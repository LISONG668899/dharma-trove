# 《大宝积经》卷第一百六（阿阇世王子会、大乘方便会之一）

唐·三藏菩提流志 奉诏译

## 阿阇世王子会第三十七

【按】译者题名，明本无“大”字，“三藏”作“三藏法师”。本会异译有西晋竺法护译《佛说太子刷护经》（T0343）、失译《佛说太子和休经》（T0344）。

#### 师子王子请问菩萨行

如是我闻：一时，佛在王舍城耆阇崛山中，与大比丘众一千二百五十人在一起。那时阿阇世王所爱的儿子，名为师子，与他的同伴五百人一起，都已趣向阿耨多罗三藐三菩提，各自持着种种幢幡宝盖，从王舍城前往耆阇崛山，到如来所礼拜供养。于是王子合掌恭敬，对佛说：“唯愿如来为我宣说诸菩萨行。”那时王子便说颂道：

```
云何得端正？莲花中化生？
云何知宿命？愿佛为宣说。
```
（大意：怎样得到端正之身？怎样在莲花中化生？怎样能知宿命？愿佛为我宣说。）

那时如来通达诸行，到达究竟彼岸，随所问而回答，便说颂道：

```
忍辱得端正，施莲花化生，
法施知宿命，汝当如是解。
```
（大意：修忍辱得端正之身，布施莲花得莲花化生，行法布施得知宿命，你应当这样理解。）

王子又问：

```
云何得成就，三昧陀罗尼？
凡有所发言，皆令人信受？
```
（大意：怎样得以成就三昧与陀罗尼？怎样使凡有所言，都令人信受？）

世尊回答：

```
修心得三昧，忍获陀罗尼，
敬重于众生，发言人信受。
```
（大意：修心得三昧，修忍获陀罗尼，敬重众生，所说的话便令人信受。）

王子又问：

```
云何得正念？具足智慧生？
如法而修行，坚固不可坏？
```
（大意：怎样得到正念？怎样具足智慧生起？怎样如法修行，坚固不可破坏？）

世尊回答：

```
不谄得正念，巧观智慧生，
尊重所修行，护法心坚固。
```
（大意：不谄曲得正念，善巧观察便生智慧，尊重所修之行，护持正法便心意坚固。）

王子又问：

```
云何成妙相，具足三十二，
八十随形好，观者乐无厌？
```
（大意：怎样成就妙相，具足三十二相、八十随形好，令观看者欢喜无厌？）

世尊回答：

```
由施得诸相，行慈获随好，
等心于众生，观者无厌足。
```
（大意：由布施得诸相，行慈心获随形好，对众生平等存心，观看者便无厌足。）

王子又问：

```
云何得梵音、迦陵频伽声？
云何令世间，见者皆欢喜？
```
（大意：怎样得到梵音与迦陵频伽鸟那样的妙声？怎样令世间见者都欢喜？）

世尊回答：

```
诚言获梵音，迦陵由软语，
离绮言两舌，见者皆欢喜。
```
（大意：说诚实语获得梵音，说柔软语得迦陵频伽之声，远离绮语与两舌，见者都欢喜。）

王子又问：

```
由何等业行，得生诸佛前，
能请微妙义？唯愿如来说。
```
（大意：由什么样的业行，得以生在诸佛面前，能请问微妙之义？唯愿如来宣说。）

世尊回答：

```
于诸法施中，不曾为障碍，
因此故恒得，值遇诸如来。
```
（大意：对一切法布施，从不曾作障碍，因此常能值遇诸如来。）

王子又问：

```
云何离诸难，而生于善趣？
云何世世中，性常无放逸？
```
（大意：怎样远离诸难而生于善趣？怎样在生生世世中，本性常无放逸？）

世尊回答：

```
净信离诸难，持戒生善趣，
由修习于空，所生无放逸。
```
（大意：清净信心远离诸难，持戒生于善趣，由修习空性，所生之处便无放逸。）

王子又问：

```
云何获神通，及证宿命智，
能永尽诸漏？愿佛为开演。
```
（大意：怎样获得神通，以及证得宿命智，能永远尽除诸漏？愿佛为我开示演说。）

世尊回答：

```
施乘得神通，教授成宿命，
舍离于二边，由是尽诸漏。
```
（大意：布施车乘得神通，教授他人成就宿命智，舍离二边，由此尽除诸漏。）

王子又问：

```
云何净业成，魔网不能羂，
而于世世中，为众之所爱？
```
（大意：怎样成就清净之业，魔网不能罗缚，而在生生世世中为大众所爱？）

【按】“羂”，同“罥”，以绳网罗取。

世尊回答：

```
胜解成净业，精进摧伏魔，
如说而修行，所生令众爱。
```
（大意：殊胜的信解成就清净之业，精进摧伏魔，如所说而修行，所生之处令大众喜爱。）

王子又问：

```
云何得长寿，获少病之身，
感难坏眷属？愿牟尼宣说。
```
（大意：怎样得以长寿，获得少病之身，感得难以破坏的眷属？愿牟尼宣说。）

世尊回答：

```
不害得长寿，除他忧少病，
诤讼使和安，得难坏眷属。
```
（大意：不伤害众生得长寿，解除他人忧苦得少病，调解诤讼使人和睦安宁，得难以破坏的眷属。）

【按】“诤讼使和安”之“安”，宋、元、明、宫本作“合”。

王子又问：

```
云何得财富，资具无损减，
于世世所生，成就大威德？
```
（大意：怎样得到财富，资具无有损减，在生生世世所生之处，成就大威德？）

世尊回答：

```
不嫉获财富，无悭资具增，
谦下成尊贵，有威德自在。
```
（大意：不嫉妒获得财富，不悭吝资具增长，谦下成就尊贵，有威德而自在。）

王子又问：

```
云何获大力，众魔不能害，
威势常超胜？唯愿人尊说。
```
（大意：怎样获得大力，众魔不能伤害，威势常常超胜？唯愿人中尊宣说。）

世尊回答：

```
恒施上味食，恐怖令安隐，
由斯得大力，威势常超胜。
```
（大意：常布施上妙饮食，令恐怖者得安稳，由此得大力，威势常常超胜。）

王子又问：

```
云何得成就，天眼及天耳？
云何能了知，种种众生心？
```
（大意：怎样得以成就天眼与天耳？怎样能了知种种众生之心？）

世尊回答：

```
施灯感天眼，奉乐成天耳，
远离于二边，故获他心智。
```
（大意：布施灯明感得天眼，奉献音乐成就天耳，远离二边，所以获得他心智。）

王子又问：

```
云何得净土，及以众圆满，
获随体圆光？功德海当说。
```
（大意：怎样得到清净佛土，以及眷属大众圆满，获得随身圆光？功德之海请为宣说。）

世尊回答：

```
由愿得净土，忍力众成就，
施众妙宝帐，得周遍圆光。
```
（大意：由发愿得清净佛土，以忍辱之力成就大众，布施众多妙宝帐幔，得周遍的圆光。）

王子又问：

```
云何所生处，菩提心不坏，
乃至于梦中，亦无有忘失？
```
（大意：怎样在所生之处菩提心不坏，乃至在梦中也不会忘失？）

世尊回答：

```
凡所游行处，城邑聚落中，
化众趣菩提，菩提心不坏。
```
（大意：凡所游行之处，在城邑聚落之中，教化众人趣向菩提，菩提心便不坏。）

王子又问：

```
云何大牟尼，为众之所爱，
摄取一切法？唯愿人尊说。
```
（大意：大牟尼！怎样为大众所爱，摄取一切法？唯愿人中尊宣说。）

世尊回答：

```
胜志乐具足，不退菩提心，
由此摄诸法，为众之所爱。
```
（大意：具足殊胜的志乐，不退失菩提心，由此摄取诸法，为大众所爱。）

#### 如来微笑授记

那时王子与诸大众听了这些偈颂，都这样说：“如佛所说的这些妙行，我们从今以后都当修学。”这时如来便现微笑，放大光明，遍照无量无边世界。于是弥勒菩萨对佛说：“世尊！以什么因缘现这微笑？愿为宣说，断除疑惑。”

那时佛告诉弥勒菩萨摩诃萨说：“善男子！这些王子等五百同伴，都在往昔为求无上正等菩提，恭敬供养十那由他八十亿诸佛。而我往昔在然灯佛时，作婆罗门之子，成熟了他们。而那些人在未来世，于弥勒佛等诸世尊前，常受化生，亲自承事供养。这样奉事十亿如来，满三百劫，其中最后一佛号为无边智善学诸法。那时无边智佛知道那些人心中的欲乐，各随所应，为他们授阿耨多罗三藐三菩提记：同在安乐光严劫中成等正觉，都号为智慧幢相。这些佛刹所有的庄严，也如西方无量寿佛国一样，没有差别。善男子！若有众生听闻这里所说而生信解，发愿当成大菩提，应当知道这人所获的功德，在三世中无与伦比。善男子！若有人能在六百劫中，常以众宝遍于诸佛刹土奉施如来；又若有人听闻这部经典所生的善根，与前面的功德相比，前者是算数校计所不能及的。”

【按】“遍于诸刹”之“于诸”，宋、元、明、宫本作“诸佛”。

宣说此法时，众中八十亿众生一时趣向阿耨多罗三藐三菩提。又这三千大千世界都震动，天上降下妙花。那时王子与五百同伴听闻授记之后，欢喜踊跃，都这样想：“我们必定当成无上觉。”于是王子以及诸位同伴，作了供养之后，获得五神通，便在佛前种种变现，出家修道。

那时诸菩萨摩诃萨以及诸天人中所有趣向大菩提的人，见到那王子与诸同伴随大众所乐示现神变，都大欢喜，都这样说：“师子王子所问的疑惑，如来法王都为他断除了。这样，世尊不可思议，如来的正法以及能信受的人，乃至果报，都不可思议。如来的功德无量无边，对一切法无不明达，为世间导师，度化未得度的人，普遍能到十方世界，已完全了知三世诸法。哪一位智者听闻这样能生安乐之处的功德之聚，而不发起猛利的信乐，趣求菩提呢？”

佛说此经之后，师子王子等五百同伴欢喜奉行。

## 大乘方便会第三十八之一

东晋·天竺居士竺难提 译

【按】本会异译有西晋竺法护译《慧上菩萨问大善权经》（T0345）、宋施护译《大方广善巧方便经》（T0346）。

#### 智胜菩萨问方便

如是我闻：一时，佛在舍卫国祇树给孤独园精舍，与大比丘八千人在一起，都是有学、无学的大声闻众。又有菩萨摩诃萨一万二千人，都已得神通，为众人所知识，得陀罗尼与无碍辩才，得诸法忍，无量功德都已成就。

那时如来从三昧起，有无量百千万亿众生恭敬围绕，佛为他们说法。那时众中有一位菩萨摩诃萨，名为智胜，便从座起，偏袒右肩，右膝著地，合掌向佛，对佛说：“世尊！我想请问一事，唯愿听许。若佛允许，我才敢咨请。”佛告诉智胜菩萨：“善男子！任你所问，当为你说，断除你的疑惑。”

那时智胜菩萨对佛说：“世尊！所说的方便，什么是菩萨的方便？世尊！菩萨摩诃萨怎样行于方便？”这样问了之后，佛赞叹智胜菩萨说：“善哉善哉。善男子！你为了诸菩萨摩诃萨而问方便的义理，多所利益，多所安乐，怜愍世间，利益安乐诸天与世人，为了摄持未来诸菩萨的智慧以及过去、未来、现在诸佛之法。善男子！当为你说。谛听谛听，好好思念。”智胜菩萨受教而听。

【按】“利益安乐诸天世人”之“诸”，《大正藏》作“唯”，今依CBETA作“诸”。

#### 一抟食施一切众生

“善男子！行方便的菩萨，以一抟食布施给一切众生。为什么呢？行方便的菩萨以一抟食施与，下至畜生，愿求一切智，因此菩萨与一切众生共同享有这善根，回向阿耨多罗三藐三菩提。以这两种因缘摄取一切众生，就是求一切智之心以及愿方便。善男子！这名为菩萨摩诃萨行于方便。

#### 随喜施者

“又，善男子！菩萨摩诃萨行于方便，若见到行布施的人，生起随喜之心，以这随喜的善根，愿与一切众生共同享有，回向阿耨多罗三藐三菩提。这位方便菩萨也愿施者与受者都不离一切智心；假使受者是二乘人，也愿他不离一切智心。这名为菩萨摩诃萨行于方便。

#### 合集花香供佛

“又，善男子！菩萨摩诃萨行于方便，若见到十方世界中无主的花树以及种种香，便在心中合集起来，愿以此供养诸佛。若见到十方世界中有主的花香，或香或叶，被风所吹的，都在心中合集起来，愿以此供养十方诸佛。以这善根，或为自己，或为一切众生，具足一切智心。以这善根因缘的缘故，得无量的戒、定、慧、解脱、解脱知见。这名为菩萨摩诃萨行于方便。

#### 见乐愿乐，见苦代受

“又，善男子！菩萨摩诃萨行于方便，若见到十方世界众生受种种乐报，见后这样想：‘愿一切众生得一切智之乐。’若见到十方世界众生受种种苦报，便为诸众生忏悔诸罪，作这样的大庄严：‘这些众生所受的苦恼，我都代他们承受，令他们得乐。以这善根，愿成一切智，除去一切众生的苦恼。’以这因缘的缘故，终究不受一切诸苦，纯受诸乐。这名为菩萨摩诃萨行于方便。

#### 礼一佛即礼一切佛

“又，善男子！菩萨摩诃萨行于方便，若礼拜一佛，恭敬供养，尊重赞叹，便这样想：‘一切如来同一法界，同一法身，同一戒、同一定、同一慧、同一解脱、同一解脱知见。’这样想之后，应当知道，若礼拜一佛，恭敬供养，尊重赞叹，就是礼拜、供养、恭敬、尊重、赞叹一切诸佛。若供养一佛，就是供养十方诸佛。这样便已供养了十方佛。这名为菩萨摩诃萨行于方便。

#### 解一偈义即知一切佛法

“又，善男子！菩萨摩诃萨行于方便，若是钝根之人，不应自己轻视自己；乃至若能通晓一首四句偈，便这样想：‘若理解一首四句偈的义理，便知一切佛法，一切佛法都摄在这一偈的义理之中。’这样通达之后，心不懈怠，若到诸国城邑聚落，以慈悲心广为人说，不求利养、名闻、赞叹，作这样的愿：‘这四句偈，愿令他人得闻。以这善根因缘方便，愿令一切众生多闻都如阿难，并得如来的辩才。’这名为菩萨摩诃萨行于方便。

#### 贫穷乞食施僧

“又，善男子！菩萨摩诃萨行于方便，若生在贫穷之家，这菩萨乃至乞食，若得到一抟食，便用来施僧。若只施一人，也不以为羞愧，应当这样想：‘如佛所说，心意增广殊胜，胜过财物布施。我的财施虽少，以一切智心，愿这善根成就一切智，令诸众生都得宝手，犹如如来。’以这缘故，具足布施、持戒、禅定的福处。这名为菩萨摩诃萨行于方便。

【按】“一抟食用施僧”之“食”，宋、元、明本作“食持”，宫本作“持”。“宝手”，谓手中能出无尽珍宝，随意施与。

#### 见二乘得利养，以二缘自慰

“又，善男子！菩萨摩诃萨行于方便，若见声闻、缘觉多得利养、尊重、赞叹，这菩萨便以两种因缘自我宽慰其心。哪两种？就是因为有菩萨才有诸如来，因为有如来才有声闻、缘觉。这样思惟：‘二乘之人虽得利养，我仍胜过他们。他们所食用的，是我父亲的财物，我怎能对此生起希求之心？’这名为菩萨摩诃萨行于方便。

#### 行施具六度

“又，善男子！菩萨摩诃萨行于方便，行布施时具足六波罗蜜。哪六种？善男子！菩萨行方便时，若见到乞讨的人，除去悭惜之心，具足大施，这名为檀波罗蜜（布施度）。自己持守禁戒，布施给持戒的人；见到破戒的人，劝他持戒，劝他持戒之后才给予布施，这名为尸波罗蜜（持戒度）。自己除去瞋恚，行于慈愍，心无秽浊，利益众生，以平等心而布施，这名为羼提波罗蜜（忍辱度）。若布施饮食汤药，当即具足身心的精进，来去进止、屈伸俯仰（都精勤不懈），这名为毘梨耶波罗蜜（精进度）。若布施之后其心得定，欢喜悦豫，专念不乱，这名为禅波罗蜜（禅定度）。这样布施之后分别诸法：施者是谁？谁是受者？谁是受报者？这样观察之后，没有一法名为施者，或受施的人，以及受报者，这名为般若波罗蜜（智慧度）。善男子！这名为菩萨摩诃萨行于方便，具足六波罗蜜。”

【按】“毘梨耶”之“梨”，明本作“离”。

那时智胜菩萨对佛说：“世尊！真是未曾有。菩萨摩诃萨行于方便，就在布施之时，以这布施摄取一切佛法以及诸众生。”佛告诉智胜菩萨：“善男子！如你所说。菩萨摩诃萨行于方便，以方便之力，虽然行少许布施，所得的福德无量无边阿僧祇。”

#### 远离劝早入涅槃的恶知识

佛又告诉智胜菩萨：“善男子！菩萨摩诃萨虽然已到不退转地，也以方便而行布施，这名为菩萨行于方便。善男子！有时恶知识教菩萨说：‘你何必长久处在生死中？可以在此身早入涅槃。’菩萨知道后，便应远离他，（心想：）‘我这样以大庄严教化一切众生，这人却为我制造种种留难。若我不在生死之中，怎能教化无量众生？’”

#### 菩萨何为犯重罪

智胜菩萨对佛说：“世尊！若有众生因为妄想而犯了四重罪（，又当如何）？”佛告诉智胜菩萨：“善男子！若出家菩萨因为妄想犯了四重罪，行方便的菩萨能完全除灭。我现在也说，没有犯罪者以及受报者。”

智胜菩萨对佛说：“世尊！菩萨怎样是犯罪？”佛告诉智胜菩萨：“善男子！菩萨虽然行持解脱戒，在百千劫中吃果子、食草，能忍受众生善恶的言语，若与声闻、缘觉共同思惟其法（，以其法为心），善男子！这名为菩萨摩诃萨犯于重罪。善男子！如声闻人犯了重禁，不能就在此身证入涅槃。善男子！菩萨也是这样，若不除去与声闻、缘觉共同思惟其法，不舍弃、不悔改，终究不能成就阿耨多罗三藐三菩提；若说能得佛法，没有这个道理。”

#### 众尊王菩萨与女人同坐

那时尊者阿难对佛说：“世尊！我今天早晨入舍卫城次第乞食，见到众尊王菩萨与一位女人同坐在一张床上。”阿难说了这话，当即大地六种震动。众尊王菩萨在大众中上升虚空，高七多罗树，对阿难说：“尊者！哪有犯罪的人能住于空中呢？阿难！可以拿这件事去问世尊：什么是罪法？什么不是罪？”

那时阿难心怀忧愁，向佛右膝著地，手执佛足：“世尊！我现在悔过。这样的大龙，我说他犯罪；这样的菩萨，我寻求他的过失。世尊！我现在悔过，唯愿允许。”

佛告诉阿难：“你不应在大乘大士身上寻求他的罪过。原文：“阿难！汝声闻人，于障处行寂灭定，无有留难断一切结。”（大意：阿难！你们声闻人，要在避开障碍之处修寂灭定，才能没有留难而断一切结。存疑。）阿难！行方便的菩萨这样成就一切智心，虽然在中宫与婇女共相娱乐，不起魔事以及种种留难，而得阿耨多罗三藐三菩提。为什么呢？原文：“阿难！行方便菩萨无有受如是众生不以三宝劝化，若阿耨多罗三藐三菩提。”（大意：阿难！行方便的菩萨所摄受的这些众生，没有不以三宝或阿耨多罗三藐三菩提来劝化的。存疑。）阿难！若修学大乘的善男子、善女人不离一切智心，若见到可意的五欲，便在其中共相娱乐。阿难！你应当这样想：‘这位菩萨就是能成就如来的根本。’”

【按】“于障处行”之“障”，宫本作“彰”。

佛告诉阿难：“你现在谛听谛听。以什么缘故，众尊王菩萨摩诃萨与这女人同坐一张床？阿难！那女人曾在过去五百世中，作众尊王菩萨的妻子。那女人因为本来的习气，见到众尊王菩萨，心生爱著，系缚不舍。这位众尊王菩萨因为威德端正、持戒之力，她见了之后欢喜踊跃，在一个独处的地方生起这样的心：‘若众尊王菩萨能与我同坐一张床，我当发阿耨多罗三藐三菩提心。’阿难！那时众尊王菩萨知道那女人心中所想，这样知道后，便在早晨著衣持钵，入舍卫城次第乞食，到了那女人家，便进入她的屋舍，随即思惟这样的法门：‘或内在的地大，或外在的地大，都是同一个地大。’以地大之心执女人的手，共坐一张床。众尊王菩萨便在座上说偈道：

```
如来不赞叹，凡夫所行欲；
离欲及贪爱，乃成天人师。
```
（大意：如来不赞叹凡夫所行的欲，离开欲与贪爱，才能成为天人师。）

【按】“说偈言”之“言”，宋、元、明、宫本作“曰”。

佛告诉阿难：“那时那女人听了这偈，心中大欢喜，踊跃无量，便从座起，向众尊王菩萨接足敬礼，说偈道：

```
我不贪爱欲，贪欲佛所呵。
离欲及贪爱，乃成天人师。
```
（大意：我不贪爱欲，贪欲是佛所呵责的，离开欲与贪爱，才能成为天人师。）

【按】“踊跃”，《大正藏》作“跃踊”，今依CBETA（所录高丽藏）作“踊跃”。

“说了这偈，又这样说：‘我先前所生的恶欲之心，现在应当悔过。’便生起善欲，发菩提心，愿利益一切众生。”

佛告诉阿难：“那时众尊王菩萨劝那女人发阿耨多罗三藐三菩提心之后，便从座上离去。阿难！你看这女人专心（所得的）福报：我现在以正遍知为这女人授记，她在此命终后，得以转女身而成男子，在将来世九十九劫中，供养百千无量阿僧祇诸佛，具足一切佛法，得以成佛，号为无垢烦恼如来、应供、正遍知。那佛成道之后，当那时世，没有一人生起不善心。阿难应当知道，行方便菩萨所摄受的眷属，终究不堕三恶道。”

#### 众尊王菩萨誓不舍一人

那时众尊王菩萨从空中下来，顶礼佛足，礼后对佛说：“世尊！菩萨行于方便，若为一个人生起大悲心，合集善法，或似乎犯罪，或真实犯罪，（以致）在百千劫中堕大地狱。世尊！这菩萨能忍受种种恶以及地狱之苦，以这善根，愿不舍弃一人。”

#### 树提梵志悲愍女人

那时世尊赞叹众尊王菩萨说：“善哉善哉。善男子！菩萨成就这样的悲心，虽受五欲，不犯重罪，离于种种罪，远离一切堕恶道之业。善男子！我忆念过去阿僧祇劫，又超过这个数目，那时有一位梵志，名为树提，在四十二亿岁中于空林里常修梵行。那时梵志过了这么多岁月，从林中出来，进入极乐城，入城后见到一位女子。那时女人见这梵志仪容端严，便生起欲心，随即走向梵志，用手抓住他的脚，当即倒地。善男子！那时梵志告诉女人说：‘姊妹，你求什么？’女子说：‘我求梵志。’梵志说：‘姊妹！我不行欲事。’女子说：‘若不顺从我，我现在就要死。’

【按】“即时躄地”之“躄”，宫本作“僻”。

“善男子！那时树提梵志这样思惟：‘这不是我的法，也不是我的时候。我四十二亿岁修清净梵行，怎能在今天毁坏？’那时梵志勉强挣脱，得以离开七步。离开七步后，生起哀愍之心，这样思惟：‘我虽然犯戒堕于恶道，我能忍受地狱之苦；我现在不忍心看见这女人受这样的苦恼，不让这人因我而死。’善男子！那时梵志又这样思惟之后，回到女人处，用右手拉她起来，这样说：‘姊妹起来，随你所欲。’善男子！那时梵志在十二年中与她共为家室，过了十二年后，随即又出家，当即又具足四无量心，具足之后，命终生于梵天之中。

【按】“寻复出家”之“寻”，《南藏》作“还”。

“善男子！你不要怀疑。那时的梵志就是我身，那女人就是现在的瞿夷（释尊为太子时之妃）。善男子！我在那时为那女子的欲事暂时生起悲心，便得超越十百千劫生死之苦。善男子！你这样观察：其余众生由于爱欲的缘故堕于地狱，行方便的菩萨却由此生于梵天。这名为菩萨摩诃萨行于方便。”

#### 无垢比丘飞空救五仙人

佛又告诉智胜菩萨：“善男子！若舍利弗、大目犍连等能行方便，便不会让瞿伽离堕于地狱。为什么呢？善男子！我忆念过去世拘留孙佛时，有一位比丘名为无垢，在空林野地中住在洞窟里。离洞窟不远处有五位仙人。那时忽然起了大云，降下大雨，有一个贫穷女子在路上遇到暴雨，衣不蔽体，寒冷恐怖，便进入无垢所住的洞窟中。雨停后，无垢比丘与这女人一同从窟中出来。那时五位仙人见到这事，心生污秽的念头，互相说：‘无垢比丘心怀奸诈，作了不净之行。’

“那时无垢比丘知道那些仙人心中所想，便纵身跃上虚空，高七多罗树。那时五位仙人见无垢比丘上升虚空，见后又互相说：‘我们所见的书记经论中说，若人作不净行，不能这样飞升虚空；若修清净之行，便能这样。’那时仙人便向无垢五体投地，合掌悔过，不敢覆藏。”

佛告诉智胜菩萨：“善男子！那时无垢比丘若不作这样的方便飞升虚空，这五位仙人便会以这现生之身堕入地狱。善男子，那时的比丘难道是别人吗？就是弥勒菩萨。善男子！你现在应当知道，舍利弗、目犍连若作这样的方便飞升虚空，瞿伽离比丘便不会堕地狱。善男子！你现在应当知道，诸菩萨摩诃萨所行的方便，是声闻、缘觉所没有的。

#### 婬女、黑蜂、种子、鱼师、咒术之喻

“善男子！譬如婬女善知六十四种媚态，为了财宝，以媚言引诱他人，假意许身，对对方所看重的财物毫不吝惜（地索取），后来得到了那财物；得到财物之后，便将他驱逐离去，不生悔心。善男子！行方便的菩萨能知随宜而行方便，这样教化一切众生，随他们所欲而为他们现身，对他们所需之物，心无吝惜，乃至为众生舍身，爱乐善根，不求果报。知道众生作了善根之后心不退转，便在那时心生舍离，所示现的五欲永无恋著。

【按】“六十四态”之“态”，宫本作“能”。“无所匮惜”之“匮”，宫本作“遗”。

“善男子！譬如黑蜂在畜生之中，对一切花虽然经历其香味，而对其中没有依止之想，没有爱著，对花、叶、茎、香都不带走而离去。善男子！菩萨摩诃萨行于方便也是这样，为了教化众生处在五欲之中，见法无常，不以常想而生起爱著，又不害自己，也不害他人。

【按】“虽经香味”之“经”，宋、元、明本作“著”，宫本作“遥”。“亦得如是”之“得”，宋、元、明本作“复”，今依此译作“也是这样”。

“善男子！如小种子虽然生出芽，然而它的本色没有亏损，不生出异物。善男子，就是这样，空、无相、无作、无我的智慧种子，菩萨虽有烦恼，处于五欲娱乐中，不生三恶道之芽，不损善根之色，也不退转。

【按】“生于牙”之“牙”，宋、元、明、宫本作“芽”，下同。

“善男子！譬如渔师用饵食涂在网上，投入深渊，满足所求之后便随即拉出。善男子！行方便的菩萨也是这样，以空、无相、无作、无我的智慧熏修其心，结成网，以一切智心为涂饵，虽然投入五欲的污泥之中，如其所愿，拉出欲界，命终之后生于梵世。

【按】“勋修”之“勋”，明本作“熏”，今依此译作“熏修”。

“善男子！譬如有人善知咒术，被官府抓捕，受五种系缚，这人凭借咒术之力，便断开五缚，随愿而去。善男子！菩萨摩诃萨行于方便也是这样，虽然处在五欲中共相娱乐，为了教化众生，如其所求，以一切智之咒断除五欲之缚，生于梵世。

【按】“呪术”之“呪”，宫本作“祝”。

#### 健士藏刀之喻

“善男子！譬如有一位男子善知战法，藏着一把利刀，护送行人。而那些人中没有一个人能知道这人暗怀奇谋，反而轻视他，更生怜愍，没有敬重之心，互相说：‘那人既没有兵器，也没有同伴，这不是健士，又没有势力，自身都救不了，怎能救济别人？说他能破贼，没有这个道理。那人必定会遭受种种困厄。’那时这男子到了空旷的沼泽，群贼一齐出来。那时男子牢牢地自我装备，随即拔出所藏的刀，刚一挥刀，群贼便丧命；诸贼被破之后，又把刀藏起来。

【按】“密怀”，宫本作“蜜怀”。

“善男子！行方便的菩萨善于隐藏智慧之刀，而以方便处在五欲中共相娱乐，为了教化众生。声闻见到这位方便菩萨处在五欲中共相娱乐，不知是方便，所以生起浊心，或又怜愍他，认为他放逸：‘这样的人尚且不能自度，何况能救度一切众生？说他能破魔，没有这个道理。’那时菩萨善用方便智慧之刀，如其所求，断除诸烦恼，令其完全摧灭，以智慧之刀到达清净佛土，没有诸女人，乃至没有一念欲想。”

【按】“况能救度”之“况”，宋、元、明、宫本作“何况”；“度”字，宋、元、明、宫本无。

#### 爱作菩萨与德增女

那时有一位菩萨名为爱作，入舍卫城次第乞食，渐渐到了一位长者家。长者有一个女儿名为德增，住在高楼上。那时这女人听到菩萨的声音，随即拿着食物出来走向爱作菩萨。女子见到菩萨，执取他的形容、相好、音声，欲心当即生起，被欲火所烧，当即命终，骨节解散。

爱作菩萨见到德增女，也生起恶觉与婬欲之心。那时爱作菩萨便自己思惟：原文：“云何彼法？法者为著。”（大意：那法是什么？所谓法，只是所执著的对象。存疑。）“那眼是什么？哪个是这眼？眼的本性没有知觉，只是一团肉，不爱、不知、不思、不觉、无所分别，其本性本来是空。耳、鼻、舌、身、意、法也是这样。”他观察薄皮厚皮、血肉脂肪、发毛爪齿、骨髓筋脉，从脚到头这样观察之后，或内或外，没有一法可以爱著，或可以瞋、可以痴。对一切法如实观察，便离于欲心，得无生忍。

【按】“肉团”之“团”，宋、元本作“搏”，明本作“抟”，宫本作“揣”。

得无生忍之后，他心中欢喜踊跃无量，便升到虚空中，高一多罗树，绕舍卫城七圈。那时世尊见爱作菩萨飞腾虚空，犹如鹅王，无所挂碍。佛见了之后，告诉阿难说：“阿难！你见到爱作菩萨飞腾虚空，犹如鹅王，无所挂碍吗？”阿难说：“是的，已经见到。”佛告诉阿难：“这位爱作菩萨因为生起欲心而推求诸法，便破坏魔众，将转法轮。”

#### 德增天子来诣佛所

那时德增女命终之后生于三十三天，转女身而得成男子，自然处在七宝宫殿中，纵广正等十二由旬，有一万四千位天上的婇女作为侍卫。这位德增天子能知宿命，推究先前的业行：“以什么业缘而生到这里？”这样思惟后，见到自己在舍卫城中作长者之女，因为见爱作菩萨生起婬欲之心，欲心炽盛，当即命终，便转女身得成男子。“我因为这件事得到无量神力。”

【按】“婇女”之“婇”，宫本作“采”。“因见爱作”之“因见”，宋、元、明、宫本无。

那时德增天子这样思惟：“因为生起婬欲而得到这样的果报。现在我对爱作菩萨心意甚为清净，当礼敬供养。我现在若还住在先前所受的五欲之中，这不是我所宜。”这样思惟后，便要前往如来处，并想见爱作菩萨，礼敬供养。

【按】“先受五欲”之“受”，元、明、宫本作“爱”。

那时德增天子与他的眷属，持着天花、香、涂香、末香，就在初夜来到佛所，以自身光明普照祇洹（即祇园精舍），入内觐见世尊，并见到爱作菩萨，便以天花、末香、涂香供养佛，顶礼佛足以及爱作菩萨与一切大众，右绕三圈，合掌向佛，便说偈道：

```
天人之尊，不可思议，菩萨所行，亦不可议。
如来之法，不可思议，大名称者，亦不可议。
我昔舍卫，曾为童女，在长者家，名曰德增。
其年幼少，颜貌端正，父母爱念，为作遮护。
如来世尊，无有轻戏，有子爱作，有大威德。
入舍卫城，而行乞食，渐到我父，所止之舍。
我时闻其，好妙音声，心大欢喜，即持食出。
寻时向于，行大心者，如来之子，爱作菩萨。
见菩萨时，已在我心，观其净妙，心生染欲。
我若不得，内心所愿，便当即时，身命殒没。
我于尔时，口不能言，手所持食，不能与之。
内心怀热，而发婬欲，是时身热，寻便命终。
我时命终，经一念顷，寻得上生，三十三天。
离于最下，女人之身，得成男子，为人所赞。
胜妙宫殿，自然而出，种种妙宝，人之所珍。
具足一万，四千婇女，如是眷属，是我所有。
我以此缘，寻观宿命，而自思惟，即知往因。
```
（大意：天人之尊不可思议，菩萨所行也不可思议；如来之法不可思议，大名称者也不可思议。我往昔在舍卫城，曾为童女，在长者家，名叫德增，年纪幼小，容貌端正，父母爱念，为我遮护。没有轻戏的如来世尊，有一位佛子名叫爱作，有大威德。他入舍卫城乞食，渐渐到了我父亲所住的屋舍。我那时听到他美妙的声音，心中大欢喜，便拿着食物出来，随即走向这位行大心者、如来之子爱作菩萨。见到菩萨时，他已经在我心里了；看着他清净美妙的样子，心生染欲：我若不能得到内心所愿，便当即身命殒没。我在那时口不能言，手中所持的食物也不能给他，内心怀着热恼，生起婬欲，那时身体发热，随即命终。我那时命终，只经一念之顷，随即上生三十三天，离开了最下劣的女人之身，得成男子，为人所赞。殊胜美妙的宫殿自然现出，种种妙宝都是人所珍爱的，具足一万四千婇女，这样的眷属都为我所有。我以此因缘，随即观察宿命，自己思惟，便知往昔的因缘。）

```
因发欲心，得如是报，我以染心，视于爱作，
由见菩萨，得喜光明。我身所出，光明之焰，
因彼业缘，得如是报。我终不愿，求于二乘，
所愿之处，唯佛知之。婬欲之心，得报尚尔，
何况能作，善心供养。如我于今，向于世尊，
发如是愿，求一切智。假使所行，劫如恒沙，
终不退转，于佛智慧。遇善知识，爱作菩萨，
今我当以。真法供养，若余供养，非为供养，
唯发菩提，是真供养。行于菩提，最胜最尊。
更不以欲，视诸女人，我愿如是，离于女身。
```
（大意：因为发起欲心，得到这样的果报。我以染心看着爱作，由于见到菩萨而得欢喜光明，我身上所出的光明之焰，是因为那业缘而得到这样的果报。我终究不愿求二乘，我所愿之处，唯有佛知道。婬欲之心得报尚且如此，何况能以善心供养！如我现在向世尊发这样的愿，求一切智，假使所行之劫多如恒河沙，终究不会从佛的智慧中退转。我遇到善知识爱作菩萨，现在我当以真法供养；其余的供养不是真供养，唯有发菩提心才是真供养，行于菩提最胜最尊。我不再以欲心看诸女人，我愿这样离开女身。）

```
向诸佛说，四无所畏，我之父母，寻晓见我，
身坏碎烂，悲号啼哭。父母谓之，比丘所为，
称怨啼哭，呵骂比丘。佛之神力，令彼天子，
至父母所，呵责谏喻：于此比丘，勿生瞋恚，
莫于长夜，受诸苦恼。德增女人，先命终已，
即得上生，三十三天。离于女身，得成男子，
为天人身，光明远照。父母今当，诣世尊所，
先不善心，今应悔过。若除如来，诸佛世尊，
更无有人，可归依者。以无畏心，劝喻父母，
即时父母，得闻佛名。寻共和合，至于释迦，
牟尼佛所。至佛所已，头顶敬礼，二足之尊。
今者悔过，本瞋恚心；恭敬尊重，人中之尊。
今者应问，如来自知。云何供养，佛法及僧？
云何修习，行于善行？如是所问，愿为说之，
若得闻已，专心修行。佛知父母，其心决定，
天人之师，说如是言：若欲供养，一切诸佛，
专心坚固，发菩提心。德增父母，及诸眷属，
其数具足，满五百人。闻天人师，如是之言，
```
（大意：向诸佛宣说四无所畏（存疑）。我的父母天亮时看见我，身体坏碎烂坏，悲号啼哭；父母认为是那比丘所为，称怨啼哭，呵骂比丘。佛的神力令那天子到父母处呵责劝谕：“对这位比丘不要生瞋恚，不要在长夜中受种种苦恼。德增女人先前已经命终，随即上生三十三天，离开女身，得成男子，为天人之身，光明远照。父母现在应当前往世尊之所，先前的不善之心，现在应当悔过。除了如来诸佛世尊，再没有人可以归依。”他以无畏之心劝谕父母，当时父母得闻佛名，随即一同前往释迦牟尼佛所。到了佛所，以头顶敬礼二足之尊：“现在悔过本来的瞋恚之心，恭敬尊重人中之尊。现在应当请问，如来自然知晓：怎样供养佛、法与僧？怎样修习善行？所问的这些，愿为我们宣说，若得听闻，当专心修行。”佛知道父母心意决定，天人之师说这样的话：“若想供养一切诸佛，应当专心坚固，发菩提心。”德增的父母以及诸眷属，人数具足满五百人，听闻天人师这样的话，）

```
发菩提心，而作大愿。尔时佛告，贤者阿难：
汝今善听，我之所说。菩萨所行，不可思议，
无上智慧，及以方便。爱作菩萨，数数发愿，
女人见我，若发欲心，寻时得离，于女人身，
得成男子，为人所尊。阿难汝观，德力如是，
若犯非法，应堕恶道。健士行之，得坏魔众，
令彼生天，得为天人。今此天子，供养于我，
其心恭敬，正向菩提。彼当供养，无量世尊，
来世成佛，号曰善见。此五百人，向菩提者，
亦当作佛，为天人师。佛有是德，谁不供养？
是处深信，得无量乐。非一女人、非二非三，
无量百千，那由他亿，见于爱作，发婬欲心，
寻即命终，得为男子。大医药王，有大名称，
如是菩萨，谁不尊敬？虽生欲心，更得快乐，
况于菩萨，生恭敬心。
```
（大意：便发菩提心而作大愿。那时佛告诉贤者阿难：“你现在好好听我所说。菩萨所行的无上智慧以及方便，不可思议。爱作菩萨屡屡发愿：女人见到我，若发欲心，随即得离女人之身，得成男子，为人所尊。阿难你看，他的德力就是这样。若犯非法，本应堕于恶道；健士行之，却能破坏魔众，令那人生天，得为天人。现在这位天子供养于我，其心恭敬，正向菩提；他将供养无量世尊，来世成佛，号为善见。这五百人趣向菩提，也将作佛，为天人师。佛有这样的功德，谁不供养？对此深信，得无量之乐。不是一个女人，不是两个、三个，而是无量百千那由他亿女人，见到爱作而发婬欲心，随即命终，得为男子。大医药王有大名称，这样的菩萨，谁不尊敬？对他虽生欲心，尚且更得快乐，何况对菩萨生起恭敬之心！”）

【按】“寻共和合”之“共”，宫本作“其”。“云何供养”之“何”，《大正藏》作“可”，今依CBETA（所录高丽藏）作“何”。“菩萨所行”之“所”，宫本作“尔”。
