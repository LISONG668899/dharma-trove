<div class="dt-subtitle">成唯识论白话译注（二十三）　卷第八之中<br>护法等菩萨造　唐　玄奘译</div>

本篇要目：一、第十九颂　二、第一解：业习气与二取习气　三、第二解：三种习气　四、第三解：惑、业、苦　五、十二有支略摄为四：能引支　六、所引支　七、能生支　八、所生支　九、诸支立名的理由　十、一重因果足以显示轮转　十一、诸支的种种分别　十二、诸支与诸受、四谛、四缘　十三、惑业苦摄十二支

一、第十九颂

外人质问：只有内识，没有外缘，有情的生死怎能相续？世亲菩萨用颂回答：

```
由诸业习气　二取习气俱
前异熟既尽　复生余异熟
```

大意：由于种种业的习气，与二取的习气共同作用，前一期的异熟果报受尽了，又生起后一期的异熟果报。

二、第一解：业习气与二取习气

论中解释：“诸业”，是指福业、非福业、不动业，就是有漏的善与不善的思业。业的眷属也立“业”的名称，因为同样招感引业和满业的异熟果。

【译注】福业是欲界的善业，非福业是不善业，不动业是色界、无色界禅定的善业，所感的果报不会动摇改变。

业刚一生起，紧接着就灭了，没有道理能招感将来的异熟果。业熏习本识，生起自己的功能，业的功能就称为习气，是业的气分熏习所成，为了简别过去现行的业，所以称为“习气”。业的习气展转相续，到成熟时，招感异熟果。以上显示的是将来果报殊胜的增上缘。

相分与见分、名与色、心王与心所、本与末，所取的都属于“二取”。由二取所熏发、能直接生起二取的本识上的功能，称为二取习气。以上显示的是来世异熟果的心王，以及相应心所的一切因缘种子。

【译注】二取有四种解释：一取相分和见分；二取名和色，即五蕴；三取心王和心所；四取本和末，本是第八识的真异熟，末是前六识的异熟生。四种解释，都是指来世果报身心的直接种子。

颂中的“俱”，是说业种子与二取种子同时俱在，一是疏缘，一是亲缘，互相帮助。业招感生死的作用显著，所以颂中先说业。

“前异熟”是指前前诸生的业所感的异熟果；“余异熟”是指后后诸生的业所感的异熟果。

二取种子受果无穷无尽，业习气受果有穷尽。

```
异熟果性别难招，
等流增上性同易感。
```

大意：异熟果与因的性质不同，难以招感；等流果和增上果与因的性质相同，容易招感。

【译注】二取种子生同类的果，是等流，生了一次又能再生，相续无穷。业种子感异类的果，善恶业感无记的身心，属于异熟，异类相生费力，一旦感果，势力就用尽了。所以一期生命终有结束，二取种子永不枯竭，只要新的业种成熟，就又开始新的一期。

由于感生其余诸生的业等种子成熟，前一期的异熟果受用尽时，又另外生起后一期的异熟果。由此生死轮转无穷，何必依靠外缘才得以相续？

颂的意思是：由于业和二取，生死轮回，都不离识，因为心王与心所法是业和二取的体性。

三、第二解：三种习气

其次，生死相续由于种种习气。习气总共有三种。

第一是名言习气，就是一切有为法各自的亲生种子。名言有两种：一是表义名言，就是能诠表意义的音声差别；二是显境名言，就是能了别境界的心王与心所法。随着两种名言所熏成的种子，作为一切有为法各自的因缘。

【译注】心王与心所不是语言，为什么称为“名言”？因为心能显现境界，如同名言能显示意义，所以也称为名言。说话与起念，都在熏成种子。

第二是我执习气，就是虚妄执着我和我所的种子。我执有两种：一是俱生我执，就是修道所断的我执和我所执；二是分别我执，就是见道所断的我执和我所执。随着两种我执所熏成的种子，令有情等有自他的差别。

第三是有支习气，就是招感三界异熟果的业种子。有支有两种：一是有漏的善，就是能招感可爱果的业；二是一切不善，就是能招感不可爱果的业。随着两种有支所熏成的种子，令异熟果有善趣与恶趣的差别。

应知我执习气和有支习气，对差别的果是增上缘。

颂中所说的“业习气”，应知就是有支习气。“二取习气”，应知就是我执和名言两种习气，因为是由取我、我所以及取名言而熏成的，所以都称为“取”。“俱”等其余的文义，如前面所解释。

四、第三解：惑、业、苦

其次，生死相续由于惑、业、苦。

发起业、滋润生的烦恼，称为惑；能感招后有的诸业，称为业；业所引生的众苦，称为苦。惑、业、苦的种子，都称为习气。

前两种习气，即惑与业，对生死之苦作为增上缘，帮助生起苦果。第三种习气，即苦的种子，对生死之苦能作因缘，直接生起苦果。颂中的三种习气，应随其所应了知。

惑和苦称为“取”，因为惑是能取，苦是所取。“取”是执着的意思，业不能称为取。“俱”等其余的文义，如前面所解释。

惑、业、苦，应知总摄十二有支，就是从无明乃至老死，如论中广释。

五、十二有支略摄为四：能引支

十二有支，大略可摄为四类。

第一是能引支，就是无明和行，因为能牵引识等五种果的种子。

能引支的无明，只取能发起真正感招后世善恶业的无明；无明所发起的业，才称为行。由此，一切顺现受业，以及另外帮助当来果报的业，都不是行支。

【译注】十二有支：无明、行、识、名色、六处、触、受、爱、取、有、生、老死。

六、所引支

第二是所引支，就是本识中直接生起当来异熟果的识、名色、六处、触、受五支的种子，因为由前面无明和行两支所引发。

其中，识的种子是指第八本识的因。除了后三种因，其余的因都属于名色的种子。后三种因，依名称次第，就是六处、触、受的种子。或者，名色的种子总摄五种因，在其中依殊胜立其余四种。六处与识的关系，总别也是如此。

《集论》说识也是能引支，因为识中的业种子称为识支，异熟识的种子属于名色。经中说识支通于能引和所引，因为业种子和识种子都称为识。识是名色的所依，不属于名色。

识等五支的种子由业熏发，实际上是同时的；诸圣教依主与伴、总与别、胜与劣、因与果的不同相状，假说为有前后。或者依当来现起的分位有次第，所以说有前后。由此，识等五支也说为现行，因为在因位时决定没有现行的意义。由此又说，能生支与能引支同时，因为润与未润的时候，必定不同时存在。

七、能生支

第三是能生支，就是爱、取、有，因为能就近生起当来的生和老死。

缘取迷于内在异熟果的愚痴，发起真正能招感后有的诸业，以诸业为缘，引发直接生起当来生和老死阶位的五种果种子之后；又依迷于外在增上果的愚痴，缘取境界之受，生起贪爱；以贪爱为缘，再生起欲取等四种取。爱与取共同滋润能引的业种子和所引的因，转称为“有”，因为都能就近成为后有的果。

【译注】两种愚痴：迷于异熟果的愚，是不懂善恶感苦乐果报的道理，所以造业；迷于增上果的愚，是对眼前境界的苦乐感受迷惑，所以生爱。前者发业，后者润生。四取是欲取、见取、戒禁取、我语取。

有的地方只说业种子称为“有”，因为业种子能真正感招异熟果。又有地方只说五支的种子称为“有”，因为五支种子直接生起当来的识等。

八、所生支

第四是所生支，就是生和老死，因为是爱、取、有就近所生。

从中有到本有之中，还没有衰变之前，都属于生支。一切衰变的阶位，总称为老。身坏命终，才称为死。老不是必定都有，所以附在死上立为一支。

外人质问：病为什么不立为一支？论主回答：因为病不普遍，也不决定。老不是决定的，是普遍的，所以立为一支，因为一切界、趣、生中的有情，除了中途夭亡的，将要命终时都有衰朽的现象。

外人质问：名色不普遍，为什么立为一支？论主回答：因为名色是决定的，所以立为一支。胎生、卵生、湿生的有情，六处还没有完备时，决定有名色。名色支也是普遍的：有色界的化生有情，初受生时具足五根，五根还没有作用，那时不称为六处支；初生在无色界时，决定有意根，意根不明了，不称为意处。由此论中说，十二有支一切都在，上二界只有一部分。

外人质问：爱不是普遍都有，为什么另立一支？论主回答：生在恶趣的有情，不爱恶趣。因为爱是决定的，所以另立一支：不求无有、生在善趣的有情，决定有爱。不还果润生时不起爱，如同取，决定有种子。爱也是普遍的，因为生在恶趣的有情，对现在的自我境界也有爱。依没有希求恶趣之身的爱，经中说生恶趣者无爱，并不是完全没有。

九、诸支立名的理由

外人质问：为什么所生支只立生和老死，所引支另立识等五支？

论主回答：因为在因位，差别的相状难以了知，所以依当来果位，另立五支：续生时，作为因的识相显著；其次，根还没有完备时，名色的相增上；其次，根完备时，六处明盛；依六处发起触；因触生起受；那时才称为受果究竟。依果位的五个阶段，把因立为五支。果位的差别相状容易了解，所以总立生和老死二支，显示苦苦、坏苦、行苦三苦。

所生的果，如果在未来，为了令人生厌，说生和老死；如果已到现在，为了令人了知分位相生，说识等五支。

外人质问：为什么在发业的阶位总立一个无明，在润业的阶位另立爱和取两支？

论主回答：一切烦恼都能发业、润生；在发业的阶位，无明的力量增盛，因为无明具足十一种殊胜之事，如所缘等，经中广说。在润业的阶位，爱的力量偏增，经中说爱如水，能浇灌滋润。要多次浇灌，才能生出“有”的芽，所以依初次和后来的浇灌，分为爱和取两支。发业没有重复发起的意义，所以只立一个无明。取支中包括一切烦恼，因为爱润的作用殊胜，所以说取是爱的增长。

一切缘起支都依于自地。有的所发之行依于他地的无明，如同下地的无明发起上地的行。不然的话，初次伏除下地染污的人所生起的上地之定，就不应是行支，因为上地的无明那时还没有生起。

外人质问：从上地生到下地、从下地生到上地的有情，缘取什么受而生起爱支？论主回答：爱也缘取将要投生之地的受，无论是现行或种子，在道理上都没有违背。

十、一重因果足以显示轮转

十二支中，十支是因，二支是果，因与果决定不同在一世。在因的十支中，前七支与爱、取、有，或者不同世，或者同世。能引的两支、能生的三支、所引与所生的七支，各自决定同在一世。

```
如是十二一重因果，足显轮转及离断常；
施设两重，实为无用。
```

大意：十二支作为一重因果，已足以显示生死轮转，以及远离断见和常见；施设两重因果，实在没有用处。

或者，如果超过一重，就会导致无穷。

【译注】说一切有部立“三世两重因果”：过去的无明、行为因，现在的识至受为果；现在的爱、取、有为因，未来的生、老死为果。唯识宗立“二世一重因果”：识等五支是种子，与爱取有同在因位，只有生和老死在果位。依唯识，十二支只需一重因果就能显示轮回。

十一、诸支的种种分别

十二支依意义分门，九支是实有，三支是假有：已被滋润的六支合称为“有”；识等五支的生、住、衰三相分位，称为生、老死。所以有、生、老死三支是假。

五支各是一事，即无明、识、触、受、爱；其余各支不是一事。

三支只是染污，因为是烦恼性，即无明、爱、取。七支只是不染污，因为是异熟果，即识、名色、六处、触、受、生、老死；七支的分位中可以生起染污，所以假说通于两种。其余的行与有，通于染与不染两种。

无明、爱、取称为独相，因为不与其余各支交杂；其余各支是杂相。

六支只是非色，即无明、识、触、受、爱、取；其余各支通于色与非色两种。

十二支都是有漏，只属于有为，因为无漏法和无为法不是有支。

无明、爱、取，只通于不善和有覆无记。行只是善或恶。有通于善、恶、无覆无记。其余七支只是无覆无记，在七支的分位中也可以生起善和染污。

十二支都通于三界，有部分与全部的区别。上地的行支能伏除下地的烦恼，就是修习粗、苦等六种行相，因为有人求生上地而生起。

【译注】六种行相：观下地为粗、苦、障，观上地为静、妙、离，称为六行观，是凡夫伏惑生上的方法。

十二支都只是非学非无学。圣者所起的有漏善业，以明为缘，违背有支，所以不属于有支。由此应知，圣者必定不造感招后有的业，因为对后来的苦果不再迷惑希求。圣者杂修禅定，资助下地原有的业，生到净居天等，在道理上没有违背。

关于十二支的所断，论中列出两家。

第一家认为：无明只属于见道所断，因为要迷于谛理才能发起行，圣者必定不造后有的业。爱和取两支只属于修道所断，因为贪求当来之有而润生，九种命终心都与俱生的爱俱起。其余九支都通于见道所断和修道所断。

第二家，即护法论师，认为：十二支都通于见道所断和修道所断。论中说，预流果已断一切有支的一部分，没有全断的。如果无明支只属于见道所断，怎能说预流果对无明支没有全断？如果爱和取两支只属于修道所断，怎能说预流果已断一切支的一部分？论中又说，全界的一切烦恼都能结生；往恶趣的行，只有分别起的烦恼能发起；没有说润生只属于修道所断，感招后有的一切行都由见道所断的烦恼发起。由此可知，无明、爱、取三支也通于见道所断和修道所断。真正发业的无明，只属于见道所断，帮助发业的无明不一定；真正润生的爱和取，只属于修道所断，帮助润生的爱取不一定。

另外，染污法本身应断，因为对治生起时，染污法永远断除。一切有漏的不染污法，不是本身应断，因为不违背道。有两种意义说为断：一是离缚，就是断除缘取、混杂于不染污法的烦恼；二是不生，就是断除不染污法的所依，令不染污法永远不再生起。依离缚而断，说有漏的善和无覆无记只属于修道所断。依不生而断，说一切恶趣、无想定等只属于见道所断。说十二支通于两种所断，对前面的种种断，应随其所应了知。

十二、诸支与诸受、四谛、四缘

十支与乐受、舍受俱起，除去受支和老死支：受支不与受相应，老死阶位多数没有乐受，又可以有舍受。十一支与苦受俱起，除去受支，因为受支不与受俱起。

十一支的一部分属于坏苦，除去老死支，因为老死阶位多数没有乐受，坏苦是依乐受而立，所以不说老死。十二支的一部分属于苦苦，因为一切支中都有苦受。十二支全部属于行苦，因为一切有漏法都是行苦。依舍受而说，十一支的一部分属于行苦，除去老死支，如同坏苦所说。以上是实义。诸圣教中随着各支相状的增盛，所说不一定。

十二支都属于苦谛，因为都是取蕴的性质。其中五支也属于集谛，因为是业和烦恼的性质，即无明、行、爱、取、有。

诸支之间，增上缘决定都有，其余三缘有无不定。契经依决定而说，只说有增上缘一种。

爱对取、有对生，有因缘的意义。如果说识支是业种子，行对识也作因缘。其余各支之间，没有因缘的意义。《集论》说无明对行有因缘，是依无明时的业习气而说，因为与无明同时，所以假说为无明，实际上是行的种子。

《瑜伽师地论》说诸支之间没有因缘，是依现行的爱、取，以及只是业的有而说。

无明对行、爱对取、生对老死，有其余两缘，即等无间缘和所缘缘。有对生、受对爱，没有等无间缘，有所缘缘。其余各支之间，两缘都没有。以上只是依邻近、顺次、不相杂乱的实际缘起而说；不是如此相对的，为缘的情形不一定。聪慧的人应依道理思考。

十三、惑业苦摄十二支

惑、业、苦三者摄十二支：无明、爱、取属于惑；行和有的一部分属于业；识等七支和有的一部分属于苦。

有的地方说业全摄有，应知是依业有而说。有的地方说识属于业，是说业种子是识支。惑和业所感招的，唯独称为苦，因为只属于苦谛，为了令人生厌。

由于惑、业、苦就是十二支，所以惑业苦能令生死相续。

以上卷第八之中译毕。
