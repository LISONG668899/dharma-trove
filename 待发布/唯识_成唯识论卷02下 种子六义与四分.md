一、种子的六种条件

种子的含义，大略有六种条件。

第一，刹那灭。种子的体刚一生起，紧接着必定灭去，有殊胜的功能力量，才成为种子。刹那灭一条，遮除常住之法：常住之法恒常没有转变，不能说有生果的作用。

第二，果俱有。种子与所生的现行果法同时显现、和合在一起，才成为种子。果俱有一条，遮除因果前后相隔，以及因果决定相离。种子与现行性类不同，互不相违，在同一身中同时有生果的作用。种子生起自类的后念种子，前后相续，前念与后念互相违背，必定不同时存在，所以种子生种子不属于果俱有。因与果有同时的，也有不同时的，只有现在时可以有因的作用；未生的还没有体，已灭的已经没有体。依生起现行果法，立“种子”之名；不依引生自类后念，立“种子”之名。所以只说种子与果同时俱有。

【译注】种子生种子，是前念生后念，前后相续；种子生现行，是同一刹那中种子与现行同时存在。“种子”的正名，只依后一种关系而立。

第三，恒随转。种子要长时间同一类别地相续不断，直到究竟位，才成为种子。恒随转一条，遮除前七转识：前七转识时有转变、时有间断，与种子的含义不相应。恒随转显示种子是自类相生的。

第四，性决定。种子随着能熏之因的力量，生善、生恶等功能决定不变，才成为种子。性决定一条，遮除其余部派所执“异性之因生异性之果”有因缘关系的主张。

第五，待众缘。种子要等待自己所需的众缘和合，功能殊胜，才成为种子。待众缘一条，遮除外道所执的自然因不待众缘、恒常一下子生起一切果；或遮除其余部派所执的“缘恒常存在”，显示所等待的缘不是恒常存在的。所以种子对于果，不是恒常一下子生起。

第六，引自果。种子对于各自不同的色法、心法等果，各自引生，才成为种子。引自果一条，遮除外道所执的“唯一之因生一切果”；或遮除其余部派所执的“色法与心法互为因缘”。

只有阿赖耶识中的功能差别，具足以上六种条件，才是种子，其余的都不是。

二、内种与外种

外在的谷、麦等，是识所变现的，所以只是假立“种子”之名，不是真实的种子。

种子的势力生起近处的正果，称为生因；引生远处的残余之果，使果不立刻断绝，称为引因。

【译注】依《述记》的大意：生因之果，如种子生芽、业种生起一期身心；引因之果，如人死后尸骸仍存留一段时间，草木枯后不立即消散。

内种必定由熏习而生长，能直接生果，是因缘性质。外种的熏习，或有或无，作为增上缘成就所生的果。外种的果，必定以内种为因缘，因为外种的果是共相种子所生的果。

三、所熏的四种条件

外人质问：依什么意义而立“熏习”之名？论主回答：所熏与能熏各自具足四种条件，令种子生长，所以称为熏习。

外人质问：什么叫所熏的四种条件？论主回答：

第一，坚住性。如果一种法始终同一类别相续不断，能保持习气，才是所熏。坚住性一条，遮除前七转识以及声音、风等，因为前七转识与声、风等性质不坚住，所以不是所熏。

第二，无记性。如果一种法平等，没有违逆，能容纳习气，才是所熏。无记性一条，遮除善性与染性，因为善性与染性势力强盛，不能容纳习气，所以不是所熏。由此，如来的第八净识，只带着原有的种子，不再接受新的熏习。

第三，可熏性。如果一种法自在，体性不坚密，能接受习气，才是所熏。可熏性一条，遮除心所和无为法：心所依于心王，不自在；无为法体性坚密，不能接受熏习。所以心所和无为法不是所熏。

第四，与能熏共和合性。如果一种法与能熏同时、同处，不即不离，才是所熏。共和合性一条，遮除他人之身，以及前后刹那，因为他人之身和前后刹那没有和合的意义，所以不是所熏。

只有异熟识具足以上四种条件，可以作为所熏，心所等都不是。

四、能熏的四种条件

外人质问：什么叫能熏的四种条件？论主回答：

第一，有生灭。如果一种法不是常住，能有作用，生长习气，才是能熏。有生灭一条，遮除无为法，因为无为法前后不变，没有生长习气的作用，所以不是能熏。

第二，有胜用。如果一种法有生灭，势力增盛，能引生习气，才是能熏。有胜用一条，遮除异熟识的心王与心所等，因为异熟识的心王与心所势力微弱，所以不是能熏。

第三，有增减。如果一种法有殊胜的作用，可增可减，能摄持、培植习气，才是能熏。有增减一条，遮除佛果圆满的善法，因为佛果的善法无增无减，所以不是能熏。佛果的善法如果能熏，就不是圆满，前佛与后佛的佛果就应有胜有劣。

第四，与所熏和合而转。如果一种法与所熏同时、同处，不即不离，才是能熏。和合而转一条，遮除他人之身，以及前后刹那，因为他人之身和前后刹那没有和合的意义，所以不是能熏。

只有前七转识及前七转识的心所，有殊胜势用而有增有减，具足以上四种条件，可以作为能熏。

【译注】八条合起来看，熏习是一种严格的配对：所熏必须是持久、中性、开放、同处的阿赖耶识，能熏必须是生灭、有力、有增减、同处的前七识。少一条，熏习就不能成立。

五、熏习与三法同时

能熏的识等与所熏的识，同时生起，同时灭去，熏习的意义就成立了。能熏使所熏的识中种子生长，如同用花熏胡麻，胡麻带上花香，所以称为熏习。

能熏的识等从种子生起时，就能作为因，再熏成新的种子。三种法展转相生，因果同时：本有的种子生起现行，现行同时熏成新的种子。如同灯炷生起火焰，火焰同时烧焦灯炷；又如同两束芦苇，互相依靠。因果同时，道理稳固不动。

能熏的现行生起新种子，种子生起现行，如同俱有因得到士用果。种子前后自类相生，如同同类因引生等流果。种子生现行、现行熏种子、种子生种子，三种关系对于果都是因缘性质。除此以外的其余法，都不是因缘。即使称为因缘，应知也是假说。

以上是略说一切种子的相状。

六、阿赖耶识的行相与所缘

外人质问：阿赖耶识的行相与所缘是什么？论主回答：就是颂中所说“不可知执受、处、了”。

“了”是了别，就是阿赖耶识的行相，因为识以了别为行相。

“处”是处所，就是器世间，因为器世间是一切有情所依的处所。

“执受”有两种，就是一切种子和有根身。一切种子，是指诸相、名、分别的习气。有根身，是指眼等诸色根，以及诸根所依的身体。一切种子和有根身，都被阿赖耶识所执受，摄为阿赖耶识的自体，与阿赖耶识同安危。

执受和处，都是阿赖耶识的所缘。阿赖耶识由因缘的力量，自体生起时，向内变现为种子和有根身，向外变现为器世间，就以所变现的为自己的所缘，阿赖耶识的行相依托所缘而生起。

颂中的“了”，是说异熟识对自己的所缘有了别的作用，了别的作用属于见分。

七、相分与见分

一切有漏识自体生起时，都显现出似所缘和似能缘两种相。与有漏识相应的心所，也是如此。似所缘的相，称为相分；似能缘的相，称为见分。

心王与心所如果没有所缘的相，就不能缘取自己的所缘境；或者每一个心王与心所，都能缘取一切境，因为自己的境如同其余的境，其余的境也如同自己的境。心王与心所如果没有能缘的相，就不能缘取，如同虚空等；或者虚空等也应是能缘。所以心王与心所必定有两种相。如契经的偈颂说：

```
一切唯有觉　所觉义皆无
能觉所觉分　各自然而转
```

大意：一切都只是觉知，被觉知的外在对象都不存在。能觉知的部分和被觉知的部分，各自依因缘自然运转。

执着有离识的所缘境的人，认为：外境是所缘，相分称为行相，见分称为事，因为见分是心王与心所的自体相。小乘认为，心王与心所所依的根相同，所缘的外境相同，行相相似；体数相等，相各不同，因为识、受、想等的行相各别。

【译注】“执着有离识的所缘境的人”，指小乘部派。小乘认为外境是所缘，心上所现的外境影像是行相。

通达没有离识的所缘境的人，认为：相分是所缘，见分称为行相，相分与见分所依的自体称为事，就是自证分。

如果没有自证分，就应不能忆起自己过去的心王与心所，如同从未经历过的境，必定不能忆起。心王与心所所依的根相同，所缘的相分相似，行相各别，因为了别、领纳等作用各不相同。体数相等，相各不同，因为识、受等的体各有差别。

【译注】“自证分”的论证，关键在于“能忆”：我们能记起“刚才我在看”，说明当时“看”的动作本身已被证知；如果当时没有任何作用证知见分，后来就无从忆起。

八、三分与四分

每一个心王与心所生起时，依道理推究，各有三分，因为有所量、能量、量果的区别，相分和见分必定有所依的体。如《集量论》的偈颂说：

```
似境相所量　能取相自证
即能量及果　此三体无别
```

大意：似境的相分是所量，能取的见分是能量，自证分是量果。三分的体没有区别。

【译注】《集量论》是陈那论师的著作。窥基大师在《述记》中以尺量绢为喻：绢是所量，尺是能量，知道量出几尺几寸的智，是量果。

心王与心所如果细加分别，应有四分。前三分如前所说，还有第四分，称为证自证分。

如果没有证自证分，谁来证知第三分？心的各分既然相同，都应有证知者。自证分也应没有量果，而一切能量都必定有量果。不应说见分是第三分的量果，因为见分有时不属于正确的量，有时是非量。所以见分不能证知第三分，因为证知自体的，必定是现量。

四分之中，前二分是外，后二分是内。第一分只是所缘，后三分通于所缘和能缘：第二分只缘第一分，或是量，或是非量，或是现量，或是比量；第三分能缘第二分和第四分；证自证分只缘第三分，不缘第二分，因为缘第二分没有用处。第三分和第四分都属于现量。

所以心王与心所由四分合成，具备所缘与能缘，没有无穷追溯的过失。四分不即不离，唯识的道理就成立了。

【译注】第三分与第四分互相证知，所以不需要第五分来证知第四分，也就没有“证知者还需要证知者”的无穷后退。依《述记》，一分说属安慧论师，二分说属难陀论师，三分说属陈那论师，四分说属护法论师。

所以契经的偈颂说：

```
众生心二性　内外一切分
所取能取缠　见种种差别
```

大意：众生的心由二分合成，无论内分还是外分，都被所取和能取所缠缚。见分有种种差别：或是量，或是非量，或是现量，或是比量。

偈颂中的“见”，是见分。四分也可以合为三分，因为第四分可以并入自证分。四分也可以合为二分，因为后三分都是能缘，都属于见分，偈中所说的“见”是能缘的意思。四分也可以合为一分，因为四分的体没有区别。如《入楞伽经》的偈颂说：

```
由自心执著　心似外境转
彼所见非有　是故说唯心
```

大意：由于自心的执着，心显现得好像外境。所见的外境并不存在，所以说唯有心。

诸经中处处所说的“唯一心”，“一心”也包括心所。所以识的行相就是了别，了别就是识的见分。

九、器世间：共同变现

颂中所说的“处”，是指异熟识由共相种子成熟的力量，变现出似色等的器世间之相，就是外在的四大种和四大所造的色法。一切有情所变现的器世间，各自不同，相状相似，处所没有分别，如同众多的灯光，各自遍满一室，看起来像是一个光。

外人质问：谁的异熟识变现器世间？论中列出三家。

第一家认为：一切有情的异熟识都变现。原因是：契经说，器世间由一切有情的业力共同生起。

第二家破斥：照此道理，诸佛菩萨就应真的变现此界杂秽的国土，凡夫等就应真的变现他方世界和此界中的清净妙土。诸圣者厌离色法，生到无色界，决定不再往下界投生，变现此土又有什么用？所以，现在居住此界和将来生到此界的有情，异熟识才变现此界。契经是依一部分有情而说“一切”，凡是业相同的有情，都共同变现。

第三家破斥：照此道理，器世间将要坏灭时，既没有现在居住的，也没有将来生到此界的有情，谁的异熟识变现此界？凡夫厌离色法，生到无色界，现在没有色身，预先变现国土又有什么用？即使有色身，与其他地的器世间粗细悬殊，不能互相依持，变现其他地的器世间又有什么益处？

第三家正面说明：变现的国土，本来是为了让色身依持、受用。如果国土对某一有情的身体可以有依持、受用的作用，该有情的识就变现该国土。所以，即使生在他方世界或自己所在的地，该有情的识也可以变现此界的国土。所以器世界将坏和初成时，即使没有有情，器世界也照样显现。

以上所说，是一切有情共同受用的器世间。各别受用的部分，可以照此类推。鬼、人、天等所见各不相同。

【译注】第三家以“受用”为准，立为正义。“鬼、人、天所见各异”，即《摄大乘论》诸释常说的一水四见：同一条河，人见为水，鬼见为脓血，天见为琉璃，鱼见为宅舍，因为各类有情的业力所变不同。

十、种子与根身

颂中所说的“种子”，是指异熟识所执持的一切有漏法种子。有漏法种子属于异熟识的体性，所以是阿赖耶识的所缘。

无漏法种子依附于异熟识，并不属于异熟识的体性，所以不是阿赖耶识的所缘。无漏种子不是所缘，与异熟识不相离，如同真如的体性不违背唯识。

颂中所说的“有根身”，是指异熟识由不共相种子成熟的力量，变现出似色根和根所依处的身体，就是身内的四大种和四大所造的色法。异熟识又由共相种子成熟的力量，在他人身体所在之处，也变现出似他人身体的相。不然的话，就应没有受用他人身体的意义。

关于变现他人身体，有两家主张。第一家认为：异熟识也变现似他人的根。原因是：《辩中边论》说，显现似自身和他身的五根。第二家认为：异熟识只能变现似他人根所依处的身体，因为他人的根对自己没有用处。《辩中边论》说“似自身他身的五根显现”，是说自己的识和他人的识各自变现自己的根。所以，有情生到他地或入般涅槃后，留下的尸骸仍然被看见相续存在。

【译注】尸骸仍被看见，正是第二家的证据：他人死后，根已不存在，他人根所依的身体由旁人的识共同变现，所以旁人仍能看见。

以上是说业力所变现的外在器世间与内在根身，界与地各有差别。如果是禅定等力量所变现的器世间与身体，界与地、自与他，就不一定。

所变现的身体与器世间，大多恒常相续；变现的声音、光明等，大多是暂时的，因为声音、光明等随着现前因缘的力量激发而起。

略说阿赖耶识所变现的境，就是有漏种子、十种有色处，以及法处所摄的实色。

【译注】十种有色处指眼、耳、鼻、舌、身五根和色、声、香、味、触五境。法处所摄的实色指禅定所变现的色。

十一、第八识为何不变现心法

外人质问：阿赖耶识为什么不能变现似心王、心所等作为所缘？

论主回答：有漏识的变现，大略有两种。第一种随着因缘的势力而变现，第二种随着分别的势力而变现。第一种所变现的必定有实在的作用，第二种所变现的只是认识的对象。

异熟识的变现，只随着因缘的势力。异熟识所变现的色等，必定有实在的作用。异熟识如果变现心等，就没有实在的作用，因为相分中的心等不能缘取境。心的实在作用，要另外从心自己的种子生起。异熟识变现无为法等，也没有实在的作用。所以异熟识不缘取心等。

到无漏位时，第八识与殊胜的智慧相应，没有分别，澄明清净，所以即使没有实在的作用，也能显现心等的影像。不然的话，诸佛就应不是遍知。

所以在有漏位，异熟识只缘取器世间、根身和有漏种子。在欲界和色界，异熟识具有三种所缘。在无色界，异熟识只缘取有漏种子，因为无色界的有情厌离色法，没有业果所生的色。无色界有禅定所生的色，在道理上没有违背，异熟识也缘取禅定所生的色为境。

十二、为何称为“不可知”

颂中的“不可知”，是说阿赖耶识的行相极其微细，难以了知。或者，阿赖耶识所缘的内在执受之境也极其微细，外在器世间的量难以测知，所以称为不可知。

外人质问：阿赖耶识怎能取所缘境，行相又难以了知？论主回答：如同灭尽定中，不离身的识，应当相信是存在的。必定应当承认灭尽定中有识，因为灭尽定中的人属于有情，如同有心的时候。无想定等阶位，也应当知道同样如此。

以上卷第二之下译毕，成唯识论卷第二终。

下一篇：卷03上　第八识相应与恒转如流。论主解释第三、第四颂：阿赖耶识与触、作意、受、想、思五遍行心所相应；阿赖耶识只与舍受相应，性质是无覆无记；再解释“恒转如瀑流”，阐明非断非常的缘起正理，并破斥小乘的因果相续说。
