# 真如十颂

梅纪巴（阿阇黎无二金刚）造　据藏文译出

## 题解

《真如十颂》（梵 Tattvadaśaka，藏 de kho na nyid bcu pa，直译"真性十［颂］"）收于德格版丹珠尔续部释 ཝི 函第 112b 至 113a 页（东北目录 D2236），紧接在《无住义明示》（D2235）之后，同属梅纪巴的"无念法类"。据跋语，此论先由上师金刚手与粗敦译出，后来又由译师戒胜（那措译师）重译。

这是梅纪巴最有影响的短论之一。全篇十颂：第一颂礼敬真如；第二颂是全篇最著名的一颂，说真如既非有相、亦非无相，而没有上师口诀庄严的中观也只是中等而已——后世噶举派讨论大手印与中观、显教与密乘的关系时，常常引用这一颂；第三、四颂说事物本身即是菩提，迷乱本身也无所住，真如就是事物的无自性，却又依因果而显现；第五至七颂说诸法一味，以"如实三摩地"见一切为光明，连"离二"的念头也同样是光明；第八、九颂描述证悟者如狮子般无畏，以及转离世法、依疯行、以自加持庄严、无所缘而行一切的行持；第十颂结示，劝大智者通达。

此论在同一函中另有一部《真如十颂广释》（Tattvadaśakaṭīkā，东北目录 D2254），是印度大德俱生金刚（Sahajavajra）所造的详细注释，篇幅很长。本译只依根本颂译出，按语中的理解属于译者依上下文所作，若日后译出《广释》，应以《广释》的解释为准，再作订正。

体例：每颂先列藏文原颂于代码块中，再按完整的意义单元译出；为了便于理解而补的字，都放在方括号中。原文含混或可有两解之处，以"【按】"说明，不妄补内容。文末附通篇连读。

## 题名与礼敬

梵语题名：Tattvadaśaka-nāma。藏语题名：名为《真如十颂》。

敬礼文殊童子！

## 第一颂　礼敬真如

```
ཡོད་དང་མེད་པའི་སྦྱོར་བས་ཀྱང་། །
སྤངས་པ་གང་ཞིག་དྲི་མེད་པ། །
བྱང་ཆུབ་རང་བཞིན་རྟོགས་པ་གང་། །
དེ་བཞིན་ཉིད་དེ་ཕྱག་འཚལ་འདུད། །
```

那远离"有"与"无"的配合［，也就是不能以有、无来安立］、无垢的，那证悟菩提自性的——［就是］真如，我对它恭敬顶礼。

【按】"远离有与无的配合"（yod dang med pa'i sbyor bas kyang spangs pa），意思是真如不能用"有""无"这样的概念组合来安立，有、无、亦有亦无、非有非无都不能触及它。第三句"证悟菩提自性的"，可以理解为真如本身即是对菩提自性的证悟，也可以理解为真如是那被证悟的菩提自性，两种读法都显示真如与菩提不二，存疑。

## 第二颂　非有相非无相

```
དེ་བཞིན་ཉིད་ནི་ཤེས་འདོད་པས། །
རྣམ་བཅས་མ་ཡིན་རྣམ་མེད་མིན། །
བླ་མའི་ངག་གིས་མ་བརྒྱན་པའི། །
དབུ་མའང་འབྲིང་པོ་ཙམ་ཉིད་དོ། །
```

想要了知真如的人［应当明白］：［真如］既不是有相［唯识所说的那样］，也不是无相［唯识所说的那样］；而没有以上师口诀来庄严的中观，也只不过是中等而已。

【按】"有相""无相"，即唯识宗中有相论（rnam bcas）与无相论（rnam med）两派，在《中观六颂》《梦教示》中已经出现。这一颂先遮遣两种唯识，再说即使是中观，若没有上师的口诀来庄严，也只是"中等"（'bring po）。

"中等"一词的意思值得细辨：一种理解是，中观见本身虽然正确，但若只停留在理论抉择、没有上师口诀指示的直接证悟，就只是中等的；另一种理解是，没有口诀庄严的中观，在诸见之中只算中品，不是最上。梅纪巴在别处以无住论为中观的究竟，又以上师口诀的证悟为大手印的要点，两种理解都与此相合。这里所说的"上师口诀"，在梅纪巴的传统中，通常就是指大手印的直指教授。

这一颂后来成为藏传佛教中讨论"大手印是否超出中观""不依密乘灌顶能否证悟大手印"的重要依据，各家对此有不同的解释，这里只照原文译出，不涉及后世的争论。

## 第三颂　事物即菩提

```
དངོས་པོ་འདི་ནི་བྱང་ཆུབ་འགྱུར། །
ཆགས་པ་སྤངས་པའི་རང་བཞིན་ཉིད། །
འཁྲུལ་པ་ལས་ནི་ཆགས་མེད་འགྱུར། །
འཁྲུལ་པའང་གནས་པ་མེད་པར་འདོད། །
```

这事物本身就成为菩提，因为它的自性就是远离贪著的；［事物］是从迷乱中成为无贪著的，而迷乱本身，也被承许为无所住的。

【按】这一颂很浓缩。意思大概是：种种事物（dngos po）并不需要被舍弃才能成就菩提，因为它们的自性本来就远离贪著；所谓"无贪著"，不是离开迷乱另外得到的，而是就在迷乱之中实现的，因为迷乱本身也是无所住、无自性的。第三句"从迷乱中成为无贪著"，也可以理解为"由于［了知它是］迷乱，所以成为无贪著"，即认出迷乱本身就是解脱的契机。两种读法要点一致：不舍迷乱而得菩提，存疑。

## 第四颂　真如即事物的无自性

```
དེ་ཉིད་ཅི་ན་དངོས་རང་བཞིན། །
དངོས་པོ་དངོས་མེད་གང་ཡིན་པའོ། །
དངོས་པོ་མེད་པའང་དངོས་པོར་འགྱུར། །
རྒྱུ་དང་འབྲས་བུའི་རང་བཞིན་གྱིས། །
```

真如是什么呢？［就是］事物的自性——也就是事物的无实体性。而这"无实体性"，又依于因与果的本性，而成为［显现的］事物。

【按】"事物的无实体性"（dngos po dngos med），意思是事物的自性正是没有自性。后两句是说：这无实体性并不是一无所有的断灭，它依于因果、缘起，而显现为种种事物。所以空性与缘起不二：真如是事物的空性，空性又显现为缘起的事物。这与《无住义明示》第七颂"诸法之生本身就是空性"的意思相通。

## 第五颂　诸法一味，皆是光明

```
དེ་ལྟར་ཆོས་རྣམས་རོ་གཅིག་སྟེ། །
ཐོག་མ་མེད་ཅིང་གནས་མེད་པར། །
ཇི་ལྟ་བ་ཡི་ཏིང་འཛིན་གྱིས། །
འདི་དག་ཐམས་ཅད་འོད་གསལ་ཏེ། །
```

如此，诸法都是一味的，无始，也无所住；以"如实三摩地"［来照见］，这一切都是光明。

【按】"一味"（ro gcig），是大手印四瑜伽中的第三个次第之名，这里指一切法同为真如、没有差别。"如实三摩地"（ji lta ba'i ting 'dzin），ji lta ba 一般对应梵文 yathābhūta 或 yathāvat，意思是"如其本然""如实"；这里指如其本然地照见诸法的三摩地，而不是另外造作出一种观想。"光明"（'od gsal），即心性的明净本性。

## 第六颂　如实三摩地的来源

```
ཇི་ལྟ་བ་ཡི་ཏིང་འཛིན་ཡང་། །
རབ་ཏུ་འཇུག་པའི་སེམས་ཉིད་ཀྱིས། །
གང་ཕྱིར་དེ་ཡང་གནས་རིག་པས། །
དེ་ཉིད་རྒྱུན་མི་འཆད་ལས་སྐྱེས། །
```

那如实三摩地，也是由趣入［真如］的心本身［而有］；因为它了知［诸法的］住相，所以它是从那不间断的真如中生起的。

【按】这一颂的藏文很难确定，以下是依上下文的推测。"趣入的心本身"（rab tu 'jug pa'i sems nyid），可以理解为趣入真如的心，也可以理解为种种转起之心本身，即如实三摩地不离日常转起的心。"了知住相"（gnas rig pa），gnas 可以是"住、安住"，也可以是"真实的状态、实相"；这里依后者。第四句"从那不间断的真如中生起"，de nyid 可以是"真如"，也可以是"那［三摩地］本身"，若依后者，意思就是"它本身是从不间断［的修习］中生起的"。由于几处都可两解，这一颂整体存疑，宜待《广释》订正。

## 第七颂　离二之念亦是光明

```
ཤེས་དང་ཤེས་བྱ་རྣམ་བྲལ་བའི། །
འགྲོ་བ་ཉིད་ནི་གཉིས་མེད་འདོད། །
གཉིས་དང་བྲལ་བར་རློམ་པ་ཡང་། །
དེ་ལྟར་འོད་གསལ་བ་ཉིད་དོ། །
```

众生本身，远离能知与所知，被承许为无二的；而那以为"［我］已离开二取"的念头，也同样就是光明。

【按】"以为已离开二取的念头"（gnyis dang bral bar rlom pa），rlom pa 是"自认为、自负、执以为"，带有"未必真实"的意味。这一颂的要点在后两句：修行人常会生起"我已证得无二"的念头，这本身又是一种执著；作者并不要求另外再去遣除它，而是说这个念头本身也同样是光明。这正是大手印"念头即法身""不舍分别而认出其本性"的要点。

## 第八颂　如狮子般无畏

```
དེ་ལྟའི་དེ་ཉིད་ངེས་རྟོགས་ན། །
ཇི་ལྟ་དེ་ལྟར་གང་དེ་ན། །
རྣལ་འབྱོར་མིག་ནི་རྒྱས་འགྱུར་བས། །
ཀུན་དུ་སེང་གེ་ཇི་བཞིན་ནོ། །
```

如果决定地证悟了这样的真如，那么，无论［身在］何处、［所行］如何，由于瑜伽之眼已经广大开展，［行者］处处都像狮子一样［无所畏惧］。

【按】"瑜伽之眼广大开展"（rnal 'byor mig ni rgyas 'gyur），意思是证悟的智慧之眼完全开显。"像狮子一样"，是说如同狮子在山野中行走无所畏惧，证悟者在一切境界中都不再被迷惑、恐惧所动。第二句"ji lta de ltar gang de na"语法较松散，这里理解为"无论何处、无论如何"。

## 第九颂　疯行与无所缘之行

```
འཇིག་རྟེན་ཆོས་ལ་རྣམ་ལོག་འདིས། །
སྨྱོན་པའི་སྤྱོད་པ་ལ་བརྟེན་ནས། །
བདག་བྱིན་བརླབ་པས་རྣམ་བརྒྱན་ནས། །
དམིགས་པ་མེད་པར་ཐམས་ཅད་བྱེད། །
```

这样的［瑜伽士］，转离世间法，依止疯行，以自加持来庄严［自身］，无所缘地行一切［事业］。

【按】"转离世间法"，指不再随顺世间八法（利、衰、毁、誉、称、讥、苦、乐）。"疯行"（smyon pa'i spyod pa），是印度大成就者的一种特殊禁行，外表看起来像疯人，不依世俗的规矩，内里则是安住于证悟而对一切境界不取不舍。"自加持"（bdag byin brlabs，梵 svādhiṣṭhāna），在密续中是指以自身安住于本尊、光明的证悟来加持自己，属于密法的修持内涵。

这一颂所说的，是已经"决定证悟真如"（上一颂）的瑜伽士的行持，以证悟为前提。疯行、自加持都须依具德上师的灌顶与口授来理解，修行人不可在没有证悟之时照字面模仿，以疯行为放逸的借口；梅纪巴在《除恶见》《幻教示》中对此已有明确的告诫。

## 第十颂　结示

```
དྲི་མེད་དེ་ཉིད་གང་བསྟན་ཅིང་། །
གཉིས་སུ་མེད་པ་གང་སྨྲས་པ། །
མཉམ་དང་མི་མཉམ་འདི་སྤངས་ནས། །
བློ་ཆེན་རྣམས་ཀྱིས་རྟོགས་བྱའི་རིགས། །
```

这里所开示的无垢真如，这里所宣说的无二［之理］，诸大智者应当舍弃"平等"与"不平等"［的分别］，来证悟它。

【按】第三句"mnyam dang mi mnyam 'di spangs nas"有两种读法：一是"舍弃'平等'与'不平等'［这两种分别］"，即对真如不作平等或不平等的分别；二是"舍弃这［一切］平等与不平等之见"，意思相同。也有可能这里的 mi mnyam 是"无等、无比"（asama）之义，即与佛的称号"无等等"有关，那么意思就会完全不同，但从上下文看可能性较小，存疑。"应当证悟"（rtogs bya'i rigs），rigs 是"应当、适合"，也有"［大智者］这一类人"的意思。

## 跋

《真如十颂》，阿阇黎无二金刚所造，圆满。

上师金刚手与粗敦译出。后来又由译师戒胜重译。

【按】"金刚手"，原文作 phyag na（"手持"），是金刚手（phyag na rdo rje，Vajrapāṇi）的略称。"重译"，原文作 bsgyur，可能是修订旧译，也可能是另行翻译；现存的德格本究竟是哪一次的译本，跋语没有说明。

## 通篇连读

敬礼文殊童子！

那不能以有、无来安立、无垢的，那证悟菩提自性的，就是真如，我对它恭敬顶礼。

想要了知真如的人应当明白：真如既不是有相唯识所说的那样，也不是无相唯识所说的那样；而没有以上师口诀庄严的中观，也只不过是中等而已。

这事物本身就成为菩提，因为它的自性本来就远离贪著；事物是从迷乱中成为无贪著的，而迷乱本身也是无所住的。

真如是什么呢？就是事物的自性，也就是事物的无实体性；而这无实体性，又依于因与果的本性，显现为种种事物。

如此，诸法都是一味的，无始，也无所住；以如实三摩地来照见，这一切都是光明。

那如实三摩地，也是由趣入真如的心本身而有；因为它了知诸法的实相，所以它是从那不间断的真如中生起的。

众生本身远离能知与所知，是无二的；而那以为"我已离开二取"的念头，也同样就是光明。

如果决定地证悟了这样的真如，那么无论身在何处、所行如何，由于瑜伽之眼已经广大开展，处处都像狮子一样无所畏惧。

这样的瑜伽士，转离世间法，依止疯行，以自加持庄严自身，无所缘地行一切事业。

这里所开示的无垢真如，这里所宣说的无二之理，诸大智者应当舍弃平等与不平等的分别，来证悟它。

《真如十颂》，阿阇黎无二金刚造，圆满。上师金刚手与粗敦译出，后来又由译师戒胜重译。
