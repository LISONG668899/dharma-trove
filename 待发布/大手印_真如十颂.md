# 真如十颂

梅纪巴（阿阇黎无二金刚）造　据藏文译出

## 题解

《真如十颂》（梵 Tattvadaśaka，藏 de kho na nyid bcu pa，直译"真性十［颂］"）收于德格版丹珠尔续部释 ཝི 函第 112b 至 113a 页（东北目录 D2236），紧接在《无住义明示》（D2235）之后，同属梅纪巴的"无念法类"。据跋语，此论先由上师金刚手与粗敦译出，后来又由译师戒胜（那措译师）重译。

这是梅纪巴最有影响的短论之一。全篇十颂：第一颂礼敬真如；第二颂是全篇最著名的一颂，说真如既非有相、亦非无相，而没有上师口诀庄严的中观也只是中等而已——后世噶举派讨论大手印与中观、显教与密乘的关系时，常常引用这一颂；第三、四颂说事物本身即是菩提，迷乱本身也无所住，真性就是事物的自性，即事物与空性无二，空性又依因果而显现为事物；第五至七颂说诸法一味，以"如实三摩地"见一切为光明，连"离二"的念头也同样是光明；第八、九颂描述证悟者如狮子般无畏，以及转离世法、依疯行、以自加持庄严、无所缘而行一切的行持；第十颂结示，劝大智者通达。

此论在同一函中另有一部《真如十颂广释》（Tattvadaśakaṭīkā，东北目录 D2254），是印度大德俱生金刚（Sahajavajra）所造的详细注释，篇幅很长。本译初稿只依根本颂译出；后来译出《广释》（见《大手印_真如十颂广释.md》），已依《广释》的解释订正了第一、二、四、五、六、八、九、十颂的译文或按语，凡依《广释》所改之处，按语中都注明"依《广释》"。《广释》所引的根本颂是另一个译本，与本单行本文字有多处不同，也在相关各颂按语中列出。

体例：每颂先列藏文原颂于代码块中，再按完整的意义单元译出；为了便于理解而补的字，都放在方括号中。原文含混或可有两解之处，以"【按】"说明，不妄补内容。文末附通篇连读。

## 第一颂　礼敬真如

```
ཡོད་དང་མེད་པའི་སྦྱོར་བས་ཀྱང་། །
སྤངས་པ་གང་ཞིག་དྲི་མེད་པ། །
བྱང་ཆུབ་རང་བཞིན་རྟོགས་པ་གང་། །
དེ་བཞིན་ཉིད་དེ་ཕྱག་འཚལ་འདུད། །
```

那远离"有"与"无"的配合［，也就是不能以有、无来安立］、无垢的，那证悟菩提自性的——［就是］真如，我对它恭敬顶礼。

【按】"远离有与无的配合"（yod dang med pa'i sbyor bas kyang spangs pa），意思是真如不能用"有""无"这样的概念组合来安立，有、无、亦有亦无、非有非无都不能触及它。第三句"证悟菩提自性的"，初稿曾说可以有两种读法。依《广释》第六节，真如之所以值得礼敬，是因为它"就是真正圆满的佛陀本身的本体"，与佛没有差别，所以礼敬真如就是礼敬佛；"无垢"即客尘烦恼完全舍弃的清净。《广释》所引此颂第二、三句作"于它无浊，具有证悟菩提的自性"（གང་ལ་རྙོག་པ་མེད་པ་ཉིད། བྱང་ཆུབ་རྟོགས་པའི་རང་བཞིན་ཅན།），与本单行本文字不同，意思相同。

依《广释》第七节，这一颂同时开示了本论的三事："远离有无之结合"是所诠的法性；"无垢"与"证悟"是能成的道；"菩提自性"是所成的果。

## 第二颂　非有相非无相

```
དེ་བཞིན་ཉིད་ནི་ཤེས་འདོད་པས། །
རྣམ་བཅས་མ་ཡིན་རྣམ་མེད་མིན། །
བླ་མའི་ངག་གིས་མ་བརྒྱན་པའི། །
དབུ་མའང་འབྲིང་པོ་ཙམ་ཉིད་དོ། །
```

想要了知真如的人［应当明白］：［真如］既不是有相［派所说的那样］，也不是无相［派所说的那样］；而没有以上师口诀来庄严的中观，也只不过是中等而已。

【按】"有相""无相"（rnam bcas、rnam med），初稿只解释为唯识宗中有相论与无相论两派。依《广释》第十至十二节，这两句有三种解释：一、遮遣把识承许为有自性的有相、无相两类，包括经部、毗婆沙与唯识；二、遮遣唯识以离能取所取之识为实有的真如；三、指寂护等的"有相中观"与罗婆巴（Kambala）等的"无相中观"，说二者都不是最上。第三种解释最为重要，它说明下两句"中观也只是中等"，正是就这两种中观而说的。

"中等"（'bring po）一词，初稿列出两种理解。依《广释》第十六节，单凭理论抉择的中观，是"遮遣了各种差别之后，承许其余部分的境界"，即遮了有、无等边之后，又另外承许某种剩余（如"唯不生""唯空"），所以只是中等；真正要证悟的是"生与不生的双运"，而这要依殊胜上师的口诀来庄严。这更接近初稿的第一种理解：中观见本身并非错误，但若不依上师口诀成为智慧方便的双运，就停留在遮遣之后的某一边上。《广释》并说，经中说"唯空"，只是偏重智慧一分，不是为了割裂二谛的双运。这里所说的"上师口诀"，在梅纪巴的传统中，通常就是指大手印的直指教授。

这一颂后来成为藏传佛教中讨论"大手印是否超出中观""不依密乘灌顶能否证悟大手印"的重要依据，各家对此有不同的解释，这里只照原文译出，不涉及后世的争论。

## 第三颂　事物即菩提

```
དངོས་པོ་འདི་ནི་བྱང་ཆུབ་འགྱུར། །
ཆགས་པ་སྤངས་པའི་རང་བཞིན་ཉིད། །
འཁྲུལ་པ་ལས་ནི་ཆགས་མེད་འགྱུར། །
འཁྲུལ་པའང་གནས་པ་མེད་པར་འདོད། །
```

这事物本身就成为菩提，因为它的自性就是远离贪著的；［事物］是从迷乱中成为无贪著的，而迷乱本身，也被承许为无所住的。

【按】这一颂很浓缩。意思大概是：种种事物（dngos po）并不需要被舍弃才能成就菩提，因为它们的自性本来就远离贪著；所谓"无贪著"，不是离开迷乱另外得到的，而是就在迷乱之中实现的，因为迷乱本身也是无所住、无自性的。第三句"从迷乱中成为无贪著"，也可以理解为"由于［了知它是］迷乱，所以成为无贪著"，即认出迷乱本身就是解脱的契机。两种读法要点一致：不舍迷乱而得菩提。

依《广释》第二十二、二十三节："这"指现量所见，"事物"指五蕴；"贪著"指对有、无等任何自性的执著；迷乱是把有无等增益为事物的自性，即贪嗔痴本身；"迷乱也无所住"，是说迷乱不是像刺一样要以生灭的方式拔出的实物，只要遍知它的自性本来不生，迷乱就当下无所住，并引"在这上面没有任何要去除的，也没有一点要增加的"一偈为证。《广释》所引的第三句作"从贪著中成为迷乱"（ཆགས་པ་ལས་ནི་འཁྲུལ་པར་འགྱུར），与本单行本"从迷乱中成为无贪著"意思几乎相反，但两种读法都归到第四句"迷乱也无所住"，要点相同。

## 第四颂　真如即事物的无自性

```
དེ་ཉིད་ཅི་ན་དངོས་རང་བཞིན། །
དངོས་པོ་དངོས་མེད་གང་ཡིན་པའོ། །
དངོས་པོ་མེད་པའང་དངོས་པོར་འགྱུར། །
རྒྱུ་དང་འབྲས་བུའི་རང་བཞིན་གྱིས། །
```

真性是什么呢？［就是］事物的自性，也就是［显现的］事物与非事物［即空性］；非事物也成为事物，［这是］依于因与果的自性［而说的］。

【按】"事物与非事物"（dngos po dngos med），初稿读作"事物的无实体性"。依《广释》第二十四节，应读作"事物与非事物"："事物"是显现出来的一切，即本体；"非事物"被开示为空性；两者都是真性，所以"事物本身的本体就是真性"，并不离开事物另有真性。第三句"非事物也成为事物"，是回应"色等既然是空性，岂不成断灭"的疑问：空性本身就显现为事物，这就是双运真如。两种读法结论相同，都是空性与显现不二，但依《广释》层次更清楚，所以译文已据此改动。

依《广释》第二十五节，"依因与果的自性"有两种解释：一是依所开示的正理，所成、能成与真性都没有过失；二是"果"指显现的事物，以缘起为自性，"因"指真如，在胜义中不生，却是"俱生"（lhan cig skyes pa，sahaja）的；"自性"就是本然（gnyug ma），即双运的本体。这就把本颂与大手印的"俱生"联系起来。这与《无住义明示》第七颂"诸法之生本身就是空性"的意思相通。

## 第五颂　诸法一味，皆是光明

```
དེ་ལྟར་ཆོས་རྣམས་རོ་གཅིག་སྟེ། །
ཐོག་མ་མེད་ཅིང་གནས་མེད་པར། །
ཇི་ལྟ་བ་ཡི་ཏིང་འཛིན་གྱིས། །
འདི་དག་ཐམས་ཅད་འོད་གསལ་ཏེ། །
```

如此，诸法都是一味的，无始［一作"无碍"］，也无所住；以"如实三摩地"［来照见］，这一切都是光明。

【按】"一味"（ro gcig），是大手印四瑜伽中的第三个次第之名，这里指一切法同为真如、没有差别。"如实三摩地"（ji lta ba'i ting 'dzin），ji lta ba 一般对应梵文 yathābhūta 或 yathāvat，意思是"如其本然""如实"；这里指如其本然地照见诸法的三摩地，而不是另外造作出一种观想。"光明"（'od gsal），即心性的明净本性。

依《广释》第二十六节：《广释》所引第二句作"ཐོགས་པ་མེད་ཅིང་"（无碍），并解释为"对自性没有增益"；本单行本作"ཐོག་མ་མེད་ཅིང་"（无始），两字形近，必有一处是传写之误，依《广释》的解释，应以"无碍"为是，译文中以括注标出。"无住"就是不生，因为不住于有与无的自性。《广释》所引第三句作"如实生起的三摩地"（ཇི་ལྟར་འབྱུང་བའི་ཏིང་འཛིན），并解释为"具有止观双运的道"；"光明"是"自性远离垢染而成为自证，所以极为光明"。

## 第六颂　如实三摩地的来源

```
ཇི་ལྟ་བ་ཡི་ཏིང་འཛིན་ཡང་། །
རབ་ཏུ་འཇུག་པའི་སེམས་ཉིད་ཀྱིས། །
གང་ཕྱིར་དེ་ཡང་གནས་རིག་པས། །
དེ་ཉིད་རྒྱུན་མི་འཆད་ལས་སྐྱེས། །
```

那如实三摩地，也是由行［菩提］心而有；因为［依上师口诀］了知它的所依处，它本身是从不间断［的刹那相续］中生起的。

【按】这一颂初稿的译文是依上下文推测的，并注明"整体存疑，宜待《广释》订正"；现依《广释》第二十七、二十八节改译。

"趣入之心"（rab tu 'jug pa'i sems），《广释》解释为大乘所说的"行菩提心"（'jug pa'i sems），即与愿菩提心相对的行心，而不是初稿所说的"趣入真如的心"或"种种转起之心"。《广释》先依莲华戒《修习次第》说明显乘的愿心、行心与止观次第，然后指出那种"由观察而作"的行心并不是本颂的意趣；本颂所说的，是以无观察之心为先导、依上师口诀而修的行心，即"遍知一切法之后，无所修本身就是修"。

"了知它的所依处"（de yi gnas rig pa），初稿理解为"了知诸法的住相"；依《广释》，"它的所依处"就是行心的所依处，即双运真如的体性，也就是"空性与悲心无别的胜义菩提心"，要由殊胜上师的口诀来了知。"不间断"，就是这种证悟在各个刹那中相续生起；"因为以它为体性，所以称为瑜伽士"。

所以全颂的意思是：如实的三摩地，由行菩提心而成；因为依上师口诀了知行心的所依处——空悲无别的胜义菩提心，所以它在每一刹那都相续不断地生起。

## 第七颂　离二之念亦是光明

```
ཤེས་དང་ཤེས་བྱ་རྣམ་བྲལ་བའི། །
འགྲོ་བ་ཉིད་ནི་གཉིས་མེད་འདོད། །
གཉིས་དང་བྲལ་བར་རློམ་པ་ཡང་། །
དེ་ལྟར་འོད་གསལ་བ་ཉིད་དོ། །
```

众生本身，远离能知与所知，被承许为无二的；而那以为"［我］已离开二取"的念头，也同样就是光明。

【按】"以为已离开二取的念头"（gnyis dang bral bar rlom pa），rlom pa 是"自认为、自负、执以为"，带有"未必真实"的意味。这一颂的要点在后两句：修行人常会生起"我已证得无二"的念头，这本身又是一种执著；作者并不要求另外再去遣除它，而是说这个念头本身也同样是光明。这正是大手印"念头即法身""不舍分别而认出其本性"的要点。

依《广释》第二十九、三十节，这与初稿的理解完全一致，并有补充："无二"不是吠陀论者所说常恒的唯一者，而是非一非多；"远离能知所知"是唯识所成立的，"连认知本身也无自性"是中观所成立的，以方便与智慧为体性的无二之知，就是菩提心。"自以为离二的念头"，就是"观察真性的分别"。《广释》以此会通《入无分别陀罗尼》"以不作意舍弃诸相"之说：观察真如、对治、果的三种分别，本身也本性清净、是光明，遍知它们的本性就是真性，所以不需另外舍弃，并引"不住于对治之分，对真性也不贪著，对任何果也不希求，他就了知大手印"一偈。《广释》又说明："不作意"不是闭眼什么都不见，而是依观察或上师口诀，见而无所缘。《广释》所引第四句作"因为那也被承许为光明"（གང་ཕྱིར་དེ་ནི་འོད་གསལ་འདོད），文字稍异。

## 第八颂　如狮子般无畏

```
དེ་ལྟའི་དེ་ཉིད་ངེས་རྟོགས་ན། །
ཇི་ལྟ་དེ་ལྟར་གང་དེ་ན། །
རྣལ་འབྱོར་མིག་ནི་རྒྱས་འགྱུར་བས། །
ཀུན་དུ་སེང་གེ་ཇི་བཞིན་ནོ། །
```

如果决定地证悟了这样的真如，那么，无论［身、语、意］如何［行事］，以任何［饮食为食］，由于瑜伽之眼已经广大开展，［行者］处处都像狮子一样［无所畏惧］。

【按】"瑜伽之眼广大开展"（rnal 'byor mig ni rgyas 'gyur），意思是证悟的智慧之眼完全开显。"像狮子一样"，是说如同狮子在山野中行走无所畏惧，证悟者在一切境界中都不再被迷惑、恐惧所动。第二句"ji lta de ltar gang de na"语法较松散，初稿理解为"无论何处、无论如何"。依《广释》第三十四节，"ji lta de ltar"（无论如何）指身、语、意的一切行为方式；"gang de(s)"（以任何）指饮食，即得到什么就吃什么，不分可食与不可食、喜与不喜；译文已据此改动。《广释》又说："瑜伽之眼开展"是因为一切法都是真如甘露的自性，所以没有需要专门修的对治之分；另一种解释是证悟时眼中含泪、头低垂、身心被润泽。"处处"就是一切处无所畏惧。《广释》所引末句作"像狮子一样处处游行"（ཀུན་དུ་སེང་གེ་དེ་བཞིན་རྒྱུ），多"游行"一词。

《广释》在这一颂下还说明了这种修法的地位：它没有四手印与本尊慢的大乐，成佛比密咒瑜伽士慢；但因依上师口诀证悟双运真如，又远胜一般依波罗蜜多理趣的瑜伽士。

这一颂所说的行持，《广释》以"以一切欲妙的受用去修，就会很快成就"等无上瑜伽续的经文来解释，并说明在一切行为中"一刹那也没有别的心"，即对一切都不生执著，以"决定证悟真性"为前提。这只能依具德上师的灌顶与口授来理解，不可照字面模仿。

## 第九颂　疯行与无所缘之行

```
འཇིག་རྟེན་ཆོས་ལ་རྣམ་ལོག་འདིས། །
སྨྱོན་པའི་སྤྱོད་པ་ལ་བརྟེན་ནས། །
བདག་བྱིན་བརླབ་པས་རྣམ་བརྒྱན་ནས། །
དམིགས་པ་མེད་པར་ཐམས་ཅད་བྱེད། །
```

这样的［瑜伽士］，转离世间法，依止疯行，以自加持来庄严［自身］，无所缘地行一切［事业］。

【按】"转离世间法"，指不再随顺世间八法（利、衰、毁、誉、称、讥、苦、乐）。"疯行"（smyon pa'i spyod pa），是印度大成就者的一种特殊禁行，外表看起来像疯人，不依世俗的规矩，内里则是安住于证悟而对一切境界不取不舍。"自加持"（bdag byin brlabs，梵 svādhiṣṭhāna），在密续中是指以自身安住于本尊、光明的证悟来加持自己，属于密法的修持内涵。

依《广释》第三十八节："世间"就是会坏灭的五蕴，"转离世间法"就是超越五蕴的自性以及由它而有的八法。"疯行"的核心是"使心意没有［造作的］意图"，即心中没有刻意的计较、取舍，外在形式并不是重点。"无所缘地行一切"，是说虽然超越了世间法，却不住涅槃，在世间的事业中行持乃至受生，而对有、无等都无所缘，连自证也是不生的。"自加持"，《广释》解释为"把自身，即瑜伽士的心相续，加持为本然的真性、真如的体性"，以从真如自性中自然放射出来的［功德］来庄严，并没有特别提到本尊。《广释》所引第二句作"依止疯行的禁行"（སྨྱོན་པའི་བརྟུལ་ཞུགས），第三、四句次序与本单行本对调。

这一颂所说的，是已经"决定证悟真如"（上一颂）的瑜伽士的行持，以证悟为前提。疯行、自加持都须依具德上师的灌顶与口授来理解，修行人不可在没有证悟之时照字面模仿，以疯行为放逸的借口；梅纪巴在《除恶见》《幻教示》中对此已有明确的告诫。

## 第十颂　结示

```
དྲི་མེད་དེ་ཉིད་གང་བསྟན་ཅིང་། །
གཉིས་སུ་མེད་པ་གང་སྨྲས་པ། །
མཉམ་དང་མི་མཉམ་འདི་སྤངས་ནས། །
བློ་ཆེན་རྣམས་ཀྱིས་རྟོགས་བྱའི་རིགས། །
```

这里所开示的无垢真如，这里所宣说的无二［之理］，诸大智者应当舍弃"平等"与"不平等"［的分别］，来证悟它。

【按】第三句"mnyam dang mi mnyam 'di spangs nas"有两种读法：一是"舍弃'平等'与'不平等'［这两种分别］"，即对真如不作平等或不平等的分别；二是"舍弃这［一切］平等与不平等之见"，意思相同。初稿还提出 mi mnyam 可能是"无等、无比"之义，存疑。依《广释》第三十九节，"平等"指执著涅槃，"不平等"指执著轮回，"舍弃平等与不平等"就是不执涅槃、也不执轮回，存疑可据此订正。

《广释》又指出，第二句"以'无二'所宣说的"，"无二"（gnyis su med pa，advaya）兼指作者梅纪巴的名字"无二金刚"（Advayavajra），是"以自己的名字来标示论典"；同时也指方便与智慧不相别异的无二。"诸大智者"，《广释》所引作"诸慧藏者"（blo gter），解释为要像验金那样以智慧观察，而不是枯燥的思辨。"应当证悟"（rtogs bya'i rigs），rigs 是"应当、适合"，也有"［大智者］这一类人"的意思。

## 跋

《真如十颂》，阿阇黎无二金刚所造，圆满。

上师金刚手与粗敦译出。后来又由译师戒胜重译。

【按】"金刚手"，原文作 phyag na（"手持"），是金刚手（phyag na rdo rje，Vajrapāṇi）的略称。"重译"，原文作 bsgyur，可能是修订旧译，也可能是另行翻译；现存的德格本究竟是哪一次的译本，跋语没有说明。

## 通篇连读

敬礼文殊童子！

那不能以有、无来安立、无垢的，那证悟菩提自性的，就是真如，我对它恭敬顶礼。

想要了知真如的人应当明白：真如既不是有相派所说的那样，也不是无相派所说的那样；而没有以上师口诀庄严的中观，也只不过是中等而已。

这事物本身就成为菩提，因为它的自性本来就远离贪著；事物是从迷乱中成为无贪著的，而迷乱本身也是无所住的。

真性是什么呢？就是事物的自性，也就是显现的事物与非事物（空性）；非事物也成为事物，这是依于因与果的自性而说的。

如此，诸法都是一味的，无始（一作无碍），也无所住；以如实三摩地来照见，这一切都是光明。

那如实三摩地，也是由行菩提心而有；因为依上师口诀了知它的所依处，即空悲无别的胜义菩提心，它本身是在每一刹那相续不断地生起的。

众生本身远离能知与所知，是无二的；而那以为"我已离开二取"的念头，也同样就是光明。

如果决定地证悟了这样的真如，那么无论身语意如何行事、以任何饮食为食，由于瑜伽之眼已经广大开展，处处都像狮子一样无所畏惧。

这样的瑜伽士，转离世间法，依止疯行，以自加持庄严自身，无所缘地行一切事业。

这里所开示的无垢真如，这里所宣说的无二之理，诸大智者应当舍弃执著涅槃与执著轮回的平等与不平等之分别，来证悟它。

《真如十颂》，阿阇黎无二金刚造，圆满。上师金刚手与粗敦译出，后来又由译师戒胜重译。
