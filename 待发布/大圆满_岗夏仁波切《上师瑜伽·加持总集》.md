# 上师瑜伽·加持总集

堪布岗夏旺波 造

```
རང་སེམས་སྤྲོས་པ་བྲལ་བ་ལ། །
རང་ངོ་ཤེས་པས་སྐྱབས་སུ་མཆི། །
མ་རིག་འཁྲུལ་པའི་མ་རྣམས་ཀུན། །
གདོད་མའི་ས་ལ་བཀོད་པར་བགྱི། །
```

于离戏之自心，以自证自识而皈依；一切因无明而迷乱之如母有情，愿悉皆安置于本初之地。

```
ཨཱ། །
རང་སྣང་དག་པ་དབྱིངས་ཀྱི་མཁར། །
རང་རིག་སྤྲོས་བསྡུ་བྲལ་བ་ཡི། །
རིག་རྩལ་མ་འགག་ཅིར་ཡང་འཆར། །
འཁོར་འདས་ཀུན་ཁྱབ་སྲིད་ཞིའི་དཔལ། །
རིག་སྟོང་འཛིན་མེད་ཀློང་དུ། །
ཨཱཿ ། ། 
```

阿！自现清净法界之宫殿，自证觉性离于放收（离戏）之觉性力用，无有间断、无所不现，遍摄轮涅一切、有寂之荣耀——于觉空无执之广袤界中：啊！

如是，当下此刻平常赤裸之心识，离于造作、空明无为之觉性——应决断此即是吉祥上师之智慧心，并于此境界中加以护持。

应具足三学之上师玛哲之劝请，岗夏旺波书写而成。

---

## 译者说明

本篇依藏文原文重新译出，参考但不依循已有中译本之措辞。此篇为上师瑜伽之精要仪轨，前段为皈依发心之偈颂，中段"阿……啊"为观修法界宫殿、觉空无执之简短观诵文，末段为直指心性之散文教授，说明当下赤裸平常心之觉性，即是上师智慧心，应就此加以护持——此为大圆满上师瑜伽中"上师智慧心与自心无二"之核心见地。文中"ཨཱ"与"ཨཱཿ"为观修中所诵之种子字，依惯例音译为"阿"与"啊"，保留其咒语性质，不作意译。
