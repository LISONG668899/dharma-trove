# 无住义明示

梅纪巴（阿阇黎无二金刚）造　据藏文译出

## 题解

《无住义明示》（梵 Apratiṣṭhānaprakāśa，藏 rab tu mi gnas pa gsal bar ston pa，直译"极无住之明示"）收于德格版丹珠尔续部释 ཝི 函第 112a 至 112b 页（东北目录 D2235），紧接在《幻教示》（D2234）之后，同属梅纪巴的"无念法类"。译者是印度上师金刚手与那措译师。

前面的《中观六颂》《梦教示》依次判摄诸家见解，最后都归到"无住"之说；本篇就专门开示这"无住"。全篇共十一颂四十四句，大致可以分为四部分：

第一颂总标：无住之智是诸佛共同的传承，而它又能无勤作地利益众生。

第二至六颂破斥与辨析：以遮遣、成立而生的分别心，落在常、断二边；接着处理一个难题——如果自证之中一切显现都已舍弃，那就没有众生，佛又怎样利益众生？如果说后得位中有众生，众生是否又成了实有？作者以根本定与后得的关系、三时之心无所住来回答。

第七至十颂正说无住：诸法之生本身就是本然、不可思议的，这就叫空性，不落断见；无住之因生无住之果；对离贪之行，不能说有禅定或无禅定；一切缘起都是无二的种种心，由空、种种、心的分别而有三身。

第十一颂回向。

本篇的论证极为简略，多处像是辩论中的问答缩写，下面按语中尽量依上下文把问答的脉络补出来，凡属推测的，都标明存疑。

体例：每颂先列藏文原颂于代码块中，再按完整的意义单元译出；为了便于理解而补的字，都放在方括号中。原文含混或可有两解之处，以"【按】"说明，不妄补内容。文末附通篇连读。

敬礼文殊童子！

## 一、总标：无住之智

```
ཤེས་པ་རབ་ཏུ་མི་གནས་པ། །
སངས་རྒྱས་ཕ་ནོར་ཐམས་ཅད་འདོད། །
འོན་ཀྱང་འབད་མེད་སྦྱོར་བ་ཡིས། །
གང་ཚེ་སེམས་ཅན་དོན་བྱེད་ནའོ། །
```

全然无所住的智慧——所有［佛弟子］都承许它是诸佛［传下］的祖业家财；然而，［这无住之智］却是在以无勤作的方式，［同时］作利益众生的事业。

【按】"祖业家财"（pha nor），字面是"父亲的财产"，即代代相传的家业。"sangs rgyas pha nor thams cad 'dod"一句，可以理解为"一切［佛教徒］都承许［它］为诸佛的家业"，也可以理解为"诸佛所欲求的一切家财"；这里依前一种。后两句的语法不完整，直译是"然而以无勤作的结合，当作众生利益之时"，意思应是：无住之智虽然无所住、无所执，却并不因此停止利他，而是无勤作地成办众生的利益；这也引出下文的难题。

【按】《梦教示》第九颂有"sangs rgyas pa kun nor yin pas"一句，当时 nor 有"错失""珍宝"两种读法，我在那里取了"错失"。本篇开头以"诸佛的家财"（pha nor）称无住之智，与那一句很可能是同一个说法，这就使"珍宝"的读法变得更有力：意思是"因为无住是一切佛教徒的珍宝"。

## 二、分别心落于常断

```
གང་ཕྱིར་གཞན་སེལ་སྒྲུབ་ལས་སྐྱེས། །
དེ་ནི་རྟག་དང་ཆད་ལ་གནས། །
རྟག་ཏུ་མ་སྐྱེས་མི་འགག་ཉིད། །
སྐྱེ་དང་འགག་པ་བྱོལ་སོང་ཚིག །
```

因为［分别心］是从遣除他者与成立而生起的，所以它安住于常边与断边；［而实相］恒常是不生、不灭的，［说实有］生和灭，只是畜生般［愚昧］的言语。

【按】"遣除他者"（gzhan sel，梵 anyāpoha），是佛教因明的术语：分别心与语言并不直接把握事物本身，而是以"排除非此"的方式来认识，比如以"非非牛"来认识"牛"。这里的意思是：分别心只能以遮遣、成立来运作，所以说"有"便落常边，说"无"便落断边，不能契入不生不灭的实相。"畜生般的言语"（byol song tshig），是很重的贬词，指执著实有生灭的说法愚昧不通；也可能是指只认现量所见生灭的凡俗之见，存疑。第三句的主语原文没有明说，这里依上下文补为"实相"。

## 三、难题之一：自证中无众生

```
གལ་ཏེ་རང་རིག་ཚད་མ་ནི། །
རིག་དེ་སེམས་ཅན་འདོད་མ་ཡིན། །
སྣང་བ་ཐམས་ཅད་སྤང་བའི་ཕྱིར། །
སེམས་ཅན་བདེན་པ་མ་ཡིན་ནོ། །
```

如果［以］自证为量，那么这种觉知中并不承许有众生；因为［在其中］一切显现都已舍弃，所以众生并不是真实的。

【按】这一颂与下一颂，看来是在处理第一颂引出的难题：无住之智既然无所住，又怎样利益众生？这里先说：在自证现量的境界中，一切显现都已舍弃，并没有"众生"可得，所以众生不是真实的。这一颂可能是作者自己的立场，也可能是对方的说法；从下一颂以"若说"起头来看，这一颂较可能是作者的立场，下一颂才是对方的反驳。存疑。

## 四、难题之二：后得中的众生

```
རྗེས་ལ་སེམས་ཅན་འདོད་ཅེ་ན། །
དེ་ཚེ་སེམས་ཅན་རྫས་ཡོད་མིན། །
དམ་བཅས་གཅོད་པ་གནོད་པའི་དོན། །
རྗེས་སུ་རྟག་པ་ཞེས་བརྗོད་དོ། །
```

如果说："在后得［位］中承许有众生。"那么，这时众生也不是实体有的。［若把后得的众生执为实有，］那就是损害、断送［自己］所立宗义的意思，［这］就叫作"后得的常见"。

【按】"后得"（rjes），指从根本定出定之后的阶段；"实体有"（rdzas yod），指作为真实实体而存在。这一颂的后两句最难解，直译是"断除所立宗、有妨害之义，称为随后之常"。这里的理解是：如果在后得位把众生执为实有，那就与"一切无生"的宗义相违，等于自己破坏自己的宗义，而且落入了常见；由于这种常见发生在后得位，所以称为"后得的常见"。"rjes su rtag pa"也可以理解为"随顺于常见"，意思相近。这一理解是依上下文的推测，存疑。

## 五、根本定与后得

```
དངོས་གཞི་ལ་ཡང་རིག་པ་ཡོད། །
རྗེས་ལ་དེ་ལྟར་སྣང་བའི་ཕྱིར། །
དང་པོ་མི་རྟོག་པར་འགྱུར་གྱིས། །
དེ་ལས་འཛིན་པའི་ཤེས་པའོ། །
```

在根本［定］中，也是有觉知的，因为在后得中［显现］就是那样显现的。最初［根本定中］成为无分别，从那［之后］，才有能执取的［分别］心识。

【按】"根本"（dngos gzhi），指根本定、正行。这一颂似乎在回答上面的难题：根本定中并不是一无所知的空白，仍然有觉知；正因如此，出定之后才会有那样的显现。根本定是无分别的，出定之后才有执取的分别识。作者的意思大概是：众生的显现与利生的事业，属于后得的如幻显现，并不与根本定的无所住相违，也不需要把众生执为实有。第一、二句的因果关系，也可以读作"根本定中有觉知，所以后得中能如此显现"，两种读法意思相近。

## 六、三时之心无住

```
འདས་དང་མ་འོངས་ལ་སོགས་པའོ། །
སེམས་ནི་གནས་པ་ཡོད་མ་ཡིན། །
དེས་ན་དེ་དག་མེད་པར་ནི། །
འགྲོ་ལ་འགྲོ་བའི་མགོན་པོས་བསྟན། །
```

过去、未来等［三时］之中，心都没有所住之处。所以，众生的怙主［佛陀］为众生开示：这些［三时之心］都是不存在的。

【按】这一颂与《金刚经》"过去心不可得，现在心不可得，未来心不可得"的意思相合，也与诸经中"心不住内、不住外、不住中间"的说法一致。"这些"（de dag），指三时之心，也可以理解为三时本身。

## 七、诸法之生即是空性

```
ཆོས་རྣམས་ཀྱི་ནི་སྐྱེ་བ་ཉིད། །
རང་ཉིད་གཉུག་མ་བསམ་མི་ཁྱབ། །
དེ་ཉིད་སྟོང་པ་ཉིད་ཅེས་བརྗོད། །
ཆད་པའི་རྗེས་འགྲོ་མ་ཡིན་ནོ། །
```

诸法的生起本身，其自体就是本然的、不可思议的；正是这［本然不可思议的生起］，被称作空性——［所以这空性］并不是随顺断见的。

【按】这一颂很重要：作者不是把空性理解为"生起被否定之后剩下的什么都没有"，而是说诸法的生起本身，作为本然、不可思议的，就是空性。"本然"（gnyug ma），即本来如此、非造作的，大手印中常说的"本然心"（sems gnyug ma）用的就是这个词。因为空性就是那不可思议的生起本身，而不是生起的断灭，所以说"不是随顺断见的"。

## 八、无住之因生无住之果

```
རབ་ཏུ་མི་གནས་ས་བོན་ལས། །
འབྲས་བུ་རབ་ཏུ་མི་གནས་འབྱུང་། །
སྐྱོབ་པ་དེ་ཉིད་དམ་པ་སྟེ། །
བཅོས་མའི་བཅོས་མ་དེ་བཞིན་ནོ། །
```

从全然无住的种子，生出全然无住的果；那救护者［佛陀］正是［这无住之果的］最胜者。就像造作的［因］生出造作的［果］一样，［无住之因也生无住之果］。

【按】第四句"bcos ma'i bcos ma de bzhin no"，直译是"造作者的造作，也是如此"。这里的理解是：这是一个反面的类比——造作的因生造作的果，同样，无住的因生无住的果，因果是相应的。所以要得无住的佛果，就要修无住之因。另一种可能的理解是：相对于造作而言的"造作"，也是如此无住，存疑。"救护者"（skyob pa），是佛陀的称号。

## 九、离贪之行不可说有无禅定

```
དེ་བཞིན་བསམ་གཏན་ཡོད་མེད་ཅེས། །
ཆགས་མེད་སྤྱོད་ལ་བརྗོད་དུ་མེད། །
གང་ཕྱིར་རྟེན་ནས་འབྱུང་བ་རྣམས། །
ཉམས་མྱོང་ཇི་བཞིན་རྟག་ཏུ་སྐྱེ། །
```

同样，对于无所贪著的行持，不能说它"有禅定"，也不能说它"无禅定"；因为种种缘起之法，总是如其［所］领受的那样生起。

【按】这一颂的意思是：证悟无住的瑜伽士，他的行持没有贪著，既不住于禅定，也不离开禅定，所以不能用"在定""出定"来描述。种种缘起显现如其所领受地生起，瑜伽士也不去取舍。这与大手印"无修""无散"的说法相合。"如其所领受的那样"（nyams myong ji bzhin），也可以读作"如［各人］体验的那样"。

## 十、无二的种种心与三身

```
རྟེན་ནས་འབྱུང་བ་གང་དང་གང་། །
དེ་དེ་གཉིས་མེད་སྣ་ཚོགས་སེམས། །
སྟོང་དང་སྣ་ཚོགས་སེམས་དབྱེ་བས། །
ཆོས་དང་ལོངས་སྤྱོད་སྤྲུལ་པ་ཉིད། །
```

凡是缘起的一切，每一个都是无二的种种心；以空、种种与心［三者］的区分，［便安立为］法身、报身与化身。

【按】这一颂极为简略，后两句的对应关系原文没有说明。依字面次序，可以理解为：空——法身，种种［显现］——报身，心——化身；但"种种显现"对应化身、"心之明性"对应报身，似乎更合乎一般的说法。另一种理解是：以"空"与"种种心"二者的分别，安立三身。这里只照原文次序译出，不强作对应，存疑。"无二的种种心"，是说种种显现都是心，而能取所取无二；这里所说的"种种心"，应在无住的意义上理解，与《梦教示》中作为一种唯识主张的"种种心"不同。

## 十一、回向

```
བདག་གིས་མི་གནས་བརྗོད་པ་ལས། །
བདེ་བ་བསགས་པ་གང་ཡོད་དེས། །
ཉེ་བར་སྤྱོད་པ་ཐམས་ཅད་དང་། །
འགྲོ་རྣམས་མི་གནས་ཐོབ་པར་ཤོག །
```

我宣说无住［之义］，由此所积集的一切安乐［福德］，愿以此使一切受用［这一教法］的人与一切众生，都获得无住［之果］！

【按】"安乐"（bde ba），在回向中常是"善、福德"之义。"一切受用者"（nye bar spyod pa thams cad），也可以理解为"一切受用"，即愿众生连同其一切受用都得无住；这里取指人的读法，存疑。

## 通篇连读

敬礼文殊童子！

全然无所住的智慧，一切佛弟子都承许它是诸佛传下的家财；然而，它却是在以无勤作的方式，作利益众生的事业。

分别心从遣除他者与成立而生起，所以落在常边与断边；而实相恒常不生不灭，说实有生灭，只是畜生般愚昧的言语。

如果以自证为量，这觉知中并不承许有众生；因为其中一切显现都已舍弃，所以众生并不是真实的。

如果说"后得位中承许有众生"，那么这时众生也不是实体有的；若把它执为实有，就是损害自己所立的宗义，这叫作后得的常见。

根本定中也是有觉知的，因为后得中显现就是那样显现的；最初根本定中是无分别，从那之后，才有能执取的心识。

过去、未来等三时之中，心都没有所住之处；所以众生的怙主为众生开示：三时之心都不存在。

诸法的生起本身，其自体就是本然的、不可思议的，正是这被称作空性，所以它并不随顺断见。

从全然无住的种子，生出全然无住的果；那救护者正是这无住之果的最胜者，就像造作的因生出造作的果一样。

同样，对于无所贪著的行持，不能说它有禅定，也不能说它无禅定；因为种种缘起之法，总是如其所领受的那样生起。

凡是缘起的一切，每一个都是无二的种种心；以空、种种与心三者的区分，便安立为法身、报身与化身。

我宣说无住之义，由此所积集的一切福德，愿使一切受用这一教法的人与一切众生，都获得无住之果！

《无住义明示》，阿阇黎无二金刚造，圆满。金刚手与那措译出。
