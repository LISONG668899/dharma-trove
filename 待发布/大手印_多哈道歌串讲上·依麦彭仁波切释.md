# 萨绕哈《多哈道歌》串讲·上：依麦彭仁波切释

## 缘起

萨绕哈是印度八十四大成就者之首，大手印传承的源头之一。他的道歌以俗语唱出，不讲名相次第，只是一再把人推回自己的心。藏地各派大德讲心性时，常引其中的金刚语。

本文依麦彭仁波切所造《多哈道歌释》的思路，把全篇串成一条线来讲。偈颂引用索达吉堪布译本，只取关键数句；欲读注释全文，请参阅原书。依印度无二金刚《难释》的读法，见本系列下篇。

## 一、先破：凡是造作的，都到不了那里

道歌开篇不谈心性，先唱一长串"不对"。婆罗门诵吠陀、烧火供，苦行者裸身拔发、站着吃饭，萨绕哈一一点破，语气近乎嘲讽：裸体若能解脱，狗和狐狸早该解脱了。

这些话不只是对外道说的。他随即把矛头转向佛门自家：讲经的、持唯识的、修中观的、观坛城的、执空性的，只要离开了俱生智，修得再精进，也只能成就自己心里想出来的那个东西。

```
远离俱生者，修行涅槃法，
彼除世俗外，胜义终不成。
```

麦彭仁波切在这里点出一个要害：实相不会随着我们的想法改变。我信什么、观什么、安住在什么定里，都是心的造作，而要认识的恰恰是未经造作的本来面目。

所以这一部分的"破"，不是否定修行，而是先把"靠做点什么去得到它"这条路堵死。

## 二、空悲不二：这条路一开始就定了方向

破完之后，萨绕哈第一句正面开示，就是空悲双运。偏于空性而离开悲心，会落入小乘的寂灭；只修悲心而不见空性，斩不断轮回的根。

```
空悲双运者，轮涅俱不住。
```

这一句要先记住，因为全篇到最后，又落回空性之树与大悲之树。首尾相应，说明大手印的见地从来不是一个人独享的寂静。

## 三、俱生：本来就在，只是没认出

萨绕哈说，这个东西没法指给人看，只能依上师口诀认出。认出的那一刻，就像看见自己掌中的宝。重点在"自己的"：不是得到新东西，是发现原有的。

它是什么样子？道歌说"非实非无实"。它不像瓶子那样实在，也不像虚空那样什么都没有。注释说，萨绕哈常常高声赞叹这一点，可惜世人听不懂。

《难释》在这一偈下引了弥勒菩萨的偈子："此中无所破，亦无少所立，于真性正观，见真即解脱。"不用去掉什么，也不用添上什么，如实看见，就是解脱。这可以视为全篇见地的总纲。

紧接着的"常住十四地，无身隐于身，识彼即解脱"，也是同一个意思。麦彭仁波切把"十四地"解为与第十三地无别的本体，它不是更高的一级阶位，而是诸地本来的体性。它常住，无形，藏在这个身体里，要的只是认出。

## 四、心：如意宝，也是绳结

道歌中最常被引用的，大概就是向心顶礼的一偈：

```
心唯一切种，彼现轮涅法，
能赐所欲果，顶礼如意心。
```

轮回从这颗心现，涅槃也从这颗心现。所以萨绕哈说，心被绑住就是束缚，心解开就是解脱。愚人被它困住，智者凭着同一颗心迅速出离。

怎么解开？他的回答出人意料：放松。

```
疙瘩缚此心，放松定解脱。
```

他打了个比方：骆驼被拴紧了，就拼命往四面乱冲；松开缰绳，它反而安静地站着不动。心也是这样，越想按住，越是翻腾。

所以他反对闭目、盯鼻尖、强行憋气这类刻意的功夫。注释说，用力把心集中，气反而像浪一样狂乱，好比蚕被自己吐的丝缠住。认出俱生的本性，心自然就稳了。

## 五、日用：不离吃饭走路

如果放松只能在坐垫上做到，那还是有造作。萨绕哈把它推到每一个当下：

```
见闻触忆念，食嗅游走住，
闲谈及对答，一心不动摇。
```

看、听、碰触、回忆，吃饭、闻味、走路、闲谈、回话，都知道这是自己的心，不离那唯一的本然。这里的"不动摇"不是死守一个状态，而是不管做什么都没有离开。

乌鸦的比喻也在讲这个。从船上飞出去的乌鸦，绕了一圈又一圈，最后还是落回船上。念头往外散，不必追，也不必拦，放下了，它自己回来。

更进一步，萨绕哈说念头散出去的那一刻，就是本性本身，正如波浪离不开水。到了这里，轮回与寂灭已经没有分别。

## 六、融：水入水，盐入水

这一段是道歌里最美的几个比喻。水注入水，分不出哪一份是原来的；盐溶在水里，看不见却遍在每一滴中。心融入自性时，自他平等，再也用不着辛苦造作的禅修。

还有一个火的比喻：火在林中蔓延，烧尽一切。面前出现的种种显现，都被认作心的空性，不必另找对治的办法。

## 七、找家主：最近的，最难见

萨绕哈说，有人跑到外面去找"家主"，来时没见到，走时也找不着。它就住在那里，却认不出来。麦彭仁波切解释，家主指本来的智慧，舍弃自证向外追寻，就会这样当面错过。

那该怎么办？道歌说，像婴儿一样安住。婴儿没有那么多思量取舍，能想的、所想的都放下，只是精勤于上师的教言，俱生智自然会现前。注释说，分别念本身就是病，不能再拿分别念当药吃。

## 八、大乐：黑暗中的月宝

萨绕哈常用"大乐"一词。这里的乐不是世俗的快感，而是远离分别、自他俱泯时本来的安乐。道歌说，就像漆黑中升起一颗月亮宝珠，只要一刹那契入这大乐，相续中的罪业都会消尽。

即使是愚人，只要这样回头看自己的心，种种邪见也会自己解开。这是道歌对每个人的承诺：方法不复杂，要紧的是肯不肯回头。

## 九、轮涅无二：不必逃，也不必守

到这里，萨绕哈唱出全篇的核心：轮回就是涅槃，两者没有丝毫差别。

他对修行人的劝告很实际：不要为了躲避家里的烦恼逃进森林，也不要被贪著拴在家里。无论身在何处，只要心认出本然，行住坐卧都在菩提之中。

注释还说，大海澄清时，水泡本来就是水，终会融回大海。妄念也是这样，本身就带着俱生的体性。

## 十、空悲妙树：最后落回利他

见地讲到究竟处，萨绕哈没有停在那里，而是画了一棵树：无二之心的妙树遍布三界，开出大悲的花，结出利他的果。

```
一种生双树，其法相一果，
无二若思此，解脱于轮涅。
```

一颗种子长出空性与大悲两棵树，结的却是同一个果。麦彭仁波切说，因与果虽可分说，在大乐中平等无二，能这样了知的人，轮回与涅槃两边都不住。这正好回应了开头的"空悲双运者，轮涅俱不住"。

全篇最后两偈落在一个最平常的场景：有人上门乞讨，你给不给？萨绕哈说，让求助的人失望而去，还不如自己舍了家，捡个破碗去流浪。不做利他的事，守着的家财不过是轮回里的一点果报，所以应当舍弃自我。

这个结尾很有分量。前面讲了那么多无修无整，最后却要求你在一件具体的小事上兑现。证悟是否真实，就看能不能放下"我"去帮人。

## 结语

把全篇串起来看，萨绕哈只说了一件事：本来具足的心，认出它，安住它，在一切时中不离它，并让它自然流出悲心。

破外道、破内执，是为了让人不再向外求；放松、日用、融入，是认出之后的安住；空悲妙树和门前的乞者，是安住之后的流露。

萨绕哈的语言粗犷、直接，甚至近乎冒犯，但每一句都指向同一处。读这部道歌，不妨少一点分析，多一点回头。
