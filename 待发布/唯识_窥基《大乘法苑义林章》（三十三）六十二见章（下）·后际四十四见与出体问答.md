# 窥基《大乘法苑义林章》（三十三）六十二见章（下）·后际四十四见与出体问答

〔译注：本篇续译第二门中"计后际"的五类四十四见：有想论十六、无想论八、非有想非无想论八、断灭论七、现法涅槃论五；再译第三门出体（边见摄四十七，邪见摄十五）、第四门迷谛通别、第五门问答。第五门窥基只列出十个问题，没有给出答案，留待学人推寻。〕

## 六、计后际的五类四十四见

### （一）十六种有想论

#### 1. 依三种见立四句

《瑜伽师地论》第六卷、《显扬圣教论》第九卷说：最初的四种见，依三种见而立：

1. 如果计执命者就是身体，就计执我是色。
2. 如果计执命者异于身体，就计执我不是色。
3. 如果计执我遍满、无二无缺，就计执我也是色也不是色。
4. 如果为了对治这种执着，在这个意义中，由不同的文句而生起执着，就计执我不是色、也不是非色。

这个意思是说：无想天处称为无想；有顶称为非有想非无想；下三无色地、色界中除去无想天的其余各处、欲界等，都称为有想。

第八十七卷说："由于依'命者就是身'的见，计执我有色，死后或者有色有想，或者无想，或者非有想非无想。由于依'命者异于身'的见，计执我无色，死后有想，或者无想，或者非有想非无想。由于依这'总是我遍满、无二无缺'的见，说我也有色也无色死后有想、非有色非无色死后有想。无想以及非有想非无想也是这样。"

上面的意思是说：执着有色等死后有想的最初四句，与死后无想，以及死后非有想非无想的最初四句相同，只是生处有差异，现在世都相同。因为依于"命者异于身"、"无二无缺"等三种见之上，立这三种四句的意义。

1. 执着色为我，称为命即是身。
2. 执着非色为我，称为命异于身。
3. 双执色和非色作为我，称为无二无缺。

"我有色"等句：在无色界下三地，如果说有色，也遍于那里；如果说无色，就不及于那里。

死后有想的四句：

1. 执着我有色，死后有想。
2. 执着我无色，死后有想。
3. 执着我也有色也无色，死后有想。
4. 执着我非有色非无色，死后有想。

#### 2. 有边等四句

第八十七卷说："计执我是色的，或者说狭小，或者说无量；计执我无色的，应当知道也是这样，也有狭小以及无量，因为所依、所缘、作用等法有大有小。"这两种我论，依第三种"总遍满、无二无缺"的见，立为两种论：一是计执我狭小，二是计执我无量。由这四种我论的差别，说"我有边"等四句，依次配合。

所以《瑜伽师地论》第六卷说：

1. 如果见到少许色、少许非色，就计执有边。
2. 如果见到这两者无量，就计执无边。
3. 如果又遍见，而色的部分少、非色的部分无量，或者色的部分无量、非色的部分少，就计执也有边也无边。
4. 为了对治这种执着，只由于文句不同，不由于意义不同，而生起执着，就计执非有边非无边。

观察这段文的意思，第六卷最为正确。第八十七卷中依次配合，是意义的次第，不是文句的次第：执着色、非色狭小的，称为有边；执着色、非色无量的，称为无边；交互执着多少的，作为俱句；遮遣这些的，作为第四句，与前面的文相同。以这四种，死后生到有想地，称为第二组"有边"等四句。

#### 3. 一想等四句

再其次的四句，第六卷只有名称，没有辨明处所。第八十七卷说：

1. 执着我一想：在空无边处、识无边处。不说无所有处，是因为文字简略；无所有处也是一想，与《大毗婆沙论》相同。因为《瑜伽师地论》说无量想配前面的一想，所以略去不论无所有处，那里不是无量想，只是一想。
2. 执着我种种想：就是在下地。
3. 执着我有狭小想：就是在下地。
4. 执着我无量想：就是空无边处、识无边处。

第八十七卷说："就如所说的两种想，随其次第应当了知，说我有狭小想、有无量想。"这是以义理逆着次第配合。

《大毗婆沙论》说：执着少许色为我，想为我所，我与想和合，称为少想，在欲界、色界，除去无想天；无量想，就是执着无量色为我，想为我所等，如前面广说。《瑜伽师地论》的意思是说：就在前面所说一想的地方，有无量想；种种想的地方，有这种少想。也不相违。

#### 4. 苦乐等四句

再其次的四句：

1. 我纯有乐，死后有想。第六卷只有名称，没有处所；第八十七卷说，就是下三静虑。
2. 我纯有苦，死后有想：就是在地狱。
3. 我有乐有苦，死后有想：在鬼、傍生、人、欲界天。
4. 我无乐无苦，死后有想：在第四静虑以上，乃至有顶。

以上说明有想十六论完毕。

### （二）八种无想论与八种非有想非无想论

八种无想论、八种非有想非无想论，就是有想论中最初的两组四句，即"有色""有边"等，如前面所引的教文已经简略说完，只是所生的处所有差异，其余的意义都相同。

《瑜伽师地论》等只说"有色"，没有说明在什么地方。《大毗婆沙论》说是前三无色地。有人说：说有色，也包括无色界；说无色，就不及于无色界。

### （三）七种断灭论

《瑜伽师地论》第七卷、《显扬圣教论》第十卷说：

1. 我有粗色、四大所造之身，任持还没有坏的时候，有病、有痈、有箭；如果我死后断坏不存在，那时我就是断灭。
2. 欲界诸天。
3. 色界诸天。
4. 空无边处所摄的诸天。
5. 识无边处。
6. 无所有处。
7. 非想非非想处所摄的诸天。

这些死后断灭。这里的七种断灭，不限定自己或他人，今身或后身，一切都可以。

### （四）五种现法涅槃论

《瑜伽师地论》第七卷、《显扬圣教论》第十卷说：

1. 如果我解脱，心得自在，观得自在，就是对诸天微妙的五欲，坚固执着、摄受、嬉戏、淫乐，随意受用，这就称为得到现法涅槃第一清净。这是说胜妙的，略去人中；《大毗婆沙论》说有人中。
2. 如果有人离开欲望和恶不善法，在初静虑中得以具足安住。
3. 离开寻伺，得第二静虑具足安住。
4. 离开寻伺和喜，得第三定具足安住。
5. 离开喜乐等，得第四静虑具足安住，是现法涅槃第一清净。

以上称为后际分别的各种见。

## 第三门　出体性

六十二见以五见中的两种见为体性：一是边见，二是邪见。

《杂集论》第一卷说："问：六十二见属于哪一种见所摄？答：或者两种，或者一切。"觉师子解释说："两种，是从自性来说；一切，是从眷属来说。"

### 一、边见所摄四十七见

《瑜伽师地论》第五十八卷、《成唯识论》第六卷说："边见的差别，就是执着前际的四种遍常论、四种一分常论，以及计执后际的十六种有想论，无想、俱非各有八论，七种断论等，属于边执见所摄。"

《瑜伽师地论》第五十八卷说："常见所摄的六十二见中，就是计执前际的各种遍常论、一分常论，以及计执后际的各种有想论、无想论、非想非非想论；断见所摄的，就是七事断论。"常见摄四十种，断见摄七种，总合边见摄四十七种。

### 二、邪见所摄十五见

《成唯识论》以及《瑜伽师地论》第五十八卷说："邪见的差别，有执着前际的两种无因论、四种有边等论、四种不死矫乱论，以及计执后际的五种现法涅槃论。"这样邪见摄十五种见。

所以说从自性来说，属于两种见所摄。如果连同眷属，属于五见所摄，因为同类等流相互引生。这样就显示六十二见通于不善和有覆无记，属于别境中的慧所摄。

## 第四门　迷谛的通与别

《瑜伽师地论》第五十八卷说："愚夫对苦谛生起二十句萨迦耶见，称为迷苦谛的萨迦耶见。以这种见为依止，对五取蕴见我是断、是常，所以边执见也迷于苦谛。"

依此就显示：边见所摄的四十七见，都迷于苦谛。对于其余三谛，我见等微弱，边见的行相狭窄，不能有这样广泛的分别。

邪见中：

1. 两种无因论，迷集谛而生起。第五十八卷说："怎样迷集谛有八种随眠？就是各种沙门、婆罗门，谤因的邪见。"所以两种无因论迷集谛而生起。
2. 四种有边等论，通迷苦、灭二谛而生起。第五十八卷说："又有各种见，计执边、无边等，这样也称为迷苦谛的邪见，也称为迷灭谛的邪见。"因为迷于有漏、无漏的果。
3. 不死矫乱论，通迷四谛，因为以决定胜道作为所问，迷于四谛而作回答。
4. 五种现法涅槃论，第五十八卷说迷灭谛而生起，因为正是迷于灭谛。

这里所说的，都以行相所迷深远，作为迷谛；只举出各别的行相，不举出总的行相。总的行相的见解，随应思惟而说。这称为第四门，迷谛的相状。

## 第五门　问答分别

这一门只列出十个问题：

1. 这些见中，几种是欲界系，几种是色界系，几种是无色界系？应当从上到下，一一推寻勘定来解释。
2. 为什么遍常论中，只有二十劫乃至八十劫，没有超过这个数或少于这个数的？也没有计执生的？也没有捷疾智的？
3. 一分常论中，为什么没有计执从色界二禅以上殁后来生的？欲界中为什么没有另外两种天以及其余诸趣？
4. 为什么遍常、一分常是常见，就标出"常见"的名称；有想等也是常见，为什么不标出"常见"的名称，而标出"有想"等？
5. 为什么断灭论不计执其余各地以及三恶趣之后的断灭？
6. 为什么无因论不计执其余各地的身等之后有无因？
7. 为什么无色界等以及四根本定的方便定，不计执为涅槃？为什么人、天合为一种涅槃，在断灭论中又分开？
8. 这些见中，几种是在即蕴之我上生起，几种是在离蕴之我上生起？
9. 为什么不说见取、戒禁取，以及我见和其余的邪见，作为六十二见等见解的数目？
10. 为什么只立前际、后际二际，不立现在作为中际？

〔译注：原文第五门只列问题，不作答，体例与他章不同。〕

（《六十二见章》终）
