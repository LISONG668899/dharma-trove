# 迦波离悲行之见

阿阇黎达日卡巴 传　阿阇黎萨尔巴卡 造

## 题解

本篇出自德格版丹珠尔续部（རྒྱུད་འགྲེལ།）ཟི 函第49a叶第3行至第6行，东北目录编号 D2436。全篇十九句，每句七个音节，另有礼敬和跋语。篇幅很短，所以把藏文原文全部保留在代码块中，按段落分开，每段后附汉译，疑难之处另以【按】说明。

梵文题名：Karuṇā-kapāla-caryā-dṛṣṭi-nāma（ཀཱ་རུ་ཎ་ཀ་པཱ་ལ་ཙརྱཿདྲྀཥྚི་ནཱ་མ）。

藏文题名：སྙིང་རྗེ་སྤྱོད་པ་ཐོད་པའི་ལྟ་བ（悲心行颅器之见）。

【按】题名中的“ཐོད་པ”（颅器，梵文 kapāla，音译“迦波离”或“嘎巴拉”），是密乘瑜伽士所持的法器，象征空性。题名大意是“以颅器为象征的悲心之行的见地”。本篇标题依通行译名作“迦波离悲行之见”；跋语中的题名作“སྙིང་རྗེ་ཐོད་པ་སྤྱོད་པའི་ལྟ་བ”，语序稍异，意思相同。

【按】跋语说本篇“由阿阇黎达日卡巴（དྷ་རི་ཀ་པ）传下，阿阇黎萨尔巴卡（སར་བྷ་ཁ）所造”。达日卡巴大概就是八十四大成就者中的 Dārikapa；“萨尔巴卡”或许是八十四大成就者中以贪食著称的 Sarvabhakṣa。这些对应都只是依名字推定。跋语没有记载译者。

## 正文

### 第一段：金柄伞与金刚空行

```
ནམ་མཁར་གསེར་གྱི་ཡུ་བ་ཅན། །གདུགས་སྟེང་མགོ་ལ་འཛིན་ནས་གནས། །རྡོ་རྗེ་མཁའ་འགྲོ་གཤེགས་པར་མཛོད། །
```

在虚空中，（我）把那有黄金伞柄的伞举在头上而安住。金刚空行啊，请您前行！

【按】“གསེར་གྱི་ཡུ་བ་ཅན་གདུགས”，“有黄金伞柄的伞”，在印度是尊贵者的标志。“在虚空中举伞于头上”，可能比喻安住于虚空般的心性中而受庇护；也可能描写瑜伽士的威仪。这是推解。

【按】“རྡོ་རྗེ་མཁའ་འགྲོ་གཤེགས་པར་མཛོད”，“金刚空行请前行”，“གཤེགས་པར་མཛོད”是敬语的祈请，“请您前往”。是向金刚空行祈请前行（引导），还是送别，原文没有说明，这里照字面译出。

### 第二段：达日空行母之子

```
དྷ་རི་མཁའ་འགྲོ་མ་ཡི་སྲས། །ཅི་ཕྱིར་ཞེ་ན་དེ་ཡི་ནི། །དྲིན་གྱིས་རྣལ་འབྱོར་བསམ་པ་གྲུབ། །
```

（我是）达日空行母之子。若问为什么？由于她的恩德，瑜伽士的心愿才得以成就。

【按】“དྷ་རི་མཁའ་འགྲོ་མ་ཡི་སྲས”，“达日空行母之子”，“达日”（དྷ་རི）大概与跋语中的“达日卡巴”（དྷ་རི་ཀ་པ）有关。依藏传成就者传记，八十四大成就者中有一位达日卡巴（Dārikapa），原是国王，后来舍弃王位，侍奉一位妓女（实为空行母）十二年而得成就。“达日空行母之子”，或许是指达日卡巴本人，也或许是指传承中的弟子自称为空行母之子。这里照字面译出，所指不能确定。

### 第三段：空性之碗盛方便之汁

```
སྟོང་ཉིད་ཁམ་ཕོར་ལག་ཏུ་ཐོགས། །ཐབས་ཀྱི་ཁུ་བས་བཀང་བྱས་ནས། །སངས་རྒྱས་ཞིང་དུ་ཕྱིན་ཏེ་གནས། །
```

手中拿着空性的碗，用方便的汁液把它盛满，然后前往佛的刹土而安住。

【按】“སྟོང་ཉིད་ཁམ་ཕོར”，“空性之碗”，与题名中的“ཐོད་པ”（颅器、嘎巴拉）相应：密乘瑜伽士手持颅器，颅器象征空性（智慧），其中所盛的甘露象征方便（大乐）。“以方便的汁液盛满空性之碗”，比喻空性与方便、智慧与大乐双运。

### 第四段：断三有缚，封十门

```
སྲིད་གསུམ་བཅིང་བ་རྩད་ནས་བཅད། །མཁའ་འགྲོ་མ་བརྒྱད་རྟག་ཏུ་བསྲུངས། །སྒོ་བཅུ་དག་ནི་རྒྱ་ཡིས་བཏབ། །
```

从根本上斩断了三有的束缚；八位空行母常时守护；十个门都封上了印。

【按】“མཁའ་འགྲོ་མ་བརྒྱད”，“八空行母”，与前面所译《无二根本修习次第》中的“八瑜伽母”大概是同一类，可能指喜金刚或胜乐坛城中的八位空行母。

【按】“སྒོ་བཅུ་རྒྱ་ཡིས་བཏབ”，“十门封印”，“十门”所指不明，可能是身体的九窍加上顶门梵穴，共为十门；前面所译《自性不成立口诀》中说身体是“一柱九门的殿堂”，可以参看。“封印”可能比喻诸根收摄、气息不外泄。这是推解。

### 第五段：遍一切而为一，无分别则不可说

```
དྷ་རི་ཀ་ནི་སྨྲ་བར་བྱེད། །ཀུན་ལ་ཁྱབ་ཀྱང་གཅིག་གིས་ནི། །དེ་ཡི་མཚན་ཉིད་རྟོག་མེད་ན། །
བདག་གིས་ཇི་ལྟར་བསྟན་པར་བྱས། །
```

达日卡这样说：（它）虽然遍及一切，却只是一；如果它的性相是无分别的，我又怎么能宣说出来呢？

【按】“ཀུན་ལ་ཁྱབ་ཀྱང་གཅིག”，“遍一切而为一”，意思可能是：心性遍及一切显现，而本身唯一无二。“它的性相无分别，我怎能宣说”，表示心性超越言说，与前面所译《降伏心分别之见》中“心的体验谁也说不出”的意思相同。“它”所指，原文没有明说。

### 第六段：心愿如意成就

```
དྷ་རི་མཁའ་འགྲོ་མ་ཡི་སྲས། །ཅི་ཕྱིར་ཞེ་ན་དེ་ཡི་ནི། །བསམ་པ་ཡིད་བཞིན་འགྲུབ་པར་འགྱུར། །
```

（我是）达日空行母之子。若问为什么？由于她（的恩德），心愿就能如意成就。

【按】这三句与第二段首尾呼应，表示一切成就都来自空行母（智慧）的恩德。

## 跋语

སྙིང་རྗེ་ཐོད་པ་སྤྱོད་པའི་ལྟ་བ་ཞེས་བྱ་བ་སློབ་དཔོན་དྷ་རི་ཀ་པ་ནས་བརྒྱུད་པ་སློབ་དཔོན་སར་བྷ་ཁས་མཛད་པ་རྫོགས་སོ།། །

名为《悲心颅器之行的见地》，由阿阇黎达日卡巴传下，阿阇黎萨尔巴卡所造，圆满。
