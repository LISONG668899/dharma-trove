本篇要目：一、第三十颂：究竟位　二、无漏界　三、佛的身土是否属于蕴处界　四、不思议、善、常、安乐　五、解脱身与法身　六、三身　七、五法如何摄三身　八、三身的差别与自利利他　九、三身所依的佛土　十、诸佛身土的共与不共　十一、身土的性质与“唯识”的深意　十二、论名与回向

一、第三十颂：究竟位

外人质问：最后的究竟位，相状是怎样的？世亲菩萨用颂回答：

```
此即无漏界　不思议善常
安乐解脱身　大牟尼名法
```

大意：二种转依果就是无漏界，不可思议，是善，是常，是安乐；二乘所得称为解脱身，大牟尼佛所得称为法身。

二、无漏界

论中解释：前面修习位所得的转依，应知就是究竟位的相状。颂中的“此”，是指前面所说的大涅槃和大菩提二种转依果，就是究竟的无漏界所摄。

一切漏永远断尽，不是漏所随增的，体性清净，圆满明亮，所以称为无漏。

“界”是藏的意思，因为无漏界中含容无边稀有的大功德。或者，“界”是因的意思，因为能生起五乘世间与出世间的利乐之事。

外人质问：清净法界可以说只属于无漏，四智心品怎能只属于无漏？

论主回答：四智心品属于道谛，所以只属于无漏。佛的功德和身土等，都是无漏种性所生，因为有漏法的种子已永远舍弃。佛示现生死之身、业和烦恼等，似苦谛和集谛，实际上是无漏，属于道谛。

三、佛的身土是否属于蕴处界

外人质问：《集论》等说十五界等只是有漏，如来难道没有五根、五识、五外界等？论中列出三家。

第一家认为：如来的功德和身土甚深微妙，非有非无，远离一切分别，断绝一切戏论，不属于界、处等法门，所以与《集论》的说法在道理上不相违。

第二家认为：如来的五根和五境，由妙定所生，属于法界所摄的色。非佛者的五识依如来的五根五境而变现，粗细不同，所以如来的五根五境不属于五境。如来的五识，不属于五识界，因为经中说佛心恒常在定中，论中说五识的体性是散乱的。

外人质问：成所作智与哪一识相应？第二家回答：与第六识相应，因为成所作智起变化的作用。

外人质问：成所作智与妙观察智的体性有什么区别？第二家回答：妙观察智观察诸法的自相共相等，成所作智只起变化，所以有区别。

外人质问：两种智品就应不同时生起，因为同一类的两个识不同时俱起？第二家回答：承认两种智不同时生起，在道理上没有违背；或者同一体而作用分为二，同时俱起也没有过失。

或者，成所作智与清净的第七识相应，依眼等根，缘取色等境，是平等性智的作用差别：清净的第七识生起他受用身土之相的，属于平等性智品；生起变化身土的，属于成所作智品。

外人质问：成所作智品难道不是转五识而得？第二家回答：转某识而得，体并不就是某识。如同说转生死而得涅槃，不能说涅槃与生死同属一类。所以对此不应责难。

第三家，即护法论师，认为：如来的功德和身土，随其所应，摄在蕴、处、界中，因为蕴、处、界三者都通于有漏和无漏。《集论》等说十五界等只是有漏，是依二乘粗浅的境界而说，不是说一切。其余人所成就的十八界中，只有后三界，即意界、法界、意识界，通于无漏。佛所成就的十八界都是无漏，不是二乘所知的境界。

其余地方说佛的功德等不是界等，是因为不同于二乘劣智所知的界等之相。道理必定如此。原因如下：经中说一切有为法都属于蕴；经中说一切法都属于界和处；十九界等是圣者所遮止的。如果断绝戏论就不是界等，也不应说佛是无漏界、善、常、安乐、解脱身等。经中处处说转无常之蕴，获得常住之蕴；界和处也是如此。怎能说如来不是蕴处界？所以说“不是”，是密意之说。

论中说五识的体性散乱，是说其余人所成就的五识，不是佛所成就的。所以佛身中十八界等都具足，而纯是无漏。

【译注】护法论师的立场：佛不是脱离一切法另成一个不可说的东西；佛的身心仍有十八界的结构，全部转为无漏。成佛不是什么都没有了，是一切都清净了。

四、不思议、善、常、安乐

二种转依果，又是不可思议，因为超过寻思和言议的道路；微妙甚深，是自己内证的；不是一切世间譬喻所能比喻的。

又是善，因为是白净法的体性。清净法界远离生灭，极为安稳；四智心品妙用无方，极为巧便。两种转依果都有顺益的相，违背不善，所以都说为善。

外人质问：论中说处等八界只是无记，如来难道没有五根和三境？论主回答：此处有三种解释，广说如前。一切如来的身土等法，都属于灭谛和道谛，所以只是善，因为圣教说灭谛和道谛只是善性，说佛土等不是苦谛和集谛。佛识所变现的有漏、不善、无记之相等，都从无漏善种所生，属于无漏善。

又是常，因为没有穷尽的时候。清净法界无生无灭，体性没有变易，所以说为常。四智心品所依的清净法界是常，四智心品又没有断尽，所以也说为常。四智心品不是自性常，因为从因而生，有生的必定归于灭，是一向可以记别的，没有见过色法心法不是无常的。四智品由于本愿力，所化的有情没有尽期，所以穷尽未来际，无断无尽。

【译注】两种“常”：真如是自性常，本来不生不灭；四智是相续常，有生灭，刹那相续，因悲愿无尽而永不断绝。论主分得很清楚，不把有为的佛智说成不生不灭。

又是安乐，因为没有逼迫苦恼。清净法界一切相寂静，所以称为安乐。四智心品永远远离恼害，所以称为安乐。两种转依果的自性都没有逼恼，又能安乐一切有情，所以两种转依都称为安乐。

五、解脱身与法身

二乘所得的两种转依果，只是永远远离烦恼障的系缚，没有殊胜的功德法，所以只称为解脱身。

大觉世尊成就无上的寂默之法，所以称为大牟尼。大牟尼尊所得的两种转依果，永远远离二障，也称为法身，因为由无量无边的力、无畏等大功德法所庄严。“身”是体、依、聚的意思，总说称为身。

法身以五法为体性：清净法界与四智心品。并不是只有清净法界称为法身，因为两种转依果都属于法身。

【译注】“牟尼”意为寂默。“身”有三义：体，是本体；依，是功德所依；聚，是功德的积聚。

六、三身

法身有三种相的差别。

第一是自性身，就是一切如来真实清净的法界，是受用身和变化身平等的所依，离相寂然，断绝一切戏论，具足无边真实常住的功德，是一切法平等的真实性。自性身也称为法身，因为是大功德法的所依止。

第二是受用身，受用身有两种。

一是自受用身，就是一切如来在三无数劫中修集无量的福德与智慧资粮，所生起的无边真实功德，以及极其圆满清净、常住周遍的色身，相续湛然，穷尽未来际，恒常自己受用广大的法乐。

二是他受用身，就是一切如来由平等性智，示现微妙清净的功德之身，居于纯净的国土，为住于十地的诸菩萨众，现大神通，转正法轮，决断众人的疑网，令十地菩萨受用大乘的法乐。

自受用身与他受用身合称为受用身。

第三是变化身，就是一切如来由成所作智，变现无量随类的化身，居于净土或秽土，为未登地的诸菩萨众、二乘和凡夫，相称各自的根机，显现神通，说法，令各自获得种种利乐之事。

七、五法如何摄三身

关于清净法界与四智如何摄三身，论中列出两家。

第一家认为：清净法界和大圆镜智摄自性身。因为经中说真如是法身；论中说转去阿赖耶识得自性身，大圆镜智品是转去藏识而证得的。平等性智和妙观察智两种智品摄受用身。因为经中说平等性智在纯净土为诸菩萨现佛身；经中说妙观察智在大集会中说法断疑，显现自在；经中说转诸转识得受用身。成所作智品摄变化身，因为经中说成所作智在十方国土显现无量种难思的变化。又如“智殊胜”中具摄三身，可知三身都有真实的智。

第二家，即护法论师，认为：只有清净法界摄自性身。因为经中说自性身本性常住；说佛的法身无生无灭；说法身由证因而得，不是由生因而得；又说法身是诸佛共有，遍于一切法，如同虚空，无相无为，不是色法也不是心法。

论中说转去藏识而得自性身，是说由转灭第八识中二障的粗重，显现法身。“智殊胜”中说法身，是因为法身是诸智的依止，是诸智的真实性。自性法身有真实无边的功德，因为是无为，所以不可说为色法心法等物。

四智品中真实的功德，以及大圆镜智所起的常住周遍的色身，摄自受用身。平等性智品所现的佛身，摄他受用身。成所作智品所现的随类种种身相，摄变化身。

经中说大圆镜智是受用佛，因为转诸转识得受用身。转藏识也得受用身；经中说转藏识，是为了显示法身，所以对得受用身略而不说。

经中又说法身无生无灭，只由证因而得，不是色法心法等；大圆镜智品与此相违，如果不是受用身，属于哪一身？受用身摄佛不共的有为真实功德，所以四智品中实有的色法和心法，都属于受用身。

他受用身和变化身，都是为了教化他人而方便示现，所以不可说以真实的智为体。经中说化身属于“智殊胜”，是因为化身显现得似智，或者是智所生起的，假说为智，体实际上不是智。经中只说平等性智和成所作智能显现受用身和变化身的三业，没有说二身就是二智，所以二智属于自受用身。

变化身和他受用身，没有真实的心王和心所，有化现出来的心王心所法。无上觉者的神力难以思议，所以能化现没有形质的法。不然的话，如来怎能显现贪瞋等？因为贪瞋等早已断除。声闻和畜生等怎能知道如来的心？因为如来真实的心，等觉菩萨尚且不知。由此经中说：化现无量种类，都令有心。又说：如来的成所作智化作三业。又说：变化身有依他的心，因为依他人真实之心的相分而显现。论中说变化身没有根和心等，是依其余的变化而说，不是依如来。化现的色根和心王心所法，没有根等的作用，所以不说有。

【译注】护法论师的三身观要点：自性身是无为的真如，不是智；自受用身是佛真实的四智和色身；他受用身与变化身是为度化众生而示现的，有化现的心，没有真实的心。

八、三身的差别与自利利他

三身都具足无边功德，又各有不同。

自性身只有真实的常、乐、我、净，远离一切杂染，是众善的所依，是无为的功德，没有色法心法等差别的相和作用。

自受用身具有无量种微妙的色法心法等真实功德。

他受用身和变化身，只具有无边似色法心法等、利乐他人的作用与化相的功德。

自性身正属于自利，因为寂静安乐，没有动作；也兼属利他，因为作为增上缘，令一切有情得到利乐。自性身又作为受用身和变化身的所依止，所以属于自利利他两种。

自受用身只属于自利。他受用身和变化身只属于利他，因为是为他人而显现。

九、三身所依的佛土

自性身依于法性土。自性身与法性土的体没有差别，依属于佛与属于法，相与性有不同。自性身与法性土都不属于色法。不可说形量的大小，随着事相，量是无边的，譬如虚空，遍一切处。

自受用身依于自受用土。与大圆镜智相应的清净识，由于过去所修自利的无漏纯净佛土因缘成熟，从初成佛直到未来际，相续变现为纯净的佛土，周遍圆满，没有边际，众宝庄严，自受用身恒常依之而住。如同净土的量，身量也是如此。诸根和相好，每一种都无边，因为由无限的善根所引生。功德与智慧不是色法，不可说形量的大小；依所证的真如和所依的身，也可以说遍一切处。

他受用身也依于自己所变的国土。由平等性智的大慈悲力，由于过去所修利他的无漏纯净佛土因缘成熟，随着住于十地菩萨的所宜，变现为净土，或小或大，或劣或胜，前后改转，他受用身依之而住。能依的身量也没有一定的限度。

变化身依于变化土。由成所作智的大慈悲力，由于过去所修利他的无漏净秽佛土因缘成熟，随着未登地有情的所宜，化现为佛土，或净或秽，或小或大，前后改转，佛的变化身依之而住。能依的身量也没有一定的限度。

十、诸佛身土的共与不共

自性身和法性土，一切如来所证相同，所以体没有差别。

自受用身及所依的国土，一切佛各自变现，各不相同，又都无边无际，互不障碍。

他受用身和变化身及所依的国土，随着诸如来所化的有情，有共与不共。

所化的有情如果是共同的，在同一处所、同一时间，诸佛各自变现，作为身和土，形状相似，互不障碍，展转相杂，作为增上缘，令所化的众生自己的识变现出来，就是在一个国土中有一尊佛身，为众生显现神通、说法饶益。对于不共的众生，只有一尊佛变现。

一切有情从无始以来，种性法尔互相系属，或者多个有情属于一尊佛，或者一个有情属于多尊佛，所以所化的众生有共与不共。不然的话，多尊佛长久住世，各自辛勤劳苦，实在没有益处，因为一尊佛就能利益一切众生。

【译注】众生见到的佛身佛土，最终仍是“令所化生自识变现”：诸佛的变现只是增上缘，众生要以自己的识变现出佛的影像，才得见佛。唯识的道理，一直贯彻到见佛闻法。

十一、身土的性质与“唯识”的深意

一切身土，无论净或秽，在无漏识上所变现的，与能变的识同样是善和无漏，因为由纯善无漏的因缘所生，属于道谛，不属于苦谛和集谛。所变现的蕴等之相，不一定都与识相同，因为由识、根、境三法的因缘交杂引生。

在有漏识上所变现的，与能变的识同样都是有漏，因为纯由有漏的因缘所生，属于苦谛和集谛，不属于灭谛和道谛。所变现的善等之相，不一定都与识相同，因为由三性的因缘交杂引生。蕴等的同异，可以依此类推。否则，就不应有五十二等的分别。

【译注】“五十二等”一语，《述记》有专释，此处存疑不强解。大意是：所变的相分在蕴处界、三性的分类上不必与能变的识相同，否则种种法的分类就无从安立。

相分等依识而变现，不像识的体性在依他起中是实有；否则唯识的道理就不能成立，因为承认识与内境都是实有。

或者，识所变的相分、见分等，从缘而生，都是依他起，虚实如同识。“唯”字只遣除心外之境，不遮除心内之境；否则真如也应不是实有。

外人质问：内境与识既然都不是虚假的，为什么只说“唯识”，不说“唯境”？

论主回答：识只在内，境通于内外，恐怕与外境混淆，所以只说唯识。

```
或诸愚夫迷执于境，起烦恼业，生死沉沦，
不解观心，勤求出离；
哀愍彼故，说唯识言，令自观心，解脱生死，
非谓内境如外都无。
```

大意：或者，因为一切愚夫迷惑执着外境，生起烦恼，造作恶业，在生死中沉沦，不懂得回观自心，勤求出离；佛哀愍愚夫，所以说“唯识”，令愚夫自己观心，解脱生死，并不是说心内之境也如同心外之境一样完全没有。

【译注】“哀愍彼故”一段是全论最温暖的一句：“唯识”不是一个用来争胜的哲学命题，是佛为沉沦生死的众生指出的一条回头路，教人不再向外追逐，回过头来观照自心。

或者，相分等都以识为体性，由于熏习的力量，显现得似多个部分而生起。真如也是识的真实性。所以除了识性，没有别的法。

“唯识”的“识”也包括心所，因为心王与心所决定相应。

十二、论名与回向

《成唯识论》以三分成立唯识，所以称为《成唯识论》。也称为《净唯识论》，显示唯识的道理极其明净。

本论称为《唯识三十》，因为由三十首颂显示唯识的道理，才得圆满，不增不减。

```
已依圣教及正理　分别唯识性相义
所获功德施群生　愿共速登无上觉
```

大意：已经依据圣教和正理，分别解说唯识的性与相的意义；所获得的功德布施给一切众生，愿大家一同迅速登上无上的觉悟。
