# 道歌宝藏（毗瓦巴）

瑜伽自在毗瓦巴（Virūpa）造　据藏文译出

## 题解

《道歌宝藏》（梵 Dohakoṣa，藏 do ha mdzod）收于德格版丹珠尔续部释 ཞི 函第 134a 至 136a 页（东北目录 D2280），紧接在圣天《无分别开示》（D2279）之后。跋语说是"瑜伽自在毗瓦巴"所造，由印度亲教师吉祥毗卢遮那（Śrī Vairocana，即毗卢遮那金刚 Vairocanavajra）"自译"为藏文；篇末又记传承：毗瓦巴、黑行者（nag po pa）、阿阇黎声师足（sgra mkhan zhabs）、阿阇黎布罗巴（pu ra pa）、吉祥毗卢遮那。

毗瓦巴是印度八十四大成就者之一，以道果法（lam 'bras）的祖师而著称，在萨迦派中地位极高。本篇是他名下的道歌，共约一百三十句，全篇围绕"大手印"展开：

一、大手印的本体：三有与寂灭本来清净如虚空，离一切言诠、譬喻、边见，连"非"也不是；一切名言只是假立，如兔角的锐钝；心性名空、离戏，就是大手印；众生都是大手印的化现，苦乐等二现都是大手印的游戏。

二、破斥偏差：有人以灌顶自苦，有人念"吽呸"数念珠，有人吃粪尿血精肉，有人修脉气瑜伽，都是迷乱；名声、博学、好的觉受、悉地与加持的征相，都是造作之道，是垢染。

三、修持的要点：依上师而证悟本然的实相；不作意、不分别有无，在不散乱的本然中安住；连"空性""无生""离边"也不作意，否则就是大散乱；在空与不空都不计较的松坦状态中，像起尸那样无取无舍。

四、行持与果：逆缘就是最殊胜的悉地，像以鞭策良马；行持要配合见地，"即使见地高如虚空，取舍因果细如面粉"一类的告诫在这里也有，如：即使不畏轮回，也要谨慎微细的恶业；即使证悟无自他，也要在世俗中利益众生；即使不依其他导师，也要把恩师顶戴在头上。最后说一切都是假名，连"大手印""法界"之名也是如此。

本篇的用语，如"本然"（gnyug ma）、"不造作"（ma bcos）、"自地解脱"（rang sar grol）、"大通彻"（zang thal chen po）、"觉性清净于基"（rig pa gzhi la dag）、"松坦"（lhug pa）等，与后期藏地大手印、大圆满著作的用语非常相近；而毗卢遮那金刚是十二世纪来藏的印度上师，本篇又是他"自译"的，所以本篇的成文年代与形成背景，学界有不同的看法。这里只照原文译出。

**与前译的关系：**本篇破斥灌顶、念诵、外道苦行的部分，与萨惹哈《国王道歌》《民众道歌》的风格一脉相承；"即使证悟……也要……"一组告诫，与《四偈半》对"以证悟为足"的破斥意思一致。本篇以前没有译过。

体例：本篇是偈颂体，依本译对短篇的体例，按意义单元把藏文原文列于代码块中，再以完整的意义单元译出；为了便于理解而补的字，都放在方括号中。各节标题为译者所加。原文含混或可有两解之处，以"【按】"说明，不妄补内容。文末附通篇连读。

【按】"无我母"（bdag med ma，Nairātmyā），是喜金刚的佛母，道果法所依的根本续就是《喜金刚续》，所以毗瓦巴的道歌以礼敬无我母开篇。"唉玛吙"（e ma ho），是表示惊叹、稀有的感叹词。

## 一、大手印离言离边（第 9–19 句）

```
སྲིད་དང་ཞི་བ་ཕྱག་རྒྱ་ཆེན་པོ་ནི། །
ངོ་བོ་ཉིད་ཀྱིས་མཁའ་ལྟར་རྣམ་པར་དག །
མཚོན་བྱའི་གནས་ལུགས་མེད་པས་ཐ་སྙད་ཚིག་ལམ་ཆད། །
རང་བཞིན་སྤྲོས་མེད་ངོ་བོ་ལྟོས་ཆོས་ཀུན་དང་བྲལ། །
བརྟག་དང་དཔྱད་དུ་མེད་ཅིང་མཚོན་པའི་དཔེ་དང་བྲལ། །
དཔེ་བྲལ་ཉིད་ལའང་མི་གནས་བློ་ཡི་ཡུལ་ལས་འདས། །
```

三有与寂灭——大手印，本性就像虚空一样清净；因为没有可被指示的实相，名言与言语之道都断了。自性离戏，本体远离一切相对之法；不可推求，不可观察，远离能指示的譬喻；连"离譬喻"也不住，超越了心识的境界。

```
རྟག་མིན་ཆད་མིན་འཁོར་དང་མྱ་ངན་འདས་པ་མིན། །
སྣང་མིན་སྟོང་མིན་དངོས་དང་དངོས་མེད་སྐྱེ་མེད་མིན། །
ཆོས་ཉིད་གཉུག་མ་མ་ཡིན་བློ་ལས་འདས་པའང་མིན། །
མིན་པའང་མིན་ཞིང་ཡིན་མིན་བློ་ཡིས་བརྗོད་མེད་ཕྱིར། །
གཉིས་ཆོས་གང་དང་འབྲེལ་མེད་གཟོད་ནས་མཉམ་པ་ཉིད། །
```

不是常，不是断，不是轮回，也不是涅槃；不是显现，不是空，不是有，不是无，也不是无生；不是本然的法性，也不是"超越心识"；连"不是"也不是，因为"是"与"不是"都不是心识所能言说的；与任何二元之法都没有关联，从本以来就是平等性。

【按】这两组偈颂以层层遮遣的方式开示大手印：不但遮遣常断、轮涅、显空、有无，连"无生""本然的法性""超越心识"这些正面的描述也一并遮遣，最后连"不是"本身也遮遣掉。这与梅纪巴《真如十颂》"离有无之结合"、《真如十颂广释》"连离四边也不执"的意思一致。

## 二、一切名言如兔角（第 20–26 句）

```
ངོ་བོ་ངེས་ཚིག་བྱེད་པའི་ལས་རྣམས་བཤད་པ་ཡང་། །
རི་བོང་རྭ་རྫུན་དེ་ཡི་རྣོ་རྟུལ་རྫུན་དང་མཚུངས། །
ཆོས་རྣམས་ཐམས་ཅད་མཚན་ཉིད་དེ་དང་ཁྱད་པར་མེད། །
```

对［大手印的］本体、词义、作用所作的种种解说，就像兔角是虚假的，说它锐利或钝也是虚假的一样。一切法都与那体相没有差别。

```
ཇི་ལྟར་སྣང་ཞིང་སྲིད་པའི་ཀུན་རྫོབ་ཆོས་ཅན་རྣམས། །
ངོ་བོ་ཉིད་མེད་མིང་ཙམ་སྒྲ་ཙམ་བཏགས་པ་ཙམ། །
མིང་དང་དོན་ལ་ཁྱད་པར་བྱེ་བྲག་ཅུང་ཟད་མེད། །
གདོད་ནས་ལྷན་ཅིག་སྐྱེས་པས་གཞན་ནས་བཙལ་དུ་མེད། །
```

如此显现于三有中的一切世俗有法，都没有自性，只是名、只是声、只是假立；名与义之间，没有一点点差别。［它们］从本以来就是俱生的，所以不要到别处去寻求。

【按】"兔角的锐钝"，是说兔角本来不存在，讨论它锐利或钝都是虚妄；同样，大手印本来离言，对它所作的种种定义、解释，都是对不存在之物的描述。"名与义之间没有差别"，是说事物与它的名称同样都是假立的。"从本以来就是俱生的，所以不要到别处去寻求"，是大手印"俱生即是"的要点。

## 三、心性即大手印（第 27–33 句）

```
སེམས་ཉིད་མིང་སྟོང་སྤྲོས་བྲལ་ཕྱག་རྒྱ་ཆེན་པོ་སྟེ། །
ནམ་མཁའ་རང་བཞིན་གདོད་ནས་མིང་སྟོང་ཡིན་དང་མཚུངས། །
ངོ་བོ་ཉིད་ཀྱིས་མ་སྐྱེས་མཚན་མའི་སྤྲོས་དང་བྲལ། །
མཁའ་ལྟར་ཀུན་ལ་ཁྱབ་ཅིང་འཕོ་དང་འགྱུར་བ་མེད། །
དུས་རྣམས་ཀུན་དུ་སྟོང་ཞིང་ཡེ་ནས་བདག་མེད་དེ། །
དྲན་རྟོག་མཚན་མ་མེད་དེ་སྨིག་རྒྱུའི་ཆུ་བོ་ལྟར། །
མ་བཅིང་མ་གྲོལ་གཉུག་མའི་ངང་ལས་མ་གཡོས་སོ། །
```

心性名空、离戏，就是大手印，就像虚空的自性从本以来就是名空的一样。本性不生，远离相的戏论；像虚空一样遍于一切，没有迁移与变化；在一切时中都是空，从本以来就是无我；没有忆念、分别与相，就像阳焰之河；不被束缚，也没有解脱，从本然的状态中从未动摇。

【按】"名空"（ming stong），意思是只有名称而无实体，即"仅有名称的空"。"不被束缚，也没有解脱"（ma bcing ma grol），是说心性本来不曾被束缚，所以也无所谓解脱，这是大手印、大圆满常说的"本来解脱"。

## 四、众生与苦乐都是大手印的游戏（第 34–39 句）

```
སེམས་ཅན་ཐམས་ཅད་ཕྱག་རྒྱ་ཆེན་པོའི་སྤྲུལ་པ་ལ། །
སྤྲུལ་པའི་ངོ་བོ་ཡེ་ནས་སྐྱེ་མེད་ཆོས་ཀྱི་དབྱིངས། །
བདེ་སྡུག་ལ་སོགས་གཉིས་སྣང་མཚན་མ་ཐམས་ཅད་ཀྱང་། །
ཆོས་ཉིད་གཉུག་མ་ཕྱག་རྒྱ་ཆེན་པོའི་རོལ་པའོ། །
རོལ་པ་ཉིད་ལ་བདེན་མེད་མི་བརྟན་འགྱུར་བའི་ཕྱིར། །
གནས་ལུགས་སྟོང་པའི་རྒྱ་ལས་ནམ་ཡང་མ་འདས་སོ། །
```

一切众生都是大手印的化现，而化现的本体，从本以来就是不生的法界。苦乐等二现的一切相，也都是本然法性——大手印的游戏。游戏本身因为不真实、不坚固、会变化，所以从来没有超出实相——空性之印。

【按】"游戏"（rol pa），指心性自然的显现、妙用。"空性之印"，藏文作"སྟོང་པའི་རྒྱ"，"rgya"可以是"印"（phyag rgya 的 rgya），也可以是"范围、界限"，两种读法意思都是：一切显现都不超出空性，存疑。

## 五、种种迷乱的修法（第 40–43 句）

```
ཁ་ཅིག་དབང་བསྐུར་བ་ཡིས་ཡོངས་སུ་གདུང་བར་བྱེད། །
ཁ་ཅིག་ཧཱུཾ་ཕཊ་ཟེར་ཞིང་ཕྲེང་བ་ཡོངས་སུ་བགྲང་། །
ཁ་ཅིག་བཤང་གཅི་ཁྲག་དང་ཁུ་བ་ཤ་རྣམས་ཟ། །
ཁ་ཅིག་རྩ་དང་རླུང་གི་རྣལ་འབྱོར་བསྒོམ་སྟེ་ཡོངས་སུ་འཁྲུལ། །
```

有人以灌顶使自己受尽煎熬；有人口念"吽呸"，一遍遍数着念珠；有人吃粪、尿、血、精与肉；有人修习脉与风的瑜伽——都完全迷乱了。

【按】这一偈与萨惹哈《民众道歌》等批评外道与佛教中种种执著形式的修法的偈颂风格相同。这里所批评的，不是灌顶、念诵、圆满次第本身，而是把它们当作究竟、执著外在形式而不认识心性的做法。"吃粪、尿、血、精与肉"，是指某些密乘行者以"五甘露"等为修法而执著其形式，这也是被批评的对象。

## 六、依上师证悟本然实相（第 44–54 句）

```
ཨེ་མ་ཧོ། །
བླ་མ་དམ་པས་ཟིན་པས་ཅིག་ཤོས་འདི་ལྟར་རྟོགས། །
གང་ཡང་འཁྲུལ་པ་ཡིན་ཕྱིར་ཡང་དག་རྟོགས་པ་མེད། །
རྟོགས་བྱ་རྟོགས་བྱེད་མེད་པས་ཕྱོགས་རིས་མཐའ་དང་བྲལ། །
བྲལ་དང་མ་བྲལ་མེད་པས་མཉམ་ཉིད་གཉུག་མའི་ངང་། །
འདི་ལྟར་རྟོགས་ན་ངེས་པར་གཞན་དུ་དྲི་ས་མེད། །
```

唉玛吙！被殊胜上师摄受的另一种人，是这样证悟的：因为凡是［所修的］都是迷乱，所以［其中］没有真正的证悟；因为没有所证与能证，所以远离偏执与边见；因为没有远离与不远离，所以［安住于］平等性的本然状态。若这样证悟，一定不必再到别处去探问。

```
སྣ་ཚོགས་ཆོས་སྐུར་གསལ་བས་སྤོང་ལེན་སེམས་མི་འབྱུང་། །
བསྒོམ་དང་མི་བསྒོམ་མེད་ཅིང་མཚན་མས་གོས་པ་མེད། །
སྣང་དང་མི་སྣང་ཡུལ་ལ་ནམ་ཡང་བརྟེན་མི་བྱེད། །
བྱ་དང་བྱེད་པའི་སེམས་མེད་དམིགས་པ་ཀུན་དང་བྲལ། །
རེ་དང་དོག་པའི་སེམས་མེད་ཀུན་ལ་ཞེན་པ་ལོག །
```

种种［显现］明现为法身，所以不生起取舍之心；没有修与不修，也不被相所染；对于显现与不显现的对境，从来都不依靠；没有作者与所作之心，远离一切所缘；没有希望与恐惧之心，对一切的贪著都已返离。

【按】"另一种人"（cig shos），与上一节"有人……有人……"相对，指被殊胜上师摄受、真正证悟的人。"种种明现为法身"，是大手印"显现即法身"的要点。

## 七、自解脱与无垢（第 55–62 句）

```
བླ་མས་བསྟན་པས་གཉུག་མའི་གནས་ལུགས་རྟོགས་གྱུར་ན། །
དྲན་རིག་སྣ་ཚོགས་ཆོས་ཀྱི་དབྱིངས་སུ་རང་རླག་སྟེ། །
རྣམ་ཤེས་ཡུལ་ལ་མི་གནས་ཆགས་ཞེན་ཀུན་བྲལ་བས། །
མ་བཅོས་གཉུག་མའི་ངང་དུ་ཆོས་ཀུན་གྲོལ་བར་འགྱུར། །
```

若依上师的开示而证悟了本然的实相，种种的念头与觉知，都自己消融于法界之中；识不住于对境，远离一切贪著，所以在不造作的本然状态中，一切法都得解脱。

```
ཀུན་ལ་མ་ཆགས་ང་རྒྱལ་ལ་སོགས་དྲི་མ་བྲལ། །
གུས་པར་ལྡན་ཞིང་དམ་པས་ཡོངས་སུ་ཟིན་པ་དང་། །
གང་ཡང་ཡིད་བྱེད་བྲལ་ན་དྲི་མེད་ཐེ་ཚོམ་མེད། །
ཤེས་དང་ཤེས་བྱ་དག་པས་ཆོས་ཉིད་མངོན་སུམ་འཆར། །
```

对一切都不贪著，远离我慢等垢染；具足恭敬，又被殊胜者完全摄受；若远离任何作意，就是无垢的，对此没有怀疑；能知与所知清净了，法性就现前显现。

【按】"自己消融"，藏文作"རང་རླག"，字面是"自己失去、自己消失"，这里译为"自己消融"。"远离任何作意"，与梅纪巴"不作意"的宗旨一致。

## 八、不证悟的过患与造作之道（第 63–70 句）

```
གཉུག་མ་ཕྱག་རྒྱ་ཆེན་པོ་རྟོགས་པར་མ་གྱུར་ན། །
རྟག་ཏུ་གཉིས་འཛིན་དབང་གིས་ཀུན་ལ་ཞེན་གྱུར་པས། །
བསམ་རིག་རབ་རིབ་སྣ་ཚོགས་རྒྱུན་དུ་སྐྱེ་འགྱུར་ཞིང་། །
མ་ནོར་དོན་ལ་མི་གནས་སྲིད་པར་འཁོར་ཞིང་འཁྱམ། །
```

若没有证悟本然的大手印，就会因为二取的力量而恒常对一切贪著；种种如眼翳般的念头与觉知就会相续不断地生起，不住于无误之义，在三有中轮转流浪。

```
སྙན་གྲགས་བསྙེན་བཀུར་ཀུན་ལ་ཆགས་ཞིང་ཞེན་པ་དང་། །
ཐོས་བསམ་གོ་རྟོགས་ཆེ་དང་ཉམས་མྱོང་བཟང་པོ་དང་། །
དངོས་གྲུབ་བྱིན་རླབས་ནུས་པའི་རྟགས་བྱུང་བཅོས་མའི་ལམ། །
དོན་གྱིས་དྲི་མ་ཡིན་ཕྱིར་མཁས་པས་ཡིད་མི་གཏད། །
```

对名声、恭敬的贪著与执著，广大的闻思理解、好的觉受，以及悉地、加持、能力的征相出现——这些都是造作之道，实际上都是垢染，所以智者不会把心寄托在上面。

【按】这一偈是大手印传承中非常重要的告诫：博学、好的觉受（nyams）、神通与加持的征相，都不是证悟本身，执著它们就是"造作之道"。这与《无分别开示》第四偈"禅悦也只是遍计"的意思一致。

## 九、观心之山，不作意而安住（第 71–77 句）

```
དེ་ཉིད་ཡིད་ལ་བྱེད་ཅིང་གཉིས་མཐའི་ཕྱོགས་ལྷུང་ན། །
འཁོར་བར་འཁོར་ཞིང་སྲིད་པའི་རྩ་བ་ཡིན་པའི་ཕྱིར། །
ཀུན་གྱི་གཞི་རྩ་ཡིད་ཀྱི་རི་བོ་གང་ཡིན་ལྟོས། །
བལྟས་པས་མ་མཐོང་ཡིད་དང་བྲལ་ན་ངེས་པར་གྲོལ། །
```

若作意于那［真性］本身，而落入二边之一，那就是在轮回中轮转，因为［它］是三有的根本。要看那一切的根基——心之山是什么！看了而没有见到，若远离了心意，就一定解脱。

```
སེམས་ཀྱིས་ཆོས་ཀྱི་དབྱིངས་ལ་འདི་ཞེས་མེད་པས་ན། །
དེ་ལ་སྒོམ་དང་བསྒོམ་པར་བྱ་བ་གཉིས་སུ་མེད། །
ཡོད་མེད་ཅིར་ཡང་མི་རྟོག་མ་ཡེངས་ངང་ལ་ཞོག །
```

因为心对于法界，没有"这个"可言，所以在那里，没有能修与所修二者。不要分别为有或无，安住在不散乱的状态中。

【按】"心之山"（yid kyi ri bo），比喻心的念头如山一样坚固地被执为实有，要直接去观察它。"看了而没有见到"（bltas pas ma mthong），是大手印"观心而不见心"的要点，即在观察中发现心无实体可得，这本身就是见到心性。

## 十、松坦安住，如起尸（第 78–83 句）

```
སྟོང་པ་ཉིད་དང་སྐྱེ་མེད་བློ་ལས་འདས་པ་དང་། །
མཐའ་བྲལ་ལ་སོགས་གང་ཡང་ཡིད་ལ་བྱེད་པ་ན། །
གནས་ལུགས་དོན་ལ་མི་གནས་ཤིན་ཏུ་ཡེངས་པའོ། །
སྟོང་དང་མི་སྟོང་རྩིས་མེད་ལྷུག་པའི་ངང་ལ་ཞོག །
གཞག་དང་མི་གཞག་མེད་པར་རང་དགའ་ཡན་པར་ཐོང་། །
བཏང་དང་བཟུང་བའི་སེམས་མེད་རོ་ལངས་ཇི་བཞིན་གྱིས། །
```

若作意于空性、无生、超越心识、离边等等任何［概念］，就不住于实相之义，是极大的散乱。

在不计较空与不空的松坦状态中安住；没有安住与不安住，自在地放任它；没有放下与执持之心，就像起尸一样。

【按】"连空性、无生、离边也不作意"，与《真如十颂广释》第三十节"观察真如、对治、果的分别，本身也要遍知为光明"、《入无分别陀罗尼》舍弃四相的意思相通。"松坦"（lhug pa），是放松、不紧绷的状态。"起尸"（ro langs），是印度传说中被咒术唤起的尸体，没有自己的意志与取舍，这里比喻修行人没有放下与执持的造作之心，存疑。

## 十一、安住与不安住的差别；眼翳之喻（第 84–89 句）

```
དེ་ཉིད་གནས་ལུགས་རིག་ནས་དེ་ཡི་ངང་གནས་ན། །
གཉིས་སྣང་མཚན་མའི་བག་ཆགས་མྱུར་དུ་འཇིག་པར་འགྱུར། །
རྟོགས་པའི་ངང་ལ་མི་གནས་མཚན་མས་གཡེངས་གྱུར་ན། །
གཉིས་སྣང་མཚན་མའི་བག་ཆགས་ལྡོག་པར་མི་འགྱུར་ཏེ། །
རབ་རིབ་ཅན་གྱི་མིག་གི་ནང་དུ་ཤེས་གྱུར་ཀྱང་། །
མིག་གི་ནད་མ་བྱང་བར་རབ་རིབ་སྣང་མི་ལྡོག །
```

若认识了那实相，安住在它的状态中，二现之相的习气就会很快消灭。若不住于证悟的状态，被相所散乱，二现之相的习气就不会返离；就像患眼翳的人，虽然心里知道［那是眼翳］，在眼病没有治好之前，眼翳的显现不会消失。

【按】这是一个很重要的比喻：理论上知道显现是虚妄的，并不能消除二现的习气，就像患眼翳的人知道所见的毛发是眼病造成的，仍然会看见毛发；必须安住在证悟的状态中，像治好眼病那样，习气才会消失。这与《四偈半》第十三节"初一的月亮不是满月，证悟必须以串习圆满"的意思一致。

## 十二、歧途与束缚（第 90–92 句）

```
གནས་ལུགས་ཡིད་ལ་བྱེད་ཅིང་ཉམས་ལ་ཞེན་པ་དང་། །
དེ་ཉིད་དོན་ལ་གོམས་ཤིང་བསྒོམས་ན་གོལ་བའི་རྒྱུ། །
མཐུན་འཇུག་རྣམས་ལ་ཆགས་སྡང་སྐྱེ་ཕྱིར་འཆིང་བའོ། །
```

作意于实相，贪著于觉受，对那［实相的］意义加以串习、修习，就是歧途之因；对顺缘生起贪与嗔，就是束缚。

【按】"歧途"（gol ba），是大手印、大圆满中常用的术语，指偏离正道的修法。"对顺缘生起贪与嗔"，"嗔"字与"顺缘"不很相应，可能是说对顺缘生贪、对失去顺缘生嗔，存疑。

## 十三、逆缘即悉地（第 93–97 句）

```
མི་མཐུན་རྐྱེན་ངན་ཐམས་ཅད་དངོས་གྲུབ་དམ་པ་སྟེ། །
མི་མཐུན་རྐྱེན་གྱིས་རྣལ་འབྱོར་ཉམས་ཀྱི་གསལ་འདེབས་ཕྱིར། །
རྐྱེན་ངན་མི་སྤང་དེ་ཉིད་ཤེས་པས་དེ་ལ་སྦྱང་། །
དེ་ལྟར་སྐྱོང་ཞིང་ཉམས་རྟོགས་མཐར་འབྱིན་སྤྱོད་པ་སྟེ། །
གྱི་ལིང་དག་ལ་ལྕག་གིས་བསྐུལ་བ་ཇི་བཞིན་ནོ། །
```

一切不顺的恶缘，都是殊胜的悉地，因为逆缘能使瑜伽士的觉受更加明显。不要舍弃恶缘，要了知它的真性，在它上面修炼。这样护持，就是使觉受与证悟达到究竟的行持，就像用鞭子来策励良马一样。

【按】"逆缘即悉地"，是噶举、萨迦等派"将逆缘转为道用"的修心要点。"良马"，藏文作"གྱི་ལིང"（gyi ling），是一种良种马。

## 十四、行持的要点（第 98–102 句）

```
གལ་ཏེ་རྟོགས་ལྡན་ཉམས་བཟང་སྤྱོད་པའི་གྲོགས་མེད་ན། །
ཇི་ལྟར་མི་ལྡན་སྐྱེས་བུ་དག་ནི་རྐང་པ་མེད་དང་མཚུངས། །
དོན་དམ་རྣལ་མ་ཆགས་མེད་དོན་ལ་སྤྱད་བྱ་སྟེ། །
མི་སྤང་མི་སྒྲུབ་མི་ཞེན་མི་སྤྱོད་མི་འགོག་པར། །
རང་ལུས་ཅི་བདེར་སྤྱོད་པ་རབ་མཆོག་དམ་པའོ། །
```

如果有证悟、有好的觉受，却没有行持的助伴，就像不具足［四肢］的人没有脚一样。要在胜义本然、无贪著的意义上行持：不舍、不修、不著、不作、不遮，随着自己身体的安乐而行，这是最上最殊胜的。

【按】"就像不具足［四肢］的人没有脚一样"，藏文作"ཇི་ལྟར་མི་ལྡན་སྐྱེས་བུ་དག་ནི་རྐང་པ་མེད་དང་མཚུངས"，文句有些重复，意思是：有见地而无行持，就像人没有脚，不能前进，存疑。"随着自己身体的安乐而行"（rang lus ci bder spyod pa），是印度成就者"随意而行"的说法，以证悟为前提，见下一节的告诫。

## 十五、"即使……也要……"的告诫（第 103–116 句）

```
ཀུན་རྫོབ་སངས་རྒྱས་མི་རོའི་གདེང་ཆེན་ལྡན་གྱུར་ཀྱང་། །
སེམས་ཅན་ཚོགས་ཆེན་མི་སྤང་ཅི་ནུས་འབད་པར་བྱ། །
འཁོར་བ་དག་ལ་དོག་པའི་སེམས་མེད་འཇིགས་བྲལ་ཡང་། །
སྡིག་པའི་ལས་རྣམས་ཕྲ་མོ་དག་ནས་འཛེམ་པར་བྱ། །
ཆོས་རྣམས་སྟོང་པ་མཁའ་ལྟར་རྩ་བྲལ་རྟོགས་གྱུར་ཀྱང་། །
ཆགས་སྡང་འཛིན་ཆགས་མཐའ་དག་རྩད་ནས་སྤང་བར་བྱ། །
ཆོས་ཉིད་མཐའ་བྲལ་ཟང་ཐལ་ཆེན་པོའི་དོན་རྟོགས་ཀྱང་། །
བརྟན་པ་མ་ཐོབ་བར་དུ་ཉམས་རྟོགས་གཞན་ལ་གསང་། །
དོན་དམ་བདག་གཞན་གཉིས་སུ་མེད་པ་རྟོགས་གྱུར་ཀྱང་། །
ཀུན་རྫོབ་འགྲོ་ལ་ཕན་པའི་དོན་ཆེན་དག་ལ་བསམ། །
འདྲེན་པ་གཞན་ལ་མི་ལྟོས་གདེང་དང་ལྡན་གྱུར་ཀྱང་། །
བཀའ་དྲིན་ཅན་གྱི་བླ་མ་སྤྱི་བོའི་གཙུག་ཏུ་བཀུར། །
```

即使在世俗中具有［不再］希求佛果的大信心，也不要舍弃广大的众生，要尽力精进［利益他们］。即使对轮回没有疑惧之心，远离了恐惧，也要谨慎避免微细的恶业。即使证悟了诸法空如虚空、没有根本，也要把贪、嗔、执著全部从根本上舍弃。即使证悟了法性离边、大通彻的意义，在没有得到稳固之前，也要把觉受与证悟对他人保密。即使证悟了胜义中自他无二，在世俗中也要思惟利益众生的大事。即使具有不依赖其他导师的信心，也要把恩重的上师恭敬地顶戴在头顶上。

```
ཆགས་ཤིང་ཞེན་པར་བཅས་པས་ཀུན་ལ་དགག་སྒྲུབ་བྱེད། །
རྒྱུད་དང་མི་འཚམ་འགལ་བའི་སྤྱོད་པ་གོལ་བའོ། །
```

带着贪著与执著，对一切都加以遮遣与成立，［以及］与自己的相续不相称、违背［正法］的行持，都是歧途。

【按】这一组"即使……也要……"的告诫，是全篇极为重要的部分，与莲花生大士"见地高于虚空，取舍因果细于粉末"的教言意思完全一致：证悟空性的人，在世俗中更要谨慎因果、利益众生、恭敬上师，而不是以"空性""无修"为借口而放逸。第一句"具有不再希求佛果的大信心"，藏文作"ཀུན་རྫོབ་སངས་རྒྱས་མི་རོའི་གདེང་ཆེན"，"mi ro'i"意思不明，可能是"mi re'i"（不希求的）之误，这里依此译出，存疑。"大通彻"（zang thal chen po），是无碍、透彻之意，大圆满中常用。

## 十六、果：一切自地解脱（第 117–124 句）

```
མཐོང་བྱ་མཐོང་བྱེད་མེད་པས་ཐ་དད་རང་སར་གྲོལ། །
ཉམས་སུ་མྱོང་མཁན་སྟོར་བས་རྩོལ་སྒྲུབ་ཀུན་དང་བྲལ། །
ཐོབ་བྱའི་འབྲས་བུ་སྟོར་བས་རེ་དོག་ཀུན་ལས་གྲོལ། །
ང་བདག་རྩད་ནས་ཐོན་པས་བདུད་ཀྱི་གཡུལ་ལས་རྒྱལ། །
དངོས་འཛིན་རང་སར་ཞིག་པས་འཁོར་འདས་ཀུན་ལ་གྲོལ། །
རིག་པ་གཞི་ལ་དག་པས་རྫོགས་སངས་རྒྱས་ཞེས་བརྗོད། །
ཆོས་བློ་ཟད་སར་ཟད་པས་མྱ་ངན་འདས་ཞེས་བཤད་པའི་ཕྱིར། །
མ་བཅོས་མ་བསྒྱུར་སྤངས་ཐོབ་ཀུན་ལས་ཡོངས་སུ་གྲོལ། །
```

因为没有所见与能见，种种差别都在自地解脱；因为体验者已失，所以远离一切勤作与修持；因为所得之果已失，所以从一切希望与恐惧中解脱；因为我与我所已从根本上拔除，所以在魔的战场上得胜；因为对实有的执取在自地崩解，所以在一切轮回与涅槃中解脱。

因为觉性在基上清净，所以称为"圆满的佛"；因为法与心识在穷尽之处穷尽了，所以说为"涅槃"；不造作，不改变，从一切舍与得中彻底解脱。

【按】"体验者已失"（nyams su myong mkhan stor），"stor"是"失去、丢失"，意思是连那个"在体验的人"也找不到了，这与大手印"能所双泯"的意思一致。"觉性在基上清净"（rig pa gzhi la dag），是大圆满中常见的说法。

## 十七、一切皆是假名（第 125–139 句）

```
ཨེ་མ་ཧོ། །
ཕྱག་རྒྱ་ཆེན་པོ་ཞེས་བྱ་ཟབ་མོའི་སྒྲ་ཆེན་དེ། །
གདགས་གཞི་གང་ཡིན་སྟོང་པ་ཞེས་བྱའང་བཏགས་པ་ཙམ། །
སྐད་ཅིག་ངོ་བོས་སྟོང་པར་བདག་མེད་སུ་ཡིས་རྟོགས། །
རྟོག་མཁན་ཉིད་མེད་མིང་ཙམ་སྒྲ་ཙམ་བཏགས་པ་ཙམ། །
དེ་ཉིད་ཡང་དག་མ་ཡིན་གདུལ་བྱའི་སྣང་བའོ། །
གདུལ་བྱ་ཉིད་ལའང་བདག་མེད་སྒྱུ་མ་སྤྲུལ་པ་འདྲ། །
ཕྱག་རྒྱ་ཆེན་པོ་ཞེས་བྱ་བྱིས་པའི་བློས་བརྟགས་སོ། །
འཁྲུལ་དང་མ་འཁྲུལ་ཞེས་བྱ་མིང་ཙམ་བཏགས་པ་ཙམ། །
འཁྲུལ་པར་ཚོར་ཞིང་རིག་པའི་སྐྱེས་བུ་སུ་ཞིག་ཡིན། །
འབྲས་བུ་མྱང་འདས་རྡུལ་ཙམ་མེད་ཅིང་མི་དམིགས་ན། །
གྲོལ་དང་མ་གྲོལ་ཞེས་བྱ་གློ་བུར་སྒྲོ་བཏགས་ཏེ། །
ནམ་མཁའ་ཞི་ཞིང་དག་ལ་མེད་པ་གྲོལ་ལམ་ཅི། །
ཀུན་རྫོབ་དོན་དམ་ཞེས་བྱའང་ནན་གྱིས་བཏགས་པ་སྟེ། །
ཆོས་ཀྱི་དབྱིངས་ལ་བདེན་པ་གཉིས་མེད་ཆོས་དབྱིངས་མེད། །
```

唉玛吙！"大手印"这个甚深的大声音，无论它的假立之基是什么，连"空"这个名字也只是假立而已。刹那间本体就是空，［就是］无我，［又有］谁能证悟呢？连能证悟者本身也没有，只是名、只是声、只是假立。

那本身也不是真实的，［而是］所化众生［心中］的显现；所化众生本身也是无我的，就像幻术与化现一样。所谓"大手印"，是愚者的心所遍计的。

"迷乱"与"不迷乱"，只是名，只是假立；感觉、认知到迷乱的那个人，又是谁呢？如果果——涅槃连微尘许也没有、不可得，那么"解脱"与"不解脱"只是突然［生起的］增益而已；在寂静、清净的虚空中，什么都没有，［还说什么］解脱或别的呢？

"世俗"与"胜义"，也只是勉强假立的；在法界中没有二谛，［连］法界也没有。

【按】最后一节把前面所说的一切，连"大手印""空""证悟者""解脱""二谛""法界"本身，都说为假名，与第一节"连'不是'也不是"首尾呼应。这正是"离戏"的究竟：大手印不是一个可以执持的东西，连"大手印"这个名字也要放下。"所化众生［心中］的显现"（gdul bya'i snang ba），是说佛所说的这些名言，都只是为了引导众生而显现的。

## 跋

```
དོ་ཧ་མཛོད་ཅེས་བྱ་བ་རྣལ་འབྱོར་གྱི་དབང་ཕྱུག་བིརྺ་པས་མཛད་པ་རྫོགས་སོ།། །།
རྒྱ་གར་གྱི་མཁན་པོ་ཤྲཱི་བཻ་རོ་ཙ་ནས་རང་འགྱུར་དུ་བསྒྱུར་བའོ།། །།
བརྒྱུད་པ་ནི་བིརྺ་པ།
ནག་པོ་པ།
སློབ་དཔོན་སྒྲ་མཁན་ཞབས།
སློབ་དཔོན་པུ་ར་པ།
ཤྲཱི་བཻ་རོ་ཙ་ནའོ།།
```

《道歌宝藏》，瑜伽自在毗瓦巴所造，圆满。

印度亲教师吉祥毗卢遮那亲自译出。

传承是：毗瓦巴、黑行者、阿阇黎声师足、阿阇黎布罗巴、吉祥毗卢遮那。

【按】"吉祥毗卢遮那"（śrī bai ro tsa na），即毗卢遮那金刚（Vairocanavajra），十二世纪来藏的印度上师，出生于南印度憍萨罗，曾译出多部道歌（包括下一篇帝洛巴的《道歌宝藏》），不是莲花生大士时代的大译师毗卢遮那。"自译"（rang 'gyur），意思是他本人通藏文，亲自译出，没有藏族译师合作。"黑行者"（nag po pa，Kṛṣṇācārya / Kāṇha），是毗瓦巴的弟子之一。"声师足"（sgra mkhan zhabs）、"布罗巴"（pu ra pa），依藏文意译或音译，具体是哪两位上师，未能确定，存疑。

## 通篇连读

敬礼吉祥金刚萨埵！敬礼世尊无我母！唉玛吙！

三有与寂灭——大手印，本性就像虚空一样清净；没有可被指示的实相，名言与言语之道都断了。自性离戏，远离一切相对之法；不可推求，不可观察，远离譬喻，连离譬喻也不住，超越了心识的境界。不是常，不是断，不是轮回，不是涅槃；不是显现，不是空，不是有，不是无，也不是无生；不是本然的法性，也不是超越心识；连"不是"也不是，因为是与不是都不是心识所能言说的；与任何二元之法都没有关联，从本以来就是平等性。

对它的本体、词义、作用所作的解说，就像说兔角锐利或钝一样虚假，一切法都与那体相没有差别。显现于三有中的一切世俗法，都没有自性，只是名、只是声、只是假立，名与义之间没有差别；它们从本以来就是俱生的，不要到别处去寻求。

心性名空、离戏，就是大手印，就像虚空从本以来就是名空的。本性不生，远离相的戏论；像虚空一样遍于一切，没有迁移与变化；在一切时中都是空，从本以来无我；没有忆念、分别与相，就像阳焰之河；不被束缚，也没有解脱，从本然的状态中从未动摇。一切众生都是大手印的化现，化现的本体从本以来就是不生的法界；苦乐等二现的一切相，都是本然法性大手印的游戏；游戏不真实、不坚固、会变化，所以从来没有超出空性的实相。

有人以灌顶自苦，有人口念吽呸、数着念珠，有人吃粪尿血精肉，有人修脉风瑜伽，都完全迷乱了。唉玛吙！被殊胜上师摄受的另一种人，是这样证悟的：凡是所修的都是迷乱，其中没有真正的证悟；没有所证与能证，所以远离偏执与边见；没有远离与不远离，所以安住于平等性的本然状态。这样证悟，就不必再到别处探问。种种显现明现为法身，所以不生取舍之心；没有修与不修，不被相所染；不依显现与不显现的对境；没有作者与所作之心，远离一切所缘；没有希望与恐惧，对一切的贪著都已返离。

若依上师的开示证悟了本然的实相，种种念头与觉知都自己消融于法界；识不住于对境，远离贪著，在不造作的本然状态中一切法都得解脱。对一切不贪著，远离我慢等垢染，具足恭敬，被殊胜者摄受；远离任何作意，就是无垢，对此没有怀疑；能知与所知清净了，法性就现前显现。

若没有证悟本然的大手印，就会因二取而恒常贪著一切，种种如眼翳般的念头相续生起，不住于无误之义，在三有中轮转流浪。对名声恭敬的贪著，广大的闻思，好的觉受，悉地、加持、能力的征相，都是造作之道，实际上都是垢染，智者不会把心寄托在上面。

若作意于那真性而落入二边，那就是轮回的根本。要看那一切的根基——心之山是什么！看了而没有见到，远离了心意，就一定解脱。心对于法界没有"这个"可言，所以没有能修与所修；不要分别有无，安住在不散乱的状态中。若作意于空性、无生、超越心识、离边等等，就不住于实相，是极大的散乱。在不计较空与不空的松坦状态中安住，没有安住与不安住，自在地放任它，没有放下与执持之心，就像起尸一样。

认识了实相而安住在它的状态中，二现的习气很快就会消灭；若不住于证悟的状态，被相所散乱，习气就不会返离，就像患眼翳的人，虽然知道是眼翳，眼病没有治好之前，所见的毛发不会消失。作意于实相、贪著觉受，对它加以串习修习，就是歧途之因；对顺缘生起贪嗔，就是束缚。一切逆缘都是殊胜的悉地，因为它使瑜伽士的觉受更加明显；不要舍弃恶缘，要了知它的真性，在它上面修炼；这样护持，就是使觉受与证悟达到究竟的行持，就像用鞭子策励良马。

有证悟、有好觉受而没有行持的助伴，就像人没有脚。要在胜义本然、无贪著的意义上行持：不舍、不修、不著、不作、不遮，随着自身的安乐而行，这是最上最殊胜的。即使具有不希求佛果的大信心，也不要舍弃众生，要尽力利益；即使对轮回无所畏惧，也要谨慎微细的恶业；即使证悟诸法空如虚空，也要把贪嗔执著从根本舍弃；即使证悟法性离边、大通彻，在得到稳固之前，也要把觉受证悟对他人保密；即使证悟自他无二，在世俗中也要思惟利益众生的大事；即使具有不依其他导师的信心，也要把恩师顶戴在头顶。带着贪著对一切加以遮遣与成立，以及违背正法的行持，都是歧途。

没有所见与能见，种种差别都在自地解脱；体验者已失，远离一切勤作；所得之果已失，从希望与恐惧中解脱；我与我所从根拔除，在魔的战场上得胜；实有执取在自地崩解，在一切轮回涅槃中解脱。觉性在基上清净，所以称为圆满的佛；法与心识在穷尽之处穷尽，所以说为涅槃；不造作，不改变，从一切舍与得中彻底解脱。

唉玛吙！"大手印"这个甚深的大声音，无论假立之基是什么，连"空"这个名字也只是假立；刹那间本体就是空、就是无我，又有谁能证悟呢？连证悟者本身也没有，只是名、只是声、只是假立。那本身也不是真实的，而是所化众生心中的显现；所化众生也是无我的，像幻术与化现。所谓"大手印"，是愚者的心所遍计的。"迷乱"与"不迷乱"只是假名，感觉到迷乱的人又是谁？如果涅槃之果连微尘许也不可得，"解脱"与"不解脱"只是增益而已；在寂静清净的虚空中，什么都没有，还说什么解脱？"世俗"与"胜义"也只是勉强假立的；在法界中没有二谛，连法界也没有。

《道歌宝藏》，瑜伽自在毗瓦巴所造，圆满。印度亲教师吉祥毗卢遮那亲自译出。
