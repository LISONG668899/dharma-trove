# 《大宝积经》卷第四十三（菩萨藏会·尸波罗蜜品）

唐·三藏法师玄奘 奉诏译

## 菩萨藏会第十二之九

【按】品名“尸波罗蜜”，宋、元、明、宫本作“尸波罗蜜多”。

### 尸波罗蜜品第七之二

#### 四种广胜处法：本身、人中、天中

那时，佛告诉舍利子：“菩萨摩诃萨行尸罗波罗蜜多时，由于成就这样的善根之力，获得四种广胜处法。是哪四种？一是对于诸善法能迅速趣入，二是为说法师所赞美，三是修行成满，无有毁犯，四是对于佛的正法坚持不坏。舍利子！这是菩萨摩诃萨获得的四种广胜处法。又，舍利子！菩萨摩诃萨由于这力量，处在人中，又获得四种广胜处法。是哪四种？一是为众多众生所追随修学，对于诸白法究竟安住；二是在平坦道路上营建旅舍，极为坚固严密，迅速令众生获得欢喜；三是在长夜中因得法利，欢泰之心无有退减；四是临终舍命时，没有迷惑缠心，往生善趣的安乐世界。舍利子！这是菩萨摩诃萨处在人中获得的四种广胜处法。又，舍利子！菩萨摩诃萨由于这力量，处在天中，又获得四种广胜处法。是哪四种？一是以福德所感，能摄受天众。二是诸天集会，瞻仰他的面容：‘菩萨现在将演说什么？我们听了将有所开悟。’三是为天帝释以及其余天子所参觐，请法断疑，而这位菩萨不必前往他们那里。四是显现大宫殿，为菩萨所受用。舍利子！这是菩萨摩诃萨处在天中获得的四种广胜处法。舍利子！这样，菩萨摩诃萨行尸罗波罗蜜多时，无论在天上或生在人中，又得到无量无边百千万亿种种妙法门，都为了满足尸罗波罗蜜多。”那时世尊想重宣此义，而说颂道：

【按】“欢泰”之“泰”，宫本作“奉”。“参觐”之“觐”，《大正藏》作“观”，今依CBETA作“觐”。

```
菩萨处高座，诸天所礼敬，
瞻仰彼尊颜，将宣何等法？
一切皆恭敬，具慧除悭悋，
处欢喜宫殿，释天来请疑。
天中命尽已，来生于人间，
为转轮圣王，大力无悭悋。
若人中命终，还复生天上，
曾未更众苦，奉养法师故。
恒获如是等，四种广胜处，
为无下劣心，恭敬说法者。
若以敬爱心，奉施于水器，
则天龙及人，所应亲供养。
```
（大意：菩萨处在高座上，为诸天所礼敬，瞻仰他的尊容：“将宣说什么法？”一切都恭敬他，他具足智慧，除去悭吝，处在欢喜的宫殿中，帝释天前来请问疑惑。在天中寿命尽了之后，来生于人间，作转轮圣王，具大力而无悭吝。若在人中命终，又生到天上，从未经历众苦，都是因为奉养法师。恒常获得这样的四种广胜处，因为没有下劣之心，恭敬说法的人。若以敬爱之心奉施水器，便为天、龙以及人所应亲近供养。）

#### 天中四法与四种圆成胜法

“再者，舍利子！这些菩萨摩诃萨行尸罗波罗蜜多时，由于成就这样的诸善根，又在天中得到四种法。是哪四种？一是了知先世所经历造作的业；二是了知因这善业而来生天上，以及能了知善法的退失；三是了知从此命终将生于某处；四是为诸天众宣说妙法，开示、教导、赞叹、令其欢喜，利益之后便舍弃天身。舍利子！这是菩萨摩诃萨生在天中所得的四种法，都由于尸罗波罗蜜多。

“再者，舍利子！菩萨摩诃萨行尸罗波罗蜜多时，由于成就这样的诸善根，又得到四种圆成胜法。舍利子！是哪四种？一是菩萨摩诃萨舍弃天宫之后，又来到人趣，与戒俱生。二是菩萨摩诃萨处在人中，获得五种成胜生法。哪五种？就是得生于殊胜之家，得到殊胜妙色，得到殊胜净戒，得到殊胜眷属，对众生得修殊胜之慈，这样名为获得五种成胜生法。三是菩萨摩诃萨处在人中，又得到五种成不坏法。哪五种？就是所得的善知识不可破坏，所受的身体终无中途夭折，所得的财位中间无有退失，所得的菩提心无人能破坏，在正法匮乏之时自己得以丰足，这样名为获得五种成不坏法。四是菩萨摩诃萨处在人中，又获得五种希有圆满之法。哪五种？菩萨摩诃萨在舍宅中安放空器，随菩萨的手所触及之处，一切众宝立即盈满，这名为获得第一希有圆满之法。菩萨摩诃萨若遇口渴之时，便在他面前自然涌现具八功德的水池，这名为获得第二希有圆满之法。菩萨摩诃萨以福德持身，不被外物所侵害，就是或毒、或刀、或火、或水、吸人精气者，或药叉以及种种恶鬼，都不能损害，这名为获得第三希有圆满之法。菩萨摩诃萨在赡部洲遇到种种灾劫兴起，就是刀兵劫、饥馑劫、疾病劫、火劫、水劫、风劫、渴劫、热光劫、药叉劫；舍利子！这样的别劫兴起之时，那时菩萨不生在其中，而处在天上受极大快乐，受众多极乐，这名为获得第四希有圆满之法。菩萨摩诃萨就以这样的善根之力，永不再生于诸难之处，不生于恶趣，若有追悔缠心，便能见知而迅速远离，这名为获得第五希有圆满之法。舍利子！这名为菩萨摩诃萨因行尸罗波罗蜜多，又获得四种希有圆成胜法。

#### 四种妙法、离三劫夺、四种无病

“再者，舍利子！菩萨摩诃萨行尸罗波罗蜜多时，由于成就这样的善根之力，常不远离四种妙法。哪四种？一是菩萨摩诃萨只要见到有苦的众生，便获得大悲之心；二是菩萨摩诃萨所有的儿女，都对菩萨恭敬随顺；三是菩萨摩诃萨能制伏衰老，不为其所侵；四是菩萨摩诃萨的资生作业获利百倍，或超过于此二倍、三倍。舍利子！这是菩萨摩诃萨行尸罗波罗蜜多时，成就这样的四种妙法，恒常不远离。

“再者，舍利子！菩萨摩诃萨行尸罗波罗蜜多时，由于成就这样的诸善根，不被三种法所劫夺。是哪三种？一是不被贪欲所劫夺，二是不被瞋恚所劫夺，三是不被愚痴所劫夺。舍利子！这是菩萨摩诃萨因行尸罗波罗蜜多，远离三种劫夺之法。

“再者，舍利子！菩萨摩诃萨行尸罗波罗蜜多时，由于成就这样的诸善根，获得四种无病之法。是哪四种？一是菩萨摩诃萨不被长期疾病所缠逼，二是菩萨摩诃萨肢体鲜泽，从未羸弱憔悴，三是菩萨摩诃萨的资生众具无有损减，四是菩萨摩诃萨不被国王、盗贼、恶人以及其余众生所加恼害。舍利子！这是菩萨摩诃萨因行尸罗波罗蜜多，获得四种成无病法。

【按】“获得四种无病之法”之“获”，明本作“复”。

#### 四种尊位之相

“再者，舍利子！菩萨摩诃萨行尸罗波罗蜜多时，由于成就这样的诸善根，获得四种尊位之相。是哪四种？一是菩萨摩诃萨作转轮王，威加四方，以法治世，名为法王，七宝前来应现，都得成就。是哪七宝？就是轮宝、象宝、马宝、女宝、末尼珠宝、主藏宝、主兵臣宝。千子满足，形貌端严，威势雄猛，降伏怨敌。这位转轮王为四大洲所朝宗、钦仰、归化，又为宰相群臣所守卫，为众会、国界人民以及诸小王所共同遵敬。舍利子！这是菩萨摩诃萨获得的第一尊位之相。又，舍利子！菩萨摩诃萨对于美妙的五欲不染乐著，就是眼所识的色、耳所识的声、鼻所识的香、舌所识的味、身所识的触；菩萨摩诃萨因为对这五欲不染著，以清净信心舍家入道，迅速获得五通，为人以及非人所恭敬。舍利子！这是菩萨摩诃萨获得的第二尊位之相。舍利子！菩萨摩诃萨在所生之处，自然常得最上的觉悟、最上的智慧、最上的辩才，为诸大王所尊敬；如过去世的大乌末荼为国王所敬重，这位菩萨也是这样，为国王敬重，请他升上御座，又为宰相群臣所守卫，为众会、国界人民所共同尊仰。舍利子！这是菩萨摩诃萨获得的第三尊位之相。又，舍利子！菩萨摩诃萨觉悟阿耨多罗三藐三菩提之后，威德殊胜，圆满第一，为诸天、龙、药叉、健达缚、阿素洛、揭路荼、紧捺洛、牟呼洛伽、人非人等一切有情所共同归敬。为什么？因为这位菩萨成就最胜的戒、定、慧品，解脱、解脱智见品，在这法中证得清净。舍利子！这是菩萨摩诃萨获得的第四尊位之相。舍利子！这名为菩萨摩诃萨行尸罗波罗蜜多时获得的四种尊位之相，都为了成满尸罗波罗蜜多。

【按】“大乌末荼”，人名，事迹未详。

#### 四种最胜资财

“再者，舍利子！这样的菩萨摩诃萨行尸罗波罗蜜多时，以清净之心将贮水之器奉施邬波柁耶以及阿遮利耶二位尊师，获得这样无量无边的功德妙法。就是菩萨摩诃萨为了求法，去来进止随顺于师，如其所言，终不违逆，由于成就这样的善根之力，又获得四种最胜资财。是哪四种？一是菩萨摩诃萨在所生之处，获得大王所用的资财，不是其余众生的下劣资具。二是菩萨摩诃萨在所生之处，受持离欲之法，获得仙人之财，以清净信心舍家入道，名为圣法之财。三是菩萨摩诃萨在所生之处得到宿命之念，名为获得念财；由于这念，在生生之处终不忘失菩提之心。四是菩萨摩诃萨证得阿耨多罗三藐三菩提之后，名为菩提之财，常为四众、天、龙、药叉、健达缚、阿素洛、揭路荼、紧捺洛、牟呼洛伽、人非人等前后围绕。舍利子！这名为菩萨摩诃萨因行尸罗波罗蜜多而证得的四种最胜资财。

【按】“邬波柁耶”之“邬”，《大正藏》作“鄥”，今依CBETA作“邬”。

#### 四种成高胜法

“再者，舍利子！菩萨摩诃萨行尸罗波罗蜜多时，对于说法师，乃至只是受持四句颂等的人，去来进止都随顺其教命，就是：这是善，这是不善；这是有罪，这是无罪；这应当修，这不应修。又这样的教导：乃至作了这事之后，会在长夜中感得无义、无利的种种苦恼之法；若作了这事，会在长夜中感得有义、有利的种种安乐之法。这样的教导，都随师长所命，不作不善，修习善法，无违无逆。由于这位菩萨摩诃萨成就这样的善根之力，又获得四种成高胜法。是哪四种？一是菩萨摩诃萨得以具足尸罗，成就高胜之法；二是菩萨摩诃萨所感得的形体，一切身分都圆满；三是菩萨摩诃萨获得大慧、涌慧、高慧、广慧、捷慧、利慧、速慧、深慧、决择之慧；四是菩萨摩诃萨身坏命终，生于善趣诸天世界。舍利子！这名为菩萨摩诃萨行尸罗波罗蜜多时获得的四种成高胜法。

#### 四种无能观法

“再者，舍利子！菩萨摩诃萨行尸罗波罗蜜多时，由于成就这样的善根之力，又获得四种无能观法。是哪四种？舍利子！菩萨摩诃萨由于成就这样的善根之力，在所生之处感得隐密的阴藏之相，这名为第一无能观法。

【按】“阴藏之相”之“相”，宫本作“根”。

“舍利子！菩萨摩诃萨由于成就这样的善根之力，从初生起，无论母亲、父亲，或其余眷属，或天、龙、药叉、罗刹、健达缚、阿素洛、揭路荼、紧捺洛、牟呼洛伽、人非人等，所有众生，无论心清净或心杂染，都不能见到菩萨的顶，这名为第二无能观法。

“舍利子！菩萨摩诃萨由于成就这样的善根之力，从初生起，无论母亲、父亲，乃至人非人等，所有众生，无论心清净或心杂染，都无人能修饰菩萨的面容。瞻视菩萨的人若起心：‘我要妆饰菩萨的面容’，菩萨的面像便显现在双足上。为什么？舍利子！因为这位菩萨摩诃萨成就这样希奇之法，所以名为善丈夫，又成就最胜丈夫第一的诃辩，这名为第三无能观法。

原文：“又复成就最胜丈夫第一诃辩”（大意：又成就最胜丈夫第一的诃辩。“诃辩”，宋、元、明、宫本作“词辩”，所指未详，存疑。）

“舍利子！菩萨摩诃萨由于成就这样的善根之力，初生之时，无人扶持，自己站立在地上，遍观四方，便获得明利之智。为什么？因为这位菩萨摩诃萨在过去世以无谄之心求闻正法。这位菩萨摩诃萨又获得无邪谄之眼；由于成就这无谄之眼，以清净天眼超胜于人，乃至能观见三千大千世界所有众生。又，这位菩萨摩诃萨获得迅速广大之智；由于成就这广大之智，能了知一切众生在三时中所积集的心。为什么？因为这位菩萨摩诃萨在往昔求法之时，作意摄心，勤加恭敬，对于正法生起良药之想、珍宝之想、难遇之想、妙善之想，如其所念而求闻正法，闻后受持。菩萨摩诃萨又因此，再获得敏捷的简择之智；由于成就这简择之智，善能称量众生的戒，乃至善能称量其正闻、定、慧、解脱、解脱智见。又，菩萨摩诃萨善能称量一切众生的尸罗同性，乃至善能称量其正闻、定、慧、解脱、解脱智见的同性；又，菩萨摩诃萨善能称量一切众生戒的等流，乃至善能称量其正闻、定、慧、解脱、解脱智见的等流；又，菩萨摩诃萨善能称量一切众生尸罗等流的超胜之相，乃至善能称量其正闻、定、慧、解脱、解脱智见等流的超胜之相；又，菩萨摩诃萨善能称量一切众生进止威仪、修行正行的勇猛之相。舍利子！菩萨摩诃萨这样展转称量思惟一切众生的种种功德之后，这样想：‘这些众生所有的戒、闻，乃至解脱、解脱智见；这些众生所有的尸罗同性，乃至正闻、定、慧、解脱、解脱智见的同性；这些众生所有的尸罗等流，乃至正闻、定、慧、解脱、解脱智见的等流；这些众生所有的尸罗等流超胜之相，乃至正闻、定、慧、解脱、解脱智见等流的超胜之相；这些众生所有的进止威仪、修行正行的勇猛之相——这样的种种相，都是众生所有的功德。我现在于其中称量观察，不见有与自己平等的。’那时菩萨又进一步思惟：‘一切众生的根本坚住，与自己比较，不见一切众生中有与我相等的。’

【按】“扶侍”之“侍”，宋、元、明、宫本作“持”，今依之译作“扶持”。

“又，舍利子！菩萨摩诃萨初生之时，在刹那间能迅速发起业报的妙智；由于这智，在一弹指之顷，善能了知一切众生的千种心相。这时菩萨摩诃萨以智寻思这一切心，不见有与自己平等的。菩萨摩诃萨这样正知：我现在独处最上的尊位，如狮子王安住无畏，如大龙王具大威德。足不践地，各行七步，忆念菩提座的微妙业报，安住现前，唱出这样的话：‘我在世间最为尊大，我在世间最为殊胜，我当证得生老死的边际，我当度脱一切众生的生老病死、忧悲苦恼，我当为众生宣说广大、微妙、最胜、无上的正法。’舍利子！菩萨摩诃萨说这话时，中间没有间隔，其声遍告，充满这三千大千佛世界；其中众生听到这声音，惊怖毛竖，天鼓战栗，屡屡发出大声，而这世界全都震动，唯有菩萨所住之地，如车轮大小，巍然安静；就是这地轮下面所依的水聚，也不被那大风所摇动。这位菩萨摩诃萨自观己身，见无量光明遍身而住，便证得阿耨多罗三藐三菩提，为众生所共同瞻仰，这名为第四无能观法。舍利子！这名为菩萨摩诃萨获得的四种无能观法。为什么？都是因为菩萨摩诃萨在过去世行尸罗波罗蜜多时，随顺法师去来进止，遵承教命，无有违逆。

【按】“中无有间”之“间”，宫本作“闻”。“即证”之“即”，宋、元、明、宫本作“既”。

#### 四种迅速之法与成佛诸功德

“再者，舍利子！菩萨摩诃萨行尸罗波罗蜜多时，成就这样的诸善根之后，又获得四种迅速之法。是哪四种？菩萨摩诃萨成佛之时具足这样：诸佛如来所说之法无有缺减，所说之法言不虚设，这名为第一迅速之法。菩萨摩诃萨成佛之时具足这样：诸佛如来若有所命，这样说：‘进来，苾刍！’那时众生便来到佛所，头发自然断落，披上袈裟，手持钵多罗，这名为第二迅速之法。菩萨摩诃萨成佛之时具足这样：诸佛如来善知众生三时之心，这名为第三迅速之法。菩萨摩诃萨成佛之时具足这样：诸佛如来善知众生应病与药之智，这名为第四迅速之法。舍利子！这名为菩萨摩诃萨获得的四种迅速之法。为什么？因为在往昔行尸罗波罗蜜多时，以清净之心向邬波柁耶以及阿遮利耶等诸说法师奉施水器。

“再者，舍利子！菩萨摩诃萨依尸罗波罗蜜多，具足这样的善根之力，成佛之时又得到四种他不害法。是哪四种？舍利子！如来之身无依无受。为什么？如来之身若被火、刀、毒药或他物所能损害，无有是处。舍利子！这是菩萨摩诃萨成佛之时，因具尸罗而获得的四种无损害法。

原文：“成佛之时复得四种他不害法。何等为四？舍利子！如来身者无依无受”（原文问“何等为四”，下文只举一种，今依原文照译，存疑。）

【按】“获得四种无损害法”之“获”，宋、元、明、宫本作“能获”。

“再者，舍利子！菩萨摩诃萨依尸罗波罗蜜多，由于具足这样的善根之力，成佛之时又得到四种他无过法。是哪四种？一是诸佛如来无依无受。为什么？没有众生能在如来面前说这样的话：‘我为如来说了未曾听闻之法，乃至一句。’若能这样说，无有是处。二是诸佛如来无依无受。为什么？没有众生能在如来面前如法立论，乃至一句；若能立论，无有是处。三是诸佛如来无依无受。为什么？没有众生能得到如来乃至微细一分的不定之心；若能得到，无有是处。为什么？舍利子！诸佛如来的心恒常在定，因为住于慈、悲、喜、舍等。四是诸佛如来无依无受。为什么？没有众生能取到如来身色的诸相；若能取相，无有是处。舍利子！诸佛如来因具尸罗而获得四种他无过法。

【按】“无众生能得”之“无”，宋、元、明、宫本作“无有”。

“再者，舍利子！诸佛如来由于成就这样的善根之力，获得具足五种无量之法。是哪五种？一是诸佛如来的尸罗无量，二是诸佛如来的正闻无量，三是诸佛如来的正定无量，四是诸佛如来的正慧无量，五是诸佛如来的解脱、解脱智见无量。舍利子！如来这样的五种无量之法，都是由于往昔行尸罗波罗蜜多时，对邬波柁耶、阿遮利耶等诸尊重之师随顺师教，去来进止，无有违逆。

“再者，舍利子！诸佛如来具足尸罗波罗蜜多之后，由于成就这样的善根之力，获得四种无障碍智。是哪四种？就是诸佛世尊对于过去世有无障无碍的智见运转；诸佛世尊对于未来世有无障无碍的智见运转；诸佛世尊对于现在世有无障无碍的智见运转；诸佛世尊善能发起平等之心，由于生起这样的平等之心，能知三世平等之性。舍利子！这是如来因具尸罗而获得的四种无障碍智。

【按】“平等心”，元、明本作“平等之心”。

#### 如来了知风轮与上方佛土

“再者，舍利子！诸佛如来又善能成就正智，由于正智，不依属他人而能全知一切诸法。诸佛如来又能成就不思议智，由于成就这不思议智，而能了知种种风雨之相。舍利子！如来善知世间有大风名为乌卢博迦，乃至众生种种觉受都由这风所摇动；这风轮之量高三拘卢舍。在这风上的虚空中又有风生起，名叫云风，这风轮之量高五拘卢舍。在这风上的虚空中又有风生起，名为瞻薄迦，这风轮之量高十逾缮那。在这风上的虚空中又有风生起，名为吠索缚迦，这风轮之量高三十逾缮那。又在这风上的虚空中有风生起，名叫去来，这风轮之量高四十逾缮那。这样，舍利子！次第向上，六万八千拘胝风轮之相，如来、应、正等觉依止大慧都能了知。舍利子！最上的风轮名为周遍，为上界的水轮所依止，那水的高量为六十八百千逾缮那，为那大地所依止；那地的高量为六十八千逾缮那。

【按】“拘胝”，明本作“俱低”。

“舍利子！这地量之上有一个三千大千世界，其中有佛，号为弘蕴如来、应、正等觉，现在在那里住世施化。那尊佛寿量三十拘胝岁，声闻弟子有三十拘胝那庾多，都是大阿罗汉，诸漏已尽，不再有烦恼，乃至证得诸心自在的最上波罗蜜。那时那尊佛与这样的大声闻众共同集会。又有百拘胝等菩萨摩诃萨，都已证得菩萨藏法，对于诸义理妙善决定，是多闻之海、大法师，安住于空、无相以及无愿。舍利子！我涅槃后满一千年，那尊佛才入般涅槃；正法住世满一千年，舍利流布，遍益世间，也如我现在般涅槃后舍利流布、遍益世间之相。舍利子！如来的无障碍智又能了知超过那佛世界之上无量无边的风轮圆相，以及诸佛国土的具足圆相。舍利子！又超过此上，有另外的世界，现在没有如来，而有百千独觉居住，其中众生都在独觉处种下善根。舍利子！如来依那智慧，又能了知此世界之上有殑伽沙等诸佛如来出兴于世，现在在那里度化众生。这样，十方无量无数、不可思议、不可称量的诸佛如来、应、正等觉出兴于世，现在在那里度化众生，如来的妙智都能了知。舍利子！如来又能了知如上所说的诸佛世界正在燃烧等成坏之相，无量无边，如来的妙智都能明了。”

【按】“百千独觉”之“百”，宋本作“百百”。“出兴于世”之“于”，宋本作“子”。

#### 由敬法得无障碍智

如来说完这话，长老舍利子对佛说：“世尊！如来、应、正等觉成就什么样的善根，而能获得这样无量不可思议的无障碍智？”

佛告诉舍利子：“如来由于安住尸罗波罗蜜多，妙善自在，对于正法生起恭敬尊重之想，生起良药之想，生起珍宝之想，生起难遇之想，生起善根之想、如所应之想，生起深敬之想，又能安住于摄持正法之想。舍利子！如来由于安住尸罗波罗蜜多、敬重正法，获得这样明利的大智；这样的大智又能了知超过前面所说之量的无量无数之事。舍利子！诸佛世尊的无断之智，无量无数，不可思议，不可称量，不可宣说往来之相。舍利子！诸佛如来因具尸罗，又得到这样自在之力，所以如来在一弹指之顷，前往殑伽沙等诸佛世界，又旋返回到本来所住之处。舍利子！诸佛如来对于这正法、尸罗波罗蜜多，以净信解听闻受持，由此获得迅速解脱；由此解脱，我善得解脱。在什么法中得到解脱？就是在诸苦中善得解脱。

原文：“诸佛世尊无断之智，无量无数不可思议不可称量不可宣说往来之相”（大意：诸佛世尊的无断之智，无量无数，不可思议，不可称量，不可宣说往来之相。句意未详，存疑。）

#### 慧所成法、多所作法、支分之法

“再者，舍利子！若有菩萨摩诃萨对于这四种恭敬住处，听闻这法之后得到清净信心，行尸罗波罗蜜多，发起这样的心：‘我这样安住，我安住于此；由于我这样常常安住，我常不离诸佛正法。’舍利子！菩萨摩诃萨受持这部经的法门章句，他由于这样的善根之力，又获得四种慧所成之法。是哪四种？一是由于具足智慧，能发起大慧；二是由于具足智慧，逢遇诸佛，亲觐承事；三是由于具足智慧，以清净信心舍家入道；四是由于具足智慧，迅速证得阿耨多罗三藐三菩提。舍利子！这名为菩萨摩诃萨行尸罗波罗蜜多时获得的四种慧所作法。

原文：“若有菩萨摩诃萨于此四种恭敬住处”（大意：若有菩萨摩诃萨对于这四种恭敬住处。“四种恭敬住处”所指未详，存疑。）

“再者，舍利子！菩萨摩诃萨行尸罗波罗蜜多时，由于成就这善根之力，又获得四种多所作法。是哪四种？一是受得人身，名为多所作；二是遇到佛出世，名为多所作；三是以清净信心舍家入道，名为多所作；四是迅速证得阿耨多罗三藐三菩提，名为多所作。舍利子！这名为菩萨摩诃萨行尸罗波罗蜜多时获得的四种多所作法。

“再者，舍利子！菩萨摩诃萨行尸罗波罗蜜多时，由于成就这善根之力，又获得四种支分之法。是哪四种？一是菩萨摩诃萨获得转轮之支，就是处在人中作转轮王；二是菩萨摩诃萨处在梵世，作大梵王；三是菩萨摩诃萨处在诸天众中，作天帝；四是菩萨摩诃萨证得阿耨多罗三藐三菩提之后，对于一切法具足圆满，号为法王，处世垂化，又获得吉祥诸力、清净众生之智、神通境界，这样的种种相都能了知，作为诸世间天人之眼。”那时世尊想重宣此义，而说颂道：

```
救世之明眼，诸群生最上，
善解诸医法，由斯证寂灭。
往返随师教，感报为如是，
未曾受众苦，及不善自在。
速往生天上，速还返人中，
速奉见诸佛，速得离诸难。
巨富丰大财，目观诸伏藏，
随手之所及，众宝皆盈满。
化现妙池沼，八德水常盈，

端严众乐观，容相皆鲜妙。
诸天龙鬼神，及以世人等，
供养而尊敬，为妙自在德。
远离诸恶道，往人天善趣，
速悟大菩提，为善自在果。
若人悉能了，一切众生心，
各行七步已，妙音告世界。
```

```
信者营灵庙，复由沈恶趣。
```
（大意：若人能了知一切众生之心，各行七步之后，以妙音告知世界：此人智慧最上，此人慧最上，解脱也最上，在众生中最上。慧令慧清净，慧依智而安立，慧、智与解脱，都依诸佛而证得。由慧的自性而生，所知由智而了，若有人具足智慧，所求无不如愿。这样甚深之义，我为你略说；无慧而少欲之人，岂能领受此义？他们被愚痴所迷，被众恶所逼迫，生起忿恚，不恭敬正法。若少欲的众生对于这样的正法不再兴起恭敬，反而生起其余诸事；不恭敬正法的众生，被忿恚所迷执，常怀染污之心，不应为他们宣说。那些年老衰迈的摩诃罗，临命终时，虚言住于后有；那些年老衰迈的摩诃罗，妄吞阿罗汉的供养，迅速堕入地狱。具足戒尚且难得，何况阿罗汉果；有信心的人为他营建灵庙，却又因此沉沦于恶趣。）

【按】“不复兴恭敬”之“兴”，宫本作“与”。“摩诃罗”，指年老无知的比丘。

原文：“若少欲众生”（大意：若少欲的众生。“少欲”在此所指未详，存疑。）

#### 五组十种清净尸罗

“再者，舍利子！菩萨摩诃萨行尸罗波罗蜜多时，这样精勤修行戒行，为了求菩萨藏，以身承事正行的诸师，获得如上所说的功德，又获得倍过前数的无量无边、不可思议的功德利益。舍利子！应当知道，菩萨摩诃萨安住于这样的菩萨藏，行善妙自在、美妙清净之戒的诸菩萨行。舍利子！什么名为妙戒清净？舍利子！菩萨摩诃萨因行尸罗波罗蜜多，获得十种清净尸罗，你应当知道。是哪十种？一是对众生从无损害；二是对他人财物不行劫盗；三是对他人妻妾远离种种染习；四是对众生不兴欺诳；五是和合眷属，无有乖离；六是对众生不起粗言，因为能堪忍他们的恶言；七是远离绮语，因为凡有所言，都审谛而说；八是远离贪著，因为对他人的受用没有我所之想；九是远离瞋恚，因为善能忍受粗言辱骂；十是远离邪见，因为不敬事其余诸天仙以及神鬼。舍利子！这是菩萨摩诃萨行尸罗波罗蜜多时获得的十种清净尸罗，应当这样修学。

【按】“远离贪著”之“离”，宋、元、明、宫本作“诸”。

“再者，舍利子！菩萨摩诃萨行尸罗波罗蜜多时，又有十种清净尸罗，你现在应当知道。是哪十种？一是不缺的尸罗，因为不是由无智所证；二是不穿的尸罗，因为远离不平等之生；三是不斑杂的尸罗，因为不被一切烦恼所混杂；四是不染的尸罗，因为只被白法所增长；五是应供的尸罗，因为随其所欲而自在行；六是受称赞的尸罗，因为不被诸聪慧者所呵毁；七是不受诃呰的尸罗，因为不容受一切过恶；八是善护的尸罗，因为善能守护诸根之门；九是善守的尸罗，因为自然正智恒常现前；十是善趣的尸罗，因为以大菩提愿为助伴。舍利子！这是菩萨摩诃萨行尸罗波罗蜜多时获得的十种清净尸罗，应当这样修学。

“再者，舍利子！菩萨摩诃萨因行尸罗波罗蜜多，又有十种清净尸罗，你现在应当知道。是哪十种？一是少欲的尸罗，因为如法清净，善知分量；二是知足的尸罗，因为永断一切贪著；三是正行的尸罗，因为能令身心都远离；四是住于寂静的尸罗，因为对种种喧闹都舍离远避；五是杜多功德、蠲除嗜欲的尸罗，因为是自在善根所成；六是圣种知足的尸罗，因为不看他人颜色，无所希望；七是如说而行的尸罗，因为幽明之中都奉持摄护，不欺人天；八是自省己过的尸罗，因为常以法镜照了自心；九是不讥他人过失的尸罗，因为顾护他人之意；十是成熟众生的尸罗，因为不舍诸摄法。舍利子！这是菩萨摩诃萨因行尸罗波罗蜜多而获得的十种清净尸罗，应当这样修学。

【按】“愦閙”之“愦”，宋、元、明、宫本作“阓”。“杜多”即头陀。

“再者，舍利子！菩萨摩诃萨行尸罗波罗蜜多时，又有十种清净尸罗，你现在应当知道。是哪十种？一是对佛净信的尸罗，因为离开心中的疑根；二是对法净信的尸罗，因为守护正法；三是对僧净信的尸罗，因为恭敬圣众；四是俯身屈己从事的尸罗，因为不离思惟佛的菩提；五是亲近善友的尸罗，因为善于积集觉分的资粮；六是远离恶友的尸罗，因为弃舍一切不善之法；七是大慈波罗蜜多的尸罗，因为成熟一切众生；八是大悲波罗蜜多的尸罗，因为令困厄的众生解脱；九是大喜波罗蜜多的尸罗，因为对于那正法生起喜乐；十是大舍波罗蜜多的尸罗，因为对于爱与恚都能舍弃。舍利子！这是菩萨摩诃萨因行尸罗波罗蜜多而获得的十种清净尸罗，应当这样修学。

原文：“于佛净信尸罗，离心栽枿故”（大意：对佛净信的尸罗，因为离开心中的栽枿。“栽枿”所指未详，存疑。）

“再者，舍利子！菩萨摩诃萨行尸罗波罗蜜多时，又有十种清净尸罗，你现在应当知道。是哪十种？一是柁那波罗蜜多的尸罗，因为善于成熟众生；二是羼底波罗蜜多的尸罗，因为善护一切众生之心；三是毘利耶波罗蜜多的尸罗，因为对于诸正行不退转；四是静虑波罗蜜多的尸罗，因为善于满足静虑的资粮；五是般若波罗蜜多的尸罗，因为对于听闻的根本无有厌足；六是乐求闻法的尸罗，因为常乐请求菩萨藏；七是不顾惜身的尸罗，因为以无常之想恒常观察；八是不珍重生命的尸罗，因为常以如幻之心现前观察；九是诸意满足的尸罗，因为从初发心就善加清净；十是与佛戒和合的尸罗，因为回向如来的一切戒。舍利子！这是菩萨摩诃萨因行尸罗波罗蜜多而获得的清净尸罗，应当这样修学。

【按】“毘利耶”之“利”，明本作“梨”。

“再者，舍利子！这些菩萨摩诃萨行尸罗波罗蜜多时，由于具足这样的清净戒：没有任何人天的美妙快乐是这些菩萨所不受用的；没有任何世间的工巧业处是这些菩萨所不知道的；没有任何世间众生所受用的资具是这些菩萨不能感得的；没有凡夫不互相为怨，而这位菩萨对那些众生从无瞋恚；没有任何世间的虚诳妄语是菩萨听了不信受的；没有任何世间众生是菩萨不对之起母亲之想的；没有任何世间众生是菩萨不对之生父亲之想的；没有任何世间众生是菩萨不对之生保任亲附之想的；没有任何有为之法是菩萨不对之起无常生灭之想的。舍利子！菩萨摩诃萨了知诸行都是无常之后，不顾身命，修清净戒，行诸菩萨所行的正行，都为了成满尸罗波罗蜜多。”

【按】“工巧业处”之“业”，《大正藏》作“等”，CBETA依高丽藏、碛砂藏作“业”，今从之。

【按】“无有世间虚诳妄语菩萨于彼不生信受”一句，与下文偈颂“或设虚妄言，有闻皆信受”相应，依之译出。

那时世尊想重宣此义，而说颂道：

```
妙色妙音声，能济乐法者，
菩萨未为难，住净尸罗故。
面目皆圆净，不生盲跛伛，
诸身分端正，皆由净戒生。
具大力大势，赫奕大威光，
复由精进慧，令恶魔惊怖。
诸王咸供养，天龙所尊敬，
善断诸疑网，深心行大慈。
安住于戒聚，法行大名称，
苦逼不生畏，终不堕恶道。
众生皆惛睡，菩萨能觉之，
常无有暂眠，遍四方求法。
安住于戒聚，为求菩提道，
舍最上名珍，妻子身肉等，
求最胜法教，及无上佛法，
于世间所依，应修诸供养。
若诃责骂詈，恼害兴恶行，
加哀及赞美，斯由住忍故。
```
（大意：美妙之色、美妙之音声，能救济乐法的人，对菩萨并非难事，因为住于清净尸罗。面目都圆满清净，不生为盲、跛、驼背，诸身分端正，都由清净戒所生。具大力、大势，赫奕的大威光，又由于精进与智慧，令恶魔惊怖。诸王都来供养，为天龙所尊敬，善断种种疑网，以深心行大慈。安住于戒聚，奉行正法，有大名称，被苦逼迫也不生畏惧，终不堕于恶道。众生都昏睡，菩萨能令他们觉醒，常无片刻睡眠，遍于四方求法。安住于戒聚，为求菩提之道，舍弃最上的名贵珍宝、妻子、身肉等，求取最胜的法教以及无上佛法，对于世间所依止的人，应当修种种供养。若有人呵责、骂詈、恼害、兴起恶行，他却加以哀悯以及赞美，这是由于住于忍辱。）

【按】“深心行大慈”之“心”，宋、元、明、宫本作“修”。“苦逼不生畏”之“苦”，《大正藏》作“若”，CBETA依高丽藏作“苦”，今从之。

```
如所说修行，言常不虚诳，
安坐道场已，震动于大地。
于佛法无疑，舍离邪天众，
恒事天所尊，谓佛薄伽梵。
世间诸众生，刀杖等相加，
能令彼和合，是为聪敏相。
众生受重苦，多百拘胝劫，
虽不来见求，若覩常无舍。
善友交谈论，义利由斯获，
而众生不求，反更相加害。
我以赡部洲，及诸佛国土，
满中珍宝聚，用资求善友。
假使以利刀，割断我支节，
于彼众生类，常行平等心。
舍愚夫作业，为佛法因缘，
常守净尸罗，安住微妙法。
修习法随法，行菩提妙行，
为求佛菩提，三明慧甘露。
```
（大意：如所说而修行，言语常不虚诳，安坐于道场之后，震动大地。对于佛法没有疑惑，舍离邪天之众，恒常奉事天所尊敬的，就是佛薄伽梵。世间众生以刀杖等相加害，能令他们和合，这是聪敏之相。众生受重苦，经许多百拘胝劫，虽然不来求见，若见到也常不舍弃。与善友交谈议论，由此获得义利；而众生不去求，反而互相加害。我以赡部洲以及诸佛国土中满满的珍宝之聚，用来资助求得善友。假使以利刀割断我的支节，对那些众生，我常行平等之心。舍弃愚夫的作业，为了佛法的因缘，常守清净尸罗，安住于微妙之法。修习法与随法，行菩提妙行，为求佛的菩提，以及三明智慧的甘露。安住于戒聚，修学诸佛之法，这是聪慧者，是天人世间应当供养的。）

【按】“谓佛薄伽梵”之“佛”，宋、元、明、宫本作“供”。“行菩提妙行”之“菩提”，《大正藏》作“菩萨”，CBETA依高丽藏、碛砂藏作“菩提”，今从之。

```
安住于戒聚，修学诸佛法，
是为聪慧者，天世应修供。
一切法无疑，善达诸工巧，
深晓众生意，弘扬美妙法。
戒聚已清净，安坐菩提树，
降伏恶魔军，悟无上正觉。
扬晖满世界，犹如日月光，
菩萨有情尊，能开圣慧眼。
授手引群生，问道皆开示，
常欢笑先言，曾无怀嫉恚。
舍无量自身，及施多财宝，
未尝有远离，最上佛菩提。
信戒已圆具，善住谛实言，
曾无有幻伪，安住尸罗聚。
诸来菩萨所，或设虚妄言，
有闻皆信受，而恒依谛语。
若有许菩萨，假言衣食施，
终无有惠及，菩萨无恚心。
```
（大意：对一切法没有疑惑，善能通达种种工巧，深晓众生之意，弘扬美妙之法。戒聚已经清净，安坐菩提树下，降伏恶魔军，觉悟无上正觉。光辉充满世界，犹如日月之光，菩萨是有情之尊，能开启圣慧之眼。伸手接引众生，问道者都为他开示，常欢笑而先开口问候，从不怀嫉恚。舍弃无量的自身，以及布施许多财宝，从未远离最上的佛菩提。信与戒已圆满具足，善住于谛实之言，从未有幻伪，安住于尸罗之聚。诸来到菩萨所的人，或者设虚妄之言，菩萨听了都信受，而自己恒依于谛实之语。若有人许诺菩萨，假言要施予衣食，终究没有给予，菩萨也无恚心。）

【按】“嫉恚”之“恚”，元、明本作“妬”。
