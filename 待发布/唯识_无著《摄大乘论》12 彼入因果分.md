彼入因果分第五

一、六波罗蜜多是入唯识的因与果

上面已经说了入所知相，彼入的因与果应当如何看待？就是由布施、持戒、忍辱、精进、静虑、般若六种波罗蜜多。

如何由六波罗蜜多得入唯识？又如何六波罗蜜多成为彼入的果？菩萨不贪著财位，不违犯尸罗，对苦不动摇，对修行不懈怠；在上面所说的种种散动之因不现行的时候，心专注一境，就能如理简择诸法，得入唯识。菩萨依六波罗蜜多入唯识以后，证得六种清净增上意乐所摄的波罗蜜多。所以，菩萨在入唯识之后，即使离开六种波罗蜜多的现起加行，由于对圣教得到胜解，以及由于爱重、随喜、欣乐等作意，恒常无间、相应方便地修习六种波罗蜜多，也能迅速圆满。

【世亲释】“现起加行”，是波罗蜜多现行的加行。“对圣教得到胜解”，是对与波罗蜜多相应的圣教，即使极其甚深，也能信解。“爱重作意”，是对波罗蜜多见到殊胜功德而深生爱味。“欣乐作意”，是愿自己和一切有情，都能证得如同诸佛已到最胜彼岸的清净意乐。

二、清净增上意乐的七相

关于清净增上意乐，有三颂：

```
已圆满白法
及得利疾忍
菩萨于自乘
甚深广大教
等觉唯分别
得无分别智
悕求胜解净
故意乐清净
前及此法流
皆得见诸佛
了知菩提近
以无难得故
```

大意：菩萨已经圆满白净之法，并得到锐利迅疾的忍；对自乘甚深广大的教法，平等觉知唯是分别，得到无分别智；希求与胜解清净，所以意乐清净。在意乐清净之前与之中，在法流定中都得见诸佛；了知菩提已近，因为已不难证得。

由上面三颂，总显清净增上意乐有七种相：资粮，堪忍，所缘，作意，自体，瑞相，胜利。颂中诸句依次显示七相。

【世亲释】七相依次是：资粮，“已圆满白法”，在胜解行地已善备资粮。堪忍，“得利疾忍”，忍有软、中、上三品，最上品称为利疾忍。所缘，“于自乘甚深广大教”，法无我性是甚深之事，虚空藏等三摩地是广大之事。作意，“等觉唯分别，得无分别智”，觉知一切法唯有分别，就能获得无分别智。自体，“悕求胜解净”，欲（希求）与信（胜解）都清净，所以意乐清净。瑞相，“前及此法流，皆得见诸佛”，“前”是意乐清净位之前，“此”是意乐清净位之中，“法流”是定位，都能见佛。胜利，“了知菩提近”，因为已得能证菩提的殊胜方便，所以不难证得。

三、为什么只有六数

为什么波罗蜜多只有六数？因为要成立对治所治之障，因为是证得诸佛之法的所依处，因为随顺成熟诸有情。

为了对治不发趣的原因，建立布施、持戒波罗蜜多；不发趣的原因，是贪著财位和贪著家室。为了对治已经发趣、又退还的原因，建立忍辱、精进波罗蜜多；退还的原因，是处在生死中，有情违犯所生的众苦，以及长时修习善品加行所生的疲倦。为了对治已经发趣、不再退还、仍会失坏的原因，建立静虑、般若波罗蜜多；失坏的原因，是种种散动和邪恶的智慧。由于成立对治所治之障，所以只立六数。

又，前四种波罗蜜多是不散动的因，第五种波罗蜜多是不散动的成就。以不散动为依止，如实等觉诸法的真义，就能证得一切佛法。由于是证得诸佛之法的所依处，所以只立六数。

由布施波罗蜜多，对诸有情能正确摄受。由持戒波罗蜜多，对诸有情能不毁害。由忍辱波罗蜜多，遭到毁害也能忍受。由精进波罗蜜多，能帮助经营有情所应作的事。由上面的摄受利益的因缘，使诸有情对成熟之事有所堪任。从此以后，心未得定的令其得定，心已得定的令其解脱，在开悟的时候，有情得以成熟。由于随顺成熟一切有情，应当了知只立六数。

四、六种最胜

六种波罗蜜多的相应当如何看待？由六种最胜。第一，由所依最胜，以菩提心为所依。第二，由事最胜，具足现行。第三，由处最胜，以一切有情的利益安乐之事为依处。第四，由方便善巧最胜，被无分别智所摄受。第五，由回向最胜，回向无上正等菩提。第六，由清净最胜，由烦恼障、所知障二障的无障所集起。

布施就是波罗蜜多吗？波罗蜜多就是布施吗？有布施而不是波罗蜜多，应当作四句分别。如同布施，其余波罗蜜多也应当作四句，如理了知。

【世亲释】“事最胜”，是对内外一切事物都具足现行，只有菩萨能如此。“方便善巧最胜”，是三轮清净，不分别施物、施者、受者，被无分别智所摄。“清净最胜”，是到佛果时布施等才真正清净，因为那时已经解脱二障。四句是：有布施而不是波罗蜜多，就是离开六种最胜而布施；有波罗蜜多而不是布施，就是六种最胜所摄的持戒等；有既是布施又是波罗蜜多，就是六种最胜所摄的布施；有既不是布施也不是波罗蜜多，就是离开六种最胜的持戒等。

五、次第与训释

为什么六种波罗蜜多按上面的次第宣说？因为前一种波罗蜜多随顺生起后一种波罗蜜多。

又，诸波罗蜜多的训释名言应当如何看待？布施等善根，在一切世间、声闻、独觉的布施等善根中最为殊胜，能到彼岸，所以通称为波罗蜜多。又，能破裂悭吝和贫穷，并能引得广大的财位与福德资粮，所以称为施。能息灭恶戒与恶趣，并能取得善趣与等持，所以称为戒。能灭尽忿怒与怨仇，并能使自他安稳而住，所以称为忍。能远离一切懈怠与恶不善法，并能出生无量善法、令其增长，所以称为精进。能消除一切散动，并能引得内心安住，所以称为静虑。能除遣一切见趣与邪恶之慧，并能真实地分别了知诸法，所以称为慧。

六、五种修习与六种意乐

应当如何了知修习波罗蜜多？应当了知，修习简略有五种：第一，现起加行修；第二，胜解修；第三，作意修；第四，方便善巧修；第五，成所作事修。前四种修习如前已说。成所作事修，就是诸如来任运作佛事，没有休息；在已经圆满的波罗蜜多上，又更修习六种到彼岸。

【世亲释】诸如来安住法身，无功用地作佛事，常无休息；六种波罗蜜多不再现行，为了摄益诸有情，恒常现行而成所作之事。

作意修，就是修习六种意乐所摄的爱重、随喜、欣乐作意。六种意乐是：第一，广大意乐；第二，长时意乐；第三，欢喜意乐；第四，荷恩意乐；第五，大志意乐；第六，纯善意乐。

如果诸菩萨要经过若干无数大劫，才现证无上正等菩提，在其间的每一刹那中，假使一时舍弃一切身命，又以殑伽河沙数世界盛满七宝奉施如来，直到安坐妙菩提座，菩萨布施的意乐仍然没有厌足。在其间的每一刹那中，假使三千大千世界中充满炽火，在行住坐卧四威仪中，常常缺乏一切资生用具，持戒、忍辱、精进、静虑、般若之心恒常现行，直到安坐妙菩提座，菩萨的持戒、忍辱、精进、静虑、般若意乐仍然没有厌足。称为菩萨的广大意乐。

又，诸菩萨对无厌足的意乐，直到安坐妙菩提座，常常没有间断。称为菩萨的长时意乐。

又，诸菩萨以六种波罗蜜多饶益有情，对所作的饶益深生欢喜，受益的有情的欢喜也比不上。称为菩萨的欢喜意乐。

又，诸菩萨以六种波罗蜜多饶益有情，见有情对自己有大恩德，不见自己对有情有恩。称为菩萨的荷恩意乐。

又，诸菩萨以六种到彼岸所积集的善根，深心回施一切有情，令有情得到可爱殊胜的果报。称为菩萨的大志意乐。

又，诸菩萨又以六种到彼岸所积集的善根，与诸有情共同回求无上正等菩提。称为菩萨的纯善意乐。

如上所说，菩萨修习六种意乐所摄的爱重作意。又，诸菩萨对其余菩萨修习六种意乐相应的无量善根，深心随喜；如上所说，菩萨修习六种意乐所摄的随喜作意。又，诸菩萨深心欣乐一切有情六种意乐所摄的六种到彼岸修习，也愿自身与六种到彼岸修习恒不相离，直到安坐妙菩提座；如上所说，菩萨修习六种意乐所摄的欣乐作意。

如果有人听闻菩萨六种意乐所摄的作意修习，只要能生起一念信心，尚且能生起无量福聚，诸恶业障也将消灭，何况菩萨本身。

【世亲释】“每一刹那”的意思是：假使以三大阿僧祇劫的时量作为一刹那，如此的刹那积集起来，直到证得菩提，在其中的每一刹那都如此。三千大千世界充满炽火、缺乏资具，显示住处的艰难与资缘的匮乏。“诸恶业障也将消灭”，是灭除恶业能感异熟的功能，或对治恶业堕往恶趣的力量。

七、三品差别

诸波罗蜜多的差别应当如何看待？应当了知每一种各有三品。布施三品：第一，法施；第二，财施；第三，无畏施。持戒三品：第一，律仪戒；第二，摄善法戒；第三，饶益有情戒。忍辱三品：第一，耐怨害忍；第二，安受苦忍；第三，谛察法忍。精进三品：第一，被甲精进；第二，加行精进；第三，无怯弱、无退转、无喜足精进。静虑三品：第一，安住静虑；第二，引发静虑；第三，成所作事静虑。慧三品：第一，无分别加行慧；第二，无分别慧；第三，无分别后得慧。

【世亲释】法施资益他人的善根，财施资益他人的身体，无畏施资益他人的心。律仪戒是其余二戒的依持：安住律仪，才能建立摄善法戒，由此修集一切佛法；才能建立饶益有情戒，由此成熟有情。谛察法忍能审谛观察诸法，由此忍力建立前二种忍。

【世亲释】三种精进，就是契经所说的五句：“有势，有勤，有勇，坚猛，不舍善轭。”被甲精进是“有势”，最初发心的势力。加行精进是“有勤”，加行时能精勤。无怯弱是“有勇”，心不退屈；无退转是“坚猛”，遇生死之苦不退；无喜足是“不舍善轭”，不因得少许善就生喜足而不证菩提。安住静虑，能安住现法乐住；引发静虑，能引发六种神通；成所作事静虑，依此成办利益有情之事。

八、相摄、所治与胜利

上面的相摄应当如何看待？由于六波罗蜜多能摄一切善法：因为是一切善法之相，因为是随顺，因为是等流。

【世亲释】一切善法，就是一切菩提分法。“相”是般若之相；“随顺”是信、轻安等；“等流”是六种神通、十力等其余功德。

上面的所治，摄诸杂染，应当如何看待？因为是所治之相，因为是所治之因，因为是所治之果。

【世亲释】“相”，是贪等之相。“因”，是悭等之因，就是不信与邪见等。“果”，是悭吝、犯戒、忿怒等诸果。

上面六种波罗蜜多所得的胜利应当如何看待？诸菩萨流转生死时，由于富贵所摄，由于大生所摄，由于大朋大属所摄，由于广大事业加行成就所摄，由于没有种种恼害、本性烦恼淡薄所摄，由于善知一切工巧论议明处所摄，得到殊胜而无罪的生，直到安坐妙菩提座，常能现作一切有情的一切义利。称为胜利。

【世亲释】外道也得殊胜的生，因为被杂染污，所以有罪，又是无常，只能自利，不能利他。波罗蜜多所得的殊胜之生，直到安坐菩提座都不失，常能现作一切有情的义利。

九、互相抉择

上面六种波罗蜜多的互相抉择应当如何看待？世尊对六种波罗蜜多，有的地方以“施”之名来说，有的地方以“戒”之名来说，有的地方以“忍”之名来说，有的地方以“勤”之名来说，有的地方以“定”之名来说，有的地方以“慧”之名来说。上面的说法有什么意趣？在修习一切波罗蜜多的加行中，都有一切波罗蜜多互相助成，是上面的意趣。

【世亲释】比如修布施的时候，防护身与语，就有持戒波罗蜜多相助；了知布施的因果，就有般若波罗蜜多相助。其余互相助成，如理了知。

关于本分，有一首嗢拖南颂：

```
数相及次第
训词修差别
摄所治功德
互抉择应知
```

大意：本分所说，依次是：数量、相、次第、训释、修习、差别、相摄、所治、功德、互相抉择，应当了知。

下一篇：13　彼修差别分。论本说明菩萨十地，十相所知法界与十种无明，十地的名义，得地与修地，十地别修十波罗蜜多，以及修行诸地经三无数大劫。
