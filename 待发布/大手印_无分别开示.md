# 无分别开示

圣天（Āryadeva）造　据藏文译出

## 题解

《无分别开示》（梵 Nirvikalpaprakaraṇa，藏 rnam par mi rtog pa'i rab tu byed pa，直译"无分别之论"）收于德格版丹珠尔续部释 ཞི 函第 133a 至 134a 页（东北目录 D2279），紧接在《四偈半》（D2278）之后。跋语说是"大阿阇黎圣天"所造，由大班智达大悲（Mahākaruṇa）与玛班·法炬（rma ban chos 'bar）译出。玛班·法炬也是《五如来印释》《所缘修习》等的译者。

全篇共十五偈，主旨是"无分别"：一切由分别所遍计的事物都没有自性；偏离龙树之道、失去世俗谛的方便，就没有解脱；连禅修中喜乐的觉受也只是分别；事物不生，如空花、如乾闼婆城；五蕴空无自性，唯是自证明了，其中无能知所知、无心与心所，这就是无分别的自性；最后说，以无所缘之心安住，就成为无所缘。

**与前译重复，请留意：**本篇第六至十五偈（第 31–70 句），与此前已译出的《所缘修习》（D2277，藏文题名 dngos po sbyong ba，"事物之净治"，题为龙树所造，玛班·法炬与金刚手合译）的前十偈几乎相同，只是文字略有出入，次序也基本一致。可见这十偈是两部短论共用的偈颂，或者其中一部是从另一部摘出、改编而成的。本篇独有的，是前五偈（第 7–30 句）：遍计无自性、不可偏离龙树之道与世俗谛、分别之外无涅槃、禅悦也是分别、离贪与二者是三有之因。

本译对共同的十偈重新译出，各偈按语中列出《所缘修习》的异文，以便与前译对照；若译文措辞与前译有出入，请以两者对照，取义理一致者为准。另外，本篇第一偈"由何分别、遍计何物，那些遍计之物都没有自性"，与《所缘修习》后半"凡是以任何自体遍计任何诸法，那［所遍计的］在那上面都不存在"意思也相近。

体例：本篇是短篇偈颂，依本译对短篇的体例，每偈先列藏文原文于代码块中，再以完整的意义单元译出；为了便于理解而补的字，都放在方括号中。原文含混或可有两解之处，以"【按】"说明，不妄补内容。文末附通篇连读。

```
བོད་སྐད་དུ།
རྣམ་པར་མི་རྟོག་པའི་རབ་ཏུ་བྱེད་པ།
བླ་མ་དང་སངས་རྒྱས་ལ་ཕྱག་འཚལ་ལོ། །
```

梵语题名：Nirvikalpaprakaraṇa。藏语题名：《无分别开示》。

敬礼上师与佛！

## 第一偈　遍计之物无自性

```
རྣམ་པར་རྟོག་པ་གང་གང་གིས། །
དངོས་པོ་གང་དང་གང་བརྟགས་པ། །
ཡོངས་སུ་བརྟགས་པ་འདི་ཉིད་དག །
རང་བཞིན་ཡོད་མིན་པ་ཁོ་ན། །
```

无论以什么分别，遍计什么事物，这些被遍计的［事物］本身，都只是没有自性的。

## 第二偈　偏离龙树之道则无解脱

```
སློབ་དཔོན་ཀླུ་སྒྲུབ་ཞལ་སྔ་ཡི། །
ལམ་ལས་ཕྱི་རོལ་སོང་གྱུར་ཅིང་། །
ལེགས་པར་མངོན་པའི་ཐབས་མེད་པའི། །
ཀུན་རྫོབ་དེ་ཉིད་བདེན་པ་ལས། །
ཉམས་པས་ཐར་པའི་དངོས་གྲུབ་ནི། །
ཡོད་པ་མ་ཡིན་དེ་དག་ཉམས། །
```

那些走到阿阇黎龙树之道以外的人，没有［获得］增上生的方便，从世俗谛本身退失，所以没有解脱的悉地；他们是毁坏了的。

【按】"增上生"（legs par mngon pa，梵 abhyudaya），指人天善趣的果报，与"决定胜"（解脱）相对；获得增上生的方便，就是布施、持戒等世俗的善行。这一偈的意思是：偏离龙树中观之道的人，既不懂空性，也因否定世俗而失去了积累福德的方便，所以不能解脱。这与《真如十颂广释》第十九节"灭除世俗就落入断边"、《四偈半》第十七节"过于执著空性也会毁灭"的意思一致。

## 第三偈　分别之外无涅槃

```
གང་ཞིག་ལས་ལས་བྱུང་བ་ཡི། །
རྣམ་པར་རྟོག་པ་གང་ཅིའང་རུང་། །
དེ་དག་སྤངས་པའི་རང་བཞིན་ལས། །
མྱ་ངན་འདས་པ་གཞན་ན་ནི། །
ཡོད་མིན་ཡུལ་ནི་གང་དུ་ཡང་། །
རྣམ་པར་མི་སེམས་བདག་ཉིད་དོ། །
```

凡是由业所生的任何分别，从舍弃了这些的自性之外，在别处并没有涅槃；［涅槃］没有任何对境，是不思惟的自体。

【按】意思是：涅槃不在别处，就是舍弃了由业所生的种种分别的那个自性本身；它没有所缘的对境，是"不思惟"（rnam par mi sems）的体性。这与梅纪巴《不作意论证》的主旨相通。

## 第四偈　禅悦也只是分别

```
གང་ཡང་དགའ་བའི་རང་བཞིན་གྱིས། །
སེམས་ལ་བདེ་བ་འབྱུང་གྱུར་ཅིང་། །
ཉམས་སུ་མྱོང་བའི་སར་ཕྱིན་པ། །
དེ་ཡང་ཀུན་དུ་རྟོག་པ་ཙམ། །
```

凡是以喜悦的自性，在心中生起安乐，而到达了体验之地的，那也只是遍计而已。

【按】这一偈是对修行人的重要告诫：禅修中生起的喜乐、种种觉受（nyams su myong ba），即使似乎是很高的境界，也只是分别遍计，不是无分别的真性。这与《四偈半》第十六节"若以造作的心贪著造作的安乐，就不能渡过轮回之海"的意思一致。

## 第五偈　离贪与二者也是三有之因

```
གང་དེ་འདོད་ཆགས་བྲལ་བ་ཡི། །
རང་གི་ངོ་བོ་དེ་དག་དང་། །
གཉིས་པོ་གང་ཡིན་པ་དེ་ནི། །
སྲིད་པའི་རྒྱུ་ཡི་མཆོག་ཡིན་ནོ། །
```

那远离贪欲的［状态］、［与贪欲相关的］那些自体，以及凡是这两者，那就是三有最上的因。

【按】这一偈的文字很简略，意思不容易确定。一种理解是：不仅贪欲是轮回之因，执著"离贪"也是；凡是落入"贪"与"离贪"二者之中的，都是三有之因。另一种理解是："离贪者的自体"指禅定中离欲的境界（如色界、无色界的禅定），它与贪欲两者，都是三有之因。两种理解都说明：只要还有对立的分别，就仍是轮回之因。"最上的因"（rgyu yi mchog），意思大约是"根本的因"，存疑。

## 第六偈　事物不生，如空花

```
དངོས་པོ་དངོས་པོ་ལས་མི་སྐྱེ། །
དངོས་པོ་དངོས་མེད་ལས་ཀྱང་མིན། །
དངོས་པོ་སྐྱེ་བ་རྟག་ཏུ་སྤངས། །
དངོས་འཁྲུལ་ནམ་མཁའི་མེ་ཏོག་བཞིན། །
```

事物不从事物生，事物也不从非事物生；事物之生永远被舍离，对事物的迷乱就像空中的花。

【按】这一偈对应《所缘修习》第一偈，《所缘修习》作：

```
དངོས་པོ་མེད་ལ་དངོས་པོར་ཤེས། །
དངོས་མེད་སྐྱེ་བ་ཡོད་མ་ཡིན། །
རྟག་ཏུ་སྐྱེ་བ་དངོས་པོ་ཉིད། །
དངོས་འཁྲུལ་ནམ་མཁའི་མེ་ཏོག་བཞིན། །
```

前三句文字不同（"于非事物知为事物，非事物没有生，恒常之生就是事物"），第四句相同，意思大致相通。

## 第七偈　一切法与虚空相等

```
མཁའ་དང་མཉམ་པའི་ཆོས་རྣམས་ཀུན། །
སྐྱེ་བ་མཁའ་དང་མཉམ་པ་ཉིད། །
རྐྱེན་ནི་མཁའ་དང་མཉམ་ཀུན་ངེས། །
སྲིད་པར་གྱུར་པ་བདེན་པ་ཡིན། །
```

一切与虚空相等的法，它们的生也与虚空相等；诸缘也必定都与虚空相等，［这样］成为三有的，［才是］真实［的情况］。

【按】这一偈对应《所缘修习》第二偈，《所缘修习》作：

```
མཁའ་དང་མཉམ་པའི་ཆོས་རྣམས་ནི། །
སྐྱེ་བ་མཁའ་དང་མཉམ་ཉིད་མཆོག །
ཐམས་ཅད་རང་བཞིན་གྱིས་མཁའ་མཉམ། །
དེས་ན་སྲིད་པ་དམ་པའི་དངོས། །
```

第四句两本差别较大：本篇作"སྲིད་པར་གྱུར་པ་བདེན་པ་ཡིན"（成为三有的是真实），《所缘修习》作"དེས་ན་སྲིད་པ་དམ་པའི་དངོས"（所以三有就是殊胜之事）。本篇这一句的意思不很清楚，可以理解为：三有的真实情况，就是与虚空相等；这里依此译出，存疑。

## 第八偈　无因无果，世间不实

```
རྒྱུ་མེད་འབྲས་བུ་མེད་གྱུར་ཅིང་། །
ལས་ཀྱི་རང་བཞིན་ཡོད་མ་ཡིན། །
འཇིག་རྟེན་པ་མེད་འཇིག་རྟེན་མེད། །
མི་བརྟན་པར་གྱུར་ཆོས་འདི་ཀུན། །
```

没有因，也没有果，业的自性也不存在；没有世间之人，也没有世间，这一切法都是不坚固的。

【按】这一偈对应《所缘修习》第三偈，第四句《所缘修习》作"འདི་དག་ཐམས་ཅད་བདེན་མ་ཡིན"（这一切都不真实），本篇作"不坚固"，意思相同。这里所说的"没有因果、没有业"，是就胜义而说的，不是否定世俗的因果；正如第二偈所说，否定世俗谛的人没有解脱。

## 第九偈　不生之物不可知，如石女儿

```
མ་སྐྱེས་པས་ནི་དངོས་པོ་གང་། །
ཇི་ལྟར་གཞན་ལས་ཤེས་པར་གྱུར། །
མོ་གཤམ་བུ་ཡི་བཞིན་ཡང་ནི། །
དེ་ལྟར་ཤེས་པར་མི་ནུས་སོ། །
```

因为不生，所以任何事物，怎么能从别的［事物］而被了知呢？就像石女的儿子的面容一样，那样是不能被了知的。

【按】这一偈对应《所缘修习》第四偈，后两句《所缘修习》作"མོ་གཤམ་གྱི་ནི་བུ་ཉིད་ཀྱང་། དེ་ཚེ་སྐྱེ་བར་འགྱུར་མ་ཡིན"（石女的儿子，那时也不会出生），本篇作"就像石女儿子的面容，那样是不能被了知的"，比喻相同而说法不同。"面容"，藏文作"བཞིན"，也可以读作"像……一样"，存疑。

## 第十偈　世间如乾闼婆城

```
འཇིག་རྟེན་གཟོད་ནས་མ་སྐྱེས་ཏེ། །
གང་གིས་ཀྱང་ནི་སྤྲུལ་པ་མེད། །
དོན་མེད་འཁྲུལ་པའི་འཇིག་རྟེན་འདི། །
དྲི་ཟའི་གྲོང་ཁྱེར་ཇི་བཞིན་ནོ། །
```

世间从本以来就是不生的，也不是由任何［造物者］所化现的；这没有实义的、迷乱的世间，就像乾闼婆城一样。

【按】这一偈对应《所缘修习》第五偈，第四句《所缘修习》作"ཟླ་བ་བཟང་པོའི་གྲོང་ཁྱེར་བཞིན"（像月贤之城），本篇作"དྲི་ཟའི་གྲོང་ཁྱེར"（乾闼婆城）。"乾闼婆城"即海市蜃楼，是佛经中常见的幻喻；"月贤之城"意思不明，可能是"乾闼婆城"的另一种译法或误写，本篇的读法较为通顺。"不是由任何［造物者］所化现的"，是破斥大自在天等造物主之说。

## 第十一偈　世间生于分别，分别生于心

```
རྣམ་རྟོག་ལས་གང་འཇིག་རྟེན་འབྱུང་། །
རྣམ་རྟོག་སེམས་ལས་བྱུང་བ་སྟེ། །
གང་ཕྱིར་ལུས་ལས་སེམས་བྱུང་བས། །
དེ་ཕྱིར་ལུས་ལ་རྣམ་པར་བརྟག །
```

世间从分别而生起，分别是从心所生的；因为心是从身而生的，所以要对身加以观察。

【按】这一偈对应《所缘修习》第六偈，第一句《所缘修习》作"འཇིག་རྟེན་རྣམ་པར་རྟོག་ལས་འབྱུང"，本篇作"རྣམ་རྟོག་ལས་གང་འཇིག་རྟེན་འབྱུང"，意思相同。"心是从身而生的"，这里不是说心以身体为本源（那是唯物论者的说法），而是说在凡夫的经验中，心依身而起，所以观察心的源头，要从观察身体入手，下一偈就从五蕴（以色蕴为首）开始观察，存疑。

## 第十二偈　五蕴无自性，唯是自证明了

```
གཟུགས་སྟོང་ཚོར་བ་རང་བཞིན་མེད། །
འདུ་ཤེས་མེད་ཅིང་འདུ་བྱེད་ཀྱིས། །
དངོས་པོ་ཡོད་པ་མ་ཡིན་ཏེ། །
རང་རིག་གསལ་བའི་བདག་ཉིད་དོ། །
```

色是空的，受没有自性，想不存在，由行［而有的］事物也不存在，［唯］是自证明了的体性。

【按】这一偈对应《所缘修习》第七偈，后半两本差别较大：《所缘修习》作"འདུ་ཤེས་མེད་ཅིང་འདུ་བྱེད་མེད། སེམས་བྱུང་མེད་ཅིང་དངོས་པོ་མེད"（没有想，没有行，没有心所，没有事物）；本篇作"没有想，由行［而有的］事物也不存在，［唯］是自证明了的体性"，多了"自证明了的体性"（rang rig gsal ba'i bdag nyid）一句。这一句是本篇的特色：五蕴虽然都空无自性，却不是断灭，而是"自证明了"，即心性本身的明觉。这与梅纪巴一系"光明即自证"（《真如十颂广释》第二十六节）的说法一致。

## 第十三偈　无能知所知，即无分别的自性

```
དེ་ལ་ཤེས་དང་ཤེས་བྱ་མེད། །
སེམས་དང་སེམས་ལས་བྱུང་བ་མེད། །
འབྱུང་བ་མེད་དེ་དེ་ཡི་ཕྱིར། །
རྣམ་པར་མི་རྟོག་རང་བཞིན་ནོ། །
```

在那里，没有能知与所知，没有心与心所；因为没有生起，所以就是无分别的自性。

【按】这一偈与《所缘修习》第七偈后半、第八偈前半相应，《所缘修习》作"དེ་ཕྱིར་མི་རྟོག་རང་བཞིན་ནོ"（所以是无分别的自性），本篇第四句相同，前三句为本篇所增，说明"无分别"的意思：在自证明了中，没有能知所知的二分，没有心与心所的生起。这正是本篇题名"无分别"的所在。

## 第十四偈　无二之道

```
དེ་ནི་སེམས་མིན་ལུས་ཀྱང་མིན། །
ཁམས་རྣམས་མ་ཡིན་ཆོས་ཀྱང་མིན། །
གཉིས་སུ་མེད་པའི་ལམ་མཆོག་འདི། །
དེ་ཉིད་རིག་པ་རྣམས་ཀྱིས་གསུངས། །
```

它不是心，也不是身，不是诸界，也不是法；这殊胜的无二之道，是通达真性的人们所宣说的。

【按】这一偈对应《所缘修习》第八偈，《所缘修习》作"དེས་ན་སེམས་མིན་ཆོས་ཀྱང་མིན། ལུས་མིན་ཁམས་ལ་སོགས་པ་མིན། གཉིས་སུ་མེད་པའི་ལམ་འདི་ནི"，词序稍有不同，本篇多一"殊胜"（mchog）字，意思相同。

## 第十五偈　以无所缘之心而成无所缘

```
དམིགས་པ་མེད་པའི་ཆོས་འདི་ཀུན། །
དམིགས་པ་མེད་ལས་རབ་ཏུ་གྲོལ། །
དམིགས་མེད་བློ་ཡི་ངང་བྱས་ན། །
དམིགས་པ་མེད་པར་འགྱུར་བ་ཡིན། །
```

这一切无所缘的法，都从无所缘中彻底解脱；若使心安住于无所缘的状态，就会成为无所缘。

【按】这一偈对应《所缘修习》第九偈，第二、三句两本不同：《所缘修习》作"དམིགས་པ་མེད་པར་རབ་ཏུ་བསྟན། དམིགས་པ་མེད་པའི་བློ་བྱས་ན"（被开示为无所缘；若作无所缘之心），本篇作"དམིགས་པ་མེད་ལས་རབ་ཏུ་གྲོལ། དམིགས་མེད་བློ་ཡི་ངང་བྱས་ན"（从无所缘中彻底解脱；若使心安住于无所缘的状态）。本篇的"安住于……状态"（ngang byas），更明确地指向修持：不是另外造作一个"无所缘"的念头，而是让心安住在本来无所缘的状态中。"从无所缘中彻底解脱"，意思可能是"以无所缘而彻底解脱"，存疑。

《所缘修习》在这一偈之后，还有说六度、方便智慧、名言唯假等内容，本篇则到此结束。

## 跋

```
རྣམ་པར་མི་རྟོག་པའི་རབ་ཏུ་བྱེད་པ་སློབ་དཔོན་ཆེན་པོ་ཨཱརྱ་དེ་ཝའི་ཞལ་སྔ་ནས་མཛད་པ་རྫོགས་སོ།། །།
པཎྜི་ཏ་ཆེན་པོ་མ་ཧཱ་ཀཱ་རུ་ཎ་དང་།
བོད་ཀྱི་ལོ་ཙཱ་བ་རྨ་བན་ཆོས་འབར་གྱིས་བསྒྱུར་བའོ།།
```

《无分别开示》，大阿阇黎圣天所造，圆满。

大班智达大悲与西藏译师玛班·法炬译出。

【按】"圣天"（Āryadeva），一般指龙树的弟子、《四百论》的作者；但丹珠尔续部中题为"圣天"所造的论典，有些是后期密乘的圣天（又称"提婆"）所造，与《四百论》的作者是否同一人，学界有不同看法。本篇第二偈说"走到阿阇黎龙树之道以外的人……没有解脱"，以龙树之道为准则，符合圣天作为龙树弟子的身份，但也可能是后期托名，存疑。"大悲"（Mahākaruṇa），是与玛班·法炬合译的印度班智达。"玛班·法炬"，见《五如来印释》《慈五颂》跋语按语。

## 通篇连读

敬礼上师与佛！

无论以什么分别、遍计什么事物，这些被遍计的事物，都只是没有自性的。

那些走到阿阇黎龙树之道以外的人，没有获得增上生的方便，从世俗谛本身退失，所以没有解脱的悉地，他们是毁坏了的。

凡是由业所生的任何分别，离开舍弃了它们的那个自性，在别处并没有涅槃；涅槃没有任何对境，是不思惟的自体。

凡是以喜悦的自性在心中生起安乐、到达了体验之地的，那也只是遍计而已。

那远离贪欲的状态、那些自体，以及凡是这两者，就是三有最上的因。

事物不从事物生，也不从非事物生；事物之生永远被舍离，对事物的迷乱就像空中的花。

一切与虚空相等的法，它们的生也与虚空相等；诸缘也必定都与虚空相等，这样成为三有的，才是真实的情况。

没有因，也没有果，业的自性也不存在；没有世间之人，也没有世间，这一切法都是不坚固的。

因为不生，任何事物怎么能从别的事物而被了知呢？就像石女儿子的面容一样，那样是不能被了知的。

世间从本以来就是不生的，也不是由任何造物者所化现的；这没有实义的、迷乱的世间，就像乾闼婆城一样。

世间从分别而生起，分别是从心所生的；因为心是依身而起的，所以要对身加以观察。

色是空的，受没有自性，想不存在，由行而有的事物也不存在，唯是自证明了的体性。

在那里，没有能知与所知，没有心与心所；因为没有生起，所以就是无分别的自性。

它不是心，也不是身，不是诸界，也不是法；这殊胜的无二之道，是通达真性的人们所宣说的。

这一切无所缘的法，都从无所缘中彻底解脱；若使心安住于无所缘的状态，就会成为无所缘。

《无分别开示》，大阿阇黎圣天所造，圆满。大班智达大悲与西藏译师玛班·法炬译出。
