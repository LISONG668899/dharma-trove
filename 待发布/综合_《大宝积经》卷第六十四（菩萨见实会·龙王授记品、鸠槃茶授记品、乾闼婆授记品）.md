# 《大宝积经》卷第六十四（菩萨见实会·龙王授记品、鸠槃茶授记品、乾闼婆授记品）

北齐·三藏那连提耶舍 译

## 菩萨见实会第十六之四

【按】会名“菩萨”二字，宫本无。

### 龙王授记品第七

#### 诸龙王兴云供佛

那时难陀、优波难陀龙王等九亿诸龙，见到诸龙女设置美妙的供养，以及听到龙女得到授记之后，生起稀有之心、未曾有之心，这样思惟：“如来、世尊、应、正遍知实在稀有，未曾有过。因为如来了知众生的根机，令其深信如来，没有少分不见、不闻、不证如来的正法；他善于宣说，能令大众听了之后，当下便知，不待时节，随根机授法，必定令其得果，令诸智者现前证知。乃至女人动转轻躁，智慧浅短，尚且能理解佛所说的深法，何况其余的智者、善能安住于如来法中的诸弟子众。”诸女人欲心增上、瞋心增上、痴心增上，尚且能了知如来所说。所以难陀、优波难陀龙王以及诸龙等对如来生起稀有之心、生起未曾有之心，为了供养，在阎浮提诸山与大海兴起云，遍覆一切世间，普降香水，成为香泥。那香泥之气充满三千大千佛刹，其中众生闻到香气的，都不退失于阿耨多罗三藐三菩提。在迦毘罗城纵广正好六十由旬，降下赤真珠，遍覆其地，又以无价的种种众宝周匝遍覆尼拘陀园。又以龙花化成美妙的殿堂，纵广正好六十由旬，椽、柱、梁、壁都用七宝。又化作无量乐器，为了供养而击出美妙的音声。在那龙花的微妙殿堂中，化作九亿种种杂色众花旒苏悬挂在殿上，以毘琉璃网覆盖诸宝柱，以无价之宝遍布殿下。那宝柔软，譬如三十三天的般筹缄婆罗石，那石的颜色如毘琉璃，石的触感柔软如迦遮邻提迦衣，微妙可乐，牵系人的眼目，令诸天人爱恋系念；那些宝也是这样。那种种摩尼宝中，或有发出清凉的光焰，有流出青水的，有流出赤水的，有流出白水的，有流出黄水的，或有流出杂色之水的，或有发出清凉安乐之风的；或有宝珠，随众生所需之事都能全部流出；或有宝流出膏腴润泽；或有摩尼堪为明镜，一切大众都显现其中，从迦毘罗大城中出来的人民，随其多少都显现在宝中，一切大众都看见佛以及声闻。作这样种种的神通变化，以那摩尼宝的神力，从那地中出现种种杂色宝盖，以及种种杂色宝幢，也有种种杂色宝幡；又出现种种杂花旒苏，也有种种杂香旒苏，又有种种杂宝旒苏，又出现种种真珠旒苏；又出现种种杂色龙幡，又出现种种众宝铃网；又出现种种杂色良马。凡所出现的，都是龙的力量。

【按】“旒苏”之“旒”，明本作“流”。“系人眼目”之“系”，宋、元、明、宫本作“击”。“腴泽”之“腴”，圣、圣乙本作“油”。“龙幡”之“龙”，宫本作“杂”。

那时难陀、优波难陀龙王以及九亿龙，驱赶那良马，随之步行，右绕三匝，以美妙的迦遮邻提迦柔软之宝散于世尊；那殿下地中所出现的种种众宝升上虚空，降在如来以及声闻之上；又以诸龙的无量乐器，在虚空中自然发出美好的微妙音声，供养于佛。那时九亿诸龙绕佛三匝之后，在佛前合掌，默然念佛的功德，瞻仰如来，目不暂舍，乐于佛的功德，因为深心安住于阿耨多罗三藐三菩提。他们片刻合掌默然念佛功德之后，偏袒右肩，右膝着地，合掌向佛，五体投地为佛作礼，大众同一音声，以偈赞叹说：

```
久修威仪百福相，
悲心离垢行具足，
弃舍无尽众宝地，
世尊出于迦毘城。
于六年中修苦行，
如来不得甘露道，
善逝意犹不退闷，
以其久修智慧故。
如来真是天人师，
为世间故修苦行，
世人闻已尚不堪，
况复能以目亲覩。
牟尼过去舍头目，
如圣所集菩提心，
我等闻是不生乐，
由闻如来苦行故。
如佛本作忍辱仙，
为迦利王截手足，
及劓耳鼻不生恚，
我等闻是不能忍。
```
（大意：长久修习威仪与百福之相，悲心离垢，行业具足，弃舍无尽的众宝之地，世尊从迦毘罗城出家。在六年中修习苦行，如来仍未得到甘露之道，善逝的心意仍不退缩烦闷，因为长久修习智慧。如来真是天人之师，为了世间而修苦行，世人听了尚且不能忍受，何况能亲眼看见。牟尼过去舍弃头目，如圣者所积集的菩提心，我们听了心不欢乐，由于听闻如来的苦行。如佛本来作忍辱仙人，被迦利王截断手足，以及割去耳鼻而不生恚恨，我们听了不能忍受。）

```
如佛以身上秤盘，
为鸟归投不舍弃，
我等闻已亦不乐，
如来过去甚勤苦。
何故我等心不乐？
以世尊行极苦故，
于如来所作恶者，
堕恶道时佛复悲。
具足圣慧大导师，
云何能行不害心？
修习道行无疮疣，
唯愿佛说安乐行。
今此龙众已发心，
求于善逝菩提行，
如佛所说悉能行，
唯愿速说菩提道。
此诸龙众甚渴仰，
唯求不死不生处，
愿说如来安隐行，
令此众生易受化。
```
（大意：如佛以身体放上秤盘，为了投奔归依的鸟而不舍弃，我们听了也不欢乐，如来过去甚为勤苦。为什么我们心中不乐？因为世尊所行极苦，对如来作恶的人，堕恶道时佛又生悲悯。具足圣慧的大导师，怎样能行不害之心？修习道行而无瑕疵，唯愿佛宣说安乐之行。现在这些龙众已经发心，求善逝的菩提之行，如佛所说的都能奉行，唯愿迅速宣说菩提之道。这些龙众甚为渴仰，唯求不死不生之处，愿说如来的安隐之行，令这些众生容易受化。）

【按】“秤盘”之“秤”，宋、元、明、宫本作“称”；“盘”，明本作“槃”。

原文：“牟尼过去舍头目，如圣所集菩提心”（大意：牟尼过去舍弃头目，如圣者所积集的菩提心。下句所指未详，存疑。）

#### 马胜请问与授龙王记

那时世尊见到诸龙众设置供养以及听到他们发愿，知道他们已生深信，佛在那时现出微笑之相。诸佛之法是这样：若现出微笑，便从面门放出种种颜色的无量光明，其光遍照，上至梵天，照耀之后又回来，从佛顶入。那时慧命马胜比丘以偈问道：

```
善哉沙门大牟尼，
非是无因现微笑，
慈悲导师唯愿说，
无等善慧笑因缘。
大众瞻仰求欲闻，
世尊无量功德行，
于笑生疑心不乐，
唯愿法王断众疑。
谁于释迦佛法中，
今生敬信心欣喜？
谁令今日魔波旬，
心意迷乱不欣乐？
谁于今日能恭事，
功德法父大导师？
谁作第一胜供养？
愿释师子上上说。
此诸大众合指掌，
皆悉对佛瞻仰住，
唯愿导师除疑网，
为众演说笑因缘。
大众闻已生欣喜，
能知世尊正法教，
大智世尊令众喜，
随顺正教善安住。
```
（大意：善哉沙门大牟尼，并非无因而现微笑，慈悲的导师唯愿宣说无等善慧的微笑因缘。大众瞻仰，求欲听闻世尊无量的功德之行，对微笑生起疑惑，心中不乐，唯愿法王断除大众的疑惑。谁在释迦佛法中，今天生起敬信，心中欢喜？谁令今天的魔波旬心意迷乱而不欣乐？谁在今天能恭敬承事功德的法父、大导师？谁作了第一殊胜的供养？愿释迦师子最上地宣说。这些大众合掌，都对佛瞻仰而住，唯愿导师除去疑网，为大众演说微笑的因缘。大众听了之后生起欢喜，能知世尊的正法教，大智世尊令大众欢喜，随顺正教，善加安住。）

【按】“唯愿”之“唯”，明本作“惟”；“导师”之“导”，宋、元、明、宫本作“众”。

那时世尊以偈回答慧命马胜说：

```
深广智慧大众师，
说时梵音具八种，
清净其心离秽浊，
谛听我说笑因缘。
此诸龙王敬信心，
于我设供超一切，
是等为求佛菩提，
利益一切世间故。
悲心增上观众生，
无有导师云何乐？
我云何得大菩提，
成熟众生不疲劳？
深乐寂定具智慧，
乘安乐乘心清净，
于空无相及无愿，
无量劫来久已修。
其心平等观世间，
如佛所得智慧相，
慈悲喜心皆平等，
为令世间安隐故。
第一悲心怜愍者，
当得作佛称其意，
彼等观察世间已，
当成导师号无怨。
```
（大意：智慧深广的大众之师，说法时梵音具足八种，清净其心，远离秽浊，谛听我说微笑的因缘。这些龙王以敬信之心对我设置供养，超过一切，他们是为了求佛菩提，为了利益一切世间。悲心增上，观察众生：没有导师，怎能安乐？我怎样得到大菩提，成熟众生而不疲劳？深乐寂定，具足智慧，乘安乐之乘，心意清净，对于空、无相以及无愿，从无量劫来早已修习。其心平等地观察世间，如佛所得的智慧之相，慈、悲、喜心都平等，为了令世间安隐。具第一悲心的怜愍者，当得作佛，称其心意，他们观察世间之后，当成为导师，号为无怨。）

【按】“恒常演说”之“演”，宫本作“复”。

```
彼等当得甘露时，
无有魔怨亦无余，
恒常演说无我法，
一向无有世俗说。
彼诸如来具大悲，
令诸众生入佛智，
是诸善逝说法时，
一切众生皆信解。
彼等世世修道时，
成熟众生不为难，
彼所成熟闻法已，
当得解脱证甘露。
诸闻法者悉解脱，
是诸众生皆端严，
一切众生皆能知，
彼诸如来所说法，
一切鬼神及畜生，
无有不解彼佛语，
一切皆得念法已，
能解如来甘露法。
无有众生闻佛说，
当时不生爱乐心，
爱乐彼佛所说者，
一切皆悉得甘露。
彼时所有受化者，
当得解脱生老病，
及解脱死忧悲苦，
闻佛说已心无垢。
```
（大意：他们得到甘露之时，没有魔怨，也没有其余的障碍，恒常演说无我之法，一向没有世俗之说。那些如来具足大悲，令众生入于佛智，这些善逝说法之时，一切众生都能信解。他们世世修道之时，成熟众生并不困难，他们所成熟的众生听法之后，当得解脱，证得甘露。听法的人都得解脱，这些众生都端严，一切众生都能了知那些如来所说之法，一切鬼神以及畜生，没有不理解那佛之语的，一切都得以忆念法之后，能理解如来的甘露之法。没有众生听闻佛说之时不生起爱乐之心，爱乐那佛所说的，一切都得甘露。那时所有受教化的人，当得解脱生、老、病，以及解脱死、忧、悲、苦，听佛说法之后，心中无垢。）

```
如是释迦牟尼佛，
说诸龙意答佛子，
如彼坚智心中转，
为得无等菩提故。
如来授彼诸龙记，
大众闻已皆欣喜，
大众喜已归依佛，
一切皆悉心寂静。
```
（大意：像这样，释迦牟尼佛宣说诸龙的心意，回答佛子，如那坚固智慧者心中所转的念头，是为了得到无等的菩提。如来为那些龙授记，大众听了都欢喜，大众欢喜之后归依于佛，一切都心意寂静。）

【按】“如是释迦牟尼佛”以下八句，CBETA标点置于引号之外，今依句式并入偈中。

### 鸠槃茶授记品第八

【按】“鸠槃茶”之“茶”，宋、宫、圣、圣乙本作“荼”（下同）。

#### 鸠槃茶化现宝盖宝车

那时又有一亿八千万鸠槃茶，见到诸阿修罗、伽楼罗、龙女、龙王等供养如来、听闻授记之后，称其心意，踊跃欢喜，生起稀有之心，得未曾有：“如来世尊的功德智慧微妙殊胜，得到这样稀有的供养，不惊怪也不欢喜，因为佛的智慧在诸智慧中最为尊胜。譬如大海不增不减。为什么？因为深广。像这样，世尊得到殊胜的供养，心无增减，也是这样。为什么？因为对一切法无所疑惑。”

【按】“伽楼罗”之“伽”，宋、元、明、宫本作“迦”。

那时一亿八千万鸠槃茶等为了供养，化作一亿八千万盖，都由七宝所成：金线宝盖、银线宝盖、毘琉璃线众宝之盖、颇梨珠线众宝之盖、赤真珠线众宝之盖、马瑙珠线众宝之盖、砗磲珠线众宝之盖。那些鸠槃茶在众宝盖上悬挂宝旒苏，有种种颜色：金线宝盖悬银线旒苏，银线宝盖悬金线旒苏，毘琉璃盖悬颇梨旒苏，颇梨宝盖以毘琉璃线为旒苏，赤真珠盖悬砗磲旒苏，砗磲宝盖以赤真珠线为旒苏，马瑙宝盖悬颇梨旒苏。又化作一亿八千万辆众宝之车，也有种种颜色，甚为奇特微妙，就是金、银、琉璃、颇梨、真珠、砗磲、马瑙。在那车上又化作一亿八千万众宝之盖，与车相连，每一宝盖都有百个盖子，那些盖茎都用金、银以及颇梨、毘琉璃等。在那宝盖上又化作种种宝花旒苏庄饰其盖，就是金花旒苏、银花旒苏、以毘琉璃花作旒苏、颇梨旒苏、赤宝旒苏、龙珠旒苏、以赤真珠花作旒苏，又以赤真珠网遍覆其上。又化作鸠槃茶的音乐，发出种种声音来娱乐佛。又化作一亿八千万匹众宝颜色的马，调伏而骏疾，以之驾车。那时鸠槃茶等各乘宝车绕佛三匝，以七宝花散在佛上。那时那些鸠槃茶等从车上下来，来到佛前，头面礼拜之后，又绕三匝，曲躬合掌，站立一旁，以偈赞叹说：

【按】“颇梨”，宫本作“玻𭹳”。“马瑙”，圣乙本作“码碯”。“车𤦲”之“𤦲”字先前电子文本未能显示，今据《大正藏》补出，即“砗磲”。

```
不增不减大牟尼，
譬如须弥诸山王，
受此无上供养者，
如来以得无畏故。
观诸众生但有名，
及但有用不取著，
导师以修寂灭定，
是故智者无贡高。
牟尼知世犹如幻，
亦如梦中受欲乐，
复似水月春时焰，
如是观察悉无余。
譬如乾城无有实，
于十方求不可得，
其城无实但有名，
佛见世法悉如是。
```
（大意：不增不减的大牟尼，譬如须弥诸山之王，接受这无上供养的人，因为如来已得无畏。观察众生只有名称，以及只有作用，而不取著，导师由于修习寂灭之定，所以智者没有贡高。牟尼了知世间犹如幻化，也如在梦中受欲乐，又似水中之月、春时阳焰，这样观察一切，毫无遗余。譬如乾闼婆城没有实体，在十方寻求都不可得，那城没有实体，只有名称，佛见世间之法都是这样。）

```
一切人天所供养，
宝车宝盖及音乐，
幢花旒苏合掌等，
世尊观知如影响。
我等设是供养已，
愿我当来得作佛，
亦愿我知世如梦，
知已说法如世尊。
我等见诸苦恼者，
生老病死之所逼，
愿知无死佛菩提，
说令闻者得解脱。
于诸无智众生所，
愿得菩提为说法，
演说无有垢浊法，
无道众中为作导。
```
（大意：一切人天所作的供养，宝车、宝盖以及音乐、幢、花、旒苏、合掌等，世尊观察知道都如影子与回响。我们设置这供养之后，愿我们将来得以作佛，也愿我们了知世间如梦，了知之后如世尊一样说法。我们看见那些苦恼的人被生老病死所逼迫，愿了知无死的佛菩提，宣说令听闻者得到解脱。在那些无智的众生之中，愿得菩提而为他们说法，演说没有垢浊之法，在无道的众生中作导师。）

【按】“无死”之“死”，元、明本作“比”。“无道”之“道”，宋、元、明、宫本作“导”；“为作导”之“导”，圣、圣乙本作“道”。

#### 授鸠槃茶记

那时世尊知道诸鸠槃茶等已生深信，现出微笑之相。那时慧命马胜比丘以偈问道：

```
佛非无因现微笑，
不怪一切为希有，
如来不怪而现笑，
我今愿闻此因缘。
一切天人皆有疑，

谁佛所赞行供养？
人中胜者我愿闻。

见其过患能弃舍？
今日谁能住实际？
清净心者我愿闻。
谁能降魔及眷属？
谁能令佛心欣喜？
谁能得深有为底？
我愿得闻断疑心。
一切大众合掌住，
为闻如来笑因缘，
愿断一切众生疑，
两足尊者说彼记。
```
（大意：佛不是无因而现微笑，不惊怪于一切，却作为稀有，如来不惊怪而现微笑，我现在愿闻这因缘。一切天人都有疑惑，看见佛口中现出微笑，唯愿断除种种疑网，演说世尊微笑之事。谁对正法得到深信？谁能如法见到慈父？谁行佛所赞叹的供养？人中殊胜者，我愿听闻。今天谁对有为之行见到其过患而能弃舍？今天谁能安住于实际？心意清净的人，我愿听闻。谁能降伏魔以及眷属？谁能令佛心中欢喜？谁能得到深入有为的底蕴？我愿得以听闻，断除疑心。一切大众合掌而住，为了听闻如来微笑的因缘，愿断除一切众生的疑惑，两足尊者宣说那授记。）

```
汝于世间大利益。
以汝问笑因缘故，
谛听马胜我今说。

心生希有起愿求。

愍众生故供养我，
为失道者起慈心，
此等贤智作是已，

```

### 乾闼婆授记品第九

#### 乾闼婆乘象供佛

那时又有三亿六千万乾闼婆众，见到诸阿修罗、迦楼罗、龙女、龙王、鸠槃茶等供养世尊、听闻授记之后，称其心意，欢喜踊跃，生起稀有之心，得未曾有，赞叹说：“稀有，未曾有之事！乃至如来所说的法界没有变异，而示现有作、善根增长；虽然没有作者，而示现作业。”那些乾闼婆等对这法这样了知之后，对如来心生尊重，发阿耨多罗三藐三菩提心。他们欢喜之后，为了供养佛，化作三亿六千万头㖶罗婆那大龙象王，都有六牙；每一牙上化作七个池，每一池中化作七朵莲花，每一莲花化作千片花瓣，每一花瓣上化作七位玉女，每一花瓣间化作七位侍女，以诸天之宝作为庄严之具而加以装饰，又持天香来供养。又在每一头㖶罗婆那象王的头上化作三亿六千万盖，七宝旒苏悬挂在盖的四边，以七宝罗网覆盖盖上。又在每一头㖶罗婆那象王的头上化作三亿六千万帐，都由诸天的妙香所成，缯彩旒苏悬挂在帐的四边。化作三亿六千万头㖶罗婆那大象王之后，那些乾闼婆等各乘其象，奏起天上的音乐，在虚空中旋绕如来三十六匝，以天栴檀末、天沉水末、天多摩罗叶末、天真金末、曼陀罗花、摩诃曼陀罗花、曼殊沙花、摩诃曼殊沙花、波楼沙花、摩诃波楼沙花、迦迦罗婆花、摩诃迦迦罗婆花，又化作七宝之花，散在佛上。那些乾闼婆等散香花时，那香花之气逆风、顺风、纵横都能传去。又降下种种天上美妙的香水；降香水时，在迦毘罗城纵广正好六十由旬都成为香泥，那香泥之气充满三千大千世界，其中众生闻到香气的，都不退失阿耨多罗三藐三菩提。奏音乐时，其种种音声遍满三千大千世界，其中众生听到这声音的，也得不退阿耨多罗三藐三菩提。像这样，每一位乾闼婆各在三亿六千万象王头上设置供养，令诸玉女有奏乐的，有唱歌的，有跳舞的；那些玉女歌舞之时，令大众一心观望。又有玉女动身挥手的，散栴檀末的，散沉水末的，广作供养，如阿修罗所设之事一样，没有差异。那时乾闼婆等各乘㖶罗婆那大象王的头，在虚空中绕佛三十六匝之后，各从象上下来，又绕三匝，头面礼佛，曲躬合掌，站在一旁，以偈赞叹说：

```
世尊胜慧出有顶，
自既出已复度他，
一切世间无如佛，
相好光颜极端正。
人中最妙无边称，
示现世间不思议，
不见一法性相异，
而令众生住于善。
无有变异真如法，
但有言说无余义，
无有用事及用者，
虽然佛化诸群生。
不来不去亦不生，
佛能演说如是法，
虽说诸法体性空，
世雄而令修习道。
无有一法能自作，
世间明者说有作，
诸法各各不觉知，
世尊示现一切作。
如车多集众分支，
彼支不知自能作，
其车功用现可见，
佛说诸法亦如是。
```
（大意：世尊殊胜的智慧超出有顶，自己既已出离，又度化他人，一切世间没有如佛的，相好光明，容颜极为端正。人中最妙，名称无边，示现于世间，不可思议，不见一法的性相有差异，而令众生安住于善。没有变异的真如之法，只有言说，没有其余的义理，没有所用之事以及能用之人，虽然如此，佛仍教化群生。不来不去，也不生，佛能演说这样的法，虽然宣说诸法的体性是空，世雄仍令人修习道。没有一法能自己造作，世间的明智者说有造作，诸法各各不能觉知，世尊示现一切造作。如车聚集众多部件，那些部件不知自己能造作，那车的功用现前可见，佛说诸法也是这样。）

```
诸法各各不相教，
亦不迭互相觉寤，
一切亦复不相依，
法本不生亦不死。
佛为世谛如是说，
世谛诸法不全无，
如世谛法体性住，
如是知已为众说。
世尊如是说诸法，
大悲所作甚奇特，
诸法体性不可见，
如来方便说其性。
```
（大意：诸法各各不相教导，也不互相觉悟，一切也不相依赖，法本来不生也不死。佛为世俗谛这样宣说：世俗谛的诸法并非全无，如世俗谛之法的体性而住，这样了知之后为大众宣说。世尊这样宣说诸法，是大悲所作，甚为奇特，诸法的体性不可见，如来以方便宣说其性。）

```
我等愿作无边称，
具百福相大导师，
大悲利益诸世间，
愿作世亲如今佛。
我等愿于暗障者，
```

（大意：我们愿作具无边名称、具百福之相的大导师，以大悲利益诸世间，愿作世间的亲人，如现在的佛。我们愿对被黑暗障蔽的人、随顺贪欲急流的人、被渴爱缠缚而受百苦的人，如世尊一样救济度脱。我们愿对受众苦的人、不见彼岸而被魔缚的人、如猿猴般奔走轻躁的人，如世尊一样救济度脱。我们愿对盲冥的人、在六趣往来疲劳的人、自己毁坏业果的人，如世尊一样救济度脱。）

#### 授乾闼婆记

那时世尊知道那三亿六千万乾闼婆众已生深信，现出微笑之相。那时慧命马胜比丘以偈问道：

```
无边威德现微笑，
导师如是非无因。
愿佛速说此因缘，
断除众生诸疑网。
今见世尊微笑已，
大众皆悉为疑网，
一切愿闻微笑义，
唯愿大悲断众疑。
谁于佛法生敬信？
能得离于诸疑网？
佛知众生深信已，
人天胜者故现笑。
谁有智慧能随顺，
如来所说真如法，
知其念慧解行已？
在大众中现微笑。
一切大众无异心，
唯欲乐闻雄猛说，
合十指掌在首顶，
一心瞻仰如来面。
离诸秽浊无忧虑，
世眼现在故欣喜，
为除一切心疑惑，
愿大悲说笑因缘。
```
（大意：具无边威德者现出微笑，导师这样并非没有原因，愿佛迅速宣说这因缘，断除众生的种种疑网。现在见到世尊微笑之后，大众都生起疑网，一切都愿听闻微笑之义，唯愿大悲者断除大众的疑惑。谁对佛法生起敬信，能得以远离种种疑网？佛知道众生的深信之后，人天中的殊胜者所以现出微笑。谁有智慧能随顺如来所说的真如之法，知道他们的念、慧、解、行之后，在大众中现出微笑？一切大众没有异心，唯欲乐闻雄猛者的宣说，合十指掌，放在头顶，一心瞻仰如来之面。远离种种秽浊，没有忧虑，因为世间之眼现在而欢喜，为了除去一切心中的疑惑，愿大悲者宣说微笑的因缘。）

【按】“导师如是”之“如是”，圣、圣乙本作“知见”。

```
导师所现此微笑，

诸法寂灭安不动，
此等大众趣实际，
如乾闼城如是入，
供养于我无有等。
如是诸法无有生，
一切亦复不尽灭，
大众思惟如幻住，
未能解了生疑惑。
不可说法方便说，
我以真实故如是，
彼等入我正法已，
乘大龙象供养佛。
```

```
观察菩提无生灭，
乾闼婆王供养我，

彼等修净佛行已，

化无量众发道心，

知诸世间性空已，
亦以此法教导他，
令众安住一切智，
住世无量那由劫。
彼佛同号无边慧，
一一诸佛住于世，
皆悉无量那由劫，
演说佛道令他闻。
```
