# 《大宝积经》卷第四十五（菩萨藏会·羼底波罗蜜多品、毘利耶波罗蜜多品）

唐·三藏法师玄奘 奉诏译

## 菩萨藏会第十二之十一

【按】本卷《羼底波罗蜜多品》相当于《佛说大乘菩萨藏正法经》（T0316）的《忍辱波罗蜜多品》（卷二十四），《毘利耶波罗蜜多品》相当于该经的《精进波罗蜜多品》（卷二十五至卷三十）。羼底即忍辱，毘利耶即精进。

### 羼底波罗蜜多品第八

#### 忍辱的总相

那时，佛告诉舍利子：“什么名为菩萨摩诃萨的羼底波罗蜜多？菩萨摩诃萨为了阿耨多罗三藐三菩提，对这样的法精勤修学，行菩萨行。舍利子！菩萨摩诃萨由于安住这样的羼底波罗蜜多，具足忍力，立性坚正，对于种种寒热、饥渴、蛇蝎、蚊虻、风日等触，其志都能堪忍；又能忍受粗恶的言说、鄙陋的词句，以及依身所起的猛烈迅疾的苦受、坚硬辛楚乃至夺命至死的苦，这样所有的苦受都能堪忍。舍利子！若诸菩萨摩诃萨能具足这些，便名为羼底波罗蜜多。

【按】“志能堪忍”之“志”，宋、元、明、宫本作“悉”；“堪忍”之“忍”，圣本作“堪忍”。

#### 世尊往昔被骂不瞋

“再者，舍利子！我往昔长夜还未成佛时，行菩萨行，常修忍辱。”舍利子对佛说：“世尊！世尊作菩萨时，怎样修集忍辱，行菩萨行？”佛告诉舍利子：“我忆念过去行菩萨行时，有许多众生屡屡来毁骂，非法呵责，当面对我说出种种非法、弊恶的言语。舍利子！我那时因行羼底波罗蜜多，制伏其心，不生忿恚、悭吝、恼热，只这样想：‘在诸行之中，没有少许法比毁骂与呵责更容易得到的，所以我现在应当修舍。又，我对他们应当生起慈悲。为什么？世间众生多安住于毁骂呵责，由于这业，又感得同样的诃毁果报，在在所生常得丑陋可厌之身。我现在不喜乐丑陋之事，岂应乐于行毁骂呵责？为什么？这样诃毁的种种恶业，便名为不相应之业、不称理之业、愚夫之业，是下劣之业，不是善人之业，不是贤圣之业。由于这业，堕于地狱、傍生、焰魔世界；又由于这业，与诸恶趣作为眷属；由于这业，感得贫穷的药叉之身，又由于这业，感得贫穷药叉的根本果报；由于这业，感得贫穷的饿鬼之身，又由于这业，感得贫穷饿鬼的根本果报；由于这业，感得贫穷的人趣之身，又由于这业，感得贫穷人趣的根本果报；又由于这样的诃毁之业，感得下趣以及下趣的根本果报。我现在不应求下劣之趣。为什么？若我求作这样的事，与众生有什么差别？然而那些众生不顺于理，我既顺于理，便不应与他们相同。’舍利子！这些行羼底波罗蜜多的菩萨摩诃萨，应当随我修学这法。为什么？舍利子！这些菩萨被他人毁骂呵责之时，便能依这正法作意思惟而忍受。这位菩萨摩诃萨由于得到这样的忍辱之力，又获得无量种种美妙善根；假使以种种珍宝充满佛世界的四大洲，用来布施，比起前面的功德，都不能及。为什么？这忍辱之行，只有极善的丈夫才能修习。为什么？因为一切众生多被毁骂呵责所拘执，由于这样，生死流转，不能断绝。

#### 被诃毁时当念三宝与本愿

“再者，舍利子！这些行羼底波罗蜜多的菩萨摩诃萨，应当自我勉励，审谛观察，这样想：‘我若被他人诃毁之时，能思惟佛、菩提以及法、僧吗？若能思惟，便是善；若不能思惟，便不名为善。’又以其余无量方便，思惟佛，思惟菩提以及法、僧。舍利子！菩萨摩诃萨这样思惟之后，应当观察：我现在与一切众生有什么差别殊异之相？为什么？那些众生现在对我生起瞋害的，对佛、菩提以及法、僧从不思惟；我若和他们一样不思惟，与众生有什么差别，有什么殊异希奇之相？舍利子！这位菩萨摩诃萨又思惟：‘若被他人现起瞋恚时，心便舍弃，对佛、菩提以及法、僧等从无思念，这不是我所应当的。’又这样想：‘若我对他生起瞋恚，便是无智，没有忍辱之力，也是弃舍了本愿。为什么？若生起瞋恚，便没有这样的心：我当摄受一切众生，我当不舍一切众生。我若对一个有情生起瞋恚，便不名为菩萨摄化之法。谁请我行菩萨道？何况我往昔发过这样的愿：我当迅速证得阿耨多罗三藐三菩提之后，广为众生宣说正法。刚发这样的弘誓之时，诸佛世尊共同为我作证，便这样想：这位族姓子发心安住这样的无上正等觉之后，将为众生广宣正法。又在现在，诸佛世尊以无障碍的智、无障碍的见现前证知我。所以，不应在被他人毁骂呵责之时，若生起瞋恚，对佛、菩提、法、僧生起舍弃之心，就不应这样忆念。为什么？现在东方殑伽沙等诸佛世界，那些世界中有殑伽沙等如来、应、正等觉现在住持，那些佛世尊也证知我心中所生的正愿；南、西、北方、四维、上下也是这样。当我发这正愿之时，诸佛同声赞叹我的忍力，所以我不应作了狮子吼之后又作野干之声。狮子吼，是说我当证得大忍辱之力；野干声，是说对众生行瞋恚、诃毁等相。’

原文：“谁请于我行菩萨道”（大意：谁请我行菩萨道？语意未详，存疑。）

原文：“是故不应为他毁骂诃责之时，若起瞋恚，于佛菩提法僧之所若生舍者，不应忆念”（大意：所以，不应在被他人毁骂呵责之时，若生起瞋恚，对佛、菩提、法、僧生起舍弃之心，就不应这样忆念。句读未详，存疑。）

“舍利子！这位菩萨摩诃萨又这样想：‘世间众生若得到他人的利益，才去利益他人；我若也这样，得到众生的利益才去利益他们，我与世间有什么差别？有什么殊异希奇之相？’又这样想：‘世间众生若对方对此人作了无义利之事，此人又对对方作无义利之事；我若也这样，众生对我作无义利之事，我又对他们作无义利之事，若是这样，我与众生有什么希奇差别殊异之处？’舍利子！菩萨摩诃萨对这法应当修学。又这样想：‘世间众生互相怨对，若得到对方的利益，便称为善友；若得不到利益，便互相杀害。我见到这样深重的过失，应当不去看一切众生对我身作种种利乐，以及对我身作无义利之事。’只这样想：‘我现在必当饶益一切众生，为了满足羼底波罗蜜多。’”那时世尊想重宣此义，而说颂道：

【按】“我今与”，明本作“我今与彼”。“于佛菩提”，宋、元、明、宫本作“我于佛菩提”。

```
设彼于我为无利，
经于多百拘胝劫，
见彼有情受众苦，
终无安住于舍心。
设有互得世财利，
更相称赞为善友，
若互不得世财利，
彼此怨对相残害。
假使以此赡部洲，
或复三千佛世界，
盛满珍宝来相惠，
常求我为贤善友。
假使执持利刀剑，
来解我身诸支节，
我当于彼诸众生，
平等利益心无二。
于诸毁骂我当忍，
亦忍一切诸难苦，
当为众生赞忍力，
亦自安住大忍中。
世间暴恶诸有情，
以刀毒等相加害，
能和合彼为善友，
此则圣贤聪叡相。
我当不学世愚夫，
又应与彼而为异，
凡夫圣者之所行，
流转寂灭差别故。
```
（大意：假使他人对我作无义利之事，经过多个百拘胝劫，见到那些有情受众苦，我也终不安住于舍弃之心。假使有人互得世间财利，便互相称赞为善友；若互相得不到世间财利，彼此怨对，互相残害。假使以这赡部洲，或者三千佛世界，盛满珍宝来相赠，常求我作贤善之友；假使执持利刀剑，来肢解我身体的各个支节，我对那些众生，都平等利益，心无二致。对于种种毁骂，我当忍受，也忍受一切种种难忍之苦，当为众生赞叹忍力，也自己安住于大忍之中。世间暴恶的有情，以刀、毒等相加害，能令他们和合为善友，这是圣贤聪睿之相。我当不学世间愚夫，又应与他们不同，因为凡夫与圣者所行，有流转与寂灭的差别。）

【按】“来相惠”之“惠”，圣本作“慧”。

#### 存命犹庆与忿恚为魔业

“再者，舍利子！菩萨摩诃萨行羼底波罗蜜多时，应当这样修学正法。舍利子！这位菩萨摩诃萨又这样想：‘假使经过百千那庾多拘胝大劫，被众生常以刀杖、瓦石、土块种种加害，只要须臾之间能保住微弱的性命，仍应欣庆，这样想：“奇哉！这样的有情圣者，能不完全断绝我的性命。”’这位菩萨摩诃萨从此以后转加修学，又这样想：‘假使众生在走七步的时间里，斩截我的头，多如殑伽沙数，我对他们终不生起忿或恚。为什么？所谓忿恚，能迅速损害百千大劫所积集的善根；若我的善根被瞋所害，又要经过百千大劫，才开始勤苦修行圣道。若是这样，阿耨多罗三藐三菩提极难得到，所以我应当披上忍辱之铠，以坚固之力摧伏忿恚之军。’

【按】“欣庆”之“欣”，元、明本作“忻”。“为瞋害已”之“瞋”，明本作“损”。

“又，舍利子！住于大乘的菩萨摩诃萨若生起忿恚之心，魔便得其便；得便之后，能对阿耨多罗三藐三菩提作障碍。舍利子！忿恚之心能对菩提道作扰乱，扰乱之心能发起恶魔所有的魔业。这其中什么名为魔业？若有菩萨心住于衣钵，不能舍离，应当知道是魔业；心住于乞食与诸施主之家，不能舍离，应当知道是魔业；心住于名闻、恭敬、利养，不能舍离，应当知道是魔业；对于出家之法常生厌患，应当知道是魔业；对于白净之法多生轻贱，应当知道是魔业；对于空寂之处没有志求之心，应当知道是魔业；不乐于无上正等菩提，应当知道是魔业；对于其余的智慧恒常欣求修习，应当知道是魔业；乃至对于邬波柁耶、阿遮利耶二位殊胜之师不修敬仰恭顺之心，应当知道是魔业。舍利子！这样等等的忿恚之心，能对菩提作扰乱。舍利子！这便名为住于扰乱之心的菩萨摩诃萨，被诸恶魔所驱使，作种种魔业。

【按】“邬波柁耶”之“邬”，《大正藏》作“鄥”，今依CBETA作“邬”。

#### 修行处仙人五百年被魔骂

“再者，舍利子！菩萨摩诃萨行羼底波罗蜜多时，这样想：‘在长夜中，众生被诸恶魔伺求其便的，就是瞋恚。’舍利子！我现在为你广说这事。我忆念过去作大仙人，名叫修行处，那时有恶魔化作五百个凶悍的骂人丈夫，恒常追随我，发出种种恶骂；无论昼夜去来、行住坐卧，在僧坊静室、聚落俗家，或在街巷，或在空闲之处，随我坐或立，这些化魔都以粗恶之言毁骂呵责，满五百年从未停止。舍利子！我自己忆念往昔五百年中被诸魔罗所诃毁，从未对他们生起丝毫怨恨之心，恒常兴起慈心救护而加以观察。舍利子！我那时又这样想：‘若有诸善男子守护尸罗，具足众善法，贪瞋痴之性轻微，并不是只对他们作种种利益，就说我是行难行之人；也不是只对他们作种种利益，就能证得无上正等菩提。为什么？若有众生刚强难伏，毁犯尸罗，具足种种恶法，其性浊重，多贪瞋痴，若我对他们作种种利益，这才说我是行难行之人。由于我对他们作种种利益，迅速成就无上正等菩提，先应当令他们证得寂灭。’舍利子！这些菩萨摩诃萨若忿恚之心现前时，应当生起这样种种大正念；若生起这念，种种利益之事便迅速得以圆满。舍利子！如来在过去世，由于行这样的羼底波罗蜜多的菩萨行，证得阿耨多罗三藐三菩提。所以，想要求无上正等觉的菩萨摩诃萨，对种种忍力常具足成就，堪受一切寒热、饥渴、风日、蚊虻、蛇蝎等触，又能堪忍粗恶的言说、鄙陋的词句、依身所生的猛利诸苦、坚硬辛楚乃至夺命至死，这样的苦受都能堪忍。舍利子！这名为菩萨摩诃萨安住于这忍，迅速能成就羼底波罗蜜多。

【按】“坚鞕”之“鞕”，明本作“鞭”。

#### 菩萨忍的种种相

“再者，舍利子！什么是菩萨摩诃萨的羼底波罗蜜多？菩萨摩诃萨依之修行，具足成满忍法之相。舍利子！菩萨之忍：没有瞋恚，是菩萨忍；没有忿怼，是菩萨忍；没有种种怒害，是菩萨忍；不起怨诤，是菩萨忍；没有种种烦恼，是菩萨忍；善能自护，是菩萨忍；善能护他，是菩萨忍；当善护身，是菩萨忍；当善护语，是菩萨忍；当善护心，是菩萨忍；如理观察，是菩萨忍；厌离诸欲，是菩萨忍；依于清净业报，是菩萨忍；身善清净，是菩萨忍；语善清净，是菩萨忍；心善清净，是菩萨忍；受用诸天人圆满的清净之乐，是菩萨忍；如来相好圆满庄严，是菩萨忍；如来言说梵音微妙，是菩萨忍；行菩萨行，摄持诸善本令不坏失，是菩萨忍；出离众生的逼迫苦恼，是菩萨忍；除灭一切恶怨对，是菩萨忍。舍利子！简略地说，应当知道，一切如来的力、无所畏、不共佛法、大慈、大悲、大喜、大舍，无量圆满的诸佛妙法，都是菩萨摩诃萨的羼底波罗蜜多所成就的。

【按】“无诸烦恼”之“烦”，明本作“损”。“依净业报”之“依”，明本作“作”。“天人”，元、明本作“人天”。

“再者，舍利子！菩萨摩诃萨行羼底波罗蜜多时，应当具足种种忍的正行。舍利子！菩萨摩诃萨若被骂詈，终不报复，因为善达言语如回响之声；若被捶打，终不报复，因为善达身形如影像；若遭忿怒，终不报复，因为善观其心如幻化；若遇赞叹或毁谤，终无爱恚，因为善知自身功德圆满；对于得与失、利与衰不生欣戚，因为调伏其心，住于寂静；不希求美名，不犯恶名，因为善能观察，智慧广大；被毁不下沉，被赞不高举，因为功德善安住，不倾动；对于种种苦事从无厌恶，因为对受苦的众生深怀眷恋；对于种种乐相从无欣爱，因为知道有为之乐其性无常；不被世间八法所染，因为不依一切有趣之生；对于自己的种种苦善能堪忍，因为终不令他人受苦恼；对于殊胜菩提心无退屈，因为觉分资粮善加圆满；节节肢解乃至斩首善能堪忍，因为希求如来的金刚之身；屠割身肉善能堪忍，因为求取如来美妙的相好；种种变故恶事善能堪忍，因为要种植一切善业之力。舍利子！这样等等的相，名为菩萨摩诃萨成就羼底波罗蜜多，应当这样修学。

【按】“如幻幻故”之后一“幻”，宋、元、明、宫、圣本作“化”，今依之译作“如幻化”。

#### 非毕竟忍与毕竟忍

“再者，舍利子！菩萨摩诃萨行羼底波罗蜜多时诸忍之相：就是菩萨摩诃萨所修行的忍，名为毕竟堪忍。为什么？若认为‘我能堪忍毁骂’而生起忍，这名为俱生之忍，这样的忍不是毕竟之忍。若认为‘谁能起骂？又骂什么？’而生起忍，这名为较计法之忍。若认为‘是眼能骂眼吗？’而生起忍，这名为观察诸处之忍。若认为‘这其中没有能骂、所骂’而生起忍，这名为悟入一切无众生之忍。舍利子！这样的种种忍都不是菩萨的毕竟之忍。又，舍利子！若认为骂声只是一些文字，这名为回响之忍，这样的忍不是毕竟之忍。若认为彼与我都是无常，这名为悟无常之忍。若认为他有颠倒、我无颠倒，这名为高下之忍。若认为他不是正理、我是正理，这名为相应不相应之忍。若认为他住于邪道、我住于正道，这名为二道分别之忍，这样的忍不是毕竟之忍。若认为：我忍于空而不忍于见趣，我忍于无相而不忍于种种觉，我忍于无愿而不忍于志求，我忍于无作而不忍于诸行，我忍于惑尽而不忍于烦恼，我忍于诸善而不忍于不善，我忍于无罪而不忍于有罪，我忍于无漏而不忍于有漏，我忍于出世而不忍于世间，我忍于清净而不忍于杂染，我忍于涅槃而不忍于生死——舍利子！这样的种种忍只能名为对治断除之忍，都不是菩萨的毕竟之忍。

“再者，舍利子！菩萨摩诃萨行羼底波罗蜜多时，怎样修行菩萨的毕竟之忍？舍利子！若随顺于空而不减损诸见，对那空性也无增益，这样的忍名为菩萨的毕竟之忍。若随顺于空而不减损求愿，对无愿之性也无增益；若随顺于空而不减损诸行，对无作之性也无增益；若随顺于空而不减损烦恼，对惑尽之性也无增益；若随顺于空而不减损不善，对那善性也无增益；若随顺于空而不减损有罪，对无罪之性也无增益；这样乃至若随顺于空而不减损生死，对涅槃之性也无增益。舍利子！以这样等等的相而生起忍，便名为菩萨摩诃萨的毕竟之忍。舍利子！一切诸法，不是能生，不是所生，不是已生，不是现生，没有一法是可以生起的；因为无生起，所以便无有尽。若有人能了知这无尽，便名为菩萨摩诃萨的毕竟之忍。舍利子！一切诸法，不是有为，也不是无为，没有增益，无损无增，也无长养，无盛无衰，没有作者，没有起者；由于无起，所以也无有尽。这样的忍，便名为菩萨摩诃萨的无生之忍。舍利子！菩萨摩诃萨为了阿耨多罗三藐三菩提行菩萨行，若有人具足成就这样的忍，这名为菩萨摩诃萨的羼底波罗蜜多圆满成就。舍利子！若菩萨摩诃萨安住于这样的羼底波罗蜜多，精勤修学，行菩萨行，便不被诸魔、魔众、天子所扰乱，也不被异道邪论所摧伏。”

【按】“不减诸见”之“减”，宋、元、明、宫本作“灭”。“无损无增”之“损”，宋、元、明、宫、圣本作“殖”。

### 毘利耶波罗蜜多品第九之一

【按】“毘利耶”，明本作“毘梨耶”。

#### 不顾身命求菩萨藏

那时，佛告诉舍利子：“菩萨摩诃萨怎样为了阿耨多罗三藐三菩提，依毘利耶波罗蜜多行菩萨行？舍利子！菩萨摩诃萨对这正勤波罗蜜多精进修学，行菩萨行。舍利子！菩萨摩诃萨具足成就不退的正勤，而能不顾所珍重的身命，发大精进，求取菩萨藏微妙法门，殷重地听闻、受持、读诵，究竟研寻，通达义趣，广为他人敷演开示，或者书写受持，如理修学，这名为菩萨摩诃萨行菩萨行。

“舍利子！什么名为不顾身命？舍利子！菩萨摩诃萨行正勤波罗蜜多时，假设被他人恐吓，这样说：‘若你对这部菩萨藏经受持读诵，乃至广为他人开示、书写受持、如理修学，我当用一百支箭矟贯穿举起你的身体，断除你的性命。’舍利子！菩萨摩诃萨在那时，虽然听到这话，从不放在心上，无恐、无怖、无惊、无畏，发起四种坚固勇猛的威势，对菩萨藏微妙法门转加精进，不弃、不舍、不远、不离，具足成就猛利的信解、坚固的信解、坚固的堪忍、坚固的正勤。

【按】“百具箭矟”之“百”，宋本作“白”。

“舍利子！我当为你说坚固忍、坚固正勤的方便譬喻，为了令菩萨得到坚固忍、坚固正勤，行菩萨道而不顾身命。舍利子！假使三千大千世界所有众生、有情所摄者，或卵生、或胎生、或湿生、或化生，或有色、或无色，或有想、或无想、或非有想非无想，或可见、或不可见，那些众生在刹那间都得到人身，对菩萨共同结下百千极重的怨仇。那些怨家对菩萨说：‘你若对这部菩萨藏经的种种文句受持读诵，乃至广为他人开示、书写受持、如理修学，我们这些人同时捆缚你，断你的性命。’舍利子！菩萨摩诃萨因行毘利耶波罗蜜多，在那时，虽然听到这话，丝毫不起一念怖畏之心，只具足摄持四种正法，专心寻求大菩萨藏微妙法门。舍利子！这名为菩萨摩诃萨具足成就不退的正勤波罗蜜多。又成就无边势力的勇猛精进：正勤勇健、心意勇健、净戒勇健、大忍勇健、等持勇健、大慧勇健，正行与胜智都勇健。

“舍利子！这位菩萨摩诃萨行正勤波罗蜜多时，由于具足这样的大忍力，假使十方无量众生各自争相执持百千刀剑，对菩萨加以逆害，菩萨那时对那些有情终不生起一丝瞋心。舍利子！这样的菩萨摩诃萨由于住于忍力，如大梵王、如天帝释、如苏迷卢四宝山王，不可倾动，常住于慈悲，恒常生起意解，救疗众生，对于所行终无退转。这位菩萨的心如大地、心如大水、心如大火、心如大风以及虚空，又能善修对治贪瞋痴等的根株。舍利子！若有菩萨摩诃萨以殑伽沙等无量世界盛满一切无价珍宝，用来奉施无量如来、应、正等觉；又有菩萨摩诃萨行毘利耶波罗蜜多，听闻这样的大菩萨藏微妙法门，听了这经之后前往空闲之处，系念思惟这样的法，精进修学，令还未修学的诸菩萨等爱乐习行。舍利子！这样的菩萨摩诃萨因行正勤，摄持无量种种美妙善根，不是那行布施者所能及的。为什么？舍利子！因为这样的善根系属于阿耨多罗三藐三菩提。所以诸菩萨摩诃萨对于菩萨藏微妙法门，应当听闻、受持、读诵，或者书写，广为他人宣说，发起正勤，勇猛修习。

【按】依上下文，“四种正法”即前所说“猛利信解、坚固信解、坚固堪忍、坚固正勤”。

#### 不行行处

“再者，舍利子！发起正勤波罗蜜多的菩萨摩诃萨，应当修行不行行处。舍利子！什么名为不行行处？舍利子！不行行处，就是涅槃。所说的不行，是因为诸恶天魔所不行；所说的行，是因为正勤的善人所行。所说的善人，就是诸佛、独觉以及佛的弟子。为什么？因为诸登上圣道的所有善人以及佛世尊，都是为了趣向般涅槃。舍利子！一切众生多行于三处。哪三处？就是随顺恶道、趣向恶道、将堕恶道。所以诸菩萨摩诃萨对于杂染之法终不随顺，只求出离、戒、忍、多闻、白法等诸法。舍利子！世间众生多住于无业，却恒常自认为住于有业；世间众生多有懈怠，却恒常自认为发起了正勤。所以，舍利子！聪慧的菩萨摩诃萨终不与那无业、懈怠的人相亲近，也不堕入他们的行列之中，只与同行发起正勤的诸大菩萨相亲近。为什么？舍利子！没有众生对那最胜、无染、清净之相的大般涅槃生起清净信解，如菩萨那样。舍利子！发起正勤波罗蜜多的菩萨摩诃萨，不只是为了自己证得涅槃而发勤精进，而是为了摄受一切有情，令众生得到利乐，修行正行，发勤精进，开示教导，安置众生于圣道之路，所以说菩萨名为善丈夫。”那时世尊想重宣此义，而说颂道：

原文：“世间众生多住无业，而恒自计住于有业”（大意：世间众生多住于无业，却恒常自认为住于有业。“无业”“有业”所指未详，存疑。）

```
正勤无缓缦，常具大精进，
于菩萨藏法，聪叡恒受持。
善思惟法义，于佛不思议，
但勤求净法，故名为菩萨。
正勤大慧者，坐妙菩提树，
摧怖恶魔军，由般若精进。
现守护禁戒，任持诸世间，
为利益众生，常精进无限。
```
（大意：正勤没有松缓，常具足大精进，对于菩萨藏之法，聪睿而恒常受持。善思惟法义，对于佛不可思议的功德，只勤求清净之法，所以名为菩萨。正勤的大慧者，坐于美妙的菩提树下，摧伏怖畏的恶魔军，是由于般若与精进。显现守护禁戒，任持一切世间，为了利益众生，常精进无有限量。）

【按】“缓缦”之“缦”，明本作“慢”。

#### 后五百岁持此经者

“再者，舍利子！这样的大乘大菩萨藏微妙经典流布于世，能令众生生起大欢喜，又能引生福德与智慧，感得大财富，令其增长，能感得诸天殊胜的快乐，能感得一切圆满具足，能生起一切诸佛如来的力、无所畏、无碍智解、大慈、大悲、大喜、大舍、不共佛法。简略地说，能引生一切诸佛之法，摧伏怖畏魔怨，令心清净，能发起猛利的智慧，穷尽生死的根本，到达苦的边际，能接近涅槃。舍利子！在未来世，我与你们般涅槃之后的后五百岁，那时多有薄福的众生，对这经不生信重，毁灭舍弃；又有无量有福德的众生，钦奉这经，如理修学，勤加精进：为了求无上正等菩提，为了求尸罗，为了求多闻、求定、慧、解脱、解脱智见，为了求一切佛法，利乐一切众生，为了舍弃邪见、修行正见，为了舍弃生死流转、修习圣道，为了演说正法、降伏天魔，为了舍离贪爱、调伏瞋心、摧破愚痴、除灭无明、发起智慧之明。

“再者，舍利子！未来之世若有众生听闻这法之后，为了求一切善法，当发起增上的勇猛正勤；由于听闻这样的微妙之法，对于诸佛之法无有障碍，决定无疑。舍利子！那时又有无量众生，被福德之果所资助，住于增上之意，为了求无上正等觉而听闻这部经典，听后将获得广大欢喜，对菩萨藏微妙法门极善研习，如说修行。又，舍利子！那时将有对如来教法乐于闻法的人，那些众生随以什么样的差别因缘，得以听闻这样的经典，听后将获得广大欢喜；生起欢喜之后，发起坚固的精进，能对这样的大菩萨藏微妙法宝取得少分之宝。

【按】“取少宝分”之“宝”，宋、元、明、宫本作“实”。

#### 海中熟果之喻

“舍利子！譬如大海水上漂流着无量种种成熟的果实，色、香、美味都具足。有一个丈夫发起勇猛的大精进之力，便进入海中，运动手足，接取那果实，或两个、或三个。这丈夫拿着这些果实从海中出来，到了一个地方，取来品尝，才知道其味淳美希有，便这样想：‘这样色香味俱足的妙果，我从生下来从未吃过，应当再发勤精进，重新进入海中，运动手足，收取其余的果实。’这样想后，来到海滨，遍处观看，再也看不见了，深深追悔，生起大忧恼：‘我先前为什么不多收取，竟令失去了这无量的妙果！’这样，舍利子！在我灭度之后的后五百岁，无上正法将要灭尽之时，将有无量众生等，少信、少施、少戒、少慧、少修精进，随以什么样的差别因缘，得以听闻这样的经宝。听闻正法之后，对于这经只得到少分微浅之义，乃至只受持一首四句颂，又被恶魔娆乱障蔽，不被众人所敬问以及供养、称赞、信奉。这位持经者知道众人不敬重，便对这经安住于舍弃之心，持着先前所闻经中句义的微细少分，前往一处静处思惟观察，心生欢喜，而又悔恨，这样说：‘呜呼！奇哉！我现在大失善利！诸佛如来的无上正教，为什么不多听闻领受？’又对如来生起深重之心，比先前发正念时更加倍。舍利子！在那个时候，有诸苾刍被恶魔所持，听闻这经之后，在众人面前将起诽谤，说这部经典是诸文人才子所造作，实在不是佛说。由于这样，有诸苾刍对这部经典全不听受。”那时世尊想重宣此义，而说颂道：

```
闻是法已，当无障碍，
于诸佛法，最上无疑。
诸少福者，不得听闻，
诸多福者，闻是经典。
少福之人，虽闻不信，
多福闻已，顶戴如鬘。
诸少福者，言非圣教，
当坠恶趣，如盲堕坑。
多福之人，闻生欢喜，
当往善趣，如酥滴水。
诸薄福者，闻生忧恼，
受苦长夜，不脱黑暗。
虽得少闻，复为魔娆，
谤佛菩提，速入地狱。
```
（大意：听闻这法之后，便无障碍，对于诸佛之法，最上而无疑。诸少福的人，不得听闻；诸多福的人，得闻这经典。少福之人，虽闻而不信；多福之人听闻之后，顶戴如花鬘。诸少福的人说这不是圣教，将坠入恶趣，如盲人堕入坑中。多福之人听闻后生欢喜，将往生善趣，如酥滴入水中。诸薄福的人听闻后生忧恼，长夜受苦，不能脱离黑暗；虽得少许听闻，又被魔娆乱，诽谤佛的菩提，迅速堕入地狱。）

原文：“当往善趣，如酥滴水”（大意：将往生善趣，如酥滴入水中。“如酥滴水”所取之义未详，存疑。）

#### 四种无障清净之法

“再者，舍利子！诸佛如来具足成就清净妙智，乃至能知四众之心：若一苾刍、苾刍尼、邬波索迦、邬波斯迦，在未来世正法灭时，或有人听闻这样的经典，随顺领受；或有人听闻之后轻毁诽谤；或有众生全不听闻；这样一切，如来的净智都能了知。舍利子！若有菩萨摩诃萨以及其余一切众生，听闻之后领受这样的经典，精进修习，将成就四种无障清净之法。是哪四种？一是成就尸罗无障清净，二是成就具足无难清净，三是成就逢值诸佛、亲自承事供养的无障清净，四是成就见到慈氏佛、初见之时的无障清净。舍利子！那些众生听闻这经之后，如上所说的种种妙善根，随其方便必定获得。舍利子！这名为菩萨摩诃萨因修行正勤波罗蜜多而成就的四种无上清净之法。

【按】原文“邬波索、迦邬波斯迦”断句有误，当作“邬波索迦、邬波斯迦”，即优婆塞、优婆夷。

#### 正法灭时的十种障碍

“再者，舍利子！在未来世正法灭时，有诸菩萨摩诃萨安住于大乘，修行正勤波罗蜜多，对这部经典勤加修学，发大精进，听闻受持，书写读诵，穷究旨趣，广为他人宣说，敷扬开显。那时将有十种障碍之法出现于世间，诸有智者应当深深觉知，不应随之而转，只应发起勇猛精进，受持这经。舍利子！什么名为十种障碍，智者觉知而不应随转？

“舍利子！有诸苾刍发勤精进，对这部经典求闻诵习，那时恶魔令持经者口噤不能说话，便对这经不能建立。这名为第一障碍之法，诸有智者应当深深觉知，不应随转。又，舍利子！有诸苾刍发勤精进，对这部经典求闻诵习，那时恶魔令持经者患眼病，便对这经不能建立。这名为第二障碍之法，诸有智者应当深深觉知，不应随转。又，舍利子！有诸苾刍发勤精进，对这部经典求闻诵习，那时恶魔令持经者身体各个支节同时都病，便对这经不能建立。这名为第三障碍之法，诸有智者应当深深觉知，不应随转。又，舍利子！有诸苾刍发勤精进，对这部经典求闻诵习，那时恶魔令持经者对其住处心不喜乐，随即想要舍弃，便对这经不能建立。这名为第四障碍之法，诸有智者应当深深觉知，不应随转。又，舍利子！有诸苾刍发勤精进，对这部经典求闻诵习，那时恶魔令持经者互生忿恚，以忿恚破坏其心，互相残害，便对这经不能建立。这名为第五障碍之法，诸有智者应当深深觉知，不应随转。

“又，舍利子！有诸苾刍发勤精进，对这部经典想要求得诵习，那时恶魔令持经者生起言诤之事、斗讼之事、讥刺之事、乖离之事、瞋骂之事；由于这些事，彼此口中互相生出矛矟，互相言讼，互相残害，互相乖竞；由于生起这样的诤竞之事，便生起障碍，对这部经典不能流通，起意造作其余事业。这名为第六障碍之法，诸有智者应当深深觉知，不应随转。又，舍利子！有诸苾刍发勤精进，对这部经典想要求得诵习，那时恶魔为了破坏，作出种种形相，或俗人之形，或出家之形，来到他们那里，娆乱其意，令他们对这经不能受持，反而加以谤毁，又起心乐于其余事业。这名为第七障碍之法，诸有智者应当深深觉知，不应随转。

“又，舍利子！未来之世正法将灭之时，那时有诸年少苾刍，对这部经典生起清净信心，心生爱乐，在我的法律中为了行毘利耶波罗蜜多而发勤精进，对阿耨多罗三藐三菩提深心安住，又对这经恭敬听闻，得闻之后生大欢喜。那时诸年少苾刍将被邬波柁耶以及阿遮利耶两位本学之师所障碍，令他们对自己的法不生乐欲。那时二师对他们说：‘你们所持的经，这不是佛语，不是佛菩提，不是正法，不是毘奈耶，不是大师之教。’那时那些苾刍听了师长的教诲，信受领解，对佛菩提便即弃舍。这时二师又对苾刍说：‘你们应当精进修学我所说的法与律。’那时诸苾刍信受领纳之后，先前所修习的增上善根被师长所破坏，全部断灭。舍利子！那些苾刍断了善根之后，又被恶魔所诳惑；由于被诳惑，对佛的正教造作障法之业，临命终时恶境现前，昏痴迷乱，乃至夭死之相都集中显现，又重新兴起感得地狱之业。舍利子！这样未来的种种不善之事，如来对此都能了知。又，舍利子！未来之世，有诸年少苾刍对这部经典生起种种恶见，诽谤不信，凡所游履、经行往来，以种种言语常兴谤毁，如来对此都能了知。

【按】“乃至夭死”之“夭”，宋、元、明、宫、圣本作“大”。

“舍利子！发勤精进、住于大乘的菩萨摩诃萨，在那时应当生起四种想。是哪四种？一是应当发起自我调伏之想；二是应当观察自身所作的事业，不应观察他人的种种事；三是对那些有情生起悲悯之想；四是住于空闲之处，对于自他之心生起随顺守护之想。舍利子！这样的四种想，住于大乘的人若被诽谤，应当发起。

“又，舍利子！未来之世，无量众生接受种种邪见，对那演说正法的苾刍，信受的人少，不怀敬重，不请问经义，又不供养、亲近、往来，也不承事，反而生起凌蔑；对那宣说非法的苾刍，信受的人多，得到大势力，为众生所共同敬重，请问经义，供养称赞这些说非法的人。因此缘故，又对这经毁谤讥笑。舍利子！在那时，众生等对这部经典本不欣乐的，听到这毁谤，更加不欣乐；那些欣乐的人，因为被谤毁，便对这经舍离乐欲，又教他人离开乐欲。诸苾刍等转加炽盛，致使转读这部经典的人在众会之前不能开示。这名为第八障碍之法，诸有智者应当觉知，不应随转。

【按】“凌蔑”之“凌”，宋、元、明、宫本作“陵”。

原文：“诸苾刍等转更炽盛”（大意：诸苾刍等转加炽盛。所指何等苾刍未详，存疑。）

“又，舍利子！未来之世有诸苾刍，被贪爱所蔽，多行劫盗，欣乐世间的三种弊法。是哪三种？一是欣乐追求世间的衣钵，二是欣乐追求世间的饮食，三是欣乐追求世间的戏论、绮饰文颂。这样的三种法，名为第九障碍之法，诸有智者应当觉知，不应随转。

“又，舍利子！未来之世正法灭时，有诸菩萨安住于大乘，因行毘利耶波罗蜜多，对这部经典发勤勇猛，增上精进，书写、受持、研寻、读诵，广为他人开示演说。那些人将被诸魔所执持，被烦恼业障所覆蔽，喜好世间之业，乐于世间之业，以方便勤求世间事业；对于世间谈论，喜乐转增，以方便勤求世间谈论；喜乐睡眠；以方便勤求，喜于众乱，乐于众乱，以方便勤求，乐著众乱。对这部经典不能受持，又不转读研寻其义，也不为他人广为敷演开示。舍利子！在佛教中，没有其余的能作内部损害，没有其余的能迅速毁灭，唯除懒惰的诸恶苾刍。这名为第十障碍之法，诸有智者应当觉知，不应随转。”那时世尊想重宣此义，而说颂道：

【按】“又不转读”之“读”，明本作“诵”。

```
正法灭时多障碍，
当兴种种恶魔业，
于白净法不修习，
亦不乐求胜涅槃。
薄少智慧具恶觉，
不求安住于正法，
备行种种非法行，
游诸恶趣定无疑。
彼诸众生临命终，
无有能为救护者，
又彼亲教及传授，
命终当堕三恶趣。
百千拘胝那庾劫，
为求世利涉诸苦，
常为三火所烧然，
云何令彼速解脱？
我已证成无等觉，
转于微妙梵法轮，
诸天世间不能转，
今故为转度众生。
如是彼时诸群生，
舍我世间难得法，
习近恶魔诸品类，
当受无边极重苦。
障彼习行施戒等，
菩提圣道之因缘，
若有精勤于佛教，
当迷惑彼正道路。
```
（大意：正法灭时多有障碍，将兴起种种恶魔之业，对于白净之法不修习，也不乐于求取殊胜的涅槃。智慧薄少，具足恶觉，不求安住于正法，具行种种非法之行，必定游于诸恶趣，无疑。那些众生临命终时，没有能为他们救护的人，又他们的亲教师以及传授之师，命终也将堕入三恶趣。在百千拘胝那庾多劫中，为了求世间之利而经历种种苦，常被三毒之火所焚烧，怎能令他们迅速解脱？我已证成无等正觉，转动微妙的梵法轮，诸天世间所不能转的，现在所以为众生而转。这样，那时的众生舍弃我这世间难得之法，习近恶魔的种种品类，将受无边极重的苦。障碍他们习行布施、持戒等这些菩提圣道的因缘，若有人精勤于佛教，便将迷惑他们的正道之路。）

【按】“备行”之“备”，宋、元、宫本作“修”。

```
诸有听闻如是法，
宣说无我诸空理，
安住此法正行时，
恶魔当为彼障碍。
谓此最胜此真实，
于非胜实胜实想，
反加谤毁佛正教，
当知速堕于地狱。
若有众生于佛所，
深起坚牢爱恭敬，
听闻如是正法已，
欢喜随顺而称赞。
恶魔知彼既生喜，
与诸眷属同愁怖，
便兴种种惊畏相，
于彼人所生留难。
或当变作苾刍形，
诈现相亲窃言议，
谓此非正菩提道，
何故在此而奔趣？
有诸众生于是经，
将发坚固住正勤，
又被诱附而轻弄，
用斯废舍不修学。
既被魔罗所惑乱，
随魔意转而拘执，
乃告此经非正法，
便于寂灭永弃舍。
```
（大意：诸有听闻这样的法，宣说无我、诸空之理，安住于此法而正行之时，恶魔将为他们作障碍。认为“这是最胜，这是真实”，对于非胜非实的生起胜实之想，反而谤毁佛的正教，应当知道将迅速堕入地狱。若有众生在佛所深深生起坚牢的爱敬，听闻这样的正法之后，欢喜随顺而称赞；恶魔知道他已生欢喜，与诸眷属一同愁怖，便兴起种种惊畏之相，在那人那里制造留难。或者变作苾刍之形，诈现亲近，私下议论：“这不是正确的菩提之道，为什么在这里奔趣？”有众生对这经将要发起坚固，安住于正勤，又被诱导而轻慢戏弄，因此废舍而不修学。既被魔罗所惑乱，随魔的意而转，被其拘执，便说这经不是正法，于是对寂灭永远弃舍。）

【按】“便兴种种”之“兴”，《大正藏》作“与”，CBETA依高丽藏作“兴”，今从之。

```
彼又弃舍大导师，
复不勤求无上法，
又复发生我爱已，
速疾趣彼地狱中。
尔时当有少众生，
乐欲勤求此空法，
不得和合同修习，
乃各流散他方土。
如是无上最胜法，
诸当闻者皆轻毁，
持法者怖远逃避，
是相当兴未来世。
此国全无持法者，
远方虽有未为多，
纵有受持此经者，
悉皆捐舍无咨问。
世间依怙圣教中，
如是甚深无上法，
无量障碍在未来，
了然犹如现在住。
时有持法贤善者，
不顾身命住空闲，
修习演宣如是法，
速疾往升于善趣。
```
（大意：他们又弃舍大导师，也不勤求无上之法，又生起我爱之后，迅速趣入那地狱之中。那时将有少数众生，乐欲勤求这空法，却不得和合共同修习，便各自流散到他方国土。这样无上最胜之法，将来听闻的人都加以轻毁，持法的人恐怖远逃，这种情形将在未来世兴起。此国全没有持法之人，远方虽有，也不多，纵然有受持这经的人，人们也都捐舍而不去请问。世间依怙的圣教之中，这样甚深无上之法，未来有无量障碍，清楚得如同现在一样。那时若有持法的贤善之人，不顾身命，住于空闲之处，修习演说这样的法，便迅速往升于善趣。）
