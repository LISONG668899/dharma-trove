# 法性本来面目

**堪钦阿旺巴桑 造　白话译文**

---

如是，关于法性等义……

法性的本然体性，虽然是"有"的，但从眼见的角度而言，却并不显现出任何具体的相状；虽然说它是"无"，却又不是彻底断灭、一无所有；它不堕于"有"或"无"任何一边，却也并没有执持一个叫做"中"的东西作为立足点——正因为如此，它超越了始与终、生与灭、去与来、（过去现在未来）三时、边缘与中央，也超越了一切勤作与修成。

对于这样一种超越了一切戏论边际的东西而言，"解脱"根本没有一个可以立足的基础——因为它本来就如同水面上画出的图纹一样，随画随散，任运自然地自行消解，无需任何外在的因缘去促成它的消融。之所以这样说，是因为这个法性本身周遍一切、无处不在，没有一个独立的所依之基，也没有一个可以追溯的根源。

在这言语、思维、表诠都无法企及的境界之中，与那自然明朗、当下现见的胜观本自一体、无二无别的这个层面上——烦恼以及种种分别念的聚集，从本以来，就不曾真正"有过"，也同样不曾真正"没有过"；它们不是靠"断除"才被断除的，不是靠"净化修炼"才变得清净的，不是靠"转变"才被转变的，也不是靠"解脱"才获得解脱的。

如果不能真正领会这一点——即"以解脱而实无所解脱"这一层意涵，就会把"所应断除之物"与"能断除之法"等等，看作截然对立的两种东西。然而，实际上，这一切法从本体上说本来就是同一个东西，所以"净化"与"解脱"根本不能被割裂开来、当作前后两个不同的阶段来理解。

正如吉美林巴尊者在《功德藏》中这样说道：

```
ཨེ་མ་སེམས་ཉིད་རིག་པའི་ངོ་བོ་སྟེ།
མ་བཅོས་མ་བསླད་རང་སར་རང་བབས་ཞོག
རང་སེམས་མ་བཅོས་རིག་པ་གཅེར་བུ་འདི།
རྒྱལ་བ་རྣམས་ཀྱི་ཐུགས་དང་ཡེ་ནས་མཉམ།
```

大意：奇哉！心的本性，正是觉性的本体啊——不需要任何造作，也没有一丝一毫的染污，只需任其自然，安住于它本自具足的本位之中。这未经丝毫改造的自心，这赤裸裸、一丝不挂的觉性，从本以来，就与一切诸佛的密意平等无二、毫无差别。

又说：

```
སྒོམ་མེད་རིག་པ་ལྷུན་གྲུབ་ཆེན་པོ་ནི།
བཅའ་བཅོས་མ་བྱེད་རིག་བསྲུང་ངང་དུ་ཞོག
```

大意：无需刻意修持的觉性，正是这大自成、任运圆满的本体——不必对它做任何整治、造作，只需护持这份觉性，让它安住在本然的状态之中。

---

《法性本来面目》（终）
