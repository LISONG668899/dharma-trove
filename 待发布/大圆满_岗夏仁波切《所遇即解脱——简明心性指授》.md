# 所遇即解脱
## 于吉祥札估讲修兴盛洲所传授之简明心性指授

堪布岗夏旺波 造

## 前行

若作善业，则生安乐之果；若作不善业，则生痛苦之果，此理无欺不虚，故须认清何为善、何为恶。

于此，首先须指认身、语、意三者；认识之后，须了知善恶二者，究竟由身、语、意三者中何者为主。

若问何者为主，则心为最主要者：

```
ལུས་ནི་དགེ་སྡིག་ཀུན་གྱི་གཡོག་པོ་ཡིན། །
སེམས་ནི་ཀུན་ལ་དབང་སྒྱུར་རྒྱལ་པོ་འདྲ། །
```

身乃一切善恶之仆从，心乃主宰一切、犹如国王——如是所说。

心犹如国王，身与语二者犹如仆从，因此，若心未曾念及，身则不可能造作善恶之业，语亦不可能说出好坏之言语，故须认清：其根本，终归于心。

而后，应观察此心究竟是有、还是无。它并非单方面成立为有，因其并无白、黄、红、绿等颜色，亦无三角、四方等形状可见。然亦并非单方面成立为无，因这周知周觉之王——能思、能忆之作用，从未间断地存在。

是故，吉祥让炯多杰足下曾说：

```
ཡོད་པ་མ་ཡིན་རྒྱལ་བས་ཀྱང་མ་གཟིགས། །
མེད་པ་མ་ཡིན་འཁོར་འདས་ཀུན་གྱི་གཞི། །
```

非是有故，纵佛陀亦未曾得见；非是无故，乃轮涅一切之根基——如是所说。

以上，前行部分已竟。

## 正行

正行者：身心舒适坦然、松坦而住，不作任何思虑，任运安住。眼睛向上、直视虚空，口微微张开，呼吸任其自然，如是之时——

无论所思为何、所忆为何、所现为何、悦意与否，皆无所思、无所忆、无所显、无所悦、无所苦之心性本身，明朗朗、鲜活活、锐利利、赤裸裸者——此即三界一切有情心之自性，亦即殊胜导师、吉祥上师之智慧心，三世诸佛之密意。

亦称为"法身大手印"，亦称为"光明大圆满"，亦称为"道果"，亦称为"空性大悲"。虽有种种不同名称，然其所指之处，实为同一。

是故，吉祥让炯多杰足下曾说：

```
ཐམས་ཅད་བདེན་མིན་རྫུན་མིན་ཏེ། །
ཆུ་ཟླ་བཞིན་དུ་མཁས་རྣམས་འདོད། །
ཐ་མལ་ཤེས་པ་འདི་ཉིད་ལ། །
ཆོས་དབྱིངས་རྒྱལ་བའི་སྙིང་པོ་ཟེར། །
```

一切既非真实、亦非虚妄，智者皆许其如水中之月；此平常心识本身，即称之为法界、佛之心要——如是所说。

无论何念生起，皆不加造作，直接任运安住；生起次第、圆满次第、持诵、观修等一切之心要，悉皆含摄于此。

于此，须辨明散乱与不散乱二者之差别。若不散乱、任运安住，无有任何利害者，即是本觉；若略有散乱，则心中或将生起苦乐，由此而积集黑白之业分，因而于轮回中流转。

故须辨明"心"与"觉性"二者之差别；心识分别念犹如云朵聚集一般，须使其澄净；内在之觉性，须令其坚固。

于此，须修习以疾病为道用、以烦恼为道用、以中阴为道用、以愚痴（昏沉）为道用等。一切道用之心要，即是于本体之上任运而住。

此时，不须过多繁琐赘言。

此乃兼具智者与成就者二德之岗夏旺波，于火鸡年六月初七日，于札估札西曲林寺属下之讲修兴盛洲学院共同僧众之前，慈悲传授而成。吉祥圆满！

## 译者说明

本篇依藏文原文重新译出，参考但不依循已有中译本之措辞。原题直译为"于吉祥札估讲修兴盛洲所传授之简略相遇即解脱心性指授"，"འཕྲད་ཚད"（凡所相遇）意谓无论遇上何种境相——苦乐、疾病、烦恼、乃至中阴——皆可当下解脱，此为题中要义，故以"所遇即解脱"为题。文中两处所引让炯多杰（第三世噶玛巴）之教证，皆依藏文原颂重新译出并置于代码框内，以与正文散文体分开标示。
