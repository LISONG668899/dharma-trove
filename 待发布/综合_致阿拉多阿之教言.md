# 致阿拉·多阿之教言

*华智仁波切 造*

【译注：阿拉·多阿（阿拉·多阿嘉措，又称"扎巴·多阿"）生平事迹鲜为人知，多见于其同时代高僧传记中的旁笔。在华智仁波切的传记中，他曾作为居中联络人，试图促成华智仁波切与瑜伽士夏嘎·措珠让卓（1781—1851）的会面，然而此次会面终究未能成行——华智仁波切启程前往，行至果洛之时，方得知夏嘎已然示寂。而在蒋阳钦哲旺波的另一位法嗣米滂仁波切的传记中，阿拉·多阿又被塑造为一位在辩经中败于米滂仁波切之手的、见地有所偏失的论敌形象。】

```
ཤིང་མཆོག་དམ་པ་ཉེ་གྲོ་དྷ་ཡི་དྲུང་དུ། །
སྡེ་དང་བཅས་པའི་བདུད་སྡེ་ཇི་སྙེད་མ་ལུས། །
རང་ཉིད་གཅིག་པུའི་བྱམས་པའི་སྟོབས་ཀྱིས་བཏུལ་ནས། །
མངོན་སངས་རྒྱས་པའི་སྟོན་པ་མཆོག་དེ་མཁྱེན་ནོ། །
```
于至圣毕钵罗树下，独自一人，仅凭慈心之力，便降伏了魔王及其眷属大军——如是圆满正觉的殊胜导师，愿您垂念于我！

```
མགོན་པོ་ཁྱེད་ཀྱིས་འཁོར་ལོས་བསྒྱུར་བའི་རྒྱལ་སྲིད། །
དུག་དང་འདྲེས་པའི་ཟས་བཞིན་ཡོངས་སུ་སྤང་སྟེ། །
རང་ཉིད་གཅིག་པུ་དབེན་པའི་ནགས་སུ་གཤེགས་ནས། །
རྩེ་གཅིག་བསམ་གཏན་སྒྲུབ་པར་མཛད་ཅེས་ཐོས་སོ། །
```
怙主，您舍弃转轮王之国政，如弃毒食一般彻底抛却；您独自一人前往寂静山林，一心修持禅定——我如是听闻。

```
དེ་ཡི་ཕྱིར་ན་དབེན་པའི་རི་ངོགས་ཉམས་དགའ། །
མགོན་པོ་མཆོག་དེའི་རྗེས་འཇུག་བུ་ལ་གནང་བའི། །
ཕ་ཁྱིམ་ལགས་ཕྱིར་སྐྱོབས་པ་མཆོག་དེའི་བཀའ་བཞིན། །
དབེན་པ་བསྟེན་པ་སྐྱིད་པའི་ཡང་རྩེ་ལོས་ཡིན། །
```
正因如此，寂静的山崖河谷，才如此令人心生欢喜；这正是殊胜怙主赐予其追随之子的家业。遵从至尊怙主的教敕，依止寂静而修，正是安乐之巅峰。

```
ནགས་དང་དགོན་པ་བས་མཐའི་གནས་མལ་ལ་སོགས། །
རྒྱལ་སྲས་རྣམས་ཀྱི་ཕྱི་ཡི་དབེན་པ་ལགས་ཏེ། །
རང་འདོད་ཡིད་བྱེད་ཞུམ་པའི་བློ་ཆུང་སྤང་བ། །
སེམས་དཔའ་རྣམས་ཀྱི་ནང་གི་དབེན་པ་དེ་ལགས། །
```
森林、静处以及荒僻的边地栖所等等，这些是佛子们外在的寂静；而舍弃只顾自身安逸、怯懦退缩的狭小心量，这才是菩萨内在的寂静。

```
དེ་ཕྱིར་ཕྱི་ཡི་དབེན་པ་དག་ལ་བསྟེན་ཏེ། །
ནང་གི་ཉོན་མོངས་ཞི་ལྷག་སྟོབས་ཀྱིས་འདུལ་ཞིང་། །
ཀུན་བཟང་སྤྱོད་མཆོག་སྨོན་པའི་ཡུལ་དུ་བཟུང་བའི། །
སྐལ་བཟང་དེ་འདྲ་རྒྱལ་བའི་སྲས་པོ་ཡིན་ནོ། །
```
因此，依止外在的寂静，以止观之力调伏内在的烦恼，将普贤菩萨殊胜行愿作为祈愿的对境——具有如此福德之人，才真正堪称胜者之子。

```
ལྷུང་ལྷུང་བསིལ་བའི་ཕུ་ཆུ་སྙན་པར་འབབས་ཤིང་། །
བྲག་རིའི་བ་གམ་ལྷ་ཡི་ཐེམ་སྐས་འགྲམ་ལ། །
ཟླ་འོད་དཀར་པོའི་ཟིལ་པ་དལ་གྱིས་འབབ་པའི། །
དབེན་པའི་རི་དེ་ལྷ་ཡུལ་ལས་ཀྱང་ལྷག་གོ ། །
```
潺潺清凉的溪水淙淙流淌，岩崖峭壁宛如登天的阶梯，皎洁月光的露珠缓缓滴落——这样的寂静山林，胜过天界。

```
འདོད་ཉོན་མི་སྐྱེ་རྐང་འཐུང་བུ་མོའི་ཟློས་གར། །
ཆགས་སྡང་ཡུལ་མིན་བྱ་ཚོགས་སྙན་གླུས་བཟུང་ཞིང་། །
རྟོག་མེད་དེ་ཡི་གྲིབ་བསིལ་འཇམ་པོས་འགེབ་པའི། །
གཞོན་ནུའི་གྲོགས་དེ་སྐད་མེད་སྟོང་ལས་ལྷག་གོ ། །
```
五欲烦恼无从生起，没有汲水少女的歌舞喧闹，也没有引生贪嗔的鸟语声——唯有悦耳的鸣啭，笼罩在无分别的清凉树荫之下——这样年少的伙伴，胜过千言万语的寂静虚空。

```
བསམ་གཏན་ཚེར་མ་སྒྲ་ཅ་ཅོ་མེད་པའི། །
གྲོགས་མེད་གཅིག་པུ་དབེན་པའི་གནས་བཟང་དེ་ན། །
སེམས་ཀྱི་སྤྲེ་རྒན་ཡུལ་ལ་འཕྱན་པ་མེད་དེ། །
ནང་དུ་གནས་ནས་ཉམས་མྱོང་སིམ་པ་སྤྱོད་དོ། །
```
在这样美好的寂静之处，没有会扰乱禅定的荆棘般喧哗噪声，独自一人、没有伴侣——心中那只老猿猴，再也无处攀援外境游荡，只能安住于内，享受禅悦法喜。

```
མང་ཚོགས་རྣམ་གཡེངས་ཉི་མའི་འོད་ཀྱིས་ནོན་པའི། །
རང་སྐྱོན་རྟོག་ངན་རྒྱུ་སྐར་ལས་ཀྱང་མང་བ། །
དབེན་གསུམ་བསིལ་ཟེར་བདུད་རྩིའི་རེག་ལས་མངོན་ཏེ། །
གཉེན་པོའི་སྟོབས་ཀྱིས་གཞོམ་ལ་དཀའ་བ་མ་ལགས། །
```
身处熙攘散乱的人群之中，如烈日般被遮蔽的，是自己那多于繁星的种种过失与恶劣分别念；而唯有触及三种寂静【译注：即身、语、意三门之寂静】清凉甘露之光，才能以对治之力轻易摧破它们。

```
སྐྱོ་བའི་ཉམས་ཀྱིས་རྟོག་པའི་རྙོགས་མ་བགྲུང་བའི། །
སེམས་ཀྱི་རྫིང་བུ་གཡོ་མེད་གནས་པའི་ངང་ལ། །
དད་དང་སྙིང་རྗེའི་གཟུགས་བརྙན་འགོག་མེད་འཆར་བའི། །
ལྷོད་མེད་དེ་ལ་གཅིག་པུའི་སྐྱོ་གྲོགས་ཅི་དགོས། །
```
当心中不为忧愁烦恼所搅扰、如止水般澄澈安住之时，信心与悲心的影像便会不受阻碍、自然浮现——在这样毫不松懈的状态中，又何须寻觅伴侣来排遣孤独？

```
སེམས་ཀྱི་མེ་ལོང་ཕྱིས་ཤིང་ཕྱིས་པའི་ངོས་ལ། །
ཡུལ་རྐྱེན་མང་པོའི་གཟུགས་བརྙན་འཆར་བ་མེད་ན། །
ཐོས་བསམ་བསྒོམ་པའི་རི་མོ་གསལ་ཞིང་བཀྲ་སྟེ། །
ཉམས་མྱོང་ཆོས་ཀྱི་འོད་སྣང་འཆར་ལ་སུ་འགོག །
```
若心的明镜不断被外境、外缘的种种影像所蒙尘，那么闻思修所刻画的图案，便能清晰灿然地映现——那时，谁还能阻止修证体验的法光升起呢？

```
བཀྲེས་སྐོམ་གྲང་སོགས་ལུས་ཀྱི་གདུང་བའི་ཚོགས་དང་། །
སྐྱོ་འཇིགས་ལ་སོགས་སེམས་ཀྱི་དུཿཁ་དུ་མ། །
ཆོས་བཞིན་སྤྱོད་ལ་སྒྲིབ་སྦྱང་ལམ་གྱི་བོག་འདོན། །
སྤང་བླང་ཅི་དགོས་སེམས་ཀྱི་རྒྱན་དུ་འཁྱེར་ཆོག །
```
饥渴寒冷等种种身体的煎熬，忧愁恐惧等种种内心的痛苦，若能如法修持而转为道用，便能成为净除障垢、加速证悟之道的助力——何须刻意取舍？大可将其转为庄严自心的饰品。

```
བླུན་པོས་སྨོན་པའི་འདོད་ལྔ་ཡུལ་གྱི་བདེ་བ། །
དབེན་པའི་གནས་ན་ལྷ་བཞིན་བལྟམ་པ་མེད་ཀྱང་། །
མཁས་པས་བསྔགས་པའི་ཆོས་ཀྱི་དགའ་བ་བརྒྱ་ཕྲག །
དགའ་ལྡན་ལྷ་ལས་དབེན་པའི་ནགས་ན་མང་ངོ་། །
```
愚人所祈愿的、外境中五欲的享乐，在寂静处虽不似天人那般唾手可得；但智者所赞叹的百千种法喜，在寂静山林之中，却比兜率天宫更加丰盛。

```
སྡུག་བསྔལ་གདུང་བ་བརྩོན་པའི་གྲོགས་སུ་འཆར་བའི། །
རྒྱལ་སྲས་དེ་ལ་ཆོས་ཀྱི་འགལ་ཟླ་མེད་དོ། །
བྱེ་བ་བརྒྱ་ཕྲག་བདུད་སྡེ་དགྲ་རུ་ལང་ཀྱང་། །
རྐྱེན་ངན་གྲོགས་ཤར་མཁས་པ་དེ་ལ་ཅི་བྱ། །
```
对于能将痛苦煎熬转为精进助伴的佛子而言，没有任何事物是与修法相违的；纵使千百万魔军的大敌一齐蜂拥而起，于这样以恶缘为道友的智者而言，又能奈何？

```
བླ་མའི་མན་ངག་བདུད་རྩིའི་འབྲས་བཟང་མྱོང་བ། །
ཐོས་མང་ཚིག་གི་སྤུན་པ་འཕྱར་ཕྱིར་མི་རྒྱུག །
ས་མཆོག་སེམས་དཔའི་ཐུགས་རྗེའི་འོད་སྣང་འདོད་དེ། །
སོ་སྐྱེ་གཏམ་གྱི་སྒྲོན་མེར་རེ་བ་མ་ཡིན། །
```
已经亲尝上师窍诀甘露妙果之人，绝不会再追逐那多闻夸夸其谈的空洞言辞；他所祈愿的，是登地菩萨大悲的光明，而不是凡夫俗子闲谈的微弱灯光。

```

མོས་གུས་བརྩོན་པའི་རྒྱུད་ལ་ཐང་ལྷོད་མེད་པའི། །
ང་རྒྱལ་རློམ་པའི་བདུད་ལ་དོགས་ཟོན་མཛད་ནས། །
ཚེ་འདི་སྐྱིད་ཀྱིས་ཆོད་པར་མཛོད་ཅིག་ཨེ་གོ །
```
我的道友，你已然踏上了通往一切安乐的道路；只是在信心与精进不曾松懈之时，也务必对我慢自满这个魔障保持警惕、加以提防——这样，此生也定能以安乐画上句点，你明白吗？

```
ལྷ་མཐོང་འདྲེ་རིག་རྫུན་གྱི་རྐྱལ་ཆེན་མ་རྡོལ། །
ཡོན་ཏན་ནོར་བུས་སེམས་ཀྱི་བང་མཛོད་བཀང་ནས། །
བཀའ་གདམས་གོང་མའི་རྗེས་ཤུལ་ཁྱེད་ཀྱིས་སྙོགས་པའི། །
སྨོན་ལམ་བདེན་དཔང་ཐོག་མའི་མགོན་ལ་ཞུའོ། །
```
不要被"见到本尊"、"觉知鬼神"之类虚妄的谎言，撑破了自欺的大气球；而应当以功德之珍宝，充实自心的宝库；愿你追随往昔噶当派祖师们的足迹——以此真实的祈愿，向本初怙主祈请为证。

```
ཨ་བུ་ལས་ངན་རེ་ཞིག་ངན་འགྲོར་འཆི་ཡང་། །
བླ་མའི་ཐུགས་རྗེས་ཐར་པའི་དུས་ཤིག་ཡོད་ཀྱི། །
དེ་ཚེ་མ་རྒན་འགྲོ་ཀུན་ཟད་ཀྱི་བར་དུ། །
བྱང་ཆུབ་སྤྱོད་མཆོག་ལྷན་ཅིག་སྐྱོང་བར་སྨོན་ནོ། །
```
纵然我阿布这个罪业深重之人，此番命终恐将堕入恶趣，但终有一日，仰赖上师的悲心眷顾，必得解脱之时；届时，愿我能与你携手同行，共同护持殊胜的菩提行愿，直至一切如母有情的痛苦悉皆穷尽为止。

```
དྲང་པོའི་གཏམ་འདི་དྷི་ཆུང་དབེན་པའི་རི་ནས། །
ཡིད་ཅིག་གྲོགས་དེའི་སྐྱོ་བ་སངས་པའི་ཆེད་དུ། །
ཁ་ལ་འཇའ་ཤར་ཨ་བུ་ཧྲལ་པོས་ཕུལ་ལོ། །
བརྗོད་དོན་ལེགས་དགུ་མངོན་དུ་མཐོང་བར་ཤོག་ཅིག །
```
这番出自真心的诚挚话语，是从底穹（意为"小林"）的寂静山中，为了消除一位知心道友的忧愁，由衣衫褴褛的阿布口中，如彩虹般自然涌现而写就、呈奉的。愿其中所说的一切善妙义理，都能真实显现！
