# 除暗明灯之窍诀细说

## 串讲说明

本稿依据麦彭仁波切《除暗明灯》藏文根本文及 Lotsawa House 英译，参照康萨丹贝旺旭仁波切《除暗明灯释》汉文转载，并以麦彭仁波切《住、动、觉》《心性》及华智仁波切《智者吉祥王殊胜教言》自释作义理对照。它是串讲与疏通，不是根本文的逐句新译。

正文中标作“引文大意”的语句，是对原文的转述，不冒充某一汉译的逐字原话；标明“我们的疏通”的部分，是本稿的分析。穿插的藏文，取自 Lotsawa House 藏文电子本，以代码块呈现，供对照，不另作逐字翻译。

法王如意宝《窍诀宝藏库》与顶果钦哲仁波切讲解的全文尚未取得，本稿不据此立说。需要进一步校勘的词句与版本问题置于文末，不让未定的译法承担核心论证。

---

## 一、这盏灯照见什么

《除暗明灯》是一篇篇幅不长、下手极细的教言。它关心的不是怎样积累越来越多的特殊感受，而是怎样在自心上辨清：安静是否已经成为认识，清明是否仍带执取，认识以后怎样熟悉，熟悉又应如何检验。

全文有三个窍诀：破开无明蛋壳，断除生死之网，安住如虚空平等。随后引萨惹哈的教言，收摄修持要点，说明串习之量、正道之相与果位。

三个名称帮助我们把握教学重点，但不能把它们当作界线绝对分明的三个阶位。一个人可能尚未真正认识，就执著清明；已有初步认识，也可能再落回含混。阅读这篇教言，需要让前后相互校正：自然安住不能代替认识，认识不能代替熟悉，熟悉不能以执著一种感觉来完成。

本文所说“觉性”，对应藏文 rigpa，在此指被认识的本性之明知，不能凡见“知道”“清醒”就一概归入。所谓“觉受”，则是修持中出现的经验，例如乐、明、无念、宽广、沉静，或不悦、动荡与昏浊。经验可以很强烈，认识却不能只凭经验强弱来判定。

全文还有几条词脉，值得先记住，读到时自会相应：**“本然”**（藏文 བབས／བབ 一族），从看的方式一路用到本性的存在方式；**“澄清”**（དྭངས），三个窍诀的成果与果位都用它；**“仅仅”**（ཙམ），标记几处似是而非的岔口。

## 二、第一窍诀：安静之中，仍可能没有认出

第一窍诀从自然安住说起。让心不追随特定思考，并保持正念的相续，可能出现一种中性、无记、昏暗茫然的心识。粗大的念头暂时止息了，却没有辨明本性的胜观。

```
རང་གི་སེམས་འདི་རང་བབས་སུ་ཅི་ཡང་མི་བསམ་པར་བཞག་ནས་དེའི་ངང་དུ་དྲན་པའི་རྒྱུན་བསྐྱང་བ་དེའི་ཚེ་བཏང་སྙོམས་ལུང་མ་བསྟན་གྱི་ཤེས་པ་མུན་ནག་ཐོམ་མེ་བ་ཞིག་འབྱུང༌།
```

这是全文第一道分界：没有明显妄念，不等于无明已经停止。一个人可以清楚知道自己现在很安静，甚至能持续保持，却仍没有认识这份知的本性。

这里说“无明”，着重于未认识；说“无记”，原文解释为不能辨明、说出这究竟是什么；说普通的“舍”，则说明它可以看似平稳，却仍只是普通心识的安住。应按本篇的具体说明理解这些词，既不能机械套入其他论典的全部定义，也不能认为作者使用易懂法语，就完全取消了术语背景。

留意一处用字：这种“随意待着”（藏文 རང་གར་བསྡད་པ），与描述觉性的“自然安住”字面上几乎一样。昏昧之难辨，就难在它看上去同样松坦、同样无念、同样不作意。

本篇在这个语境中称此为阿赖耶中的普通安住。“阿赖耶”与后文“法身”的区分，是本篇认识与未认识的辨析；不能把这一处直接等同于唯识学关于第八识的全部理论。

安住法在这里有作用：它使粗重散乱暂息，为认识提供条件。但作为方便的是安住法，不能因此说无明本身是应当培养的方便。教言面对已经出现的含混，指出如何辨明，并没有要求人人先制造同样的昏昧，更没有把昏昧规定为一律必经的修道阶段。

原文紧接着一句转折，是这一层的分水岭：

```
བཞག་ཐབས་དེ་འདྲ་བ་ལ་བརྟེན་ནས་མི་རྟོག་ཡེ་ཤེས་བསྐྱེད་དགོས་ཀྱང༌། རང་ངོ་རིག་པའི་ཡེ་ཤེས་མ་ཤར་བ་དེ་འདྲ་བསྒོམ་གྱི་དངོས་གཞི་མ་ཡིན་ཏེ།
```

引文大意是：虽应依这样的安住而生起无分别智，但认识自性的智慧若未现起，这种安住就不是修持的正行。句首的让步语气（ཀྱང）承担了全句的转折，不宜断成两个各自独立的判断。

因此，遇到安静时，不必立即宣布认识成立；遇到含混时，也不必立刻否定此前所有安住。须辨清的是：这里究竟只有一种可维持的状态，还是对心的本性已有真实的认识。

## 三、破壳的转折：既然正在经验，就向心本身看去

第一窍诀最关键的转折，是说这种无念、不动而茫然的状态既然被心经验，就自然看向知道这一状态、无念而住的心本身。

```
དེ་འདྲ་སེམས་ཀྱིས་མྱོང་བས་ན་དེ་འདྲའི་དོན་ཤེས་མཁན་དང་མི་བསམ་པར་འདུག་མཁན་ཁོ་རང་ལ་བབས་ཀྱིས་བལྟས་པས་
```

我们可以这样疏通：行者原来停留于“这里很安静”“这里什么也没有”，教授将方向转向经验这一切的心。不是继续研究那片茫然的内容，也不是寻找另一种更高级的感受，而是从当下已有的经验入手。

句中 མྱོང་བས་ན，在此语境中是“既然被经验”而非“如果能体验到”；下手处就在当下的经验里。看的方式是 བབས་ཀྱིས——随当下之势而看，不另加一份更紧的审查。

不过，茫然被知道，只说明这里有教授的下手处；不能因此说，知道茫然的普通心识已经就是被认识的觉性。这里仍须有真正的转折。

原文用“知道者”“无念而住者”（两个 མཁན）引导，紧接着却说能经验与所经验无二。两处必须连读。借“者”指向心，不是为了找到一个真实不变的经验者；若只停在“我发现背后还有一个观察者”，主体只是退后了一层。

麦彭仁波切《住、动、觉》也说明，直看心的本性时，虽有种种显现，却无真实自性；虽空，明知却不因此断灭。能看与所看不再分离。我们的疏通是：找不到一个可执取的心，与明知并未消失，可以同时成立，不必在“有一个真实心”与“完全没有知觉”之间选择。

所谓自然看去，也不等于消极等待。它有明了的方向，却不必制造一份更紧的审查。若每看一次，又加一个负责检查的自己，便容易形成无穷后退的观察循环。

## 四、两种不可说：含混与确然不能混同

原文随即描述，觉性通透、无内外，虽无能受所受的二分，对自心本性却有决断。这不是靠解释把所有问题答完，而是所指之义不再含混。

第二窍诀进一步辨明，两种状态都可以被称为不可说：

```
སྔ་མ་མུན་ཐོམ་མེ་བ་དེ་ལ་བརྗོད་དུ་མེད་ཀྱང་ཅི་ཡང་བརྗོད་མ་ཤེས་པས་ཁོ་ཐག་མ་ཆོད་པ་ཡིན་ལ། རིག་པའི་ངོ་བོ་ལ་བརྗོད་དུ་མེད་ཀྱང་བརྗོད་མེད་ཀྱི་དོན་ལ་ཐེ་ཚོམ་པའི་ཁོ་ཐག་ཆོད་པ་ཡིན་པས་
```

先前的不可说，是未辨明，所以说不出；觉性的不可说，是其义不能由语言穷尽，却不因此犹疑。大师以盲人与明眼人的差别作比，并说阿赖耶与法身之辨也集中于此。

这个比喻很实在：两个人都沉默，不能由沉默判断他们看见的是否相同。同样，无念、离言、不作意，也不能单靠名字判断。

“决断”仍不能孤立成一个心理测试。强烈确信可以来自理论、暗示、特殊经验，甚至反复自我说服。这里的决断须连着通透、无二、无可执取来读，不能简化为“我相信自己悟了，所以认识成立”。

也不能把“本性自己决断”解释为一个更深的实体，对自己进行确认。此处藏文第二个“自己”是属格（རང་གི），不是施事格（རང་གིས），所以不宜读成“本性去确认自己”。要表达的是：没有另立主体面对客体，却并非昏昧无知。非二取之义，由“能受所受无二”一句承担；语言可以指引，不能替代认识本身。

## 五、第二窍诀：清明与空，也可以结成生死之网

第二窍诀先说，所认识的法性本来自然安住，不由因缘制造；离此而另有一个自成一体的心，也不可得。

```
དེ་ལས་གཞན་དུ་གྱུར་པའི་སེམས་ཞེས་བྱ་བ་རྡུལ་ཙམ་ཡང་ཡོད་པར་མ་དམིགས་སོ། །
```

所否定的是“离法性而另成一物之心”（གཞན་དུ་གྱུར་པ），用的是“找不到”（མ་དམིགས）而非“不存在”。这并非否定明知，而是防止在法性之外再立一个真实的心。

随后指出两种偏差。一种把单纯的明、单纯的知当作所护持者，住在“这里是明的”的感觉中；另一种把心执著在空的经验上，仿佛心识已经空掉了。两者都可能成为意识层面的二取觉受。

此处“仅仅是明、仅仅是知”连用两个 ཙམ，而“仅仅是知”用的正是觉性的那个“觉”字（རིག）——可见单纯的知觉性被当作所护持的对象，也会落入偏差。更细的标志是“觉得是明的”（གསལ་ལོ་སྙམ་པ）：未必是粗念，可能只是背后一份持续的感觉。

这里的危险不一定粗重。行者未必在心里说完整的句子，也未必觉得用力。他可能只是轻轻靠住某种感觉，怕它消失；或者默认这份感觉在那边，负责守住它的自己在这边。

我们的疏通是：问题不在清明或空出现，而在它们被固定为认识的凭据。清明一减弱，就以为本性消失；空的感觉一改变，就以为修持失败。这样，经验的变化便支配了对本性的判断。

这也不是“先认识成功，才会发生的错误”。尚未认识者可以误执，已有认识者也可能黏著。因此，第二窍诀兼有辨伪与去执的作用。

不能用“变明了”“变空了”直接排除认识。所认识的本性不由制造，但认识可以有初次发生，有从未辨明到辨明的变化。关键是有没有把后来获得的状态，当作本性本身。

## 六、拔出所依之橛：看清整个执取关系

对治时，原文同时列出清明与执取清明者、空与把空执为空者，要求看其本然。这一点不能省成“只看执取者，不看所执的状态”。

```
གསལ་བ་དང་གསལ་བ་འཛིན་མཁན་སྟོང་པ་སྟོང་པར་འཛིན་མཁན་གྱི་ཤེས་པ་དྲན་འཛིན་གྱི་རྒྱུད་བྲིང་ངེ་བ་དེའི་བབ་ལ་ལྟས་ནས་གཟུང་འཛིན་དུ་ཞེན་པའི་རྣམ་ཤེས་ཀྱི་རྟེན་ཕུར་ཕྱུངས་ཏེ་
```

所要辨明的，是当下这整个执取关系。如果只是从清明转向守清明的人，再从守清明的人转向观察他的另一个自己，观察位置不断后退，二取并没有因此终止。看的方式仍是 བབ（本然），与第一窍诀 བབས（随势）同族，不是用力审查。

原文以“拔出所依之橛”（རྟེན་ཕུར，固定、支撑之物）作譬喻。我们的疏通是：执取活动的本性被看清后，能所不再有可供固定的依据。不是找出一个隐藏主体，再把它消灭；也不是把所有明知压下去。联系窍诀之名“断除生死之网”：橛一拔，网自然垂落，不必一根根去剪网线。

更细的偏差，是把“去执”本身变成新任务。不断检查有没有执，努力守住一个无执状态，仍可能形成新的依靠。橛原来固定在清明上，后来可能固定在“我已经没有执取”上。

因此，第二窍诀不是无限的自我监察。它要求看清，而非不断另造一个负责看清的人。随后所说的明空无中无边，也不能只理解为感觉辽阔；它同时不支持把某个能知位置固定为中心。

原文说脱离“带执取的觉受之壳”（འཛིན་པ་ཅན་གྱི་ཉམས་ཀྱི་ཤུན་པ，修饰语“带执取的”不可省）。这不要求乐、明、无念一律停止，也不保证去执后原有觉受原样保留。经验可以继续、改变、消失；要脱离的是以它确立自己的黏著与遮蔽。

## 七、华智仁波切的对照：截断的不只是念头

华智仁波切《智者吉祥王殊胜教言》自释，在松坦安住后指出，初学者仍会执著乐、明、无念等经验。突然的“呸”，所击破的不只是念头的延续，也包括心所造作、所依靠的禅修。

所以，不能把两篇教授简单分工成“散乱者用猛力，昏昧者用轻看”。华智仁波切也面对安静修境中的黏著。两篇切入方式不同，却都不让行者躲在熟悉的体验中。

以“呸”骤然截断，不等于惊一下便已完成；自然返观，也不等于多想一层便已完成。两者都须落在认识，而不是只留下暂时的空白或清醒感。

这里的对照用于理解文义，不能据文字宣称自己已经取得某一传承教授的全部操作要点。我们可以辨清教言所破的错误，却不应把几个词拼成自动有效的认识公式。

## 八、第三窍诀：熟悉认识，不保存修境

第三窍诀说，应像辨认去壳的谷粒一样，辨认离开意测与觉受遮蔽的觉性。

```
ཡིད་དཔྱོད་ཉམས་ཀྱི་སྤུན་པ་སྣ་ཚོགས་དང་བྲལ་བའི་རིག་པ་འབྲས་སྣེའུ་ལྟ་བུ་ཆོས་ཉིད་རང་བབས་རང་གསལ་གྱི་སྒོ་ནས་ངོས་ཟིན་པར་བྱའོ། །རིག་པའི་གཤིས་དེ་ཤེས་པ་ཙམ་གྱིས་མི་ཆོག་པས་
```

要剥的不只是觉受，也包括 ཡིད་དཔྱོད（意测、推度之解）这层“我大概懂了”的壳。仅仅知道其本性还不够，还要熟悉，使安住稳固。这里的“仅仅”（ཙམ）与第二窍诀的“仅仅是明”同字而病处不同：那是把觉性缩小成觉受，这是只认出一次而未熟习。

这里没有“只认识一次”的限定。它区别的是知道与熟悉稳定。即使已有认识，旧习仍可能使行者散乱、追逐或再度含混。

需要熟悉的，不是某次体验的外观。若初次认识伴随宽广、安静，便反复复制宽广与安静，熟起来的可能是状态，而非不迷失的认识。

本性不是越练越成形；熟悉与稳定却可以增长。这两点需要同时成立。以本来具足否定熟悉，会把道上的差别抹去；以熟悉制造本性，又会把本性当成可训练出来的新能力。

正文再次要求正念相续不散。正念本身不是病根，带执取的把持才是问题——正念在三窍诀中三度现身：第一窍诀守无念仍落昏昧（不足），第二窍诀“绷着的念持”成橛（成病），第三窍诀依于本然而护持（成道）。不能为了去执而任由散乱，也不能为了不散而把觉性变成一个必须捏住的对象。

我们的疏通是：护持并非找一个正确对象来依附，而是在认识中不遗失、不散乱，同时不固定所认出的本性。“依附在本然上”这类说法要小心，容易把本然变成最后的所缘。

## 九、觉受如沿途景象：不专执，也不取消辨明

第三窍诀列出多种经验：愚钝无念、通透无念，带贪著与不带贪著的乐，带执取与离执取的明，粗糙与柔和，念头纷飞与昏明难辨。它们由长期习惯与业风等条件生起，未必按照预期出现。

这里的“业风”是传统修道体系中与业习、心动相关的风，并非日常空气或现代生理学术语。串讲的重点，是经验具有复杂条件，不能把它们都归结为一个简单的成败指标。

大师以长途旅行作喻。平坦与险峻都可能经过，不因某处悦意就停留（ཆེད་འཛིན，特意执取），也不因某处艰难就放弃方向。所护持的“自己的路”（རང་ལམ），就是觉性本身——路边的风景不是路。

觉受的悦意程度不能单独作为证量尺度。好感受不自动证明认识，坏感受也不自动否定道路。不过，不专执不是一律不处理：被念头带走与不散乱仍有区别，昏明不辨与认识仍有区别。对经验不追逐、不厌弃，同时仍须辨明是否迷失。

这两层共同构成平等的分寸。平等不是把经验修成同一种样子，也不是取消明辨；它是不让好坏经验成为新的贪拒与自我确认。

觉受名单中“通透无念”一项有重要文本出入（详见文末）。因此，本稿不依这一项建立固定次第，也不以排列整齐反推原文应怎样写。

## 十、念头像火：不因动荡退心

初学尚未熟悉时，种种念头可能像火一样燃烧。正文特别提醒，不要因此厌倦（དེས་མ་སུན་པ，被它弄得厌倦退心，不只是“烦躁”），以松紧适中的方式继续护持。

这句话纠正一种常见想法：我已经开始修，念头就应当越来越少。经验未必按这个预期变化。看到更多念头，也可能与观察变细有关；但具体原因不能只凭一句通用解释认定。

这里既不要求压制每个念头，也不鼓励跟随它们。松紧适中，是不因厌倦放弃，也不把用力压住当作精进。

正文提到后续“得”等觉受逐渐出现，说明经验可以具有熟悉过程中的参考意义。但不能把宁静程度直接排成觉性深浅的排行榜。定的安住程度与认识、解脱能力，应当辨别而又相互联系地理解。

在稳固之前，安排适当环境与座次有实际意义。结构上的精进不等于心中对经验的把持；反过来，“自然”也不意味着不安排时间、不再修习。

## 十一、辨明之后，为什么不反复审查

第三窍诀将觉性与无明、阿赖耶与法身、心识与本智的辨析收在一起，要求依上师窍诀，在体验上认识并建立把握。随后说，护持时不要反复作“这是识还是智”的取舍审查，也不要让书本理解不断翻腾。

这不是分辨与不分辨的矛盾，而是两种作用的区别。需要辨明时，依教授与体验辨明；正在护持时，不再不断追加裁决。原文的语序本身给出了答案：“以上师窍诀，在体验上认识并建立把握”在前，“护持时不审查”在后。它不要求所有分辨在入座以前一次完成。

若没有辨明，就可能把含混当自然；若不断审查，又可能以审查重新构造二取。信心不能代替辨明，辨明所得的把握却可以使反复审查不再必要。

正文以不搅动之水自然澄清作喻，要求让心识安住本位，其法性显为自生本智。

```
ཆུ་མ་བསྒུལ་ན་དྭངས་བ་ལྟར་རྣམ་ཤེས་རང་སར་བཞག་པས་དེའི་ཆོས་ཉིད་ཡེ་ཤེས་རང་བྱུང་དུ་གསལ་བ
```

“其”（དེའི）字重要：不必丢掉心识，去别处寻找本智——本智即心识之法性。但这也不能成为“普通心随便放着，便自动是本智”的理由。此前的认识与辨明，仍是语境中的条件。

“本位”不是身体中的地点，也不是一个可以定位的心理位置。我们的疏通是：不继续扰动、加工、取舍其经验，使已辨明的本性不被新一轮执取遮蔽。

水喻说的是不扰动的作用，不必把障碍想成实体污物，等它沉底。更不能把“自然澄清”解释为任由习气发展，迟早自行成佛。这个“澄清”（དྭངས），与第一窍诀“黑暗澄清”、第二窍诀“澄澈清明”同字——三窍诀的成果，都不靠另加什么。

## 十二、止观本来不二：不是拼出一个理想状态

第三窍诀末尾，把自然安住中正念相续的稳定称为止的熟悉分，把自明地认识本性称为观。这里的止，是稳定、不散的方面；观，是辨明本性的方面。二者以自身之力相连（རང་ཤུགས་ཀྱིས་འབྲེལ་བ），熟悉稳固，本来不二的止观显露为大圆满的密意。

“自然相连”不必解释为两个独立力量各自发力，再把对方拉过来。它也不是要求先制造稳定，再制造明了，最后将两种状态拼合。

我们的疏通是：在熟悉中，安住与认识不再被经验为两项必须分别操作的工作。道上修出的止观（正念熟悉分、认出自性的观），显出的正是基上本来无别的止观（“本然本住”རང་བབས་ཡེ་གནས 与“自性光明”རང་བཞིན་འོད་གསལ）。本性不是一半不动、一半清明的组合，也不因心里没有念头才成为不二。

此处“本然”（རང་བབས）归宿了全篇那条词脉：从第一窍诀“随势而看”，到此处“本然本住”，看的方式与本性的存在方式用的是同一组词。

所谓如虚空平等，不能留下一个躲在经验后面、永远不动的观察者。更合适的理解是：经验变化不必使认识转成追逐与取舍，不必随每一种变化重新建立能取的位置。

虚空譬喻指向无可执取与不受局限，不是要求制造太空般的内在景象。宽广可以是一种觉受，虚空之喻不能只用宽广感解释。三窍诀之名连起来，正是一条路线：蛋壳（被包、看不见）、网（看见却被缠）、虚空（无包无缠，无边、无处挂网）。

## 十三、萨惹哈之证：安住不能离开直指

三个窍诀之后，麦彭仁波切引萨惹哈教言。引文大意说，舍弃思与所思，像孩童般无思安住；认真依上师教言实践，则俱生者必定现起。

作者自己把前两句说明为安住法，将依上师教言联系到直指觉性的窍诀，再说明俱生智慧现起。这样，单纯安住与具足认识教授便没有被混为一谈。这一配对是作者原文，不是注释者的发挥。

孩童之喻说明一种不作繁复思量的安住方式，不能将孩子的无思当作证悟。全篇第一窍诀已经防止我们这样误读。

精勤仍然有位置：认真听受、辨明、实践、熟悉。此处“专注”（བསྒྲིམ）与第三窍诀“松紧”的“紧”同字，却用在对上师教言的专注上，而非用在捏紧心上。但精勤不必等于把心捏紧，自然也不等于不再用功。

本文没有核实萨惹哈偈的具体道歌出处，故只能据麦彭仁波切所引讨论，不能宣称已经恢复它在原道歌中的完整上下文。

## 十四、从自心法性到一切法法性

随后，作者说明本来与自心俱生的法性，即自生觉性本智，与一切法的法性无别。此处的“俱生”已说明本来同在，故随后说它“现起”（འབྱུང）是显露，不是从无到有。

这里的修持从自心下手，所认识的却不必局限于一个私人内在世界。心性并非我个人拥有的特殊物件。若把自心光明理解为藏在身体里的个人灵体，便难以理解与一切法法性无别。

也不能由此推出，认识本性一次，就已经知道所有事物的全部细节。对法性的认识、道上熟悉与果位二智的圆满，全文仍有区别。

后分将自然安住与护持所认识的觉性，收摄为百要归一；觉性、心的体性、法性，是此处相互说明的称谓（原文以“或”连接，指同一所指的不同名）。但第二窍诀关于名同义异的提醒仍然有效：名词可以相通，不能因此把凡称“心”“觉”的经验都视为同一所指。

“回到本然”可以总结方法倾向，却不能取代全部条件。全篇说的本然，是与认识、不散乱、无执相连的本然；含混、惯性与任意放松也可以让人觉得自然，必须辨清。

## 十五、验相：不让特殊感觉成为唯一依据

后分提供几个不同的检验角度。串习之量，联系夜间光明；正道之相，联系信心、悲心与智慧自然增长（རང་ཤུགས་ཀྱི་འཕེལ，以自力增长，与止观“以自力相连”同字）；容易与少辛劳，由亲身体验得知；甚深迅速，则联系修证程度的比较。

分成四项，是本稿的阅读方式，不能冒充原文设立了四个彼此独立的认证标准。可注意的是：它们各配不同的验法，没有一项只凭单一感觉下结论。

夜间光明帮助理解熟悉是否超出清醒时的刻意维持。但它不是简易自测：没有梦的记忆，不证明睡眠中认识未失；梦中知道自己做梦，也不直接等于所说光明。具体层次须依注释与教授辨明，不能由亮光、广阔视野或特殊睡眠经验自行宣布成就。

信心、悲心、智慧的增长，提供了不局限于座上感觉的观察角度。信心包括对教法的信解，悲心包括对有情的关切，智慧包括辨明能力，不只是人变得温和。这些增长与行为相关，却不能用一两次情绪变化给自己或别人判定证悟。此处与第一窍诀首尾相扣：昏昧中久住，信、悲、对因果的信解都会丧失；而正道之相恰是此三者增长。同一组品质，开头是错路的验相，结尾是正路的验相。

“自然增长”不排除发菩提心、闻思、积资净障与利他行。它说明如理修持的作用可以自然展开，不能据此删除其他必要条件。

“容易”也不能单凭轻松判断。放逸同样会使人舒服。需联系整个教授，看是否真实辨明、是否不散、是否减少执著、是否增长信悲智慧。开篇“以很小的辛劳”的许诺，到此交给亲身体验去验证。

修证比较不等于给他人排名。对比较双方没有可靠了解，就不能宣称自己已经据此证明某种方式更深、更快。正文的比较句还有断句与译法问题，故本稿不扩大为对所有其他道路的一概裁决。

## 十六、果位：清净与开展都不能省略

果位段说，分别与习气的障蔽自然清净，二智无勤开展，三身任运成就。它运用了藏文“佛”名 sangs rgyas 中清净（སངས）与开展（རྒྱས）的双关。

```
དེའི་སྟེང་གི་རྣམ་རྟོག་དང་དེའི་བག་ཆགས་ཀྱི་སྒྲིབ་པ་རང་སངས་ཚེ་མཁྱེན་གཉིས་རྩོལ་མེད་དུ་རྒྱས་ནས་གདོད་མའི་གཏན་སྲིད་ཟིན་ཏེ་སྐུ་གསུམ་ལྷུན་གྱིས་གྲུབ་པ་ཡིན་ནོ། །
```

障蔽是“附在它之上”（དེའི་སྟེང་གི）的，不在光明之中，故能自然清除，不需另加对治——与三窍诀“澄清”同理：浊不是水本身。

二智通常指如所有智与尽所有智：知诸法的如实本性，知诸法的种种差别。这样，究竟果便不能被缩减为无念、寂静或一片没有内容的空白。

三身，是法身、报身、化身，传统上说明成佛的真实体性、圆满受用与应机利生等方面。在这里应理解为佛果的表述，不能根据某次明空体验，自行宣布三身功德已经圆满。

“自然清净”并非放任习气。它在修持、认识与熟悉的全文语境中成立。“无勤”说明果的开展不靠继续制造一个本性，不表示道上没有精进，也不表示初次认识后便已无事可做。

所谓掌握本初的王位（གདོད་མའི་གཏན་སྲིད），是比喻性的果位语言，意近收复本来属于自己的王国。可以说明本性并非外来所得，却不宜据此设想一个真实自我，收回原本属于它的王国。

我们的疏通是：果不以制造另一种本性为成立条件；但认识、熟悉、障蔽清净与功德圆满的差别，仍须尊重。这也正是全篇不把初次认识与究竟成佛混同的分寸。全段主语是“修持自心光明”，果也不在别处——与第一窍诀“天亮看见自己家中”首尾呼应。

此外，跋文自称此篇为具证长老体验性的“赤裸引导”（དམར་ཁྲིད），以通俗易懂的法语写成。这正是读全篇的钥匙：一位精通因明、中观的大学者，有意选用老修行人的俗语，所以“无记”“中庸”等词不能按论典定义硬套；对译者而言，要追求的是体验上的准确，而非术语上的对等。

## 十七、串讲收束：不知、执取与不熟，各须辨清

回看三个窍诀，第一处提醒，持续安住不能保证认识；第二处提醒，持续清明不能保证无执；第三处提醒，经验变化不必破坏认识，却需要熟悉才能不被带走。

三个提醒不是三条互不相关的路。安住中需要认识，认识中需要去执，去执不取消不散乱，熟悉也不能变成守住修境。它们彼此校正，才不会把自然读成含混，把精进读成把持，把本来具足读成无需实践。

破壳，不是把无念变得更长；断网，不是不断退到另一个观察位置；如虚空平等，不是留下一个永远不动的旁观者。它们共同指向对自心本性的辨明，以及在显现各异时不再以二取固执它。

同时，文字上的通达不能代替教授与体验。我们可以通过细读知道误解在哪里，知道哪些条件不能省略；却不能仅凭把概念说顺，就替自己确认认识已经成立。

《除暗明灯》之所以是一盏灯，正在于它不让安静、清明、空、离言、不作意这些美好的名称遮住分界。灯照见的不只是喧闹的妄念，也包括安静之中未被辨明的含混、清明之中轻微的黏著，以及修持之中不断确认自己的习惯。

在这些分界上如实辨明，既不另造本性，也不省略道路；既不追逐经验，也不放弃认识。后分再以熟悉程度、信悲智慧与究竟功德，使这一认识有可继续深化的方向。
