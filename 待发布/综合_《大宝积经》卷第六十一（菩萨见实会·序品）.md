# 《大宝积经》卷第六十一（菩萨见实会·序品）

北齐·三藏那连提耶舍 译

## 菩萨见实会第十六之一

【按】译者题署，宋、宫本作“高齐那连提耶舍译”，元本作“高齐北天竺三藏那连提黎耶舍奉诏译”，明本作“高齐北天竺三藏那连提耶舍译”。会名“菩萨”二字，宫本无；“第十六”，宋、元、明、宫、圣、圣乙本作“第十六之一”，今从之。本会异译有宋日称等译《父子合集经》（T0320）。

### 序品第一

#### 法会大众

如是我闻：一时，佛在迦毘罗国尼居陀林，与大比丘众一千二百五十人在一起，他们的名字是：优楼毘螺迦叶、伽耶迦叶、那提迦叶、摩诃迦叶、舍利弗、大目犍连。他们都是大阿罗汉，诸漏已尽，不再有烦恼，其心自在，心善解脱，慧善解脱，如大龙象，所作已办，都已放下重担，逮得自利，尽除诸有之结；在正教中心得善解，对一切法心无所碍，已到彼岸。自己得到解脱，眷属也得解脱；自己得到调伏，眷属也得调伏；自己得到寂定，眷属也得寂定；自己得到度脱，眷属也得度脱；自己已到彼岸，眷属也到彼岸；自己已到陆地，眷属也到陆地；自己得到安隐，眷属也得安隐；自己得到寂灭，眷属也得寂灭；自己破除烦恼，眷属也破除烦恼；自己得到沙门之果，眷属也得沙门之果；自己得到息恶，眷属也得息恶；自己是婆罗门，眷属也是婆罗门；自己除去恶法，眷属也除去恶法；自己了知诸法，眷属也了知诸法；自己能得度，眷属也能得度；自己具足诸德，眷属也具足诸德；自己没有烦恼，眷属也没有烦恼；自己远离五支，眷属也远离五支；自己得以离障，眷属也得离障；自己得到静意，眷属也得静意；自己具足六通，眷属也具足六通；自己远离憎爱而解脱，眷属也远离憎爱而解脱；自己守护一心，眷属也守护一心；自己念门具足，眷属也念门具足；自己依于四依，眷属也依于四依；自己远离种种诸见，眷属也远离种种诸见；自己弃舍种种希望，眷属也弃舍种种希望；自己得到尽行，眷属也得尽行；自己事已完毕，眷属也事已完毕；自己修习，眷属也修习；自己没有浊念，眷属也没有浊念；自己断除有觉，眷属也断除有觉；自己倚于身行，眷属也倚于身行；自己得到乐不动，眷属也得乐不动；自己心善解脱，眷属也心善解脱；自己慧善解脱，眷属也慧善解脱；自己得成贤圣，眷属也成贤圣。像这样等等，已离开枝叶，除去皮肤，唯有心实坚固而住。

【按】“能度眷属”，宋、元、明、宫本作“能得度眷属”。“事讫”之“讫”，圣乙本作“说”。

原文：“自离五支，离五支眷属……自倚身行，倚身行眷属”（大意：自己远离五支，眷属也远离五支……自己倚于身行，眷属也倚于身行。“五支”“倚身行”所指未详，存疑。）

#### 世尊觅人往化净饭王

那时世尊在后夜于露地而坐，比丘众四面围绕。那时世尊默然而住，观察比丘众，告诉诸比丘：“你们寻访一个人，能够前往教化净饭王。”那时慧命阿若憍陈如便从座起，偏袒右肩，右膝着地，合掌向佛，作礼之后对佛说：“世尊！我当前往教化净饭王吗？”佛说：“憍陈如，你止步！你现在具足大师的德望，不应前往那里。”那时有慧命婆涩摸以及大名、耶输陀、优楼毘螺迦叶、摩诃迦叶、舍利弗、大目连等，各自对佛说：“世尊！我们能够前往教化净饭王。”佛告诉摩诃目连：“你们暂且止步。你们都具足大师所应受尊重的威德，不应前往教化。”

【按】“汝今具足”之“今”，圣乙本作“尔”。“耶输陀”之“输”，圣、圣乙本作“轮”。

那时大德摩诃目连便这样想：“世尊现在想令谁去教化净饭王呢？”那时目连便入如实三昧，以三昧之力庄严其心，便见到佛心中所念的是慧命迦卢陀夷，想令他前往教化净饭王。譬如在重阁楼的窗中，太阳从东边照入，光照在西壁上；目连见到世尊的心专注于迦卢陀夷，想令他教化国王，也是这样。那时慧命目连便从定中起，前往迦卢陀夷处，到了之后说：“世尊心念知道你能够前往教化净饭王。迦卢陀夷！你现在应当发大勇猛，迅速前往教化国王。”目连说了这话，那时慧命迦卢陀夷对目连说：“平民尚且难化，何况国王？为什么？刹利种姓的灌顶大王有自在之力，难以教化。大目连！譬如堆积许多柴，或两年、三年，乃至千年，这样的柴堆经过多年，甚为干燥。那时有人放火去烧，成为大火堆。你认为怎样？这火堆大吗？”目连说：“很大。”“若又有人用无量酥油浇灌，这火会增盛吗？”大目连说：“更加炽盛。”“你认为怎样？这火可以靠近吗？”目连说：“难以靠近。”“像这样，大目连！刹利种姓的灌顶大王难以教化，不可靠近，也是这样。大目连！譬如发狂之象的牙，可以触碰吗？”目连说：“不可触碰。”“像这样，大目连！灌顶刹利难以教化，也是这样。”

【按】“种姓”之“姓”，宋、元、宫本作“性”（下“种姓”宋、宫本作“性”）。“难可化故”之“难”，宫本作“谁”。“苏油”之“苏”，宋、元、明、宫本作“酥”。

那时慧命目连又对优陀夷说：“世尊心念知道你能够前往教化净饭王。”优陀夷又对目连说：“世尊确实垂念，认为我能够前往教化净饭王吗？”目连回答说：“世尊确实诚心念你，认为你能够教化父王。”那时世尊亲自告诉优陀夷说：“优陀夷！你可以入城教化父王。为什么？唯有我与你能够教化净饭王。优陀夷！在我的诸声闻弟子之中，你教化诸城邑聚落最为第一。”那时世尊便以偈颂告诉优陀夷说：

```
谛听优陀夷！汝能善教导，
必令释种喜，往化最胜王。
王今受悟时，兼利诸天人，
必得到彼岸，汝当速往化。
释种净饭王，今怀恨乱浊，
住念惠不行，犹如坠高崖。
恋惜子高位，慧心尽迷没，
如商失重宝，追念生大苦。
如天坠宫殿，追恋五欲乐，
未知佛正法，悲哀大恼乱。
自念失七宝，及与人四道，
忆此圣王位，口出非法言。
```
（大意：谛听，优陀夷！你能善于教导，必能令释种欢喜，前往教化最殊胜的国王。国王现在受到开悟之时，兼能利益诸天人，必定得到彼岸，你应当迅速前往教化。释种净饭王现在心怀怨恨，迷乱浑浊，正念与智慧都不能运行，犹如坠落高崖。他恋惜儿子的高位，智慧之心全部迷没，如商人失去贵重的珍宝，追念时生起大苦。如天人从宫殿坠落，追恋五欲之乐，不知佛的正法，悲哀而大为恼乱。他自念失去了七宝以及人中四道，忆念这圣王之位，口出非法之言。）

【按】“住念惠不行”之“惠”，宋、元、明、宫、圣、圣乙本作“慧”。“恋惜子高位”之“子”，明本作“于”。“追恋”之“恋”，圣、圣乙本作“念”；“五慾”之“慾”，宋、元、明、宫本作“欲”。“人四道”之“道”，宫、圣、圣乙本作“通”。

原文：“自念失七宝，及与人四道”（大意：他自念失去了七宝以及人中四道。“人四道”所指未详，存疑。）

```
王时悲乱言，不觉己及他，
如夺精魂鬼，执持于人身。
犹在鸡罗山，一切无所见，
如是恼恨障，应见不复覩。
亦如睡眠死，己心不自了，
忧恨迷惑障，王不识自喜。
如妇夫婿亡，悲泪生忧悔，
王今痴恼乱，哀恋生大苦。
汝具巧方便，往化净饭王，
摧倒邪慢憧，当建正法灯。
更无有能化，净饭大王者，
唯汝优陀夷，过去曾同行。
```
（大意：国王那时悲乱地说话，不觉察自己以及他人，如同被夺去精魂的鬼执持着人身。犹如身在鸡罗山中，一切都看不见；这样的恼恨障碍，应当看见的也不再看见。也如睡眠或死去，自己的心不能自知；被忧恨迷惑所障，国王不认识自己应有的喜乐。如妇人丈夫死去，悲泣流泪，生起忧悔；国王现在愚痴恼乱，哀恋而生起大苦。你具足善巧方便，前往教化净饭王，摧倒邪慢之幢，当建立正法之灯。再没有别人能教化净饭大王，唯有你优陀夷，过去曾经与他同行。）

【按】“王不识自喜”之“喜”，宫、圣、圣乙本作“善”。“忧悔”之“悔”，元、明本作“恼”。“邪慢憧”之“憧”，宋、元、明、宫本作“幢”，今从之。

```
优陀夷当知，曾有大国王，
名曰增长实，声名震十方。
如法作国主，一切皆归化，
能以正法治，王领四天下。
城邑悉满中，花果香园苑，
多诸贤圣众，无有杂恶人。
芳林甚稠密，地净无棘刺，
多饶净妙等，花池庄严好。
人民广殷盛，弃恶常善住，
闭诸恶趣门，必升妙天道。
彼王昔有子，曾广供养佛，
备修诸善根，具足诸功德，
名曰妙坚惠，亿众所供养，
常见色欲过，弃家乐闲静。
```
（大意：优陀夷应当知道，曾有一位大国王，名为增长实，声名震动十方。他如法作国主，一切人都归服教化，能以正法治理，统领四天下。城邑全都充满，有花果香园苑囿，多有贤圣之众，没有杂恶之人。芳林甚为稠密，地面洁净，没有荆棘，多有清净美妙的花池，庄严美好。人民广大殷盛，弃恶而常住于善，关闭诸恶趣之门，必定升上妙天之道。那国王往昔有一个儿子，曾广为供养诸佛，具备修习诸善根，具足诸功德，名为妙坚慧，为亿众所供养，常见色欲的过患，弃家而乐于闲静。）

【按】“作国主”之“主”，元、明、圣乙本作“王”。“殷盛”之“殷”，元、明、圣乙本作“炽”。

```
父王勅子言：『汝可受五欲，
婇女自娱乐，游观宝宫池，
我今为汝办，玩弄无乏少。
云何不爱乐？汝当说其意。
知诸趣善妙，汝爱宝宅中，
女宝常围遶，妙境甚可乐，
诸仙处闲林，犹舍退还家，
受诸色欲乐，况汝无乏少？
婇女众围遶，王臣皆随从，
台馆若天宫，应受五欲乐。
诸女甚端正，美丽若天人，
善奏歌舞乐，可以自娱意。
目如优波叶，唇赤若含丹，
面满广黛眉，平额姝咽颈，
膺平缺骨满，臂如象王鼻，
掌如莲花色，指圆𦟛纤好，
舌薄广红赤，美言若甘露，
齿素利齐密，珠璎宝衣服，
脐深腹不现，脊如金刚杵，
髀股𦟛圆直，伊尼鹿王𨄔，
行步如鹅王，皆各瞻视汝，
盛年甚可爱，堪能存后嗣。
汝及众丽人，犹如春花开，
盛年色未退，应当速受乐。』
```
（大意：父王敕令儿子说：“你可受用五欲，与婇女自相娱乐，游观宝宫与池苑，我现在为你备办，玩赏之物无所缺少。为什么不爱乐？你应当说出你的心意。你知道诸趣中的善妙，你应爱乐宝宅之中，女宝常常围绕，美妙的境界甚可爱乐。诸仙人住在闲静的林中，尚且舍弃而退回家中，受种种色欲之乐，何况你无所缺少？婇女众围绕，王臣都随从，台馆如同天宫，应当受用五欲之乐。诸女甚为端正，美丽如天人，善于演奏歌舞之乐，可以自娱心意。她们眼如优波罗花叶，唇红如含丹砂，面庞丰满，眉黛宽长，额头平整，咽颈美好，胸膛平满，锁骨丰满，手臂如象王之鼻，手掌如莲花之色，手指圆润纤美，舌薄宽广红润，美言如甘露，牙齿洁白锐利，整齐细密，以珠璎宝衣为服饰，肚脐深而腹部不显，脊背如金刚杵，髀股丰圆挺直，小腿如伊尼鹿王，步行如鹅王，都各自瞻视着你；正当盛年，甚为可爱，能够延续后嗣。你与众丽人，犹如春花开放，盛年容色未退，应当迅速受乐。”）

【按】“婇女”之“婇”，圣、圣乙本作“綵”。“云何不爱乐”之“云”，《大正藏》作“示”，今依CBETA所录高丽藏作“云”；“爱”，明本作“受”。“汝爱宝宅”之“汝”，宫本作“次”；“爱”，宋、元、明、宫、圣乙本作“受”。“膺平”之“膺”，元、明本作“臂”；“臂如象王”之“臂”，元、明本作“譬”。“𦟛”字（月旁庸）先前电子文本未能显示，今据《大正藏》补出，形容圆润丰满；圣、圣乙本作“傭”。“珠璎”之“璎”，圣、圣乙本作“缨”。“脐”，圣乙本作“齐”。“𨄔”字先前电子文本未能显示，今据《大正藏》补出，即小腿；宋、元、宫本作“踹”，明本作“腨”。

```
坚慧白父王：『王言非正理，
若有如法语，所勅不敢违。
王听我今说，乐善真实语，
乃至于梦中，不起婬欲想。
父王今此言，智者所不许，
愚者乐此事，明人常所厌。
何故明目人，而羡盲瞽导？
岂有岸上人，反乐沈溺者？
何有解脱人，而复乐牢狱？
岂有安乐人，钦羡众苦者？
我意观父王，如盲溺狱者，
如梦受五欲，复为欲所溺。
父王如盲冥，我目见殊胜，
王为欲所漂，我今甚厌贱。
欲如毒药器，亦如毒蛇头，
如利刀剑矟，亦如大猛火。』
```
（大意：坚慧对父王说：“大王的话不合正理，若是如法的话，所敕令的我不敢违背。大王请听我现在说，乐善的真实之语：乃至在梦中，也不起淫欲之想。父王现在所说的话，是智者所不许的；愚者乐于此事，明智的人常常厌弃。为什么明目之人，反而羡慕盲人的引导？岂有已在岸上的人，反而乐于沉溺的人？哪有已解脱的人，又乐于牢狱？岂有安乐的人，钦羡受众苦的人？我看父王，如盲人、溺水者、狱中之人，如在梦中受五欲，又被欲所沉溺。父王如盲者处于黑暗，我的眼睛见到殊胜；大王被欲所漂流，我现在甚为厌贱。欲如盛毒药的器皿，也如毒蛇之头，如锋利的刀剑矛槊，也如大猛火。”）

【按】“明目人”之“目”，圣乙本作“自”。

```
王臣劝化时，坚慧悉不许，
捐亲及国土，弃欲而出家。
如蛇脱故皮，亦如弃涕唾，
远离于过恶，绝望永出家。
坚慧舍俗时，臣子随出家，
其人名月施，弃欲随坚慧。
童子出家已，并及大臣子，
成就四梵住，具足五神通。
深见五尘过，超绝于欲界，
转正妙法轮，直生梵天上。
童子出家已，父王起嫌恨，
月施诣王所，善化令王喜。
优陀夷当知，昔时坚慧者，
远离于五欲，今即我身是。
优陀夷当知，彼时增实王，
岂为异人乎？净饭王是也。
优陀夷当知，随我出家者，
月施汝身是，亦曾化增实。
是故优陀夷，今应化父王，
必有大利益，昔曾教化故。
```
（大意：王臣劝化之时，坚慧全都不许，舍弃亲人以及国土，弃欲而出家，如蛇脱去旧皮，也如弃去涕唾，远离种种过恶，断绝希望而永远出家。坚慧舍俗之时，有一位大臣之子随他出家，那人名为月施，弃欲而随坚慧。童子出家之后，以及大臣之子，成就四梵住，具足五神通，深见五尘的过患，超越欲界，转正妙法轮，径直生于梵天上。童子出家之后，父王生起嫌恨，月施前往国王处，善加教化，令国王欢喜。优陀夷应当知道，昔时的坚慧，远离五欲的，现在就是我自身。优陀夷应当知道，那时的增实王，难道是别人吗？就是净饭王。优陀夷应当知道，随我出家的月施就是你，也曾教化增实王。所以优陀夷，现在应当去教化父王，必有大利益，因为往昔曾经教化过他。）

【按】“五尘过”之“过”，圣本作“赴”，圣乙本作“起”。

#### 优陀夷乘空入王宫

那时慧命优陀夷受了佛的教示，默然许可。那时优陀夷过了一夜，到天亮至食时，穿衣持钵，进入迦毘罗城。那时有一千多位释种聚集在王宫门前，都各有所求。那时净饭王听说佛如来到了迦毘罗城，住在尼居林，生起嫌恨之意：“这孩子出家，令我的种族失去富贵大乐。如果他在家，应当继承金轮王，统治四天下，如法统领，人民没有违逆之命，七宝具足。那七宝是什么？一是轮宝，二是象宝，三是马宝，四是摩尼宝，五是女宝，六是主藏臣宝，七是导师宝；具足千子，勇健难当，容颜美妙，能摧毁强敌，护卫四天下；不用刀杖治理国土，如法治正，自然太平。我得到轮王的自在快乐，他应当尊重供养我；由于儿子出家，所应得的都全部失落。”这样想了之后，敕令诸释种：一切人不得前往我儿那里敬信听法，若有违犯的，当斩其首。

【按】“三曰马宝”之“曰”，宋、元、明、宫本作“名”。“主藏臣宝”之“宝”，宋、元、宫本无。“刀杖”之“杖”，宋本作“仗”；“料理”之“料”，宋、元、明、圣、圣乙本作“断”。

那时有一位释种名为喜面，不在众中，没有听到国王的教令，见到优陀夷，便来到他那里，稽首说：“善来，尊者！平安吗？世尊安乐，少病少恼，起居轻便，在路上不疲劳，供养饮食不缺乏吧？”那时优陀夷回答喜面说：“如来安乐，少病少恼，起居轻便，在路上不疲劳，饮食不缺乏。”那时有一位释种名为善觉，见到喜面与优陀夷在僻静处说话，也来到那里，说：“大德从远方而来，近来安康吉祥吗？世尊起居安乐，少病少恼，在路上不疲劳，供养饮食不缺乏吧？”优陀夷回答说：“如来圣体安乐，在路上不疲劳，无所缺少。”那时又有两位释种，一名无忧，二名离忧，见到喜面、善觉与优陀夷在僻静处，也离开大众来到那里，对优陀夷说：“善来至此，气力好吗？世尊起居安乐吗？远涉途路，没有疲劳吧？”优陀夷回答说：“如来圣体安乐，涉路不疲。”那两位释种又说：“如来在途路中为什么没有缺乏？”优陀夷回答说：“因为四天王以及天帝释、诸梵天王常来供养，所以无所缺乏。”那时诸释种一同对优陀夷说：“我们现在想前往佛所，到世尊处供养听法，恐怕不能如愿。为什么？净饭大王先前有敕旨，敕令诸释种都不许前往佛所供养听法，若有违犯，当斩其首。由于顾虑国王的法令，所以不能礼拜供养、听受正法。”

【按】“供馔”之“馔”，圣、圣乙本作“饍”。“勅旨”，宫、圣、圣乙本作“旨勅”。

那时优陀夷听了这话，知道其父王有大怨恨，想：“我现在用什么方便前往国王处？”这样想了之后，又想：“我当升高七多罗树，在虚空中结跏趺坐，到国王那里。”那时慧命优陀夷便入如实三昧，以那三昧庄严其心，又以神力升高七多罗树，在虚空中跏趺而坐，飞空前往净饭王处。那时国王远远看见优陀夷以神通力在虚空中跏趺而来，从座而起，合掌恭敬，向优陀夷说偈道：

【按】“结加”“加趺”之“加”，宋、元、明、宫、圣、圣乙本多作“跏”。

```
染服大师从何来？
成就威仪难见者，
若有所须愿速说，
我今诚心必奉给。
```
（大意：身着染色衣的大师从哪里来？成就威仪，难得一见。若有所需，愿迅速说出，我现在诚心必定奉给。）

那时慧命优陀夷以偈回答说：

```
我是大王子之子，
大王即是我祖父。
我为如来行乞食，
得食奉送大善逝。
大王今日获善利，
王儿人天最尊上，
威德光明照十方，
犹如秋月日中时。
如日处空离云雾，
光明晃曜普皆照，
如是最胜王圣子，
威德光显闻十方。
犹如秋日初出时，
蔽诸萤火光普照，
如是最胜王圣子，
伏诸外道独显曜。
犹如日中盛隆炽，
凌于星辰故不现，
如是最胜王圣子，
降伏外道自光显。
犹如日中凌月明，
令月失光明不现，
是王圣子伏外道，
如日盛明月隐照。
```
（大意：我是大王之子的儿子，大王就是我的祖父。我为如来行乞食，得到食物奉送给大善逝。大王今日获得善利，王子是人天中最尊上者，威德光明照耀十方，犹如秋月、如日中之时。如太阳处于空中，远离云雾，光明晃耀，普皆照耀；这样最殊胜的国王之圣子，威德光明显扬，闻于十方。犹如秋日初出之时，遮蔽一切萤火之光，普照一切；这样最殊胜的国王之圣子，降伏诸外道，独自显耀。犹如日中隆盛炽烈，凌驾于星辰，令其不现；这样最殊胜的国王之圣子，降伏外道，自身光明显扬。犹如日中凌驾月光，令月亮失去光明而不显现；这国王的圣子降伏外道，如日光盛明而月光隐没。）

【按】“凌”，宋、元、明、宫、圣、圣乙本作“陵”。

```
如禽兽闻师子吼，
水陆空行散还穴，
惊奔逃走迷诸方，
以师子声难忍故。
大圣如来震吼时，
邪外道闻无我声，
假使无知至有顶，
闻此无我皆悉怖。
盲冥愚痴人天中，
有目如来示明炬，
为作明灯除愚暗，
兴举无上智光轮。
显示邪正等不等，
教导世间道非道，
为失路者示其路，
拔欲淤泥置岸上。
如兴云荫覆枯池，
注雨充足原隰满，
如是大王仙圣子，
兴建法雨润人天。
如水沾地及山川，
并诸百卉丛林树，
药草条茎及枝蔓，
诸花蓊蔚遍山好。
```
（大意：如禽兽听到师子吼，水中、陆上、空中的都散去，回到巢穴，惊奔逃走，迷失方向，因为师子之声难以忍受。大圣如来震吼之时，邪见外道听到无我之声，即使无知之辈到了有顶天，听到这无我之说也都恐怖。在盲冥愚痴的人天之中，有目的如来出示明炬，作为明灯除去愚暗，举起无上的智慧光轮。显示邪正、等与不等，教导世间何为道、何为非道，为迷失道路的人指示道路，从欲望的淤泥中拔出，安置于岸上。如兴起云荫覆盖枯竭的池塘，降雨充足，原野低地都充满；这样大王的仙圣之子，兴起法雨润泽人天。）

【按】“拔欲淤泥”之“拔”，宫本作“伏”。“枯池”之“池”，圣、圣乙本作“地”。

```
如是十力四无畏，
具足十八不共树，
一切智果花庄严，
王仙圣子微妙身。
如须弥山处大海，
严好不动天乐居，
如斯善逝大王子，
沙门海中最第一。
忉利天主舍脂夫，
于天众中奇特妙，
如斯世尊大王子，
沙门众中最殊妙。
吼说秘奥甚深法，
以悲鬘电遍一切，
如来龙王降法雨，
念处池水细注下。
持戒威德如日轮，
以三昧力除恼暗，
智慧光灭烦恼爱，
大牟尼日照世间。
具足念处摩尼宝，
戒定船栰渡彼岸，
觉支宝𨥥禅浩满，
复求毕叉入佛海。
```
（大意：如雨水沾润大地以及山川，并诸百草、丛林树木、药草的枝茎以及枝蔓，诸花繁茂，遍满山间，美好。这样具足十力、四无畏、十八不共法之树，以一切智之果与花庄严，是国王仙圣之子的微妙之身。如须弥山处于大海，庄严美好不动，为天人安乐所居；这样的善逝大王子，在沙门之海中最为第一。忉利天主、舍脂之夫，在天众中奇特美妙；这样的世尊大王子，在沙门众中最为殊妙。他吼说秘奥甚深之法，以悲心为电光遍照一切，如来龙王降下法雨，在念处的池水中细细注下。持戒的威德如日轮，以三昧之力除去恼暗，以智慧之光灭除烦恼与爱，大牟尼之日照耀世间。具足念处的摩尼宝，以戒定为船筏渡到彼岸，以觉支为宝矿，禅定浩瀚充满，又求毕叉，入于佛海。）

【按】“蓊蔚”之“蔚”，圣、圣乙本作“欝”。“王仙圣子”之“仙”，圣、圣乙本作“位”；“微妙”，圣、圣乙本作“妙微”。“𨥥”字（金旁丱）先前电子文本未能显示，今据《大正藏》补出，即“矿”；宋、宫本作“鑛”。

原文：“觉支宝𨥥禅浩满，复求毕叉入佛海”（大意：以觉支为宝矿，禅定浩瀚充满，又求毕叉，入于佛海。“毕叉”所指未详，存疑。）

```
清净戒根坚难动，
三昧树叶念处枝，
七觉华空坚树身，
无我坚固成佛树。
戒林中行大力者，
三昧调伏德山依，
三解脱门为境界，
佛十力牙是王子。
正见无著牟尼尊，
能降强敌胜牛王，
恐怖种种诸外道，
是大王子无畏吼。
尸罗德藏妙庄严，
禅定寂灭无量衣，
具智牟尼解脱境，
能施财物如长者。
远离诸恶集诸善，
灭诸烦恼善慧根，
慧施天人修罗等，
光明晃曜王圣子。
戒云空慧以为电，
八支细雨能润泽，
牟尼能与胜苗子，
王子犹如大龙雨。
```
（大意：清净的戒根坚固难动，以三昧为树叶，以念处为树枝，以七觉为花，以空为坚固的树身，以无我为坚固，成就佛之树。在戒林中行走的大力者，以三昧调伏，依于功德之山，以三解脱门为境界，以佛的十力为象牙，这就是王子。具正见而无著的牟尼尊，能降伏强敌，是殊胜的牛王，令种种外道恐怖，这是大王子的无畏之吼。以尸罗德藏美妙庄严，以禅定寂灭为无量之衣，具足智慧的牟尼以解脱为境界，能施与财物，如同长者。远离诸恶，积集诸善，灭除诸烦恼，以善慧为根，以智慧布施天、人、修罗等，光明晃耀的是国王的圣子。以戒为云，以空慧为电，以八支道为细雨，能够润泽；牟尼能给予殊胜的苗种，王子犹如大龙降雨。）

【按】“慧施”之“慧”，圣本作“惠”。“细雨”之“细”，元、明、宫、圣、圣乙本作“绸”。

原文：“七觉华空坚树身，无我坚固成佛树”（大意：以七觉为花，以空为坚固的树身，以无我为坚固，成就佛之树。句读未详，存疑。）

#### 净饭王与优陀夷问答

那时净饭王以偈问道：

```
胜士得来安乐耶？
至于饮食无乏少，
身无疲劳床卧具，
如花在岸不蔫萎。
```
（大意：殊胜之士来到这里安乐吗？饮食不缺少吗？身体没有疲劳，床座卧具齐备吗？是否如花生于岸上而不枯萎？）

那时优陀夷以偈回答说：

```
禅定境界具神力，
身心安乐遍充满，
牟尼神虑依寂止，
犹如金莲不枯燥。
```
（大意：以禅定为境界，具足神力，身心安乐，遍满充满；牟尼的神思依于寂止，犹如金莲不会枯燥。）

那时净饭王以偈问道：

【按】“净饭王”，圣、圣乙本作“净饭大王”。

```
昔以旌鼓自惊悟，
美音筝笛及箫瑟，
妙好伎女以自娱；
今独林中不苦耶？
```
（大意：往昔以旌旗鼓乐自相警悟，以美妙的筝、笛以及箫、瑟，美好的伎女来自娱；现在独自在林中，不苦吗？）

【按】“惊悟”之“惊”，宋、元、明、圣、圣乙本作“警”。

那时优陀夷以偈回答说：

```
禅定寂定为境界，
巧能修学三昧乐，
行住坐卧依诸善，
心常喜乐无苦恼。
```
（大意：以禅定寂定为境界，巧能修学三昧之乐，行住坐卧都依于诸善，心中常常喜乐，没有苦恼。）

【按】“禅定”之“定”，圣本作“宅”。

那时净饭王以偈问道：

```
无价宝床常安卧，
眠时美女众在侧，
周围广设明灯树，
如何暗卧不悒戚？
```
（大意：往昔在无价的宝床上常常安卧，睡眠时众多美女在旁，周围广设明灯之树；现在怎能在黑暗中躺卧而不忧闷？）

那时优陀夷以偈回答说：

```
牟尼眠时卧圣床，
慈为毡褥悲乐枕，
佛住喜心常怡悦，
舍三有趣不悒戚。
```
（大意：牟尼睡眠时卧于圣床，以慈为毡褥，以悲乐为枕头；佛住于喜心，常常怡悦，舍弃三有诸趣，不会忧闷。）

那时净饭王以偈问道：

```
诸健释种常围遶，
博达多闻以为伴，
殿舍天宫中长养；
如何今日乐林间？
```
（大意：往昔诸位健勇的释种常常围绕，以博达多闻的人为伴，在殿舍天宫中长养；现在怎么乐于住在林间？）

那时优陀夷以偈回答说：

```
如法生子恒现前，
同修寂止在其侧，
心好闲林修诸定，
离畏导师乐山林。
```
（大意：如法所生之子恒常现前，同修寂止的人在其身旁，心中喜好闲林，修习诸定，远离怖畏的导师乐于山林。）

那时净饭王以偈问道：

```
童子昔日在宫时，
以天浴池而澡沐，
亦用香泽涂其身；
今在林中谁为洗？
```
（大意：童子昔日在宫中时，以天上般的浴池洗浴，也用香泽涂身；现在在林中，谁为他洗浴？）

那时优陀夷以偈回答说：

```
诸法池水戒善岸，
牟尼自浴并浴他，
己及诸子浮不湿，
自度以讫及群生。
```
（大意：以诸法为池水，以戒为善岸，牟尼自浴并为他人洗浴，自己与诸弟子漂浮其中而不湿，自度已毕，又度群生。）

【按】“自度以讫”之“度”，宫本作“庆”。

那时净饭王以偈问道：

```
昔种种香常熏体，
金线真珠以严身，
常著天子妙衣服；
今在林间用何饰？
```
（大意：往昔以种种香常熏其身，以金线真珠庄严其身，常穿天子的美妙衣服；现在在林间用什么装饰？）

那时优陀夷以偈回答说：

```
功德鬘严戒香熏，
禅定璎珞惭愧衣，
通明解脱自庄严，
光明威德曜林中。
```
（大意：以功德为鬘庄严，以戒香熏身，以禅定为璎珞，以惭愧为衣，以神通、明、解脱自我庄严，光明威德照耀林中。）

```
昔以刀剑弓箭矛，
健士执持常防卫，
亦用宝盖恒覆荫；
今独林中谁守护？
```
（大意：往昔以刀剑、弓箭、矛，由健士执持，常常防卫，也用宝盖恒常覆荫；现在独自在林中，谁来守护？）

那时优陀夷以偈回答说：

```
慈悲忍辱自防卫，
声闻弟子眷属力，
以功德法定无怖，
十力雄猛四无畏。
```
（大意：以慈悲忍辱自我防卫，以声闻弟子为眷属之力，以功德法定而无所怖畏，以十力雄猛与四无畏。）

#### 优陀夷赞佛与净饭王忆念本誓

那时优陀夷又对国王说：“大王！婆伽婆是大众之师，善于调御群生，是大仙人，能善安住于沙门众中，是沙门中之王，光明普照。譬如十五日夜里清净的月亮圆满，众星围绕，光明甚盛，照耀一切；世尊也是这样，在沙门众中光明照耀，也是这样。譬如秋日在空中，没有云翳；那婆伽婆也是这样，在大众中光明照耀，也是这样。譬如帝释，是天中之王，坐在善法堂上，在诸天之中光明显赫；那婆伽婆在大众中光明晃耀，也是这样。譬如须夜摩天王、兜率陀天王、化乐天王、他化自在天王，在天众中光明显耀，威德独尊；那婆伽婆在沙门众中威德显赫，也是这样。犹如娑婆世界之主大梵天王，被百亿梵众所围绕，光明晃耀，威德独尊；那婆伽婆在沙门众中光明显赫，威德尊胜，也是这样。”

【按】“秋日”之“日”，宋、元、明、宫本作“月”。“须夜摩天”之“天”，元、明本作“天王”。

那时净饭王听了宣说婆伽婆的道德，心中这样想：“这只是世尊的声闻弟子，尚且有这样的大神通、大威力、大功德，何况如来。”又想：“太子初生之时，大地六种十八相震动：动、遍动、等遍动，踊、遍踊、等遍踊，吼、遍吼、等遍吼，震、遍震、等遍震，起、遍起、等遍起，觉、遍觉、等遍觉，放大光明；无人扶持而行走七步；空中有两道流水注下，洗浴其身；自然而有真金的圣座，在虚空中化成天盖，诸天礼拜。乃至未出家时，不被五欲所迷惑；凡有所作，决定不退，随其所说而能做到；在一切时中坚固有大力，不说妄语，不违背信行。他本来说过这样的话：‘我成就阿耨多罗三藐三菩提，自度之后，当再度化大王。’”那时国王念及佛作菩萨时的本誓愿，说这偈道：

【按】“踊”，明本作“涌”。

```
若有初生已，明智言不虚，
所说事不异，智者谁不信？
若有初生时，世亲说无等，
必作天人尊，智者谁不信？
若有不能惜，宝聚如雪山，
离于贪悋者，智者谁不信？
若能于梦中，不作虚妄语，
如说如修行，智者谁不信？
如刀剑之语，不能恼令瞋，
离于忿怒事，智者谁不信？
无有能欺者，贪瞋亦不染，
具足智慧王，智者谁不信？
一切妙五欲，及以种种报，
无有能系缚，智者谁不信？
种种希有事，及以众妙物，
无有能怖畏，智者谁不信？
```
（大意：若有人初生之后，明智而言不虚，所说之事不变异，智者谁不相信？若有人初生之时，世间亲见者都说他无与伦比，必定成为天人之尊，智者谁不相信？若有人不吝惜如雪山般的宝聚，远离贪吝，智者谁不相信？若能在梦中也不说虚妄之语，如所说而修行，智者谁不相信？如刀剑般的言语也不能恼乱他，令他生瞋，远离忿怒之事，智者谁不相信？没有能欺骗他的，贪瞋也不能染污，具足智慧之王，智者谁不相信？一切美妙的五欲以及种种果报，没有能系缚他的，智者谁不相信？种种稀有之事以及众多美妙之物，没有能令他怖畏的，智者谁不相信？）

【按】“能欺者”之“欺”，圣、圣乙本作“知”。

```
以诸美妙言，明人善巧说，
无有能惑缚，智者谁不信？
以诸顺义语，诸欲决定句，
于此不能缚，智者谁不信？
以诸军驾力，及以种种护，
能出于妙城，智者谁不信？
弃舍妙欲乐，为求甘露行，
悕望于菩提，智者谁不信？
六年修苦行，勇猛无能当，
求于胜菩提，智者谁不信？
六年麁少食，求于胜菩提，
利安诸世间，智者谁不信？
六年为魔扰，相续求短缺，
不能得其便，智者谁不信？
远离五欲过，不求于他物，
常利益世间，智者谁不信？
```
（大意：以种种美妙的言语，由明智之人善巧地宣说，也没有能迷惑系缚他的，智者谁不相信？以种种顺义之语、种种欲乐决定之句，对此也不能系缚他，智者谁不相信？以种种军驾之力以及种种守护，他仍能出离美妙的王城，智者谁不相信？弃舍美妙的欲乐，为求甘露而修行，希望于菩提，智者谁不相信？六年修苦行，勇猛无人能当，求殊胜的菩提，智者谁不相信？六年粗食少食，求殊胜的菩提，利益安乐诸世间，智者谁不相信？六年被魔扰乱，魔相续寻求其短处缺失，却不能得其便，智者谁不相信？远离五欲的过患，不求他人之物，常常利益世间，智者谁不相信？）

```
不从他闻法，自然成菩提，
寂定难可觉，智者谁不信？
梵天自劝请，勤求佛世尊，
如请而演说，智者谁不信？
哀怜愍我故，来到尼俱园，
为度诸释种，智者谁不信？
如来自度已，度我于有海，
忆念本誓愿，智者谁不信？

为怜愍我故，智者谁不信？
我今当往诣，见人导师身。
作是思念时，自省是人王。
```
（大意：不从他人闻法，自然成就菩提，寂定之境难以觉知，智者谁不相信？梵天亲自劝请，勤求佛世尊说法，他如所请而演说，智者谁不相信？因为哀怜愍念我，来到尼俱园，为了度化诸释种，智者谁不相信？如来自度之后，又度我出离有海，忆念本来的誓愿，智者谁不相信？现在正是得利之时，知道佛是一切智者，为了怜愍我而来，智者谁不相信？我现在应当前往，见那人中导师之身。这样思念之时，又自省自己是人间之王。）

【按】“来到尼俱园”之“来”，圣、圣乙本作“求”。“作是思念时，自省是人王”二句，CBETA标点置于引号之外，今依其句式并入偈中。

那时净饭王久久思量之后，对慧命优陀夷说：“比丘！你现在到这里，还需要什么？”那时优陀夷以偈回答说：

#### 净饭王生信

那时净饭王听了慧命优陀夷善说世尊作菩萨时所修的功德，便自己想起如来本来的誓愿：“我得度之后，必当度化大王。”这样想了之后，深生敬信，又对慧命优陀夷说：“比丘！你现在就是我儿子的儿子。你可以吃完饭后迅速回到佛所，把饭食奉献给佛。我现在也当前往拜见世尊。”

那时慧命优陀夷知道净饭王已得敬信，吃完饭后，便拿着肴馔奉献给如来。那时佛告诉诸比丘说：“优陀夷教化净饭王得到正信。诸比丘！今天诸天世人大得利益。”那时世尊赞叹优陀夷说：“善哉善哉！你今天得大福德，因为净饭王得到了敬信。”那时佛告诉诸比丘说：“迦卢陀夷教化净饭王所得的功德，若是有形之色，十方世界恒河沙数佛刹也容纳不下，因为这功德聚广大无量。”

【按】“饭食已讫”之“已”，圣、圣乙本作“以”。
