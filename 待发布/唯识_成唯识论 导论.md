一、《成唯识论》是一部什么样的论

《成唯识论》解释的是世亲菩萨的《唯识三十颂》。世亲菩萨用三十首偈颂，把唯识的全部道理收摄净尽。依窥基大师所传，世亲菩萨造完三十颂，还没来得及亲自作长行解释，就舍寿了。三十颂的文字极简，义理极深，后来印度先后有十位大论师各自为三十颂作释论。

十位论师是：亲胜、火辨、德慧、安慧、难陀、净月、护法、胜友、胜子、智月。亲胜与火辨和世亲菩萨同时，其余八位在世亲菩萨之后。十家之中，护法论师的解释最为精审，玄奘大师的老师戒贤论师就是护法论师的弟子。

玄奘大师把十家释论糅合成一部，以护法论师的解释为正义，其余各家的见解作为“有义”保留在论中，一一经过辨析和评判。《成唯识论》因此既是三十颂的注释，也是印度唯识学两百年争论的总结。

论名的含义，论末自己作了交代。论中说，以三分成立唯识，所以称为《成唯识论》。论中又说，这部论也叫《净唯识论》，因为显示唯识道理极为明净。论中还说，本颂称为《唯识三十》，因为三十首颂显示唯识道理恰好圆满，不多也不少。

二、玄奘大师糅译十家的经过

十卷本之后附有沈玄明居士所作的《成唯识论后序》。沈玄明居士与玄奘大师同时，后序以骈文写成，是关于这部论翻译经过的第一手记录。后序的大意如下。

后序说，《唯识三十颂》是世亲菩萨晚年最后的著作，理趣深广，一字含有千训，深义还没有宣说出来。后来护法、安慧等十大菩萨各自依照本颂作释，都称为《成唯识论》，也称为《净唯识论》。十家的释论破斥心外的能取所取，息灭执着实有的迷途。十家的释论又成立识内的一心，遣除偏执空无的妄执。

后序接着说，玄奘大师哀悼佛陀微言隐没光彩，于是发誓西行，周游五印十几年，带回经论。唐太宗、唐高宗两朝下诏翻译，于志宁、许敬宗等人润色文字，神泰法师等人证义，靖迈法师等人校核文辞。从贞观十九年到显庆末年，玄奘大师译出经论将近六十部，近千卷。

后序记载，显庆四年冬天，玄奘大师把十家释论共四千五百颂的篇幅糅合起来，归类汇聚，每一种义理都依照原本，合成一部，编为十卷。后序用一句话评价糅译的成果：

```
遂使文同义异，若一师之制焉。
```

大意：十家的文字合成一体，各家的义理仍然分明，读起来就像一位论师的著作。

“四千五百颂”是印度计算篇幅的单位，三十二个音节为一颂，并不是指偈颂的首数。后序最后讲到玄奘大师的弟子窥基大师，说窥基大师亲承教诲，总括这部论的纲领，判定章节品第，又撰写义疏传给后学。

糅译的缘由，窥基大师在《成唯识论掌中枢要》里还有更具体的记载。依窥基大师所记，玄奘大师最初打算把十家释论分别全译，由神昉、嘉尚、普光、窥基四人一同承担。几天之后，窥基大师请求退出，理由是十家各自译出，文义纷杂，后学难以抉择取舍。窥基大师请求玄奘大师糅合十家，以一家为准，玄奘大师采纳了这个建议，于是遣退其余三人，只留窥基大师一人执笔受义。窥基大师又记载，护法论师的释本是玄奘大师在印度从玄鉴居士手中得到的。

这段经过决定了《成唯识论》的面貌：一位总编（玄奘大师），一位正义（护法论师），九家旁义，一位记录与传述者（窥基大师）。读懂这个结构，就读懂了论中一半的难处。

三、唯识三十颂：全论的骨架

窥基大师把全论分为三分。第一是宗前敬叙分，即开头的归敬颂与造论缘起。第二是依教广成分，即逐颂解释三十颂。第三是释结施愿分，即论末的回向颂。

归敬颂：

```
稽首唯识性　满分清净者
我今释彼说　利乐诸有情
```

大意：顶礼证得唯识真性的诸佛与菩萨，诸佛圆满清净，菩萨分证清净。现在解释世亲菩萨的颂文，为了利益安乐一切有情。

依教广成分的三十颂，又分为三段：前二十四颂讲唯识相，第二十五颂讲唯识性，后五颂讲唯识位。下面依段列出颂文，每段之后注明大意和所在篇目。

第一段，略标三能变（第一颂至第二颂前半）：

```
由假说我法　有种种相转　彼依识所变　此能变唯三
谓异熟思量　及了别境识
```

大意：世间与圣教所说的我和法，都是假立的名言，假立的我相和法相种种不同。种种我相和法相都依识所变现而施设。能够变现的识只有三类：异熟识、思量识、了别境识。所在篇目：卷01上至卷02中。

第二段，初能变阿赖耶识（第二颂后半至第四颂）：

```
初阿赖耶识　异熟一切种
不可知执受　处了常与触　作意受想思　相应唯舍受
是无覆无记　触等亦如是　恒转如瀑流　阿罗汉位舍
```

大意：第一能变称为阿赖耶识，也称为异熟识、一切种子识。阿赖耶识执受种子与根身，变现器世间，了别作用极其微细，难以了知。阿赖耶识常与触、作意、受、想、思五个心所相应，只与舍受相应，性质是无覆无记。阿赖耶识恒常相续，又刹那变转，如同瀑流。到阿罗汉位，阿赖耶识的名称才舍弃。所在篇目：卷02中至卷04上。

第三段，第二能变末那识（第五颂至第七颂）：

```
次第二能变　是识名末那　依彼转缘彼　思量为性相
四烦恼常俱　谓我痴我见　并我慢我爱　及余触等俱
有覆无记摄　随所生所系　阿罗汉灭定　出世道无有
```

大意：第二能变称为末那识。末那识依阿赖耶识而生起，又以阿赖耶识为所缘，以恒审思量为自性和行相。末那识常与我痴、我见、我慢、我爱四种烦恼相应，也与触等心所相应。末那识的性质是有覆无记，生在哪一地就系属哪一地。在阿罗汉位、灭尽定中、出世道中，染污的末那识都不存在。所在篇目：卷04中至卷05中。

第四段，第三能变六识及其心所（第八颂至第十六颂）：

```
次第三能变　差别有六种　了境为性相　善不善俱非
此心所遍行　别境善烦恼　随烦恼不定　皆三受相应
初遍行触等　次别境谓欲　胜解念定慧　所缘事不同
善谓信惭愧　无贪等三根　勤安不放逸　行舍及不害
烦恼谓贪瞋　痴慢疑恶见　随烦恼谓忿　恨覆恼嫉悭
诳谄与害憍　无惭及无愧　掉举与惛沉　不信并懈怠
放逸及失念　散乱不正知　不定谓悔眠　寻伺二各二
依止根本识　五识随缘现　或俱或不俱　如涛波依水
意识常现起　除生无想天　及无心二定　睡眠与闷绝
```

大意：第三能变是眼、耳、鼻、舌、身、意六识，以了别境界为自性和行相，通善、不善、无记三性。六识与六类心所相应：遍行五、别境五、善十一、根本烦恼六、随烦恼二十、不定四，六识都与苦、乐、舍三受相应。前五识依根本识，随缘生起，有时同起，有时不同起，如同波涛依水。意识常常生起，只在五种情况下不起：生在无想天、无想定、灭尽定、极重睡眠、极重闷绝。所在篇目：卷05中至卷07中。

第五段，正明唯识，解答疑难（第十七颂至第十九颂）：

```
是诸识转变　分别所分别　由此彼皆无　故一切唯识
由一切种识　如是如是变　以展转力故　彼彼分别生
由诸业习气　二取习气俱　前异熟既尽　复生余异熟
```

大意：诸识转变出能分别的见分和所分别的相分，离开识所变的二分，实我实法都不存在，所以一切唯有识。没有外境，种种分别依然能够生起，因为一切种子识中的种子不断转变成熟，现行诸识又展转相助。没有外缘，生死依然能够相续，因为业的习气与二取的习气共同作用，前一期异熟果报受尽，后一期异熟果报又生起。所在篇目：卷07下至卷08中。

第六段，三性（第二十颂至第二十二颂）：

```
由彼彼遍计　遍计种种物　此遍计所执　自性无所有
依他起自性　分别缘所生　圆成实于彼　常远离前性
故此与依他　非异非不异　如无常等性　非不见此彼
```

大意：虚妄分别周遍计度种种事物，所计度的实我实法称为遍计所执性，遍计所执性根本没有自体。分别心由众缘所生，称为依他起性。在依他起性上永远远离遍计所执性，所显的真如称为圆成实性。圆成实性与依他起性不异也不一，如同无常性与无常的诸法。不证见圆成实性，就不能如实见到依他起性。所在篇目：卷08下。

第七段，三无性与唯识性（第二十三颂至第二十五颂）：

```
即依此三性　立彼三无性　故佛密意说　一切法无性
初即相无性　次无自然性　后由远离前　所执我法性
此诸法胜义　亦即是真如　常如其性故　即唯识实性
```

大意：佛依三性建立三种无性，以密意宣说一切法无自性。依遍计所执性立相无性，依依他起性立生无性，依圆成实性立胜义无性。圆成实性是诸法的胜义，也就是真如，在一切位中常如其性，就是唯识的真实性。第二十五颂单独讲唯识性。所在篇目：卷09上。

第八段，唯识五位（第二十六颂至第三十颂）：

```
乃至未起识　求住唯识性　于二取随眠　犹未能伏灭
现前立少物　谓是唯识性　以有所得故　非实住唯识
若时于所缘　智都无所得　尔时住唯识　离二取相故
无得不思议　是出世间智　舍二粗重故　便证得转依
此即无漏界　不思议善常　安乐解脱身　大牟尼名法
```

大意：五颂依次讲悟入唯识的五个阶位。资粮位，还没有生起顺抉择分的智慧，二取的种子还不能伏灭。加行位，心前还安立一个“唯识性”的相，还有所得，所以还没有真正安住唯识。通达位，智慧对所缘境一无所得，远离能取所取二相，才真正安住唯识。修习位，反复修习无分别智，舍弃二障种子，证得转依。究竟位，转依的果就是无漏界，不可思议，是善，是常，是安乐，二乘所得称为解脱身，佛陀所得称为法身。所在篇目：卷09上至卷10下。

释结施愿分的回向颂：

```
已依圣教及正理　分别唯识性相义
所获功德施群生　愿共速登无上觉
```

大意：依照圣教和正理，已经分别解说唯识的性与相，所获功德回施一切众生，愿大家一同速证无上菩提。

四、怎样读“有义”

《成唯识论》最让人迷路的地方，是一个问题之下接连出现“有义……有义……有义……”。每一个“有义”就是一位论师或一派论师的主张，原文不标名字。分辨各家，有三条线索。

第一条线索：看起首词。论中以“有义”引出的，大多是大乘内部诸论师的主张。论中以“有说”“有执”“有作是说”“有余部说”引出的，大多是外道或小乘部派的主张，例如说一切有部、经部、大众部、上座部。

第二条线索：看判词。论主破斥一家，常用“彼说非理”“理教相违”“彼说亦不应理”。论主认可一家，常用“应说”“若作是说，善顺教理”“妙符理教”“深契教理”“不违理教”。凡是出现认可判词的一家，就是论主所取的正义，通常是护法论师的主张。

第三条线索：看位置。几家并列时，护法论师的主张大多放在最后，前面各家依次被破，最后一家立为正义。也有少数地方，论主先立正义，再列旁义作参考，这时就要靠判词来分辨。

举一个例子。卷二讨论种子从哪里来，论中列出三家。第一家主张一切种子本来就有，熏习只能使种子增长，窥基大师判为护月论师的主张。第二家主张一切种子都由熏习新生，窥基大师判为难陀论师等人的主张。第三家主张种子有本有和新熏两类，窥基大师判为护法论师的正义。论中对第三家没有破斥，最后结论说：“由此应知，诸法种子各有本有、始起二类。”

本译注依窥基大师《成唯识论述记》的判定，在每一个“有义”处直接写出论师的名字。《述记》判定明确的，直接点名。《述记》判定不明，或后世注家说法分歧的，标为存疑，不强配人名。

五、入门必备的十二个名相

下面十二个名相贯穿全论，每一个都采用论中自己给出的定义，并注明出处。

我与法。论中说：“我谓主宰，法谓轨持。”窥基大师解释：主如国君，能自在作主；宰如宰相，能裁断事务。“我”就是被认为在身心之中自在作主、裁断一切的那个主人。轨是轨范，一样事物有固定的样子，人就能照着样子认出这样事物；持是任持，一样事物守住自己的特性，不会失去。“法”就是任何守住自身特性、让人能够照着特性认出来的事物。用现代话说破：“我”是被当作主体的东西，“法”是被当作对象的东西，连虚空、涅槃这类能被认识的名目也算在“法”里。世间和圣教所说的一切，不出主体和对象两类，所以论中一开头就把一切收归“我法”二字。（卷一）

识与变。论中说：“识谓了别……变谓识体转似二分。”大意：识的作用是了别，识的变现是识体转起，显现为见分和相分两部分。（卷一）

三能变。能变现的识分为三类：第八阿赖耶识是异熟能变，第七末那识是思量能变，前六识是了境能变。（卷二）

阿赖耶识三义。阿赖耶识具有能藏、所藏、执藏三种含义：阿赖耶识能摄藏一切种子，阿赖耶识被杂染法熏习所藏，阿赖耶识被末那识执着为自我。（卷二）

种子。论中说，种子是“本识中亲生自果功能差别”。大意：种子是阿赖耶识中能够直接生起各自果法的潜在功能。（卷二）

熏习。前七识生起时，把影响留在阿赖耶识中，使种子生起或增长，称为熏习。所熏和能熏各具四种条件，卷二有详细辨析。（卷二）

四分。每一个心和心所生起时，都有四个部分：相分是被认识的影像，见分是能认识的作用，自证分是证知见分的自体，证自证分是证知自证分的作用。（卷二）

末那识。末那识恒常审察思量，把阿赖耶识执着为自我，是我执的根源。（卷四）

心所。论中说，心所“恒依心起，与心相应，系属于心”。大意：心所是依心王生起、与心王相应、隶属于心王的心理作用，共有六位五十一种。（卷五）

三性。遍计所执性是虚妄分别所执着的实我实法，根本没有自体；依他起性是依众缘生起的诸法，如幻而有；圆成实性是二空所显的真如，圆满、成就、真实。（卷八）

二障。执着实我生起的烦恼称为烦恼障，障碍涅槃；执着实法生起的烦恼称为所知障，障碍菩提。（卷九）

转依。论中说：“依谓所依，即依他起……转谓二分转舍转得。”大意：转依是在依他起性上转舍遍计所执的杂染，转得圆成实的清净。转舍烦恼障证得大涅槃，转舍所知障证得大菩提。（卷九）

十二个名相之上，有一句话总括唯识宗旨，出自卷七：

```
我法非有，空识非无，离有离无，故契中道。
```

大意：实我实法并不存在，真空与识并非没有，远离执有和执无两边，所以契合中道。

六、白话译注的体例

逐句翻译。每一句原文都译出，不删减，不概括，不另作讲义式的发挥。

点名说话人。“有义”处依《述记》写出论师名字。外人提问译为“外人质问”，并尽量写明是哪一派；论主回答译为“论主回答”。

改写因明论式。原文中压缩的宗、因、喻，改写为“主张是……理由是……例证是……”。原文省略了喻或宗的，在译注中补出。

扭转倒装与指代。古文与梵文的倒装句，一律改为现代汉语的正常语序。原文中的“此”“彼”“其”，一律换成所指的名称。译文不用转折句式，直接陈述。

保留名相。阿赖耶识、末那识、遍计所执等名相保留玄奘大师的原词，第一次出现时在译文中就地讲明含义。

颂文与金刚语。三十颂的颂文和论中引用的经颂，保留原文，放在单独的格式框中，之后给出大意。论中特别精要的语句也保留原文，附上大意。

译注简短。译注只用于真正卡住的地方：论师归属、名相初见、论式省略、文义难解。每条译注力求一两句话说透。

订正底本。底本用大正藏第三十一册第一五八五号。电子底本中繁简转换造成的错字，例如“噁心”应为“恶心”，“唸唸”应为“念念”，“末耶”应为“末那”，以及显示为乱码的缺字，翻译时依大正藏径改，不另出注。
