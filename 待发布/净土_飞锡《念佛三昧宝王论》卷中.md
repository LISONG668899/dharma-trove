# 飞锡《念佛三昧宝王论》卷中

唐代终南山紫阁峰草堂寺沙门飞锡撰。卷中六门，念现在佛，即专念西方阿弥陀佛，以此贯通三世。作者生平见卷上〈作者考据〉。

## 第八门　念现在佛专注一境

问："念未来佛就是念众生，这玄妙的道理我已经听了，事相广博而理趣幽深。又怕心散乱难以收摄，现在想一以贯之，专念西方一尊佛，踏上不退之地，除去有漏之心，乘一叶扁舟于黄金池上，礼拜阿弥陀佛于白玉殿中，以此贯通三世，希望沾得九品往生之益，这样不可以吗？"

答："龙树菩萨所造的《十住毗婆沙论》（解释《华严经·十地品》的论）〈易行品〉说：'菩萨道有难行道，如陆地上乘船；有易行道，如水路上乘船。'

"阿弥陀佛有本愿之力，如果有人听到佛名而称念，自然归于彼国，就像船得了水，又遇上顺风，一举千里，不是很容易吗？释迦如来的父王眷属，六万释迦族人，都往生极乐国土，这是因为阿弥陀佛与这个世界的众生因缘深厚。专注一境而圆通三世，不是很好吗？"

问："专注一境，圆通三世，确实如此。然而称念佛名、自然往生彼国，这是有为法，虚伪不实，就像风多浪起。何不如不向外驰想，只在内摄心，契合无为的宗旨呢？"

答："有为虽然虚伪，舍弃它，道业就不能成就；无为虽然真实，执取它，慧心就不能明朗。经中说：'厌离有为功德，是魔业；乐著无为功德，也是魔业。'您现在厌离与乐著交相争斗，岂不是落入魔的骨髓中了？

"又，如果说圣贤摄心叫做内，凡夫驰想叫做外，假如把向外驰散当作乱，住在内里当作定，那仍然是被内外所驱使，不是念佛三昧摄心的意思。

"《注维摩经》中，罗什法师说：'外国有一个女子，身体是金色的。有一位长者子名叫达暮多罗，用千两黄金邀她进入竹林，同车而去。文殊菩萨在路上变身为一位白衣居士，穿着宝衣，衣服非常庄严美好。女子见了，内心生起贪心。文殊说：你想得到这件衣服，应当发菩提心。女子说：什么是菩提心？文殊说：你的身体就是。女子问：怎么就是呢？文殊答：菩提性空，你的身体也空，所以就是。

"'这女子曾在迦叶佛处多种善根，广修智慧，听了这话，立即证得无生法忍。证得法忍后，为了显示贪欲的过患，仍与长者子进入竹林。进林之后，她自己示现死亡，身体膨胀腐烂发臭。长者子见了，非常恐怖，去到佛所，佛为他说法，他也证得法忍。'

"大觉尚未圆满成就，还不能闲适任运，所以名为'忍'。观自身的实相，观佛也是这样；女身是空，佛身也是空，从来没有不同，菩提的意义又怎么会不同呢？

"这样说来，一切有为就是无为，一切内外都非内外。处在有中而未曾有，有而常无；居于无中而未曾无，无而恒有。又何必担忧佛有相、心有念呢？"

## 第九门　此生他生一念十念

问："易行道、难行道的说法，身即菩提的观法，其宗旨像镜子一样分明了。人生在世，如石中之火、闪电之光，一旦失念蹉跎，后悔莫及。修道的人尚且不亲近自心，何况亲近身体；尚且不亲近身体，何况身外之物？我常怕一口气出去不再回来，就属于来世了，像狂风吹起的飞蓬，茫茫然不知飘向何方。希望开示一念、十念的法门，此生、来生的打算。"

答："净土的法会，是功业中最大的。二乘人澄神于虚无，耽著空性而怖畏有相，不念众生，所以没有净土；大乘才有净土。

"按《悲华经》说：'阿弥陀佛过去曾是转轮王，名叫无诤念，七宝、千子全都具足。因为宝海大臣是他的善知识，他在宝藏佛处发菩提心，取西方极乐净土。诸经中知名的诸佛、菩萨、声闻等，都是他当年的千子。

"'他的长太子名叫不眴，就是观世音菩萨；次子名叫摩尼，就是大势至菩萨；次子名叫王众，就是文殊师利菩萨；次子名叫能伽奴，就是金刚智慧光明菩萨；次子名叫无畏，就是莲华尊如来；次子名叫庵婆罗，就是虚空光明菩萨；次子名叫善臂，就是师子香菩萨；次子名叫泯图，就是普贤菩萨；次子名叫蜜苏，就是阿閦佛。

"'蜜苏王子自从发心以来，行走时步步之间，心与心所之中，常念诸佛，如今登上正觉，生在妙乐世界。'

"我认为，在宽阔的路上经行，在幽静的林中漫步，与蜜苏王子的修行没有不同。如果是佩玉鸣珂入朝的官员，在肃穆的仪仗中，车马疾驰，又怎能不在步步之间用心呢？依此类推，也不会改变前面所说的操守。

"凡是有齿有发的人，处在生死交际之间，没有不靠出入息的。一口气不回来就属于来世，确实如您所问。世上的人，大多用宝玉、水晶、金刚子、菩提子、木槵子做念珠；我则以出入息为念珠。称念佛的名号，随着呼吸，有了大依靠，何必害怕一口气不回来就属于来世呢？

"我在行住坐卧中常用这串念珠，即使在昏沉睡眠中，也含着佛号入睡，醒来就继续念。这样必定会在梦中见到那尊佛，就像钻木取火时，冒烟正是出火的前兆。梦中常常见佛，三昧就成就了，亲见佛的白毫，亲蒙授记，就万无一失了。您应当努力。"

又问："一念、十念往生净土，哪一种是正说？"

答："只要一念往生，就住于不退地，这是正说。如佛所说，谤佛、毁经、打僧、骂尊长，五逆、四重罪，都是一念恶业成就，堕入无间地狱，就像射箭一样快。现在念佛往生净土，也是一念善业成就，就登上极乐。就像屈伸手臂那样短的时间，前一念五阴灭，后一念五阴生，如同用蜡印印在泥上，蜡印坏了，印文已成，尚且不需要两念，哪里要十念呢？打僧、骂尊长虽不是正式的五逆罪，也属于五逆之类。

"又说一念的例子，如经中说：'有个爱吃乳酪的沙弥，生了一念爱心，后来就生在乳酪中做虫。'又大萨婆长者的妻子，坐对明镜，自爱其身，后来海风吹破了船，她便生在自己的旧尸中做虫，嬉戏往来，不离其所。这些都是一念，不是十念。

"又《大无量寿经》说明一念念佛都得往生。《观无量寿经》说十念，自有它的道理：是因为人在病中衰弱，力量微小，心力低劣，所以须要十声称念阿弥陀佛来帮助他的念力；如果心力强盛而不昏昧，一念就能往生，就像栽下发丝般细小的幼苗，将来也能长成百围的大树。"

## 第十门　是心是佛，是心作佛

问："经中说明'是心是佛，是心作佛'。为什么要远远地称念阿弥陀佛，存想极乐国土；近处又要念诸佛，对未来佛生起恭敬？这都是向外求，怎能说是心是佛呢？"

答："您问错了。您只是引用经文，却不知经文的旨趣。这部经就是《观无量寿经》，正是阐明念阿弥陀佛的经文。'以念佛故，佛从想生'，所以说是心是佛。怎能窃取观阿弥陀佛的经文，反过来咬噬念阿弥陀佛的心呢？

"如果这样，完全不念佛，而说是心是佛，那么也应该完全不想恶，而说是心是恶吗？那个既然不对，这个又怎么可以？何况极乐国土的阿弥陀世尊，十万亿个须弥山王的距离，也不能障碍眼根；如恒河沙数的光明相好，由佛的愿力而观想成就；屈伸手臂之间就得往生，哪里还计较那方的远近呢？"

问："是心是佛的道理，我已恭听了。然而这部经所说的十六妙观，韦提希夫人修成了，于是冰与太阳都可观想，金山晃耀分明。可是魔光与佛光，自观与他观，邪正混杂，怎样才能澄清？希望一一开示，使念佛的人即使离开老师独自修行，心也能像大海一样安定。"

答："冰想，是观琉璃地的基础；日想，是观白毫光的前阶。依照观想而显现的，叫做自观、正观；不依照观想而显现的，叫做他观、邪观。本来观想白毫，白毫没有现出来，却没有观想绀青色的眼目，绀目反而现出来了，这就违背了本来的心意，岂不是邪？其余的观想更是这样。

"又，魔光有影子，刺眼；佛光没有影子，也不刺眼。所以《楞伽经》偈说：

```
佛地名最胜，清净妙庄严，照耀如盛火，光明悉遍至，
炽焰不坏目，周轮化三有。
```

大意是：佛地名为最胜，清净而妙好庄严，照耀如盛火，光明遍至一切处；光焰炽盛却不伤眼目，周遍教化三界众生。"

问："现在现出的光，火焰炽盛而伤眼，不是魔是什么？光明而不刺眼，不是佛是什么？"

答："还有，真实的光，令念佛人身心澄静清净；虚假的光，令念佛人心中躁动恍惚。所以《涅槃经》说：'澄渟清净，就是真解脱；真解脱，就是如来。'这就明白了。"

又问："至人无思无虑，现在却用观想，岂不荒谬？"

答："不荒谬。如《大威德陀罗尼经》说：'要超越有的结缚，应当发起欲心，去想无欲之事。'现在依此类推，要修念佛，应当发起想心，去想无想之事。所以《方等贤护经》说：'以恶欲想女人，就梦见女人；以善欲想佛，就梦见佛。'

"我认为这两种想名称相同，善恶却天差地别，不可一听到'想'就一概厌弃。如果一概厌弃，即使不毁经、不谤佛，也必定生到无想天宫去了。如果固执无想而咬噬念佛之想，就名为谤法；因为谤法，立即堕入十方无间地狱的牢狱，不知何日才能出来，哪里还有生天的希望？即使能够生天，也名为外道天，不是解脱之路。

"《涅槃经》说：'随着听到毒鼓的声音，远近的人都会死。'这也是这样，随着拨弃观想，远近的人都会堕落。经中所说'有时离地一尺、二尺，往返游行'，说的就是这种情形。这怎能与三界的流转相同？怎能与九品往生相同？

"何况使船倾覆的、承载船的，都是水；使人跌倒的、扶人起来的，都是地。想是妄的，就是众生；想是真的，就是诸佛。离开想之外，还用什么呢？"

问："事相上的解释已经完了，理在哪里呢？如《般舟三昧经》说：'心起想就是痴，无想就是涅槃。'现在用观想，不也是这样吗？"

答："不是。如果执著有所想的佛、能想的心，或者回避观想佛，把恶取空当作无想，那就是痴得很了。我现在了知佛都从想生，无佛、无想，有什么痴呢？这是观空三昧，不是邪见。

"您又问：'理在哪里？'至人冥合真理，体性寂静，胸怀虚空，虽然同时照了万法，而心未曾有，那么真智无所缘，所以名为无念；俗智有所缘，所以念想得以生起。

"又，'想不异空，空不异想'，名为第一义中道之理，这显示法身；'空即是想'，名为俗谛之理，恒沙万德都依俗谛而立，这显示报身；'想即是空'，名为真谛之理，破二十五有（三界中二十五种存在），得二十五三昧，常空常化，和光利物，这显示化身。

"这就是以三观观三谛，证三德，成三身，乃至十种三法，有什么不可以？为什么要摈弃清净的想，去取无想之想呢？为什么要堵塞禅定之门，却想跨进成佛的门槛呢？

"《楞伽经》《密严经》都说：'宁可起有见如须弥山，'意思是相信因果，存想念佛，往生极乐净土，所以说宁可起有见；'不起空见如芥子，'意思是拨无因果，诽谤念佛，堕入阿鼻地狱，所以说不起空见。可畏啊，就在这里！"

## 第十一门　高声念佛，面向西方

问："想即无想，我已恭听了。然而《方等经》中修无上深妙禅定，令人相续观想白毫，同时称念佛号，以求得殊胜的禅定；契入之后，心与佛两忘，我相信有这回事。但默念如泉水般澄静，三昧自然到来，又何必声音喧闹于街巷，响声震动山林，然后才算修道呢？"

答："正如您所问，出声念佛也没有过失，我试着说明。为什么呢？

"第一，避免散乱的要诀，在于出声。声音不高，心就窃窃然、飘飘然不定；声音高亢，就像拔茅草连根带出，扬鞭策马，从此以后，一心一意直到命终，永远辞别百般忧愁。

"第二，就近处来说，声音与光明所到之处，万种灾祸冰消，功德如丛林，如千山青松茂盛。

"第三，就远处来说，佛的金色身容光辉灿烂，宝华纷纷从空中飘落，清楚得如指掌中之物，都是声音所招致的。

"第四，如同拖拉沉重的木石，重得拖不动，大家齐声高喊号子，就飘然轻举了。

"第五，与魔军作战，旗鼓相望，在战车上用声律鼓舞士气，以此击破强敌。

"具备这么多意义，还有什么可厌弃的呢？不过不如喧与静两全，止与观双运，契合佛意，不是更好吗？如果定慧均等，那么心与佛两忘，就正如您所问的了。

"所以庐山慧远大师〈念佛三昧诗序〉说：'功高易进，念佛为先。'仔细体会玄妙的佛音叩击心扉，一听就使尘累消散，滞塞的情识融化明朗，若不是天下最奥妙的法门，谁能做到这样呢？

"要说明证，没有比《华严经》偈更好的了：

```
宁受无量苦，得闻佛音声，不受一切乐，而不闻佛名。
```

大意是：宁可受无量的苦而能听到佛的音声，也不愿享受一切快乐而听不到佛的名号。

"这样说来，佛的名号声音远远震动，开发善根的萌芽，就像春雷惊动百草，怎能轻易诋毁呢？"

问："高声、低声称念佛的名号，我已恭承其义。十方净土都有如来，只面向西方，岂不是太执滞了吗？"

答："您问错了。这是方等经典中这样说的，不是凡人老师的意思，怎能诽谤方等经典呢？"

问："教证我已恭听，理在哪里呢？"

答："也有它的道理。比如说，有个愚人看见观世音菩萨像有十一面，就设难说：'为什么不安十二面？'等到依他的话安了十二面，他又设难说：'为什么不安十一面？'您想用东方来责难西方，意思就像这样。

"如果还迷而不醒，就让他用这个身体，安置得不背对任何一方，他就会自己醒悟了。如果还是不悟，实在无法教化，只能悲悯了。

"又《胜天王般若经·二行品》说明如来八十种随形好中，有一种随好光明功德，名叫'一切向'，意思是不背对任何人。佛不可背对，常面向一切众生，不像冤家仇人不愿相见，这是慈悲的极致，这就是其中的意义。

"智者大师从孩提之年到六十岁，躺下就合掌，坐下必面向西方。临终时，令人诵读阿弥陀佛四十八愿和九品往生，光明满山，天乐交替演奏，往生净土。面向西方的意义，不是很弘大吗？"

问："面向西方的教理，我已恭听了。般舟的意义在哪里呢？"

答："梵语'般舟'，汉语叫'现前'，意思是思惟不停，佛就在定中现前。九十天常行道，是助成般舟的因缘，不是般舟本身的正义。"

问："净土妙门、般舟的意义，我已全部听到剖析了。然而近代以来，有谁登上了安养国（极乐世界）？既然没有人来回报，怎么知道去了哪里？希望为我说明。"

答："东晋庐山慧远法师是最早倡导的人。慧远大师从佛陀跋陀罗三藏受念佛三昧，与弟弟慧持、高僧慧永，以及朝中贤士、隐逸的清信之士宗炳、张野、刘遗民、雷次宗、周续之、谢灵运、阙公则等一百二十三人，凿山刻铭，发誓往生净土。

"刘遗民所写的发愿文大略说：'我们推想人生如交臂之间便已沦没，觉悟到无常之期迫在眼前；审察三世果报的道理，更知道险恶的去处难以拔出。所以同志诸贤，日夜警惕勤勉，仰望能得救度。然后以妙观证入大义，开启心灵的正照，神识因觉悟而一新，形体随教化而改变。托身于中流的莲花，荫蔽于琼树之下而吟咏，云衣飘拂于八方，香风中泛游度岁。身体忘却安适而更加和穆，心超越快乐而自得怡悦。面对三恶道而远远辞别，傲视天宫而永远告别。继承众多圣灵的轨迹，以舍报往生为期。究竟这条道路，岂不是很弘大吗？'

"慧远大师所作的〈念佛三昧诗序〉说：'所谓三昧是什么？就是思专想寂。思专，就志向专一而不转移；想寂，就气息虚静而精神明朗。气虚，智慧就恬然照了；神朗，就没有幽暗之处照不透。这两者是自然的玄妙符契，会归于一而起作用。又，种种三昧，名目很多，若论功效高而容易进修，以念佛为第一。如果以匹夫所修众定的所缘相比，就不必谈其优劣，高下自然可知了。'

"谢灵运的〈净土咏〉说：

```
法藏长王宫，怀道出国城，愿言四十八，弘誓拯群生。
净土一何妙，来者皆菁英，颓年安可寄？乘化必晨征。
```

大意是：法藏比丘生长于王宫，怀道出离国城，发下四十八大愿，以弘誓救拔众生。净土多么美妙，往生的都是菁英；衰残的年岁怎能寄托？应当乘着化机，及早启程。

"您问'没见到往生的人来回报'，东晋有位阙公则，发愿往生，后来就回来报信了。后来与他同发誓愿的朋友在东京洛阳白马寺，那天夜里为阙公则的忌日诵经，当时林木殿宇都变成金色，空中有声音说：'我是阙公则！我所祈求的往生极乐宝国，现在已经实现，所以来报告。'说完就不见了。支道林赞叹说：

```
大哉阙公！歆虚纳灵，神化西域，迹验东京。
徘徊霄虚，流响耀形，岂钦一赞，示以匪冥。
```

大意是：伟大啊阙公！心慕虚寂，含纳灵明，神识往生西方，事迹应验于东京洛阳；在空中徘徊，留下声响，显耀形迹，并不是为了博取一赞，而是要显示往生不虚。

"又虞孝敬赞叹说：

```
猗欤公则，先甘法味，知我者希，其道乃贵，
金光夜朗，玉颜朝睟，不舍有缘，言告其类。
```

大意是：美哉公则，先尝法味；知我者稀，其道乃贵。金光照亮夜空，玉颜清朗如晨；不舍有缘之人，回来告诉同道。"

## 第十二门　梦觉一心以明三昧

问："阙公则往生，以金光来回报，我恭敬地接受了。佛说一切法如梦，不知所念的佛、所生的净土是否也如梦？如果不是梦，那么佛就在心外；如果是梦，那么佛就在梦中。就像梦中得到黄金，醒来一无所获，我实在怕白白地念三身佛，最终归于一场虚妄。请为我分辨。"

答："不是虚妄。怎么知道呢？如果修念佛三昧的人，像梦中得金、醒来一无所获，那就等同于虚妄了。可是究竟因念佛而往生净土，怎能说是虚妄呢？

"如修习天眼法，先观想宝珠、火等光明，观想不停，就真的发起天眼，谁能说是虚妄？这岂能与梦中的黄金、毕竟无有相同？不要把远处的事当作近处所见，拿梦来作比喻。不能把念佛往生完全等同于梦，这就明白了。

"又《华严经》说：'心、佛与众生，是三无差别。'心迷就像梦，九法界的众生就是；心悟就像醒，一法界的诸佛就是。迷与悟只在一心，梦与醒从来没有两条路。经中所说：'了妄本自真，则见卢舍那。'即使是梦妄，又有什么差失呢？只要唯心而观察，心志如磐石不移。"

## 第十三门　念三身佛破三种障

问："佛有三身，应当怎样忆念？希望开示方便，使我没有差失。"

答："佛的三身，就是法身、报身、化身。法身如月的本体，报身如月的光明，化身如月的影子。万水之中都有月亮，这月亮是多还是一呢？不能说是一，因为万水中的月亮各有差别；不能说是多，因为虚空中的月亮常是一个。就像梵文的伊字三点、摩醯首罗天的三只眼，纵、横、并、别都不可思议。经中说'或现小身，丈六、八尺'，都是众生心水中所现的佛。佛尚且无形，哪里有两个呢？净土与秽土也是这样，都在众生自己。

"如果想以念三身佛破三种障，现在试着说明。佛身的生起，从止观而生；止观不均衡，障碍必然生起。

"念佛的人修止时，心沉没下去，昏暗之障就生起，障蔽化身佛。这时须要用观心来策励，念佛的白毫光明，破除昏暗之障。

"修观时，心浮动起来，无恶不造，障蔽报身佛。这时还要修止，止息一切恶。念诸佛往昔因地所修恒沙功德、智慧圆满，酬答因地的修行叫做报，以此破除恶念之障。

"如果有无与边见两种障碍动起来，种种诡异的形状、万象纷纭，如刚强与柔软两种盗贼，这就障蔽法身佛。要用中道第一义空来破除它。偈中说：

```
无色无形相，无根无住处，不生不灭故，敬礼无所观。
```

大意是：佛无色、无形相，无根、无住处，因为不生不灭，所以以无所观之心敬礼佛。

"所观的这个理，就像毗岚猛风吹散重重乌云，显出法身清净的宝月，破除逼恼之障。这就是应病与药，不正是这样吗？（这是天台智者大师的解释，我所披阅寻访还不够广，但确实未曾见过其他各家有这样精妙的解释。止观的意旨前面已经略加辨明，至于细节，有待口头讲解，不是文字所能尽述的。）

"我既然教化他人，他人也教化他物，物我都得成就，三昧就更加兴盛；众生无尽，三昧也就不绝。"

以上六门，都是念现在阿弥陀佛，以此贯通三世的意思。详细的内容，如道绰禅师《安乐集》、天台《净土十疑论》、怀感法师《释净土群疑论》、《往生传》、僧稠禅师《法宝义论》所解释的那样，也如我飞锡先前所撰《无上深妙禅门传集法宝》一卷中所广说的那样。
