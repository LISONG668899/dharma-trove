# 蒋扬钦哲旺波《辨析宗义之言·了义耳饰》

## 题解

这是蒋扬钦哲旺波（1820—1892）答复他人提问的一篇短论，通篇以偈颂写成，收在《钦哲旺波文集》第二函。

藏文原题 grub pa'i mtha' rnam par dbye ba'i gtam nges don rna cha，直译是「辨析宗义之言·了义耳饰」。耳饰是比喻：这番话如同一只耳环，献给听者的耳朵。

此文兼属藏地两类文体。一类是宗义（grub mtha'），按见解高下排列印藏各家学说。一类是答问（dris lan），弟子提问，上师作答。文末说提问者「以稀有的智慧赐下无边的提问」，但此人是谁、何时何地所写，全文都没有交代。

全篇的骨干是一句话：从有部到大圆满，一切宗派都是证悟同一法性的方便。文中依次辨析外道、有部、经部、唯识、自续、应成，而后以大半篇幅讲萨迦道果，指出道果与唯识的距离、道果与大圆满的一味、道果与他空的不同，最后讨论佛智是有是无，归结到实修。

## 顶礼

上师的自性是无为法性，面容是空、无相、无愿三解脱门，与自心的金刚无二无别。尊者向这样的上师顶礼之后，说：以下略略开演答问。

## 佛陀为何宣说无量乘

宣说无二者的自在尊，为了把声闻、缘觉、菩萨三种种姓的所化众生，安置在各自的菩提果位上，宣说了不可思议的因乘与果乘。

不了悟这一点的众生，抓住自己暂时认可的一方，搅乱教法。尊者的断语很重：

```
不悟彼义诸有情，执取一时所欲边，
扰乱圣教即是将，大天行迹装作法。
```

大天，是佛教史传中与僧团第一次分裂相关的那位比丘。把宗派偏执当成护法，在尊者眼中不是弘法，是坏法。

此中，从声闻有部起，直到最胜秘密的金刚藏，全都是为证悟唯一法性之真如而正确宣说的方便。「最胜秘密的金刚藏」在此即指大圆满。

【按】尊者先立下这条总纲，后文的层层高下才有归处：分辨高低不是为了贬斥，是为了认路。

## 内外之分在哪里

一切喜好宣说常见断见的外道，彼此争执不休，却有一点完全一致：都承认有一个常、一、自主的补特伽罗我。

佛门内的各宗，则有一个共同的起点。在五蕴上寻找这个我：说它与蕴是一，找不到；说它与蕴是异，找不到；离开蕴另有，也找不到。因此成立人我不存在。各宗都以此为基础，再向上分出高下。

【按】原文此处作 rang sde，是「自宗」即内道全体，不限于声闻一家。汉译旧本作「自宗教法声闻曰」，把范围缩窄了。

## 四宗的次第

有部承许所取境的微尘、能取识的刹那是无分而真实成立的，所以连粗分的法我也没有断除。

经部虽然承许一切外境都只是心上的显现分，但仍然承许这显现的来源是外境本身，所以断除了所取方面的粗分法我。

【按】经部这一立场是它特有的认识论：根识与所缘有前后因果关系，心所见的是自己的行相，而这行相由在先的真实外境作所缘缘而生。所以它既不说心直接见外境，又不肯放弃外境。

唯识宗观察：色法分不出真实的方分，心识分不出真实的时分。由此确定能取所取并非真实成立。但唯识宗仍然承许，远离能所二取的圆成实是真实成立的。

【按】这里只说方分与时分不成立，不是说色法心识一概没有。所破的范围要照原文守住。又，此处是本论按宗义高下所作的判摄，不等于所有唯识论师自己的表述。

中观自续派以五大正理，把唯识宗留下的那个圆成实也抉择为无实，于是安立：胜义中无自性，世俗中如其显现而承许。

【按】「五大正理」原文作 rig chen lnga，依文义当读作 rigs chen lnga。论中没有列出名目。通常所说的五大因是金刚屑因、破有无生因、破四句生因、离一多因、大缘起因，此处的补充属于译者注。

中观应成派则舍尽一切属于增益与损减的承许戏论，专以指出他宗主张自身内部相违的正理摧破对方，这是它的独到处。

## 应成与大圆满一味

```
彼与大圆满二者，于不可思议法性、
超越分别之境中，一味故当以极深
等持之心而观之。
```

应成派与大圆满，在不可思议的法性、超越分别心的境界中，是同一个味道。对这一点，尊者只给出一句话的指示：当以极深等持之心去观察。

【按】这是全篇最要紧的一句叮嘱之一。原文说的是「以极深等持之心观之」，强调亲自安住体证，并不是说此事与正理无关——本论自己大量使用教证理证。它要防的是：仅凭概念上把两家对照一番，就断定自己已经懂得一味。

## 唯识与他空并不相同

无垢清净的唯识宗与他空派，两家并不相同。因为前一家承许识是胜义，后一家承许智慧是胜义。

## 道果的三步

道果派的抉择分三步：成立显现即是心，成立心的显现如同幻术，成立这幻术本身也没有自性。第三步又从缘起与离言两门来说明。

【按】这三步即萨迦道果所传毗瓦巴《道果金刚句》的次第。原文于第三步只说「分缘起、离言二者」，没有展开。

有人以为，既然道果主张显现唯心，那就和主张实有的唯识一样了。尊者说，这种想法是邪分别，毛病出在没有用细致的智慧去观察。

【按】果然巴在《入中论释·遣除恶见》末尾驳斥过同一类指控，说「以粗劣智慧讲毗瓦巴是唯识师的人，至尊上师早已遮破」。所指的上师即萨迦班智达。

## 显现唯心有续部与正理的依据

若问何故如此？《金刚帐续》说：

```
除此珍宝心以外，无有佛陀无众生，
识之所依与所缘，于外丝毫不可得。
```

《桑布札续》也说：

```
内外一切有体者，此等皆应观为心，
除心之外于他处，诸法并非有所住。
```

其中的道理，怙主龙树在《菩提心释》中讲得明白：

```
于一外境形色上，诸识各别而趣入，
凡是悦意之色相，于他显现成他样。
同一女人之身躯，苦行贪者与狗三，
视为不净、所欲境、可食之物成三种。
```

同一个身体，苦行者看见的是不净，贪欲者看见的是所欲，狗看见的是食物。

【按】尊者引这段，是为了证成「显现唯心」有圣教与正理的依据，并非道果一家的杜撰。从「不同心识所见不同」这一点，不宜直接跳到「外境全然不存在」的结论——经部同样承认一个在外的因能引生不同认识，而并不放弃外境。此处的证成范围要守住。

【按】龙树此颂，德格版作「尸体」（ro），本论所引作「不净」（mi gtsang）。二者都通，此处依本论。

特别要分清：道果承许显现唯心的方式，虽与瑜伽行派相同，但道果不承许心性真实成立，而许其离戏。差别正在这里。

## 见解次第出自续部

此外，光明大圆满的《觉性自现大续》等，从宣说常断的外道起，直到最胜秘密的金刚藏，广分见解的次第。

《喜金刚根本续》也说：

```
于彼先示有部宗，经部亦复如是说，
其后乃是瑜伽行，继此而示中观宗。
```

【按】《喜金刚根本续》这段的上下文是教授弟子的次第：先授斋戒，次授十学处，然后依次教有部、经部、瑜伽行、中观，遍知密咒次第之后，才开始修喜金刚。所以它说的是引导的阶梯，不是优劣的清单。

## 道果如何胜过四宗

瑜伽自在毗瓦巴，为了让修行人次第趣入而解释的密意心要，以蕴、界、处来宣说。就这一点而言，它与声闻二部相同，而胜过外道。

道果宣说：没有外境，能缘之识，以及异于这二者的「无二」，都没有自性成立。就这一点而言，它胜过唯识宗。

道果承许世俗虽如幻显现，却不对胜义作「胜义就是此」的立宗。就这一点而言，它胜过主张无自性的中观。

【按】此处的「主张无自性的中观」（ngo bo nyid med pa'i dbu ma），在萨迦判教中通常指自续一系，与瑜伽行中观相对。论中未明言，故存此一说。

因此，本来就超越了分别心所造作的四边戏论，又以双运的方式实修，这才是此道密意的究竟。

## 道果与大圆满一味

```
此亦并非唯言词，于胜义作各别观
之本智，从法界中
迸涌之时，即与大
圆满成一味也。
```

这并不只是言词上的事。当于胜义各别观照的本智，从法界中迸涌而出的时候，它就与大圆满成了一个味道。

【按】此处用的是「本智」（ye shes），承接前文超越四边的实修，不是指分别思辨更加锐利。「从法界中迸涌」的 klong 是界、广界，不宜译作「内心深处」。这一句说的是智慧的实际现前，不是概念上对两家的比较。

既然一味，两家的教法为何看起来如此不同？尊者答：甚深秘密心髓中所说的「以强力直指觉性」，针对的是利根、顿悟种姓的人；语教道果的讲说方式，则是次第引导。差别在根机与引导方式，不在最后所证。若能善知此理，所谓两家相违的戏论，自然息灭于法界。

## 道果与他空名同义不同

毗瓦巴把心性安立为明空双运，他空派则把如来藏安立为圆成实。二者名称虽同，意义不同。

若问何故？文殊怙主萨迦班智达说：

```
是故如来之藏性，以其本自离戏故，
于诸有情前佛陀，与轮回二皆应理。
```

以此等众多能立，成立如来藏即是离戏；而他空一方则许它是常、是坚固、是圆成实。这两种主张，有相同的时候吗？

因此，大全知说：

```
自性光明水晶界，习气颜料所染转，
由是现为种种位，此界即轮涅之基。
```

水晶本身透明，挨着什么颜色就现什么颜色。自性光明的法界也是这样，被习气染动，暂时现出种种景象。轮回与涅槃，都以这个法界为基。

为显明此义，他又说：

```
此中慈氏与龙树，许为明而不间断、
空于四边戏论者，即无为之双运也。
```

并以教证理证广为成立：龙树与无著两大车轨的密意，归于一处。

【按】「大全知」原文作 kun mkhyen chen po，未出名。钦哲愿景计划的译注指此为果然巴·索南僧格（1429—1489），并将水晶喻与慈氏龙树二颂定位在他的《三律仪辨别论补遗》第六四七页。前一引文出自萨迦班智达《三律仪辨别论》，此处接以果仁巴的补遗，文脉相顺，此说可从。惟笔者未逐页核对果然巴原集，姑依译注。

## 这个法界的众多名称

这一事相的能诠，又以法界、有垢真如、光明、善逝藏、心之自性清净等许多异名来宣说。《楞伽经》《密严经》、瑜伽自在的窍诀，以及吉祥月称足等诸师，也都承许「阿赖耶」这个名称所指的就是它。在甚深续部中，还以文殊、大智慧、俱生、金刚、金刚萨埵、吉祥、普贤等无量名称宣说。对这些明白的讲法，应当以细致的智慧去观察。

【按】此处原文只作 kun gzhi（一切基、阿赖耶），没有「识」字。藏文中这个词在不同脉络里所指不同：在唯识是心的基础或阿赖耶识，在大圆满心部则与觉性同义。所以不能仅凭名称相同，就把这里的离戏法界与唯识第八识划等号。

## 两种偏执，此处暂不破立

除此以外，有人主张这藏性只是在有垢的心上以正理遮破实有而已，有人立宗说它唯是真实成立。依清净的理路，可以指出前者落入损减、后者落入增益。但尊者说：此处依中观之道，暂时不作遮破，也不作成立。

## 佛智是有是无

果位的佛智，中观自续派许为无，他空派说它是常、是坚固、是不变。究竟了义的应成派，因为佛智是不与分别心共处的不可思议行境，所以主张它离于有无二种承许。

【按】这是本论的判摄，不等于各家自己对佛智的通行定义。

经中说「无有智慧」，密意是说佛智不与有漏诸法相应；这样讲的必要，是为了遮止常执。有些经中说「有智慧」，密意是说超越思议言说的智慧周遍一切轮涅；这样讲的必要，是为了遣除断边。

【按】「相应」（mtshungs ldan）是术语，指心与心所那样的相应关系。经说「无智」，不是说佛没有智慧，是说佛智不是与有漏法相应的那一类东西。有与无两种说法，都要按尊者随即给出的密意去理解，不能停在字面。

实则，超越二边、离诸承许的实相，一旦在自前现量证悟，常断戏论便当下解脱于法界。

## 结劝

```
若欲善知此义者，寂静悦意林泉中，
除一心而等持外，寻思诤辩终不及。
```

想要真正懂得这个道理，除了在寂静悦意的林泉里一心等持之外，靠寻思者那一套自相纠缠的诤辩，永远到不了。

【按】此处所呵的是「寻思」（rtog ge，即以概念推度为能事的诤辩），不是前文反复使用的「正理」（rigs pa）。本论自己正是以教证理证立论，并不排斥闻思抉择；它所拒绝的，是以辩论代替亲证。

因此，具善缘的你，饮下甚深义如初升之日的精华，愿你殊胜的智慧如白莲绽放，以修断之果而富足。

【按】「修断之果」（sgom spangs 'bras bu）一语，指修道所断已尽的果位，即圆满正觉。

尊者最后说：你以稀有的智慧赐下无边的提问，可我被愚昧与懈怠所转，哪里有广说的机会。虽然如此，愿此略摄奉上之作中的过失得以清除；以此善根，愿如海的一切有情都证得遍智。

愿恒时吉祥。

## 文献说明

底本为蒋扬钦哲旺波《文集》第二函（kha），宗萨二〇一四年版，第一五六至一六二页；另有甘托克一九七七至一九八〇年版第二函第一五八至一六五页。本文依藏文迻译并作白话疏解，文中引文均按藏文重译。

论中所引出处：《金刚帐续》（Toh. 419）、《桑布札续》即《真实相合大续》（Toh. 381）、龙树《菩提心释》（Toh. 1800）、《喜金刚根本续》（Toh. 417/418）、《觉性自现大续》（大圆满十七续之一）、萨迦班智达《三律仪辨别论》、果然巴《三律仪辨别论补遗》。

人名对照：毗瓦巴（bir wa pa），旧译亦作彼瓦巴、波瓦巴；果然巴·索南僧格（go rams pa bsod nams seng ge）；慈氏怙主（byams mgon）即弥勒；二大车轨指龙树与无著。

本论另有汉译流通本，题作《诸乘法了义辨别之言·耳饰论》。其中「诸乘法」对应藏文 grub pa'i mtha'，实为「宗义」；篇中数处亦与藏文有出入，故本文另立题名，并重译全文。
