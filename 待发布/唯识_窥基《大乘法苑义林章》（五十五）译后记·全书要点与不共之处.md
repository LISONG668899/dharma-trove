# 窥基《大乘法苑义林章》（五十五）译后记·全书要点与不共之处

《大乘法苑义林章》七卷二十九章，到这里全部译完，共五十四篇。这篇译后记做三件事：

1. 交代全书的脉络和体例。
2. 归纳各章的要点。
3. 说明这部书有别于其他唯识典籍的不共之处。

最后附上翻译说明。

## 一、全书脉络

"法苑"是佛法的园林，"义林"是义理的丛林。窥基把唯识学最要紧的题目一个个提出来，每个题目立为一章，用"几门分别"逐层抉择。七卷的分布如下：

1. 卷一：总料简章、五心章、唯识义林、诸乘义林。
2. 卷二：诸藏章、十二分章、断障章、二谛章。
3. 卷三：大种造色章、五根章、表无表色章。
4. 卷四：归敬章、四食章、六十二见章、八解脱章、二执章。
5. 卷五：二十七贤圣章、大乘蕴界处义、极微章、胜定果色章、十因章、五果义、法处色义林。
6. 卷六：三宝义林、破魔罗义林、三慧义林、三轮义林。
7. 卷七：三身义林、佛土章。

按内容看，这二十九章正好走完一条由教到果的路：

1. 教：总料简章判定佛陀一代教法的利益、时期、宗旨、体性、名称；诸藏章、十二分章说明教法的部类。
2. 理：唯识义林立本宗的根本道理；二谛章安立真俗；诸乘义林、二执章、断障章说明所破的执、所断的障。
3. 法相：五心章细析一念心的生起；大种造色、五根、表无表色、极微、胜定果色、法处色、蕴界处、四食诸章，把色心诸法的体性一一判清；十因章、五果义说明因果的法则；六十二见章破外道诸见。
4. 行位：八解脱章、二十七贤圣章、三慧义林说明修行的方法和位次；归敬章、三宝义林说明皈依的对象；破魔罗义林说明修行的障碍怎样降伏。
5. 果：三轮义林说明佛菩萨的教化作用；三身义林、佛土章说明佛果的身与土。

所以这部书可以看作一部以专题写成的唯识学纲要。《成唯识论述记》是随论文逐句解释，《义林章》是把散在各论中的名相按题目收拢，学唯识的人对照读，脉络就清楚了。

## 二、体例的特点

读过全书会发现，窥基每一章都用同一套方法写：

1. 门分别：每章先说"略以几门分别"，通常是辨名、出体、废立、诸门问答等，一门之下再"于中有二""复分为三"，层层分科。本译文的标题和编号，就是照这些科判排出来的。
2. 先列众说，后出正义：遇到有争议的地方，窥基用"有义……有义……"列出几家说法，最后说"如实义者"，表明自宗的抉择。《三身义林》出体一门列六说，判"三理无谬"；《佛土章》处所一门列三说，取"如实义"，都是这种写法。
3. 六合释：几乎每个名相，窥基都分析是持业释、依主释、相违释、带数释还是有财释。这是慈恩一系解名的家法，学人借此可以准确把握每个复合名词的结构。
4. 会通诸教：经论说法有出入，窥基不轻易判某一说错误，常说"各据一义，亦不相违"，再指出各说依据的角度。《三身义林》会通《金光明经》应身、化身与《成唯识论》他受用、变化，《佛土章》会通净土诸因，都是例子。
5. 广引经论：全书所引经论极多，以《瑜伽师地论》《成唯识论》《佛地经论》《摄大乘论》《显扬圣教论》《杂集论》为主，兼引《解深密经》《楞伽经》《金光明经》《胜鬘经》《涅槃经》《法华经》《大般若经》等。有的章节几乎是一部小型的经论汇编。

## 三、各章要点

### （一）判教与教体：总料简章

总料简章是全书的总纲，分五门：

1. 教益有殊：法轮的利益与了义的利益。
2. 时利差别：先评菩提流支一时教等古人判教，再依《解深密经》立三时教。初时为声闻说四谛有相，第二时为大乘说一切法无自性，第三时普为一切乘显了说三无自性性。第三时是"无上无容，是真了义"。
3. 诠宗各异：列外道十六种宗、小乘诸宗，再列大乘两派。清辨等依《般若经》说胜义皆空，窥基称为"偏于一边的宗主"；天亲等依《解深密经》说一切法非空非有，是"中道的宗主"。
4. 体性不同：辨外道、小乘、大乘各家所说的教体。
5. 得名悬隔：用六合释解释经论得名的缘由。

这一章确立了全书的立场：以《解深密经》第三时教为了义，以三性、唯识所成立的非空非有为中道。

### （二）唯识的根本：唯识义林

唯识义林是全书的理论核心，有三个要点：

1. 五种唯识：境唯识、教唯识、理唯识、行唯识、果唯识。窥基说一切经论所说的唯识，不出这五种。
2. 五重唯识观：
   - 遣虚存实识：遣除遍计所执，保留依他起、圆成实。
   - 舍滥留纯识：舍去容易与外境相混的相分，保留见分等。
   - 摄末归本识：把见分、相分收摄归于自证分。
   - 隐劣显胜识：隐去心所，显出心王。
   - 遣相证性识：遣除事相，证得唯识的真性。

   这五重从粗到细，由遍计到圆成，是慈恩一宗观行的骨架。
3. 唯识义林还说明：以哪一识作观，真性识与幻性识的差别，悟入唯识的五位，以及观法依身、依地生起的条件。

### （三）乘、障、谛：诸乘义林、断障章、二谛章、二执章

1. 诸乘义林：依《楞伽经》《大乘庄严经论》立五种种性。《法华经》说一乘，是为了引摄不定种性。依《法华论》四种声闻，佛只为退菩提心声闻和应化声闻授记，不为趣寂声闻、增上慢声闻授记。这就是"一乘方便，五性真实"。
2. 断障章：辨析所断的烦恼障、所知障，能断的道，二障各在哪一识，各由哪一道断，以及见道、修道中顿断与渐断的次第。
3. 二谛章：立四重二谛。世俗谛有四重：世间、道理、证得、胜义；胜义谛也有四重，最高是"废诠谈旨"的胜义胜义谛。窥基用这一结构会通《涅槃经》七番二谛等各家说法，使"有"与"空"在不同层次上各得其位。
4. 二执章：分析人我执、法我执，各在第六识、第七识中的体性和相应心所。这一章原文残缺，只存前五门，译文附上散落的十六空颂释文。

### （四）一念心与色法：五心章及色法诸章

1. 五心章：一个境界现前，心识依次生起率尔心、寻求心、决定心、染净心、等流心。窥基用十二门分析五心在八识中的有无、刹那的多少、乱生与不乱生、属于三性中的哪一性、属于三量中的哪一量。这是唯识学对认知过程最细的分析之一。
2. 大种造色章、五根章：说明四大种与所造色的关系，五根的体性和作用。
3. 表无表色章是全书最长的一章，共十门。唯识宗的立场是：身表、语表都是假立，真正的业性是思；无表色依思的种子上防发的功能假立。窥基又详细比对四部广律、五部律论所说的得戒方式、具支多少、舍戒因缘，是研究戒体的重要材料。
4. 极微章：大乘不承认实有的极微，极微只是以慧分析粗色所假想立的。
5. 胜定果色章、法处色义林：说明由殊胜禅定所变现的色法，以及法处所摄色。
6. 大乘蕴界处义：以唯识立场重新安立五蕴、十二处、十八界。

### （五）因果、见、行位：十因、五果、六十二见、八解脱、二十七贤圣、三慧

1. 十因章、五果义：十因、四缘、五果的相互关系，是唯识因果论的总汇。这两章原文都有残缺。
2. 六十二见章：依前际十八见、后际四十四见，一一说明外道诸见的成因与体性。
3. 八解脱章：说明八解脱的体性、所缘、依地。
4. 二十七贤圣章：说明声闻二十七种有学、无学的建立。原文有几个问题缺了答案。
5. 三慧义林：闻慧、思慧、修慧的体性、所缘、废立，诸智相摄，十种法行，以及陀罗尼与地上证得。

### （六）皈依与教化：归敬章、四食章、三宝义林、破魔罗义林、三轮义林

1. 归敬章、四食章：说明归敬的意义，段食、触食、思食、识食四食的体性。
2. 三宝义林：分同体、别体、一乘、三乘、真实、住持六类三宝，逐类出体。
3. 破魔罗义林：说明四魔的体性和降伏的次第。
4. 三轮义林：神变轮、记心轮、教诫轮是佛菩萨摧伏众生的三种作用。窥基不取《俱舍论》"三示导"的名称，因为大乘的"示导"只是教诫轮。

### （七）佛果：三身义林、佛土章

1. 三身义林：
   - 出体一门列六说，判定：法身以清净法界为体；四智品的真实功德是自受用身；平等性智所现、为十地菩萨所见的是他受用身；成所作智所现、为地前三乘所见的是变化身。
   - 开合一门收摄二身、三身、四身、十佛、十身。
   - 因起果相一门依多闻熏习说明无漏种子"本有、新熏兼有"，以"转灭""转齐"说明种子逐品增胜。法身由了因显现，受用身、变化身由生因生起。
   - 诸门一门辨三身的常与无常。法身是自性常，受用身是不断常，化身是相续常；受用身从因生起，所以不是本性常。
2. 佛土章：
   - 立法性土、自受用土、他受用土、变化土四土。
   - 四土配识：法性土是法性心，自受用土是第八识所变，他受用土是第七识所变，变化土是前五识所变。
   - 净土的因是善根与大愿。
   - 西方极乐世界是报土还是化土，列两种解释，任凭读者取舍。
   - 末尾依《佛地经》十种圆满说明四土的相状。

## 四、不共之处

把这部书放在汉传佛教的义学典籍中看，有以下几点是其他宗派的章疏所不具备的：

### （一）以"非空非有"的中道立宗

窥基判清辨"胜义皆空"为偏于一边，以天亲依《解深密经》建立的三性、唯识为中道：遍计所执是空，依他起、圆成实是有；在胜义中言语断绝，非空非有。全书一切抉择，从唯识观到三身四土，都从这个立场出发。天台讲性具，华严讲性起，进路都与此不同。

### （二）五重唯识观

五重唯识观是慈恩宗独有的观行体系。观行从遣遍计到证圆成，层次分明，每一重都对应心识结构中的一个层面：相分与见分、自证分、心王与心所、事与理。慈恩宗的观法建立在八识、四分、三性的精细分析上，这是本宗观行的特色。

### （三）五性各别，一乘为方便

窥基坚持五种种性真实存在，承认有决定种性的声闻、独觉，以及无种性的有情。《法华经》的一乘，窥基判为引摄不定种性的方便说。《三轮义林》末尾也说，无种性的有情可以受三轮教化，终究不能证得无上菩提。这是慈恩宗与天台、华严、禅宗"一切众生皆当成佛"之说最根本的分歧，也是汉传佛教史上长期争论的题目。读者读到这些地方，可以看到窥基所依的经论根据和推理，再与其他宗派的说法对照。

### （四）四重二谛

用世俗、胜义各四重的结构安立真俗，把"有"与"空"分配在不同层次。这样，说"有"的经文与说"空"的经文各有所当，不必互相取消。这一结构是窥基会通诸教的主要工具。

### （五）色法与业的唯识化

表无表色章、极微章、胜定果色章、法处色义林几章，把有部、经部所说的实色一一判为依识假立：表业以思为体，无表依思种假立，极微只是慧所分析。这几章是唯识宗色法论最集中、最系统的表述。

### （六）三身四土配八识四智

三身义林、佛土章把佛身、佛土与四智、八识一一对应：

1. 自受用身由大圆镜智所起，自受用土由第八识所变。
2. 他受用身由平等性智所现，他受用土由第七识所变。
3. 变化身由成所作智所现，变化土由前五识所变。

他受用身与变化身的差别，由所化的众生是十地还是地前决定。这一套"身土配识"的体系，是慈恩宗佛果论的不共之处。

### （七）无漏种子本有、新熏兼有，以"转灭""转齐"说增长

窥基破"只有新熏"和"只有本有"两说，取"本有、新熏兼有"，再用"转灭"（劣品灭，胜品生）、"转齐"（劣品转成胜品）两种意义说明无漏种子从下品到上品的增长。这为"成佛有因"提供了种子论的说明，与如来藏系"本自具足"的说法路径不同。

### （八）净土不出三界处所

佛土章破斥古人"三界之外另有净土处所"的说法：所化的众生必有异熟识，异熟识必属三界。"超过三界"是说净土不被三界所系，不是另有方位。窥基又说"随心净处即净土处"。这一论断把净土问题放回唯识的立场来看。窥基对西方是报土还是化土并不独断，两说并列，任人取舍。

## 五、翻译说明

1. 底本：《大正藏》第四十五册 No. 1861，以简体本为工作本，对照繁体本。
2. 用语：一般名相采用索达吉堪布的译经用词，如"恒常""所化""加行""后得智"等。
3. 原文保留：精彩、重要的经论引文，以及难以确定的句子，保留原文，附上大意；陀罗尼保留原文，不翻译。
4. 存疑与补字：遇到原文疑有讹误、文义难以确定之处，标"存疑"，说明所依的推测。原文缺字的地方补字并加注。
5. 残缺章节：二执章只存前五门；十因章止于"答略有六别"；五果义只存第三门；二十七贤圣章有几个问题没有答案。凡是残缺之处，译文都照原样保留，并加译注说明。
6. 句式：原文中古汉语和梵文翻译带来的倒装、指代、转折，尽量改为现代汉语的直接表达，每处都写明主语，方便现代人阅读。

窥基的文字以简古难读闻名，本译难免有理解不到、表达不准的地方。凡标"存疑"之处，都欢迎读者对照原文指正。
