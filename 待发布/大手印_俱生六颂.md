# 俱生六颂

梅纪巴（阿瓦都帝·无二金刚）造　据梵藏对勘译出

## 题解

《俱生六颂》（梵 Sahajaṣaṭka，藏 lhan cig skyes pa drug pa）收于德格版丹珠尔续部释 ཝི 函第 111a 页（东北目录 D2232），紧接在《除恶见难释》（D2231）之后，与前面的《中观六颂》（D2230）是一对同样体裁的短篇，同属梅纪巴的"无念法类"。藏译者是印度上师金刚手与藏地的粗敦译师。本篇的梵文原本尚存，收于马特斯（Klaus-Dieter Mathes）所校订的梅纪巴无念法类梵藏对勘本中。

《中观六颂》是从宗义的角度，判摄各家对"离四边"的理解，最后归到密乘；这一篇则直接从密乘与大手印的角度来讲"俱生"。全篇的线索是：先立真性远离常断二边（第一颂）；再说观察时一切无、不观察时一切有，既不落实有，也不坏世俗缘起（第二颂）；然后说真实瑜伽士随增益之起而摧破增益（第三颂）；接着说俱生不造作，所以执著不属俱生，俱生即乐，乐以离著为相（第四颂）；了知此乐，万象都成为自证，没入俱生之海（第五颂）；最后说密咒瑜伽士安住离著之义，把诸有都当作上师，于一切境都无所执著（第六颂）。

修订说明：本站初版只据藏文译出。此次依梵文原本与马特斯、布伦赫尔兹（Karl Brunnhölzl）、达夫（Tony Duff）三家译本逐句对勘，有几处实质改正：第一颂末句，藏文传本作"作礼"或"富"，据梵文应作"畜"，即"愚夫之言"；第二颂末句，藏译脱落否定词，据梵文应作"不观察时一切有"；第四至第六颂反复出现的关键词，藏译作"无疑惧"，梵文作"离执著"，正文改依梵文，藏文读法并存于按语。

体例：每颂先列藏文原颂、梵文原颂于代码块中，再出白话译文，次出七言偈颂译文，最后以"【按】"说明梵藏异读与义理上可有两解之处。白话中为便于理解而补的字，放在方括号中。藏文底本照德格本录出，不径改，校改意见都写在按语里。文末附白话连读与偈颂通读。

## 第一颂

```
རྟག་དང་ཆད་ལས་ངེས་གྲོལ་བ། །
དེ་ཉིད་བདེ་གཤེགས་རྣམས་ཀྱིས་བཞེད། །
རང་བཞིན་ལས་སྐྱེས་ཆོས་རྣམས་ལ། །
སྒྲུབ་དང་སེལ་བར་ཕྱག་ནི་བརྗོད། །
```

```
śāśvatocchedanirmuktaṃ tattvaṃ saugatasaṃmatam |
prakṛtyājātadharmeṣu vidhyapohau paśor vacaḥ ||
```

白话：决定远离常边与断边的真性，是善逝［之教的追随者］所承许的。对于本然而生起的诸法，妄加成立或遣除，那是愚夫的言论。

<div class="dt-verse">
永离常断二边者，<br>
善逝许此为真实；<br>
于诸本然生起法，<br>
妄加立遣愚夫言。
</div>

【按】一，末句的关键字，本篇所据德格底本作 ཕྱག（礼敬），另有传本作 ཕྱུག（富），达夫即依后者译作"富于成立与遣除之言"，两读都难以通解。梵文作 paśor vacaḥ，意思是"畜类之言"，可知藏文原应作 ཕྱུགས（畜），传写时脱去后加字而讹。本站初版依 ཕྱག 译作"就其离于成立与遣除而作礼赞"，并已注明"藏译或有讹误，存疑"；今据梵文改正，初版读法撤回。paśu（畜）在密续中常用来称呼尚未开悟、被分别所系缚的凡夫，所以这里译作"愚夫"，并非骂詈之辞。

二，"善逝所承许"，梵文 saugatasaṃmata 中的 saugata，字面是"善逝之徒"，也就是佛弟子，马特斯、布伦赫尔兹都译作"佛教徒"；藏译 bder gshegs rnams 则读成"诸善逝"。偈颂用"善逝"二字，两种读法都可以包含。

三，"本然而生起"，梵文 prakṛtyājāta，按连声规则也可以拆成 prakṛtyā ajāta，即"自性无生"；但三家译本都读作 jāta（生起），藏译也作 skyes（生），今从之。这里的"本然"是修饰"生起"的，意思是缘起的显现本来如此，不是由分别后来造作出来的，而不是说有一个实体性的"自性"生出诸法。

四，"成立与遣除"，梵文 vidhi 与 apoha，藏文 sgrub 与 sel，指肯定地安立为有、否定地排除为无。对本然生起的诸法妄加有无的判定，正是下一颂所要对治的两种人。

## 第二颂

```
ཡོད་པར་སྨྲ་བ་ལ་བརྗོད་པ། །
ཐམས་ཅད་རྣམ་པར་དཔྱད་ན་མེད། །
མེད་པར་སྨྲ་བ་ལ་བརྗོད་པ། །
རྣམ་པར་དཔྱད་ན་ཐམས་ཅད་ཡོད། །
```

```
astīti vadato brūmo nāsti sarvaṃ vicārataḥ |
nāstīti vadato brūmaḥ sarvam asty avicārataḥ ||
```

白话：对说"有"的人，我们这样说：一经观察，一切都没有。对说"无"的人，我们这样说：不加观察，一切都是有的。

<div class="dt-verse">
若向执有者而言，<br>
一经观察一切无；<br>
若向执无者而言，<br>
不加观察一切有。
</div>

【按】一，末句藏文作 rnam par dpyad na thams cad yod，字面是"若观察，则一切有"，脱落了否定词。梵文作 avicārataḥ，即"不观察时"，马特斯、布伦赫尔兹都据梵文译作"不作观察时，一切皆有"。本站初版依藏文译作"若仔细观察，一切法都是有的"，并曲为之解，今据梵文改正。

二，这一颂并不是说"什么都没有"。以胜义的正理观察时，没有一法能经得起自性的分析，所以对执有者说"无"；不作这种胜义观察时，世俗中缘起的显现宛然成立，所以对执无者说"有"。说有、说无，都是随对方的执著而施设的对治，真性本身远离二边，与第一颂相应。

## 第三颂

```
ཇི་ལྟ་ཇི་ལྟར་སྒྲོ་བཏགས་པ། །
དེ་ཉིད་རྣལ་འབྱོར་པ་རྣམས་སྐྱེ། །
དེ་ལྟ་དེ་ལྟར་སྒྲོ་བཏགས་པ། །
རྣལ་འབྱོར་དེ་ཉིད་ཀྱིས་ནི་འཇོམས། །
```

```
yathā yathā samāropā jāyante tattvayoginaḥ |
tathā tathā samāropā hanyante tattvayoginā ||
```

白话：增益以怎样的方式在真实瑜伽士［心中］生起，增益就以同样的方式被真实瑜伽士摧破。

<div class="dt-verse">
增益随其如何起，<br>
起于真实瑜伽者；<br>
真实瑜伽即随彼，<br>
如其所起如是摧。
</div>

【按】一，"增益"（梵 samāropa，藏 sgro btags pa），指对本来没有的东西妄加安立，如把无自性的执为有自性。

二，第二句藏文 de nyid rnal 'byor pa rnams skye 最难解，本站初版曾列两读：de nyid 作"那同样的"，或作术语"真性"。梵文作 tattvayoginaḥ（属格）与 tattvayoginā（具格），tattva 即"真性、真实"，可知 de nyid 应读作"真实"，"真实瑜伽士"是一个词。整颂是一句话分作两半：前半说增益生起于真实瑜伽士，后半说增益被真实瑜伽士摧破。原文前两句只有"生起"一个动词，没有"了知"之类的意思，偈颂也不增补。

三，"以怎样的方式……就以同样的方式"，梵文是对称的 yathā yathā 与 tathā tathā，只说方式相应，并没有"在何处生起，就在何处摧破"的处所义。可以理解为：瑜伽不是在增益之外另造一个对治，而是增益怎样起，就怎样被看破；这是依句式的推想，原文没有展开，存疑。

## 第四颂

```
གང་ཕྱིར་ལྷན་ཅིག་སྐྱེས་མ་བཅོས། །
དེ་ཕྱིར་དོགས་མེད་ལྷན་ཅིག་སྐྱེས། །
བདེ་བས་ལྷན་ཅིག་སྐྱེས་གཞན་མིན། །
བདེ་བ་དོགས་པ་མེད་མཚན་ཉིད། །
```

```
sahajo ’kṛtrimo yasmāt tasmāt saṅgo na sāhajaḥ |
sukhaṃ na sahajād anyat sukhaṃ cāsaṅgalakṣaṇam ||
```

白话：因为俱生是不造作的，所以执著并不属于俱生。乐不在俱生之外；乐，以离开执著为它的体相。

<div class="dt-verse">
俱生本来非造作，<br>
是故执著非俱生；<br>
俱生之外无别乐，<br>
乐以离著为其相。
</div>

【按】一，"俱生"（梵 sahaja，藏 lhan cig skyes pa），指与心同时本有、不由修造而生的本性，在大手印中即指心的本来面目。

二，本颂及以下两颂反复出现的关键词，梵文作 saṅga（执著、黏著）与 asaṅga、niḥsaṅga（离执著），马特斯、布伦赫尔兹都译作 attachment（执著）。藏译则作 dogs pa med pa（无疑惧），当是译者所据梵本作 śaṅkā、niḥśaṅka（疑惧、无疑惧）；梵文写本中 s 与 ś 极易混淆，两种读法都有来历。德格本此字另有作 dog（狭窄）的异文，达夫即据以译作"无局限"。本站初版依藏文译作"无疑惧"，此次正文改依梵文作"离著"。"著"不只是贪欲，而是一切黏著、系著。

三，第二句梵文 saṅgo na sāhajaḥ 的主语是"执著"，意思是"执著不属于俱生"；藏译则作"俱生无著"。两说义理相通，但依梵文更能看出前两句的推理：俱生不造作，执著是造作出来的，所以执著不是俱生。

四，第四句梵文 asaṅgalakṣaṇa，是说乐以"离著"为其体相（lakṣaṇa），不是说"离著就是乐"。

五，"乐"在密乘中有特定的修持内涵，须依具德上师的灌顶与口授来理解，不可照字面揣度。"离著"是从"俱生不造作"推出来的：证悟了本来不造作的俱生，执著自然无从安立，而不是凭意志放下戒律、作无所顾忌之行。未证悟而自称"离著"，只是放逸而已。

## 第五颂

```
ཤེས་ཕྱིར་དོགས་པ་མེད་པའི་བདག །
དབྱེར་མེད་རྟོགས་པ་དམ་པ་བདེ། །
སྣ་ཚོགས་རང་རིག་རྟོགས་བྱས་པས། །
ལྷན་ཅིག་སྐྱེས་པའི་རྒྱ་མཚོར་ནུབ།
```

```
jñātvā niḥsaṅgatātmānaṃ nirvedhāgatasatsukham |
viśvaṃ svasamayaṃ kṛtvā magnaṃ sahajasāgare ||
```

白话：了知那以离执著为体性、由通达而得的真实之乐，使种种万象都成为自证，［万象］便没入俱生的大海之中。

<div class="dt-verse">
了知离著为体性，<br>
通达所得真实乐；<br>
万象悉成自证知，<br>
没入俱生大海中。
</div>

【按】一，第二句梵文 nirvedhāgatasatsukham，nirvedha 是"通达、洞见"，全语意思是"由通达而得的真实之乐"，马特斯译作"与证悟相应的真实之乐"，布伦赫尔兹译作"洞见的真实之乐"。藏译作 dbyer med rtogs pa dam pa bde（无别之证悟、殊胜之乐），dbyer med（无别）当是译者读作 nirbheda 所致。本站初版依藏文译作"证悟无二无别，就是殊胜的大乐"，此次偈颂依梵文；若依藏文，此句可作"无别所证真实乐"，存疑。

二，依马特斯的读法，前两句是一句话：所了知的，正是这由通达而得的真实之乐，而此乐以离执著为体性。藏文 bdag 在这里不是指"我"，而是本性、体性。

三，第三句梵文 svasamayaṃ kṛtvā，马特斯译作"转为自证悟"；藏译作 rang rig rtogs byas，即"证为自证"。"自证"（rang rig）指心自明自知，不是"自现"（rang snang）。说万象都成为自证，是说种种显现并不是心外的境，而是心的自明，由此不再有能取所取的对立。

四，第四句的主语，梵文 magnam 在语法上可与 viśvam（万象）相配，马特斯即读作"万象没入俱生之海"；布伦赫尔兹则补出"瑜伽士没入"。白话依梵文语法补"万象"，偈颂不出主语，两读都可容纳。

## 第六颂

```
སྔགས་ཀྱི་དེ་ཉིད་རྣལ་འབྱོར་པས། །
དོགས་མེད་དོན་ལ་རབ་ཏུ་གནས། །
སྲིད་པ་ཡང་འདི་བླ་མར་བྱས། །
དོགས་པ་མེད་པའི་ཡུལ་གྱིས་སྟོན། །
```

```
mantratattvasthito yogī niḥsaṅgārthapratiṣṭhitaḥ |
bhāvāṃś cāsau gurūn kṛtvā niḥsaṅgaviṣayo bhavet ||
```

白话：安住于密咒真性的瑜伽士，稳固地安立于离执著的义理之中；他把诸有、一切事物都当作上师，于是对一切境界都无所执著。

<div class="dt-verse">
密咒真实瑜伽士，<br>
安住离著之义中；<br>
诸有万象皆为师，<br>
所对诸境悉离著。
</div>

【按】一，第三句梵文 bhāvān，是长音的 bhāva，意思是"诸法、诸事物"，马特斯译作"诸存在因素"；藏译作 srid pa（有、三有），当是读成了短音的 bhava。偈颂作"诸有万象"，兼顾两读。

二，"当作上师"，梵文 gurūn kṛtvā，藏文 bla mar byas。guru 一词也有"尊重、殊胜"的意思，本站初版曾列"使之成为殊胜"一读；今依马特斯、布伦赫尔兹，取"作为上师"。

三，第四句梵文 niḥsaṅgaviṣayo bhavet，意思是"他将成为于境离著者"，马特斯译作"他将于诸境无所执著"，动词是"成为"。本篇所据德格底本作 yul gyis ston（以境开示），另有传本作 yul 'di ston（开显此境），本站初版依藏文译作"以无疑惧的境界来开示"；今依梵文改正。

四，这一颂的要点是：轮回的显现不必舍弃，对证悟者而言，诸有本身就成了开示离著实相的上师。这是证悟者的境界。修行人不可在未证之时，借口"诸有即上师""一切离著"而放逸，第四颂的按语已经说明。

## 跋

《俱生六颂》，上师梅纪巴所造，圆满。

上师金刚手与粗敦译出。

【按】"梅纪巴"，藏文作 mai tri pa。梵本题记称作者为班智达、出家行者吉祥无二金刚（Advayavajra）。"粗敦"，藏文作 mtshur，一般认为就是与金刚手合译梅纪巴多部著作的粗敦·智慧源（mtshur ston ye shes 'byung gnas）。

## 通篇连读

敬礼持金刚！

决定远离常边与断边的真性，是善逝之教的追随者所承许的；对于本然而生起的诸法，妄加成立或遣除，那是愚夫的言论。

对说"有"的人，我们就说：一经观察，一切都没有；对说"无"的人，我们就说：不加观察，一切都是有的。

增益以怎样的方式在真实瑜伽士心中生起，增益就以同样的方式被真实瑜伽士摧破。

因为俱生不造作，所以执著不属于俱生；乐不在俱生之外，乐以离开执著为体相。

了知那以离执著为体性、由通达而得的真实之乐，使种种万象都成为自证，万象便没入俱生的大海。

安住于密咒真性的瑜伽士，稳固地安立于离执著的义理之中；他把诸有都当作上师，于是对一切境界都无所执著。

《俱生六颂》，上师梅纪巴造，圆满。上师金刚手与粗敦译出。
