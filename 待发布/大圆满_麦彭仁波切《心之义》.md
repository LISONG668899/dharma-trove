# 心之义

麦彭仁波切 造

顶礼上师文殊师利！

```
གཉུག་མའི་ཤེས་པ་རྒྱ་ཡན་བཟོ་མེད་འདི། །
ཚིག་གིས་མི་མཚོན་སོ་སོ་རང་གིས་རིག །
```

此本然之觉性，坦荡开阔、离于造作，非言语所能诠表，唯由各自内证而知。

```
བླ་མའི་བྱིན་རླབས་ཞུགས་ཚེ་འབད་མེད་རྟོགས། །
འདི་དོན་ནམ་མཐོང་མ་བཅོས་སྐྱོང་ཚུལ་ཤེས། །
```

当上师之加持融入之时，证悟便任运而生、无需勤作；一旦照见此义，便自然知晓如何以不加造作之方式加以护持。

```
རང་སེམས་སྐྱོང་ངོ་སྙམ་དུ་བསྐྱང་མི་བྱ། །
མི་སྐྱོང་སྙམ་དུའང་སེམས་པར་མི་བྱ་སྟེ། །
རང་སར་ཅོག་གེ་ཞོག་དང་ངང་གིས་གསལ། །
```

不应作"我要护持自心"之念而加以护持，亦不应作"我不护持"之念；只需任其自然安住于本位，自会澄明朗现。

```
རང་བབ་རང་གནས་རྣལ་འབྱོར་སྒོམ་པའི་མཆོག །
```

任运自住之瑜伽，乃修持之最上者。

```
དེ་ལ་གོམས་ནས་བྱར་མེད་གཉུག་མའི་ངང་། །
སྣ་ཚོགས་རྟོག་པ་ཕན་གནོད་མེད་པར་ནི། །
ནམ་མཁའི་ངང་ན་སྤྲིན་བཞིན་རྒྱུ་བའི་ཚེ། །
```

于此串习之后，在无所作之本然境界中，种种分别念，皆无利无害，犹如浮云飘行于虚空之中一般。

```
བག་ཡངས་བདེ་བའི་རྣལ་འབྱོར་ཨ་ལ་ལ། །
```

此乃坦然安乐之瑜伽——啊拉拉！

```
གནད་ཀྱི་མན་ངག་སྙིང་གི་བུ་ལ་གདམས། །
```

此中要害之窍诀，传授予吾心子。

于火猴年二月十九日，修法座间，文殊金刚书写而成。吉祥圆满！

---

## 译者说明

本篇依藏文原颂重新译出。"ཨ་ལ་ལ"为藏文中表欢喜、赞叹之语气词，无实际词义，故依其声、其情，译为"啊拉拉"，以存原颂咏叹之神韵。"རང་བབ་རང་གནས"（任运自住）与"བྱར་མེད"（无所作）为大圆满见地中常见用语，指心不假造作、任运安住于本然状态，故依此惯例译出。
