# 《无尽宝藏圆满之歌·本然真如极明示广释》（上）

无二金刚（梅纪巴）造　般若室利智称 译藏　据藏文译出

## 题解

本篇藏译收于德格版丹珠尔续部释 ཝི 函第 207b1 至 265a1 页（东北目录 D2257）。作者在造论偈中自称"梅纪"（mai tri），即印度大手印传承的梅纪巴（Maitrīpa），署名无二金刚（Advayavajra）；德格本正文末只有造者跋，没有译者跋；德格版丹珠尔目录（388a）记载本论由印度瑜伽士、乞食者般若室利智称（Prajñāśrījñānakīrti）自译为藏文。跋文称作者是"以通达大瑜伽自在者吉祥萨惹哈巴之密意而著称的吉祥无二金刚"。

本论所释的根本颂，是一部名为《无尽宝藏圆满之歌》的道歌。它与萨惹哈的"王后道歌"（D2264）有不少相同的词句，但整体并不是同一部作品：王后道歌三百二十余句中，只有极少数完整地出现在本论里。所以本论不能看作王后道歌的注释，而是同一教法系统中另一部道歌的广释。释论说，这部道歌是"至尊吉祥山者"把亲自证悟之义唱成的歌，梅纪巴从那里得到了这些义理。

本论的解释体系，以"平常心"（tha mal shes pa）贯穿始终：一切显现本是法身，平常心由上师的恩德而得证悟，不由勤作修成。释论屡引《极无住续》《不可思议续》两部续典为证，并大量使用空行母的表示语、"蔑戾车语"等密码音节。

体例：本论先引一偈根本颂，再逐词解释，小节标题注明是根本颂第几偈，根本颂文句以引号标出。空行表示语、蔑戾车语等密码音节不作翻译，照录藏文于代码块中，后接释论自己的解释。原文的讹误、脱漏、文意不明之处，以"【按】"说明，依上下文所作的校改也在【按】中交代，不妄补内容。

全论结构：开头是题名、造论偈、空行表示语与立宗；中间依次解释根本颂一百一十七偈（偈数是本译按释论引文的起止所编，并非原文所标）；最后是第七义之歌、回向与跋。

因篇幅较长，本译分为上、中、下三篇：上篇收题解、序分与根本颂第一至第二十七偈（破斥外道与诸乘的邪行，开示悲空双运）；中篇收第二十八至第八十偈（依止上师、修习方法、松缚与心性）；下篇收第八十一至第一百一十七偈，以及第七义之歌、回向与跋。

## 题名与礼敬

梵语题名：Dohānidhikoṣa-gīti-nāma-paripūrṇa……ṭīkā。藏语题名：名为《无尽宝藏圆满之歌》的、极明示本然真如的广释。

【按】梵语题名电子本作 do ha ni dhi ko ṣa gīti nā ma ba ri pū ra pra śā sta ma ni ti yo ṭī kā，后半错乱，大致可以辨出 paripūrṇa（圆满）与 ṭīkā（释）两个词，其余今不强行还原。

敬礼世尊文殊语自在胜士！敬礼诸位殊胜上师！

## 造论偈

诸位胜士证悟真如的体性，以般若之剑斩断烦恼的至尊，开示那殊胜胜士之真如的上师——我以不可思议之义如实赞叹他们之后，［宣说如下］。

那由佛自身使人证悟佛的吉祥体性，也就是这未被认识的本然体性——平常心，梅纪依照诸位圣者口诀的如实之义，为了斩断"差别"的分别，宣说了平等性。

【按】"梅纪"，原文 mai tri，即作者梅纪巴（Maitrīpa）的自称。"平常心"，原文 tha mal shes pa，是噶举大手印的核心术语。

## 一、至尊吉祥山者之歌

关于法身与其密意无二无别，至尊吉祥山者把他亲自证悟之义唱成了歌；这些不可思议的义理，我已经彻底获得了。

【按】"至尊吉祥山者"，原文 rje btsun pa dpal gyi ri bo，指居于吉祥山（Śrīparvata）的上师。传统上，萨惹哈晚年隐居吉祥山，并在那里教授夏瓦日巴；梅纪巴则在吉祥山一带从夏瓦日巴得法。此处所指，可能是萨惹哈，也可能是梅纪巴的根本上师夏瓦日巴，今不作判定，直译为"吉祥山者"。

## 二、空行哑语及其义

又因为这义理不能借推理而获得，空行母们便说了"哑语"：

```
དུ་མ་མི་ལི།
```

它的意思是：外道的声量与诸量，现量、比量这些推理之矛，乃至上等的智慧与微细的神通，都不能证悟它——这就是口诀。

【按】"诸量"，原文 tshad med（无量），从上下文"现量、比量"看，应为 tshad ma（量）之误，依此翻译。

所以又说：

```
ཏུག་ཀན་ཙམ་ན།
```

它的意思是：所生非生而能生，所取无取而得取，所说非说、无言之表示；它不是"义"，不是"无义"，也不是"非无义"。这是从上师的言语中决定获得之义。

【按】末句原文 don min med don med min no，句读不太确定，今按四句否定的格式翻译，存疑。

所以又说：

```
ཧི་མ་ཧཱུཾ་མཾ་ས་ར་ཧཱུཾ་ཧོ།
```

它的意思是：斩下头颅，抛向虚空；以内脏之聚设宴；把脚底与头顶弯合在一起；转动脐轮——这是"决定结合"之分。

【按】这一组都是表示语，字面上是尸林瑜伽或气脉修法的意象，具体所指原文没有进一步解释，今只译字面。

所以又说：

```
རྟག་ལ་ལ་ཨ་རི་ཏ།
```

它的意思是：因为它不成立，所以示以梦；因为它是传承，所以唱成歌；因为它是秘密，所以用空行语；因为它是口诀，所以应当修持——这是"安住"之支分。

所以又说：

```
ཨེ་ཀྲ་ན།
```

关于那些无生者，［它的意思是］：从无生虚空中融入而现起；他续是果之明点；声音示现大时与变时；婆罗门在外道林中［如是说］——这应当用于具闻者。

【按】这一偈极为隐晦，"他续是果之明点"（rgyud gzhan 'bras bu'i thig pa）、"声音示现大时与变时"等句，所指不明，今只照字面翻译，存疑。

所以又说：

```
ཧ་ཧི་ཏ་མ་ནི།
```

它的意思是：彰显他者之心要的殊胜，从贤善上师那里证悟它；［这是］修治于本然之行；在这里应当修持；果由此而生。这些都应当结合到所应理解的义理上。

所以又说：

```
མ་ཀི་ཤུ་ཀྵ་ན་རེ།
```

它的意思是：右非他，他亦非彼；左非为观察显明；彼真如非证真如；"非"者，非王之知——这是在说殊胜之义。

【按】这一偈全由否定句组成，文意极为隐晦，今只照字面翻译，存疑。

所以又说：

```
དོ་ཧ།
```

它的意思是：

```
ཨ་ཨི།  ཨེ་ཨུ།  ཨི་ཨ།  ལི་རི་ཨ།  ཨཽ་ལྀ།  ཨི་ཨ་ར།  ཨུ་ལྀ་ཨི།  ཨ་ར།  ཨ་ཨཾ་ཨའི།
```

自身所无，是 a i；与自身相具，是 e u；彼此二者都不言说，是 i a；体性，是 li ri a；断除他者，是 au ḷ；相之义，是 i a ra；示现处所的作用，是 u ḷ i；以体验而言，是 a ra；真如本身的言说，是 a aṃ ai。

这是空行母之声的第一义。

## 三、表示语的四种运用

把声音之词运用于"众多贤善"之义，就是：负着大重担而行走迅速；无所到达，就是初地；鼓动双翅，就是虚空之湖；在须弥山宝洲中安乐。

把声音之词运用于佛语，就是：趋入凶暴的摩竭鱼口中，住在龟的背上，大吞鱼的腹中，在日轮中极为美妙。

运用于教法之声，就是：被火烤干的甘露，饮尸林聚会中的骨［所盛之物］；大海之上的少女；国王持大地，是旃陀罗中最胜者。

由精通声音者所运用的，就是：脚底、头顶与心中平等；口与下门相连，是狗的食物；虫子携着火，是河流的相续；拍掌，是虚空之声。

【按】以上四组都是表示语的举例，各有字面意象，原文没有逐一解释其所指，今只照字面翻译，存疑。

## 四、共通的教法表示：题名之义

共通的教法运用是：

```
པར་སུ་ནི་གི་ཧི་ད་ཀོ་ཤ་བུ་ཧ་ས་ན་གི་ཏ་ན་མ།
```

【按】这一串音节，大致可以看出是本论梵语题名 Paripūrṇa……nidhi……dohā-koṣa……gīti-nāma 的打散重排，是以题名本身作为表示语。

它的意思是：

不尽、无尽、无有尽，是究竟金刚的自性；佛不是被分别为佛的，［证悟它］就像看见手中的宝珠。

善逝的显现是心的自性；宣说了义的，是我的心；能令人证悟的，是宝珠之所依；它又像种子由水而生。

从像旃陀罗一样［卑微者］的言说中，大宝珠来到了手中——诸位殊胜的佛陀如是宣说。

对虚空不说，也无可说；一切都是大法轮；大手印是本然之境。乐与离［戏］，是法身；明与无分别，是报身；显与空，是化身——这就是极安住于本性之道。

虽然说了，却无所成立，就像梦中的财宝一样。这远离相状的金刚歌，应当从上师口中决定领受。

【按】"乐与离［戏］"，原文 bde dang bral ba，字面是"离乐"。与后两句"明与无分别""显与空"都是二者并举的句式相对照，这里应当也是两项并举，所以今译作"乐与离［戏］"，存疑。

所以又说：

```
ཨ་ཨི་ཨུ་ཨེ་ར་ལི་ཨོ།
```

它的意思是：第一，以善妙殊胜为力；第二，应当唱成歌；第三，相等；第四，受用；第五，能成就；第六，真如；第七，安住；第八，戏论。

【按】这里表示语只有七个音节，解释却列了八项，可能有脱漏，存疑。

## 五、表示之义唯少数人能知

所以，这些表示之义，只有至尊吉祥山者、我，以及与我和我的支分相连的人，才能证悟。

为什么呢？因为空行母拉玛（Lāmā）与杜玛迪日尼，是如来的化身；康卡、拙火母、亥母、起尸母、怖面母，是诸位大圣女之母；堪杂罗希（Khaṇḍarohā）与贝达里（Vetālī），是至尊的母亲；金刚勇母苏卡·玛哈悉地（Sukha Mahāsiddhi），是加持我的母亲——因为她们与其他人没有关联。

不仅如此，我住在大圣地的时候，准提母（Cundā）、胜力母、白母、屠女，为我示现了"味"之表示。在如来出生的殊胜处所，在嘿汝嘎［圣地］，尸林母、大瑜伽母、大鼻母示现了"福德轮"之表示。在金刚尊母面前，地下母、跳跃母、禁行母与行持游行者们，也示现了"孩童"之表示。

【按】以上诸空行母的名号，凡能考订梵名的附于括号中，其余依藏文意译，未必准确。"嘿汝嘎［圣地］"，原文只作 he ru ka，从上下文"殊胜处所"看，应当是指地名，今补"圣地"二字。

所以，瑜伽士们应当善巧于表示之义。这些的意义，我用蔑戾车语说出来：

```
ཧོ་ས་ར་ན་ཨ་ས་ར་ན། ཨེ་ཏ་ཨ་ས་ར། ཧེ་དུས་བུ་ལ། ཨ་ཏ་ཀ་ཏ། མུ་ལུ་ས། ལ་ཧི། མུ་ས་རས་ཏྲིས། ཏྲ་ས་ར། ཨཾ་ཙ་པ་མ། ཨ་ཙ་བ་ཨ་ཨ་ཏི་མ། ཨ་ཨི་སུ་མིག །པོ་ལི། ཀའི་སྣིག །ཤ་ཧོ་ས་ར། ཀི་པི་ཙ་ཏ། ཡོ་པི། ཙན་ཧེ་ཏྲན། ཧེ་ཧོ་མ་ཧེ། ཧི་མ་རི། ཏ་མ་བེ། ཨ་སིག །མ་ལ་པོ་ཡ་ཧ། པོ་ཡིན་ལ། ཧ་ཧི་ཧོ། །ཨེ་ན་ས་སུ་ག་དོ་ཡི་ལ། དོ་པ་ན། རུ་མིག་ས་ར། ཧ་ཧི་ཧོ། །ཨི་བ་ཏ་ན་ཧ་ཧི་ཨི་པ་ན་ཧ། པོ་ཙ་ན་ཏོ་ཡ་ལི། དུ་མ་ཧོ་འོ་ལོ་ཙན་དོ། སྨྲི་རི་སུ་པ་རི། །སྨྲི་རི་ཀའི་ལ། ཙན་དོ་པ་ཡི་ལ། ད་ཀི་ས་ཕེཾ་ཕེཾ་ཕེཾ་ཧ་ཧ་ཧོ།
```

这里所说的，全都是诸有之轮的表示。至尊安住于平等之中，［其义］唯有我一人知晓。

【按】"蔑戾车语"，原文 kla klo'i skad，即"边地语、化外之语"。这一大段音节中，有些可以看出是阿波布朗舍语一类的道歌句子，比如 sa ra ha、do（dohā）等，但电子本已经无法可靠还原，今照录原文，不作翻译。

## 六、略说之方式

略说的方式是：

第一，即是寂静；那些是"具"；大种；加持；伏藏；四；清净；贤善之行；正行；大；力；尊胜；手印；入定；光明；大乐；反转之加行；现前；五；三；一；一切；一切无；所取；无所取；一切；同时；阶梯；善；极善；言说；名言；轮；豺狼；庄严；身之轮；语之轮；意之轮；平等性之轮。

由此，表示之义便分解开来了。

【按】这一串只是一个个单词的罗列，大概是全论纲要的关键词或表示语的分类，原文没有进一步说明，今照录翻译，不作解释。

## 七、立宗：此义离戏，唯依圣者口诀

又，诸位至尊吉祥山者以大悲心所发起、所分解的佛智行境之义，我将依照这些［义理］，以解开并阐明的方式来宣说。

首先，以心要的实义，就相状的差别抉择真实义，对如此的真如表达不可思议的供养，然后立誓宣说。这些义理，远离有戏论的名言。为什么呢？因为这些是大瑜伽自在者所证悟的义理。

《极无住续》中说："诸位大自在者所体验的这个，是圣者们的口诀。"所以，能使人决定了知这些义理的，是开示远离能诠之无二的教言、从圣者证悟中流出的口中甘露，以及证悟心性为大不可思议的身体，而不是依赖于各种不同的经卷。

【按】"《极无住续》"（rab tu mi gnas pa'i rgyud）与下文的"《不可思议续》"（bsam gyis mi khyab pa'i rgyud），都不是常见的藏译续典题名，可能是今已不存的续典，也可能是印度大手印传承中对某些续典的别称，今照字面翻译。

该续又说："这是极为结合无二的教言，诸圣者所贯穿的言语；那不可思议的心之广界，是诸位大自在者的根本。"所以，应当体验这一义理，把一切都结合到大乐的明觉之中。

该续又说："瑜伽之明是大明，自在之明无有上；体验是义理之主，一切结合于大乐。"

所以，口诀的滴露融入心中莲花的花蕊，便自然生起光明；由此，一切分别的束缚都会自然解脱。

《不可思议续》中说："心中莲花的平常心，被平等性的汁液所遍满；如果心的蜜蜂去吮吸它，那就是法性无造作的大乐之身。"又说："平常心从内斩断增益；［其实］无可斩断，［它就是］法界的大轮。"

所以，应当了知一切显现都是法身本然的体性，在一切时中，唯独观看大手印。

《极无住续》中说："显有即是大手印，大乐即是普贤；这是心的轮，瑜伽自在者应当观看它。"所以，在一切时中，都应当以俱生无二智慧的方式去行持。

该续又说："不观为自，亦非为他，也不观为二者；俱生的智慧，是无二的大行。"所以，那些法身不应当到别处去观察，而应当就自心的本来面目去做。

又说："佛无所成立，所以不在他处观察；无所成立的心，就像金刚一样。它安住在一切众生的相续中，无所住，是大金刚心要。"

## 八、非勤作所成；一刹那成佛

所以，那些［功德］不是以勤作所修、所成就的；由于对本然而无颠倒的义理串习到究竟，此生便能出现所谓的"成佛"。

《不可思议续》中说："不是以勤作成就它；对所证悟的义理串习之时，此生便得到佛果——贤善的嘿汝嘎如是宣说。"所以，这些［修证的］时节，是就共通的方面来说的。

殊胜的意义是：这些平常心，由于殊胜上师的恩德，饮下甘露的汁液，证悟自己的真如，在一刹那间便现前圆满成佛。

《不可思议续》中说："证悟与串习的究竟，在这里并不存在；在证悟的那一刹那，便决定安住于第十四地。"

【按】"第十四地"一说，与王后道歌第八段"证悟［心要］，便安住于第十四地"一句相合，可见本论与王后道歌属于同一个教法系统。

## 根本颂第一偈：礼敬与立誓

释论说：为了阐明这一义理，［根本颂］说：

"具一切而非一切，［二者］相具的俱生体性之吉祥，乐空无别之身——向本然之义顶礼之后，我把真如［示于］如我者，如我者再向他人开示真如；由表示而知、而体验，那不可言说之义，在这里宣说。"

【按】"不可言说"，原文 smar med，应为 smra med 之误。

这一偈的意义是：要说出诸位殊胜上师所教诫的那些义理。

"具一切"，指一切显现与声音之法。它们具有什么呢？具有心，也就是佛的体性。"非一切"，是说：对它所起的执著之识的一切分别，都不是它。"相具"，是说：心的本然体性无颠倒、清净，具足三时一切诸佛的三身与五智的体性。

"俱生"，指法身，［分为］显现俱生与心性俱生。所以，这些不是暂时的，而是从最初就在法身的体性上证悟而成为"吉祥"的。

【按】"法身"，原文电子本记有异文 gi su / kyi sku，作 kyi sku（法身）义长，今从之。

它们是大乐的自性，［分为］有漏之乐与无漏之乐；这些乐也都是从身与心生起的。对它们加以观察而没有迷乱，就是"空"。这样乐与空无别，就是法身；那平常心的体性不变，就是"殊胜"，就是"身"。

这就是心无造作的本然之义。就像把酥油放进酥油里、把水放进水里一样，把显现安放在心上，这些就是法界体性智。因为它安住于一切，而且具足义理，所以应当向它顶礼、敬拜。

"之后"一词，表示还有下文，意思是：要把上面所供赞的对象，不可思议地依照如实之义加以阐明。

"我"，是就名言之心而说的，指至尊本人。"真如"，是［上师］心中无二的智慧。第一个"如我者"，指一切显现与声音之法：它们被平常心本身所主宰，一切时中平等，不离于它。

那么，这个义理要向谁开示呢？就是第二个"如我者"：与至尊我相等的人，或者具足善缘、根器上等、对这无二之义信解趣入、由积聚资粮的力量而决定成就的人；向这样的"他人"，开示或宣说真如。

这些可以开示吗？不能。［所以］借 i du pa ka、ka la mu su ra、tsi trid ka ni ka、ni ba lo pi ka、ha sna na ma da ni ma da ra 等表示而使人了知，并在学人的心中，开示那无可体验的体验本身。这些体验，以及那不可言说、［本来］无有的义理，为了让思辨者明白，便以增益的方式加以宣说——这就是"在这里宣说"的意思。

【按】这里列出的 i du pa ka 等，也是表示语，原文没有解释其义，今照录不译。

那么，要怎样宣说呢？共有六个方面：排除颠倒的理解；心要之义的殊胜；依靠上师的开示而证悟；［说明这是］修治于本然之人的行境；修持它；开示生起果位的次第。

## 根本颂第二偈：远离诽谤者

首先，开示不要与不相合、颠倒的人交往。［根本颂说：］

"如毒蛇般无缘的人，对决定的圣人，以过失之垢加以染污，造作诽谤的言辞；具足一味的人，仅仅见到［他们］，就应当畏避。"

这一偈的意义是：这是针对那些持颠倒理解、被"差别"的浓厚习气所压的众生而说的。

"毒蛇"，是指有毒的蛇。男人和女人见了它就会恐惧，碰到它就会惊骇，被它舔、被它咬，就会肿胀而死。

这样无缘的人，会诽谤诸位大瑜伽自在者：见面时，带着嗔怒去看他们；同住时，对那些决定结合佛的本然体验、无欺之义的圣人，以分别的过失使人不能进入真如，使已经进入的人退转，并生起怀疑。他们以这些垢染加以染污，造作诽谤的言辞，说"这不是佛法，这不是导师的教法，圣者们没有这样教导过"。

对这样的人，具足乐空不可分之一味的殊胜之人，一见到这些不相合的人，就应当畏避。

诸位大瑜伽自在者，是把心性看作本然自性的；而那些体验与此不合之义的瑜伽士们，你们就到别处去吧！为什么呢？因为［他们］损害心，会使人体验并产生不能成熟［为道果］的东西。

【按】末句"不能成熟"，原文 rnam par smin pa ma yin pa，字面是"非异熟"，意思大概是：与他们交往，会使修行不能成熟，甚至招致障碍。今照字面翻译，存疑。

## 根本颂第三偈：婆罗门之行不能解脱

接下来开示：婆罗门的禁行不能使人解脱。［根本颂说：］

"迷于真如的外道，住于婆罗门之行，以四座时安住，读诵如幻的四吠陀，断除幻化之物，执持'生'之见。"

这一偈的意义是：开示离开了本然的梵行，不能使人解脱。

"真如"，指法性无造作、本然如实的本来面目。"迷于真如"的，是持叶外道。他们住于像婆罗门一样的行为中，常常勤于清洁和沐浴，佩戴梵线和 gundhe。

【按】"持叶外道"，原文 mu stegs lo ma can，大概指以树叶为衣、苦行林居的外道。gundhe 是何物，不详，存疑。

他们修行的次第，产生不了力量，也不可信赖，所以是"幻"。"明"（吠陀）能生出共通的成就，又分为男吠陀、女吠陀、中性吠陀与业吠陀，也就是 ba ra hi、ru na ha ta、ki hi na、bi ru ha na。由这些，可以成就地下成就、空行成就、眼药成就与捷足成就。

他们具足早晨、下午、黄昏、黎明这四座时的明咒，经过十一年之久，结金刚跏趺而读诵。如果出现幻化之物——男人、女人或者成群的畜生——便截断［与它们的］往来。

【按】"四吠陀"在这里被列为男、女、中性、业四种，各有一个音写名称，与一般所说的《梨俱》《娑摩》《夜柔》《阿闼婆》四吠陀不同，是本论特有的说法，今照原文翻译。"截断往来"，原文 'phro gcod，意思大概是截断与外物的接触，存疑。

"见"，是执持自在天［为造物主］。他们的主张是这样的：最初，虚空中有两个风的极微，由大自在天的悲心与众生宿业的力量而生起；二者相遇聚合，便生起了坚硬厚重的大风轮。在它上面，成就了两个地的极微，二者相遇聚合，便生起了大金地。在它上面，成就了两个水的极微，二者相遇聚合的那一刹那，便生起了大水轮。在它上面，成就了两个火的极微，二者相遇聚合的那一刹那，便成为大火卵。从中生出了名叫"结发祖父"的四面梵天，从他的四面，生出了胎生、湿生、卵生、化生［四类众生］。

以供养使他欢喜满意，便生起一切善妙与成就；不使他欢喜的人，无论怎样勤作，也不会成就——他们持的就是这样的邪见。

那么，他们是从什么根源上迷乱的呢？在婆罗奈斯的大城 li ga ta na，有一位生于婆罗门种姓、行梵行的瑜伽士，名叫 Siṅha pa na ha。他依据《文殊勇士明幢续》，近行事续与 kriyā 的禁行，修持的方式与那些续典并不相违。

【按】"事续与 kriyā"，原文 bya ba'i rgyud dang kri ya'i brtul zhugs，kriyā 就是"事"的梵语，二者重出，今照原文翻译。

那部经典中说："应当常行梵行，住于沐浴与清洁之中，断除肉、酒、蒜、葱；常行婆罗门之行，佩戴珍珠与水晶之线，同样缠绕头、足、腰与全身。本尊天女的明咒、法与明的念诵，具足梵行者，以四座时念诵十一［年］。结金刚跏趺，具足本尊之慢；舍弃言谈、嬉笑、散乱与作障碍之人，便必定成就。"

依据这些义理去修持，他便转生为长者"幢自在"，在那里具足一切受用；此后转生，可以见到他生为三十三天的天子"光幢炽燃"。

迷于此而成为持叶外道的，是一个名叫 Lo tan ta 的人。他近入这种禁行，凡与他同样行持的，都是他的追随者。

【按】依这段的说法，Siṅha pa na ha 依事续而修，得到人天善果，本身并非错误；后来的外道只是模仿其外在的禁行，失去了本然之义，才成了迷乱。下一偈的结构也是如此。"可以见到"，原文 mthong ngo，大概是作者自述以神通或传承所见，今照字面翻译。

## 根本颂第四偈：山林苦行者的火供

接下来开示：山林外道瑜伽士的行为不能使人解脱。［根本颂说：］

"猴之 la la 禁行者，以土、水、吉祥草与牛［五物］，作为座位、食物与沐浴之用；在旃檀木上点起火来，说是［天神的］蒸气而熏烤身体——作这种无意义的火供，只不过是让烟伤害眼睛罢了。"

这一偈的意义是：开示迷乱的禁行者。

"猴"（spre），指山林中的恐怖之处；"'u"，指外道空行母聚集之地；"la la"，指追求邪定的人。"禁行"，是抑止平常的行为，而进入猛烈之势。

【按】这里《义灯》式的拆字解释，是把 spre'u（猴）拆成 spre 与 'u 两个音节分别作解，属于表示语的解读方法，未必是根本颂的字面义。

他们用沙土净化过的三堆土，洗身体的上部、下部和腰部；走进湖中，从头顶开始勤于沐浴；用牛的五种产物作曼荼罗，在上面铺好吉祥草，坐在上面；以吃过悦意香草的牛所产的五物为食物。他们又住在骨屋之中，一再勤修吉祥草之座、食用牛五物、以土与水洗浴。

到了中午，在用安息香熏过的旃檀木上点起火来，用许多布做的扇子把烟扇向南方。禁行者们露出身体，说"这是大自在天口中的气息"，用它来熏身体；等到身体的外面变得乌黑，便说："我的一切障碍都已净除，得到了法性不变的征兆。"这样作无意义的火供，只不过是让烟伤害眼睛罢了，与城里人生的火没有什么差别。

【按】根本颂中的"牛［五物］"，原文 pa yu，释论解释为"牛的五种产物"（ba'i rnam pa lnga），即印度宗教中所说的"牛五净"（pañcagavya：乳、酪、酥、尿、粪），今依此翻译。

那么，他们是从什么根源上迷乱的呢？有一位名叫帝洛巴的大瑜伽士，入于吉祥贤善嘿汝嘎的禁行，住在山林之中，也就是安住于那些处所的行为。那是什么样的行为呢？［经典中说：］

"欲求成就佛果的殊胜嘿汝嘎［行者］，在尸林寂静之处的殊胜地方，远离内外杂务与散乱，坐在青色吉祥草的座位上，以牛五物为食，在黎明时以土与水洗浴；在美好悦意的曼荼罗上，好好地铺开花鬘，好好地垒起白旃檀木，为了使善逝欢喜，常常献上火供。用 haṃ ti ta、木橘的心、ag ma ka、kre ya a ka ru 调和成的汁液涂抹身体。由此能迅速得到共通与殊胜的成就，而成为殊胜之人。"

依照这种方式安住的人，转生成为国王"力象"；在那里圆满积聚了资粮，可以见到他到无余蕴的持明之地，参加会供轮。

外道 La kin ti 迷于这些，进入了那种山林禁行；凡持守他们那种方式的，就是他和他的追随者。

【按】这里所说的"大瑜伽士帝洛巴"（rnal 'byor pa chen po te lo pa），与噶举派祖师帝洛巴同名。但文中说他依此修法转生为国王"力象"，这与噶举传统所述帝洛巴的生平不合，是否同一人，存疑。引文中的药物名称，haṃ ti ta、ag ma ka、kre ya a ka ru 不详，"木橘"原文 bil pa，即梵语 bilva，今照录。

## 根本颂第五偈：持猴禁行者

接下来开示：林中的外道不能解脱。［根本颂说：］

"持猴之禁行者，住在顶髻与两根木杖之上，以刺签之尖刺［身］，说'［血］流出就摧毁了烦恼'，以善具天之慢而住，［自以为与佛］现前之慢无有差别。"

这一偈的意义是：这是持林中外道禁行的人。"猴"，是借住在树梢者的样子来称呼他们。"禁行"，是抑止宽松自在，而进入依止痛苦的习气。

他们在林中把地面整平，在上面竖起 takṣana 木的大树干，用佉陀罗木十字相连，做成轮的形状，在两根木杖相连的两端安置四只"猴子"，然后住在它们上面。他们把极其锋利的刺签涂上油，好好磨利，为了让血流出来，用签尖刺遍所有的血脉，说："血和黄水流出来，我的烦恼就摧毁了。"每天都用佉陀罗木做的秤称量自己的身体。

就这样一路下去，他们以"我与大善具天毫无差别"的我慢而住；又以"我是一切果位的本体"的现前之慢，说自己与佛没有差别。

【按】"善具天"，原文 lha legs ldan chen po，藏文中 legs ldan 常指大黑天（Mahākāla）一系的护法，这里所指不能确定，今直译。"四只猴子"，原文 spre'u bzhi，从下文故事看，大概是指四位修此行的瑜伽士在世人眼中显现为猴的样子，存疑。

那么，他们是从什么根源上迷乱的呢？在南方的摩罗国，有一位瑜伽士，名叫 Dha sña ru pa，是阿阇黎董比嘿汝嘎的弟子，心安住于般若续。他对大王勇施说："大王，你应当专心投入密咒乘！为什么？因为此生就能具足大成就。"

国王说："山居者，你有什么能力？显给我看，再看我是否生起信心。"

瑜伽士说："大王，我进入这密咒乘还没有多久；虽然如此，我身上所有的血和黄水，都会变成乳汁。"

国王说："那我要看看。"

瑜伽士说："你大约二十天后来吧。"说完便到尸林去，为了不让虫蚁进入身上的血和黄水，坐在一个做好的木圈上，用刺签之尖刺穿身体，让血和黄水流出来，饮下了乳汁。

此后，四部的四位空行母守护这些瑜伽士，世间的人看见他们，便看成了四只猴子。然后，国王为了［验证］他们，把瑜伽士的身体砍成一段一段；虽然砍了，却没有流出血和黄水，而是滴出乳汁。

于是国王惊叹不已，皈依了这位瑜伽士，舍弃了整个王国，入于三摩地。此后，就在那一生中，生起了无量的共通成就。

外道 Ha la ka ga sha 看见了这些，便照着他们的样子去行持；凡是紧紧依从这种做法的，就是他和他的追随者。

【按】"董比嘿汝嘎"，原文 slob dpon ḍoṃ bi he ru ka，即印度大成就者 Ḍombi Heruka。"勇施"，原文 dpa' bas byin，今依字面意译。"饮下了乳汁"一句，原文 'o ma 'thungs so，意思大概是：他流出的已是乳汁，并以此为饮，存疑。"皈依了这位瑜伽士"，原文作 rnal 'byor pa bdag la（瑜伽士我），"我"字可能是指这位瑜伽士自己，今依上下文翻译。

## 根本颂第六偈：天鹅声游行者

接下来开示：行持的禁行不能使人解脱。［根本颂说：］

"以尸林天鹅之声游行，以此教示调伏他人、宣说法；对心要之义与其他［法］不加辨明；以这样的执著，众生成就的只是虚妄的解脱。"

这一偈的意义是：这是起尸外道的行持。他们在城中乞食游行的时候，用住在尸林中的天鹅的叫声"Kaṅkara！"来游行。

依照他们所欲的字义去分解："kaṃ"是禁行，"kara"是自在天之慢，"和"字是他们的供养。他们把这个意义开示给属于 Li ka ru 大供养的人们，使人进入外道的教法，调伏他人——这就是像上面那样"宣说法"。

他们说别人的［教法］"不是法，不是导师的教法"，对这些心要之义与内道佛法的其他教法，都不加辨明。

这样执著于"我"与"我所"的外道众生，不能生出真实的果；由于他们是在欺诳，所以成就的只是虚妄的解脱。

【按】"不加辨明"，原文 ma sel ba，sel 有"排除""辨明"二义，句意不太清楚，今取"不加辨明"，存疑。"Li ka ru 大供养"，大概是某种外道祭祀的名称，不详。

## 根本颂第七偈：作禅定状的外道

接下来开示：外道禅定的禁行不能使人解脱。［根本颂说：］

"作禅定之状的外道，用灰装满 gundhe 与 e re；睡觉时涂灰、解开发髻；乞食，以明点涂身，［发］束于顶；坐在洁净的毡上，作梵天之慢；以 e ran 之灯供养自在天；在边界抛施朵玛、摇铃；结跏趺坐，闭上眼睛，以无表示的言语行欺诳；开示无发、无饰的明妃；以颅器在尸林中灌顶；以上师之慢收取供养。"

这一偈是开示：外道的禁行，总的来说都不能使人解脱。

"禅定"，是佛密意的正体；没有证悟它的禅定，只是"作禅定之状"，也就是颠倒的证悟。

住于这种禅定的外道，把 gundhe 挂在肩上；焚烧婆罗门尸体所得的灰，叫做 e ri。这些外道把灰装满 gundhe，睡觉的时候也把灰涂在身上，把发髻从头顶解开，披在身上。他们在村落和一切尸林中乞食游行，用血和脂肪的点子画满全身。

他们把盘着蛇的发髻束在头顶；在用藤和竹子编的坐垫上画一匹马，弄得极其洁净，用旃檀、藏红花等香料熏过，坐在上面，面向东方，作四面梵天之慢。

"e ran"，是指有毒的蛇。他们用蛇的油脂在颅器中点灯，用它来供养石头做的大自在天像，也就是"诸有之面"的天神。在东方的边界，每天抛施十份朵玛；在尸林中的旧颅器上，用佉陀罗木汁画八瓣莲花，在中央写上"诸有之祖"，然后摇铃。

【按】"诸有之面的天神"，原文 lha srid pa'i gdong can，所指不明，存疑。"诸有之祖"（srid pa'i mes po），通常是梵天的称号。

他们结金刚跏趺，闭上眼睛，说"只要六识之聚还没有止息，就没有三摩地"，连耳朵也堵上。他们用"da ri ha"这类没有表示义的言语去对施主们施咒，行欺诳之事。

他们在无发、无饰的妻子额上画上"诸有之祖"，开示说"这些是密咒的明妃"，并说："我是远离贪欲的。为什么？你们看看这些明妃就知道了。"

他们在尸林的头骨上画大自在天的像，装进发网之中，到尸林里去，屠割青年男女的尸体来吃，又把那些头骨放在［人的］头上作灌顶，说："这些是诸大天神所赐的成就。"然后坐在高座上，说"我是你们的大上师"，以我慢收取弟子们献上的供养。

【按】"无发、无饰的明妃"，是模仿密续中"散发、无饰的明妃"之说，但把"散发"变成了"无发"，所以是有形无实的模仿。下文所引的续文可以对照。

这些人的迷乱根源是：有一位名叫 Danta kola 的大瑜伽士，安住于《大幻化》［续］的时候，依照那部续的方式修持。那部续中说：

"常住于尸林之中，具足嘿汝嘎之慢，向诸空行母施朵玛，呼唤'Kaṅkara'。以大勇士之慢，［穿戴］尸林装束、明点与头［饰］，把发髻束于头顶。常以香与灯供养，在尸林中施朵玛。对裸身、无饰、散发而具足相好的明妃，灌顶而生起大乐——这就是三有清净之义，是无尽庄严之轮。"

依照这些去行持的人，转生之后，生为瑜伽士 Śāntiṅ dharmaka；一切空行母为他灌顶，他能转动三有的一切轮。

裸体外道 Legs srung 看见了这些，便进入了这种禁行；与他相近相同的，就是他和他的追随者。

【按】《大幻化》，原文 sgyu 'phrul chen mo，即《大幻化续》（Mahāmāyā Tantra），属母续。"能转动三有的一切轮"，大概是说能自在调伏三有，存疑。

## 根本颂第八偈：长发长甲、裸身拔发者

接下来开示：与［密行］禁行相似的外道，也不能解脱。［根本颂说：］

"发与甲长，以垢涂身；不著衣服，拔除头发。"

这一偈的意义是：这是与密咒的行持相似的做法。他们留着很长的头发，用 klu shing 树花的汁涂在发根上，使它变成灰黄色，再用蛇把它束在头顶。他们的指甲也留得极长，身上涂着用 thang chu 与甘露调和的污垢。他们以裸身的方式而住，一直不著衣服；还把头发的边缘全都拔掉，说："我是远离贪欲的。"

【按】klu shing 是何种树，thang chu 是何物，均不详，今照录原文。"甘露"在密续中常是五甘露的隐语，此处所指不明。

那么，他们是从什么根源上迷乱的呢？在北方的芦苇林中，有一位名叫"大吉祥足"的瑜伽士，入于世尊喜金刚之慢，十九年中没有从一张树叶坐垫上起身；他的饮食，是靠反转大小便的流向来维持的。

他以裸身的方式而住，头发和指甲都长得很长；垂在地上盘绕的发梢，甚至一段一段地断落了。

这时，天子们在空中以偈颂说道："具足胜士的勇士嘿汝嘎，至尊请起身，请从禅定中起来！为了积聚那些堕落的有业众生的资粮，请您前往三十三天，做转轮王。"说完，空中以无量的音乐迎接、瞻仰，然后他便去了。

名叫 Gdong pa U ri ta na 的人看见了这些，便追随他行持禁行；与他相近相同的，就是他和他的追随者。

【按】"大吉祥足"，原文 dpal gyi zhabs chen po，可能是某位成就者的尊称，不能确定所指，今直译。"反转大小便的流向"，原文 dri chen dang dri chu'i rgyun log pa，是指某种使排泄之流逆转的瑜伽，今照字面翻译。

## 根本颂第九偈：总破诸外道

所有这些，都是这样的方式。［根本颂说：］

"心意观想于虚空界；损害教法，示现道的形相；'我'欲求解脱，喜好解脱；安住于不当之忍；［自称］大乘之基地。"

这一偈的意义是：开示上述所有［外道］的共同特征。他们把意识指向虚空的边际，修习虚空；他们损害佛的教法，说"我是持佛教法的人"，使智慧狭小的凡夫进入他们示现为"道"之形相的东西。

他们全都只想自己解脱，只为了自己而喜好解脱。他们安住于那些勉强忍受、毫无意义的禁行，以及"虚空之心"中，［自称是］大乘行者的基地——一加观察，就只不过是一块土地罢了。

【按】末句是双关：根本颂说他们自称是"大乘之基地"（gzhi'i sa），释论把 sa 解作"土地"，意思是：所谓"基地"，一加观察，只是土而已。"不当之忍"，原文 gnas min bzod pa can，意思是勉强忍受那些不当忍受、毫无意义的苦行。

## 根本颂第十偈：狐狗禁行

接下来开示：狐与狗的禁行不能使人解脱。［根本颂说：］

"以裸身而住，如果以狐与狗的禁行就能解脱，那么尸林中的狗与狐，因为与你相同，也应当解脱。"

这一偈的意义是：外道们常常以裸身而住，把四肢撑在地上，以狐和狗的样子而住，以这种禁行去行持。这是不能解脱的。如果说这样能解脱，那么尸林中的狐与狗，因为与你们相同，也应当解脱了。

这些人的迷乱根源是：大瑜伽士 Prin ti ra 和他的妹妹两人，曾用腐臭的烟去熏如来佛像的眼前，又穿着鞋子走进寺庙，因此转生为尸林中的狐和野狗。他们转生之后，又生为空行母 Sug sme si la ha 与大瑜伽士"大顶尖者"两人。

名叫"无畏游行"的婆罗门看见了这些，便持守了他们的禁行；与此相同的，就是他和他的追随者。

【按】这一则的迷乱根源，与前几偈的格式不同：前几则所追溯的，都是依续典如法修持的瑜伽士；这一则追溯的，却是两人先造恶业堕为狐狗，后来再转生为瑜伽士。外道只看到他们曾经的狐狗之形，便模仿起来。"大顶尖者"，原文 tog rtse ba chen po，今直译。

## 根本颂第十一偈：少女装束的禁行

接下来开示：少女［装束］的禁行不能使人解脱。［根本颂说：］

"住在石板之上，以剃除体毛、扮作少年之态就能解脱的话，那么正值青春的年轻女子，出嫁之时剃除腰下之毛、拔除腋毛，也应当解脱了。"

这一偈的意义是：［这些人］坐在洁净的石板上，以谨慎的样子而住。他们住在王宫之中，剃除身上的毛，戴上头饰、身饰与肢饰，用少女的样子说话，还用拂尘为别人扇风。

如果这样就能解脱，那么国王、婆罗门、长者的女儿们，到了青春之年，用种种少女的饰物来打扮自己，被长者等人用珍宝和成群的牲畜聘娶，出嫁到夫家的时候，为了吉祥而剃除腰下的毛，为了吉祥而拔除腋下的毛，以谨慎的举止出行——她们也应当解脱了。

【按】"拔除腋毛"，根本颂原文作 mtshan spu（字面"阴毛"），释论解作 mchan khung gi spu（腋毛），今依释论。依下一偈释文所说的迷乱根源，这里批评的是男子模仿瑜伽士"以女子装束修行"，只学到外在的装扮，所以根本颂以新嫁娘的习俗来讥讽。

## 根本颂第十二偈：孔雀禁行

接下来开示：孔雀的禁行不能使人解脱。［根本颂说：］

"外道 Pantitapa 你，系上尾巴，显示美丽的姿态，说'对着太阳展开、回头观看，就会解脱'——这极不合理，［否则］孔雀、牦牛等也会解脱。"

这一偈的意义是：［这是］bu ra ka na ti。他们执著于颠倒之见，又示现有害的禁行，所以是外道。Pantitapa 是一个种姓的名称。"你"，是要被破斥的对象。

他们的做法是：在 nya kri ta ma ra 木上用雄黄画上图案，做成孔雀尾巴的形状，系在后门上，坐在平滑的木头上，向别人显示孔雀般美丽的姿态。他们说"对着太阳展开、向背后观看，就会解脱"——这极不合理；否则孔雀和牦牛等也和你们相同，也应当解脱了。

【按】bu ra ka na ti 是表示语还是某类外道的名称，不详。nya kri ta ma ra 木，可能是榕树（nyagrodha）的音讹，存疑。

他们的迷乱根源是：在东方名叫 Be ta la 的国度，有一位名叫"富力"的长者，他的妻子名叫"施光"，一次生下了两个儿子。他们请婆罗门相士看相，婆罗门问："这两个孩子出生时，有什么征兆？"回答说："和他们同时，有三器皿的 mu ru te 米自然盛满，又有两个月亮升起。"

于是婆罗门说："给哥哥取名叫 Sālutripa，把他送到尸林中的瑜伽士那里去；给弟弟取名叫 Candrajñāna，把他送到求学的地方去。"

后来就照这样送去了。那位瑜伽士［哥哥］以女子的装束而住，以无我母本尊之慢如此修习。［弟弟］成了大学者，为了从续典中提炼出毒的甘露［而修学］。［有人］说："住在孔雀装束中的人，城中的人们应当去看看。"于是人们去了：那位瑜伽士能以女子装束的身体宣说佛法，那位学者涂上毒的甘露，能够平息一切疾病。

大家都惊叹不已。婆罗门 Gaṅgātara 的两个儿子"象"与"象力"向他们请求［传法］，却没有得到允许。于是这二人自作主张，进入了外道的"少女禁行"与"孔雀禁行"。与他们相近相同的，就是他们和他们的追随者。

【按】这一段叙事有些地方主语不明，例如"住在孔雀装束中的人"究竟是兄弟中的哪一位，原文没有交代清楚。今依上下文补出"哥哥""弟弟"及"有人"等字，并用方括号标明。"毒的甘露"（dug gi bdud rtsi），指以毒为药的甘露丸一类。

## 根本颂第十三偈：站立禁行

接下来开示：站立的禁行不能使人解脱。［根本颂说：］

"好好地住在林中，如果站着吃［饭］就能解脱，那么马与象也应当解脱。"

这一偈的意义是：住在闭关处的外道们，走进极其茂密、荆棘粗大的林中，说："在我得到成就之前，愿我不从这里退回！"立下坚定的决心，所有的饮食都站着吃。别人对他说："善士，请坐下吧，我来供给你饮食。"他却说："与其坐享饮食、［安住于］舒适之中，不如站着、受苦而死。"

如果这样就能解脱，那么马、象、野牛与水牛等也都站着吃东西，因此也应当解脱了。

他们的迷乱根源是：大瑜伽士董比嘿汝嘎，在竹林中行了三年站立的禁行。有一次，他同时化现出整整一百个化身，在一切如来出生之处的所依前作供养，显现得令人惊叹。住在南方摩罗国的长者 Mahābala，于是进入了这种禁行的方式。与他相近相同的，就是他和他的追随者。

## 根本颂第十四偈：自称证得中观者

这些人的见解是什么样的呢？［根本颂说：］

"想要与这些行为相同的人，心意分别于虚空，说'证得了中观的胜义'；那些持箭阵锐兵的人，公然宣称'得不到解脱'。"

这一偈的意义是：上面所说的那些行为，他们的想法，就是像上面所说的"分别于虚空之心"。

他们说"中观的最胜义，我们已经证得了"，这叫做"a i"，就是与圣者没有关联的证悟。

那些"箭阵"，也就是手持"自性"［理路］之锐利兵器的人，公然宣称："法身与其他的解脱，都是得不到的。"

所以，他们只应当在这一义理上接受教导。

【按】"a i"，是本论开头"道歌"一词的表示语中出现过的音节，那里解释为"自身所无"，这里用来指"与圣者没有关联的证悟"。"自性的锐利兵器"，大概是指以"自性空"的推理去破斥一切，乃至连法身与解脱也一并否定的人，存疑。

## 根本颂第十五偈：总说邪苦行

这样，就把那些外道禁行不能解脱的种种颠倒理解，顺带排除了。接下来开示：以远离安乐的究竟苦行，得不到解脱。［根本颂说：］

"邪苦行使身体不安；以颠倒的心意，那不是真如。"

这一偈的意义是：凡是不具足这大乐本然体性的，都是住于邪苦行之中。这就是 ka kalpa sta ha dza na，意思是：以带有分别的束缚，得不到大乐。

为什么呢？因为一切果位中最殊胜的法身，本来就安住于大乐的自性之中，连一刹那也不住于痛苦的边际——这是就心性而说的。而这些苦行却使身体受煎熬；由于心依附于身，所以心中不会生起安乐。这等于在煎熬法身，使果位耗尽，所以叫做"邪苦行"。

"心意"，是以觉知之识去破斥所破、成立所立，这就是带有分别的识，也就是痛苦本身。为什么呢？因为轮回中的痛苦与缺乏安乐，都是从分别中生起的。这些有破有立的，就是"颠倒的心意"。

它们又为什么是颠倒的呢？因为它们没有证悟本然的真如。真如是一切戏论自然寂灭，连"真如"这个名言，也自然被截断了。

以上是总说。下面分别来说：智慧狭小的声闻乘人，住于斋戒等苦行之中，使身体不安。他们虽然知道补特伽罗是空的，却一定还在思维对法的我执；虽然知道所取没有自性，却不知道能取没有自性，主张识是常住的实体。以他们这种颠倒的心意，那不是真如，是不能证得的。

【按】这里对声闻乘见地的描述，相当于说他们只证人无我而未证法无我，并持"识实有"之见，与印度后期论典中批评有部、经部的说法一致。

《极无住续》中说："以颠倒的苦行束缚身体，被束缚的心便受煎熬；由此法身耗尽，不能证悟本然。"

至尊山居者也说："以观察的分别，不可能解开真实；安住于无分别的平常心，便是大乐。就像一个人去分别虚空的边际，这个边际，我是不知道的。"

所以，上面所说的那些人所能体验的，只不过是艰苦而已。

【按】"至尊山居者"，原文 rje btsun pa ri bo ba，与本论开头所说的"至尊吉祥山者"应是同一人。

## 根本颂第十六偈：声闻与独觉

那么，这些［声闻］住于什么样的行持方式呢？［根本颂说：］

"以身语之行为主；比丘、沙弥、优婆夷等，上座、执事、所推选者，［是教法之］基；离家而出家的方式；修学小乘经典；对四谛现前愚昧之心；十八部互不相合，舍弃他部；于补特伽罗无我，却于法住于我执；说识于三时为实有；以非择灭为究竟。经部即是独觉，对十二缘起的流转次第加以逆转，想以遮止它而得解脱。有人以大乘为因，以诸量详加观察，把识成立为极微尘——由此也不过是阿罗汉，并非其他。"

这一偈的意义是：智慧狭小的声闻，也把自己显示出来。

他们住于"断除七［不善］及其眷属"的学处中，以身的三种、语的四种行为为主，并以七众的方式而住，也就是：比丘、比丘尼、沙弥、沙弥尼、优婆塞、优婆夷、式叉摩那。他们聚集在一起，叫做"僧伽"，在园林精舍中，像各个团体一样共同行事。

他们共同的基础是：上座，就像商队的首领；执事，由言语柔和、熟悉次第的人担任；由聚集的僧伽所推选的，是寺内纠察，依照《宝聚》中所说的方式行事。"基"，是指作为教法的基础，或者作为三种律仪的基础。

【按】"宝聚"（rin po che'i phung po），可能指《宝积经》（Ratnakūṭa）或律部的某部经，不能确定。

那么，［出家］是怎样的呢？就像《幢顶经》中所说的：

"诸比丘！住在家中，是在受用痛苦之因。诸比丘！智慧在衰退，命根在断绝，寿命的诸行也必定会毁坏，为什么不以精进和坚固的信心去成就呢？人身极其难得，得到人身之后，在胜者的教法中出家，也很难得；如果被那些与解脱之义相违的东西所欺骗，你们就会受苦啊！"

"离开生命而死去，是容易的；破坏戒律，却不是这样。为什么呢？离开生命，只是这一生结束；而破坏戒律，在百千生中都会远离种姓、舍弃安乐，感受异熟的痛苦。"

"所以，诸比丘，不要住在家中！家，是烦恼的住处，是罪恶的罗网，是轮回的束缚，是一切无尽痛苦的来源。诸比丘，住在家中，就是智慧狭小，永远不能从轮回的牢狱中解脱。诸比丘，住在家中的人，会焚烧善的种子；［家］是捕捉的网罗，像鱼网，像泥沼，像敌人的兵器，像骑在发狂的大象上，像住在着火的房子里，像没有轮子的车，像 sikati 花，像坐在 khri mon 上，像被砍掉树顶的多罗树，像失去四肢的大力士，像被太阳晒焦的青芽。因为它充满过失，所以应当离家而出家。"

"诸比丘，我是一切两足者中最殊胜的；过去一切诸佛世尊，都始终不违越出家的戒律。所以，我已作所应作，诸漏已尽，烦恼已摧，重担已卸，已越过诸有的荒野，已随念自己的利益。"

【按】"幢顶经"（mdo rgyal mtshan gyi rtse mo），即《幢顶经》（Dhvajāgra-sūtra）。sikati 花、khri mon 不详，今照录原文。

追随这些而修学的，是圣者憍陈如、阿难、须菩提等人，他们都应当被视为化现的声闻。像他们那样行持的，是有学之人、预流者等，他们修学小乘的《广光经》《圣百业经》《导师 Kauśani 经》等。他们对苦、集、灭、道四谛，执为常住的迷乱，只不过是现前愚昧罢了，所行的唯有带分别的［法］。

【按】"《广光经》"（rgyas par 'od kyi mdo）、"《导师 Kauśani 经》"不详，今照字面翻译。"《圣百业经》"，即《业百》（Karmaśataka）。"执为常住的迷乱"，原文 rtag pa nyid kyi 'khrul pa，意思大概是把四谛执为实有不变，存疑。

"部"，是指保持比丘、沙弥身份的团体，以及由此分出的部派。分开来说，共有十八部，其中根本四部是：大众部、说一切有部、上座部、正量部。

第一部又分出：东山部、西山部、雪山部、说出世部、说常部。

第二部又分出：根本说一切有部、饮光部、化地部、法藏部、多闻部、赤衣部、分别说部。

第三部又分出：祇陀林寺部、无畏山寺部、大寺部。

第四部又分出：鸡胤部、护部、犊子部。

【按】这里十八部的分法，与藏传通行的"四根本部、十八部"之说大致相合。大众部下的"说常部"（rtag par smra ba），通行的名单作"说假部"（Prajñaptivāda），今照原文直译。"鸡胤部""护部"，原文作 sa sgrogs rigs pa、bsrung ba，依通行名单比对，大致相当于 Kaurukullaka 与 Āvantaka。

这些部派的行持之门互不相合，彼此破斥，舍弃他部。

他们的见解，分为声闻毗婆沙宗与经部二者，基础相同：由于知道所取没有自性，所以证悟补特伽罗无我；但由于能取还作为自性而存在，所以仍住于对法的我执。

他们还主张，过去、未来、现在三时所积聚的物质，成立为极微尘：它们像 nyes'u gsing 和牦牛尾一样，零散而有间隙，被聚集之风所聚拢，以障碍的性质而存在；或者说，它们成为团块，彼此之间没有间隙，却又互不接触。

他们又说：显现的色之基、主体的心之基、眷属的心所之基，是世俗谛；而不相应［行］之基与法性无为之基，则说为非择灭，把真如与虚空作为究竟。

【按】nyes'u gsing 不详，可能是某种草。"有间隙""无间隙而不接触"，是有部与经部关于极微是否相触的两种说法。

其中，根器锐利的声闻经部，就是独觉。他们认为：轮回从十二缘起之因中生起，对这些在身上加以遮止、逆转，以遮止它，便能得到不共的解脱之果。

有些人——中观毗婆沙宗——说：以大乘为因，便能得到像这样的果。他们成立"基"与"圆满之基"，接受现量、比量、言语之兵器、论辩之兵器、根所生之量，以及由量所利益而成立、以随顺利益之声［所表达］的东西。他们以自己所愿的心智，把所观察的识成立为极微尘，对此深信并努力，但所得的阿罗汉果，不像刻在石头上的纹路，而像写在水上的字——所以说"不过是阿罗汉，并非其他"。

为什么呢？因为它离开了那不可思议的大乐。

【按】"中观毗婆沙宗"，原文 dbu ma pa bye brag tu smra ba，这个名称很少见，所指不明，可能是指以有部式极微论来解释中观的某一派，存疑。这一段列举的各种"量"与"兵器"，原文句读不太清楚，今照字面翻译。

## 根本颂第十七偈：只作观想的密咒行者

接下来开示：密咒的瑜伽士们也得不到解脱。［根本颂说：］

"思辨而智慧狭小的人，经观察而修本尊坛城，像外道之'我'一样，分别为'成就'；把瓶灌、密灌、智慧智灌，乃至究竟的口诀，只当作词句来诵读，离开了义理的形相；勤作而执著于轮回；分别空性如虚空，是在他处。"

这一偈的意义是：那些只执著遍计之物的识，被相状的思辨扰乱心意，所以是"智慧狭小"。那些极力想要成就的人，把自身观想为所依与能依的体性，去修本尊坛城，并且带着我慢说"已经成就"——这就像与外道的"我"没有差别一样，［他们］也是这样分别"成就"的。

这是由于不知道灌顶的本性而产生的。

瓶灌，是从无明的五种烦恼中逆转，生起明觉的五种智慧，也就是法界；他们却把它执为由此展开的分别。

密灌，是生起无漏的智慧，也就是菩提心；他们却把它执为趣入它的分别。

"智慧智"，是依靠智慧业印，体验俱生的智慧，也就是法身；他们却把它分别为对欲乐的执著。

究竟之义，是 prajñā a mu sna，意思是大般若，具足明、无分别、乐的自性，也就是本然的真如。他们却把这些口诀，只当作词句而已。

【按】prajñā a mu sna，可能是梵语 prajñā 加上某个讹变的词，不详。这里所说的三种灌顶，大致对应瓶灌、密灌、智慧智灌，第四灌则以"究竟口诀"来表示。

所以，他们离开了心的本然自性，也离开了体验它的方式。他们没有积聚资粮，也不亲近圣者；即使能够决断、安住于勇猛之中，由于没有离开"差别"的分别，所以仍在轮回中流转、执著。

他们的空性，就像世间人所见的一样，把它分别为在他处、如同虚空。为什么呢？因为他们没有在本然之中，饱足于大乐。

## 根本颂第十八偈：执空的中观者

接下来开示：中观者得不到解脱。［根本颂说：］

"有人以见缚于空性。"

这是说：他们执著于空性的无分别分，以执著的方式去看它，所以只不过是束缚。为什么呢？因为［真正的空性］是无可观看的。

它的意义，［根本颂］说："俱生的体性，是由证悟而现前成就的，是自身现前成就的。"

这些的意义是：ma ha ra na ka，就是心，是俱生的形相。pa na sa ka ri，就是"一"，是心的形相。a na as pu ta，就是从上师的口诀中所生的，是从最初就已成佛的体性。e i thar，就是分别；这就是平常心本身。e bud，就是分别之……；这是由体验而现前成就的，是从最初就已成佛的体性。e i at ma ki ti，就是在自身之中现前成就，这就是普贤。

所以，［它的］义理是殊胜的。

【按】这一段又是以表示语逐一解释，各音节与释义的对应关系原文已有，但表示语本身无法还原为可读的梵语，今照录。"e i thar 就是分别，这就是平常心本身"，前后似乎相反，可能是说"分别"的本质即是平常心，存疑。

## 根本颂第十九偈：观于他处、勤作于因者

其他的人则不具足这一点。是怎样的呢？［根本颂说：］

"观于他处，说'在因上好好勤作，就能得到涅槃'。"

这一偈的意义是：把果分别在他处，对见解抱着希望，所以是分别。他们主张分别是由证悟而成就的，说"在因上，也就是福德资粮上，好好勤作，分别就会穷尽，从而得到涅槃之义"——这仍然是分别。

以分别去［对治］分别，只会是欺诳，也就是轮回；而轮回又使分别［显得］不欺诳，这就是痛苦。

【按】末句原文 'khor ba nyid kyis rtog pa mi slu bar byed de sdug bsngal lo，意思大概是：轮回使人把分别执为真实可靠，由此便是痛苦，存疑。

## 根本颂第二十偈：善巧词句者

那么，应当观察这些是从哪里来的。［根本颂说：］

"对于言语与身的形相，看起来极为善巧；但因为另一者在他们那里没有形相，所以不能有力。"

这一偈的意义是：他们生起言语名言的分别，去分别那无边之物；他们抉择显现与声音之境的形相，去分别那没有意义的东西；对这些部分的形相，以"我极为善巧"而起我慢——这就是轮回。

为什么呢？他们看起来善巧，其实并不善巧。那像国王宝库一样的，是本性的如意宝珠；"另一者"在他们那里并不存在，它的形相也不存在——这就是 ka ka ra，意思是"不会沉没"。

这些人因为把迷乱当作观察的对象，所以不是真如。

【按】ka ka ra 的释义"不会沉没"（nub par mi 'gyur ba），与上下文的关联不清楚，存疑。"另一者"，大概指上一偈所说的、离开一切分别的本然体性。

## 根本颂第二十一偈：口诀为基

这一点的意义是：［根本颂说：］

"因为口诀成立于基，所以上者所说的方式，并非不合理。"

这一偈的意义是：u pa ha ra，意思是以体验而生起义理；gu ru u pa ri，就是口诀。依照殊胜上师的口诀去体验，就是法身。

这又是为什么呢？［因为它］可以是无因者与非男非女者的行境，具有分别观察的智慧，因与果同时，像河流一样安住；它从最初就已成佛，法身的本然自性安住于一切之中，一切都在大乐手印中同为一味，因与果同时，在一切时中都成立为"四"。

所以，is a ra，就是"上者"，也就是我。我说下面那些人得不到解脱，这种说法的方式并非不合理，而是合乎正理的。

【按】"非男非女者"，原文 ma ning，字面是"中性"。密续中常以"非男非女"喻指超越方便与般若二分的不二之境，这里或许是此义，存疑。"成立为'四'"，原文 bzhi ru grub pa，所指不明，可能是指四身或四喜，存疑。

所以，［这些人］都既离开了方便，也离开了般若，也就是说，他们没有平常心以及它的自性，所以得不到解脱。

## 根本颂第二十二偈：信解义理而欲以行持得果者

下面要说明这一点。［根本颂说：］

"如果有人信解义理，想以行持而得到果。"

这一偈的意义是："有人"，是指某种推理。他们对所谓的"胜义见"信解、趣入，乃至执著；为了成就它，又想以梵行得到殊胜之果，所以只不过是有破有立而已，那并不是真如。

## 根本颂第二十三偈：证无二者不需外在仪轨

［根本颂说：］

"如果有人离开了对无二的体验，那么佛语与下劣的禅定，因为没有必要，便应当排除。证悟了心要的最胜义时，灯与供食又有什么用？如果无二之中没有出定与入定，还作什么行持？不诵咒语。以业与作为为主，在阶梯边的水中沐浴，这本然的苦行又有什么用？如果与真如之义不相关联，以沐浴等是不能解脱的。"

【按】第一句"离开了对无二的体验"，依下面的释文，这里的"离开"不是"缺少"，而是"超越体验"的意思，也就是"无所体验的体验"。所以全句的意思是：对于已经证悟无二、超越体验的人，下面这些都不需要。

这一偈的意义是：对于安住于证悟心要之义的无二、没有出定与入定的人，这些行持自然就被遮止了，因为它们会以分别而束缚，所以开示它们不需要；同时也隐含地开示：即使去行持，也离开了那［真如］。

"有人"，是指作为所依的殊胜之人。"无二"，是指平常心本身。"体验"，是指明、无分别与乐；"离开"，是指无所体验的体验，也就是什么都不是。

对于具有这种体性的人来说，外道艰苦的禁行、下劣的声闻所具有的行持、见与修，以及唯识与中观带有破立的禅定，因为没有必要，都应当排除。当证悟了这最殊胜的心要之义时，分别便已逆转，佛也无需去成就，所以灯、花、香、涂香、供食等等，又有什么用呢？因为没有可以成就的东西。

如果不动摇于无二之境，出定与入定没有差别，那么布施等行持又能作什么呢？因为［对他而言］已无意义。也不诵咒语，因为果位是无可成就的。

以令上师欢喜等业、以会供等作为为主，坐在阶梯边的水中沐浴、行洁净之行，以及斋戒的苦行与种种难行，又有什么用呢？因为这些本身就会成为束缚。

但这并不像是刻意地斩断它们，而是它们自然止息；也不像是刻意地成立［不做］。所以，如果与真如之义不相关联，以上面所说的沐浴等行持是不能解脱的；而如果与之相关联，它们就会成为有意义的——这一点，应当从言外之意去了知。

【按】这一段要和下文合看，以免误解。释论明说，这些行持之所以"不需要"，是对已证无二、出入定无别的人而言，而且是"自然止息"，并非刻意舍弃；同时又明说，与真如相关联的行持是有意义的。下一偈紧接着就讨论尚未证悟的初学者应当怎样做。

## 根本颂第二十四偈：初学者在证悟之前不舍修持

那么，没有证悟、还有出定与入定、与义理不相关联的人，也应当这样做吗？［根本颂说：］

"初业之人，虽然能体验真如，在没有证悟之前，不舍弃它；如果证悟了，［它］就是本然之道。"

这一偈的意义是：那些福缘极佳的初业之人，由殊胜之人的口诀而得以亲近［真如］。他们体验真如的形相，虽然与真如并不分离，但在它还没有成为无二的广界之前，它还不是真如本身——所以，在没有证悟之前，不要舍弃它。

如果证悟了，那些福德资粮，也就是心之本然体性的平等大道。

【按】"不舍弃它"的"它"，依上一偈，是指布施、供养、诵咒、沐浴等修持。这一偈与上一偈合看，意思是：证悟无二的人，这些修持自然止息；尚未证悟的初学者，则不应舍弃，证悟之后它们本身也就成了本然之道。

## 根本颂第二十五偈：悲空双运

那么，这些［证悟］是从口诀的什么力量中生起的呢？是从般若与悲心双运之中生起的。下面开示：二者各自分开是不能成就的，必须是无二无别的体性。［根本颂说：］

"离开悲心的空性，不能证悟心要，现前舍弃了殊胜之道，必定住于声闻地。只修悲心的话，身心会受煎熬，与外道没有差别，应当知道这是魔业。具足殊胜之士，能够把二者结合起来，舍离轮回与涅槃，现前安住于无住之际。"

这一偈的意义是：离开悲心的空性，应当知道是魔业；离开空性的悲心，也应当知道是魔业；而这无二之义，应当知道就是佛的密意。

为了阐明这一点，世尊在《明示一切瑜伽士之业续》中说了这样一个故事：

在南方伊舍那国名叫"积塔"的城中，有一位婆罗门，名叫"贤宝"。他从别的国度，娶了一位名叫"善施花"的婆罗门女子为妻。这位年轻女子容貌端丽，见者喜爱，一切人都对她心生倾慕。她安住于清净行的律仪，专心于洁白的正法，对父母极为孝敬，照顾一切眷属与属民，对仆役怀着慈爱与大悲，像比丘一样行清净之行。

【按】"明示一切瑜伽士之业续"，原文 rnal 'byor pa thams cad kyi las nges par bstan pa'i rgyud，不详，今照字面翻译。

在一个吉祥之月的十四日，她到寺庙去作供养，见到了清净的殊胜比丘们，生起极大的信心，于是发愿说："愿我也生下殊胜的儿子，然后让他们出家，与教法之道相合。"

当天夜里，她在梦中梦见头顶上长出三把剑：一把剑落进了大深渊；一把剑被油浸过，失去了锋刃；另一把剑放出无量的光明，遍满整个虚空，化为鲜花，降下大雨，使一切众生都得到满足，并成熟为同一个果实。

第二天早晨，她起身沐浴，对婆罗门说："长者啊，请听我说。我在睡梦之中，头顶生出三把剑：左边的落进大深渊，右边的被油浸过、失去锋刃，中间的剑放出光明，遍满虚空，开满鲜花，降下雨流，使众生满足，成熟为同一个果实。这些是吉兆还是凶兆，我不知道，请你随宜为我解说。"

于是婆罗门对这位贤妻说："贤妻啊，你一向安住于清净行，这些殊妙的梦，不会是坏事。去问问别人吧。"于是从婆罗奈斯请来了一位名叫 Agaśatana 的婆罗门相士。

那位婆罗门说："清净的父母啊，请听我说。这些征兆，表示你们将生下三个儿子。其中一个执著于空性，会落进断灭的深渊；一个执著于悲心，会被悲心之油所煎熬，受到魔的加持；还有一个，会从般若与悲心无别之中，自然生起大光明。降下报身之花与化身之雨，这是法身之果将成就为一的征兆。这三人都会倾心于佛法，由于发愿与善知识的力量，事情就会这样发生。他们的名字，应当叫做'大力'、'悲力'与'无上力'。"

此后，依照次序，生下了三个具足相好的儿子。

长子长久依止瑜伽之道，向一位名叫"圣 Gayate"的［上师］请法。由于他执著于我见，［上师］便为他开示空性的真如，他因此对空性特别执著。由此，他得不到那不是轮回之乐的涅槃之乐，也不能成为得到它的因。

后来他住在竹林中，在瑜伽士聚会的时候，空行母"慧女"与"善施女"以偈颂说道："执著于空性的人，不能涅槃，也不能度脱；即使生于无色界，也是众生无义地堕入轮回。"此后，他死后转生，生于无色界。

次子向一位名叫"自聚"的瑜伽士请法，历经无量年。那位瑜伽士见他嗔心很重，便让他修悲心。他因此被悲心折磨得格外厉害，一见到众生就哭泣，以致精神错乱。

后来在瑜伽士聚会的时候，空行母"旃女"与"拉玛"在空中以偈颂说道："由于悲心太重，心意受煎熬；心虽然远离了恶趣之处，但因为受到魔的加持，死后［生为］他化自在天。"此后，他死后转生，生为魔王他化自在天。

幼子向一位名叫"有与"的瑜伽士请法，历经无量年。那位瑜伽士为他开示了般若与悲心双运之智慧的真如，他的体验便像初一的月亮渐渐增长到十五的满月一样。那些殊胜的上师们，在他心中好好地修治那"什么都不是"的空性，以及远离煎熬的悲心之相，并使他体验。

后来在瑜伽士聚会的时候，空行母"散陀希"与"近者"以偈颂说道："以般若与悲心双运，证悟就是涅槃；舍离轮回与涅槃，在无住之地现前成佛。"于是他入于无余依涅槃。

所以，善男子们应当长久依止殊胜的善知识，并开示方便与般若无二之义。

【按】故事中的人名，"圣 Gayate""自聚""有与"等，以及诸空行母的名号，原文多为音写或简称，今或照录、或依藏文意译，未必准确。

依照这部续，下面加以解说。

"悲心"，是没有嫉妒的善根，它的本质是希望一切众生远离痛苦，就像自己远离头痛时感到欣喜一样。

而远离安乐的空性，既不能成为大乘的善根，也不能证悟心要的法身；它现前舍弃了最殊胜的无二之道，必定住于一心趣向寂灭的声闻地。

只修离开空性的悲心，会出现身体发抖、汗毛竖立、头皮发麻等难以忍受的现象，所以身体受煎熬；由于身与心是相依而住的，所以心也受煎熬。因此，这与外在的外道没有差别；因为它会耗尽心中佛的体性，所以应当知道这是魔业。

那由福德之因所成就、具有殊胜上师的人，能以不作意的方式，把空性与悲心无别的二者结合起来，舍离对轮回的贪恋与对涅槃的执著：以般若不住于轮回，以悲心不住于涅槃，现前安住于平常心的边际，也就是佛的密意。

【按】"远离安乐的空性"，原文 bde ba dang bral ba'i stong pa nyid。本论一贯以"乐空无别"为法身，所以这里把偏空的过失说成"离乐之空"，与根本颂的"离悲之空"相对应。

## 根本颂第二十六偈：放下希惧勤作之心

所以，应当从这样的义理中接受教导。［根本颂说：］

"咳吙！说我执与邪执是虚妄；对［说它是］虚妄，也不要决定地执著；不作执著的分别，放下希望、疑惧与勤作之心。"

这一偈的意义是："咳吙"，是呼唤三界的一切众生，意思是要教导他们。

那么，教导的是什么呢？"我"，是执著于由"差别"的分别所遍计的自我；从执取这个"我"，便显现为轮回、成为痛苦，所以要放下它。

分别它的边际，就是"邪执"。由于它带有欺诳，不可信赖，所以要以离贪之心说它是"虚妄"。

又教导说：对"我已经离贪"这种遮止虚妄之义，也不要决定地执著。

那么，应当怎样安住呢？不作执著于差别的分别，而安住于本然之义、真如本身。放下那对果位抱着希望、对与轮回相等之义勤勉努力的心——这"什么都不是"、本然自在的心，才是最殊胜的。

【按】"对与轮回相等之义勤勉努力"，原文 'khor ba dang mnyam pa'i don la brtson par byas pa，所指不太清楚，大概是指以有为之心在轮回范围内的努力，存疑。

## 根本颂第二十七偈：证悟之后，一切皆是彼

这样开示了无二之义之后，下面说明：如果证悟了它，一切都是它的体性。［根本颂说：］

"证悟之后，一切都是它，除此之外，谁也不知道还有别的；诵读、受持、思维与修习，就是它本身；论典在心上讲解，决定领会；没有能表示'是'与'不是'的见解。"

这一偈的意义是：如果证悟了本然之义，一切显现与声音都是它的体性；在它之外的四边，即使是一切智者与至尊等，也无人能知。

《极无住续》中说："心性成为广界，就是普贤；体验那平常心本身；诸位圣者证悟它的时候，这就是嘿汝嘎，是一切的本然之境。"

所以，诵读、受持、思维、修习，一切都被视为它的分别显现，因为都没有超出它的体性。

该续又说："从虚空清净的体性中，虽然生起了云等暂时的垢染，它仍是那虚空，仍是虚空本身的境界。心性所安住的金刚智慧，虽然显现为种种，仍是本然的体性；虽然显现为种种不同的作为之门与形相，此外并没有别的义理。这就是本性，是大乐。"

所以，应当把一切都了知为真如的自性。

因此，以表示与名言，不能衡量、开示这些。这些从殊胜之法、诸圣者口中的甘露中流出来的［义理］，由于心什么都不是，所以是对那"什么都不是"的心去讲解，并使人在那里领会——这是决定的。

它的体性，不分别为"是"与"不是"，也没有能表示它的见解。所以，这些是不可衡量的，其中既没有"证悟"，也没有"未证悟"。

【按】"诵读、受持、思维、修习"，原文 klog 'dzin bsam dang sgom pa，指闻思修的种种学法。依释论，这一偈不是否定这些学法，而是说：证悟之后，它们都是真如的显现。
