# 飞锡《念佛三昧宝王论》卷下

唐代终南山紫阁峰草堂寺沙门飞锡撰。作者生平见卷上〈作者考据〉。卷下七门，念过去佛，并通念三世，无不是佛；末附北宋黄伯思跋文。

## 第十四门　念过去佛因果相同

问："念现在佛、专注一境的奥义，我已经听了。所念的佛，穷尽玄理，是极圣之人，尊称如来，自然可以；可是能念佛的人，刚刚窥见真门，还处在凡夫位上，怎能冒称与正觉相同呢？"

答："《观佛三昧海经》说：'所念的佛，如出胎的狮子王，比喻佛果；能念佛的人，如在胎中的狮子王，比喻佛子。'因与果虽然不同，威神却前后相续，就其为佛而论，又有什么不同呢？要让胎中的狮子立刻就能吼叫、飞跃、奔走、伏兽，那是没有的事；但出胎之后，就可以翘足而待，又缺少什么呢？这是因果相同的第一个意义。

"又《大法鼓经》说：'如波斯匿王与敌国作战，中了毒箭，痛苦难忍。听说有一种良药名叫消毒，国王把药涂在鼓上，用鼓槌敲击，鼓声一响，毒箭应声跳出，伤口平复如初。如果听到释迦牟尼佛的名号，以及听到相信方广经的比丘的名字，就能令身中贪、嗔、痴三毒之箭应声跳出。所以这部经名为大法鼓。'释迦，就是过去佛，是果；比丘，就是信方广经的人，是因。灭罪的功效相同，这是第二个意义。

"这两部经所说的人，虽然还没有登上极圣之位，听到他们的名字就能获益，与佛没有不同。所以《法华三昧师资传》第五卷中说：'隋朝南岳慧思大禅师有位弟子大善禅师，证得慈悲三昧。当时衡阳内史郑僧果，素来不深信佛法，有一次出外打猎，围住了几十头鹿，对县令陈正业说：你常称赞大善禅师有慈悲之力，对这些鹿又能怎样呢？正业就率领左右几个人，齐声称念：南无大善禅师！一声刚出，群鹿就腾空而出。'这与观世音菩萨的神力又有什么不同呢？大善禅师当时与智者大师齐名。

"如果不侮慢圣人的话，那么念佛三昧能殄灭魔障、止息灾难，就像金子在冶炉中一样确定无疑。怎能拖延日月而不修习呢？"

## 第十五门　无心念佛理事双修

问："圆满地念三世佛，或者专门面向一方念佛，这幽深的道理我已恭听了。但这些都是有念、有思，有生、有灭，怎能与《胜天王般若经》所说'以无所念心而修念佛'的宗旨相同呢？"

答："对于无念的说法，人们大多像站在岔路口哭泣，如果不仔细精研，恐怕会迷失道路。现在用理门、事门来分辨。

"先说理门，这是真无念。解释说：说有也好，说无也好，就是这一念，本来就无。为什么呢？佛从念生，心就是佛，就像刀不能自己割自己，手指不能自己触自己，佛不能自己成为佛的对象，心不能自己成为心的对象。怎能在佛外立一个心，在心外立一个佛呢？佛既然不是实有，心又怎么会是实有？无心念佛的意义就明白了。所以世人说念佛是有念，我却说念佛是无念，还有什么疑惑呢？

"又，念就是空，哪里有念？并不是灭了念才空，哪里有无念？念的本性自空，哪里有生灭？

"又，'无所念心'，就是《金刚经》所说的'应无所住'；'而修念佛'，就是'而生其心'。'无所念心'，就是《维摩经》所说的'从无住本'；'而修念佛'，就是'立一切法'。'无所念心'，是念即是空；'而修念佛'，是空即是念。空与念不相异，这就阐明了中道。

"双寂叫做止，双照叫做观，定慧不均等，就不是正受，哪里配得上三昧之名呢？现在照而常寂，就是无所念心；寂而常照，就是而修念佛。如来所证的寂照三摩地，就是念佛三昧的究竟地位。所以这三昧能生出首楞严王三昧、狮子吼定，这就明白了。

"如《菩萨念佛三昧经》中破相的偈子说：

```
念佛真金色，安住无著心，观法何名佛，摄心恒相续，
金色非如来，四阴亦如是，离色非如来，想识应当知。
此是佛世尊，最胜寂静处，善能灭一切，外道诸邪见，
如龙王降雨，泽及于一切。
```

大意是：念佛的真金色身，安住于无所执著的心；观察法中什么名为佛，摄心恒常相续不断。金色身不是如来，受想行识四阴也是如此；离开色身也不是如来，想与识也应当这样了知。这就是佛世尊最殊胜的寂静之处，能灭除一切外道邪见，就像龙王降雨，恩泽普及一切。

"这部经说明六度万行，没有一法不是念佛三昧。"

问："理门已经说完了，希望开示事门，使学人得到真无念，契合般若波罗蜜，开启无相大乘甚深禅定，不也很广博吗？"

答："理与事相距有多远呢？前面说明的是即事之理，现在说明即理之事。

"《大品般若经》说：'佛为钝根人说诸法空寂，因为他们一动就生起执见；为利根人说诸佛的相好，因为他们如莲花不染尘埃。'须菩提是小乘中解空第一的人，奉行无名无相；等到他蒙佛授记，将来成佛，佛号却叫'名相如来'。如果不是大乘，他常怕声、香、味、触得了方便，逃避都来不及，哪里敢在名相的园林中盘桓游赏呢？既然通达了名相，所以得到佛的授记。

"说到事门，佛从心生，般舟三昧就是无念而已；至极的境界从我而出，法华三昧不求快而自然到来。'无所念心'，是断绝种种乱想；'而修念佛'，是善于观想一尊佛。

"《文殊所说摩诃般若经》说：'如人学射箭，久练就巧，后来即使无心，箭发皆中。如果有人想入一行三昧，随佛所在的方向，专心称念佛的名字，念念相续，就在念中见到三世诸佛。就像那学射的人，练熟之后，无心也能射中。'这不正是无念吗？为什么呢？

"所以《方等经》说：'孜孜不倦地念，不要休息，佛就会现前。'《璎珞经》说：'道名一心，多想非道。'《坐禅三昧经》说：'菩萨坐禅，不念一切，唯念一佛，如清凉大海中的金色须弥山王，乃至功德法身，也这样念。'"

问："如果说无念才是三昧，直接超入无念就是了，何必绕远路，还要用念呢？"

答："《楞伽经》说：'用楔出楔'（用一个木楔把另一个木楔顶出来）；俗话说：'使贼捉贼'。现在以念止念，有什么不可以？何况念到纯熟时，不用谋划自然成就，不必用力了。就像剑客舞剑，忽然把剑挥向青云，再用剑鞘背着去接，从未失手；庖丁解牛，刀刃都落在骨节空隙之间，声音合于桑林乐舞的节拍。这就是念到纯熟，不是很明白吗？

"所以《大乘起信论》说：'如果知道虽然说，却无能说与所说；虽然念，却无能念与所念，这名为随顺；如果离于念，名为得入。'得入，就是真如三昧。

"何况无念的地位在妙觉佛果，因为那时才了知心最初生起之相。论中说'知道最初之相，就是所谓无念'，这不是菩萨十地所能知道的。而现在的人，还没有登上十信位，就不依照马鸣菩萨的教导，从有说进入无说，从有念进入无念，实在恐怕是羡慕高台却轻视一筐一筐的土，倒提衣裳去找衣领，怎么可能做到呢？

"《大佛顶首楞严经》说：'大势至法王子，与他同修的五十二位菩萨，即从座起，顶礼佛足，对佛说：我回忆往昔恒河沙劫以前，有佛出世，名无量光，十二位如来相继在一劫中出世，最后一位佛名超日月光，那位佛教我念佛三昧。

"'譬如有两个人，一个专门忆念对方，一个却专心忘记对方，这样两个人，即使相逢也如不逢，相见也如不见。如果两人互相忆念，彼此忆念都很深，这样乃至从这一生到那一生，都像形与影一样，不相离异。

"'十方如来怜念众生，就像母亲忆念儿子。如果儿子逃走，母亲虽然忆念又有什么用？儿子如果忆念母亲，像母亲忆念他那样，母子就生生世世不相远离。如果众生心中忆佛念佛，现在或将来，必定见佛，离佛不远，不假借其他方便，自然得以心开意解，就像染香的人身上自有香气，这名为香光庄严。

"'我在因地中，以念佛心入无生法忍，如今在这个世界摄受念佛的人归于净土。佛问圆通法门，我没有别的选择：都摄六根，净念相继，得三摩地，这是第一。'"

## 第十六门　了心境界妄想不生

问："不了解心与所缘，就会生起两种妄想。现在存有所念的佛、能念的心，岂不正是两种妄想吗？"

答："《楞伽经》说：'了知心及境界，妄想就不生。'所谓不生心，就是远离种种能相、所相。我现在念佛足下的千辐轮相、胸前的万字、绀青色的眼目、眉间的白毫种种妙相，都是我的自心，没有佛可得。所缘既然不是实有，心又怎么会是实有？那么能相的念、所相的佛，自然远离了，怎能住在两种妄想中呢？前代圣人所知道的，辗转相传，妄想没有自性，在这里就领悟了。

"又如观佛的实相，观身也是这样，遇到的境界都是真实，没有一个心不是佛，中道之理遍于一切，哪里还存有一个所缘的佛呢？

"又有一种解释说：'就像鼻子上有个墨点，对着明镜，人讨厌那墨点，却只去擦镜子，怎么擦得掉？好恶是非，对着眼前的境界，不了知自心，只去怨怪境界，又怎么能解决？'不如洗去分别心这个鼻上的墨点，那么整面镜子都圆满清净了，万境都是真实了，拿起石头就成宝了，众生就是佛了。

"所以《续高僧传》说：'北齐时有一位向居士，写信给慧可禅师通好，信中说：影子由形体而起，回响随声音而来。玩弄影子而劳累形体，不知道形体是影子的根本；扬起声音去止息回响，不知道声音是回响的根源。除去烦恼而求涅槃，就像避开形体而寻找影子；离开众生而求佛性，就像默不作声而寻找回响。所以知道，迷与悟是一条路，愚与智没有分别。本来无名而立名，因为有名，是非就生起了；本来无理而立理，因为有理，诤论就兴起了。幻化不是真实，谁是谁非？虚妄没有实体，什么空什么有？由此知道，得也无所得，失也无所失。我还没有机会当面请教，姑且表达这点意思，希望您回答。'慧可禅师提笔写下自己的心意，回答居士说：

```
说此真法皆如实，契真幽理竟不殊。
本迷摩尼谓瓦砾，豁然自觉是真珠。
无明智慧等无异，当知万法即皆如。
破此二见之徒辈，申辞措意作斯书。
观身与佛无差别，何须更觅彼无余？
```

大意是：您所说的真法都如实，契合真实幽深之理，毫无差别。本来迷惑时，把摩尼宝珠当作瓦砾，忽然自己觉悟，才知道是真珠。无明与智慧平等无异，应当知道万法都是如如。为了破除执著这两种见解的人，我才措辞写下这封信。观察自身与佛没有差别，何必再去寻觅那无余涅槃呢？

"这两位上士，依照达摩大师所说的'称法行'，以理观用心，都是念中道第一义谛的法身佛。必定不会离开念而另存一个无念，离开生而另立一个无生。如果说离开它们另立一个，这就是不了解烦恼就是涅槃、众生就是诸佛，怎能悟得那瓦砾就是真珠呢？

"既然离开它们不可以，那么就念佛而真无念，就往生而真无生。这样一来，这个道理就焕然明白，像秋天天空澄澈、雨后放晴，明月从云中出来一样。怎能像愚人那样只看手指而不看月亮呢？"

## 第十七门　诸佛解脱心行中求

问："念佛名为真无念，往生名为真无生，我相信了。《维摩经》说：'诸佛的解脱，当到哪里去求？当在一切众生的心行中求。'既然说'在一切心行中求'，为什么不在自心中求，却去求外面的佛呢？"

答："您认为念佛三昧这无上妙禅，不是在心行中求，不是这样的，我为您说明。

"心之所以为'行'，是行于三种境界：一是行于善境，就是念佛三昧，是善中之善，天中之天；二是行于不善境，就是贪、嗔、痴等种种恶的境界；三是行于无记境，就是心无所住，不缘善也不缘恶。

"若论理性，理遍于这三种境界；若论顺于理性，只留下善境。经中说'执取我是垢，不执取我是净'，意思是：不了知法性本体中没有悭贪，违背法性而不行布施，即使布施，也住著于布施，不能舍离布施之相，这不是垢是什么？如果能了知并随顺法性，行布施波罗蜜，没有悭贪，也没有布施之相，善于随顺理性，这不是净是什么？不善与无记，违背法性，不能与善并列。

"所以胜天王问佛：'菩萨怎样通达禅波罗蜜？'佛告诉大王：'菩萨摩诃萨学般若波罗蜜、行禅波罗蜜时，应当观察这心行于什么境界，是善、不善还是无记的境界。如果行于善境，就勤加修习，譬如莲花上不停留水滴，一点不善之海也不得暂住。'依据这金口之言，岂有不善、无记的心不加以摈弃的呢？这就是顺理：善心行于善境，炽然念佛，解脱就在心行之中。如果说念佛的心行不是解脱，不善、无记两种心行又怎么会是解脱呢？

"这样的解脱，迷了就滞留于浩劫之中，悟了就证得如反掌一样容易。修习禅定的明镜，正在这里。如来世雄考察种种禅定，以念佛三昧为禅中之王；其余种种有所待、有所对的三昧，都是匹夫之定而已。

"然而这宝王三昧，不住于尊相，不住于卑相，邪相、正相，生死相、涅槃相，烦恼相、菩提相，静相、乱相，成正觉相、度众生相、坐道场相、无所得相，这些相都一概不住，就像从梦中醒来，空廓无有来去。所以《大品般若经》说：'无去、无来就是佛。'这样一来，连中道都要遣除，哪里还会住于两边呢？

"如《诸法无行经》偈说：

```
譬如人，于梦中，得佛道，度众生，
此无道，无众生，佛法性，亦复然。
坐道场，无所得，若不得，则不有，
明无明，同一相，知如是，为世尊。
众生性，即菩提，菩提性，即众生，
菩萨众，亦不二，知如是，为世尊。
```

大意是：譬如有人在梦中成佛度众生，其实既没有道可成，也没有众生可度，佛法的本性也是这样。坐道场时一无所得，既然不得，也就没有什么存在；明与无明同一个相，这样了知的就是世尊。众生的本性就是菩提，菩提的本性就是众生，菩萨众也是不二，这样了知的就是世尊。"

## 第十八门　三业供养真实表敬

问："三昧观门的奇妙言论，我已经听了。再请问：以身口意三业供养佛，在佛在世时与佛灭度后，哪一种获福更多？"

答："若论供养法界海，在万行之中，凡是能清净三业的，都名为供养，何况心思在真境中驰骋，怎能不是供养呢？《理趣般若经》说：'观察一切法，无论常还是无常，都不可得。'于是对诸如来广设供养，这不是很明白吗？

"又，如来在世时，人们庄严供奉，表达诚心，都说华云香海遍满微尘刹土，还嫌太少。大菩萨所以入观用想，以须弥山为灯芯，以大海为灯油，还觉得没有尽到恭敬，于是焚烧金色的手臂，供养净明的宝塔，金身火焰洞照十方，喜见菩萨（药王菩萨前身）就是例子。

"而现在的人，只是推说供养在自心，或者远远地指着花树说供养了，违背了奉献的礼仪，这是多么深重的傲慢！

"您问'佛在世时与灭度后，哪一种获福更多'，试为您说明。汉代丁兰在堂中刻木像供奉父母，早晚问候冷暖，如同父母在世，因此名垂青史，人们到今天还称他为真孝子。如果如来在世，金身如山般光耀，庄严的相好赫然在目，谁见了不发道心？献花表达诚恳，不是很容易吗？等到世雄隐去行迹，如月亮隐入重山，不能再奉事真容，只流传贝叶经文，这时对着佛的形像发起无上道心，能献上一朵花，这种志向、这种心，足以嘉许崇尚。能这样做的人，不是很难吗？

"《涅槃经》说：'乃至献上一朵花，就能往生不动国。'那么一香、一花、一灯、一乐，以及饮食，尽心欢喜地供奉三世诸佛，这是净土的妙因，成圣的开端，怎能把这件事看得轻易而不遵行呢？

"如果离开这种修行，听信无稽之言，说什么献心花、点心灯、焚心香、礼心佛，以此来求正觉，这与卖弄猿猴般的机巧、守着梅林的空想解渴又有什么不同呢？如果让他穿心里的衣、吃心里的饭，他就会困窘抗拒不已；至于六度万行，为什么偏要用空见之心来排斥呢？指心、指空之说，过失就是这样，不可不慎！

"真言门中的瑜伽观行，也依事门来表相，并不一味推说在心，经常庄严供奉香花，六时不废。"

## 第十九门　无相献华信毁交报

问："花是事相，理在哪里？相信与毁谤，各自的报应在哪里？"

答："花就是理，色即是空。

"先说相信的报应。《悲华经》说：'从前有位王子名叫无所畏，手持莲花供养宝藏佛。佛说：你用莲花印于虚空，现在给你立号，名为虚空印，将来成佛，世界名为莲华，佛号莲华尊，就是你。'国土与佛号，都依据往昔所献的莲花而立名，是要让人清楚认识修因感果的道理。为什么要阻止布施度中的献花，而另外去遵从无相呢？

"再说毁谤的报应。《大方广总持经》说：'从前有一位比丘名叫净命，住于正见，持花供养；又有一位比丘名叫法行，住于邪见，坐而证得四禅，常说空宗般若最殊胜，他诽谤净命法师说：净命所受的那些花，不拿去供养，却自己受用了。就因为这一句话，他在六万世中常常没有舌根，乃至成佛时，还住在五浊恶世。'那人是谁？就是释迦佛。

"佛说：'少闻的人在我的法中作两种说法，命终之后堕入地狱，经过许多百千劫。如果用恶眼看发菩提心的人，得无眼的果报；用恶口诽谤发菩提心的人，得无舌的果报。'

"如果只修一个般若波罗蜜就能成就菩萨，那么往昔迦尸迦王行菩萨行时，舍弃自己所爱的身体、头、眼、骨髓、脑，那时这位国王难道没有智慧吗？由此可知，六波罗蜜应当具足修习，执著一种而否定其余，就是魔业。怎能舍弃献花的布施波罗蜜，而以恶取空去冒充般若的真无相呢？无舌的果报，是自己招来的过咎。如来之所以自己引出往昔的过失，是想让众生不要重蹈覆辙。

"一朵花尚且如此，一切泥塑木雕的佛像，竹简帛书的经典，剃发的僧尼，住持三宝，戒定慧三学，无论是福田还是非福田，都可以恭敬，一切都归入真实的三业供养法界海中，有什么不可以？为什么要省略它呢？

"《法华经》偈说：

```
若人于塔庙，宝像及画像，以华香幡盖，敬心而供养，
乃至一小音，皆已成佛道。
```

大意是：如果有人在塔庙中，对宝像或画像，以花、香、幡、盖恭敬供养，乃至以一点点微小的音声赞佛，都已成就佛道。"

## 第二十门　万善同归皆成三昧

问："布施灯明，得以长明，往生日宫月宫；花、香、幡、盖与灯没有不同，都是生天的福报。而经中却说'皆已成佛道'，为什么酬报这么深厚呢？"

答："就像帝王出巡，万辆车驾，千员官吏，乃至步卒，都带着'御'字的标记，冒犯了他们就是冒犯天子仪仗，顷刻就会被处死。如果銮驾回宫，步卒解散，回到乡村，如果还自称带着'御'字，也会顷刻被处死。同样是步卒，生死却不同，这是因为缘起不同，才有这样的荣辱。

"假如花、盖、香、灯没有遇到《法华经》这位经王的天子仪仗，确实也只是生天的果报；现在遇上了三昧宝王，就像扈从在侧，乃至献一朵花，都已成就佛道。这就是'佛种从缘起'，理与教都是这样。也像鸟飞向须弥山，都变成同一种金色；水流入大海，就不再有别的名称。

"所以《大宝积经·文殊普门会》中，会集天龙八部、地狱、畜生，以及色声香等一切万法，都是三昧。这也像一根毫毛容纳大海，一粒芥子容纳须弥山，难道是毫毛、芥子本身有神通吗？是神妙的作用使它神妙罢了。

"由此可知，解如眼睛，行如双足；解正则行正，解邪则行邪；魔与佛的深浅，都依凭于解。所以《涅槃经》说：'对于戒律松缓的，不名为缓；对于大乘松缓的，才名为缓。'乘，就是慧解的称呼。一行既然如此，万行都是这样。

"法华三昧就是念佛三昧。所以如来把这殊胜的禅定称为三昧宝王、光明藏、除罪珠、邪见者的明灯、迷途者的向导、王子的金印、贫人的宝藏、空三昧、圣三昧、陀罗尼、真思惟、最胜观、如意珠、佛性、法性、僧性、无尽藏、胜方便、大慧光明、消恶观法三昧等。

"所以知道，教、理、行、果，八万四千波罗蜜门，都是念佛三昧的异名。这样，献一朵花，就遍供三世尘刹诸佛；念一尊佛的本体，就通达未来世雄。就像以大地为箭靶，哪有箭射出去而射不中的呢？不然，就违背了《思益经》中对'畏空、舍空、行空、索空'者的诃责了。"

## 客赞

客人说："医生离去留下药方，商人远行寄存黄金。前贤所珍藏的，不是合适的人不传。弟子昏昧于道、懵懂于学，却得以窥见三昧之门，还希望证得无生，常盼听到唯一真实的教法。

"以上的奥旨，是法的宝印：动与寂双照，理与事圆融，举心都是真实，触类而长；称一声南无，都成就佛道；散一朵花、弹一下指，都超越到菩提。经王所在之处自然尊贵，就像用金錍刮去眼中的翳膜。这二十门的义理，我从来没有听说过。

"我欣喜地洗雪了轻视众生的过失，得以优游于宝庄严的国土，这是何等的幸运！愿不改变这个身体，就获得醍醐般的妙记，领悟未来诸佛就是众生。"

于是他向多宝塔稽首，对着莲华僧众，与我一同普观十方世尊，圆念三世诸佛，长跪合掌，说偈颂道：

```
一心忆念过去佛，亦忆未来诸世尊，
现在一切人中雄，亦学于其所说法，
无有一佛在过去，亦无现在及当来，
唯此清净微妙禅，彼不可言证能说。
```

大意是：一心忆念过去诸佛，也忆念未来诸位世尊，以及现在一切人中之雄，也学习他们所说的法。其实没有一尊佛在过去，也没有在现在和未来；唯有这清净微妙的禅，不可言说，唯证能知。

## 跋（北宋黄伯思）

孔夫子说："站着时，就看见它立在面前；坐在车上，就看见它靠在车辕的横木上，这样才能去实行。"史书说："坐着就看见尧在墙上，吃饭就看见尧在汤里。"（语出《后汉书·李固传》）道不可须臾离开，就是这样。虽然如此，这只是世间之道。

《首楞严经》说："如果众生忆佛念佛，现前当来必定见佛，不假方便，自得心开。"我认为修念佛三昧，也应当像"参于前、倚于衡"以及"见尧于墙、见尧于羹"那样，行住坐卧都应忆念，何愁不能见佛呢？这真是出世成道的要津。

修这个三昧的人，应当以往生安养国为期。因为阿弥陀佛的愿力，以接引众生为要务，大光明普照，摄取不舍，凡是存心忆念的，都能往生，利益多么广博！哪里只是像见尧于墙、见尧于羹那样的虚想呢？

政和七年（1117）十一月三日，在符离境内的船中，因为读唐代飞锡大师的《念佛宝王论》，于是想到我们孔夫子与汉代史书的话，与佛说契合得像符节一样，就记在这本书上，希望时时观看，用来策励自己。凡是见到、听到的人，也都勉励吧。黄伯思长睿父谨书。
