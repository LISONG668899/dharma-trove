# 金刚歌（佚名）

未署作者　据藏文译出

## 题解

《金刚歌》（梵 Vajragīti，藏 rdo rje'i glu）收于德格版丹珠尔续部释 ཞི 函第 153a 页（东北目录 D2290），夹在那洛巴的两篇《金刚歌》（D2288、D2289）与黑行者的《金刚歌》（D2291）之间。跋语只说"《金刚歌》圆满"，没有作者与译者的名字，所以本译称为"佚名"。它是否也是那洛巴所作，从原文无法判定，存疑。

全篇只有正文五个短句，没有偈颂的格律，几乎是一句口诀：使"我"与"你"成为相异的，就是分别念；分别念就像从甘露大海中出现的蛇；所以要摧毁分别念。

**与前译的关系：**本篇以前没有译过，与已译篇目没有重复。"分别念如蛇"的意象，与紧接在前面的那洛巴《金刚歌》（D2289）相同，可以连读。

体例：本篇极短，依本译的体例，保留藏文原文于代码块中，按意义单元译出，最后附通篇连读；补的字放在方括号中，存疑之处以"【按】"说明。

## 题名与礼敬

```
༄༅༅། །
རྒྱ་གར་སྐད་དུ།
བཛྲ་གཱི་ཏི།
བོད་སྐད་དུ།
རྡོ་རྗེའི་གླུ།
ཐུགས་རྗེ་ཆེན་པོ་ལ་ཕྱག་འཚལ་ལོ། །
```

梵语题名：Vajragīti。藏语题名：《金刚歌》。

敬礼大悲［观世音］！

【按】"大悲"（thugs rje chen po），在藏文中常作为观世音菩萨的称号，这里也可能只是敬礼大悲心本身，存疑。

## 正文

```
ཇི་ལྟར་ན་ང་།
དེ་ལྟར་ན་ཁྱོད།
ཐ་དད་པར་བྱེད་པ་རྣམ་པར་རྟོག་པ།
```

我是怎样的，你就是怎样的；使［我与你］成为相异的，是分别念。

【按】"我是怎样的，你就是怎样的"（ji ltar na nga / de ltar na khyod），说自他本来平等无二；使自他成为对立的，只是分别念。这里的"你"，可能是指弟子，也可能是指一切众生，或者是指上师、本尊，存疑。

```
བདུད་རྩིའི་རྒྱ་མཚོ་ལས་སྦྲུལ་འོངས།
ཆོམ་རྣམ་པར་རྟོག་པ།
```

从甘露的大海中，来了一条蛇。摧毁分别念吧！

【按】"从甘露的大海中，来了一条蛇"：甘露大海比喻本来清净、本具一切功德的心性；蛇比喻分别念，它从心性中生起，却成为伤害自己的毒。这个意象可能与印度"搅乳海"的神话有关：诸天与阿修罗搅动乳海求取甘露，却先搅出了剧毒，存疑。

"摧毁"（chom），是"'joms"（摧毁）的命令式，所以译为"摧毁分别念吧"。

## 跋

```
རྡོ་རྗེའི་གླུ་རྫོགས་སོ།།
```
