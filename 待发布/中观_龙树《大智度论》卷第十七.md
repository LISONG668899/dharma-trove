# 龙树《大智度论》卷第十七

龙树菩萨造　后秦龟兹国三藏鸠摩罗什奉诏译

## 释初品中禅波罗蜜第二十八

【经】“因为不乱、不味着，所以应当具足禅波罗蜜。”

【论】

### 一、菩萨何以离众修禅

问：菩萨之法以度化一切众生为事业，为什么闲坐在林泽之中，静默在山间，独善其身，舍弃众生？

答：菩萨身体虽然远离众生，心中却常不舍弃；在静处求定，得到真实智慧以度化一切。譬如服药调养身体，暂时停下家务，气力恢复健康之后，就像原来一样经营事业；菩萨宴坐寂静也是这样，以禅定之力，服用智慧之药，得到神通之力，又回到众生之中，或者作父母妻子，或者作师徒宗长，或者作天，或者作人，下至作畜生，以种种语言方便开导。

再者，菩萨修行布施、持戒、忍辱，这三件事名为福德之门。在无量世中作天王、释提桓因、转轮圣王、阎浮提王，常以七宝、衣服、五根所欲之物布施众生，使他们今世、后世都具足。如经中说：“转轮圣王以十善教化人民，人民后世都生天上；世世利益众生，使他们得到快乐。这快乐是无常的，又会再受苦。”菩萨因此发大悲心，想以常乐的涅槃利益众生。这常乐涅槃从真实智慧而生，真实智慧从一心禅定而生。譬如点灯，灯虽然能照，在大风中却不能发挥作用；如果放在密闭的屋中，它的作用才能完全发挥。散乱心中的智慧也是这样，如果没有禅定这间静室，即使有智慧，它的作用也不完全；得到禅定，真实智慧就生起。所以，菩萨虽然离开众生，远处静处，求得禅定。因为禅定清净，智慧也清净；譬如灯油与灯炷清净，它的光明也清净。所以，想要得到清净智慧的人，应当修行这禅定。

再者，如果求取世间浅近的事情，不能专心，事业尚且不能成就，何况甚深的佛道而不用禅定！

禅定名为收摄诸乱心。乱心轻飘，甚于鸿毛；奔驰散乱不停，快过疾风；不可制止，比猕猴还厉害；刚一出现就转而消失，甚于闪电。心的相状这样不可禁止，如果想制伏它，非禅定不能使之安定。如偈中说：

```
禅为守智藏，　　功德之福田；
禅为清净水，　　能洗诸欲尘；
禅为金刚铠，　　能遮烦恼箭；
虽未得无余，　　涅槃分已得。
得金刚三昧，　　摧碎结使山；
得六神通力，　　能度无量人。
嚣尘蔽天日，　　大雨能淹之；
觉观风散心，　　禅定能灭之。
```

大意：禅定守护智慧的宝藏，是功德的福田；禅定是清净之水，能洗去种种欲尘；禅定是金刚铠甲，能遮挡烦恼之箭；虽然还没有得到无余涅槃，却已得到涅槃的一分。得到金刚三昧，能摧碎结使之山；得到六神通之力，能度无量之人。喧嚣的尘土遮蔽天日，大雨能把它压下去；觉观之风吹散心意，禅定能使之止息。

再者，禅定难以得到，修行者一心专求而不废弃，才能得到；诸天以及神仙尚且不能得到，何况懈怠心的凡夫！

如佛在尼拘卢树下坐禅时，魔王的三个女儿说偈问道：

```
独坐林树间，　　六根常寂默，
有若失重宝，　　无援愁苦毒。
容颜世无比，　　而常闭目坐，
我等心有疑，　　何求而在此？
```

大意：独自坐在林树之间，六根常常寂然静默，好像失去了贵重的宝物，无依无援而愁苦。容颜世上无比，却常闭目而坐，我们心中有疑：你在这里求什么？

那时，世尊以偈回答：

```
我得涅槃味，　　不乐处染爱；
内外贼已除，　　汝父亦灭退。
我得甘露味，　　安乐坐林间；
恩爱之众生，　　为之起慈心。
```

大意：我已得到涅槃之味，不乐于处在染爱之中；内外之贼已经除尽，你们的父亲也已灭退。我得到甘露之味，安乐地坐在林间；对沉溺恩爱的众生，为他们生起慈心。

这时三女心生惭愧，自己说：“这人已经离欲，不可动摇。”当即消失不见。

### 二、修禅的方便：却五事、除五法、行五行

问：修行什么方便，能得到禅波罗蜜？

答：却除五事（五尘），除去五法（五盖），修行五行。

#### （一）呵五欲

怎样却除五事？应当呵责五欲。可悲啊众生！常被五欲所恼，却仍然追求不止！

这五欲，得到了反而更加剧烈，如用火烤疥疮。

五欲没有益处，如狗啃骨头。

五欲增长争斗，如群鸟争肉。

五欲烧人，如逆风持火炬。

五欲害人，如踩到毒蛇。

五欲不真实，如梦中所得。

五欲不长久，如暂借片刻。

世人愚痴迷惑，贪着五欲，至死不舍，因此后世受无量苦。譬如愚人贪着好果子，爬上树去吃，不肯及时下来；有人砍伐那棵树，树倒了他才掉下来，身首毁坏，痛恼而死。

又这五欲，得到时有片刻的快乐，失去时却是大苦；如刀上涂蜜，舔的人贪图甜味，不知道会伤到舌头。

五欲之法，是与畜生共有的；有智慧的人认识到这一点，能自己远离。

如经中所说：有一位优婆塞，与众商人远出谋生。当时天寒下雪，夜行时与同伴失散，住在一个石窟中。这时山神变为一个女子，来想要试探他，说这偈：

```
白雪覆山地，　　鸟兽皆隐藏；
我独无所恃，　　惟愿见愍伤！
```

大意：白雪覆盖山地，鸟兽都藏了起来；我独自无所依靠，只愿你怜悯我！

优婆塞两手捂住耳朵，以偈回答：

```
无羞弊恶人，　　说此不净言，
水漂火烧去，　　不欲闻汝声！
有妇心不欲，　　何况造邪淫？
诸欲乐甚浅，　　大苦患甚深。
诸欲得无厌，　　失之为大苦；
未得愿欲得，　　得之为所恼。
诸欲乐甚少，　　忧苦毒甚多，
为之失身命，　　如蛾赴灯火！
```

大意：不知羞耻的恶人，说这不净之言，让水漂走、火烧掉吧，我不想听你的声音！我有妻子尚且心中不想欲事，何况造作邪淫？诸欲的快乐很浅，苦患很深。诸欲得到了不知满足，失去了就是大苦；没得到时盼望得到，得到了又被它所恼。诸欲的快乐很少，忧苦之毒很多，为它失去身命，如飞蛾扑向灯火！

山神听了这偈，当即托起这人送到他的同伴那里。

这是智者呵责欲而不可执着。五欲，名为美妙的色、声、香、味、触；想要求禅定，都应当舍弃。

##### 1. 呵色

怎样舍弃色？

观察色的过患：如果人执着色，诸结使之火都炽燃起来，烧害人身。如火烧过的金银、煮沸的热蜜，虽然有颜色与滋味，却会烧伤身体、烫烂口舌，应当赶快舍弃。如果人染着美妙的色与美味，也是这样。

再者，好恶在于人，色并没有一定。凭什么知道？如远远看见所爱的人，当即生起喜爱之心；如果远远看见怨家恶人，当即生起愤怒加害之心；如果看见不相干的人，就无怒无喜。如果想要舍弃这喜怒，应当把邪念与色同时都舍弃；譬如熔化的金子烧身，如果想除去它，不能只想舍弃火而留下金子，必须金与火一起舍弃。

如频婆娑罗王因为色的缘故，只身进入敌国，独自待在淫女阿梵婆罗的房中。

忧填王因为染着于色，截断了五百仙人的手足。

像这样等等种种因缘，这名为呵责色欲。

##### 2. 呵声

怎样呵责声？声的相状不停，刚听到就消失了。愚痴的人不了解声相是无常、变化、消失的，所以在音声中妄生喜好；对已经过去的声音，忆念而生起执着。

如五百仙人住在山中，甄陀罗女在雪山的池中沐浴；仙人听到她的歌声，当即失去禅定，心醉狂乱，不能自持。譬如大风吹动诸林树；听到这细妙的歌声，柔软清净，生起邪念想，所以不知不觉心意狂乱；今世失去诸功德，后世当堕恶道！有智慧的人，观察声音念念生灭，前后不同时存在，互不相及；这样了知，就不生染着。像这样的人，诸天的音乐尚且不能扰乱他，何况人的声音？

像这样等等种种因缘，这名为呵责声欲。

##### 3. 呵香：沙弥贪香作龙、池神呵比丘

怎样呵责香？人们认为执着香的罪过小，然而染爱于香，就打开了结使之门；即使百年持戒，也能在一时之间毁坏。

如有一位阿罗汉常到龙宫受食，吃完后把钵交给沙弥让他洗；钵中有几粒剩饭，沙弥闻了很香，吃了非常美味。他便想了个办法，钻到师父的绳床下面，两手抓住绳床的脚；师父去时，他就随着绳床一起进入龙宫。龙说：“这人还没有得道，为什么带他来？”师父说：“我没有察觉。”沙弥得到饭食吃了，又看见龙女身体端正，香妙无比，心中大生染着，当即发愿：“我应当作福，夺取这龙的住处，住在它的宫殿中！”龙说：“以后不要带这沙弥来了！”沙弥回去之后，一心布施、持戒，专求所愿，愿早日作龙。这时他绕寺而行，脚下冒出水来，自知必定能作龙了。他径直到师父原来进入龙宫之处的大池边，用袈裟蒙住头跳了进去，当即死去，变为大龙；因为福德大，当即杀了那条龙，整个池子都染红了。在这之前，诸师父与僧众呵斥他。沙弥说：“我心意已定，心的相状已经显现了。”那时，师父带领众僧到池边观看。这样的因缘，是由于执着香。

再者，有一位比丘在林中莲花池边经行，闻到莲花的香，心中喜悦，走过之后还心生爱着。池神对他说：“你为什么舍弃那林下禅修清净的坐处，来偷我的香？因为执着香，诸结使原本卧伏的都起来了。”这时，又有一个人来到池中，大量采摘莲花，挖拔根茎，弄得一片狼藉而去；池神默然不说话。比丘说：“这人破坏你的池子，采你的花，你一句话都不说；我只是在池边走走，就被呵骂，说我偷你的香！”池神说：“世间的恶人常在罪垢粪中，被不净淹没了头，我不同他说话。你是修禅行的好人，却执着这香，破坏了你的好事，所以呵斥你！譬如洁白的布鲜亮干净，上面有一点黑污，众人都看得见；那恶人，譬如黑衣上点了墨，人们看不见，谁会去问他！”

像这样等等种种因缘，这名为呵责香欲。

##### 4. 呵味：爱酪沙弥、月分王太子

怎样呵责味？应当自己觉悟：“我只因为贪着美味，就会受众苦，熔铜灌口，吞烧红的铁丸；如果不观察饮食之法，嗜好之心坚固执着，就会堕入不净的虫类之中。”

如有一个沙弥，心中常爱乳酪，诸施主供僧乳酪时，沙弥常得到剩下的部分，心中爱着，喜乐不离；命终之后，生在这剩酪的瓶中。沙弥的师父已得阿罗汉道，僧众分乳酪时，师父说：“慢慢来！不要伤了这个爱酪的沙弥！”众人说：“这是虫，为什么说是爱酪的沙弥？”师父回答：“这虫本来是我的沙弥，只因为贪爱剩酪，所以生在这瓶中。”师父分到乳酪，虫也随着来了。师父说：“爱酪的人！你为什么来？”就把乳酪给了它。

再者，如有一国，国王名叫月分。国王有一个太子，爱着美味，国王的守园人每天送来好果子。园中有一棵大树，树上有鸟养育幼雏，常飞到香山中，取好的香果来喂养幼雏；幼雏们争抢，一个果子掉在地上，守园人早晨看见了，觉得不同寻常，就送给国王。国王珍视这果子香色奇异，太子看见了就要，国王爱子，就给了他。太子吃了果子，尝到它的香味，心中深深染着，天天都想要；国王就召来守园人，问果子的来由。守园人说：“这果子没有种植，是从地上捡到的，不知从哪里来。”太子啼哭不吃饭，国王催逼守园人：“全靠你去弄到它。”守园人到捡果子的地方，看见有鸟巢，知道是鸟衔来的，就藏身在树上，伺机想要夺取；鸟母来时，当即夺得果子送去，天天如此。鸟母恼怒，从香山中取来毒果，它的香、味、色全都与先前的相似。守园人夺来献给国王，国王给太子吃了，不久太子身肉溃烂而死。执着于味就是这样，有丧身之苦。

像这样等等种种因缘，这名为呵责着味之欲。

##### 5. 呵触：一角仙人

怎样呵责触？

这触是生起诸结使的大因，是系缚心的根本。为什么？其余四根各自只管各自的部分，而触则遍满身识；因为生起之处广，所以多生染着，这种执着难以离开。凭什么知道？如人执着于色，观察身体三十六种不净就生起厌离之心；如果对触生起执着，即使知道不净，仍贪恋它的细软，观不净也没有用，所以难以离开。

再者，因为它难以舍弃，所以人常为它造作重罪。如果堕入地狱，地狱有两部：一名寒冰，二名焰火。在这两种地狱中，都以身触受罪，苦毒万端。这触名为大黑暗之处，是危难的险道。

再者，如《罗睺罗母本生经》中说：释迦文菩萨有两位夫人，一名劬毗耶，二名耶输陀罗。耶输陀罗是罗睺罗的母亲。劬毗耶是宝女，所以不怀孕生子。耶输陀罗在菩萨出家那一夜，自觉怀了孕。菩萨出家六年苦行，耶输陀罗也怀孕六年不生产。诸释种质问她：“菩萨出家了，怎么会有这事？”耶输陀罗说：“我没有别的罪过，我所怀的孩子，确实是太子的骨血。”诸释种说：“为什么这么久还不生产？”她回答：“这不是我所能知道的！”诸释种集会商议，禀告国王，想要依法治她的罪。劬毗耶对国王说：“请宽恕她！我常与耶输陀罗同住，我为她作证，知道她没有罪。等她的孩子生下来，看是否像父亲，再治罪也不晚！”国王就宽缓了此事。

佛六年苦行圆满，初成佛时，那一夜生下罗睺罗。国王看见孩子像父亲，爱乐而忘却忧愁。对群臣说：“我的儿子虽然离去了，现在得到他的儿子，与儿子在身边没有不同！”耶输陀罗虽然免于罪罚，恶名却传遍全国。耶输陀罗想要除去恶名；佛成道之后，回到迦毗罗婆度化诸释子。那时，净饭王与耶输陀罗常请佛入宫受食。这时耶输陀罗拿一钵百味欢喜丸给罗睺罗，让他拿去献给佛。这时佛以神力把五百阿罗汉变得都像佛身，毫无分别。罗睺罗以七岁之身，拿着欢喜丸径直走到佛前，献给世尊。这时佛收回神力，诸比丘的身体恢复原样，都是空钵而坐，唯有佛的钵中盛满欢喜丸。耶输陀罗当即对国王说：“以此为证，我是没有罪的！”耶输陀罗当即问佛：“我有什么因缘，怀孕六年？”

佛说：“你的儿子罗睺罗，过去久远世时，曾作国王。那时有一位五通仙人来到国王的国中，对国王说：‘国王依法惩治盗贼，请治我的罪！’国王说：‘你有什么罪？’仙人回答：‘我进入大王的国家，犯了不与而取，擅自喝了大王的水，用了大王的杨枝！’国王说：‘我已经给了你，有什么罪？我初登王位时，就把水和杨枝施给一切人了！’仙人说：‘大王虽然已经施与，我心中疑悔，罪过不能除去！愿现在就治我的罪，以免后世受罪。’国王说：‘如果一定要这样，稍等一下，等我进去再回来！’国王进入宫中，六天没有出来。这位仙人在王园中饥渴了六天。仙人思惟：‘这国王正是以此来治我。’国王过了六天出来，向仙人道歉：‘我把你忘了，请不要怪罪！’因为这个因缘，受五百世三恶道之罪，五百世常常在母胎中六年。”以此为证，耶输陀罗是无罪的。

这时，世尊吃完饭出去了，耶输陀罗心生悔恨：“这样的好人，世间稀有，我得以遇到，如今却永远失去了！”世尊坐着时，她目不转睛地凝视；世尊出去时，她跟在后面看，直到远远地看不见了才停止。心中大为懊恨，每一想起，就扑倒在地，气息断绝；旁人用水洒她，才得以苏醒。她常独自思惟：“天下有谁善于咒术，能转变他的心，使他恢复本意，像当初一样欢乐？”就把七宝名珠放在金盘上，拿来招募人。有一位梵志应募，说：“我能咒他，使他心意转变；应当作百味欢喜丸，用药草调和，再用咒语加持，他的心便会转变，必定回来无疑！”耶输陀罗接受了他的方法，派人请佛：“愿与圣众一同屈驾光临！”佛进入王宫，耶输陀罗就把百味欢喜丸放进佛的钵中。佛吃了之后，耶输陀罗盼望如愿，像当初一样欢娱。佛吃了却毫无异样，心与目澄净安静。耶输陀罗说：“现在不动，是因为药力还没有发作；药力发作时，必定如我所愿！”佛吃完饭，咒愿之后，从座位起身离去。耶输陀罗盼望药力在傍晚日落时发作，佛必定回到宫中。佛饮食如常，身心毫无异样。诸比丘第二天到了吃饭时间，穿衣持钵入城乞食，详细听说了这件事，更加恭敬：佛的力量无量，神妙的心难以测度，不可思议！耶输陀罗的药欢喜丸力量很大，而世尊吃了，身心毫无异样。诸比丘吃完饭出城，把这事详细禀告世尊。佛告诉诸比丘：“这耶输陀罗，不只是今世以欢喜丸迷惑我，在过去世时，也曾以欢喜丸迷惑我！”

那时，世尊为诸比丘讲述本生因缘：

过去久远世时，婆罗柰国（原文“柰”字缺损，下同）的山中有一位仙人。在仲春之月，他在澡盘中小便，看见公鹿母鹿交合，淫心当即发动，精液流在盘中。母鹿喝了，当即怀孕。足月生子，形貌像人，只是头上有一只角，脚像鹿。母鹿将要生产时，到仙人的庵边生产。看见孩子是人形，就交给仙人而离去。仙人出来时，看见这鹿生的孩子，自己想起本来的因缘，知道是自己的儿子，就收养了他。等他长大，勤加教他学问，通达十八种大经。又学坐禅，修四无量心，当即得到五神通。一次上山，遇到大雨，泥地湿滑，他的脚不便利，跌倒在地，摔破了他的军持（净瓶），又伤了脚；便大为瞋恚，用军持盛水，咒令天不下雨。因为仙人的福德，诸龙鬼神都为他不下雨。因为不下雨，五谷、五果全都不生，人民穷乏，再无活路。

婆罗柰国王忧愁懊恼，命诸大官集会商议下雨的事。明白的人议论说：“我曾听说仙人山中，有一位一角仙人，因为脚不便利，上山跌倒伤了脚，瞋恨而咒这雨，使之十二年不下。”国王思惟说：“如果十二年不下雨，我的国家就完了，不再有人民了！”国王当即公开招募：“有能使仙人失去五神通、归属我作臣民的，就分一半国土给他治理。”

这婆罗柰国有一个淫女，名叫扇陀，端正无双，来应国王的招募，问众人说：“这是人还是非人？”众人说：“是人，是仙人所生的。”淫女说：“如果是人，我能破坏他。”说完这话，拿金盘盛着好的宝物，对国王说：“我会骑在这仙人的脖子上回来！”淫女当即要了五百辆车，载着五百美女；五百辆鹿车，载着种种欢喜丸，都用众药调和，用各种颜色画得像种种果子；又带着种种烈性美酒，颜色、味道如水一般。她们穿树皮，披草衣，在林树间行走，装作仙人的样子；在仙人庵边搭草庵住下。

一角仙人游行时看见了她们，诸女都出来迎接，以好花好香供养仙人，仙人大喜。诸女都以美言敬辞问候仙人，带他进入房中，坐在好的床褥上，把好的清酒当作净水给他，把欢喜丸当作果蓏给他。吃饱喝足之后，仙人对诸女说：“我从出生以来，从未得到过这样好的果子、好的水！”诸女说：“我们因为一心行善，天满足我们的愿望，得到这好果子、好水。”仙人问诸女：“你们为什么肤色丰满？”回答说：“我们吃这好果子，喝这美水，所以这样丰满！”女子对仙人说：“你为什么不在这里住？”仙人回答：“也可以住！”女子说：“可以一起洗浴！”仙人也答应了。女子的手柔软，触到他，他心就动了；接着又与诸美女轮流相互洗浴，欲心渐生，于是成了淫事，当即失去神通，天降大雨。七天七夜给他欢喜丸饮食，七天以后，酒与果子都吃完了，接着给他山水木果，味道不美，他再要先前的，回答说：“已经吃完了！现在应当一起去，离这里不远，有可以得到的地方。”仙人说：“随你的意！”当即一同出发；淫女知道离城不远了，就在路上躺下，说：“我累极了，不能再走了！”仙人说：“你如果走不动，就骑在我的脖子上，我驮你去！”

女子先派人禀告国王：“大王可以来看看我的才智。”国王命令备好车驾，出来观看，问：“你是怎样做到的？”女子对国王说：“我以方便之力，现在已经这样了，他再也没有什么能力了。”国王让仙人住在城中，好好地供养恭敬他，满足他的五欲，拜为大臣。在城中住了不久，他的身体渐渐消瘦；他念及禅定之心的快乐，厌恶这世间的欲乐。国王问仙人：“你为什么不快乐？身体渐渐消瘦？”仙人回答国王：“我虽然得到五欲，却常常自己忆念林间的闲静、诸仙人游历之处，心中放不下。”国王自己思惟：“如果我强行违背他的意志，违背意志就是苦，苦到极点就会死。本来是为了求除旱灾，现在已经达到了，还有什么理由强夺他的意志？”当即送他回去。回到山中之后，精进不久，又得到了五神通。

佛告诉诸比丘：“一角仙人就是我；淫女就是耶输陀罗。那时她以欢喜丸迷惑我，我还没有断除结使，被她所迷惑；现在又想以药欢喜丸迷惑我，是不可能的了！”因为这件事，知道细软的触法，能动摇仙人，何况愚夫？

像这样种种因缘，这名为呵责细滑之欲。

像这样呵责五欲。

#### （二）除五盖

除去五盖。

##### 1. 贪欲盖

再者，贪欲的人，离道甚远。为什么？欲是种种恼乱的住处，如果心执着贪欲，就无从接近道。如除欲盖的偈中所说：

```
入道惭愧人，　　持钵福众生；
云何纵尘欲？　　沉没于五情！
著铠持刀杖，　　见敌而退走；
如是怯弱人，　　举世所轻笑。
比丘为乞士，　　除发著袈裟；
五情马所制，　　取笑亦如是。
又如豪贵人，　　盛服以严身；
而行乞衣食，　　取笑于众人。
比丘除饰好，　　毁形以摄心；
而更求欲乐，　　取笑亦如是！
已舍五欲乐，　　弃之而不顾；
如何还欲得！　　如愚自食吐！
如是贪欲人，　　不知观本愿，
亦不识好丑，　　狂醉于渴爱。
惭愧尊重法，　　一切皆已弃，
贤智所不亲，　　愚骇所爱近。
诸欲求时苦，　　得之多怖畏，
失时怀热恼，　　一切无乐时。
诸欲患如是，　　以何当舍之？
得诸禅定乐，　　则不为所欺。
欲乐著无厌，　　以何能灭除？
若得不净观，　　此心自然无。
著欲不自觉，　　以何悟其心？
当观老病死，　　尔乃出四渊。
诸欲难放舍，　　何以能远之？
若能乐善法，　　此欲自然息。
诸欲难可解，　　何以能释之？
观身得实相，　　则不为所缚。
如是诸观法，　　能灭诸欲火；
譬如大澍雨，　　野火无在者！
```

大意：入道而知惭愧的人，持钵为众生作福田，怎么能放纵尘欲，沉没在五根之中！披铠持刀杖，见敌却退走，这样怯弱的人，为举世所轻笑；比丘作为乞士，剃发穿袈裟，却被五根之马所制，被人取笑也是这样。又如豪贵之人，穿着盛装庄严其身，却去乞讨衣食，被众人取笑；比丘除去装饰，毁形以摄心，却又追求欲乐，被人取笑也是这样！已经舍弃五欲之乐，弃之不顾，怎么又想要得到！如同愚人自吃呕吐之物！这样贪欲的人，不知观察本来的誓愿，也不识好丑，狂醉于渴爱之中；惭愧与尊重之法，一切都已舍弃，贤智之人不亲近他，愚痴之人爱接近他。诸欲求取时苦，得到后多有怖畏，失去时怀着热恼，一切时中都没有快乐。诸欲的过患是这样，用什么来舍弃它？得到诸禅定之乐，就不被它欺骗。对欲乐执着而无厌，用什么能灭除？如果得到不净观，这心自然就没有了。执着于欲而不自觉，用什么使其心觉悟？应当观察老病死，这才能出离四大深渊。诸欲难以放舍，用什么能远离它？如果能乐于善法，这欲自然止息。诸欲难以解开，用什么能解脱它？观察身体而得其实相，就不被它所缚。像这样种种观法，能灭除诸欲之火，譬如大雨倾注，野火无一留存！

像这样等等种种因缘，灭除贪欲盖。

##### 2. 瞋恚盖

瞋恚盖，是失去诸善法的根本，堕入诸恶道的原因，诸种快乐的怨家，善心的大贼，种种恶口的府库。如佛教诲易瞋的弟子的偈中说：

```
汝当知思惟，　　受身及处胎，
秽恶之幽苦，　　既生之艰难！
既思得此意，　　而复不灭瞋，
则当知此辈，　　则是无心人！
若无罪报果，　　亦无诸呵责，
犹当应慈忍，　　何况苦果剧！
当观老病死，　　一切无免者；
当起慈悲心，　　云何恶加物？
众生相怨贼，　　斫刺受苦毒；
云何修善人，　　而复加恼害？
常当行慈悲，　　定心修诸善；
不当怀恶意，　　侵害于一切！
若勤修道法，　　恼害则不行，
善恶势不并，　　如水火相背。
瞋恚来覆心，　　不知别好丑，
亦不识利害，　　不知畏恶道，
不计他苦恼，　　不觉身心疲，
先自受苦因，　　然后及他人。
若欲灭瞋恚，　　当思惟慈心，
独处自清闲，　　息事灭因缘。
当畏老病死，　　九种瞋恼除，
如是思惟慈，　　则得灭瞋毒！
```

大意：你应当思惟：受身与处胎时，污秽幽暗之苦，出生时的艰难！既已思惟懂得这层意思，却仍不灭除瞋恚，就应当知道这类人是没有心的人！即使没有罪报之果，也没有种种呵责，尚且应当慈忍，何况苦果剧烈！应当观察老病死，一切人都不能免；应当生起慈悲心，怎么能以恶加于众生？众生相互为怨贼，砍刺而受苦毒，修善的人怎么能再加恼害？应当常行慈悲，以定心修诸善，不应当怀着恶意侵害一切！如果勤修道法，恼害就不会发生；善与恶势不两立，如水火相违。瞋恚来覆盖心时，不知分别好丑，也不识利害，不知畏惧恶道，不顾他人的苦恼，不觉自己身心疲惫，先自己受苦因，然后才及于他人。如果想要灭除瞋恚，应当思惟慈心，独处而清闲，止息事务，灭除因缘。应当畏惧老病死，除去九种瞋恼；这样思惟慈心，就能灭除瞋毒！

像这样等等种种因缘，除去瞋恚盖。

##### 3. 睡眠盖

睡眠盖，能破坏今世三件事：欲乐、利乐、福德。能破坏今世、后世、究竟之乐，与死没有差别，只是还有气息。如一位菩萨以偈呵责贪睡的弟子说：

```
汝起勿抱臭身卧，　　种种不净假名人！
如得重病箭入体，　　诸苦痛集安可眠！
一切世间死火烧，　　汝当求出安可眠！
如人被缚将去杀，　　灾害垂至安可眠！
结贼不灭害未除，　　如共毒蛇同室宿，
亦如临阵白刃间，　　尔时安可而睡眠！
眠为大暗无所见，　　日日侵诳夺人明，
以眠覆心无所识，　　如是大失安可眠！
```

大意：你起来，不要抱着这臭身躺着，它是种种不净所成的假名之人！如同得了重病、箭射入身体，诸苦痛聚集，怎么能睡！一切世间被死亡之火焚烧，你应当求出离，怎么能睡！如人被捆绑着拉去杀，灾害即将到来，怎么能睡！结使之贼未灭，祸害未除，如同与毒蛇同室而宿，也如身临阵前白刃之间，这时怎么能睡眠！睡眠是大黑暗，一无所见，天天侵蚀欺诳，夺去人的明慧；以睡眠覆盖心，一无所知，这样的大损失，怎么能睡！

像这样等等种种因缘，呵责睡眠盖。

##### 4. 掉悔盖

掉悔盖：掉这种法，破坏出家之心。如人收摄其心，尚且不能安住，何况掉动散乱？掉动散乱的人，如没有钩制的醉象、鼻绳断了的骆驼，不可禁制。如偈中说：

```
汝已剃头著染衣，　　执持瓦钵行乞食，
云何乐著戏掉法！　　既无法利失世乐！
```

大意：你已经剃头、穿上染色的衣服，拿着瓦钵行乞食，怎么还乐着于嬉戏掉动之法！既没有得到法的利益，又失去了世间之乐！

悔这种法，如犯了大罪的人，常怀畏惧，悔恨之箭射入心中，牢固不可拔出。如偈中说：

```
不应作而作，　　应作而不作；
悔恼火所烧，　　后世堕恶道。
若人罪能悔，　　已悔则放舍，
如是心安乐，　　不应常念著！
若有二种悔，　　不作若已作，
以是悔著心，　　是则愚人相！
不以心悔故，　　不作而能作；
诸恶事已作，　　不能令不作。
```

大意：不应作的作了，应作的却没有作，被悔恼之火所烧，后世堕入恶道。如果人对罪过能悔，悔过之后就放下，这样心中安乐，不应当常常念着！如果有两种悔，对没作的和已作的，因此而悔恨执着于心，这就是愚人之相！不会因为心中悔恨，就能把没作的变成作了；种种恶事已经作了，也不能使它变成没作。

像这样等等种种因缘，呵责掉悔盖。

##### 5. 疑盖

疑盖，因为疑覆盖了心，所以在诸法中不能得到定心；没有定心，所以在佛法中空无所得。譬如人进入宝山，如果没有手，就什么也拿不到。如说疑的意义的偈中说：

```
如人在岐道，　　疑惑无所趣；
诸法实相中，　　疑亦复如是。
疑故不勤求，　　诸法之实相，
是疑从痴生，　　恶中之弊恶！
善不善法中，　　生死及涅槃，
定实真有法，　　于中莫生疑！
汝若生疑心，　　死王狱吏缚。
如师子搏鹿，　　不能得解脱！
在世虽有疑，　　当随妙善法，
譬如观岐道，　　利好者应逐！
```

大意：如人站在岔路口，疑惑而不知往哪里去；在诸法实相之中，疑也是这样。因为疑，所以不勤求诸法的实相；这疑从愚痴而生，是恶中最坏的恶！在善与不善法中，在生死与涅槃中，确定真实的法，对此不要生疑！你如果生起疑心，就被死王的狱吏所缚，如狮子扑住鹿，不能得到解脱！在世间虽然有疑，应当随顺美妙的善法，譬如在岔路口观察，应当走有利的好路！

像这样等等种种因缘，应当舍弃疑盖。

舍弃这五盖，譬如欠债得以解脱，重病得以痊愈，从饥饿之地到达丰饶之国，如从牢狱中出来，如在恶贼之中得以自免、安稳无患；修行者也是这样，除去五盖，其心安稳，清净快乐。譬如日月被五件事遮蔽：烟、云、尘、雾、罗睺阿修罗的手遮挡，就不能明亮照耀；人心也是这样，被五盖所覆，自己不能得利，也不能利益他人。

#### （三）行五法，得初禅

如果能呵责五欲，除去五盖，修行五法：欲、精进、念、巧慧、一心。修行这五法，得到五支，成就初禅。

“欲”，名为想要从欲界中出离，想要得到初禅。

“精进”，名为离家持戒，初夜、后夜专精不懈，节制饮食，收摄其心，不使驰散。

“念”，名为念初禅之乐，知道欲界不净，狂乱迷惑，可轻贱；初禅尊重可贵。

“巧慧”，名为观察衡量欲界之乐与初禅之乐的轻重得失。

“一心”，名为常把心系在所缘之中，不使分散。

再者，专求初禅，放舍欲乐；譬如忧患怨家，常想消灭他，就不会被怨家所害。如佛为执着欲的婆罗门说：“我从前观察欲：欲是怖畏、忧苦的因缘；欲的快乐少，苦很多。”欲是魔网，缠绵难出；欲是烧热，烤干一切快乐，譬如树林四边起火；欲如临火坑，非常可怖；如逼近毒蛇；如怨贼拔刀；如恶罗刹；如恶毒入口；如吞熔铜；如三处流液的狂象；如临大深坑；如狮子挡道；如摩竭鱼张口。诸欲也是这样，非常可怖！如果执着诸欲，使人恼苦。执着欲的人，也如狱中的囚犯，如被围的鹿，如入网的鸟，如吞钩的鱼，如被豺扑住的狗，如乌鸦在鸱鸮群中，如蛇遇到野猪，如老鼠在猫群中，如一群盲人临近深坑，如苍蝇粘在热油上，如病弱之人（原文此处二字缺损）在战阵中，如跛子遇到火灾，如进入沸腾的咸河，如舔涂蜜的刀，如四通大道上的肉块，如薄薄覆盖的刀林，如花覆盖不净之物，如涂了蜜的毒瓮，如装毒蛇的箱子，如梦一般虚诳，如借来的东西终须归还，如幻术诳骗小孩，如阳焰无实，如沉没大水，如船驶入摩竭鱼之口，如冰雹毁坏谷物，如霹雳临近人身。诸欲也是这样，虚诳不实，不牢固、不坚强，乐少苦多。欲是魔军，破坏诸善功德，常为劫害众生而出现。

像这样等等种种譬喻，呵责五欲，除去五盖，修行五法，得以到达初禅。

### 三、何以独名禅波罗蜜

问：八背舍、八胜处、十一切入、四无量心、诸定三昧，像这样等等种种定，不名为波罗蜜，为什么只说禅波罗蜜？

答：这些定的功德，都是思惟修。禅，汉语意为思惟修。说禅波罗蜜，就把一切都包括了。

再者，禅最大，如国王，说禅就包括了一切，说其余的定就不能包括。为什么？

在这四禅中，智慧与定力均等而有乐；未到地定、中间禅，智慧多而定力少；无色界定力多而智慧少，这些地方不是乐处。

譬如车子一个轮子强、一个轮子弱，就不安稳；智慧与定力不均等，也是这样。

再者，在这四禅之处，有四无量心、五神通、背舍、胜处、一切处、无诤三昧、愿智、顶禅、自在定、练禅、十四变化心、般舟三昧、诸菩萨三昧——首楞严等，略说有一百二十种，诸佛三昧——不动等，略说有一百零八种，以及佛的成道、舍寿，像这样等等种种功德、妙定，都在禅中。所以，禅名为波罗蜜，其余的定不名为波罗蜜。

### 四、四禅四无色定

问：你先前说呵责五欲，除去五盖，修行五法，得到初禅。修什么事、依什么道，能得到初禅？

答：依不净观、安那般那念（数息观）等诸定门。

如《禅经》说禅义的偈中说：

```
离欲及恶法，　　有觉并有观，
离生得喜乐，　　是人入初禅。
已得离淫火，　　则获清凉定；
如人大热闷，　　入冷池则乐。
如贫得宝藏，　　大喜觉动心；
分别则为观，　　入初禅亦然。
知二法乱心，　　虽善而应离，
如大水澄静，　　波荡亦无见。
譬如人大极，　　安隐睡卧时；
若有唤呼声，　　其心大恼乱。
摄心入禅时，　　以觉观为恼；
是故除觉观，　　得入一识处。
内心清净故，　　定生得喜乐，
得入此二禅，　　喜勇心大悦！
摄心第一定，　　寂然无所念，
患喜欲弃之，　　亦如舍觉观。
由受故有喜，　　失喜则生忧，
离喜乐身受，　　舍念及方便。
圣人得能舍，　　余人舍为难。
若能知乐患，　　见不动大安，
忧喜先已除，　　苦乐今亦断。
舍念清净心，　　入第四禅中。
第三禅中乐，　　无常动故苦，
欲界中断忧，　　初二禅除喜，
是故佛世尊，　　第四禅中说，
先已断忧喜，　　今则除苦乐。
```

大意：离开诸欲与恶法，有觉也有观，因离欲而生起喜乐，这人就进入初禅。已经离开淫欲之火，就获得清凉之定，如人在大热中烦闷，进入凉池就快乐。如穷人得到宝藏，大喜而觉动其心，分别就是观；进入初禅也是这样。知道觉、观二法扰乱心，虽然是善，也应当离开，如大水本来澄静，波浪一荡就什么也看不见。譬如人极其疲倦，正安稳地睡卧时，如果有呼唤之声，其心就大为恼乱；收摄其心入禅时，以觉观为恼乱，所以除去觉观，得以进入一心之处。因为内心清净，由定生起喜乐，得以进入这第二禅，喜悦踊跃，心中大为愉悦！收摄其心于第一定中，寂然无所念，以喜为患而想舍弃它，也如舍弃觉观一样。因为有所领受所以有喜，失去喜就生忧；离开喜而以身领受乐，有舍、有念以及方便。圣人得到这乐能够舍弃，其余的人难以舍弃。如果能知道乐的过患，见到不动之处的大安稳，忧与喜先前已经除去，苦与乐现在也已断除，以舍念清净之心，进入第四禅中。第三禅中的乐，因为无常、动摇，所以是苦；在欲界中断除忧，在初禅、二禅中除去喜，所以佛世尊在第四禅中说：先前已断除忧喜，现在又除去苦乐。

再者，持戒清净，闲居独处，守护收摄诸根，初夜、后夜专精思惟，舍弃外在之乐，以禅自娱。离开诸欲与不善法，依未到地定，得到初禅。

#### （一）初禅

初禅，如《阿毗昙》中说：“禅有四种：一是味相应禅，二是净禅，三是无漏禅，四是初禅所摄的报得五众。”这其中修行者进入净禅、无漏禅。

二禅、三禅、四禅也是这样。

如佛所说：“如果有比丘离开诸欲及恶不善法，有觉、有观，离生喜乐，进入初禅。”

“诸欲”，是所爱着的色等五欲，思惟分别；呵责欲，如先前所说。

“恶不善法”，是贪欲等五盖。

离开这内外二事，所以得到初禅。

初禅之相：有觉、有观、喜、乐、一心。

“有觉、有观”，是在初禅中得到从未得到过的善法功德，所以心中大为惊觉。常被欲火所烧，得到初禅时，如进入清凉的池子；又如穷人忽然得到宝藏。修行者思惟，分别欲界的过罪，知道初禅的利益功德很多，心中大为欢喜，这名为“有觉、有观”。

问：有觉、有观，是一法？还是二法？

答：是二法。粗心最初的念，这名为觉；细心的分别，这名为观。譬如撞钟，最初声音大时名为觉；后来声音微细名为观。

问：如《阿毗昙》中说：“欲界乃至初禅，在一心之中，觉、观相应。”现在为什么说“粗心最初的念名为觉，细心的分别名为观”？

答：二法虽然在一心之中，二相却不同时显现；觉时，观不明了；观时，觉不明了。譬如太阳出来，众星不现；一切心与心所法，随时受名，也是这样。如佛说：“如果断除一法，我证明你得阿那含。这一法，就是悭贪。”实际上应当说五下分结断尽才得阿那含，为什么说“只断一法”？因为这人悭贪偏多，其余诸结使都随之而生；所以悭贪断尽，其余结使也断了。觉、观随时受名，也是这样。

修行者知道这觉观虽然是善法，却扰乱定心。因为心想离开，所以呵责这觉观，作这样的念头：“觉观扰动禅心，譬如清水，波浪一荡就什么也看不见；又如疲惫至极的人，得以休息想睡，旁人呼唤，种种恼乱。收摄其心于内定之中，觉观扰动，也是这样。”像这样等等种种因缘，呵责觉观。

#### （二）二禅

“觉观灭，内清净，系心一处，无觉无观，由定生喜乐，进入二禅。”

既已得到二禅，就得到二禅中从未得到过的无比喜乐。

“觉观灭”，是因为知道觉观的过罪，所以灭除。

“内清净”，是进入深禅定，相信舍弃初禅的觉观，所得的利益大，所失的很少，所获的很多；系心于一缘，所以名为内清净。

修行者观察喜的过患，也如观察觉观；随着有所喜之处，喜多就忧也多。为什么？如穷人得到宝物，欢喜无量；一旦失去，他的忧愁也深，喜就转而成为忧，所以应当舍弃。

#### （三）三禅

“因为离开这喜，所以修行舍、念、智，以身领受乐。这乐圣人能得能舍，一心在乐中，进入第三禅。”

“舍”，是舍弃喜心，不再追悔。

“念、智”，是既已得到三禅中的乐，不使在乐中生起过患。

“以身领受乐”，是三禅的乐，遍身都领受。

“圣人能得能舍”，是这乐在世间第一，能使心生起执着，凡夫很少能舍弃。所以，佛说修行慈心的果报，在遍净天中为第一。

#### （四）四禅

修行者观察乐的过失，也如观察喜，知道心不动之处最为第一。如果有动摇之处，那就有苦；修行者因为第三禅的乐有动摇，所以求不动之处。

“因为断除苦乐，先前已灭除忧喜，所以不苦不乐，舍念清净，进入第四禅。”

这第四禅中无苦无乐，只有不动的智慧。所以，说第四禅是“舍念清净”。

第三禅的乐因为动摇，所以说是苦；所以在第四禅中说“断苦乐”。

#### （五）四无色定

如佛说：“超过一切色相，不念种种别相，灭除有对之相，得以进入无边虚空处。”

修行者作这样的念头：“如果没有色，就没有饥、渴、寒、热之苦。这身体之色粗重弊恶，虚诳不实，是前世因缘和合，报得这身体，是种种苦恼的住处，怎样才能免除这身体的祸患？应当观察这身体中的虚空。”

常观察身体是空的，如笼子、如甑子，常念不舍，就能超越色，不再见到身体。如内身是空，外色也是这样，这时能观察无量无边的空；得到这观察之后，无苦无乐，其心更加增长。如鸟被关在瓶中，瓶破了得以飞出，这名为空处定。

这空无量无边，以识缘它，所缘多了就散乱，能破坏定。修行者观察以虚空为所缘的受、想、行、识，如病、如痈、如疮、如刺，无常、苦、空、无我，是欺诳的和合而有，不是真实的。

这样念过之后，舍弃以虚空为所缘，只缘识。怎样缘？以现前的识，缘过去、未来无量无边的识。这识无量无边，如虚空无量无边，这名为识处定。

这识无量无边，以识缘它，识多了就散乱，能破坏定。修行者观察这以识为所缘的受、想、行、识，如病、如痈、如疮、如刺，无常、苦、空、无我，是欺诳的和合而有，不是真实有。

这样观察之后，就破除了识相。这是呵责识处，赞叹无所有处，破除诸识相，系心于无所有之中，这名为无所有处定。

无所有处以受、想、行、识为所缘，如病、如痈、如疮、如刺，无常、苦、空、无我，是欺诳的和合而有，不是真实有。

这样思惟：无想处如痈，有想处如病、如痈、如疮、如刺；第一妙处，是非有想非无想处。

问：非有想非无想处，有受、想、行、识，为什么说非有想非无想？

答：这其中有想，但微细难以觉察，所以称为“非有想”；因为有想，所以“非无想”。凡夫心中认为得到了诸法实相，这就是涅槃；佛法中虽然知道有想，因为沿用它本来的名称，所以名为“非有想非无想处”。

问：什么是无想？

答：无想有三种：一是无想定；二是灭受定；三是无想天。

凡夫想要灭心，就入无想定；佛弟子想要灭心，就入灭受定。

### 五、诸禅的修与断（阿毗昙分别）

这诸禅定有两种：或有漏，或无漏。

有漏，就是凡夫所行的，如上面所说；无漏，是十六圣行。

如果是有漏道，依上地的近分（边地）离下地之欲；如果是无漏道，离自地之欲以及上地之欲。

所以，凡夫在有顶处不能离欲，因为再没有上地的近分了。

如果佛弟子想要离欲界之欲、欲界的烦恼，以思惟断除九品：上、中、下；上上、上中、上下；中上、中中、中下；下上、下中、下下。

因为断除这九品，佛弟子如果依有漏道想得初禅，这时在未到地的九无碍道、八解脱道中，现在修有漏道，未来修有漏、无漏道。在第九解脱道中，于未到地，现在修有漏道，未来修未到地的有漏、无漏道，以及初禅近分的有漏道。如果以无漏道想得初禅，也是这样。

如果依有漏道离初禅之欲，在第二禅的近分，九无碍道、八解脱道中，现在修二禅近分的有漏道，未来修二禅近分的有漏道，也修无漏初禅及其眷属；在第九解脱道中，于第二禅近分，现在修二禅近分的有漏道，未来修二禅近分、初禅无漏及其眷属，以及二禅的净禅、无漏禅。

如果以无漏道离初禅之欲，在九无碍道、八解脱道中，现在修自地的无漏道，未来修初禅及其眷属的有漏、无漏道。在第九解脱道中，现在修自地的无漏道，未来修初禅及其眷属的有漏、无漏道，以及修二禅的净禅、无漏禅。

乃至在无所有处离欲时，也是这样。

在非有想非无想处离欲时，九无碍道、八解脱道中，只修一切无漏道；第九解脱道中，修三界善根以及无漏道；除去无心定。

修有两种：一是得修，二是行修。

得修，名为本来没有得到而现在得到；未来世修自己的事，也修其余的事。

行修，名为曾经得到，在现前修习，未来也是这样，不修其余的。

像这样等等，在种种禅定中修习。

#### （一）诸禅的种类与因缘

再者，禅定之相，略说有二十三种：八种味禅、八种净禅、七种无漏禅。

又有六因：相应因、共有因、相似因（同类因）、遍因、报因、名因（能作因）。

每一种无漏禅，七种无漏禅互为相似因；在自地中增加相应因、共有因。

初禅的味定，是初禅味定的因，乃至最后的味定，是最后味定的因。

净禅也是这样。

四缘：因缘、次第缘、缘缘、增上缘。

因缘，如上面所说。

初禅无漏定之后，可以次第生起六种定：一是初禅净禅，二是初禅无漏禅；二禅、三禅也是这样。

二禅无漏定之后，可以次第生起八种定：自地的净禅、无漏禅；初禅的净禅、无漏禅；三禅、四禅也是这样。

三禅无漏定之后，可以次第生起十种：自地二种，下地四种，上地四种。

第四禅、空处也是这样。

识处无漏定之后，可以次第生起九种：自地二种，下地四种，上地三种。

无所有处无漏定之后，可以次第生起七种：自地二种，下地四种，上地一种。

非有想非无想处的净禅之后，次第生起六种心：自地二种，下地四种。诸净禅之地也是这样，又都加上自地的味禅。

初禅味禅之后，次第生起两种：味禅、净禅。乃至非想非非想处的味禅，也是这样。

净禅、无漏禅，以一切处为所缘；味禅缘自地中的味禅，也缘对净禅的爱；因为没有以无漏为所缘的缘故，所以不缘无漏。

净禅、无漏禅的根本无色定，不缘下地的有漏法。

名因（能作因）、增上缘，通于一切。

四无量心、三背舍、八胜处、八一切处，都以欲界为所缘。

五神通以欲界、色界为所缘；其余的各随其所缘。灭受想定无所缘。

#### （二）练禅、顶禅、愿智、四辩、无诤三昧

一切四禅中都有练法，因为以无漏练有漏，所以得到四禅之心的自在。能以无漏第四禅练有漏第四禅，然后第三、第二、第一禅，都以自地的无漏练自地的有漏。

问：为什么名为“练禅”？

答：诸圣人乐于无漏定，不乐于有漏定；离欲时，净的有漏禅不乐而自然得到；现在想要除去它的渣滓污秽，所以以无漏练它。譬如炼金除去污秽，以无漏练有漏也是这样，从无漏禅起来进入净禅，这样反复多次，这名为“炼”。

再者，诸禅中有顶禅，为什么名为“顶”？有两种阿罗汉：退法阿罗汉、不退法阿罗汉。不退法阿罗汉，在一切深禅定中得到自在，能生起顶禅。得到这顶禅，能把寿命转为财富，把财富转为寿命。

又有愿智、四辩、无诤三昧。

“愿智”，是愿意了知三世之事，随所愿就能了知。这愿智属于两处所摄：欲界、第四禅。

“四辩”：法辩、辞辩，属于两处所摄：欲界、初禅；其余两种辩，属于九地所摄：欲界、四禅、四无色定。

“无诤三昧”，是使他人心中不起争诤，属于五处所摄：欲界以及四禅。

#### （三）得禅的时机与变化心

问：得诸禅时还有其他的法吗？

答：味定在受生时得到，也在退失时得到。净禅在受生时得到，在离欲时得到。无漏禅在离欲时得到，在退失时得到。

九地的无漏定：四禅、三无色定、未到地定、中间禅，能断结使。

未到地定、中间禅，与舍根相应。

如果有人成就了禅，下地的变化心也成就。

如初禅成就，有两种变化心：一是初禅的，二是欲界的。

二禅成就：有三种。

三禅成就：有四种。

四禅成就：有五种。

如果在二禅、三禅、四禅中想要闻、见、触时，都用梵世（初禅）的识，识灭时就停止。

四无量心、五神通、八背舍、八胜处、十一切入、九次第定、九相、十想、三三昧、三解脱门、三无漏根、三十七道品，像这样等等诸功德，都在禅波罗蜜中生起，这里应当详细说明。

【译注】本节从“诸禅定有二种”到“皆禅波罗蜜中生”，是照搬阿毗昙的禅定分别：有漏无漏离欲的不同、九无碍道八解脱道中现修未来修、六因四缘、诸定次第相生的数目、练禅顶禅等。译文依原文逐句直译，术语只作最少的括注。论主随即以“应说禅波罗蜜，何以但说禅”一问收住，说明这些都只是“禅”，下文才说何以成“波罗蜜”。

### 六、禅何以成波罗蜜

问：应当说禅波罗蜜，为什么只说禅？

答：禅是波罗蜜的根本。得到这禅之后，怜悯众生：内心中有种种禅定的妙乐，他们却不知道去求，反而在外法的不净与苦中求乐。这样观察之后，生起大悲心，立下弘誓愿：“我应当使众生都得到禅定的内乐，离开不净之乐；依这禅乐之后，再使他们得到佛道之乐。”这时禅定得名为波罗蜜。

再者，在这禅中不受其味，不求果报，不随果报而受生，为了调伏其心而入禅；以智慧方便，又生回欲界，度脱一切众生，这时禅名为波罗蜜。

再者，菩萨进入深禅定，一切天人都不能知道他的心所依、所缘，在见、闻、觉、知的法中心不动摇。如《毗摩罗诘经》中，为舍利弗说宴坐之法：“不依身，不依心，不依三界，在三界中不得身、心，这才是宴坐。”

再者，如果有人听说禅定之乐胜过人天之乐，便舍弃欲乐而求禅定，这是自己求乐求利，不足为奇。菩萨则不是这样，只是为了众生，想使慈悲心清净，不舍弃众生。菩萨的禅，在禅中都发起大悲心。禅有极其美妙的内乐，众生却舍弃它而求外乐。譬如一个大富的盲人，有许多埋藏的宝物，不知道、看不见，却去行乞求讨。智者怜悯他自己有美妙之物，不能知见，却向他人乞求。众生也是这样，心中自有种种禅定之乐而不知开发，反而求取外乐。

再者，菩萨因为了知诸法实相，所以入禅时心中安稳，不执着禅味；其余的外道虽然入禅定，心中不安稳，因为不知道诸法的真实，所以执着禅味。

### 七、菩萨禅与二乘、外道禅的差别

问：阿罗汉、辟支佛都不执着禅味，为什么不得禅波罗蜜？

答：阿罗汉、辟支佛虽然不执着禅味，因为没有大悲心，所以不名为禅波罗蜜，又不能尽行诸禅。

菩萨尽行诸禅，粗的细的、大的小的、深的浅的、内缘的外缘的，一切都尽行。所以，在菩萨心中名为禅波罗蜜，其余的人只名为禅。

再者，外道、声闻、菩萨都能得禅定。而外道的禅中有三种过患：或者味着，或者邪见，或者憍慢；声闻的禅中慈悲淡薄，对诸法不能以锐利的智慧贯通了达诸法实相，独善其身，断绝诸佛种性；菩萨的禅中没有这些事，因为想要积集一切诸佛之法，所以在诸禅中不忘众生，乃至对昆虫也常加慈念。

#### （一）螺髻仙人顶上鸟卵

如释迦文尼佛，前世为螺髻仙人，名叫尚阇利。常修第四禅，出入息断绝，在一棵树下坐，兀然不动。鸟看见他这样，以为是木头，就在他的发髻中生了卵。这位菩萨从禅中出来，知道头上有鸟卵，就自己思惟：“如果我起身走动，鸟母必定不再回来；鸟母不回来，鸟卵必定会坏。”当即又入禅定，直到小鸟飞走，这才起身。

#### （二）欲界心次第入禅、别相离欲

再者，除了菩萨，其余的人不能以欲界心次第入禅。菩萨修行禅波罗蜜，能以欲界心次第入禅。为什么？因为菩萨世世修集诸功德，结使之心淡薄，心意柔软。

再者，其余的人得到总相的智慧能离欲，如无常观、苦观、不净观；菩萨在一切法中，能以别相分别而离欲。

如五百仙人飞行时，听到甄陀罗女的歌声，心中执着而狂醉，都失去神足，同时坠落在地。

如声闻听到紧陀罗王屯仑摩弹琴歌唱，以诸法实相赞叹佛。这时，须弥山以及诸树木都动摇；大迦叶等诸大弟子，都在座上不能自安。天须菩萨问大迦叶：“你年纪最长，修行头陀第一，现在为什么不能制心自安？”大迦叶回答：“我对人天诸欲，心不倾动；这是菩萨无量功德果报所生的声音，又以智慧变化而作出的声音，是我所不能忍受的。如八方之风刮起，不能使须弥山动摇；劫尽时毗蓝风到来，就把须弥山吹得如腐草一般。”所以知道，菩萨在一切法中以别相观察而得以离开诸欲。其余的人只得到禅的名字，没有得到波罗蜜。

#### （三）菩萨住禅之心不可知

再者，其余的人知道菩萨入禅、出禅之心，却不能知道他住在禅中之心所缘所至、所知诸法的深浅。阿罗汉、辟支佛尚且不能知，何况其余的人？譬如象王渡水，入水时、出水时，足迹可见；在水中时，不可得知。如果得到初禅，同样得到初禅的人能够知道，却不能知道菩萨入初禅。有人得到二禅，观察而知道得初禅之心，清清楚楚，却不能知道菩萨入初禅之心；乃至非有想非无想处也是这样。

#### （四）超越三昧

再者，在超越三昧中，从初禅起入第三禅，从第三禅起入虚空处，从虚空处起入无所有处。二乘只能超越一地，不能超越二地；菩萨自在超越，从初禅起，或者如常规入三禅，或者有时入第四禅，或者入空处、识处、无所有处，或者入非有想非无想处，或者入灭受想定；从灭受想定起，或者入无所有处，或者识处、空处、四禅乃至初禅；或者有时超越一地，或者有时超越二地，乃至超越九地。声闻不能超越二地，为什么？因为智慧、功德、禅定之力薄弱。譬如两种狮子：一是黄狮子，二是白发狮子。黄狮子虽然也能跳跃，却不如白发狮子王。像这样等等种种因缘，分别禅波罗蜜。

### 八、常在定中而为众生说法

再者，这时菩萨常入禅定，收摄其心而不动，不生觉观，也能为十方一切众生以无量音声说法而度脱他们，这名为禅波罗蜜。

问：如经中说：“先有觉观思惟，然后才能说法。”入了禅定之中，没有言语、觉观，不应当能说法；你现在为什么说“常在禅定中，不生觉观而为众生说法”？

答：生死之人的法则，入禅定时，先以言语、觉观，然后说法。

法身菩萨离开生死之身，知道一切诸法常住，如禅定之相，不见有散乱；法身菩萨变化无量身为众生说法，而菩萨心中无所分别。

如阿修罗的琴，常常自己发出声音，随心意而奏，没有人弹它；这琴也没有散乱之心，也没有收摄之心，是因为福德果报所生，所以随人的心意发出声音。法身菩萨也是这样，无所分别，也没有散乱之心，也没有说法之相。因为无量福德、禅定、智慧的因缘，这法身菩萨种种法音随应而出。悭贪心多的人，听到说布施之声；破戒、瞋恚、懈怠、乱心、愚痴之人，各自听到说持戒、忍辱、禅定、智慧之声。听到这些法之后，各自思惟，渐渐以三乘而得度脱。

### 九、乱、定不二

再者，菩萨观察一切法，无论散乱或禅定，都是不二之相。其余的人除去散乱而求禅定。为什么？因为在散乱之法中生起瞋想；在禅定之法中生起执着之想。

#### （一）郁陀罗伽仙人瞋鱼鸟

如郁陀罗伽仙人得到五神通，每天飞到国王宫中受食。国王的大夫人按照她国家的礼法，握住他的脚礼拜。夫人的手一触到他，他当即失去神通。他向国王要了车，乘车而出，回到原来的住处。进入林树之间，再求五神通，一心专注；快要得到时，有鸟在树上急叫，扰乱了他的心意。他离开树下到水边求定，又听到鱼争斗搅动水的声音。这人求禅不得，当即生起瞋恚：“我要把鱼、鸟杀尽！”这人很久以后思惟得定，生到非有想非无想处；在那里寿命尽了，下生作飞狸，杀害诸鱼、鸟，造无量罪，堕入三恶道。这是在禅定中生起执着之心的因缘。

#### （二）四禅比丘增上慢堕阿鼻

外道是这样，佛弟子中也有。一位比丘得到四禅，生起增上慢，以为得到了四道果。得初禅时，以为是须陀洹；得第二禅时，以为是斯陀含；得第三禅时，以为是阿那含；得第四禅时，以为得了阿罗汉。依恃于此而止步，不再求进。寿命将尽时，见到四禅的中阴之相到来，便生起邪见，认为：“没有涅槃，佛欺骗了我。”因为生起恶邪见，失去四禅的中阴，便见到阿鼻泥犁的中阴之相，命终当即生在阿鼻地狱。诸比丘问佛：“某某比丘修阿兰若行，命终生在何处？”佛说：“这人生在阿鼻泥犁中！”诸比丘都大为惊怪：“这人坐禅、持戒，怎么会这样？”佛说：“这人有增上慢，得到四禅时，以为得到四道果。临命终时，见到四禅的中阴之相，便生起邪见，认为没有涅槃；我是阿罗汉，现在却又要受生，佛是虚诳的。这时当即见到阿鼻泥犁的中阴之相，命终当即生在阿鼻地狱中。”这时，佛说偈道：

```
多闻持戒禅，　　未得无漏法；
虽有此功德，　　此事不可信！
```

大意：多闻、持戒、修禅，却还没有得到无漏法；虽然有这些功德，这些事也不可依恃！

这比丘受这恶道之苦。

所以知道，取散乱之相，能生瞋等烦恼；取禅定之相，能生执着。菩萨不取散乱之相，也不取禅定之相，因为乱与定之相是一，这名为禅波罗蜜。

#### （三）观五盖不可得：五盖实相即禅实相

如初禅之相，是离欲、除盖、摄心一处。这菩萨以利根智慧观察，所以对五盖无所舍，对禅定之相无所取，因为诸法之相是空。怎样对五盖无所舍？

贪欲盖不在内、不在外，也不在两者中间。为什么？

如果在内法中有，就不应当待外境而生。如果在外法中有，对我也就没有祸患。如果在两者中间有，两者中间就没有处所。

也不是从前世而来。为什么？因为一切法都无来处。如儿童没有欲，如果是从前世带来的，小时候也应当有。因此，知道不是从前世而来，也不去到后世；不从诸方而来，也不是常自存在；不在身体的一部分中，也不遍在全身中；也不从五尘而来，也不从五根而出。无所从生，无所从灭。

这贪欲，或者生在先，或者生在后，或者同时生，这些都不对。为什么？

如果先有生，后有贪欲，这其中就不应当是贪欲在生，因为还没有贪欲；如果后有生，先有贪欲，那么生就无所生；如果同时生，就没有生者、没有所生之处，因为生者与所生之处无所分别。

再者，这贪欲与贪欲者，不一不异。为什么？离开贪欲，贪欲者不可得；离开贪欲者，贪欲不可得，这只是从和合因缘而生。和合因缘所生之法，就是自性空。像这样，贪欲与贪欲者相异不可得。如果是一，贪欲与贪欲者就没有分别。

像这样等等种种因缘，贪欲之生不可得。如果法无生，这法也就无灭；因为不生、不灭，所以无定、无乱。

像这样观察贪欲盖，就与禅为一；其余的盖也是这样。

如果得到诸法实相，观察五盖就无所有，这时便知道五盖的实相就是禅的实相，禅的实相就是五盖。菩萨这样能知五欲以及五盖、禅定以及禅支是一相，无所依而入禅定，这是禅波罗蜜。

【译注】“五盖实相即是禅实相，禅实相即是五盖”，是本卷最深的一句。前文从呵五欲、除五盖、行五法一步步讲到四禅四空，都是“除乱求定”；到这里论主说，除乱求定本身，于乱生瞋想、于定生着想，郁陀罗伽与增上慢比丘正是两个例子。菩萨以观贪欲不内不外、不先不后、不一不异，知其无生无灭，于是“于五盖无所舍，于禅定相无所取”，乱与定一相，这才是经文“不乱不味”的究竟义。

### 十、禅波罗蜜的作用

再者，如果菩萨修行禅波罗蜜时，其余五波罗蜜和合助成，这名为禅波罗蜜。

再者，菩萨以禅波罗蜜之力得到神通，在一念之间，不从定起，能以花香、珍宝等种种供养，供养十方诸佛。

再者，菩萨以禅波罗蜜之力，变身无数，遍入五道，以三乘之法教化众生。

再者，菩萨进入禅波罗蜜中，除去诸恶不善法，进入初禅乃至非有想非无想定。其心调柔，在每一禅中修行大慈大悲；以慈悲的因缘，拔除无量劫中的罪；因为得到诸法实相的智慧，所以为十方诸佛以及大菩萨所护念。

再者，菩萨进入禅波罗蜜中，以天眼观察十方五道中的众生：

见到生在色界中的，享受禅定的乐味，又堕入禽兽之中受种种苦。

又见到欲界诸天，在七宝池中以花香自娱，后来堕入咸水、沸屎地狱中。

见到人中多闻、有世俗智慧、善辩聪明的人，因为没有得道，又堕入猪羊畜兽之中，一无所知。

像这样等等种种，失去大乐、得到大苦，失去大利、得到大衰，失去尊贵、得到卑贱。对这些众生生起悲心，渐渐增长扩大，成就大悲；为了众生，不惜身命，勤修精进，以求佛道。

### 十一、释“不乱不味”

再者，因为不乱、不味，所以名为禅波罗蜜。如佛告诉舍利弗：“菩萨住在般若波罗蜜中，具足禅波罗蜜，因为不乱、不味。”

问：什么名为乱？

答：乱有两种：一是微细的，二是粗显的。

“微细的”，有三种：一是爱多，二是慢多，三是见多。

什么是爱多？得到禅定之乐，其心乐着而爱其味。

什么是慢多？得到禅定时，自认为难事已经办到，因而自高。

什么是见多？以我见等入禅定，分别取相，认为“这是真实的，其余都是虚妄之语”。

这三种，名为微细的乱。

因为这些因缘，从禅定中退失，生起三毒，这是粗显的乱。

“味”，是最初得到禅定时，一心爱着，这是味。

问：一切烦恼都能使人染着，为什么只把爱名为味？

答：爱与禅相似。为什么？禅是收摄其心坚固安住，爱也是专注执着难以舍弃。又最初求禅时，心中专一想要得到，爱的本性就是想要快乐而专心求取，欲与禅定不相违背。既已得到禅定，深深执着不舍，就破坏了禅定。譬如布施给人东西，一定希望得到现报，就没有福德；在禅中受其味，爱着于禅，也是这样。所以只把爱名为味，不把其余结使名为味。

## 本卷要义

本卷释“不乱不味故，应具足禅波罗蜜”。开篇一问极为切要：菩萨以度众生为事，为何闲坐林泽、独善其身？论主答以服药将身之喻，并点出一个次第：施、戒、忍是福德门，所得是天上人间的无常之乐，乐尽还苦；常乐涅槃从实智慧生，实智慧从一心禅定生，如灯在风中不能照物，置于密室其用乃全。菩萨离众入禅，正是为了带着智慧回到众生中去。

修禅方便是“却五事，除五法，行五行”。呵五欲一段，论主用的几乎全是故事：沙弥嗅龙宫残饭而发愿作龙，比丘过莲池闻香被池神呵为“偷香”，爱酪沙弥生在残酪瓶中，太子贪香果而食毒果死，一角仙人被扇陀以欢喜丸、美酒与细滑之触破了五通。触欲讲得最重，因为其余四根各当其分，触则遍满身识，观不净也难离。池神说白布上的一点墨众人皆见，黑衣上的墨无人过问，这比喻正好落在修禅者身上：越是清净处，一点染着越显。

从初禅到非想非非想处，论主依经依偈，把每一地的舍离理由讲得清楚：觉观虽善而扰乱定心，如清水起波；喜随得失而转为忧；三禅之乐世间第一，因而能生执着，仍是动；第四禅舍念清净，只有不动的智慧；四空定则一层层观所缘的受想行识如病如痈，无常苦空无我，直到非想非非想处，凡夫以为是涅槃，佛法知其仍有微细之想。其后大段阿毗昙分别，论主照录，却以一问收住：这些都只是禅，何以名波罗蜜？

禅成为波罗蜜，论主给出的标准始终如一：怜悯众生自有禅定内乐而向外求乐，如大富盲人坐拥伏藏而行乞；不受味、不求报、不随报生，以智慧方便还生欲界；尽行诸禅而不忘昆虫，如螺髻仙人入定待鸟子飞去。二乘无大悲且不能尽行诸禅，外道有味着、邪见、憍慢三患，声闻慈悲薄而独善其身。超越三昧的自在、紧陀罗王琴声动大迦叶、象王渡水足迹不可见，都在说菩萨禅的深广不可测度。

全卷的落点在“乱定不二”。余人除乱求定，于乱生瞋、于定生着：郁陀罗伽求禅被鸟鸣鱼斗所扰，发恶誓而后生为飞狸；比丘以四禅为四果，临终见四禅中阴便谤佛无涅槃，堕入阿鼻。菩萨则观贪欲不内不外、不从先世来、不先不后、与贪欲者不一不异，无生无灭，所以于五盖无所舍，于禅相无所取，五盖实相即是禅实相。卷末释“不乱不味”，把乱分为爱、慢、见三种微细乱与退禅起三毒的粗乱，又说爱之所以独名为味，因为它与禅相似：都是专心坚住，所以最能从禅的内部坏禅。
