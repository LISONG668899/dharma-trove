# 龙树之歌

阿阇黎龙树造　据藏文译出

## 题解

本篇收于德格版丹珠尔续部释 ཟི 函第 10a 页（东北目录 D2373）。开头没有梵藏题名与礼敬，跋语作"龙树之歌，圆满"，没有记载译者。这里的龙树，一般认为是密乘传统中的成就者龙树，与中观论师龙树是否同一人，藏地传统多视为同一人，学界有不同看法，这里不作断定。本站已译他名下的《自性不成立口诀》（D2382）。

全篇约十五句，共五段：先说住于空性、以悲心为自性，一切方便智慧如同影像；然后以密乘会供的象征语言说"食世俗之肉，饮空性之酒"；明说此义只对有缘者开示，对无缘者要极为保密；以解脱之香涂身，不作意净与不净；最后说进入秘密坛城，方便智慧结合不断，不舍俱生之女。

关于密乘内容的特别告诫：本篇第二、四、五节，全部是无上瑜伽续会供、圆满次第与事业手印的象征语言，第三节原文明说要对无缘者保密。"肉""酒""旃陀罗女"等，都不可照字面理解。这类修法只能在具德上师座前，依具足的灌顶与口授领受，读者只可了解其义，绝不可揣测或效仿。

体例：藏文原文全部保留在代码框中，按段落分节，每节后附汉译。凡标"存疑"的按语，表示本译对原文意思没有把握。藏文依 Esukhia 德格丹珠尔电子版。

## 一、住空具悲，知如影像

```
སྟོང་པ་ལ་གནས་སྙིང་རྗེའི་བདག་ཉིད་ཅན། །
ཞིང་ན་བཞུགས་པའི་ཐབས་དང་ཤེས་རབ་ཚོགས། །
གཟུགས་བརྙན་ལྟ་བུར་ཤེས་པར་བྱ། །
སྙིང་རྗེའི་རོ་ཡིས་ཐ་དད་རྩོད་པ་སྤངས། །
```

安住于空性，以悲心为自性的人，对于安住于刹土中的方便与智慧之聚，要了知它们如同影像；以悲心之味，断除差别之争。

【按】第一段立下全篇的根本：空性与悲心不二；一切方便与智慧，都如影像般无实。以下说到的"肉""酒""涂香""秘密坛城"，都要在这个见地的摄持下理解。

## 二、食世俗之肉，饮空性之酒

```
དེར་ནི་ཀུན་རྫོབ་ཡུལ་གྱི་ཤ་རྣམས་བཟའ། །
ཤིན་ཏུ་རྣམ་དག་སྟོང་པའི་ཆང་ནི་བཏུང། །
```

在那里，吃世俗境界的肉，喝极为清净的空性之酒。

【按】"世俗境界的肉"与"空性之酒"，是密乘会供的象征语言：以受用世俗显现为"食肉"，以安住空性为"饮酒"。这里的重点在于"世俗境界"与"空性"，不是劝人饮酒食肉。

## 三、对有缘者说，对无缘者密

```
སྐྱེ་འགྲོ་སྐལ་ལྡན་རྣམས་ལ་དོན་འདི་བསྟན། །
སྐལ་མེད་རྣམས་ལ་ཤིན་ཏུ་གསང་བར་བྱ། །
```

对有缘的众生开示这个意义，对没有缘分的人，要极为保密。

【按】这两句明说：本篇所说是密法，不可向无缘者宣说。读者只可了解其义，不可照字面理解或效仿。

## 四、涂解脱之香，随意受用

```
རྣམ་ཐར་བྱུག་པས་ཕྱི་ནང་བརླན་བྱས་ལ། །
ཡུལ་གྱི་ལོངས་སྤྱོད་ལ་ནི་ཅི་བདེར་སྤྱད། །
ཕན་ཚུན་འགྲོ་དང་འོང་བའི་ཆོས་རྣམས་ལ། །
དག་དང་མ་དག་ཡིད་ལ་མི་བྱའོ། །
```

以解脱的涂香，润泽内外，对于境界的受用，随意享用；对于来来往往的诸法，不去作意净与不净。

【按】"不作意净与不净"，是密乘的见地：在空性与悲心的摄持下，不执著净与不净的分别。这是就证悟者而说的，有特定的前提。

## 五、入秘密坛城，不舍俱生之女

```
བྱང་ཆུབ་སེམས་ཀྱི་ཕྲེང་བས་རྣམ་བརྒྱན་ལ། །
གསང་བའི་དཀྱིལ་འཁོར་ནང་དུ་འཇུག་བྱ་སྟེ། །
ཐབས་དང་ཤེས་རབ་སྦྱོར་བ་རྒྱུན་མི་འཆད། །
ལྷན་ཅིག་སྐྱེས་པའི་གཡུང་མོ་མི་སྤང་ངོ། །
```

以菩提心之鬘庄严，进入秘密的坛城；方便与智慧的结合相续不断，不舍弃俱生的旃陀罗女。

【按】"秘密坛城""方便与智慧的结合""俱生的旃陀罗女"（ལྷན་ཅིག་སྐྱེས་པའི་གཡུང་མོ），都是无上瑜伽续圆满次第与事业手印的象征语言。"旃陀罗女"在印度成就者的道歌中，常象征俱生智或明妃。这类修法只能在具德上师座前，依具足的灌顶与口授领受，第三节已明说要对无缘者保密，读者绝不可照字面揣测或效仿。

## 跋语

```
ཀླུ་སྒྲུབ་ཀྱི་གླུ་རྫོགས་སོ། །
```

龙树之歌，圆满。

## 通篇连读

安住于空性，以悲心为自性的人，对于安住于刹土中的方便与智慧之聚，要了知它们如同影像；以悲心之味，断除差别之争。

在那里，吃世俗境界的肉，喝极为清净的空性之酒。

对有缘的众生开示这个意义，对没有缘分的人，要极为保密。

以解脱的涂香，润泽内外，对于境界的受用，随意享用；对于来来往往的诸法，不去作意净与不净。

以菩提心之鬘庄严，进入秘密的坛城；方便与智慧的结合相续不断，不舍弃俱生的旃陀罗女。
