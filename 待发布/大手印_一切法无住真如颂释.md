# 一切法无住真如颂释

吉祥阿瓦都底足造　据藏文译出

## 题解

《显示一切法极无住之真如半颂释》（藏 chos thams cad rab tu mi gnas par ston pa'i de kho na nyid tshigs su bcad pa phyed kyi 'grel pa）收于德格版丹珠尔续部释 ཞི 函第 214b 至 226b 页（东北目录 D2296）。卷首题名作"颂释"（ཚིགས་སུ་བཅད་པ་བྱེད་ཀྱི་འགྲེལ་པ），跋文作"半颂之释"（ཕྱེད），从正文看，所解释的正是开头两句半颂，"བྱེད"应是"ཕྱེད"之误。本译标题沿用"颂释"之名。

作者与传承：跋文说是"吉祥阿瓦都底足所作"。阿瓦都底巴（Avadhūtipa）一般认为是梅纪巴（Maitrīpa）的别名。第三十三节作者自述，这部论是"在南方的森林中，从吉祥夏瓦日金刚座前得到的"，与相传梅纪巴往南方师从夏瓦日巴之说相合；但本篇没有直接说明作者即梅纪巴，仍存疑。本篇没有译者跋语。

所释的半颂：全篇只解释两句："因生之智，如大象；摧伏它的狮子，是我的论。"作者以"大象与狮子"的比喻层层展开，显示从不了义到了义的次第：

在显教方面，瑜伽行派主张由他因而生的无二之识实有，能摧伏外境实有论者，所以如大象；但它仍执内识为实有，所以被说"一切法极无住"的中观这头狮子所摧伏。

在密咒方面，主张俱生喜在第四的"强行派"与虽主张第三却执体验为实的"不善灌顶者"，如未调伏之象；"善巧灌顶者"虽能摧伏前二者，但只依业手印，也仍是可被摧伏的大象。真正的狮子，是以大手印、第四灌顶为了义，把灌顶中的坛城、瓶水、秘密灌顶、智慧母、莲花、金刚、俱生喜等一切，都解释为"如金刚的菩提心"本身。

全篇纲领：开头第二节与结尾第三十六节，都以"自性、修法、获得"三者为纲：一切法的自性是无生与平等；修法是无颠倒地证悟并熟习；获得是成为把握而不再退转。

本篇的立场：作者明确说，他所依止的上师们不认为依业手印是真实之道；只把业手印看作道，是外道与魔的道理；持三律仪的初业梵行者，未得稳固之前不应趣入；比丘持金刚最为殊胜，出家律仪连一支也不可损坏。同时他也说，对已证悟的殊胜之人，烦恼可以成为菩提之支，并警告不可毁谤密续中的双运之法。第二十八节所引的长篇续文，预言末世自称"行瑜伽者"的种种堕落之相，是作者所警诫的反面。

与汉地经典的关系：本篇有两处引文与汉译经典高度吻合，值得注意。第十四、十五节所引魔业经文，与《楞严经》卷九"五十阴魔"中"口中好言眼耳鼻舌皆为净土，男女二根即是菩提涅槃真处""近则九生，多逾百世""失正遍知，堕无间狱"等文句非常接近；藏文大藏经中收有从汉文转译的《楞严经》部分品段，这里很可能引自该经。第十八节所引"续"文，与《大日经·入真言门住心品》"得一切智智已，为无量众生广演分布……而此一切智智道一味，所谓如来解脱味"一段几乎逐句相合。按语中都附有汉译原文以资对照。

与已译各篇的关系：第八节所批评的"强行派"与"不善灌顶者"，与已译的《四印口诀》（D2295）中的"猛厉派"与"劣派"完全对应；关于俱生喜居第三的立场，也与已译的《灌顶教示》（D2252）、《灌顶教示难释》（D2253）一致，可以互相参看。本篇与已译各篇没有重复。

关于密乘内容的告诫：本篇多处讨论业手印、灌顶、明点、风息等无上瑜伽续的隐秘内容，所引续文中的"妓女""精液""颅器"等，都是密语，作者自己也以了义解释为空性与菩提心，不可照字面理解。凡涉及修法之处，只能在具德上师座前，依具足的灌顶与口授领受，绝不可依文字自行理解或模仿。原文第 523–524 句，依本译体例略去不译，另附的藏文底本相应两句也以［略］标出。

体例说明：各节标题后括号中的句号，对应另附的《一切法无住真如颂释_藏文底本.txt》中的编号。藏文原文放在代码框中，其后按完整的意义单元译出。按语中凡标"存疑"的，表示本译对原文意思没有把握，读者宜依上师与其他译本审定。

## 三、瑜伽行派之见如大象（第 14–35 句）

```
དེ་ལ་རྣལ་འབྱོར་སྤྱོད་པའི་གཞུང་གིས།
```

瑜伽行派的论典说：从他因所生的胜义之法——由教与理所成立的、有显现或无显现的自性，是一切法的基础与所依，是无二之智，是［以能取所取］观察而空的，相续不断，因离开四边而是中道——只有这个是真实存在的；修法与果也是如此。

```

ཅིའི་ཕྱིར་ཞེ་ན།
ཕྱི་རོལ་གྱི་དོན་ཡོད་པར་སྨྲ་བའི།
མུ་སྟེགས་དང་ཉན་ཐོས་དང་།
མདོ་སྡེའི་གཞུང་རྣམས་ཕལ་ཆེར་ལུང་རིགས་ཀྱི་ཆེ་བས་འཇོམས་པར་ནུས་པ་དང་།
རྣམ་པར་ཤེས་པ་ནི་སངས་རྒྱས་པའི་ཆོས་རྣམས་ཀྱི་ལུས་སུ་གྱུར་པས།
ཡེ་མི་བཞེད་པ་མ་ཡིན་པའི་ཕྱིར་བསྟོད་པའོ། །
```

这就像大象。为什么呢？主张外境实有的外道、声闻与经部的论典，大多能被它以教理之大力摧伏；而且识是佛法的身体，［中观者］也并非完全不承认，所以加以赞叹。

```
འོན་ཀྱང་ཤེས་བྱ་ནང་གི་དངོས་པོ་ལྟ་བས་ན་དེ་ཉིད་ཀྱང་།
གཞོམ་དུ་རུང་བའི་ཕྱིར་གླང་པོ་ཆེ་དང་འདྲའོ། །
```

然而，因为它把所知视为内在的实有之物，所以它本身也是可以被摧伏的，因此像大象。

```
གང་གིས་འཇོམས་པར་བྱེད་ཅེ་ན།

```

以什么来摧伏它呢？因为以说"极无住"的中观——如狮子般的、极为猛利的教理之牙，来摧伏它。

【按】"因生之智"（རྒྱུ་སྐྱེས་ཡེ་ཤེས），指瑜伽行派所主张的、从他因而生（依他起）的无二之识。"极无住"（རབ་ཏུ་མི་གནས་པ，梵 sarvadharmāpratiṣṭhāna），是梅纪巴一系所说的最高中观，已译的《四印口诀》（D2295）、《真如宝鬘》等篇中也有说明。本篇的比喻是：瑜伽行派能摧伏外境实有论者，所以如大象；但它仍执内识为实有，所以又被极无住中观这头狮子所摧伏。

```
སེམས་ཙམ་ལས་མེད་པའི་ཕྱིར་རོ། །
```

［其二，］有人想："［佛］显示一切法除了唯心之外别无他物之法。"为什么呢？由于把种种法施设为恒常坚固的习气安置于心中的力量，在一切时中虽然显现为我与诸法的差别，但在胜义中没有自性，因为只是心而已。

```
ཁ་ཅིག་གིས་ནི་སེམས་ཉིད་ཀྱང་མ་སྐྱེས་པ་ཡིན་པར་བདག་ཅག་ལ་ཆོས་སྟོན་ཏོ་སྙམ་པའང་ཡིན་ཏེ།
དེ་ཅིའི་ཕྱིར་ཞེ་ན།
འདི་ལ་དབྱིབས་སམ།
ཁ་དོག་གམ།
དུས་གསུམ་མམ།
མཐའ་དབུས་མེད་པའི་ཕྱིར་རོ། །
```

［其三，］有人想："［佛］为我们显示心本身也是无生之法。"为什么呢？因为它没有形状，没有颜色，没有三时，没有边与中。

```
ཁ་ཅིག་གིས་ནི་ཆོས་ཐམས་ཅད་སྒྱུ་མ་བཞིན་དུ་སྣང་ཞིང་སྒྱུ་མ་བཞིན་དུ་མ་གྲུབ་པའི་ཆོས་སྟོན་ཏོ་སྙམ་པའང་ཡིན་ཏེ།
དེ་ཅིའི་ཕྱིར་ཞེ་ན།
ཆོས་ཐམས་ཅད་ནི་རྒྱུ་དང་རྐྱེན་ལས་སྐྱེ་ཞིང་འབྱུང་བའི་ཕྱིར་རོ། །
```

［其四，］有人想："［佛］显示一切法如幻显现、如幻不成立之法。"为什么呢？因为一切法都从因与缘而生起、出现。

```
ཁ་ཅིག་གིས་ནི་ཆོས་ཐམས་ཅད་རང་བཞིན་གྱིས་མ་སྐྱེས་པ།
ངོ་བོ་ཉིད་ཀྱིས་མི་གནས་པ།
ལས་དང་བྱ་བའི་མཐའ་ཐམས་ཅད་དང་བྲལ་བ།
རྟོག་པ་དང་མི་རྟོག་པར་ཡུལ་ལས་འདས་པ་ཐོག་མ་མེད་པའི་དུས་ནས་སྤྲོས་པ་རྣམ་པར་དག་པའི་ཆོས་སྟོན་ཏོ་སྙམ་པའང་ཡིན་ཏེ།
དེ་ཅིའི་ཕྱིར་ཞེ་ན།
ཆོས་ཐམས་ཅད་རང་གི་ངོ་བོ་ཉིད་ཕྱིན་ཅི་མ་ལོག་པ་དེ་ཡིན་པའི་ཕྱིར་རོ་ཞེས་གསུངས་སོ། །
```

［其五，］有人想："［佛］显示一切法自性无生、体性无住、离开一切业与作的边际、超越分别与无分别之境、从无始以来离戏论而清净之法。"为什么呢？因为那就是一切法不颠倒的自体。——这样说了。

```
དེ་ལས་གཞན་བགྲང་མི་དགོས་སོ། །
```

此外不必再列举了。

【按】所引经文的出处待考，存疑。这五种观法，依次对应：名言中如幻而有、唯心、心亦无生、如幻不成立、一切法极无住，大致是从世俗有到极无住中观的层层上升。

## 五、理证：缘起故如幻，胜义中如空花（第 69–77 句）

```
རིགས་པ་གང་ཞེ་ན།
བདག་ཉིད་ཆེན་པོ་རྣམས་ཀྱིས་སྔོན་དུ་ལེགས་པར་བཀོད་པའི་གང་དག་ཡོད་པར་གྲགས་པའི་ཆོས་ཐམས་ཅད་རྟེན་ཅིང་འབྲེལ་པར་འབྱུང་བ་ཙམ་ལས་བྱུང་བའི་ཕྱིར།
སྒྱུ་མ་ལྟ་བུའོ་ཞེས་བྱ་བ་དང་།
དེ་ཉིད་ཀྱིས་དོན་དམ་པར་ན་རང་དང་གཞན་དང་གཉིས་ཀ་དང་རྒྱུ་མེད་པ་ལས་སྐྱེ་བ་ནམ་ཡང་མི་འཐད་པའི་ཕྱིར་དོན་དམ་པར་ནམ་མཁའི་པདྨ་ལྟ་བུའོ་ཞེས་བསྟན་པ་འདི་ཁོ་ནས་ཆོག་སྟེ།
ཤེས་རབ་ཀྱི་མིག་དང་ལྡན་པ་རྣམས་ཀྱིས་རང་བཞིན་གྱི་གཏན་ཚིགས་འདི་ཁོ་ནའི་སྒོ་ནས་དྲང་པོར་ཞིབ་ཏུ་བལྟས་ན།
མཐར་ཅི་ཡང་གྲུབ་པ་མ་རྙེད་པས།
ཆོས་ཐམས་ཅད་རབ་ཏུ་མི་གནས་པར་མ་གྲུབ་པའོ། །
```

理证是什么呢？诸大士先前善为安立的：凡是被认为存在的一切法，因为只是从缘起而生，所以如幻；也正因为如此，在胜义中，从自、从他、从二者、从无因而生，都决不合理，所以在胜义中如同空中之莲花——只要这样显示就足够了。具有智慧之眼的人，若仅仅从这个自性因之门直接细看，最终找不到任何成立之物，所以一切法以极无住而不成立。

```
གཏན་ཚིགས་མ་གྲུབ་པ་ལ་སོགས་པའང་མ་ཡིན་ཏེ་མང་དུ་བརྗོད་མི་དགོས་སོ། །
དེ་ཉིད་ཀྱིས་ཕྱིན་ཅི་ལོག་གི་གཞུང་མ་ལུས་པར་ཡང་ཆོམས་པར་འགྱུར་ཏེ།
```

这也没有"因不成"等［过失］，不必多说。也正因此，一切颠倒的论典都将被摧毁。

【按】"从自、从他、从二者、从无因而生都不合理"，即龙树《中论》开头所说的四不生。"自性因"（རང་བཞིན་གྱི་གཏན་ཚིགས），因明术语，指以法的自性为理由的推理。

## 六、偈颂：破诸种生论（第 78–97 句）

```
འདིར་ཚིགས་སུ་བཅད་པ།
```

这里有偈颂说：

```
ལྟོས་མེད་བདག་ལས་སྐྱེ་འདོད་ན། །
རྟག་པར་རྒྱུར་སྨྲ་གྲངས་ཅན་པ། །
རྒྱུ་གཞན་དག་ལས་སྐྱེ་འདོད་ན། །
བྱེད་པ་རྒྱུར་སྨྲ་བྱེ་བྲག་པ། །
གཉིས་ཀ་ལས་ནི་སྐྱེ་འདོད་ན། །
དབང་ཕྱུག་རྒྱུར་སྨྲ་གཅེར་བུ་པ། །
སྐྱེ་བ་མེད་ལས་སྐྱེ་འདོད་ན། །
རང་བཞིན་རྒྱུར་སྨྲ་རྒྱང་པན་པ། །
སྐྱེས་པ་སྟོང་བར་འགྱུར་འདོད་ན། །
ནམ་མཁའི་ཡིད་ཅན་ཆད་པའི་ལམ། །
གང་ཡང་ཁས་མི་ལེན་གྱུར་ན། །
ངན་གཡོ་རྨོངས་པའི་ལྟ་བ་སྟེ། །
```

若主张从不观待［他］的自体而生，是说常法为因的数论派；若主张从他因而生，是说作者为因的胜论派；若主张从二者而生，是说自在天为因的裸形派；若主张从无生而生，是说自性为因的顺世派；若主张生了之后成为空，是"虚空意者"的断灭之道；若什么都不承认，是诡诈愚痴之见。

```
རང་བཞིན་གྲུབ་དང་མ་གྲུབ་དང་། །
གཞན་ནི་རྟག་དང་མི་རྟག་ལས། །
བརྟགས་ན་སྐྱེ་བ་མི་འཐད་ཕྱིར། །
དེ་བཞིན་རེས་འགའ་བ་ཉིད་ཕྱིར། །
འདི་ཀུན་རྟེན་ཅིང་འབྲེལ་འབྱུང་ཚུལ། །
སྤྲོས་པའི་མཐའ་ཀུན་གདོད་ནས་ཞི། །
ཞེས་བྱའོ། །
```

因为观察：［自体］自性成立或不成立、他者是常或无常，［从中］生起都不合理；又因为［生起］只是偶尔的，所以这一切都是缘起之理，一切戏论之边本来寂灭。——这样说。

【按】这一段把"自生、他生、共生、无因生"等主张分别配给数论、胜论、裸形派（耆那教）、顺世派等，配法与通常的说法不尽相同，依原文译出，存疑。"虚空意者"（ནམ་མཁའི་ཡིད་ཅན），所指不明，可能是某一断灭论者的名称，存疑。

## 七、"我之论"的意思（第 98–101 句）

```
དེས་ན་ཆོས་ཐམས་ཅད་ཡང་དག་པར་མ་སྐྱེས་པས།
ཡིད་ལ་བྱར་མེད་ཅིང་།
གང་ལ་ཡང་སྨིན་དུ་མེད་པ་ནི།
བདག་གི་གཞུང་ཞེས་བྱའོ། །
```

所以，一切法真实无生，因此无可作意，对任何［法］也无所成熟——这就称为"我之论"。

【按】"无可作意"（ཡིད་ལ་བྱར་མེད，梵 amanasikāra），是梅纪巴一系大手印"无作意"之说的关键词。"无所成熟"（གང་ལ་ཡང་སྨིན་དུ་མེད），意思不很确定，存疑。

## 八、密咒中的对应：强行派与不善灌顶者如未调之象（第 102–115 句）

```
ཡང་དག་གི་དོན་དེ་ཉིད་ནི།
གསང་སྔགས་ཀྱི་གཞུང་དུ་ནི།
ལས་ཀྱི་ཕྱག་རྒྱ་ལས་གྲུབ་པ། །
ལྷན་ཅིག་སྐྱེས་པའི་དགའ་བར་འདོད་དོ། །
```

那真实之义，在密咒的论典中，［有人］认为是从业手印所成就的俱生之喜。

```
དེ་ཡང་ལྷན་ཅིག་སྐྱེས་པའི་དགའ་བ་བཞི་པ་ལས་འདོད་པ་ནི།
དགའ་བྲལ་གྱི་དང་པོ་ལ་སོགས་པར་འབྱུང་བའི་ལུང་དང་།
དགའ་བྲལ་ནི་རྗེས་ཐོབ་དྲོད་ཀྱི་ཤེས་པ་ཞེས་བྱ་བ་ལ་སོགས་པའི་རིགས་པ་དང་།
མངོན་སུམ་དང་འགལ་བའི་ཕྱིར་བཙན་ཐབས་ལ་ཞེས་བྱའོ། །
```

其中，主张俱生喜在第四的，与"离喜之初"等所出的经教、与"离喜是后得的暖之识"等理、以及与现量相违，所以称为"强行派"。

```
ཡང་ལྷན་ཅིག་སྐྱེས་པའི་དགའ་བ་གསུམ་པ་ལ་འདོད་ཀྱང་།
དོན་གྱིས་གནས་སྦས་པ་ལ་མངོན་པར་རྨོངས་པས་མུ་སྟེགས་ཀྱི་གཞུང་དང་ཁྱད་པར་མེད་པའི་ཕྱིར་དང་།
རྡོ་རྗེ་སེམས་དཔའི་ཕྱག་རྒྱ་དང་བྲལ་བའི་ཕྱིར་དང་།
མངོན་སུམ་དང་འགལ་བའི་ཕྱིར།
དབང་ལ་མི་མཁས་པ་ཞེས་བྱའོ། །
```

又，［有人］虽然主张俱生喜在第三，但实际上对于隐秘之处显然愚昧，所以与外道的论典没有差别，又离开了金刚萨埵之印，又与现量相违，所以称为"不善灌顶者"。

```
དེ་གཉིས་ནི་རྣམ་པར་མ་སྦྱངས་པའི་གླང་པོ་དང་འདྲའོ། །
```

这二者，就像未经调伏的大象。

【按】这一节与已译的《四印口诀》（D2295）第十一、十二节所说的"猛厉派"与"劣派"完全对应：前者把俱生喜排在第四，后者虽排在第三却执体验为实。"离喜是后得的暖之识"，意思是离喜属于后得位，所以不应是最后的俱生，存疑。

## 九、善巧真实灌顶者（第 116–153 句）

```
ཡང་།
དགའ་བྲལ་དང་པོ་མཆོག་གི་མཐའ། །
ཞེས་བྱ་བ་ལ་སོགས་པའི་ལུང་དང་།
བཅོམ་ལྡན་འདས་ཀྱི་སྐུའི་བརྡ་དང་།
གཞུང་གཞན་ཁེགས་པའི་རིགས་པ་དང་།
བརྒྱུད་པའི་མན་ངག་དང་།
རང་རིག་པའི་མངོན་སུམ་གྱིས་ཤིན་ཏུ་ཕྲ་བའི་སྐད་ཅིག་གིས་གསུམ་པ་ལ་ལྷན་ཅིག་སྐྱེས་པའི་དགའ་བ་རྙེད་པ་ནི།
ཡང་དག་པའི་དབང་ལ་མཁས་པ་ཞེས་བྱའོ། །
```

又，依"离喜之初、胜喜之末"等经教，依薄伽梵身的表示，依遮除他宗的理，依传承的口诀，［以及］以自证现量，在极细微的刹那，于第三［喜］得到俱生之喜——这就称为"善巧真实灌顶者"。

```
དེ་ཉིད་རྣལ་འབྱོར་ཆེན་པོ་དང་།
རྣལ་འབྱོར་མའི་རྒྱུད་ལས།
མུན་པ་ལ་ནི་མར་མེ་ལྟར། །
ཞེས་བྱ་བ་ལ་སོགས་པའི་དཔེ་སྣ་ཚོགས་ཀྱིས་བསྒྲུབ་པ།
གསང་སྔགས་རྡོ་རྗེ་ཐེག་པའི་ངེས་པའི་ཚིག་ཏུ་གཞག་པ།
ཕ་རོལ་ཏུ་ཕྱིན་པའི་ཐེག་པ་ལས་ཐབས་ཁྱད་པར་དུ་གྱུར་པ།
སྐལ་བ་དང་ལྡན་པའི་སྤྱོད་པའི་ཡུལ།
དགྱེས་པའི་རྡོ་རྗེ་དང་།
དམ་པ་དང་པོ་དང་།
ཟླ་གསང་ཐིག་ལེ་ལ་སོགས་པའི་རང་བཞིན་དུ་གྱུར་པའོ། །
```

这在大瑜伽续与瑜伽母续中，以"如黑暗中的灯"等种种譬喻成立，被安立为密咒金刚乘的决定之语，方便胜过波罗蜜多乘，是具缘者的行境，成为《喜金刚》《第一胜》《月密明点》等［续］的自性。

```
དེ་ལྟར་དེ་བཞིན་བཞི་པ་ཡང་། །
ཞེས་འབྱུང་བས།
སྒྲུབ་པའི་ཐབས་དང་།
གྲུབ་པའི་རང་བཞིན་ཡང་དེ་བཞིན་དུ་ཤེས་པར་བྱའོ་ཞེས་ཟེར་རོ། །
```

［续中］说"如是第四亦然"，所以，修法的方便与成就的自性，也要同样了知——这样说。

```
ཤེས་རབ་ཡེ་ཤེས་ཀྱི་དབང་དག་གི་སྤྱིར་ཁྱབ་པའི་མན་ངག །
ཕྱག་རྒྱ་ཉེ་བར་བརྟགས་པ་དང་།
ལས་ཀྱི་གོ་རིམ་དང་།
རྣམ་པ་དང་།
དཔེ་དང་།
གནས་དང་།
བརྡ་དང་།
སའི་རིམ་པ་གང་ཐོབ་པ་ལ་སོགས་པ་ནི།
བདག་གིས་གསལ་བར་ཤེས་མོད་ཀྱི། །
འདིར་བརྗོད་པའི་དགོས་པ་མེད་དོ། །
```

智慧智灌顶的普遍口诀——手印的观察、事业的次第、相、喻、处、表示、所得之地的次第等，我虽然清楚知道，这里没有必要说。

```
དེ་ལྟར་ཡང་དག་པའི་དབང་ལ་མཁས་པས་ནི།
བཙན་ཐབས་དང་།
དབང་ལ་མི་མཁས་པའི་གཞུང་དག་ལུང་རིགས་ཀྱི་མཆེ་བས་འཇོམས་པར་ནུས་པ་དང་།
ཐབས་ཀྱི་ཐེག་པའི་ལུས་སུ་གྱུར་པའི་ཕྱིར། །
གླང་པོ་ཆེ་དང་།
བརྡའོ་ཞེས་བསྟོད་པའོ། །
```

这样，善巧真实灌顶者，能以教理之牙摧伏强行派与不善灌顶者的论典，并且成为方便乘的身体，所以被赞为"大象"与"表示"。

【按】"薄伽梵身的表示"，可能指本尊身相所表示的义理，存疑。"《第一胜》"（དམ་པ་དང་པོ，梵 Paramādya）、"《月密明点》"（ཟླ་གསང་ཐིག་ལེ，梵 Candraguhyatilaka），都是密续名。"被赞为'大象'与'表示'"，原文 གླང་པོ་ཆེ་དང་བརྡའོ，"表示"一词与上下文关系不明，可能有讹文，存疑。这里的意思是：善巧灌顶者在密咒范围内也像大象，能摧伏前两派，但下文说它仍可被摧伏。手印、事业次第等都属业手印的隐秘修法，作者自己也说"不必在这里说"，须依灌顶与口授。

## 十、方便：以虚妄之道引入真实之道（第 154–172 句）

```
ཐབས་གང་ཞེ་ན།
རྫུན་པའི་ལམ་གྱིས་བསླུས་ཏེ།
ཡང་དག་པའི་ལམ་ལ་སྦྱོར་བའོ། །
```

方便是什么呢？以虚妄之道引诱，使之趣入真实之道。

```
གང་སླུ་ཞེ་ན།
ཐེག་པ་གཞན་ལས་ཡངས་པ་དང་། །
གཞན་ནས་འཇུག་པ་དང་།
ཐ་མལ་པ་དང་།
ཚངས་པར་སྤྱོད་པའོ། །
```

引诱谁呢？从他乘中出离的（？）、从别处趣入的、凡俗之人，以及梵行者。

```
ཇི་ལྟར་སླུ་ཞེ་ན།
དང་པོ་གསུམ་ནི་སྡོམ་པ་ཡང་དག་པར་བླངས་པ་གཏོང་བའི་ཉེས་པ་མེད་པས།
སྤྱོད་ཡུལ་དངོས་ལ་སྦྱོར་བའམ། །
ཡང་ན་སློབ་དཔོན་དང་འགལ་ན། །
ཐབས་གཞན་གྱིས་བཟུང་སྟེ།
རེ་ཞིག་དམན་པའི་ཡུལ་ལས་མི་བཟློག་པར་ཅི་རིགས་པའི་སྒྲར་བསྟན་པའོ། །
```

怎样引诱呢？对前三种人，由于没有舍弃已正受之律仪的过失，［就］使之与实际的行境相结合；或者，如果违背了阿阇黎，就以其他方便来摄持，暂且不遮止下劣之境，以适当的言词为他开示。

```
ཚངས་པར་སྤྱོད་པ་ནི།
དེ་དང་ཆོས་མཐུན་པའི་ཐབས་གཞན་གྱིས་བཟུང་སྟེ།
དོན་ས་གཞན་ལ་དྲང་བའམ། །
ཡང་ན་དོན་ཉིད་བཤད་པར་བྱའོ། །
```

对于梵行者，以与之相合的其他方便来摄持，把义理引向其他的地［道］，或者就宣说义理本身。

```
ཡང་དེ་ཉིད་ཡང་དག་པའི་མན་ངག་མ་ཡིན་པའི་གཞོམ་དུ་རུང་བའི་ཕྱིར་གླང་པོ་ཆེའོ། །
```

又，那［善巧灌顶者之说］也因为不是真实的口诀、是可被摧伏的，所以是大象。

【按】"从他乘中出离的"，原文 ཐེག་པ་གཞན་ལས་ཡངས་པ，意思不很确定，存疑。这一节是说：对不同根器、不同戒律身份的人（尤其是持梵行的出家人），上师以不同的方便引导，对持梵行者不用实际的业手印，而以其他方便或直接宣说义理。这些都属于上师观机施教的范围，读者不可据此自行判断。

## 十一、以真实的教、理、口诀如狮子来摧伏（第 173–190 句）

```
ཡང་དག་པའི་འཇོམས་པར་བྱེད་ཅེ་ན།
ཡང་དག་པའི་ལུང་དང་།
རིགས་པ་དང་།
མན་ངག་སེང་གེ་ལྟ་བུས་སོ། །
```

以什么来真实地摧伏它呢？以真实的教证、理证与口诀——如同狮子。

```
དེ་ཡང་།
ལས་ཀྱི་ཕྱག་རྒྱ་འཁོར་རྒྱུ་ཅན། །
ཐག་རིང་རྣམ་པར་སྤང་བར་བྱ། །
ཞེས་འབྱུང་བ་ལ་སོགས་པའི་ལུང་གིས་གསལ་བ་དང་།
```

也就是：以"具有轮回之因的业手印，要远远地舍弃"等所出的教证来阐明；

```
གདུལ་བྱ་ཤིན་ཏུ་དམན་པ་ལ་བསྟན་པའི་ཕྱིར།
དམ་པ་རྣམས་ཀྱིས་སྤང་བར་བྱ་བ་དང་།
ཐབས་གཞན་ཡོད་པའི་ཕྱིར་མ་ངེས་པ་དང་།
ལས་དང་པོའི་ཚངས་པར་སྤྱོད་པ་ལ་མ་གནང་བའི་ཕྱིར།
འགལ་བ་དང་།
རྩོལ་བ་ལས་བྱུང་བའི་ཕྱིར་སྐད་ཅིག་མ་སྟེ་སྟོན་ཀའི་པདྨ་ལྟ་བུའོ་ཞེས་བཀོད་པའི་རིགས་རྣམས་ཀྱིས་བཅོམ་པ་དང་།
```

又以这样安立的诸理来破斥：因为这是为极下劣的所化而说的，所以圣者应当舍弃；因为另有其他方便，所以不是决定［唯一之道］；因为对初业的梵行者不开许，所以相违；因为是从勤作而生的，所以是刹那性的，如同秋天的莲花；

```
ཁུ་བ་རླུང་དུས་སུ་ལྟ་བ། །
ཀྱེ་ཡི་རྡོ་རྗེ་དེས་མི་ཤེས། །
མ་ཡིན་ངེས་དོན་གཞན་དུ་དཔྱད། །
ཅེས་ཡང་དག་པའི་མན་ངག་གཞན་ཡོད་པར་ཁ་འཕངས་པའི་ཕྱིར་རོ། །
```

又因为［续中说］"观于精液与风之时，那位嘿金刚并不了知；这不是了义，要在别处观察"，暗示另有真实的口诀。

【按】"具有轮回之因的业手印，要远远地舍弃"与"观于精液与风之时"等句，出处待考，存疑。"嘿金刚"（ཀྱེ་ཡི་རྡོ་རྗེ），即喜金刚。这一节是全篇的转折：作者明确主张，单以业手印为道，不是真实的了义口诀。

## 十二、只把业手印看作道，是外道与魔的道理（第 191–201 句）

```
མདོར་ན་ཡང་དག་པར་དཔྱད་ན།
ཕྱག་རྒྱ་ཆེན་པོའི་དོན་ནི་མི་ཤེས་པར།
ལས་ཀྱི་ཕྱག་རྒྱ་ལ་ལམ་དུ་མཐོང་བ་མཐའ་དག །
```

```
མི་དག་གིས་ཡིད་ཆེས་པར་བཟུང་ནས།
སྔ་མའི་སེམས་ནི་སྟོར་ཞིང་བརྗེད་ནས།
སྲོག་ལུས་དེར་བསྟན་ཏེ།
ཡོད་མ་མྱོང་བ་ཐོབ་བོ་ཞེས་སོ། །
```

人们信以为真，遗失、忘记了以前的心，在那里献出身命，说"得到了前所未有的"。

```
དེ་ལ་སོགས་པ་ནི་བླུན་ཞིང་འཁྲུལ་པས།
བར་བར་ནི་བྱང་ཆུབ་སྙམ་ནས།
བདག་གི་སེམས་བརྗེད་དེ་སྟོར་ནས།
སངས་རྒྱས་ཀྱི་ཚུལ་ཁྲིམས་ནི་བཤིག །
ལྐོག་ན་གཡེམ་པ་སྤྱོད་དོ། །
ངག་གིས་སྲིད་པ་སྨྲ་སྟེ།
མིག་དང་རྣ་བ་དང་སྣ་དང་ལྕེ་ཀུན་སངས་རྒྱས་ཀྱི་ཞིང་ཡིན་ནོ། །
མོ་མཚན་དང་ཕོ་མཚན་ནི་བྱང་ཆུབ་ཀྱི་ལམ་ཡིན་ཏེ།
ཡང་དག་པའི་མྱ་ངན་ལས་འདས་པ་ནི་སུས་ཀྱང་མི་ཤེས་སོ་ཞེས་པ་དང་།
སྟོང་པའི་སེམས་ཐོབ་སྟེ་རྟེན་ཅིང་འབྲེལ་པར་འབྱུང་བ་མེད་དོ་ཞེས་པ་དང་།
```

这些人愚痴迷乱，有时以为［这就是］菩提，忘失了自己的心，破坏佛的戒律，私下行淫；口中宣说三有，说："眼、耳、鼻、舌都是佛刹，女根与男根是菩提之道，真实的涅槃谁也不知道。"又说："得到了空的心，就没有缘起。"

```
ཡང་ཚིག་ཏུ་ནི་ཕྱོགས་བཅུའི་སེམས་ཅན་ཐམས་ཅད་ངའི་བུ་ཡིན།
བདག་ལ་སངས་རྒྱས་ཐམས་ཅད་སྐྱེས།
ང་ནི་འཇིག་རྟེན་དུ་འབྱུང་།
ང་ནི་ཡེ་ནས་སངས་རྒྱས་པ་ཡིན་ཏེ།
འཇིག་རྟེན་དུ་བྱུང་མོད་ཀྱི་འདུས་བྱས་ལས་སྐྱེས་པ་ནི་མ་ཡིན་ནོ་ཞེས་པ་དང་།
བར་བར་ང་ནི་རྡོ་རྗེ་འཆང་ཡིན་ཏེ།
ཁྱོད་ལ་ཚེ་རིང་བར་བྱའོ་ཞེས་བྱ་བ་ལ་སོགས་པར་འབྱུང་ངོ་། །
```

又说："十方一切众生都是我的儿子，一切佛都从我而生，我出现于世间；我本来就是佛，虽然出现于世间，却不是从有为法所生。"有时说："我是金刚持，让你长寿。"等等。

```
ཡང་དགའ་བོ་བདུད་དེ་དག་ནི་མ་འོངས་པའི་དུས་ཀྱི་ཚེ།
ངའི་གསུང་རབ་ཏུ་འབྱུང་སྟེ།
ཆོས་ཀྱི་ལམ་སྒྲུབ་པའི་མིའི་སེམས་ཀྱི་ལམ་དུ་འཇུག་པར་བྱེད་དོ། །
གཡེམ་པ་སྦྱོར་བ་ལ་བསྟོད་ཅིང་། །
སངས་རྒྱས་ཀྱི་ཚུལ་ཁྲིམས་འཇིག །
སྔར་ནི་མཁན་པོས་བསླུས། །
ཕྱིས་ནི་སློབ་མས་བསླུས་ཏེ་གཡེམ་པ་སྤྱོད་ཅིག་པར་འདེབས་པར་བྱེད་དོ་ཞེས་པ་དང་།
```

又［经中说］："难陀，那些魔在未来之时，会出现在我的教法中，进入修持法道之人的心中；赞叹淫欲之行，破坏佛的戒律；先被堪布所骗，后被弟子所骗，劝人'去行淫欲吧'。"

```
ཡང་།
ཉེ་ན་ཚེ་རབས་དགུ། །
རིང་ན་ཚེ་རབས་བརྒྱའི་བར་དུ་དགེ་བ་སྤྱོད་ཅིང་བདུད་ཀྱི་བཤེས་གཉེན་དུ་འགྱུར་རོ། །
དེ་ནས་ཚེ་བརྗེས་ནས་བདུད་ཀྱི་བྱེ་བྲག་ཏུ་འགྱུར་རོ། །
ཡང་དག་པར་ཁྱབ་པར་ཤེས་པའི་དྲལ་སྟོར་ནས་མཚམས་མེད་པའི་སེམས་ཅན་དམྱལ་བར་ལྟུང་ངོ་ཞེས་འབྱུང་སྟེ།
```

又说："近则九世，远则百世之间，行持善法而成为魔的善知识；然后转世，成为魔的眷属；失去正遍知，堕入无间地狱。"

```
དེ་ལྟ་བུའི་བདུད་ཀྱི་ལས་དག་ཤེས་པར་བྱའོ། །
```

应当了知这样的魔业。

【按】本节所引经文，与汉译《楞严经》卷九所说"五十阴魔"中的文句非常接近，例如经中说魔所附者"口中好言眼耳鼻舌皆为净土，男女二根即是菩提涅槃真处"，又说"近则九生，多逾百世，令真修行总为魔眷"，"失正遍知，堕无间狱"。藏文大藏经中收有从汉文译出的《楞严经》部分品段，这里很可能就引自该经，存疑。"难陀"（དགའ་བོ），依《楞严经》应是阿难（藏文一般作 ཀུན་དགའ་བོ），这里可能是省称或讹误，存疑。本节所述种种邪说（饮酒食肉行淫、以男女根为菩提道、自称本来是佛等），都是作者所破斥的魔业。

## 十五、以空悲无别的菩提心对治魔业（第 315–321 句）

```
དེ་ཡང་སྟོང་པ་དང་སྙིང་རྗེ་དབྱེར་མེད་པའི་བྱང་ཆུབ་ཀྱི་སེམས་ལ་བརྟན་པར་གནས་པས་སྤང་བར་བྱའོ། །
```

那［魔业］要以稳固安住于空性与悲心无别的菩提心来舍弃。

```
མདོ་སྡེ་ཉིད་ལས་ཀྱང་།
ཁྱོད་འཁོར་བ་ལ་མ་འཇུག་པར་སྔར་ཤེས་པར་གྱིས་ཤིག་ཅེས་པ་དང་།
དགའ་བོ་རིགས་ཀྱི་བུ་དག་ཏིང་ངེ་འཛིན་ལ་མི་གནས་པའི་ཡང་དག་པ་ཉིད་ལ་མཉམ་པར་གཞག་ན་བདུད་རྣམས་སེམས་ཐག་ཆོད་དོ་ཞེས་པ་དང་།
ཕྱི་མའི་དུས་ངན་པ་ཐ་མའི་ཚེ་སྙིང་རྗེ་ཆེན་པོ་བསྐྱེད་དེ།
ཡང་དག་པར་དད་པའི་སེམས་ཅན་རྣམས་གྲོལ་ཞིང་ཐར་བར་གྱིས་ཤིག་ཅེས་པ་དང་།
འདི་ཁྱབ་པར་སྟོན་ཅིག་ཅེས་འབྱུང་ངོ་། །
```

经中也说："你在未入轮回之前，先要了知。"又说："难陀，善男子们若安住于'不住三摩地'的真实性中，诸魔就会死心。"又说："在后世恶时的末期，要生起大悲，使真实具信的众生解脱、出离。"又说："要普遍宣说这个。"

【按】"要普遍宣说这个"，与《楞严经》中佛嘱咐"于我灭后传示末法，遍令众生开悟斯义"的意思相合，存疑。

## 十六、持三律仪者，连学处的一支也不许损坏（第 322–331 句）

```
སྡོམ་པ་གསུམ་འཛིན་པས་ནི་བསླབ་པའི་ཡན་ལག་ཙམ་ཡང་ཉམས་པར་མ་གནང་སྟེ།
གཞུང་ལས།
ཁར་གསིལ་ལྷུང་བཟེད་ཆོས་གོས་དང་། །
ཆུ་ཚགས་སྦྱངས་པའི་ཡོན་ཏན་གྱིས། །
ཡན་ལག་ལུང་བཞིན་མི་སྤང་སྟེ། །
ལུང་མ་རྟོགས་པར་རྣལ་འབྱོར་པ། །
སངས་རྒྱས་མུ་སྟེགས་ཅན་དུ་འགྱུར། །
ཞེས་འབྱུང་སྟེ།
```

持三律仪的人，连学处的一支也不许损坏，论中说："锡杖、钵、法衣与滤水囊等清净的功德，各支分都不可违教而舍弃；不了解教证的瑜伽士，［本是］佛［弟子］，却会成为外道。"

```
བསླབ་པ་ཐམས་ཅད་མ་ཉམས་ཤིང་།
ཕུན་སུམ་ཚོགས་པར་ལྡན་པས་དགེ་སློང་རྡོ་རྗེ་འཛིན་པ་མཆོག་ཏུ་གསུངས་སོ། །
```

由于不损坏一切学处、圆满具足，所以［经中］说比丘持金刚者最为殊胜。

【按】"三律仪"，即别解脱戒、菩萨戒与密咒戒。"比丘持金刚"，指受具足戒而修持密法的比丘，在密续中被称为最殊胜的持金刚。这一节明确表示：修持密法不可以舍弃出家律仪。

## 十七、漏失之乐不是菩提心（第 332–346 句）

```
གཞན་ཡང་དུས་ཐམས་ཅད་དང་།
གཟུགས་ཅན་མ་ཡིན་པ་དང་།
ཐམས་ཅད་ལ་ཁྱབ་པ་དང་།
མི་འགྱུར་བའི་ཡན་ལག་རྣམས་ཀྱིས་བྱང་ཆུབ་ཀྱི་སེམས་ཡིན་པར་གསུངས་ན།
འཛག་པའི་བདེ་བ་སྐད་ཅིག་མ་ནི་དེ་ལས་བཟློག་པའི་མཚན་ཉིད་དེ།
བསམ་གཏན་གྱི་ལྷ་རྣམས་ལ་ཡང་ཡོད་པར་མ་གྲགས་ན།
ཆོས་ཀྱི་དབྱིངས་ཀུན་དུ་འགྲོ་བ་ལ་མངའ་བརྙེས་པའི་ཡེ་ཤེས་ཀྱི་ལྷ་རྣམས་ལ་དྲི་མ་དེ་ལྟ་བུ་ཇི་ལྟར་མངའ།
```

此外，［经中］说菩提心具有贯通一切时、非有色、遍于一切、不变等支分；那么，刹那性的漏失之乐，就是与之相反的相。连禅定天都不认为有［这样的乐］，那么，对于已在遍行法界中得自在的智慧本尊们，怎么会有这样的垢染呢？

```
དེས་ན་མཚོན་བྱ་དང་།
མཚོན་བྱེད་དང་།
རྒྱུ་དང་འབྲས་བུ་འབྲེལ་པར་ཡང་ཇི་ལྟར་རུང་།
```

因此，能表与所表、因与果之间的关联，又怎么能成立呢？

```
དེའི་ཕྱིར་སངས་རྒྱས་པའི་གཞུང་ལས་གསུངས་པ་ནི།
སྲིད་པའི་ཡེ་ཤེས་དང་།
མི་མཐུན་པའི་དཔེ་དང་།
དོན་གཞན་མཚོན་པ་དང་།
དགོངས་པ་གཞན་ཡིན་པར་ཟད་དོ། །
```

所以，佛教论典中所说的［这类话］，只不过是三有之智、不相似的譬喻、表示其他的意义，或者别有密意而已。

```
ཡང་དག་པར་ན་ཆོས་ཐམས་ཅད་ཀྱི་རང་བཞིན་གང་དུ་ཡང་མི་གནས་པར་བསྟན་པ་ལ་སོགས་པའི་ཕྱིར་རོ། །
```

不是的。对于殊胜之人，也有烦恼成为菩提之支的时候：也就是为了生起大乐之止的力量，修习无碍之观的能力，入于无碍之行的平等性之列，显示成就瑜伽的标准，使有学的瑜伽士生起欢喜，除去世间凡人的增益与损减，降伏傲慢者，以及显示真实中一切法的自性不住于任何处等。

```
དེ་ལྟ་བུ་ལ་དགོངས་ནས་རྒྱུད་ལས།
ཟབ་མོའི་ཆོས་ནི་སྟོན་པ་ལ། །
གལ་ཏེ་མོས་པར་མ་གྱུར་ཀྱང་། །
སྨད་པ་དག་ཏུ་མི་བྱ་སྟེ། །
ཆོས་ཉིད་བསམ་མི་ཁྱབ་དྲན་བྱ། །
ཞེས་འབྱུང་བ་དང་།
```

密意于此，续中说："对于开示甚深之法，即使不能信解，也不要毁谤，要忆念法性不可思议。"

```
ཡང་།
མི་གང་གསང་སྔགས་རྒྱུད་དག་གིས། །
སྦྱོར་བ་ལ་ནི་འཕྱ་བྱེད་པ། །
དེས་ནི་དངོས་གྲུབ་ཐོབ་མི་འགྱུར། །
དེ་ནི་རྟག་ཏུ་གདོན་གྱིས་འཛིན། །
ཁབ་ལེན་རྡོ་ལ་ལྕགས་འདུ་ལྟར། །
མི་འདོད་ཡིད་དུ་འོང་བ་ཡི། །
ཚེ་འདིར་མི་བདེ་སྣ་ཚོགས་འདུ། །
ཕྱི་མར་ངན་སོང་གསུམ་མཐར་ལྟུང་། །
ཞེས་འབྱུང་ངོ་། །
```

又说："凡是以密咒续而讥毁［双运］结合的人，他不会得到成就，常被邪魔所执持；如同磁石吸聚铁一样，不想要的、［违逆］心意的种种不乐，此生都会聚集，后世堕入三恶趣的边际。"

【按】这一节是作者对前文的补充：他并不是全盘否定业手印之道，而是说，对已证悟的殊胜之人，烦恼可以转为菩提之支；对一般人则不许。所以他一方面破斥"以业手印为究竟"，另一方面也警告不可毁谤密续中的双运之法。"入于平等性之列"，原文 མཉམ་པ་ཉིད་ཀྱི་ཀྲུང་དུ་འཇུག་པ，"ཀྲུང"意思不很确定，存疑。

## 二十、初业的梵行者不应趣入（第 426–446 句）

```

ཤེས་རབ་ཀྱིས་བརྟགས་ཏེ་སྨྲ་བར་བྱའོ། །
```

所以，过失之业大多从愚痴而生，因此要以智慧观察之后再说。

```
ལས་དང་པོ་པའི་ཚངས་པར་སྤྱོད་པ་རྣམས་ལ་ནི་དགོས་པའི་དོན་མཐོང་བའི་སྐབས་སུ།
བརྡ་དང་ཐ་སྙད་ཙམ་ལས་མ་གཏོགས་པ།
དོན་གྱི་དངོས་པོ་ནམ་ཡང་སྣང་བ་མེད་པས།
བརྟན་པ་མ་ཐོབ་བར་དུ་ཡང་།
སྡོམ་གསུམ་ལྡན་པས་འཇུག་མི་བྱ། །
ཞེས་འབྱུང་སྟེ།
སླར་ལྟུང་བར་གྱུར་པ་དང་།
གཞན་གྱི་ཡང་བཞད་གད་དུ་འགྱུར་བའི་ཕྱིར་རོ། །
```

对于初业的梵行者，在见到［某种］必要之义的时候，［对他们来说］除了表示与名言之外，义的实体从未显现，所以在未得稳固之前，［续中］说："具三律仪者不应趣入。"因为会再度堕落，也会成为他人的笑柄。

```
དེ་བས་ན་གང་དུ་ཡངས་པའི་སྤྱོད་པ་བསྟན་པ་དེ་ན།
རབ་ཏུ་དག་པའི་རྣལ་འབྱོར་པའི་ནུས་པ་དང་།
ས་མཚམས་ལ་སོགས་པ་བསྟན་ནས་ཡོད་པས།
རང་དང་གཞན་ལ་ཕན་པར་འདོད་པའི་སྔགས་པ།
ཤེས་རབ་ཀྱི་མིག་དང་ལྡན་པ་དག་གིས་དམ་པ་རྣམས་ཀྱིས་མཛད་པའི་གཞུང་དུ་ལྟོས་ཤིག །
```

所以，凡是开示开放之行的地方，都说明了极清净瑜伽士的能力与界限等；因此，想要利益自他的密咒师，具有智慧之眼的人，要去看圣者们所作的论典。

```
མདོར་ན་འདིར་མང་དུ་སྨྲ་བས་ཅི་ཞིག་བྱ།
རང་གི་ལུང་དུ་གྱུར་པའི་བླ་མ་དམ་པ་རྣམས་ལས་ཀྱི་ཕྱག་རྒྱ་ལ་བརྟེན་པ་ཡང་དག་པའི་ལམ་དུ་མི་བཞེད་དོ། །
```

总之，这里多说又有什么用呢？我自己所依的殊胜上师们，都不认为依业手印是真实之道。

```
དེ་བས་ན།
རྒྱུ་སྐྱེས་ཡེ་ཤེས་གླང་པོ་ཆེ། །
ཞེས་བྱའོ། །
དྲང་བའི་དོན་བསྟན་ཟིན་ཏོ།། །།
```

所以［说］："因生之智，如大象。"不了义已经说完了。

【按】"具三律仪者不应趣入"，即持别解脱、菩萨、密咒三种律仪的出家人，在未得稳固证悟之前，不应依业手印修持。"开放之行"（ཡངས་པའི་སྤྱོད་པ），指密续中所说的不拘常规的行持。"我自己所依的殊胜上师们"，这是作者表明自己传承的立场。

## 二十一、了义：大手印即第四灌顶，一切灌顶之义都摄于菩提心（第 447–501 句）

```
ངེས་པའི་དོན་གང་ཞེ་ན།
འཇོམས་བྱེད་སེང་གེ་བདག་གི་གཞུང་། །
ཞེས་གསུངས་སོ། །
```

了义是什么呢？［就是］所说的："摧伏它的狮子，是我的论。"

```
ཕྱག་རྒྱ་ཆེན་པོ་ལ་གཞོལ་བར་བྱེད་པའོ། །
དབང་བཞི་པའོ། །
དེ་ཉིད་ཀྱང་གང་ཞེ་ན།
སྙིང་པོ་དང་།
དེའི་ཡན་ལག་གོ། །
```

就是趣入大手印，即第四灌顶。那又是什么呢？就是心要及其支分。

```
སྙིང་པོ་གང་ཞེ་ན།
ཡང་དག་པའི་བླ་མ་བརྒྱུད་པ་ལས་མཐོང་བ་ནི་རྡོ་རྗེ་ལྟ་བུའི་བྱང་ཆུབ་ཀྱི་སེམས་སོ། །
དེ་ནི་ལུང་དང་རིགས་པ་ལས་ཀྱང་འདས་པའོ། །
```

心要是什么呢？从真实上师的传承中所见的、如金刚一般的菩提心。它也超越了教与理。

```
དེའི་ཡན་ལག་གང་ཞེ་ན།
ལུང་དང་རིགས་པ་དང་མི་འགལ་བ་ཙམ་མོ། །
```

它的支分是什么呢？只是与教理不相违而已。

```
དེའི་ཅུང་ཟད་དབྱེ་བ་ནི།
ཐམས་ཅད་ཀྱི་གཞིར་གྱུར་ཅིང་སྙིང་པོ་ལེན་པས་ན་དེ་ཉིད་དཀྱིལ་འཁོར་རོ། །
```

对它稍加分别：因为它是一切的基础，并且摄取心要，所以它就是坛城。

```
འཁྲུལ་པའི་དྲི་མ་དག་པར་བྱེད་པ་དང་།
མཆོག་ཏུ་གྱུར་པ་དང་།
མི་འགྱུར་བ་དང་།
རང་བཞིན་གྱིས་སྟོང་པ་དང་།
བརྡར་བཏགས་པ་དང་།
ཐམས་ཅད་ལ་ཁྱབ་པ་དང་།
རང་གིས་རིག་པ་ལ་སོགས་པའི་ཕྱིར།
དེ་ཉིད་ཆུ་ལ་སོགས་པའི་དབང་ངོ་། །
```

因为它净化迷乱之垢、最为殊胜、不变、自性空、以表示而施设、遍于一切、自证等，所以它就是水等［瓶］灌顶。

```
དམ་པ་མི་ཟད་པའི་བདེ་བ་ཡིན་པ་དང་།
བརྒྱུད་པའི་མན་ངག་གིས་གནང་བས་ན།
དེ་ཉིད་གསང་བའི་དབང་ངོ་། །
```

因为它是殊胜不尽之乐，并且由传承的口诀所授予，所以它就是秘密灌顶。

```
ཐམས་ཅད་ཀྱི་སྐྱེད་མར་གྱུར་པ་དང་།
དེ་ཉིད་ཡུལ་དུ་བྱ་བ་མ་ཡིན་པ་དང་།
དགའ་བ་སྐྱེད་པར་བྱེད་པ་དང་།
ཐམས་ཅད་རོ་གཅིག་ཏུ་གྱུར་པ་དང་།
མངོན་པར་ཞེན་པའི་སྲོག་འཕྲོག་པར་བྱེད་པས་དེ་ཉིད་མ་ལ་སོགས་པའི་རང་གི་རིགས་ཀྱི་ཤེས་རབ་མའོ། །
```

因为它是一切的生母，不是所缘之境，生起喜乐，使一切成为一味，夺取执著的性命，所以它就是母等自种姓的智慧母。

```
མ་སྐྱེས་པ་དང་དཔེ་ལས་འདས་པ་དང་།
ཐམས་ཅད་ལ་ཁྱབ་པ་དང་།
རང་བཞིན་གཉུག་མར་གནས་པའི་དོན་ཡིན་པས་དེ་ཉིད་གཞོམ་པ་ལ་སོགས་པའི་ཡོན་ཏན་བཞི་དང་ལྡན་པའོ། །
```

因为它无生、超越譬喻、遍于一切、是本性安住之义，所以它具有不可摧等四种功德。

```
མཐའ་དབུས་མེད་པ་དང་།
རྫས་མེད་པ་དང་།
བདེ་བའི་འབྱུང་གནས་སུ་གྱུར་པས།
དེ་ཉིད་རབ་ཏུ་རྒྱས་པ་ལ་སོགས་པའི་ཆོས་དང་ལྡན་པའི་པདྨའོ། །
```

```
ཕྱིན་ཅི་མ་ལོག་པར་འབིགས་པ་དང་།
ངེས་པར་འཇོམས་པ་དང་།
གཞན་དུ་མི་འགྱུར་བས་དེ་ཉིད་ཐ་མི་དད་པར་སྦྱོར་བ་ལ་སོགས་པའི་ཆོས་དང་ལྡན་པའི་རྡོ་རྗེའོ། །
```

因为它无颠倒地穿透、决定地摧坏、不变异，所以它就是具有无别结合等性质的金刚。

## 二十六、真实的瑜伽士即"狮子"（第 658–662 句）

```
དེ་ལྟར་ན་ཆོས་ཐམས་ཅད་རྟེན་ཅིང་འབྲེལ་པར་འབྱུང་བའི་མཐར་རྟོགས་པས།
ལམ་དང་ལམ་མ་ཡིན་པ་བྱེ་བྲག་ཤིན་ཏུ་ཕྱེད་པ་དང་ཐེག་པ་གསུམ་དུ་ཕྱེ་ཡང་དོན་མི་འགལ་བར་བསྟན་པ་ཁོང་དུ་ཆུད་པས་འདྲེན་པ་རྣམས་ཀྱི་བསྟན་པ་ལ་གུས་པར་ཡིད་ཆེས་པ་དང་།
ཚད་མ་གསུམ་གྱིས་ཆོས་རྣམས་བདག་མེད་པར་གཏན་ལ་ཕེབས་པས་དོན་ལ་ཐམས་ཅད་མཉམ་པ་ཉིད་དུ་ཤེས་ཤིང་གདེང་དུ་གྱུར་པ་ནི་ཡང་དག་པའི་རྣལ་འབྱོར་པ་སྟེ།
འཇོམས་བྱེད་སེང་གེ་བདག་གི་གཞུང་། །
ཞེས་བྱ་བའོ། །
```

这样，由于究竟证悟一切法缘起，所以能极善区分道与非道；虽然分为三乘，也了解所示的义理并不相违，所以对诸导师的教法恭敬、信解；以三量抉择诸法无我，所以了知义上一切平等而得到把握——这就是真实的瑜伽士，也就是"摧伏它的狮子，是我的论"。

【按】"三量"，可能指现量、比量与圣教量，存疑。

```
ཕས་ཕམ་ལ་སོགས་རབ་ཏུ་བྱེད། །
```

对善说的毗奈耶，不安住、不守护，毁坏佛的胜幢，极犯他胜罪等。

```
གང་གིས་བཏུང་བའི་མཆོག་མི་ཤེས། །
སཱ་ལུ་ལ་སོགས་བཅོས་སྦྱར་བའི། །
མྱོས་པའི་ཁུ་བ་འཐུང་བྱེད་ཅིང་། །
དེ་ཡིས་ཕུང་ཁྲོལ་རབ་ཏུ་བསྐྱེད། །
```

不知道最胜的饮料，［却］饮用以稻米等酿造的醉人之液，由此极生败坏。

```
གང་དག་ཐ་སྙད་ཙམ་ཅིག་ལ། །
བརྟེན་ཏེ་མི་དགེའི་ལས་བཅུ་སྤྱོད། །
དེ་དག་འགྲོ་བ་ཅི་འདྲ་བ། །
འདྲེན་པ་ཡིས་ཀྱང་ག་ལ་རྟོགས། །
ཞེས་འབྱུང་ངོ་། །
```

凡是仅仅依靠名言而行十不善业的人，他们将去往何种趣处，就连导师又怎能了知呢？——这样说。

【按】这一大段续文的出处待考，存疑。它所描述的，都是末世以"瑜伽行者"自居、实则破戒败德者的种种行相，是作者所要警诫的反面，读者切不可误为修行之法。"恒常停留在行［双运］结合的时候"，指只贪著业手印之行而不求了义。"抛弃了［戒律的］结"，原文 མདུད་པ་བོར་བ，意思不很确定，存疑。"毁坏孩童"（བྱིས་པ་འཇིག），"孩童"在这里多指愚昧无知的初学者，存疑。"最胜的饮料"，指密续中所说的甘露（菩提心），而不是酒；这里正是批评以饮酒冒充密行者。"他胜罪"，即比丘的根本重罪（波罗夷）。

## 二十九、以狮子为喻的种种相合之义（第 777–809 句）

```
གཞན་ཡང་སེང་གེ་ལ་དཔེར་བཞག་པ་ནི་དོན་མཐུན་པ་མང་དུ་ཡོད་དེ།
འདི་ལྟར་བྱང་ཆུབ་ཀྱི་སེམས་ནི་འཁོར་བ་མ་རྟོགས་པའི་དུས་ན་ཡང་།
རང་བཞིན་གྱིས་མཐུ་དང་ལྡན་པ་དང་།
བྱང་ཆུབ་ཀྱི་སེམས་རྟོགས་ཤིང་སྐྱེས་མ་ཐག་ཏུ་གཞན་ཟིལ་གྱིས་གནོན་པའི་མཐུ་དང་ལྡན་པ་དང་།
བྱང་ཆུབ་ཀྱི་སེམས་གོམས་པ་མཐར་ཕྱིན་པའི་དུས་ན་མི་མཐུན་པ་རྩད་ནས་འཇོམས་པའི་མཐུ་དང་ལྡན་པ་དང་།
དེ་དང་ལྡན་པའི་དམ་པ་དཀོན་པ་དང་། །
དེ་དཔའ་བ་དང་།
དེ་སྟོང་པ་ཉིད་ཀྱི་རི་དང་།
རྫོང་ལ་གནས་པ་དང་།
དེ་བདག་མེད་པའི་སྒྲ་སྒྲོགས་པ་དང་།
དེ་རང་གི་རྒྱུད་ལེགས་པར་འཇོག་པ་ལ་སོགས་པའོ། །
```

又，以狮子为喻，有许多相合之义：菩提心即使在［流转］轮回、尚未证悟之时，自性也具有力量；证悟菩提心、一生起之时，就具有压伏他者的力量；修习菩提心到究竟之时，具有从根本摧毁违品的力量；具有它的圣者稀有；它勇猛；它住于空性的山岳与要塞；它宣说无我之声；它善于安置自己的相续等。

```
དེ་ལྟར་གཞུང་དག་ལས་ཀྱང་། །
ཇི་ལྟར་ཁྱུང་དང་སེང་གེའི་བུ། །
མངལ་དང་སྒོ་ངས་བསྒྲིབས་གྱུར་ཀྱང་། །
རང་ལ་ཡོད་པའི་རྩལ་གྱིས་ནི། །
གཉེན་པོར་འགྱུར་བའི་མཐུ་སྟོབས་ལྡན། །
```

论中也说："如同大鹏与狮子之子，虽然被胎与卵所遮蔽，以自身本有的能力，具有成为对治的力量。"

```
བྱང་ཆུབ་སེམས་ལ་འཇུག་པ་དང་། །
དེ་བཞིན་སྨོན་པར་བྱེད་པ་ནི། །
མུན་པ་ལོ་སྟོང་ལོན་པ་ཡང་། །
སྒྲོན་མེ་གཅིག་གིས་སེལ་བར་བྱེད། །
```

"趣入与发愿菩提心，如同千年的黑暗，一盏灯就能除去。"

```
དེ་བཞིན་སེང་གེའི་ཕྲུ་གུས་ཀྱང་། །
ཤིན་ཏུ་རྒས་པའི་གཅན་གཟན་འཇིགས། །
གཅན་གཟན་རྒྱལ་པོ་གཅིག་པུས་ཀྱང་། །
གླང་ཆེན་དྲེགས་ཁྱུའི་ཀླད་པ་འགེམས། །
ས་ལ་སེང་གེ་ཁྱུས་འཁོད་སྔོན་མ་བྱུང་། །
གང་ཟག་དམ་པ་ཁྱུས་འཁོད་སྔོན་མ་བྱུང་། །
དཔའ་བོ་སེང་གེ་ལྟ་བུར་འཇིགས་མེད་སྤྱོད། །
```

"同样，狮子之子，也令极老的猛兽恐惧；兽中之王独自一个，也能击碎傲慢象群的头脑。地上狮子成群而居，从来没有过；圣者成群而居，从来没有过；勇士如狮子般无畏而行。"

```
ཅེས་བྱ་བ་དང་།
དཔེར་ན་སེང་གེ་རི་སུལ་བརྟེན་ནས་འཇིགས་མེད་པར། །
རི་དྭགས་ཕྲ་མོ་མང་སྐྲག་བྱེད་ཅིང་སྒྲ་སྒྲོགས་ལྟར། །
མི་ཡི་སེང་གེ་ཤེས་རབ་ཕ་རོལ་ཕྱིན་བརྟེན་ནས། །
མུ་སྟེགས་ཅན་མང་སྐྲག་བྱེད་འཇིག་རྟེན་སྒྲ་ཡང་སྒྲོག །
ཅེས་འབྱུང་ངོ་། །
```

——这样说。又说："譬如狮子依于山谷，无畏地使众多小兽恐惧，而发出吼声；人中狮子依于般若波罗蜜多，使众多外道恐惧，也发出［震动］世间之声。"——这样出现。

【按】第 788–803 句所引"论"，出处待考，存疑；其中"千年的黑暗，一盏灯就能除去"，是佛典中常见的譬喻。第 805–808 句"人中狮子依于般若波罗蜜多"一偈，可能出自般若经类，存疑。

## 三十、狮子由自身之缘而死：极无住的瑜伽士也是如此（第 810–824 句）

```
གཞན་ཡང་སེང་གེ་ཁོ་ན་ལ་དཔེར་བཞག་པ་ནི།
སེང་གེ་ནི་རི་དྭགས་གཞན་གྱིས་གཞོམ་པར་མི་ནུས་ཤིང་།
མཐར་རང་གི་རྐྱེན་གྱིས་འཆི་བར་འགྱུར་ཏེ།
དེའི་རོ་ཡང་གཞན་གྱིས་བཤིག་པར་མི་ནུས་ལ།
རང་ཉིད་ཀྱི་ཕུང་པོ་ལྷག་མ་མེད་པར་འཇིག་པར་འགྱུར་བ་བཞིན་དུ།
ཆོས་ཐམས་ཅད་རབ་ཏུ་མི་གནས་པར་སྨྲ་བའི་རྣལ་འབྱོར་པ་ཡང་དེ་ལྟར་ཤེས་པར་བྱའོ། །
```

又，只以狮子为喻的［另一层意思］是：狮子不能被其他野兽摧毁，最终由于自身的因缘而死；它的尸体，他者也不能毁坏，而是自己的蕴无余地毁坏——说一切法极无住的瑜伽士，也应这样了知。

```
དེ་ཡང་སོ་སོར་རྟོག་པའི་ཡེ་ཤེས་མེ་དང་འདྲ་བ་དང་།
སྒྱུ་འཕྲུལ་དྲ་བའི་ཏིང་ངེ་འཛིན་ལམ་དང་འདྲ་བ་དང་།
དེ་བཞིན་ཉིད་དམིགས་ཀྱི་ཏིང་ངེ་འཛིན་ཆུ་དང་འདྲ་བ་དང་།
ལྷན་ཅིག་སྐྱེས་པའི་བྱང་ཆུབ་ཀྱི་སེམས་ནམ་མཁའ་དང་འདྲ་བའི་རྣལ་འབྱོར་ལ་མི་གནས་པར་གནས་པའི་ཚུལ་གྱིས།
ཡུན་རིང་དུ་གོམས་པའི་རྐྱེན་གྱིས་མི་མཐུན་པའི་རྣམ་པར་རྟོག་པ་དང་།
གཉེན་པོའི་ཕྱོགས་ཀྱི་རྣམ་པར་རྟོག་པ་དང་།
དེ་ཁོ་ན་ཉིད་ཀྱི་རྣམ་པར་རྟོག་པ་དང་།
འབྲས་བུའི་རྣམ་པར་རྟོག་པ་ཐམས་ཅད་སྤངས་ཏེ།
དུས་གསུམ་མཉམ་པ་ཉིད་ཀྱི་གོ་འཕང་ཐོབ་ནས་གང་ཅི་ལ་ཡང་གནས་པར་མི་འགྱུར་རོ། །
```

也就是：以如火一般的各别观察之智、如道一般的幻化网三摩地、如水一般的缘真如三摩地、如虚空一般的俱生菩提心之瑜伽中"不住而住"之理，以长久串习之缘，舍弃一切违品的分别、对治方面的分别、真如的分别与果的分别，得到三时平等之位后，就不住于任何［处］。

【按】这一节的意思是：极无住的见地不会被他宗所破，最终连"违品、对治、真如、果"等一切分别也由自身串习而消尽，就像狮子由自身而灭、尸体也不留。"火、道、水、虚空"四喻，配四种瑜伽，所指的具体修法待考，存疑。

## 三十一、结尾偈颂之一：以菩提心摄持，一切都是正道（第 825–866 句）

```
འདིར་ཚིགས་སུ་བཅད་པ།
```

这里有偈颂说：

```
ཇི་ལྟར་ནད་མེད་རྩིས་ནི་ཁྱབ་པ་ཡི། །
ཐ་མལ་ཟས་ཀྱང་སྨན་གྱི་མཆོག་ཡིན་ལྟར། །
མཉམ་ཉིད་བྱང་ཆུབ་སེམས་ཀྱིས་ཟིན་པ་ཡི། །
བསྐྱེད་རྫོགས་ཐམས་ཅད་ཡང་དག་ལམ་ཡིན་ནོ། །
```

如同遍布了无病之药的平常食物，也成为最上的药；以平等性的菩提心所摄持的一切生起次第与圆满次第，都是真实之道。

```
དབའ་དང་ཡན་དང་གཟུང་དང་བཏང་བ་དང་། །
བསྐྱིལ་དང་གཞུག་དང་ལྟ་དང་བསྲེ་ལ་སོགས། །
གནད་ཀྱི་མན་ངག་གང་ལ་གོམས་བྱས་ཀྱང་། །
སླུ་བ་མེད་དེ་ཡང་དག་ལམ་ཡིན་ནོ། །
```

```

རྣམ་པར་མི་རྟོག་ལྷུན་གྱིས་གྲུབ། །
དུས་གསུམ་སངས་རྒྱས་ལས་བྱེད་པ། །
སངས་རྒྱས་ཐོག་མ་ཐ་མ་མེད། །
ཅེས་བྱ་བ་ལ་སོགས་པ་ཟབ་ཅིང་རྒྱ་ཆེ་བར་འགྱུར་རོ། །
```

续中又说："识超越于法性，持智慧无二之理，无分别而任运成就，作三时诸佛的事业，佛无始也无终。"等等——［显示了］甚深与广大。

【按】第 868–877 句所引"论"，以"朋友"（གྲོགས་མོ）称呼听者，文体像成就者的道歌，出处待考，存疑。第 879–915 句所引"续"中的"密咒怙主"（གསང་སྔགས་མགོན་པོ）与"密咒自在"（གསང་སྔགས་དབང་ཕྱུག），在汉译密典中常译为"秘密主"，是金刚手的称号；这段续文"如虚空离一切分别"等的意趣，与《大日经》中的说法相近，但这里"密咒怙主"似作为所说的主体，也可能原是对秘密主的呼告，存疑。第 918 句"识超越于法性"，意思不很确定，存疑。

## 三十三、"我之论"的意思：上师传承与得法之处（第 924–928 句）

```
བདག་གི་གཞུང་ཞེས་གསུངས་པ་ནི། །
མ་འོངས་པའི་དུས་སུ་ཟབ་མོའི་དོན་ལ་མོས་པའི་སྐལ་བ་དང་ལྡན་པའི་སློབ་མའི་རྒྱུད་གཟུང་བའི་ཕྱིར།
བླ་མ་བརྒྱུད་པའི་འགྲེལ་པ་བསྟན་པ་སྟེ།
འདི་ལྟར་དོན་དམ་པར་ཆོས་ཐམས་ཅད་གང་དུ་མི་གནས་པར་སྟོན་པའི་གཞུང་ལྷོ་ཕྱོགས་ཀྱི་ནགས་ཚལ་དུ་དཔལ་རི་ཁྲོད་རྡོ་རྗེའི་ཞལ་སྔ་ནས།
བདག་གིས་རྙེད་པ་ཡིན་ནོ་ཞེས་བྱ་བའི་དོན་ཏོ། །
```

所说的"我之论"，是为了摄受未来对甚深之义有信解、具足缘分的弟子相续，而显示上师传承的解释。也就是说："这部在胜义中开示一切法都不住于任何处的论，是我在南方的森林中，从吉祥夏瓦日金刚的座前得到的。"——这就是它的意思。

【按】"夏瓦日金刚"（རི་ཁྲོད་རྡོ་རྗེ，梵 Śavaravajra），即夏瓦日巴（萨惹哈的弟子），相传梅纪巴曾到南方师从夏瓦日巴，得大手印口诀。这与作者"阿瓦都底巴"即梅纪巴的说法相合，但本篇没有直接说明，存疑。

## 三十四、结尾偈颂之二：无偏地看一切教法（第 929–938 句）

```
འདིར་ཚིགས་སུ་བཅད་པ།
འདྲེན་པ་རྣམས་ཀྱིས་དུས་གསུམ་བསྟན་པ་ནི། །
དོན་དམ་གཉིས་མེད་བྱང་ཆུབ་སེམས་ཉིད་དེ། །
ཐུབ་པའི་བསྟན་པ་ཐམས་ཅད་རོ་གཅིག་པས། །
ཕྱོགས་རིས་མེད་པར་སྡེ་སྣོད་གསུམ་དུ་ལྟོས། །
རིགས་པའི་གཟེར་ལྡན་བསྟན་བཅོས་བཟང་པོར་ལྟོས། །
ཡིད་ཆེས་མན་ངག་གྲུབ་པའི་གཞུང་དུ་ལྟོས། །
དེ་དག་རྣམས་ནི་བལྟ་བར་མི་ནུས་པས། །
བརྒྱུད་པའི་གདམས་ངག་སྙིང་པོ་འདི་ལ་ལྟོས། །
ཞེས་སོ། །
```

这里有偈颂说：诸导师所开示的三时［之法］，就是胜义无二的菩提心；能仁的一切教法都是一味，所以要无偏地看三藏；要看具有正理之钉的善论；要看可信的口诀与成就者的论典；如果那些都无力去看，就看这传承口诀的心要吧。——这样说。

## 三十五、真实口诀要隐藏，只传给堪受之人（第 939–953 句）

```
ཡང་དག་པའི་མན་ངག་སྦ་བ་དང་།
གཏད་པའི་གནས་ཀྱང་འདི་ལྟར་གཞུང་ལས།
ཐ་སྙད་ཚིག་གི་ང་རྒྱལ་གྱིས། །
བླ་མ་མི་བསྟེན་བསྙེན་བཀུར་མེད། །
དམན་པའི་ལྟ་བ་ལ་མོས་ཏེ། །
སྦས་གསུམ་ལྟ་ཞེན་མི་གཏོང་ཞིང་། །
མཐར་ཐུག་དོན་ལ་མི་སྨོས་ཏེ། །
རིགས་པ་གཙོར་བྱེད་ཤེས་རབ་ཀྱིས། །
མཐར་ཐུག་ཟབ་མོ་སུན་འབྱིན་པ། །
དེ་ལ་འདི་ཉིད་བསྟན་མི་བྱ། །
```

真实口诀的隐藏与所传之处，论中也这样说："以名言言词的我慢，不依止上师，不承事［上师］；信解下劣之见，不舍弃三种隐藏的见执，不提究竟之义；以理为主的智慧，破斥究竟的甚深——对这样的人，不应开示这个。"

```
གང་ཞིག་བླ་མ་བསྙེན་བཀུར་ཞིང་། །
ཐམས་ཅད་སྟོང་པས་མི་སྐྲག་བཟོད། །
མཐར་ཐུག་དོན་ལ་དད་མོས་ལ། །
དེ་ལ་བླ་མའི་དྲིན་སྦྱིན་བྱ། །
ཞེས་གསུངས་སོ། །
```

"凡是承事上师，对一切皆空不怖畏而能安忍，对究竟之义有信解的人，对他，就应施予上师的恩惠［即传授此法］。"——这样说。

【按】"三种隐藏的见执"（སྦས་གསུམ་ལྟ་ཞེན），所指不明，存疑。

## 三十六、全篇总结与跋文（第 954–964 句）

```
འདིར་དོན་ཉེ་བར་བསྡུ་ན། །
མདོར་ན་ཆོས་ཐམས་ཅད་ཀྱི་རང་བཞིན་ནི་མ་སྐྱེས་པ་དང་། །
ཐམས་ཅད་མཉམ་པ་ཉིད་དོ། །
སྒྲུབ་ཐབས་ནི།
དེའི་དོན་ནི་ཕྱིན་ཅི་མ་ལོག་པར་རྟོགས་ཤིང་འདྲིས་པའོ། །
ཐོབ་པ་ནི་གདེང་དུ་གྱུར་པས་ཕྱིར་མི་ལྡོག་གོ། །
```

这里总摄其义：总之，一切法的自性，就是无生与一切平等；修法，就是无颠倒地证悟并熟习它的义理；获得，就是成为把握而不再退转。

```
དེ་ལྟར་མི་གནས་སེང་གེའི་དོན། །
འགྲོ་བ་གང་གིས་ཤེས་གྱུར་པ། །
ལོག་ལྟའི་གླང་པོ་མྱུར་བཅོམ་སྟེ། །
རྣམ་གྲོལ་ལམ་ལས་ཕྱིར་མི་ལྡོག །
```

这样，凡是了知无住狮子之义的众生，就能迅速摧毁邪见的大象，在解脱道上不再退转。

```
ཆོས་ཐམས་ཅད་རབ་ཏུ་མི་གནས་པར་སྟོན་པའི་དེ་ཁོ་ན་ཉིད་ཚིགས་སུ་བཅད་པ་ཕྱེད་ཀྱི་འགྲེལ་པ་དཔལ་ཨ་ཝ་དྷཱུ་ཏཱིའི་ཞབས་ཀྱིས་མཛད་པ་རྫོགས་སོ།།
```

《显示一切法极无住之真如半颂释》，吉祥阿瓦都底足所作，圆满。

【按】"自性、修法、获得"三者，回应全篇开头第二节所说的纲领。"阿瓦都底足"（ཨ་ཝ་དྷཱུ་ཏཱིའི་ཞབས），一般认为即梅纪巴（Maitrīpa）的别名阿瓦都底巴（Avadhūtipa），但也有同名的其他成就者，存疑。本篇没有译者跋语。
