# 内外宗义辨析摄要

*华智仁波切 造*

顶礼遍知一切智者！

以下，我对一切宗义的分类略作说明。这类分法本来十分广泛，若从根本上划分，可以先分为世间与出世间两大类。

**世间**：其一，是人天乘。人乘是奉行十六种清净人规（做人的准则），以求生善趣为目标；天乘则是取舍十善——奉行十善业，断除与之相违的十恶业。其二，是受持斋戒律仪（近住律仪）而安住其中。

**外道见**：外道对"坏聚见"（我见）的观点，总的说有三百六十种，归纳起来可摄为二十种边执见，再归纳，便不出常见与断见两类。

常见，以数论外道为代表，此派可说是一切外道之根本、总纲。他们以喜、忧、暗三德为道，主张这三者平衡均等的本体即是"我"——洁白光润、圆满，大如拇指、小如芥子，恒常不坏，安住于一切众生心中，无可摧毁。将来获得解脱时，这个"我"便安住于天界之上，犹如一顶周匝环绕的白伞，具有色相与形状。

断见分两种：执因断灭见与执果断灭见。

执因断灭见认为：过去之心并非现在这个心识；心其实本来就潜藏于地、水、火、风四大之中，只是被各自大种的自体所遮蔽而不显现，一旦遇上暖、湿等外缘，便从中生起而成为心识。他们的理由是：地能承载重物、水会向下流动、火燃烧而有声、风能吹动摇曳——这一切属性便被称为"心"。

执果断灭见则更进一步，不仅否认前世的存在，也认为四大之中并无能生心识之因，一切法都是各自本体自然而生。譬如荆棘之所以尖锐、太阳之所以升起、水之所以向下流、豆子之所以浑圆、孔雀羽毛之所以斑斓、公主之所以容貌姣好——这一切都无人造作，纯属自然而生，别无缘由。

**出世间**：出世间之乘分为两种，一是声闻、缘觉的小乘，二是大乘。

**声闻乘**：小乘中的声闻，又分毗婆沙宗（有部）与经部两家。

毗婆沙宗，是佛陀涅槃之后，近护尊者等七百阿罗汉造《大毗婆沙论》，此后依此论修学之人。经部则只以佛陀亲口所说之经为量，不承许论典为量，因此得名。

毗婆沙宗对二谛的安立是：譬如认知牦牛尾、草甸等法的心识所对之境，从世俗谛而言，是具支分的整体（如牦牛尾）；从胜义谛而言，则可分割至最细无分微尘，如同将水分成一滴一滴那样。至于心识，其相续为世俗，当下这一刹那的心识则是胜义。他们虽证得人无我，却未证得法无我。于道位，须依四谛而趣入退出，断除见道、修道所摄四百一十种所断，现前八种灭尽与不生的殊胜智慧，方得解脱。

经部宗声闻，人无我的见解与毗婆沙宗相同；但在法我方面，因通达具支分微尘及五种所知事之法性，故超胜于毗婆沙宗。他们同样以四谛为趣入退出之门，断除粗细烦恼共八十八种，证得殊胜智慧。

二者皆须精进修习资粮、加行、见、修、无学五道，各自对治三毒：对治贪欲，观修不净八法与骸骨；对治嗔恚，观修慈心；对治愚痴，观修十二缘起。果位则得阿罗汉等四果，细分为向、住各四，共八种圣者次第。

**独觉乘**：独觉分麟角喻独觉与部行独觉（鹦鹉喻）两种。"独觉"一词，意为独自一人成佛。

麟角喻独觉，因独自安住如犀牛角，故得此名。他们观修四谛所摄一切法依十二缘起顺次而生——从无明乃至老死，由此断除三界一切粗细烦恼。顺观十二缘起，即观无明生行、行生识，乃至老死。于见解上，他们在证人无我之外，进而部分证得法无我，通达所取境（无论具支分或无分微尘）皆无自性、不生不灭。

部行独觉则群居而住。他们同样观修四谛所摄一切法，以十二缘起逆观：前往尸陀林，观察眼前尸体从何而来——由死而来，死由老而来……如此层层推究，直至无明。由此证得如前所说人无我与法无我之各一半，进而修习五道，终至现证灭尽、不生之觉悟。

以上二乘所修，除假立名相之外，皆不曾直接宣说正法，唯以象征表法。

**大乘**：大乘之所以超胜声闻、缘觉，正在于具足利他的菩提心。大乘又分唯识与中观两宗。

唯识宗中，有实相唯识（真相唯识）与假相唯识（虚相唯识）两派。

实相唯识主张：显现为外境之相，其实只是内在心识本身向外显现而已。此中又分三种主张：一者认为，有多少种显现之相，便有多少种能知之识；二者认为，所取相与能取识如同一颗蛋剖分为二；三者认为，所取相与能取识虽显现种种，实为无二。

第一种主张：听闻声音时，唯有能执声音之识生起，执色等识不会同时生起，因为唯有对应某一境的识才会生起，别无其他，故有多少种境，便有多少种能知之识。

第二种（如蛋剖为二）主张：所取相与能取识，亦即境与有境，实于同一心识上同时显现。

第三种（种种无二）主张：对境之相虽显现种种，实由内在同一能取之识所了知——譬如隔着四扇窗户模糊望见一只猴子四处跳跃，看似多猴，其实唯是一猴；同理，五根门所对之境，皆由同一心识所了知。

假相唯识则主张：外境显现于心，只是虚妄习气所现，属错乱之相；因能量之识亦属虚妄，故所量之境与能量之识，二者皆只是错乱虚妄的自性而已。此宗又分有染污与无染污两派。

中观宗分自续派与应成派两支。

自续派主张：种种纷呈的显现之相及能量之识，虽是无遮的明分显现，但不仅如此——连各别自证的胜义智慧本身，也是无自性的。此派又分幻化胜义与全然不住两派。

前者（幻化胜义）认为：境与有境虽于世俗中成立，但那不可思议、超越言说的觉性智慧，在胜义中仍以幻化方式存在。凭借修行的功德，于道位与究竟果位上，佛陀如幻的智慧得以成办利生事业。《中般若经》云：

```
ཆོས་ཐམས་ཅད་སྒྱུ་མ་ལྟ་བུ་རྨི་ལམ་ལྟ་བུ། མྱ་ངན་ལས་འདས་པ་ཡང་སྒྱུ་མ་དང་རྨི་ལམ་ལྟ་བུ། མྱ་ངན་ལས་འདས་པ་ལས་ཆེས་ལྷག་པའི་ཆོས་ཞིག་ཡོད་ན། དེ་ཡང་རྨི་ལམ་ལྟ་བུ་སྒྱུ་མའོ།
```

大意是说：一切诸法如幻如梦，就连涅槃也不例外，同样如幻如梦；纵使有超胜涅槃的法存在，那也不出如幻如梦的自性。因此，这一派也称为"自续下部"。

后者（全然不住）主张：连如幻的胜义也不安立——既无能取所取之相，连那种"无相"的觉受、各别自证本身也不存在，如同不孕妇人之子一般，连能衡量它的心识都没有。《中般若经》云：

```
དོན་དམ་པ་ནི་འཕོ་བ་ཡང་མེད། མྱང་འདས་ཡང་མེད། སྟོང་ཉིད་ཀྱང་མེད་དེ། ཚིག་བླ་དྭགས་ཙམ་ལགས་སོ།
```

大意是说：在胜义之中，既无迁流变化，也无涅槃可得，甚至连"空性"本身也不存在，这一切不过是言语上的假名安立罢了。

应成派则主张：如是遮破胜义有所成立，也遮破世俗中仅仅显现的幻化等一切安立，超越有无二边，远离一切承许。龙树菩萨云：

```
གལ་ཏེ་ངས་གང་དམ་བཅའ་ཡོད། །དེ་ཚེ་ང་ལ་སྐྱོན་དེ་ཡོད། །ང་ལ་དམ་བཅའ་མེད་པས་ན། །ང་ནི་སྐྱོན་མེད་ཁོ་ན་ཡིན།
```

大意是说：倘若我有所承许，那便有相应的过失；而我本来没有任何承许，所以我唯是远离一切过失。

**密乘**：若问，大乘密咒（金刚乘）比因乘（显教）究竟殊胜在何处？《三理炬论》云：

```
དོན་གཅིག་ན་ཡང་མ་རྨོངས་དང་། །ཐབས་མང་དཀའ་བ་མེད་པ་དང་། །དབང་པོ་རྣོན་པོའི་དབང་བྱས་ནས། །སྔགས་ཀྱི་ཐེག་པ་ཁྱད་པར་འཕགས།
```

大意是说：密咒与显教虽究竟义理无别，但密咒不生迷惑，方便众多而无诸艰难，又特别摄受利根之人，因此密咒乘极为殊胜。

之所以称为"密咒"，是因它被赞誉为守护、遮止烦恼的最殊胜方便。密乘可分四部或六部续。所谓"续"，是因它能使自相续中如所有性的法界光明得以显现，故名为续。

四部续，即事续、行续、瑜伽续、无上瑜伽续。前三者合称下三部续，或称外续；第四者称上部续，或称内续。内续又依父续、母续、无二续而分，共为六部续。

事续着重于外在沐浴、清洁等事相上的行持，故名事续。行续，外在行持与事续相仿，内在禅定则与瑜伽续相仿，是内外兼具之续，故名行续。瑜伽续以内在禅定为主，故名瑜伽续。

无上瑜伽之所以超胜下三部，在于它完全远离对五肉、五甘露等净秽的分别执着，通达真谛无别、任运双运、大平等性。此中又分生起次第的大瑜伽（玛哈瑜伽）、教传的随瑜伽（阿努瑜伽）、无二的极瑜伽（阿底瑜伽）三部。

以上，皆是至尊华智仁波切所说。
