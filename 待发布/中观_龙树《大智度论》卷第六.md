# 龙树《大智度论》卷第六

龙树菩萨造　后秦龟兹国三藏法师鸠摩罗什奉诏译

## 初品中十喻释论第十一

【经】

解了诸法：如幻、如焰、如水中月、如虚空、如响、如犍闼婆城、如梦、如影、如镜中像、如化。

【论】

这十个譬喻，是为了解说空法。

问：如果一切诸法都空，如同幻化，为什么诸法有可见、可闻、可嗅、可尝、可触、可识的？

如果真的一无所有，就不应当有可见乃至可识的。

再者，如果本来没有而虚妄地见到，为什么不会看见声音、听到颜色？如果一切都同样空无所有，为什么有可见的、有不可见的？如果诸法空，就像一根手指，第一个指甲没有，第二个指甲也没有，为什么看不见第二个指甲，唯独看见第一个指甲？因此知道：第一个指甲真实存在，所以可见；第二个指甲实际没有，所以不可见。

答：诸法之相虽然是空，也有分别，有可见与不可见。

譬如幻化出来的象、马以及种种事物，虽然知道不是真实的，然而颜色可以看见，声音可以听到，与六情一一相对，不相错乱。

诸法也是这样，虽然是空，却可见可闻，不相错乱。

如《德女经》中说：

“德女问佛：‘世尊！无明是在内的吗？’

“佛说：‘不是！’

“‘是在外的吗？’

“佛说：‘不是！’

“‘是在内外的吗？’

“佛说：‘不是！’

“‘世尊！这无明是从前世来的吗？’

“佛说：‘不是！’

“‘是从此世到后世去的吗？’

“佛说：‘不是！’

“‘这无明有生者、灭者吗？’

“佛说：‘没有！’

“‘有一种法，有确定的真实自性，名为无明吗？’

“佛说：‘没有！’

“那时，德女又对佛说：‘如果无明不在内，不在外，也不在内外，不是从前世来到今世、从今世去到后世，也没有真实的自性，为什么会从无明缘行，乃至众苦聚集？世尊！譬如有一棵树，如果没有根，怎能生出茎、节、枝、叶、花、果？’

“佛说：‘诸法之相虽然是空，凡夫无闻无智，所以在其中生起种种烦恼；以烦恼为因缘，造作身、口、意业；以业为因缘，形成后世之身；以身为因缘，感受苦、感受乐。这其中，实际上没有造作烦恼的，也没有身、口、意业，也没有感受苦乐的人。譬如幻师，以幻术变作种种事物。你意下如何？这幻术所作的事物在内吗？’

“德女回答：‘不在！’

“‘在外吗？’

“回答：‘不在！’

“‘在内外吗？’

“回答：‘不在！’

“‘是从前世来到今世、从今世去到后世吗？’

“回答：‘不是！’

“‘幻术所作的事物有生者、灭者吗？’

“回答：‘没有！’

“‘真实有一种法，是幻术所作的吗？’

“回答：‘没有！’

“佛说：‘你曾见过、听过幻术所变作的伎乐吗？’

“回答：‘我听过，也见过。’

“佛问德女：‘如果幻术是空的，是欺诳而不真实的，为什么从幻术中能变作伎乐？’

“德女对佛说：‘世尊！幻的相本来就是这样，虽然没有根本，却可以听见、看见。’

“佛说：‘无明也是这样，虽然不在内，不在外，不在内外；不是从前世来到今世、从今世去到后世，也没有真实自性，没有生者、灭者，然而以无明为因缘，诸行生起，乃至众苦之阴聚集。如同幻术停止，幻术所作的也就停止；无明也是这样，无明灭尽，行也灭尽，乃至众苦聚集都灭尽。’”

再者，这幻的譬喻是向众生显示：一切有为法空而不坚固。如经中说：“一切诸行如幻，欺骗小孩子，属于因缘，不自在，不久住。”

所以说“诸菩萨知诸法如幻”。

所谓“如焰”：焰是因为日光照射、风吹动尘土，在旷野中看起来像野马一般浮动，无智的人初见，以为是水。男相、女相也是这样：结使烦恼的日光照热诸行之尘，邪忆念之风吹动，在生死的旷野中流转，没有智慧的人以为是一种实相，是男，是女。这名为“如焰”。

再者，远远看见阳焰，以为是水，走近了就没有水的想法。无智的人也是这样，如果远离圣法，不知道无我，不知道诸法空，就在阴、界、入这些自性空的法中，生起人相、男相、女相；亲近圣法，就知道诸法实相，这时虚诳的种种妄想都除尽了。

所以说“诸菩萨知诸法如焰”。

所谓“如水中月”：月亮真实地在虚空中，影子显现在水里；实法之相的月亮，在真如、法性、实际的虚空中，而凡夫、天人的心水中，却显现出我、我所之相。所以名为“如水中月”。

再者，如小孩子看见水中的月亮，欢喜地想去捞取，大人看见就笑。无智的人也是这样，因为身见，所以见到有吾我；因为没有真实智慧，所以见到种种法；见了之后心生欢喜，想要取着种种相，如男相、女相等，诸得道的圣人看了就笑。如偈中说：

```
如水中月炎中水，　梦中得财死求生；
有人于此实欲得，　是人痴惑圣所笑！
```

大意：如同水中的月亮、阳焰中的水、梦中得到的财物、死了还求生，有人对这些真想得到，这个人愚痴迷惑，为圣人所笑！

再者，譬如在平静的水中看见月影，搅动水就看不见了。在无明之心的静水中，看见吾我、憍慢等诸结使的影子；以真实智慧之杖搅动心水，就看不见吾我等诸结使的影子了。

所以说“诸菩萨知诸法如水中月”。

所谓“如虚空”：虚空只有名称，没有真实之法。

虚空不是可见之法，因为远看，眼光转折，所以看见青白色。诸法也是这样，空无所有，人因为远离无漏的真实智慧，舍弃实相，看见彼我、男女、屋舍、城郭等种种杂物，心生执着。

如小孩子仰望青天，以为有真实的颜色；有人飞上极远之处，却什么也看不见；因为远看，所以以为是青色。诸法也是这样。所以说“如虚空”。

再者，如虚空的本性常清净，人们却以为阴云遮蔽时是不清净。诸法也是这样，本性常清净，因为淫欲、瞋恚等遮蔽，人们以为不清净。如偈中说：

```
如夏月天雷电雨，　阴云覆曀不清净；
凡夫无智亦如是，　种种烦恼常覆心。
如冬天日时一出，　常为昏气云荫曀；
虽得初果第二道，　犹为欲染之所蔽。
若如春天日欲出，　时为阴云所覆曀；
虽离欲染第三果，　余残痴慢犹覆心。
若如秋日无云曀，　亦如大海水清净；
所作已办无漏心，　罗汉如是得清净。
```

大意：如夏天时雷电交加、下雨，阴云遮蔽，天空不清净；凡夫无智也是这样，种种烦恼常遮蔽心。如冬天太阳偶尔出来，常被昏暗之气与云层遮蔽；即使得到初果、二果，仍被欲染所遮蔽。如春天太阳将出时，常被阴云遮蔽；即使离开欲染、得到三果，残余的痴与慢仍遮蔽心。如秋天的太阳没有云层遮蔽，又如大海之水清净；所作已办的无漏之心，阿罗汉就这样得到清净。

再者，虚空没有开始、没有中间、没有终结，诸法也是这样。

再者，如摩诃衍中，佛对须菩提说：“虚空没有前世，也没有中世，也没有后世，诸法也是这样。”那部经，这里应当广说。

所以说“诸法如虚空”。

问：虚空是真实存在的法。为什么？如果虚空不是真实的法，那么举起、放下，来、往，屈、伸，出、入等一切动作，都应当不能有，因为没有可以活动的地方。

答：如果虚空之法真实存在，虚空应当有住处。为什么？没有住处就没有这个法。如果虚空住在孔穴中，这是虚空住在虚空中，所以不应当说住在孔中；如果住在实体之中，实体不是空的，虚空就不能住在其中，因为实体不能容受。

再者，你说：“住处就是虚空。”如石壁的实体之中，没有住处；没有住处就没有虚空；因为虚空没有住处，所以没有虚空。

再者，因为没有相，所以没有虚空。诸法各有各的相，有相所以知道有法。如地是坚相，水是湿相，火是热相，风是动相，识是了别之相，慧是解了之相，世间是生灭之相，涅槃是永灭之相；这虚空没有相，所以没有。

问：虚空有相，你不知道，所以说没有；没有色的地方，就是虚空之相。

答：不是这样！“无色”是指破除了色，此外没有别的法，如同灯灭了，此外没有别的法。所以没有虚空之相。

再者，这虚空之法是没有的。为什么？你是因为色，才以没有色的地方为虚空之相。如果这样，色还没有生起时，就没有虚空之相。

再者，你认为：“色是无常法，虚空是常法。”那么色还没有存在时，就应当先有虚空之法，因为虚空是常。如果色还没有存在，就没有“无色之处”；没有“无色之处”，就没有虚空之相；没有相就没有法。所以虚空只有名称，没有实体。

如同虚空，诸法也是这样，只有假名而没有实体。

所以说“诸菩萨知诸法如虚空”。

所谓“如响”：在深山狭谷中，或者在深而险绝的山涧中，或者在空旷的大房子里，有说话的声音或敲打的声音，从声音又产生声音，名为“响”。无智的人以为有人在说话；有智慧的人心想：“这声音没有人造作，只是因为声音触碰，所以又有声音，名为响。响这件事是空的，能欺骗耳根。”

如人想说话时，口中的风名为忧陀那，回到脐部，触到脐部而发出声响；声响发出时，触到七个部位而退回，这名为言语。如偈中说：

```
风名忧檀那，　触脐而上去；
是风七处触，　项及龂齿唇，
舌咽及以胸，　是中语言生。
愚人不解此，　惑著起瞋痴；
中人有智慧，　不瞋亦不著，
亦复不愚痴，　但随诸法相。
曲直及屈申，　去来现语言，
都无有作者。　是事是幻耶？
为机关木人？　为是梦中事？
我为热气闷，　有是为无是？
是事谁能知？　是骨人筋缠，
能作是语声，　如融金投水。
```

大意：有一种风名为忧檀那，触到脐部而向上走；这风触到七个部位，就是颈项、牙龈、牙齿、嘴唇、舌头、咽喉与胸部，言语就在这其中生起。愚人不懂这道理，迷惑执着，生起瞋与痴；中等的人有智慧，不瞋也不执着，也不愚痴，只是随顺诸法之相。弯曲与伸直、屈与伸、去与来、显现的言语，都没有造作者。这件事是幻术吗？是机关木人吗？是梦中的事吗？还是我被热气闷昏了？这到底是有还是没有？这件事谁能知道？这由筋缠绕骨头而成的人，能发出这样的言语声音，就像熔化的金子投入水中发出声响一样。

所以说“诸菩萨知诸法如响”。

所谓“如犍闼婆城”：太阳刚升起时，看见城门、楼橹、宫殿，行人出入；太阳越升越高，景象就越来越淡，直至消失。这城只能用眼睛看见，却没有实体，名为犍闼婆城。

有一个人从前没有见过犍闼婆城，早晨向东方看见了，以为真是快乐之处，就快步奔去，越走近越消失，太阳升高就完全不见了。这人饥渴闷极，看见热气浮动如同野马，以为是水，就快步奔去，越走近越消失。疲惫困顿到极点，走到穷山狭谷中，大声呼喊啼哭，听到有回响应答，以为有居民，去寻找，疲惫至极，却什么也没看见。这人思惟之后自己醒悟，渴求的心就止息了。无智的人也是这样，在空的阴、界、入中见到吾我与诸法，以淫欲、瞋恚之心执着，四处狂奔，求乐以满足自己，被颠倒所欺诳，穷困已极，懊恼不已；如果以智慧知道无我、没有真实之法，这时颠倒之愿就止息了。

再者，犍闼婆城不是城，人心中想象它是城；凡夫也是这样，不是身而想象为身，不是心而想象为心。

问：一件事已经可以知道了，为什么要用这么多譬喻？

答：我先前已经回答过，这摩诃衍如同大海水，摄尽一切法；摩诃衍因为因缘多，所以用很多譬喻，并无过失。

再者，这些菩萨智慧甚深锐利，以种种法门、种种因缘、种种譬喻破除诸法；为了使人理解，应当多引譬喻。

再者，在一切声闻法中，没有犍闼婆城的譬喻，有种种其他的无常譬喻：“色如聚沫，受如水泡，想如野马，行如芭蕉，识如幻”，以及《幻网经》中的空譬喻。因为犍闼婆城的譬喻不同，所以在这里说。

问：声闻法中以城比喻身体，这里为什么说犍闼婆城的譬喻？

答：声闻法中的城，比喻众缘是真实存在的，只是“城”是假名；犍闼婆城连众缘也没有，如同旋转的火轮，只是迷惑人的眼睛。声闻法中为了破除吾我，所以以城为喻；这里的菩萨根性锐利，深入诸法空性之中，所以以犍闼婆城为喻。

【译注】这一问答点出了声闻空与大乘空的分界。声闻以城喻身：砖木等众缘实有，只是“城”这个总名是假，破的是我执；大乘以犍闼婆城为喻：连构成城的众缘也没有，如旋火轮，纯是迷眼之相，破的是法执。同是说“空”，一个空到总名为止，一个连支撑总名的众缘也一并空去。

所以说“如犍闼婆城”。

所谓“如梦”：如梦中没有真实的事，却以为是真实的，醒来之后知道没有，自己也觉得好笑；人也是这样，在诸结使的睡眠中，实际没有却执着为有，得道觉醒时，才知道没有真实，也会自己觉得好笑。所以说“如梦”。

再者，梦是因为睡眠之力，没有某种事物却能看见；人也是这样，因为无明睡眠之力，种种本来没有的却看见为有，就是我、我所、男女等。

再者，如梦中没有可喜的事却欢喜，没有可瞋的事却瞋恚，没有可怕的事却恐怖；三界众生也是这样，因为无明睡眠，不应当瞋却瞋，不应当喜却喜，不应当怖却怖。

再者，梦有五种：如果身体不调和，热气多，就多梦见火，梦见黄色、红色；如果冷气多，就多梦见水，梦见白色；如果风气多，就多梦见飞，梦见黑色；又，所闻所见的事多加思惟忆念，所以梦见；或者天神给予梦境，想让人知道未来的事。这五种梦都没有真实的事，却虚妄地看见。人也是这样，五道中的众生，以身见之力为因缘，见到四种我：色阴是我，色是我所，我中有色，色中有我；如同色，受、想、行、识也是这样；四乘以五，共二十种。得道而以真实智慧觉醒之后，知道这些都没有真实。

问：不应当说“梦没有真实”！为什么？识心得到因缘才会生起；梦中的识有种种所缘，如果没有这些所缘，怎能生起识？

答：没有真实！不应当见到的却见到了，梦中见到人头上有角，或者梦见身体在虚空中飞，人实际上没有角，身体也不会飞，所以没有真实。

问：确实有人头，别处也确实有角；因为心迷惑了，所以见到人头上有角。确实有虚空，也确实有能飞的东西；因为心迷惑了，所以自己见到身体在飞，并不是没有真实。

答：虽然确实有人头，确实有角，但人头上生角，就是虚妄所见。

问：世界广大，前世的因缘种种不同；或者有其他国家，人头上生角，或者只有一手一足，有一尺高的人，有九个头的人，人有角有什么奇怪的？

答：如果是其他国家的人有角，可以这样说；但是梦见这个国家所认识的人有角，那就不可能是真实的。

再者，如果有人梦见虚空的边际、方位的边际、时间的边际，这件事怎会有真实？哪里会没有虚空、没有方位、没有时间？所以梦中是没有而见为有。

你先前说：“没有所缘，怎能生起识？”虽然没有五尘为所缘，因为自己思惟忆念之力的运转，所以以法为所缘而生起识。如有人说“有两个头”，因为言语而生起想象；梦中没有而见为有，也是这样。

诸法也是这样，诸法虽然没有，却可见、可闻、可知。如偈中说：

```
如梦、如幻、　如犍闼婆；　一切诸法，
亦复如是。
```

大意：如梦，如幻，如犍闼婆城；一切诸法，也是这样。

所以说“诸菩萨知诸法如梦”。

所谓“如影”：影子只能看见，却不能捉取；诸法也是这样，眼等六情所见闻觉知的，实际上不可得。如偈中说：

```
是实知慧，　四边叵捉；　如大火聚，
亦不可触；　法不可受，　亦不应受。
```

大意：这真实的智慧，从四边都无法捉取，如同大火聚，也不可触碰；法不可执受，也不应当执受。

再者，如影子，有光照就显现，没有光照就没有；诸结使烦恼遮蔽了正见之光，就有我相、法相的影子。

再者，如影子，人走它就走，人动它就动，人停它就停；善恶业的影子也是这样，去往后世时它也跟去，今世住时它也住，因为果报不断，罪福成熟时就显现出来。如偈中说：

```
空中亦逐去，　山石中亦逐，
地底亦随去，　海水中亦入！
处处常随逐，　业影不相离。
```

大意：在空中也追随而去，在山石中也追随，到地底也跟着去，进入海水中也跟着进入！处处常常追随，业的影子与人不相分离。

所以说“诸法如影”。

再者，如影子空无，寻求其真实不可得；一切法也是这样，空而没有真实。

问：影子空而没有真实，这话不对！为什么？《阿毗昙》中说：“什么名为色入？青、黄、赤、白、黑、缥、紫、光、明、影等，以及身业的三种作色，这名为可见的色入。”你怎么说没有？

再者，影子确实存在，因为有因有缘：因是树，缘是光明，这两件事和合，就有影子生起，怎么说没有？如果影子没有，其余从因缘而有的诸法，也都应当没有！

再者，这影子之色，可以看见长短、大小、粗细、曲直，形体动，影子也动，这些事都可以看见，所以应当是有。

答：影子实际上是空无的。你说阿毗昙中这样说，那是解释阿毗昙义理的人所作的；只说了一种法门，人们不体会其中的用意，执取为真实。如《鞞婆沙》中说：“微尘极细，不可破，不可烧。”这就是常有！又说：“三世中的法，从未来出到现在，从现在入到过去，没有丢失。”这就是常！又说：“诸有为法，念念新生灭，不停住。”如果这样，这就是断灭之相！为什么？因为先有而今无。

像这样种种不同的说法，违背佛语，不能以此为证。

影子与色法不同：色法生起，必定有香、味、触等，影子却不是这样，所以影子不是实有。

如瓶子，可以由两根了知，就是眼根与身根；影子如果实有，也应当可以由两根了知，却没有这样的事。所以影子不是实有之物，只是欺诳眼睛的法；如同手持火把快速旋转，看起来成了火轮，并不真实。

影子不是实有之物！如果影子是实有之物，应当可以破、可以灭；如果形体不灭，影子终究不会坏，所以是空。

再者，影子属于形体，不自在，所以是空；虽然是空，心中却会生起眼见之识。

所以说“诸法如影”。

所谓“如镜中像”：如镜中的像，不是镜子造作的，不是面孔造作的，不是拿镜子的人造作的，也不是自然而然造作的，也不是没有因缘。

为什么不是镜子造作的？如果面孔没有到镜前，镜中就没有像，所以不是镜子造作的。

为什么不是面孔造作的？没有镜子就没有像。

为什么不是拿镜子的人造作的？没有镜子、没有面孔，就没有像。

为什么不是自然而然造作的？如果还没有镜子，还没有面孔，就没有像；像要依待镜子、依待面孔然后才有，所以不是自然而然造作的。

为什么不是没有因缘？如果没有因缘，像就应当常有；如果常有，即使去掉镜子、去掉面孔，像也应当自己出现。所以不是没有因缘。

诸法也是这样，不是自己造作，不是他者造作，不是自他共同造作，也不是没有因缘。

为什么不是自己造作？因为我不可得，一切从因所生的法都不自在，诸法属于因缘，所以不是自己造作。

也不是他者造作：自己既然没有，他者也就没有；如果是他者造作，就失去了罪福的力量。他者造作有两种：或者是善，或者是不善。如果是善，就应当给予一切快乐；如果是不善，就应当给予一切痛苦。如果苦乐相杂，凭什么因缘给予快乐？凭什么因缘给予痛苦？

如果是自他共同造作，就有两重过失：自作的过失与他作的过失。

如果没有因缘而生起苦乐，人就应当常乐，离开一切苦；如果没有因缘，人就不应当去作乐的因、除苦的因。一切诸法必定有因缘，只是因为愚痴，所以不知道。

譬如人从木头中求火，从地中求水，从扇子中求风；像这样种种，各有因缘。这苦乐是和合的因缘，从和合的因缘而生：前世的业为因，今世或者善行、或者邪行为缘，从中得到苦或乐。这苦乐的种种因缘，以真实去寻求，没有造作的人，也没有感受的人，只是空的五众造作，空的五众感受。无智的人得到快乐，就以淫心爱着；得到痛苦，就生起瞋恚；这快乐灭去时，又再寻求想要得到。如同小孩子看见镜中的像，心中喜爱执着，失去了所爱着的像，就打破镜子去寻找，有智慧的人看了就笑；失去快乐又再寻求，也是这样，也为得道的圣人所笑。

所以说诸法如镜中像。

再者，如镜中的像实际上是空，不生不灭，欺诳迷惑凡人的眼睛；一切诸法也是这样，空而没有真实，不生不灭，欺诳迷惑凡夫人的眼睛。

问：镜中的像从因缘而生，有面孔、有镜子、有拿镜子的人、有光明，这些事和合，所以像生起；因为这像，人生起忧喜，像也能作因，也能作果，怎么说“实际上是空，不生不灭”？

答：从因缘而生，不自在，所以是空。如果法是真实存在的，也就不应当从因缘而生。为什么？如果因缘中先已有果，因缘就没有用；如果因缘中先没有果，因缘也没有用。

譬如乳中如果先已有酪，这乳就不是酪的因，因为酪先已存在；如果乳中先没有酪，如同水中没有酪，这乳也就不是酪的因；如果没有因而能有酪，水中为什么不生出酪？如果乳是酪的因缘，乳也不自在，乳也从因缘而生；乳从牛而有，牛从水草而生，像这样无边无际，都有因缘。所以，因缘中的果，不能说有，不能说无，不能说亦有亦无，不能说非有非无；诸法从因缘而生，没有自性，如同镜中之像。如偈中说：

```
若法因缘生，　是法性实空；
若此法不空，　不从因缘有。
譬如镜中像，　非镜亦非面，
亦非持镜人，　非自非无因。
非有亦非无，　亦复非有无，
此语亦不受，　如是名中道。
```

大意：如果法从因缘而生，这法的本性实际上是空；如果这法不空，就不会从因缘而有。譬如镜中的像，不是镜子造作，也不是面孔造作，也不是拿镜子的人造作，不是自己造作，也不是没有原因。不是有，也不是无，也不是亦有亦无；连这样的话也不执受，这名为中道。

所以说“诸法如镜中像”。

所谓“如化”：有十四种变化心：初禅有两种，就是依欲界、依初禅的变化心；二禅有三种，就是依欲界、初禅、二禅；三禅有四种，就是依欲界、初禅、二禅、三禅；四禅有五种，就是依欲界、初禅、二禅、三禅、四禅。

这十四种变化心，能作八种变化：一是能变小，乃至小如微尘；二是能变大，乃至充满虚空；三是能变轻，乃至轻如鸿毛；四是能自在，能把大变小、把长变短，像这样种种；五是能有主力（有大力之人，无所屈下，所以说“有主力”）；六是能远到；七是能震动大地；八是随心所欲都能得到：一身能变作多身，多身能变作一身，石壁都能穿过，履水而行，凌空而走，手摸日月，能转变四大，把地变作水，把水变作地，把火变作风，把风变作火，把石头变作金子，把金子变作石头。

这变化又有四种：欲界中以药物、宝物、幻术能变化诸物；诸有神通的人以神力能变化诸物；天、龙、鬼神等以生来果报之力能变化诸物；色界众生以生来果报之力与修定之力能变化诸物。

如同化人没有生老病死，没有苦没有乐，与人的出生不同，所以是空而没有真实。一切诸法也是这样，都没有生、住、灭。

所以说“诸法如化”。

再者，化生没有确定的物质，只是以心生起，就有所造作，都没有真实；人身也是这样，本来没有所依的因，只是从前世的心，生出今世的身，都没有真实。

所以说“诸法如化”。

如变化之心灭了，化物也就灭了；诸法也是这样，因缘灭了，果也灭了，不自在。

如化出的事物虽然实际上是空的，却能使众生生起忧苦、瞋恚、喜乐、痴惑；诸法也是这样，虽然空而没有真实，却能使众生生起欢喜、瞋恚、忧怖等。

所以说“诸法如化”。

再者，如变化所生之法，没有开始、没有中间、没有终结；诸法也是这样。

如变化之物，生起时无所从来，灭去时也无所去；诸法也是这样。

再者，如变化之相，清净如同虚空，无所染着，不为罪福所污染；诸法也是这样，如同法性、如如、真际，自然常清净。譬如阎浮提的四条大河，每一条大河有五百条小河归属，这些河水种种不清净，流入大海之后都清净了。

问：不应当说变化之事是空。为什么？变化之心也是从修定而得，从这心作种种变化，或者变人，或者变物；这变化有因有果，怎么是空？

答：在“如影”中已经回答过了，现在再回答：这因缘虽然有，变化之果是空的。如口里说“无所有”，虽然是心生起而口说出，不能因为心与口是有的，所说的“无所有”就成了有；如果说“有第二个头、第三只手”，虽然是从心与口生出的，也不能说“有头、有手”。如佛说：观察无生，从有生中得到解脱；依于无为，从有为中得到解脱；虽然观察无生之法是无，却可以作为因缘，无为也是这样；变化虽然是空，也能作为生起心的因缘。

譬如幻、焰等九个譬喻，虽然没有实体，却能生起种种心。

再者，这变化之事，在六因四缘中寻求都不可得；因为在其中与六因、四缘都不相应，所以是空。

再者，空不是因为看不见才叫空，而是因为没有真实的作用，所以说空。

所以说“诸法如化”。

问：如果诸法与这十个譬喻都空，没有差别，为什么只以这十件事为譬喻，不以山、河、石壁等为譬喻？

答：诸法虽然空，却有分别：有难以理解的空，有容易理解的空；现在是以容易理解的空，比喻难以理解的空。

再者，诸法有两种：有心会执着之处，有心不会执着之处；以心不执着之处，来解开心执着之处。

问：这十个譬喻，为什么是心不执着之处？

答：这十件事不久住，容易生、容易灭，所以是心不执着之处。

再者，有人知道这十个譬喻是欺诳耳目之法，却不知道诸法空，所以以这十个譬喻来比喻诸法。

如果有人对这十个譬喻心生执着，不理解种种质难与论议，以为这十个譬喻是有，那么这十个譬喻对这个人就没有用，应当再为这个人说其他的法门。

问：如果诸法都空，不生不灭，这十个譬喻等种种譬喻、种种因缘论议，我已经都知道是空了；如果诸法都空，就不应当说这些譬喻；如果说这些譬喻，就是不空。

答：我说空，是为了破除诸法为有；现在所说的，如果说是有，先前已经破了；如果说是无，就不应当质难！

譬如管事的比丘高声举手宣告：“大众都安静！”这是以声音遮止声音，不是为了求得声音。所以，虽然说诸法空、不生不灭，是因为怜悯众生而说，虽然说了，所说的并不是有。

【译注】“以声遮声”是本论说明空的言说性质的名喻。说“空”本身也是一句话，龙树并不否认；这句话的作用只在遮止“有”，自身不立为一种主张，就像“大众安静”这声喊是为了让声音止息，喊的人并不是要求得更多声音。所以说空不落入自相矛盾。

所以说“诸法如化”。

【经】

得无碍无所畏。

【论】

在种种众、界、入的因缘中，心无碍、无尽、无灭，这是无碍无所畏。

问：如前面已经说诸菩萨在无量大众中无所畏，现在为什么又说“无碍无所畏”？

答：前面说的是无所畏的因，现在说的是无所畏的果。在诸大众乃至菩萨众中，说法无穷无尽，论议毫不减损，心中没有疑难，因为已经得到无碍无所畏。

再者，如前面说在无量大众中无所畏，不知道是凭什么力量而无畏；所以再说无所畏，是因为得到了无碍之力。

问：如果诸菩萨也有无碍无所畏，佛与菩萨有什么不同？

答：如我先前所说，诸菩萨自有菩萨的无所畏之力，所以在诸法中无所畏，不是佛的无所畏。

再者，无碍之法有两种：一是一切处无碍，二是非一切处无碍。所谓非一切处无碍，如进入一部经书乃至百千部经书中无碍，进入一个大众乃至百千个大众中无所畏；诸菩萨也是这样，在自己的智慧中无碍，在佛的智慧中则不然。如佛放下钵时，五百阿罗汉以及弥勒等诸菩萨都不能拿起；诸菩萨也是这样，在自己的力量中无碍，在佛的智慧力量中有碍。

所以说“诸菩萨得无碍无所畏”。

【经】

悉知众生心行所趣，以微妙慧而度脱之。

【论】

问：怎样是“悉知众生心行”？

答：知道众生的心在种种法中处处运行，如同日光普照；菩萨全都知道众生的心行有所趣向，于是教导众生说：“一切众生的趣向有两种：一是心常常求乐，二是以智慧分别，能知道好坏。你不要随着心而执着，应当随着智慧；应当自己责备自己的心：你无数劫以来，积集种种杂业而没有满足，只是追逐世间的快乐，不觉得这是苦。你没有看见世间贪乐招致祸患吗？在五道中受生，都是心所造作，是谁让你这样的？你如同狂象践踏伤害，没有约束，谁来调伏你！如果能得到好好调伏，就能离开世间的祸患。应当知道，住在胎中不清净、痛苦困厄，如同地狱；出生在世之后，有老、病、死之苦，忧悲万端。如果生到天上，还会再堕落。三界中没有安稳，你为什么乐着？像这样种种呵责自己的心，立誓不再随着心。”这是菩萨知道众生心行。

问：什么叫“以微妙慧而度脱之”？这里什么叫微妙慧？什么叫粗智慧？

答：世间的巧慧，名为粗智慧；行布施、持戒、禅定，名为微妙慧。

再者，布施之智是粗慧，持戒、禅定之智名为微妙慧。

再者，持戒、禅定之智是粗慧，禅定之智名为微妙慧。

再者，禅定之智是粗慧，无所依倚的禅定名为微妙慧。

再者，取着诸法之相是粗慧，对诸法之相不取不舍，名为微妙慧。

再者，破除无明等诸烦恼，得到诸法之相，名为粗慧；契入如实的法相，譬如真金不损不失，也如金刚不破不坏，又如虚空无染无着，名为微妙慧。

像这样等等无量的微妙慧，菩萨自己证得，又教导众生。

所以说“诸菩萨悉知众生心行所趣，以微妙慧而度脱之”。

## 初品中意无碍释论第十二

【经】

意无罣碍。

【论】

什么叫“意无罣碍”？

菩萨对一切怨家、亲人、非怨非亲的人，平等心而没有障碍。

再者，一切世界的众生中，如果有人来侵害，心中不恚恨；如果有人以种种方式恭敬，心中也不喜悦。如偈中说：

```
诸佛菩萨，　心不爱著；　外道恶人，
心不憎恚。
```

大意：对诸佛菩萨，心不爱着；对外道恶人，心不憎恚。

像这样清净，名为意无罣碍。

再者，在诸法中心无障碍。

问：这菩萨还没有得到佛道，还没有得到一切智，怎么在诸法中心无障碍？

答：这菩萨得到无量清净的智慧，所以在诸法中心无障碍。

问：诸菩萨因为还没有得到佛道，不应当有无量智慧；因为还有残余的结使，不应当有清净智慧。

答：这些菩萨不是三界中由结使与业所成的肉身，都已得到法身自在，超过老病死；因为怜悯众生，所以在世间中行走；为了庄严佛土，教化众生；已经得到自在，想成佛就能成佛。

问：如果是法身菩萨，就与佛没有差别，为什么还称为菩萨？为什么还要礼佛听法？

如果与佛有差别，怎会有无量清净的智慧？

答：这菩萨虽然是法身，没有老病死，与佛仍有少许差别。譬如每月十四日的月亮，众人生疑，不知道是圆还是不圆；菩萨就是这样，虽然能作佛、能说法，然而还没有真正成佛。佛如同十五日的月亮，圆满无疑。

再者，“无量”与“清净”各有两种。一种是：实际上是有量的，对于不能测量的人来说，称为无量。譬如海水、恒河沙等，人不能测量，称为无量；对诸佛菩萨来说，并不是无量。菩萨的无量清净智也是这样，诸天、人以及声闻、辟支佛所不能测量，称为无量智。

菩萨得到无生道时，诸结使断除，所以得到清净智。

问：如果那时已经断除诸结使，成佛时又断什么？

答：这清净有两种：一是成佛时，结使全部除尽，得到真实的清净；二是菩萨舍弃肉身、得到法身时，断除诸结使而得的清净。

譬如一盏灯能除去黑暗，能借着这光做事；再有一盏大灯，就更加明亮。佛与菩萨断除诸结使也是这样，菩萨所断的，虽然称为已断，相对于佛所断的，仍然没有断尽。

这名为“因为得到无量清净智，所以在诸法中意无罣碍”。

【经】

大忍成就。

【论】

问：前面已经说过等忍、法忍，现在为什么又说“大忍成就”？

答：这两种忍增长了，名为大忍。

再者，等忍是在众生中一切都能忍；柔顺法忍是在甚深法中能忍。这两种忍增长而作证，就得到无生忍；在最后的肉身中，见到十方诸佛化现在面前，坐在空中，这名为“大忍成就”。

譬如声闻法中：暖法增长名为顶法，顶法增长名为忍法，此外并没有另外一种法增长而成为不同的东西。等忍、大忍也是这样。

再者，有两种忍：生忍、法忍。生忍就是在众生中忍，如在恒河沙数的劫中，众生以种种方式加害，心不瞋恚；以种种方式恭敬供养，心不欢喜。

再者，观察众生没有开始：如果有开始，就没有因缘；如果有因缘，就没有开始。如果没有开始，也应当没有终结。为什么？因为开始与终结是相待而成的。如果没有开始与终结，中间也应当没有。这样观察时，不落入常、断二边，以安稳之道观察众生，不生邪见，这名为生忍。

对甚深之法心无罣碍，这名为法忍。

问：什么是甚深法？

答：如先前在“甚深法忍”中所说。

再者，所谓甚深法，就是在十二因缘中辗转生果，因中不是有果，也不是没有果，果却从因中出来，这名为甚深法。

再者，进入空、无相、无作三解脱门，就能得到涅槃常乐，这名为甚深法。

再者，观察一切法非空非不空，非有相非无相，非有作非无作；在这样的观察中心也不执着，这名为甚深法。如偈中说：

```
因缘生法，　是名空相，　亦名假名，
亦名中道。　若法实有，　不应还无，
今无先有，　是名为断。　不常不断，
亦不有无；　心识处灭，　言说亦尽。
```

大意：因缘所生之法，名为空相，也名为假名，也名为中道。如果法是真实存在的，就不应当又变为无；先有而今无，这名为断。不常不断，也不有不无；心识活动之处灭尽，言说也穷尽。

对这甚深之法，信心无碍，不后悔，不退没，这名为“大忍成就”。

【经】

如实巧度。

【论】

有些外道之法，虽然度化众生，却不是如实地度化。为什么？因为还残留种种邪见与结使。

二乘虽然有所度化，却不能如所应度那样度化。为什么？因为没有一切智，方便之心薄弱。

唯有菩萨能如实巧度。

譬如渡船的人：一个人用浮囊、草筏渡人，一个人用方舟渡人，两种渡法相差悬殊；菩萨巧妙地度化众生也是这样。

再者，譬如治病：用苦药、针灸，虽然痛苦，病也能痊愈；又如有一种妙药，名叫苏陀扇陀，病人眼睛一看见，种种病都痊愈了。除病虽然相同，方法却有优劣之分。

声闻与菩萨教化度人也是这样。修苦行头陀，初夜、中夜、后夜勤心坐禅，观察苦而得道，这是声闻的教法。观察诸法之相，无缚无解，心得清净，这是菩萨的教法。如文殊师利的本缘：

文殊师利对佛说：“大德！过去世中，在无量阿僧祇劫以前，那时有佛名叫狮子音王，佛与众生的寿命都是十万亿那由他岁，佛以三乘度化众生。国名千光明，那国中的树都是七宝所成，树中发出无量清净的法音，就是空、无相、无作、不生不灭、无所有之音，众生听了，心中开解而得道。

“当时狮子音王佛初会说法，有九十九亿人证得阿罗汉道，菩萨众也是这样多。这些菩萨全都证得无生法忍，进入种种法门，见到无量诸佛，恭敬供养，能度化无量无数的众生，得到无量陀罗尼门，能得到无量种种三昧。初发心、新入道门的菩萨，多得不可称数。这佛土有无量庄严，说也说不尽。当时佛教化完毕，入无余涅槃；佛法住世六万年，诸树的法音也不再发出了。

“那时，有两位菩萨比丘：一位名叫喜根，一位名叫胜意。

“这位喜根法师，容貌仪态质朴正直，不舍弃世间之法，也不分别善恶。

“喜根的弟子聪明乐法，喜欢听闻深义；他们的老师不赞叹少欲知足，不赞叹戒行头陀，只说诸法实相清净。喜根对弟子们说：‘一切诸法的淫欲相、瞋恚相、愚痴相，这些法相就是诸法实相，没有罣碍。’以这样的方便，教导弟子们进入一相之智。当时弟子们在人群中无瞋无悔；因为心不悔，所以得到生忍；因为得到生忍，所以得到法忍，在真实之法中不动如山。

“胜意法师持戒清净，修行十二头陀，得到四禅、四无色定。

“胜意的弟子们根性迟钝，多所求取，分别这是清净、那是不清净，心就随之动转。

“胜意有一次进入村落，到了喜根一位弟子的家中，在座位上坐下；赞叹持戒、少欲、知足、行头陀行、在闲静处禅寂，并诋毁喜根说：‘这个人说法，教人进入邪见之中；他说淫欲、瞋恚、愚痴是无罣碍之相，他是杂行之人，不是纯净清净的。’

“这位弟子根性锐利，已得法忍，问胜意说：‘大德！这淫欲之法是什么相？’

“胜意回答：‘淫欲是烦恼相。’

“问道：‘这淫欲烦恼，是在内呢？还是在外呢？’

“胜意回答：‘这淫欲烦恼不在内，也不在外。如果在内，就不应当依待外在的因缘而生；如果在外，与我无关，就不应当恼害我。’

“居士说：‘如果淫欲不在内，不在外，不在东、西、南、北、四维、上下，来来去去遍求它的实相都不可得，这法就是不生不灭；如果没有生灭之相，空无所有，怎能恼害人？’

“胜意听了这话，心中不悦，不能再回答，从座位上站起来，说：‘喜根欺骗了很多人，使人陷入邪道之中。’

“这位胜意菩萨没有学过音声陀罗尼，听到佛所说的就欢喜，听到外道所说的就瞋恚；听到三不善法就不欢悦，听到三善法就大欢喜；听到说生死就忧愁，听到涅槃就欢喜。

“胜意从居士家来到林间，进入精舍中，对诸比丘说：‘应当知道喜根菩萨这个人虚妄欺诳，使很多人陷入邪恶之中。为什么？他说淫、恚、痴之相，以及一切诸法，都是无碍之相。’

“这时，喜根这样想：‘这个人大起瞋恨，被恶业所遮蔽，将会堕入大罪！我现在应当为他说甚深之法，虽然他现在一无所得，可以为他作后世成就佛道的因缘。’于是，喜根集合僧众，一心说偈：

```
淫欲即是道，　恚痴亦如是；
如此三事中，　无量诸佛道。
若有人分别，　淫怒痴及道，
是人去佛远，　譬如天与地。
道及淫怒痴，　是一法平等；
若人闻怖畏，　去佛道甚远。
淫法不生灭，　不能令心恼，
若人计吾我，　淫将入恶道。
见有无法异，　是不离有无；
若知有无等，　超胜成佛道。
```

“大意：淫欲就是道，恚与痴也是这样；在这三件事中，有无量的诸佛之道。如果有人把淫、怒、痴与道分别开来，这个人离佛很远，如同天与地之隔。道与淫、怒、痴，是一法而平等；如果有人听了感到恐惧，离佛道就非常远。淫欲之法不生不灭，不能使心恼乱；如果有人执着吾我，淫欲就会把这个人带入恶道。见到有法与无法相异，这就没有离开有无；如果知道有与无平等，就能超胜而成就佛道。

“喜根说了这样等等七十多首偈，当时有三万天子证得无生法忍，一万八千声闻人因为不执着一切法，都得到解脱。

“这时，胜意菩萨的身体当即陷入地狱，受了无量千万亿年的苦！出生到人间之后，七十四万世常被人诽谤，无量劫中听不到佛的名字。这罪渐渐减轻之后，得以听闻佛法，出家修道，却又舍戒还俗，像这样六万三千世常常舍戒；在无量世中作沙门，虽然不再舍戒，却诸根暗钝。

“这位喜根菩萨，如今在东方过十万亿佛土之外作佛，那国土名叫宝严，佛号光逾日明王。”

文殊师利说：“那时的胜意比丘，就是我的前身。我观察到那时受了这样无量的苦。”

文殊师利又对佛说：“如果有人求三乘道，不想遭受种种痛苦，就不应当破坏诸法之相而心怀瞋恚。”

佛问文殊师利：“你听了那些偈，得到什么利益？”

文殊师利回答：“我听了这些偈，得以了结众苦，世世得到锐利的根性与智慧，能理解甚深之法，善巧宣说甚深的义理，在诸菩萨中最为第一。”

像这样等等，名为巧说诸法之相。

这名为“如实巧度”。

【译注】喜根、胜意一段，经中自己点明了要害：喜根教弟子“入一相智”，是在诸法实相上说淫、恚、痴无罣碍；胜意的过失，在于“未学音声陀罗尼”，闻善则喜、闻恶则瞋，听到实相之说便起大瞋、诋毁说法者。文殊的结论是“不应破诸法相而怀瞋恚”。喜根偈中自己也说“若人计吾我，淫将入恶道”，平等的前提是不计吾我。

## 本卷要义

十喻是本卷的主体，但龙树开篇就回应了一个最实在的质疑：如果一切都空，为什么看得见第一片指甲，看不见第二片？为什么眼不闻声、耳不见色？回答是：空并不取消分别。幻化的象马同样色可见、声可闻，与六情相对不相错乱。《德女经》把这一点推到最根本处：无明不在内、不在外、不在内外，不从前世来、不往后世去，没有生者灭者，也没有实性，却仍然“无明缘行，乃至众苦集”；正如幻术无根而伎乐可见可闻。空是就实性说，缘起是就作用说，两者从来不在同一个层面上相争。

十喻并不是同一个意思说十遍，每一喻各自击破一种执取的支点。焰是远看为水、近看则无：执着来自远离圣法。水中月是天上之月映在心水：实相本在，凡夫只见映在心中的我相，以智慧之杖搅水，影便散了。虚空一段最有论辩力，龙树追问虚空的住处与相，证明虚空只是“无色处”的假名，色未生时连这假名也无从安立。响破的是“有说话者”，梦破的是“有所缘就有实物”，影破的是阿毗昙“影是色入”的实有论，镜中像以“非镜作、非面作、非持镜者作、非自然、非无因”展开了中观的四句破，化则说明“心灭化灭”、因缘尽则果尽。到了镜中像的偈，“非有亦非无，亦复非有无，此语亦不受，如是名中道”，连否定四句的话本身也不执受，这才是十喻真正的落点。

犍闼婆城一问，点出了大乘空与声闻空的分界。声闻以城喻身，砖木众缘实有，只破“城”这个总名，用来破我执；犍闼婆城连众缘也没有，如旋火轮，只是惑人眼目，用来破法执。十喻之所以选这十件事，也有讲究：它们“不久住，易生易灭”，是人心本来就不执着的东西；以心不著处来解心著处，以易解之空喻难解之空。最后一问把整套方法收住：既然说空，说这些譬喻岂不是有？龙树答，空是用来破有的，如维那喊“大众安静”，是以声遮声，不是在求声。说空并不在空之外另立一法。

卷末喜根、胜意的本缘，是十喻在修行上的一面镜子。胜意持戒清净、得四禅四空定，却“未学音声陀罗尼”，闻佛语则喜、闻外道语则瞋，闻生死则忧、闻涅槃则喜，心随名言动转；一听“淫欲是道”便起大瞋，结果堕地狱、七十四万世被谤。喜根所说的“道及淫怒痴，是一法平等”，正是十喻要人看见的东西：诸法如幻如化，淫怒痴也没有实在的自相可以恼人，恼人的是“计吾我”。文殊自陈前身就是胜意，所得的教训落在一句话上：不应破诸法相而怀瞋恚。持戒与禅定若不通于实相，仍会在一句话面前失守。
