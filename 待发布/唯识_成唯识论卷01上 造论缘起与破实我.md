本篇要目：一、归敬与造论的三重缘起　二、第一颂：我和法都依识假立　三、三种实我及其破斥　四、即蕴、离蕴与有无思虑作用　五、我见的所缘与两种我执　六、三个问难与回答

一、归敬与造论的三重缘起

```
稽首唯识性　满分清净者
我今释彼说　利乐诸有情
```

大意：顶礼证得唯识真性的诸佛与菩萨，诸佛圆满清净，菩萨分证清净。现在解释世亲菩萨的颂文，为了利益安乐一切有情。

现在造《成唯识论》，第一个目的，是让对我空、法空迷惑错谬的人生起正确的理解。让人生起正确的理解，是为了断除两种沉重的障碍。两种障碍都从执着生起：执着实我，生起烦恼障；执着实法，生起所知障。证得我空和法空，两种障碍就随之断除。断除障碍，是为了得到两种殊胜的果。断除令生死相续的烦恼障，证得真解脱；断除障碍正确认识的所知障，证得大菩提。

第二个目的，是向错误执着我和法、对唯识道理迷惑的人开示，让迷惑的人通达我空和法空，如实了知唯识的道理。

第三个目的，是纠正四种对唯识道理的错误理解。第一种人认为，外境和识一样真实存在。第二种人认为，内识和外境一样并不存在。第三种人认为，诸识的作用各不相同，诸识的体性是同一个。第四种人认为，离开心王，没有另外的心所。为了遮止种种错误执着，让人对唯识深妙的道理得到如实的理解，所以造《成唯识论》。

【译注】依《述记》，四种错误理解分别指：说一切有部等小乘，认为境与识都实有；清辨论师等，依空性经教而说识也非有；大乘中一类论师，认为八识只是一个识体；经部的觉天论师等，认为心所就是心王。

外人质问：如果只有识，为什么世间和圣教都说有我、有法？世亲菩萨用颂回答：

```
由假说我法　有种种相转
彼依识所变　此能变唯三
谓异熟思量　及了别境识
```

大意：世间与圣教所说的我和法，都是假立的名言，假立的我相和法相种种不同。种种我相、法相都依识所变现而施设。能够变现的识只有三类：异熟识、思量识、了别境识。

二、第一颂：我和法都依识假立

论中解释：世间和圣教说有我、有法，只是假立，我和法并没有真实的自性。

```
我谓主宰，法谓轨持。
```

大意：我是主宰，法是轨持。

【译注】窥基大师解释：主如国君，能自在作主；宰如宰相，能裁断事务。“我”就是被认为在身心之中自在作主、裁断一切的那个主人。轨是轨范，一样事物有固定的样子，人就能照着样子认出这样事物；持是任持，一样事物守住自己的特性，不会失去。“法”就是任何守住自身特性、让人能够照着特性认出来的事物。用现代话说破：“我”是被当作主体的东西，“法”是被当作对象的东西。世间与圣教所说的一切，不出主体和对象两类。第一颂要破的，正是“真有一个主体”和“真有种种对象”两种根深蒂固的认定。

我和法都有种种不同的相状在流转。我的种种相状：世间所说的有情、命者等，圣教所说的预流、一来等。法的种种相状：世间所说的实、德、业等，圣教所说的蕴、处、界等。“转”的意思是，随着不同的因缘，施设出不同的名目。

【译注】实、德、业是胜论外道六句义的前三项，分别指实体、属性、运动。预流、一来是声闻四果的前二果，圣教用预流、一来等名称称呼修行者，也是假立的“我”。

外人质问：种种相状如果都是假说，依什么而成立？论主回答：种种我相、法相，都依识所转变而假立施设。

识的意思是了别。这里所说的“识”也包括心所，因为心所与识必定相应。变的意思是，识体转起时，显现为相分和见分两部分；相分和见分都依自证分生起。依相分和见分施设我和法；我和法离开相分和见分，就没有所依。

【译注】相分是心中显现的影像，见分是认识影像的作用，自证分是相分和见分共同的识体。四分的详细辨析在卷二。

对“变”还有另一种解释：内识转起，显现得好像外境。由于过去分别我、法所留下的熏习力，诸识生起时，就变现出似我、似法的影像。似我、似法的影像存在于内识之中，由于分别的作用，显现得好像在心外。

有情从无始以来，以内识变现的影像为所缘，执着为实我、实法。如同眼睛患病的人和做梦的人，由于病和梦的力量，心中显现种种好像外境的相状，就以心中的相状为所缘，执着为真实存在的外境。

愚夫所计度的实我、实法，完全没有，只是随着虚妄的情执而施设，所以说为“假”。内识所变现的似我、似法，确实存在，并不是真实的我和法的体性；似我、似法只是显现得像我和法，所以也说为“假”。

外境随着情执而施设，所以外境不像识那样存在。内识必定依因缘而生，所以内识不像外境那样不存在。内识与外境如此分判，就同时遮除了增益和损减两种执着：执着外境实有是增益，否定内识存在是损减。

```
境依内识而假立故唯世俗有，
识是假境所依事故亦胜义有。
```

大意：外境依内识而假立，所以外境只是世俗的存在；识是假立外境所依托的实事，所以识也是胜义的存在。

【译注】这里的“胜义有”，是说识依因缘真实生起，相对于随情施设的外境而言是实有，并不是说识就是真如。

三、三种实我及其破斥

外人质问：怎么知道实际上没有外境，只有内识显现为外境而生起？论主回答：因为实我和实法都找不到。

外人质问：实我为什么找不到？论主回答：外道所执的我，大略有三种。第一种主张，我体常住，周遍一切处，体量等同虚空，我随所在之处造业、感受苦乐。第二种主张，我体常住，体量不定，随身体大小有伸有缩。第三种主张，我体常住，极细如一个极微，潜在身中运转，造作事业。

【译注】依《述记》，第一种是数论、胜论等外道的主张，第二种是无惭外道（即裸形的尼乾子）的主张，第三种是兽主、遍出等外道的主张。

第一种主张不合道理。原因是：我若常住周遍、体量等同虚空，我就不应随着身体感受苦乐；我若常住周遍，就不会移动，又怎能随着身体造作种种业？

论主再问：一切有情的我，是同一个我，还是各不相同的我？

如果说是同一个我，一人作业时，一切人都应作业；一人受果时，一切人都应受果；一人解脱时，一切人都应解脱。这是极大的过失。

如果说是各不相同的我，各人的我都周遍一切处，互相遍满，各人的我体就应混杂在一起。一人作业、受果时，所在之处与一切人的我所在之处没有分别，这次作业、受果就应称为一切人的作业、受果。

外人辩解：作业和受果各有归属，没有“一人作业、一切受果”的过失。论主回答：外人的辩解也不合道理。业、果和身体与一切人的我都结合在一起，说业果只属于某一个我、不属于其余的我，不合道理。一人解脱时，一切人都应解脱，因为所修所证的法与一切人的我都结合在一起。

第二种主张也不合道理。原因是：我体若是常住，就不应随身体伸缩。我体既有伸缩，就像风箱里的风一样，不是常住。我体随着身体大小变化，就应当可以分割，怎能执着我体是一？所以第二种主张如同儿童的游戏。

第三种主张也不合道理。原因是：我的体量若极小，如同一个极微，怎能让整个大身体处处都动？外人辩解：我体虽小，在身中迅速巡行，如同旋转的火把画出火轮，看起来处处都在动。论主回答：我体若在身中巡行，所执的我就既不是一，也不是常，因为凡是有往来的东西，都不是常，也不是一。

四、即蕴、离蕴与有无思虑作用

所执的我，还可以分为三种：第一种，我就是五蕴；第二种，我离开五蕴而存在；第三种，我与五蕴不即不离。

第一种“即蕴我”不合道理，因为我若就是五蕴，我就应和五蕴一样，不是常，也不是一。再分别来看：身内的色法，必定不是实我，因为身内色法有质碍，如同身外的色法。心王与心所，也不是实我，因为心王与心所不恒常相续，要依待众缘才生起。其余的行蕴和色蕴，也不是实我，因为其余的行蕴和色蕴没有觉知的特性，如同虚空。

【译注】“其余的行蕴和色蕴”，指不属于心所的行蕴（如命根、得等不相应行）和不属于身内根身的色蕴（如无表色）。论中依次逐蕴排除，五蕴之中没有一处可以安立实我。

第二种“离蕴我”也不合道理，因为离开五蕴的我，应当像虚空一样，既不能作业，也不能受果。

第三种“非即非离我”也不合道理。持第三种主张的人承认，我依五蕴而安立，既不是五蕴，也不离五蕴。论主破斥：

主张是：非即非离的我不是实我。理由是：持论者承认非即非离的我依五蕴而立，既不即蕴也不离蕴。例证是：如同瓶子依泥土等而立，瓶子不是实物。

持论者又说，非即非离的我既不可说是有为，也不可说是无为。论主回答：既然如此，非即非离的我也应不可说是我，也不可说不是我。所以持论者所执的实我不能成立。

【译注】依《述记》，第三种是犊子部、正量部的主张，称为“不可说我”。

再问：所执的实我，有思虑还是没有思虑？我若有思虑，我就应是无常，因为我不是一切时都有思虑。我若没有思虑，我就应如同虚空，既不能作业，也不能受果。所以所执的我，两种情况都不能成立。

再问：所执的实我，有作用还是没有作用？我若有作用，我就应如同手足，是无常。我若没有作用，我就应如同兔角，不是实我。所以所执的我，两种情况都不能成立。

五、我见的所缘与两种我执

再问：所执的实我，是不是我见所认识的对象？

如果实我不是我见的对象，你们凭什么知道有实我？如果实我是我见的对象，我见就如实认识了实我，我见就不属于颠倒。那么，你们所信奉的至教，为什么都毁斥我见、称赞无我？至教说，无我见能证涅槃，执着我见就沉沦生死。哪有邪见能证涅槃、正见反令人沉沦生死的道理？

论主立两个论式。

第一个论式：主张是，一切我见都不以实我为所缘。理由是，我见是有所缘的心。例证是，如同缘色、声等其余对象的心。

第二个论式：主张是，我见所缘的对象必定不是实我。理由是，我见的对象是所缘。例证是，如同色、声等其余诸法。

【译注】两个论式的力量在于：对方也承认，缘色、声的心并不缘实我，色、声等法也不是实我。我见同样是有所缘的心，我见的对象同样是所缘，没有理由例外。

所以，我见不以实我为所缘，只以内识所变现的五蕴为所缘，随着自己的虚妄情执，作种种计度。

我执大略有两种：第一种是俱生我执，第二种是分别我执。

俱生我执，是无始以来虚妄熏习的内在力量，使我执恒常与身俱在，不需要邪教和邪分别，自然而然地运转，所以称为俱生。俱生我执又有两种。第一种恒常相续，在第七识中：第七识以第八识为所缘，生起自心中的影像，执为实我。第二种有时间断，在第六识中：第六识以识所变现的五取蕴相为所缘，或者总缘五蕴，或者别缘一蕴，生起自心中的影像，执为实我。两种俱生我执都很微细，所以难断，要到见道之后的修道位中，反复修习殊胜的生空观，才能除灭。

分别我执，是由现世的外缘力量引起的，并不与身俱在，要依靠邪教和邪分别才会生起，所以称为分别。分别我执只在第六意识中存在。分别我执也有两种。第一种以邪教所说的五蕴之相为所缘，生起自心中的影像，分别计度，执为实我。第二种以邪教所说的我相为所缘，生起自心中的影像，分别计度，执为实我。两种分别我执都很粗显，所以易断，初入见道时，观一切法的生空真如，就能除灭。

一切我执所缘的五蕴，自心之外的五蕴有时有、有时无，自心之内的五蕴一切我执都有。所以一切我执都以无常的五取蕴相为所缘，虚妄执为自我。

【译注】自心之外的五蕴，是作为依托的本质；自心之内的五蕴，是心中变现的影像。例如缘邪教所说的“神我”时，心外根本没有对应的本质，心内依然有影像。所以说本质或有或无，影像一切都有。

种种五蕴之相从因缘生起，所以是如幻的存在。虚妄所执的我，是横加计度出来的，所以决定没有。因此契经说：比丘们应当知道，世间沙门、婆罗门等所有的我见，一切都以五取蕴为所缘而生起。

六、三个问难与回答

第一个问难。外人质问：实我若没有，怎么会有记忆、认识、诵读、温习、报恩、结怨等事？

论主回答：你们所执的实我，常住不变。没有记忆的时候，我体如此；有记忆的时候，我体也如此。我体前后没有区别，那么后来就应和先前一样没有记忆，先前就应和后来一样已有记忆。

外人辩解：前后变化的是我的作用，我的体不变。论主回答：这也不合道理。作用不离我体，作用就应和我体一样常有；我体不离作用，我体就应和作用一样无常。

论主正面回答：一切有情各有本识，本识同一类别地相续不断，任持种子，与一切法互为因，由熏习的力量，所以有记忆、认识等事。所以你们提出的诘难，过失落在你们自己的主张上，并不落在唯识宗上。

第二个问难。外人质问：实我若没有，谁能造业？谁来受果？

论主回答：你们所执的实我，没有变易，如同虚空，怎能造业受果？实我若有变易，就应是无常。论主正面回答：有情的心王与心所，由因缘的力量，相续不断，造业受果，在道理上没有违背。

第三个问难。外人质问：实我若没有，谁在生死中轮回诸趣？谁又厌离痛苦、求趣涅槃？

论主回答：你们所执的实我，既没有生灭，怎能说生死轮回？实我常住如同虚空，不被痛苦所恼，又为什么要厌离痛苦、求趣涅槃？所以你们的说法，处处自相伤害。

论主正面回答：有情的身心相续不断，由烦恼和业的力量，轮回诸趣；厌患痛苦，所以求趣涅槃。

由此可知，决定没有实我，只有诸识。诸识从无始以来，前念灭、后念生，因果相续；由虚妄熏习，显现出似我的相状，愚痴的人就在似我的相状中，虚妄执着为我。

以上卷第一之上译毕。
