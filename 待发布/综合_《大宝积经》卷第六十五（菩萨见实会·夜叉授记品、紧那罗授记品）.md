# 《大宝积经》卷第六十五（菩萨见实会·夜叉授记品、紧那罗授记品）

北齐·三藏那连提耶舍 译

## 菩萨见实会第十六之五

【按】会名“菩萨”二字，宫本无。

### 夜叉授记品第十

#### 夜叉赞佛智无尽

那时又有八亿夜叉，见到诸阿修罗、伽楼罗、龙女、龙王、鸠槃荼、乾闼婆等供养如来、听闻授记之后，欢喜踊跃，都称心意，生起稀有之心，得未曾有，知道佛世尊的智慧无尽、最尊、最胜、无所罣碍、不可思议；又得听闻法门的次第，对佛世尊作导师之想，又对佛作无尽智慧之想。那些夜叉知道佛的智慧无有穷尽之后，对佛的正法生起爱乐之心；他们对佛法甚为爱乐之后，为了供养而发勤精进，也以偈赞叹说：

【按】“伽楼罗”之“伽”，明本作“迦”。“鸠槃荼”之“荼”，元、明本作“茶”。“最胜、无所罣碍”，《大正藏》作“最无胜所罣碍”，今依CBETA所录高丽藏改。“偈赞曰”之“曰”，圣、圣乙本无。

```
我等今赞利世者，
以佛智力具足故，
无尽无量如大海，
故人师子身无等。
须弥可得知轻重，
虚空可得知广狭，
如来所有智慧力，
一切不能得测量。
知诸众生敬信心，
是故应受皆已度，
于其度者知所趣，
故佛无比亦无等。
随彼所修善恶界，
一切生处受其身，
知彼根信所应受，
故佛无比亦无等。
贪欲恶行瞋恚行，
及以痴行佛悉知，
憍慢嫉妬亦如是，
故佛无比亦无等。
众生于此多所失，
如来善知彼业道，
世尊知彼甚捷利，
故佛无比亦无等。
善逝善见诸世间，
随其方面所失者，
及以语言所丧失，
世尊见彼悉无余。
```
（大意：我们现在赞叹利益世间者，因为佛的智力具足，无尽无量如大海，所以人中师子之身无与伦比。须弥山可以知其轻重，虚空可以知其宽窄，如来所有的智慧之力，一切都不能测量。了知众生的敬信之心，所以应度的都已度化，对那已度的人知其所趣，所以佛无比也无等。随他们所修的善恶之界，在一切生处受其身，知道他们的根性与信心所应受的，所以佛无比也无等。贪欲的恶行、瞋恚之行以及痴行，佛都了知，憍慢、嫉妒也是这样，所以佛无比也无等。众生在此多有所失，如来善知他们的业道，世尊知之甚为敏捷，所以佛无比也无等。善逝善见诸世间，随其方向所失的，以及言语所丧失的，世尊见之毫无遗余。在六道中住了多久，随他们多少所受的苦，以及所受的种种身，世尊一切都知见。）

【按】“应受皆已度”之“受”，宋、元、明、宫、圣、圣乙本作“度”。

```
于六道中几时住，
随彼多少所受苦，
及其所受种种身，
世尊一切悉知见。
随其烦恼力所起，
造作方便及与业，
随业所受种种苦，
导师一切悉了知。
随其所求解脱道，
于佛法中已出家，
精勤修学圣道已，
尽诸烦恼佛悉知。
于佛法中有凡夫，
虽得出家不知义，
诽谤明人微妙法，
世尊亦复善见彼。
彼诸诽谤正法人，
业行所得众苦恼，
随其地狱久近住，
如来亦能具足知。
于佛深得敬信已，
出家受持正法藏，
观察诸法皆悉空，
断除一切诸有道。
不愿一切诸趣身，
观察此身犹如幻，
知诸音声亦如响，
坚住道者佛亦知。
赞叹无等大导师，
我今所得福德聚，
以此福德愿成佛，
亦愿众生成自然。
```
（大意：随其烦恼之力所生起的，造作的方便以及业，随业所受的种种苦，导师一切都了知。随其所求的解脱之道，在佛法中已经出家，精勤修学圣道之后，尽除诸烦恼，佛都了知。在佛法中有凡夫，虽然得以出家，却不知义理，诽谤明智之人的微妙之法，世尊也善见他们。那些诽谤正法的人，由业行所得的众多苦恼，随其在地狱中住的久近，如来也能具足了知。对佛深得敬信之后，出家受持正法之藏，观察诸法都是空，断除一切诸有之道，不愿一切诸趣之身，观察此身犹如幻化，知种种音声也如回响，坚住于道的人，佛也了知。赞叹无等的大导师，我现在所得的福德之聚，以这福德愿成佛，也愿众生成就自然之智。）

#### 授夜叉记

那时世尊知道夜叉众已生深心之信，现出微笑之相。那时慧命马胜比丘以偈问道：

```
人中师子所现笑，
唯愿说其笑因缘，
一切诸佛非无因，
而现微笑人中月。
今此大众皆怀疑，
以见导师微笑故，
唯愿世尊除其疑，
皆令此众得欣喜。
今于佛所得信者，
及知微妙正法者，
其心坚固不动者，
愿佛宣说令彼闻。
此诸大众皆怀疑，
一切瞻仰如来面，
今日当有何等事，
唯愿世尊断彼疑。
今日谁现大神力，
今日谁发大精进，
今日佛共谁亲友，
于此大众愿显现。
善哉牟尼愍世间，
唯愿断除诸疑惑，
天人大众若得闻，
今日必当大欣喜。
```
（大意：人中师子所现的微笑，唯愿宣说其微笑的因缘，一切诸佛并非无因而现微笑，人中之月。现在这大众都怀疑惑，因为见到导师微笑，唯愿世尊除去其疑惑，都令这大众得到欢喜。现在在佛所得到信心的人，以及了知微妙正法的人，其心坚固不动的人，愿佛宣说，令他们听闻。这些大众都怀疑惑，一切都瞻仰如来之面，今天将有什么事？唯愿世尊断除其疑惑。今天谁现出大神力？今天谁发起大精进？今天佛与谁为亲友？愿在这大众中显现。善哉牟尼，怜愍世间，唯愿断除种种疑惑，天人大众若得听闻，今天必当大为欢喜。）

【按】“人中月”之“月”，圣、圣乙本作“有”。“世尊除其疑”之“尊”，宫、圣、圣乙本作“亲”。

那时世尊以偈回答慧命马胜说：

```
善哉马胜汝所问，
今当大利诸世间，
由汝能问笑因缘，
故叹汝善解我意。
我今尽当答彼义，
汝当一心专谛听，
知诸夜叉心意已，
我为世间现微笑。
夜叉诸众心敬信，
以知菩提寂灭故，
叹佛真实功德已，
发心趣向大菩提。
为知诸法空寂故，
除遣一切所有相，
于诸趣中愿舍已，
发心趣向大菩提。
以禅定力知诸阴，
但是世谛不取著，
不著诸有如莲花，
发心趣向大菩提。
于诸有中障碍事，
彼见空故不为缚，
知佛菩提无上已，
彼等能修菩提行。
```
（大意：善哉马胜你所问的，现在当大利益诸世间，由于你能问微笑的因缘，所以赞叹你善解我意。我现在当全部回答那义理，你应当一心专注谛听，了知诸夜叉的心意之后，我为世间而现微笑。夜叉诸众心生敬信，因为了知菩提寂灭，赞叹佛的真实功德之后，发心趣向大菩提。为了了知诸法空寂，除遣一切所有之相，对诸趣中的愿求都舍弃之后，发心趣向大菩提。以禅定之力了知诸阴只是世俗谛，而不取著，不著于诸有，如莲花一样，发心趣向大菩提。对于诸有中的障碍之事，他们见到空，所以不被束缚，了知佛菩提无上之后，他们能修菩提之行。）

```
诸生老死皆悉空，
此即无上菩提道，
知法自性空寂已，
能得安隐大菩提。
知阴自性空寂已，
寂静菩提性亦离，
所修菩提行亦空，
此智能知非凡了。
能观智慧性自空，
所观境界皆寂灭，
知者亦空知是已，
是人能修菩提道。
当知空亦性自空，
相愿亦复无体性，
若有人能如是知，
是人能修真实行。
天人大众闻是已，
心生欣喜获利益，
一切于佛敬信已，
心住菩提寂静句。
```
（大意：一切生老死都是空，这便是无上菩提之道，了知法的自性空寂之后，能得安隐的大菩提。了知诸阴的自性空寂之后，寂静菩提之性也是离，所修的菩提之行也是空，这智慧能知，不是凡夫所了。能观之智慧其性自空，所观的境界都寂灭，知者也是空，了知这些之后，这人能修菩提之道。应当知道空也自性为空，无相、无愿也没有体性，若有人能这样了知，这人能修真实之行。天人大众听了这些之后，心生欢喜，获得利益，一切都对佛敬信之后，心住于菩提的寂静之句。）

【按】“性亦离”之“离”，《大正藏》作“难”，宋、元、明、宫本作“离”，今依CBETA所录思溪藏、碛砂藏作“离”。

```
今此殊胜供养已，
夜叉之众心清净，
此诸智者舍鬼道，
于善趣中久受乐。
彼于未来多亿佛，
以神通力一念中，
于多佛土修供养，
即于佛所获得忍。
于诸世界不起相，
智者能以神力往，
观此世间犹如化，
智者游行无所著。
此等勇猛供诸佛，
当得无上大菩提，
亦得无上净佛土，
其中当度无量众。
彼等当成世间解，
一切同号无边智，
名闻十方寿千劫，
寂灭智慧寿命等。
彼等所有声闻众，
犹如静夜诸星宿，
彼悉易得大菩提，
一切无有苦难事。
天人大众闻是已，
为于菩提心踊悦，
其心坚固发精勤，
以精进力持诸行。
```
（大意：现在这殊胜的供养之后，夜叉之众心意清净，这些智者舍离鬼道，在善趣中长久受乐。他们在未来于多亿佛所，以神通力在一念之中，于众多佛土修习供养，便在佛所获得法忍。在诸世界中不起相想，智者能以神力前往，观察这世间犹如化现，智者游行而无所著。这些勇猛的人供养诸佛，当得无上的大菩提，也得无上清净的佛土，在其中当度化无量大众。他们当成为世间解，一切同号无边智，名声闻于十方，寿命千劫，寂灭的智慧与寿命相等。他们所有的声闻众，犹如静夜中的诸星宿，他们都容易得到大菩提，一切都没有苦难之事。天人大众听了这些之后，为了菩提心中踊跃，其心坚固，发起精勤，以精进之力持守诸行。）

【按】“天人大众闻是已”以下四句，CBETA标点置于引号之外，今依句式并入偈中。

### 紧那罗授记品第十一

#### 大树紧那罗王之疑

那时又有八亿紧那罗众，以大树紧那罗王为上首，见到诸阿修罗、伽楼罗、龙女、龙王、鸠槃荼、乾闼婆、夜叉等供养如来以及听闻授记之后，甚生稀有、未曾有之心，这样思量：“这实在是稀有、未曾有之事。因为众生不可得，没有命者，没有生者，没有人，没有摩那婆，没有养育者，没有寿者，没有我，也没有我所；由于诸阴，所以名为众生，而一切诸阴也不可得；由于诸界，所以名为众生，而一切诸界也不可得；由于有诸入，所以名为众生，而一切诸入也不可得；由于有业，所以得有果报，而那行业也不可得；无上菩提也不可得，一切菩萨也不可得，一切诸佛也不可得。世尊虽然如此，却又为诸菩萨授记。以什么义理，如来为诸菩萨授记，示其名号，显现业报，宣说其将来？又为菩萨大众显示诸佛的神通之力，又宣说正法之力，又显现庄严的佛土，宣说众生有业有报，又宣说清净的佛刹，示显菩萨游历诸佛国，从一佛土到一佛土；又演说菩萨前往那里供养，也宣说供养的殊胜神变，又列举供具的微妙稀有；又宣说经过若干劫当得作佛，那佛住世经过若干劫，那佛当有若干声闻，那佛灭度后正法住世经过若干劫。为什么如来舍弃众生而入般涅槃？”

【按】“得有果报”之“得”，宋、宫本无。“示显菩萨”之“示”，宋、元、明、宫本作“亦”。

那时大树紧那罗王生起这疑惑之后，与八亿紧那罗众从座而起，偏袒右肩，右膝着地，合掌向佛，以偈问道：

```
我等闻佛所记已，
甚生疑惑。大智慧！
既说授记复言空，
我于二说不能解。
既说空寂离自性，
法界平等无变动，
而复如来受供养，
此事云何？众中月！
佛既说于无有生，
而复说发菩提心，
于无量智二种说，
此言秘密我不解。
云何言灭不可得，
而人师子说有死？
唯愿如实为记说，
除断我疑令无余。
云何佛说犹如幻，
又复显示生天中？
于释师子如是说，
此秘密教我不解。
佛说诸法无所依，
而复说依善知识，
此是世尊秘密语，
我实不解人中雄。
云何说于无所堪，
复教众生修诸业？
降伏怨敌天中尊，
秘密之说我不解。
云何佛说性自空，
复言观空得解脱？
我今于此不能解，
愿无边智断我疑。
```
（大意：我们听闻佛所授的记之后，甚生疑惑，大智慧者！既宣说授记，又说是空，我对这两种说法不能理解。既宣说空寂、离于自性，法界平等，没有变动，而如来又接受供养，这事是怎样的？众中之月！佛既宣说无有生，而又宣说发菩提心，对无量智者的这两种说法，这言语秘密，我不理解。为什么说灭不可得，而人中师子又说有死？唯愿如实为我们记说，断除我们的疑惑，毫无遗余。为什么佛说如幻，又显示生于天中？对释迦师子这样的说法，这秘密之教，我不理解。佛说诸法无所依，而又说依止善知识，这是世尊的秘密之语，我实在不理解，人中之雄。为什么说无所堪能，又教众生修种种业？降伏怨敌的天中之尊，这秘密之说我不理解。）

```
云何佛说事尽灭，
复说诸法性寂灭？
我今唯愿无等等，
开显此等秘密说。
云何端正修伽陀，
显示诸法如虚空，
而愚痴人毁谤法，
死必堕于大地狱？
大雄恒说诸天道，
又复说于诸余趣，
既言此等由作业，
复道无有作业者。
不可胜者所宣说，
种种差别不可知，
我今于此生疑惑，
唯愿世尊见除断。
既言善业无可集，
复说修行得菩提，
沙门法王如是说，
此亦我等不能解。
云何说法不可尽，
而言谤者罪可毕？
无量智慧愿开示，
我于是中大有疑。
如来既说真际法，
复言颠倒及施等，
无翳净眼灭罪者，
此义唯愿为我说。
余无有能为我等，
宣释如是所疑事，
唯有如来能断除，
是故我敬一切智。
```
（大意：为什么佛说自性空，又说观空而得解脱？我现在对此不能理解，愿无边智者断除我的疑惑。为什么佛说事尽灭，又说诸法自性寂灭？我现在唯愿无等等者开显这些秘密之说。为什么端正的修伽陀显示诸法如虚空，而愚痴的人毁谤法，死后必定堕于大地狱？大雄恒常宣说诸天道，又宣说其余诸趣，既说这些由作业而来，又说没有作业者。不可胜者所宣说的种种差别不可知，我现在对此生起疑惑，唯愿世尊为我除断。既说善业没有可积集的，又说修行而得菩提，沙门法王这样说，这也是我们不能理解的。为什么说法不可尽，而又说谤法者的罪可以了毕？无量智慧者愿为开示，我对此中大有疑惑。如来既说真实际之法，又说颠倒以及布施等，无翳清净之眼、灭除罪业者，这义理唯愿为我们宣说。再没有别人能为我们解释这样的疑惑之事，唯有如来能断除，所以我敬礼一切智者。）

【按】“修伽陀”之“修”，元、明、宫、圣本作“须”。修伽陀，即善逝。“由作业”之“作”，宫、圣本作“化”。

#### 世尊释疑与阿字总持门

那时世尊听了大树紧那罗王等所问的种种疑惑之后，以偈回答说：

```
汝言说空复授记，
于此二事不能解。
诸法若是不空者，
佛不为其说授记。
以何因缘如是说？
诸法若有体性者，
一切常住不可转，
彼应不减亦不增。
诸法体性本自空，
犹如平正清净镜，
能现一切诸色像，
如是当知一切法。
法界无有变异相，
汝于一切供养物，
一一诸分当观察，
何等分中而有相？
法界常住无变异，
智者应当如是观，
诸凡夫人悉迷惑，
无智慧故不能解。
```

（大意：善哉马胜知时而问，我现在为你分别宣说，由于你的发问，我便显示，众人当得佛的功德。你应当清净专一其心，听闻稀有之事，不要散乱心意，就是善逝最殊胜的智慧，没有障碍的大知见。紧那罗王设问疑惑，是为了利益一切众生，我现在宣说他们将来的果报，谛听，我当断除你的疑惑。树紧那罗八亿等，国王以及臣民、诸眷属，这些人供养我之后，从此命终，生于天上。从此以后九亿劫，在人天中流转，具足修习五神通，得到智慧的自在与心的自在。他们在那由他佛刹中，这些人中师子遭化而生，身处天宫而不动摇，恒常受禅悦的安隐之乐。他们在九十千万劫中，在人天中流转之后，各自在自己的佛刹中都得以成就无上道。）

【按】“从此已后”之“从”，《大正藏》作“徒”，今依CBETA所录高丽藏作“从”。“遭化生”，宋、元、明、宫本作“遣化往”，圣本作“遣化生”。

原文：“彼于那由他佛刹，是人师子遭化生”（大意：他们在那由他佛刹中，这些人中师子遭化而生。“遭化生”句意未详，存疑。）

```
其劫号曰常照曜，
于彼劫中成佛道，
此皆一生补处人，
彼智慧者当得佛。
彼佛国土无一人，
非是修行成熟者，
皆是一生补处人，
无求声闻二乘者。
一切皆是大菩萨，
为世明者悉生彼，
悉是一生补处人，
后当皆得成佛道。
彼土诸大菩萨众，
安住弘誓大愿中，
我于无量诸佛刹，
皆悉修治令清净。
彼菩萨愿甚广大，
于长夜中善思量，
以其清净信乐心，
各自修治已佛刹。
彼诸佛土妙庄严，
远离一切诸烦恼，
其地遍有诸宫林，
解脱一切诸恶道。
所有诸过及八难，
彼佛国土悉皆无，
既修清净佛刹已，
众生便即易调伏。
如是世尊天中天，
为紧那罗说授记，
彼时一切诸大众，
闻已心皆大欣喜。
```
（大意：那劫号为常照曜，在那劫中成就佛道，这些都是一生补处之人，那些智慧者当得成佛。那佛国土中没有一人不是修行成熟的，都是一生补处之人，没有求声闻二乘的人。一切都是大菩萨，为世间作光明的人都生在那里，都是一生补处之人，以后都当成就佛道。那国土的诸大菩萨众，安住于弘誓大愿之中：我在无量诸佛刹中，都修治令其清净。那些菩萨的愿甚为广大，在长夜中善加思量，以其清净的信乐之心，各自修治自己的佛刹。那些佛土美妙庄严，远离一切种种烦恼，其地遍有种种宫殿园林，解脱一切诸恶道。所有种种过患以及八难，那佛国土都没有，已经修治清净的佛刹之后，众生便容易调伏。像这样，世尊天中之天为紧那罗宣说授记，那时一切大众听了，心中都大欢喜。）

【按】“如是世尊天中天”以下四句，CBETA标点置于引号之外，今依句式并入偈中。
