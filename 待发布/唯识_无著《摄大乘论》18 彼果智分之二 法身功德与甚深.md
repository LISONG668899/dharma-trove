<p class="dt-title">法身功德与甚深</p>

<div class="dt-subtitle">摄大乘论白话译注　第十八篇　彼果智分之二<br>无著菩萨造　唐　玄奘译　附世亲释、无性释</div>

本篇要目：一、法身与种种功德相应　二、功德归礼颂　三、自性、因、果、业、相应、转　四、法身的十二种甚深

一、法身与种种功德相应

应当了知，法身与几种功德相应？就是与最清净的四无量、解脱、胜处、遍处、无诤、愿智、四无碍解、六神通、三十二大士相、八十随好、四种一切相清净、十力、四无畏、三不护、三念住、拔除习气、无忘失法、大悲、十八不共佛法、一切相妙智等功德相应。

二、功德归礼颂

关于法身的功德，有多颂：

```
怜愍诸有情
起和合远离
常不舍利乐
四意乐归礼
解脱一切障
牟尼胜世间
智周遍所知
心解脱归礼
能灭诸有情
一切惑无余
害烦恼有染
常哀愍归礼
无功用无著
无碍常寂定
于一切问难
能解释归礼
于所依能依
所说言及智
能说无碍慧
常善说归礼
为彼诸有情
故现知言行
往来及出离
善教者归礼
诸众生见尊
皆审知善士
暂见便深信
开导者归礼
摄受住持舍
现化及变易
等持智自在
随证得归礼
方便归依净
及大乘出离
于此诳众生
摧魔者归礼
能说智及断
出离能障碍
自他利非余
外道伏归礼
处众能伏说
远离二杂染
无护无忘失
摄御众归礼
遍一切行住
无非圆智事
一切时遍知
实义者归礼
诸有情利乐
所作不过时
所作常无虚
无忘失归礼
昼夜常六返
观一切世间
与大悲相应
利乐意归礼
由行及由证
由智及由业
于一切二乘
最胜者归礼
由三身至得
具相大菩提
一切处他疑
皆能断归礼
```

大意：十六颂依次礼敬上面所列的功德，每一颂礼敬一种或一组功德，各颂所指见下面的无性释。

【无性释】十六颂所礼敬的功德依次如下。

第一颂，四无量：怜愍诸有情是总句；欲令有情和合于乐，是慈；欲令有情远离苦，是悲；欲令有情常不舍乐，是喜；欲令有情获得利益安乐，是舍。

第二颂，解脱、胜处、遍处：解脱一切障，胜过一切世间，智周遍一切境界，具此三德，心离系缚，不像声闻只有八解脱、八胜处、十遍处。

第三颂，无诤：声闻的无诤，是入城邑前先观察，若有一个有情会因自身生起烦恼争执，就不入；如来观见有情会缘佛身起烦恼，若堪受化，就往彼处方便调伏，令灭一切烦恼。只害烦恼，不害有情；有情有烦恼染，佛常哀愍，不加呵害，如同咒鬼的良医，只呵害鬼魅，不呵害被鬼魅附身的人。

第四颂，愿智：声闻的愿智要随所愿入定，只能知所愿之事；佛的愿智无功用、无著、无碍、常在寂定，一切时都能解释一切问难。

第五颂，四无碍解：所依是契经等教法，能依是所诠的义，对两者无碍，是法无碍与义无碍；对言词无碍，是训词无碍；对分析诸法的智无碍，是辩说无碍。

第六颂，六神通：现身往所化之处，是如意通；知言，是天耳通；知行，是他心通；知往，是宿住通；知来，是死生通；知出离，是漏尽通。

第七颂，相好：众生见到世尊具足相好，都审知是大善士，暂见便生深信。

第八颂，四种一切相清净：摄受、住持、舍自身自在，是所依清净；现化与变易，是所缘清净；等持自在，是心清净；智自在，是智清净。

第九颂，十力：魔在四种事上诳惑众生，十力能摧魔说。说善趣、恶趣的方便时，魔颠倒善恶，或说无因、自在天为因，处非处智力摧之；说世间皆由自业时，魔诳惑，业异熟智力摧之；说世间与出世间的清净时，魔诳惑，静虑等持等至智力摧之；说大乘究竟出离时，魔说菩提难得，宜求声闻，其余七力摧之。

第十颂，四无畏：佛说“我是真实正等觉者”，是一切智；说“我是真实漏尽者”，是漏尽；一切智与漏尽是自利。说“我为弟子所说的出离之法，真实能出离”，说“我所说的障道之法，真实能障”；说出离与说障道是利他。外道不能降伏，所以无畏。

第十一颂，三不护与三念住：身语等威仪没有丑恶需要藏护，处大众能伏他说，是三不护；对恭敬听与不恭敬听的弟子，善住正念，远离爱恚二种杂染，是三念住。

第十二颂，拔除习气：声闻等烦恼已尽，仍有习气，如大目犍连尊者五百生中曾作猕猴，离烦恼后，听到音乐时仍作猕猴跳跃；世尊一切行住，没有一件不是圆满智慧所应作的事。

第十三颂，无忘失法：佛对所化有情，应作之时就作，终不失时，如同海潮必定应时。

第十四颂，大悲：佛于昼夜各三时观一切世间，谁善法增，谁善法减，谁善根已熟，谁堪受何种法器。

第十五颂，十八不共佛法：由行，是行时一切事业无有误失，乃至无不择而舍；由证，是六种无退；由智，是于三世无著无碍的智见；由业，是身语意业以智为前导。

第十六颂，一切相妙智：由三身证得具一切相的大菩提，正知一切境相，所以能断一切人天的疑惑。

【译注】第九颂第三句，世亲释所引作“于此诸众生”，依论本与无性释作“诳众生”。第十一颂第二句，论本作“迷离”，依世亲释与无性释作“远离”。

三、自性、因、果、业、相应、转

诸佛法身与上面所列的功德相应，又与其余的自性、因、果、业、相应、转等功德相应。所以应当了知，诸佛法身有无上的功德。关于法身的自性等，有两颂：

```
尊成实胜义
一切地皆出
至诸众生上
解脱诸有情
无尽无等德
相应现世间
及众会可见
非见人天等
```

大意：世尊以圆成实的胜义为自性；从一切地修行而出；达到一切众生之上；能解脱诸有情；与无尽、无等的功德相应；示现于世间，以及在众会中可见，人天等不能见。

【世亲释】“尊成实胜义”，显示法身的自性，诸佛都以圆成实胜义的清净真如为自性。“一切地皆出”，显示法身的因，修一切地而成佛。“至诸众生上”，显示法身的果。“解脱诸有情”，显示法身的业。“无尽无等德相应”，显示相应。“现世间可见”，是变化身；“及众会可见”，是受用身；“非见人天等”，是自性身，诸人天等都不能见；三身的差别，称为“转”。

四、法身的十二种甚深

又，诸佛的法身甚深，最为甚深。甚深的相应当如何看待？关于法身的甚深，有多颂：

```
佛无生为生
亦无住为住
诸事无功用
第四食为食
无异亦无量
无数量一业
不坚业坚业
诸佛具三身
现等觉非有
一切觉非无
一一念无量
有非有所显
非染非离染
由欲得出离
了知欲无欲
悟入欲法性
诸佛过诸蕴
安住诸蕴中
与彼非一异
不舍而善寂
诸佛事相杂
犹如大海水
我已现当作
他利无是思
众生罪不现
如月于破器
遍满诸世间
由法光如日
或现等正觉
或涅槃如火
此未曾非有
诸佛身常故
佛于非圣法
人趣及恶趣
非梵行法中
最胜自体住
佛一切处行
亦不行一处
于一切身现
非六根所行
烦恼伏不灭
如毒咒所害
留惑至惑尽
证佛一切智
烦恼成觉分
生死为涅槃
具大方便故
诸佛不思议
```

应当了知，上面所说的甚深有十二种：生、住、业、住的甚深；安立、数、业的甚深；现等觉的甚深；离欲的甚深；断蕴的甚深；成熟的甚深；显现的甚深；示现等觉与涅槃的甚深；住的甚深；显示自体的甚深；断烦恼的甚深；不可思议的甚深。

【译注】第十一颂第三句，论本作“由惑至惑尽”，依世亲释作“留惑”。

【世亲释】十二种甚深依次如下。

第一颂，生、住、业、住甚深：诸如来没有业与烦恼所造的生，所以称为无生，示现的生难以了知，称为生甚深。以无住涅槃为住处，称为住甚深。诸如来的事业无功用而平等，称为业甚深。佛所食的是四种食中第四种“唯示现依止住食”：为了令能施的有情由净信而增长福德，示现受食，不作食事，如来食时，诸天受取。

第二颂，安立、数、业甚深：诸佛法身无差别，所以无异；无量依止现等觉，所以无量。佛有无量，同一事业。受用身的事业坚住，变化身的事业不坚住。

第三颂，现等觉甚深：补特伽罗与法都非有，所以现等觉非有；依假名之理说一切佛现等正觉，所以并非无；一一念中有无量佛现等正觉；诸佛是有与非有的真如所显。

第四颂，离欲甚深：贪欲无，所以非染；染既然无，离染也无。菩萨伏断贪缠，留贪的随眠，得到究竟出离，否则如同声闻入般涅槃。了知遍计所执的贪欲无贪欲之性，就悟入欲的法性真如。

第五颂，断蕴甚深：诸如来超过色等五取蕴，安住于无所得的法性蕴中；已舍遍计所执诸蕴，又安住于诸蕴的法性，所以与诸蕴非一非异；不舍圆成实蕴，就是妙善的涅槃。

第六颂，成熟甚深：如同众流入海，海水相杂，同为鱼鳖受用；诸佛同入法界，所作事业和合无二，等为成熟有情受用。佛不作“我已作、现作、当作他利”之想，无功用而能作一切利乐，如同如意宝珠与天乐。

第七颂，显现甚深：佛身常住，世间为什么不见？如同破器中水不能住，月影不现；有情身中没有奢摩他之水，佛月不现，水比喻等持。佛身不现时，以契经等法，如同日光遍满世间，作佛事，成熟有情。

第八颂，示现等觉涅槃甚深：如同火有时燃烧、有时息灭，诸佛对未熟的有情示现涅槃，对已熟的有情示现成佛；火性无差别，法身也唯一。

第九颂，住甚深：佛在不善法中住空等圣住，在人趣、恶趣中，缘彼有情住诸静虑的天住，在非梵行法中住慈悲等梵住，以最胜的自体住于最胜之住。

第十颂，显示自体甚深：后得智于善、不善、无记中分别而转，所以一切处行；无分别智不行一处。又，变化身行一切处，其余二身不行一处。变化身为化度捺落迦等，现生其中，捺落迦等有情见到时不能如实了知，所以非六根所行。

第十一颂，断烦恼甚深：菩萨位中伏烦恼缠，未灭烦恼，还有随眠，如同被咒力所制的毒，体仍在而不为害；留随眠，不像声闻速入涅槃，烦恼尽时证得一切智。

第十二颂，不可思议甚深：诸菩萨具大方便，烦恼集谛转成觉分，生死苦谛即是涅槃。

下一篇：19　彼果智分之三　念佛、净土与三身。论本说明念佛法身的七种念、清净佛土的十八种圆满、法界的五种业、一乘的意趣、多佛与涅槃，受用身与变化身不是自性身的道理，以及化身为什么不毕竟住。
