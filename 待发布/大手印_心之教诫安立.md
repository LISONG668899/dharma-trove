# 心之教诫安立

阿阇黎阿卓吉 造

## 题解

本篇出自德格版丹珠尔续部（རྒྱུད་འགྲེལ།）ཟི 函第19b叶末至第20b叶第4行，东北目录编号 D2387。全篇四十九句偈颂（每句约十三至十五个音节），另有礼敬和跋语。篇幅只有一叶左右，所以把藏文原文全部保留在代码块中，按意义段落分开，每段后附汉译，疑难之处另以【按】说明。

梵文题名：Cittasya-sampradhāya-vyāvaṣṭanaṃ-nāma（ཙིཏྟ་སྱ་སཾ་པྲ་དྷཱ་ཡ་བྱཱ་བཥྚ་ནཾ་ནཱ་མ）。

藏文题名：སེམས་ལ་གྲོས་འདེབས་པ（向心进献劝告）。

【按】藏文题名直译是“向心进言”“对心劝告”，也就是作者在劝告自己的心，全篇的“你”都是指作者自己的心。本译题名用通行的《心之教诫安立》。梵文题名的拼写看来已经讹变，照德格版转写，恕不强作还原；“安立”二字大概对应梵文题名中的 vyāvaṣṭana 一类的词（有“建立”“确定”之义），但这一对应只是推测，特此注明。

【按】作者“ཨ་ཛོ་ཀི”，这里音译为“阿卓吉”。八十四大成就者中有一位“ཨ་ཛོ་ཀི”（Ajogi），可能就是本篇的作者，但跋语只称“阿阇黎”，没有更多信息，无法确证。跋语也没有记载译者。

【按】全篇的结构大致是：先礼敬黑鲁嘎并立誓劝心；然后劝心忆念心性的见、修、果，以求大手印；接着反复用衰老、六道之苦、受用无常、亲友不可依等，激发出离心；最后归到观一切显现如梦如幻，对心性不贪不执地修持，迷乱穷尽而得佛果。可以说是一篇以出离心为前导、以大手印为归宿的道歌。

## 礼敬

```
ཡུམ་རྡོ་རྗེ་ཕག་མོ་ལ་ཕྱག་འཚལ་ལོ། །
```

敬礼佛母金刚亥母！

【按】这句礼敬可能是藏译者所加的译礼，也可能是作者原有的。本篇没有译者跋语，无法判定。

## 正文

### 第一段：礼敬与立誓

```
དཔའ་བོ་དཔའ་མོ་འབྱུང་པོ་རྣམས་ཀྱིས་བསྐོར་བྱས་པའི། །དཔལ་ཆེན་ཧེ་རུ་ཀ་ཡི་ཞབས་ལ་ཕྱག་འཚལ་ནས། །
ཁམས་གསུམ་སེམས་ཅན་རྣམས་ཀྱི་སྒྲིབ་པ་བསལ་བའི་ཕྱིར། །བདག་གཞན་རྣམས་ཀྱི་དོན་དུ་སེམས་ལ་ཕན་པའི་གྲོས་འདེབས་བྱ། །
```

在勇父、勇母以及诸部多众围绕之中的大吉祥黑鲁嘎足下，我顶礼之后，为了遣除三界一切众生的障碍，也为了自己和他人的利益，要向自己的心进献有益的劝告。

【按】“འབྱུང་པོ”一般指部多，即鬼神一类的众生，这里列在勇父、勇母之后，是黑鲁嘎坛城中的眷属，大概泛指护法与尸林中的鬼神，所以译作“诸部多众”。

【按】“སེམས་ལ་གྲོས་འདེབས”直译是“向心献策”“对心进言”，也就是本篇题名。全篇的“你”（ཁྱོད）都是作者在对自己的心说话，读者读到“你”字，可以理解为作者在叮嘱自己的心，同时也在叮嘱每一位读者的心。

### 第二段：忆念心性的见、修、果

```
འདོད་པ་པདྨའི་ཆུ་ལྟར་རིག་ནས་སེམས་ཉིད་ཀྱི། །བླ་མེད་ལྟ་སྒོམ་འབྲས་བུ་ཁྱོད་ཀྱིས་དྲན་པར་གྱིས། །
དེ་ཡིས་དཔལ་ལྡན་ཞལ་མཐོང་གཉིས་མེད་དོན་རྟོགས་ཏེ། །དེ་ཕྱིར་ཉམས་ལེན་བརྩོན་པས་ཕྱག་རྒྱ་ཆེན་པོ་ཐོབ་པའི་ཕྱིར། །
```

你要了知，种种欲乐就像莲叶上的水珠一样（滚动不住，转眼就会滑落），然后要忆念心性那无上的见、无上的修、无上的果。由此便能得见吉祥（本尊）的尊颜，证悟无二的真义；所以，为了获得大手印，应当精勤修持。

【按】“པདྨའི་ཆུ”直译是“莲花之水”，指莲叶上的水珠，在印藏譬喻中常用来比喻无常、不能停留。下文第十一段又说“此生如被风吹动的莲上水珠一般坏灭”，可以互相印证。

【按】“སེམས་ཉིད་ཀྱི་བླ་མེད་ལྟ་སྒོམ་འབྲས་བུ”，“心性的无上见修果”，在语法上也可以读成“以心性为（所依）的无上见、修、果”，意思相通，都是说见、修、果三者都不离心性。

【按】“དཔལ་ལྡན་ཞལ་མཐོང”直译是“见吉祥者之面”，“吉祥者”没有明说是谁。依开头礼敬黑鲁嘎的脉络，可以理解为得见本尊黑鲁嘎的尊颜；也可以理解为见到心性本来面目。这里补“本尊”二字放在括号中，表示是译者所补。

【按】本段末句以“ཐོབ་པའི་ཕྱིར”（为了获得）结尾，在语法上没有收结，像是承接下一段“若对色声等不贪不执”。但从文意看，本段末句自成一意（为得大手印而精勤修持），下一段另起一层，所以这里依文意把“为了获得大手印”与“精勤修持”连读。

### 第三段：不贪不执，得无因涅槃

```
སྣ་ཚོགས་གཟུགས་སྒྲ་སོགས་ལ་མ་ཆགས་མ་ཞེན་ན། །འཁོར་བར་མི་གནས་རྒྱུ་མེད་མྱ་ངན་འདས་པ་ཐོབ། །
```

对于种种色、声等（外境），如果不贪恋、不执著，就不会住于轮回，而能获得无因的涅槃。

【按】“རྒྱུ་མེད་མྱ་ངན་འདས་པ”，“无因涅槃”。“无因”的意思，最可能是指涅槃不是由因缘造作而生的，也就是无为法，与有为的轮回相对。另一种读法是“不再有（轮回之）因的涅槃”。两种读法都符合法义，这里照字面译作“无因”，不作取舍。

### 第四段：根衰心昧，何必执毒

```
པདྨ་བཞིན་མཛེས་མངོན་སུམ་མིག་གི་དབང་པོ་དང་། །སྒྲ་བརྙན་རྣ་བ་ཉམས་ཤིང་སེམས་ཉིད་རྨོངས་འགྱུར་བས། །
ཀྱེ་མ་ཞེ་སྡང་ཕྲག་དོག་དུག་ནི་ཅི་ཕྱིར་འཛིན། །
```

如莲花一般美好、清明现前的眼根，以及能听闻声响的耳根，终将衰退，心也会变得昏昧。唉！既然如此，你为什么还要执持嗔恨与嫉妒这些毒呢？

【按】“སྒྲ་བརྙན་རྣ་བ”直译是“回声（之）耳”。“སྒྲ་བརྙན”本义是回声、声影，常用作“如回声般不实”的譬喻。这里可能是说耳朵所听到的只不过是回声般的声音，也可能“སྒྲ་བརྙན”只是“声音”的雅称。原文意思不十分确定，这里取较平实的读法，译作“能听闻声响的耳根”，请读者留意。

【按】“སེམས་ཉིད་རྨོངས་འགྱུར”的“སེམས་ཉིད”，在本篇其他地方（第二段、第十四段）指“心性”，但在这里与眼耳衰退并列，说的是衰老时心智昏昧，所以译作“心”而不作“心性”。心性本身不会衰退昏昧，若译作“心性昏昧”就扭曲了法义，特此说明。

### 第五段：见衰老之相，仍被贪执所缚

```
སྐྲ་དཀར་གཉེར་མ་ལ་སོགས་ཁྱོད་ཀྱིས་མཐོང་གྱུར་ཀྱང་། །ཡོངས་སུ་ཚོལ་བའི་ཞེན་པས་ཉེས་པ་སྐྱོན་གྱིས་བཅིངས། །
```

你虽然已经看到（自己）生出了白发、皱纹等等（衰老之相），却仍然因为四处追求的贪执，被种种过失与罪咎束缚着。

【按】“ཡོངས་སུ་ཚོལ་བ”是“遍求”“到处寻求”，指对欲乐、名利不断追逐。

### 第六段：贪嗔我慢，流转恶趣

```
རབ་འབྲིང་ཐ་མའི་སྤྱོད་ལམ་འདོད་ཆགས་ཞེ་སྡང་གིས། །མཁས་བཙུན་མངོན་པའི་ང་རྒྱལ་འཁོར་བའི་གནས་སུ་འཁྱམ། །
ཡི་དྭགས་ལྷ་མིན་དུད་འགྲོ་ལ་སོགས་སྡུག་བསྔལ་མང་། །དེ་ཕྱིར་ཕྲག་དོག་སྤངས་ལ་རང་ཉིད་དམིགས་པར་གྱིས། །
```

上、中、下各种人的行为，都由于贪欲与嗔恨，以及自显为智者、持戒者的我慢，而在轮回的处所中流浪。（流转到）饿鬼、非天、畜生等处，痛苦非常多。所以你要舍弃嫉妒，回过头来观照自己。

【按】“རབ་འབྲིང་ཐ་མའི་སྤྱོད་ལམ”，“上中下的行为（威仪）”，可以指上中下三等根器的人，也可以指上中下三种程度的行为。这里译作“上、中、下各种人的行为”，兼顾两种理解。

【按】“མཁས་བཙུན་མངོན་པའི་ང་རྒྱལ”，“显现为智者、尊者的我慢”。“མཁས་བཙུན”是“博学而持戒”，是藏地称赞学者的常用语。这里说的是自以为博学持戒、并向人显露这种身份所生的我慢。这是修行人特别容易有的过患，作者把它与贪嗔并列，值得注意。

【按】“རང་ཉིད་དམིགས་པར་གྱིས”直译是“要缘自己”“要以自己为所缘”。结合上句“舍弃嫉妒”，意思应是：不要去盯着别人（而生嫉妒），而要反观自己的心。这里译作“回过头来观照自己”。

### 第七段：心王不知足

```
ལྷ་དང་ཀླུ་དང་མི་རྣམས་བདེ་བར་གྲངས་མང་ཐོབ་གྱུར་ཀྱང་། །སེམས་ཀྱི་རྒྱལ་པོ་འདོད་པས་མི་ངོམས་ངོ་མཚར་ཆེ། །
གཉེན་བྲལ་སྡུག་བསྔལ་མཆི་མ་རྒྱ་མཚོ་བས་ཀྱང་ལྷག། །དུར་ཁྲོད་གནས་ཀྱི་ཀེང་རུས་བསགས་པ་རི་དང་མཉམ། །
འདོད་པའི་རྨ་ཕྱུང་འཁྲུགས་པའི་ཁྲག་ནི་མཚོ་དང་འདྲ། །
```

纵然在天、龙、人中多次获得安乐，心王仍然因为贪欲而永不满足，真是太稀奇了！（在无始轮回中）与亲人离别的痛苦所流的泪水，比大海还多；尸林里堆积的骸骨，与山一样高；因贪欲而受伤、在争斗中所流的血，就像湖海一样。

【按】“སེམས་ཀྱི་རྒྱལ་པོ”，“心王”，在这里是对心的拟人称呼，也可以理解为唯识所说的“心王”（相对于心所）。从语气看，作者是在讥讽这位“心王”虽然尊贵，却永不知足。

【按】泪多于海、骨积如山、血流成海这一组譬喻，是经论中常见的说法，意思是在无始轮回中，每个众生所受的痛苦已经无量无边。原文没有“无始轮回中”几个字，这里在括号中补出，以便读者理解。

【按】“འདོད་པའི་རྨ་ཕྱུང་འཁྲུགས་པའི་ཁྲག”字面是“欲之伤、争斗之血”，意思不十分清楚，可以理解为“为了欲乐而受伤、在争斗中所流的血”。这里依此译出。

### 第八段：既得暇满，当利自他

```
ཀྱེ་མ་སེམས་ཀྱི་རྒྱལ་པོའི་རྣལ་འབྱོར་ཅི་ཕྱིར་སྲིད་མི་སྤོང་། །མི་ལུས་འདོད་བྱ་ཁོམ་ལྡན་ཡང་དག་ཐོབ་བྱས་ནས། །
དངོས་པོ་རྣམས་ནི་ཆུ་བུར་ལྟ་བུར་བརྟགས་བྱས་ལ། །ཁྱོད་ཀྱིས་བདག་གཞན་རྣམས་ལ་ཇི་སྲིད་ཕན་པར་གྱིས། །
```

唉！心王啊，你这修瑜伽的人，为什么还不舍弃三有呢？既然已经真正获得了人人向往、具足闲暇的人身，就应当把一切事物观察为水泡一般（虚幻不实），并且尽你所能地利益自己和他人。

【按】“སེམས་ཀྱི་རྒྱལ་པོའི་རྣལ་འབྱོར”直译是“心王之瑜伽（士）”，语法上有几种读法：一是呼格，“心王啊，瑜伽士啊”；二是“修心王之瑜伽的人”；三是“心王的瑜伽”。这里依上下文对心说话的语气，译作“心王啊，你这修瑜伽的人”。原文较简略，请读者留意。

【按】“ཇི་སྲིད”是“尽其所有”“在一切时”，可以理解为“尽你所能”，也可以理解为“只要（还活着）”。这里取前者。

### 第九段：六道之苦

```
འཁོར་བའི་འདམ་ལ་བྱིང་འགྱུར་ཐར་པ་ཤིན་ཏུ་དཀའ། །དམྱལ་བའི་སྡུག་བསྔལ་ངུ་འབོད་ཚ་གྲང་སྲེག་ཅིང་བཙིར། །
སྲེད་པས་ཕྲག་དོག་ཡི་དྭགས་བཀྲེས་སྐོམ་སྐྱེ་འགྱུར་ལ། །སྙིང་རྗེའི་གནས་ཐོབ་དུད་འགྲོ་ཕན་ཚུན་ཞེ་སྡང་ཆེ། །
ལྷ་ཡང་གནས་ནས་ལྟུང་འགྱུར་མི་རྣམས་སྡུག་བསྔལ་མང་། །
```

一旦沉陷在轮回的泥沼中，要想解脱就极其困难。地狱的痛苦是：哭号呼喊，或热或冷，被焚烧，被压榨。由于贪爱与嫉妒，将会投生为饥渴交迫的饿鬼。投生到可悲悯之处的畜生，彼此之间嗔恨深重。天人也会从天界堕落，人类的痛苦也非常多。

【按】“སྲེད་པས་ཕྲག་དོག་ཡི་དྭགས”一句，可以读作“由于贪爱，（生为）嫉妒的饿鬼”，也可以读作“由于贪爱与嫉妒，（生为）饿鬼”。饿鬼道的主因一般说是悭吝与贪爱，这里取后一种读法，把“嫉妒”与“贪爱”并列为因。

【按】“སྙིང་རྗེའི་གནས”直译是“悲悯之处”，指值得怜悯的处境，在这里修饰畜生道，意思是畜生处在可悲可悯的境地，不是说畜生具有悲心。

【按】本段依次说地狱、饿鬼、畜生、天、人五道，没有提到非天（阿修罗）；第六段已经提到过非天，所以这里大概是省略了。

### 第十段：忆念众生苦，舍弃种种名言

```
དེ་ལྟར་འགྲོ་བའི་སྡུག་བསྔལ་ཁྱོད་ཀྱིས་དྲན་བྱོས་ལ། །དོན་དམ་ཀུན་རྫོབ་ཐ་སྙད་སྣ་ཚོགས་སྤང་བར་གྱིས། །
```

你要这样忆念诸道众生的痛苦，并且舍弃胜义、世俗种种名言（戏论）。

【按】本句“དོན་དམ་ཀུན་རྫོབ་ཐ་སྙད་སྣ་ཚོགས་སྤང་བར་གྱིས”，字面是“要舍弃胜义、世俗、名言种种”，这一句很容易误解，必须特别说明：这里所说的舍弃，不是说要否定二谛的道理，也不是说世俗的因果可以不顾；而是说在修持大手印时，对“这是胜义”“那是世俗”等种种概念、名言的执著与分别都要放下，这与第三段“不贪不执”、第十四段“对心性不贪不执地修持”的意思是一贯的。所以在“名言”后面补“戏论”二字，并加括号，表示是译者所补。

【按】这一句在语法上也可以读成“胜义、世俗、名言（这三者）种种（分别）都要舍弃”，意思与上相同。

### 第十一段：受用、寿命、青春皆无常

```
ལོངས་སྤྱོད་སྤྲིན་ཕུང་གློག་ལྟར་རྣམ་པར་གཡོ་བར་འགྱུར། །ཚེ་འདི་རླུང་གིས་བསྐྱོད་པའི་པདྨའི་ཆུ་ལྟར་འཇིག། །
ལང་ཚོ་རྣམས་ནི་མི་རྟག་དེ་ལྟར་བལྟས་བྱས་ནས། །མཁས་པ་རྣམས་ནི་མྱུར་དུ་ནགས་སུ་འགྲོ་བར་གྱིས། །
```

受用财物，就像云聚、闪电一样，摇动不定；此生就像被风吹动的莲叶上的水珠一样，终将坏灭；青春年少也都是无常的。这样观察之后，有智慧的人们啊，应当赶快到山林中去（修行）。

【按】“ནགས་སུ་འགྲོ”，“前往森林”，在印度传统中指舍离家室、到寂静处修行。“修行”二字是译者所补。

### 第十二段：亲友贪恋，终归阎罗

```
འཁོར་བའི་འདོད་པའི་གཉེན་བཤེས་ཆགས་པས་ཕྲག་དོག་སྐྱེ། །མཐར་ཡང་གཤིན་རྗེའི་གནས་འགྲོ་རྒྱལ་བ་ཐོབ་མི་འགྱུར། །
ཁྱོད་ཀྱིས་དེ་ལྟར་ཤེས་ན་ཐར་པའི་ལམ་ཐོབ་བོ། །མི་ལུས་དམ་པ་ཡང་དང་ཡང་དུ་ཐོབ་པ་དཀའ། །
```

对轮回中所贪恋的亲友，由于贪著而生嫉妒，最后也只会去往阎罗王之处，不能获得胜者的果位。你如果这样了知，便能得到解脱之道。殊胜的人身，难以一再获得。

【按】“རྒྱལ་བ་ཐོབ་མི་འགྱུར”，“རྒྱལ་བ”可以指“胜者”（佛），也可以指“胜利”。依上下文，译作“不能获得胜者的果位”，即不能成佛；若读作“不能得胜”，意思是在与死亡、烦恼的较量中终究失败，法义上也说得通。

### 第十三段：观一切如幻，如鸟脱网

```
དཔེར་ན་རྒྱ་མཚོའི་ཆུ་རླབས་རླབས་སྣང་ཟླ་བའི་གཟུགས་བརྙན་དང་། །རྨི་ལམ་མིག་འཕྲུལ་འཁྲུལ་སྣང་སྣ་ཚོགས་སྒོམ་བྱེད་ན། །
འཁོར་བའི་ཞགས་པས་བཅིངས་གྲོལ་རྒྱལ་བྱ་བཞིན་ནོ། །
```

譬如大海里的波浪、波浪中显现的月影，以及梦境、幻术——若将种种迷乱显现都这样观修，就能像被轮回绳索所缚的王鸟得到解脱一样。

【按】本段首句“ཆུ་རླབས་རླབས་སྣང”，“波浪、浪中所现”，“རླབས”一字重复，可能是原文的修辞，也可能是“ཆུ་ཟླ”（水月）之类的传抄讹误。这里依字面，译作“波浪、波浪中显现的月影”。

【按】“རྒྱལ་བྱ”直译是“王鸟”“鸟中之王”，可能指金翅鸟，也可能指天鹅一类被视为高贵的鸟。原文没有说明，这里只照字面译作“王鸟”。

【按】“བཅིངས་གྲོལ”是“被缚而得解脱”。整句的意思是：被轮回绳索所缚的心，如果能如是观修一切显现如幻，就能像被缚的鸟挣脱罗网，自在飞去。

### 第十四段：心性不贪不执，得佛果

```
དེ་ཕྱིར་སེམས་ཉིད་མ་ཆགས་མ་ཞེན་ཉམས་ལེན་གྱིས། །འཁྲུལ་ཟད་གང་ཞིག་རྣལ་འབྱོར་བདེ་བ་ཐོབ་པ་དེས། །
སེམས་གསལ་ཡལ་ག་བརྒྱ་ཡིས་སངས་རྒྱས་འབྲས་བུ་ཐོབ། །
```

所以，要对心性不贪不执地修持。凡是迷乱已经穷尽、获得瑜伽安乐的人，就能以明心的百枝，获得佛果。

【按】“འཁྲུལ་ཟད”，“迷乱穷尽”，在大手印、大圆满中常用来形容究竟的证悟。

【按】“སེམས་གསལ་ཡལ་ག་བརྒྱ”直译是“心明之百枝”，是全篇最后一个难点。可能的理解是：明了的心如同大树，枝繁叶茂，自然结出佛果，所以说“以百枝而得果”。也可能“百枝”是指种种功德或方便。由于没有注释可依，这里照字面译作“以明心的百枝获得佛果”，请读者留意。

## 跋语

```
སེམས་ཀྱི་གྲོས་འདེབས་ཞེས་བྱ་བ་སློབ་དཔོན་ཨ་ཛོ་ཀིས་མཛད་པ་རྫོགས་སོ།། །
```

名为《向心进言》（心之教诫），阿阇黎阿卓吉所造，圆满。

【按】跋语中的题名作“སེམས་ཀྱི་གྲོས་འདེབས”（心的劝告），与开头的“སེམས་ལ་གྲོས་འདེབས”（向心劝告）只差一个格助词，意思相同。

## 通篇连读

在勇父、勇母以及诸部多众围绕之中的大吉祥黑鲁嘎足下，我顶礼之后，为了遣除三界一切众生的障碍，也为了自己和他人的利益，要向自己的心进献有益的劝告。

你要了知，种种欲乐就像莲叶上的水珠一样（滚动不住，转眼就会滑落），然后要忆念心性那无上的见、无上的修、无上的果。由此便能得见吉祥（本尊）的尊颜，证悟无二的真义；所以，为了获得大手印，应当精勤修持。

对于种种色、声等（外境），如果不贪恋、不执著，就不会住于轮回，而能获得无因的涅槃。

如莲花一般美好、清明现前的眼根，以及能听闻声响的耳根，终将衰退，心也会变得昏昧。唉！既然如此，你为什么还要执持嗔恨与嫉妒这些毒呢？

你虽然已经看到（自己）生出了白发、皱纹等等（衰老之相），却仍然因为四处追求的贪执，被种种过失与罪咎束缚着。

上、中、下各种人的行为，都由于贪欲与嗔恨，以及自显为智者、持戒者的我慢，而在轮回的处所中流浪。（流转到）饿鬼、非天、畜生等处，痛苦非常多。所以你要舍弃嫉妒，回过头来观照自己。

纵然在天、龙、人中多次获得安乐，心王仍然因为贪欲而永不满足，真是太稀奇了！（在无始轮回中）与亲人离别的痛苦所流的泪水，比大海还多；尸林里堆积的骸骨，与山一样高；因贪欲而受伤、在争斗中所流的血，就像湖海一样。

唉！心王啊，你这修瑜伽的人，为什么还不舍弃三有呢？既然已经真正获得了人人向往、具足闲暇的人身，就应当把一切事物观察为水泡一般（虚幻不实），并且尽你所能地利益自己和他人。

一旦沉陷在轮回的泥沼中，要想解脱就极其困难。地狱的痛苦是：哭号呼喊，或热或冷，被焚烧，被压榨。由于贪爱与嫉妒，将会投生为饥渴交迫的饿鬼。投生到可悲悯之处的畜生，彼此之间嗔恨深重。天人也会从天界堕落，人类的痛苦也非常多。

你要这样忆念诸道众生的痛苦，并且舍弃胜义、世俗种种名言（戏论）。

受用财物，就像云聚、闪电一样，摇动不定；此生就像被风吹动的莲叶上的水珠一样，终将坏灭；青春年少也都是无常的。这样观察之后，有智慧的人们啊，应当赶快到山林中去（修行）。

对轮回中所贪恋的亲友，由于贪著而生嫉妒，最后也只会去往阎罗王之处，不能获得胜者的果位。你如果这样了知，便能得到解脱之道。殊胜的人身，难以一再获得。

譬如大海里的波浪、波浪中显现的月影，以及梦境、幻术——若将种种迷乱显现都这样观修，就能像被轮回绳索所缚的王鸟得到解脱一样。

所以，要对心性不贪不执地修持。凡是迷乱已经穷尽、获得瑜伽安乐的人，就能以明心的百枝，获得佛果。
