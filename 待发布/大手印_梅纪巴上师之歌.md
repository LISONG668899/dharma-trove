# 梅纪巴上师之歌

梅纪巴上师造　据藏文译出

## 题解

本篇收于德格版丹珠尔续部释 ཟི 函第 6a 页（东北目录 D2353），开头没有梵藏题名，篇末只有一句"上师梅纪之歌，圆满"（བླ་མ་མཻ་ཏྲིའི་གླུ），没有记载译者。"梅纪"即梅纪巴（Maitrīpa），本站已译他的不作意法类诸篇、《四印口诀》（D2295）以及紧接在前的《四金刚之歌》（D2352）。题名依跋语与通行称法，定为《梅纪巴上师之歌》。

全篇很短，共四段，每段两句正文，加叠句："根本是心性，它是种种迷乱的自性；而那无始迷乱的自性，若去探究，是找不到的。"四段依次说：无生无灭，束缚与解脱只对迷乱者显现；见到诸法本来无生，就无人生灭被缚；心如无垢虚空，三有也是如此；自性本来光明，要以无分别的自明亲身体验，迷乱从未真正蒙蔽它。全篇是纯粹的心性开示，没有涉及具体的密法修持。

体例：藏文原文全部保留在代码框中，按段落分节，每节后附汉译；凡标"存疑"的按语，表示本译对原文意思没有把握。藏文依 Esukhia 德格丹珠尔电子版。

## 一、无生无灭，唯迷乱者见缚

```
གང་ཡང་མི་སྐྱེ་མི་འགག་དངོས་པོ་བཅིང་བ་མེད། །
ཁམས་གསུམ་གྲོལ་མེད་འཁྲུལ་པ་རྣམས་ལ་སྣང། །
རྩ་བ་སེམས་ཉིད་སྣ་ཚོགས་འཁྲུལ་པའི་རང་བཞིན་ནི། །
ཐོག་མེད་འཁྲུལ་པའི་རང་བཞིན་གཞིགས་ན་རྙེད་མི་འགྱུར། །
```

无论什么都不生、不灭，事物没有束缚；三界也没有解脱可言，［束缚与解脱］只是对迷乱者显现。根本是心性，它是种种迷乱的自性；而那无始迷乱的自性，若去探究，是找不到的。

【按】"根本是心性，它是种种迷乱的自性；而那无始迷乱的自性，若去探究，是找不到的"，是全篇的叠句，以下各节照原文重复。它的意思是：种种迷乱都以心性为根本，从心性中显现；但若去追究迷乱本身，找不到任何实体，所以迷乱本来不成立。这正是大手印"认识迷乱即解脱"的道理。

【按】存疑。"ཁམས་གསུམ་གྲོལ་མེད"，本译译为"三界也没有解脱可言"，意思是：既然本无束缚，也就无所谓解脱。

## 二、见诸法本来无生，谁生谁缚

```
དངོས་རྣམས་གདོད་ནས་སྐྱེ་མེད་མཐོང་བ་གང་ཞིག་ཡིན། །
སུ་ཞིག་སྐྱེ་བར་འགྱུར་དང་འགག་དང་བཅིང་བ་སེམས། །
རྩ་བ་སེམས་ཉིད་སྣ་ཚོགས་འཁྲུལ་པའི་རང་བཞིན་ནི། །
ཐོག་མེད་འཁྲུལ་པའི་རང་བཞིན་གཞིགས་ན་རྙེད་མི་འགྱུར། །
```

凡是见到诸事物本来无生的人，又有谁会生、会灭、会被束缚呢？——根本是心性，它是种种迷乱的自性；而那无始迷乱的自性，若去探究，是找不到的。

【按】存疑。第六句末字"སེམས"，可以连上读作"［谁会生、灭、被缚］之心"，也可以读作"心"作主语，意思不完全确定，本译依义译出。

## 三、心如无垢虚空

```
སེམས་ནི་ནམ་མཁའ་དྲི་མེད་དང་འདྲ་སློབ་དཔོན་གསུང། །
སྲིད་པ་གསུམ་པོ་དེ་འདྲའི་རང་བཞིན་ཡིན། །
རྩ་བ་སེམས་ཉིད་སྣ་ཚོགས་འཁྲུལ་པའི་རང་བཞིན་ནི། །
ཐོག་མེད་འཁྲུལ་པའི་རང་བཞིན་གཞིགས་ན་རྙེད་མི་འགྱུར། །
```

阿阇黎说：心就像无垢的虚空；三有也是这样的自性。——根本是心性，它是种种迷乱的自性；而那无始迷乱的自性，若去探究，是找不到的。

【按】"阿阇黎说"，这里的"阿阇黎"大概指梅纪巴自己的上师，或泛指诸师。"心如无垢虚空"，是萨惹哈以来大手印常用的譬喻。

## 四、自性光明，何以迷闷

```
རང་བཞིན་མི་རྟོག་རང་རིག་ཉམས་སུ་མྱོང་བས་འགྲུབ། །
རང་བཞིན་འོད་གསལ་འཁྲུལ་པས་ཅི་ཕྱིར་རྨོངས་པར་འགྱུར། །
རྩ་བ་སེམས་ཉིད་སྣ་ཚོགས་འཁྲུལ་པའི་རང་བཞིན་ནི། །
ཐོག་མེད་འཁྲུལ་པའི་རང་བཞིན་གཞིགས་ན་རྙེད་མི་འགྱུར། །
```

自性［大手印］，要以无分别的自明亲身体验而成就；自性本来是光明的，又为什么会被迷乱所蒙蔽呢？——根本是心性，它是种种迷乱的自性；而那无始迷乱的自性，若去探究，是找不到的。

【按】末两句是一个反问：自性本来光明，迷乱又从何而来？答案就在叠句之中：迷乱若去探究，本来找不到，所以光明从未真正被蒙蔽。

## 跋语

```
བླ་མ་མཻ་ཏྲིའི་གླུ་རྫོགས་སོ། །
```

上师梅纪之歌，圆满。
