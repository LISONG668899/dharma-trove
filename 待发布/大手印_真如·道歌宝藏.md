# 真如·道歌宝藏

阿阇黎塔嘎纳造　据藏文译出

## 题解

本篇梵名 Tattvadohagītikā，藏名 do ha mdzod kyi de nyid kyi glu，直译为《道歌宝藏之真如歌》，本站依通行题名称为《真如·道歌宝藏》。收于德格版丹珠尔续部释 ཟི 函第 4a 页（东北目录 D2346）。跋语说是"从阿阇黎卡纳日传承下来的塔嘎纳所造"，没有记载译者。

塔嘎纳（Thaganapa）是八十四成就者之一。依成就者传记，他原是一个惯于说谎的人，上师告诉他：一切法本来就如谎言般虚妄不实，以此引导他证悟空性。本篇反复说"真如很难以言语表达""仅凭言语岂能成办"，正与他的这段因缘相应。跋语中的"卡纳日"（ཀ་ན་རི），所指不明，可能是他的上师，存疑。

全篇约二十句，以"证悟真如极为困难，就像孩童玩掷骰的游戏"与"塔嘎纳这样说"为叠句，主旨是：自他无实；不除去执显、执空的分别，不能解脱；真如不能以言语成办，只能在证悟心性中得到。全篇没有涉及具体的密法修持。

体例：藏文原文全部保留在代码框中，按意义分节，每节后附汉译；凡标"存疑"的按语，表示本译对原文意思没有把握。藏文依 Esukhia 德格丹珠尔电子版。

## 一、自他无实，如哑童之梦

```
བརྟགས་ན་བདག་གཞན་དངོས་པོ་མེད། །
བྱིས་པ་ལྐུགས་པའི་རྨི་ལམ་འདྲ། །
དེ་ཉིད་རྟོགས་པ་ཤིན་ཏུ་དཀའ། །
བྱིས་པ་རྒྱན་པོ་རྩེ་བ་འདྲ། །
ཐ་ཀ་ན་ནི་སྨྲ་བར་བྱེད། །
དེ་ཉིད་ཚིག་གིས་བརྗོད་པ་དཀའ། །
```

若加观察，自与他都没有实体，就像哑巴孩童做的梦。证悟真如极为困难，就像孩童玩掷骰的游戏。塔嘎纳这样说：真如很难以言语表达。

【按】"哑巴孩童的梦"，比喻心性的体验真实可感，却说不出来，萨惹哈《见修行果道歌》中也有"如哑巴做梦"的譬喻。

【按】存疑。"བྱིས་པ་རྒྱན་པོ་རྩེ་བ་འདྲ"，"རྒྱན་པོ"一般指赌博、掷骰之戏，本译译为"孩童玩掷骰的游戏"。这句在全篇反复出现，比喻的用意不完全确定：可能是说证悟真如如同掷骰，不能以计度求得；也可能是说凡夫的分别如同孩童游戏，徒劳无实。

## 二、不除显空之念，岂得解脱

```
སྣང་སྟོང་རྟོག་པ་མ་སེལ་བར། །
ཐར་པ་ཐོབ་པར་ག་ལ་འགྱུར། །
ལུས་ངག་ཡིད་གསུམ་དབྱིངས་སུ་ནི། །
དེ་ཉིད་མཉམ་པར་མ་ཤེས་ན། །
དེ་ཉིད་རྟོགས་པར་ཤིན་ཏུ་དཀའ། །
བྱིས་པ་རྒྱན་པོ་རྩེ་བ་འདྲ། །
དངོས་པོ་ཚིག་གིས་བརྗོད་པ་དཀའ། །
```

如果不除去执显、执空的分别念，又怎么能得到解脱呢？对于身、语、意三者在法界中，如果不了知它们与真如平等，那么证悟真如就极为困难，就像孩童玩掷骰的游戏。事物是很难以言语表达的。

【按】"执显、执空的分别念"，是说执著显现为有、执著空为无，都是分别；必须连"空"这一念也放下，才能解脱。

## 三、言语不能成办

```
ཆོས་རྣམས་ཚིག་ཏུ་སྨྲ་བ་ཡང། །
ཚིག་ཙམ་གྱིས་ནི་འགྲུབ་བམ་ཅི། །
སེམས་ཀྱི་དེ་ཉིད་མ་རྟོགས་པར། །
ཐམས་ཅད་གཅིག་པར་རྟོགས་པ་མེད། །
དོན་དམ་རྟོགས་པ་ཤིན་ཏུ་དཀའ། །
བྱིས་པ་རྒྱན་པོ་རྩེ་བ་འདྲ། །
ཐ་ཀ་ན་ནི་སྨྲ་བར་བྱེད། །
```

对于诸法，即使以言语去说，难道仅凭言语就能成办吗？没有证悟心的真如，就无法证悟一切为一。证悟胜义极为困难，就像孩童玩掷骰的游戏。塔嘎纳这样说。

【按】"证悟一切为一"，即证悟一切法一味。全篇的意思是：真如不在言语之中，只能在证悟心性中得到；所以塔嘎纳一再说"难"，是要人放下以言语、思辨求真如的做法。
