# 般若庄严论总义修行次第略讲——教典善说

*华智仁波切 造*

顶礼佛陀！

```
顶礼印藏诸智者成就者，
彼等了知三种所知智慧之实相，
于应当摄持于心的四种加行之道中修学，
并证得应当获得之果——法身。
```

有福缘之人若欲修持无谬之方便，以证得法身之究竟果位，可依两种方式而行，即：**思维（观察修）**与**加行（实修）**。

## 一、思维

要使菩提心的意乐在心中如理生起，必须了知三件事：

一、所应证得的究竟果位。若不了知此点，便不知愿菩提心所缘为何。

二、借以证得此果的道之体性。若不了知此点，便不知行菩提心的实修方法为何。

三、如何避免道上可能出现的种种歧途。若不了知此点，便无法生起胜义菩提心，空性与大悲也就无法双运合一。

因此，最初应当如此思维：

> 从无始以来，一切有情——无一不曾做过我慈爱的母亲、以大恩慈悲怀抱养育过我——却始终漂泊沉沦于苦海的波涛之中，感受着种种痛苦，这是多么可怜！我如今要发起精进的力量，让这一切如母有情，都能从痛苦中获得庇护，都能被引向安乐之地。

如此思维，便能生起大乘之根本——大悲的意乐。

当我们再也无法忍受有情所受的苦难，就如同一位没有双臂的母亲，眼睁睁看着自己的孩子被河水冲走却无能为力一般痛切之时，我们内心本具的佛性（种姓）便已被唤醒，已经准备好领受甚深的教法。

于是我们便这样思维：

> 我如今要成办一切有情的利益，可是连我自己都还没有从轮回的痛苦中解脱出来，甚至连超越这些痛苦的方法都还不知道，又怎能指望利益他人呢？我在想，是否有一种方法，能够毫不费力、无须艰辛，便能成办无量有情的利益？如果有，我发愿全力以赴、去成办它！

生起这样的想法之后，接下来便应当这样告诉自己：

> 呀！善男子（善种姓子），这样的方法确实是存在的。你必须从为一切有情发起菩提心开始，循序渐进地修学，最终证得遍知一切的智慧。然后，你还必须将自己所走过的这条道路，教导给他人。如此一来，你便能自然而然、毫不费力、无须艰辛地，成办无量有情的利益。

你或许会想，这个"遍知一切的智慧"究竟是什么样的？"你所走过的道路"这一说法，是以因来指示果——遍智，正是渐次圆满发菩提心等十种要点之后所证得的究竟之果。而"教导他人[所走之道]"这一说法，是以境来指示能证之心——正是因为通过遍智了知了菩提心等十种要点的对境，才能够将它们向他人宣说。

你或许还会问：为何在解释"遍知一切"这一概念时，不是直接依它自身的定义特相来说明，而是通过它的因与它的境来说明呢？这是因为，若不通过这两者来加以指认，"遍智"是无法解说清楚的。譬如，我们说明"眼识"之时，或者说它是由眼根等因所生，或者描述它对蓝色等对境的了别，但若不依这两者之一，就无法说明它究竟是什么。此处的道理与此相同。

你或许还会想："遍知一切"（一切种智），是否意味着毫无例外地了知一切所知之法？若仅仅是对这十种要点的了知，又怎能称之为"遍知一切"呢？——之所以特别宣说这十种要点，是因为若要毫不费力地成办他利，就必须了知这十种要点，因此才因其至关重要而特意提出，但这并不是说，除此之外的其他一切便都不能了知了。就好比一个人若能看清远处的一根细针，那么近旁的一把刀，自然也能轻易看见——透过了知这些较为深奥难解的要点，其余较为容易理解的事物，自然也会随之通达。

也有人主张，了知这十种要点，就意味着毫无例外地了知一切所知之法。他们依据"所缘乃是一切诸法"这样的说法【译注：出自《现观庄严论》第一品第41颂】，认为一切都已含摄于此。但这样的推论并不成立。譬如，走在道上修行的菩萨，了知道上所缘的一切对境，包括修习一切诸法皆空等等，但这并不意味着他们已经了知了这一切诸法本身。此处的道理相同。也可以说，一个专注于对善、恶、无记三类事物加以取舍的人，理解了这三种范畴，一切事物固然都可以归摄于这三类之中，但这并不意味着，理解了这三种范畴，就等于了知了一切诸法。

再者，有福缘之人或许会想："既然我必须尽己所能地证得这种了知一切相的智慧，那么我究竟应当在什么样的道上修学，才能成办此事呢？"——既然果必须与因相应，就必须修学与此果相应的道。当我们为有情谋求利益之时，由于一切有情的根器意乐各不相同，无法都走同一条道，所以必须了知三乘的一切道，并对它们有一定的亲身体验，才能够将这些道展示给他人。怀着这样的意乐，就必须训练自心生起利他之愿，这便成为心中生起行菩提心的因。

之后，修行者会如此思维："为了这个目标，我要在三乘的道上修学。但既然我所追求的唯独是究竟的大乘，我就必须正确了知上下诸道之间的差别，避免误入较低之道。"怀着这样的想法，并且不离开大悲这一方便，还必须修持真如之义——即观照作为基础的蕴、界、处，远离三十二种分别妄执（增益）。如此一来，用不了多久，胜义菩提心便会在心中生起。

三种智慧是依次第而生的：前者是后者之因，后者是前者之果。因此，当它们被作为闻思所了知的对象、并被作为发菩提心的所缘之时，遍智（一切相智）是最先被提及的，这是为了引发对究竟果位的希求心，因为它是唯一最先被证得的。然而，就它们在个人心相续中生起的次第而言，情况则是：首先，对作为基础的一切诸法直接现证无我；随后，在心中生起超越下劣之道的殊胜大悲；接着，通过针对三种根器的弟子、依其各自之道而施教，成办圆满、成熟、清净，由此使遍智之果得以显现。与这一次第相应，本论第三品结尾处说道：

```
如是此复此……
```

【译注：出自《现观庄严论》，此处仅列出总结偈颂的开头，全颂是对基智等内容的总摄。】

此处是以基智为首而作总摄。

因此，由于这三者的体相是通过闻思无误抉择之后，才被作为发菩提心的所缘的，所以在"六种现观"的总摄脉络中，它们被称为"体相"；而在"三种总摄"的脉络中，它们被称为"所缘——三种因"【译注："六现观""三总摄"均为《现观庄严论》科判体系中的说法，此处论及不同科判角度下对三智之名相的不同称谓】。

因此，当通过闻思来抉择所应了知的对象（即三智）之时，无论是以境来说明能知之心，还是以能知之心来说明境，能够审察这些法义的，唯有一切相智这一种智慧。

这些法固然是一切相智的所缘对境，但同时也是菩萨道智的所缘对境。实际上，它们不仅是这最初两种智慧的对境，也是声闻、缘觉基智的对境。了知这一点，有助于破除对轮回、涅槃以及道中所摄一切诸法体相的种种妄执分别。

在把这三种智慧作为发菩提心的所缘之时，应当发下这样的誓愿："既然是以境来说明能知之心，我就必须在自心中生起与三乘或四种种姓的人相应的种种证悟，从而了知这些对境、并付诸相应的行动。"这样发愿，才够格称为大乘意义上真实的菩提心。正如《经庄严论》所说：

```
善巧乘与智慧之周遍……
```

【译注：出自《经庄严论》第三品第3颂。无著菩萨在其注释中说明，此处"周遍"共有四层含义："有情周遍"，指以利益一切有情为意乐而入此乘；"乘周遍"，指必须修学三乘之全部；"智慧周遍"，指必须通达二种无我；"涅槃周遍"，指由于轮回与涅槃寂静无二无别，故不应从各自过失或功德的角度分别看待二者。】

因此，从一开始便誓愿投身于周遍一切的乘与周遍一切的智慧，是最殊胜的承诺。

由此可知，将这三种智慧与菩提心相联系起来考察，它们无疑分别是愿菩提心、行菩提心以及胜义菩提心之因，这一点前面已经说明。同时，它们也分别是"意乐"（'dun pa）、"思维"（bsam pa）、"殊胜意乐"（lhag bsam）这三个阶段之因。依此次第，首先，对所应证得的一切相智生起意乐；随后，通过作为其因的道智，对成办他利生起思维；进而，通过修学避免误入下劣之道的种种歧途、不堕入二边，这份思维便从自利之中解脱出来，成为殊胜意乐。至于其后如何趣入加行等其余各层次的菩提心，则不难理解。

这三种智慧，也可以依照《宝性论》释论中所说的方式，与自心中成就三宝相对应加以说明：第一，通过一切相智宣说佛陀的智慧，对应"于一切法圆满正觉"；第二，在道智的脉络中宣说三乘的一切道，对应"圆满转动法轮"；第三，在基智的脉络中宣说上下诸乘弟子各自不同的证悟，对应"被无量已调伏之眷属所围绕"。这只是另一种归纳方式而已。

【译注：出自《宝性论》相关释论，其中三句原文合参为："薄伽梵于一切法圆满正觉、圆满转动法轮、为无量调伏眷属所围绕。"依无著菩萨之解释，此三句依次显示佛、法、僧三宝次第生起之理。】

在这些脉络当中，基智在经文本身当中，被明确宣说为是不堕于二边的、作为对治的基智。而堕入二边之中任何一边的、不利的基智，则是通过反面的方式加以理解的；由于声闻、缘觉的种种证悟并未被直接说明，经文才说它是"他者所未能体验的"【译注：出自《现观庄严论》第一品对基智的界定】。

因此，头脑不够敏锐的人，或许会因"基智被解释为一种可能的歧途，同时又是在心中产生道智的方法、以及生起胜义菩提心之因"这样的说法，而心生些许疑惑。但实际上，一旦遣除了一切不利的歧途，真正的、作为对治一切增益与损减的基智在心中生起之时，那便是大乘的道智，也正是胜义菩提心。同时，在此过程中也会连带获得对声闻、缘觉之道的了解，因此二者并不矛盾。而且，之所以在道智的脉络中说明声闻、缘觉之道，正是为了能够引导那类根器的人。修学与小乘相应的无我证悟，并不会与大乘之道相冲突，正是为了能够藉此引导他人。至于应当避免的那种基智，则被解释为：小乘行者所怀有的、对真实存在的执著性增益，这确实与大乘之道相冲突，此外还包括仅仅为求自利而趣入寂灭的片面极端。因此，这两种"基智"（应取的与应舍的）并非只是简单的重复。

将这三种智慧与后续的五种现观相联系时，一切加行与顶加行主要是基智的加行，渐次加行与刹那加行则是道智的加行，而所证得的果——法身，正是一切相智本身。因此，八种现观可以依"思维"与"加行"这一区分，归纳为三类。礼敬文中也宣说了这三者，这正是为何说"全论的义理都含摄于礼敬文之中"的缘故。

在把四种加行与两种智慧（基智、道智）相联系时，我们用了"主要"一词。也就是说，这样的解说方式，是依据其中最为重要的关联而说的，有助于理解各道之间的关系、次第以及所含摄的内容；但这并不是说，它们在每一个方面都彼此对应，正如在解说"一切相加行圆满之时"也涉及三智的加行这一点上所看到的那样。

```
圣者所说、智者所解之义理，
以三种智慧善加抉择，
此即三智之心要义理，
若换一种方式解说，岂不更加困难？
```

【译注：此颂中"以三种智慧善加抉择"之"三种智慧"，指闻、思、修三慧，与前文反复所说的"三智"（遍智、道智、基智）并非同一概念，藏文原颂在此处刻意运用二者读音、字形相近之处（shes rab gsum 与 mkhyen pa gsum）以为文字游戏，中译难以兼顾，特此说明。】

## 二、加行

第二个总义，是大乘之道上的加行。这一部分分为两个方面：一、一切相加行，借此能够娴熟于证悟；二、渐次加行，借此能够令证悟稳固。

### （一）娴熟于证悟：一切相加行

所谓"娴熟于证悟"，是指已经如三智所示，了知了一切所知诸法的体相之后，将三乘的种种证悟作为希求向往的对境，然而此时尚未获得哪怕丝毫证悟的功德。打个比方：就好比一个贫穷的仆人，虽然清楚知晓、能够精确计算她那富有的主人所拥有的一切财物受用，却连一根针也不能据为己有。

因此，我们所说的"娴熟于证悟"，是指依照二谛无二双运的方式，修习从最初的无常之相，一直到究竟菩提之相为止的一切相，从而对先前尚未证悟的内容生起证悟。

至于什么是"令证悟稳固"，则是指将此前在心中生起的一切先后修法加以连结、并依正确的次第使其现前。此外，对于此前尚未生起的部分，通过闻思使自己逐渐熟悉，并生起愿其生起的希求，同时精进地稳固对一切已生起证悟的熟悉程度。打个比方：就好比孩童初学识字之时，先是逐一学习字母的音节，学习卡、卡哈等基本字母，再学习后加字、前加字等等，这好比是一切相加行；随后，他们学着拼读由若干已学字母组合而成的词语，比如"桑杰"（意为"佛"）这样的词，通过不断熟悉而变得更加娴熟，这好比是渐次加行。至于顶加行与刹那加行，则是对前两种加行达到完全娴熟的阶段，它们并不是另外独立的修行方法。

一切相加行达到完全娴熟，共有四种情形【译注：英译本此处有一条注释，指出所依据的藏文版本（SGa）作"gnas skabs bzhi"（四种阶段），另一版本（SGb）作"bcu"（十种），系刊刻讹误，学者Brunnhölzl似采用了后一种读法，此处依SGa版本译为"四种"】：

一者，在世间道中，加行道的顶点，出现在能够压伏四种能取所取分别念及其增长的确定对治之征相在心中生起之时。由世间修法所能生起的证悟，没有比这更高的了。

二者，在圣者之道中，首先，见道的顶点，出现在作为断除见道所应断除的四种能取所取分别念之对治的见道无分别智，在心中生起之时。由直接照见法性的等持所能生起的证悟，没有比这更高的了。

三者，随后，修道的顶点，出现在断除修道所应断除的四种能取所取分别念的对治在心中生起、并通过修习一切相而能够娴熟成办一切世间利益安乐之时。修道所修的三摩地，没有比这更高的了。

四者，此后，究竟道的顶点，出现在就连对二谛各自分别、或善或恶、或相互抵触这样的微细执著与显现也已断除、并且由所缘、行相与因这三者所标示的无分别智在心中生起之时。这是因为，在究竟果位——法身——之前，再没有其他居间的道了。

渐次加行完全娴熟的时机，则是刹那加行。当一种无穷无尽的功德得以现前之时，便是道的顶点得以现前之时——此时，此前所证悟的一切无穷功德，都以无二、离相的方式一并现前。这与前面所说的"无碍道的顶点"，二者仅仅是依"正行"与"后得"这两个概念上有所区分，实际上并无差别。

因此，真正需要修学的训练，是一切相加行与渐次加行。而且，依照经文的次第，顶加行是依据一切相加行而在心中生起的，这似乎表明修行是循序渐进地发展的，但这只是它们作为因果两两配对而被解说的次第，并不是实际修行时的次第。在实际修行时，从最初阶段开始，二者便同时具足于修行实践之中。譬如，渐次加行在闻思的脉络中，也是这样被解说的。

现在，让我们说明这两种加行与实修的关系，作为它们如何被修习的入门介绍。首先，就一切相加行而言，三智的诸相被归纳为一百七十三相，这些便是禅修的对境。其中，让我们以基智的第一相——无常之相——为例，说明修法。所谓"境相"（所缘之相），是指一切属于有为法范畴的诸法，都以刹那生灭的相续之流的方式而安住。所谓"识相"（能知之相），则是指依据教证与理证，修习这一无常的事实本身，从而遣除一切错误的分别妄执。在声闻、缘觉之道中，仅此便已足够。然而在大乘之中，则必须在此基础上生起与一切乘相应的证悟，所以仅止于此并不足够；必须将境相与识相二者都作为对境，通过加行加以修习。

虽说有二十种加行【译注：此处所指为一切相加行内部所细分的二十种加行】，其中三种只是就了知三智的方式所作的划分，另外十五种则是就范围界限所作的划分。因此，就实际的禅修而言，只有两种：**无住加行**（不住于任何法之加行）与**不加行之加行**（无所加行之加行）。就此而言，所谓"无住"的禅修，是指对境已经止息了执著攀缘的禅修【译注：华智仁波切在别处的著作《中阴简明教授》中，将"无住加行"定义为"断除对外境好坏二者的执著"】。在此语境中，由于实际所缘的无常之相本身就是对境，所谓"无住加行"，是指不保留任何心识上的执著攀缘，因为即便是对无常的了知，也仅仅是名言、世俗层面的证悟，而从胜义的角度而言，就连无常本身也没有真实的存在性。

如此了知无常本身即是空性之后，就连正在修行的心识本身，也会被发现是超越一切边执的空性。此时，并没有一个"正在修习某种瑜伽的人"可被观察到。因此，就连"禅修"这个词本身，也只是一种概念上的分别构造而已；从实相而言，连一粒微尘大小的"所修"都不存在。这种理解，被称为"不加行之加行"，因为它是这样一种理解：无论从对境还是从能知之心的角度而言，都没有什么可以被加行、被修持的。这正是止息对能知之心（主体）之执著攀缘的禅修【译注：华智仁波切在《中阴简明教授》中，将"不加行之加行"定义为"不作意、不散乱、无所修，只是安住于自然状态之中"】。

这两种加行，也被称为"止息交替安住"以及"瑜伽"——"瑜伽"一词，与"加行"是同义词。我们也可以用另一套佛法术语来说明这二者：这二者所指的，正是所谓"无所修之境，亦无能修之行"。"无住加行"，指的是没有任何作为禅修所缘的对境；"不加行之加行"，指的是没有任何能够修持的行动本身。

再者，《般若佛母经》中所解释的"无分别"，其义理正是这个——即不去缘取任何基于对境相或心相之实有性的执著攀缘所生起的种种分别念。或者也可以这样说："无住"，是指由于对境本无实有，心便不会攀缘任何东西；而"不加行之加行"，则是指这种对一切都不攀缘的状态，本身就是一切瑜伽当中最为殊胜的一种。这触及了所谓"无修之修"这一说法的同一要点。正如《大乘经庄严论》所说：

```
无有能观于所修之见，
是为最胜之禅修。
```

【译注：出自《大乘经庄严论》第十八品第74颂。】

因此，既然这才是修习《般若佛母经》真实义理的究竟修法，我们就必须真诚努力地遣除对这一要点的一切误解。否则，若因为经文中直接论及这一点的文字相对较少，便将其视为无关紧要的枝节，反而在无关宏旨的种种细节上滔滔不绝地卖弄学问，那只会切断自己与这甚深法义之佛法的联系。

因此，印度、西藏成千上万位智者、成就者所留下的种种经教传承与修行指南，最终都汇归于"无所执著"这唯一一点之上，就如同千万条溪流最终汇归于同一座桥梁之下一般。当你了知这一点之后，便会明白，那些仅仅因为措辞上的些许差异，就误以为彼此真实相违、从而激烈争辩、剑拔弩张的做法，是完全没有必要的。事实上，我认为，对一切法门传承都怀有源自信心与确信而生的满足感与安然自在，正是已经学习过般若的一种标志。

这并不是说，你应当抱持一种断灭见，认为既然一切诸法都是空性，就无所可修，从而原地不动、无所作为。这里的要点在于，应当了知：就究竟而言，能所二者所标示的一切诸法，从其自性而言本来就远离一切戏论、本来无生、超越分别心的境界，因此不应对任何事物生起执著攀缘。然而与此同时，在如幻的世俗层面上，你必须依照三种要点而修：最初发起菩提心，正行不落分别念之缘取，最后作回向。若能如此修持——以"无修之修"的方式，修习从有为法的无常之相，一直到菩提本身之相的一切相——并将其融入心相续之中，这便是依《般若经》修习空性最为殊胜的方法。正如经中所说：

```
善巧木工之技艺，
能造男女之形像，令行种种事；
如是菩萨善巧于智慧之行，
以无分别智成办一切事业。
```

【译注：出自《般若摄颂》第四品第5颂。】

这与在基智脉络中所说的、一切诸法皆可通过七种觉受之相加以指示、并以"四种无所执"而修习之义理相同。

【译注：英译本原注此处提及"四种无所执"（rlom med bzhi），系《般若庄严论》基智品中所说的四种修法要点，其详细内容因篇幅所限未加展开。】

如此修习，短期之内，能够生起三乘的种种证悟。究竟而言，这一切最终都清净、融摄于那唯一的、远离戏论的空性——即无所执著这一广大境界之中。有智慧的人应当了知，正是这种显与空、或方便与智慧不可分割的双运，将二种资粮融合为一，才是令诸佛欢喜的、无与伦比的殊胜之道。

在这一脉络中，还有诸如十力、四无畏等种种功德之相，这些是佛陀智慧的诸相，此刻虽不能直接修持，但仍然可以通过培养"愿于未来令其在心中生起"这样的意乐与愿力而加以修习。据说，一旦证得诸地，虽然这些功德尚未真正现前，但相续中已经会生起某种相似的征兆。

### （二）令证悟稳固：渐次禅修

如此，将三智的一切相归纳为一百七十三种，通过一切相加行，依二谛无二双运的方式一一修习之后，便要对一切相加行之时心中所生起的证悟，加以稳固。具体做法是：依次第、以越来越快的速度修习，将前后相续的修法加以连结，并且修习到每一相之中都圆满具足其余一切相的程度。

让我们通过修习与第一种智慧（基智）相关的苦谛之相，来加以说明。首先，专注于无常、苦等各个相；然后，对于一切有为法在世俗层面上如何毫无恒常可言，生起稳固的确信。此外，还要了知这一切在胜义层面上即是空性，从而不生起任何增益或执著。在心相续中，依次修习这二者无二双运的境界，这便是一切相加行的修法。以这种方式在心中生起的种种相，要按照正确的次第——比如无常、苦、空、无我——一次又一次地反复提炼、精修，在成办前一相之后，随即成办后一相，如是刹那刹那相续不断。而且，其余三相都含摄于无常这唯一一相之中，因为经中说"苦是由于无常而产生的"，而由于有为法犹如相续不断的流水之链，所以也是空性、无我的。如此思维一切相如何相互含摄，从而增进熟悉。

那么，你或许会问：既然经文将渐次加行解释为忆念佛陀等十三个要点，为何修习无常等种种相，也算是渐次加行呢？——这十三点，的确是渐次修法的组成要素，但并非其主要修法。就此而言，三宝是渐次修法的所依，因为皈依乃是一切道之基础。忆念本尊，则为修道提供了见证。其余七项，构成了修法的具体方式，因为对于每一相，都要修习六度乘以六（即三十六度）如何圆满具足、并被空性所摄持。忆念布施与持戒并加以受持，能够成办修道所需的一切顺缘——投生善趣的色身依止，以及丰足的资粮，因此这对于来世继续修学也是有益的。

因此，真正的修法，是在中品证悟【译注：即《现观庄严论》第二品所说的道智】的脉络中被界定的：

```
体相、加行，
其顶点、其次第。
```

【译注：出自《现观庄严论》第二品第2颂。】

如果我们将此处的"其"字理解为指三智之相，那么便可以推知，三智之相正是渐次修法的所缘境。而如果我们将同一个"其"字，每次都理解为指代它前面所提到的内容，那么"渐次"便是指一切相加行之顶点渐次呈现的次第。无论如何理解，可以肯定的是，渐次修法的所缘境，与一切相加行修法时的所缘境，并无二致。

既然渐次修法的所缘与一切相加行修法的所缘并无二致，你或许会问：那为何要把它们说成是两种不同的证悟呢？——这是因为二者在着重点等方面有所不同。一切相加行，主要是修习三智之相所标示的一切诸法，如何是远离戏论的空性；而渐次修法，则主要是以大悲为动力，训练令一切相之等持愈发有力。此外，一切相加行侧重于"正行入定"，渐次修法则侧重于"后得出定"。

我们在谈及这两种加行时用到"正行"与"后得"这两个词，但这并不是我们目前心识状态中所理解的意思——即"正行"指处于等持之中平等安住的时刻，"后得"指从那种状态中起身之后从事日常活动的阶段。此处的"正行"，是指已登诸地的圣者们，以无分别智安住于远离一切相的境界之中平等安住的状态；"后得"，则是指其后，他们运用其对一切相所修之等持的力量，而展开的种种活动。

我们这些初学者，此刻在修习一切相加行之时，是先将无常等诸相带入心中，确立其空性之后，再加以修习。而对于渐次修法，则是不离于这份空性，依次将每一相带入心中，加以提炼、精修。因此，对我们而言，似乎二者之间只是修法方式上的差别——是依次修习一相还是同时统摄众相，或是侧重于空性还是侧重于诸相之别，看起来并不存在"正行"与"后得"这样的差别。然而，对于已登诸地的圣者而言，在修习一切相之时，并不需要逐一确立每一相各自的空性、然后再修习它们如何超越生起——一切能所二取的分别显现，早已在无分别智的境界之中被清净殆尽，就如同盐溶于水一般。而且，超越凡夫心一切戏论分别的胜义境界，也已经现前彰显，这便是"正行"入定。对于圣者而言，情形正如《密严经》中所说，善财童子的诸位善知识展现了自身等持的解脱力量一般：正是凭借等持的力量，才能够成办布施等菩萨行事业的浩瀚洪流。因此，"后得"，是指通过渐次修法，将含摄一切相的等持予以现前实现。

尽管圣者的正行入定并不涉及对种种不同诸相的修习——因为一切戏论分别都已彻底寂灭——但这并不意味着它完全不含有任何相。譬如，就见道顶点的脉络而言，经中说：

```
布施等诸法，
彼此互相含摄，
于一刹那忍中悉皆汇合，
此即此处所说之见道。
```

【译注：出自《现观庄严论》第四品第10—11颂。】

因此，此处的见道，被解释为具足六度乘以六（即三十六种）波罗蜜多的体性。同样，三智的一切相，也都圆满含摄在这种于无分别智之中一切戏论已然寂灭的等持境界之中。因此，这也正是所谓"于一切相中圆满正觉"这一说法的含义。

【译注：出自《现观庄严论》第一品第1颂，全称"一切相智性"，此处的"圆满正觉"即指对一切相的证悟圆满具足于一心之中。】

在七不净地【译注：即初地至七地】之中，菩萨在后得位中所成办的一切如大海般浩瀚的事业，都是依托于一切相的等持而成办的。然而，他们尚不能做到令这一切事业与超越诸相的绝对法界完全成为一味一体地修学。到了第七地，虽已具有无相等持，但仍需要借助功用，因此一切相加行与渐次修法之间仍有区别。从第八地开始，通过以一切相之最殊胜为体性的空性等持，如来一切无边、不可思议的功德，都会在无垢的法界之中渐次证得。至此，无功用、无相之道自然任运地成办自他二利。这便是修学"轮涅平等加行"的阶段。这也正是一切相加行与渐次修法开始融合为一的起点。到了相续末尾的无碍道，垢染在法界中得以清净的最终殊胜功德得以现前。基于执持二谛为各别不同的十六种相违见解，此时已被彻底断除、了无余痕，一切相加行与渐次修法的正行与后得，至此变得无二无别。智慧与等持得以均等平衡，这便是刹那智的显现。

此外，在《贤劫经》《三摩地王经》等诸多经典之中，虽然列举了无数种菩萨事业之门，例如广大平等之等持等等，但这些无不含摄于这渐次修法的等持之中。

至于修习这二者的必要性：若没有一切相加行——即修习一切诸法皆空——就无法连同习气一并断除二障，也就无法证得对一切诸法平等性的证悟而成佛。而若没有渐次修法——在后得位中娴熟掌握一切所知诸法——就无法证得遍知一切的智慧本身，也就无法凭借令仅仅一种无垢功德得以现前，便令一切此类功德一并现前。这正相当于《宝性论》中所说：

```
清净客尘烦恼，
简言之，可说是
无分别智所生之果；
而具足一切相之最殊胜的法身之决定获得，
则显示为后得智所生之果。
```

【译注：出自《宝性论》第五品第6颂。】

简单来说，这两种加行构成了大乘的究竟修法，是证得佛陀究竟二身之因。因此，它们含摄了诸如空性与大悲、智慧与方便、诸道与诸地、见道与修道、智慧与等持、断与证、法性与差别、法身与色身等等无量功德。有人主张这些是同一自性，也有人说它们相似，或说在范围上有所不同，或说它们是因果关系——这些都有待进一步探讨。

在资粮道与加行道上，由于心仍然执著于实有，尚未从业与烦恼中解脱，所以必须主要修习空性、修习一切相加行。而一旦登地之后，则主要致力于成办他利，因此主要修习作为遍智之因的渐次修法。这正是为什么说"到达顶点之后便修习渐次法"，也是为什么经中说"其顶点、其次第……"的缘故。此中义理应当如此理解。

## 破除偏执一端之诸种邪见

有人说，那些揭示甚深空性——如虚空一般、远离一切复杂构造、超越凡夫心境界——的教法，是为诸如圣者一类的最上根器之人所说的；而那些以行持为主的末转法轮经典及其释论，则是为初学者所说的。这样的主张，与胜者诸佛及其菩萨心子的传承并不相符。譬如，向一个满口都是糖蜜的人解说糖蜜的滋味，又有什么意义呢？为一个刚出生的婴儿摆设丰盛的宴席，又有什么用处呢？同样，向已经亲自证悟了甚深真理的圣者们讲说这甚深的真理，又有什么必要呢？凡是尚未在见道上证悟实相的本性、尚未在修道上串习种种等持的人，更遑论那些具有不可思议解脱的菩萨们浩瀚广大的事业，都还无法修学真实的六度。正如经中所说：

```
当与布施不相顺之因素已经衰减，
且已具足无分别之智慧，
则一切所愿皆能圆满成办——
此即成熟有情之三种相状。
```

【译注：出自龙树菩萨《般若摄义》第26品第8颂。】

透过审视诸如此类关于六度定义的论述，便可理解这一要点。

再者，也有人说，一旦证悟了空性，便无须再修学广大的行持。这样的说法，实在是一种欺人的谎言，因为唯有证悟空性，才能够真正修学这样的广大行持。一个尚未证悟空性的人，又如何能够成办这样的事业呢？难道一个还在摇篮中的婴儿，能够在众人面前翩翩起舞吗？

那么，你或许会问：既然如此，证悟空性之后，从事这样的事业，其意义又何在呢？布施等修法，难道不正是纯粹为了证悟空性而修的吗？——这样的想法，恰恰暴露出对大乘之道最基本原则的误解，是把低劣之道错认为大乘。礼赞文中说："谁以道智，助益乐于利他之人成办世间之利……"由此可见，菩萨的究竟关切正是他利。因此，通过布施等广大行持，圆满成办一切无量有情的愿望，正是大乘道的主要修法。若不能直接证悟空性，便无法了知自他平等，因而自己的行为也就无法达到彻底的清净。这正是为什么直接证悟空性，是菩萨浩瀚事业之洪流的前行准备。然而，这怎么可能是大乘之道最终极的追求呢？《经庄严论》说：

```
既已圆满证悟真如之性，
随后修学增上戒学、
增上定学与增上慧学。
```

【译注：出自《经庄严论》第二十品第17颂。】

在关于菩萨阶位的划分脉络中，也说明处于七不净地的菩萨，是安住于"行持"之中的。

不过，也有人认为，行持固然是为了净化心相续所必需，却并非大乘之道的究竟目标。他们或许会引用佛经中的说法，认为直到第八地之前，诸佛都不会为菩萨授记，是因为此时仍然安住于行持之中；而一旦证得第八地，一切行持都已彻底超越，因此才会授记。此处的义理，正如前面所解释的：直到第七地为止，尚不具备无功用、超越诸相的道，无分别智尚未与利他行事业融合为不可分割的双运。因此，此时对行持之实有性仍存有些微的执著，所以说是"安住于行持之中"。而在证得第八地之后，无功用、超越诸相的境界得以现前，由于此时已经远离了对行持哪怕丝毫的执著攀缘，行持便任运自成，因此说是"超越行持"。然而，即便到了这个阶段，据说仍然存在堕入无分别的、寂静一边法界的风险，那便会成为一种断灭性质的涅槃。因此，诸佛才会一再劝勉菩萨，鼓励他们为利他众而勤奋努力。倘若行持并非道的究竟要点，那么这样的劝勉又有什么意义呢？

再者，你或许会主张：如果布施等修法不是为了证悟智慧而修，这岂不是与《入菩萨行论》中的这段话相矛盾：

```
此等一切法之支分，
能仁皆为智慧而宣说。
```

【译注：出自《入菩萨行论》第九品第1颂上半。】

然而，此处所说的"智慧"（般若），指的是诸佛无二的本智（吉纳纳，ye shes），正如陈那阿阇黎所说：

```
般若波罗蜜多，
即无二之本智，此即如来。
```

【译注：出自陈那论师《般若摄义论》，此处所引即"般若波罗蜜多者，即如来无二智"之意。】

至于要如何指认这种智慧的本体，本论智慧品中说：

```
实有与非实有，
若俱不住于心前，
则于彼时，别无他途，
唯有安住于远离概念的彻底寂静之中。
```

【译注：出自《入菩萨行论》第九品第34颂。】

由此可知，本论是将智慧，等同于远离一切戏论概念的胜义境界来加以指认的。随后，本论紧接着便破斥了这样一种质疑：既然如此，色身岂不是就不会为利益众生而显现了吗？

```
犹如如意宝与如意树，
能满足一切希求与愿望，
同样，凭借为所调伏众生所发的祈愿，
诸佛胜者才会显现于世间。
```

【译注：出自《入菩萨行论》第九品第35颂。】

你或许会接受这一点，但仍然坚持认为，大乘道最重要的要素，是证悟无我的智慧；大乘道所追求的，是断除二障之后的觉悟境界，而这必须通过甚深的智慧才能予以彰显。对此，我们不妨反问：你为何仍然固执于这种错误的见解，坚持将低劣之道误认为大乘呢？大乘之道所真正追求的，并不是断除二障之后的佛果。正如礼赞文所说："诸圣者所具足者，藉此以遍知种种方式而说法……"在这段话中，"人"是指诸佛，"方便"是指遍智，"果"是转动法轮。倘若究竟所求的仅仅是觉悟本身，为何还要提及一个更进一步的果呢？

因此，无论是从暂时还是究竟的角度而言，大乘之道最为重要的追求，都是他利。至于成办他利的真实方便，在道位阶段，是布施等菩萨行；在果位阶段，则是佛陀本身的事业。而在这两个阶段中，能够成办这一切最重要的前行或因，都是智慧——这正是为何智慧被描述为最殊胜、最首要的缘故。

《般若摄颂》说：

```
布施之前所应先具者，即是智慧，
其后持戒、安忍、
精进与禅定，
亦复如是，皆以智慧为先——
智慧能护持诸善法，令其不致虚耗。
```

【译注：出自龙树菩萨《般若摄颂》第四品第5颂。】

又说：

```
一群盲人若无向导，
不知道路，又岂能寻至城中？
同样，若无智慧，其余五度亦如盲者，
若无智慧作向导，终究无法抵达觉悟。
```

【译注：出自《般若摄颂》第七品第1颂。】

这段话说明，智慧必须走在最前面，就如同引导盲人的向导一般。首先在心相续中生起对空性的无分别智证悟，随后，通过布施等广大菩萨行，历经无量劫为利益他人而努力精进——如此，透过圆满、成熟、清净，才能证得真实的究竟边际——这便是无有错谬的道之次第安排。

在解说六度的次第之时，经中说：不过分执著于财物，本身就是一种持戒；而奉行持戒，本身也就是一种安忍。因此可以说，前者是后者之因，后者是前者之果。经中又说：

```
是故布施能带来丰足的资财，
持戒则引向善趣，禅定能克服烦恼；
而智慧能遣除一切烦恼障与所知障，
因此智慧最为殊胜，其因正是研习此经。
```

【译注：出自龙树菩萨《般若摄颂》第七品第？颂。此段藏文原本未标明确切出处颂号，然依经文脉络，当属《般若摄颂》相关章节所摄。】

诸如此类涉及品质高下的说法，是就凡夫的布施等修法而言的。这也同样适用于前面所引《入菩萨行论》那段经文的理解。

正因如此，当我们在资粮道与加行道上，为了净化心相续、积累资粮，而修学布施等诸度之时，这仅仅是令甚深见地得以在心中生起的一种因，并不算是修学广大菩萨行本身，甚至也算不上是真实的六度，因为这样的修学并不具足以下四种特相中的任何一种：

一者，并非以无分别智现前的方式而行；
二者，与之相违的因素尚未减损；
三者，尚不能圆满成办有情的一切愿望；
四者，尚不能依有情各自的因缘，令其安立于三种觉悟中的任何一种。

再者，由于既未成办这四种功德，也未克服七种贪著【译注：依无著菩萨《经庄严论》释论对布施波罗蜜多的解释，这七种贪著分别是：一、对财物的贪著；二、拖延不修的懈怠；三、满足于少许修行；四、期望有所回报；五、贪著异熟果报；六、贪著顺缘；七、散乱】，所以并不具备"波罗蜜多"（度、到彼岸）的资格。譬如，声闻、缘觉修习不净观等禅定，依大乘的标准而言，并不能算作真实的禅定波罗蜜多。

有智慧的人，可以透过一个譬喻来理解这些要点。就好比一位精通医术的良医，使用珍贵的水银来治疗众生的疾病，首先要将水银提炼净化、反复洗涤，然后加热处理；一旦解毒完成，便可以配合各种药物，用来治疗种种疾病。同理，菩萨们在心中生起珍贵的菩提心——这是断除一切轮涅之病的唯一之因。只要他们仍是凡夫，就仍带有自利自私的贪毒，因此必须让自己反复串习甚深的空性。当实相的本性在见道中现前彰显之时，他们便了知了诸法的平等性，由此得以清净，从而摆脱了一切自利贪欲的垢染。此后，将三轮无分别的修法，运用到菩萨的一切广大事业之中，凭借舍弃自利之心而生起的殊胜精进，他们便能治愈一切由有情的烦恼障、所知障所生的种种疾病。

再者，《陀罗尼自在王请问经》【译注：即《宝积经》中的相关章节】中以清洁宝珠为喻的一段经文，也说明了同样的道法次第。前两个阶段容易理解，而后面提到的"不退转法轮"这一说法，在《经集论》【译注：即龙树菩萨《大乘宝要义论》】等释论中，被解释为大悲与空性智慧相结合的道。"三轮完全清净"，是指毫无三轮概念地修习布施等菩萨行。至尊圣者龙树在其《经集论》中引用了这段经文，以证成究竟而言唯有一乘的道理。经文说明，最初通过思维无常、苦等而对轮回生起厌离，然后趣入大乘甚深与广大的部分——这证明了声闻、缘觉之道，不过是通往大乘的垫脚石而已。圣者无著菩萨在其《宝性论释》中，也引用了同一段经文，说明这正是菩萨如何渐次净化自身根性的过程，以此建立如来藏这一要素，指出所应净化的，正是那清净的、作为佛性的本元。

这两种解释，本质上是相似的。这两位开宗立派的大德，都主张同一种次第之道：第一阶段，通过思维无常、苦等，来净化自心；第二阶段，通过宣说三解脱门，彰显甚深见地所指的实相本性；第三阶段，通过宣说不退转法轮以及三轮完全清净的教法，修学菩萨的广大行持。凡是懂得如何调和这两位世间无比庄严的圣者毫无瑕疵的论著、并将其融会贯通于实修之中的人，才配得上被称为真正的智者。若只是出于对某一立场的执著所生起的贪嗔之心，而一味热衷于辩论，那么这或许会招致舍弃正法这样严重的恶业，却绝不可能通过闻思学习而令自心获得真正的解脱。

简而言之，大乘之道的主要目标，是佛陀的事业——将遍满宇宙的一切有情，都安立于无上圆满佛陀的果位之中。正因如此，菩萨的善根之源，才是无穷无尽、遍满一切的。正如《普贤行愿品》所说：

```
乃至虚空世界尽，
众生及业烦恼尽，
如是一切无尽时，
我愿究竟恒无尽。
```

倘若不是这样，若大乘暂时的目标仅仅是证悟空性，究竟的目标仅仅是心从二障的束缚中解脱、证得佛果，那么菩萨的善根之源，也就会随着这一证得而穷尽，因而是有限的——这便与依循低劣之道所证得的无余涅槃没有什么区别了。

以上这些说明，其实都是多余的，因为它们所要建立的，不过是过去诸位大德早已证成的道理。然而，像我这样智慧下劣之人，最初是因为见到诸佛的功德才发起菩提心，是因为看到诸乘之间的差别，才对佛果生起向往。简言之，他们或许会误以为，只要具备平常的慈悲心态，便足以称得上是大乘的菩提心；他们或许相信，在道上一旦证悟了空性，便完全没有必要再修学布施等其他诸度；他们或许误解了"修道即是对见道所见之境加以串习"这一说法的含义，从而以为，只要在证得见道之后不断串习无分别智，便足以成就觉悟，而不知正是菩萨的菩提心与行持，才是大乘有别于小乘的关键所在，反而以为唯有空性见才是二者的分野；他们或许认为，只要文字中出现了看似甚深的关于见地与禅修的语言，而丝毫不提及利他的意乐与实修，这样的说法就已经属于大乘了；他们或许把甚深见与广大行这两种毫无瑕疵的传承，看作是水火不容、彼此对立的；又或者，他们或许固执一端地执著于佛陀中转法轮或末转法轮的教法之一，认为单凭其中之一便已足够。我之所以不厌其烦、反复强调这一要点，甚至甘冒重复啰嗦之嫌，正是希望能够利益任何怀有这类偏执之见的人，对此我坦诚相告。

此外，我也想对未来世中，那些希望能在大乘经论所示之道上无谬修学的有福缘之人，说几句话。这样的人，即便仍处于凡夫地，也应当依止诸如《入菩萨行论》以及《菩提道次第》等论典中所讲授的入门修心法门，藉此矫正自己的品性，使之从僵硬顽固，转变为如皮革般柔软驯顺，如箭一般笔直端正。然后，还应当依止诸如至尊怙主龙树阿阇黎所造的《中观根本慧论》等论典，遣除对甚深见地所生起的一切执著于边执的分别妄想，乃至断除对实有的丝毫执著概念，对超越分别构造的见地生起确定的了悟。仅仅做到这一点还不够，还应当进一步深入探究末转法轮的甚深教法，以及佛陀补处及其随学者们毫无瑕疵的经教传承，使自心趋向于普贤菩萨那无上的行持。不应像急于把湿皮子直接放到火上烘烤那样，急躁地想着"就在这一生"就要成办一切；而应当以菩萨那不可思议、犹如大海般浩瀚的事业为依归。他们所行之事，是依据"不可思议解脱"这一法门而行的，其广大程度，正如虚空与有情界一般无边无际。正如经中所说：

```
愿我菩萨之行广大无边，
愿我觉悟之功德亦无有限量，
安住于此无量之行持中，
愿我成办觉悟之一切神变力！
```

【译注：出自《普贤行愿品》。】

如此这般，他们便能够对胜者及其心子这毫无瑕疵的传承——以这甚深广大、诸佛之母的伟大通途为其架构——生起兴趣与向往。这该是多么美好的事啊！

```
大乘之道，甚深而又广大，
其要点在于，将甚深与广大无碍地融为一体，
凡是证悟这甚深广大之道的人，
必将得到这诸佛之母的摄受护念。
```

依此殊胜的思维与加行而修行所得之果，便是法身连同其事业——这一点从本论自身即可加以了知。

总而言之，无论胜者的心子最初以何种意乐立誓，那便是他所追求的究竟果位。因此，菩萨之道的主要目标，便是那广大、恒常、周遍、任运自成的利生事业，直至轮回空尽为止。这一事业之所依，正是法身；而这法身，又具有断与证两个方面。其中，作为成办利生事业之主要主宰条件的，是证悟的智慧法身。正如本论正文的陈述部分所说：

```
法身连同其事业……
```

【译注：出自《现观庄严论》第八品开首。】

而在诸现观的总摄偈中也说：

```
果——法身与事业……
```

【译注：出自《现观庄严论》相关总摄偈颂。】

遍知一切智慧的现前彰显，固然是已经连同习气一并断除二障的标志。然而，也有人主张，即便在小乘之中，声闻、缘觉透过断除，也能证得无余的阿罗汉果，从而不再具有作为二障之基础的东西。若是如此，那么就无法单纯依据"断"这一方面，来区分大小乘的果位，而只能依据是否证悟法身、是否具足事业来加以区分。有鉴于此，并且由于最初的发心是通过发菩提心而无误地加以指认的，所以前面才说，大乘之道所追求的，并不是断除二障之后的佛果。然而，这并不与"这正是应当在他人心中成办的究竟目标或果位"这一事实相矛盾。虽然佛果与遍知智慧有时会被分别提及，但究竟而言，二者是无二无别的。

在以基、道、果的方式，阐述八种现观之时，依据是否涉及因，有两种不同的解释方式，正如诸现观总摄偈所说：

```
所缘、三重之因。
```

【译注：出自《现观庄严论》相关总摄偈颂。】

然而实际上，这二者是完全相同的。作为基，三智是通过闻思无误抉择而了知的；然后，通过修习四种加行，在道上加以修持；作为果，则是现前证得法身。

此外，正如我在这里所阐述的那样，也存在依"思维"与"加行"这两方面来解说的方式。在这里，每一方面也都可以分别具有其自身基、道、果三个层面。

首先，在通过道智训练利他行持、以彰显遍智之果位之前，必须先证悟作为基础的蕴、界、处等一切诸法，如何远离三十二种概念性的分别构造。

其次，在了知了三智所摄的一切诸法——即作为基础的部分——皆具三种无生的体性之后，通过一切相加行修习空性。在此基础上，作为在自身相续中所生起的道，通过渐次修法，令一切证悟的智慧得以稳固。由此，证得暂时的果位——顶加行与刹那加行，并现前究竟的果位——法身连同其事业。此后，直至轮回空尽之前，将持续展开广大、不间断、无功用、任运自成的利生事业。

```
我依止诸位智者而撰写此论，
他们毫无瑕疵地持守着圣者的见解，
是对诸佛之母这难以测度的密意
最为无与伦比的注释者。

此中略有若干之处，未见于其余诸释论，
仅仅在众多智者的善说之中隐约提及，
我亦已用心加以核对，
使其与至尊弥勒的其余论著相符无违。

甚深大乘之法，乃是一件大有力量之事，
经中说，凡是自行创设法义、别出心裁标新立异之人，
必有众多过失；
若此论亦犯此过，我谨在此诚心忏悔、致以歉意。

然而，正因我对这殊胜甚深乘之道
怀有真诚的信心，又因为我曾研习过
其中众多经论及释论，
我确信，就其究竟意趣而言，本论并无自相矛盾之处。

愿以撰写此论所生之无边功德，
令地狱、饿鬼、畜生、阿修罗
永远从其恶业习性之中解脱出来，
往生于至尊怙主弥勒佛陀座前！
```

我深知，圣者解脱军尊者（Ārya Vimuktasena）关于《般若庄严论》密意的无与伦比的释论，曾如日月一般，举世无双，名扬阎浮提。若能依照宗喀巴大师对其见地的种种解说，撰写一篇简明扼要的概说，必定能对我最亲近的几位法友有所直接助益，或许对至尊怙主也同样合适。因此，我——这老狗阿布——便在纳琼（"小林"）静修处闭关期间，利用座间的空隙，写下了这篇文字。愿此善妙吉祥！善哉！
