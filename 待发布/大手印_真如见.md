# 真如见

阿阇黎达日卡巴 造

## 题解

本篇出自德格版丹珠尔续部（རྒྱུད་འགྲེལ།）ཟི 函第49b叶第4行至第50a叶第1行，东北目录编号 D2438。全篇二十八句，每句七个音节，以“唉看这棵树多么稀奇，没有种子苗芽却结出无量果实”为叠句。篇幅很短，所以把藏文原文全部保留在代码块中，按段落分开，每段后附汉译，疑难之处另以【按】说明。

梵文题名：Tathatā-dṛṣṭi-nāma（ཏ་ཐཱ་ཏཱ་དྲྀཥྚི་ནཱ་མ）。

藏文题名：དེ་བཞིན་ཉིད་ཀྱི་ལྟ་བ（真如之见）。

【按】作者达日卡巴（དཱ་རི་ཀ་པ，Dārikapa），即前面所译《迦波离悲行之见》跋语中的传承上师，大概就是八十四大成就者中舍弃王位、侍奉空行母而得成就的那一位。正文第22句自称“达日巴”（དྷ་རི་པ）。跋语没有记载译者。

【按】前面所译因札菩提的《八真如之见》，题名中的“真如”是“དེ་ཉིད”（真实性），本篇的“真如”是“དེ་བཞིན་ཉིད”（如如、真如），藏文原词不同，作者也不同，是两部不同的作品。

## 正文

### 第一段：真如之树

```
དེ་བཞིན་ཉིད་ཀྱི་ཤིང་དྲུང་ལ། །རྩ་བ་ཡལ་ག་དམིགས་པ་མེད། །མེ་ཏོག་འབྲས་བུ་རྟག་ཏུ་འབྱིན། །
ཀྱེ་མ་ཤིང་འདི་ངོ་མཚར་ལྟོས། །ས་བོན་མྱུ་གུ་མེད་པ་ཡི། །འབྲས་བུ་དཔག་ཏུ་མེད་པ་འབྱུང་། །
```

在真如之树下，根与枝都不可得，却常常开花结果。唉！看哪，这棵树多么稀奇！没有种子，也没有苗芽，却结出无量无边的果实。

【按】本篇通篇以“真如之树”为喻：树比喻真如（心性），根、枝不可得，比喻真如无相、无可执取；常开花结果，比喻真如中自然显现种种功德与事业；没有种子、苗芽而结出无量果实，比喻真如不从因缘生，而功德无尽。以下的配释，都是依这一譬喻推定的。

【按】“དམིགས་པ་མེད”，“不可得”“无所缘”，意思是根与枝都找不到、不能作为执取的对象。

### 第二段：如拳击虚空，树不可断

```
དེ་ཡི་རང་བཞིན་ཇི་ལྟ་བུ། །ནམ་མཁའ་ཆད་པར་བཅུག་ནས་ནི། །ཁུ་ཚུར་དག་གིས་གཅོག་པ་བཞིན། །
ཤིང་དེ་གཅོག་པ་དེ་དང་འདྲ། །
```

它的自性是怎样的呢？就像要把虚空割断、用拳头去砸碎一样，砍伐那棵树也正是如此。

【按】“ནམ་མཁའ་ཆད་པར་བཅུག་ནས། ཁུ་ཚུར་གྱིས་གཅོག་པ”，“割断虚空、以拳击碎”，比喻做不到的事：虚空无法割断、无法击碎；同样，真如之树也不能被砍伐、不能被毁坏。这一句的语法比较简略，这里依文意译出。

### 第三段：树遍虚空

```
རྩ་བ་དག་ཀྱང་ཡོད་འགྱུར་ལ། །ཡལ་ག་དག་ཀྱང་ཡོད་པ་ཡི། །ཤིང་གིས་ནམ་མཁའ་ཁྱབ་པར་སྣང་། །
ཀྱེ་མ་ལྟོས་དང་ཤིང་འདི་ལ། །ནམ་མཁའ་ཁྱབ་པ་ངོ་མཚར་ཆེ། །ཀྱེ་མ་ཤིང་འདི་ངོ་མཚར་ལྟོས། །
ས་བོན་མྱུ་གུ་མེད་པ་ཡི། །འབྲས་བུ་དཔག་ཏུ་མེད་པ་འབྱུང་། །
```

（看起来）既有根，也有枝，这棵树显现为遍满虚空。唉！看哪，这棵树遍满了虚空，真是稀奇！唉！看哪，这棵树多么稀奇！没有种子，也没有苗芽，却结出无量无边的果实。

【按】这几句与第一段“根与枝都不可得”看似矛盾，其实是说：真如本身无相不可得，却显现为有根有枝、遍满虚空的样子，也就是空而不碍显现、显现而本来是空。这是推解。

### 第四段：精进勿懈，勿半途而废

```
དེ་བཞིན་ཉིད་ཀྱི་ཤིང་འདི་ཡི། །མཚན་ཉིད་ཁྱོད་ཀྱིས་རྟོགས་པ་མེད། །བདག་གིས་བསྟན་པར་རྟོགས་པར་འགྱུར། །
དྷ་རི་པ་ནི་སྨྲ་བར་བྱེད། །འདི་ལ་ལེ་ལོ་བྱས་པ་ཡིས། །མཐའ་རུ་ཕྱིན་པར་མ་གྱུར་པས། །
བར་དུ་ཕུང་བར་མ་བྱེད་ཅིག། །ཀྱེ་མ་ཤིང་འདི་ངོ་མཚར་ལྟོས། །ས་བོན་མྱུ་གུ་མེད་པ་ཡི། །
འབྲས་བུ་དཔག་ཏུ་མེད་པ་འབྱུང་། །
```

这真如之树的性相，你自己是不能了悟的，经我开示，就能了悟。达日巴这样说：对此如果懈怠，就不能到达究竟，不要在半途中毁了自己啊！唉！看哪，这棵树多么稀奇！没有种子，也没有苗芽，却结出无量无边的果实。

【按】“མཚན་ཉིད་ཁྱོད་ཀྱིས་རྟོགས་པ་མེད། བདག་གིས་བསྟན་པར་རྟོགས་པར་འགྱུར”，“你不能了悟，经我开示就能了悟”，表示真如需要依上师的开示才能认识，这与大手印重视上师直指的传统一致。“我”是作者达日巴（达日卡巴）的自称。

【按】“བར་དུ་ཕུང་བར་མ་བྱེད་ཅིག”，“不要在半途中毁了”，劝诫修行人不可懈怠，要坚持到究竟。“自己”二字是译者所补。
