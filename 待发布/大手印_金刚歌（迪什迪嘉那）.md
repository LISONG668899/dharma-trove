# 金刚歌（迪什迪嘉那）

上师至尊迪什迪嘉那说　据藏文译出

## 题解

本篇收于德格版丹珠尔续部释 ཟི 函第 7a 页（东北目录 D2358）。开头没有梵藏题名，只有"敬礼佛陀"；跋语说："证悟无住之义的上师至尊迪什迪嘉那亲口所说，名为金刚歌，圆满。"没有记载译者。

作者"迪什迪嘉那"（དྷིཥྚི་ཛྙཱ་ན），梵名可能是 Dṛṣṭijñāna 或类似的名字，生平不详，今依藏文音译，存疑。跋语称他"证悟无住之义"，与正文反复说"无住自性的蜜蜂"相应。

关于题名：本站已有多篇"金刚歌"，即《大手印金刚歌》（D2287），以及《金刚歌》的那洛巴之一、之二、佚名、黑行者各篇（D2288 至 D2291）。为了区分，本篇依作者名题为《金刚歌（迪什迪嘉那）》。

全篇约十五句，共四段，以"这样的人，心是欢喜的；一切动与不动，都是无垢的珍宝"为叠句，以"无住自性的蜜蜂"为主喻：先劝婆罗门、苦行者、僧人等信解佛智；再劝修持无住的蜜蜂，精勤依止上师口诀；又说这蜜蜂本来不生，如梦中女子；最后说了知它，此生就能成就。全篇没有涉及具体的密法修持。

体例：藏文原文全部保留在代码框中，按段落分节，每节后附汉译；叠句照原文每次重复。凡标"存疑"的按语，表示本译对原文意思没有把握。藏文依 Esukhia 德格丹珠尔电子版。

## 礼敬

```
སངས་རྒྱས་ལ་ཕྱག་འཚལ་ལོ། །
```

敬礼佛陀！

## 一、劝诸人信解佛智

```
ཀྱེ་བྲམ་ཟེ་རལ་ཅན་སྐྱེས་བུ་སང་གྷ་བ། །
སངས་རྒྱས་ཡེ་ཤེས་དག་ལ་མོས་པར་གྱིས། །
དེ་འདྲའི་སྐྱེས་བུའི་སེམས་ནི་དགའ་བ་ཡིན། །
བརྟན་གཡོ་ཐམས་ཅད་དྲི་མེད་རིན་པོ་ཆེ། །
```

嗟！婆罗门、结发的苦行者、僧伽巴等诸人啊，要对佛的智慧生起信解！这样的人，心是欢喜的；一切动与不动，都是无垢的珍宝。

【按】"这样的人，心是欢喜的；一切动与不动，都是无垢的珍宝"，是全篇的叠句。"动与不动"指有情与器世间，即一切显现；说它们都是"无垢的珍宝"，是说在证悟者眼中，一切显现本来清净。

【按】存疑。"སང་གྷ་བ"，可能指僧人（僧伽中人），也可能是某一人名或某类修行者的称呼，今音译为"僧伽巴"。

## 二、无住的蜜蜂，依上师口诀

```
མི་གནས་རང་བཞིན་བུང་བ་ཁྱོད་ནི་བསྒོམ། །
ཡང་དག་བླ་མའི་མན་ངག་ནན་ཏན་གྱིས། །
དེ་འདྲའི་སྐྱེས་བུའི་སེམས་ནི་དགའ་བ་ཡིན། །
བརྟན་གཡོ་ཐམས་ཅད་དྲི་མེད་རིན་པོ་ཆེ། །
```

无住自性的蜜蜂啊，你要修持；要精勤依止真实上师的口诀。这样的人，心是欢喜的；一切动与不动，都是无垢的珍宝。

【按】"蜜蜂"是全篇的主喻：蜜蜂在花间采蜜，不停留在任何一朵花上，比喻心性无所住、于一切显现中受用而不执著。帝洛巴、萨惹哈的道歌中也常用这个譬喻。

## 三、如梦中女，本来不生

```
མི་གནས་རང་བཞིན་བུང་བ་མ་སྐྱེས་པ། །
རྨི་ལམ་བུད་མེད་དེ་བཞིན་མེད་པ་སྟེ། །
དེ་འདྲའི་སྐྱེས་བུའི་སེམས་ནི་དགའ་བ་ཡིན། །
བརྟན་གཡོ་ཐམས་ཅད་དྲི་མེད་རིན་པོ་ཆེ། །
```

无住自性的蜜蜂，是不生的；就像梦中的女子，本来就不存在。这样的人，心是欢喜的；一切动与不动，都是无垢的珍宝。

【按】"梦中的女子"，比喻显现虽然宛然，却没有实体；心性如蜜蜂般受用一切，它自己也是不生的。

## 四、知此即生成就

```
མི་གནས་རང་བཞིན་བུང་བ་དེ་ཤེས་ན། །
ཚེ་འདི་ཉིད་ལ་སངས་རྒྱས་དངོས་གྲུབ་འགྲུབ། །
དེ་འདྲའི་སྐྱེས་བུའི་སེམས་ནི་དགའ་བ་ཡིན། །
བརྟན་གཡོ་ཐམས་ཅད་དྲི་མེད་རིན་པོ་ཆེ། །
```

如果了知了那无住自性的蜜蜂，在这一生中就能成就佛果的悉地。这样的人，心是欢喜的；一切动与不动，都是无垢的珍宝。

【按】"在这一生中就能成就"，是大手印与密乘常说的"即生成佛"，前提是真正了知无住的心性，并依止上师的口诀（第二节）。

## 跋语

```
མི་གནས་པའི་དོན་ཐུགས་སུ་ཆུད་པ་བླ་མ་རྗེ་བཙུན་དྷིཥྚི་ཛྙཱ་ནའི་ཞལ་སྔ་ནས་རྡོ་རྗེའི་གླུ་ཞེས་བྱ་བ་རྫོགས་སོ། །
```

证悟无住之义的上师至尊迪什迪嘉那亲口所说，名为金刚歌，圆满。
