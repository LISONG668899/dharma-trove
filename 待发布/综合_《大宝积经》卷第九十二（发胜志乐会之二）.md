# 《大宝积经》卷第九十二（发胜志乐会之二）

唐·三藏法师菩提流志 奉诏译

## 发胜志乐会第二十五之二

【按】译者题名“大”字，明本无。

#### 初业菩萨增长慧力所应舍、所应修

那时弥勒菩萨摩诃萨对佛说：“世尊！初业菩萨出家之后，未得慧力而想得到，应当舍弃什么法、修习什么法，才能令未生的慧力生起，已生的慧力增长？”佛告诉弥勒菩萨说：“弥勒！初业菩萨出家之后，想令慧力增长，应当了知利养的过失，必须舍离。若喜好喧闹、世俗闲谈，耽著睡眠，广营众务，乐于种种戏论，这样的过失都应当远离。所以应当舍弃利养，修习少欲；舍弃种种喧闹，乐于寂静；舍弃种种世间闲谈，观察真实之义。初夜、后夜远离睡眠，观察思惟，随所行而修习。舍弃众务以及种种戏论，修习出世之道，慈念众生。弥勒！初业菩萨出家之后，未得慧力而想得到，这些法应当舍弃，这些法应当修习。

“为什么呢？弥勒！那些菩萨出家之后，未得慧力而想得到，若不舍弃利养、不修少欲，而能令未生的慧力生起、已生的慧力增长，是不可能的。不舍弃喧闹、不住于寂静，而能令未生的慧力生起、已生的慧力增长，也是不可能的。不舍弃世间闲谈、不观察真实之义，而能令未生的慧力生起、已生的慧力增长，是不可能的。初夜、后夜耽著睡眠，从不觉醒、系念思惟，不舍众务，喜好种种戏论，对出世之道不能修行，对众生不生慈念，而能令未生的慧力生起、已生的慧力增长，也是不可能的。弥勒！所以菩萨未得慧力而想得到，对应当舍弃的诸法必须舍离，对应当修习的诸法必须修习。为什么呢？菩萨的智慧从因缘而生，若没有因缘终不能生，因缘和合才得生起。”

#### 利养之过

那时弥勒菩萨对佛说：“世尊！什么名为利养中的过失？若观察这些，能令菩萨乐于少欲，不生热恼。”佛说：“弥勒！初业菩萨应当观察：利养能生贪欲；应当观察：利养能坏失正念，生起瞋恚；应当观察：利养令人念其得失，生起愚痴；应当观察：利养能生高下与嫉妒之心；应当观察：利养令人对亲友之家悭吝耽著，生起诳惑；应当观察：利养令人成就对滋味的贪爱，生起谄曲；应当观察：利养令人舍弃四圣种，没有惭愧；应当观察：利养为一切诸佛所不许可，令人数数习于憍逸，生起高慢；应当观察：利养令人对殊胜福田生起轻慢，成为魔党；应当观察：利养是众恶的根本，令诸善坏灭；应当观察：利养令人多所贪著，犹如霜雹；应当观察：利养令人在亲友之家察言观色，生起忧恼；应当观察：利养令人在所爱之物损坏时，忧心散乱；应当观察：利养令人对四念处多所忘失，白法羸弱；应当观察：利养令人对四正勤多有退失，能令一切他论胜过自己；应当观察：利养令人自称已得神通智慧，生起违背；应当观察：利养先得后失，生起怨憎；应当观察：利养令人互相瞋嫌，说其过恶，多起觉观；应当观察：利养令人为了活命营办种种世间事业，计度思惟，安乐减损；应当观察：利养乃至令禅定、解脱、三昧、三摩钵底之心如淫女一般，能令其退失；应当观察：利养令人舍离智慧与断除，堕于地狱、饿鬼、畜生、阎摩罗界诸恶道；应当观察：利养令人与提婆达多、乌陀洛迦同住于一法，堕入恶道。

【按】“先得后失”，明本作“先后得失”。“心如婬女”之“婬”，元本作“媱”。“乌陀洛迦”，即郁陀迦罗摩子。

“弥勒！初业菩萨这样观察利养的过失，便乐于少欲，不生热恼。为什么呢？弥勒！少欲的菩萨，一切过失都不生起，堪为诸佛清净的法器。他不系属于在家人或出家人，住于真实最胜的意乐，不卑下也不惊怖，因为远离了诸恶道堕落的怖畏；无人能映蔽他，因为舍弃了耽著滋味；从众魔境界中得到解脱；为一切诸佛所称赞，诸天以及人也都爱慕。对种种禅定不染著，因为住于边际。他的心质直，没有谄曲，对五欲也不放逸，因为见到五欲的过患。如所说而修行，能住于圣种，同修梵行的人也都爱乐他。弥勒！若有菩萨智慧聪敏，对这些功德能这样了知，便以殊胜的意乐舍弃利养，以殊胜的意乐住于少欲，因为是为了断除贪爱而发起的。”

#### 愦閙之过

那时弥勒菩萨对佛说：“世尊！什么名为喧闹中的过失？若观察这些，菩萨能独处闲静而不生热恼。”佛说：“弥勒！初业菩萨应当观察，喧闹的过失有二十种。若观察这些，能令菩萨独处闲静而不生热恼。弥勒！什么名为乐于喧闹的二十种过失？一是不守护身业，二是不守护语业，三是不守护意业，四是多增贪欲，五是增长愚痴，六是耽著世间闲谈，七是远离出世之语，八是对非法尊重修习，九是舍离正法，十是天魔波旬得其便，十一是对不放逸未曾修习，十二是对放逸之行常怀染著，十三是多起种种觉观，十四是多闻减损，十五是不得禅定，十六是没有智慧，十七是很快就做出非梵行之事，十八是不爱佛，十九是不爱法，二十是不爱僧。弥勒！这是菩萨观察喧闹的二十种过失。”那时世尊重说偈道：

```
舍离诸贪瞋，不住于愦閙，
若有专住彼，是过不应作。
憍慢及觉观，皆由愦閙生，
坏行无戒人，称叹于愦閙。
愚人乐世论，退失第一义，
放逸多觉观，是过不应作。
比丘舍多闻，言论不如理，
损减诸禅定，常思惟世间。
耽著思惟者，何得于寂静？
其心常散逸，永离于正观。
速得非梵行，諠杂无仪捡，
亦不曾爱佛，及爱于圣众，
弃舍离欲法，耽著非法言。
```
（大意：应当舍离种种贪瞋，不住于喧闹；若有人专住于喧闹，这过失不应作。憍慢以及觉观，都由喧闹而生；破坏修行、无戒之人，才称叹喧闹。愚人乐于世间言论，退失第一义；放逸而多觉观，这过失不应作。比丘舍弃多闻，言论不如理，减损种种禅定，常思惟世间之事。耽著于思惟世事的人，怎能得到寂静？其心常散逸，永离正观。很快就做出非梵行之事，喧杂而没有仪轨检束，也不曾爱佛以及爱圣众，弃舍离欲之法，耽著非法之言。）

【按】“言论不如理”之“如”，宫本作“知”。

```
我常舍千身，支分及头目，
为求无上道，闻法无厌足；
是诸非法人，少闻便厌舍。
我昔作国王，为求四句偈，
妻子及财宝，悉皆能施与。
何有于智者，而不勤听法？
我甞舍一切，非法之戏论，
为于百千劫，难得解脱故；
汝等应欣乐，志求微妙法。
若乐于解脱，最胜功德者，
世间诸事业，皆所不应问。
衣食无胜利，亦不证涅槃，
当称叹最胜，善来诸比丘，
应敷座令坐，互说诸法要。
```
（大意：我曾舍弃千身，以及肢体与头目，为了求无上道，闻法无厌足；这些非法之人，少闻便厌而舍弃。我往昔作国王，为了求四句偈，妻子以及财宝，都能施与。哪有智者而不勤加听法？我曾舍弃一切非法的戏论，是因为百千劫中解脱难得；你们应当欣乐，志求微妙之法。若乐于解脱这最胜功德的人，世间的种种事业都不应问。衣食没有殊胜的利益，也不能证涅槃；应当称叹最胜之法，对来到的比丘说“善来”，应当敷座请他坐，互相宣说诸法要义。）

【按】“我常舍千身”之“常”，宫本作“甞”；“我甞舍一切”之“甞”，元、明本作“常”。

```
人身甚难得，随分行白法，
读诵及禅定，汝应如是问。
如来入涅槃，遗法当灭坏，
比丘多放逸，乐众弃闲静，
为饮食利养，昼夜谈世话。
愚人于梦中，惊怖而漂溺，
自知多毁犯，当堕三恶道。
应生欢喜心，独处于闲寂，
若在阿兰若，志求无上道。
不应见人过，自谓最尊胜，
憍恣放逸本，莫轻下劣人，
彼于遗法中，渐次而解脱。
```
（大意：人身甚为难得，应随分修行白净之法，读诵以及禅定，你们应当这样互相问询。如来入于涅槃之后，遗法将要灭坏，比丘多放逸，乐于聚众而弃舍闲静，为了饮食利养，昼夜谈说世间之事。愚人在梦中惊怖而漂溺，自知多所毁犯，将堕三恶道。应当生起欢喜之心，独处于闲寂；若在阿兰若，志求无上道。不应见他人过失，自以为最尊胜；憍恣是放逸的根本，不要轻视下劣之人，他们在遗法之中，也会渐次得到解脱。）

```
比丘虽破戒，深信于三宝，
是则解脱因，不应见其过。
摧伏贪瞋难，勿惊于放逸，
余习法应尔，是故不须说。
若清净比丘，伺他人过失，
是最非真实，不名修正法。
如理修行者，当须自观察，
求道诸比丘，舍离恶言论，
常以欢喜心，独处于闲静。
```
（大意：比丘虽然破戒，若深信三宝，这便是解脱之因，不应见他的过失。摧伏贪瞋本是难事，对他人的放逸不要惊异，余习之法本来如此，所以不须宣说其过。若清净的比丘伺察他人的过失，这最为不真实，不名为修习正法。如理修行的人，应当自己观察；求道的比丘们，应当舍离恶的言论，常以欢喜之心独处于闲静。）

那时弥勒菩萨又对佛说：“希有，世尊！耽著喧闹竟有这样无量的过恶，退失功德，没有利益，增长烦恼，堕入诸恶趣，远离白净之法。哪有求善法的菩萨，听了这些过失，还不乐于独处闲静的？”

【按】“独处闲静”之“静”，明本作“寂”。

#### 世话之过

那时弥勒菩萨对佛说：“世尊！什么名为世间闲谈中的过失？若观察这些，菩萨应当住于决定之义，由于观察这义而不生热恼。”佛说：“弥勒！初业菩萨应当观察，世间闲谈的过失有二十种。若观察这些，能令菩萨住于决定之义，由于观察这义而不生热恼。弥勒！什么名为乐于世间闲谈的二十种过失？一是心生憍恣，不敬多闻；二是对种种诤论多起执著；三是失去正念与如理作意；四是作不应作之事，身多躁动；五是很快起伏高下，坏失法忍；六是心常刚强，禅定智慧从不熏修；七是非时而语，被言论所缠；八是不能坚固地证得圣智；九是不被天龙所恭敬；十是常被有辩才的人所轻贱；十一是被身证者所呵责；十二是不住于正信，常怀悔恨；十三是心多疑惑，摇动不安；十四是犹如倡伎追随音声；十五是染著诸欲，随境流转；十六是不观真实，诽谤正法；十七是有所希求，常不能如愿；十八是其心不调，被人弃舍；十九是不知法界，随顺恶友；二十是不了知诸根，被烦恼所系属。弥勒！这是菩萨乐于世间闲谈的二十种过失。”那时世尊重说偈道：

【按】“倡伎”之“伎”，元、明本作“妓”。

```
憍傲于多闻，执著诸诤论，
失念不正知，是名世话过。
远离正思惟，身心不寂静，
退失于法忍，是名世话过。
其心不调顺，远离奢摩他，
及毘钵舍那，是名世话过。
不尊敬师长，爱乐于世论，
智慧不坚固，是名世话过。
诸天不恭敬，龙神亦复然，
退失于辩才，是名世话过。
圣者常呵责，如是耽著人，
唐捐于寿命，是名世话过。
```
（大意：对多闻者憍傲，执著于种种诤论，失念而不正知，这名为世间闲谈的过失。远离正思惟，身心不寂静，退失法忍，这名为世间闲谈的过失。其心不调顺，远离奢摩他以及毗钵舍那，这名为世间闲谈的过失。不尊敬师长，爱乐世间言论，智慧不坚固，这名为世间闲谈的过失。诸天不恭敬，龙神也是这样，退失辩才，这名为世间闲谈的过失。圣者常常呵责这样耽著的人，虚度寿命，这名为世间闲谈的过失。）

```
诸行皆缺减，远离大菩提，
命终生忧苦，是名世话过。
疑惑心动摇，犹如风吹草，
智慧不坚固，是名世话过。
譬如倡妓人，赞说他勇健，
彼人亦复然，是名世话过。
随逐世语言，染著诸欲境，
常行于邪道，是名世话过。
希求心不遂，谄曲多诤论，
远离于圣行，是名世话过。
愚人得少利，其心常摇动，
如猿猴躁扰，是名世话过。
智慧多退失，无有觉悟心，
愚者所摄持，是名世话过。
迷惑于眼耳，乃至意亦然，
常与烦恼俱，是名世话过。
```
（大意：诸行都有缺减，远离大菩提，命终时生起忧苦，这名为世间闲谈的过失。疑惑之心动摇，犹如风吹草，智慧不坚固，这名为世间闲谈的过失。譬如倡妓之人，赞说他人的勇健，那人也是这样，这名为世间闲谈的过失。追随世间语言，染著种种欲境，常行于邪道，这名为世间闲谈的过失。希求之心不能如愿，谄曲而多诤论，远离圣行，这名为世间闲谈的过失。愚人得到少许利益，其心常常摇动，如猿猴躁扰，这名为世间闲谈的过失。智慧多有退失，没有觉悟之心，被愚者所摄持，这名为世间闲谈的过失。对眼、耳迷惑，乃至意也是这样，常与烦恼俱在，这名为世间闲谈的过失。）

```
愚人乐世话，尽寿常空过，
不如思一义，获利无有边。
譬如甘蔗味，虽不离皮节，
亦不从皮节，而得于胜味。
皮节如世话，义理犹胜味，
是故舍虚言，思惟于实义。
智慧诸菩萨，能知世话过，
常爱乐思惟，第一义功德。
法味及义味，解脱第一味，
谁有智慧者，心生不欣乐？
是故应弃舍，无利诸言话，
常乐勤思惟，殊胜第一义。
如是第一法，诸佛所赞叹，
是故明智人，当乐勤修习。
```
（大意：愚人乐于世间闲谈，一生常常空过，不如思惟一句义理，获得的利益无边。譬如甘蔗之味，虽然不离开皮节，也不是从皮节中得到殊胜之味。皮节如同世间闲谈，义理犹如殊胜之味，所以应舍弃虚言，思惟真实之义。有智慧的诸菩萨，能知世间闲谈的过失，常爱乐思惟第一义的功德。法味以及义味，解脱是第一之味，哪个有智慧的人心中不欣乐？所以应当弃舍没有利益的言谈，常乐于勤加思惟殊胜的第一义。这样的第一法，为诸佛所赞叹，所以明智之人应当乐于勤加修习。）

【按】“心生不欣乐”之“生不”，元、明、宫本作“不生”。

那时弥勒菩萨又对佛说：“希有，世尊！竟能善说世间闲谈的过失，以及思惟胜义的利益功德。世尊！哪有求如来真实智慧的菩萨，还乐于虚诳的世间闲谈？”

#### 睡眠之过

那时弥勒菩萨对佛说：“世尊！什么名为睡眠中的过失？若观察这些，菩萨应当发起精进，不生热恼。”佛说：“弥勒！初业菩萨应当观察，睡眠的过失有二十种。若观察这些，能令菩萨发起精进，意乐无倦。弥勒！什么名为乐于睡眠的二十种过失？一是懈怠懒惰，二是身体沉重，三是颜色憔悴，四是增加种种疾病，五是火界羸弱，六是饮食不消化，七是身上生疮疱，八是不勤修习，九是增长愚痴，十是智慧羸劣，十一是皮肤暗浊，十二是非人不敬，十三是所行愚钝，十四是被烦恼缠缚，十五是随眠覆心，十六是不乐善法，十七是白净之法减损，十八是行下劣之行，十九是憎嫌精进，二十是被人轻贱。弥勒！这是菩萨乐于睡眠的二十种过失。”那时世尊重说偈道：

【按】“懈怠嬾惰”之“嬾”，宫本作“懒”。

```
身重无仪捡，懈怠少堪任，
颜色无光泽，是乐睡眠过。

```
（大意：身体沉重，没有仪轨检束，懈怠而少有堪任，颜色没有光泽，这是乐于睡眠的过失。那人常受疾病苦恼，风、黄病多所积集，四大互相违逆，这是乐于睡眠的过失。饮食不消化，身体没有光润，声音嘶哑不清澈，这是乐于睡眠的过失。其身生疮疱，昼夜常昏睡，种种虫生于关节之中，这是乐于睡眠的过失。退失精进，缺乏种种财宝，多梦而不觉悟，这是乐于睡眠的过失。愚痴之网常常增长，乐著于种种见，炽盛而难以疗治，这是乐于睡眠的过失。减损种种智慧，增长愚痴，志意常常下劣，这是乐于睡眠的过失。他住在阿兰若，常怀懈怠之心，非人得其便，这是乐于睡眠的过失。昏昧而失去正念，讽诵不通利，说法多有废忘，这是乐于睡眠的过失。）

#### 众务之过

那时弥勒菩萨对佛说：“世尊！什么名为众务中的过失？若观察这些，能令诸菩萨不营办众务，勤修佛道。”佛说：“弥勒！初业菩萨应当观察乐于营办众务的二十种过失。若观察这些，能令菩萨不营办众务，勤修佛道。弥勒！什么名为二十种过失？一是耽著世间下劣之业，二是被读诵修行的比丘所轻贱，三是也被勤修禅定的比丘所呵责，四是心中常发起无始以来生死流转之业，五是白白受用居士以及婆罗门净心的信施，六是对种种财物心怀执取，七是常乐于广营世间事务，八是挂念家业，常怀忧叹，九是性情狠戾，发言粗犷，十是心中常忆念勤修家业，十一是爱著种种滋味，增长贪欲，十二是在没有利养之处不生欢喜，十三是多生恼害障碍之业，十四是常乐于亲近优婆塞以及优婆夷，十五是只念衣食而度过昼夜，十六是数数询问世间所作的事业，十七是常乐于发起非法的言语，十八是依恃营办众务而生憍慢，十九是只求他人过失而不自我观察，二十是对说法者心怀轻贱。弥勒！这是菩萨乐于营办众务的二十种过失。”那时世尊重说偈道：

【按】“一者”之“者”，《大正藏》作“我”，今依CBETA（所录高丽藏）作“者”，宫本同。“其性佷戾”之“佷”，元、明本作“狠”。“但求人过”之“但”，宫本作“每”。

```
安住下劣业，远离殊胜行，
退失大利益，是名众务过。
乐读诵比丘，及修禅定者，
一切皆呵责，是名众务过。
常行生死业，舍离解脱因，
虚受于信施，是名众务过。
乐受诸财宝，不得生忧恼，
住于下劣行，是名众务过。
是人多爱染，往来婬女家，
如鸟入樊笼，是名众务过。
常忧叹家业，恒怀热恼心，
出言人不信，是名众务过。
不受尊者教，违拒而轻贱，
毁犯清净戒，是名众务过。
其心多忆想，勤营于世业，
不能修智断，是名众务过。
贪心恒炽盛，乐著于诸味，
曾无知足心，是名众务过。
得利生欢喜，无利便忧恼，
贪悋无仁心，是名众务过。
```
（大意：安住于下劣之业，远离殊胜之行，退失大利益，这名为众务的过失。乐于读诵的比丘以及修禅定的人，都呵责他，这名为众务的过失。常行生死之业，舍离解脱之因，白白接受信施，这名为众务的过失。乐于接受种种财宝，得不到便生忧恼，住于下劣之行，这名为众务的过失。这人多有爱染，往来于淫女之家，如鸟进入樊笼，这名为众务的过失。常忧叹家业，恒怀热恼之心，所说的话人不相信，这名为众务的过失。不接受尊者的教导，违拒而轻贱，毁犯清净之戒，这名为众务的过失。其心多忆想，勤于营办世间事业，不能修习智慧与断除，这名为众务的过失。贪心恒常炽盛，乐著于种种滋味，从无知足之心，这名为众务的过失。得利便生欢喜，无利便生忧恼，贪吝而没有仁心，这名为众务的过失。）

【按】“樊笼”之“笼”，《大正藏》作“龙”，今依CBETA（所录高丽藏）作“笼”，宫本同。“违拒”之“拒”，元本作“矩”。

```
恼害无慈愍，增长诸恶业，
爱蔓相缠缚，是名众务过。
远离于师长，亲近恶知识，
摈斥持戒人，是名众务过。
昼夜无余想，唯念求衣食，
不乐诸功德，是名众务过。
常问世间智，不乐出世言，
耽爱于邪说，是名众务过。
自恃知众务，轻慢诸比丘，
犹如狂醉人，是名众务过。

轻毁有德人，是名众务过。
如是愚痴者，无有善方便，
轻慢说法者，是名众务过。
如是下劣业，具足诸过失，
何有智慧人，爱乐而修习？
清净殊胜业，具足诸功德，
是故有智人，爱乐常修习。
若乐下劣业，智者当呵责，
如人舍多财，贪求于少分。
是故明智人，当舍下劣业，
应求胜上法，诸佛常称叹。
```
（大意：恼害他人而没有慈愍，增长种种恶业，被爱欲的藤蔓互相缠缚，这名为众务的过失。远离师长，亲近恶知识，摈斥持戒之人，这名为众务的过失。昼夜没有别的念想，只念求取衣食，不乐于种种功德，这名为众务的过失。常问世间的智巧，不乐于出世之言，耽爱于邪说，这名为众务的过失。自恃懂得众务，轻慢比丘们，犹如狂醉之人，这名为众务的过失。常伺求他人的短处，不见自己的过失，轻毁有德之人，这名为众务的过失。这样的愚痴之人，没有善巧方便，轻慢说法的人，这名为众务的过失。这样的下劣之业，具足种种过失，哪有智慧之人会爱乐而修习？清净殊胜之业，具足种种功德，所以有智之人爱乐而常修习。若乐于下劣之业，智者应当呵责，如人舍弃大量财富，却贪求少许。所以明智之人，应当舍弃下劣之业，应当求殊胜上妙之法，为诸佛所常称叹。）

那时弥勒菩萨对佛说：“希有，世尊！那些菩萨舍离殊胜的精进之业，而发起下劣之事，应当知道这人甚为少智，觉慧微浅。”

佛告诉弥勒菩萨说：“弥勒！我现在以实言告诉你，若有菩萨不修诸行，不断烦恼，不习禅定与读诵，不求多闻，我说这人不是出家者。弥勒！若有人勤修智慧与断除之行，智慧得以出生，智慧得以成就，不作世间事业、不营办众务，我说这人住于如来的教导。若有菩萨乐作世间事业、营办众务，作不应作之事，我说这人住于生死，所以菩萨不应亲近他。弥勒！若有菩萨多营众务，造七宝塔遍满三千大千世界，这样的菩萨不能令我生欢喜，也不是供养恭敬我。弥勒！若有菩萨对与波罗蜜相应之法，乃至受持一首四句偈，读诵、修行、为人演说，这人才是供养我。为什么呢？诸佛的菩提从多闻而生，不是从众务而得生起。

“弥勒！若有菩萨勤营众务，令那些读诵、修行、演说的菩萨等也去营办众务，应当知道这人增长业障，没有种种福利。为什么呢？这样所说的三种福业，一切都从智慧而生。所以弥勒！营事的菩萨对那些读诵、修行、演说的菩萨，不应障碍，为他们制造留难；读诵、修行、演说的菩萨对修禅定的菩萨，不应障碍，为他们制造留难。弥勒！若满一阎浮提的营事菩萨，对一位读诵、修行、演说的菩萨，应当亲近供养承事。若满一阎浮提的读诵、修行、演说的菩萨等，对一位勤修禅定的菩萨，也应当亲近供养承事。这样的善业，如来随喜，如来悦可。若对勤修智慧的菩萨承事供养，当获无量的福德之聚。为什么呢？智慧之业无上最胜，超过一切三界之所行。所以弥勒！若有菩萨发起精进，应当在智慧中勤加修习。”

【按】“勤修智慧”之“智”，宫本作“习”。

#### 戏论之过

那时弥勒菩萨对佛说：“世尊！如来善说初业菩萨乐于喧闹、世间闲谈、睡眠、众务的过失。世尊！什么名为戏论中的过失？若观察这些，菩萨当得住于寂静，没有种种诤论。”佛说：“弥勒！初业菩萨戏论的过失无量无边，我现在略说有二十种。什么名为二十种过失？一是在现在生中多有种种苦恼，二是增长瞋恚，退失忍辱，三是被种种怨敌所恼害，四是魔以及魔民都生欢喜，五是未生的善根都不能生起，六是已生的善根能令其退失，七是增长种种斗诤怨竞之心，八是造作地狱恶趣之业，九是当得丑陋不善之果，十是舌头不柔软，言词结巴滞涩，十一是所受的教法不能忆持，十二是对未曾听闻的经，听了也不能领悟，十三是诸善知识都舍离他，十四是很快会值遇诸恶知识，十五是修行于道难得出离，十六是常常听到不悦意的话，十七是在在处处所生多有种种疑惑，十八是常生于难处，不闻正法，十九是修行白净之法多有障碍，二十是对所受用之物多有怨嫉。弥勒！这是菩萨耽著戏论的二十种过失。”那时世尊重说偈道：

（大意：这样种种过失，都因戏论而生，所以有智之人应当迅速远离。这样戏论的人难证大菩提，所以有智之人也不应亲近他们。戏论诤论之处，多起种种烦恼，智者应当远离，远去百由旬之外。也不要在那附近建造房舍，所以出家之人不应住于诤论。你们没有田宅、妻子以及僮仆，乃至荣华地位等，因为什么缘故兴起诤论？出家住于寂静，身披法服，诸仙都敬事你们，应当修习忍辱之心。这样戏论的人增长毒害之心，当堕于恶趣，所以应当修习忍辱。囚禁以及系缚，刑罚加害而捶打，这样等种种苦，都由诤论而生。这样戏论的人常遇恶知识，名称不增长，从无欢喜之心。若舍弃诤论，无人能伺其便，眷属不乖离，当遇到善友。在所修之乘中得清净，业障尽灭无余，摧伏魔军，勤修忍辱之行。诤论多有种种过失，无诤具足功德，若有修行的人，应当住于忍辱。）

#### 末世菩萨疑谤此经

那时弥勒菩萨又对佛说：“希有，世尊！竟能善说这样的过失，令诸菩萨生起觉悟之心。世尊！在后来末世五百岁中，会有菩萨听闻宣说这样诤论的过失，能生忧悔而远离烦恼吗？”佛告诉弥勒菩萨说：“弥勒！在后来末世五百岁中，少有菩萨能生忧悔、舍离烦恼。多有菩萨其心刚强，不互相尊敬，怀增上慢，互相是非。听闻宣说这样甚深的义趣与殊胜功德，虽然也受持、读诵、演说，由于这些菩萨业障深重，不能生起殊胜功德，便对这经疑惑不信，不再受持、为人演说。那时魔波旬见到这种情况，为了诳惑他们，化作比丘之像，来到他们那里，这样说：‘这些经典都是世俗善于文辞的人所制造的，不是如来所宣说的。为什么呢？此经所说的功德利益，你们都没有得到。’由于魔波旬这样诳惑，他们对这与空性义利相应的甚深契经心生疑惑，生起种种诤论，不再受持、读诵、演说。弥勒！那些愚人不能了知，由于自己的业，不能护持那殊胜的功德；自己的业消尽之后，决定当得这样的功德。”

【按】“来到其所说如是言”之“说”，明本作“作”。“不能护彼殊胜功德”之“护”，元、明、宫本作“获”。

#### 往生极乐的十种心

那时弥勒菩萨对佛说：“世尊！如佛所说阿弥陀佛极乐世界的功德利益。若有众生发十种心，随其中每一种心专念趣向阿弥陀佛，这人命终当得往生那佛世界。世尊！什么名为发十种心？由于这些心，当得往生那佛世界。”佛告诉弥勒菩萨说：“弥勒！这样的十种心，不是凡愚、不善丈夫、具烦恼者所能发起的。哪十种？一是对众生生起大慈，无损害之心；二是对众生生起大悲，无逼恼之心；三是对佛的正法不惜身命，乐于守护之心；四是对一切法发生殊胜之忍，无执著之心；五是不贪利养、恭敬、尊重，清净的意乐之心；六是求佛的种智，在一切时无忘失之心；七是对众生尊重恭敬，无下劣之心；八是不执著世间言论，对菩提分生起决定之心；九是种诸善根，无有杂染的清净之心；十是对诸如来舍离诸相，生起随念之心。弥勒！这名为菩萨发十种心。由于这些心，当得往生阿弥陀佛的极乐世界。弥勒！若人在这十种心中随成就一种心，乐欲往生那佛世界，若不得往生，是不可能的。”

#### 流通

那时尊者阿难对佛说：“希有，世尊！竟能开示演说如来真实的功德，发起菩萨殊胜的志乐。世尊！应当怎样称呼此经？我们应当怎样受持？”佛告诉阿难说：“此经名为‘发起菩萨殊胜志乐’，也名为‘弥勒菩萨所问’，以这名字你应当受持。”

佛说此经之后，弥勒菩萨以及诸声闻，一切世间的天、人、阿修罗、乾闼婆等，听闻佛所说，都大欢喜，信受奉行。
