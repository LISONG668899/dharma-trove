# 佛地经论白话（卷七）

**《佛说佛地经》唐三藏法师玄奘 译**

**《佛地经论》亲光等菩萨 造　唐三藏法师玄奘 译**

**经论合编　白话译文**

---

【译注】本卷为最后一卷。世尊以四首偈颂总摄前面所说的义理，论中对每半颂都给出两种解释：一种配五法与三身，一种配清净法界的六种相。偈颂之后，论主借"三身"这一句，对三身的名义、相用、与五法的配属、常与无常、形量、有无差别、所化共不共等作了全面的抉择。最后是依教奉行分，以及论主的回向偈。

## 一、世尊说颂

【经】那时，世尊说了以下偈颂：

```
一切法真如，二障清净相，
法智彼所缘，自在无尽相。
普遍真如智，修习证圆满，
安立众生二，诸种无尽果。
身语及心化，善巧方便业，
定及总持门，无边二成就。
自性法受用，变化差别转，
如是净法界，诸佛之所说。
```

【论】世尊将说四首偈颂，总摄前面所说的义理，简略地显示佛地清净法界之相。

如来地中的一切有为、无为功德，都由清净法界所摄持，都是清净法界之相，因为所相与能相都可以称为"相"。

在这四首偈颂中，前三首半分别显示其相，最后半首总结。

在分别显示其相的部分，有一种观点认为：第一个半颂显示清净法界，第二个半颂显示大圆镜智，第三个半颂显示平等性智，第四个半颂显示妙观察智，第五个半颂显示成所作智，第六个半颂显示四智所摄的眷属功德，第七个半颂显示五法所成的三身差别。

另一种观点认为：这里显示清净法界有六种相，总摄一切佛地功德，就是自性相、因相、果相、作业相、相应相、差别相。依次来说，第一种（自性相）占一首偈颂，其余每种各占半首偈颂。

【译注】两种解释并行贯穿下文：第一种把七个半颂依次配清净法界、四智、眷属功德、三身；第二种把它们配为法界的六相，其中"自性相"包括前两个半颂（清净法界与四智之体）。

## 二、第一个半颂：清净法界（自性相之一）

```
一切法真如，二障清净相。
```

这半颂的意思是：一切法的真如，远离二障、本性清净，这就是清净之相。

### （一）真如的种种开合

【论】一种观点认为，这里显示的是清净法界。也就是一切法空、无我性所显示的真如，永远远离二障，本性清净，现在又远离了染污，能作为一切善法的所依，所以称为清净法界。

"一切法"，就是世间、出世间，有漏、无漏的蕴、界、处等。"真如"，就是诸法的真实本性、无颠倒的本性，与一切法不一不异，体性唯是一味，随着诸法之相而分为多种。

或者说真如有两种：就是人空无我、法空无我。真如实际上并不是空无我性，因为它远离分别、断绝戏论；只是由于修习空、无我的观行，灭除了障蔽真如的我执、我所执而证得它，所以称为空无我。

或者说有三种：就是善、不善、无记，因为真如是这三种法的真实本性。

或者说有四种：就是欲界系、色界系、无色界系、不系，因为真如是这四种法的真实本性。

或者说有五种：就是心真如，乃至无为真如，因为真如也是这五种法的真实本性。

或者说有六种：就是色真如，乃至无为真如，因为真如是五蕴与无为的真实本性。

或者说有七种：一、流转真如，就是一切行从无始以来流转的真实本性；二、实相真如，就是一切法二空无我所显示的真实本性；三、唯识真如，就是一切法唯识的真实本性；四、安立真如，就是有漏法即苦谛的真实本性；五、邪行真如，就是业与烦恼即集谛的真实本性；六、清净真如，就是善的无为法即灭谛的真实本性；七、正行真如，就是种种有为无漏善法即道谛的真实本性。

或者说有八种：就是不生不灭、不断不常、不一不异、不来不去，由这八种遣除诸相之门所显示的真如。

或者说有九种：就是由九品道除去九品障碍所显示的真如。

或者说有十种：就是在十地中除去十种无明所显示的真如，也就是十种法界，如《摄大乘论》中详细辨析其名相。

像这样逐次增加数目，乃至穷尽，一切法门都是真如差别之相；而真如的本体非一非多，一切分别、言说都不能辨明它。

因为它远离一切虚妄颠倒，所以假名为"真如"。因为它能作为一切善法的所依，所以假名为"法界"。因为它远离损减的诽谤，所以假名为"实有"。因为它远离增益的诽谤，所以假名为"空无"。分析推求诸法的虚假，推到这里就再也不能推求了，唯有这是真实的，所以假名为"实际"。它是无分别最胜圣智所证的境界，所以假名为"胜义"。像这样广说。

【译注】七真如出自《解深密经》，后为《成唯识论》所采。八不即龙树《中论》开头所说的八不。十真如即十地所证的十种法界。

### （二）二障的体性

【论】所谓"二障"：一、烦恼障；二、所知障。

扰乱身心、令其不得寂静，称为烦恼障。覆蔽所知境界的无颠倒本性，令其不能显现，称为所知障。

烦恼障，以执著实我的萨迦耶见（身见）为首，一百二十八种根本烦恼以及随烦恼，以及它们所发起的业、所得到的果，都包括在内，因为都以烦恼为根本。

所知障，以执著遍计所执诸法的萨迦耶见为首，所有的无明、法爱、恚等种种心与心所法，以及它们所发起的业、所得到的果，都包括在内，因为都以法执以及无明等为根本。

### （三）法执在哪些心中

【论】关于法执与无明等存在于哪些心中，有不同的观点。

一种观点认为：法执及无明等，遍在一切善、恶、无记的有漏心品，以及二乘的无漏心品中，因为这些心都不能通达法无我，都是相似于相分、见分而生起的。

另一种观点认为：法执只存在于不善、无记的有漏心品中。理由如下：

《瑜伽师地论》说，种种无明只有两种：一是不善，二是无记；又有两种：一是染污，二是不染污。没有说有善的无明。不能说非善的无明与善心相应，因为性质相违。又，善心品必定与无痴善根相应，痴就是无明，不可能一个心中痴与无痴并存，就像贪与无贪、瞋与无瞋不能相应一样。不能说法执不与痴俱起，因为如果没有无明，就不会有颠倒的执著；就像执著有我必定与无明俱起一样，这里也应当是这样。

又，种种善心，本性没有迷执，都与信等俱起，随顺无我的理解，是二空观的前方便。不可能由法执来引导法空观，就像我执从来没有见过引导人空观这样的事。所以有漏、无漏的善心，决定不与二执、无明、爱等相应，否则就违背圣教和正理。

一切异熟无记心品，也没有法执及无明等，因为它们分别的力量微弱，不能执著。

如果阿赖耶识有颠倒执著而成为法我见，有无明等，那么阿赖耶识就不应当只与五个遍行心所相应了，因为见、无明等属于慧等所摄。又，如果这个识有法执，因为没有能熏的（第八识本身是所熏），它的法执就应当念念消失，不需要对治，这就成了大过失；而烦恼障中没有这样的事。又，法空观初次现前时，这个识就应当断灭，因为障与对治相违，不能同时运行。如果这样，其余的有漏种子就应当没有所依，所修的功德也应当没有熏习之处，因为没有所熏的识了。也不能说熏习在镜智相应的清净识中，因为那个识不是无记性的，而且那时还没有获得。

阿赖耶识既然没有法执，其余转识中属于异熟果的部分，也应当是这样，因为性类相同。

前五识中也没有法执，因为它们没有猛利的分别作用，不能推求。《摄大乘论》说，能遍计的心只是意识。所以可知前五识不缘遍计所执自性，就像没有分别、没有推求的见解不能计度"我"一样，所以也不能计度诸法。

然而，由于意识计度我、计度法而生起爱、恚等，引起前五识中不属于见所摄的爱、恚等生起；前五识虽然没有"见"，却有爱、恚、无明等属于二障所摄的法。所以，二执的分别推求，只在第六、第七意识中。至于不属于见所摄、不推求的爱恚等，也存在于前五识中。

诸我执等烦恼障的体性，只存在于不善、有覆无记两种心中。法执等所知障的体性，也存在于无覆无记心中，因为二乘无学也有现行。无学位中没有不善、有覆无记，这是就二乘而称为"无覆"；如果相对于菩萨来说，因为是染污的，也称为"有覆"。所以所知障也称为无覆，也称为有覆，同一个体有两个名称，因为所对照的不同。

烦恼障中有所知障，因为所知障是烦恼障的所依，必定是执著有法，才会计度有我。两者体性虽然没有两个，但作用有别；就像一个识体，取境的作用有多种，由此熏习生起的一个种子体，也有多种作用。生起时虽然同时，但断除时有先后，因为圣道的势力有分齐。

有人问：如果所知障就二乘来说是无覆无记，那么在四种无记中属于哪一种无记？

回答说：属于异熟生无记，因为是从异熟识生起的。

问：如果这样，哪些不是异熟生呢？

答：就像增上缘一样，其余所不摄的都属于这一类。威仪等心，因为不坚固执著，不是普遍的，所以没有二障之体。

【译注】四无记：异熟生、威仪路、工巧处、变化。论主此处说所知障若就二乘而言属无覆无记中的"异熟生"。

有人问：如果善心和无覆无记心中没有法执，为什么不能通达法空？它们也没有我执，为什么不能通达人空？

回答说：这是由于它们与第七识中的我执俱起，所以不能通达人空；同样，也应当是由于与第七识中的法执俱起，所以不能通达法空。

问：它们既然相似于相分、见分而生起，为什么不称为法执所摄呢？

答：诸佛菩萨的无漏智等也有相、见二分，为什么不是执著呢？所以缘生的相分、见分属于依他起性所摄；如果在这上面虚妄地计度有心外之法、或计度有决定的自性，才称为"执"。

所以，所知障在第七识中的部分，普遍与六识三性之心俱起，但不是相应的心品。暂且停止详细的争论，应当解释本文。

【译注】论主取后一说：法执只在第六、第七识的不善、有覆、无覆无记心中，不在善心、异熟心、前五识中。善心与无漏心之所以不能通达法空，是因为同时有第七识的法执在旁伴随。后来《成唯识论》也有类似的辨析。

### （四）清净之相

【论】所谓"清净相"，是说这真如本性清净，被二障所覆蔽，就像清净的虚空被烟云等遮障，看起来好像不清净。获得出世间证悟真如之道，逐渐除去二障的所有种子，就像大风吹散烟云等。到金刚喻定现前的时候，灭除远离一切障碍的种子而无余，获得清净法界究竟的转依，称为"清净相"。

这样已经显示了前面五法中的清净法界。

另一种观点认为：这是显示自性相中法界清净的那一部分，也就是六相中自性相的一部分，文义与前面的解释相同。

## 三、第二个半颂：大圆镜智（自性相之二）

```
法智彼所缘，自在无尽相。
```

这半颂的意思是：缘于诸法的智慧，以及以真如为所缘的智慧，具有自在、无尽之相。

### （一）第一种解释：大圆镜智

【论】一种观点认为，这里显示的是大圆镜智。

"法"，就是依他起性；缘于法的镜智，称为"法智"。大圆镜智也缘世俗的依他起性，因为它显现依他起法的影像，不迷于它们。

"彼所缘"，"彼"是指真如，而不是指那法智。虽然隔了一句，但义理的脉络相应，所以没有过失。法智以真如为所缘，所以称为"彼所缘"，并不是说法智是真如的所缘。大圆镜智也缘胜义的圆成实性，因为它穷尽生死之际，内证圆成实性。

这是说镜智缘一切法的自相、共相，以依他起性、圆成实性都为境界。遍计所执只是凡夫愚人的妄心所计度的，不是圣智的境界，所以不说镜智缘它。正如论中所说：遍计所执唯是凡夫之智的境界，圆成实性唯是圣者之智的境界，依他起性既是凡夫之智的境界，也是圣者之智的境界。遍计所执因为没有体性，所以不是圣者所证的。

有人问：如果这样，圣智就不能知一切了？

回答说：遍计所执既然是没有的，智慧要知道什么呢？如果知道它为有，就成了颠倒；如果知道它为无，那么所知的就不是遍计所执的自性：心所显现的，属于依他起所摄；真如之理没有它，属于圆成实所摄。所以圣智虽然知道有、无，却不以遍计所执自性为所缘的境界。

【译注】这是三性说的要义：遍计所执本无，圣智不缘；圣智所知的"它是无"，其实是知依他起上本无此执、真如上本离此执。

"自在"，是说大圆镜智由六度修习而成，具足十种自在，妙用无碍。

"无尽相"，是说它穷尽生死之际，无间无断，相续恒常。"相"是所相，或者是能相，因为它表示自体。

这样总的显示了前面五法中的大圆镜智。

### （二）第二种解释：四智之自性

【论】另一种观点认为：这是显示自性相的一部分，也就是佛果四智，即六相中自性相的一部分。

有为功德的"法"，就是大圆镜智。由对治之力，转去一切粗重所依的阿赖耶识，转得清净的依他起性，远离一切心思分别，所缘与能缘平等平等，不可宣说。缘生法性不增不减；内证的行相，能显现一切诸法的影像；对一切境界普能照了，因为没有分别。

总的说为"法智"的"智"，就是平等性智。由对治之力，转去执著众生与法的第七末那识，转得清净的依他起性，缘镜智等以及清净法界，平等平等，内证的行相，所以称为"智"。

"彼所缘"，就是其余二智（妙观察智、成所作智）。由对治之力，转去世间分别的六识，转得清净的依他起性，或者是出世间的、或者是世出世间的。它们是后得智，缘上面所说的真如以及法智等依他起性作为境界，没有执著的分别，相似于所缘而显现，分别自内所证与能证。因为以上面所说的真如、法智为所缘，所以称为"彼所缘"。

这四智妙用无碍，所以称为"自在"。穷尽生死之际，恒常运用不息，所以称为"无尽"。大圆镜智、平等性智恒常没有间断，所以称为无尽；妙观察智、成所作智虽然有间断，但只要暂时作意就能现前，屡屡生起没有穷尽，所以也称为无尽。

"相"是体相。它们都是从缘而生，所以称为清净依他起性；都没有颠倒，所以称为清净圆成实性。都有内证，有照境的作用，相似于境界而显现，所以称为"智"。这些意义能表示它们的自体，所以称为"相"。

## 四、第三个半颂：平等性智（因相）

```
普遍真如智，修习证圆满。
```

这半颂的意思是：普遍证知真如的智慧，经过修习，证得圆满。

【论】一种观点认为，这里显示的是平等性智。也就是在初地初次现观的时候，获得这平等的无分别智，观察真如等一切平等。在其后诸地中逐渐修习，转增胜、转清净，直到佛地证得圆满，究竟清净，证得法界等一切理与事都是平等的。这样显示了前面五法中的平等性智。

另一种观点认为：这里显示的是六相中的因相。也就是在初地中，以无分别智观察第一种法界，经过见道的三心，断除见道所断的一百一十二种根本烦恼以及随烦恼，并灭除见道所断的不染污无明、分别法执中最粗的一部分，显现第一种法界，智慧的种子增长。

从此以后，在一切地的修道位中，以无分别智观察其余的法界真如；对于那一切法门，在闻思修等加行智等方便位中逐渐修习，这样随其所应，逐渐伏断修道所断的十六种烦恼以及随烦恼，并随其所应逐渐灭除修道所断的不染污无明、俱生法执的其余部分，显现其余的法界，智慧的种子增长。以此为因，直到佛地，证得法界与四智圆满。

【译注】"见道三心"：唯识说见道有真见道、相见道，相见道中又有三心之说（如"内遣有情假缘智"等三心）。修道所断十六种烦恼，即卷一所说一百二十八种中的修所断部分（欲界有贪、瞋、痴、慢、身见、边见六种，色界、无色界各除瞋而为五种，合计十六）。

## 五、第四个半颂：妙观察智（果相）

```
安立众生二，诸种无尽果。
```

这半颂的意思是：安立众生于利益与安乐二事，种类众多、无有穷尽，这是果。

【论】一种观点认为，这里显示的是妙观察智。也就是这妙智能为众生宣说妙法等，安立众生于利益、安乐，所以称为"二"。这两种有许多品类，所以称为"诸种"。这两件事穷尽生死之际，恒常地做而不断绝，所以说"无尽"。这就称为"果"，因为是智慧的果。这样显示了前面五法中的妙观察智。

另一种观点认为：这里显示的是六相中的果相。也就是清净法界与四种妙智，都能安立一切众生于利益安乐。

令众生修习善因，称为利益；令众生得到乐果，称为安乐。又，令众生远离恶法，称为利益；令众生摄取善法，称为安乐。又，拔除众生的痛苦，称为利益；施与众生快乐，称为安乐。此世、他世、世间、出世间等，应当知道也是这样。品类众多，所以称为"诸种"；穷尽未来际，所以称为"无尽"。这样的二事、诸种、无尽，是清净法界与四智的果，因为由它们而生起。

## 六、第五个半颂：成所作智（作业相）

```
身语及心化，善巧方便业。
```

这半颂的意思是：身、语、心的化现，以及善巧、方便的事业。

### （一）两种解释

【论】一种观点认为，这里显示的是成所作智。也就是这个智能生起身、语、心的化现；契合根机，所以称为"善巧"；加行不断，所以称为"方便"，这就称为"业"。或者说，这个智以善巧方便，能生起身、语、心三种化业。这样显示了前面五法中的成所作智。

另一种观点认为：这里显示的是六相中的作业相。也就是清净法界与四种妙智，能生起身、语、心三种化业，以及善巧业与方便业。成所作智生起身、语、心三种化业；妙观察智生起善巧业，因为观察根机等极为善巧方便；其余二智以及清净法界生起方便业，因为能自然地作为一切业的方便。

### （二）身化三种

【论】身化有三种：

一、与自身相应：就是把自身化现为转轮王等种种形类，以及示现种种本生之事。

二、与他身相应：就是把魔王化成佛身等，把舍利弗变成天女等，寄托在他人身上示现种种变化形类。

三、与身不相应：就是把大地化现为七宝等，或者示现无量佛的化身等，或者放出光明照耀无边世界。像这些，离开自身与他身而另外化作有情、非情的种种色法形类，震动大地、放出光明、风与香等事，都是为了利乐诸有情，一切都称为佛的化身业。

【译注】"变舍利弗为天女"，即《维摩诘经·观众生品》中天女与舍利弗互换身形一事。

### （三）语化三种

【论】语化也有三种：

一、与自身相应：就是佛自身化现梵音，遍告无边世界等种种语业。

二、与他身相应：就是令声闻大弟子等以佛的梵音宣说大乘甚深之法等。所以声闻、诸菩萨等宣说不是自己分内的甚深妙法，都是如来变化所作，不是他们自己的力量。

三、与身不相应：就是化现山、海、草木等类，乃至虚空，也发出音声宣说大法等。

像这些都称为变化语业。

### （四）心化二种

【论】心化只有两种：

一、与自身相应：就是在自心上化现种种心与心所法的影像差别。

二、与他身相应：就是令他人的心也显现种种心与心所法的影像差别。这两种都是相分相似于见分而显现。

有一种观点认为：以定力能令自心理解非分内之法，称为化自心；加持有情，令愚昧的人理解深细之法，令失去正念的人得到正确的忆念，称为化他心。然而心本身不能化，因为心没有形质。正如论中所说："心没有形相，所以不可变化。"又说化身没有心、心所法。

（论主回应说：）这是就二乘及诸凡夫的定力而说的，他们的定力薄弱，不能化现没有形质的法。诸佛菩萨不可思议的定，都能化现。如果不是这样，如来怎么能示现贪、瞋等？声闻及畜生等怎么能知道如来的心？经中为什么说化现无量种类都令他们有心？前面为什么说种种化意业？经中为什么说有依他之心？只是种种化色与真实的色有同样的作用，化根与化心只有相状的显现，没有与真实相同的作用；又是就下位者而这样说的。

有人问：如果这样，为什么不化现非情之物，令其显现心相呢？

回答说：非情之物已经是心等的相分了，怎么能再令它显现有心之相呢？如果显现心相，就称为有情，不再属于非情所摄了。所以化心只说两种。

如前面已经说过的，妙观察智能观察自证的陀罗尼门、三摩地等，能观察有情的根、欲、性等，宣说妙法之药，称为善巧业。其余二智以及清净法界，作为种种功德的所依止，能生起种种利益有情之事，称为方便业。

## 七、第六个半颂：眷属功德（相应相）

```
定及总持门，无边二成就。
```

这半颂的意思是：三摩地门与陀罗尼门，以及无边的福德、智慧二种庄严，都已成就。

【论】一种观点认为，这里显示的是四智所摄的眷属功德。另一种观点认为，这里显示的是六种相中的相应相。

"定门"，就是八万四千三摩地门。"总持门"，就是八万四千陀罗尼门。这两种能普遍生起一切有为功德，普遍显示一切无为功德，普遍引发一切神力作用、利益众生之事，所以称为"门"。

"无边二"，就是福德、智慧两种庄严，其中的差别有无量种，有八万四千种福德智慧；或者因为是无量劫修习所成，所以称为"无边"。前五波罗蜜多称为福德，后五波罗蜜多称为智慧；或者随其所应，每一种的自性与眷属都具足这两种。

这样的二门与两种庄严，在四智品中每一品都完全具足，恒常与之相应，也依止于清净法界，与清净法界不相舍离，所以称为"成就"。

【译注】"前五""后五"是就十波罗蜜多而言：施、戒、忍、精进、静虑属福德，般若、方便、愿、力、智属智慧。

## 八、第七个半颂：三身差别（差别相）

```
自性法受用，变化差别转。
```

这半颂的意思是：自性法身、受用身、变化身，三身差别而运转。

### （一）三身名义

【论】一种观点认为，这里显示的是五法所成的三身差别。另一种观点认为，这里显示的是六种相中的差别相：虽然诸如来所依的清净法界体性没有差别，但有三身种种相状不同、转变不同，所以称为"差别"。

"自性法"，就是如来的第一种自性身，体性恒常不变，所以称为"自性"；因为是十力、四无畏等种种功德法的所依止，所以也称为"法身"。

"受用"，就是第二种受用身，因为能令自己和他人受用种种大法之乐。

"变化"，就是第三种变化身，因为为了利益安乐众生，示现种种变化之事。

体的意义、所依的意义、众德积聚的意义，总称为"身"。这样简略地解释了三身的名义。

### （二）三身相用

【论】又，**法身**：以究竟转依的真如为相；是一切佛法平等的所依；能生起一切自在作用；是一切清净白法增上所显现的；是一切如来平等的自性，微妙难测；灭除一切分别，断绝一切戏论。所以契经说："诸佛的法身不应当寻思，不是寻思的境界，超过一切寻思戏论。"

**受用身**：以一切功德圆满为相；是一切佛法共同集合而成的；能生起一切自在作用；是一切白法增上所生起的；是一切如来各别的自体，微妙难测；居住在纯净的国土，自然湛然，穷尽未来际自己受用法乐；又示现种种形相，宣说种种法，令大菩萨也受用法乐。

**变化身**：以一切神变圆满为相；是一切化用共同集合而成的；示现一切自在作用；是一切白法增上所引发的；是一切如来各别的化用，微妙难测；居住在净土或秽土，示现种种形相，宣说种种法，成熟下位的菩萨、二乘以及凡夫众，令他们进入大地（登地），出离三界，脱离种种恶趣。这样简略地解释了三身的相与用。

### （三）五法如何摄三身

【论】又，前面的五法如何摄三身呢？有两种观点。

第一种观点认为：前两种（清净法界、大圆镜智）摄自性身，中间两种（平等性智、妙观察智）摄受用身，成所作智摄变化身。理由是：经中说真如是法身；论中说转去阿赖耶识得自性身，而大圆镜智是转第八识所得，所以可知前两种摄自性身。本经中说成所作智生起种种化业，《大乘庄严经论》说成所作智在一切世界发起种种无量难思的变化事，所以可知最后一种摄变化身。平等性智，如其他论中所说，能在净土中随诸菩萨所乐示现种种佛身；妙观察智，也如论中所说，在大集会中能显现一切自在作用、说法断疑；又说转去种种转识得受用身，所以可知中间两种摄受用身。又，佛的三身都属于十种殊胜中的"智殊胜"所摄，所以可知三身都有智慧。

第二种观点认为：只有第一种（清净法界）摄自性身。四智的自性以及与之相应共有的法，以及为登地菩萨所显现的一部分细相，摄受用身；如果是为登地以前的诸菩萨等所显现的一部分粗相化用，则摄变化身。理由是：

诸经都说清净真如是法身。《赞佛论》说如来法身无生无灭。《大乘庄严经论》说佛的自性身本性常住。《能断金刚般若论》说受持演说那部经的功德，对于佛的法身是证得之因，对于其余二身是生起之因。诸经论说以究竟转依为法身，而转依就是清净真如，不是对治之道。所以可知法身唯以清净法界真如为体性。

《大乘庄严经论》说大圆镜智是受用佛。《摄大乘论》说转种种转识得受用身。至于说转去阿赖耶识得法身，这是说转去第八识中的二障种子，显现得到清净转依的法身，并不是说镜智，因为论中已经说镜智是受用身了。

又，受用身大略有两种：一、自受用身，是三大阿僧祇劫修习所成的；二、他受用身，是为了令诸菩萨受用法乐的。所以四智与相应共有之法以及一部分化现，是受用身。

经论都说，化身是为了化度登地以前的众生而示现种种相的。既然是登地以前众生的境界，可知不是真实的功德，只是化用。经论只说成所作智能生起化业，并不是说它就是化身。

虽然说三种身都属于智殊胜所摄，但那是因为：法身是智慧所依、所证的，化身是智慧所生起的作用，相似于智慧而显现，所以假说为智，也没有过失。

【译注】两说之中，第二说（法身唯清净法界，四智属受用身，化身是成所作智所起之用）后来为《成唯识论》所采，成为法相宗的定说。"十种殊胜"出自《摄大乘论》，智殊胜即"彼果智殊胜"，讲佛三身。

### （四）三身是常还是无常

【论】有人问：这三身中，受用身与变化身既然有生灭，为什么经中说诸佛之身是常住的？

回答说：因为二身所依的法身是常住的。又，受用身与变化身虽然有生灭，但因为恒常受用种种法乐、从不休废，在十方世界屡屡示现化身、从不断绝，就像说"常受快乐""常行布施饮食"一样，所以说名为"常"。

《大乘庄严经论》说，常有三种：一、本性常，就是自性身，因为此身本来体性常住；二、不断常，就是受用身，因为恒常受用法乐，没有间断；三、相续常，就是变化身，因为隐没了又再显现，化现无尽。

这样，法身远离一切分别戏论，没有生灭，所以说名为常。二身虽然念念生灭，但因为依于常住之身、没有间断、恒常相续，所以说名为常。

经中说如来的色、受等法一切常住，是依这个道理，并不是说没有生灭。因为它们是由无漏种子修习增长所生起的；"有生必灭"是一向确定的道理；色与心都被见到是无常的；常住的色与心从来没有被见过。

### （五）三身的形量

【论】这三身的形状大小如何呢？

**法身**以清净真如为体，真如就是诸法的真实本性。诸法没有边际，法身也是这样，遍在一切法中，无处不有。就像虚空一样，不能说它的形状大小；就相状而言，遍在一切处。

**受用身**，有色法，也有非色法。非色诸法没有形质，也不能说它的形状大小；如果就其所依之身以及所知的境界来说，也可以说遍在一切处。

色法又有两种：一是实色，二是化色。

所谓**实色**：由三大阿僧祇劫修习感得色身相好等的业，转变五根等有漏的色身，获得佛无漏的五根等色法，以无量相好庄严，其身周遍法界，与真实的净土相称。

在生死中，业有分限，阿赖耶识所变现的身形大小不定。就拿这个世界来说：赡部洲人的善业最劣，所得的色身最高只有四肘；东胜身洲人的善业稍胜，身高八肘。这样善业逐渐增胜，所得色身的形量也逐渐增大，乃至色界的色究竟天，因为感得色身的业最为殊胜，所得色身有一万六千由旬之高。十地菩萨，由于无漏善根的资助熏习，身形转大，如经中广说。

到金刚喻定现前的时候，灭除一切障碍，善根的势力量无边际，所以所得的色身充满法界，遍于真实的净土。因为与大圆镜智相应的清净识所变现的身土没有限量。诸佛的识所变现的身土，同一处所、同一时间，相状相似，互不障碍，穷尽未来际，无间无断，依此能令诸佛受用广大的喜乐，所以称为受用身土。

这样的身土唯有佛才能知道，不是诸菩萨的五根所能证知的。佛的每一个色根，都能证知一切所受用的境界而无障碍。所以诸佛有无见顶相、无边的法音，一切色根的作用没有限量，因为遍满一切处。

【译注】"无见顶相"即佛的肉髻相，一切人天无能见其顶。

所谓**化色**：由于悲愿之力，为了进入大地（登地）的诸菩萨众，示现种种身、种种相好、种种言音，依于种种国土，形量不定。

**变化身**，也是由悲愿之力，为了化度登地以前的诸有情而示现的变化身，通于色法与非色法。非色法就是变化的意业，以及十力、四无畏等种种功德之相，因为没有形质，所以没有形量。色法就是变化的身业、语业等，随时、随处、随着大众所宜而示现，所示现的身形大小不定，如经中广说。

### （六）诸佛三身有无差别

【论】这三身，一切如来之间有差别还是没有差别呢？

法身的真实本性，一切如来都共有，所以没有差别；就能证的因有差别来说，假说有差别。

其余二身，由各别的因所感，各有各的自性，实际上是有差别的；但没有各别的执著，同一处所、相状相似，利乐的意乐与事业都平等，所以说没有差别。

所以说：一切诸佛，由于所依、意乐、事业，对于三种身依次说没有差别：因为所依的法界没有差别，因为利乐的意乐没有差别，因为共同所做的事业没有差别。

### （七）三身各有怎样的功德

【论】这三身各自有不同的功德吗？

如来的法身，以清净真如转依为相，是真实的善，本性清净，远离一切杂染法；因为是一切功德的所依止，因为是一切功德的真实本性，所以说它具足一切功德，但没有色、心差别的功德。

佛的受用身，具足一切色、心等法的真实功德，以及为他人所显现的化相功德。

佛的变化身，只具足一切示现的色、心等化相功德。

所以三身都说具有超过恒河沙数量的功德。

### （八）诸佛所化有情是共还是不共

【论】一切如来所化度的有情，是共同的还是不共同的？

一种观点认为都是共同的。因为每一尊佛都能化度一切有情，福德智慧一切平等，三大阿僧祇劫勤修行愿，同样是为了拔济一切有情而求菩提。正如经中所说："一尊佛所化度的有情，就是一切佛所化度的有情。"

另一种观点认为是不共同的。因为佛所化度的诸有情类，本来就有相属关系。

所以过去在底沙佛时，释迦与慈氏（弥勒）曾一同作为他的弟子。佛观察到释迦所化度的有情善根先成熟、慈氏所化度的有情善根后成熟，又观察到慈氏的因行先圆满、释迦的因行后圆满，于是在一处入火光三昧，令释迦看见。释迦七日七夜翘起一足、以一首偈颂赞叹，令他超越慈氏，在慈氏之前成佛。

【译注】此即"释迦超劫成佛"的故事：底沙佛（Tiṣya，又译弗沙佛）为令释迦先成佛，入火光定；释迦见之，翘足七日七夜赞叹，由此超越九劫，先于弥勒成佛。

又，佛将要入涅槃的时候，这样说："我所应当度化的，都已经度化完了。"

又，契经说："佛涅槃时，观察到一个应受化度的众生，现在正生在非想非非想处天，将来会生到这个世界，应当受佛的化度。于是佛留下一个化身，潜住在这个世界，而先前所受的身体示现入涅槃。那个众生从非想非非想处天命终，来生到这里，佛所留下的化身为他宣说妙法，令他成阿罗汉，那时化身才隐没不现。"

又，诸经中处处宣说，能化者与所化者的相属关系是决定的。所以诸佛所化度的众生是不共同的。

按照如实的义理来说：有共同的，也有不共同的。从无始以来，种性法尔如是，互相系属：或者多个众生属于一尊佛，或者一个众生属于多尊佛。菩萨在因地时成熟有情，也不是决定的，或共或不共，所以成佛之后，或者共同化度，或者各别化度。

如果所化度的众生一向是共同的，何须要有多尊佛呢？一尊佛就能化度一切众生了。那就应当只有一尊佛常住世间教化众生，其余的佛都应当入永寂灭了；佛也不应当化度其余众生令他们趣向大乘，因为没有用处；只应当化度他们证得三乘之果、入永寂灭就好了，因为那比较容易获得。哪有智者会舍易就难、点灯去帮助太阳呢？所以所化度的众生并不是一向共同的。

如果所化度的众生一向是不共同的，菩萨就不应当发弘大誓愿，历事诸佛，修学大乘；苏达那（善财童子）等也不应当参访承事众多善知识；诸佛也不应当把自己所化度的众生付嘱给后来的佛。这些事都相违背了，所以不应当说一向不共同。

虽然每一尊佛都有化度一切有情的功能，但诸有情对于没有因缘的佛不肯受化，也不能见闻。虽然每一尊佛穷尽未来际常住世间，教化无量的有情类，但随众生所宜示现种种化相：或示现成等正觉，或示现涅槃，或名为释迦，或名为慈氏等。随着某一个化相所应度的有情，就说"都已度完"。那位生在非想处天的众生，适合见到释迦的化相而得度，所以留下化身等待他，这也并不相违。

有人问：如果诸如来有同一个所化的众生，那么由哪一尊佛现前来化度他呢？

回答说：诸佛都有悲愿之力，不能只由一尊佛化度、其余的都止息。只是有缘的诸佛，在同一处所、同一时间，于后得智上各自显现一个化身，相状相似，互不障碍，互相和杂作为增上缘，令所化众生的识这样变现，以为见到一尊佛为他示现神通、宣说正法。像这样的事不可思议，若不是依唯识的道理，是不能理解的。

【译注】论主以唯识解释"多佛共化一人"：诸佛各现化相，于众生识上合为一佛之相，如众灯共照一室。

### （九）三身属自利还是利他

【论】又，自性身寂灭安乐，正属于自利功德所摄；因为作为增上缘利益众生，所以兼属于利他；又因为是二身自利利他两种功德的所依，所以属于二利所摄。

受用身具有两部分：一、自受法乐分，就是三大阿僧祇劫修习自利之行，圆满所证得的色等实身，令自己受用微妙的喜乐；二、他受法乐分，就是三大阿僧祇劫修习利他之行，圆满所证得的色等化身，为了进入大地的诸菩萨众，示现种种形相、宣说种种法，令诸菩萨受用大法之乐。由于这两部分，有时说此身只属于自利，有时说只属于利他，有时说两者都属于，都不相违。

变化身只是为了利他而示现种种化相，所以属于利他所摄。

### （十）受用与变化的四句

【论】这三身有四个部分，所以可以作成四句：

一、是受用而非变化：就是自利部分的真实受用身。

二、是变化而非受用：就是变化身，为了化度登地以前的种种类别的众生，或粗或妙，或令欢喜或令怖畏，改变转换不定，只称为变化，不称为受用，因为不一定令他们享受现法之乐。

三、既是受用也是变化：就是为登地菩萨所示现的种种化身，因为令诸菩萨享受法乐，又因为随时改变转换、不决定。

四、既非受用也非变化：就是自性身。

### （十一）二身说与十佛说

【论】有些地方说佛有两种身：一是生身，二是法身。自性身与真实受用身，都称为法身，因为是种种功德法的所依止，是种种功德法所集成的。变化身与他受用身，都称为生身，因为随大众所宜而屡屡示现受生。

又，其他经中说有十种佛：一、现等觉佛；二、弘誓愿佛；三、业异熟佛；四、住持佛；五、变化佛；六、法界佛；七、心佛；八、定佛；九、本性佛；十、随乐佛。前五种是世俗的，后五种是胜义的，随其所应由三身所摄。像这一类，应当随其相状而了知。

【译注】十佛之说见于《华严经·离世间品》等。

## 九、第八个半颂：总结

```
如是净法界，诸佛之所说。
```

这半颂的意思是：这样的清净法界，是诸佛共同所宣说的。

【论】这样的如来清净法界，是诸佛共同宣说的，具足佛地五种功德与三身差别，或者自性等六句的义相。由这四首偈颂，简略地宣说了佛地的一切功德；连同前面的广说，应当知道总称为"圣教所说分"。

## 十、依教奉行分

【经】那时，薄伽梵说完这部经后，妙生菩萨摩诃萨等，诸大声闻，世间的天、人、阿素洛等一切大众，听闻佛所说，都大欢喜，信受奉行。

【论】这里显示听法的众会依教奉行。

由于佛的清净识被悲愿所引发，变现相似的契经，以增上缘之力，令当时大众自心的善根成熟，相似于那经教之相而显现，也就是以为听到佛说法，都生起欢喜，信受奉行。

诸声闻等，或者是化现的，或者是真实的。受用土与变化土同在一处，听法的徒众所听到的虽然相同，所见到的却各不相同，互不障碍：上位者也能见到下位者所见，下位者却见不到上位者所见；各自的利益安乐之事都得以成就。

【译注】这与卷一开头"地前见化身在秽土说法，地上见受用身在净土说法"首尾呼应。

## 十一、论主回向偈

```
佛地甚深诸句义，我今随分已略释，
功德普施诸群生，愿速等成无上果。
诸有书写所生福，后后胜善等流果，
愿此相续尽未来，利益安乐诸含识。
```

这两首偈颂的意思是：佛地经甚深的种种句义，我现在已随自己的能力简略地解释完毕；以此功德普遍施予一切众生，愿大家迅速同成无上佛果。凡是书写此论所生的福德，以及由此辗转生起的更殊胜的善法等流之果，愿它们相续不断、穷尽未来际，利益安乐一切有情。
