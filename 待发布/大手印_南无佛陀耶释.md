# 南无佛陀耶释

作者、译者不详　据藏文译出

## 题解

本篇藏名 na mo buddhā ya'i 'grel pa，即《南无佛陀耶释》，收于德格版丹珠尔续部释 ཞི 函第 228b 页（东北目录 D2300）。篇首没有梵藏题名，篇末只有题名，没有作者与译者的名字。

"南无佛陀耶"（namo buddhāya）意思是"敬礼佛陀"。本篇把这句话拆成"那、摩、布、达、耶"五个音节，每个音节配一颂，说明它所诠示的意义。这是一种"字门"式的释义：借某一字母作为某些梵语词的首字，来引出相应的法义。例如"那"（na）在梵语中是否定词，所以配"无生无灭"；"摩"（mo）可联想到愚痴（moha）、解脱（mokṣa）、魔（māra）；"达"（dhā）可联想到总持（dhṛ）、法（dharma）、法界（dharmadhātu）；"耶"（ya）可联想到"如"（yathā）。这些对应是本译按语中的推测，原文本身没有说明。

全篇很短，义理上是由"无"入"有"：先以"那"字说一切二边俱无，再以"摩""布"说佛能破痴、赐解脱、净烦恼，以"达"说诸法与法界不离，最后以"耶"说如住如坏、如说如行。

体例：凡标"存疑"的按语，表示本译对原文意思没有把握。藏文依 Esukhia 德格丹珠尔电子版。

## 一、标题句

```
ན་མོ་བུདྡྷཱ་ཡ།
```

南无佛陀耶（敬礼佛陀）。

## 二、那字

```
སྐྱེ་བ་མེད་ཅིང་འགག་པ་མེད། །
གཟུགས་མེད་གཟུགས་དང་ལྡན་པའང་མེད། །
འཁོར་མེད་མྱ་ངན་འདས་པའང་མེད། །
ན་ཡི་ཡི་གེས་བརྗོད་པའོ། །
```

无生亦无灭；既不是无色，也不是有色；没有轮回，也没有涅槃——这是由"那"字所诠示的。

【按】"那"（na）在梵语中是否定词，所以用来诠示生灭、有色无色、轮回涅槃等一切二边俱无。

## 三、摩字

```
མོ། གཏི་མུག་རྟག་ཏུ་འཇིག་པར་བྱེད། །
ཐར་པ་གཅིག་པུ་ལེགས་པར་སྟེར། །
བདུད་དང་ཉོན་མོངས་འཇོམས་པར་བྱེད། །
ཡི་གེ་མ་ཡིས་བརྗོད་པའོ། །
```

摩：恒常摧毁愚痴，唯一能善予解脱，摧伏魔与烦恼——这是由"摩"字所诠示的。

【按】标题作"mo"，颂末作"ma"字，因为 mo 是 ma 加元音 o 而成。愚痴（moha）、解脱（mokṣa）、魔（māra）三词都以 m 起首，这或许是本颂配义的由来，原文没有说明。

## 四、布字

```
བུད། སངས་རྒྱས་ཀྱིས་ནི་ཕ་རོལ་གཤེགས། །
སངས་རྒྱས་འགྲོ་བ་ཕན་པ་མེད། །
སངས་རྒྱས་ཉོན་མོངས་དག་པ་ནི། །
ཡི་གེ་བུད་ཀྱིས་བརྗོད་པའོ། །
```

布：佛已逝往彼岸；佛饶益众生；佛的烦恼已经清净——这是由"布"字所诠示的。

【按】存疑。第二句原文作"sangs rgyas 'gro ba phan pa med"，字面是"佛，众生利益无"，文义难通。本译怀疑 med（无）是 mdzad（作）之讹，依"佛饶益众生"译出，这样三句分别说佛的断德（逝往彼岸）、悲德（饶益众生）、净德（烦恼清净），较为整齐。若依原文不改，也可以理解为：于胜义中，佛并没有所饶益的众生，与《金刚经》所说"实无众生得灭度者"同一意趣。两解并存。

【按】"布"（bud）是 buddha（佛陀、觉者）的首音节。buddha 一词有"觉醒""开敷"之义，与烦恼清净之意相应。

## 五、达字

```
དྷཱ། ཆོས་རྣམས་ཐམས་ཅད་འཛིན་པ་ཡིས། །
ཆོས་ཀྱི་དབྱིངས་དང་བཅས་པར་ནི། །
ཆོས་རྣམས་ཉིད་ནི་ཆོས་ཀྱི་མཆོག །
ཡི་གེ་དྷཱ་ཡིས་བརྗོད་པའོ། །
```

达：由于总持一切法，［一切法］都与法界俱在而不相离；诸法本身，就是法中最殊胜的——这是由"达"字所诠示的。

【按】梵语"法"（dharma）一词，来自"持"（dhṛ）这个词根，意思是"能持自相"；法界（dharmadhātu）也以 dh 起首。本颂以"总持一切法""与法界俱""诸法即是最胜法"三句，说明诸法当体不离法界。第二句"与法界俱"，原文语法较简，方括号内是补足的意思。

## 六、耶字

```
ཡ། ཇི་ལྟར་གནས་པ་དེ་བཞིན་འཇིག །
ཇི་ལྟར་འཇིག་པ་དེ་བཞིན་གནས། །
ཇི་ལྟར་སྨྲས་པ་དེ་བཞིན་བྱེད། །
ཡི་གེ་ཡ་ཡིས་བརྗོད་པའོ། །
```

耶：如其所住，即如是而坏；如其所坏，即如是而住；如其所说，即如是而行——这是由"耶"字所诠示的。

【按】梵语 yathā（如）以 ya 起首，所以本颂三句都用"如……如是……"的句式。前两句"住即是坏、坏即是住"，说住与坏本来不二。第三句"如所说而行"，佛经中常用来称叹佛的言行一致（梵 yathāvādī tathākārī，如说而行），这里用来说佛语真实不虚。

## 跋语

```
ན་མོ་བུདྡྷཱ་ཡའི་འགྲེལ་པ་རྫོགས་སོ།། །།
```

《南无佛陀耶释》圆满。

## 通篇连读

南无佛陀耶。

无生亦无灭；既不是无色，也不是有色；没有轮回，也没有涅槃——这是由"那"字所诠示的。

恒常摧毁愚痴，唯一能善予解脱，摧伏魔与烦恼——这是由"摩"字所诠示的。

佛已逝往彼岸；佛饶益众生；佛的烦恼已经清净——这是由"布"字所诠示的。

由于总持一切法，一切法都与法界俱在而不相离；诸法本身，就是法中最殊胜的——这是由"达"字所诠示的。

如其所住，即如是而坏；如其所坏，即如是而住；如其所说，即如是而行——这是由"耶"字所诠示的。
