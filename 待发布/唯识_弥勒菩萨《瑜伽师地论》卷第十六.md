# 弥勒菩萨《瑜伽师地论》卷第十六（思所成地）

弥勒菩萨说　唐三藏法师玄奘奉诏译

## 本地分中思所成地第十一之一

### 一、三门标列

已经说完了闻所成地。什么是思所成地？应当知道略说由三种相：一是由自性清净，二是由思择所知，三是由思择诸法。

### 二、自性清净

什么是自性清净？应当知道有九种相。

第一，就是如有某人，独处空闲，审谛思惟如其所闻、如其所究达的诸法道理。

第二，远离一切不可思议之处，审谛思惟所应思惟之处。

第三，能善于了知黑说与大说。

第四，凡所思惟，唯依于义，不依于文。

第五，对于法的少分，唯生信解；对于法的少分，以智慧观察。

第六，坚固地思惟。

第七，安住地思惟。

第八，相续地思惟。

第九，对于所思惟的能善加究竟，终究不会中途厌怖退屈。

由这九种相，名为清净、善净的思惟。

### 三、思择所知

#### 所观察义

什么是思择所知？就是善于思择所观察的义。什么名为所观察的义？就是对于有的法了知有相，对于非有的法了知无相，这样名为所观察的义。

什么名为所观察的有法？应当知道这法略有五种：一是自相有法，二是共相有法，三是假相有法，四是因相有法，五是果相有法。

#### 自相有法

什么名为自相有法？应当知道这法略有三种：一是胜义相有，二是相状相有，三是现在相有。

胜义相有，就是诸法中离言说的义，出世间智所行的境界，不是安立之相。

相状相有，就是由四种所观察的相状：第一，在此处名可得；第二，在此处事可得；第三，这名对于这事并非不决定，所谓不决定，就是或者由于迷乱而不决定，或者由于无常而不决定；第四，这名对于这事无碍地随转，不是在某处随转，在某处又退还。

现在相有，就是已经生起的，以及具有因果之性的。

像这一切，总说为一种自相有法。

#### 共相有法

什么名为共相有法？应当知道这相又有五种：一是种类的共相，二是成所作的共相，三是一切行的共相，四是一切有漏的共相，五是一切法的共相。

种类的共相，就是色、受、想、行、识等各别的种类，总名为一种类共相。

成所作的共相，就是善的有漏法对于感得可爱之果，由于能成办所作的共相，说名为共相。如善的有漏法对于感得可爱之果，像这样，不善法对于感得不可爱之果，念住、正断、神足、根、力、觉支、道支等菩提分法对于得到菩提，由于能成办所作的共相，说名为共相，应当知道也是如此。

一切行的共相，就是一切行的无常之性相。

一切有漏的共相，就是有漏之行都是苦的性相。

一切法的共相，就是一切法空、无我的性相。

像这一切，总说为一种共相有法。

#### 假相有法：六种言论

什么名为假相有法？就是如果在某处，略有六种言论生起，应当知道这处名为假相有。

什么名为六种言论？就是属主相应的言论、远离此彼的言论、众共施设的言论、众法聚集的言论、不遍一切的言论、非常的言论。

属主相应的言论，就是诸言论要配属于所属之主才能了解它的相，不是不属于主。比如说生的时候，要问这是谁的生，待所属之主才起这言论，就是色的生，受、想、行、识的生。而不是说色的时候，要问这是谁的色，待所属之主才起这言论。如生，像这样老、住、无常等心不相应行，应当随其所应完全了知。这名为属主相应的言论。如果在某处起这言论，应当知道这处是假相有。

远离此彼的言论，就是诸言论，既不是以此显示此，也不是以彼显示彼，这说名为远离此彼的言论。如果是以此显示此的言论，这言论既在实相之处运转，也在假相之处运转。如果是以彼显示彼的言论，这言论也既在实相之处运转，也在假相之处运转。如果既不是以此显示此，也不是以彼显示彼的言论，这言论一向在假相之处运转。

如何以此显示此的言论在实相之处运转？比如说地的坚。如何这又在假相之处运转？比如说石的圆。如地的坚、石的圆，像这样，水的湿、油的滴、火的暖、炽燃的焰、风的动、飘风的鼓荡，也是如此。

如何以彼显示彼的言论在实相之处运转？比如说眼的识、身的触，像这些。如何这又在假相之处运转？比如说佛授、德友所饮食的、所乘的车乘、所穿的衣服、所戴的庄严具等。

如何既不是以此显示此，也不是以彼显示彼的言论，一向在假相之处运转？比如说宅的门、舍的壁、瓶的口、瓮的腹、军的车、林的树、百中的十、十中的三，像这些。这名为远离此彼的言论。

众共施设的言论，就是对于六种相状的言说自性，假立言论。六种相状：一是事的相状，二是所识的相状，三是净妙等的相状，四是饶益等的相状，五是言说的相状，六是邪行等的相状。事的相状，就是识所取的。所识的相状，就是作意所取的，能生起识。净妙等的相状，就是触所取的。饶益等的相状，就是受所取的。言说的相状，就是想所取的。邪行等的相状，就是思所取的。

众法聚集的言论，就是对于众多和合，建立自性的言论。比如对于内在的色、受、想、行、识，建立种种我等言论；对于外在的色、香、味、触等事和合的差别，建立宅、舍、瓶、衣、车、乘、军、林、树等种种言论。

不遍一切的言论，就是诸言论在某处随转，在某处退还。比如对于舍宅说“舍宅”的言论，在诸舍宅处处随转；对于村落、聚落、亭逻、国家等，就退还。对于盆、瓮等说“盆”等的言论，在盆、瓮等处处随转；对于瓶器等，就退还。对于军说“军”，随诸军而转；对于各别的男女幼少等类，就退还。对于林说“林”，随诸林而转；对于各别的树根、茎、枝、条、叶、花、果等类，就退还。

非常的言论，应当知道由四种相：一由破坏，二由不破坏，三由加行，四由转变。由破坏，就是瓶等破了之后，“瓶”等言舍弃，“瓦片”等言生起。由不破坏，就是种种物共同和合之后，或者成丸或者成散，种种杂物各别的言语舍弃，“丸”“散”的言语生起。由加行，就是对于金块等起诸加行，造作环钏等不同的庄严具，“金块”等言舍弃，“环钏”等言生起。由转变，就是饮食等在转变时，“饮食”等言舍弃，“大便”等言生起。像这一类，应当知道名为非常的言论。

随于诸物发起这样的六种言论，应当知道这物都是假有。这名为假相有法。

#### 因相有法

什么名为因相有法？应当知道这因略有五种：一是可爱的因，二是不可爱的因，三是长养的因，四是流转的因，五是还灭的因。

可爱的因，就是善的有漏法。不可爱的因，就是不善法。

长养的因，就是前前所生的善、不善、无记法，由于修习、善修习、多修习，能使后后所生的善、不善、无记法辗转增胜，名为长养的因。

流转的因，就是由这种子，由这熏习，由这助伴，那法流转；这对于那法，名为流转的因。

还灭的因，就是诸行的还灭、杂染的还灭，所有一切能寂静之道、能般涅槃、能趣菩提，以及它们的资粮，并其方便，能生能办，名为还灭的因。

像这样总名为因相有法。如果广为分别，应当如思择因果中了知其相。

#### 果相有法

什么名为果相有法？就是从那五种因，或生、或得、或成、或办、或转，应当知道这名为果相有法。

#### 所观无法

什么名为所观察的无法？应当知道这相也有五种：一是未生之无，二是已灭之无，三是互相之无，四是胜义之无，五是毕竟之无。

未生之无，就是未来的诸行。已灭之无，就是过去的诸行。互相之无，就是诸其余的法，由于其余的相，或者有远离之性，或者有非有之性；或者其余的法与诸其余的法有不和合之性。胜义之无，就是由世俗言说的自性、假设言论所安立之性。毕竟之无，就是石女之子等毕竟没有的一类。

#### 五种有性与五种无性

又有五种有性、五种无性。

什么名为五种有性？一是圆成实相的有性，二是依他起相的有性，三是遍计所执相的有性，四是差别相的有性，五是不可说相的有性。

这里，第一是胜义之相。第二是缘生之相的相。第三是假施设之相。第四是不二之相：生相、老相、住相、无常相、苦相、空相、无我相、事相、所识相、所取相、净妙等相、饶益等相、言说相的相、邪行等相的相，像这些相，应当知道名为差别相。

第五，由于四种不可说，名为不可说相。第一，由于无而不可说，就是补特伽罗对于那些蕴，不可宣说是异还是不异。第二，由于甚深而不可说，就是离言的法性不可思议，如来的法身不可思议，诸佛的境界、如来灭度之后是有是无等，不可宣说。第三，由于能引生无义而不可说，就是如果诸法不能引发法、义、梵行，诸佛世尊虽然证知也不说。第四，由于法相法尔所安立而不可说，就是真如对于诸行等，不可宣说是异还是不异之性。

什么名为五种无性？一是胜义相的无性，二是自依相的无性，三是毕竟自相的无性，四是无差别相的无性，五是可说相的无性。

### 四、思择诸法

什么是思择诸法？应当知道这又有两种：一是思择素呾缆的义，二是思择伽他的义。

思择素呾缆的义，将在摄事分及菩萨藏教授中广说。

思择伽他的义，又有三种：一是建立胜义的伽他，二是建立意趣义的伽他，三是建立体义的伽他。

#### 建立胜义伽他：举颂

建立胜义的伽他，如经中说：

```
都无有宰主　及作者受者
诸法亦无用　而用转非无
唯十二有支　蕴处界流转
审思此一切　众生不可得
```

（大意：本来没有宰主、作者、受者；诸法自身没有作用，然而作用的运转并非没有。唯有十二有支、蕴、处、界在流转，审谛思惟这一切，众生实不可得。）

```
于内及于外　是一切皆空
其能修空者　亦常无所有
我我定非有　由颠倒妄计
有情我皆无　唯有因法有
诸行皆刹那　住尚无况用
即说彼生起　为用为作者
```

（大意：内与外一切皆空，能修空的人也恒常无所有。圣者之我与凡夫之我决定没有，只是由颠倒妄计；有情与我都没有，唯有以因为性的诸法存在。诸行都是刹那，连住尚且没有，何况作用；就说它的生起为作用、为作者。）

```
眼不能见色　耳不能闻声
鼻不能嗅香　舌不能甞味
身不能觉触　意不能知法
于此亦无能　任持驱役者
法不能生他　亦不能自生
众缘有故生　非故新新有
法不能灭他　亦不能自灭
众缘有故生　生已自然灭
```

（大意：眼不能见色，乃至意不能知法；这里也没有能任持、驱使它们的主宰。法不能生他，也不能自生；众缘具有所以生起，并非旧有而新新生起。法不能灭他，也不能自灭；众缘具有所以生起，生起之后自然灭去。）

```
由二品为依　是生便可得
恒于境放逸　又复邪升进
愚痴之所漂　彼遂邪升进
诸贪爱所引　于境常放逸
```

（大意：以无明与贪爱二品为所依，生便可得。被愚痴所漂流，于是邪向升进；被贪爱所牵引，于是对境恒常放逸。）

```
由有因诸法　众苦亦复然
根本二惑故　十二支分二
自无能作用　亦不由他作
非余能有作　而作用非无
非内亦非外　非二种中间
由行未生故　有时而可得
设诸行已生　由此故无得
未来无有相　过去可分别
分别曾所更　非曾亦分别
行虽无有始　然有始可得
```

（大意：有因的诸法与众苦都是如此，以两种根本烦恼为本，十二支分为两分。业自己没有作用，也不由他作，不由其余所作，然而作用并非没有。杂染不在内、不在外、不在中间；未来之行尚未生起，所以有时可得；已生之行即由此无可分别；未来没有相，过去可以分别，曾经历的与未曾经历的都可分别。诸行虽无开始，却有新起的开始可得。）

```
诸色如聚沫　诸受类浮泡
诸想同阳焰　诸行喻芭蕉
诸识犹幻事　曰亲之所说
诸行一时生　亦一时住灭
```

（大意：色如聚沫，受如浮泡，想如阳焰，行如芭蕉，识如幻事，这是日亲之族所说。诸行同时生起，也同时住、灭。）

```
痴不能痴痴　亦不能痴彼
非余能有痴　而愚痴非无
不正思惟故　诸愚痴得生
此不正思惟　非不愚者起
福非福不动　行又三应知
复有三种业　一切不和合
现在速灭坏　过去住无方
未生依众缘　而复心随转
毕竟共相应　不相应亦尔
非一切一切　而说心随转
于此流无断　相似不相似
由随顺我见　世俗用非无
```

（大意：痴不能痴于痴，也不能痴于他，没有其余能痴的，然而愚痴并非没有。由于不正思惟，诸愚痴得以生起；而这不正思惟，也不是不愚痴的人所起。福、非福、不动三种行，又有三世，以及三种业，一切都不和合。现在迅速灭坏，过去住无方所，未生依于众缘，却说心随之而转；无论毕竟相应或不相应，都不是一切与一切，而说心随转。在这相似、不相似的流转中没有断绝，由于随顺我见，世俗的作用并非没有。）

```
若坏于色身　名身亦随灭
而言今后世　自作自受果
前后差别故　自因果摄故
作者与受者　一异不可说
因道不断故　和合作用转
从自因所生　及摄受所作
乐戏论为因　若净不净业
诸种子异熟　及爱非爱果
```

（大意：如果色身坏了，名身也随之灭去，却说今世后世自作自受其果。由于前后差别，由于自身的因果所摄，作者与受者是一是异都不可说。由于因的道路不断，和合的作用运转；从自因所生，以及由摄受所作。以乐著戏论为因，与净不净业一起，有诸种子与异熟，以及可爱与不可爱的果。）

```
依诸种异熟　我见而生起
自内所证知　无色不可见
无了别凡夫　计斯为内我
我见为依故　起众多妄见
总执自种故　宿习助伴故
听闻随顺故　发生于我见
贪爱及与缘　而生于内我
摄受希望故　染习外为所
```

（大意：依于诸种子与异熟，我见得以生起；它是自内所证知，无色而不可见。不能了别的凡夫，计执它为内在的我；以我见为依，生起众多妄见。由于总执自种，由于宿习与助伴，由于随顺所听闻，发生我见。由于贪爱及其助缘，生起对内我的执著；由于摄受与希望，染习外物为我所。）

```
世间真可怖　愚痴故摄受
先起爱藏已　由兹趣戏论
彼所爱藏者　贤圣达为苦
此苦逼愚夫　刹那无暂息
不平等缠心　积集彼众苦
积集是愚夫　计我苦乐缘
诸愚夫固著　如大象溺泥
由痴故增上　遍行遍所作
此池派众流　于世流为暴
非火风日竭　唯除正法行
```

（大意：世间真正可怖的，是由于愚痴而摄受，先起爱藏，由此趣入戏论。他所爱藏的，贤圣通达为苦；这苦逼迫愚夫，刹那没有暂息。不平等之缠缚其心，积集那众苦；积集之后，愚夫以之为计我与苦乐之缘。诸愚夫固著于此，如大象陷没于泥中。由于愚痴，这苦是增上、遍行、遍所作的；如同这池分出众流，于世间之流最为暴恶，不是火、风、日所能竭尽，唯有正法之行能使之干涸。）

```
于苦计我受　苦乐了知苦
分别此起见　从彼生生彼
染污意恒时　诸惑俱生灭
若解脱诸惑　非先亦非后
非彼法生已　后净异而生
彼先无染污　说解脱众惑
其有染污者　毕竟性清净
既非有所净　何得有能净
诸种子灭故　诸烦恼尽故
即于此无染　显示二差别
自内所证故　唯众苦尽故
永绝戏论故　一切无戏论
众生名相续　及法想相中
无生死流转　亦无涅槃者
```

（大意：在苦中计执我为受者，了知苦乐皆是苦；由分别于此生起诸见，从诸见所生又生起分别。染污意恒时与诸烦恼俱生俱灭；解脱诸烦恼时，非先亦非后。并不是那法生起之后再清净，另有清净之意生起；它本来没有染污，所以说解脱众惑。那有染污的，本性毕竟清净；既然没有所净，哪里有能净。由于诸种子灭、诸烦恼尽，即在此显示无染，显示烦恼解脱与事解脱二种差别。由于自内所证，由于唯是众苦尽，由于永绝戏论，一切都无戏论。在众生之名的相续以及诸法之想相中，没有生死流转，也没有涅槃者。）

#### 建立胜义伽他：长行解释

这里，是依止补特伽罗无我的胜义，宣说这样的胜义伽他，为了对治增益、损减二边的执著。

对于所摄受的说为宰主，对于诸业用说为作者，对于诸果报说为受者。这半颂，遮遣在诸法之外别有一义所分别的我。“诸法亦无用”，遮遣就在诸法上所分别的我。由此远离增益边的执著。“而用转非无”，显示法有其性；由此远离损减边的执著。用有三种：一是宰主之用，二是作者之用，三是受者之用。由于这些用，假立宰主、作者、受者。

虽然说了诸法，而尚未宣说什么是法，所以接着说“唯十二有支”等半颂。如有支的次第，诸蕴等流转，这显示不取微细的众多之我，便能对治宰主、作者以及受者的执著。以眼与色为缘，生起眼识之果，另外没有受者。这里显示，就在十八界上说受者之性。虽然说没有主，而尚未宣说没有什么样的主，为了显示，所以接着说：“审思此一切，众生不可得。”所说的审思，是依于三量审谛观察。

如果这没有，如何建立内与外的成就？所以接着说：“于内及于外，是一切皆空。”这显示内外唯是假立。

如何建立能观与所观两种成就？所以接着说：“其能修空者，亦常无所有。”

如何建立圣者与异生两种成就？所以接着说：“我我定非有，由颠倒妄计。”这显示圣者以及异生之我，决定没有真实的我性，唯由颠倒妄计为有。

如何建立彼此的成就？所以接着说：“有情我皆无。”

如何建立染与净的成就？所以接着说：“唯有因法有。”染者、净者都不可得。

虽然说诸法都没有作用，而尚未宣说怎样没有作用，所以接着说：“诸行皆刹那，住尚无况用。”如前面已说作用的运转并非没有，如何没有作用而有作用的运转？所以接着说：“即说彼生起，为用为作者。”由于是果，所以名为用；由于是因，所以名为作者。“彼生起”，显示从诸处有诸识得以生起。它得以生起，并不是离开眼等而能成就。

如前面所说诸法没有作用，这显示没有作用略有七种：第一，没有作用之用，就是眼不能见色等。第二，没有随转之用，就是“于此亦无能任持驱役者”；依其次第，宰主、作者都无所有，所以没有能随转的作用。第三，没有生他之用，就是法不能生他。第四，没有自生之用，就是也不能自生。第五，没有移转之用，就是“众缘有故生，非故新新有”。第六，没有灭他之用，就是法不能灭他。第七，没有自灭之用，就是也不能自灭。

问：如众缘具有所以生起，也是众缘具有所以灭去吗？

答：众缘具有所以生起，生起之后自然灭去。

如前面所说“唯有因法有”，为了显示在家以及出家的杂染自性是有因之法而有，所以接着说“由二品为依，是生便可得”等。由这两颂，显示无明与爱是有因之法而有。

其次后面五颂，显示杂染品差别的所依、因以及时分。这里，“有因诸法”，就是无明乃至受。有因的众苦，就是爱乃至老死。这话显示烦恼、业、生三种杂染。

“根本二惑故”，这话显示烦恼杂染，唯取最殊胜的烦恼杂染。“自无能作用”等言，又重新分别显示业杂染的意义，由于它所作有差别，由于它的果报异熟不可思议。“自无能作用”，是由于要依待善恶之友，被他人所引。“亦不由他作”，是由于要依待自己的功用所成办。“非余能有作”，是由于要依待前生之因的差别，才有所作。

“非内亦非外”等颂中，显示依于未来，不生杂染；依止现在、过去的诸行，能生杂染。假设诸行已经生起，就由此相而没有分别；未来没有相，所以没有分别，因为如此如此当来之事决定不可知。如果不是这样分别，异类有时可得。如果对于过去，就可以分别，因为如此如此曾有的相貌可以分别。不只是曾经经历的可以分别；未曾经历的，虽然不能分明地取其相貌，然而随其种类也可以分别。这就显示，依于对现在之行的分别为因，生起诸杂染。“行虽无有始，然有始可得”，显示杂染时分的差别：因为从无始时来常相随逐，因为刹那刹那新近所起。

自此以后，显示清净品，因为如实观察时得以清净。或者由于自相，就是观察色等如聚沫等。或者由于共相，就是观察有为法同有生、住、灭的所有共相。或者由于世俗谛与胜义谛，就是虽然没有痴者，并非没有愚痴；由于众缘所生的世俗谛，说痴能痴。又显示并不是不愚痴的人会不正思惟，所以他是被愚痴所痴。又由于世俗，宣说诸识随福等行而转；如果就胜义，就没有所随逐的。

“又三应知”，就是过去、未来、现在。“三种业”，就是身等业。“一切不和合”，是由于互相对望都不和合。为什么呢？“现在速灭坏，过去住无方，未生依众缘，而复心随转。”如果那与这互相相应，如福等行没有和合，那心相应的道理也是如此，怎么会有真实的随转之性？为什么呢？如果心与那些诸行相应，或者不相应；并不是这与那有时不相应，有时又并非不相应。又并不是一切心或者相应，或者不相应。像这样，由于胜义，心的随转之性不能成就。现在应当显示由于世俗说心随转的所有因缘。

“于此流无断”，现在这颂中，显示世俗谛并非没有作用以及随转。又由于胜义，没有作者以及受者；由于世俗，才得以宣说自作自受。又，作者、受者或一或异都不可说；为了显示这个意义，所以接着说“前后差别故”等颂。

像这样，由于胜义，没有宰主、作者、受者，唯有因果。对于因果之相解释疑难，略由五颂，显示在这里生起我的颠倒。第一颂显示：虽然没有我，而有后有，没有断绝；又诸因果不是顿时同时都有；不是从一切生出一切；又这因的道路没有断绝。颂中四句，依其次第解释这四个疑难。

由第二颂，显示因果之相。由后三颂，显示在无我的诸因果中生起我的颠倒。这里显示它的所缘境、它的所依止、它的因、它的果。

第一颂显示它的所缘境：自内所证，无色而难见，难以寻思，所以名为无色，因为经中说色相是为了寻思；难以说示于他人，所以不可见。

由第二颂，显示它的所依与果：凡夫是所依，众见是果。

由第三颂，显示它的因：俱生的我见，由总执自身种子的随眠所生起。诸外道等分别所起的我见，由宿习等所生起。这外道之见，必须由于数数串习，由于不正寻思，又由于得以随顺从他人听闻非正法，才得以生长。这里显示由于所依止、作意、所缘诸过失，分别所起的我见才得以生起。

其次后面五颂，显示那我见由集的次第发生苦；又显示这苦与我见是两种苦的因缘；又显示它对于解脱能作障碍。这里第一颂，显示集。第二、第三颂，显示行苦所摄的阿赖耶识：爱藏这阿赖耶识之后，便趣入戏论，就是“我当有”“我当无”等。所说的爱藏，是因为摄为自己的体。又这苦在一切时恒常随逐，没有一刹那暂时止息。由第四颂，显示这苦是能计我以及苦乐的缘。由第五颂，显示计我由于愚痴，障碍解脱。所说的“增上”，是相对于其余两种苦而说。所说的“遍行”，是由于随逐诸受。“遍所作”，是由于遍于善、恶、无记。

现在应当显示阿赖耶识所摄的行苦与其他相似，又显示它的差别：由于唯有正法之行才能使之竭尽，所以在世间众流中最为暴恶。所说的众流，比喻眼等六处、五趣、三界等。

又，“法行”，显示解了解脱的遍知以及系缚的遍知。

解了系缚的遍知，就是了知苦，就是了知我所受的苦受与乐受，都依于苦。又这分别能生起诸见；从它所生的诸见，也能生起分别。

显示解了系缚的遍知之后，其余六颂，显示解了解脱的遍知，就是“染污意恒时，诸惑俱生灭；若解脱诸惑，非先亦非后”等。非先，是由于与诸烦恼恒常俱生。非后，是由于就与那烦恼同时灭去。又显示所说的解脱之相，就是并不是那染污意生起之后才清净，另有其余的清净之意生起；而是由于它从来没有染污，说为解脱。为了成立这个意义，所以又说“其有染污者，毕竟性清净”等颂。

又显示两种解脱，就是烦恼的解脱以及事的解脱。“诸种子灭故，诸烦恼尽故”，显示烦恼的解脱。“即于此无染”，显示事的解脱，如经中说：苾刍应当知道！如果对于眼中的贪欲永断，这样这眼也应当永断，乃至广说。

像这样显示有余依的解脱之后，其次应当显示无余依的解脱。“自内所证”，显示它不可思议。“唯众苦尽”，是为了遣除妄计唯是无性的执著，就是由于有余依永远寂灭，说为寂灭，而不是完全无性。“无戏论”，这解脱之性唯是内在所证；是异还是不异、死后当有还是当无等一切戏论都不能说。为了显示补特伽罗以及法，都不是流转生死或者般涅槃，所以又颂说：“众生名相续，及法想相中，无生死流转，亦无涅槃者。”


#### 建立意趣义伽他：举颂

已经解释了胜义的圣教伽他，其次应当建立意趣义的伽他。如经中说：有一时，索诃世界之主大梵天王来到世尊之所，顶礼佛足，退坐一面，以美妙的伽他赞叹请问说：

```
于学到究竟　善断诸疑网
今请学所学　修学为我说
```

（大意：您于学已到究竟，善断一切疑网；现在请您为我宣说什么是学、所学有几种、应当如何修学。）

```
大仙应善听　学略有三种
增上戒心慧　于彼当修学
应圆满六支　四乐住成就
于四各四行　智慧常清净
```

（大意：世尊答：大仙应当善听，学略有三种，就是增上戒、增上心、增上慧，应当于此修学。应当圆满戒的六支，成就四种乐住，对于四谛各修四种行相，智慧常得清净。）

```
初善住根本　次乐心寂静
后圣见恶见　相应不相应
先净乐静虑　及于谛善巧
即于诸谛中　应生远增长
于诸学处中　有四趣三所
远离于二趣　于二趣证得
二安住二种　一能趣涅槃
渐次为因缘　纯杂而修习
```

（大意：先善住于根本之戒，其次乐于心的寂静，最后与圣见相应、与恶见不相应。先是戒的清净，其次乐于静虑，以及善巧于诸谛，于诸谛中应生起、应远离、应增长。在三种学处中，有四种趣；应远离前二趣，证得后二趣。前二学能作为后二学的安住，一学能趣向涅槃；渐次作为因缘，或纯或杂而修习。）

```
最先离恶作　最后乐成满
诸学是为初　于此学聪叡
由此智修净　净生乐成满
诸学是为中　于此学聪叡
从此心解脱　永灭诸戏论
诸学是为尊　于此学聪叡
```

（大意：最先远离恶作，最后乐于成满，这是诸学之初；由此智慧修习清净，清净生起，乐于成满，这是诸学之中；从此心得解脱，永灭诸戏论，这是诸学之尊；对于这些学都应聪慧。）

```
若行趣不净　亦趣于善趣
是行说为初　当知此非共
若行趣清净　非诸趣究竟
是行说为中　当知亦非共
若行趣清净　于诸趣究竟
是行说为尊　当知此必共
若有学无学　当知并聪叡
若有学无学　当知并愚夫
```

（大意：若所行可趣向不净，也可趣向善趣，这行说为初学，应知它与后二学不共。若所行趣向清净，却未于诸趣究竟，这行说为中学，也非与初学不共。若所行趣向清净，又于诸趣究竟，这行说为尊，应知它必与前二学共。有学与无学，都应知是聪慧者；有学与无学，也都可能是愚夫。）

```
若弃舍摄受　亦断除麁重
及现见所知　是受持三学
若有缘无缘　亦细麁显现
由受持远离　言发悟所引
初学唯有一　第二学二种
第三学具三　慧者皆超越
```

（大意：若能舍弃所摄受，断除粗重，现见所知，这就是受持三学。三学或有缘或无缘，或细或粗而显现；由受持誓愿、由身心远离、由他人之言与自身觉悟所引生。初学唯有一种，第二学有两种，第三学具足三种；有智慧的人超越这一切。）

```
不毁坏尸罗　于学誓能顺
轨范无讥论　于五处远离
若无犯出离　无恶作恶作
于彼学寻求　及勤修彼行
终无有弃舍　命难亦无亏
常住正行中　随毘柰耶转
修治誓为先　亦修治净命
二边皆远离　亦弃舍邪愿
于诸障碍法　终无有耽染
乱心法才生　寻当速远离
非太沈太浮　恒善住正念
根本眷属净　而修行梵行
```

（大意：不毁坏尸罗，于学誓愿能顺，轨范没有讥议，远离五种不应行之处；无犯而出离，无恶作亦无所犯；对彼学处寻求而勤修其行；终不舍弃，遇命难也不亏损；常住于正行之中，随毗奈耶而转。以誓愿为先修治轨范，也修治清净的活命；远离两边，舍弃邪愿；对于诸障碍之法终不耽染，散乱心法刚一生起，随即迅速远离；不太沉也不太浮，恒常善住正念，根本与眷属都清净，而修行梵行。）

```
应发勤精进　常坚固勇猛
恒修不放逸　五支善安住
当隐自诸善　亦发露众恶
得诸衣服等　麁妙皆欢喜
少随于世务　麁弊亦随转
受杜多功德　为寂离烦恼
当具足威仪　应量而摄受
终无有所为　诈现威仪相
不自说实德　亦不令他说
虽有所方求　而非现异相
从他边乞求　终不强威逼
以法而获得　得已不轻毁
```

（大意：应当发勤精进，恒常坚固勇猛，常修不放逸，善住于五支。应当隐藏自己的善，发露自己的恶；得到衣服等，粗与妙都欢喜；少随世务，粗弊之物也能随顺；受持杜多功德，为了寂静、远离烦恼。应当具足威仪，适量摄受；终不为了有所图而诈现威仪之相；不自说实德，也不令他人说；虽有所求，而不现异相；从他人乞求，终不强行威逼；如法获得，得了不轻毁。）

```
不耽著利养　及所有恭敬
亦不执诸见　增益与损减
不著顺世间　无义文呪术
亦不乐畜积　无义长衣钵
恐增诸烦恼　不染习居家
为净修智慧　当亲近贤圣
不畜朋友家　恐发忧悲乱
能生苦烦恼　才起寻远离
不受于信施　恐加害疮疱
于如来正法　甞无有弃舍
于他愆犯中　无功用安乐
常省自过失　知已速发露
若犯于所犯　当如法出离
所应营事中　能勇励自作
```

（大意：不耽著利养与恭敬，也不执取增益与损减的诸见；不著于随顺世间、无义的文辞与咒术，也不乐于积蓄无义的多余衣钵。恐怕增长烦恼，不染习在家生活；为了清净修习智慧，应当亲近贤圣。不亲近蓄养在家朋友之家，恐怕引发忧悲散乱，能生众苦与烦恼；烦恼才生起，随即远离。不受信施，恐如疮疱被加害；对于如来的正法，从未舍弃。对于他人的过犯，不作意寻觅，自于善品安乐；常省察自己的过失，知道了迅速发露；若犯了所犯，应当如法出离；对于所应营办之事，能勇励亲自去作。）

```
于佛及弟子　威德与言教
一切皆信受　观大罪不谤
于极甚深法　不可思度处
能舍旧师宗　不坚执自见
常乐居远离　及边际卧具
恒修习善法　坚精进勇猛
无有欲生欲　不憎恶憎恶
离睡眠睡眠　时不居寂静
离恶作恶作　无希虑希虑
一切种恒时　成就正方便
```

（大意：对于佛及弟子的威德与言教，一切都信受，观察诽谤的大罪而不诽谤。对于极甚深、不可思度之处，能舍弃旧师的宗派，不坚执自己的见解。常乐住于远离之处及边远的卧具，恒常修习善法，坚固精进勇猛。没有欲而生欲，不憎恶而憎恶，离睡眠而睡眠，有时不住于寂静，离恶作而恶作，无希虑而希虑——在一切种类、一切时中成就正确的方便。）

```
引发与觉悟　及和合所结
有相若亲昵　亦多种喜乐
侵逼极亲昵　名虚妄分别
能生于欲贪　智者当远离
诸欲令无饱　众多所共有
是非法因缘　能增长贪欲
贤圣所应离　速趣于坏灭
仗托于众缘　危逸所依地
诸欲如枯骨　亦如软肉段
如草炬相似　犹如大火坑
譬如蟒毒蛇　亦如梦所见
如借庄严具　如树端熟果
如是知诸欲　都不应耽乐
```

（大意：引发、觉悟、和合所结、有相、亲昵、多种喜乐、侵逼、极亲昵，名为虚妄分别，能生欲贪，智者应当远离。诸欲令人不能满足，为众人所共有，是非法的因缘，能增长贪欲，为贤圣所应远离，迅速趋于坏灭，依托于众缘，是危险放逸的所依之地。诸欲如枯骨，如软肉段，如草炬，如大火坑，如蟒与毒蛇，如梦中所见，如借来的庄严具，如树梢的熟果。这样了知诸欲，都不应耽乐。）

#### 建立意趣义伽他：长行解释

“于学到究竟，善断诸疑网，今请学所学，修学为我说”，在这颂中，大梵天王先赞叹世尊，后兴起请问。

赞叹世尊，就是在一切学中，已得第一究竟，这是依自利之行圆满的不共功德而说；又能善断辗转所生的一切疑网，这是依利他之行圆满的不共功德而说。

兴起请问，就是：什么是学？学有几种？应当如何于学修学？

所以世尊的意思，是为了策励那些怖畏多所作为的懈怠众生，总摄一切，略说三学。所以接着告诉他说：“大仙应善听！学略有三种：增上戒、心、慧，于彼当修学。”这里显示依于戒、心、慧：如果是散乱的人，为了使他不散乱，方便为他说增上戒学；心未定的人，为了使他得定，方便为他说增上心学；心已得定而尚未解脱的人，为了使他解脱，方便为他说增上慧学。由于这个因缘，诸修行者一切所作都得以究竟。这显示世尊以密意宣说一切诸学，无不摄在这三学之中。

又为了显示在诸学中由这样的方便成办所学，所以接着说：“应圆满六支，四乐住成就，于四各四行，智慧常清净。”

现在这颂中，依其次第，显示成办三学的方便。“应圆满六支”，是应当依增上戒学的方便修学。是哪六支？一是安住清净尸罗，二是守护别解脱律仪，三是轨则圆满，四是所行圆满，五是对于诸小罪见大怖畏，六是受学学处。这六支，显示四种尸罗清净：安住清净尸罗，是所依的根本。守护别解脱律仪，显示出离的尸罗清净，因为是为了求解脱而出离。轨则、所行都圆满，这两者显示无所讥毁的尸罗清净。对于诸小罪见大怖畏，显示没有穿缺的尸罗清净。受学学处，显示没有颠倒的尸罗清净。由于这六支极为圆满，增上戒学为其余的方便作所依止。

“四乐住成就”，显示增上心学的方便：四种静虑，名为四种心住；由于是现法乐住，所以名为乐。

“于四各四行，智慧常清净”，是依增上慧学而说，就是在苦、集、灭、道四圣谛中，每一谛都有四种行相，即无常等。增上慧学由这清净之智所显示。

“初善住根本，次乐心寂静，后圣见恶见，相应不相应”，这颂显示增上三学次第生起。根本，就是增上戒，因为后两种是这初学所流出的同类。既已具足尸罗，由无悔等次第修习，能得到第二种心乐静定。心得定的人，由于见到如实，能得到第三种成就圣见，远离恶见。

“先净乐静虑，及于谛善巧，即于诸谛中，应生、远、增长”，这颂显示三学次第清净的差别。“先净”，是初学。“乐静虑”，是第二学。“于谛善巧”，是第三学。又在这样的谛善巧中，“应生”，就是道谛，因为应当生起。“应远”，就是苦谛、集谛，因为应当远离。“应增长”，就是灭谛，因为软、中、上品的烦恼依次数数渐断，灭不断增长。

“于诸学处中，有四趣三所，远离于二趣，于二趣证得”，这颂显示在增上戒、心、慧学处中，由于所修学有成有败，随其所应所得果报的四趣差别。就是在欲界人、天所摄的所有善趣，是增上戒成就所得的果；就在欲界其余趣所摄的所有恶趣，是增上戒毁败所得的果。色界、无色界天趣所摄的所有上趣，是增上心的果。三界所不摄的涅槃趣，是增上慧的果。在这些诸趣中，远离前两种善趣、恶趣之后，应当证得后两种上趣以及涅槃趣。这话显示世间与出世间两种道所得的果。

“二安住二种，一能趣涅槃，渐次为因缘，纯杂而修习”，在这颂中，显示最初的增上戒学、增上心学，渐次能作为增上心学、增上慧学的安住因缘；显示中间的增上慧、静虑律仪所摄的增上戒学，能作为两种的安住因缘；显示最上一种，能作为涅槃的安住因缘。应当知道这里显示修习或别或总，随其所应。

“最先离恶作，最后乐成满，诸学是为初，于此学聪叡”，这颂显示由于增上戒学，以无悔等渐次修习，作为后面转进的因。

“由此智修净，净生、乐成满，诸学是为中，于此学聪叡”，这颂显示由于增上心学，修所成慧最殊胜的善根渐次生起，作为最上之学的因。

“从此心解脱，永灭诸戏论，诸学是为尊，于此学聪叡”，这颂显示由于增上慧学，能作为最殊胜的涅槃之果的因。

“若行、趣不净，亦趣于善趣，是行说为初，当知此非共”，这颂显示增上戒学如果有毁败，是恶趣的因；如果能成立，是善趣的因。这是不共的，因为离开后两种学也能成立。

“若行、趣清净，非诸趣究竟，是行说为中，当知亦非共”，这颂显示中间的学行，由于离开欲界之欲得以清净，所以名为趣向清净；由于尚未能完全离开上界之欲，也尚未永拔欲的随眠，所以不得名为在诸趣中究竟清净。这离开最上之学也能成办，所以名为不共，但不能离开最初之学。

“若行、趣清净，于诸趣究竟，是行说为尊，当知此必共”，这颂显示最上的学行，由于三界诸欲都已远离，也能永拔诸随眠，所以在诸趣中最为究竟。由于不离前两种学而能单独成办，所以名为必共。

“若有学、无学，当知并聪叡”，这前半颂，显示在三学中聪慧者之相，因为有正确的学，没有邪的学。

“若有学无学，当知并愚夫”，这后半颂，显示在三学中愚夫之相，因为有邪的学，没有正确的学。

“若弃舍摄受，亦断除麁重，及现见所知，是受持三学”，这颂显示：如果能弃舍家宅亲属等所摄受的，如果能断除三摩地之障的诸粗重，如果能现见四圣谛之相所知的道理，依其次第，三学得以成满。

“若有缘、无缘，亦细、麁显现”，这前半颂，显示后两种学以及最初之学，依其次第，有有缘、无缘、细、粗的差别。

“由受持远离，言发悟所引”，这后半颂，显示初、中、后学依其次第的引发因缘：就是由誓愿期约所引，由身心远离所引，由他人言音与内心正确思惟所引。

“初学、唯有一，第二学、二种，第三学、具三，慧者皆超越”，这颂显示：最初一种不共，中间的不离最初，最上的不离前两种。超越那一切的，应当知道是无学的阿罗汉。

“不毁坏尸罗，于学誓能顺，轨范无讥论，于五处远离”，此后显示受持戒的相。“不毁坏尸罗于学”，就是安住于清净之戒。“誓能顺”，就是守护别解脱律仪。“轨范无讥论”，就是轨则没有违犯。“于五处远离”，就是所行没有违犯。略有五处，是诸苾刍等所不应行的，就是王家、唱令家、酤酒家、倡秽家、旃荼罗以及羯耻那家。唱令家，就是屠羊等之家；由于普遍宣告这屠羊等事，成为极重之罪，多造恶业，杀害羊等。

“若无犯、出离，无恶作、恶作”，显示对于诸小罪见大怖畏：如果如法出离，也就没有恶作；如果有恶作，也就没有所犯。

“于彼学寻求，及勤修彼行”，显示受学学处。

“终无有弃舍，命难亦无亏，常住正行中，随毘柰耶转”，这颂四句，依其次第显示恒常的尸罗之性、坚固的尸罗之性、恒常所作之性、恒常随转之性。

“修治誓为先，亦修治净命”，这前半颂，显示轨范以及活命的清净。由于诸轨范要先发誓愿，然后才修行，所以名为誓。

“二边皆远离，亦弃舍邪愿”，这后半颂，显示由于远离受用欲乐与自我苦行两边，以及舍弃求生天等愿，尸罗得以清净。

“于诸障碍法，终无有耽染，乱心法才生，寻当速远离”，这颂显示：对于不守护根门等障碍清净所学的法，不见其功德，没有耽染；对于诸不善的欲寻、恚寻等扰乱心意之法，虽然暂时生起，随即除遣；所以学得清净。

“非太沈、太浮，恒善住正念，根本眷属净，而修行梵行”，这颂显示：由于远离微劣的恶作，由于远离非处的恶作，由于远离失念，在究竟之时以及方便之时，修行梵行都得清净。

瑜伽师地论卷第十六

## 本卷要义

思所成地以三门建立：自性清净、思择所知、思择诸法。九相清净的思惟，第二条“远离一切不思议处，审谛思惟所应思处”，第四条“唯依于义，不依于文”，第五条“于法少分唯生信解，于法少分以慧观察”，都是思惟佛法的基本态度——有些法只能信解，有些法必须观察，智者知道其中的分寸。

思择所知中的五种有法与五种无法，特别是“假相有法”的六种言论，把假有的判别标准具体化：凡是需要配属于主才能理解的、以此显彼而非以此显此的、众共施设的、众法聚集的、不遍一切的、会随破坏转变而改名的，所指的都是假有。这为后来唯识学分析假有与实有提供了切实可用的工具。五种有性以三自性为首，加上差别相与不可说相；不可说相又分无故、甚深故、引无义故、法尔故四种，真如与诸行“不可宣说异不异性”一句，正是唯识学二谛关系的精要。

本卷的核心是胜义伽他四十四颂及其解释。颂文以“都无有宰主，及作者受者；诸法亦无用，而用转非无”开篇，一边遮遣增益之执，一边遮遣损减之执，贯穿全篇的就是这“无作用而用转非无”的中道。颂中明确说到“依诸种异熟，我见而生起”“染污意恒时，诸惑俱生灭”，长行解释为阿赖耶识被爱藏为我、染污意与诸惑俱生俱灭——这是本论中阿赖耶识与末那识最集中、最明确的早期表述之一。解脱一段说：染污意并不是灭后另生一个清净意，而是“彼先无染污，说解脱众惑”，“其有染污者，毕竟性清净”。这与如来藏、本性清净的思想遥相呼应，而又牢牢立足于缘起。最后以“众生名相续，及法想相中，无生死流转，亦无涅槃者”作结，在胜义上，人与法都无流转与涅槃可说。

意趣义伽他共五十一颂，首颂是大梵天王请问学与所学，其余是世尊的回答；本卷长行解释到受持戒相为止，其余在下卷继续。三学之间“初学唯有一，第二学二种，第三学具三”的关系，以及“此非共”“亦非共”“此必共”的分辨，把戒、定、慧相互依存而又各有其独立作用的道理讲得极为清楚。
