# 《大宝积经》卷第七十五（菩萨见实会·六界差别品之三、四转轮王品之一）

北齐·三藏那连提耶舍 译

## 菩萨见实会第十六之十五

### 六界差别品第二十五之三

#### 身触恐惧：梦缠热铜叶喻

“大王！如人在梦中自己拿着灼热的铜叶缠裹其身。此人醒后，忆念梦中所披的铜叶。你认为怎样？此人所梦的是真实的吗？”王说：“不是的。”“大王！你认为怎样？此人把所梦执以为真实，这是智慧吗？”王说：“不是的，世尊！为什么呢？梦中毕竟没有铜叶，何况用来披在身上。此人只是白白疲劳，全无真实。”

【按】“铜鍱”之“鍱”，宋、元、明、宫、圣本作“叶”。

佛说：“大王！同样，愚痴无闻的凡夫，见到恐惧之事心生执著，生执著后生起怖畏，生起怖畏后作怖畏之业，就是身三种、口四种、意三种业。造了那业之后便即谢灭，这业灭了之后，不依于东方而住，也不依于南、西、北方、四维、上下而住。这样的业，乃至临死之时最后识灭，见到先前所作，在心想中显现。大王！此人见后心生慌乱恐惧，自身这一分的业已尽，另一业现前。大王！犹如梦醒后忆念梦中之事。像这样，大王！以最后识为主，以那业为因缘，以这两种缘，在受生的一分之中，识心初起，或生于地狱，或生于畜生，或生于阎魔罗界，或生于阿修罗，或生于天中，或生于人中。前识既已灭去，受生之识生起，受生相续，心的种类不断绝。

【按】“起怖畏已”之“起”，宋、元、明、宫、圣本作“于”。

“大王！没有一法从今世到后世而有生灭，见到所作之业以及所受果报，都不失坏，没有作业者，也没有受报者。大王！那最后识灭时，名为入于死之类；若初识生起，名为入于生之类。大王！那最后识生起时无所从来，到它灭时也无所至。其缘生起时也无所从来，灭时也无所至。其业生起时也无所从来，灭时也无所至。死时也无所从来，灭时也无所至。初识生起时也无所从来，灭时也无所至。其生也无所从来，灭时也无所至。为什么呢？因为自性远离。那最后识、最后识的体性空，缘、缘的体性空，业、业的体性空，死、死的体性空，初识、初识的体性空，受生、受生的体性空，世间、世间的体性空，涅槃、涅槃的体性空，起、起的体性空，坏、坏的体性空。

“大王！像这样，作业与果报都不失坏，没有作业者，没有受报者，只是随顺世俗而有，不是第一义。大王应当知道，一切诸法都是空寂，一切诸法空，这是空解脱门；空无空之相，名为无相解脱门；若无相，便无愿求，名为无愿解脱门。像这样，大王！一切法都具足三解脱门，与空同行，是涅槃的先导之道，远离相，远离愿求。究竟于涅槃界，决定如同法界，周遍虚空边际。大王应当知道，诸根如幻，境界如梦。一切譬喻都应当这样了知。

#### 身根坏喻

“大王！如人在梦中见到身根毁坏，不能觉知诸触。此人醒后，忆念梦中毁坏之相。你认为怎样？此人所梦的是真实的吗？”王说：“不是的。”“大王！你认为怎样？此人把所梦执以为真实，这是智慧吗？”王说：“不是的，世尊！为什么呢？梦中毕竟没有身根，何况毁坏。此人只是白白疲劳，全无真实。”

【按】“执谓为实”之“为”，明本作“真”。“愚痴无闻”之“无闻”，宫本作“无间”。

#### 意著五欲：梦幻师幻作五欲喻

“大王！如人在梦中梦见幻师幻作五欲，自己见到自身与那些五欲围绕，共相娱乐。此人醒后不见五欲，便忆念梦中五欲之乐。你认为怎样？此人所梦的是真实的吗？”王说：“不是的。”“大王！你认为怎样？此人把所梦执以为真实，这是智慧吗？”王说：“不是的，世尊！为什么呢？梦中毕竟没有幻师，何况幻作五欲，相互娱乐。此人只是白白疲劳，全无真实。”

#### 意生忧恼：梦大水漂荡喻

“大王！如人在梦中梦见大水漂荡，自身与妻子眷属被漂走之后，心中生起无量种种忧恼。此人醒后，忆念梦中被水所漂的忧苦之事。你认为怎样？此人所梦的是真实的吗？”王说：“不是的。”佛说：“大王！此人把所梦执以为真实，这是智慧吗？”王说：“不是的，世尊！为什么呢？梦中毕竟没有大水，何况漂荡而生大忧恼。此人只是白白疲劳，全无真实。”

#### 意生迷乱：梦饮酒惛醉喻

“大王！如人在梦中自己见到自身饮酒，昏醉而无所觉知，不识罪福、善恶、尊卑、优劣。此人醒后，忆念梦中饮酒迷乱。你认为怎样？此人所梦的是真实的吗？”王说：“不是的。”“大王！你认为怎样？此人把所梦执以为真实，这是智慧吗？”王说：“不是的，世尊！为什么呢？梦中竟然没有酒，何况饮后昏乱，不识尊卑、善恶、优劣。此人只是白白疲劳，全无真实。”

佛说：“大王！同样，愚痴无闻的凡夫，梦见饮酒昏醉，心生执著，生执著后生起染爱之心，生起染爱之心后作染爱之业，就是身三种、口四种、意三种业。造了那业之后便即谢灭，这业灭了之后，不依于东方而住，也不依于南、西、北方、四维、上下而住。这样的业，乃至临死之时最后识灭，见到先前所作，在心想中显现。大王！此人见后心生爱著，自身这一分的业已尽，另一业现前。大王！犹如梦醒后忆念梦中之事。像这样，大王！以最后识为主，以那业为因缘，以这两种缘，在受生的一分之中，识心初起，或生于地狱，或生于畜生，或生于阎魔罗界，或生于阿修罗，或生于天中，或生于人中。前识既已灭去，受生之识生起，受生相续，心的种类不断绝。

### 四转轮王品第二十六之一

#### 劝王系心观察

那时佛告诉净饭王说：“大王！如上所说之法，应当系心精勤，自己观察修行，不要随顺他人。此法是过去、未来、现在诸佛的菩提，能超越一切世间的自在，能除去一切渴爱，降伏我慢，灭除罪过，在一切诸法中得到平等。它不是凡夫之地，是一切声闻所不能到达的，不是一切辟支佛的境界，是一切菩萨所修行的，是一切诸佛所证得的。

“大王！在此法中应当安住心意，应当作这样的念头：‘我应当怎样在天人之中成为眼目，成为灯明，成为大火炬，成为船筏而善知水路，成为导师，成为商主，成为引导之首？我应当怎样自己得度后又能度他人，自己既已解脱，令他人解脱，自己得安隐，令他人安隐，自己证得涅槃，令他人得涅槃？’大王应当知道，不应观望过去世际所经历的豪富自在。大王！诸根如幻，没有满足之时，也没有能令其满足的人。境界如梦，对色、声、香、味、触没有厌足。

【按】“大炬”，宫本作“火炬”。“船筏”之“筏”，宋、元、明、宫本作“栰”。“所经”之“经”，圣本作“逕”。

#### 无量称王试福德力

“大王！过去世有一位转轮王，名为无边称大王。那无边称王具足无量众宝，辇舆、军众、象、马，无碍的轮宝，七宝具足，所有军队车乘无人能破坏。他在先佛之所种植诸善根，意力成就，随念即办。大王！那无量称王有所忆念，无不如意。为什么呢？因为具足成就了善根之力。

【按】王名此处作“无边称”，以下皆作“无量称”，原文如此。“殖诸善根”之“殖”，明本作“植”。

“大王！那时无量称王作这样的念头：‘我现在自己试一试福德之力。’这时无量称王便作这样的念头：‘以我的威力，令这四天下所有的树木常有花果，用之不尽。’大王！那无量称王作此念后，四天下所有的树林花果繁茂，用之无穷无尽。大王！无量称王又作这样的念头：‘令四天下所有人民，种种欲愿都随意而无违逆。’大王！那无量称王作此念后，四天下中一切人民的一切所愿都得到充满。大王！无量称王又作这样的念头：‘我当再试善根之力。若我有福，令四天下降注香水。’作此念后，四天下随即降下香雨。

【按】“作如是念”，元、明本作“即作是念”。“我今自试”之“我今”，元、明本作“以我”。

“大王！那时无量称王又作这样的念头：‘我现在当再自己试一试福力。’大王！这时无量称王便作这样的念头：‘若我有福力，令四天下普降妙花。’作此念时，四天下随即降下妙花。大王！那时无量称王又作这样的念头：‘我现在当再自己试一试福力。若我有福，令四天下普降妙衣。’作此念后，四天下随即降下天上的劫贝树衣。大王！那无量称王又作这样的念头：‘我现在自己试一试福力。若我有福，令四天下普降银雨。’作此念后，四天下随即降下银雨。大王！那无量称王又作这样的念头：‘我现在当再自己试一试福力。’又作这样的念头：‘若我有福，令四天下普降金雨。’作此念后，四天下随即降下金雨。为什么呢？无量称王所愿都能随意，都是由于过去对一切众生修习共业之善。

#### 宝庄严城的庄严

“大王！那时这阎浮提地纵广正等，一万八千由旬。在那时，这阎浮提有六十千万座大城郭。大王！那时在这阎浮提中建立一座有护城壕的城，名为宝庄严。那城纵广十二由旬，四面平正，精妙巧作而成，街巷庄严，界分分明。在那城外有多罗树七重行列，那些多罗树由四宝合成，就是金、银、琉璃、颇梨，庄饰端严，甚可爱乐。那金树，根、茎、枝条都是金，其叶、花、果都是白银。那银树，根、茎、枝条都是银，其叶、花、果都是黄金。毗琉璃树，根、茎、枝条都是琉璃，其叶、花、果都是颇梨。那颇梨树，根、茎、枝条都是颇梨，其叶、花、果都是毗琉璃。

【按】“颇梨”，明本作“玻瓈”。

“大王！那时那宝庄严城四周有七重悬挂的宝铃网，种种庄严，微妙第一，又以种种众宝罗网覆盖其上。在那城外有七重宝堑，那每一重堑深半由旬，宽一由旬。那七重堑的底与岸都平正，八功德水清净盈满，众鸟容易饮用。又有种种花，就是优钵罗花、拘物头花、波头摩花、分陀利花，充满其中。底下铺着金沙。那堑的四边周匝有阶道，以四宝庄严，就是金、银、琉璃、颇梨，种种微妙，甚可爱乐。那些阶道由四宝合成：黄金为阶，白银为踏级；白银为阶，黄金为踏级；琉璃、颇梨上下间错，交互庄饰。周匝的栏楯由七宝所成，端严无比。每一条阶道有七重宝门，种种庄严，微妙最上，每一条阶道两边都有金芭蕉树。那堑四边周匝的阶道，在其两头各有七宝妙座。那所有种种庄严，都是那无量称王的福德所致。

【按】“种种微妙”前之“颇梨”，宋、元、宫本作“玻𰢎”，明本作“玻瓈”。

“那宝庄严城外四周有八万座园林，无量称王建造这些园林，不起爱著我所之心，全都施予众生，共同受乐。每一座园林有八个大池，每一个大池纵广半由旬。在那池中有种种花，优钵罗花、波头摩花、拘物头花、分陀利花，这样的众花覆盖其上。每一个池边有八条阶道，每一条阶道由四宝所成，端严殊妙。那阶道头建有七宝幢门，就是金、银、琉璃以及玛瑙等。那阶道两边以阎浮檀金为芭蕉树，庄饰严丽。八功德水充满池中，众鸟可以饮用。那池的四边种植种种妙花，就是阿提目多伽花、薝卜花、阿输伽花、拘罗婆花、波吒梨花、迦腻迦罗花、婆拘罗花、婆利师迦花、末利迦花、苏摩那花、摩楼多花、池㝹师迦花。像这些陆地所生的花，无量称王为了令众人受适意之乐，种植这样种种妙花，那些人民在其中游戏，欢娱受乐。

【按】“众鸟堪饮”之“众”，宋、元、明、宫、圣本作“乌”。“池㝹师迦花”之“池”，明本作“陀”。“㝹”字先前电子文本未能显示，今据CBETA补出，《大正藏》作组字形。

“大王！那宝庄严城所有的宝铃、罗网、宝多罗树，微风吹动，发出和雅之音。譬如有人善于演奏五种微妙音乐，其声和雅，甚可爱乐。那无量称王所有宫城的铃网、宝树、园林、乐器所发出的妙音甚可爱乐，也是这样。大王！那时宝庄严王城中所有人民，以那妙音娱乐受乐。那时那宝庄严城丰乐安隐，人民充满，豪富自在。处处都有优钵罗花、波头摩花、拘物头花、分陀利花。

【按】“和雅音”之“雅”，圣本作“邪”。

#### 王巡三洲升忉利天

“大王！那无量称王又在另一时作这样的念头：‘我现在当前往西瞿陀尼。’作此念后，王以及四兵一起升入虚空，前往瞿陀尼。王到那里之后，那里的诸小王都来奉迎，各以国土奉献。大王！那时无量称王在那里住了百千万岁。在那里为王统领。大王！那无量称王又作这样的念头：‘我现在当前往东弗婆提。’作此念后，便与四兵一起升入虚空，前往弗婆提。王到那里之后，那里的小王也都来奉迎，又以国土奉上。大王！无量称王在那里住了百千万岁。在那里为王统领。大王！那无量称王又在另一时这样思惟：‘我当前往那北郁单越。’作此念后，便与四兵升上虚空，前往郁单越。王到那里之后，那里的人民欢喜归化。王在那里住了多百千岁。为王统领，受乐，教导自己的眷属。

【按】“各以国土”之“土”，宫本作“上”。

“大王！那无量称王在那里住了很久，又作这样的念头：‘我曾听说有三十三天住在须弥山顶，我现在应当前往忉利天上。’作此念后，便乘龙象，又与四兵飞升虚空，上须弥山。大王！那时无量称王便问驾驭的大臣：‘你看须弥山以及大海和四天下，情形怎样？’驾驭之臣回答王：‘我见须弥山以及大海水、四天下等都在旋转。犹如陶师用杖转轮，我见须弥山以及四天下都在旋转，也是这样。’王告诉驾驭之臣：‘这龙象王的大行进还未停止。’大王！那时无量称王又再前进，问驾驭之臣说：‘你看须弥山、大海以及四天下，又是怎样？’驾驭之臣回答说：‘我见须弥山以及大海水、四天下等都在振动。’王回答大臣说：‘现在将要到达须弥山顶。这龙象王的小行进还未停止。’大王！那无量称王又再前行，问驾驭之臣说：‘你看须弥山以及大海水和四天下，相状又是怎样？’驾驭之臣回答王：‘我见须弥山以及大海水、四天下等不动不转。’王告诉大臣说：‘这龙象王现在已到达那须弥山顶。’大王！那时无量称王以及四兵，随即到达那须弥山顶。

【按】“振动”之“振”，明本作“震”。“御臣答王”之“王”，明本作“言”。

“大王！那时帝释远远望见无量称王，欢喜来迎，这样说：‘善来，大王！’便分出半座，请王坐下。王便就座。在那天上经过无量岁，与那天主分半而治。大王！那时无量称王又过了很久，作这样的念头：‘我宁可让那天主退位，便住在其中，独自作天王。’作此念后，无量称王以及四兵，便从那三十三天退落，回到阎浮提的宝庄严城，堕落在七宝园中。

#### 堕落人间而命终

“那时宝庄严城中的人民出到城外，到宝箧园中，见到无量称王以及四兵从天而堕，在那园中。众人见后迅速入城，告诉城中的人这样说：‘现在有天子以及四兵从天而来，在宝箧园中。’那时宝庄严城中又有一位王，名为作爱，执掌国事。那作爱王听说有天子以及四兵从天而堕，在宝箧园中，听后迅速严令四兵驾御好车乘，与城中人一起从宝庄严城出来，前往宝箧园。王以及城中人见到无量称王，惊怪为前所未有。

“那时作爱王随即命令迅速备办种种香花、末香、涂香，急速来到无量称王之所，偏袒右肩，右膝著地，合掌长跪，向无量称王这样说：‘你是谁？’王便回答说：‘你从往昔以来，可曾听说过本来有一位无量称王吗？’那时作爱王以及诸臣民都说：‘我们往昔曾从先前的老人那里听说，本来有一位大王名为无量称，统领四天下，与他的四兵升上忉利天。’无量称王便回答他们说：‘如你们所听说的，无量称王就是我。’

【按】“颇曾闻本无量称王”之“本”，宋、元、明、宫本作“有”。“如汝所闻”之“闻”，宋、宫本作“问”。

“那时无量称王刚从天上下来，闻到那人间饮食的精气，心中不爱乐，不能堪忍，身体沉重昏沉，犹如醍醐投入热沙之中，随即沉没，不能暂停。无量称王对阎浮提的饮食诸味不生爱乐，身心沉没也是这样。那时作爱王见到无量称王不堪人间的香气饮食，身心顿时衰弊，不能支持，便这样说：‘无量称王有什么善言？我在来世当传说什么？’大王！那时无量称王告诉作爱王说：‘你现在应当知道，无量称王从往昔以来，统领四天下，威德自在，有所需求，无不随意：树林花果以及随意之果，能除一切众生的苦恼，随众生所需之物都令如意。我又能降下天香，降下天衣、天花，降下银雨、金雨，统领四天下，豪富自在。升上忉利天，帝释分座，共治天事。因为贪而无厌，所以从天上退落，下到阎浮提，于是便命终。’那时无量称王告诉作爱王说：‘如上述种种事，你在未来应当这样说：“无量称王豪富自在，贪求无厌，自取命终。”’说完这话便即命终。”

#### 佛示本生与说偈

佛说：“大王应当知道，不要作别的看法，不要生犹豫疑惑之心。那时的无量称王难道是别人吗？就是我自身。大王！所以应当知道，诸根如幻，境界如梦。大王！应当这样系心正观，不要相信他人。”那时世尊便说偈道：

```
常乐法自在，数数策其心，
贪欲自在中，智心应远离。
离欲自在已，住法自在中，
若能降伏心，则能伏烦恼。
若能降烦恼，即得离业道，
若离业道已，则为世间塔。
不为欲秽染，显示烦恼过，
念饶益众生，故号为支提。
```
（大意：常乐于法的自在，屡屡策励其心，对于贪欲的自在，智慧之心应当远离。离开欲的自在之后，安住于法的自在之中，若能降伏其心，便能降伏烦恼。若能降伏烦恼，便得离开业道，若离开业道之后，便成为世间的塔庙。不被欲的秽恶所染，显示烦恼的过患，念念饶益众生，所以号为支提。）

【按】“则为世间塔”之“则”，《大正藏》作“即”，今依CBETA（所录高丽藏）作“则”。

```
闻贪欲过已，便能离贪欲，
一切智净心，故号为支提。
最胜大丈夫，念灭众生恶，
解脱彼瞋恚，故号为支提。
最胜大丈夫，念灭众生痴，
脱彼愚痴心，故号为支提。
调御天人师，念灭众生慢，
净彼众生心，故号为支提。
```
（大意：听闻贪欲的过患之后，便能远离贪欲，具一切智的清净之心，所以号为支提。最胜大丈夫，念念灭除众生之恶，令他们解脱瞋恚，所以号为支提。最胜大丈夫，念念灭除众生之痴，令他们脱离愚痴之心，所以号为支提。调御天人之师，念念灭除众生之慢，清净那些众生之心，所以号为支提。）
