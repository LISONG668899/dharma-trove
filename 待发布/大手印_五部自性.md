# 五部自性

梅纪巴（吉祥无二金刚）造　据藏文译出

## 题解

《五部自性》（梵 Pañcasvabhāva，藏 rang bzhin lnga pa，直译"五种自性"；跋语称为《金刚萨埵五自性》）收于德格版丹珠尔续部释 ཝི 函第 134b 至 136b 页（东北目录 D2245），同属梅纪巴的"无念法类"。跋语说本论是应阿弥利达天（Amṛtadeva）的请求而造，没有记载译者。

与前面以见地为主的各篇不同，本论是一部简略的观修仪轨（成就法）：以"嗡阿吽"守护自身、处所与瑜伽之后，于坛城中央观想不动佛，其上有金刚萨埵；四方莲瓣上观想毗卢遮那、宝生、无量光、不空成就四佛；四隅观想佛眼、摩摩基、白衣、度母四位佛母。每一尊都配以种子字、身色、标帜、手印、五蕴、五智、部族、烦恼、季节、六味、时分、字母组等，并有持诵的咒语。

本论最重要的，是把这套观修与见地结合起来：作者反复说明，诸佛之身"离开孔窍、血肉与骨骼，只是明现，如镜中影像，非真亦非妄"；以三身来解释每一尊佛；并且以不动佛印定四佛，表示五蕴唯是识，再以金刚萨埵印定不动佛，表示识也无自性、即空悲无别——这与《五如来印释》的论点完全一致，可以对照着读。

下表依本论内容，把五佛的主要配对简列出来，便于对照：

| 方位 | 本尊 | 种子 | 身色 | 标帜 | 手印 | 蕴 | 智 |
|---|---|---|---|---|---|---|---|
| 中央 | 不动佛 | 吽 | 黑（种子为蓝） | 黑金刚杵 | 触地印 | 五蕴之本性 | 法界清净 |
| 东 | 毗卢遮那 | 嗡 | 白 | 白法轮 | 最胜菩提印 | 色蕴 | 大圆镜智 |
| 南 | 宝生 | 当（trāṃ） | 黄 | 宝 | 与愿印 | 受蕴 | 平等性智 |
| 西 | 无量光 | 舍（hrīḥ） | 红 | 莲花 | 禅定印 | 想蕴 | 妙观察智 |
| 北 | 不空成就 | 康（khaṃ） | 绿 | 剑 | 无畏印 | 行蕴 | 成所作智 |

本论是密乘的观修仪轨，所说的种子字、本尊、咒语、坛城等，必须在具德上师座前领受相应的灌顶与口授之后，才能依之修持；本译只是把论中的内容译成汉文，供读者了解其义理，不能作为自行修持的依据。论中的种种配对与象征，也须依上师的讲解来理解，不可照字面揣度。

体例：本论以散文为主，按观修的次第分为十节，节题是译者所加。咒语与种子字照录藏文原文于代码块中，不作翻译。为了便于理解而补的字，都放在方括号中。原文含混或可有两解之处，以"【按】"说明，不妄补内容。原文异文依校勘惯例取后一读。原文有一句描写四位佛母年龄与容貌的话，依本译体例略去不译，见第九节按语。藏文原文另见《五部自性_藏文底本.txt》。

## 一、题名与礼敬

梵语题名：Pañcasvabhāva。藏语题名：《五部自性》。

敬礼吉祥金刚萨埵！

我顶礼那无戏论、无上的金刚萨埵；为了让弟子能简要地了解，我来讲说这五种［自性］。

【按】藏题 rang bzhin lnga pa，原文另有异文作 rang bzhin lnga ma，依校勘惯例取 pa。题名的"五种自性"，指五方如来所表的五种本性。

## 二、前行：守护与供养

以"嗡阿吽"来守护自身、处所与瑜伽。

```
ཨོཾ་ཨཱཿཧཱུཾ
```

然后，在涂抹了妙香等的地面上，［画出］四方等形的坛城，在其中央，供养五如来与五位瑜伽母。

【按】"五位瑜伽母"（rnal 'byor ma lnga），从下文来看，指四位佛母，再加上不动佛或金刚萨埵的佛母；下文只具体说了四位，第五位所指原文没有明说，存疑。

## 三、中央：不动佛

在那［坛城］中央，由杂色的"邦"（paṃ）字转变成杂色的、八瓣盛开的莲花；在其莲心上，由红色的"让"（raṃ）字转变成日轮；从安住在日轮上的蓝色吽字，［生起］不动佛：

一面二臂，结触地印，金刚跏趺坐；身体以三十二相与八十种好庄严，是十力、四无畏等功德聚的所依；离开了孔窍、血肉与骨骼，只是明现而已，如同镜中的影像；不是真实，也不是虚妄。

因为他是大慈的体性，所以身色是黑的。手持黑色金刚杵为标帜，是法界清净的［体现］，是五蕴的本性。剃除须发，身披法衣。头顶以金刚萨埵为标志；而金刚萨埵的本性，就是空性与悲心无别。

【按】"离开了孔窍、血肉与骨骼"（bu ga dang sha dang rus pa spangs pa），是密乘观修中对本尊身的标准描述，意思是本尊不是血肉之躯，而是如虹光、如镜影一般只是明现的智慧身。"非真亦非妄"，与《喜金刚续》"不是真实，不是虚妄"的说法一致（见《五如来印释》第九节）。

不动佛一般为蓝色，这里说种子字吽是蓝色，而不动佛的身色是黑色，"因为他是大慈的体性"；这是本论的特殊说法，照原文译出。"剃除须发，身披法衣"，说明这里所观的五佛是出家相的化身装束，与报身佛的宝冠璎珞装束不同；但下文又说他们是"报身"，二者如何协调，原文没有说明，存疑。

## 四、不动佛与三身

这［不动佛］本身，是因与果的体性，具足一切殊胜相的空性之相，是无为的，又是真如的体性，所以是法身；因为只是明现，所以是圆满报身；因为是遍计之识的体性，所以是化身。

如［论中］所说："无为之心是法身，常住是圆满报身之相，种种［显现］本身是化身，本然是一切［身］的自性［身］。"

【按】"具足一切殊胜相的空性"，见《大乐义明示》结颂按语。"遍计之识"（brtags pa'i rnam par shes pa），字面是"被分别安立的识"，指化身是随众生的分别而显现的。所引偈颂出处不详，偈中第四句"本然是一切的自性"，指第四身——自性身（ngo bo nyid kyi sku），即三身一味的本性；下文第七节明确说到"三身一味是自性身"。

## 五、不动佛的配对与咒语

因为［它］不被分别等所了知，所以是金刚部；也因为那金刚部不被世间人所了知。

嗔恨、金刚水、正直、正午、辛味、闻（耳）、虚空、声，以及"左"（ca）字组——这些是不动佛的清净，是外在与内在的体性的安立。

在这里，四身的安立，也与前面相同。

这是持诵的咒语：

```
ཨོཾ་ཨཱཿབཛྲ་དྷྲྀཀ་ཧཱུཾ།
```

【按】这一节列出不动佛所配的种种外内之法：烦恼（嗔）、时分（正午）、味（辛）、根境（耳、声）、大种（虚空）、梵文字母组（ca 组）等。这类配对在无上瑜伽续中很常见，用来表示外在的世界、内在的身心，都是诸佛的清净体性。其中"金刚水"（rdo rje chu）、"正直"（drang ba）所指不明，可能是讹文或特殊的象征用语，存疑。"辛味"，原文 ro tsha ba，tsha ba 一般是"辣、热"，这里依此译为"辛"。

"四身的安立与前面相同"，指上一节所说的法身、报身、化身，再加上自性身。

## 六、中央：金刚萨埵

金刚萨埵，也是从吽字生起：白色，一面二臂，手持金刚杵与铃，是意的本性；以空性印定；是涩味之身；是秋季的清净；是 ya、ra、la、va 等［字母］的体性；［时分是］从半夜到黎明。"法界"是［他的］另一个名称。

【按】金刚萨埵居于不动佛的头顶，即上文所说"头顶以金刚萨埵为标志"。"以空性印定"（stong pa'i rgyas btab），意思是金刚萨埵所表的就是空性；见第八节。ya、ra、la、va，是梵文字母中的半元音组。

## 七、四方四佛

在东方的莲瓣上，于月轮之上，由嗡字生起毗卢遮那：身色白，以白色法轮为标帜，结最胜菩提印。他是色蕴的本性、愚痴之身的本性、粪的清净、如来部、安住于大圆镜智、冬季的清净、甜味之身、"嘎"（ka）字组、上午时分的体性，是身的本性。咒语是：

```
ཨོཾ་ཨཱཿཛི་ན་ཛིཀ་ཧཱུཾ།
```

在南方的莲瓣上，于日轮之上，由"当"（trāṃ）字生起宝生：身色黄，以宝为标帜，结与愿印。他是受蕴的本性、"phra ma"之身、血的体性、宝部，具有平等性智的本性，是春季的清净、咸味之身的本性，遍及"札"（ṭa）字组，是第三时分的体性。他的咒语是：

```
ཨོཾ་ཨཱཿརཏྣ་དྷྲྀཀ་ཧཱུཾ།
```

在西方的莲瓣上，于日轮之上，由红色的"舍"（hrīḥ）字生起无量光：身色红，以莲花为标帜，结禅定印。他是想蕴的本性、贪欲之身、精液的体性、莲花部，具有妙观察智之相，是夏季的本性、酸味之身、"达"（ta）字组的体性，是夜间的第一时分。他持诵的咒语是：

```
ཨོཾ་ཨཱཿཨ་རོ་ལི་ཀ་ཧཱུཾ།
```

在北方的莲瓣上，于日轮之上，由绿色的"康"（khaṃ）字生起不空成就：身色绿，是肉的本性，以剑为标帜，结无畏印。他是行蕴的体性、业部、嫉妒的本性、成所作智、雨季的本性、涩味的本性、"巴"（pa）字组的清净，如同半夜的时分。他持诵的咒语是：

```
ཨོཾ་ཨཱཿཔྲཛྙཱ་དྷྲྀཀ་ཧཱུཾ།
```

【按】这一节的配对，与一般流传的五佛配对有些不同：例如，一般以大圆镜智配不动佛、法界体性智配毗卢遮那，这里则以大圆镜智配毗卢遮那；在《灌顶义摄》中，水灌顶（大圆镜智）也配不动佛。这些差异是各续传承不同所致，这里照原文译出，不作更改。

宝生的"phra ma'i lus"，phra ma 一般是"离间、谗言"，与其他三佛所配的烦恼（愚痴、贪欲、嫉妒）对照，这里应对应"我慢"，但原文作 phra ma，可能是讹文，也可能是特殊用语，这里照录藏文，存疑。

"涩味"既配金刚萨埵，又配不空成就，原文如此，存疑。"夜间的第一时分""第三时分""半夜"等，是把一日一夜分为若干时分（thun）来配五佛。"粪、血、精液、肉"等，是密续中把身中诸物视为诸佛清净体性的说法，属于特定的象征与观修内容，须依上师口授来理解，不可照字面理解。

## 八、五佛的共同体相：三身与印定

这些［五佛］都是金刚跏趺坐，一面二臂，有顶髻，剃除须发，身披法衣，以三十二相、八十种好庄严，是十力、四无畏等功德的所依，离开了孔窍、血肉与骨骼，如同镜中的影像，远离真与妄等一切边，无垢，只是明现——这是圆满报身。

三身一味，是自性身。有为法的真如之体性，是法身。［这些都］与遍计之识的身不相分离。

以色、受、想、行四蕴为体性的毗卢遮那、宝生、无量光与不空成就，为了使人证悟［它们］只是识，所以以不动佛来印定，也就是以不动佛来庄严他们的头顶。

为了使人证悟识也没有自性，［它］就是空性与悲心的体性，所以不动佛又以金刚萨埵来印定。由于这些［印定］，众生就会证悟：因与果、三有与涅槃，都只是一味而已。

如［续中］所说："空性与悲心无别，心于其中善加修习的，那就开示为佛、法与僧。"又说："如同红糖是甜的、火是热的那样，是其本然的自性；同样，一切法的空性，就被承许为［它们的］自性。"又如所说："若能完全了知三有，那就称为涅槃。"

【按】"有为法的真如之体性，是法身"（'dus byas pa'i de bzhin nyid kyi bdag nyid chos kyi sku），这里说"有为法的真如"，与第四节"无为"的说法表面上不同；可能是说法身是有为诸法的真如，也可能 'dus byas 是 'dus ma byas（无为）的讹文。两种理解都可以讲通，存疑。

这一节的论点，与《五如来印释》第二至六节完全一致：以不动佛印定四佛，表示四蕴唯是识；再以金刚萨埵印定不动佛，表示识也无自性，即空悲无别。"空性与悲心无别"一偈，出自《空行网律续》，《五如来印释》第九节也引用过。"红糖是甜的、火是热的"一偈与"若能完全了知三有"一句，出处待考。

## 九、四隅四佛母

在东南方的莲瓣上，于月轮之上，由白色的"朗"（laṃ）字生起佛眼佛母：身色白，以眼为标帜，是地大的本性，出自如来部，乐于愚痴。她的种子字与咒语是：

```
ཨོཾ་ཨཱཿལཾ་ཧཱུཾ་སྭཱ་ཧཱ།
```

在西南方，于月轮之上，由黑色的"芒"（maṃ）字种子生起摩摩基佛母：身色黑，以黑色金刚杵为标帜，是水大的本性，属金刚部，乐于嗔恨。她的种子字与咒语是：

```
ཨོཾ་ཨཱཿམཾ་ཧཱུཾ་སྭཱ་ཧཱ།
```

在西北方，于月轮之上，由"邦"（paṃ）字种子生起名为白衣佛母者：身色红，以莲花为标帜，是火大的本性，属莲花部，乐于贪欲。她的种子字与咒语是：

```
ཨོཾ་ཨཱཿཔཾ་ཧཱུཾ་སྭཱ་ཧཱ།
```

在东北方，于月轮之上，由深蓝色的"当"（tāṃ）字转变成度母：身色深蓝，以青莲花为标帜，是风大的本性，属业部，乐于嫉妒。她的种子字与咒语是：

```
ཨོཾ་ཨཱཿཏཱཾ་ཧཱུཾ་སྭཱ་ཧཱ།
```

【按】四位佛母的方位，原文作"火方"（东南）、"离谛方"（bden bral，西南）、"风方"（西北）、"自在方"（dbang ldan，东北），这是印度传统的四隅之名，这里依通行的方位名译出。"乐于愚痴""乐于嗔恨"等，意思是佛母以转化这些烦恼为其体性，不是说她们真有烦恼；这是密乘象征的语言。

原文在这里有一句描写这四位佛母年龄与容貌的话，依本译的体例略去不译。

## 十、结说与回向

［她们］如前一样，以四身为体性，令人心悦，是胜者一切功德的本性。在以五如来为本性的这些［本尊］中央，这以元音为本性的金刚萨埵之身，是从本初以来就成就的金刚界。

因为我以少许努力简要地造了这部论，是为了让弟子了解；这部仪轨因为简略，［所以能］长久利益众生；［又］因为它具足一切胜者的教证与正理——以我由此所得的一切善根，愿众生都成为胜者！

【按】"以元音为本性的金刚萨埵"（ā li'i rang bzhin），ā li 指梵文的元音字母组；在密续中，元音与辅音（kā li）常被用来象征智慧与方便、月与日等。"从本初以来就成就的金刚界"（rdo rje dbyings dang po nas grub pa），意思是金刚萨埵所表的本性，并不是修出来的，而是本来就成就的。

## 跋

这部《金刚萨埵五自性》，吉祥无二金刚所造，圆满。

应阿弥利达天的请求而造。

【按】"阿弥利达天"（a mri de ba，梵 Amṛtadeva），是请求作者造论的人，生平不详。本论跋语没有记载藏译者。
