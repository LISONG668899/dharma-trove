一、第九颂与心所的定义

外人质问：六识与几种心所相应？世亲菩萨用颂回答：

```
此心所遍行　别境善烦恼
随烦恼不定　皆三受相应
```

大意：六识与六类心所相应：遍行、别境、善、烦恼、随烦恼、不定；六识都与苦、乐、舍三受相应。

论中解释：六转识总共与六位心所相应，即遍行等。心所恒常依心而起，与心相应，系属于心，所以称为心所，如同属于我的东西称为我所。

二、心王取总相，心所兼取别相

心王对所缘只取总相，心所对所缘也取别相，助成心王的作用，所以得到“心所”的名称。

```
如画师资，作模填彩。
```

大意：如同画师与弟子，师父勾画轮廓，弟子填上色彩。

【译注】心王如师父勾勒全貌，知道“有个东西在那里”；心所如弟子在轮廓上填色，触知可意不可意，受知顺违，想知名称，思知该怎么做。心王与心所合作，才成就一次完整的认识。

所以《瑜伽师地论》说：识能了别事物的总相；作意能了别识所未了的相，就是诸心所所取的别相；触能了别可意等相；受能了别摄受等相；想能了别言说之因的相；思能了别正因等相。所以作意等称为心所法。《瑜伽》的论文表示心所也缘总相。

其余地方又说：欲也能了别可乐事物的相，胜解也了别已决定事物的相，念也能了别串习事物的相，定和慧也了别功德与过失等相。由此对境界生起善、染等。一切心所法，对所缘都兼取别相。

三、六位五十一心所与“四一切”

诸心所的名称和含义并非不同，有六位种类的差别：遍行五种，别境五种，善十一种，烦恼六种，随烦恼二十种，不定四种，六位合共五十一种。

六位的划分理由如下：遍行，在一切心中决定可得；别境，缘取各别不同的境界而生起；善，只在善心中才能生起；烦恼，体性属于根本烦恼；随烦恼，只是烦恼的等流；不定，对善、染等都不一定。

《瑜伽师地论》把六位合为五位，因为烦恼和随烦恼都是染污。又以“四一切”分辨五位的差别：一切性、一切地、一切时、一切俱。

遍行具足四个一切。别境只有前两个一切。善只有一个，就是一切地。染污的烦恼和随烦恼，四个一切都没有。不定只有一个，就是一切性。

【译注】一切性：通于善、恶、无记三性。一切地：通于三界九地。一切时：一切心生起时都有。一切俱：同类心所同时俱起。遍行五种四者全具，所以称为“遍行”，任何一念心都少不了。

由于以上五位种类的差别，六转识变动不定，所以都可以与三受相应，因为六转识都领纳顺境、违境、非顺非违境的相。

四、三受的种种分类

领纳顺境的相，令身心适悦，称为乐受。领纳违境的相，令身心逼迫，称为苦受。领纳中庸境的相，对身对心既不逼迫也不适悦，称为不苦不乐受。

三受或者各分为两种：与五识相应的，称为身受，因为另依于身；与意识相应的，称为心受，因为只依于心。

三受又都通于有漏和无漏，苦受也可以由无漏而起。

或者各分为三种：见道所断、修道所断、非所断。又分为有学、无学、非有学非无学三种。

或者总分为四种：善、不善、有覆无记、无覆无记。三受都可以各自分为四种。五识俱起的任运贪痴，纯受苦的恶趣中任运生起而不发业的烦恼，都是无记，都可以与苦根相应。《瑜伽师地论》说：任运生起的一切烦恼，在三受中都可以现行；如果通于一切识身，就普遍与一切受根相应；如果不通于一切识身，就在意地与一切受根相应。《杂集论》说：欲界所系的任运烦恼，如果发起恶行，也是不善；其余的都是有覆无记。所以可知，三受各自都可以有四种。

五、五受：苦乐忧喜舍

或者总分为五种：苦、乐、忧、喜、舍。

三受中苦和乐各分为二，理由有三：逼迫身与逼迫心、适悦身与适悦心，相状各不相同；五识无分别，意识有分别；苦乐有特别深重和轻微的差别。

不苦不乐不分为二，理由有三：非逼非悦的相状没有不同；没有分别；平等运转。

一切适悦的受，与五识相应，恒常称为乐。与意识相应的：如果在欲界、初禅和二禅的近分定，称为喜，因为只适悦心；如果在初禅和二禅的根本定，称为乐，也称为喜，因为适悦身心；如果在第三禅的近分定和根本定，称为乐，因为安静、特别深重、没有分别。

一切逼迫的受，与五识相应，恒常称为苦。

六、意识中的逼迫受称忧还是称苦

与意识相应的逼迫受，论中列出两家。

第一家认为：只称为忧，因为逼迫心，诸圣教说意地的忧戚之受称为忧根。《瑜伽师地论》说：生在地狱的有情，异熟无间断，有异熟生的苦和忧相续。又说：地狱中寻伺与忧俱起，一部分鬼趣和畜生也是如此。可知意地特别深重的忧戚之受，尚且称为忧，何况其余轻微的。

第二家，即护法论师，认为：通于两种。人天中的，恒常称为忧，因为不特别深重。畜生和鬼界的，称为忧，也称为苦，因为杂受与纯受有轻重。地狱中的，只称为苦，因为纯受特别深重，没有分别。

护法论师的证据如下。《瑜伽师地论》说：任运生起的一切烦恼，在三受中都可以现行，广说如前。又说：俱生的身见只是无记，边见也是如此。与俱生身见俱起的苦受，不属于忧根，因为论中说忧根不是无记。

《瑜伽师地论》又说：地狱中的诸根，其余三根的现行决定不成就，纯受苦的鬼界和畜生也是如此。“其余三根”决定是乐、喜、忧三根，因为地狱有情必定成就现行的舍根。

【译注】地狱有情决定成就八根：眼、耳、鼻、舌、身、意、命七根，加上第八根。第八根是什么，就是下面辩论的焦点。护法论师主张是舍根，所以“其余三根”就是乐、喜、忧，地狱中意识的逼迫受也就不是忧，只能称为苦。

外人质问：难道地狱中客受的舍受不一定成就吗？论主回答：你怎么知道论文只说客受？如果只说客受，论中就不应说地狱有情决定成就意根，因为六种客识有时不存在。不应说论中对受根只说客受、对意根通说一切，因为没有不同的理由。论文如果依客受而说，怎能说地狱有情决定成就八根？

如果说五识不相续，所以决定以忧根为第八根，那么在死、生、闷绝时，怎能有忧根？有人执着苦根为第八根，也照此破斥。

如果执着男女二根中的一形为第八根，道理也不对，因为形不一定有：地狱有情由恶业所感，可能没有形。地狱有情由于恶业，令五根之门恒常受苦，所以决定成就眼等五根；必有一形对地狱有情有什么用？在无间大地狱中，不会有希求淫欲的事。

所以第八根决定是舍根，因为第七识和第八识与舍受相应。如同极乐之地，意中的适悦称为乐，没有喜根；所以极苦之处，意中的逼迫称为苦，没有忧根。所以“其余三根”决定是忧、喜、乐。

其余地方说地狱有等流的乐，应知是依随转理门而说；或者是通说其余杂受之处，因为没有异熟的乐，所以称为纯苦。诸圣教说意地的忧戚之受称为忧根，是依多数情况而说，或者是随转门，没有相违的过失。《瑜伽师地论》说生在地狱的有情苦忧相续，又说地狱寻伺与忧俱起，一部分鬼趣和畜生也是如此，也是依随转门。

另外，与意识相应的苦根，与其余的忧同类，所以假说为忧。或者，苦根损害身心，属于苦根，也称为忧，如同近分定的喜利益身心，属于喜根，也称为乐。《显扬圣教论》等都显示苦根亦名忧的意义。未至定决定没有乐根，因为论中说未至定只有十一根。由此应知，意地的忧戚之受，在纯受苦之处，也属于苦根。

苦忧之辨的圣教，差别有多种，恐怕文字繁多，不详述。

七、六识三受能否同时

关于六识的三受能否同时，论中列出两家。

第一家认为：六识的三受不同时俱起，因为六识都向外门运转，三受互相违背。与五识俱起的意识，与五识同一所缘；五识与三受俱起，意识也应如此，意识三受俱起违背正理，所以必定不同时俱起。《瑜伽师地论》等说藏识一时与转识相应、三受同时俱起，是依多念而说，如同说“一心”并非只有一次生灭，没有相违的过失。

第二家，即护法论师，认为：六识的三受可以同时俱起。理由有四：顺境、违境、中庸境可以同时领受；意识不一定与五识的受相同；意识偏向专注于哪一境，就起哪一受；没有偏注时，意识就起舍受。由此，六识的三受可以同时俱起。

在得自在的阶位，六识只有乐、喜、舍三受，因为诸佛已经断除了忧和苦。

八、第十颂与五遍行

前面略标了六位心所，现在应广说六位心所的差别相。外人质问：先说前二位，相状是怎样的？世亲菩萨用颂回答：

```
初遍行触等　次别境谓欲
胜解念定慧　所缘事不同
```

大意：第一位是遍行，即触等五种；第二位是别境，即欲、胜解、念、定、慧五种，所缘的境事各不相同。

论中解释：六位中的第一位遍行心所，就是触等五种，前面已经广说。

外人质问：怎么知道触等五种是遍行？论主回答：以圣教和正理作为决定的标准。

圣教，如契经说：眼根与色境为缘，生起眼识，根、境、识三者和合生触，与触同时生起受、想、思，乃至广说。由此可知，触、受、想、思四种是遍行。

契经又说：如果根不坏，境界现前，作意正在生起，才能生起识。其余的经又说：对某处作意，就对某处了别；对某处了别，就对某处作意；所以作意与识恒常和合，乃至广说。由此可知，作意也是遍行。诸如此类的圣教，确实的证据不止一处。

正理如下。识生起时必定有根、境、识三和，三和决定生触，识必定由触而有。如果没有触，心王与心所就不应和合，共同接触同一境。

作意引导心趋向自己的境，如果没有作意，心就不应存在。

受能领纳顺境、违境、中庸境，令心等生起欢喜、忧戚、舍的相。没有任何心生起时，不带三受之一。

想能安立自己所缘之境的界限，如果心生起时没有想，就不能取境界的界限相状。

思令心取正因等相，造作善等行为。没有任何心生起时，不带善等之一，所以必定有思。

由此证知，触等五法，心生起时必定都有，所以是遍行。其余心所为何不是遍行，到后面再说。

九、别境之一：欲

其次是别境，即欲乃至慧。别境所缘的境事，大多不相同，在六位中排在第一位之后，所以颂中说“次”。

什么是欲？对所喜好的境，希望为自性；作为精进的所依，是欲的作用。

关于“所喜好的境”，论中列出三家。

第一家认为：所喜好的，是可欣喜的境。对可欣喜的事物，想要见闻等，有希望。

外人质问：对可厌的事物，希望可厌的事物不要与自己相合，希望与可厌的事物分离，难道不是有欲？第一家回答：希求分离时只是希求不相合、分离时的可欣喜的状态，所希求的不是可厌的事物本身。所以对可厌的境和中庸的境，完全没有欲。缘取可欣喜的事物时，如果不希望，也没有欲生起。

第二家认为：所喜好的，是所希求的境。对可欣喜和可厌的事物，希求相合或分离等，有希望。对中庸的境，完全没有欲。缘取可欣喜或可厌的事物时，如果不希求，也没有欲生起。

第三家，即护法论师，认为：所喜好的，是想要观察的境。对一切事物，想要观察的，都有希望。如果不想观察，只是随着因和境的势力任运地缘取，就完全没有欲。由此道理，欲不是遍行。

有人说：心王与心所要由希望境界的力量，才能取所缘，所以经中说欲是诸法的根本。论主破斥：“欲为诸法本”的说法不对。心王等取境，是由于作意，诸圣教说作意现前能生识，从来没有地方说由欲能生心王与心所。如同经中说诸法以爱为根本，难道心王与心所都由爱而生？所以说“欲是诸法的根本”，是说欲所发起的一切事业；或者是说善欲能发起正勤，由正勤助成一切善事。所以论中说欲以作为精进的所依为作用。

十、别境之二：胜解

什么是胜解？对已决定的境，印可执持为自性；不能被引转，是胜解的作用。

由于邪或正等教证、理证的力量，对所取的境审察决定、印可执持，由此其他的缘不能引转。所以对犹豫的境，完全没有胜解；不是审察决定的心，也没有胜解。由此，胜解不属于遍行。

有人说：心王等取自己的境时，没有拘碍，所以都有胜解。论主破斥：“心皆有胜解”的说法不合道理。原因是：能令心不受拘碍的，就是诸法本身；不受拘碍的，就是心等本身；殊胜地发起心的，是根和作意。如果说由于胜解，心才殊胜地发起，胜解就还要等待其他的心所，就有无穷的过失。

十一、别境之三：念

什么是念？对曾经熟习的境，令心明白记忆、不忘失为自性；作为定的所依，是念的作用。

念能一再忆持曾经领受的境，令不忘失，所以能引生定。对从未领受过的境，完全不起念。即使曾经领受，如果不能明白记忆，念也不生起。所以念决定不属于遍行。

有人说：心生起时必定有念俱起，因为念能作为后来忆念的原因。论主破斥：“心起必有念”的说法不合道理。不然的话，后来有痴、有信，前时也必定有痴、有信。前时的心王与心所，或者想的势力，就足以作为后来忆念的原因。

十二、别境之四：定

什么是定？对所观察的境，令心专注不散为自性；作为智的所依，是定的作用。

在观察功德、过失、非功德非过失的境时，由定令心专注不散，依定就有抉择的智慧生起。“心专注”的意思，是显示想要安住在哪里就能安住在哪里，并不是只限于一个境。不然的话，见道时历观四谛，前后所观的境不同，就应没有等持。如果不系心专注于境，就没有定生起，所以定不是遍行。

有人说：不专注时也有定生起，只是相状微隐。论主回答：应当说出真实可靠的理由。

如果说定能令心等和合，共同趣向一境，所以是遍行，道理也不对，因为令心等和合是触的作用。

如果说定能令刹那间的心不改变所缘，所以属于遍行，也不合道理，因为一刹那的心对所缘本来就没有改变的意义。

如果说由于定，心才取所缘，所以属于遍行，也不合道理，因为令心取所缘的是作意。

有人说：定的体就是心，因为经中说定学为心学，说定是心一境性。论主回答：引经不是确实的证据。经中是依定摄持心、令心专注一境而说心学。定属于五根、五力、七觉支、八正道支，如同念和慧等，不就是心。

十三、别境之五：慧

什么是慧？对所观察的境，简择为自性；断除疑惑，是慧的作用。

在观察功德、过失、非功德非过失的境时，由慧推求，得到决定。对不观察的境，在愚昧的心中，没有简择，所以慧不属于遍行。

有人说：不观察时也有慧生起，只是相状微隐。论主反问：天爱，你怎么知道？

外人回答：阿毗达磨说慧是大地法。论主回答：各部派的阿毗达磨互相矛盾，你们怎能执为决定的标准？只有触等五种，经中说是遍行；说十种都是遍行，不是经中所说，不应固执。欲等五种不是触等，所以决定不是遍行，如同信、贪等。

【译注】说一切有部立十大地法：受、想、思、触、欲、作意、胜解、念、三摩地、慧，即把唯识的遍行五与别境五合为一类。唯识宗只依经说立遍行五，别境五需要特定的境界条件才生起。

十四、五别境的组合与诸识有无

关于五别境是否必定同时俱起，论中列出两家。

第一家认为：五别境决定互相资助，任何一种生起时，必定有其余四种。

第二家，即护法论师，认为：不一定。《瑜伽师地论》说别境在四个一切中没有后两个，即没有一切时与一切俱。又说别境五种缘四种境而生，所缘与能缘不一定同时俱起。

应当说：五别境有时只起一种。或者对所喜好的境，只起希望；或者对已决定的境，只起印解；或者对曾经熟习的境，只起忆念；或者对所观察的境，只起专注。例如愚昧的人为了止息散乱的心，专注于所缘，不能简择，世间共知愚昧的人有定无慧。愚昧的人在加行位中稍有闻思，所以说等持缘取所观的境；或者是依多数情况而说。又如戏忘天专注于一境，生起贪瞋等，有定无慧。诸如此类，种类很多。或者对所观察的境，只起简择，不专注，奔驰散乱地推求。

有时起两种。例如对所喜好的已决定的境，起欲和胜解；或者对所喜好的曾经熟习的境，起欲和念。依此类推，乃至对所观察的境，起定和慧。两两组合，共有十种。

有时起三种。例如对所喜好、已决定、曾经熟习的境，起欲、胜解、念。依此类推，乃至对曾经熟习、所观察的境，起念、定、慧。三三组合，共有十种。

有时起四种。例如对所喜好、已决定、曾经熟习、所观察的境，起前四种。依此类推，乃至对已决定、曾经熟习、所观察的境，起后四种。四四组合，共有五种。

有时起五种。对所喜好、已决定、曾经熟习、所观察的境，五种都生起。

如此，对四种境起欲等五种，单起与合起，总共有三十一种组合。

【译注】原文“合有十二”“合有十三”“合有五四”，是说两两相合有十种、三三相合有十种、四四相合有五种，不是十二、十三之数。单起五种，加上十、十、五、一，正是三十一。

有时心中五种别境都不生起。例如对四种境以外的境率尔堕起的心，以及与藏识俱起时，诸如此类，不止一种。

第七、第八识中的别境五种，随阶位有无，如前所说。第六意识在一切阶位都可以同时具有，因为转依与未转依都不遮止。

关于五识有无别境，论中列出两家。

第一家认为：五识中别境五种都没有。五识缘取已得到的境，没有希望；不能审察决定，没有印持；恒常取新的境，没有追忆；自性散动，没有专注；不能推度，没有简择。

第二家，即护法论师，认为：五识可以有别境五种。五识对境没有增上的希望，有微弱的喜好；没有增上的审决，有微弱的印可；没有明白记忆曾经熟习的境体，有微弱的念境之类；不作意系念一境，有微弱的专注。论中说五识自性散动，是为了遮止等引，并不是遮止等持，所以五识可以有定。五识对所缘不能推度，有微弱的简择，由此圣教说眼通、耳通是眼识、耳识相应的智慧。其余三识照此类推，有慧没有过失。

在未自在的阶位，五识中的别境五种可能没有。得到自在时，五识中的别境五种决定都有：乐于观察诸境，欲没有减少；印可境界的胜解恒常没有减少；忆持曾经领受之境的念没有减少；佛的五识缘取三世；如来没有不定的心；佛的五识都有成所作智。

十五、别境与五受

关于别境与五受的关系，论中列出两家。

第一家认为：欲与三受相应，除了忧和苦，因为忧和苦的境不是所喜好的。其余四种别境通于四受，只除了苦受，因为审察决定等作用，五识中没有。

第二家，即护法论师，认为：五种别境都与五受相应。论中说，对无上法思慕愁戚，求欲证得，所以忧根中有欲。在纯受苦之处，希求解脱，意识有苦根，前面已经说过。论中说贪爱与忧苦相应，与贪爱俱起必定有欲。苦根既然有与意识相应的，审察决定等四种与苦受俱起有什么过失？与五识俱起的，也有微细的印可境界等四种，意义如前所说。由此，欲等五种与五受相应。

五种别境，还可以依性、界、学等诸门分别，应依道理思考。
