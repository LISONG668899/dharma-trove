本篇要目：一、第四解：二业为因、二障为缘　二、分段生死与不思议变易生死　三、变易生死的种种疑难　四、净法相续也由内识　五、第二十至二十二颂　六、遍计所执性：能遍计与所遍计　七、遍计所执与依他起的分界　八、圆成实性　九、圆成实与依他起非异非不异　十、三性都不离心　十一、三性与诸法相摄：无为、七真如、六法、五事、五相、四真实　十二、三性与四谛、三解脱门、二谛　十三、三性的智境、假实、一异

一、第四解：二业为因、二障为缘

其次，生死相续由于内在的因和缘，不需要外缘，所以唯有识。

“因”是指有漏和无漏两种业，因为二业真正感招生死，所以说为因。“缘”是指烦恼障和所知障两种障，因为二障帮助感招生死，所以说为缘。

二、分段生死与不思议变易生死

外人质问：理由何在？论主回答：生死有两种。

第一是分段生死，就是一切有漏的善业和不善业，由烦恼障作为缘帮助的力量，所感招的三界粗显的异熟果。身体和寿命的长短，随着因缘的力量，有决定的限度，所以称为分段。

第二是不思议变易生死，就是一切无漏的有分别业，由所知障作为缘帮助的力量，所感招的殊胜微细的异熟果。由悲愿的力量，改变转换身体和寿命，没有决定的限度，所以称为变易。由无漏的禅定和誓愿真正资助感招，妙用难以测度，所以称为不思议。或者称为意成身，因为随意愿而成就。

如契经说：如同以取为缘、有漏业为因，延续后有的人，生在三有之中；同样，以无明习气之地为缘、无漏业为因，有阿罗汉、独觉、已得自在的菩萨，生起三种意成身。意成身也称为变化身，因为无漏定力转变，令身体异于原本，如同变化所成。

如有论说：声闻无学永远断尽后有，怎能证得无上菩提？依变化身证无上觉，不是依业报身，所以不违背道理。

【译注】分段生死是凡夫的生死：每一期身寿有固定的长短，一段一段地生死。变易生死是圣者的“生死”：烦恼已断，为了继续修菩萨行，以定力和愿力延续、改转身命，长短随愿。前者由业力推动，后者由悲愿推动。

三、变易生死的种种疑难

外人质问：如果所知障帮助无漏业能感招生死，二乘定性的人也有所知障和无漏业，就应不能永远入无余涅槃，如同凡夫被烦恼所拘。

外人质问：道谛怎能真正感招苦果？

论主回答：谁说真正感招？

外人质问：不然又是怎样？

论主回答：无漏的禅定和誓愿资助有漏的业，令所得的果报相续长久，展转增胜，假说为“感”。如此感招时，由所知障作为缘帮助，不是无漏业单独能感招。所知障不障碍解脱，因为没有发业润生的作用，所以二乘定性的人不受其拘。

外人质问：何必资助感招生死之苦？

论主回答：为了自证菩提、利乐他人。不定性的独觉、声闻，以及已得自在的大愿菩萨，已经永远断除或伏除烦恼障，不可能再受将来的分段身；恐怕废弃长时修行的菩萨行，于是以无漏的殊胜禅定和誓愿力，如同延寿法，资助现在身体的因，令现在的身体长时与果不断绝；一次次如此以禅定誓愿资助，直到证得无上菩提。

外人质问：既然如此，何必还要所知障的帮助？

论主回答：理由有三。第一，还没有圆满证得无相大悲，如果不执着菩提和有情实有，就没有理由发起猛利的悲愿。第二，所知障障碍大菩提，为了永远断除所知障，留身久住。第三，所知障是有漏法的所依，所知障如果没有，有漏法就决定不存在，所以所知障对身体的久住有很大的帮助。

【译注】此处说破了一个微妙之处：菩萨留身度众，恰恰要借助所知障中“执着有情实有、菩提实有”的那一分，悲愿才能猛利生起。所知障在此反成助缘，直到成佛才断尽。

如果所留的身体由有漏的禅定和誓愿资助，属于分段身，因为是二乘和凡夫智慧所知的境界。如果由无漏的禅定和誓愿资助，属于变易身，因为不是二乘和凡夫智慧所知的境界。

由此应知，变易生死的体性是有漏，属于异熟果，对无漏业是增上果。有些圣教中说变易生死是无漏、超出三界，是随着帮助的因而说。

颂中所说的“诸业习气”，就是前面所说有漏、无漏两种业的种子。“二取习气”，就是前面所说烦恼、所知两种障的种子，因为二障都是执着。“俱”等其余的文义，如前面所解释。

变易生死没有分段生死那种前后异熟一期期分别结束、分别生起的情形，由于一次次资助，前后改转，也有前一期结束、后一期又生起的意义。

生死相续，也由现行；种子决定存在，所以颂中只说种子。或者，为了显示真异熟的因与果都不离本识，所以不说现行。现行的异熟因不能立即与果，因为前七转识有间断，不是异熟。

四、净法相续也由内识

过去、现在、未来的生死轮回，不需要外缘，既然由内识而成，清净法的相续，应知也是如此。

从无始以来，依附本识有无漏种子，由转识等一次次熏发，渐渐增胜，直到究竟成佛时，转舍本来杂染的识种，转得新起的清净种识，任持一切功德种子，由本愿力，穷尽未来际生起种种妙用，相续无穷。由此应知，唯有内识。

五、第二十至二十二颂

外人质问：如果唯有识，为什么世尊在许多经中说有三性？论主回答：应知三性也不离识。原因如颂所说：

```
由彼彼遍计　遍计种种物
此遍计所执　自性无所有
依他起自性　分别缘所生
圆成实于彼　常远离前性
故此与依他　非异非不异
如无常等性　非不见此彼
```

大意：种种虚妄分别，周遍计度种种事物，所计度执着的，称为遍计所执性，遍计所执性根本没有自体。依他起性，是由众缘所生的分别。圆成实性，是在依他起性上恒常远离前面的遍计所执性。所以圆成实性与依他起性，既不是异，也不是不异，如同无常性与无常诸法的关系。不证见圆成实性，就不能如实见到依他起性。

六、遍计所执性：能遍计与所遍计

论中解释：周遍计度，所以称为“遍计”。品类众多，所以说“彼彼”。能遍计的是虚妄分别，就是由种种虚妄分别，遍计种种所遍计的事物，即所妄执的蕴、处、界等，或作为法，或作为我，执其自性与差别。所妄执的自性与差别，总称为遍计所执自性。遍计所执自性完全没有，因为依理证和教证推究，都不可得。

或者，第一句显示能遍计的识，第二句显示所遍计的境，后半首才说明遍计所执的我或法，自性不存在，因为前面已经广说我法不可得。

外人质问：能遍计的自性是什么？论中列出两家。

第一家，依《述记》为安慧论师的主张：一切有漏的八识及心所，都能遍计，因为都以虚妄分别为自性，都显现为似所取、似能取；又论中说阿赖耶识以遍计所执自性的妄执种子为所缘。

第二家，即护法论师，认为：第六、第七识心品中执着我法的，才是能遍计。理由如下：

论中只说意识能遍计；“意”与“意识”都可称为意识。计度分别才能遍计。执着我法的必定是慧。我法二执必定与无明俱起。论中没有说无明有善性。痴与无痴等不能相应。没有见过执着能引导空智的。执有与执无不能同时生起。从来没有执着不能熏习的。有漏心等因为不能证实，一切都称为虚妄分别；显现为似所取、似能取，并不都属于能遍计，否则无漏心也应有执着，如来的后得智也应有执着。经中说佛智显现身土等种种影像，如同镜子等；如果没有缘取的作用，就不应是智等。论中说藏识缘取遍计所执的种子，没有说“唯”缘遍计，所以不是确实的证据。

由此道理，只有第六、第七识心品中有能遍计。识品只有两种，有二、三、四、五、六、七、八、九、十等种种不同的遍计，所以颂中说“彼彼”。

外人质问：所遍计的自性是什么？论主回答：《摄大乘论》说，所遍计是依他起性，因为是能遍计之心等的所缘缘。

外人质问：圆成实性难道不是能遍计的境？论主回答：圆成实性不是虚妄执着的所缘境；依展转的关系而说，也可以说是所遍计。遍计所执是能遍计的境，不是所缘缘，所以不是所遍计。

【译注】所遍计与遍计所执要分清：所遍计是“被拿来乱认的东西”，是依他起的实有；遍计所执是“乱认出来的结果”，根本没有。如同夜里把绳子看成蛇：绳子是所遍计，蛇是遍计所执。

七、遍计所执与依他起的分界

外人质问：遍计所执的相状是怎样的？与依他起有什么区别？论中列出两家。

第一家，依《述记》为安慧论师的主张：三界的心王与心所，由无始以来的虚妄熏习，各自的体是一，显现为似两分，就是见分和相分，即能取和所取。见相二分在情执中有，在道理上无，二分的相状说为遍计所执。二分所依的识体，真实依托众缘而生，体性不是没有，称为依他起，因为是虚妄分别、由缘所生。外人质问：怎么知道如此？第一家回答：诸圣教说虚妄分别是依他起，二取称为遍计所执。

第二家，即护法论师，认为：一切心王与心所由熏习力所变现的见相二分，从缘而生，所以也是依他起。能遍计依于见相二分，妄执为决定实有、无、一、异、俱、不俱等，被妄执出来的二取，才称为遍计所执。

护法论师的理由如下。诸圣教说唯量、唯二、唯种种，都称为依他起。相等四法、十一识等，论中都说属于依他起。不然的话，无漏后得智品的见相二分，就应称为遍计所执。如果承认，圣智就应不缘见相二分而生，缘见相二分的智品就应不是道谛；如果不承认，应知有漏的见相二分也是如此。

见相二分如果是遍计所执，就应如同兔角等，不是所缘缘，因为遍计所执的体不存在。见相二分就应不能熏成种子，后来识等生起时，就应没有见相二分。一切习气属于相分，难道不是实有之法，能作为因缘？如果缘所生的内在见相二分不是依他起，二分所依的识体也应如此，因为没有不同的原因。

由此道理，众缘所生的心王心所之体，以及见分相分，无论有漏无漏，都是依他起，因为依靠他缘而得以生起。

颂中说“分别缘所生”，应知只是说染分的依他起，因为净分的依他起也属于圆成实。或者，一切染净的心王心所法，都称为分别，因为能缘虑；那么一切染净依他起，都属于颂中所说的依他起。

【译注】两家的分歧是全论最重要的分歧之一：安慧认为见相二分本身就是虚妄，只有识体是依他起；护法认为见相二分也是缘生的真实显现，虚妄只在执着二分为实我实法的那一层。依护法，心中显现的一切影像本身并不虚妄，虚妄在于把影像当成心外实物。

八、圆成实性

二空所显的、圆满、成就的诸法真实性，称为圆成实。显示圆成实性周遍、常住、体性不虚谬，以简别自相、共相，以及虚空、我等。无漏的有为法，远离颠倒，究竟，殊胜的作用周遍，也可以得到圆成实的名称。颂中说的是前者，不是后者。

【译注】“圆”是周遍，简别只在一处的自相；“成”是常住，简别生灭的诸法；“实”是不虚谬，简别外道所立的虚空、神我等。三字合起来，只有真如当得起。

颂的意思是：圆成实性，就是在依他起性上，恒常远离前面的遍计所执，二空所显的真如为体性。

说“于彼”，显示圆成实与依他起不即不离。说“常远离”，显示虚妄所执的能取所取性，在道理上恒常没有。“前”字的意思，显示不空的依他起。“性”字显示二空不是圆成实，因为真如远离有与无。

【译注】“二空所显”不是说空就是真如。空只是去掉执着的方法，真如是去掉执着后显露的实性。所以论主特别用“性”字点出：圆成实是二空所显的性，不是空本身。

九、圆成实与依他起非异非不异

由前面的道理，圆成实与依他起，非异也非不异。

如果是异，真如就应不是依他起的真实性。如果不是异，圆成实性就应是无常；圆成实与依他起都应同样是清净智慧的境界，或同样不是；根本智与后得智的作用就应没有区别。

外人质问：圆成实与依他起二性，怎么是非异非一？

论主回答：如同无常、无我等性。无常等性如果与诸行等法相异，诸行等法就应不是无常等；如果不异，无常等就应不是诸行的共相。由此比喻显示，圆成实与依他起，非一非异。法与法性，在道理上必定如此，因为胜义与世俗是相待而有的。

颂中“非不见此彼”，是说不证见圆成实性，就不能见依他起性。因为没有通达遍计所执性空，就不能如实了知依他起是有。

无分别智证得真如之后，在后得智中，才能了达依他起性如同幻事等。从无始以来，心王与心所法已能缘取自己的见分相分等，因为我执法执恒常同时运转，所以不能如实了知众缘所引生的自心心所虚妄变现，如同幻事、阳焰、梦境、镜像、光影、谷响、水中月、变化所成，非有似有。依此意义，有偈颂说：

```
非不见真如　而能了诸行
皆如幻事等　虽有而非真
```

大意：不见真如，就不能了知诸行都如同幻事等，有而不是真实。

【译注】先证真如，回头才看清缘起如幻。没有证悟以前说“如幻”，只是比量的理解；证悟之后的后得智中见到“如幻”，才是现量的亲见。

十、三性都不离心

以上的意思是说：三种自性都不远离心王与心所法。

心王与心所及所变现的，由众缘而生，如同幻事等，非有似有，欺诳迷惑愚夫，一切都称为依他起性。

愚夫对依他起，横执为我、法、有、无、一、异、俱、不俱等，如同空花等，体性与相状都没有，一切都称为遍计所执。

在依他起上，所妄执的我和法都空，此空所显的识等真实性，称为圆成实。

所以三性都不离心等。

十一、三性与诸法相摄：无为、七真如、六法、五事、五相、四真实

外人质问：虚空、择灭、非择灭等，属于哪一性？论主回答：三性都可以摄。心等变现为似虚空等的相，随心而生，属于依他起。愚夫对虚空等妄执为实有，属于遍计所执。如果在真如上假立虚空等名义，属于圆成实。

有漏的心等，决定属于依他起。无漏的心等，可以属于两性：由众缘而生，属于依他起；没有颠倒，属于圆成实。

外人质问：三性与七真如怎样相摄？论主回答：七真如是：一流转真如，就是有为法流转的真实性；二实相真如，就是二无我所显的真实性；三唯识真如，就是染净诸法唯识的真实性；四安立真如，就是苦谛的真实性；五邪行真如，就是集谛的真实性；六清净真如，就是灭谛的真实性；七正行真如，就是道谛的真实性。七种真实性都属于圆成实，因为都是根本智与后得智的境界。随相状而摄：流转、苦、集三种，属于前两性，因为是妄执和杂染；其余四种，都属于圆成实。

外人质问：三性与六法怎样相摄？论主回答：六法中都具有三性，因为色、受、想、行、识及无为，都有妄执、缘生、真理的意义。

外人质问：三性与五事怎样相摄？论主回答：诸圣教说相摄的情形不一定。

【译注】五事是：相、名、分别、正智、真如。

有的地方说：依他起性摄相、名、分别、正智；圆成实性摄真如；遍计所执不摄五事。该处是说：有漏心王心所变现为似所诠，称为相；变现为似能诠，施设为名；能变的心等，立为分别；无漏的心等离开戏论，只总称为正智，不说能诠所诠。前四事从缘而生，都属于依他起。

有的地方说：依他起性摄相和分别；遍计所执只摄名；正智和真如属于圆成实。该处是说：有漏心王心所的相分称为相，其余的称为分别；遍计所执完全没有体，为了显示非有，假说为名；正智和真如都没有颠倒，所以属于圆成实。

有的地方说：依他起性只摄分别；遍计所执摄相和名；正智和真如属于圆成实。该处是说：有漏心王心所的见分相分等，总称为分别，因为以虚妄分别为自性；遍计所执的能诠所诠，随情执立为名和相二事。

又有地方说：名属于依他起性，义属于遍计所执。该处是说：有漏心王心所的见分相分等，由名言的势力成为所遍计，所以说为名；遍计所执随名横加计度，体实际不存在，假立“义”的名称。

诸圣教所说的五事，文字有不同，意义没有违背。最初的说法不相杂乱，如《瑜伽师地论》广说可知。

外人质问：圣教中又说有五相，与三性怎样相摄？论主回答：所诠相和能诠相，各具三性：虚妄所计的，属于第一遍计所执性；相、名、分别，随其所应作为所诠和能诠，属于依他起；真如和正智，随其所应作为所诠和能诠，属于圆成实，因为后得智变现似能诠的相。第三相属相，只属于第一性，因为妄执义与名决定相属。执着相，只属于依他起，因为以虚妄分别为自性。不执着相，只属于圆成实，因为以无漏智等为自性。

外人质问：圣教中又说四种真实，与三性怎样相摄？论主回答：世间极成真实和道理极成真实，属于依他起，因为由相、名、分别三事所摄。烦恼障净智所行真实和所知障净智所行真实，属于圆成实，因为由正智、真如二事所摄。《辩中边论》说：第一种真实只属于第一性，因为是世间共同所执；第二种真实通于三性，因为道理通于执着与无执着、杂染与清净；后两种真实只属于第三性。

十二、三性与四谛、三解脱门、二谛

外人质问：三性与四谛怎样相摄？论主回答：四谛中，每一谛都具三性。

先说苦谛。苦谛的无常、苦、空、无我四相，各有三性。

无常有三种：一是无性无常，因为遍计所执的体性恒常没有；二是起尽无常，因为依他起有生灭；三是垢净无常，因为圆成实的阶位有垢与净的转变。

苦有三种：一是所取苦，因为遍计所执是我法二执所依所取；二是事相苦，因为依他起有三苦的相；三是和合苦，因为圆成实与苦相和合。

空有三种：一是无性空，因为遍计所执的体性不存在；二是异性空，因为依他起与妄执的自性相异；三是自性空，因为圆成实以二空所显为自性。

无我有三种：一是无相无我，因为遍计所执的我相没有；二是异相无我，因为依他起与妄执的我相相异；三是自相无我，因为圆成实以无我所显为自相。

集谛有三种：一是习气集，就是遍计所执自性的执着习气，执着习气，假立“集”的名称；二是等起集，就是业和烦恼；三是未离系集，就是还没有离开障碍的真如。

灭谛有三种：一是自性灭，因为遍计所执的自性不生；二是二取灭，就是择灭，因为二取不再生起；三是本性灭，就是真如。

道谛有三种：一是遍知道，因为能遍知遍计所执；二是永断道，因为能断依他起；三是作证道，因为能证圆成实。遍知道也通于后两性。

以上七种三法，依次配属三性。现在配属的三性，或假或实，应依道理了知。

外人质问：三解脱门所行的境界，与三性怎样相摄？论主回答：实际上三解脱门都通于三性；依相状而说，各配一性：空解脱门配遍计所执，无愿解脱门配依他起，无相解脱门配圆成实，依次应知。缘取三性，又生起三种无生忍：一是本性无生忍，二是自然无生忍，三是惑苦无生忍，依次以三性为境。

外人质问：三性怎样摄二谛？论主回答：应知世俗谛具足三性，胜义谛只是圆成实性。

世俗有三种：一是假世俗，二是行世俗，三是显了世俗，依次就是三性。

胜义有三种：一是义胜义，就是真如，是殊胜智慧的境义；二是得胜义，就是涅槃，殊胜即是所得之义；三是行胜义，就是圣道，以殊胜涅槃为所求之义。三种胜义无变异、无颠倒，随其所应，都属于圆成实性。

十三、三性的智境、假实、一异

外人质问：三性是什么智慧所行的境界？

论主回答：遍计所执完全不是智慧所行的境界，因为没有自体，不是所缘缘。愚夫执着为有，圣者通达为无，所以也可以说是凡夫和圣者智慧的境界。依他起性，是凡圣两种智慧所行的境界。圆成实性，只是圣者智慧的境界。

外人质问：三性之中，几种是假，几种是实？

论主回答：遍计所执是虚妄安立的，所以可以说为假；没有体和相，所以既不是假也不是实。依他起性有实有假：聚集、相续、分位的性质，说为假有；心王、心所、色法从缘而生，说为实有。如果没有实法，假法也就没有，因为假法依实法为因而施设。圆成实性只是实有，因为不依他缘而施设。

【译注】遍计所执连“假”都够不上：假法至少依于实法而有，如同瓶子依泥土而立；遍计所执如同兔角，连所依都没有。

外人质问：三性是异还是不异？

论主回答：应说都不是：没有另外的体，所以不是异；妄执、缘起、真义各不相同，所以不是不异。

三性的意义种类无边无际，恐怕读者厌烦繁文，只略示纲要。
