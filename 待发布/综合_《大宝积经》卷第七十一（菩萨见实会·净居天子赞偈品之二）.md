# 《大宝积经》卷第七十一（菩萨见实会·净居天子赞偈品之二）

北齐·三藏那连提耶舍 译

## 菩萨见实会

### 净居天子赞偈品第二十三之二

【按】会题“菩萨见实会”，宋、元、明、宫本作“菩萨见实会第十六之十一”。

#### 赞知诸界与三聚

那时力生天子说偈赞叹：

```
若诸因缘业，及所得果报，
此体性悉空，佛说如师子。
```
（大意：种种因缘、业以及所得的果报，其体性都是空，佛如狮子般这样宣说。）

那时随顺力天子说偈赞叹：

```
若以业因缘，增长于诸果，
两足尊能知，是故佛无等。
```
（大意：若以业的因缘，增长种种果报，两足尊能够了知，所以佛无与等者。）

【按】“诸果”，宋本作“识界”，元、宫本作“诸界”。

那时顺行力天子说偈赞叹：

```
修习如是界，造作如是业，
当还获是报，佛眼悉能知。
```
（大意：修习这样的界，造作这样的业，当还得这样的果报，佛眼都能了知。）

那时力起天子说偈赞叹：

```
修习如是界，成就如是性，
佛知诸众生，如观手五指。
```
（大意：修习这样的界，成就这样的性，佛了知众生，如看手上五指。）

那时力行天子说偈赞叹：

```
修习如是界，还值如是友，
如是相亲近，胜丈夫悉知。
```
（大意：修习这样的界，还会遇到这样的朋友，这样相互亲近，殊胜丈夫都了知。）

那时力加天子说偈赞叹：

```
加持于彼界，导师能了知，
亲近于诸友，人尊悉照见。
```
（大意：加持于那界，导师能了知，亲近于诸友，人中之尊都能照见。）

那时决定界天子说偈赞叹：

```
彼界彼要期，彼友彼相应，
佛悉决定知，故能除疑惑。
```
（大意：那界、那要期，那友、那相应，佛都决定了知，所以能除疑惑。）

那时正定界天子说偈赞叹：

```
彼界彼相续，随所住世间，
所行及诸趣，胜人皆悉知。
```
（大意：那界、那相续，随其所住的世间，所行以及诸趣，殊胜之人都了知。）

那时学界天子说偈赞叹：

```
于彼诸界中，导师智能知，
彼智体性空，胜智如是说。
```
（大意：在那些界中，导师的智慧能够了知，那智慧的体性是空，殊胜智者这样宣说。）

那时乘界天子说偈赞叹：

```
修习于彼界，随机时住世，
佛悉如实知，故号无比身。
```
（大意：修习那界，随机缘与时节住于世间，佛都如实了知，所以号为无比之身。）

那时随顺界天子说偈赞叹：

```
修习于彼界，随所得功德，
依因及果报，佛知悉无余。
```
（大意：修习那界，随其所得的功德，依于因以及果报，佛都了知无余。）

那时共界住天子说偈赞叹：

```
随所修习界，随其所向道，
佛悉知无余，故为智所敬。
```
（大意：随所修习的界，随其所趣向的道，佛都了知无余，所以为智者所敬。）

那时智行天子说偈赞叹：

```
随所修习界，随其所向道，
佛知众生行，故号学智者。
```
（大意：随所修习的界，随其所趣向的道，佛了知众生之行，所以号为学智者。）

那时行无畏天子说偈赞叹：

```
正定及邪定，及不定众生，
于此三聚中，佛能决定知。
```
（大意：正定聚、邪定聚以及不定聚的众生，在这三聚之中，佛能决定了知。）

那时乘行天子说偈赞叹：

```
若正定众生，堪趣涅槃者，
佛为世间日，于中智无碍。
```
（大意：若是正定聚的众生，堪能趣向涅槃，佛是世间的太阳，在其中智慧无碍。）

那时解脱行天子说偈赞叹：

```
若有诸众生，住于不定聚，
堕于诸恶道，亦为说涅槃。
```
（大意：若有众生住于不定聚，堕在诸恶道中，佛也为他们宣说涅槃。）

#### 赞假名二谛

那时力期会天子说偈赞叹：

```
佛者但假名，力智亦如是，
及四无畏等，但随言说有。
```
（大意：佛只是假名，力与智也是这样，以及四无畏等，只是随言说而有。）

那时见实天子说偈赞叹：

```
无佛及佛法，亦无余智聚，
显示第一义，如来如实知。
```
（大意：没有佛以及佛法，也没有其余的智聚，显示第一义，如来如实了知。）

那时力住天子说偈赞叹：

```
住于佛法力，因是得无畏，
自在随所欲，悉是诸佛子。
```
（大意：住于佛法之力，因此得到无畏，自在随其所欲，这些都是佛子。）

那时法无畏天子说偈赞叹：

```
世谛及真谛，显示此二种，
彼于真谛中，言说不可得。
```
（大意：世俗谛以及真谛，显示这两种，在那真谛之中，言说不可得。）

那时智尊天子说偈赞叹：

```
法言说各异，法相亦复异，
是言说无相，佛智是法相。
```
（大意：法的言说各不相同，法相也各不相同，这言说无相，佛智才是法相。）

【按】“佛智”之“智”，元、明本作“知”。

那时行精进天子说偈赞叹：

```
非处不定众，或向于异趣，
邪定一切处，大牟尼悉知。
```
（大意：非处、不定的众生，或趋向其他之趣，以及一切处的邪定众生，大牟尼都了知。）

#### 赞知信与根

那时信力天子说偈赞叹：

```
修习于彼界，如起信乐心，
见贪以为净，牟尼悉了知。
```
（大意：修习那界，如此生起信乐之心，见贪欲以为清净，牟尼都了知。）

那时不净乘天子说偈赞叹：

```
不实妄分别，增长贪欲界，
信则行彼道，牟尼如实知。
```
（大意：不实地虚妄分别，增长贪欲之界，若信则行那条道，牟尼如实了知。）

【按】“妄分别”之“妄”，《大正藏》作“忘”，今依CBETA（所录高丽藏）作“妄”。

那时慈乘行天子说偈赞叹：

```
不实妄分别，增长瞋恚界，
信则乘彼道，牟尼悉了知。
```
（大意：不实地虚妄分别，增长瞋恚之界，若信则乘那条道，牟尼都了知。）

那时乘因缘道天子说偈赞叹：

```
不实妄分别，增长愚痴界，
信则乘彼道，牟尼悉了知。
```
（大意：不实地虚妄分别，增长愚痴之界，若信则乘那条道，牟尼都了知。）

那时乘舍天子说偈赞叹：

```
有不活畏者，增长于嫉妬，
信彼则习行，牟尼悉了知。
```
（大意：有怖畏不能活命的人，增长嫉妒，若信那条道便习行它，牟尼都了知。）

那时习近善知识天子说偈赞叹：

```
近于善恶友，还增彼恶界，
还成于彼信，瞿昙悉了知。
```
（大意：亲近善友与恶友，还会增长那恶界，还会成就对那恶的信，瞿昙都了知。）

那时识坚固天子说偈赞叹：

```
流转于世间，随所修习界，
随顺信于彼，佛知悉无余。
```
（大意：流转于世间，随所修习的界，随顺信于那界，佛都了知无余。）

那时行坚固天子说偈赞叹：

```
流转于生死，修习如是行，
随顺信于彼，佛知悉无余。
```
（大意：流转于生死，修习这样的行，随顺信于那行，佛都了知无余。）

那时信根天子说偈赞叹：

```
若有诸众生，随所修习界，
佛悉能了知，故号无碍智。
```
（大意：若有众生，随其所修习的界，佛都能了知，所以号为无碍智。）

那时根行天子说偈赞叹：

```
佛了知诸根，随其方便起，
攀缘及境界，随所入如生。
```
（大意：佛了知诸根，随其方便而起，攀缘以及境界，随其所入如何生起（存疑）。）

那时乘根天子说偈赞叹：

```
身苦所逼迫，由贪著渴爱，
断灭诸渴爱，唯佛智为胜。
```
（大意：身被苦所逼迫，是由于贪著渴爱，断灭种种渴爱，唯有佛智最为殊胜。）

那时根境界天子说偈赞叹：

```
教下根众生，远离于色爱，
教利者观察，两足尊所说。
```
（大意：教导下根众生远离对色的爱，教导利根者观察，这是两足尊所说。）

那时根胜天子说偈赞叹：

```
下根住空闲，能灭于贪欲，
正观于渴爱，两足尊能知。
```
（大意：下根者住于空闲之处，能灭除贪欲，以正观观察渴爱，两足尊能够了知。）

那时根决定天子说偈赞叹：

```
于先起爱欲，佛观无所得，
知无知寂灭，故名为胜根。
```
（大意：对先前所起的爱欲，佛观察其无所得，了知无知寂灭，所以名为胜根（存疑）。）

那时不离根天子说偈赞叹：

```
远离不忿怒，是离瞋对治，
是下根所行，佛知众生欲。
```
（大意：远离而不忿怒，这是离瞋的对治，是下根者所行，佛了知众生的意乐。）

那时信根天子说偈赞叹：

```
行慈除瞋恚，能起众生智，
彼能灭恚界，人尊悉能知。
```
（大意：行慈以除瞋恚，能生起众生的智慧，他们能灭除瞋恚之界，人中之尊都能了知。）

那时求根天子说偈赞叹：

```
不瞋无过恶，慈行性寂灭，
净秽不可得，故号人中尊。
```
（大意：不瞋而没有过恶，慈行之性寂灭，净与秽都不可得，所以号为人中尊。）

那时根顺行天子说偈赞叹：

```
行于邪分别，为他说邪行，
惑重无方便，佛见倒解脱。
```
（大意：行于邪分别，为他人宣说邪行，迷惑深重而没有方便，佛见到他们颠倒地求解脱（存疑）。）

【按】“倒解脱”之“倒”，宋本作“而”。

那时智起天子说偈赞叹：

```
贪瞋恚痴等，取著于前事，
违彼得智明，大名称悉知。
```
（大意：贪、瞋、痴等，取著于眼前之事，违离它们而得智慧光明，大名称者都了知。）

那时离智爱天子说偈赞叹：

```
贪瞋及愚痴，及明暗事中，
其性不可得，两足尊悉知。
```
（大意：贪、瞋以及愚痴，以及明与暗的事中，其性不可得，两足尊都了知。）

【按】“事中”，元、明本作“中事”。

#### 赞知禅定解脱

那时持威德天子说偈赞叹：

```
众生所得智，随得智多少，
随所成智器，如来悉能知。
```
（大意：众生所得的智慧，随其得智的多少，随其所成就的智慧之器，如来都能了知。）

那时求根天子说偈赞叹：

```
以智知于智，远离诸烦恼，
天人师悉知，故我稽首礼。
```
（大意：以智知智，远离诸烦恼，天人师都了知，所以我稽首礼敬。）

【按】“知于智”之“于”，宫本作“求”。

那时一向乐根天子说偈赞叹：

```
国土及时节，观察法方便，
烦恼秽及净，如来悉知空。
```
（大意：国土以及时节，观察法的方便，烦恼之秽以及清净，如来都知其为空。）

那时智幢天子说偈赞叹：

```
众生根欲信，上中下差别，
缚解及智慧，悉见无觉知。
```
（大意：众生根性、意乐与信心，有上中下的差别，系缚、解脱以及智慧，佛都见其无有觉知。）

那时根幢天子说偈赞叹：

```
诸根上中下，烦恼智及受，
调伏不调伏，佛说悉无相。
```
（大意：诸根的上中下，烦恼、智慧以及受，调伏与不调伏，佛说都是无相。）

那时修根天子说偈赞叹：

```
禅解脱烦恼，正受三摩提，
起清净众生，如来悉能知。
```
（大意：禅定、解脱、烦恼，正受、三摩提，从中生起的清净众生，如来都能了知。）

那时力速疾天子说偈赞叹：

```
得禅寂灭故，于诸法自性，
悉皆能了知，故号一切智。
```
（大意：因为得禅定寂灭，对诸法的自性，都能了知，所以号为一切智。）

那时力铠天子说偈赞叹：

```
若法及自性，能说于此法，
能如实正受，故不著三世。
```
（大意：若法以及自性，能宣说此法，能如实正受，所以不执著于三世。）

那时乐力天子说偈赞叹：

```
烦恼邪分别，起生于四种，
能知业所生，故号无比人。
```
（大意：烦恼、邪分别，生起四种，能知业之所生，所以号为无比之人。）

那时知力天子说偈赞叹：

```
能知清净法，对治于烦恼，
能宣说于业，故号佛无比。
```
（大意：能知清净之法，对治于烦恼，能宣说业，所以号为无比之佛。）

那时力士天子说偈赞叹：

```
于禅解脱起，三摩提正受，
烦恼及清净，佛悉说虚假。
```
（大意：从禅定、解脱而起，三摩提、正受，烦恼以及清净，佛都说为虚假。）

【按】天子名“力士”，宋、元、明、宫本作“力生”。

那时力生天子说偈赞叹：

```
禅解脱清净，三昧及正受，
彼从不逸生，佛于此悉知。
```
（大意：禅定、解脱、清净，三昧以及正受，它们从不放逸而生，佛对此都了知。）

那时力增长天子说偈赞叹：

```
大雄于此中，能于禅等转，
知入舍无碍，如风行于空。
```
（大意：大雄在其中，能于禅定等运转，知入与出都无碍，如风行于空中。）

#### 赞知前际

那时知前际天子说偈赞叹：

```
于无数亿劫，住于诸有中，
不为有过染，故号胜丈夫。
```
（大意：在无数亿劫中，住于诸有之中，不被有的过失所染，所以号为殊胜丈夫。）

那时住前际天子说偈赞叹：

```
于无数亿佛，已曾修供养，
为求无上道，是故我归依。
```
（大意：在无数亿佛所，已曾修习供养，为求无上道，所以我归依。）

那时见前际天子说偈赞叹：

```
曾于过去世，种种奉施佛，
于其种种辩，人尊悉获得。
```
（大意：曾在过去世中，以种种物奉施于佛，对于种种辩才，人中之尊都已获得。）

那时前际善巧天子说偈赞叹：

```
昔流转世间，如法学如行，
曾见无量佛，故能深解法。
```
（大意：往昔流转于世间，如法而学，如学而行，曾见无量佛，所以能深解法。）

那时学前际天子说偈赞叹：

```
诸佛法王所，大雄昔修行，
于佛边学已，故礼知众行。
```
（大意：在诸佛法王之所，大雄往昔修行，在佛身边修学之后，所以礼敬了知众行的人。）

那时本方便具足天子说偈赞叹：

```
于无量亿劫，无边诸佛行，
修行胜精进，为求佛智故。
```
（大意：在无量亿劫中，修行无边诸佛之行，修行殊胜的精进，是为求佛的智慧。）

那时本方便决定天子说偈赞叹：

```
一切法决定，多亿劫观察，
一切法无入，但说缘和合。
```
（大意：一切法决定，经多亿劫观察，一切法无所入，只说是因缘和合。）

那时思前际天子说偈赞叹：

```
于无量亿劫，导师曾修行，
知于处非处，故名解世间。
```
（大意：在无量亿劫中，导师曾经修行，了知处与非处，所以名为世间解。）

那时简择前际天子说偈赞叹：

```
住于处非处，观察于业因，
界根禅解脱，佛悉能知彼。
```
（大意：安住于处与非处，观察业因，界、根、禅定、解脱，佛都能了知。）

那时观察前际天子说偈赞叹：

```
过去曾观察，增长智慧力，
十力大雄猛，以智观世间。
```
（大意：过去曾经观察，增长智慧之力，十力大雄猛，以智慧观察世间。）

那时前际境界天子说偈赞叹：

```
大雄本修行，知一切众生，
净行不净行，故能治众生。
```
（大意：大雄本来修行，了知一切众生，清净之行与不清净之行，所以能对治众生。）

那时观察前际行天子说偈赞叹：

```
先观于众生，过去之所行，
信乐及与界，然后治众生。
```
（大意：先观察众生过去所行，以及信乐与界，然后对治众生。）

那时信力天子说偈赞叹：

```
我今信如来，不可思议劫，
观察本所行，心悉无所著。
```
（大意：我现在信如来，在不可思议劫中，观察本来所行，心都无所执著。）

那时智信天子说偈赞叹：

```
于无数亿劫，思佛昔所行，
善男子无能，测尽如来德。
```
（大意：在无数亿劫中思惟佛往昔所行，善男子没有人能测尽如来的功德。）

【按】“测尽”之“测”，宋、宫本作“恻”。

#### 赞天眼知业报

那时观后际善巧天子说偈赞叹：

```
如来以佛眼，观十方众生，
初生及与死，种种业相应。
```
（大意：如来以佛眼观察十方众生，初生以及死亡，与种种业相应。）

那时学后际天子说偈赞叹：

```
若因及以业，随趣向佛道，
牟尼悉知彼，故号一切智。
```
（大意：若因以及业，随其趣向佛道，牟尼都了知，所以号为一切智。）

那时识生死天子说偈赞叹：

```
若众生以界，熏习造诸业，
众生及业习，佛了知无觉。
```
（大意：若众生以界熏习而造诸业，众生以及业的熏习，佛了知其无有觉知。）

那时知生死天子说偈赞叹：

```
近如是朋友，造作如是业，
趣向如是道，牟尼悉了知。
```
（大意：亲近这样的朋友，造作这样的业，趣向这样的道，牟尼都了知。）

那时所须善巧天子说偈赞叹：

```
能知于所须，随其如作业，
如是作业已，如来悉了知。
```
（大意：能知所需，随其所作之业，这样作业之后，如来都了知。）

【按】“如作业”之“如”，明本作“所”。

那时事善巧天子说偈赞叹：

```
依于如是事，造作如是业，
佛悉能知彼，皆是佛境界。
```
（大意：依于这样的事，造作这样的业，佛都能了知，这都是佛的境界。）

那时知事天子说偈赞叹：

```
随所执著事，能有所造作，
佛了诸根故，悉能知彼业。
```
（大意：随其所执著的事，能有所造作，佛了知诸根，所以都能了知那业。）

那时智善巧天子说偈赞叹：

```
若智及与事，佛知彼妄想，
随彼如执著，佛亦知无余。
```
（大意：若智以及事，佛知其为妄想，随其如何执著，佛也了知无余。）

那时修作善巧天子说偈赞叹：

```
随执著造业，由于烦恼故，
佛悉能知彼，故为世间归。
```
（大意：随其执著而造业，是由于烦恼的缘故，佛都能了知，所以为世间所归依。）

那时趣善巧天子说偈赞叹：

```
随趣如造业，随业得彼果，
随所缘作业，佛眼悉了知。
```
（大意：随其所趣而造业，随其业而得那果报，随其所缘而作业，佛眼都了知。）

那时攀缘善巧天子说偈赞叹：

```
能知于所缘，随缘业成熟，
于诸趣受报，佛悉知无失。
```
（大意：能知所缘，随缘而业成熟，于诸趣中受报，佛都了知而无失误。）

那时习气善巧天子说偈赞叹：

```
知恶业习气，善业亦复然，
知过去所行，众生趣趣中。
```
（大意：了知恶业的习气，善业也是这样，了知过去所行，众生在各趣之中。）

那时业善巧天子说偈赞叹：

```
能知三种业，现未及过去，
众生于趣中，凡于中迷惑。
```
（大意：能知三种业，现在、未来以及过去，众生在诸趣中，凡夫对此迷惑。）

那时报善巧天子说偈赞叹：

```
少作得多报，多作得少报，
及知多少等，外道于中惑。
```
（大意：少作而得多报，多作而得少报，以及知其多少相等，外道对此迷惑。）

那时学业天子说偈赞叹：

```
知于现报业，亦知生报业，
及以后报业，佛眼悉能了。
```
（大意：了知现报之业，也了知生报之业，以及后报之业，佛眼都能了知。）

那时知现法业天子说偈赞叹：

```
若现世作业，现在则受报，
佛悉能了知，凡夫不能解。
```
（大意：若现世作业，现在便受报，佛都能了知，凡夫不能理解。）

那时知生报天子说偈赞叹：

```
若作如是业，于异生得报，
彼大智悉知，众生不能了。
```
（大意：若作这样的业，在另一生得报，那大智者都了知，众生不能了知。）

那时知后报天子说偈赞叹：

```
若业多亿劫，然后得受报，
或复过于彼，如来悉了知。
```
（大意：若业经多亿劫，然后才受报，或更超过那劫数，如来都了知。）

那时知业不熟天子说偈赞叹：

```
若所造作业，其业缘未熟，
未得于果报，如来悉了知。
```
（大意：若所造作之业，其业缘尚未成熟，还未得到果报，如来都了知。）

那时观业未熟天子说偈赞叹：

```
如来善观业，若业相应时，
生于诸众生，悉皆能善说。
```
（大意：如来善于观察业，若业相应之时，生于众生之中，都能善加宣说。）

那时善知业熟天子说偈赞叹：

```
彼业若成熟，能与当来报，
佛能如实知，亦知彼智空。
```
（大意：那业若成熟，能给与未来之报，佛能如实了知，也了知那智慧是空。）

那时业熟决定天子说偈赞叹：

```
一切智了达，轻业及以重，
能知众生欲，故得为我尊。
```
（大意：一切智者了达轻业以及重业，能知众生的意乐，所以得为我们所尊。）

那时知业轻重天子说偈赞叹：

```
趣恶道众生，随其业如见，
彼业若轻重，智者悉了知。
```
（大意：趣向恶道的众生，随其业如何显现，那业是轻是重，智者都了知。）

那时知众生行天子说偈赞叹：

```
见众生所行，及轻重诸业，
雄猛随顺知，外道不能了。
```
（大意：见到众生所行，以及轻重诸业，雄猛者随顺了知，外道不能了知。）

那时观众生行天子说偈赞叹：

```
观于众生行，宣说于业报，
如器恒河水，投盐于一两。
```
（大意：观察众生之行，宣说业报，如以器盛恒河之水，投下一两盐（存疑）。）

那时学业天子说偈赞叹：

```
若受于思业，佛说业究竟，
亦学无学报，胜仙已宣说。
```
（大意：若受于思业，佛说业的究竟，也修学有学、无学之报，殊胜仙人已经宣说（存疑）。）

那时乐佛智天子说偈赞叹：

```
佛胜眼所见，三界中愚智，
随业受于报，见微细顶礼。
```
（大意：佛以殊胜之眼所见，三界中的愚者与智者，随其业而受报，见到微细之处，我顶礼。）

那时说业尽天子说偈赞叹：

```
生死众生所，世尊大导师，
悉了知无余，故礼智无畏。
```
（大意：生死中的众生之所，世尊大导师都了知无余，所以礼敬智慧无畏者。）

#### 赞漏尽如梦幻

那时无所得天子说偈赞叹：

```
若业生及死，众生各趣趣，
彼报由如梦，两足尊悉知。
```
（大意：若业、生以及死，众生各在诸趣中，那果报犹如梦境，两足尊都了知。）

【按】“生及死”，元、明本作“及生死”。“由如梦”之“由”，元、明本作“犹”。

那时求烦恼天子说偈赞叹：

```
贪欲瞋恚痴，两足尊悉尽，
犹如梦渴人，饮于清冷水。
```
（大意：贪欲、瞋恚、愚痴，两足尊都已断尽，犹如梦中口渴的人，喝下清凉的冷水。）

那时离分别天子说偈赞叹：

```
从于分别生，贪欲瞋恚痴，
犹如梦中戏，归命胜说者。
```
（大意：从分别而生起贪欲、瞋恚、愚痴，犹如梦中的游戏，归命殊胜的说法者。）

那时灭分别天子说偈赞叹：

```
若灭于分别，则名尽烦恼，
如梦见云散，人尊显现此。
```
（大意：若灭除分别，就名为断尽烦恼，如梦中见云散去，人中之尊显现此理。）

那时观察漏尽天子说偈赞叹：

```
如梦见天雨，起漏亦如是，
大雄能显示，起漏之因缘。
```
（大意：如梦中见天降雨，生起诸漏也是这样，大雄能够显示生起诸漏的因缘。）

那时观察梦天子说偈赞叹：

```
如梦见大雨，起漏亦如是，
大雄能显示，凡迷惑生漏。
```
（大意：如梦中见大雨，生起诸漏也是这样，大雄能够显示凡夫迷惑而生起诸漏。）

【按】“大雨”之“大”，明本作“天”。

那时观如梦天子说偈赞叹：

```
如梦见天雨，随顺起诸漏，
大雄能显示，凡迷生诸漏。
```
（大意：如梦中见天降雨，随顺而生起诸漏，大雄能够显示凡夫迷惑而生起诸漏。）

那时如自性知天子说偈赞叹：

```
如女梦生子，生已还复死，
生喜亦生悲，佛观世亦然。
```
（大意：如女人梦中生子，生后又死去，生起欢喜，也生起悲伤，佛观察世间也是这样。）

那时思量梦天子说偈赞叹：

```
如梦见斩首，尽漏亦如是，
自解亦教他，故礼悉解者。
```
（大意：如梦中见斩首，漏尽也是这样，自己解了，也教导他人，所以礼敬都已解了的人。）

那时修习慧天子说偈赞叹：

```
见法能解了，如梦遇爱事，
远离彼非实，如是悦世间。
```
（大意：见法而能解了，如梦中遇到可爱之事，远离那不实之事，这样令世间欢悦。）

那时智心天子说偈赞叹：

```
闻于如来法，以空法自悦，
如梦中说梦，如是晓世间。
```
（大意：听闻如来之法，以空法自我欢悦，如在梦中说梦，这样开晓世间。）

那时欣喜意天子说偈赞叹：

```
禅定者能令，世间天人喜，
观察于诸趣，犹如镜中像。
```
（大意：修禅定的人能令世间天人欢喜，观察诸趣，犹如镜中之像。）

【按】天子名“欣喜意”之“欣”，宋、元、明本作“欢”。

那时决定慧天子说偈赞叹：

```
闻于如来法，由如箜篌音，
渡人天疑海，故礼人中王。
```
（大意：听闻如来之法，犹如箜篌之音，渡过人天的疑惑之海，所以礼敬人中之王。）

【按】“由如”之“由”，元、明本作“犹”。

那时幻喜天子说偈赞叹：

```
如人作幻化，迷惑于愚人，
智者终不迷，知幻不实故。
```
（大意：如人作幻化，迷惑愚人，智者终不迷惑，因为知道幻化不实。）

那时除相天子说偈赞叹：

```
观于一切世，犹如梦作幻，
我于中无疑，以闻佛法故。
```
（大意：观察一切世间，犹如梦中所作的幻事，我对此没有疑惑，因为听闻了佛法。）

那时学幻天子说偈赞叹：

```
如幻师作幻，自于幻不迷，
以知幻虚故，佛观世亦然。
```
（大意：如幻师作幻，自己对幻不迷惑，因为知道幻是虚假的，佛观察世间也是这样。）

那时观妄想天子说偈赞叹：

```
妄想生世间，大导师悉知，
如精进念佛，梦中即见佛。
```
（大意：妄想生起世间，大导师都了知，如精进念佛的人，在梦中便见到佛。）

那时灭妄想天子说偈赞叹：

```
非事能生欲，皆由妄想起，
不实妄起欲，人尊如实知。
```
（大意：不是由事物能生起欲望，都是由于妄想而起，不实而妄起欲望，人中之尊如实了知。）

那时识解天子说偈赞叹：

```
犹如深谷声，其响无有实，
是故不著世，如是观世间。
```
（大意：犹如深谷中的声音，其回响并无实体，所以不执著于世间，这样观察世间。）

那时说善巧天子说偈赞叹：

```
彼声无有实，而于中听闻，
人尊宣说此，救拔诸凡愚。
```
（大意：那声音没有实体，而在其中听闻，人中之尊宣说此理，救拔凡愚。）

那时如说行善巧天子说偈赞叹：

```
于法别义中，众生异妄取，
能行者知法，于中除疑惑。
```
（大意：对于法的各别义理，众生各异地妄取，能修行的人了知法，在其中除去疑惑。）

那时顺义行天子说偈赞叹：

```
若义及法实，无有能了者，
无说亦无证，牟尼作是说。
```
（大意：若义理以及法的真实，没有能了知的人，无说也无证，牟尼这样宣说。）

那时法假名行天子说偈赞叹：

```
烦恼垢漏习，皆想妄分别，
秽污及清净，但假名言说。
```
（大意：烦恼、垢、漏、习气，都是妄想分别，秽污以及清净，只是假名言说。）

那时分别善巧天子说偈赞叹：

```
一切但名字，谓烦恼漏等，
秽污及清净，大智之所说。
```
（大意：一切只是名字，所谓烦恼、漏等，秽污以及清净，这是大智者所说。）

#### 赞离爱

那时无依慧天子说偈赞叹：

```
于三界不著，其心如虚空，
离恶真福田，顶礼心寂灭。
```
（大意：对三界不执著，其心如虚空，远离恶法的真福田，顶礼心已寂灭的人。）

那时不下劣天子说偈赞叹：

```
非色非非色，非欲非涅槃，
佛心无所依，其犹如虚空。
```
（大意：非色也非非色，非欲也非涅槃，佛心无所依止，犹如虚空。）

那时无欲天子说偈赞叹：

```
离于欲界爱，色无色亦然，
解脱于贪碍，顶礼爱尽者。
```
（大意：远离欲界之爱，色界、无色界也是这样，解脱于贪的障碍，顶礼爱已断尽的人。）

【按】“贪碍”之“碍”，宋、元、明、宫本作“痴”。

那时远离爱天子说偈赞叹：

```
于有无有中，佛永断远离，
于三界无著，顶礼牟尼王。
```
（大意：于有与无有之中，佛永远断除、远离，对三界没有执著，顶礼牟尼之王。）

那时障爱天子说偈赞叹：

```
障蔽于三界，行于丈夫行，
能解脱众生，归命救济者。
```
（大意：障蔽于三界，行大丈夫之行，能令众生解脱，归命救济者。）

那时解脱渴爱天子说偈赞叹：

```
远离于结使，于后尽生灭，
身心皆清净，顶礼无热亲。
```
（大意：远离结使，于后际尽除生灭，身心都清净，顶礼无热恼的世间之亲。）

【按】“无热亲”之“热”，宋、元、明、宫本作“怨”。

那时知自性天子说偈赞叹：

```
大雄解自在，知法中无事，
无缚亦无解，顶礼见实者。
```
（大意：大雄理解自在，知法中无有事物，无缚也无解，顶礼见到真实的人。）

【按】“自在”之“在”，元、明、宫本作“性”。

那时出瘀泥天子说偈赞叹：

```
远离爱欲泥，亦离于诸有，
无取亦无舍，顶礼尽后有。
```
（大意：远离爱欲的泥淖，也远离诸有，无取也无舍，顶礼已尽后有的人。）

【按】天子名“出瘀泥”之“瘀”，元、明本作“淤”。

那时吐弃资缘天子说偈赞叹：

```
弃垢及资缘，舍罪亦远爱，
亦离于诸盖，归命大导师。
```
（大意：弃舍污垢以及资缘，舍弃罪过，也远离爱，又远离诸盖，归命大导师。）

那时弃欲天子说偈赞叹：

```
弃舍利不利，无著行决定，
出离于魔网，顶礼无著者。
```
（大意：弃舍利与不利，无所执著，行持决定，出离魔网，顶礼无所执著的人。）

那时乐利益天子说偈赞叹：

```
若自及他道，远离恼热者，
大雄见彼道，顶礼无碍见。
```
（大意：若自道以及他道，远离恼热的人，大雄见到那道，顶礼无碍之见。）

那时得名称天子说偈赞叹：

```
与佛智相应，如说如观者，
彼能除烦恼，顶礼解世间。
```
（大意：与佛智相应，如所说而观察的人，他们能除烦恼，顶礼世间解。）

#### 赞师子吼无畏

那时无畏天子说偈赞叹：

```
于诸法决定，无能当对者，
师子吼无畏，智海吼亦然。
```
（大意：对于诸法决定，没有能与之对抗的人，如狮子吼而无所畏惧，智慧之海的吼声也是这样。）

那时一切处无所畏天子说偈赞叹：

```
善度一切处，远离诸毒箭，
无畏不怯弱，我礼最胜者。
```
（大意：善于度过一切处，远离种种毒箭，无畏而不怯弱，我礼敬最胜者。）

那时无所希天子说偈赞叹：

```
非天乾闼婆，非魔及与梵，
能有难问者，故佛如师子。
```
（大意：无论天、乾闼婆，或魔以及梵天，没有能够诘难的人，所以佛如狮子。）

那时师子游步天子说偈赞叹：

```
佛于法无畏，晓了诸法故，
无碍故无著，无能难问者。
```
（大意：佛对法无所畏惧，因为晓了诸法，因为无碍所以无著，没有能诘难的人。）

那时无怖天子说偈赞叹：

```
如山林师子，无怖亦无畏，
摧伏诸禽兽，林中而大吼。
世尊如是吼，惊怖诸外道，
天龙乾闼婆，不见敌对者。
```
（大意：如山林中的狮子，无怖也无畏，摧伏众禽兽，在林中大吼。世尊也这样吼，惊怖诸外道，天、龙、乾闼婆，都不见有能对敌的人。）

那时一切处超胜天子说偈赞叹：

```
一切三界中，悉皆都无有，
力敌于佛者，故为我归依。
```
（大意：在一切三界之中，全都没有力量能敌佛的人，所以是我的归依。）

那时师子慧天子说偈赞叹：

```
大智见一切，于诸法无畏，
世间无与等，我礼无所畏。
```
（大意：大智者见一切，对诸法无所畏惧，世间无与等者，我礼敬无所畏的人。）

那时称顺生天子说偈赞叹：

```
自知是正觉，如法无能难，
若有能难者，世间悉无有。
```
（大意：自知是正觉，如法而无人能诘难，若说有能诘难的人，世间都没有。）

【按】“世间”之“间”，宫本作“闻”。

那时持藏天子说偈赞叹：

```
佛作师子吼，开显诸法藏，
亿梵闻说已，悉发菩提心。
```
（大意：佛作狮子吼，开显诸法之藏，亿数梵天听闻之后，都发菩提心。）

那时顺威仪天子说偈赞叹：

```
彼众得大利，顺佛威仪者，
发菩提心已，必作胜导师。
```
（大意：他们大众得大利益，随顺佛威仪的人，发菩提心之后，必定成为殊胜导师。）

那时顺乐法天子说偈赞叹：

```
彼世大众生，得闻佛法已，
能发菩提心，必成妙丈夫。
```
（大意：那世间的大众生，听闻佛法之后，能发菩提心，必定成就妙丈夫。）

那时净心天子说偈赞叹：

```
得闻佛说已，世间无与比，
千亿众生等，发胜菩提心。
```
（大意：听闻佛的宣说之后，世间无与伦比，千亿众生等发起殊胜的菩提心。）

那时清净流天子说偈赞叹：

```
人王于长夜，佛学善修习，
故佛身清净，严相三十二。
```
（大意：人中之王在长夜中，修学佛道，善加修习，所以佛身清净，以三十二相庄严。）

那时无漏心天子说偈赞叹：

```
佛得尽漏故，而作师子吼，
得上智慧山，无能难问者。
```
（大意：佛因为得以尽漏，而作狮子吼，登上最上的智慧之山，没有能诘难的人。）

那时顺众生天子说偈赞叹：

```
三界中悉无，天人及修罗，
言佛漏不尽，故佛具十力。
```
（大意：三界中都没有天、人以及阿修罗能说佛的漏未尽，所以佛具足十力。）

那时巧尽漏天子说偈赞叹：

```
大胜沙门漏，皆悉尽无余，
于是无能难，故佛是我父。
```
（大意：大胜沙门的诸漏，都已断尽无余，于是没有能诘难的人，所以佛是我的父亲。）

那时常精进天子说偈赞叹：

```
于人王能难，言有余烦恼，
世间不可得，故佛自在父。
```
（大意：说人中之王还有剩余的烦恼，能这样诘难的人，世间不可得，所以佛是自在之父。）

【按】“自在父”之“父”，宋本作“天”。

那时寂灭行天子说偈赞叹：

```
佛已断贪瞋，愚痴及习气，
亦灭恶业行，我礼寂灭者。
```
（大意：佛已断除贪、瞋、愚痴以及习气，也灭除恶业之行，我礼敬寂灭者。）

那时方便行天子说偈赞叹：

```
若以方便观，断尽诸烦恼，
彼佛满足智，是故我顶礼。
```
（大意：若以方便观察，断尽诸烦恼，那佛智慧圆满，所以我顶礼。）

那时方便解天子说偈赞叹：

```
无量巧方便，导师于中修，
断彼诸烦恼，皆悉尽无余。
```
（大意：无量的善巧方便，导师在其中修习，断除那些烦恼，都已断尽无余。）

那时方便慧天子说偈赞叹：

```
导师照世间，巧慧无有尽，
故断诸烦恼，及以习气等。
```
（大意：导师照耀世间，善巧智慧无有穷尽，所以断除诸烦恼以及习气等。）

那时修寂灭天子说偈赞叹：

```
断诸烦恼故，习气悉无余，
于是佛大智，不动无所畏。
```
（大意：因为断除诸烦恼，习气也都无余，于是佛的大智慧，不动而无所畏惧。）

那时观道理天子说偈赞叹：

```
佛断烦恼尽，及灭诸习气，
照明如佛者，世间更无比。
```
（大意：佛已断尽烦恼，并灭除诸习气，照明如佛的人，世间再无可比。）

那时断使天子说偈赞叹：

```
佛断诸习气，无有腥臭事，
故佛一切智，天中最胜慧。
```
（大意：佛断除诸习气，没有腥臭之事，所以佛具一切智，是天中最殊胜的智慧。）

那时住边天子说偈赞叹：

```
佛今最后身，已断生因缘，
由尽诸漏故，世亲得无畏。
```
（大意：佛现今是最后身，已断除受生的因缘，由于尽除诸漏，世间之亲得到无畏。）

那时无量智天子说偈赞叹：

```
大雄断种子，焚烧苦恼牙，
枯涸忧枝蔓，我礼离恼者。
```
（大意：大雄断除种子，焚烧苦恼之芽，枯干忧愁的枝蔓，我礼敬远离苦恼的人。）

【按】“苦恼牙”之“牙”，元、明本作“芽”。

那时出坑㵎天子说偈赞叹：

```
世尊一切智，已离无明坑，
佛行已得净，故佛得无畏。
```
（大意：世尊一切智者已离开无明之坑，佛的行为已得清净，所以佛得无畏。）

【按】“㵎”字先前电子文本未能显示，今据《大正藏》补出，即“涧”字。

那时度有天子说偈赞叹：

```
已度于有海，导师所作办，
亦舍于彼岸，自利得无畏。
```
（大意：已度过有之海，导师所作已办，也舍弃那彼岸，自利已成而得无畏。）

那时入涅槃天子说偈赞叹：

```
佛已得寂灭，悉破诸烦恼，
乃至少习气，世亲皆悉无。
```
（大意：佛已得寂灭，破除一切烦恼，乃至少许习气，世间之亲都已没有。）

#### 赞法幢与佛子发心

那时法幢天子说偈赞叹：

```
佛建正法幢，摧折憍慢幢，
大雄已显示，无量诸法行。
```
（大意：佛建立正法之幢，摧折憍慢之幢，大雄已经显示无量诸法之行。）

那时法性天子说偈赞叹：

```
性与诸子本，牟尼达诸法，
善友于群生，我礼最胜海。
```
（大意：本性与诸子之本，牟尼通达诸法，是群生的善友，我礼敬最胜之海（存疑）。）

【按】“诸子”之“子”，明本作“了”。

那时法充天子说偈赞叹：

```
渴乐于佛法，故得无所畏，
无著诸佛子，而作师子吼。
```
（大意：渴乐于佛法，所以得无所畏，无所执著的诸佛子，便作狮子吼。）

那时求法天子说偈赞叹：

```
为求诸法故，佛子得发心，
及见佛无畏，有知求菩提。
```
（大意：为了求诸法，佛子得以发心，以及见到佛的无畏，有智者求菩提。）

【按】“有知”之“知”，宋、元、明、宫本作“智”。

那时渴法天子说偈赞叹：

```
渴乐佛法故，多亿众生辈，
闻佛无畏已，深发大精进。
```
（大意：因为渴乐佛法，多亿众生们，听闻佛的无畏之后，深发大精进。）

那时法起天子说偈赞叹：

```
见佛说法胜，建立于正法，
无畏布施已，佛子求菩提。
```
（大意：见佛说法殊胜，建立于正法，施予无畏之后，佛子求菩提。）

那时持法天子说偈赞叹：

```
世尊所说法，甚深难可见，
佛子得闻已，求无上菩提。
```
（大意：世尊所说之法，甚深而难以得见，佛子听闻之后，求无上菩提。）

那时无悋天子说偈赞叹：

```
身命及余财，佛子无悋惜，
闻佛师子吼，悉求妙菩提。
```
（大意：对身命以及其余财物，佛子都无所吝惜，听闻佛的狮子吼，都求妙菩提。）

那时无异慧天子说偈赞叹：

```
闻佛说法已，心思无有异，
于佛无畏所，求法持律仪。
```
（大意：听闻佛说法之后，心思没有异念，在佛的无畏之所，求法而持守律仪。）

那时无异行天子说偈赞叹：

```
闻法王吼已，不趣于异路，
远离于二乘，求无上菩提。
```
（大意：听闻法王之吼后，不趣向其他道路，远离二乘，求无上菩提。）

【按】“闻法王吼已”，宫本作“闻人三吼已”。

那时近住天子说偈赞叹：

```
见佛师子吼，诸子得闻已，
定得胜菩提，当成如来身。
```
（大意：见佛作狮子吼，诸子听闻之后，必定得殊胜菩提，当成就如来之身。）

那时近辩天子说偈赞叹：

```
于佛世尊所，得闻辩才已，
如来妙法中，深生喜乐心。
```
（大意：在佛世尊之所，听闻辩才之后，在如来的妙法中，深生喜乐之心。）

那时得辩才天子说偈赞叹：

```
佛吼无畏时，所说不可毁，
信乐心决定，终无退转意。
```
（大意：佛作无畏之吼时，所说不可毁坏，信乐之心决定，终无退转之意。）

那时常喜天子说偈赞叹：

```
十力吼无畏，所有诸佛子，
一切时欣喜，心调求菩提。
```
（大意：十力者作无畏之吼，所有诸佛子，一切时都欢喜，心已调柔而求菩提。）

【按】“欣喜”之“欣”，宋、元、明本作“欢”。

那时无怯弱心天子说偈赞叹：

```
常喜不怯弱，世尊诸佛子，
乐求胜菩提，以闻佛语故。
```
（大意：常常欢喜而不怯弱，世尊的诸佛子，乐求殊胜菩提，因为听闻了佛语。）

那时无碍心天子说偈赞叹：

```
彼等求佛心，终不有退转，
欣喜微妙心，闻佛善说故。
```
（大意：他们求佛之心，终究不会退转，以欢喜微妙之心，因为听闻佛的善说。）

#### 赞说障道法无畏

那时巧知无边法天子说偈赞叹：

```
以修正法故，白法党不减，
导师知非处，不生厌足心。
```
（大意：因为修习正法，白法一方不减，导师知道这是非处，不生厌足之心。）

那时巧说法天子说偈赞叹：

```
修行黑法党，若不退减者，
世尊知非处，故佛无所畏。
```
（大意：修行黑法一方，若说不退减，世尊知道这是非处，所以佛无所畏。）

那时法性无畏天子说偈赞叹：

```
黑法体性尔，必当秽净法，
彼不污心者，佛知彼非处。
```
（大意：黑法的体性如此，必当秽染清净之法，说它不污染心，佛知道这是非处（存疑）。）

那时巧相应天子说偈赞叹：

```
黑法及白法，二异不相合，
佛说于彼义，故佛是我师。
```
（大意：黑法以及白法，二者相异而不相合，佛宣说那义理，所以佛是我的导师。）

那时巧知善不善天子说偈赞叹：

```
大雄皆悉知，诸法不杂聚，
妄想分别故，于善法中退。
```
（大意：大雄都了知诸法不杂乱聚集，由于妄想分别，所以在善法中退失。）

【按】“分别故”之“故”，宋、宫本作“说”。

那时如说行满足天子说偈赞叹：

```
行于烦恼者，终不生白法，
不生白法故，当知必退减。
```
（大意：行于烦恼的人，终究不生白法，因为不生白法，应当知道必定退减。）

那时乐解脱天子说偈赞叹：

```
若乐解脱者，修行于黑法，
佛说彼有障，故佛一切智。
```
（大意：若是乐于解脱的人，却修行黑法，佛说他有障碍，所以佛具一切智。）

那时净心天子说偈赞叹：

```
心乐解脱者，须知烦恼事，
大雄说此法，故佛应受供。
```
（大意：心乐解脱的人，必须了知烦恼之事，大雄宣说此法，所以佛应受供养。）

那时见烦恼天子说偈赞叹：

```
行于烦恼中，不识烦恼者，
彼不知正法，善逝如是说。
若言行诸恶，不退善法者，
于解脱非器，两足尊所说。
```
（大意：行于烦恼之中，却不认识烦恼的人，他们不知正法，善逝这样宣说。若说行种种恶，却不退失善法，这样的人不是解脱之器，这是两足尊所说。）

那时调伏天子说偈赞叹：

```
离欲及愦閙，亦离瞋痴等，
如佛所说法，应当如是修。
烦恼及白法，愚痴不知者，
佛于彼非师，大仙如是说。
```
（大意：远离欲望以及愦闹，也远离瞋、痴等，如佛所说之法，应当这样修习。烦恼以及白法，愚痴者不了知，佛不是他们的导师，大仙这样宣说。）

那时勤修解脱天子说偈赞叹：

```
佛说对治法，为除烦恼故，
行彼不尽惑，无能击难者。
```
（大意：佛宣说对治之法，是为了除去烦恼，修行它而不能断尽迷惑的，没有能以此诘难佛的人。）

那时向解脱天子说偈赞叹：

```
佛说如是法，为断烦恼故，
若修不灭惑，无能击难者。
```
（大意：佛宣说这样的法，是为了断除烦恼，若修习而不灭迷惑，没有能以此诘难佛的人。）

那时方便相应天子说偈赞叹：

```
佛是说法者，为诸声闻等，
若修不证者，无能击难佛。
```
（大意：佛是说法者，为诸声闻等宣说，若修习而不证悟，没有能以此诘难佛的人。）

那时趣解脱天子说偈赞叹：

```
佛说如是法，为欲断烦恼，
若不灭惑者，无能击难佛。
```
（大意：佛宣说这样的法，是为了断除烦恼，若有不灭迷惑的，没有能以此诘难佛的人。）

那时无畏功德天子说偈赞叹：

```
为灭烦恼故，佛说不净观，
若不尽灭者，无能击难佛。
```
（大意：为了灭除烦恼，佛宣说不净观，若有不能尽灭的，没有能以此诘难佛的人。）

那时善发心必修天子说偈赞叹：

```
慈能断瞋恚，修慈若不断，
无能击难佛，世尊得无畏。
```
（大意：慈心能断瞋恚，修慈若不能断，没有能以此诘难佛的人，世尊得无畏。）

那时净目天子说偈赞叹：

```
佛说能修彼，智慧除愚痴，
若彼不断者，无能击难佛。
```
（大意：佛说能修习那智慧，以除去愚痴，若他不能断除，没有能以此诘难佛的人。）

那时灭觉观天子说偈赞叹：

```
为觉对治故，说于安般念，
修彼不灭者，无能击难佛。
```
（大意：为了对治觉观，宣说安般念，修习它而不能灭除的，没有能以此诘难佛的人。）

那时尊重无相天子说偈赞叹：

```
为断吾我故，佛说空寂灭，
以彼不灭者，于是无能难。
```
（大意：为了断除吾我，佛宣说空与寂灭，以此不能灭除的，于是没有能诘难的人。）

那时断我慢天子说偈赞叹：

```
为断憍慢故，佛说无相法，
若修不灭者，不见能难佛。
```
（大意：为了断除憍慢，佛宣说无相之法，若修习而不能灭除，不见有能诘难佛的人。）

那时净身天子说偈赞叹：

```
深心信清净，一切烦恼尽，
修彼不断者，无能击难者。
```
（大意：深心信解清净，一切烦恼断尽，修习它而不能断除的，没有能以此诘难的人。）

【按】“击难者”之“者”，元、明本作“佛”。

那时深解想天子说偈赞叹：

```
对治及朋党，求于烦恼道，
无畏难佛者，如来初不见。
```
（大意：对治以及其党类，求烦恼之道，以无畏诘难佛的人，如来从来不曾见到（存疑）。）

那时解用天子说偈赞叹：

```
世尊但名用，此彼尽不尽，
无畏问难者，彼亦但假名。
```
（大意：世尊只是名与用，此与彼、尽与不尽，以无畏发问诘难的人，也只是假名。）

#### 赞三业清净

那时调伏身业天子说偈赞叹：

```
以智善解已，身业得流行，
世尊悉遍知，故号一切智。
```
（大意：以智慧善加理解之后，身业得以流行，世尊都普遍了知，所以号为一切智。）

那时知身天子说偈赞叹：

```
身业甚清净，大雄悉无余，
怜愍群生者，我礼世间亲。
```
（大意：身业甚为清净，大雄都无余，怜愍群生的人，我礼敬世间之亲。）

那时身业简择天子说偈赞叹：

```
善简择身业，怜愍众生等，
照世而造作，故号胜丈夫。
```
（大意：善于简择身业，怜愍众生等，照耀世间而造作，所以号为殊胜丈夫。）

那时善见身业天子说偈赞叹：

```
身业得清净，导师悉观见，
怜愍诸群生，故等一切智。
```
（大意：身业得以清净，导师都观见，怜愍群生，所以号为一切智。）

【按】“故等一切智”之“等”，宋、元、明、宫本作“号”，今依文意从之。

那时善观身天子说偈赞叹：

```
善观得清净，身业得相应，
怜愍群生故，胜丈夫游行。
```
（大意：善于观察而得清净，身业得以相应，因为怜愍群生，殊胜丈夫游行世间。）

那时成就语言天子说偈赞叹：

```
具甘美功德，离于绮澁语，
智慧相围绕，世亲而演说。
```
（大意：具足甘美的功德，远离绮语与涩语，以智慧相围绕，世间之亲演说法。）

那时时语天子说偈赞叹：

```
依时义相应，远离无益事，
佛言无不忠，众生悉受行。
```
（大意：依时而与义理相应，远离无益之事，佛语无不忠实，众生都领受奉行。）

那时成就智慧天子说偈赞叹：

```
不恼愍众生，成相应不浊，
不坏于因果，佛本如是说。
```
（大意：不恼害而怜愍众生，成就相应而不浊乱，不破坏因果，佛本来这样宣说。）

那时不相违天子说偈赞叹：

```
乃至为身命，未曾有妄语，
是故佛功德，于世无有碍。
```
（大意：乃至为了身命，也未曾有妄语，所以佛的功德，在世间没有障碍。）

那时实语天子说偈赞叹：

```
佛行实语因，以是世瞻仰，
至心乐听闻，为得佛法故。
```
（大意：佛行实语之因，因此为世间所瞻仰，至心乐于听闻，为了得到佛法。）

那时从实生天子说偈赞叹：

```
世尊以实语，渐备成菩提，
诸法真实性，世尊皆悉知。
```
（大意：世尊以真实之语，渐渐具备而成就菩提，诸法的真实之性，世尊都了知。）

那时实精进天子说偈赞叹：

```
于诸有为法，如性真实见，
世尊皆悉知，诸法真实相。
```
（大意：对于诸有为法，如其本性真实而见，世尊都了知诸法的真实之相。）

那时简择业天子说偈赞叹：

```
于己及与他，知身口意业，
以其智清净，故号佛无等。
```
（大意：对于自己以及他人，了知身、口、意业，因为其智慧清净，所以号为无等之佛。）

那时观察意业天子说偈赞叹：

```
人王心意业，所有思量事，
悲念于众生，故礼愍世者。
```
（大意：人中之王的心意之业，所有思量之事，都是悲念众生，所以礼敬怜愍世间的人。）

【按】“愍世者”之“者”，明本、北藏作“间”。

那时巧觉观意天子说偈赞叹：

```
世尊心缘处，是心皆调柔，
悲念于众生，故礼愍世者。
```
（大意：世尊心所缘之处，这心都调柔，悲念众生，所以礼敬怜愍世间的人。）

那时巧方便天子说偈赞叹：

```
众生心所缘，意业所起作，
种种智慧生，世尊悉知彼。
```
（大意：众生心所缘的，意业所起的造作，种种智慧的生起，世尊都了知。）

那时解慧天子说偈赞叹：

```
意业是佛地，愍观众生故，
方便智清净，佛智无体性。
```
（大意：意业是佛地，因为怜愍而观察众生，方便智清净，佛智没有体性（存疑）。）

#### 赞三世智无碍

那时巧知过去天子说偈赞叹：

```
佛知过去世，若人所行业，
戒忍精进智，佛皆悉知彼。
```
（大意：佛了知过去世，人们所行之业，戒、忍、精进、智慧，佛都了知。）

那时观察过去天子说偈赞叹：

```
观察过去行，能知多亿佛，
过去所行处，求胜菩提故。
```
（大意：观察过去之行，能知多亿佛，在过去所行之处，为求殊胜菩提的缘故。）

那时本行具足天子说偈赞叹：

```
忆念本行事，亿劫阿僧祇，
佛心无所著，佛本所行处。
```
（大意：忆念本来所行之事，经亿数阿僧祇劫，佛心无所执著，这是佛本来所行之处。）

那时观察本行天子说偈赞叹：

```
阿僧祇亿佛，导师悉曾问，
出生三昧方，种种成佛法。
```
（大意：在阿僧祇亿佛之所，导师都曾请问出生三昧的方法，以及种种成佛之法。）

【按】“三昧方”之“方”，明本作“力”。

那时本行生天子说偈赞叹：

```
无量阿僧祇，导师三昧门，
过去诸佛所，曾问亦修行。
```
（大意：无量阿僧祇的导师三昧之门，在过去诸佛之所，曾请问也曾修行。）

那时观察本住天子说偈赞叹：

```
生死中多过，应供非应供，
观已化众生，度脱于盲冥。
```
（大意：生死之中多有过患，应供与非应供，观察之后教化众生，度脱于盲冥之中。）

那时厌过去世天子说偈赞叹：

```
彼此相食噉，亦曾相戏乐，
迭互相杀害，世尊皆悉知。
```
（大意：众生彼此相互食啖，也曾相互戏乐，又迭相杀害，世尊都了知。）

那时知未来境界天子说偈赞叹：

```
导师未来时，智慧无有碍，
众生信业报，诸趣佛能知。
```
（大意：导师在未来之时，智慧没有障碍，众生的信、业报以及诸趣，佛都能了知。）

那时从本行来天子说偈赞叹：

```
世尊于过去，智慧无障碍，
善业三摩提，离趣知诸趣。
```
（大意：世尊在过去，智慧没有障碍，善业、三摩提，离于诸趣而了知诸趣。）

那时巧知未来天子说偈赞叹：

```
佛于未来时，智慧无障碍，
终死及生处，于业报亦尔。
```
（大意：佛在未来之时，智慧没有障碍，命终以及受生之处，对于业报也是这样。）

那时离有法天子说偈赞叹：

```
世尊王三界，三世中说胜，
佛智常无碍，善知有境界。
```
（大意：世尊是三界之王，在三世中说为最胜，佛智常无障碍，善知诸有的境界。）

那时用行天子说偈赞叹：

```
众生业行趣，及受果报事，
此等但假名，世尊如是说。
```
（大意：众生的业、行、趣，以及领受果报之事，这些只是假名，世尊这样宣说。）

那时观察现在天子说偈赞叹：

```
王尊王现在，智慧终不碍，
于无数佛土，牟尼皆悉知。
```
（大意：世尊之王在现在，智慧终不障碍，对无数佛土，牟尼都了知。）

【按】“王尊王现在”之第一“王”，宋、元、明、宫本作“世”，今依文意从之。

那时现在无畏天子说偈赞叹：

```
世尊正观察，三世悉平等，
究竟无所有，迷惑凡夫智。
```
（大意：世尊正确观察，三世都平等，究竟无所有，迷惑凡夫的智慧。）

那时智无所住天子说偈赞叹：

```
导师如是见，三世无所住，
以依于法性，诸法无事故。
```
（大意：导师这样见，三世无所住，因为依于法性，诸法没有事物。）

那时教三世天子说偈赞叹：

```
过去及未来，阴生必败坏，
无事无自性，导师所显说。
```
（大意：过去以及未来，五阴生起必定败坏，无事物也无自性，这是导师所显示宣说的。）

那时意无著天子说偈赞叹：

```
世尊说三世，皆悉无坚牢，
如幻亦如焰，说言犹如响。
```
（大意：世尊宣说三世，都不坚牢，如幻也如阳焰，说之犹如回响。）

那时三世自在富天子说偈赞叹：

```
世尊于三世，常勤增智慧，
知诸行如幻，诸根无所著。
```
（大意：世尊于三世中，常勤增长智慧，知诸行如幻，对诸根无所执著。）

#### 赞不共法

那时欲到彼岸天子说偈赞叹：

```
大雄于其夜，得证上菩提，
世尊勤进欲，至今不退减。
```
（大意：大雄在那一夜，证得无上菩提，世尊勤进之欲，至今不曾退减。）

那时欲作精进天子说偈赞叹：

```
世灯所有欲，常不有退减，
世尊诸子等，甚乐精进欲。
```
（大意：世间明灯所有的欲，常常不曾退减，世尊的诸子等，甚乐精进之欲。）

那时建立欲作天子说偈赞叹：

```
世尊从欲起，犹如水中莲，
不为世所染，如莲处于水。
```
（大意：世尊从欲而起，犹如水中莲花，不被世间所染，如莲花处于水中。）

那时欲解脱天子说偈赞叹：

```
欲及世间亲，此二名法界，
不二无二体，世尊皆悉见。
```
（大意：欲以及世间之亲，这二者名为法界，不二、无二体，世尊都见到（存疑）。）

那时精进生天子说偈赞叹：

```
以精进威德，克证大菩提，
于其是非法，终不舍精进。
```
（大意：以精进的威德，克证大菩提，对于是法与非法，始终不舍精进。）

那时念具足天子说偈赞叹：

```
佛于一切处，发心皆随顺，
于其善恶法，佛念不损减。
```
（大意：佛在一切处，发心都随顺，对于善恶之法，佛的念不损减。）

【按】“于其善恶法”之“于”，宫本作“以”。

那时摄心天子说偈赞叹：

```
世亲常摄心，知诸众生行，
随其所修行，而为其说法。
```
（大意：世间之亲常常摄心，了知众生之行，随其所修之行，而为他们说法。）

那时敬重般若天子说偈赞叹：

```
世尊智慧海，边际不可得，
经亿僧祇劫，佛说不可尽。
```
（大意：世尊的智慧之海，边际不可得，经亿数阿僧祇劫，佛说也说不尽。）

那时学解脱天子说偈赞叹：

```
无等佛世尊，解脱不损减，
解脱及脱者，佛求不能得。
```
（大意：无等的佛世尊，解脱不损减，解脱以及得解脱者，佛求之不能得。）

那时会解脱智天子说偈赞叹：

```
世尊解脱者，等解脱知见，
解真实不减，以知无自性。
```
（大意：世尊是解脱者，解脱知见也同等，理解真实而不减，因为了知无自性。）

那时观察身天子说偈赞叹：

```
佛于然灯始，常修真实行，
三业无过失，故叹号为佛。
```
（大意：佛从然灯佛开始，常修真实之行，三业没有过失，所以赞叹而号为佛。）

那时深行天子说偈赞叹：

```
世尊无过失，不如余众生，
知诸法自性，佛自性不惑。
```
（大意：世尊没有过失，不同于其余众生，了知诸法的自性，佛的自性不迷惑。）

那时大慧天子说偈赞叹：

```
佛于一切种，心念不迷惑，
其念常现前，譬如油满钵。
```
（大意：佛在一切种之中，心念不迷惑，其念常现在前，譬如端着盛满油的钵。）

那时心不散乱天子说偈赞叹：

```
乃至少许时，心念终不乱，
佛得不共法，众生悉不知。
```
（大意：乃至少许时间，心念终究不乱，佛得此不共之法，众生都不知晓。）

那时善解智慧天子说偈赞叹：

```
若有思量舍，善逝无此事，
世尊不共法，其法不思议。
```
（大意：若有思量后的舍，善逝没有这种事，世尊的不共之法，其法不可思议。）

那时超一切天子说偈赞叹：

```
于是三界中，知其一切法，
一切无如佛，故号难降伏。
```
（大意：在这三界之中，了知其一切法，一切众生无人如佛，所以号为难降伏者。）

那时坚持天子说偈赞叹：

```
无上坚固士，于法无所畏，
等同一切佛，能觉未觉者。
```
（大意：无上坚固之士，对法无所畏惧，与一切佛等同，能觉悟未觉悟的人。）
