# 《大宝积经》卷第三十三（出现光明会）

唐·三藏菩提流志 译

## 出现光明会第十一之四

【按】本卷全卷承上卷，叙世尊入王舍城时空中所出偈颂，其间有陀罗弭拏咒一段，又有魔子舍爱称赞佛，末段以四言偈列举了知眼尽边所成诸智，并称赞如来种种名号。至卷末偈颂未完，接下卷。

### 空中声续说偈

#### 闻空中说得眼清净

```
世尊入城时，无量诸众生，
闻空中所说，得眼尽边智。
世尊入城时，无量诸众生，
闻空中所说，了知眼自性，
毕竟空无我，皆获眼清净。
耳鼻舌身心，色声香味触，
乃至音声名，一切皆如是。
贪瞋痴忿慢，悭嫉诳贡高，
乃至于放逸，当知亦复然。
```
（大意：世尊入城时，无量众生听到空中所说，得到眼的尽边智。世尊入城时，无量众生听到空中所说，了知眼的自性毕竟空、无我，都获得眼的清净。耳鼻舌身心，色声香味触，乃至音声、名，一切都是这样；贪、瞋、痴、忿、慢，悭、嫉、诳、贡高，乃至放逸，应当知道也是如此。）

【按】“悭嫉诳贡高”之“悭”，宫本作“憍”。

```
世尊入城时，无量众生类，
于上虚空中，闻佛种种名：
或闻灭坏贪，无有等比名；
或闻灭坏瞋，利益世间名；
或闻了愚痴，摧伏憍慢名；
或闻示世间，寂静导师名；
或闻现智慧，利益世间名；
或闻现方便，饶益众生名；
或闻降伏魔，无有怼恨名；
或闻以教法，示现解脱名；
或闻广度脱，诸苦众生名；
或闻人中尊，运济世间名；
闻是诸名已，皆得眼清净。
虚空及海水，乃至于须弥，
一切皆可量，佛智无穷尽。
```
（大意：世尊入城时，无量众生在上方虚空中听到佛的种种名号：或听到“灭坏贪、无有等比”之名；或听到“灭坏瞋、利益世间”之名；或听到“了知愚痴、摧伏憍慢”之名；或听到“为世间开示寂静的导师”之名；或听到“显现智慧、利益世间”之名；或听到“显现方便、饶益众生”之名；或听到“降伏魔军而无有怨恨”之名；或听到“以教法示现解脱”之名；或听到“广为度脱诸苦众生”之名；或听到“人中之尊、运载救济世间”之名。听到这些名号之后，都得到眼的清净。虚空以及海水，乃至须弥山，一切都可以度量，佛的智慧却无穷无尽。）

#### 眼尽决定则得法身

```
若于眼尽得决定，
成就法身不为难，
若能成就胜法身，
当获无边总持智。
若获无边总持智，
彼悟无量诸契经，
若悟无量诸契经，
于佛神通不难得。
若于眼生得决定，
成就法身不为难，
若能成就胜法身，
当获无边总持智。
若获无边总持智，
彼悟无量诸契经，
若悟无量诸契经，
于佛神通不难得。
如是耳鼻舌身心，
色声香味并触法，
乃至音声及名等，
当知一切亦复然。
```
（大意：若对于眼的尽得到决定，成就法身便不困难；若能成就殊胜法身，当获无边的总持智。若获无边总持智，他便能领悟无量契经；若领悟无量契经，佛的神通便不难得到。若对于眼的生得到决定，成就法身便不困难；若能成就殊胜法身，当获无边的总持智。若获无边总持智，他便能领悟无量契经；若领悟无量契经，佛的神通便不难得到。像这样，耳鼻舌身心，色声香味以及触、法，乃至音声及名等，应当知道一切也是如此。）

#### 诸天展转相庆

```
尔时大地皆震动，
大海诸山亦如是，
阿修罗众及诸天，
一切皆悉生欢喜。
魔及魔军摧谄曲，
咸求成就佛庄严，
诸天各处妙宫殿，
净心欢喜相庆言：
导师今已出世间，
为利一切人天众。
地居天众在本宫，
亦以净心相庆慰，
善哉导师今出现，
普为世间安乐因。
空行天众闻是言，
咸皆欢喜生净信，
以悦意声称叹佛，
导师出现利世间。
```
（大意：那时大地都震动，大海与诸山也是如此，阿修罗众以及诸天，一切都生起欢喜。魔与魔军的谄曲被摧伏，都求成就佛的庄严。诸天各在美妙的宫殿中，以净心欢喜，互相庆贺说：“导师如今已出现于世间，为利益一切人天大众。”地居天众在本宫中，也以净心互相庆慰：“善哉！导师今已出现，普为世间安乐之因。”空行天众听到这话，都欢喜而生净信，以悦意之声称叹佛：“导师出现，利益世间。”）

```
四王天众闻是言，
咸皆欢喜生净信，
以殊胜音称叹佛，
导师出现利世间。
忉利天众闻是言，
咸皆欢喜生净信，
以殊胜音称叹佛，
导师出现利世间。
夜摩天众闻是言，
咸皆欢喜生净信，
以殊胜音称叹佛，
导师出现利世间。
我等当发菩提心，
志求如来无上智，
依止天人最胜尊，
度脱一切众生类。
兜率天众闻是言，
咸皆欢喜生净信，
以殊胜音称叹佛，
导师出现利世间。
如来往昔俱胝劫，
修习无边殊胜行，
示苦众生安隐道，
令超生死证涅槃。
```
（大意：四王天众听到这话，都欢喜而生净信，以殊胜之音称叹佛：“导师出现，利益世间。”忉利天众、夜摩天众听到这话，也同样欢喜生信，以殊胜之音称叹佛：“导师出现，利益世间。”“我们应当发菩提心，志求如来的无上智，依止天人中最胜之尊，度脱一切众生。”兜率天众听到这话，都欢喜而生净信，以殊胜之音称叹佛：“导师出现，利益世间。”“如来往昔在俱胝劫中，修习无边殊胜之行，为受苦众生指示安稳之道，令他们超越生死，证得涅槃。”）

【按】“夜摩天”之“摩”，元、明本作“魔”。

```
化乐天众闻是言，
咸皆欢喜生净信，
以殊胜音称叹佛，
导师出现利世间。
他化天众闻是言，
咸皆欢喜生净信，
以微妙声称赞佛，
导师出现利世间。
如来已度于生死，
降伏众魔并外道，
成就无上佛菩提，
拯济群生登彼岸。
诸梵天众闻是言，
咸皆欢喜生净信，
以微妙声称赞佛，
导师出现利世间。
如是展转声递闻，
诸梵眷属皆欣庆，
导师出现利世间，
魔军怖畏怀忧戚。
```
（大意：化乐天众听到这话，都欢喜而生净信，以殊胜之音称叹佛：“导师出现，利益世间。”他化天众听到这话，都欢喜而生净信，以微妙之声称赞佛：“导师出现，利益世间。”“如来已度过生死，降伏众魔以及外道，成就无上佛菩提，救济众生登上彼岸。”诸梵天众听到这话，都欢喜而生净信，以微妙之声称赞佛：“导师出现，利益世间。”这样展转相传，声音递相听闻，诸梵天的眷属都欣喜庆贺：“导师出现，利益世间。”魔军却怖畏而心怀忧戚。）

【按】“声递闻”之“递”，宫本作“遍”。“怀忧戚”之“怀”，明本作“咸”。

```
上至有顶诸天众，
闻佛出现利世间，
如是展转声遍闻，
修罗损减天增长，
恶魔宫殿悉空虚，
诸天眷属皆充满，
以无畏力降邪众，
速成最胜大菩提。
如是刹那天遍知，
世尊出现利群品，
善哉世间开导者，
以清净眼施众生。
```
（大意：上至有顶天的诸天众，都听到佛出现、利益世间。这样展转相传，声音遍闻，阿修罗损减，诸天增长，恶魔的宫殿全都空虚，诸天的眷属都已充满。佛以无畏之力降伏邪众，速成最胜大菩提。像这样，一刹那间诸天普遍得知世尊出现、利益众生：“善哉！世间的开导者，以清净之眼施予众生。”）

#### 闻对治法而烦恼灭

```
世尊入城时，贪欲逼恼者，
闻说不净观，贪欲灭无余。
世尊入城时，瞋恚逼恼者，
闻说慈悲法，瞋恚灭无余。
世尊入城时，愚痴逼恼者，
闻说智慧法，愚痴灭无余。
世尊入城时，憍慢逼恼者，
闻说离慢法，憍慢灭无余。
世尊入城时，嫉妬逼恼者，
闻说离嫉法，嫉妬灭无余。
世尊入城时，忿怒逼恼者，
闻说离忿法，忿怒灭无余。
世尊入城时，悭悋逼恼者，
闻说离悭法，悭悋灭无余。
若修调伏行，闻此无边法，
便入多闻海，成就总持门。
```
（大意：世尊入城时，被贪欲逼恼的人，听说不净观，贪欲便灭尽无余。世尊入城时，被瞋恚逼恼的人，听说慈悲之法，瞋恚便灭尽无余。世尊入城时，被愚痴逼恼的人，听说智慧之法，愚痴便灭尽无余。世尊入城时，被憍慢逼恼的人，听说离慢之法，憍慢便灭尽无余。世尊入城时，被嫉妒逼恼的人，听说离嫉之法，嫉妒便灭尽无余。世尊入城时，被忿怒逼恼的人，听说离忿之法，忿怒便灭尽无余。世尊入城时，被悭吝逼恼的人，听说离悭之法，悭吝便灭尽无余。若修调伏之行，听闻这无边之法，便进入多闻之海，成就总持之门。）

#### 神变随类说法

```
又闻空中说，以华供养佛，
成就胜功德，大悲神变说。
又闻空中说，赞叹如来身，
生处及种族，言音悉殊胜。
如彼众生趣，神通随类说，
眼耳鼻舌身，若色若声等，
屈伸或俯仰，所现皆殊胜。
如来超世间，而作世灯炬，
示现诸色像，皆佛神通力。
凡夫乐著色，为现种种身，
随彼众生类，说色无坚固。
若人多执著，如来现神力，
随彼器非器，为说相违法。
```
（大意：又听到空中说：以花供养佛，能成就殊胜功德——这是大悲神变所说。又听到空中说：赞叹如来之身，其生处与种族，以及言音，都很殊胜。随着那些众生的趣类，以神通随其类别而说：眼、耳、鼻、舌、身，或色、或声等，屈伸或俯仰，所显现的都很殊胜。如来超出世间，而作世间的灯炬，示现种种色像，都是佛的神通力。凡夫乐著于色，便为他们示现种种身，随那些众生的类别，宣说色无坚固。若人执著多，如来便示现神力，随其是法器或非法器，为他们宣说相违之法。）

```
众生无量世，未曾供养佛，
刚强难调伏，为说于地狱。
若人迷业道，依见乐戏论，
世尊令彼闻，息见戏论声。
又闻空中说，眼性决定空，
无来亦无去，无相无所有。
又百千众生，闻空中演说，
肉眼及慧眼，乃至于法眼。
世尊神变力，闻说戒定声，
智慧及解脱，解脱知见声。
众生若干种，如应现神变，
以随类言音，演说真实法。
```
（大意：众生在无量世中从未供养过佛，刚强难以调伏，便为他们宣说地狱之事。若人迷于业道，依于见解，喜好戏论，世尊便令他们听到止息见解与戏论之声。又听到空中说：眼性决定是空，无来也无去，无相，无所有。又有百千众生听到空中演说肉眼与慧眼，乃至法眼。以世尊的神变之力，听到宣说戒、定之声，智慧与解脱、解脱知见之声。众生有若干种类，便随其所应示现神变，以随其类别的言音演说真实之法。）

```
若有诸众生，乐修施戒忍，
神通随类说，施戒忍辱声。
世尊神变力，随众生根性，
皆为广分别，令受持演说。
世尊神变力，闻说蕴界处，
缚解若远近，地位差别相。
又闻说诸地，无量智光明，
亦闻烦恼习，有离有非离。
世尊神变力，闻说人天性，
由业果不同，受生有差别。
或于女人众，化女庄严身，
空声说厌离，闻者除贪欲。
```
（大意：若有众生喜乐修习布施、持戒、忍辱，神通便随其类别而宣说布施、持戒、忍辱之声。以世尊的神变之力，随众生的根性，都为他们广为分别，令他们受持演说。以世尊的神变之力，听到宣说蕴、界、处，系缚与解脱，或远或近，诸地位的差别之相。又听到宣说诸地的无量智慧光明，也听到烦恼习气，有已离的，有未离的。以世尊的神变之力，听到宣说人与天之性，由于业果不同，受生有差别。或者在女人众中，化现女身庄严，空中之声宣说厌离，闻者便除去贪欲。）

#### 神通示现无边

```
又以毘沙门，提头赖吒等，
无数殊妙声，说真实呪法。
如是无量声，善逝神通说，
神通无有量，所说亦无边。
或于无佛刹，游戏神通力，
佛身众围绕，亦如今所见。
于不思议刹，现无量变化，
初生行七步，舍王位出家，
道场成正觉，思惟所得法，
为众转法轮，示现入涅槃，
及以神变力，演说种种法，
令无量众生，成就殊胜智。
```
（大意：又以毘沙门、提头赖吒等的无数殊妙之声，宣说真实的咒法。这样无量的声音，都是善逝以神通所说；神通无有限量，所说也无边际。或者在无佛的刹土，游戏神通之力，佛身被大众围绕，也如今天所见。在不可思议的刹土中，示现无量变化：初生行走七步，舍弃王位出家，在道场成正觉，思惟所得之法，为大众转法轮，示现入涅槃，以及以神变之力演说种种法，令无量众生成就殊胜之智。）

#### 魔子舍爱称赞佛

```
尔时有魔子，名为舍爱者，
最初称赞佛，能知眼尽边，
亦了眼生边，乃至寂灭相。
又知眼尽等，无边名义句，
以善巧言词，为众生演说，
而于名义中，无著无疑惑。
了知无去来，无取亦无舍，
自性常空寂，远离于文字，
亦无能受持，读诵修行者。
往昔诸如来，已曾广开示，
得以假名字，而实无所说。
如是自性空，超过蕴界处，
无妄无真实，亦无处非处，
乃至言语断，心行处亦灭。
愚夫著相故，见佛有入城，
世尊离诸相，愚人妄分别。
```
（大意：那时有一位魔子，名叫舍爱，最初称赞佛：能知眼的尽边，也了知眼的生边，乃至寂灭之相；又知眼的尽等无边的名、义、句，以善巧言词为众生演说，而在名与义之中无所执著，无有疑惑；了知无去无来，无取也无舍，自性常空寂，远离文字，也没有能受持、读诵、修行的人。往昔诸如来已曾广为开示，只是以假名字而说，而实际上无所说。这样的自性空，超越蕴、界、处，无虚妄也无真实，也没有处与非处，乃至言语道断，心行处也灭。愚夫因为执著于相，见佛有入城之事；世尊远离诸相，是愚人妄加分别。）

```
世尊无量劫，修习诸苦行，
为证于性空，愚人不能了。
世尊入城时，百千众围绕，
人及非人等，净心而供养。
若于刹那顷，思惟眼尽边，
了达诸相空，其福复过彼。
乃至算数分，皆所不能及，
如是眼生边，边际与流转，
乃至于寂灭，当知亦复然。
耳鼻舌身心，色声香味触，
乃至音声名，一切皆如是。
```
（大意：世尊在无量劫中修习种种苦行，是为了证得性空，愚人却不能了知。世尊入城时，百千大众围绕，人与非人等都以净心供养；若在一刹那顷思惟眼的尽边，了达诸相皆空，其福德又超过前者，乃至算数譬喻的一分都不能及。像这样，眼的生边、边际与流转，乃至寂灭，应当知道也是如此；耳鼻舌身心，色声香味触，乃至音声、名，一切都是这样。）

### 四言偈：入城希有事与了知眼尽边

#### 入城时的瑞相

```
尔时世尊，当入城时，
以足按地，普皆震动，
诸山倾靡，悉向于佛，
人天为法，咸来恭敬。
尔时世尊，当入城时，
天主人王、阿修罗众，
并诸夜叉，各舍本城，
来诣佛所，欢喜供养。
尔时世尊，当入城时，
复有无量，异类诸鸟，
鹦鹉孔雀、迦陵频伽，
覩佛如来，殊胜功德，
于虚空中，欢喜游戏，
皆出种种，微妙音声。
尔时世尊，当入城时，
以佛功德，威神力故，
能令无量，百千众生，
盲者能视、聋者能听，
不完具者，令得完具，
不安乐者，令得安乐。
```
（大意：那时世尊正要入城时，以足按地，大地普遍震动，诸山倾斜，都朝向佛，人天为了求法都来恭敬。那时世尊正要入城时，天主、人王、阿修罗众以及诸夜叉，各自舍弃本城，来到佛所，欢喜供养。那时世尊正要入城时，又有无量异类的鸟——鹦鹉、孔雀、迦陵频伽，看到佛如来的殊胜功德，在虚空中欢喜游戏，都发出种种微妙音声。那时世尊正要入城时，以佛功德的威神力，能令无量百千众生：盲者能看见，聋者能听闻，身根不完具的得以完具，不安乐的得到安乐。）

【按】“普皆震动”之“震”，圣本作“振”。“天主人王”之“主”，元、明本作“王”。

#### 离相者见如来

```
尔时世尊，当入城时，
于虚空中，闻如是说，
若以诸相，分别如来，
是人不名，供养于佛，
亦不了知，眼尽边性；
若离诸相，殖众德本，
则能了知，眼尽边性。
以能了知，眼尽边故，
则能了知，诸佛功德。
于眼尽边，无有执藏，
于眼生边，无有依止，
于眼寂静，无有动念，
是人则为，见于如来。
于眼生边，无有分别，
于眼边际，无有意谓，
于眼灭坏，无有表示，
是人则为，见于如来。
于眼无有，无有染著，
于眼无生，无有摄受，
于眼寂灭，无有所执，
是人则为，见于如来。
```
（大意：那时世尊正要入城时，在虚空中听到这样说：若以诸相来分别如来，此人不名为供养佛，也不了知眼的尽边之性；若远离诸相，种植众德之本，便能了知眼的尽边之性。因能了知眼的尽边，便能了知诸佛的功德。对于眼的尽边无所执藏，对于眼的生边无所依止，对于眼的寂静不起动念，此人便是见到如来。对于眼的生边无有分别，对于眼的边际无有意想，对于眼的灭坏无有表示，此人便是见到如来。对于眼的无有不起染著，对于眼的无生无所摄受，对于眼的寂灭无所执取，此人便是见到如来。）

```
知眼尽故，于根修习，
知眼边故，于根决定，
知眼生故，于根自在，
是人则为，见于如来。
知眼无有，于色了达，
知眼灭坏，于法观察，
知眼无生，于道修习，
是人则为，见于如来。
如实了知，眼尽边故，
于业差别，亦能了知，
以能了知，业差别故，
是人则为，见于如来。
如实了知，眼生边故，
于苦差别，亦能了知，
以能了知，苦差别故，
是人则为，见于如来。
如实了知，眼灭坏故，
于苦灭坏，亦能了知，
以能了知，苦灭坏故，
是人则为，见于如来。
如实了知，眼无有故，
于离诸相，亦能了知，
以能了知，离诸相故，
是人则为，见于如来。
如实了知，眼无生故，
于离习气，亦能了知，
以能了知，离习气故，
是人则为，见于如来。
```
（大意：知眼的尽，便于根修习；知眼的边，便于根决定；知眼的生，便于根自在——此人便是见到如来。知眼的无有，便于色了达；知眼的灭坏，便于法观察；知眼的无生，便于道修习——此人便是见到如来。如实了知眼的尽边，对于业的差别也能了知；因能了知业的差别，此人便是见到如来。如实了知眼的生边，对于苦的差别也能了知；因能了知苦的差别，此人便是见到如来。如实了知眼的灭坏，对于苦的灭坏也能了知；因能了知苦的灭坏，此人便是见到如来。如实了知眼的无有，对于远离诸相也能了知；因能了知远离诸相，此人便是见到如来。如实了知眼的无生，对于远离习气也能了知；因能了知远离习气，此人便是见到如来。）

【按】“眼尽边故，于业差别”之“尽”，宋本作“生”；“眼生边故，于苦差别”之“生”，宋本作“尽”。

```
又如实知，眼无常性，
于离障碍，亦能了知，
以能了知，离障碍故，
是人则为，见于如来。
又如实知，眼无文字，
于佛智力，亦能了知，
以能了知，佛智力故，

于离烦恼，亦能了知，
以能了知，离烦恼故，
是人则为，见于如来。
```
（大意：又如实了知眼的无常之性，对于远离障碍也能了知；因能了知远离障碍，此人便是见到如来。又如实了知眼无文字，对于佛的智力也能了知；因能了知佛的智力，此人便是见到如来。又如实了知眼的不来之性，对于远离诸欲也能了知；因能了知远离诸欲，此人便是见到如来。又如实了知修习禅定，对于远离烦恼也能了知；因能了知远离烦恼，此人便是见到如来。）

```
无有无生，寂灭之性，
令诸众生，得清净智、
诸势力智、精进之智。
```
