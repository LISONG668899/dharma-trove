# 《大宝积经》卷第三（三律仪会）

唐·三藏菩提流志 奉诏译

## 三律仪会第一之三

### 不生厌离与谤佛菩提的四法

这时，尊者摩诃迦叶对佛说：“真是稀奇啊，世尊！这样的人听闻这些经，竟不生厌离。”

佛告诉大迦叶说：“如果有众生成就四法，听闻宣说这部经就不生厌离。哪四法呢？一是由于多放逸，不能深信；二是对于业的异熟果报，也不深信；三是对于大地狱，不能审实地信；四是对于‘我将会死’（不能信）。如果有人成就这样的四法，就不生厌离。

“迦叶！又有众生成就四法，不生厌离。哪四法呢？年轻力壮时自恃强力，耽著欲乐，贪嗜各种酒，不能了知明了的思惟观察。如果有人成就这样的四法，就不生厌离。

“迦叶！如果有比丘成就四法，就会诽谤佛菩提。哪四法呢？一是本来所造的恶业已经成就，因此毁坏正法——这样的比丘对于不善异熟的种种恶业不自发露；二是对比丘尼行秽欲；三是他有为众人所敬重的和上或阿阇梨诽谤佛菩提，这样的弟子随学于师，也生起诽谤；四是寡闻之人，由于嫉妒而谤毁诸佛。比丘成就这样的四法，就会诽谤佛菩提。

【按】此四法，异译《大方广三戒经》作：“本造众恶，毁乱正法，现造恶业，谤比丘尼。彼有和上阿阇梨，多人所敬，然谤菩提；是亦随学谤于菩提；少于闻见，以嫉妒故谤佛菩提。”可参看。

### 一法成沙门：于一切法心无所住

“迦叶！有一种法，能成就沙门及婆罗门。是哪一法呢？就是：于一切法，心无所住。这样的一法，能成就沙门及婆罗门。

“譬如有人从高山顶上坠落，以为没有大地、树木、丛林，只生起空想，于是出入息断绝。迦叶！执著诸法的人也是这样：如果执取眼想以及眼相，执取耳、鼻、舌、身、意想，乃至意相，如果执取色、受、想、行、识之想，执取清净持戒、多闻、惭愧、经行往来、得菩提之想——像这些法，都不能成为沙门婆罗门。如果起想，就会被伤害。被谁伤害呢？就是被贪、瞋、痴伤害。如果执取眼相，由于执著可爱、不可爱的色相，就被眼所伤害；同样，执著耳、鼻、舌、身、意相，乃至由于执著可爱、不可爱的法相，乃至被意所伤害。如果被伤害，就会在地狱、畜生、饿鬼、人、天界中，极为受伤害。

“由于什么缘故被伤害？由于想的执著。什么叫想著呢？就是执取我想及我所想、女想、男想、地水火风想、骨想、坏想、青瘀想、血涂想、色变想、离散想、胜解脱想；（执取）这一方有少分得胜解脱想，那一方有少分不得胜解脱想；有无量种宿住随念、现证而作想：‘我随念之想异于过去，异于现在；我是过去的我，我是现在的我。’对于诸法生起想的执著，乃至涅槃想、‘我得涅槃’想。迦叶！简要地说，执著的人处处起想，乃至在空性中起一切想，都不能成为沙门婆罗门之法，不是沙门行，也不是婆罗门行。

“迦叶！如来所说的沙门婆罗门法，譬如虚空和大地。为什么呢？虚空之法终究不会想：‘我是虚空。’正是这样，迦叶！沙门婆罗门终究不会自认为‘我是沙门，我是婆罗门’，所以诸法也不自认为是能成就沙门婆罗门之法。沙门之法，既不造作，也不除遣，这才是沙门及婆罗门。

“迦叶！譬如有人在黑夜中挥弄手臂，摇动面目，这样说：‘我在戏弄世间！我在戏弄世间！’你意下如何？他是在戏弄谁呢？”

迦叶回答说：“世尊！这个人是在戏弄自己。为什么呢？因为其中并没有人可以戏弄。”

佛告诉大迦叶说：“正是这样，正是这样！如果有比丘到阿兰若，或到树下、空室、露地，这样想：‘眼是无常，耳、鼻、舌、身、意都是无常。’又这样思惟：‘色是无常，声、香、味、触、法也都是无常。’又这样思惟：‘我趣向涅槃。’像这一类，是自己徒劳，不是沙门行。为什么呢？因为有种种邪执。了知眼相之后，为了灭除眼而勤劳修习；同样，了知耳、鼻、舌、身、意相之后，乃至为了灭除意而勤加修习。如果在三处了知信受，就会在三处生起分别。如果对诸见生起分别，又怎能得到心一境性呢？

【按】“三处”，异译《大方广三戒经》作：“先著于眼，后修无常，后行无常……而是三处俱不可得，执著三处随所想著，当于何处而得一心？”可参看。

### 心一境性

“迦叶！甚深的菩提难以契入，难以趣向，难以具足资粮。所谓心一境性，以多少名为心一境性呢？周遍推求，乃至一法也不可得。也就是说：在眼上得不到实，在耳、鼻、舌、身、意上也得不到实，在一切法上都得不到实。为什么呢？本性如此：心性不生，一切诸法无实可得，所以那个心是不可得的。如果过去、未来、现在都无所得、无所作，这就叫无所作。什么叫无所作？无论新的旧的都不可造作，名为无所作。在这当中，过去心不解脱，现在心不解脱，未来心不解脱；随其所有的心都无所得，这就是心一境性。这就名为入于心之数。

### 未来执蕴如梦为实者

“迦叶！未来将有比丘、比丘尼、优婆塞、优婆夷，执著眼等，说为灭坏，在诸蕴中生起实物之想。如来说蕴犹如梦，他们却说梦是实有：‘因为世间都说有这个梦；如果没有梦，我们就不应当有梦想之事。因为有表示，所以我们在睡梦中生起梦想。正是这样：蕴是有所因的，所以才说它如梦；如果没有蕴，就不应说蕴犹如梦。’那些愚夫认为梦是实有的，听闻这些经便生起诽谤。

“其中将有比丘尼等，在施主家妄称‘我是阿罗汉果’，或依凭浅薄的智慧，说自己已经现证。优婆塞、优婆夷等，听了经、律、偈颂，也说‘我已现证’。

“迦叶！到那时，如果有比丘在二十年、三十年中，常乐居住阿兰若处精勤修习，为了佛法的缘故，来到一位初信佛才一日的优婆塞身边，却只是以空言互相唱说：‘空啊，空啊！所以我已遍知，我已遍知！’或者有比丘听了这些经，互相谈说，有人听了便生怖畏，又这样说：‘一切在家、出家人都不应当亲近他们，应当远离，这些人不是教师。为什么呢？因为他们所知的，与我们不相亲合。’又有宣说甚深法的人，被在家、出家人等舍弃、轻贱。为什么呢？我现在宣说殊胜微妙的梵行，尚且很少有人了知，何况未来世，乃至最少数了知的人也都灭没了。

【按】此段异译《大方广三戒经》作：“诸比丘等有二十腊至三十腊，住阿练儿处，有优婆塞初信一日，所解佛经等无差别。迦叶！当尔时世互唱空名‘此空此净，此空此净’。”可参看。

“在那个时代，说法的比丘一千人之中，能如实理解、信入正法的，一个也难得；乃至二千人中也是如此。其中有些其余的比丘，下至不能暂时开口说话，何况能够理解呢？

“迦叶！到那时，在家人和出家人共同轻视这个教法。如果有比丘发起勤勇精进，为了灭除不善、生起善法，在初夜、后夜减少睡眠，精进修学，就会被他人讥嫌舍弃，甚至断其命根。这样的经典就将毁灭，安住于正法的比丘也都灭尽。其中的智者，深刻、殊胜、无染、能够理解的人，应当尊重他们，以深心恭敬，共同集会之后，安住于阿兰若。”

### 偈颂：正法隐没，诸天悲叹

这时，世尊说偈颂道：

```
我所说善法，第一义相应，
言蕴无坚实，应观察如梦。
尔时诸比丘，斗诤心纷扰，
无礼别尊卑，唯有空名相。
比丘所发言，俗亦如是说，
如斯之教法，道俗语皆同。
比丘谓俗言，汝解法希有，
是谓佛菩提，已发初地果。
彼心谓见法，亲近在家人，
数奉施比丘，与其最上供。
如斯比丘说，无异语皆真，
与彼共相亲，言我能见法。
```

（大意：我所说的善法，与第一义相应，说诸蕴没有坚实，应当观察它犹如梦幻。到那时，诸比丘心怀斗诤，纷扰不安，没有礼节，不分尊卑，只有空洞的名相。比丘所说的话，俗人也照样说；这样的教法，出家人和在家人说的话都一样。比丘对俗人说：“你理解佛法真是稀有，这就叫作佛菩提，你已经发起了初地之果。”俗人心里以为自己已经见法，就亲近这个在家人，屡屡奉施这个比丘，给他最上等的供养。像这样的比丘所说的，都说没有一句不是真的；俗人与他互相亲近，说“我能见法”。）

```
生于彼时者，为施故出家，
不住正法中，毁坏菩提道。
我示汝道者，近我勿亲余，
不久汝得之，还如我所得，
此最寂静位，共汝相向言。
和合大众中，毁坏我教法，
犹如劫村贼，性怀凶险心，
破坏诸国城，及以大聚落。
比丘亦如是，无智多愚痴，
少慧起诸非，著命数取趣。
离我所说教，依止诸见心，
说是罗汉人，尽怀增上慢。
于大和合会，诸比丘众前，
说已慧名闻，于中一难得。
```

（大意：生在那个时代的人，为了布施而出家，不住在正法之中，毁坏菩提之道。他们说：“我指示你道，你亲近我，不要亲近别人；不久你就会得到，就像我所得到的一样。这是最寂静的境地，我只对你一个人说。”他们在和合的大众中毁坏我的教法，犹如劫掠村庄的盗贼，本性怀着凶险之心，破坏诸国城以及大聚落。比丘也是这样：没有智慧，多有愚痴，少慧而造作种种非法，执著命者与数取趣；离开我所说的教法，依止于种种见解之心，自称是阿罗汉，全都怀着增上慢。在大和合会中，在诸比丘众前，宣说自己的智慧与名闻——其中真正的智者，一个也难得。）

```
或时有比丘，安住如实者，
被说恶名闻，言非佛弟子。
法王大菩提，于时被诽谤，
天众怀忧戚，相向数悲啼。
对彼信心天，身自投于地，
观斯释师子，无上法轮摧。
嗟叹佛如来，快哉所说法，
奇特福田僧，佛之所爱子。
我等不复闻，法王之所说，
牟尼今灭度，无觉抱迷心。
```

（大意：有时有比丘安住于如实之法，却被说成恶名，说他不是佛弟子。法王的大菩提，那时遭到诽谤。天众心怀忧戚，相对屡屡悲泣；在那些有信心的天人面前，自己投身于地，眼看着释迦狮子的无上法轮被摧毁。他们嗟叹佛如来：“快哉，佛所说的法！奇特的福田僧，是佛所爱的儿子！我们再也听不到法王所说的法了，牟尼如今已经灭度，众生没有觉悟，怀抱着迷惑之心。”）

```
地居天次后，出于大音声，
唱令告诸天，法炬今将灭。
汝等得闻佛，不亲近如来，
勿致后天龙，而当怀悔恨。
经于无数劫，为自及为他，
遍受于众苦，尔乃方成佛。
此是诸世尊，为诸众生类，
所说善法门，今皆当隐没。
矫乱人兴世，可畏造诸非，
魔使及恶魔，恣情恶言说。
谄诈多痴钝，诳惑劣愚夫，
若瞋与不瞋，毁师及胜教。
```

（大意：地居天随后发出大音声，传告诸天：“法炬现在将要熄灭了！你们曾得以听闻佛法，却不亲近如来，不要让后来的天龙心怀悔恨。佛经过无数劫，为了自己也为了他人，遍受种种苦难，这才成佛。这是诸位世尊为众生所说的善法之门，如今都将隐没。矫诈惑乱的人兴起于世，可怖畏地造作种种非法；魔的使者以及恶魔，恣意说恶言；谄诈而多痴钝，诳惑那些下劣的愚夫；无论瞋或不瞋，都毁谤导师以及殊胜的教法。”）

```
闻地天声已，上天皆惨然，
人及四王天，悉亦怀忧恼。
夜叉众来集，阿吒筏底城，
皆发可畏声，满面流悲泪。
天居众宝饰，城郭妙庄严，
皆悉失光晖，犹如于聚土。
国城非似本，堪生爱乐心，
今见宝严城，须臾不可乐。
诸天同诣彼，善逝本生国，
躄踊而号咷，转增大悲苦。
我从天降地，往诣诸国城，
真法尽沉沦，遍观皆不见。
下至阎浮境，见法大崩摧，
逼恼诸出家，发声大号哭。
胜城七日内，处处失光晖，
天亦七日中，数悲数啼泣。
```

（大意：听到地居天的声音之后，上方的诸天都惨然悲伤，人与四王天也都心怀忧恼。夜叉众聚集到阿吒筏底城，都发出可怖畏的声音，满面流下悲伤的眼泪。天上的居所有众宝装饰，城郭美妙庄严，却都失去了光辉，犹如一堆泥土。国城不再像从前那样能令人生起爱乐之心，如今见到宝饰庄严的城，片刻也不觉可乐。诸天一同前往善逝出生的国土，捶胸顿足，号啕大哭，更增大悲苦，说：“我们从天上降到地上，前往各国城，真实的佛法都已沉沦，遍观各处都看不到；下至阎浮提境内，见到佛法大为崩摧，出家人受到逼恼，于是放声大哭。”殊胜的天城七日之内处处失去光辉，诸天也在七日之中屡屡悲泣。）

【按】慧琳《一切经音义》卷第十一说（解释）：“阿吒筏底城”是梵语，即多闻天王所居之宫。“数悲数啼泣”之“悲”，《大正藏》作“非”，CBETA 据高丽藏作“悲”。

```
呜呼大雄健，昔曾亲面奉，
何期今不见，言说亦成空。
曾住舍卫城，来已皆恭敬，
于其地界内，数悲而数啼。
见佛所坐林，言佛曾于此，
转四谛法轮，我等亲闻听。
世间还黑暗，更互不相尊，
己造诸罪因，往生三恶趣。
天众多宫殿，今者悉空虚，
赡部诸众生，无主无救护。
言佛经行处，毁坏悉荒芜，
法王已涅槃，世间不可乐。
```

（大意：他们说：“呜呼，大雄健者！往昔曾亲自面见奉事，哪里想到如今却见不到了，连佛的言说也成了空。佛曾住在舍卫城，我们来了都恭敬礼拜。”他们在那片地界内，屡屡悲伤、屡屡啼泣；见到佛所坐的树林，说：“佛曾在这里转四谛法轮，我们亲耳听闻。如今世间重又黑暗，人们彼此不相尊重，自己造作种种罪因，往生三恶趣。天众的许多宫殿，如今都已空虚；赡部洲的众生，无主而无救护。”他们说：“佛经行之处，都已毁坏荒芜；法王已经涅槃，世间不再可乐。”）

```
三十三天主，帝释立其中，
苦恼发忧愁，高声大悲恸。
诸忉利天等，举手共哀号，
适闻园苑中，其次便驰走。
是等诸天众，恒叹佛如来，
自嗟离世尊，曾为说法者。
不能食甘露，亦绝歌乐声，
如是等诸天，心忧经六月。
阿修罗闻说，教法空无主，
于是即相呼，兴师伐忉利。
赡部诸王等，毁坏佛制多，
当于尔时中，天与修罗战。
```

（大意：三十三天之主帝释立于其中，苦恼忧愁，高声悲恸；诸忉利天众举手共同哀号，刚在园苑中听到消息，接着便四处奔走。这些天众常常赞叹佛如来，自己嗟叹离开了世尊——那位曾为他们说法的人。他们吃不下甘露，也断绝了歌乐之声，像这样诸天心中忧愁，历经六个月。阿修罗听说佛的教法已空、无人作主，于是互相招呼，兴兵讨伐忉利天。赡部洲的诸王毁坏佛的制多（塔），在那时，诸天与阿修罗交战。）

```
多有诸比丘，及多比丘尼，
生诸恶趣中，备受众苦毒。
在家犯诸罪，近事坏尸罗，
互相扬恶名，以之生苦趣。
女人行不善，皆亦入三涂，
如是事兴时，世间不安静。
或时行聚落，或投窜山林，
人众以波逃，寿命便殀促。
多有贼盗起，亦复有饥荒，
苗稼不时登，蝗虫起灾暴。
若于饥馑世，人有寿命终，
便生饿鬼中，具受多辛苦。
所有施塔庙，及与四方僧，
尔时诸比丘，悉共分张取。
于我灭度后，如是众苦兴，
应速发精勤，勿复更回顾。
```

（大意：有许多比丘，以及许多比丘尼，生到种种恶趣之中，备受众苦。在家人犯种种罪，近事男女毁坏尸罗（戒），互相宣扬恶名，因此生于苦趣；女人行不善，也都入三涂。这样的事兴起时，世间不得安宁：人们有时奔走于聚落，有时逃窜到山林，众人像波浪一样四处奔逃，寿命也就短促夭折。多有盗贼兴起，又有饥荒，庄稼不能按时成熟，蝗虫兴起灾害。如果在饥馑之世，有人寿命终了，便生到饿鬼之中，具受许多辛苦。所有布施给塔庙以及四方僧的财物，那时的比丘们都共同瓜分拿走。在我灭度之后，这样的众苦将会兴起，应当迅速发起精勤，不要再回头顾恋。）

```
诸有愚夫类，而无智慧人，
愚夫业已成，速生诸恶趣。
应乐读诵说，智慧从此生，
人修智慧心，速能升善趣。
常以智慧观，如我如是学，
永离众系缚，速至于涅槃。
正法不久留，应发坚精进，
我已如是说，宜速正思惟。
此劫过去已，满于六十劫，
当不闻佛名，何能生信乐。
```

（大意：那些愚夫之类、没有智慧的人，愚夫的恶业已经造成，就迅速生到诸恶趣中。应当乐于读诵、宣说，智慧从此而生；人修习智慧之心，就能迅速升于善趣。常以智慧观察，像我这样修学，就能永离种种系缚，迅速到达涅槃。正法不能久留，应当发起坚固的精进；我已经这样说了，你们应当迅速正确地思惟。这一劫过去之后，满六十劫之中，都将听不到佛的名号，又怎能生起信乐呢？）

【按】“永离众繫缚”之“繫”，《大正藏》作“繁”，CBETA 校作“繫”。“满于六十劫”，异译《大方广三戒经》作：“于我灭后时，六十小劫中，有闻佛名号，谁当有爱者？”

```
若人相会遇，饥饿苦所侵，
母子是时中，互相食其肉。
彼时所生子，慞惶行不安，
住在己家中，犹生大怖畏。
见闻此事已，知其生死烧，
谁有智慧人，于中生爱乐？
无明是生根，女人是欲根，
蕴为苦恼根，是故应舍苦。
世有愚众生，耽著于女欲，
人能离痴者，疾当得涅槃。
宣畅此法时，不遭于恶果，
不说果有漏，故堕恶趣中。
所有无漏法，空空无所有，
寂静本无坚，宜应速了悟。
```

（大意：那时人们相互遇见，被饥饿之苦所侵逼，母与子在那时互相吃对方的肉。那时所生的孩子，惊惶不安，即使住在自己家里，仍然生起大怖畏。见闻这些事之后，便知道生死如火焚烧，哪一个有智慧的人，会在其中生起爱乐呢？无明是生的根本，女人是欲的根本，诸蕴是苦恼的根本，所以应当舍离苦。世间有愚痴的众生，耽著于女色之欲；人如果能远离愚痴，就能迅速证得涅槃。宣畅这个法时，不会遭受恶果；不说果报是有漏的，所以堕入恶趣之中。所有无漏之法，空而又空，无所有，寂静，本无坚实，应当迅速了悟。）

【按】“宣畅此法时”四句，诸本、古注都未见解释，照字面译出，存疑。异译《大方广三戒经》此处作：“不正造业苦，果报来应现，此果是有漏，是故堕恶道。”可参看。

### 坚固修习

“再者，迦叶！如果有比丘或其余众生，由于能成就这第一法而求无漏，应当这样说：于一切法，心无所住。

“再者，迦叶！菩萨应当坚固修习。什么是坚固？什么是修习？所谓坚固，就是坚固之心、坚固精进。什么叫作坚固之心呢？菩萨这样想：‘乃至供养恒河沙数的佛之后，才发起一念之心求佛道；此后又经过恒河沙劫，才有一尊佛出现于世；由于发起恒河沙数之心，才得一次人身；以恒河沙数的人身，才听闻一句法的智慧光明，对阿耨多罗三藐三菩提作大利益。’应当发起这样坚固的心。又以种种方便摄取佛的智慧，以种种苦行作为希求，以种种苦行摄受佛智。又有这样坚固的心。

“再者，迦叶！我现在为你宣说譬喻，由于这个譬喻，诸有智慧的人能理解我所说的义理。由于种种难行苦行才能得到菩提，在恒河沙劫中都不应休止废弃；如果在恒河沙劫中修学而不休废，就能现证无上菩提。应当发起这样坚固的心，以此作为势力，以此作为策励，终究不舍离阿耨多罗三藐三菩提。又有这样坚固的心。

【按】“尔所说义”之“尔”，宋、元、明、宫本作“今”。

“迦叶！如果有菩萨发起这样的心，用什么来摄受呢？就是：不取处，也不取非处。为什么不取处、非处呢？如果取于处、非处，对于无上觉就成为障碍；由于不取处、非处，就能迅速证得无上正等菩提。迦叶！譬如有人以充满三千大千世界的珍宝用来布施；如果有如来所说的这样种种经典，有人随顺菩提，受持其教法，以信心安住，他所生的福聚比前者多出许多倍。

“迦叶！菩萨又有坚固之心：乃至坚固之心也不可得，所以修行不可休废。所谓修习，就是多多修行。有多少呢？随着有若干多多修习之法，如果只起一心，是不能理解的。为什么呢？因为那个法不能作为表示。然而这最殊胜的修习之法，就是坚固的心性。”

这时，世尊说偈颂道：

```
无心起心想，当有大怖畏，
我当成不成？是事为云何？
而常起寻伺，住在于一边，
诽谤于正道，不可得菩提，
此是懈怠心，非是菩提相。
斯人疑一切，诸佛及声闻，
不行而希望，贤圣诸佛法。
```

（大意：心本无心，却生起心想，就会有大怖畏：“我将会成佛还是不会成佛？这件事究竟怎样？”于是常常生起寻伺，住在一边，诽谤正道，就不能得到菩提——这是懈怠之心，不是菩提之相。这样的人怀疑一切诸佛与声闻，自己不修行，却希望得到贤圣诸佛之法。）

```
非但由言说，能成安乐果，
要有信乐心，能成广大法。
亦非唯心量，能获胜堪任，
由一法能成，诸有所作事，
知其殊胜已，为佛故应修。
```

（大意：并不只是由于言说，就能成就安乐之果；要有信乐之心，才能成就广大之法。也不只是靠心量，就能获得殊胜的堪能；由一法能成就一切所作之事，了知它的殊胜之后，为了成佛的缘故，应当修习。）

### 在家菩萨的种种三法

#### 三种修、六法与五障

“再者，迦叶！菩萨由于能成就这个法，即使不亲近供养诸佛，也能自己记别：‘我将会成为如来、应供、正等觉。’

“迦叶！在家菩萨有三种修，能对菩提作出利益。哪三种呢？为了一切智而深生爱乐，不堕于本业，坚持五戒。具足这三支，能成就六法。哪六法呢？就是：得到圣处，不哑、不口吃、不聋、不失听力，身形端严，迅速得到深信，对甚深法不生怖畏，随其所闻之法不用功劳就能领解，迅速得到不退转。对于这六法，应当善知。

“有五种障碍。哪五种呢？就是：离间语、一切妄语、意乐不成、心怀嫉妒、耽著诸欲。这五法会成为障碍。

【按】“具此三支”之“支”，宫本作“友”。

“又有三法应当修行。哪三法呢？就是：常常兴起想要出家的心；对于持戒的沙门婆罗门尊重恭敬；如果是不同类的说法者，应当远离他。为什么呢？菩萨不应当修学他的法；如果修学，就像背负草料一样。为什么呢？因为那不是佛道。如果背负，就是执著，与愚痴的人相同，所以不应当修学那种法。

【按】慧琳《一切经音义》卷第十一释“负蒭”说：“蒭”是草的总名。异译《大方广三戒经》作“菩萨不应担不实草”。

“再者，迦叶！菩萨又应当受学三法。哪三法呢？就是：常常随顺诸佛如来；为他人演说，并且勤于自己修行；对一切众生修习慈心。对这三处，受持之后应当修学。又应当亲近三法。哪三法呢？就是：远离捶打；不毁辱他人，说他卑贱；对于怖畏的人施予无畏。应当亲近这样的三法。”

这时，世尊说偈颂道：

```
不亲下劣人，见不正直者，
见已当远离，犹如避毒蛇，
不应随学他，不礼应远离，
犹如见恶狗，以生恶趣中，
有怀执著人，学之同恶趣。
闻说胜空法，应生爱乐心，
及乐空比丘，亦应起尊敬，
增长多闻道，而生利智心。
亲近胜菩提，有情应敬礼，
疾行受其教，速生诸善根，
增长智慧心，如莲生在水。
宜多听受法，所增善速增，
以增智慧心，能断于诸漏。
```

（大意：不亲近下劣的人；见到不正直的人，见到后就应当远离，犹如躲避毒蛇；不应随他学习，不礼敬他，应当远离，犹如见到恶狗，因为会因此生到恶趣之中；怀有执著的人，学他的人也同堕恶趣。听闻宣说殊胜的空法，应当生起爱乐之心；对于乐空的比丘，也应当生起尊敬，增长多闻之道，生起锐利的智慧之心。亲近殊胜菩提的有情，应当敬礼他们，迅速去领受他们的教导，就能迅速生起种种善根，增长智慧之心，如同莲花生在水中。应当多多听受正法，所增长的善就会迅速增长，以增长的智慧之心，能断除一切漏。）

```
大威德无畏，大智大精勤，
为欲利益他，自身盛利益。
在家应舍离，捶楚打众生，
发趣求菩提，于法得不退，
无病最端正，人皆爱敬之。
若修习慈心，舍离诸恶道，
三十三天上，五欲自欢娱。
从天若命终，不堕于三恶，
生处于人世，种族豪贵家，
形貌最端严，人无能毁者，
天龙所守护，随法正修行。
受于胜妙处，为人所爱重，
善得安隐眠，寤亦心安隐，
以为天拥护，终无怖畏心，
此之广大法，有如是胜相。
```

（大意：具大威德、无畏、大智慧、大精勤的人，为了利益他人，自身也得到盛大的利益。在家人应当舍离捶楚、打众生，发心趣求菩提，于法得不退转，无病而最为端正，人人都爱敬他。如果修习慈心，就能舍离诸恶道，在三十三天上自在享受五欲之乐。从天上命终之后，不堕三恶道，生在人世间豪贵种族之家，形貌最为端严，没有人能毁辱他，受天龙所守护，随顺正法而修行；他得到殊胜美妙的处所，为人所爱重，安隐地睡眠，醒来时心也安隐，因为有天人拥护，始终没有怖畏之心——这广大之法，有这样殊胜的相状。）

```
在家或出家，更有大饶益，
令发悟忆念，多人诸善根。
怖者以施安，趣向菩提果，
更不事余天，唯除一切智，
是人得正道，诸智共相应。
以此诸善根，舍离三恶趣，
得智获三明，善学于三学。
如所作功德，如其所礼敬，
独为众生尊，人多恭敬礼，
礼敬如来者，众中为最上。
住于在家地，若发菩提心，
为彼说法言，及余汝当听。
```

（大意：无论在家或出家，还有更大的饶益：能令许多人发起觉悟、忆念，生起种种善根。对怖畏的人施予安乐，趣向菩提之果；不再奉事其他天神，唯独奉事一切智者。这样的人得到正道，与种种智慧相应；以这些善根，舍离三恶趣，得到智慧，获得三明，善于修学三学。随其所作的功德，随其所行的礼敬，他独为众生所尊，许多人恭敬礼拜；而礼敬如来的人，在大众中最为上首。安住于在家之地，如果发起菩提心，为他所说的法，以及其余的法，你们应当谛听。）

#### 应成、应修与不应作的三法

“再者，迦叶！在家菩萨应当成就三法。哪三法呢？应当远离世间的嬉戏放逸、互相赠送礼物以及选择良日吉时；应当常常清洁，远离多所纳受；又应当精进修学多闻。菩萨应当成就这样的三法。

“又有三法应当受持修行。哪三法呢？对于说法的人不作障碍；应当劝请说法的人；常常点燃灯烛。常应当行这三种行。

“再者，迦叶！有三种法终究不应当做，如果做了，就会受女身。哪三种呢？不应当障碍母亲听闻正法以及见比丘；不应当障碍妻子见诸比丘以及听闻正法；乃至不应当对自己的妻子行非道。这样的三法终究不应当做，如果做了，便受女身。”

这时，世尊说偈颂道：

```
常应以信心，燃灯烛光曜，
便获无尘垢，清净之佛眼，
由依此眼故，了诸所知法。
若能了所知，以知过去法，
知现在亦然，不分别未来，
无有三种相。有斯二种相，
舍离于第三，相即名无相，
皆同为一义。佛所说诸根，
然法无根本，于斯起分别，
便失胜菩提。净修佛眼已，
现证一切法，此句即菩提，
如上所开示。法无有能示，
亦无能毁者，诸法如虚空，
是故说开示。导师宣此义，
以为在家人，常燃灯烛光，
得佛眼明了。不断他说法，
释师子之教，终不往三涂，
不受生盲果。能常劝请他，
宣扬最胜教，以此善根力，
转无上法轮。若人于母所，
为作法留难，受鄙陋女身，
盲伛多众罪，不曾睹众色，
亦不少闻声，住于幽暗间，
犹如蝙蝠类。于妻生妒忌，
与作障法缘，从兹速命终，
当为极陋女，发黄眼睛绿，
黧黯目盲冥，足跛怀毒心，
耳聋多口舌。如斯种类处，
速受众恶身，常为欲因缘，
丈夫生嫉妒。
```

（大意：常常应当以信心点燃灯烛，使光明照耀，便能获得没有尘垢的清净佛眼；依靠这佛眼，了知一切所知之法。如果能了知所知，以此了知过去之法，了知现在也是如此，对未来不作分别，就没有三种相。有了这二种相，舍离第三种相，相就名为无相，都同为一义。佛所说的诸根，然而法本无根本，如果在此生起分别，便会失去殊胜的菩提。清净修得佛眼之后，现证一切法，这一句就是菩提，如上所开示的那样。法没有能开示的，也没有能毁坏的，诸法犹如虚空，所以才说“开示”。存疑。）

【按】“有斯二种相”之“二”，明、宫本作“三”。此段“无有三种相”以下数句，诸本、古注都未见解释，照字面译出，存疑。

（大意：导师宣说这个义理，是为了在家人：常常点燃灯烛的光明，就能得到明了的佛眼；不断绝他人宣说释迦狮子的教法，终究不往三涂，不受生盲的果报；能常常劝请他人宣扬最殊胜的教法，以这善根之力，将来能转无上法轮。如果有人对母亲作听法的留难，就会受鄙陋的女身，又盲又驼背，多有众罪，从来没有见过种种色彩，也很少听到声音，住在幽暗之中，犹如蝙蝠之类。如果对妻子生起妒忌，为她制造听法的障碍，从此很快命终，就会成为极其丑陋的女人：头发黄，眼睛绿，肤色黑黄，眼睛盲暗，脚跛，心怀恶毒，耳聋，多是非口舌。像这样的种种之处，他很快就会受种种恶身，常常为了欲的因缘，而对丈夫生起嫉妒。）

#### 在家菩萨不应作的三法：他施之物、留难出家、营塔取财

“再者，迦叶！在家菩萨有三种法不应当做。哪三种呢？如果是他人布施的东西，即使是少许酥、醍醐等，乃至或多或难施之物，施主如果没有请托，就不应当（擅自）拿去布施；他人想出家，不应当作留难，对于未出家的人，应当劝导，使他出家；见到有人建立如来塔庙，应当协助修建营造，不应当借此获取其中的财物。这样的三法，是在家菩萨所不应当做的。”

这时，世尊说偈颂道：

```
他施功德财，不应与非处，
于重便获罪，所施不能遮。
信者诣施前，合掌俨然立，
于中人力少，乐欲给侍僧。
应随施主言，助其少人力，
水浆汤饮等，及余轻物类，
无违施主心，不令他怨恨。
```

（大意：他人所施的功德之财，不应当给予不当之处；对于贵重之物，便会获罪，所施的东西却不能阻止。存疑。有信心的人来到施物之前，合掌庄严而立；其中如果人力缺少，乐于为僧众供给侍奉，就应当随顺施主的话，帮助那些人力不足之处，以水浆汤饮等，以及其余轻便之物，不违背施主的心意，不让他人怨恨。）

【按】“于重便获罪，所施不能遮”二句，诸本、古注都未见解释，照字面译出，存疑。

```
若有欲出家，或子或亲属，
菩萨于是中，不应作留难。
愿有情安乐，愿得证涅槃，
我胜意乐然，愿说无上法。
知其过失已，不应秽自身，
勿长夜忧嗟，为烦恼所染。
```

（大意：如果有人想要出家，无论是儿子还是亲属，菩萨在这当中不应当作留难，而应发愿：“愿有情得安乐，愿他们证得涅槃。我的殊胜意乐正是如此，愿为他们宣说无上之法。”了知其中的过失之后，不应污秽自身，不要在长夜中忧愁叹息，被烦恼所染污。）

#### 不应修行的三法：贩卖人口、给予非药

“再者，迦叶！在家菩萨有三种法不应修行。哪三种呢？不应贩卖男子女人，也不应给他人非药（不当之药、毒物）；如果有人做了这些事，不应亲近他。”

这时，世尊说偈颂道：

```
应离贩卖男，亦离贩卖女，
非药勿与他，若与者应离。
为苦众生故，天等所同诃，
随趣诸方维，忧箭所中害。
长夜增忧恼，众苦逼其身，
殀寿自销亡，是故不应作。
此过及余失，我悉了其因，
为诸菩萨等，略说其少分。
```

（大意：应当远离贩卖男子，也远离贩卖女人；不要把非药给予他人，如果有人给予，应当远离他。因为这会使众生受苦，诸天都共同呵责；他无论去到哪个方向，都会被忧愁之箭所射中伤害；长夜中增长忧恼，众苦逼迫其身，夭寿而自行消亡。所以不应当做。这些过失以及其余的过失，我都了知其因缘，为了诸菩萨，简略地说出其中少分。）

#### 不应作的三法：淫女家、媒人、屠宰处

“再者，迦叶！在家菩萨有三种法不应当做。哪三种呢？不应当前往淫女之家，不应当亲近做媒的人，不住在屠杀牛羊等的地方。这样的三法不应当做。”

这时，世尊说偈颂道：

```
不至淫女家，专行秽欲者，
速致世讥嫌，亲近下欲故。
尊者知其往，便即起嫌诃，
招疾害其身，以之令寿尽。
常不应亲近，媒媾男女人，
他娶女为婚，近之被诽谤。
亦不应往诣，诸为屠宰家，
菩萨胜依人，皆所不称赞。
此诸深过患，如来悉了知，
为不正行人，我今如实说。
世尊所有教，我弟子能知，
斯人于佛前，能诣所行处。
众生住圣道，将速至涅槃，
佛为如是人，非为恶行说。
```

（大意：不去淫女之家，不去专行秽欲的人那里，否则很快招致世人的讥嫌，因为亲近了下劣之欲；尊者知道他前往，便会嫌弃呵责，他还会招致疾病伤害其身，因此令寿命终尽。常常不应当亲近为男女做媒的人，他人娶妻成婚，亲近媒人就会被诽谤。也不应当前往那些屠宰之家，菩萨这样殊胜的依止者，都不称赞这种行为。这些深重的过患，如来都了知，为了那些不正行的人，我现在如实地宣说。世尊所有的教法，我的弟子能够了知，这样的人在佛前，能到达所应行之处。众生安住于圣道，将迅速到达涅槃，佛是为这样的人说，不是为恶行的人说。）

#### 观身命如客

“再者，迦叶！在家菩萨应当成就三法。哪三法呢？住在家中，观察自己的身命，作如客使之想；对于已经布施出去的财物，作积聚之想；对于还没有布施的财物，作远离自己百由旬之想，不作为妻子儿女而积聚之想。在家菩萨应当成就这样的三法。”

【按】“於已施物”之“已”，《大正藏》作“己”，CBETA 校作“已”。异译《大方广三戒经》亦作“若已施者起集聚想”。

这时，世尊说偈颂道：

```
常修于死想，我命速当终，
于其所积财，应修取坚实。
财不为妻子，亦不为己身，
速疾得坚牢，身命及财物。
殷重求佛道，不起贡高心，
若舍饶益门，常遭诸损害。
犹如於戏童，少尝非饱足，
法味尚轻微，虽信非堪保。
修行非猛励，相去实全遥，
弘扬若不休，名为究竟法。
迦叶我今说，如斯诸法门，
人能解了之，名为一切智。
以智善观察，于身生厌离，
常自正思惟，想之如对我。
```

（大意：常常修习死想：“我的生命很快就要终结。”对于所积聚的财物，应当修习布施，以取得坚实之物；财物不为妻子，也不为自身，迅速取得坚牢的身命与财物。殷重地求佛道，不生起贡高之心；如果舍弃了饶益之门，常会遭受种种损害。犹如嬉戏的孩童，稍稍尝一点，并不能饱足；法味尚且轻微，虽然有信心，却不堪依靠。修行如果不猛利，相距实在还很遥远；弘扬如果不休止，才名为究竟之法。迦叶！我现在所说的这些法门，人如果能理解，名为一切智。以智慧善加观察，对身体生起厌离，常常自己正确思惟，想念它就像面对着我一样。）

#### 得不退转的三法

“再者，迦叶！在家菩萨成就三法，对于阿耨多罗三藐三菩提得不退转。哪三法呢？父母不信，令他们安住于信；父母毁戒，劝令他们安住于戒；父母悭贪，劝令他们安住于舍；赞叹无上正等菩提，为他人说法。这是第一种得不退转无上菩提之法。

“再者，迦叶！在家菩萨了知可供养与不可供养：可供养的就供养他，不可供养的就不供养，然而对于他修习慈心。由于成就这第二法，对无上菩提得不退转。

“再者，迦叶！在家菩萨勤苦积聚财物，不令虚费，不令散失，不随意给予他人，应当坚固收藏；而对于持清净戒的沙门婆罗门以及一切众生平等布施，对于同法的人没有障碍。由于成就这第三法，对无上菩提得不退转。”

这时，世尊说偈颂道：

```
若在家菩萨，求无上菩提，
生三根本慧，此为最上觉。
若父及与母，恶慧无信心，
劝令生信乐，令其住胜法。
悭犯住戒舍，无慧教令慧，
亦常劝于是，为菩提胜法。
应往于四方，遍求说法者，
法施以教人，由斯增智慧。
犯戒令住戒，无信令信心，
无慧教令慧，得成不退转。
若逢慧比丘，持戒多闻者，
恭敬亲近之，数往而咨问，
在家由此法，得不退菩提。
```

（大意：如果在家菩萨求无上菩提，应生起三种根本智慧，这是最上的觉悟。如果父亲以及母亲智慧低劣而没有信心，就劝他们生起信乐，令他们安住于殊胜之法；对悭吝、犯戒的，令其安住于戒与舍；对没有智慧的，教他们生起智慧；也常常劝导他们这些，作为菩提的殊胜之法。应当前往四方，遍求说法的人，以法布施教导他人，由此增长智慧。令犯戒的人安住于戒，令无信的人生起信心，教无慧的人生起智慧，就能成就不退转。如果遇到有智慧、持戒、多闻的比丘，恭敬亲近他，屡屡前往请教，在家人由此法，就能得到不退的菩提。）

```
知彼胜德人，多闻具诸智，
慧解堪尊重，可持身肉施。
此为信心相，如我前所言，
无信则不能，发大菩提意。
聪明见胜事，速成深利益，
于诸殊妙法，取证不为难。
知自及与他，如斯胜饶益，
与出离相应，是故增智慧。
本来恒积集，所有诸资财，
为与持戒俱，共贮当来物。
是无有异语，彼亦不虚言，
勇进坚施成，当证如来果。
```

（大意：了知那位有殊胜德行的人多闻而具足诸智，智慧与见解堪受尊重，甚至可以用自己的身肉布施给他。这就是信心之相，如我前面所说：没有信心，就不能发起大菩提意。聪明的人见到殊胜之事，能迅速成就深广的利益，对于种种殊妙之法，取证也不困难。了知自己与他人这样殊胜的饶益，与出离相应，所以增长智慧。原本恒常积聚的所有资财，是为了与持戒者一同贮存未来之物。这话没有虚异，他们也不说虚言：勇猛精进，坚固地成就布施，将证得如来之果。）

```
持戒易共住，勇健获深慈，
布施摄众生，如先后无异。
清净最上施，无所有希求，
若金若与银，无有不施者。
勇猛施一切，宿世所行檀，
希求无上乘，甚深最胜位。
非法而供养，一切诸天人，
不如能顺法，供养一众生。
勇健为法求，以法能了法，
聪明由胜道，获无上菩提。
```

（大意：持戒的人容易共住，勇健者获得深切的慈心，以布施摄受众生，前后如一，没有差别。清净最上的布施，没有任何希求，无论是金还是银，没有不能布施的。勇猛地施舍一切，正如宿世所行的布施，以此希求无上乘那甚深最殊胜之位。以非法去供养一切天人，不如能随顺正法，供养一个众生。勇健者为法而求，以法能了达法，聪明的人由殊胜之道，获得无上菩提。）

#### 退入声闻乘的三法

“再者，迦叶！在家菩萨发阿耨多罗三藐三菩提心之后，成就三法，就会在声闻乘中般涅槃。哪三法呢？这里有一类人，畏怖三恶道，对于大菩提生起重担之想，对已经积集的善根不专心思念，不喜好善加寻求，被自己的心所伤害，便生起苦想。由于成就这第一法，退失菩提，在声闻乘中般涅槃。再者，迦叶！这里有一类人，对于所行的布施不生欢喜之心，布施之后便生追悔，又不回向佛的智慧。由于成就这第二法，退失菩提，迅速在声闻乘中般涅槃。再者，迦叶！这里有一类人，不勤精进，不专求多闻，以下劣的善根迅速般涅槃。由于成就这第三法，退失菩提，迅速趣向声闻乘而般涅槃。”

这时，世尊说偈颂道：

```
发菩提心已，不正随顺行，
退失于佛乘，入于声闻道。
菩提非不信，及以懈怠心，
无智守悭贪，则为有障碍。
知恩住净戒，常乐广行檀，
菩提不难得。由心造诸恶，
心亦善行檀，众生心若坚，
当为世间塔。若能离三法，
心趣大菩提，当为世间尊，
成无上应供。
```

（大意：发菩提心之后，不正确地随顺而行，就会退失佛乘，进入声闻之道。对菩提不信，以及懈怠之心，无智而守着悭贪，这些都是障碍。知恩、安住于净戒，常乐广行布施，菩提就不难得。由于心而造作种种恶，也由于心而善行布施；众生的心如果坚固，就将成为世间之塔。如果能远离这三法，心趣向大菩提，就将成为世间所尊，成就无上应供。）

#### 退入独觉乘的三法

“再者，迦叶！在家菩萨由于成就三法，退失菩提，在独觉乘中般涅槃。哪三法呢？这里有一类人，虽然已经发起趣向大菩提之心，对法却悭吝。又有一类人，耽著于观望，以及取世间吉凶之相。又有一类人，发了菩提心，由于懈怠，不能遍求菩提分法。由于成就这三种法，每一种都能使人退失菩提，在独觉乘中般涅槃。”

这时，世尊说偈颂道：

```
悭悋于正法，不教诲他人，
得独觉菩提，退失无上道。
由斯二种义，失利众苦生，
亲近而修行，疑惑菩提道。
思惟大乘法，就吉以避凶，
此非正信心，为佛所弃舍。
有能专意乐，坚固向菩提，
终不礼余尊，唯除世间塔。
若有净信心，不事余天等，
是为成最上，号曰天中天。
若有乐菩提，不事余天等，
在在所生中，色力恒具足。
```

（大意：对于正法悭吝，不教诲他人，就会得到独觉菩提，退失无上之道。由于这两种情况，失去利益，生起众苦；亲近而修行（吉凶之事），对菩提道生起疑惑；思惟大乘法时，却要趋吉避凶，这不是正信之心，为佛所舍弃。如果有人能专一意乐，坚固地趣向菩提，终究不礼拜其他尊神，唯独礼拜世间之塔（佛）。如果有清净的信心，不奉事其他天神等，这就是成就最上，号称“天中天”。如果有人乐求菩提，不奉事其他天神等，在所生之处，色身与力量常常具足。）

【按】“由斯二种义”之“二”，宋、元、明本作“三”。

#### 受身黑闇的三法

“再者，迦叶！在家菩萨由于成就三法，受生黑暗之身。哪三法呢？在如来塔所取走灯明；对他人的诤讼显现瞋恚；对于与自己无关的黑皮肤之人，横加毁呰。由于这三法，其身黑暗。”

这时，世尊说偈颂道：

```
塔所燃灯明，断取是光焰，
身便为黑暗，犹如乌毯毛。
毁呰于黑人，我白汝身黑，
由其轻毁他，受身便黑暗。
宜善护其语，业终不败亡，
随其所造业，当为彼业器。
```

（大意：在塔所燃灯之处，截取那些光焰，自身便会变得黑暗，犹如乌鸦毛织的毯子。毁呰黑皮肤的人，说“我白，你身黑”，由于轻毁他人，所受之身便会黑暗。应当善于守护自己的言语，业终究不会消失，随其所造之业，就将成为那业的器皿（承受其果报）。）

#### 生工匠家的三法

“再者，迦叶！在家菩萨由于成就三种业，会生在工匠之家。哪三种呢？菩萨自身能持五戒，如果有亲属从远方来，就给酒让他喝，或者劝他人喝酒，就会生在那工匠之家，这名为第一法。再者，迦叶！在家菩萨自己修持梵行，却撮合他人去行秽欲，由于造作这种业积集成就，就会生在那工匠之家，这名为第二法。再者，迦叶！菩萨见到他人精勤读诵，而自己家里正在动工兴作，随即对他说：‘你暂且停下读诵之业，及时为我营办成就这件事。’由于这种业缘积集成就，就会生在那工匠之家，这名为第三法。”

这时，世尊说偈颂道：

```
持酒劝他人，及与诸亲属，
以成狂饮故，便为饶语匠。
不解作刀针，及余工巧处，
唯能坐摇手，炉前鼓橐囊。
自能修梵行，为他称赞淫，
此业异熟时，当为饶语匠。
不解作刀针，不能鼓风橐，
唯解奋长槌，砧前而锻铁。
令他弃舍法，从兹而命终，
速生工巧家，禀识常愚暗。
初不见囊橐，亦不见钳槌，
其业报应然，悉破坏众器。
```

（大意：拿酒劝他人以及诸亲属喝，由于让他们狂饮，便成为“饶语匠”；不会制作刀针，以及其余工巧之事，只能坐着摇手，在炉前鼓动风囊。自己能修梵行，却为他人称赞淫欲，这个业成熟时，就成为“饶语匠”；不会制作刀针，也不会鼓动风囊，只会挥舞长槌，在铁砧前锻铁。令他人舍弃正法，从此命终，很快生到工巧之家，禀性心识常常愚暗；起初连风囊都没见过，也没见过铁钳和槌，他的业报应当如此，会把种种器具都破坏掉。）

【按】“饶语匠”，诸本、古注都未见解释，照字面保留，存疑；异译《大方广三戒经》此处只作“生堕工巧家”。“橐囊”，慧琳《一切经音义》卷第十一说（解释）：是用来鼓风吹火的袋子，俗称韛袋。

```
迦叶应防意，及善护其言，
永勿教他人，一切不善法。
轮回生死苦，由爱故增生，
善法可勤修，应诃诸不善。
```

（大意：迦叶！应当防护心意，并且善于守护言语，永远不要把任何不善之法教给他人。轮回生死之苦，由于爱而增长生起；善法应当勤加修习，应当呵责一切不善。）

#### 生刹利豪族的三法

“再者，迦叶！在家菩萨成就三法，将生在刹利豪族之家的众同分中，容貌端严，为人所爱敬，聪慧善巧，不会懒惰。哪三法呢？就是：见到从未见过的沙门婆罗门，就生起信心，供养礼敬，说‘这是福田’，以清净心延请供养衣服、饮食、卧具、医药等一切所需。在家菩萨成就这第一法，将生在刹利豪族之家的众同分中。再者，迦叶！在家菩萨坚定安住于本来的誓愿，如所说而修行，始终不说妄语。由于成就这第二法，将生在刹利豪族之家的众同分中。再者，迦叶！在家菩萨对于具足戒蕴的沙门婆罗门修供养时，能摄受坚固之法。由于成就这第三法，将生在刹利豪族之家的众同分中。”

这时，世尊说偈颂道：

```
诸有智慧等，见持戒多闻，
应生欢喜心，往彼而请命。
既为请命已，如法供养之，
无有厌悔心，所施无罣阂。
是取坚牢法，所为亲近者，
种种智相应，于难而速得。
如斯深信意，趣向大菩提，
是智之所行，佛道非难证。
恒为上活命，应受最胜财，
希求殊妙法，证无上涅槃。
```

（大意：一切有智慧的人，见到持戒多闻者，应当生起欢喜之心，前往那里延请。延请之后，如法供养他，没有厌倦后悔之心，所施没有罣碍。这就是取得坚牢之法；他所亲近的人，与种种智慧相应，在困难中也能迅速得到。像这样深信之意，趣向大菩提，这是智者所行之道，佛道并不难证。常常以上等的方式活命，应当受用最殊胜的财物，希求殊妙之法，证得无上涅槃。）

```
当生豪族家，颜貌甚端严，
得上妙衣服，证最上涅槃，
如佛所称誉。行于最上乘，
以佛乘能证，清凉妙涅槃，
是为最胜果。如其所造业，
获果亦等流，设经百亿劫，
是业终无坏。
```

（大意：他将生在豪族之家，容貌十分端严，得到上妙的衣服，证得最上的涅槃，正如佛所称誉的那样。行于最上乘，以佛乘能证得清凉微妙的涅槃，这是最殊胜之果。随其所造之业，所获之果也是等流；即使经过百亿劫，这个业终究不会坏失。）

#### 不受五欲的三法

“再者，迦叶！在家菩萨成就三法，种下种种善根，乃至证得无上菩提，终究不受五欲世间之乐。哪三法呢？在家菩萨受持五戒，不向他人赞叹五欲之乐，勤修自己的事业，不役使女人，并且发这样的心：‘我停止亲近一切女人，乃至证得无上菩提，愿我不遇到五欲世间之乐。’由于成就这最初之法，乃至菩提都不受五欲。

“再者，迦叶！在家菩萨听闻这些经而生起深信，求趣涅槃；虽然这些教法被隐蔽而不能流行，但有人能演说、发起它，如果有人听了，就会舍离种种恶作之处。以这样的善根，得到无碍辩才、无著辩才，无论现在还是命终之时，都能迅速见佛；命终之后往生天上，不久证得阿耨多罗三藐三菩提。由于成就这第二法，乃至菩提都不受五欲。

“再者，迦叶！在家菩萨把所有的善根全都回向无上菩提，不乐于色、声、香、味、触、法，不乐于财物、封邑、尊贵，不爱眷属，以无为之心、无为的果报，迅速证得无上正等菩提。由于成就这第三法，乃至菩提都不受五欲。”

这时，世尊说偈颂道：

```
在家修五戒，坚守善护持，
不亲近女人，于中生厌恶，
如是等法门，勤求无厌足，
所有恶作处，应速舍离之。
一切诸善法，悉回向菩提，
以此诸善根，速离于五欲。
常获胜多闻，为众生说法，
发生大慈意，求无上菩提。
是故闻此利，应生贤善心，
不近于诸欲，速疾转法轮。
```

（大意：在家人修持五戒，坚固守护，善加护持，不亲近女人，对之生起厌恶；对于这样的法门，勤求而没有厌足，所有恶作之处，应当迅速舍离。一切善法，全都回向菩提，以这些善根，迅速远离五欲。常常获得殊胜的多闻，为众生说法，发起大慈之意，求无上菩提。所以，听闻这种利益，应当生起贤善之心，不接近诸欲，就能迅速转法轮。）

### 经名与流通

这时，大迦叶对佛说：“世尊！现在这部经法以什么为名？我们现在应当怎样奉持？”

佛告诉迦叶：“这部经名为《说三律仪》，也名《宣说菩萨禁戒》，也名《同入一切诸法》。”

佛说完这部经，尊者大迦叶以及诸大众，一切世间的天、人、阿修罗、乾闼婆等，听闻佛所说，都大欢喜，信受奉行。

【按】本卷相当于异译《大方广三戒经》卷下全卷。异译经名作“演说三戒”“说菩萨禁戒”“集一切佛法”。三律仪会至此终。
