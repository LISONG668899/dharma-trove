# 歌（智慧狮子）

作者不详　据藏文译出

## 题解

本篇收于德格版丹珠尔续部释 ཟི 函第 8a 页（东北目录 D2363）。开头没有梵藏题名，只有"敬礼佛陀"；篇末只有"圆满"二字，没有作者与译者的名字。

全篇约十五句，共四段，每段一个"你不要……"，叠句是"要像自在欢喜的智慧狮子一样"：对三世善恶不要欢喜或不欢喜；对修与不修、具不具菩提心不作分别；对佛与众生之道不分顺违；对轮回涅槃、苦乐果法不怀希惧。全篇是纯粹的心性开示，没有涉及具体的密法修持。

关于同名：德格丹珠尔 ཟི 函中，D2363 与 D2364 两篇的题名都只是"歌"，作者也都没有记载；前面的 D2359、D2360 也同题为"歌"。本站依各篇叠句的主题，以括号区分：D2363 题为《歌（智慧狮子）》，D2364 题为《歌（嘎纳之剑）》。

体例：藏文原文全部保留在代码框中，按段落分节，每节后附汉译；叠句照原文每次重复。凡标"存疑"的按语，表示本译对原文意思没有把握。藏文依 Esukhia 德格丹珠尔电子版。

## 礼敬

```
སངས་རྒྱས་ལ་ཕྱག་འཚལ་ལོ། །
```

敬礼佛陀！

## 一、于三世善恶，不喜不忧

```
འདས་དང་མ་འོངས་ད་ལྟར་གྱི། །
དགེ་དང་མི་དགེའི་ལས་རྣམས་ལ། །
དགའ་དང་མི་དགའ་ཁྱོད་མ་བྱེད། །
རང་དགའ་ཡེ་ཤེས་སེང་གེ་བཞིན། །
```

对于过去、未来、现在的善业与不善业，你不要欢喜，也不要不欢喜。要像自在欢喜的智慧狮子一样。

【按】"要像自在欢喜的智慧狮子一样"，是全篇的叠句。"自在欢喜"（རང་དགའ），指不依外缘、自然而然的喜悦与自在；狮子象征无畏。全篇四段，每段都是一个"你不要……"，劝人放下一对对二元的分别。

【按】"对善业不欢喜，对不善业不忧"，是就证悟者的心境而说：不执著善恶的分别，安住于心性。这不是说可以不分善恶、不取舍因果。

## 二、于修与不修，不作分别

```
ཆོས་ཉིད་ཟབ་མོ་རྣལ་འབྱོར་ཡུལ། །
སྒོམ་དང་མི་སྒོམ་བྱང་ཆུབ་སེམས། །
ལྡན་དང་མི་ལྡན་ཁྱོད་མ་བྱེད། །
རང་དགའ་ཡེ་ཤེས་སེང་གེ་བཞིན། །
```

对于甚深的法性、瑜伽的境界，对于修与不修、具不具菩提心，你都不要作［分别］。要像自在欢喜的智慧狮子一样。

【按】存疑。第六至八句的语法关系不完全清楚，本译理解为：法性是瑜伽士的境界，在其中不要分别修与不修、具不具菩提心。

## 三、于佛与众生之道，不分顺违

```
སངས་རྒྱས་དང་ནི་སེམས་ཅན་གྱི། །
སྤྱོད་པའི་ལམ་ནི་འདི་ཡིན་ཞེས། །
མཐུན་དང་མི་མཐུན་ཁྱོད་མ་བྱེད། །
རང་དགའ་ཡེ་ཤེས་སེང་གེ་བཞིན། །
```

说"佛与众生的行道就是这个"，对此你不要作顺与不顺的［分别］。要像自在欢喜的智慧狮子一样。

## 四、于轮涅苦乐，不怀希惧

```
བདེ་དང་སྡུག་བསྔལ་འབྲས་བུའི་ཆོས། །
འཁོར་དང་མྱ་ངན་འདས་པ་ལ། །
རེ་དང་དོགས་པ་ཁྱོད་མ་བྱེད། །
རང་དགའ་ཡེ་ཤེས་སེང་གེ་བཞིན། །
```

对于乐与苦这些果法，对于轮回与涅槃，你不要怀有希望与恐惧。要像自在欢喜的智慧狮子一样。

【按】"对于轮回与涅槃不怀希惧"，与帝洛巴《恒河大手印》"没有希望与恐惧，果就会现前"、《歌（可叹与稀有）》（D2360）"没有希望与恐惧就是大手印"同一意趣。
