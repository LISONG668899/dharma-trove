# 龙树《释摩诃衍论》卷第一

龙树菩萨造　姚秦三藏筏提摩多奉诏译

## 序

天册凤威姚兴皇帝制

听说日月宝珠般的佛陀，曾安住在灵山禅宫，行于真俗二道，游化百国，以平等之观遍达恒河沙数的国土，举起极喜的宝珠，照见寂灭的灵宫。佛陀在世时，众生虽然听闻，仍未觉悟；百千恒沙世界中的众生迷惘不清，直到那时才开始得到开解。

我从前听到街巷中传颂佛名，盼望教化的时节，只见佛像的形迹，只在佛风散去之后瞻仰。如今果然面见摩尼宝藏来到东土，如同得到因陀罗网上的宝珠：内心欢喜，好比祇园的莲座不待召请自来，可以作为龟镜；外目庆幸，好比月中涌现的楼台不再离去，令人钦仰。

我正要在七觉支的宝林中培植妙花的善因，在八功德的宝池中种下莲种，回顾往昔而欢喜，面对将来而急切。加上金轮从东方自来，应于威门之地，道王的偈颂先已记载，珠镜山灵已经降临。佛经中也曾记载，未来八万年时法轮东行，过去五百年时觉珠南至，现在都应验了。

这部论的教理，好比向观世音菩萨借来千眼千手，去搜求超过恒沙的教门；这部论的义理，好比借帝释天的珠网之功，去照亮尘沙数的义理。马鸣先圣光明的德行，在这时完全显现；龙树大士妙云的祥瑞，在这里开启，广大而庄严。若不是在山林中立下誓愿、在香池中种下双因的大士，谁能在弥勒之前悬起演法的宝盖，在释迦之后敷陈受持的秘轨？

《释摩诃衍论》，穷尽性海源头的秘藏，说尽修行因地的根本。它的义理像星轮超过月珠，君子不能识其宗旨；像锦华直达日边，众人难测其边际。可以说一山之中有两个日月，一个天下有两个皇帝。

我听说此论的梵本原在中天竺，派遣使者奉迎，近来到达东界。在弘始三年九月上旬，于大庄严寺亲自参与笔削，恭敬译出此论。直接翻译的是筏提摩多三藏，传译俗语的是刘连陀等人，执笔的是谢贤金等人，前后两年才缮写完毕。

此时日月圆满临照，群星舒展光芒，江河之水澄清，大海的波澜平静，我还来不及细说。这部论能把金轮从大地上托出，把须弥山纳入掌中，细到喜乐之门周遍法界，大到寂静之室纳入毫端。这样的道理，超出文字所能称说，离开图画所能描绘。用语言来说，维摩诘会呵斥我；用谈论来说，须菩提会让我吐露。然而言语终归要止于讽诵，词章终归要止于默然；拆了楼台，不能弘扬太虚；毁了镜玉，不能显出影像。我无以为言，只好请月兔借笔，草草写成这篇序。

## 归敬颂

```
顶礼圆满觉，觉所证法藏，
并造论大士，及诸贤圣众。
欲开隔檀门，权显往向位，
利益诸众生，分报师恩故。
```

（大意：顶礼圆满觉悟的佛陀，顶礼佛所证悟的法藏，顶礼造论的马鸣大士和一切贤圣僧众。为了打开凡圣之间那道隔碍之门，权巧显示趣向佛果的阶位，利益一切众生，并以此稍报师恩。）

## 一、造论的本趣

论中说：现在造这部论，是为了重新解释《摩诃衍论》，也就是马鸣菩萨的《大乘起信论》。为什么要重释？

第一，为了显示自己的老师马鸣菩萨所造之论，本体深玄，穷尽微妙。还没有得到正证、还没有出离邪行的人，在漠漠冥冥之中，实在无从窥见它的门径，因为它超出了思惟的境界。

第二，为了让利根和钝根的众生，打开顿入之门，显示渐进的阶位，趣入此论甚深的所诠之理。

第三，因为老师养育之恩极其深重，以此稍报师恩。

第四，暗中观察到未来的众生会生起百千种争论，破坏此论的宗旨。

第五，亲自听受了老师的意乐（阿世耶）。

有这些因缘，所以必须造论。

## 二、论的差别

已经说了本趣，下面说论的差别。论有多少？归入几类？《摩诃衍论》属于哪一类？颂说：

```
十万九千部，总十论所摄，
摩迦罗、跋提、邬舍摩、阇他、
筏那提舍论、阿部帝、跋摩、
呼呵、摩僧那、键婆摩迦摄。
```

（大意：一代所集的诸论共十万九千部，总归十类所摄。）

论中说：汇集一代的种种诸论，共有十万九千部，总归十类所摄。哪十类？一是摩迦罗论，二是跋提论，三是邬舍摩论，四是阇他论，五是筏那提舍论，六是阿部帝论，七是跋摩论，八是呼呵论，九是摩僧那论，十是键婆论。《摩诃衍论》属于键婆论，也就是如意论。

马鸣菩萨所造的论有多少？其中多少重文辞，多少重义理？《摩诃衍论》属于哪一类？颂说：

```
总有一百部，九十九种文，
十种义所摄，斯论宝册摄。
```

（大意：马鸣菩萨共造一百部论，九十九部属于文辞一类，另有义论一类；这部论是义论中的宝册。）

论中说：马鸣菩萨所造的论共有一百部。百部之中，九十九部属于花文论，其余属于摄义的论。这部宝册所属的十种摄义论，名字是什么？所开示的义理是同是异？颂说：

```
遍满及归真，中藏与微妙，
合一并三昧，清净、本原论，
玄理、起信论，建立同一相。
```

（大意：十种义论名称各别，所建立的宗旨相同。）

论中说：十种是：一心遍满论、融俗归真论、法界中藏论、秘密微妙论、众命合一论、真如三昧论、心性清净论、不动本原论、甚深玄理论、大乘起信论。这十部论数目虽然不同，所建立的义理是同一个。

## 三、藏的差别

已经说了论的差别，下面说藏的差别。藏有多少？归入几藏？《摩诃衍论》属于哪一藏？颂说：

```
或五十一藏，或唯十如经，
总三藏所摄，论或通或别。
```

（大意：藏有说五十一的，有说十种的，总归三藏所摄；这部论或通属诸藏，或别属一藏。）

论中说：说五十一藏，是为了区别因果、表显功德、引导修行人。《金刚契经》中说，佛告诉佛子：我当以无碍的言辞，为你宣说开示五十种因藏和一种果藏。

也有说十藏的。

第一，只立一藏总摄诸法，叫作法界法轮藏。《圆满契经》中说，一切众生所有的言音，无不是如来法轮之声所摄。

第二，立二藏总摄诸法，就是声闻藏和菩萨藏。《总持契经》中说，法门虽然无边，不出两种藏。

第三，立三藏总摄诸法，再加上如来藏。《光明契经》中说，超过恒沙的一切诸佛，只宣说声闻法藏、菩萨法藏、如来法藏，再没有别的道。

第四，立四藏总摄诸法，再加上补特伽罗藏。《道品契经》中说：佛子谛听，我为你解说仁藏、义藏、礼藏、智藏、信藏，以及声闻藏、菩萨藏、大觉法藏，因为这是一切修行人渐次转胜的次第之法。

第五，立五藏总摄诸法，再加上天藏。《天子契经》中说，佛告诉耶论：不可言说的清净报空，我为大众广为宣说净藏、人藏、二乘藏，以及一切诸佛的大觉法藏。

第六，立六藏总摄诸法，再加上地狱（捺落迦）藏。《怖畏契经》中说：我不动本座，分别宣说八万四千地狱藏，加上前面的五种藏。

第七，立七藏总摄诸法，再加上鬼神（摩罗鸠多耶）藏。《班母契经》中说：我今真实地为班母等一亿七万三千大众，分别宣说五万一千三百零二种鬼神道藏，加上前面的六种藏。

第八，立八藏总摄诸法，再加上傍生（键婆陀那跋）藏。《龙王契经》中说，难陀龙王发起八千个问题请问如来，佛开示了十亿傍生道藏，加上前面的七种藏。

第九，立九藏总摄诸法，再加上器世界藏。《世界契经》中说：那时世尊告诉树神说，善哉善哉，如你所说。你若想听，我今为你分别演说所依止的世界藏，加上前面的八种藏。

第十，立十藏总摄诸法，再加上杂乱藏。《音声契经》中说：我今开示八种杂藏，加上前面的九种藏。

这些藏总共摄十亿八千法藏。根本三藏也可以摄这十藏。三藏是：素呾缆藏（经藏）、毗捺耶藏（律藏）、阿毗达磨藏（论藏）。《摩诃衍论》或者为诸藏共摄，或者只属阿毗达磨藏，所以颂中说或通或别。通，是总通；别，是简别。能持修行之法，随所应用而不失，所以叫作藏。

## 四、经的差别

已经说了藏的差别，下面说经的差别。经有多少？归入几类？《摩诃衍论》依据什么经？颂说：

```
总百洛叉数，十二部经摄，
修多罗、祇夜、及毗伽罗那、
伽陀、忧陀那、并与尼陀那、
阿波陀那经、伊帝目多伽、
阇陀伽、佛略、阿浮陀达摩、
优波提舍经，依或通或别。
```

（大意：诸经数量极多，总归十二部经所摄；此论所依之经，或通或别。）

论中说：汇集一代的种种诸经，共有一百亿部，总归十二部所摄：修多罗、祇夜、毗伽罗那、伽陀、忧陀那、尼陀那、阿波陀那、伊帝目多伽、阇陀伽、毗佛略、阿浮陀达摩、优波提舍。

《摩诃衍论》所依据的本经，或通或别。通是总通，别是简别。

问：《摩诃衍论》文字简短，句子极少，为什么要以无量无边的契经之海为共同所依？

答：就像婆萨伊伽诺，就像标多罗呾提，所以没有过失。

别所依的经有多少？名字是什么？各有多少眷属？颂说：

```
总一百契经，光明大觉等，
初五十各百，后五十各千。
```

（大意：别所依的经共一百部，以《光明大觉经》为首；前五十部各有百部眷属，后五十部各有千部眷属。）

论中说：《摩诃衍论》别所依的经共有一百部，名为：光明大觉经、甚深顺理经、金刚三昧经、诸法无行经、树林说法经、无尽一地经、清净如如经、自性自体经、大乘同性经、阿梨耶识经、果圆满经、虚空等经、三三昧经、一心法经、本性智经、真法界经、摄无量经、最上极经、维摩诘经、楞伽王经、中实经、无始经、十因经、轮转经、慈云经、器心经、无位经、贤圣经、隐密经、华严经、大品经、寂灭经、圣轨经、遍缘经、熏习经、佛性经、玄理经、楞伽经、本业经、蕴高山经、归本经、真修经、八德经、佛慧经、缘起经、一体经、自佛慧经、大海经、无相经、遍真如经、十种如来藏经、三身本有经、八识通达缘经、众生身等法经、诸佛无尽藏经、赞叹不善品经、诸法同一相经、一体大悲观经、如如本智慧经、尘尘法界刹土经、轮转本际经、法界法轮经、大智本有经、平等法界经、四相常住经、真如一相经、流转不动经、寂静涅槃经、通达音声经、如来自相经、夫人经、法门经、八喻经、中在经、总持经、不动经、两智经、道智经、本觉经、大无量经、自然本果经、甚深法藏经、一道清净经、十种妄想经、法门显了经、境界圆满经、光明实智经、因果同体经、心神不空经、真智无生行经、无碍解脱经、随缘增长经、法性实际经、广大虚空经、本因缘起经、诸法无为经、本来清净经、修行道地经、不修具德经、摩诃萨云若经。

这一百部经的眷属，依次前半各有一百部，后半各有一千部。列举经名，是为了作为本论的纲目，下文会随文开示。

## 五、造论的人

已经说了经的差别，下面讨论造论的人。契经中关于马鸣的不同说法有几种？现在的马鸣论师属于哪一种？颂说：

```
总有六马鸣，契经异说故，
然随机应故，无有相违失。
```

（大意：诸经中说有六种马鸣，说法不同；但都是随机示现，并无相违的过失。）

论中说：汇集一代诸经中的种种异说，共有六种。

第一，《大乘本法契经》中说：无上大觉世尊宣说入涅槃的因缘时，马鸣菩萨从座而起，顶礼佛足，合掌恭敬，对佛世尊说偈：

```
大慈满足无上尊，无边劫海备万行，
唯慈悲群生类故，而佛自言入涅槃，
我及一切诸大众，冥冥而乱失心神。
大慈满足世尊尚，弃自子等往异界，
况我慈悲未满足，随佛往异界谁谤？
```

（大意：圆满大慈的无上世尊，在无边劫海中修备万行，只为慈悲众生，如今却说要入涅槃，我和大众心神昏乱。圆满大慈的世尊尚且舍下自己的孩子们前往他界，何况我慈悲还未圆满，随佛前往他界，谁会责怪？）

马鸣说完此偈，望着佛的眼睛，慢慢命终。

第二，《变化功德契经》中说：那时世尊告诉马鸣：我灭度后三百多年，你当承我的加持之力，以种种方便之法利益安乐末世众生。如果我不加持，你自己不能做到。

第三，《摩诃摩耶契经》中说：如来灭度六百年后，九十六种外道邪见竞起，毁灭佛法。有一位比丘名叫马鸣，善说法要，降伏一切外道。

第四，《常德三昧契经》中说：佛灭度后八百年中，有一位智者名叫马鸣，或在外道众中，或在佛门众中，破斥外道，建立佛法。

第五，《摩尼清净契经》中说：佛涅槃后一百多年，马鸣大士出现于世，守护正法，安立佛的法幢。

第六，《胜顶王契经》中说：如来成道第十七天，有一个外道名叫迦罗诺鸠尸摩，把自身变化成大龙王，现出八万六千个头、八万六千条舌，同时发出八万六千个相违的难问，请问如来。如来以三重回答，通解了他所有的难问。于是龙王又发十重问难，如来以百重回答通解。问答之后，佛告诉龙王：善哉善哉，马鸣沙门！你为了守护法城，以破坏之相来建立佛法。好好忍耐，常这样修，常这样行，不要只在小处游行，要普遍游行。

于是龙王恢复本形，舍弃畜生之相，在无上世尊面前顶礼致敬，满面欢喜地对佛说颂：

```
善哉善哉言，经听于我耳，
假耶实耶自，极疑于我心。
我非畜生身，我非外道众，
而赞化为生，变化如是形。
世尊如镜知，我没于是界，
出于余世界，如教普游行。
```

（大意：世尊称赞的善哉之言传入我耳，是假是真，我自己心中也极为疑惑。我不是畜生身，也不是外道众，是为了赞助教化众生，才变化成这样的形相。世尊如明镜一样知道：我将在此界隐没，在其余世界出现，依教普遍游化。）

马鸣说完此偈，如入禅定一般，进入寂室。

这就是六种。这些经各自别说，都是随机示现，没有相违的过失。

马鸣菩萨是什么位次的人？在哪里诞生？为什么叫马鸣？颂说：

```
本大光明佛，因不动位中，
西天竺出现，从过去立名。
```

（大意：本地是大光明佛，因位是第八不动地；出现于西天竺，名字来自过去的因缘。）

论中说：马鸣菩萨，若论本地，是大光明佛；若论因位，是第八地中的菩萨。他在西天竺诞生，父亲名叫卢伽，母亲名叫瞿那，一同利益众生。

过去世中，有一位大王名叫轮陀，养了一千只白鸟，都有美妙的声音。鸟若鸣叫，大王的福德就增长；鸟若不鸣，大王的福德就减损。这些鸟见到白马就鸣叫，见不到就不出声。大王遍求白马，终日不得，于是说：如果外道能让这些鸟鸣叫，我就彻底破除佛教，独尊独信外道；如果佛弟子能让这些鸟鸣叫，我就彻底破除外道之教，独尊独信佛法。那时菩萨用神通力，化现一千匹白马，让一千只白鸟鸣叫，使正法继续兴隆，不致断绝。所以世尊为他取名马鸣。

## 六、归敬三宝

### 归敬佛宝

已经说了造论之人，下面引本论原文来解释。

本论：

```
归命尽十方，最胜业遍智，
色无碍自在，救世大悲者。
```

（大意：以尽十方一切众生的生命，归依业用最胜、智慧遍知、色身无碍自在、救度世间的大悲世尊。）

论中说：这一颂有两门：一是总摄一切众命门，二是归向圆满大觉门。

总摄门，是通摄十方世界中所有众生的命根，所以本论说命尽十方。

归向门，是用这样的众命，归向圆满大慈悲的人，所以本论说归最胜业遍智色无碍自在救世大悲者。

论师举了几种功德来赞叹大觉世尊？各自的相状如何？颂说：

```
总八万四千，四十八种德，
最胜等各十，智无碍各四，
及八万四千，色相差别故，
功德虽无量，终不出此数。
```

（大意：总共举了八万四千零四十八种功德：最、胜、业、遍各十种，智与无碍各四种，加上八万四千种色相差别。佛的功德虽然无量，终不出此数。）

论中说：马鸣菩萨总共举出八万四千零四十八种功德，赞叹无上大觉。佛果位上的清净功德虽然无量无边，终不出此数，所以马鸣总相赞叹。

八万四千种功德，是因为色相的差别而成。四十种，是最、胜、业、遍各十种。八种，是智和无碍各四种。

十种最：

第一，超过最，远离二乘之地。第二，出离最，永离三界。第三，对治最，顿断四住地烦恼。第四，厌患最，已经越过五蕴的聚落。第五，离爱最，永别六道的歧路。第六，威德最，击退七种恶军。第七，兵众最，尽伐八邪之林。第八，智慧剑最，斩断九结的羁绊。第九，解脱最，断除十缠的绳索。第十，勇猛最，摧伏九十六种外道。这是十最，也就是经中的十种第一。

十种胜：

第一，力胜，具足十力。第二，无畏胜，具足四无畏。第三，不共胜，具足十八不共法。第四，道品胜，具足三十七道品。第五，变化胜，具足百千种变化。第六，言音胜，具足八十八种梵音。第七，端严胜，具足三十二种大丈夫相。第八，吉祥胜，随所作境界之处，出生增长功德善根。第九，难得胜，在三界中独一至尊。第十，住处胜，所居宫殿以九万八千种微妙圆满来庄严。这是十胜，也就是经中的十种殊胜。

十种业：

第一，自然业，所作自在。第二，平等业，教化利益没有差别。第三，相应业，随机出现。第四，具足业，圆满福德与智慧两种资粮。第五，无尽业，没有边际。第六，同生业，随六趣受生。第七，无著业，远离尘累，如莲花一样。第八，依止业，作众生的归依之处，如大地一样。第九，无厌业，摄受众生无穷无尽，如大海一样。第十，通达业，没有障碍，如虚空一样。这是十业，也就是经中的十种作用。

十种遍：

第一，根遍，佛的诸色根，每一根都周遍法界。第二，识遍，佛的诸心识无所不达。第三，境界遍，圆满之智所缘没有界限。第四，寿命遍，不可思议。第五，眷属遍，不可测量。第六，功德遍，每一功德都等同虚空界。第七，慈悲遍，没有拣择。第八，言说遍，佛的言音无所不至。第九，证遍，无所不穷。第十，无等遍，无与伦比。这是十遍，也就是经中的十种周遍。

四种智：

第一，光明无尽藏智，能出生十亿一千种智慧之门。第二，一味一相智，通达恒沙一切诸法没有差别。第三，大悲无边智，随起一个化身，遍满十方一切世界。第四，无为寂灭智，远离一切起动作业。这是四智，也就是经中的四种圆满智。

四无碍：

第一，法无碍，了知诸法的实相实性。第二，义无碍，了知诸法的共相、差别相和生灭相。第三，辞无碍，不坏假名而说实相。第四，乐说无碍，发出无边言说，如契经之海次第不断。这是四无碍，也就是经中的四种解脱智。

自在一词，通于以上一切，所以不另外解释。色相的名称和意义，如《大总持》中广说。

### 归敬法宝与僧宝

已经说了佛宝，下面说法宝和僧宝。

本论：

```
及彼身体相，法性真如海，
无量功德藏，如实修行等。
```

（大意：以一切众生之身，归依佛身的体相、法性真如之海、无量功德之藏，以及如实修行的圣众。）

论中说：这一颂也有两门：一是体摄一切众身门，二是总达法藏僧伽门。

体摄门，是尽摄一切无量众生生灭流转的无常之身，所以本论说彼身体相。总达门，是以这样的众身，总归于一切甚深法藏和一切如实修行的圣者，所以本论说法性真如海、无量功德藏、如实修行。等字，总通致敬之意。

论师依多少法宝和僧宝而致敬？其相如何？颂说：

```
总归于十四，僧十法四故，
或兼上下故，有多类僧众。
```

（大意：总共归依十四处：僧宝十种，法宝四种；又因兼摄上下位次，所以僧众有多类。）

论中说：马鸣菩萨总共归依十四种功德之处，因为僧有十种、法有四种的差别。十种僧，是十地的差别。四种法，是教、理、行、果的差别。

法，指教法，也就是随顺众生根机的一切契经之海。性真如，指理法，在一切法上体性平等，离开虚妄的假，也绝离执著的实。海，指果法，在妙觉果位上万德圆满，无有穷尽，犹如大海。无量功德藏，指行法，六度万行的清净眷属不可思议，超过数量。如，指十种真如；实修行，指十种正智。证得真如之理，依真实之智建立僧名。理与智和合相通，能证与所证一味平等，平等而无诤论。

问：为什么以命来标示十方？

答：为了显示所摄的命根广大圆满，没有边际。

问：为什么以身来标示体相？

答：为了显示被生住异灭四相所扰乱的一切众生都被摄取，想让他们获得金刚常住不动之身。

问：为什么论师不只归依自己的身命，而是通取一切无量众生的身命归依三宝？

答：因为明了知道一切众生平等平等，唯一真如，没有差别，众生的身命和自己的身命一味一相，不相分离。所以颂中说等，等字极为甚深。

问：为什么摄取一切众生的无量身命，归依三宝而致敬？

答：因为这样，十方三世一切诸佛都欢喜，十方三世一切菩萨都赞叹，十方三世一切法藏常恒流布，不会断绝。

问：马鸣菩萨证得不动地，下地的功德都已圆满，为什么下位的僧众也都致敬？

答：因为能归依的人，不都和他自己同一位次。如果只论他自己的归依，只应礼敬不动地满心和以上二地。

问：那么为什么不取地前的僧众？

答：并不是没有地前的归依者，只是不另外列举，以上兼下，影略显示。

问：法云地菩萨作为能归依的人时，应当依什么僧？

答：在妙觉地有真实僧，所以没有过失。

问：那么为什么不另外列举？

答：以下兼上，影略显示。所以颂说或兼上下，故有多类僧众。

## 七、造论的本趣

已经说了法宝和僧宝，下面说本趣。

本论：

```
为欲令众生，除疑舍邪执，
起大乘正信，佛种不断故。
```

（大意：为了让众生除去疑惑、舍弃邪执，生起大乘正信，使佛种不断。）

论中说：这一颂有两门：一是断绝障缚门，二是连续解脱门。

断绝门有四种差别。

第一，决定信心门：为了让一切无量众生断除疑惑之心，发起坚固之信，对甚深大乘正道生起决定。

第二，远离舍心门：为了让一切无量众生远离厌舍之心，增长欲乐之意，精进于甚深大乘正道。

第三，对治邪论门：为了对治九十六种大外道和九万三千眷属外道、四种大魔和三万二千眷属魔众，断除一亿四万六千种世间之论，趣入大乘甚深正道。

第四，除遣执著门：为了让一切无量凡夫、一切二乘、一切菩萨，断除五种人见，证得五种对治；断除两种法执，证得两种对治，回向甚深大乘正道。

这就是本论所说的为欲令众生除疑舍邪执，起大乘正信。

连续门有三种差别。

第一，不断大觉门：为了集成万行之因，庄严大觉之果，使无上法王不断绝。

第二，不断法藏门：为了出现殊胜微妙的梵音，宣说一切契经之海，使八万四千法藏不断绝。

第三，不断僧伽门：为了修习地前地上的大道，建立真如法界的宫殿，使正位僧和后位僧住世而不断绝。

这就是本论所说的佛种不断故。

颂中众生一词，范围如何？为了对治哪些断绝，而建立三宝不断？颂说：

```
通摄三聚人，未得圆满故，
对四种断故，建立三不断。
```

（大意：众生通摄三聚之人，因为都还没有得到圆满；为了对治四种断，建立三宝不断。）

论中说：马鸣菩萨通以三聚众生为所缘境界，因为他们都还没有证得圆满之果。三聚的分法有三种。

第一种：十信以前名为邪定聚，因为不能相信业果报应。三贤和十圣名为正定聚，因为已经决定安立于不退之位。十种信心名为不定聚，因为或进或退，还没有决定。

第二种：十信以前加上十信，名为邪定聚，因为都没有善根。无上大觉果名为正定聚，因为已经圆满。三贤和十圣名为不定聚，因为都还没有究竟。

第三种：十信以前名为邪定聚，因为没有乐求之心。十圣名为正定聚，因为已经得到真证。十信和三贤名为不定聚，因为还没有得到正证。

马鸣菩萨取第一种分法。为了对治四种断，建立三宝不断的意义。四种断是：

第一，疑惑断：因为犹豫之心不能决定，断了三宝的种子。第二，厌舍断：因为贪爱三有之心不能乐法，断了三宝的种子。第三，见邪断：因为妄想之心不能正见，断了三宝的种子。第四，定执断：因为执实有之心不能离著，断了三宝的种子。

## 八、总体

已经说了本趣，下面开示总体。

本论：有一种法，能生起对大乘的信根，所以应当宣说。

论中说：这段文有两门：一是能入门，二是所入门。能入门，是对所诠之理善能趣入。所入门，是善为彼法作依止。

有法，总标十六种能入的门法。能起信根，总标门法的作用。摩诃衍，总标十六种所入的法体，以及不二摩诃衍之体。

信是决定前进之心，根是生长修行之法。若要趣入真理，没有超过这两者的，所以说信根。

又，信指十信，根指从初发心住乃至法云地。为什么？初信没有根，随缘进退，譬如班多伽伊摩华；后来的信转胜坚固，不动摇，譬如键鸠阿弥礼树。

信和根各有多少含义？各自的相状如何？颂说：

```
各有十种义，澄净下转等。
```

（大意：信与根各有十种含义，信以澄净为首，根以下转为首。）

论中说：信有十种含义：

第一，澄净义，能令心性清净明白。第二，决定义，能令心性淳厚坚固。第三，欢喜义，能断除种种忧恼。第四，无厌义，能断除懈怠之心。第五，随喜义，对他人的殊胜修行生起同喜之心。第六，尊重义，对有德之人不轻贱。第七，随顺义，对所见所闻不违逆。第八，赞叹义，随他人的殊胜修行至心称赞。第九，不坏义，安住专一之心，不会忘失。第十，爱乐义，能令成就慈悲之心。

根有十种含义：

第一，下转义，能除憍慢。第二，隐密义，能诠显甚深之理。第三，出生义，生长种种功德。第四，坚固义，全部摄持，不会缺失。第五，相续义，辗转增长，没有断绝。第六，出离义，一地比一地殊胜，渐渐远离。第七，集成义，修集种种道品之法。第八，茂荣义，以种种修行的功德来庄严，非常可爱。第九，具足义，在等觉位中圆满因行。第十，高胜义，在妙觉果位上最胜广大，无能超过。

能入与所入的种种差别，在立义分中自然会显说。

## 九、五分的建立

已经说了总体，下面说明建立。

本论：说有五分：一是因缘分，二是立义分，三是解释分，四是修行信心分，五是劝修利益分。

论中说：为什么次第是这样？因为教法的出现，法尔如此。

这是什么意思？上味妙药，一定是针对所要对治的疾病而出现；能化的教法，一定是因所要教化的根机而发起。病之前没有药，根机之前没有教。所以先立因缘分。

如意宝珠虽然只有一颗，却是一切宝物的根本；大乘法虽然只是一体，却是恒沙法门的体性，只有威德重大的大龙才能受用，只有利根智者才能领解。所以第二立立义分。

摩尼宝藏虽然具备无量万宝，但要打开千重之门，群龙才能知道；大乘本法虽然圆满无边千义，但要分别散说解释，钝根人才能明白。所以第三立解释分。

虽然眼耳中见闻了宝雨的妙术，心中理解了无尽的圆满功德，但如果不能真正去做，入门的路就不通，往趣的路就不近，那道隔碍就打不开，即使得到如意宝藏，也无从登上宫殿。虽然口中诵持教义的尊贵言辞，心中观察广略的深理，但如果不勤加修行，增长胜进，就不能在金刚般坚固的信心上站稳，即使得到法界宝藏，也无从契入玄理。所以第四立修行信心分。

虽然开示了广略之法，指明了进入之门，但怯弱的众生听到广说的法门，不堪进修；钝根的众生听到略说的法门，不能理解，因此生起厌离之心。这样的众生，如果遇到劝请的因缘，就会渐渐进修，具备百行之因，达到万德之果；如果得不到劝策的因缘，就会越退越远，带着恒沙烦恼，一直到无性的境地。马鸣菩萨见到这个利害，所以显示利益，劝请修行，最后立劝修利益分。

有什么因缘，不增不减只立五分？颂说：

```
摄彼大总地，五十法门故，
是故不增减，唯建立五分。
```

（大意：因为摄取《大总地论》的五十法门，所以不增不减，只立五分。）

论中说：马鸣菩萨在十万颂的《大总地论》中，总共立了五十门来判释诸教理。现在这部论中的五分法门，各摄彼论的十门，所以不增不减，只立五分。彼论中所化圆满等十门，属于因缘分；百六十摩诃衍等十门，属于立义分；安立随顺抉择等十门，属于解释分；修习决定趣入等十门，属于修行分；劝请、呵责、引导等十门，属于劝修分。

## 十、因缘分：八种因缘

已经说了建立门，下面说唱章判说门。

本论：先说因缘分。问：因为什么因缘而造此论？答：因缘有八种。第一是因缘总相，就是为了让众生离一切苦、得究竟乐，不是为了求世间名利恭敬。第二，为了解释如来根本之义，让众生正解不谬。第三，为了让善根成就的众生，对大乘法能够承担而信心不退。第四，为了让善根微少的众生修习信心。第五，为了开示方便，消除恶业障，善护其心，远离痴慢，走出邪网。第六，为了开示修习止观，对治凡夫二乘的心过。第七，为了开示专念的方便，往生佛前，必定信心不退。第八，为了开示利益，劝人修行。有这些因缘，所以造论。

论中说：这八种因缘中，第一种是立义分的正因缘，第二、三种是解释分的正因缘，第四至第七种是修行信心分的正因缘，第八种是劝修利益分的正因缘。

第一种因缘中有四门，后七种因缘中各有三门。四门是：一、能化教法出兴门，二、所化众生分际门，三、出兴作业善巧门，四、除遣诤论诽谤门。三门就是前三门。下面依次解释。

### 第一因缘

因缘总相，是总举能化教法出兴门。这是为八种根本总体作正因缘，所以说因缘；总为二十四种分离别相作正因缘，所以说因缘相。三十二种总别法相，在立义分中自然显说。

为令众生，是总举所化众生分际门。摄邪定聚十亿八万六千种众生、不定聚三十种众生、正定聚一百二十种众生。

离一切苦得究竟乐，是总举出兴作业善巧门。以三聚众生为所缘境界，宣说开示妙法要义，要让一切无量众生远离生灭无常之苦，获得根本总相之乐。

非求世间名利恭敬故，是总举除遣诤论诽谤门。愚痴的众生会这样怀疑：马鸣菩萨位居不动地，还没到法云地，却把上地菩萨也当作所化的境界，这只是显示自己殊胜，求名利而已，有虚言而无实义，哪有下地菩萨教化上地菩萨的？所以马鸣为了遣除这种不信之疑，自己说明：我在久远劫前已经成就正觉，现在是助佛教化利益众生，为了满足本愿而权且示现修行的位次，并不是为了求名利才这样说。

### 第二因缘

解释如来根本之义，是总举能化教法出兴门。这个因缘是显示正义、对治邪执的正因缘，所以说如来根本之义。为什么？十方三世一切如来，没有一佛不是依根本一心、二门、七种对治而成正觉的。

令诸众生，是总举所化众生分际门，摄十亿八万六千种邪定聚众生。

正解不谬故，是总举出兴作业善巧门。以邪定聚中狂乱的众生为所缘境界，宣说开演显示正义、对治邪执的甚深之法，纠正恒沙般的谬误邪解，摧破尘数般的逆乱之见，断除一阐提不信之障，让他们趣入十信大道。

### 第三因缘

第三因缘是分别发趣道相的正因缘，这是能化教法出兴门，指三种发心。

善根成就众生，是总举所化众生分际门，摄上品十信、三品十解、三品十行、三品十向、三品十地的众生。

于摩诃衍法堪任不退信心故，是总举出兴作业善巧门。以这两聚众生为所缘境界，宣说开示三种发心，让他们超过自己的现位，获得胜进。

### 第四因缘

第四因缘是修行信心分中四种信心、四种修行的正因缘，这是能化教法出兴门。

善根微少众生，是总举所化众生分际门，摄已得十信位前五心的中品众生。已得前五心，所以不是毫无善根，称为微少；还没得后五心，不能具足，所以不称成就。

修习信心故，是总举出兴作业善巧门，为了让他们成就后五种信心。

### 第五因缘

第五因缘是修行信心分中进门末段的正因缘，也就是从复次若人虽修行信心，到得免诸障、善根增长故那一段，这是能化教法出兴门。这里的众生，摄十信位初心的下品众生，这是所化众生分际门。消恶业障等，是总举出兴作业善巧门，开示礼拜、忏悔等方便，消除种种业障之海。

### 第六因缘

修习止观，是总举能化教法出兴门，为修行信心分中修行止观门作正因缘。凡夫二乘，是总举所化众生分际门，摄十信位二心的下品众生，以及邪定聚所摄的一切二乘。对治心过，是总举出兴作业善巧门，以止观两轮通对治凡夫和二乘的见执过失。

### 第七因缘

第七因缘是修行信心分末段的正因缘，也就是从复次众生初学是法，到毕竟得生住正定聚那一段，这是能化教法出兴门。这里的众生，摄十信位前四心中不能再胜进的下品众生，他们住在这个世界，对信心成就极为怖畏，这是所化众生分际门。必定不退信心故，是总举出兴作业善巧门，以殊胜的外缘之力，把他们安立于正定聚。

### 第八因缘

第八因缘是劝修利益分的正因缘，这是能化教法出兴门。这里的众生，摄十亿八万六千种邪定聚众生，这是所化众生分际门。为示利益劝修行故，是总举出兴作业善巧门，宣说功德，增长欲乐，显示过患，令人觉悟厌离。

### 关于八因缘的几个问答

问：一切教法都已在立义分中说尽，一切所化之机都已在第一因缘中说尽，为什么又开三分来别释，立七种因缘来散说？

答：为了显示利钝、广略、总别各有不同。

问：为什么二乘人要在四处重复摄取？

答：为了显示二乘众生下劣狭小，发菩提心趣向无上道极其艰难，超过其余众生。

问：为什么其余的邪定众生只在三处摄取？

答：为了显示其余众生比起二乘，过失较轻。

问：为什么不定聚的人要分三品摄取？

答：为了显示不定聚众生微薄暗钝，发决定心趣向无上道极其艰难，超过正定聚众生。

问：为什么正定聚的人不分三品，只是总摄？

答：为了显示正定聚众生比起不定聚，过失较轻。

问：有什么因缘，不增不减只立八种？为什么次第是这样？颂说：

```
总摄大总地，八十因缘故，
修行转胜法，次第如是故。
```

（大意：因为总摄《大总地论》的八十种因缘，所以只立八种；修行转胜之法，次第自然如此。）

论中说：马鸣菩萨在十万颂的《大总地论》中，总共立了八十种因缘作为造论的缘由。现在这部论中的八种因缘，各摄彼论的十种因缘，所以不增不减只立八种。本论说如是等，等字就是总摄那八十种。

因缘的次第，是修行之法本来如此：除去阐提不信之障，得十信心；除去执著我的障碍，得十住心；除去畏苦之障，得十行心；除去舍离之障，得十向心；断除凡夫性等十种障，证得欢喜地等十地。

## 十一、四种根机

已经说了八种因缘，下面说四种根。

本论：问：经中已经具有此法，何必重说？答：经中虽有此法，但众生的根器和修行不同，接受和理解的因缘也不一样。如来在世时，众生根利，说法者身心业胜，圆音一演，异类等解，就不需要论。如来灭后，有的众生能以自力广闻而得解，有的众生也以自力少闻而多解，有的众生没有自力，依靠广论才能得解，还有的众生嫌广论文多为烦，心乐以少文摄多义的总持而能得解。所以这部论，是为了总摄如来广大深法的无边之义，应当宣说。

论中说：这段文有两门：一是所说无异难问门，二是举时分位决疑门。

问曰修多罗中具有此法何须重说，是难问门。意思是：《光明大觉经》等一百部契经中，已经开示了一切无量法藏，随根机的分量摄取利益，没有缺失。中等之士何必费心造这部论，重传彼法，又没有更加显明的力量？现在造论重说彼法，难道不是在求称赞之类的事吗？这样终究不能使人尊信。这是所说无异难问门。

答曰修多罗中虽有此法，以众生根行不等，受解缘别，是总举决疑门。马鸣自己说明：三世诸佛的一切教理，自然常住，一味平等，没有移转，没有起灭。所以经题论名虽有差别，文字不同，但教法唯是一味，唯是平等，不可分别。然而众生的根性有差别，利钝不同，心行有差别，广略不同。所化的根机既然不同，能化的人就不能一样，所以让众生所受的教法名字各别，理解文义的因缘各别。也就是说，有的众生依佛的伽陀修多罗而得解，有的众生要依菩萨所造的论才能得解，所以为这些人必须造论。

再者，如来在世时，所化的众生清净，能化的佛陀圆满：八万四千种色相、四种心遍智、十种作业、十种殊胜、六十八种梵圆、八十八种妙音，没有前后，同时敷演，无量无边的种种异类众生，有的见佛妙色而得解，有的思惟佛的心品而得解，有的观察如来十业十胜而得解，有的听闻佛的圆满梵音而得解。这样平等明了通达，就不需要论。

佛灭度后，所化的众生杂乱，能化的人有所欠缺，经与论所对的根机不同，广与略所对的根器有别。根，指四种根；机，指三乘之机。

四种根是：一、广自力根，二、略自力根，三、广无力依他根，四、略无力依他根。这四种根性中，前两种是依经的众生，后两种是依论的众生。

问：为什么在因缘门中所化众生圆满，在根性门中所化众生微少？

答：为了显示清净的誓愿和意乐没有边际，也为了显示真正受教实行的众生有其分际。

以什么因缘出现广略两重教法？其相如何？颂说：

```
本愿系属故，出兴此法门，
楞伽王契经，分明显说故。
```

（大意：因为师徒本愿相系，才出现这两重法门，《楞伽王契经》中有明白的记载。）

论中说：因为本愿相系的因缘之力，出现两重甚深法门。为什么这样说？因为契经中有明白的记载。

《楞伽王契经》中说：那时世尊告诉文殊师利：我回忆过去无量劫，曾有五百世作忍辱仙人，在山林中专心修行少欲知足的四圣种清净之法。那时有一条大蛇从山顶下来，到我这里，听我诵经，就投身礼拜忏悔。投身之后，用头叩地，恳切地作偈说：

```
我过去世，忍辱仙人，住于此山，
六时行道。而一时嗔，因缘力故，
今得蛇身，常受大苦。若命终后，
得人同分，我当弟子，随汝修行。
汝所读诵，常我所诵，是故我今，
发大惭愧。
```

（大意：我过去世也是忍辱仙人，住在这座山中，昼夜六时修行。只因一时起嗔，因缘之力，今生得了蛇身，常受大苦。若命终之后得生为人，我愿作你的弟子，随你修行。你所读诵的，正是我从前常诵的，所以我今生起大惭愧。）

说完此偈就命终了，后来得了人身，成为我的弟子。那时我们互相发愿系属。我发愿说：我若证得无上道，宣说九十洛叉的广说修多罗，利益意乐广大的众生；宣说十洛叉的略说修多罗，利益意乐总持的众生。我的弟子发愿说：我当在师父灭度后，造九十部广说的论，利益意乐广大的众生；造十部略说的论，利益意乐总持的众生。因为这个因缘，我现在宣说种种契经之海；因为这个因缘，我灭度后，我的弟子会造论教化。

## 十二、立义分：三十三种法门

已经说了因缘分，下面说立义分。立义分中的法门名称有多少？其相如何？颂说：

```
有三十三种，十六所入法，
十六能入门，及不二别故。
```

（大意：立义分共有三十三种法门：十六种所入之法，十六种能入之门，加上一种不二摩诃衍。）

论中说：立义分中的法门共有三十三种差别：十六种所入本法、十六种能入门，以及不二摩诃衍。

为什么摩诃衍成为十六种？根本摩诃衍中开为八种，一心法界与三大义中又各开为两种。为什么能入门成为十六种？一心法界与三大义各有两种，或者说各开两种门。这是本数。

### 本论原文

已经说了法数，下面分别解释。

本论：摩诃衍总说有两种：一是法，二是义。所说的法，就是众生心，这颗心总摄一切世间法和出世间法，依于此心显示摩诃衍的含义。为什么？这颗心的真如相，直接显示摩诃衍的体；这颗心的生灭因缘相，能显示摩诃衍自身的体、相、用。所说的义有三种：一是体大，一切法真如平等，不增不减；二是相大，如来藏具足无量的本性功德；三是用大，能生一切世间出世间的善因果。因为一切诸佛本来乘此，一切菩萨都乘此法到达如来地。

论中说：这段文有三门：一是所入根本总体门，二是能依趣入别相门，三是通达轨则不动门。前两门各有两重，应当安住思考，仔细观察。

### 第一重：根本摩诃衍八种

摩诃衍者总，就是所入根本总体门。根本摩诃衍中有八种差别：

第一，一体一心摩诃衍。第二，三自一心摩诃衍。第三，无量无边诸法差别不增不减体大摩诃衍。第四，寂静无杂一味平等不增不减体大摩诃衍。第五，如来藏功德相大摩诃衍。第六，具足性功德相大摩诃衍。第七，能生一切世间因果用大摩诃衍。第八，能生一切出世间善因果用大摩诃衍。

这八种摩诃衍法，都是从能入之门来立名。以一体一心为门所趣入的，叫作一体一心摩诃衍；乃至以能生一切出世间善因果用大为门所趣入的，叫作能生一切出世间善因果用大摩诃衍。譬如转轮圣王，随其轮宝的相状来立名；摩诃衍法也是这样，随其门相来立名。

《大觉契经》中说：佛告诉文殊师利：仔细听，好好思念，我当为你分别开说八种身法：一、一体趣入身法，二、三自趣入身法，三、诸法差别不增不减体大趣入身法，四、纯净一相无杂不增不减体大趣入身法，五、如来藏功德显了大趣入身法，六、圆满性功德显了大趣入身法，七、出生世间因果自在无碍大趣入身法，八、出生出世间妙因果自在无碍大趣入身法。

马鸣菩萨正是摄取这段经文，所以说摩诃衍者总。这个总字，在上下两处都是总体：上望根本，下临诸门。《大总地论》中开八十门广释根本摩诃衍法，现在各摄十门成一种，所以只立八法。

为什么知道有八种？因为能入的别相有八种，所以知道所入的总体也有八种。能入与所入这八种法相，胜劣广狭如何？颂说：

```
平等平等一，皆无有别异，
各摄诸法故，然终不杂乱。
```

（大意：这些法相平等平等，同为一体，没有差别，因为各自都摄尽诸法；然而终究不相杂乱。）

论中说：这能入与所入的十六种法相，遍满遍满，平等平等，一味一相，没有差别。为什么？因为各自都摄尽诸法。

问：如果这样，本与末、总与别岂不全都混同，应当杂乱？

答：本末终究不相杂乱，总别之门初后都有，然而各各都同等，所以叫平等，并不是说只有一个法才称为平等。

### 第二重：一心与二门

已经说了第一重。第二重的四种法中，各有三门：一是本法所依决定门，二是根本摄末分际门，三是建立二种摩诃衍门。

所言法者谓众生心，就是本法所依决定门。现在用总持之颂来显说，其相如何？颂说：

```
众谓四衍众，生谓四种生，
是一法界藏，遍于彼八处。
```

（大意：众，指四类圣众；生，指四种生。这就是一法界藏，周遍于前面八处。）

论中说：众有四种：一切如来众、一切菩萨众、一切声闻众、一切缘觉众。生有四种：卵生、胎生、湿生、化生。超过数量所以叫众，受生所以叫生。

这一法界心，在前面八处中周遍圆满，不可分析，不可离散，唯是一体，唯是一相。以四种众摄尽诸圣，以四种生摄尽诸凡，马鸣论师为了显示一心广大圆满，所以名为众生。

《顺理契经》中说：那时世尊放大光明，显现神力之后，告诉佛子说：仔细听，好好思念，我当为你分别解说一法界藏。善男子，一法界藏，遍于诸如来众、诸菩萨众、诸声闻众、诸缘觉众及诸凡夫，无所不通，无所不至，无所不当，所以名为一法界藏。

论主摄取这段经文，所以名为众生。马鸣菩萨在六万颂的《本藏论》中，开十种门别释散说，这里简略摄取，所以只说众生。

按：众生心的众生，在这里不是凡夫的意思，而是上摄诸佛菩萨、下摄四生的一法界心。大乘不在凡夫心外，也不在诸佛心外，就是这一颗心周遍于凡圣。

已经说了本法所依决定门。是心即摄一切世间法出世间法，就是根本摄末分际门。其相如何？颂说：

```
是一法界心，总摄二种门，
名摄世出世，作法界名法。
```

（大意：这一法界心总摄二门，所以说摄世间与出世间法；一切都作为法界，所以称为法。）

论中说：一法界心总摄一切生灭门的法，所以说摄世间法；总摄一切真如门的法，所以说摄出世间法。都作为法界，所以称为法。

《自体契经》中说：广大神王摄一切种种无明、一切种种染法、一切种种清白之法；又摄一切清净法、一切无碍法、一切解脱法、一切绝离法、一切满足法、一切寂静法。然而广大神王本身，不是世间法，也不是出世间法。

论主摄取这段经文，所以说摄。马鸣菩萨在八万颂的《归宗论》中，开二十门分明显说，这里简略，只说到这里。

按：广大神王比喻一心。一心能摄世间法和出世间法，一心本身却不落在世间、出世间任何一边。能摄而不属，正是下文两门不相离的根据。

已经说了根本摄末分际门。依于此心显示摩诃衍义等，就是建立二种摩诃衍门。其相如何？颂说：

```
总标二种门，言依于此心，
总标二本法，显示摩诃衍。
```

（大意：依于此心一句，总标两种能入之门；显示摩诃衍一句，总标两种所入本法。）

论中说：依于此心，总标能入的两种门；显示摩诃衍义，总标所入的两种法。

两种门是：心真如门、心生灭门。两种本法是：一体摩诃衍、自体自相自用摩诃衍。这两种所入本法，也是从能入之门立名：以真如之体为门所趣入的，名为体；以自相本觉之心为门所趣入的，名为自。因为能入之门有两种区别，所以知道所入本法也有两种。

何以故，是请问之辞：凭什么意义说依于此心一句中具有两种门，显示摩诃衍义一句中具有两种本法？

回答：作为一法界心的真如门，就显示一体摩诃衍法；作为一法界心的生灭门，能显示自体自相自用摩诃衍法。因此应当知道，各具两门两法。

《大觉契经》中说：再者，文殊师利，有两种法，甚深微妙，不可思议：一是体相平等摩诃衍，二是自相自然摩诃衍。若想证得这两种法，应当行两种门：一是无断无缚门，二是有断有缚门。

论主摄取这段经文，所以这样说。《大总地论》中开八种门分明散说。

### 三大的能入所入

已经说了建立二种摩诃衍门。三大义中，各省略前两门，只立后一门，这是马鸣菩萨的本意，举后摄前，所以只说到这里。

再者，前面次第分明显了，以上两颂的本文应当至此。

一者体大，总标所入的两种本法：一是无量无边诸法差别不增不减摩诃衍，二是寂静无杂一味平等不增不减摩诃衍。谓一切法真如平等不增不减故，总标能入的两种别门，门名与本法名相同。

二者相大，总标所入的两种本法：一是如来藏功德摩诃衍，二是具足性功德摩诃衍。所谓如来藏具足无量性功德故，总标能入的两种别门，门名与本法名相同。

三者用大，总标所入的两种本法：一是能生一切世间因果摩诃衍，二是能生一切出世间善因果摩诃衍。谓能生一切世间出世间善因果故，总标能入的两种别门，门名与本法名相同。

三大义的分别解释，如《总地论·本地品》中分明显说。

### 不二摩诃衍

问：为什么不二摩诃衍法没有因缘？

答：此法极妙，甚深独尊，离开根机。

问：为什么离开根机？

答：因为没有根机。

问：那何必建立？

答：因为它本不是建立出来的。

问：这个摩诃衍法是诸佛所得的吗？

能得于诸佛，诸佛得不故，菩萨二乘一切异生亦复如是，性德圆满海是焉。（大意：不二摩诃衍能得诸佛，诸佛却得不到它；菩萨、二乘、一切凡夫也是如此。这就是性德圆满之海。）

为什么？因为离开根机，离开教说。

问：为什么八种本法从因缘而起？

答：因为应于根机，顺于教说。

问：为什么应于根机？

答：因为有根机。

问：这八种本法是诸佛所得的吗？

答：是诸佛所得。对诸佛来说是可得的，菩萨、二乘、一切凡夫也是如此。这是修行种因之海。为什么？因为有根机，有教说。

按：这是本论最深的一个判摄。三十二种法门都有根机、有教说，是可以修、可以得的修行种因之海；唯独不二摩诃衍离开根机、离开教说，诸佛也得不到它，因为它不是被得的对象，而是能得诸佛的本身。凡夫也得不到它，同样的道理，它从来不在能得所得之中。

### 体与自的名称

问：为什么依真如门所趣入的摩诃衍法只立体名，依生灭门所趣入的摩诃衍法立自名？

答：真如门中没有他相，生灭门中有他相。他，指一切不善品法；自，指一切清净品法。如果所对治的他没有，能对治的自也没有，所以只说体，不说自。如果所对治的他有，能对治的自也有，所以称自，不只说体。

又，为了显示一法界体平等平等，没有偏私，无量性德自然本有，不是靠他力而得。

又，这是随宜安立，没有定准。

问：为什么在别说门中，一心单独作为一项，三大却总为一项，而两者同样各诠两种摩诃衍？

答：三大义合起来，才能诠两种摩诃衍。大义之名通于三种，所以总为一义，没有别的意趣。

现在所开示的十六法门，胜劣广狭如何？颂说：

```
平等平等一，皆无有别异，
各摄诸法故，然终不杂乱。
```

（大意：十六法门平等平等，同为一体，没有差别，因为各自都摄尽诸法；然而终究不相杂乱。）

论中说：能入与所入的十六法门，圆满圆满，平等平等，周遍法界，没有差别。为什么？因为各自都摄尽诸法。然而本末能所终究不相杂乱。

### 通达轨则不动门

已经说了总别二门。一切诸佛本所乘故，一切菩萨皆乘此法到如来地故，就是通达轨则不动门。

微尘数的过去诸佛、微尘数的现在诸佛、微尘数的未来诸佛，都乘这三十二种甚深安稳之车，到达清净无上之地。十方三世一切菩萨也是如此。

这里说的菩萨，通取三聚一切众生。为什么？因为没有一个众生不能通达如来地。

按：三十三种法门减去不二摩诃衍，正好是三十二种车。不二摩诃衍不是车，它是车所行驶的大地，也是车所到达的那个地方本身。卷末一句没有一个众生不能通达如来地，是把邪定聚也收进来了。
