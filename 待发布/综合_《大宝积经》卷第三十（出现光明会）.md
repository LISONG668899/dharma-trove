# 《大宝积经》卷第三十（出现光明会）

唐·三藏菩提流志 奉诏译

## 出现光明会第十一之一

【按】本会未见汉译异本对勘。本卷除开头一段外，全为世尊所说偈颂，依颂意分段，各附大意。

### 月光童子问光明因缘

如是我闻：一时，佛在王舍城耆阇崛山，与大比丘众五百人在一起，他们都已得大自在；又有八十那由他菩萨摩诃萨，都是一生补处，以弥勒菩萨为上首；又有四十那由他诸大菩萨，以文殊师利法王子等为上首。

【按】“第一十一”，宋、元、明本作“第十一”。

那时会中有一位童子，名叫月光，即从座起，偏袒右肩，右膝着地，顶礼佛足，合掌恭敬，对佛说：“世尊！如来往昔修什么业，能得到这样的光明：决定光明、摄取光明、发起光明、显现光明、种种色光明、无杂色光明、狭小光明、广大光明、清净光明、遍清净光明、无垢光明、极无垢光明、离垢光明、渐增长光明、鲜净光明、极鲜净光明、无边光明、极无边光明、无量光明、极无量光明、无数量光明、极无数量光明、速疾光明、极速疾光明、无住光明、无处光明、炽盛光明、照耀光明、爱乐光明、到彼岸光明、无能障光明、不动光明、正直光明、住无边处光明、色相光明、种种色相光明、无量色相光明、青黄赤白色相光明、红色相光明、颇梨色相光明、虚空色相光明——这样种种光明，每一种都与五色光明和合显现，乃至青黄赤白等，每一种也与无量无边种种色光和合显现？”

【按】“颇梨”，宋、元、明、宫本作“玻璃”。

### 世尊说偈答

那时，世尊就为月光说偈道：

#### 光由无作慧现

```
我以不思议，善业因缘故，
远离诸迷惑，成就种种光。
复以种种行，安住于佛道，
以空无作慧，而现和合光。
譬如外法中，种种相差别，
于中空无我，无作无心意。
又如内身中，空无我无作，
于中能示现，种种诸音声。
由如是无作，现无边色光，
随其所意乐，皆令得满足。
```
（大意：我以不可思议的善业因缘，远离诸迷惑，成就种种光明；又以种种修行安住于佛道，以空、无作的智慧，显现和合之光。譬如外在诸法中有种种相的差别，而其中空、无我，无作也无心意；又如自身之内，空、无我、无作，而其中能显示种种音声。由这样的无作，显现无边色光，随众生的意乐，都令他们得到满足。）

#### 一光出多色及其因

```
或于一光中，出生二种色，
各有上中下，差别而显现。
或于一光中，出生三种色，
各有上中下，差别而显现。
或于一光中，出生四种色，
各有上中下，差别而显现。
或于一光中，出生五种色，
各有上中下，从于净业生。
或于一光中，出生六种色，
各有上中下，从于方便生。
或于一光中，出生七种色，
各有上中下，从于善业生。
或于一光中，出生八种色，
各有上中下，从于胜善生。
或于一光中，出生九种色，
各有上中下，从于资粮生。
或于一光中，出生十种色，
各有上中下，从于布施生。
```
（大意：或在一道光中出生二种色、三种色、四种色，各有上、中、下的差别而显现；或在一道光中出生五种色，各有上中下，从清净之业而生；出生六种色，从方便而生；出生七种色，从善业而生；出生八种色，从殊胜的善而生；出生九种色，从资粮而生；出生十种色，从布施而生。）

```

或于一事中，出生三十色，
各有上中下，从于忍辱生。
或于一事中，出生四十色，
各有上中下，从于精进生。

各有上中下，从于禅定生。
或于一事中，出生六十色，

或于一事中，出生九十色，
各有上中下，从于喜心生。
或于一事中，出生百种色，
各有上中下，从于舍心生。

各有上中下，从千功德生。
或于一事中，出生万种色，

```
（大意：或在一事中出生二十种色，各有上中下，从持戒而生；三十种色，从忍辱而生；四十种色，从精进而生；五十种色，从禅定而生；六十种色，从智慧而生；七十种色，从慈心而生；八十种色，从悲心而生；九十种色，从喜心而生；一百种色，从舍心而生；一千种色，从千种功德而生；一万种色，从福德资粮而生。）

```

各有上中下，从于净信生。
或于一事中，现二俱胝色，
各有上中下，从于随喜生。
或于一事中，现三俱胝色，

各有上中下，从尊重僧生。
或于一事中，现七俱胝色，
各有上中下，从尊重戒生。
或于一事中，现八俱胝色，
各有上中下，从尊重定生。
或于一事中，现九俱胝色，
各有上中下，从普怜愍生。

```
（大意：或在一事中显现一俱胝色，各有上中下，从净信而生；二俱胝色，从随喜而生；三俱胝色，从轻安而生；四俱胝色，从尊重佛而生；五俱胝色，从尊重法而生；六俱胝色，从尊重僧而生；七俱胝色，从尊重戒而生；八俱胝色，从尊重定而生；九俱胝色，从普遍怜愍而生；十俱胝色，从无放逸而生。）

#### 毛孔诸光的名称与因

```
又从一毛孔，所现诸光明，
彼光种种名，今当为汝说。
我有一光明，名为云净照，
其光由积集，无量善根生。
以于往昔时，见有众生类，
种种多病恼，皆生怜愍心，
给施诸医药，令彼悉除愈，
以此因缘故，得如是光明。
```
（大意：又从一个毛孔所显现的诸光明，那些光的种种名称，现在当为你宣说。我有一种光明，名为云净照，这光由积集无量善根而生：因为往昔见到众生多受种种病恼，都生起怜愍之心，施给他们诸医药，令他们都痊愈，以这个因缘，得到这样的光明。）

（大意：我有光明名为念佛，为诸如来所称赞，在许多佛所修习诸行，才得以成就这样的光明。佛身所显现的诸光明，多如千俱胝佛刹的微尘之数；像这样无量俱胝佛刹，其数又如大海之沙；每一微尘数的光明，各有若干眷属；其光遍往没有佛的国土，化作如来清净之身，演说甚深微妙之法，令众生安住于忍辱之中。我有光明名为佛，令诸众生安住于佛道；名为法，清净照耀，没有瑕垢；名为僧，为诸佛如来所称叹；名为清净，其光殊胜，甚为难得；名为华，利益众生，令其成熟。我有光明名为梵，或名为帝释，或名为天，名为月、名为龙、名为夜叉、名为阿修罗、迦楼罗，或有名为王、名为妇女，或名为童女、童男；这样种种光明，各以善法教化同类，能令无量俱胝众生都成就菩提。我有光明名为智慧，或名为戒，或名为慈，或名为悲、喜，或名为灯，或号为涂香、音乐；这样一类的光明，各随其本行而得名，都摄受无量群生，由此成就这光明。我有光明名为尊重，为诸佛如来所称赞，因为对佛的教法常常恭敬，由此成就这光明。）

#### 乐声王本生

```
过去有佛，名为最胜，
彼佛住世，寿命无量。
最初成道，法会之中，
时有八十，那由他众。
尔时于此，阎浮提中，
有一国王，名为乐声。
其王复有，五百王子，
颜貌端正，见者欢喜。
是时父王，威德自在，
于三宝所，深生信乐。
其王所有，胜妙园苑，
悉皆奉施，彼佛世尊。
是园苑中，经行之处，
复有无量，薝卜迦树、
拘律陀树、甄叔迦树、
优昙钵罗、波罗波吒，
及尸利沙、无忧树等，
其数各有，八十俱胝。
如是诸树，冬夏敷荣，
华果枝叶，光色鲜茂，
出微妙香，薰如来身。
有诸比丘，身真金色，
各各皆坐，是林树下，
勇猛精进，得陀罗尼。
```
（大意：过去有佛，名为最胜，那佛住世，寿命无量。他最初成道时的法会中，有八十那由他大众。那时在这阎浮提中，有一位国王，名为乐声；那国王又有五百王子，容貌端正，见者欢喜。这时父王威德自在，对三宝深生信乐，把他所有殊胜美妙的园苑，全部奉施给那佛世尊。这园苑中经行之处，又有无量的薝卜迦树、拘律陀树、甄叔迦树、优昙钵罗树、波罗波吒树，以及尸利沙树、无忧树等，其数各有八十俱胝。这些树冬夏都开花繁茂，花果枝叶光色鲜明茂盛，散出微妙香气，熏染如来之身。有诸比丘，身作真金色，各自坐在林树之下，勇猛精进，得陀罗尼。）

```
尔时彼佛，愍其父王，
及诸王子，并余大众，
演说如是，决定光经。
其王闻已，心生欢喜，
以无量偈，称赞如来。
其王复以，八十俱胝，
微妙宝盖，奉献于佛。
一一宝盖，以摩尼珠，
于其网间，周匝严饰。
是摩尼宝，一一价直，
八十俱胝，阎浮檀金。
是一一盖，八十俱胝，
摩尼宝珠，以为璎珞。
是摩尼宝，色泽鲜净，
无有昼夜，常放光明。
一一光明，照百由旬，
其光显曜，蔽于日月。
其盖复以，八十俱胝，
师子宝带，八十俱胝，
金缕宝鬘，四面严饰。
复以种种，妙色珍奇，
间错庄严，真珠宝网。
以如是盖，周覆园苑，
其上复有，苏摩那花、
阿提目多、目真隣陀、
优昙钵罗、青莲华等，
如是种种，无量华盖，
一一皆悉，称其宝网。
复以金缕，俱吒摩衣，
以为缯盖，而覆其上。
复有金足，栴檀宝床，
其数亦有，八十俱胝。
其床复以，八十俱胝，
缯彩茵褥，而严饰之。
```
（大意：那时那佛愍念他的父王以及诸王子和其余大众，演说这样的《决定光经》。国王听后心生欢喜，以无量偈颂称赞如来。国王又以八十俱胝微妙宝盖奉献给佛：每一宝盖都以摩尼珠在网间周匝庄饰，这摩尼宝每一颗价值八十俱胝阎浮檀金；每一宝盖以八十俱胝摩尼宝珠作为璎珞；这摩尼宝色泽鲜净，无论昼夜常放光明，每一道光明照百由旬，其光明显赫，映蔽日月。那宝盖又以八十俱胝师子宝带、八十俱胝金缕宝鬘四面庄饰，又以种种妙色珍奇交错庄严真珠宝网。以这样的宝盖周遍覆盖园苑，其上又有苏摩那花、阿提目多花、目真邻陀花、优昙钵罗花、青莲花等，这样种种无量花盖，每一个都与宝网相称。又以金缕俱吒摩衣作为缯盖，覆盖其上。又有金足的栴檀宝床，其数也有八十俱胝，那床又以八十俱胝缯彩茵褥庄饰。）

【按】“决定光经”之“经”，明本作“明”。“色泽鲜净”之“净”，明本作“润”。

```
是时一切，诸众生类，
乃至有顶，皆来集会，
于如来所，听是经典，
天龙夜叉、乾闼婆王、

诸天龙神，及阿修罗，
以殷净心，雨曼陀华、
真珠等宝，而为供养。
尔时复有，八十俱胝，
大威力天，闻是经已，
心生欢喜，发菩提愿，
于未来世，得斯光明。
是时如来，知彼意乐，
即授其记，当得作佛。
尔时复有，八十俱胝，
释提桓因，并诸梵众，
闻说如是，现光经典，
亦生欢喜，发菩提心，
皆得授记，当来作佛。
尔时复有，八十俱胝，
那由他龙，闻是经已，
发菩提心，皆蒙授记。
尔时复有，八十俱胝，
金翅鸟王，闻是经已，
坚持五戒，亦授其记。
尔时复有，八十俱胝，
乾闼婆王，闻是经已，
奏千种乐，出微妙声，
供养于佛，而得授记。
复有八十，那由他数，
夜叉鬼王，闻是经已，
于佛智慧，深生净信，
一切皆得，受菩提记。
```
（大意：这时一切众生之类，乃至有顶天，都来集会，在如来所听闻这部经典。天、龙、夜叉、乾闼婆王、摩睺罗伽、阿修罗等，听了这部经后生起欢喜心，以百千偈称赞如来，一切都发起大菩提愿。诸天、龙神以及阿修罗以殷重清净之心，降下曼陀罗花、真珠等宝作为供养。那时又有八十俱胝大威力天，听了这部经后心生欢喜，发菩提愿，愿于未来世得到这样的光明；这时如来知道他们的意乐，就为他们授记，当得作佛。那时又有八十俱胝释提桓因以及诸梵众，听闻宣说这样的《现光经典》，也生欢喜，发菩提心，都得授记，将来作佛。那时又有八十俱胝那由他龙，听了这部经后发菩提心，都蒙授记。那时又有八十俱胝金翅鸟王，听了这部经后坚持五戒，也为他们授记。那时又有八十俱胝乾闼婆王，听了这部经后演奏千种音乐，发出微妙之声供养佛，而得授记。又有八十那由他数的夜叉鬼王，听了这部经后对佛的智慧深生净信，一切都得到菩提之记。）

【按】“皆蒙授记”之“授”，宋、元、明、宫本作“受”。原文“听是经典天龙夜叉”，今依四言句读断为“听是经典，天龙夜叉”。

```
月光当知，时乐声王，
种种供养，彼如来者，
岂异人乎？即汝身是。
汝因往昔，闻是经典，

```
（大意：月光，你应当知道，那时以种种供养那如来的乐声王，难道是别人吗？就是你自身。你因为往昔听闻过这部经典，所以今天又来请问。若有人在我般涅槃之后、法轮将要灭坏之时，对这教法生起净信，就能广说这样的经典。）

#### 乐与不乐此经之人

```
若于未来说是经，
则为护持于我法，
犹如众商善导师，
亦名护持于宝藏。
若于末世闻此经，
如弹指顷生欣乐，
当知皆是佛威神，
亦由文殊所加护，
是人则为见诸佛，
授其秘法令聪慧。
若人质直心柔软，
常勤供养于诸佛，
修行无我生慈忍，
是人爱乐于此经。
若人常怀不善心，
贪求利养无厌足，
于诸寂静无欣慕，
是人不乐于此经。
```
（大意：若在未来宣说这部经，就是护持我的法，犹如众商人的好导师，也名为护持宝藏。若在末世听闻这部经，如弹指之间生起欣乐，应当知道这都是佛的威神，也由文殊所加护；这人就是见到诸佛，诸佛授他秘密之法，令他聪慧。若人质直、心柔软，常勤供养诸佛，修行无我，生起慈忍，这人爱乐这部经。若人常怀不善之心，贪求利养没有厌足，对诸寂静之法没有欣慕，这人不乐这部经。）

```
若人供养诸如来，
善能了知深妙法，
于佛正智生净信，
是人爱乐于此经。
若人散乱无净心，
常行魁脍难调伏，
于诸欲境为僮仆，
是人不乐于此经。
若人常乐阿兰若，
独处空闲心寂静，
不著利养及亲属，
是人爱乐于此经。
若人随顺恶知友，
损坏自他诸善法，
彼于戒定多退失，
是人不乐于此经。
若人意乐极清净，
常以智慧观诸法，
为善知识之所护，
是人爱乐于此经。
若人系著亲友家，
与之花果令欢喜，
心无正直怀谄曲，
是人不乐于此经。
若人常念诸佛恩，
于胜善根生爱乐，
回向菩提无谄曲，
是人爱乐于此经。
若人恋著于妇女，
种种上服而严饰，
常愿与彼同游戏，
是人不乐于此经。
若人深心无所依，
于诸欲境曾无染，
不以饮食生谀谄，
是人爱乐于此经。
若人教导诸群生，
而言婬欲无诸过，
则为诽谤三世佛，
是人不乐于此经。
若人信乐常坚固，
发起精进求诸法，
不生疲倦及轻慢，
是人爱乐于此经。
若人系著诸妇女，
常于欲境怀思念，
不修智慧广饶益，
是人不乐于此经。
若人宴坐山林中，
修习智慧皆清净，
不贪一切资生具，
是人爱乐于此经。
```
（大意：若人供养诸如来，善能了知深妙之法，对佛的正智生起净信，这人爱乐这部经。若人散乱，没有清净之心，常行屠脍之事，难以调伏，在诸欲境中作为奴仆，这人不乐这部经。若人常乐住阿兰若，独处空闲，心中寂静，不执著利养与亲属，这人爱乐这部经。若人随顺恶友，损坏自他的诸善法，他对戒定多有退失，这人不乐这部经。若人意乐极为清净，常以智慧观察诸法，为善知识所护持，这人爱乐这部经。若人系著于亲友之家，给他们花果令他们欢喜，心不正直，怀着谄曲，这人不乐这部经。若人常念诸佛之恩，对殊胜善根生起爱乐，回向菩提而无谄曲，这人爱乐这部经。若人恋著妇女，以种种上等衣服装饰她们，常愿与她们一同游戏，这人不乐这部经。若人深心无所依，对诸欲境从无染著，不因饮食而生谀谄，这人爱乐这部经。若人教导诸群生，说淫欲没有过失，就是诽谤三世诸佛，这人不乐这部经。若人信乐常时坚固，发起精进以求诸法，不生疲倦与轻慢，这人爱乐这部经。若人系著诸妇女，常对欲境怀着思念，不修智慧以广饶益，这人不乐这部经。若人宴坐山林之中，修习智慧都清净，不贪一切资生之具，这人爱乐这部经。）

【按】“魁脍”，即屠脍，指杀生之业。

#### 此经的功德与往昔为此经供养

```
若人了知眼尽性，
于无我相能通达，
彼则常闻如是法，
深生信解得无疑。
若人思惟眼尽性，
昼夜精勤无懈惓，
彼则成就总持辩，
常能演说于此经。
若人思惟于此经，
成就出现光明智，
彼则显发诸如来，
于眼空性能通达。
假使建立百千塔，
供养一切诸世尊，
若人思惟于此经，
所获功德复过彼。
假使百千诸伎乐，
供养如来之舍利，
若人得闻于此经，
所获功德复过彼。
佛眼所见诸众生，
皆同如来而供养，
过于无量俱胝劫，
不如受持于此经。
若人于此契经中，
受持演说四句偈，
当于是人生恭敬，
犹如最胜大悲尊。
```
（大意：若人了知眼的尽性，对于无我之相能够通达，他就常能听闻这样的法，深生信解而无疑惑。若人思惟眼的尽性，昼夜精勤而不懈倦，他就成就总持与辩才，常能演说这部经。若人思惟这部经，成就出现光明之智，他就能显发诸如来（之德），对于眼的空性能够通达。假使建立百千座塔供养一切诸世尊，若人思惟这部经，所获的功德又超过那人。假使以百千种伎乐供养如来的舍利，若人得以听闻这部经，所获的功德又超过那人。佛眼所见的诸众生，都如同如来一样受到供养，经过无量俱胝劫，也不如受持这部经。若人对这部契经，受持演说四句偈，应当对这人生起恭敬，犹如对最胜的大悲世尊。）

```
我于往昔百千劫，
流转三有生死中，
曾于无量诸佛所，
为是经故而供养。
或然无量百千灯，
其炷各等由旬量，
为于此经得自在，
是故供养大导师。
或以薝卜婆利花，
苏摩那花无忧花，
以此花鬘及幢盖，
种种供养如来塔。
我于往昔生死中，
有来求者咸能施，
或施花果诸林苑，
或施桥梁及井泉，
或施白象及麒麟，
或施宝马并彩女，
或施金床珍宝帐，
或施璎珞杂花鬘，
如是一一满百千，
为此经故心无倦。
```
（大意：我在往昔百千劫中，流转于三有生死之中，曾在无量诸佛之所，为了这部经而作供养。或燃起无量百千盏灯，每盏灯炷都等同一由旬之大，为了对这部经得到自在，所以供养大导师。或以薝卜花、婆利花、苏摩那花、无忧花，以这些花鬘以及幢盖，种种供养如来之塔。我在往昔生死之中，有来求取的人都能施与：或施花果与诸林苑，或施桥梁与井泉，或施白象与麒麟，或施宝马与婇女，或施金床与珍宝帐，或施璎珞与杂花鬘；像这样一一都满百千，为了这部经，心无疲倦。）
