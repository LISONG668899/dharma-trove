# 摩咥里制吒之歌

阿阇黎摩咥里制吒造　据藏文译出

## 题解

本篇收于德格版丹珠尔续部释 ཟི 函第 7b 至 8a 页（东北目录 D2362）。开头没有梵藏题名，只有"敬礼佛陀"；跋语作"摩底制达之歌，圆满"（མ་ཏི་ཙི་ཏྲའི་གླུ），没有记载译者。作者一般还原为 Mātṛceṭa，汉译通称摩咥里制吒，是以赞佛诗著称的印度论师（著有《一百五十赞》等）；但本篇是密乘道歌，是否出自同一人，不能确定，可能是同名的另一位成就者。

特别说明：本篇与本站已译的《俱生之歌》（D2341，题为瑜伽自在寂天所造）几乎是同一首歌。两篇都以空性树上一朵多色的花为主喻，叠句都赞叹无比、无价之花，四段的内容与次序完全相同：空性树上一花多色；无根无枝；截取花蕊者是幻化之师，以花供养金刚自在；观察胜喜与离喜，礼敬上师。只是字句有出入，作者署名也不同。二者大概是同一首道歌的两种传本或两次翻译。本译照常译出，并在各节按语中列出与 D2341 的主要异同，读者可以对读。

关于密乘内容的告诫：第三、四节的"花蕊""胜喜""离喜"，属于圆满次第的象征语言与四喜之说，须依灌顶与上师口授理解。

体例：藏文原文全部保留在代码框中，按段落分节，每节后附汉译；叠句照原文每次重复。凡标"存疑"的按语，表示本译对原文意思没有把握。藏文依 Esukhia 德格丹珠尔电子版。

## 一、空性树上，一花多色

```
མེ་ཏོག་གཅིག་རྒྱས་ཁ་དོག་སྣ་ཚོགས་པ། །
སྟོང་པའི་ལྗོན་ཤིང་དག་ལས་ཤིན་ཏུ་རྒྱས། །
བཙན་པོ་དཔེ་མེད་མེ་ཏོག་རབ་རྒྱས་པ། །
རིན་ཐང་མེད་པའི་མེ་ཏོག་འདི་སྣོམས་ཤིག། །
```

一朵花开放，有种种颜色，从空性的树上极为繁茂地开放。无与伦比的花，强劲地盛开着；去嗅一嗅这无价的花吧！

【按】本篇与已译的《俱生之歌》（D2341，瑜伽自在寂天造）几乎是同一首歌：两篇都以空性林中一朵多色之花为主喻，叠句都说"无比之花""无价之花"，四段的内容与次序也相同，只是字句有出入。D2341 叠句作"便胜过十方，去取那无价的花吧"，本篇作"强劲地盛开，去嗅一嗅这无价的花吧"。二者大概是同一首道歌的两种传本或两次翻译，被分别归于寂天与摩咥里制吒名下。

【按】"无与伦比的花，强劲地盛开着；去嗅一嗅这无价的花吧"，是全篇的叠句。

## 二、无根无枝，看那美好时节

```
དེ་ཤིང་རྩ་བ་ཡལ་ག་ལོ་མ་མེད། །
ལྟོས་དང་ཟླ་ཉལ་འགྲོ་ནི་བཟང་པོའི་དུས། །
བཙན་པོ་དཔེ་མེད་མེ་ཏོག་རབ་རྒྱས་པ། །
རིན་ཐང་མེད་པའི་མེ་ཏོག་འདི་སྣོམས་ཤིག། །
```

那棵树，没有根，没有枝，也没有叶。看哪，月落之时，正是美好的时节。无与伦比的花，强劲地盛开着；去嗅一嗅这无价的花吧！

【按】存疑。"ལྟོས་དང་ཟླ་ཉལ་འགྲོ་ནི་བཟང་པོའི་དུས"，文义难解，本译读作"看哪，月落之时，正是美好的时节"，所指不确定。对应的 D2341 此句作"朋友们，看那金黄美好、胜过诸方［的花］"，二者差异较大，可能有一方传写有误。

## 三、截取花蕊者是幻化之师

```
གེ་སར་གཅོད་མཁས་སྒྱུ་མའི་མཁན་པོ་ཡིན། །
ཆོས་དབྱིངས་རྡོ་རྗེ་དབང་ཕྱུག་མཆོད་པ་འབུལ། །
བཙན་པོ་དཔེ་མེད་མེ་ཏོག་རབ་རྒྱས་པ། །
རིན་ཐང་མེད་པའི་མེ་ཏོག་འདི་སྣོམས་ཤིག། །
```

善于截取花蕊的人，就是幻化之师；［以这花］向法界金刚自在献上供养。无与伦比的花，强劲地盛开着；去嗅一嗅这无价的花吧！

【按】与 D2341 第三段相同。"花蕊"在密乘象征语中常与明点、大乐相关；"金刚自在"指金刚持或心性本身。这些都是象征语言，须依上师口授理解，不可照字面揣测。

## 四、观察胜喜离喜，礼敬上师

```
མཆོག་དགའ་དང་ནི་དགའ་བྲལ་གཞིག་ནས་ལོངས། །
ཡང་དག་བླ་མའི་ཞབས་བཏུད་ནན་ཏན་གྱིས། །
བཙན་པོ་དཔེ་མེད་མེ་ཏོག་རབ་རྒྱས་པ། །
རིན་ཐང་མེད་པའི་མེ་ཏོག་འདི་སྣོམས་ཤིག། །
```

把胜喜与离喜分析开来，然后受用；精勤地礼敬真实上师的双足。无与伦比的花，强劲地盛开着；去嗅一嗅这无价的花吧！

【按】与 D2341 第四段相同。"胜喜"与"离喜"是密乘四喜中的两种，属于无上瑜伽续圆满次第，须在具德上师座前依灌顶与口授领受。D2341 作"善加观察而把握"，本篇作"分析开来然后受用"，意思相近。
