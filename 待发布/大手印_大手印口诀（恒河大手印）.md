# 大手印口诀（恒河大手印）

大成就者帝洛巴说　据藏文译出

## 题解

本篇梵名 Mahāmudropadeśa，藏名 phyag rgya chen po'i man ngag，即《大手印口诀》，收于德格版丹珠尔续部释 ཞི 函第 243a 至 244a 页（东北目录 D2303）。跋语说是吉祥帝洛巴在恒河岸边为那洛巴所说，所以藏地通称为《恒河大手印》（phyag chen gang gA ma）。

帝洛巴（Tilopa）是印度大成就者，噶举派的初祖；那洛巴（Nāropa）是他的弟子，后来把法传给藏地的玛尔巴译师。德格本跋语没有记载译者，传统上认为是玛尔巴从那洛巴处得到并译传藏地，但跋语中没有这样说，这里不作肯定。帝洛巴名下另有《道歌宝藏》（D2281），已译，可以参看。

全篇正文约一百一十句，每句九个音节，是噶举派大手印最根本的教言之一。内容大致分为四个部分：

一、缘起与前行（第一、二节）：大手印本不可说，为具缘的那洛巴而说；观世法如梦幻，生起厌离，独处静修。

二、正说心性（第三至十五节）：以心识与造作见不到实义；以断树根、明灯、虚空、云散、太阳、浊水澄清等譬喻，开示心性本来光明、不被染污、不可言说、无所依止。修持的要点是不造作、不作意、无取舍、放松安住，"束缚放松了，解脱就毫无疑问"。其中第五节为一时不能安住的钝根者开示风息等辅助方便，第十四、十五节以见、修、行、果四王总摄。

三、修行次第与劝诫（第十六至二十节）：以三种水譬喻修行的三个阶段；执著宗义、生起企求就见不到光明；悲愍不信者，劝依上师加持。

四、方便道与结愿（第二十一、二十二节）：开示事业手印之道及其功德，最后发愿。

关于密乘内容的告诫：第五节的风息、观视、持心诸法，第二十一节的事业手印，都属于密乘修法，篇中以简略、象征的语言说出。只能在具德上师座前，依具足的灌顶与口授领受和修持，绝不可依文字自行理解或模仿。全篇的根本，是前面所说的直接认识心性。

体例：藏文原文全部保留在代码框中，按意义分节，每节后附汉译；凡标"存疑"的按语，表示本译对原文意思没有把握。藏文依 Esukhia 德格丹珠尔电子版，异文取第二读。

## 题名与礼敬

```
རྒྱ་གར་སྐད་དུ། མ་ཧཱ་མུ་དྲ་ཨུ་པ་དེ་ཤཾ།
བོད་སྐད་དུ། ཕྱག་རྒྱ་ཆེན་པོའི་མན་ངག།
དཔལ་ལྷན་ཅིག་སྐྱེས་པ་ལ་ཕྱག་འཚལ་ལོ། །
```

梵语：玛哈穆札·乌巴德香。藏语：《大手印口诀》。

敬礼吉祥俱生！

## 一、为具缘的那洛巴而说

```
ཕྱག་རྒྱ་ཆེན་པོ་བསྟན་དུ་མེད་གྱུར་ཀྱང། །
དཀའ་བ་སྤྱོད་ཅིང་བླ་མ་ལ་གུས་པའི། །
སྡུག་བསྔལ་བཟོད་ལྡན་བློ་ལྡན་ནཱ་རོ་པ། །
སྐལ་ལྡན་ཁྱོད་ཀྱི་སྙིང་ལ་འདི་ལྟར་བྱོས། །
```

大手印虽然是无法以言语开示的，但是，对于修持苦行、恭敬上师、能够忍受痛苦、具有智慧的那洛巴——具有善缘的你，要在心中这样去做：

【按】这四句是全篇的缘起。那洛巴依止帝洛巴时，经历了著名的十二大苦行，所以这里称他"修持苦行、恭敬上师、能忍受痛苦"。"大手印无法言说开示"，是说大手印是心的本性，不是言语与概念的对象；下面所说的一切，都只是指示，而不是大手印本身。

## 二、观世法如梦幻，独处静修

```
ཀྱེ་ཧོ་འཇིག་རྟེན་ཆོས་ལ་ལེགས་ལྟོས་དང། །
རྟག་མི་ཐུབ་སྟེ་རྨི་ལམ་སྒྱུ་མ་འདྲ། །
རྨི་ལམ་སྒྱུ་མ་དོན་ལ་ཡོད་མ་ཡིན། །
དེས་ན་སྐྱོ་བསྐྱེད་འཇིག་རྟེན་བྱ་བ་ཐོང། །
འཁོར་གཡོག་ཆགས་སྡང་ཉེ་འབྲེལ་ཀུན་སྤོངས་ལ། །
གཅིག་པུ་ནགས་འདབ་རི་ཁྲོད་དགོན་པར་བསྒོམས། །
བསྒོམ་དུ་མེད་པའི་ངང་ལ་གནས་པར་གྱིས། །
ཐོབ་མེད་ཐོབ་ན་ཕྱག་རྒྱ་ཆེན་པོ་ཐོབ། །
```

唉！好好地观看世间的诸法吧：它们不能恒常，就像梦与幻一样；梦与幻，在实义上并不存在。所以，要生起厌离心，抛下世间的事务。舍弃眷属与仆从、贪爱与嗔恨，以及一切亲友，独自在森林边、山间的静处、寂静的道场中修习。要安住在无所修的境界之中。如果得到了那无所得的，就得到了大手印。

【按】先说"修习"，又说"安住于无所修"，并不矛盾：前者是说要真实去修，后者是说修的方法就是不造作、不以心造出一个所修的对象。"得到无所得"，是说大手印不是从外面新得到的东西，本来具足，认识了它，就叫作"得到大手印"。

【按】帝洛巴开示大手印，首先是从观世法无常如梦、生起厌离、远离愦闹开始的。这说明大手印虽然是最高的见地，却不离出离心这一切修行的基础。

## 三、心识与造作见不到实义

```
འཁོར་བའི་ཆོས་འདིས་དོན་མེད་ཆགས་སྡང་རྒྱུ། །
བྱས་ཆོས་སྙིང་པོ་མེད་པས་དོན་དམ་སྙིང་པོ་ལྟོས། །
བློ་ཡི་ཆོས་ཀྱིས་བློ་འདས་དོན་མི་མཐོང། །
བྱས་པའི་ཆོས་ཀྱིས་བྱར་མེད་དོན་མི་རྙེད། །
བློ་འདས་བྱར་མེད་དོན་དེ་ཐོབ་འདོད་ན། །
རང་སེམས་རྩད་ཆོད་རིག་པ་གཅེར་བུར་ཞོག། །
རྟོག་པ་དྲི་མའི་ཆུ་དེ་དངས་སུ་ཆུག། །
སྣང་བ་དགག་སྒྲུབ་མི་བྱ་རང་སོར་ཞོག། །
སྤོང་ལེན་མེད་ན་ཕྱག་རྒྱ་ཆེན་པོར་གྲོལ། །
```

轮回的这些法，没有意义，只是贪嗔的因；有为造作之法没有精华，所以要去看胜义的精华。以心识（分别）的法，见不到超越心识的实义；以造作的法，找不到无可造作的实义。如果想要得到那超越心识、无可造作的实义，就要对自心追究到底、断其根源，让明觉赤裸地安住；让分别垢染的水，自然澄清；对于显现，不要遮止，也不要成立，让它安住于本位；没有了取舍，就在大手印中解脱。

【按】"རང་སེམས་རྩད་ཆོད"，"对自心追究到底、断其根源"："རྩད་ཆོད"有彻底寻求、断定根本的意思，是说观察自心的来处、住处、去处，直到决定它无有根本。"རིག་པ་གཅེར་བུར་ཞོག"，"让明觉赤裸地安住"，是说不以任何概念、修法去包覆它，让它如其本然地显露。

【按】"让分别垢染之水自然澄清"，是著名的譬喻：浊水不去搅动，泥沙自然沉下，水自然清澈；同样，对分别念不去对治、不去追随，它自然平息，心性自然显明。"对显现不遮不立"，就是对一切显现不排斥、不执著，这正是"没有取舍"的意思。

## 四、断根与明灯之喻

```
དཔེར་ན་ལྗོན་ཤིང་ཡལ་ག་ལོ་འདབ་རྒྱས། །
རྩ་བཅད་ཡལ་ག་ལོ་འདབ་ཁྲི་འབུམ་སྐམས། །
དཔེར་ན་བསྐལ་སྟོང་བསགས་པའི་མུན་པ་ཡང། །
སྒྲོན་མེ་གཅིག་གིས་མུན་པའི་ཚོགས་རྣམས་སེལ། །
དེ་བཞིན་རང་སེམས་འོད་གསལ་སྐད་ཅིག་གིས། །
བསྐལ་པར་བསགས་པའི་སྡིག་སྒྲིབ་མ་ལུས་སེལ། །
```

譬如一棵大树，枝叶繁茂，只要砍断了树根，千万的枝叶都会枯干。又譬如千劫所积聚的黑暗，一盏灯就能除去所有的黑暗。同样，自心的光明，在一刹那之间，就能除去多劫所积聚的一切罪障。

【按】第一个譬喻原文没有说出合法（对应的意义），一般理解为：认识了自心这一根本，一切分别与烦恼的枝叶自然枯萎，不必一一去对治。第二个譬喻说明：黑暗无论积累多久，灯一点亮就消失；罪障无论积累多久，认识自心光明的那一刹那就能清除。这是就证悟的力量而说的，并不是说可以轻视取舍因果。

## 五、为钝根者说风要与调心

```
བློ་དམན་སྐྱེ་བོ་དོན་ལ་མི་གནས་ན། །
རླུང་གི་གནད་བཟུང་རིག་པ་གཅུད་ལ་བོར། །
ལྟ་སྟངས་དང་ནི་སེམས་འཛིན་དུ་མ་ཡིས། །
རིག་པ་དང་ལ་མི་གནས་བར་དུ་གཅུན། །
```

智慧低劣的人，如果不能安住于实义，就要把握风（气）的要诀，调紧明觉；以种种观视的方式与执持心的方法，调伏它，直到明觉安住于本然的状态中为止。

【按】这四句是为一时不能直接安住于心性的人，开示的辅助方便。"把握风的要诀"，一般指宝瓶气等调息的修法；"ལྟ་སྟངས"（观视的方式），指眼的种种注视方法；"སེམས་འཛིན"（执持心），指种种令心专注的修法。这些具体修法，都须在具德上师座前依口授学习，不可依文字自行练习风息，以免损伤身心。

【按】存疑。"རིག་པ་གཅུད་ལ་བོར"，"调紧明觉"，"གཅུད"有拧紧、扎紧的意思，大概是说使散乱的明觉收摄起来，这里依字面试译。末句"རིག་པ་དང་ལ"，"དང"可能是"ངང"（状态）的讹写，这里依后者读作"明觉安住于本然的状态中"。

## 六、虚空之喻：以心观心

```
དཔེར་ན་ནམ་མཁའི་དཀྱིལ་ནི་བརྟག་བྱས་ན། །
མཐའ་དང་དབུས་སུ་འཛིན་པ་འགག་པར་འགྱུར། །
དེ་བཞིན་སེམས་ཀྱིས་སེམས་ལ་བརྟག་བྱས་ན། །
རྣམ་རྟོག་ཚོར་འགག་རྟོག་མེད་གནས་གྱུར་ནས། །
བླ་མེད་བྱང་ཆུབ་སེམས་ཀྱི་རང་བཞིན་མཐོང། །
```

譬如观察虚空的中央，执著边际与中央的念头就会止息；同样，以心来观察心，分别的聚合止息了，安住于无分别之中，就能见到无上菩提心的本性。

【按】"观察虚空的中央"：越是去寻找虚空的边与中，越是找不到，执著边、中的念头自然就停止了。以心观心也是这样：去寻找心的形色、处所，什么也找不到，分别自然止息，就见到了心的本性。这里的"菩提心"，指胜义菩提心，即心的本性。

【按】存疑。"རྣམ་རྟོག་ཚོར་འགག"一句，"ཚོར"字面是"感受"，可能是"ཚོགས"（聚合）的讹写，这里读作"分别的聚合止息"；若照字面，就是"分别与感受止息"。

## 七、云散于空

```
དཔེར་ན་ས་རླངས་སྤྲིན་ནི་ནམ་མཁར་དེངས། །
གར་ཡང་སོང་མེད་གར་ཡང་གནས་པ་མེད། །
དེ་བཞིན་སེམས་ལས་བྱུང་བའི་རྟོག་ཚོགས་ཀྱང། །
རང་སེམས་མཐོང་བས་རྟོག་པའི་དབའ་རླབས་དེངས། །
```

譬如地上蒸腾的雾气所成的云，在虚空中自然消散，它没有去到任何地方，也没有住在任何地方；同样，从心中生起的种种分别念，由于见到了自心，分别的波浪也就自然消散了。

【按】这个譬喻说明：分别念从心中生起，又在心中消散，就像云在虚空中生起又消散，既没有来处，也没有去处。认识了心性，不必去消灭念头，念头自己就消散了。

## 八、虚空离色，不被染污

```
དཔེར་ན་ནམ་མཁའ་ཁ་དོག་དབྱིབས་ལས་འདས། །
དཀར་ནག་དག་གིས་གོས་མེད་འགྱུར་བ་མེད། །
དེ་བཞིན་རང་སེམས་ཁ་དོག་དབྱིབས་ལས་འདས། །
དགེ་སྡིག་དཀར་གནག་ཆོས་ཀྱིས་གོས་མི་འགྱུར། །
```

譬如虚空超越了颜色与形状，不被黑白所染污，也没有变化；同样，自心超越了颜色与形状，不被善恶、黑白诸法所染污。

【按】"不被善恶黑白诸法所染"，是就心的本性来说的：心性本身如虚空，善念、恶念都不能染污它，也不能改变它。这并不是说世俗中可以不分善恶、不取舍因果。

## 九、日藏不被暗蔽

```
དཔེར་ན་གསལ་དག་ཉི་མའི་སྙིང་པོ་དེ། །
བསྐལ་པ་སྟོང་གི་མུན་པས་བསྒྲིབས་མི་ནུས། །
དེ་བཞིན་རང་སེམས་སྙིང་པོ་འོད་གསལ་དེ། །
བསྐལ་པའི་འཁོར་བས་བསྒྲིབས་པར་མི་ནུས་སོ། །
```

譬如明亮清净的太阳的精华，千劫的黑暗也不能遮蔽它；同样，自心的精华光明，多劫的轮回也不能遮蔽它。

【按】这是说心性本来光明，众生虽然在轮回中流转了无数劫，心的光明本身从来没有减损；所谓"障蔽"，只是没有认识它而已。

## 十、光明不可言说

```
དཔེར་ན་ནམ་མཁའ་སྟོང་པར་རབ་བརྟགས་ཀྱང། །
ནམ་མཁའ་ལ་ནི་འདི་འདྲ་བརྗོད་དུ་མེད། །
དེ་བཞིན་རང་སེམས་འོད་གསལ་བརྗོད་གྱུར་ཀྱང། །
བརྗོད་པར་འདི་འདྲ་གྲུབ་ཅེས་བརྟག་གཞི་མེད། །
```

譬如虽然把虚空假立为"空"，但对于虚空本身，却不能说它"是这样的"；同样，虽然说自心是"光明"，但所说的也没有"成立为这样"的观察依据。

【按】这一段是在防止对"光明"的执著：前面说心是光明，但光明也只是假立的名言，就像说虚空是"空"一样；如果把"光明"当成一个实有的东西去执著，那就又错了。

## 十一、无所依，松坦安住

```
དཔེར་ན་ནམ་མཁའ་གང་ལ་གང་གིས་བརྟེན། །
དེ་བཞིན་རང་སེམས་ཕྱག་ཆེན་རྟེན་ཡུལ་མེད། །
མ་བཅོས་གཉུག་མའི་ངང་དུ་གློད་ལ་ཞོག། །
བཅིངས་པ་གློད་གྱུར་གྲོལ་བར་ཐེ་ཚོམ་མེད། །
དེ་ལྟར་སེམས་ཀྱི་རང་བཞིན་ནམ་མཁའ་འདྲ། །
ཆོས་རྣམས་མ་ལུས་དེ་རུ་མ་འདུས་མེད། །
```

譬如虚空，依于什么？被什么所依？同样，自心大手印，也没有所依的对象。在不造作的本然状态中，放松而安住；束缚放松了，解脱就毫无疑问。这样，心的本性犹如虚空，一切诸法，没有不摄集在其中的。

【按】"བཅིངས་པ་གློད་གྱུར་གྲོལ་བར་ཐེ་ཚོམ་མེད"，"束缚放松了，解脱就毫无疑问"，是这首道歌中最著名的句子之一。所谓"束缚"，就是心的紧张与执著；所以解脱的方法不是去做什么，而是放松。"མ་བཅོས་གཉུག་མ"，"不造作的本然"，是大手印的根本要求：不改造、不修整，让心如其本然。

## 十二、身语意的要诀

```
ལུས་ཀྱི་བྱ་བ་ཡོ་ཐོང་རྣལ་མར་ཞོག། །
ངག་གི་སྨྲ་བརྗོད་མ་མང་བྲག་ཅ་འདྲ། །
ཡིད་ལ་མི་སེམས་ལ་བཟླའི་ཆོས་ལ་ལྟོས། །
ལུས་ལ་སྙིང་པོ་མེད་པས་སྨྱུག་སྡོང་འདྲ། །
སེམས་ནི་ནམ་མཁའི་དཀྱིལ་ལྟར་བསམ་ཡུལ་འདས། །
དེ་དང་བཏང་གཞག་མེད་པར་གློད་ལ་ཞོག། །
སེམས་ལ་གཏད་སོ་མེད་ན་ཕྱག་ཆེན་ཡིན། །
དེ་ལ་གོམས་པས་བླ་མེད་བྱང་ཆུབ་འཐོབ། །
```

身体的作为要放下，自然地安住；口中的言说不要多，要像空谷回音一样；意中不要思维，去观看那超越（思维）的法。身体没有实质，就像空心的芦苇；心就像虚空的中央，超越了思维的范围。对它，不放也不收，放松而安住。心如果没有所专注的地方，那就是大手印；串习于此，就能获得无上菩提。

【按】这一段是身、语、意三门的修持要诀：身放下而自然，语少说而如回声，意不思而观超越之法。

【按】存疑。"ལ་བཟླའི་ཆོས"，"ལ་བཟླ"字面是"翻越山口"，这里引申为"超越（思维）的法"，意思不完全确定。

【按】"བཏང་གཞག་མེད་པ"，"不放也不收"，是说既不刻意放任心去散乱，也不刻意收摄心去专注，心离开这两种造作，就自然安住。"སེམས་ལ་གཏད་སོ་མེད"，"心没有所专注的地方"，是说不以任何对象作为所缘，这正是大手印与一般禅定的区别。

## 十三、无所缘，无道可行

```
དམིགས་པའི་ཡུལ་མེད་སེམས་ཀྱི་རང་བཞིན་གསལ། །
བགྲོད་པའི་ལམ་མེད་སངས་རྒྱས་ལམ་སྣ་ཟིན། །
བསྒོམ་མེད་གོམས་པས་བླ་མེད་བྱང་ཆུབ་འཐོབ། །
```

没有所缘的对境，心的本性就明亮；没有要走的道路，却已掌握了成佛之道的门径；串习那无所修的，就能获得无上菩提。

【按】"བགྲོད་པའི་ལམ་མེད་སངས་རྒྱས་ལམ་སྣ་ཟིན"，"没有要走的道路，却掌握了成佛之道的门径"："ལམ་སྣ་ཟིན"字面是"抓住了路头"。意思是：在大手印中，没有一条从此处走到彼处的道路，因为佛就是自心；认识了这一点，就已经走上了成佛的正道。

## 十四、见修行果之王

```
གཟུང་འཛིན་ཀུན་འདས་ལྟ་བའི་རྒྱལ་པོ་ཡིན། །
ཡེངས་པ་མེད་ན་བསྒོམ་པའི་རྒྱལ་པོ་ཡིན། །
བྱ་བརྩལ་མེད་ན་སྤྱོད་པའི་རྒྱལ་པོ་ཡིན། །
རེ་དོགས་མེད་ན་འབྲས་བུ་མངོན་དུ་འགྱུར། །
```

超越了一切能取与所取，就是见之王；没有散乱，就是修之王；没有作为与勤作，就是行之王；没有希望与恐惧，果就会现前。

【按】这四句以"见、修、行、果"概括大手印的修持，是噶举派常引的名句。"没有散乱"，是说修的要点不在于修什么，而在于不离开心性；"没有作为与勤作"，是说行持不出于刻意的造作；"没有希望与恐惧"，是说不希望得到佛果，也不畏惧轮回，这时果就自然现前。

## 十五、阿赖耶无生，再说见修行果

```
ཀུན་གཞི་སྐྱེ་མེད་བག་ཆགས་སྒྲིབ་གཡོགས་བྲལ། །
མཉམ་རྗེས་མི་བྱ་སྐྱེ་མེད་སྙིང་པོར་ཞོག། །
སྣང་བ་རང་སྣང་བློ་ཡི་ཆོས་རྣམས་ཟད། །
མུ་མཐའ་ཡོངས་གྲོལ་ལྟ་བའི་རྒྱལ་པོ་ཡིན། །
མུ་མེད་གཏིང་ཡངས་བསྒོམ་པའི་རྒྱལ་པོ་མཆོག། །
བྱར་མེད་རང་གནས་སྤྱོད་པའི་རྒྱལ་པོ་མཆོག། །
རེ་མེད་རང་གནས་འབྲས་བུའི་རྒྱལ་པོ་མཆོག། །
```

阿赖耶本来无生，远离习气与障蔽的覆盖；不要作入定与后得（的区分），安住于无生的精华之中；显现就是自己的显现，心识的诸法都已经穷尽。边际完全解脱，是见之王；无边而深广，是最胜的修之王；无所作为而自然安住，是最胜的行之王；无所希望而自然安住，是最胜的果之王。

【按】这里的"ཀུན་གཞི"（阿赖耶），是指一切法的根基、心的本基，不是唯识宗所说杂染的第八识；所以说它"本来无生，远离习气与障蔽"。"མཉམ་རྗེས་མི་བྱ"，"不要作入定与后得"，是说在证悟的境界中，入定与出定没有分别，不必刻意去入定，也不必担心出定。

【按】这里第二次说见、修、行、果之王，与上一节相应而更进一层：上一节是从"没有什么"（无二取、无散乱、无勤作、无希惧）来说，这一节是从"本来如何"（边际解脱、无边深广、自然安住）来说。

## 十六、三种水的譬喻

```
ལས་ནི་དང་པོ་གཅོང་རོང་ཆུ་དང་འདྲ། །
བར་དུ་ཆུ་བོ་གངྒཱ་དལ་བུས་འབབ། །
ཐ་མ་ཆུ་བྲན་མ་བུ་ཕྲད་པ་འདྲ། །
```

初学的修行人，就像峡谷中奔流的水；中间，就像恒河的水缓缓流淌；最后，就像众水汇合，如同母与子相逢。

【按】这三句以三种水比喻修行的三个阶段：初学时，念头如峡谷急流，湍急不停；中间，心渐渐平稳，如恒河缓流；最后，如众水汇入大海，母子相逢。"母子相逢"，噶举传统通常解释为"子光明"（修道中所认识的光明）与"母光明"（本来的基光明）会合无二。

【按】存疑。"ཆུ་བྲན"指细小的水流、溪流，字面是"小水流与母亲相会"，这里依义译作"众水汇合"。

## 十七、宗义见不到光明

```
སྔགས་སུ་སྨྲ་དང་ཕ་རོལ་ཕྱིན་པ་དང། །
འདུལ་བའི་སྡེ་སྣོད་ལ་སོགས་ཆོས་རྣམས་དང། །
རང་རང་གཞུང་དང་གྲུབ་པའི་མཐའ་ཡིས་ཀྱང། །
འོད་གསལ་ཕྱག་རྒྱ་ཆེན་པོ་མཐོང་མི་འགྱུར། །
```

无论是说密咒者、波罗蜜多乘，还是律藏等诸法，以及各自的经典与宗义，都见不到光明大手印。

【按】这里并不是轻视密咒、显教与戒律，而是说：如果只是执著于各自的经典、宗义与概念，以分别心去理解，就见不到超越分别的光明大手印。下文第十九节又说，远离企求、不住于边，就能见到一切三藏之法，前后合看，意思就很清楚了。

## 十八、不作意，离企求

```
ཡིད་ལ་མི་བྱེད་ཞེ་འདོད་ཀུན་དང་བྲལ། །
རང་བྱུང་རང་ཞི་ཆུ་ཡི་དབའ་རླབས་འདྲ། །
ཞེ་འདོད་བྱུང་བས་འོད་གསལ་མ་མཐོང་བསྒྲིབས། །
རྟོགས་པ་བསྲུང་སྡོམ་དམ་ཚིག་དོན་ལས་ཉམས། །
```

不作意，远离一切的企求；（念头）自己生起，自己平息，就像水上的波浪。一生起企求，就遮蔽了光明而不能见；以分别来守护的戒律与三昧耶，反而从实义中退失。

【按】"ཡིད་ལ་མི་བྱེད"，"不作意"（梵 amanasikāra），是印度大手印的核心概念，梅纪巴的不作意法类就以此为名，可与已译的梅纪巴诸篇互相参看。

【按】存疑。末句的"རྟོགས་པ"，这里依上下文读作"རྟོག་པ"（分别）。"以分别守护的三昧耶从实义中退失"，意思是：如果只是以分别心、执著心去守持戒律与三昧耶，就还没有契合它们的实义；最殊胜的守护，是不离心性。这是就证悟的境界而说的，绝不是说可以不守戒律与三昧耶。

## 十九、不住不缘，即是明灯

```
མི་གནས་མི་དམིགས་དོན་ལས་མི་འདའ་ན། །
དམ་པ་ཉམས་ལེན་མུན་པའི་སྒྲོན་མེ་ཡིན། །
ཞེ་འདོད་ཀུན་བྲལ་མཐའ་ལ་མི་གནས་ན། །
སྡེ་སྣོད་ཆོས་རྣམས་མ་ལུས་མཐོང་བར་འགྱུར། །
དོན་འདིར་གཞོལ་ན་འཁོར་བའི་བཙོན་ལས་ཐར། །
དོན་འདིས་མཉམ་གཞག་མ་ལུས་སྡིག་སྒྲིབ་བསྲེག། །
བསྟན་པའི་སྒྲོན་མེ་ཞེས་སུ་བཤད་པ་ཡིན། །
```

如果不住、不缘，不离开这一实义，这就是殊胜的修持，是黑暗中的明灯。如果远离一切企求，不住于任何边，就能见到三藏的一切诸法。专注于这一实义，就能从轮回的牢狱中解脱；以这一实义入定，能焚尽一切罪障——这被称为"教法的明灯"。

【按】"不住于边"，就是不住于有、无、常、断等一切边见。"见到三藏的一切诸法"，是说证悟了心性，三藏的一切教义自然通达，与第十七节"执著宗义见不到大手印"正好相对。

## 二十、悲愍不信者，劝依上师

```
དོན་འདིར་མི་མོས་སྐྱེ་བོ་བླུན་པོ་རྣམས། །
འཁོར་བའི་ཆུ་བོས་རྟག་ཏུ་ཁྱེར་བར་ཟད། །
ངན་སོང་སྡུག་བསྔལ་མི་བཟོད་སྙིང་རེ་རྗེ། །
སྡུག་བསྔལ་ཐར་འདོད་བླ་མ་མཁས་པ་བསྟེན། །
བྱིན་རླབས་ཞུགས་པས་རང་སེམས་གྲོལ་བར་འགྱུར། །
```

对这一实义不生信解的愚痴之人，只会被轮回的河流永远冲走；他们在恶趣中，承受难以忍受的痛苦，真是可怜！想要从痛苦中解脱，就要依止具有智慧的上师；上师的加持融入了，自心就会解脱。

【按】"上师的加持融入，自心就会解脱"，是噶举派大手印的特点：大手印的证悟，主要依靠上师的加持与弟子的虔信，而不仅仅依靠思维与学问。

## 二十一、事业手印之道及其功德

```
ལས་རྒྱ་བསྟེན་ན་བདེ་སྟོང་ཡེ་ཤེས་འཆར། །
ཐབས་དང་ཤེས་རབ་བྱིན་རླབས་སྙོམས་པར་ཞུགས། །
དལ་བར་དབབ་ཅིང་དཀྱིལ་འཁོར་དྲང་བ་དང། །
གནས་སུ་བསྐྱལ་དང་ལུས་ལ་ཁྱབ་པར་བྱ། །
དེ་ལ་ཞེན་མེད་བདེ་སྟོང་ཡེ་ཤེས་འཆར། །
ཚེ་རིང་སྐྲ་དཀར་མེད་ཅིང་ཟླ་ལྟར་རྒྱས། །
བཀྲག་མདངས་གསལ་ཞིང་སྟོབས་ཀྱང་སེང་གེ་འདྲ། །
ཐུན་མོང་དངོས་གྲུབ་མྱུར་ཐོབ་མཆོག་ལ་གཞོལ། །
```

如果依止事业手印，乐空的智慧就会显现：方便与智慧以加持而入于等至；缓缓地降下，导引坛城，送回原处，并使它遍布于全身；对此没有贪执，乐空的智慧就会显现。（这样修持，）就会长寿，没有白发，如月亮般增长；容光焕发、明亮，力量如同狮子；迅速获得共同成就，并且趋向殊胜的成就。

【按】这一节是无上瑜伽续圆满次第中"事业手印"的方便道修法，全部是象征语言。"缓缓降下、导引、送回原处、遍布全身"，一般认为是指明点修法的降、持、回、遍等次第；"导引坛城"（དཀྱིལ་འཁོར་དྲང་བ）意思不完全确定，这里只照字面译出，存疑。"对此没有贪执"，是这一修法的关键：如果有贪执，就只是凡俗的欲乐，不能生起乐空智慧。

【按】这一修法，在藏传佛教各派中，都只对具足灌顶、严守三昧耶、在生起与圆满次第上已有很深修证的修行人，在具德上师亲自指导下才开示，历代祖师都一再告诫不得私修，更不得以此为名放纵欲乐。帝洛巴把它放在全篇将尽之处，前面所说的不造作、不作意、无取舍，才是全篇的根本。这里只是如实翻译原文，读者绝不可照字面理解或效仿。

【按】"长寿、无白发、力如狮子"等，是传统上所说修持风脉明点的世间功德；"共同成就"指种种世间成就，"殊胜成就"指证悟大手印、成就佛果。

## 二十二、结愿

```
ཕྱག་རྒྱ་ཆེན་པོ་གནད་ཀྱི་གདམས་པ་འདི། །
འགྲོ་བ་སྐལ་ལྡན་སྙིང་ལ་གནས་པར་ཤོག། །
```

这大手印要诀的教言，愿它安住在具有善缘的众生心中！

```
དཔལ་ཏི་ལླི་པས་ནྭ་རོ་པ་ལ་ཆུ་བོ་གངྒཱའི་འགྲམ་དུ་གསུངས་པ་རྫོགས་སོ།། །།
```

吉祥帝洛巴在恒河岸边为那洛巴所说，圆满。

## 通篇连读

敬礼吉祥俱生！

大手印虽然是无法以言语开示的，但是，对于修持苦行、恭敬上师、能够忍受痛苦、具有智慧的那洛巴——具有善缘的你，要在心中这样去做：

唉！好好地观看世间的诸法吧：它们不能恒常，就像梦与幻一样；梦与幻，在实义上并不存在。所以，要生起厌离心，抛下世间的事务。舍弃眷属与仆从、贪爱与嗔恨，以及一切亲友，独自在森林边、山间的静处、寂静的道场中修习。要安住在无所修的境界之中。如果得到了那无所得的，就得到了大手印。

轮回的这些法，没有意义，只是贪嗔的因；有为造作之法没有精华，所以要去看胜义的精华。以心识（分别）的法，见不到超越心识的实义；以造作的法，找不到无可造作的实义。如果想要得到那超越心识、无可造作的实义，就要对自心追究到底、断其根源，让明觉赤裸地安住；让分别垢染的水，自然澄清；对于显现，不要遮止，也不要成立，让它安住于本位；没有了取舍，就在大手印中解脱。

譬如一棵大树，枝叶繁茂，只要砍断了树根，千万的枝叶都会枯干。又譬如千劫所积聚的黑暗，一盏灯就能除去所有的黑暗。同样，自心的光明，在一刹那之间，就能除去多劫所积聚的一切罪障。

智慧低劣的人，如果不能安住于实义，就要把握风（气）的要诀，调紧明觉；以种种观视的方式与执持心的方法，调伏它，直到明觉安住于本然的状态中为止。

譬如观察虚空的中央，执著边际与中央的念头就会止息；同样，以心来观察心，分别的聚合止息了，安住于无分别之中，就能见到无上菩提心的本性。

譬如地上蒸腾的雾气所成的云，在虚空中自然消散，它没有去到任何地方，也没有住在任何地方；同样，从心中生起的种种分别念，由于见到了自心，分别的波浪也就自然消散了。

譬如虚空超越了颜色与形状，不被黑白所染污，也没有变化；同样，自心超越了颜色与形状，不被善恶、黑白诸法所染污。

譬如明亮清净的太阳的精华，千劫的黑暗也不能遮蔽它；同样，自心的精华光明，多劫的轮回也不能遮蔽它。

譬如虽然把虚空假立为"空"，但对于虚空本身，却不能说它"是这样的"；同样，虽然说自心是"光明"，但所说的也没有"成立为这样"的观察依据。

譬如虚空，依于什么？被什么所依？同样，自心大手印，也没有所依的对象。在不造作的本然状态中，放松而安住；束缚放松了，解脱就毫无疑问。这样，心的本性犹如虚空，一切诸法，没有不摄集在其中的。

身体的作为要放下，自然地安住；口中的言说不要多，要像空谷回音一样；意中不要思维，去观看那超越（思维）的法。身体没有实质，就像空心的芦苇；心就像虚空的中央，超越了思维的范围。对它，不放也不收，放松而安住。心如果没有所专注的地方，那就是大手印；串习于此，就能获得无上菩提。

没有所缘的对境，心的本性就明亮；没有要走的道路，却已掌握了成佛之道的门径；串习那无所修的，就能获得无上菩提。

超越了一切能取与所取，就是见之王；没有散乱，就是修之王；没有作为与勤作，就是行之王；没有希望与恐惧，果就会现前。

阿赖耶本来无生，远离习气与障蔽的覆盖；不要作入定与后得（的区分），安住于无生的精华之中；显现就是自己的显现，心识的诸法都已经穷尽。边际完全解脱，是见之王；无边而深广，是最胜的修之王；无所作为而自然安住，是最胜的行之王；无所希望而自然安住，是最胜的果之王。

初学的修行人，就像峡谷中奔流的水；中间，就像恒河的水缓缓流淌；最后，就像众水汇合，如同母与子相逢。

无论是说密咒者、波罗蜜多乘，还是律藏等诸法，以及各自的经典与宗义，都见不到光明大手印。

不作意，远离一切的企求；（念头）自己生起，自己平息，就像水上的波浪。一生起企求，就遮蔽了光明而不能见；以分别来守护的戒律与三昧耶，反而从实义中退失。

如果不住、不缘，不离开这一实义，这就是殊胜的修持，是黑暗中的明灯。如果远离一切企求，不住于任何边，就能见到三藏的一切诸法。专注于这一实义，就能从轮回的牢狱中解脱；以这一实义入定，能焚尽一切罪障——这被称为"教法的明灯"。

对这一实义不生信解的愚痴之人，只会被轮回的河流永远冲走；他们在恶趣中，承受难以忍受的痛苦，真是可怜！想要从痛苦中解脱，就要依止具有智慧的上师；上师的加持融入了，自心就会解脱。

如果依止事业手印，乐空的智慧就会显现：方便与智慧以加持而入于等至；缓缓地降下，导引坛城，送回原处，并使它遍布于全身；对此没有贪执，乐空的智慧就会显现。（这样修持，）就会长寿，没有白发，如月亮般增长；容光焕发、明亮，力量如同狮子；迅速获得共同成就，并且趋向殊胜的成就。

这大手印要诀的教言，愿它安住在具有善缘的众生心中！
