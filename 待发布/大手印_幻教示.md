# 幻教示

梅纪巴（阿阇黎无二金刚）造　据藏文译出

## 题解

《幻教示》（梵 Māyānirukti，藏 sgyu ma nges par bstan pa，直译"幻之决定开示"）收于德格版丹珠尔续部释 ཝི 函第 111b 至 112a 页（东北目录 D2234），紧接在《梦教示》（D2233）之后，同属梅纪巴的"无念法类"。译者是印度堪布金刚手与译师比丘戒胜（即那措译师）。

《梦教示》以"梦"为喻，判摄六种见解而归于无住；本篇则以"幻"为喻，讲如幻之见如何离开常、断二边，以及如幻的见地落实到修行人的行为上应当是什么样子。全篇共十二颂四十八句，可以分为三部分：

前六颂讲见地：先设一问——众生既然如幻、本来是佛，智者为什么不去解脱他们？再以幻术师为喻作答；接着说明如幻不是断灭，法界不生、诸法不生不灭，所以既非断见，也不是如木石一般的顽空；最后说诸佛正因为如此，能够无勤作地转法轮。

中间五颂讲行持：瑜伽士要舍弃懈怠与我慢，安住于无住；并且严厉批评那些只是享受饮食、口说清净而不实修的人，指出真正能依理实修的人难得；然后描述如幻瑜伽士的行持，以及这种行持在今生就能见到的果。

最后一颂是回向。

本篇对"口说清净而不实修"的批评，与《除恶见》强调初业善行的精神前后呼应，可以对照着读。

体例：每颂先列藏文原颂于代码块中，再按完整的意义单元译出；为了便于理解而补的字，都放在方括号中。原文含混或可有两解之处，以"【按】"说明，不妄补内容。原文异文依校勘惯例取后一读（rdzun、'ong），下文不再一一注出。文末附通篇连读。

## 题名与礼敬

梵语题名：Māyānirukti-nāma。藏语题名：名为《幻教示》。

敬礼文殊童子！

## 一、问：众生如幻，何须解脱

```
འགྲོ་རྣམས་སྒྱུ་མ་ཇི་བཞིན་དུ། །
དངོས་མེད་ཚེ་ན་དངོས་སངས་རྒྱས། །
མཁས་པས་བདེ་བའི་བསམ་པ་ཡིས། །
འགྲོ་འདི་ཅི་ཕྱིར་གྲོལ་མ་བྱས། །
```

［有人问：］众生就像幻化一样，既然没有实体，那么［众生］实际上就是佛了；［若是如此，］具智者以利乐［众生］的意乐，为什么没有把这些众生解脱呢？

【按】这一颂是设问，用来引出下文的回答。疑问的意思是：如果众生如幻、无实，本来就是佛，那么诸佛菩萨以悲心度众，为什么众生至今仍未解脱？或者，既然本来是佛，又何须解脱？藏文"为什么没有解脱"一句，可以兼含这两层意思。"实际上就是佛"（dngos sangs rgyas），也可以读作"真正的佛"。

## 二、答：幻术师之喻

```
སྒྱུ་མ་མཁན་བྱས་སྒྱུ་མ་ནི། །
ཁྱིམ་ནི་རབ་ཏུ་འབར་བ་ལ། །
ཁ་ཅིག་ལ་ནི་བདེན་པར་སྣང་། །
སྒྱུ་མ་མཁན་བཞིན་མཁས་པས་རིག །
```

幻术师变出的幻相——一座熊熊燃烧的房子——在一些人看来是真实的；而具智者就像幻术师本人一样，了知［那是幻化］。

【按】这是对上一颂的回答：众生虽然本来如幻，但他们自己不知道，把幻化的火宅当成真的，因而真实地感受痛苦；具智者如同变幻的幻术师，清楚知道那是幻化。所以，"本来是佛"并不等于众生已经不受苦，度化众生仍然是必要的。"火宅"之喻，令人联想到《法华经》的火宅喻，但本颂的重点在于幻术师与观众对同一幻相的不同认识。

## 三、见如幻者的无勤作

```
སྒྱུ་མར་མཐོང་བས་འབད་མེད་པར། །
འདོད་པ་གང་དེ་རང་འོང་འགྱུར། །
འདི་ལ་ཐམས་ཅད་སྒྱུ་མ་སྤྱོད། །
གང་ཀུན་སྒྱུ་མར་རྟོགས་པའི་ཕྱིར། །
```

由于见到［一切］如幻，所希求的一切，不需勤作，便会自然到来。在这［如幻见］中，一切行为都是如幻之行，因为［行者］证悟了一切都如幻化。

【按】"所希求的一切自然到来"，原文有异文（rang 'ang 'gyur 与 rang 'ong 'gyur），依校勘惯例取后者，意思是"自然到来"。这里的"所希求"，从上下文看，是指利益众生等的愿求，而不是世俗的欲望；一个证悟如幻的人，既不执著所求，也就不需勤作而自然成办。"一切都是如幻之行"，也可以读作"一切众生都在行于幻化之中"，存疑。

## 四、如幻不是断灭

```
ཁྱོད་ཀྱིས་རྫུན་པར་མ་རྟོག་པར། །
སྒྱུ་མ་རྟག་པར་སྨྲ་བར་གྱིས། །
ཆོས་དབྱིངས་མ་སྐྱེས་པ་ཡི་ཕྱིར། །
ཆད་པར་ཐལ་བར་མི་འགྱུར་རོ། །
```

你不要把［一切］分别为虚假，而应当常常说［一切］如幻。因为法界是不生的，所以［如幻之说］不会落入断见的过失。

【按】这一颂与《梦教示》的思路一致：把显现断定为"虚假"、什么都没有，便落入断边；说"如幻"，则是显现仍在，只是没有自性。"不会落入断见的过失"（chad par thal bar mi 'gyur），thal ba 是辩论中"有过失、会推出某种错误结论"的意思。

## 五、如幻不是顽空

```
ཆོས་རྣམས་མ་སྐྱེས་མི་འགག་ཕྱིར། །
བེམས་པོར་གྱུར་པ་མ་ཡིན་ནོ། །
ཆོས་རྣམས་སྟོང་ཉིད་ལ་བསྐྱེད་པའི། །
སྟོང་ལས་ཆོས་ཉིད་གཞན་མ་ཡིན། །
```

因为诸法是不生不灭的，所以［如幻之说］并不使［诸法］成为无知的物质。诸法就生起于空性之中，而法性并不是在这空性之外的另一种东西。

【按】"无知的物质"（bems po），指如木石一般没有觉知的东西。这里的意思是：说诸法不生不灭，并不是说一切变成了一无所知的顽空；空性之中仍有显现生起。后两句的藏文"ཆོས་རྣམས་སྟོང་ཉིད་ལ་བསྐྱེད་པའི། སྟོང་ལས་ཆོས་ཉིད་གཞན་མ་ཡིན"，可以理解为"诸法生起于空性中，那空性与法性并非异体"，也可以理解为"诸法在空性中生起，而诸法的法性不外于空性"；两种读法要点一致：显现与空性不二。

## 六、佛的无勤作事业

```
དེ་ཡི་ཕྱིར་ན་ཀུན་མཁྱེན་གྱིས། །
སངས་རྒྱས་ཉམས་པར་མི་མཛད་དོ། །
འབད་མེད་དབང་གིས་ཐམས་ཅད་དུ། །
ཆོས་ཀྱི་འཁོར་ལོ་བསྐོར་བའང་འཇུག །
```

因此，一切智者不会使佛［的境界］有所损减；［同时，］以无勤作的力量，也于一切处转动法轮。

【按】"不会使佛［的境界］有所损减"（sangs rgyas nyams par mi mdzad），意思是：佛虽然显现度化众生的种种事业，但并不因此离开或损减佛的法身境界；反过来说，安住于法身，也不妨碍于一切处转法轮。这正是"如幻"之见在果位上的体现：显现与空性不二，事业与寂静不二。这也回应了第一颂的问题：佛正是在如幻的了知中，无勤作地度化如幻的众生。另一种读法是"不会使众生的佛性有所损减"，存疑。

## 七、瑜伽士的安住

```
རྐང་པ་བརྐྱང་བ་སྤངས་ནས་ནི། །
ང་རྒྱལ་ལ་སོགས་བཏང་ནས་ཀྱང་། །
གནས་མེད་གནས་ལ་ལེགས་གནས་ཏེ། །
རྣལ་འབྱོར་པ་ཡིས་ཆོས་ལ་སྤྱོད། །
```

舍弃伸腿［而卧的懈怠］，也放下我慢等［烦恼］，善妙地安住于无住之处——瑜伽士就是这样行持正法的。

【按】"伸腿"（rkang pa brkyang ba），字面是"把腿伸直"，在这里应是指懈怠、放逸地躺卧，或傲慢无礼的姿态；与下一句"我慢"并列，似以前者为主，指懈怠。"无住之处"（gnas med gnas），即一切法无所住，这呼应《梦教示》所归结的"无住"。

## 八、呵斥空谈不修者

```
བཟའ་དང་བཏུང་བའི་རོ་རྙེད་ནས། །
དག་པ་ཉིད་ཀྱི་གཏམ་སྨྲ་ཞིང་། །
གང་ཞིག་སྤྱད་པ་མི་སྤྱོད་པ། །
རྫོགས་པའི་བྱང་ཆུབ་སྤྱོད་འདི་མིན། །
```

有的人尝到了饮食的美味，口中说着［一切本来］清净的言谈，却不去实践应当实践的［行持］——这不是圆满菩提的行持。

【按】这一颂批评的是这样一类人：他们以"一切本来清净""一切如幻"为口实，享受饮食，却不实际修行。这正是误解如幻之见的危险：如幻是证悟的境界，不是放逸的借口。这与《除恶见》强调初业善行、破斥"修无分别便不需善行"的恶见，是同一个意思。

## 九、实修者难得

```
སྐྱེ་བོ་དེ་ཉིད་གཏམ་སྨྲ་ཞིང་། །
སྤྱོད་པ་འདི་ལ་ཡི་རང་བྱེད། །
རིགས་པ་བསྒྲུབ་པ་ཉམས་ལེན་པའི། །
འབྱོར་པའི་སྐྱེ་བོ་རྙེད་པར་དཀའ། །
```

［很多］人谈论真性，也随喜这种行持；可是能依正理而修成、真正实修的具福之人，却很难找到。

【按】"谈论真性"（de nyid gtam smra），也可以读作"说着同样的话"，即与上一颂所批评的人一样空谈；这里依 de nyid 常用的"真性"义。"依正理而修成、真正实修"，原文 rigs pa bsgrub pa nyams len pa，也可以理解为"把正理付诸修证"。"具福之人"（'byor pa'i skye bo），'byor pa 可以是"具足［闲暇、善缘］"，也可以是"富足"，这里取具足善缘之义，即有福报、有能力真正修行的人。

## 十、如幻瑜伽士的行持

```
ས་ཡི་ལམ་ལ་ཕྱོགས་ཀྱི་གོས། །
སློང་མོའི་ཟས་ནི་ཟ་བ་དང་། །
སྐྱེ་མེད་ཆོས་ལ་བཟོད་པ་དང་། །
འབད་མེད་རྩེ་བ་འཇུག་པའོ། །
```

［以］大地为道路，［以］十方为衣服，食用乞讨得来的食物；对无生之法得忍，以及趣入无勤作的游戏——［这就是如幻瑜伽士的行持］。

【按】"大地为道路"（sa yi lam），也许是指以大地为卧处、到处游方，原文简略，存疑。"十方为衣服"（phyogs kyi gos），对应梵文 digambara（以方为衣），即不着衣服或衣不蔽体，是印度瑜伽行者、成就者离弃世俗的一种行持；这是印度苦行传统的特殊行为，不是一般修行人应当模仿的。"无生法忍"（skye med chos la bzod pa），是大乘菩萨证悟诸法无生而心安住不动的境界。"无勤作的游戏"，指证悟者自然任运的行为。这一段所描述的，是成就者的禁行，须以证悟为前提，修行人不可在未证之时照字面模仿。

## 十一、今生的果

```
ཆོས་གང་སྐྱེ་བོ་ལས་རྒྱལ་བ། །
དེ་ལ་རྒྱལ་བ་དེ་སྤྱོད་པ། །
དེ་ཡི་འབྲས་བུ་ཚེ་འདིར་ལྟོས། །
བླ་མེད་འབྲས་བུ་སྨོས་ཅི་དགོས། །
```

胜者［佛陀］所行持的，正是那超胜于一般人的法；请看这［行持］在今生就［显现］的果，更何须说那无上的果呢！

【按】前两句的藏文很难确定。一种理解是：那超胜于凡俗之人的法，正是胜者佛陀所行持的；另一种理解是：［瑜伽士］行持那超胜于凡人之法的人，就在那［法］上得胜。这里依第一种理解，存疑。后两句意思明确：这样的行持，今生就能见到功效，至于无上菩提之果，就更不必说了。

## 十二、回向

```
སྒྱུ་མ་བསྟན་པའི་བསོད་ནམས་གང་། །
དགེ་བའི་སེམས་ཀྱིས་གང་ཐོབ་དེས། །
གཉིས་མེད་འཇིག་རྟེན་ལས་འདས་པ། །
གོ་འཕང་འཇིག་རྟེན་གྱིས་ཐོབ་ཤོག །
```

以善心开示如幻［之义］所得到的一切福德，愿以此使世间［众生］都获得那无二、出世间的果位！

## 通篇连读

敬礼文殊童子！

有人问：众生就像幻化一样，既然没有实体，实际上就是佛了；那么，具智者以利乐众生的意乐，为什么没有把这些众生解脱呢？

回答是：幻术师变出一座熊熊燃烧的房子，在一些人看来是真实的；而具智者就像幻术师本人一样，了知那是幻化。

由于见到一切如幻，所希求的一切，不需勤作便自然到来；在这如幻之见中，一切行为都是如幻之行，因为证悟了一切都如幻化。

你不要把一切分别为虚假，而应当常说一切如幻；因为法界不生，所以如幻之说不会落入断见。

因为诸法不生不灭，所以如幻之说并不使诸法成为无知的物质；诸法生起于空性之中，法性并不在空性之外。

因此，一切智者不会使佛的境界有所损减，同时以无勤作的力量于一切处转动法轮。

舍弃伸腿而卧的懈怠，放下我慢等烦恼，善妙地安住于无住之处——瑜伽士就是这样行持正法的。

有的人尝到了饮食的美味，口中说着清净的言谈，却不去实践应当实践的行持，这不是圆满菩提的行持。

很多人谈论真性，也随喜这种行持；可是能依正理而修成、真正实修的具福之人，却很难找到。

以大地为道路，以十方为衣服，食用乞讨得来的食物，对无生之法得忍，趣入无勤作的游戏——这就是如幻瑜伽士的行持。

胜者所行持的，正是那超胜于一般人的法；请看这行持在今生就显现的果，更何须说那无上的果呢！

以善心开示如幻之义所得到的一切福德，愿以此使世间众生都获得那无二、出世间的果位！

《幻教示》，阿阇黎无二金刚造，圆满。印度堪布金刚手与译师比丘戒胜译出。
