# 《大宝积经》卷第二（三律仪会）

唐·三藏菩提流志 奉制译

## 三律仪会第一之二

### 末世诈现菩萨行者

“再者，迦叶！到那时，有人假装修菩萨行，便自我标榜，生起放逸。生起放逸之后，自以为胜过独觉和阿罗汉，安住于非理之中，这名为不可救治的人，将堕入恶趣。

“再者，迦叶！未来有人安住于不正当的事业，由于作不正当的事业，取着众生之相而为人说法，到处游行，只修相似的行持：极其相似的布施、持戒、安忍、精进、静虑、般若波罗蜜，炽盛地流布开来。如果有人如实宣说这部经，就会被他人憎恶嫌弃、排斥舍弃，他们对这部经生起邪见之想。这些愚痴的人，不知道这部经是在呵责破戒。迦叶！到那时，他们都被贼行所秽污，因此那些人不思惟自己的过失，能严重地破坏正等菩提；由于覆藏自己的过错，心怀羞愧，反而诽谤无上佛果。

“再者，迦叶！到那时，他们不随顺僧团，不知报恩，而去行‘开发’。什么叫开发？就是开发他人的心。如来说，他们频频以言语诳惑他人，来招致饮食。

【按】此段异译《大方广三戒经》作：“多不知恩，勇健为恶。作何等恶？数数言说，称佛名号以致供养。”可参看。

“迦叶！到那时，他们不守护语言，呵毁如来的别解脱戒，又与不守护语言的人共同从事，不收摄威仪，住在不清净之处，为住在不清净之处的人宣说种种法门，这个法将渐渐被人轻贱。就这样，渐渐有很多女人舍弃丈夫，进入寺舍，为了听法而就座。这时，有比丘便为她们宣说相似的涅槃。

“迦叶！我观察那时，有五百种非法之门，不修行的人常常随顺；五百种烦恼丝毫没有减少，所作所为与世俗人没有分别。将会有这样大可怖畏的事，而他们还在其中希望得到利益。

### 求菩提者应远离与亲近之法

“所以，求菩提的人，不应当亲近比丘尼，也不应当行这样的行为。应当常常舍离一切交游，在一切时中舍弃利养，受持乞食之行；舍弃所喜爱的衣服，受持粪扫衣；舍弃一切楼阁、房舍、床铺、卧具，应当住在溪涧、岩窟、树下；舍离一切因病而求的医药资具所需，依止陈弃药；了知一切众生往昔都曾是自己的亲属，而行大慈心；常常应当忍受捶打呵骂，始终不捶打、毁骂他人；舍离一切知友、施主及诸眷属之家，应当随顺自己的业而行于智慧，不应与那些在家俗人相同；常常应当顺从奉行波罗提木叉的教诫。

【按】“谿㵎”之“㵎”，即“涧”字，先前电子文本作“溪涧”。

“迦叶！世间如果有人对别解脱戒生起违背之想，就是对佛的力与无畏生起违背；他如果对佛的力与无畏生起违背，就是对过去、未来、现在诸佛生起违背，由此在未来所受的异熟果报，是无量的大苦。假使三千大千世界的一切众生都受地狱之苦，与前面那个众生所受的苦毒相比，百分不及其一，千分不及其一，百千俱胝分，乃至算数分、譬喻分、优波尼沙昙分，也不及其一。如果想要远离这样的苦恼，应当远离这一类恶行。对于这样的比丘，即使相距千踰缮那之远，也应当远远避开，何况近处呢？如果只是听到他的名字，尚且应当舍弃，何况见到、听到了而不远离呢？

“所以应当亲近一法。哪一法呢？就是：一切法都无所有。如果得到诸法无所有忍，就不会亲近、供养、承事这样的恶人。

“这个人又应当亲近二法。哪二法呢？就是：求诸法本无所有，以及求诸法之性；然而也不应生起求取之心。应当怎样求呢？就像所求的一切都不可得；在不可得之中，也不应生起‘无所得’之心，那就如同邪见。像这样，远离一切三界之心，就是随顺菩提之行；远离一切相之心，就是随顺菩萨之行。所谓菩萨行，就是前面所说的菩萨行。

“所以，听闻这个法之后，就应当舍离那些恶人，那么在来世，就能亲自奉事弥勒世尊，心既不贡高，也不卑劣，并且唱言：‘真是快乐安乐啊！我已经解脱了魔的罗网和种种恶趣。’

### 闻经信受者，付嘱弥勒

“迦叶！如果在后世听闻这部经典，不惊不怖，并且见到自身在其中随顺，又能发心受持这个教法，佛就知道这个人必定会守护我的正法。

“迦叶！譬如一位长者，财宝无量，他的儿子在家中，乃至见到一个盛水的器皿，都生起‘这是父亲的财物’之想。后来，他的父亲去世，资财散失，儿子忽然见到那个器皿，随即心想：‘这是我父亲的东西。’就把它放在身边，或者收藏起来。迦叶！到那时，诸比丘们也是这样，听闻这部经后，心想：‘这是如来以柔软微妙的大梵音声所演说的。’又有比丘听了加以诽谤，护持正法的比丘就说：‘这是最真实的如来所说。’那些持法者人数稀少，住处也很简陋，他们把这样的经典昼夜收藏起来，遭受到极大的诽谤。这样的人，我都知道、都见到，全都付嘱给弥勒世尊；在最后之时，他们将护卫如来的法城，其后将行无碍的大布施。

“再者，迦叶！如果善男子听闻这个法之后，随着自己的智慧而修行，成就深信与正见的众生，在未来世会遇到弥勒佛，在初会之中具足修持梵行，在最后之时也将护卫如来的法城。

“迦叶！我现在普遍观察：乃至没有见到一个人，是不曾亲近我的，却能在未来世的五十年中，听闻这部经典而不生诽谤、能够受持读诵——这是没有的事。如果在此时得以见到我身，以及奉事供养我的人，他们在来世的五十年中，将能够读诵受持这部经。不必等我赞叹他们的功德，他们自己成就一切智智、同一体性之时，随念于我，心生欢喜，这样说：‘稀有奇特啊，释迦牟尼佛！善能摄受、护念我们。’所以，迦叶！应当修学这个法。修学这个法的人，随其所乐求，一切功德都不难证得。”

### 迦叶自谓不能成佛

这时，大迦叶对佛说：“世尊！我已经究竟，不再有所志求。在这个法中，我已退于阿耨多罗三藐三菩提。我在这当中已极为知足，终究不能成就一切智智。世尊！无上菩提是稀有之事，对我们声闻来说，难以证得。”

佛告诉大迦叶说：“我不是为你说，而是现在因为你，为他人敷演。你现在不要对这样的大事生起疑惑，你们也将迅速证得无上正等菩提。

### 四法精进：言说表示皆非实有

“再者，迦叶！如果众生成就渴求正法之心、成就求法之心，渐渐地都会证得无上菩提。证得之后，为了断除一切希求之心，为众生宣说正法。

“迦叶！菩萨应当成就四法，发起大精进。是哪四法呢？什么是精进呢？就是：不求色、受、想、行、识，而求无漏法。也就是：没有地界，没有水、火、风界；不说地界，不说水、火、风界。所有的言说都名为表示，这些表示之法都不是实有，菩萨不应当把表示之法当作坚实。”

这时，大迦叶对佛说：“世尊！我们对如来实在没有疑惑。如果有人问：‘这些表示之法既然都不是真实的，那么佛的音声言说表示，也是虚妄的吗？’如果有这样的问题，应当怎样回答？”

### 未来比丘怖畏此经

佛告诉大迦叶说：“在未来世，有些比丘不修身、不修戒，心不识义理，瞋恚炽盛，言辞粗犷，对于这部经典不能受持，也不能如法读诵。为什么呢？因为他们安住于色、受、想、行、识而生心的缘故。未来的比丘安住于这部经典的表示法中，就如同安住于色、受、想、行、识而生起一样。

“又有一类比丘安住于在家之法，对于胜义谛不再有志求，就像天生的盲人，用金花鬘装饰自己的头，自己却看不见。到那时，诸比丘们也是这样，听闻这些经的言说文字尚且不能受持，何况能够进入所修的胜义呢？

“譬如幼童，无论男孩女孩，被一个大丈夫呵叱过。这些男孩女孩后来某一天，听到这个人的名字，就会惊恐怖畏。到那时，诸比丘们也是这样，听闻这些经如实地说出他们的过失，知道了却不悔改，依然乐于好的衣服，反而对这部经生起怖畏。

“迦叶！就像把一只虾蟆系在猕猴手中，这只猕猴转过脸去，不肯回头看它。到那时，诸比丘们也是这样，听闻这些经就违背而不顾，不肯住在它面前。

“迦叶！譬如野干被狗追逐，就逃向坟冢之间、洞窟、深坑。到那时，诸比丘们也是这样，听说这部经，就像野干那样逃走。所谓野干逃走，是说他们毁犯禁戒，诽谤这部经；听闻这部经后，退失道心而还家，奔驰追求欲境，趋向女人，趋向斗诤、喧杂、医术以及断事，而在其中多犯禁戒——我说这就像逃向坟冢之间；身坏命终，堕入恶趣——就像逃向洞窟；奔驰于剑叶、刀刃、枪林等诸大地狱——就像逃向深坑。迦叶！到那时，诸比丘们成就这样的野干之法，不能悟入这样的经典，只能毁谤它、宣扬它的过失，身坏命终，堕入大地狱。

【按】“諠杂”，《大正藏》作“喧”，CBETA 据高丽藏作“諠”。

### 折伏执表示者

“再者，迦叶！如果有比丘这样说：‘如果表示之法不是真实的，难道如来的言说也不是真实的吗？’他如果说：‘佛的表示名为真实，那么一切表示之法也应当名为真实。’有智慧的比丘应当问他：‘大德！你现在执取的是什么？是执取空呢，还是执取表示？’

“他如果说：‘我执取表示。’就应当回答他：‘那你就是佛了。为什么呢？因为你有言说表示之法。’

“他如果说：‘我执取空。’就应当问他：‘请为我说说，你执取的是什么样的空？为什么这样问？因为不可言说的才名为空。如果执取表示而以为是空，那么或许是在我、我所、众生、寿者这些非空之处执取为空。’又问他：‘你意下如何，你乐于一切法空吗？’

“他如果回答：‘我不喜乐一切法空。’智者就说：‘你早已失去沙门释子的身份了。为什么呢？因为佛说一切皆空、无我，不说有我、众生、寿者、数取趣。’

“他如果说：‘一切法空，我乐于空性。’就应当对他说：‘你的心尚且乐于一切法空，何况如来、应供、正等觉呢？再者，尊者！是眼是如来呢？还是耳、鼻、舌、身、意是如来呢？’他如果说：‘眼是如来，耳、鼻、舌、身、意是如来。’就应当对他说：‘那你现在也是如来了。’

“他如果说：‘眼不是如来，耳、鼻、舌、身、意也不是如来。’就应当对他说：‘仁者！你这样说，眼这一表示不是如来，乃至意这一表示不是如来，那么非表示就是如来了——我在这一点上难道还不明白吗？’

“他如果说：‘眼不是如来，也不离眼而有如来；乃至意不是如来，也不离意而有如来。’就应当对他说：‘如来所说的十二处，就是眼处、色处，乃至意处、法处，这些就是众生以及众生的名字。仁者！是眼是如来，还是不是如来呢？乃至法是如来，还是不是如来呢？’

“他如果回答：‘眼是如来，乃至法是如来。’就应当告诉他：‘照仁者所说，一切众生以及山林大地都应当是如来了。’他如果回答：‘眼不是如来，乃至意不是如来。’又应当告诉他：‘照仁者所说，如来就是法以及非法了。’

“他如果说：‘色不是如来，乃至法不是如来。’就应当告诉他：‘如果是这样，难道是以非法为如来吗？’他如果说：‘就是以非法为如来。’就应当告诉他：‘如果是这样，那么所有不孝父母、不敬沙门婆罗门及诸尊长、杀害生命、犯不与取、行欲邪行、说虚诳语、离间语、粗恶语、杂秽语、贪瞋邪见的众生，都应当是如来了。’

“他如果说：‘不是非法而是如来。’就应当告诉他：‘那么非法、非非法应当是如来了。如果非法、非非法是如来，那就没有表示了。仁者！无可表示的，就是如来啊！’

“迦叶！应当这样折伏愚人。我不见世间有人、天能与这样如法说法的人对论，除了瞋恚愚痴、不堪忍受的人：即使为他开示，他也不生信心，毁呰空法，舍弃而去。

### 持经者当得三名

“迦叶！你们应当受持这部经。在未来世，有受持这部经的比丘，将得到三种名称作为对他们的表示。哪三种呢？就是：说断灭者、说无物无蕴者，以及无恭敬者。到那时，这样的经典会被他人诽谤。

“你看那时：他们不恭敬佛，不恭敬法，只依表示、名字、语言，空担僧人之名而没有真实的德行。虽然口称佛号，为他人开示却不能理解，又怎能瞻仰奉事如来呢？虽然宣说佛法，却不能了知如来的意趣，又怎能称为善于说法呢？四双八辈是佛的弟子、声闻之僧，他们只知道这个名称，对于其功德却不知其义，不能领受依名而有的真实德行；为了衣服、饮食、卧具、病药的缘故，毁谤正法。菩萨在其中，应当勤加精进，对这些经典深深生起稀有、乐欲之心，受持读诵。为什么呢？因为这样的人在来世是护持法城的人。

“迦叶！我忆念过去九十一劫空无佛法之时，这样的经典不再流布。又忆念过去超过千劫，有佛出世，名号为休息热恼，住世八万四千劫，成熟菩萨，利益世间。又忆念过去，又有如来名号为无边力，住世二十亿劫；他在二十亿劫中行菩萨道，然后证得阿耨多罗三藐三菩提。迦叶！你看佛修习了多少难行之行来摄受众生！

### 劫浊之世与诸见

“再者，迦叶！在劫浊将尽之世，我们不应当轻贱自身。为什么呢？在劫浊之中，乃至有一个人能在我这里信解这个法，就极为稀有；一切众生不持刀杖追逐我们，也是稀有。为什么呢？因为这个法就是善丈夫之法，也就是对于诸行作无行之想，是难以了知的。

“如果有我见、众生见、命见、数取趣见、有见，如果依诸蕴而起戒见，如果有多闻见、佛见、法见、涅槃见——如果有人生起涅槃见，如来全都知道，这些见都是邪见。为什么呢？佛对于涅槃，既无分别，也无所得。如果对于涅槃生起分别、有所得，如来全都说名为邪见。如果是邪见，就名为无智；如果无智，就名为损害；如果损害，就名为愚夫；名为愚夫的人，对于大菩提就没有乐欲，乃至远离生天的胜道。

“迦叶！在未来世，将会有比丘，年纪二十、三十、四十乃至百岁，已被衰老所侵，却还装饰衣服；虽然剃除了须发，却毁坏威仪，老病衰朽，没有威光，趋向邪法。临命终时，被罪恶的意乐所障蔽，明知自己已经犯戒，却懈怠不修，而在三处示现证得。哪三处呢？或者矫饰威仪，或者假装修持清净之行，或者举手自称‘我无与伦比’。由于这三处示现有所证得，这些人都堕入增上慢中；临命终时，心生追悔；命终之后，生在地狱中。

“所以，迦叶！我现在明明白白地宣告你们：我是你们真正的善知识，乐于利益、哀愍你们，不让你们后来遭受大热恼，像慕理迦（唐言尾宿）、畔地迦（唐言路生）、波利婆罗理迦（唐言女梵志）那样遭受种种苦毒。

“迦叶！我终究不允许执著我见、众生见、寿者见、补特伽罗见的人在我的法中出家。我若不允许而强行出家的，都是贼；吃那贵重的信施，也不能成就真正的比丘戒。迦叶！宁可绝食达六日之久，也不要在我的法中出家之后，吃着贵重的信施，却生起我见、众生见、寿者见、数取趣见，乃至涅槃见。

“所以，菩萨应当发起精勤，不应执著我见、众生见、寿者见、数取趣见、有见、涅槃见，为了断除一切见，应当说法。迦叶！这样的经典，我现在付嘱给诸菩萨。为什么呢？因为他们的意乐与我相同。如果他们的意乐与我相同，就是我的伴侣；是我的伴侣，就能够承受我的付嘱。”

### 偈颂（一）

这时，世尊说偈颂道：

```
众苦所逼迫，都无能救护，
唯除世导师，无有戏论者。
诸苦恼众生，修下劣邪道，
渐增诸欲贪，由斯堕恶趣。
无导无救护，住之崄旷远，
趣向邪道中，终无安隐处。
```

（大意：众生被种种苦所逼迫，全都没有能救护的；唯有世间的导师——远离戏论的佛，才能救护。苦恼的众生修习下劣的邪道，渐渐增长对诸欲的贪求，由此堕入恶趣；他们没有引导、没有救护，住在险恶旷远之处，趋向邪道之中，终究没有安隐之处。）

```
譬如人持财，求利行远道，
于中群贼起，劫尽诸赀财。
失财已空归，为利增热恼，
所贷他人财，被债倍生苦。
斯等亦如是，为法故出家，
本所持法财，白业皆销灭。
唯净剃须发，愚堕诸见中，
执著我众生，补特伽罗想。
```

（大意：譬如有人带着钱财，为求利而走远路，途中群贼兴起，把钱财抢劫一空；他失去钱财，空手而归，为了求利反而增加热恼，从别人那里借贷的钱财，被人追债，加倍生苦。这些人也是如此：为了法而出家，原本所持的法财——种种白业，全都消灭了；只是剃净了须发，愚痴地堕入种种见中，执著我、众生、补特伽罗之想。）

### 后五十岁的恶比丘

“再者，迦叶！如来灭度之后，往昔在佛所深种善根的比丘们都已般涅槃，具有殊胜意乐的众生也都命终殆尽。后五十年正法灭亡之时，将有比丘，本性怀着贪著，猛利的贪欲覆蔽了他们的心；他们乐于离间之语，以毒害加于他人，言辞粗犷，神情惨厉，皱眉蹙额，安住于三种法中。哪三种呢？就是：医道、贩卖交易、亲近女人。

【按】“后五十岁”，明本作“五百”。

“安住于这三法，就退失四事。哪四事呢？就是：退失戒蕴、善趣、果证，以及如实见佛。由于退失这四事，又成就四法，不生厌离，炽盛增长。哪四法呢？就是：嫉妒增长炽盛，瞋恚恶心增长炽盛，耽著种族增长炽盛，贪著饮食、积聚众味。由于爱乐衣服覆蔽了心，便把衣服收藏在箱笥之中，专门从事这些事作为常业；对于沙门之法空无所获，也不能生起沙门的证道。

“他们听闻这些经典，将堕入四处。哪四处呢？就是：堕入谤法，佛所不许的反而去说，单独为女人宣说法要，毁谤如来的别解脱戒。听闻这些经典，反而更加败坏正法，而堕入生长恶业之中。

### 恶狗与愚夫服酥之喻

“迦叶！譬如一只恶狗，用苦胆汁灌它的鼻子，你意下如何？那只狗是否加倍生起凶恶之心？”

迦叶对佛说：“世尊！正是这样，正是这样。”

佛告诉迦叶：“那些恶人犹如恶狗以及毗舍遮，见到有比丘安住于清净意乐，受持这个法、宣说这个法，安住于真实少欲、赞叹少欲，对这样的人，他们不生欢喜，反而生起厌背，心怀怯弱，又生起热恼；由于瞋恚障蔽了心，便这样想：‘我们住在不适当的时候、不适当的地方，在这不适当的时候被别人轻毁。’所以，听闻这样的经典，便生起诽谤，当面加以毁辱，以瞋恚粗暴的言语说：‘这不是佛教！’这类人受用的是多欲的因缘，不是少欲的人。

“迦叶！我以种种名称赞叹少欲与喜足，称之为易养，也称为易满，称为净除者、行头陀者、极端严者。我也赞叹住阿兰若者、发精进者、遍净命者。你们不应当多修贮藏、积聚箱箧等法。为什么呢？因为应当修习这样的法。你们不应当像铜钹那样，空有其声，应当随顺如来，修行这个法。也不应当生起深重的瞋恚，也不应当摄取事物，应当安住于无事无物。不要对处所生起住著之心，应当无所住。不应当自我赞叹，也不应当畜养牛、驴等类，不应当成就安住于懈怠之处，应当发起殊胜的精进，舍离不善，摄受善法。

“迦叶！我以种种名称赞叹寂静、住阿兰若、不处愦闹，现在在这里又以种种名称宣说极净除之行。如果有不安住于极净除、有大欲望、造成罪恶的人，就会诽谤那些安住于极净除的人。

“迦叶！譬如愚夫在四个月中服酥，因而口渴，随即前往池边求水而饮。别人告诉他说：‘你已经服了酥，不要再喝水，否则会丧命。’这时愚夫由于瞋恚覆蔽了心，毁呰骂詈，不听别人的话，喝了水而死去。迦叶！正是这样，正是这样：未来的比丘贪著有见，安住于不善之行；有持法的人这样教导说：‘这是应当做的，这是不应当做的。’那些恶比丘由于瞋恚覆蔽了心，便毁呰骂詈，诽谤这部经典。

【按】“尋詣池所”之“池”，宋、元、明、宫本作“他”。

“迦叶！如今在如来面前尚且多有诤竞，何况未来呢？你且看这位贤护比丘：如来制戒，让诸比丘受持一坐食，他由于瞋恚覆蔽了心，在夏季三个月中不到我这里来。迦叶！如今在我面前尚且有这样轻视梵行的人，何况佛灭度之后，贪著饮食、衣钵、病药，被睡眠所覆盖，瞋恚猛利——这样的比丘听闻这个法之后，尚且不恭敬如来大师，又怎能恭敬那些持法的比丘呢？

“迦叶！这名为不善，也名为极恶，这样的法宝即将隐没。其中如果有求大利益、信我教法的善男子、善女人，在后来滓浊的末世、正法极为覆藏、善人难得之时，听闻这样甚深的法之后，应当为如理的人说，不为不如理的人说；为有信心的人说，不为没有信心的人说。我现在也是为如理的人说，不为不如理的人说；为有信心的人说，不为没有信心的人说。

### 被善甲

“迦叶！譬如劣马不肯接受披甲，如果与良马一同披甲，反而生起惊怖，何况再听到螺贝、鼓声，要它能够承受，是没有这个道理的。正是这样，正是这样：破戒的比丘，没有任何时候能够忍受善丈夫之法，就像劣马反而生起惊怖一样。迦叶！破戒的比丘，乃至听说一句‘诸法无我’，由于执著我想，便在其中生起怖畏与诤竞，何况听说披上善妙的铠甲呢？

“如果披上了铠甲，就能降伏百亿魔军，使它们毕竟不再生起斗诤。诸位善比丘披上精进之甲：不破坏根本的头陀功德，以净除为根本，以无贪、恚、痴为根本，以无嫉妒为根本，以离欲为根本，以独处之性为根本，以觉寤为根本；在一切时、一切种中，不应发起瞋恚与贪心，对种种事物无所希求——这样的披甲，名为无根本。

【按】“𭔋寤”之“𭔋”，原字作组字式［宋-木+悎］，先前电子文本未能显示，今据《大正藏》补出；元、宫本作“寤”。

“如果披上了这样种种的铠甲，就应当发起无上菩提之心，对于一切处都不应执著，何况生起我想呢？所以，不应生起我想、众生想、寿者想、数取趣想、女想、男想、地水火风想、欲界色界无色界想、持戒想、破戒想、空性想。简要地说，一切诸想都不应生起，因为一切想都无所得。

### 贪非实有，著想如须弥

原文：“迦叶！贪若实有则应了知，近之令灭贪爱之心，非住一处无住可得，唯除妄语，是故如来名实语者。”（大意：迦叶！贪如果是实有的，就应当能了知它，接近它而令贪爱之心灭除；然而贪并不住于一处，没有住处可以得到，除非是妄语才说它有，所以如来名为实语者。）

【按】此句异译《大方广三戒经》作：“若贪欲不实，知灭欲者亦复不实。迦叶！欲无定处但虚妄说，是故如来如实而说。”可参看。

“如来说，一切所有的贪都是非我。像这样的诸法，就是沙门之法；一切沙门之法都无所得。如果又有人执著这个想，这个人就是执著我想等，大如须弥山，退失圣教，丝毫不能生起沙门之法，也不能安住于沙门之法。这样广大最殊胜的法，对于那些被愚痴所衰损的愚夫，丝毫也不应当说。为什么呢？如果执取少许法，就会摄受极可怖畏之处，在大地狱中住上一劫。

“迦叶！你看俱迦利比丘（唐言恶时者）、提婆达多比丘（唐言天授）、骞荼达罗比丘（唐言鈌财）、迦卢底输比丘（唐言器鬼宿）、母达罗多比丘（唐言海授）、阿湿繁比丘（唐言马腾）、布那婆苏比丘（唐言柳宿）、苏气怛罗比丘（唐言善星），他们是我的给侍，亲自对着我，听我说法，见我经行，见我端坐，见我以神足游于虚空，见我在大众中降伏数千外道、摧破他们的邪法。像这样的人，尚且对我不生信乐，每走一步都总想毁谤我，因此一步一步渐渐增长他们的恶业。

“再者，如果有人说起佛的名号而信为真实，应当拿着像须弥山那样大的上妙器皿，盛满栴檀末，撒在他的身上；应当做一顶像三千大千世界那样大的伞盖，持在空中覆盖在他的上方。为什么呢？因为他信佛的缘故。何况信了之后舍弃诸欲而出家，无所依倚，修习种种静虑呢？迦叶！这样的众生能在其中忍可，极为稀有；能善于护持佛所制定的戒律，就能了知那甘露之法。

### 我想与瞋恚：皮革人像之喻

“譬如在大众之中，用皮革和其他臭秽之物共同制作人像，或者造出种种不同的面具，彩画装饰，使它极其端严。有人拿着它戴在脸上，或者用衣物缠裹着到处游行。难道因为它的相貌就说它好吗？仔细了知它的污秽丑恶，便会生起厌离。正是这样，正是这样：那些恶比丘，以如来威德的容仪装饰得整齐庄严，仔细观察，才知道他们极为丑恶，是由于自他的我想而生起贪爱。

“如果有人了知我想不是真实的，听闻这些经就不生瞋恚。为什么呢？因为即使被他人毁呰违逆，听闻这些经也会加倍增长厌离。如果有众生心怀执著，应当知道，他就是邪见之人；如果生起邪见，对于这些经如实的教诲，就会生起瞋恚。为什么呢？因为有我想的人就有瞋恚。

“如果有比丘、比丘尼、优婆塞、优婆夷，听闻这些经而瞋恚、毁坏、诽谤，就不是沙门。虽然说他有沙门之名，却不是我的声闻，我也不是他的老师。为什么呢？我的声闻不说妄语，我不是妄语者的老师。为什么呢？因为如来是实语者，是能如实宣说一切法空的人。

### 非类之喻

“迦叶！如来能破除我执，与之斗诤；如果与如来相诤的，名为恶魔，如来不允许魔众出家受具足戒。如果有人说：‘青雀小鸟生出了大龙象。’你意下如何？这样的话可信吗？”

迦叶回答说：“不可信，世尊！”

佛告诉迦叶：“你意下如何？它们是同类吗？”

迦叶回答说：“不是同类。”

“再者，迦叶！又如有人说：‘妙翅鸟王生出了飞鸟。’你意下如何？可信吗？是同类吗？”

迦叶回答说：“不可信，世尊！也不是同类。”

“再者，迦叶！又如有人说：‘萤火小虫背负须弥山飞向空中而去。’你意下如何？可信吗？是同类吗？”

迦叶回答说：“不可信，世尊！也不是同类。”

佛告诉迦叶：“像这样的恶人，如果安住于我想，乃至涅槃想，却称我为师，就更加不是同类。

### 诈宣王制之喻

“迦叶！譬如有一位帝王安住于国土，抚育群生，快乐无极，种种饮食自然成办，身旁有侍臣奉行国王的正当教化。这时有一个大家都不曾认识的人，为了财利而模仿大臣的做法，并不禀承王命，却在大臣和国王等众人之中假传王的制令，这样说：‘你们应当住在这里。’或者说：‘你们去做这样的事。’

“迦叶！如来法王也是这样：君临大千世界，摄化一切三乘众生，十力功德圆满成就，作种种佛事，安乐无边，饮食供养自然丰足。其中有一类大家都不曾认识的人，为了活命而宣说我、众生，乃至涅槃，不接受如来无我的圣教，这样说：‘如来所说，这件事应当做，这件事不应当做。’其中有人信佛、顺从教法、不诽谤，听了他们所说的话，认为他们是殊胜微妙的清净福田，便节省自己的资财以及妻子儿女的份额，以殷重的信心如法布施，乃至在没有察觉他们种种过失以前，从来没有断绝。

“这样的恶人，就像那个众人不曾认识的人一样：吃完饭后，就在热闹的聚集之处，天天谈说国王的事、盗贼的事、饮食的事、淫欲的事、女人的事、医方的事、饮酒的事、日月薄蚀的事、国王来去的事、种族的事等；或者说：‘某某吉日应当到别人那里去，会得到饮食。’像这样种种言谈，推度着昼夜过日子；回到僧伽蓝，或者经过两夜，乃至六夜，在所住之处也常常谈说这些事。没有正念与智慧，失坏威仪，昏沉愚痴地睡眠，口涎流溢；随着心中所想象的，在睡梦中见到，或者梦见自己前往别人那里，快走、慢走等种种事情。醒来之后，互相对着说：‘我梦见你的身体如此行、如此坐，从某处得到了什么、没得到什么。’又有人说：‘这个梦吉祥，应当及时赶快前往村邑王城。’到了别人家里，出入往来，摇动面目；由于被苦所逼恼，心不安和，没有等引之定；贡高自大，诸根杂乱，与世俗人没有分别；言语不合时宜，心多驰散，乐于游走世俗乡里、各族姓之家，不能奉持别解脱戒；单独为女人宣说法要，在说法时心住于贪染，而在其中增加获得利养；染著之心犹如噬咬，愚痴耽爱，越住越执著，从不生起悔心，所以在离别时啼泣而去。

【按】“日月博蚀”之“博”，宋、元、明、宫本作“薄”，今依“薄蚀”（日月亏蚀）义译出。“𭔋寤”，宋、宫本作“𭔏𡩺”，元本作“𭔋𡩺”。

“又在两处向他人开示。哪两处呢？得到洁净美好的布施，就赞叹；得到不洁净美好的，就毁呰。相会遇时，互相看彼此所得到的东西，又互相问：‘施主现在施了什么东西？施给了谁？饮食资财有多少？’迦叶！应当知道，这就叫作不修行的人。乃至直到命终所说的话都是如此。不修行的人还有其他过失，就是生起恶意乐，也就是诽谤正法。迦叶！对于这样的比丘们，应当生起怜愍之心。为什么呢？因为他们将要遭受苦恼的果报。”

### 偈颂（二）

这时，世尊说偈颂道：

```
愚夫缘活命，随学帝王臣，
故往诣余处，诈宣王制令，
至彼传密言，勿致王瞋罚。
愚人于此处，亦以活命缘，
何况最胜佛，于多百劫中，
舍身支节等，及作多难事。
```

（大意：愚夫为了活命，模仿帝王的大臣，故意前往别处，假传王的制令，到了那里传达秘密的言语：“不要招致国王的瞋怒惩罚。”愚人在这里，也是为了活命的缘故——何况最殊胜的佛，在多百劫中舍弃身体支节等，作了种种难行之事。）

```
我非法王家，僮仆被谪罚，
亦无问者能，为作为不作。
施与比丘房，上妙美珍馔，
及施上妙衣，一切恭敬与。
勤苦求财物，奉施持戒人，
不以自供身，亦不将供子，
```

（大意：“我非法王家”四句存疑，照字面是说：我这法王之家，并没有僮仆受谪罚之事，也没有谁能追问“是作还是不作”。其下是说：施主布施比丘房舍、上妙的美味珍馐，又布施上妙的衣服，一切都恭敬地给予；他们勤苦求得财物，奉施给持戒的人，不用来供养自己，也不拿来供养子女。）

【按】“我非法王家”四句，异译《大方广三戒经》作：“此非我法王，令住是谪罚，亦无有问者，为当作不作。”诸本、古注都未见解释，今照字面译出。

```
不如法住者，食之便舍去，
共相会遇时，言我快意噉。
所在聚集处，说王事贼事，
关逻镇守事，种种饮食论，
说日月博蚀，及王来去事。
或言当得胜，或说当败亡，
此非所应言，常共数论说。
```

（大意：不如法而住的人，吃完就离去；共相会遇时，说：“我吃得真痛快。”在所到的聚集之处，谈论国王的事、盗贼的事、关卡巡逻镇守的事，种种饮食的议论，谈论日月亏蚀以及国王来去的事；或者说“将会得胜”，或者说“将会败亡”——这些都是不应当说的话，他们却常常一起屡屡谈论。）

```
极妙卧具上，昼夜耽睡眠，
昼往善人家，求多富有处。
言此施非少，亦非为最上，
寻思是事已，安敷空坐谈，
愚惰不勤修，如驴恒负重。
而于眠梦中，见所分别相，
觉已宣示他，相向益谈说。
言勿忧勿笑，汝当得安乐，
此事宜速成，勿复生忧恼。
```

（大意：在极其美妙的卧具上，昼夜耽于睡眠；白天前往善人之家，寻求多有富裕之处，说：“这家的布施不算少，也不算最上。”寻思这些事之后，安然敷座，空坐闲谈；愚痴懒惰，不勤修行，就像驴子常常负着重担。在睡梦中，见到自己所分别的种种相，醒来之后向别人宣说，互相对着更加谈论，说：“不要忧愁，也不要笑，你将会得到安乐，这件事应当赶快去办，不要再生忧恼。”）

```
数往于村邑，动止无威仪，
喻若行猕猴，回转于面目。
入于聚落内，为女说法言，
弃舍佛契经，及善别解脱。
既从施家出，观其物少多，
见少则骂他，亦毁他眷属。
于相会遇时，发言互相问，
得何物何食？相问答何事？
略说如是事，经于百年中，
如是所寻思，以为自活命。
```

（大意：他们屡屡前往村邑，举止没有威仪，就像行走的猕猴，转动着面目。进入聚落之内，为女人说法，却舍弃了佛的契经和善妙的别解脱戒。从施主家出来之后，察看所得东西的多少，见少就骂人，也毁谤人家的眷属。在相会遇时，开口互相询问：“得到了什么东西、什么饮食？”相互问答的就是这些事。简略地说，像这样的事，经过百年之中，以这样的寻思来作为自己活命的方式。）

```
争蒲桃酒味，及以香华等，
为药疗其身，求之少病恼。
假令有百佛，无能奈彼何，
弃舍所修行，与在家无异，
于身生保爱，不离于我人。
彼作是修行，由斯堕恶趣，
若人谤正法，重苦所烧然，
无觉慧愚夫，与在家无别。
```

（大意：他们争着葡萄酒的美味以及香花等，说是作为药物来疗养身体，求得少病少恼。即使有一百尊佛，也对他们无可奈何：他们舍弃了所修之行，与在家人没有差别，对自己的身体生起保护爱惜，不离我、人之见。他们这样“修行”，由此堕入恶趣；如果有人诽谤正法，就会被重苦所焚烧。没有觉慧的愚夫，与在家人没有分别。）

【按】“不离于我人”之“人”，明本作“法”。

```
若诸释师子，修实行声闻，
不以活命缘，毁犯微少戒。
智者不贪食，常生重檐想，
不净观修心，以还施主债。
舍离欲漏故，了知一切想，
我听如是等，此教中出家。
```

（大意：至于那些释迦狮子的、修真实行的声闻，不会为了活命的缘故，毁犯哪怕微小的戒律。有智慧的人不贪饮食，常生起“负着重担”之想，以不净观修心，以此来偿还施主的债。由于舍离了欲漏，了知一切想，我允许这样的人在这个教法中出家。）

【按】“重檐”之“檐”，宋、明本作“担”。

```
智人不诽法，于所说空性，
数数起勤求，不可得坚实。
勇健大智人，了知空性理，
能怖畏魔军，彼堪销供养。
若能离贪染，不毁于空性，
佛子勇健人，两足中应供。
```

（大意：有智慧的人不诽谤正法，对于所宣说的空性，屡屡生起勤求，而了知其中没有坚实可得。勇健而有大智慧的人，了知空性之理，能令魔军怖畏，他们才堪能消受供养。如果能远离贪染，不毁坏空性，这样勇健的佛子，在人中堪受供养。）

```
正法不久住，生世多愚痴，
少柔和比丘，求不放逸者，
智者应生忧，不久自磨灭。
后于昼夜间，谈说曾有我，
世间无救护，唯除两足尊，
修行学处人，悉皆当灭没。
```

（大意：正法不能久住，生于世间的人多是愚痴，柔和的比丘、求不放逸的人很少。智者应当生起忧虑：“不久之后，正法将自行磨灭。”此后昼夜之间，谈说曾有我（此句存疑，照字面保留）；世间没有救护，唯有两足尊能救护，而修行学处的人，都将灭没。存疑。）

【按】此段异译《大方广三戒经》作：“智者作是虑：‘不久速至死，我夜当云何？昼亦如是尽。世更无救护，唯除二足尊，诸学及无学，皆悉当灭度。’”可参看。

```
彼不了如是，所有密意言，
则不恭敬佛，及无上正法。
正法当尽灭，应速发精勤，
乃至少时间，听闻当不久。
```

（大意：那些人不了解这样所有的密意之言，于是不恭敬佛和无上正法。正法将要灭尽，应当迅速发起精勤；乃至能听闻的时间也很短暂，不会长久了。）

【按】本卷相当于异译《大方广三戒经》卷上末段至卷中终。
