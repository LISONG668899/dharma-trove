# 风之真如道歌

阿阇黎摩希巴造　据藏文译出

## 题解

本篇梵名 Vāyutattvadohagītikā，藏名 rlung gi de nyid kyi do ha'i glu，即《风之真如道歌》，收于德格版丹珠尔续部释 ཟི 函第 5a 至 5b 页（东北目录 D2350）。跋语说是"从阿阇黎黑行者传承下来的阿阇黎摩希巴所造"，没有记载译者。

摩希巴（Mahipa）是八十四成就者之一。依成就者传记，他原是一个力大无穷、以勇力自负的人，从上师得到教授后，以自己的力量与骄慢为道而成就。篇末说他从"持颅器的黑行者"那里得到口诀，与跋语相应。本站已译黑行者的《道歌宝藏（黑行者）》（D2301）、《道歌宝藏广释（黑行者）》（D2302）等，可以互参。

全篇约四十句，是以情歌口吻写成的道歌：作者向"俱生的喜女""俱生的美女"倾诉，以"请作我的见证""三有一旦剧烈动摇，又怎么能再与你相逢"为叠句。这里的"喜女""美女"，象征俱生智，也是圆满次第明妃的隐语。全篇的意思是：心安坐于风之宫殿的金刚座上；俱生智就在自身，不必外求；死时三有动摇，若未认出就难再相逢；即使净化了五部之城，造作的修法也见不到它；最后从黑行者得到口诀，断除三有之缚。

关于密乘内容的告诫：题名"风之真如"与第一节"风之宫殿"，涉及圆满次第风息与心的修持；第五节"需要手印"，可能涉及事业手印。全篇的"喜女""美女"都是象征语言。这些都须在具德上师座前，依灌顶与口授理解，不可照字面揣测或效仿。

体例：藏文原文全部保留在代码框中，按意义分节，每节后附汉译；叠句照原文每次重复。凡标"存疑"的按语，表示本译对原文意思没有把握。藏文依 Esukhia 德格丹珠尔电子版。

## 一、风之宫殿，心之金刚座

```
བརྟན་གཡོ་རླུང་གི་གཞལ་ཡས་ཁང། །
སེམས་ཀྱི་རྡོ་རྗེ་གདན་དུ་བཞུགས། །
སྟོང་པ་ཉིད་ནི་ཟབ་མོ་ལ། །
ཀྱེ་ཧོ་ལྷན་ཅིག་སྐྱེས་པ་ཡི། །
དགའ་མོ་བདག་གི་དཔང་དུ་གསོལ། །
```

在动与不动的风之宫殿里，安坐于心的金刚座上；对于甚深的空性——嗟吙！俱生的喜女啊，请作我的见证！

【按】"风之宫殿"，指身体，或指风息所运行的脉道；"心的金刚座"，比喻心性坚固不动，如释迦牟尼成道的金刚座。全篇题名"风之真如"，正是从风息与心的关系入手。

【按】"俱生的喜女"（ལྷན་ཅིག་སྐྱེས་པའི་དགའ་མོ），与下文"俱生的美女"（མཛེས་མ），在道歌传统中常象征智慧、空性，或俱生智本身，也是圆满次第明妃的隐语。作者以情歌的口吻向她倾诉，表达对俱生智的渴求。这是象征语言，不可照字面理解。

## 二、三有动摇，何能再逢

```
སྲིད་པ་འདི་ནི་རབ་གཡོས་ན། །
སླར་ཡང་ཇི་ལྟར་ཕྲད་པར་འགྱུར། །
སྐྱེ་བོ་ལྷན་ཅིག་སྐྱེས་པ་ཡི། །
མཛེས་མ་བདག་གི་དཔང་དུ་གསོལ། །
ཁྱེད་ནི་བཞུགས་ན་བདག་གིས་ནི། །
ཇི་ལྟར་བདག་གིས་གཞན་ལ་བཙལ། །
```

这三有一旦剧烈动摇，又怎么能再相逢呢？［众生］与俱生之美女啊，请作我的见证！你既然就安住［在这里］，我又怎么会到别处去寻找呢？

【按】"三有剧烈动摇"，一般理解为死亡之时，风息离散、身心崩解；那时如果还没有认出俱生智，就再难相逢。这是劝人趁此生及时认识心性。

【按】"你既然就安住在这里，我又怎么会到别处去寻找"，是全篇的眼目：俱生智就在自身，不必外求。

【按】存疑。第十三句"སྐྱེ་བོ་ལྷན་ཅིག་སྐྱེས་པ་ཡི"，与他处叠句的"ཀྱེ་ཧོ"（嗟吙）不同，作"སྐྱེ་བོ"（众生、人），可能是"ཀྱེ་ཧོ"的讹写，今照原文补译为"［众生］"。

## 三、船将沉没，欲导正道

```
གྲུ་ནི་འབྱིང་བར་འགྱུར་བ་ལ། །
ཡོངས་སུ་དྲང་བར་འདོད་པ་ལ། །
ཀྱེ་ཧོ་ལྷན་ཅིག་སྐྱེས་པ་ཡི། །
དགའ་མོ་བདག་གི་དཔང་དུ་གསོལ། །
སྲིད་པ་འདི་ནི་རབ་གཡོས་ན། །
སླར་ཡང་ཇི་ལྟར་ཕྲད་པར་འགྱུར། །
```

船就要沉没了，想要把它引回正道——嗟吙！俱生的喜女啊，请作我的见证：这三有一旦剧烈动摇，又怎么能再与你相逢？

【按】"船就要沉没"，比喻轮回中的身心随时会沉溺于苦海；"引回正道"，指以风息与心的修持调伏它。

## 四、净遍五部之城，不见尊颜

```
ཁྱེད་ཀྱི་སླད་དུ་བདག་གིས་ནི། །
རིགས་ལྔའི་གྲོང་ནི་བསང་བྱས་ཀྱང། །
ཁྱོད་ཀྱི་ཞལ་ནི་བདག་གིས་ནི། །
སྐད་ཅིག་གཅིག་ཀྱང་མ་མཐོང་ངོ། །
ཀྱེ་ཧོ་ལྷན་ཅིག་སྐྱེས་པ་ཡི། །
དགའ་མོ་བདག་གི་དཔང་དུ་གསོལ། །
སྲིད་པ་འདི་ནི་རབ་གཡོས་ན། །
སླར་ཡང་ཇི་ལྟར་ཕྲད་པར་འགྱུར། །
ཀྱེ་ཧོ་ལྷན་ཅིག་སྐྱེས་པ་ཡི། །
མཛེས་མ་བདག་གི་དཔང་དུ་གསོལ། །
```

为了你，我虽然净化了五部之城，却连一刹那也没有见到你的面容。嗟吙！俱生的喜女啊，请作我的见证：这三有一旦剧烈动摇，又怎么能再与你相逢？嗟吙！俱生的美女啊，请作我的见证！

【按】"净化五部之城"，可能指以生起次第观修五方佛部，或以风息净化五蕴、五大。作者说虽然做了这些修持，却仍未见到俱生智的面容，意思是：一切造作的修法，都不能直接见到俱生。这与萨惹哈"以造作的心得不到瑜伽"同一意趣。

【按】存疑。"五部之城"所指，本译只作推测。

## 五、须得手印，不存种姓之念

```
ཁྱེད་ཀྱི་སླད་དུ་བདག་གིས་ནི། །
ཕྱག་རྒྱ་དགོས་ཏེ་ཅུང་ཙམ་ཡང། །
རིགས་ངན་བྲམ་ཟེའི་བསམ་པ་མེད། །
ཀྱེ་ཧོ་ལྷན་ཅིག་སྐྱེས་པ་ཡི། །
དགའ་མོ་བདག་གི་དཔང་དུ་གསོལ། །
སྲིད་པ་འདི་ནི་རབ་གཡོས་ན། །
སླར་ཡང་ཇི་ལྟར་ཕྲད་པར་འགྱུར། །
```

为了你，我需要手印；对于下贱种姓与婆罗门，一点分别之念也没有。嗟吙！俱生的喜女啊，请作我的见证：这三有一旦剧烈动摇，又怎么能再与你相逢？

【按】"需要手印"，在这里可以理解为需要大手印（证悟），也可以理解为圆满次第的事业手印。"对下贱种姓与婆罗门没有分别"，是说在俱生智面前，净与不净、贵与贱的分别都已放下，与里拉巴《断分别之歌》、巴德《俱生喜见》同一意趣。这一节涉及密乘方便道，须依灌顶与上师口授理解，不可照字面揣测或效仿。

## 六、从黑行者得口诀，断三有之缚

```
རྒྱ་མཚོའི་ནང་དུ་གཟིངས་བཅས་པ། །
ཐོད་པ་ཅན་ན་ཀ་ཧྞ་ལས། །
མ་ཧིས་གདམས་ངག་ཐོབ་པར་འགྱུར། །
སྲིད་པའི་བཅིང་བ་ཡོངས་སུ་བཅད། །
ཀྱེ་ཧོ་ལྷན་ཅིག་སྐྱེས་པ་ཡི། །
མཛེས་མ་བདག་གི་དཔང་དུ་གསོལ། །
```

在大海之中，有船有筏；摩希从持颅器的黑行者那里，得到了口诀，彻底斩断了三有的束缚。嗟吙！俱生的美女啊，请作我的见证！

【按】全篇以得到上师口诀作结：前面说船将沉没，这里说在大海中得到了船筏，就是上师的口诀。"持颅器者"（ཐོད་པ་ཅན），指以颅器为法器的瑜伽士，即黑行者（Kāṇha，梵 Kṛṣṇa），本站已译他的《道歌宝藏（黑行者）》等多篇。

【按】存疑。"ཀ་ཧྞ"，应是"ཀཱ་ཧྣ"（Kāṇha，黑行者）的异写，与跋语"从阿阇黎黑行者传承下来"相应。
