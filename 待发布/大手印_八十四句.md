# 八十四句

瑜伽大自在吉祥毗瓦巴（Virūpa）造　据藏文译出

## 题解

《八十四句》（梵 Śrīvirūpapadacaturaśīti，藏 dpal bir+wa pa'i tshig rkang brgyad cu rtsa bzhi pa，直译"吉祥毗瓦巴的八十四句"）收于德格版丹珠尔续部释 ཞི 函第 138a 至 139a 页（东北目录 D2283），紧接在黑行者《五颂》（D2282）之后。跋语说是"瑜伽大自在吉祥毗瓦巴"所造，由"生于南方憍萨罗的瑜伽大自在吉祥毗卢遮那金刚"亲自译出并宣说。毗卢遮那金刚也是《道歌宝藏（毗瓦巴）》（D2280）的译者。

题名中的"八十四句"（tshig rkang brgyad cu rtsa bzhi），是说全篇由八十四个偈句组成；实际数下来，从礼敬句到最后"诸持口诀者请听"，共八十三句，与题名相差一句，可能是计算方式不同（例如把礼敬句或某一长句算作两句），或传写时脱了一句，存疑。

全篇的结构与毗瓦巴《道歌宝藏》前半相近，但批评的范围更广、更具体：

一、俱生之道不是依造作的修法而得：心要不动、稳固、一心专注，没有所思、禅定、坛城、手印；固定眼神、作种种仪式、封闭诸门、修持瓶气、在脐轮点燃拙火、封闭十门、在顶上观白莲、观上颚、鼻尖、喉间放光、额间观月、观下方的莲花金刚、修乌仗那收束、四梵住、观自影、观芝麻大的坛城、观空中的身像——这些人都像畜生一样，自以为懂法，却连俱生的一分也没有见到。

二、批评劣师、空谈空悲、外道、吃精血粪、念吽呸、滥传灌顶、炼金术等。

三、正说：让心像疯人一样自由地动；了知生、住、灭三者；舍弃装饰与手印；世人依赖文字，无文字的［真义］没有进入他们的心。本初怙主没有善与不善，遍于一切，是大乐空性，自己就是观世音，是最殊胜的自在主；即使以禅定生起三摩地，也见不到本初怙主；在那里没有身语意，无垢的勇士融入虚空。

**与前译的关系：**本篇批评"念吽呸数念珠""吃精血"等的句子，与《道歌宝藏（毗瓦巴）》第五节几乎相同；"世人依赖文字"，与萨惹哈道歌中的说法相近。本篇以前没有译过。

**关于内容的说明：**本篇所批评的种种修法，如瓶气、拙火、封门、观想坛城等，很多是密乘圆满次第中正式的修法。作者批评的不是这些修法本身，而是执著这些造作的修法、以为由此就能得到俱生，而不认识心性的做法。这与毗瓦巴《道歌宝藏》、萨惹哈道歌的立场一致。读者不可据此而轻视或诽谤这些修法，正如《四偈半》第十五节那洛巴所说："诽谤佛语，就会堕入地狱。"

体例：本篇是偈颂体，依本译对短篇的体例，按意义单元把藏文原文列于代码块中，再以完整的意义单元译出；为了便于理解而补的字，都放在方括号中。各节标题为译者所加。原文含混或可有两解之处，以"【按】"说明，不妄补内容。文末附通篇连读。

## 一、此论从俱生流出（第 7–9 句）

```
ཉིན་མཚན་རྟག་ཏུ་བླ་མ་མཆོག་གི་ཞབས་ལ་འདུད། །
གཞུང་འདི་ལྷན་ཅིག་སྐྱེས་པས་འཕྲོས་ནས་བྱུང་། །
དེས་ནི་རྒ་ཤི་རྣམས་ལ་བཞད་གད་བྱས། །
```

日夜恒常顶礼殊胜上师的双足。这部论是从俱生中流出的，以它来嘲笑衰老与死亡。

## 二、造作的修法不能清净（第 10–15 句）

```
སེམས་ནི་མི་གཡོ་བརྟན་པར་རྩེ་གཅིག་བྱ། །
དེས་ན་བསམ་བྱ་བསམ་གཏན་དཀྱིལ་འཁོར་ཕྱག་རྒྱ་མེད། །
དེ་རྣམས་བསྒོམས་པས་རྣམ་པར་དག་མི་འགྱུར། །
ལྟ་སྟངས་འཆིང་དང་ལས་རྣམས་བྱེད་པ་དང་། །
སྒོ་རྣམས་དགག་པར་བྱ་བ་མ་ཡིན་ནོ། །
དེས་ནི་ལྷན་ཅིག་སྐྱེས་པའི་ལམ་མི་ཤེས། །
```

要使心不动摇、稳固、一心专注；所以，没有所思、禅定、坛城与手印；修习那些，并不能清净。固定眼神、作种种仪式、封闭诸门，［都］不是［应当］做的；［做这些的人］不知道俱生之道。

【按】第一句"要使心不动摇、稳固、一心专注"，与下文"没有所思、禅定、坛城与手印"的关系是：心本来就应当安住于不动的本然中，所以不需要造作的禅定、坛城与手印。"固定眼神"（lta stangs 'ching），是某些瑜伽修法中固定视线的方法；"封闭诸门"（sgo rnams dgag pa），可能是指封闭身体的诸窍（与下文"十门"相应），也可能指封闭诸根门，存疑。第五句藏文"སྒོ་རྣམས་དགག་པར་བྱ་བ་མ་ཡིན་ནོ"，可以读作"封闭诸门不是［应当］做的"，也可以读作"［这些都是］不应当做的封闭诸门"，意思相同。

## 三、批评气脉拙火之执（第 16–22 句）

```
གང་ཞིག་སྲོག་དང་རྩོལ་བ་གང་བ་ཅན་དང་ནི། །
བུམ་པ་ཅན་གྱི་རླུང་ལ་བསྟོད་བྱེད་པ། །
གང་གིས་ལྟེ་བའི་དཀྱིལ་འཁོར་ཉིད་དུ་ནི། །
གཏུམ་མོ་སྦར་བར་བྱེད་ཅིང་ནན་ཏན་གྱིས། །
སྒོ་བཅུ་ལ་ནི་སྒོ་ལྕགས་འཇུག་པར་བྱེད། །
གང་ཞིག་སྤྱི་བོར་པདྨ་དཀར་པོ་བསྒོམ། །
རྨོངས་པ་དེས་ནི་དང་པོའི་ཐར་པ་མི་རྙེད་དོ། །
```

凡是赞叹命气、勤作、充满与瓶气的人；凡是在脐轮中点燃拙火，又努力把十门上闩的人；凡是在顶上观想白莲花的人——那些愚者，得不到本初的解脱。

【按】"命气、勤作、充满、瓶气"（srog dang rtsol ba，gang ba，bum pa can），都是圆满次第中修风息（prāṇāyāma）的方法；"拙火"（gtum mo），是从脐轮生起的内热；"把十门上闩"，是封闭身体诸窍以留住风息；"在顶上观想白莲花"，与圆满次第中顶轮的观修有关。这些都是密乘中正式的修法，作者批评的是执著这些造作、以为由此就能得到"本初的解脱"的做法，而不是修法本身。

## 四、种种观想之执（第 23–34 句）

```
དྲིལ་ཅན་རྐན་དང་སྣ་རྩེར་བསམ་བྱེད་དང་། །
སྟེང་དང་འོག་དང་བསྡོམས་ནས་ཤིང་བཙུགས་དང་། །
མགྲིན་པའི་ཕུགས་སུ་འོད་ཟེར་འབར་བྱེད་དང་། །
དཔྲལ་བར་ཟླ་བ་རྟག་ཏུ་སྒོམ་བྱེད་དང་། །
ནམ་མཁའི་རྩེ་མོར་མི་གཡོའི་སྣ་རྩེར་བསྒོམ། །
ལ་ལ་འོག་ཏུ་པདྨ་རྡོ་རྗེ་ལྟ། །
ལ་ལ་ཨུ་རྒྱན་འཆིང་ཞིང་འདེགས་པར་བྱེད། །
ལ་ལ་ཚངས་པའི་གནས་བཞི་སྒོམ་པར་བྱེད། །
ལ་ལ་རང་གྲིབ་སྟོང་པར་བྱས་ནས་ཆས་ལ་ལྟ། །
ལ་ལ་དཀྱིལ་འཁོར་ཏིལ་གྱི་འབྲུ་ཙམ་བསྒོམ། །
ལ་ལ་བར་སྣང་སྐུ་གཟུགས་སྒོམ་བྱེད་པའི། །
བྱོལ་སོང་རྣམས་ནི་རང་ཉིད་ཆོས་རྣམས་ཤེས་པར་སྨྲ། །
```

［有人］专注于有铃［形］的上颚和鼻尖；［有人］把上与下合在一起而竖起木桩；［有人］在喉咙的深处燃放光芒；［有人］恒常在额间观想月亮；［有人］在虚空的顶端、不动的鼻尖观想。

有的人看下方的莲花与金刚；有的人修乌仗那的收束与提升；有的人修四梵住；有的人把自己的影子观空之后看向天空；有的人观想芝麻粒大小的坛城；有的人观想空中的身像——这些畜生们，［却］说自己懂得诸法。

【按】这一节列举了种种瑜伽观修法：
- "有铃［形］的上颚"（dril can rkan），可能指悬雍垂（小舌）附近，是某些风息与明点修法的专注处；
- "把上与下合在一起而竖起木桩"（steng dang 'og dang bsdoms nas shing btsugs），意思不明，可能是指上下二气相合、中脉如柱的修法，存疑；
- "看下方的莲花与金刚"，是第三灌顶中的象征用语，这里不作解说；
- "乌仗那的收束与提升"（u rgyan 'ching zhing 'degs），可能是指哈达瑜伽中的"乌地亚那收束"（uḍḍiyāna-bandha），即收腹提气的方法，"u rgyan"在这里不是指乌仗那国，存疑；
- "四梵住"（tshangs pa'i gnas bzhi），即慈、悲、喜、舍四无量心，在这里被列入"造作的修法"，是因为执著它为究竟而不认识心性；
- "把自己的影子观空之后看向天空"，是一种观影的修法，藏文作"ཆས་ལ་ལྟ"，"chas"意思不明，可能是"mkha'"（天空）之误，存疑。

"这些畜生们"（byol song rnams），是道歌中常见的激烈批评，指这些人像畜生一样只依本能而不认识心性。

## 五、俱生不在任何地方（第 35–39 句）

```
དེ་རྣམས་ཀྱིས་ནི་སྐྱེ་བ་འབྲས་བུ་མེད། །
བློ་རྣམས་ཟད་ཅིང་སྡིག་པ་རྣམས་ལ་སྤྱོད། །
དེས་ནི་ལྷན་ཅིག་སྐྱེས་པའི་ཆ་ཡང་མ་མཐོང་ངོ་། །
དེ་ནི་ནམ་མཁའ་དང་ནི་ས་འོག་དང་། །
ས་སྟེང་དང་ནི་ཚངས་པའི་གནས་སུའང་མེད། །
```

那些人得不到生［起俱生］的果；智慧耗尽了，还去做种种恶事；他们连俱生的一分也没有见到。它不在天上，不在地下，不在地面，也不在梵天的住处。

【按】"那些人得不到生［起俱生］的果"，藏文作"དེ་རྣམས་ཀྱིས་ནི་སྐྱེ་བ་འབྲས་བུ་མེད"，字面是"他们没有生、果"，意思不很清楚，可能是"他们的修法不会生起果"，存疑。"它不在天上……也不在梵天的住处"，是说俱生不在外在的任何地方，要在自心中寻找。

## 六、批评劣师与空谈空悲（第 40–46 句）

```
དམན་པའི་སློབ་དཔོན་བསྟེན་པར་མ་བྱེད་ཅིག །
དེས་ནི་སྡིག་པའི་ལས་རྣམས་མ་སྤངས་པར། །
ཁ་ནི་འགུལ་ཞིང་འགུལ་ཞིང་རེ་ལ་གནས། །
རང་གིས་སྟོང་པ་སྙིང་རྗེ་བྱེད་པར་རྩོམ། །
དེས་ནི་སྲིད་པ་སྤོང་ཐབས་མི་ཤེས་སོ། །
སྟོང་པ་སྙིང་རྗེ་རྟོགས་ཞེས་ཟེར་ཞིང་གནས། །
དཔལ་ལྡན་བདེ་ཆེན་གཏམ་ཡང་མི་འདྲིའོ། །
```

不要依止低劣的阿阇黎！他没有舍弃恶业，嘴唇动个不停，住在希望之中；自己开始做"空性与悲心"［的修法］，却不知道舍弃三有的方法；说着"我已证悟了空性与悲心"而住，却连吉祥大乐的话也不问一问。

【按】"嘴唇动个不停"，指不停地念诵。"连吉祥大乐的话也不问一问"，是说这些人只是口头上谈空性与悲心，却对真正的大乐（俱生）毫不关心。

## 七、批评外道与种种执著（第 47–54 句）

```
ལ་ལ་དབང་ཕྱུག་ཨུ་མ་རེ་ལ་གནས། །
བདག་ཉིད་སྲིད་པའི་འཆིང་བའི་ཞགས་པས་བཅིངས། །
ལ་ལ་ཁུ་བ་ཁྲག་དང་རྣམ་སྣང་ཟ། །
བྱ་རོག་བྱ་རྒོད་བཞིན་དུ་བདག་ཉིད་འཁོལ། །
ལ་ལ་གནས་གསུམ་སྐད་ཅིག་གསུམ་དུ་བསྒོམ། །
ལ་ལ་སྙིང་གའི་པདྨ་འཁོར་ལོ་འཆང་། །
ལ་ལ་ཧཱུཾ་ཕཊ་ཟེར་ཞིང་ཕྲེང་བ་བགྲང་། །
བྱོལ་སོང་རྣམས་ནི་འཁྲུལ་པ་རྒྱུན་མི་འཆད། །
```

有的人住在对大自在天与乌玛［天女］的希望中，把自己用三有之束缚的绳索捆住。有的人吃精、血与"毗卢遮那"，像乌鸦与秃鹫一样使自己堕落。有的人在三刹那中观修三处；有的人执持心间的莲花之轮；有的人口念"吽呸"，数着念珠——这些畜生的迷乱永不断绝。

【按】"大自在天与乌玛"（dbang phyug u ma），即湿婆与其妃乌玛（Umā），指湿婆派外道。"毗卢遮那"（rnam snang），在密续的隐语中，指五甘露中的粪；"吃精、血与毗卢遮那"，是批评执著五甘露等外在形式而不认识心性的人，与《道歌宝藏（毗瓦巴）》第五节的意思相同。"在三刹那中观修三处"（gnas gsum skad cig gsum），可能是指生起次第中三金刚（身语意，即顶、喉、心三处）的观想，存疑。

## 八、批评滥传灌顶与炼金术（第 55–65 句）

```
དབང་དང་དབང་བསྐུར་མང་པོ་གསུངས་པ་རྣམས། །
བླ་མ་རྣམས་ལ་སློབ་མས་ལེན་པར་བྱེད། །
དེ་ནས་བརྩམས་ཤིང་སློབ་མ་རྣམས་ལ་འཆད། །
དབང་བསྐུར་གྱི་ནི་ཕྱོགས་ཀྱང་མ་མཐོང་ངོ་། །
```

弟子们从上师那里接受了所说的许多"灌顶"与"授权"，然后就开始为弟子们讲说，［却］连灌顶的方向也没有见过。

```
ལ་ལས་གསེར་འགྱུར་རྩི་ནི་ལྟ་བྱེད་པས། །
དེས་ནི་ཁྱིམ་པ་རྣམས་ནི་དབུལ་པོར་བྱས། །
ལྷ་རྣམས་ཀྱིས་ཀྱང་མི་བདེ་བ་ལ་སྦྱར། །
ནགས་ལ་སྐྱེས་པའི་རྩྭ་དང་ཤིང་རྣམས་དང་། །
ཤིང་ལོ་མེ་ཏོག་རྣམས་ཀྱིས་སྐྱིད་མ་བསྟན། །
དུས་སུ་བསམ་གཏན་འཇིག་རྟེན་པ་རྣམས་བྱེད། །
དེས་ནི་མཆོག་གི་ཐར་པ་མི་ཤེས་སོ། །
```

有的人因为去看点金药，结果使在家人都变成了穷人；诸天也使［他们］陷于不安乐之中。森林中生长的草木，以及树叶与花朵，都没有显示安乐。世间之人有时也修禅定，［但］他们不知道殊胜的解脱。

【按】"点金药"（gser 'gyur rtsi），即印度炼金术中能把贱金属变成黄金的药，修炼者往往耗尽家财。"诸天也使［他们］陷于不安乐之中"一句，意思不很清楚，可能是说崇拜诸天的人也得不到安乐，存疑。"森林中生长的草木……都没有显示安乐"，可能是批评隐居山林、以为离开世间就能得到安乐的人，存疑。

## 九、正说：让心像疯人一样（第 66–75 句）

```
ཅལ་ཅོལ་མང་པོ་སྨྲས་པས་ཅི་ཞིག་བྱ། །
ཇི་ལྟར་སྨྲས་པ་དེ་དག་ཐམས་ཅད་རྫུན། །
གདམས་ངག་པ་རྣམས་གསལ་པོའི་གནས་ལུགས་ཉོན། །
གང་གིས་གསལ་པོར་ཐར་པ་གྲོལ་བ་རྙེད། །
```

说那么多废话有什么用呢？像那样所说的一切，都是虚假的。诸持口诀者，请听这清楚的实相！由它，就能清楚地得到解脱。

```
སེམས་ནི་གཡོ་ཞིང་སྨྱོན་པ་ལྟ་བུར་ཐོང་། །
སྐྱེ་དང་གནས་དང་འཇིག་པ་གསུམ་པོ་རྟོགས་པར་གྱིས། །
མགུལ་རྒྱན་དང་ནི་ཕྱག་རྒྱ་མ་ལུས་ཐོང་། །
དེས་ནི་མགོན་པོ་ཇི་ལྟར་མཐོང་བར་འགྱུར། །
འཇིག་རྟེན་པ་ནི་ཡི་གེ་རྣམས་ལ་གཏོད། །
ཡི་གེ་མེད་པ་དེ་ནི་སྙིང་ལ་མ་ཆུད་དོ། །
```

让心动摇，像疯人一样放任它；要证悟生、住、灭三者；把项链与手印［饰物］全都丢掉。那样，怎么会见到怙主呢？世间的人依赖文字，那无文字的［真义］，没有进入他们的心中。

【按】"让心动摇，像疯人一样放任它"，是大手印的一个要点：不刻意让心不动，而是像疯人那样，不加控制地让心自由活动，在动中认识心性。这与本篇第一节"要使心不动摇、稳固"表面上矛盾，实际上指的是两个层次：第一节是说心性本来不动，这里是说不要刻意去控制念头。

"项链与手印"（mgul rgyan dang ni phyag rgya），可能是指修行人佩戴的骨饰等六种手印（骨饰），即密乘行者外在的装饰与标志，存疑。"那样，怎么会见到怙主呢"，藏文作"དེས་ནི་མགོན་པོ་ཇི་ལྟར་མཐོང་བར་འགྱུར"，可以理解为反问"那样［执著装饰］怎么能见到怙主"，也可以理解为"由此［舍弃之后］，怎样就能见到怙主"，存疑。

## 十、本初怙主：大乐空性（第 76–82 句）

```
གདམས་ངག་པ་རྣམས་ཉོན་ཅིག་ངས་ནི་བཤད་པར་བྱ། །
ཁམས་གསུམ་བོར་ནས་དཔལ་ལྡན་ཐེག་པ་ཆེ། །
དང་པོའི་མགོན་པོ་ལ་ནི་དགེ་དང་མི་དགེ་མེད། །
མ་ལུས་ཁྱབ་ཅིང་བདེ་ཆེན་སྟོང་པ་ཉིད། །
བྱེད་པ་འཕྲོག་པ་རང་ཉིད་སྤྱན་རས་གཟིགས། །
ཟད་པ་མེད་ཅིང་གཞན་དུ་སོང་བ་མེད། །
དེ་ནི་མཆོག་གི་དབང་ཕྱུག་དམ་པའོ། །
```

诸持口诀者，请听！我来讲说：舍弃三界，［就是］吉祥的大乘。本初怙主没有善与不善，遍于一切，是大乐空性；作者与夺者，就是自己——观世音；没有穷尽，也没有去到别处；那就是最殊胜的自在主。

【按】"本初怙主"（dang po'i mgon po，梵 Ādinātha），是本初佛之意，指心性本身。"作者与夺者，就是自己——观世音"，意思是：创造与毁灭一切的，不是外在的神，而是自己的心性，即观世音（大悲）；"最殊胜的自在主"（mchog gi dbang phyug），是以佛教的方式重新诠释"大自在天"（Maheśvara），与上文批评"大自在天与乌玛"相对应。这与《金刚句》第十八节"梵天、遍入天、湿婆都是俱生智慧的异名"的方式相同。

## 十一、禅定见不到本初怙主；勇士融入虚空（第 83–89 句）

```
བསམ་གཏན་གྱིས་ནི་ཏིང་འཛིན་སྐྱེས་བྱས་ཀྱང་། །
དང་པོའི་མགོན་པོ་དེ་ནི་མ་མཐོང་ངོ་། །
དེ་ལྟའི་སེམས་ནི་སྙིང་ལ་མ་ཆུད་དོ། །
དེ་ལ་ལུས་དང་ངག་དང་ཡིད་མེད་དེ། །
དཔའ་བོ་དྲི་མེད་དེ་ནི་ནམ་མཁར་ཐིམ། །
བིརྺ་པ་ཡིས་སེམས་ཅན་དོན་དུ་བྱས། །
དོན་དམ་འདི་ནི་གདམས་ངག་པ་རྣམས་ཉོན། །
```

即使以禅定生起了三摩地，也见不到那本初怙主；这样的心，没有进入心中。在那里，没有身、语、意；无垢的勇士融入虚空。毗瓦巴为了众生的利益而作［此歌］；诸持口诀者，请听这胜义！

【按】"这样的心，没有进入心中"（de lta'i sems ni snying la ma chud），意思是：依禅定造作出的三摩地，并不是真正认识了心性，存疑。"无垢的勇士融入虚空"，"勇士"（dpa' bo，梵 vīra）在密续中指证悟的瑜伽士或嘿噜嘎，这里可能是说证悟者的心融入虚空般的法界。

## 通篇连读

敬礼诸上师！

日夜恒常顶礼殊胜上师的双足。这部论是从俱生中流出的，以它来嘲笑衰老与死亡。

要使心不动摇、稳固、一心专注；所以没有所思、禅定、坛城与手印，修习那些并不能清净。固定眼神、作种种仪式、封闭诸门，都不是应当做的，做这些的人不知道俱生之道。

赞叹命气、勤作、充满与瓶气的人，在脐轮中点燃拙火、努力把十门上闩的人，在顶上观想白莲花的人，那些愚者得不到本初的解脱。有人专注于上颚和鼻尖，有人把上与下合在一起而竖起木桩，有人在喉咙深处燃放光芒，有人恒常在额间观想月亮，有人在虚空的顶端、不动的鼻尖观想；有人看下方的莲花与金刚，有人修乌仗那的收束与提升，有人修四梵住，有人观空自己的影子而看向天空，有人观想芝麻粒大的坛城，有人观想空中的身像——这些畜生们，却说自己懂得诸法。他们得不到果，智慧耗尽了还去做恶事，连俱生的一分也没有见到。它不在天上，不在地下，不在地面，也不在梵天的住处。

不要依止低劣的阿阇黎！他没有舍弃恶业，嘴唇动个不停，住在希望之中；自己做空性与悲心的修法，却不知道舍弃三有的方法；说着"我已证悟了空性与悲心"，却连吉祥大乐的话也不问一问。有人住在对大自在天与乌玛的希望中，用三有的绳索捆住自己；有人吃精、血与毗卢遮那，像乌鸦秃鹫一样使自己堕落；有人在三刹那中观修三处，有人执持心间的莲花之轮，有人口念吽呸数着念珠，这些畜生的迷乱永不断绝。弟子们从上师那里接受了许多灌顶与授权，就开始为弟子讲说，却连灌顶的方向也没有见过。有人去看点金药，使在家人都变成了穷人；诸天也使他们陷于不安乐；森林中的草木花叶也都没有显示安乐；世间之人有时也修禅定，却不知道殊胜的解脱。

说那么多废话有什么用？像那样所说的一切都是虚假的。诸持口诀者，请听这清楚的实相！由它就能清楚地得到解脱。让心动摇，像疯人一样放任它；要证悟生、住、灭三者；把项链与手印饰物全都丢掉——那样，怎么会见到怙主呢？世间的人依赖文字，那无文字的真义没有进入他们的心中。

诸持口诀者，请听！我来讲说：舍弃三界，就是吉祥的大乘。本初怙主没有善与不善，遍于一切，是大乐空性；作者与夺者就是自己——观世音；没有穷尽，也没有去到别处，那就是最殊胜的自在主。即使以禅定生起了三摩地，也见不到那本初怙主，这样的心没有进入心中。在那里没有身、语、意，无垢的勇士融入虚空。毗瓦巴为了众生的利益而作此歌，诸持口诀者，请听这胜义！

《八十四句》，瑜伽大自在吉祥毗瓦巴所造，圆满。生于南方憍萨罗的瑜伽大自在吉祥毗卢遮那金刚亲自译出并宣说。
