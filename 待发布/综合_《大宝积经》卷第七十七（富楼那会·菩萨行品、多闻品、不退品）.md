# 《大宝积经》卷第七十七（富楼那会·菩萨行品、多闻品、不退品）

后秦·三藏鸠摩罗什 译

## 富楼那会第十七之一

【按】译者题名，宋、宫本作“姚秦三藏鸠摩罗什译”，元本作“姚秦三藏法师鸠摩罗什奉诏译”，明本作“姚秦三藏法师鸠摩罗什译”。

### 菩萨行品第一

#### 富楼那请问菩萨所行

如是我闻：一时，佛住在王舍城竹园中，与大比丘众在一起，以及大菩萨摩诃萨，其数无量。那时慧命富楼那弥多罗尼子从座而起，偏袒右肩，右膝著地，合掌向佛，对佛说：“世尊！我想稍有所问，唯愿如来垂愍听许。”佛告诉富楼那：“随意发问。我当为你解说，令你欢喜。”富楼那说：“我现在是为了那些修行上妙功德、名闻高远、常为众生求安乐的诸菩萨摩诃萨，有所咨请。”那时富楼那以偈颂说：

```
「行最上功德，名称极高远，
净戒乐法者，我问其所行。
云何修治心？云何广行施？
云何度众生？喜心常行道？」
```
（大意：修行最上功德，名称极为高远，持守净戒、乐于正法的人，我问他们所行之事：怎样修治其心？怎样广行布施？怎样度化众生？怎样以欢喜之心常行于道？）

富楼那对佛说：“世尊！我现在为这些大士，问这样的事。菩萨怎样修集多闻，犹如大海不可竭尽？怎样能聚集多闻的宝藏，能在诸法中得到决定之义，对种种语言善于了知章句？”便说偈道：

```
「菩萨云何求，多闻如大海，
于法得定义，能善知佛道？
云何于一言，而解无量义，
能以智慧力，通达一切法？
多闻无穷尽，问难心不动，
慈愍故说法，以断众生疑。」
```
（大意：菩萨怎样求得多闻如大海，于法得到决定之义，能善知佛道？怎样从一句话中理解无量之义，能以智慧之力通达一切法？多闻无穷无尽，面对问难心不动摇，因慈愍而说法，以断除众生的疑惑。）

富楼那对佛说：“世尊！我现在随自己所处之地的智力请问如来：诸菩萨摩诃萨怎样能于阿耨多罗三藐三菩提不退转？”便说偈道：

【按】“不退转”之“转”，宫本作“得”。

```
「云何离众难，得值遇诸佛，
得值诸佛已，速得清净信？
得无上信已，难舍而能舍，
弃舍一切已，力行无碍道？
云何乐出家，闲静修空智？
云何不逆法？愿具答是事。」
```
（大意：怎样远离种种难处，得以值遇诸佛？值遇诸佛之后，怎样迅速得到清净的信心？得到无上信心之后，难舍而能舍，舍弃一切之后，努力行于无碍之道？怎样乐于出家，在闲静处修习空智？怎样不违逆于法？愿完整回答这些事。）

【按】“无碍”之“碍”，圣乙本作“阂”。

富楼那对佛说：“世尊！我们都知道佛已具足一切智慧，已度到一切神通的彼岸，在三界中最为高尊，得到无与伦比的微妙大智，在诸法中行无障碍。所以我现在请问这些事。”以偈赞叹说：

```
「佛住上功德，已度神通岸，
得无障碍智，我为勇猛问。
善学一切法，功德最高胜，
破暗生慧明，令众悉欢喜。
怨亲无憎爱，无忧无欺诳，
大战胜死王，摧破魔军众。
不执于刀杖，降伏诸怨敌，
常有慈悲心，坚住清净戒。
世尊无谄曲，无慢无戏调，
得证明解脱，功德中最胜。
如本所行道，所得胜智慧，
愿今为我说，云何行得佛？」
```
（大意：佛安住于上妙功德，已度到神通彼岸，得到无障碍之智，我为勇猛者发问。善学一切法，功德最为高胜，破除黑暗，生起智慧光明，令大众都欢喜。对怨与亲没有憎爱，无忧也无欺诳，在大战中战胜死王，摧破魔军之众。不执持刀杖，却降伏种种怨敌，常有慈悲之心，坚住清净之戒。世尊没有谄曲，没有傲慢，没有戏笑轻调，证得明与解脱，在功德中最为殊胜。依照本来所行之道与所得的殊胜智慧，愿现在为我宣说：怎样修行而得成佛？）

【按】“刀杖”之“杖”，宋、宫本作“仗”。

#### 佛说菩萨发心所行

那时佛告诉富楼那说：“善哉善哉！你能向如来咨问这些事。谛听谛听，好好思念，当为你宣说诸菩萨发心所行，修集一切无量佛法。”那时世尊以偈颂说：

```
「我今说菩萨，初发菩提心，
常以勇猛力，乐行菩萨道。
诸菩萨所行，种种深心行，
于佛得受记，是事当略说。
深心乐法心，无量无有边，
种种现诸行，不以一事成。
喜心内充满，而行于布施，
施已心无悔，其意益欢悦。
```
（大意：我现在宣说菩萨，初发菩提心，常以勇猛之力，乐于修行菩萨道。诸菩萨所行，种种深心之行，于佛所得受记，这些事当简略宣说。深心与乐法之心，无量无边，种种示现诸行，不是以一件事成就。欢喜之心在内充满，而行布施，施后心无悔恨，其意更加欢悦。）

```
菩萨作是念：『众生常贫穷，
无有多闻财，我当为求之。
众生常贫穷，皆由于懈怠，
我当勤精进，从是得菩提。
我当为众生，加心行忍辱，
恶言骂捶打，默受而不报。』
当念谁骂我？骂者不可得；
骂詈瞋恨者，皆悉是空事。
如是思惟已，心无有瞋恨，
常修行忍辱，从是成佛道。
```
（大意：菩萨这样想：“众生常常贫穷，没有多闻之财，我当为他们求取。众生常常贫穷，都是由于懈怠，我当勤行精进，由此得到菩提。我当为众生更加用心修行忍辱，被恶言辱骂、捶打，默默承受而不报复。”应当思念：是谁骂我？骂者不可得；骂詈与瞋恨的人，都是空的事。这样思惟之后，心中没有瞋恨，常修行忍辱，由此成就佛道。）

```
『众生无善心，当为作世灯，
令其得归趣，无财足以财。
众生可愍伤，皆共行邪道，
我当度脱之，令住于涅槃。
众生皆贫穷，无有智慧财，
我得一切智，令其得充足。』
如是诸菩萨，为度众生故，
发心求菩提，行如是等愿。」
```
（大意：“众生没有善心，我当为他们作世间之灯，令他们得到归趣，没有财物的，以财物令其满足。众生可怜可悯，都共同行于邪道，我当度脱他们，令他们安住于涅槃。众生都贫穷，没有智慧之财，我得到一切智后，令他们得以充足。”像这样，诸菩萨为了度化众生，发心求菩提，行这样的种种誓愿。）

#### 菩萨四大希有事

佛告诉富楼那：“诸菩萨摩诃萨以种种因缘示现其心，不住于一法。为什么呢？诸菩萨学一切法，然后得道。菩萨有四种大希有事，不见其余之法有胜过这些事的。哪四种？菩萨能在懈怠的众生中勤行精进，这名为希有。能在强横瞋恚的众生中修行忍辱，这名为希有。见到众生行于邪道，自己勤修正道，这名为希有。为了度化众生、扭转生死的缘故，以深心发阿耨多罗三藐三菩提心，这名为希有。富楼那！这四种希有，名为菩萨最大的希有。”那时世尊以偈颂说：

```
「见懈怠众生，勤心发精进：
『我不应效彼，行诸非法事。
不应效瞋恚，瞋恚非佛道，
常修慈悲心，菩提从是生。
众生乐邪径，依止于邪径，
菩萨求正道，令众住正道。
见生死过患，一心求佛智，
我得无上财，当度诸众生。』
如是希有事，余更无胜者，
以是故当知，得离障碍法。
设使烧身衣，头然犹不救，
懈怠心若生，即应速除灭。」
```
（大意：见到懈怠的众生，勤心发起精进：“我不应效仿他们，行种种非法之事。不应效仿瞋恚，瞋恚不是佛道，常修慈悲之心，菩提由此而生。众生乐于邪路，依止于邪路，菩萨求取正道，令众生安住于正道。见到生死的过患，一心求佛智慧，我得到无上之财，当度化众生。”这样的希有之事，再没有胜过的，因此应当知道，由此得以离开障碍之法。即使焚烧到身上的衣服、头上着火，尚且不去救，懈怠之心若生起，就应当迅速除灭。）

【按】“障碍”之“碍”，圣本作“阂”。

#### 菩萨四法生喜心

佛告诉富楼那：“菩萨有四法能生欢喜心。哪四种？见到众生安处生死，不能精进，自见其身在佛道中修行精进，便生欢喜心。见到众生心常懈怠，自见其身在佛法中勤行精进，便生欢喜心。见到众生瞋恨嫉妒，自见其身没有瞋恚嫉妒，常怀慈悲，便生欢喜心。不见其余的人勤行佛法与我相等的，便生欢喜心。”那时世尊以偈颂说：

【按】“嫉妬”之“嫉”，圣、圣乙本作“疾”。

```
「见众生懈怠，已身行精进，
是故此菩萨，自得欢喜心。
见生死过患，而生厌离心，
怖畏三界狱，勤心求舍离。
众生乐瞋恨，自住慈悲心，
是故此菩萨，生欢喜悦乐。
『众生所可作，皆所不应作，
是故我当求，无有上佛道。
是名真实智，诸佛所称叹，
我当学是智，众生得归趣。』
是故此菩萨，常得欢喜心，
从有无空伪，当生真实法。」
```
（大意：见到众生懈怠，自身行于精进，所以这位菩萨，自得欢喜之心。见到生死的过患，而生起厌离之心，怖畏三界的牢狱，勤心求得舍离。众生乐于瞋恨，自己安住慈悲之心，所以这位菩萨，生起欢喜悦乐。“众生所能作的，都是不应作的，所以我当求取无上的佛道。这名为真实的智慧，是诸佛所称叹的，我当修学这智慧，令众生得到归趣。”所以这位菩萨常得欢喜之心，从有、无、空、伪之中，当生出真实之法。）

【按】“而生厌离心”之“生”，圣本作“坐”。

#### 菩萨四法离难值佛

佛告诉富楼那：“菩萨有四法，得以离开诸难，生于无难之处，生后不失，能修佛法。哪四种？一是菩萨谦逊，其心柔软，凡见到众生常说‘善来’，和颜悦色，先主动问讯，与人共语时常含笑容。二是一心求法，常乐咨问，勤求善利，没有厌足。三是常乐于空闲、远离、独处。四是自身安住于佛菩提道，也教化众生，令其安住于佛道。菩萨有这四法，得以离开诸难，生于无难之处，生后不失，能修佛法。”那时世尊以偈颂说：

【按】“问讯”之“讯”，圣乙本作“说”。“当乐空闲”之“当”，明本作“常”。

```
「具足柔软心，常乐行慈悲，
若与众生语，谦下心和悦。
常求佛所叹，甚深微妙法，
常持清净戒，乐行头陀事。
虽行头陀法，亦行深妙智，
是故此菩萨，离难值无难。
常于诸佛所，咨问诸深法，
是故智增长，不生诸难处。
```
（大意：具足柔软之心，常乐行于慈悲，若与众生交谈，心谦下而和悦。常求佛所称叹的甚深微妙之法，常持清净之戒，乐行头陀之事。虽然行头陀之法，也行深妙之智，所以这位菩萨离开难处，生于无难之处。）

【按】“佛所叹”之“叹”，圣乙本作“难”。

```
常乐在空闲，清净行头陀，
是故此菩萨，离难值无难。
诸有智慧者，亲近此四法，
能离一切难，得值遇诸佛。
得值诸佛已，具足不坏信，
能发上精进，以求于佛智。
是故求智者，应当学正法，
若能学正法，得佛道不难。」
```
（大意：常在诸佛之所，咨问种种深法，所以智慧增长，不生于种种难处。常乐在空闲处，清净地行头陀，所以这位菩萨离开难处，生于无难之处。凡是有智慧的人，亲近这四种法，能离开一切难处，得以值遇诸佛。值遇诸佛之后，具足不坏的信心，能发起上等精进，以求佛的智慧。所以求智慧的人，应当学习正法，若能学习正法，得成佛道并不困难。）

【按】“智增长”之“增”，宋本作“憎”。

### 多闻品第二

#### 求十二部经

佛告诉富楼那：“菩萨有四法，便能修集多闻，犹如大海不可竭尽，常能修集多闻的宝藏，能在诸法中得到决定之义，对种种语言善于了知章句。哪四种？菩萨求法，就是十二部经：修多罗、祇夜、受记经、伽陀、忧陀那、尼陀那、如是诸经、本生经、方广经、未曾有经、阿波陀那、论议经。求得之后诵读，诵读之后正确忆念，正确忆念之后如所说而行。富楼那！菩萨有这第一法，便能修集多闻，犹如大海不可竭尽。常能修集多闻的宝藏，能在诸法中得到决定之义，对种种语言善于了知章句。

【按】“如是诸经”之“诸”，圣、圣乙本作“语”。

#### 无所依止得不住智

“又，富楼那！菩萨对一切法无所依止，虽然入于禅定，也无所依。因为无所依，在诸法中得到不住之智。得到不住之智后，在诸法中得到无碍的知见。为什么呢？富楼那！没有法可以贪著而作障碍。菩萨有这第三法，便能修集多闻，犹如大海不可竭尽，能常修集多闻的宝藏，能在诸法中得到决定之义，对种种语言善于了知章句。

【按】“此三法”之“三”，宫、圣乙本作“二”。此段为第二法，原文作“三”，下段亦作“三”。

#### 以法因缘念佛念法

“又，富楼那！菩萨以法的因缘念佛以及念佛法，此人以法的因缘念佛、念佛法时，不见有法可以贪受。此人因为不贪受，对一切法心无所著。此人因为对一切法无所著，对种种问难，随所问而答，没有障碍。菩萨有这第三法，便能修集多闻，犹如大海不可竭尽，能常修集多闻的宝藏，能在诸法中得到决定之义，对种种语言善于了知章句。

【按】“可贪受”之“受”，宋、元、明本作“爱”；“不贪受”之“受”，宋、元、明、宫、圣乙本作“爱”。

#### 无所得慈即是佛慈

“又，富楼那！菩萨成就无所得的慈心，于行无碍。无所得的慈心，不受取种种事。为什么呢？富楼那！住于这个相的人，或生贪欲，或生瞋恚，或生愚痴。住于那个相的人，也或生贪欲，或生瞋恚，或生愚痴。住于事相、物相，阴相、入相、界相，法相、非法相的人，也或生贪欲，或生瞋恚，或生愚痴。所以富楼那！所有受取相的，都名为邪见，菩萨灭尽一切相而修集慈心。因为众生败坏，所以相也败坏；因为相败坏，所以事也败坏；因为事败坏，所以见也败坏；菩萨那时破坏一切法而修集慈心。这样的慈名为无所得慈，这样的无所得慈名为法慈，这样的法慈名为佛慈。富楼那！什么叫作佛慈？无作无坏，这名为佛慈。又，富楼那！如实通达一切诸法，这名为佛慈。”

“世尊！什么叫作如实通达一切诸法？”佛告诉富楼那：“所通达的，不说是法，也不说是非法。为什么呢？富楼那！若说有法，就是非法。若有无法，也没有非法，那么其中便没有戏论；若没有戏论，这名为涅槃。你完全地观察它，是极远还是极近？”富楼那说：“不远也不近。为什么呢？世尊！这样的义理，无方无处，无内无外。”佛说：“是这样，富楼那！这是对法作名数。”“世尊！对什么样的法作名数？”“富楼那！如凡夫所执著的法，如来不得、不修、不证、不通达。对这样的法作名数，富楼那！这些法数不是为了分别法。富楼那！现在为你宣说，这样第一寂灭之法能摄佛道。富楼那！未来有人欣求世间利益，若听闻此经，不乐于听受。富楼那！我的这菩提，你们只是以音声章句稍稍知道而已，其中的义趣是你们所不知道的。此义玄远，不可言宣，唯有智者可以内心了知。”那时世尊说偈道：

【按】“欣赴”之“赴”，宫、圣乙本作“起”。

```
「不能知义者，闻佛法忧苦，
若能知义者，如来为作师。
若人佛为师，是则求涅槃，
无有诤讼心，能正思量法。
此中无法生，亦无有法灭，
无生无有灭，是诸法实相。
若法无有生，即无有作起，
是非与一异，此法中皆无。
是名为涅槃，中无有灭者，
若言极远近，是二俱为空。
若能知空者，即名知涅槃，
若知涅槃者，是名我弟子。
```
（大意：不能了知义理的人，听闻佛法便忧苦；若能了知义理，如来便为他作老师。若人以佛为师，便是在求涅槃，没有诤讼之心，能正确思量于法。这其中没有法生起，也没有法灭去，无生也无灭，这是诸法的实相。若法无有生起，便没有造作生起，是与非、一与异，在此法中都没有。这名为涅槃，其中没有灭去者，若说极远或极近，这二者都是空。若能了知空，就名为了知涅槃，若了知涅槃，这名为我的弟子。）

“富楼那！菩萨有这四法，便能修集多闻，犹如大海而不竭尽，能常修集多闻的宝藏，能在诸法中得到决定之义，对种种语言善于了知章句。”那时世尊以偈颂说：

```
「常欲求多闻，诸佛所称叹，
能得定实义，是故如大海。
能于一字中，及与一句义，
于千万亿劫，说之而不尽。
故当求正法，求已正思量，
勿贪取法相，不贪佛所赞。
忆念诸如来，及念于正法，
不以贪竞心，而求于导师。
常于诸众生，修行慈愍心，
而不著众生，散灭一切法。
大名称菩萨，修习如是法，
疾得陀罗尼，多闻从是生。
```
（大意：常想求多闻，这是诸佛所称叹的，能得到决定真实之义，所以如同大海。能于一个字中以及一句的义理，在千万亿劫中说之而不尽。所以应当求正法，求得之后正确思量，不要贪取法相，不贪著佛所称赞的。忆念诸如来，以及念正法，不以贪求竞争之心去求导师。常对众生修行慈愍之心，而不执著众生，散灭一切法。具大名称的菩萨修习这样的法，迅速得到陀罗尼，多闻由此而生。）

【按】“正思量”之“量”，明本作“惟”。

```
犹如虚空性，无增无有减，
法性亦如是，无增无有减。
我以智慧力，无量劫说法，
所说无央数，犹亦不名说。
尽诸众生性，皆使得人身，
普共行出家，多闻如阿难。
陀罗尼菩萨，为是一切人，
千亿劫说法，智慧犹不尽。
佛智慧无等，同虚空无量，
虚空无生起，智慧亦如是。
```
（大意：犹如虚空之性，无增也无减，法性也是这样，无增也无减。我以智慧之力在无量劫中说法，所说无数，仍不名为说。若令一切众生都得到人身，普遍一同出家，多闻都如阿难；得陀罗尼的菩萨为这一切人，在千亿劫中说法，智慧仍不穷尽。佛的智慧无与伦比，同于虚空，无量无边，虚空无生无起，智慧也是这样。）

【按】“无有减”之“减”，圣乙本作“灭”。

```
如龙不取水，而能雨大水，
是水无住处，所雨无穷尽。
菩萨亦如是，得此陀罗尼，
诸法无住处，是缘说不尽。
故应求多闻，求已正思惟，
以法缘念佛，多闻从是生。
慈普覆众生，散灭众生相，
亦灭诸法相，多闻从是生。」
```
（大意：如龙不取水，却能降下大雨，这水没有住处，所降之雨无穷无尽。菩萨也是这样，得到这陀罗尼，诸法没有住处，因此说之不尽。所以应当求多闻，求得之后正确思惟，以法为缘而念佛，多闻由此而生。以慈心普覆众生，散灭众生之相，也灭除诸法之相，多闻由此而生。）

【按】“所雨无穷尽”之“无”，圣本作“足”。

### 不退品第三

#### 闻未闻法不即言非

佛告诉富楼那：“菩萨成就四法，能于阿耨多罗三藐三菩提不退转。哪四种？菩萨听闻未曾听闻之法，思量其义理，不即刻说它不对。菩萨成就这第一法，便于阿耨多罗三藐三菩提不退转。”那时世尊以偈颂说：

【按】“则于”之“则”，圣本作“即”。

```
「闻所未闻法，其心逮不逆，
思量其义理，不即言非法。
若闻于空法，常求其义理，
是故智增长，佛道从是生。
闻所未闻法，应求其义理，
不退于菩提，智慧得增长。
闻所未闻法，不随恶慢心，
不生于谄曲，生则非菩提。
闻所未闻法，应求解其义，
先虽未曾闻，一心应思念。
是人求法时，能得闻正法，
常值遇诸佛，不退失菩提。
```
（大意：听闻未曾听闻之法，其心便不违逆，思量其义理，不即刻说它不是法。若听闻空法，常求其义理，所以智慧增长，佛道由此而生。听闻未曾听闻之法，应当求其义理，便不退失菩提，智慧得以增长。听闻未曾听闻之法，不随顺恶慢之心，不生起谄曲，若生起便不是菩提。听闻未曾听闻之法，应当求解其义，先前虽然未曾听闻，也应一心思念。此人求法时，能听闻正法，常值遇诸佛，不退失菩提。）

```
得见诸佛已，则能正问难，
声闻人得闻，咸以为欢喜。
是人甚希有，能作如是问，
我等尚无心，况能闻是事。
声闻称希有，天神皆欢喜，
诸佛称其名，此是多闻果。
若有所问时，佛答其所问，
无量诸大众，皆得大饶益。
得闻是多闻，菩萨所问答，
无量众皆得，无上之法眼。」
```
（大意：见到诸佛之后，便能正确问难，声闻人听闻了，都为之欢喜：“此人甚为希有，能作这样的提问，我们尚且没有这样的心，何况能听闻这样的事。”声闻称其希有，天神都欢喜，诸佛称扬其名，这是多闻的果报。若有所问时，佛回答其所问，无量大众都得到大饶益。听闻这多闻菩萨的问答，无量大众都得到无上的法眼。）

【按】“称希有”之“称”，圣乙本作“积”。

#### 一切功德光明王佛与那罗延法师

佛告诉富楼那：“因为这个因缘，应当知道菩萨听闻未曾听闻之法，信受而不违逆，以正心思量，不即刻说它不对，便能饶益无量众生。富楼那！在过去无量无边不可思议阿僧祇劫，那时有佛，号为一切功德光明王如来、应供、正遍知、明行足、善逝、世间解、无上士、调御丈夫、天人师、佛、世尊。富楼那！这一切功德光明王佛寿命八十亿岁，那佛一次法会中的声闻弟子，不受诸法，漏尽解脱，如恒河沙数，这不可计数，这些阿罗汉都得到俱解脱。菩萨众的数目也是这样。富楼那！那佛灭度后，正法住世六万岁。将入涅槃时，佛给予百亿菩萨神力，为了护法，他们遍布在百亿阎浮提内，每一阎浮提各有一位菩萨。

【按】“皆与神力”之“与”，宋、元、明、宫、圣、圣乙本作“兴”。

“富楼那！一切功德光明王佛灭度之后，众弟子渐渐都懈怠，不再诵持这样的深经，诸法空经、净戒头陀经渐渐都灭尽，因为他们不能读诵宣说。那法广大，有八百四万法藏，每一法藏有六十八百万亿那由他修多罗，每一修多罗中有三万六千忧陀那，每一忧陀那中有七百六万亿偈。富楼那！最后末世法将灭时，在这么多的佛法藏中，只剩下一部修多罗忧陀那。那时有一位比丘法师，名为那罗延，在这阎浮提中。佛给予他神力，是为了护法。这那罗延法师多闻广博，善能说法，文辞严饰，义理明了，常乐于宣说未曾听闻之法。他说法时，多有人众违逆毁破。那罗延法师便这样想：‘这些人众，对未曾听闻之法，听了不能相信，不乐听受，若听了不理解，心不随顺，听后违逆，破坏、挑剔过失，这样说：“这不是佛语，不是大师之教。为什么呢？我们未曾从师父、和上那里听过这样的经。又诸长老比丘也不说曾从师父、和上那里辗转听过。”现在诸比丘只剩下一部修多罗忧陀那，我现在何不独处闲静。’富楼那！那罗延法师作此念后，独自进入深山。

【按】“和上”，明本作“和尚”。

“那时阎浮提中，从劫初以来有六万八千座大城，城长十二由旬，宽七由旬，装饰严整，街巷相对，人民充满，丰乐安隐。其后又续造八十四亿座小城，有宽七由旬，或六、五、四、三、二由旬的，其中最小的宽一由旬。富楼那！那时阎浮提中有一座大城，名为安乐，城中有一位长者，名为阇匿，有一个儿子，名为摩诃耐摩陀。这长者之子在空闲之处，有一位天人来为他说偈道：

```
「『汝当勤求法，求已正思惟；
功德王如来，已记汝作佛。』
```
（大意：“你应当勤求正法，求得之后正确思惟；功德王如来，已为你授记作佛。”）

#### 摩诃耐摩陀出家

“富楼那！天人说偈之后忽然不见。那时长者之子便到父亲那里，头面礼足，这样说：‘我想出家，在一切功德光明王佛的法中修习梵行。’那时阇匿长者以偈回答说：

【按】“以偈答曰”之“曰”，宋、元、明、宫、圣、圣乙本作“言”。

```
「『我家多财宝，金银无有量，
阎浮提所无，我家悉具有。
我所求财宝，为子受欲乐，
云何行出家，为世所轻贱？』
```
（大意：“我家多有财宝，金银无可计量，阎浮提所没有的，我家都具有。我所求取的财宝，是为了让儿子享受欲乐，为什么要去出家，被世人所轻贱？”）

【按】“为子受欲乐”之“受”，宋、元、明、宫、圣、圣乙本作“爱”。

“那时长者之子以偈回答父亲说：

```
「『我乐常求法，求已正思惟，
不乐受富乐，当为世作佛。
不须家业宝，我欲求少欲，
所出之法财，今当行出家。
诸佛出世难，佛说法亦难，
我今值佛法，云何当舍离？』
```
（大意：“我乐于常常求法，求得之后正确思惟，不乐于享受富乐，当为世间作佛。不需要家业的宝物，我想求得少欲，以及出世之法的财富，现在应当出家。诸佛出世难值，佛说法也难值，我现在值遇佛法，怎能舍离？”）

“富楼那！那时长者之子头面礼父亲之足，绕行之后出门，说这偈道：

```
「『设有一亿父，及有百亿母，
犹尚不能遮，今我出家心。
我舍身寿命，父母亲族财，
唯不舍佛法，当行出家求。』
```
（大意：“即使有一亿个父亲，以及有百亿个母亲，仍不能遮止我现在出家之心。我舍弃身体与寿命、父母、亲族与财物，唯独不舍佛法，当去出家求道。”）

“富楼那！那时长者之子说此偈后，出家为道。便到那罗延法师处，请求听法。那时那罗延法师便为他演说未曾听闻之经。那时摩诃耐摩陀比丘听闻未曾听闻之经后，问那罗延法师说：‘我对此经先前未曾听闻。这样的诸经，是谁读、谁诵、谁受持的？从何处听来？’那罗延说：‘我因宿世善根的因缘，也因一切功德光明王佛的威神之力，这样的深经自然在心中。’富楼那！这摩陀比丘听了这话之后，更加用心思念，智力随即生起。以大智慧方便之力，问难那罗延法师。那罗延随其义理回答之后，这样说：‘一切功德光明王佛时，有一位比丘向佛问这件事，就如你现在所问，佛这样回答。’那时这比丘听后欢喜。富楼那！这摩诃耐摩陀比丘又问那罗延法师。那罗延说：‘一切功德光明王佛时，有一位比丘问这样的事，就如你现在所问，佛这样回答。’那时这比丘听后欢喜。

【按】“摩诃耐摩陀比丘”之“诃”，《大正藏》作“阿”，宋、元、明、宫、圣、圣乙本作“诃”，今依CBETA（所录高丽藏）作“诃”。第二处“闻已欢喜”之下，宋、元、明、宫、圣、圣乙本多出“摩诃耐摩陀比丘复问那罗延法师……”一段重复问答。

#### 那罗延说一法门摄一切问答

“富楼那！那时摩陀比丘对那罗延法师说：‘正士！往昔从佛那里听过多少这样的问答之事？’那罗延说：‘暂且不要问这个。这事难以相信，其余未亲证增上法的人也难以相信。’第二次、第三次也这样问。摩诃耐摩陀问道：‘正士！往昔从佛那里听过多少这样的问答之事？’那罗延说：‘暂且不要问这个。若不得已，现在当为你以譬喻解说，有智慧的人借譬喻能够理解。比丘！我在一切功德光明王佛之所，听闻众生之性多于大地的微尘。比丘！假使一切三千大千世界的众生，有色的、无色的，有想的、无想的、非有想非无想的，全部令其得到人身，有智慧之力，每一个众生在弹指之间能提出恒河沙数那么多的问题，而所问的各各不同。比丘！这样辗转，乃至十方无余世界的一切众生，在一劫或超过一劫中提出这些问题。又有一人，能在弹指之间提出这么多人的一切问题，各各差别不同。这样一人，又穷尽一切无余众生，在一劫或少于一劫中提出种种问题。你认为怎样？所提出的问题多不多？’回答说：‘甚多，不是譬喻所能及的。’

【按】“减一劫”之“减”，圣乙本作“灭”。

“那罗延对摩陀比丘说：‘我现在明白地告诉你，不要生起疑悔。如那一切无余众生在一劫或少于一劫中所提出的疑问，我从佛听闻，在一个法门中所作的回答比那还多。这样二门、三、四、五门，十、二十、三十、四十、五十，乃至百千万亿门，比丘！我当略说一切所有算数名字，无量无尽，不可思议，超过这些数目的，我都诵持。比丘！这些回答全都总摄在一个法门中，我都知道，就是一切功德光明王如来所说的道句、门句、印句、本事句、金刚句、重句、不可动句、难得底句。比丘！在一门中摄一切法，就是无作门。一切诸法、一切诸句，以这门为根本，都入于这门。一切修多罗忧陀那都入于门句，分别一个字能入于许多字。比丘！这样能入于七万八千种陀罗尼，其中有九万二千种诸根的差别。在这众生行门中，有八万亿种形色，在诸道中各有差别，这些形色我都知道其名。在每一种色中我知道一百个名字，这样二百个名字、三百个名字，乃至知道一千个名字，都在阎浮提中。又超过这里的十方佛国，其中所有各各的因缘、各各的名字，我都能知道。总而言之，佛所有的力量，在诸法中各各的差别、问答的差别，我都知道，这都是一切功德光明王如来的威神之力。’

#### 摩陀卫护那罗延流布正法

“富楼那！那时摩陀比丘对那罗延法师说：‘唯愿正士回到聚落城邑，随顺转动一切功德光明王如来的法轮。愿接受我的请求，我将卫护，作为受法之人。’那罗延说：‘暂且不说这个。现今的比丘都懈怠，对于积集善法没有深切的意欲。’摩陀又说：‘我从今日起，当对善法深生意欲，为求此法不敢懈怠。’富楼那！摩陀比丘便请那罗延回到聚落说正法，自己将随从卫护，咨问听闻未曾听闻之法。

【按】“摩陀比丘语那罗延法师”之“语”，圣乙本作“诸”。

“富楼那！那时摩陀比丘多为人众所供养恭敬，当时的人都认为他持戒、智慧、多闻最上，功德无量。那时摩陀比丘进入城邑聚落，称赞那罗延法师，为了令众生入于正法，又使佛法普遍流布。富楼那！那时摩陀比丘多方引导人众，使他们供养法，恭敬守护那罗延法师，为了听法。富楼那！其后那罗延法师被摩陀比丘守护之后，进入城邑聚落，以种种方式广说一切功德光明王如来在阿僧祇劫中所修的菩提，令其普遍流布。像这样，富楼那！摩陀比丘在百年中常随那罗延法师，所问的诸法常是新异的，未曾重复宣说。富楼那！那罗延法师因为得到这摩陀比丘的护持帮助，使无量众生安住于圣法中，无量众生安住于佛菩提。富楼那！你认为那时的那罗延法师，那守护法、善说法的人，是别人吗？就是弥勒菩萨。

#### 摩陀辗转值佛问经

“富楼那！摩陀比丘守护法师，辅佐帮助，劝请说法，以这福德之力，命终之后，便生到下方第十世界上众佛之所，在那佛前请问断一切众生疑经。佛那时称赞百千声善哉，便为他演说断一切众生疑经。说此经时，无量众生初发阿耨多罗三藐三菩提心，便入于必定。富楼那！摩陀比丘命终之后，又值遇须弥山佛，在那佛前请问摄出一切法经。那时佛称赞百千声善哉，便为他广说摄出一切法门经。说此经时，无量众生必定得阿耨多罗三藐三菩提。命终之后，又值遇山王佛，在那佛前请问诸法门经。那时佛称赞百千声善哉，便为他广说一切法门经。说此经时，无量众生必定于阿耨多罗三藐三菩提。命终之后，又值遇梵音声佛，在那佛前请问摄一切法经。佛那时称赞百千声善哉，便为他广说摄一切法经。说此经时，无量众生必定于阿耨多罗三藐三菩提。

【按】“佐助劝请”之“劝”，圣乙本作“观”。

“富楼那！摩陀比丘这样辗转，所值遇的诸佛，值遇之后请问经典，所度的众生，令他们安住于阿耨多罗三藐三菩提。我若以一劫或超过一劫的时间，宣说那些佛的名号以及众生所住的阿耨多罗三藐三菩提，也说不尽。富楼那！这摩陀比丘所护持的诸佛正法，恒河沙尚可计数，这些佛，无论现在住世的或已灭度的，都不可称计。所以富楼那！应当知道菩萨摩诃萨听闻未曾听闻之法，思惟义理，得到这样等大功德利益。富楼那！你认为那时的摩诃耐摩陀比丘，在那罗延法师处听闻未曾听闻之法、随顺其义趣的人，是别人吗？就是桥越兜菩萨。那时摩诃耐摩陀比丘守护正法，听闻未曾听闻之法，随顺其义趣，不执著言辞，因为这因缘值遇无量佛，值遇后听闻种种深妙之经。由于往昔这善根因缘，现今在我这里也请问摄一切法大海法门经。我为他宣说时，无量众生得到大饶益。”那时世尊想再次阐明此事，说偈道：

【按】“恒沙可数”，圣乙本作“恒河沙数”。“岂异人乎”之“乎”，圣本作“于”。

```
「菩萨闻未闻，应思其义理，
不应作是言：『我昔未曾闻。』
闻所未闻法，正念思其义，
是故慧增长，如海受众流。
多闻转增上，智慧亦复尔，
能问诸佛事，广利诸众生。
集多闻如海，智慧不可尽，
善能知章句，差别中第一。
是故应当闻，所未曾闻法，
求所未闻法，得如是果报。
```
（大意：菩萨听闻未曾听闻之法，应当思惟其义理，不应当这样说：“我往昔未曾听过。”听闻未曾听闻之法，以正念思惟其义，所以智慧增长，如大海容受众流。多闻辗转增上，智慧也是这样，能请问诸佛之事，广利众生。积集多闻如大海，智慧不可穷尽，善能了知章句，在差别之中第一。所以应当听闻未曾听闻之法，求取未曾听闻之法，便得到这样的果报。）

【按】“能问诸佛事”之“问”，元、明、圣、圣乙本作“闻”。

#### 菩萨真实精进

“又，富楼那！菩萨摩诃萨对于求多闻深生意欲，对于空闲之处深生乐心，一心勤求阿耨多罗三藐三菩提。求得之后，为断瞋恚而修集慈观，为断贪欲而修不净观，为断愚痴而修因缘观。富楼那！什么是菩萨的精进？菩萨怎样修集精进？富楼那！若有菩萨在一劫或少于一劫中，无论行走或坐着，常发精进。富楼那！这样不名为真实精进。有菩萨在一劫或少于一劫中修行净戒，苦行难行，具足头陀，对所缘之事深生意欲，却离开诸法实相，这样不名为真实精进。”

富楼那对佛说：“世尊！什么是菩萨的真实精进，为诸佛所称赞，世间有智之人所不讥嫌？”佛告诉富楼那：“菩萨对于未曾听闻的、与甚深空法相应、没有丝毫之相、契合第一义的这样的深经，不违不逆，明了其义，勤发精进，心不退没，听受读诵，为人解说，这名为菩萨的真实精进。就是听闻深经，通达其义，不违不逆，这样的精进为诸佛所称赞，世间有智之人所不能呵责。所以富楼那！菩萨应当发起这样的庄严：世间众生不能到底的，我在其中当穷尽其底。世间众生所会沉没之处，我在其中不应沉没。世间众生所会畏惧之处，我在其中不应怖畏。为什么呢？我发起庄严不与世间相合，是为了离开世间法而发起庄严；不是为了行世间法而发起庄严，是为了不行世间法而发起庄严；不是为了随顺世间法而发起庄严，是为了转变世间法而发起庄严。富楼那！这名为菩萨摩诃萨的真实精进。菩萨成就这第二法，便于阿耨多罗三藐三菩提不退转。”那时世尊想阐明此义，说偈道：

【按】“菩萨应发”之“应”，圣乙本作“摩”。“为不行世法”之“世”，元、明本无。

```
「菩萨求深法，常勤发精进，
思量其义理，不随于音声。
菩萨不随言，知皆是虚诳，
知诸法空故，但求于善语。
若于千万亿，无量诸劫数，
昼夜常行坐，加心行苦行。
于所未闻经，不信非精进，
能得深义底，不名为懈怠。
```
（大意：菩萨求取深法，常常勤发精进，思量其义理，不随顺于音声。菩萨不随顺言语，知道言语都是虚诳，因为知道诸法是空，只求取善妙之语。若在千万亿无量劫数中，昼夜常常行走或坐着，更加用心修行苦行；对未曾听闻之经却不相信，这不是精进；能得到深义之底的，不名为懈怠。）

【按】“千万亿”之“亿”，圣乙本作“信”。

```
如是精进者，诸佛所称叹，
世间不得底，菩萨得其底，
世间所畏没，菩萨不畏没，
勤心常欲求，空寂真妙法。
空法中无畏，亦无有退没，
住我相法相，故生怖畏没。
散坏一切法，名为菩提道，
勤心发精进，疾成多闻海。
```
（大意：这样精进的人，为诸佛所称叹，世间不能到底的，菩萨得到其底；世间所畏惧沉没之处，菩萨不畏惧沉没，勤心常想求取空寂的真妙之法。在空法中没有畏惧，也没有退没，因为住于我相、法相，所以生起怖畏与沉没。散坏一切法，名为菩提之道，勤心发起精进，迅速成就多闻之海。）

#### 善知阴入界缘得无依止智

“又，富楼那！菩萨善知五阴，善知十二入，善知十八界，善知十二因缘，因为善知五阴、十二入、十八界、十二因缘，便能成就无依止的智慧。因为得到无依止的智慧，便对一切法不忆念、不分别。以不忆念、不分别为众生说法，破除一切见，令他们拔除身见。菩萨成就这第三法，便于阿耨多罗三藐三菩提不退转。”那时世尊以偈颂说：

```
「菩萨知五阴，十二入皆空，
分别十八界，通达十二缘。
不随于五阴，知身是虚诳，
于诸内外入，悉知其性空。
如是知诸法，知已为人说，
是故此菩萨，智慧转高大。
```
（大意：菩萨知道五阴、十二入都是空，分别十八界，通达十二因缘。不随顺于五阴，知道身是虚诳，对于种种内外之入，都知道其本性是空。这样了知诸法，了知之后为人宣说，所以这位菩萨，智慧辗转高大。）

#### 学一切法是菩萨学戒

“又，富楼那！菩萨摩诃萨对于所制定的戒、所宣说的戒，善能随顺修学，没有缺犯。什么是菩萨学戒？学一切法是菩萨学戒。为什么呢？富楼那！菩萨学一切法，得到一切法的智慧，以这法智得到无分别的智慧，以这无分别的智慧能知一切事。怎样知一切事？菩萨都知道一切内事、一切外事、一切内外事。

“富楼那！为什么名为内？内是指凡所有领受、可以贪著之处，就是这从十二因缘所生的内身，其中只有世俗的假名，就是这眼、这耳、这鼻、这舌、这身、这意。富楼那！这名为内。这些法因为是凡夫所贪著的，所以名之为内。他们这样说：‘我当得到这样的眼，不要这样的眼；得到这样的耳、鼻、舌、身、意，不要这样的耳、鼻、舌、身、意。’其中只因所起的业缘而有果报生起，所以名为内。其中的种种差别，凡夫贪著，说这是眼、是耳、身、鼻、舌、意，都名为内。又，富楼那！内名为二。此事虚诳，凡夫们贪著受取，而生起诤讼。

【按】“是耳身鼻舌意”之“身鼻舌”，明本作“鼻舌身”。

“富楼那！如来对此，从本以来如实了知而不贪著。如来怎样如实了知而不贪著？如来在此法中不作归依。是谁不作归依？是爱结。这眼不作归依，离眼也不作归依；耳、鼻、舌、身、意不作归依，离意也不作归依。为什么呢？富楼那！如来于法不得内，也不得外，所以如来在此法中不作归依。如来是实语者，这样说：‘比丘！眼不是你们的，也不是他人的。为什么呢？因为其本体不可得。什么法是眼？这眼属于谁？什么法是耳、鼻、舌、身、意？这意属于谁？为什么呢？因为其本体不可得。’

【按】“不得外”之“得”，圣、圣乙本作“可”。

“富楼那！眼现在应当推究检查，耳、鼻、舌、身、意现在应当推究检查，于法无所贪受。为什么呢？若有所受之法，便生苦恼，因为苦恼生起，便没有快乐。所以富楼那！于法有所受，都是受苦恼，若受苦恼，便不能离苦。富楼那！这名为推究检查眼，推究检查耳、鼻、舌、身、意，没有进入之处。为什么呢？富楼那！若有进入之处，便有出离之处。所以如来在经中说，眼是空、无我、无我所，本性如此。耳、鼻、舌、身、意是空、无我、无我所，本性如此。这本性无性，这样无性，无作无坏。富楼那！这样的法性，无论诸佛出世或不出世，这本性常住。如来对诸法之生，知其是不生，所以如来是实语者，这样说：‘无论有佛出世或佛不出世，这本性常住。’

【按】“是名推捡眼”之“推”，宫本无。“无有入处”之“入”，圣乙本作“人”。

#### 无生与无生智

“富楼那！什么名为无生？什么名为无生智？富楼那！诸法平等名为无生，道名为无生智。苦尽名为无生，道名为无生智。这名为如来宣说有二谛，就是世俗谛、第一义谛。富楼那！如来所说的苦相，就是说无相。什么名为苦相？就是无为之相，无为就是无相。智者知道无为是无相。富楼那！智者怎样知道无为是无相？就是知道无为法是空，知道是寂灭，知道是归处，知道是第一利益，知道是无热恼。智者这样了知无为，在这智慧中也不生起相。富楼那！智者离开诸相，得到第一义利，无作无坏。富楼那！若人有所作，便是坏；若无作，便无坏。无坏之相是空，无坏之相是无相，无坏之相是无愿。富楼那！空法没有人作，没有人坏，无相、无愿没有人作，没有人坏。富楼那！这名为诸佛阿耨多罗三藐三菩提不坏之相。什么是诸佛的阿耨多罗三藐三菩提？就是诸如来所不得的。”

【按】“所不得是”之“是”，宋、元、明、宫本无。

#### 一切法皆是菩提

富楼那对佛说：“世尊！什么法是诸如来所不得的？”佛说：“富楼那！一切法是诸如来所不得的。”“世尊！因此一切法是诸佛的菩提吗？”佛说：“是这样。富楼那！一切法是诸佛的菩提，而这菩提不名为一切法。说一切法是诸佛的菩提，只是以世俗假名言说，不精进的人难解难知。为什么呢？不精进的人不能修习诸法平等，若不平等，便与佛相诤。富楼那！什么人不能修行平等？富楼那！一切世间都行于不平等，诸佛的菩提，其中无等也无不等。富楼那，我以这道得阿耨多罗三藐三菩提。因为这因缘，我在经中说一切诸法在正位中都入于必定，这名为必定入菩提门。所以富楼那！一切法都是菩提。”

【按】“诸法平等”之“法”，宋、宫本无。“阿耨多罗”之“罗”，《大正藏》作“萨”，今依CBETA（所录高丽藏）作“罗”。

那时富楼那对佛说：“希有，世尊！这诸佛的阿耨多罗三藐三菩提，亦定亦不定，亦入文字亦不入文字，亦入语言亦不入语言。为什么呢？世尊！我现在从佛听闻宣说此经，在诸法中普遍得到决定的光明。世尊！我现在这样在诸法中得到决定的光明，在一事中知一切事，在知一切事中知一事。”

【按】“知一切事中”之“知”，宋、元、明、宫本作“于”。

#### 富楼那往昔退失菩提心

那时佛赞叹富楼那说：“善哉善哉！富楼那！你能这样迅速入于诸佛的一切法利，应当知道你已曾在过去世供养诸佛，种诸善根，亲近咨问。富楼那！我忆念过去，在这片土地的虚空分中，你已曾在六万八千诸佛之所听闻此经。因为这善根功德的因缘，你在诸法中普遍得到决定的光明。”

“世尊！若我已在若干佛所听闻此经，我为什么不能以一念发起阿耨多罗三藐三菩提心呢？”佛告诉富楼那：“我忆念过去世，你曾在一劫中发阿耨多罗三藐三菩提心，不掺杂其余之心，却又退失了。因为这福德因缘，我现在说你在诸法师中最为第一。”富楼那对佛说：“世尊！我本来作了什么罪障，在一劫中发阿耨多罗三藐三菩提心却又退失？”佛说：“富楼那！因为随逐依止恶知识，又不能广为流布正法，你对阿耨多罗三藐三菩提心又退失了。

【按】“若千佛所”之“千”，宋、元、明、宫、圣、圣乙本作“干”。“不杂余心”之“杂”，宋、明、圣乙本作“离”。

#### 四法退失菩提成声闻乘

“富楼那！有四法会退失阿耨多罗三藐三菩提，成为声闻乘。哪四种？菩萨因为亲近恶知识，能令善根增恶、远离，那恶知识这样说：‘何必这样发菩提心？生死长远，苦恼无量，往来于五道，生于无难之处难，值遇诸佛难，得净信也难，即使值遇佛，出家又难。你现在得以生于无难之处，不要再失去。你在诸佛之所还未受阿耨多罗三藐三菩提记，善根未定，不得涅槃，还要轮转五道。’此人听了这话之后心便退没，对菩提道懈怠不乐。富楼那！菩萨有这第一法，退失菩提，成为声闻乘。

“又，富楼那！菩萨不听闻与菩萨相应的经，就是菩萨藏经、发菩萨心经、摄菩萨事经、应六波罗蜜经。因为不听闻，所以不能如所说而行，不能如所说而学，此人不知道菩萨什么法应当亲近，什么法应当远离，什么法应当受持，什么法不应受持，什么法是菩萨法，什么法是声闻法。因为这样不知、不分别，应当亲近的法却不亲近，不应亲近的法反而亲近。此人因为应当亲近的法不亲近，不应亲近的法却亲近，便退失诸佛的菩提，心弱懈怠厌倦，废舍本愿。富楼那！菩萨有这第二法，退失菩提，成为声闻乘。

【按】“发菩萨心经”之“萨”，明本作“提”。“废舍”之“废”，《大正藏》作“癈”，今依CBETA（所录高丽藏）作“废”。

“又，富楼那！菩萨计执诸法可得，贪著吾我，行于邪见，堕在边见，沉没在恶邪之中，难以拔出。听闻契合第一义、没有丝毫之相的深经，违逆不信，不能通达，造下破法之罪。因为这因缘，生在难处，不得值遇佛，不得听闻法，不得值遇诸佛所教化之法，不得善知识。此人因为不见佛，所以不闻法；因为不闻法，所以不值遇诸佛所教导之法；因为不值遇诸佛所教导之法，所以不得善知识；因为不得善知识，所以失去无难之处，生在难处；因为在难处，所以离开善知识，遇到恶知识；因为与恶知识共事，所以忘失本来的忆念；此人因为失去本来的忆念，所以舍弃菩萨心，舍弃菩萨乘而退转，永远失去菩提之念，只行生死之法，不能修习大乘行法。富楼那！菩萨有这第三法，退失菩提，成为声闻乘。

“又，富楼那！菩萨听闻这样等经，却不能以深心教化他人，其心退没，只乐于独行，悭吝惜法，心不想说，不能以法广摄人众。因为这不善根的因缘，失去智慧之念。失去智慧之念后，不与他人共同读诵经法。不能以法与他人共享，此人转生之后失去菩萨心，忘失菩萨念。富楼那！菩萨有这第四法，退失菩提，成为声闻乘。”那时世尊想阐明此事，说偈道：

```
「亲近恶知识，懈怠于菩提，
以是因缘故，失上菩提心。
深生恶我见，堕在边邪见，
而起破法罪，生在于难处。
生于难处已，则断菩提心，
忘失本忆念，是故失菩提。
是人不得闻，生菩提心法，
是心若增长，能成于菩提。
```
（大意：亲近恶知识，对菩提懈怠，因为这个因缘，失去无上的菩提心。深生邪恶的我见，堕在边见与邪见中，造下破法之罪，生在难处。生在难处之后，便断了菩提心，忘失本来的忆念，所以失去菩提。此人不得听闻生起菩提心之法，这心若增长，能成就菩提。）

```
得广大妙法，悭悋不欲说，
以是因缘故，退失于菩提。
求大乘菩萨，应知是四法，
若知此四法，菩提得以生。
是故应远离，如此四恶法，
勤修行空法，得近善知识。
得如是经已，不应悭悋惜，
勤心为人说，从是生菩提。」
```
（大意：得到广大妙法，却悭吝不想宣说，因为这个因缘，退失了菩提。求大乘的菩萨，应当了知这四法，若知道这四法，菩提便得以生起。所以应当远离这样四种恶法，勤修空法，得以亲近善知识。得到这样的经之后，不应悭吝爱惜，应勤心为人宣说，菩提由此而生。）

#### 四法令回向不失

佛告诉富楼那：“菩萨成就四法，随其回向，菩提心不退失，随其回向的诸善根也不退失。哪四种？菩萨持戒清净，忆念成就，有正念安住的智慧，勤心精进而不懈怠退转，成就多闻而生智慧。富楼那！菩萨有这四法，随其回向，菩提心不退失，随其回向的诸善根也不退失。”那时世尊想阐明此义，说偈道：

```
「菩萨具持戒，所忆念深远，
勤心当精进，多闻庄严慧。
菩萨常亲近，如是之四法，
随心所起事，皆能得成就。
是故应常持，净戒勤精进，
不断忆念法，常勤求多闻。
持戒净生处，忆念能净智，
精进净佛法，多闻生大慧。
是故诸菩萨，当学是上法，
学是上法已，当转无上轮。
```
（大意：菩萨具足持戒，所忆念深远，勤心应当精进，以多闻庄严智慧。菩萨常亲近这样的四法，随心所起之事，都能得以成就。所以应当常持净戒，勤行精进，不断忆念于法，常勤求多闻。持戒清净受生之处，忆念能清净智慧，精进能清净佛法，多闻能生起大慧。所以诸菩萨应当学习这上妙之法，学习这上妙之法后，当转无上法轮。）

#### 四法利益菩提

“又，富楼那！菩萨有四法，便能利益菩提。持戒便是利益菩提之法，忍辱便是利益菩提之法，精进便是利益菩提之法，多闻便是利益菩提之法。富楼那！这名为四法利益菩提。”那时世尊想阐明此义，说偈道：

```
「菩萨净持戒，利益于菩提，
精进及忍辱，多闻亦如是。
清净持戒者，所愿皆得成，
戒净多利益，菩提不为难。
菩萨行忍辱，身相智慧成，
是故当行忍，求佛相智慧。
精进亦复能，多利益菩提，
常行精进者，菩提则不难。
多闻亦能利，闻已得近法，
远离于非法，菩提则不难。
四法是种子，从是生菩提，
是故诸菩萨，应近是利法。
```
（大意：菩萨清净持戒，能利益菩提，精进以及忍辱，多闻也是这样。清净持戒的人，所愿都能成就，戒清净多有利益，菩提并不困难。菩萨修行忍辱，身相与智慧得以成就，所以应当修行忍辱，以求佛的相好与智慧。精进也能多多利益菩提，常行精进的人，菩提便不困难。多闻也能利益，听闻后得以亲近正法，远离非法，菩提便不困难。四法是种子，从此生出菩提，所以诸菩萨应当亲近这些利益之法。）

【按】宫本于“菩提则不难”下重出“精进亦复能，多利益菩提，常行精进者，菩提则不难”一偈。

#### 四法得身色财物眷属具足：行一切法空慈

“又，富楼那！菩萨摩诃萨成就四法，便得到身色具足、财物具足、眷属具足，始终不生于种种恶难之处，常值遇诸佛，为诸佛所称赞。哪四种？菩萨行慈，不瞋恨、不恼害一切众生。富楼那！什么叫作菩萨行慈，不瞋恨、不恼害一切众生？菩萨行慈，对众生生起‘我来救护’的慈心，见到众生身苦心苦，应当这样想：‘我当勤行精进，度化这些众生。对于生死之苦中的这些众生，我应当给予快乐，我应当拔济他们离开生死之苦。’对众生应当发起这样的心，发起这心之后，勤行精进，修习六波罗蜜：布施、持戒、忍辱、精进、禅定、智慧。

【按】“财物具足”之“财”，圣乙本作“则”。

“富楼那！菩萨因为般若波罗蜜，得以具足六波罗蜜。什么是菩萨的般若波罗蜜？菩萨怎样因般若波罗蜜而勤发精进？富楼那！菩萨这样思量：‘什么法名为我？什么法名为我所？’这样思量时，不见有法是我，不见有法是我所。这样想：‘这样想之后，在此法中没有我法，没有我所法。’菩萨因为离开我、我所，所以知道身空；因为身空，所以众生空。为什么呢？在诸法中，我、我所尚且是空，何况众生。菩萨这样因为离开我、我所，所以知道众生空；因为众生空，所以知道色阴空；因为色阴空，所以受、想、行、识阴空。菩萨这样因为离开我、我所，所以知道身空；因为身空，所以知道众生空；因为众生空，所以知道诸阴空。因为诸阴空，所以知道诸种也空，就是地、水、火、风、虚空、识种，地种的地种之相空，水、火、风、虚空、识种的识种之相空。这些种没有作者，没有使作者，若没有作者，这法便是空。

“富楼那！菩萨在此因为离开我、我所，所以知道身空；因为身空，所以知道众生空；因为众生空，所以知道诸阴空；因为知道诸阴空，所以知道诸种空；因为诸种空，所以知道诸入空；因为诸入空，所以诸入之相空。诸入没有作者，没有使作者，若法没有作者、没有使作者，这法便是空。富楼那！菩萨以此观一切法空。观一切法空时，不见诸法的本体中有可以生起瞋恚之处。富楼那！这名为菩萨摩诃萨的大慈。知身空之慈、众生空之慈、阴入种空之慈，菩萨若能行这样的慈，这名为行一切法空之慈。富楼那！这名为菩萨行于大慈。

“这样，菩萨离开我、我所，心中对阿耨多罗三藐三菩提深生意欲，对众生生起大悲心。若有众生不知这样的诸法实相，为了令他们知道而发起大庄严，这名为菩萨行于大悲。‘我来救护’，所以名为慈；‘我来作为’，所以名为悲。菩萨成就这样的大慈，能为众生作救护、作归依、作屋舍、作洲渚，能作究竟。所以菩萨应当这样修行大慈，不贪著众生，也不生瞋恨，这名为菩萨众生空之慈，没有瞋恚。富楼那！若菩萨因为慈、因为离、因为空，能入一切诸法不生不灭，这名为菩萨常行大慈。菩萨这样通达诸法，诸魔、魔民以及魔所使唤的，都不能破坏。菩萨成就这第一法，能断除一切功德中的系缚，因为断除功德的系缚，得到平等波罗蜜。”那时世尊想阐明此事，说偈道：

【按】“因离因空”之“离”，明本作“利”。“功德中缚”之“缚”，《大正藏》作“转”，今依CBETA作“缚”。

```
「菩萨常如是，修慈而观空，
知阴入界离，是中无有我。
我我所二法，决定不可得，
为不得诸法，而修行慈心。
不依止诸法，亦非不依止，
是名诸佛道，诸不依止法。
能得无上忍，忍诸法实相，
诸法无生灭，能善通其理。
诸有大智者，亲近于是法，
常得妙身色，亦得乐说辩，
常得值诸佛，知诸法义利，
是故此菩萨，得无为上道。
```
（大意：菩萨常这样，修慈而观空，知道阴、入、界都是离，其中没有我。我与我所二法，决定不可得，为了不执得诸法，而修行慈心。不依止诸法，也不是不依止，这名为诸佛之道，种种不依止之法。能得到无上的忍，忍可诸法实相，诸法无生无灭，能善于通达其理。凡是有大智慧的人，亲近这样的法，常得美妙的身色，也得到乐说之辩，常得值遇诸佛，了知诸法的义利，所以这位菩萨得到无为的上道。）

【按】“菩萨常如是”之“如”，宋、元、明、宫本作“知”。

#### 供养佛塔

“又，富楼那！菩萨摩诃萨精勤供养诸佛塔寺，以恭敬之心，用好的花、香、璎珞、涂香、末香、幡盖、伎乐等种种供具来供养。菩萨成就这第二法，能得到具足一切功德。”那时世尊想阐明此义，说偈道：

【按】“缨珞”之“缨”，宋、元、宫本作“璎”。“妓乐”之“妓”，宋、宫本作“伎”。

```
「菩萨以上妙，供养上智塔，
花香及幡盖，以求上智慧。
以此功德缘，受身常端正，
饶财多宝珍，眷属具成就。
必定于菩提，常安住于法，
在在所生处，功德转高增。
诸王所恭敬，天龙神常念，
一切诸众生，亦皆共恭敬。
若人供养佛，现在若灭后，
所生得供养，常在无难处。
```
（大意：菩萨以上妙之物供养具上智者的佛塔，以花、香以及幡盖，以求取上等智慧。以这功德因缘，所受之身常常端正，多有财物与宝珍，眷属都具足成就。必定趣向菩提，常安住于法，在一一所生之处，功德辗转高增。为诸王所恭敬，天、龙、神常常护念，一切众生也都共同恭敬。若人供养佛，无论佛在世或灭度后，所生之处都得供养，常在无难之处。）

#### 供养法

“又，富楼那！菩萨摩诃萨常当勤心供养于法。什么名为法？什么名为供养法？名为四念处、四正勤、四如意足、四禅、五根、五力、七觉意、八圣道、止观、明、解脱、三解脱门、尽智、无生智，这名为法。怎样供养？对这些法如所说而行，随顺不逆，生起意欲精进，具足修习，这名为供养法。又，富楼那！供养法，法名为这样等经，信解、思惟、分别、随顺，心不违逆，这名为供养法。菩萨成就这第三法，能得到具足一切功德。”那时世尊想阐明此义，说偈道：

```
「常勤供养法，如所说中住，
闻深空妙法，其心不违逆，
故身常端正，亦得乐说辩。
如我所赞法，以此转高增。
```
（大意：常勤供养于法，安住于如所说之中，听闻甚深空妙之法，其心不违逆，所以身相常端正，也得到乐说之辩。如我所称赞的法，因此辗转高增。）

#### 供养圣众

“又，富楼那！菩萨摩诃萨勤心供养如来的圣众，或以花，或以香，或以璎珞，或以末香，或以涂香，或以幡盖、衣服、饮食、卧具、医药等资生之物，或建造僧坊，或建立园林、经行之处，或以浴池，或以井泉，或以人使，像这样等其余供具，以种种方式供养这样的圣众。菩萨成就这第四法，能得到具足一切功德。”那时世尊想阐明此义，说偈道：

```
「无上供养具，供养如来众，
以此功德缘，所生多财宝，
身色常端正，亦得乐说辩，
具足诸功德，智慧转高增。
供养正直心，无我我所者，
以此智因缘，生处得供养。
诸佛所称赞，四法常亲近，
所生常尊贵，功德转高增。」
```
（大意：以无上的供具供养如来的圣众，以这功德因缘，所生之处多有财宝，身色常常端正，也得到乐说之辩，具足种种功德，智慧辗转高增。以正直之心供养没有我、我所的人，以这智慧因缘，所生之处都得供养。为诸佛所称赞，常亲近这四法，所生之处常为尊贵，功德辗转高增。）
