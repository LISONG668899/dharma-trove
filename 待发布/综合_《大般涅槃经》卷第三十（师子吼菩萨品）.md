# 《大般涅槃经》卷第三十（师子吼菩萨品）

北凉·天竺三藏昙无谶 译　刘宋·沙门慧严等 依《泥洹经》再治

## 师子吼菩萨品之六

### 既有佛性，何须修道

师子吼菩萨说："世尊，若一切业不必定得果，一切众生都有佛性，应当修习八圣道，以什么因缘一切众生都不能得这大般涅槃？世尊，若一切众生有佛性，就应当必定得无上正等正觉，何必修习八圣道？

"世尊，如这部经中说有病人：若得到医药及看护、合宜的饮食，或者得不到，都能痊愈。一切众生也是这样：若遇到声闻、辟支佛、诸佛菩萨、诸善知识，或者听法修习圣道，或者不遇、不闻、不修习道，都当得成无上正等正觉。为什么呢？因为有佛性。

"世尊，譬如日月，没有什么能遮止它们不到达頞多山边；四大河水，没有什么能遮止它们不流入大海；一阐提等，没有什么能遮止他们不堕地狱。一切众生也是这样，没有什么能遮止他们不到达无上正等正觉。为什么呢？因为有佛性。

【按】頞多山，即日落之山（西方之山）。

"世尊，因为这个道理，一切众生不须修道，以佛性之力，应当得无上正等正觉，不是以修习圣道之力。世尊，若一阐提、犯四重禁、五逆罪等不能得无上正等正觉，才应当修习；因为依佛性必定当得，不是因修习然后才得。世尊，譬如磁石，离铁虽远，以其力量，铁就随之吸附；众生的佛性也是这样，所以不须勤修习道。"

### 恒河七种人

佛说："善哉，善哉！善男子，如恒河边有七种人，或者为了洗浴，或者畏惧盗贼，或者为了采花，就进入河中。

"第一种人，入水就沉没。为什么呢？因为体弱无力，不习游泳。

"第二种人，虽然沉没又浮出，浮出之后又沉没。为什么呢？因为身力大，所以能浮出；因为不习游泳，浮出之后又沉没。

"第三种人，沉没之后随即浮出，浮出之后不再沉没。为什么呢？因为身重，所以沉没；因为力大，所以浮出；因为先已习于游泳，浮出之后就能停住。

"第四种人，入水就沉没，沉没之后又浮出，浮出之后就停住，环顾四方。为什么呢？因为身重，所以沉没；因为力大，所以又浮出；因为习于游泳，就能停住；因为不知出路，所以观看四方。

"第五种人，入水就沉没，沉没之后又浮出，浮出之后就停住，停住之后观看方向，看了就离去。为什么呢？因为怖畏。

"第六种人，入水之后就前进，到浅处就停住。为什么呢？因为要观察盗贼的远近。

"第七种人，已经到达彼岸，登上大山，不再有恐怖，远离诸怨贼，受大快乐。

#### 合法：七种人

"善男子，生死大河也是这样，有七种人。

"因为畏惧烦恼之贼，发意想渡生死大河，出家剃发，身披法服；出家之后，亲近恶友，随顺其教，听受邪法，即：'众生之身就是五阴，五阴就名为五大；众生若死，就永远断了五大；断了五大，何必修习善恶诸业？所以应当知道没有善恶以及善恶之报。'这就名为一阐提。一阐提名为断善根，因为断了善根，沉没在生死河中，不能出来。为什么呢？因为恶业深重，没有信力。如恒河边的第一种人。

"善男子，一阐提之辈有六种因缘，沉没在三恶道中不能出来。哪六种？一是因为恶心炽盛，二是因为不见后世，三是因为乐于习近烦恼，四是因为远离善根，五是因为恶业障隔，六是因为亲近恶知识。

"又有五事沉没在三恶道中。哪五事？一是在比丘那里作非法之事，二是在比丘尼那里作非法之事，三是自在地使用僧祇之物，四是在母亲那里作非法之事，五是在五部僧中互相是非。

"又有五事沉没在三恶道中。哪五事？一是常说没有善恶之果，二是杀害发菩提心的众生，三是喜说法师的过失，四是法说为非法、非法说为法，五是为了寻求法的过失而听受。

"又有三事沉没在三恶道中。哪三事？一是说如来无常永灭，二是说正法无常迁变，三是说僧宝可以灭坏。所以常沉没在三恶道中。

"第二种人，发意想渡生死大河，因为断了善根，沉没而不能出。所说的出，是亲近善友，就得信心。信心，是相信布施有布施之果，相信善有善果，相信恶有恶果，相信生死是苦、无常、败坏，这名为信。因为得到信心，修习净戒，受持、读诵、书写、解说，常行惠施，善修智慧。因为根钝，又遇到恶友，不能修习身、戒、心、慧，听受邪法；或者遇到恶时，处于恶的国土，断了诸善根；因为断了善根，常沉没在生死之中。如恒河边的第二种人。

"第三种人，发意想渡生死大河，因为断了善根，在其中沉没；亲近善友，得名为出。相信如来是一切智者，常恒不变，为了众生说无上道；一切众生都有佛性；如来不灭，法与僧也是这样，没有灭坏；一阐提等若不断除其法，终不能得无上正等正觉，必须远离一阐提之法，然后才能得。因为信心，修习净戒；修了净戒，受持、读诵、书写、解说十二部经，为众生广为宣说流布，乐于惠施，修习智慧。因为根利，坚住于信与慧，心无退转。如恒河边的第三种人。

"第四种人，发意想渡生死大河，因为断了善根，在其中沉没；亲近善友，所以得到信心，这名为出。因为得到信心，受持、读诵、书写、解说十二部经，为了众生广为宣说流布，乐于惠施，修习智慧。因为根利，坚住于信与慧，心无退转，遍观四方。四方，就是四沙门果。如恒河边的第四种人。

"第五种人，发意想渡生死大河，因为断了善根，在其中沉没；亲近善友，所以得到信心，这名为出。因为信心，受持、读诵、书写、解说十二部经，为了众生广为宣说流布，乐于惠施，修习智慧。因为根利，坚住于信与慧，心无退转；无退转之后，就向前进。向前进，就是辟支佛，虽然能自己度过，却不能度及众生，这名为去。如恒河边的第五种人。

"第六种人，发意想渡生死大河，因为断了善根，在其中沉没；亲近善友，获得信心；因为得到信心，名之为出。因为信心，受持、读诵、书写、解说十二部经，为了众生广为宣说流布，乐于惠施，修习智慧。因为根利，坚住于信与慧，心无退转；无退转之后，又向前进，终于到达浅处；到了浅处，就停住不去。停住不去的，就是菩萨，为了度脱众生，停住观察烦恼。如恒河边的第六种人。

"第七种人，发意想渡生死大河，因为断了善根，在其中沉没；亲近善友，获得信心；得到信心之后，这名为出。因为信心，受持、读诵、书写、解说十二部经，为了众生广为宣说流布，乐于惠施，修习智慧。因为根利，坚住于信与慧，心无退转；无退转之后，就向前进；向前进之后，得以到达彼岸，登上大高山，离开诸恐怖，多受安乐。善男子，彼岸之山比喻如来，受安乐比喻佛常住，大高山比喻大涅槃。

【按】此喻中第二至第七种人，都以"断善根故于中沉没"起句，意谓都曾一度沉没于生死。

#### 不得涅槃，非佛之咎

"善男子，这恒河边的诸人都具足手足，而不能渡过；一切众生也是这样，确实有佛宝、法宝、僧宝，如来常说诸法要义，有八圣道、大般涅槃，而众生都不能得到。这不是我的过失，也不是圣道、众生等的过失，应当知道都是烦恼的过恶。因为这个道理，一切众生不得涅槃。

"善男子，譬如良医知病说药，病人不服，不是医生的过失。善男子，如有施主把所有的东西施给一切人，有不接受的，不是施主的过失。善男子，譬如太阳出来，幽暗之处都明亮，盲人看不见道路，不是太阳的过失。善男子，如恒河之水能解除渴乏，口渴的人不饮，不是水的过失。善男子，譬如大地普遍生长果实，平等无二，农夫不种，不是大地的过失。善男子，如来普为一切众生广开分别十二部经，众生不受，不是如来的过失。

### 佛性须修道乃见

"善男子，若修道，就能得无上正等正觉。善男子，你说众生都有佛性，应当得无上正等正觉，如磁石吸铁。善哉，善哉！因为有佛性的因缘力，能得无上正等正觉；若说不须修圣道，这意义是不对的。

"善男子，譬如有人行走旷野，口渴遇到一口井，那井极深，虽然看不见水，应当知道必定有水；此人方便寻求水罐绳索，汲取就能见到水。佛性也是这样，一切众生虽然有它，必须修习无漏圣道，然后才能得见。

"善男子，如有胡麻，就能见到油，离开诸方便，就不能见到；甘蔗也是这样。

"善男子，如三十三天、北郁单越，虽然是确有之法，若没有善业、神通、道力，就不能见到。地中的草根以及地下的水，因为被地覆盖，众生看不见。佛性也是这样，因为不修圣道，所以不能得见。

"善男子，如你所说，世间有病人，若遇到看护、良医、好药、合宜饮食，或者不遇，都能痊愈。善男子，我是为六住诸菩萨等说这样的意义。

"善男子，譬如虚空对于众生，非内非外，因为非内外，所以也没有挂碍；众生的佛性也是这样。

"善男子，譬如有人有财物在他方，虽然不在眼前，却能随意受用，有人问他，就说'是我的'。为什么呢？因为确定是有。众生的佛性也是这样，不在此也不在彼，因为必定能得，所以说一切众生都有。

"善男子，譬如众生造作诸业，或善或恶，非内非外；这样的业性，非有非无，也不是本无今有，不是无因而出，不是此作此受，此作彼受，彼作彼受，无作无受，时节和合而得果报。众生的佛性也是这样，也不是本无今有，非内非外，非有非无，非此非彼，不是从别处来，不是没有因缘，也不是一切众生都见不到；有诸菩萨在时节因缘和合时得见。时节，就是十住菩萨摩诃萨修八圣道，对众生得平等心，那时得见，不名为造作。

### 破磁石之喻：异法有故异法出生

"善男子，你说如磁石，这意义是不对的。为什么呢？石头不吸铁。为什么这样说？因为它没有心业。善男子，此法有，所以彼法出生；此法无，所以彼法灭坏；没有作者，没有坏者。

【按】"异法有故异法出生，异法无故异法灭坏"，"异法"指与之相异的他法，即此有故彼生、此无故彼灭之意，下文诸喻皆同。

"善男子，犹如猛火，不能焚烧柴薪，火出来，柴薪坏了，名为焚烧柴薪。

"善男子，譬如葵花藿叶随太阳而转，而这葵藿也没有恭敬之心，没有识，没有业，因为他法之性，所以自己回转。

"善男子，如芭蕉树因雷声而增长，这树没有耳朵，没有心意识，此法有，所以彼法增长；此法无，所以彼法灭坏。

"善男子，如阿叔迦树，女人摩触它，花就为之开出，这树没有心，也没有觉触，此法有，所以彼法出生；此法无，所以彼法灭坏。

"善男子，如橘树得到尸体，果实就多，而这橘树没有心，没有触觉，此法有，所以彼法滋多；此法无，所以彼法灭坏。

"善男子，如安石榴树，因为砖骨粪肥，果实繁茂，安石榴树也没有心与触觉，此法有，所以彼法出生；此法无，所以彼法灭坏。

"善男子，磁石吸铁也是这样，此法有，所以彼法出生；此法无，所以彼法灭坏。众生的佛性也是这样，不能吸取无上正等正觉。

"善男子，无明不能吸取诸行，行也不能吸取识，也得名为无明缘行，行缘于识。有佛无佛，法界常住。

### 佛性无住处

"善男子，若说佛性住在众生之中，善男子，常法没有住处，若有住处，就是无常。善男子，如十二因缘没有固定的住处，若有住处，十二因缘就不得名为常。如来的法身也没有住处，法界、法入、法阴、虚空都没有住处，佛性也是这样，都没有住处。

"善男子，譬如四大，其力虽然均等，有坚、有热、有湿、有动，有重、有轻，有赤、有白、有黄、有黑，而这四大也没有业，因为各自的法界不同，所以各不相似。佛性也是这样，因为法界不同，时候到了就显现。

"善男子，一切众生不退于佛性，所以名之为有：因为是阿毗跋致，因为当来会有，因为决定能得，因为必定当见。所以名为一切众生都有佛性。

### 盲人摸象

"善男子，譬如有一位国王告诉一位大臣：'你牵一头象来给盲人看。'那时大臣接受国王的命令，召集了很多盲人，把象给他们看。当时那些盲人各自用手触摸。大臣就回去对国王说：'臣已经给他们看过了。'

"那时大王就召来众盲人，一一问他们：'你们见到象了吗？'

"众盲人各自说：'我已经见到了。'

"国王说：'象是什么样的？'

"那摸到象牙的就说：象的形状如萝卜根；摸到耳朵的说：象如簸箕；摸到头的说：象如石头；摸到鼻子的说：象如杵；摸到脚的说：象如木臼；摸到脊背的说：象如床；摸到腹部的说：象如瓮；摸到尾巴的说：象如绳子。

"善男子，如那些盲人，并没有说出象的整体，也不是没有说象。若这些相都不是象，离开这些以外，更没有别的象。

"善男子，国王比喻如来、应供、正遍知，大臣比喻方等《大涅槃经》，象比喻佛性，盲人比喻一切无明众生。

#### 众生各执五阴与我为佛性

"这些众生听了佛所说之后，或者这样说：'色是佛性。为什么呢？这色虽然灭了，却次第相续，所以能获得无上如来的三十二相；如来之色是常，因为如来之色常而不断。所以说色名为佛性。譬如真金，形质虽然迁变，颜色常不改变，或时作钏，作蛇形饰，作盘，然而它的黄色从来没有改易。众生的佛性也是这样，形质虽然无常，而色是常。所以说色为佛性。'

【按】"作蛇"，北本作"作[金毗]"，当是一种金饰之名，南本"蛇"字或为形近之误，译作"蛇形饰"以存其字。

"或有人说：'受是佛性。为什么呢？因为受的因缘，获得如来真实之乐；如来之受，就是究竟之受、第一义之受。众生的受性虽然无常，然而次第相续不断，所以能获得如来常住之受。譬如有人姓憍尸迦，人虽然无常，而姓是常，经过千万世没有改易。众生的佛性也是这样。所以说受为佛性。'

"又有人说：'想是佛性。为什么呢？因为想的因缘，获得如来真实之想；如来之想，名为无想之想；无想之想，不是众生之想，不是男女之想，也不是色、受、想、行、识之想，不是想断之想。众生之想虽然无常，因为想次第相续不断，所以能得如来常恒之想。善男子，譬如众生的十二因缘，众生虽然灭了，而因缘是常。众生的佛性也是这样。所以说想为佛性。'

"又有人说：'行为佛性。为什么呢？行名为寿命，因为寿命的因缘，获得如来常住的寿命；众生的寿命虽然无常，而寿命次第相续不断，所以能得如来真实常住的寿命。善男子，譬如十二部经，听者与说者虽然无常，而这经典常存不变。众生的佛性也是这样。所以说行为佛性。'

"又有人说：'识为佛性。因为识的因缘，获得如来平等之心；众生的意识虽然无常，而识次第相续不断，所以能得如来真实常住之心。如火的热性，火虽然无常，热不是无常。众生的佛性也是这样。所以说识为佛性。'

"又有人说：'离开五阴而有我，我是佛性。为什么呢？因为我的因缘，获得如来八种自在之我。有诸外道说：去来、见闻、悲喜、言说为我，这样的我相虽然无常，而如来之我真实是常。善男子，如阴、入、界虽然无常，而名称是常。众生的佛性也是这样。'

"善男子，如那些盲人各自说象，虽然没有得到实体，也不是没有说象；说佛性的人也是这样，佛性不即是这六法，也不离这六法。善男子，所以我说众生的佛性不是色，不离色，乃至不是我，不离我。

#### 外道之我与如来之我

"善男子，有诸外道虽然说有我，而实在没有我。众生的我，就是五阴，离开五阴之外，更没有别的我。善男子，譬如茎、叶、须、台和合为莲花，离开这些之外，更没有别的花；众生的我也是这样。善男子，譬如墙壁草木和合，名之为房舍，离开这些之外，更没有别的房舍；如佉陀罗树、波罗奢树、尼拘陀树、优昙钵树和合为林，离开这些之外，更没有别的林；譬如车兵、象兵、马兵、步兵和合为军，离开这些之外，更没有别的军；譬如五色杂线和合，名之为绮，离开这些之外，更没有别的绮；如四姓和合名为大众，离开这些之外，更没有别的大众。众生的我也是这样，离开五阴之外，更没有别的我。

"善男子，如来常住，就名为我。如来的法身无边无碍，不生不灭，得八种自在，这名为我。众生实在没有这样的我以及我所；只因为必定当得究竟的第一义空，所以名为佛性。

### 佛性的诸种异名

"善男子，大慈大悲名为佛性。为什么呢？大慈大悲常随菩萨，如影随形；一切众生必定当得大慈大悲，所以说一切众生都有佛性。大慈大悲名为佛性，佛性名为如来。

"大喜大舍名为佛性。为什么呢？菩萨摩诃萨若不能舍弃二十五有，就不能得无上正等正觉；因为众生必定当得，所以说一切众生都有佛性。大喜大舍就是佛性，佛性就是如来。

"佛性名为大信心。为什么呢？因为信心，菩萨摩诃萨就能具足檀波罗蜜乃至般若波罗蜜；一切众生必定当得大信心，所以说一切众生都有佛性。大信心就是佛性，佛性就是如来。

"佛性名为一子地。为什么呢？因为一子地的因缘，菩萨就对一切众生得平等心；一切众生必定当得一子地，所以说一切众生都有佛性。一子地就是佛性，佛性就是如来。

"佛性名为第四力。为什么呢？因为第四力的因缘，菩萨就能教化众生；一切众生必定当得第四力，所以说一切众生都有佛性。第四力就是佛性，佛性就是如来。

【按】"第四力"，即如来十力中的第四"知诸根胜劣智力"，能知众生根性而施教化。

"佛性名为十二因缘。为什么呢？因为因缘，如来常住；一切众生必定有这样的十二因缘，所以说一切众生都有佛性。十二因缘就是佛性，佛性就是如来。

"佛性名为四无碍智。因为四无碍的因缘，说字与义无碍；因为字义无碍，能教化众生。四无碍就是佛性，佛性就是如来。

"佛性名为顶三昧。因为修这样的顶三昧，就能总摄一切佛法，所以说顶三昧名为佛性。十住菩萨修这三昧还未得具足，虽见佛性而不明了；一切众生必定能得，所以说一切众生都有佛性。

"善男子，如上所说的种种诸法，一切众生必定当得，所以说一切众生都有佛性。

"善男子，我若说色是佛性，众生听了，就会生起邪见颠倒；因为邪见颠倒，命终就生阿鼻地狱。如来说法是为了断除地狱，所以不说色是佛性，乃至说识也是这样。

"善男子，若众生了知佛性，就不须修道。十住菩萨修八圣道，少分见到佛性，何况不修的人能得见？善男子，如文殊师利诸菩萨等，已在无量世中修习圣道，了知佛性，声闻、辟支佛等怎能知佛性？若众生想明明了了知道佛性，应当一心受持、读诵、书写、解说、供养、恭敬、尊重、赞叹这部《涅槃经》；见到有受持乃至赞叹这部经的人，应当以好的房舍、衣服、饮食、卧具、医药供给他，并且赞叹、礼拜、问讯。

"善男子，若有人已在过去无量无边世中亲近供养无量诸佛，深种善根，然后才能听到这部经的名字。

"善男子，佛性不可思议，佛、法、僧宝也不可思议；一切众生都有佛性而不能知，这也不可思议；如来常乐我净之法也不可思议；一切众生能信这样的《大涅槃经》，也不可思议。"

师子吼菩萨说："世尊，如佛所说，一切众生能信这样的《大涅槃经》不可思议。世尊，这大众中有八万五千亿人对这部经不生信心，所以能信这部经的人，名为不可思议。"

"善男子，这些人在未来世，也必定会信这部经典，见佛性，得无上正等正觉。"

### 不退菩萨如何自知

师子吼说："世尊，不退菩萨怎样自知决定有不退之心？"

佛说："善男子，菩萨摩诃萨应当以苦行自试其心：每日只吃一粒胡麻，持续七日；粳米、绿豆、麻子、粟稗以及白豆，也是这样，各持续七日。吃一粒胡麻时，这样思惟：'这样的苦行都没有利益，没有利益的事尚且能做，何况有利益的事而不做？'对于没有利益的事，心能堪忍，不退不转，所以必定能得无上正等正觉。

【按】原文"粟??"缺字，南北本同，依文意当是"稗"一类谷物，存疑。

"这样每日修苦行时，一切皮肉消瘦皱缩，如切断的生瓠瓜放在太阳下；眼睛深陷，如井底的星星；肉尽肋骨突出，如腐朽的草屋；脊骨连连显现，如层层叠起的砖线；所坐之处，如马蹄印；想坐就伏倒，想起就仰倒。虽然受这样无利益的苦，却不退失菩提之心。

"再者，善男子，菩萨摩诃萨为了破除众苦、施予安乐，乃至能舍弃内外财物以及自己的身命，如弃草芥。若能不惜这身命，这样的菩萨自知必定有不退之心：'我必定当得无上正等正觉。'

"再者，菩萨为了法的因缘，剜身作灯，以细布缠裹皮肉，灌上酥油，烧以为灯炷。菩萨那时受这大苦，自己呵责其心，这样说：'这样的苦，比起地狱之苦，百千万分还不及一分。你在无量百千劫中受大苦恼，都没有利益；你若不能受这轻苦，怎能在地狱中救度受苦的众生？'菩萨摩诃萨作这样的观察时，身体不觉苦，其心不退、不动、不转。菩萨那时应当深自知道：'我必定当得无上正等正觉。'

【按】原文"为灯?缠"缺字，北本同缺，依文意当是"叠"（细布）一类，译作"细布"。

"善男子，菩萨那时具足烦恼，还没有断除，为了法的因缘，能以头目髓脑、手足血肉施人，以钉钉身，投岩赴火。菩萨那时虽受这样无量的众苦，若心不退、不动、不转，菩萨应当知道：'我现在必定有不退之心，当得无上正等正觉。'

#### 受畜生身而不作畜生业

"善男子，菩萨摩诃萨为了破除一切众生的苦恼，愿作粗大的畜生之身，以身上的血肉施予众生；众生取食时，又生怜悯，菩萨那时闭气不喘，示现死相，令那些取食的人不生杀害的疑虑之想。菩萨虽受畜生之身，终不造作畜生之业。为什么呢？善男子，菩萨得了不退之心以后，终不造作三恶道的业。

"菩萨摩诃萨若在未来世有微尘那样多的恶业果报，是不必定受的，以大愿力，为了众生而全都承受。譬如病人被鬼附着，鬼藏隐在身中，以咒力的缘故，即时显现其相，或说话，或喜，或瞋，或骂，或啼，或哭。菩萨摩诃萨未来世的三恶道之业也是这样。

【按】此喻原文简略，照字面译出，存疑。

"菩萨摩诃萨受熊身时，常为众生演说正法；或受迦宾阇罗鸟身，为了众生说正法；受瞿陀身、鹿身、兔身、象身、羖羊、猕猴、白鸽、金翅鸟、龙、蛇之身。受这样等畜生之身时，终不造作畜生的恶业，常为其余畜生众生演说正法，令他们听法，迅速转离畜生之身。菩萨那时虽受畜生之身，不作恶业，应当知道必定有不退之心。

【按】迦宾阇罗，鸟名；瞿陀，蜥蜴类。

"菩萨摩诃萨在饥馑之世，见到饥饿的众生，就化作无量由旬的龟身、鱼身，又发这样的愿：'愿众生取我肉时，随取随生；因为吃了我的肉，离开饥渴之苦，一切都发无上正等正觉之心。'菩萨发愿：'若有因我离开饥渴的人，愿他们在未来世迅速远离二十五有的饥渴之患。'菩萨摩诃萨受这样的苦，心不退的，应当知道必定得无上正等正觉。

"再者，菩萨在疾疫之世，见到病苦的人，这样思惟：'如药树王，若有病人取其根，取其茎，取其枝，取其叶，取其花，取其果，取其皮，取其肤，都能治愈疾病；愿我这身也是这样，若有病人听到我的声音，触到我的身体，服食我的血肉乃至骨髓，病都除愈。愿众生吃我的肉时，不生恶心，如吃自己孩子的肉；我治好他们的病之后，常为他们说法，愿他们信受、思惟、转教他人。'

"再者，善男子，菩萨具足烦恼，虽受身苦，其心不退、不动、不转，应当知道必定得不退之心，成就无上正等正觉。

"再者，善男子，若有众生被鬼所害而病，菩萨见了，就这样说：'愿作鬼身，大身、健身、多眷属之身，使他们见闻之后，病得除愈。'菩萨摩诃萨为了众生勤修苦行，虽有烦恼，不污染其心。

"再者，善男子，菩萨摩诃萨虽然修行六波罗蜜，也不求六度之果。修行无上六波罗蜜时，发这样的愿：'我现在以这六波罗蜜施予每一个众生，每一个众生受了我的布施之后，都令他们得成无上正等正觉。我也自己为了六波罗蜜，勤修苦行，受诸苦恼；当受苦时，愿我不退失菩提之心。'善男子，菩萨摩诃萨发这样的愿时，这名为不退菩提之相。

### 菩萨不可思议

"再者，善男子，菩萨摩诃萨不可思议。为什么呢？菩萨摩诃萨深知生死多有罪过，观察大涅槃有大功德，为了众生处在生死之中，受种种苦，心无退转，这名为菩萨不可思议。

"再者，善男子，菩萨摩诃萨没有因缘而生怜悯，实在没有受人之恩而常施恩于人，虽然施恩而不求回报，所以又名为不可思议。

"再者，善男子，或有众生为了自己的利益修诸苦行，菩萨摩诃萨为了利他而修行苦行，这名为自利，所以又名为不可思议。

"再者，菩萨具足烦恼，为了破除怨亲的分别，承受诸苦，修平等心，所以又名为不可思议。

"再者，菩萨若见诸恶、不善的众生，或呵责，或软语，或驱逐，或放任；对有恶性的，示现软语；对有憍慢的，示现大慢，而他的内心实在没有憍慢。这名为菩萨的方便不可思议。

"再者，菩萨具足烦恼，财物少的时候来求的人多，心不窄小，这名为菩萨不可思议。

"再者，菩萨在佛出世时知道佛的功德，为了众生，在没有佛的地方受边地之身，如盲，如聋，如跛，如手足痿蹙，这名为菩萨不可思议。

"再者，菩萨深知众生所有的罪过，为了度脱他们，常与他们同行，虽然随顺其意，却不被罪垢所污，所以又名为不可思议。

"再者，菩萨明明了了地知见：没有众生之相，没有烦恼之污，没有修习道而离烦恼的人；虽为菩提，没有菩提之行，也没有成就菩提之行的人；没有受苦以及破苦的人；而也能为众生破除苦，行菩提之行。所以又名为不可思议。

#### 兜率天三胜

"再者，菩萨受最后边身，处于兜率天，这也名为不可思议。为什么呢？兜率陀天在欲界中最殊胜：在其下的诸天，其心放逸；在其上的诸天，诸根暗钝，所以名为殊胜。修布施、修持戒，得上下诸天之身；修布施、持戒、禅定，得兜率天之身。一切菩萨呵毁诸有，破坏诸有，终不造作兜率天的业而受那天身。为什么呢？菩萨若处在其余诸有，也能教化成就众生；实在没有欲心而生在欲界，所以又名为不可思议。

"菩萨摩诃萨生在兜率天，有三件事殊胜：一是寿命，二是容色，三是名称。菩萨摩诃萨实在不求寿命、容色、名称，虽然没有求心，而所得殊胜。菩萨摩诃萨深乐涅槃，然而所得也殊胜，所以又名为不可思议。

"菩萨摩诃萨这三件事虽然胜过诸天，而诸天等对于菩萨终不生起瞋心、妒心、憍慢之心，常生欢喜之心；菩萨对于诸天也不憍慢，所以又名为不可思议。

"菩萨摩诃萨不造寿命之业，而在那天中得究竟的寿命，这名为寿命殊胜；也没有容色之业，而有妙色之身，光明遍满，这名为容色殊胜；菩萨摩诃萨处在那天宫中，不乐五欲，唯为法事，所以名称充满十方，这名为名称殊胜。所以又名为不可思议。

#### 下生、入胎

"菩萨摩诃萨从兜率天下降时，大地六种震动，所以又名为不可思议。为什么呢？菩萨下降时，欲界、色界诸天都来侍送，发大音声赞叹菩萨，因为口中风气，令大地震动。又有菩萨是人中象王，人中象王名为龙王；龙王初入胎时，有诸龙王在这地下，或惊怖，或觉醒，所以大地六种震动，所以又名为不可思议。

"菩萨摩诃萨知道入胎时、住胎时、出胎时，知道父亲，知道母亲，不被不净所污，如帝释所发的青色宝珠，所以又名为不可思议。

### 大海八不思议

"善男子，《大涅槃经》也是这样不可思议。善男子，譬如大海有八种不可思议。哪八种？一是渐渐转深，二是深而难得其底，三是同一咸味，四是潮水不过其限，五是有种种宝藏，六是大身众生居住其中，七是不留宿死尸，八是一切万流与大雨投入其中，不增不减。

"善男子，渐渐转深有三件事。哪三件？一是众生的福力，二是顺风而行，三是河水流入的缘故。乃至不增不减，也各有三件事。

【按】大海八不思议，见于诸阿含及律典，名目大同。

"这大涅槃微妙经典也是这样，有八种不可思议。

"一是渐渐转深，即五戒、十戒、二百五十戒、菩萨戒；须陀洹果、斯陀含果、阿那含果、阿罗汉果、辟支佛果、菩萨果、无上正等正觉之果。这部《涅槃经》说这些法，这名为渐渐转深，所以这部经名为渐渐转深。

【按】"五戒、十戒、二百五十戒"，北本作"优婆塞戒、沙弥戒、比丘戒"，所指相同。

"二是深而难得其底：如来世尊不生不灭，不得无上正等正觉，不转法轮，不食，不受，不行惠施，所以名为常乐我净；一切众生都有佛性；佛性不是色，也不离色，不是受、想、行、识，乃至也不离识；是常，可以得见；是了因，不是作因；须陀洹乃至辟支佛，当得无上正等正觉；也没有烦恼，也没有住处；虽然没有烦恼，也不名为常。所以名为深。

"又有甚深之处：在这部经中，或有时说我，或说无我；或有时说常，或说无常；或有时说净，或说不净；或有时说乐，或有时说苦；或有时说空，或说不空；或说一切有，或说一切无；或说三乘，或说一乘；或说五阴就是佛性，金刚三昧以及中道，首楞严三昧，十二因缘，第一义空，慈悲平等对待众生，顶智，信心，知诸根力，一切法中无挂碍之智；虽有佛性，不说是决定的。所以名为深。

"三是同一味：一切众生同有佛性，都同一乘，同一解脱，一因一果，同一甘露，一切当得常乐我净，这名为一味。

"四是潮水不过其限：在这部经中制定诸比丘不得受蓄八种不净之物。若我的弟子有能受持、读诵、书写、解说、分别这大涅槃微妙经典的，宁可失去身命，终不违犯，这名为潮水不过其限。

"五是有种种宝藏：这部经就是无量的宝藏。所说的宝，就是四念处、四正勤、四如意足、五根、五力、七觉分、八圣道分，婴儿行、圣行、梵行、天行，诸善方便，众生的佛性，菩萨的功德、如来的功德、声闻的功德、缘觉的功德，六波罗蜜，无量三昧，无量智慧，这名为宝藏。

"六是大身众生所居住之处：大身众生，就是佛与菩萨。因为有大智慧，所以名为大众生；因为有大身，有大心，有大庄严，有大调伏，有大方便，有大说法，有大势力，有大徒众，有大神通，有大慈悲，常住不变，对一切众生没有挂碍，能容受一切众生，这名为大身众生所居住之处。

"七是不留宿死尸：死尸，就是一阐提、犯四重禁、五无间罪、诽谤方等、非法说为法、法说为非法、受蓄八种不净之物、随意使用佛物僧物、或在比丘比丘尼那里作非法之事，这名为死尸。这部《涅槃经》远离这些，所以名为不留宿死尸。

"八是不增不减：因为无边际，因为无始终，因为不是色，因为不是造作的，因为常住，因为不生不灭，因为一切众生都平等，因为一切法性同一性，这名为不增不减。所以这部经如那大海，有八种不可思议。"

### 如来何以不受化生

师子吼说："世尊，若说如来不生不灭名为深，一切众生有四种生，即卵生、胎生、湿生、化生，这四种生在人中都有。如施婆罗比丘、优婆施婆罗比丘、弥迦罗长者之母、尼拘陀长者之母、半阇罗长者之母，各有五百子，都是卵生，应当知道人中也有卵生。湿生，如佛所说：'我往昔作菩萨时，作顶生王以及手生王。'如现在所说的庵罗树女、迦不多树女，应当知道人中也有湿生。劫初之时，一切众生都是化生。如来世尊得八种自在，以什么因缘不受化生？"

佛说："善男子，一切众生由四生而生，得圣法之后，不得再如本来那样卵生、湿生。

"善男子，劫初的众生都是化生，在那时佛不出世。善男子，若有众生遇到病苦时，须要医生，须要药物；劫初之时众生化生，虽有烦恼，其病还未发作，所以如来不出现于那世。劫初的众生，身心还不是法器，所以如来不出现于那世。

"善男子，如来世尊所有的事业胜过众生，即种姓、眷属、父母，因为殊胜，凡所说法，人都信受，所以如来不受化生。

"善男子，一切众生，父作子的业，子作父的业；如来世尊若受化身，就没有父母；若没有父母，怎能令一切众生作诸善业？所以如来不受化身。

"善男子，佛的正法中有两种护持：一是内护，二是外护。内护，就是禁戒；外护，就是族亲眷属。若佛如来受化身，就没有外护，所以如来不受化身。

"善男子，有人依恃姓氏而生憍慢，如来为了破除这样的憍慢，生在高贵的种姓，不受化身。

"善男子，如来世尊有真实的父母，父亲名叫净饭，母亲名叫摩耶，而众生尚且说是幻化，怎能受化生之身？若受化身，怎能有碎身舍利？如来为了增益众生的福德，碎其身而令人供养，所以如来不受化身。一切诸佛都没有化生的，怎么独令我受化身？"

### 师子吼偈赞

那时师子吼菩萨合掌长跪，右膝着地，以偈赞佛：

```
如来无量功德聚
我今不能广宣说
今为众生演一分
唯愿哀愍听我说
众生无明暗中行
具受无边百种苦
世尊能令远离之
是故世称为大悲
众生往返生死绳
放逸迷荒无安乐
如来能施众安乐
是故永断生死绳
佛能施众安乐故
自于己乐不贪乐
为诸众生修苦行
是故世间兴供养
```

（大意：如来是无量功德之聚，我今不能广说，现在为众生演说一分，唯愿哀悯听我说。众生行于无明黑暗之中，具受无边百种苦，世尊能令他们远离，所以世间称为大悲。众生在生死之绳中往返，放逸迷荒，没有安乐；如来能施予众生安乐，所以永断生死之绳。佛能施予众生安乐，对自己的安乐却不贪恋，为了众生修苦行，所以世间兴起供养。）

```
见他受苦身战动
处在地狱不觉痛
为诸众生受大苦
是故无胜无有量
如来为众修苦行
成就具足满六度
心处邪风不倾动
是故能胜世大士
众生常欲得安乐
而不知修安乐因
如来能教令修习
犹如慈父爱一子
佛见众生烦恼患
心苦如母念病子
常思离病诸方便
是故此身系属他
```

（大意：见他人受苦，身体为之战动；自己处在地狱，却不觉痛；为了众生受大苦，所以无可胜过，功德无量。如来为众生修苦行，成就具足圆满六度；心处在邪风之中而不倾动，所以能胜过世间的大士。众生常想得到安乐，却不知修安乐之因；如来能教导他们修习，犹如慈父爱独子。佛见众生的烦恼之患，心中苦痛，如母亲挂念病儿，常思离病的种种方便，所以这身属于众生。）

```
一切众生行诸苦
其心颠倒以为乐
如来演说真苦乐
是故称号为大悲
世间皆处无明□
无有智嘴能破之
如来智嘴能啄坏
是故名为最大子
不为三世所摄持
无有名字及假号
觉知涅槃甚深义
是故称佛为大觉
有河洄澓没众生
无明所盲不知出
如来自渡能渡彼
是故称佛大船师
```

（大意：一切众生行于诸苦，其心颠倒，以苦为乐；如来演说真实的苦与乐，所以称号为大悲。世间都处在无明之壳中，没有智慧之嘴能啄破它；如来的智慧之嘴能啄破，所以名为最先破壳的长子。不被三世所摄持，没有名字及假号，觉知涅槃的甚深之义，所以称佛为大觉。有河流回旋，淹没众生，众生被无明所盲，不知出路；如来自己渡过，又能渡人，所以称佛为大船师。）

【按】原文"无明?"缺一字，南北本同，依下句"智嘴能啄坏"，当是卵壳之"壳"（鷇）。"最大子"，即卵中最先啄壳而出者，喻佛为世间第一个破无明之壳的人。

```
能知一切诸因果
亦复通达尽灭道
常施众生病苦药
是故世称大医王
外道邪见说苦行
因是能得无上乐
如来演说真乐行
能令众生受快乐
如来世尊破邪道
开示众生正真路
行是道者得安乐
是故称佛为导师
非自非他之所作
亦非共作无因作
如来所说苦受事
胜于一切诸外道
```

（大意：能知一切诸因果，也通达灭尽之道，常施众生病苦之药，所以世间称为大医王。外道邪见说修苦行能得无上之乐；如来演说真实的乐行，能令众生受快乐。如来世尊破除邪道，开示众生正真之路，行这道的人得安乐，所以称佛为导师。如来所说的苦受之事，非自作、非他作、非共作、也非无因作，胜过一切诸外道。）

```
成就具足戒定慧
亦以此法教众生
以法施时无妒吝
是故称佛无缘悲
无所造作无因缘
获得无因无果报
是故一切诸智者
称说如来不求报
常共世间放逸行
而身不为放逸污
是故名为不思议
世间八法不能污
如来世尊无怨亲
是故其心常平等
我师子吼赞大悲
能吼无量师子吼
```

（大意：成就具足戒、定、慧，也以此法教导众生，以法布施时没有嫉妒悭吝，所以称佛为无缘之悲。无所造作，没有因缘，获得无因无果之报，所以一切智者称说如来不求回报。常与世间放逸之人同行，而身不被放逸所污，所以名为不可思议，世间八法不能染污。如来世尊没有怨亲，所以其心常平等。我师子吼赞叹大悲者，他能作无量的师子吼。）

大般涅槃经卷第三十

【按】本卷相当于北本卷第三十二（师子吼菩萨品第十一之六）。
