# 《大宝积经》卷第一百三（善住意天子会·开实义品、文殊神变品、破魔品、菩萨身行品）

隋·天竺三藏达摩笈多 译

## 善住意天子会第三十六之二

【按】译者题名“天竺”二字，宋、元、明、宫本无；“三藏”，宋、宫本作“沙门”。

### 开实义品第二

#### 诸天雨花，文殊升座

那时大集会的大众中有几位上首天子，就是善住意天子、善寂天子、惭愧天子，与这样等九十六亿天子在一起，一切都修行菩萨之道，一同前往文殊师利之所，到了他的门外，右绕七匝。绕了七匝之后，然后雨下天上的曼陀罗花。所雨的花遍覆虚空，高十由旬，成为花网台，形状如宝塔。当时文殊师利持这花台供养世尊。供养之后，便以神力令这三千大千世界一切国土的虚空中花网遍覆，这花的光明普照三千大千世界，都极为明亮，又雨下天上的曼陀罗花。

那时文殊师利菩萨摩诃萨闲雅安详地从精舍出来，又以神力令所居之地自然有七宝妙座，那座巍巍，具足庄严。文殊师利敛容整服，登上这宝座。当时善住意天子见文殊师利登上宝座之后，便顶礼文殊师利足，退住一面。一切诸天也都顶礼文殊师利足。

【按】“安详”之“详”，元、明本作“庠”。

#### 文殊思惟谁为法器

那时文殊师利这样思惟：“今日谁能与我在世尊面前对扬深法？谁是法器，能受这样的不可思议之句、甚难证悟之句、无处所之句、无所执著之句、无戏论之句、不可得之句、不可说之句、甚深之句、真实之句、无碍之句、不可坏之句、空之句、无相之句、无愿之句、如如之句、实际之句、法界之句、无形貌之句、不取之句、不舍之句、佛之句、法之句、僧之句、智慧满足之句、三界平等之句、一切法无所得之句、一切法无生之句、狮子之句、勇猛之句、无句之句？这样说了之后，谁是听者呢？”

于是文殊师利又思惟：“现在只有善住意天子，已在过去供养多佛，入于深法忍，具足辩才，能与我在世尊面前共谈真实之义。”那时文殊师利这样想之后，便对善住意天子说：“天子！你现在已得甚深法忍，又能具足无碍辩才。现在应当与我前往世尊之所，对论这样深妙的义理吗？”

【按】“即语善住意天子”之“意”，宫本无。

#### 说者与听者皆无所取

当时善住意天子回答文殊师利说：“大士！我这样说：他若对我没有语言，不为我演说，不作请问，也没有回答，没有佛、法、僧众，断灭三乘，没有生死，没有涅槃，不合不散，不开启不发起，不发出声音，除去一切文字，若这样说，我便与他共谈。”

【按】“不存咨问”之“存”，南藏作“为”。“不出声音”之“音”，宫本作“香”。

文殊师利对善住意天子说：“天子！我这样说：他能对我无听无闻，无读无诵，无受无持，不思不念，不取不舍，不觉不知，不闻我的话，不为他人说。为什么呢？诸佛的菩提本来没有文字，无心而离心，没有觉悟，虽然假借名字来说，那名字也是空的。”

【按】“无受不持”之“不”，宋、元、明、宫本作“无”。

善住意又说：“大士！现在且为诸天子说，这些天子对大士所说乐于听闻。”文殊师利说：“天子！我终究不为乐于听闻的人说，也不为听受的人说。为什么呢？凡有听受，便是取著。什么是取著？就是我执著、人执著、众生执著、寿命执著、士夫执著。因为有取著，便有听受；这样的听受，应当知道他住于三种系缚之中。什么是三缚？一是见我之缚，二是见众生之缚，三是见法之缚。天子！若没有这样三种见缚而听法，应当知道他住于三种清净之中。什么是三净？一是不见自身，不分别，不思念，不证知；二是不见说者，不分别，不思念，不证知；三是不见所说之法，不分别，不思念，不证知。天子！这便名为三种清净。天子！若有人能这样听，这是平等之听，不是不平等。”

#### 退转从分别生

那时善住意天子赞叹文殊师利说：“善哉善哉，畅快地作这样的宣说。大士！若有人能这样说，应当知道就是不退转之说。”文殊师利说：“且止，天子！你现在不应妄想分别菩萨的退转。为什么呢？若菩萨有退转，他终究不能成等正觉。为什么呢？因为这菩提之中没有退转之法。”

善住意又说：“大士！若是这样，在何处有这退转？”文殊师利说：“天子！应当知道，从贪欲而有退转，从瞋恚而有退转，从愚痴而有退转，从有爱而有退转，从无明而有退转，乃至从十二有支、生死所生而有退转。从因而有退转，从见而有退转，从名而有退转，从色而有退转，从欲界而有退转，从色界而有退转，从无色界而有退转，从声闻行而有退转，从辟支佛行而有退转，从分别而有退转，从执著而有退转，从相而有退转，从取相而有退转，从断见而有退转，从常见而有退转，从取而有退转，从舍而有退转，从我想而有退转，从众生想而有退转，从寿命想而有退转，从士夫想而有退转，从补伽罗想而有退转，从思想而有退转，从系缚而有退转，从颠倒而有退转。从我见而有退转，从以我见为根本的六十二见而有退转，从诸盖而有退转，从诸阴而有退转，从诸入而有退转，从诸界而有退转。从佛想而有退转，从法想而有退转，从僧想而有退转。像这样乃至‘我当成佛、我当说法、我度众生、我当破魔、我得智慧’，从这些想而有退转。像这样，天子！若能不分别如来十力，不分别四无所畏，不分别十八不共法，不分别一切根、力、觉、道，不分别诸相好，不分别庄严佛国，不分别声闻，不分别菩萨，乃至不分别一切分别与退转，这名为不退转。”

【按】“福伽罗”之“福”，宋、元、明本作“补”；补伽罗即补特伽罗，意为人、数取趣。

那时善住意天子又对文殊师利说：“大士！若是这样，在何处得不退转？”文殊师利说：“天子应当知道，从通达佛慧而得不退转，从空而不退转，从无相而不退转，从无愿而不退转，从如如而不退转，从法性而不退转，从实际而不退转，从平等而不退转。”

#### 退转非有非无

善住意说：“大士！若这样说，一切诸分别与无分别二者都没有差异。为什么呢？都从思惟分别而生，所以可以说它们有退转。”又问：“这样的退转，是有法呢？还是无法呢？”文殊师利说：“这样的退转非有非无。”善住意说：“大士！若是这样，在何处退转？”文殊师利说：“无论有或无，都是虚妄之取、颠倒之取、不如实之取，他便不取，也不是不取，由于这个道理，可以说退转。而那退转之法，不可说有，不可说无。为什么呢？若在有无之中有退转，他便有过失。为什么呢？若有法退转，便堕于常边；若无法退转，便堕于断边。然而世尊说，不住于常中，不住于断中，非断非常，是世尊所说的。天子！若他对先前不真实之想，而他能证知，便名为非断非常。天子！这是菩萨退转的法门。”宣说此法时，一万天子得无生法忍。

### 文殊神变品第三

#### 虚空即如来

那时善住意天子对文殊师利说：“大士！现在可以一同前往如来之所，奉见顶礼，请受未闻之法，也趁此时如法问难。”文殊师利说：“天子！你不要分别取著如来。”善住意说：“大士！如来在哪里而说不要执著？”文殊师利说：“就在面前。”善住意说：“若是这样，我为什么不见？”文殊师利说：“天子！你现在若能一切都不见，这便名为真见如来。”善住意说：“若在面前，为什么告诫我不要执取如来？”文殊师利说：“天子！你说现在面前有什么？”善住意说：“有虚空界。”文殊师利说：“是这样，天子！所说的如来，就是虚空界。为什么呢？因为诸法平等，如虚空。所以虚空就是如来，如来就是虚空，虚空与如来无二无别。天子！由于这个道理，若有人想求见如来，应当作这样的观察：如实觉了真际，其中没有一物可以分别。”

#### 文殊化宝堂，后发先至

那时文殊师利菩萨摩诃萨又以神力化作三十二所重阁宝堂，车舆具足，四面方正，四角有柱，周匝有栏楯，宝网交络，殊特美好，高显巍巍，具足庄严，甚可爱乐。诸堂阁内都有殊胜的床座，由众宝所成，覆以天衣。那些床上各有化现的菩萨坐着，具足三十二大人之相。那时文殊师利普遍示现这样的庄严之事后，便又与那莲花上的化佛以及化菩萨，以及这宝车、重阁殿堂中的诸菩萨众，一同前往佛所，绕佛七匝，并也围绕比丘众之后，跃在虚空中，光明普照众会的道场，在四面而住。

那时文殊师利在善住意之后出发，忽然在前面先到了佛所。善住意天子反而后到，说：“大士！我在前面出发，反而在后面到达。仁者从哪条路来到这里？”文殊师利说：“天子！假使你供养满恒河沙的诸如来等，稽首作礼，也终究见不到我的往来进止。”

【按】“后善住发”，宋、元、明本作“后善住意发”。

#### 化菩萨偈赞

那时花台上的诸化菩萨以及宝堂中的诸菩萨众，同声说偈赞叹如来：

```
已曾供养过恒河，
不可思议诸世尊，
炽然修行求菩提，
是故超出天人上。
光明妙色三界雄，
牟尼众相实奇特，
为众宣说甚深法，
无有寿命及人我。
世尊行施持净戒，
忍辱精进具修禅，
智慧清净三界表，
我礼彼岸最胜尊。
其有发意求菩提，
则受天人妙供养，
若于深空无疑惑，
当绍出世大法王。
过去诸佛等正觉，
现在一切两足尊，
常说如是诸法空，
本来无相亦无作。
众生体性不可得，
何有生者及死灭？
本既无来亦无去，
一切诸法如虚空。
如彼化人观众事，
虽复示现而无真，
世尊说法亦如是，
斯皆虚诳同幻梦。
恒沙世界满中宝，
持以布施一切人，
若能修忍善说空，
如是行施超于彼。
复于恒沙诸劫中，
供养诸佛天人上，
奉献香花及众具，
为求菩提离世间。
得闻如是甚深法，
无有众生及命人，
当知彼得明净忍，
是为供养十方佛。
于无数劫行布施，
衣食象马及众珍，
当知彼非解脱因，
以有我人众生想。
```
（大意：已曾供养超过恒河沙数不可思议的诸世尊，炽然修行求取菩提，所以超出天人之上。光明妙色的三界之雄，牟尼的众相实在奇特，为大众宣说甚深之法：没有寿命以及人与我。世尊行布施、持净戒，忍辱、精进，具足修禅，智慧清净超出三界之表，我礼敬那到达彼岸的最胜之尊。若有人发心求菩提，便受天人美妙的供养；若对甚深的空法没有疑惑，当继承为出世的大法王。过去诸佛等正觉，现在一切两足之尊，常说这样的诸法空，本来无相，也无作。众生的体性不可得，哪有生者以及死灭？本来既没有来，也没有去，一切诸法如同虚空。如那化人观看种种事，虽然示现却不真实，世尊说法也是这样，这些都是虚诳的，如同幻梦。以充满恒河沙世界的宝物布施一切人；若能修忍辱、善说空，这样的布施超过前者。又在恒河沙劫中，供养诸佛、天人之上的尊者，奉献香花以及种种供具，是为了求菩提而出离世间。得闻这样甚深之法：没有众生以及命者与人，应当知道他得到明净之忍，这便是供养十方诸佛。在无数劫中行布施，以衣食、象马以及种种珍宝，应当知道那不是解脱之因，因为有我、人、众生之想。）

【按】“过恒河”之“河”，宋、元、明本作“沙”。

```
归命灭度人中尊，
救济众生无量数，
诸法皆空本清净，
如是解脱智庄严。
诸佛出世甚难值，
得闻正法生信难，
人身难得今已获，
善哉佛法汝顺行。
已得蠲除斯八难，
永绝迫窄处空闲，
于诸正法得信行，
应当勇猛发精进。
若闻法已应正思，
不可闻声即取著，
汝等常行阿兰若，
必当速疾成人雄。
近善知识及法师，
应速远离诸恶友，
汝于众生平等想，
慎勿妄起我人心。
常乐多闻持禁戒，
捐弃舍宅坐林间，
腐药治病莫诈善，
亦恒乞食受粪衣。
一切有为即无为，
等同一相如阳焰，
若了实际见真如，
疾成无上菩提道。
当观五阴犹如幻，
内外诸入如空舍，
世尊常说如斯法，
法等于彼莫生著。
贪欲瞋恚性自空，
愚痴我慢分别起，
彼法已灭今亦无，
如是知者得成佛。
```
（大意：归命已灭度的人中之尊，救济无量数的众生，诸法都空，本来清净，这样的解脱以智慧为庄严。诸佛出世甚难值遇，得闻正法而生信心也难，人身难得，现在已经获得，善哉，你们随顺修行佛法。已得除去这八难，永远断绝逼迫狭窄，身处空闲，对诸正法得以信行，应当勇猛发起精进。若听闻法之后，应当正确思惟，不可一听到音声便执取；你们常行阿兰若，必当迅速成就人中之雄。亲近善知识以及法师，应当迅速远离诸恶友，你们对众生作平等之想，切勿妄起我人之心。常乐于多闻，持守禁戒，舍弃房舍，坐于林间，以陈腐之药治病，不要诈现善相，也恒常乞食，穿粪扫衣。一切有为即是无为，同一相，如阳焰；若了达实际，见到真如，迅速成就无上菩提道。应当观察五阴犹如幻化，内外诸入如同空舍，世尊常说这样的法，法也同于那些，不要生起执著。贪欲、瞋恚的本性自空，愚痴、我慢由分别而起，那法已灭，现在也没有，这样了知的人得以成佛。）

这样，诸化菩萨说这偈时，那会众中二万二千众生都发阿耨多罗三藐三菩提心。五百比丘漏尽意解，心得解脱。三百比丘尼远尘离垢，得法眼净。七千优婆塞、优婆夷与二万五千天子也远离尘垢，法眼清净，三百菩萨得无生法忍。于是三千大千世界大地六种震动，就是动、遍动、等遍动，震、遍震、等遍震，涌、遍涌、等遍涌，乃至吼、起、觉等也是这样。

【按】“三百比丘尼”之“三”，元、明本作“五”。“六种振动”之“振”，宋、元、明、宫本作“震”，下同。

### 破魔品第四

#### 舍利弗问瑞相

那时尊者舍利弗对佛说：“世尊！现在这瑞相是谁所作？能令这三千大千世界大地六种震动。又这宝车、殿堂、莲花座上的诸菩萨等放大光明照这众会，演说这样微妙的深法。又令这样无量亿数的诸天子众都来集会，又有亿数的诸菩萨等也来集会。”那时佛告诉舍利弗：“这是文殊师利的威神之力，所以现出这样美妙庄严之事，也令菩萨与诸天云集。为什么呢？舍利弗！这文殊师利与善住意天子将要带领大众来到我这里，请问这样破散诸魔的三昧法门，是为了具足成就种种不可思议的甚深佛法。”

【按】“复有亿数”之“亿”，宫本作“无”。“成就诸不思议”之“诸”，《大正藏》脱，今依CBETA（所录高丽藏）补。

#### 文殊入破魔三昧，诸魔衰老

当时舍利弗又对佛说：“世尊！若是这样，因为什么缘故我观察这大众，竟不见那文殊师利？”佛告诉舍利弗：“你暂且等待。现在文殊师利已对一切魔王、一切魔众、一切魔宫作了大衰损，所作的神变极其美妙庄严，将到我这里，你自会见到。”

于是文殊师利便入于破散诸魔三昧。由于三昧之力，当时三千大千世界的百亿魔宫都朽旧昏暗，像要毁坏一样，那变化已经显现，不再有威光，令一切魔不乐于其所在，各自见到自身昏聩衰老、羸弱消瘦，拄着拐杖而行，诸天女都变成老妇。一切众魔见到这种情况，心中大为忧愁，身毛都竖起，惶怖地想：“这是什么变怪，令我们内外都这样不祥？莫非是死亡的时候到了，果报离散吗？还是世间将坏的劫灾之事呢？”

【按】“惛耄”之“惛”，宋、元、明、宫本作“昏”。“柱杖”之“柱”，宋、元、明、宫本作“拄”。

那些魔众这样想时，文殊师利又以神力示现百亿天子，站在魔面前，告诉魔众说：“你们不要忧惧。这不是你们的灾难，也不是劫尽。为什么呢？现在这里正有一位住于不退转的菩萨大士，名为文殊师利，有大威神，道德超越世间，此时正入于破散诸魔三昧法门。因为那位大士三昧的威神，所以有这样的事，不是别的原因。”诸化天子说这话时，一切魔王以及诸魔众听到诸化天说文殊师利大士的名号，更增惶恐，战栗不安，一切魔宫都大为震动。

【按】“战悼”之“悼”，宋、元、明、宫本作“掉”，今依此译作“战栗”。

当时诸魔王回答化天说：“唯愿仁者慈悲，救我们于危难。”诸化天子又对魔说：“不要怕，不要怕。你们现在应当迅速前往释迦牟尼佛世尊之所。为什么呢？那佛如来有大慈悲。若众生忧恐煎迫，只要前往归依，都能蒙受安乐，除去种种忧苦。”当时诸化天这样说之后，便在那里忽然不见。

#### 诸魔诣佛求救

那时一切魔王以及诸魔众听了化天的教导，无不欢欣，都同心在须臾之间，羸弱地拄着拐杖，都来到释迦牟尼佛面前，同声说：“大德世尊！愿救护我们，愿救护我们，免除这变怪困苦的大难。世尊！我们宁可听受百千万亿诸佛的名号，也不愿听那文殊师利一位菩萨的名号。为什么呢？我们一听到这文殊师利菩萨的名号，便大为惊恐，如同丧失自身。”

【按】“及诸魔众”之“诸”，明本作“语”。“须臾顷”之“顷”，《大正藏》作“项”，今依CBETA（所录高丽藏）作“顷”。

那时世尊告诉诸魔说：“波旬！你现在为什么忽然说这样的话？为什么呢？这位文殊大士凡所开导、利益众生之事，是亿百千佛往昔所未作、现在也不作、将来也不作的。只有这位文殊师利在过去、未来、现在常为众生建立这样的大事，众生成熟之后，把他们安置于解脱之中，所以你们虽然听闻那百千佛的名号，也不生苦恼，也没有惊怖。为什么说我现在忽然听到一位文殊师利的名号都大为惊恐？”当时那些魔众说：“世尊！我们实在惭耻于这衰老的弊身，加上惶惧，才说这话。世尊！我们从今以后归依正觉，唯愿哀愍，恢复我们本来的形貌。”佛告诉他们说：“暂且等待片刻。文殊师利来了之后，自会除去你们的羞耻。”

#### 文殊至佛所，说三昧因缘

于是文殊师利从三昧中起来，便与无量百千天众，又与无量百千诸大菩萨摩诃萨等，以及无量百千的龙、夜叉、乾闼婆、阿修罗、迦楼罗、紧那罗、摩睺罗伽等前后围绕，又作出无量百千微妙的乐音，又雨下这样无量的妙花，就是优钵罗花、钵头摩花、拘物头花、分陀利花，具足大庄严，有大神通，威德无极，一同来到佛所，头面礼敬，右绕三匝，退住一面。

那时世尊告诉文殊师利说：“文殊师利！你入了这样的破散诸魔三昧吗？”文殊师利说：“世尊！是的，已经入了。”佛说：“文殊师利！你从哪位佛听闻这三昧？修了多久才得以成满？”文殊师利说：“世尊！我本来还未发菩提心时，从佛那里听闻这样的三昧。”又问：“文殊师利！那位佛世尊的名号是什么，宣说这三昧令你得以听闻？”文殊师利说：“世尊！我忆念过去无量无边不可思议阿僧祇劫，那时有佛，号为曼陀罗花香如来、应供、正遍知、明行足、善逝、世间解、无上士、调御丈夫、天人师、佛、世尊，出现于世时，宣说这样的破散诸魔三昧。我在那时初次听闻。”

【按】“出现世时”之“时”，南藏作“间”。

#### 得破魔三昧的二十法与六组四法

佛告诉文殊师利：“这样的三昧怎样修得？”文殊师利说：“世尊！若菩萨摩诃萨具足成就二十种法，便能得到这破魔三昧。哪二十种？就是：一是诃毁贪欲，破坏贪心；二是诃毁瞋怒，破坏瞋心；三是诃毁愚痴，破坏痴心；四是诃毁嫉妒，破坏妒心；五是诃毁憍慢，破坏慢心；六是诃毁诸盖，破坏盖心；七是诃毁热恼，破坏恼心；八是诃毁想念，破坏想心；九是诃毁诸见，破坏见心；十是诃毁分别，破坏分别之心；十一是诃毁取事，破坏取心；十二是诃毁执著，破坏执心；十三是诃毁诸相，破坏相心；十四是诃毁有法，破坏有心；十五是诃毁常法，破坏常心；十六是诃毁断法，破坏断心；十七是诃毁诸阴，破坏阴心；十八是诃毁诸入，破坏入心；十九是诃毁诸界，破坏界心；二十是诃毁三界，破坏三界之心。世尊！这是菩萨摩诃萨具足二十法，毕竟成就这样的三昧。

【按】“呵毁”之“呵”，宫本作“诃”。“坏三界心”之“坏”，宋、元、明、宫本作“破坏”。

“世尊！菩萨摩诃萨又有四法，具足修行便得这三昧。哪四法？一是建立心行，清净调柔；二是心性淳直，没有种种谄曲；三是心无攀缘，入于深法忍；四是外内所有的一切都能布施。这是菩萨摩诃萨具足四法，成就三昧。

“世尊！菩萨摩诃萨又有四法，能得三昧。哪四法？一是毕竟深信，二是成就实语，三是常乐空闲，四是不取诸相。这是菩萨具足四法，成就三昧。

【按】“毕竟深信”之“信”，《大正藏》作“心”，今依CBETA（所录高丽藏、碛砂藏）作“信”，宫本同。

“又有四法，菩萨成就，便得这三昧。哪四法？一是亲近善友，二是常知止足，三是独坐思惟，四是不乐喧杂。这是菩萨具足四法，成就三昧。

“又有四法，菩萨成就，便得这三昧。哪四法？一是不破坏之戒，二是不缺犯之戒，三是无所依之戒，四是不望回报之戒。这是菩萨具足四法，成就三昧。

“又有四法，菩萨成就，便得这三昧。哪四法？一是舍弃声闻之心，二是远离缘觉之心，三是住于菩萨之忍，四是不舍众生。这是菩萨具足四法，成就三昧。

“又有四法，菩萨成就，便得这三昧。哪四法？一是修空而舍我，二是无相而离相，三是无愿而除愿，四是舍弃一切所有。这是菩萨具足四法，能得三昧。

【按】“无相离相”，元、明本作“离相无相”。

“世尊！当时那位曼陀罗花香如来、应供、正遍觉宣说这破散诸魔的法门，我从那佛听闻之后开始修习。其次又有佛，号为一切宝电蔽日月光如来、应供、正遍觉，我当时在那佛那里具足成就。那位佛世尊宣说这法门时，那众会中一万菩萨都得以成就这三昧门。”

【按】“说此法门时”，《大正藏》“此”下有“法”字，今依CBETA（所录高丽藏）删，宋、宫本同。

#### 十方诸魔皆变，摄神力复本形

那时尊者舍利弗对佛说：“希有，世尊！现在这文殊师利竟能久远成就这样的降魔三昧。由于三昧之力，能令波旬以及诸魔众头发变白，衰老昏聩，形体与意志都衰退，到了这种地步。”佛告诉舍利弗：“你认为怎样？你现在说这文殊师利只是令三千大千世界的众魔这样衰老吗？舍利弗！你现在不应作这样的见解。为什么呢？舍利弗！现在十方如恒河沙等诸佛世界所有的诸魔，一切都这样变坏，全是文殊师利的威力所作。”

于是世尊告诉文殊师利说：“文殊师利！你现在应当暂且收回你的神力，令那众魔得以恢复本来的形貌。”那时文殊师利受了佛的教导，告诉诸魔说：“诸位仁者！你们真的厌恶这身形吗？”诸魔回答说：“是的，大士！”文殊师利说：“若是这样，你们现在也应当厌恶贪欲，不要执著于三界。”诸魔回答说：“善哉大士！恭敬地听闻您的嘉言教诲，岂敢违背。唯愿稍借威神，除去这羞惭之苦。”文殊师利便收回神力，令一切魔恢复那天人之形，庄严如故。

【按】“诸魔报曰”之“诸”，宋、元、明、宫本无。

#### 为魔说眼等是魔境与非魔境

那时文殊师利告诉诸魔说：“波旬！你们所有的眼，什么是眼？什么是眼想？像这样，何处是眼的执著、是眼的相、是眼的攀缘、是眼的障碍、是眼的思、是眼的我、是眼的依止、是眼的喜乐、是眼的戏论、是眼的我所、是眼的守护、是眼的忆念、是眼的执取、是眼的舍弃、是眼的分别、是眼的思量、是眼的成就、是眼的生、是眼的灭，乃至是眼的来去。这样等法，是你们的境界、魔业与障碍。如眼，乃至身、意也是这样。又如色，乃至触、法，是你们的境界、魔业与障碍，也是这样。你们都应当如实了知。

“再者，波旬！你们所有的眼，即是非眼，也是无眼。是无眼想、无眼的执著、无眼的相、无眼的攀缘、无眼的障碍、无眼的思、无眼的我、无眼的依止、无眼的爱、无眼的戏论、无眼的我所、无眼的守护、无眼的忆念、无眼的执取、无眼的舍弃、无眼的分别、无眼的思量、无眼的决定、无眼的生、无眼的灭、无眼的去、无眼的来。这样等法不是你们的境界，你们在其中不能作主，没有法，没有力量，不得自在，也没有取著。如眼，乃至身、意也是这样。又如色，乃至触、法也是这样。你们都应当如实了知。”文殊师利宣说此法时，众中一万位魔王波旬都发阿耨多罗三藐三菩提心，八万四千诸魔眷属远尘离垢，得法眼净。

### 菩萨身行品第五

#### 诸来菩萨现身

那时尊者摩诃迦叶对佛说：“世尊！我们愿请文殊师利令我们见到那些菩萨摩诃萨等。为什么呢？世尊！这些大士难以值遇。”那时世尊便告诉文殊师利说：“你应当知道，现在这大众都渴仰，思愿见到十方所有前来的菩萨摩诃萨之身。现在正是时候，你应当令他们显现。”

于是文殊师利蒙受圣教之后，便告诉那法轮菩萨、月光菩萨、除魔菩萨、妙音菩萨、离垢菩萨、寂灭菩萨、选择菩萨、法王吼菩萨，像这样等无量菩萨摩诃萨说：“诸大士！你们现在应当各在宫殿中显现自身，分明地显现你们本国的形状。”

【按】“除魔菩萨”之“除”，宋、元、明本作“降”。“汝等今宜”之“宜”，《大正藏》作“宣”，今依CBETA作“宜”。

文殊师利说了这话之后，于是诸菩萨众从三昧起来，各自现出本身，令大众一切都看见。或有菩萨，身高大如须弥山王；或有菩萨，身大八万四千由旬；或有身大十万由旬，或九万，乃至五万、四万、三万、二万由旬的。或有身大一万由旬，乃至或有五千、四千、三千、二千由旬的。或有身大一千由旬，乃至或有五百、四百、三百、二百由旬的。或有身大一百由旬，乃至或有五十、四十、三十、二十由旬的。或有身大十由旬，乃至或有五、四、三、二、一由旬的。像这样，乃至或有菩萨，身量大小、长短、宽窄与这娑婆世界的人身没有差异。在那时候，这三千大千世界大众充满，没有一处空地如杖头大小。其中所有的诸大菩萨摩诃萨众，一切多是功德巍巍，智慧深远，具足威力，成就神通，放大光明，遍照十方无量百千诸佛世界，乃至一切大威德天，以及诸天、龙、夜叉、乾闼婆、阿修罗、迦楼罗、紧那罗、摩睺罗伽、人非人等，大小诸王，都充满其中。

#### 文殊问何谓菩萨：觉一切法

那时文殊师利从座而起，整理衣服，偏袒右肩，右膝著地，合掌向佛，说：“世尊！我现在想向如来、应供、正遍觉稍问心中的疑惑。不知世尊垂允听许吗？”佛告诉文殊师利：“如来、应供、正遍觉任你所问，当为你解释，决断你的疑惑，令你心喜。”文殊师利说：“是的，世尊！愿为宣说，我当听受。”

【按】“偏袒右髆”之“髆”，宋、元、明、宫本作“肩”。

文殊师利说：“世尊！什么名为菩萨摩诃萨？所说的菩萨，是什么意义？”佛告诉文殊师利：“你问‘什么是菩萨？菩萨有什么意义？’，因为能觉了一切法，所以名为菩萨摩诃萨。文殊师利！那一切法，菩萨所觉的，是指言说。文殊师利！菩萨怎样觉一切法？就是觉眼、觉耳、觉鼻、觉舌、觉身、觉意。文殊师利！菩萨怎样觉眼、觉耳乃至觉意？文殊师利！就是菩萨觉那眼法本性是空。这样觉了之后，终不生起‘我能觉知’之念。像这样，觉耳乃至觉意，都是本性空。这样觉了之后，也不生起‘我能觉知’之念。菩萨这样觉了眼等之后，又觉那色本性自空。这样觉了之后，也不分别‘我能觉知’。像这样，觉声乃至觉法，都是本性空，也不分别‘我能觉知’。这是菩萨觉一切法。

#### 觉五阴

“再者，文殊师利！菩萨怎样觉那五阴？就是菩萨观见五阴之体本性自空。因为这样觉，所以观察无相；因为这样觉，所以观察无愿；因为这样觉，所以观察无欲；因为这样觉，所以观察寂静；因为这样觉，所以观察远离；因为这样觉，所以观察无所有；因为这样觉，所以观察无实；因为这样觉，所以观察无动；因为这样觉，所以观察无生；因为这样觉，所以观察无来；因为这样觉，所以观察无去；因为这样觉，所以观察无真；因为这样觉，所以观察无主；因为这样觉，所以观察无证；因为这样觉，所以观察无知；因为这样觉，所以观察无见；因为这样觉，所以观察无人；因为这样觉，所以观察无想；因为这样觉，所以观察不可说。因为这样觉，所以观察只有名字；因为这样觉，所以观察无我；因为这样觉，所以观察由分别而起；因为这样觉，所以观察从因缘而生；因为这样觉，所以观察如幻；因为这样觉，所以观察如化；因为这样觉，所以观察如梦；因为这样觉，所以观察如镜中之像；因为这样觉，所以观察如回响；因为这样觉，所以观察如芭蕉；因为这样觉，所以观察不久住；因为这样觉，所以观察不牢固；因为这样觉，所以观察虚妄；因为这样觉，所以观察无物。因为这样觉，这是菩萨觉一切法。

【按】“觉但有名”之“觉”，宋、元、明、宫本作“观”，与上下文“观”字相次，今依此译。

#### 觉三毒、三界、众生行、一切众生

“再者，文殊师利！菩萨摩诃萨怎样觉贪、恚、痴？就是觉那贪欲是由分别而起，觉那瞋恚是由分别而起，觉那愚痴是由分别而起，而也觉那分别空无所有，无物，无戏论，不可说，不可证。这是菩萨觉一切法。

“再者，文殊师利！菩萨摩诃萨怎样觉于三界？就是觉那欲界没有我与人，觉那色界无所作，觉无色界空无所有，觉那三界都是远离的。这是菩萨觉一切法。

“再者，文殊师利！菩萨摩诃萨怎样觉众生之行？就是觉这众生是贪欲之行，觉这众生是瞋恚之行，觉这众生是愚痴之行，觉这众生是等分之行。这样觉了之后，这样证知，这样为他们宣说，这样教化众生，这样令他们得以解脱。这是菩萨觉一切法。

“再者，文殊师利！菩萨摩诃萨怎样觉一切众生？就是觉一切众生只有名字，离开那名字之后，没有另外的众生。所以一切众生即是一个众生，那一个众生即是一切众生，这样的众生即非众生。若能这样没有分别，这是菩萨摩诃萨觉一切法。又怎样觉一切法？能这样觉菩提之道，这是菩萨摩诃萨觉一切法。”

【按】“觉菩萨道”之“萨”，宋、元、明、宫本作“提”，今依此译作“菩提之道”。

#### 世尊重颂

那时世尊重明此义，以偈颂道：

```
觉眼及与耳，自体常空寂，
不言我能觉，是名为菩萨。
观鼻及与舌，本性无所有，
不分别我觉，是名为菩萨。
智慧观察身，亦觉意自然，
觉已为他说，是名为菩萨。
色声香味触，意所乐诸尘，
觉知本性空，是名为菩萨。
觉色及受想，诸行与识心，
一切斯同幻，是名为菩萨。
五阴聚如梦，觉彼无一相，
不分别我知，是名为菩萨。
不生亦不出，无作复无言，
如是说唯名，彼名亦非物。
觉贪欲瞋恚，斯由分别起，
彼分别无体，毕竟终自空。
痴亦分别生，分别因缘生，
缘此生诸见，诸见不可得。
觉察三界空，一切无真实，
于彼不可动，故名为菩萨。
欲界不成就，皆缘分别起，
色有无色有，一切不牢固。
```
（大意：觉了眼以及耳，自体常空寂，不说我能觉，这名为菩萨。观察鼻以及舌，本性无所有，不分别我觉，这名为菩萨。以智慧观察身，也觉意本自如此，觉了之后为他人宣说，这名为菩萨。色、声、香、味、触以及意所乐的诸尘，觉知它们本性是空，这名为菩萨。觉了色以及受、想、诸行与识心，一切都同于幻化，这名为菩萨。五阴之聚如梦，觉了它们没有一相，不分别我知，这名为菩萨。不生也不出，无作又无言，这样说只是名字，那名字也不是实物。觉了贪欲、瞋恚，这些由分别而起，那分别没有实体，毕竟终究自空。痴也由分别而生，分别由因缘而生，缘此生起种种见，诸见都不可得。觉察三界是空，一切都不真实，对此不可动摇，所以名为菩萨。欲界并不成就，都缘分别而起，色有、无色有，一切都不牢固。）

【按】“彼名亦非物”之“非”，元、明本作“无”。“终自空”之“自”，宫本作“目”。“分别因缘生”之“生”，宫本作“出”。

```
众生之所行，智者悉明了，
贪欲与瞋恚，及彼愚痴等。
一切诸众生，即彼一众生，
智者无所觉，不念彼众生。
诸法之所起，悉因颠倒生，
觉彼颠倒者，知颠倒真相。
智慧甚微妙，不取诸音声，
觉已无所著，故名为菩萨。
能舍己肉身，终亦无依止，
如是觉真实，乃名为菩萨。
```
（大意：众生的所行，智者都明了，就是贪欲与瞋恚，以及那愚痴等。一切众生即是那一个众生，智者无所觉，不念那些众生。诸法的生起，都因颠倒而生，觉了那颠倒的人，知道颠倒的真相。智慧甚为微妙，不取著种种音声，觉了之后无所执著，所以名为菩萨。能舍弃自己的肉身，终究也没有依止，这样觉了真实，才名为菩萨。到达持戒的彼岸，也不念那彼岸，觉了戒行之法如如，无生也无尽。慈心遍及众生，不得众生之相，觉了那众生的边际，只是以假名言说宣示。勇猛大精进，深心厌离有为，见三界空虚，证得无上等觉。常入于微妙的禅定，无执著，无所依，无住，无攀缘，智者的定就是这样。能以锋利的智慧之刀，断除种种见的系缚，观察法界之性，无割也无伤。若人真正觉了一切法如实，应时利益众生，才名为菩萨。）

【按】“能舍己肉身”之“己”，《大正藏》作“已”，今依CBETA作“己”。
