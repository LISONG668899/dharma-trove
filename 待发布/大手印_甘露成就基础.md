# 甘露成就基础

大阿阇黎毗瓦巴（Virūpa）造　据藏文译出

## 题解

《甘露成就基础》（梵 Amṛtasiddhimūla，藏 bdud rtsi grub pa'i rtsa ba，直译"甘露成就之根本"）收于德格版丹珠尔续部释 ཞི 函第 143a 至 145a 页（东北目录 D2285），紧接在《道果经教》（D2284）之后。题名作《甘露成就之根本》，跋语作《甘露成就》，说是"大阿阇黎毗瓦巴"所造，由"印度亲教师、得成就的瑜伽士、印度人诶德巴（e de ba）"译出。

本篇在丹珠尔中颇为特别：它的内容不是一般的密续释论，而是以身体的姿势、收束与风息为主的瑜伽修法，讲的是"大手印""大收束""大穿透"三种修法，以及"阴门手印""林伽手印"等，目的是使风息进入中脉、穿透梵天等三结、打开顶门，从而得到"甘露成就"——不死、不老、无病。这些修法与后来印度"哈达瑜伽"（haṭha yoga）典籍中的"大手印"（mahāmudrā）、"大收束"（mahābandha）、"大穿透"（mahāvedha）等名称与做法几乎相同。现存有一部梵文与藏文对照的《甘露成就》（Amṛtasiddhi），被学界视为最早的哈达瑜伽典籍之一，也与毗瓦巴（Virūpākṣa）的名字相连；本篇与那部《甘露成就》的关系，尚待进一步考订。

**名相的特别说明：**本篇所说的"业手印""三昧耶手印""法手印""大手印"，与梅纪巴一系所说的四手印（以业手印为外在的明妃，以大手印为心性的证悟）名称相同，含义却完全不同。在本篇中，它们都是身体的姿势与风息的修法：例如"业手印"是以左脚跟抵住下门、手握脚趾、下颚压胸的坐姿；"大手印"是束住手足、三次吸气、拉动诸脉的修法。读者切不可把本篇的名相与《灌顶教示》《金刚句》等的四手印混为一谈。同样，"阴门手印"（ཛོ）与"林伽手印"（ལིངྒ），在这里也是身体与风息的收束法，不是指男女双运。

**关于修持的告诫：**本篇所说的种种收束、闭气、拍击、提升风息的方法，都是有一定危险性的身体与呼吸修法，必须在具有经验的上师亲自指导下才能修习，自行照文字修习，可能导致身心的严重损伤。本译只照原文译出，不作任何修法上的解说。文中有几处藏文明显残缺或难解（如"ཛྷ་ཡེ་དྷ་ཡི་ཀརྨ"一句），都在按语中存疑。

**与前译的关系：**本篇以前没有译过，与已译篇目没有重复。

## 一、此法的功德（第 11–17 句）

```
ཕྱག་རྒྱ་ཆེན་པོ་རྣམས་བཤད་བྱ། །
མི་ནི་གང་གིས་ཐོས་པ་ལ། །
ལྷ་རྣམས་ཀུན་གྱིས་བཀུར་སྟི་མཛད། །
སྐྱེ་བ་བྱེ་བ་སྟོང་དག་ཏུ། །
ལེགས་ལས་རྒྱ་ཆེན་རྣམས་བྱས་པས། །
དེ་ཐོབ་འཁོར་བའི་རྒྱ་མཚོ་ལ། །
ཕ་རོལ་ཏུ་ནི་རྣལ་འབྱོར་འགྲོ། །
```

我要讲说诸大手印。凡是听闻这些的人，一切天神都会恭敬他。由于在千万生中作了广大的善业，才得到这［法］；瑜伽士［依此］就能到达轮回大海的彼岸。

## 二、业手印：封闭九门（第 18–25 句）

```
གཡོན་པའི་རྟིང་པས་བཤང་ལམ་དགག །
གཡས་པ་ཅུང་ཟད་བརྐྱང་བྱས་ལ། །
མཐེབ་ཆེན་བོལ་གོང་ལག་པས་གཟུང་། །
སྙིང་ག་ལྐོག་མས་མནན་པ་ནི། །
སྒོ་དགུ་དགག་པའི་སྦྱོར་བའོ། །
དེ་ཡི་རྩ་གསུམ་དག་ལ་ནི། །
རིམ་པ་བཞིན་དུ་བསྣུན་པར་བྱ། །
འདི་ནི་ལས་ཀྱི་ཕྱག་རྒྱའོ། །
```

以左脚跟抵住下门；右［脚］稍微伸直；用手握住大脚趾与踝骨；以下颚压住心口——这就是封闭九门的修法。对它的三脉，要依次拍击。这就是业手印。

【按】这一节描写的是一种坐姿：左脚跟抵住会阴（下门），右腿伸直，以手握住右脚，下颚压住胸口。这与后来哈达瑜伽典籍中"大手印"（mahāmudrā）的姿势完全相同。"踝骨"，藏文作"བོལ་གོང"，意思是脚背或踝部，存疑。"九门"，指身体的九窍。"对它的三脉，要依次拍击"，"拍击"（bsnun pa），可能是指以呼吸或身体的动作依次刺激左、右、中三脉，存疑。

如题解所说，这里的"业手印"是一种身体的姿势，与梅纪巴一系以业手印为外在明妃的含义完全不同。

## 三、三昧耶手印：日月合一（第 26–31 句）

```
རྐང་པ་གཅིག་པ་སེམས་བསྡུ་ཞིང་། །
རླུང་རྣམས་གཅིག་ཏུ་བསྡུས་བྱ་སྟེ། །
རླུང་གིས་བསྡམ་པ་བརྩམ་པར་བྱ། །
ཉི་ཟླ་གཉིས་ནི་གཅིག་པར་བྱ། །
དེ་ལྟར་བྱས་ན་རླུང་ནི་འགག །
འདི་ནི་དམ་ཚིག་ཕྱག་རྒྱའོ། །
```

以单足［之姿］收摄心，把诸风收摄为一；以风来开始收束；使日月二者合一。这样做了，风就止息了。这就是三昧耶手印。

【按】"单足"（rkang pa gcig pa），可能是一种单腿的姿势，也可能是"一心"的比喻，存疑。"日月二者"，指左右二脉（或上下二气），使之合一而入中脉，这是圆满次第与哈达瑜伽共通的说法。

## 四、风的修法：使明点上升（第 32–45 句）

```
བཤང་ལམ་འཁོར་ལོ་གྱེན་དུ་བཟློག །
ཐིག་ལེ་སྒྲ་བཅས་གྱེན་དུ་བསླང་། །
རྩ་རྣམས་ཐམས་ཅད་རབ་ཏུ་གཡོ། །
མཆོག་གི་རྩ་ནི་གྱེན་དུ་འོང་། །
ལུས་ངག་ཡིད་གསུམ་སྦྱོར་བ་ཡིས། །
སྐུ་གསུང་ཐུགས་ནི་བསྒྲུབ་པར་བྱ། །
གོམས་པ་བརྟན་པར་གྱུར་པ་ཡིས། །
རང་གི་མེ་ནི་གསལ་བའོ། །
ཕྱག་རྒྱ་འདི་ཡིས་ཐམས་ཅད་དུ། །
རྣལ་འབྱོར་པ་ནི་ངེས་པར་འགྲོ། །
འདི་ནི་ཁ་སྦྱོར་སྦྱོར་བ་སྟེ། །
རྩ་བའི་གདམས་པར་འདོད་པའོ། །
འདི་ནི་རླུང་གི་སྦྱོར་བ་ཡིན། །
མཁས་པ་རྣམས་ཀྱིས་འདི་བསྒྲུབ་པོ། །
```

把下门之轮向上翻转；使明点带着声音向上提升；一切脉都剧烈地动摇，最殊胜的脉就会向上而来。以身、语、意三者的结合，来成就［佛的］身、语、意。由于串习稳固了，自身的火就会明亮。以这个手印，瑜伽士一定能到达一切处。这就是结合的修法，被承许为根本的口诀；这就是风的修法，智者们修持它。

【按】"把下门之轮向上翻转"，可能是指收提会阴（mūlabandha）的修法；"最殊胜的脉"，即中脉；"自身的火"，即拙火。"结合"（kha sbyor），这里是指风息、明点与中脉的结合，存疑。这些都是身体与风息的修法，须依具德上师的亲自指导，这里不作解说。

## 五、两种手印：阴门与林伽（第 46–57 句）

```
ཕྱག་རྒྱ་གཉིས་སུ་ཤེས་པར་བྱ། །
ཇི་བཞིན་བསྡམ་པའི་ཆོ་ག་ཤེས། །
ཛོ་ནི་ལྷ་མོའི་ཕྱག་རྒྱ་ཡིན། །
ལིངྒའི་ཕྱག་རྒྱ་ལྷ་ཡིན་ནོ། །
ཕོ་དང་མོ་ཡི་སྦྱོར་བ་ལས། །
ཕྱི་རོལ་དུ་ནི་སྐྱེས་པ་འབྱུང་། །
ཇི་བཞིན་སྦྱོར་བ་འདི་གཉིས་ཀྱིས། །
སྐྱེ་བ་ནང་དུ་གསང་བར་བྱ། །
རྩ་ནི་བུད་མེད་གཟུགས་ཅན་ཏེ། །
སྐྱེས་པ་མེད་ན་འབྲས་བུ་མེད། །
ཕྱག་རྒྱ་ཆེ་དང་བསྡམས་པ་ཆེ། །
དབྱེ་བ་མེད་ན་འབྲས་བུ་མེད། །
```

要了知两种手印，要了知如实收束的仪轨：阴门是女尊的手印，林伽的手印是男尊。从男女的结合中，在外面会生出［子嗣］；以如实的这两种修法，要把生［的力量］秘藏在内里。脉具有女性的形相，没有男性就没有果；大手印与大收束，若不是无别的，就没有果。

【按】"阴门"（ཛོ，梵 yoni）与"林伽"（ལིངྒ，梵 liṅga），在这里是身体与风息的两种收束法的名称（后来哈达瑜伽中有"阴门手印"yonimudrā 等），以男女象征来说明：外在的男女结合生出子嗣，内在的这两种修法则把生殖的力量（明点）秘藏于体内而不外泄。这些都是象征用语与身体的修法，不是指男女双运，须依具德上师的亲自指导来理解。"要把生［的力量］秘藏在内里"，藏文作"སྐྱེ་བ་ནང་དུ་གསང་བར་བྱ"，存疑。

## 六、使风入中脉，穿透四轮（第 58–65 句）

```
རླུང་ནི་འཁོར་ལོ་གཅིག་ཏུ་བསྡུ། །
ཇི་སྲིད་བསྡམས་པ་བཞིན་དུ་བྱ། །
རྣལ་འབྱོར་པ་ཡིས་བཤིག་པར་བྱ། །
རང་གི་རླུང་སེམས་བཤིག་པར་བྱ། །
སྦྱོར་བའི་རིམ་པས་བཤིག་པར་བྱ། །
རླུང་ནི་སྟོབས་དང་ལྡན་བྱས་ལ། །
དབུ་མའི་སྒོ་རུ་གཞུག་བྱ་སྟེ། །
འཁོར་ལོ་བཞི་པོ་རླུང་གིས་དབུག །
```

把风收摄于一轮；随着收束的时间而作。瑜伽士要摧破——摧破自己的风心，以修法的次第来摧破。使风具有力量之后，引入中脉之门；以风穿透四轮。

## 七、大穿透：以风制风（第 66–77 句）

```
ལག་གཉིས་ལིངྒའི་ཕྱག་རྒྱ་བཅའ། །
དེ་ནི་ས་ལ་གཞག་ནས་སུ། །
རྐང་པའི་རྩེ་མོ་ས་ལ་གཟུགས། །
བརླ་ནི་བརྡབ་པར་བྱ་བ་ཡིས། །
རླུང་གིས་རླུང་ནི་བཤིག་པར་བྱ། །
རླུང་གིས་རླུང་ལ་བཏེག་པར་བྱ། །
རླུང་གིས་རླུང་ནི་གསད་པར་བྱ། །
རླུང་གིས་ཡོངས་ལ་ཁྱབ་པ་ཡིས། །
རླུང་གིས་དངོས་གྲུབ་ཐམས་ཅད་སྦྱིན། །
རླུང་གིས་འཆི་བ་མེད་པར་འགྱུར། །
དེས་ནི་བདུད་རྩི་གྲུབ་པར་ནི། །
བིཪྺ་ང་ཡིས་ཡང་དག་བཤད། །
```

两手结林伽手印，把它放在地上，脚尖抵住地面；以拍击大腿［于地］，以风来摧破风，以风来提升风，以风来杀死风。以风遍满一切，风给予一切悉地，以风而成为不死。因此，我——毗瓦巴，真实地讲说了甘露成就。

【按】这一节描写的是后来哈达瑜伽中"大穿透"（mahāvedha）的做法：以两手撑地，提起身体后以臀部（或大腿）轻轻拍击地面，使风息进入中脉。"以风来摧破风、提升风、杀死风"，是说以修法所控制的风，来制伏平常散乱的风。这些都是有危险性的身体修法，必须在上师亲自指导下修习。

## 八、穿透三结，打开顶门（第 78–94 句）

```
ལེགས་པར་བསྡམས་པ་ལུས་ཀྱི་ལས། །
རྡོ་རྗེ་རླུང་རྩེ་བྱེ་བ་ཡིས། །
ལྷུན་པོ་ཡི་ནི་བར་དག་ཏུ། །
དགུག་པའི་སྦྱོར་བ་འདི་ཡིས་ནི། །
ཚངས་སོགས་མདུད་པ་བཤིག་པར་བྱ། །
ལྷུན་པོའི་སྟེང་དུ་ལྷ་རྣམས་འགྲོ། །
ལྷུན་པོ་དག་ནི་གཡོ་འགྱུར་ཏེ། །
དེས་ནི་ཐམས་ཅད་བརྒྱལ་བར་འགྱུར། །
ཚངས་པ་ལ་སོགས་ལྷ་རྣམས་བསད། །
དང་པོ་ཡི་ནི་སྦྱོར་བ་ཡིས། །
ཚངས་པའི་མདུད་པ་བཤིག་པར་བྱ། །
དེ་ནས་དབང་ཕྱུག་མདུད་པ་བཤིག །
དེ་བཤིག་ནས་ནི་བིཥྞུ་བཤིག །
དེ་ནས་གཏི་མུག་ལ་སོགས་སྤངས། །
གཙུག་ཏོར་སྒོ་ནི་སྦས་པ་ལ། །
རླུང་གིས་སྒོ་ནི་རྣམ་པར་དབྱེ། །
དེ་ནི་འབིགས་པ་ཆེན་པོའོ། །
```

善加收束的身体之业，以千万道金刚风尖，在须弥山的中间，以这勾召的修法，摧破梵天等的结。诸天走向须弥山顶；须弥山都动摇了，一切因此都昏厥了；梵天等诸天都被杀死了。

以第一个修法，摧破梵天之结；然后摧破自在天之结；摧破了它之后，再摧破毗湿奴［之结］；然后舍弃愚痴等。顶髻之门是隐藏着的，以风打开那门——这就是大穿透。

【按】"须弥山"，在这里比喻脊柱或中脉；"梵天、自在天、毗湿奴之结"，是后来哈达瑜伽中所说中脉上的三个"结"（granthi），即梵天结、毗湿奴结、楼陀罗（自在天）结，修行者以风息依次穿透这三结，最后打开顶门。这里的次第是梵天结、自在天结、毗湿奴结，与后来哈达瑜伽通常的次第（梵天、毗湿奴、楼陀罗）不同，存疑。"诸天都被杀死了"，是说这些结（以诸天为名）被穿透，不是字面上的杀害。

## 九、三法即法手印（第 95–108 句）

```
བསྡམ་པ་ཆེ་དང་འབིགས་པ་ཆེ། །
ཕྱག་རྒྱ་ཆེ་ནི་གསུམ་པ་ཡིན། །
འདི་ནི་གསང་དབང་གསུམ་ཡིན་ནོ། །
འདི་དག་གིས་ན་སྦྱོར་གྲུབ་གྲགས། །
དེ་ཉིད་གསུམ་ནི་གང་རིག་པས། །
དེ་ནི་འཇིག་རྟེན་གསུམ་རིག་གོ། །
གང་གིས་འདི་ལ་གོམས་བྱས་ན། །
ཐམས་ཅད་ཀྱི་ནི་མངའ་བདག་འགྱུར། །
གསང་བ་ལྷ་ཡི་ལྷ་རྣམས་དང་། །
མི་ཡི་བདག་པོའི་བདག་པོར་འགྱུར། །
དབང་བསྐུར་ཀུན་ལ་དབང་བ་ཡིན། །
ཐམས་ཅད་མ་ལུས་ལྷག་པར་འགྱུར། །
དེས་ན་ལྷ་རྣམས་ཀུན་གྱི་དབང་། །
ཆོས་ཀྱི་ཕྱག་རྒྱར་འདོད་པའོ། །
```

大收束、大穿透，以及第三的大手印——这三者就是秘密的三种灌顶，因此被称为"修法的成就"。凡是了知这三种真性的人，就了知了三界。凡是串习这个的人，就会成为一切的主宰，成为秘密天神中的天神、人间诸王之王；对一切灌顶都有自在，超胜一切。所以，［它］是一切天神的自在，被承许为法手印。

【按】"这三者就是秘密的三种灌顶"（gsang dbang gsum），意思不很清楚，可能是说这三种修法如同三种秘密的灌顶，存疑。"被承许为法手印"，与上文"业手印""三昧耶手印"一样，是本篇特有的名相，与梅纪巴一系所说的法手印含义不同。

## 十、大手印的功德（第 109–122 句）

```
ཕྱག་རྒྱ་ཆེ་ལ་གོམས་པར་བྱ། །
ཕྱག་རྒྱ་འདི་ལས་ཐམས་ཅད་འབྱུང་། །
གྲུབ་པ་ཆེན་པོ་འབྱུང་བ་ཡིན། །
ཕྱག་རྒྱ་ཆེན་པོ་གང་ཡིན་པ། །
རྣམ་གཉིས་དེ་ནི་དམ་པ་དང་། །
འཆི་བ་ལས་ནི་གྲོལ་བ་དང་། །
ལུས་སེམས་དག་ལ་བདེ་བ་འབྱུང་། །
སེམས་ལ་གནས་པ་ཙམ་གྱིས་ཀྱང་། །
མངལ་དུ་སྐྱེ་བར་མི་འགྱུར་རོ། །
དང་པོའི་མིང་ནི་ཡི་གེ་ཡིན། །
སྦྱོར་བ་ལྡན་པ་བཤད་པར་བྱ། །
དད་དང་ལྡན་པའི་སྦྱོར་བ་ཡིན། །
རྣལ་འབྱོར་པ་ནི་ངེས་པར་ནི། །
ཕྱག་རྒྱ་ཆེན་པོ་འགྲུབ་པ་ཡིན། །
```

要串习大手印！从这个手印中生出一切，生出大成就。凡是大手印，那两种是殊胜的，从死亡中解脱，身与心都生起安乐；仅仅安住于心中，就不会再入胎受生。

第一个名称就是文字；我要讲说具足修法的［方式］：这是具足信心的修法，瑜伽士一定能成就大手印。

【按】"那两种是殊胜的"（rnam gnyis de ni dam pa），"两种"所指不明，可能是指身与心两方面，存疑。"第一个名称就是文字"（dang po'i ming ni yi ge yin），意思不明，存疑。

## 十一、大手印的修法：以风除病（第 123–136 句）

```
ཕྱག་རྒྱ་ཆེན་པོ་བཤད་པར་བྱ། །
རྐང་པ་ལག་པ་བསྡམ་བྱ་སྟེ། །
རླུང་ནི་ལན་གསུམ་འཐུངས་བྱས་ལ། །
རྩ་རྣམས་ཐམས་ཅད་འཐེན་པར་བྱ། །
ལངས་པས་རྩ་རྣམས་གྱེན་དུ་ཕྱོགས། །
ནད་རྣམས་ཐམས་ཅད་བཅོམ་ནས་ནི། །
ཕྱག་རྒྱ་ཆེན་པོའི་དོན་ཡང་རྫོགས། །
ཇི་ལྟར་ནམ་མཁའ་བར་སྣང་ལ། །
སྤྲིན་ཚོགས་འབར་བ་འཁྲིགས་པ་དེ། །
རླུང་གི་ཤུགས་ཀྱིས་གཏོར་བ་ལྟར། །
དེ་ལྟར་ལུས་འདི་དག་ལ་ནི། །
ནད་ཀྱིས་ཡོངས་སུ་བསྒོས་གྱུར་ཀྱང་། །
ཐབས་ཀྱི་རླུང་གིས་གཞོམ་པར་བྱ། །
འདི་ནི་ཕྱག་རྒྱ་ཆེན་པོའོ། །
```

我要讲说大手印：要束住脚与手，吸三次气，拉动一切脉；站起来时，诸脉都朝向上方；摧毁了一切疾病之后，大手印的意义也就圆满了。就像虚空中聚集的燃烧般的云团，被风力吹散一样，即使这身体被疾病完全浸染，也要以方便之风来摧毁［疾病］。这就是大手印。

## 十二、按摩与力轮（第 137–148 句）

```
ཛྷ་ཡེ་དྷ་ཡི་ཀརྨ་ཡི། །
ལག་པས་འབྱུང་བ་ལྔ་དག་ཀྱང་། །
ལས་ཀྱི་བྱ་བས་མཉེ་བྱ་ཞིང་། །
བསྡམས་པ་ཆེན་པོས་གནས་པ་ཡི། །
སྟོབས་ཀྱི་འཁོར་ལོ་འདི་ཡིས་ནི། །
སྟེང་དུ་ལྷ་ཡི་འཇིག་རྟེན་སྐྲག །
ལག་པ་བརྐྱང་བསྐུམ་འདི་ཡིས་ནི། །
ཕྱོགས་བཞི་དག་ཀྱང་གཡོ་བར་བྱེད། །
རྐང་པ་འོག་ཏུ་བརྐྱང་པ་ཡིས། །
ཀླུ་རྣམས་ཐམས་ཅད་སྐྲག་པར་བྱེད། །
དབང་པོ་ངལ་ཞིང་དུབ་བའི་ཚེ། །
རྩེ་གཅིག་སེམས་ཀྱི་ངང་ལ་གཞག །
```

……以手对五大也作按摩的作业；以大收束而安住的这个力量之轮，使上方的天界都恐惧；以伸展与收缩双手，四方都动摇；把双脚向下伸展，使一切龙族都恐惧。当诸根疲劳困倦的时候，就安住于一心专注的状态中。

【按】这一节第一句藏文作"ཛྷ་ཡེ་དྷ་ཡི་ཀརྨ་ཡི"，是一串不成文的梵文音节，意思不明，可能是某个梵文词的残缺音译，这里不妄补，存疑。"使上方的天界都恐惧""使一切龙族都恐惧"，是以夸张的方式形容这些修法的力量。"当诸根疲劳困倦的时候，就安住于一心专注的状态中"，是说身体的修法之后，要以心的安住作为结束。

## 十三、收束的修法：封闭三道（第 149–173 句）

```
བསྡམ་པའི་སྦྱོར་བ་བཤད་པར་བྱ། །
རླུང་གིས་ལུས་ནི་འཛིན་པར་འགྱུར། །
བསྡམ་པ་གཉིས་ནི་ཤེས་བྱ་སྟེ། །
ཇི་ལྟར་ཐིག་ལེ་གནས་པ་དང་། །
ཛོ་ནི་བྷ་དྷའི་ལྷ་མོ་ཡིན། །
མགྲིན་པ་བསྡམས་པ་ལྷ་ཡིན་ནོ། །
དགང་བ་ཅན་དང་བུམ་པ་ཅན། །
ཕྱག་རྒྱ་གཟུང་བ་རྣམ་པར་བྱ། །
ལྷ་དང་ལྷ་མིན་ཀུན་ལ་གསང་། །
རྣལ་འབྱོར་བསྡམ་པར་བྱ་བ་ཡིས། །
དབུ་མའི་སྒོ་རུ་གཏད་པར་བྱ། །
ལམ་གསུམ་རྣམ་པར་བཀག་བྱས་ལ། །
རླུང་ནི་ནང་དུ་གཟུང་བར་བྱ། །
སྲོག་ནི་རླུང་ཡང་རླན་པར་བྱ། །
དེ་ལྟར་བྱས་པས་འོག་ཏུ་འབབ། །
སྐད་ཅིག་ཉིད་ལ་བསྡམ་པར་བྱ། །
སྟེང་འོག་རླུང་གི་སྦྱོར་བ་ཡིས། །
མཉམ་པའི་རླུང་དང་བསྲེག་པར་བྱ། །
དེས་ནི་གྱེན་དུ་བསྐྱོད་པར་བྱ། །
བཤང་ལམ་བསྡམས་པ་དང་ལྡན་པས། །
རླུང་ནི་རྣམ་པར་བསྐུམ་པ་དང་། །
གྱེན་དུ་བླང་བ་བྱས་པ་ཡིན། །
འཁྲུལ་འཁོར་དང་ནི་རླུང་སྦྱོར་གྱིས། །
དགྲམ་དང་རབ་ཏུ་བསྡམ་པར་བྱ། །
ཟུང་འཇུག་ལམ་གསུམ་བསྒོམ་པར་བྱ། །
```

我要讲说收束的修法：以风来持住身体。要了知两种收束，以及明点如何安住：阴门是……的女尊，收束喉咙是男尊；以充满［气］与瓶［气］，要结持诸手印；对一切天神与阿修罗都要保密。

瑜伽士以收束，把［风］对准中脉之门；封闭三条道路，把风持于内里；使命与风也得到滋润；这样做了，就会向下降；在一刹那间就要收束。以上下风的修法，与平住风一起燃烧；由此使［风］向上运行。具足收束下门，使风收缩并提升。以幻轮与风的修法，展开并极力收束；要修习双运的三道。

【按】"阴门是……的女尊"，藏文作"ཛོ་ནི་བྷ་དྷའི་ལྷ་མོ་ཡིན"，"bha dha"意思不明，存疑。"收束喉咙"（mgrin pa bsdams pa），即后来哈达瑜伽中的"扣喉收束"（jālandhara-bandha）。"充满［气］与瓶［气］"（dgang ba can dang bum pa can），是闭气（kumbhaka）的修法。"三条道路"，指左、右、中三脉或上、中、下三门，存疑。"平住风"（mnyam pa'i rlung，梵 samāna），是五风之一。"幻轮"（'khrul 'khor，梵 yantra），即身体的动作修法，藏传密法中称为"幻轮"或"拙火的身体运动"。这些都是有危险性的身体与呼吸修法，必须在上师亲自指导下修习，这里不作解说。

## 十四、大收束：如以堤坝使水倒流（第 174–191 句）

```
འདི་ལྟར་མི་ཡི་ལུས་ལ་ནི། །
གྲུབ་པའི་ལམ་ནི་རབ་གསལ་བ། །
ཉམས་མྱོང་སྐྱེ་ཞིང་ལུས་རྒྱས་འགྱུར། །
རྒས་པར་ཡང་ནི་མི་འགྱུར་རོ། །
རྩ་རྣམས་རྒྱུན་གྱིས་འབབ་པ་དང་། །
རྟག་པར་འོག་ཏུ་འགྲོ་བ་དེ། །
བསྡམས་པ་ཆེན་པོ་འདི་ཡིས་ནི། །
རྣམ་པར་ལྡོག་པར་འགྱུར་བ་ཡིན། །
གཤིས་ནི་ཐུར་དུ་འགྲོ་བ་ཡིན། །
ཡུར་བའི་ནང་དུ་ཆུ་འབབ་པ། །
དེ་ནི་བསྡམས་པས་ལྡོག་པར་འགྱུར། །
དེ་བཞིན་ནང་གི་ལུས་ལ་ཡང་། །
ལུས་ཀྱི་ཕྱི་རོལ་འགྲོ་བ་དེ། །
རྣལ་འབྱོར་རྟག་ཏུ་ཤེས་པར་བྱ། །
ལུས་ཀྱི་རྩ་ནི་མ་ལུས་པ། །
འདིས་ནི་བསྡམས་པར་རབ་ཏུ་གྲགས། །
བསྡམས་པ་འདི་ཡི་མཐུ་ཡིས་ནི། །
ལྷ་རྣམས་ཀུན་ཀྱང་གསལ་བར་འགྱུར། །
```

这样，在人的身体上，成就之道是非常明显的：会生起觉受，身体会丰盛，也不会衰老。诸脉相续地流下，恒常往下而去，以这大收束，就会使它返转。［明点的］本性是往下流的，就像水在渠道中流下，以堤坝阻挡就会返转；同样，在身体内部，那往身体外面流去的，瑜伽士要恒常了知。身体的一切脉，以这［修法］而被称为"收束"；以这收束的力量，一切天神都会明显。

【按】这一节说明"大收束"的原理：明点的本性是往下流失的，就像渠水往下流，以修法收束，就能像以堤坝阻水一样使它返转向上。这是印度瑜伽"使明点不外泄、向上提升以得长生"的基本观念。

## 十五、四手印封闭三道，开通一道（第 192–212 句）

```
དེ་ལྟར་ཕྱག་རྒྱ་བཞི་ཡིས་ནི། །
ལམ་གསུམ་རྣམ་པར་བཀག་པའོ། །
ལམ་གཅིག་པ་ནི་གསལ་བའོ། །
གྲུབ་པ་ལྷ་ཡི་ལམ་དུ་འགྲོ། །
སྐྱེ་དང་འཆི་བའི་ལམ་གཉིས་པོ། །
འོག་ནི་ལམ་དུ་བཤད་པ་ཡིན། །
བསོད་ནམས་དང་ནི་སྡིག་རྒྱུ་ཡི། །
དེ་ཕྱིར་སྐྱོན་གཉིས་རྣམ་པར་སྤངས། །
རླུང་གི་དེ་ཉིད་བུམ་པ་ཅན། །
དེ་ནི་རབ་ཏུ་མཉམ་པར་བྱ། །
སྟེང་གི་ལམ་དུ་རྣམ་བྱས་ལ། །
རླུང་དང་ལྷན་ཅིག་སྦྱོར་བ་ཡིས། །
བསྡམས་པས་ཆུ་རྒྱུན་འགག་པ་ལྟར། །
འགྲོ་བ་ཐམས་ཅད་རྣམ་པར་འགོག །
དེས་ན་དེ་ཡི་བཀའ་དྲིན་གྱིས། །
ཛོ་ནི་གདམས་པ་ཞེས་གྲགས་སོ། །
གྲུབ་པའི་ལམ་དང་ཡང་དག་ལྡན། །
མི་ནི་འགྱུར་ཏེ་གཞན་དུ་མིན། །
ཕྱག་རྒྱ་འདི་ནི་ཤེས་པ་ཡིས། །
དྲེགས་པ་ཡོད་ཀྱང་དོན་དང་ལྡན། །
དེས་ན་ཐམས་ཅད་ཤེས་པ་ཡིན། །
```

这样，以四种手印，封闭了三条道路，那一条道路就明显了；成就者走向天神之道。生与死的两条道路，下面的被称为［轮回之］道，是福德与罪恶之因；所以舍弃了这两种过失。

风的真性是瓶［气］，要使它极为平等；在上方之道作好之后，以与风的结合，像以收束止住水流一样，止住一切的流动。所以，由于它的恩德，被称为"阴门口诀"。具足成就之道的，［才］成为［真正的］人，而不是别的。由于了知这个手印，即使有骄慢，也具有意义；所以［他］就是了知一切的。

【按】"封闭了三条道路，那一条道路就明显了"，是说封闭左右二脉等，使中脉这一条道路开通，成就者就由中脉而走向"天神之道"（解脱）。"生与死的两条道路"，可能指左右二脉。"阴门口诀"（ཛོ་ནི་གདམས་པ），存疑。"具足成就之道的，［才］成为［真正的］人，而不是别的"，意思不很清楚，存疑。"即使有骄慢，也具有意义"（dregs pa yod kyang don dang ldan），意思不明，存疑。
