本篇要目：一、末那识缘什么：四家主张　二、护法正义：唯缘藏识见分　三、思量为性相　四、四根本烦恼　五、为何只有四种烦恼　六、我见、我慢、我爱为何能同时俱起　七、“及余触等俱”：第一家唯九心所　八、第二家：五随烦恼，共十五　九、第三家：六随烦恼，共十九　十、第四家：十随烦恼，共二十四　十一、护法正义：八随烦恼，共十八

一、末那识缘什么：四家主张

以上已经说完末那识的所依。外人质问：末那识的所缘是什么？论主回答：就是颂中的“缘彼”。“彼”就是前面所说的末那识的所依识，因为圣教说末那识缘取藏识。

关于末那识缘取藏识的哪一部分，论中列出四家。

第一家，依《述记》为难陀论师的主张：末那识缘取藏识的体及藏识相应的心所，依次执为“我”和“我所”。理由是：论中说末那识恒常与我执、我所执相应。末那识缘取藏识的体，执为我；缘取藏识相应的心所，执为我所。诸心所不离识，所以如同“唯识”的“识”包括心所，说末那识缘藏识，也没有违背圣教的过失。

第二家，依《述记》为火辨论师的主张：第一家的说法在道理上不对，因为从来没有地方说末那识缘取触等心所。应当说：末那识只缘取藏识的见分和相分，依次执为“我”和“我所”。相分和见分都以识为体，所以不违背圣教“缘藏识”的说法。

第三家，依《述记》为安慧论师的主张：第二家的说法也不合道理。理由有四：藏识的相分中有五色根和五境，五根五境不属于识蕴，不能说相分以识为体；末那识若缘相分中的五境，就应如同五识，也缘取外境；末那识就应如同意识，缘取与他人共有的境；生在无色界的有情，就应不执我所，因为无色界有情厌离色法，阿赖耶识不变现色法。应当说：末那识只缘取藏识和藏识中的种子，依次执为“我”和“我所”。种子就是藏识的功能，不是实有之物，所以不违背圣教。

二、护法正义：唯缘藏识见分

第四家，即护法论师，认为：前面三家的说法都不合道理。

色等的种子不属于识蕴，不能说末那识缘种子就是缘藏识。论中说种子是实有，因为假法如同无，不能作为因缘。

末那识相应的萨迦耶见，即身见，任运地、同一类别地恒常相续生起，怎能另外执着有“我”和“我所”两种对象？一个心中，不会同时有断见、常见等两种分别对境的执着。也不应说我执和我所执前后交替生起，因为末那识从无始以来，一味地运转。

应知末那识只缘取藏识的见分，不缘其余部分。因为藏识的见分从无始以来同一类别地相续，看起来像是常住、单一，又恒常作为一切法的所依。

末那识只把藏识的见分执为自己内在的我。论中说“我所”，只是顺着语句的气势而说。或者，末那识把藏识的见分执为“我的我”，所以对同一个我见，说了“我”和“我所”两个名称。

【译注】“我的我”，即“属于我的那个我”。末那识的执着只有一个对象，只是一个我见；“我所”二字只是同一执着的另一种说法，并不是另有一个所执的对象。

```
若作是说，善顺教理。
```

大意：依护法之说，就善于随顺道理和圣教。

因为许多地方只说末那识有我见；我执与我所执不同时生起。

在未转依的阶位，末那识只缘取藏识。转依之后，末那识也缘取真如及其余诸法，因为与平等性智相应的末那识证得十种平等性，又了知一切有情胜解的差别，示现种种佛的影像。颂中只是依未转依时而说，所以只说末那识缘取藏识。悟时所缘普遍，迷时所缘局限，道理应当如此；无我智的境界普遍，我执的境界局限。

外人质问：末那识怎能缘取自己的所依？论主回答：如同后念的意识缘取前念的意根，大家都承认，末那识缘取自己的所依藏识，又有什么过失？

三、思量为性相

颂中“思量为性相”，同时显示末那识的自性和行相：末那识以思量为自性，又以思量为行相。由此也兼带解释了所立的名称：能够审察思量，所以称为末那。

在未转依的阶位，末那识恒常审察思量所执的我相；在已转依的阶位，末那识也审察思量无我的相。

四、四根本烦恼

外人质问：末那识与几种心所相应？论主回答：首先，与四种烦恼恒常俱起。颂中的“俱”字，显示相应的意义。

从无始以来，到未转依之前，末那识任运地恒常缘取藏识，与四种根本烦恼相应。四种是什么？就是我痴、我见、我慢、我爱。

我痴，就是无明。对我的相状愚昧，迷于无我的道理，所以称为我痴。

我见，就是我执。对不是我的法，虚妄地计度为我，所以称为我见。

我慢，就是倨傲。依仗所执的我，令心高举，所以称为我慢。

我爱，就是我贪。对所执的我，深深地生起耽着，所以称为我爱。

颂中的“并”字，表示我慢、我爱与我见同时俱起，遮除其余部派所执“见、慢、爱不能相应”的主张。

四种烦恼恒常生起，扰乱污浊内心，令外在的转识恒常成为杂染。有情由于四种烦恼，在生死中轮回，不能出离，所以称为烦恼。

【译注】四种烦恼是一个整体：我痴是根，因为不明白无我，所以把藏识见分看作我，就是我见；有了我，就自恃高举，就是我慢；有了我，就爱着不舍，就是我爱。四者日夜不停地在心底运转，前六识所做的一切，都因此带上“我”的色彩。

五、为何只有四种烦恼

外人质问：根本烦恼有十种，末那识为什么只与四种相应？

论主回答：末那识有我见，所以其余的见不生起，因为一个心中不能有两个慧心所。

外人质问：末那识为什么一定要有我见，而不是其余的见？

论主回答：见取见、戒禁取见和邪见，只由分别而生，只属于见道所断；末那识相应的烦恼只是俱生的，只属于修道所断。我所见和边见依我见而生；末那识相应的见不依我所见和边见生起，恒常在内执着有我，所以一定要有我见。

由于见的作用审察决定，疑就没有生起的余地。由于爱着自我，瞋就不能生起。所以末那识相应的烦恼只有四种。

【译注】十种根本烦恼是贪、瞋、痴、慢、疑、身见、边见、邪见、见取见、戒禁取见。末那识只取其中的痴、身见（我见）、慢、贪（我爱）四种，其余六种都被排除。

六、我见、我慢、我爱为何能同时俱起

外人质问：见、慢、爱三者，怎能同时俱起？论主回答：三者的行相互不违背，同时俱起有什么过失？

外人质问：《瑜伽师地论》说，贪令心下沉，慢令心高举，难道不互相违背？

论主回答：分别起的与俱生的、缘外境的与缘内境的、所欺陵的与所依恃的，粗细有所不同，所以《瑜伽师地论》的论文与此处的论文，意义并不互相违背。

【译注】《瑜伽师地论》所说，是分别起的、缘外境的粗显贪慢：爱一件东西时心向下趋附，欺陵他人时心向上高举，二者相违。末那识中的我爱与我慢，是俱生的、缘内境的微细执着：爱的是我，恃的也是我，同一对象，并不相违。

七、“及余触等俱”：第一家唯九心所

外人质问：末那识的心所只有四种吗？论主回答：不是，因为颂中说“及余触等俱”。

关于“余”字的含义，论中列出五家。

第一家认为：末那识的心所只有九种，即前面的四种烦恼，以及其余的触等五法，即触、作意、受、想、思，因为意识与遍行心所必定相应。前面说触等与异熟识俱起，恐怕人误以为末那识的触等也如同前面一样是无覆，为了显示末那识的触等与异熟识的触等不同，所以颂中加“余”字。“及”字是集合的意思：前四种烦恼与后五种遍行，合起来与末那识恒常相应。

外人质问：末那识为什么没有其余的心所？第一家回答：

欲，希望尚未得到的事物。末那识任运地缘取已经得到的境，没有希望，所以没有欲。

胜解，印可执持尚未决定的境。末那识从无始以来恒常缘取已决定的事物，早已印持过了，所以没有胜解。

念，只记忆曾经熟习的事物。末那识恒常缘取现在所受的境，不需要记忆，所以没有念。

定，只系心专注于一个境界。末那识任运地刹那刹那各别缘取，不专注于一，所以没有定。

慧，就是我见，所以不另外列出慧。

善法是清净的，所以不与末那识俱起。

随烦恼的生起，必定依于烦恼前后分位的差别而建立。末那识恒常与四种烦恼俱起，前后同一类别，分位没有差别，所以末那识没有随烦恼。

恶作，追悔过去所造的业。末那识任运地恒常缘取现前之境，不追悔过去的业，所以没有恶作。

睡眠，必定依于身心沉重昏昧，由外在众缘的力量，有时暂时生起。末那识从无始以来同一类别地在内执着，不借助外缘，所以没有睡眠。

寻和伺，都依外门而运转，或浅或深地推度，或粗或细地发言。末那识只依内门而运转，同一类别地执着我，所以不与寻伺俱起。

八、第二家：五随烦恼，共十五

第二家认为：第一家对“余”字的解释不合道理。颂中已另外说末那识“有覆无记摄”，不需要用“余”字来简别。第一家的说法缺少了与末那识俱起的随烦恼，烦恼必定与随烦恼俱起，所以“余”字显示的是随烦恼。

在主张有随烦恼的诸家中，第二家认为：五种随烦恼普遍与一切染污心相应。理由是：《集论》说，惛沉、掉举、不信、懈怠、放逸，在一切染污品中恒常共同相应；离开无堪任性等五种，染污性就不能成立。烦恼生起时，心既然染污，所以染污心的阶位必定有五种随烦恼。烦恼生起，必定由于无堪任、嚣动、不信、懈怠、放逸。

掉举遍于一切染心，在贪起时最为增盛，所以只说掉举是贪的一分。如同睡眠与恶作遍于三性心，在痴起时最为增盛，所以说是痴的一分。

其余地方说有六种或十种随烦恼遍于一切染心，是依其他意义说“遍”，并不是真的遍于一切染心。依二十种随烦恼中，通于粗细、通于无记与不善、通于障定与障慧的相状显著，说六种。依二十二种随烦恼中，通于粗细与二性，说十种。所以《集论》与其余诸论的说法，并不互相违背。

所以末那识相应的心所共有十五种：前面九种，五种随烦恼，加上别境的慧。我见属于别境的慧，在五十一心所中意义有差别，所以分开为二。

外人质问：末那识为什么没有其余的心所？第二家回答：

忿等十种小随烦恼，行相粗动；末那识审察微细，所以不与忿等俱起。

无惭和无愧只是不善；末那识是无记，所以不与无惭无愧相应。

散乱，令心奔驰流散于外境；末那识恒常在内执着同一类境，不向外奔驰流散，所以没有散乱。

不正知，指起于外门的身、语、意行为违越规则；末那识只在内执着，所以不与不正知俱起。

其余心所没有的理由，如前所说。

九、第三家：六随烦恼，共十九

第三家认为：应当说六种随烦恼普遍与一切染心相应。理由是：《瑜伽师地论》说，不信、懈怠、放逸、忘念、散乱、恶慧，与一切染心都相应。

如果没有忘念、散乱、恶慧，心必定不能生起诸烦恼，因为要缘取曾经领受过的境界种类，发起忘念和邪误的简择，才能生起贪等烦恼。烦恼生起时，心必定流荡，流荡都是由于对境生起散乱。

惛沉与掉举的行相互相违背，并不是一切染心都能普遍生起。论中说五法遍于染心，是从通于粗细、违背唯善之法、纯随烦恼通于二性的角度说的。说十种遍于染心，意义如前所说。

所以末那识相应的心所共有十九种：前面九种，六种随烦恼，加上念、定、慧，再加惛沉。

另外说念，可以依照前面慧的解释：念心所与忘念意义有别，所以分开。有定，是因为末那识专注于同一类所执的我境，从来不舍。加惛沉，是因为末那识相应的无明特别深重，心惛沉。没有掉举，是因为掉举与惛沉相违。其余心所没有的理由，如上所说。

十、第四家：十随烦恼，共二十四

第四家又认为：十种随烦恼普遍与一切染心相应。理由是：《瑜伽师地论》说，放逸、掉举、惛沉、不信、懈怠、邪欲、邪胜解、邪念、散乱、不正知，十种随烦恼在一切染污心生起时都有，通于一切处，系属三界。

如果没有邪欲和邪胜解，心必定不能生起诸烦恼，因为对所领受的境，要乐于相合或相离，印可执持事相，才能生起贪等烦恼。

一切对道理有疑惑的人，对色等事物必定没有犹豫，所以与疑相应的心也有胜解。对所缘的事物也犹豫的，不是烦恼的疑，如同在暗处怀疑前面是人还是树桩。

其余地方不说邪欲和邪胜解遍于染心，是因为缘取非可爱之事的心，以及与疑相应的心，邪欲和邪胜解不粗显。其余诸心所互有互无的意义，如前所说。

所以末那识相应的心所有二十四种：前面九种，十种随烦恼，加上别境五种。可以依照前面的道理解释。其余心所没有的理由，如上所说。

十一、护法正义：八随烦恼，共十八

第五家，即护法论师，认为：前面各家的说法都没有穷尽道理。

先问第四家：怀疑来世有还是没有时，对来世有什么欲和胜解的相状？

烦恼生起时，如果没有惛沉，就不一定有无堪任性。如果没有掉举，就应没有嚣动，就如同善心等，不是染污的阶位。如果染心中没有散乱，就不应流荡，就不是染污心。如果没有失念和不正知，怎能生起烦恼现前？

所以，染污心决定都与八种随烦恼相应而生，就是惛沉、掉举、不信、懈怠、放逸、忘念、散乱、不正知。

以念和慧为体性的忘念和不正知，不遍于一切染心，因为并不是一切染心都缘取曾经领受的境，都有简择。以无明为自性的忘念和不正知，遍于一切染心生起，理由如前所说。

【译注】忘念与不正知各有两种解释：一种以念心所、慧心所的染污一分为体，另一种以无明（痴）的一分为体。护法论师认为，以无明为体的忘念和不正知才遍于一切染心，所以能与末那识俱起。

所以末那识相应的心所共有十八种：前面九种，八种随烦恼，加上别境的慧。其余心所没有的理由，以及论中三处说法的会通，可以依照前面的道理解释。

```
若作是说，不违理教。
```

大意：依护法之说，就不违背道理和圣教。

【译注】五家的心所数目可以并列来看：第一家九种，第二家十五种，第三家十九种，第四家二十四种，护法论师十八种。护法正义的十八种是：四根本烦恼、五遍行、八大随烦恼、别境的慧。

以上卷第四之下译毕，成唯识论卷第四终。
