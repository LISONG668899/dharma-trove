# 龙树《大智度论》卷第三

龙树菩萨造　后秦龟兹国三藏法师鸠摩罗什奉诏译

## 初品中“住王舍城”释论第五

### 一、释“住王舍城”

【经】

住王舍城。

【论】

现在来解说。

#### （一）先说处、时、人，令人生信

问：为什么不直接说般若波罗蜜之法，而要说“佛住王舍城”？

答：说出地方、时间、人物，是为了使人心中生起信心。

#### （二）天住、梵住、圣住、佛住

什么叫“住”？坐、卧、行、住四种身体威仪，这名为住。

又为了使魔军畏怖，使自己的弟子欢喜进入种种禅定，所以佛住在这里。

再者，住有三种：天住、梵住、圣住。

六欲天所安住之法，这是天住。

梵天等乃至非有想非无想天所安住之法，这名为梵住。

诸佛、辟支佛、阿罗汉所安住之法，这名为圣住。

在这三种住法中，佛住于圣住之法；因为怜悯众生，所以住在王舍城。

再者，布施、持戒、善心这三件事，名为天住。

慈、悲、喜、舍四无量心，名为梵住。

空、无相、无作这三三昧，名为圣住。

圣住之法，佛住于其中。

再者，住有四种：天住、梵住、圣住、佛住。

前三种住，如前面所说。

所谓佛住：首楞严等诸佛无量三昧、十力、四无所畏、十八不共法、一切智等种种智慧，以及八万四千法藏度人之门。像这样种种诸佛功德，是佛所住之处，佛住于其中。

“住”的意义，简略地说完了。

#### （三）王舍城得名三说

所谓“王舍城”：

问：如舍婆提、迦毗罗婆、波罗奈等大城，都有诸王的宫舍，为什么唯独称这座城为王舍？

答：有人说：“摩伽陀国王有一个儿子，一个头，两张脸，四条手臂。当时的人认为不吉祥，国王就把孩子的身体与头撕裂，丢弃在旷野中。有个名叫梨罗的罗刹女鬼，把孩子的身体重新合起来，喂奶养育。孩子后来长大成人，力量能够兼并诸国，称王天下，捉来一万八千位诸国国王，安置在这五座山中。这位国王以大力势统治阎浮提，阎浮提的人因此称这座山为王舍城。”

再者，有人说：“摩伽陀王先前所住的城，城中失火，烧了一次就重建一次，这样反复七次。国人疲于劳役，国王非常忧虑恐惧，召集诸位有智慧的人询问缘故。

“有人说：‘应当换个地方。’国王就另外寻找住处。看见这五座山环绕四周如同城墙，就在其中建造宫殿居住，因此名为王舍城。”

再者，在久远的古代，这个国家有一位国王名叫婆薮，心中厌离世间之法，出家作了仙人。

当时，在家的婆罗门与诸位出家仙人一起论议。

在家婆罗门说：“经书上说：‘在祭天时，应当杀生吃肉。’”

诸出家仙人说：“在祭天时不应当杀生吃肉。”双方争论不休。

诸出家婆罗门说：“这里有一位大王出家作了仙人，你们信不信这个人？”

诸在家婆罗门说：“信。”

诸出家仙人说：“我们就以这个人为证，改日去问。”

诸在家婆罗门当天夜里就先到婆薮仙人那里，种种询问之后，对婆薮仙人说：“明天论议，你应当帮我们。”

这样，第二天早上论议时，诸出家仙人问婆薮仙人：“祭天时应当杀生吃肉吗？”

婆薮仙人说：“依婆罗门法，祭天时应当杀生吃肉。”

诸出家仙人说：“在你真实的心里怎么认为？应当杀生吃肉吗？”

婆薮仙人说：“为了祭天，应当杀生吃肉。这些牲畜在祭天中死去，所以能生到天上。”

诸出家仙人说：“你大错了！你说了大妄语！”随即唾弃他说：“罪人，滚开！”这时，婆薮仙人随即陷入地中，没到脚踝。这是因为婆薮仙人最先开启了大罪之门。

诸出家仙人说：“你应当说实话；如果故意说妄语，你的身体就要陷入地中。”

婆薮仙人说：“我知道为了祭天而杀羊、吃肉，没有罪。”随即又陷入地中，没到膝盖。这样渐渐下沉，没到腰，没到脖子。

诸出家仙人说：“你现在说妄语，得到了现世的果报。如果改说实话，即使已经陷入地下，我们也能把你救出来，使你免罪。”

那时，婆薮仙人自己思惟：“我是尊贵之人，不应当说两样的话。况且婆罗门的四围陀法中，以种种因缘赞叹祭天之法，我一个人死了，又有什么值得计较的！”就一心说道：“应当在祭天时杀生、吃肉，没有罪。”

诸出家仙人说：“你这个重罪之人！快走！不想再见到你！”于是婆薮仙人全身没入地中。从那时直到今天，人们常用婆薮仙人之王法，在祭天时杀羊；下刀时就说：“是婆薮杀你。”

婆薮的儿子名叫广车，继位为王；后来也厌离世间之法，却又不能出家。广车王这样思惟：“我的父亲先王出了家，活着陷入地中；我如果治理天下，又会造下大罪，我现在该如何自处？”

正这样思惟时，听到空中有声音说：“你如果在行走时见到难得遇见的稀有之处，你就应当在那里建造房舍居住。”说完这话，就再也听不到声音了。

没过多久，国王出外打猎，看见一只鹿跑得快如疾风，国王就去追赶，却追不上，于是追个不停，百官与侍从没有一个能跟上。往前走去，看见有五座山，环绕四周，险峻坚固；山中地面平坦端正，生着细软的草，美好的花开遍地面，种种林木花果茂盛，温泉与凉池都清净无比。这片土地庄严，处处散有天花、天香，能听到天上的伎乐。

那时，乾闼婆伎乐众刚看见国王到来，就各自返回了。国王心想：“这个地方稀有，从未见过，现在我正应当在这里建造房舍居住。”这样思惟之后，群臣百官循着踪迹也到了。

国王告诉群臣：“我先前听到空中的声音说：‘你行走时如果见到稀有难遇之处，你就应当在那里建造房舍居住。’我现在见到了这个稀有之处，我应当在这里建造房舍居住。”随即舍弃原来的城，住在这山中。这位国王最先住在这里，从此以后，历代国王相继住在这里。这位国王最初在这里建造宫舍，所以名为王舍城。

王舍城的由来，简略地说完了。

### 二、释“耆阇崛山中”

【经】

耆阇崛山中。

【论】

#### （一）鹫头山名义

“耆阇”意为鹫，“崛”意为头。

问：为什么名为鹫头山？

答：这座山的山顶形似鹫鸟，王舍城的人看它像鹫鸟，就互相传说是鹫头山，于是名为鹫头山。

再者，王舍城南面的尸陀林中，有很多死人，鹫鸟常来啄食，吃完回到山头栖息，当时的人就称为鹫头山。

这座山在五座山中最高最大，有很多好的林木与水源，是圣人所住之处。

#### （二）佛何以多住王舍城、舍婆提

问：已经知道耆阇崛山的意义了。佛为什么住在王舍城？

诸佛之法普遍慈爱一切，如同太阳照耀万物，没有不蒙受光明的。

如沤祇尼大城、富楼那跋檀大城、阿蓝车多罗大城、弗迦罗婆多大城，像这些大城，人口众多、富足安乐，佛却不住；为什么多住在王舍城、舍婆提大城？

波罗奈、迦毗罗婆、瞻婆、婆翅多、拘睒鞞、鸠楼城等，佛虽然也有住的时候，却多住在王舍城、舍婆提。怎么知道佛多住在这两处？因为看到佛的诸经多在这两座城中宣说，在其余城中宣说的少。

答：佛虽然以大慈平等普及，然而沤祇尼等诸大城是边地国家，所以佛不住。

又因为那里弥离车等弊恶之人多，善根还没有成熟。如偈中说：

```
如日光等照，　华熟则时开，
若华未应敷，　则亦不强开。
佛亦复如是，　等心而说法，
善根熟则敷，　未熟则不开。
以是故世尊，　住三种人中：
利智善根熟，　结使烦恼薄。
```

大意：如同日光平等照耀，花成熟了就应时开放；如果花还不到开放的时候，日光也不会强使花开。佛也是这样，以平等心说法，善根成熟的就开放，没有成熟的就不开。所以世尊住在三种人之中：智慧锐利的人、善根成熟的人、结使烦恼轻薄的人。

再者，佛因为知恩，所以多住在王舍城、舍婆提城。

问：怎么知道因为知恩，所以多住这两座城？

答：憍萨罗国是佛出生之地。如佛回答频婆娑罗王的偈中说：

```
有好妙国土，　在于雪山边，
丰乐多异宝，　名曰憍萨罗。
日种诸释子，　我在是中生，
心厌老病死，　出家求佛道。
```

大意：在雪山边上有一片美好的国土，丰饶安乐，多有奇珍异宝，名叫憍萨罗。我生在日种的释迦族中，心中厌离老病死，出家寻求佛道。

再者，这憍萨罗国的国主波斯匿王住在舍婆提大城中；佛是法王，也住在这座城中，因为两位君主应当同住一处。

再者，这憍萨罗国是佛的生身之地，佛因为知恩，所以多住在舍婆提。

问：如果因为知恩而多住舍婆提，迦毗罗婆城离佛出生之处更近，为什么不多住？

答：佛的一切结使已尽，不再有残余习气，亲近亲属也不会生起异样的念头；然而释迦族出身的弟子大多还没有离欲，如果亲近亲属，就会生起染着之心。

问：为什么不为舍婆提出身的弟子护念，让舍婆提的弟子避开亲属，却多住在舍婆提？

答：迦毗罗婆出身的弟子多。佛初次回国时，迦叶兄弟所带领的一千比丘，本来修婆罗门法，在山间苦行，形容憔悴。父王净饭王见了，认为这些比丘不足以光耀装饰世尊，就挑选释迦族贵族子弟中体格健壮的少年，每户派一人，强令出家。这些人中有善心乐道的，也有不乐道的。这些释迦族比丘不应当让他们回到本来出生的地方。舍婆提的弟子们不是这样，所以佛多住在舍婆提，不多住在迦毗罗婆。

再者，出家之法，应当不亲近亲属，因为亲属的心会生执着，如同火，如同蛇。在家的婆罗门子弟为了求学，尚且不应当留在出生之地，何况出家的沙门！

再者，舍婆提城大，迦毗罗婆不是这样。舍婆提城有九亿户人家，在这里如果只住很短的时间，就不能度化很多人，所以多住。

再者，迦毗罗婆城是佛出生之处，城中的人已经长久修习，善根成熟，智慧锐利，佛在这里只需短时间住下说法，不必久住，度化完毕就离开了。

舍婆提的人，有的初学修行，有的长久修行；有的善根成熟，有的善根未熟；有的根性锐利，有的根性不利。因为多学种种经书，把心磨得锐利，却陷入种种邪见之网，奉事种种老师，归属种种天神。杂行的人多，所以佛在这里住得久。

如同治疗毒疮的医师，知道疮已经成熟，就把疮挑破，挤出脓来，给了药就离开；如果疮还没有成熟，就要久住，敷药抚慰。佛也是这样：如果弟子善根成熟，教化完毕就转往别处；如果可度的弟子善根还没有成熟，就必须久住。

佛出现于世间，正是为了度化众生，把众生安置在涅槃境界的安稳快乐之处，所以多住在舍婆提，不多住在迦毗罗婆。

佛在摩伽陀国尼连禅河边的沤楼频螺聚落，证得阿耨多罗三藐三菩提，成就了法身，所以多住在王舍城。

#### （三）二城之中何以多住王舍城

问：已经知道多住王舍城、舍婆提的因缘了。在这两座城中，为什么又多住王舍城？

答：为了报答生身之地的恩，所以多住舍婆提，因为一切众生都怀念出生之地。如偈中说：

```
一切论议师，　自爱所知法；
如人念生地，　虽出家犹诤。
```

大意：一切论议师都爱自己所知的法，如同人怀念出生之地，即使出了家还在为此争执。

为了报答法身之地的恩，所以多住王舍城，因为诸佛都爱法身。如偈中说：

```
过去、未来，　现在诸佛，　供养法身，
师敬尊重。
```

大意：过去、未来、现在诸佛，都供养法身，以法身为师，恭敬尊重。

因为法身胜过生身，所以两座城中多住王舍城。

再者，因为王舍城坐禅的精舍多，别处没有这么多。如竹园、鞞婆罗跋恕、萨多般那求呵、因陀世罗求阿、萨簸恕魂直迦钵婆罗。王舍城有五座精舍，竹园在平地上；其他国家没有这么多精舍。

舍婆提有一处，是祇洹精舍；另有一处，是摩伽罗母堂，再没有第三处。

婆罗奈斯国有一处，是鹿林中的精舍，名叫梨师槃陀那。

毗耶离有两处：一名摩呵槃，二名猕猴池岸精舍。

鸠睒弥有一处，名叫劬师罗园。

像这样，诸国或者只有一处精舍，或者只有空旷的树林。

因为王舍城精舍多，适宜坐禅的人，那里又安稳，所以佛多住在这里。

再者，王舍城中有富那罗等六师，自称是一切智人，与佛作对；还有长爪梵志、婆蹉姓梵志、拘迦那大等，都是外道的大论议师；还有长者尸利崛多、提婆达多、阿阇世等，图谋加害佛，不信佛法，各自心怀嫉妒！因为有这些人，佛多住在这里。譬如毒草生长的地方，附近必定有良药。

如偈中说：

```
譬如师子，　百兽之王；　为小虫吼，
为众所笑。　若在虎狼，　猛兽之中，
奋迅大吼，　智人所可。

诸论议师如猛虎，　在此众中无所畏；
大智慧人多见闻，　在此众中最第一。
```

大意：譬如狮子是百兽之王，如果对着小虫吼叫，会被众人嘲笑；如果在虎狼猛兽之中奋迅大吼，才为智者所认可。诸论议师如同猛虎，佛在这些人中无所畏惧；大智慧、多见闻的人，在这些人中是第一。

因为大智慧、多闻的人都在王舍城，所以佛多住在王舍城。

再者，频婆娑罗王到伽耶祭祀之所迎接佛，以及其余束发的一千位阿罗汉。当时佛为国王说法，国王证得须陀洹道，随即请佛说：“愿佛与僧众到我的王舍城，终身接受我所供养的衣被、饮食、卧具、医药，供给一切所需。”佛随即接受邀请，所以多住在王舍城。

再者，阎浮提四方之中，以东方为开始，因为太阳最先从东方升起；其次依次是南方、西方、北方。东方之中，摩伽陀国最殊胜。摩伽陀国中，王舍城最殊胜，城中有十二亿户人家。

佛涅槃后，阿阇世王因为人口渐渐减少，舍弃了王舍大城，在旁边另建一座小城，长宽各一由旬，名叫波罗利弗多罗，仍然是诸城中最大的，何况原来的王舍城！

再者，这里的人大多聪明，都广学多识，其他国家没有这样。

再者，有些应当得道的人，要等待时机、等待处所、等待人。佛预先知道帝释天与八万诸天应当在摩伽陀国的石室中得道，所以佛多住在王舍城。

再者，这个国家丰饶安乐，乞食容易得到，其他国家比不上。又有三种因缘：

一是频婆娑罗王敕令宫中，常备一千位比丘的饭食。

二是树提伽虽然生在人间，却常享受天上的富乐；又有很多富贵的优婆塞。

三是阿波罗逻龙王以善心接受教化，作了佛弟子，为了除去世间的饥荒，常降好雨，所以国家丰饶。

如佛涅槃后，长老摩诃迦叶想结集法藏，思惟：“哪个国家丰饶安乐、乞食容易得到，可以迅速结集法藏？”这样思惟之后，想起王舍城中频婆娑罗王曾敕令常设一千位比丘的饭食。频婆娑罗王虽然已死，这个做法没有中断，在这里饮食容易得到，容易结集法藏，别处没有这样经常性的供养。如果出外乞食，外道就会来一起论议；如果与外道论议，结集法藏的事就会荒废；如果不与外道论议，外道就会说沙门们不如自己。这样思惟之后，挑选最上等的一千位阿罗汉，带到耆阇崛山，结集经藏。

因为这三种因缘，所以知道摩伽陀国乞食容易得到。

如《阿含》与《毗尼》中说，毗耶离国时常有饥荒。如《降难陀婆难陀龙王兄弟经》中说，舍婆提国有饥荒；其余诸国也时常有饥荒，摩伽陀国没有这种事，所以知道摩伽陀国丰饶安乐，乞食容易得到。

再者，王舍城在山中，闲静；其他国家的精舍在平地上，人员杂乱，进出往来容易，所以不闲静。

又这山中精舍多，诸坐禅人与诸圣人都喜好闲静，大多能住在其中；佛是圣人与坐禅人之主，所以多住在王舍城。因为像这样种种因缘，所以佛多住在王舍城。

#### （四）五山之中何以多住耆阇崛山

问：如果住在王舍城，可以理解。为什么不多住竹园，而多住耆阇崛山？

答：我已经回答过了，圣人与坐禅人喜好闲静之处。

问：另外还有四座山，鞞婆罗跋恕等，为什么不多住，而多住耆阇崛山？

答：因为耆阇崛山在五座山中最殊胜。怎样殊胜？耆阇崛山的精舍离城近，而山又难以攀登，所以杂乱的人不来；因为离城近，乞食不会疲劳。因此，佛多在耆阇崛山中，不在别处。

#### （五）大迦叶入山待弥勒

再者，长老摩诃迦叶在耆阇崛山结集三法藏，度化了可度的众生。度化完毕，想要随佛入涅槃；清晨穿衣持钵，进入王舍城乞食之后，登上耆阇崛山，对诸弟子说：“我今天要入无余涅槃。”说完这话，进入房中结跏趺坐，以诸无漏禅定熏修自身。

摩诃迦叶的诸弟子进入王舍城，告诉诸位贵人：“知道吗？尊者摩诃迦叶今天要入无余涅槃。”

诸贵人听了这话，都极为忧愁，说：“佛已经灭度了，摩诃迦叶护持佛法，今天又要入无余涅槃！”诸贵人与诸比丘在申时都聚集到耆阇崛山。

长老摩诃迦叶在申时从禅定中起身，进入大众中坐下，赞说无常：“一切有为法，因为是因缘所生，所以无常；本来没有而现在有，已经有了又归于没有，所以无常。因为因缘所生而无常，因为无常而苦，因为苦而无我；因为无我，有智慧的人不应当执着我与我所；如果执着我与我所，就会得到无量的忧愁苦恼。在一切世间中，心应当厌离，寻求离欲。”

摩诃迦叶这样种种宣说世间之苦，开导众人的心，使众人趣入涅槃。说完这些话，穿上从佛那里得来的僧伽梨，拿着衣钵与锡杖，如同金翅鸟一般显现，上升虚空，示现坐、卧、行、住四种身仪；一身现出无量身，充满东方世界，又从无量身还归为一身；身上出火，身下出水；身上出水，身下出火。南方、西方、北方也是这样。

大众的心都厌离世间，生起欢喜之后，摩诃迦叶在耆阇崛山头，连同衣钵一起，发愿说：“愿我的身体不坏，等到弥勒成佛时，我这骨身再出来，以此因缘度化众生。”这样思惟之后，直接进入山头的岩石之中，如同进入软泥；进去之后，山又合拢了。

后来，人的寿命八万四千岁、身高八十尺时，弥勒佛出世；弥勒佛身高一百六十尺，面部宽二十四尺，圆光十里。那时，众生听说弥勒佛出世，有无量的人随佛出家。

弥勒佛在大众中初次说法时，有九十九亿人证得阿罗汉道，六通具足；第二次大会，有九十六亿人证得阿罗汉道；第三次大会，有九十三亿人证得阿罗汉道。从此以后，度化了无数的人。

那时，人们时间久了渐生懈怠厌倦。弥勒佛见众人这样，就用脚趾叩开耆阇崛山。这时，长老摩诃迦叶的骨身穿着僧伽梨走出来，礼拜弥勒佛的双足，上升虚空，示现神变如同从前，随即在空中灭身而般涅槃。

那时，弥勒佛的诸弟子感到奇怪，问道：“这是什么人？像人却这么小，身穿法衣，能作变化！”弥勒佛说：“这个人是过去释迦文尼佛的弟子，名叫摩诃迦叶，修阿兰若行，少欲知足，修头陀行，在比丘中第一，是证得六神通、共解脱的大阿罗汉。那时人的寿命一百岁，超过的少，不到的多，这个人以这样小的身体，能成办这样的大事。你们身体高大、根性锐利，为什么不作这样的功德？”

这时，诸弟子都惭愧，生起很大的厌离心；弥勒佛随顺大众的心，为大众说种种法。有的人证得阿罗汉、阿那含、斯陀含、须陀洹；有的人种下辟支佛的善根；有的人证得无生法忍，成为不退转菩萨；有的人得以生到天上、人间，享受种种福乐。

因此知道，这耆阇崛山是福德吉祥之处，是诸圣人喜爱居住的地方。佛是诸圣人之主，所以佛多住在耆阇崛山。

#### （六）三世诸佛住处，摩诃衍经多于此说

再者，耆阇崛山是过去、未来、现在诸佛的住处。如《富楼那弥帝隶耶尼子经》中说：“佛告诉富楼那：‘即使三千大千世界经历劫火焚烧又再生成，我也常在这山中住。一切众生被结使缠缚，不作见佛的功德，所以见不到我。’”

再者，耆阇崛山清净鲜洁，接受三世诸佛与诸菩萨居住，再没有这样的地方，所以佛多住在耆阇崛山。

再者，诸摩诃衍经大多在耆阇崛山中宣说，在别处宣说的少。为什么？因为这里清净、有福德、闲静；是一切三世诸佛的住处，十方诸菩萨也赞叹恭敬这个地方；诸天、龙、夜叉、阿修罗、迦楼罗、乾闼婆、甄陀罗、摩睺罗伽等大力众神，都守护、供养、恭敬这个地方。如偈中说：

```
是耆阇崛山，　诸佛所住处，
圣人所止息，　覆荫一切故。
众苦得解脱，　唯有真法存。
```

大意：这耆阇崛山，是诸佛所住之处，是圣人所止息之处，因为能覆荫一切众生。在这里，众苦得到解脱，唯有真实之法长存。

再者，在这里，十方无量具大智慧、大福德、大力量的菩萨，常来拜见释迦牟尼佛，礼拜恭敬，听闻佛法，所以佛宣说诸摩诃衍经，多在耆阇崛山。诸摩诃衍经中，《般若》最大；如今要宣说《般若》，怎能不住在耆阇崛山？

住耆阇崛山的因缘，简略地说完了。

## 共摩诃比丘僧释论第六

### 一、释“共摩诃比丘僧”

【经】

共摩诃比丘僧。

【论】

“共”的意思是：同一处所、同一时间、同一心、同一戒、同一见、同一道、同一解脱，这名为“共”。

“摩诃”，汉语意为大，或者多，或者胜。

怎样是大？在一切大众中最上，一切障碍都已断除，天王等大人都恭敬，这名为大。

怎样是多？数目达到五千，所以名为多。

怎样是胜？能破斥一切九十六种外道的论议，所以名为胜。

#### （一）比丘四义

什么叫“比丘”？

比丘名为乞士，因为以清净的方式维持生命，所以名为乞士。

如经中说：“舍利弗进城乞食，乞到之后，面对墙壁坐着吃饭。

“这时有一位梵志女，名叫净目，来见舍利弗。

“净目问舍利弗：‘沙门，你在吃饭吗？’

“舍利弗回答：‘在吃。’

“净目说：‘你这沙门是下口食吗？’

“舍利弗回答：‘不是，姐妹。’

“‘是仰口食吗？’

“‘不是！’

“‘是方口食吗？’

“‘不是！’

“‘是四维口食吗？’

“‘不是！’

“净目说：‘吃饭的方式有四种，我问你，你都说不是；我不明白，请你解说。’

“舍利弗说：‘有些出家人调制药物、种植谷物、栽种树木等，以不清净的方式维持生命，这名为下口食。

“‘有些出家人观看星宿、日月、风雨、雷电、霹雳，以不清净的方式维持生命，这名为仰口食。

“‘有些出家人曲意谄媚豪强权势，为人四方奔走传信，巧言多求，以不清净的方式维持生命，这名为方口食。

“‘有些出家人学习种种咒术，占卜吉凶，像这样种种以不清净的方式维持生命，这名为四维口食。

“‘姐妹！我不落在这四种不清净的食法中，我以清净的乞食维持生命。’

“这时，净目听了清净的法食之说，欢喜信解。舍利弗趁机为净目说法，净目证得须陀洹道。”

像这样，以清净乞食维持生命，所以名为乞士。

再者，“比”意为破，“丘”意为烦恼；能破除烦恼，所以名为比丘。

再者，出家人名为比丘；譬如胡人、汉人、羌人、虏人，各有各的名称。

再者，受戒时自己说：“我某某比丘，终身持戒。”所以名为比丘。

再者，“比”意为怖，“丘”意为能，能使魔王与魔的眷属畏怖。当一个人出家剃头、穿染色衣、受戒的时候，魔就畏怖。为什么畏怖？魔王说：“这个人必定能入涅槃。”如佛说：“有人能剃头、穿染色衣、一心受戒，这个人就会渐渐断除结使，离苦而入涅槃。”

#### （二）僧伽与四种僧

什么叫“僧伽”？“僧伽”，汉语意为众；许多比丘在一处和合，这名为僧伽。

譬如许多大树丛聚在一起，名为林；单独一棵树不名为林，除去每一棵树也没有林。同样，单独一位比丘不名为僧，除去每一位比丘也没有僧；诸比丘和合，所以“僧”这个名称才生起。

僧有四种：有羞僧、无羞僧、哑羊僧、实僧。

什么叫有羞僧？持戒不犯，身口清净，能分别好坏，还没有得道，这名为有羞僧。

什么叫无羞僧？破戒，身口不净，无恶不作，这名为无羞僧。

什么叫哑羊僧？虽然不破戒，却根性迟钝，没有智慧，不能分别好坏，不知道轻重，不知道有罪无罪；如果僧团有事，两人争执，不能判断决定，只是默然无言。譬如白羊，即使人要杀它，也不能出声，这名为哑羊僧。

什么叫实僧？或者是有学人，或者是无学人，住于四果，行于四向之道，这名为实僧。

这其中，有羞僧与实僧这两种僧，可以一同作百一羯磨、说戒、受岁等种种僧事。

这里所说的大会中，真实的声闻僧有六千五百人。菩萨僧有两种：有羞僧、实僧。因为有实僧，其余的人都可以名为僧。所以名为比丘僧。

### 二、释“大数五千分”

【经】

大数五千分。

【论】

什么叫“大数”？稍多一点或稍少一点，这名为“大数”。

什么叫“分”？从众多大众中取出一部分，这名为“分”。

这些比丘，是从千万大众中取出一部分五千人，所以名为“五千分”。

### 三、释“皆是阿罗汉”

【经】

皆是阿罗汉。

【论】

什么叫“阿罗汉”？

“阿罗”意为贼，“汉”意为破；破除一切烦恼之贼，这名为“阿罗汉”。

再者，阿罗汉一切漏已尽，所以应当得到一切世间诸天与人的供养。

再者，“阿”意为不，“罗汉”意为生；后世不再受生，这名为“阿罗汉”。

### 四、释“诸漏已尽”

【经】

诸漏已尽。

【论】

三界中的三种漏已经断尽，没有剩余，所以说漏尽。

### 五、释“无复烦恼”

【经】

无复烦恼。

【论】

一切结、使、流、受、扼、缚、盖、见、缠等都已断除，所以名为无烦恼。

### 六、释“心得好解脱，慧得好解脱”

【经】

心得好解脱，慧得好解脱。

【论】

问：为什么说“心得好解脱，慧得好解脱”？

#### （一）外道一处解脱，不名好解脱

答：外道中离欲的人，只是在一处、以一种道使心得到解脱，并不是从一切障碍之法中得到解脱。所以，阿罗汉名为“心得好解脱，慧得好解脱”。

再者，诸阿罗汉在见谛道、思惟道这两种道中，心都得到解脱，所以名为“心得好解脱”。有学人的心虽然也得到解脱，却不是好解脱。为什么？因为还有残余的结使。

再者，诸外道等的助道之法不圆满，或者只行一种功德，或者只行两种功德，求道而不能得。比如有人只靠布施求清净；有人祭祀天神，说能脱离忧患衰败，能生在常乐之国；还有人说八种清净道：“一是自觉，二是听闻，三是读经，四是畏惧内在之苦，五是畏惧大众生之苦，六是畏惧天上之苦，七是得遇好师，八是大布施；而只说第八种名为清净道。”

再者，有些外道只以布施、持戒说清净，有些只以布施、禅定说清净，有些只以布施、求智慧说清净。

像这样种种道都不具足，或者没有功德，或者功德很少，就说是清净。这些人即使在一处使心得到解脱，也不名为好解脱，因为涅槃之道不圆满。如偈中说：

```
无功德人不能渡，　生老病死之大海；
少功德人亦不渡，　善行道法佛所说。
```

大意：没有功德的人，不能渡过生老病死的大海；功德少的人，也不能渡过。应当好好修行佛所说的道法。

#### （二）须跋陀梵志最后得度

这里应当说《须跋陀梵志经》：“须跋陀梵志，一百二十岁，得五神通，住在阿那跋达多池边。夜里梦见一切人都失去了眼睛，赤身裸体，站在黑暗中；太阳坠落，大地破裂，大海干涸，大风吹起，把须弥山吹得破碎散落。

“须跋陀醒来后很恐惧，思惟：‘为什么会这样？是我的寿命快要尽了吗？还是天地之主将要坠落？’犹豫不决，不能自己明白，因为做了这样的恶梦。

“须跋陀前世有一位善知识天人，从天上下来，对须跋陀说：‘你不要恐惧！有一位一切智人，名叫佛，今天后半夜将入无余涅槃，所以你做了这个梦，不是为了你自身。’

“这时，须跋陀第二天来到拘夷那竭国，在树林中看见阿难在经行，对阿难说：‘我听说你的老师说新的涅槃之道，今天夜半将取灭度！我心中有疑惑，请求见佛，为我决断疑惑。’

“阿难回答：‘世尊身体极度疲惫，你如果去质难，会劳扰世尊。’须跋陀这样再三请求，阿难的回答都和起初一样。

“佛远远听到了，敕令阿难：‘让须跋陀梵志上前来，随意质难。这是我最后一次与人谈论，须跋陀是我最后得道的弟子。’

“这时，须跋陀得以上前见佛，问讯世尊之后，在一旁坐下，这样想：‘诸外道舍弃恩爱与财宝出家，都不得道，唯独瞿昙沙门得道。’

“这样想完，随即问佛：‘这阎浮提的六师等人，各自声称“我是一切智人”，这话真实吗？’

“那时，世尊以偈回答：

```
我年一十九，　出家学佛道，
我出家已来，　已过五十岁。
净戒禅智慧，　外道无一分，
少分尚无有，　何况一切智？
```

“大意：我十九岁出家学佛道，出家以来已经过了五十年。清净的戒、禅定与智慧，外道连一分也没有；连少分都没有，何况一切智？

“佛又说：‘如果没有八正道，其中就没有第一果、第二果、第三果、第四果；如果有八正道，其中就有第一果、第二果、第三果、第四果。须跋陀！我的法中有八正道，其中有第一道果、第二、第三、第四道果。其余外道之法都是空的，没有道，没有果，没有沙门，没有婆罗门。我就这样在大众中真实地作狮子吼！’

“须跋陀梵志听了这法，证得阿罗汉道，思惟：‘我不应当在佛之后般涅槃。’这样思惟完毕，在佛前结跏趺坐，自己以神通力，身中出火焚烧自身而取灭度。”

所以佛说：“没有功德、功德少的人，助道之法不圆满，都不能得度。”佛说：“因为一切功德具足，所以能度化弟子。”譬如小医师，只用一种药、两种药，药不具足，所以不能治愈重病；大医师们具足各种药物，能治愈一切疾病。

#### （三）爱离得心解脱，无明离得慧解脱

问：如果是离开一切三界烦恼，心才得到解脱，为什么佛说“染爱离，心得解脱”？

答：爱能系缚封闭人心，有很大的力量，所以只说爱，不说其余烦恼。爱断了，其余烦恼也就断了。

再者，如果有人说国王来了，就知道必定有将领随从；染爱也是这样。又如捉住毛巾的一头，其余部分全都跟着起来；爱染也是这样，爱断了，就知道其余烦恼都已断了。

再者，一切结使都分属于爱与见：属于爱的烦恼遮覆心，属于见的烦恼遮覆慧。所以爱离开了，属于爱的结使也离开了，就得到心解脱；无明离开了，属于见的结使也离开了，就得到慧解脱。

再者，这五千阿罗汉是不退法阿罗汉，得到无生智，所以说“心得好解脱，慧得好解脱”，因为不退。退法阿罗汉所得的是时解脱，如劬提迦等，虽然得到解脱，却不是好解脱，因为是退法。

### 七、释“心调柔软”

【经】

心调柔软。

【论】

有人恭敬供养，有人瞋恚、辱骂、殴打，心都平等，没有差别；得到珍宝与得到瓦石，看待都一样；有人拿刀砍截手足，有人用栴檀涂身，也同样平等，没有差别。

再者，淫欲、瞋恚、憍、慢、疑、见的根本都已断除，这叫“心调柔软”。

再者，这些阿罗汉，在会生起贪染之处不贪染，在会生起瞋恚之处不瞋恚，在会生起愚痴之处不愚痴，守护六情，所以名为“心调柔软”。如偈中说：

```
人守护六情，　如好马善调；
如是实智人，　诸天所敬视。
```

大意：人能守护六情，就像好马被善加调伏；这样有真实智慧的人，为诸天所恭敬瞻仰。

其余凡人，不能守护六情，欲、瞋、慢、痴、疑、见都没有断除，所以不调柔，如同恶劣的马。所以诸阿罗汉名为“心调柔软”。

### 八、释“摩诃那伽”

【经】

摩诃那伽。

【论】

“摩诃”意为大，“那”意为不，“伽”意为罪。诸阿罗汉断除了一切烦恼，所以名为不罪。

再者，“那伽”有时指龙，有时指象。这五千阿罗汉在无数阿罗汉中力量最大，所以说如龙、如象。在水中行走的众生中，龙的力量最大；在陆地上行走的众生中，象的力量最大。

再者，如同善于调伏的象王，能攻破大军，一直冲入而不回头，不怕刀杖，不避水火，不逃跑，不后退，死到临头也不躲避。诸阿罗汉也是这样，因为修习禅定与智慧，能攻破魔军与种种结使之贼；被辱骂、殴打，不后悔，不瞋恚；面对老死、水火，不畏惧，不躲避。

再者，如同大龙王从大海中出来，兴起大云，遍覆虚空，放出大电光，照亮天地，降下大雨，润泽万物。诸阿罗汉也是这样，从禅定与智慧的大海中出来，兴起慈悲之云，润泽可度之人，显现大光明与种种变化，宣说真实的法相，以法雨滋润弟子的心，使弟子的心生出善芽。

### 九、释“所作已办”

【经】

所作已办。

【论】

问：什么叫“所作”？什么叫“已办”？

答：得到信、戒、舍、定等诸善法，名为“所作”；得到智慧、精进、解脱等诸善法，名为“已办”。两类法都具足圆满，所以名为“所作已办”。

再者，烦恼有两种：一种属于爱，一种属于见。断除属于爱的烦恼，名为“所作”；断除属于见的烦恼，名为“已办”。

再者，善于照见色法，名为“所作”；善于照见无色法，名为“已办”。可见与不可见、有对与无对等两两相对之法，也是这样。

再者，断除不善法与无记法，名为“所作”；思惟善法，名为“已办”。成就闻慧、思慧，名为“所作”；成就修慧，名为“已办”。种种三法也是这样。

再者，得到暖法、顶法、忍法、世间第一法，名为“所作”；得到苦法忍等诸无漏善根，名为“已办”。

得到见谛道，名为“所作”；得到思惟道，名为“已办”。

成就有学道，名为“所作”；得到无学道，名为“已办”。

得到心解脱，名为“所作”；得到慧解脱，名为“已办”。

诸漏已尽，名为“所作”；得到共解脱，名为“已办”。

除去一切结使，名为“所作”；得到非时解脱，名为“已办”。

自利已经完成，名为“所作”；利益他人，名为“已办”。

像这样“所作已办”的意义，可以自在地解说。

### 十、释“弃担能担”

【经】

弃担能担。

【论】

五众粗重，常常恼害众生，所以名为“担”。如佛所说：“什么是担？五众就是担。”诸阿罗汉已经除去这副担子，所以说“弃担”。

所谓“能担”：佛法中有两种功德之担应当担起：“一是自己得利益，二是他人得利益。”一切诸漏已尽、不悔、解脱等诸功德，这名为自利；能把信、戒、舍、定、慧等诸功德给予他人，这名为利他。这些阿罗汉，自己的担子与他人的担子都能担起，所以名为“能担”。

再者，譬如强壮有力的大牛，能负载重物；这些阿罗汉也是这样，得到无漏的根、力、觉、道，能担起佛法大事之担。所以诸阿罗汉名为“能担”。

### 十一、释“逮得己利”

【经】

逮得己利。

【论】

什么叫己利？什么叫非己利？

修行诸善法，这名为己利；其余非法，这名为非己利。

再者，信、戒、舍、定、慧等诸功德，胜过一切财宝，能使人今世后世常得安乐，能使人到达甘露之城，因为这三种因缘，名为“己利”。如〈信品〉中的偈说：

```
若人得信慧，　是宝最第一；
诸余世财利，　不及是法宝！
```

大意：如果人得到信与慧，这是第一的宝；其余世间的财利，都比不上这法宝！

再者，如果人今世得乐、后世得乐，并得涅槃常乐，这名为己利；其余的都不是己利。如偈中说：

```
世知种种无道法，　与诸禽兽等无异。
当求正智要道法，　得脱老死入涅槃！
```

大意：世人所知的种种无益于道的法，与禽兽没有差别。应当寻求正智与得道的要法，才能脱离老死，进入涅槃！

再者，八正道与沙门果，这名为诸阿罗汉的己利。这五千阿罗汉既得到道，又得到果，两件事都得到了，所以名为己利；所以说“逮得己利”。

### 十二、释“尽诸有结”

【经】

尽诸有结。

【论】

有三种有：欲有、色有、无色有。

什么是欲有？“以欲界所系的业与取为因缘，能生出后世，这也是业的果报，这名为欲有。”

色有、无色有也是这样，这名为“有”。

所谓“结尽”：结有九种，就是爱结、恚结、慢结、痴结、疑结、见结、取结、悭结、嫉结。

这些结使断尽了，有也随之断尽；有断尽了，结使也随之断尽，所以名为“有结尽”。

#### 果中说因

问：诸阿罗汉的结使应当永远断尽了，因为已经离开一切烦恼。有却不应当已经断尽。为什么？因为阿罗汉还没有灭度时，眼根等五众、十二入、十八持这些“有”都还具备。

答：这没有妨碍！这是果中说因，也就是用果的名称来说因。

如佛说：“檀越施食时，给予五件事：寿命、气色、力量、安乐、辩才（“辩”字原文缺损，依诸经所说施食五事补出）。”食物并不一定能给予这五件事，有的人得到大量饮食却死了，有的人只得到少许食物却活了下来。食物是这五件事的因，所以佛说施食能得五事。

如偈中说：

```
断食死无疑，　食者死未定；
以是故佛说，　施食得五事。
```

大意：断绝饮食，必死无疑；吃了饮食，死不死还不一定。所以佛说，施食能得五件事。

又如有人吃了百斤金，“金子是不能吃的”，但金子是食物之因，所以说“吃金子”。佛说“女人是戒的污垢”，女人本身不是戒的污垢，而是戒的污垢之因，所以说“女人是戒的污垢”。又如“人从高处坠落还没有着地，就说这个人死了”，虽然还没有死，因为知道必定会死，所以说“这个人死了”。同样，“诸阿罗汉结使已尽”，知道有必定会断尽，所以说“有结尽”。

【译注】“果中说因”，下文所举诸例，都是把必然到来的结果直接安在因上来说：施食名为“与五事”，坠落未着地名为“死”。阿罗汉结使已断，五众之“有”虽仍现前，必随舍寿而尽，所以经中径称“有结尽”。

### 十三、释“正智已得解脱”

【经】

正智已得解脱。

【论】

#### （一）眼见不能得清净

如摩犍提梵志的弟子，抬着摩犍提的尸体放在床上，抬着走在城市人多的地方，高声宣称：“如果有人亲眼见到摩犍提的尸体，这些人都能得到清净之道，何况礼拜供养的人？”很多人相信了这话。诸比丘听到这话，问佛：“世尊！这件事怎么样？”

佛说偈：

```
小人眼见求清净，　如是无智无实道，
诸结烦恼满心中，　云何眼见得净道？
若有眼见得清净，　何用智慧功德宝？
智慧功德乃为净，　眼见求净无是事。
```

大意：浅陋的人想靠亲眼见到来求清净，这样无智，没有真实之道；种种结使烦恼充满心中，怎能靠眼见得到清净之道？如果眼见就能得到清净，还要智慧与功德之宝做什么？智慧与功德才是清净，靠眼见求清净，没有这回事。

所以说“正智得解脱”。

#### （二）阿罗汉何以常在佛边

问：诸阿罗汉所作已办，不再求进步，为什么常在佛身边，不到别处度化众生？

答：一切十方众生虽然都应当供养佛，阿罗汉所受的恩重，所以应当加倍供养。为什么？这些阿罗汉是从佛那里得以成就，受到无量功德，知道结使已断，信心更加增多，所以诸大德阿罗汉在佛身边享受功德的乐味，供养恭敬，为了报答佛恩，所以住在佛身边。

诸阿罗汉围绕着佛，佛的功德更加尊贵。如同梵天众围绕梵天王，如同三十三天围绕释提桓因，如同诸鬼神围绕毗沙门王，如同诸小王围绕转轮圣王，如同病人病愈后住在大医身边；同样，诸阿罗汉住在佛身边，因为诸阿罗汉围绕供养，佛的功德更加尊贵。

#### （三）所作已办，何以仍听般若

问：如果诸阿罗汉所作已办，已经得到己利，不需要再听法，为什么宣说般若波罗蜜时，有五千阿罗汉在一起？

答：诸阿罗汉虽然所作已办，佛想用甚深的智慧之法来考验诸阿罗汉。如佛问舍利弗，如《波罗延经》阿耆陀所问的偈中说：

```
种种诸学人，　及诸数法人，
是人所行法，　愿为如实说！
```

大意：种种有学之人，以及诸数法之人，这些人所修行的法，愿佛如实宣说！

佛问：“这里所说的，怎样是有学人？怎样是数法人？”那时，舍利弗默然。这样问了三次，舍利弗三次默然。佛提示义理的端绪，告诉舍利弗：“有生吗？”舍利弗回答：“世尊！有生。所谓有生，为了灭除有为的生法而修行，名为有学人；以智慧证得无生之法，名为数法人。”这部经，这里应当广说。

再者，无论是有漏还是无漏的诸禅定，未得的想要得到，已得的想要使之坚固深入，所以诸阿罗汉在佛身边听法。

再者，为了现前的快乐，如《难陀迦经》中说：“为了今世的快乐而听法。”

再者，诸阿罗汉在佛身边听法，心无厌足，如《蜫卢提迦经》中说：“舍利弗对蜫卢提迦说：‘在我的法中，听法没有厌足。’”

再者，如佛大师，尚且一心从弟子那里听法，不应当质难说：阿罗汉所作已办，为什么还要听法？譬如吃饱的人得到好的食物，尚且还要再吃，怎么能说饥渴的人不应当吃！所以，诸阿罗汉虽然所作已办，常在佛身边听法。

再者，佛住在解脱法中，诸阿罗汉也住在解脱法中，所住之法相应，眷属庄严。如《栴檀譬喻经》中说：“有栴檀林，伊兰围绕着栴檀林；有伊兰林，栴檀围绕着伊兰林；有栴檀，就以栴檀为丛林；有伊兰，伊兰就自相围绕。”佛与诸阿罗汉也是这样。佛住在善法解脱中，诸阿罗汉也住在善法解脱中，所住之法相应，眷属庄严。

佛有大众围绕，如同须弥山王有十座宝山围绕，如同白香象王有白香象围绕，如同狮子王有狮子群围绕。佛也是这样，佛是世间无上的福田，与诸弟子围绕共住。

### 十四、释“唯除阿难在学地，得须陀洹”

【经】

唯除阿难在学地，得须陀洹。

【论】

问：为什么说“唯除阿难”？

答：上面所赞叹的诸阿罗汉，阿难不在其中。为什么？因为阿难还在有学之地，还没有离欲。

#### （一）阿难何以未离欲

问：大德阿难是第三师，是大众的法将，种下涅槃的种子已经无量劫，常亲近佛，受持法藏。

大德阿难根性锐利，为什么到现在还没有离欲，还是有学人？

答：大德阿难的本愿是这样：“我要在多闻众中最为第一。”也因为依诸佛之法，阿罗汉所作已办，不应当作供给供养佛的侍者，因为阿罗汉在佛法中能成办大事，烦恼之贼已破，与佛同坐在解脱床上。

再者，长老阿难对种种经典听闻、受持、诵读通利、观察，所以智慧多，摄心少；智慧与摄心两种功德均等的人，才能证得漏尽之道。所以，长老阿难是有学人，是须陀洹。

再者，阿难贪恋供给世尊，所以作佛的侍者，这样想：“如果我早证漏尽之道，就会远离世尊，不能再作侍者。”所以阿难虽然能证阿罗汉道，却自己克制而不取证。

再者，处所、时间、人物还没有会合。什么是处所？能结集法藏的一千位阿罗汉还没有聚集在耆阇崛山，这是处所。世尊还没有到逝去之时，这是时间。长老婆耆子还不在，这是人物。所以长老阿难的漏还没有断尽。必须世尊逝去、结集法藏的大众聚合、婆耆子说法劝谏，这三件事会合，阿难才得到漏尽之道。

再者，大德阿难厌离世间法的心少，不如其他人。这位阿难世世出生于王族，端正无比，福德无量；是世尊的近亲，常侍从佛，必定有这样的念头：“我是佛的近侍，知道法宝之藏，漏尽之道法，我不怕失去。”因为这个缘故，不太殷勤。

#### （二）阿难名字的三种由来

问：大德阿难的名字，是由什么因缘而来？是前世的因缘？是父母所起的名字？还是依某种因缘而立的名字？

答：是前世的因缘，也是父母所起的名字，也是依因缘而立的名字。

问：怎样是前世的因缘？

答：释迦文佛前世作陶师，名叫大光明。那时有佛名叫释迦文，弟子名叫舍利弗、目犍连、阿难。佛与弟子一同到陶师家住了一宿。那时，陶师布施草座、灯明、石蜜浆，以这三样供养佛与比丘僧，随即发愿说：“我在未来老、病、死、恼的五恶之世作佛，名号像现在这位佛一样叫释迦文；我的佛弟子的名字，也像现在这位佛的弟子的名字一样。”因为佛的这个愿，阿难得名为阿难。

再者，阿难世世立愿：“我在释迦文佛的弟子中，愿在多闻众中最为第一，名叫阿难。”

再者，阿难世世修忍辱、除瞋恚，因为这个因缘，一出生就相貌端正。父母因为阿难端正，见到的人都欢喜，所以为阿难取名阿难（阿难，汉语意为欢喜）。

这是前世因缘的名字。

怎样是父母所起的名字？

从前有一位日种王，名叫狮子颊。这位国王有四个儿子：第一名净饭，第二名白饭，第三名斛饭，第四名甘露饭。有一个女儿，名叫甘露味。

净饭王有两个儿子：佛、难陀。

白饭王有两个儿子：跋提、提沙。

斛饭王有两个儿子：提婆达多、阿难。

甘露饭王有两个儿子：摩诃男、阿泥卢豆。

甘露味女有一个儿子，名叫施婆罗。

这其中，悉达陀菩萨渐渐长大，舍弃转轮圣王之位，夜半出家，到了沤楼鞞罗国中尼连禅河边，苦行六年。这时，净饭王因为爱念儿子，常派使者探问消息：“我的儿子得道了吗？还是病了？还是死了？”

使者回来禀告国王：“菩萨只剩皮、骨、筋相连撑着，生命非常微弱！或许今天，或许明天，不会太久了。”国王听了这话，非常忧愁，沉没在忧恼的大海中：“我的儿子既不作转轮王，又不能成佛，多么衰弱痛苦，一无所得就要死了！”国王这样忧恼，心神昏乱闭塞。这时，菩萨舍离苦行之处，吃了百味乳糜，身体充实；在尼连禅河水中洗浴之后，来到菩提树下，坐在金刚座上，自己立誓说：“我不破这结跏趺坐，就要成就一切智；不得一切智，终不起座。”这时，魔王率领十八亿魔众来到菩萨处，胆敢与菩萨决一胜负；菩萨凭借智慧力，大破魔军。魔王打不过，退了回去，心想：“菩萨难以胜过，我去恼乱菩萨的父亲。”于是来到净饭王处，诈称：“你的儿子今天后半夜已经死了。”国王听到这话，惊恐得从床上跌落，如同热沙中的鱼。国王当时悲哭着说偈：

```
阿夷陀虚言，　瑞应亦无验，
得利之吉名，　一切无所获！
```

大意：阿夷陀仙人的预言是虚假的，种种瑞应也没有应验；“成利”这个吉祥的名字，到头来一无所获！

这时，菩提树神非常欢喜，拿着天上的曼陀罗花来到净饭王处，说偈：

```
汝子已得道，　魔众已破散；
光明如日出，　普照十方土！
```

大意：你的儿子已经得道，魔众已经破散；光明如同太阳升起，普照十方国土！

国王说：“先前有天人来说你的儿子已经死了；你现在来说破魔得道；两种说法相互矛盾，该相信谁？”

树神又说：“我实在没有说谎。先前来的天人诈称已经死了，那是魔心怀嫉妒，故意来恼乱你。今天诸天、龙神以花香供养，空中悬挂缯幡；你的儿子身放光明，遍照天地。”国王听了这话，心从一切苦恼中得到解脱。

国王说：“我的儿子虽然舍弃了转轮圣王，如今成了转法轮之王，必定得到大利，没有什么损失。”国王心中非常欢喜。这时，斛饭王家的使者来了，禀告净饭王：“您的弟弟生了个男孩。”国王心中欢喜，说：“今天大吉，是欢喜的日子！”对来使说：“这孩子应当取名为阿难。”

这是父母所起的名字。

怎样是依因缘而立的名字？

阿难端正清净，如同明亮的镜子，老人与少年、美与丑，各种容貌形状，都在阿难身上映现。阿难的身体明净，女人见了，欲心随即就动，所以佛允许阿难穿覆肩衣。这位阿难能使见到的人心与眼都欢喜，所以名为阿难。于是造论者赞叹说：

```
面如净满月，　眼若青莲华；
佛法大海水，　流入阿难心！
能令人心眼，　见者大欢喜；
诸来求见佛，　通现不失宜！
```

大意：面容如同清净的满月，眼睛如同青莲花；佛法大海之水，流入阿难的心中！能使见到的人心与眼都大为欢喜；凡是前来求见佛的人，阿难都通报引见，从不失宜！

像这样，阿难虽然能证得阿罗汉道，为了供给供养佛，自己不断尽诸漏。因为这个大功德，阿难虽然不是无学，却列在无学之数；虽然还没有离欲，却列在离欲之数，所以一同列在五千人之中。因为实际上还不是阿罗汉，所以说“唯除阿难”。

## 初品中四众义释论第七

【经】

复有五百比丘尼、优婆塞、优婆夷，皆见圣谛。

【论】

### 一、何以比丘五千，三众各五百

问：为什么诸比丘有五千人，其余三众各只有五百人？

答：女人大多智慧短浅，烦恼垢重，只求喜乐；因为爱行多，很少能断除结使，得到解脱的证悟。如佛说：“这因缘生起之法，第一甚深，难以证得；一切烦恼断尽、离欲而得涅槃，更加难见。”所以女人不能多得，不如比丘。

优婆塞、优婆夷有家室，所以心不清净，不能断尽诸漏，只能证得四圣谛，作有学人。如偈中说：

```
孔雀虽有色严身，　不如鸿雁能远飞；
白衣虽有富贵力，　不如出家功德胜！
```

大意：孔雀虽然有美丽的羽色装饰身体，却不如鸿雁能远飞；在家白衣虽然有富贵的势力，却不如出家的功德殊胜！

所以，诸比丘尼虽然出家舍弃了世间事业，因为智慧短浅，所以只有五百位阿罗汉比丘尼。在家白衣两众，因为家事繁忙急迫，得道的也各只有五百人。

### 二、何以不别赞三众

问：如五千阿罗汉都受到赞叹，其余三众为什么不赞叹？

答：大众既然已经赞叹了，就知道其余三众也是赞叹的。

再者，如果分别赞叹，外道就会呵斥说：“为什么赞叹比丘尼！”从而生起诽谤；如果赞叹在家白衣，外道就会说：“这是为了得到供养。”所以不赞叹。

### 三、般若大会何以声闻众少

问：其余诸摩诃衍经中，佛与大比丘众在一起，有时八千人，有时六万人、十万人。这部《摩诃般若波罗蜜经》在诸经中第一大。如〈嘱累品〉中说：“其余经典全都忘失，罪过很小；忘失般若波罗蜜一句，罪过很大。”因此知道般若波罗蜜经第一大，在第一大经中应当有第一大的法会。为什么声闻众的人数这么少，只有比丘五千人，比丘尼、优婆塞、优婆夷各五百人？

答：因为这部大经甚深难解，所以声闻众少。譬如国王有真正的宝物，不给凡人看，只给信任喜爱的大人看。如国王谋划议事时，与诸大臣中信任喜爱的智者共同讨论，其余小臣就不得进入。

再者，这六千五百人都已得道，虽然不能完全理解甚深的般若波罗蜜，却都能信受，因为已经得到无漏的四种不坏信。其余经中的声闻众虽然很多，却多半杂乱，不是都已得道。

再者，这里先赞叹的，是从千万阿罗汉中挑选出最殊胜的五千人；比丘尼、优婆塞、优婆夷也是这样。殊胜的人难得，所以不多。

## 本卷要义

本卷看似只是在交代经首的地点与听众，龙树却在这些平实的名相里，层层安放了般若的入口。“住”字先分天住、梵住、圣住，再加上佛住：布施持戒是天住，四无量心是梵住，空、无相、无作三三昧是圣住，首楞严三昧、十力、一切智与八万四千度人之门是佛住。佛的身住王舍城，心住在圣住与佛住之中；一个“住”字，已经把佛所住的空三昧与经文即将宣说的般若连在一起。

佛为什么多住王舍城、舍婆提，答案前后有十几条，归结起来是两种恩：舍婆提是生身之地，王舍城是成道之地、法身之地，“法身于生身胜”，所以两城之中多住王舍城。佛不回迦毗罗婆久住，不是不念亲族，而是佛已无余习，释种弟子却多未离欲；佛在舍婆提久住，是因为那里根性杂、邪见多，如疮未熟，须久住涂慰。住在哪里，从来不是佛自己的偏好，处处都是随众生根熟与未熟而定。最后归到一点：诸摩诃衍经多在耆阇崛山说，般若是摩诃衍中最大，所以必在此山说。迦叶入山待弥勒、佛说“劫烧若更生，我常在此山中住”，都在说明这座山是三世诸佛不断的法座，众生不见，只因结使缠缚。

对五千阿罗汉的一连串赞叹，表面是阿毗昙式的名相铺陈，核心却在“心得好解脱，慧得好解脱”一句。外道离欲，只在一处、以一道解脱，助道法不满；阿罗汉断属爱的烦恼得心解脱，断属见的烦恼得慧解脱，又是不退法，所以称为“好”。须跋陀一段把这一点推到极处：外道“净戒禅智慧，无一分”，有八正道才有四果。听般若的人，先要是这样已经出离的人；然而这些所作已办的阿罗汉仍要常在佛边听法，因为佛要“以甚深智慧法试”。舍利弗面对“学人、数法人”之问三度默然，正预示了后文声闻在般若面前的处境：已得解脱，却未穷甚深。

本卷最动人的人物仍是阿难。阿难具足一切成就阿罗汉的条件，却“自制不取”：本愿要作多闻第一，要作佛的侍者，智多定少，又要等处、时、人三事和合。论主说阿难“虽非无学，在无学数中；虽未离欲，在离欲数中”，供养佛的功德，使一位须陀洹得以列入五千阿罗汉的行列。结尾声闻众只有六千五百人，龙树的解释是般若甚深，如王之真宝只示信爱的大人；人数少，因为个个已得道，具足四不坏信，能信而未必能尽解。般若面前，信是门槛，解还在门内。
