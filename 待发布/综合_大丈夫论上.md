# 大丈夫论（上）

**提婆罗菩萨 造　北凉沙门道泰 译　白话译文**

---

## 施胜品第一

```
敬禮等正覺　大悲哀世尊
因彼起正法　三界中真濟
眾中第一尊　無量功德藏
菩薩本所行　我當說少分
我今哀愍彼　開演妙施門
一切諸賢士　應當歡喜聽
```

大意：论主先礼敬正等正觉、大悲怜愍一切众生的世尊——正是依着世尊，正法才得以兴起，成为三界众生真正的救护。世尊是大众中第一尊贵者，是无量功德的宝藏。菩萨本来所修行的法门浩瀚无边，论主在此只能略说一小部分。为了哀愍众生，愿意为大家开演这微妙的布施法门，一切有德行的贤士，都应当欢喜听闻。

```
菩薩行施時　大地皆震動
巨海湧眾寶　慧雲雨妙花
無心猶如是　況有情識者
菩薩施廣大　猶如虛空界
假使五通僊　充滿十方剎
聽聞猶尚難　況複分別說
```

大意：菩萨行布施的时候，大地都会为之震动，大海涌现出种种珍宝，智慧的云彩降下美妙的花雨。连没有心识的大地、大海尚且会有这样的感应，何况是有情有识的众生呢？菩萨的布施广大无边，就如同虚空一般没有边际。即使有具足五种神通的仙人，遍满十方一切国土，想要听闻菩萨布施的全部境界尚且很难，何况要一一分别演说呢？

```
無有地方所　而不以求施
淨水浸大地　無有不徧處
無有一切物　菩薩所未施
無有一眾生　不曾受施者
```

大意：没有一个地方，是菩萨不曾在那里寻求布施机缘的；就像清净的水浸润大地，没有一处不曾遍及。没有任何一件东西，是菩萨不曾布施过的；也没有任何一个众生，是不曾接受过菩萨布施的。

```
論者語大地　一切應禮汝
何故禮大地　菩薩行施處
菩薩一日施　種種眾雜物
辟支佛百劫　不能知邊際
```

大意：论主对大地说：一切众生都应当礼敬你。为什么要礼敬大地呢？因为大地正是菩萨行布施的处所啊。菩萨一天之中所布施的种种财物，其数量之广，即使辟支佛以百劫的时间去推算，也不能知道它的边际。

```
所以不能知　大悲為施體
能成種智果　施因為最大
此是智者說　施能到彼岸
若一到彼岸　諸度悉具足
波羅蜜義者　名為和集聲
譬如多人處　名之為大眾
```

大意：之所以无法测知，是因为菩萨的布施以大悲心为体，能够成就一切种智的果位，所以布施这个因是最为广大的。这是有智慧的人所说的道理：布施能够到达彼岸；如果一种布施到达了彼岸，其余的一切波罗蜜也就都随之具足了。"波罗蜜"这个词的意思，就是"和合聚集之声"——就好比许多人聚集在一处，就称之为"大众"一样（六度看似各别，实则一度圆满、诸度俱摄）。

```
菩提之種子　能成大智果
一切眾事具　莫不由施成
施是生天道　出世之胞胎
無相施為妙　平等為最勝
```

大意：布施是菩提的种子，能够成就广大智慧的果实；一切美好的事业，没有不是由布施而成就的。布施是往生天界之道，也是出离世间的胞胎（成就出世功德的根本依托）。而其中，不着相的布施最为微妙，心怀平等的布施最为殊胜。

```
身及物皆施　無有所吝惜
一切處皆施　無有方所者
一切時皆施　無有不施時
於此四施中　心智常不動
如是行施者　名不思議施
```

大意：无论是自己的身体还是身外之物，菩萨都能布施，没有丝毫吝惜；无论在什么地方，菩萨都能布施，没有地域的限制；无论在什么时候，菩萨都能布施，没有不布施的时候。在"身、物、处、时"这四种布施之中，菩萨的心智始终如如不动。像这样修行布施的人，才称得上是"不可思议的布施"。

```
若施一眾生　一切盡蒙樂
若不如是施　是名為欺誑
雖名施一人　是為施一切
所以名一切　大悲心普故
大悲所以普　為求種智故
```

大意：如果菩萨布施一个众生，实际上是让一切众生都蒙受安乐；如果不是以这样的心去布施，那就叫做自欺欺人。虽然名义上只是布施给一个人，实际上却是布施给了一切众生——之所以能称为"布施一切"，是因为菩萨的大悲心普遍周遍的缘故；而大悲心之所以能够普遍，正是为了求证一切种智的缘故。

```
施佛及羅漢　世名良福田
不悲平等施　是為最勝施
```

大意：布施给佛陀和阿罗汉，世间人称之为殊胜的福田；但如果不问对方是否为殊胜福田，只凭平等的悲心去布施，这才是最殊胜的布施。

```
無量財寶施　不如暫止息
悲心施一人　功德如大地
為己施一切　得報如芥子
救一厄難人　勝餘一切施
```

大意：布施无量的财宝珍玩，还比不上片刻停下来，以悲心布施给一个真正需要的人——这样的功德犹如大地一般深厚广大。反过来，如果是为了自己的名利而布施给一切人，所得的果报却只如芥子一般微小。救济一个正处在厄难中的人，胜过其余种种布施。

```
眾星雖有光　不如一月明
眾生垢心重　所施恆為己
菩薩悲心施　如灰去眾穢
救濟慈悲施　普為群生類
```

大意：众星虽然都有光明，却终究比不上一轮明月；一般众生心中垢染深重，所行的布施，往往还是为了自己。而菩萨以悲心行布施，就像草木灰能够去除种种污秽一样，能够涤除众生心中的垢染；菩萨救济众生的慈悲布施，是普遍利益一切众生的。

```
如是慈悲施　功德無窮盡
如此微妙施　安樂諸眾生
貪求佛智慧　心無有厭足
如是悲心施　能除無明障
開導愚冥者　使得智慧眼
能滅諸結使　消伏老病死
施與悲心俱　眾生之甘露
```

大意：像这样出于慈悲的布施，功德是无穷无尽的；像这样微妙的布施，能够使一切众生得到安乐。菩萨一心贪求佛陀的智慧，永远没有满足的时候；正是这样的悲心布施，能够破除无明的障蔽，开导愚昧昏暗的众生，使他们得到智慧的眼目，能够灭除种种烦恼结使，消除、降伏老、病、死的痛苦。布施与悲心结合在一起，就是能救度众生的甘露。

## 施胜味品第二

```
大悲所起施　意願成菩提
如是知見人　能成一切施
如是一切施　終成一味智
大悲心為體　能起種種施
種種救眾生　得到於智處
能除諸愛結　及以無明垢
能令一切眾　悉皆得安樂
如是悲心施　誰不生愛樂
```

大意：从大悲心中生起的布施，心中所愿求的是成就菩提。能这样知见的人，才能真正成就一切布施；这样的一切布施，最终都会归入唯一的一味智慧之中。以大悲心为体，能够生起种种形式的布施；用种种方式救度众生，最终能到达智慧的境地，能够除去种种爱染的结缚以及无明的垢染，能使一切众生都获得安乐。像这样以悲心所行的布施，还有谁不会心生爱乐呢？

```
大悲心所起　功德之施利
不能生愛樂　背離於救濟
是人為愛系　菩提甚難得
```

大意：而如果对于大悲心所生起的、有功德利益的布施，反而不能生起爱乐之心，背离了救济众生的本怀——这样的人，是被爱染所系缚的，想要求得菩提，就非常困难了。

```
諸欲求佛者　愛樂施甘味
智人喜惠施　甘樂菩提味
深見三有過　涅槃味甚樂
速疾欲遠離　一念頃不住
又見於施樂　復過於涅槃
愛樂施自在　心則忘菩提
心既忘菩提　謂菩提難得
```

大意：一切想要求得佛果的人，都会爱乐于布施这甘美的滋味。有智慧的人，喜欢广行布施，甘心乐意地品味菩提之味。他们深深地照见三有（欲界、色界、无色界）的种种过患，因而觉得涅槃之味极为快乐，一念之间都不愿再停留于三有之中，急切地想要迅速远离。可是，如果又发现布施本身的快乐，竟然超过了涅槃的快乐，因而贪爱、耽乐于布施的自在境界，心中就会忘失了菩提的追求——心一旦忘失了菩提，就会觉得菩提是很难求得的了（这是提醒行者：布施之乐固然殊胜，若耽着其乐而忘失菩提本愿，反成障碍）。

```
自觀樂施心　由悲眾生故
不覺施味樂　施有三樂味
```

一者求報施味。二者求解脫施味。三者求大悲心施味。此三種味者名增長樂味施。

大意：真正应当自我观照的是：乐于布施的心，究竟是由于悲愍众生而生起的呢，还是不知不觉贪着于布施本身的滋味呢？布施的滋味，共有三种：第一种是为了求得回报的布施之味，第二种是为了求得自身解脱的布施之味，第三种是为了成就大悲心的布施之味。这三种滋味，都可以称为"能增长安乐滋味的布施"，而其中以大悲心为根本的布施之味，才是最为究竟的。

## 施主体品第三

受者得无量珍宝，心中大为欢喜；而施者只是行了少许布施，心中的欢喜，却要超过受者百千万倍——能够这样布施的人，才是第一等的修行。

```
成就救濟者　飲大悲甘露
菩薩行此行　永除慳病老
```

大意：能够真正成就救济众生这件事的人，正是在饮用大悲的甘露；菩萨修行这样的布施之行，便能永远除去吝啬这种如同疾病、衰老一般的心垢。

菩萨以悲心为体，世间众生却是以烦恼结使为体，众生所受用的，纯粹只是种种苦受的一味而已；菩萨为了让众生得到安乐，才修行悲心布施。就像太阳以照明为作用、月亮以清凉为体性一样，菩萨是以悲心为体，用智慧和财物的布施，使一切众生得到安乐。又如同人从初入胎（歌罗逻位）一直到年老，虽然经历十个阶段的差别变化，但即使到了年老，也不曾舍弃婴儿时期就具有的那个身相；菩萨渴望布施救济众生的心，也是这样，即使证得再高的果位，也不曾舍弃对凡夫众生的悲悯——就像修行者远离欲界的贪爱、一直证到非想非非想处定，仍然不曾脱离"凡夫"这个身份的本相一样，菩萨不舍弃布施之心、救济众生，道理也是相同的。

想要止息布施的渴望，就应当饮用大布施之水；然而布施的渴望暂时止息了，其余的渴望却仍未止息——这是因为菩萨爱乐布施的缘故。一切众生依靠饮食才能生存，菩萨的大悲心也是这样，是依靠布施而"存活"的；菩萨的法身，并不是依靠饮食才能存续的，而是以大悲为食粮，菩萨的法身才得以存续。

悲心如同火一般炽盛，想要布施的渴求如同饥饿一般迫切；给予好的食物，菩萨乐于享用而没有厌足。悲心如同大海，布施如同焦渴之地（沃焦），救济之心如水，如同焦渴之地能够吞纳无尽的流水一样——菩萨渴望趣向菩提，以一切众生为伴侣，以悲心为体，行布施永无厌足，就像大海能够吞纳众多河流、永无止息一样。

```
一切眾生來　各各索異物
菩薩皆施與　心無有疲惓
諸苦惱眾生　盡皆為除滅
設有未除者　心無有厭足
```

大意：一切众生前来，各自索求不同的东西，菩萨都能一一施与，心中没有丝毫的疲倦厌倦。凡是受苦受恼的众生，菩萨都想要将他们的痛苦一一除灭；假使还有没能除灭的，菩萨的心也绝不会因此而生起厌足懈怠。

## 施主乞者增长品第四

有大悲心的人，能够安处于生死之中，以种种布施来灭除众生的痛苦。如果能够这样善巧地安住于生死轮回之中——

```
福德善丈夫　悲心施惠手
拔貧窮淤泥　不能自出者
```

大意：这样具足福德的善丈夫，以悲心作为布施的双手，能够拔济那些深陷贫穷淤泥、自己无法脱身的众生。

菩萨以悲心为体，能够修行广大的布施，灭除众生的痛苦，就好像盛夏酷热之时，兴起大云降下大雨一样——菩萨兴起大悲之云，降下布施的冰雹，摧破众生的贫穷，就像摧毁高山巨石一般；救拔贫穷的人，没有限量地布施，使那些贫穷的人永远远离贫苦。以大布施之雨普遍利益一切，使得众生的贫穷永无立足之处。菩萨为了救度众生而修行布施的时候，魔王及其眷属都会心生嫉妒、忧愁苦恼；菩萨修行无量的财施、法施之时，那些悭贪嫉妒的众生也都会惊恐哀号，无不心怀愁怖。

```
慈心端嚴身　悲心為千眼
施為金剛杵　菩薩如帝釋
悉皆能摧壞　貧窮阿修羅
菩薩悲心弓　種種施為箭
破貧窮怨賊　永無有住處
悲心堅固根　愛語以為莖
忍辱為枝條　佈施以為果
求者為鳥鹿　乞者如大風
能吹施果落　貧者得滿足
菩薩出時夜　慈心如滿月
淨施以為光　求如拘牟頭
以淨施光明　令彼得開敷
```

大意：慈心是菩萨端严的身相，悲心是菩萨的千只慧眼，布施是菩萨手中的金刚杵——菩萨就如同帝释天一般，能够彻底摧破"贫穷"这个阿修罗。菩萨的悲心是弓，种种布施是箭，能够破除贫穷这个怨敌盗贼，使它永远无处安身。悲心是这棵树坚固的根，爱语是它的茎干，忍辱是它的枝条，布施则是它所结的果实——前来求索的众生如同飞鸟走鹿，前来乞求的人如同一阵大风，能够吹落布施这棵树上的果实，使贫穷的人得到满足。菩萨出现于世间黑暗之时，就如同一轮满月，慈心是那月亮，清净的布施是它的光明，前来祈求的众生就如同拘牟头花（睡莲一类），因这清净布施的光明照耀，而得以开敷绽放。

乞求的人一旦得到满足，心生欢喜悦乐，转而又将所得辗转布施给别人，这也如同菩萨一般；布施与乞求的人彼此辗转相闻，这个消息也像菩萨的美名一样传扬开来。菩萨行布施的美名，一旦传扬到各处，所有贫穷的人都会前来归投依附，就好像旷野中的一棵大树，行路的人在酷热之时都会前往那里寻求荫凉一样。菩萨爱乐美名、殊胜的解脱，为什么呢？因为能够使前来乞求的人，让菩萨自己因此得到布施的福德；正因为有这样的布施之福，才称之为得到了殊胜之处——一切众生都前来归附聚集，像这样的大士，实在应当受到一切众生的礼敬。

菩萨心中一旦生起欢喜，就会觉得身体轻安，凭着这样的征相，就知道必定有人前来乞求了。如果有人来告诉菩萨说："有乞求的人来了"，菩萨便心生欢喜，立刻拿出财物赏赐给报信的人；菩萨随即又拿出别的财物给予前来乞求的人。看见乞求者前来，心生欢喜、爱重恭敬；乞求者开口说"乞求"这两个字的时候，菩萨怀着怜愍之心听着这句话。如果有乞求者还不了解菩萨天性乐于布施，菩萨就会握着他的手，欢喜地与他交谈，就像老朋友一样，破除他心中的隔阂、消除疑虑，使他生起亲近了知之相。那位乞求者得到财物之后心生欢喜，旁边看见的人也一同欢喜，都愿这位救济者能够长久住世——这才是乞求者真正的依怙救济啊。

菩萨见到乞求者前来的时候，身心都感到欢喜，脸上的神情犹如满月一般，使那乞求者也心生欢喜悦乐，如同用甘露涂抹在心上一般。菩萨和颜悦色，用慈悲的目光注视对方，就好像在饮用甘露一样。譬如有人偷盗了别人的东西拿到市集上去卖，如果很快就卖出去了，心中会大为欢喜；菩萨得到布施给乞求者财物的机会时，心中的欢喜要远远超过这样的情形。又譬如巨富之人拥有极多的财宝，家有千子，对子女随心所欲、恣意布施，心中充满爱念欢喜——这样的欢喜，也比不上菩萨见到乞求者时心中的大欢喜。

菩萨见到乞求者的时候，心中的欢喜，胜过一般人见到自己所亲爱之人的欢喜。如果看见对方获得许多财宝，随心恣意而生起自负骄傲之心，菩萨见了，反而加倍地生起欢喜。如果听见乞求者开口说话的时候，菩萨渴望布施的心情最为深重，耳中听到"乞求"这句话，就像饮用甘露一样。听到乞求的话，心中生起珍爱重视之情，没有什么能够破坏这份心意；但如果听到"已经足够了"这样的话，反而会破坏这份珍爱布施的心意。菩萨对于乞求者，常常心生爱念，如果听到他们说"够了"的脚步声（意为满足离去的动静），反而会破坏这份布施的美味。

菩萨观察眼前接受布施的这块福田，会想："是不是也有和我相同心意的人呢？"于是见到了贪爱之心——众生原来与我是同类的：为什么呢？因为他们贪求之心没有满足的时候，我布施之心也同样没有厌足的时候。那贪求之人，喜爱布施的大施主；菩萨见到许多前来乞求的人，也同样深深生起爱敬之心。贪求的人常常寻求施主，想要布施的人也常常寻求乞求者、想要给予他们所需要的东西。菩萨常常与世间人相反：世间人是乞求者向施与者求索，而菩萨却是主动向乞求者布施。

乞求的人一旦听说施主的财物匮乏用尽，就会生起大苦恼；菩萨如果寻求乞求者而不可得的时候，心中所生起的忧恼，要超过前者百千万倍。对于求索的人，菩萨这样思惟：佛陀说过，"求不得苦"确实就是这样的啊。菩萨对于前来乞求的人，生起"难得值遇"的想法——为什么呢？因为如果没有乞求的人，布施波罗蜜就不能圆满，无上菩提也就不可能证得。所以，菩萨对于乞求的人，会深深生起悲悯忧恼之情。如果有乞求的人前来，无上菩提便如同已经掌握在手中一样并不困难。菩萨听到乞求者说"给我吧，给我吧"，心中便生起欢喜，觉得这正是在把无上菩提送到自己手中。

世间愚痴的众生，如果听到别人向自己乞讨财物，往往会心生轻慢，不会生起爱敬之心；菩萨却这样想："之所以称为'乞求者'，大多是因为世间愚痴众生心怀悭吝，才给他们起了这样一个不好听的名字。其实这样的人，才真正可以称为'施主'啊——虽然自己拥有财物，却没有布施之心；纵然想要布施，又没有前来受施的人。如果这三件事都齐备了，那才是真正大有福德的人。"

就好比有个穷人得到了一大笔宝藏，心中反而生起恐惧，害怕国王、盗贼、水灾、火灾前来侵夺；这时遇到了亲友，对他说："我现在为你想种种办法，使这笔财宝不会失落"，穷人便心生大欢喜——菩萨得到乞求者，把他当作自己的好伴侣，心中的大欢喜也正是这样的。菩萨的悲心遍及一切处所，对那些乞求的人，更是特别生起怜愍之心。菩萨的悲心，一见到乞求的人便和颜悦色，使那乞求者生起"必定能够得到"的信心。乞求者看到菩萨神色和悦的时候，便立刻生起了必定能够得到的确信。

菩萨见到乞求者的时候，会说："你来了，想要什么尽管随意取用。"又安慰他说："善哉，你来得正好，贤者不要心生恐惧，我会成为你的依靠之处。"就这样用种种话语安慰乞求的人，常常用慈爱的言语，使那乞求者的心得到清凉，种种财宝随他心意而给予。乞求的人内心贪求的火焰炽盛燃烧，菩萨常常用布施的乳汁，去熄灭这贪求的烈火。

如果能够这样种种布施的人，才称得上是"活人"；如果不能这样，就叫做"死人"。接受布施的人得到了大量的财物，旁人见了也会欢喜赞叹；菩萨在这样的时刻，菩提之果，就如同已经握在手掌之中一样。悲心清净，布施才清净；如果没有悲心，布施就不能算是清净的。菩萨这样想："善于调伏、随顺自心的人，会恭敬悲心，因为悲心最能使布施变得清净。"菩萨见到贫穷困苦的人，悲心格外深重；众生中极度贫穷的人，一旦得到菩萨的布施，便顿时成为大富之人——就好比有人得到如意宝珠，想要什么都能得到，那些贫穷的人一旦遇到菩萨，一切贫苦都能得到消除。

菩萨行布施，是先布施财物，再舍弃自己的亲人，然后舍弃手足，最后舍弃身命——就这样依次逐渐地布施舍离。菩萨前往乞求者所在之处，给予他财宝；如果乞求者呼唤自己的亲人一同前来，菩萨也一并给予他们；如果乞求者亲自现身求索手足，菩萨便布施手足；如果乞求者开口求索身命，菩萨便舍弃身命。如果乞求者不曾前来，菩萨也会主动前往施与。有前来求索的人，尚且甘愿舍弃身命，何况是财物，又怎会不布施给予呢？

菩萨成就悲心，对众生就如同对待从未离开过的自己的身体一样。见到前来求索的人，会在自己的身体上，生起对方(他人)的想法——菩萨心中反而生起烦恼热恼："我这样愚痴，怎么会在自己的身体上生起'他人'的想法呢？"于是对乞求者说："这一切财物，本来早就都给了你，都是你的东西，你现在只管拿去，为什么还要说'乞求'呢？"求索的人便问："什么时候给过我呢？"菩萨回答说："我早先在三界至尊之前发下宏大的誓愿，那时就已经给了你，你现在为什么反倒还要向我乞求呢？"

菩萨发心愿一切众生对于自己的财物，都生起"这本来就是我自己的东西"这样的想法——就好比辛头河边，飞禽走兽前来，随意就着河水饮用，没有人会去遮拦守护一样。至于给与不给，菩萨早已在心中舍离了这个分别，不会再去说"给"这个字，也不会因此生起欢喜之心——为什么呢？因为早已给出去了。以这样"一切都已舍出"的心，使一切众生都能够得到快乐。菩萨对于一切众生，就如同差遣供人使唤的仆役一样（甘愿听凭众生需求）；而一切众生，才是真正的"施主"。那些贫穷的人心得满足的时候，菩萨的布施波罗蜜也就在那时得到圆满；布施波罗蜜圆满的时候，也就知道自己的功德已经圆满了。

心怀悭贪的人，看见乞求者前来时会转过身去、避开对方的目光；修行功德的人，看见乞求者前来时却是欢喜地注视、亲近对方，乞求者便由此得到布施。菩萨行布施的时候，看见受施的人又转而将所得辗转布施给别人，便心生欢喜；一切众生都赞叹欢喜，菩萨听到这样的赞叹，心中大为欢悦，这份快乐胜过证得解脱之乐。

菩萨以悲心行布施的时候，见到一切众生大多得到财宝、丰足快乐，众生们得到快乐之后，便发愿说："我愿长久处于生死之中修行种种功德，不求速证解脱。"菩萨见到众生能够这样发愿长久处于生死之中修行，心中大为欢喜，想："我现在便已经得到了现前的果报；纵然还没有证得菩提，这也已经算是圆满具足了。"

## 胜解脱品第五

菩萨这样思惟："我平素所爱乐、所追求的殊胜解脱，如今来觉悟我了。"那前来乞求的人，其实并不是为了财宝而来，而是为了成就我的大事因缘而来的啊。菩萨有时示现为人间的国王，正在修行种种功德，这时有人来禀告国王："有乞求的人来了。"国王便这样想："这个所谓的'乞求者'，其实正是殊胜的解脱前来了，我如今得到他了。"国王又这样想："我如今并不贪恋执著于王位，只是为了利益一切众生，才不应当空占着王位，应当修行布施之果，使它圆满——而那位使者，正是来觉悟我的人啊。"

凡是身为乞求者，往往都难以启齿，心怀惭愧羞耻，脸色也会有所变化。菩萨立即体察他的心意，安慰他说："如果有什么需要，尽管随意求取。"乞求者得到财物之后，心中大为欢喜。布施的人和受施的人，两方都感到欢喜，就如同证得涅槃之乐一样。三有生死如烈火般炽然燃烧，充满巨大的痛苦，菩萨身处其中，却如同处在涅槃之乐当中一样——为什么呢？因为菩萨是为了救济众生而处于其中的。

菩萨这样想："悲愍众生，正是我的解脱。以广大的布施惠泽救济众生，众生得到快乐，正是我的解脱。虽然行了广大的布施，如果没有悲心，就不能称为真正的布施；如果有悲心，那么布施本身，就是解脱。"菩萨这样思惟："我从前在三界至尊之前，听闻解脱是极大的快乐，我如今已经证得了——为什么呢？因为随顺自己的心愿去布施，本身就是解脱。如果阿罗汉的解脱之乐，与由悲心所生起的布施之乐相似，我便会爱乐阿罗汉的解脱；如果不相似，我便不会爱乐它。我只爱乐布施之乐，把它当作是我的解脱。"

由悲心而生起布施所得到的快乐，是没有什么可以比拟的；没有悲心的布施所得的解脱之乐，即使是它的百千万分之一，也比不上前者。由悲心所生起的布施所得到的欢喜快乐，如果一定要找一个譬喻来形容，那也是最为广大的譬喻——正因为如此，才说它是无可比拟的。

## 施主增长品第六

由悲心生起的布施，能够给予众生快乐的聚集；像这样能给予众生快乐的施主，胜过单纯求解脱的人，堪称最为殊胜。施主能够成就他人的快乐，是因为修习悲心的缘故——对一切众生都能生起平等的心，这样的人，才称得上是真正的"檀越"（施主）；不能这样布施的人，只能算是"乞求者"（虽有财而心贫，反倒成了向众生乞求福德的人）。

如果行布施的时候，能使听闻的人为之悲泣感动，这才叫做善巧的布施；如果不能这样，就算不上是善巧的施主。如果行布施能够使受施者的子孙都能随意受用、心生欢喜赞叹，这才称得上是健全有力的施主；如果是别人开口乞求才给予，还算不上是真正的施主，能够主动前往给予的，才是善巧的施主。如果舍弃一切财物却还带着贪爱执著之心去给予，也算不上是施主；反过来，有悲心的人，即使暂时没有财物可以给予，也仍然称得上是大施主。

对于一切前来求索的人，都能使他们随心所欲；能够满足对方本来的心愿，这才是善巧的施主；不能满足对方原本的心愿，即使拥有巨大的财富，也只能算是精神上的"贫穷者"。富有的人，如果给予了却没有悲悯之心，只能称为"给予"而不能称为"施主"；有悲悯之心的布施，才真正称得上是施主。如果不曾亲自品尝布施的滋味，就没有真正的果报；有所施与却没有悲心，虽然施与了，也算不上是真正的布施；没有悲心的布施，即使给予了，也不能叫做布施；而有悲心的人，即使一时没有给予，也可以称之为布施。

如果是为了求得回报而布施的人，只能称为"施与者"，就连商人做买卖也可以叫做"施与"；如果是为了求得回报的布施，其果报尚且是无量的，何况是有悲心而不求回报的布施，它的果报又怎么能够计算呢？如果是为求回报而布施，只能求得自己的快乐，不能真正救济他人，只是徒然使自己疲劳罢了；有悲心的布施，才真正能够有所救济，将来得到果报的时候，也能带来广大的利益。

贫穷的人不如拥有财富的人，拥有财富的人不如能够自己受用财富的人，能够自己受用财富的人，又不如能够布施的人；而有悲心去布施的人，能够善巧地利益一切众生。富有的人应当布施，布施的人应当心怀悲悯——富有的人能够布施，财富才能坚固牢靠；布施的人能够怀有悲心，布施才能坚固牢靠。修行布施能够得到富足，修行禅定能够得到解脱，修行悲心却能够得到无上菩提——在这些果报之中，悲心所得的果报最为殊胜。

## 恭敬乞者品第七

菩萨这样思惟："正是因为有乞求者的存在，我才能够证得菩提；我应当将这份菩提回向给一切众生，来报答他们的恩德。我如今正是因为布施众生，才得到了无比的快乐；正因为有这样的快乐，我才能够成就菩提。像这样的菩提，我也应当布施给前来乞求的人。我如今因为布施乞求者，得到了超过解脱之乐的快乐——单单是布施这个'因'，尚且能带来这样的快乐，何况是无上菩提这个'果'呢？我应当把它也一并舍出，布施给一切乞求的人。像这样的乞求者，他们的恩德极为深重，实在无从报答；正是这样的乞求者，才能成为我获得广大快乐的因缘。如果单凭财宝还不足以报答这份恩德，我就应当把将来所证得的无上菩提，也一并布施给他们。凭着我这样的福德，愿使这些乞求者，在未来世也能像我今天一样，成为广大的施主。"

菩萨在心中这样思惟：正是因为有乞求者，我才能得到布施的快乐；也愿使乞求者能够证得无上菩提，成为"以法布施"的施主。那些前来乞求的人，看见菩萨广大布施，便这样问他："您是为了求得什么，才这样平等地行广大布施呢？"菩萨一一回答说："我如今并不是为了求得人天的果报，也不是为了求得声闻的涅槃，只愿求得无上菩提，来拔济救度一切众生。"

那些悭贪的人便心生疑惑："菩萨为什么能够这样行广大的布施，心中却毫无疲倦厌烦呢？"菩萨回答说："我的老师是三界至尊，怜悯忧念一切众生；我如今无以报答老师的恩德，所以布施起来毫无疲倦厌烦。一切的快乐之中，没有比解脱之乐更殊胜的了，可是我爱众生，胜过爱解脱本身。正是因为我爱念众生、想要使他们得到解脱，所以才修行种种布施。假如生死轮回不是极端痛苦的，我行布施便终究不会去求菩提；正因为生死轮回充满痛苦，我才因布施而求取菩提。能够拔除生死痛苦的，究竟是谁的作为呢？是烦恼借着业力所造作出来的（生死之苦是烦恼业力所感，须以菩提之道方能拔除）。愿使一切众生，都能以悲心为体，常常乐于布施惠施。"

## 施悭品第八

不感念他人恩德的人，是没有悲心的；如果没有悲心，就不能真正行布施；如果不能行布施，就不能救度众生出离生死。没有悲心的人，也就不会再有真正的亲友；有悲心的人，才能够拥有真正的亲友。执著于"我"的人，是以爱染为体的；能够救济他人的人，是以悲心为体的。心中怀有深重的爱染，却没有人能够真正了知；心中怀有深重的悲心，同样也没有人能够真正了知——若不能行布施，悲心就会被遮蔽覆盖，就好比在石头上作画，才能分辨出真伪一样：如果见到受苦受难的人，能够行广大的布施，就可以知道这个人是真正有悲心的。

悭吝心重的人，即使是自己最亲近的人前来乞求，也会反目成仇，视如怨敌；悲心深重的人，即使是仇敌，也能像对待亲友一样对待。悭吝心重的人，即使布施的是泥土，也会看得比金玉还要贵重；悲心深重的人，即使布施的是金玉，也会看得比草木还要轻贱。悭吝心重的人，一旦失去财宝，心中便大为忧恼；悲心深重的人，虽然拥有财宝，一旦没有可以布施的对象，心中怀抱的悲苦，反而更超过前者。

舍弃财物，大约有两种情形：一种是临命终时才被迫舍弃，一种是在生前主动布施而舍弃。临死时的舍弃，是把一切都彻底舍弃了，却连一丝一毫也带不到后世去；而生前布施的舍弃，只是舍弃了一点点东西，却能得到广大的果报。哪里还有明白这个道理的人，见到这样的利害得失，却仍旧不肯行布施呢？

行布施的时候，如果能使受施的人心生喜悦，自己也会跟着喜悦；如果不能从心底深处生起这样的喜悦，那就是在自欺欺人了。如果有乞求的人有所求索，只是因为自己贪求"福报"这个念头，才勉强布施一点点东西，心中生起的欢喜也是有限的；还有一种施与者，是主动前去布施，不求任何果报而行广大的布施——这样即使只剩下少许财物，心中的快乐也是无法用言语比拟的。假如有美味的食物，如果不肯布施给别人，自己一个人吃，也不会觉得味道有多美；假如是粗劣的食物，只要肯拿去布施了，然后再自己食用，心中反而会感到欢喜，觉得那是极为美味的。如果行布施完毕，还剩下一些留给自己食用，善良正直的丈夫，心中所生起的喜乐，就如同证得涅槃一般——没有信心的人，谁又会相信这样的话呢？

假使有美味的食物，眼前有饥饿的人，却不肯布施给他——这样的人，连食物都不肯施舍，又怎么谈得上把殊胜的解脱布施给别人呢？假使拥有很多财物，有人前来乞求，尚且没有布施之心，何况是布施一点点东西呢？可想而知，这样的人在生死轮回之中，几乎没有什么快乐可言，倒不如干脆安住在涅槃里去了。如果有人身处大水之旁，却连一点点水都不肯布施给别人，那么他在生死轮回之中所受的苦恼，必定是无量无边的——你不要停留在这样的生死之中了，还是尽快趣入般涅槃吧。就好比身旁有浩瀚的大水，要拿来布施别人并不困难；同样，如果心中怀有悲心，想要证取涅槃也并不困难。世间的粪土，本来比水还容易得到，可悭贪的人一旦听到有人来乞讨粪土，尚且心怀吝惜，何况是真正的财物呢？

## 财物施品第九

譬如有两个人，一个是大富之人，一个是贫穷之人。这时有乞求的人前来，这两个人心中都会感到苦恼：拥有财物的人，害怕对方前来求索；没有财物的人，则烦恼着"我该如何才能得到一点点财物给他呢"。这两个人虽然同样感到忧苦，果报却截然不同：因悲悯而忧恼的人，将来会投生天道人间，享受无量的快乐；而悭贪的人，则会投生到饿鬼道中，承受无量的痛苦。

如果菩萨对眼前的众生怀有悲悯之心，那么单单这份悲心就已经算是圆满具足了，何况还能布施给他一点财物呢？就好比大富之人拥有众多的财宝，随心所欲地使用，心中生出欢乐——菩萨以悲心思惟布施，心中所生起的忧念，要超过那位富人百千万倍。有悲心的人即使没有财物，见到别人前来乞求时，说不出"没有"这句话，心中悲苦得流下眼泪；而见到别人受苦受难却流不出眼泪的人，又怎能称得上是修行悲心的人呢？殊胜的人，听说别人的苦难尚且不能忍受，何况是亲眼见到别人的苦恼，却不去救济，这是绝对没有的事。

有悲心的人，见到贫苦的众生，自己却没有财物可以布施，便悲苦叹息，那种心情是无可比拟的；救济众生的人，见到众生受苦，会悲伤哭泣、流下眼泪——正是因为流泪，才能知道他的心是柔软的，菩萨本性的清净，就是这样显现出来的。为什么这么说呢？因为知道这份清净会显现出来：见到受苦的众生时，眼中会流下泪水，因此可以知道菩萨的本性是清净柔软的。

菩萨的悲心，就好比堆积的白雪，雪堆一旦见到阳光就会完全融化——菩萨的悲心见到受苦的众生，就如同雪堆遇见太阳一般，所以眼中才会流下泪水。菩萨流泪的情形，共有三种时候：第一种是见到修行功德的人，因心怀爱敬而为他们流泪；第二种是见到受苦受难、没有功德的众生，因悲悯而为他们流泪；第三种是在修行广大布施的时候，悲喜交集、内心踊跃，也会因此流泪。据说，菩萨自古以来所流的眼泪，累积起来已经超过四大海的水量了。世间的众生，因舍离亲属而悲泣流泪，也比不上菩萨看见贫苦众生却没有财物可以布施时，那种悲泣流泪的深切。

菩萨入于救度众生的禅定极乐之中，与悲心相应，无穷无尽的宝藏便会自然涌现，一切乞求的人也会自然前来。善良正直的丈夫，能够用财物广施于乞求的人；乞求的人得到财物之后，也会再去广行布施。菩萨能够用财物布施给众生，使他们变得富足，以平等的悲心，听到乞求者的声音，便会为他们流下泪水；乞求者见到菩萨落泪，虽然还没有开口说"给你"，也已经知道自己必定能够得到。

菩萨见到乞求者前来的时候，心中会生起极大的悲苦；乞求者得到财物的时候，心中生起欢喜，悲苦便得以消解。菩萨听到乞求的话语时，会悲泣落泪、不能自已，一直到乞求者说"够了"，才会停止。菩萨修行种种布施之后，众生都得到了满足，便进入山林修行禅定：怎样才能灭除一切众生贪、瞋、痴三毒的苦患呢？菩萨的财物越来越多，却已经没有乞求者可以布施了——"我现在还守着这些财物做什么呢？现在应当把它们全都舍弃，出家修行去了。"
