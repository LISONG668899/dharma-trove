# 飞锡《念佛三昧宝王论》卷上

唐代终南山紫阁峰草堂寺沙门飞锡撰，三卷，收入《大正藏》第四十七册（No.1967）。

## 作者考据

飞锡法师的生平，主要见于北宋赞宁《宋高僧传》卷三〈唐大圣千福寺飞锡传〉，又散见于同书的楚金、南阳慧忠、圆照诸传，以及南宋志磐《佛祖统纪》。综合这些史料，可以勾勒如下。

### 籍贯与师承

本传开头就说，飞锡"未知何许人也"，籍贯与俗姓都已失考。传中说他神气高远，识量过人。最初学习律仪，后来与沙门楚金一起，潜心研习天台宗"一心三观"的法门。

楚金是长安千福寺的法华行者，七岁诵《法华经》，后来建多宝塔，设法华道场，一生诵《法华经》六千余遍，乾元二年（759）示寂，唐德宗时追谥"大圆禅师"。飞锡与楚金同修天台止观，所以《佛祖统纪》把他列入天台宗的"未详承嗣传"：确属天台一系，但师承谱系不详。

### 草堂寺与千福寺

唐玄宗天宝初年（742年以后），飞锡游历京城长安，大多住在终南山紫阁峰的草堂寺。草堂寺是姚秦时鸠摩罗什译经的旧址。

《佛祖统纪》记载，不久朝廷有诏，令他住持千福寺法华道场，这正是楚金所建的道场。本论序中，飞锡自述"天书曲临，自紫阁山草堂寺，令典千福法华胜场，向三十年矣"，意思是圣旨降临，令他从紫阁山草堂寺出来，主持千福寺法华道场，至今将近三十年。这与史传完全相合。

### 参与不空三藏译场

当时不空三藏主持传译，慎重挑选英才，飞锡入选，多次担任笔受（记录译文）、润文（润色文辞）之职。

唐代宗永泰元年（765）四月十五日，飞锡奉诏，在大明宫内道场，与义学沙门良贲等十六人，参译《仁王护国般若经》与《密严经》。本传说，这两部经在梵文贝叶上原是偈颂，新译多改成散文，由不空三藏与飞锡等人，以及翰林学士柳抗，重新详加审定。飞锡担任"证义正员"（审定译义的正式成员），本传称他的辞笔"不愧斯职"。《佛祖统纪》也记载，这年吐蕃进逼京师，代宗诏不空三藏、飞锡、良贲等在大明宫南桃园重译《仁王经》。

不空三藏上表请求重译《仁王经》时，奏请参译的僧人名单中也有飞锡。《宋高僧传·圆照传》又记载，大历末年朝廷命京城临壇大德佥定《四分律疏》，期间有敕书称"检校道场大德昙邃、飞锡等"，可见他晚年仍在长安，为朝廷所重。

### 文章与碑铭

赞宁在本传的"系曰"中说，飞锡兼研儒家、墨家之学，尤其擅长文笔，当时很多人请他撰写碑文，如南阳慧忠国师碑、楚金碑等。

这在史传中都有印证。〈慧忠传〉记载，慧忠国师于大历十年（775）示寂，谥大证禅师，"译经沙门飞锡为碑纪德"。〈楚金传〉也记有"紫阁峰草堂寺飞锡碑文，吴通微书"。

赞宁把他与晋陵德宣、吴兴皎然（昼公）相提并论，说三人同在文坛驰骋，难分高下；又批评德宣与飞锡"亦有不羁之失，缘饰过其实"，认为他们的文章有时修饰过度，不如皎然切实。这是就文章风格而论。

### 著述

飞锡现存的著作，以这部《念佛三昧宝王论》为代表。《佛祖统纪》说他"尝撰《念佛三昧宝王论》三卷，明净土三世通修之义"。本论卷中末尾，飞锡自己提到先前还撰有《无上深妙禅门传集法宝》一卷，今已不传。

### 本论的宗旨与写作年代

本论书名中的"宝王"，取自《观佛三昧海经》：如来把观佛三昧称为"大宝王"，意即一切三昧之王。全论假托一位居士来访问法，设二十门问答，分三卷：上卷七门，念未来佛；中卷六门，念现在佛，即专念西方阿弥陀佛；下卷七门，念过去佛，并通念三世，无不是佛。

飞锡出身天台，又亲历不空三藏的密教译场，所以论中以天台的三观、三谛、三身来解释念佛，以《法华经》常不轻菩萨"我不敢轻于汝等，汝等皆当作佛"的精神，统摄"念未来佛"，也提到瑜伽真言的本尊观，禅、教、净、密在这里融为一炉。

至于写作年代，序中说他主持千福寺法华道场"向三十年"。如果从天宝初年算起，成书大约在他晚年，即唐代宗大历年间前后。这只是依序文推算，史传没有明文记载。

书后附有北宋黄伯思的跋文，作于政和七年（1117）。黄伯思（1079—1118），字长睿，北宋著名学者、书法家与金石学家。

## 序

有一位客人，深具信心，来到我的禅居，上前礼拜请问，言辞非常清雅。他问我："修心的人成道的捷径，有法华三昧中常不轻菩萨的行持，有念佛三昧中般舟三昧的宗旨，人们都推为无上深妙的禅门。我希望听听其中的道理。"

我回答说："我在九峰山中拱手静默，与世人所务不同。后来圣旨降临，令我从紫阁山草堂寺出来，主持千福寺法华道场，到现在将近三十年了。追慕高远、叩问寂灭之理的人，还没有像您这样发问的。您将要渡过无生的龙津，像大鹏一样展翅南飞，我虽然不聪敏，也试着谈一谈。现在略开二十门，来阐明这个宗旨。"

上卷七门，念未来佛。

中卷六门，念现在佛。

下卷七门，念过去佛，并通念三世，无不是佛。

卷上七门，念未来佛。

## 第一门　念未来佛速成三昧

心之所以分成二，是从种种妄想而生。种种妄想虽然虚幻，迷惑的人仍然滞著不放，不能解脱，圣人因此而忧虑。玄妙的法音虽然畅演，却无可言说；法身本空，却具足相好。如果相不明，说不圆，那一味的宗旨、言语道断的道路，谁能知道它的归趣呢？

三昧的宗旨，是要让流落在外的众生知道，不二法门既在言语之中，也在静默之中，并不只是维摩诘居士杜口无言、文殊菩萨赞叹而已。

为什么这样说？帝释天的宝网还没有张开，千颗宝珠哪里看得见？大网一举起，万个网眼一齐张开。在大海中沐浴的人，已经用上了百川之水；称念佛名的人，必定成就三昧。一言以蔽之，就在这里。

这又好比"清珠下于浊水，浊水不得不清；佛想投于乱心，乱心不得不佛"：清水珠放进浊水，浊水不能不清；佛的念头投入散乱的心，散乱的心不能不成为佛。契入之后，心与佛双双泯亡，双亡就是定；心与佛双双照了，双照就是慧。这就是定慧均等，那么哪一个心不是佛？哪一尊佛不是心？心与佛既然如此，那么万境万缘，无一不是三昧。

然而世上的人，大多念过去释迦佛如满月般的面容，观想现在阿弥陀佛如大海般的眼目，就像拔出了毒箭，就像登上了快乐的宫殿。我也认为这是最好的教法。但还没有听说有人念未来诸佛，那些聚集如日的诸佛。为什么呢？大概是因为不明白如来对着众生之粗、说诸佛之妙，于是把众生隔在诸佛之外，所以没有听说，又有谁肯去念呢？

《维摩经》中说，入薝卜林（一种香花林）的人只嗅薝卜的香气，不嗅其余的香；天女散花，花有著在声闻身上的，有不著在菩萨身上的。这是贬抑小乘、褒扬大乘。贬抑小乘时，须菩提被维摩诘问得茫然，想放下钵离开；褒扬大乘时，便同游不二法门。

《法华经》开决了声闻法，是诸经之王，一切声闻都成了薝卜林中人，花不著身的道理就很清楚了。如果不是这样的人，就会认为诸佛最尊贵，众生最卑贱，高下之分一出，种种妄想就兴起，恭敬与傲慢一对立，唯一的真实就隐没了。

这样的人，必然把万物视同草芥，把天下看得轻如锱铢，我慢的幢幡已经竖起，高傲突兀，眼睛送着飞鸿，心游于青天，不肯屈下。这就违背了《维摩经》所说"恭敬一切众生，是供养中最上"的经文。

他又不相信《楞伽经》所说：如来藏自性清净，转三十二相，入于一切众生身中，犹如无价的大宝珠被脏衣包裹。这岂不正如《维摩经》中维摩诘居士把璎珞分作两份，一份施给城中最下贱的乞丐，一份奉给难胜如来，平等看待，毫无差别吗？

如果圆满地念三世诸佛，普遍地观十方世尊，就契合《理趣般若经》所说"一切有情皆是如来藏，因为普贤菩萨的自体周遍一切"的经文了。贫女怀着未来的转轮圣王，米粒藏在糠皮之中，这个道理像镜子一样分明，怎么能犯下八种我慢的过失呢？

人们都敢侮慢未来的佛（众生），却不敢侮慢过去、现在的金色佛身。殊不知造罪的根源，都在对未来佛的轻慢上，而不在已成佛、今佛身上。如果没有众生，未来佛又在哪里？如果知道母亲因儿子而尊贵，米粒因糠皮而保全，与《法华经》常不轻菩萨的心相契合，那么念佛三昧不必求快，自然迅速成就。

问："法华，是法；念佛，是佛。怎么能把法当作佛，把佛当作法，岂不是混乱一片？"

答："不乱。本来就是一门，谁说乱呢？灵芝之类的仙药，与求仙的人，本来各在天涯，都没有'仙'的名号。因为人服了这药，羽化飞升，于是药得了仙药之名，人得了仙人之称。人和药不同，'仙'却是一个。

"如果没有圣人，谁与大道同游？法如果没有佛来觉悟，怎能让众生自己觉悟？法不靠佛就不能觉悟，于是有念佛三昧；佛不靠法就不能显明，于是有法华三昧。一个'仙'字有两种称呼，都得'仙'名；念佛与法华同名为佛慧。佛慧既然相同，那么常不轻菩萨的行持与般舟三昧，作为无上深妙的禅门，在这里就领悟了。它们从来没有不同，又有什么混乱呢？"

## 第二门　嬖女群盗皆不可轻

问："一切众生就是未来诸佛，我已经恭听了。可是淫女、盗贼，是最恶的人，怎么也要求念佛的人恭敬他们呢？"

答："佛所宣说的，有两种门：一是对待门，二是决了门。

"所谓对待门，是相对于女子的虚伪，来说如来的至真，那么佛可尊崇，女色可厌离。厌离有两种：一是诃斥欲望，二是放心。

"先说诃斥欲望。如菩萨诃斥色欲，经中说：'女色是世间的枷锁，凡夫恋著，不能自拔；女色是世间的重病，凡夫被它所困，到死也不能免；女色是世间的衰祸，凡夫遭遇它，没有什么灾厄不会到来。修行人既然已经舍弃，如果又去顾念，就像从牢狱中出来，又想再进去；从狂乱中停止，又再去喜欢它；病好了，又想再得病。智者怜悯这样的人，知道他狂乱颠倒，离死不远了。

"'凡夫看重女色，甘心做她的仆役，一生奔走辛苦；即使刀斧交加、锋刃齐至，也甘心承受，不以为患。狂人喜欢狂乱，不过如此。修行人如果能弃之不顾，就是打破枷锁，厌恶狂乱，厌离疾病，远离衰祸，既安且吉，得出牢狱，永无患难。

"'女人的形相，言语如蜜，心意如毒。譬如平静清澈的泉水，却有蛟龙住在里面；金山宝窟，却有狮子居住其中。应当知道，这种祸害不可接近。家室不和，是因为妇人；毁宗败族，是妇人的罪过。她实在是暗中的盗贼，灭人的智慧光明；又如猎人的围网，很少有人能逃出。譬如张起的罗网，群鸟落入，不能奋飞；又如密网，众鱼投入，就被剖肠切肉；也像暗坑，像无眼的飞蛾扑火。所以智者知道了就远离它，不受其害；厌恶而视为污秽，不被它所迷惑。'

"《大宝积经》中，佛为优陀延王说这样的偈子：

```
锋刃刀山，毒箭诸苦，女人能集，众多苦事。
假以香华，而为严好，愚人于此，妄起贪求。
如海疲鸟，迷于彼岸，死必当堕，阿鼻地狱。
现见众苦，皆来集身，善友乖离，天宫永失。
宁投铁狱，驰走刀山，眠卧炎炉，不亲女色。
```

大意是：刀山剑刃、毒箭等种种痛苦，女色都能招集而来。用香花装扮得美好，愚人就妄起贪求，像大海上疲倦的鸟，迷失彼岸，死后必堕阿鼻地狱。眼前众苦都集于身，善友离去，天宫永失。宁可投入铁狱，奔走刀山，卧于火炉，也不亲近女色。

```
如鸟为求食，不知避网罗，贪爱于女人，被害亦如是；
譬如水中鱼，游泳网者前，便为他所执，岂非自伤损？
女若捕鱼人，谄诳犹如网，男子同于鱼，被网亦如是。
```

大意是：鸟为了觅食不知躲避罗网，贪爱女色的人受害也是这样；水中的鱼游到撒网人面前，就被捉住，岂不是自己伤害自己？女子就像捕鱼人，谄媚欺诳就像网，男子就像鱼，被网住也是如此。

"再说放心。如《大宝积经》中说：文殊师利菩萨告诉善住天子：'如果有人一心专精自守，贪欲心生起时，应当立刻觉知，以方便散除，令心恢复寂静。怎样散除？应当这样想：这是空，这是不净。追求这欲心生在何处、灭在何处，从哪里来，到哪里去？其中是谁在染？谁是被染的？什么是染法？这样观察时，不见能染，不见所染，不见染事。因为不见，就没有取；因为不取，就没有舍；因为不舍，就没有爱。不舍不爱，就名为离欲，就是寂静涅槃。'如果又放任心进入种种尘劳、生死之中，而也不受贪、嗔、痴等烦恼过患所困，这叫做放心。

"以上说明第一对待门完毕。

"第二是决了门。如果究竟远离一切妄想，无染如虚空，那就是过去、现在诸佛，而不是未来佛了。你没有听说吗？要求无价之宝，必须潜入大海；要采智慧之宝，必须先在烦恼中求。五逆之相就是解脱之相，魔界之如就是佛界之如。如果听到佛的声音就欢喜，听到魔的声音就嗔恨，不入音声法门，不住音声实际，不觉悟诸法，这就像向北驾车却要去南方越国的人，怎么能和他谈道呢？

"再为你说明。经中不是说吗：'从前有位仙人，名叫鹿蹄，因地面湿滑跌倒，就用仙咒令天下大旱。国人深以为患，国王招募美艳的女子，诱惑他而得手，女子骑在他颈上进城，顿时浓云四起，大雨滂沱。那位仙人虽有乘风而行、凌越太空的神通，却毫无施展之处。'这仙人就是释迦佛，那女子就是耶输陀罗。在法华会上，耶输陀罗被授记未来成佛，号具足千万光相如来。可是念佛的人，只看到女子如玉的容貌，不念她未来千万光相的金色妙好，就失去了常不轻菩萨的宗旨，念佛三昧怎能不受欺诳呢？

"又如阿那律尊者，过去曾是盗贼首领，进寺盗取佛像额上的宝珠，用箭挑亮佛前的灯，使灯光不灭。阿那律，翻译过来就是'无灭'，原因就在这里。他将来成佛，号普明如来。这些都是同类的例子。

"念佛的人，对盗贼尚且不敢轻视，何况对不偷盗的人呢？这两位未来佛犹如皎洁的太阳，何愁三昧不能成就呢？"

## 第三门　持戒破戒但生佛想

问："两个疑难都解开了。《梵网经》说：'若人受佛戒，即入诸佛位。'出家众佩着明月般的戒珠，挂着璎珞般的宝珠，位列三宝之中，统摄七众，自然应当恭敬。可如果他们不精进持戒，行为颠倒放逸，轻慢他们有什么过错？有什么罪呢？希望为我剖析。"

答："如来曾在《观佛三昧海经》中为父王说：'从前有四位比丘，犯了戒律，深感羞耻，觉得无所依靠。忽然听到空中有声音说：你们所犯的罪，以为无可救药，其实不然。空王如来虽然已入涅槃，形像还在，你们可以进入佛塔，观看一下宝像眉间的白毫。比丘们依言而行，流泪说：佛像尚且如此庄严，何况佛的真容！于是全身投地，如大山崩倒。如今他们在四方都已成正觉：东方阿閦佛，南方宝相佛，西方无量寿佛，北方微妙声佛，就是这四位破戒比丘。'

"所以如来把这观佛三昧称为'大宝王戒品海'，能洗涤破戒的罪垢，得到尘累的清净。这四位比丘一观宝像，都成为世间的雄尊，念佛的人怎能对破戒的僧人生起疑惑呢？

"所以《大集经》说：'如果国王大臣打骂出家人，无论持戒破戒，罪过等同出百亿佛身血。'如果见到披袈裟的人，不论持戒犯戒，只生佛想。佛想，就是念佛三昧。这是佛的金口所说，阐明了常不轻菩萨的深旨，怎能任意打骂而不畏惧呢？

"经中说：'宁可做心的老师，不要以心为老师。'见到悭贪的人，作布施想；见到破戒的人，作持戒想。这样就不会被六蔽（悭贪、破戒、嗔恚、懈怠、散乱、愚痴）的境界所缠缚，反而成就到达六度彼岸的观门。如果住在分别心中，自取冥府的惩罚，不是很可悲吗？如果能翻转这种见解，念佛三昧就会像江河一样流淌不息了。"

## 第四门　现处汤狱不妨受记

问："如果破戒比丘观佛都能成正觉，固然不可轻视，这我相信了。可是那些正在汤镬地狱中，或者陷身饿鬼道的众生，菩提心难以生起，就像等黄河变清一样遥遥无期，怎么也要让念佛的人同样恭敬他们呢？"

答："难道没听说过吗？采良药的人，一定在险峻的山中，药不是从华美的厅堂里长出来的；集法药的人，一定在险恶的三有之中，法药不是从无为之中自己生出来的。

"《首楞严三昧经》说有四种授记：一是未发心授记，二是初发心授记，三是秘密授记，四是现前授记。现在这些众生虽然身处饿鬼、地狱，没有发心，佛却授记他们将来必定发大志愿，遇到真善知识，行菩萨行，还成正觉。所以不可轻视，这就是未发心授记。

"佛说这四种授记时，迦叶尊者对佛说：'我们从今以后，对一切众生都生世尊想，如果生轻慢心，就是自己伤害自己。'佛说：'善哉！说得好！人都不应衡量众生，唯有如来才能衡量。因为这个缘故，我嘱咐诸声闻和其余菩萨，对一切众生应生佛想。'《华严经·普贤行愿品》中破除百万障门，也用这种佛想。

"这样说来，现在身居恶道而蒙佛授记的众生，就像宅中的宝藏还没有开掘，不妨宝藏就在宅内；额上的宝珠突然没入皮肉，又何妨宝珠仍隐在额中。

"如果不把众生念为未来佛，必定把六尘当作寇贼，这就像防备魔军却自己毁坏营垒，留着敌国而常起怨仇，所以战事不得安宁，战鼓依然震响，怎能高枕而卧呢？如果能使不降的来降，不服的都服，天下就统一了。那时猎猎的旌旗还有什么用？翩翩的飞将又去哪里？我将退回战马，让它去耕田施肥，日出而作，日入而息。即使帝尧那样的圣君，对我又有什么作用呢？百姓日日受用而不自知，这才显出圣化的广大普被。

"如果能悟色、声即是佛，念众生为未来佛，必定不会在心前立一个凡夫的境界；或者观想自身就是本尊，这与瑜伽真言深妙的观门不谋而合。凡是因观想而有的，岂能不空？那么大鹏与小鷃可以齐等，泰山与秋毫可以为一，也就没有削平山岳的偏执，也没有接长凫腿的忧虑了。"

问："汤镬地狱中的众生虽然还没有发心，如来法王宽宥其过，为他们授记，千道光明四射，十种名号圆满光明。正如您所说，谁敢不信？但推究起来，他们尚未觉悟，从何处得以醒悟呢？"

答："说尚未觉悟，也有它的道理。长江的源头，只能浮起一只酒杯；大迷的根本，在于两种见解。如果认为在念之外另立无念，在生之外另立无生，那么生死就不同于涅槃了，即使万佛的洪音也无法教化。如果了知念而无念，观生而不生，烦恼就是菩提，以一相庄严，这就能悟了。这又像岩石上的群蜂，蜂房里早已满是纯蜜；井中的七宝，何妨称为珍宝。都是本来就有，不是今天才有。

"念未来佛，罪从何生？我放开我的心，遍及一切所缘之处，处处都见如来，道从嗔恚等烦恼中生。

"所以《如来藏经》中，佛告诉金刚慧菩萨说：'善男子，我以佛眼观察一切众生，在贪欲、嗔恚、愚痴诸烦恼中，有如来智、如来眼、如来身，结跏趺坐，俨然不动，乃至德相具足，与我无异。'经中广说一切众生都有如来藏，以九种譬喻来说明。《宝性论》解释后，总结说：

```
萎华中诸佛，粪秽中真金，地中珍宝藏，诸果子中芽，
朽故弊坏衣，缠裹真金像，贫贱丑陋女，怀转轮圣王，
焦黑泥模中，有上妙宝像。众生贪瞋痴，妄想烦恼等，
尘劳诸境中，皆有如来藏。下至阿鼻狱，皆有如来身，
真如清净法，名为如来体。
```

大意是：枯萎的花中有佛，粪秽中有真金，地下有宝藏，果实中有芽，破旧的衣服裹着金像，贫贱丑陋的女人怀着转轮圣王，焦黑的泥模中有上妙宝像。同样，众生的贪嗔痴、妄想烦恼等尘劳境界中，都有如来藏；乃至阿鼻地狱，都有如来身。真如清净之法，名为如来的本体。

"用这段经文来证明汤镬地狱中的众生蒙佛授记，就豁然明白了，三昧之门自然洞开。"

问："至人用心，淡然清净，攀缘永远断绝。现在您说放开心念，遍缘一切所缘之处，处处都见如来，这在教典中有根据吗？"

答："也有教典说：起心遍缘六尘、三业，同时发起妙愿，进入佛的境界，每一个缘起都不离如来，这名为'悉皆见'。这是圆满之见，不是用眼睛见的。

"所以《涅槃经》说：'声闻人虽有天眼，也名为肉眼；学大乘的人虽然只有肉眼，也名为佛眼。为什么？因为他明了自身有佛性。'

"又如《胜天王般若经》中，佛告诉胜天王菩萨摩诃萨：'以方便力行般若波罗蜜，于一切法心缘自在。缘一切色，愿得佛色，因为无所得；心缘众声，愿得如来微妙音声；心缘众香，愿得如来清净戒香；心缘诸味，愿得如来味中第一的大丈夫相；心缘诸触，愿得如来柔软的手掌；心缘诸法，愿得如来寂静之心；心缘自身，愿得佛身；心缘自口，愿得佛口；心缘自意，愿得如来平等之意。'

"菩萨摩诃萨行般若波罗蜜，没有一心、一行空过而不趣向一切智的。遍缘诸法而能不执著，观见诸法，无不趣向菩提之道。菩萨修习种种行，都是依外缘而成就。又如大地住在水上，如果开凿池井，就能得到水用；不开凿的，就无从见水。圣智的境界也是这样，遍于一切法，如果勤修般若方便，就能得到；不修的人，怎能得到心缘的道理呢？这岂不是很伟大吗？"

## 第五门　观空无我择善而从

问："即动而静，静是躁的主宰；即凡而圣，圣隐藏在凡夫之中。这深远的宗旨我已恭听了。再请问：儒、道、佛三教都说无我，道理既然没有不同，那'择善而从'的意义在哪里呢？"

答："三教所说的道理，名称从来没有不同，道理却从来没有相同。孔夫子'绝四'中的'毋我'，是谦让光明的意思，以此为无我；道家的无我，是'长而不宰'（养育万物而不主宰），以此为无我；佛教的无我，是观五蕴皆空，以此为无我。

"前两家的教门都不讲五蕴，又有谁辨明四谛、六度万行、贤圣的阶位？对此完全没有听闻，只是和光同尘，守雌守静，既慈且俭，不敢为天下先。各是一位圣人，何必去评论他们的深浅呢？三教所说的无我，就清楚了。

"所谓'择善而从'，是说善、不善、无记三性之理，理无所不在。修心的人择善而从，是因为不善对至真毫无益处，无记则善恶两亡，妨碍扰乱佛理的，不都是从这里来吗？所以圣人拣择它们而不取。所以《涅槃经》说：'一阐提人，心不攀缘一切善法，乃至不生一念之善。'由此可知，念佛三昧是善中最上，万行之首，所以称为三昧之王。"

## 第六门　无善可择无恶可弃

问："如果择善而从，为什么不选择诸佛之善，舍弃众生之恶，反而念未来诸佛，把他们与过去、现在的正觉者等同呢？"

答："不必改动您的问话，它自己就成了我的回答。为什么呢？'择善而从'，原是不得已而说的，因为力量微小而担子太重，不能即恶而善、即妄而真，所以这样说明。

"如果能念未来之佛，契合常不轻菩萨的行持，那么天地就是一指，万物就是一马，众生都是佛，此土常是净土，不同于舍利弗所见的土石沙砾，而同于梵王所见的珍宝庄严。这就是择善的极致，也就无恶可弃了。

"天台智者大师解释《法华经》，阐明'绝待妙'，引证经文说：

```
众生见劫尽，大火所烧时，我此土安隐，天人常充满，
园林诸堂阁，种种宝庄严。
```

大意是：众生看到劫末大火焚烧世界的时候，佛的这片国土依然安稳，天人常常充满，园林楼阁都以种种珍宝庄严。

"又《胜天王般若经》说：'佛所住之处，实在没有秽土，众生福薄，所以见为不净。'道理正在这里。

"梵语'南无'，唐朝话叫'归命'；梵语'阿弥陀'，唐朝话叫'无量寿'。三世诸佛，岂只有一位佛寿命无量呢？现在我与您一同念三世的阿弥陀佛，一同往生十方的极乐世界，有什么不可以？为什么要像鹢鸟那样往后倒飞呢？

"这样一来，三昧的猛焰炽烈燃烧，纤细如蚊蚋的妄念无处停留；十念的洪钟铿然一响，即使在散乱中称佛也不被阻隔，这就明白了。念阿弥陀佛能通三世既然如此，念诸佛菩萨不也是这样吗？"

问："念未来佛，就与过去、现在诸佛相等，希望听听其中的道理。"

答："《华严经》说：'一切诸如来，同共一法身，一身一智慧，力、无畏亦然。'《楞伽经》偈说：'迦叶佛、拘留孙佛、拘那含佛就是我，以这四种平等，我为佛子宣说。'

"所谓四种平等：一是字平等，同名为佛；二是语平等，都具足迦陵频伽般的梵音声相；三是法平等，都证得菩提分法和无障碍智；四是身平等，法身、色身、相好都没有差别。

"《大乘起信论》说：'依方向而迷，方向实际并没有转。'这样说来，悟的人悟了一方，其余诸方自然都正了；念的人念一佛，诸佛都现前。经中所说'水不上升，月不下降'，因为水光清净的因缘，虚空中的皓月便显现在清水中；彼佛不来，我身不往，因为念佛的因缘，如来的宝月便显现在心水之中。正如偈中所说：

```
菩萨清凉月，游于毕竟空，众生心水净，菩提影现中。
```

大意是：菩萨如清凉的明月，游于毕竟空中；众生的心水一旦清净，菩提的月影就显现其中。"

## 第七门　一切众生肉不可食

问："肉是人吃的东西，为什么念佛的人家要断绝它呢？"

答："尸毗王救鸽，割自己的肉放在秤上，要和鸽子一样重才平衡。国王与禽鸟不同，保全性命的心却是一样的。怎能执意吃它们的肉，来滋养这个终将败坏的身体，还昏昏然不知畏惧呢？

"如果能领悟众生都是未来诸佛，谁还肯对着赤鳞的鱼挥动白刃，放出苍鹰去追捕狡兔，像夜晚的飞蛾扑火，自取灭亡呢？所以《楞伽经》（〈佛语心品〉）与《宝积经》中有偈说：

```
为利杀众生，以财网诸肉，二俱是恶业，死堕叫唤狱。
```

大意是：为了牟利而杀害众生，用钱财去买各种肉，这两者都是恶业，死后堕入叫唤地狱。

"依这圣旨，如果不花钱买肉，那么张网捕捉的人、屠宰的人自然就停止了。龙树菩萨尚且不轻视鸽雀，高僧行路不跨越虫蚁。有人问其中的缘故，他们回答说：'它们与我同在生死之中，它们或许会先成正觉，怎能随意轻视呢？'轻视尚且不可，怎能专门吃它们的血肉呢？

"《宝性论》说：'《如来藏经》中告诉舍利弗：众生就是第一义谛，就是如来藏，就是法身，就是菩提。'

"我认为，狗只会追逐土块，不知道去追扔土块的人，土块就永远不停；只念过去、现在佛，不念未来佛，我慢就永远不息。如果像狮子那样去追扔土块的人，土块自然就停了。

"懂得恭敬与傲慢的道理，便能一以贯之：把对父母的恭敬移来作傲慢，把父母看得和普通人一样，这是最大的悖逆；把对普通人的傲慢移来作恭敬，把普通人看得和父母一样，这是最大的孝道。所以《梵网经》说：'六道众生，都是我的父母，孝名为戒。'道理正在这里。如果把六道众生看作未来佛，那么'父母'的说法还只是浅近的话。

"如果能像沙弥救蚂蚁那样，短促的寿命得以延长；像流水长者救鱼那样，天上降下花雨，革除旷劫以来对众生的见解，念他们是未来善逝之身，就会知道粪秽之中有真金，重云之间有明月。那么食肉的昏雾、生死的烟霾，都被智慧之风扫除，归于三昧的长空。

"《梵网经》说：

```
我是已成佛，汝是当成佛，常作如是信，戒品已具足。
```

大意是：我是已成之佛，你是将成之佛，常常这样相信，戒品就已经具足了。怎能不念众生是佛呢？"

问："肉不可吃，我相信了。那么五辛（葱、蒜、韭、薤、兴渠五种辛臭蔬菜）怎么样呢？"

答："圣教已经说明了。《大佛顶首楞严经》说：'佛告阿难：这五种辛菜，熟吃会引发淫欲，生吃会增长嗔恚。世间吃辛菜的人，即使能宣说十二部经，十方天仙也嫌他臭秽，都远离他；而那些饿鬼，趁他吃的时候，舔他的嘴唇，所以他常与鬼住在一起，福德日日消减，永无利益。吃辛菜的人修三摩地，菩萨、天仙、十方善神都不来守护，大力魔王便得其方便。'佛告阿难：'修菩提的人，永断五辛，这名为第一增进修行渐次。'这是佛的金口所说，不是很真实吗？

"酒就更不必说了。《百喻经》说：'从前有个穷人在路上走，捡到一袋金钱，心中大喜，立刻数起来，还没数完，钱的主人忽然来了，全部夺了回去。这人当时后悔没有赶快离开，懊恼之情，痛苦极了。遇到佛法的人也是这样，虽然遇到三宝福田，却不勤修方便，只喜欢多闻，忽然命终，堕入三恶道，就像那个愚人，钱又被主人夺走了。'偈中说：

```
今日营此事，明日营彼事，乐著不观苦，不觉死贼至，
匆匆营众务，凡人无不尔，如彼数钱人，其事亦如是。
```

大意是：今天忙这件事，明天忙那件事，贪著享乐而不观察痛苦，不知道死亡这个盗贼已经来临。匆匆忙忙经营种种事务，凡夫没有不是这样的，就像那个数钱的人一样。"

以上七门，都是念未来诸佛，以此贯通三世的意思。如果想念弥勒佛，必得上生兜率天宫，见到慈氏世尊，那么"弥天释道安"（东晋道安法师）就是最早倡导的人了。
