# 心之本体

麦彭仁波切 造

顶礼上师文殊师利！

法性虽不可思议、无可言说，然而对于欲趣入甚深法性之义的具善缘者，姑且以言词加以譬示、宣说如下：

所谓"心之本体"，即是无为觉性之赤裸本面，通过上师之加持融入及窍诀教授而得以指认者。

## 本体为何

若问：此本体究竟为何？其体性为空、无所缘执；其自性为明、任运成就；其大悲周遍一切、无有间断；即是三身无别之觉性。是故，持明者噶拉多杰（极喜金刚）于其《遗教》中说：

```
ཡིན་པ་ཅིར་ཡང་མེད་པའི་རིག་པ་འདི། །
རྣམ་པ་འཆར་ཚུལ་ཅིར་ཡང་མ་འགགས་པས། །
```

此觉性，非任何存在之物，然其行相之显现方式，却无所不现、毫无障碍。

若归纳而言，心之法性，即是本自任运而住之实相，是此本然觉性，离于造作、坦荡开阔者。

## 遮遣之说

若从遮遣之角度加以譬示、宣说：非是可执取之有；非是断灭之无；非是此二者之聚合；亦非非二者之第三品类。对此，无论以何种戏论皆无法执之为"此即其本体"，此即所谓"非任何存在之见地"。

## 成立之说

若从体验之角度、以成立之方式宣说其本体：空荡荡然，明朗朗然，澄澈清清然，平等坦坦然，宽广豁豁然。

以譬喻示之：无边无中，犹如虚空；明晰周遍无碍，犹如阳光遍照虚空；无有内外，犹如水晶球；无有执著，犹如空中鸟迹；无生无灭，犹如虚空等。

## 遣除邪见之说

为遣除对此教授可能生起之邪分别，若以"遮而复遮"之方式宣说：即是不偏于任何一方之大明，无所缘之大空，不可分割之大双运等。

## 就义理而言

就其义理而言：因言词无法譬示，故不可言说；因寻常心识无法了知，故不可思议；因不堕任何边，故为大离戏。终究超越"此即一切""此非一切""一切皆在其境界中""此亦非然"等种种言说，唯安住于各自内证自明之中。

## 名相与譬示

譬示之名，即"本净"（噶达）与"任运成就"（伦珠）；归纳而言，即"自生智慧唯一明点"。就其具足功德之法门而言，因已臻至一切之顶巅，故亦称"般若波罗蜜多"等。

以表征指示而言，可借由太阳、火晶（凸透镜）、水晶球、指向虚空之手指等而加以指认。

```
ནོར་བུ་རང་ལག་ཐོབ་པ་ལ། །
གཞན་པས་འདོར་ཀྱང་ཁོང་ཁྲོ་ཅི། །
ཆོས་ཀུན་རྩེ་མོའི་མན་ངག་ལ། །
རང་སྐལ་མ་ཆད་སྐལ་བ་བཟང་། །
གཞན་པ་གཤེ་ཡང་ཅི་ལ་ཁྲོ། །
```

于自己手中已得之珍宝，纵然他人弃而不顾，又何须动怒？于此一切法之顶巅窍诀，自身之善缘既未断绝，实乃殊胜之福分，纵然他人加以毁谤，又何须动怒？

麦彭所造。

## 译者说明

本篇依藏文原文重新译出。正文以"本体为何、遮遣之说、成立之说、遣除邪见之说、就义理而言、名相与譬示"六层依次铺陈，是大圆满教法中说明觉性（本净、任运成就）之典型论述方式，译文依原文段落划分逐层标出，以清眉目。文中所引噶拉多杰（极喜金刚）《遗教》一颂及篇末结颂，皆保留藏文原文置于代码框内，中译置于其后。
