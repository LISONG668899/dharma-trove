一、遍计所执显现而非称体

又，如何得知：在依他起自性上，遍计所执自性显现，并不与依他起的体相称？因为在名之前，觉知不起，与名义称体相违；因为一义有众多名，与多体相违；因为名不决定，与杂体相违。关于此义，有两颂：

```
由名前觉无
多名不决定
成称体多体
杂体相违故
法无而可得
无染而有净
应知如幻等
亦复似虚空
```

大意：在名之前没有觉知，一义有多名，一名所指不决定，所以“名与义同体”的说法，与称体、多体、杂体三者相违。法实际上没有，而可以得到；本来没有染污，而说有清净：应当了知，如同幻事等，又如同虚空。

【世亲释】如果名与义同一相，就不应当等待名，对义的觉知就能生起。比如瓶，离开“瓶”的名，对瓶的义就没有瓶的觉知；如果瓶名与瓶义同一相，瓶的觉知应当生起；名与义不是同一相，所以不生起。即第一种相违。又，一义有众多名，如果名与义同一相，义也应当如名一样有多种，一义成为多体，即第二种相违。又，名不决定，一个“瞿”声可以指九种义，如果名与义同一相，多种义应当同一体，即第三种相违。

【世亲释】后一颂以幻事等譬喻开导弟子的两种疑问：为什么法实际上没有而可以得到？为什么本来没有染污而说有清净？如同幻象实无所有而现前可得，诸义也是如此。如同虚空，本性清净，不被云等所染，云等离去时，称为清净；诸法也是如此，本来没有染污，性本清净，客尘障垢灭离时，称为清净。

二、依他起与圆成实不可全无

又，为什么如所显现的那样实无所有，依他起自性并不是一切都完全没有？如果依他起没有，圆成实自性也就没有；如果依他起和圆成实都没有，就一切都没有。如果依他起和圆成实自性没有，就成为没有杂染和清净的过失。杂染与清净现在可以得到，所以不应当一切都没有。关于此义，有一颂：

```
若无依他起
圆成实亦无
一切种若无
恒时无染净
```

大意：如果没有依他起，圆成实也就没有。一切种类都没有，就永远没有染与净。

三、方广教中的三性与四种清净

诸佛世尊在大乘中宣说方广教，方广教中说：应当如何了知遍计所执自性？应当了知，以种种异门说无所有。应当如何了知依他起自性？应当了知，譬如幻事、阳焰、梦境、影像、光影、谷响、水月、变化。应当如何了知圆成实自性？应当了知，宣说四种清净法。

四种清净法是什么？第一，自性清净，就是真如、空、实际、无相、胜义、法界。第二，离垢清净，就是同一真如远离一切障垢。第三，得此道清净，就是一切菩提分法、波罗蜜多等。第四，生此境清净，就是诸大乘微妙正法之教。大乘法教是清净之缘，所以不是遍计所执自性；是最清净法界的等流，所以不是依他起自性。上面四种法，总摄一切清净法无余。关于三性与四种清净，有两颂：

```
幻等说于生
说无计所执
若说四清净
是谓圆成实
自性与离垢
清净道所缘
一切清净法
皆四相所摄
```

大意：以幻事等譬喻宣说的，是依他起；宣说“无”的，是遍计所执；宣说四种清净的，就是圆成实。自性清净、离垢清净、清净之道、道的所缘，一切清净法都由四种相所摄。

【世亲释】自性清净，就是真如的自性本来清净，是一切有情平等的共相；由于有自性清净，所以说一切法有如来藏。离垢清净，就是同一真如远离烦恼障与所知障的垢染，由清净真如显成诸佛。得此道清净，就是能证得真如的念住等菩提分法和一切波罗蜜多。生此境清净，就是能生菩提分法的所缘境界，即契经等十二分教。如果圣教是遍计所执，就应当成为杂染之因；如果是依他起，就应当成为虚妄；圣教是最清净法界的等流，所以不是虚妄，远离两种自性，成为圆成实。四种清净中，前两种没有变异，所以是圆成实；后两种没有颠倒，所以是圆成实。

四、幻等八喻

又，为什么如经中所说，对依他起自性说幻等譬喻？为了除去他人对依他起自性的虚妄之疑。他人对依他起自性有什么虚妄之疑？他人有以下的疑问。

实际上没有义，为什么能成为所行的境界？为了除去此一疑问，说幻事的譬喻。

没有义，为什么心与心法能够转起？为了除去此一疑问，说阳焰的譬喻。

没有义，为什么有可爱、不可爱的受用差别？为了除去此一疑问，说梦的譬喻。

没有义，为什么净业、不净业的可爱、不可爱果报会差别而生？为了除去此一疑问，说影像的譬喻。

没有义，为什么种种识能够转起？为了除去此一疑问，说光影的譬喻。

没有义，为什么种种戏论言说能够转起？为了除去此一疑问，说谷响的譬喻。

没有义，为什么有真实所取的诸三摩地所行境界转起？为了除去此一疑问，说水月的譬喻。

没有义，为什么诸菩萨以无颠倒心，为了成办有情的种种利乐之事，故意受生？为了除去此一疑问，说变化的譬喻。

【世亲释】阳焰喻：阳焰比喻心与心法，水比喻义。阳焰由于动摇，没有水，也生起水的觉知；心与心法也是如此，由于动摇，没有义，也生起义的觉知。水月喻：水月实际上没有，由于水润滑澄清的性质，月影现前可得；定心也是如此，所缘境义实际上没有，由于定心润滑澄清，境相现前可得。变化喻：变化之物实际上没有，由于化者的力量，一切事都能成办；菩萨所受的身体，义实际上没有，仍能作一切有情的利益安乐。

五、生死涅槃无差别的密意

世尊依据什么密意，在《梵问经》中说“如来不得生死，不得涅槃”？在依他起自性上，依据遍计所执自性和圆成实自性，有生死与涅槃无差别的密意。为什么？同一依他起自性，由遍计所执的一分成为生死，由圆成实的一分成为涅槃。

【世亲释】依他起不决定是生死，因为由圆成实一分成为涅槃；也不决定是涅槃，因为由遍计所执一分成为生死。所以不可决定说是一性。依据此一意趣，《梵问经》中说如来不得生死，不得涅槃。

六、法有三分与金土藏喻

《阿毗达磨大乘经》中，薄伽梵说法有三种：第一，杂染分；第二，清净分；第三，杂染与清净二分。依据什么密意如此说？在依他起自性中，遍计所执自性是杂染分，圆成实自性是清净分，依他起本身是二分。依据上面的密意如此说。

在此义上，以什么譬喻显示？以金土藏为譬喻。比如世间的金土藏中有三法可得：第一，地界；第二，土；第三，金。在地界中，土并非实有而现前可得，金是实有而不可得。用火烧炼时，土相不现，金相显现。又，地界中，土显现时是虚妄显现，金显现时是真实显现，所以地界是二分。识也是如此。无分别智之火还没有烧炼时，识中虚妄的遍计所执自性显现，真实的圆成实自性不显现。识被无分别智之火烧炼时，识中真实的圆成实自性显现，虚妄的遍计所执自性不显现。所以，虚妄分别的识，也就是依他起自性，有杂染与清净二分，如同金土藏中的地界。

七、常与无常等无二的密意

世尊有的地方说一切法常，有的地方说一切法无常，有的地方说一切法非常非无常。依据什么密意如此说？依他起自性，由圆成实性一分是常，由遍计所执性一分是无常，由二分是非常非无常。依据上面的密意如此说。

如同常与无常无二，同样，苦与乐无二，净与不净无二，空与不空无二，我与无我无二，寂静与不寂静无二，有自性与无自性无二，生与不生无二，灭与不灭无二，本来寂静与非本来寂静无二，自性涅槃与非自性涅槃无二，生死与涅槃无二，也是如此。像上面所说种种差别的一切诸佛密意语言，都应当依三自性随之决了，如前面所说的常与无常等门。关于此义，有多颂：

```
如法实不有
如现非一种
非法非非法
故说无二义
依一分开显
或有或非有
依二分说言
非有非非有
如显现非有
是故说为无
由如是显现
是故说为有
自然自体无
自性不坚住
如执取不有
故许无自性
由无性故成
后后所依止
无生灭本寂
自性般涅槃
```

大意：如所执之法实际上不有，所以“非法”；如所显现不是只有一种，所以“非非法”；因此宣说无二的意义。依一分而开显，或说有，或说非有；依二分而说，非有也非非有。如所显现的那样并不是有，所以说为无；由于如此显现，所以说为有。诸法没有离缘自然而有的体，灭后没有自体，生后没有坚住的自性，如愚夫所执取的那样不有，所以许可诸法无自性。由于无自性，无生、无灭、本来寂静、自性涅槃得以成立，后一后依于前一而成。

【世亲释】一切法无自性的意趣有四种。自然无：一切法没有离开众缘、自然而有的体性。自体无：法灭以后，不再生起。自性不坚住：法才生起，一刹那后就没有力量安住。上面三种无自性的道理，与声闻共通。如执取不有：如愚夫所执取的遍计所执自性，并不如此而有；依据此一意趣，大乘说一切法都无自性，此一种不与声闻共通。由于无自性，所以无生；由于无生，所以无灭；无生无灭，所以本来寂静；本来寂静，所以自性涅槃。“后后所依止”，是后一后依于前一而有。

八、四种意趣与四种秘密

又有四种意趣、四种秘密，一切佛语都应当依此随之决了。

四种意趣：第一，平等意趣，比如佛说“我过去某时就是名为胜观的正等觉者”。第二，别时意趣，比如佛说“如果诵持多宝如来的名号，就对无上正等菩提已得决定”；又比如说“只由发愿，便得往生极乐世界”。第三，别义意趣，比如佛说“如果已经承事过像殑伽河沙那么多的佛，才能对大乘法解义”。第四，补特伽罗意乐意趣，比如为同一个人，先赞叹布施，后又毁訾布施；如同布施一样，持戒和一分修行，应当了知也是如此。上面称为四种意趣。

【世亲释】平等意趣：如同有人取相似之法说“那就是我”，世尊以平等法身置于心中，说“我过去曾是那尊佛”，并不是说过去的毗钵尸佛就是今天的释迦牟尼佛。别时意趣：令懈怠的人由此精勤修习，善根增长；诵多宝如来名号，是向上增进之因，不是只诵名号就当下得到决定；如同说“由一金钱得千金钱”，不是一日就得，意在别时，因为一金钱是得千金钱之因。别义意趣：“解义”是对三自性的义理亲自证得其相；如果只是了解文字言说的意义，愚夫也能了解，所以说“解义”意在证解，要由过去承事多佛才能达到。意乐意趣：对原本吝啬的人赞叹布施；对已经乐于布施的人，又毁訾布施，令修更殊胜的行。

四种秘密：第一，令入秘密，就是在声闻乘或大乘中，依世俗谛的道理，说有补特伽罗，以及有诸法的自性和差别。第二，相秘密，就是在宣说诸法之相的地方，显示三自性。第三，对治秘密，就是在宣说诸行对治的地方，说八万四千种对治。第四，转变秘密，就是在某些地方以别的意义，诸言诸字就显示别的意义。比如有颂说：

```
觉不坚为坚
善住于颠倒
极烦恼所恼
得最上菩提
```

大意：字面的意思是：把不坚固觉为坚固，善于安住在颠倒中，被烦恼极度所恼，证得最上菩提。颂中每个关键字都转作别义，真实意趣见下面的世亲释。

【世亲释】“不坚”指定，因为定不刚强、不驰散，所以称为不坚；对定生起尊重之心，称为“觉为坚”。“颠倒”：把无常等执为常等，是颠倒；把无常等知为无常等，是能颠倒（能破颠倒）；善于安住在能破颠倒之中。“烦恼”：精进劬劳称为烦恼，为众生长时劬劳精进所恼。
