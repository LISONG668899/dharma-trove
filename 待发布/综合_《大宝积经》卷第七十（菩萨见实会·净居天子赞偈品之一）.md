# 《大宝积经》卷第七十（菩萨见实会·净居天子赞偈品之一）

北齐·三藏那连提耶舍 译

## 菩萨见实会第十六

### 净居天子赞偈品第二十三之一

【按】会题“第十六”，宋、元、明、宫、圣、圣乙本作“第十六之十”。品题“之一”，宫本无。

#### 赞六度四摄等佛德

那时净居诸天子知道无量众生得以安住菩提，对佛法没有疑虑之后，称心如意，踊跃欢喜，各以妙偈赞叹佛的功德。

那时信施天子以偈赞叹说：

```
所爱妻子施，并舍所重身，
乃至王位财，我礼檀度者。
```
（大意：所爱的妻子也施舍，并且舍弃所珍重的身体，乃至王位与财物，我礼敬圆满布施度的人。）

【按】“所爱”之“所”，圣乙本作“爱”。

那时乐持戒天子以偈赞叹说：

```
如来本持戒，一切无所著，
获果到彼岸，我礼戒度者。
```
（大意：如来本来持戒，对一切都无所执著，获得果报，到达彼岸，我礼敬圆满持戒度的人。）

那时乐忍天子以偈赞叹说：

```
佛昔修忍辱，堪受解支节，
初无悔恼心，我礼忍度者。
```
（大意：佛往昔修习忍辱，堪受肢节被支解，始终没有懊悔恼恨之心，我礼敬圆满忍辱度的人。）

那时乐精进天子以偈赞叹说：

```
不退勇健首，精进有大力，
已得上菩提，我礼进度者。
```
（大意：不退的勇健首领，精进具有大力，已得无上菩提，我礼敬圆满精进度的人。）

【按】“勇健首”之“首”，宋、元、明、圣、圣乙本作“者”。

那时乐禅天子以偈赞叹说：

```
佛本修禅定，世间所不知，
三际得平等，我礼禅度者。
```
（大意：佛本来修习禅定，是世间所不知的，于三际得平等，我礼敬圆满禅定度的人。）

那时威德天子以偈赞叹说：

```
大雄于般若，相续而修行，
获得无尽慧，我礼智度者。
```
（大意：大雄对于般若相续修行，获得无尽的智慧，我礼敬圆满智慧度的人。）

那时界慧天子以偈赞叹说：

```
布施及爱语，利益与同事，
以此度众生，我礼大导师。
```
（大意：以布施、爱语、利益与同事，以此度化众生，我礼敬大导师。）

那时净慧天子以偈赞叹说：

```
于大慈悲喜，长夜常修习，
以是济群生，归命大船师。
```
（大意：对于大慈、大悲、大喜，长夜常常修习，以此救济群生，归命大船师。）

【按】“于大慈”之“于”，圣乙本作“施”。

那时净心天子以偈赞叹说：

```
以度无诤行，调心大牟尼，
能调未调者，我礼调御师。
```
（大意：以度化而行无诤之行，调伏自心的大牟尼，能调伏未调伏的人，我礼敬调御师。）

那时无垢慧天子以偈赞叹说：

```
广心柔软心，心调及诸根，
知诸众生心，我礼悉知者。
```
（大意：心广大而柔软，心已调伏，诸根也已调伏，了知众生之心，我礼敬一切悉知者。）

那时净意天子以偈赞叹说：

```
具足正念者，安住坚慧中，
明达悉了知，礼觉觉他者。
```
（大意：具足正念的人，安住于坚固的智慧中，明达而都能了知，礼敬自觉又觉他的人。）

那时庄严心天子以偈赞叹说：

```
佛久心清净，亦净佛国土，
及净群生慧，我礼净法王。
```
（大意：佛久已心得清净，也清净佛国土，以及清净群生的智慧，我礼敬清净的法王。）

那时无胜天子以偈赞叹说：

```
所愿无能坏，降伏魔怨力，
满足诸大愿，悦喻诸天众。
```
（大意：所发之愿无人能破坏，降伏魔怨之力，满足种种大愿，令诸天众喜悦。）

【按】“悦喻”之“喻”，明本作“豫”。

那时速营事天子以偈赞叹说：

```
如来速知法，亦疾净众生，
已见难见法，我礼速事者。
```
（大意：如来迅速了知法，也迅速清净众生，已见到难见之法，我礼敬速成其事的人。）

那时坚精进天子以偈赞叹说：

```
处处悉解脱，离痴无诸漏，
已度彼岸住，我礼坚固力。
```
（大意：在一切处都得解脱，远离愚痴，没有诸漏，已度到彼岸而安住，我礼敬具坚固力的人。）

【按】“已度”之“度”，圣、圣乙本作“渡”。

那时乐威仪天子以偈赞叹说：

```
离欲无诸过，除暗得漏尽，
为世胜福田，我礼应供者。
```
（大意：离欲而没有过失，除去黑暗，得以漏尽，是世间殊胜的福田，我礼敬应供者。）

那时善住天子以偈赞叹说：

```
世尊住正法，三界所供养，
一道安隐行，是故我敬礼。
```
（大意：世尊安住于正法，为三界所供养，以唯一之道安隐而行，所以我敬礼。）

那时无动天子以偈赞叹说：

```
佛如坚固山，不为风所动，
毁誉常平等，是故今敬礼。
```
（大意：佛如坚固之山，不被风所动摇，对毁谤与称誉常常平等，所以现在敬礼。）

那时得平等天子以偈赞叹说：

```
大雄色殊胜，具三十二相，
有大深智慧，我礼端正智。
```
（大意：大雄的色身殊胜，具足三十二相，有广大甚深的智慧，我礼敬相好端正的智者。）

那时深慧天子以偈赞叹说：

```
非身大身者，安住真如法，
显说于实际，世间无与等。
```
（大意：非身而为大身的人，安住于真如之法，显示宣说实际，世间无人与之相等。）

那时无等碍慧天子以偈赞叹说：

```
究竟同不二，勇健能伏魔，
不疑于深义，照法到彼岸。
```
（大意：究竟同于不二，勇健能降伏魔，对甚深之义没有疑惑，照见诸法，到达彼岸。）

【按】天子名“无等碍慧”，圣、圣乙本作“无量慧”。

那时喜意天子以偈赞叹说：

```
喜意本勇健，所学皆通利，
弃舍此三界，如蛇脱故皮。
```
（大意：喜意本来勇健，所学都通达无碍，弃舍这三界，如蛇脱去旧皮。）

那时定意天子以偈赞叹说：

```
譬如暗室灯，油尽故明灭，
智者如是灭，由闻佛法故。
```
（大意：譬如暗室中的灯，因油尽而光明熄灭，智者也像这样寂灭，是由于听闻佛法的缘故。）

#### 赞止观与诸法实相

那时住舍摩他天子以偈赞叹说：

```
如来普观察，为欲所结缚，
佛能断彼羂，由执智剑故。
```
（大意：如来普遍观察众生被欲所结缚，佛能断除那罗网，是由于执持智慧之剑的缘故。）

那时多舍摩他天子以偈赞叹说：

```
定心及定行，定威仪境界，
佛能灭烦恼，我礼伏怨者。
```
（大意：定心以及定行，定的威仪与境界，佛能灭除烦恼，我礼敬降伏怨敌的人。）

那时无畏舍摩他天子以偈赞叹说：

```
学佛舍摩他，菩萨得名称，
正定导引故，成就定心佛。
```
（大意：修学佛的舍摩他，菩萨得以有名称，由于正定的引导，成就定心之佛。）

那时定食天子以偈赞叹说：

```
寂灭一切法，大雄所演说，
解彼大智者，疾成于如来。
```
（大意：寂灭一切法，是大雄所演说的，理解此法的大智者，迅速成就如来。）

那时常观天子以偈赞叹说：

```
常观诸众生，悉随如来学，
获得胜菩提，满足大智慧。
```
（大意：常常观察众生，他们都随如来修学，获得殊胜菩提，圆满大智慧。）

那时持德天子以偈赞叹说：

```
如来智彼岸，菩萨修学故，
成世大威德，能见无量法。
```
（大意：如来的智慧彼岸，菩萨因为修学它，成为世间的大威德者，能见无量之法。）

那时造光天子以偈赞叹说：

```
彼得不思光，当获无垢乐，
照世如来所，得闻智境界。
```
（大意：他们得到不可思议之光，当获无垢之乐，在照耀世间的如来之所，得以听闻智慧的境界。）

那时无垢光天子以偈赞叹说：

```
诸法无分别，以善方便故，
修习如是智，故成妙丈夫。
```
（大意：诸法无分别，由于善巧方便，修习这样的智慧，所以成就妙丈夫。）

那时无所住天子以偈赞叹说：

```
无住无触娆，诸法无所觉，
不觉于自他，佛依真实见。
```
（大意：无住，无有触扰，诸法无所觉知，不觉知自与他，佛依真实而见。）

那时宅慧天子以偈赞叹说：

```
诸法无窟宅，导师如是见，
为众生说故，随顺取法相。
```
（大意：诸法没有窟宅，导师这样见，为了给众生宣说，随顺而取法相。）

那时无依慧天子以偈赞叹说：

```
诸法无所依，远离于彼此，
如来显真实，如掌庵罗果。
```
（大意：诸法无所依，远离彼与此，如来显示真实，如同掌中的庵罗果。）

那时虚空行天子以偈赞叹说：

```
知法如虚空，不生亦不灭，
佛见法如是，故能离世间。
```
（大意：了知法如虚空，不生也不灭，佛这样见法，所以能离开世间。）

那时无积聚天子以偈赞叹说：

```
无求亦无慢，无觉无不觉，
依真无自性，是佛见世间。
```
（大意：无求也无慢，无觉也无不觉，依真实而无自性，这是佛所见的世间。）

那时修慧天子以偈赞叹说：

```
犹如巧幻师，幻作种种事，
非实而见实，故佛无与等。
```
（大意：犹如善巧的幻师，幻作种种事物，并非真实而见为真实，所以佛无人可比。）

【按】“巧幻师”之“巧”，元、明、宫、圣、圣乙本作“工”。

那时喜悟天子以偈赞叹说：

```
譬如镜中像，虽见非真实，
佛如是见法，不迷于世间。
```
（大意：譬如镜中之像，虽然可见，却不真实，佛这样见法，对世间不迷惑。）

那时除疑天子以偈赞叹说：

```
佛如呼声响，诸法亦复然，
说闻俱非实，是佛见世间。
```
（大意：佛如呼喊的回响，诸法也是这样，说与听都不真实，这是佛所见的世间。）

那时无碍辩天子以偈赞叹说：

```
安住正法者，辩才深妙说，
世尊久证法，故能具足辩。
```
（大意：安住于正法的人，以辩才作深妙之说，世尊久已证法，所以能具足辩才。）

那时无障智天子以偈赞叹说：

```
依真无自性，一切法如是，
如来如实知，故能除暗冥。
```
（大意：依真实而无自性，一切法都是这样，如来如实了知，所以能除去暗冥。）

那时无忧天子以偈赞叹说：

```
无忧亦无恼，无静无娆浊，
诸法无垢染，佛见真实性。
```
（大意：无忧也无恼，无寂静也无扰浊，诸法没有垢染，佛见其真实之性。）

【按】“无静”之“静”，元、明本作“诤”。

那时行具足天子以偈赞叹说：

```
无来亦无去，诸法无所有，
如来真实见，如是为世说。
```
（大意：无来也无去，诸法无所有，如来真实地见，这样为世间宣说。）

那时胜慧天子以偈赞叹说：

```
无染亦无净，非愚亦非智，
诸法无能所，佛依如实见。
```
（大意：无染也无净，非愚也非智，诸法没有能与所，佛依如实而见。）

那时得无碍天子以偈赞叹说：

```
非明亦非暗，非色非非色，
非缚非解脱，佛慧如实见。
```
（大意：非明也非暗，非色也非非色，非缚也非解脱，佛以智慧如实而见。）

那时勇目天子以偈赞叹说：

```
非𢩁亦非遍，非有亦非无，
如梦受五欲，佛见法如实。
```
（大意：非局限也非周遍，非有也非无，如在梦中受五欲，佛如实见法。）

【按】“𢩁”字先前电子文本未能显示，今据《大正藏》补出；明、圣、圣乙本作“局”，今依文意作“局”（局限）解。“五欲”之“欲”，《大正藏》作“慾”，宋、元、明、圣、圣乙本作“欲”。

那时不瞬天子以偈赞叹说：

```
不生亦不灭，亦不住中间，
迷彼无智者，唯佛见真实。
```
（大意：不生也不灭，也不住于中间，那无智之人对此迷惑，唯有佛见到真实。）

【按】天子名“不瞬”之“瞬”，圣、圣乙本作“眴”。

那时住空天子以偈赞叹说：

```
非人非众生，非用非世财，
随说故有用，佛能真实见。
```
（大意：非人也非众生，非用也非世间财物，随言说才有作用，佛能真实而见。）

那时住无相天子以偈赞叹说：

```
所用一切法，彼皆悉无相，
诸法性相离，导师如是见。
```
（大意：所用的一切法，都是无相，诸法离于性与相，导师这样见。）

那时无愿天子以偈赞叹说：

```
因法空无相，以是不起愿，
假设有愿求，唯佛如实知。
```
（大意：因为法空无相，所以不起愿求，假设有所愿求，唯有佛如实了知。）

那时三昧流注天子以偈赞叹说：

```
已得解脱门，无有解脱者，
烦恼本亦无，佛见真实性。
```
（大意：已得解脱门，却没有解脱者，烦恼本来也无，佛见其真实之性。）

那时无毁天子以偈赞叹说：

```
舍弃一切恶，集诸功德聚，
故佛无毁訾，亦无毁呰事。
```
（大意：舍弃一切恶，集聚诸功德，所以佛无可毁訾，也没有可毁訾之事。）

【按】“毁呰”之“呰”，宋、元、明、宫、圣、圣乙本作“訾”。

那时电云天子以偈赞叹说：

```
犹如雷电云，降雨充大地，
佛注正法雨，充足诸群生。
```
（大意：犹如雷电之云，降雨充满大地，佛注下正法之雨，充足一切群生。）

那时不唐愿天子以偈赞叹说：

```
世尊辞无上，能转正法轮，
明达深法理，具足一切智。
```
（大意：世尊言辞无上，能转正法轮，明达甚深法理，具足一切智。）

【按】“能转”之“能”，圣、圣乙本作“愿”。

那时具智慧天子以偈赞叹说：

```
无生亦无灭，诸法自性尔，
如来善知故，亦复转教他。
```
（大意：无生也无灭，诸法自性如此，如来善于了知，也辗转教导他人。）

那时师子吼天子以偈赞叹说：

```
如来师子吼，演说空法时，
外道皆怖畏，如兽畏师子。
```
（大意：如来作师子吼，演说空法之时，外道都怖畏，如野兽畏惧狮子。）

#### 赞不放逸

那时业无放逸天子以偈赞叹说：

```
现前无放逸，佛修成菩提，
导师于正法，无逸到彼岸。
```
（大意：当下不放逸，佛修行而成就菩提，导师对于正法，不放逸而到彼岸。）

那时住无放逸天子以偈赞叹说：

```
安住不放逸，增益佛正法，
十力及余行，佛法不思议。
```
（大意：安住于不放逸，增益佛的正法，十力以及其余诸行，佛法不可思议。）

那时无放逸生天子以偈赞叹说：

```
会于无放逸，助道得生长，
以此济群生，佛亦自解脱。
```
（大意：会合于不放逸，助道之法得以生长，以此救济群生，佛自己也得解脱。）

【按】“生长”之“长”，宋、元、明本作“天”。

那时成无放逸天子以偈赞叹说：

```
无逸得成就，诸有依解脱，
声闻及菩萨，皆从如是学。
```
（大意：以不放逸得成就，于诸有得解脱，声闻以及菩萨，都从这样修学。）

那时不逸行天子以偈赞叹说：

```
所有诸佛子，常不放逸行，
能取一切智，善观世间故。
```
（大意：所有佛子，常行不放逸之行，能取得一切智，因为善于观察世间。）

那时无逸护天子以偈赞叹说：

```
佛修菩提时，守护不放逸，
逮得胜菩提，大悲庄严故。
```
（大意：佛修菩提时，守护不放逸，逮得殊胜菩提，以大悲为庄严。）

那时住不放逸天子以偈赞叹说：

```
若住不放逸，拣择一相法，
佛子大勇健，当得父遗财。
```
（大意：若安住于不放逸，简择一相之法，佛子大勇健，当得父亲的遗财。）

【按】“拣择”之“拣”，宫、圣、圣乙本作“简”。

那时乐不放逸天子以偈赞叹说：

```
勇健乐不逸，能破烦恼山，
是等以佛智，疾灭高慢聚。
```
（大意：勇健者乐于不放逸，能破烦恼之山，他们以佛的智慧，迅速灭除高慢之聚。）

那时坚持不放逸天子以偈赞叹说：

```
守护无放逸，昔求一切智，
阿僧祇亿劫，佛心无疲倦。
```
（大意：守护不放逸，往昔求一切智，经阿僧祇亿劫，佛心没有疲倦。）

#### 赞舍摩他

那时舍摩他现前天子以偈赞叹说：

```
法寂自性尔，是诸佛境界，
智者依彼住，能趣胜菩提。
```
（大意：法寂灭，自性如此，这是诸佛的境界，智者依此而住，能趣向殊胜菩提。）

那时依舍摩他天子以偈赞叹说：

```
诸佛依舍摩，依而不取著，
众生烦恼灭，如雨淹诸尘。
```
（大意：诸佛依于舍摩他，依止而不取著，令众生烦恼灭除，如雨淹没诸尘。）

那时住舍摩他天子以偈赞叹说：

```
诸佛住舍摩，不动如大山，
天魔不能坏，心寂故归命。
```
（大意：诸佛安住舍摩他，不动如大山，天魔不能破坏，因心寂静，所以归命。）

【按】“大山”之“大”，明本作“泰”。

那时舍摩他调伏天子以偈赞叹说：

```
舍摩所调伏，佛子无讥毁，
亿魔不能动，离欲如罗汉。
```
（大意：为舍摩他所调伏的佛子，无可讥毁，亿数魔众不能动摇，离欲如同罗汉。）

那时修舍摩他天子以偈赞叹说：

```
大雄昔修习，舍摩他定时，
无有知佛心，依何得禅定。
```
（大意：大雄往昔修习舍摩他定时，无人知道佛心依于什么而得禅定。）

那时舍摩他上首天子以偈赞叹说：

```
佛转正法轮，奋得舍摩他，
余法悉依彼，以是获菩提。
```
（大意：佛转正法轮，奋力而得舍摩他，其余诸法都依于它，因此获得菩提。）

【按】“奋得”之“奋”，宫、圣、圣乙本作“旧”。

那时留舍摩他天子以偈赞叹说：

```
佛说舍摩他，是为心笼网，
众生堕迷狱，佛教降伏心。
```
（大意：佛说舍摩他是心的笼网，众生堕入迷惑之狱，佛教导降伏其心。）

那时舍摩他境界天子以偈赞叹说：

```
诸佛妙境界，是为舍摩他，
修此得无碍，成就大导师。
```
（大意：诸佛的妙境界，就是舍摩他，修此得无碍，成就大导师。）

那时满足舍摩他天子以偈赞叹说：

```
以禅充满心，复更修集慧，
故佛得菩提，复能安众生。
```
（大意：以禅充满其心，又更修集智慧，所以佛得菩提，又能安顿众生。）

【按】“修集”之“集”，圣、圣乙本作“习”。

那时重舍摩他天子以偈赞叹说：

```
不见有余道，唯在佛法中，
获得大智慧，成就无上士。
```
（大意：不见有其余之道，唯在佛法之中，获得大智慧，成就无上士。）

#### 赞毗婆舍那

那时欣毗婆舍那天子以偈赞叹说：

```
佛依毘舍那，能视一切法，
菩萨随顺学，成就自然智。
```
（大意：佛依于毗婆舍那，能观视一切法，菩萨随顺修学，成就自然智。）

那时生毗婆舍那天子以偈赞叹说：

```
到智彼岸故，成就大医王，
显示四真谛，皆由毘舍那。
```
（大意：因为到达智慧的彼岸，成就大医王，显示四真谛，都是由于毗婆舍那。）

那时住毗婆舍那天子以偈赞叹说：

```
住毘婆舍那，如实知诸法，
勇健证菩提，能成大导师。
```
（大意：安住毗婆舍那，如实了知诸法，勇健者证得菩提，能成为大导师。）

那时修尽毗婆舍那天子以偈赞叹说：

```
大士以智慧，修习胜菩提，
不生识境界，成就大导师。
```
（大意：大士以智慧修习殊胜菩提，不生识的境界，成就大导师。）

那时乐毗婆舍那天子以偈赞叹说：

```
智者依真实，观察如此法，
能获无等果，成佛号导师。
```
（大意：智者依于真实，观察这样的法，能获得无等之果，成佛号为导师。）

那时勤习毗婆舍那天子以偈赞叹说：

```
勤修智慧故，能立诸苦行，
彼成难降伏，不为邪道坏。
```
（大意：因为勤修智慧，能立种种苦行，他们成为难以降伏的人，不被邪道所破坏。）

那时毗婆舍那天子以偈赞叹说：

```
所有诸佛子，观察法相故，
彼知法相已，成就调御师。
```
（大意：所有佛子，因为观察法相，他们了知法相之后，成就调御师。）

【按】“彼知”，明本作“知彼”。“法相已”之“相”，圣、圣乙本作“想”。

那时修毗婆舍那天子以偈赞叹说：

```
如来于长夜，修习胜智慧，
能成一切智，度脱无量众。
```
（大意：如来在长夜中修习殊胜智慧，能成就一切智，度脱无量众生。）

那时殊胜行天子以偈赞叹说：

```
佛修一切智，成就大导师，
以法济世间，越渡驶流水。
```
（大意：佛修一切智，成就大导师，以法救济世间，越渡湍急的河流。）

【按】“驶流”之“驶”，《大正藏》作“駃”，宋、明、宫本作“驶”，元本作“駚”，今依CBETA作“驶”。

那时住毗婆舍那天子以偈赞叹说：

```
住毘婆舍那，观察一切法，
出生诸佛法，地生尼拘树。
```
（大意：安住毗婆舍那，观察一切法，出生诸佛法，如大地生出尼拘树。）

那时持毗婆舍那天子以偈赞叹说：

```
世尊诸佛子，摄受胜智慧，
得上菩提已，能度诸众生。
```
（大意：世尊的诸佛子，摄受殊胜智慧，得无上菩提之后，能度化众生。）

那时游戏毗婆舍那天子以偈赞叹说：

```
游戏于诸法，得佛无所畏，
无怯亦无怖，胜智大牟尼。
```
（大意：游戏于诸法，得佛的无所畏，无怯也无怖，是殊胜智慧的大牟尼。）

那时随顺毗婆舍那天子以偈赞叹说：

```
大雄于诸法，皆会毘舍那，
观察无自性，是即佛菩提。
```
（大意：大雄对于诸法，都会合于毗婆舍那，观察其无自性，这就是佛的菩提。）

那时毗婆舍那坚固天子以偈赞叹说：

```
诸佛智坚固，于法无所畏，
观见群生苦，能起大悲心。
```
（大意：诸佛智慧坚固，对法无所畏惧，观见群生之苦，能生起大悲心。）

那时毗婆舍那天子以偈赞叹说：

```
以智趣菩提，有智能善学，
彼得胜菩提，度脱诸众生。
```
（大意：以智慧趣向菩提，有智者能善于修学，他们得殊胜菩提，度脱众生。）

#### 赞空

那时修空天子以偈赞叹说：

```
修习于空法，智者悟菩提，
能坏诸牢狱，亦度结缚者。
```
（大意：修习空法，智者觉悟菩提，能破坏种种牢狱，也度脱被结缚的人。）

【按】“悟菩提”之“悟”，宋、宫、圣、圣乙本作“寤”。

那时解空天子以偈赞叹说：

```
世尊解空故，不见于身命，
无缘无自性，依是为世说。
```
（大意：世尊因为理解空，不见有身与命，无缘、无自性，依此为世间宣说。）

那时空境界天子以偈赞叹说：

```
一切佛境界，诸法性自空，
大雄于中学，愍济众生故。
```
（大意：一切佛的境界，诸法自性空，大雄于其中修学，是为了怜愍救济众生。）

那时信空天子以偈赞叹说：

```
如来离臭秽，怖畏亦久度，
不著于诸法，如风无所依。
```
（大意：如来远离臭秽，也早已度脱怖畏，不执著于诸法，如风无所依止。）

【按】“久度”之“度”，圣、圣乙本作“灭”。

那时乐空天子以偈赞叹说：

```
修习空法者，能乐佛境界，
彼即供养佛，亦成无上供。
```
（大意：修习空法的人，能乐于佛的境界，他就是供养佛，也成就无上的供养。）

那时空建立天子以偈赞叹说：

```
修习空法故，导师得建立，
通达空法已，成就世间亲。
```
（大意：因为修习空法，导师得以建立，通达空法之后，成就世间之亲。）

那时向空天子以偈赞叹说：

```
佛知无一法，不是涅槃者，
诸法趣涅槃，此是佛菩提。
```
（大意：佛知道没有一法不是涅槃，诸法趣向涅槃，这就是佛的菩提。）

【按】“此是”之“是”，圣、圣乙本作“事”。

那时空成就天子以偈赞叹说：

```
已得空寂定，佛子得成就，
彼等供养佛，是修空法者。
```
（大意：已得空寂之定，佛子得以成就，他们供养佛，是修习空法的人。）

那时趣空天子以偈赞叹说：

```
所有归空者，有智非愚痴，
无著断烦恼，离垢得菩提。
```
（大意：所有归于空的人，有智慧而不愚痴，无所执著，断除烦恼，离垢而得菩提。）

那时满足空天子以偈赞叹说：

```
佛法得满足，成就难降伏，
所有修空者，能利益世间。
```
（大意：佛法得以圆满，成就难以降伏，所有修习空的人，能利益世间。）

【按】“利益”之“益”，圣、圣乙本作“诸”。

那时住空天子以偈赞叹说：

```
安住佛法中，能修空智者，
无量诸魔众，不能动彼等。
```
（大意：安住于佛法中，能修空智的人，无量的魔众都不能动摇他们。）

#### 赞无相

那时乐无相天子以偈赞叹说：

```
喜乐于无相，不著有相中，
拣择诸法已，佛能超世间。
```
（大意：喜乐于无相，不执著于有相之中，简择诸法之后，佛能超越世间。）

【按】“拣择”之“拣”，宋、元、明、宫、圣、圣乙本作“简”。

那时无相行天子以偈赞叹说：

```
习行无相时，清净寂灭行，
离相众生等，魔不知彼趣。
```
（大意：习行无相时，清净寂灭而行，离相的众生等，魔不知道他们所趣向之处。）

那时无相境界天子以偈赞叹说：

```
无相佛境界，如来于中修，
无相难证解，我礼定行者。
```
（大意：无相是佛的境界，如来在其中修习，无相难以证解，我礼敬修行禅定的人。）

那时渴乐无相天子以偈赞叹说：

```
此等一切众，渴乐无相法，
悕求父资财，供养天人师。
```
（大意：这一切大众，渴乐无相之法，希求父亲的资财，供养天人之师。）

那时修无相行天子以偈赞叹说：

```
如来于无相，昼夜常修行，
天人及鬼神，不知佛所趣。
```
（大意：如来对于无相，昼夜常常修行，天、人以及鬼神，都不知佛所趣向之处。）

那时无相解脱天子以偈赞叹说：

```
大雄住无相，思量一切法，
导师所修学，是故我敬礼。
```
（大意：大雄安住无相，思量一切法，这是导师所修学的，所以我敬礼。）

那时无相游戏天子以偈赞叹说：

```
大慈现游戏，常依无相法，
成熟众生故，住于佛智中。
```
（大意：大慈者示现游戏，常依于无相之法，为了成熟众生，安住于佛智之中。）

那时无相成就天子以偈赞叹说：

```
善修离相者，能得佛菩提，
亦能供养佛，如子恭敬父。
```
（大意：善修离相的人，能得佛菩提，也能供养佛，如儿子恭敬父亲。）

那时久乐无相天子以偈赞叹说：

```
彼爱佛正法，即是众生塔，
所有弃相者，得住于师处。
```
（大意：他们爱乐佛的正法，就是众生的塔庙，所有弃舍相的人，得以安住于导师之处。）

那时无相道天子以偈赞叹说：

```
众生诸所归，依道得济度，
无著寂灭行，如来最无上。
```
（大意：众生所归向的，是依道而得济度，无著寂灭之行，如来最为无上。）

【按】“众生”之“生”，圣、圣乙本作“主”。

那时信无相天子以偈赞叹说：

```
信解无相者，寂灭离诸怨，
我礼一切佛，自度度他者。
```
（大意：信解无相的人，寂灭而离诸怨敌，我礼敬一切佛，自度又度他的人。）

#### 赞无愿

那时趣无愿天子以偈赞叹说：

```
世尊所有愿，求之不可得，
彼等离所作，是佛出世间。
```
（大意：世尊所有的愿，求之不可得，他们远离所作，这是佛出于世间。）

那时修无愿天子以偈赞叹说：

```
于有不起愿，修行寂灭心，
断除渴爱缚，是佛离世间。
```
（大意：对于有不起愿求，修行寂灭之心，断除渴爱之缚，这是佛离于世间。）

那时无愿生天子以偈赞叹说：

```
彼得大精进，于有离爱染，
是等如来子，悉礼自己父。
```
（大意：他们得大精进，对于有远离爱染，这些如来之子，都礼敬自己的父亲。）

那时从无愿生天子以偈赞叹说：

```
彼等不起愿，于有而坏有，
所能断爱者，佛子离讥毁。
```
（大意：他们不起愿求，于有之中破坏有，能断除爱的人，是佛子，远离讥毁。）

【按】“断爱者”之“者”，宋、元、明、圣、圣乙本作“缚”。

那时无愿解脱天子以偈赞叹说：

```
无愿得解脱，不求离诸缚，
放舍不起愿，佛子持威德。
```
（大意：以无愿得解脱，不求离开诸缚，放舍而不起愿，佛子持有威德。）

那时出无愿天子以偈赞叹说：

```
出离忧旷野，拔断爱染根，
彼等礼如来，得除饥渴者。
```
（大意：出离忧愁的旷野，拔断爱染之根，他们礼敬如来，是得以除去饥渴的人。）

【按】“爱染”之“染”，圣乙本作“深”。

那时必定无愿天子以偈赞叹说：

```
善知有苦者，亦知世乐妄，
佛是彼等父，彼为导师子。
```
（大意：善知有是苦的人，也知世间之乐是虚妄，佛是他们的父亲，他们是导师之子。）

那时向无愿天子以偈赞叹说：

```
于有见苦者，彼人得调伏，
我礼善调伏，破有调御师。
```
（大意：在有之中见到苦的人，此人得以调伏，我礼敬善于调伏、破除诸有的调御师。）

那时超无愿天子以偈赞叹说：

```
超度有旷野，得住安隐处，
普礼大导师，已伏烦恼怨。
```
（大意：超度有的旷野，得以安住于安隐之处，普礼大导师，他已降伏烦恼怨敌。）

那时被无愿铠天子以偈赞叹说：

```
战胜破怨敌，最强难伏者，
降诸魔众已，勇健不求有。
```
（大意：战胜而破怨敌，最强而难以降伏，降伏魔众之后，勇健者不求有。）

那时无愿力天子以偈赞叹说：

```
大力于解脱，能断诸魔缚，
是诸佛子等，观魔如网草。
```
（大意：以大力于解脱，能断诸魔之缚，这些佛子，看魔如同细草。）

【按】“网草”之“网”，元、明、宫、圣、圣乙本作“细”，今依文意从之。

#### 赞观身

那时观身天子以偈赞叹说：

```
诸有观此身，彼能乐佛法，
无身无作者，是等随顺法。
```
（大意：凡是观察此身的人，他们能乐于佛法，无身也无作者，他们随顺于法。）

那时念身天子以偈赞叹说：

```
所有念此身，秽恶不清净，
已知身如实，敬礼大导师。
```
（大意：所有忆念此身的人，见其秽恶不清净，已如实了知身，敬礼大导师。）

那时厌患身天子以偈赞叹说：

```
系念于内身，观见不净相，
彼得离身苦，调伏故敬礼。
```
（大意：系念于内身，观见不净之相，他们得以离开身苦，因为得到调伏，所以敬礼。）

那时舍身天子以偈赞叹说：

```
舍此脓血身，如蛇脱故皮，
敬礼于非身，是大如来身。
```
（大意：舍弃这脓血之身，如蛇脱去旧皮，敬礼于非身，这是伟大的如来之身。）

那时厌恶身天子以偈赞叹说：

```
厌恶脓血身，不净甚臭秽，
舍此不净身，归敬天人师。
```
（大意：厌恶脓血之身，不净而甚为臭秽，舍弃这不净之身，归敬天人之师。）

【按】“不净身”之“身”，宫、圣、圣乙本作“满”。

那时患身疲劳天子以偈赞叹说：

```
所患烂坏身，佛子求清净，
彼得悉礼佛，所修正法身。
```
（大意：所厌患的是烂坏之身，佛子求清净，他们得以都礼敬佛所修成的正法之身。）

【按】“彼得”之“得”，宋、元、明、宫本作“等”。

那时怖身天子以偈赞叹说：

```
观知此四大，犹如恶毒蛇，
彼等超度身，敬礼大导师。
```
（大意：观察了知这四大，犹如恶毒之蛇，他们超度了身，敬礼大导师。）

【按】“观知”之“知”，宫本作“如”。

那时见身过天子以偈赞叹说：

```
现前见身过，是得智慧眼，
悉照此三有，智者依佛慧。
```
（大意：当下见到身的过患，这是得到了智慧之眼，普照这三有，智者依于佛的智慧。）

那时不乐身天子以偈赞叹说：

```
所有不乐身，不依法相住，
无著于诸结，彼等礼调御。
```
（大意：所有不乐于身的人，不依法相而住，对诸结无所执著，他们礼敬调御师。）

#### 赞断有

那时于有起怨想天子以偈赞叹说：

```
于有如怨想，修观坏诸有，
佛子如是学，智生悟菩提。
```
（大意：对于有作怨敌之想，修观而破坏诸有，佛子这样修学，智慧生起，觉悟菩提。）

那时坏有天子以偈赞叹说：

```
于有见过已，能知灭无畏，
佛子勤求道，获得父遗财。
```
（大意：对于有见到过患之后，能知灭而无所畏，佛子勤求于道，获得父亲的遗财。）

那时弃有天子以偈赞叹说：

```
所修弃诸有，乐住大涅槃，
心净离众结，我礼大导师。
```
（大意：所修的是弃舍诸有，乐于安住大涅槃，心净而离众结，我礼敬大导师。）

那时断有天子以偈赞叹说：

```
断除有根本，照达三千界，
世尊诸子等，所学悉通利。
```
（大意：断除有的根本，照达三千世界，世尊的诸子等，所学都通达无碍。）

那时度有天子以偈赞叹说：

```
已度于有海，济拔孤独者，
于此三界中，彼等不在数。
```
（大意：已度过有之海，济拔孤独的人，在这三界之中，他们不在其数。）

那时破有天子以偈赞叹说：

```
佛子修道者，能破于三有，
彼是供养佛，以化众生故。
```
（大意：修道的佛子，能破除三有，他们是在供养佛，因为教化众生。）

那时于有解脱天子以偈赞叹说：

```
有流得解脱，究竟住后际，
大雄出世间，敬礼断有者。
```
（大意：从有的流中得到解脱，究竟住于后际，大雄出离世间，敬礼断除有的人。）

那时灭有天子以偈赞叹说：

```
灭除有根本，度有到彼岸，
已断于后际，世间无如佛。
```
（大意：灭除有的根本，度过有而到彼岸，已断除后际，世间无人如佛。）

那时住后际天子以偈赞叹说：

```
如来后际住，寂灭到彼岸，
度有一切智，觉了未寤者。
```
（大意：如来住于后际，寂灭而到彼岸，度过有、具一切智者，觉悟未觉悟的人。）

【按】“未寤”之“寤”，宋、元、明、宫本作“悟”。

那时于有住后际天子以偈赞叹说：

```
佛于后际住，说彼三有因，
不见有诸结，后能不生有。
```
（大意：佛住于后际，宣说那三有之因，不见有诸结，以后能不再生有。）

那时得灭有天子以偈赞叹说：

```
知有空寂已，能解三有因，
精进不怯弱，我礼平等者。
```
（大意：了知有是空寂之后，能理解三有之因，精进而不怯弱，我礼敬平等者。）

那时度有到彼岸天子以偈赞叹说：

```
度有到彼岸，拔除有根源，
救度诸群生，导师愍一切。
```
（大意：度过有而到彼岸，拔除有的根源，救度群生，导师怜愍一切。）

#### 赞观受

那时于受无恼天子以偈赞叹说：

```
于受无贡高，无思亦无虑，
禅事悉知解，观受如水泡。
```
（大意：对于受没有贡高，无思也无虑，对禅定之事都了知，观受如同水泡。）

那时解受天子以偈赞叹说：

```
如来知诸受，本来无自性，
凡夫所著处，如梦受欲乐。
```
（大意：如来了知诸受本来无自性，是凡夫所执著之处，如在梦中享受欲乐。）

那时观受天子以偈赞叹说：

```
有智观诸受，能取于善道，
不生未来受，如是见导师。
```
（大意：有智者观察诸受，能取于善道，不生未来之受，这样见到导师。）

那时离受天子以偈赞叹说：

```
受及所受者，佛见无自性，
能即为众说，难知甚深句。
```
（大意：受以及受者，佛见其无自性，能即为大众宣说难知的甚深之句。）

那时决定知受天子以偈赞叹说：

```
诸受但世谛，第一义中无，
如来说真实，除断世间疑。
```
（大意：诸受只是世俗谛，在第一义中没有，如来宣说真实，除断世间的疑惑。）

那时善解受天子以偈赞叹说：

```
世尊善知受，犹如空中云，
谁迷无智者，独佛能实解。
```
（大意：世尊善知诸受犹如空中之云，那无智之人迷惑，唯独佛能如实理解。）

那时通达受天子以偈赞叹说：

```
如来达诸受，解受到彼岸，
知受无我所，说法最为上。
```
（大意：如来通达诸受，理解受而到彼岸，知受无有我所，说法最为无上。）

【按】“知受”之“知”，圣、圣乙本作“如”。

那时度受天子以偈赞叹说：

```
世尊已久度，最难三受海，
舍离恶污泥，佛智号无上。
```
（大意：世尊早已度过最难的三受之海，舍离恶浊的污泥，佛智号为无上。）

那时断受天子以偈赞叹说：

```
导师于诸受，了知出世间，
超离污染泥，不著于诸有。
```
（大意：导师对于诸受，了知而出离世间，超离污染的泥淖，不执著于诸有。）

那时思受天子以偈赞叹说：

```
如来念诸受，由受苦世间，
众生烦恼缚，佛知真实性。
```
（大意：如来念诸受，世间由于受而苦，众生被烦恼所缚，佛知其真实之性。）

【按】“佛知”之“知”，宋、元、明、宫本作“智”。

#### 赞观心

那时解心天子以偈赞叹说：

```
佛心伏烦恼，亦降诸魔怨，
依真无所破，故佛号牟尼。
```
（大意：佛心降伏烦恼，也降伏魔怨，依真实而无所破，所以佛号为牟尼。）

那时识心天子以偈赞叹说：

```
佛久识心相，犹如巧幻师，
幻作种种像，故佛号应供。
```
（大意：佛久已识知心相，犹如善巧的幻师，幻作种种影像，所以佛号为应供。）

【按】“应供”之“供”，圣、圣乙本作“作”。

那时心行天子以偈赞叹说：

```
大雄已修行，能断心所缘，
亿劫阿僧祇，心性不可得。
```
（大意：大雄已经修行，能断心的所缘，经亿数阿僧祇劫，心性不可得。）

那时摄心天子以偈赞叹说：

```
躁动难调伏，无体而住窟，
佛断速疾心，故能受胜供。
```
（大意：躁动而难以调伏，无体而住于窟中，佛断除这迅疾之心，所以能受殊胜的供养。）

那时拣择心天子以偈赞叹说：

```
佛已拣择心，众生为心缚，
佛能真实知，如幻师教子。
```
（大意：佛已简择心，众生被心所缚，佛能真实了知，如幻师教导弟子。）

那时修心境界天子以偈赞叹说：

```
所行心境界，导师决定见，
如梦受五欲，迷彼愚痴者。
```
（大意：所行的心境界，导师决定地见到，如在梦中受五欲，那愚痴之人对此迷惑。）

那时心自在天子以偈赞叹说：

```
调伏作业已，心无分别事，
如来见心相，世间所不知。
```
（大意：调伏作业之后，心中没有分别之事，如来见到心相，这是世间所不知的。）

那时心勇天子以偈赞叹说：

```
所言心勇者，能破魔军众，
以心见心者，观心不疲倦。
```
（大意：所说的心勇者，能破魔的军众，以心见心的人，观心而不疲倦。）

那时建立天子以偈赞叹说：

```
如来观众生，于法建立者，
以心能知心，彼则真佛子。
```
（大意：如来观察众生中于法得以建立的人，以心能知心，他们就是真佛子。）

那时定心天子以偈赞叹说：

```
所有伏心者，彼能行寂灭，
是等离诸缚，不为魔所恼。
```
（大意：所有降伏其心的人，他们能行寂灭，这些人远离诸缚，不被魔所恼乱。）

那时柔软心天子以偈赞叹说：

```
勇健柔软心，调伏众生辈，
所乐佛法者，不著于诸欲。
```
（大意：勇健者具柔软之心，调伏众生，乐于佛法的人，不执著于诸欲。）

那时净心天子以偈赞叹说：

```
善心乐清净，审思而作业，
闻佛正法已，无疑于深义。
```
（大意：善心乐于清净，审慎思虑而后作业，听闻佛的正法之后，对甚深之义没有疑惑。）

那时住法天子以偈赞叹说：

```
所有向法心，深乐不退没，
彼是真佛子，已到调伏地。
```
（大意：所有向法之心，深深爱乐而不退没，他们是真佛子，已到达调伏之地。）

#### 赞法界

那时思惟法天子以偈赞叹说：

```
思惟于法界，境界无非一，
一切法界净，诸佛所学处。
```
（大意：思惟法界，境界无不是一，一切法界清净，是诸佛所学之处。）

那时法界建立天子以偈赞叹说：

```
法界所建立，是大慈悲心，
能住一相中，彼是真佛子。
```
（大意：法界所建立的，是大慈悲心，能安住于一相之中，他们是真佛子。）

那时法界境界天子以偈赞叹说：

```
世尊说法界，是为诸佛土，
大士所行处，此智不思议。
```
（大意：世尊说法界，就是诸佛之土，是大士所行之处，这智慧不可思议。）

那时法界生天子以偈赞叹说：

```
法界所出生，是智难思议，
不疑深佛法，亦知诸根性。
```
（大意：从法界所出生的，是难以思议的智慧，对甚深佛法不疑，也知众生诸根之性。）

那时入法界天子以偈赞叹说：

```
入深法界者，解法无与等，
是力不思议，亦得诸妙愿。
```
（大意：进入甚深法界的人，理解法无人能比，这力量不可思议，也得到种种妙愿。）

那时法界无畏天子以偈赞叹说：

```
已得无畏法，是住安隐处，
所有辩才力，无能与等者。
```
（大意：已得无畏之法，是安住于安隐之处，所有的辩才之力，无人能与之相等。）

那时善解法界天子以偈赞叹说：

```
如来解法界，亦达一切智，
示现法界相，如掌庵罗果。
```
（大意：如来理解法界，也通达一切智，示现法界之相，如同掌中的庵罗果。）

那时住法界天子以偈赞叹说：

```
世尊住法界，见法真实性，
不依亦不离，不取复不舍。
```
（大意：世尊安住法界，见到法的真实之性，不依也不离，不取也不舍。）

那时法界行天子以偈赞叹说：

```
如来行法界，寂静如虚空，
境界大牟尼，敬礼慈悲父。
```
（大意：如来行于法界，寂静如虚空，以此为境界的大牟尼，敬礼慈悲之父。）

那时归法界天子以偈赞叹说：

```
随其种种门，世尊说法界，
彼彼法门中，无心亦无色。
```
（大意：随着种种法门，世尊宣说法界，在那一一法门之中，无心也无色。）

那时法界精进天子以偈赞叹说：

```
世尊说精进，能知于法界，
因修精进故，觉智到彼岸。
```
（大意：世尊宣说精进，能知法界，因为修习精进，觉悟的智慧到达彼岸。）

那时法界充满天子以偈赞叹说：

```
大慈以正法，充饱诸世间，
能知法界者，彼得住菩提。
```
（大意：大慈者以正法充饱诸世间，能知法界的人，他们得以安住菩提。）

那时彻法界天子以偈赞叹说：

```
世尊彻深法，故能观世间，
法界悉知已，我礼天人师。
```
（大意：世尊彻见甚深之法，所以能观察世间，对法界都了知之后，我礼敬天人之师。）

#### 赞处非处

那时住智处天子以偈赞叹说：

```
是处人中上，如来智所得，
法界及十方，导师所行处。
```
（大意：这处是人中之上、如来以智慧所得的，法界以及十方，是导师所行之处。）

那时住处天子以偈赞叹说：

```
法界是住处，众智所行道，
诸有一切法，悉作一相解。
```
（大意：法界是安住之处，是众智所行之道，诸有的一切法，都作一相理解。）

那时知处天子以偈赞叹说：

```
世尊知法界，已作一相修，
众生诸欲性，佛亦悉了知。
```
（大意：世尊了知法界，已作一相而修，众生的种种欲乐与根性，佛也都了知。）

那时出处天子以偈赞叹说：

```
能取一切智，是谓诸佛子，
于此法界处，惟智所能知。
```
（大意：能取得一切智的，名为诸佛子，在这法界之处，唯有智慧所能了知。）

【按】“惟智”之“惟”，宋、元、明、宫、圣、圣乙本作“唯”。

那时学处天子以偈赞叹说：

```
所习法界者，安住菩提中，
得达自然处，疾成于如来。
```
（大意：所修习法界的人，安住于菩提之中，得以到达自然之处，迅速成就如来。）

那时非处学天子以偈赞叹说：

```
所见非处者，能乐如来教，
千亿众魔军，不能迷惑彼。
```
（大意：所见为非处的人，能乐于如来之教，千亿魔军不能迷惑他们。）

那时知非处天子以偈赞叹说：

```
所有知非处，智者得欣喜，
我等修菩提，亿魔不能动。
```
（大意：所有了知非处的智者得以欢喜，我们修习菩提，亿数魔众不能动摇。）

那时深密处天子以偈赞叹说：

```
善学深智处，安住正法中，
能乘魔波旬，如车驾调马。
```
（大意：善于修学甚深智慧之处，安住于正法之中，能驾驭魔波旬，如以车驾驭调顺之马。）

那时善非处天子以偈赞叹说：

```
非处善法界，习学于一相，
若魔能恼者，佛说无是处。
```
（大意：非处是善法界，修学于一相，若说魔能恼乱他们，佛说没有这个道理。）

那时住处天子以偈赞叹说：

```
是处及非处，示现愚痴者，
如来自觉已，复为众生说。
```
（大意：是处以及非处，示现给愚痴之人，如来自己觉悟之后，又为众生宣说。）

【按】“自觉”之“觉”，宋、宫本作“学”。

#### 赞业报智力

那时善取天子以偈赞叹说：

```
彼因所取事，及昔所作业，
彼因修业处，世尊皆悉知。
```
（大意：那因所取之事，以及往昔所作之业，那因与修业之处，世尊都了知。）

【按】“皆悉知”之“皆”，宫本作“悉”。

那时巧业天子以偈赞叹说：

```
贪欲及恚痴，佛亦知因业，
为因为业者，如来悉知彼。
```
（大意：贪欲以及瞋恚、愚痴，佛也知其因与业，作为因、作为业的，如来都了知。）

那时知当来天子以偈赞叹说：

```
知彼当来世，众生所作业，
彼因所作事，是处佛悉知。
```
（大意：知道那未来世众生所作之业，那因所作之事，这些处，佛都了知。）

那时思现在天子以偈赞叹说：

```
普及十方界，众生业与因，
处及因业事，导师悉了知。
```
（大意：普及十方世界，众生的业与因，处以及因业之事，导师都了知。）

那时力境界天子以偈赞叹说：

```
若业若与因，处所及出生，
如来无不知，故称天人师。
```
（大意：无论是业，或是与因，处所以及出生，如来无不了知，所以称为天人之师。）

那时乐力天子以偈赞叹说：

```
因业及处所，三世果报中，
彼有所作事，如来皆悉知。
```
（大意：因、业以及处所，在三世果报之中，他们所作之事，如来都了知。）

那时力主天子以偈赞叹说：

```
因业所作事，报因及因缘，
处所性自离，是佛无有等。
```
（大意：因业所作之事，果报之因以及因缘，处所的本性自离，所以佛无与等者。）

那时力吉祥天子以偈赞叹说：

```
因业所作事，处因缘世谛，
所受用果报，佛知彼悉空。
```
（大意：因业所作之事，处、因缘与世俗谛，所受用的果报，佛知道这些都是空。）

那时力悦天子以偈赞叹说：

```
因业所作事，俗谛因缘处，
佛自悉知已，说彼无自性。
```
（大意：因业所作之事，俗谛的因缘与处，佛自己都了知之后，宣说它们无自性。）

那时力游戏天子以偈赞叹说：

```
因缘所作事，处因缘世谛，
不由自他生，佛知从缘起。
```
（大意：因缘所作之事，处、因缘与世俗谛，不是由自生或他生，佛知道它们从缘而起。）
