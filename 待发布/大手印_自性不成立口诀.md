# 自性不成立口诀

龙树阿阇黎 造

## 题解

本篇出自德格版丹珠尔续部（རྒྱུད་འགྲེལ།）ཟི 函第14a叶第2行至第14b叶第1行，东北目录编号 D2382。篇幅极短，只有三十六句偈颂加一行跋语，所以把藏文原文全部保留在代码块中，每一段后附汉译，疑难之处另以【按】说明。

梵文题名：Svabhāva-asiddhi-nāma-upadeśa（སྭ་བྷཱ་བ་ཨ་སིདྡྷི་ནཱ་མ་ཨུ་པ་དེ་ཤ）。

藏文题名：རང་བཞིན་གྲུབ་པ་མེད་པའི་གཞིའི་མན་ངག（自性不成立之基的口诀）。

【按】梵文题名只说“名为自性不成立的口诀”，藏文题名却多出“基”（གཞི）一字，作“自性不成立之基的口诀”。两种题名不一致，原因未详，可能是藏译者增字以显明本篇所讲的是“万法自性不成立”这一根本，也可能梵文题名在流传中脱落一字。本译题名取通行简称《自性不成立口诀》，跋语中则照藏文译出“之基”二字，以存原貌。

【按】跋语只说“阿阇黎龙树所造”，没有记载译者，也没有记载校订者，这在丹珠尔续部小篇中并不少见，但也意味着本篇的译出年代与来历无从由跋语考定。藏传传统一般把造中观论的龙树与密续部、成就者传承中的龙树视为同一人，现代学界则多主张二者有别。本篇属于道歌式的密乘口诀，作者究竟是哪一位龙树，这里不作判定，只依原文称“阿阇黎龙树”“圣者龙树”。

【按】本篇通篇用“殿堂—鸽子”的譬喻：殿堂喻身体，鸽子喻住在身中的心识，殿堂坍毁喻死亡，鸽子离去喻心识出离身体。这一读法是依偈颂自身的脉络，以及藏地常见的“身如旅舍、识如过客”一类譬喻推定的，原文本身并没有明白点破，只有最后一句“这是心的幻化”作了总结。读者可以把本篇的重心理解为：身体再怎么修葺护持也终将坍毁，心识再怎么寻觅也找不到可以常住的处所，而殿堂、鸽子、坍毁、离去，统统只是心的幻化，没有一样是自性成立的——这正好扣合题名“自性不成立”。

## 礼敬

```
རྗེ་བཙུན་སྒྲོལ་མ་ལ་ཕྱག་འཚལ་ལོ། །
```

敬礼至尊度母！

【按】这句礼敬位于题名之后、正文之前，按丹珠尔通例多半是藏译者所加的译礼，而不是作者本人的礼敬偈。但本篇没有译者跋语，无法确证，故仍照录。

## 正文

### 第一段：一柱九门的殿堂

```
ཨེ་མ་ཇི་ལྟར་མཁས་པ་ཡིས། །ལྷ་ཁང་འདི་ནི་བཞེངས་པར་བྱ། །
ཀ་བ་གཅིག་ལ་སྒོ་དགུ་པའི། །ཤིང་མཁན་གང་གིས་ཁང་པར་བྱས། །
```

奇哉！这座殿堂，是何等善巧的人所建造的呢？只有一根柱子，却开了九扇门户——这样的屋宇，到底是哪一位木匠把它营造出来的？

【按】“ཨེ་མ”是惊叹词，译为“奇哉”。第二句“བཞེངས་པར་བྱ”字面是“应当建造”“将要建造”的语气，与下文“是谁造成的”的问句口气不太吻合；这里依全段文意，读作感叹“这殿堂是怎样善巧地建成的”。若严格照字面，也可以读成“奇哉！应当如善巧者那样建造这座殿堂”，那么前两句就成了劝勉之辞，后两句才是发问。两种读法在法义上差别不大，都在引出“身体这座殿堂由谁造成”的问题，特此注明。

【按】“一根柱子、九扇门户”，按一般密乘与医方明的说法，“九门”指身体的九窍（两眼、两耳、两鼻孔、口、大小便道），“一柱”则可能指脊柱，也可能指中脉。原文未说明，这里只照字面译出。至于“木匠”，依佛法通义可以理解为造作此身的业与烦恼，但这同样是推解，原文并没有说。

### 第二段：鸽子何处寻栖

```
ཇི་ལྟར་ནམ་ཞིག་ལྷ་ཁང་དེར། །འཇིག་པར་འགྱུར་བ་མི་ཤེས་ན། །
ལྷ་ཁང་ནང་ནས་ཕུག་རོན་ནི། །གནས་ནི་གང་དུ་ཚོལ་བར་བྱེད། །
```

那座殿堂究竟哪一天会坍毁，既然谁也不知道，那么住在殿堂里面的那只鸽子，又要到哪里去寻找它的栖身之处呢？

【按】“ཇི་ལྟར་ནམ་ཞིག”直译是“如何、某时”，合起来表示“究竟在什么时候”，强调死期不定。下文这两句反复出现，作叠句（副歌）用，以下各段照此译出，不再逐一说明。

### 第三段：修葺护持也挡不住虫蛀

```
ཇི་ལྟར་ནམ་ཞིག་ལྷ་ཁང་དེར། །འཇིག་པར་འགྱུར་བ་མི་ཤེས་ན། །
གང་གིས་གཡོགས་ཤིང་ཞལ་ཞལ་བྱས། །སྒོ་རབ་བསྡམས་པ་དེ་ལྟར་ན། །
ཀ་བ་སྲིན་གྱིས་ཟོས་པ་ན། །ཇི་ལྟར་ནམ་ཞིག་ལྷ་ཁང་དེར། །
འཇིག་པར་འགྱུར་བ་མི་ཤེས་སོ། །
```

那座殿堂哪一天会坍毁，既然无从知晓——不管是谁替它盖好屋顶、抹好泥灰，又把各扇门户紧紧关上，像这样严加护持，可是一旦柱子被虫蛀蚀，那座殿堂究竟哪一天会坍毁，仍旧没有人能知道。

【按】“གཡོགས”是覆盖、盖顶；“ཞལ་ཞལ”是墙壁上涂抹的泥灰、灰浆。“སྲིན”在这里应是“སྲིན་བུ”（虫）的省略，指蛀虫，不是“罗刹”之义。譬喻的意思，大概是说：人对身体百般照料，衣食护养、关闭诸根，但内在的衰败（柱子被蛀）照样在进行，死期依然不定。

【按】本段开头两句与上一段开头两句完全重复，结构上像是“若不知何时坍毁”一句被抄了两次，使本段成了七句的奇数段落。这可能是道歌原有的复沓手法，也可能是传抄中的衍文。本译尚未与北京版、那塘版对勘，暂依德格版照录。

### 第四段：喂以酥蜜，仍如劣种

```
གང་གིས་གཡོགས་ཤིང་ཞལ་ཞལ་བྱས། །ལྷ་ཁང་ནང་ནས་ཕུག་རོན་ནི། །
གནས་ནི་གང་དུ་ཚོལ་བར་བྱེད། །
```

纵然有人替它盖好屋顶、抹好泥灰，殿堂里面的那只鸽子，又要到哪里去寻找它的栖身之处呢？

```
མར་དང་སྦྲང་རྩིའི་ཟས་བྱིན་ཡང་། །རིགས་ངན་གྱི་ནི་སྤྱོད་པ་འདྲ། །
དེ་བཞིན་རྡོ་རྗེ་འགྲོ་བར་བྱེད། །ཇི་ལྟར་ནམ་ཞིག་ལྷ་ཁང་དེར། །
འཇིག་པར་འགྱུར་བ་མ་ཤེས་སོ། །
```

即使拿酥油和蜂蜜做成的饮食去供养它，它的所作所为也还是像劣种之人一样；同样地，金刚也终将离去。那座殿堂究竟哪一天会坍毁，人们却不曾知晓。

【按】“རིགས་ངན”直译是“劣种”“恶种姓”，在藏文中常用来指品性卑劣、不知报恩的人。这两句的意思，依上下文应是：以酥油、蜂蜜之类的上妙饮食滋养身体，身体却像不知感恩的小人，终究要背弃主人而坏灭。这一解释是依文意推定的。

【按】“དེ་བཞིན་རྡོ་རྗེ་འགྲོ་བར་བྱེད”一句最为难解，直译是“同样地，金刚去了（或：金刚行走）”。这里的“金刚”所指，原文没有说明，至少有三种可能：一是指住在身中的心识，即上文的鸽子，意思是心识同样要离身而去；二是依密乘的说法，指身中的明点、精华，意思是死亡时精华耗散离去；三是“རྡོ་རྗེ”或为传抄讹误。本译暂按字面译作“金刚也终将离去”，不强作解，请读者留意。

【按】本段叠句作“མ་ཤེས་སོ”（不曾知晓、未知），而前面几段作“མི་ཤེས”（不知）。“མ”多表过去或已然，“མི”多表现在或未来。这一差异可能有意，表示殿堂已经坍毁而人们事先浑然不知；也可能只是抄写上的出入。译文照此分别译出，以存差异。

### 第五段：彩鸽弃瓶，从勇士门发声

```
ལྷ་ཁང་ནང་དེའི་ཕུག་རོན་ནི། །གནས་ནི་གང་དུ་ཚོལ་བར་བྱེད། །
སྣ་ཚོགས་མདོག་ཅན་ཕུག་རོན་ནི། །ལྷ་ཁང་བུམ་པ་སྤངས་ནས་ནི། །
དཔའ་བོའི་སྒོ་ནས་སྨྲ་བར་བྱེད། །ཇི་ལྟར་ནམ་ཞིག་ལྷ་ཁང་དེར། །
འཇིག་པར་འགྱུར་བ་མ་ཤེས་སོ། །
```

那殿堂里面的鸽子，要到哪里去寻找它的栖身之处呢？那只披着种种杂色羽毛的鸽子，舍弃了殿堂的宝瓶之后，便从勇士之门发出声音。那座殿堂究竟哪一天会坍毁，人们却不曾知晓。

【按】“སྣ་ཚོགས་མདོག་ཅན”是“具种种颜色”，用来形容鸽子。若鸽子喻心识，“种种颜色”可以理解为心识夹杂着种种习气与烦恼，也可以理解为心识能显现种种形相。原文未释，这里只照字面译出。

【按】“ལྷ་ཁང་བུམ་པ”直译是“殿堂宝瓶”。藏式殿堂顶上常有宝瓶状的顶饰，也可以把整座殿堂看作一只容器；而在密乘中，身体常被称为“瓶”（如“瓶气”之说）。所以“舍弃殿堂宝瓶”大概是指心识舍离身体。这是推解，并非原文明说。

【按】“དཔའ་བོའི་སྒོ་ནས་སྨྲ་བར་བྱེད”直译是“从勇士的门而言说”，是全篇第二个难点。“勇士”（དཔའ་བོ）在密乘中常指勇父、空行一类的圣众，也可以泛指英勇无畏者。这一句至少可以有三种读法：一是指心识离开身体时所经由的某一个门户（例如颅顶梵穴），但原文并没有这样说，译者也未能查到“勇士之门”作为梵穴别称的明确出处；二是读作“以勇士的姿态发言”，意思是心识脱离身体束缚之后无畏地宣说；三是指心识出离后归入勇父、空行的境界。由于没有注释可以依据，本译只照字面译作“从勇士之门发出声音”，不取任何一说。至于“སྨྲ་བར་བྱེད”，原义是“说话、言说”，用在鸽子身上，大概也可以理解为鸽子的鸣叫。

### 第六段：结归心的幻化

```
ལྷ་ཁང་ནང་ནས་ཕུག་རོན་ནི། །གནས་ནི་གང་དུ་ཚོལ་བར་བྱེད། །
ལྷ་ཁང་བུམ་པ་སྤངས་ནས་ནི། །དཔའ་བོའི་སྒོ་ནས་སྨྲ་བར་བྱེད། །
སེམས་ཀྱི་རྣམ་འཕྲུལ་ཡིན་ནོ་ཞེས། །འཕགས་པ་ཀླུ་སྒྲུབ་སྨྲ་བར་བྱེད། །
```

殿堂里面的那只鸽子，要到哪里去寻找它的栖身之处呢？它舍弃了殿堂的宝瓶，便从勇士之门发出声音。“这一切都只是心的幻化而已。”——圣者龙树如是宣说。

【按】“སེམས་ཀྱི་རྣམ་འཕྲུལ”是“心的幻化”“心的变现”。这一句是全篇的点睛之处：前面反复追问“鸽子到哪里去寻找住处”，始终没有给出答案，到这里才说，殿堂也好，鸽子也好，坍毁与离去也好，都是心的幻化。既然是心的幻化，就没有一处可以执为实有的住所，也没有一个自性成立的“住者”，这便是题名所说的“自性不成立”。

【按】“这一切”三字是译者为了使汉文通顺而补的，原文只说“是心的幻化”，没有明说主语。从全篇脉络看，主语可以是上面所说的种种情形，也可以单指鸽子（心识）发声这件事。为避免扭曲，这里特别注明。

【按】结尾以第三人称说“圣者龙树如是宣说”，这在印度道歌中常见，作者往往在末句自署其名。但也正因为是第三人称，不能排除本篇是后人依托龙树之名所传的可能。

## 跋语

```
རང་བཞིན་གྲུབ་པ་མེད་པའི་གཞིའི་མན་ངག་ཅེས་བྱ་བ་སློབ་དཔོན་ཀླུ་སྒྲུབ་ཀྱིས་མཛད་པ་རྫོགས་སོ།། །
```

名为《自性不成立之基的口诀》，阿阇黎龙树所造，圆满。

## 通篇连读

奇哉！这座殿堂，是何等善巧的人所建造的？一根柱子、九扇门户，是哪一位木匠营造而成？

这殿堂哪一天会坍毁，谁也不知道，那么住在殿堂里的鸽子，又要到哪里去寻找栖身之处？不管是谁替它盖顶抹泥、紧闭门户，只要柱子被虫蛀蚀，它哪一天坍毁，仍旧没有人知道。

纵然有人替它盖顶抹泥，殿中的鸽子又往哪里去找住处？即使拿酥油蜂蜜去喂养，它的行径仍像劣种之人；同样地，金刚也终将离去。那殿堂何时坍毁，人们却不曾知晓。

殿中的鸽子往哪里去找住处？那只杂色的鸽子，舍弃了殿堂的宝瓶，便从勇士之门发出声音。那殿堂何时坍毁，人们却不曾知晓。

殿中的鸽子往哪里去找住处？它舍弃了殿堂的宝瓶，从勇士之门发出声音。“这一切都只是心的幻化。”——圣者龙树如是宣说。
