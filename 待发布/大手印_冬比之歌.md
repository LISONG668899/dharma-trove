# 冬比之歌

阿阇黎冬比造　据藏文译出

## 题解

本篇收于德格版丹珠尔续部释 ཟི 函第 9a 页（东北目录 D2368）。开头没有梵藏题名，只有"敬礼佛陀"；跋语作"冬比之歌，圆满"，没有记载译者。冬比（Ḍombī Heruka）是八十四成就者之一，传说他原是一位国王，与一位旃陀罗女子一同修行而成就，常骑着一头母虎。

全篇约十五句，共四段，以猎鹿为喻，叠句是"邪见之鹿往哪里去，我看见了；冬比拉满利箭，进入林中"。四段依次说：在幻化的森林中猎鹿；五支箭向东射出；无弓无箭，却必定射杀；以五部佛为顶饰，再把被杀的鹿复活。

特别说明：全篇的"猎鹿""射杀"都是象征语言，指以智慧斩断邪见与分别，绝不是世间的狩猎杀生；末段"把被射杀的鹿复活"，正说明邪见是被转化为智慧，而不是被消灭。读者不可照字面理解。

体例：藏文原文全部保留在代码框中，按段落分节，每节后附汉译；叠句照原文每次重复。凡标"存疑"的按语，表示本译对原文意思没有把握。藏文依 Esukhia 德格丹珠尔电子版。

## 礼敬

```
སངས་རྒྱས་ལ་ཕྱག་འཚལ་ལོ། །
```

敬礼佛陀！

## 一、幻化森林中猎鹿

```
སྒྱུ་མའི་ནགས་ཚལ་མང་པོ་དེ་དང་དེར། །
རི་དྭགས་གསད་ཕྱིར་བློན་པོ་ཌོམྦི་འགྲོ། །
ལོག་འགྲོ་རི་དྭགས་གར་འགྲོ་ང་ཡིས་མཐོང། །
ཌོམྦི་མདའ་རྣོན་བཀང་ནས་ནང་དུ་ཞུགས། །
```

在许许多多幻化的森林里，为了猎杀野兽，大臣冬比前去。邪行之鹿往哪里去，我看见了；冬比拉满利箭，进入［林中］。

【按】全篇以猎鹿为喻："幻化的森林"象征如幻的轮回，"邪见之鹿"象征邪见与分别，"冬比射鹿"象征以智慧之箭斩断邪见。这是象征语言，不是说世间的狩猎杀生。"邪见之鹿往哪里去，我看见了；冬比拉满利箭，进入林中"，是全篇的叠句（首段作"邪行之鹿"）。

【按】"大臣冬比"：依成就者传记，冬比（Ḍombī Heruka）原是一位国王，与旃陀罗女子一同修行，后被驱逐，最终成就；这里称"大臣"，所指不完全确定。

## 二、五支箭向东射出

```
མདའ་ལྔ་ཡོད་དེ་ལྔ་ཀ་ཤར་གྱིས་བཏོན། །
ཌོམྦི་གཞུ་བཀང་གཟུང་ནས་རྣམ་པར་འདུག། །
ལོག་ལྟའི་རི་དྭགས་གར་འགྲོ་ང་ཡིས་མཐོང། །
ཌོམྦི་མདའ་རྣོན་བཀང་ནས་ནང་དུ་ཞུགས། །
```

有五支箭，五支都向东射出；冬比拉满弓，握持着［弓］而安住。邪见之鹿往哪里去，我看见了；冬比拉满利箭，进入［林中］。

【按】存疑。"五支箭"，可能象征五智或五根，所指不确定。

## 三、无弓无箭，必定射杀

```
གཞུ་མེད་རྒྱུད་མེད་སྨྱུག་མེད་མདེའུ་མེད། །
ཌོམྦི་ཐེ་ཚོམ་མེད་དེ་ངེས་པར་བསད། །
ལོག་ལྟའི་རི་དྭགས་གར་འགྲོ་ང་ཡིས་མཐོང། །
ཌོམྦི་མདའ་རྣོན་བཀང་ནས་ནང་དུ་ཞུགས། །
```

没有弓，没有弦，没有箭杆，也没有箭镞，冬比毫无疑问，必定射杀［邪见之鹿］。邪见之鹿往哪里去，我看见了；冬比拉满利箭，进入［林中］。

【按】"无弓无箭而必定射杀"，与已译的《金刚持毗瓦巴之歌》（D2356）"射出俱生之箭，没有靶子"同一意趣：斩断邪见的智慧，本身没有可执的形相。

## 四、以五部为冠，令鹿复活

```
རྒྱལ་བ་རིགས་ལྔ་དབུ་རྒྱན་བྱས་ནས་སུ། །
རི་དྭགས་བསད་པ་སླར་ལ་སོས་པར་བྱ། །
ལོག་ལྟའི་རི་དྭགས་གར་འགྲོ་ང་ཡིས་མཐོང། །
ཌོམྦི་མདའ་རྣོན་བཀང་ནས་ནང་དུ་ཞུགས། །
```

以五部佛为顶饰，再把被射杀的鹿复活过来。邪见之鹿往哪里去，我看见了；冬比拉满利箭，进入［林中］。

【按】"以五部佛为顶饰"，指观想自身为本尊、头戴五佛冠。"把被射杀的鹿复活"，是全篇的点睛之笔：所"杀"的邪见，并不是被消灭，而是被转化；邪见被斩断之后，同一颗心就"复活"为智慧。这再次说明全篇的"猎杀"都是象征。
