# 二谛明灯

## 作者：慧光大师传略

慧光，藏名音译"喜饶沃色"，梵文译名
Prajñāraśmi，冠以地名尊号准波德钦（意为"准波地方的大掘藏师"）又号卓杜林巴（"调伏众生洲"）。生于藏历土虎年（1518年），卒于1584年，是藏传佛教宁玛派历史上一位承前启后的重要掘藏师与学问僧，卫藏琼结白日寺的开山祖师。

慧光幼年即显露出与常人不同的根器——不待教导，自然生起出离心与悲心，智慧之力也异于同龄孩童，是大乘种性早熟之相。八岁时，依止一位善知识受近事居士戒，因此得法名"喜饶沃色"（意为"智慧光"，此后汉译"慧光"即由此而来）。

少年时代，他先后在萨迦、格鲁两大教派门下受学，广泛研习因明、中观、般若等显教经论，历时六年之久，于辩经场中"法螺震响，无人能敌"，因此被尊为格西钦莫（大格西），这是当时西藏显教学问的最高荣誉之一。这段经历意味着，慧光并非一位单纯依靠"净相""授记"而弘法的伏藏师，他首先是一位受过严格显教因明训练的学者——这也正是他后来所撰《二谛明灯》能够严整地依循中观应成派论式、层层立破的学理根源。

十八岁那年，慧光拜谒止贡噶举法主止贡仁钦彭措，师徒二人法谈契合，慧光由此生起不可动摇的坚固信心，正式皈依止贡传承，成为止贡噶举与宁玛派共同承许的传承持有者。这一师承转折，使他此后的著述带有鲜明的噶举——宁玛融通色彩：既有格鲁——萨迦学统训练出的严密因明论证功底，又秉持噶举大手印与宁玛大圆满的实修见地。这种"显密兼通、教派不拘"的气质，正是他日后被追认为利美（不分教派）运动先驱之一的原因。

慧光一生最重要的事业，是在卫藏琼结河谷（藏地历代赞普陵墓所在之地）创建了白日大乘洲寺，这是该地区第一座重要的宁玛派寺院。在后世的宁玛派寺院谱系中，白日寺一度与多杰扎、敏珠林、噶陀、白玉、佐钦并称"宁玛六大母寺"，虽然近代已趋式微、其位置在名单中被协庆寺取代，但在十六至十七世纪，白日寺曾是卫藏宁玛教法复兴的重要枢纽。

作为掘藏师，慧光最负盛名的取藏是《解脱心要·意自解脱》法类，属大圆满窍诀部的重要伏藏法门，在后世宁玛派实修传承中影响深远。此外，他还主持了《莲花遗教》的校订与重编工作。

慧光身后近两百年，宁玛派大掘藏师晋美林巴**（**1730--1798）取出龙钦宁提伏藏，开创了近代宁玛派最具影响力的实修传承之一。晋美林巴与白日寺、与慧光的"解脱心要"法脉渊源颇深，学者珍尼特·嘉措在研究晋美林巴自传的专著中，即记录了这一关联。更直接的证据是：晋美林巴曾亲自为慧光所撰《二谛明灯》的根本文撰写注释，阐明其纲要——这说明《二谛明灯》并非一篇孤立流传的小品文，而是被后世龙钦宁提传承正式纳入教学系统、郑重造论阐释的根本文本。

《二谛明灯》藏文原题为《决定义中观应成派之理趣明析：照亮二谛之灯》，简称《照亮二谛之灯》，收于慧光文集（*Gsung
'bum*，噶伦堡：Gonpo Tseten
版），亦见于不丹版《中观根本颂与中观二谛》合刊本。

综观慧光一生：他是格鲁、萨迦显教学统训练出的因明大格西，是止贡噶举的皈依弟子与法嗣，是宁玛派卫藏母寺白日寺的开山祖师，是《解脱心要》与《莲花遗教》校订本的掘藏与整理者，其学理著述又被后世龙钦宁提传承的开创者晋美林巴亲自造论阐释。这样一位兼通显密、贯通教派、上承止贡下启龙钦宁提的十六世纪祖师，其所撰《二谛明灯》，分量自不待言。

## 正文

众生陷入无明黑暗，为执诸境实有之罥网所缚。此《二谛明灯》显示解脱之道，以智慧利剑斩断错乱分别之网。

顶礼诸胜者化现之诸上师足下！

一般而言，一个人若欲获得解脱与一切智，就必须具备如眼目一般的正见，通达一切内外诸法之实相——即一切法空性之义。若没有此见，那么即使修持布施等其余诸道，也如盲人行路；纵然勤苦修习，亦不能获得佛果。

《般若摄颂》云：

```
生盲之人若无向导，不识万千道路，岂能入城？
如是，无智慧眼之五波罗蜜，既无导师，亦不能触证菩提。
```

大意：缺乏空性智慧引导，纵然修习其余五度，也如盲人无向导，终不能到达菩提。

因此，此处所开示的，正是作为一切道之眼目的空性智慧。其内容分二：一、所应证悟之法；二、所应修持之法。

## 一、所应证悟之法

所应证悟之法又分为二：一、一切所知诸法的实相；二、能知之心识自身的实相。

### 一、一切所知诸法的实相

对于一切所知诸法，首先应依二谛而认识；究竟则应证悟二谛无别。

#### （一）依二谛认识一切所知诸法

一般而言，一切所知之本性——法界——从本以来即远离一切戏论。在此法界之中，本来没有一个真实成立、可以作为"二谛"等名言安立之所依。

然而众生不能认识这一真如。因此，一切智为使众生了知实相，便从两种认知面向——迷乱之识与无迷乱之识——加以观察，而首先将一切所知法判为二谛：世俗谛与胜义谛。

**1. 世俗谛**

世俗谛的体性，就是迷乱心，以及在此迷乱心前显现的一切境。就名称而言，"kun"表示迷乱心及其一切所现的总体；"rdzob"表示这些显现皆是错乱、欺诳、虚假、空疏、无实义、无实体，并且有遮蔽真实义之意。之所以称为"谛"，是因为在迷乱心前，它显现为真实。

**1.1 世俗谛分为颠倒世俗与正世俗**

世俗谛可分为两种：颠倒世俗与正世俗。

藏地多数论师解释说：在显现层面能够发挥实际作用者，如天空中的月亮，是正世俗；虽有显现却不能发挥相应作用者，如水中月影，是颠倒世俗。

若从世间迷乱者的角度概括而言，所谓世俗，无非就是迷乱识前的一切显现。

正世俗具有四种特征：共同如是显现；能够发挥作用；从因缘而生；以正理观察时为空。

所谓共同如是显现，是说从学者、班智达，一直到愚者、牧童，对于器世间与有情世间的这些通常显现，都有相应的共同经验。

所谓能够发挥作用，例如大地能够承载众生等，各种事物都有其各自的作用。

所谓从因缘而生，是说一切事物皆由四大等种种因缘聚合而产生。

所谓观察时为空，是说若以中观五大因等正理加以观察，一切法皆无自性可得。

阿底峡尊者《入二谛论》云：

```
世俗承许有二种：颠倒世俗与正确世俗。初者（颠倒世俗）复有二种：水月以及恶宗分别。
```

大意：世俗谛分正、倒两种；颠倒世俗又可细分为"水中月"式的错觉与执持错误宗见两类。

又说：```
诸法有生亦有灭，唯不观察时可安立，并且具有实际作用，是即承许为正世俗。
```

大意：诸法虽有生有灭，但只在不加观察、且能发挥实际作用的前提下才可安立，这才是正世俗。

依其他中观经论传统，也就是：如天空之月，在显现层面有其作用，故称正世俗；如水中月，虽现而无相应作用，故称颠倒世俗。

**1.2 依"大中观"区分颠倒世俗与正世俗**

依龙树阿阇黎"大中观"的传统，则作另一种判别：

从各种错误宗见，乃至唯识宗所作的错误分别，皆属于颠倒世俗；而已经证悟中观正见的瑜伽士，其所见的一切显现，则属于正世俗。

凡夫依各自迷乱相续而执取这些显现；外道或执之为常，或执之为断；声闻宗将能取与所取执为不可再分的实有法；唯识宗则把离能所二取的心识，执为究竟胜义。

这些宗见由于依止错误分别、错误师长、错误论典及错误友伴，将非真实者执为真实；又因为这些执著不能成为断除轮回、获得解脱的有效之因，所以都只能成立为颠倒世俗。

至于正世俗，已经证悟中观见的瑜伽士，了知一切显现仅是表相，其自相如八种幻喻。此即正世俗之相。

过去有些藏地论师所安立的正世俗定义，仍然只是依迷乱识作出的判定。

依大中观这一传统，瑜伽士所共同见到的显现，虽不存在，却依然显现，故如八幻喻一般，是"如幻而显现"。

它又具有作用：了知一切显现如幻，能够成为舍弃轮回、获得解脱之因。

它也从因缘而生：这种"了知显现如幻"的证悟，是依上师教授以及自己往昔积集福德、智慧二资粮等因缘而生。

若加观察，则为空：在胜义谛中，就连这些如幻显现也丝毫不能成立。一切法离有、无，离实、妄，因此称之为空。此即阿底峡尊者的密意。

善知识仲敦巴也说：

从凡夫直至世第一法之间，凡其心前所现，一切皆属颠倒世俗，因为这些显现都是由错乱识所成立。对于错乱识前的显现，不再另外分出"颠倒"与"正确"两类；两者总体上皆属颠倒世俗。因为它们尚不能成为真实正道，所以不用"正"这一名称。

从菩萨初地以上，诸地圣者在后得位中的一切显现，则称为正世俗。因为这是无错乱现量之所见，圣者现量了知这些显现皆如幻；又因为这种认识与正道相应，所以称为正世俗。

若问：对于我们现在这个心来说，又应如何判定？

一般而言，从无间地狱的显现，直至十地菩萨后得位中的显现，全部都属于世俗谛。

凡夫心前所见的一切，都是由自己心识错乱而呈现的迷乱显现。因此，对于凡夫及初学者而言，其所见一切整体上皆属颠倒世俗；在这一层面，并不再依"颠倒世俗、正世俗"的名称来作根本区分。

那么，凡夫所见的世俗显现内部，是否完全没有差别？

当然有差别。

有能起实际作用的，也有不能起作用的；有因眼根病患等过失而显现的，也有并非由于这种过失而显现的；有持续时间较长的，也有短暂的；有自行消失的，也有不会自行消失的，如此可以作出许多区分。

但因为这些全都没有超出颠倒世俗，所以不以"正世俗"称之。

对于具信修行者而言，如果通过证悟而认出一切显现如幻，那么这些显现便属于正世俗；若尚未如此证悟，便属于颠倒世俗。

从菩萨初地以上，圣者所见一切则皆为正世俗。

若问：世间的一切显现既然由心之迷乱所生，那么从初地直至十地，圣者后得位中的这些显现，又从何而来？

这是因为，从无始以来，由实执所熏成的强大习气一直存在。圣者虽然以禅定之力断除了由实执生起烦恼的粗重因，但它的习气尚未完全断尽，所以仍会产生这些显现。

譬如一个盛过麝香的容器，即使已经把麝香取走，空器中仍然留有香气。

佛陀则连这些习气的根本也已断尽，因此此类迷乱显现丝毫不现，唯住于离一切戏论的胜义谛。

**1.3 密乘的角度**

依密咒乘而言，为了对治将凡庸器世间与有情世间执为实有的颠倒世俗，而将器世间观修为清净无量宫，将有情观修为清净本尊，同时了知这一切皆如幻。

如此，原本的颠倒世俗便转成正世俗。

**2. 胜义谛**

胜义的体性，是远离一切戏论的法界。

就名称解释而言，所谓"胜义"，是无错乱智慧所趋入之境；又是希求解脱者所追求、所抵达之义，故称为"义"；因其无有欺诳，故称为"胜"；从无错乱认知的角度，它是真实不欺的，故称为"谛"。

胜义谛虽然就离戏法界本身而言，并无真正可以分开的差别，但依据是否已由证悟而显露，可以分为：基之胜义谛，以及证悟真如之胜义谛。

也可以分为：通过闻、思、修断除增益而通达的胜义谛，以及瑜伽士亲身现证的胜义谛。

又可以分为：凡夫依比量所通达的"义共相之胜义"，以及圣者以现量所证、以自相为境的胜义。

依论理名言，还可分为：名言分别中所安立的胜义，与不属于任何名言分别类别的胜义。

经中说：无上菩提，不落名言差别之数。

**3. 二谛的三种显现方式**

二谛又可从三种方式来理解。

凡夫位中，显现被看作独立自在之法，并成为执著之境，这就是所谓颠倒世俗。

圣者位中，显现虽仍然显现，却已经现量了知其如幻，对之不起实执，这就是所谓正世俗。

佛陀位中，对于"有无显现""有无执著"这些分别判断本身都不存在，这就是所谓胜义。

可以用幻术来比喻：凡夫见到幻相并执以为真，好比受到幻术咒力控制的观众。

圣者同样见到幻相，却不执以为真，好比施幻术的幻师本人。

佛陀则不再分别"究竟有没有这些幻相""执还是不执"，犹如根本未受幻术咒力影响之人。

关于这一点，格西坚阿瓦将认知判为三类：颠倒之识、了知世俗之识、了知胜义之识。

所谓颠倒之识，是说从无始以来，心由于反复串习实执所留下的习气，将色、声等一切显现执为真实实体，并依此而运转于有与无、常与断、真与假、善与恶等二元分别之中。

这就是错误之识、颠倒之识、迷乱之识、未证实相之识。

所谓了知世俗之识，是心经过具德上师教授的纠正之后，色声等一切显现虽然仍然显现，却依八幻喻而了知它们无有自性。

凡夫对此的认识尚须依赖分别观察；圣者则不依分别观察，而以现量亲见。

所谓了知胜义之识，就是证悟一切法的实相皆为法界，远离有无、常断、实妄等一切戏论。

在此法界中，实际上连"知"与"不知"的名言都无法安立。为了使人理解，才说"了知胜义"，这也只是一种暂时的增益安立。

就此而言，还可说：凡夫依分别与比量所认识的，是义共相；初地以上圣者在禅定中，则以现量亲证其自相。而初地以上圣者的这种现证，从其所证实相而言，与佛陀本智并无不同。

以上，是首先依二谛认识一切所知诸法。

#### （二）究竟证悟二谛无别

其次，应当证悟二谛究竟无别。

愚者将二谛的体性执为两个彼此独立的东西，就像山羊的两只角：一说世俗谛，便把它执成真实存在；一说胜义谛，又把它执成彻底的断灭、全无。

如此把有与无执为二元对立的认知，不符合中观正见。

龙树阿阇黎说：```
定有则执常，定无则成断；是故诸智者，不应住有无。
```

大意：执定为有则堕常边，执定为无则堕断边，智者应远离有无二边。

因此，不住于有无、常断等任何一边，才称为"中道"。

就在证悟胜义谛与世俗谛具有同一本然实相、同样远离有无常断诸边之时，二谛即不可分离地融为一体。

《般若经》佛母中说：

须菩提，世间的世俗谛虽说为异，胜义谛之真如却并非另一个东西。世俗谛为何，其自身即是胜义谛之真如。

《中观二谛论》说：

世俗谛之真如为何？我等许彼自身即为胜义谛。

在胜义谛——也就是佛陀密意、法界——之中，对于属于有无、常断的"实法"与"非实法"，都没有任何分别安立。

寂天菩萨说：

```
若实与非实，皆不住心前；尔时无余相，无缘极寂静。
```

大意：当"实有""非实"二相皆不现于心前，一切相尽泯，即是无缘寂静之境。

若因此便说："既然究竟二谛无别，也就完全没有必要分别二谛。"这又不对。

虽然在所知法的真实本性中，并不存在真实成立的二谛安立之基，但迷乱认知与无迷乱认知这两个认知面向恰恰相反。为了让尚未通达真如的人容易理解，所以才方便安立"二谛"的名言。

从迷乱认知的角度，各种显现呈现为种种真实事物，因此假名为"世俗谛"。

从迷乱已经穷尽的认知而言，一切实体乃至一微尘都不可得，丝毫没有可自体成立之法，因此假名为"胜义谛"。

事实上，在究竟所知——离一切戏论的大法界——之中，本无二谛之分别。

究竟而言，在佛陀密意中，同样没有二谛之分别。

即使就目前这些如幻显现而言，二谛也绝非像山羊两角一样，是两个彼此分离的实体。

安住于现空无别、觉空无别之中，对此完全证悟、彻底串熟，即是法性之无二本智；这就是胜义谛，也就是佛陀密意。

阿底峡尊者说：

```
凡此世俗之所现，若以正理而观察，一法亦不可获得；不可得即是胜义，本始安住之法性。
```

大意：世俗一切显现，以正理观察皆了不可得；这不可得本身，即是本来安住的法性胜义。

密乘龙树阿阇黎《五次第论》说：

```
世俗以及胜义，各各分位而了知；于何处正融为一，彼即说名为双运。
```

大意：世俗、胜义先分别了知，二者真正融为一体之处，便是"双运"。

又说：```
此即无二之本智，即是无住之涅槃。
```

大意：这无二的本智，正是无住涅槃本身。

以上说明一切所知诸法的实相。

### 二、能知之心识自身的实相

接下来，应当证悟能知之心识自身的实相。

即使已经通达一切所知境的实相，如果没有进一步通达能知者自身——也就是这个心识——的实相，那么对于烦恼与业的对治仍不能真正生效，而且还可能由于"我已经证悟空性"而生起骄慢与自负。

因此，对于这个作为能知者的"智""心""意识"——也就是粗分人我所依的能知心识——必须进一步认识它自身究竟如何存在。

心或认知自身的实相，也分两步：首先，依二谛认识；究竟，则证悟二谛无别。

#### （一）依二谛认识心识自身

对于一切所知法，我们已经说过：世俗谛中的显现如幻，本无自性；胜义谛中，有与无等一切范畴皆不成立，犹如虚空。

可是，这个正在分别思维："二谛究竟无别，法界就是远离一切边际戏论的大中观"的心或意识，它自身仍然只是世俗谛。

寂天菩萨说：胜义非心之行境，心则说名为世俗。

一个人若仍以分别心执持"我已通达这种道理"，便会产生骄慢与自负；一有骄慢自负，就成为魔业，因此仍属于颠倒之识。

《圣佛境界不可思议所说经》云：

所谓"获得"，即是欺诳；所谓"现证"，即是贡高。具增上慢者便作分别："我已经获得了，我已经现证了。"

然而，这个分别心自身的本性，又正是胜义谛。

向内观察这个分别念、这个心、这个认知本身，根本找不到任何可以成立为实体的东西。

它从本以来，离有离无，离生离灭，离来离去，离常离断，亦超越过去、现在、未来三时。正因为法性、胜义谛如此不可成立，所以说它是空。

《迦叶所问经》云：

迦叶，心不在内，也不在外，亦不在内外二者之间；心毕竟不可得。

《弥勒所问经》云：

心无形色，无内、无住处，犹如虚空。

#### （二）究竟证悟心识之二谛无别

心的究竟实相，安住于二谛无别之中；二谛究竟只是一味。

虽然暂时安立"世俗谛""胜义谛"两个名称，但最初所作的这种二分安立，最终本身也必须消融。

法界之中，所谓"心"不可得，所以二谛的安立之基亦不可得。

就究竟果位与佛陀密意而言，心本身亦不可得，因此所谓二谛的名言同样无从成立。

即使迷乱众生的心性，本来也是明与空。若不再于其上重新执取二谛，安住于**觉空、明空**之中，便能证悟二谛无别。

若又因此说："那么根本没有必要分二谛。"仍然不对。

因为必须证悟二谛无别之义；而要证悟二谛无别，就必须先依了知二谛各自法相作为方便。

如此，离戏的一切所知之实相，与离戏的能知心识之实相，最终不可分离地融为**一味**。

人无我，法亦无我。一切内外诸法，皆远离有无、实妄、常断等一切戏论，犹如无为虚空。

既无所见，也无能见；既无所证，也无能证。

如此证悟，才是无错乱之证悟。

《圣净信女所问经》云：

以无分别而证悟，即名"不见诸法"；所谓"见"，只是"证悟"的异名。

阿底峡尊者《二谛小论》亦云：

以无所见而见之故，假名为"证悟空性"。

## 二、所应修持之法

所应修持之法分为两种：利根者顿时修持；钝根者依次第修持。

### 一、利根者的顿时修持

有些利根具缘者，由于宿业成熟、深具加持，并且往昔已经积集广大福慧二资粮，所以只要听闻二谛教授，证悟便能顿时生起，并且能够直接安住于这一证悟本身。

这种体验远离能知与所知的二元对立。

对于二谛，他们安住于如虚空般远离一切戏论的无我境界中修持。

如此修习时，若恶劣分别念生起，不必刻意排斥，它自来而自灭；若善妙本智现起，也不以分别心刻意把持、造作安立。

如怙主弥勒与龙树阿阇黎所说：

```
于此无何可遣除，亦无丝毫可安立；如实正观真实性，如实见即得解脱。
```

大意：法性中无可遣除、无可安立，如实照见其本然，如实见即是解脱。

此后，无论显现什么，虽有显现，却皆无自性。

行者安住于如梦如幻、二谛双运的状态。

与此同时，对于那些尚未证悟、同样如幻的一切众生，生起如幻而不舍的大慈、大悲与菩提心，并为一切众生发广大愿。

### 二、钝根者的次第修持

钝根者因为往昔积集资粮较少，仅仅听到表示义共相的语言概念，甚深证悟不会立即生起。

为了亲自体验真如，应依三士道次第训练自心。上层修法建立在下层修法之上，因此首先修习下士、再修中士、上士诸法。

依次观修暇满难得、死亡无常、业因果、轮回过患、菩提心，最后进入二谛之义。

对于世俗谛中无论显现什么，都依八幻喻而观修。

当对此获得定解之后，再观修：世俗谛自身之本性就是胜义谛，空寂如无为虚空。

对此获得定解之后，再修二谛双运，即远离一切戏论的中道胜义谛。

如此修习，内心生起寂静安乐，这便是寂止。

进而证悟所修之境、能修之心以及修这一行为，三者都无有自性，这便是胜观。

在此基础上，为利益众生勤行能够积集福德资粮的广大行持，如是不断训练，便会依次生起五道、十地的证悟。

阿底峡尊者说：

```
如是若见无愚蒙，行持亦复极清净，则不趋入歧误道，当往色究竟之境。
```

大意：若见地不再愚昧、行持清净无染，便不会误入歧途，终将抵达色究竟天的证悟之境。

## 三、获得定解的征相

如此无误证悟空性之义以后，获得决定智会出现以下征相：

对于一切内外诸法的真实执著开始逆转。

一切显现变得如雾气一般，朦胧、轻虚，虽现而无可执取。

对于形形色色的任何事物，不执著之心自然生起。

无论何种认知现起，都能连续而无障碍地运行。

心相续渐趋寂静，内心生起喜悦、宽舒与自在。

对于过去的追悔以及对于未来的忧虑恐惧，逐渐止息。

面对一切法，生起无碍的自信与无畏。

从内心深处生起智慧，能够解除自己与他人的一切疑惑。

对于业因果的取舍极其清楚，不再颠倒错乱。

对于一切众生，大慈、大悲与菩提心强烈生起。

除了为利益众生而作的行持之外，自己的行为方式与世间一般人的行为开始有所不同。

对于甚深之见与广大之行获得坚固定解，安住其中而不动摇。

所谓"甚深"，是说即使有一百位博学者前来追问，也无法把此见拘限、衡量于某个分别宗派的概念框架之中。

所谓"广大"，是说对于各种所诠法及其法相能够善巧开示，同时对于一切如幻众生，为其利益而全心修学菩萨的一切学处。

在教法与见行上，即使面对魔众、外道乃至声闻、独觉等不同或偏狭的见行，也不能使自己从人无我、法无我的定解中动摇。

具足这些征相之人，将进入不退转之道。

不断修习真如，以现量无间亲见法性真实义之后，便会善巧通达行于法界之道的方便。

由此获得力量、无畏、殊胜功德，并能总摄诸佛一切教法。

圆满无垢布施等六波罗蜜之后，迅速获得无上菩提，究竟利益一切众生。

《圣铠甲庄严所说经》云：

若于不生不灭、极其甚深的空性法门，以坚忍精进而圆满修持，即能迅速善巧通达菩萨行于法界之方便。将获得力量、无畏、殊胜功德，总集一切无上教法；为诸佛胜者所赞叹，圆满具足正法所需的一切功德。

圆满布施，安住极清净戒律，获得极清净安忍、无上精进、无所缘禅定以及广大智慧。其后安住菩提心藏，四大天王手持幢幡，劝请其转正法轮。于天人之前示现广大功德，最终安住圆满无上菩提。

不仅如此，若对这一甚深空性义的教法，以大精进力不断修习，那么舍弃此身之时，就会如迦楼罗雏鸟破卵而出。

获得最胜成就后，具足神通，于诸佛清净刹土中往来无碍。

《圣宝髻所问经》云：

安乐住于一切法无相之智慧中，临舍此身之时，忆念无上菩提。身心分离之际，犹如鸟从卵中破壳而出。以此人身即能获得无上菩提，又具意生身，往来一切处皆无障碍。

名为《二谛明灯》之此论，由慧光撰著。

至此暂告圆满。
