# 《大宝积经》卷第二十五（被甲庄严会）

唐·三藏菩提流志 奉诏译

## 被甲庄严会第七之五

### 月灯王如来时二菩萨

#### 清净国土

“又，无边慧！我忆念往昔，过二阿僧祇劫，那时有佛出现于世间，号为月灯王如来、应供、正遍知、明行足、善逝、世间解、无上士、调御丈夫、天人师、佛、世尊。劫名甘露，国名清净。那佛的世界由颇梨所成，常有光明遍照其国土；若有众生遇到这光明，就清净美妙，端严殊好，所以那世界名为清净。

【按】“颇梨”，宋、元、明、宫本作“玻瓈”。

“那里没有另外的城邑、聚落之名；交道殊妙，以金绳为界作装饰，诸交道之间，每一段都等量半俱卢舍。每一条道间有光明宝柱与杂多罗树，各八十四株，辉映成行；又有四个池，以堤塘围绕。人民住在七宝台观之中，台观覆以铃网，悬挂诸缯带，花饰珍玩犹如诸天。那世界的众生寂静安乐，十善业道都已成就，容貌端严，寿命长远，贪瞋痴薄，容易开悟，以少许方便就能广知诸法。

“那佛寿命一千俱胝年，灭度之后正法住世一俱胝年。他十次集会说法，诸声闻众住于有学地的，每一法会各有二十俱胝那由他；诸菩萨众趣向一乘的，其数无量。

【按】“千俱胝岁”之“千”，明本作“十”。

“无边慧！那月灯王如来的宝菩提树，周围五十由旬，高一百由旬，以珊瑚为根，琉璃为干，黄金为枝，马瑙为叶；道场纵横一百由旬。基座台阶周匝有栏楯围绕，美妙的多罗树成行种植，金铃宝网弥覆庄严。大菩提座高三由旬，上面铺设细软的坐具，以百千妙衣交错装饰垂下，旁边树立二十面幢幡。月灯王佛在这座上证得阿耨多罗三藐三菩提。那时那国界没有三恶趣以及恶趣之名，也没有诸难以及诸难之名。月灯王佛常在一切诸世界中化现其身，转于法轮。

#### 云音、无边音二菩萨问法

“无边慧！那月灯王如来有两位菩萨：一名云音，二名无边音。这两位菩萨对那如来说：‘世尊！诸菩萨摩诃萨怎样在一切法的理趣之中得到善巧方便的安立？’

“那时那如来想令诸菩萨摩诃萨在一切法的理趣之中得到善巧方便的安立，为两位菩萨广说这法。那时诸菩萨摩诃萨听闻这法后，在一切法的理趣之中便获得善巧方便的安立。这两位菩萨从此以后，在二万年中没有睡眠，没有贪欲、瞋恚与恼害，不起饮食之想，不生卧息之想，也没有疾病因缘、汤药等想，不乐于世间的游观谈笑嬉戏。在那如来说法之时，就在法座上得到无生忍。

#### 无所求而得忍

“那时那如来问他们说：‘善男子！在一切法的理趣之中这样善巧方便地安立，你们现在是在求它吗？’

“这两位菩萨就对佛说：‘世尊！我们尚且不见有一切法理趣善巧安立之名，也不见有一切法理趣善巧安立之法，何况一切法理趣善巧方便安立。世尊！我们也不得一切诸法，我们也不得诸法的安立，对于一切法无住也无不住。世尊！我们是这样见的。还怎么能说在一切法的理趣之中这样善巧方便地安立，是求还是不求呢？

“‘世尊！我们也不见在一切法的理趣之中有这样善巧方便安立而去求它的人，也不见有在内、在外、在二者中间的。无论一切法，或是法的理趣善巧方便而安立的人，也不见那法在内、在外、在二者中间。无论一切法，或是法的理趣善巧方便可以安立，世尊！我们也不见乃至少许法在内、外、中间，有理趣善巧方便的安立可以趣向、可以亲近。

“‘世尊！既然没有少许法可以趣向、可以亲近，我们在其中当如何安立？世尊！我们也不见过去、现在、未来作为安立之处；若安立之处无所有，我们在何处可以安立？世尊！因为无安立，所以非与住相应，非与不住相应，与无尽相应，与无生相应。世尊！我们也不见从谁、由谁、在何处、在何时，我们的心意识或生或灭。又怎能说以心意识在一切法的理趣中善巧方便地安立呢？’

“无边慧！这两位菩萨在如来面前这样说时，一千菩萨得无生忍，一千俱胝菩萨发菩提心。

“那时月灯王如来又告诉他们说：‘善男子！你们以无住而住于无处，而住于一切法理趣的善巧方便安立。善男子！一切诸法也是这样。如来随顺世俗之道的缘故，现证阿耨多罗三藐三菩提；若对如来不随世俗而说现证阿耨多罗三藐三菩提，也是这样。善男子！诸法无处，也非无处；无论处与无处，都是随顺世俗而说；若随顺世俗，其中就没有少许法可以生起，可以了知。所以，善男子！应当更加精勤，迅速对诸法得到解脱。’

“这两位菩萨在如来面前听闻这法后，飞腾虚空，就以偈颂赞叹如来说：

```
法王不思议，得未曾有法，
遍知两足尊，佛法无过上，
以法无上故，如来世无等。
一切法无生，我今获此忍，
我常不分别，若生若无生，
如是亦不念，一切无分别。
法王大牟尼，功德离言念，
愿说清净法，令众皆欢喜。
于佛胜功德，欲知其边际，
设经无量劫，而亦不可得，
功德无边故，最胜无过上。
```

（大意：法王不可思议，得到未曾有之法；遍知两足尊的佛法无可超过；因为法无上，所以如来在世间无与等同。一切法无生，我现在获得这忍；我常不分别生与无生，也不这样起念，一切都无分别。法王大牟尼的功德远离言说与思念，愿您宣说清净之法，令大众都欢喜。对于佛殊胜的功德，想要知道它的边际，即使经过无量劫也不可得；因为功德无边，所以最胜而无可超过。）

```
一切法无生，我亦不分别，
我于佛法中，未曾有毁坏。
不谓众善根，云何当可得？
诸法无示现，无生亦无相，
如是无相忍，于此亦皆证。
我今所得忍，毕竟无退转，
故于一切智，以此生欢喜。
我于如来法，决定不犹豫，
亦于一切法，远离众疑惑。
无上佛法中，我今得此忍，
我亦不分别，亦无不分别。
```

（大意：一切法无生，我也不分别；我在佛法之中，从未有所毁坏。（若）不说众善根，又如何能够得到？诸法无可示现，无生也无相，这样的无相之忍，在这里也都证得。我现在所得之忍，毕竟没有退转，所以对于一切智，因此生起欢喜。我对如来之法决定而不犹豫，也对一切法远离众多疑惑。在无上的佛法中，我现在得到这忍，我也不分别，也无不分别。）

原文：“不谓众善根，云何当可得？”（大意：此句语意未明，依字面译出，存疑。）

#### 授记与后续因缘

“无边慧！这两位菩萨说完这偈后，绕月灯王如来右绕三匝，以天上的妙花与栴檀末香散在佛上。那时那如来就为他们授记，告诉他们说：‘你们云音等，过二万劫当证阿耨多罗三藐三菩提。’

“这两位菩萨听到如来授记，踊跃欢喜，谛观如来，入于诸禅，游戏神通，出没自在，烟焰光辉迸发。又为众生说法开示，令二十四俱胝人天趣向阿耨多罗三藐三菩提。这两位菩萨乃至尽其寿命勤修梵行，对那如来的中时正法、后时正法都能护持；又在那时，教化成熟四俱胝众生趣向阿耨多罗三藐三菩提。

“这两位菩萨次第供养、亲近、承事许多百千佛，对诸如来的三昧与正法一一受持；过二万劫，又遇到宝幢如来，随顺他转法轮，教化成熟无量众生趣向阿耨多罗三藐三菩提。宝幢如来的刹土清净，没有诸声闻，唯有一生补处的菩萨。宝幢如来将要灭度时，就为他们授记：‘我灭度后，云音菩萨其次当现证阿耨多罗三藐三菩提，号为日灯王如来。那佛的刹土成就庄严，积集无量无边的功德，菩萨与声闻大众圆满。日灯王如来灭度之后，无边音菩萨其次当现证阿耨多罗三藐三菩提。’

【按】“无边音菩萨”之“音”，宋、元、明、宫本作“慧”。

#### 依此法速成一切智

“无边慧！因为这法门无所得、无言说，不可示现，无生无灭，诸菩萨摩诃萨应当如理精勤修习。若有菩萨住于一切法理趣的善巧方便安立，以无所得获无生忍，以圆满佛法的无量功德作为庄严，而发心趣向阿耨多罗三藐三菩提。

“无边慧！我从不说诸菩萨摩诃萨离开这法之外，另有少许法能迅速成就一切智智。若有人对这无生无灭的甚深空法勤加修行，就能迅速得到菩萨的法界理趣善巧方便以及陀罗尼，具足辩才与无上的摄化，为诸佛世尊所称赞，以法的庄严具来庄严自身，能圆满布施，住于清净戒，得清净忍、无上精进、无所缘的禅定，以大智慧而发心趣向阿耨多罗三藐三菩提。在诸殊胜者中最为殊胜，迅速得名为一切智者。坐于道场时，四大天王持伞盖前来，劝请转法轮，为诸人天作大光明，都令他们趣向阿耨多罗三藐三菩提。

### 一切法海印三昧

#### 一法与一切法和合

“又，无边慧！若诸菩萨摩诃萨对一切法海印三昧勤加修行，就见一切法同于法界。这样见时，不在法界中见一切法，不在诸法中见法界；精进修习，以一切法诸界和合的善巧方便，对一切法诸界和合无所执著，也无所动；对一切法诸界和合的善巧方便，也无执著，也无分别。

“能在一法的和合之中见一切诸法的和合，能在一切诸法的和合中又见一法的和合；不对一切诸法的和合而亲近一法的和合，不在一法的和合之中亲近一切诸法的和合。因为能了知这一法，也能了知一切诸法；因为能了知一切法，对这一法应当了知之处也能了知；不以诸法亲近一法。

【按】“而见一切诸法和合”之“见”，宋、宫本作“现”。

“对诸取蕴的和合都能了知，不对取蕴种种性相的有和合或无和合而生执著。诸菩萨摩诃萨这样修行时，若有诸法以众因缘和合而生起，若有诸法以众因缘和合而成就，对那些法都能了知。若有诸法因缘和合，以种种性相应而起，对那些法也能了知，也无执著；随顺了知一切诸法施设之相，也能了知有相与无相，也能了知诸界的差别与诸界种种性相的差别，也能了知以谁为因；不以烦恼去亲近趣向诸缘起法，也对世间、出世间法不相违背，随顺了知世间、出世间的一切诸法，对世间的相印都能遍知。

#### 一法门与一切法门

“以一法门能了知一切法门，以诸法门又能了知一法门；不以一切诸法门去亲近一法门，也不以一法门去亲近诸法门。这样的法门都能净治。

“无边慧！诸菩萨摩诃萨对这法勤加修习的，以一种理趣言教之门，能了知一切诸法之性同一味，对一切法得到殊胜的无诤，如理寂静而不相违背，能在大会中赞说这法，精勤修习，得一切法海印三昧。这样修习，无论有诤论、无诤论，都令其寂静，如理而住；随顺断除憍慢放逸；对决定之说善能受持，对差别的名言也能觉了；勤修法界理趣的方便；对诸法门善加寂静思念：当以何法与何法相应或不相应，能以方便在决定的义理上住于清净之念。

“无边慧！诸菩萨摩诃萨对这法门这样安住的，以少许加行就得一切法海印三昧，以这无量的法海三昧而发心趣向阿耨多罗三藐三菩提。”

那时，世尊说偈道：

```
汝观一切法，流入法界中，
诸法同法界，理趣悉平等。
复观于法界，流入诸法中，
法界同诸法，理趣亦平等。
不于法界中，观察一切法，
亦不离法界，而见于诸法。
不于诸法中，观察于法界，
亦不离诸法，而见于法界。
了知种种界，法界种种性，
一切法和合，善巧无所住。
一切时及处，种种性和合，
无住无所依，亦无有所取。
和合差别性，分别不分别，
于彼二俱无，智者平等见。
知一和合故，则知诸和合，
知诸和合故，则知一和合。
和合不和合，一性差别性，
不近不分别，无执无所著。
了知一切法，彼法无和合，
亦不念和合，无执无所著。
了知一切种，彼法施设相，
亦不念亲近，无执无所著。
```

（大意：你看一切法流入法界之中，诸法同于法界，理趣都平等；又看法界流入诸法之中，法界同于诸法，理趣也平等。不在法界中观察一切法，也不离开法界而见诸法；不在诸法中观察法界，也不离开诸法而见法界。了知种种界与法界的种种性，一切法的和合，善巧而无所住。在一切时与处，种种性和合，无住、无所依，也无所取。和合与差别之性，分别与不分别，对那二者都没有，智者平等而见。因为知一种和合，就知诸种和合；因为知诸种和合，就知一种和合。和合与不和合，一性与差别性，不亲近也不分别，无执也无所著。了知一切法，那法无和合，也不念和合，无执也无所著。了知一切种，那法施设之相，也不念亲近，无执也无所著。）

【按】“尔时世尊而说偈言”之“说”，《大正藏》作“来”，CBETA 据高丽藏作“说”。

```
业及业果报，一切悉能知，
于彼不相违，斯为精进者。
业及业作者，此二和合相，
知彼相无相，斯为精进者。
于诸界和合，诸界差别性，
知彼常平等，斯为精进者。
因果相系属，一切悉能知，
于彼诸缘法，被甲如理住。
能知出世法，于诸世间法，
无有少相违，如是平等住。
亦知世间法，于诸出世法，
亦无少相违，如是平等住。
世间所应作，一切诸相印，
随顺能观察，遍知平等住。
能以一法门，了知诸法门，
亦以诸法门，了知一法门。
不以一法门，亲近诸法门，
不以诸法门，亲近一法门。
一切法门中，平等遍清净，
于法无异相，斯为观察者。
于诸法言教，而能平等说，
常住平等性，斯为观察者。
于诸法言教，如理能知见，
便得善相应，斯为方便者。
```

（大意：业与业的果报，一切都能知道，对它们不相违背，这是精进者。业与造业者，这二者和合之相，知道那相即是无相，这是精进者。对诸界的和合与诸界的差别之性，知道它们常时平等，这是精进者。因果相互系属，一切都能知道，对那诸缘起之法，披甲而如理安住。能知出世间法，与诸世间法没有少许相违，这样平等而住；也知世间法，与诸出世间法也没有少许相违，这样平等而住。世间所应作的一切诸相印，能随顺观察，遍知而平等安住。能以一法门了知诸法门，也以诸法门了知一法门；不以一法门亲近诸法门，不以诸法门亲近一法门。在一切法门中平等而遍清净，对法无异相，这是观察者。对诸法的言教能平等宣说，常住于平等之性，这是观察者。对诸法的言教能如理知见，便得善巧相应，这是方便者。）

```
不起于诤论，不作诤因缘，
一切不相违，斯为相应者。
常起于无诤，无诤得相应，
平等不相违，斯为智慧者。
于法理趣中，永息诸诤论，
被甲如理修，斯为勇猛者。
如是遍观察，纯一无违诤，
能于法会中，赞说无上法。
如是诸菩萨，成就一切法，
大海印三昧，斯为正念者。
如是勤修习，纯一无违诤，
息诤论相应，成就此三昧。
如理而安住，能知秘密说，
知我及我慢，断慢绝矜高。
决定言教中，成就善方便，
亦知差别名，斯为有智者。
诸法理趣中，如理勤修习，
能见诸法门，斯为见法者。
如是勤修习，能知一切法，
何法共相应？何法不相应？
一切诸法中，念业清净者，
能于决定义，而得善方便。
一切诸法中，精进思惟者，
了知一切法，乃获此三昧。
```

（大意：不生起诤论，不作诤论的因缘，一切都不相违背，这是相应者。常生起无诤，与无诤相应，平等而不相违，这是智慧者。在法的理趣中永息诸诤论，披甲而如理修行，这是勇猛者。这样遍加观察，纯一而无违诤，能在法会中赞说无上之法。这样的诸菩萨成就一切法的大海印三昧，这是正念者。这样勤加修习，纯一而无违诤，与止息诤论相应，成就这三昧。如理而安住，能知秘密之说，知道我与我慢，断除我慢，绝去矜高。在决定的言教中成就善巧方便，也知差别之名，这是有智者。在诸法的理趣中如理勤修，能见诸法门，这是见法者。这样勤加修习，能知一切法：何法共相应？何法不相应？在一切诸法中，念业清净的人，能在决定的义理上得到善巧方便。在一切诸法中精进思惟的人，了知一切法，才获得这三昧。）

#### 法光明门与诸印门

“又，无边慧！诸菩萨摩诃萨对这法勤加修习的，又有能摄受三昧之法。仔细听，仔细听，好好思念，我当为你解说。”

无边慧说：“是的，世尊！我愿意听闻。”

那时，世尊告诉无边慧菩萨摩诃萨说：“无边慧！诸菩萨摩诃萨有法光明门，能出生诸法理趣的善巧方便，也能出生一切法印，能入于一切法印之门，对一切法所应作的能了知、能入，对法光明能得、能说，以法光明随顺趣入诸法的句门。

“什么名为法光明门而能出生善巧光明？就是能了知异名教门、秘密教门、异名事门、摄取事门、诸差别门。怎样对它们得以了知，才能出生三昧之门、一切法界理趣之门，入于一义而能随顺解了诸法光明？

“无边慧！诸菩萨摩诃萨对这甚深诸法理趣的善巧方便，无论现在修行、将来修行，现在求、将来求的，听闻这法门，以少许加行就得大光明，入于诸法门；从这法门又生起光明。以这光明，随何法门、随何所行，应当入、应当行，都如其理趣；以三昧之力观察诸法门，在三昧门中出生智慧而能了知；由于如实理趣的三昧之力、观察法门、生起智慧，以三昧门了知法界，住于善巧方便，能生起一切法门的光明，得一切法海印三昧。

#### 字印印一切法

“无边慧！什么是法门？就是以阿字印印一切法：是无明所作；行得圆满，以阿字为首；无明止息，无所作的缘故，诸菩萨摩诃萨应当入于无相印门。

“以𣘨字印印一切法：业的异熟果、业所应作、业与果的和合；因为了知业果和合之缘，诸菩萨摩诃萨应当入于无业、无果、无有和合、无缘的印门。

【按】“𣘨”字先前电子文本未能显示，今据《大正藏》补出，原有夹注“阿可反”。

“以诸行印印一切法：对于种种业、业所应作，生起一切法的智慧光明，诸菩萨摩诃萨应当入于一切诸行善巧的印门。

“以𭢟字印印一切法：以麽字辅助施设名言，与种种法相应；因为了知𭢟与麽相互辅助，诸菩萨摩诃萨应当入于无合、无助、无名的印门。

【按】“𭢟”字先前电子文本未能显示，今据《大正藏》补出，原有夹注“那可反”。以上诸字门，文义简略，依字面译出，存疑。

“以无边印印一切法：一切分别都不可得，因为远离分别，诸菩萨摩诃萨应当入于无分别的印门。

“以无际印印一切法：诸际不和合，因为穷尽边际，诸菩萨摩诃萨应当入于无寻、无伺、无言说的印门。

“以无种种自性之印印一切法：以一种自性生起造作之相，断除种种自性之想，诸菩萨摩诃萨应当入于种种自性的印门。

“以与欲相应和合之印印一切法：现起有为诸行圆满；因为离欲寂静、无有和合，诸菩萨摩诃萨应当入于尽欲、智见、无和合的印门。

“无边慧！这就是菩萨摩诃萨以印门印一切法，以这些印门应当入于一切法中。

【按】“是为菩萨”，宋、元、明、宫本作“是为诸菩萨”。

#### 无障碍门、无和合门

“无边慧！又有无障碍门、无和合门，诸菩萨摩诃萨应当随之悟入。什么是无障碍门、无和合门？就是：

“以虚空印印一切法，诸菩萨摩诃萨应当入于无著印门；以空闲印印一切法，应当入于无二印门；以寂静印印一切法，应当入于止息印门；以无门印印一切法，应当入于不动印门；以无处印印一切法，应当入于无染印门；以性空印印一切法，应当入于无得印门；以无相印印一切法，应当入于善巧修习方便印门；以无愿印印一切法，应当入于善寂静愿光明印门；以无贪印印一切法，应当入于遍知分别如实印门；以无生印印一切法，应当入于生正智见无生印门；以寂灭印印一切法，应当入于离蕴印门；以尽相印印一切法，应当入于生尽印门；以法界印印一切法，应当入于显现法界善巧印门；以无念印印一切法，应当入于实无分别平等印门；以离性印印一切法，应当入于遍知一切自性印门；以涅槃印印一切法，应当入于如实寂静顺灭印门。

“无边慧！这就是诸菩萨摩诃萨对于一切法的无障碍门、不和合门，超过一切断常之见门、无边际门、前后际门，因为厌离、寂灭、止息、清凉的缘故。诸菩萨摩诃萨对这一切法印之门随学随入，以善修行这些法门，得一切法海印三昧。这三昧，如实相应，能摄取诸法的善巧方便之智；所以诸菩萨摩诃萨对这些印门应当善加修习，住于一切法海印三昧观察一切法，而能出生无量无边的大法光明。

#### 以大海喻海印

“无边慧！譬如大海之水无量，没有能测其量的；一切诸法也是这样，终究没有能测其量的。又如大海，一切众流都流入其中；一切诸法入于法印之中，也是这样。所以名为海印，印一切法，都入于诸法海印之中；在这印中，见一切法同于法印。

“又如大龙与诸龙众，诸大身众生，能拥有大海，能入于大海，以那大海为住处；诸菩萨摩诃萨也是这样，在无量百千劫中善修诸业，才能入于这三昧印门，以那印门为住处；为了证得诸佛之法、善巧圆满一切智的缘故，成就这样的诸法印门。诸菩萨摩诃萨精勤修学这法门时，就能修学一切法门，因为见到诸法门都在这一门中，而能生起诸法的光明，入于一切法海之中，所以这法名为一切法海印三昧。又如大海是大珍宝积集之处，这三昧也是这样，是一切法以及法的善巧积集之处。

#### 付嘱法印

“无边慧！若有众生为了得到无上的佛之知见，对这三昧已求、当求、现求的，他就能求得一切法海的圆满智慧。由于这个缘故，我把这法印付嘱于你。你在末世后五十岁正法灭尽之时，以这法印印诸众生。被这法印所印的人，都于阿耨多罗三藐三菩提得不退转，成就佛法，迅速前往道场，转无上法轮，绍隆佛种，随顺安住于一切智地，能于无上大般涅槃而般涅槃，令诸天人受持正法。无边慧！诸菩萨摩诃萨若想摄取这样无量殊胜的功德，对这深法应当精勤爱乐而不放逸。

【按】“后五十岁”，明本作“后五百岁”，与本会卷第二十三“末世后五百岁”相合。

### 超过须弥光王如来时二菩萨

“又，无边慧！我忆念往昔，超过极大无量阿僧祇劫，又加倍那么多劫，那时有佛出现于世间，号为超过须弥光王如来、应供、正遍知、明行足、善逝、世间解、无上士、调御丈夫、天人师、佛、世尊。劫名善住，国名悦意。那时那劫中众生的寿命不可限量，安稳丰饶，安住众善法，所以那劫名为善住。那佛的国界广博庄严，多有美妙之物，见者和乐悦意，名香周流普遍，所以那国名为悦意。

“那时四洲之中，三洲大小等同，各八万由旬，每一洲中有二万座城，每一座城各十由旬。唯有阎浮一洲，广一俱胝由旬，有八万座城，每一座城二十由旬，有重楼、表刹、垣墙周匝，以种种衣树、种种味树、诸杂花树、宝多罗树庄严，国界安乐，人民充满。其中又有一座最大的都城，周围百由旬，有二万座园苑围绕。诸园苑中，澄澈的深潭与回流处处盈满注灌，花蕊与甘美的果实一一繁茂，名香普熏，闻者欣悦，鸟兽和鸣，其声雅亮。那时那佛住在一座园中为大众说法。

【按】“二万园苑”之“苑”，宫本作“华”。“泝流”之“泝”，宫本作“素”。

“无边慧！超过须弥光王如来寿命十小劫，灭度之后正法住世满一小劫。那时那如来四次集会说法；每一法会中，诸声闻众住于有学地的各有五百俱胝那由他，诸阿罗汉及菩萨众各有五十俱胝那由他。

“那时那如来有两位菩萨：一名勇猛军，二名勇猛力。这两位菩萨具足神通，得无生忍，上前对佛说：‘世尊！以什么法成就菩萨摩诃萨的一切诸法海印三昧？’那时那如来以这句门为他们广为宣说。说这法时，一万菩萨得无生忍；这两位菩萨证得一切法海印三昧以及证得菩萨的一切三昧。由于证得诸法海印三昧以及菩萨的诸三昧，能在一切佛刹土中现大神变，放大光明，出微妙梵音，为诸众生演说正法，能成熟八俱胝人趣向阿耨多罗三藐三菩提。

【按】“是二菩萨证”之“二”，宫本作“名”。

“那时那如来就为他们授记：‘过一百劫，都当证得阿耨多罗三藐三菩提。在百劫之中，每一劫供养承事五百位如来，对那些如来的中时正法、后时正法都能受持，为诸众生作大饶益。每一劫中一心不乱，每一生处都受化生，每一生中不退失三昧，以神变说法度诸众生。过百劫后，又遇到无边功德如来，供养亲近，善能游戏无量三昧、神变、解脱。’

“这两位菩萨在那佛所，一名离忧，二名善住，能随如来转于法轮，教化无量无数众生，令他们安住于三乘。那时那如来又为他们授记：‘我灭度后，离忧当证阿耨多罗三藐三菩提，号为无边辩才如来；他灭度之后，善住当证阿耨多罗三藐三菩提，号为最胜光明如来。共寿一劫，刹土积集无量功德。’这两位菩萨在如来面前受此授记后，次第证得阿耨多罗三藐三菩提。无边慧！若诸菩萨摩诃萨为了一切法海印三昧，应当生起爱乐，发起大精进，不惜身命，以不放逸而修行。”

### 慧义菩萨赞叹

那时，大众中又有一位菩萨摩诃萨名叫慧义，即从座起，上前对佛说：“希有，世尊！竟能为诸菩萨摩诃萨得一切法智的善巧、得如来一切智的缘故，宣说一切法海印三昧。世尊！若得诸法海印三昧，决定当得诸法理趣的善巧方便，迅速前往道场，以这无边功德大海而发心趣向阿耨多罗三藐三菩提，常见诸佛，勤修正法，与僧同行，能受用如来最上的供养，超过声闻、缘觉之地。”

那时，世尊告诉慧义菩萨摩诃萨说：“是这样，是这样，如你所说。慧义！诸菩萨摩诃萨得一切法海印三昧，就得无量殊胜功德。若住于诸法海印三昧，能以诸法海印三昧的善巧方便，决定趣向阿耨多罗三藐三菩提。

“慧义！譬如须弥山王由众宝所成，出于大海，高八万四千由旬，巍然安住，光明最为极盛；诸菩萨摩诃萨也是这样，以这三昧善于发趣的缘故，出于一切法藏的大海，映蔽一切世间天人，无上安住，光明最为极盛。又如满月为众星围绕；诸菩萨摩诃萨也是这样，能在一切世间天人大众之中作大光明。

“慧义！你看这法，有谁对它不生爱乐、不起精进而放逸呢？唯除下劣薄福的众生。若诸众生有大智慧，就能成就这广大之法。广大之法，具足功德，是诸善丈夫所摄取的。如我所说，若能摄取这广大的法财，就为诸天人所侍卫，为十方诸佛、诸大菩萨所护念。”

那时，世尊告诉无边慧菩萨摩诃萨说：“无边慧！诸菩萨摩诃萨若对这法勤加修学，能为众生作大饶益，除一切疑，解一切结，舍诸习气，断诸随眠，超越诸喜爱，渡过诸有之海，永灭黑暗，永离惊怖，迅速以善巧能知一切众生之心。”

### 放光动地与付嘱

那时，世尊说完这话，放大光明，那光明遍照无数世界，映夺一切日月的光明。放出这光明后，又告诉无边慧菩萨摩诃萨说：“无边慧！诸菩萨摩诃萨若能勤修海印三昧，也当这样现大神变，放大光明，作大师子吼，演说这法，超过三界，作大照明，如我今日一样，没有差异。”

这时，无边慧菩萨摩诃萨对佛说：“世尊！唯愿如来加持这法，在后来的末世，若有众生听到这法之名，当获得无量无边的功德。”

那时，世尊为了加持这法门，又放出光明，又以一根手指遍动三千大千世界，令诸众生得到大安乐。这时会中的天、龙、夜叉、乾闼婆、阿修罗、迦楼罗、紧那罗、摩睺罗伽等众，散天上的妙花与天上的妙衣，天上的诸伎乐同时奏起。无量诸天手持天衣，摇曳翻飞，充满虚空之中，同声唱言：“奇哉，奇哉！诸佛的境界不可思议。若有受持这深法的人，应当知道他堪受一切众生恭敬作礼。”

【按】“摇裔”之“裔”，宋、元、明、宫本作“曳”，今从之。

那时，世尊又告诉无边慧菩萨摩诃萨说：“无边慧！在后来的末世，薄福的众生听不到这甲胄庄严、三昧庄严。若诸众生有善巧方便，摄取了大资粮，在后来的末世才能听到这法。若对这法勤加修行，就为三世诸佛世尊所摄受。无边慧！在后来末世大怖畏之时，我把这法门付嘱于你们。我在无数俱胝那由他劫中积集的无上诸法宝藏，具足功德与无边安乐，你们现在都已得到；一切苦蕴，你们现在都已舍弃。你们以无边的功德大海，迅速趣向阿耨多罗三藐三菩提。”

那时，无边慧菩萨摩诃萨与五百位菩萨摩诃萨，以及诸居士，以贤护商主等为上首，顶礼佛足，说道：“世尊！我们随自己的力量，当受持如来的大菩提法，在后来的末世为诸众生作大饶益。”

那时，诸菩萨摩诃萨各从座起，以诸杂花散在如来身上，脱下身上的妙衣用来供养，这样说：“世尊！以这善根，我们都回向一切众生，愿诸众生都得圆满菩提分法，成就如来的一切法智。在后来的末世，一切众生所有的善根，愿都得成就。”

那时，世尊为了令一切菩萨摩诃萨生起欢喜，说偈道：

```
为诸众生故，当兴大饶益，
持我菩提法，法王师子吼。
于后末世中，若诸求法者，
闻斯广大法，一切获安乐。
如我之所说，若有见此乘，
闻斯契经法，得随其所乐。
若有智慧者，修习善方便，
闻斯最上法，身心大欢喜。
若在于此会，现前见我说，
得闻斯法已，善能爱乐者。
于后末世中，生汝大福聚，
无数无有量，广大无边际。
于后末世中，若能受持此，
法王所说法，为佛之摄受。
于后末世中，持我菩提法，
则为无量佛，最后持法者。
```

（大意：为了诸众生的缘故，你们当兴起大饶益，受持我的菩提法，作法王的师子吼。在后来的末世中，若有诸求法的人，听闻这广大之法，一切都获安乐。如我所说，若有人见到此乘，听闻这契经之法，就能随其所乐而得。若有智慧的人修习善巧方便，听闻这最上之法，身心大欢喜。若有人在这会中，现前见我宣说，听闻这法后善能爱乐，在后来的末世中，就会生出你们的大福聚，无数无量，广大无边。在后来的末世中，若能受持这法王所说之法，就为佛所摄受。在后来的末世中，受持我的菩提法，就是无量诸佛最后的持法者。）

【按】“契经法”之“法”，宫本作“说”。

那时，世尊说完这法，无量菩萨得无生忍，无量众生成熟善根。无边慧菩萨摩诃萨及诸菩萨摩诃萨，以及一切世间的天、人、阿修罗等，听闻佛所说，都大欢喜，信受奉行。

【按】被甲庄严会至此终，本会凡五卷（卷第二十一至卷第二十五），未见汉译异本对勘。
