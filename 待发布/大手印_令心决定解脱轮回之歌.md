# 令心决定解脱轮回之歌

阿阇黎吉祥燃灯智（阿底峡）造　嘉尊僧格、楚臣嘉瓦 译

## 题解

本篇出自德格版丹珠尔续部（རྒྱུད་འགྲེལ།）ཞི 函第253a叶第6行至第254b叶第7行，东北目录编号 D2313。全篇一百三十一句，句长不一，另有礼敬与跋语。篇幅不长，所以把藏文原文全部保留在代码块中（逐句排列），按意义段落分开，每段后附汉译，疑难之处另以【按】说明。

梵文题名：Saṃsāra-manoniryāṇīkāra-nāma-saṃgīti（ས་ན་ས་ར་མཱ་ན་ནི་ཡཱ་ཎི་ཀ་ར་ནཱ་མ་སངྒཱི་ཏི），拼写似有讹变，照录不改。

藏文题名：འཁོར་བ་ལས་ཡིད་ངེས་པར་འབྱུང་བར་བྱེད་པ་ཞེས་བྱ་བའི་གླུ（令心于轮回决定出离之歌）。跋语中作“འཁོར་བ་ལ་ཡིད་ཆེས་པར་འབྱུང་བར་བྱེད་པ”，“ངེས”作“ཆེས”，当是传抄之异。

【按】跋语说本篇是“阿阇黎吉祥燃灯智亲造”，即阿底峡尊者（Atiśa Dīpaṃkaraśrījñāna）。由尊者本人与大校订译师嘉尊僧格（རྒྱ་བསྟོན་སེང་གེ）在超戒寺译出；后来又由尊者本人与译师楚臣嘉瓦（ཚུལ་ཁྲིམས་རྒྱལ་བ，即纳措译师）修订定稿。可见本篇是阿底峡在印度时就已译成藏文的作品，后来到藏地又重新修订。

【按】本篇是一首劝人出离轮回的道歌，内容属于“共同前行”：先讲轮回的因（烦恼与业）、业的分类与成熟次第、十二缘起；然后讲轮回之苦，特别是人道从入胎到衰老之苦；再着重讲寿命无常、死期不定，生动描写人们“明日复明日”而死主已在身旁；然后劝人取舍精要，不必遍学诸论，但求能令心安住的上师口诀；舍弃一切贪著，住于寂静；最后给出数息、不净、慈心、缘起等对治分别的口诀。与前面几篇大手印见地论相比，本篇是修持大手印之前必不可少的出离心的基础。

## 正文

### 一、礼敬医王

```
ཨེ་མའོ། །
འདུ་བྱེད་སྡུག་བསྔལ་འགྱུར་བའི་སྡུག་བསྔལ་དང་། །
སྡུག་བསྔལ་སྡུག་བསྔལ་ལ་སོགས་བརྒྱ་རྩ་བཅུ། །
སྡུག་བསྔལ་ཀུན་ལས་སྐྱོབ་པར་མཛད་པ་ཡི། །
སྨན་པའི་རྒྱལ་པོ་དེ་ལ་ཕྱག་འཚལ་ལོ། །
```

唉！行苦、坏苦、苦苦等等，共一百一十种苦——能从一切苦中救护众生的那位医王，我向他顶礼。

【按】“医王”指佛陀，佛陀如良医，能治众生的一切苦病。“行苦、坏苦、苦苦”是佛经中所说的三苦。“一百一十种苦”，见于《瑜伽师地论·菩萨地》等论典，是对苦的详细分类。

### 二、轮回之因：烦恼与业

```
ཀྱེ་ཀྱེ་ཀྭའི་གྲོགས་པོ་དག། །
འཁོར་བའི་རྒྱུ་ནི་ཉོན་མོངས་པ་དང་ལས། །
ཉོན་མོངས་ཁམས་གསུམ་གནས་ནི་དགུ་བཅུ་བརྒྱད། །
ཟག་པའི་ཆུ་བོ་སྦྱོར་བ་ཉེ་བར་ལེན། །
རྒྱུ་དང་ཡུལ་དང་སྦྱོར་བའི་སྟོབས་ཀྱིས་བྱུང་། །
```

喂，喂，朋友们！轮回的因，是烦恼与业。三界的烦恼，以九十八种（随眠）为所依；还有漏、暴流、轭、取，都是由因、境与加行的力量而生起的。

【按】“ཀྱེ་ཀྱེ་ཀྭའི་གྲོགས་པོ་དག”，是全篇反复出现的呼唤，“ཀྭའི”是呼告语气词，这里译作“喂，喂，朋友们”。

【按】“九十八随眠”是《俱舍论》所说三界烦恼的总数。“漏、暴流、轭、取”，是阿毗达磨中对烦恼的四种分类。“因、境、加行”，指烦恼生起的三种条件：烦恼的种子（因）、所对的境界、不如理作意（加行）。

### 三、业的分类与成熟次第

```
ཀྱེ་ཀྱེ་ཀྭའི་གྲོགས་པོ་དག། །
སྣ་ཚོགས་འདི་དག་ལས་ལས་བྱུང་། །
དེ་ཡང་ཉོན་མོངས་སྟོབས་ལས་བྱུང་། །
དགེ་དང་མི་དགེ་ལུང་མ་བསྟན། །
མཐོང་ལ་མྱོང་དང་སྐྱེས་ནས་མྱོང་། །
གཞན་དུ་མྱོང་དང་མ་ངེས་པའི། །
དཀར་དང་གནག་དང་འདྲེན་མའོ། །
འཁོར་བའི་ལས་ནི་ལྕི་གང་དང་། །
ཉེ་བ་གང་དང་གོམས་པ་གང་། །
སྔོན་བྱས་གང་ཡིན་དེ་ལས་ནི། །
སྔ་མ་སྔ་མ་རྣམ་སྨིན་འགྱུར། །
```

喂，喂，朋友们！这种种（世间），都是从业而生的；而业又是从烦恼的力量而生的。（业有）善、不善与无记；有现法受、顺生受、顺后受与不定受；有白业、黑业与混杂的业。轮回中的业，哪个重、哪个临近（死时）、哪个是串习、哪个是先前所作的，就依照这个次第，先后成熟果报。

【按】“现法受、顺生受、顺后受、不定受”，是依果报成熟时间所分的四种业。“白、黑、混杂”，是依业的性质所分。“重、近、串习、先作”，是《俱舍论》等所说业成熟的先后次第：重业先熟，其次是临终时的业，其次是串习的业，其次是先前所造的业。

【按】第18句“འདྲེན་མ”，依上下文应是“འདྲེས་མ”（混杂）的讹误，这里依此译出。

### 四、十二缘起，迷乱轮转

```
གྲོགས་དག་སོམས་ཤིག་ཐོག་མ་མེད་པ་ནས། །
མ་རིག་ལ་སོགས་བཅུ་གཅིག་རྒ་ཤིའི་མཐའ། །
ཡན་ལག་བཅུ་གཉིས་ཆ་གསུམ་ཟོ་ཆུན་ཚུལ། །
ནང་གི་རྟེན་འབྲེལ་ཡང་དང་ཡང་དུ་འཁོར། །
ཚེ་རབས་ཚེ་རབས་གྲངས་མེད་དེ་དང་དེར། །
སྐྱེ་དང་རྒ་དང་ན་དང་འཆི་བ་ཡི། །
སྡུག་བསྔལ་རྣམས་ཀྱིས་ཡང་དང་ཡང་དུ་གདུངས། །
འཁྲུལ་ནས་འཁོར་གྱུར་འཁྲུལ་ཅིང་འཁོར་བར་འགྱུར། །
```

朋友们，想一想吧！从无始以来，无明等等，直到老死为止，十二支分成三份，像水车的斗一样，内在的缘起一再地轮转。生生世世，无数次地，在那里被生、老、病、死的痛苦一再煎熬；因为迷乱而轮回，又在迷乱中继续轮回。

【按】“十二支分三份”，是把十二缘起分为过去、现在、未来三世，或分为惑、业、苦三类。“像水车的斗”，水车上的斗一个接一个地上下轮转，比喻十二缘起循环不息。第24句“བཅུ་གཅིག”（十一）与“十二支”不合，可能是说“从无明起的十一支，直到老死”，这里依文意译出。

### 五、以苦为乐，与畜生无别

```
ཀྱི་ཧུད་སྲིད་པའི་ལམ་གྱིས་དུབ་པའི་འགྲོན་པོ་རྣམས། །
སྡུག་བསྔལ་བདེ་བར་བཟུང་ནས་མི་སྐྱོ་བ། །
ཁྱེད་ཡིད་དེ་ལ་རྟག་ཏུ་ཆགས་བྱེད་པ། །
ཕྱུགས་དང་ཁྱད་པར་མེད་པར་བླ་མ་གསུང་། །
```

唉！在三有之路上疲惫不堪的旅客们，把痛苦执为安乐，而不生厌离；你们的心常常贪著于此，上师说，这与畜生没有差别。

### 六、观众生苦，由骨髓生悲

```
བླ་མས་ཟིན་པའི་སྐྱེ་བོ་མཁས་པ་དག། །
སྐད་ཅིག་སྐད་ཅིག་འགྲོ་བ་ལྔ་པོ་ཀུན། །
འཁོར་བའི་སྡུག་བསྔལ་ཚེར་མ་ཟུག་འདྲ་ལ། །
རུས་པའི་གཏིང་ནས་སྙིང་རྗེ་སུ་མི་སྐྱེ། །
ལས་ངན་དབང་གིས་འཁོར་བའི་རྒྱ་མཚོ་འདིར། །
ཡང་ཡང་སྐྱེ་ཞིང་ཡང་ཡང་རྒ་དང་ན། །
ཡང་ཡང་འཆི་འགྱུར་འདི་ནི་མི་སེམས་པར། །
ཡུལ་ལ་ཆགས་བྱེད་བདག་གིས་ཇི་ལྟར་བྱ། །
```

被上师所摄受的智者们！五道的一切众生，在每一刹那，都受着轮回之苦，就像被荆棘刺扎一样，谁能不从骨髓深处生起悲心呢？由于恶业的力量，在这轮回的大海中，一再地出生，一再地衰老与生病，一再地死去——不去思惟这些，却贪著于境界，我该怎么办才好呢？

【按】“五道”，是把天与非天合并，或不计非天，所说的五趣。

### 七、人道之苦：从入胎到衰老

```
གྲོགས་དག་སྲིད་པ་གསུམ་ནང་གནས་པ་ཀུན་སྡུག་བསྔལ། །
དེ་ཡང་མི་ཡི་སྡུག་བསྔལ་བདག་གིས་མཐོང་། །
མངལ་གྱི་སྡུག་བསྔལ་འདི་ལྟ་བུ་རུ་གནས། །
ནུར་ནུར་མེར་མེར་གོར་གོར་ནར་ནར་པོ། །
ལྟར་ལྟར་མཁྲང་དང་རྐང་ལག་རིམ་གྱིས་རྫོགས། །
ནུ་ཞོ་མར་གྱིས་གསོ་བྱེད་ཅིང་། །
ཤིན་ཏུ་ཉམ་ཆུང་གན་རྐྱལ་ཉལ། །
བྱིས་པ་དར་མ་ལང་ཚོ་དང་། །
རྒས་པས་སླར་ཡང་བྱིས་བར་འགྱུར། །
```

朋友们，住在三有中的一切都是痛苦；其中，人的痛苦，我亲眼见到了。胎中的痛苦，是这样的：（胚胎）滑软、稠浊、凝结、渐渐坚实，然后逐渐长成躯干与手脚。（出生以后）用乳、酪、酥来养育，非常孱弱，只能仰卧。经历童年、壮年与青春，衰老之后又重新变得像孩子一样。

【按】第46句“ནུར་ནུར་མེར་མེར་གོར་གོར་ནར་ནར་པོ”，描写胎儿在母胎中逐步形成的几个阶段，佛经中称为羯罗蓝、頞部昙、闭尸、键南等（各家说法与译名不完全相同）。这里依藏文字面的意思译出，不作一一对应。

### 八、寿命无常，必定会死

```
ཚེ་ནི་མི་རྟག་ཤིན་ཏུ་གཡོ་བ་སྟེ། །
ཡུད་ཙམ་སྡོད་པའི་མཐུ་ཡང་ཡོད་མ་ཡིན། །
བདག་ནི་ངེས་པར་འཆི་འགྱུར་མི་སེམས་པ། །
གྲོགས་དག་སྐྱེས་བུ་དེ་ནི་ངོ་མཚར་ཆེ། །
འཁོར་བའི་སྐྱོན་དང་ཉེས་དམིགས་མི་ཤེས་པས། །
ཕྱིན་ཅི་ལོག་པ་བཞི་ལ་གནས་ནས་སུ། །
བདག་ནི་ངེས་པར་འཆི་འགྱུར་མི་སེམས་པར། །
ཡུལ་ལ་མངོན་ཞེན་ཉིན་མཚན་དོན་མེད་འདས། །
```

寿命是无常的，非常动摇，连片刻停留的力量都没有。不想到“我必定会死”的人，朋友们，那人真是稀奇！由于不知道轮回的过患与过失，安住于四种颠倒之中，不想到“我必定会死”，贪著于境界，日日夜夜都无意义地度过。

【按】“四种颠倒”，指以无常为常、以苦为乐、以不净为净、以无我为我。

### 九、死期不定

```
འཛམ་བུའི་གླིང་པ་དུས་མིན་འཆི་བས་ཏེ། །
ངེས་པ་ཅན་ཡང་ཟད་པར་འགྱུར་བས་ན། །
ཡང་དང་ཡང་དུ་ངེས་པར་འཆི་འོ་ཞེས། །
བསམ་པར་རིགས་སོ་ཀྭའི་བཞིན་བཟང་དག། །
སོ་ག་མེ་ཏོག་རྒྱས་པའི་དུས་འདི་བྱུང་བར་གྱུར། །
ཟླ་བ་གསལ་བས་མཚོན་པའི་སྟོན་དུས་འདི་འབྱུང་ཞེས། །
སྐྱེ་བོ་ཐམས་ཅད་དགའ་འགྱུར་བདག་གི་ཚེ་འདི་ནི། །
ཟད་པར་འགྱུར་ཞེས་ཤིན་ཏུ་མི་དགར་འགྱུར་བ་མེད། །
```

南赡部洲的人，会非时而死；即使有一定寿量的，也终将耗尽。所以，应当一再地想：“我必定会死。”相貌端好的朋友们！（人们说）“春天花开的时节到了”“明月所表的秋天到了”，一切人都很欢喜；却没有一个人，会因为想到“我的寿命将要耗尽”而深深地不乐。

【按】“南赡部洲的人会非时而死”，佛经中说，北俱卢洲的人寿命有定，而南赡部洲的人寿命无定，随时可能死亡。

### 十、明日复明日，死主已在侧

```
དེ་རིང་འདི་བྱ་སང་ནི་འདི་བྱ་དེ་ནས་འདི་དང་འདི་བྱ་ཞེས། །
སྲིད་པ་གཡོ་བའི་རང་བཞིན་མ་ཤེས་དོན་མེད་ཡིད་བརྟན་ཚོལ་བྱེད་པའི། །
སྐྱེ་དགུ་འཆི་བདག་གི་ནི་ཆུ་སྲིན་ཁར་ནི་གྲུ་ནི་ཞུགས་པ་ལྟར། །
བྱ་བ་མཐར་མ་ཕྱིན་པར་ཡུལ་གྱི་ཆུ་ཡི་དབའ་ཀློང་ནང་དུ་ལྷུང་། །
འདི་ནི་སང་བྱ་འདི་ནི་ཐང་ཅིག་འོག་ཏུ་བྱ། །
འདི་ནི་དེའུ་རེ་བྱ་ཞེས་སྐྱེ་བོ་སེམས་པ་ན། །
གཤིན་རྗེ་བེ་ཅོན་ལག་ཐོགས་ཟུར་གྱིས་ལྟ་བྱེད་ཅིང་། །
མིག་རྩ་དམར་ཁྲོས་མ་རུངས་གད་མོས་རེ་སྙམ་འདེབས། །
རྣལ་འབྱོར་བསྟན་བཅོས་ཐམས་ཅད་དང་། །
སྦྱོར་བ་དུ་མ་རབ་ཤེས་ཀྱང་། །
དེང་བྱ་སང་བྱ་ཞེས་སྨྲ་ཞིང་། །
བསམ་དང་ལྡན་པས་འཆི་བར་འགྱུར། །
```

“今天做这件事，明天做那件事，然后再做这件和那件。”不知道三有动摇的本性，毫无意义地寻求安稳的众生，就像驶进了死主摩羯鱼口中的船一样，事情还没有做完，就落入了境界之水的波涛之中。“这件明天做，这件过一会儿做，这件稍后再做。”当人们这样想的时候，阎罗手持棍棒，正斜眼看着，眼角充血，愤怒凶暴，狞笑着暗想：“（看你）还盼什么！”即使精通一切瑜伽论典与种种修法，口里说着“今天做、明天做”，怀着种种打算，就死去了。

【按】这一段是全篇最生动的部分：人们总在计划明天、后天，却不知死主已在身旁冷笑。“死主摩羯鱼”，以摩羯鱼（海中大鱼）比喻死亡，船驶入其口，无可逃脱。第75句“རེ་སྙམ་འདེབས”意思不完全确定，这里依文意译作“暗想：看你还盼什么”。

【按】“即使精通一切瑜伽论典”而仍拖延修行，是对学者的警策：学问再多，不及时实修，死时也无用。

### 十一、一息不还，明日何有

```
ཚེ་འདི་གནོད་མང་རླུང་གིས་བཏབ་པ་ཡི། །
ཆུ་ཡི་ཆུ་བུར་བས་ཀྱང་མི་རྟག་ན། །
དབུགས་འབྱུང་དབུགས་རྔུབ་གཉིད་ཀྱིས་ལོག་པ་ལས། །
སང་ཁོམ་གང་ལགས་དེ་ནི་ངོ་མཚར་ཆེ། །
```

这生命被众多危害之风所吹，比水泡还要无常；呼出一口气、吸进一口气、睡着之后，（还能醒来而）有明天的空闲，那真是稀奇！

【按】这一偈与龙树《亲友书》中“寿命多害，比风中的水泡还要无常；呼气吸气、睡后能醒，这正是稀有”的偈子意思相同，阿底峡大概是化用了龙树的这一名偈。

### 十二、如鹅取乳，取所当取

```
ཀྱེ་ཀྱེ་ཀྭའི་གྲོགས་པོ་དག། །
ཚེ་ནི་ཡུན་ཐུང་ཤེས་བྱའི་རྣམ་པ་མང་། །
ཚེ་ཡི་ཚད་ཀྱང་ཅི་ཙམ་མི་ཤེས་པས། །
ངང་པས་ཆུ་ལས་འོ་མ་ལེན་པ་ལྟར། །
རང་གི་འདོད་པ་དང་ལ་བླང་བར་གྱིས། །
```

喂，喂，朋友们！寿命短暂，所知的种类却很多；寿命有多长，也不知道。所以，要像天鹅从水中取乳一样，取自己所需要的。

【按】“天鹅从水中取乳”，是印度著名的譬喻：天鹅能把水与乳分开，只饮乳汁；比喻在浩如烟海的知识中，只取对解脱最有用的精要。

### 十三、观照自心

```
ཀྱེ་ཀྱེ་ཀྭའི་གྲོགས་པོ་དག། །
འཇིག་རྟེན་སྤྱོད་པ་དག་ལ་ཕར་བལྟས་ན། །
བྱས་པ་ཐམས་ཅད་དོན་མེད་སྡུག་བསྔལ་རྒྱུ། །
ཅི་ལ་བསམས་ཀྱང་ཕན་པར་མི་འགྱུར་བས། །
རང་གི་སེམས་ལ་ལྟ་བ་གོམས་པར་གྱིས། །
```

喂，喂，朋友们！向外去看世间的种种作为，所作的一切都没有意义，都是痛苦之因；无论想什么，都没有真正的益处，所以要串习观照自己的心。

### 十四、不必遍学诸论，但求安心口诀

```
ཀྱེ་ཀྱེ་ཀྭའི་གྲོགས་པོ་དག། །
ཚད་མ་བདུན་དང་བརྡ་སྤྲོད་རྣམ་པ་བཞི། །
མངོན་པ་དང་ནི་ཡོ་ག་ཙརྱའི་ས། །
མདོ་སྡེ་དང་ནི་འདུལ་བ་མངོན་པ་དང་། །
གཞུང་དུ་བཀོད་པ་མ་ལུས་ཐམས་ཅད་ཀུན། །
མ་མཐོང་མ་མཉན་མ་བཤད་མ་བྲིས་ཞེས། །
དེ་ལ་གདུང་བ་མ་བསྐྱེད་བཞིན་བཟང་དག། །
བླ་མའི་མན་ངག་ཅེས་བྱ་བདུད་རྩིའི་རོ། །
གང་གིས་སེམས་མཉམ་འཇོག་པ་དེ་ཙམ་ཞིག། །
ཡོངས་སུ་བཙལ་གྱིས་གཞུང་མང་ཅི་ཞིག་དགོས། །
ཐམས་ཅད་ཡིད་ནི་འཁྲུལ་པར་བྱེད་པའི་རྒྱུ། །
```

喂，喂，朋友们！七部量论、四种声明，阿毗达磨与瑜伽师地，经藏、律藏与论藏，论典中所记载的一切，全部都——（如果自己）“没有见过、没有听过、没有讲过、没有写过”，贤善的朋友们，不要为此生起焦虑。所谓上师的口诀，是甘露之味；只要寻求能使心平等安住的那一点就够了，要那么多论典做什么呢？一切（多余的）都只是令心迷乱之因。

【按】“七部量论”是法称的七部因明论；“四种声明”指声明学（语法学）的几种主要论著；“瑜伽师地”即《瑜伽师地论》。

【按】这一段必须正确理解：阿底峡本人是极为博学的大班智达，这里并不是否定闻思与经论的价值，而是针对寿命短暂、急需实修的人说：与其追求遍学一切论典，不如专心求得上师能使心安住的口诀，依之实修。前面的闻思是必要的基础，这里强调的是闻思之后不可只停留在多学多闻上，而要落实于修。读者千万不要误解为可以不学经论。

### 十五、舍弃一切贪著

```
འཁོར་བའི་གནས་འདི་ངེས་པ་མེད་པས་ན། །
ཕ་མ་ལ་སོགས་ཕ་མར་མ་ངེས་པས། །
ཉེ་དུ་འབྲེལ་པ་དག་ལ་ཆགས་པ་སྤངས། །
དགྲ་ཡང་མ་ངེས་དེ་ལ་སྡང་བ་སྤངས། །
ནད་མེད་ལང་ཚོ་ཕུན་སུམ་ཚོགས་པ་དང་། །
འདོད་ཡོན་ལྔ་ལ་རང་བཞིན་གྱིས་ཆགས་སྤངས། །
རྙེད་པ་དང་ནི་བཀུར་སྟི་གྲགས་པ་དང་། །
རིགས་དང་རུས་དང་ཚིགས་སུ་བཅད་པ་སྤངས། །
སློབ་མ་ཡང་སློབ་ཆོས་ཀྱི་འབྲེལ་པ་སྤངས། །
```

因为轮回之中没有定准，父母等也不一定（永远）是父母，所以要舍弃对亲属的贪著；仇敌也不一定（永远是仇敌），所以要舍弃对他的嗔恨。对于无病、青春与圆满，以及五种欲妙，要舍弃本能的贪著；要舍弃利养、恭敬与名声，种姓、家族与诗文；也要舍弃与弟子、再传弟子之间的法缘。

【按】“父母不一定是父母，仇敌不一定是仇敌”，是佛经中常说的道理：在无始轮回中，一切众生都曾互为亲怨，所以亲怨都没有定准。

【按】“舍弃与弟子、再传弟子之间的法缘”，是对专心实修者而说的：为了专注于自己的修行，不再为收徒传法等事务所缠绕。这并不是否定弘法利生，而是说在一心实修的阶段，要放下这些牵挂。

### 十六、远离世间，住于寂静

```
ཀྱེ་ཀྱེ་ཀྭའི་གྲོགས་པོ་དག། །
འཇིག་རྟེན་སྟག་སྦྲུལ་མེ་དང་དུག་འདྲ་བར། །
བསམས་ནས་སྤངས་ཏེ་དབེན་པར་གནས་པར་བྱ། །
བུད་མེད་མཚན་ཉིད་སྐྱེས་པའི་མཚན་ཉིད་དང་། །
སྨན་དང་གླང་ཆེན་བརྟགས་པའམ་གཟའ་སྐར་རྩིས། །
མཚོན་ཆ་བརྟགས་པའམ་རྟ་དཔྱད་རང་བཟོའམ། །
བསྟན་བཅོས་ངན་པ་སློབ་དང་ཀློག་པ་སྤངས། །
```

喂，喂，朋友们！把世间看作猛虎、毒蛇、烈火与毒药一样，思惟之后舍弃它，住在寂静之处。要舍弃学习与阅读：看女人相、看男人相，医药、相象，星象历算，相兵器、相马、工巧，以及种种恶论。

【按】这里所列的种种学问（相术、医药、星算、工巧等），在当时是谋生或世间的技艺。阿底峡劝专心实修的人放下这些世间学问。这也是就实修的阶段而说的。

### 十七、对治分别的口诀

```
ཡུལ་ལ་མངོན་དགའི་སེམས་ནི་བྱུང་བ་དང་། །
རྣམ་རྟོག་དེ་དག་རྣམས་ནི་བྱུང་བ་ནས། །
བདག་ནི་ངེས་པར་འཆི་བ་དྲན་བྱས་ལ། །
འོག་ནས་འབྱུང་བའི་གཉེན་པོ་རྣམས་ཀྱིས་བཟློག། །
རྣམ་རྟོག་མང་བ་དབུགས་བགྲང་པ་ཡིས་གཞིལ། །
འདོད་ཆགས་སེམས་བྱུང་རྣམ་པར་རྟོག་པ་དེ། །
རང་བཞིན་མི་གཙང་ཀེང་རུས་བལྟ་བས་བཟློག། །
ཞེ་སྡང་ལ་ནི་བྱམས་པའི་ཆུ་ཡིས་བཏབ། །
གཏི་མུག་ལ་ནི་རྟེན་འབྲེལ་ལམ་གྱིས་སོ། །
མི་གཙང་བ་དང་བྱམས་པ་རྟེན་འབྲེལ་གྱི། །
མན་ངག་བླ་མའི་ཞལ་ནས་འབྱུང་བཞིན་བྱ། །
```

当对境界生起贪乐之心、生起这些分别的时候，要忆念“我必定会死”，并以下面所说的对治来遮止它们：分别念多的时候，以数息来平息；贪欲的心所与分别，以观察自性不净的骨锁来遮止；对于嗔恨，浇以慈心之水；对于愚痴，以缘起之道（来对治）。不净观、慈心观与缘起观的口诀，要依照上师亲口所说的去修持。

【按】这一段讲的是对治烦恼的具体口诀，与佛教传统的“五停心观”相近：数息观对治散乱，不净观（骨锁观）对治贪欲，慈心观对治嗔恨，缘起观对治愚痴。阿底峡特别强调，这些口诀要依上师的亲口传授来修持。

## 跋语

```
འཁོར་བ་ལ་ཡིད་ཆེས་པར་འབྱུང་བར་བྱེད་པ་ཞེས་བྱ་བའི་གླུ། །སློབ་དཔོན་དཔལ་མར་མེ་མཛད་ཡེ་ཤེས་ཀྱི་ཞལ་སྔ་ནས་མཛད་པ་རྫོགས་སོ།། །།རྒྱ་གར་གྱི་མཁན་པོ་དེ་ཉིད་དང་། ཞུ་ཆེན་གྱི་ལོ་ཙཱ་བ་རྒྱ་བསྟོན་སེང་གེས་བི་ཀ་མ་ལ་ཤཱི་ལའི་གཙུག་ལག་ཁང་དུ་བསྒྱུར་བའོ། །སླད་ནས་བླ་མ་དེ་ཉིད་དང་། ལོ་ཙཱ་བ་ཚུལ་ཁྲིམས་རྒྱལ་བས་བཅོས་ཤིང་གཏན་ལ་ཕབ་པ།།
```

名为《令心于轮回决定出离之歌》，阿阇黎吉祥燃灯智亲造，圆满。由那位印度堪布本人与大校订译师嘉尊僧格，在超戒寺译出。后来又由那位上师本人与译师楚臣嘉瓦修订定稿。

## 通篇连读

唉！行苦、坏苦、苦苦等等，共一百一十种苦——能从一切苦中救护众生的那位医王，我向他顶礼。

喂，喂，朋友们！轮回的因，是烦恼与业。三界的烦恼，以九十八种（随眠）为所依；还有漏、暴流、轭、取，都是由因、境与加行的力量而生起的。

喂，喂，朋友们！这种种（世间），都是从业而生的；而业又是从烦恼的力量而生的。（业有）善、不善与无记；有现法受、顺生受、顺后受与不定受；有白业、黑业与混杂的业。轮回中的业，哪个重、哪个临近（死时）、哪个是串习、哪个是先前所作的，就依照这个次第，先后成熟果报。

朋友们，想一想吧！从无始以来，无明等等，直到老死为止，十二支分成三份，像水车的斗一样，内在的缘起一再地轮转。生生世世，无数次地，在那里被生、老、病、死的痛苦一再煎熬；因为迷乱而轮回，又在迷乱中继续轮回。

唉！在三有之路上疲惫不堪的旅客们，把痛苦执为安乐，而不生厌离；你们的心常常贪著于此，上师说，这与畜生没有差别。

被上师所摄受的智者们！五道的一切众生，在每一刹那，都受着轮回之苦，就像被荆棘刺扎一样，谁能不从骨髓深处生起悲心呢？由于恶业的力量，在这轮回的大海中，一再地出生，一再地衰老与生病，一再地死去——不去思惟这些，却贪著于境界，我该怎么办才好呢？

朋友们，住在三有中的一切都是痛苦；其中，人的痛苦，我亲眼见到了。胎中的痛苦，是这样的：（胚胎）滑软、稠浊、凝结、渐渐坚实，然后逐渐长成躯干与手脚。（出生以后）用乳、酪、酥来养育，非常孱弱，只能仰卧。经历童年、壮年与青春，衰老之后又重新变得像孩子一样。

寿命是无常的，非常动摇，连片刻停留的力量都没有。不想到“我必定会死”的人，朋友们，那人真是稀奇！由于不知道轮回的过患与过失，安住于四种颠倒之中，不想到“我必定会死”，贪著于境界，日日夜夜都无意义地度过。

南赡部洲的人，会非时而死；即使有一定寿量的，也终将耗尽。所以，应当一再地想：“我必定会死。”相貌端好的朋友们！（人们说）“春天花开的时节到了”“明月所表的秋天到了”，一切人都很欢喜；却没有一个人，会因为想到“我的寿命将要耗尽”而深深地不乐。

“今天做这件事，明天做那件事，然后再做这件和那件。”不知道三有动摇的本性，毫无意义地寻求安稳的众生，就像驶进了死主摩羯鱼口中的船一样，事情还没有做完，就落入了境界之水的波涛之中。“这件明天做，这件过一会儿做，这件稍后再做。”当人们这样想的时候，阎罗手持棍棒，正斜眼看着，眼角充血，愤怒凶暴，狞笑着暗想：“（看你）还盼什么！”即使精通一切瑜伽论典与种种修法，口里说着“今天做、明天做”，怀着种种打算，就死去了。

这生命被众多危害之风所吹，比水泡还要无常；呼出一口气、吸进一口气、睡着之后，（还能醒来而）有明天的空闲，那真是稀奇！

喂，喂，朋友们！寿命短暂，所知的种类却很多；寿命有多长，也不知道。所以，要像天鹅从水中取乳一样，取自己所需要的。

喂，喂，朋友们！向外去看世间的种种作为，所作的一切都没有意义，都是痛苦之因；无论想什么，都没有真正的益处，所以要串习观照自己的心。

喂，喂，朋友们！七部量论、四种声明，阿毗达磨与瑜伽师地，经藏、律藏与论藏，论典中所记载的一切，全部都——（如果自己）“没有见过、没有听过、没有讲过、没有写过”，贤善的朋友们，不要为此生起焦虑。所谓上师的口诀，是甘露之味；只要寻求能使心平等安住的那一点就够了，要那么多论典做什么呢？一切（多余的）都只是令心迷乱之因。

因为轮回之中没有定准，父母等也不一定（永远）是父母，所以要舍弃对亲属的贪著；仇敌也不一定（永远是仇敌），所以要舍弃对他的嗔恨。对于无病、青春与圆满，以及五种欲妙，要舍弃本能的贪著；要舍弃利养、恭敬与名声，种姓、家族与诗文；也要舍弃与弟子、再传弟子之间的法缘。

喂，喂，朋友们！把世间看作猛虎、毒蛇、烈火与毒药一样，思惟之后舍弃它，住在寂静之处。要舍弃学习与阅读：看女人相、看男人相，医药、相象，星象历算，相兵器、相马、工巧，以及种种恶论。

当对境界生起贪乐之心、生起这些分别的时候，要忆念“我必定会死”，并以下面所说的对治来遮止它们：分别念多的时候，以数息来平息；贪欲的心所与分别，以观察自性不净的骨锁来遮止；对于嗔恨，浇以慈心之水；对于愚痴，以缘起之道（来对治）。不净观、慈心观与缘起观的口诀，要依照上师亲口所说的去修持。
