# 修心七要之祈祷文
## 意之甘露

蒋扬钦哲旺波 造

具足七种天法教法之主宰、觉沃噶当派之窍诀——名为"修心七要"者，依恰卡瓦·耶喜多杰之传承，加以解说，分为三部分：

## 一、初善

分二。

### 1. 祈祷文之名称

"修心七要之祈祷文·意之甘露"。

### 2. 礼赞

```
སྲིད་ཞིའི་ཡོན་ཏན་ཀུན་གྱི་འབྱུང་གནས། །
ཐེག་མཆོག་དགེ་བའི་བཤེས་ལ་འདུད་དོ། །
དད་པ་གསུམ་གྱི་བློ་རྒྱུད་དག་པར། །
རྗེ་བཙུན་བླ་མས་བྱིན་གྱིས་རློབས་ཤིག །
```

有寂一切功德之来源，顶礼于殊胜乘之善知识！愿以三种信心，令心相续得以清净，至尊上师，祈请加持！

## 二、中善：正文本义

分七。

### 1. 宣说前行所依之法

```
དལ་འབྱོར་རྙེད་དཀའ་འཇིག་སླར་ཤེས་པས། །
ལས་འབྲས་བླང་དོར་ཚུལ་བཞིན་བརྩོན་ཅིང་། །
བཅོས་མིན་ངེས་འབྱུང་སྔོན་འགྲོ་འབྱོངས་པར། །
རྗེ་བཙུན་བླ་མས་བྱིན་གྱིས་རློབས་ཤིག །
```

了知暇满难得、易于坏灭，于业果取舍，如理精勤，愿不假造作之出离心，于前行中得以娴熟，至尊上师，祈请加持！

### 2. 正行修习菩提心

```
གཟུང་འཛིན་བདེན་མེད་དབྱིངས་སུ་སྦྱངས་ཏེ། །
བདག་གཞན་བདེ་སྡུག་གཏོང་ལེན་ཟབ་མོའི། །
བྱང་ཆུབ་སེམས་གཉིས་རྟག་ཏུ་བསྒོམ་པར། །
རྗེ་བཙུན་བླ་མས་བྱིན་གྱིས་རློབས་ཤིག །
```

将能所二取之无实，净治于法界之中，以自他苦乐甚深之施受法，愿恒常修习世俗、胜义二种菩提心，至尊上师，祈请加持！

### 3. 转恶缘为菩提之道

```
རྐྱེན་ངན་སྡུག་བསྔལ་ཇི་ལྟར་བྱུང་ཡང་། །
བདག་འཛིན་འགོང་པོའི་འཕྲུལ་དུ་མཐོང་ནས། །
བྱང་ཆུབ་སེམས་ཀྱིས་ལམ་དུ་འཁྱེར་བར། །
རྗེ་བཙུན་བླ་མས་བྱིན་གྱིས་རློབས་ཤིག །
```

无论生起何种恶缘痛苦，皆视为我执魔之幻化把戏，愿以菩提心，将其转为道用，至尊上师，祈请加持！

### 4. 摄示一生修持之要

```
བསམ་སྦྱོར་དག་པས་ཚོགས་བསགས་སྒྲིབ་སྦྱོང་། །
སྨོན་ལམ་དང་བཅས་སྟོབས་ལྔ་ལྡན་པའི། །
ཚེ་གཅིག་ཉམས་ལེན་སྙིང་པོར་དྲིལ་བར། །
རྗེ་བཙུན་བླ་མས་བྱིན་གྱིས་རློབས་ཤིག །
```

以清净之意乐加行，积集资粮、净治罪障，兼具发愿及五力，愿将一生之修持，摄集为心要，至尊上师，祈请加持！

### 5. 修心之量

```
ཆོས་ཀུན་བདག་འཛིན་གཉེན་པོར་འཆར་ཞིང་། །
རང་སེམས་དབང་ཐོབ་ཡིད་བདེའི་གདེངས་ཀྱིས། །
འགལ་རྐྱེན་ཐམས་ཅད་ལམ་དུ་ལོངས་པར། །
རྗེ་བཙུན་བླ་མས་བྱིན་གྱིས་རློབས་ཤིག །
```

愿一切法皆显现为对治我执之法门，以自心已获自在、心生欢喜之把握，愿一切违缘皆能纳入道用，至尊上师，祈请加持！

### 6. 修心之誓言

```
ཁས་བླངས་དོན་ལྡན་ཚུལ་འཆོས་དང་བྲལ། །
ཕྱོགས་རིས་མེད་པར་མངོན་ཚན་ཆུང་ངུས། །
བློ་སྦྱོང་དམ་ཚིག་སྲོག་བཞིན་བསྲུང་བར། །
རྗེ་བཙུན་བླ་མས་བྱིན་གྱིས་རློབས་ཤིག །
```

所许承诺具实义、离于虚伪造作，无有偏私党执，且少现夸耀之相，愿如护己命一般，护持修心之誓言，至尊上师，祈请加持！

### 7. 修心之学处

```
མདོར་ན་བྱང་ཆུབ་སེམས་གཉིས་འཕེལ་བའི། །
བསླབ་བྱ་ཐམས་ཅད་ཚུལ་བཞིན་སློབ་པས། །
ཚེ་འདིར་ཐེག་མཆོག་བཟོད་པ་ཐོབ་པར། །
རྗེ་བཙུན་བླ་མས་བྱིན་གྱིས་རློབས་ཤིག །
```

总而言之，愿能增长二种菩提心之一切学处，皆能如理修学，愿于此生，证得殊胜乘之忍位，至尊上师，祈请加持！

## 三、后善

### 1. 发愿

```
མཉམ་མེད་ཇོ་བོ་ཡབ་སྲས་ཐུགས་བཅུད། །
དོན་ཚན་བདུན་ལྡན་དགེ་སྦྱོང་ཚུལ་ལ། །
སྙིང་ནས་སྨོན་པའི་ལེགས་བྱས་འདིས་ཀྱང་། །
འགྲོ་ཀུན་བྱང་ཆུབ་ཐོབ་པར་མཛོད་ཅིག །
```

无与伦比之觉沃父子（阿底峡师徒）心要，具足七要之善巧修持法，愿以此发自内心之发愿善行，令一切众生皆证得菩提！

### 2. 后记

如是，于吉雪聂塘吉祥阿底峡尊者珍贵法相之前，一心专注祈祷之作者，乃游历诸国之无事闲人、于珍贵噶当派传承怀持至上敬信之蒋扬钦哲旺波，祈愿加持令此如实成就！

科判之细字，乃芒嘎拉（顶果钦哲仁波切）所加。

## 译者说明

本篇依藏文原文重新译出，参考但不依循已有中译本之措辞。原文本身即依"初善、中善、后善"三分、及中善下"前行、正行菩提心、转恶缘为道用、一生修持摄要、修心之量、修心之誓言、修心之学处"七支科判层层注解，此科判结构乃顶果钦哲仁波切（芒嘎拉）所加，为噶当派恰卡瓦大师《修心七要》根本颂之传统释注体例，译文完整保留此科判架构，以便与《修心七要》原颂对照阅读。
