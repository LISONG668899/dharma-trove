# 阿底峡法歌（守护心）

阿底峡尊者造　据藏文译出

## 题解

本篇收于德格版丹珠尔续部释 ཟི 函第 10a 至 10b 页（东北目录 D2374）。开头只有"敬礼佛陀"；跋语作"吉祥燃灯智之法歌，圆满"，没有记载译者。吉祥燃灯智（Dīpaṃkaraśrījñāna），即阿底峡尊者。

关于题名：本站已译阿底峡的《令心决定解脱轮回之歌》（D2313），另有《法界见歌》（D2314）待译。为了区分，本篇依叠句加括号，题为《阿底峡法歌（守护心）》。

全篇约十五句，以"守夜防贼"为喻，叠句是"嗟！不要懈怠，要守护自心，警醒而不眠"：分别是盗贼，戒律是财宝，懈怠如睡眠；睡着了，盗贼就会夺走戒财；没有戒就没有定，没有定，真如之日就不升起；以修持真如之日来守夜，那时轮回就天亮了。全篇体现了阿底峡重视戒律、以戒定慧次第修行的风格，没有涉及具体的密法修持。

体例：藏文原文全部保留在代码框中，按段落分节，每节后附汉译；叠句照原文每次重复。凡标"存疑"的按语，表示本译对原文意思没有把握。藏文依 Esukhia 德格丹珠尔电子版。

## 礼敬

```
སངས་རྒྱས་ལ་ཕྱག་འཚལ་ལོ། །
```

敬礼佛陀！

## 一、为护戒财，须守夜

```
རྣམ་རྟོག་འཇིག་པའི་ཆོམ་རྐུན་འཇིགས་ཤེས་ན། །
ཚུལ་ཁྲིམས་ནོར་ཆེན་བསྲུང་ཕྱིར་མེལ་ཚེ་གྱིས། །
ཀྱེ་སྙོམ་ལས་མ་བྱེད་སེམས་ཀྱི་མེལ་ཚེ་གྱིས། །
```

如果知道分别这毁坏一切的盗贼是可怕的，为了守护戒律这大财宝，就要守夜。嗟！不要懈怠，要守护自心，警醒而不眠！

【按】全篇以"守夜防贼"为喻：分别念是盗贼，戒律是财宝，懈怠如睡眠，守护自心如守夜。"嗟！不要懈怠，要守护自心，警醒而不眠"，是全篇的叠句。这与前一篇《瑜伽士扎萨惹之歌》"卖象而眠"恰好形成对照：那一篇说的是证悟者已无可守护，这一篇说的是修道者必须警醒守护，两者各有所指。

## 二、愚痴之眠，轮回夜长

```
གཏི་མུག་གཉིད་ཀྱིས་འཁོར་བའི་མཚན་མོ་རིང། །
ཀྱེ་སྙོམ་ལས་མ་བྱེད་སེམས་ཀྱི་མེལ་ཚེ་གྱིས། །
```

因为愚痴的睡眠，轮回的长夜十分漫长。嗟！不要懈怠，要守护自心，警醒而不眠！

## 三、睡则盗入

```
གཉིད་ལོག་ན་ནི་ཁྱིམ་ནང་ཆོམ་རྐུན་འགྲོ། །
ཁྱོད་ཀྱི་ཚུལ་ཁྲིམས་ནོར་ཆེན་འཕྲོག་པར་འགྱུར། །
```

如果睡着了，盗贼就会进入屋中，夺走你的戒律大财。

## 四、无戒无定，日不升起

```
ཚུལ་ཁྲིམས་ནོར་དེ་མེད་ན་ཏིང་འཛིན་མེད། །
དེ་མེད་ན་ནི་ཉི་མ་འཆར་བ་མེད། །
དེ་ཉིད་ཉི་མ་བསྒོམ་པས་མེལ་ཚེ་གྱིས། །
སྐད་ཅིག་གཅིག་ཀྱང་ནོར་ཆུང་གཞན་མ་བྱེད། །
```

如果没有戒律这财宝，就没有等持；没有等持，［真如的］太阳就不会升起。要以修持真如之日来守夜，一刹那也不要去做其他的小财［之事］。

【按】"无戒则无定，无定则日不升"，是戒、定、慧三学次第的通说：戒是定的基础，定是慧的基础。阿底峡尊者以重视戒律著称，这首歌也正体现了他的风格。

【按】存疑。"ནོར་ཆུང་གཞན་མ་བྱེད"，本译译为"不要去做其他的小财之事"，意思大概是：不要为世间的小利分心。

## 五、真如日出，轮回天明

```
དེ་ཡི་དུས་ན་དེ་ཉིད་ཉི་མ་འཆར། །
འདི་ལྟར་དེ་ཚེ་འཁོར་བའི་ནམ་ལངས་འགྱུར། །
ཀྱེ་སྙོམ་ལས་མ་བྱེད་སེམས་ཀྱི་མེལ་ཚེ་གྱིས། །
```

那时，真如的太阳就会升起，这样，轮回就天亮了。嗟！不要懈怠，要守护自心，警醒而不眠！

【按】全篇以"轮回天亮"作结：守住戒律、修持等持，真如的太阳升起，轮回的长夜就结束了。
