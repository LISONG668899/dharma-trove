# 三句要害之窍诀

麦彭仁波切 造

顶礼文殊师利！

```
ཐ་མལ་ཤེས་པ་རྒྱ་ཡན་མ། །
ཚིག་གིས་མི་མཚོན་རང་གིས་རིག །
```

平常心，坦荡开阔者，非言语所能譬示，唯由自己内证而知；

```
བཟོ་བཅོས་འཛིན་ཞེན་རང་ལོག་ན། །
སེམས་ཀྱི་ངོ་བོ་རིག་ཅེས་བྱ། །
```

造作与执著若能自然消退，此即所谓"识得心之本体"。

```
རྣམ་རྟོག་འཇུར་བུས་མ་བཅིངས་པར། །
གཉུག་མའི་ངང་ཚུགས་མ་ཤོར་བཞིན། །
བྱ་རྩོལ་ཆེད་འཛིན་མེད་པ་ན། །
སྒོམ་པ་སྐྱོང་ཞེས་དེ་ལ་བྱ། །
```

不被分别念之纠结所缠缚，而又不失本然之状态，无有刻意造作、勤求执取之时，此即所谓"护持禅修"。

```
ནམ་མཁའི་ངང་ནས་སྤྲིན་བཞིན་དུ། །
སྣ་ཚོགས་རྣམ་རྟོག་རྦ་རླབས་ཀུན། །
ཕན་གནོད་མེད་པར་བློ་བདེ་ན། །
རང་སར་གྲོལ་ཞེས་དེ་ལ་བྱ། །
```

犹如虚空中之云朵一般，种种分别念之一切波涛，若能于无利无害中心安理得，此即所谓"于本位解脱"。

```
ཚིག་གསུམ་གནད་ཀྱི་མན་ངག་འདི། །
ནང་གི་མྱོང་བ་ཅན་གྱིས་རྟོགས། །
ཁ་འབྱམས་རྟོག་གིས་ཕྱོགས་མི་ཤེས། །
```

此三句要害之窍诀，唯具内在体验者方能证悟，空谈泛论、分别思辨，无法了知其分毫。

麦彭南杰所写，于火猴年二月十九日整。

---

## 译者说明

本篇依藏文原颂重新译出。全篇以"识得心之本体""护持禅修""于本位解脱"三句，依次对应大圆满立断法门中之见、修、行三要，篇幅虽短，然为麦彭仁波切诸多口诀体教言中常见之凝练格式，故译文亦逐句对应，力求简明。
