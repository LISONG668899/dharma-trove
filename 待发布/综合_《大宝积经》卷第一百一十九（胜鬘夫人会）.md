# 《大宝积经》卷第一百一十九（胜鬘夫人会）

唐·三藏菩提流志 奉诏译

## 胜鬘夫人会第四十八

【按】译者题名，明本无“大”字，“三藏”作“三藏法师”。本会异译有刘宋求那跋陀罗译《胜鬘师子吼一乘大方便方广经》（T0353）。

#### 父母遣书，胜鬘说偈

如是我闻：一时，佛在舍卫国祇树给孤独园。那时憍萨罗国的波斯匿王与末利夫人初证佛法之后，互相商议说：“我们的女儿胜鬘聪慧敏利，多闻而有智慧，若见到如来，对甚深之法必能迅速理解，没有种种疑惑。我们现在应当派一位善于晓谕的人去，启发她的诚信。”这样商议之后，国王与夫人便写了一封信，称扬如来真实的功德。那时派遣一位使者，名为真提罗，奉持国王的书信，前往无斗城，交给胜鬘夫人。那时胜鬘夫人打开书信，反复读阅，顶戴受持，欢喜庆幸，生起稀有之心，向真提罗说偈道：

```
我闻如来声，世间颇难遇，
斯言若真实，当赐汝衣服。
若彼佛世尊，为利世间现，
必应见哀愍，令我覩真相。
```
（大意：我听闻如来之名，世间极难值遇，这话若是真实，当赏赐你衣服。若那位佛世尊为利益世间而出现，必定应当哀愍我，令我得见真容。）

```
言念须臾顷，佛于虚空中，
现不思议身，普放大光明。
胜鬘及眷属，皆悉来集会，
合掌瞻仰礼，称赞大导师：
```
（大意：刚生起这念头的须臾之间，佛在虚空中显现不可思议之身，普放大光明。胜鬘与眷属都来集会，合掌瞻仰礼敬，称赞大导师：）

```
如来妙色身，世间无与等，
无比不思议，是故今敬礼。
如来色无尽，智慧亦复然，
一切法常住，是故我归依。
善调心过恶，及与身四种，
到不思议地，故我今敬礼。
知诸尔炎法，智身无罣碍，
于法无忘失，故我今敬礼。
稽首过称量，稽首无伦等，
稽首法自在，稽首超思惟。
哀愍覆护我，令法种增长，
逮及最后身，常在如来前。
我所修福业，此世及余生，
由斯善根力，愿佛恒摄受。
```
（大意：如来的妙色身，世间无与伦比，无比而不可思议，所以现在敬礼。如来之色无尽，智慧也是这样，一切法常住，所以我归依。善于调伏心的过恶，以及身的四种过恶，到达不可思议之地，所以我现在敬礼。了知一切所知之法，智身无所挂碍，于法无所忘失，所以我现在敬礼。稽首礼敬超过称量者，稽首礼敬无与伦比者，稽首礼敬于法自在者，稽首礼敬超越思惟者。愿哀愍覆护我，令法的种子增长，直到最后身，常在如来面前。我所修的福业，在此世以及余生，由这善根之力，愿佛恒常摄受。）

【按】“尔炎”，梵语 jñeya 音译，意为所知、境界。

#### 佛为胜鬘授记

那时胜鬘夫人说了这偈之后，与诸眷属以及一切大众顶礼佛足。那时世尊便为胜鬘说偈道：

```
我昔为菩提，曾已开示汝，
今复值遇我，及来世亦然。
```
（大意：我往昔为了菩提，曾经已开示过你，现在你又值遇我，未来世也是这样。）

说了这偈之后，便在会中为胜鬘夫人授阿耨多罗三藐三菩提记：“你现在称叹如来殊胜的功德，以这善根，当于无量阿僧祇劫在天人之中作自在王，种种所受用的都完全具足，所生之处常得遇见我，现前称叹，如今天一样没有差异。又当供养无量无数诸佛世尊，过二万阿僧祇劫，当得作佛，号为普光如来、应供、正等觉。那佛的国土没有种种恶趣、衰老病苦，也没有不善恶业道之名。其中的众生形色端严，具足五种妙境，纯受快乐，胜过他化自在诸天。那些众生都趣向大乘，凡是这样修学大乘的人，都来生到那里。”

【按】“具五妙境”之“五”，《南藏》作“天”。

那时胜鬘夫人得授记之后，无量天人心怀踊跃，都愿往生那佛世界。这时世尊都为他们授记，当生于那国。

#### 十大受（十弘誓）

那时胜鬘夫人听到佛的授记后，在如来面前合掌而立，发十种弘誓，这样说：“世尊！我从今天起，乃至成就菩提，对所受的种种戒，不起违犯之心。世尊！我从今天起，乃至成就菩提，对诸师长不起憍慢之心。世尊！我从今天起，乃至成就菩提，对诸众生不起恚恨之心。世尊！我从今天起，乃至成就菩提，对胜过自己的人以及种种胜事，不起嫉妒之心。世尊！我从今天起，乃至成就菩提，即使只有少许食物，也不起悭吝之心。世尊！我从今天起，乃至成就菩提，不为自己受取蓄积财物，凡有所受，都是为了救济贫苦的有情之类。世尊！我从今天起，乃至成就菩提，不求回报而行四摄事，以无贪利之心、无厌足之心、无限碍之心摄受众生。世尊！我从今天起，乃至成就菩提，见到诸众生没有依怙，被幽禁、系缚、疾病、苦恼种种危厄，终不舍离，必愿令他们安稳，以善法饶益，令他们免除众苦。

“世尊！我从今天起，乃至成就菩提，若见到一切种种恶律仪，以及毁犯如来清净禁戒的，凡在我所摄的城邑聚落中，应当调伏的便调伏他，应当摄受的便摄受他。为什么呢？因为调伏与摄受的缘故，正法便得久住；因为正法久住的缘故，天人充满，恶道减少，能令如来的法轮常转。世尊！我从今天起，乃至成就菩提，摄受正法，终不忘失。为什么呢？忘失正法便忘失大乘，忘失大乘便忘失波罗蜜，忘失波罗蜜便舍弃大乘。若诸菩萨对大乘不能决定，摄受正法便不坚固，便不能超越凡夫的境界，这便是大损失。世尊！现在、未来摄受正法的诸菩萨等，具足无边广大的利益。

【按】“忘大乘者”，元、明本作“忘失大乘者”。

“我发这些弘誓，圣主世尊虽然已经证知，而诸有情善根微薄，或许会起疑网，因为这十种弘誓难以成就的缘故，他们或许长夜修习不善之法，受种种苦恼。为了利益这样的众生，现在在佛前发诚实之誓：世尊！我现在发这十种弘誓愿，若真实不虚，愿在大众上方降下天花，发出天上的妙音。”胜鬘夫人在如来面前说了这话之后，那时虚空中便降下天花，发出天上的妙音，赞叹说：“善哉胜鬘夫人！如你所说，真实无异。”那时众会见到这瑞相，没有种种疑惑，生大欢喜，同声唱说：“愿与胜鬘夫人在所生之处同其愿行。”那时佛世尊都为大众授记，如其所愿。

#### 三大愿与一大愿

那时胜鬘夫人又在佛前发三种弘愿：“以这愿力，利益无边诸有情之类。第一愿：以我的善根，在一切生中得正法之智。第二愿：若我所生之处得正智之后，为诸众生演说而不倦。第三愿：我为了摄受护持正法，对所生之身不惜身命。”那时世尊听了这些愿，告诉胜鬘说：“如一切色都入于虚空界，这样，菩萨恒河沙数的诸愿都入于这愿，这三种愿真实广大。”

那时胜鬘夫人又对佛说：“世尊！我现在当承佛的威神辩才之力，想说大愿，希望垂允听许。”佛说：“胜鬘！任你所说。”胜鬘夫人说：“菩萨所有恒河沙数的诸愿，一切都入于一大愿中。一大愿，就是摄受如来的正法。这样摄受正法，真实广大。”

佛说：“善哉胜鬘！你久已修习，智慧方便甚深微妙。有能理解你所说义理的人，他在长夜中已种植诸善本。如你所说的摄受正法，都是过去、未来、现在诸佛已说、今说、当说的。我得无上正等菩提，也常以种种相宣说摄受正法，这样称扬摄受正法，所有的功德没有边际，如来的智慧也没有边际。为什么呢？因为这摄受正法有大功德，有大利益。”

#### 摄受正法广大义

那时胜鬘夫人又对佛说：“世尊！我当承佛的威神之力，再演说摄受正法的广大义理。”佛说：“听你宣说。”胜鬘夫人说：“摄受正法的广大义理，是为了得到无量一切佛法，乃至能摄持八万行蕴。譬如劫初兴起种种色云，降下众宝之雨，这样，摄受正法的善根之云，能降下无量的福报之雨。世尊！又如劫初的大水之中，能生出三千大千世界的界藏以及四百亿种种类的洲。这样，摄受正法出生大乘无量的界藏，以及诸菩萨的神通之力、种种法门，一切世间以及出世间的安乐具足，是一切天人所未曾有的。

“又如大地荷负四种重担。哪四种？一是大海，二是诸山，三是草木，四是众生。这样，摄受正法的诸善男子以及善女人，堪能荷负四种重任，超过那大地。哪四种？就是对离开善友、没有闻法、行于非法的诸有情之类，以人天善根成熟他们；对求声闻的人授与声闻乘；对求独觉的人授与独觉乘；对求大乘的人授与大乘。这名为摄受正法的诸善男子以及善女人堪能荷负四种重任，超过那大地。世尊！这样摄受正法的善男子、善女人等建立大地，堪能荷负四种重任，普为众生作不请之友，以大悲利益、哀愍有情，作世间的法母。

“又如大地是四种宝所生之处。哪四种？一是无价，二是上价，三是中价，四是下价。这样，摄受正法的善男子、善女人建立大地，有情遇到之后，获得四种大宝，在一切宝中最为殊胜。哪四种？就是诸有情遇到这样的善友，或有获得人天善根的，有证得声闻、辟支佛或无上乘之善根功德的。这名为摄受正法的善男子、善女人建立大地，有情遇到之后，便能获得四种大宝。世尊！出生大宝的，名为真实摄受正法。

#### 正法即摄受正法，摄受正法即波罗蜜

“世尊！所说的摄受正法，就是正法与摄受正法无异，正法即是摄受正法。世尊！波罗蜜与摄受正法无异，摄受正法即是波罗蜜多。为什么呢？摄受正法的善男子、善女人，对应以布施成熟的人，便以布施成熟他，乃至舍身，随顺他的心意而成熟他，令那有情安住于正法，这名为布施波罗蜜。对应以持戒成熟的人，便守护六根，清净身语意，乃至威仪，随顺他的心意而成熟他，令那有情安住于正法，这名为持戒波罗蜜。对应以忍辱成熟的人，若那有情骂詈、毁辱、诽谤、扰乱，便以无恚之心、利益之心与最上的忍力，乃至颜色也不改变，随顺他的心意而成熟他，令那有情安住于正法，这名为忍辱波罗蜜。

【按】“波罗蜜多”之“多”，宋、元、明本无。

“对应以精进而成熟的人，对那有情不起懈怠下劣之心，生起大乐欲与最上的精进，在四威仪中随顺他的心意而成熟他，令那有情安住于正法，这名为精进波罗蜜。对应以静虑（禅定）而成熟的人，对那有情以无散乱之心成就正念，曾经所作之事终不忘失，随顺他的心意而成熟他，令那有情安住于正法，这名为静虑波罗蜜。对应以智慧而成熟的人，那些有情为了利益而问诸法之义，便以无倦之心为他们演说一切诸论、一切明处，乃至种种工巧之处，令他们得以究竟，随顺他的心意而成熟他，令那有情安住于正法，这名为智慧波罗蜜。所以，世尊！波罗蜜与摄受正法无异，摄受正法即是波罗蜜。”

【按】“成就正念”之“就”，宋、元、明本作“熟”。

#### 摄受正法者即是摄受正法；舍身命财

那时胜鬘夫人又对佛说：“世尊！我现在承佛的威神辩才之力，再说大义。”佛说：“什么大义？”“世尊！摄受正法与摄受正法者无异。摄受正法者无异，是说摄受正法的善男子、善女人便是摄受正法。为什么呢？若摄受正法的善男子、善女人为了正法而舍弃身、命、财，这样的人，因为舍身的缘故，证得生死的后际，远离老病，得到不坏、常住、无有变易、究竟寂静、不可思议的如来法身。因为舍命的缘故，证得生死的后际，永离于死，得到无边的常住，成就不可思议的种种善功德，安住于一切佛法的神变。因为舍财的缘故，证得生死的后际，超过有情，无尽无减，果报圆满，具足不可思议的功德庄严，为诸有情所尊重供养。世尊！舍弃身命财而摄受正法的善男子、善女人等，为诸如来所授记。

“世尊！若善男子、善女人，在正法将要灭亡之时，有诸比丘、比丘尼、优婆塞、优婆夷互相结党，生起种种诤讼，他以不谄曲、不欺诳之心，爱乐正法，摄受正法，入于善的朋群之中。入于善朋群的人，必定为诸佛所授记。世尊！我见摄受正法有这样的大力，如来以此为眼，为法的根本，为引导之法，为通达之法。”

#### 佛赞摄受正法大威德

那时世尊听到胜鬘夫人所说摄受正法有大威力，赞叹说：“是这样，是这样。善哉胜鬘！如你所说，摄受正法有大威德之力。如大力士稍微触到人的末摩（要害、死穴），便生大苦痛，更增重病。是这样，胜鬘！假使有少分的摄受正法，便令魔波旬痛切愁恼，悲号叹息，也是这样。胜鬘！我从来不见其余一种善法能令魔愁恼，如同少分的摄受正法。

“胜鬘！譬如牛王形色端正，身量殊特，胜过诸牛。是这样，胜鬘！修大乘的人，假使有少分的摄受正法，便能胜过声闻、独觉的一切善法。胜鬘！又如须弥山王高广严丽，胜过众山。是这样，胜鬘！初趣大乘的人以饶益之心，不顾身命，摄受正法，便能超过顾惜身命而久住大乘的一切善根。所以，胜鬘！应当以摄受正法开示教化一切有情。是这样，胜鬘！摄受正法获得大福利以及大果报。胜鬘！我在无数阿僧祇劫中称赞这样的摄受正法所有的功德，也得不到边际，所以摄受正法成就这样无量的功德。”

#### 摄受正法即是大乘

佛告诉胜鬘：“你现在应当再演说我所说的摄受正法，这是一切诸佛所共同爱乐的。”胜鬘说：“善哉世尊！摄受正法便名为大乘。为什么呢？因为大乘出生一切声闻、独觉，以及世间、出世间所有的善法。如阿耨达池流出八大河，这样，大乘出生一切声闻、独觉，以及世间、出世间所有的善法。世尊！又如一切种子、草木、丛林，都依大地而得生长，这样，一切声闻、独觉，以及世间、出世间所有的善法，都依大乘而得生长。所以，世尊！住于大乘、摄受大乘，便是住于、摄受声闻、独觉，以及世间、出世间所有的善法。

#### 六处皆为大乘说

“如佛世尊所说的六处，就是正法住、正法灭、别解脱、毗奈耶、正出家、受具足，这是为大乘而说的六处。为什么呢？正法住，是为大乘而说，大乘住即是正法住；正法灭，是为大乘而说，大乘灭即是正法灭。别解脱与毗奈耶，这两种法义一而名异。毗奈耶即是大乘之学。为什么呢？因为是为佛而出家受具足戒，所以大乘的戒蕴是毗奈耶，是正出家，是受具足。

#### 阿罗汉有怖畏，去涅槃远

“世尊！阿罗汉没有出家以及受具足。为什么呢？因为阿罗汉不是为如来而出家受具足的。阿罗汉有怖畏之想，所以归依如来。为什么呢？阿罗汉对一切行住于怖畏之想，如有人拿着剑要来害自己，所以阿罗汉不证出离的究竟安乐。世尊！依止者不求依止，如诸众生没有归依，处处恐怖，为了安稳，便求归依。世尊！这样，阿罗汉因为有恐怖，所以归依如来。所以阿罗汉以及辟支佛，生法有余，梵行未立，所作未办，当有所断，因为尚未究竟，所以离涅槃尚远。为什么呢？唯有如来、应供、正等觉证得涅槃，成就无量不可思议的一切功德，所应断的都已断尽，究竟清净，为诸有情所瞻仰，超过二乘与菩萨的境界。阿罗汉等便不是这样，说他们得涅槃，是佛的方便，所以阿罗汉等离涅槃尚远。世尊说阿罗汉以及辟支佛观察解脱，四智究竟，得以苏息，都是如来随他人之意所说、不了义之说。

#### 二种死

“为什么呢？有两种死。哪两种？一是分段死，二是变易死。分段死，是指相续流转的有情。变易死，是指阿罗汉以及辟支佛、自在菩萨的随意生身（意生身），乃至菩提。两种死中，以分段死而说阿罗汉以及辟支佛生起‘我生已尽’之智；由于能证得有余之果，生起‘梵行已立’之智，这是一切愚夫所不能作、七种有学之人尚未成办的；因为相续的烦恼究竟断除，生起‘所作已办’之智。世尊说生起‘不受后有’之智，是说阿罗汉以及辟支佛不能断除一切烦恼，没有了知一切受生之智。为什么呢？因为这阿罗汉以及辟支佛有剩余的烦恼尚未断尽，不能了知一切受生。

【按】“分段”之“段”，宋、元本作“叚”。

#### 住地烦恼与起烦恼；无明住地

“烦恼有两种，就是住地烦恼以及起烦恼。住地有四种。哪四种？就是见一处住地、欲爱住地、色爱住地、有爱住地。世尊！这四种住地能生起一切遍起的烦恼。起烦恼，刹那刹那与心相应。世尊！无明住地，从无始以来与心不相应。世尊！四住地的力量能作为遍起烦恼的所依，与无明住地相比，算数譬喻所不能及。世尊！这样的无明住地，比有爱住地，其力量最大。譬如魔王的色、力、威德以及众眷属，胜过他化自在诸天，这样，无明住地胜过四住地，是超过恒河沙数烦恼的所依，也令四种烦恼久住。声闻、独觉的智慧不能断除，唯有如来的智慧能够断除。世尊！是这样，是这样，无明住地其力最大。

“世尊！如以取为缘，以有漏业为因，而生三有；这样，以无明住地为缘，以无漏业为因，能生阿罗汉以及辟支佛、大力菩萨的随意生身。这三地的随意生身以及无漏业，都以无明住地为所依之处。它虽然有缘，也能作为缘。世尊！所以三种随意生身以及无漏业，都以无明住地为缘，与有爱（住地）相同。世尊！有爱住地与无明住地的作用不同，无明住地异于四住地。异于四住地的，唯有佛能断除。为什么呢？阿罗汉、辟支佛断除四住地，对漏尽之力不得自在，不能现证。为什么呢？世尊所说的漏尽，是增语。

#### 有余解脱与一切解脱

“所以阿罗汉、辟支佛以及最后有的诸菩萨等，因为被无明住地所覆蔽，对那种种法不知不见。因为对那种种法不知不见，应断而不断，应尽而不尽。因为对那种种法不断不尽，得的是有余的解脱，不是一切解脱；得的是有余的清净，不是一切清净；得的是有余的功德，不是一切功德。世尊！因为得的是有余解脱、不是一切解脱，乃至有余功德、不是一切功德，所以知的是有余的苦，断的是有余的集，证的是有余的灭，修的是有余的道。”

那时胜鬘夫人又对佛说：“世尊！若知有余之苦，断有余之集，证有余之灭，修有余之道，这名为少分灭度，证少分涅槃，趣向涅槃界。若知一切苦，断一切集，证一切灭，修一切道，他便于无常败坏的世间证得常住寂静清凉的涅槃。世尊！他在无护无依的世间，作为护持，作为依止。为什么呢？于诸法中见有高下的人，不证涅槃；智慧平等、解脱平等、清净平等的人，才证涅槃。所以涅槃名为平等一味。什么是一味？就是解脱之味。

#### 无明住地为恒沙烦恼所依

“世尊！若无明住地不断不尽，便不得涅槃一味、平等之味。为什么呢？因为无明住地不断不尽，超过恒河沙数的一切过失之法，应断而不断，应尽而不尽；因为超过恒河沙数的一切过失之法不断不尽，超过恒河沙数的诸功德法便不能了知、不能证得。所以无明住地是一切所应断之法与种种随烦恼的生起之处，从它而生：障心的烦恼，障止的烦恼，障观的烦恼，障静虑的烦恼，乃至障三摩钵底（等至）、加行、智、果、证、力、无畏。所有超过恒河沙数的一切烦恼，是如来菩提、佛金刚智所能断除的。种种起烦恼，一切都依于无明住地，以无明住地为因缘。世尊！这起烦恼，刹那刹那与心相应；世尊！无明住地从无始以来与心不相应。

“世尊！若又超过恒河沙数如来菩提、佛金刚智所应断的法，一切都是依靠无明住地而持守建立。譬如一切种子、丛林，都依大地而生长，若大地坏了，它们也随之而坏；这样，超过恒河沙数如来菩提、佛金刚智所应断的法，一切都依无明住地而生长，若那无明住地断除，超过恒河沙数如来菩提、佛金刚智所应断的法，也都随之断除。这样，超过恒河沙数所应断的法，一切烦恼以及起烦恼都已断除，便能证得超过恒河沙数不可思议的诸佛之法，对一切法能证得无碍神通，得种种智见，离一切过失，得种种功德，作大法王，于法自在，证得一切法的自在之地，作正师子吼：‘我生已尽，梵行已立，所作已办，不受后有。’所以世尊以师子吼，依于了义，一向记说。

#### 二种不受后有智

“世尊！不受后有之智有两种。哪两种？一是诸如来以调御之力摧伏四魔，超越诸世间，为一切有情所瞻仰；证得不可思议的清净法身，于所知之地得法自在，最胜无上，再无所作，不见还有所应证之地；具足十力，登上最胜无畏之地，对一切法无碍观察，作正师子吼：不受后有。二是阿罗汉以及辟支佛，得以度脱无量生死怖畏，受解脱之乐，作这样的想：‘我现在已离生死怖畏，不受诸苦。’世尊！阿罗汉、辟支佛这样观察，认为不受后有，却不证第一苏息的涅槃。他们对尚未证得之地不迷惑于法，能够自己了解：我现在证得的是有余依之地，必定当证阿耨多罗三藐三菩提。

#### 三乘即是一乘

“为什么呢？声闻、独觉都入于大乘，而大乘就是佛乘，所以三乘即是一乘。证一乘的人得阿耨多罗三藐三菩提，阿耨多罗三藐三菩提即是涅槃，所说的涅槃即是如来清净法身，证法身即是一乘，与如来无异，与法身无异。所说的如来即是法身，证究竟法身即是究竟一乘，究竟一乘即是离开相续。为什么呢？世尊！如来住世之时没有限量，等于后际，如来能以无限的大悲、无限的誓愿利益世间，这样说的名为善说。若又说如来是常，是无尽之法，是一切世间究竟的依止，也名为善说。所以，能在无护的世间、无依的世间，与后际相等，作无尽的归依、常住的归依、究竟的归依的，就是如来、应供、正等觉。

#### 如来即三归依

“法是一乘之道，僧是三乘之众，这两种归依不是究竟的依止，名为少分的依止。为什么呢？宣说一乘之道，证得究竟法身，在此之后便不再宣说一乘之道；三乘之众因为有恐怖，归依如来，求出离而修学，因为有所作，因为趣向阿耨多罗三藐三菩提。（所以这）两种依止不是究竟的依止，是有限的依止。若诸有情被如来调伏，归依如来，得到法的滋润，由于信乐之心，归依于法以及比丘僧。这两种归依，是由于法的滋润而信入的归依。如来不是由于法的滋润而信入的归依，所说的如来是真实的依止。这两种归依，以真实之义而言，便名为究竟归依如来。为什么呢？如来与这两种归依无异，所以如来即是三归依。为什么呢？因为宣说一乘之道，如来最胜，具四无畏，作正师子吼。若诸如来随他们的欲乐，而以方便宣说二乘，那便是大乘。以第一义而言，没有二乘，二乘同入一乘，一乘即是胜义之乘。

#### 出世第一义智

“世尊！声闻、独觉初证圣谛，不是以一种智慧断除诸住地，也不是以一种智慧证得四种遍知等种种功德，也不是以法能善于了知这四法之义。世尊！在出世间之智中，没有四种智慧渐次到达、渐次缘取。世尊！出世间智没有渐次到达之法，如金刚之喻。世尊！声闻、独觉以种种圣谛之智断除诸住地，没有出世间第一义之智。唯有如来、应供、正遍知，不是诸声闻、独觉的境界，以不可思议的空性之智，能破一切种种烦恼之壳。世尊！破除烦恼之壳的究竟之智，这名为出世间第一义之智。初证圣谛之智不是究竟之智，是趣向阿耨多罗三藐三菩提之智。

【按】“于出世智”之“出”，《南藏》作“住”。“㲉”，即壳，下同。

#### 圣谛与如来藏

“世尊！真实的圣义，不是二乘。为什么呢？声闻、独觉只能成就少分的功德，名之为圣。世尊！所说的圣谛，不是诸声闻、独觉之谛以及他们的功德。这谛，唯有如来、应供、正等觉最初了知，然后为那些被无明之壳所藏覆的世间众生开示演说，所以名为圣谛。世尊！这圣谛甚深微妙，难见难了，不可分别，不是思量的境界，是一切世间所不能相信的，唯有如来、应供、正等觉所能了知。为什么呢？因为这是说甚深的如来之藏。如来藏是佛的境界，不是诸声闻、独觉所行的。在如来藏上宣说圣谛之义，这如来藏甚深微妙，所说的圣谛也甚深微妙，难见难了，不可分别，不是思量的境界，是一切世间所不能相信的，唯有如来、应供、正等觉所能了知。若对被无量烦恼所缠的如来之藏不疑惑的人，对出离一切烦恼之藏的如来法身也没有疑惑。

#### 有作圣谛与无作圣谛

“世尊！若有人对这如来之藏以及佛法身——不可思议的佛秘密境界——心得究竟，便对所说的二种圣谛之义能信、能了、能生胜解。什么名为二种圣谛之义？就是有作与无作。有作圣谛，是不圆满的四圣谛之义。为什么呢？因为由他人护持，所以不能知一切苦、断一切集、证一切灭、修一切道，所以不知有为、无为以及涅槃。世尊！无作谛，是说圆满的四圣谛之义。为什么呢？因为能自己护持，知一切苦、断一切集、证一切灭、修一切道。这样所说的八种圣谛之义，如来只以四圣谛来说。对这无作四圣谛之义，唯有如来、应供、正等觉作事究竟，不是阿罗汉以及辟支佛之力所能及的。为什么呢？不是以胜劣、下中上之法能证涅槃。

“怎样是如来于无作谛得事究竟？就是诸如来、应供、正等觉遍知诸苦，断除诸烦恼以及上烦恼所摄的苦集，能证一切意生身蕴所有的苦灭，以及修一切苦灭之道。世尊！不是因为坏法，名为苦灭。为什么呢？所说的苦灭，无始、无作、无起、无尽、常住不动、本性清净，出离烦恼之壳。世尊！如来成就超过恒河沙数、具足解脱智的不可思议之法，说名为法身。世尊！这样的法身不离烦恼，名为如来藏。

【按】“超烦恼”之“超”，宋、元、明本作“起”。

#### 空如来藏与不空如来藏

“世尊！如来藏即是如来的空性之智。如来藏是一切声闻、独觉所未曾见、也未曾得的，唯有佛了知以及能作证。世尊！这如来藏空性之智又有两种。哪两种？就是空如来藏，所谓离于不解脱智的一切烦恼；世尊！不空如来藏，具足超过恒河沙数佛解脱智的不可思议之法。世尊！这两种空智，诸大声闻由信而能入。世尊！这样，一切声闻、独觉的空性之智，在四颠倒的境界上攀缘而转，所以是一切声闻、独觉所未曾见、也未曾证的。一切苦灭，唯有佛现证，破坏诸烦恼，修苦灭之道。

#### 一谛是常

“世尊！这四谛中，三谛无常，一谛是常。为什么呢？这样的三谛入于有为之相，有为之相便是无常。所说的无常，是破坏之法，破坏之法不是谛，不是常，不是归依之处。所以三谛以第一义而言，不是谛，不是常，不是归依之处。世尊！唯一的苦灭谛离开有为之相，离开有为之相便本性常住，本性常住不是破坏之法，不是破坏之法便是谛，是常，是归依之处。世尊！所以苦灭圣谛以胜义而言，是谛，是常，是归依之处。世尊！这苦灭谛不可思议，超过诸有情的心识境界，也不是一切声闻、独觉之智所能及的。譬如天生盲人看不见众色，七日的婴儿看不见日轮，苦灭谛也是这样，不是诸凡夫心识所缘的，也不是一切声闻、独觉之智的境界。

#### 断常二见与正见

“凡夫之识，是说二边之见；一切声闻、独觉之智，名为净智。所说的边见，是对五取蕴执著为我，生起异分别。边见有两种。哪两种？就是常见以及断见。世尊！若又有人见生死无常、涅槃是常，不是断见、常见，这名为正见。为什么呢？那些计度的人，见身、诸根、受者、思者现世之法灭坏，对于有（生命）的相续不能了知，盲而没有智慧之眼，生起断见；对于心的相续刹那灭坏，愚暗不了意识的境界，生起常见。世尊！然而那种种义理超过种种分别以及下劣之见，由于诸愚夫妄生异想、颠倒执著，认为是断，认为是常。

#### 常乐我净

“世尊！颠倒的有情对五取蕴，于无常作常想，于苦作乐想，于无我作我想，于不净作净想。声闻、独觉所有的净智，对如来的境界以及佛法身，是未曾见的。或有众生因为相信如来，对如来生起常想、乐想、我想以及净想，这不是颠倒之见，便是正见。为什么呢？因为如来法身是常波罗蜜、乐波罗蜜、我波罗蜜、净波罗蜜。若诸有情作这样的见，名为正见；若是正见，名为真佛子，从佛口生，从正法生，从法化生，得佛法之分。

#### 四入流与唯一入流

“世尊！所说的净智，就是一切声闻、独觉的智波罗蜜。这净智对苦灭谛尚且不是其境界，何况（证）苦灭谛。这是四入流智所行的。为什么呢？三乘初业不迷于法的人，能对那义理当证当了。世尊！为什么说四入流？世尊！这四入流是世间法。世尊！唯一的入流，在诸入流中最为最上，以第一义而言，这是入流，这是归依，这是苦灭谛。

【按】“唯一入流”之“唯”，《大正藏》作“能”，今依CBETA（所录高丽藏）作“唯”。

#### 生死依如来藏

“世尊！生死依于如来藏，因为有如来藏，所以说前际不可了知。世尊！因为有如来藏，所以得有生死，这名为善说。世尊！生死，是诸受根灭，无间相续而未受的根生起，名为生死。世尊！生死二法是如来藏，在世俗法中名为生死。世尊！死是诸受根灭，生是诸受根起，如来藏则不生不死，不升不坠，离开有为之相。世尊！如来藏常恒不坏，所以，世尊！如来藏是与不离、解脱智藏（之法）的依止、持守、建立，也是与外离、不解脱智的诸有为法的依止、持守、建立。

“世尊！若没有如来藏，便应当没有厌苦、乐求涅槃。为什么呢？这六识以及所知，这样的七法，刹那不住，不受众苦，不能厌离而愿求涅槃。如来藏没有前际，无生无灭，法受诸苦，它为了厌离苦，愿求涅槃。世尊！如来藏不是有我、人、众生、寿者。如来藏，不是身见有情、颠倒有情、空见有情所行的境界。

#### 自性清净心与客尘烦恼

“世尊！如来藏是法界藏，是法身藏，是出世间藏，是自性清净藏，这本性清净。如来藏，如我所理解的，纵然被客尘烦恼所染，仍是不可思议的如来境界。为什么呢？世尊！刹那刹那的善心、不善心，客尘烦恼所不能染污。为什么呢？烦恼不触心，心不触烦恼。不触之法，怎么能染心？世尊！由于有烦恼，便有随之而染的心。随烦恼而染，难解难了，唯有佛世尊为眼、为智、为法的根本、为尊、为导、为正法之依，如实知见。”

那时世尊赞叹胜鬘夫人说：“善哉善哉，如你所说。自性清净之心随烦恼而染，难可了知。又，胜鬘！有两种法难可了知。哪两种？就是自性清净之心难可了知，那心被烦恼所染也难可了知。这样的两种法，你以及成就大法的菩萨才能听受，其余的声闻由信才能理解。

#### 随顺法智与五善巧观

“胜鬘！若我的弟子有增上之信，随顺法智，便在这法中得以究竟。随顺法智，是观察根、识、境界，观察业报，观察阿罗汉的眠（睡眠），观察心的自在、爱乐禅乐，观察声闻、独觉的圣神变通。由于成就这五种善巧之观，现在、未来的声闻弟子因增上之信随顺法智，善能理解自性清净之心被烦恼所染而得以究竟。胜鬘！这究竟是大乘之因。你现在应当知道，相信如来的人，对甚深之法不生诽谤。”

#### 三种善男子善女人

那时胜鬘夫人对佛说：“世尊！又有其余的义理能多多利益，我当承佛的威神之力演说这事。”佛说：“善哉，现在任你宣说。”胜鬘夫人说：“有三种善男子、善女人，对甚深之法远离自我毁伤，生出众多功德，入于大乘之道。哪三种？若善男子、善女人等，能自己成就甚深的法智；或有成就随顺法智的；或有对这甚深法中不能理解，便仰推如来：唯有佛所知，不是我的境界。除了这三种善男子、善女人，其余的有情对甚深之法，随自己所取而执著妄说，违背正法，修习诸外道，是腐败的种子，即使在其他地方，也应当前往除灭。那些腐败的人，一切天人应当共同摧伏。”

#### 世尊还舍卫城；胜鬘化导国人

胜鬘夫人说了这话，与诸眷属顶礼佛足。那时佛世尊赞叹说：“善哉。胜鬘！你对甚深之法以方便守护，降伏怨敌，善能通达。你已亲近百千俱胝诸佛如来，所以能宣说这义理。”

【按】“俱胝”之“胝”，宋本作“祇”。

那时世尊放出殊胜的光明，普照大众，身升虚空，高七多罗树，以神通力足步虚空，回到舍卫城。那时胜鬘夫人与诸眷属瞻仰世尊，目不暂舍，世尊过了眼界之后，欢喜踊跃，相互称叹如来的功德，一心念佛，回到无斗城，劝友称王建立大乘。城中七岁以上的女人，她以大乘教化；友称大王也以大乘教化七岁以上的诸男子，全国人民无不修学。

#### 付嘱与经名

那时世尊进入逝多林，告诉尊者阿难，并心念天帝释。那时天帝释与诸眷属应念而至，住在佛前。那时世尊告诉帝释说：“憍尸迦！你应当受持这部经，演说开示，为了三十三天得安乐的缘故。”又告诉阿难：“你也受持，为四众分别演说。”

那时天帝释对佛说：“世尊！应当怎样称呼这部经？怎样奉持？”佛告诉天帝：“这部经成就无边功德，一切声闻、独觉之力所不能及，何况其余有情。憍尸迦应当知道，这部经甚深微妙，是大功德之聚，现在当为你略说其名。谛听谛听，好好思念。”那时天帝释与尊者阿难说：“善哉世尊！是的，我们受教。”

佛说：“这部经赞叹如来真实功德，应当这样受持；宣说不可思议的十种弘誓，应当这样受持；以一大愿摄一切愿，应当这样受持；宣说不可思议的摄受正法，应当这样受持；宣说入于一乘，应当这样受持；宣说无边圣谛，应当这样受持；宣说如来藏，应当这样受持；宣说佛法身，应当这样受持；宣说空性之义隐覆真实，应当这样受持；宣说一谛之义，应当这样受持；宣说常住不动、寂静唯一的依止，应当这样受持；宣说颠倒与真实，应当这样受持；宣说自性清净心被烦恼隐覆，应当这样受持；宣说如来真子，应当这样受持；宣说胜鬘夫人正师子吼，应当这样受持。又，憍尸迦！这部经所说，断除一切疑惑，决定了义，入于一乘之道。憍尸迦！现在把所说的《胜鬘夫人师子吼经》付嘱给你，乃至正法住世，在十方世界开示演说。”天帝释说：“善哉世尊！是的，我受教。”

那时天帝释、尊者阿难，以及诸大会的天、人、阿修罗、健闼婆（乾闼婆）等，听闻佛所说，都大欢喜，信受奉行。

【按】“健闼婆”之“健”，宋、元本作“揵”，明本作“犍”。
