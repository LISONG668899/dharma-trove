# 龙树《大智度论》卷第十五

龙树菩萨造　后秦龟兹国三藏鸠摩罗什奉诏译

## 释初品中羼提波罗蜜法忍义第二十五

### 一、何名法忍

什么名为法忍？

忍受种种恭敬、供养的众生，以及种种瞋恼、淫欲的人，这名为生忍。

忍受那供养、恭敬之法，以及瞋恼、淫欲之法，这是法忍。

再者，法忍是：对内六根不执着，对外六尘不领受，能对这二者不作分别。为什么？因为内相如同外相，外相如同内相，二相都不可得；因为是一相，因为是因缘和合，因为实际上是空，因为一切法相常清净，因为如真际法性之相，因为是不二之入；虽然无二，也不是一。像这样观察诸法，心中信受而不退转，这名为法忍。

如《毗摩罗诘经》中，法住菩萨说：“生、灭为二；不生、不灭，是入不二法门。”乃至文殊尸利说：“无闻、无见，一切心灭，无说、无语，是入不二法门。”毗摩罗诘默然无言，诸菩萨赞叹说：“善哉！善哉！这才是真正的入不二法门。”

### 二、于非心法中忍

再者，一切法有两种：一是众生，二是诸法。菩萨在众生中忍，如先前所说；现在说在法中忍。法有两种：心法，非心法。

非心法中有内、有外：外有寒热、风雨等；内有饥渴、老病死等。像这样等等种种，名为非心法。

心法中有两种：一是瞋恚、忧愁、疑等；二是淫欲、憍慢等。这二种名为心法。

菩萨对这两种法，能忍而不动，这名为法忍。

问：在众生中，如果瞋恼、害命就得罪，怜悯就得福；寒热、风雨，对它们既不能增也不能损，为什么要忍？

答：虽然对它们无所增损，却会自己生起恼乱忧苦，妨害菩萨道，所以应当忍。

再者，不只是杀害恼乱众生才得罪，因为以恶心作为因缘所以有罪。为什么？虽然杀了众生而是无记心，就没有罪；慈念众生，虽然没有给予什么，却得大福；所以，对寒热、风雨，虽然无所增损，然而因为能生起恶意，所以得罪。因此，应当忍。

再者，菩萨自己知道宿世罪业的因缘：“生在这苦处，这是我自己造作的，我应当自己承受。”这样思惟，所以能忍。

再者，菩萨思惟：“国土有两种：有净的，有不净的。”菩萨如果生在不净的国土中，受这些辛苦、饥寒等众恼，自己发起清净之愿：“我成佛时，国中没有这些众苦。”“这里虽然不净，却正是我的利益。”

再者，菩萨思惟：“世间八法，贤圣都不能免，何况是我？”所以应当忍。

再者，菩萨思惟：“知道这人身不牢固、不坚强，被老、病、死所追逐；即使是清净的天身，没有老、没有病，却耽着天上之乐，譬如醉人，不能修行道业福德、出家离欲。”所以，在这人身中自己忍受，修福，利益众生。

再者，菩萨思惟：“我受这四大、五众之身，应当有种种苦分，没有受身而不苦的；富贵、贫贱，出家、在家，愚痴、智慧，明达、暗昧，没有能免的。为什么？富贵之人常有畏怖，守护财物，譬如肥羊，早早就上了屠案；如乌鸦衔着肉，众乌鸦追逐它；贫贱之人，有饥寒之苦。出家之人，今世虽然苦，后世受福得道；在家之人，今世虽然乐，后世受苦。愚人先求今世之乐，无常一到，以后就受苦；智人思惟无常与苦，以后就受乐得道。像这样等等受身的人，没有不苦的。”所以菩萨应当修行忍辱。

再者，菩萨思惟：“一切世间都是苦，我怎么还想在其中求乐？”

再者，菩萨思惟：“我在无量劫中常受众苦，毫无利益，从来不曾为法而受苦；今日为众生求佛道，虽然受这些苦，必当得到大利益。所以外内诸苦，都应当忍受。”

再者，菩萨发大心誓愿：“即使是阿鼻泥犁（地狱）之苦，我也应当忍受，何况小苦却不能忍？如果小苦不忍，怎么能忍大苦？”

像这样种种在外法中的忍，名为法忍。

### 三、于内心法中忍

问：怎样在内心之法中能忍？

答：菩萨思惟：“我虽然还没有得道，诸结使还没有断，如果不忍，与凡人没有差别，就不是菩萨。”

又自己思惟：“如果我已经得道，断了诸结使，就没有法可忍了。”

#### （一）内外魔军：佛答魔王十军偈

再者，“饥渴、寒热，是外在的魔军；结使、烦恼，是内在的魔贼。我应当破这两种军以成就佛道；如果不这样，佛道不能成就。”

如经中所说，佛苦行六年时，魔王来说：“刹利贵人，你千分生机中只剩一分活路了！快起来回国，布施修福，可以得到今世、后世，人中、天上之乐；道是得不到的，你白白勤苦；你如果不接受这好言相劝，固守迷执不起来，我就率领大军来击破你！”

菩萨说：“我现在要破你力量强大的内军，何况外军？”

魔说：“什么是我的内军？”

菩萨回答：

```
欲是汝初军，　　忧愁为第二，
饥渴第三军，　　渴爱为第四，
睡眠第五军，　　怖畏为第六，
疑悔第七军，　　瞋恚为第八，
利养虚称九，　　自高蔑人十。
如是等军众，　　厌没出家人；
我以禅智力，　　破汝此诸军，
得成佛道已，　　度脱一切人。
```

大意：欲是你的第一军，忧愁是第二军，饥渴是第三军，渴爱是第四军，睡眠是第五军，怖畏是第六军，疑悔是第七军，瞋恚是第八军，利养虚名是第九军，自高轻人是第十军。像这样的军众，压没出家之人；我以禅定与智慧之力，破你这些军众，成就佛道之后，度脱一切人。

菩萨对这些军众虽然还不能破除，却披上忍辱之铠，握着智慧之剑，执着禅定之盾，遮挡诸烦恼之箭，这名为内忍。

#### （二）遮而不断：无脂肥羊

再者，菩萨对诸烦恼，应当修忍，不应当断结。为什么？

如果断了结使，所失甚多，堕入阿罗汉道中，与根已败坏的人没有差别。所以遮止而不断除，以修忍辱，不随顺结使。

问：结使还没有断，怎么能不随顺？

答：因为正确思惟，虽然有烦恼，也能不随顺。

再者，因为思惟观察空、无常之相，所以即使有美妙的五欲，也不生诸结使。譬如国王有一位大臣，自己隐藏了罪过，别人不知道。国王说：“取一只没有油脂的肥羊来，你如果得不到，就治你的罪。”大臣有智慧，拴了一只大羊，用草谷好好喂养；每天三次用狼来恐吓它，羊虽然得到喂养，却肥而无脂。他把羊牵来给国王，国王派人宰杀，果然肥而无脂。国王问：“怎么能这样？”大臣以上面的事回答。菩萨也是这样，见到无常、苦、空之狼，使诸结使的油脂消去，诸功德之肉肥壮。

再者，菩萨的功德福报无量，所以其心柔软，诸结使淡薄，容易修习忍辱。譬如狮子王在林中吼叫，有人看见它，叩头哀求，它就放人离去；虎豹等小兽，不能这样。为什么？因为狮子王是尊贵的兽，有智慧能分别；虎豹是卑贱的兽，不知分别。又如溃败的军队，遇到大将就能活命，遇到小兵就会被杀。

再者，菩萨以智慧之力，观察瞋恚有种种恶，观察忍辱有种种功德，所以能忍结使。

再者，菩萨心有智慧之力，能断结使，为了众生而久住世间；知道结使是贼，所以忍而不随顺。菩萨系缚这结使之贼，不让它放纵，而自己修行功德；譬如有一个贼，因为某种因缘不杀他，把他牢牢关在一处，而自己修自己的事业。

【译注】“菩萨于诸烦恼中应当修忍，不应断结”，是本卷法忍的一个要处。断尽结使则入阿罗汉道，论主比之为“根败”，因为菩萨要为众生久住世间；所以菩萨对烦恼是遮而不断、系而不随，以正思惟与无常、苦、空之观使结使之脂自消。下文“不以诸结使为恶，不以功德为妙”，又把这遮而不断推到实相上：结与功德一相，所以于结不瞋，于功德不爱。

再者，菩萨如实了知诸法之相，所以不认为诸结使是恶，不认为功德是妙；所以对结使不瞋，对功德不爱。以这智慧之力，能修忍辱。如偈中说：

```
菩萨断除诸不善，　　乃至极微灭无余；
大功德福无有量，　　所造事业无不办。
菩萨大智慧力故，　　于诸结使不能恼；
是故能知诸法相，　　生死涅槃一无二。
```

大意：菩萨断除诸不善，乃至极微细的也灭尽无余；大功德福无量，所作的事业无不成办。菩萨因为大智慧之力，诸结使不能恼乱他；所以能了知诸法之相，生死与涅槃是一而无二。

像这样种种因缘，虽然还没有得道，在诸烦恼法中能忍，这名为法忍。

### 四、观一切法一、二、三相

#### （一）一相

再者，菩萨对一切法，了知其一相而无二。

一切法都有可识之相，所以说一。眼识识色，乃至意识识法，这都是有可识之相的法，所以说一。

再者，一切法都有可知之相，所以说一。苦法智、苦比智，知苦谛；集法智、集比智，知集谛；灭法智、灭比智，知灭谛；道法智、道比智，知道谛。以及善的世俗智，也知苦、集、灭、道，以及虚空、非智缘灭，这都是有可知之相的法，所以说一。

再者，一切法都有可缘之相，所以说一。眼识以及与眼识相应的心法缘色；耳识、鼻识、舌识、身识也是这样；意识以及与意识相应的心法，也缘眼、也缘色、也缘眼识，乃至缘意、缘法、缘意识。一切法都有可缘之相，所以说一。

再者，有人说：一切法各自都是一，一又有一，名为二；三个一名为三；像这样乃至千万，都是一而假名为千万。

再者，一切法中都有相，所以说一；因为是一相，所以名为一。一切物都名为法；因为是法相，所以名为一。像这样等等无量的“一”门，破除异相，又不执着于一，这名为法忍。

#### （二）二相

再者，菩萨观察一切法为二。

哪二种？二名为内相、外相。因为有内、外之相，所以内不是外相，外不是内相。

再者，一切法因为有有、无之相，所以为二。空与不空，常与非常，我与非我，色与非色，可见与不可见，有对与非有对，有漏与无漏，有为与无为，心法与非心法，心所法与非心所法，心相应法与非心相应法。

像这样无量的“二”门，破除一，又不执着于二，这名为法忍。

#### （三）三相

再者，菩萨有时观察一切法为三。

哪三种？下、中、上；善、不善、无记；有、无、非有非无；见谛所断、思惟所断、无所断；学、无学、非学非无学；报、有报、非报非有报。

像这样无量的“三”门，破除一，又不执着于异，这名为法忍。

### 五、信受甚深法

#### （一）信三法印

再者，菩萨虽然还没有得到无漏道，结使还没有断，却能信受无漏的圣法，以及三种法印：一是一切有为生法无常等印，二是一切法无我印，三是涅槃实法印。

得道的贤圣之人，自己证得、自己了知；菩萨虽然还没有得道，却能信、能受，这名为法忍。

#### （二）于十四难中忍：毒箭喻

再者，在十四难不答之法中，有常、无常等，观察而无所障碍，不失中道，对这样的法能忍，这是法忍。

如有一位比丘，对这十四难思惟观察，不能通达，心中不能忍受；拿着衣钵来到佛那里，对佛说：“佛如果能为我解答这十四难，使我心中明了，我就作佛的弟子；如果不能解答，我就再去求其他的道！”

佛告诉他：“痴人！你本来与我约定过：‘如果回答了十四难，你就作我的弟子’吗？”

比丘说：“没有！”

佛说：“你这痴人，现在为什么说：‘如果不回答我，就不作弟子’？我是为老、病、死之人说法救度；这十四难是斗诤之法，对法毫无益处，只是戏论，问它做什么？如果为你回答，你心中不明了，到死也不能理解，不能脱离生、老、病、死。譬如有人身中毒箭，亲属请来医生，要为他拔箭涂药，他却说：‘还不可以拔箭，我先要知道你的姓名、亲族籍贯、父母的年岁；其次要知道这箭出自哪座山，是什么木、什么羽，作箭镞的是什么人，是什么样的铁；又要知道弓是哪座山的木、什么兽的角；又要知道药生在哪里，是什么种类、什么名称；像这样的事，全都清清楚楚地知道了，然后才让你拔箭涂药。’”

佛问比丘：“这人能够先知道这些事，然后再拔箭吗？”

比丘说：“不可能知道！如果等到全都知道，这人早已死了。”

佛说：“你也是这样！被涂着爱毒的邪见之箭已经射入你的心中，想要拔出这箭，才作我的弟子；你却不想拔箭，反而要穷究世间是常、是无常，有边、无边等，求之未得，就已经失去慧命，与畜生同死，自投于黑暗之中！”

比丘惭愧，深深领会佛语，当即证得阿罗汉道。

再者，菩萨想要成为一切智人，应当推求一切法，了知其实相；在十四难中不滞留、不障碍，知道它是心的重病，能够出离、能够忍受，这名为法忍。

#### （三）信甚深佛法

再者，佛法甚深，清净微妙，演说种种无量法门，能一心信受，不疑、不悔，这名为法忍。

如佛所说：“诸法虽然是空，也不断、也不灭；诸法以因缘相续而生，也不是常；诸法虽然没有神我，也不失罪福。”在一念之间，身中诸法、诸根、诸慧，转灭不停，到不了后一念；新新生灭，却也不失去无量世中因缘所造之业。在诸众、界、入中，都空而无神我，而众生却在五道中轮转，受生受死。

像这样等等种种甚深微妙之法，虽然还没有得到佛道，能信能受，不疑、不悔，这是法忍。

再者，阿罗汉、辟支佛畏恶生死，早求入涅槃；菩萨还没有成佛，却想求一切智，想怜悯众生，想清清楚楚地分别了知诸法实相，在这当中能忍，这名为法忍。

### 六、观诸法实相

问：怎样观察诸法实相？

答：观察了知诸法没有瑕隙，不可破、不可坏，这就是实相。

问：一切言语，都可以被诘答、可以被破、可以被坏，为什么说“不可破坏，这就是实相”？

答：因为诸法不可破，所以在佛法中，超越一切言语之道，心行之处灭尽，常不生不灭，如涅槃之相。为什么？如果诸法之相是实有的，就不应当变为无；如果诸法先有而今无，这就是断灭。

#### （一）非常、非无常

再者，诸法不应当是常。为什么？如果是常，就无罪、无福，无所伤杀，也没有施与生命，也没有修行的利益，也无缚、无解，世间就是涅槃。像这样等等因缘，所以诸法不应当是常。

如果诸法是无常，那就是断灭，也无罪、无福，也没有增减功德之业，因缘果报也失去了。像这样等等因缘，所以诸法不应当是无常。

#### （二）方便语与直语

问：你说“佛法中常也不实，无常也不实”，这事不对！为什么？佛法中常也是实，无常也是实。常，是数缘尽（择灭）、非数缘尽（非择灭）、虚空，因为不生、不住、不灭，所以是常相；无常，是五众，因为有生、住、灭，所以是无常相。你为什么说“常、无常都不实”？

答：圣人有两种语：一是方便语；二是直语。方便语，是为了人、为了因缘的缘故。为了人，是为众生说这是常、这是无常，如对治悉檀中所说。如果说无常，是想拔除众生对三界的执着与贪乐；佛思惟：“用什么使众生得以离欲？”所以说无常之法。如偈中说：

```
若观无生法，　　于生法得离；
若观无为法，　　于有为得离。
```

大意：如果观察无生之法，就能从有生之法中得到出离；如果观察无为之法，就能从有为之法中得到出离。

什么是“生”？“生”名为因缘和合，无常，不自在，隶属于因缘；有老、病、死之相，欺诳之相，破坏之相，这名为“生”；生就是有为法。如对治悉檀所说：常与无常，都不是实相，因为二者都有过失。如果说诸法非有常、非无常，这是愚痴之论。为什么？如果说非有，就破了无；如果说非无，就破了有；如果破了这两件事，还有什么法可说？

#### （三）非有非无亦不可著

问：佛法常以空为相，其中非有、非无；以空来除有，以空空来遮无，这就是非有、非无，为什么说是愚痴之论？

答：佛法的实相，不受、不着。你对非有、非无有所受着，所以是愚痴之论。如果说非有、非无，这就可以说、可以破，这是心生起之处，是斗诤之处。

佛法则不是这样，虽然因为因缘的缘故说非有、非无，却不生执着；不生执着，就不可坏、不可破。诸法或者有边，或者无边，或者亦有边亦无边，或者非有边非无边；或者死后有去，或者死后无去，或者死后亦有去亦无去，或者死后非有去非无去；身就是神，身与神相异，也是这样，都不是实。在六十二见中观察诸法，也都不是实。

像这样一切都除去，信受佛法清净不坏之相，心不悔、不退转，这名为法忍。

【译注】此处辨“非有非无”最见分寸：外人以为佛法以空除有、以空空遮无，便是非有非无；论主说，只要对“非有非无”还有所受着，它就仍是可说、可破、斗诤之处，仍是痴论。佛法也因缘说非有非无，而不生着，所以不可破坏。实相的“不可破”，不在于立了一个驳不倒的命题，而在于无所受着。

#### （四）有、无二见虚诳不实

再者，有、无二边：观察诸法生起时、住时，就成为有见之相；观察诸法衰老时、坏灭时，就成为无见之相；三界众生，多执着这二种见相。这两种法，虚诳不实。如果实有其相，就不应当变为无。为什么？现在无而先前有，就堕入断灭之中，如果是断灭，那是不对的。

再者，一切诸法，因为名字和合，所以称之为有；因此，名字和合所生之法，不可得。

问：名字所生之法，虽然不可得，却有名字的和合！

答：如果没有法，名字为谁而和合？这样也就没有名字。

#### （五）坚相随心识而有

再者，如果诸法实有，不应当是因为心识才知道它有；如果是因为心识才知道它有，这就不是实有。如地的坚相，因为身根、身识知道，所以有；如果没有身根、身识知道，就没有坚相。

问：身根、身识无论知或不知，地常是坚相！

答：如果先前自己知道有坚相，或者从他人那里听说而知道有坚相；如果先前不知道、没听说，就没有坚相。

再者，地如果常是坚相，就不应当舍弃其相；如凝固的酥、蜡蜜、树胶，融化时就舍弃其坚相，落入湿相之中；金、银、铜、铁等也是这样。如水是湿相，寒冷时就转为坚相。像这样等等种种，都会舍弃其相。

再者，诸论议师之辈，有能使无变为有、有变为无的；诸贤圣之人、坐禅之人，能使地变作水、水变作地。像这样等等诸法都可转变，如十一切入中所说。

再者，这有见，是为贪欲、瞋恚、愚痴、结缚、斗诤而生；如果有生起这些贪欲、瞋恚等之处，就不是佛法。为什么？因为佛法之相是善而清净的，所以它不是实。

#### （六）色法与无色法皆空

再者，一切法有两种：色法，无色法。

色法分析乃至微尘，散灭无余，如〈檀波罗蜜品〉破所施之物中所说。

无色法，因为不是五根所能知，而是在意根生、住、灭时观察，所以知道心有分位；有分位，所以无常；无常，所以空；空，所以不是有。

一弹指之间有六十个时刻，每一个时刻中，心都有生、灭；因为相续而生，所以知道这是贪心，这是瞋心，这是痴心，这是信心、清净的智慧与禅定之心。修行者观察心的生灭，如流水、如灯焰，这名为进入空智之门。为什么？如果在一个时刻中生起，在其余时刻中才灭，这心就应当是常。为什么？因为在这极短的时刻中没有灭；如果在一个时刻中没有灭，就应当始终没有灭。

再者，佛说有为法都有三相。如果在极短的时刻中生起而没有灭，这就不是有为法。如果在极短的时刻中心有生、住、灭，为什么只是先生而后灭，不是先灭而后生？

再者，如果先有心，后有生，那么心就不待于生；为什么？因为先前已经有心了。如果先有生，那么生就无所生。又生与灭的性质相违，生时就不应当有灭，灭时就不应当有生。因此，同时不可得，异时也不可得，这就是无生；如果无生，就无住、无灭；如果无生、住、灭，就没有心所法；没有心所法，就没有心不相应诸行。

因为色法、无色法都不存在，所以无为法也不存在。为什么？因为有有为，所以有无为；如果没有有为，也就没有无为。

再者，因为见到造作之法是无常，所以推知不造作之法是常。如果是这样，现在见到造作之法是有法；不造作之法就应当是无法。因此，常法不可得。

再者，外道以及佛弟子所说的常法，有相同的，有不同的：相同的是虚空、涅槃；外道有神我、时间、方位、微尘、冥初，像这样等等名为不同的。又佛弟子说：“非数缘灭是常。”又说：“灭除因缘之法是常；因缘所生之法是无常。”摩诃衍中的常法，有法性、如、真际，像这样等等种种，名为常法。虚空、涅槃，如先前〈赞菩萨品〉中所说。神我以及时间、方位、微尘，也如上面所说。因此，不应当说诸法是有。

#### （七）破无见

如果说诸法是无，有两种：一是常无，二是因断灭而无。

如果先有今无，或者今有后无，这就是断灭。如果是这样，就没有因缘；没有因缘，就应当一件东西中出生一切东西，也应当一切东西中都无所出生。

后世之中也是这样，如果罪福的因缘断绝了，就不应当有贫富、贵贱的差别，以及堕入恶道、畜生之中。

如果说常无，就没有苦、集、灭、道；如果没有四谛，就没有法宝；如果没有法宝，就没有八贤圣道；如果没有法宝、僧宝，就没有佛宝；如果是这样，就破坏了三宝。

再者，如果一切法实在是空无，就没有罪福，也没有父母，也没有世间的礼法，也无善无恶。这样就善恶同门，是非一贯，一切东西全都没有，如梦中所见。如果说实在是无，有这样的过失，这话谁会相信！

如果说因为颠倒所以见到有，那么见一个人时，为什么不见成两个、三个？因为它实际上是无而颠倒地见为有的缘故。

#### （八）离有无二见，得中道实相

如果不堕入这有见、无见，就得到中道实相。怎样知道是实？如过去恒河沙数诸佛菩萨所知所说，未来恒河沙数诸佛菩萨所知所说，现在恒河沙数诸佛菩萨所知所说。

因为信心大，所以不疑、不悔；因为信力大，所以能持、能受；这名为法忍。

再者，因为禅定之力，心柔软清净，听闻诸法实相，与心相应契会，信受执持而深入，无疑无悔。为什么？疑、悔是欲界所系之法，粗恶，所以进不了柔软的心中，这名为法忍。

再者，因为智慧之力，在一切诸法中作种种观察，没有一法可得；对这样的法能忍、能受，不疑、不悔，这名为法忍。

再者，菩萨思惟：“凡夫因为无明之毒，在一切诸法中作颠倒之想：非常作常想，苦作乐想，无我作有我想，空的认为有实，非有认为有，有认为非有，像这样在种种法中作颠倒之想。得到圣者的真实智慧，破除无明之毒，就了知诸法实相。”得到无常、苦、空、无我的智慧，弃舍而不执着，对这样的法能忍，这名为法忍。

#### （九）观空而不着空

再者，观察一切诸法从本以来常空，今世也空，对这样的法能信、能受，这是法忍。

问：如果说从本以来常空，今世也空，这是恶邪之见，为什么说是法忍？

答：如果观察诸法常毕竟空，而以取相之心执着，这是恶邪见；如果观空而不执着，不生邪见，这是法忍。如偈中说：

```
诸法性常空，　　心亦不著空；
如是法能忍，　　是佛道初相。
```

大意：诸法之性常是空，心也不执着于空；对这样的法能忍，这是佛道最初的相状。

像这样等等种种进入智慧之门，观察诸法实相，心不退、不悔，不随逐诸观，也无所忧虑，能得自利、利他，这名为法忍。

### 七、三事清净，住般若中具足羼提

这法忍有三种行清净：不见忍辱之法，不见自身，不见骂辱自己的人；不戏论诸法，这时名为清净法忍。因为这个缘故，说菩萨住在般若波罗蜜中，能具足羼提波罗蜜，因为不动、不退。

什么名为“不动不退”？瞋恚不生，不出恶言，身不加恶，心无所疑。菩萨了知般若波罗蜜的实相，不见诸法，因为心无所执着；如果有人来骂，或者加以鞭打毒害、杀害，一切都能忍。

所以说“住在般若波罗蜜中，能具足羼提波罗蜜”。

## 释初品中毗梨耶波罗蜜义第二十六

【经】“因为身心精进不懈息，所以应当具足毗梨耶波罗蜜。”

【论】

### 一、精进何以第四

毗梨耶（汉语意为精进）。

问：精进是一切善法的根本，应当排在最前，现在为什么排在第四？

答：布施、持戒、忍辱，世间常有。

如宾主之间的道理，按理应当供给，乃至畜生也知道布施；或者有人因为种种因缘而能布施，或者为了今世，或者为了后世，或者为了道而布施，都不必须精进。

如持戒，看见作恶的人被王法治罪，便自己畏惧，不敢为非；或者有人天性善良，不作诸恶；有人听说今世作恶、后世受罪，因为怖畏，所以能持戒；有人听说持戒的因缘能得以脱离生、老、病、死，于是心中发起、口中说出：“我从今日起，不再杀生。”像这样等等就是戒，哪里需要精进波罗蜜才能修行？

如忍辱中，如果被骂、被打、被杀，或者因为畏惧而不报复，或者因为力量小，或者因为畏惧罪报，或者因为修习善人之法，或者为了求道，默然不报复，都不一定需要精进波罗蜜才能忍。

现在想要了知诸法实相，因为修行般若波罗蜜，所以修行禅定；禅定是真实智慧之门，在这当中应当勤修精进，一心修禅。

再者，布施、持戒、忍辱，是大福德，安稳快乐，有好的名誉，想要的都能得到；既已尝到这福利的滋味，现在想要更加增进，再得到殊妙的禅定、智慧。譬如挖井，已经看见湿泥，再更加努力，必定能得到水；又如钻木取火，已经看见烟，加倍用力，必定能得到火。

想要成就佛道，共有两门：一是福德，二是智慧。

修行布施、持戒、忍辱，这是福德之门；了知一切诸法实相，即摩诃般若波罗蜜，这是智慧之门。

菩萨进入福德之门，除去一切罪，所愿都能得到；如果不能得愿，是因为罪垢遮障的缘故。

进入智慧之门，就不厌生死、不乐涅槃，因为二者是一。

现在想要出生摩诃般若波罗蜜，般若波罗蜜必须经由禅定之门，禅定之门必须有大精进之力。

为什么？散乱的心不能见到诸法实相。譬如在风中点灯，不能照物；灯在密闭的屋中，光明必定能照。

这禅定、智慧，不能凭福德与愿力求得，也不是粗浅的观察所能得到，必须身心精勤，紧切而不懈怠，这才能成办。如佛所说：血、肉、脂、髓都使之竭尽，只剩下皮、骨、筋，也不舍弃精进，这样才能得到禅定、智慧；得到这两件事，众事都能成办。

所以精进排在第四，名为禅定与真实智慧的根本。前三种之中虽然也有精进，因为少，所以不说。

问：有人说：只要修行布施、持戒、忍辱，就得到大福德；因为福德之力，所愿都能得到；禅定、智慧自然而至，又何必用精进波罗蜜？

答：佛道甚深难得，虽然有布施、持戒、忍辱之力，仍须精进，才能得到甚深禅定、真实智慧以及无量诸佛之法。如果不修行精进，就不能生起禅定；禅定不生，就不能生到梵天王处，何况想求佛道？

再者，有人如民大居士等，想要得到无量宝物，随意都能得到。

如顶生王统治四天下，天降七宝以及所需之物，释提婆那民分出一半座位与他同坐；虽然有这样的福德，却不能得道。

如罗频珠比丘，虽然得了阿罗汉道，乞食七天都乞不到，空钵而回；后来以禅定之火自焚其身而般涅槃。

因此知道，不只是凭福德之力就能得道；想要成就佛道，必须勤修大精进。

【译注】此处说精进为何列在第四，要点在于：施、戒、忍世间常有，种种因缘都能成办，不一定需要精进；而禅定与实相智慧，“不可以福愿求，亦非粗观能得”，必须身心精勤。所以精进列于施、戒、忍之后、禅与般若之前，是由福德门转入智慧门的关口。顶生王与罗频珠比丘两例，一个福大而不得道，一个得道而福薄，正好说明福德与道是两回事。

### 二、精进的利益

问：菩萨观察精进，有什么利益而勤修不懈？

答：一切今世、后世的道德利益，都由精进而得。

再者，如果有人想要度脱自身，尚且应当勤奋精进，何况菩萨誓愿要度脱一切众生！如赞叹精进的偈中说：

```
有人不惜身，　　智慧心决定，
如法行精进，　　所求事无难！
如农夫勤修，　　所收必丰实；
亦如涉远路，　　勤则必能达。
若得生天上，　　及得涅槃乐，
如是之因缘，　　皆由精进力。
非天非无因，　　自作故自得，
谁有智慧人，　　而不自勉励？
三界火炽然，　　譬如大炎火，
有智决断人，　　乃能得免离！
以是故佛告：　　阿难正精进，
如是不懈怠，　　直至于佛道。
勉强而勤修，　　穿地能通泉；
精进亦如是，　　无求而不得。
能如行道法，　　精进不懈者，
无量果必得，　　此报终不失！
```

大意：有人不惜身命，以智慧之心决定，如法修行精进，所求之事没有困难！如农夫勤于耕作，收获必定丰实；也如走远路，勤走必定能到达。无论得生天上，还是得涅槃之乐，这些的因缘都由精进之力。不是天神所赐，也不是没有原因，是自己作所以自己得；哪个有智慧的人不自我勉励？三界之火炽燃，如同大火，有智慧、能决断的人，才能免离！所以佛告诉阿难要正精进，这样不懈怠，直到佛道。勉力勤修，挖地就能通到泉水；精进也是这样，没有求而不得的。能如修道之法精进不懈的人，必定得到无量果报，这果报终究不会失去！

再者，精进之法，是一切诸善法的根本，能出生一切诸道法，乃至阿耨多罗三藐三菩提，何况小利！如《毗尼》中说：“一切诸善法，乃至阿耨多罗三藐三菩提，都从精进不放逸而生。”

再者，精进能激发前世的福德，如雨水滋润种子，能使之必定生长；这也是这样，虽然有前世福德的因缘，如果没有精进，就不能生起；乃至今世的利益尚且不能得到，何况佛道！

再者，诸大菩萨荷负众生，承受一切苦，乃至阿鼻泥犁中的苦，心也不懈怠，这是精进。

#### （一）精进遍在众法：巴豆喻

再者，一切众事，如果没有精进，就不能成就。譬如泻下之药，以巴豆为主；如果除去巴豆，就没有泻下之力。像这样，念处、神足、根、力、觉支、道支，必定有待于精进；如果没有精进，众事就不能成办。

如戒只在八正道中，不在其余之处；信在五根、五力中，其余之处就没有。而精进则无处不有；既总摄众法，又另外自有其门。譬如无明使，遍在一切诸使之中，而另外又有不共无明。

#### （二）增益精进：呵懈怠

问：菩萨想要得到一切佛法，想要度脱一切众生，想要灭除一切烦恼，都能如意，怎样增益精进而能成佛？譬如小火不能烧大林，火势增大，就能烧尽一切。

答：菩萨从初发心时，就立下誓愿：“应当使一切众生得到欢乐，常为一切众生，不吝惜自身；如果吝惜自身，诸善法就不能成办。”所以增益精进。

再者，菩萨以种种因缘呵责懈怠之心，使自己乐于精进：懈怠如黑云，遮覆诸明慧，吞灭功德，增长不善；懈怠的人，起初虽然有小乐，后来却有大苦。譬如有毒的食物，起初虽然香美，时间久了就会杀人。懈怠之心焚烧诸功德，譬如大火焚烧林野。懈怠的人失去诸功德，譬如遭了盗贼，一无所剩。如偈中说：

```
应得而不得，　　已得而复失，
既自轻其身，　　众人亦不敬。
常处大暗中，　　无有诸威德，
尊贵智慧法，　　此事永以失。
闻诸妙道法，　　不能以益身，
如是之过失，　　皆由懈怠心。
虽闻增益法，　　不能得上及，
如是之过罪，　　皆由懈怠心。
生业不修理，　　不入于道法，
如是之过失，　　皆由懈怠心。
上智所弃远，　　中人时复近，
下愚为之没，　　如猪乐在溷。
若为世中人，　　三事皆废失：
欲乐及财利，　　福德亦覆没。
若为出家人，　　则不得二事：
生天及涅槃，　　名誉二俱失。
如是诸废失，　　欲知其所由，
一切诸贼中，　　无过懈怠贼！
以是众罪故，　　懒心不应作，
马井二比丘，　　懈怠坠恶道；
虽见佛闻法，　　犹亦不自免！
```

大意：应当得到的得不到，已经得到的又失去；既自己轻贱自身，众人也不恭敬。常处在大黑暗中，没有种种威德，尊贵与智慧之法，永远失去了。听闻种种妙道之法，却不能用来利益自身，这样的过失，都由懈怠之心。虽然听闻增益之法，却不能达到上位，这样的过罪，都由懈怠之心。谋生之业不修治，也不进入道法，这样的过失，都由懈怠之心。上智之人弃之远离，中等之人时而又接近它，下愚之人为它所淹没，如猪乐于待在粪坑中。如果是世间之人，三件事都荒废失去：欲乐与财利，福德也覆没。如果是出家人，就得不到两件事：生天与涅槃，名誉也一并失去。这种种荒废失去，想知道它的由来，一切诸贼之中，没有超过懈怠之贼的！因为这众多罪过，懒惰之心不应当作；马宿、满宿两位比丘因懈怠而堕入恶道，虽然见到佛、听闻了法，仍然不能自免！

像这样等等种种观察懈怠之罪，精进就增长。

#### （三）观精进之益

再者，观察精进的利益：今世、后世、佛道、涅槃的利益，都由精进而来。

再者，菩萨了知一切诸法都空无所有，却不证入涅槃；怜悯众生，积集诸善法，这是精进波罗蜜的力量。

再者，菩萨一人独自，没有同等的伴侣，以精进福德之力，能破魔军以及结使之贼，得以成就佛道。

既已得到佛道，对一切诸法，了知一相无相，其实都是空；却为众生说诸法的种种名称、种种方便，度脱众生的生、老、病、死之苦。

将要灭度时，把法身交付给弥勒菩萨摩诃萨、迦叶、阿难等；然后进入金刚三昧，自己把身骨粉碎得如芥子一般，以此度化众生，而不舍弃精进之力。

再者，如阿难为诸比丘说七觉支；说到精进觉支时，佛问阿难：“你在说精进觉支吗？”阿难说：“在说精进觉支。”这样三问三答。佛当即从座位上起身，告诉阿难：“人能爱乐修行精进，没有什么事得不到；得以到达佛道，终究不会落空。”

像这样种种因缘，观察精进的利益而使之增益。

#### （四）欲、精进、不放逸

这样的精进，佛有时说为“欲”，有时说为“精进”，有时说为“不放逸”。

譬如人想要远行，刚想出发时，这名为“欲”；出发上路而不停留，这是“精进”；能自我劝勉，不使行程耽搁，这是“不放逸”。

因此，知道欲生出精进，精进生起所以不放逸，不放逸所以能生诸法，乃至得以成就佛道。

再者，菩萨想要脱离生、老、病、死，也想要度脱众生，常应当精进，一心不放逸。如人捧着油钵在大众中行走，因为当下一心不放逸，所以大得名利。又如在悬崖边的栈道、险峻的道路上，或者攀着悬绳，或者骑着山羊而行；在这些险恶的道路上，因为一心不放逸，身体得以安稳，今世大得名利。求道的精进也是这样；如果一心不放逸，所愿都能得到。

再者，譬如水流能冲开大石；不放逸之心也是这样。专修方便，常行不废，能破除烦恼诸结使之山。

再者，菩萨有三种思惟：“如果我不作，就得不到果报；如果我自己不作，果报也不会从他人那里来；如果我作了，终究不会失去。”这样思惟，必定精进，为了佛道，勤修专精而不放逸。

#### （五）林神警懈怠比丘

如有一位年轻的阿兰若比丘，独自在林中坐禅，却生起懈怠。林中有一位神，是佛弟子，进入一具死尸的骨架中，唱歌跳舞而来，说这偈：

```
林中小比丘，　　何以生懈废？
昼来若不畏，　　夜复如是来！
```

大意：林中的年轻比丘，为什么生起懈怠荒废？白天我来，你如果不怕，夜里我还会这样来！

这比丘惊怖地起来坐好，在心中思惟；到了半夜又睡着了，这神又显现十个头，口中出火，牙齿爪子如剑，眼睛红如火焰。回头对随从说：“捉住这个懈怠的比丘！这里不应当懈怠，为什么这样！”这比丘非常恐惧，当即起来思惟，专精念法，证得阿罗汉道。这名为自强精进、不放逸的力量，能得道果。

再者，这精进不吝惜身体而珍惜果报；在身体的四种威仪——坐、卧、行、住中，常勤精进，宁可自己失去身体，也不荒废道业。譬如失火，用瓶中的水去浇，只求灭火，不吝惜瓶子。

如仙人之师教导弟子，说偈道：

```
决定心悦豫，　　如获大果报，
如愿事得时，　　乃知此最妙！
```

大意：心意决定而喜悦，如同获得大果报；等到如愿之事得成时，才知道这是最妙的！

像这样种种因缘，观察精进的利益，能使精进增益。

#### （六）苦行而念三涂众生

再者，菩萨修种种苦行，如果有人来求索头、目、髓、脑，都能给予，而自己想：“我有忍辱、精进、智慧、方便之力，承受这些尚且觉得苦，何况愚痴的三涂众生？我应当为了这些众生，勤修精进，早成佛道而度脱他们。”

## 本卷要义

本卷把忍辱从众生推到法上。上卷的生忍，忍的是恭敬供养、淫欲、瞋恼的人；本卷开头就说，忍那恭敬供养之法、瞋恼淫欲之法，才是法忍。这一转，使忍的对象从人变成了法本身：内不着六情，外不受六尘，内外一相，不作分别，以《维摩诘经》不二法门为证。于是法忍有了由浅入深的几层：对寒热饥渴等非心法能忍，对瞋恚、淫欲等心法能忍，对一、二、三等无量法门不著，对十四难不滞不碍，对甚深佛法能信能受，最后对诸法实相不疑不悔。

对内心烦恼的忍，是本卷最见菩萨道特色之处。论主说菩萨于烦恼应当修忍，不应当断结，断尽结使则堕阿罗汉道，与根败无异；所以菩萨是遮而不断、系而不随。无脂肥羊之喻说得透彻：羊照样吃草谷，却每日被狼惊吓，所以肥而无脂；菩萨照样处在五欲之中，以无常、苦、空之狼使结使之脂消去、功德之肉肥壮。更深一层是“不以诸结使为恶，不以功德为妙”，生死涅槃一而无二，所以对结不瞋、对功德不爱，这才是忍得住烦恼的根本。

十四难与毒箭之喻，把法忍的另一面显出来：不是要答尽常、无常、有边、无边，而是知道这些是心的重病，能出能忍。紧接着论主正面讲实相，实相不可破坏，因为它超过一切言语之道。外人以佛法本有常法、无常法来驳，论主分出方便语与直语，说常与无常都是对治悉檀中的方便，两者俱有过失；外人又以“非有非无”为佛法正义，论主说只要对非有非无还有受着，它就仍是可说、可破、斗诤之处。这里的分寸在于，实相的“不可破”不靠命题驳不倒，而靠无所受着。

破有、破无两段，各有其路。破有，从名字和合、坚相随心识而有、地相可转、心念念生灭而生住灭同异俱不可得，一路推到心所、心不相应行、有为乃至无为都不可得；破无，则指出断灭之无使因果、罪福、四谛、三宝都失去，一切如梦而善恶同门。两边都不堕，才是中道实相；而菩萨尚未得道，所凭的是信力、禅定之力与智慧之力，对此能持能受、不疑不悔，这就是法忍。“诸法性常空，心亦不著空”一偈，正是全品的收束；而不见忍法、不见己身、不见骂辱之人，三事清净，才说住般若中具足羼提。

精进一品的开头回答了一个次第问题：精进是一切善法之本，为何列在第四？因为施、戒、忍世间常有，不必精进也能成办；禅定与实相智慧却不能以福愿求得，非身心精勤不可。顶生王福报至极而不得道，罗频珠得道而乞食不得，福德与道并非一事。于是精进成为由福德门入智慧门的关口，又像巴豆之于泻药、无明之于诸使，遍在一切法中而自有其门。论主呵懈怠、赞精进，以欲、精进、不放逸为远行的三个阶段，以擎油钵、走险道、水流穿石为不放逸之相，最后以菩萨苦行时念及三涂众生之苦作结，把精进的根源落在悲心上。
