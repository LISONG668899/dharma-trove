# 赠郭桑登之教言道歌

堪钦岗夏旺波 造

```
ནང་གི་རིག་པ་ཁ་ཡན་ཐོང་། །
ཕྱི་རུ་སྣང་ལ་མ་ཞེན་པར། །
ཕྱི་ནང་མེད་པ་ཟང་ཐལ་ལེ། །
རེ་དྭོགས་གྲོལ་ལ་ཨེ་མ་ཧོ། །
```

内在觉性，任其开阔坦荡；于外在显现，不生耽著；内外二者俱泯，通透洞然；希冀忧惧悉皆解脱，稀有哉！

```
ཡེངས་པ་ཡོད་ན་སེམས་ཀྱི་ཆ། །
དེ་དུས་རྒྱུ་འབྲས་ཁྱད་མ་བསད། །
ཡེངས་མེད་རིག་པའི་འཁོར་ལོ་བསྐོར། །
ལུས་སེམས་སྦུབ་དེ་གྲོལ་ལ་ཤོག །
```

若有散乱，此乃心之一分，于此之时，切莫轻忽因果；令无散乱觉性之轮得以运转，愿身心之窒闷郁结皆得解脱！

```
གང་ཤར་དབྱིངས་ལས་མ་གཡོས་པའི། །
དབྱིངས་རིག་འབྲལ་མེད་དབང་པོ་དེས། །
འཇིགས་མེད་ནམ་མཁའི་ཀློང་ནས་བརྡོལ། །
ཁྱེད་ཀྱང་ང་དང་གཉིས་མེད་ཤོག །
```

无论何念生起，皆未曾动摇于法界之外，以此法界与觉性无别之主宰力，无畏自虚空般之广袤界中迸发而出；愿你与我，无二无别！

堪钦岗夏旺波，为郭桑登所书写。

---

## 译者说明

本篇依藏文原颂重新译出，参考但不依循已有中译本之措辞。第二颂"心之一分"一语，与岗夏旺波其他教言（如《所遇即解脱》《安住心性之方便》）中反复出现之表述相呼应，指散乱等种种显现皆不出自心之显现范畴，故仍译为"心之一分"，以保持其一贯用语之统一。末颂"法界与觉性无别之主宰力"，喻指法界（空分）与觉性（明分）双运不二之力用，是大圆满教法中"觉空双运"见地的诗化表达。
