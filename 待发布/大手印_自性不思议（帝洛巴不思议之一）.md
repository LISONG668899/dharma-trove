# 自性不思议（帝洛巴不思议之一）

瑜伽自在帝洛巴说　据藏文译出

## 题解

本篇是帝洛巴"不思议"八篇口诀的第一篇（东北目录 D2305），跋语说是帝洛巴在郭日夏（གོ་རི་ཤར་བ）王宫中为一位瑜伽士所说，名为"自性不思议"。全篇约一百句，开示心性即佛、本住坛城、烦恼即智慧、界智无二，修持的要点是离执而安住于如其本然的心性。篇末以卵壳中的金翅鸟雏为喻，说众生本来是佛，只是没有证悟；又说能亲见心性，全靠上师之恩。

帝洛巴名下有八篇以"不思议"（bsam gyis mi khyab pa）为名的短篇口诀，在德格版丹珠尔续部释 ཞི 函中连续排列（第 246a 至 253a 页前后，东北目录 D2305 至 D2312）。第一篇之前有梵藏总题"大手印不思议"（梵 Acintyamahāmudrā，藏 phyag rgya chen po bsam gyis mi khyab pa），东北目录据此把第一篇编为 D2305。八篇各有独立的开头、礼敬与跋语，跋语都说是瑜伽自在帝洛巴在某地对某一种人所说，都没有译者的记载。八篇依次是：对瑜伽士说"自性不思议"，对威力者说"事业不思议"，对歌者说"音乐不思议"，对外道说"法性不思议"，对屠夫说"杀之结合不思议"，对吠陀师说"种种不思议"，对幻师说"事物不思议"，对娼女说"不思议大乐"。

这一组口诀的特点是"随类说法"：帝洛巴就每一种人所熟悉的行业与生活，把它转为认识心性的大手印之道。歌者的音声、屠夫的屠宰、幻师的幻术、娼女的欲乐，都被用作象征，指向同一个不可思议的心性。所以篇中凡是说到杀、欲、酒肉等，都是象征语言，绝不可照字面理解或效仿；涉及圆满次第风脉明点与事业手印的部分，只能在具德上师座前，依具足的灌顶与口授领受。

关于编号：所据的 Esukhia 电子版只在第一篇前标有 {D2305}，第二至第八篇没有单独的编号标记。本译依篇次顺序，把八篇依次配为 D2305 至 D2312，这一配属与东北目录通行的次序一致，但未能逐篇核对目录原书，读者须知。

体例：藏文原文全部保留在代码框中，按意义分节，每节后附汉译；凡标"存疑"的按语，表示本译对原文意思没有把握。藏文依 Esukhia 德格丹珠尔电子版，异文取第二读。

## 总题与礼敬

```
རྒྱ་གར་སྐད་དུ། །
ཨ་ཙིནྟྱ་མ་ཧཱ་མུ་དྲ་ནཱ་མ། །
བོད་སྐད་དུ། །
ཕྱག་རྒྱ་ཆེན་པོ་བསམ་གྱིས་མི་ཁྱབ་པ་ཞེས་བྱ་བ། །
དཔལ་རྡོ་རྗེ་སེམས་དཔའ་ལ་ཕྱག་འཚལ་ལོ། །
```

梵语：阿钦迭·玛哈穆札·纳玛。藏语：《大手印不思议》。

敬礼吉祥金刚萨埵！

【按】这里的梵藏题名"大手印不思议"，是整组八篇的总题，不只是本篇的题名。本篇自己的题名"自性不思议"，见于篇末跋语。

## 一、敬礼甚深寂静无为

```
སྐྱེ་འགག་མེད་པའི་ཆོས་ཉིད་འོད་གསལ་ནི། །
སྨྲ་བསམ་བརྗོད་མེད་ཕྱག་རྒྱ་ཆེན་པོའི་ལམ། །
ངོས་གཟུང་དང་བྲལ་ཡིད་ལ་མི་བྱེད་པའོ། །
ཟབ་ཞི་འདུས་མ་བྱས་ལ་ཕྱག་འཚལ་ལོ། །
```

无生无灭的法性光明，是不可言说、不可思议、无法表述的大手印之道，远离认取，不作意。敬礼甚深、寂静、无为［的法性］！

【按】这一颂是全组八篇的总礼敬，也点出全组的宗旨：法性光明不可言说、不可思议，所以称为"不思议"；修持的方法是"离认取""不作意"，与梅纪巴的不作意法类相同。

## 二、自明从无明之壳中显露

```
ཨེ་མ་ཧོ། །
རྡོ་རྗེ་དབྱེར་མེད་སྐྱེ་འཇིག་བྲལ། །
དྲག་པོས་ཁམས་གསུམ་འགྲོ་བ་ཐམས་ཅད་འདུལ། །
མུན་ཁུང་གཏེར་ལ་སྒྲོན་མེ་ལྟར། །
མ་རིག་སྦུབས་ནས་རང་རིག་གསལ། །
```

唉玛吙！金刚无别，远离生灭；以猛厉之力调伏三界一切众生。就像暗穴中的宝藏遇到明灯，自明的觉性从无明的壳中显露出来。

【按】"金刚无别"，指心性坚固不坏、无二无别。"以猛厉调伏三界"，是密乘忿怒尊调伏的象征语，这里指心性本身具有摧破一切迷乱的力量。"无明之壳"（སྦུབས），原义是壳、鞘、胎膜；第十一节以卵壳中的金翅鸟雏为喻，与此相应。

## 三、心性即佛，本住坛城

```
ཆོས་ཀུན་རྩ་བ་བྱང་ཆུབ་སེམས། །
རང་བཞིན་གཉིས་སུ་མེད་པའི་ཕྱིར། །
སེམས་ཉིད་རང་བྱུང་ཡེ་ཤེས་ཏེ། །
མ་འདྲེས་ཡོངས་རྫོགས་རྒྱལ་བའི་ཐུགས། །
དེ་ཉིད་ཇི་བཞིན་རྟོགས་གྱུར་ན། །
སངས་རྒྱས་ཞེས་ནི་དེ་ལ་བྱ། །
གདོད་ནས་གནས་པའི་དཀྱིལ་འཁོར་ལ། །
གྲུབ་མེད་སྤྲུལ་པའི་དཀྱིལ་འཁོར་ཤར། །
```

一切法的根本是菩提心；因为它的自性是无二的，所以心性就是自生的智慧，是无杂、圆满的诸佛之意。如实证悟了它，就称之为"佛"。在本来安住的坛城之中，无所成立的化现坛城显现出来。

【按】"本来安住的坛城"指心性本身；"化现的坛城"指从心性中显现的一切身、智、事业。"无所成立"（གྲུབ་མེད），是说这些显现虽然现起，却没有实有的自性。

## 四、无勤安住，化现不可思议

```
དེ་ལྟར་རྟོགས་པའི་རྣལ་འབྱོར་པ། །
གདལ་ཁྱབ་ས་ལ་འབད་པ་མེད། །
ཟག་མེད་རྣམ་གྲོལ་ངང་དུ་གདབ། །
རྒྱལ་བའི་དགོངས་པ་འདི་ཁོ་ན། །
དཀྱིལ་འཁོར་ལ་སོགས་འཕྲོ་འདུ་རྣམས། །
ཆེད་དུ་མ་བྱས་ངང་ནས་ཤར། །
འོད་གསལ་ཆུ་བོའི་དབའ་རླབས་ཀྱི། །
ངོ་མཚར་རྣམ་སྤྲུལ་བསམ་མི་ཁྱབ། །
```

如此证悟的瑜伽士，在周遍一切的境界中，无须勤作，只是安置于无漏解脱的状态之中。诸佛的密意，唯此而已。坛城等等的放射与收摄，都是从非刻意造作的状态中显现的，是光明河流上的波浪，稀有的化现不可思议。

【按】存疑。"གདལ་ཁྱབ་ས"，字面是"平铺、遍满之地"，本译理解为心性周遍一切的境界。"放射与收摄"（འཕྲོ་འདུ），是生起次第中光明放射、收回的观修；这里说它们都从心性自然现起，如同河上的波浪，不必刻意造作。

## 五、烦恼显为智慧

```
དེ་ཕྱིར་ཆོས་རྣམས་སྣ་ཚོགས་ཀུན། །
ཇི་བཞིན་མ་ཡིན་མ་བཅོས་བཞིན་དུ་སྣང། །
ཉོན་མོངས་ལྔ་སོགས་རང་བཞིན་རྣམས། །
རྣམ་གྲོལ་ཡེ་ཤེས་ཆེན་པོར་ཤར། །
དེ་ཉིད་མངོན་གྱུར་བརྟན་པ་ན། །
མི་ཟད་རྒྱན་གྱི་འཁོར་ལོ་སྣང། །
གཉིས་སྣང་རྣམ་པ་མི་མངའ་བས། །
རང་དོན་རང་བཞིན་ལྷུན་གྱིས་གྲུབ། །
```

因此，一切种种诸法，都是如其本然、未经造作地显现。五毒等烦恼的自性，显现为解脱的大智慧。当真如现前而稳固时，无尽庄严之轮就会显现；因为没有二现的相，自利就以自性任运成就。

【按】存疑。"ཇི་བཞིན་མ་ཡིན་མ་བཅོས་བཞིན་དུ་སྣང"一句，字面是"不是如实的，像未造作那样显现"，文义难通。本译怀疑"མ་ཡིན"有讹，依上下文译为"如其本然、未经造作地显现"。另一种读法是：诸法并非如［凡夫所执］那样实有，只是像未造作般显现，强调显现无实；两解大意不相违。

【按】"五毒显为智慧"，是说贪、嗔、痴、慢、嫉五种烦恼的本性，就是五种智慧；这是就认识心性者而说的，并不是说可以放任烦恼。"无尽庄严之轮"，指佛的身、语、意功德无穷无尽地显现。

## 六、界智无二，方便智慧无二

```
འདི་ལྟར་སྣང་བའི་ཆོས་རྣམས་ཀུན། །
དབྱིངས་དང་ཡེ་ཤེས་གཉིས་སུ་མེད། །
འཁོར་བའི་རྣམ་རྟོག་སྣ་ཚོགས་ལས། །
རྒྱལ་བའི་སྐུ་དང་ཡེ་ཤེས་འབྱུང། །
རང་བཞིན་མ་སྐྱེས་ཡུམ་གྱི་ཀློང། །
མ་འགགས་ཤར་བ་ཡབ་ཀྱི་མཁའ། །
དེ་ལྟར་གཉིས་མེད་བདེ་བ་ནི། །
རྣལ་འབྱོར་རིག་པའི་དགོངས་པ་ཡིན། །
བྱ་བྱེད་རིག་པའི་རྩོལ་བ་རྣམས། །
ཐབས་དང་ཤེས་རབ་གཉིས་སུ་མེད། །
འཁོར་བའི་ཉོན་མོངས་དུག་གསུམ་འདི། །
ལྷུན་གྲུབ་མ་བཅོས་སྐུ་གསུང་ཐུགས། །
```

如此显现的一切诸法，法界与智慧是无二的。从轮回的种种分别之中，生起诸佛的身与智慧。自性不生，是佛母的广界；无碍显现，是佛父的虚空。这样的无二之乐，就是瑜伽士明觉的密意。能作与所作、明觉的种种勤作，都是方便与智慧的无二。轮回的烦恼三毒，就是任运成就、不加造作的身、语、意。

【按】"佛母"象征智慧、空性，"佛父"象征方便、显现；"佛母之界""佛父之空"，是以父母双运象征空性与显现无二。这是密乘的象征语言，不可照字面理解。"三毒即身语意"，是说贪、嗔、痴的本性就是佛的身、语、意三密。

## 七、离执而住于心性

```
འདུས་བྱས་ཕུང་པོའི་རང་བཞིན་ནི། །
ཟག་མེད་རྣམ་པར་གྲོལ་བ་དང། །
སྣ་ཚོགས་སྣང་བའི་འཁོར་ལོ་འདི། །
རང་བཞིན་སྤྱོད་པ་སྒྱུ་མའི་གྲོགས། །
གསང་ཆེན་བླ་མེད་ཐེག་པ་འདི། །
ཐབས་དང་ཤེས་རབ་ཕུལ་དུ་ཕྱིན། །
སྣང་དང་མི་སྣང་གཉིས་སུ་མེད། །
འཛིན་པ་བྲལ་བ་དེ་ཙམ་མོ། །
ཇི་བཞིན་མ་བཅོས་སེམས་ཉིད་ལ། །
མ་ཡེངས་བཅོས་བསླད་མེད་པར་གནས། །
```

有为五蕴的自性，就是无漏的解脱；种种显现之轮，是自性之行、如幻的伴侣。这无上秘密之乘，方便与智慧都到达究竟；显现与不显现无二，只是离开了执取而已。对于如其本然、不加造作的心性，不散乱，不以造作掺杂，就这样安住。

【按】"只是离开了执取而已"，是这一节的要点：显现本身不是问题，问题在于执取；离开执取，显现与不显现就没有差别。

## 八、心性如宝箧，显现如化乐

```
དེས་ན་གསང་བའི་སྙིང་པོ་ནི། །
ཚིག་གི་བརྗོད་པའི་ཡུལ་ལས་འདས། །
རང་ལུས་དབེན་པའི་དགོན་པ་དེར། །
ཕྱི་ནང་གསང་བའི་ཡོ་བྱད་འཛིན། །
སེམས་ཉིད་རིན་ཆེན་ཟ་མ་ཏོག། །
ཆགས་བྲལ་ནམ་མཁའ་ལྟར་དུ་འཆར། །
སྣང་བ་སྒྱུར་བྱེད་རྣལ་འབྱོར་པ། །
རིན་ཆེན་མཛེས་པ་སྣ་ཚོགས་ལ། །
འཕྲུལ་དགའ་ལྟ་བུར་སྣང་བས་ན། །
དོན་དུ་མི་འགྱུར་ཡོངས་མ་གསུངས། །
```

因此，秘密的心要，超越了言语所能表达的范围。在自身这寂静的道场里，执持外、内、密的种种资具；心性如同珍宝之箧，离贪而如虚空般显现。能转变显现的瑜伽士，对种种珍宝与美好之物，都看作化乐般的显现，所以［佛］从未说它们会成为实义。

【按】存疑。"自身寂静的道场"，是说不必到外面去找修行之处，自身就是道场。"外内密的资具"，指外在的供品、内在的风脉明点、秘密的心性等修行所用之物，具体所指不确定。

【按】存疑。"འཕྲུལ་དགའ"，字面是"幻化之乐"，可能指欲界第五天化乐天，比喻种种美好之物只是心的化现。第六十九、七十句"所以不成为实义，完全没有说过"，文义简略，本译依上下文补"佛"为主语，意思是：种种美好之物都只是心的化现，佛从未说它们是真实的。

## 九、自心即佛，何须另求

```
བདག་ཉིད་ཆེན་པོ་རྒྱལ་བའི་སེམས། །
རྟོགས་པར་འདོད་པ་དགད་བྲོ་ཨང། །
ཁམས་གསུམ་ཡེ་ནས་རྒྱལ་བའི་སྐུ། །
འཁོར་བ་མྱང་འདས་གཉིས་སུ་མེད། །
དུས་གསུམ་རྒྱལ་བ་རང་གི་སེམས། །
འབད་ཅིང་རྩོལ་བའི་ནང་དང་བྲལ། །
བདེ་དང་སྡུག་བསྔལ་དབྱེར་མེད་ལ། །
སྤོང་ལེན་མཚན་མ་འདོད་པ་ཅི། །
དེ་ཉིད་རང་གསལ་འཛིན་པ་མེད། །
འཛིན་མེད་གྲུབ་མཐའ་ལྟ་བ་བྲལ། །
```

想要［向外］去证悟大我的诸佛之心，真是可笑啊！三界本来就是佛身，轮回与涅槃无二；三时诸佛就是自己的心，远离了勤作与造作的状态。乐与苦没有分别，又何必想要取舍的相呢？它自己明了而没有执取，没有执取就远离了宗义与见解。

【按】"大我"（བདག་ཉིད་ཆེན་པོ），是对佛或心性的尊称，不是外道所说实有的我。"真是可笑啊"（དགད་བྲོ），是帝洛巴道歌中常见的语气：心性本来就是佛，还要到别处去寻求证悟，所以可笑。

【按】存疑。"འབད་ཅིང་རྩོལ་བའི་ནང་དང་བྲལ"，"ནང"字面是"内"，疑是"ངང"（状态）之讹，今依"远离勤作的状态"译出。

## 十、心之明镜，上师之恩

```
སེམས་ཀྱི་མེ་ལོང་དེ་གསལ་བ། །
སྔགས་འཆང་དགོངས་པ་མཉམ་པ་ཉིད། །
རང་ལ་གནས་པས་གཞན་དུ་མིན། །
རྒྱུན་དུ་གནས་ཀྱང་གཏིང་དཔག་དཀའ། །
རྩོལ་སྒྲུབ་བྲལ་བར་ཡོངས་ལ་ཁྱབ། །
དངོས་སུ་མཐོང་བ་བླ་མའི་དྲིན། །
མ་སྐྱེས་སྤྲོས་བྲལ་སེམས་ཉིད་ནི། །
ཁ་དོག་དབྱིབས་དང་གནས་རིག་བྲལ། །
ཟབ་ཅིང་རྒྱ་ཆེ་གསལ་བར་ལྡན། །
བརྟན་གཡོ་མ་ལུས་དེ་ལྟར་བྱོས། །
```

心的明镜明亮，就是持明者平等性的密意。它就在自己身上，不在别处；虽然恒常安住，它的深度却难以测量；远离勤作与修成，周遍一切；能亲眼见到它，是上师的恩德。不生、离戏的心性，远离颜色、形状、处所与种类；甚深广大而具足明性。对一切动与不动［的事物］，都要这样［看待］。

【按】"持明者"（སྔགས་འཆང），原义是"持咒者"，指密乘修行人。"能亲见它是上师之恩"，是噶举大手印的特点：心性本来具足，但若没有上师的指示，就不能认识。

【按】存疑。"གནས་རིག"，本译读作"处所与种类"（gnas rigs），所指不完全确定。

## 十一、众生是佛，如卵中金翅

```
འགྲོ་བ་འདི་ཀུན་སངས་རྒྱས་ཏེ། །
གསལ་བར་ཡོད་ཀྱང་རྟོགས་པ་མེད། །
སེམས་ཉིད་ནོར་བུ་རིན་ཆེན་དེ། །
སྦུབས་ན་མཁའ་ལྡིང་ཕྲུ་གུ་འདྲ། །
དམ་པ་མཉེས་བྱེད་སྐྱེས་བུ་ཡིས། །
བདེ་གཤེགས་དགོངས་པ་རྫོགས་པའི་དོན། །
དུག་གསུམ་སྐུ་གསུང་ཐུགས་སུ་དག། །
དཔའ་བོ་སེང་གེ་བཞིན་དུ་རྒྱུ། །
```

这一切众生都是佛，虽然［佛性］明明存在，却没有证悟。心性这如意宝珠，就像还在卵壳中的金翅鸟雏。能使殊胜上师欢喜的人，［得到］善逝密意圆满的实义：三毒清净为身、语、意，如勇士、如狮子般游行。

【按】"卵壳中的金翅鸟雏"，是佛典常用的譬喻：金翅鸟雏在卵中已经具足飞翔之力，一旦破壳，立刻能够高飞；众生心性本来是佛，只是被无明之壳所覆，一旦破除，佛的功德当下显现。这与第二节"自明从无明之壳中显露"首尾相应。

## 十二、平等行的瑜伽士

```
ཐེག་ཆེན་གསང་བའི་རྣལ་འབྱོར་གྱིས། །
སྤྱོད་པའི་ཁྱད་པར་ཅི་སྤྱད་ཀྱང། །
ཚོགས་བསྒྱུར་ལེན་མེད་འཛིན་དང་བྲལ། །
དཀྱིལ་འཁོར་ཆེན་པོའི་གསང་བར་ཞུགས། །
སྐུ་གསུང་ཡོན་ཏན་ཕྲིན་ལས་ལ། །
འོད་གསལ་ཡེ་ཤེས་སྙོམས་མཛད་པ། །
བདག་གཞན་གཉིས་ཀྱི་འདོད་པ་སྒྲུབ། །
ཐུགས་རྗེས་ཁམས་གསུམ་སྒྲོལ་ལ་བརྩོན། །
རོལ་པའི་ཡེ་ཤེས་དགྱེས་པ་ལས། །
ཐབས་ཆེན་ཟབ་མོའི་ཐེག་པ་སྤྲོ། །
མི་ཟད་བསྡུ་བ་ཟུང་དུ་འཇུག། །
དེ་ལྟར་མཉམ་སྤྱོད་རྣལ་འབྱོར་གྱིས། །
```

修持大乘秘密的瑜伽士，无论做何种殊胜的行持，对于会供、转变，都没有取舍，远离执取，进入大坛城的秘密之中。在身、语、功德、事业上，以光明智慧平等地作为，成办自己与他人二者的心愿，以悲心精进地度脱三界。从游戏智慧的喜悦中，开展大方便的甚深之乘；无尽的摄受，双运而入。像这样，以平等行的瑜伽士……

【按】存疑。"ཚོགས་བསྒྱུར་ལེན་མེད"一句，"ཚོགས"可解为会供，也可解为资粮；"བསྒྱུར"是转变；本译依字面译为"对于会供、转变都没有取舍"，意思不完全确定。"无尽的摄受双运而入"，"བསྡུ་བ"可指摄受众生，也可指收摄，所指不确定。

【按】最后一句"以平等行的瑜伽士"，句子没有说完，直接接上跋语。可能原文有脱漏，也可能是以跋语中的"帝洛巴"为主语，意思是"像这样以平等行而修的瑜伽自在帝洛巴……"。今照原文保留未完句。

## 跋语

```
རྣལ་འབྱོར་གྱི་དབང་ཕྱུག་ཏི་ལླི་པས་གོ་རི་ཤར་བའི་རྒྱལ་པོའི་ཁབ་ཏུ་རྣལ་འབྱོར་པ་ལ་གདམས་པ། །
རང་བཞིན་བསམ་གྱིས་མི་ཁྱབ་པ་ཞེས་བྱ་བ་ཨི་ཐི། །
```

瑜伽自在帝洛巴在郭日夏王宫中，为一位瑜伽士所说的教言，名为《自性不思议》。如是。

## 通篇连读

无生无灭的法性光明，是不可言说、不可思议、无法表述的大手印之道，远离认取，不作意。敬礼甚深、寂静、无为［的法性］！

唉玛吙！金刚无别，远离生灭；以猛厉之力调伏三界一切众生。就像暗穴中的宝藏遇到明灯，自明的觉性从无明的壳中显露出来。

一切法的根本是菩提心；因为它的自性是无二的，所以心性就是自生的智慧，是无杂、圆满的诸佛之意。如实证悟了它，就称之为"佛"。在本来安住的坛城之中，无所成立的化现坛城显现出来。

如此证悟的瑜伽士，在周遍一切的境界中，无须勤作，只是安置于无漏解脱的状态之中。诸佛的密意，唯此而已。坛城等等的放射与收摄，都是从非刻意造作的状态中显现的，是光明河流上的波浪，稀有的化现不可思议。

因此，一切种种诸法，都是如其本然、未经造作地显现。五毒等烦恼的自性，显现为解脱的大智慧。当真如现前而稳固时，无尽庄严之轮就会显现；因为没有二现的相，自利就以自性任运成就。

如此显现的一切诸法，法界与智慧是无二的。从轮回的种种分别之中，生起诸佛的身与智慧。自性不生，是佛母的广界；无碍显现，是佛父的虚空。这样的无二之乐，就是瑜伽士明觉的密意。能作与所作、明觉的种种勤作，都是方便与智慧的无二。轮回的烦恼三毒，就是任运成就、不加造作的身、语、意。

有为五蕴的自性，就是无漏的解脱；种种显现之轮，是自性之行、如幻的伴侣。这无上秘密之乘，方便与智慧都到达究竟；显现与不显现无二，只是离开了执取而已。对于如其本然、不加造作的心性，不散乱，不以造作掺杂，就这样安住。

因此，秘密的心要，超越了言语所能表达的范围。在自身这寂静的道场里，执持外、内、密的种种资具；心性如同珍宝之箧，离贪而如虚空般显现。能转变显现的瑜伽士，对种种珍宝与美好之物，都看作化乐般的显现，所以［佛］从未说它们会成为实义。

想要［向外］去证悟大我的诸佛之心，真是可笑啊！三界本来就是佛身，轮回与涅槃无二；三时诸佛就是自己的心，远离了勤作与造作的状态。乐与苦没有分别，又何必想要取舍的相呢？它自己明了而没有执取，没有执取就远离了宗义与见解。

心的明镜明亮，就是持明者平等性的密意。它就在自己身上，不在别处；虽然恒常安住，它的深度却难以测量；远离勤作与修成，周遍一切；能亲眼见到它，是上师的恩德。不生、离戏的心性，远离颜色、形状、处所与种类；甚深广大而具足明性。对一切动与不动［的事物］，都要这样［看待］。

这一切众生都是佛，虽然［佛性］明明存在，却没有证悟。心性这如意宝珠，就像还在卵壳中的金翅鸟雏。能使殊胜上师欢喜的人，［得到］善逝密意圆满的实义：三毒清净为身、语、意，如勇士、如狮子般游行。

修持大乘秘密的瑜伽士，无论做何种殊胜的行持，对于会供、转变，都没有取舍，远离执取，进入大坛城的秘密之中。在身、语、功德、事业上，以光明智慧平等地作为，成办自己与他人二者的心愿，以悲心精进地度脱三界。从游戏智慧的喜悦中，开展大方便的甚深之乘；无尽的摄受，双运而入。像这样，以平等行的瑜伽士……
