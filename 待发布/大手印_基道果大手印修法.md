# 基道果大手印修法

阿阇黎般迦拉 造

## 题解

本篇出自德格版丹珠尔续部（རྒྱུད་འགྲེལ།）ཟི 函第20b叶第4行至第21a叶第3行，东北目录编号 D2388。全篇三十二句，每句七个音节，另有礼敬和跋语。篇幅很短，所以把藏文原文全部保留在代码块中，按段落分开，每段后附汉译，疑难之处另以【按】说明。

梵文题名：Sthāna-mārga-phala-mahāmudrā-bhāvanā-nāma（སྠཱ་ན་མཱརྒ་ཕ་ལ་མ་ཧཱ་མུ་དྲ་བྷཱ་བ་ན་ནཱ་མ）。

藏文题名：གཞི་ལམ་འབྲས་བུ་བསྒོམ་པའི་ཕྱག་རྒྱ་ཆེན་པོའི་ཉམས་ལེན（修习基道果之大手印修持）。

【按】跋语中的题名作“གཞི་ལམ་འབྲས་བུ་བླ་མ་བསྒོམ་པའི་ཕྱག་རྒྱ་ཆེན་པོའི་ཉམས་ལེན”，比开头的题名多了“བླ་མ”（上师）一词，意思是“修习基道果上师之大手印修持”。从正文以观想上师为主来看，跋语的题名似乎更贴切。两处都照录。

【按】作者名在跋语中作“སློབ་དཔོན་པཾ་ཀ་ལས”。“ལས”可以看作作格助词，那么名字就是“པཾ་ཀ་ལ”（般迦拉）；也可以看作名字的一部分。八十四大成就者中有一位“莲生”（Paṅkajapa，藏文作པཾ་ཀ་ཛ་པ），名字相近，但是否同一人，无法确定。这里暂且音译为“般迦拉”。跋语没有记载译者。

【按】本篇的修法，是在左、右、中三脉的端口观想嗡、阿、吽三字，在三字顶上观想传承上师放光收光，属于上师瑜伽与圆满次第气脉修法相结合的修法。依传统，这类修法必须先得到相应的灌顶，并依具格上师的口授才能修持。这里翻译出来，只供学习了解之用；按语中的解释是译者依通常说法与本篇结构所作的推测，并不代表传承的口诀。

## 正文

### 第一段：标宗劝听

```
གཞི་ལམ་འབྲས་བུ་གསུམ་གྱི་ནི། །རྩ་གསུམ་བརྒྱུད་པའི་བླ་མ་དང་། །ཡིག་འབྲུ་གསུམ་གྱི་ཉམས་ལེན་ནི། །ཉམ་ཆུང་ཉོན་ཅིག་བཤད་པར་བྱ། །
```

关于基、道、果三者，以及三根本（或：三脉）传承的上师，和三个字的修持——卑微的人啊，你要仔细听，我现在来宣说。

【按】“རྩ་གསུམ”有两种可能的意思：一是“三根本”（上师、本尊、空行），二是“三脉”（左、右、中三脉）。本段说“རྩ་གསུམ་བརྒྱུད་པའི་བླ་མ”，读作“三根本传承的上师”最为顺当；但下一段第三句明明用“རྩ་གསུམ”指三脉，而且下文正是在三脉的端口观想传承上师，所以也可以读作“（安住于）三脉中的传承上师”。原文没有更多说明，这里两种读法并存，正文以“三根本”为主，括号中注出“三脉”。

【按】“ཉམ་ཆུང”是“卑微者”“弱小者”，在这里应当是称呼听法的弟子，带有亲切而谦下的语气；也有可能是作者自谦。依“ཉོན་ཅིག”（你要听）的语气，取前一种读法。

【按】“ཡིག་འབྲུ་གསུམ”，“三字”，依下文是指嗡（ཨོཾ）、阿（ཨ）、吽（ཧཱུཾ）三字。

### 第二段：专注三脉

```
ལྟེ་བ་སྤྲུལ་པའི་འཁོར་ལོ་ནས། །སྣ་བུག་གཉིས་དང་ཚངས་པའི་བར། །རྩ་གསུམ་ལ་ནི་སེམས་གཏད་བྱ། །
```

从脐间的化身轮起，直到两个鼻孔和梵穴之间，要把心专注在这三条脉上。

【按】“ལྟེ་བ་སྤྲུལ་པའི་འཁོར་ལོ”，“脐间化身轮”，是圆满次第中脐轮的通称。上一篇《四瑜伽修法》称脐轮为“智慧轮”，与此不同，特此附记。

【按】“ཚངས་པ”在这里是“ཚངས་པའི་བུ་ག”（梵穴，即顶门）的省略。这一句的意思是：三脉从脐轮起，左右二脉向上通到左右两个鼻孔，中脉向上通到顶门梵穴。

### 第三段：三脉三字

```
གཡོན་གྱི་དཀར་དང་གཡས་རྩ་དམར། །དབུས་ཀྱི་མི་བསྐྱོད་མཐིང་ག་ལ། །གཡས་པར་ཧཱུཾ་དང་གཡོན་པར་ཨོཾ། །ཚངས་པའི་བུ་གར་ཨ་ཡིག་བསམ། །
```

左脉是白色，右脉是红色，中央是不动佛（色）的蓝色（中脉）。在右（脉的端口）观想吽字，在左（脉的端口）观想嗡字，在梵穴观想阿字。

【按】“དབུས་ཀྱི་མི་བསྐྱོད་མཐིང་ག”直译是“中央之不动蓝色”，意思应是中脉为蓝色，蓝色是不动佛（阿閦佛）的颜色，所以称为“不动蓝”。这里在括号中补出“色”和“中脉”二字。

【按】本篇所配的三字位置是：右吽、左嗡、顶阿。一般常见的配法是嗡字白色在顶（或额）、阿字红色在喉、吽字蓝色在心，与本篇不同；而且本篇顶门所观的是“ཨ”（阿）字，不是常见的“ཨཱཿ”（啊）。这可能是本篇所依传承的特殊配法，原文如此，照录不改。

【按】另外，左脉白色而左边观嗡字，嗡字通常也是白色，彼此相应；右脉红色而右边观吽字，吽字通常是蓝色，与右脉的红色并不相应。原文没有交代三字各自的颜色，所以这里只照原文的位置译出。

### 第四段：放光与收摄

```
འོད་གསལ་མཐིང་ག་དཀར་དང་དམར། །ཁམས་གསུམ་སྤྲུལ་པའི་འོད་ཀྱིས་ཁྱབ། །གདུལ་བྱ་བཏུལ་ནས་སླར་ཡང་ཐིམ། །
```

（三字放出）蓝、白、红色的光明，化身之光遍满三界，调伏了所化众生之后，又再收摄回来，融入（三字）。

【按】这三句原文没有主语，依上下文，应是上一段所观的三字放光，所以在括号中补出“三字放出”和“融入三字”。“蓝、白、红”的次序原文就是如此，大概对应中、左、右三脉的颜色。

### 第五段：明点上观传承上师

```
ཡི་གེ་གསུམ་གྱི་ཟླ་ཚེས་ལ། །སྟོང་པའི་ཐིག་ལེ་སྟེང་དུ་ནི། །བརྒྱུད་པའི་བླ་མ་འོད་གསལ་ནི། །དེ་སྟེང་འདི་ལྟར་བསྒོམ་པར་བྱ། །
```

在三个字的新月之上、空性的明点之上，是光明的传承上师——要在那上面这样观修。

【按】“ཟླ་ཚེས”，“新月”“月牙”。藏文的种子字（如ཧཱུཾ、ཨོཾ）顶上常有“月牙、明点、那达”的标记，这里说“三字的新月之上、空性明点之上”，就是指这一部分。所以“空性的明点”指种子字顶上的圆点，而以空性为它的体性。

【按】第四句“དེ་སྟེང་འདི་ལྟར་བསྒོམ་པར་བྱ”，“在那上面这样观修”，“这样”可能是指上面刚说的观法，也可能是引出下文各别的观法。这里两种都可以，照字面译出。

### 第六段：左鼻孔字上观证验上师

```
གཡོན་གྱི་སྣ་བུག་ཡི་གེ་ལ། །ཡིད་ཆེས་ཉམས་མྱོང་བླ་མ་ནི། །སྐར་མ་ལྟ་བུའི་འོད་གསལ་བསྒོམ། །
```

在左鼻孔（端口）的字上，要观修信心与证验的上师，（那上师是）如星辰一般的光明。

【按】“ཡིད་ཆེས་ཉམས་མྱོང་བླ་མ”，“信心与证验的上师”，从全篇以“基、道、果”为纲来看，上一段的“传承上师”、本段的“信心证验上师”、下一段的“果现证上师”，可能正好对应基、道、果三者：传承上师是基，信心与证验（修道中的体验）的上师是道，现证果位的上师是果。这一对应是译者依结构推定的，原文没有明说。

【按】左鼻孔的字依第三段是嗡字。

### 第七段：吽字上观现证果位上师

```
འབྲས་བུ་མངོན་སུམ་བླ་མ་སྟེ། །ཧཱུཾ་ཡིག་ཟླ་ཚེས་སྟེང་དུ་སྟེ། །བརྟན་པར་བསམ་གཏན་བསྒོམ་པར་བྱ། །
```

果，就是现证的上师，（观想在）吽字的新月之上；（这样）要稳固地修习禅定。

【按】依上一按语的推定，本段对应“果”。吽字在右鼻孔端口。那么顶门阿字之上，大概就是第五段所说的“传承上师”（对应“基”）。但第五段说的是“三个字的新月之上”，似乎是总说三字上都观上师，然后第六、七段再分别细说，这样理解也说得通。两种理解这里都保留。

### 第八段：修习的功德

```
རླུང་གསུམ་འགགས་ཏེ་གདོན་གསུམ་སེལ། །དུག་གསུམ་རྣམ་རྟོག་བྲལ་འགྱུར་བ། །རྒྱུ་འབྲས་ཆོས་ཀྱི་རྟོག་པ་སྤངས། །ལུས་ཀྱི་དགོན་པ་བརྟན་འགྱུར་བས། །
བདག་གཞན་གཉིས་མེད་དོན་རྟོགས་ཏེ། །དུར་ཁྲོད་ཀྱི་ནི་འཇིགས་པ་སྤངས། །
```

（由于这样修习，）三种风息止息，便能遣除三种魔障；（心）远离三毒的分别念；舍弃对因果诸法的分别执著。由于身体这座寂静处稳固了，便能证悟自他无二的真义，舍弃了尸林中的怖畏。

【按】“རླུང་གསུམ”，“三风”，依上文三脉的脉络，大概指在左、右、中三脉中运行的风息；也可能指其他分法（如入、住、出三种）。“གདོན་གསུམ”，“三种魔障”，原文没有说是哪三种，大概是泛说魔障，与“三风”“三毒”配成一组。

【按】“རྒྱུ་འབྲས་ཆོས་ཀྱི་རྟོག་པ་སྤངས”，“舍弃因果诸法的分别”，这一句非常重要，必须说明：这里说的是舍弃对因果诸法的分别执著，也就是在修持中不执著“这是因”“这是果”等概念，安住于离戏的本性中；绝对不是说因果不存在，或者修行人可以不顾取舍因果。在世俗中，因果丝毫不爽，仍须谨慎取舍。

【按】“ལུས་ཀྱི་དགོན་པ”，“身之寂静处”，直译是“身体的阿兰若（寺院、静处）”，意思是把身体本身当作修行的寂静处。身体稳固，指身体与脉、气安住不动。

【按】“དུར་ཁྲོད་ཀྱི་འཇིགས་པ”，“尸林的怖畏”，印度瑜伽士多在尸林中修行，尸林中种种可怖的景象与鬼神，是修行人的考验。证悟自他无二，便不再有能怖与所怖，所以说舍弃了尸林的怖畏。

### 第九段：受用如幻

```
ཧ་རི་ཙནྡྲ་ནམ་མཁའི་དབྱིངས། །དྲི་ཟའི་གྲོང་ཁྱེར་ལོངས་སྤྱོད་བྱེད། །
```

如同哈里旃陀罗（之城）在虚空界中一般，（瑜伽士）受用着乾闼婆城（般的一切显现）。

【按】“ཧ་རི་ཙནྡྲ”是梵文 Hariścandra 的音译，是印度传说中的一位国王。在梵文传统中，“哈里旃陀罗城”常用来称呼空中出现的幻城（类似海市蜃楼），与“乾闼婆城”同义。所以这两句是说：瑜伽士了知一切显现都如空中幻城、乾闼婆城一样，有显现而无自性，在这样的了知中受用一切。这一解释依梵文传统推定，原文非常简略，括号中的字都是译者所补。

【按】“དྲི་ཟའི་གྲོང་ཁྱེར”，“乾闼婆城”，“乾闼婆”（དྲི་ཟ）是以香为食的天众，“乾闼婆城”是佛经中常用的如幻之喻，指空中显现的城郭，远看似有，近前却无。

## 跋语

```
གཞི་ལམ་འབྲས་བུ་བླ་མ་བསྒོམ་པའི་ཕྱག་རྒྱ་ཆེན་པོའི་ཉམས་ལེན་ཞེས་བྱ་བ་སློབ་དཔོན་པཾ་ཀ་ལས་མཛད་པ་རྫོགས་སོ།། །
```

名为《修习基道果上师之大手印修持》，阿阇黎般迦拉所造，圆满。

【按】德格版此处“ཉམས་ལེན”一词有异文作“ཉམས་ལན”，“ལན”当是“ལེན”的讹误，这里依“ལེན”。

## 通篇连读

关于基、道、果三者，以及三根本（或：三脉）传承的上师，和三个字的修持——卑微的人啊，你要仔细听，我现在来宣说。

从脐间的化身轮起，直到两个鼻孔和梵穴之间，要把心专注在这三条脉上。

左脉是白色，右脉是红色，中央是不动佛（色）的蓝色（中脉）。在右（脉的端口）观想吽字，在左（脉的端口）观想嗡字，在梵穴观想阿字。

（三字放出）蓝、白、红色的光明，化身之光遍满三界，调伏了所化众生之后，又再收摄回来，融入（三字）。

在三个字的新月之上、空性的明点之上，是光明的传承上师——要在那上面这样观修。

在左鼻孔（端口）的字上，要观修信心与证验的上师，（那上师是）如星辰一般的光明。

果，就是现证的上师，（观想在）吽字的新月之上；（这样）要稳固地修习禅定。

（由于这样修习，）三种风息止息，便能遣除三种魔障；（心）远离三毒的分别念；舍弃对因果诸法的分别执著。由于身体这座寂静处稳固了，便能证悟自他无二的真义，舍弃了尸林中的怖畏。

如同哈里旃陀罗（之城）在虚空界中一般，（瑜伽士）受用着乾闼婆城（般的一切显现）。
