# 大乐义明示

梅纪巴（阿阇黎阿瓦都帝巴·吉祥无二金刚）造　据藏文译出

## 题解

《大乐义明示》（梵 Mahāsukhaprakāśa，藏 bde ba chen po gsal ba，直译"大乐之明示"）收于德格版丹珠尔续部释 ཝི 函第 114b 至 115a 页（东北目录 D2239），紧接在《无别五颂》（D2238）之后，同属梅纪巴的"无念法类"。译者是上师金刚手与玛班译师。

前面几篇多从显教的中观与大手印来讲无住、如幻、双运，本篇则转入密乘，从生起次第与圆满次第来讲"大乐"。全篇十六颂七言，最后以一颂长句作结，大致可以分为五部分：

一、礼敬与立宗（第一、二颂）：礼敬方便与智慧为体性的金刚萨埵，说明要讲的是生起、圆满二次第的双修。

二、生起次第依缘起而成立（第三至五颂）：诸法无生，正因为是缘起，所以本尊可以从种子字生起；以"从空性菩提生种子、种子生身相、身相上布字"的次第，说明一切都依缘而生；续中所说外在的"双入"，要理解为是为了内在的证悟。

三、大乐非有非无（第六至九颂）：若无乐，便不是菩提；若执乐为实有，又成为大贪、轮回之因；缘起之乐本来寂静，非有非无；世俗与空性二者应当无二地修成。

四、由大乐而入双运（第十至十三颂）：具慧者以咒与身相的瑜伽趣入大乐，见种种如幻无二，入于真实际，证双运位，并一心利益众生；种种轮是方便，空性是智慧，内外清净即是智慧方便的体性。

五、摄要与结颂（第十四至十六颂及结颂）：显现唯是缘起，非有非空，即是本尊瑜伽；瑜伽士持嘿噜嘎的佛慢，如狮子般游行于大地；结颂赞叹证悟者成为诸轮之主、金刚空行。

本篇所说的本尊、种子字、布字、"双入"、佛慢、嘿噜嘎等，都属于密法的修持，须依具德上师的灌顶与口授来理解与修习；其中有象征的语言，不可照字面理解，更不可凭文字自行揣度而修。梅纪巴在本篇中也明确指出：续中所说外在的"双入"，是为了内在的证悟而说的。

体例：按意义单元分段，每段先列藏文原颂于代码块中，再译出；为了便于理解而补的字，都放在方括号中。原文含混或可有两解之处，以"【按】"说明，不妄补内容。原文异文 brdzun、rdzun 依校勘惯例取后者，意义相同，下文不再注出。文末附通篇连读。

## 题名与礼敬

梵语题名：Mahāsukhaprakāśa。藏语题名：《大乐义明示》。

敬礼佛陀！

【按】藏本梵题音写作 ma hā su kha pra ka sa，pra ka sa 即 prakāśa（明示、显明），与前面《无住义明示》《双运义明示》的题名同一格式。

## 一、礼敬与立宗

```
ཐབས་ཤེས་ངོ་བོ་ཉིད་ཅན་གྱི། །
རྡོ་རྗེ་སེམས་དཔའ་ལ་བཏུད་ནས། །
དངོས་པོ་དེ་ཉིད་མདོར་བསྡུས་པ། །
བདེ་བ་ཆེན་པོ་བདག་གིས་བཤད། །
བསྐྱེད་རིམ་བསྒོམ་པ་གཅིག་ཡིན་ཏེ། །
གཉིས་པ་རྫོགས་རིམ་བསྒོམ་པའོ། །
དེ་ཕྱིར་གཉི་ག་བསྒོམ་པ་ནི། །
དེ་ནི་བདག་གིས་འདིར་བརྗོད་བྱ། །
```

我顶礼以方便与智慧为本体的金刚萨埵，然后宣说大乐，［它］就是诸法真如的扼要。［修持］第一是修生起次第，第二是修圆满次第；所以，［如何］兼修这二者，我要在这里讲说。

【按】"方便与智慧"（thabs shes），在密乘中，方便指大乐、悲心，智慧指空性；金刚萨埵以二者无别为体性。"生起次第"（bskyed rim）与"圆满次第"（rdzogs rim），是无上瑜伽续修持的两个次第：前者以观想本尊、坛城为主，后者以证悟空乐、光明为主。第三句"dngos po de nyid mdor bsdus pa"，也可以理解为"把事物的真如简要地［说为］大乐"。

## 二、生起次第依缘起而成立

```
ཆོས་རྣམས་རྐྱེན་མེད་པ་རུ་ནི། །
སྐྱེ་བ་མེད་པར་ངེས་པ་སྟེ། །
རྟེན་ཅིང་འབྲེལ་འབྱུང་རང་བཞིན་ཕྱིར། །
ཧཱུཾ་སྐྱེས་མྃ་སྐྱེས་དེས་ཅི་མིན། །
```

诸法若没有因缘，就决定不会生起；［但］正因为［诸法］的本性是缘起，［本尊］从吽字生起、从芒字生起，这又有什么不可以的呢？

【按】这一颂回应一个疑问：既然诸法无生，生起次第中观想本尊从种子字生起，岂不是与无生相违？作者的回答是：无生，是指没有离开因缘的自生；而诸法正是缘起的，所以依种子字等因缘而显现本尊，完全合理。"吽"（hūṃ）、"芒"（maṃ），是生起次第中常见的种子字，例如勇父本尊多从吽字生起、佛母本尊多从芒字生起等，具体所指依各续而不同。末句"des ci min"直译是"由此为何不［可］"，这里依反问语气译出。

```
སྟོང་ཉིད་བྱང་ཆུབ་ལས་ས་བོན། །
ས་བོན་ལས་ནི་གཟུགས་སྐྱེས་འགྱུར། །
གཟུགས་ལའང་དགོད་དང་དེ་དགོད་བྱ། །
དེ་ཕྱིར་ཐམས་ཅད་རྐྱེན་ལས་སྐྱེས། །
```

从空性菩提［生起］种子［字］，从种子［字］生出身相；在身相上又［有］布字，以及那所要布的［字］——所以，一切都是从因缘而生的。

【按】这一颂与《喜金刚续》中生起次第的著名说法相合：先修空性菩提，从空中生种子字，种子字转成本尊身相，再于身相上安布种子字（梵 nyāsa，"布字"）。作者引用这个次第，是为了证成上一颂：生起次第的每一步都是依因缘而起，所以与"无生"并不相违。第三句"dgod dang de dgod bya"，直译是"布与那所布"，即"布字的动作与所布之字"，这里依此译出，具体的布字方法须依上师口授。

```
ཕྱི་རོལ་གཉིས་ནི་སྙོམས་འཇུག་པ། །
ཐུབ་པ་ཡིས་ནི་ཉེར་བསྟན་གང་། །
དེ་ནི་ནང་གི་རྟོགས་དོན་དུ། །
རྒྱུད་དུ་གསལ་བར་ཤེས་པར་བྱ། །
```

能仁［佛陀］所开示的，外在二者的"双入"，应当了知：那在续中是为了内在的证悟而明白宣说的。

【按】"双入"（snyoms 'jug，梵 samāpatti），在密续中指本尊父母的和合，也就是以男女双身为象征的修法。作者在这里明确指出：续中所说外在的"双入"，是为了内在的证悟——即方便与智慧、大乐与空性的无二——而说的。这一颂对理解全篇极为重要：它说明这一类的语言首先是象征，指向的是内在的证悟，而不是以外在的行为本身为目的。这类修法在无上瑜伽续中有极严格的条件与次第，须依具德上师的灌顶、口授与亲自引导，绝不可凭文字理解，更不可自行揣度而行。

## 三、大乐非有非无

```
བདེ་བ་ངོ་བོ་ཉིད་འདོད་གང་། །
བདེ་བ་མེད་ན་བྱང་ཆུབ་མིན། །
ཡོད་ནའང་ཆགས་པ་ཆེན་པོ་སྟེ། །
འཁོར་བར་སྐྱེ་བའི་རྒྱུ་ཉིད་དོ། །
```

那被承许为本体的大乐：若是没有乐，就不是菩提；但若［把乐执为实］有，那又是大贪著，正是投生轮回的因。

【按】这一颂提出大乐的两难：一方面，密乘认为菩提的本体就是大乐，没有乐便不是菩提；另一方面，若把这乐执为实有，就成了贪著，反而是轮回之因。下一颂就解决这个两难。

```
རྟེན་ཅིང་འབྲེལ་འབྱུང་བདེ་བ་གང་། །
གཟོད་ནས་ཞི་བའི་བདེ་བར་རྟོགས། །
དེ་ཕྱིར་དངོས་པོ་མེད་པར་བརྗོད། །
བདེ་བ་ཡོད་མིན་མེད་པའང་མིན། །
```

那缘起的乐，［应当］证悟为本来寂静的乐；所以说它没有实体：乐既不是有，也不是无。

【按】"本来寂静"（gzod nas zhi ba），即本来离开戏论、无生无灭。这一颂的意思是：菩提的大乐是缘起的，所以它并不是一个可以执取的实体，不会成为贪著之因；但它也不是没有，所以不是断灭。这与本组短论中反复出现的"离有无二边"是同一个思路，只是这里把它用在"大乐"上。

```
རེ་ཞིག་དེ་ནི་མ་སྐྱེས་པ། །
ཆོས་རྣམས་ཀྱི་ནི་དོན་དམ་ཉིད། །
བདེ་བ་རྫུན་པར་གསལ་བ་ནི། །
དག་པའི་ཀུན་རྫོབ་ཏུ་ཤེས་པས། །
བདེན་པ་ཉིད་ནི་རྣམ་པར་དག །
ཀུན་རྫོབ་སྟོང་ཉིད་རྣལ་འབྱོར་པ། །
གཉིས་པོ་གཉིས་མེད་བསྒྲུབ་བྱ་སྟེ། །
དོན་དམ་རྣམ་པར་སྤངས་བྱས་སོ། །
```

就其本身而言，那［乐］是不生的，这是诸法的胜义；而乐虚妄地明现，［应当］了知它是清净的世俗；［这样，二］谛本身都是全然清净的。修世俗与空性的瑜伽士，应当把这二者无二地修成，［而不是］把胜义［从世俗中］割离开来。

【按】"就其本身而言"（re zhig），字面是"暂且、首先"，这里理解为"就其自身而论"。这一段把大乐放在二谛中说明：大乐不生，是胜义；大乐明现如幻，是清净的世俗。两者都清净，所以不需舍世俗而另求胜义。

末句"don dam rnam par spangs byas so"最难解，直译是"胜义被作为全然舍弃"。若照字面，似乎是说"舍弃胜义"，与上文不合。这里的理解是：瑜伽士要无二地修成世俗与空性，不把胜义当作与世俗分离、可以单独执取的东西，所以说"舍弃"那与世俗割离的胜义。另一种可能是"远离［对］胜义［的执著］"。两种理解要点相近，原文可能有讹误，存疑。

## 四、由大乐而入双运

```
སྔགས་དང་དབྱིབས་ཀྱི་སྦྱོར་བདག་ཉིད། །
བློ་ལྡན་བདེ་བ་དེར་སོང་ནས། །
དེ་ནས་སྣ་ཚོགས་སྒྱུ་མ་བཞིན། །
གཉིས་སུ་མེད་པར་དེ་ལྟར་མཐོང་། །
དེ་ནས་ཡང་དག་མཐར་འཇུག་ཅིང་། །
ཟུང་འཇུག་གོ་འཕང་རྟོགས་པར་འགྱུར། །
ཟུང་འཇུག་ལ་གནས་རྣལ་འབྱོར་པ། །
སེམས་ཅན་དོན་ལ་གཅིག་ཏུ་བརྩོན། །
```

具慧者以咒与身相的瑜伽为体性，趣入那大乐之后，便见种种［显现］如幻，如此无二。然后，他入于真实际，证悟双运的果位。安住于双运的瑜伽士，一心一意地致力于利益众生。

【按】"咒与身相的瑜伽"（sngags dang dbyibs kyi sbyor），指生起次第中持诵咒语与观想本尊身相的修持。"真实际"（yang dag mtha'，梵 bhūtakoṭi），指实相的究竟边际，在密续圆满次第中常指证悟光明。"双运的果位"（zung 'jug go 'phang），在无上瑜伽续中指幻身与光明双运的境界。作者特别强调：安住于双运的瑜伽士，一心利益众生——这与前面几篇反复说明的"证悟空性并不舍弃利他"是一致的。这些次第都属于密法的修持，须依具德上师的口授。

```
བདེ་སེམས་ལྷ་ཡི་རྣལ་འབྱོར་པ། །
སྣ་ཚོགས་འཁོར་ལོ་ཐབས་ཡིན་ཏེ། །
ཤེས་རབ་སྟོང་པ་ཉིད་དུ་བརྗོད། །
དེ་ནི་བདག་ཉིད་བསྒྲུབ་བྱར་འདོད། །
ཕྱི་ནང་དག་པ་དེ་ཉིད་ནི། །
ཤེས་རབ་ཐབས་ཀྱི་བདག་ཉིད་དེ། །
བདེ་བ་གནས་མེད་རྣལ་འབྱོར་པས། །
མདོར་བསྡུས་འདི་ལྟར་ཤེས་པར་བྱ། །
```

对以乐心［修］本尊的瑜伽士来说，种种［显现之］轮是方便，智慧则说为空性；这［二者］被承许为要［在］自身上修成的。那内外的清净本身，就是智慧与方便的体性。安住于无住之乐的瑜伽士，应当这样扼要地了知：

【按】"乐心"（bde sems），指与大乐相应的心。"种种之轮"（sna tshogs 'khor lo），可以理解为显现的种种坛城，也可以理解为身中的种种脉轮；从"方便"与"智慧"对举来看，这里应指种种显现，以显现为方便、空性为智慧。"要在自身上修成"（bdag nyid bsgrub bya），也可以理解为"以［二者为］体性而修成"。"无住之乐"（bde ba gnas med），把本篇的大乐与《无住义明示》的无住连接起来：大乐不住于有、不住于无。末句"应当这样扼要地了知"，引出下一段的摄要。

## 五、摄要：显现即本尊瑜伽

```
རྟེན་ཅིང་འབྲེལ་འབྱུང་ཙམ་ཉིད་ཕྱིར། །

སྣང་བ་ལྷ་ཡི་རྣལ་འབྱོར་ཡིན། །
ཇི་ལྟ་ཇི་ལྟར་སྣང་གྱུར་པ། །

གཉིས་དང་གཉིས་མེད་ཤེས་པ་གང་། །
```

因为［显现］只是缘起而已，所以它既不是有，也不是［断灭的］空；以无自性为自性的显现，就是本尊瑜伽。种种显现怎样显现，它们就怎样是空性的体性。那［同时］了知二与无二的［觉知］，是远离那［二取］的习气的。

【按】第二句"不是空"（stong nyid min），这里的"空"应理解为断灭的空无，而不是中观所说的空性，否则与第六句"就是空性的体性"相违；所以补为"断灭的空"。"以无自性为自性"，是中观常用的说法。"显现就是本尊瑜伽"，是说证悟显现无自性、唯是缘起，便是本尊瑜伽的真义；本尊不是在显现之外另立的东西。

末两句较难确定。"了知二与无二"（gnyis dang gnyis med shes pa），可以理解为：了知世俗中有二、胜义中无二，而对二者都不执著的觉知；"远离那［二取］的习气"（de yi bag chags bral），de yi 可以指"二取"，也可以指"那［二与无二之分别］"。这里取前一种，存疑。

瑜伽士持守嘿噜嘎的佛慢，安住于嘿噜嘎的真义之中；他把这事物［世间］奉为上师，像狮子一样游行于大地之上。

【按】"嘿噜嘎"（he ru ka），是无上瑜伽续中忿怒本尊的总称，如胜乐金刚、喜金刚等。"佛慢"（nga rgyal），这里不是烦恼的我慢，而是生起次第中以自身即本尊的坚定认同。"嘿噜嘎的真义"，指本尊所表的空乐双运的意义。"把这事物奉为上师"（dngos 'di bla mar byas），与《俱生六颂》第六颂"就连三有，也被他奉为上师"是同一说法，那里已说明 bla mar byas 也可以理解为"使之成为殊胜"，这里同样并存。"像狮子一样"，与《真如十颂》第八颂相同，指无所畏惧。这些都属于证悟者的境界与密法的修持，须依具德上师的灌顶与口授。

## 结颂

```
གང་ཞིག་རྒྱལ་བ་རྣམས་ཀྱི་དག་པ་སྣ་ཚོགས་འདི་དག་ཀུན་ནས་རྟག་ཏུ་སྣང་། །
གཟོད་ནས་མ་སྐྱེས་མི་འཇིག་བསྐལ་པ་བྱེ་བར་རང་དང་གཞན་དུ་རྟོག་པ་སྤངས་པ་ཡི། །
བདེན་པ་རྫུན་པར་སྣང་བ་སྲིད་དང་ཞི་བར་མཉམ་པ་ཉིད་དུ་གཉིས་མེད་རང་བཞིན་ཕྱིར། །
འདི་ནི་འཁོར་ལོའི་བདག་པོ་རྒྱལ་བའི་ཡོན་ཏན་ཐུབ་དབང་རྡོ་རྗེ་མཁའ་འགྲོ་ངེས་པར་འགྱུར། །
```

对于那样的［瑜伽士］来说，诸佛的种种清净［功德］，时时处处都显现着；［他］本来不生，千万劫中也不坏灭，远离了"自"与"他"的分别；［他见到］谛实显现为虚妄，三有与寂灭平等，因为［一切］本性无二——这样的人，必定成为诸轮之主，［具足］胜者的功德，成为能仁之王、金刚空行。

【按】这一颂是长句的结颂，语法较松散。第一句的"gang zhig"（那样的人），这里理解为指上文所说的瑜伽士；也可以理解为"凡是"，即"凡是诸佛种种清净功德常时普现的［人］"。"谛实显现为虚妄"（bden pa rdzun par snang ba），可以理解为：在证悟者看来，凡夫所执为真实的，都显现为如幻不实。"三有与寂灭平等"，即轮回与涅槃平等不二。"诸轮之主"（'khor lo'i bdag po），可以是坛城之主，也是胜乐金刚等本尊的称号。"金刚空行"（rdo rje mkha' 'gro，梵 Vajraḍāka），也是本尊之名。这一颂以本尊的果位赞叹证悟者，属于密乘的表达方式。

## 通篇连读

敬礼佛陀！

我顶礼以方便与智慧为本体的金刚萨埵，然后宣说大乐，它就是诸法真如的扼要。修持第一是修生起次第，第二是修圆满次第；如何兼修这二者，我要在这里讲说。

诸法若没有因缘，就决定不会生起；但正因为诸法的本性是缘起，本尊从吽字生起、从芒字生起，又有什么不可以呢？

从空性菩提生起种子字，从种子字生出身相，在身相上又有布字以及所布之字——所以一切都是从因缘而生的。

能仁所开示的外在二者的双入，应当了知：那在续中是为了内在的证悟而明白宣说的。

那被承许为本体的大乐，若没有乐，就不是菩提；但若把乐执为实有，那又是大贪著，正是投生轮回的因。

那缘起的乐，应当证悟为本来寂静的乐；所以说它没有实体：乐既不是有，也不是无。

就其本身而言，乐是不生的，这是诸法的胜义；乐虚妄地明现，应了知它是清净的世俗；这样，二谛本身都是全然清净的。修世俗与空性的瑜伽士，应当把二者无二地修成，而不把胜义从世俗中割离开来。

具慧者以咒与身相的瑜伽为体性，趣入那大乐之后，便见种种显现如幻，如此无二；然后入于真实际，证悟双运的果位。安住于双运的瑜伽士，一心一意地致力于利益众生。

对以乐心修本尊的瑜伽士来说，种种显现之轮是方便，智慧则说为空性，这二者要在自身上修成。那内外的清净本身，就是智慧与方便的体性。安住于无住之乐的瑜伽士，应当这样扼要地了知：

因为显现只是缘起而已，所以它既不是有，也不是断灭的空；以无自性为自性的显现，就是本尊瑜伽。种种显现怎样显现，它们就怎样是空性的体性；那同时了知二与无二的觉知，远离了二取的习气。

瑜伽士持守嘿噜嘎的佛慢，安住于嘿噜嘎的真义之中；他把这世间奉为上师，像狮子一样游行于大地之上。

对于那样的瑜伽士来说，诸佛的种种清净功德时时处处都显现着；他本来不生，千万劫中也不坏灭，远离了自与他的分别；他见到谛实显现为虚妄，三有与寂灭平等，因为一切本性无二——这样的人，必定成为诸轮之主，具足胜者的功德，成为能仁之王、金刚空行。
