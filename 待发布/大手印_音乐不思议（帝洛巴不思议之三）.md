# 音乐不思议（帝洛巴不思议之三）

瑜伽自在帝洛巴说　据藏文译出

## 题解

本篇是帝洛巴"不思议"八篇口诀的第三篇（东北目录 D2307），跋语说是帝洛巴在宝聚市集（འདུས་པ་རིན་པོ་ཆེའི་ཚོང་དུས）上对一位歌者所说，名为"音乐不思议"。全篇约七十句。帝洛巴借歌者所熟悉的音声、音调、元音辅音、男声女声，开示声空无二、方便智慧双运，把歌唱转为供养与修行之道；又说一切法都摄于心，最后自称是"护持众生的歌者"。篇末劝已证的瑜伽士在尸林中行疯狂之行，属于大成就者的禁行，须知其前提，不可模仿。

帝洛巴名下有八篇以"不思议"（bsam gyis mi khyab pa）为名的短篇口诀，在德格版丹珠尔续部释 ཞི 函中连续排列（第 246a 至 253a 页前后，东北目录 D2305 至 D2312）。第一篇之前有梵藏总题"大手印不思议"（梵 Acintyamahāmudrā，藏 phyag rgya chen po bsam gyis mi khyab pa），东北目录据此把第一篇编为 D2305。八篇各有独立的开头、礼敬与跋语，跋语都说是瑜伽自在帝洛巴在某地对某一种人所说，都没有译者的记载。八篇依次是：对瑜伽士说"自性不思议"，对威力者说"事业不思议"，对歌者说"音乐不思议"，对外道说"法性不思议"，对屠夫说"杀之结合不思议"，对吠陀师说"种种不思议"，对幻师说"事物不思议"，对娼女说"不思议大乐"。

这一组口诀的特点是"随类说法"：帝洛巴就每一种人所熟悉的行业与生活，把它转为认识心性的大手印之道。歌者的音声、屠夫的屠宰、幻师的幻术、娼女的欲乐，都被用作象征，指向同一个不可思议的心性。所以篇中凡是说到杀、欲、酒肉等，都是象征语言，绝不可照字面理解或效仿；涉及圆满次第风脉明点与事业手印的部分，只能在具德上师座前，依具足的灌顶与口授领受。

关于编号：所据的 Esukhia 电子版只在第一篇前标有 {D2305}，第二至第八篇没有单独的编号标记。本译依篇次顺序，把八篇依次配为 D2305 至 D2312，这一配属与东北目录通行的次序一致，但未能逐篇核对目录原书，读者须知。

体例：藏文原文全部保留在代码框中，按意义分节，每节后附汉译；凡标"存疑"的按语，表示本译对原文意思没有把握。藏文依 Esukhia 德格丹珠尔电子版，异文取第二读。

## 篇题

```
གླུ་མཁན་ལ་གདམས་པ་བཞུགས། །
```

对歌者的教言。

## 一、能仁以歌说法

```
ཀྱེ་ཧོ་སངས་རྒྱས་རྣམས་ཀྱིས་གསང་བའི་གསུང། །
མཛད་པ་རྣམ་གྲོལ་ཡེ་ཤེས་ཆེན་པོ་ལ། །
དགྱེས་མཉམ་རོལ་པས་ཆོས་ཀྱི་ཕུང་པོ་རྣམས། །
ཡིད་འོང་གླུ་རུ་ཐུབ་པས་བཀའ་སྩལ་ཏོ། །
```

嗟！诸佛所说的秘密之语，在解脱大智慧的事业中，以欢喜平等的游戏，能仁把一切法蕴化为悦意的歌曲而宣说。

【按】本篇对一位歌者说法，所以开篇就说：佛陀本身也是以"悦意的歌曲"来宣说法蕴的。"法蕴"（ཆོས་ཀྱི་ཕུང་པོ），指佛所说的一切教法。

## 二、声空无二，五分配佛

```
གསང་སྔགས་བརྡ་ཡི་ཚིག་མཐུན་བཀའ་ལུང་ཅན། །
ཟབ་མོའི་སྒྲ་སྒྲོགས་རྣམ་དག་སྔགས་ཉིད་དེ། །
ལུས་ཅན་གདུང་བ་སེལ་བ་བདེ་བའི་སྒྲ། །
གྲག་སྟོང་གཉིས་སུ་མེད་པ་ཟུང་འཇུག་དང། །
སྣང་བ་སྐུ་ལ་སྒྲ་ཚིག་སྣ་ཚོགས་གསུང། །
མཁྱེན་པ་ཐུགས་ལ་བྱ་བ་ཡོན་ཏན་ཡིན། །
མཛད་པ་ཕྲིན་ལས་ཡེ་ཤེས་རྣམ་པ་ལྔ། །
ཕྱོགས་བཅུ་དུས་གསུམ་རྒྱལ་བའི་རང་བཞིན་ནོ། །
```

［这些歌］与密咒表示的语言相应，具有教敕的依据；宣扬甚深的声音，就是清净的真言；是消除有身者热恼的安乐之声。音声与空性无二，就是双运。显现是身，种种音声言语是语，了知是意，所作是功德，事业是事业，配合五种智慧：这就是十方三世诸佛的自性。

【按】"声空无二"，是密乘对一切音声的看法：音声在听闻时就是空性，空性中音声宛然，二者双运无别。"身、语、意、功德、事业"，是佛的五种秘密，传统上与五智相配。帝洛巴把歌唱中的一切，都对应到这五种上。

## 三、歌之师即是佛的身语意

```
གླུ་ཡི་མཁན་པོ་མཉམ་གནས་ངོ་བོའི་སྐུ། །
ཐམས་ཅད་སྤྲུལ་པས་འཕྲོ་བར་ཁྱབ་པར་གསུངས། །
དེ་ཉིད་དབྱེར་མེད་ངང་དུ་འདུས་པ་ཐུགས། །
```

歌唱之师，是安住平等的体性身；以化现放射而遍满一切，就是语；这些在无别的状态中汇聚，就是意。

【按】存疑。第十五句"ཐམས་ཅད་སྤྲུལ་པས་འཕྲོ་བར་ཁྱབ་པར་གསུངས"，末字"གསུངས"可解为"宣说"，也可解为"语"（gsung）。本译依上下文"身、语、意"的结构，读作"就是语"。

## 四、阿字所引的梵音

```
རྒྱལ་བའི་གསུང་ལ་ཐ་དད་མེད་པ་ཡི། །
ཨ་ཡིས་དྲངས་པ་ཚངས་པའི་དབྱངས་ཀྱི་སྒྲ། །
ངོ་བོ་སྐྱེ་མེད་བརྗོད་པའི་ཡུལ་ལས་འདས། །
ང་རོ་བཅུ་དྲུག་རང་བྱུང་དགའ་བ་ཡིན། །
ཤེས་རབ་ཡུམ་ཆེན་ཁོ་ནས་འདྲེན་པའོ། །
གསལ་བྱེད་འདྲེན་པས་མི་འབྱུང་ཚིག་ཏུ་འབྲེལ། །
```

与佛语无别、由"阿"字引出的梵音之声，它的体性不生，超越了言说的范围。十六种音调，是自生的喜乐，唯有由般若大母来引导；以辅音来引导，联结成不生之语。

【按】"阿"字是一切字母之首，象征不生。"十六种音调"（ང་རོ་བཅུ་དྲུག），指梵文的十六个元音；密乘中以元音象征智慧（佛母）、以辅音象征方便，元音与辅音结合成语，象征方便与智慧双运。

【按】存疑。"མི་འབྱུང་ཚིག"，本译译为"不生之语"，也可能是"不出现的语"，所指不完全确定。

## 五、歌词开示大义

```
ཐུབ་པའི་དགོངས་པ་ལྐོག་གྱུར་མཁྱེན་པ་གཉིས། །
ཐུགས་རྗེས་སྤྲོ་ཕྱིར་གསལ་བའི་ཚིག་ཏུ་བརྒྱུས། །
དོན་ཆེན་སྟོན་པ་གླུ་ཡི་ཚིག་ཡིན་ནོ། །
```

能仁隐晦的密意与智慧二者，为了以悲心开展，编织成明白的词句；开示大义的，就是歌词。

## 六、男声女声，以声表意

```
ཕོ་ཡིས་དྲངས་ནས་མོ་ཡི་རྒྱུན་དང་ལྡན། །
གཉིས་མེད་ང་རོ་གསལ་བ་མཐོ་དང་དམའ། །
སེམས་བྱུང་རྒྱུན་གཅོད་ངང་དུ་གནས་པར་བྱེད། །
དེའུ་ཡི་སྒྲ་སྟེ་འདྲེན་པ་གླུ་ཡི་རྒྱན། །
སྒྲ་ཡིས་ཡིད་མཚོན་ཚིག་གི་དོན་ལ་སྦྱོར། །
དགྱེས་པའི་རང་རྩལ་མི་མཐུན་ཕྱོགས་ལས་རྒྱལ། །
```

由男声引出，具足女声的流续；无二的音调，明朗而有高有低；能截断心所的流续，安住于本然的状态。那是"德乌"之声，是引导，是歌曲的庄严；以音声表示心意，结合于词句的意义。欢喜的自力，胜过一切违品。

【按】"男声""女声"，在这里也象征方便与智慧；二者结合，音调就成为"无二"。"能截断心所的流续"，是说以歌声为所缘，可以使散乱的念头停息，安住于本然。

【按】存疑。"དེའུ"，可能是某种音乐术语（如颤音、拖腔），所指不明，今音译为"德乌"。

## 七、歌声作为供养

```
གསང་སྔགས་བདེན་པའི་ངག་ཏུ་བྱིན་གྱིས་རློབ། །
མི་དམིགས་ཐུགས་རྗེ་མཉམ་པའི་དབྱིངས་ལས་བྱུང། །
ཡེ་ཤེས་ཆེན་པོ་སྒྱུ་མར་རང་སྣང་བས། །
ཟག་མེད་སྙན་པའི་ང་རོ་བསོད་ནམས་ཚོགས། །
གསང་བའི་དབྱིངས་ལས་རབ་ཏུ་འཕྲོས་གྱུར་པ། །
དཀྱིལ་འཁོར་མཐའ་ཡས་རྣམས་ལ་རོལ་པས་དབུལ། །
དབང་པོ་ཡུལ་དུས་རགས་བའི་ཚོགས་རྣམས་དང། །
འབྱུང་བ་ཤེས་རབ་བྱང་ཆུབ་རྡོ་རྗེ་སྟེ། །
ལྷག་པའི་ཡེ་ཤེས་དེ་བཞིན་ཉིད་མཆོག་ལ། །
སྐལ་པ་མཉམ་པའི་མཉེས་པ་ཆེན་པོའོ། །
```

［歌声］被加持为密咒的真实语，从无所缘的悲心、平等的法界中生起。因为大智慧如幻般自然显现，所以无漏的悦耳音调，就是福德资粮。从秘密的法界中放射出来，以游戏的方式供养无边的坛城。诸根、外境、时间等等粗分的聚集，以及诸大种，都是智慧与菩提金刚；对殊胜的智慧、真如的最胜者［而言］，这是缘分相等的大欢喜。

【按】存疑。第四十、四十一句文义简略，本译理解为：以如此的歌声供养，对已证真如的诸佛来说，是"缘分相等"、同一体性的欢喜。"缘分相等"（སྐལ་པ་མཉམ་པ），也可解为"同等的福分"。

## 八、以歌为道

```
དེ་ལྟར་གླུ་ཡིས་འཇིག་རྟེན་གདུང་སེལ་ཅིང། །
འཇིག་རྟེན་འདས་པ་མཉེས་པའི་མཆོད་པ་སྟེ། །
དོན་དུ་ངེས་པ་དག་གི་རིག་བྱེད་ཅན། །
མཁྱེན་པའི་འཇུག་སྒོ་བསམ་གྱིས་མི་ཁྱབ་པ། །
སྡུག་བསྔལ་བདེ་བར་སྦྱར་བས་མཐུ་སྟོབས་ཅན། །
ཉོན་མོངས་རྣམ་གྲོལ་ཡེ་ཤེས་ཆེན་པོའི་ལམ། །
ལས་ལས་ཡེ་ཤེས་འབྱུང་བས་འཛིན་པ་མེད། །
ངེས་པར་སྦྱོར་བས་རྡོ་རྗེའི་ཚིག་གི་གླུ། །
རང་བཞིན་གཉིས་མེད་དགོངས་པ་མཐའ་ཡས་སྟོན། །
```

这样，以歌声消除世间的热恼，同时又是令出世间者欢喜的供养；具有决定之义的明者，［以此为］智慧的入门，不可思议。把痛苦转为安乐，所以具有威力；烦恼得到解脱，是大智慧之道；智慧从行为中生起，所以没有执取。以决定的结合，金刚语的歌，开显自性无二、无边的密意。

【按】存疑。"རིག་བྱེད་ཅན"，字面是"具明者"，也可能指通达明论（如吠陀）的人。这里依上下文译为"具有决定之义的明者"。

## 九、护持众生的歌者帝洛巴

```
དེ་ཡི་རྒྱུ་ཉིད་དོན་དམ་བློ་ལས་འདས། །
འབྲས་བུ་རོལ་པའི་དཀྱིལ་ལས་རྔམ་པའི་གདངས། །
མི་དམིགས་ཐུགས་རྗེའི་རྩལ་དུ་རང་ཤར་རོ། །
ཆོས་རྣམས་མ་ལུས་སེམས་སུ་འདུས་པ་སྟེ། །
སེམས་ལས་མ་གཏོགས་ཤེས་བྱ་གཞན་མེད་པས། །
སེམས་ཀྱི་རང་བཞིན་ཡེ་ནས་རྒྱལ་བའི་ཐུགས། །
འཕོ་འགྱུར་མེད་པས་འཕེལ་འགྲིབ་གོལ་ས་ཆོད། །
རང་བྱུང་དགའ་བས་འགྲོ་བའི་གདུང་བ་སེལ། །
དངས་མ་རྩེར་ཕྱིན་མཁྱེན་པ་བསམ་མི་ཁྱབ། །
སྐྱེ་དགུའི་བདག་པོ་ཚངས་པའི་རྩེ་མོའི་བར། །
སྐྱོང་བའི་གླུ་མཁན་ཏིལླི་པ་ཡིན་ནོ། །
```

它的因，就是超越心识的胜义；它的果，是从游戏的中心发出的威猛之声，自然现为无所缘悲心的力用。一切法都摄集于心，除了心之外，没有其他所知；心的自性本来就是佛心。因为没有迁移与变化，所以截断了增减的歧途；以自生的喜乐，消除众生的热恼；精华到达顶点，智慧不可思议。从众生之主梵天之顶以下，护持一切的歌者，就是帝洛巴。

【按】"一切法都摄集于心，除心之外没有其他所知"，是全篇的见地核心：歌声、听者、歌者，都不离心性。最后帝洛巴自称"歌者"，与本篇的听者相同，意思是：真正的歌者，是以证悟之歌护持三界众生的人。

## 十、在尸林中行疯狂之行

```
ཀྱེ། །
ཡོན་ཏན་སྒྱུ་མ་ཡིན་པས་སྐྱོན་ལ་དངོས་མ་གྲུབ། །
གནས་ལ་ངེས་པ་མེད་པས་འཕོ་འགྱུར་ཉམ་མི་ང། །
སེམས་ལ་སྐྱེ་ཤི་མེད་དེ་འོད་གསལ་ངང། །
དྲན་རིག་སྣ་ཚོགས་ཡེ་ཤེས་རོལ་པའི་རྩལ། །
དེ་ལྟར་ཤེས་པས་སྤང་བླང་འཛིན་པ་མེད། །
རིག་པའི་ངོ་བོ་མཉམ་ལས་མ་གཡོས་པར། །
དུར་ཁྲོད་ཆེན་པོར་སྨྱོན་པའི་སྤྱོད་པ་གྱིས། །
རྣལ་འབྱོར་རྣམས་ལ་ང་ཡིས་ལུང་བསྟན་ནོ། །
```

嗟！功德是如幻的，所以过失也没有实体；处所不是固定的，所以不畏惧迁移变化；心没有生死，是光明的状态；种种的念头与觉知，都是智慧游戏的力用。这样了知，就没有取舍的执著。明觉的体性不离平等，在大尸林中行疯狂之行——我这样为瑜伽士们授记。

【按】"在大尸林中行疯狂之行"，是印度大成就者的"禁行"（བརྟུལ་ཞུགས），指已经得到稳固证悟的瑜伽士，在尸林等处以超越世俗规范的行为来检验、增长证悟。这是对已证者而说的，有一定的前提与次第，不是一般修行人可以模仿的。

## 跋语

```
རྣལ་འབྱོར་གྱི་དབང་ཕྱུག་ཏིལླི་པས། །
འདུས་པ་རིན་པོ་ཆེའི་ཚོང་དུས་སུ་གླུ་མཁན་ལ་གདམས་པ་རོལ་མོ་བསམ་གྱིས་མི་ཁྱབ་པ་ཞེས་བྱ་བ་ཨི་ཐི། །
```

瑜伽自在帝洛巴在宝聚市集上，为一位歌者所说的教言，名为《音乐不思议》。如是。

## 通篇连读

嗟！诸佛所说的秘密之语，在解脱大智慧的事业中，以欢喜平等的游戏，能仁把一切法蕴化为悦意的歌曲而宣说。

［这些歌］与密咒表示的语言相应，具有教敕的依据；宣扬甚深的声音，就是清净的真言；是消除有身者热恼的安乐之声。音声与空性无二，就是双运。显现是身，种种音声言语是语，了知是意，所作是功德，事业是事业，配合五种智慧：这就是十方三世诸佛的自性。

歌唱之师，是安住平等的体性身；以化现放射而遍满一切，就是语；这些在无别的状态中汇聚，就是意。

与佛语无别、由"阿"字引出的梵音之声，它的体性不生，超越了言说的范围。十六种音调，是自生的喜乐，唯有由般若大母来引导；以辅音来引导，联结成不生之语。

能仁隐晦的密意与智慧二者，为了以悲心开展，编织成明白的词句；开示大义的，就是歌词。

由男声引出，具足女声的流续；无二的音调，明朗而有高有低；能截断心所的流续，安住于本然的状态。那是"德乌"之声，是引导，是歌曲的庄严；以音声表示心意，结合于词句的意义。欢喜的自力，胜过一切违品。

［歌声］被加持为密咒的真实语，从无所缘的悲心、平等的法界中生起。因为大智慧如幻般自然显现，所以无漏的悦耳音调，就是福德资粮。从秘密的法界中放射出来，以游戏的方式供养无边的坛城。诸根、外境、时间等等粗分的聚集，以及诸大种，都是智慧与菩提金刚；对殊胜的智慧、真如的最胜者［而言］，这是缘分相等的大欢喜。

这样，以歌声消除世间的热恼，同时又是令出世间者欢喜的供养；具有决定之义的明者，［以此为］智慧的入门，不可思议。把痛苦转为安乐，所以具有威力；烦恼得到解脱，是大智慧之道；智慧从行为中生起，所以没有执取。以决定的结合，金刚语的歌，开显自性无二、无边的密意。

它的因，就是超越心识的胜义；它的果，是从游戏的中心发出的威猛之声，自然现为无所缘悲心的力用。一切法都摄集于心，除了心之外，没有其他所知；心的自性本来就是佛心。因为没有迁移与变化，所以截断了增减的歧途；以自生的喜乐，消除众生的热恼；精华到达顶点，智慧不可思议。从众生之主梵天之顶以下，护持一切的歌者，就是帝洛巴。

嗟！功德是如幻的，所以过失也没有实体；处所不是固定的，所以不畏惧迁移变化；心没有生死，是光明的状态；种种的念头与觉知，都是智慧游戏的力用。这样了知，就没有取舍的执著。明觉的体性不离平等，在大尸林中行疯狂之行——我这样为瑜伽士们授记。
