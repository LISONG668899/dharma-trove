# 真如口诀·道歌宝藏

梅纪巴（阿瓦都帝巴）造　据藏文译出

## 题解

本篇（藏 do ha ti zhes bya ba de kho na nyid kyi man ngag，直译"名为'道哈'的真如口诀"；藏本所录梵题作 Dohāti-nāma-tattvopadeśa）收于德格版丹珠尔续部释 ཝི 函第 137a 至 137b 页（东北目录 D2247），紧接在《智慧·方便·慈五颂》（D2246）之后，同属梅纪巴的"无念法类"。译者是至尊陀利室利智（Dhīriśrījñāna）。

全篇十四颂，每句九言的长句，以道歌（dohā）的形式写成。它的内容，正是《真如宝鬘》（D2240）的韵文提要：先依三乘四宗，逐一说明声闻下品、中品、上品、缘觉、经部、瑜伽行有相派与无相派、中观如幻派与无住派各自的见解、禅定与过患，与《真如宝鬘》的次第、用语几乎一一对应；最后几颂则转入密咒乘，说大乐的体验、方便与智慧的和合，以及俱生之乐，补充了《真如宝鬘》中"不详说密咒"的部分。

所以，本篇与《真如宝鬘》可以对照着读：《真如宝鬘》详细，本篇简要，便于记诵。本篇有几处说法，还能帮助澄清《真如宝鬘》中的疑难，下面在按语中逐一说明。

最后三颂涉及密乘圆满次第的象征语言，如"金刚与莲花的和合""日月的和合"等，所说的都是方便与智慧、空性与悲心的双运，须依具德上师的灌顶与口授来理解，不可照字面理解。

题名中的"道哈"（do ha），即道歌（dohā）；梵题末尾的 ti，意义不明，可能是讹文。本篇题名依来稿作《真如口诀·道歌宝藏》，与萨惹哈的《道歌宝藏》（do ha mdzod）是不同的作品，读者不要混淆。

体例：按意义单元分为十二节，节题是译者所加；每节先列藏文原颂于代码块中，再译出；为了便于理解而补的字，都放在方括号中。原文含混或可有两解之处，以"【按】"说明，不妄补内容。文末附通篇连读。

## 题名与礼敬

梵语题名：Dohāti-nāma-tattvopadeśa。藏语题名：名为《道哈》的真如口诀。

敬礼吉祥嘿噜嘎！

## 一、三乘与毗婆沙宗的两派

```
ཐེག་པ་གསུམ་ནི་གནས་པ་ཞེས་བཤད་དེ། །
བྱེ་བྲག་སྨྲ་བ་གཉིས་སུ་ཤེས་པར་བྱ། །
ཉན་ཐོས་དམན་དང་འབྲིང་པོ་ནུབ་ཕྱོགས་པ། །
མཆོག་དང་རང་རྒྱལ་དག་ནི་ཁ་ཆེ་བའོ། །
```

三乘，是就［各宗的］立场而说的；毗婆沙宗，应当了知有两派：下品与中品的声闻，是西方［毗婆沙师］；上品［声闻］与缘觉，则是迦湿弥罗［毗婆沙师］。

【按】这一颂对应《真如宝鬘》第二节（总说三乘与四宗）。《真如宝鬘》说下品、中品声闻是"bye brag tu smra ba'i phyi ma"，当时按语说 phyi ma 可以理解为"后期的"，也可以理解为"外［地］的"。本篇此处明确作"西方［毗婆沙师］"（nub phyogs pa），与梵文 pāścātya 一词正相合：pāścātya 兼有"西方的"与"后期的"两义，藏译者在《真如宝鬘》中取了"后"义，在本篇中取了"西"义。由此可知，《真如宝鬘》那里所说的应是"西方毗婆沙师"，与"迦湿弥罗毗婆沙师"相对。

## 二、补特伽罗论与皈依

```
ཕུང་པོ་ལྔ་ནི་ཀུན་གྱི་གྲུབ་མཐའ་ཡིན། །
གང་ཟག་བརྗོད་མེད་ནུབ་ཕྱོགས་པ་གཉིས་འདོད། །
ཐམས་ཅད་ཇི་སྲིད་འཚོ་བར་གསུམ་སྐྱབས་འགྲོ། །
བདག་ཉིད་དུལ་བའི་སྙིང་རྗེ་ལྷག་པར་འབྱུང་། །
```

五蕴，是［毗婆沙宗］所有［派别］共同的宗义；而"不可说的补特伽罗"，是西方的两派［即下品与中品声闻］所承许的。他们全都乃至命终皈依三宝，而以调伏自己为主的悲心，生起得特别多。

【按】对应《真如宝鬘》第三节。"不可说的补特伽罗"（gang zag brjod med），即《真如宝鬘》所说"不可说是常、也不可说是无常"的补特伽罗，是犊子部等补特伽罗论者的主张。"以调伏自己为主的悲心"，对应《真如宝鬘》中下品声闻"唯愿我自己一人得以调伏"的发愿。

## 三、下品与中品的禅定与过患

```
ཐེག་པ་དམན་པ་མི་གཙང་བམ་པ་དེ། །
ལུས་གཙང་བློ་དེ་དྲི་མར་ཤེས་པར་བྱ། །
འབྱུང་དང་འཇུག་པ་འབྲིང་པོའི་སྒོམ་པ་སྟེ། །
དེ་ཡི་དྲི་མ་བུམ་པར་མཉམ་སྦྱོར་ཡིན། །
```

下乘［行者所修的］，是不净、肿胀［的尸身之观］；应当了知，把身体视为清净的心念，是［所要去除的］垢染。出息与入息，是中品［声闻］的修法；它的过患，是［闭气入］瓶的等持。

【按】对应《真如宝鬘》第三、四节。"肿胀"（bam pa），指不净观中所观的肿胀尸身。第二句的"垢染"，在《真如宝鬘》中下品的过患是"以补特伽罗为常"；本篇说"把身体视为清净的心念是垢染"，可能是指不净观所要对治的对象，而不是禅定的过患，两处说法不同；这里照字面译出，存疑。"闭气入瓶的等持"，即《真如宝鬘》所说"风瓶"的无心状态。

## 四、上品声闻：四谛

```
རབ་ཀྱི་སྒོམ་པ་བདེན་པ་བཞི་པོ་སྟེ། །
ཡན་ལག་རྒྱས་ལམ་གང་ཟག་སྟོང་པ་ཉིད། །
སྡུག་བསྔལ་འཁོར་བ་ཀུན་འབྱུང་ཆགས་པ་སྟེ། །
འགོག་པ་མྱ་ངན་འདས་པ་ཟག་མེད་ལམ། །
```

上品［声闻］的修法，是四谛；［其中］具足支分的道，是补特伽罗空性。苦［谛］是轮回，集［谛］是贪著，灭［谛］是涅槃，［道谛是］无漏的道。

【按】对应《真如宝鬘》第五节。"具足支分的道"（yan lag rgyas lam），可能指八支圣道。本篇对四谛的解释，与《真如宝鬘》略有不同：《真如宝鬘》说"集谛是分别念""灭谛是胜观""道谛是空性"，本篇则说"集谛是贪著""灭谛是涅槃""道谛是无漏道"，较为通常。

## 五、上品声闻的过患与缘觉

```
རྟག་པ་བཞི་པ་ལ་དམིགས་དྲི་མ་མེད། །
རང་གི་བསམ་མི་ཁྱབ་སྒོམ་རང་སངས་རྒྱས། །
མཉམ་གཞག་འདི་ནི་དྲི་མ་གཉིས་ཤེས་ཏེ། །
མྱོས་དང་སེམས་མེད་པ་རུ་ཤེས་པར་བྱ། །
```

缘取第四［谛］为常，［便是过患］……缘觉修自心的不可思议；应当了知，这种等持有两种过患，即沉醉［于乐］与无心。

【按】第一句原文作"rtag pa bzhi pa la dmigs dri ma med"，字面是"缘取常、第四，无垢"，句意不通。对照《真如宝鬘》第五节，上品声闻的过患是"把空性增益为恒常寂静之相"，那么这一句应是说"把第四谛（灭谛）缘取为常，是过患"；句末的 med（无）或是 yin（是）之讹。这里依《真如宝鬘》的意思译出，存疑。

后两句对应《真如宝鬘》第七节：缘觉禅定的两种过患，"沉醉"（myos）即《真如宝鬘》所说"由止观摄心而得的安乐状态"，"无心"即"心所完全灭尽的状态"。

## 六、经部宗

```
ཕྲ་བ་འདུས་པ་མདོ་སྡེ་པ་ཡི་ལུགས། །
བསམ་མི་ཁྱབ་སྒོམ་དྲི་མ་སྔོན་དང་འདྲ། །
འདི་ཡི་ལྟ་བ་ཕ་རོལ་ཕྱིན་དྲུག་ཉིད། །
སྙིང་རྗེའི་སྟོབས་ཀྱིས་ཡོངས་སུ་བསྔོ་བའོ། །
```

微细［极微］的积聚，是经部宗的观点；［他们］修不可思议，过患与前面相同。这一宗的发心行持，就是六波罗蜜多，以悲心的力量而作回向。

【按】对应《真如宝鬘》第九节。"发心行持"，原文 lta ba，见《真如宝鬘》第三节按语。

## 七、瑜伽行有相派

```
འགྲོ་བ་སེམས་ཙམ་ཡིན་ཏེ་རྡུལ་ཕྲན་མེད། །
རྣལ་འབྱོར་སྤྱོད་པ་རྨི་ལམ་ལྟ་བུ་སྟེ། །
སྔོན་པོ་སེར་པོ་ལ་སོགས་སྣ་ཚོགས་སྣང་། །
གང་ཞིག་འདོད་པ་ཐམས་ཅད་རང་བཞིན་ཏེ། །
ཐམས་ཅད་རང་གིས་རིག་པའི་བསམ་གཏན་ནོ། །
རྟག་པར་ལྟ་བ་སྒོམ་པའི་དྲི་མར་ཤེས། །
```

众生只是心，没有极微——瑜伽行宗［认为一切］如梦：青、黄等种种［行相］显现，［这些行相］所承许的一切，都是［心的］自性；一切都是自证——这是［有相派的］禅定。应当了知，把［心］视为常，是修习的过患。

【按】对应《真如宝鬘》第十至十三节中有相派的部分。"把心视为常是过患"，即《真如宝鬘》所说：若把种种行相证为胜义的心，就会近于吠檀多的"梵"。第四句"gang zhig 'dod pa thams cad rang bzhin"，也可以理解为"凡所欲求的一切都是［心的］自性"，这里依前者。

## 八、瑜伽行无相派

```
གཞན་ཡང་སྲིད་པའི་བག་ཆགས་འདོད་པའོ། །
རྣམ་པ་ཐམས་ཅད་མི་མཐུན་ཕྱོགས་སུ་གནས། །
གཉིས་སུ་མེད་མཉམ་བསམ་ཡས་རྣམ་པར་དག །
སྙིང་རྗེའི་རང་བཞིན་རྣམ་མེད་རྫོགས་སངས་རྒྱས། །
གཟུགས་ཀྱི་ས་གཉིས་རྩ་བ་ལས་འཕྲོས་ཏེ། །
བསམ་གཏན་ལྟ་བའི་དྲི་མ་སྔོན་རང་བཞིན། །
```

另一派则承许［行相］是三有的习气：一切行相都处于［应断的］违品之中；［而心本身是］无二、平等、不可思议、完全清净的。以悲心为本性、无相的圆满正等觉，两种色身从［这］根本中流出；［其］禅定、发心行持与过患，与前面的本性相同。

【按】对应《真如宝鬘》第十一至十三节中无相派的部分：无相派认为种种行相是习气所现的虚妄，只有无相的心是清净的；从无相的法身流出两种色身。"两种色身"，原文作 gzugs kyi sa gnyis（色之二地），sa（地）疑为 sku（身）之讹，这里依后者译出，存疑。"与前面的本性相同"（sngon rang bzhin），意思是与有相派相同，即把心执为实有便有近于"梵"的过患。

## 九、中观如幻派

```
མཐའ་བཞི་སྤངས་ནས་རང་གི་རིག་པ་ཙམ། །
ཆུ་ཟླ་སྒྱུ་མ་རྨི་ལམ་ལྟ་བུ་ཉིད། །
ལྟ་བ་འདི་ཡི་བསམ་གཏན་དེ་གསུངས་པའོ། །
རང་རིག་སྤངས་པའི་ཆད་པ་དྲི་མ་ཡིན། །
```

远离四边，只是自证，如水中月、如幻、如梦——这就是所说的这一见解的禅定；舍弃自证的断灭［之见］，是［它的］过患。

【按】对应《真如宝鬘》第十四节：如幻派离四边，以如幻的自证为禅定，以执著断灭为过患。本篇明说"舍弃自证的断灭"是过患，可以看出如幻派不舍自证。

## 十、中观无住派

```
འགྲོ་བ་གཞན་ནས་གཞན་དུ་གཞན་ཐོབ་འགྱུར། །
རྣམ་པ་ཐམས་ཅད་རང་བཞིན་དག་པ་སྟེ། །
འདི་ནི་དཔེ་མེད་རབ་ཏུ་མི་གནས་པའོ། །
བསམ་གཏན་ལྟ་བའི་དྲི་མ་མཐའ་དག་རིག །
རྣམ་པ་དེ་ཕྱིར་ཕ་རོལ་ཕྱིན་ཐེག་པའོ། །
```

众生从一处到另一处，获得另一［身］；［然而］一切行相，本性都是清净的——这就是无可比拟的"全然无住"。［对于它的］禅定、发心行持与过患，都要完全了知。以上这些［宗派］，就是波罗蜜多乘。

【按】对应《真如宝鬘》第十五节。第一句"'gro ba gzhan nas gzhan du gzhan thob 'gyur"，字面是"众生从他到他，得他"，意思不明。这里理解为：众生虽然在轮回中辗转流转，从一生到另一生，但一切行相本性清净，所以说"无住"；也可能是说众生的显现辗转不定、无所住著。这一理解只是推测，存疑。

最后一句"以上这些就是波罗蜜多乘"，总结前面从经部到中观的部分，下面转入密咒乘。

## 十一、密咒乘：大乐与和合

```
བདེ་བའི་རང་བཞིན་ཉམས་མྱོང་གསང་སྔགས་ཆེ། །
རྡོ་རྗེ་དང་ནི་མཚོ་སྐྱེས་སྦྱོར་བའི་སེམས། །
མཆོག་ཏུ་ཆགས་པའི་ཉི་ཟླ་ཡང་དག་སྦྱོར། །
སྙིང་རྗེའི་ཐབས་ཀྱི་སྟོབས་ཀྱིས་འགྲོ་བ་ཀུན། །
གདོད་མའི་བདེ་བ་དེར་ནི་དེ་བཞིན་ཉིད། །
གང་དུ་རོ་མཉམ་བྱང་ཆུབ་སེམས་རང་བཞིན། །
དེ་ནི་ལྷན་ཅིག་སྐྱེས་པའི་བདེ་བའོ། །
```

大密咒［乘］，是对大乐自性的体验：金刚与莲花和合之心，最胜贪爱的日月真实和合。以悲心方便的力量，一切众生在那本初的大乐中［就是］真如；在那味道平等、以菩提心为本性之处，那就是俱生的大乐。

【按】这一段是密咒乘的部分，对应《真如宝鬘》中作者说"不详说密咒，已在《灌顶决定开示》中说明"的部分。"金刚与莲花"（rdo rje dang mtsho skyes）、"日月"（nyi zla），在密续中是方便与智慧的象征；"最胜贪爱"（mchog tu chags pa），指转贪为道的大乐，与世俗的贪欲不同。"菩提心"在这里是密续的用语，有其特定的象征意义。"味道平等"（ro mnyam），即一切法同一味。

这些都是无上瑜伽续圆满次第的象征语言，所说的是方便与智慧、空性与大乐的双运，须依具德上师的灌顶与口授来理解，不可照字面理解，更不可自行揣度而行。

## 十二、空悲平等，俱生之相

```
དེ་ཚེ་གཉིས་ནི་སྔོན་དུ་དེར་ལྷུང་བ། །
གཞན་ཡང་སྟོང་དང་སྙིང་རྗེ་དེར་མཉམ་གྱུར། །
འགྲོ་ཀུན་ལྷན་ཅིག་སྐྱེས་པའི་རྣམ་པ་རུ། །
བླ་མ་མཆོག་གིས་བཀའ་སྩལ་ཇི་ལྟར་རྟོགས།
```

那时，二者首先落入其中；再者，空性与悲心在那里成为平等；一切众生［都显现］为俱生之相——这要如殊胜上师所教导的那样去证悟。

【按】"二者首先落入其中"（gnyis ni sngon du der lhung ba），"二者"可能指上文的方便与智慧（金刚与莲花、日月），"落入其中"即融入俱生大乐之中；原文简略，这里依上下文理解，存疑。末句"如殊胜上师所教导的那样去证悟"，与本组短论多处"依上师恩德证悟"的说法一致。

## 跋

《名为"道哈"的真如口诀》，圆满。阿瓦都帝巴所造，至尊陀利室利智译出。

【按】译者"陀利室利智"，原文作 dhi ri shrī dznyā na，梵文或为 Dhīriśrījñāna 或 Dhīraśrījñāna，生平不详。本篇是本组短论中少数不由金刚手参与翻译的作品之一。

## 通篇连读

敬礼吉祥嘿噜嘎！

三乘，是就各宗的立场而说的；毗婆沙宗有两派：下品与中品的声闻是西方毗婆沙师，上品声闻与缘觉则是迦湿弥罗毗婆沙师。

五蕴是毗婆沙宗共同的宗义，而不可说的补特伽罗，是西方两派所承许的；他们都乃至命终皈依三宝，以调伏自己为主的悲心特别多。

下乘行者修不净观、观肿胀的尸身，应当了知，把身体视为清净的心念是垢染；出息与入息是中品声闻的修法，它的过患是闭气入瓶的等持。

上品声闻的修法是四谛，具足支分的道是补特伽罗空性；苦谛是轮回，集谛是贪著，灭谛是涅槃，道谛是无漏的道。

缘取灭谛为常，便是过患；缘觉修自心的不可思议，这种等持有两种过患，即沉醉于乐与无心。

微细极微的积聚，是经部宗的观点；他们修不可思议，过患与前面相同；这一宗的发心行持就是六波罗蜜多，以悲心之力而作回向。

众生只是心，没有极微——瑜伽行宗认为一切如梦，青、黄等种种行相显现，都是心的自性；一切都是自证，这是有相派的禅定；把心视为常，是修习的过患。

另一派则承许行相是三有的习气，一切行相都处于应断的违品之中，而心本身是无二、平等、不可思议、完全清净的；以悲心为本性、无相的圆满正等觉，两种色身从这根本中流出；其禅定、发心行持与过患，与前面相同。

远离四边，只是自证，如水中月、如幻、如梦，这就是如幻派的禅定；舍弃自证的断灭之见，是它的过患。

众生从一处到另一处，获得另一身，然而一切行相本性都是清净的——这就是无可比拟的全然无住；对它的禅定、发心行持与过患，都要完全了知。以上这些宗派，就是波罗蜜多乘。

大密咒乘，是对大乐自性的体验：金刚与莲花和合之心，最胜贪爱的日月真实和合。以悲心方便的力量，一切众生在那本初的大乐中就是真如；在那味道平等、以菩提心为本性之处，那就是俱生的大乐。

那时，二者首先融入其中，空性与悲心在那里成为平等，一切众生都显现为俱生之相——这要如殊胜上师所教导的那样去证悟。

《名为"道哈"的真如口诀》，阿瓦都帝巴造，圆满。至尊陀利室利智译出。
