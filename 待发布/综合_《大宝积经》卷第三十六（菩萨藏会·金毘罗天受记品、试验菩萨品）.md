# 《大宝积经》卷第三十六（菩萨藏会·金毘罗天受记品、试验菩萨品）

唐·三藏法师玄奘 奉诏译

【按】译者题名，明本无“大”字。

## 菩萨藏会第十二之二

【按】本卷《金毘罗天受记品》相当于宋·法护等译《佛说大乘菩萨藏正法经》（T0316）的《无怖夜叉品》（卷五），《试验菩萨品》相当于该经的《菩萨观察品》（卷六）。

### 金毘罗天受记品第二

#### 金毘罗供佛

那时，世尊就在那半路上，不移动所在之处，令诸长者建立圣果。之后以如来的威势进入王舍城，四众围绕，容仪安详有序。那时有一位守护王舍城的诸天药叉大善神王，名叫金毘罗，这样想：“如今如来形相殊异，在世间中最为殊胜，难以遇见，堪受人天的供养。我们现在应当以种种上妙供具奉献如来。”这样想后，便以最殊胜的饮食，具足香味，成就妙色，奉献给佛。那时世尊怜悯他所奉献，为他纳受。那时金毘罗王所统领的大药叉众六万八千，在虚空中都生随喜，以清远之音唱言：“善哉！善哉！”那时金毘罗即以此义告诉部众说：“我已经奉献佛上妙供具，你们也应以种种供养施给苾刍僧，当令你们在长夜中得到利益安乐。”诸药叉众受了王的教命，即以上妙供品施给苾刍僧，那时诸僧众哀悯而接受其供养。

那时，世尊为了乞食而进入王舍城，得食之后将要回到住处。那时有无量千的天、龙、药叉、健达缚、阿素洛、揭路荼、紧捺洛、牟呼洛伽，以及无量千的人与非人，又有无量拘胝那庾多百千众生，随从在佛后面。那时如来前往一处最殊胜宽广的地方，如常敷座，坐在上面。那时金毘罗与其部众，即持种种天上的曼陀罗花、殟钵罗花、钵特摩花、拘贸陀花、奔荼利花，又持种种天上的栴檀末等供养之具，散在佛身上，就是胜散、大胜散，妙散、大妙散。这样殷勤散花之后，合掌在佛前礼敬而住。

#### 佛现微笑放光

那时，如来知道金毘罗及其大众心中所念，便现微笑。诸佛的常法是：现微笑时，从面门放出种种无量色的光，就是青、黄、赤、白、红色、银色以及水精色。其光遍照无量无边一切世界，日月的威光都被遮蔽而不现；向下照到地狱，令那里的众生悦乐，乃至向上涌到梵世；所应作的事作完之后又回来，右绕七匝，或在世尊顶上隐没，或从两肩、或从两膝隐没。诸佛的常法是：若为地狱众生授记时，光明从两足下隐没；若为畜生授记，光从背后隐没；若为鬼趣授记，从身前隐没；若为人道授记，从左胁隐没；若为天趣授记，从右胁隐没；若为声闻授记，从两膝隐没；若为独觉授记，从两肩隐没；若佛世尊为诸菩萨摩诃萨授阿耨多罗三藐三菩提记时，那时光明从顶上隐没。

【按】“上踊”之“踊”，元、明本作“涌”。

那时，长老阿难陀见到世尊微笑放光，以七条衣覆盖左肩，偏袒右肩，右膝着地，合掌礼足，以颂问道：

```
照世依怙者，何故放光明？
利益世间尊，何缘现微笑？
谁今下圣种，为佛菩提因？
今为谁授记？
谁应住解脱？
大雄猛导师，非无因而笑，
愿牟尼当说，现光之所为？
```
（大意：照耀世间的依怙者，为何放出光明？利益世间的尊者，以何因缘显现微笑？今天是谁种下圣种，作为佛菩提之因？今天为谁授记？谁应当安住于解脱？大雄猛的导师不会无因而笑，愿牟尼宣说，放光是为了什么？）

#### 佛为金毘罗授记

那时，世尊便以颂回答阿难说：

```
金毘罗净心，奉献诸供具，
救世依怙者，故现斯微笑。
舍神王报已，往三十三天，
受彼天福尽，上生焰摩天，
又生覩史多，受诸天欲乐，
福尽生人中，兴为智慧王，
王四洲人主，自在转轮帝。
舍后人王已，便生梵世天，
天上及人中，数往来不息，
二十拘胝劫，常感诸妙乐。
最后舍王位，出家求佛道，
众缘具足已，成究竟菩提。
```
（大意：金毘罗以清净之心奉献种种供具，所以救世依怙者显现这微笑。他舍弃神王之报后，往生三十三天；享受那里的天福尽了，上生焰摩天；又生覩史多天，享受诸天的欲乐；福尽之后生到人间，兴起为智慧之王，统领四洲，作人主，成为自在的转轮帝王。舍弃后来的人王之位后，便生到梵世天；在天上与人间屡屡往来不息，二十拘胝劫中常感受种种妙乐。最后舍弃王位，出家求佛道，众缘具足之后，成就究竟菩提。）

【按】“覩史多”之“多”，宋、元、明、宫本作“天”。

```
三万诸药叉，由奉养于佛，
便舍药叉报，生三十三天。
后见慈氏尊，复获阿罗汉，
既蒙授道化，即各供诸佛。
满千药叉众，为住大菩提，
由是善根故，不生诸恶趣。
或有千药叉，当供佛导师，
求无上菩提，利益众生故。
或有二三千，持香花鬘等，
当供养诸佛，为得佛菩提。
或有千拘胝，当供诸佛已，
修自体清净，后证入菩提。
```
（大意：三万药叉由于奉养佛，便舍弃药叉之报，往生三十三天；后来见到慈氏尊，又获得阿罗汉果；蒙受教化之后，各自供养诸佛。满一千的药叉众，为了安住于大菩提，由于这善根的缘故，不生于诸恶趣。或有一千药叉，将供养佛导师，求无上菩提，为了利益众生。或有二三千，手持香与花鬘等，将供养诸佛，为了得到佛菩提。或有一千拘胝，将在供养诸佛之后，修习自体清净，后来证入菩提。）

【按】“即各供诸佛”之“各”，宋、元、明、宫、圣本作“名”。“后证入菩提”之“入”，宋、元、明、宫本作“大”。

```
金毘子世罗，具大神通力，
亦发大愿心，我当成等觉。
曾供养诸佛，遍起于弘誓，
今复供养我，心趣无上道。
由此善根力，舍诸弊恶趣，
当见慈氏尊，又献拘胝盖，
献拘胝盖已，复献拘胝衣，
献拘胝衣已，尔时便出家。
具满五百岁，专修行梵行，
求最上菩提，利益众生故。
当成彼愿故，修行施戒等，
如殑伽沙劫，精勤常不断。
如是汝当知，为示现故说，
彼修行胜行，倍增过上数。
如前说譬喻，殑伽沙劫数，
得见彼诸佛，当修大供养。
```
（大意：金毘罗之子世罗，具有大神通力，也发大愿心：“我当成就等正觉。”他曾供养诸佛，普遍发起弘誓，如今又供养我，心趣向无上道。由这善根之力，舍离种种弊恶之趣，将见到慈氏尊，又献上一拘胝宝盖；献了一拘胝宝盖之后，又献一拘胝衣；献了一拘胝衣之后，那时便出家。整整五百年专修梵行，求最上菩提，为了利益众生。为了成就那愿，修行布施、持戒等，如殑伽沙数劫，精勤而常不间断。你应当知道，这是为了示现而说的，他所修的殊胜之行，倍增而超过上面所说的数目。如前面所说的譬喻，在殑伽沙数劫中，他将见到那些佛，当修广大供养。）

```
奇哉胜妙智，奇哉无上心，
诸众大导师，名所不能显。
后当成正觉，一切众生尊，
号名曰医王，普闻十方界。
七十拘胝岁，说法度众生，
其两足世尊，久当入寂灭。
二十大集会，调伏众生心，
最后一大会，经二百亿岁。
如所说大会，度无量声闻，
如声闻数量，菩萨众亦尔。
利益众生已，如来方涅槃，
正法住世间，经于百千岁。
满五百劫中，是苾刍成佛，
于彼一一劫，千如来出现。
```
（大意：奇哉！殊胜微妙之智；奇哉！无上之心；诸众的大导师，名号也不能显其功德。后来当成正觉，为一切众生之尊，名号叫作医王，普闻于十方世界。在七十拘胝年中说法度众生，这位两足世尊很久之后才入寂灭。有二十次大集会，调伏众生之心；最后一次大会，经历二百亿年。如所说的大会，度化无量声闻；如声闻的数量，菩萨众也是如此。利益众生之后，如来才入涅槃；正法住于世间，经过百千年。满五百劫中，这位苾刍成佛；在那每一劫中，有一千如来出现。）

```
诸有智慧者，当思法水灌，
应生勇猛心，行多闻正理。
远于非正理，常修正理法，
应修习多闻，由此慧增长。
四根本法义，济度诸菩萨，
施戒闻舍法，贤善菩提道。
为众说是法，最胜无上乘，
演布声闻道，善断诸疑网。
诸有请问者，我今悉开许，
能说深妙法，照世者难遇。
```
（大意：一切有智慧的人，应当思惟以法水灌溉，应生勇猛之心，修行多闻与正理；远离非正理，常修正理之法，应当修习多闻，由此智慧增长。四种根本法义，济度诸菩萨：布施、持戒、多闻、舍弃之法，是贤善的菩提之道。为大众宣说这法，是最胜的无上乘；也演布声闻之道，善断种种疑网。凡有请问的人，我现在都开许；能说深妙之法的照世者，是难以遇见的。）

#### 世罗庄严道路

那时，金毘罗之子世罗在佛前听闻佛为他授记，欢喜踊跃，得未曾有，这样想：“现在世尊将前往鹫峰山王，我应当再在如来之所种植少许善根。”这样想后，告诉他的部众说：“你们应当知道，如来将从王舍大城出发，登上鹫峰山；你们应当发勇猛心，随自己的能力备办种种供养。”

那时，这位世罗即与官属，从王舍城到鹫峰山之间的道路上，除去杂草污秽、砖瓦砾石、树桩毒刺，令其极为平净，如明镜之面；又以香水洒地，在道路中间铺满殊胜美妙的衣服，散布名花，堆积与人等高，焚烧美妙的坚香，沿路普遍熏香，排列竖立幢幡，悬挂种种宝盖，在虚空中张设缯彩，分条间隔，罗布其上。又作种种天上的音乐，前后充满。那条道路极为宽广，有一箭之远，全都遍覆着水生的种种花，就是殟钵罗花、钵特摩花、拘贸陀花、奔荼利花。又以鸳鸯等殊胜之鸟间错在花中，排列在道路两侧。在那道路上又以金缕缯彩铺设，上面再施以七宝所成的殊妙宝网，遍覆道路。

【按】“株杌”之“杌”，《大正藏》作“𣐎”，CBETA依碛砂藏作“杌”，今从之；元、明本作“机”。“幢旛”之“旛”，宫本作“幡”。

那时，这位世罗在佛所经由的道路上作了这样的大庄严之后，自己化现其身，令其极为美好高大，与诸官属欢喜踊跃，倍生欣庆，发起种种殊胜之心，就是：畅适心、调善心、柔软心、清净心、离盖心、充美心、归依佛心、归依法心、归依僧心、不动的菩提心、不退转心、无等心、无等等心、超过一切三界之心、对一切众生起大慈心、起大悲心、起大喜心、起大舍心、成为一切佛法之器的心、坚心、固心、不可坏心、不朽败心、舍离声闻独觉地之心、成立一切菩萨地之心。他安住于这样的种种殊胜之心后，前往如来之所，顶礼佛足，右绕三匝，退住一面，合掌向佛而说颂道：

```
我已为世依，办无上供养，
佛为世间尊，演最上法者。
十力皆成就，安住诸无畏，
利益众生事，如导师所作。
具相三十二，八十随形好，
世怙犹如日，流光遍于世。
转于妙法轮，最胜十二行，
宣布深妙法，利益群生故。
显示诸神变，如佛之仪式，
为多拘胝众，作诸利益事。
未来诸大雄，祐世间如日，
宣扬彼圣法，悟成无上智。
```
（大意：我已经为世间所依，备办了无上的供养；佛是世间之尊，是演说最上之法的人；十力都已成就，安住于种种无畏，利益众生之事，如导师所作。具足三十二相、八十随形好，世间依怙犹如太阳，流光遍照世间；转动微妙法轮，最殊胜的十二行相，宣布深妙之法，为了利益众生。显示种种神变，如佛的仪式，为众多拘胝众生作种种利益之事。未来的诸大雄，护佑世间如同太阳，宣扬那圣法，觉悟成就无上智。）

```
为舍为救拔，为道为归趣，
为诸生盲众，导之施慧眼。
五趣众生类，我当作依怙，
解脱诸苦聚，如先佛所离。
我为两足尊，天中天日月，
天帝那伽众，阿素洛奉敬。
所设诸供具，世无有等者，
我作上妙业，无有相似者。
如法主世尊，具足三十二，
上微妙福相，世无与等者。
```
（大意：作为庇护、作为救拔，作为道路、作为归趣，为种种生盲之众，引导他们，施予慧眼。对于五趣众生之类，我当作他们的依怙，令他们解脱诸苦之聚，如先佛所出离的那样。我将作两足尊、天中之天、日月，为天帝、那伽众、阿素洛所奉敬。我所设的种种供具，世间无与等者；我作的上妙之业，无有相似者；如法主世尊，具足三十二种上妙福相，世间无与等者。）

【按】“为道为归趣”之“为”，《大正藏》作“然”，CBETA依高丽藏作“为”，今从之。“如法主世尊”之“主”，明本作“王”。

那时，世尊为金毘罗之子世罗说颂道：

```
诸供大师者，为最上法因，
彼有情中胜，菩提不难得。
供养照世间，光性世依怙，
诸天龙及人，所应供养者。
悟上妙菩提，坐最胜道树，
摧伏诸恶魔，为众生说法。
```
（大意：凡供养大师的人，是最上之法的因，他在有情中最为殊胜，菩提不难证得。供养照耀世间、具光明之性的世间依怙者，是诸天、龙以及人所应供养的；他将觉悟上妙菩提，坐于最胜道树之下，摧伏诸恶魔，为众生说法。）

#### 佛往鹫峰山升座

那时，世尊与无量百千的天、龙、药叉、罗刹、健达缚、紧捺洛、牟呼洛伽、人与非人，又有无量百千那庾多拘胝众生等前后围绕，佛在其中居于众首。以如来的大威德、大神通、大宗势、种种自在的大变化，放大光明，震动大地，降下大莲花充满虚空，奏响百千那庾多拘胝的天上伎乐。那时大众赞叹从未有过，见到神变，倍加恭敬。那时如来的双足踏着大如车轮的莲花，沿着庄严的道路前往鹫峰山王。

到了那里，佛告诉长老阿难陀说：“你为如来敷设殊胜之座，就是最上之座、法座、微妙之座、胜过一切三界之座、尊胜之座、佛座、如来之座。我将坐在这里，为了利益一切众生，宣说大乘菩萨行所依的经典，名为《微妙吉祥大菩萨藏》。这部经能令一切众生的疑山崩塌，这部经能令一切众生的疑网断绝，这部经能令一切众生的疑根不生；这部大乘经是为了利益安乐众生，哀悯大众以及诸天与人，所以如来才为之开阐。”

那时，长老阿难陀如佛所教，敷设法座。那时众中有六十八拘胝天子，各自脱下上衣，为如来铺在法座上。佛在上面如常敷座，顾视诸天子而说颂道：

```
诸天敷衣服，最胜上微妙，
救世大导师，安处此法座。
到诸法彼岸，如来升座已，
大地六种动，令众皆欢喜。
放光照佛土，并耀诸山王，
世尊现神通，济度乐法者。
诸天龙及人，鸠槃荼饿鬼，
布怛那等众，互相见无障。
百千那庾多，拘胝诸天等，
覩佛放光明，此时甚难遇。
频毘娑罗王，诸大臣围绕，
来诣世依怙，最胜如来所。
佛知天龙人，大众皆坐已，
为利诸众生，顾视于四方。
告诸有疑者，当问两足尊，
我将导世间，善断诸疑网。
```
（大意：诸天铺敷最胜上妙的衣服，救世的大导师安处在这法座上。到达诸法彼岸的如来升座之后，大地六种震动，令大众都欢喜。放光照耀佛土，并照耀诸山王，世尊示现神通，济度喜乐正法的人。诸天、龙以及人、鸠槃荼、饿鬼、布怛那等众，互相看见而无障碍。百千那庾多拘胝的诸天等，见到佛放光明，这样的时刻极为难遇。频毘娑罗王被诸大臣围绕，来到世间依怙、最胜如来之所。佛知道天、龙、人等大众都已就座，为了利益众生，顾视四方：“告诉有疑问的人，应当来问两足尊，我将引导世间，善断种种疑网。”）

【按】“并耀”之“耀”，宋、元、明、宫本作“曜”。“频毘娑罗”之“娑”，《大正藏》作“婆”，今依CBETA作“娑”。

#### 召集大众

那时，三千大千世界所有众生，为了听法都来集会；听到如来这样说后，为了闻法，止息外缘，心住一境，摄念而住。那时世尊告诉长老大目揵连：“你现在应当知道，有哪位苾刍住在远处、还没有来到会座的，应当召他们来集会。”那时长老大迦叶住在大雪山南面，大目揵连忆念得知后，以神通力前往那里，对他说：“如来现在在鹫峰山，将在大众前为诸天、魔、梵、沙门、婆罗门、天人、阿素洛等宣说妙法，正在等待仁者，可与我一同前往，不要让我们对于听法有所障碍。”那时大迦叶对大目揵连说：“你先前往，我随后就到。”说了这话，那时大迦叶不起于座，以变化的神通力进入王舍城，带领四部众，引导大众而行，前往鹫峰山，顶礼佛足，在大众中佛前不远处坐下。那时大目揵连看到这变化后，以神通力来到佛所，才见到迦叶已先坐在座上。他对迦叶说：“尊者！您成就了迅速的大神通分，竟能不起本座而现出这样的神变。”大迦叶说：“世尊说你神通第一，我现在只是稍微显现，不值一提。”

【按】“速疾大神通分”之“分”，宋、元、明、宫本作“力”。

### 试验菩萨品第三

#### 舍利子请问

那时，长老舍利子即从座起，以郁多罗僧覆盖左肩，偏袒右肩，以右膝轮着地，向佛合掌恭敬而住，对佛说：“世尊！我现在想有少许请问，唯愿如来、应、正遍知哀悯听许，为我解说。”佛告诉长老舍利子说：“随你所问，如来现在当为你解说，令你心生欢喜。”

【按】“覆左肩上”，宋、宫本无“左”字。

舍利子对佛说：“世尊！菩萨摩诃萨成就几种法，身业无失、语业无失、意业无失？成就几种法，身业清净、语业清净、意业清净？成就几种法，身业不动、语业不动、意业不动，不被天魔以及魔军众所扰乱动摇，从初发一切智心修行正行，在一地一地中增胜善巧方便，为一切众生作殊胜的导师，作普遍的导师，作大照炬，作大阶梯，作桥、作船，作济度者，作到彼岸者，作庇护、作救护，作归依、作归趣，而能不舍一切智心？”那时舍利子想重宣此义，以颂问道：

```
菩萨何等义，能住大菩提？
何名德及法，由此悟无上？
又行何等行，利益诸众生？
修习何法已，成佛人中胜？
云何伏恶魔，住最胜菩提，
震动拘胝土，悟无上正觉？
菩萨者何义？
如是句云何？
云何为菩提，及无上佛法？
云何行世间，利益群生类，
不染如莲花，解脱拘胝众？
云何为天龙，非人等供养？
我诸所请问，慈悲愿为说。
```
（大意：菩萨以什么样的义理，能安住于大菩提？以什么名为德与法，由此觉悟无上？又行什么样的行，利益众生？修习什么法之后，成佛而为人中最胜？怎样降伏恶魔，安住于最胜菩提，震动拘胝国土，觉悟无上正觉？菩萨是什么意思？这样的句义是怎样的？什么是菩提，以及无上佛法？怎样行于世间，利益众生，如莲花般不受污染，解脱拘胝众生？怎样为天、龙、非人等所供养？我所请问的这些，愿您慈悲为我宣说。）

#### 一法：菩提心与信欲具足

那时，佛告诉长老舍利子：“善哉！善哉！我现在当为你分别解说。舍利子！菩萨摩诃萨成就一种法，便能摄受你所问之法，以及其余无量无边的佛法。是哪一法？就是菩提心以及具备信欲。舍利子！这名为菩萨摩诃萨成就一法，便能摄受无边佛法。”

舍利子对佛说：“世尊！什么名为信欲具足？又以什么义名为菩提心？”

佛告诉舍利子：“信欲具足，是说坚实而不可破坏；是说牢固而不可动摇。说不动，是因为没有蹶失；没有蹶失，是因为能善安住；能善安住，是因为不退转；不退转，是因为观察众生；观察众生，是因为以大悲为根本；以大悲为根本，是因为不疲倦；不疲倦，是因为成熟众生；成熟众生，是因为善知自己的喜乐；善知自己的喜乐，是因为无所希望；无所希望，是因为不染著资具；不染著资具，是因为作众生的依靠；作众生的依靠，是因为顾念下劣的众生；顾念下劣的众生，是为了救济；为了救济，是为了作他们的归趣；作归趣，是因为不卒暴；不卒暴，是因为善于观察；善于观察，是因为没有怨嫌；没有怨嫌，是因为善于调伏信欲；善于调伏信欲，是因为无所存留；无所存留，是因为善能清净；善能清净，是因为美妙鲜白；美妙鲜白，是因为内离垢染；内离垢染，是因为外善清净。舍利子！像这样坚实难坏，乃至内离垢染、外善清净，这名为信欲具足。”

佛又告诉舍利子：“菩提心是什么相、什么貌？舍利子！菩提心没有过失，因为不被一切烦恼所染。菩提心相续不绝，因为不是其余诸乘中所证得的。菩提心坚固难动，因为不被异论所牵夺。菩提心不可破坏，因为一切天魔都不能令其倾败。菩提心常恒不变，因为是善根资粮所积集的。菩提心不可摇动，因为必能独证诸佛之法。菩提心美妙善住，因为善能安住于菩萨地。菩提心没有间断，因为不被其余诸法所对治。菩提心譬如金刚，因为善能穿彻佛的甚深之法。菩提心殊胜善妙而平等，因为对于众生的种种欲解无不平等。菩提心最胜清净，因为其性不染。菩提心没有尘垢，因为发明智慧。菩提心宽博无碍，因为含受一切众生之性。菩提心广大无边，因为如同虚空。菩提心没有障碍，因为令无碍智遍行于一切，无缘大悲不断绝。菩提心应当亲近，因为为诸智者所称赞。菩提心犹如种子，因为能生一切诸佛之法。菩提心能够建立，因为建立一切喜乐之事。菩提心发生种种愿，因为戒清净。菩提心难以摧灭，因为安住于忍辱。菩提心不可制伏，因为正勤。菩提心最极寂静，因为依于一切大静虑。菩提心无所匮乏，因为智慧资粮善加圆满。

“再者，舍利子！菩提心就是如来的尸罗蕴、三摩地蕴、般罗若蕴、解脱蕴、解脱智见蕴的根本；又，菩提心就是如来十力、四无所畏、十八不共佛法的根本。”

【按】“难可摧灭”之“灭”，《大正藏》作“减”，今依CBETA作“灭”。“十八不共佛法”，宋、宫本作“十八佛不共佛法”。

舍利子说：“所谓菩提心，是说此心以菩提为其生起之体，所以名为菩提心。”

佛说：“是这样，舍利子！诸菩萨摩诃萨因为成就信欲与菩提心，所以名为菩提萨埵，名为广大萨埵，名为极妙萨埵，名为胜出一切三界的萨埵，名为身业无失、语业无失、意业无失，名为身业清净、语业清净、意业清净，名为身业无动、语业无动、意业无动。菩萨摩诃萨因为具足这样的诸业清净，不被天魔以及魔军众所扰乱动摇，从初发一切智心修行正行，在一地一地中增胜善巧方便，不被一切世间法所动摇，能为众生作大导师，作殊胜导师，作普遍导师，作大照炬，作大阶梯，作桥、作船，作济度者，作到彼岸者，作庇护、作救护，作归依、作归趣。舍利子！菩萨摩诃萨这样发一切智心，所以魔与魔军不能使其倾动。”

【按】“不为一切世法所动”之“动”，元、明、圣本作“染”。

#### 信欲具足者的行持

那时，佛告诉舍利子：“诸菩萨摩诃萨由于具足这样清净的信欲，发阿耨多罗三藐三菩提心之后，心多净信，乐于见到贤圣，乐于听闻正法，乐于不悭吝，舒展心手而行大布施，欣乐大舍，乐于平均普施。对于众生，心无罣碍，心无秽浊，心无愦乱，心不间杂；对于业与业报深心奉敬，无疑无虑，知道黑白之法的果报不会坏失，乃至遇到命难也不起诸恶，永离杀生、不与取、邪淫行、妄语、乖离语、粗恶语、绮语、贪染、瞋恚、愚痴邪见。为了断除这样的不善业道，受持奉行十善业道。

“由于具足信心，对于那些沙门或婆罗门——他们正至、正行，具德具戒，其心纯净，成就调顺之法，具足多闻，勤于请问，修正作意，调善寂静，亲近寂灭，不起诤讼，不说不爱之语，善知信欲而不是不善知，与善法相应，远离诸恶法，不掉举、不高慢，其性远离躁动，其性远离粗言，言语没有浮杂，守护正念而住，心安于妙定，善断有的根本，不中毒箭，舍离重担，超度疑虑——以及后来的诸佛世尊、菩萨摩诃萨、声闻、独觉，对于这样的善知识，如实觉知之后，便亲近觐见，敬仰奉事，将护承迎。

“行者这样以身行奉事善知识，又以法施摄受他人，宣说妙法，开示教导，赞叹令喜，就是：若行柁那，得大财富；若行尸罗，得生天之乐；若好多闻，获得大慧；若修诸定，便离系缚。又为他们开显种种微妙清净的殊胜之法：这是布施，这是布施之报；这是悭吝，这是悭吝之报；这是尸罗，这是尸罗之报；这是犯戒，这是犯戒之报；这是忍辱，这是忍辱之报；这是瞋恚，这是瞋恚之报；这是正勤，这是正勤之报；这是懈怠，这是懈怠之报；这是静虑，这是静虑之报；这是乱心，这是乱心之报；这是智慧，这是智慧之报；这是恶慧，这是恶慧之报；这是身妙行，这是身妙行之报；这是身恶行，这是身恶行之报；这是语妙行，这是语妙行之报；这是语恶行，这是语恶行之报；这是意妙行，这是意妙行之报；这是意恶行，这是意恶行之报；这是善，这是不善；这应当作，这不应当作；这若作了，会感得长夜的义利安乐；这若作了，会感得长夜非义、非利、非安乐之果。

【按】“柁那”即布施（dāna），“尸罗”即戒（śīla）。

#### 为法器者开示空与缘起

“舍利子！行者这样为诸善友宣说此法、开示教导赞叹令喜之后，觉知谁堪为大法器，便为他开示甚深微妙的空相应之法，就是空法、无相法、无愿法、无行法、无生法、无起法、无我法、无数取法、无寿命法、无众生法。又为他开示甚深的缘起，就是：此有故彼有，此生故彼生；无明缘行，行缘识，识缘名色，名色缘六处，六处缘触，触缘受，受缘爱，爱缘取，取缘有，有缘生，生缘老死、愁、叹、忧、苦、身心焦恼，这样种种生起纯大苦聚。又，此无故彼无，此灭故彼灭；就是无明灭故行灭，行灭故识灭，乃至生灭故老死灭，这样乃至纯大苦聚灭。

“舍利子！又应当为他说：这其中没有一法是有、可得而可灭的。为什么？因为那些法从因缘而生，没有主宰，没有作者，没有受者，随因缘而转；又没有一法流转、旋还，也没有随转。由于痴妄而假立三界，随烦恼与苦而流转，只是假施设。行者这样如实观察痴妄之时，没有一法能作其余的法；若在其中没有作者，因为作者不可得，乃至没有一法流转旋还，因为流转旋还不可得。舍利子！行者若听闻这样的甚深之法，无疑无虑，善入诸法无罣碍之性，此人便不执著于色，不执著于受、想、行、识，不执著于眼、色以及眼识，不执著于耳、鼻、舌、身、意、法以及意识，因为都不可得。

#### 出家多闻与不放逸

“再者，舍利子！菩萨摩诃萨信受这样的性空之法后，不退失见佛，不退失闻法，不退失奉事僧，在在处处所生之处，不离见佛，不离闻法，不离奉事僧，当面生在佛前，猛励正勤，志求善法。此人安住于正勤后，不贪恋居家、男女眷属、奴婢仆使以及种种资具；此人不被淫欲所扰，迅速在今生舍弃盛年之乐，以清净信心在佛法中出家入道。出家之后，得到善知识、善伴、善友，善住于思惟，善住于信欲。由于善住于信欲，好好听闻正法，坚固奉行，不只以言说为宗极，觉慧成就，乐求多闻，无有厌足。如所听闻的法，以无染之心为他人广为演说，对于利养、恭敬、名誉，心无希望，不舍正义而妄为他人宣说，如其所闻、如其所住而为人说法。对于听法之众生起大慈心，对于一切众生生起大悲心。

“舍利子！行者这样因为多闻，不顾身命，少欲知足，欣乐寂静，易满易养，乐处空闲，如所听闻的法观察其义，依于实义，不依于文字；为诸天、人、阿素洛界所依止；不专为自己，而为众生求于大乘，就是佛智、无等智、无等等智、胜出一切三界之智。舍利子！我说此人获得了第一的不放逸法。

【按】“面生佛前”之“面”，宋、元、明本作“而”。

“舍利子！什么名为不放逸法？就是诸根寂静。什么是诸根寂静？就是眼见到色，不取其相貌，如实觉知色的味著、色的过患以及色的出离；这样，耳所闻的声、鼻所嗅的香、舌所尝的味、身所觉的触、意所识的法，都不取其相貌，如实觉知法的味著、法的过患以及法的出离。舍利子！这样名为心不放逸。再者，不放逸，就是调伏自心，善护他心，除去对烦恼的喜乐，趣向于喜乐正法，不行欲觉、恚觉、害觉，不行贪不善根、瞋不善根、痴不善根，不行身恶行、语恶行、意恶行，不行不如理作意，不行一切恶不善法，这就名为不放逸。

#### 如理作意知有知无

“这样，舍利子！诸菩萨摩诃萨既不放逸，便能勤修如理作意：若法是有，如实知有；若法是无，如实知无。观察这其中什么是有，什么是无，即以智慧之力如实了知。正修习者，圣解脱是有；邪修习者，圣解脱是无。无业报者，这是有；有业报者，这是无。再者，眼是有，有眼者是无；耳、鼻、舌、身、意，意是有，有意者是无。再者，色是无常、苦、变异之法，这是有；色是常住、不变、不坏，这是无。受、想、行、识是无常、苦、变异之法，这是有；受、想、行、识是常住、不变、不坏，这是无。再者，以无明为缘，诸行便有；若无无明，诸行便无；乃至以生为缘，老死便有；若无生，老死也无。再者，布施感得大财富，这是有；布施感得贫穷，这是无。持戒生天，这是有；犯戒生天，这是无。多闻生大慧，这是有；诸恶慧者能生大慧，这是无。修定离系缚，这是有；修定而系缚，这是无。再者，若说如理作意而有系缚、不如理作意而离系缚，这两者都是无。若诸菩萨发起正勤，菩提便有；若起懒惰，菩提便无。若无憍慢，出家授记，这名为有；若是憍慢者，寂灭便无。再者，遍一切处的空性是有；遍一切处有我、数取、众生、寿命、丈夫等类，这是无。

原文：“无业报者此则是有，有业报者此则是无”（大意：无业报者，这是有；有业报者，这是无。与下文“眼为是有，有眼者无”同一句式，所指未详，存疑。）

“这样，舍利子！若诸菩萨摩诃萨行不放逸，能善修习如理作意，对于世间智者共同知道是有的，便施设为有；世间智者共同知道是无的，便施设为无。舍利子！若决定说有，不是正确了知；若决定说无，这也名为不是正确了知。为什么？因为诸佛世尊所说的真实义，能随之而觉了。

#### 四邬柁南

“舍利子！诸佛世尊具有大智力，总摄诸法，安处于四种邬柁南中。是哪四种？就是一切行无常，一切行苦，一切法无我，涅槃寂灭。舍利子！所演说的一切行无常，是如来为了那些有常想的众生断除常想。所演说的一切行苦，是如来为了那些有乐想的众生断除乐想。所演说的一切法无我，是如来为了那些有我想的众生断除我想。所演说的寂灭涅槃，是如来为了那些住于有所得颠倒的众生断除有所得颠倒之心。

“舍利子！这些菩萨摩诃萨若听闻如来说一切行是无常，便能善入毕竟无常；若听闻说一切行苦，便能兴起厌离，生起离愿之心；若听闻说诸法无我，便能修习三摩地的妙解脱门；若听闻说寂灭涅槃，便能修习无相三摩地，而不在不适当的时候趣入真际。这样，舍利子！若诸菩萨摩诃萨能善修习这样的法，终不退失一切善法，迅速能圆满一切佛法。”

【按】“邬柁南”即优陀那（udāna），此处指法印。
