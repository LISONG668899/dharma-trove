# 《月灯三昧经》卷第九

高齐天竺三藏那连提耶舍汉译　白话今译

## 一、世尊自述：勇健得王即是我身

这时，世尊就说偈道：

我在往昔修行的时候，曾作国王，名号叫勇健得。那时有一座城名叫珍宝，那位国王出城前往园林。

他乘驾宝车，遇到一位比丘，端正殊特，非常微妙，以三十二相庄严，光明普照于十方。

善花月的名字遍于各个地域，他安住于慈悲，能利益众生；为了救度众生而入城，功德与威势极其端严。

我那时的容貌比不上他，于是生起增上的妒嫉之心，被爱欲与耽乐荒迷所缠结，恐怕那位比丘夺取我的王位。

往昔我有一千个儿子作为眷属，乘驾宝车跟随在我后面，以种种宝冠庄严自身，走起路来如同忉利天的诸天子。

在那些儿子中有五百人，都穿着美妙宝饰的摩尼鞋，以宝冠、璎珞庄严自身，金网遍覆在车上。

宫女与眷属有八万人，一切都端妙美丽，登上宝舆，见到比丘端正犹如须弥山。

她们见到他都生起如同父亲之想，各自发起无上菩提心，从他那里受持清净梵行，脱下殊胜的璎珞散在比丘身上。

我随即生起极大的嫉妒之意，便生起嗔怒浑浊之心，被豪富迷惑扰乱，命令儿子们说：“可以杀掉站在我面前的这个比丘。”

儿子们听到父亲的命令之后，深怀忧恼，禀白父亲说：“愿大王不要说这样的话，我们终究不能杀这个人。

“即使有人割截我们的身体，经过恒河沙数多亿劫，我们也终究不能杀这位法师，因为我们是从他那里发起道心的缘故。

“我们在那位尊者那里发起这样的心：愿我们成佛，成为人中最殊胜者；趣向菩提的人不作恶事，我们都是佛日之子。”

国王听到儿子们这样说，就命令奴仆去召唤旃陀罗：“快叫刽子手来杀这比丘，就是站在我宫人面前的那个。”

随即把杀人者带来，名叫难提，极其暴恶，手执利刀，照着国王的旨意惩治，把这位比丘截成八段。

比丘被斩时身上没有流血，割处流出千种光明，也有功德吉祥之轮的纹相，在肉里炳然显现。

造作了这极重的恶业之后，我那时为了嬉戏前往园林，一切歌舞都不能使我快乐，因为思念花月法师的缘故。

那时我匆忙离开那园林，回到珍宝城中，于是乘车前往他那里，来到割截比丘的地方。

当时在空中听到悲恶的声音，无量那由他天人号叫，都说：“恶王造了重业，死后将堕阿鼻地狱，受极大的苦。”

国王那时听到诸天的声音，心怀忧恼，大为怖畏，说：“我犯下了无量的重罪过失，因为杀害了善花比丘的缘故。

“如来具足无量的智慧，他是如来最殊胜的真佛子，诸根调柔，心中寂灭，我却因为爱欲的缘故杀了他；

“如果有人能受持如来之法，在正法宝藏灭坏的时候，能在世间点燃智慧之灯，我却为了贪欲的缘故杀了这个人；

“他在一切世间作大医王，疗治众生的烦恼之病，又以甘露使之流布，我却为了爱欲的缘故杀了他；

“他受持导师殊胜的法藏，为黑暗中的众生作明灯，是受持陀罗尼的法王之子，我却为了贪欲的缘故杀了他；

“他为世间演说殊胜微妙之法，甚深微细，难以得见，显说趣向道场之路，我却为了爱欲的缘故杀了这个人。

“他的智慧清净，没有秽杂，凝静寂灭，恒常在定中，我被爱欲所盲而杀了他；贪欲是苦的因，应当舍弃。

“过去、未来所有的佛，以及现在的人中至尊，功德无量如同大海，我一切都合掌归命于他们。

“我死后将趣向恶道，入于阿鼻地狱，在那里没有能救护我的人；这不可爱的果报之业，既然是我自己造作的，正是由于杀害了殊胜的法师。

“咄哉！恶心造作苦业。咄哉！依恃王位而自我傲慢。这里究竟没有坚实可靠之物，终当舍弃一切而独自离去。

“他从来没有欲染，修习清净之业，有悲心，说爱语，是真正的佛子；他独为世间的亲人，远离一切过失，我的善花月如今去了哪里？

“呜呼！圣者具足忍辱之财。呜呼！妙色与功德相应。他没有谄曲与戏论，是功德之聚，您如今舍我而去了哪里？

“我现在才明白大仙所说的话：世间被贪欲所破坏，身心热恼，是恶道之因；这样了知之后，我要舍弃贪欲之行。

“我死后将趣向恶道，入于地狱之中，没有能救济我的人，因为造作了极重的恶业，正是由于杀害了那位比丘的缘故。

“我要舍弃这令人怖畏、疲劳的王位之处，奉持禁戒，修行梵行；我现在要为那位自在者，以欢喜清净之心建造大塔，

“为了供养那位没有热恼的智者、智慧的宝藏、具有惭愧的人，愿我不堕三恶趣，也远离恶名和讥毁。”

国王当时向妃后、宫人、诸亲戚、最殊胜的辅相以及僮仆、刹帝利、长者以及诸官员哀泣着说：

“你们为我迅速备办种种殊胜美妙的香木、名贵的衣服、上等的服饰以及酥油，准备用来火化这位比丘的身体。

“你们现在迅速在这里积集一切殊胜美妙的种种香柴、应时的栴檀与沉香汁、苏卑力迦香以及龙脑，以百千件衣服涂上酥油，全部缠裹那位尊者的身体。我要以增上的信心与敬重之心，以种种供具来供养。”

第一辅相与城中的人民听到大王的命令之后，以种种香油涂抹香木，以种种殊胜美妙的香末、种种末香水为法师的身体洗浴，又用种种香涂在他的身上，以涂了酥油的衣服缠裹他的身体，放置在香木堆上。

那位往昔牟尼尊者（法师）的妙身，火化后得到舍利三斛六斗；那位国王建造殊胜美妙的宝塔，以种种供养恒常礼拜。

以涂香、末香、香鬘、百种赞颂，悬挂种种美妙的铃铛以及幡盖；妃后、宫人以及子孙，从城中出来前往那里。

国王每天三次供养，然后才从塔所回去；以殊胜美妙的花鬘供养，以宝幢幡盖庄严。

正是因为愚痴而造作了种种罪业，他在那塔所全部忏悔，经过九十五亿年，恒常忏悔而不疲倦。

他为智慧所摄持，殊胜清净，坚持禁戒而没有缺漏，日夜长时受持八关斋戒，清净护持而不毁犯。

## 二、业果不失：忏悔后仍受余报

国王被爱欲所缠蔽，自身造作了不善业，身坏命终之后堕入地狱，在极苦的阿鼻地狱之中。

从那以后，他没有值遇九十五亿尊如来；在那九十五亿劫中，在那么多的世代中常常生而目盲；

在六十二亿那由他劫中，即使得到眼根也又坏失；又在一亿那由他生中，即使得到眼睛也还会失去，

也常常被截断手足，以及耳、鼻、唇、舌等；在人中经过亿那由他劫，在其他受生之处也是如此。

那位国王造作了无量的恶业，在一切世间恒常受苦；如果有人想要得到安乐，想到这一点就不要造作哪怕少许的恶业。

```
其王虽复忏先罪　而不得免昔所作
造斯如是恶业已　死后当堕阿鼻狱
```

大意是：那位国王虽然忏悔了先前的罪业，却仍不能免除往昔所作之业的果报；造作了这样的恶业之后，死后仍当堕入阿鼻地狱。

【按】这首偈对修行人是严肃的提醒：忏悔有大力，但重业仍有余报，业果丝毫不爽。本经说空最彻底，说业果也最严格，两者从不分开。冈波巴大师教导弟子“见地虽高如虚空，取舍因果细如粉”，在经中正有这样的依据。

他被斩截身体、头颅以及四肢，也被割耳、劓鼻、挖去双目，次数不可计算，在无量亿劫中都是因为贪欲的缘故。

在广造恶业的果报酬偿完毕之后，后来他自己剜身布施他人，也就是施舍头颅以及手足，舍弃王位以及儿子，为了求取菩提。

所爱的妻子、众多的财产、宫人、婇女、象、马等，车乘、船舫、种种美妙的珍宝，在无量亿生中都为求道而布施。

```
勇健得王我身是　彼昔千子贤劫佛
莲花上佛花月是　魁脍即是寂王佛
```

大意是：那位勇健得王就是我（释迦牟尼佛）的前身；他往昔的一千个儿子就是贤劫千佛；善花月法师就是莲花上佛；那位刽子手就是寂王佛。

【按】世尊以本生自陈：杀害法师的恶王正是自己的前身。佛陀并不讳言往昔的重罪，而以此说明业报的真实与忏悔、发心的力量：造重罪者经长劫受报之后，仍能转而行菩提道、终成佛果。连刽子手也终成为佛，这正显示佛性无人不具。

宫人、妃后以及城中人民、亲戚、知友以及仆役、殊胜的刹帝利与城主，那么多的人都是我的眷属。

如果有人对那位法师持守禁戒，以信敬之心供养他，一切都般涅槃了，因为以善心的缘故证得菩提。

童子！我往昔在无量劫中，得见离垢无恼佛，修行殊胜上妙的菩提之行，往昔尚且承受这样的苦。

如果有菩萨安住于总持，善修慈心之行，安稳不动，他终究不会堕入种种恶处，能供养离垢无恼佛。

如果想要成佛作法王，以三十二相庄严，应当护持戒律而没有秽染动摇，说法不断，安住于总持。

## 三、安住戒聚，于一切菩萨起师想

“所以，童子！如果菩萨这样想：‘我现在要怎样才能安乐地证得无上正等正觉呢？’那些菩萨应当安住于清净的戒聚，对一切菩萨生起老师之想。”

这时，世尊说偈道：

如果有菩萨安住于戒聚，以利益之心修行菩提，这个人迅速前往可乐的佛刹，能获得上妙之忍而成为法王。

所以心中和顺，安稳不动，恒常造作可爱之业，然后得见许多佛日，迅速得到菩提，远离疑网。

听闻我这最殊胜的教导，见到诸比丘持守清净戒律，以没有谄曲之心奉事他们，然后不久就能得到此定。

如果以恒河沙数的种种伏藏，全部以七宝充满其中，那些宝藏极其广大，犹如无量恒河沙数的佛刹；

如果有菩萨乐于惠施，日夜常常不间断，勇猛布施而不暂停，经过无量恒河沙劫；

如果有人听闻这个三昧，就是受持了一切牟尼的宝藏，这是无量的福德之聚，超过前面的布施，难以思议。

这样的福德广大无边，能使世间之苦灭除，这是最上的功德之聚，与布施的福德相比，广大难以测量。

这是随顺菩提的第一宝藏，有智慧的菩萨能够受持；如果有人受持这个三昧，就称为具有大财富的殊胜菩萨。

这是佛法的多闻之海，这个人的福德难以穷尽边际；对于这殊胜微妙、难以思议之法，他就称为菩萨中真正的护持者。

如果有人能宣说这寂灭之定，这个人的菩提就会增长；除了世间导师调御士、具足大悲与自然智者之外，

他能获得无量的种种功德，福德成就而愈加增上，在三千大千世界中，没有能与他相比的；

其余人的福德没有能与他相等的，智者所赞叹的智慧也是如此；如果有人听闻这个三昧，能够受持而读诵，为了求取诸佛殊胜的菩提，这样的人才能与他相等。

他出生的多闻犹如大海，这个人的福德不可测量；受持、读诵这个三昧，就是这样的人所摄持的福德。

童子！如果福德是有形色的东西，一切世界都容纳不下。

所以，童子！菩萨如果想要供养一切佛，过去、现在、未来的清净者，就应当受持这个三昧。

这是诸佛殊胜的菩提，童子！你应当相信我的话；如来所说的没有差异，我们诸佛所说的话不虚妄。

往昔在难以思议的百劫之中，我为了这个缘故而使身体枯竭，常修最妙的菩提之行，为了求取这殊胜之定。

所以你应当领受这法藏，那由他部经典都从这里出生；这福德之聚广大不可思议，因为能获得诸佛的智慧。

一切众经以此为首，出生无量的种种善业；恒常无畏地宣说这部经，那法的边际不可得。

## 四、法师的无尽辩才与不动

把三千大千世界碾碎成微尘，或许还能知道微尘的数目；而法师常说难思的百千部经，却没有人能测量。

这佛刹中一切众生的出入气息尚且可以知道；而菩萨常常所演说的经，却没有人能知道它的边际。

如果佛刹国土多如恒河沙，其中六道的众生，有人能测量他们心念的数目，也没有人能知道法师所说的经；

无量亿数的世界佛刹，那些世界中大海、河流、池塘的沙，这些沙数可以计算得知，却没有人能知道法师所说的法；

把一根毫毛的末端分析为百分，用它来滴取多亿佛刹中所有一切的水聚，可以数得清滴数，法师的言音却不可知；

过去无量亿劫中所有的一切众生，他们身体的微尘数尚且可以计算，却不能知道法师所说的经；

十方一切众生的音声可以计算得知，而法师所演说的不断绝，不能知道他的修多罗有多少。

他对于言词句义已经善学，又能演说一切法，具有广大敏捷锐利的智慧，了知真实之法以及问答。

他的智慧通达深广的义理，应当常常了知心是不可思议的，完全了知音声的自体性，所以言说毫无挂碍。

【按】法师辩才无尽的根源，经中说是“应常知心不思议，悉知音声自体性”：了知心不可思议、音声无自性，言说才能无碍。这与第五卷“陀罗尼即是智慧，能知一切诸法但有名字”同一意趣。

他称为无碍的大法师，为世间说法而无所执著，问答与解释已经善加修习，因为了达第一义谛的缘故。

在一句之中有亿种论释，不可思议地宣说而毫无滞著；修学无碍的句义，在大众中演说而毫无壅滞。

如果有人常住于这个三昧，就成就无畏而不动转，已经得到法的力量，修行殊胜之行，能利益无量亿众生。

犹如须弥山安稳不动，一切猛风都不能摧坏；法师比丘也是如此，一切论议都不能使他改变。

三千大千世界中所有的诸山等，一切风吹或许都会动摇，比丘安住于空性却没有什么能使他动摇。

```
若能与空恒相应　是佛决定所住处
若人定知诸法空　一切异论无能胜
```

大意是：如果能与空性恒常相应，这就是佛决定所安住之处；如果有人决定了知诸法皆空，一切异论都不能胜过他。

【按】“与空恒相应”是安住，“定知诸法空”是决定。前者是修，后者是见。大手印讲“见决定、修相续”，在这两句中都有了。

其余一切邪说都不能使他倾动，一切外道的论议都不能破坏他，没有人能侵凌毁蔑他，因为他宣说这寂定的缘故；

这个人穷尽了空性之法，恒常安住于无量的智慧，对于一切法没有疑惑，因为受持这最殊胜的三昧的缘故；

诸力、道品得到都不难，神足、无碍辩才等，以及获得殊胜的神通也是如此，因为受持读诵这部经的缘故；

在此处死、在彼处生不是难事，能见到最殊胜的无量智者，不可思议亿那由他的佛，受持此经的人都能见到。

在这一切诸佛那里，得以听闻这离垢之定，成就最殊胜的相应之智，能到达四种辩才的彼岸。

在一切三千大千世界中，从最下际直到有顶天，以诸天可爱发光的摩尼宝以及七宝全部充满；

在十方无量诸佛刹中，从下方大地直到有顶天，以阎浮提金全部充满，全部以这些珍宝奉献给牟尼；

以一切世间所有的珍宝，经过无量劫用来布施，奉献给如来，恒常不绝，以深信之心为了求取菩提；

如果有比丘爱乐空性，一念之间合掌礼佛，与前面广大布施的福德之聚相比，布施之福还不及其迦罗分之一（极微小的一分）。

如果有人得到那广大众多的财物，以信心为了福德而行布施，为了求取无与伦比的佛菩提，我了知世间，已经作了比较衡量；

如果有人对于这个三昧，听闻之后受持一首四句偈，这个人所积集的功德，前面的福德百分之一都不及。

最殊胜的菩萨行布施，尚且未能迅速得到无上之道；如果有人听闻这殊胜的宝定，他就能迅速得到无上菩提。

假使得到珍宝之藏，遍满无量恒河沙数佛刹，种种宝物都充满其中，菩萨也不认为是富足；

如果断除渴爱，修习功德，又能得到这个三昧，便具足一切资生之物，库藏盈满，具备大财。

假使获得四天下，智者对此也不欢喜；如果得到这样的离垢之定，就欢喜踊跃，利益众生。

## 五、弥勒菩萨赞叹此三昧

这时，弥勒菩萨摩诃萨披上铠甲，便赞叹这个三昧的利益，也为了使未来的菩萨受持读诵时得到欢喜的缘故，助其势力而说偈道：

那些能受持智者之法、具有功德威势的救护者，也能在诸佛那里受持广大殊胜微妙的法眼。

在末世恶时，众生多有贪、嗔，舍弃不放逸而常常放逸；这部具足真实义理的殊胜经典，有谁能够受持呢？

那些具有戒、定、忍辱、多闻之财，善学威仪而作庄严，爱乐法与智慧的解脱之树，能披上惭愧这殊胜上妙之衣，

持有大智慧，乐于出离的人，就是大地上的法山之王；他们观察到世间没有导师，就为众生趣向佛的菩提。

那些调伏自心、心已寂灭的人，这样的人趣向一切智；他们使不调伏的众生得到调伏，是一切智者最殊胜的儿子。

自己证得解脱，也使他人到达解脱，从贪爱的枝条中得到脱离；对于那些常常放逸、沉睡的众生，便能使他们得到觉悟。

那些恒常乐于善加调伏，也常常喜乐于法施，不与一切嫉妒共处，喜好行惠施而没有吝惜，

见到那些被逼迫的贫穷众生，常使他们的资生之具充足，这是圆满功德的第一道路，智者一切时中恒常修习。

那些以欢喜之心擂击殊胜美妙大法鼓的人，断除疑网，解说妙法，智慧坚固如同金刚，

安住于殊胜的圣法而处在大众之中，能了知众生心中的乐欲，演说最上的甘露之法，也就是殊胜扼要的修多罗。

那些自己安住于殊胜神通的人，能施给世间最殊胜的眼目，遣除愚痴的黑暗犹如太阳，能出生智慧也如同矿藏，

显示真实，除去怖畏，以增上的智慧修习禅定；他们宣说最微妙、微细之法，这称为寂灭殊胜的出离。

那些闻持而为智者所敬重的人，建立信解义理的增上福德，能了知世间殊胜的法藏，恒常宣说美妙的言语，

以善巧的言语通达仪则，是法之明灯所依止的；常以善心利益众生，修行最上微妙之法。

他们安住于法道，远离尘染，以及滋润增益寂静的信心，以法教化一切世间，得以成为最殊胜的大法王，

能成为无上的法中之尊，安住于第一上妙的恭敬，恒常护持微妙的正觉，随顺而转动殊胜的法轮。

那些愚痴而放纵自己的人，见到这样恶劣的众生，见他们心中惑乱，趣向险道，临近恶趣之门，难以越度，

他们就生起大慈悲的清净之心，生起之后能除去世间之苦，演说最殊胜微妙之道，也就是那八正道的殊胜之路。

这就是那法的广大坚固，造作无上殊胜的法船，能在生死烦恼的大海中，济度那些怖畏的世间众生；

以观察道品空性作为铠甲，得以成为勇健的大船师，到达彼岸，远离怖畏，常得安乐，把众生安置在那殊胜之处。

那些受持咒术、威仪与行持的人，解脱一切苦的逼迫，到达明术智慧的彼岸；智者能了知众生的意欲，

见到众生被烦恼之病所困而无所归依，种种恶的过患恼害世间，就以法药使病转泻而出，如法地为他们疗治。

那些以殊胜的言说摧伏异论的人，言辞上妙而得自在，了知种种言音，通达法义，勇健地安住于殊胜的智慧之地，

以忍辱之力作为智慧的武器，披上慈悯的坚固铠甲；圣者以智慧使智人喜悦，安住于法中而没有谄曲。

那些三有中最殊胜的尊者，对一切众生得到自在，见到众生依随魔道，游行而迷失了正真之路，

那道最为上妙，是圣洁无垢的，他们能无所畏惧地加以显示，使无量百千那由他的大众，前往这无忧之处。

那些为世间作明灯的人，作救护、作归依、作洲渚屋宅，为怖畏的众生施予无畏，安慰一切众生，

见到众生被百苦所恼，犹如天生的盲人一无所见，就点燃最殊胜的大法炬，演说显示真实的义理。

他们学习工巧技艺以利益众生，能获得名闻与功德之乐，安住于如法的技艺，使一切众生得到安乐，

使一切众生都到达彼岸，能成为最殊胜的大导师，为了怜悯世间而趣向菩提，使众生安住于无畏之处。

牟尼恒常没有厌足的，就是智慧与福德；已经到达持戒、忍辱、禅定的彼岸，安住于甚深微妙之法。

对于他人从不厌倦，演说最殊胜的寂灭之法，犹如天降大雨遍洒大地，法雨的充满也是如此。

如果有众生前往他那里，请求解说甚深之法以及名义，在他那里听闻法宝，就能除去无量无边的苦。

对于众生广大的种种疑惑，迅速以法刀加以斩断，到达戒、忍、三昧的彼岸，能了知众生的种种信乐。

大士到达那究竟的智慧，已经善加了知众生的意欲，观察众生心中所行，如其心中所行而决定了知。

如果有人听到他智慧的言语，就能使那由他的大众得到清净的法眼，度过禅定与解脱的彼岸，能入于并安住于真实之道。

亿那由他的诸魔众，都不能测知他的心行，犹如虚空中的鸟迹，众人都不能测知。

他以调伏寂灭的智慧之力，安住于最上的圣法之中；自在地摧坏诸魔的力量，悟解最上殊胜的菩提。

他常常到达神通的彼岸，能迅速前往百千世界，见到那由他多亿尊佛，其数也如恒河沙。

他的清净之眼没有种种障碍，看见十方一切导师；守护诸根而无所染著，自在地前往无量佛刹。

假设十方的一切众生，一时都成为导师，在那由他劫数之中，恒常赞叹宣说而不断绝，

以无碍的辩才而说不尽，所赞叹的功德也无穷无尽；对于这无与伦比的离垢之定，持在心中的人就能这样。

## 六、善化王与名称光法师的本生

这时，世尊又想显示这个三昧的功德利益，宣说菩萨往昔所行之事，也为了显现、增长月光童子之力的缘故，宣说自己的本缘，以偈颂说：

童子！你现在应当好好听：我在百千劫中所行，供养百千诸如来，为的是求得这殊胜的寂定。

在过去不可思议劫，有百个佛刹的微尘沙数那么多的劫数以前，你应当了知我所说的事：有佛名号叫众自在。

那位佛如来有眷属，满六十亿千之数，一切漏尽而没有烦恼，对于八解脱善能决定。

那时一切大地都安稳丰乐，没有浊乱，一切众人都安乐，游行往来，舒适喜悦而满足，

大富而饶有财物，全都充满，享受一切诸天之乐；他们持戒调伏，烦恼稀少，容貌端正，乐于忍辱之力，

犹如天宫中的诸天子，这些智者戒行与功德都具足。

在那个时世有一位国王，名声广大，名号叫善化；那时那位国王有众多儿子，满五百人，都具足正念与智慧。

那时这位殊胜的国王在佛所，施舍了六百万座园林，以美妙的花果树木庄严，奉献给具足大悲的佛；

建造寺院满六百万座，经行处与床座也是如此；袈裟、衣服有亿百千件，敷设在经行与休息之处，像这样无量百千种，一切沙门所需的器具，

那时这位殊胜的国王以信敬之心，全部奉献给善逝；他成就了一切福德之力，形色端严，非常可爱。

那位国王常以十善道使自己以及他人都安住其中，众人有百千那由他，跟随国王前往佛所。

他们手执美妙的花与涂香、殊胜的宝盖、幢幡以及音乐，供养最殊胜的佛世尊，合掌于头顶而站立。

一千位比丘大众默然而住，人、天、阿修罗、龙、夜叉，一切都恭敬地观看佛：“善哉！自然觉悟的世尊将宣说什么法呢？”

牟尼世尊了知他们的意欲，也了知那位殊胜国王最上的心，佛能了达他的信乐，就为他宣说这个三昧。

善逝演说这话的时候，大地与诸山都震动，一念之间虚空中降下众花，百千朵莲花从地中涌出。

佛已经善知微妙的义理句义，了知他们的意欲而为之记说，为国王宣说这寂灭之定：“你听我往昔所分别的：

“一切有与无都是妄想所起，空如阳焰，也如泡沫，如云、如闪电，都是空无，一切无我，没有众生。

“过去、未来的法也是空的，无去、无住，离于处所，常常没有坚实，如同幻化之性，一切殊胜清净，如同虚空。

```
非青非黄非赤白　名字空无但声性
其心离心无心性　离诸音声而空无
演说句味而不住　虽不说时字不空
文字亦不往诸方　亦复不从余处来
```

“大意是：心不是青，不是黄，也不是赤与白；名字是空无的，只是音声之性。这心本来离于心，没有心的自性，远离一切音声而空无所有。演说句义滋味而不住著；虽然不说的时候，文字也并不因此成为空无；文字既不前往诸方，也不从别处而来。

【按】“其心离心无心性”，是本经关于心性最精炼的一句：心非青黄赤白，无形无色；心本离心，没有一个可执的“心”的自性。大手印认识心性，正是认识这“离心无心性”的心。紧接着又说文字“不往诸方，不从余处来”，言说与心性同样无来无去。

“那文字是无尽的，这是无尽之藏；无论说还是不说，都恒常无尽；常常宣说句义滋味而说不尽，这样了知的人就得到无尽。

“如果了知此法是无尽的，他就常能宣说无尽之法；虽然宣说千种修多罗，却恒常了知诸法离于文字。

“百千诸佛都已过去，也曾宣说百千种法；对于一切法都没有穷尽，因为法无所得的缘故而无尽。

“如果有人为他人演说佛法，而不执著于文字，了知法本来无我、无众生，他就能演说而无尽。

“智者演说一切言语，不因为言语而改变他的心；了知一切言音如同山谷回响，所以对于言语没有执取。

“以种种言音来宣说此法，这言语一念之间就坏灭了；这些言音是这样的相，一切诸法的相也是如此。

“诸法无相，也离于相，恒常无相，其相空寂；空寂而无欲、无取舍，所以寂定也不可得。

“有为与无为都远离，这样的大仙没有分别，远离一切恶见之道，了达诸趣都是无为。

“恒常没有贪染，没有嗔、痴，所以心的体性恒常寂灭；以这个三昧的力量最为殊胜，所以能了知这法空。

“如同空寂的山河以及溪谷，能听到殊胜美妙的回响之声；有为法的流转由因缘而生起，一切世间都是空的，犹如幻化。

“具足智力，爱乐功德之法，安住于智慧与神通的仙人，发出言语能够善巧，能宣说这寂灭之定。

“所说的觉观只是妄想，世间不可得其边际；本际从来没有相，却成为未来的因缘之道。

“造业所作而有所生起，随着上、中、下（的业）而有所受生；这法的自性没有知觉，应当了知法空无我。

```
黑白之业不坏灭　自所作者还自受
业不能到于果所　而业能为彼作因
```

“大意是：黑业与白业都不会坏灭，自己所作的还要自己承受；业本身并不能走到果报那里，然而业却能作为果报之因。

【按】这首偈把前面卷七“业既不至彼”与“所作之业无失坏”两个方面合为一处：业没有一个实体从因走到果，所以说空；然而业确实能作为果的因，所以果报不失。因果相续而无实物往来，这就是缘起性空最精确的表述。

“诸佛演说世俗谛之法，对于有为与无为应当这样观察：没有真实，也没有我与人，一切世间的相都是如此。

“一切诸有都是虚妄的，犹如幻化与水中之月，空无所有，也如水上聚集的泡沫，以音声来显说那恒常的寂灭。

“一切都施舍而无所执取，持戒与威仪也无所依恃，不执著于忍力与众生，这样修行的人就能得到寂定。”

随着那位国王心意所乐，如来称合其根机而演说；国王听了世尊所说之法，国王及其眷属都受了戒。

殊胜的国王听闻这个三昧之后，欢喜踊跃，这样说道：“善哉！能宣说这个三昧，所以我归依佛世尊。”

那时有八万人，听闻这最殊胜的法之体性，演说真实的第一义谛，全都获得无生法忍。

众生没有生灭，诸法无生，恒常空寂；国王及其眷属这样了知，都各自获得无生法忍。

那时善化王舍弃王位，投入那位佛的法中出家；那位国王所有的五百个儿子，都跟随国王出家；

国王与诸子出家的时候，其余的人还有无量之数，一切人都为了求取佛法的缘故，也在那佛法中出家。

自在如来为他们说法，满足二千年；国王、他的儿子以及眷属，在二千年中修行法行。

过了这么多年之后，那位佛世尊入于涅槃，那时诸声闻弟子都灭度了，正法在后来非常衰微。

## 七、名称光法师以空性之誓化刀为花

那位善化王有一个殊胜的儿子，名号叫福慧，具足正信；国王有一位法师作为导师，受持这殊胜的寂定。

这位法师聪明黠慧，具有念力，有无量百千人供养他，有百亿诸天一同侍从，前往各处赞叹他。

他言语柔软而不粗犷，调伏而乐于持戒，善加防护；他的声音和雅，言语可爱，智力与总持全都具足。

他得到的殊胜袈裟有百亿之数，这位比丘名号叫名称光；他的福德之力无与匹敌，无量的比丘对他生起妒嫉。

他具足福德以及色身之力，也具有智慧与神通，护持清净戒律与禅定之力，这是比丘的法力所生起的。

在家、出家的四众等，众人都依恋仰慕而爱乐他；若对佛法得到信心的人，都以爱重恭敬之心供养他。

往昔善化王那位殊胜的儿子，名号叫福慧，具有清净信心，知道那些比丘对法师生起恶心，就对自己的老师加以守护。

那时有五十万军众，都披着铠甲，手持刀剑，常常拥护这位法师，让他演说菩提寂灭之行。

他在大众中宣说这样的法，也就是空、无我、无寿命；那些计我执著的人，不喜乐法师所说的。

不信空性之法的比丘众，随即起身，手持刀剑，说：“这人妄说非法，杀了他就能获得大福德。”

法师见到刀剑并不怖畏，因为他思念空性之法的缘故：没有众生可以被杀，空无我、人，犹如石壁。

法师比丘随即合掌，发声称念“南无佛”：“如果空性之法确实不虚，愿这些刀剑化为曼陀罗花。”

由于这位护持戒律者的愿力，他发声之后，空中便降下花雨，大地与诸山都震动，刀剑随即变成美妙的香花。

【按】名称光法师与第七卷安隐德比丘一样，以“空法审实”为誓。经中一再显示：真实的空性见地本身具有力量，因为它与诸法实相相应。法师见刀不惧，所依的不是神通，而是“无有众生而可杀”的认识。

那时执取邪见、手持刀剑的那些比丘，都感到羞耻悔恨，他们的手握着刀却不能动弹，惊惧恐怕，大为怖畏。

那些对佛有信心、爱乐空性之法的大众，发出大声号哭，把一切衣服都奉献散布。

法师比丘生起慈心，在大众面前这样说：“如果有人对我生起嗔恨，我就为了他而修行菩提。”

护法的伴党非常少，法师常常被那些人侵凌，听到一切不喜之言，他的忍辱之力反而更加增上。

那时这位法师八十年中演说如来的空性法藏；无量百千的恶比丘，由于那位王子的力量而被驱散。

这位法师在其他时候，利益了无量百千大众，思量自己的戒行没有缺漏，就前往福慧那里。

王子见到法师非常恭敬，就问那位比丘说：“愿不要让人在我的大师这里，恼乱您的心，使您不喜悦。”

法师就回答说：“王子！愿您听我说：这是诸佛忍力所生起的，如果有人对我发出恶言，我就生起增上的殊胜忍辱。”

## 八、世尊结说本生并教诫末世

他已经在过去世无量百千劫中修习忍辱；“那位名称光比丘就是我的前身”，释迦如来这样说；

“往昔那位福慧王子，拥护名称光法师的人，在千生之中作我的朋友，我已经授记他为慈尊（弥勒）；

“往昔供养自在佛、为他建造殊胜微妙塔寺的人，就是那时出家的善化王，他成佛名号为莲花上。

“我也在无量百千劫中受持如来最殊胜之法，我已经积集了忍辱之力，童子！你应当随顺修学。

“我般涅槃去世之后，在以后正法灭尽的时候，比丘们乐于外道的典籍，他们便毁谤我殊胜的法；

“他们轻浮躁动、调戏而没有惭耻，贪嗜饮食而不护持戒罪，乃至对于衣钵恋著不舍，这些人毁谤我最殊胜的法；

“他们常乐于斗诤，反复无常，出身于贫穷下劣的种姓，在我的法中出家，却不乐于空寂与寂灭；

“随顺魔意的愚痴众生，随着魔的自在而执著，贪欲放纵的凡愚之人，他们不乐于空寂与寂灭；

“在家、出家的四众等，谗佞愚痴而生起恶心，随顺这样的恶党的人，他们在末世毁谤空性之法。

“童子！你听闻我的教导之后，应当常常供给阿兰若的僧人，也就是乐于空寂的人，这样的人能受持佛法。

“在我的佛法中容纳这样的人，出家受戒以及布萨，远离一切过失染污，能消受信众的布施，这样的人能受持菩提。

“乃至舍弃身命，修习空性之法，乐于寂灭，心与空性之法相应，乐于住在阿兰若，如同野鹿。

“以幢幡宝盖以及花香，在诸佛那里设置供养，供养无与伦比的殊胜支提（佛塔），就能迅速获得这个三昧。

“建立无比殊胜的塔庙，以种种金银涂饰，造作无量种的佛像，为了菩提而生起慈心。

“所有一切供养之具，天上与人间清净美妙的，你都应当寻求来供养佛，为了求取无上的佛智。

“应当如法地观想诸佛，也就是住于十方的诸如来；现前有无量安住于法的人，一切佛子都能证知。

“心中常常利益他人，喜好布施，持戒清净，安住于忍力，乐于修行忍辱以及远离之行，能了知一切诸法皆空；

“精进勇猛而不懈退，致力于修习禅定、持戒、多闻，智慧了达而常常清净，不久就能成为大悲者。

“以不净观除去贪染，以慈心之力对治嗔恚，以因缘之法破除愚痴，便能得到最上无上之道。

“观察身体犹如水上聚集的泡沫，一切都空而没有坚实；观察五蕴全都空无，就能迅速成就最殊胜的智慧；

“远离执取一切恶见，不依恃寿命以及我、人，了知一切诸法皆空，就能迅速成为那牟尼王。

“对于种种利养不贪著，得不到利养也不要生起忧愁，听到他人的赞叹或毁谤，心不要改变，犹如须弥山不动。

“为了求法而生起恭敬，不要在听闻之后执著于所闻，安住于一切佛所行之处，就能迅速游历百个世界；

“对于一切世间都平等，不要生起憎爱分别之心，千万不要求取利养以及名闻，就能迅速成为天人之师。

“恒常赞叹宣说佛的功德，以言辞语句如实地赞叹，众生听到这样的赞叹，对于佛的功德就会生起爱乐。

“对于父母、师长以及众生，这一切都恭敬，而不随顺于魔的力量，便能获得三十二种相好。

“常常远离一切喧闹，住在寂静空闲的林中，既能自利也能利他，为了求取解脱而迅速去实行。

“常乐于修习慈心、悲心，以及喜心、舍心也是如此，调伏寂灭，应当赞叹，就能迅速成就利益世间。

“如果有人想要得到寂灭之定，趣向无上菩提，千万不要亲近恶知识，要恒常亲近善人。

“又不要愿求声闻之地，也不要爱乐他们所修之行，勇猛地立志乐求佛的功德，就能迅速成佛，正如我一样。

“恒常说真实清净的话，千万不要妄语以及恶口，常说可爱美妙的言语，就能得到最殊胜的佛菩提。

“对于身命不要顾恋，千万不要自我称誉、轻毁他人，只要自己思念自己的功德（反省自己），不要去观察他人的所行。

```
常乐观空及解脱　于诸趣中勿愿乐
舍一切相悉无余　心恒安住于无相
常能远离于二边　于有于无莫分别
观诸众生但因缘　若能知此为大师
```

“大意是：常乐于观察空性以及解脱，对于诸趣不要生起愿乐；舍弃一切相，全然无余，心恒常安住于无相。常能远离二边，对于有与无都不要分别；观察一切众生只是因缘和合，如果能了知这一点，就能成为大师。

【按】这八句可视为本卷的修持总结：观空、舍相、住无相、离有无二边，同时观众生唯是因缘。这正是“空而不断、有而无实”的中道观。冈波巴大师传授大手印时，常以“离二边”作为见地的标准，此偈即是经证。

“舍弃一切爱欲之行，全部断离浑浊之心，剪除一切愚痴的黑暗，就能成为寂灭的人中狮子。

“恒常乐于观察无常，远离诸有中的苦、乐等，观察秽污不净以及无我，这样修行的人能成为人中之尊。

“佛在世间作明灯，而能宣说这殊胜的正法；他也降伏了魔的力量，已经到达无上殊胜的菩提。

“我前面所说的种种功德，以及所显示的无量百千种过失，应当远离过失、修习功德，童子！这样必定能成佛。”

《月灯三昧经》卷第九终
