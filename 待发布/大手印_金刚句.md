# 金刚句

金刚手（Vajrapāṇi）造　据藏文译出

## 题解

《金刚句》（梵 Vajrapada，藏 rdo rje'i tshig）收于德格版丹珠尔续部释 ཝི 函第 177a 至 180b 页（东北目录 D2255），紧接在《真如十颂广释》（D2254）之后。作者是梅纪巴的弟子金刚手（phyag na rdo rje，Vajrapāṇi），他是梅纪巴的四大弟子之一，曾到西藏传授梅纪巴的大手印法类；译者就是他本人与粗敦·智慧源（mtshur ston Jñānākara），两人也合译了梅纪巴的《真如十颂》。

正如书名与结颂"把金刚句摘集起来"所示，这不是一部论述性的论典，而是一部"摘句集"：作者从《喜金刚续》等母续中摘集出与四手印相关的"金刚句"（续部的原句），依业手印、法手印、大手印、三昧耶手印的次第编排，每一部分末尾各有"业手印开示完毕"等标题。开头的造论缘起中说，这是为了让弟子理解"业手印等的修法"而写的。所以，本篇可以视为梅纪巴一系四手印体系的续部经证汇编，与《灌顶教示》（D2252）、《灌顶教示难释》（D2253）、《五如来印释》（D2242）等互相发明。

全篇的结构大致是：

一、业手印：四灌顶与"诶旺"，四刹那（种种、异熟、坏相、离相）与四喜，四灌顶与四喜的配对，菩提心如月，"嘿噜嘎"的字义，坛城与轮的释名，"一切皆乐"，"我是说者"，五大与俱生。

二、法手印：一切如水中月，钻木取火之喻，轮回即涅槃，俱生远离贪嗔痴，空悲无别的菩提心。

三、大手印：无念诵、无坛城、无修者与所修，一切清净无所有，本尊之名的真义，自证智慧超越言语，众生与佛同一而为客尘所蔽，俱生要依上师与自己的福德而了知。

四、三昧耶手印：了知真如就能解脱，心性就是圆满的佛，事物的束缚由了知而解脱，平等一味，"一切众生从我而生"，以毒攻毒、以贪离贪的"逆修"。

**与前译重复的提示：**本篇所摘的续部原句，有相当一部分已经在此前译出的《灌顶教示》《灌顶教示难释》中出现过，例如"'诶'的美好形状……诸佛的宝箧"、四刹那的定义、"种种说为种种相，即拥抱、亲吻等"、"灌顶有四种之数，喜等应依次了知"、"笑是阿阇黎，注视是秘密……"、"在舍弃种种的刹那，真实获得胜喜"等。本译在译文上尽量与前译保持一致，各处在按语中注明。

**关于内容的说明：**本篇大部分是无上瑜伽续（特别是《喜金刚续》）的原句，其中业手印部分包含大量第三灌顶中的象征用语，如"金刚""莲花""宝珠""菩提心""婆伽"（bhaga）、"菩提心的融化"等。本译依此前的原则处理：这些用语只照原文直译，不作任何解说或引申；按语中只说明它们是象征用语，须依具德上师的灌顶与口授来领受。读者绝不可凭文字理解，更不可自行揣度而行。正如《灌顶教示难释》第四十九节所说，把业手印当作真如本身，正是梅纪巴一系所严厉批评的；本篇把业手印放在四手印的最初，正是为了引向法手印、大手印的证悟。

另外，原文第 55 至 58 句是一偈续文，其中有对未成年人的描写，依本译的体例略去不译；这一偈在《灌顶教示难释》第二十八节中也已略去。藏文底本中这一偈也已作了删略。

体例：本篇是偈颂体（中间有一段散文），依本译对短篇的体例，先把藏文原句按意义单元列于代码块中，再以完整的意义单元译出；为了便于理解而补的字，都放在方括号中。各节标题为译者所加，标题后注明藏文底本的句号（共 376 句，见《金刚句_藏文底本.txt》）。所引续文能确定出处的，在按语中注明；不能确定的，不妄加出处。原文含混或可有两解之处，以"【按】"说明，不妄补内容。

## 一、题名、礼敬与造论缘起（第 1–14 句）

```
༄༅༅། །
རྒྱ་གར་སྐད་དུ།
བཛྲ་པ་ད་ནཱ་མ།
བོད་སྐད་དུ།
རྡོ་རྗེའི་ཚིག་ཅེས་བྱ་བ།
རྡོ་རྗེ་འཛིན་པ་ལ་ཕྱག་འཚལ་ལོ། །
དངོས་པོ་ཀུན་གྱིས་བདག་གུས་པས། །
དང་པོ་བླ་མ་མཆོག་ཕྱག་འཚལ། །
སླར་ཡང་རི་ཁྲོད་པ་དེ་བཞིན། །
དགྱེས་པའི་རྡོ་རྗེ་མ་རྒྱུད་དུ། །
དེ་བཞིན་གཤེགས་པས་སྤངས་པ་གང་། །
རྣམ་བཤད་ཕྱག་ན་རིགས་ལྡན་པས། །
ལས་ཀྱི་ཕྱག་རྒྱ་སོགས་སྒྲུབ་ཐབས། །
སློབ་མ་ཡིས་ནི་རྟོགས་ཕྱིར་བྲི། །
```

梵语题名：Vajrapada-nāma。藏语题名：名为《金刚句》。

敬礼持金刚！

我以一切［身语意］之事，恭敬地首先敬礼殊胜的上师，然后同样［敬礼］山居者。

在《喜金刚》母续中，如来所［宣说］的业手印等的修法，由具种姓的金刚手加以解释，为了让弟子们理解而写下。

【按】"山居者"（ri khrod pa），即夏瓦日巴（Śavaripa），梅纪巴的根本上师之一（见《灌顶教示》第十三节、《灌顶教示难释》第五十节按语）。作者先礼"殊胜的上师"，应是指梅纪巴，再礼梅纪巴的上师夏瓦日巴，这是梅纪巴一系的传承次第。

"如来所［宣说］的"，藏文作"དེ་བཞིན་གཤེགས་པས་སྤངས་པ་གང་"（如来所舍弃的），意思不通，"spangs pa"（舍弃）应是"gsungs pa"（宣说）或类似词的误写，这里依上下文译出，存疑。"具种姓的金刚手"（phyag na rigs ldan），是作者的自称，"具种姓"是谦敬之词，也可能指"具［金刚］部族者"。

## 二、四灌顶与"诶旺"（第 15–30 句）

```
སངས་རྒྱས་ཀུན་བདག་སྡོམ་པ་ནི། །
ཨེ་ཝཾ་རྣམ་པར་རབ་ཏུ་གནས། །
ཡང་དག་དབང་བསྐུར་ཞེས་བྱ་བ། །
གཅིག་པུའི་རྣམ་པ་བདེ་ཆེན་པོ། །
བུམ་པའི་དབང་ནི་དང་པོ་སྟེ། །
གསང་བ་མཆོག་ནི་གཉིས་པ་ཡིན། །
ཤེས་རབ་ཡེ་ཤེས་གསུམ་པ་སྟེ། །
དེ་ལྟར་དེ་བཞིན་བཞི་པ་ཡང་། །
ཨེ་ཡི་ཆ་བྱད་བཟང་པོ་གང་། །
དབུས་སུ་ཝཾ་གིས་རྣམ་པར་བརྒྱན། །
བདེ་བ་ཐམས་ཅད་ཀྱི་ནི་གནས། །
སངས་རྒྱས་རིན་ཆེན་ཟ་མ་ཏོག །
དེ་ལས་དགའ་བ་སྐྱེ་བར་འགྱུར། །
སྐད་ཅིག་དབྱེ་བ་ཐ་དད་པས། །
སྐད་ཅིག་ཡེ་ཤེས་བདེ་ཡེ་ཤེས། །
ཨེ་ཝཾ་རྣམ་པར་རབ་ཏུ་གནས། །
```

一切佛的律仪，安住于"诶旺"之中。所谓"真实的灌顶"，就是唯一之相的大乐。

瓶灌顶是第一，殊胜的秘密［灌顶］是第二，智慧智［灌顶］是第三，第四也同样如此。

"诶"的美好形状，中央以"旺"来庄严，是一切安乐的处所，是诸佛的宝箧。从它生起喜，以刹那的区分而有差别；刹那的智慧，就是安乐的智慧，安住于"诶旺"之中。

【按】"诶旺"（e waṃ，梵 evaṃ），见《灌顶教示》开篇按语："诶"表智慧，"旺"表方便，是方便与智慧双运的象征。"'诶'的美好形状……是诸佛的宝箧"一偈，在《灌顶教示难释》第四节中已引用并译出，这里译文与之保持一致；一般认为出自《喜金刚续》第二品第三章。"律仪"（sdom pa，saṃvara），在母续中又有"总摄、和合"的意思。

## 三、四刹那（第 31–42 句）

```
རྣམ་པ་སྣ་ཚོགས་རྣམ་པར་སྨིན། །
རྣམ་ཉེད་དེ་ནི་མཚན་ཉིད་བྲལ། །
སྐད་ཅིག་མ་བཞི་ཡང་དག་རྟོགས། །
འདི་ལྟར་རྣལ་འབྱོར་མས་ནི་ཤེས། །
སྣ་ཚོགས་རྣམ་པ་སྣ་ཚོགས་བརྗོད། །
འཁྱུད་དང་འོ་བྱེད་ལ་སོགས་པ། །
རྣམ་པར་སྨིན་པ་དེ་ལས་བཟློག །
བདེ་བའི་ཡེ་ཤེས་ཟ་བའོ། །
རྣམ་པར་ཉེད་པ་དཔྱོད་པར་བརྗོད། །
བདག་གིས་བདེ་བ་སྤྱད་དོ་ཞེས། །
མཚན་ཉིད་བྲལ་བ་གསུམ་ལས་གཞན། །
ཆགས་དང་ཆགས་བྲལ་རྣམ་པར་སྤངས། །
```

种种、异熟、坏相，以及那离相——瑜伽母要这样了知、真实证悟四刹那。

"种种"，说为种种相，即拥抱、亲吻等。"异熟"与它相反，就是享受安乐的智慧。"坏相"，说为观察，［即生起］"我已享受了安乐"［的念头］。"离相"，是在这三者之外，远离了贪与离贪。

【按】这是《喜金刚续》第二品第三章对四刹那的著名定义，在《灌顶教示》第七节以下及《灌顶教示难释》第二十八至三十一节中已多次引用并解释，这里译文与之保持一致。这些都是第三灌顶中有特定内涵的象征用语，只能在具德上师座前依灌顶与口授领受，这里只照原文译出。

依梅纪巴一系的宗旨（见《灌顶教示》），四刹那的次第是种种、异熟、离相、坏相，以"离相"为第三；这里所摘的续文次第则是种种、异熟、坏相、离相，是续文的原次第。两者的差别，在《灌顶教示难释》中有详细的讨论。

## 四、四喜（第 43–50 句）

```
དང་པོར་དགའ་བ་རྣམ་སྣ་ཚོགས། །
མཆོག་ཏུ་དགའ་བ་རྣམ་པར་སྨིན། །
དགའ་བྲལ་དགའ་བ་རྣམ་པར་ཉེད། །
ལྷན་ཅིག་སྐྱེས་དགའ་མཚན་ཉིད་བྲལ། །
དགའ་བ་དང་པོ་འགྲོ་བ་ཉིད། །
མཆོག་ཏུ་དགའ་བའང་འགྲོ་བ་ཉིད། །
དགའ་བྲལ་དགའ་བ་འགྲོ་བ་ཉིད། །
ལྷན་ཅིག་སྐྱེས་པ་གསུམ་མི་དམིགས། །
```

初喜是种种，胜喜是异熟，离喜之喜是坏相，俱生喜是离相。

初喜也就是众生，胜喜也就是众生，离喜之喜也就是众生，俱生则三者都不可得。

【按】"初喜是种种……俱生喜是离相"，即《灌顶教示难释》第三十三节所引《喜金刚续》的话。"初喜也就是众生……俱生则三者都不可得"，意思是前三喜都还在众生（世间）的范围内，俱生喜则超越前三者，不能以前三者来缘取。这也出自《喜金刚续》，存疑。

## 五、观照之法（第 51–54 句）

```
པདྨའི་ནམ་མཁའ་རྡོ་རྗེ་ཟེའུ་འབྲུ་དག །
རྡོ་རྗེ་སྐྱིལ་ཀྲུང་གིས་མནན་གནས་དག་ཏུ། །
སེམས་ནི་ནོར་བུའི་ནང་དུ་ཆུད་པས་བལྟ། །
ཡེ་ཤེས་གང་སྐྱེས་ཡེ་ཤེས་བརྗོད་མེད་གཟུགས། །
```

在莲花的虚空中，金刚的花蕊［之处］，以金刚跏趺坐压住的处所，心进入宝珠之中而观看；所生起的智慧，是不可言说的智慧之相。

【按】这一偈全是第三灌顶中有特定内涵的象征用语（"莲花""金刚""花蕊""宝珠"等），只能在具德上师座前依灌顶与口授领受，这里只照原文译出，不作任何解说。第二句"以金刚跏趺坐压住的处所"，藏文作"རྡོ་རྗེ་སྐྱིལ་ཀྲུང་གིས་མནན་གནས་དག་ཏུ"，语法不很清楚，存疑。

【按】原文此后（第 55 至 58 句）是一偈续文，说明阿阇黎灌顶的情形，其中有对未成年人的描写，依本译的体例略去不译；《灌顶教示难释》第二十八节引用这一偈时也已略去。

## 六、四灌顶与四喜的配对（第 59–68 句）

```
སློབ་དཔོན་གསང་བ་ཤེས་རབ་དང་། །
དེ་ལྟར་དེ་བཞིན་བཞི་པ་ཡང་། །
དབང་བཞི་ཡི་ནི་གྲངས་ཀྱིས་ཀྱང་། །
དགའ་བ་ལ་སོགས་རིམ་བཞིན་ཤེས། །
དགོད་པའི་དགའ་བ་སློབ་དཔོན་ཏེ། །
ལྟ་བ་དེ་བཞིན་གསང་བའི་དབང་། །
འཁྱུད་པ་ཤེས་རབ་ཡེ་ཤེས་ཏེ། །
དེ་ཡང་གཉིས་ཀྱིས་གཉིས་སྤྲོད་རྒྱུད། །
སེམས་ཅན་རྣམས་ཀྱི་དངོས་གྲུབ་འགྱུར། །
དབང་བསྐུར་རྣམ་པ་བཞི་རུ་བཤད། །
```

阿阇黎、秘密、智慧，第四也同样如此；以四灌顶之数，喜等也要依次了知。

笑之喜是阿阇黎，注视同样是秘密灌顶，拥抱是智慧智，那［续］也以两者的两者相合［为喻］；［由此］成就众生的悉地，灌顶被说为四种。

【按】"灌顶有四种之数，喜等应依次了知"，见《灌顶教示难释》第二十八节；"笑是阿阇黎，注视是秘密，拥抱是智慧，两者的两者相合是续"，见《灌顶教示》第七节及《灌顶教示难释》第三十节按语，是续中以笑、视、抱、合四种象征来区分四部续（事、行、瑜伽、无上瑜伽）或四种灌顶的说法。第四句藏文"དེ་ཡང་གཉིས་ཀྱིས་གཉིས་སྤྲོད་རྒྱུད"，《灌顶教示难释》所引作"那两者的两者相合是因"，这里"rgyud"可以读作"续"，也可以读作"相续"，存疑。

## 七、灌顶的字义与胜喜（第 69–78 句）

```
བླུགས་ཤིང་བཀྲུས་པ་འདི་ཡིས་ནི། །
དབང་བསྐུར་ཞེས་བྱ་མངོན་པར་བརྗོད། །
སྣ་ཚོགས་སྤང་བའི་སྐད་ཅིག་ལ། །

འདི་དེ་ཉིད་ཀྱིས་ཡེ་ཤེས་ཆེ། །
ལུས་ཀུན་ལ་ནི་རྣམ་པར་གནས། །
```

因为以此而灌注、洗涤，所以称为"灌顶"。

在舍弃种种的刹那，真实获得胜喜。导师开示："大勇士啊，［这是］大乐的真实之相；乃至未获得菩提之间，为了众生的利益而持金刚。"

这本身就是大智慧，遍住于一切身中。

【按】"因为以此而灌注、洗涤，所以称为灌顶"，是《喜金刚续》对"灌顶"（abhiṣeka）一词的字义解释。"在舍弃种种的刹那，真实获得胜喜"一偈，见《灌顶教示难释》第二十九节（那里所引的后半作"上师开示：大勇士啊，要真实地执持大乐"），这里藏文作"大乐的真实之相"，文字稍异。"这本身就是大智慧，遍住于一切身中"，是《喜金刚续》第一品第一章中的名句："大智慧住于身中，远离一切分别，遍于一切事物，住于身中而非身所生。"本篇第二十一节还会摘引这一偈的下文。

## 八、菩提心如月（第 79–87 句）

```
བྱང་ཆུབ་སེམས་ནི་ཟླ་བར་གྱུར། །
བཅོ་ལྔའི་ཆའི་བདག་ཉིད་ཅན། །
ཨཱ་ལིའི་གཟུགས་ཀྱིས་བདེ་ཆེན་པོ། །
རྣལ་འབྱོར་མ་ནི་དེ་ཡི་ཆ། །
དོན་གྱི་བྱ་བ་མི་བྱེད་ཕྱིར། །
ཐམས་ཅད་མཐའ་ནི་འབད་པས་སྤངས། །
བཅུ་དྲུག་གི་ནི་ཆ་མ་ཡིན། །
ལྷན་ཅིག་སྐྱེས་པའི་ངོ་བོ་གང་། །
དགའ་བྲལ་དང་པོ་མཆོག་གི་མཐའ། །
```

菩提心成为月亮，具有十五分的体性；以元音之相为大乐，瑜伽母就是它的［一］分。

因为不作［世俗］意义的作用，所以努力舍弃一切边；不是那第十六分，而是俱生的本体，［在］离喜之初、胜［喜］之末。

【按】这一偈出自《喜金刚续》，是以月亮的十六分来比喻菩提心：前十五分是"元音之相"的大乐，瑜伽母是其分；俱生的本体则不同于这些分，在"离喜之初、胜喜之末"。这都是圆满次第中有特定内涵的象征用语，只能依具德上师的灌顶与口授领受，这里只照原文译出，不作解说。"元音之相"（ā li'i gzugs），ā li 即梵文的元音字母序列。"不是那第十六分"，藏文作"བཅུ་དྲུག་གི་ནི་ཆ་མ་ཡིན"，与上文"十五分"的关系不很清楚，存疑。"离喜之初、胜［喜］之末"，藏文作"དགའ་བྲལ་དང་པོ་མཆོག་གི་མཐའ"，这与《灌顶教示》所说俱生在"胜喜之末、离喜之前"的位置相合。

## 九、"嘿噜嘎"的字义（第 88–100 句）

```
སྟོང་ལས་སྟོང་ཉིད་ཧེ་རུ་ཀ །
ཤྲཱི་ནི་གཉིས་མེད་ཡེ་ཤེས་ཏེ། །
ཧེ་ནི་རྒྱུ་སོགས་སྟོང་པའོ། །
རུ་ནི་ཚོགས་དང་བྲལ་བ་ཉིད། །
ཀ་ནི་གང་དུའང་མི་གནས་པ། །
ཁུ་བའི་རྣམ་པ་བཅོམ་ལྡན་འདས། །
དེ་ཡི་བདེ་བ་འདོད་མར་བརྗོད། །
འདི་ནི་གཅིག་དང་དུ་མ་བྲལ། །
སྐད་ཅིག་གཅིག་ལ་མཆོག་ཏུ་དགའ། །
གཉིས་སུ་མེད་དང་གཉིས་ཀྱི་ཚུལ། །
དངོས་དང་དངོས་མེད་བདག་ཉིད་གཙོ། །
བརྟན་དང་གཡོ་བ་ཁྱབ་སྟེ་གནས། །
སྒྱུ་མའི་གཟུགས་ནི་ཉིད་དུ་སྣང་། །
```

从空［中出生］的空性，就是嘿噜嘎："吉祥"（śrī），就是无二的智慧；"嘿"（he），就是因等的空性；"噜"（ru），就是远离聚合；"嘎"（ka），就是不住于任何处。

世尊是［白］精之相，他的安乐被说为［佛］母。

这远离一与多，在一刹那中就是胜喜；［是］无二与二的方式，事物与非事物之体性的主尊；遍于不动与动而安住，显现为如幻之相本身。

【按】"嘿噜嘎"（Heruka）的字义解释，出自《喜金刚续》：śrī（吉祥）是无二智慧，he 是因等的空性，ru 是远离聚合，ka 是不住于任何处。这是以字母来开示嘿噜嘎即空性智慧的体性。"世尊是［白］精之相，他的安乐被说为［佛］母"一偈，是圆满次第中以菩提心为世尊、以其安乐为佛母的象征说法，藏文"ཁུ་བ"（khu ba），是"精华、白精"之意，在密续中指菩提心明点，这里只照原文译出，不作解说。"［佛］母"，藏文作"འདོད་མ"（可爱的女子，梵 kāminī），存疑。

## 十、坛城与轮（第 101–122 句）

```
དཀྱིལ་འཁོར་འཁོར་ལོ་སོགས་ཐབས་དང་། །
དེ་ནི་རྟག་ཏུ་ངེས་པར་གྲོལ། །
དཀྱིལ་ནི་སྙིང་པོར་བརྗོད་པ་སྟེ། །
བྱང་ཆུབ་སེམས་ནི་བདེ་ཆེན་པོར། །
ལེན་པར་བྱེད་པས་དཀྱིལ་འཁོར་ཏེ། །
འདུས་པས་དཀྱིལ་འཁོར་དུ་ནི་བཤད། །
འཁོར་ལོའི་ཚོགས་ནི་ནམ་མཁའི་ཁམས། །
ཡུལ་ལ་སོགས་པ་རྣམ་སྤྱོད་པའོ། །
རྡོ་རྗེ་པདྨ་སྦྱོར་བའི་ཐབས། །
དེ་ཡི་བདེ་བ་རྟོགས་པར་བྱེད། །
ནམ་མཁའི་ཁམས་སུ་བྷ་ག་བསམ། །
དབུས་སུ་བསྒོམ་པར་བྱ་བ་ནི། །
འཁོར་ལོ་སྔོན་འགྲོ་ཚུལ་ཇི་བཞིན། །
ལྷ་རྣམས་ཇི་ལྟར་འབྱུང་བ་བསམ། །
མཁའ་དབྱིངས་ཞེས་བྱའི་པདྨ་ལ། །
བྷ་ག་འདིར་ནི་ཡེ་ཤེས་བརྗོད། །
བསྒོམས་པ་འདིར་ནི་སྙོམས་འཇུག་པ། །
དེ་ཡི་བདེ་བ་འཁོར་ལོར་བརྗོད། །
ཕྱག་རྒྱ་ཆེན་པོ་དབང་བསྐུར་བ། །
ཇི་ལྟར་བདེ་བ་ཆེན་པོ་ཡི། །
དེ་ཉིད་འདི་ཡི་མཐུ་སྟོབས་ཀྱིས། །
དཀྱིལ་འཁོར་གཞན་དུ་མི་འབྱུང་ངོ་། །
```

坛城、轮等方便，以及那［方便］，恒常决定地解脱。

"坛"（dkyil），说为心要；因为把菩提心取为大乐，所以是"坛城"（dkyil 'khor）；由于聚合，所以说为坛城。

轮的聚集，就是虚空界，就是对境等的受用。金刚与莲花结合的方便，能使人证悟它的安乐。

要在虚空界中观想"婆伽"；在中央所应修习的，是依照轮的前行的方式，观想诸本尊如何出现。

在名为"虚空界"的莲花上，这里的"婆伽"说为智慧；这里所修的，是等入；它的安乐，被说为"轮"。

大手印的灌顶：就像大乐的那真性，以它的威力，坛城不会在别处出现。

【按】这一节是《喜金刚续》对"坛城"（maṇḍala）、"轮"（cakra）的字义解释与修法要点。"坛城"一词被解释为：maṇḍa 是心要（精华），la 是"取"，即把菩提心取为大乐；"轮"被解释为虚空界、对境的受用。其中"金刚与莲花结合""婆伽"（bhaga）等，都是第三灌顶中有特定内涵的象征用语；"婆伽"，续中说"这里的婆伽说为智慧"，"虚空界"即"名为虚空界的莲花"。这些只能在具德上师座前依灌顶与口授领受，这里只照原文译出，不作任何解说。"坛城不会在别处出现"，意思是：真正的坛城就是大乐的真性本身，不在此外另有坛城。

## 十一、一切皆乐（第 123–131 句）

```
བདེ་བ་ནག་པོ་བདེ་བ་སེར། །
བདེ་བ་དམར་པོ་བདེ་བ་དཀར། །

བདེ་བ་ཤེས་རབ་བདེ་བ་ཐབས། །
དེ་བཞིན་ཀུན་དུ་རུ་སྐྱེས་བདེ། །

རྡོ་རྗེ་སེམས་དཔའ་བདེ་ཆེན་བརྗོད། །
དངོས་དང་དངོས་མེད་གཉིས་ཀྱང་ངོ་། །
```

黑色是乐，黄色是乐，红色是乐，白色是乐，绿色是乐，青色是乐，一切动与不动都是乐；智慧是乐，方便是乐，同样，一切处的莲花所生也是乐；事物是乐，非事物也是乐——金刚萨埵被说为大乐。

【按】这一偈出自《喜金刚续》，说五方佛的颜色（黑、黄、红、白、绿、青）、动与不动的一切、智慧与方便、事物与非事物，都是乐，金刚萨埵就是大乐。"莲花所生"（ru skyes），藏文作"ཀུན་དུ་རུ་སྐྱེས"，应是"chu skyes"（水生，即莲花）的误写，这里依上下文译出，存疑。最后"事物与非事物两者也是［如此］"一句，与上下文的衔接不很清楚，存疑。

## 十二、"我是说者"（第 132–144 句）

```
དངོས་པོ་རྟོགས་ཕྱིར་སངས་རྒྱས་པ། །
ལེ་ལོས་ཉེ་བར་བཅོམ་པ་དང་། །
རྨོངས་པ་རྣམས་ཀྱིས་ང་མི་ཤེས། །
རྡོ་རྗེ་བཙུན་མོའི་བྷ་ག་མཆོག །
བདེ་བ་ཅན་ན་ང་གནས་ཏེ། །
ཨེ་ཡི་ཆ་བྱད་ཀྱི་ནི་གཟུགས། །
སངས་རྒྱས་རིན་ཆེན་ཟ་མ་ཏོག །
འཆད་པ་པོ་ང་ཆོས་ཀྱང་ང་། །
རང་གི་ཚོགས་ལྡན་ཉན་པ་ང་། །
འགྲོ་བ་སྟོན་པ་བསྒྲུབ་བྱ་ང་། །
འཇིག་རྟེན་འཇིག་རྟེན་འདས་པ་ང་། །
ལྷན་ཅིག་སྐྱེས་གཞན་རང་བཞིན་ང་། །
མཆོག་མཐའ་བྲལ་བ་དང་པོ་སྟེ། །
```

为了证悟事物［的真性］，诸佛［开示了这些］；［然而］被懒惰所摧毁的人，以及愚痴的人，都不认识我。

我安住于金刚后妃殊胜的婆伽——极乐之中，是"诶"字形状之相，是诸佛的宝箧。

说法者是我，法也是我；具有自己的眷属、听法者也是我；众生的导师、所修者是我；世间与出世间也是我；俱生的、他者的自性，也是我。

［这是］胜［喜］之末、离［喜］之初。

【按】这一节是《喜金刚续》中世尊以"我"（ahaṃ）宣说自己即是一切的名句："说法者是我，法也是我，听法者也是我……世间与出世间也是我，俱生的自性也是我。"这里的"我"，是指嘿噜嘎、即俱生智慧本身，并不是凡夫所执的我。"金刚后妃殊胜的婆伽"等，是第三灌顶中的象征用语，见上一节按语，这里只照原文译出。

第一句"为了证悟事物，诸佛……"，藏文"དངོས་པོ་རྟོགས་ཕྱིར་སངས་རྒྱས་པ"与下句的衔接不很清楚，存疑。最后一句"胜［喜］之末、离［喜］之初"（མཆོག་མཐའ་བྲལ་བ་དང་པོ），与第八节"离喜之初、胜喜之末"相应，是说俱生的位置。

## 十三、五大与俱生（第 145–158 句）

```
བོལླ་ཀ་ཀོ་ལ་སྦྱོར་བས། །
རེག་པ་ལས་ནི་སྲ་བའི་རྫས། །
ས་ནི་དེ་ལས་སྐྱེས་པར་འགྱུར། །
བྱང་ཆུབ་སེམས་ནི་ཞུ་བ་ལས། །
ཆུ་ཡི་ཁམས་སུ་ཡང་ནི་འབྱུང་། །
བསྐྱོད་པ་ལས་ནི་མེ་ཡིན་ཏེ། །
འགྲོ་བ་རླུང་དུ་རབ་ཏུ་གྲགས། །
བདེ་བ་ཡང་ནི་ནམ་མཁའི་ཁམས། །
ལྔ་པོ་རྣམས་ཀྱིས་ཡོངས་སུ་བསྐོར། །
དེ་ཕྱིར་བདེ་བ་དེ་ཉིད་མིན། །
གང་ཕྱིར་འབྱུང་བ་ཆེ་བདེ་བ། །
ལྷན་ཅིག་སྐྱེས་པའི་ངོ་བོ་གང་། །
ལྷན་ཅིག་སྐྱེས་པར་ངེས་པར་བཤད། །
ལས་ཀྱི་ཕྱག་རྒྱ་བསྟན་པའོ། །
```

由"波拉""迦柯拉"的结合，从触而生坚硬之物，地就从它而生起；由菩提心的融化，又生起水界；从摇动而生火；行动被称为风；安乐也就是虚空界。

被这五者所围绕，所以［这种］安乐并不是真性；因为大种［所生的］安乐，［并不是］俱生的本体，［而］被确定地说为俱生。

——业手印开示完毕。

【按】"波拉"（bolla）与"迦柯拉"（kakkola），是续中的隐语，分别指金刚与莲花，即第三灌顶中的象征用语，只能依具德上师的灌顶与口授领受，这里不作解说。

这一节是业手印部分的总结，要点在后半："被五大所围绕的安乐，并不是真性"——由业手印所生的安乐，是大种所生的安乐，不是俱生本身。这与《灌顶教示难释》第四十七节所引续文"大种所生的安乐，并不是安乐之安乐本身"、第四十九节"由二根所生的安乐，恶人说那就是真如，而最胜的胜者并没有说那是大乐"的意思完全一致。最后两句藏文作"གང་ཕྱིར་འབྱུང་བ་ཆེ་བདེ་བ། ལྷན་ཅིག་སྐྱེས་པའི་ངོ་བོ་གང་། ལྷན་ཅིག་སྐྱེས་པར་ངེས་པར་བཤད།"，字面是"因为大种的安乐，凡是俱生的本体，被确定地说为俱生"，与上句"所以安乐并不是真性"的关系不很清楚：可以理解为"大种所生的安乐不是俱生；凡是俱生的本体，才被确定地说为俱生"。这里依此理解译出，存疑。

所以，本篇把业手印放在四手印的最初，并在这一部分的结尾明确指出它的安乐不是真性，正是为了引向下面的法手印与大手印。

## 十四、法手印：一切如水中月；钻木取火之喻（第 159–172 句）

```
རང་བཞིན་ཉིད་ནི་མ་སྐྱེས་ན། །
བདེན་པ་མ་ཡིན་རྫུན་པ་མིན། །
ཐམས་ཅད་ཆུ་ཟླ་ལྟ་བུ་དེ། །
རྣལ་འབྱོར་མ་རྣམས་ཤེས་པར་འདོད། །
```

自性既然不生，［一切］就不是真实，也不是虚妄；瑜伽母们要了知，一切都像水中的月亮。

```
འདི་ལྟ་སྟེ།
གཙུབ་གཏན་དང་།
གཙུབ་ཤིང་དང་།
སྐྱེས་བུའི་ལག་པ་བསྐྱོད་པ་ལས་གློ་བུར་དུ་མེ་མངོན་སུམ་དུ་འབྱུང་སྟེ།
མེ་དེ་ནི་གཙུབ་ཤིང་ལ་ཡང་མི་གནས།
གཙུབ་གཏན་ལ་ཡང་མེད།
སྐྱེས་བུའི་ལག་པ་ལ་ཡང་མ་ཡིན་ཏེ།
རྣམ་པ་ཐམས་ཅད་དུ་ཡོངས་སུ་བཙལ་ན་གཅིག་ལ་ཡང་གནས་པ་མེད་དོ། །
མེ་དེ་ཡང་བདེན་པ་ཡང་མ་ཡིན་རྫུན་པ་ཡང་མ་ཡིན་ཏེ།
དེ་ལྟར་ཆོས་ཐམས་ཅད་ཡིད་ལ་གྱིས་ཤིག །
```

就像这样：由钻木的下木、钻木的上木，以及人的手的转动，火忽然现前生起。那火，并不住在上木中，也不在下木中，也不在人的手中；从一切方面去寻找，［它］也不住在任何一处。那火，既不是真实的，也不是虚妄的。要这样去思惟一切法。

【按】这一段散文是《喜金刚续》中的名喻：火由钻木、木座与人手的转动和合而生，却不在其中任何一处，所以不是真实也不是虚妄。这就是缘起性空：一切法依因缘而显现，却找不到实有的自性。法手印部分以此开始，说明一切法如水中月、如钻木之火。

## 十五、轮回即涅槃（第 173–184 句）

```
དེ་ལྟར་འཁོར་བ་དེ་ཉིད་དོ། །
འཁོར་བ་མ་རྟོགས་གཞན་དུ་ནི། །
མྱ་ངན་འདས་པ་མི་ཤེས་སོ། །
འཁོར་བ་གཟུགས་དང་སྒྲ་ལ་སོགས། །
འཁོར་བ་ཚོར་བ་ལ་སོགས་ཏེ། །
འཁོར་བ་དབང་པོ་རྣམས་ཉིད་དོ། །
འཁོར་བ་ཞེ་སྡང་ལ་སོགས་པ། །
ཆོས་འདི་དག་ནི་མྱ་ངན་འདས། །
རྨོངས་པས་འཁོར་བའི་གཟུགས་ཅན་ཉིད། །
འཁོར་བ་གཏི་མུག་མེད་པ་དག །
བྱང་ཆུབ་སེམས་ནི་མྱ་ངན་འདས། །
དོན་དམ་ཀུན་རྫོབ་རང་བཞིན་ནོ། །
```

这样，轮回本身就是［涅槃］。离开了对轮回的证悟，在别处是不能了知涅槃的。

轮回就是色与声等，轮回就是受等，轮回就是诸根本身，轮回就是嗔等；这些法本身就是涅槃。

由于愚痴，［它们］才具有轮回之相；没有愚痴的轮回，就是涅槃；菩提心就是涅槃，［是］胜义与世俗的自性。

【按】这一节出自《喜金刚续》第二品第四章前后："离开轮回，就没有涅槃""轮回就是色声等……这些法本身就是涅槃，由于愚痴而成为轮回之相"。这是大手印"轮涅无二"最重要的续部经证之一，与《真如十颂广释》第三节所引龙树"若彻底了知轮回本身，就称为涅槃"的意思一致。第一句藏文"དེ་ལྟར་འཁོར་བ་དེ་ཉིད་དོ"（这样，轮回本身就是），句子没有说完，这里依下文补"涅槃"，存疑。

## 十六、俱生；空悲无别的菩提心（第 185–196 句）

```
འདོད་ཆགས་ཞེ་སྡང་མེད་ཅིང་གཏི་མུག་མེད། །
ཕྲག་དོག་མེད་ཅིང་སེར་སྣ་མེད། །
ང་རྒྱལ་མེད་ཅིང་ལྟ་བ་མེད། །
སྒོམ་པ་པོ་དང་བསྒོམ་པ་མེད། །
སྣ་ཚོགས་ལྷན་ཅིག་སྐྱེས་པ་རླབས་བྲལ་བ། །
རང་བཞིན་ལྷན་ཅིག་སྐྱེས་ཞེས་བརྗོད། །
ཐམས་ཅད་གཅིག་པའི་སྡོམ་པ་ནི། །
རྣལ་འབྱོར་སྙིང་རྗེའི་ཐབས་སུ་འགྱུར། །
ཕྱག་རྒྱ་རྒྱུ་དང་རྣམ་པར་བྲལ། །
སྟོང་ཉིད་སྙིང་རྗེ་དབྱེར་མེད་པ། །
བྱང་ཆུབ་སེམས་ཞེས་བྱ་བར་བརྗོད། །
ཆོས་ཀྱི་ཕྱག་རྒྱ་བསྟན་པའོ། །
```

没有贪，没有嗔，也没有痴；没有嫉妒，也没有悭吝；没有我慢，也没有见；没有修者，也没有所修。

种种之中的俱生，远离波浪，被称为"自性俱生"。

一切合一的律仪，成为瑜伽与悲心的方便；手印远离了因，空性与悲心无别，被称为"菩提心"。

——法手印开示完毕。

【按】"远离波浪"（rlabs bral ba），比喻俱生如无波的大海，不被分别的波浪所动。"一切合一的律仪"（thams cad gcig pa'i sdom pa），"律仪"（saṃvara）在母续中有"总摄、和合"之义，见第二节按语。"手印远离了因"一句，意思不很清楚，可能是说法手印超越了因果的造作，存疑。"空性与悲心无别，被称为菩提心"，与《真如十颂广释》第二十八节所说"空性与悲心无别的胜义菩提心"完全一致。

## 十七、大手印：无念诵、无坛城（第 197–215 句）

```
སྔགས་བཟླས་དཀའ་ཐུབ་མེད་ཅིང་སྦྱིན་སྲེག་མེད། །
དཀྱིལ་འཁོར་མེད་ཅིང་དཀྱིལ་འཁོར་བ་ཡང་མེད། །
དེ་ནི་སྔགས་བཟླས་དཀའ་ཐུབ་སྦྱིན་སྲེག་ཡིན། །
དེ་ནི་དཀྱིལ་འཁོར་བ་དང་དཀྱིལ་འཁོར་ཉིད། །
མཉམ་པ་ཉིད་དུ་སེམས་ནི་འདུས་པའི་རང་བཞིན་ནོ། །
```

没有念诵密咒，没有苦行，没有火供；没有坛城，也没有坛城中的［本尊］。那［心性］就是念诵密咒、苦行与火供；那就是坛城中的［本尊］，就是坛城本身。心在平等性中，就是总集的自性。

```
དམ་པའི་དགའ་བ་དངོས་དང་དངོས་མེད་དངོས་པོར་ལྡན་པ་མེད། །

ཤེས་རབ་རིགས་པ་འདི་ཡིས་ནི། །

殊胜的喜，没有事物与非事物，不具有事物；没有身体，没有所取，也没有能取；没有肉与血，没有粪与尿；没有不净，没有愚痴，也没有净地与清净。

【按】这一节出自《喜金刚续》第一品第十章、第二品第五章前后，是大手印部分的开始：真正的念诵、苦行、火供、坛城，就是心性本身；俱生的大乐中没有能取所取、没有六根六境，乃至没有心与心所。

"如是而去，又如是而去"（de bzhin nyid gshegs），是"如来"（tathāgata）一词的字义解释：tathā（如是、真如）+ gata（去、证达）。"心在平等性中，就是总集的自性"（mnyam pa nyid du sems ni 'dus pa'i rang bzhin），"总集"可能是"密集"（samāja）之意，即诸佛总集，存疑。

འཇུག་པས་ཁྱབ་འཇུག་ཉིད་དུ་བརྗོད། །

ཐམས་ཅད་བདག་ཉིད་གནས་པ་ཀུན། །
རང་རིག་པ་ཡི་ཡེ་ཤེས་འདི། །
ངག་གི་སྤྱོད་ཡུལ་ལམ་ལས་འདས། །
བྱིན་གྱིས་བརླབས་པའི་རིག་པ་གང་། །
ཀུན་མཁྱེན་ཡེ་ཤེས་དེ་རང་བཞིན། །
```

没有修者，也没有所修；没有本尊，也没有密咒；密咒与诸本尊，安住于远离戏论的自性中。

毗卢遮那、不动、不空成就、宝生、无量光、具勇者；梵天、遍入天、湿婆，一切觉者，也同样被宣说。

因为涅槃，所以是梵天；［因为］觉醒，所以是佛；因为遍入，所以说为遍入天；因为恒常吉祥，所以是湿婆；［因为］一切的体性都安住，［所以是］一切。

这自证的智慧，超越了言语行境之道；那加持的觉知，就是一切智智的自性。

【按】这一节出自《喜金刚续》第一品第一章前后：五方佛（毗卢遮那、不动、不空成就、宝生、无量光）以及"梵天、遍入天、湿婆"等名，都被重新解释为俱生智慧的异名——"梵天"（Brahmā）是涅槃，"佛"（Buddha）是觉醒，"遍入天"（Viṣṇu）是遍入，"湿婆"（Śiva）是恒常吉祥。这是密续中以佛教义理重新诠释外道神名的方式，并不是承认外道的神。"无量光"，藏文作"འཁོར་འདས"（轮回涅槃），从五方佛的名单看，应是指无量光（阿弥陀佛），可能有误写，存疑。"具勇者"（snying stobs can），即金刚萨埵（sattva），存疑。

## 十九、安乐、生佛不二与上师的方便（第 232–245 句）

གང་ཕྱིར་འཆི་བའི་བདེ་བ་འདི། །

```

就像从［他］那里获得安乐，那安乐要自己去享受；因为这是死亡的安乐，它的安乐被说为禅定。

众生与佛是同一的，然而被客尘的垢染所遮蔽；舍弃了这些，以本尊本身，［就能］成佛，对此没有怀疑。

这样，那真性不是真实也不是虚妄，不是他人所能言说的俱生，从任何地方都得不到；要从依止上师的时机与方便中，以自己的福德来了知。

【按】"众生就是佛，然而被客尘的垢染所遮蔽，除去这些，就是佛"，是《喜金刚续》第二品第四章的名句（"sattvā buddhā eva kiṃtu āgantukamalāvṛtāḥ"），是如来藏与大手印最重要的续部经证之一。

"俱生不是他人所能言说的，从任何地方都得不到，要从依止上师的时机与方便中，以自己的福德来了知"，也是《喜金刚续》的名句，是大手印"依上师加持与自己的福德而证悟"的根本经证，与梅纪巴《真如十颂》"没有上师口诀庄严的中观只是中等"、《真如十颂广释》"口诀只在上师的口中"相呼应。

སངས་རྒྱས་མ་ཡིན་སེམས་ཅན་མེད། །

དེ་ལྟར་བདེ་བ་མི་ཤེས་སོ། །

无知的世间，就像吃了猛毒而昏迷；舍弃愚痴、了知真性的人，就会断除忧苦。

同样，了知解脱方便的人，了知喜金刚之后，无明等就不能执取他，愚痴等也不能束缚他；以自证来真实观察。

没有不是佛的众生：地狱、饿鬼、畜生，以及天、阿修罗、人，乃至粪尿中的虫等，本来就是常乐的自性；［然而］连天与阿修罗也不能这样了知安乐。

在任何世界中，都不能在别处找到佛；心性就是圆满的佛，不能开示有别处的佛。

旃陀罗、竹匠等，以及心存杀害的人，他们若了知喜金刚，也会成就，对此没有怀疑。

愚者被无知所遮蔽，不能了知这条道路；那愚痴就是轮回，堕入六道三有的牢狱。

金刚藏，大悲者！得到喜金刚之方便的人，若清净诸境，就会获得无上的果位。

【按】这一节大多是《喜金刚续》的原句。其中最重要的是："没有不是佛的众生""心性就是圆满的佛，不能开示有别处的佛"，这是大手印"心性即佛"的根本经证。"旃陀罗、竹匠等，以及心存杀害的人，若了知喜金刚也会成就"，是续中强调此法门不拣根器、即使是被社会最轻视或造重罪的人也能成就，并不是认可杀害等恶行。"金刚藏"（rdo rje snying po），是《喜金刚续》中请法的菩萨，世尊对他宣说此续。

"以自证来真实观察"一句，藏文作"རང་རིག་གིས་ནི་ཡང་དག་རྟོག"，rtog 可以是"观察"，也可以是"证悟"（rtogs）的误写，存疑。"乃至粪尿中的虫等，本来就是常乐的自性"一句，藏文作"རྟག་ཏུ་བདེ་བའི་རང་བཞིན་ལས"（从常乐的自性中），与下句"连天与阿修罗也不能这样了知安乐"的衔接不很清楚，存疑。

## 二十一、事物的束缚与嘿噜嘎的修习（第 278–290 句）

```
དངོས་པོའི་འཆིང་བས་བཅིངས་བ་ནི། །
དེ་ཡོངས་ཤེས་པས་གྲོལ་བར་འགྱུར། །
དངོས་པོ་མེད་པ་ཡོངས་ཤེས་པས། །
དངོས་པོ་བསྒོམ་མེད་ཤེས་རབ་ཅན། །
དངོས་པོ་བསྒོམ་པ་ཡོངས་ཤེས་བྱ། །
དེ་ལྟར་ཧེ་རུ་ཀ་བསྒོམ་པ། །
ཡེ་ཤེས་ཆེན་པོ་ལུས་ལ་གནས། །
རྟོག་པ་ཐམས་ཅད་ཡང་དག་སྤངས། །
དངོས་པོ་ཀུན་ལ་ཁྱབ་པ་སྟེ། །
ལུས་ལ་གནས་ཀྱང་ལུས་སྐྱེས་མིན། །
ཆོས་འབྱུང་ལས་སྐྱེས་ཡེ་ཤེས་ཡིན། །
མཁའ་མཉམ་དེ་ཡི་ཐབས་དང་ལྡན། །
དེ་ལས་འཇིག་རྟེན་གསུམ་པོ་སྐྱེད། །
```

被事物的束缚所束缚的，由彻底了知它而解脱；由彻底了知非事物，具慧者就不修事物；［应当］彻底了知事物的修习。

这样修习嘿噜嘎：大智慧住于身中，彻底远离一切分别，遍于一切事物；虽住于身中，却不是身所生；是从法生中生起的智慧，与虚空相等，具有它的方便；从它生起三界，［它是］方便与智慧的自性。

【按】"大智慧住于身中……虽住于身中，却不是身所生"一偈，是《喜金刚续》第一品第一章的名句，第七节已摘引其上句。"法生"（chos 'byung，dharmodaya），见第二节及《灌顶教示难释》第四节按语，是表示空性、智慧之源的象征。

"由彻底了知非事物，具慧者就不修事物；［应当］彻底了知事物的修习"三句，意思是：既不执事物而修，也要了知"修事物"本身的真性，存疑。

## 二十二、平等一味（第 291–314 句）

```
ཐབས་དང་ཤེས་རབ་རང་བཞིན་ཏེ། །
དམན་དང་འབྲིང་པོ་མཆོག་དང་ནི། །
གཞན་རྣམས་གང་རྣམས་དེ་རྣམས་ནི། །
དེ་དག་ཐམས་ཅད་མཉམ་ཉིད་དུ། །
དེ་ཉིད་བསྒོམ་པས་བལྟ་བར་བྱ། །
དམན་པ་ཕྲ་བའི་དངོས་པོ་སྟེ། །
མཆོག་ནི་སྲིད་པར་བརྗོད་པ་ཡིན། །
འབྲིང་པོ་གཉིས་ལ་སྤངས་པ་ལས། །
གཞན་རྣམས་ཤེས་པའི་དབང་པོ་དྲུག །
གང་རྣམས་དེ་རྣམས་གཡོ་དང་བརྟན། །
མཉམ་པ་མཚུངས་པའི་རང་བཞིན་ཏེ། །
རོ་མཉམ་དེ་ཉིད་བསྒོམ་པར་བྱ། །
མཉམ་པ་མཚུངས་པར་བརྗོད་པ་སྟེ། །
དེ་ཡི་འཁོར་ལོ་རོར་བཤད་དོ། །
རོ་མཉམ་པ་ཡི་ངོ་བོ་རུ། །
དོན་འདི་ཡིས་ནི་བརྗོད་པ་ཡིན། །
```

下、中、上，以及其他，以及凡是［所有的］，要以修习那真性，把它们一切都看作平等。

"下"，就是微细之物；"上"，被说为三有；舍弃了这两者的就是"中"；"其他"，是六种认知之根；"凡是"，就是动与不动。

平等，是相同的自性，要修习那一味；平等说为相同，它的轮说为味；在一味的本体中，以这意义而宣说。

【按】这是《喜金刚续》中对"下、中、上、其他、凡是"五个词的解释，要把它们一切都看作平等一味。"它的轮说为味"（de yi 'khor lo ror bshad），意思不很清楚，存疑。

```
འགྲོ་བ་ཐམས་ཅད་ང་ལས་སྐྱེས། །
ང་ལས་གནས་གསུམ་པོ་ཡང་བྱུང་། །
ང་ཡིས་འདི་དག་ཐམས་ཅད་ཁྱབ། །
ང་ལས་གཞན་པའི་འགྲོ་མ་མཐོང་། །
དེ་ལྟར་ངེས་ཤེས་རྣལ་འབྱོར་པ། །
ཤིན་ཏུ་མཉམ་གཞག་གང་གོམས་ན། །
བསོད་ནམས་ཆུང་བའི་མི་ཡིས་ཀྱང་། །
དེ་ཉིད་འགྲུབ་འགྱུར་ཐེ་ཚོམ་མེད། །
```

一切众生都从我而生，三处也从我而生；这一切都被我所遍满，我看不到有别于我的众生。

这样决定了知的瑜伽士，若串习极深的等持，即使是福德微小的人，也会成就那真性，对此没有怀疑。

【按】"一切众生都从我而生……我看不到有别于我的众生"，是《喜金刚续》第一品第八章的名句（"mayā vyāptam idaṃ sarvaṃ nānyaṃ paśyāmi jagat"）。这里的"我"，是指俱生智慧本身，见第十二节按语。"三处"（gnas gsum），一般指三界或天上、地上、地下三处，存疑。

## 二十三、一切行为中不断；自证清净（第 315–342 句）

```
ཡན་ལག་ཇི་སྙེད་བསྒྱུར་བ་དང་། །
རབ་ཏུ་རྒྱས་པར་སྨྲ་བ་རྣམས། །
དེ་སྙེད་སྔགས་དང་ཕྱག་རྒྱ་རྣམས། །
ཧེ་རུ་ཀ་དཔལ་གོ་འཕང་གནས། །
བཟའ་དང་བཏུང་དང་དེ་བཞིན་ཁྲུས། །
འགྲོ་བའམ་ཉལ་བས་བསམ་པར་བྱ། །
དེ་རྙེད་དེ་ནི་རྒྱུན་མི་འཆད། །
ཕྱག་རྒྱ་ཆེན་པོ་མངོན་འདོད་པ། །
```

凡是转变肢体以及广说的种种密咒与手印，都安住于吉祥嘿噜嘎的果位中。

吃、喝、同样洗浴、行走或睡卧时，都要［如此］思惟；得到它之后，那就不会间断——［这是］希求大手印的人［所应作的］。

【按】"吃、喝、洗浴、行走、睡卧时都要思惟，得到它之后就不会间断"，与《真如十颂广释》第三十一节所引"行、住、坐、卧时，都安住于等持之中"、第三十四节所引"一刹那也没有别的心"的意思相通，是大手印在一切行为中不离证悟的要点。"转变肢体"（yan lag ji snyed bsgyur ba），可能是指手印等的结印动作，存疑。

```
གང་ཕྱིར་བརྟན་དང་གཡོ་བའི་དངོས། །
རྩྭ་ལྕུག་འཁྲི་ཤིང་ལ་སོགས་པ། །
བདག་གི་དངོས་པོའི་རང་བཞིན་ལས། །
དམ་པའི་དེ་ཉིད་ངེས་པར་བསྒོམ། །
རང་རིག་པ་ཡིས་བདག་ཉིད་དག །
དག་པ་གཞན་གྱིས་རྣམ་མི་གྲོལ། །
ཡུལ་རྣམས་དག་པའི་རང་བཞིན་པས། །
རང་རིག་པ་ཡི་བདེ་བ་མཆོག །
གཟུགས་སོགས་ཡུལ་དང་གཞན་དག་ཀྱང་། །
རྣལ་འབྱོར་པ་ལ་གང་སྣང་བ། །
དེ་ཀུན་དག་པའི་རང་བཞིན་ཏེ། །
འགྲོ་བ་སངས་རྒྱས་རང་བཞིན་ཉིད། །
གང་དང་གང་གིས་འཇིག་རྟེན་བཅིངས། །
དེ་ཡིས་བཅིངས་པ་ལས་གྲོལ་འགྱུར། །
དེ་ཉིད་ཤེས་པས་འཇིག་རྟེན་གྲོལ། །
དེ་ཉིད་རྣམ་སྤངས་གྲོལ་བ་མིན། །
དེ་ཕྱིར་གཟུགས་མེད་སྒྲ་དྲི་མེད། །
རོ་མེད་སེམས་མེད་རྣམ་པར་དག །
རེག་མེད་ཆོས་མེད་རྣམ་པར་གྲོལ། །
དག་པའི་རང་བཞིན་འགྲོ་བས་ཤེས། །
```

因为动与不动的事物、草、灌木、藤蔓等，都来自我自己之事物的自性，所以要决定地修习那殊胜的真性。

以自证，自身就是清净的；不能以别的清净而解脱。因为诸境都是清净的自性，所以自证的安乐是最胜的。

色等诸境，以及其他凡是对瑜伽士显现的，那一切都是清净的自性，因为众生就是佛的自性。

世间被什么所束缚，就从那束缚中解脱；了知那真性，世间就解脱；舍弃那真性，就不是解脱。

所以，没有色，没有声与香，没有味，没有心，完全清净；没有触，没有法，完全解脱——众生要了知清净的自性。

【按】这一节出自《喜金刚续》第一品第九章前后，说明诸境、诸蕴本来清净，以自证了知这清净，就是解脱，不需要别的清净法。"世间被什么所束缚，就从那束缚中解脱"，是下一节"以毒攻毒"的总纲。"舍弃那真性，就不是解脱"一句，藏文"དེ་ཉིད་རྣམ་སྤངས་གྲོལ་བ་མིན"，意思是离开对那［束缚之物］真性的了知，就没有解脱。

## 二十四、以毒攻毒的"逆修"（第 343–369 句）

```

རྣམ་རྟོག་སོ་སོར་རྟོག་པ་ཡིན། །
ཇི་ལྟར་རྣ་བར་ཆུ་བླུགས་པ། །
ཆུ་གཞན་གྱིས་ནི་དབྱུང་བར་བྱ། །
དེ་བཞིན་དངོས་པོའི་རྣམ་རྟོག་ཀྱང་། །
རྣམ་པར་ངེས་པར་སྦྱོང་བར་བྱེད། །
ཇི་ལྟར་མེ་ཡིས་ཚིག་པ་ལ། །

【按】这一节是《喜金刚续》第二品第二章的著名段落（"以毒攻毒""世间被贪欲所束缚，也以贪欲而解脱，这样的逆修，佛教徒与外道都不了知"，约第 2.2.46–51 颂）。"逆修"（bzlog pa'i bsgom pa，viparītabhāvanā），是说不舍弃烦恼，而以了知烦恼真性的方便，使烦恼本身成为解脱之道。"以风来摧毁风"，是印度医学的说法：风病者吃产风的豆类，以同类相治。

这里的关键在"若具有方便"与"了知毒之真性"：并不是放纵烦恼就能解脱，而是在证悟真性、具足上师所传方便的前提下，烦恼才能转为道用；正如《真如十颂广释》第三十五节所说，"捉蛇人与蛇嬉戏而不被咬"，前提是已掌握驯蛇的方法。这属于无上瑜伽续的甚深见地与修法，只能依具德上师的灌顶与口授来理解，不可照字面模仿，更不可以此为放纵烦恼的借口。

## 通篇连读

敬礼持金刚！我以一切身语意之事，恭敬地首先敬礼殊胜的上师，然后同样敬礼山居者。在《喜金刚》母续中，如来所宣说的业手印等的修法，由具种姓的金刚手加以解释，为了让弟子们理解而写下。

一切佛的律仪，安住于"诶旺"之中；真实的灌顶，就是唯一之相的大乐。瓶灌顶是第一，殊胜的秘密灌顶是第二，智慧智灌顶是第三，第四也同样如此。"诶"的美好形状，中央以"旺"来庄严，是一切安乐的处所，是诸佛的宝箧；从它生起喜，以刹那的区分而有差别；刹那的智慧，就是安乐的智慧，安住于"诶旺"之中。

种种、异熟、坏相与离相，瑜伽母要这样真实证悟四刹那。种种，说为种种相，即拥抱、亲吻等；异熟与它相反，是享受安乐的智慧；坏相，说为观察，即"我已享受了安乐"；离相，是在这三者之外，远离了贪与离贪。初喜是种种，胜喜是异熟，离喜之喜是坏相，俱生喜是离相。初喜、胜喜、离喜之喜都还是众生，俱生则三者都不可得。

在莲花的虚空中、金刚的花蕊之处，心进入宝珠之中而观看，所生起的智慧，是不可言说的智慧之相。阿阇黎、秘密、智慧，第四也同样如此，以四灌顶之数，喜等也要依次了知。笑之喜是阿阇黎，注视是秘密灌顶，拥抱是智慧智，续也以两者的两者相合为喻；由此成就众生的悉地，灌顶被说为四种。因为以此而灌注、洗涤，所以称为灌顶。

在舍弃种种的刹那，真实获得胜喜。导师开示："大勇士啊，这是大乐的真实之相；乃至未获得菩提之间，为了众生的利益而持金刚。"这本身就是大智慧，遍住于一切身中。菩提心成为月亮，具有十五分的体性；以元音之相为大乐，瑜伽母就是它的分；因为不作世俗意义的作用，所以努力舍弃一切边；不是那第十六分，而是俱生的本体，在离喜之初、胜喜之末。

从空中出生的空性，就是嘿噜嘎：吉祥是无二的智慧，嘿是因等的空性，噜是远离聚合，嘎是不住于任何处。世尊是白精之相，他的安乐被说为佛母。这远离一与多，在一刹那中就是胜喜；是无二与二的方式，事物与非事物之体性的主尊；遍于不动与动而安住，显现为如幻之相本身。

坛城、轮等方便以及那方便，恒常决定地解脱。坛，说为心要；因为把菩提心取为大乐，所以是坛城；由于聚合，所以说为坛城。轮的聚集，就是虚空界，就是对境等的受用；金刚与莲花结合的方便，能使人证悟它的安乐。要在虚空界中观想婆伽，在中央依照轮的前行的方式，观想诸本尊如何出现；在名为虚空界的莲花上，这里的婆伽说为智慧，这里所修的是等入，它的安乐被说为轮。大手印的灌顶，就像大乐的真性，以它的威力，坛城不会在别处出现。

黑色是乐，黄色是乐，红色是乐，白色是乐，绿色是乐，青色是乐，一切动与不动都是乐；智慧是乐，方便是乐，一切处的莲花所生也是乐；事物是乐，非事物也是乐，金刚萨埵被说为大乐。

被懒惰所摧毁的人与愚痴的人，都不认识我。我安住于金刚后妃殊胜的婆伽——极乐之中，是"诶"字形状之相，是诸佛的宝箧。说法者是我，法也是我，具有眷属的听法者也是我；众生的导师、所修者是我；世间与出世间是我；俱生的、他者的自性，也是我。

由波拉与迦柯拉的结合，从触而生坚硬之物，地就从它而生起；由菩提心的融化，生起水界；从摇动而生火；行动称为风；安乐就是虚空界。被这五者所围绕，所以这种安乐并不是真性；大种所生的安乐不是俱生，凡是俱生的本体，才被确定地说为俱生。——业手印开示完毕。

自性既然不生，一切就不是真实，也不是虚妄；瑜伽母们要了知，一切都像水中的月亮。就像由钻木的下木、上木以及人手的转动，火忽然生起；那火不在上木中，不在下木中，也不在人的手中，从一切方面去寻找，都不住在任何一处；那火既不是真实，也不是虚妄。要这样去思惟一切法。

这样，轮回本身就是涅槃；离开了对轮回的证悟，在别处不能了知涅槃。轮回就是色与声等，就是受等，就是诸根，就是嗔等；这些法本身就是涅槃。由于愚痴，它们才具有轮回之相；没有愚痴的轮回，就是涅槃；菩提心就是涅槃，是胜义与世俗的自性。

没有贪，没有嗔，没有痴；没有嫉妒，没有悭吝；没有我慢，没有见；没有修者，也没有所修。种种之中的俱生，远离波浪，被称为自性俱生。一切合一的律仪，成为瑜伽与悲心的方便；手印远离了因，空性与悲心无别，被称为菩提心。——法手印开示完毕。

没有念诵密咒，没有苦行，没有火供，没有坛城，也没有坛城中的本尊；那心性就是念诵、苦行与火供，就是坛城中的本尊与坛城本身；心在平等性中，就是总集的自性。殊胜的喜，没有事物与非事物；没有身体，没有能取所取；没有肉与血，没有粪与尿；没有不净，没有愚痴，也没有净地与清净。自性中没有色与见，没有声与听，没有香与嗅，没有味与尝者，没有所触与触，没有心，也没有心所生。吉祥者如是而去，又如是而去，以这智慧的正理，称为如来。

没有修者，也没有所修；没有本尊，也没有密咒；密咒与诸本尊，安住于远离戏论的自性中。毗卢遮那、不动、不空成就、宝生、无量光、具勇者，以及梵天、遍入天、湿婆，一切觉者，也同样被宣说：因为涅槃，所以是梵天；因为觉醒，所以是佛；因为遍入，所以是遍入天；因为恒常吉祥，所以是湿婆；因为一切的体性都安住，所以是一切。这自证的智慧，超越了言语行境之道；那加持的觉知，就是一切智智的自性。

那安乐要自己去享受，它的安乐被说为禅定。众生与佛是同一的，然而被客尘的垢染所遮蔽；舍弃了这些，以本尊本身就能成佛，对此没有怀疑。这样，那真性不是真实也不是虚妄；俱生不是他人所能言说的，从任何地方都得不到，要从依止上师的时机与方便中，以自己的福德来了知。——大手印开示完毕。

无知的世间，就像吃了猛毒而昏迷；舍弃愚痴、了知真性的人，就会断除忧苦。同样，了知解脱方便的人，了知喜金刚之后，无明等不能执取他，愚痴等不能束缚他，他以自证来真实观察。没有不是佛的众生：地狱、饿鬼、畜生、天、阿修罗、人，乃至粪尿中的虫等，本来就是常乐的自性，然而连天与阿修罗也不能这样了知安乐。在任何世界中，都不能在别处找到佛；心性就是圆满的佛，不能开示有别处的佛。旃陀罗、竹匠等，以及心存杀害的人，若了知喜金刚，也会成就，对此没有怀疑。愚者被无知所遮蔽，不能了知这条道路；那愚痴就是轮回，堕入六道三有的牢狱。金刚藏，大悲者！得到喜金刚之方便的人，若清净诸境，就会获得无上的果位。

被事物的束缚所束缚的，由彻底了知它而解脱；由彻底了知非事物，具慧者就不修事物，而彻底了知事物的修习。这样修习嘿噜嘎：大智慧住于身中，彻底远离一切分别，遍于一切事物；虽住于身中，却不是身所生；是从法生中生起的智慧，与虚空相等，具有它的方便；从它生起三界，它是方便与智慧的自性。

下、中、上、其他、凡是，要以修习那真性，把它们一切都看作平等：下是微细之物，上是三有，舍弃这两者的是中，其他是六种认知之根，凡是就是动与不动。平等是相同的自性，要修习那一味。一切众生都从我而生，三处也从我而生；这一切都被我所遍满，我看不到有别于我的众生。这样决定了知的瑜伽士，若串习极深的等持，即使是福德微小的人，也会成就那真性，对此没有怀疑。

一切密咒与手印，都安住于吉祥嘿噜嘎的果位中。吃、喝、洗浴、行走或睡卧时，都要如此思惟；得到它之后，就不会间断——这是希求大手印的人所应作的。动与不动的事物、草、灌木、藤蔓等，都来自我自己之事物的自性，所以要决定地修习那殊胜的真性。以自证，自身就是清净的，不能以别的清净而解脱；因为诸境都是清净的自性，所以自证的安乐是最胜的。色等诸境以及凡是对瑜伽士显现的，一切都是清净的自性，因为众生就是佛的自性。世间被什么所束缚，就从那束缚中解脱；了知那真性，世间就解脱；舍弃那真性，就不是解脱。所以，没有色，没有声与香，没有味，没有心，完全清净；没有触，没有法，完全解脱——众生要了知清净的自性。

一切人因一小块毒而死亡，了知毒之真性的人，就以毒来摧毁毒。就像对被风病所侵的人要给他吃豆子，以风来摧毁风，要把它看作对治之药。以三有本身来清净三有。就像水灌进了耳朵，要用别的水把它引出来，事物的分别也要以分别来决定地清净。就像被火烧伤的人，又要用火来烘烤，被贪欲之火烧伤的人，要以贪欲之火来烘烤。众生以什么可怕的业而被束缚，若具有方便，就以那业本身而从三有的束缚中解脱。世间被贪欲所束缚，也以贪欲而解脱；这样的逆修，一般的佛教徒与外道都不了知。——三昧耶手印开示完毕。

摘集了具足业手印等的金刚句，以我所获得的福德，愿世间都成为持金刚！
