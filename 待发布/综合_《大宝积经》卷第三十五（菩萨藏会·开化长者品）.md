唐·三藏法师玄奘 奉诏译

## 菩萨藏会第十二之一

【按】本会异译为宋·法护等译《佛说大乘菩萨藏正法经》（T0316，四十卷），《大正藏》注为[No. 310(12)]。本会诸品与该经诸品次第相应，本品《开化长者品》相当于该经《长者贤护品》（卷一至卷四），该经“贤守”作“贤护”。

### 开化长者品第一

#### 贤守长者见佛

我是这样听说的：有一个时候，薄伽梵在室罗筏国度过雨安居，三个月后举行自恣，做好衣服，与大苾刍众一千二百五十人在一起，游行教化诸国。这位薄伽梵成就广大微妙的名称，出现于世间，为诸天与人所赞颂，就是如来、应、正等觉、明行圆满、善逝、世间解、无上丈夫、调御士、天人师、佛、薄伽梵。他深住于自证，具足神通，威德映蔽诸天、世间、魔王、梵王、阿素洛等。他常为众生宣说微妙之法，开示初善、中善、后善，文义巧妙，纯一圆满，清白梵行。那时，四部众、国王大臣、种种外道、沙门、婆罗门，以及诸长者、天、龙、药叉、人非人等，都以无量上妙的衣服、饮食、卧具、医药种种供具奉献如来。

【按】“雨安居”，元、明本作“而安居”。“种种外道”之“外道”，宋本作“妙道”。

那时，世尊被大众围绕，受到供养、恭敬、尊重、赞叹，渐次游行到摩揭陀国，来到王舍大城，住在鹫峰山。那时王舍城中有一位大长者，名叫贤守，他已曾亲近觐见过去诸佛，宿世种植善根，福报感应通达，出身大族，家中大富，资产财宝无不具足。那时这位长者听说：大沙门出自释氏王宫，证得无上正等菩提，与大众来游此国；那位佛世尊有这样广大的名称出现于世间，十号具足，成就神通智慧，宣说微妙之法，乃至圆满清白梵行。那时这位长者这样思惟：“我现在应当前往鹫峰山王，为了奉见那位如来；我若得见，必定获得善利。”这样想后，便与五百位长者出了王舍城，将要前往佛所。

【按】“摩揭陀”之“揭”，宋、元、明、宫本作“竭”。

那时，世尊在一日的初分，披上僧伽胝，执持衣钵，诸苾刍僧侍从围绕，在大众之前威仪严整，进止安详，以正智而行，顾视与屈伸都端严殊异，为了教化众生而示现乞食之法，正要入城，走在半路上。那时贤守等五百长者远远望见如来：威严超群挺拔，为大众所乐于瞻观，成就金色之身，具三十二种大丈夫相，诸根寂定，神思恬淡，证得上胜的调顺寂止，摄护诸根如大龙象，清净无扰如澄澈的泉池；双足踏在七宝所成、有百千亿花瓣的红莲花上，为无数天、人、药叉所供养，天上降下大天花散在如来身上，那些花如水流般铺满地面。诸长者见到世尊以无量百千功德庄严从远处走来，赞叹从未有过，以清净心来到如来之所，顶礼佛足，退住一面。

【按】“进止安庠”之“庠”，圣本作“详”。“众所乐观”之“观”，宫本作“见”。

那时，贤守等五百长者对佛说：“世尊！真是从未有过。如来的神力映夺天仙、吉祥天、魔王、梵天；如来的威德具大名称，圆光与妙色遮蔽一切大众。世尊的体相如大金山，容貌端严，无与等同。世尊成就一切世间极为希奇之法。我想世尊的威德如此，当初是观察到什么样的相，而弃舍在家之法，觉悟大菩提的呢？”那时，贤守长者即在佛前说颂道：

```
我昔曾闻最胜尊，
吉祥妙色大名称，
今覩威光胜所闻，
如真金像备众德。
如来色像喻金山，
高广严净观无厌，
威德庄严苾刍众，
犹如满月处众星。
世尊顶相无能见，
高显映发逾山王，
顶髻周圆渐次敛，
其相平偃犹天盖。
绀发软腻而右旋，
如安缮色帝青宝，
鲜净光逾孔雀项，
我今瞻仰无厌足。
面貌端严额平正，
眉相皎净若天弓，
白毫映彻无瑕秽，
光洁照曜如星王。
发喜净眼甚微妙，
众覩皆生欣乐心，
我今奉观无暂舍，
顶礼净眼世间依。
```
（大意：我往昔曾听闻最胜尊吉祥妙色、具大名称，如今亲睹其威光更胜所闻，如同真金之像，具备众德。如来的色像可比金山，高广庄严清净，观之无厌；以威德庄严苾刍众，犹如满月处在众星之中。世尊的顶相无人能见其顶，高显映发，超过山王；顶髻周圆，渐次收敛，其相平展覆盖，犹如天盖。绀青色的头发柔软细腻而右旋，如安缮那色的帝青宝，鲜明洁净，光泽胜过孔雀颈项，我如今瞻仰，无有厌足。面貌端严，额头平正，眉相皎洁清净，好像天弓；白毫映彻，无有瑕秽，光洁照耀，如同星王。令人发喜的清净之眼极为微妙，大众见了都生欣乐之心；我如今奉观，片刻不舍，顶礼世间所依的清净之眼。）

【按】“渐次敛”之“敛”，《大正藏》作“歛”，CBETA依高丽藏作“敛”，今从之。

```
鼻相高平修且直，
渐广圆成如铸金，
唇相丹晖极清净，
喻频婆果末尼等。
妙齿鲜白含光润，
等鹤牛乳莲华根，
坚密齐平极明净，
调顺奢摩他所感。
齿及随齿根深固，
龂际上下皆齐整，
佛牙光白最超胜，
如彼鴈行王处中，
善逝广长之舌相，
覆面薄净如莲华，
赤铜赤色末尼宝，
含晖皎镜如初日，
世尊耳相极端严，
梵世天人不闻见，
乔答摩种狻猊颔，
无畏犹如师子王。
我观善逝咽喉相，
能引世间甘露味，
清净映彻无瑕秽，
具大神力不思议。
颈前横约修且直，
处中都无纤杂文，
现人中胜天中天，
恒食味中第一味。
```
（大意：鼻相高挺平正，修长而端直，渐渐宽广，圆满成形，如同铸金；唇相丹红有光，极为清净，可比频婆果与末尼宝。美妙的牙齿鲜白而含光润，如同白鹤、牛乳、莲花之根，坚固紧密，齐平而极为明净，这是由调顺的奢摩他所感得。牙齿与随齿的根部深固，齿龈上下都整齐；佛牙光白，最为超胜，如同雁行中的雁王居于中央。善逝广长的舌相，覆盖面部，薄而清净如莲花，如赤铜色、赤色的末尼宝，含光皎洁如镜，如初升的太阳。世尊的耳相极为端严，梵世天人从未闻见；乔答摩种族的狻猊之颔，无畏犹如狮子王。我观善逝的咽喉之相，能引出世间的甘露之味，清净映彻，无有瑕秽，具大神力，不可思议。颈前的横纹修长而端直，中间没有一丝杂纹，显现为人中最胜、天中之天，恒常得食味中第一之味。）

【按】“修且直”之“且”，《大正藏》作“旦”，宫本及高丽藏作“且”，今从之。“含光润”之“含”，宋、宫本作“金”，明本作“舍”。“龂际”之“龂”，《大正藏》作“断”，CBETA依高丽藏作“龂”，今从之。“纤杂文”之“纤”，《大正藏》作“孅”，今依高丽藏作“纤”。

```
肩膊充圆悉成满，
胸臆雄猛威容盛，
人中尊相世未闻，
如山顶日光流照。
手足两肩及项后，
七处光净恒平满，
修臂𦟛圆象王鼻，
双掌垂下摩于膝。
上身广厚如兽王，
瞿陀树相周圆满，
那罗延力合成身，
具足大力及忍力。
无垢身毛皆上靡，
随现一孔一毛生，
烟尘不污如莲华，
右旋相成而细软。
我昔传闻隐密相，
阴藏深如天马王，
髀腨周圆渐次敛，
其相犹如天鹿王，
足厚隆起跟圆长，
手相网鞔如鴈王，
平满纤长二十指，
赤铜甲色如莲华，
双跖千辐金轮相，
光净微妙具庄严。
```
（大意：肩膊充实圆满，胸臆雄猛，威容盛大，这样的人中尊之相，世间从未听闻，如同山顶的太阳光芒流照。两手、两足、两肩以及项后，这七处光洁清净，恒常平满；修长的手臂均直圆满，如象王之鼻，双掌垂下可以摩到膝盖。上身宽广厚实，如同兽王；如尼拘陀树般周圆丰满；以那罗延之力合成其身，具足大力以及忍力。无垢的身毛都向上而靡，每一孔只生一毛，烟尘不能污染，如同莲花，右旋而成，细软柔和。我往昔传闻的隐密之相，阴藏深隐如天马王；髀与腨周圆而渐次收敛，其相犹如天鹿王；足背厚而隆起，足跟圆长；手指间有网鞔相，如雁王；平满纤长的二十指，赤铜色的指甲如莲花；双足底有千辐金轮之相，光净微妙，具足庄严。）

【按】“𦟛”字（月旁庸）先前电子文本未能显示，今据《大正藏》补出，通“傭”，意为均直圆满。“项后”之“项”，元、明本作“顶”。“网鞔”之“鞔”，元、明本作“缦”。“纤长”之“纤”，《大正藏》作“孅”，今依高丽藏作“纤”。“瞿陀树”即尼拘陀树。

```
如来游步于世间，
瞿拉坡相不相触，
去地四指蹈空行，
众宝红莲随足现，
顾视安行象王步，
进趣端肃如天主，
大圣威严无所畏，
处众逾于师子王，
妙色映蔽毘沙门，
威光超胜百千日，
梵世天人尚无等，
何况出过如来者。
行住说法度众生，
天仙龙神咸恭敬，
或散天华奏天乐，
纷然繁会满虚空。
今覩世尊大神变，
故我窃怀疑惑心，
本观何等胜功德，
出家趣于无上道？
```
（大意：如来游步于世间，双足踝互不相触，离地四指踏空而行，众宝红莲随足而现；回顾安行如象王之步，进趋端肃如同天主；大圣威严，无所畏惧，处在大众中胜过狮子王；妙色映蔽毘沙门，威光超胜百千个太阳；梵世天人尚且无与之等同的，何况超过如来的呢！行住说法，度化众生，天仙、龙、神都恭敬，或散天花，或奏天乐，纷然交会，充满虚空。如今亲睹世尊的大神变，所以我私下心怀疑惑：您当初观察到什么殊胜的义利，而出家趣向无上道？）

【按】“天仙龙神”之“仙”，宫本作“人”。“本观何等”之“本”，宫、圣本作“人”。“瞿拉坡”，梵语gulpha之音译，即足踝。

#### 世尊说出家的十种因缘

那时，世尊告诉贤守长者说：“长者应当知道，我观察世间一切众生，被十种苦事所逼迫。是哪十种？一是生苦逼迫，二是老苦逼迫，三是病苦逼迫，四是死苦逼迫，五是愁苦逼迫，六是怨恨逼迫，七是苦受逼迫，八是忧受逼迫，九是痛恼逼迫，十是生死流转的大苦所逼迫。长者！我见到这样十种苦事逼迫众生，为了证得阿耨多罗三藐三菩提，出离这样的逼迫之事，所以以清净信心舍弃释氏之家，趣向无上道。”那时世尊想重宣此义，而说颂道：

```
我观诸凡夫，闭流转牢狱，
常为生老病，众苦所逼迫。
愁忧及怨恨，死苦等所牵，
为除牢狱怖，令欣出离法。
```
（大意：我观察诸凡夫，被关闭在流转的牢狱之中，常被生、老、病等众苦所逼迫，被愁、忧以及怨恨、死苦等所牵缠；为了除去牢狱的怖畏，令他们欣乐出离之法。）

“再者，长者！我观察世间一切众生，因十种恼害而互相憎嫉。是哪十种？一是曾对我自身作不饶益之事，心生恼害；二是现在对我自身作不饶益之事，心生恼害；三是将来会对我自身作不饶益之事，心生恼害；四是曾对我所爱的人作不饶益之事，心生恼害；五是现在对我所爱的人作不饶益之事，心生恼害；六是将来会对我所爱的人作不饶益之事，心生恼害；七是曾对我所不爱的人作饶益之事，心生恼害；八是现在对我所不爱的人作饶益之事，心生恼害；九是将来会对我所不爱的人作饶益之事，心生恼害；十是对种种过失作不饶益，心生恼害。长者！我见到这样十种恼害，恼害世间一切众生，为了证得阿耨多罗三藐三菩提，出离这样的恼害之事，所以以清净信心舍弃释氏之家，趣向无上道。”那时世尊想重宣此义，而说颂道：

```
众生互憎嫉，皆由十恼生，
于我及我亲，三世俱恼害。
或于我非亲，起诸饶益相，
怨憎由此生，三世俱恼害。
第十诸过失，生长怨憎苦，
我观如是过，厌患故出家。
```
（大意：众生互相憎嫉，都由十种恼害而生：对于我以及我的亲人，三世都会恼害；或者对于并非我亲近的人，作种种饶益之事，怨憎也由此而生，三世都会恼害；第十是种种过失，生长怨憎之苦。我观察到这样的过患，因厌患而出家。）

“再者，长者！我观察世间一切众生，进入十种恶见稠林，由于种种异见，不能自己出来。是哪十种？一是我见的恶见稠林，二是有情见的恶见稠林，三是寿命见的恶见稠林，四是数取趣见的恶见稠林，五是断见的恶见稠林，六是常见的恶见稠林，七是无作见的恶见稠林，八是无因见的恶见稠林，九是不平等因见的恶见稠林，十是邪见的恶见稠林。长者！我见到众生进入十种恶见稠林，不能出来，为了证得阿耨多罗三藐三菩提，永断这样的种种恶见，所以以清净信心舍弃释氏之家，趣向无上道。”那时世尊想重宣此义，而说颂道：

```
一切愚凡夫，入恶见稠林，
我见有情见，及以寿命见，
断见与常见，依无作见等，
为安立正见，是故我出家。
```
（大意：一切愚痴凡夫，进入恶见稠林：我见、有情见以及寿命见，断见与常见，依于无作见等；为了安立正见，所以我出家。）

“再者，长者！我观察世间一切众生，在无数劫中造作百千那庾多拘胝的过失，常被十种大毒箭所射中。是哪十种？一是爱毒箭，二是无明毒箭，三是欲毒箭，四是贪毒箭，五是过失毒箭，六是愚痴毒箭，七是慢毒箭，八是见毒箭，九是有毒箭，十是无有毒箭。长者！我见到众生被十种毒箭所射中，求阿耨多罗三藐三菩提，为了永断这样的种种毒箭，所以以清净信心舍弃释氏之家，趣向无上道。”那时世尊想重宣此义，而说颂道：

```
爱箭毒众生，过拘胝大劫，
无明之所盲，从暗入于暗。
欲箭中诸蕴，吸染名贪箭，
闷乱过失箭，被服愚痴箭，
陵高发慢箭，违诤起见箭，
因有无有箭，堕有及无有。
诸愚痴凡夫，锋刃由其口，
更相起诤论，此实此非实。
为拔毒箭故，如来兴世间，
救诸中箭者，出家成圣道。
```
（大意：爱箭毒害众生，经过拘胝大劫；被无明所盲，从黑暗走入黑暗。欲箭射中诸蕴，吸取染著名为贪箭；令人闷乱的是过失箭，被其覆盖的是愚痴箭；凌驾高举而发出慢箭，违逆诤论而生起见箭；因有箭与无有箭，堕于有以及无有。诸愚痴凡夫，锋刃在其口中，互相诤论：“这是真实，那不真实。”为了拔除毒箭，如来兴起于世间，救护那些中箭的人，出家成就圣道。）

【按】“此实此非实”，宋、宫本作“此实非此实”。

“再者，长者！我观察世间一切众生，由十种爱建立根本。是哪十种？就是：缘于爱而追求，缘于追求而获得，缘于获得便生起我所，缘于我所而生起种种定执，缘于定执而生起欲贪，缘于欲贪而生起深深耽著，缘于深深耽著而生起悭吝，缘于悭吝而生起聚敛，缘于聚敛而生起守护，缘于守护而执持刀仗、诤讼讥谤，生起种种苦；又因此而兴起离间之语，长养种种恶不善法。长者！我见到众生被这十种爱的根本法所建立，求阿耨多罗三藐三菩提，为了证得无根、无所依之法，所以以清净信心舍弃释氏之家，趣向无上道。”那时世尊想重宣此义，而说颂道：

```
爱所吞众生，寻逐于诸欲，
得利兴我所，从此生定执，
我当作所作，欲贪缚增长，
耽著悭悋等，相续次第生，
悭过染世间，能起坚积聚，
聚敛故守护，遍生无有间，
守护在愚夫，刀仗相加害，
种诸不善业，因此生众苦。
观爱因缘已，众苦则不生，
无根无住觉，诸觉中最上。
```
（大意：被爱所吞没的众生，追逐种种欲乐，得到利益便生起我所，从此生起定执：“我应当作所应作的。”欲贪的系缚由此增长，耽著、悭吝等相续次第而生。悭吝的过失染污世间，能生起坚固的积聚；因为聚敛而守护，遍处生起，无有间断；守护在愚夫那里，便以刀仗相互加害，种下种种不善业，因此生起众苦。观察爱的因缘之后，众苦便不再生起；无根、无住的觉悟，是诸觉之中最上的。）

“再者，长者！我观察世间一切众生，都由十种恶邪之性而建立邪定。是哪十种？一是邪见，二是邪思惟，三是邪语，四是邪业，五是邪命，六是邪精进，七是邪念，八是邪定，九是邪解脱，十是邪解脱智见。长者！我观察众生由这样十种邪性而建立邪定，为了证得阿耨多罗三藐三菩提，出离这样的种种邪性，所以以清净信心舍弃释氏之家，趣向无上道。”那时世尊想重宣此义，而说颂道：

```
怀邪见众生，邪思惟境界，
宣说于邪语，及行诸邪业，
邪命邪精进，邪念与邪定，
成就邪解脱，及趣邪智见。
邪性决定聚，愚夫之所依，
为令住正性，故趣无上道。
```
（大意：怀有邪见的众生，以邪思惟为境界，宣说邪语，以及行种种邪业，邪命、邪精进、邪念与邪定，成就邪解脱，以及趋向邪智见。邪性决定聚，是愚夫所依止的；为了令他们安住于正性，所以我趣向无上道。）

```
诸害命众生，劫盗他财物，
行诸邪欲行，速堕于地狱。
麁言离间语，妄语乖寂静，
绮语等凡夫，愚痴之所缚。
贪著他资财，数起于瞋恚，
兴种种邪见，是人趣恶道。
三种由身起，四种语业生，
意能成三恶，故名恶行者。
行诸恶业已，牵趣恶道中，
吾今现世间，拔济令出离。
```
（大意：种种害命的众生，劫盗他人财物，行种种邪欲之行，便迅速堕于地狱。粗恶之言、离间之语、妄语乖违寂静，说绮语等的凡夫，被愚痴所系缚。贪著他人资财，屡屡生起瞋恚，兴起种种邪见，此人便趣向恶道。三种由身而起，四种由语业而生，意能成就三种恶，所以名为恶行者。行了种种恶业之后，便被牵引趣入恶道之中；我如今出现于世间，救拔他们，令其出离。）

“再者，长者！我观察世间一切众生，由于十种染污法，处在烦恼之中，堕于烦恼垢中。是哪十种？一是悭吝之垢染污，二是恶戒之垢染污，三是瞋恚之垢染污，四是懈怠之垢染污，五是散乱之垢染污，六是恶慧之垢染污，七是不遵尊长教诲之垢染污，八是邪疑之垢染污，九是不信解之垢染污，十是不恭敬之垢染污。长者！我见到众生被这样十种染污法所染污，为了证得阿耨多罗三藐三菩提，证得无染的无上之法，所以以清净信心舍弃释氏之家，趣向无上道。”那时世尊想重宣此义，而说颂道：

```
世多分众生，十染所逼迫，
乐有为烦恼，曾不生厌离。
悭垢所染污，一切愚凡夫，
犯戒非寂静，不习三摩地，
瞋垢背忍辱，懈怠退正勤，
其心不专住，恶慧愚钝者，
于父母师长，不遵奉言教，
疑见网众生，不求照世觉，
诽谤于甚深，佛所说妙法，
被服无明蕴，圣蕴怀轻贱。
观是染污已，谁乐处有为，
当勤证寂灭，无为无染污。
```
（大意：世间大多数众生，被十种染污所逼迫，喜乐有为的烦恼，从不生起厌离。一切愚痴凡夫被悭垢所染污；犯戒而不寂静，不修习三摩地；有瞋垢而违背忍辱，因懈怠而退失正勤；其心不能专住，是恶慧愚钝之人；对于父母师长，不遵奉其言教；被疑见之网所缠的众生，不求照耀世间的觉者；诽谤佛所说的甚深妙法；被无明之蕴所覆，对于圣蕴心怀轻贱。观察这些染污之后，谁还乐于处在有为之中？应当勤证寂灭，无为而无染污。）

“再者，长者！我观察世间一切众生，被十种缠缚所缠缚。是哪十种？一是被悭嫉之网所缠缚，二是被无明之膜所覆翳，三是被烦恼迷醉，堕于愚痴之坑，四是被爱欲的急流所漂没，五是被射中末摩死节的邪箭所中，六是被忿恨的浓烟所熏，七是被贪欲的盛火所焚烧，八是被过失的毒药所闷乱，九是被诸盖的毒刺所遮碍，十是常处在生死流转的饥馑旷野中，正勤疲惫懈怠。长者！我观察众生被这样十种缠缚所缠缚，求阿耨多罗三藐三菩提，为了证得无缠无缚之法，所以以清净信心舍弃释氏之家，趣向无上道。”那时世尊想重宣此义，而说颂道：

老吞少盛年，老坏净妙色，

为彼除悔恼，说法故出家。

#### 五百长者请法

那时，五百长者听了佛所说，得未曾有，才知道如来是真正的觉者，即在佛前异口同声说颂道：

```
我等怖畏老死逼，
愿宣妙法尽其际。
世尊诸有趣清净，
离有性净超诸有，
愿拔诸有令不有，
及在禁闭有家者。
世雄离染最解脱，
远离尘垢心清净，
调御法中大调御，
愿开微妙甘露门。
备上妙色胜丈夫，
天人世间无等者，
世无等等最胜尊，
愿说妙法济群生。
三垢永灭吐诸过，
慧眼清净翳障消，
净尘离暗开痴网，
愿无等尊宣妙法。
```
（大意：我们怖畏老死的逼迫，愿世尊宣说妙法，令我们穷尽其边际。世尊对于诸有已趣向清净，远离诸有，其性清净，超越诸有；愿您拔除诸有，令其不再有，以及救拔那些被禁闭在有之家中的人。世雄远离染污，最为解脱，远离尘垢，心地清净，在调御之法中是大调御者，愿您开启微妙的甘露之门。具备上妙之色的殊胜丈夫，天人世间无与等者，世间无等等的最胜尊，愿您宣说妙法，救济众生。三垢永灭，吐尽种种过失，慧眼清净，翳障消除，净除尘垢，远离黑暗，打开痴网，愿无等尊宣说妙法。）

#### 世尊升空问十事

那时，世尊这样想：“这五百长者善根已经成熟，堪受法化，我现在应当为他们如其所应而说法，令诸长者即在此处除去俗相，以信心出家，断除种种烦恼，得漏尽之慧。”这样想后，即升到虚空中结跏趺坐。诸长者见到这神变，赞叹从未有过，对如来倍加生起敬重信仰之心。

那时，世尊告诉诸长者：“你们好好听。世间有十种逼迫的苦事，就是生苦、老苦、病苦、死苦、愁苦、怨苦、苦受、忧受、痛恼、生死，这样十种逼迫的苦事逼迫众生，你们现在想要解脱吗？

“再者，诸长者！世间有十种恼害之事，就是：曾对我自身作不饶益，现在对我自身作不饶益，将来对我自身作不饶益；对我曾爱的人作不饶益，对我现在所爱的人作不饶益，对我将来所爱的人作不饶益；对我曾不爱的人作饶益，对我现在不爱的人作饶益，对我将来不爱的人作饶益；又对一切不饶益的过失心生恼害。这样十种恼害之事，你们现在想要解脱吗？

“再者，诸长者！世间有十种异见恶见的稠林，就是我见、众生见、寿命见、数取见、断见、常见、无作用见、无因见、不平等见、邪见。这样十种恶见稠林，你们现在想要解脱吗？

“再者，长者！世间被十种大毒箭所射中，就是爱毒、无明毒、欲毒、贪毒、过失毒、愚痴毒、慢毒、见毒、有毒、无有毒。这样十种大毒之箭，你们现在想要解脱吗？

“再者，诸长者！世间有十种爱的根本法，就是：缘于爱而追求，缘于追求而获得，缘于获得便生起我所，缘于我所而生起种种定执，缘于定执而生起欲贪，缘于欲贪而生起深深耽著，缘于深深耽著便生起悭吝，缘于悭吝而生起聚敛，缘于聚敛便生起守护，缘于守护而执持刀仗、讥谤诤讼，生起离间之语，种种诸苦与恶不善法都因此而生起。这样十种爱的根本法，你们现在想要解脱吗？

【按】“起深耽著”之“著”，《大正藏》作“者”，CBETA依高丽藏作“著”，今从之。“缘深耽著便起悭吝”，宋、元、明、宫本作“缘深耽著故便起悭吝”。“聚敛”之“敛”，明本作“歛”。“起别种语”之“种”，元、明本作“离”，即“离别语”，与前文“兴别离语”相应，今依文意译作“离间之语”。

“再者，诸长者！世间有十种邪性，就是邪见、邪思惟、邪语、邪业、邪命、邪勤、邪念、邪定、邪解脱、邪解脱智见。这样十种邪性，你们现在想要解脱吗？

“再者，诸长者！世间有十种不善业道，就是害命、不与取、行邪淫、妄语、离间语、粗恶语、绮语、贪、恚、邪见。这样十种不善业道，你们现在想要解脱吗？

“再者，诸长者！世间有十种染污垢法，就是悭垢、恶戒垢、瞋垢、懈怠垢、散乱垢、恶慧垢、不遵尊教垢、疑垢、不信解垢、不恭敬垢。这样十种染污垢法，你们现在想要解脱吗？

“再者，诸长者！世间有十种生死流转的大怖畏事，就是：被悭嫉之网所缠缚，被无明之膜所覆翳，堕坠愚痴深坑，漂没于爱欲急流，被末摩邪箭所射中，被忿恨浓烟所熏，被贪欲盛火所焚烧，被过失毒药所迷闷，被诸盖毒刺所遮障，在饥馑的流转旷野中。这样十种生死流转的大怖畏事，你们现在想要解脱吗？”

【按】“驶流”之“驶”，《大正藏》作“駃”，CBETA依碛砂藏作“驶”，今从之。

那时，五百长者一心同声对佛说：“世尊！我们现在愿意解脱所说的十种逼迫苦事，就是生、老、病、死、愁、怨、忧、苦、恼害、生死，这样广说，乃至流转的饥馑旷野种种逼迫之事，我们都愿意得到解脱。”

#### 诸处非我，诸法唯假施设

那时，世尊告诉这五百长者说：“你们好好听，我现在当说正法的要义。诸长者！眼不求解脱。为什么？因为眼无作无用，眼不能思惟，不能了别。所以，诸长者，眼不是我，应当这样受持。耳、鼻、舌、身、意也是这样：意不求解脱。为什么？因为意无作无用，意不能思惟，不能了别。所以，诸长者，意也不是我，应当这样受持。

“再者，诸长者！色不求解脱。为什么？因为色无作无用，色不能思惟，不能了别。所以，诸长者，色也不是我，应当这样受持。声、香、味、触、法也是这样：法不求解脱。为什么？因为法无作无用，法不能思惟，不能了别。所以，诸长者，法也不是我，应当这样受持。

“再者，诸长者！色蕴不求解脱。为什么？因为色蕴无作无用，色蕴不能思惟，不能了别。所以，诸长者，色蕴不是我，应当这样受持。受蕴、想蕴、行蕴、识蕴也是这样：识蕴不求解脱。为什么？因为识蕴无作无用，识蕴不能思惟，不能了别。所以，诸长者，识蕴不是我，应当这样受持。

“再者，诸长者！地界不求解脱。为什么？因为地界无作无用，地界不能思惟，不能了别。所以，诸长者，地界不是我，应当这样受持。水界、火界、风界、空界、识界也是这样：识界不求解脱。为什么？因为识界无作无用，识界不能思惟，不能了别。所以，诸长者，识界不是我，应当这样受持。

“再者，诸长者！诸法不实，是分别所起，依于众缘，无能无力，随众缘而转。若有众缘，便假设诸法；若无众缘，便无假法。诸长者！一切诸法只是假施设，其中都没有生者、老者、死者、尽者、起者，唯有永断诸趣、清净寂灭，可以归依，所以你们应当这样了知。所以，诸长者！一切诸法是不实分别所生起的，依于众缘，羸劣无力，随众缘而转。若有众缘，便假立诸法；若无众缘，便无假法。诸长者！一切诸法只是假立，其中都没有生者、老者、死者、尽者、起者，唯有永断诸趣、清净寂静，可以归依。

#### 依不实分别假立十二缘起

“这样，诸长者！若有不实分别，便有假立的不正作意；若无不实分别，便无假立的不正作意。若有不正作意，便有假立的无明；若无不正作意，便无假立的无明。若有无明，便有假立的诸行；若无无明，便无假立的诸行。若有诸行，便有假立的识；若无诸行，便无假立的识。若有假识，便有假立的名色；若无识，便无假立的名色。若有名色，便有假立的六处；若无名色，便无假立的六处。若有六处，便有假立的触；若无六处，便无假立的触。若有触，便有假立的受；若无触，便无假立的受。若有受，便有假立的爱；若无受，便无假立的爱。若有爱，便有假立的取；若无爱，便无假立的取。若有取，便有假立的有；若无取，便无假立的有。若有有，便有假立的生；若无有，便无假立的生。若有生，便有假立的老死；若无生，便无假立的老死。

“这样，诸长者！什么是老？就是情识昏耄，头白发落，皮肤松弛，面容起皱，寿命损减，诸根衰熟，诸行朽故，这名为老。什么是死？就是丧灭、转世、休废、堕落，诸蕴散坏，委弃于地，舍弃众同分，这名为死。若老若死，合称老死。

“诸长者！生若是有，便有假立的老死；生若是无，便无假立的老死。什么是生？就是生、等生、趣、起，诸蕴出现，以及得到诸处，会合众同分，这名为生。诸长者！有若是有，便有假立的生；有若是无，便无假立的生。什么是有？就是欲有、色有以及无色有，福业、非福业、不动业等，这名为有。诸长者！取若是有，便有假立的有；取若是无，便无假立的有。什么是取？就是欲取、见取、戒禁取、我取，所以名为取。诸长者！爱若是有，便有假立的取；爱若是无，便无假立的取。什么是爱？就是色爱、声爱、香爱、味爱、触爱、法爱，这名为爱。诸长者！受若是有，便有假立的爱；受若是无，便无假立的爱。什么是受？就是眼触所生的受，耳触、鼻触、舌触、身触、意触所生的受，这名为受。诸长者！触若是有，便有假立的受；触若是无，便无假立的受。什么是触？就是眼触、耳触、鼻触、舌触、身触、意触，这名为触。诸长者！六处若有，便有假立的触；六处若无，便无假立的触。什么是六处？就是眼处、耳处、鼻处、舌处、身处、意处，这是六处。诸长者！名色若有，便有假立的六处；名色若无，便无假立的六处。什么是名色？就是受、想、思、触、作意，四大界以及四大界所造之色，这名为名色。诸长者！识若是有，便有假立的名色；识若是无，便无假立的名色。什么是识？就是眼识、耳识、鼻识、舌识、身识、意识，这名为识。诸长者！行若是有，便有假立的识；行若是无，便无假立的识。什么是行？就是色思、声思、香思、味思、所触思、法思，这名为行。诸长者！无明若有，便有假立的行；无明若无，便无假立的行。什么是无明？就是对前际无知、对后际无知、对前后际无知，对内无知、对外无知、对内外无知，对苦无知、对集无知、对灭无知、对道无知，对缘无知、对缘起无知；对于缘生之法，或黑或白，有缘无缘，有光影无光影，有罪无罪，可亲近不可亲近，无知、无见、无对观、无通达解了，这样的种种相，名为无明。

【按】“所触思”，明本无“所”字。

“诸长者！不正作意若有，便有假立的无明；若无不正作意，便无假立的无明。什么名为不正作意？就是：‘我在过去是什么样的性？在什么样的处所？是什么样的种类？我往未来，是什么样的性？在什么样的处所？是什么样的种类？’又对于自身多起疑惑：‘什么名为我？我是谁？是有还是无？是虚还是实？是什么样的性？在什么样的处所？是什么样的种类？我从前住在何处？’在那里生起这样的不正作意，从六种见中随生一种见：执有我见，执无我见，或依我而观我见，或不依我而观我见；又虚妄生起这样的见：‘我即是世间，或当缘起，是常、是恒，不转不变，永远正住而止。’这样的种种见，名为不正作意。

【按】“若无不正作意”之“无”，宋、宫本作“无作”。

“诸长者！不实分别若有，便有假立的不正作意；不实分别若无，便无假立的不正作意。什么名为不实分别？就是我、有情、命者、丈夫、数取、生者、意生、摩纳婆、作者、受者，这名为不实。而那些无闻的凡夫妄起这样的我分别、有情分别、命者分别、丈夫分别、数取分别、生者分别、意生分别、摩纳婆分别、作者分别、受者分别等种种分别，所以是不实分别。诸长者！这样的不实分别若有，便有假立的不正作意；不实分别若无，便无假立的不正作意。诸长者！不正作意若有，便有假立的无明；不正作意若无，便无假立的无明。无明若有，便有假立的诸行；无明若无，便无假立的诸行。这样乃至生若是有，便有假立的老死；生若是无，便无假立的老死。”

【按】“数取分别”，宋、宫本无。

#### 鱼依水喻与诸法无我

那时，佛告诉诸长者：“你们现在应当知道，一切诸法是不实分别所起，依于众缘，羸劣无力，随众缘而转。众缘若有，便有假法；众缘若无，便无假法。诸长者！一切诸法只是假立，其中都没有生者、老者、死者、尽者以及起者，唯有永断诸趣、清净寂灭，可以归依。诸长者！你们认为怎样？譬如大池中所生的诸鱼与水族之类，依什么力而住？”长者回答说：“世尊！这些鱼等依水力而住。”佛说：“是这样，是这样。诸长者！这水是否有思念，是否有力？”长者回答说：“世尊！这水无力无能，有什么思念？”佛说：“是这样，是这样。诸长者！不实分别所起的诸法也是这样，只是假施设，无力无能，随众缘而转。众缘若有，便有假法；众缘若无，便无假法。诸长者！一切诸法只是假立，其中都没有生者、老者、死者、尽者、起者，唯有永断诸趣、清净寂灭，可以归依。

“所以，诸长者！你们应当正确观察这样的众缘，不是安稳之处，难以保持，应当深生怖惧，逃走远避。又应当观察：这是什么法？因为怖畏什么法而来到这里？你们这样正确观察时，无法可得，无所怖，也无所舍。为什么？因为一切诸法都不可得，以一切方式寻求都不可得的缘故；诸法无我，因为离于尘垢；诸法无众生，因为远离我；诸法无命，因为超出生老病死、愁忧苦恼逼迫等；诸法无数取，因为三世已断；诸法无字，因为一切言音不可说；诸法无著，因为无所缘；诸法寂静，因为是寂灭之相；诸法普遍，因为是虚空之性；诸法性空，因为无有定属；诸法无动，因为无所依；诸法依实际而住、善住，因为与无动相应；诸法不可开阐，因为离于相的波浪；诸法不可显示，因为无相、无形、无有光影，离于诸行；诸法不是我所有，因为离于我所；诸法不可分别，因为离于心意识；诸法无有爱藏，因为超过眼耳鼻舌身意之道；诸法不可举移，因为离于生住坏；诸法无作无用，因为离于心意识；诸法属于众缘，因为其性羸劣。

【按】“超过眼耳鼻舌身意道”之“道”，元、明本作“识”。

#### 观眼多过

“诸长者！我说这眼是四大所造，是无常、无住、无恒、不坚之法，羸弱而迅速朽坏，难以保信，众苦所集，多病多害。你们诸长者！眼就是这样，不应依止；耳、鼻、舌、身、意也是这样，不应依止，应当这样观察。

“再者，诸长者！眼如聚沫，不可撮摩；眼如浮泡，不能久住；眼如阳焰，由业、惑、爱而生；眼如芭蕉，其性不坚固；眼如幻术，从颠倒而起；这眼如梦，只是虚妄所见；这眼如回响，系属于众缘；眼如光影，是业的光影所现；眼如浮云，是聚散纷乱之相；眼如闪电，刹那便灭；这眼无主，犹如大地；这眼无我，犹如水；眼不是有情，犹如火；眼不是寿命，犹如风；眼不是数取，犹如虚空；眼是不实的，是依藏于诸大之中的；这眼是空的，离于我与我所；这眼无知，如草木土石；这眼无作，如机关被风所转；这眼是虚假的，是朽秽的聚集；这眼是浮伪的，是摧散破坏灭尽之法；眼如丘井，常被老所逼迫；眼没有住留的边际，终究归于磨灭。诸长者！眼有许多过失，应当这样观察，乃至意以及一切诸法也都是这样。

【按】“业惑爱生”之“惑”，元、明本作“感”。

#### 唯有妄欲与出家无欲

“再者，诸长者！一切诸法只是妄欲，异生愚夫不知是妄欲，所以妄称这是眼，妄称这是耳，乃至妄称这是意。诸长者！只是妄欲，异生愚夫不知是妄欲，所以称这是色，称这是声，香、味、触、法也是这样。诸长者！只是妄欲，异生愚夫不知是妄欲，所以称这是色蕴，称这是受蕴，想、行、识蕴也是这样。诸长者！只是妄欲，异生愚夫不知是妄欲，所以称这是地界，称这是水界，火、风、空、识界也是这样。诸长者！一切诸法只是妄欲，异生愚夫不知是妄欲，所以称这是有为，称这是无为，乃至一切诸法也都是这样。

【按】“不知妄欲故，谓此是色”之“妄”，《大正藏》作“忘”，CBETA依高丽藏作“妄”，今从之。

“诸长者！你们现在应当舍弃妄欲，趣向无欲；对于妻子、家宅、财物，深知其虚妄，不应执著。因不执著，以清净信心舍离在家之法，趣向非家，当得无欲。诸长者！什么名为出家无欲？就是安住于尸罗别解脱戒，具足摄持威仪与所行之处，见到微小的违犯也生大怖畏，受学律仪，成就戒蕴。诸长者！你们若能奉持戒律之后，对于这六根、六境、五蕴、六界，深知其虚假，都不执著，因不执著的缘故，这名为出家无欲之法。

“诸长者！若不执著眼乃至识界，因不执著，便不保护。不保护什么？眼不保护，耳、鼻、舌、身、意不保护；色不保护，声、香、味、触、法不保护；色蕴不保护，受、想、行、识蕴不保护；地界不保护，水、火、风、空、识界不保护。因不保护，便没有烦恼；若无烦恼，便名为轻。什么是轻？就是无所见。若无所见，便不依于事物而生起瞋害之心；由于无瞋害，便不自害，不想害他，不想自他俱害；因无害的缘故，便在无余大涅槃界中证入。

#### 谁证寂灭与尽智

“诸长者！你们应当知道，是谁在寂灭中证入？诸长者！眼不入寂灭，耳、鼻、舌、身、意不入寂灭；然而因眼而生起种种妄执，或计为我，或计为我所，若远离这些，就是寂灭。远离什么而为寂灭？若远离贪，就是寂灭；若远离瞋，就是寂灭；若远离痴，就是寂灭；若远离无智，就是寂灭。

“再者，诸长者！过去的无智不可远离，未来的无智不可远离，现在的无智不可远离；然而要因为远离无智，正智才生起。诸长者！什么是智？就是尽智。什么是尽智？过去不是尽智，未来不是尽智，现在不是尽智；然而，诸长者，因为远离无智，这智才生起。这智不远离智，因为远离对眼的无智，这智才生起。

原文：“此智不远离智，因离眼无智而此智生”（大意：这智不远离智，因为远离对眼的无智，这智才生起。“此智不远离智”一句所指未详，存疑。）

“又，诸长者！眼不是我所；若不是我所，便不取著；若不取著，就是最上；若是最上，就是解脱。在何处解脱？在我执之处得到解脱；在有情执之处、寿命执之处、数取执之处、断常执之处、一切执之处，乃至分别执之处得到解脱。行者若能在执著中解脱，便不分别；若不分别，便既非分别也非不分别。不分别什么？就是不分别我以及我所。行者那时对于一切法，离散而不积集，舍弃而不取著；因舍弃的缘故，寂灭、解脱、除遣，最胜解脱，离诸系缚。在什么地方名为除遣？在一切苦处得到除遣。你们诸长者！若求出离，不要对任何一法生起取著。为什么？若有取著，便有怖畏；若无取著，便无怖畏。

“再者，诸长者！眼不是寂灭，耳、鼻、舌、身、意也不是寂灭，色不是寂灭，乃至识界也不是寂灭。然而，诸长者，因识界而生起不实的执著，或计为我以及我所，若离开这些，就是寂灭。远离什么而得寂灭？就是远离贪而得寂灭，远离瞋、远离痴以及无智而得寂灭。

“再者，诸长者！过去的无智不可远离，未来的无智不可远离，现在的无智不可远离；然而离开无智，智才得以生起。诸长者！什么是智？就是尽智。什么是尽智？过去不是尽智，未来不是尽智，现在不是尽智；然而，诸长者，因为远离无智，智才得以生起。这智不远离智，因为远离对识的无智，智才得以生起。而这识界不是我所；若不是我所，便不取著；若不取著，就是最上；若是最上，就是解脱。在何处解脱？在我执之处得到解脱，在有情、寿命乃至一切分别执之处得到解脱。行者若能在执著中解脱，便不分别；若不分别，便既非分别也非不分别。不分别什么？就是不分别我以及我所。行者那时离散而不积集，舍弃而不取著；因舍弃的缘故，寂灭、解脱、除遣，最胜解脱，离诸系缚。在何处除遣？在一切苦处得到除遣。你们诸长者！若求出离，不要对任何一法生起取著。为什么？若有取著，便有怖畏；若无取著，便无怖畏。”那时世尊想重宣此义，而说颂道：

```
取著生怖畏，由斯趣恶道，
观此有怖处，智者不应取。
汝修诸圣道，应当善观察，
如是观便得，异此则不可。
一切处皆空，虚动非坚实，
爱诳惑世间，勿于此生乱。
我已知空法，了诸法不坚，
湛然获安泰，证无动妙乐。
若如是了知，诸法唯空者，
彼解脱众苦，及灭于诤论，
欲摄受一切，生诸灾横者。
摄受故取著，著故生诸有，
从有生于生，由生远寂灭，
生者老病死，如是大苦逼。
无欲故无取，无取故无有，
无有故无生，老病死亦尔。
```
（大意：取著生起怖畏，由此趣向恶道；观察到这有怖畏之处，智者不应取著。你们修习种种圣道，应当善加观察；这样观察便能得到，不这样则不可得。一切处都是空，虚妄动摇而不坚实；爱诳惑世间，不要因此而生迷乱。我已了知空法，了知诸法不坚，湛然获得安泰，证得无动的妙乐。若能这样了知诸法唯是空，他便解脱众苦，以及灭除诤论。想要摄受一切，便生起种种灾横；因摄受而取著，因取著而生诸有，从有而生于生，由生而远离寂灭；生者便有老、病、死，被这样的大苦所逼迫。因无欲而无取，因无取而无有，因无有而无生，老病死也是如此。）

【按】“观此有怖处”之“怖处”，宋、元、明、宫本作“怖畏”。

```
聚集资生具，一时皆弃舍，
并舍爱妻子，趣苾刍威仪。
勿贪亲与财，咄哉念知足，
勿如旃荼罗，下贱心来往，
勿自恃持戒，轻毁犯戒者，
恃戒凌于人，是名真破戒。
譬如鹿被弶，若缚若致死，
处魔羂慢者，缚害亦如是。
慢能坏善心，又损自他善，
故勿轻毁戒，况持戒梵行。
当学大仙子，常住空闲处，
勿顾于身命，趣寂静解脱。
应离无义本，顺世尼乾论，
爱敬演甚深，空相应妙法。
```
（大意：把聚集的资生之具一时全都弃舍，并舍弃所爱的妻子，趣向苾刍的威仪。不要贪恋亲人与财物；咄！应当念念知足；不要像旃荼罗那样，以下贱之心往来。不要自恃持戒而轻毁犯戒的人；倚恃持戒而凌驾他人，这名为真正的破戒。譬如鹿被弶索所缚，或被缚住，或致死亡；处在魔网中的憍慢者，被缚被害也是这样。慢能破坏善心，又损害自他的善根；所以不要轻毁破戒者，何况是持戒修梵行的人。应当学习大仙之子，常住在空闲之处，不顾身命，趣向寂静解脱。应当远离无义的根本，即顺世外道与尼乾子之论；爱敬演说甚深的、与空相应的妙法。）

【按】“念知足”之“足”，宫本作“之”。“旃荼罗”之“荼”，《大正藏》作“茶”，CBETA依高丽藏作“荼”，今从之。“轻毁犯戒者”之“轻”，《大正藏》作“经”，CBETA依高丽藏作“轻”，今从之。

```
内外十二处，我说心为本，
彼复因业生，业由思久住，
眼色俱为缘，而生起于识，
缘阙则不生，譬无薪之火。
如是生诸法，和合互相生，
无作无受者，现作用如幻，
一切内外法，我已知空幻，
愚夫颠倒执，分别我我所。
眼中无有情，外诸处亦尔，
非我作寿者，诸法类应知。
眼不思解脱，耳鼻舌亦然，
身意等无作，诸法观如是。
譬如巨海中，鼓涛成沫聚，
明眼者察知，审其非坚实。
如是五蕴体，达者知非固，
当解脱生老，愁忧灾横等。
我法中出家，知诸法如幻，
不虚彼信施，即名供诸佛。
```
（大意：内外十二处，我说以心为根本；心又因业而生，业由思而久住。眼与色共同为缘，而生起识；缘若缺少便不生，譬如没有柴薪的火。这样生起的诸法，是和合而互相生起，无作者，无受者，所显现的作用如幻。一切内外诸法，我已了知是空是幻；愚夫颠倒执著，分别我与我所。眼中没有有情，外在诸处也是这样，不是我、作者、寿者；诸法依此类推，应当了知。眼不思惟解脱，耳、鼻、舌也是这样，身、意等都无作用，应当这样观察诸法。譬如巨海之中，鼓动波涛形成泡沫之聚，明眼人观察便知，审察出它并不坚实。这样的五蕴之体，通达的人知其不坚固，当解脱生老以及愁忧灾横等。在我的法中出家，了知诸法如幻，不虚受那些信施，这就名为供养诸佛。）

【按】“缘阙”之“阙”，明本作“缺”。“譬无薪之火”之“无”，明本作“如”。“达者知非固”之“固”，宫本作“因”。

#### 长者得法眼净，佛说诸处炽然

那时，五百长者听了这法，即在此处远离尘垢，于诸法中得法眼净，如同没有污黑的干净衣服放进染缸，迅速受染上色；这些长者法眼清净，也是这样。

那时，世尊又为诸长者宣说妙法，开示、教导、赞叹、令其欢喜：“诸长者！我说这眼的自性是苦，而且炽然燃烧。被什么炽然燃烧？就是被贪火、瞋火、痴火所炽然燃烧，被生、老、病、死、愁、叹、忧、苦、不安等法所炽然燃烧。这样，诸长者！我说这耳、鼻、舌、身、意的自性是苦，而且炽然燃烧。被什么炽然燃烧？就是被贪火、瞋火、痴火，被生、老、病、死、愁、叹、忧、苦、不安等法所炽然燃烧。诸长者！我说这色的自性是苦，而且炽然燃烧。被什么炽然燃烧？就是被贪火、瞋火、痴火所炽然燃烧，乃至声、香、味、触、法也是这样。诸长者！我说色蕴的自性是苦，而且炽然燃烧。被什么炽然燃烧？就是被贪火、瞋火、痴火所炽然燃烧，乃至受、想、行、识蕴也是这样。诸长者！我说地界的自性是苦，而且炽然燃烧。被什么炽然燃烧？就是被贪火、瞋火、痴火所炽然燃烧；这样乃至水、火、风、空、识界，自性是苦，而且炽然燃烧。被什么炽然燃烧？就是被贪火、瞋火、痴火，被生、老、病、死、愁、叹、忧、苦、不安等法所炽然燃烧。

【按】“示教赞善”之“善”，宋、元、明、宫本作“喜”，即“示教赞喜”。

“所以，诸长者！我现在不执著眼、耳、鼻、舌、身、意，你们也应当这样随学。我现在不执著色、声、香、味、触、法，乃至不执著色等诸蕴、地等诸界、此世他世，你们也应当这样随学。诸长者！你们若对于眼、耳、鼻、舌、身、意不执著，便不依眼而住，不依耳、鼻、舌、身、意而住。你们不依色、声、香、味、触、法时，便不依于一切法而住。你们若不依色蕴乃至不依识蕴而住，便是不依色蕴乃至识蕴而住。你们不依地、水、火、风、空、识界时，便不依地界乃至识界而住。你们若不依此世、他世以及一切世间而住，这样，你们不取一切法时，便不依于一切法而住。若能不依一切法而住，这便名为既非当有，也非不当有。你们若悟入既非当有、也非不当有，我说你们便解脱了生老病死诸苦。”那时世尊想重宣此义，而说颂道：

```
生死所炽盛，烧然诸世间，
受苦无能救，丧失于圣道。
照世诸如来，时乃一兴现，
无刹那远离，当起坚精进，
修习于正行，慧观应察知，
如慧观当得，异此非所获。
若于此修习，应知一切空，
了达空法已，非心空菩提。
贪瞋及与痴，是三毒大火，
烧诸世愚者，长眠而不觉。
生老病及死，愁叹诸苦等，
知世逼迫已，勿依诸法住。
```
（大意：生死炽盛，焚烧世间，受苦而无人能救，丧失了圣道。照耀世间的诸如来，要经很久才出现一次，不要有一刹那远离，应当生起坚固的精进，修习正行，以智慧观察而了知；如智慧所观便能证得，不这样则无所获。若在这里修习，应当了知一切皆空；了达空法之后，不是以心空为菩提。贪、瞋以及痴，这三毒大火，焚烧世间诸愚者，他们长眠而不觉醒。了知生老病死、愁叹诸苦等逼迫世间之后，不要依于诸法而住。）

原文：“了达空法已，非心空菩提”（大意：了达空法之后，不是以心空为菩提。所指未详，存疑。）

#### 五百长者出家证阿罗汉

那时，五百长者对佛说：“世尊！我们现在想在佛所出家，受具足戒，修清净行，不知世尊能否垂怜允许？”佛说：“善来苾刍！”他们当即名为出家，受了具足戒，成就苾刍之法。那时世尊想重宣此义，而说颂道：

```
袈裟执受已，其发自然断，
一切皆持钵，即座成罗汉。
知得罗汉已，于苾刍众前，
及对诸天等，大师已问说：
『昔于世依怙，广行诸布施，
随其所生处，常感多安乐。
彼今得见我，复生清净心，
由彼心清净，故为说妙法。』
闻说得罗汉，永离于我见，
证空法现前，解脱诸生死。
```
（大意：执受袈裟之后，头发自然断落，人人都手持钵，即在座上成就阿罗汉。知道他们已得阿罗汉之后，大师在苾刍众前以及面对诸天等，问答宣说：“他们往昔对世间依怙者广行布施，随其所生之处，常感得许多安乐；他们如今得见我，又生起清净之心，由于他们心清净，所以为他们宣说妙法。”他们听闻之后证得阿罗汉，永离我见，证得空法现前，解脱了一切生死。）

【按】“大师已问说”之“已”，元、明、宫、圣本作“无”。“复生清净心”之“净”，宫、圣本作“信”。
