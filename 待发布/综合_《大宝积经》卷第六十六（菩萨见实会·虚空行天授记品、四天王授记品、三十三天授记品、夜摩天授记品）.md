# 《大宝积经》卷第六十六（菩萨见实会·虚空行天授记品、四天王授记品、三十三天授记品、夜摩天授记品）

## 菩萨见实会第十六之六

### 虚空行天授记品第十二

#### 虚空行天雨花赞佛

那时又有八万虚空行天，见到阿修罗、伽楼罗以及龙女、龙王、鸠槃茶、乾闼婆、夜叉、紧那罗等供养如来并听闻授记，都大欢喜，踊跃无量，对佛法深心爱乐；为了供养佛，发起勇猛之心。那些虚空行天在迦毘罗城外周遍八方六十由旬，降下曼陀罗花，遍布其地，厚及人膝。降曼陀罗花遍布地面之后，用以供养佛，绕佛三匝，便以偈颂赞佛说：

【按】“伽楼罗”之“伽”，明本作“迦”。“鸠槃茶”之“茶”，宋、元、宫本作“荼”。“紧那罗”之“那”，《大正藏》作“陀”，今依CBETA作“那”（下二品同）。“八方六十由旬”，元、明本作“八万六千由旬”，宫本作“八方六由旬”。

```
诸根寂静微笑面，
救护一切诸众生，
善逝具足大慈悲，
故为世尊人师子。
如来大众皆安住，
于佛法中及涅槃，
导师世尊胜妙足，
我今头面而顶礼。
如十五日月盛满，
世人皆礼星中月，
如是一切诸天众，
覩佛笑面咸敬礼。
积集无量大福聚，
亦复成就智慧身，
具足无量大威德，
故我顶礼世间亲。
具足十力功德山，
于谛无畏离三垢，
成就十八不共法，
明见无疑说中胜。
具足三十二种相，
八十种好而自严，
其心胜上如帝幢，
故我顶礼无等等。
```
（大意：诸根寂静，面带微笑，救护一切众生，善逝具足大慈悲，所以世尊是人中师子。如来使大众都安住于佛法中以及涅槃中，导师世尊殊胜美妙的双足，我现在头面顶礼。如十五日月亮盛满，世人都礼拜群星中的月亮；像这样，一切诸天众见到佛的笑容，都恭敬礼拜。积集无量的大福聚，也成就智慧之身，具足无量的大威德，所以我顶礼世间的亲人。具足十力的功德之山，对四谛无畏，远离三垢，成就十八不共法，明见无疑，说法中最殊胜。具足三十二种相，以八十种好自为庄严，其心殊胜高上如帝释之幢，所以我顶礼无等等者。）

```
已能究竟持戒力，
禅力决定不倾动，
执持最上智慧剑，
最胜勇健降天魔。
于智慧力到彼岸，
调御声闻心无悋，
其心寂静游诸方，
度脱一切诸天人。
世尊人中胜师子，
得于最上寂灭法，
惟然十力愿我等，
亦当得此胜妙法。
愿我亦当天人中，
为诸世间所信乐，
愿如世尊等无异，
了知众生心乐欲。
愿我得利诸世间，
以怜愍心大悲心，
堕生死海苦众生，
愿我皆能得度脱。
愿我于诸天人中，
得作无上大导师，
我当解脱诸有趣，
为百苦逼诸众生。
```
（大意：已能究竟持戒之力，禅定之力决定而不倾动，执持最上的智慧之剑，最殊胜勇健，降伏天魔。在智慧之力上已到彼岸，调御声闻，心无吝惜，其心寂静，游化诸方，度脱一切诸天人。世尊是人中殊胜的师子，得到最上的寂灭之法，是的，十力者！愿我们也当得到这殊胜美妙之法。愿我们也在天人之中，为诸世间所信乐，愿如世尊一样没有差异，了知众生的心意乐欲。愿我们得以利益诸世间，以怜愍之心、大悲之心，堕在生死海中的受苦众生，愿我们都能令其得度脱。愿我们在诸天人之中，得以作无上的大导师，我当令那被百种苦所逼的众生解脱于诸有之趣。）

【按】“惟然”之“惟”，宫、圣本作“唯”。

#### 授虚空行天记

那时世尊知道虚空行天深心信乐之后，便即微笑。那时马胜比丘便以偈颂问佛说：

```
佛牟尼王非无缘，
三界照明现微笑，
唯愿十力为我说，
为何众生现喜相？
见佛如来最胜面，
现微笑相令众喜，
一切大众皆怀疑，
愿闻佛说笑因缘。
愿大导师速为说，
微笑因缘利益事，
愿为除断众疑网，
沙门中王为宣说。
孰能令佛现喜笑？
谁于佛所上供养？
令谁能达生死底？
愿人师子除我疑。
谁于今日动魔宫，
令魔狂乱心不安？
谁于今日令天众，
悉皆欣喜大踊跃？
唯愿为我速宣说，
除断一切世疑网，
大众若得闻佛说，
一切皆悉大欣喜。
```
（大意：佛牟尼王并非无缘，照明三界而现出微笑，唯愿十力者为我们宣说：为了哪些众生现出喜相？见到佛如来最殊胜的面容，现出微笑之相，令大众欢喜，一切大众都怀疑惑，愿闻佛说微笑的因缘。愿大导师迅速为我们宣说微笑因缘的利益之事，愿为我们除断大众的疑网，沙门中之王，请为宣说。谁能令佛现出喜笑？谁在佛所作了上等的供养？令谁能到达生死的底处？愿人中师子除去我的疑惑。谁在今天震动魔宫，令魔狂乱，心中不安？谁在今天令天众都欢喜大踊跃？唯愿为我们迅速宣说，除断一切世间的疑网，大众若得听闻佛说，一切都会大欢喜。）

【按】“非无缘”之“缘”，圣本作“胜”。“孰能”之“孰”，宫、圣本作“熟”。“现喜笑”之“喜”，宋、元、明本作“微”。“动魔宫”之“魔”，圣本作“广”。

那时世尊便以偈颂回答马胜说：

```
马胜汝今请问我，
虚空行天受记事，
汝今问我大利益，
无量世间诸人天。
十力师子若无问，
不得为说佛子记，
汝于今日问如来，
广利一切世间故。
是空行天于我所，
以欣喜心供养我，
过于阿僧祇劫数，
灭除烦恼得成佛。
从于此间终没已，
便即生于天胜处，
于无量亿诸佛所，
悉知香花修供养。
于彼佛所发道心，
亦复增进菩提意，
以诸无量胜妙偈，
赞人师子自然智。
此等当于未来世，
无量无边诸佛所，
以胜香花而供养，
亦以妙偈而赞佛。
那罗延身菩萨等，
供养赞叹诸佛已，
于当来世欣喜劫，
得成最胜无上智。
```
（大意：马胜，你现在请问我虚空行天受记之事，你现在问我，大大利益无量世间的诸人天。十力师子若没有人问，便不能为佛子宣说授记，你今天问如来，是为了广利一切世间。这些空行天在我这里，以欢喜之心供养我，经过阿僧祇劫数，灭除烦恼，得以成佛。从这里命终之后，便生于天上的殊胜之处，在无量亿诸佛所，都以香花修习供养。在那些佛所发起道心，也增进菩提之意，以种种无量殊胜美妙的偈颂，赞叹人中师子的自然之智。这些人当在未来世，在无量无边诸佛所，以殊胜的香花供养，也以美妙的偈颂赞佛。具那罗延身的菩萨等，供养赞叹诸佛之后，在未来世的欣喜劫中，得以成就最殊胜的无上智慧。）

【按】“悉知香花”之“知”，宋、元、明、宫本作“以”，今从之。“以诸无量”之“诸”，宋、元、明、宫本作“说”。

```
其佛号曰花幢尊，
名称普闻无讥毁，
彼等八万天神众，
皆同一劫得作佛。
彼佛刹中无地狱，
亦无饿鬼及畜生，
彼土亦无修罗趣，
无有一切八难等。
此空行天成佛时，
彼土一切诸人民，
彼诸众生寿无量，
果报犹如忉利天。
其国不闻恶道名，
何况而有作恶者，
彼时众生皆如法，
一切悉是调伏众。
彼佛度人无量亿，
其数过于恒河沙，
为说无依无著法，
十力度脱彼众生。
彼佛入般涅槃已，
广布舍利起佛塔，
彼佛一一诸舍利，
于中皆现佛身相。
名称无毁诸身分，
为彼众生示神变，
无量亿数诸众生，
皆发无上菩提心。
导师如是智方便，
为彼空行天授记，
一切大众闻记已，
皆悉欣喜大踊跃。
```
（大意：那佛号为花幢尊，名称普闻，无有讥毁，那八万天神众都在同一劫中得以作佛。那佛刹中没有地狱，也没有饿鬼以及畜生，那国土也没有阿修罗趣，没有一切八难等。这些空行天成佛之时，那国土的一切人民，那些众生寿命无量，果报犹如忉利天。那国土听不到恶道之名，何况有作恶的人，那时众生都如法，一切都是调伏之众。那佛度人无量亿，其数超过恒河沙，为他们宣说无依无著之法，十力者度脱那些众生。那佛入般涅槃之后，广布舍利，建起佛塔，那佛的每一粒舍利中都显现佛的身相。名称无毁的佛身诸分，为那些众生示现神变，无量亿数的众生都发无上菩提心。导师以这样的智慧方便，为那些空行天授记，一切大众听闻授记之后，都欢喜大踊跃。）

【按】“导师如是智方便”以下四句，CBETA标点置于引号之外，今依句式并入偈中（下诸品同例）。

### 四天王授记品第十三

#### 四天王天化帐赞佛

那时九万四天王天，见到阿修罗、伽楼罗、龙女、龙王、鸠槃茶、乾闼婆、夜叉、紧那罗等供养如来，并听闻为空行天授记，都大欢喜，踊跃无量，对佛法深心信乐。譬如有人乘坐瓦船进入河中，心中这样想：“这瓦船不久当会损坏，在未沉没之前，可迅速渡到岸上，以免水难。”像这样，九万四天王天也是这样，见到佛的威神，为了得到佛法，生起深深的信乐，发起勇猛之心供养如来。那时四天王天并四天王变化出九万七宝妙帐，种种杂色，端妙稀奇，广大庄严华丽，其中多有赤真珠帐、火珠宝帐、琉璃宝帐、天金色帐、金刚珠帐。化作这样九万七宝帐之后，在虚空中绕佛三匝；又化作九万天乐，在虚空中也旋转绕佛三匝；又化作曼陀罗花、摩诃曼陀罗花、曼殊沙花、摩诃曼殊沙花、迦迦罗婆花、摩诃迦迦罗婆花，持这化花散在佛上，又绕三匝，便以偈颂赞佛说：

【按】“龙女、龙王”，圣本作“龙王、龙女”。“覩佛威神”之“覩”，明本作“观”。“金刚珠帐”之“珠”，宋、宫本无。

```
诸天有九亿，悉于导师所，
皆一心合掌，愿乐佛功德。
无掉亦无没，无贪亦无悔，
无举亦无下，故礼两足尊。
断除诸有种，亦灭无明暗，
拔除烦恼刺，能摧我慢山。
佛善拔毒箭，能灭诸疮疣，
善修不逸行，身圆满无减。
灭除诸烦恼，解脱一切缚，
断除诸结使，出离诸愦閙。
空及无相法，是佛之所行，
一切诸有中，其心无愿乐。
除断渴爱根，弃舍无明暗，
于诸四颠倒，悉皆能远离。
```
（大意：诸天有九亿，都在导师之所，都一心合掌，愿乐佛的功德。没有掉举也没有沉没，没有贪求也没有追悔，没有高举也没有低下，所以礼拜两足尊。断除诸有的种子，也灭除无明的黑暗，拔除烦恼之刺，能摧毁我慢之山。佛善于拔除毒箭，能灭除种种疮疣，善修不放逸之行，身体圆满无所减损。灭除种种烦恼，解脱一切系缚，断除种种结使，出离种种愦闹。空以及无相之法，是佛之所行，在一切诸有之中，其心没有愿乐。断除渴爱之根，弃舍无明之暗，对于种种四颠倒，都能远离。）

【按】“九亿”之“亿”，明本作“万”。

```
佛能知实际，世间无知者，
凡夫闻生惧，如鹿怖猎师。
堕身见众生，于空不能知，
无明所覆蔽，著世间系缚。
如实见真如，观世犹空拳，
为世显实智，由彼获净眼。
显示诸阴空，名色亦复然，
界法体非有，诸入亦如是。
此法及余法，以名字而说，
此名字诸法，佛说悉皆空。
譬如大幻师，化作种种像，
无众生施设，无命亦无人。
如是诸阴界，诸根十二入，
皆从幻化生，如来作是说。
```
（大意：佛能了知实际，世间没有能知的人，凡夫听了生起恐惧，如鹿畏怖猎人。堕于身见的众生，对空不能了知，被无明所覆蔽，执著于世间的系缚。佛如实见到真如，观察世间犹如空拳，为世间显示真实的智慧，由此他们获得清净之眼。显示诸阴是空，名色也是这样，界法的体性非有，诸入也是这样。这法以及其余的法，都以名字来宣说，这名字所表的诸法，佛说都是空。譬如大幻师，化作种种形像，没有众生可以施设，没有命者，也没有人。像这样，诸阴、诸界、诸根、十二入，都从幻化而生，如来这样宣说。）

```
譬如善画师，画作白象身，
枝节皆相似，高下亦复然。
实无高下相，但惑愚者眼，
是法界平等，愚者自迷惑。
佛皆为显示，如掌庵罗果，
智者不迷惑，善学诸佛教。
如来大智慧，为世间智炬，
转于妙法轮，教化诸群生。
当愿开觉我，无上寂菩提，
转于妙法轮，如佛今所转。
我等于世间，迷失道路者，
当为说妙法，如今佛所说。
```
（大意：譬如善于绘画的画师，画出白象之身，枝节都相似，高下也是这样，实际没有高下之相，只是迷惑愚者之眼；这法界平等，愚者自己迷惑。佛都为之显示，如掌中的庵罗果，智者不迷惑，善学诸佛之教。如来的大智慧，是世间的智慧之炬，转动美妙的法轮，教化诸群生。愿开悟我们，得到无上寂静的菩提，转动美妙的法轮，如佛现在所转的。我们对世间迷失道路的人，当为他们宣说妙法，如现在佛所说的。）

【按】“枝节”之“枝”，明本作“肢”。

#### 授四天王天记

那时世尊知道那四天王天深心所念，便即微笑，佛口中放出种种五色光明。那时马胜便以偈颂问如来说：

```
佛非无因缘，而现微笑相。
大雄佛世尊，愿为说笑缘。
覩佛现微笑，一切诸会众，
悉怀大疑惑，人尊应当知。
谁今坏魔众？谁今得除疑？
谁于法决定？唯愿人尊说。
谁今得供佛？谁奉佛教行？
此众皆怀疑，愿导师为说。
两足尊说记，众生若闻已，
悉皆除疑网，唯愿导师说。
复令诸众生，依于种智道，
速逮得菩提，是故应说记。
```
（大意：佛并非没有因缘而现出微笑之相，大雄佛世尊，愿为宣说微笑之缘。见到佛现出微笑，一切会众都怀有大疑惑，人中之尊应当知道。谁今天破坏了魔众？谁今天得以除去疑惑？谁对法得到决定？唯愿人中之尊宣说。谁今天得以供养佛？谁奉行佛的教示？这大众都怀疑惑，愿导师为我们宣说。两足尊宣说授记，众生若听闻之后，都除去疑网，唯愿导师宣说。又令众生依于一切种智之道，迅速得到菩提，所以应当宣说授记。）

【按】“奉佛教行”，圣本作“奉行佛教”。

那时世尊又以偈回答马胜说：

```
善哉汝马胜！为众故请佛，
其微笑因缘。
谛听为汝说。
为愍诸世间，当一心专听，
诸天满九万，悉皆住我前。
以清净信心，已曾供养佛，
复以偈赞叹，了知诸空法，
于法得决定，安住我法中。
此等诸天众，曾供八亿佛，
复于当来世，无量亿佛所，
供养彼诸佛，求于无上道。
于无量亿佛，若不供养者，
彼于菩提树，终不坐取证。
彼等当来世，得成于佛道，
号名曰大持，于世间最上。
```
（大意：善哉你马胜！为了大众请问佛微笑的因缘，谛听，我为你宣说。为了怜愍诸世间，应当一心专注谛听：诸天满九万，都住在我面前，以清净的信心，已经供养佛，又以偈赞叹，了知诸空之法，对法得到决定，安住于我的法中。这些诸天众曾供养八亿佛，又在未来世，在无量亿佛所，供养那些佛，求无上之道。对于无量亿佛，若不供养，他们在菩提树下终究不会坐而取证。他们在未来世得以成就佛道，号名为大持，于世间最上。）

【按】“坐取证”之“取”，圣本作“作”。“大持”之“大”，圣本作“火”。

```
彼诸世间灯，各有声闻众，
八十众会集，知见无障碍。
彼等成佛已，彼土诸众生，
一切皆寿命，具足八亿岁。
```

（大意：那些世间之灯各有声闻众，有八十次众会集会，知见无有障碍。他们成佛之后，那国土的众生，一切人的寿命都具足八亿岁。那佛有无量的智慧，有无数亿比丘，都远尘离垢，都住于最后身。那佛灭度之后，为那功德者庄严那佛刹，建造无量的塔。那无量千众以及百那由他众，供养那些塔庙，利益世间之人，有的发菩提心，有的证得涅槃。那佛灭度之后，正法久住于世，经过八亿年、无量那由他年，那些法王子为了护法而受持。四天王天众，那佛为他们授记之后，为了利益世间，成熟众生。大众得以听闻之后，心中都大欢喜，踊跃无量，奉顺如来的教示。）

### 三十三天授记品第十四

#### 帝释与忉利诸天化现供具

#### 诸天知法如幻

那时那八亿天这样想：“这些化现的天女供养如来，一切诸法也是这样，如佛所说。”他们了知一切法如幻化之后，对诸法没有疑网；对诸法得无疑之后，绕佛三匝，顶礼佛足，退住一旁。他们了知诸法如幻之后，也了知自身同于幻化，了知那供养以及如来也同于幻，佛所说的法也是这样。对种种幻法得无疑之后，便以偈颂赞佛说：

```
此诸化人设供养，
一切诸人亦复然，
帝释天等及诸法，
一切悉皆如幻化。
如来导师亦如幻，
声闻众从法化生，
于佛所说悉无疑，
能解如来所说记。
如来世尊所说法，
愚痴凡夫不能了，
如来所说诸法等，
一切悉皆犹如幻。

佛弟子众调伏者，
此等亦复如幻化，
我于此法得无疑。
世尊若人乐寂默，
独一无恼如骐驎，
此等一切悉同幻，
我于此法亦无疑。
```
（大意：这些化人所设的供养，一切人也是这样，帝释天等以及诸法，一切都如幻化。如来导师也如幻，声闻众从法化生，对佛所说都没有疑惑，能理解如来所说的授记。如来世尊所说的法，愚痴凡夫不能了知，如来所说的诸法等，一切都犹如幻。若诸有学以及无学、佛弟子众已调伏的人，这些也如幻化，我对此法得无疑惑。世尊！若有人乐于寂默，独自一人，无恼如麒麟，这些一切都同于幻，我对此法也无疑惑。）

```
若行佛行菩萨行，
利益众生不放逸，
彼是菩萨如来子，
一切悉皆如幻化。

十力大悲智无量，

如佛世尊所说法，
清凉寂静无所依，

善逝如法无所有，

于此佛法及智慧，
我等于中悉无疑。

见一切法亦如幻，
我等行此佛境界，

```
（大意：若行佛之行、菩萨之行，利益众生而不放逸，他们是菩萨、如来之子，一切都如幻化。善逝导师的自然之智，十力、大悲、智慧无量，智慧自在，世间最上，那佛这样也如幻。如佛世尊所说的法，清凉寂静，无所依止，得涅槃之法以及涅槃，这些也犹如幻。善逝如法而无所有，一切犹如幻化之性，对这佛法以及智慧，我们对其中都没有疑惑。我们常愿得以如佛一样，见一切法也如幻，我们行于这佛的境界，愿得成佛而无疑惑。）

#### 授忉利诸天记

那时世尊知道八亿三十三天深心信乐之后，便即微笑。那时慧命马胜便以偈颂请问佛说：

```
名称无比具诸德，
如来现笑非无因。
如来今日为何笑？
唯愿为说除我疑。
众见如来现微笑，
见已众皆怀犹豫，
唯愿除彼众疑惑，
令众勿怀诸疑网。
彼诸天众皆欣喜，
赞叹如来及供养，
如来现笑今为谁？
愿佛为说令众喜。
诸德清净犹如月，
应供养者愿为说，
如来所说彼若闻，
此等欣喜得成佛。
如此诸天大众等，
知一切法犹如幻，
诸天修学无障碍，
唯愿十力说此事。
一切大众若除疑，
以欣喜心修菩提，
起增上欲不下劣，
众闻即发勇猛心。
```
（大意：名称无比、具足诸德者，如来现出微笑并非无因。如来今天为什么笑？唯愿为我们宣说，除去我的疑惑。大众见到如来现出微笑，见了之后大众都怀犹豫，唯愿除去大众的疑惑，令大众不要怀有种种疑网。那些天众都欢喜，赞叹如来以及供养，如来现在现出微笑是为了谁？愿佛宣说，令大众欢喜。诸德清净犹如月亮、应受供养者，愿为宣说，如来所说的若被他们听到，这些人会欢喜而得成佛。这样的诸天大众等，了知一切法犹如幻，诸天修学没有障碍，唯愿十力者宣说这事。一切大众若除去疑惑，以欢喜之心修习菩提，生起增上的意欲而不下劣，大众听了便发起勇猛之心。）

那时世尊以偈颂回答马胜说：

```
马胜汝今问如来，
善合时机大利益，
佛知天众欣喜已，
我现笑缘今当说。
汝为天众问笑因，
今大利益诸众生，
我今为汝说笑因，
以清净心善谛听。
如是诸天大众等，
知一切法犹如幻，
无量无碍智见慧，
当来离暗得作佛。
过去流转生死中，
曾供诸佛如恒沙，
于彼佛所数修习，
一切诸法犹如幻。
今复于我设胜供，
亦知诸法同幻化，
此于佛法深信乐，
当来之世必成佛。
于此佛法所作福，
无有失坏及障碍，
天众于我供养已，
复知诸法犹如幻。
当来世近住劫中，
得成最胜说中胜，
彼胜福者皆同号，
名因陀罗幢王佛。
彼佛宣说如幻法，
度脱无量亿众生，
是故汝等舍放逸，
修一切法应如幻。
是不逸者我所化，
为满菩提分法故，
精进由如救头然，
速求寂灭胜菩提。
```
（大意：马胜你现在问如来，善合时机，有大利益，佛知道天众欢喜之后，我现出微笑的因缘现在当说。你为天众问微笑之因，现在大大利益众生，我现在为你宣说微笑之因，以清净心善加谛听。这样的诸天大众等，了知一切法犹如幻，具无量无碍的智见慧，将来远离黑暗，得以作佛。过去在生死中流转，曾供养如恒河沙数的诸佛，在那些佛所数数修习一切诸法犹如幻。现在又对我设置殊胜的供养，也了知诸法同于幻化，他们对佛法深心信乐，在将来之世必定成佛。在这佛法中所作的福德，没有失坏以及障碍，天众供养我之后，又了知诸法犹如幻。在将来世的近住劫中，得以成就最殊胜、说法中最殊胜者，那些殊胜福德者都同一名号，名为因陀罗幢王佛。那佛宣说如幻之法，度脱无量亿众生，所以你们应舍弃放逸，修习一切法应当如幻。这些不放逸的人是我所教化的，为了圆满菩提分法，精进犹如救头上之火，迅速求取寂灭的殊胜菩提。）

### 夜摩天授记品第十五

#### 夜摩天思惟世谛与第一义

那时又有四亿夜摩天众，见到阿修罗、伽楼罗、龙女、龙王、鸠槃茶、乾闼婆、夜叉、紧那罗、虚空行天、四天王天、忉利天等供养如来并听闻授记，都大欢喜，踊跃无量。那时夜摩天众知道佛如来以无碍之智为他们授记之后，便对佛法生起信乐之心；生起信乐之后，便这样想：“这样的佛法甚为奇妙。若证得佛法的人，没有不知的，没有不见的，没有不拣择的，没有不证的；对于已生、未生、现生，或已灭、当灭、现灭，或业以及果报，都如实了知。甚奇！如来能知世谛以及第一义，善知这二者，再没有其余。那佛世尊对空法善能知见，善知拣择，善证相应，所以名为萨波若。

【按】“萨波若”之“波”，明本作“婆”。萨波若，即一切智。

“什么是世谛？一切世俗的生死所行，对这些法都能通晓了知。第一义，就是没有言说，没有知者，不是心所能行。由于无知，所以没有能说者，没有显示者，没有开说者，没有听闻者；由于无说，也没有知者。无生无示，没有见者；没有施设，没有取著，没有觉知，没有能到者，也没有所到之处，没有能亲近的，没有能测量的，没有建立，没有弃舍，没有所作，也没有能作，无誉无毁，无利无衰，无称无讥，无苦无乐；非色非非色，非数非非数，非明非非明，非有烦恼非离烦恼，非世间非涅槃，非觉非观，非进非退，无动无作；没有戏论，超过一切戏论。所说的色相不可得，受、想、行、识也不可得；眼相不可得，耳、鼻、舌、身、意诸相也是这样；色相不可得，声、香、味、触、法相不可得；眼识相不可得，耳、鼻、舌、身、意识也不可得；眼触相不可得，耳、鼻、舌、身以及意触相也是这样；眼触所生的受也不可得，耳、鼻、舌、身、意触所生的受也是这样；色的思觉之相也不可得，乃至法的思觉之相也是这样；意相不可得，空相不可得，地界、水界、火界、风界、识界也不可得；欲界相不可得，色界相不可得，无色界相不可得；有为相不可得，无为相不可得。像这样等等，若那一一法以言说而没有能说者，像这样的法名为不可说之法。佛法最为殊胜，因为无闻愚痴的凡夫众生不能了知；听了之后惊怖，他们对佛法心生怖畏，对一切智智便即退失。诸天世人应当怜愍这样的众生，常处在生死之中，恒受苦切。”

【按】“能恻量”之“恻”，元、明、宫、圣本作“测”。“耳鼻舌身意诸相”之“意”，宫、圣本作“心意”。“意识亦不可得”之“识”，宋、元、明本作“识相”。“意相不可得”五字，宋、元、明、宫、圣本无。“苦切”之“切”，圣本作“忉”。

```
佛见诸阴皆空寂，
于其界入亦复然，
诸根聚积皆离相，
如来如实悉了知。
世间智者于实法，

所谓世谛及真谛，

如来悲愍于一切，
```

【按】“婢使”之“使”，《大正藏》作“便”，今依CBETA所录高丽藏作“使”。

```
观于世谛诸法已，

众生乐著于生死，
不能离于世八法，
所谓利衰及毁誉，

不净乐中说乐净，

```

```
此诸天众皆成佛。
```
（大意：若有人在佛法中如实观察而不颠倒，弃舍诸有，入于涅槃，犹如蛇脱去旧皮。一切诸法的体性无，空无有相，是第一义，若听闻这法而生爱乐，必得无上殊胜的菩提。如来如实宣说这法，除断天众的种种疑惑，都发无上菩提心，为了度一切众生。这样的天众发心之后，都欢喜，心意清净，得闻最殊胜的佛法之后，这些天众都将成佛。）

#### 授夜摩天记

那时世尊知道那四亿夜摩天众深心信乐，便即微笑。那时马胜便以偈颂问如来说：

```
佛为世间故现笑，
一切时众皆生疑。
唯愿世尊说笑因，
令此众会皆欣喜。
闻于诸天授记已，
一切皆悉大踊跃，
有智慧者发勇猛，
于佛法中如说行。
此佛如来诸胜众，
具足有佛功德器，
善哉宣说美妙言，
为摄如是大众故。
闻佛功德心喜乐，
此诸大众必当得，
闻于如来授记已，
如法当勤修精进。
善哉人尊说中胜，
于疑惑众二心者，
唯愿世尊速为说，
时众一心乐欲闻。
彼夜摩天授胜记，
愿人师子速为说，
此诸大众皆欣喜，
一切悉发菩提心。
```
（大意：佛为了世间而现出微笑，一切时众都生起疑惑，唯愿世尊宣说微笑之因，令这会众都欢喜。听闻诸天授记之后，一切都大踊跃，有智慧的人发起勇猛，在佛法中如所说而行。这佛如来的诸殊胜之众，具足佛的功德之器，善哉宣说美妙之言，为了摄受这样的大众。听闻佛的功德，心生喜乐，这些大众必定当得，听闻如来授记之后，如法当勤修精进。善哉人中之尊、说法中最殊胜者，对于疑惑之众、怀有二心的人，唯愿世尊迅速宣说，现时大众一心乐欲听闻。那夜摩天受殊胜之记，愿人中师子迅速宣说，这些大众都欢喜，一切都发菩提心。）

【按】“授胜记”之“授”，宋、元、明、宫本作“受”，今从之。

那时世尊便以偈颂回答马胜说：

```
为利世间故现笑，
马胜合时善咨问，
利益无量诸大众，
闻佛如来功德故。
乐著贪瞋诸众生，
于佛功德无乐惠，
其心愚痴所惑乱，
当没生死大海中。
若于佛法深信乐，
曾于先佛已请问，
与大悲心相应者，
是人能得佛功德。
若人见彼衰恼逼，
胜人于彼起悲心，
彼诸众生闻佛德，
顶受佛教如花鬘。
我诸众会大清净，
于先佛所曾修福，
彼于如来功德所，
顶受犹如婆师鬘。
夜摩天众先佛所，
曾修持戒除贪著，
厌离烦恼心清净，
于秽众生起悲心。
于无量佛曾亲近，
其数犹如恒河沙，
彼曾修习无量善，
为求无上菩提故。
```
（大意：为了利益世间而现出微笑，马胜合时而善于咨问，利益无量的大众，因为听闻佛如来的功德。乐著于贪瞋的众生，对佛的功德没有乐欲之心，其心被愚痴所惑乱，当沉没于生死大海之中。若对佛法深心信乐，曾在先佛处已经请问，与大悲心相应的人，这人能得佛的功德。若有人见到他人被衰恼所逼，殊胜之人对他们生起悲心，那些众生听闻佛的功德，顶受佛的教法如戴花鬘。我的诸会众大为清净，曾在先佛处修习福德，他们对于如来的功德，顶受犹如婆师花鬘。夜摩天众在先佛处曾修持戒，除去贪著，厌离烦恼，心意清净，对污秽的众生生起悲心。）

原文：“乐著贪瞋诸众生，于佛功德无乐惠”（大意：乐著于贪瞋的众生，对佛的功德没有乐欲之心。“乐惠”所指未详，存疑。）

```
知众生没烦恼已，
于苦众生起悲心，
于人师子利世者，
问诸法门无有量。
我今导师为彼说，
闻者悉得成佛道，
知彼众生烦恼钩，
为说最上胜妙法。
彼胜丈夫大导师，
为彼众生说空法，
彼闻诸佛所说已，
悉皆了知诸法空。
所谓空无诸法相，
说无自性无相法，
如是了知诸佛法，
悉皆安住佛功德。
此等胜妙供养我，
如法各自受记莂，
当于来世星宿劫，
悉皆得成无上道。
如是如来无增减，
其数满足四十亿，
其佛同号净智尊，
开悟无量诸众生。
大仙降伏诸怨者，
答于马胜所咨问，
满夜摩天所愿求，
大众天人皆欣喜。
```
（大意：曾亲近无量的佛，其数犹如恒河沙，他们曾修习无量的善，为了求无上菩提。知道众生沉没于烦恼之后，对受苦的众生生起悲心，向人中师子、利益世间者请问无量的法门。我现在作为导师为他们宣说，听闻的人都得成佛道，知道那些众生被烦恼之钩所钩，为他们宣说最上殊胜美妙之法。那殊胜的丈夫、大导师，为那些众生宣说空法，他们听闻诸佛所说之后，都了知诸法是空。所说的空，没有诸法之相，宣说无自性、无相之法，这样了知诸佛之法，都安住于佛的功德。这些人以殊胜美妙的供养供我，如法各自受到授记，将在未来世的星宿劫中，都得以成就无上道。这样的如来，不增不减，其数满足四十亿，那些佛同号净智尊，开悟无量众生。大仙、降伏诸怨敌者，回答马胜所咨问的，满足夜摩天所愿求的，大众天人都欢喜。）

【按】“所说已”之“说”，圣本作“记”。“记莂”之“莂”，圣本作“别”。“四十亿”之“十”，南藏作“千”。
