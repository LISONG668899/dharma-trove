# 窥基《大乘法苑义林章》（五十二）三身义林（五）·诸门分别

〔译注：本篇译《三身义林》第五门"诸门分别"。原文列十四门，详细解释的有前五门：

1. 常无常门：依《金光明经》《大乘庄严经论》《佛地论》《摄大乘论》，辨明三身各是哪一种常。窥基借《涅槃经》四记说明受用身不是本性常。
2. 自他二利门。
3. 有异无异门。
4. 三身形量门：讲受用身随十地所见逐渐广大，以及变化身示现的苦相实际上是无漏。
5. 所化有情共不共门：举释迦在底沙佛时翘足七日超越弥勒的公案，结论是所化有情有共有不共。

后九门窥基只注明见于哪些经论，不展开。本篇是《三身义林》的最后一篇。〕

《三身义林》第五门诸门分别，略有十四门。

## 一、常无常门

### （一）化身的常与无常

《金光明经》说："这样的三身，有一种意义说为常，有一种意义说为无常。化身恒常转法轮，所以处处如如方便相续不断，因此说为常。化身不是根本，具足的作用不显现，因此说为无常。"

《大乘庄严经论》说，常有三种：

1. 本性常
2. 不断常
3. 相续常

《佛地论》说："这变化身隐没以后又显现，因为变化没有穷尽，所以是相续常。化身的所依是常，所以也说为常。化身有生灭，所以也是无常。"这正与《金光明经》相同。

### （二）应身的常与无常

《金光明经》说："应身从无始以来相续不断，因为一切诸佛的不共之法能摄持应身。众生没有穷尽，应身的作用也不穷尽，因此说为常。应身不是根本，因为具足的作用不显现，所以说为无常。"

《佛地论》说："应身是不断常，因为恒常受用法乐，没有间断。应身的所依是常，所以也说为常。"依这种常的意义，《涅槃经》说获得常住的色等，又说："如果说如来身是无常，这个人的舌根为什么不堕落？"应身从因生起，有生灭，所以也说为无常。

### （三）以四记说明受用身不是本性常

各种论以及《涅槃经》第三十五卷都说，记别（回答问题的方式）有四种：

1. 一向记
2. 分别记
3. 返问记
4. 舍置记

这四记有两类：一是人的四记，二是法的四记。

人的四记：

1. 问："生者都会死吗？"答："是这样。"应当一向记别。
2. 问："死者还会再生吗？"答："应当分别：有烦恼的人，死了还会再生；没有烦恼的人，死了不再生。"应当分别记别。
3. 问："人是殊胜的吗？"应当反问对方："你和什么相比？"如果和天相比，回答说人是低劣的；如果和其余的众生相比，回答说人是殊胜的。应当返问记别。
4. 问："我是有还是无？"应当舍置不答。这是舍置记。

法的四记：

1. 问："生起的法都会灭吗？"答："是这样。"这是一向记。
2. 问："灭了的法还会再生吗？"答："这要分别：有因缘的，灭了还会再生；没有因缘的，灭了不再生。"二乘的五蕴没有大悲的因缘，入无余依涅槃，灭了不再生。如来之身只堕在法数中，不堕在生数中，因为有大悲，本愿还没有穷尽，有因缘，所以灭了又再生。这是分别记。
3. 问："声闻的善心是殊胜还是低劣？"应当反问对方："你和什么相比？"随着所比较的对象回答。这是返问记。
4. 问："第六蕴是善还是不善？"应当舍置不答。这是舍置记。

佛的受用身既然堕在法数中，"生起的法能灭"是一向记，所以不能说受用身是本性常。如果承认受用身从因生起，又说是本性常，就违背比量。

### （四）法身的常

《金光明经》中说："法身不是行法，没有变异的相状，因为没有变异；法身是自己的根本，因此说为常。"

如如法身不是行法，没有变异的相状；如如智法身是自己的根本。理与智广大，冥合无相，犹如虚空，因此说为常。

《佛地论》说："如如法身是自性常，因为离开各种分别和戏论，本性常住，没有生灭，因此说为常。"《涅槃经》依这种意义说："佛就是法，法就是僧，僧就是常，常就是虚空，虚空就是佛性，佛性就是法身。"

如如智身是不断常，因为众生没有穷尽，本愿没有穷尽，又不入涅槃，中间没有间断；与智冥合，如虚空没有边际，也离开分别和各种戏论，因此说为常。如果只说如如是法身，就只是自性常。

### （五）《摄大乘论》的异门常

《摄大乘论》问："佛的受用身和变化身既然是无常，为什么经中说如来身是常？"论中自己回答说："因为这两种身所依的法身是常。"

无性解释说："这不是身本身是常，是因为依止常住的身。"这显示等流身和变化身是异门的常，不是自性常。

论中又说："又，这两种身，因为恒常受用、没有休止，屡屡示现变化、不永远断绝，就像说'常受乐''常施食'。如来身是常，应当知道也是这样。"

无性解释说：

1. 受用身：因为恒常受用、没有休止，犹如世间说"常受乐"。受乐并不是恒常没有间断，也说"常受乐"。佛的受用身也是这样，各个菩萨受用法乐没有停止，受用身不是常住，也说为常。所以《胜鬘经》说："如来的色身没有穷尽，智慧也是这样。"
2. 化身：由于佛的化身屡屡示现变化，不永远断绝，犹如世间说"常施食"。施食并不是没有间断，屡屡布施，布施的心不断绝，称为常施食。化身也是这样，屡屡示现变化，不永远断绝。

这两种身说为常，是密意的常。

## 二、自他二利门

### （一）经论的说法

《金光明经》说："善男子，一切诸佛利益自他，达到究竟。自利益的是法如如，利益他人的是如如智。在利益自他之处，一切都得自在，因为成就种种无边的作用。所以分别佛法，有无量无边种种差别。"

《杂集论》说："佛的受用身，自利最殊胜；变化身，利他最殊胜；自性身，自利利他都殊胜。"他受用身本属利他所摄，从自受用身受用圣法之财，最为增胜，所以只说自利。

### （二）三身各属自利、利他

1. 法身：《佛地论》《成唯识论》都说法身寂静安乐，没有动作，所以正属于自利所摄。《金光明经》依这一点说"自利益的是法如如"，没有说法身能作为增上缘利益众生，所以法身也兼有利他。又，法身与受用、变化二身共同作为自利、利他的所依，所以属于自利、利他二利所摄。
2. 受用身有两种：
   - 自受用身：自己的愿行圆满，能自己受用微妙的法乐，正属于自利所摄。
   - 他受用身：为他人的愿行圆满，令诸菩萨受用大法乐，属于利他所摄。

   由于有这两种，有的说受用身只属于自利，有的说属于利他，有的说属于自利利他两者，都不相违。
3. 反过来解释《金光明经》"能利益他人的是如如智"：这是只说能作为受用身、变化身利益他人的，是如如智，并不遮止如如智也是自利。
4. 变化身：只为利他，示现各种变化的相状，属于利他所摄。

## 三、有异无异门

### （一）法身

《摄大乘论》说："诸佛的法身，因为依止、意乐、事业没有差别，应当说没有差异；因为无量的依身示现正等觉，应当说有差异。"

无性解释说："真如没有差异，依止没有差别；利益安乐众生的意愿相同，意乐没有差别；正觉、涅槃种种事业相同，事业没有差别。"这是说能依和所依都相同，所以说没有差异。

《佛地论》说："法身的真实体性是诸佛共有，所以没有差别。就能证的因有差别来说，假说有差别。"只就所依来说，没有差别，因为体性没有二；如果就能依来说，有差别，因为体性有不同。

### （二）受用身与变化身

《摄大乘论》又说："如说法身，受用身也是这样，因为意乐和事业没有差别，应当说没有差异；不是由于依止没有差别，因为无量的依止差别而转。变化身也是这样。"

《佛地论》说："其余两种身，各由不同的因所感，各有不同的自性，真实有差别。"这就是《摄大乘论》所说"无量的依身示现正等觉，应当说有差异"。只是诸佛没有各别的执着，利益安乐的意乐和事业平等，所以说没有差别，两种说法也不相违。

## 四、三身形量门

### （一）法身

《佛地论》说："法身没有边际，犹如虚空，遍满一切处，不能说法身形量的大小。"就相状来说，法身如虚空，没有边际。

### （二）自受用身

自受用身有色法和非色法：

1. 非色法：没有形相，不能说形量的大小。随着所依的身和所缘的境，也可以说遍满一切处。
2. 有色的各种法：大劫修因，得到殊胜的根和境，每一种相好都周遍法界，不同于生死业有分限，生死业所感的身形有小有大。

佛的无漏身，是在无量劫中，值遇无边的佛，断除无边的障，利益无边的众生，修习无量的善所生起，所以果也没有边际。由于大圆镜智所变现的身没有限量，诸佛所变现的身同处、同时，相状相似，互不障碍，始终没有间断地受用法乐，只有佛能了知，不是其余众生根识的境界。所以圣教说："无见顶相、无边法音，每一种功德作用都没有限量。"

### （三）他受用身

他受用身为诸菩萨显现种种身，言音、相好、形量不定。

《梵网经》说："我现在是卢舍那佛，正坐在莲花座上……乃至一国有一释迦。"

《华严经》等说：

1. 初地菩萨见到一百个佛国，一国就是一个大千世界。
2. 一个大千世界有一位释迦化身，每一个四天下各有一位化身。一个大千世界有一位大释迦，是四善根位所见；百亿小释迦，是其余三乘所见。
3. 初地菩萨自己见到百个大千世界有一位卢舍那佛，阿弥陀佛的身量就是初地菩萨所见。
4. 这样，二地菩萨见到一千个，三地菩萨见到一万个等，应当依此累计了知。
5. 乃至十地金刚心菩萨将要成佛时，色究竟天上有大宝莲花的相状显现，周圆的大小如十阿僧祇百千三千大千世界微尘的数量，其中一微尘相当于一个大千世界，菩萨坐在大宝莲花上成正觉。这时所见的佛身量难以了知。自受用身是这些菩萨所见不到的。

《法华经》等说阿难成佛时国土的大小，依此推知，那时的佛身属于他受用身所摄，是哪一地菩萨所见，依道理推算应当可以全部了知。

### （四）变化身

变化身化导地前的大众，资粮位、加行位二位所见不同，随大众所宜，形量不定。释迦牟尼佛身高一丈六尺，是众生身量的一倍；弥勒佛身高一千尺，随众生所宜而见。

他受用身、化身都是化现的色法，体性是四尘或五尘。非色的功德没有形质，也能化现。《成唯识论》说："无上觉者神力难思，所以能化现没有形质的法。"比如显现贪、嗔等，令其他众生了知。

《瑜伽师地论》说："变化不能变出四种事：一是心，二是心所，三是根，四是业果。"变化没有真实的作用，显现相似的心、心所法，就是相分的心；化现相似的五根，体性是四尘；显现相似的业果，体性就是无漏。六年苦行、马麦、金枪，看起来都像苦，实际上是无漏。

〔译注："马麦""金枪"指佛陀受报的故事：佛曾在毗兰若国三个月食马麦，又曾被金枪刺足。窥基依此说明变化身示现的苦相实为无漏。〕

## 五、所化有情共不共门

自性身、自受用身没有这种分别，他受用身和化身有这一门的意义。《佛地论》中略有三种说法。

### （一）第一说：全都是共

每一尊佛都能化导众生，福德、智慧平等，长时修行，同样求菩提。如说"一尊佛所化导的有情，就是一切佛所化导的有情"。所以可知全都是共。

### （二）第二说：全都不共

佛所化导的众生，本来就与这尊佛相系属。

1. 释迦牟尼佛在底沙佛的时候，曾经与弥勒菩萨同时奉事底沙佛。底沙佛观察所化的众生，释迦的所化先成熟，弥勒的所化后成熟；观察能化的菩萨，弥勒先成就，释迦后成就。底沙佛便入火光定，令释迦菩萨见到。释迦菩萨七日七夜翘起一只脚赞叹底沙佛，于是超越弥勒，在前面成佛。
2. 又，释迦牟尼佛说："我所应度化的，都已经度化完毕。"
3. 又，契经说：佛涅槃时，观察到有一位所化众生现在住在有顶天，将来应当生到这个世界，接受佛的化导。佛便留下一个化身，暗中住在这个世界，佛身示现涅槃。那位众生从有顶天命终，来生到这个世界，留下的化身才化导这位众生，这位众生成就无学以后，化身才灭去。
4. 又，处处说能化、所化互相系属，是决定的。

所以是不共。

### （三）第三说：如实义，有共有不共

如实的意义是：有共的，也有不共的。《成唯识论》也这样说：

1. 所化众生是共的：在同一处、同一时，诸佛各自变现，作为身，作为土，形状相似，互不障碍，辗转相杂，作为增上缘，令所化的众生由自己的识变现，认为在一个国土中有一尊佛身，为自己显现神通，说法饶益。
2. 所化众生是不共的：只有一尊佛变现。各类有情从无始以来，种姓法尔互相系属，或者多位众生系属一尊佛，或者一位众生系属多尊佛。

所以所化的众生有共、有不共。如果不是这样，多尊佛长久住世，各自辛劳，实际上就没有利益，因为一尊佛就能利益一切众生。这个意义详细如《佛地论》等所说。

## 六、其余九门

1. 第六，三身诸相门。
2. 第七，由几种自在得自在门。
3. 第八，三身依止几处门。
4. 第九，由几种佛法所摄持门。
5. 第十，受用身、变化身不是法身门。
6. 第十一，功德相应门。以上第六至第十一门都如《摄大乘论》所说。
7. 第十二，有漏、无漏识所变门，如《成唯识论》所说。
8. 第十三，净土差别门，如另外的义林所说。
9. 第十四，三身说法差别门，如《楞伽经》所说。

这三身的意义，差别无边，恐怕读者厌烦繁文，暂且略加指述。如《十地经》《金光明经》《楞伽经》《金刚般若经》《涅槃经》《胜鬘经》《解深密经》《法华经》《维摩诘经》，《瑜伽师地论》《摄大乘论》，两部《金刚般若论》，《对法论》《佛地论》《成唯识论》《宝性论》等论，以及《法华经疏》《维摩诘经疏》，都广泛辨析三身的相状。

（《三身义林》终）
