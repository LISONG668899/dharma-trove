# 见修行果之窍诀

**（藏文：ལྟ་སྒོམ་སྤྱོད་འབྲས་ཀྱི་གདམས་པ）**

**娘啦·白玛邓灯 造**

汉译：据藏文原颂，参汉译本

---

```
༄༅། །ལྟ་སྒོམ་སྤྱོད་འབྲས་ཀྱི་གདམས་པ།
```

大意：见、修、行、果之窍诀。

```
ལྟ་སྒོམ་སྤྱོད་འབྲས་ཀྱི་གདམས་པ་ནི། ན་མོ་མ་ཧཱ་གུ་རུ་བུདྡྷ་ཡ།
```

大意：见修行果之窍诀者，如下：南无、大师佛陀耶（顶礼大恩上师佛陀）！

```
ཕྱི་ནང་གསང་གསུམ་ཐེག་པའི་གྲུབ་མཐའི་ཁྱད། རྣམ་མང་ལེགས་བཤད་ཆུ་གཏེར་བརྒལ་བའི་གནད། སངས་རྒྱས་ཀུན་གྱི་དགོངས་དོན་གཅིག་ཆོག་དེ། རང་རིག་བླ་མ་ཤེས་པར་བྱིན་གྱིས་རློབས།
```

大意：外、内、密三乘之宗见虽各有差别，善说纷繁犹如渡越广大海藏，然而能超越此一切、堪为要害之关键，即是一切佛陀密意所归、独一而已足够之义——愿加持我，令我识得自觉本身即是上师！

```
ལྟ་བ་མ་བཅོས་རྩ་བྲལ་གཉུག་མའི་གཤིས། རྟོག་མེད་ཡེ་ཤེས་ལྟ་བ་མངོན་དུ་གྱུར། སྒོམ་པ་ཤེས་རིག་དམིགས་མེད་འཛིན་བྲལ་ངང་། བསྒོམས་མེད་འོད་གསལ་དགོངས་པ་ཀློང་དུ་གྱུར། སྤྱོད་པ་གང་ཤར་བརྟུལ་ཞུགས་ལམ་དུ་ཁྱེར། སྣང་སེམས་རོ་གཅིག་རྟོགས་པའི་སྤྱོད་པར་ཤར། འཁོར་འདས་གཉིས་མེད་རེ་དོགས་བྲལ་བའི་ངང་། ཆོས་ཉིད་དོན་གྱི་འབྲས་བུ་མནོང་དུ་གྱུར། ཅེས་སོ།
```

大意：所谓"见"，即是无有造作、离于根本之本然天成体性——离于分别念之本智，此见已然现前、显露无遗。所谓"修"，即是于能知之觉性、无所缘、离能执之境中——非由造作修持而生之明光，已然融入证悟之广境。所谓"行"，即是将凡所显现之一切，皆携入苦行瑜伽之道用中——显现与心识本为一味之证悟，即由此显露而成为其"行"。所谓"果"，即是于轮回涅槃无二、离于希冀与畏惧之境中——法性实义之果位，已然亲证现前。以上所说即是。

**无有造作、自然而生之见地窍诀，如下：**

```
ཡང་ཅིག་གསོན་དང་དད་ལྡན་སློབ་མའི་ཚོགས། མ་བཅོས་གནས་ལུགས་བརྟན་པ་ཐོབ་པའི་དུས། ལྟ་ཡང་མི་དགོས་འོད་གསལ་རང་བཞིན་འཆར། བསྒོམ་ཡང་མི་དགོས་སེམས་ཉིད་རང་སར་ཟིན། ཡེངས་ཀྱང་མི་སྲིད་རིག་པ་རང་ངོར་གནས། འགྱུ་བ་རང་སངས་དྲན་རིག་མཁའ་ལྟར་དག བཅའ་བཅོས་མི་དགོས་སྟོང་གསལ་ངང་ལ་གནས། རེ་དོགས་མི་དགོས་འཁོར་འདས་མཉམ་གྲོལ་ཡིན།
```

大意：具信弟子众等，且再听闻一次！当对无有造作之本住实相获得稳固证悟之时，其时纵然不求见地，明光之自性亦将自然显露；纵然不加修持，心之本性亦将自然安住于本位；纵然欲加散乱，亦无从散乱，觉性自然安住于自己本面之中；一切妄念之动摇皆自然清净，觉知犹如虚空一般清澄无染；无需任何调整造作，自然安住于空明之境；无需怀有任何希冀或畏惧，轮回与涅槃于此境中本自平等而解脱。

```
ཡང་ཅིག་གསོན་དང་སློབ་མའི་ཚོགས། ཡེ་གྲོལ་སེམས་ལ་མཚན་དཔེ་མེད། བལྟས་ཀྱང་མཐོང་མེད་སྟོང་པ་ཉིད། སྟོང་པ་མ་ཡིན་རིག་ཅིང་གསལ། རིག་སྟོང་དབྱེར་མེད་མཁའ་ལྟར་ཁྱབ། གཏད་མེད་ཟང་ཐལ་འགྲོ་འོང་མེད། མེད་ཀྱང་དྲན་རིག་སྣ་ཚོགས་འཆར། ཡོད་པ་མ་ཡིན་སྟོང་པ་སོང་། མེད་པ་མ་ཡིན་རང་རིག་སྣང་། སྣང་སྟོང་ཟུང་འཇུག་རྟོགས་པའི་རྩལ། རང་སེམས་ཡེངས་མེད་ཆོས་སྐུ་དང་། སངས་རྒྱས་དགོངས་པ་ཆོས་སྐུ་གཉིས། དབྱེར་མེད་འོད་གསལ་ངང་དུ་འདྲེས། སྟོང་ཉིད་ཆོས་སྐུའི་གཞི་རྩལ་ནས། ལྷུན་གྲུབ་འོད་གསལ་ཤར་བའི་དུས། མཁྱེན་བརྩེ་ཕྲིན་ལས་ནུས་མཐུ་འབར། ཡེ་ཤེས་རྩོལ་བྲལ་ཕྱོགས་མེད་རྒྱས། སྐུ་དང་ཞིང་ཁམས་དཔག་མེད་འཆར།
```

大意：弟子众等，且再听闻一次！本来解脱之心，本无任何相状可执；纵然凝目而观，亦无所见，此即是空性本身；然而它并非一无所有之空，乃是能知能觉、明朗清晰之空；觉性与空性无二无别，如虚空一般周遍一切；无有任何所缘、通透无碍，亦无来无去；然虽如此，却非全然无有——能忆念、能觉知之种种显现自然生起。它并非实有存在，因它本已趋入空性；然亦并非全然不存在，因自觉本身正在显现光明。显现与空性双运不二，正是证悟本身之力用展现。

自心不散乱，即是法身；佛陀之证悟密意，亦是法身——此二者于明光无二之境中融合为一。从空性法身之根基力用中，当任运自成之明光显露之时，智慧、慈悲、事业与威能之力，皆炽然显发；离于造作勤求之本智，无有偏向、周遍广大地展开；无量之佛身与佛刹，由此显露现前。

```
ཡང་ཅིག་གསོན་དང་སློབ་མའི་ཚོགས། སྤྲང་པོ་བདག་གི་ཉམས་ལེན་ནི། ལྟ་བ་རྫོགས་པ་ཆེན་པོ་ཡིན། སྒོམ་པ་ཕྱག་རྒྱ་ཆེན་པོ་ཡིན། སྤྱོད་པ་འདུལ་བ་ཁོ་ན་ཡིན།
```

大意：弟子众等，且再听闻一次！我这乞讨老丐所修持之法，其见地即是大圆满；其修持即是大手印；而其行止，唯是清净律仪（毗奈耶）而已。
