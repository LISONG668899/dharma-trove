# 事业不思议（帝洛巴不思议之二）

瑜伽自在帝洛巴说　据藏文译出

## 题解

本篇是帝洛巴"不思议"八篇口诀的第二篇（东北目录 D2306），跋语说是帝洛巴在力士宝珠城（གྱད་ཀྱི་ནོར་བུ）对一位威力者（མཐུ་ཅན，以咒术、威力为业的人）所说，名为"事业不思议"。全篇约六十句。帝洛巴借咒术师熟悉的忿怒事业，即钩召、诛灭、度脱等，开示其中真实的意义：所谓"度脱"，就是把一切安置于无生的法界；真正的"大事业"，是无所缘的心性。第八节明说：没有证悟真如而行度脱，就是罗刹之业，与正法相差如天地。

特别告诫：本篇通篇以忿怒事业为象征，所说的钩召、剖开、刺橛、度脱等，都是密乘象征语言，指的是以智慧断除我执与烦恼，绝不是世间的杀害。这类修法只能在具德上师座前，依具足的灌顶与口授领受。凡夫照字面理解或效仿，不仅不能成就，反而造下极重的恶业。

帝洛巴名下有八篇以"不思议"（bsam gyis mi khyab pa）为名的短篇口诀，在德格版丹珠尔续部释 ཞི 函中连续排列（第 246a 至 253a 页前后，东北目录 D2305 至 D2312）。第一篇之前有梵藏总题"大手印不思议"（梵 Acintyamahāmudrā，藏 phyag rgya chen po bsam gyis mi khyab pa），东北目录据此把第一篇编为 D2305。八篇各有独立的开头、礼敬与跋语，跋语都说是瑜伽自在帝洛巴在某地对某一种人所说，都没有译者的记载。八篇依次是：对瑜伽士说"自性不思议"，对威力者说"事业不思议"，对歌者说"音乐不思议"，对外道说"法性不思议"，对屠夫说"杀之结合不思议"，对吠陀师说"种种不思议"，对幻师说"事物不思议"，对娼女说"不思议大乐"。

这一组口诀的特点是"随类说法"：帝洛巴就每一种人所熟悉的行业与生活，把它转为认识心性的大手印之道。歌者的音声、屠夫的屠宰、幻师的幻术、娼女的欲乐，都被用作象征，指向同一个不可思议的心性。所以篇中凡是说到杀、欲、酒肉等，都是象征语言，绝不可照字面理解或效仿；涉及圆满次第风脉明点与事业手印的部分，只能在具德上师座前，依具足的灌顶与口授领受。

关于编号：所据的 Esukhia 电子版只在第一篇前标有 {D2305}，第二至第八篇没有单独的编号标记。本译依篇次顺序，把八篇依次配为 D2305 至 D2312，这一配属与东北目录通行的次序一致，但未能逐篇核对目录原书，读者须知。

体例：藏文原文全部保留在代码框中，按意义分节，每节后附汉译；凡标"存疑"的按语，表示本译对原文意思没有把握。藏文依 Esukhia 德格丹珠尔电子版，异文取第二读。

## 篇题

```
མཐུ་ཅན་ལ་གདམས་པ་བཞུགས། །
```

对威力者的教言。

## 一、敬礼嘿噜嘎

```
གདུག་པ་ཚར་གཅོད་ཡེ་ཤེས་ཆེན་པོའི་ཀློང། །
རབ་འབར་འཇིགས་བྱེད་ཧེ་རུ་ཀ་ལ་འདུད། །
ཐབས་དང་ལྡན་པ་རྣལ་འབྱོར་ཆེན་པོའི་གཞུང། །
མ་ལུས་རྒྱལ་བའི་རྗེས་སུ་འཇུག་པར་བྱ། །
```

敬礼断除恶毒者的大智慧广界——炽燃怖畏的嘿噜嘎！具足方便的大瑜伽之轨，应当完全随顺诸佛而行。

【按】嘿噜嘎（Heruka）是无上瑜伽续中忿怒相的本尊。本篇对一位以咒术、威力为业的人说法，所以从忿怒尊的礼敬开始。

## 二、忿怒事业的缘由

```
སྡང་བའི་སེམས་ཅན་ཞི་བས་མི་འདུལ་བ། །
གཉེན་པོས་ཚར་གཅོད་ཕྲིན་ལས་ཆེན་པོའི་ལུགས། །
བླ་མ་ལ་སྨོད་བསྟན་ལ་སྡང་སོགས་ལ། །
རང་གཞན་གྲོལ་ཕྱིར་བསྒྲལ་བའི་སྦྱོར་བ་ཙམ། །
མཉམ་ཉིད་རིག་པའི་རྣལ་འབྱོར་ཆོས་ཀུན་ནི། །
རོ་གཅིག་ཞི་བས་སྡུག་བསྔལ་རྒྱུ་འབྲས་བཅད། །
```

对于以寂静之法无法调伏的嗔恨众生，以对治来诛灭，是大事业的规则。对于毁谤上师、憎恨教法等人，为了使自己与他人解脱，［所用的］只是"度脱"的方法而已。了知平等性的瑜伽士，于一切法一味寂静，截断了痛苦的因与果。

【按】"度脱"（བསྒྲལ་བ），是密乘忿怒事业的专门术语，字面是"使之解脱"。传统上说，唯有已证空性、具足悲心与神通、能确实把对方的心识迁往净土的大成就者，才可以行此事业，目的是使对方免于继续造恶而堕落。本篇第八节明说：没有证悟真如而行度脱，就是罗刹之业。所以这里所说的一切，凡夫绝不可照字面理解或效仿。

## 三、钩召、剖开与净化

```
ཐབས་ལྡན་ལྕགས་ཀྱུས་འཁོར་ལོ་ཕུང་པོ་དགུག། །
ཐུགས་རྗེའི་ལྕིད་མནན་ཤེས་རབ་མཚོན་གྱིས་དྲལ། །
ཆུ་ཤིང་ཁ་ཕྱེ་མ་རིག་མུན་པ་བསལ། །
ཡེ་ཤེས་འོད་ཀྱིས་འབྱུང་བ་རིམ་པར་སྦྱངས། །
དེ་སེམས་གསལ་བ་ཉི་ཟླའི་གདན་སྟེངས་སུ། །
ཨ་ཧཱུཾ་སྦྱོར་བས་འོད་ཀྱི་སེམས་དཔའི་ཚུལ། །
```

以具足方便的铁钩，钩召［五］蕴之轮；以悲心的重物压住，以智慧的利刃剖开；剖开芭蕉树，除去无明的黑暗；以智慧之光依次净化诸大种。那心明亮，在日月座垫之上，以"阿""吽"结合，成为光明勇识的样子。

【按】以下第三至五节，是以忿怒事业为象征的观修次第，全部是象征语言。"芭蕉树"（ཆུ་ཤིང），佛典中常用来比喻五蕴中空无实；"剖开芭蕉树"，即看破五蕴无实。"依次净化诸大种"，是说地、水、火、风等大种次第融入、清净。

【按】"光明勇识"（འོད་ཀྱི་སེམས་དཔའ），这里指被观想为光明种子字之相的心识。这些观修的具体做法，篇中只举纲要，须依上师口授。

## 四、劝请往生，化为供云

```
འོག་མིན་གནས་སུ་ཡ་ཡིས་རབ་ཏུ་བསྐུལ། །
གཉིས་མེད་རྒྱལ་བའི་སྲས་གྱུར་རྡོ་རྗེ་སེམས། །
རིག་པའི་དབང་བསྐུར་གཞན་དོན་མཛད་པ་ཅན། །
ངོ་མཚར་སྒྱུ་མའི་དཔེ་བྱད་རྣམས་ཀྱིས་སྤྲས། །
ཕུང་པོ་ལ་སོགས་འབྱུང་བ་དབང་པོ་རྣམས། །
མཆོད་པའི་སྤྲིན་དུ་ཕྱོགས་བཅུ་ཁྱབ་པར་སྤྲོ། །
```

以"耶"字，殷切劝请［心识］前往色究竟天；成为无二的佛子金刚萨埵，具足明觉灌顶、能作利他之事者，以稀有如幻的相好为庄严。五蕴等诸大种与诸根，化为供养之云，遍满十方而放出。

【按】"耶"（ཡ）是风大的种子字，这里象征以风推动心识往生。"色究竟天"（འོག་མིན），是报身佛的净土。这一节的意思是：度脱的目的，是把对方的心识迁往净土，使他成为金刚萨埵；对方的蕴、界、根都转为供养。这是密乘迁识类修法的象征，须依灌顶与口授。

## 五、以手印之心要度脱罪恶

```
མཉམ་དུ་སྦྱོར་བས་དེ་ཉིད་ངེས་པ་ཡི། །
ཨ་ཡི་རང་བཞིན་ཐོག་མཐའ་མེད་པའི་ནང། །
ཏ་ལ་མངོན་མཚོན་བྲིས་པའི་གཟུགས་ལ་བལྟ། །
ཧཱུཾ་བལྟས་ཕུར་བུས་བཏབ་བསྐོར་རྩད་ནས་བཅད། །
ཕྱག་རྒྱའི་སྙིང་པོ་བདག་པོ་དགུ་འདས་པས། །
གོ་འཕང་སྟེར་བྱེད་ཆགས་པས་སྡིག་པ་སྒྲོལ། །
```

以平等结合，决定真如：在"阿"字无始无终的自性之中，观看画在多罗叶上、显明标示的形像；以"吽"观视，以橛刺入，旋转，从根本上断除。手印的心要，超越了九主，赐予果位；以贪爱度脱罪恶。

【按】"阿"字象征不生的空性，度脱是在空性中进行的。"画在多罗叶上的形像"，存疑："ཏ་ལ"可解为多罗叶，也可能指手掌或其他所依；一般认为指度脱仪轨中作为所依的像。"橛"（ཕུར་བུ），是忿怒事业所用的法器。

【按】存疑。"བདག་པོ་དགུ་འདས་པས"，"超越九主"，所指不明，可能指世间的九类神祇，也可能另有所指。"以贪爱度脱罪恶"，大概是说以方便道的乐空智慧清净罪业，与下节"嗔恨融入安乐"相应，意思不完全确定。

## 六、方便智慧相连的秘密方法

```
ཐབས་དང་ཤེས་རབ་འབྲེལ་པ་གསང་བའི་ཐབས། །
དཀའ་ཐུབ་ཚོགས་དང་བྲལ་བ་གྲུབ་པའི་ལམ། །
ཉི་ཟླའི་རྩི་ཟིན་ཞེ་སྡང་བདེ་བར་ཐིམ། །
ཉོན་མོངས་དྲན་རྟོག་ཤེས་རབ་སྣང་བར་གསལ། །
གོམས་པའི་སྦྱོར་བ་ལེགས་གཞག་བསྟན་པ་ཡིས། །
རྟེན་མེད་འཛིན་པ་བྲལ་བ་ཡེ་ཤེས་ལྷ། །
མཉམ་པར་སྦྱོར་བས་ཟག་མེད་བདེ་བ་ཆེ། །
གཉིས་འཛིན་བུད་ཤིང་མེ་ལྟར་རང་ཚིག་འགྱུར། །
```

方便与智慧相连，是秘密的方法；远离苦行与繁复的积聚，是成就之道。日月的精华被持住，嗔恨融入安乐；烦恼、念头与分别，显为智慧的光明。以熟习的结合，好好安置所开示的［方法］，无所依、离执取的智慧本尊，平等结合，就是无漏的大乐；二取就像木柴在火中，自己焚尽。

【按】"日月的精华被持住"，是圆满次第风脉明点修法的象征语，日、月指左右二脉或红白明点。"二取如木柴自焚"，是说能取与所取的执著，在智慧之火中自然烧尽，不需另外去除。

## 七、束缚与解脱皆如幻

```
དེ་ལྟར་ཤེས་པའི་སྐྱེས་བུ་འཛིན་པ་དང། །
འཕེལ་འགྲིབ་ཟག་པ་ཡོད་མེད་ལ་སོགས་པ། །
འཆིང་གྲོལ་ཁང་པར་སྣ་ཚོགས་སྣང་བ་ཀུན། །
སྒྱུ་མའི་སྦྱོར་བ་རྒྱལ་བའི་མཛད་པས་གནས། །
སྦྱོར་བས་གདུག་པ་མ་ལུས་བསྒྲལ་བྱ་ཞིང། །
བསྒྲལ་བས་སྐྱེ་མེད་དབྱིངས་སུ་ངེས་པར་སྦྱོར། །
དངོས་པོ་དངོས་མེད་འཇིག་རྟེན་འཇིག་རྟེན་འདས། །
སྤྱོད་ཡུལ་བྲལ་བས་གསང་བའི་ལམ་མཆོག་གོ། །
```

这样了知的人，对于执取与增减、有漏与无漏、有与无等等，在束缚与解脱之屋中的种种显现，一切都以如幻的结合、佛的事业而安住。以结合度脱一切恶毒者，以度脱决定结合于无生之界。事物与非事物、世间与出世间，因为远离了行境，所以是殊胜的秘密之道。

【按】"以度脱决定结合于无生之界"，是本篇的关键：所谓度脱，真实义是把一切安置于无生的法界，也就是证悟空性；不是世间所说的杀害。

## 八、无真如而度脱即罗刹之业

```
གནོད་སྦྱིན་སྲིན་པོའི་མཐུ་རྩལ་ངན་སོང་ལམ། །
གཉིས་འཛིན་ཞེན་པས་རང་རྒྱུད་འཁོར་བ་སྟེ། །
དེ་ཉིད་མེད་པར་གྲོལ་བ་སྲིན་པོའི་ལས། །
ཡང་དག་དོན་ལ་གནམ་ས་ལྟ་བུར་འགྱུར། །
ཐམས་ཅད་རང་བྱུང་བྱང་ཆུབ་སེམས་ཡིན་པས། །
འདི་ཉིད་མ་སྐྱེས་ཕྱོགས་རིས་ཆ་ཤས་བྲལ། །
མ་དམིགས་མི་དམིགས་དམིགས་སུ་མེད་པ་ཡི། །
ཕྲིན་ལས་ཆེན་པོས་མི་མཐུན་དྲི་མ་སེལ། །
```

夜叉、罗刹的威力，是恶趣之道；以二取的执著，自己的相续就是轮回。如果没有真如［的证悟］而行度脱，那是罗刹的行为，与真实义相差如天与地。一切都是自生的菩提心，它不生，远离偏党与部分；以无所缘、不缘、没有可缘的大事业，除去违缘的垢染。

【按】这一节是全篇最重要的告诫，原文明说：没有证悟真如而以咒术行度脱，就是罗刹之业，与正法相差如天地。帝洛巴对一位以咒术为业的人说法，正是要把他从这种恶趣之道中引出来，使他认识到真正的"大事业"是无所缘的心性。

## 九、种种事业成大乐

```
དགུག་དང་བཀུག་དང་འཐབ་དང་དགར་བ་དང། །
འདྲེན་དང་འཛིན་དང་འཁྱིལ་བར་བྱ་བ་སྟེ། །
སྦྱངས་དང་སྤེལ་བའི་ལས་ལ་ལེགས་བརྩམས་པས། །
རྒྱུན་ཆད་མེད་པའི་བདེ་བ་ཆེན་པོར་འགྱུར། །
```

钩召、已钩、斗、分离、引导、执持、缠绕等等［事业］，在净化与增益的事业上好好去做，就成为相续不断的大乐。

【按】存疑。这里列举的是咒术中常见的种种事业名目，原文只列名，具体所指不尽确定。这一节的意思是：在证悟心性的人那里，这些世间事业也都转为净化与增益之道，成为大乐。

## 十、超越思维的大事业

```
གསང་མཆོག་ཐེག་ལ་དབྱིངས་ལ་རབ་ཏུ་རྫོགས། །
ཕྱི་ནང་སྣོད་བཅུད་ཡེ་ཤེས་ཆེན་པོའི་སྐུ། །
གང་གིས་དཔག་པར་མི་ནུས་བསམ་ལས་འདས། །
རང་བྱུང་མཐའ་དབུས་མེད་པ་སྙིང་པོའི་གསང། །
དབང་པོ་དམན་དང་རྟོག་གེའི་ཡུལ་མིན་ཞིང། །
གང་དུ་འཆིང་བའི་ལས་ལ་སྤྱད་པས་ཀྱང། །
དེ་ཉིད་གྲོལ་བའི་མཆོག་སྟེར་རྒྱལ་སྲས་ལམ། །
འཕྲོ་འདུ་མེད་པ་རྒྱལ་བའི་དཀྱིལ་འཁོར་རོ། །
```

在殊胜秘密之乘中，于法界中完全圆满；外与内、器世间与有情，都是大智慧之身，任何人都无法测量，超越了思维。自生、无边无中，是心要的秘密，不是下根与思辨者的境界。即使在任何会造成束缚的事业上行持，它也赐予解脱的殊胜，这是佛子之道。没有放射与收摄，就是诸佛的坛城。

【按】"即使行于束缚之业，也赐予解脱"，是对已证心性者而说：对他们而言，世间的种种事业都能转为解脱之道。对没有证悟的人，同样的事业只会造成束缚，第八节已经说得很清楚。

## 跋语

```
རྣལ་འབྱོར་གྱི་དབང་ཕྱུག་ཏིལླི་པས། །
གྱད་ཀྱི་ནོར་བུའི་གྲོང་དུ་མཐུ་ཅན་ལ་གདམས་པ་ཕྲིན་ལས་བསམ་གྱིས་མི་ཁྱབ་པ་ཞེས་བྱ་བ་ཨི་ཐི། །
```

瑜伽自在帝洛巴在力士宝珠城，为一位威力者所说的教言，名为《事业不思议》。如是。

## 通篇连读

敬礼断除恶毒者的大智慧广界——炽燃怖畏的嘿噜嘎！具足方便的大瑜伽之轨，应当完全随顺诸佛而行。

对于以寂静之法无法调伏的嗔恨众生，以对治来诛灭，是大事业的规则。对于毁谤上师、憎恨教法等人，为了使自己与他人解脱，［所用的］只是"度脱"的方法而已。了知平等性的瑜伽士，于一切法一味寂静，截断了痛苦的因与果。

以具足方便的铁钩，钩召［五］蕴之轮；以悲心的重物压住，以智慧的利刃剖开；剖开芭蕉树，除去无明的黑暗；以智慧之光依次净化诸大种。那心明亮，在日月座垫之上，以"阿""吽"结合，成为光明勇识的样子。

以"耶"字，殷切劝请［心识］前往色究竟天；成为无二的佛子金刚萨埵，具足明觉灌顶、能作利他之事者，以稀有如幻的相好为庄严。五蕴等诸大种与诸根，化为供养之云，遍满十方而放出。

以平等结合，决定真如：在"阿"字无始无终的自性之中，观看画在多罗叶上、显明标示的形像；以"吽"观视，以橛刺入，旋转，从根本上断除。手印的心要，超越了九主，赐予果位；以贪爱度脱罪恶。

方便与智慧相连，是秘密的方法；远离苦行与繁复的积聚，是成就之道。日月的精华被持住，嗔恨融入安乐；烦恼、念头与分别，显为智慧的光明。以熟习的结合，好好安置所开示的［方法］，无所依、离执取的智慧本尊，平等结合，就是无漏的大乐；二取就像木柴在火中，自己焚尽。

这样了知的人，对于执取与增减、有漏与无漏、有与无等等，在束缚与解脱之屋中的种种显现，一切都以如幻的结合、佛的事业而安住。以结合度脱一切恶毒者，以度脱决定结合于无生之界。事物与非事物、世间与出世间，因为远离了行境，所以是殊胜的秘密之道。

夜叉、罗刹的威力，是恶趣之道；以二取的执著，自己的相续就是轮回。如果没有真如［的证悟］而行度脱，那是罗刹的行为，与真实义相差如天与地。一切都是自生的菩提心，它不生，远离偏党与部分；以无所缘、不缘、没有可缘的大事业，除去违缘的垢染。

钩召、已钩、斗、分离、引导、执持、缠绕等等［事业］，在净化与增益的事业上好好去做，就成为相续不断的大乐。

在殊胜秘密之乘中，于法界中完全圆满；外与内、器世间与有情，都是大智慧之身，任何人都无法测量，超越了思维。自生、无边无中，是心要的秘密，不是下根与思辨者的境界。即使在任何会造成束缚的事业上行持，它也赐予解脱的殊胜，这是佛子之道。没有放射与收摄，就是诸佛的坛城。
