# 彻却关要

麦彭仁波切 造

德！顶礼智慧勇识文殊菩萨。今宣说彻却之关要教言。

## 见如山王安住

```
ཤེས་པ་མ་བཅོས་རང་སོར་བཞག །དེ་ཡི་གཤིས་ལ་བབ་ཀིས་བལྟ། །
འདི་ཡིན་དེ་ཡིན་དམིགས་གཏད་ཀི། །རྣམ་པ་གང་ཡང་མེད་པ་ལ། །
བརོད་བྲལ་དེ་ཉིད་མོང་བ་ཡི། །རང་གདངས་འགགས་པ་མེད་པ་འདི། །
རྣལ་མ་གཤིས་ཀི་བབ་ཡིན་པས། །བསམ་གིས་མི་ཁྱབ་ཆོས་ཉིད་དོན། །
རང་བཞིན་འོད་གསལ་ལྷག་མཐོང་སེ། །ལྟ་བ་རི་བོ་ཅོག་བཞག་ཡིན།
```

心识不作任何造作，任其在本位上自然安住；就在此本然的自性上，以自然而然的方式观照。所谓「是此」、「是彼」之类一切能所安立、执取的形相皆不存在；然而，在这不可言诠的真如觉受当中，那无有间断的自性明力，便是本性如实安住的境界。此不可思议的法性之义、自性光明的胜观，即所谓「见如山王安住」之见。

## 修如大海安住

```
དེ་ཡི་བབ་ལ་གནས་བཞིན་དུ། །བསོམ་དུ་མེད་ལ་ཡེང་བ་མེད། །
དགག་སྒྲུབ་རོག་དཔོད་མི་གཞུག་པར། །རྣལ་མ་རང་བབ་ལྷུག་པར་བཞག །
བྱ་རོལ་འཆིང་བས་མ་བསླད་པའི། །ཆོས་ཉིད་བབ་ཀི་བསམ་གཏན་ཏེ། །
རྣལ་འབྱོར་ནམ་མཁའི་རྒྱལ་པོར་གནས། །སོམ་པ་རྒྱ་མཚོ་ཅོག་བཞག་ཡིན།
```

于此本然境界中安住之时，既无可修的「禅修」，也无所散的「散乱」；不作遮破、不作成立，不起寻思、不加观察，以坦然松展的方式，安住于本然自住之境。这种未被作意勤作的束缚所染污的、法性本然的等持，即安住于「虚空之王」般的瑜伽——所谓「修如大海安住」之修。

## 行如显现安住

```
དེ་ལྟར་བཞག་ཚེ་ནང་དུ་ནི། །སྣ་ཚོགས་རྣམ་རོག་རྒྱུ་བ་དང་། །
ཕི་རོལ་སྣང་བ་ཅི་ཤར་ཡང་། །དགག་སྒྲུབ་མེད་པར་རང་སར་བོར། །
གཤིས་ཀི་རང་བབ་མ་བརེད་ན། །གང་ཤར་ཕན་གནོད་བྲལ་བར་སྣང་། །
བཟང་ངན་བླང་དོར་རིས་གདབ་མེད། །སོད་པ་སྣང་བ་ཅོག་བཞག་ཡིན།
```

如是安住之时，内在无论生起何等形形色色的分别妄念，外在无论显现何等境相，皆不作遮破亦不作成立，任其在原位自然解脱。只要不忘失本性自住之境，则一切所现皆远离利与害；既无善恶之思，亦无取舍之算——所谓「行如显现安住」之行。

## 果如觉性安住

```
གོམས་ནས་སྣང་སིད་ཆོས་ཐམས་ཅད། །རིག་སོང་ཐིག་ལེ་ཉག་གཅིག་པོ། །
དེ་ཡི་ངང་དུ་འུབ་ཀིས་རོགས། །དེ་ནི་རོལ་མེད་ལྷུན་གིས་གྲུབ། །
རོལ་བས་སྤང་དང་བླང་བྱ་ཟད། །འཁོར་འདས་རེ་དང་དོགས་པ་མེད། །
གདོད་མའི་རང་བཞིན་མངོན་གྱུར་པ། །འབྲས་བུ་རིག་པ་ཅོག་བཞག་ཡིན།
```

如是串习纯熟之后，一切显有诸法皆融入觉空双运的唯一明点，于此境中一切一时圆满。此即无勤任运自成之境：勤作所行的取舍已然穷尽，对轮回涅槃再无希求与畏疑，本初自性直接现前——所谓「果如觉性安住」之果。

## 结语

```
ཅོག་བཞག་བཞི་ལྡན་མན་ངག་འདི། །ཁེགས་ཆོད་དགོངས་པ་མཐར་ཐུག་སེ། །
གནད་དང་ལྡང་ན་ཡུད་ཀིས་གོལ། །འཇམ་དཔལ་དཔལ་དང་ལྡན་པའི་མཆོག
```

此具足「四种安住」的窍诀，即是彻却之究竟密意。若能契合此关要，则于须臾之间获得解脱，现前具足文殊吉祥之最胜果位。
