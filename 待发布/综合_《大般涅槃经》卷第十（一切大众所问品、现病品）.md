# 《大般涅槃经》卷第十（一切大众所问品、现病品）

北凉·天竺三藏昙无谶 译　刘宋·沙门慧严等 依《泥洹经》再治

## 一切大众所问品第十七

### 纯陀奉献最后供养

那时世尊从面门放出青、黄、赤、白、红、紫种种颜色的光明，照在纯陀身上。纯陀遇到光明后，与他的眷属拿着种种肴膳，急速来到佛前，想奉献给如来及比丘僧最后的供养。种种器物盛满具足，拿到佛前。

那时有具大威德的天人，挡在他前面，周匝围绕，对纯陀说："纯陀，暂且停下，不要就去奉施。"那时如来又放出无量无边的种种光明，诸天大众遇到这光明后，随即允许纯陀到佛前奉献他的布施。

那时天人以及众生，各自拿着自己所带的供养来到佛前，长跪对佛说："唯愿如来允许诸比丘接受这些供养。"当时诸比丘知道时机已到，手持衣钵，一心安详。那时纯陀为佛及僧众布置种种狮子宝座，悬挂缯幡宝盖，以花香璎珞庄严。那时三千大千世界庄严微妙，犹如西方安乐国土。

那时纯陀站在佛前，忧悲惆怅，又对佛说："唯愿如来仍然哀悯我们，住寿一劫或将近一劫。"

佛告诉纯陀："你若想让我久住于世，应当赶快奉献最后的供养，具足檀波罗蜜。"

那时一切菩萨摩诃萨、天人与各类众生，异口同声地说："奇哉，纯陀！成就了大福德，能令如来接受他最后的无上供养。我们没有福报，所设的供具都白费了。"

那时世尊想令一切大众的愿望都得以满足，在自身每一个毛孔中化出无量佛，每一尊佛各有无量比丘僧，这些世尊以及无量大众，都示现接受他们的供养；释迦如来亲自接受纯陀所奉献的供养。那时纯陀所带来的粳米熟食，是摩伽陀国的量器满满八斛，以佛的神力，都足以充饱整个大会。那时纯陀见到这件事，心生欢喜，踊跃无量；一切大众也是如此。

那时大众承佛的圣意，各自这样想："如来现在已经接受了我们的布施，不久就要入于涅槃了。"这样想后，心中悲喜交集。那时树林之地狭小，以佛的神力，连针尖那样大的地方，都有无量诸佛世尊及其眷属坐着进食，所吃的食物也没有差别。

这时天、人、阿修罗等啼泣悲叹，这样说："如来今天已经接受了我们最后的供养，接受供养之后，就要般涅槃了。我们还能再供养谁呢？我们现在永远离开了无上调御师，如同盲人失去了眼目。"

### 佛说安慰大众偈

那时世尊为了安慰一切大众，说偈：

```
汝等莫悲叹　诸佛法应尔
我入于涅槃　已经无量劫
常受最胜乐　永处安隐处
汝今至心听　我当说涅槃
我已离食想　终无饥渴患
今当为汝等　说其随顺愿
令诸一切众　咸得安隐乐
汝闻应修行　诸佛法常住
假使乌与枭　同共一树栖
犹如亲兄弟　尔乃永涅槃
如来视一切　犹如罗睺罗
常为众生尊　云何永涅槃
假使蛇鼠狼　同处一穴游
相爱如兄弟　尔乃永涅槃
如来视一切　犹如罗睺罗
常为众生尊　云何永涅槃
假使七叶花　转为婆师香
迦留为镇头　尔乃永涅槃
如来视一切　犹如罗睺罗
云何舍慈悲　永入于涅槃
假使一阐提　现身成佛道
永处第一乐　尔乃入涅槃
如来视一切　皆如罗睺罗
云何舍慈悲　永入于涅槃
假使一切众　一时成佛道
远离诸过患　尔乃入涅槃
如来视一切　皆如罗睺罗
云何舍慈悲　永入于涅槃
假使蚊蚋水　浸坏于大地
川谷海盈满　尔乃入涅槃
悲心视一切　皆如罗睺罗
常为众生尊　云何永涅槃
以是故汝等　应深乐正法
不应生忧恼　号泣而啼哭
若欲自正行　应修如来常
当观如是法　长存不变易
复应生是念　三宝皆常住
是则获大护　如咒枯生果
是名为三宝　四众应善听
闻已应欢喜　即发菩提心
若能计三宝　常住同真谛
此则是诸佛　最上之誓愿
```

（大意：你们不要悲叹，诸佛之法本应如此。我入于涅槃，已经无量劫了，常受最胜之乐，永远处在安稳之处。你们现在至心听，我当宣说涅槃。我已离开饮食之想，终究没有饥渴之患，现在当为你们宣说随顺之愿，令一切大众都得安稳之乐；你们听了应当修行，诸佛之法常住。假使乌鸦与猫头鹰同栖一树，亲如兄弟；假使蛇、鼠、狼同处一穴，相爱如兄弟；假使七叶花变成婆师花的香气，迦留树变成镇头迦树；假使一阐提现身成就佛道，永处第一之乐；假使一切众生同时成就佛道，远离诸过患；假使蚊蚋的一滴水能浸坏大地，令河川山谷与大海都盈满——直到这些事都发生了，如来才会永入涅槃。如来以悲心看待一切众生，都如罗睺罗，常为众生之尊，怎会舍弃慈悲，永入涅槃呢？所以你们应当深乐正法，不应生起忧恼，号泣啼哭。若想自正其行，应当修习如来常住之想，应当观察这样的法长存不变易；又应当生起这样的念头：三宝都是常住。这样就能得到大护佑，如以咒力令枯树生出果实。这名为三宝，四众应当善听；听了应当欢喜，随即发起菩提之心。若能计执三宝常住，同于真谛，这就是诸佛最上的誓愿。）

"若有比丘、比丘尼、优婆塞、优婆夷，能以如来最上的誓愿而发愿，应当知道这人没有愚痴，堪受供养；以这愿力的功德果报，在世间最为殊胜，如阿罗汉。若有不能这样观察了知三宝常住的，是旃陀罗。若有能知道三宝常住真实之法的因缘，就能离苦安乐，没有娆害与能作障难的人。"

那时人天大众、阿修罗等，听了这法，心生欢喜，踊跃无量，其心调柔，善灭诸盖，心无高下，威仪清净，容颜怡悦，知道佛是常住，所以设置诸天的供养，散种种花、末香、涂香，奏天上的伎乐来供养佛。

### 大众见希有之事

那时佛告诉迦叶菩萨："善男子，你见到这大众的希有之事了吗？"

迦叶答道："已经见到了，世尊。我见到诸如来无量无边、不可称计，接受大众人天所奉的饭食供养；又见到诸佛高大庄严的身体，所坐之处只如一个针尖，却有许多大众围绕，互不障碍；又见到大众都发了誓愿，说了十三首偈；也知道大众各自心想：'如来现在只接受我的供养。'假使纯陀所奉献的饭食碎如微尘，一尘供养一佛，尚且不能周遍；以佛的神力，都令一切大众充足。唯有诸菩萨摩诃萨、文殊师利法王子等，才能了知这样的希有之事，这都是如来的方便示现。声闻大众以及阿修罗等，都知道如来是常住之法。"

那时世尊告诉纯陀："你现在所见的，是希有奇特之事吗？"

"确实如此，世尊。我先前所见的无量诸佛，以三十二相、八十种好庄严其身；现在却都见他们成了菩萨摩诃萨，身躯巨大殊异，容貌无比；只见佛身犹如药树，被诸菩萨摩诃萨等所围绕。"

佛告诉纯陀："你先前所见的无量佛，是我所化现的，为了利益一切众生，令他们得到欢喜。这样的菩萨摩诃萨等所修的行，不可思议，能作无量诸佛的事业。纯陀，你现在已经全部成就了菩萨摩诃萨的修行，得住十地，菩萨所行已经具足成办。"

迦叶菩萨对佛说："世尊，是这样，是这样，正如佛所说，纯陀所修的已成就菩萨之行，我也随喜。现在如来想为未来的无量众生作大光明，所以宣说这大乘《大涅槃经》。世尊，一切契经所说，有有余之义与无余之义吗？"

"善男子，我所说的，也有有余之义，也有无余之义。"

### 布施唯除一阐提

纯陀对佛说："世尊，如佛所说：

```
所有之物　布施一切
唯可赞叹　无可毁损
```

（大意：以所有之物布施一切人，只值得赞叹，没有可以毁訾的。）

"世尊，这是什么意思？持戒与毁戒有什么差别？"

佛说："唯除一人，其余一切布施都值得赞叹。"

纯陀问道："什么叫唯除一人？"

佛说："就是如这部经中所说的破戒之人。"

纯陀又说："我现在还不理解，唯愿为我解说。"

佛告诉纯陀："所说的破戒，是指一阐提。其余对一切人的布施，都值得赞叹，能获大果报。"

纯陀又问："一阐提是什么意思？"

佛告诉纯陀："若有比丘、比丘尼、优婆塞、优婆夷，说粗恶的话诽谤正法，造了这样的重业，永不改悔，心无惭愧，这样的人名为趋向一阐提之道。若犯了四重禁，造了五逆罪，自知确实犯了这样的重罪，而心中从无怖畏惭愧，不肯发露，对佛的正法永远没有护惜建立之心，毁谤轻贱，言语多有过失，这样的人也名为趋向一阐提之道。若又说没有佛、法、僧，这样的人也名为趋向一阐提之道。唯除这样的一阐提之辈，布施其余的人，一切都值得赞叹。"

### 破戒者可以拔济

那时纯陀又对佛说："世尊，所说的破戒，是什么意思？"

佛告诉纯陀："若犯四重禁及五逆罪、诽谤正法，这样的人名为破戒。"

纯陀又问："这样的破戒之人可以拔济吗？"

佛告诉纯陀："有因缘就可以拔济。若他身穿法衣，还没有舍离，心中常怀惭愧恐怖而自我责备：'唉！我为什么犯了这样的重罪？多么怪异啊，竟造了这样的苦业！'深自改悔，生起护法之心，想要建立正法：'有护法的人，我当供养；若有读诵大乘经典的人，我当向他请问，受持读诵；通利之后，又当为他人分别广说。'我说这人不是破戒。为什么呢？善男子，譬如太阳出来，能除去一切尘翳黑暗；这大涅槃微妙经典出现于世，也是这样，能除去众生在无量劫中所作的众罪。所以这部经说护持正法能得大果报，能拔济破戒之人。

"若有毁谤这正法的人，能自己改悔，回归于正法，自己念及所作的一切不善，如人自害，心生恐怖、惊惧、惭愧，除了这正法再没有别的救护，所以应当回归正法。若能这样如所说而归依，布施这人，得福无量，也名为世间应受供养的人。若犯了以上的恶业之罪，经过一个月或十五天，仍不生起归依发露之心，布施这人，果报很少。犯五逆罪的人也是这样，若能生起悔心，内怀惭愧：'我现在所作的不善之业甚为大苦，我当建立护持正法。'这就不名为五逆罪了，布施这人，得福无量。犯了逆罪之后，不生起护法归依之心，布施这样的人，福报不值一提。

"又，善男子，关于犯重罪的人，你现在仔细听，我当为你分别广说。他应当生起这样的心：'所谓正法，就是如来微密之藏，所以我当护持建立。'布施这样的人，能得殊胜的果报。

"善男子，譬如一个女人怀孕将要生产，遇到国家荒乱，远到他乡，在一座天庙中生下了孩子。后来听说故乡安稳丰熟，就带着孩子想回本土。途经恒河，河水暴涨湍急，她背着孩子不能渡过，就自己想：'我宁可与孩子一同丧命，终究不舍弃他而独自渡河。'这样想后，与孩子一同沉没。命终之后，随即生于天上，因为她慈念孩子，想令孩子得以渡河。而这女人本性弊恶，因为爱子的缘故，得以生于天上。犯四重禁、五无间罪的人生起护法之心，也是这样，虽然先前造了不善之业，因为护法的缘故，得以成为世间无上的福田。这护法的人有这样无量的果报。"

### 一阐提如苦核不生

纯陀又说："世尊，若一阐提能自己改悔，恭敬供养赞叹三宝，布施这样的人能得大果报吗？"

佛说："善男子，你现在不应这样说。善男子，譬如有人吃了庵罗果，把果核吐在地上，又想：'这果核中应当有甜味。'就又拿回来，破开尝尝，味道极苦，心生悔恨，怕失去果种，就又收拾起来种在地里，勤加修治，以酥油乳汁随时浇灌。你意下如何？难道能生长吗？"

"不能，世尊。即使天降无上的甘雨，也仍然不会生长。"

"善男子，那一阐提也是这样，烧灭了善根，在哪里能除罪呢？善男子，若生起善心，就不名为一阐提了。善男子，因为这个道理，一切布施所得的果报，并非没有差别。为什么呢？布施诸声闻所得的果报不同，布施辟支佛所得的果报也不同，唯有布施如来，获得无上之果。所以说一切布施并非没有差别。"

【按】"若生善心，是则不名一阐提也"，与卷五"是人若于佛正法中心得净信，尔时即便灭一阐提"相应：一阐提是就断善根、不生善心的状态而说，一旦生起善心，就已不是一阐提。

纯陀又说："如来为什么说这首偈？"

佛告诉纯陀："有因缘，所以我说这首偈。王舍城中有一位优婆塞，心中没有清净的信仰，事奉尼乾子，来问我布施的意义，因为这个因缘，所以说这首偈；也是为菩萨摩诃萨等宣说秘藏之义。这首偈的意义是什么呢？所说的'一切'，是少分的一切。应当知道，菩萨摩诃萨是人中之雄，摄取持戒的人，施予他们所需；舍弃破戒的人，如除去稊稗。

### 有余之偈：江河、丛林、女人、自在

"再者，善男子，如我过去所说的偈：

```
一切江河　必有回曲
一切丛林　必名树木
一切女人　必怀谄曲
一切自在　必受安乐
```

（大意：一切江河必有回曲，一切丛林必定称为树木，一切女人必怀谄曲，一切自在者必受安乐。）"

那时文殊师利菩萨摩诃萨即从座起，偏袒右臂，右膝着地，上前礼佛足，说偈：

```
非一切河　必有回曲
非一切林　悉名树木
非一切女　必怀谄曲
一切自在　不必受乐
```

（大意：不是一切河都必有回曲，不是一切林都称为树木，不是一切女人都必怀谄曲，一切自在者不一定受乐。）

"佛所说的偈，其义有余，唯愿垂哀，宣说其中的因缘。为什么呢？世尊，在这三千大千世界中，有一个洲名叫拘耶尼，那洲中有一条河，端直不曲，名叫娑婆耶，犹如直绳流入西海。这样的河相，佛在其他经中从未说过。唯愿如来因为这方等阿含经而说其有余之义，令诸菩萨深信理解。世尊，譬如有人先认识金矿，后来却不认识金子；如来也是这样，完全了知诸法，而所演说的却有余而不尽。如来虽然作这样有余的说法，我们应当以方便理解其中的意趣。'一切丛林必是树木'，这也是有余。为什么呢？种种金、银、琉璃宝树，也名为林。'一切女人必怀谄曲'，这也是有余。为什么呢？也有女人善持禁戒，功德成就，有大慈悲。'一切自在必受安乐'，这也是有余。为什么呢？有自在的转轮圣帝，以及如来法王，不属于死魔，不可灭尽；梵天、帝释诸天虽然得到自在，却都是无常。若得常住而无变易，才名为自在，就是大乘大般涅槃。"

佛说："善男子，你现在善得乐说之辩。暂且停下，仔细听。文殊师利，譬如长者身患病苦，良医诊治，为他调配膏药。这时病人贪多，想多服，医生对他说：'若能消化，就可以随意多服；你现在身体羸弱，不应多服。应当知道这膏药也名为甘露，也名为毒药，若多服而不能消化，就名为毒。'善男子，你现在不要以为这医生所说的违背义理，损失了膏药的效力。善男子，如来也是这样，为了诸国王、后妃、太子、王子、大臣，因为波斯匿王的王子、后妃有憍慢之心，为了调伏他们，示现恐怖，如那良医，所以说这首偈：

```
一切江河　必有回曲
一切丛林　必名树木
一切女人　必怀谄曲
一切自在　必受安乐
```

"文殊师利，你现在应当知道，如来所说没有漏失。即使这大地可以翻覆，如来的话终究没有漏失。因为这个道理，如来所说的一切都有余义。"

那时佛赞叹文殊师利："善哉，善哉！善男子，你早已知道这样的意义，因为怜悯一切众生，想令众生得到智慧，所以广问如来这样的偈义。"

### 但自观身偈

那时文殊师利法王子又在佛前说偈：

```
于他语言　随顺不逆
亦不观他　作以不作
但自观身　善不善行
```

（大意：对于他人的言语，随顺而不违逆；也不观察他人作了什么、没作什么；只观察自身的善行与不善行。）

"世尊，如来说这法药，并不是正说。'对他人的言语随顺不逆'，唯愿如来垂哀而作正说。为什么呢？世尊常说，一切外道九十五种都趋向恶道，声闻弟子都趋向正路；若护持禁戒，摄持威仪，守慎诸根，这样的人深乐大法，趋向善道。如来为什么在九部经中，见到有毁谤他人的，就加以呵责？这首偈的意义是趋向什么？"

佛告诉文殊师利："善男子，我说这首偈，也不是全为一切众生，那时只是为了阿阇世王。诸佛世尊若没有因缘，终究不作逆说；有因缘，才这样说。善男子，阿阇世王杀害了他的父亲之后，来到我这里，想折伏我，这样问：'世尊，你是一切智还是非一切智？若是一切智，调达在过去无量世中常怀恶心，追随如来想要加害，如来为什么允许他出家？'善男子，因为这个因缘，我为这位国王说这首偈：

```
于他语言　随顺不逆
亦不观他　作以不作
但自观身　善不善行
```

"佛告诉大王：'你现在杀害了父亲，已造逆罪，是最重的无间罪，应当发露，以求清净，为什么反而去看别人的过失？'善男子，因为这个道理，我为那位国王说这首偈。

"再者，善男子，也是为护持不毁禁戒、成就威仪而见到他人过失的人说这首偈。若又有人接受他人的教诲，远离众恶，又教他人令其远离众恶，这样的人就是我的弟子。"

### 恕己为譬偈

那时世尊为文殊师利又说偈：

```
一切畏刀杖　无不爱寿命
恕己可为譬　勿杀勿行杖
```

（大意：一切众生都畏惧刀杖，没有不爱惜生命的；推己及人，以自己作比，不要杀生，不要施以杖罚。）

那时文殊师利又在佛前说偈：

```
非一切畏杖　非一切爱命
恕己可为譬　勤作善方便
```

（大意：不是一切众生都畏惧杖罚，也不是一切都爱惜生命；推己及人，以自己作比，应当勤作善巧方便。）

"如来所说这法句的意义，也是未尽。为什么呢？如阿罗汉、转轮圣王、玉女、象宝、马宝、主藏大臣，若诸天人以及阿修罗手持利剑能伤害他们，没有这样的事。勇士、烈女、马王、兽王、持戒的比丘，即使刀杖临头也不恐怖。因为这个道理，如来所说的偈也是有余。若说'恕己可为譬'，这也是有余。为什么呢？若使阿罗汉以自己比喻他人，就有我想以及命想；若有我想以及命想，就应当拥护自己。凡夫也会见到阿罗汉都是有我想命想的行人，若这样，就是邪见；若有邪见，命终应当生于阿鼻地狱。又，阿罗汉对众生生起害心，没有这样的事；无量众生也没有能伤害阿罗汉的。"

佛说："善男子，所说的我想，是对众生生起大悲心，没有杀害之想，是说阿罗汉的平等之心。不要以为世尊没有因缘而作逆说。过去在这王舍城中有一个大猎人，杀了许多群鹿，请我吃肉。我那时虽然接受了他的邀请，对一切众生生起慈悲心，如对罗睺罗，说偈：

```
当令汝长寿　久久住于世
受持不害法　犹如诸佛寿
```

（大意：愿你长寿，长久住世；受持不害之法，如诸佛之寿那样长久。）

"所以我说这首偈：

```
一切畏刀杖　无不爱寿命
恕己可为譬　勿杀勿行杖
```

佛说："善哉，善哉，文殊师利！你为了诸菩萨摩诃萨，请问如来这样的秘密之教。"

### 敬父母而堕无间

那时文殊师利又说偈：

```
云何敬父母　随顺而尊重
云何修此法　堕于无间狱
```

（大意：怎么会恭敬父母，随顺尊重，修这样的法，反而堕入无间地狱？）

于是如来又以偈回答：

```
若以贪爱母　无明以为父
随顺尊重是　则堕无间狱
```

（大意：若以贪爱为母，以无明为父，随顺尊重它们，就会堕入无间地狱。）

### 属他为苦偈

那时如来又为文殊师利重说偈：

```
一切属他　则名为苦
一切由己　自在安乐
一切憍慢　势极暴恶
贤善之人　一切爱念
```

（大意：一切受制于他人的，名为苦；一切由自己做主的，自在安乐；一切憍慢的人，势力极为暴恶；贤善之人，一切人都爱念。）

那时文殊师利菩萨摩诃萨对佛说："世尊，如来所说的这首偈也是不尽，唯愿如来再垂哀悯，宣说其中的因缘。为什么呢？如长者之子跟随老师学习时，是属于老师还是不属于老师？若说属于老师，义理不成；若说不属于，也不成；若说得自在，也不成。所以如来所说有余。

"再者，世尊，譬如王子什么都没学过，做什么事都不成，这也是自在，却愚暗常苦。这样的王子，若说他自在，义理不成；若说他属于他人，义理也不成。因为这个道理，佛所说的意义名为有余。所以一切属于他人的，不一定受苦；一切自在的，不一定受乐。

"'一切憍慢，势极暴恶'，这也是有余。世尊，如诸烈女因为憍慢心的缘故出家学道，护持禁戒，威仪成就，守摄诸根，不令驰散。所以一切憍慢之结不一定暴恶。

"'贤善之人，一切爱念'，这也是有余。如有人内心犯了四重禁，却不舍法服，坚持威仪，护持正法的人见了，不会爱这个人，这人命终必定堕入地狱。若有善人犯了重禁，护持正法的人见了，就会把他驱逐出去，令他舍道还俗。因为这个道理，一切贤善之人不一定都被爱念。"

那时佛告诉文殊师利："有因缘，所以如来在这里说有余之义。又有因缘，诸佛如来才说这法。那时王舍城有一个女人，名叫善贤，回父母家，顺便来到我这里，归依我以及法、僧，这样说：'一切女人的处境都不自由，一切男子都自在无碍。'我那时知道这女人的心意，就为她宣说这样的偈颂。文殊师利，善哉，善哉！你现在能为一切众生请问如来这样的秘密之语。"

### 依食而存偈

文殊师利又说偈：

```
一切诸众生　皆依饮食存
一切有大力　其心无嫉妒
一切因饮食　而得诸病苦
一切修净行　而得受安乐
```

（大意：一切众生都依靠饮食而存活；一切有大力量的人，心中没有嫉妒；一切人都因饮食而得种种病苦；一切修清净之行的人，都得到安乐。）

"世尊，是这样。现在接受纯陀的饮食供养，莫非如来有所恐怖吗？"

那时世尊又为文殊说偈：

```
非一切众生　尽依饮食存
非一切大力　心皆无嫉妒
非一切因食　而致诸病苦
非一切净行　悉得受安乐
```

（大意：不是一切众生都依靠饮食而存活；不是一切有大力量的人心中都没有嫉妒；不是一切病苦都因饮食而致；不是一切修清净之行的人都得到安乐。）

"文殊师利，若你得病，我也应当这样得病苦。为什么呢？诸阿罗汉、辟支佛、菩萨、如来，实在无所食用，为了化度众生，示现受用无量众生所布施之物，令他们具足檀波罗蜜，拔济地狱、畜生、饿鬼。若说如来六年苦行，身体羸瘦，没有这样的事。诸佛世尊独自超出诸有，不同于凡夫，怎么会身体羸劣呢？诸佛世尊精勤修习，获得金刚之身，不同于世人危脆之身。我的诸弟子也是这样，不可思议，不依赖于饮食。

"'一切大力无嫉妒者'，也有余义，如世间人终身永远没有嫉妒之心，却没有大力量。'一切病苦因食得者'，也有余义，也见到有人得了外来之病，就是被刺、刀剑、矛槊所伤。'一切净行受安乐者'，这也是有余，世间也有外道之人，修习梵行，却多受苦恼。因为这个道理，如来所说的一切都有余义。这名为如来并非没有因缘而说这首偈，是有因缘才说的。过去在这优禅尼国，有一位婆罗门名叫羖羝德，来到我这里，想受第四八戒斋法，我那时为他说这首偈。"

【按】"欲受第四八戒斋法"，"第四"所指不详，或指一月六斋日中的某一日，存疑。

### 有余与无余

那时迦叶菩萨对佛说："世尊，什么名为无余之义？什么又名为一切之义？"

"善男子，一切，唯除助道的常乐善法，这名为一切，也名为无余。其余诸法，也名为有余，也名为无余。想令乐法的诸善男子知道这有余与无余之义。"

迦叶菩萨心中大为欢喜，踊跃无量，上前对佛说："真是奇特啊，世尊！平等看待众生如罗睺罗。"

那时佛赞叹迦叶菩萨："善哉，善哉！你现在所见的微妙甚深。"

迦叶菩萨对佛说："世尊，唯愿如来宣说这大乘《大涅槃经》所得的功德。"

佛告诉迦叶："善男子，若有人得以听闻这部经的名字，所得的功德不是声闻、辟支佛等所能宣说的，唯有佛能知道。为什么呢？因为不可思议，是佛的境界，何况受持、读诵、通利、书写经卷呢？"

### 大众请佛暂住

那时诸天、世人以及阿修罗，就在佛前异口同声地说偈：

```
诸佛难思议　法僧亦复然
是故今劝请　唯愿少停住
尊者大迦叶　及以阿难等
二众之眷属　不久须臾至
并及摩竭主　阿阇世大王
至心敬信佛　犹故未来此
唯愿佛世尊　少垂哀愍住
于此大众中　断我诸疑网
```

（大意：诸佛不可思议，法与僧也是如此，所以我们现在劝请，唯愿佛稍作停留。尊者大迦叶以及阿难等两众的眷属，不久须臾就会到来；还有摩竭陀国主阿阇世大王，至心敬信佛，还没有来到这里。唯愿佛世尊稍垂哀悯，住在这大众之中，断除我们的种种疑网。）

那时如来为大众说偈：

```
我法最长子　是名大迦叶
阿难勤精进　能断一切疑
汝等当谛观　阿难多闻士
自然能解了　是常及无常
以是故不应　心怀大忧恼
```

（大意：我法中的长子，名叫大迦叶；阿难勤勉精进，能断一切疑惑。你们应当仔细观察，阿难是多闻之士，自然能理解什么是常、什么是无常。因此你们不应心怀大忧恼。）

那时大众以种种物品供养如来，供养佛之后，就发起无上正等正觉之心，无量无边恒河沙数的诸菩萨等得住初地。那时世尊为文殊师利、迦叶菩萨以及纯陀授记，授记之后，这样说："诸善男子，好好修治自己的心，千万不要放逸。我现在背上有病，全身都痛，我现在想躺下，如那小孩以及常患病的人。文殊，你们应当为四部大众广说大法，现在把这法付嘱给你们，乃至迦叶、阿难等到来时，再付嘱这样的正法。"那时如来说了这话之后，为了调伏众生，示现身体有病，右胁而卧，如那病人一样。

## 现病品第十八

### 迦叶问如来何以示病

那时迦叶菩萨对佛说："世尊，如来已经免除一切疾病，患苦都已除去，再没有怖畏。世尊，一切众生有四种毒箭，是疾病的原因。哪四种？贪欲、瞋恚、愚痴、憍慢。若有病因，就有疾病生起，即爱热、肺病、气喘、呕吐、肌肤肿胀、心中闷乱、腹泻、呃逆哽噎、小便淋沥、眼耳疼痛、腹背胀满、癫狂、干消、被鬼魅所附，这样种种身心之病，诸佛世尊都已不再有。今天如来以什么缘故嘱咐文殊师利，这样说：'我现在背痛，你们应当为大众说法'？

【按】原文"肤体??"缺二字，依上下文是一种肌肤病症，暂译作"肌肤肿胀"，存疑。

"有两种因缘就没有病苦。哪两种？一是怜悯一切众生，二是施给病人医药。如来过去已在无量万亿劫中修菩萨道，常行爱语，利益众生，不令他们苦恼，施给病人种种医药，为什么现在自己说有病呢？

"世尊，世人有病，或坐或卧，不能安于其处，或索要饮食，敕诫家属，修治产业。如来为什么默然而卧，不教导弟子声闻人等尸罗波罗蜜、诸禅、解脱、三摩跋提，修习诸正勤？为什么不宣说这样甚深的大乘经典？如来为什么不以无量方便教导大迦叶这位人中象王以及诸大人等，令他们不退转于无上正等正觉？为什么不惩治那些受畜一切不净之物的恶比丘？世尊实在没有病，为什么默然右胁而卧？

### 菩萨施药的誓愿

"诸菩萨等凡所施给病人的医药，所得的善根都布施给众生，共同回向一切种智，为了除去众生的诸烦恼障、业障、报障。

"烦恼障，是贪欲、瞋恚、愚痴、忿怒、缠盖、焦恼、嫉妒、悭吝、奸诈、谄媚、无惭、无愧，慢、慢慢、不如慢、增上慢、我慢、邪慢、憍慢，放逸、贡高、怨恨、诤讼，邪命谄媚，诈现异相，以利求利，恶求多求，没有恭敬，不随教诲，亲近恶友，贪利无厌，缠缚难解，欲于恶欲，贪于恶贪，身见、有见以及无见，频伸、喜睡、打呵欠、不乐，贪嗜饮食，其心昏昧，心缘异想，不善思惟，身口多恶，喜好多语，诸根暗钝，说话多虚，常被欲觉、恚觉、害觉所覆盖，这名为烦恼障。

"业障，是五无间罪等重恶之病。

"报障，是生在地狱、畜生、饿鬼，以及诽谤正法与一阐提，这名为报障。

"这三障名为大病。而诸菩萨在无量劫修菩提时，施给一切病人医药，常发这样的愿：'令诸众生永断这三障重病。'

"再者，世尊，菩萨摩诃萨修菩提时，施给一切病人医药，常发这样的愿：'愿令众生永断诸病，得以成就如来金刚之身。'又愿：'一切无量众生作妙药王，断除一切诸恶重病。'愿：'众生得到阿伽陀药，以这药力能除一切无量恶毒。'又愿：'众生对于无上正等正觉没有退转，迅速成就无上佛药，消除一切烦恼毒箭。'又愿：'众生勤修精进，成就如来金刚之心，作微妙之药，疗治众病，不令有人生起诤讼之想。'也愿：'众生作大药树，疗治一切诸恶重病。'又愿：'众生拔出毒箭，成就如来无上光明。'又愿：'众生得入如来智慧大药的微密法藏。'世尊，菩萨这样已在无量百千万亿那由他劫中发了这样的誓愿，令众生都没有疾病，为什么如来在今天却说有病？

"再者，世尊，世间有病的人，不能坐起俯仰、进止行动，吃不下饭，喝不下水，也不能教诫儿子修治家业。那时父母、妻子、兄弟、亲属、知识，都对这人生起必死之想。世尊，如来今天也是这样，右胁而卧，无所论说。这阎浮提中有些愚人会这样想：'如来正觉必定要涅槃了。'生起灭尽之想。而如来之性实在不会毕竟入于涅槃。为什么呢？因为如来常住，没有变易。因为这个缘故，不应说'我现在背痛'。

"再者，世尊，世间有病的人，身体羸弱损减，或仰卧或侧卧在床褥上，那时众人心中厌恶轻贱，生起必死之想。如来现在也是这样，将被外道九十五种所轻慢，生起无常之想。那些外道会这样说：'不如我们，以我、自性、自在天、时节、微尘等法为常住，没有变易；沙门瞿昙被无常所迁，是变易之法。'因为这个道理，世尊今天不应默然右胁而卧。

### 十住菩萨的大力

"再者，世尊，世间有病的人，四大增减，互不调和，羸瘦疲极，所以不能随意坐起，卧在床褥上。如来的四大无不调和，身体力量具足，也没有羸弱损减。

"世尊，如十头小牛的力量，不如一头大牛的力量；十头大牛的力量，不如一头青牛的力量；十头青牛的力量，不如一头普通大象的力量；十头普通大象的力量，不如一头野象的力量；十头野象的力量，不如一头二牙象的力量；十头二牙象的力量，不如一头四牙象的力量；十头四牙象的力量，不如雪山一头白象的力量；十头雪山白象的力量，不如一头香象的力量；十头香象的力量，不如一头青象的力量；十头青象的力量，不如一头黄象的力量；十头黄象的力量，不如一头赤象的力量；十头赤象的力量，不如一头白象的力量；十头白象的力量，不如一头山象的力量；十头山象的力量，不如一头优钵罗象的力量；十头优钵罗象的力量，不如一头波头摩象的力量；十头波头摩象的力量，不如一头拘物头象的力量；十头拘物头象的力量，不如一头分陀利象的力量；十头分陀利象的力量，不如人中一位力士的力量；十位人中力士的力量，不如一位钵健提的力量；十位钵健提的力量，不如一位八臂那罗延的力量；十位那罗延的力量，不如一位十住菩萨一个骨节的力量。

"一切凡夫身中的诸骨节，节与节不相接；人中力士，节头相接；钵健提身上的诸骨节，相互衔接；那罗延身上的骨节，节头相互钩连；十住菩萨的诸骨节，如蟠龙相结。所以菩萨的力量最大。世界形成时，从金刚际升起金刚座，上至道场菩提树下，菩萨坐上之后，其心当即得到十力。

"如来现在不应如那婴孩小儿。婴孩小儿愚痴无智，无所能说，所以随意仰卧侧卧，无人讥诃。如来世尊有大智慧，照明一切，是人中大龙，具大威德，成就神通，是无上仙人，永断疑网，已拔毒箭，进止安详，威仪具足，得无所畏，现在为什么右胁而卧，令诸人天悲愁苦恼？"

那时迦叶菩萨就在佛前说偈：

```
瞿昙大圣德　愿起演妙法
不应如小儿　病者卧床蓐
调御天人师　倚卧双树间
下愚凡夫见　当言必涅槃
不知方等典　甚深佛所行
不见微密藏　犹盲不见道
唯有诸菩萨　文殊师利等
能解是甚深　譬如善射人
三世诸世尊　大悲为根本
如是大慈悲　今为何所在
若无大悲者　是则不名佛

唯愿无上尊　哀受我等请
利益于众生　摧伏诸外道
```

（大意：大圣德瞿昙，愿您起身演说妙法，不应如小儿与病人那样卧在床褥上。调御天人师倚卧在双树之间，下愚的凡夫见了，会说佛必定涅槃了。他们不知道方等经典与佛甚深的所行，见不到微密之藏，犹如盲人看不见道路。唯有文殊师利等诸菩萨，能理解这甚深之义，譬如善射之人。三世诸世尊以大悲为根本，这样的大慈悲，现在在哪里呢？若没有大悲，就不名为佛；佛若必定涅槃，就不名为常。唯愿无上尊哀悯接受我们的请求，利益众生，摧伏诸外道。）

### 佛起坐放光，诸恶道空

那时世尊以大悲熏心，知道众生各自心中所想，将要随顺他们而作毕竟的利益，就从卧处起身，结跏趺坐，容颜和悦如熔化的金聚，面目端严如满月，形容清净，没有垢秽，放出大光明，充满虚空，其光极盛，超过百千个太阳，照耀东方、南方、西方、北方、四维上下诸佛世界，惠施众生大智慧的火炬，令他们都灭除无明黑暗，令百千亿那由他众生安住于不退转的菩提之心。

那时世尊心无疑虑，如狮子王，以三十二大人之相、八十种好庄严其身。在他身上一切毛孔中，每一个毛孔生出一朵莲花，其花微妙，各具千瓣，纯是真金之色，以琉璃为茎，金刚为须，玫瑰为台，形状大而团圆，犹如车轮。

这些莲花各放出种种杂色光明，青、黄、赤、白、紫、颇梨色。这些光明都遍至阿鼻地狱、想地狱、黑绳地狱、众合地狱、叫唤地狱、大叫唤地狱、焦热地狱、大焦热地狱。这八大地狱中的众生，常被种种苦所逼迫，即烧煮火炙、斫刺剥皮，遇到这光明之后，这样的众苦都灭除无余，安稳清凉，快乐无极。这光明中宣说如来秘密之藏，说：'一切众生都有佛性。'众生听了，随即命终，生于人天之中。

乃至八种寒冰地狱，即阿波波地狱、阿吒吒地狱、阿罗罗地狱、阿娑娑地狱、优钵罗地狱、波头摩地狱、拘物头地狱、分陀利地狱，其中众生常被寒苦所逼恼，即身体冻裂、碎坏、互相残害，遇到这光明之后，这些苦也都灭除无余，随即得到调和，温暖适身。这光明中也宣说如来秘密之藏，说：'一切众生都有佛性。'众生听了，随即命终，生于人天之中。

那时在这阎浮提界以及其余世界，所有的地狱都空虚了，没有受罪的人，除了一阐提。

饿鬼众生被饥渴所逼，以头发缠身，在百千年中从未听到过浆水的名字，遇到这光明之后，饥渴随即除去。这光明中也宣说如来微密秘藏，说：'一切众生都有佛性。'众生听了，随即命终，生于人天之中，令诸饿鬼道也都空虚了，除了诽谤大乘方等正典的人。

畜生众生互相杀害，共相残食，遇到这光明之后，瞋恚之心都消灭了。这光明中也宣说如来秘密之藏，说：'一切众生都有佛性。'众生听了，随即命终，生于人天之中。那时畜生道也空尽了，除了诽谤正法的人。

### 莲花中诸佛的种种示现

每一朵莲花中各有一尊佛，圆光一寻，金色晃耀，微妙端严，最上无比，以三十二相、八十种好庄严其身。这些世尊，或有坐的，或有行的，或有卧的，或有站立的；或震雷音，或降大雨，或放电光，或扇大风，或出烟焰，身如火聚；或示现七宝诸山、池泉河水、山林树木；或示现七宝国土、城邑聚落、宫殿屋宅；或示现象、马、狮子、虎狼、孔雀、凤凰诸鸟；或示现令阎浮提所有众生都见到地狱、畜生、饿鬼；或示现欲界六天。

又有世尊，或说阴、界、诸入多有过患；或说四圣谛法；或说诸法因缘；或说诸业烦恼都由因缘而生；或说我与无我；或说苦与乐二法；或说常与无常等；或说净与不净。又有世尊，为诸菩萨演说所行的六波罗蜜；或说诸大菩萨所得的功德；或说诸佛世尊所得的功德；或说声闻之人所得的功德；或说随顺一乘；或说三乘成道。或有世尊左胁出水，右胁出火；或有示现初生、出家、坐于道场菩提树下、转妙法轮、入于涅槃；或有世尊作狮子吼，令这会中有人得初果、二果、三果，乃至第四果；或又宣说出离生死的无量因缘。

那时在这阎浮提中，所有众生遇到这光明之后，盲人见到色相，聋人听到声音，哑人能说话，跛足的人能行走，贫穷的人得到财物，悭吝的人能布施，瞋恚的人生起慈心，不信的人生起信心。这样，世界中没有一个众生修行恶法，除了一阐提。

那时一切天、龙、鬼神、乾闼婆、阿修罗、迦楼罗、紧那罗、摩睺罗伽、罗刹、健陀、忧摩陀、阿婆魔罗、人、非人等，都同声说："善哉，善哉！无上天尊多所利益。"说了这话之后，踊跃欢喜，或歌或舞，或身体转动，以种种花散在佛及僧众身上，即天上的优钵罗花、拘物头花、波头摩花、分陀利花、曼陀罗花、摩诃曼陀罗花、曼殊沙花、摩诃曼殊沙花、散陀那花、摩诃散陀那花、卢脂那花、摩诃卢脂那花、香花、大香花、适意花、大适意花、爱见花、大爱见花、端严花、第一端严花；又散诸香，即沉水香、多伽楼香、栴檀、郁金、和合杂香、海岸聚香；又以天上的宝幢幡盖、诸天伎乐，筝、笛、笙、瑟、箜篌、鼓吹，供养佛，说偈：

```
我今稽首大精进　无上正觉两足尊
天人大众所不知　唯有瞿昙乃能了
世尊往昔为我故　于无量劫修苦行
如何一旦弃本誓　而便舍命欲涅槃
一切众生不能见　诸佛世尊秘密藏
以是因缘难得出　轮转生死坠恶道
如佛所说阿罗汉　一切皆当至涅槃
如是甚深佛行处　凡夫下愚谁能知
施诸众生甘露法　为断除彼诸烦恼
若有服此甘露已　不复受生老病死
如来世尊已疗治　百千无量诸众生
令其所有诸重病　一切消灭无遗余
世尊久已舍病苦　故得名为第七佛
唯愿今日雨法雨　润渍我等功德种
是诸大众及人天　如是请已默然住
```

（大意：我们现在稽首大精进、无上正觉的两足尊，天人大众所不知的，唯有瞿昙才能了知。世尊过去为了我们，在无量劫中修苦行，为什么一旦舍弃本誓，舍命而要涅槃？一切众生不能见到诸佛世尊的秘密之藏，因此难以出离，轮转生死，坠入恶道。如佛所说，阿罗汉都将到达涅槃，这样甚深的佛所行之处，凡夫下愚谁能知道？佛施给众生甘露法，为了断除他们的诸烦恼，若有人服了这甘露，就不再受生老病死。如来世尊已疗治了百千无量众生，令他们所有的重病都消灭无余。世尊早已舍离病苦，所以得名为第七佛。唯愿今日降下法雨，滋润我们的功德之种。这些大众以及人天，这样请求之后，默然而住。）

说这偈时，莲花台中的一切诸佛，从阎浮提直到净居天，都听到了。

### 佛说久已无病

那时佛告诉迦叶菩萨："善哉，善哉！善男子，你已具足这样甚深微妙的智慧，不被一切诸魔外道所破坏。善男子，你已安住，不被一切诸恶邪风所动摇。善男子，你已成就乐说辩才，曾经供养过去无量恒河沙数的诸佛世尊，所以能请问如来正觉这样的意义。

"善男子，我在过去无量无边亿那由他百千万劫，已经除去病根，永远离开了倚卧。迦叶，过去无量阿僧祇劫，有佛出世，号无上胜如来、应供、正遍知、明行足、善逝、世间解、无上士、调御丈夫、天人师、佛、世尊，为诸声闻宣说这大乘《大涅槃经》，开示分别，显发其义。我那时也是那位佛的声闻弟子，受持这样的大涅槃经典，读诵通利，书写经卷，广为他人开示分别，解说其义，以这善根回向无上正等正觉。善男子，我从那时以来，从未因恶的烦恼业缘而堕入恶道，诽谤正法，作一阐提，受黄门身、无根、二根，反逆父母，杀阿罗汉，破塔坏僧，出佛身血，犯四重禁。从那时以来，身心安稳，没有诸苦恼。迦叶，我现在实在没有一切疾病。为什么呢？诸佛世尊早已远离一切疾病。迦叶，这些众生不知大乘方等的秘密之教，便以为如来真的有病。

### 如来的秘密之语

"迦叶，如说如来是人中狮子，而如来实在不是狮子，这样的话就是如来的秘密之教。迦叶，如说如来是人中大龙，而我已在无量劫中舍离了这样的业。迦叶，如说如来是人、是天，而我真实非人非天，也不是鬼神、乾闼婆、阿修罗、迦楼罗、紧那罗、摩睺罗伽，非我，非命，非可养育者，非人，非士夫，非作非不作，非受非不受，非世尊，非声闻，非说非不说，这样的话都是如来的秘密之教。

"迦叶，如说如来犹如大海、须弥山王，而如来实在不是咸味，也不同于石山，应当知道这话也是如来的秘密之教。迦叶，如说如来如分陀利华，而我实在不是分陀利华，这样的话就是如来的秘密之教。迦叶，如说如来犹如父母，而如来实在不是父母，这样的话也是如来的秘密之教。迦叶，如说如来是大船师，而如来实在不是船师，这样的话也是如来的秘密之教。迦叶，如说如来犹如商主，而如来实在不是商主，这样的话也是如来的秘密之教。迦叶，如说如来能摧伏魔，而如来实在没有恶心想令他人降伏，这样的话都是如来的秘密之教。迦叶，如说如来能治痈疮，而我实在不是治痈疮的医师，这样的话也是如来的秘密之教。

"迦叶，如我先前所说，若有善男子、善女人善能修治身口意业，舍命之时，虽然亲族取其尸骸，或用火烧，或投入大水，或弃于坟间，被狐狼禽兽争相啖食，然而他的心意识随即生于善道。而这心法实在没有去来，也无所至，只是前后相似相续，相貌不异。这样的话就是如来的秘密之教。

"迦叶，我现在说有病，也是这样，也是如来的秘密之教，所以嘱咐文殊师利：'我现在背痛，你们应当为四众说法。'迦叶，如来正觉实在没有病而右胁而卧，也不会毕竟入于涅槃。迦叶，这大涅槃就是诸佛甚深的禅定，这样的禅定不是声闻、缘觉所行之处。

"迦叶，你先前问：'如来为什么倚卧不起，不索饮食，不敕诫家属修治产业？'迦叶，虚空之性也没有坐起、求索饮食、敕诫家属、修治产业，也没有去来、生灭、老壮、出没、伤破、解脱、系缚，也不自说，也不为他人说，也不自解，也不为他人解，非安非病。善男子，诸佛世尊也是这样，犹如虚空，怎会有诸病苦呢？

### 三种难治之病

"迦叶，世间有三种人，其病难治：一是诽谤大乘，二是五逆罪，三是一阐提。这三种病在世间极重，都不是声闻、缘觉所能医治的。

"善男子，譬如有病必死难治，无论有无看护、随意医药，这样的病一定不可治，应当知道这人必死无疑。善男子，这三种人也是这样，无论有声闻、缘觉、菩萨，或有说法或不说法，都不能令他们发起无上正等正觉之心。

"迦叶，譬如病人，若有看护与随意的医药，就可以痊愈；若没有这三者，就不能痊愈。声闻、缘觉也是这样，从佛菩萨那里听闻佛法之后，就能发起无上正等正觉之心，不是不闻法而能发心。

"迦叶，譬如病人，无论有没有看护、随意的医药，都可以痊愈。有一种人也是这样，无论遇到或遇不到声闻，遇到或遇不到缘觉，遇到或遇不到菩萨，遇到或遇不到如来，听闻或不听闻佛法，都自然能成就无上正等正觉。这就是有人或为自己，或为他人，或为怖畏，或为利养，或为谄媚，或为欺骗他人，而书写这样的《大涅槃经》，受持、读诵、供养、恭敬、为他人宣说。

【按】这里依病有三类分说：必死不可治的，喻谤大乘、五逆、一阐提；须待医护才能治的，喻声闻、缘觉须闻法方能发心；无论医护与否都能痊愈的，喻曾受持书写本经之人，即使动机不纯，此经的功德也终能令其成佛。

### 五种人有病行处

"迦叶，有五种人，在这大乘大涅槃经典中，有病行之处，而不是如来。哪五种？

"一是断了三结，得须陀洹果，不堕地狱、畜生、饿鬼，在人天中往返七次，永断诸苦，入于涅槃。迦叶，这名为第一种人有病行处。这人在未来过八万劫，便当成就无上正等正觉。

"迦叶，第二种人，断了三结，减薄贪、恚、痴，得斯陀含果，名为一往来，永断诸苦，入于涅槃。迦叶，这名为第二种人有病行处。这人在未来过六万劫，便当成就无上正等正觉。

"迦叶，第三种人，断了五下分结，得阿那含果，不再来此，永断诸苦，入于涅槃。这名为第三种人有病行处。这人在未来过四万劫，便当成就无上正等正觉。

"迦叶，第四种人，永断贪欲、瞋恚、愚痴，得阿罗汉果，烦恼无余，入于涅槃，但不是如麒麟那样独自修行。这名为第四种人有病行处。这人在未来过二万劫，便当成就无上正等正觉。

"迦叶，第五种人，永断贪欲、瞋恚、愚痴，得辟支佛道，烦恼无余，入于涅槃，真是如麒麟那样独自修行。这名为第五种人有病行处。这人在未来过一万劫，便当成就无上正等正觉。迦叶，这名为第五种人有病行处，而不是如来。"

【按】"有病行处"，是说声闻四果与辟支佛仍在示现有病的境地，而如来已永离病根。经中并为四果与辟支佛都授记将来成佛，与本经"一切众生悉有佛性"、二乘终归大涅槃之说相应。"麒麟独一之行"，指麟角喻独觉，独自修行，不依师友。
