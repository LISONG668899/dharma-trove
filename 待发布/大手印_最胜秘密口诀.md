# 最胜秘密口诀

［梅纪巴法类］　据藏文译出

## 题解

《最胜秘密口诀》（藏本篇末题作 gsang ba dam pa，梵文音写作 Upadeśa-paramaguhya）收于德格版丹珠尔续部释 ཝི 函第 141a 至 141b 页（东北目录 D2251），夹在《大乘真如二十颂》（D2250）与《灌顶决定开示》（D2252）之间。

本篇与本组其他短论不同：开头没有梵藏题名，直接以"敬礼诸殊胜上师"起首；篇末只有题名，没有作者与译者的署名。因为它收在梅纪巴的"无念法类"之中，一般归于梅纪巴的法类，但是否出自梅纪巴本人之手，原文没有交代。篇中用了不少藏地大手印口诀中常见的语汇，如"本位"（rang so）、"新鲜"（so ma）、"自在放下"（rang thang zhog）等，也有人认为它可能是印度上师口授、由藏地弟子记录的口诀。这些都只是推测，存疑。

全篇四十余句七言偈，是一篇纯粹的大手印修心口诀，几乎不涉及仪轨。大致可分为八节：证悟如何生起；忆念显现的无生，而尝大乐之味；依上师恩德；没有修习的次第，修即是证；一切都是大手印，连违品也不例外；不作意的瑜伽士无定与后得之分；不二的相续；最后是直下、新鲜、不执、自在放下——在不生的心性中，没有什么要收摄，也没有什么要放出。

篇中"无修之次第""无定与后得之分"一类的话，是就已经由上师指示而认出心性的瑜伽士而说的；第三节特别说明这一切都是"依上师的恩德"。读者应当把这些口诀放在依止上师、领受直指的前提下来理解。

体例：按意义单元分为八节，节题是译者所加；每节先列藏文原颂于代码块中，再译出；为了便于理解而补的字，都放在方括号中。原文含混或可有两解之处，以"【按】"说明，不妄补内容。文末附通篇连读。

## 礼敬

敬礼诸殊胜上师！

## 一、证悟的生起

```
བསམ་གྱིས་མི་ཁྱབ་རྣལ་འབྱོར་པས། །
སྙིང་རྗེའི་རང་སེམས་གློ་བུར་སད། །
ཤེས་རབ་སྐྱེ་བ་མེད་རྒྱས་བཏབ། །
གཉིས་མེད་བསམ་མི་ཁྱབ་མཚན་ཉིད། །
```

不可思议的瑜伽士，悲心的自心忽然醒觉；以智慧——不生——来印定；［这就是］无二、不可思议的体相。

【按】"忽然醒觉"（glo bur sad），意思是证悟并不是逐步建构出来的，而是在某一刹那忽然醒来。"以智慧——不生——来印定"（shes rab skye ba med rgyas btab），可以理解为"以不生的智慧来印定［悲心］"，即悲心与证悟无生的智慧双运；见《五如来印释》中"印定"的用法。

## 二、忆念无生，尝大乐之味

```
སྣང་བའི་སྐྱེ་བ་མེད་པ་དྲན། །
དྲན་པའི་རང་བཞིན་གཟུང་བ་མེད། །
གཟུགས་སོགས་དངོས་པོའི་རང་བཞིན་གྱིས། །
བདེ་བ་ཆེན་པོའི་རོ་མྱོང་བས། །
བསམ་དུ་མེད་པའི་རྣལ་འབྱོར་རྟོགས། །
```

忆念显现的无生；［而这］忆念的本性，没有所取。以色等事物的本性，品尝大乐之味，［由此］证悟不可思议的瑜伽。

【按】"忆念显现的无生"（snang ba'i skye ba med pa dran），"忆念"（dran pa）在大手印中常指对心性的念知、正念，而不是回想过去的事。这里的意思是：对显现保持念知，而认出它本来不生；这念知本身也不执取任何对象。"以色等事物的本性品尝大乐之味"，意思是：不离开色、声等显现，就在其本性中体验大乐。

## 三、依上师恩德

```
དེ་ཡང་།
བླ་མའི་དྲིན་གྱིས་སླར་ཡང་ནི། །
སོ་སོར་རྟོག་པའི་རང་བཞིན་ནོ། །
```

又［说］：依上师的恩德，再一次［认出］，［那就是］妙观察的本性。

【按】"妙观察"（so sor rtog pa），这里可能是"妙观察智"的略称，即能清楚分辨诸法而不执著的智慧；也可能是一般意义的"分别观察"。"再一次"（slar yang），可能是说：已经有过的体验，依上师的恩德再一次被认出、确认。原文简略，存疑。

## 四、无修的次第，修即是证

```
དེ་ཡང་།
ཇི་ལྟར་མྱོང་བས་བསྐྱེད་པས་ན། །
དྲན་པས་གཟུང་དང་མ་གཟུང་མེད། །
རྒྱུ་དང་འབྲས་བུ་དབྱེར་མེད་པས། །
སྒོམ་པའི་རིམ་པ་བདག་ལ་མེད། །
སྟོང་པ་ཉིད་ཀྱི་རོ་ཚོར་བས། །
སྒོམ་པ་ཡང་ནི་རྟོགས་པའོ། །
```

又［说］：因为［这境界］是由体验而生起的，所以对忆念来说，没有所取，也没有非所取；因为因与果无别，所以对我来说，没有修习的次第。由于感受到空性之味，修习本身也就是证悟。

【按】"对我来说，没有修习的次第"，是证悟者的口吻：因与果本来无别，心性本来具足，所以不再有"先修什么、后修什么"的次第。这是就已经认出心性的瑜伽士而说的，不能理解为初学者不需要修习的次第。"修习本身也就是证悟"，与大手印"修即是证、证即是修"的说法一致。

## 五、一切都是大手印

```
གང་ཕྱིར་ཤེས་རབ་སྒོམ་པ་ཡིས། །
ཐམས་ཅད་ཕྱག་རྒྱ་ཆེན་པོ་ལ། །
གང་ཞིག་མི་མཐུན་ཕྱོགས་སུ་ཡང་། །
དེ་ཉིད་ཕྱག་རྒྱ་ཆེན་པོ་ལ། །
རང་བཞིན་ལྟུག་པ་བསམ་དུ་མེད། །
ཇི་སྲིད་བྱེ་བྲག་གཉིས་འབྱུང་བ། །
དེ་ལས་བྱུང་ནི་དེ་རུ་ཐིམ། །
དེ་ལས་བདེ་བའི་ཡེ་ཤེས་པས། །
འབྲས་བུ་དག་ལས་རེ་བ་མེད། །
```

因为以修智慧，一切都在大手印之中；凡是［被视为］违品的，也在那大手印本身之中，本性松坦，不可思议。只要还有二者的分别生起，［它们］就从那［大手印］中生起，也融入那［大手印］之中。由此，以安乐的智慧，对于果位便没有希求。

【按】第五句"rang bzhin ltug pa"，ltug 一般讲不通，疑为 lhug pa（松坦、放松）之讹，这里依此译为"本性松坦"，存疑。"违品"（mi mthun phyogs），指被视为障碍、需要对治的烦恼与分别；作者说连这些也都在大手印之中，并不需要另外去除。"从那中生起，也融入那之中"，意思是一切分别都从心性中生起，也在心性中自然消融，就像波浪从海中生起又回到海中。"对于果位便没有希求"，见《大乘二十颂》第十五颂"无所希求"的按语。

## 六、不作意的瑜伽士

```
ཡིད་ལ་མི་བྱེད་རྣལ་འབྱོར་པས། །
སྟོང་ཉིད་སྙིང་པོ་བསམ་དུ་མེད། །
གཉིས་མེད་ཤེས་རབ་རང་སོ་ལ། །
མཉམ་གཞག་རྗེས་ཐོབ་རིག་པ་མེད། །
```

对于不作意的瑜伽士来说，空性的心要是不可思议的；在无二智慧的本位之中，没有［对］根本定与后得［之分别］的知觉。

【按】"不作意"，见《不作意论证》。"本位"（rang so），是藏地大手印口诀中的常用语，指心性本来的位置、本来的样子，修习时"安住本位"即不加改造地安住于心性。"没有根本定与后得的知觉"，意思是对于安住于无二智慧的瑜伽士来说，已经没有"现在在定中""现在出定了"的分别；这是证悟者的境界。

## 七、不二的相续

```
བསམ་མེད་རྒྱུན་གྱི་རྣལ་འབྱོར་པས། །
གཉིས་སུ་མི་བྱེད་རང་སོ་ཉིད། །
མ་སྐྱེས་པ་ཉིད་དངོས་པོར་སད། །
དངོས་པོར་སྐྱེ་བ་མེད་པར་ཐིམ། །
དངོས་སུ་གཉིས་མེད་རྡོ་རྗེར་མཐུན། །
```

对于不思维之相续的瑜伽士来说，［他］不把［一切］作成二，［只是］本位本身。不生本身醒觉为事物，事物又融入不生；实际上无二，与金刚相应。

【按】"不生醒觉为事物，事物融入不生"，描述的是显现与空性的往复不二：从不生中显现出种种事物，种种事物又回归不生，二者本来是一。"与金刚相应"（rdo rjer mthun），"金刚"在这里可能指金刚般不可破的心性，或指金刚萨埵；存疑。

## 八、直下、新鲜、自在放下

```
ཉེས་པ་དབང་སོགས་གློ་བུར་བ། །
དེས་ན་དྲང་ཐད་སོ་མ་སྟེ། །
དེ་དང་དེ་ཉིད་ཐད་ཀར་བཅས། །
སྐྱེ་བ་མེད་མཐོང་རྣལ་འབྱོར་པས། །
ཤེས་པ་མི་བཟུང་རང་ཐང་ཞོག །
སྐྱེ་བ་མེད་པའི་སེམས་ཉིད་ལ། །
ཅི་ཞིག་བསྡུས་ཤིང་ཅི་ཞིག་སྤྲོ། །
```

过失、诸根等都是暂时的；所以，［心性］是直下的、新鲜的；对它和它本身，都直接［如是］安置。

见到不生的瑜伽士，不执取心识，让它自在地放下。在不生的心性之中，有什么要收摄的呢？又有什么要放出的呢？

【按】"过失、诸根等都是暂时的"（nyes pa dbang sogs glo bur ba），dbang 可能是 dbang po（诸根）的略称，也可能是"力、自在"等义；这里依前者，存疑。意思是：一切过失与根识的作用，都是暂时的客尘，并不触及心性本身。

"直下的、新鲜的"（drang thad so ma），so ma 是"新鲜、未经改造"之义，是藏地大手印口诀中描述心性的常用语，意思是不加改造、本来如是的心。"直接如是安置"（thad kar bcas），意思是不加修饰地直接安住。"自在地放下"（rang thang zhog），也是大手印口诀中的常用语，意思是让心自然、自在地安住，不加执持。

最后两句"有什么要收摄的，又有什么要放出的"，是说在不生的心性中，既不需要把心收回来，也不需要把心放出去，因为心性本来无来无去。这也是本篇的结语。

## 跋

《最胜秘密口诀》，圆满。

【按】篇末题名的梵文音写作 u pa de sha pa ra ma pa ya，前半 upadeśa 是"口诀"，parama 是"最胜"，末尾的 pa ya 应是 guhya（秘密）的讹写，这里依藏题 gsang ba dam pa 还原为 Upadeśa-paramaguhya。本篇没有作者与译者的署名。

## 通篇连读

敬礼诸殊胜上师！

不可思议的瑜伽士，悲心的自心忽然醒觉，以不生的智慧来印定，这就是无二、不可思议的体相。

忆念显现的无生，而这忆念的本性没有所取；以色等事物的本性品尝大乐之味，由此证悟不可思议的瑜伽。

又说：依上师的恩德，再一次认出，那就是妙观察的本性。

又说：因为这境界是由体验而生起的，所以对忆念来说，没有所取，也没有非所取；因为因与果无别，所以对我来说，没有修习的次第。由于感受到空性之味，修习本身也就是证悟。

因为以修智慧，一切都在大手印之中；凡是被视为违品的，也在那大手印本身之中，本性松坦，不可思议。只要还有二者的分别生起，它们就从大手印中生起，也融入大手印之中。由此，以安乐的智慧，对于果位便没有希求。

对于不作意的瑜伽士来说，空性的心要是不可思议的；在无二智慧的本位之中，没有对根本定与后得之分别的知觉。

对于不思维之相续的瑜伽士来说，他不把一切作成二，只是本位本身。不生本身醒觉为事物，事物又融入不生；实际上无二，与金刚相应。

过失、诸根等都是暂时的，所以心性是直下的、新鲜的，对它和它本身都直接如是安置。见到不生的瑜伽士，不执取心识，让它自在地放下。在不生的心性之中，有什么要收摄的呢？又有什么要放出的呢？

《最胜秘密口诀》，圆满。
