# 三种甚深窍诀

麦彭仁波切 造

顶礼文殊妙音！[^1]

```
ནད་གདོན་ཉོན་མོངས་གཡུལ་ངོ་ལས། །
རྒྱལ་བར་འདོད་ན་ནང་དང་ཕྱི། །
རང་སར་ཐིམ་པའི་མན་ངག་དགོས། །
```

若欲于疾病、邪祟、烦恼之战场上得胜，则须具备外境融入内身、内身融入外境，以及融摄于自身本位这三种窍诀。

## 一、外境融入内身之窍诀

若对邪祟、魔障生起强烈恐惧，无论如何设法皆无法平息，此时应舍弃护轮、忿怒咒等驱逐之法。三界之中，纵有无量无边之邪祟魔障，其等究竟能造成何种伤害？"受害者"与"加害者"，二者本是自心所现之虚妄；唯由能所二取之执著力，方安立为所谓"伤害"；若无此执著，亦无所谓伤害。

譬如，若坐于横死者尸体之旁，便会生起恐惧，由此而受其害；然而若不知情，将该尸体置于袋中作枕而卧，心中并不生恐惧，也不会受害。由此可知，一切皆取决于自心是否转变。

尤其，执自身为受害者、他者为加害者，因而恐惧与之相遇——应从根本上认清：此恐惧本身即是伤害之根源，而非那邪祟本身造成伤害。对于仅由心识化现之身形的天神、鬼魅，又有何可逃避的？若了知其不能加害，逃避又有何必要？若执为有害，纵是天神亦成鬼魅；若执为有益，纵是鬼魅亦成天神。

于诸法实义而言，并无可单方面成立为谛实之一端；若加以观察，则一切平等无有根基、悉皆空性。有益或有害，唯由自心分别之力所致，犹如梦中遇猛兽，恐惧愈大则所受之害亦愈大；应以正理决断——伤害乃自身所招致，并认清此中要害。

应观想：自身所恐惧之邪祟，连同其真实所在之处所，乃至遍满虚空、无边无际之一切器情世间，悉皆一时收摄，迅疾融入自身腹内；复融入心间豆粒大小、名为"自我"之黑色明点当中，此明点亦不堪承受，碎解为极微尘之自性，乃至了无痕迹地消融殆尽。于是一切诸法与自心，本体无别、融为一味，应思惟：我与你之间，再无丝毫可分之别。

让心放松坦然。不仅是那加害之邪祟，乃至一切显现有法之界中所有有益之天神、加害之鬼魅、怨敌、亲友与中庸之有情，三界一切器情世间，皆与我融为一味之后，谁能被害？谁来加害？以何种方式加害？如是观察，若见并无所谓利与害，本自如是安住，即言"就是这样"，令心放松坦然，任其安住于本然自在之状态。

若能识得觉性本面，即安住于该境界之中；若不能识得，亦当以"任由所生、听其所是"之心，坦然宽坦地安住。

以此为例，对于外境所生之一切恐惧，皆应如是而行。恐惧越强烈之时，若如是修持，则恐惧将渐次减轻，觉受亦将渐次增益，终能于邪祟之恐惧上获得胜利。

此乃麦彭·文殊喜之觉性密藏中迸发而出之第一窍诀。如此深奥之窍诀，世间罕有难得，当以甚深封印秘而护持。

## 二、内身融入外境之窍诀

若身体为疾病所扰乱，无计可施，无论如何设法皆无法平息，应思惟：如是生病，究竟是由此幻化之身所承受。若无有身体，又有何物可生病？唯因执此身为我所有、妄执"于此世间中，此身唯属于我"之狭隘执著，方才招致苦受。

此身乃依父母之精血而生，先前本无，忽然而有；是种种不净之物聚合而成，娇嫩柔弱，乃是极微尘之聚集；自出生至死亡之间，刹那刹那不断变化；是四大聚合而生种种疾病之城邑；最终无论如何，终将被舍弃，成为腐烂流散之法，应如是决断。

此身肌肉、骨骼等坚硬之界，与外在之地大并无差异；同样，体温对应于火大，呼吸对应于风大，血液及诸液体对应于水大；疾病即由此四大之变化而生。

此四大聚合，虽如是显现为实有，然若逐分剖析，乃至可分解至极微尘；此诸微尘彼此互不相混、各自独立存在，皆可摧毁、可分解、临于离散之边缘；中空无实、无有精髓，犹如水面之泡沫；若以理观察至极微尘，则连此极微尘亦不能成立，如是虽无根本、无有基础。

然而，由于无始以来串习"身体显现"之坚固分别执著，身体遂显现为实有，成为利益与损害之所依，亦成为承受安乐与痛苦之门户；虽以理观察则了无所有，然其显现却无法遮止，犹如水中之月、梦境、幻化一般，应以此了知而引生定解。

然后，为摧毁对身体之执著，诵"呸！"一声，观想体内肌肉、骨骼等一切界，豁然散开，与外在之界相融合；同样，每诵一声"呸"，依次观想血液融入水大、体温融入火大、呼吸融入风大[^2]，观想自身消融殆尽、了无所有。

其后，再诵一声"呸"，将自心与虚空融合为一，全然无有执著，豁然安住。

于后得位中，应反复忆念"自身内在五大已与外在五大无别融为一体，此狭隘之自身已然不存"之意乐。

如是修持，则疾病、邪祟、诅咒、污秽等一切疼痛与过患，皆能连根拔除。

此乃自文殊金刚之觉性密藏中迸发而出之第二甚深窍诀。

## 三、无二融摄于自身本位之窍诀

若自相续中生起烦恼与分别妄念等，以任何方法皆无法调伏，应如是思惟：我内心之中如翻腾涌动一般之分别妄念，乃是从因缘而生之有为法，因其乃是间歇性、时有时无者故。此等分别念，由执取能所而生；若不执取，则不生起，犹如虚空一般。

显现有法之种种事物，虽无量无边而存在，然而于其中，执自身狭隘之身心为能受用者，执种种善恶之境为所受用之对境，由此而生种种分别妄念，应认清此中要害。

由此，应将内在身心与外境、虚空及一切显现有法，融合为一味；无论所思为何，能思者与所思者本无差别，如虚空一般平等齐一，护持此种觉受，不作任何思维，任其安住于本然之处，观想其消融于本初之自性中。

如是应反复串习，令妄念不复生起，安住于放松坦然之中，久而久之，妄念自然消融；内在自然之安乐将炽然而生，修习止观之障碍，将自然平息。

此乃自文殊金刚之觉性密藏中迸发而出之第三甚深窍诀。

```
གཞན་ལ་དོགས་ན་ཕྱི་རོལ་རང་ལ་བསྟིམ། །
རང་ལུས་མི་བདེ་ཕྱི་རོལ་ཁམས་སུ་གཏོར། །
རང་གཞན་གཉིས་མེད་ནམ་མཁའི་ངང་དུ་བསྡད། །
ཐིམ་པ་རྣམ་གསུམ་འཇམ་དཔལ་མན་ངག་ཟབ། །
```

若恐惧他者，当将外境融入自身；若自身不适，当将其消散于外在之界；应安住于自他无二、如虚空一般之境界中；此三种融摄之法，即是文殊之甚深窍诀。

外境融入内身、内身融入外境、无二融摄于自身本位——此三种甚深窍诀，于土猪年十一月二十三日[^3]，在扎·多杰彭措山麓，从文殊金刚意海中流现而出之甚深教法也。

## 注释

[^1]: 英译本原注：本篇英译乃在堪祖·洛卓泰耶仁波切（Khentrul Lodro Thaye Rinpoche）指导下译出，仁波切明确嘱托应附加"限阅"警示——此中所述之甚深修法，唯应由已获得相应传承与指导之人研习修持。

[^2]: 英译本原注：如前文所述，肌肉、骨骼等融入地大；血液融入水大；体温融入火大；呼吸融入风大；心识融入虚空。

[^3]: 英译本原注：对应公历一九〇〇年一月二十四日。

## 译者说明

本篇正文依藏文原文重新译出，参考但不依赖已有英译本之措辞；英译本原有之三条译注，已一并译出并置于"注释"一节中标明，供读者参考。原文"ཐིམ་པ"（融摄／消融）一词贯穿全篇，指观修中将所惧、所苦之对境与能惧、能苦之自身，观想为融为一味、了无分别之状态，故据其文义，分别译为"融入""消融""融摄"，以求文从字顺。
