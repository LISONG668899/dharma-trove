# 金刚歌（那洛巴之二）

大瑜伽士那洛巴（Nāropa）造　据藏文译出

## 题解

《金刚歌》（梵 Vajragīti，藏 rdo rje'i glu）收于德格版丹珠尔续部释 ཞི 函第 153a 页（东北目录 D2289），紧接在同名的 D2288 之后。跋语说是"大瑜伽士（mahāyoga）那洛巴"所作，没有译者跋语。

本篇以"毒蛇"为中心意象，前后两用：先说分别念是狡诈的毒蛇，咬住了自心，使人随念而被束缚；再翻转过来，说智慧是多头的毒蛇，以三摩地的乳汁滋养，能杀死分别念这只"獴"，最后连那洛巴自己也被智慧之蛇吞食。结尾"谁知道？那洛巴自己知道；去问那洛巴自己"，是道歌中常见的自问自答。

**与前译的关系：**本篇以前没有译过，与已译篇目没有重复。前一篇 D2288（那洛巴之一）的主题与本篇相同，可以连读。

体例：本篇很短，依本译的体例，保留藏文原文于代码块中，按意义单元译出，最后附通篇连读；补的字放在方括号中，存疑之处以"【按】"说明。

## 一、分别念之蛇

```
རྣམ་རྟོག་སྦྲུལ་གདུག་གཡོ་ཅན་གྱིས། །
ཟིན་པར་གྱུར་ཏོ་རང་གི་སེམས། །
ཇི་ལྟ་ཇི་ལྟར་རྣམ་རྟོག་པ། །
དེ་ལྟ་དེ་ལྟར་རྣམ་པར་བཅིངས། །
དོན་མེད་སྡུག་བསྔལ་མང་པོ་མྱོང་། །
```

自己的心，被分别念这条狡诈的毒蛇咬住了。分别得有多少，就被束缚得有多少，徒然经受许多无意义的痛苦。

【按】"狡诈"（g.yo can），也有"游动不定"的意思，这里两义兼有：分别念像蛇一样游走不定，又善于欺骗人。"分别得有多少，就被束缚得有多少"（ji lta ji ltar rnam rtog pa / de lta de ltar rnam par bcings），与下文第 16–17 句"观察得有多少，就解脱得有多少"成对。

## 二、以智慧串习真如

```
འཁྲུལ་པའི་རྗེས་སུ་འབྲངས་པ་ཡིས། །
འཁྲུལ་པ་སྤངས་པར་མི་འགྱུར་ཏེ། །
དཔའ་བོ་སྙིང་རྗེར་ལྡན་པ་ཡིས། །
དེ་བཞིན་ཉིད་ལ་གོམས་པར་གྱིས། །
ཇི་ལྟ་ཇི་ལྟར་རྣམ་དཔྱད་ན། །
དེ་ལྟ་དེ་ལྟར་རྣམ་པར་འབྲལ། །
```

跟随着迷乱，迷乱是不会被舍弃的。［所以，］具足悲心的勇士啊，要串习真如！观察得有多少，就［从束缚中］脱离得有多少。

【按】"观察"（rnam dpyad），这里是指以智慧观察分别念的本性，与上文的"分别"（rnam rtog）相对：随着念头去分别，就被束缚；回过头来观察念头的本性，就得以脱离。"脱离"（rnam par 'bral），也可以理解为"离开［束缚］""远离［分别念］"。

## 三、智慧之蛇

```
ཤེས་རབ་སྦྲུལ་གདུག་མགོ་མང་གིས། །
བདག་ཉིད་ལ་ནི་ཟ་བར་བྱེད། །
ཤེས་རབ་སྦྲུལ་གདུག་མགོ་མང་ནི། །
ཏིང་འཛིན་འོ་མས་རྟག་ཏུ་གསོས། །
རྣམ་རྟོག་ནེའུ་ལེ་གསོད་པར་བྱེད། །
```

智慧这条多头的毒蛇，吞食它自己。智慧这条多头的毒蛇，恒常以三摩地的乳汁来滋养，它会杀死分别念这只獴。

【按】这里把"毒蛇"的意象翻转过来：前面说分别念是毒蛇，这里说智慧才是真正的毒蛇。

"吞食它自己"（bdag nyid la ni za bar byed），可能有两种理解：一是智慧在摧毁分别念之后，连自身也不留，如同两木相摩生火，火烧尽了木头，也就自己熄灭（《宝积经·迦叶品》的比喻）；二是"bdag nyid"也可读作"我自己"，即智慧之蛇吞食了我执。两者意思相通，存疑。

"以三摩地的乳汁滋养"：印度传说中以乳喂蛇，这里比喻智慧要以禅定来滋养。

"杀死分别念这只獴"（ne'u le，獴）：在自然中，獴是毒蛇的天敌，能杀蛇；这里却说智慧之蛇杀死分别念之獴，是有意颠倒的表征语言——平常分别念总是压倒智慧，而在修习中，智慧反过来降伏分别念。

## 四、那洛巴被吞食

```
ཤེས་རབ་སྦྲུལ་མགོ་བརྒྱ་པ་ཡིས། །
ནཱ་རོ་པ་ལ་རྟག་ཏུ་ཟ། །
དེ་ནི་སུ་ཡིས་ཤེས་པ་ཡིན། །
ནཱ་རོ་པ་ནི་ཉིད་ཀྱིས་ཤེས། །
ནཱ་རོ་པ་ནི་ཉིད་ལ་དྲིས། །
```

智慧这条百头的蛇，恒常吞食那洛巴。这是谁知道的呢？那洛巴自己知道。去问那洛巴自己吧！

【按】"恒常吞食那洛巴"：智慧之蛇最后吞食的，正是作者自己，即以"那洛巴"为代表的我执与能修者，被智慧所吞而不复存在。"那洛巴自己知道""去问那洛巴自己"，是说这种境界只能自证自知，不能由他人告诉。前面多处说"多头"，这里说"百头"，是同一意象的加强。
