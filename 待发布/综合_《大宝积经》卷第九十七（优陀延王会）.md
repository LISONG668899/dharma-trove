# 《大宝积经》卷第九十七（优陀延王会）

唐·三藏菩提流志 奉诏译

## 优陀延王会第二十九

【按】译者题名“三藏”，宋、元、明、宫本作“三藏法师”；“诏”，宫本作“诰”。本会异译有西晋法炬译《佛说优填王经》（T0332），“优填”即优陀延。

#### 舍摩夫人入慈三昧，箭不能伤

如是我闻：一时，佛在拘睒弥国瞿师罗园，与大比丘众一千二百五十人在一起。那时优陀延王的第一夫人名为舍摩，常对如来以及诸圣众深信恭敬，亲近供养，并常称赞如来的功德。当时王又有第二夫人名为帝女，常怀谄曲嫉妒，前往王那里，妄说如来以及诸弟子对大夫人有非法之事。王听了这话，极为瞋怒，便以箭射舍摩夫人。那时夫人哀愍国王，入于慈三昧，当时所射的箭随即退回，到王头顶上空中停住，那箭火焰赫赫犹如火聚，甚为可怖。乃至射了三次，箭都是这样。

【按】“乃至三发”之“发”，元、明本作“射”。

那时优陀延王见到这件事，全身毛竖，惊慌悔恨，对夫人说：“你是天女，还是龙女？或是夜叉女、乾闼婆女、毗舍遮女、罗刹女？”夫人回答：“我不是天女，乃至也不是罗刹女。大王应当知道，我在佛所听闻正法，受持五戒，作优婆夷，哀愍大王，入于慈三昧。王虽然对我生起不善之心，由于我的慈愿，得以没有伤损。”于是赞叹国王说：“善哉大王！应当对如来、应、正遍知归命顶礼，必获安隐。”

【按】“因叹王言”之“叹”，宋、元、明本作“劝”。

#### 王诣佛忏悔，请说女人过患

优陀延王便这样想：“她在佛所听闻正法，作优婆夷，尚且有这样的威神之力，何况如来、应、正等觉。”这样想之后，便前往佛所，顶礼佛足，右绕三匝，说：“世尊！我由于欲染的因缘，被那女人的虚妄言说所诳惑，便对如来以及诸圣众生起毒害之意。”把上述之事一一陈说。又对佛说：“唯愿如来以及诸圣众施我欢喜，听我忏悔，令这样的罪过迅速消灭。”

【按】“𠎝”字先前电子文本未能显示，今据CBETA补出，同“愆”，即罪过。“令速消灭”之“令”，宫本作“今”。

那时世尊告诉那位国王说：“如你所说，你以为如来以及诸圣众如凡愚之人一样有种种过患，便对福田妄起瞋毒。你现在若能依圣法律，自己忏悔其罪，没有覆藏之心，尽未来世不再违犯，我当摄受你，令你将来善法增长。”优陀延王又对佛说：“世尊！我被女人所迷惑颠倒，狂乱无知，因此生起粗猛的瞋毒，由于这罪业当堕地狱。唯愿世尊为了利益安乐众生，慈悲开示女人谄曲虚诳的过患，不要令我们亲近女人，在长夜中得免种种苦。”佛说：“暂且放下这件事。为什么要问这个而不问别的呢？”王说：“世尊！我没有别的要问。女人令我造地狱之业，我现在只为了了知女人的过患，女人的谄曲、虚诳、邪媚。愿为开示。”乃至三次请求，也是这样说。佛说：“王应当先知道男子的过患，然后再观察女人的过失。”优陀延王说：“是的，世尊。愿乐欲闻。”

【按】“瞋毒”之“毒”，元、明本作“恚”。“女人过失”之“失”，明本作“患”。

#### 丈夫第一过患：耽欲不近善人

佛说：“一切男子都由于四种不善的过失，被女人所迷乱。哪四种？一是对诸欲染耽著无厌，乐于观看女人而自我放纵，不知亲近具清净戒、修福业的沙门以及婆罗门。因为不亲近这样的人，对净信以及清净尸罗、多闻、布施、智慧都退失。他由于没有信、戒、多闻、布施、智慧等法，不是善丈夫，行饿鬼之法，没有智慧，耽欲放逸，被欲所执持，被欲所系缚，靠欲而活命，亲近愚夫，远离智者，以恶友为伴，行所不宜之事，贪著女人不净的境界，便被女人所调伏。犹如奴仆，系属于女人，堕落在女人那里。没有惭愧，亲近游止于那些疮漏之门，脓血污秽，涕唾常流，犹如冢间的不净境界。乃至对父母违背其养育之恩，舍离沙门以及婆罗门，不生殷重的恭敬供养。习行畜生所行之法，对佛、法、僧不生净信，对涅槃界永当退失。这样的人，当入众合乃至阿鼻诸大地狱，也当堕于鬼界、畜生，没有救护。虽然听闻我的教导，仍数数思念邪恶女人的歌舞戏笑，不生厌离。应当知道，他习行的是愚人之法，不乐于修行善丈夫之事。大王！应当知道，男子亲近女人之时，就是亲近恶道之法。这是男子的第一种过患。”

【按】“愆过”之“愆”，宋、元、明、宫本作“𠎝”。“洟唾”之“洟”，宋、元、明、宫本作“涕”。

那时世尊说偈道：

```
诸欲皆苦，下劣秽恶，脓血不净，深可厌畏。
众多过患，之所集处，何有智人，于此忻乐？
犹如厕中，不净盈溢，亦如死狗，若死野干，
及尸陀林，秽污充遍；欲染之患，可厌亦然。
诸愚痴辈，爱恋女人，如犬生子，未甞舍离；
亦如蝇见，所吐饮食；又若群猪，贪求粪秽。
女人能坏，清净禁戒，亦复退失，功德名闻，
为地狱因，障生天道；何有智人，于此忻乐？
```
（大意：诸欲都是苦，下劣秽恶，脓血不净，深可厌畏，是众多过患所集之处，哪有智者会对它欣乐？犹如厕中不净满溢，也如死狗、死野干，以及尸陀林中秽污充遍；欲染的过患，也同样可厌。那些愚痴之辈爱恋女人，如狗生子，从不舍离；也如苍蝇见到吐出的饮食；又如群猪贪求粪秽。女人能破坏清净的禁戒，也令人退失功德名闻，是地狱之因，障碍生天之道；哪有智者会对此欣乐？）

```
又如有人，服食毒药，身心痛恼，不能运动。
由是欲因，能为苦本，如身有毒，愚不了知。
亦如不了，幻化之法，妄有寻求，但自疲苦。
愚夫亦尔，常于欲染，疲苦贪求，堕诸地狱。
或设饮食，歌舞伎乐，婚娶他女，将为己妻，
积集众多，无利苦法。愚夫造此，无利之业，
增长诸罪，退失善根。于无利中，不惜身命，
由斯坠堕，恶道深坑，便招地狱，猛焰铁丸，
锋刃刀山，毒箭诸苦。女人能集，众多苦事，
假以花香，而为严好。愚人于此，妄起贪求，
亲近称誉，下劣之法，退失智慧，堕落三涂。
```
（大意：又如有人服食毒药，身心痛恼，不能动弹。由于这欲因，能成为苦的根本，如身中有毒，愚人却不了知。也如不了知幻化之法，虚妄地寻求，只是自己疲苦。愚夫也是这样，常对欲染疲苦贪求，堕入种种地狱。或设饮食、歌舞伎乐，娶他人的女儿作自己的妻子，积集众多无利之苦法。愚夫造作这无利之业，增长种种罪，退失善根。在无利之事中不惜身命，由此坠堕于恶道深坑，便招致地狱中的猛焰、铁丸、锋刃、刀山、毒箭种种苦。女人能聚集众多苦事，借花香来作严饰；愚人对此妄起贪求，亲近称誉下劣之法，退失智慧，堕落三途。）

【按】“伎乐”之“伎”，宋、元、明、宫本作“妓”。

```
此由愚痴，之所迷惑，如海疲鸟，迷于彼岸；
又如愚夫，取于热铁，置之颈项，如牛被轭。
欲如诸酒，狂乱于人，如何愚夫，不知苦本？
或于父母，不识恩慈，皆由欲染，生此过患。
常于如是，邪欲之法，称赞习行，无有惭愧。
彼由愚痴，所迷乱故，作是罪已，当趣三涂。
耽重于欲，惛醉之人，父母之恩，亦能弃舍。
若有贪染，亲近欲者，则为违背，福德上田。
无量俱胝，妄想烦扰，展转逼恼，从此而生。
或复悕求，世间财位，以是非法，展转相劝。
由此现招，捶打苦事，死必当堕，阿鼻地狱。
现见众苦，皆来集身，善友乖离，天宫永失。
```
（大意：这是由于愚痴所迷惑，如大海中疲倦的鸟，迷失了彼岸；又如愚夫取来热铁，放在颈项上，如牛被套上轭。欲如种种酒，令人狂乱，为什么愚夫不知它是苦的根本？或对父母不识其恩慈，都是由于欲染而生这过患。常对这样的邪欲之法称赞习行，没有惭愧。他由于被愚痴所迷乱，作了这些罪之后，当趣向三途。耽重于欲、昏醉的人，连父母之恩也能弃舍。若有贪染、亲近欲的人，便是违背了福德的上田。无量俱胝的妄想烦扰，辗转逼恼，都从此而生。或者希求世间的财物地位，以非法之事辗转相劝。由此现世招致捶打之苦，死后必当堕入阿鼻地狱。现见众苦都来集于其身，善友乖离，天宫永失。）

【按】“惛醉”之“惛”，宋、元、明、宫本作“昏”。

```
何有智人，于此忻乐？宁投铁狱，驰走刀山，
眠卧焰炉，不亲女色。若常贪染，邪欲之者，
退失众多，诸利乐事。女人能作，众苦之因，
欲能灭坏，一切安乐。恶法积集，善友乖离，
皆以耽求，女人为本。若有得闻，我之所说，
能于女人，深生厌离，则为庄严，清净天道，
亦当速证，无上菩提。
```
（大意：哪有智者会对此欣乐？宁可投入铁狱，奔走于刀山，眠卧于焰炉，也不亲近女色。若常贪染邪欲的人，会退失众多利乐之事。女人能作众苦之因，欲能灭坏一切安乐。恶法积集，善友乖离，都以耽求女人为根本。若有人得闻我所说，能对女人深生厌离，便是庄严清净的天道，也当迅速证得无上菩提。）

#### 丈夫第二过患：背父母恩

“再者，大王！父母都愿利乐所生之子，难作而能作，能忍一切难忍之事，即使种种不净秽恶也都能忍受。又想令儿子的色力之身迅速增长，令他见到阎浮提的胜妙之事，哺乳养育，没有疲厌之心。或者为了令儿子获得种种妙乐，艰辛经营求得财物，供给营办资生所需，以及前往他家结亲求娶。娶妻之后，对他家的女人爱恋耽著，由于耽著，昏醉缠心，或者见父母渐渐衰老，便违逆轻欺，所有的资财毫无惭愧地耗用，或者令父母不能住在家中。这都是由于被欲所迷惑颠倒。大王！应当知道，由于这个因缘，对自己的父母弃背其养育之恩，对他家的女人尊重承事，种种供给，没有疲厌之心，这就是成就地狱的根本。这是男子的第二种过患。”

【按】“乳餔”之“餔”，元、明本作“哺”。“营办”之“办”，宫本作“辨”。

那时世尊说偈道：

```
汝等当知，尊重供养，于父母者，是人常有，
释梵护世，之所扶持，能令居家，安隐快乐。
或因贸易，大海远方，安隐往来，获诸财利。
此即说为，无价大宝，现能与果，名最上田，
如是现世，果报珍宝，皆因供养，父母而得。
复于来世，当得远离，驼驴等身，负重驱役。
亦复不受，尸粪灰河，刀山锋刃，镕铜等苦。
又于来世，生在人中，富有财宝，丰饶谷帛，
妻子眷属，悉皆和穆。或复当来，得生天上，
宫殿园苑，音乐自然，纵意欢娱，受诸妙乐。
何有智者，闻是法音，于父母田，不勤供养？
```
（大意：你们应当知道，尊重供养父母的人，常有帝释、梵天、护世四王扶持，能令他居家安隐快乐。或者因为贸易远赴大海、远方，往来安隐，获得种种财利。这就说为无价的大宝，现世便能给予果报，名为最上的福田；这样现世果报的珍宝，都因供养父母而得。又在来世当得远离驼、驴等身，不受负重驱役之苦；也不受屎粪、灰河、刀山锋刃、熔铜等苦。又在来世生在人中，富有财宝，谷帛丰饶，妻子眷属都和睦。或者将来得生天上，宫殿园苑，音乐自然，纵意欢娱，受种种妙乐。哪有智者听了这法音，对父母这福田不勤加供养？）

【按】“释梵”，宫本作“梵释”。“尸粪”之“尸”，宋、元、明、宫本作“屎”，今依此译作“屎粪”。

#### 丈夫第三过患：邪见造恶

“再者，大王！若有男子由于邪见，不知自身迅速将会坏灭，造作种种恶而自我欺诳。那愚痴之人虚度长夜，犹如木石雕刻而成，虽然形状似人，却无所识知。习行诸欲，便是成就往恶趣之业。这是男子的第三种过患。”那时世尊说偈道：

```
丈夫为欲，之所迷乱，由斯造作，种种诸罪。
倒见暗障，隐蔽其心，乘此当生，恶趣牢狱。
邪行之者，当复远离，一切贤圣，亦不恭敬，
诸沙门等。由颠倒见，乃至归命，山河邪魅，
为于贪欲，或复杀害，一切禽兽，祭祀神祇。
倒见为因，非法求福，由斯永离，一切安乐。
若于是中，造恶之者，不知净信，凶险无惭。
如是之人，永离贤圣，彼必当堕，㘁叫地狱。
或为于欲，逼恼于他，当堕烧然，极烧然狱。
复由倒见，于佛法僧，不能亲近，恭敬供养，
正教法宝，而不听闻，远离贤圣，堕诸恶趣。
是故智者，既得人身，勿复作斯，颠倒妄见；
勤修布施，及净尸罗，当得生天，证菩提道。
```
（大意：男子被欲所迷乱，由此造作种种罪；颠倒之见与黑暗之障隐蔽其心，乘此当生于恶趣的牢狱。邪行的人当远离一切贤圣，也不恭敬诸沙门等。由于颠倒之见，乃至归命于山河邪魅，为了贪欲，或者杀害一切禽兽来祭祀神祇。以倒见为因，以非法求福，由此永离一切安乐。若在其中造恶的人，不知净信，凶险无惭，这样的人永离贤圣，必当堕入号叫地狱。或者为了欲逼恼他人，当堕入烧燃、极烧燃地狱。又由于倒见，对佛、法、僧不能亲近恭敬供养，对正教法宝不听闻，远离贤圣，堕入诸恶趣。所以智者既得人身，不要再作这颠倒妄见；勤修布施以及清净尸罗，当得生天，证得菩提之道。）

【按】“㘁”字先前电子文本未能显示，今据《大正藏》补出，元、明本作“嘷”，“㘁叫”即号叫。

#### 丈夫第四过患：为女人僮仆

“再者，大王！或有男子为了身命，极其劳苦地积集珍财。后来被女人所缠缚摄持，如那僮仆一样敬事供承，由于这因缘悭惜财宝，不布施沙门以及婆罗门，也能忍受王法的惩罚，轻毁凌辱都能忍受。或者被女人捶打呵叱，或者以至于怖惧，屈意奉承。见她忧戚，便自己想：‘我现在怎样令她欢悦？’应当观察这人是欲的僮仆，对这不净下劣的境界生起清净之想，起于爱染。亲近这样的女人之时，就是圆满恶趣之业。这是男子的第四种过患。”

【按】“凌辱”之“凌”，宋、元、明本作“陵”。“忧戚”之“戚”，宋、元、明、宫本作“慼”。

那时世尊说偈道：

【按】“说偈言”之“言”，宋、元、宫本作“曰”。

```
耽欲惛醉人，彼实无安乐，
亲近恶法故，不名善丈夫。
若人自纵逸，无有禁戒者，
随心之所为，失坏于福利。
彼无智慧人，行于畜生法，
驰趣于女色，犹猪乐粪秽。
愚者不能观，欲染之过患，
妄生殷重想，犹若盲冥人。
为色所系缚，增长于欲爱，
犹如于野干，不离尸冢间。
于声香味触，而生爱著心，
轮转生死中，如猕猴系柱。
无明缠覆故，为女所迷乱，
如市求利人，矫诈来亲附。
愚人亲近欲，是入魔境界，
犹若翳茶迦，耽嗜于粪秽。
亦如霔雹雨，能损于稼穑，
窑师常近火，多为所焚烧。
诸未见谛者，为欲失白法，
如风吹微糠，其义亦如是。
假如善丈夫，为杀者所执，
宁受斯逼害，不应亲女人。
```

#### 王归依

那时世尊说了这偈之后，优陀延王便对佛说：“现在所听闻的，希有希有。如来、应、正等觉善能宣说这些诸欲的过患。我现在归依佛、法、僧宝，从今以后乃至尽形寿归依佛、法、僧，作优婆塞。唯愿世尊摄受我。”

【按】“唯愿”之“唯”，明本作“惟”。

佛说此经之后，优陀延王以及大众，天、人、世间、阿修罗、乾闼婆等，听闻佛所说，欢喜奉行。
