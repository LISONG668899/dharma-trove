## 文殊师利普门会第十

### 无垢藏菩萨来集

如是我闻：一时，佛在王舍城耆阇崛山中，与大比丘众八百人在一起，菩萨摩诃萨四万二千人。那时有一位菩萨名叫无垢藏，与九万二千诸菩萨众恭敬围绕，从空中而来。

那时，世尊就告诉大众：“那些菩萨是受遍清净行世界普花如来的劝发，来到这娑婆世界，令他们在我这里听受普入不思议法门；其余诸菩萨也将来集会。”说了这话之后，无量无边他方与此界的诸菩萨众，都来集会于耆阇崛山，顶礼佛足，退住一边。

那时，无垢藏菩萨手持七宝千叶莲花，来到如来所，头面礼足，对佛说：“世尊！遍清净行世界的普花如来，以这宝花奉献世尊，并致以无量问候：少病少恼，起居轻利，安乐而行吗？”说了这话之后，就升入虚空，结跏趺坐。

【按】“无垢藏菩萨”，异译作“离垢藏菩萨”；“遍清净行世界普花如来”，异译作“净行世界普华如来”。

### 文殊请说普入不思议法门

那时，文殊师利菩萨摩诃萨在大众中即从座起，偏袒右肩，右膝着地，合掌恭敬，对佛说：“我忆念过去久远之时，曾在普灯佛所听闻宣说普入不思议法门。我在那时就获得八千四百亿那由他三昧，又能了知七十七万亿那由他三昧。善哉，世尊！愿垂哀愍，为诸菩萨宣说这法门。”

【按】“文殊师利”，异译作“溥首童真”。

那时，佛告诉文殊师利：“你现在仔细听，好好思念，我当为你宣说。”

文殊师利说：“是的，世尊！我愿意听闻。”

### 二十八种三昧

佛说：“若诸菩萨想要修学此法，应当修习诸三昧门，就是：色相三昧、声相三昧、香相三昧、味相三昧、触相三昧、意界三昧、女相三昧、男相三昧、童男相三昧、童女相三昧、天相三昧、龙相三昧、夜叉相三昧、乾闼婆相三昧、阿修罗相三昧、迦楼罗相三昧、紧那罗相三昧、摩睺罗伽相三昧、地狱相三昧、畜生相三昧、阎魔罗界三昧、贪相三昧、瞋相三昧、痴相三昧、不善法三昧、善法三昧、有为三昧、无为三昧。文殊师利！若诸菩萨对这样等一切三昧善能通达，就是已经修学此法了。

#### 色相三昧

“文殊师利！什么名为色相三昧？就说颂道：

```
观色如聚沫，中无有坚实，
不可执持故，是名色三昧。
```

（大意：观察色如水上聚沫，其中没有坚实之物；因为不可执持，这名为色三昧。）

#### 声相三昧

“又，文殊师利！什么名为声相三昧？就说颂道：

```
观声如谷响，其性不可得，
诸法亦如是，无相无差别，
了知皆寂静，是名声三昧。
```

（大意：观察声音如山谷回响，其性不可得；诸法也是这样，无相、无差别；了知它们都寂静，这名为声三昧。）

#### 香相三昧

“又，文殊师利！什么名为香相三昧？就说颂道：

```
假令百千劫，常嗅种种香，
如海纳众流，而无有厌足。
其香若是实，则应可满足，
但有假名字，其实不可取。
以不可取故，鼻亦无所有，
了知性空寂，是名香三昧。
```

（大意：假使在百千劫中常常嗅闻种种香气，如大海容纳众流，也不会满足。那香若是真实的，就应当可以满足；但它只有假名，实际上不可执取。因为不可执取，鼻根也无所有；了知其性空寂，这名为香三昧。）

#### 味相三昧

“又，文殊师利！什么名为味相三昧？就说颂道：

```
舌根之所受，咸醋等诸味，
皆从众缘生，其性无所有。
若能如是知，因缘和合起，
了此不思议，是名味三昧。
```

（大意：舌根所受的咸、醋等种种味道，都从众缘而生，其性无所有。若能这样了知它们由因缘和合而起，了达这不可思议之理，这名为味三昧。）

【按】“咸醋等诸味”之“味”，《大正藏》作“昧”，CBETA 据高丽藏作“味”。

#### 触相三昧

“又，文殊师利！什么名为触相三昧？就说颂道：

```
触但有名字，其性不可得，
细滑等诸法，皆是从缘生。
若能知触性，因缘和合起，
毕竟无所有，是名触三昧。
```

（大意：触只有名字，其性不可得；细滑等诸法，都是从缘而生。若能知道触的本性由因缘和合而起，毕竟无所有，这名为触三昧。）

#### 意界三昧

“又，文殊师利！什么名为意界三昧？就说颂道：

```
设集三千界，无量诸众生，
一心共思求，意界不可得。
不在于内外，亦不可聚集，
但以于假名，说有种种相。
犹如于幻化，无住无处所，
了知彼性空，是名意三昧。
```

（大意：假设集合三千大千世界无量的众生，一心共同思求，意界也不可得。它不在内，也不在外，也不可聚集，只是以假名而说有种种相。犹如幻化，无住也无处所；了知它的本性空，这名为意三昧。）

【按】“意界三昧”，元、明本作“意界相三昧”。

#### 女相三昧

“又，文殊师利！什么名为女相三昧？就说颂道：

```
四大假为女，其中无所有，
凡夫迷惑心，执取以为实。
女人如幻化，愚者不能了，
妄见女相故，生于染著心。
譬如幻化女，而非实女人，
无智者迷惑，便生于欲想。
如是了知已，一切女无相，
此相皆寂静，是名女三昧。
```

（大意：四大假合而为女人，其中无所有；凡夫以迷惑之心，执取以为真实。女人如同幻化，愚者不能了知；因为妄见女相，生起染著之心。譬如幻化出的女人，并非真实的女人，无智之人迷惑，便生起欲想。这样了知之后，一切女相都是无相，此相都寂静，这名为女三昧。）

#### 男相三昧

“又，文殊师利！什么名为男相三昧？就说颂道：

```
自谓是男子，见彼为女人，
由斯分别心，而生于欲想。
欲心本无有，心相不可得，
由妄分别故，于身起男想。
是中实无男，我说如阳焰，
知男相寂静，是名男三昧。
```

（大意：自认为是男子，见到对方是女人，由于这分别之心，而生起欲想。欲心本来无有，心相不可得；由于虚妄分别，对自身起男子之想。其中实在没有男子，我说它如同阳焰；了知男相寂静，这名为男三昧。）

#### 童男相三昧

“又，文殊师利！什么名为童男相三昧？就说颂道：

```
如树无根枝，花则不可得，
以花无有故，其果亦不生。
由无彼女人，童男亦非有，
随于分别者，假说如是名。
了知彼女人，及童男非有，
能如是观察，是童男三昧。
```

（大意：如树没有根与枝，花就不可得；因为没有花，果实也不会生。由于没有那女人，童男也不存在，只是随顺分别的人，假说这样的名字。了知那女人与童男都非实有，能这样观察，这是童男三昧。）

#### 童女相三昧

“又，文殊师利！什么名为童女相三昧？就说颂道：

```
如断多罗树，毕竟不复生，
何有智慧人，于中求果实？
若有能了知，诸法无生者，
不应起分别，童女为能生。
又如焦谷种，其牙本不生，
女人亦复然，是童女三昧。
```

（大意：如截断的多罗树，毕竟不会再生，哪有智慧的人会在其中求果实？若有人能了知诸法无生，就不应起分别，认为童女能够生育。又如烧焦的谷种，其芽本来不生，女人也是这样，这是童女三昧。）

【按】“其牙本不生”之“牙”，宋、元、明、宫本作“芽”。

#### 天相三昧

“又，文殊师利！什么名为天相三昧？就说颂道：

```
因清净信心，及以众善业，
受诸天胜报，端正殊妙身。
珍宝诸宫殿，非由造作成，
曼陀罗妙花，亦无种植者。
如是不思议，皆因业力起，
能现种种相，犹若净琉璃。
如是殊妙身，及诸宫殿等，
皆从虚妄生，是名天三昧。
```

（大意：因清净的信心以及众多善业，受诸天殊胜的果报，得端正殊妙之身。珍宝所成的诸宫殿，不是由造作而成；曼陀罗妙花，也没有人种植。这样不可思议，都由业力而起，能显现种种相，犹如清净的琉璃。这样殊妙的身体以及诸宫殿等，都从虚妄而生，这名为天三昧。）

【按】“犹若净琉璃”之“若”，宋、元、明、宫本作“如”。

#### 龙相三昧

“又，文殊师利！什么名为龙相三昧？就说颂道：

```
受此诸龙身，由不修于忍，
兴澍大云雨，遍满阎浮提。
不从前后际，亦不在中间，
而能生此水，复归于大海。
如是诸龙等，积习性差别，
起于种种业，业亦无有生。
一切非真实，愚者谓为有，
能如是了知，是名龙三昧。
```

（大意：受这诸龙之身，是由于不修忍辱；它们兴起大云降雨，遍满阎浮提。这水不从前际、后际来，也不在中间，而能生出这水，又归于大海。这样的诸龙等，因积习而性有差别，生起种种业，而业也是无生的。一切都非真实，愚者以为实有；能这样了知，这名为龙三昧。）

#### 夜叉相三昧

“又，文殊师利！什么名为夜叉相三昧？就说颂道：

```
是大夜叉身，从于自心起，
是中无有实，妄生于恐怖，
亦无有怖心，而生于怖畏。
观法非实故，无相无所得，
空无寂静处，现此夜叉相，
如是知虚妄，是夜叉三昧。
```

（大意：这大夜叉之身，是从自心而起，其中没有实体，妄生恐怖；也没有恐怖之心，却生起怖畏。观察诸法并非真实，无相、无所得；在空无寂静之处，显现这夜叉之相；这样了知其虚妄，是夜叉三昧。）

#### 乾闼婆相三昧

“又，文殊师利！什么名为乾闼婆相三昧？就说颂道：

```
彼实无所趣，名言假施设，
了知趣非趣，乾闼婆三昧。
```

（大意：它实际上无所趣向，只是名言假借施设；了知趣与非趣，是乾闼婆三昧。）

#### 阿修罗相三昧

“又，文殊师利！什么名为阿修罗相三昧？就说颂道：

```
修罗相所印，其相本无生，
无生故无灭，阿修罗三昧。
```

（大意：被阿修罗之相所印定，其相本来无生；因为无生，所以无灭，这是阿修罗三昧。）

#### 迦楼罗相三昧

“又，文殊师利！什么名为迦楼罗相三昧？就说颂道：

```
无身以为身，名字假施设，
名相无所有，迦楼罗三昧。
```

（大意：以无身为身，名字只是假借施设；名与相都无所有，这是迦楼罗三昧。）

#### 紧那罗相三昧

“又，文殊师利！什么名为紧那罗相三昧？就说颂道：

```
法无作而作，说为紧那罗，
了知此不生，紧那罗三昧。
```

（大意：法无作而作，说为紧那罗；了知它不生，这是紧那罗三昧。）

#### 摩睺罗伽相三昧

“又，文殊师利！什么名为摩睺罗伽相三昧？就说颂道：

```
彼由于名字，随世而安立，
是中无有法，而妄起分别。
了知此分别，自性无所有，
彼相寂静故，摩睺罗三昧。
```

（大意：它由于名字，随顺世间而安立；其中没有实法，而妄起分别。了知这分别，自性无所有；那相寂静，这是摩睺罗伽三昧。）

#### 地狱相三昧

“又，文殊师利！什么名为地狱相三昧？就说颂道：

```
地狱空无相，其性极清净，
是中无作者，从自分别生。
我坐道场时，了此无生相，
无相无生故，其性如虚空，
此相皆寂静，是地狱三昧。
```

（大意：地狱空而无相，其性极为清净；其中没有作者，是从自己的分别而生。我坐道场时，了知这无生之相；因为无相、无生，其性如同虚空；此相都寂静，这是地狱三昧。）

【按】“地狱空无相”之“相”，宫本作“垢”。

#### 畜生相三昧

“又，文殊师利！什么名为畜生相三昧？就说颂道：

```
如云现众色，是中无有实，
能令无智人，于此生迷惑，
于彼畜生趣，而受种种身。
犹如虚空云，现于诸色像，
了知业如幻，不生迷惑心，
彼相本寂静，是畜生三昧。
```

（大意：如云中显现种种色，其中没有实体，能令无智之人对此生起迷惑，在那畜生趣中受种种身。犹如虚空中的云，显现种种色像；了知业如幻化，不生迷惑之心；那相本来寂静，这是畜生三昧。）

#### 阎魔罗界三昧

“又，文殊师利！什么名为阎魔罗界三昧？就说颂道：

```
造作纯黑业，及以杂业者，
流转阎罗界，受于种种苦。
实无阎罗界，亦无流转者，
自性本无生，诸苦犹如梦，
若能如是观，阎罗界三昧。
```

（大意：造作纯黑之业以及杂业的人，流转于阎罗界，受种种苦。实际上没有阎罗界，也没有流转的人；自性本来无生，诸苦犹如梦境。若能这样观察，是阎罗界三昧。）

#### 贪相三昧

“又，文殊师利！什么名为贪相三昧？就说颂道：

```
贪从分别生，分别亦非有，
无生亦无相，住处不可得。
贪性如虚空，亦无有建立，
凡夫妄分别，由斯贪染生。
法性本无染，清净如虚空，
十方遍推求，其性不可得。
不了性空故，见贪生怖畏，
无畏生畏想，于何得安乐？
譬如愚痴人，怖畏于虚空，
惊惧而驰走，避空不欲见。
虚空遍一切，于何而得离？
愚夫迷惑故，颠倒分别生。
```

（大意：贪从分别而生，分别也非实有，无生也无相，住处不可得。贪的本性如同虚空，也没有建立；凡夫虚妄分别，由此生起贪染。法性本来无染，清净如虚空，在十方遍加推求，其性不可得。因为不了知其性空，见到贪而生起怖畏；在无可畏中生起畏想，又在何处得到安乐？譬如愚痴之人怖畏虚空，惊惧而奔走，想避开虚空，不愿看见它。虚空遍于一切，又在何处能够离开？愚夫因为迷惑，生起颠倒分别。）

```
贪本无自性，妄生厌离心，
如人欲避空，终无能脱者；
诸法性自离，犹如于涅槃。
三世一切佛，了知贪性空，
住此境界中，未曾有舍离；
于贪怖畏者，思惟求解脱。
如是贪自性，究竟常清净，
我证菩提时，了达皆平等。
若执贪为有，于彼当舍离，
由妄分别故，而言舍离贪。
此唯分别心，实无有舍离，
其性不可得，亦无有灭坏，
平等实际中，无解脱分别。
```

（大意：贪本来没有自性，却妄生厌离之心，如人想要避开虚空，终究没有能逃脱的；诸法之性本来远离，犹如涅槃。三世一切诸佛了知贪性空，住于这境界之中，从未有所舍离；对于贪而怖畏的人，才思惟求解脱。这样贪的自性，究竟常时清净，我证菩提时，了达一切都平等。若执著贪为实有，就说对它应当舍离；由于虚妄分别，才说舍离贪。这只是分别之心，实际上没有舍离；其性不可得，也没有灭坏；在平等的实际之中，没有解脱的分别。）

```
若于贪解脱，于空亦解脱，
虚空及与贪，无尽无差别；
若见差别者，我说令舍离。
贪实无有生，妄起生分别，
彼贪本性空，但有假名字，
不应以此名，而生于执著。
了贪无染故，是则毕竟空，
不由灭坏贪，而得于解脱。
贪法与佛法，平等即涅槃，
智者应当知，了贪寂静已，
入于寂静界，是名贪三昧。
```

（大意：若对贪得解脱，对虚空也得解脱；虚空与贪，无尽也无差别；若见有差别的人，我才说令他舍离。贪实际上无有生起，只是虚妄生起分别；那贪本性空，只有假名，不应因这名字而生起执著。了知贪无染，就是毕竟空；不是由于灭坏贪而得到解脱。贪法与佛法平等，就是涅槃；智者应当知道，了知贪寂静之后，入于寂静之界，这名为贪三昧。）

#### 瞋相三昧

“又，文殊师利！什么名为瞋相三昧？就说颂道：

```
以虚妄因缘，而起于瞋恚，
无我执为我，及由麁恶声，
起猛利瞋心，犹如于恶毒，
音声及瞋恚，究竟无所有。
如钻木出火，要假众缘力，
若缘不和合，火终不得生。
是不悦意声，毕竟无所有，
知声性空故，瞋亦不复生。
瞋不在于声，亦不身中住，
因缘和合起，离缘终不生。
如因乳等缘，和合生酥酪，
瞋自性无起，因于麁恶声。
愚者不能了，热恼自烧然，
应当如是知，究竟无所有。
瞋性本寂静，但有于假名，
瞋恚即实际，以依真如起，
了知如法界，是名瞋三昧。
```

（大意：因虚妄的因缘而生起瞋恚：把无我执为我，以及由于粗恶的言声，生起猛烈的瞋心，犹如恶毒；而音声与瞋恚，究竟都无所有。如钻木取火，要借助众缘之力；若缘不和合，火终究不能生起。这不悦意的声音，毕竟无所有；了知声音的本性空，瞋恚也就不再生起。瞋不在声音中，也不住在身中，是因缘和合而起，离开因缘终究不生。如凭借乳等因缘和合而生出酥酪，瞋的自性无起，是因粗恶之声而起。愚者不能了知，被热恼自我焚烧；应当这样了知它究竟无所有。瞋的本性寂静，只有假名；瞋恚即是实际，因为依真如而起；了知它如同法界，这名为瞋三昧。）

#### 痴相三昧

“又，文殊师利！什么名为痴相三昧？就说颂道：

```
无明体性空，本自无生起，
是中无少法，而可说为痴。
凡夫于无痴，而妄生痴想，
于无著生著，犹若结虚空。
奇哉愚痴人，不应作而作，
诸法皆非有，杂染分别生。
如欲取虚空，安置于一处，
设经千万劫，终无有积聚。
愚夫从本来，经不思议劫，
所起于痴结，而无少分增。
如彼取虚空，终无有增减，
多劫集于痴，增减亦如是。
又如于槖籥，受风无际限，
愚痴著欲乐，无有厌足时。
```

（大意：无明的体性空，本来没有生起，其中没有少许法可以说为痴。凡夫在无痴之中虚妄生起痴想，在无可执著中生起执著，犹如在虚空中打结。奇哉，愚痴之人，作不应作之事；诸法都非实有，只是由杂染分别而生。如想取虚空安置在一处，即使经过千万劫，终究不能积聚；愚夫从本以来，经过不可思议劫，所起的痴结，也没有少许增加。如那取虚空的人，终究没有增减；多劫积集的痴，增减也是这样。又如风箱，受风没有限度；愚痴之人贪著欲乐，没有厌足之时。）

```
是痴无所有，无根无住处，
以根非有故，亦无痴可尽。
以痴无尽故，边际不可得，
是故诸众生，我不能令尽。
设我一日中，能度三千界，
所有诸众生，皆令入涅槃，
复经不思议，无量千万劫，
日日如是化，众生界不尽。
痴界众生界，是二俱无相，
彼皆如幻化，故不能令尽。
痴性与佛性，平等无差别，
若分别于佛，彼则住愚痴。
痴及一切智，性皆不可得，
然彼诸众生，皆与痴平等。
```

（大意：这痴无所有，无根也无住处；因为根非实有，也没有痴可以穷尽。因为痴无尽，边际不可得，所以诸众生，我不能令其穷尽。假设我在一日之中，能度三千大千世界所有的众生，都令他们入于涅槃，又经过不可思议的无量千万劫，日日这样教化，众生界也不会穷尽。痴界与众生界，二者都无相，都如幻化，所以不能令其穷尽。痴性与佛性，平等无有差别；若分别于佛，他就住于愚痴。痴与一切智，其性都不可得；而那些众生，都与痴平等。）

```
众生不思议，痴亦不思议，
以不思议故，不应取分别。
如是思惟心，思量不可得，
痴亦不可量，以无边际故。
既无有边际，从何而得生，
自性无生故，相亦不可得。
了痴无有相，观佛亦复然，
应当如是知，一切法无二。
痴性本寂静，但有于假名，
我证菩提时，亦了痴平等，
能作如是观，是名痴三昧。
```

（大意：众生不可思议，痴也不可思议；因为不可思议，不应取著分别。这样思惟的心，思量不可得；痴也不可量，因为没有边际。既然没有边际，又从何处生起？因为自性无生，相也不可得。了知痴无有相，观佛也是这样；应当这样了知一切法无二。痴的本性寂静，只有假名；我证菩提时，也了知痴平等；能作这样的观察，这名为痴三昧。）

【按】“槖籥”，即风箱。“不应取分别”之“取”，宋、元、明、宫本作“起”。

#### 不善法三昧

“又，文殊师利！什么名为不善法三昧？就说颂道：

```
知彼贪瞋痴，种种诸烦恼，
所有诸行相，虚妄无真实，
能如是观察，是不善三昧。
```

（大意：了知那贪、瞋、痴种种烦恼，所有诸行之相都虚妄不实；能这样观察，是不善法三昧。）

#### 善法三昧

“又，文殊师利！什么名为善法三昧？就说颂道：

```
汝等应当知，诸善意乐者，
心行各差别，皆同于一行。
以一出离相，了知于一切，
皆悉寂静故，是名善三昧。
```

（大意：你们应当知道，诸怀善意乐的人，心行各有差别，却都同归于一行。以一种出离之相了知一切，因为一切都寂静，这名为善法三昧。）

#### 有为三昧

“又，文殊师利！什么名为有为三昧？就说颂道：

```
汝等应当知，一切有为法，
非是所造作，亦无可称量。
我了知诸行，性无有积集，
一切皆寂静，名有为三昧。
```

（大意：你们应当知道，一切有为法，不是所造作的，也不可称量。我了知诸行，其性没有积集，一切都寂静，名为有为三昧。）

#### 无为三昧

“又，文殊师利！什么名为无为三昧？就说颂道：

```
无为性寂静，于中无所著，
亦复无出离，但有假名字。
为执著众生，而说彼名字，
能如是了知，名无为三昧。
```

（大意：无为之性寂静，其中无所执著，也没有出离，只有假名。是为了执著的众生而说那名字；能这样了知，名为无为三昧。）

### 闻法获益

那时，世尊宣说这样等不可思议的微妙偈时，九万二千菩萨得无生法忍，三万六千比丘于诸漏心得解脱；七十二万亿那由他诸天，以及六千比丘尼、一百八十万优婆塞、二千二百优婆夷等，都发阿耨多罗三藐三菩提心。

### 诸三昧之名

那时，文殊师利菩萨又对佛说：“唯愿世尊为诸菩萨演说种种三昧的名字，令听闻的人诸根通利，对诸法得智慧之明，不被一切邪见众生所摧伏；也令他们证得四无碍辩，在一个文字中能了知种种文字，在诸文字中了知一个文字；又以无边的辩才为诸众生善说法要；也令他们证得甚深法忍，在一刹那中了知一切行，这一切行各自又有无边的行相，都能了知。”

佛说：“文殊师利！有三昧名为无边离垢，若菩萨得这三昧，能显现一切诸清净之色。又有三昧名为可畏面，得这三昧，有大威光，映蔽日月。又有三昧名为出焰光，得这三昧，能映蔽一切帝释、梵王的威光。又有三昧名为出离，得这三昧，令诸众生出离一切贪恚愚痴。又有三昧名为无碍光，得这三昧，就能照耀一切佛刹。又有三昧名为无忘失，得这三昧，能受持诸佛所说的教法，也能为他人敷演其义。又有三昧名为雷音，得这三昧，善能显示一切言音，上至梵世。又有三昧名为喜乐，得这三昧，令诸众生喜乐满足。又有三昧名为喜无厌，得这三昧，见闻他的人没有厌足。又有三昧名为专一境难思功德，得这三昧，能示现一切神变。又有三昧名为解一切众生语言，得这三昧，善能宣说一切语言，在一字中说一切字，了知一切字同于一字。又有三昧名为超一切陀罗尼王，得这三昧，能善了知诸陀罗尼。又有三昧名为一切辩才庄严，得这三昧，善能分别一切文字与种种言音。又有三昧名为积集一切善法，得这三昧，能令众生都听闻佛声、法声、僧声、声闻声、缘觉声、菩萨声、波罗蜜声；这样，菩萨住于三昧时，令诸众生听闻这些声音不断。”

### 受持此法门得四种辩才

那时，文殊师利对佛说：“唯愿世尊加威护念，令我获得无碍辩才，宣说这法门的殊胜功德。”

佛说：“善哉！随你所愿。”

文殊师利又对佛说：“若有菩萨对这法门受持读诵而无疑惑，应当知道这人在现身之中，决定获得四种辩才，就是捷疾辩才、广大辩才、甚深辩才、无尽辩才；对诸众生之心常加护念，随其所修行，若有想要毁坏的，都能觉察，令其不被毁坏。”

那时，世尊赞叹文殊师利菩萨说：“善哉，善哉！你对这义理能善加分别。如布施的人获得大财富，持禁戒的人决定生天，若能受持这部经典，现身获得辩才，必定不虚。如日光出现能除诸黑暗，也如菩萨坐菩提座成等正觉，决定无疑；受持读诵这部经典的人，现身获得辩才，也是这样。文殊师利！若又有人想在现身之中求得辩才，应当对这部经生起信乐，受持读诵，广为人说，不要生起疑惑。”

那时，无垢藏菩萨对佛说：“世尊！若诸菩萨在佛涅槃后，对这法门心无疑惑，受持读诵，为他人广说，我当摄受他们，加持他们的辩才。”

### 波旬求佛不加护此经

那时，天魔波旬愁忧苦恼，悲泣流泪，来到佛所，对佛说：“如来往昔证无上菩提时，我在那时已怀忧恼；又在今日宣说这法门，我加倍生起大苦，如中毒箭。若诸众生听闻这部经典，决定于阿耨多罗三藐三菩提不退转，入般涅槃，令我的境界都空虚。如来、应、正等觉能令一切受苦的众生都得安乐，愿垂哀愍，给与大慈悲，不对这部经加威护念，令我安稳，忧苦都除。”

【按】“愿垂哀愍与大慈悲”之“与”，宋、元、明、宫本作“兴”。

那时，世尊告诉波旬说：“不要怀着忧恼。我对这法不作加护，诸众生等也不涅槃。”

天魔波旬听了这话，欢喜踊跃，忧恼全除，就在佛前忽然不见了。

那时，文殊师利菩萨上前对佛说：“如来现在有什么密意，告诉波旬说‘我对这法不作加护’？”

佛说：“文殊师利！是以无加护来加护这法，所以对他说这样的话。因为一切法平等实际，都归于真如，同于法界，远离诸言说，是不二之相，所以没有加护。以我这样诚实之言，没有虚妄，能令这部经在阎浮提广为流布。”

### 经名与流通

那时，世尊说了这话后，告诉阿难说：“这部经名为‘普入不思议法门’。若能受持这样的经典，就是受持八万四千法门，等无差别。为什么？我对这部经善加通达之后，才能为那些众生等演说八万四千法门。所以，阿难！你对这法应当善加护持，读诵流通，不要令它忘失。”

佛说完这部经，文殊师利菩萨、无垢藏菩萨、尊者阿难，以及诸世间的天、人、阿修罗、乾闼婆等，听闻佛所说，都大欢喜，信受奉行。

【按】文殊师利普门会凡一卷，即本卷；相当于异译《佛说普门品经》全经。
