# 事物不思议（帝洛巴不思议之七）

瑜伽自在帝洛巴说　据藏文译出

## 题解

本篇是帝洛巴"不思议"八篇口诀的第七篇（东北目录 D2311），跋语说是帝洛巴在护称城（གྲོང་ཁྱེར་གྲགས་པ་སྐྱོང）对一位幻师所说，名为"事物不思议"。全篇约九十句，是八篇中结构最清楚的一篇：先称赞幻师的职业，因为佛说一切法如幻；然后依次以幻术、阳焰、梦、影像、化现五喻，说明一切事物来无所从、去无所至、显现时无实；接着回答"幻象无心，众生有心，不能相比"的疑问，引用幻士贤善供佛的故事；又说五喻虽不实，却都能起作用；最后以渡河之船为喻，说明如幻的福德在粗重未尽时仍须修持。

帝洛巴名下有八篇以"不思议"（bsam gyis mi khyab pa）为名的短篇口诀，在德格版丹珠尔续部释 ཞི 函中连续排列（第 246a 至 253a 页前后，东北目录 D2305 至 D2312）。第一篇之前有梵藏总题"大手印不思议"（梵 Acintyamahāmudrā，藏 phyag rgya chen po bsam gyis mi khyab pa），东北目录据此把第一篇编为 D2305。八篇各有独立的开头、礼敬与跋语，跋语都说是瑜伽自在帝洛巴在某地对某一种人所说，都没有译者的记载。八篇依次是：对瑜伽士说"自性不思议"，对威力者说"事业不思议"，对歌者说"音乐不思议"，对外道说"法性不思议"，对屠夫说"杀之结合不思议"，对吠陀师说"种种不思议"，对幻师说"事物不思议"，对娼女说"不思议大乐"。

这一组口诀的特点是"随类说法"：帝洛巴就每一种人所熟悉的行业与生活，把它转为认识心性的大手印之道。歌者的音声、屠夫的屠宰、幻师的幻术、娼女的欲乐，都被用作象征，指向同一个不可思议的心性。所以篇中凡是说到杀、欲、酒肉等，都是象征语言，绝不可照字面理解或效仿；涉及圆满次第风脉明点与事业手印的部分，只能在具德上师座前，依具足的灌顶与口授领受。

关于编号：所据的 Esukhia 电子版只在第一篇前标有 {D2305}，第二至第八篇没有单独的编号标记。本译依篇次顺序，把八篇依次配为 D2305 至 D2312，这一配属与东北目录通行的次序一致，但未能逐篇核对目录原书，读者须知。

体例：藏文原文全部保留在代码框中，按意义分节，每节后附汉译；凡标"存疑"的按语，表示本译对原文意思没有把握。藏文依 Esukhia 德格丹珠尔电子版，异文取第二读。

## 篇题

```
སྒྱུ་མ་མཁན་ལ་གདམས་པ་བཞུགས། །
```

对幻师的教言。

## 一、诸法如幻，即能仁密意

```
ཀྱེ་ཧོ། །
བཞིན་བཟང་རྣལ་འབྱོར་བརྩོན་པས་ང་ལ་ཉོན། །
ལེགས་སོ་ལེགས་སོ་ཁྱོད་ཀྱི་མཛད་པ་ལེགས། །
ཐེག་པའི་ཚུལ་ཆེན་ཐུབ་པའི་གསུང་རབ་རྣམས། །
སྒྱུ་མ་ལྟ་བུར་རྒྱལ་བས་རབ་ཏུ་གསུངས། །
ཆོས་རྣམས་ཐམས་ཅད་སྒྱུ་མ་སྨིག་རྒྱུ་དང། །
རྨི་ལམ་གཟུགས་བརྙན་སྤྲུལ་པ་ལྟ་བུ་རུ། །
ལེགས་པར་ཤེས་ན་ཉོན་མོངས་སྤང་དུ་མེད། །
རང་གྲོལ་ཡེ་ཤེས་ཐུབ་པའི་དགོངས་པའོ། །
```

嗟！面容美好、精进的瑜伽士，听我说：善哉，善哉！你的作为很好。大乘之理、能仁的经教，诸佛都说［一切法］是如幻的。如果善于了知一切法如幻、如阳焰、如梦、如影像、如化现，就没有需要断除的烦恼；自解脱的智慧，就是能仁的密意。

【按】本篇对一位幻师（变戏法的人）说法，帝洛巴先称赞他的职业"很好"，因为幻术正是佛陀说一切法如幻时所用的譬喻。下面依次以幻、阳焰、梦、影像、化现五喻开示。

## 二、幻术之喻

```
ཁྱོད་ཀྱིས་རྡེའུ་ཤིང་བུ་ལ་སོགས་ལ། །
སྦྱོར་བ་གོམས་པས་སྔགས་ཀྱིས་བསྣུན་པ་ན། །
སྐྱེས་པ་བུད་མེད་རྟ་དང་གླང་པོ་སོགས། །
གཟུགས་བརྙན་སྣ་ཚོགས་སྣང་བ་འབྱུང་བ་ན། །
དང་པོ་གང་ནས་ཀྱང་ནི་མ་བྱུང་ལ། །
སྣང་བའི་ཚེ་ན་སྒྱུ་མ་ཡིན་པའི་ཕྱིར། །
མཚན་ཉིད་གང་ཡང་ཡོད་མིན་སྒྱུ་མ་བསྡུས་པ་ན། །
འགགས་ཤིང་མི་སྣང་གྱུར་ཚེ་གང་དུའང་སོང་བ་མེད། །
བསྡུས་ཏེ་མི་སྣང་གྱུར་ཀྱང་སྐད་ཅིག་རྒྱུད་མ་ཆད། །
དེ་ལྟར་སྣང་དང་མི་སྣང་གཉིས་ཀའི་མཚན་ཉིད་མེད། །
གཅིག་གཉིས་ཡིན་ཕྱིར་ཇི་སྲིད་རྐྱེན་ཉིད་དང། །
ཉེ་བར་གནས་པར་སྣང་ཙམ་མཚན་ཉིད་རྫོགས། །
```

你以小石子、木片等，熟习了结合的方法，以咒语施加时，男人、女人、马、象等种种影像就显现出来。最初，它们并不是从任何地方来的；显现的时候，因为是幻，没有任何真实的体相；收摄幻术时，它们灭去、不再显现，也没有去往任何地方；虽然收摄而不显现，刹那的相续并没有断绝。这样，显现与不显现，二者都没有体相；只要因缘近住，仅仅是显现，幻的体相就已圆满。

【按】古印度的幻师以石子、木片为所依，以咒力使观众见到人、马、象等。帝洛巴指出：幻象来无所从，去无所至，显现时也没有实体。

【按】存疑。第二十一句"གཅིག་གཉིས་ཡིན་ཕྱིར"，字面是"因为是一或二"，所指不明，本译略去未强译，只依下文译出"只要因缘近住，仅仅是显现，幻的体相就圆满"。"刹那的相续没有断绝"，大概是说幻术虽收，只要条件具足，随时可以再现。

## 三、阳焰之喻

```
དེ་བཞིན་སྨིག་རྒྱུ་ཞེས་བྱ་མཚན་ཉིད་ཀྱང། །
ས་ཕྱོགས་ཚ་སྒོ་ཅན་ལ་ཉེ་བར་གནས། །
ཉི་མས་གདུང་དང་སེར་བུའི་འཇོལ་ཕྱོགས་འབབ། །
རྒྱང་ནས་བལྟས་པས་ཆུ་ཀླུང་གང་བར་མཐོང། །
དེ་ཉིད་བྱུང་དང་སྣང་བ་འགགས་པས་ཀྱང། །
སྣང་དང་མི་སྣང་དབྱེར་མེད་མཚན་ཉིད་གཅིག། །
```

同样，所谓阳焰的体相：在有热气的地方，被太阳晒着，［热气］沿着斜坡流下，从远处看去，好像见到满满的河水。它的出现与显现的消失，显现与不显现没有分别，体相同一。

【按】存疑。"སེར་བུའི་འཇོལ་ཕྱོགས་འབབ"，本译理解为热气沿斜坡流动，"སེར་བུ"一般指微风，所指不完全确定。

## 四、梦之喻

```
རྨི་ལམ་ཞེས་བྱ་སྐྱེས་བུ་གཉིད་ལོག་པས། །
གཉིད་ནང་ཀུན་དགའ་ར་བ་སྐྱེད་མོས་ཚལ། །
ལོངས་སྤྱོད་སྣ་ཚོགས་རྨི་ཞིང་སྣང་གྱུར་ཀྱང། །
བཙོན་ར་ཁྲི་མོན་སྡུག་བསྔལ་སྣ་ཚོགས་སྣང། །
སྐྱེ་དང་གནས་དང་འགག་པར་འགྱུར་བའི་ཚེ། །
དོན་གྱི་ཆ་གཞན་བསྒྲུབ་པར་བྱས་པ་མེད། །
```

所谓梦：人入睡之后，在睡梦中梦见欢喜的园林、花园，种种受用；也会显现监牢、刑具等种种痛苦。在它生起、安住、消灭的时候，并没有成办任何其他实义的部分。

【按】存疑。"ཁྲི་མོན"，本译读作"刑具"，所指不确定。

## 五、影像之喻

```
གཟུགས་བརྙན་ཞེས་བྱ་མེ་ལོང་དག་པ་ལ། །
སྣ་ཚོགས་གཟུགས་སུ་སྣང་བར་གྱུར་པ་ན། །
སྐྱེ་འགག་ལ་སོགས་རྣམ་གཞག་གཞན་མེད་པས། །
སྣང་དང་མི་སྣང་དབྱེར་མེད་མཚན་ཉིད་གཅིག། །
```

所谓影像：在清净的镜子中，显现出种种形色时，没有生灭等其他的安立，显现与不显现没有分别，体相同一。

## 六、化现之喻

```
སྤྲུལ་པ་ཞེས་བྱ་ཡེ་ཤེས་ཏིང་འཛིན་ནམ། །
རིག་སྔགས་གྲུབ་པའི་མཐུ་ལས་བྱུང་གྱུར་པ། །
མེ་ཏོག་ཁ་དོག་དབྱེ་བའི་རྣམ་པ་ཡིས། །
དེ་བཞིན་གཤེགས་པ་ལ་སོགས་སྣང་བར་འགྱུར། །
```

所谓化现：由智慧等持或明咒成就之力所生，以花朵颜色差别的样子，显现出如来等等。

## 七、内外诸法都是如此

```
དེ་བཞིན་ཕྱི་ནང་དངོས་པོ་སྣ་ཚོགས་སྣང་བ་དག། །
ཇི་སྲིད་གཟུང་དང་འཛིན་པའི་རྣམ་པར་རྟོག་པ་ཡིས། །
བག་ཆགས་དབང་གིས་ཉེ་བར་གནས་པ་དེ་སྲིད་དུ། །
དངོས་པོ་སྣ་ཚོགས་སྣང་བ་འབྱུང་བར་གྱུར་པ་རྣམས། །
དང་པོ་བྱུང་ཚེ་གང་ནས་མ་བྱུང་ལ། །
སྣང་ཙམ་ཉིད་ན་བག་ཆགས་དབང་གིས་སྣང། །
གཟུང་འཛིན་གཉིས་ཀྱི་བག་ཆགས་ཟད་པ་ན། །
མི་སྣང་གྱུར་ཚེ་གང་དུའང་སོང་བ་མེད། །
```

同样，外与内种种事物的显现，只要能取所取的分别，以习气之力近住，种种事物的显现就会生起。它们最初生起时，不是从任何地方来的；只是显现时，由于习气之力而显现；当能取所取二者的习气穷尽时，它们不再显现，也没有去往任何地方。

【按】这一节把前面五喻收归于一切法：一切显现都由能取所取的习气而现起，习气尽时显现也就止息，与幻术的生起与收摄完全相同。

## 八、幻与众生"头相等"

```
ཁྱོད་ཀྱི་སྒྱུ་མ་སེམས་དང་སེམས་བྱུང་དང། །
ཚོར་བ་འདུ་ཤེས་ཉེ་བར་མི་སྤྱོད་ཅིང། །
འགྲོ་བའི་ཕུང་པོ་སེམས་དང་སེམས་བྱུང་དང། །
ཚོར་དང་འདུ་ཤེས་ཉེ་བར་སྤྱོད་པ་ཅན། །
མགོ་མི་མཚུངས་ཞེས་ཡིད་གཉིས་བྱེད་གྱུར་ན། །
མཚུངས་པར་གྱུར་པའི་སྒྱུ་མ་ལ་སོགས་པ། །
དྲང་སྲོང་དག་ལ་བྷ་ལེ་བཅོལ་བ་འམ། །
བཟང་པོའི་སྒྱུ་མས་ཐུབ་ལ་གདུགས་ཚོད་བུལ། །
ཚོགས་གཉིས་རྫོགས་པ་སྒྱུ་མའི་སྣང་བ་ཡིས། །
བྱེ་བྲག་གྱུར་པ་མེད་དེ་མགོ་མཉམ་མོ། །
```

如果你心中怀疑说："你的幻象并不领受心、心所、受、想，而众生的五蕴却领受心、心所、受、想，所以二者头不相等。"［那么请看］相等的幻象等：或者把巴勒托付给仙人们，或者贤善幻士以幻术向能仁供养午斋；以幻的显现圆满二种资粮，并没有差别，头是相等的。

【按】"头不相等"（མགོ་མི་མཚུངས），是藏语的说法，意思是"两者不能相提并论"。帝洛巴预先回答幻师可能的疑问：幻象没有心识，众生有心识，怎能说众生如幻？

【按】"贤善幻士向能仁供养午斋"，指汉译《幻士仁贤经》（《大宝积经·授幻师跋陀罗记会》）的故事：幻师贤善（跋陀罗）以幻术作出饮食供佛，佛反以神力使其幻食化为真实，并为他授记。帝洛巴以此说明：幻的显现也能圆满资粮。

【按】存疑。"把巴勒（བྷ་ལེ）托付给仙人们"，所指的典故不明，今音译存疑。

## 九、五喻各有作用

```
སྨིག་རྒྱུ་དག་ཀྱང་ཉམས་ཀྱི་འདུ་འཕྲོ་ཡིས། །
ལམ་གྱི་བྱ་བ་བྱེད་ཀྱང་མགོ་མཉམ་མོ། །
རྨི་ལམ་དག་ལ་ལྷ་ཡིས་ལུང་བསྟན་ནས། །
མ་འོངས་དངོས་པོ་སྟོན་ཏེ་བྱེ་བྲག་མེད། །
གཟུགས་བརྙན་པྲ་ཡིས་སྔགས་ལས་གྲུབ་པ་ཡིས། །
ལྐོག་གྱུར་རྐུན་མོའི་གཟུགས་མཐོང་ཐ་དད་མེད། །
སྤྲུལ་པ་འགྲོ་བའི་དོན་དུ་རྒྱལ་བས་སྤྲུལ། །
བསྐལ་པར་གནས་ཏེ་མཛད་པ་སྒྲུབ་པ་ཡོད། །
ལོ་ཟླ་སྐད་ཅིག་སྣ་ཚོགས་སྣང་བ་ཡང། །
སྤྲུལ་པར་རྟོགས་ཏེ་བྱེ་བྲག་མཚུངས་པའོ། །
```

阳焰，以觉受的聚散，也能起到道的作用，头是相等的；梦中，天神授记，显示未来之事，没有差别；以咒语成就的影像占卜，能看见隐藏的盗贼的形像，没有不同；化身，是诸佛为利益众生而化现的，能住于劫中成办事业；年、月、刹那种种显现，也证悟为化现，差别是相同的。

【按】这一节说明：五种如幻之物，虽然不实，却都能起作用，这正好说明"如幻"不等于"无用"。"以咒语成就的影像"（གཟུགས་བརྙན་པྲ），指以咒语在镜中降神占卜的方法（梵 prasena），印度与西藏都有这种做法。

【按】存疑。"阳焰以觉受的聚散起道的作用"，所指不完全确定，可能是说修行中的种种觉受虽如阳焰，仍能助道。

## 十、渡河之后不需船

```
དེ་ལྟར་སྒྱུ་མ་འདྲ་བའི་དངོས་པོ་སྣ་ཚོགས་ཀུན། །
འབྱིན་དང་སྡུད་དང་འཕེལ་བར་བྱེད་པ་ཡིས། །
དེ་ལྟར་དེ་ལ་སྡིག་པས་ཡོངས་མི་གོས། །
བསོད་ནམས་དག་ཀྱང་དེ་བཞིན་ཤེས་པར་བྱ། །
གང་ལ་སྡིག་དང་བསོད་ནམས་གཉིས་མེད་པ། །
དེ་ལྟར་གྱུར་ལ་བྱང་ཆུབ་རབ་ཏུ་གསུངས། །
ཆུ་ཡིས་གནོད་ལ་གཟིངས་ཀྱིས་ཕན་པ་སྒྲུབ། །
ཆུ་མེད་གྱུར་ཚེ་གཟིངས་ཀྱིས་དགོས་པ་མེད། །
དེ་བཞིན་གནས་ངན་ལེན་གྱིས་གནོད་ཀྱི་བར། །
སྒྱུ་མར་ཤེས་པ་གང་ལ་ཡོད་པ་ཕན། །
གནས་ངན་ལེན་གྱི་གནོད་པ་བྲལ་བ་ན། །
བསོད་ནམས་སྒྱུ་མ་ལྟ་བུས་དགོས་པ་མེད། །
```

这样，对于一切如幻的种种事物，以生起、收摄、增长［的方式去对待］，那就不会被罪业所染；对于福德，也应同样了知。在罪与福二者都不存在之处，［佛］宣说那就是菩提。水造成伤害，船成办利益；没有水的时候，就不需要船了。同样，在还有粗重的伤害之时，有如幻之知的人就得到利益；离开了粗重的伤害时，就不需要如幻的福德了。

【按】"船筏之喻"出自佛经：渡河要靠船，到了彼岸就不必再背着船走。这里的意思是：还在轮回粗重之中时，要以如幻之知去修福德；到了离开粗重时，连"如幻的福德"也不必执著。这是就究竟而说，前提是"还有粗重时须要船"，所以绝不是说可以不修福德。

【按】"不被罪业所染"，是对已了知一切如幻、"罪与福二者都不存在"的证悟者而说，第八节以下都在说明如幻仍有作用、因果不虚，不能把这句话理解为可以造罪。"粗重"（གནས་ངན་ལེན），指烦恼习气使身心沉重不堪的状态。

## 十一、本来成佛

```
སེམས་ཅན་སངས་རྒྱས་རང་བཞིན་མཉམ་པ་སྟེ། །
ཆོས་རྣམས་ཐམས་ཅད་ངོ་བོ་ཉིད་ཀྱིས་སྟོང། །
རང་བཞིན་འོད་གསལ་གཟོད་ནས་འདུས་མ་བྱས། །
སྒྱུ་མས་གོས་མིན་ཡེ་ནས་སངས་རྒྱས་སོ། །
དེ་ལྟར་ཤེས་ནས་བདག་དང་དབྱེར་མེད་པ། །
ཕུང་སོགས་སྒྱུ་མ་ཙམ་དུ་སྣང་བ་ཡིས། །
དེ་བཞིན་གཤེགས་པར་ཤེས་པའི་བློ་ལྡན་ནི། །
ལམ་གྱི་མཆོག་ཏུ་རྒྱལ་བས་རབ་ཏུ་གསུངས། །
```

众生与佛自性平等，一切法的体性是空，自性光明，本来无为，不被幻所染，本来就已成佛。这样了知之后，［知道它］与自己无别，五蕴等只是显现为幻；具有了知它就是如来之智慧的人，诸佛宣说这是最殊胜的道。

## 十二、愿以如幻智慧利益众生

```
དེ་ལྟར་ཁྱོད་ཀྱི་བྱ་བའི་ཆོས་མཚོན་དཔེ། །
བདེན་པས་སྟོང་པའི་ཆོས་ཉིད་གང་ཡིན་དེ། །
ངེས་པའི་དོན་དུ་ཡང་དག་སྟོང་པར་རྟོགས། །
ཆོས་ཀྱི་དབྱིངས་ཡིན་རྣམ་པར་དག་པའི་ངང། །
འགྲོ་བ་སྒྱུ་མས་ལམ་ཡང་དེར་གཤེགས་ནས། །
ཡེ་ཤེས་སྒྱུ་མ་ལྟ་བུས་དོན་བྱེད་ཤོག། །
```

这样，你所作的事，是表示法性的比喻：那以真实为空的法性，在了义中证悟为真实空，就是法界清净的状态。众生以如幻之道也前往那里，愿以如幻的智慧利益［众生］！

## 跋语

```
རྣལ་འབྱོར་གྱི་དབང་ཕྱུག་ཏིལླི་པས་གྲོང་ཁྱེར་གྲགས་པ་སྐྱོང་དུ་སྒྱུ་མ་མཁན་ལ་གདམས་པ་དངོས་པོ་བསམ་གྱིས་མི་ཁྱབ་ཅེས་བྱ་བ་རྫོགས་སོ། །
ཨི་ཐི། །
ས་མ་པ་ཐ། །
```

瑜伽自在帝洛巴在护称城，为一位幻师所说的教言，名为《事物不思议》，圆满。如是。圆满。

【按】"ཨི་ཐི"是梵语 iti（如是），"ས་མ་པ་ཐ"应是梵语 samāpta（圆满）的藏文转写。

## 通篇连读

嗟！面容美好、精进的瑜伽士，听我说：善哉，善哉！你的作为很好。大乘之理、能仁的经教，诸佛都说［一切法］是如幻的。如果善于了知一切法如幻、如阳焰、如梦、如影像、如化现，就没有需要断除的烦恼；自解脱的智慧，就是能仁的密意。

你以小石子、木片等，熟习了结合的方法，以咒语施加时，男人、女人、马、象等种种影像就显现出来。最初，它们并不是从任何地方来的；显现的时候，因为是幻，没有任何真实的体相；收摄幻术时，它们灭去、不再显现，也没有去往任何地方；虽然收摄而不显现，刹那的相续并没有断绝。这样，显现与不显现，二者都没有体相；只要因缘近住，仅仅是显现，幻的体相就已圆满。

同样，所谓阳焰的体相：在有热气的地方，被太阳晒着，［热气］沿着斜坡流下，从远处看去，好像见到满满的河水。它的出现与显现的消失，显现与不显现没有分别，体相同一。

所谓梦：人入睡之后，在睡梦中梦见欢喜的园林、花园，种种受用；也会显现监牢、刑具等种种痛苦。在它生起、安住、消灭的时候，并没有成办任何其他实义的部分。

所谓影像：在清净的镜子中，显现出种种形色时，没有生灭等其他的安立，显现与不显现没有分别，体相同一。

所谓化现：由智慧等持或明咒成就之力所生，以花朵颜色差别的样子，显现出如来等等。

同样，外与内种种事物的显现，只要能取所取的分别，以习气之力近住，种种事物的显现就会生起。它们最初生起时，不是从任何地方来的；只是显现时，由于习气之力而显现；当能取所取二者的习气穷尽时，它们不再显现，也没有去往任何地方。

如果你心中怀疑说："你的幻象并不领受心、心所、受、想，而众生的五蕴却领受心、心所、受、想，所以二者头不相等。"［那么请看］相等的幻象等：或者把巴勒托付给仙人们，或者贤善幻士以幻术向能仁供养午斋；以幻的显现圆满二种资粮，并没有差别，头是相等的。

阳焰，以觉受的聚散，也能起到道的作用，头是相等的；梦中，天神授记，显示未来之事，没有差别；以咒语成就的影像占卜，能看见隐藏的盗贼的形像，没有不同；化身，是诸佛为利益众生而化现的，能住于劫中成办事业；年、月、刹那种种显现，也证悟为化现，差别是相同的。

这样，对于一切如幻的种种事物，以生起、收摄、增长［的方式去对待］，那就不会被罪业所染；对于福德，也应同样了知。在罪与福二者都不存在之处，［佛］宣说那就是菩提。水造成伤害，船成办利益；没有水的时候，就不需要船了。同样，在还有粗重的伤害之时，有如幻之知的人就得到利益；离开了粗重的伤害时，就不需要如幻的福德了。

众生与佛自性平等，一切法的体性是空，自性光明，本来无为，不被幻所染，本来就已成佛。这样了知之后，［知道它］与自己无别，五蕴等只是显现为幻；具有了知它就是如来之智慧的人，诸佛宣说这是最殊胜的道。

这样，你所作的事，是表示法性的比喻：那以真实为空的法性，在了义中证悟为真实空，就是法界清净的状态。众生以如幻之道也前往那里，愿以如幻的智慧利益［众生］！
