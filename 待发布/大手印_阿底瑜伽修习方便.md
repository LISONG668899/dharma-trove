# 阿底瑜伽修习方便

阿阇黎龙菩提造　据藏文译出

## 题解

本篇梵名 Atiyogabhāvanā，藏名 a ti rnal 'byor gyi sgom pa'i thabs，即《阿底瑜伽修习方便》，收于德格版丹珠尔续部释 ཟི 函第 35b 至 36a 页（东北目录 D2417）。跋语作《阿底瑜伽修习口诀》，说是"阿阇黎龙菩提所造"，没有记载译者。

龙菩提（Nāgabodhi），传为龙树（Nāgārjuna）的心传弟子，是《密集》圣派（Ārya 传承）的重要祖师，也列于八十四成就者之中。本篇所在的 ཟི 函这一段，是一大组印度成就者的短篇口诀。

关于"阿底瑜伽"一词，须特别说明：在宁玛派的九乘判教中，"阿底瑜伽"（Atiyoga）专指大圆满。但在印度的无上瑜伽续，尤其是龙菩提所属的《密集》圣派中，生起次第常分为"瑜伽、随瑜伽、极瑜伽、大瑜伽"四支，其中"极瑜伽"梵语正是 atiyoga，指以种子字、本尊观修为主的一个阶段。本篇的内容是八大尸林、劫火焚烧三界、烟出梵穴、月流滴下、观想怖畏怙主、观日月之间的微细吽字，基本上属于生起次第与拙火、明点一类的圆满次第修法，与宁玛派大圆满的立断、顿超不同。所以，本篇的"阿底瑜伽"很可能是印度密续意义上的"极瑜伽"，而不是宁玛派所说的大圆满。

不过，本篇中段也说"这是无二的，远离形状""怎样安住，就是那样""对无二的心而言，既不是常见，也不是断见"，由观想本尊转入对无二心性的认识，与大圆满的见地有相通之处。本站依通行的题名与"阿底瑜伽"之称，将本篇收入大圆满类目，供读者对照参看印度密续中"阿底瑜伽"一词的另一种用法。本站已译的《心宝之见》（D2431）中，"阿底"被列为外道诸宗之一，也说明"阿底"一词在印度文献中的用法不止一种。

全篇约三十句，分八节：八尸林与劫火；金刚蕊中日座上，虚空光明宣吽字；龟引出声、有兔者解结；观想俱生怖畏之主；一切皆是那位怙主；忆念自身即见真如，事物神变皆虚妄；阿底瑜伽无能所之知，如其安住，离常断二边；最后观修日月之间的微细吽字。

关于密乘内容的特别告诫：本篇几乎通篇是无上瑜伽续生起次第与圆满次第的象征语言，"劫火""梵穴""大海干涸""莲花炽燃""龟""有兔者解结""月流滴下"等，都是拙火、风息、明点修法的隐语，原文没有解释，本译的按语也只是一般性的推测。这类修法只能在具德上师座前，依具足的灌顶与口授领受；不如法地自行修习拙火、风息，容易造成身心的损伤。读者绝不可依文字自行揣测或练习。

体例：藏文原文全部保留在代码框中，按意义分节，每节后附汉译；凡标"存疑"的按语，表示本译对原文意思没有把握。藏文依 Esukhia 德格丹珠尔电子版。

## 一、八尸林与劫火

```
དུར་ཁྲོད་བརྒྱད་ལ་འཇིགས་བྱེད་བརྒྱད། །
དུས་མཐའི་མེ་འབར་ཁམས་གསུམ་བསྲེག། །
ཚངས་པའི་སྒོ་ནས་དུ་བ་འཐུལ། །
རྒྱ་མཚོ་བསྐམས་ཤིང་པདྨ་འབར། །
```

在八大尸林中，有八位怖畏者；末劫之火炽燃，焚烧三界；从梵穴中冒出烟来；大海干涸，莲花炽燃。

【按】这一段是观修的开端。"八大尸林"与"八位怖畏者"，是无上瑜伽续坛城外围的八大尸林及其中的护法，象征轮回中种种怖畏之处被转为修道之境。

【按】"末劫之火焚烧三界"、"从梵穴冒烟"、"大海干涸，莲花炽燃"，一般理解为圆满次第的隐语：脐下的拙火（末劫之火）燃起，焚尽三界（身中的分别与业风），热力上升至头顶的梵穴（顶轮）；"大海干涸"可能指风息的收摄，"莲花炽燃"可能指脐轮或密处的拙火。也可能与生起次第中观想世界焚尽、化为空性的步骤有关。所指不能完全确定，存疑。这些都只能依上师口授了知。

## 二、金刚蕊中，日座之上，虚空光明宣吽

```
རྡོ་རྗེ་ཟེ་འབྲུའི་དབུས་སུ་ནི། །
ཉི་མའི་གདན་སྟེང་གནས་པ་དེ། །
ནམ་མཁའི་འོད་ཆེན་ཧཱུཾ་ཉིད་སྒྲོགས། །
མཛེས་པའི་སེམས་ཉིད་རྒྱུ་བ་ཡིན། །
```

在金刚花蕊的中央，安住在日轮座上的那个［本尊］，以虚空的大光明，宣出"吽"字；那美妙的心性，［由此］流动。

【按】"金刚花蕊"（རྡོ་རྗེ་ཟེ་འབྲུ），在象征语中常指莲花或金刚的中心，也可能是事业手印的隐语；"日轮座"是本尊所坐的座垫。"吽"（ཧཱུྃ）是心与意金刚的种子字。

【按】存疑。"美妙的心性流动"（མཛེས་པའི་སེམས་ཉིད་རྒྱུ་བ），可能是说心与风一同运行，即"心乘风行"之意。

## 三、龟引出声，有兔者解结

```
རུས་སྦལ་འཐེན་ཅིང་སྒྲ་སྐད་འབྱུང། །
རི་བོང་ཅན་གྱིས་མདུད་པ་བཀྲོལ། །
```

龟牵引着，声音就生起；有兔者解开了结。

【按】存疑。这两句全是隐语。"有兔者"（རི་བོང་ཅན），是月亮的别名（印度传说月中有兔），在圆满次第中常指顶轮的白分明点，"解开了结"一般理解为明点融化下降，或脉结松解。"龟"所指不明，可能是某种风息、脉或身要的隐语。读者不可照字面揣测。

## 四、观想怙主

```
ཉམས་མྱོང་དཔའ་བོ་རང་རིག་རྒྱལ། །
ལྷན་ཅིག་སྐྱེས་པའི་འཇིགས་པའི་བདག། །
མགོན་པོ་ཉིད་ནི་བསམ་པར་གྱིས། །
```

体验的勇士，自明的胜者，俱生的怖畏之主——要观想那位怙主本身。

【按】"俱生的怖畏之主""怙主"，可能指嘿噜嘎一类的忿怒本尊，也可以理解为自明的觉性本身被观为本尊。这一节把本尊与"自明"（རང་རིག）等同，是由生起次第转入心性认识的关键。

## 五、一切皆是那怙主

```
དེ་ཉིད་སྙིང་རྗེའི་དཀྱིལ་འཁོར་འཕྲོ། །
དེ་ཉིད་དུར་ཁྲོད་མེ་ཡིན་ཏེ། །
དེ་ཉིད་སྨྲ་དང་ཟླ་རྒྱུན་འཛག། །
སྐྱེ་རྒ་ཤི་དང་ཁམས་གསུམ་གནས། །
```

从他放射出悲心的坛城；他就是尸林之火；他言说之时，月流滴下；生、老、死与三界，都安住于［他之中］。

【按】这一节说：本尊（即自明之心）就是一切——悲心坛城、尸林之火、月流（明点）、生老死与三界，都在其中。

【按】存疑。"他言说"（སྨྲ），本译依字面译出；也可能是某个讹写。

## 六、忆念自身，即见真如

```
རང་ཉིད་དྲན་ཏེ་དེ་ཉིད་མཐོང། །
འདི་ནི་གཉིས་མེད་དབྱིབས་དང་བྲལ། །
དངོས་པོའི་ཆོ་འཕྲུལ་རྫུན་པ་སྟེ། །
སེམས་ཉིད་འཁྲུལ་པས་མ་རྟོགས་སོ། །
```

忆念自身，就见到了那个［真如］。这是无二的，远离形状；事物的神变是虚妄的，由于迷乱，而没有证悟心性。

【按】这里由观想转入见地：所观的本尊、尸林、火焰、月流，都是"事物的神变"，是虚妄的；真正要认识的，是无二、无形的心性。

## 七、阿底瑜伽无所知

```
ཨ་ཏིའི་རྣལ་འབྱོར་རིག་པ་མེད། །
ཇི་ལྟར་བཞག་པ་དེ་ལྟར་ཡིན། །
གཉིས་མེད་སེམས་ལ་རྟག་ལྟ་དང། །
ཆད་པར་འགྱུར་བ་འང་མ་ཡིན་ནོ། །
```

阿底的瑜伽，没有［能所的］明知；怎样安住，就是那样。对无二的心而言，既不是常见，也不会落入断见。

【按】存疑。"ཨ་ཏིའི་རྣལ་འབྱོར་རིག་པ་མེད"，字面是"阿底的瑜伽没有明知"，本译补为"没有能所的明知"，意思可能是：在这一瑜伽中，没有一个能知去了知所知。也可能读作"阿底瑜伽是无与伦比的明知"，因为"རིག་པ་མེད"有时也作"无上之明"解。两解并存。

【按】"怎样安住，就是那样"（ཇི་ལྟར་བཞག་པ་དེ་ལྟར་ཡིན），即不加造作，任其本然。这一句与大圆满、大手印的"本然安住"相通。

## 八、观日月间微细吽字

```
དེ་ཕྱིར་ཉི་ཟླའི་དབུས་སུ་ནི། །
ཕྲ་བའི་ཧཱུཾ་ཉིད་བསྒོམ་པར་གྱིས། །
```

因此，要在日月的中央，观修微细的"吽"字。

【按】全篇以观修日月之间的微细吽字作结。在《密集》圣派的修法中，观修心间日月轮之间的微细种子字或明点，是摄心入中脉的重要方法。这一节明显是圆满次第的修法，具体做法须依灌顶与上师口授。
