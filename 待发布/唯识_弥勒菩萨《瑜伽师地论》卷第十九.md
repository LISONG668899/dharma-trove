# 弥勒菩萨《瑜伽师地论》卷第十九（思所成地）

弥勒菩萨说　唐三藏法师玄奘奉诏译

## 本地分中思所成地第十一之四

### 四、思择诸法（续）

【按】遁伦《瑜伽论记》说：第十四段“论议”共分二十七段，上卷已释五段，本卷释其余二十二段；卷末以一颂嗢拕南总结体义伽他十四段。

#### 建立体义伽他第十四段（论议）之六：四种善语颂

```
贤圣常说最善语
爱非不爱语第二
谛非不谛语第三
法非非法语第四
```

（大意：贤圣常说的是最善之语；第二是可爱而非不可爱之语；第三是真实而非不真实之语；第四是合法而非非法之语。）

现在这颂中所说的善语，就是善说、善言、善论。应当知道善说有三种相，就是悦意、无染、唯善。由第一种语，令他人庆悦；由第二种语，令自己的尸罗终无穿缺；由第三种语，能令他人出离不善之处，安住于善处，因此引摄利益安乐。

或有可爱之语，却不真实、不合法：就是如有一人，以美妙的言辞，称赞他人并不真实的功德。或有真实之语，却不可爱、不合法：就是如有一人，以染污之心，发出粗恶之言，诃责他人真实的过恶。或有合法之语，既可爱也真实：就是如有一人，善于了知称赞与诃责，知道什么可称赞、什么可诃责之后，却不称赞，也不诃责，唯以善巧方便为他宣说正法，能令那人出离不善之处，安住于善处。

【按】遁伦《瑜伽论记》引景师说：善说、善言、善论，体一而义异。基师说：善说是总句，后两种是别说，说其体名为善言，说其义名为善论。

再者，现在应当略辨上面所说的义理。就是薄伽梵在这里略显示一切善语，有标举，有解释。应当知道这就是这里的略义。

#### 建立体义伽他第十四段（论议）之七：趣天道颂

```
信惭戒施法　善人所称赞
是名趣天道　能往天世间
```

（大意：信、惭、戒、施、法，为善人所称赞；这名为趣向天界之道，能往生天上世间。）

这颂所说明的，是如有一人，对于佛所证的法毗奈耶获得正信；以居家为耻；受持清净之戒；得到衣服、饮食、卧具，便生欢喜知足，减少器物，节俭资缘；凡是获得的如法利养，终不私自隐藏，必定与有智慧的同梵行者共同受用；对于一切初、中、后善、称扬梵行的正法，就是契经乃至论议，都能受持、研寻、究达，传授给他人，广为开阐。

他既然成就这些善法，应当知道必定获得三种胜利：一是为诸佛、诸佛弟子、真实善人所称赞。二是如果他由尸罗与财施所摄引的福德资粮、由法施所摄引的智慧资粮善得圆满，便得以趣入证得解脱之处，就是清净诸天的众同分中。三是如果他的两种资粮尚未圆满，便能使之迅速圆满；身坏之后必定生于善趣，多往生天上快乐的世界中。

【按】遁伦《瑜伽论记》引景师说：由施所引的福智资粮，是欲界法，得生欲界天；也可以说，他由此辗转修习，生起静虑，发起无漏慧而圆满，因此后来生到五净居天，不出那天而证解脱，所以说“证解脱处”。基师说：无漏名为清净，圣者自在名为天。

又有另外的说法：就是如有一人，对于佛所证的法毗奈耶获得正信，相信恶尸罗者当堕恶趣，相信悭贪者得贫穷之报。这样相信之后，在现法中对恶戒与悭贪深生羞耻；由于羞耻，弃舍恶尸罗，受持清净之戒；弃舍悭贪，以无垢之心安处居家，广说乃至善行布施。由于这个因缘，在现法中为圣贤所赞叹；身坏之后，乃至当生善趣天上快乐的世界中。

再者，现在应当略辨上面所说的义理。就是薄伽梵在这里略显示在家、出家两种正行，以及正行之果的一切胜利。应当知道这就是这里的略义。

#### 建立体义伽他第十四段（论议）之八：多闻颂

```
多闻能知法　多闻能远恶
多闻舍无义　多闻得涅槃
```

（大意：多闻能了知正法，多闻能远离诸恶，多闻能舍弃无义，多闻能得涅槃。）

这颂所说明的，是如有一人，对于依先时所应作的施论、戒论、生天之论，这无倒的教法恭敬听闻；听了之后就能了知其义：就是现法中的种种恶行，以及将来恶趣之苦与无义之因的诸恶行处，应当迅速远离；以及往生善趣，舍弃生于恶趣之苦的无义之因。他由于了知这样的法义，法随法行，能远离苦因，能引生乐因；由于这个因缘，得乐舍苦。

【按】遁伦《瑜伽论记》说：诸不善业名为恶，外道无利的种种邪苦行名为无义之因，都要远舍。

如果对于与增上四圣谛等相应的教法恭敬听闻，听了之后就能了知其义，就是：一切有是生死大苦，涅槃是寂静。他由于了知这样的法义，如果根已成熟、资粮已满，便能获得这样的义识，由于心清净，刚一听闻法，对于诸圣谛尚未现观的，能入现观；已现观的，便得漏尽。如果根尚未成熟、资粮尚未圆满，就由这样远离诸恶，依增上戒生起增上心，依增上心发起增上慧，由此能舍弃一切苦的根本，就是烦恼这无义之法，证得涅槃。

再者，现在应当略辨上面所说的义理。就是薄伽梵在这里略显示：先听闻正法，然后如理思惟；先如理思惟，然后法随法行；以法随法行作为先因，得到胜利之果。应当知道这就是这里的略义。

#### 建立体义伽他第十四段（论议）之九：智者如空颂

```
智者如空无染污
不动犹如天帝幢
如泛清凉盈满池
不乐淤泥生死海
```

（大意：智者如虚空一样没有染污，不动犹如天帝之幢，如游泛于清凉盈满的池中，不乐于淤泥般的生死大海。）

现在这颂中，辩说阿罗汉苾刍心善解脱，超越诸戏论，犹如虚空。为什么？譬如虚空远离诸戏论，净与不净都不能染污它。诸阿罗汉也是这样，一切世间之法，或顺或违，都不能染污他，就是利、衰，乃至苦、乐。

又，诸有学已离欲贪，趣向阿罗汉，于四念住善住其心，修无相心三摩地时，如同天帝之幢，对于一切能动发的憍举、戏论营为、与受生之愿俱行的一切贪爱，都不能使他倾动。

又，诸有学已离欲贪，得不还果，对于上界的解脱心生欲乐，譬如游泛于清冷的泉池，对于爱味禅定、上分诸结这热淤泥，终不欣乐；由于在这里不欣乐，也不欣乐生死大海。

又有另外的说法：就是阿罗汉所有的饮食、言说、游行，处于无相而住，被有余依之苦所随逐，依其次第，应当知道配于三处。

又有另外的说法：就是慧解脱的诸阿罗汉、有学的身证者，以及俱解脱的诸阿罗汉，依其次第，应当知道配于三处。

【按】遁伦《瑜伽论记》说：慧解脱、有学身证、俱解脱依次配三处，是因为这三种人中，第一种烦恼障已尽而定障未尽，第二种定障已尽而烦恼障未尽，第三种二障都已远离。

再者，现在应当略辨上面所说的义理。就是薄伽梵在这里略显示：已离三界欲、于佛的圣旨尚有余依的无学，已离欲界之贪、属于胜进道所摄的趣向阿罗汉者，以及不还果。

又有另外的说法：就是略显示解脱的胜利、等持的胜利、智慧的胜利。又有另外的说法：就是略显示增上心学、增上慧学所得之果，以及显示增上心、慧二学。

#### 建立体义伽他第十四段（论议）之十：见如来法身五颂

```
若以色量我　以音声寻我
欲贪所执持　彼不能知我
若于内了知　于外不能见
由内果观察　彼音声所引
若于内无知　于外而能见
由外果观察　亦音声所引
若于内无知　于外不能见
彼普障愚夫　亦音声所引
若于内了知　于外亦能见
英雄出离慧　非音声所引
```

（大意：如果以色身来量度我，以音声来寻求我，被欲贪所执持，他就不能了知我。如果对内能了知，对外却不能见，由于以内在静虑之果来观察，他会被音声所引。如果对内无知，对外却能见，由于以外在业果来观察，也会被音声所引。如果对内无知，对外也不能见，那是被普遍障蔽的愚夫，也会被音声所引。如果对内能了知，对外也能见，这英雄的出离之慧，不被音声所引。）

【按】遁伦《瑜伽论记》说：这五颂中，前四颂是异生，后一颂是圣者，圣者完全见到佛的法身与化身，所以名为能见。异生中，第一颂是有欲贪邪分别的人；第二颂是以天眼见佛而不决定的人；第三颂是以肉眼见佛而不决定的人；第四颂是内外都有障蔽、什么都不能见的人。《金刚般若经》说：“诸以色见我，以音声寻我，彼生履邪断，不能当见我。”所说的就是这前四种异生。

这颂所说明的，是如有一人，身为异生，尚未断除虚妄分别的欲贪，看见世尊具足三十二大丈夫相，就测量说：“这位薄伽梵，必定是如来、应、正等觉，他所说的法必定微妙，他的弟子众所行必定良善。”他后来亲近不善之人，听闻不正之法，随逐他论以及他人的音声，信顺他人，被他人所引摄；由于被他人所引，对佛法僧反而生起毁谤。这都是由于不如实了知如来的法身，所以导致这样。

又有异生，由内在静虑之果的天眼通，远远看见世尊，便这样理解：“这位薄伽梵，必定是如来、应、正等觉。”其余如前所说。

又有人由外在欲界所系业的果报，就是肉眼，看见之后加以测量；应当知道他也是随逐他论以及他人的音声，信顺他人，被他人所引摄。

又有异生，对于那些所见都一无所有；他普遍被障蔽，长时被他人的音声所引。

如果是诸贤圣，已除断、调伏、超越欲贪，得到圣慧之眼；他由于这样的圣慧之眼，对内证解如来的法身。虽然对外看见如来的色身，或看见制多，或图画等，却能了知这不是第一义的应正等觉。他由于这样对内正知、对外正观，不随他论以及他人的音声，不信顺他人，不被他人所引，对佛法僧决定信受。这都是由于如实了知如来的法身，所以导致这样。

【按】遁伦《瑜伽论记》引泰师说：制多，此方翻为应供养处，旧译作“尸提”是讹略。光师说是积聚的意思。

再者，现在应当略辨上面所说的义理。就是薄伽梵在这里略显示：如果只以世俗来见如来，就不能决定；如果以胜义来见如来，就能决定。应当知道这就是这里的略义。

#### 建立体义伽他第十四段（论议）之十一：第六增上王颂

```
第六增上王　染时染自取
于无染不染　染者名愚夫
```

（大意：第六是增上之王，在染著之时，以染著执取为己有；对于无染的心而不随之染著，那就无染；随之染著的人，名为愚夫。）

现在这颂中，第六增上王，就是心、意、识。如果有人已渡过五种暴流，尚未渡过第六种意暴流，这时他的心随逐诸定的一切爱味，所以名为染时。又有补特伽罗，长夜以染著执取为己有，对于可爱之法执藏不舍，所以说他为染自取。贪名为染；由贪所生的未来世之苦，也名为染。

如果那染自取，对于所染之心不随之用功，而是摄受、遮止、修习意暴流的对治作意，这样那心在现法中就没有染污；在这无染之心上，这染自取在未来世中由之而有的诸苦，也就没有染。如果对那随之用功，而不摄受、也不遮止、不修习意暴流的对治作意，依这苦因，长夜受苦；对于这苦因不能远离，所以名为愚夫。

【按】遁伦《瑜伽论记》说：“染自取”是后念的染心，“所染心”是前念的定心。就是由后念的染心，对紧邻前念所染的定心，能不随顺而生爱染，发起功用摄受一处，令不流散，为了遮止染著而修第六意暴流的对治作意；这时能染的心现在也就没有能染相应之心，所染的心本性清净，名为无染心。论记又引《四分律》说：伊罗钵龙王向那罗陀说偈，问“何者王中上”等，那罗陀梵志以此偈问佛，佛以偈答“第六王为上，染者与染等，不染则无垢，染者谓之愚”等，与这一颂相似。

再者，现在应当略辨上面所说的义理。就是薄伽梵在这里略显示远离苦因的一切胜利，以及显示苦因能感得自己的苦，这是愚夫之性。应当知道这就是这里的略义。

#### 建立体义伽他第十四段（论议）之十二：骨城颂

```
有城骨为墉　筋肉而涂饰
其中有贪恚　慢覆所任持
```

（大意：有一座城以骨为墙，以筋肉涂饰；其中由贪、恚、慢、覆所任持。）

【按】“墉”字，宋、元、明、宫本作“墙”，下同。

现在这颂中所说的城，就是心、意、识。这城只以骨充当砖石，以筋代替绳索，以肉当作涂抹，作为形骸之墙周匝围绕。这城中被四种恶法所任持，它们违害善说法毗奈耶的一切善法：两种属于在家诸受用欲的人，就是贪与瞋；两种属于在恶说法毗奈耶中出家的人，就是慢与覆。

由于执著诸欲、悕求诸欲，与鄙秽之行不相违背，对于善说法以及毗奈耶尚且不信受，何况修善。依恃恶说之法而生憍慢，不能自己前往佛世尊或佛弟子那里；即使佛世尊或佛弟子由于悲愍，亲自前往他那里，他却由于覆这随烦恼之缠染污其心，尚且不如实发露自己的过失，何况能信解、修习诸善法。这样应当知道，这两种心城对于与善说法毗奈耶相应的善法都不能进入，何况能取为己有。

再者，现在应当略辨上面所说的义理。就是薄伽梵在这里略显示：在家、出家总由四种杂染因缘，失坏善说法毗奈耶。应当知道这就是这里的略义。

#### 建立体义伽他第十四段（论议）之十三：如龟藏支颂

```
如龟藏支于自㲉
苾刍善摄意寻思
无所依止不恼他
证般涅槃无所谤
```

（大意：如龟把肢体藏在自己的甲壳中，苾刍善于收摄意中的寻思；无所依止，不恼害他人，证得般涅槃，无所诽谤。）

这颂所说明的，是如有一人，依初静虑舍弃三种恶寻思，就是欲寻、恚寻、害寻；又能弃舍初静虑地的诸善寻思，安住于无寻无伺定中。如龟把肢体藏在自己的甲壳中，略为收摄寻思也是这样。无寻无伺定，应当知道是从此以上乃至有顶。

他在这定中正安住时，不生爱味；出定之后成就可爱乐之法，调顺柔和，容易共住，不恼害有智慧的同梵行者，又为有智慧的同梵行者欣乐共住；又成就无违诤之法。

他由于这样的正方便，对于诸圣谛能入现观，以及得到漏尽。他对于诸法不由他人而信，由于获得善净殊胜的智见，如实了知法真是法，毗奈耶真是毗奈耶。由于这样了知，终不依止诸见的颠倒。原文：“于法谤法，及于非法亦谤非法”（大意：不会对正法加以毁谤，也不会对非法颠倒评判。存疑。）终不把非法显示为法、把法显示为非法，把非毗奈耶显示为毗奈耶、或把毗奈耶显示为非毗奈耶。

再者，现在应当略辨上面所说的义理。就是薄伽梵在这里略显示善说法者断除四种扰乱的对治之道。什么名为四种扰乱？一是染与不染寻思的扰乱，二是对殊胜之定爱味的扰乱，三是相互违诤讼的扰乱，四是对正道诽谤的扰乱。应当知道这就是这里的略义。

【按】遁伦《瑜伽论记》说：第一种扰乱就是颂的前两句，第二、第三种就是第三句，第四种就是第四句。

#### 建立体义伽他第十四段（论议）之十四：等不等生颂

```
等不等而生　牟尼舍有行
内乐定差别　如俱舍卵生
```

（大意：有相等与不相等的生起，牟尼舍弃了有行；由内心的乐与定的差别，如同依茧、依卵而生。）

这颂所说明的，是佛示现住于最后有的菩萨位时，先前所获得的、以三十二大丈夫相与八十随好圆满庄严的妙色身之生，在后来证得阿耨多罗三藐三菩提时，那色身之生与先前正相等同；那名身之生，由于殊胜的无漏与先前不相似，与先前不相等同。

又佛示现以内寂静之乐以及沙门之乐为依止，得定自在；随着定心之力，舍弃诸寿行以及诸有行。他所舍弃的边际妙色身之生，与先前正相等同；那名身之生与先前不相等同，所以有差别。如同依其卵壳，卵生的鸡等依卵而生，生了之后渐渐增长，种类相似，破壳而出。如来色身与名身差别的道理，应当知道也是这样。

这里的差别，是佛世尊如果不舍弃诸寿行，应当满足寿量才般涅槃；由于被定力所持，舍弃了寿行，所以未满寿量而般涅槃。

【按】遁伦《瑜伽论记》说：俱舍，泰师说此方翻为茧，茧能生蚕，佛的名身从色身中出，如蚕从茧中出；基师说是卵壳藏的意思。论记又说：内寂静乐，是示现独处林野；沙门乐，是示现持戒无悔的善乐。寿行与有行，有行宽、寿行狭。关于舍寿，有两说：一说佛寿百年，八十岁时舍去第五分；一说佛寿一百二十年，八十岁时舍去第三分，依《大集经》，后一说为胜。

再者，现在应当略辨上面所说的义理。就是薄伽梵在这里略显示：舍弃诸寿行，色身与名身两种差别，以及显示弃舍的所依因缘。应当知道这就是这里的略义。

#### 建立体义伽他第十四段（论议）之十五：无淤泥等颂

```
无淤泥等欲　无魑魅等瞋
无罗网等痴　无江河等爱
```

（大意：没有如淤泥一般的欲，没有如魑魅一般的瞋，没有如罗网一般的痴，没有如江河一般的爱。）

这颂所说明的，是有四种能成为世俗的不自在之法，世间现见能令有情不得自在：一是陷溺在淤泥中，二是被鬼魅所附著，三是落入罗网，四是堕入湍急的河流，随流漂溺。又有四种能成为真实的不自在之法，能令有情不得自在，应当知道也是这样。哪四种？

就是如有一人，生长在欲界，陷溺在不净、腥臊、生臭的诸欲淤泥中，不能自在地引发、守护、增长善法。

又如有一人，弃舍诸欲，在善说法毗奈耶中得以出家；心怀忿怒，性多恶言；被忿所执持，不得自在；不数数学习学处，动辄违越；对于有智慧的同梵行者，屡屡以粗言击刺、诃斥摈逐、侵恼、毁辱。

又如有一人，弃舍诸欲，在恶说法毗奈耶中得以出家，进入诸恶魔的大痴之见网；他进入之后，流转生死，不得自在。

又如有一人，生长在上分的诸离欲地，对于诸爱结尚未能永断，也尚未遍知，不得自在，还生下界，顺流而住，难以出离。

再者，现在应当略辨上面所说的义理。就是薄伽梵在这里略显示诸界、诸品愚夫的缠缚。

又有另外的说法：就是如有一人，陷在欲的淤泥中，不能自在地在善说法毗奈耶中清净出家。又如有一人，本性忿怒，被忿怒所蔽，愤恚缠心，尚且对自身或害或损，何况对他人。又如有一人，成就痴品的诸恶邪见，就是认为没有父母，毁谤父母，对父母反而希望父母恭敬供养自己，何况自己能恭敬供养父母。又如有一人，广集诸欲，被贪爱所漂，不得自在，尚且不肯自己食用，何况能惠施给他人。这四种法，应当知道能障碍诸聪慧者的四种应知之法，就是：在善说法毗奈耶中清净出家，远离恚害，敬事父母，乐行惠施。

【按】遁伦《瑜伽论记》引景师说：长行两番解释，所说的法体相同，都是欲、恚、痴、爱；前一番就法体说，后一番就人的过失说。

#### 建立体义伽他第十四段（论议）之十六：虚空无鸟迹颂

```
虚空无鸟迹　外道无沙门
愚夫乐戏论　如来则无有
```

（大意：虚空中没有鸟的足迹，外道中没有沙门。愚夫乐于戏论，如来则没有。）

这颂所说明的，是有众生悕乐殊胜的欲，属于欲求所摄；又有众生悕乐殊胜的身，属于有求所摄；又有众生悕乐沙门以及婆罗门的解脱，属于梵行求所摄。

这里属于欲求、有求所摄的，是想：“我由于少分布施、少分持戒，当得往生善趣天上快乐的世界中，以美妙的五欲自我享纳，欢娱游戏。”他修习了这样的愿之后，得到最殊胜的欲以及最殊胜的身。譬如众鸟翱翔于虚空，遍虚空中没有安足之处；这样的众生，对于所得的无常诸欲以及身分中都无所安住，应当知道也是这样。

如果是乐于沙门以及婆罗门的解脱、属于梵行求所摄的，又有两种：或依于善说之法，或依于恶说之法。依于恶说之法的诸外道之辈，都没有沙门。依于善说之法而被邪梵行求所摄受的，也没有沙门。被正梵行求所摄受的，才有沙门。

又，这一切都属于三门所摄，或是欲求门，或是有求门，或是梵行求门，这样都名为乐著戏论。应当知道如来弃舍了一切所有的悕求，所以没有戏论。就以这道理，类推可知如来的诸弟子众中，被正梵行求所摄受的，也没有戏论。

再者，现在应当略辨上面所说的义理。就是薄伽梵在这里略显示：离开善说法以及毗奈耶而勤修精进的，都空而无益。应当知道这就是这里的略义。

#### 建立体义伽他第十四段（论议）之十七：牟尼游世颂

```
住戏论皆无　逾墙堑离爱
牟尼游世间　天人不能识
```

（大意：于住处、于戏论都没有爱，越过墙垣与壕堑而离于爱；这样的牟尼游行世间，天与人都不能识知他。）

【按】遁伦《瑜伽论记》说：这颂说四种离爱之相：一是于住处都无爱，二是于戏论都无爱，三是如越过墙垣而离爱，四是如越过壕堑而离爱。阿罗汉证得寂默之法，所以名为牟尼。魔怨主，就是贪爱。

这颂所说明的，是阿罗汉苾刍永离贪爱，由四种相，从恶魔怨敌这一切愚夫所系属之主那里解脱自在，随意游行于空闲之处与聚落。

有些愚夫，遇见这样的真阿罗汉，对于他最究竟的自在游行不能如实了知，便在两处妄生轻毁：“这善男子为什么弃舍属于自己、可以养命的珍财，反而去求属于他人的资生众具？为什么弃舍生天的方便，苦苦勤修精进，求取有的断灭？”这些愚夫见到生在天上有殊胜的功德，见到处在居家有很多财产，所以对牟尼妄生轻忽。他们所奉事的天，对于这位牟尼的广大功德尚且不能了知，何况奉事天的人能够识知。

怎样是离爱的诸阿罗汉由四种相，从恶魔怨敌这一切愚夫所系属之主那里解脱自在？

就是诸愚夫由于四识住，被魔怨之主所驱役，使他们在生死中往还五趣；阿罗汉则不是这样。

又诸愚夫如同由于重的过失，被魔怨之主所驱役，就是由于增益或损减的诸恶见，发起种种执持刀杖等恶不善法，堕入诸戏论，生于诸恶趣，使他们造作种种恶业之缘；阿罗汉则不是这样。

又诸愚夫如同由于中等的过失，被魔怨之主所驱役，使他们处在欲爱系缚的垣墙中，不能出离欲界受生之苦；阿罗汉则不是这样。

又诸愚夫如同由于轻的过失，被魔怨之主所驱役，使他们生于色界以及无色界，被无明的深堑周匝围绕，关闭在生死众苦的牢狱中，对于生等之苦不得出离；阿罗汉则不是这样。

再者，现在应当略辨上面所说的义理。就是薄伽梵在这里略显示：一切愚夫对于不应羞的生羞，对于应羞的不羞；对于不应怖畏的生起怖畏之见，对于应怖畏的生起无怖之见。应当知道这就是这里的略义。

【按】遁伦《瑜伽论记》说：求属于他人的资财，是不应羞的，却加以轻诮，这是羞不应羞；经营属于自己的资财、耽玩系缚，是应羞的却不羞。求有的断灭，是不应怖畏的，却诃毁勤修趣向，这是生起怖畏之见；生天纵乐，是应怖畏的，却赞叹希求，这是无怖之见。

#### 建立体义伽他第十四段（论议）之十八：熏除寻思颂

```
若有熏除诸寻思
于内无余离分别
超过碍著诸色想
四轭蠲除不往生
```

（大意：如果有人熏除诸寻思，于内心无余远离分别，超过喜乐的碍著以及诸色想，蠲除四轭，就不再往生下地。）

这颂所说明的，是如有一人，已入有学之位，尚未离欲界之欲。依初静虑，熏除欲界的诸恶寻思。依第二静虑，内等清净，心一趣性，初静虑地的一切分别无余永离，不再有分别。依第三静虑，超过第二静虑地的诸喜之碍著；依第四静虑，超过第三静虑地的诸乐之碍著。依无色定，超过一切色想。这样渐次依于诸定，乃至在有顶或入定、或受生，蠲除四轭。

哪四种？一是蠲除染污寻思之轭，二是蠲除不染污寻思之轭，三是蠲除喜乐系缚之轭，四是蠲除一切色想之轭。由于这个因缘，对于诸下地不再往生。应当知道异生虽然到达有顶，或入定、或受生，由于仍被四轭所系缚，对于诸下地还会再往生。

【按】遁伦《瑜伽论记》说：熏除，熏是熏修，除是除灭。

再者，现在应当略辨上面所说的义理。就是薄伽梵在这里略显示：到达有的边际的有学与异生两种差别。应当知道这就是这里的略义。


#### 建立体义伽他第十四段（论议）之十九：惠施福增颂

```
惠施令福增　防非灭怨害
修善舍诸恶　惑尽得涅槃
```

（大意：惠施使福德增长，防非能灭除怨害，修善而舍弃诸恶，惑尽而证得涅槃。）

这颂所说明的，是如有一人，对于佛所证的法毗奈耶获得正信，虽然处在居家，而心远离悭吝垢染的缠缚，受持七种有依的福业事。由于这个因缘，或行或住，广说如经，乃至生长这样的福德。

【按】遁伦《瑜伽论记》说：七种依福业事有三说，其中一说就是《俱舍论》所引契经所说的有依七福业事：一施羁旅客，二施路行人，三施有病人，四施侍病人，五施园林，六施常乞食，七随时施。

如果又能在善说法毗奈耶中清净出家，出家之后，具足忍力，为了守护尸罗，虽然遭到他人辱骂、侵恼、诃责，或以身手、瓦砾、刀杖殴击伤害，恐怕毁坏尸罗、成为障碍，心无恶念，口不出恶言，唯缘那境界，以与慈俱行之心，遍满一切方而住。由于这个因缘，在现法中，自他相续中的一切怨害都得以止息；当生于无恼害的快乐世界中，没有多少怨敌，为世人所欣仰，为众人所乐见。

这样善修正方便之后，依增上戒生起增上心，依增上心发起增上慧。当于圣谛入现观时，就能永远舍弃趣向恶趣之业以及诸恶趣。又由于修习如先前所得之道，渐次永除一切诸结，在有余依涅槃界中而般涅槃；这样到了后来，又在无余依涅槃界中般涅槃。

再者，现在应当略辨上面所说的义理。就是薄伽梵在这里略显示得到净信者的四种正行：一是感得财富之行；二是感得善趣之行；三是远离恶趣之苦的清净修行；四是远离一切苦的清净修行。应当知道这就是这里的略义。

#### 建立体义伽他第十四段（论议）之二十：诸恶莫作颂

```
诸恶者莫作　诸善者奉行
自调伏其心　是诸佛圣教
```

（大意：一切恶都不要作，一切善都要奉行，自己调伏其心，这是诸佛的圣教。）

这颂所说明的，是如有一人，对于佛所证的法毗奈耶获得正信，对于一切种、一切因缘、一切处所的所有恶行，都能断灭；在善说法毗奈耶中，能善受学尸罗律仪。

他由三种相奉行诸善：就是善住尸罗，守护别解脱清净律仪，乃至受学一切学处；依增上戒学发起增上心学；依增上心学发起增上慧学。他由于这样，对于所知的境界如实知见。

这样具足诸善法之后，又由三种相调伏自心：就是由于如实了知，能生起厌患；由于厌患，能得离染；由于离染，能得解脱。

【按】遁伦《瑜伽论记》说：一切种，景师、基师等说是十恶业道；一切因缘，是贪恚痴等；一切处所，是造业的对象，或有情、或非有情，以及资具等。

再者，现在应当略辨上面所说的义理。就是薄伽梵在这里略显示三学与学果，显示自己的圣教不与他人共同。应当知道这就是这里的略义。

【按】遁伦《瑜伽论记》说：三学，是前两句；学果，是第三句；不与他共，是第四句。

#### 建立体义伽他第十四段（论议）之二十一：调心颂

```
难调伏轻躁　沦坠于诸欲
善调伏其心　心调引安乐
```

（大意：心难以调伏，轻浮躁动，沉沦坠落于诸欲之中；善于调伏其心，心调伏了就引生安乐。）

这颂所说明的，是宣说心、意、识长夜爱乐愦闹杂乱之处，在愦闹之处难以远离，难以调伏。虽然勉强把它安置在无间修习诸善法之中，却不能一向安住于离贪、离瞋、离痴，也不能一向安住于策举、无掉、寂静；反而又迅速地重新生起有贪、有瞋、有痴，下劣、掉举以及不寂静。虽然勉强把它安置在内心的寂止之中，由于长夜爱乐色、声、香、味、触，对于五欲境界驰趣沉没。

诸圣弟子，对于这样乐著杂染、能生苦的心，终不放纵它使之自在流转，也不随顺它；数数思择，成办远离，恒常修习善法的心一境性。他由于这样正定之心，能如实了知；由于如实了知，能生起厌患；由于厌患，能得离染；由于离染，能得解脱。他既然这样善于调伏其心，尽除了苦因，在现法中得到安乐而住，未来的众苦也得以永尽。

再者，现在应当略辨上面所说的义理。就是薄伽梵在这里略显示：能不随顺长夜流转于左道的心，以及不随顺所得的胜利。应当知道这就是这里的略义。

【按】遁伦《瑜伽论记》说：左道，是乖离正道之理，指颂的前两句；不随左道之心，是第三句；所得胜利，是第四句。

#### 建立体义伽他第十四段（论议）之二十二：善知心相颂

```
于心相善知　能餐远离味
静虑常委念　受无染喜乐
```

（大意：对于心的诸相善于了知，就能品尝远离之味、静虑、常委、正念，受用无染的喜乐。）

这颂所说明的，是如有一位已见谛迹的有学，能善于了知止、举、舍之相。由于这个因缘，得到四种功德：

心住于一缘，远离粗重，能善受用身心的安乐，这是第一种功德。

又由于清净定心尽其所修、如其所修，能正确审虑诸法的道理，获得内法的毗钵舍那，这是第二种功德。

他由于以这样清净的止观为依止，对于所修习的菩提分法，勇猛无间，能恒常修习、能委细修习，没有懈怠、没有畏惮，这是第三种功德。

他由于这样没有懈怠畏惮之心，获得第一正念、正知，心善解脱，又能受用解脱的喜乐以及无染之乐，在现法中得到安乐而住，这是第四种功德。

【按】遁伦《瑜伽论记》说：四种功德，就是颂中的能餐远离味、静虑、常委念、受无染喜乐。惮，是畏惧怯怖。解脱喜乐是无为，无染喜乐是有为。

再者，现在应当略辨上面所说的义理。就是薄伽梵在这里略显示：对于诸相善巧的四种功德，就是奢摩他所作、毗钵舍那所作、无懈惮所作、到达究竟所作。应当知道这就是这里的略义。

#### 建立体义伽他第十四段（论议）之二十三：真苾刍颂

```
无工巧活轻自己
乐胜诸根尽解脱
无家无所无悕望
断欲独行真苾刍
```

（大意：不以工巧邪术活命，不轻贱自己，乐求殊胜，诸根清净，尽得解脱；无家可退，无所贮积，无所悕望，断欲，独行，这是真正的苾刍。）

这颂所说明的，是成就五支、永断五支，应当知道得名为真实的苾刍。

哪五支？就是不依止矫设方便的邪活命法，也不恃赖有势力之家，也不修治名称族望，也不诈受诸佛所说、圣弟子所说，犹如依止工巧处所那样，以非法悕求衣服饮食，这是第一支。

又减省器物众具，善于弃舍珍财，衣仅蔽身，食才充腹，知足欢喜；凡是游行，必定携持衣钵，这是第二支。

又悕慕沙门、爱乐沙门，悕慕学处、爱乐学处；即使遇到命难的因缘，尚且不违越所学的禁戒，何况为了少许利养的因缘，这是第三支。

又他这样正修方便，清净活命，欢喜知足，爱乐学处，对于诸圣谛尚未现观的，能入现观，得到清净之见；有时失念，暂时生起恶不善的寻思，引起贪欲、瞋恚、愚痴，只是迟缓忘念，就迅速又加以除遣，这是第四支。

又他修习如先前所得之道，对于诸结、缚、一切随眠、随烦恼、缠，心得解脱，这是第五支。

这名为成就五支。

怎样又名为永断五支？就是阿罗汉苾刍，对于五种处所不再会违犯，就是：不会舍弃所学之处而又退还；又不会有所贮积，执为己有而受用，也不受用诸欲境界；又不会为了财物、为了性命而明知故意妄语；又不会在弃舍诸欲之后，行不与取；也不会在永离贪欲、独住独行之后，又去习近非梵行之法，两两交会，或者计执苦乐是自己所作而招，或计执是他人所作、或自他共作、或非自作也非他作、不由因生而招苦乐。这名为五支永断。

【按】遁伦《瑜伽论记》说：颂的前两句是所成就的五支，后两句是所断的五支。五种所断依次是：无家，是终不舍戒退还俗网；无所，是无所贮积、不受财受境；无悕望，是不为财物性命明知而妄语；断欲，是不行不与取；独行，是贪欲已尽，无伴孤游，远离非梵行，妙达因果，不计执恶因、无因而招果。

#### 建立体义伽他第十四段（论议）之二十四：心远行颂

```
心远行独行　无身寐于窟
能调伏难伏　我说婆罗门
```

（大意：心远行、独行、无身、寐于窟中；能调伏这难以调伏的心，我说他是婆罗门。）

现在这颂中所说的心，也名为意，也名为识。

这心在过去一切愚夫身中，以无量差别的自体辗转、因辗转，虽然没有作者，却流转生死，前际不可得知，所以名为远行。

这心在现在一一而转，因为远离了第二个伴心，因为一切种类的心不会同时顿转，所以名为独行。

又这心在现在，随其自体初起现前时，或由贪性、或由瞋性、或由痴性、或由其余每一种烦恼与随烦恼之性，那自体并不毕竟相续而转。如五种色根，或同、或异、或劣、或胜，随其自体初起现前时，这自体就毕竟相续而转；心却不是这样。为什么？心经过那种种日夜、刹那、腊缚等时位，有不止一种的众多种种品类，各异的品类在其生时而生，在其灭时而灭。由于心的自性中染污之体并不成实，所以名为无身。

这心在未来世居于四识住而有随眠，在后生中可以有往来的意义，名为寐于窟中。

如果有聪慧的人，由这四种相，能对过去、现在、未来世的心如实了知，修习厌离、灭以及心解脱，他能超度诸萨迦耶，到达彼岸，安住于陆地，名为婆罗门。

【按】遁伦《瑜伽论记》说：这里的心通于八识。无量差别的自体辗转，是说以善、恶、无记三性等差别而转；因辗转，是说前前的心作为因，生起后后的心之自体。下文卷五十七说远行是由于前际无始、遍缘一切所知境界，那是偏就意识的作用说，这里通于一切识，并不相违。毕竟转，是始终相似相续的意思。五色根虽然起初暗劣、后来明胜，始终相似相续而生，名为毕竟转；心则三性品类各别，速谢而异类生灭，所以不毕竟转。又由于心性本净，它的染污之体不可得，所以说不成实，名为无身。远行说过去识，独行、无身说现在识，寐于窟说未来识。

再者，现在应当略辨上面所说的义理。就是薄伽梵在这里略显示：心在过去长时染污，没有作者之性；在现在世，其性是刹那，自性清净；在未来世，由于有放逸、不放逸，而有染污、清净。应当知道这就是这里的略义。

#### 建立体义伽他第十四段（论议）之二十五：阿氏多问十颂

```
谁能覆世间　谁能令不显
谁复能涂染　谁为大怖畏
无明复世间　放逸令不显
戏论能涂染　苦为大怖畏
诸流处处漏　是漏谁能止
当说谁防护　众流谁所偃
世间诸流漏　是漏念能止
我说能防护　由慧故能偃
念慧与名色　今问是一切
何当永灭尽　唯愿为我说
念慧与名色　我说是一切
若诸识永灭　于斯永灭尽
云何念所行　诸识当永灭
今请垂方便　为释令无疑
于内外诸受　都不生欣乐
如是念所行　诸识当永灭
若诸善说法　及有学异类
彼常委能趣　请大仙为说
不耽著诸欲　其心无浊染
于诸法巧念　是苾刍能趣
```

（大意：问：谁能覆蔽世间？谁能使之不显？谁又能涂染世间？什么是大怖畏？答：无明覆蔽世间，放逸使之不显，戏论能涂染，苦是大怖畏。问：诸流处处漏泄，这漏泄谁能止息？应说谁能防护，众流由谁来堵塞？答：世间诸流漏泄，这漏泄以念能止息；我说能防护，是由于慧能堵塞。问：念、慧与名色，现在所问的这一切，何时永远灭尽？唯愿为我宣说。答：念、慧与名色，我说这一切，若诸识永灭，就在那里永远灭尽。问：念怎样运行，诸识就当永灭？现在请垂示方便，为我解释，令我无疑。答：对于内外诸受都不生欣乐，念这样运行，诸识就当永灭。问：在善说法中，以及有学的各类人，他们恒常委细地能够趣向，请大仙为我宣说。答：不耽著诸欲，其心没有浊染，对于诸法善巧正念，这样的苾刍能够趣向。）

这是《波罗延经》中，由阿氏多所请问的颂。

【按】遁伦《瑜伽论记》说：波罗延，是经名，波罗名为彼岸，延是趣向的意思。阿氏多，此方翻为无胜；梵音迷底履，此方翻为慈氏，是他的族姓，名字叫阿氏多；旧译作“弥勒阿逸多”，都是讹略。这十颂中有五番问答，每两颂为一番，都是先问后答；长行只解释答颂，不解释问颂。

所说的世间，略有三种：一是欲世间，二是色世间，三是无色世间。现在这义理中，意在辨析出家、在家两种世间。出家世间又有两种：一是恶说法的，二是善说法的。恶说法的，被无明所覆蔽。善说法的，由于有明，应当可以显了；由于放逸，使之不能显了。至于诸在家的异类白衣，被诸戏论所涂染。

应当知道戏论略有三种：就是三种言事，名为戏论；对四种言说有所宣谈，也名为戏论；能发起语言的一切寻伺，也名为戏论。如果对于过去、未来、现在三种言事，依四种言说发起异类的分别思惟，或违或顺，这名为涂染。前面的戏论与后面的涂染，在诸在家人中大多可以见到，所以说他们被诸戏论所涂染。

【按】遁伦《瑜伽论记》说：三种言事，是三世之法；四种言说，是见、闻、觉、知。

这里，恶说法者被无明所覆蔽，善说法者由于放逸而不显了，诸在家者被戏论所涂染；他们在现法中苦因运转时，对于这苦因不能如实了知是苦因，对于这苦因爱乐而住。由于这个因缘，生起未来的苦，就说这苦名为大怖畏。

又，恶说法者，由无明之门，从六处之流漏泄众苦；诸在家者，由戏论之门，从六处之流漏泄众苦；善说法者，由放逸之门，从六处之流漏泄众苦。这样无明、放逸、戏论诸门的流漏，由于听闻他人的音声、内心正确作意，在诸行中了知过患；与此相应的念逆流而转，所以能够遮止。这样的方便，名为伏的对治。如果是出世间正见所摄的诸无漏慧，对于三种流都能堵塞。这样的方便，名为断的对治。对于这流漏，伏与永断两种对治都能断除，所以都名为防护。

又，恶说法者以及在家者，一向堕于染污品所摄。若在善说法毗奈耶中，两种都可以见到：诸放逸的人，堕于杂染品，不属于显了所摄；不放逸的人，堕于清净品，属于显了所摄。又，已经显了的与应当显了的，应当知道两种都没有放逸。

诸阿罗汉已经显了，对于不放逸，不再需要作不放逸之事；对于四念住，念与慧都已善修，已善证得清净之识，唯有决定。由于在无余依涅槃界中，善清净的识当永灭，念与慧也随之永灭；余依所摄、先业所引的一切名色，也随之灭尽。乃至那些法尚未永灭以来，对于六恒住常善安住；对于离欲地的一切内受，以及与诸欲相应的外受，不生欣乐。这名为诸阿罗汉的正念现行，乃至寿尽，识才永灭。

如果是诸有学，应当显了，对于不放逸，还需要作不放逸之事。他们的不放逸之事又有两种，就是常所作与委悉所作。所谓有学的各类，就是诸有学，极七返有，或家家、一来果等，以及在现法中堪般涅槃的人，对于下分结以及上分结心无染污；为了断除它们，修习对治。又由于对诸欲不耽著，诸下分结不能染污；由于心无浊，诸上分结不能染污。又对于一切有苦之法，如实了知其集乃至出离，于四念住善住其心，修习如先前所得的圣道，能趣向究竟。由于这样修习对治之道，他们在一切不放逸中，一切应作的不放逸之事，都得究竟。

再者，现在应当略辨上面所说的义理。就是薄伽梵在这里略显示：诸在家者以及在外道法中出家的人，决定是杂染的；以及显示在善说法毗奈耶中出家的人，如果行放逸，就堕于染污品，如果不放逸，就堕于清净品。应当知道这就是这里的略义。

#### 建立体义伽他第十四段（论议）之二十六：义品诸欲六颂

```
于诸欲悕求　或所期果遂
得已心定喜　至死而保爱
诸乐欲众生　若退失诸欲
其色便变坏　如毒箭所中
若远离诸欲　犹如毒蛇首
彼于爱世间　正念能超度
田事与金银　牛马珠环钏
女仆增诸欲　是人所耽乐
攀缘沈下劣　变坏生诸漏
从此集众苦　如船破水溢
若永绝诸欲　如断多罗顶
弃舍诸愁忧　犹莲华水滴
```

（大意：对于诸欲悕求，或者所期望的如愿以偿，得到之后心中决定欢喜，至死都保爱它。乐欲的众生，如果退失了诸欲，他的容色便会变坏，如被毒箭射中。如果远离诸欲，如避毒蛇之首，他对于贪爱的世间，以正念能够超度。田事与金银、牛、马、宝珠、环钏、女人、僮仆，增长诸欲，这是世人所耽乐的。攀缘而沉于下劣，变坏而生起诸漏，从此招集众苦，如船破而水满溢。如果永绝诸欲，如截断多罗树顶；弃舍一切愁忧，如莲花上的水滴不能停留。）

这是《义品》中依于诸欲的颂。

就是如有一人，悕求未来的一切诸欲；为了获得它们，发勤方便，得到之后现前耽著受用。这样悕求以及正在受用所得的诸欲，由于这个因缘，生喜生乐。这总名为诸欲的爱味。

又他所悕求以及正在受用的一切诸欲，对于所得、所受用之事如果退失时，随着对那些欲的恋著爱味，爱之箭入心，如中毒箭，受大忧苦，或致殒殁。这名为诸欲的过患。

又，毒蛇比喻诸欲境界；毒蛇之首，比喻诸欲中所有的爱味。诸愚夫爱味诸欲，贪著受用，如被蛇所螫。如果有多闻的诸圣弟子，远离诸欲的一切爱味，如避毒蛇之首，终不爱染而受用，广说乃至不生耽著；他对于诸色的一切贪爱，乃至对于触的一切贪爱，都能调伏、断灭、超度。这名为诸欲的出离。

又，诸欲的自性略有两种：一是事欲，二是烦恼欲。

事欲有两种：一是谷，它的所依处，就是田事；二是财，它的所依处，就是金银等事。为什么？求谷的人，必定要求田事；求财的人，必定要求金银等事。求金银等又有两种：一是事奉国王，二是商贾。求谷求田，方便需要牛；求财事奉国王，方便需要马；求财商贾的一切方便，与金银等共相应的，就是诸宝珠；与金银异类不相应的，就是环钏等。这是举最殊胜的来说，买卖、言说、事务，应当知道也是这样。积集了这样的财谷之事，受用戏乐的一切助伴，就是诸女色；如果尚未积集，在招集、守护以及生息获利中的一切助伴，就是诸僮仆。这样财谷积集广大，对这些处所耽乐不舍。这一切都名为事欲。

烦恼欲，就是对于事欲随逐爱味，依于耽著之识，生起种种虚妄分别之贪。

又对于事欲，由于烦恼欲使心沉没，成为下劣之性。如果那事欲变坏散失，便生起诸漏，愁叹忧悲种种苦恼缠绕其心。他由于这样在现法中被诸漏蔽伏而没有对治，犹如船破，水渐渐盈溢，招集未来的生老病等种种苦恼。

如果对于诸欲已得出离，便能永绝随欲爱味、发起贪著的诸染污之识，犹如截断多罗树顶，不再生长。又那事欲可爱、可乐乃至可意的，如果变坏时，在清净之识中，一切忧愁等苦恼都不能停留，如莲花叶上，水滴不著。

【按】遁伦《瑜伽论记》说：这六颂中，前三颂说明诸有学观察染著而远离，后三颂说明诸无学观察染著而永绝。宝珠等名为与金银共相应，是因为同在七宝之数，可以贵重，一切处所同样使用。

再者，现在应当略辨上面所说的义理。就是薄伽梵在这里略显示诸欲的爱味、过患、出离三种自性；又显示爱味能成为过患，以及那出离的一切功德。应当知道这就是这里的略义。

#### 建立体义伽他第十四段（论议）之二十七：造贤善颂

```
于过去无恋　不悕求未来
现在诸法中　处处遍观察
智者所增长　无夺亦无动
```

（大意：对过去无所留恋，不悕求未来，对现在诸法处处遍加观察；这是智者所增长的，不可劫夺，也不可动摇。）

这是造贤善颂。就是如有一人，对于佛所证的法毗奈耶获得净信，以正信之心弃舍家法，趣入非家，由五种相修行梵行，令其善得清净。

就是能舍离居家的种种所行，无所顾恋，也不缘念它们而心生追恋、又起染著，这是第一相。

又对于现法的利养恭敬、未来种类的一切所行，不生悕望；也不为了愿求未来人天的一切所行而修行梵行，这是第二相。

又对于现在五取蕴所摄的色等诸法以及它们的安立，能正确观察。又对于现法以及来世的诸身恶行以及恶的果报，思惟“我对于身不应发起任何恶行”，广说如经，乃至“应当断除身的诸恶行，修习身的善行”；语与意的善行，应当知道也是这样。又对于色等诸蕴，能随而观察过去、未来、现在世都是无常；由于无常所以是苦，由于是苦所以无我；由于无我，对于那一切不执为我所，乃至对于那些不执为我。这样如实以正慧观察，这是第三相。

又依于最初的法毗钵舍那，诸根成熟，福德与智慧两种资粮在未来世通达增长，不是诸国王等所能劫夺的，这是第四相。

又依于第二法毗钵舍那，在现法中涅槃的功德能善增长，不是诸烦恼以及随烦恼所能倾动的，这是第五相。

由这五种相修行梵行，令其善得清净。如果依这样修行一日一夜，也是贤善、第一贤善；应当知道它超过此外的一切梵行。

【按】遁伦《瑜伽论记》引泰师说：这颂说明造作贤善的五种观行，所以名为造贤善颂。色等诸法以及它们的安立，就是所诠与能诠。最初的法毗钵舍那与第二法毗钵舍那，是初学与成满两个分位。

再者，现在应当略辩上面所说的义理。就是薄伽梵在这里略显示：在善说法毗奈耶中所修的梵行，在一切相上都善得清净，不与他人共同。应当知道这就是这里的略义。

#### 建立体义伽他：总结嗢拕南

嗢拕南说：

```
恶说贪流怖　类与池流贪
作劬劳得义　论议十四种
```

（大意：恶、说、贪、流、怖、类、与、池、流、贪、作、劬劳、得义、论议，共十四种。）

【按】嗢拕南中第七段作“与”，遁伦《瑜伽论记》称为“举”，本译卷十八依论记作“举”。论记又说：体义伽他分三部分，这最末一颂是第三部分，以十四门总结上面所说；泰师说，从“诸行无常”以后所引的颂论辨体义，不再另立别法，所以说论议是第十四。

瑜伽师地论卷第十九

## 本卷要义

本卷是思所成地的最后一卷，解释体义伽他第十四段“论议”的其余二十二颂，并以嗢拕南总结十四段。至此思所成地终了。

这二十二段多是“略义”式的短论，每段先举一颂，再逐句解释，最后以“今当略辨上所说义”收摄要旨，形式整齐，而内容遍及戒、定、慧与在家、出家各方面。

几处值得特别留意：

“若以色量我，以音声寻我”五颂，遁伦《瑜伽论记》引《金刚般若经》“诸以色见我”一偈与之相当。论中把见佛者分为四种异生和一种圣者：以欲贪测量色相、以天眼远见、以肉眼测量、内外俱无所见，这四种都会随他人音声而退转；唯有得圣慧眼的人，对内证解如来法身，对外虽见色身、制多、图像，而知道那不是第一义的正等觉，所以对三宝决定信受。

“第六增上王”一颂，以意识为六识之王，说明已度五暴流的有学如何以对治作意遮止定中的爱味，与卷十七“越五暴流当度六”一段前后相通。

“等不等而生”一颂，以卵与鸡、茧与蚕为喻，说明佛的色身成道前后相等，而名身由于无漏而与前不等；并说明佛以定力舍寿行，所以未满寿量而般涅槃。

“心远行、独行、无身、寐于窟”一颂，是本卷对心性最集中的分析：过去无始流转而无作者，现在刹那一一而转，染污之体不成实，未来随眠居于识住。略义一句“于现在世性是刹那，自性清净”，与卷十六“其有染污者，毕竟性清净”遥相呼应。

阿氏多所问十颂，以无明、放逸、戏论分配外道、佛弟子、在家人三类，以念为伏对治、以无漏慧为断对治，最后说到阿罗汉识灭之时，念、慧与名色一同灭尽。

卷末“造贤善颂”，以五种相说明：如法修行梵行一日一夜，也胜过其余一切梵行。
