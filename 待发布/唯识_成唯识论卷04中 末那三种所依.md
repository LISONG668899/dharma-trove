一、第五至第七颂

前面已经说完初能变。外人质问：第二能变的相状是怎样的？世亲菩萨用颂回答：

```
次第二能变　是识名末那
依彼转缘彼　思量为性相
四烦恼常俱　谓我痴我见
并我慢我爱　及余触等俱
有覆无记摄　随所生所系
阿罗汉灭定　出世道无有
```

大意：第二能变称为末那识。末那识依阿赖耶识而生起，又以阿赖耶识为所缘，以恒审思量为自性和行相。末那识常与我痴、我见、我慢、我爱四种烦恼相应，也与触等心所相应。末那识的性质是有覆无记，生在哪一地就系属哪一地。在阿罗汉位、灭尽定中、出世道中，染污的末那识都不存在。

二、末那识的名义

论中解释：在初能变异熟识之后，应说明思量能变识的相状。思量能变识，圣教中另外称为“末那”，因为末那识恒常审察思量，胜过其余诸识。

外人质问：“末那”的名称，与第六意识有什么不同？

论主回答：“末那识”是持业释，如同“藏识”的名称，意思是“识就是意”。“意识”是依主释，如同“眼识”等，意思是“依意而生的识”，识与意不同。

【译注】持业释与依主释是梵语复合词的两种解法。持业释是同位关系：末那识，就是“作为意的识”，第七识本身就是意。依主释是从属关系：意识，就是“依于意根的识”，如同眼识是依于眼根的识。第六识所依的“意根”，正是第七末那识。

诸圣教恐怕第七识与第六识的名称混淆，所以对第七识只立“意”的名称。另一个原因：标出“意”的名称，是为了与“心”和“识”相区分，因为第七识积集和了别的作用都比其余诸识弱，只有思量最强。还有一个原因：为了显示第七识是第六意识最切近的所依，所以只称为“意”。

三、“依彼转”的两家解释

颂中“依彼转”，显示末那识的所依。“彼”就是前面所说的初能变识，因为圣教说末那识依于藏识。

关于末那识依于藏识的什么，有两家主张。

第一家，依《述记》为难陀论师的主张：末那识以藏识的种子为所依，不以藏识的现行为所依。因为末那识没有间断，不需要现行识作为俱有依才能生起。

第二家，依《述记》为护法论师的正义：末那识以藏识的种子和藏识的现行同时为所依。末那识没有间断，有转易，所以称为转识，必须依靠现行识作为俱有依，才能生起。

【译注】“有转易”指末那识在见道之后，由染污转为清净，状态会改变。凡是会改变的识，都要有一个同时存在的现行识作为依托。

“转”是流转的意思，显示末那识恒常依于藏识，取自己的所缘。

四、心与心所的三种所依

一切心王与心所都有所依，所依总共有三种。

第一是因缘依，就是自己的种子。一切有为法都依托因缘依，离开自己的因缘，必定不能生起。

第二是增上缘依，就是内六处。一切心王与心所都依托增上缘依，离开同时存在的根，必定不能运转。

第三是等无间缘依，就是前一刹那刚灭去的意。一切心王与心所都依托等无间缘依，离开开导根，必定不能生起。

只有心王与心所，具备三种所依，称为“有所依”，其余的法都不是。

【译注】三种所依可以如此记：种子依是“从哪里生”，俱有依是“靠什么同时撑着”，开导依是“前一念让出位置、引导后一念”。

五、种子依：种与现同时

先说种子依。

有一家说：种子要先灭了，现行的果才生起。理由是：《集论》说，没有种子之后，果才已生起；种子与芽等不同时存在。

另一家论师，即护法论师，破斥：“种灭果生”的理由不能作证。《集论》是依种子引生后念种子而说的；种子生芽等是外种，不是胜义；“种子灭了芽才生”并不是各家共许的；火焰与灯炷同时存在，互相为因。

种子自类相生，因果不同时；种子与现行互相生起，决定同时。所以《瑜伽师地论》说：无常法作为他性的因，也作为后念自性的因，种现互为因就是因缘的意义。“自性”显示种子自类前念作为后念的因，“他性”显示种子与现行互相为因。《摄大乘论》也说：藏识与染法互为因缘，如同芦苇束，同时存在。又说：种子与果必定同时俱有。

所以种子依决定不是前后相生的。即使有地方说种子与果前后相生，应知都是随顺他宗的方便说法。由此，八识及一切心所，决定各自另有种子作为所依。

六、俱有依：第一家“五根即种子”

再说俱有依。论中列出四家。

第一家说：眼等五识以意识为俱有依，因为五识现起时必定有意识。五识没有另外的眼等根作为俱有依，因为眼等五根就是五识的种子。《二十唯识论》的偈颂说：

```
识从自种生　似境相而转
为成内外处　佛说彼为十
```

大意：识从自己的种子生起，显现为似境的相而运转。为了成立内外十处，佛说识的种子与识的相为十处。

偈颂的意思是：世尊为了成立十二处，说五识的种子为眼等五根，说五识的相分为色等五境，所以眼等五根就是五识的种子。

《观所缘缘论》也说：

```
识上色功能　名五根应理
功能与境色　无始互为因
```

大意：识上能生色识的功能，称为五根，如此说合理。功能与境色，从无始以来互相为因。

偈颂的意思是：异熟识上能生起眼等色识的种子，称为色功能，说为五根，另外没有眼等根。种子与色识恒常互相为因，因为能熏与种子互相为因。

第七识和第八识没有另外的俱有依，因为第七、第八识恒常相续运转，自身的力量强。第六意识另有俱有依，因为第六意识要依托末那识才能生起。

七、俱有依：第二家的破斥与立义

第二家破斥：第一家的说法，与道理和圣教都相违。

如果五色根就是五识的种子，十八界的种子就应杂乱。十八界各自有种子，诸圣教处处如此说。

五识的种子，各有能生相分和见分的不同。你们执着哪一种为眼等根？如果是见分的种子，眼等根就应属于识蕴；如果是相分的种子，眼等根就应属于外处。见分种、相分种两种说法，都违背了圣教所说眼等五根都属于色蕴和内处。

如果五根就是五识的种子，五根就应是五识的因缘，不应说五根属于增上缘。

鼻根与舌根如果就是鼻识与舌识的种子，鼻根与舌根就应只系属欲界，或者鼻识与舌识也应通于色界。如果承认，就都与圣教相违。眼根、耳根、身根就是三识的种子，依二界五地来责难，道理也一样。

五识的种子既然通善与恶，五色根就应不只是无记。

五识的种子不属于有执受，五根就也应不是有执受。

五色根如果就是五识的种子，意识的种子就应是末那，因为第一家以五根作为意根的同类例证。

《瑜伽师地论》说眼等识都具备三种所依，五色根如果就是五识的种子，所依就只应有两种。

诸圣教都说眼等根通于现行和种子，执着眼等根只是种子，就与一切圣教相违。

有人为了避开前面所说的过失，附和第一家的执着，又转而辩解：异熟识中能感生五识的增上业种，称为五色根，不是作为因缘生起五识的种子。业种为根之说，就巧妙地符合两首偈颂，又善顺《瑜伽师地论》。

第二家破斥：业种为根的辩解只有空话，毫无实义。五色根就应不是无记；五色根就应不只是有执受、只属色蕴、只是内处；鼻根舌根就应只系属欲界；眼耳身三根就不应系属五地；感生意识的业就应是末那；眼等根就不应通于现行和种子；眼等根就应不是色根。

如果五识都是业所感，五识就应一向属于无记性。善等五识既然不是业所感，就应没有眼等根作为俱有依。所以业种为根的辩解不是好的辩解。

诸圣教处处说：阿赖耶识变现为似色根、根所依处、器世间等。你们怎能否定色根？承认眼等识变现为似色等，又不承认眼等根是藏识所变，如此迷谬，深深违背教理。

偈颂说种子功能称为五根，是为了破斥离识实有的色根，对识所变的似眼根等，因为似眼根有发生五识的作用，所以假名为种子和色功能，并不是说色根就是识的业种。

缘取五境的明了意识，应以五识作为俱有依，因为明了意识必定与五识同时俱起。明了意识如果不依于眼等识，眼等识也不应以明了意识为依，因为彼此相依的势力相等。

第七识没有间断，在见道等阶位有转易，所以应如同六识，有俱有依；否则，第七识就不属于转识，就违背了圣教所说的转识有七。所以应承认第七识有俱有依，就是现行的第八识。如《瑜伽师地论》说：有藏识，所以有末那；以末那为依，意识得以运转。论文的意思是：以现行的藏识为依止，才有末那，不是由藏识的种子。否则就应说：有藏识，所以意识得以运转。由此，第一家的说法与道理和圣教都相违。

第二家立义：前五转识，每一识决定有两种俱有依，就是五色根和同时的意识。第六转识决定恒常有一种俱有依，就是第七识；如果与五识同时生起，也以五识为俱有依。第七转识决定只有一种俱有依，就是第八识。只有第八识恒常没有转变，自己能够成立，所以没有俱有依。

八、俱有依：第三家“八识皆有俱有依”

第三家认为：第二家的说法还没有穷尽道理。

第八识与其余诸识同是识性，为什么不承认第八识有俱有依？第七识与第八识既然恒常同时运转，互相为依，有什么过失？承认现行的识以种子为依，识的种子也应承认以现行的识为依，因为能熏的识和异熟识，是识种子生起、增长、安住的依，识种子离开能熏的识和异熟识，就不能生起、增长、安住。

异熟识在有色界中，能执持身体，依色根而运转。如契经说：阿赖耶识被业风所吹，普遍依于诸根，恒常相续运转。《瑜伽师地论》也说：眼等六识各自依于不同的根，所以不能执受有色根身。异熟识如果不普遍依止有色诸根，就应如同六识，不能执受；或者，所立的理由就有不定的过失。

所以，藏识如果现起，决定有一种依，就是第七识；在有色界中，藏识也依色根。识的种子决定有一种依，就是异熟识；在最初熏习的阶位，识种子也依能熏的识。其余如前所说。

九、俱有依：护法正义

第四家，即护法论师，认为：前面各家的说法都不合道理，因为没有了解“所依”与“依”的区别。

“依”是指一切有生灭的法，依仗因、依托缘而得以生起、安住，一切所依仗、所依托的，都称为“依”，如同国王与臣子互相依存等。

“所依”是指：一种法，决定存在，能取境，作为主导，令心王与心所取自己的所缘，才是所依，就是内六处。其余的法不具备决定、有境、为主三个条件，所以不是所依。所依只如同国王，不如同臣子等。

【译注】护法论师给“所依”立了四个条件：决定、有境、为主、令心心所取自所缘。种子、色法、心所等，都可以是“依”，只有能取境而作主的根，才是“所依”。用论中自己的比喻：所依如王，依如王与臣的互相依靠。

所以诸圣教只说心王与心所称为“有所依”，色等法不是，因为色等法没有所缘。诸圣教只说心所以心为所依，不说心所作为心所的所依，因为心所不是主导。有些地方说依为所依，或说所依为依，都是随宜假说。

由此，五识的俱有所依决定有四种：五色根、第六识、第七识、第八识，缺少任何一种，五识必定不能运转。四种所依分别是同境依、分别依、染净依、根本依。圣教只说五识依于五根，因为五根是五识不共的所依，又必定与五识同缘一境，最为切近、最为相顺。

第六意识的俱有所依只有两种：第七识和第八识，缺少任何一种，第六意识必定不能运转。五识与第六识同时俱起，令第六识取境明了，五识不一定存在，所以不是第六识的所依。圣教只说第六识依于第七识，因为第七识是第六识的染净依，同属转识，最为切近、最为相顺。

第七意识的俱有所依只有一种，就是第八识，没有藏识，第七识决定不能运转。如偈颂说：

```
阿赖耶为依　故有末那转
依止心及意　余转识得生
```

大意：以阿赖耶识为依，所以有末那识运转；依止心（第八识）和意（第七识），其余的转识得以生起。

阿赖耶识的俱有所依也只有一种，就是第七识，没有第七识，阿赖耶识决定不能运转。论中说：藏识恒常与末那同时运转。又说：藏识恒常依于染污，染污就是末那。论中说三位没有末那，是依有覆的末那而说，如同说四位没有阿赖耶，并不是没有第八识。三位没有末那，也是同样的道理。阿赖耶识在有色界中也依于五根，五根不一定存在，所以不属于所依。

识的种子不能现前取自己的境，可以有“依”的意义，没有“所依”的意义。心所的所依，随着相应的识来说，再各加上自己相应的心王。

```
若作是说，妙符理教。
```

大意：依四家中护法之说，就巧妙地符合道理和圣教。

十、开导依：三家与护法正义

最后说开导依。论中列出三家。

第一家认为：五识自身和其他识前后不相续，必定由第六识引生，所以只以第六识为开导依。第六意识自身相续，也由五识引生，所以以前六识为开导依。第七识和第八识自身相续，不需要其他识引生，所以只以自类为开导依。

第二家认为：第一家的说法还没有穷究道理。前五识在未自在位，遇到不殊胜的境界，可以如第一家所说。在自在位，如诸佛等，对境自在，诸根互用，任运决定，不需要寻求，五识怎能不相续？

等流的五识，既然由决定心和染净作意的势力引生，专注于所缘，未能舍离之前，为什么不承认五识多念相续？所以《瑜伽师地论》说：决定心之后，才有染净心；染净心之后，才有等流的眼识，或善或不善地运转；等流的眼识不由自己的分别力，乃至意识不趋向其余的境，在等流的时段内，眼识与意识或善或染地相续运转。如同眼识，乃至身识，也是如此。论文的意思明显表示：在等流的时段内，眼识与意识同时相续运转。既然眼识生起时并非没有意识，所以眼识和意识不是互相交替相续生起。

如果殊胜强烈的境界相续现前，逼迫身心，不能暂时舍离，五识在道理上必定相续，如同热地狱、戏忘天等。所以《瑜伽师地论》说：如果六识作为六识的等无间缘，就施设为意根。如果五识前后决定只有意识，论中就应说“如果一识作为六识的等无间缘”，或者应说“如果六识作为一识的等无间缘”。论中既然不如此说，可知五识有相续的意义。

五识生起时，必定有意识，能引生后念的意识生起，何必以五识作为意识的开导依？无心、熟睡、闷绝等阶位，意识断了以后再生起时，藏识与末那既然恒常相续，也应作为意识的开导依。如果意识用前念自类作为开导，五识自类为什么不能以自类开导？五识不能，意识怎能？

与平等性智相应的末那识，最初生起必定由第六意识引生，也应以第六识为开导依。与大圆镜智同时的第八净识，最初必定由第六、第七识方便引生。异熟心依于染污意，或依于与悲愿相应的善心。既然如此，必定应承认第八识也以第六、第七识为开导依。由此，第一家的说法都没有穷究道理。

第二家立义：五识以前六识中任何一识为开导依。第六意识以前念自类，或第七、第八识为开导依。第七末那以前念自类，或第六识为开导依。阿陀那识以前念自类，以及第六、第七识为开导依。以上都不违背道理，理由如前所说。

第三家，即护法论师，认为：第二家的说法也不合道理。

开导依是指：一种有所缘的法，作为主导，能作为等无间缘，对后来生起的心王与心所，让开位置、引导生起，称为开导依。开导依只属于心王，不属于心所等。

如果甲识与乙识没有同时生起的可能，才可以说甲识对乙识有开导的力量。一身中的八识既然可以同时生起，怎能以异类的识作为开导依？如果承认异类识作为开导依，八识就应不能同时生起，就和其余部派“心不能并生”的主张相同了。

一身之中诸识同时生起，数目多少不定。如果诸识可以互相作为等无间缘，色法等也应如此，色法互作等无间缘，就违背了圣教所说“等无间缘只属于心王与心所”。

《摄大乘论》说色法也可以有等无间缘，是“纵夺”的说法：姑且纵容小乘所说色心前后有等无间缘，以夺去小乘所说色心前后的因缘义。否则“等”字就成了无用。

【译注】“等无间缘”的“等”，是“相等”的意思：前一念心与后一念心，数目和体量相等，才能一对一地让位引导。色法同时可以多少不定，不符合“等”的条件。

如果说“等”字不是遮遣数目多少，只是表示同类，就违背了你们所执的“异类识可以作为等无间缘”。

所以，八识各自只以自类作为开导依，深深契合教理，因为自类必定没有同时俱起的可能。心所的开导依，应随着所相应的识来说。

心王与心所是异类同时生起，互相相应，和合似一，决定同时生灭，作用必定相同，一个开导时，其余的也开导，所以心王与心所可以展转作为等无间缘。诸识之间不是如此，不应以心王心所为例。

一切心所不是开导依，因为心所对所引生的法没有主导的意义。

如果心王与心所的等无间缘各自只限于同类，第七、第八识初次转依时，相应的信等善心所，就缺少等无间缘，就违背了圣教所说“一切心王与心所都由四缘生起”。

无心、熟睡、闷绝等阶位，意识断了以后再生起时，开导依就是前念的自类意识。间断的五识，应知也是如此。没有自类的心在中间隔开，所以称为“无间”；前念意识先灭去时，已经为现在的识开导，何必以异类的识作为开导依？

圣教中说前六识互相引起，或第七、第八识依第六、第七识而生，都是依殊胜的增上缘而说，不是依等无间缘，所以并不相违。《瑜伽师地论》说：如果某识无间，诸识决定生起，就说某识是诸识的等无间缘。又说：六识作为六识的等无间缘，就施设为意根。两处论文都是言语总说、意义别指，也不相违。

```
故自类依深契教理。
```

大意：所以，八识各以自类为开导依，深深契合教理。

以上是附带的讨论，下面应回到正题。第二能变的末那识具备三种所依，颂中“依彼转”只显示前两种所依，即种子依和俱有依：为了显示末那识的所依与所缘相同，都是第八识；又因为前两种所依有殊胜的作用；或者因为开导依容易了解。
