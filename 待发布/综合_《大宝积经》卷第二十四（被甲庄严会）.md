# 《大宝积经》卷第二十四（被甲庄严会）

唐·三藏菩提流志 奉诏译

## 被甲庄严会第七之四

### 观空、无相、尽

“又，无边慧！诸菩萨摩诃萨这样观察一切法时，便对诸法得到法的光明：不在空中见空，也不离开空而见空，不见有少许法与空相应或不相应；不以空来空，不见空，也不见不空，也不以见来观一切法。

“作这样见时，不在无相中见无相，也不离开无相而见无相，也没有少许法与无相相应或不相应；不对无相以无相之见来见，不对有相以有相之见来见，既非有相之见，也非无相之见；无生、无作也是这样。

“不在尽中见尽，也不离开尽而见尽，不见有少许法与尽相应或不相应；也不对尽以尽之见来见，也不对尽以无尽之见来见，既非尽之见，也非无尽之见。

“诸菩萨摩诃萨作这样见时，没有少许法——无论可得见、不可得见，可显了、不可显了，可趣入、不可趣入，可觉知、不可觉知。无边慧！这就是菩萨摩诃萨安住于此道的大法光明。由于法的光明，见一切法都无有边际；对于边与中也无所执著；因为无所执著，所以在佛法中发心趣向。”

那时，世尊说偈道：

```
不于空见空，不异空见空，
能作如是见，说名为见空。
不住于少法，亦不见少法，
于彼空相应，及以不相应。
空以自性空，于空无所取，
以无所取故，能知一切法。
于见无所取，于观无所执，
能知见与观，此二俱不受。
于见悉清净，于观不可得，
如是观诸法，毕竟无所执。
不以无相见，不以无相观，
亦不于无相，而作无相观。
无相无所显，无愿不可得，
无有少法体，而可修习者。
不念于无相，亦不念无愿，
如是无分别，显了相无相。
不趣于无相，亦不入无相，
无趣无所入，显了平等住。
智人不见相，亦不见无相，
不见不思惟，一切无显了。
若人常思惟，无思无显了，
于思及显了，平等平等住。
```

（大意：不在空中见空，也不离空而见空，能作这样的见，名为见空。不住于少许法，也不见少许法，与那空相应或不相应。空以自性而空，对空无所取；因为无所取，所以能知一切法。对于见无所取，对于观无所执；能知见与观，这二者都不受取。对于见全都清净，对于观不可得；这样观察诸法，毕竟无所执著。不以无相去见，不以无相去观，也不对无相作无相之观。无相无所显现，无愿也不可得，没有少许法体可以修习。不念于无相，也不念于无愿；这样无分别，显了有相与无相。不趣向无相，也不入于无相；无趣也无所入，显了而平等安住。智人不见相，也不见无相，不见也不思惟，一切都无显了。若人常常思惟，而无所思、无所显了，对于思惟与显了，平等平等而住。）

```
如是于无相，无作亦复然，
虽显无所显，思惟了知故。
无生亦如是，曾无少法生，
自性无所有，显了而无体。
若生若无生，有作及无作，
亦无少所执，智者不分别。
念慧无所动，显了无思择，
有体及无体，平等离诸性。
不于尽见尽，亦不见无尽，
显了无所见，尽智无过上。
若尽若无尽，二俱不分别，
以无分别故，无念平等住。
于尽无尽见，亦无无尽见，
如是见尽时，不执尽无尽。
若于尽无尽，一切无所执，
以无所执故，尽智当显了。
尽智之境界，无畏之所得，
显了斯法故，菩萨善安住。
```

（大意：如对于无相，对于无作也是这样，虽然显了而无所显，因为思惟而了知的缘故。无生也是这样，从未有少许法生起，自性无所有，显了而无体。无论生与无生、有作与无作，也没有少许执著，智者不作分别。念与慧都无所动，显了而无所思择，有体与无体平等，远离诸性。不在尽中见尽，也不见无尽，显了而无所见，尽智无可超过。无论尽与无尽，二者都不分别；因为无分别，所以无念而平等安住。对于尽作无尽之见，也没有无尽之见；这样见尽时，不执著尽与无尽。若对于尽与无尽，一切都无所执；因为无所执，尽智当得显了。尽智的境界是无畏者所得，显了这法的缘故，菩萨善得安住。）

### 胜慧菩萨问法光明之行

那时，大众中又有一位菩萨摩诃萨名叫胜慧，从座而起，偏袒右肩，右膝着地，合掌向佛，说道：“世尊！诸菩萨摩诃萨为了摄取诸法之智而起修行，才能得到这大法光明。在法的光明中，没有少许可见；由于法的光明，了知一切法——有为、无为，世间、出世间，顺与逆，有戏论与无戏论。世尊！这法的光明，难道诸菩萨摩诃萨无须修行就能得到吗？”

【按】“无修行”，宋、元、明、宫本作“无所修行”。

那时，世尊告诉胜慧菩萨摩诃萨说：“胜慧！诸菩萨摩诃萨没有少许修行，没有胜修行，不随修行，不遍修行，（而）能得到无边的大法光明。诸菩萨摩诃萨尚且不可得、不可见，何况菩萨之行当可得、当可见呢？怎么会见到要经若干劫修行才能得到无边的大法光明？诸菩萨摩诃萨一切行止息，所行清净，就得到法的光明。法光明之行，不是数量之行，不是随相之行，从何处施设一切诸行？然而所修之行，不是施设之行，却也不离施设。胜慧！诸菩萨摩诃萨住于此行时，舍弃一切行而无所执取。具足此行的人，不是数量之行，不是随相之行，无相无行，才能得到这大法光明。”

【按】“一切行息”之“息”，元、明本作“慧”。“胜慧！诸菩萨”之“胜慧”，宋、元、宫本作“无边慧”。

那时，世尊说偈道：

```
菩萨无所行，而亦无有行，
得无有行者，无畏而发趣。
未曾有胜行，亦无有遍行，
无行无胜行，平等而发趣。
此行无示现，示无有诸相，
无相无行者，斯为行之相。
菩萨无相行，不住于诸事，
无行无所住，智者乃成就。
无行则无动，斯行为无上，
能行不动行，勇进而发趣。
菩萨不可得，行亦不可见，
亦不见色身，斯为善顺者。
无色无形相，故无一切行，
于见无所取，斯为无比行。
菩萨无上行，不堕于施设，
亦无有迁变，于中无所执。
行无施设故，乃为无上行，
若得如是行，获大法光明。
```

（大意：菩萨无所行，而也没有行；得到无有行的人，无畏而发趣。从未有胜行，也没有遍行；无行、无胜行，平等而发趣。此行没有示现，示现的是无有诸相；无相无行，这就是行的相。菩萨行无相之行，不住于诸事；无行也无所住，智者才能成就。无行就无动，此行为无上；能行不动之行，勇进而发趣。菩萨不可得，行也不可见，也不见色身，这是善于随顺的人。无色、无形相，所以无一切行；对于见无所取，这是无比之行。菩萨的无上之行，不堕于施设，也没有迁变，其中无所执著。因为行无施设，才是无上之行；若得到这样的行，就获得大法光明。）

【按】“示无有诸相”之“示”，宋、元、明、宫本作“亦”。“不堕于施设”之“堕”，宋、元、明本作“随”。

```
菩萨所修行，无言无劫量，
能以无量劫，显说于诸行。
菩萨行清净，清净妙安住，
悉舍一切行，曾无摄取者。
菩萨恒住舍，守护于诸行，
已舍一切行，于舍妙安住。
菩萨无边行，离边及无边，
彼行无所动，名为无上行。
菩萨无相行，斯行为无上，
修行此行时，超越诸魔界。
菩萨无相行，明了于无相，
若相及无相，一切无所依。
菩萨住此智，此行善成就，
无有少所行，说名不行者。
菩萨常清净，于行无所畏，
正念而发趣，斯为善安住。
```

（大意：菩萨所修之行，无言说也无劫数之量，却能以无量劫来显说诸行。菩萨之行清净，清净而妙善安住，舍弃一切行，从无摄取。菩萨恒常住于舍，守护诸行；已舍一切行，在舍中妙善安住。菩萨的无边之行，远离边与无边；那行无所动摇，名为无上之行。菩萨的无相之行，此行为无上；修行此行时，超越诸魔界。菩萨的无相之行，明了于无相；无论相与无相，一切都无所依。菩萨住于此智，此行善得成就；没有少许所行，名为不行的人。菩萨常时清净，对于行无所畏惧，正念而发趣，这是善安住。）

### 胜慧菩萨赞佛发愿

那时，胜慧菩萨摩诃萨又对佛说：“希有，世尊！诸善丈夫的种种修行竟这样甚深，诸愚夫以有相、有为所修行的人，很少能行。世尊！没有少许法入于这行中，所以这行是善丈夫的平等之行。世尊！善丈夫之行，不是诸数量边际所能测度的。”

【按】“是故此行”，《大正藏》作“是此故行”，CBETA 据高丽藏改正。

那时，胜慧菩萨摩诃萨就以偈颂赞叹如来说：

```
大雄正等觉，无上两足尊，
演说甚深行，饶益诸菩萨。
世尊妙辩才，其量颇难测，
无边辩才者，最胜大丈夫。
法王息讥论，斯由正遍知，
乃为诸菩萨，说此无上行。
世尊能演说，灭行之方便，
于行悉超过，智人当发趣。
大龙不思议，无边智境界，
遍知两足尊，善开斯妙行。
世尊所开示，牟尼不动行，
此行无能动，故名无比行。
大雄大牟尼，往昔所修行，
设以多劫行，无人能到者。
菩萨闻斯法，虽住于世间，
而于诸种智，不久亦当证。
```

（大意：大雄正等觉、无上两足尊，演说甚深之行，饶益诸菩萨。世尊的妙辩才，其量很难测度；您是无边辩才者，最胜的大丈夫。法王止息讥论，这是由于正遍知，才为诸菩萨宣说这无上之行。世尊能演说灭除诸行的方便，对于行全都超过，智人当发趣。大龙不可思议，具无边的智慧境界，遍知两足尊善开这妙行。世尊所开示的牟尼不动之行，此行无能动摇，所以名为无比之行。大雄大牟尼往昔所修之行，即使以多劫修行，也无人能够到达。菩萨听闻这法，虽住于世间，对于一切种智，不久也当证得。）

【按】“往昔所修行”之“往”，《大正藏》作“住”，CBETA 据高丽藏作“往”。

```
我等愍众生，当于末世中，
于此无上法，能为护持者。
我等闻斯法，当于末世中，
为诸众生故，能行亦能说。
我等以光明，当于末世中，
为诸求法者，而兴大利益。
我等发誓愿，当于末世中，
为诸众生故，护持而建立。
我等常思念，当于末世中，
供养佛法海，愿持无上法。
我等于法藏，当为胜丈夫，
愿持此法门，守护令久住。
我等于法水，誓愿悉能饮，
而于此法门，当为守护者。
我等闻法已，当于末世中，
愿为大丈夫，受持佛正法。
我等宁失命，不舍无上法，
愿于此法中，而为持法者。
我等持此法，未曾生喜足，
渴闻斯甚深，决定契经故。
我等于末世，为求诸法者，
当演斯正法，能令悉欢喜。
法王叵思议，能作大依怙，
愿垂加护我，念我持法者。
```

（大意：我们哀愍众生，当在末世之中，对这无上之法能作护持者。我们听闻这法，当在末世之中，为诸众生能行也能说。我们以光明，当在末世之中，为诸求法者兴大利益。我们发下誓愿，当在末世之中，为诸众生护持而建立此法。我们常常思念，当在末世之中，供养佛的法海，愿受持无上之法。我们对于法藏，当作殊胜的丈夫，愿受持此法门，守护令其久住。我们对于法水，誓愿都能饮下，而对此法门当作守护者。我们听闻法后，当在末世之中，愿作大丈夫，受持佛的正法。我们宁可丧失性命，也不舍无上之法，愿在此法中作持法者。我们受持此法，从未生起满足，渴望听闻这甚深决定的契经。我们在末世中，为诸求法的人演说这正法，能令他们都欢喜。法王不可思议，能作大依怙，愿垂加护于我，护念我这持法之人。）

【按】“叵思议”之“叵”，宋、宫本作“颇”。

### 世尊嘱胜慧末世持法

那时，世尊告诉胜慧菩萨摩诃萨说：“善哉，善哉！胜慧！你能在后来的末世之中，为了护持这些法而披大甲胄，也如往昔诸菩萨摩诃萨在最胜者所，供养承事，种诸善根，久修梵行，披大甲胄，护持诸佛世尊之法，没有差异。”

那时，世尊说偈道：

```
于后怖畏时，汝当持此法，
为利诸众生，以此法开示。
于后末世时，汝持最胜法，
若闻斯法者，悉当生爱乐。
于后末世时，汝为持法者，
我说甚深法，汝当悉受持。
秘密修多罗，汝闻当忆念，
于斯理趣中，勿复有疑惑。
决定甚深义，汝闻当忆念，
饶益诸众生，为持法藏者。
以法施一切，普润诸众生，
闻已令充悦，身心遍欢喜。
为诸菩萨道，所行之理趣，
及彼修多罗，究竟受持故。
汝当能广度，无量诸众生，
一切世间中，所不能度者。
汝持此法故，饶益诸世间，
获胜众福聚，以是而发趣。
```

（大意：在后来怖畏之时，你应当受持此法，为了利益诸众生，以此法开示。在后来末世之时，你受持最胜之法，若有人听闻此法，都当生起爱乐。在后来末世之时，你作为持法者，我所说的甚深之法，你应当全部受持。秘密的修多罗，你听闻后当忆念，对这理趣，不要再有疑惑。决定的甚深义理，你听闻后当忆念，饶益诸众生，作持法藏者。以法布施一切，普润诸众生，令他们听闻后充足喜悦，身心遍满欢喜。为了诸菩萨之道所行的理趣，以及那些修多罗，究竟受持的缘故，你当能广度无量众生，就是一切世间中所不能度的人。你因受持此法，饶益诸世间，获得殊胜的众多福聚，以此而发趣。）

【按】“为利诸众生”之“诸”，宋、元、明、宫本作“益”。“于后末世时，汝为持法者”之“时”，宋、元、明、宫本作“中”。

```
我今说此法，汝当悉受持，
于后末世中，为诸聪慧说。
现在未来世，能持斯法者，
则为能受持，千佛之正法。
为诸众生故，护持斯法门，
于后末世中，而兴大饶益。
若能于末世，护持斯法者，
彼不于一佛，亲近而承事。
若能于末世，护持斯法者，
彼已多承事，善说斯法者。
能于此法中，无有少疑惑，
末世护持法，斯为聪慧者。
被大无边甲，敌战为殊胜，
而于末世中，乃能持此法。
彼于佛正法，疑网悉已除，
闻法无所畏，乃能持此法。
```

（大意：我现在宣说此法，你应当全部受持，在后来的末世中，为诸聪慧的人宣说。现在与未来世中能受持此法的人，就是能受持千佛的正法。为了诸众生的缘故，护持此法门，在后来的末世中兴起大饶益。若能在末世护持此法的人，他不是只在一佛之所亲近承事；若能在末世护持此法的人，他已经多多承事过善说此法的诸佛。能对此法没有少许疑惑，在末世护持正法，这是聪慧的人。披上大无边之甲，与敌交战最为殊胜，才能在末世中受持此法。他对佛的正法，疑网都已除尽，听闻法而无所畏，才能受持此法。）

“所以，胜慧！若有善男子、善女人勤求最胜的大功德，在末世中，为了深法的缘故，应当披上甲胄，受持读诵，解说其义。

### 勇猛军王本生

#### 遍照如来与离垢国

“又，胜慧！我忆念往昔，超过无量劫，又加倍那么多劫，有佛出世，号为遍照如来、应供、正遍知、明行足、善逝、世间解、无上士、调御丈夫、天人师、佛、世尊。劫名超胜，国名离垢。那国土地平正广博，庄严清净，由七宝所成。

“那时那大洲纵横延袤七万由旬，其中又有六万座大城。每一座大城纵横正等十六由旬，城墙周匝，城楼雉堞庄严，城门与楼观殊胜，见者欢悦，美妙的多罗树成行围绕，有百千园苑共同庄严。诸园苑中，台座床敷处处严设，池沼渠流一一盈满，岸边台阶以众宝装饰，周围平整，出入安稳。在那岸边，沉水香、栴檀、多摩罗等杂香之树，枝叶扶疏，排列分布。那每一座城各有一万俱胝人民居住其中；那些众生都已成就十善业，所以一切都享受这样的安乐。

【按】“周回平正”之“正”，宋、元、明、宫本作“整”。“悉已成就”之“已”，《大正藏》作“己”，CBETA 校改作“已”。

“那时那如来，在从初劫起超过二百劫时出现，所以那劫名为超胜。在那劫中，有五百位如来次第出现，每一佛刹土都由七宝所成；每一佛灭度后，正法住世各一万年。这样五百位如来现化于世，多有声闻、菩萨的法会；每一法会各有俱胝那由他数的无量菩萨趣向一乘之道，获无生忍。

#### 勇猛军王厌欲求法

“那时那劫中有一位转轮王，名叫勇猛军，七宝成就，统王四天下。在阎浮提有一座大城，那城周围六十由旬，又有八万俱胝人民居住其中，安稳快乐，丰饶兴盛；有七重城壕、七重行树、七重街道、七重表刹、七重铃网，一千座园苑共同围绕庄严这大城。每一座园苑纵横正等二十由旬，其中各有七重垣墙、七重罗网，种种庄严，每一件微妙众宝珍玩都犹如诸天。各自又有一百个池沼，以毘琉璃宝作为堤岸，以马瑙杂玉作为台阶，众花盛开，宝树成行。

“在大城中，国王的正殿大七由旬，以黄金、青宝交错所成，周围以宝竿围绕，以琉璃装饰，摩尼珠网弥覆其上，诸多罗树辉映庄严。有二十个深池环绕萦带，池底铺满真金，覆以金网，以杂琉璃宝作为渡桥，以纯妙黄金作为阶道。在那池中，优钵罗花、拘勿头花、芬陀利花盛开遍满。

“那转轮王有二千婇女、六万诸子，与他的眷属在那园中享受五欲娱乐，私下这样想：‘诸欲无常，不久就会变坏，我应当决定志求佛法；若听闻佛法后如教修行，就能令我长夜利益安乐。’刚这样思惟，忽然有天人现于虚空中，告诉那国王说：‘善哉，丈夫！现在有遍照如来出现于世，演说正法，初善、中善、后善。大王应当迅速前往那佛所，当听闻正法，令大王长夜利益安乐，成就佛法，圆满佛法。’

#### 出家受持三时正法

“国王听到天人的话，踊跃欢喜，与他的眷属侍从围绕，就前往遍照如来之所，头面礼足，对佛说：‘世尊！以什么法能摄受诸法的善巧方便，能令梵行迅速圆满？我当修行。’这样问后，那时那如来为他广为开示。

“国王听法后，与他的眷属舍弃全部安乐资生之具，恭敬供养遍照如来及诸大众满二万年，在遍照如来的法中出家，修行正法。由于听闻佛法，那时获得受法的善根、持法的善根、说法的善根，凡所听闻的法，思惟而不忘，精勤修习无量功德，于是发誓愿：‘愿受持如来三时的正法，为诸众生种种宣说。’

“作了这愿之后，在超胜劫的诸如来所，一一亲近，供养承事；那些如来现前时的正法、中时的正法、后时的正法，都能受持；教化成熟四万八千俱胝那由他众生趣向阿耨多罗三藐三菩提，又以方便调伏无量众生安住于声闻、辟支佛乘。

#### 电光如来授记

“那劫中最后一位如来，号为电光。勇猛军比丘听闻电光如来说法时，获得无生忍。电光如来就为他授记：‘你勇猛军，在未来世供养无量千佛世尊，受持如来三时的正法，利益无量无数众生，安立百千俱胝那由他众生于阿耨多罗三藐三菩提，使无量众生安住于声闻乘。这样过阿僧祇劫，证得阿耨多罗三藐三菩提，号为无边精进光明功德超胜王如来。那佛刹土积集无量清净功德，安稳丰乐，人民充满，多有声闻及菩萨众。那佛寿命达五小劫，灭度后正法住世一小劫，法教流布，天人受持，舍利塔庙遍及诸刹土。’

#### 持此法的功德

“所以，胜慧！诸菩萨摩诃萨对这清净甚深之法，应当尊重受持修习，以法的庄严具庄严其身；由于法的庄严，证得如来金刚所成的大那罗延坚固之身。假使三千大千世界一切众生竭尽其身力，想要破坏这坚固之身，也没有能摧伏的。在一切世间的天、人、阿修罗众中，演说法的光明，也没有能与之论辩匹敌的。

“若有众生对这深法受持读诵、精勤修习，就随其意乐，生于清净的大族姓之家，乃至坐于菩提树下（成佛时），名称具足，世界殊妙，不杂有异道，连梵志、遮罗迦的名字尚且没有，何况有恶见邪求之辈。诸不善法也从未听闻，岂会有修习不善根的人。他能以足指放大光明，遍照无边一切世界；一切众生遇到这光明的，都得安乐，当证阿耨多罗三藐三菩提。所以，胜慧！若诸菩萨摩诃萨在我的法中勤修行，当获得这样殊胜的功德；我若具体宣说，不可穷尽。”

### 法界理趣善巧

#### 得法光明见法界

那时，世尊告诉无边慧菩萨摩诃萨说：“无边慧！若有住于这菩萨道的人，勤修这样清净甚深之法，与空相应，与寂静相应，就得到法的光明。以法的光明，见一切法的自性无异；因为自性无异，所见清净；因为见清净，就没有法见，也没有法离自性而见；法见清净，也没有清净，没有清净者，没有清净之时，能得到清净智的境界。

“见诸法界，非界、非非界；界见清净，远离诸界的种种性想；因为离性想，对于法界理趣的秘密言辞而能觉了，也能遍知诸法非界；因为见法界无差别、不可坏、不变异，便获得一切法界理趣的善巧方便。以善巧方便遍能了知法界的理趣，以等持之力，对于诸法界差别的理趣都能随顺而入。

#### 神通变化

“住于此行时，以一切法的善巧方便，对一切法无住无著；因为无所著，能对一切法界理趣随其所应作种种开示。由于等持之力，又能出生静虑、解脱、等持、等至，游戏神通，变一为多，变多为一，在山石墙壁中飞行自在而无罣碍。善巧能知四界和合而不住于界，知一切界与空界和合，对虚空界无著无系，因为有界和合的善巧之智。

“对一切界方便修习；由于修习，决了水界，能在水界中或令升起烟，或令发出火焰，或在其中烟焰同时炽盛，乃至无量种种变现，为诸众生作大饶益。由于能安住于法界理趣的善巧方便而无所动摇，随其意乐，随在哪个佛刹，都能在诸有之中转换胎藏之形，受化生之身，常见十方一切世界的诸佛如来；那些如来的这样名号、这样族姓、这样众会、这样说法，都能分别了知。”

#### 无边胜菩萨问无所住

那时，大众中又有一位菩萨摩诃萨名叫无边胜，上前对佛说：“世尊！诸菩萨摩诃萨住于什么法，能如佛所说得到这样最胜的功德？”

那时，世尊告诉无边胜菩萨摩诃萨说：“无边胜！诸菩萨摩诃萨对一切法无所住，如我所说，就能得到这样最胜的功德。无边胜！诸菩萨摩诃萨若住于色、受、想、行、识，若住于地界、水界、火界、风界、空界，若住于欲界、色界、无色界，我在这部经中就不说有这些功德。然而诸菩萨摩诃萨对一切法无所住，不入不出，所以我说他们当得无边的大功德海。

“为什么？诸菩萨摩诃萨没有少许法可得可住，也没有少许法或入或出，善能安住于诸法理趣而无所动摇。为什么？诸菩萨摩诃萨无住无动；因为无动，就无高无下；因为无高下，远离于高，不住于下；因为不住，名为善处而住。善处而住的人，住于无处；住于无处的人，不住于处。

“诸菩萨摩诃萨对少许法既不安立，也不积集，无处、无住，无起、无作。为什么？因为处不可得。因为无处，就无分别；因为无分别，不动处而住，如法界而住。没有处住，就没有住；对于处与无处都无所执著，名为善住。

“无边胜！诸菩萨摩诃萨安住于法理趣的人，这样安立，住于无住。以无住处而住，见一切法而无分别，住于这样的无分别之行。以这样的行，见一切法而无所动摇，就与如理而住相应，就与如理不动相应，就与如理不取相应。”

那时，世尊说偈道：

```
菩萨正忆念，于义善思惟，
不住诸法中，说名为智者。
未曾有少法，可为安立者，
以无安立故，无畏而发趣。
不立于诸色，亦不立诸受，
诸想及诸行，识等亦如是。
不住于诸蕴，诸界及诸处，
若处若非处，亦常无所住。
不住于地界，亦不住水界，
火界及风界，亦常无所住。
不住于欲界，色界无色界，
得无安立故，不住于三界。
及以虚空界，于彼无所住，
以无有所住，平等而发趣。
故无有少法，于中而可住，
若得无所住，斯为妙智者。
妙智无所住，无住为菩萨，
能得如是住，则住法界中。
无住相应故，彼常能善住，
无住无依止，于法得安住。
若得不依止，则常无所动，
不入亦不出，平等善安住。
于法如是住，斯为勇猛者，
一切法无高，一切法无下。
```

（大意：菩萨正确忆念，对义理善加思惟，不住于诸法之中，名为智者。从未有少许法可以安立，因为无安立，无畏而发趣。不安立于诸色，也不安立于诸受，诸想与诸行、识等也是这样。不住于诸蕴、诸界与诸处，无论处与非处，也常无所住。不住于地界，也不住于水界，火界与风界，也常无所住。不住于欲界、色界、无色界，因为得无安立，不住于三界。以及虚空界，对它也无所住；因为无所住，平等而发趣。所以没有少许法可以在其中安住；若得无所住，这是妙智者。妙智无所住，以无住为菩萨；能得这样的住，就住于法界之中。因为与无住相应，他常能善住，无住也无依止，在法中得以安住。若得不依止，就常无所动，不入也不出，平等而善安住。在法中这样安住，这是勇猛者；一切法无高，一切法无下。）

【按】“及以虚空界”之“以”，宋、元、明、宫本作“于”。“无住为菩萨”之“菩萨”，宋、元、明本作“善住”。

```
如是无所动，法界善安住，
安住不动故，便得无上住。
不住住相应，斯为勇猛者，
不住于住处，于处无所动。
成就无住处，而得善安住，
若处若非处，一切无所动。
住于不动处，乃名为不动，
若住不动处，一切无所住。
不念处非处，常住无分别，
不住于处故，则无有所动。
于处无所动，一切得无住，
若得不住处，处非处不动。
若于处不动，乃善住于处，
善住处安住，则住无所住，
能见一切法，住法相应住。
如是见诸法，种种无所住，
无住无安住，善巧于法住。
常住于诸法，而无有分别，
离诸分别故，斯为不动者。
若能住不动，于行无分别，
远离处非处，斯为观察者。
若能观不动，一切无所动，
诸法常平等，如是而发趣。
如理住相应，如理而不动，
得无动处者，常住于无处。
```

（大意：这样无所动摇，在法界中善安住；因为安住不动，便得无上之住。与不住之住相应，这是勇猛者；不住于住处，对于处无所动摇。成就无住处，而得善安住；无论处与非处，一切都无所动。住于不动之处，才名为不动；若住于不动之处，一切都无所住。不念处与非处，常住于无分别；因为不住于处，就没有所动。对于处无所动，一切得无住；若得不住于处，处与非处都不动。若对于处不动，才是善住于处；善住于处而安住，就是住于无所住，能见一切法，安住于与法相应之住。这样见诸法，种种都无所住；无住也无安住，善巧于法而住。常住于诸法而无有分别，因为离诸分别，这是不动者。若能住于不动，对于行无分别，远离处与非处，这是观察者。若能观察不动，一切都无所动，诸法常时平等，这样而发趣。与如理而住相应，如理而不动；得无动之处的人，常住于无处。）

【按】“一切得无住”之“住”，宋本作“作”。

#### 法界理趣善巧安立

那时，无边胜菩萨摩诃萨又对佛说：“希有，世尊！竟能将诸菩萨摩诃萨安立于法理趣之中，没有系缚，也没有解脱。世尊！诸菩萨摩诃萨在法理趣中善巧安立，不与少许法相应或不相应，和合或不和合，摄取或不摄取，有所归或无所归，贪或离贪，瞋或离瞋。

“世尊！诸菩萨摩诃萨在一切法的理趣之中善巧安立，即使有众生供养恭敬，也不生贪爱；即使毁辱逼恼，也不生瞋恚；没有种种之想，远离一切法。不见少许法能与少许法相应或不相应，因为超过相应与不相应；远离相应不相应之想，了知相应不相应之想；超过了知，不对少许法作或进或退、或有所趣或无所趣的相应。在一切法的理趣之中没有妄念，也无所取，以善巧方便不坏法性。世尊！诸菩萨摩诃萨对一切法这样安住时，能以善巧宣说一切法界的理趣，一切佛法迅速得以圆满。”

那时，世尊告诉无边慧菩萨摩诃萨说：“无边慧！诸菩萨摩诃萨在佛法中无所安立、无所住时，就见佛法没有安立，没有所住，也没有胜住，也没有遍住；见佛法之住不倾动、不流转、不变异，与一切法界相应而住，才名为一切法界理趣的善巧安立。

“无边慧！诸菩萨摩诃萨在佛法中，无住也无不住，无胜住也无遍住，无处住也无非处住，也无所动，也无分别，无胜分别，无遍分别，才名为一切法界理趣的善巧安立。

“无边慧！诸菩萨摩诃萨不见少许法能为少许法作安立，也不见有一切法的处所作殊胜安立，也无分别，无胜分别，无遍分别，才名为一切法界理趣的善巧安立。

“无边慧！诸菩萨摩诃萨不见少许法或住或去，也无分别，无胜分别，无遍分别，见一切法如清净虚空，光明显照，远离烦恼；因为对一切法光明照耀，才名为对一切法界理趣得善巧方便，不以安立来观法界。为什么？因为对法界不作少许安立。

#### 法界如虚空

“譬如虚空以及风界，没有处所，也无可见，无安立之处，无依止之处，无可示现；法界也是这样，无可入之处，无可见之处，无安立之处，无依止之处，也无了知，也无示现。诸菩萨摩诃萨因为无示现，与如如之界相应而住。

“无边慧！一切法界，无生、无命、无老、无死，无升、无沉，无示现之界，这就是法界；无变异之界，这就是法界；而法界遍于一切处。无边慧！法界无去，也无去处；因为无去处，才名为与法界相应而住。如如法界，其中无处，也无非处。为什么？因为如如法界、如如自性无所有的缘故。

“无边慧！诸菩萨摩诃萨听闻我这样宣说，就对一切法界理趣获得无边的大法光明；以法的光明得无生忍，迅速能圆满如来的十力、十八不共法以及一切佛法。为了成熟一切众生广大善根的殊胜资粮，为了如来种性不断绝，迅速前往道场转于法轮，映蔽诸魔宫，摧伏异论，作善丈夫的大师子吼，为诸众生演说妙法，随其乐欲，随其志愿，随其发趣正解脱，都令他们趣向阿耨多罗三藐三菩提。”

【按】“便获”，宋、元、明、宫本作“便获得”。

那时，世尊说偈道：

```
一切菩萨，不住诸法，
于佛法中，无所安立。
一切菩萨，无安立故，
于佛法中，无畏发趣。
一切菩萨，见诸佛法，
无住无处，妙善安立。
一切菩萨，不住于处，
能见诸法，无住无退。
一切菩萨，见法无住，
不动佛法，不求佛法。
一切菩萨，见法不异，
不动佛法，亦不推寻。
一切菩萨，见法如是，
于法善巧，方便而住。
一切菩萨，见常平等，
不住佛法，亦非不住，
常无住处，亦非无处，
常不分别，非不分别，
种种分别，常无所有。
一切菩萨，无住相应，
于诸时处，而无所动。
一切菩萨，于法理趣，
平等住时，名为善住。
一切菩萨，于法理趣，
不见少法，可平等住。
一切菩萨，能见诸法，
无有处所，亦不离处，
得无所动，亦无亲近。
```

（大意：一切菩萨不住于诸法，在佛法中无所安立；一切菩萨因为无安立，在佛法中无畏而发趣。一切菩萨见诸佛法，无住、无处，妙善安立。一切菩萨不住于处，能见诸法无住也无退。一切菩萨见法无住，不动摇佛法，也不求佛法。一切菩萨见法无异，不动摇佛法，也不推求。一切菩萨这样见法，对法善巧，以方便而住。一切菩萨见法常时平等，不住于佛法，也非不住；常无住处，也非无处；常不分别，也非不分别；种种分别，常无所有。一切菩萨与无住相应，在一切时处都无所动。一切菩萨对法的理趣平等而住时，名为善住。一切菩萨对法的理趣，不见有少许法可以平等而住。一切菩萨能见诸法没有处所，也不离处所，得无所动，也无亲近。）

```
一切菩萨，于一切法，
理趣善巧，方便安住，
住无所住，名为菩萨。
一切菩萨，不于少法，
若去若来，分别而住，
尔时乃住，诸法理趣。
一切菩萨，于法理趣，
种种安住，能起无边，
大法光明。以法光明，
住平等见，见一切法，
及法理趣，如净虚空，
如影如像，平等无垢。
一切菩萨，于见了知，
亦无了知，远离自性。
一切菩萨，如是观察，
于一切法，理趣而住，
能于法界，坚固勤修，
说名法界，理趣方便。
```

（大意：一切菩萨对一切法的理趣，以善巧方便安住，住于无所住，名为菩萨。一切菩萨不对少许法作或去或来的分别而住，那时才住于诸法的理趣。一切菩萨对法的理趣种种安住，能生起无边的大法光明；以法的光明住于平等之见，见一切法以及法的理趣，如清净虚空，如影如像，平等无垢。一切菩萨对于见有所了知，也无了知，远离自性。一切菩萨这样观察，对一切法的理趣而住，能在法界中坚固勤修，名为法界理趣方便。）

```
一切菩萨，不住法界，
观诸法界，毕竟非有。
一切菩萨，决了法界，
见一切法，如虚空风，
无有安立，遍一切处。
法界亦尔，遍一切处，
法界难思，无可示现。
于诸智者，不作亲近，
无示现界，乃为法界，
无有住处，名为住者。
法界无生，无命无老，
无死无沈，亦无出离。
法界难思，无来无去，
法界非蕴，非界非处，
亦不离处，而无所动。
法界如如，自性非有。
一切菩萨，如是了知，
法界难思，得法光明。
由是发趣，往诣道场，
而于佛法，无有疑惑，
不为所动，以法光明，
令诸众生，获大安乐。
```

（大意：一切菩萨不住于法界，观察诸法界毕竟非有。一切菩萨决了法界，见一切法如虚空与风，没有安立，遍于一切处；法界也是这样，遍于一切处。法界难以思议，无可示现；对于诸智者也不作亲近；无示现之界才是法界，没有住处，名为住者。法界无生、无命、无老、无死、无沉，也无出离。法界难以思议，无来无去；法界非蕴、非界、非处，也不离处，而无所动。法界如如，自性非有。一切菩萨这样了知法界难思，得到法的光明，由此发趣，前往道场，而对佛法没有疑惑，不为所动，以法的光明令诸众生获得大安乐。）

【按】“而于佛法”之“佛”，元、明本作“诸”。

“无边慧！诸菩萨摩诃萨能对这样甚深之法勤修行的人，才能得到这样的大法光明，以这智慧而发心趣向阿耨多罗三藐三菩提。”
