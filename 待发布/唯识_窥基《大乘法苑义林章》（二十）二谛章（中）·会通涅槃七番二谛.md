# 窥基《大乘法苑义林章》（二十）二谛章（中）·会通涅槃七番二谛

〔译注：本篇译第三门"相摄问答"的前半部分。窥基先完整引出《涅槃经》第十三卷关于二谛的经文，经中共有七番二谛；再介绍"古来解释"，即以立性、破性、破相、显实四宗分配七番的旧说；最后提出自己的会通：七番二谛都只是显实宗的二谛，与唯识论典所说的四重二谛没有差别。〕

## 第三门　相摄问答

分两部分：一是诸教相摄，二是问答分别。

## 一、《涅槃经》第十三卷的二谛经文

### （一）恒河岸边的树叶之喻

《涅槃经》第十三卷中，迦叶菩萨对佛说："从前佛有一次在恒河岸边的尸首林中，如来拿起树上的叶子，问诸比丘叶子的多少，乃至说：'我所没有说的法，就像林中的树叶那么多。'"

迦叶诘难说："如来所了知的无量诸法，如果都归入四谛，就是已经说了；如果不归入四谛，就应当有第五谛。"

佛称赞迦叶："是这样，诸法都已经摄在四圣谛中。"

迦叶又说："如果都在四谛中，如来为什么宣说'不说'？"

佛说："善男子，诸法归入四谛之中，仍然不称为已说。为什么？善男子，了知圣谛有两种智慧：一是中智，二是上智。中智是声闻、缘觉的智慧，上智是诸佛菩萨的智慧。

善男子，了知诸阴是苦，称为中智；分别诸阴有无量相，都是诸苦，不是二乘所能了知的，称为上智。这种上智，我在那部经中从来没有说过。处、界，以及色、受、想、行、识，这是苦谛；集谛、灭谛、道谛，也都说有中智和上智。

善男子，了知世谛的，称为中智，因为是总相了知；分别世谛有无量无边，不是二乘所能了知的，称为上智，因为是别相了知。了知一切行无常等，是第一义中的中智，因为总相了知三法印；了知第一义无量无边，不可称计，不是二乘所能了知的，称为上智。"

古来的解释说：这就是恒河沙数的万德，无量无边。

### （二）窥基对中智、上智的说明

上面这段经文，因为迦叶询问二谛的由来，世尊回答中显示每一种法都有上智和中智，用来说明二谛的差别。

"谛"是真实的意思。凡夫不能了知，只有圣者能证。凡夫的智慧能缘境，不能证得，称为下智。由于相对于凡夫的智慧，只说依中智、上智二智建立二谛。依实际来说，法有胜有劣，智有深有浅，只立二谛。现在相对于凡夫位的智慧，说中智和上智；证实的智慧只有两种。如果总相来说，二乘与上智相比较，就成为上和下，下摄在上之中。就像佛十力中的根上下智力，随其所应，下面经文会显示。

### （三）二谛不相离

文殊菩萨说："第一义中有没有世谛？世谛之中有没有第一义？如果有，就是一谛；如果没有，莫非佛说的是妄语吗？"

佛说："善男子，世谛就是第一义谛。"

这是说明二谛不相离的意义。

文殊说："世尊，如果这样，就没有二谛了。"

佛说："善男子，佛有善巧方便，随顺众生，说有二谛。善男子，如果随顺言说，就有两种：一是世间法，二是出世间法。善男子，出世间人所了知的，称为第一义谛；世间人所了知的，称为世谛。"

这是说明依人的智慧有浅深，显示二谛的差别。

### （四）七番二谛

第一番："善男子，五阴和合，称为某甲。凡夫众生随着这个称呼，称为世谛。了解五阴中没有某甲这个名字，离开五阴也没有某甲这个名字，出世间的人如其性相而能了知，称为第一义谛。"

第二番："再者，善男子，有的法有名有实，有的法有名无实。善男子，有名无实的，就是世谛；有名有实的，是第一义谛。"

第三番："善男子，如我、众生、寿命、知见、养育、丈夫、受者、作者、热时的阳焰、干闼婆城、龟毛、兔角、旋火之轮，以及诸阴、界、入，称为世谛；苦、集、灭、道，称为第一义谛。"

第四番："善男子，世间法有五种：一是名世，二是句世，三是缚世，四是法世，五是执着世。

1. 什么是名世？男女、瓶衣、车乘、屋舍，这些东西称为名世。
2. 什么是句世？四句一偈，这样的偈颂称为句世。
3. 什么是缚世？卷合、系结、束缚、合掌，称为缚世。
4. 什么是法世？如鸣钟集合僧众，击鼓操练士兵，吹螺报知时刻，称为法世。
5. 什么是执着世？如远远望见有人穿着染色的衣服，就生起想法执着说'这是沙门，不是婆罗门'；看见有人身上横佩着结绳，就生起念头说'这是婆罗门，不是沙门'。这称为执着世。

善男子，这称为五种世间法。善男子，如果有众生对这五种世间法，心中没有颠倒，如实了知，称为第一义谛。"

第五番："再者，善男子，若烧、若割、若死、若坏，称为世谛；无烧、无割、无死、无坏，称为第一义谛。"

第六番："再者，善男子，有八苦相，称为世谛；无生、无老、无病、无死、无爱别离、无怨憎会、无求不得、无五盛阴，称为第一义谛。"

第七番："再者，善男子，比如一个人有很多技能：奔走的时候称为走者；收割的时候称为刈者；做饮食的时候称为作食者；整治林木的时候称为工匠；锻打金银的时候称为金银师。像这样一个人有很多名字。法也是这样，实际是一，而有很多名称。依父母和合而生，称为世谛；十二因缘和合而生，称为第一义谛。"

## 二、古来的解释：四宗分配七番

古来的解释说：从"五阴和合"以来，后面的七番，就法来辨明相状。其中粗分有两种：一是大乘，二是小乘。细分有四宗：

1. 立性宗：就是小乘中浅显地说诸法各有体性，如萨婆多部等。
2. 破性宗：就是小乘中深入地说诸法假有、没有体性，如《成实论》等。
3. 破相宗：就是大乘中浅显地破除诸法因缘的相状，宣说诸法毕竟空寂，如《中论》《百论》等。
4. 显实宗：就是大乘中深入地说妄情所取的诸法毕竟非有，真实法界常住不坏，如《涅槃经》等。

这四宗中都有二谛。上面七番中：

1. 前三番，是立性宗中所辨的二谛。
2. 其次两番，是破性宗中所辨的二谛。
3. 再其次一番，是破相宗中所辨的二谛。
4. 最后一番，是显实宗中所辨的二谛。

这段经文以深摄浅，所以完备地论述。

### （一）立性宗的二谛

就第一宗来说，依照《大毗婆沙论》等，详细说有七番，不能繁引：

1. 情理分别：妄情所取的我、众生等，作为世谛；无我之理，作为第一义。
2. 假实分别：瓶、衣、车乘、舍宅、军队、树林，这一切假名的有，称为世谛；阴、界、入等实法的有，作为第一义。所以《杂阿毗昙心论》说："如果分析法的时候，舍去名言，就说是世俗等；分析而无所舍去的，说为第一义。"
3. 理事分别：阴、界、入等事，称为世谛；十六行相的法相道理，作为第一义。
4. 缚解分别：苦、集是世谛，灭、道是第一义。
5. 劣胜分别：苦、集以及道谛，在道理上不是最上的，同称为世谛；灭谛精妙殊胜，说为第一义。
6. 空有分别：四谛十六行相中，除去空、无我，都称为世谛；空和无我在道理上精妙，说为第一义。
7. 行教分别：教法称为世谛，修行称为第一义。所以《杂阿毗昙心论》说："经、律、阿毗昙，称为世俗正法；三十七觉品，称为第一义。"

这段经文中只彰显前三门，其余的略去不辨。

1. 就情理来分二谛："五阴和合，称为某甲"，凡夫随着这个称呼，计执有我、有人，称为世谛；圣人了解阴中没有某甲，离开阴也没有某甲，称为第一义。
2. 就假实来分二谛：先分两种法。有名有实，是实法，阴、界、入等依名称推求法，有体性可得，所以说有实。有名无实，是假法，瓶、衣、车乘、舍宅、军众，这一切都是假立施设的名称，推求起来没有体性，所以说无实。下面就谛来辨：假法是世谛，实法是第一义。
3. 就理事来分二谛：事是世谛，理是第一义。事有假有实：如我、众生，乃至兔角、旋火轮等，是假的事；诸阴、界、入，是实的事。这一切同称为世谛。苦、集、灭、道的法相道理，作为第一义。

### （二）破性宗的二谛

其次，就破性宗来辨二谛，有两门：前一门就假法的空有来辨二谛，后一门就实法的空有来辨二谛。

1. 前一门中，先说明世谛：世间法有五种。之后说"对这五种法心中没有颠倒，称为第一义"，是因为了知这五种法性空，也不执为实性，称为没有颠倒。
2. 后一门中，"若烧、割等，称为世谛"，是说五阴诸法同称为世谛；"无烧、割等，称为第一义"，是说诸法性空，称为第一义。

### （三）破相宗的二谛

其次，就破相宗来辨二谛：八苦的相状作为世谛，没有八苦的相状作为第一义。

问：破相宗所辨的二谛，与前面破性宗有什么差别？

古来的解释说：破性宗说因缘假有作为世谛，破相宗宣说妄相之有作为世谛；破性宗宣说无性之空作为第一义，破相宗宣说无相之空作为第一义。差别就在这里。

### （四）显实宗的二谛

其次，就第四显实宗来辨二谛：事相的缘起作为世谛，法性的缘起称为第一义。先说譬喻，后作合法。

譬喻是怎样的？比如一个人随着作用分成多种名称：奔走的时候称为走者，收割的时候称为收刈者。合法来说：父母所生的一边称为世谛，因缘所生的一边称为第一义。

古来的解释说：因缘所生共有六重：

1. 事因缘所生，如毗昙所说。
2. 法因缘所生，只是苦、无常、生灭等法数。
3. 假因缘所生，如《成实论》所说。
4. 妄相因缘所生，犹如幻化。
5. 妄想因缘所生，如梦中所见。
6. 真实因缘所生，就是佛性的十二因缘，如水起波浪。

前五种缘生都是世谛，现在依据第六种，所以称为第一义。

〔译注：以四宗判摄《涅槃经》七番二谛，一般认为出自隋代净影寺慧远《大乘义章·二谛义》一系的地论师旧说，窥基这里称为"古来解云"。〕

## 三、窥基的会通

上面的解释精细，现在的解释稍有不同。这里的二谛，只说明显实宗中的二谛，不说小乘以及破相宗的二谛，因为显实宗自身就有破相。小乘诸部的计执有二十部之多，佛难道会预先悬说大唐所传的这些部派？所以不会宣说两种小乘宗所有的二谛。

由此应当说：

### （一）第一番：依人立二谛

后面七番中，第一番举出事例，解释前面依人立二谛。经中说"凡夫众生随着这个称呼，称为世谛；出世间的人如其性相而能了知，称为第一义"，所以可知只是重新显示前面的意义，让人知道二谛依人相待也可以建立。

以下六番，依法的胜劣相对来建立。经中没有分明地作差别分别，以义理推究，就是这里的四重二谛。

### （二）第二番：有名无实与有名有实

第二番中，"有名无实是世俗"，就是这里的第一重世俗。《显扬圣教论》等所说的"如我、有情等"，正与此相同。"有名有实称为第一义"，就是论中所说的四种胜义，因为四种胜义都有名称和体性。这就显示我、有情等只是世俗，不是真实，最为卑劣；其余的都胜过我、有情等，可以作为胜义。或者只以三科对望我、众生等，有名有实称为第一义，也不违背道理，相状可以了知。

### （三）第三番：以二类对四谛

第三番中，"如我、众生，乃至诸阴、界、入，称为世谛；四谛是第一义"，这是以我等和阴界入两类，对望四谛之理，都称为世俗。

1. 我乃至旋火之轮，只有名称，没有体性和作用。这些法再一次被说为世俗谛，是为了显示不只是相对于三科法才称为世俗，相对于四谛等也称为世俗。依此类推，其余的世俗都可以通相比较。
2. 阴、界、入等，有名称也有体性。前面第二番以有名无体用的法，比较阴、界、入，阴界入法称为真谛，就是四重真谛中第一重胜义所摄。这里显示阴界入不只是胜义，又以三科对望四谛，事劣于理，就成为世俗，也就是论中所说的第二重世俗。四谛就是第二重胜义。

### （四）第四番：五种世法

第四番中，"世间法有五种，称为世俗；如实了知这些，称为真谛"，这是显示第一重世俗不只是我等只有名称、没有体性和作用的法，没有实体而有作用的法，也是第一重世俗。所以《显扬圣教论》等说房舍、军队、树林等也是第一重世俗，因为没有实体，与我等同类，最为卑劣。无颠倒地了知这些只有蕴等，完全没有真实的名、句等法，就是第一义，因为四重胜义中都没有所说的五种世间法。或者说三科中实际上没有这五种。

这一番看起来说得不合次第。因为阴、界、入既然已经说通于真谛，恐怕这些有作用而无体性的法也通于真谛，为了显示不是这样，解释这个疑问，所以现在才说。

五种世间法中：

1. 名世、句世两种，是能诠。
2. 缚世、法世两种，是所诠。
3. 执着世一种，是标示相状。

这是显示能诠、所诠，无论是情执还是事物，都有假立，不是真实，所以作差别的说明，没有其他的意义。

### （五）第五番：烧割与无烧割

第五番中，"若烧、割等称为世谛"等，这一对显示二无我称为世俗。外道和凡夫执着我是常一的，佛说为无。因为五蕴等可以烧割等，没有那种实我常一的相状。所以"烧割等"指的是二无我。

后面一番以这个无我对望苦谛之理等，说为真谛，就是第三重真谛。现在以无我对望一实真如：真如不依可烧割等言诠之门显示，就是胜义胜义；二无我等依言诠显示真实，称为世俗，属于第四重胜义世俗所摄。不然的话，这句话有什么能诠释的道理？世尊不说没有意义的话。一实真如就是第四重胜义胜义。

### （六）第六番：八苦相与无八苦相

第六番中，"八苦相等称为世谛"等，前面以四谛对望蕴等称为真谛，现在以四谛对望二无我等"无八苦相"之法，就成为世俗，属于第三重证得世俗所摄。八苦就是苦谛之理，偏举一个苦谛，类推其余三谛。

这一番应当在第五番说，前面的第五番应当在第六番说，因为言说方便，前后不固定。

### （七）第七番：一人多名之喻

第七番中所说的法和譬喻，总的说明二谛的体性没有差别。随着人的智慧，以及法中的空有、事理、浅深、诠旨，四重二谛胜劣相比较，成为真谛和俗谛。

1. 世间人只知道父母所生，称为世俗；出世间人知道因缘所生，称为第一义。这是随人的智慧来分二谛。
2. 父母所生的假事粗浅，称为世俗；因缘所生的实法细深，称为胜义。这是随法来分二谛。

总的说明二谛差别的法和譬喻，再没有其他的门。

### （八）总结：经论无别

仔细观察经意，经中有七重，以义理推究，与论中所说没有差别。经是根本，义理依法相来宣扬；论是末宗，禀承佛言而成立道理，怎么会自相矛盾？所谓矛盾，只是解释的人出于个人胸臆而已。所以可知经论所说没有差别，只是由于解释的人分别不同。这样会通经文，也应当是允当的。
