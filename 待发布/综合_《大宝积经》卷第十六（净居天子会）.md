# 《大宝积经》卷第十六（净居天子会）

西晋·三藏竺法护 译

## 净居天子会第四之二

### 诸梦相的解说（续）

#### 被缚将杀

“又，金刚摧！菩萨梦中自见被绑缚将要被杀，这菩萨是魔业增盛，并非业障。他应当修无碍之定，修慈心，以此净除业障。这菩萨是见六地至初地。若梦见被系缚在死尸之中，是见五地；若被绑缚，亲属围绕，是六地。这是魔业，因不勤修、初地羸弱所致；为了无上道，应当修增上精进。

【按】“若梦被系”之“梦”，宋、元、明本作“梦见”，宫、圣本作“梦梦”。“亲里”之“里”，宋、宫、圣本作“理”。

#### 刀剑中

“又，金刚摧！菩萨若梦中自知身在刀剑之中，这菩萨是初地至五地，多有恶知识，多有艰难，应当宁静而无忿怒，以无障碍之心，一心勤于利益他人，以此净除业障。他从前曾居上位，恼乱持戒之人。

“若见有人手持种种刀，自己处在其中，这菩萨是见初地；若见有人手持一把刀，自己在其中，是第二地；见持杖之人，自己在其中，是见三地；若见持石之人，自己在其中，这是见四地；见自己住在空手的众人之中，是五地。除去魔业。

#### 自见在空中

“又，金刚摧！菩萨梦中自见在虚空中，这菩萨处在信地，得无生法忍。这菩萨为诸天所护念，应当修习好的威仪，应当常修精进，劝发众生求无上道，不应常住一处，这样得以清净。这菩萨是初地至七地各处之相。

“若见在虚空中行布施，这是初地；若在空中见到仙人，这是见第二地；若见沙门，这是见第三地；若见龙，是第四地；若见天众，是第五地；若见梵天，是第六地；若见菩萨、如来，是第七地。除去魔业。

#### 手执火炬

“又，金刚摧！菩萨若梦中自见手执火炬，应当勤修明慧。这菩萨是初地至五地。这菩萨应当不顾身命，不计饮食，应当修禅而不生疑悔，这样趣向。

“住于初地乐修对治，住于二地乐修禅定，住于三地乐修慈，住于四地乐修悲，住于五地乐修舍。住于初地应修念佛以得明见，住于二地应修放舍解脱，住于三地应修闻法，住于四地应修受持，住于五地应修空。这样就能得到光明。

#### 菩萨逾宫而出

“又，金刚摧！菩萨若梦中见菩萨越过宫墙而出，这菩萨是初地至六地各处之相，增加精进，得不退转，处在菩提授记之界，迅速接近无上道。

“若见步行而出，是见初地；见乘牛车而出，是见二地；见乘马车而出，是见三地；见乘象车而出，是见四地；若见乘人车而出，是见五地；若见乘空中之车而出，是见六地。除去魔业。

#### 得经

“又，金刚摧！菩萨若梦中得经，这菩萨是初地至三地各处之相。此人多有种种因缘、多受毁谤，屡屡多有艰难，应当一心修习悔过，常修精进。

“若梦得世俗典籍与声闻经法，这是初地；梦得与布施相应的经，是见二地；梦得与甚深义相应的经，是见三地。若不勤修，乃至七地（也有此相）；或是诸天授予，或是菩萨授予，或是如来授予法藏。

【按】“如来与法藏”，《大正藏》作“如法来与藏”，CBETA 据碛砂藏改正。

#### 闻得法功德之声

“又，金刚摧！菩萨梦中听到得法功德之声，这菩萨是初地至六地各处之相，从前曾得佛的总持。这菩萨业障少，魔业增盛，应当施与辩才，不求他人过失，这样得以清净。

“听到出香陀罗尼之声，这菩萨是初地；听到文字陀罗尼，是第二地。

“听到书写陀罗尼，是八地至初地各处之相。此人不应爱著三界，应勤修独处。他业障少，魔业少，烦恼增盛，应当听闻种种法，应当修习多种观行，这样相应。

“有觉有观三昧，是初住地；无觉少观，是三住地；无觉无观，是四住地；梵处、空处三昧，是五住地；现一身三昧，是六住地；大通三昧，是七住地；出生佛庄严三昧，是第八住地。

【按】此节相当于百八相中的“闻陀罗尼声”“闻三昧声”，经文合在一处解说，以上分段照原文次第。

#### 闻方广经声

“又，金刚摧！菩萨若梦中听到方广经之声，这菩萨是六地至初地，应当修信解法与决定忍。这菩萨障碍少，趣向无上道较为迟缓，应当勤问持戒之相，应当尊重师长，这样趣向菩提。

“听到檀波罗蜜经之声，是初地；听到戒经之声，是二地；听到忍经之声，是三地；听到精进经之声，是四地；听到禅经之声，是五地；听到般若波罗蜜之声，是六地。除去不勤修的人，以及为佛所护持、善心成就的人。

#### 闻说法比丘之名

“又，金刚摧！菩萨若梦中听到说法比丘名字的声音，这菩萨是四地至初地，此人应当依止善知识。这菩萨多有艰难，多有疑悔，智慧较少，应当修无碍之心，应当以方便劝一切众生修无疑悔之心，这样得以清净。

“若见到从前所听闻的法师之名，这是初地；若听到而未见过的法师之名，是见第二地；若听到他方异世界的法师之名，是第三地；若听到一生补处菩萨之名，或听到乐于上地之声，是第四地。

【按】“见第二地”之“见”，宋、元、明、宫本作“是”。

#### 得信辩（梦中得偈）

“又，金刚摧！菩萨若梦中得到信辩，这菩萨是初地至三地。这菩萨是辩才之器，若远离三种法，就能迅速得到光明。哪三种？见他人得利，心生嫉妒；为了利养；以奸诈之心亲近他人。这三种法应当远离，然后趣向。

“说少许偈颂，是初地；能说种种偈，是二地；说甚深之偈，是三地；多说上地之偈。

#### 得经辩（梦中得经说）

“又，金刚摧菩萨！若菩萨梦中得到经辩，是初地至八地之相。此人有许多功德因缘，应当勤于依止修戒，应当修殊胜供养，供养清净修行之人，不应修智慢。这样在梦中受业障，少受苦报。

“他出初地，得四辩；说方等经，是说二地；说种种经，是三地；说前世因缘，是四地；说三世，是五地；说波罗蜜，是六地；说甚深经，是七地；说一切决定之法，是八地。

#### 闻陀罗尼声

“又，金刚摧菩萨！若菩萨梦中听到陀罗尼之声，他是七地。这菩萨受诸烦恼，业障少，应当请问智者，修于静默之处，趣向解脱，这样趣向。

“梦在村中，是初地；在房中，是二地；在僧房中，是三地；在阿练若处坐，是四地；若梦见坐着，是五地；若在园观中，是六地；梦在山顶，是七地。

#### 闻他方如来之名

“又，金刚摧菩萨！若菩萨梦中听到他方世界从未听过的如来之名，这菩萨是受记的初地至八地。因憍慢自在之故，不趣向佛道，多有魔业；为了供养而修不清净的威仪，然后才能趣向。

“修舍，是初地；梦见戒慢，是二地；闻慢，是三地；方便慢，是四地；疑慢，是五地；智慢，是六地；所说之慢，是七地；受持之慢，是八地。

【按】“修舍”之“舍”，明本作“慢”。

#### 闻他方菩萨之名

“又，金刚摧！菩萨若梦中听到某世界某菩萨的声音，这菩萨是五地至初地。这菩萨为诸菩萨所护念，烦恼少，应当远离憍慢，劝许多人修智，这样相应，得陀罗尼。

“这样听闻，是初地；梦见（那菩萨）出家，是听闻二地；梦见苦行，是三地；梦见在道场降魔，是四地；梦见觉悟佛道，是五地。

原文：“闻见上多闻见不定羸劣善心是见初地，住于疑心是二地，退心放逸是三地，增上放逸是四地，多定是五地。”（大意：听见、看见上地而多闻，见而不定，善心羸弱，是见初地；住于疑心，是二地；退心放逸，是三地；增上放逸，是四地；多入定，是五地。存疑。）

#### 入海

“又，金刚摧！菩萨梦见在大海中，这菩萨精进，是八地各处之相，应当修多闻、精进与智慧之解。

“若梦中无所依止，是初地；若在海边，是二地；若在船乘之上，是三地；梦见前往，是四地；梦见上船，是五地；梦见在水中坐，是六地；在船中坐，是七地；梦见船中满载珍宝，自己坐在上面，将要出海，是八地。

#### 集宝

“又，金刚摧！菩萨若梦中聚集珍宝，这菩萨是初地至三地各处之相。这菩萨多遭苦恼，应当乐修清净之业，不求他人短处，对说法者知恩，这样趣向。

“梦见掘地而从地中得宝，是初地；从杂土中得宝，是见二地；从杂草中得宝，是见三地。这是不勤精进之相，是魔业；若是六地或四地，是不勤方便的魔业与业障。

#### 在须弥山顶

“又，金刚摧！菩萨梦见自己在须弥山顶，此人不退转，是见初地至五地。他有少许功德，曾亲近恶友，因缘奸诈，无信而亲近善知识；现今应当修不奸诈之行，多修信解，这样趣向。

“若梦见在须弥山上，应当知道是上六住；梦见住在须弥山上，是七地；梦见向四方顾望，是八地；梦见坐着，是九地；梦见山动摇，是十地。这是初地乃至五地之相，应当勤进修善心；在善知识手中（仍不勤进），是魔业。

【按】“梦中在须弥山顶”之“在”，元、明本作“有”。“在善知识手”之“手”，宋、元、明、宫、圣本作“乎”。

#### 上山

“又，金刚摧！菩萨梦中自见上山，这菩萨是初地至五地。他能断害一切烦恼业障，（但）对说法之人不生恭敬，应当修不谄曲之行，净除业障，这样趣向菩提。

“初地增长三时勤进，二地勤修念佛，三地修空，四地修大悲，五地修智慧。梦见自己上山，是初地；在山中，是二地；在山上，是三地；梦见观看，是四地；坐着，是五地。

#### 上到山顶

“又，金刚摧！菩萨若梦见上山（至顶），这菩萨所见是七地至初地。这菩萨业障少，魔业增盛，应当舍弃一切所爱之物，供养有智慧的人，在有智慧的人身边，应当自己降伏憍慢。若梦见越过七座大山乃至须弥山，是七地。

#### 上树

“又，金刚摧！菩萨若在梦中梦见上树，这菩萨是初地至四地各处之相，应当觉察业障与魔业，应当亲近依止善知识，得到智慧光明，时时决断法义，觉知其理，这样趣向。

“见树木枝叶具足，荫凉，是初地；见香树，是二地；见花树，是三地；见果树，是四地。这是勤进之相，若不勤进，就是魔业。若见高处之树枝叶花果具足，就除去业报。

#### 见龙象

“又，金刚摧！菩萨若梦中见龙象，这菩萨是初地至六地各处之相。这菩萨行布施而不修智慧，善根困乏，应当修信，应当修善念，这样相应。

“他在初地见不清净的龙象，二地见白龙象，三地见六牙白龙象，四地见庄严的象，五地见执持幡盖的龙象，六地见欢喜游戏的龙象。

【按】“四地见庄严象”之“象”，宋、元、明、宫本作“龙象”。“六地见欢戏龙象”下，宋、元、明、宫本有“是七地”三字。

#### 乘龙象

“又，金刚摧！菩萨自己梦见骑上龙象，这菩萨是见初地至七地，一生之中当得如来、应供之果。他有入法之智，但多有希望，应当修恭敬，劝发菩萨远离幻伪奸诈，应当处处知足，修随顺他意的布施，这样得以清净。

“梦见骑象，是初地；梦见自己穿着白衣骑象，是二地；若梦见穿染色衣，是三地；若梦见穿种种色衣，是四地；若梦见穿香染之衣，具足庄严，是五地；若梦见戴冠，是六地；若梦见手执庄严之盖，是七地。除去魔业、不勤精进；上地之相，见一切具足。

【按】“具足庄严”之“庄”，圣本作“应”。

#### 乘马

“又，金刚摧！菩萨若梦中骑马，这菩萨是初地至四地，此人应当修习，依止戒波罗蜜度。他魔业增盛，业障少，应当多修空慧，勤修生起信心，这样得以清净。

“自己梦见骑在站立的马上，是初地；梦见骑在行走的马上，是二地；梦见骑在奔跑的马上，是三地；骑上庄严的马，是第四地。除去上地的魔业；这菩萨有增上慢的魔业。

#### 发真实誓

“又，金刚摧！菩萨若梦中发真实誓愿，这菩萨是一切地、十地各处之相。他业障多，魔业增盛，多行种种方术，应当善修出生三昧，应当端正修习威仪，不多积聚财物，这样净除业障。

“发真实布施之誓，这是初地；为解除系缚而发誓，是二地；为解除疾病，是三地；为城池，是四地；为国王，是五地；为阎浮提，是六地；为四天下，是七地；为千世界，是八地；为三千世界，是九地；日出之时大地游动，天降天花，是十地。除去初地至六地的魔业。

#### 见果树

“又，金刚摧菩萨！若菩萨梦中见药树，这菩萨是见初地至七地，圆满成就受记之法。应当修不望回报的布施，正直而不求他人过失，这样得以清净。

“梦见果实少的树，是初地；若见果实多的树，是二地；若见苦果之树，是四地；见药树，是五地；若见天树，是六地；若见甘果之树，是七地。

【按】此节相当于百八相中的“见果树”，而经文首句作“见药树”。所列诸地缺第三地，照原文译出。

#### 见花树

“又，金刚摧菩萨！若菩萨梦中见花树，这菩萨是七地至初地。应当作种种善根，不亲近四众，这样趣向。

“见许多花树而无香，是初地；见香花树，是二地；梦见许多香花树，是三地；见杂花果树，是四地；见无叶的花树，是五地；见天花之树，是六地；若见菩提树，是七地。除去落在恶知识手中、我慢懈缓、不勤精进的魔业；上地之相，见一切成就。

#### 见未曾见城

“又，金刚摧！菩萨若梦中见从未有过的城，这是六地至初地。这菩萨有业障，这是无生法忍之相，应先修坚固三昧、空三昧，以无碍之心行极苦之行，这样得以清净。

“梦见初建的城，是初地；见建成的城，是二地；见城中街市成就，是三地；见游戏之处成就，是四地；见池水成就，是六地。除去落在恶知识手中、我慢懈缓、不精进的魔业；上地之相，见具足。

【按】“初起城”之“起”，宫本作“趣”。所列诸地缺第五地，照原文译出。

#### 见阿耨大池

“又，金刚摧菩萨！若菩萨梦中见阿耨龙王之池，这是八地至初地。他烦恼少，能迅速出生光明。若无奸诈，勤修精进之行，不顾身命，以一切所需之物满足他人之意，这样得以清净。

“若见阿耨龙池的岸边，这是初地；若见池中，是二地；若见到全部，是三地；若用手触水，是四地；若在池中洗浴，是五地；若坐在岸边，是六地；若见阿耨龙王，是七地；若进入龙宫，龙王增与气力，是八地。除去魔业，是九地。

#### 见天子

“又，金刚摧菩萨！若菩萨梦见天子，这菩萨是上地至五地各处之相。他业障少，魔业也少，犹如微小的水滴，应当三个月勤修寂静，除去业障，得到明净。这样的人应当忆念十方诸佛，应当修不愁恼。

“他若见四大天王众，是见六地；见三十三天，是七地；见兜率天，是八地；见梵天众，是九地；见净居天，是十地。与初地相应，一切所见都是魔业；成就善心，见一切十地。

#### 见龙

“又，金刚摧！菩萨若梦见龙，这是见八地各处之相。他应当成就谨慎之忍；他虽勤精进，屡屡荒废停滞，勤修方便又屡屡放舍；他所有的财物封邑应当用来供给法师，乃至所爱之物全都舍与，然后才能趣向。

“若在山上见龙，是初地；若在旷野见龙，是二地；若在池岸上见龙，是三地；若在林中见龙，是四地；若在人众中见龙，是五地；若在王城中见龙，是六地；若见龙为众多人围绕，是七地；若在空中见龙，是八地。除去初地至六地的魔业与业障。

【按】“慎忍”之“慎”，明本作“顺”，宫本作“真”。“供给法师”之“师”，宫本无。

#### 往余阎浮提

“又，金刚摧！菩萨若梦见自己去往别处的阎浮提，是初地至六地。他若得忍，障碍就少；若不勤修，就得不到光明；若懈怠，亲近奸诈之人；他若生起信心，就这样得以清净。

“若不乐于见到阎浮提，是初地；若乐于见到，是二地；若见村落城邑可爱，是三地；若见园观杂花，是四地；若见大众喜乐，是第五地；若相互娱乐，是六地。除去魔业。

#### 穿着白衣

“又，金刚摧！菩萨梦见自己穿着白衣，这菩萨是见八地至初地。他业障清净，魔业增盛；他生起乐法之心，又屡屡退减功德，多有艰难。对一切物都不应悭惜，这样得以清净。若自见一切所需之物、一切人们所喜欢的卧具，不惜身命，多闻而修善根。

“若穿着长久旧而好的衣服，是初地；若见长领的新衣，是二地；若见长领之衣，是三地；若见捶打整治过的衣，是四地；若见捶打整治又磨光的衣，是五地；若见染色衣，是六地；若见象色之衣，是七地；若见天衣，是八地。

#### 宝鬘在头

“又，金刚摧！菩萨若梦见得到宝鬘，这是初地至九地。他没有业障，没有魔业，应当自责己过，不责备他人，求修闻法，不作斗讼，这样得以清净。

“若是一种宝鬘，是初地；像这样两种乃至七种宝鬘，是七地；若得转轮王的摩尼宝鬘，是八地；若见天宝鬘，是九地。除去魔业。这是见初地起业之相：若戏笑懈怠，亲近戏笑懈怠、不自检省的人，应当觉知。

【按】“乃至七种”之“七”，宫本作“十”。

#### 头戴花鬘

“又，金刚摧！菩萨若梦见头上戴着花鬘，是八地至初地，此人确实有业障。若初、中、后都生起定善之心，舍弃一切物而不生愁恼，这样得以清净。

“若得一种颜色的花鬘，是初地；若得颜色不好的花鬘，是二地；若得种种颜色的花鬘，是三地；若得一切花鬘，是四地；若得龙花鬘，是五地；若得天花鬘，是六地；若得天上种种花鬘，是七地；若得天人交杂的花鬘，是八地。

#### 取散花

“又，金刚摧！菩萨若梦中取得散乱的花，这菩萨是见六地至初地。这菩萨应当劝化菩萨；若有自在力势，不侵犯冤屈他人。

“若取有色无香的花，是初地；若取有色有香的花，是二地；若取金色花，是三地；若取种种颜色的花，是四地；若取水陆之花，是五地；若取水陆种种杂花，是见六地。这样的相，应当勤修精进。若是魔业，若是上地，若是四地，一切适意之物都由龙持来。

#### 击鼓作乐

“又，金刚摧！菩萨若梦中击鼓、作伎乐，他是九地各处之相，业障与魔业增盛，此人应当勤修多闻精进，对一切众生生起平等之心，这样得以清净。

“若梦见在空中击鼓，是初地；若在平地见到，是二地；若在村中见到，是三地；若在大城中见到，是四地；若在大众中见到，是五地；若在屋上见到，是六地；若在山中见到，是七地；若在须弥山顶见到，是八地；若在虚空中见到，是九地。除去勤修智慧时的魔业。

【按】“作伎”之“伎”，宋、元、明、宫本作“技”。

#### 日蚀月蚀

“又，金刚摧！菩萨若梦中见日蚀、月蚀，这菩萨是初地至六地，毁灭善法，多有烦恼，成就恶业，应当以一切物布施而不望业报，这样得以清净。

“见日月初出，是见初地、二地；见云，是三地；见聚积的云，是五地；见无尘无雾，是六地；见日月当中之时，除去魔业与业障。

【按】“见聚云五地”，明本作“见聚云四地，见散云五地”，可补四地之缺。

#### 不净涂身

“又，金刚摧！菩萨梦中见以不净之物涂身，这菩萨是见初地至三地。他前身曾毁骂贤圣，是修恶行的菩萨。这菩萨应当在三年中昼夜三时勤修忏悔，此后再不对他人生轻慢之心，应当多修信解，这样得以清净。

“以青色淤泥涂身，是初地；若涂半身，是二地；若处处被涂，是三地。乃至六地，应当觉察魔业。

#### 作王

“又，金刚摧！菩萨若自己梦见作王，这菩萨是一切十地各处之相，有深厚的善根，也有深厚的艰难。不应对他人有所希望，供养他人不起奸诈，修质直的布施，所持之戒与他人共有，不自赞，不毁他，这样来觉悟佛道。

“若在村中恐怖，是初地；若在僧房中，是二地；若在园观中，是三地；若在天祠中，是四地；若在大城中，是五地；若在山中，是六地；若作阎浮提王，是七地；若作转轮王，是八地；若在海中，是九地；若在须弥山顶，是十地。除去魔业、不勤精进，应当忆念诸佛菩萨。

#### 作王辅相在大众中

“又，金刚摧！菩萨若梦见在王前、辅相前或大众中，这菩萨是八地之相。他杂有烦恼，应当教化众生，应当修习供养，自修清净，这样得以清净。

“他初地杂有布施、众烦恼，二地是戒，三地是闻，四地是定，五地是持，六地是神通，七地是说法，八地是眷属成就。

#### 乘乘往园林

“又，金刚摧！菩萨若梦见骑乘车马在园林中，这菩萨是九地至初地之相。这菩萨不知道这是世间的利养饮食，被魔所牵缚，业障少，应当供给法师、供养所需，应当修习寂默，这样趣向。

“他初地无智之行，二地无慧，三地无决定智，四地无禅智，五地无无碍智，七地无出生智，八地无庄严智，九地无愿智。

【按】所列诸地缺第六地，照原文译出。

#### 见未曾见聚落僧坊

“又，金刚摧！菩萨若梦见从未见过的村落、僧坊与人众，这菩萨是初地至六地。他多有艰难，应当修念佛，这样得以清净。

“修信心布施，修一切信解，见到这样行相的，是初地；若突然有所兴作，是二地；若庄严，是三地；若见庄严完毕，是四地；若见四众聚会，是五地；若见天众，是六地。

【按】“若梦见所未见”之“梦”，宋、元、明、宫、圣本无。

#### 得盖

“又，金刚摧！菩萨若梦中得到伞盖，是初地至七地之相，为佛所护持，多有艰难而不为所屈；他对说法之人不应生起恶意，这样得以清净。

“若见花盖，是初地；若见琉璃盖，是二地；若见花和盖，是三地；若见物盖，是四地；若见画有茎干的盖，是五地；若见铃网盖，是六地；若见宝网盖，宝网垂覆，是七地。除去魔业、不勤精进。

#### 为多人说法

“又，金刚摧菩萨！若菩萨自己梦见为众多人说法，这菩萨是一切十地之相，他在各地都应觉知魔业与业障。想要得决定辩才，应当出外推求；对一切物不应爱著；对求法之人生清净信心；修六和敬之戒，这样得以清净。

“若梦见宣说如何修行布施，这是初地；（宣说）什么是十善法，是二地；什么是闻法，是三地；什么是头陀之德，是四地；如何说空，是五地；如何说诃责习气，是六地；如何说无染著，是七地；如何说庄严三昧，是八地；如何说庄严佛（土），是九地；如何说妙时，是十地。

“初地是布施之财，二地是持戒之财，三地是方便之财，四地具足七财，五地是奉给之财，六地是决断之财，七地是决定之财，八地是神通无碍之财，九地是修行之财，十地是得财。

“他初地善根增上，二地持戒增上，三地方便增上，四地所作增上，五地十二因缘增上，六地甚深忍增上，七地破坏（执著之）智增上，八地坏（相）教化众生增上，九地调伏增上，十地坏（相）清净国土增上。

【按】“五地十二因缘增上，六地”数字，圣本无。末三句的“壞”字，照原文译出，存疑。

#### 初立城郭

“又，金刚摧！菩萨若自己梦见初建城郭，这菩萨是八地，受不退转记。应当亲近供养有甚深信解的人；他多有决定之疑悔、法障，应当供养法师，得以除去疑悔，这样得以清净。

“他住于其中，是初地；疑惑佛道，是能得佛还是不能得佛，是二地；疑惑教化众生之智，是三地；疑惑出生禅定，是四地；疑惑应作之智，是五地；疑惑道果，是六地；疑惑出生，是七地；疑惑游戏神通，是八地。

【按】“教化众生”之“教”，《大正藏》作“敬”，CBETA 据高丽藏作“教”。

#### 施系桥梁（缚筏过浊水）

“又，金刚摧！菩萨若梦见扎筏渡过浊水，他是七地至初地，业障与魔业增盛，应当生起增上的欲心，坚固不坏，和合相应，无生之明清净。

“若智慧方便有艰难，是初地；若想勤修善业而身体懈怠，是二地；若心不合时宜，是三地；或有时明了，是四地；若稍有无畏，是五地；若教化有艰难，是六地；若佛法有艰难，是七地。

#### 集船

“又，金刚摧！菩萨若自己梦见聚集船只，这菩萨是六地。若平等修行六波罗蜜有艰难，应当修行无所依的六波罗蜜，这样得以清净。

“若梦见造船未完成，是初地；造船完成，是二地；若梦见两船并列，是三地；若将两船并排系缚，是四地；见大众登船，是五地；见入船而去，是六地。

【按】“集船”之“集”，宋、元、明本作“乘”。

#### 见云雷电

“又，金刚摧！菩萨若自己梦见云雷放电，这菩萨是五地至初地。他魔业增上，业障少，应当多思善念，舍弃所爱之物，修集陀罗尼，这样得以清净。

“若见云、雨、闪电而惊怖，是初地；若不惊怖，是二地；若忆念正法，是三地；若住于山顶忆念，是四地；若在空中忆念，是五地。除去魔业。若在上地，诸龙前来集会，奉事其所作，就不生惊怖。

#### 得庄严刀

“又，金刚摧！菩萨若梦中得到庄严之刀，这菩萨是初地至三地。他魔业与业障增盛，应当亲近忍波罗蜜、毘梨耶（精进）波罗蜜、般若波罗蜜，这样得以清净。

“若得垢腻之刀，是初地；得无垢之刀，是二地；得锋利之刀，是三地。

#### 得器物

“又，金刚摧！菩萨若梦中得到器物，这菩萨是七地，应当这样相应修行。他不一定有魔业业障，应当勤行四摄法，这样得以清净。应当净除六地，从退失之法得到增上的七地。

#### 示众生道

“又，金刚摧！菩萨若自己梦见为众生指示道路，这是一切十地之相。这样与初地相应，应当觉察业障与烦恼障，应当供养亲近法师，舍弃一切物，勤修精进，这样趣向。

“若见乘车在路上转动，是初地；指示去园观的路，是二地；指示去城中的路，是三地；指示去阿练若的路，是四地；指示山路，是五地；指示去海边的路，是六地；指示天道，是七地；指示声闻道，是八地；指示菩萨道，是九地；指示佛道，是十地。说完指示道路，再指示诸地：初地应觉察魔业、觉察烦恼业，此前六地无有过失。

#### 入园林

“又，金刚摧！菩萨若梦中进入园林之中，这菩萨是八地至初地。他在梦中受魔业、烦恼业，梦中惊怖，醒后生起愁苦。此人应当修空，听闻甚深之法，应当默然，远离睡眠，应当亲近能决定宣说道法的人，这样得以清净。

“若自己梦见退失王位，心生惊怖，是初地；梦见破戒而惊怖，是二地；梦见正法灭尽而惊怖，是三地；梦见法师无常而惊怖，是四地；若梦见被火所烧而惊怖，是五地；梦见被惊吓而惊怖，是六地；梦见从山上坠落而惊怖，是七地；梦见世尊入涅槃而惊怖，是八地。若不勤进，在六地应当觉察魔业。

#### 见五谷聚

“又，金刚摧！菩萨若梦中见五谷堆积，这菩萨是住于八地及上地。初地、第二地这样见，是不勤进；见魔业，不必多谈。他前身曾供养诸佛，多有艰难，不依附一切世间，不观于舍（之果报），守护三业，这样得以清净。

“梦见聚集谷物，是七地；梦见聚集三千大千世界的谷物，是八地；若梦见五谷成熟堆积，是九地；若梦见收割谷物，是十地。

#### 治众生病

“又，金刚摧！菩萨若梦中见自己治疗众生之病，这菩萨是八地。他业障少，魔业增盛，应当修大悲，勤于劝化，不生疑悔，这样相应。

“梦见治疗小儿，是初地；若梦见治疗女人，是二地；若梦见治疗大人，是三地；若梦见治疗热病，是四地；若梦见治疗白癞病，是五地；若梦见治疗自残之病，是六地；若梦见治疗干消病，是七地；若梦见治疗鬼病，是八地。除去魔业；应当修集忍行，成就菩萨的大悲善心。

【按】“乾消”，宋、宫、圣本作“干消”，元、明本作“乾痟”，即消渴之病。

#### 闻授记声

“又，金刚摧！菩萨若自己听到授菩提记，这菩萨是见十地。此人受记，对魔业与业障应当觉知，受十地之记。

“初地受道记，二地受菩萨行记，三地受忍记，四地受愿记，五地受三昧记，六地受慧记，七地受方便记，八地受超出声闻、辟支佛地的一切智记，九地受一生补处记，十地受佛灌顶记。他修大悲、般若波罗蜜，亲近善权方便，这样趣向。

【按】“一切知记”之“知”，元、明本作“智”。

#### 觉道

“又，金刚摧！菩萨若梦中觉悟佛道，这菩萨是初地。应当觉知大悲，应当勤修精进，应当信于善心，这样趣向。

“觉知，是八地；震动三千大千世界，是九地；梦见放光，诸天大声歌颂、欢喜长啸，是十地。初地至七地不勤进，就是魔业，其相如此。

【按】“喜啸”之“啸”，明本作“笑”。“初地七地”，宋、元、明、宫本作“初地十地”。

#### 得满瓶

“又，金刚摧！菩萨若梦中得到满瓶，这菩萨是见一切十地，应当这样了知。

“若在村中得到，是初地；若在门中得到，是二地；若在道路中得到，是三地；若在树下得到，是四地；若站着得到，是五地；若坐着得到，是六地；若在山顶得到，是七地；若在空中得到，是八地；若在饮食时得到，是九地；若在庄严的车乘之上，或在园观中得到，是十地。对这各地的魔业与业障应当觉察，这样清净而趣向。”

### 世尊说偈

那时，世尊说偈道：

```
如是相所得，决定无有疑，
大士应如是，莫见他少短，
人德难可量。大海可炽火，
火中可生水，此一一有相，
若退于菩提，终无有是处。
```

（大意：得到这样的相，决定没有疑惑。大士应当如此：不要只看见他人的小小短处，人的功德难以衡量。大海可以燃起烈火，火中可以生出水来，这一一尚且可能有其相；若说（得此相者）退失菩提，终究没有这种道理。）

```
若以于两肩，顶戴于须弥，
游至于十方，恒河沙世界；
如是之相貌，此事犹可作，
如此菩提心，终无有退转。
大地可反复，菩提心退转，
终无有是处。此中少功德，
若有善心人，以向无上道，
有四法无量。世间无智者，
虚空界难知，如是众生界，
佛知菩提心。愚者应当知，
诸菩萨所行，不应生轻毁。
```

（大意：若有人以双肩顶戴须弥山，游遍十方恒河沙数的世界，这样的事尚且可以做到；而这样的菩提心，终究不会退转。大地可以翻覆，菩提心退转，终究没有这种道理。在这里只有少许功德，若有善心之人以此趣向无上道，就有四种无量之法。世间无有智者能知虚空界，众生界也是如此难知，唯有佛知道众生的菩提心。愚人应当知道：对诸菩萨所行，不应生起轻毁之心。）

【按】“愚者应当知”之“愚”，宋、元、明、宫、圣本作“遇”。

```
可以一小草，测量于大海，
众生之所行，不可得思议。
假使大海水，尽融为洋铜，
为己身命故，犹尚可饮尽，
于诸菩萨行，终不可轻毁。
如饮洋铜苦，其苦不可数，
或有业障碍，或为魔所乱，
彼人受生处，终无有忧悔。
```

（大意：可以用一根小草来测量大海，众生之所行却不可思议。假使大海之水全部熔为烊铜，为了自己的身命，尚且可以饮尽；对诸菩萨之行，终究不可轻毁。轻毁菩萨，如饮烊铜之苦，其苦不可计数。菩萨或者有业障阻碍，或者被魔扰乱，但那人受生之处，终究不会有忧悔。）

```
若人为乐故，于恶色愚痴，
破戒可厌恶，不可恭敬者，
如是等人所，不应生轻慢。
众生之所行，甚难可得知，
犹如舍利弗，寂默入禅定，
能于一心中，唯知五十心。
犹如诸世尊，一念知无量，
不应于诸佛，而生于疑心。
犹如阿罗汉，不知自境界，
况复当能知，众生之境界。
是故一切人，不应作是言：
『我能知众生，心中之所念。』
```

（大意：若有人为了快乐，对容貌丑恶、愚痴、破戒、令人厌恶、不可恭敬的人，在这类人那里也不应生起轻慢之心。众生之所行，非常难以得知。就如舍利弗寂默入于禅定，在一心之中，也只能知道五十种心；而诸世尊在一念之中能知无量，不应对诸佛生起疑心。就如阿罗汉尚且不知自己的境界，更何况能知众生的境界。所以一切人都不应这样说：“我能知道众生心中所想。”）

```
我见染服人，须臾著白衣，
如是念念间，念念有变异，
况谁能复知，真实者愚患。
譬如阿阇世，杀害于己父，
又于如来所，而生恶逆心，
还于一念中，深悔过罪心，
即能除罪报，脱于恶道苦。
况有能自生，清净善心者，
```

（大意：我见到身穿染衣的出家人，片刻之间又穿上白衣还俗；像这样念念之间，念念都有变异，又有谁能知道谁是真实者、谁是愚患者呢？譬如阿阇世王杀害自己的父亲，又在如来那里生起恶逆之心，却在一念之中深深悔过罪心，就能除去罪报，脱离恶道之苦。何况能自己生起清净善心的人呢？）

```
此心或时缚，此心或时解，
此身是无记，亦无有所知，
云何令此身，而有于过恶？
是身亦不应，亲近于身色，
亦复所不应，杀害他人身。
譬如真净金，堕于不净中，
本性常清净，不净不能损。
彼人虽贪乐，行于世间法，
彼人实功德，善心无损减。
```

（大意：这心有时被系缚，这心有时得解脱；这身是无记的，也无所知，怎么能让这身有过恶呢？这身也不应亲近身色，也不应杀害他人之身。譬如真正纯净的金子，掉落在不净之物中，其本性常时清净，不净之物不能损坏它。那人虽然贪乐于世间法而行，那人真实的功德与善心并无损减。）

```
王子长者子，众中作戏笑，
一切诸大王，见者悉喜乐。
此众生中行，或在天人中，
或食毒不死，或捉火不烧，
况于知觉者。世间愚痴人，
不能夺痴行，缘觉及声闻，
不如施菩萨。清净心福田，
平等犹如佛，菩萨等如佛，
见善心甚深。
```

（大意：王子、长者之子在大众中嬉戏说笑，一切诸大王见了都欢喜。菩萨在这众生之中行，或在天人之中，或吃了毒而不死，或手握火而不被烧，更何况是有知觉的人。世间愚痴之人，不能夺去他的痴行。布施缘觉与声闻，不如布施菩萨。具清净心的福田，平等犹如佛；菩萨等同于佛，所见的善心甚深。存疑。）

【按】“捉火”之“捉”，宋、元、明、宫本作“投”。“知觉者”，明本作“智觉者”，圣本作“知学者”。

```
譬如恒河沙，诸佛世界中，
满中七宝施；若书持此经，
欲比其功德，倍数无比喻，
善得于命利，菩提心不失。
若人为财故，入于大海中，
必当获大利；若持一切经，
能为多人说，不闻于此经，
不知众生行。以是因缘故，
应当知胜如，不自赞己德，
不应谤毁他，善心行清行。
若欲速觉悟，第一菩提道，
乐阿练若处，常护诸情根，
勤修于精进，远离于亲里，
修第一义慈。如是当速疾，
得于菩提道。
```

（大意：譬如在恒河沙数诸佛世界中，充满七宝来布施；若有人书写受持这部经，要比较其功德，倍数之多，无可比喻，善得寿命之利，菩提心不会失去。若有人为了财物进入大海之中，必定获得大利。若受持一切经，能为多人宣说，却未听闻这部经，就不知道众生之行。由于这个因缘，应当知道（此经）殊胜。不自赞己德，不应谤毁他人，以善心修行清净之行。若想迅速觉悟第一菩提之道，应当乐住阿练若处，常常守护诸根，勤修精进，远离亲属，修第一义之慈。这样就会迅速得到菩提之道。）

【按】“命利”，宋、元、明本作“大利”。“胜如”之“如”，圣本作“劣”，即胜劣。“不自赞己”，宫、圣本作“不自己赞”。“清行”之“清”，宋、元、明、宫本作“净”。“亲里”之“里”，宋、宫、圣本作“理”。

### 闻经利益与流通

那时，世尊宣说这部经时，六万天人对阿耨多罗三藐三菩提得不退转；十八那由他尚未发心的天人发起了菩提之心。由于听闻这部经，除舍了八十劫生死之罪。所以，若想不舍弃菩提，应当受持这部经，读诵通利，善加思念，勤于方便，忍受而欢喜奉行。

那时，大众中有一万位菩萨，想要退失菩提心，生起疑悔，想要回家，不知道障碍与魔业的过患。听闻宣说这部经后，舍除了罪过，在世尊面前生起少许信心，将在这个世界与弥勒菩萨同时成佛。他们净除了二十劫的魔业，不起此座，就住于一生补处；将生到他方世界，弥勒成佛时也同时成佛，因为他们除去了二十劫的魔业与烦恼。菩萨只是听闻这部经，尚且能作许多利益，更何况受持、读诵、开显宣说。

【按】“菩萨但闻此经”，宋、元、明、宫、圣本作“若菩萨但闻此经”。

佛说完这部经，天、人、阿修罗都欢喜奉行。

【按】净居天子会至此终，本会凡二卷（卷第十五、卷第十六）。
