# 慈五颂

梅纪巴造　据藏文译出

## 题解

《慈五颂》（藏 dga' gcugs lnga pa，藏本所录梵题作 Priṇapañcaka）收于德格版丹珠尔续部释 ཝི 函第 113b 至 114a 页，紧接在《双运义明示》（D2237）之后，东北目录未单独编号，后来补编为 D2237a，同属梅纪巴的"无念法类"。译者是上师金刚手与玛班译师。

这是一首以夫妻为喻的短歌，全篇五颂二十句。前面的《双运义明示》以论理的方式说明显现与空性双运；本篇则把"显现"与"空性"比作一对亲爱的夫妻：两者本来和合，一旦被分开——执显现为实有，便成束缚；执空性为断无，又失去了大乐——这对夫妻就失和了；于是两人一同来到上师面前，上师使他们像从前一样欢喜和合。最后两颂赞叹上师的善巧，以及和合之后的双运境界。整首歌的意思是：显空双运并不是修出来的新东西，而是本来如此；只因执著而"失和"，依上师的口诀而"重归于好"。

这样的比喻在大手印道歌中很常见，读时要把握它的象征意义：所说的"夫妻""和合"，都是显现与空性的比喻，不是在讲世俗的男女之事。下面在按语中逐一说明比喻所指；由于原文简略，有几处所指不能完全确定，都标明存疑。

体例：每颂先列藏文原颂于代码块中，再按完整的意义单元译出；为了便于理解而补的字，都放在方括号中。原文含混或可有两解之处，以"【按】"说明，不妄补内容。文末附通篇连读。

## 题名与礼敬

梵语题名：Priṇapañcaka。藏语题名：《慈五颂》。

敬礼佛陀！

【按】藏题 dga' gcugs，dga' 是"欢喜、喜爱"，gcugs 是"亲爱、和好、和睦"，合起来是"欢喜和合""亲爱和睦"之义，指夫妻之间的恩爱和好，与本篇以夫妻和合为喻的内容相应。若照字面，也可译作《欢合五颂》或《和睦五颂》。这里依来稿题名作《慈五颂》，"慈"取慈爱、恩爱之义，与佛教"慈悲喜舍"的"慈"（梵 maitrī）不是同一个词，读者不要混淆。梵题 Priṇa 可能是 prīṇana（令欢喜）或 prīti（喜爱）一系的词，藏本音写或有讹误，存疑。

## 第一颂　显现：最亲爱的伴侣

```
སྣང་བ་མཆོག་ཏུ་གཅུགས་པ་ནི། །
རྟེན་ཅིང་འབྲེལ་འབྱུང་ཙམ་ཉིད་དེ། །
མེད་པར་གྱུར་ན་སྟོང་པ་ཉིད། །
འདོད་པ་མོ་དངོས་འཆིང་བར་འགྱུར། །
```

那最亲爱的［伴侣］——显现，［它］只是缘起而已。如果［把它］当作不存在，［便只剩下孤立的］空性；如果把它当作实在的女子而贪求，又会成为束缚。

【按】这一颂以"显现"为一方伴侣。显现的本性只是缘起：既不是断然的无，也不是实在的有。后两句说两种过失：一是否定显现、只取空性，落入断边；二是把显现当作实有之物来贪求，成为束缚，落入常边。"实在的女子"（mo dngos），字面是"女子的实体"，指把作为伴侣的"显现"执为实有。第三句也可以理解为"［显现］若消失了，就是空性"，即显现的消失并不是另外有一个空性；但从后一句说"束缚"来看，这里理解为两种过失的对举较为顺当，存疑。

## 第二颂　空性：无比的爱人

```
སྟོང་ཉིད་ཤིན་ཏུ་མཆོག་གྱུར་པའི། །
མཛའ་བོ་དཔེ་མེད་གཟུགས་ལྡན་གང་། །
དེ་དང་བརྒྱ་ལ་བྱེད་ན་ནི། །
དགའ་བདེའི་གཙོ་བོ་བརླག་པར་འགྱུར། །
```

那无比的爱人，是最为殊胜的空性，［又是］具有色相的；如果万一［把显现］与他［分开来］对待，那喜乐之主就会失去了。

【按】"爱人"（mdza' bo），这里是男性的爱人，比喻空性；与上一颂比作女子的"显现"相对。"具有色相的"（gzugs ldan），意思是这空性不是一片空白，而是具有显现、具有妙相的空性，与《双运义明示》所说"具足一切殊胜相"的空性相同。

第三句"de dang brgya la byed na"最难解：brgya la 一般是"万一、或许"之义，直译是"万一与他作［某事］"。这里依上下文理解为：万一把显现与空性分开，各自对待，就会失去"喜乐之主"。"喜乐之主"（dga' bde'i gtso bo），可能指双运的大乐，也可能指作为夫君的空性本身。全句所指不能完全确定，存疑。

## 第三颂　上师使之和合

```
དེ་ཕྱིར་དོགས་པས་ཁྱོ་ཤུག་གཉིས། །
བླ་མ་དམ་པའི་སྤྱན་སྔར་གནས།
དེ་ཡིས་དེ་དག་སྔོན་བཞིན་དུ། །
དགའ་བས་ལྷན་ཅིག་གཅུགས་པར་མཛོད། །
```

因此，夫妻二人心怀忧虑，［一同］来到殊胜上师的面前；上师使他们像从前一样，欢喜地和合在一起。

【按】"夫妻"（khyo shug），即显现与空性。"心怀忧虑"（dogs pas），是说因为担心失去对方，也就是修行人因执著而使显现与空性"分离"，生起种种疑惑。"像从前一样"（sngon bzhin du），意思是显空本来就是和合的，上师并不是创造出一种新的和合，而是使它恢复本来的样子。这正是大手印"直指"的意思：上师指出心性本来如此，修行人当下认出。

## 第四颂　赞叹上师

```
ཨེ་མའོ་བླ་མ་མཆོག་མཁས་ནི། །
འདི་ལྟ་བུ་ལ་མཁས་པ་མཚར། །
རང་བཞིན་གཉིས་མེད་དམིགས་པ་མེད། །
བླ་ན་མེད་པར་གཉིས་ཀ་སྐྱེས། །
```

奇哉！最胜善巧的上师，在这样的事上竟如此善巧，真是稀有！［如今两者］本性无二，无所缘取，二者都在无上［的境界］中生起了。

【按】"奇哉"（e ma'o），是道歌中常用的赞叹之词。后两句描述和合之后的境界：显现与空性本性无二，没有可以执取的所缘。第四句"bla na med par gnyis ka skyes"，直译是"二者都无上地生起"，可以理解为显现与空性二者都显现为无上的［双运］，也可以理解为"二者在无上之中生起"。这里依后者，存疑。

## 第五颂　双运的境界

```
མཚན་ཉིད་ཐམས་ཅད་ཡང་དག་རྫོགས། །
མཐའ་གཉིས་རྣམ་པར་སྤངས་པ་སྟེ། །
དངོས་པོ་ཀུན་གྱི་ངོ་བོ་ཉིད། །
རང་བཞིན་མེད་པར་རྟག་ཏུ་ཤར། །
```

一切体相都真实圆满，［常、断］二边完全远离；［这就是］一切事物的本体，恒常无自性地显现着。

【按】"一切体相都真实圆满"，是说双运之中，显现的一切相都不缺少；"二边完全远离"，是说其中既没有执有，也没有执无。末句"恒常无自性地显现"（rang bzhin med par rtag tu shar），把显现与空性收在一句之中：显现不断，而显现本身就是无自性的——这正是全篇所说的"夫妻和合"。

## 跋

《慈五颂》，阿阇黎梅纪巴所造，圆满。

上师金刚手亲口［传授］，译师玛班译出。

【按】"亲口［传授］"，原文 zhal snga nas，是对上师的敬称，相当于"座前、尊者"。"玛班"（rma ban），一般认为是玛·法炬（rma ban chos 'bar）译师，与金刚手合作译出过若干梅纪巴的著作，但跋语只作"玛班"，存疑。

## 通篇连读

敬礼佛陀！

那最亲爱的伴侣——显现，只是缘起而已；如果把它当作不存在，便只剩下孤立的空性；如果把它当作实在的女子而贪求，又会成为束缚。

那无比的爱人，是最为殊胜的空性，又具有色相；如果万一把显现与他分开来对待，那喜乐之主就会失去了。

因此，夫妻二人心怀忧虑，一同来到殊胜上师的面前；上师使他们像从前一样，欢喜地和合在一起。

奇哉！最胜善巧的上师，在这样的事上竟如此善巧，真是稀有！如今两者本性无二，无所缘取，二者都在无上的境界中生起了。

一切体相都真实圆满，常、断二边完全远离；这就是一切事物的本体，恒常无自性地显现着。
