# 善逝之见歌

阿阇黎达玛巴造　据藏文译出

## 题解

本篇梵名 Sugatadṛṣṭigītikā，藏名 bde gshegs kyi lta ba'i glu，即《善逝之见歌》，收于德格版丹珠尔续部释 ཟི 函第 4b 至 5a 页（东北目录 D2349）。跋语说是"阿阇黎达玛巴所造"，没有记载译者。

达玛巴（Dharmapa）是八十四成就者之一。依成就者传记，他本是一位博学的婆罗门学者，一生钻研经论，到晚年失明之后，才得到上师的教授，把一生的学问都融入心性之中而成就。

全篇约二十五句，以"达玛巴这样说：因为把善逝顶戴在头上，我证悟了胜义的真如"为叠句。与这一组道歌中多数篇章不同，本篇的主题是皈依与信心：皈敬三宝；以四无量心为殿堂而出家；以须弥山与草堆为喻，说佛的见地远胜外道；以宝珠与玻璃珠为喻，劝人不舍佛法；最后说三宝即是二谛。全篇没有涉及具体的密法修持。

## 一、皈敬三宝

```
སངས་རྒྱས་ཆོས་དང་དགེ་འདུན་ལ། །
ཐམས་ཅད་དུ་ནི་བདག་ཕྱག་འཚལ། །
སྐྱེ་འགག་སྡུག་བསྔལ་སྒྲོལ་ཕྱིར་མཛད། །
དྷ་མ་པ་ནི་སྨྲ་བར་བྱེད། །
བདེ་གཤེགས་སྤྱི་བོར་བཀུར་བ་ཡིས། །
བདག་ཉིད་དོན་དམ་དེ་ཉིད་རྟོགས། །
```

对于佛、法与僧，我在一切时处都顶礼；［三宝］是为了救度众生脱离生灭之苦而作为的。达玛巴这样说：因为把善逝顶戴在头上，我证悟了胜义的真如。

【按】"把善逝顶戴在头上"（བདེ་གཤེགས་སྤྱི་བོར་བཀུར་བ），是对佛的极度恭敬与皈依，也可理解为观想佛于顶上。这两句是全篇的叠句，说明作者的证悟来自对三宝的皈依与恭敬。

【按】存疑。第八句"སྐྱེ་འགག་སྡུག་བསྔལ་སྒྲོལ་ཕྱིར་མཛད"，主语不明，本译补为"三宝"；也可能是说作者自己"为了救度生灭之苦而作［顶礼］"。

## 二、在梵住殿中出家

```
ཚངས་པའི་གནས་བཞི་ལྷ་ཁང་དུ། །
འདི་རུ་བདག་ནི་རབ་ཏུ་འབྱུང། །
ཆོས་རྣམས་ཐམས་ཅད་ཁོང་དུ་ཆུད། །
དྷ་མ་པ་ནི་སྨྲ་བར་བྱེད། །
བདེ་གཤེགས་སྤྱི་བོར་བཀུར་བ་ཡིས། །
བདག་གིས་དོན་དམ་དེ་ཉིད་རྟོགས། །
```

在四梵住的殿堂里，我在这里出了家，通达了一切法。达玛巴这样说：因为把善逝顶戴在头上，我证悟了胜义的真如。

【按】"四梵住"（ཚངས་པའི་གནས་བཞི），即慈、悲、喜、舍四无量心。"在四梵住的殿堂里出家"，是比喻：不是在外在的寺院，而是以四无量心为殿堂、为出家处。依八十四成就者传记，达玛巴本是一位婆罗门学者，晚年失明后才从上师得到教授；这里的"出家"，大概是指他从世间学问中出离、安住于四无量心。

## 三、须弥与草，外道之见岂能相比

```
རི་རབ་དང་ནི་རྩྭ་ཡི་ཚོགས། །
ཇི་ལྟར་སྲང་ལ་གཞལ་ལམ་ཅི། །
དེ་བཞིན་ཕྱི་རོལ་ཐམས་ཅད་ཀྱིས། །
ལྟ་བ་འདི་དང་མཉམ་མམ་ཅི། །
དྷ་མ་པ་ནི་སྨྲ་བར་བྱེད། །
བདེ་གཤེགས་སྤྱི་བོར་བཀུར་བ་ཡིས། །
བདག་གིས་དོན་དམ་དེ་ཉིད་རྟོགས། །
```

须弥山与一堆草，难道能放在秤上去称量吗？同样，一切外道［的见解］，难道能与这见地相等吗？达玛巴这样说：因为把善逝顶戴在头上，我证悟了胜义的真如。

【按】"外道"（ཕྱི་རོལ），字面是"外者"，指佛法以外的诸宗。这一节以须弥山与草堆为喻，说佛的见地与外道之见不可相提并论，与题名"善逝之见"相应。

## 四、弃宝取琉璃，三宝即二谛

```
ནོར་བུ་རིན་ཆེན་བོར་ནས་ནི། །
སུ་དག་མཆིང་བུ་ལེན་པར་བྱེད། །
སངས་རྒྱས་ཆོས་དང་དགེ་འདུན་ནི། །
བརྟགས་ན་བདེན་གཉིས་ཡིན་པར་སྨྲ། །
དྷ་མ་པ་ནི་སྨྲ་བར་བྱེད། །
བདེ་གཤེགས་སྤྱི་བོར་བཀུར་བ་ཡིས། །
བདག་གིས་དོན་དམ་དེ་ཉིད་རྟོགས། །
```

舍弃了珍贵的宝珠，有谁会去拿玻璃珠呢？佛、法与僧，若加观察，就说是二谛。达玛巴这样说：因为把善逝顶戴在头上，我证悟了胜义的真如。

【按】"舍弃宝珠，拿玻璃珠"，是常用的譬喻，比喻舍弃殊胜的佛法而去追求外道或世间的东西。"མཆིང་བུ"，指玻璃、琉璃或廉价的珠子。

【按】"三宝若加观察，就是二谛"，意思大概是：三宝在世俗中是皈依的对象，在胜义中就是真如本身；二者不相违，所以作者以皈依三宝为起点，最后证悟胜义真如。所指不完全确定，存疑。
