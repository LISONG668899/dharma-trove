# 歌（迪什迪嘉那·嘿噜巴说）

上师迪什迪嘉那说　据藏文译出

## 题解

本篇收于德格版丹珠尔续部释 ཟི 函第 7a 页（东北目录 D2359）。开头没有梵藏题名，只有"敬礼佛陀"；跋语作"上师迪什迪嘉那亲口之歌，圆满"，没有记载译者。作者迪什迪嘉那，与紧接在前的《金刚歌（迪什迪嘉那）》（D2358）是同一人，生平不详。

全篇约十五句，共四段，以"不可思议啊——成就者嘿噜巴这样说：以想要守护的心，是认不出自性之相的"为叠句。四段依次说：怎样观看就不能那样见到；何必以欲望之矛自刺；俱生之心是空性与悲心无二；它不生不灭，证悟自性就是了知根本之心。全篇的要点是：想要把握、守护某种境界的心，正是认识心性的障碍。全篇没有涉及具体的密法修持。

关于同名：德格丹珠尔 ཟི 函中，D2359 与 D2360 两篇的题名都只是"歌"（གླུ）。本站以括号区分：D2359 依作者与叠句，题为《歌（迪什迪嘉那·嘿噜巴说）》；D2360 依全篇"可叹""稀有"两种呼语交替的结构，题为《歌（可叹与稀有）》。

体例：藏文原文全部保留在代码框中，按段落分节，每节后附汉译；叠句照原文每次重复。凡标"存疑"的按语，表示本译对原文意思没有把握。藏文依 Esukhia 德格丹珠尔电子版。

## 礼敬

```
སངས་རྒྱས་ལ་ཕྱག་འཚལ་ལོ། །
```

敬礼佛陀！

## 一、所见非所观

```
ཇི་ལྟར་བལྟས་པ་དེ་ལྟར་མཐོང་བ་མེད། །
རྫུན་པ་མེད་པའི་སླུ་བ་འབའ་ཞིག་སྟེ། །
བསམ་མི་ཁྱབ་ཅིང་གྲུབ་སྨྲ་ཧེ་རུ་པ། །
སྐྱོབ་པའི་སེམས་ཀྱིས་རང་བཞིན་གཟུགས་མི་ཤེས། །
```

怎样去观看，就不能像那样见到；［它］只是没有虚假的欺诳而已。不可思议啊——成就者嘿噜巴这样说：以想要守护的心，是认不出自性之相的。

【按】"不可思议啊——成就者嘿噜巴这样说：以想要守护的心，是认不出自性之相的"，是全篇的叠句。"想要守护的心"，指执著、想要把握或保持某种境界的心；心性不能被这样的心所把握。

【按】存疑。"嘿噜巴"（ཧེ་རུ་པ），可能是作者自称，也可能指某位名叫嘿噜巴的成就者，或指嘿噜嘎本尊；"གྲུབ་སྨྲ"，本译读作"成就者说"，所指不能确定。

【按】存疑。"རྫུན་པ་མེད་པའི་སླུ་བ་འབའ་ཞིག"，字面是"只是没有虚假的欺诳"，语意吊诡：显现虽是欺诳（不实），却又没有刻意的虚假。本译照字面译出。

## 二、何以欲矛自刺

```
ཇི་ལྟར་དེ་ལྟར་གློ་བུར་གང་ལ་བཞག། །
འདོད་པའི་མདུང་གིས་རང་ལ་ཅི་སྟེ་ཟུག། །
བསམ་མི་ཁྱབ་ཅིང་གྲུབ་སྨྲ་ཧེ་རུ་པ། །
སྐྱོབ་པའི་སེམས་ཀྱིས་རང་བཞིན་གཟུགས་མི་ཤེས། །
```

就这样、就这样，忽然之间，要安放在哪里呢？为什么要用欲望之矛刺伤自己呢？不可思议啊——成就者嘿噜巴这样说：以想要守护的心，是认不出自性之相的。

【按】"用欲望之矛刺伤自己"，比喻因企求某种境界而自寻苦恼。前一句"忽然之间要安放在哪里"，大概是说心性本无处所，不必刻意把它安放在某处。所指不完全确定。

## 三、空悲无二之心

```
ལྷན་ཅིག་སེམས་ཏེ་མཁའ་ལུས་བདེ་སྙིང་ལུས། །
གཉིས་མེད་གཉིས་ཡིན་སྟོང་དང་སྙིང་རྗེའི་སེམས། །
བསམ་གྱིས་མི་ཁྱབ་གྲུབ་སྨྲ་ཧེ་རུ་པ། །
སྐྱོབ་པའི་སེམས་ཀྱིས་རང་བཞིན་གཟུགས་མི་ཤེས། །
```

俱生之心：是虚空之身，是大乐心要之身；无二而又是二，是空性与悲心之心。不可思议啊——成就者嘿噜巴这样说：以想要守护的心，是认不出自性之相的。

【按】存疑。"无二而又是二"（གཉིས་མེད་གཉིས་ཡིན），文义吊诡，本译理解为：空性与悲心在本质上无二，在作用上又可以分说为二。

## 四、不生不灭，知根本心

```
དེ་ནི་མི་སྐྱེ་མི་འགག་རྐྱེན་མེད་དེ། །
རང་བཞིན་རྟོགས་ན་རྩ་བའི་སེམས་ཤེས་ཡིན། །
བསམ་གྱིས་མི་ཁྱབ་གྲུབ་སྨྲ་ཧེ་རུ་པ། །
སྐྱོབ་པའི་སེམས་ཀྱིས་རང་བཞིན་གཟུགས་མི་ཤེས། །
```

它不生，不灭，没有因缘；若证悟了自性，就是了知了根本之心。不可思议啊——成就者嘿噜巴这样说：以想要守护的心，是认不出自性之相的。

## 跋语

```
བླ་མ་དྷིཥྚི་ཛྙཱ་ནའི་ཞལ་སྔ་ནས་ཀྱི་གླུ་རྫོགས་སོ། །
```

上师迪什迪嘉那亲口之歌，圆满。
