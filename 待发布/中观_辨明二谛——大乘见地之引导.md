# 辨明二谛

**大乘见地引导**

*华智仁波切 著*

对于希求解脱的人而言，需要了解两方面的教授：（一）所证悟之义理的教授；（二）如何实修的教授。

## 一、所证悟之义理的教授

此中分为两个主题：一者，一切所知法的本来面目；二者，自心的本来面目。

### （一）一切所知法的本来面目

这又分为两个层面：世俗层面、胜义层面。

**1. 世俗层面**

总的来说，从最下层的无间地狱（极热地狱），一直到十地菩萨后得位（出定状态）中所显现的一切，统统属于世俗。

世俗又分为两种：颠倒世俗与正确世俗。

我们尚未踏上修行之道以前所感知的一切，都属于颠倒世俗。到了资粮道和加行道的阶段【译注：即"胜解行地"】，如果能将一部分证悟融入自身的体验，那就成为正确世俗；如果做不到，依旧是颠倒世俗。一旦登入初地以上，心前所显现的一切都是正确世俗——说它是"世俗"，是因为"唯现"（单纯的显现）尚未消失；说它"正确"，是因为已经直接照见了这些显现的虚妄本质。从初地到十地，这些显现一直都会呈现，原因是无始以来执实（把事物当作真实）的习气尚未彻底断除，就像麝香曾经放在容器里，即使取出来后，香味仍然会持续残留。最终，到了佛果的层面，当这些习气被彻底根除，便不再有任何二元对立的感知，唯一安住于远离一切戏论（概念造作）的究竟法界之中。

把我们所生活的这个器世间（外在环境）和有情世间（其中的众生）执为真实，这就是颠倒世俗。而作为对治，将一切众生观想为清净的本尊、将环境观想为清净的坛城宫殿，同时认识到这一切如梦如幻，这就是正确世俗。

**2. 胜义层面**

胜义的本质，就是远离一切戏论的法界（诸法的根本空间）。就其体性而言，本来没有任何分类，但仍然可以依据是否已经证悟了这个实相，而在名言上进行区分。因此，可以分为"本基胜义"（本来就如此的法性本身）和"证悟胜义"（使这个法性如实显露的证悟）。又可以分为：通过闻思而抉择的胜义、通过修行而亲身体验的胜义；凡夫以比量（推理）所推知的胜义、圣者以现量（直接体验）所亲证的胜义。还可以分为：随顺胜义（可以用语言描述的胜义）和非随顺胜义（超越概念、不可言诠的胜义）。

二谛的体验有三种方式：

在凡夫阶段，一切显现被执为自性实有，伴随着强烈的执取，这称为颠倒世俗。在圣者阶段，一切显现被了知为虚假欺诳的，不再有任何执取，这称为正确世俗。在佛果阶段，既没有凡庸的"显现"，也没有"不显现"的问题，关于"执取"或"不执取"的分别也完全不适用了，这称为胜义。

换一种方式来说：第一阶段既有显现也有执取；中间阶段有单纯的显现但没有执取；最终阶段则既无显现也无执取。

这三个阶段也分别被称为：无明（错误认知）、了知世俗的智慧、了知胜义的智慧。对于凡夫来说，了知世俗的智慧依赖于分析思维；但对于圣者而言，则是通过现量（直接觉知）来实现的。

虽然"了解"或"不了解"这类世间概念，并不真正适用于法性本身所安住的胜义空间，但我们仍然可以借用"了解"或"证悟"这样的词语来指称对这一状态的认识。

最终，我们需要证悟的是二谛不可分割的一体性。然而，如果只是说"世俗层面事物是存在的，胜义层面事物不存在"，那永远都不是中观正见。当我们真正证悟了正确世俗的唯一真实本性时，二谛就会不可分离地融为一体，超越"存在""不存在""常""断"等一切概念边执。正如《般若波罗蜜多经》所讲：世俗的真实本性，即是胜义的真实本性。

二谛的划分只是一种权宜方便，它基于两种不同心态（迷与悟）的视角，目的是为了便于理解。迷乱心识前所显现的种种法，被标名为"世俗"；而"胜义"指的是迷乱已经止息的心境——在那个境界中，连对"不存在"本身的丝毫概念关注都不存在。正如《入菩萨行论》【译注：出自该论第九品第34偈】所讲：

```
实有与非实，俱不住心前，
彼时无余相，无缘最寂灭。
```

实际上，在胜义法界——那究竟要证悟的大无分别、大简单之本性中——根本没有可以区分两个层面的基础，因而也就没有这样的划分。在佛果的究竟证悟中，同样没有二谛的划分。甚至我们当下所经验的迷乱显现，也并非由两个分开的层面构成；它只是显空无别、或者觉空无别的一味一体。

对此完全领悟和证悟，就是佛的智慧——法性本身的无二智（非二元的本觉）。通过分别了解二谛各自的特征，最终二谛会融合为不可分割的一体，这就是所谓"无二双运智慧"或"无住涅槃"等等。

### （二）自心的本来面目

虽然我们可能已经如上所述地了解了一切所知法的本来面目，但如果不了解能知之主体——也就是自己的心——的本来面目，那么一切法就仍然停留在被认知的对象的层面，这种了解将无法真正对治我们的烦恼。事实上，这种证悟本身反而会成为傲慢和自负的来源，只会进一步巩固我们的人我执（对自我的执着）。因此，我们必须认识那个拥有这些证悟的主体——那个心智、意识或觉知——的真正本性。

这分为两个方面：依二谛获得暂时的了解；获得二谛无别的究竟了解。

**1. 依二谛获得暂时的了解**

当我们了知了一切法的本来面目——在世俗层面，万法如幻，虽然显现却并非真实存在；在胜义层面，万法如同虚空，无法确立为存在或不存在；而且最终，二谛在远离一切概念边执的大中观——究竟法界中无别无分——此时，拥有这些了解的那个心或觉知，它本身是世俗的。正如寂天菩萨所讲：胜义非心境，说心是世俗。

拥有这种知性了解的心，可能会变得傲慢和自负。这种傲慢和自负正是魔的工具，只会损毁我们的见解。《显示不可思议佛境界经》讲道：

```
所谓"证得"实为无常之事，
所谓"证悟"不过傲慢之见。
无常也好，傲慢也好，皆是魔业。
自以为"我已证得此果"者，极为傲慢；
自以为"我已完全了悟"者，亦复如是。
```

能了知的世俗心——它的本性即是胜义。如果我们向内审视那个了知、觉察或思维的心的本性，根本找不到任何真实或实有的东西。事实上，它从来就是超越存在与不存在的、超越生灭的、超越来去的、超越常断的、超越过去现在未来的——因此它就是胜义实相本身。《迦叶请问经》讲道：心于内不可得，于外亦不存在，于内外之间也无法观察到。《弥勒请问经》也讲道：心无形相、无颜色、无处所，如同虚空。

**2. 二谛无别的究竟了解**

在心的究竟本性中，二谛是无别的。将二谛的概念施设于心的唯一本性之上，只不过是一种暂时性的名言安立而已。在本基——究竟法界中并不存在什么凡庸之心，因此没有可以施加二谛标签的基础。在果位——佛的智慧中也不存在凡庸之心，因此也无法用二谛来标记。甚至在迷乱众生心的明空本性中，我们也找不到这种区分，因为那里只有光明觉知与空性。这就是为什么我们必须证悟二谛无别。

尽管如此，由于只有先分别了解了二谛各自的特征之后，才能证悟它们的无别性，因此二谛的划分仍然是有意义的。

就这样，所知对境的本来面目——那个超越概念的大简单性——与心的本来面目——同样超越概念的大简单性——无别地融合在一起。在这个体验中，既没有人我（个体自我的概念）、也没有法我（现象实体的概念），一切内外诸法都如同无生的虚空，远离"存在""不存在""常""断"等任何概念构造；而且这个体验超越了"所见与能见""所证与能证"的二元对立。因此，这才是圆满的、无误的证悟。

## 二、如何实修的教授

此部分分为两个方面：最上根器者的直接修法；钝根者的次第修法。

### （一）最上根器者的直接修法

那些在过去世已经积累了福慧二资粮、具足深厚善根和福报的人，仅仅通过听闻二谛的引导就能获得证悟。对他们而言，只需持续保任（不间断地安住于）这个认识即可。在他们的入定状态中——远离了能知与所知的二元对立、超越了任何自我的概念——他们将以虚空般的方式安住，不涉任何关于二谛的概念造作。在这样的修行中，没有什么恶念需要清除，也没有什么善的心态需要刻意培养。正如弥勒菩萨所讲：

```
于此无可除，亦无丝毫增，
应如实观实，若见实则解。
```

随后，在后得位（出定状态），通过认识到所感知的一切虽然显现却毫无真实性，来保持二谛双运的如梦体验。同时，以如幻的菩提心、对一切尚未证悟此理的如幻如梦众生的慈悲，积累如幻的福慧二资粮，并为利益一切众生发起广大的回向和愿力。

### （二）钝根者的次第修法

根器较钝的人需要从"转心四思维"（四共加行：人身难得、寿命无常、轮回过患、因果不虚）开始，循序渐进地训练。如果不这样做，他们将永远无法超越对甚深证悟的概念性想象。

经中如此讲道：

```
一切思维与感知皆是世俗，
证悟其本性即是胜义。
能如此证悟的心是世俗，
心无真实自性即是胜义。
表示二谛的语言名称是世俗，
这些语言名称无真实自性即是胜义。
此二者的无二即是二谛双运。
在所知的本性与诸佛的智慧中，
连二谛双运也无法观察到，
因此称之为远离戏论的究竟法界。
在其中，人我与法我了不可得。
证悟这一点即是见地，
安住于此即是禅修，
出于对众生的悲悯而积累资粮即是行持，
二元感知消融于法界即是果位，
遍一切处的智慧即是功德，
任运成就利他即是佛行事业。
不要执着于文字和名相，以为那就是意义本身，
而应将心导向文字所指向的真实含义。
```

能经验万法的心本身毫无真实自性，因此我们说"无我""无众生""无个体""无作者"等等。在此语境中说"无"或"不存在"，意思是"存在"无法成立。然而，既然"存在"无法成立，"不存在"同样也无法成立，所以这个"无"字意味着：存在与不存在二者都无法成立。

这个感知对境的意识，不依赖于感官根门（眼耳鼻舌身），不从外境对象中产生，也不停留在中间任何地方。它既不在内也不在外。生起时不从任何地方来，消失时也不到任何地方去。它在生起的当下即是空的，在消失的当下也是空的。经中如此讲道：在那如实的观照中，丝毫法也不会显现。《般若波罗蜜多经》讲道：分别念是参与欲界、色界或无色界的活动，而无分别念则与三界中的任何一界都不相关。经中又讲：当不作任何造作之时，那才是所谓的"瑜伽行"；又讲：因此，保任远离一切法的平常心，即是无上之法；又问：何为无上之法？答：即是不执任何法的概念。《般若波罗蜜多经》讲道：既然无法观察到什么菩提，"菩提"只是一个名称；既然无法观察到什么佛果，"佛果"也只是一个名称。

证悟一切法如虚空般的本来面目中没有什么可以成为意识或智慧之对境的——这就是见地。以"无住而住"的方式安住于这个认知——这就是禅修。在后得位中，为如幻的众生积累如幻的福德资粮——这就是行持。心的如幻感知消融于法界——这就是究竟果位。

```
法界远离戏论，言语思维所不能及，
在其中，并没有什么"所知之对境"被"能知"所了知。
然而还是说有见地与禅修的修持，
就像虚空观照虚空，或天空禅修于自身。
在真实的本性中，没有心也没有显现，
但说"没有"恰恰表明：连存在与不存在的二分法也被超越了。
```

据说，对空性的甚深含义不感到恐惧，反而感到欢喜和信心，这是一个具缘者的标志——表明此人过去已经听闻和修习过这些教法，将会迅速证得觉悟。

```
实相本身，如天空般的法界，远离一切念头，
当它在超越言诠的本觉智慧中被证悟，
即是根本平等，远离分别与造作，
这就是三世诸佛的智慧心。
胜义——法性实相本身，犹如石女之子，
无有任何显现或呈现；它只是最根本的平常。
经验世俗中因缘所生的如幻现象——显空双运的魔术般的显现，
不取不舍、无所执着——
这就是将诸佛的智慧心带入自己的体验。
在你达到这般心之自在和成就之前，
请放下对物质财富的一切贪着，
像野鹿般栖身于僻静的山林和闭关处。
这是保持在修行道上永不退转的方法。
对一切顺逆内外境遇，
安住于无喜无悲、无贪无嗔之中，
则每一个经历都会极大地助益你的修行。
这就是如何获得对法性无生本性的稳固证悟。
当证悟心之如空本性的智慧
与不舍如幻众生的悲心
以见地与行持双运的方式汇合时，
无住大智（不执着任何一边的本觉智慧）将迅速现前。
```

《大般涅槃经》讲道：空性意味着既不感知"空"，也不感知"不空"。空性的自然光明可以显现为任何事物；由于它在显现的当下即是空的，显与空即是一体。这只有通过向内观照才能了知，它处于自己的自知觉智的领域之中。

玛吉拉准（断法传承祖师）讲道：

```
当丝毫也不去分别造作时，
怎么可能还会走入歧途？
粉碎你的一切概念，然后安住。
```

又讲道：

```
既然心并非二元的，
就以无所观的方式去看。
我们这个心，任何"看"都看不到它。
心的本性，任何"见"也见不着它。
实际上，连丝毫可以被"看"的对象
都不存在。
```

心的本性——空明一体、超越一切概念攀缘——即是真正的根本状态。由于这个远离概念构造、无法锁定的纯净觉知，其如幻的显现作为本有的表达而无间断地涌现，因此我们必须全然信赖这个超越执着的状态——在这个状态中，入定与出定之间没有分别，明与空融为一体——并通过实修将它铭刻于心。

*华智仁波切 撰*
