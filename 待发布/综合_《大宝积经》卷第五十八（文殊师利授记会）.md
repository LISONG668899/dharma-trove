# 《大宝积经》卷第五十八（文殊师利授记会）

唐·于阗三藏实叉难陀 译

## 文殊师利授记会第十五之一

【按】译者题署“大”字，元、明本无；“唐”，元本作“唐天后代”。本会异译有西晋竺法护译《文殊师利佛土严净经》（T0318）、唐不空译《大圣文殊师利菩萨佛刹功德庄严经》（T0319）。

#### 法会大众

如是我闻：一时，佛在王舍城耆阇崛山，与大比丘众一千人在一起。菩萨有八万四千位，以文殊师利菩萨、观世音菩萨、得大势菩萨为上首。又与七十二亿诸天众在一起，都趣向菩萨之道。又与四天大王、释提桓因、梵天王等以及他们的眷属，各有五万二千众在一起，也都趣向菩萨之道。有四位阿修罗王，各与无量眷属在一起。又与七万二千大龙王在一起，他们的名字是难陀龙王、优波难陀龙王、婆留那龙王、娑竭罗龙王、持大地龙王、无热恼龙王、高胜龙王、伏魔龙王、最胜龙王、月上龙王，这样等等为上首。又与无量夜叉王在一起，他们的名字是金毘罗夜叉王、阿吒薄拘夜叉王、苏支路摩夜叉王、妙意夜叉王、妙慧夜叉王、妙相夜叉王、普色夜叉王、不动夜叉王、有力夜叉王、大力夜叉王，这样等等为上首。那时王舍城的国王、大臣以及四众，天、龙、夜叉、人非人等，各以衣服、饮食、卧具、医药种种资具，在如来处恭敬尊重而作供养。

#### 世尊入王舍城

那时世尊在早晨穿衣持钵，与诸比丘以及百千天人大众前后围绕，前往王舍城阿阇世王宫。以佛的威神之力，放出百千种妙色光明，百千种音乐同时一齐演奏，降下众多妙花，优钵罗花、钵昙摩花、拘勿头花、芬陀利花缤纷而下。这时如来以神通之力，随所行之处涌出宝莲，大如车轮，以白银为茎，以真金为叶，以毘琉璃宝为其花须；在花台中有化现的菩萨结跏趺坐。这些菩萨与宝莲一同绕王舍城右旋七匝，而说颂道：


那时王舍城中男女老幼无量众生，听到这颂之后，都得开悟，各自携带香花、宝盖、幢幡、无量音乐，前往如来之所，一心瞻仰，踊跃欢喜，恭敬供养。于是世尊将要入城，脚踏门槛时，城中之地六种震动，降下众多妙花以及种种音乐。城中众生，盲者得以看见，聋者得以听闻，狂者恢复本心，裸者得到衣服，饥者得到饮食，贫者得到钱财。那时那些众生也不被贪欲、瞋恚、愚痴、憍慢所逼恼，以慈心相向，犹如父子。那乐音中说颂道：

#### 摧过咎菩萨问一法

那时王舍城有一位菩萨，是长者之子，名为摧过咎，在里巷中远远看见世尊相好奇特，端严澄明，诸根湛然寂静，观者无厌，安住于奢摩他，最上调伏，防护诸根如善调之象，正念不乱如清净的渊池，三十二相庄严其身。那位菩萨见了之后，生起极尊重的净信之心，便前往佛所，稽首双足，右绕三匝，退住一旁。又有无量百千众生一同前往佛所，无数诸天住在虚空中，合掌恭敬，尊重顶礼。这时摧过咎菩萨对佛说：“世尊！菩萨成就几种法，能迅速得到阿耨多罗三藐三菩提，随其所愿庄严清净佛刹？”

【按】“长者之子”，宫本作“长奇之于”。“住奢摩他”之“住”，宫本作“何”。“是时”之“是”，明本作“尔”。

于是世尊为了调伏众生，为了哀愍摧过咎，前往市肆，在大众中告诉他说：“善男子！菩萨成就一种法，能迅速得到阿耨多罗三藐三菩提，随其所愿庄严清净佛刹。善男子！是哪一种法？就是这菩萨对一切众生行大悲，以殊胜的志乐发菩提心。什么名为以殊胜的志乐发菩提心？应当这样说：若有已发菩提心的人，乃至微小的恶也终究不再作。不作什么？就是贪、瞋、痴以及在家的威仪调戏，都全部远离。若已出家，不再希望名利恭敬，安住于出家所修之行法。什么是出家所修之行法？就是如实悟入一切诸法。所悟的一切诸法是什么？就是蕴、界、处、有为、无为。怎样悟入？就是观察五蕴寂灭，如幻，空无所有；这样悟入时，不见有悟入，无觉无思，一切分别都全部寂灭。若对诸蕴这样悟入，便是悟入一切诸法。这名为出家所修之行法。菩萨这样修此行时，也不舍离一切众生。为什么？这菩萨如自己所观察的为众生宣说，而又不执著于法以及众生。善男子！这是菩萨成就一种法，能迅速得到阿耨多罗三藐三菩提，也令佛刹具足圆满。”

说此法时，摧过咎菩萨得无生忍，欢喜踊跃，升上虚空，高七多罗树。在那大众中，二千众生发菩提心；一万四千诸天以及人远尘离垢，于诸法中得法眼净。于是世尊熙怡微笑，从其面门放出种种颜色的光，照耀无量世界；照耀之后又回来，绕佛三匝，从顶上而入。这时阿难便从座起，整理衣服，偏袒右肩，右膝着地，在世尊面前说颂道：

```
自在力导师，到诸法彼岸，
一切智人尊，何缘现微笑？
善逝十力尊，能为诸利益，
三世悉明达，何缘现微笑？
了众生心行，上中下差别，
知诸想无碍，愿佛为宣说。
亿那由诸天，咸来顶礼佛，
愿发微妙音，充济诸渴仰。
胜定到彼岸，智慧亦复然，
远离于错谬，何缘现微笑？
百千诸天众，为法故来集，
无量诸比丘，合掌皆愿闻，
奏种种音乐，供养于如来。
善哉佛世尊，愿决众疑惑。
```
（大意：具自在力的导师，已到诸法的彼岸，一切智的人中尊，因何缘故现出微笑？善逝、十力尊，能作种种利益，三世都明了通达，因何缘故现出微笑？了知众生的心行，上、中、下的差别，了知种种想而无碍，愿佛为我们宣说。亿那由他诸天，都来顶礼于佛，愿发出微妙之音，充满救济诸渴仰者。殊胜的禅定已到彼岸，智慧也是这样，远离一切错谬，因何缘故现出微笑？百千诸天众为法而来集会，无量诸比丘都合掌愿闻，奏种种音乐，供养于如来。善哉佛世尊，愿为决断众人的疑惑。）

佛告诉阿难：“你现在看见这位摧过咎菩萨升上虚空了吗？”阿难说：“是的，已经看见了。”佛说：“善男子！这位摧过咎此后经过六万二千阿僧祇劫，在这个世界当得成佛，号为寂静调伏音声，劫名离热恼。那佛刹土的功德庄严，以及声闻、菩萨之众，也如不动如来的妙喜世界一样，没有差别。”

#### 阿阇世王宫说忿恼与无智

这时世尊与诸比丘到了阿阇世王宫，各按次第敷座而坐。那时国王便以种种饮食，亲手斟酌，供养世尊以及比丘僧，令他们都饱足；又以上妙衣服奉献如来，便在佛前坐于矮床座上，对佛说：“世尊！忿恨瞋恼从何而生？愚痴无智由何而灭？”

【按】“踞卑床座”之“踞”，宋、元、明本作“处”，宫本作“据”。

佛告诉大王：“忿恨瞋恼由我与我所而生。若不能了知功德与过失以及我与我所，名为无智。若如实了知那我与我所，这便是非智、非非智。大王应当知道，一切诸行来无所从，去无所至；若无来去，便无生灭；若无生灭，那智与无智也都没有了。为什么？没有少许法能了知生与非生。若离了能知，这便是知。”那时阿阇世王对佛说：“世尊！稀有！如来、应、正等觉这样善说，我现在宁可听闻佛法而中途夭折，也不愿徒然生存，寿命相续。”

#### 舍利弗请说庄严佛刹

那时世尊为阿阇世王劝发开晓，令他欢喜之后，从座而去，前往耆阇崛山，洗足之后敷座而坐，入于三昧。这时如来为了法施，在晡时从三昧起，诸大菩萨以及声闻众都从定中出来。于是文殊师利与四万二千位趣向菩萨乘的天子在一起，弥勒菩萨与五千菩萨众在一起，勇猛雷音菩萨与五百菩萨众在一起，这样一切菩萨以及诸声闻并阿阇世王，各带眷属，前后围绕，来到如来之所，顶礼佛足，退坐一旁。那时王舍城又有无量百千众生，都一同前往耆阇崛山，来到如来之所，顶礼佛足，退坐一旁。

于是舍利弗承佛的威神，从座而起，偏袒右肩，右膝着地，合掌恭敬，对佛说：“如来先前已在王舍城市肆之内，为摧过咎略说菩萨摩诃萨的功德庄严、清净佛刹。善哉世尊！唯愿广说：诸菩萨怎样行不退转的菩提之行，止息种种烦恼，庄严清净佛刹，圆满大愿，具足修行诸波罗蜜，远离声闻、辟支佛地，践行如来所行的足迹，降伏众魔，制伏诸外道，具一切智，转妙法轮。这样的菩萨乃至尚未得到一切种智时，就能决定利益安乐无量众生。世尊！现在这会中求菩提的善男子、善女人，听了这法之后，会欢喜修行。”

#### 世尊放光与东方法上菩萨来集

那时世尊这样思惟：“现在我所说的，不只是为了这现前的会众，所以应当示现神变。”这样想了之后，放出百千亿妙色光明，每一道光明普照十方百千亿国土，那些佛土所有的日、月、天、龙、摩尼、电、火的光明都被映蔽而不显现；而那一切大小铁围山、须弥山王以及其余诸山、丛林、树木，都被佛的光明所透彻，不能显现影子。这时如来又发出威德的謦欬之声，其声遍闻十方世界。

【按】“日月”之“月”，宫本作“日”。

那时东方距此八十四恒河沙数的佛刹之外，有一个世界名为普光明，那里现有佛，号为集吉祥王。那佛刹中没有声闻、辟支佛之名，唯有菩萨充满其国土，每一位菩萨各有百亿不退转菩萨作为眷属。那时那大众中有一位菩萨，名为法上。以什么义理名为法上？就是那位菩萨在大众前听法之后，升上虚空，高七多罗树，自己隐去身形，宣说菩萨藏法门，名为《陀罗尼金刚句》。那时那会中大众都这样想：“一切诸法只有其声。为什么？就如法上菩萨，不见其身相，只听到他的声音；这声音没有实体，如同那身相一样；既然离于见闻，便是法性。”说此法时，会中无量得忍的菩萨，远远看见那国土的法上菩萨；又看见这国土的佛放出光明，以及听到其声传到那世界。那些菩萨便一同前往集吉祥王如来之所，顶礼佛足，退住一旁。法上菩萨对佛说：“世尊！因为什么因缘而现出这未曾有的瑞相？”佛说：“善男子！西方距此超过八十四恒河沙数的佛刹，有一个世界名为娑婆，那里现有佛，号为释迦牟尼，为了召集十方世界的诸菩萨，从一切毛孔放出这光明以及謦欬之声。”法上菩萨对佛说：“世尊！我现在想前往娑婆世界，礼拜供养释迦如来以及诸菩萨，并想听法。”佛说：“可以去，现在正是时候。”

【按】“如来所”，元、明本作“如来之所”。

那时法上菩萨便这样想：“现在我以什么神变前往那里礼拜释迦如来？”这样想了之后，便入一切庄严身三昧。由于这三昧的威神之力，令这三千大千世界满是妙花，厚积及膝，百千种音乐同时演奏，宝幢、幡盖种种庄严，又以妙香普熏这世界，犹如他化自在天宫。这时法上菩萨现了神变之后，便与六十三亿大菩萨众前后围绕，譬如壮士屈伸手臂的工夫，从那国土隐没，出现在这世界中，来到如来之所，头面礼足，右绕三匝，在其来时的方位，以愿力化现莲花，坐在上面。

#### 南方宝掌菩萨来集

那时南方距此超过九十六亿那由他佛刹，有一个世界名为离尘，那里现有佛，号为师子勇猛奋迅，被无量大菩萨众恭敬围绕。在那大众中有一位菩萨，名为宝掌。以什么义理名为宝掌？就是那位菩萨在诸佛国土教化众生时，想用右手遍摸若干诸佛世界，便能随其所欲而成办；从他手中发出佛、法、僧之声，施、戒、忍、进、禅、慧、慈、悲、喜、舍之声，发出这样等等的百千亿那由他法宝之声。

【按】“法宝之声。尔时”五字，宫本无。

那时宝掌菩萨看见大光明，听到謦欬之声，前往那佛所，说：“世尊！因为什么因缘而有这瑞相？”佛说：“善男子！北方距此超过九十六亿那由他佛刹，有一个世界名为娑婆，佛号为释迦牟尼，为了演说佛刹功德庄严法门，召集诸菩萨，令他们听闻此法、摄受功德，所以现出这瑞相。”宝掌菩萨对佛说：“世尊！我们想前往娑婆世界，礼拜供养释迦如来以及诸菩萨，并想听法。”佛说：“善男子！何必去呢？为什么？那娑婆世界是具足三毒的苦恼众生所聚集之处。”宝掌菩萨对佛说：“世尊！那释迦如来、应、正等觉，见到什么义利，舍弃庄严清净的国土而示现于秽土之中？”佛说：“善男子！那佛如来往昔在长夜中这样说：‘愿我迅速成就大悲，常在弊恶众生之中成等正觉，转妙法轮。’”宝掌菩萨又对佛说：“世尊！那释迦如来竟能在往昔发起这样大悲难发之愿，示现于这样的恶世界中。这样的慈尊甚为难遇，我现在应当前往礼拜供养。”佛说：“可以，现在正是时候。然而善男子！你前往那国土，应当谨慎省察，不要自我毁伤。为什么？生于那世界的诸菩萨等虽然难遇，其余的众生心行险恶偏邪，难以调伏。”宝掌说：“那国土虽有忿恨怨仇，也无伤于我。假使一切众生尽未来际瞋恨骂辱，乃至以刀杖瓦石打掷，我都能承受，终不报复。”那时师子勇猛奋迅如来对那一切菩萨众说：“诸善男子！你们若能如宝掌一样，可以与他同行。”说这话时，在那会中有七万二千菩萨同声说：“我们一同前往娑婆世界。”宝掌菩萨便这样想：“现在我以什么神变前往那里礼拜释迦如来，又能安乐无量众生？”这样想了之后，便以右手覆盖这三千大千世界，降下种种饮食、衣服、车乘、金、银、琉璃、真珠、珂贝、珊瑚、璧玉，随众生心中所希望的都能充满；乐于闻法的，便令他们得以听闻，又使无量闻法的众生证得真实，也令无数病苦众生受殊胜微妙之乐。这时宝掌菩萨现了神变之后，与诸菩萨在一念之间从那国土隐没，出现在这世界中，来到如来之所，顶礼佛足，右绕三匝，在其来时的方位，以愿力化现莲花，坐在上面。

#### 西方胜智愿菩萨来集

那时西方距此超过七十二亿那由他百千佛刹，有一个世界名为摩尼藏，那里现有佛，号为摩尼积王。那佛刹土由清净琉璃所成，没有声闻以及辟支佛，唯有清净的大菩萨众；他们在琉璃地上去来坐立，都看见如来分明显现，如在明镜中看见自己的面像。这些菩萨在那地中看见佛世尊也是这样，看见之后便请法，佛便为他们宣说往昔的大愿，那些菩萨听法得忍。那时如来从眉间毫相的摩尼宝中放出大光明，遍照那国土，其中所有的日月光明都被映蔽而不显现，以花的开合作为昼夜。在那国土中有一位菩萨，名为胜智愿，遇到这光明之后，便前往佛所，说：“世尊！因为什么因缘而有这瑞相？”佛说：“善男子！东方距此超过七十二亿那由他百千佛刹，有一个世界名为娑婆，佛号为释迦牟尼，为了召集诸菩萨而现出这瑞相。”那时胜智愿听了这话之后，对佛说：“世尊！我们想前往娑婆世界，礼拜供养释迦如来以及诸菩萨，并想听法。”佛说：“可以去，现在正是时候。”那时胜智愿这样想：“现在我以什么神变前往那里礼拜释迦如来？”这样想了之后，便入三昧，令这三千大千世界三恶道的苦全部消灭，得到无上之乐，譬如比丘得到诸禅定。这时一切诸天、世人以及非人，都不被贪、恚、愚痴、种种见、我慢、忿恨、怒害、悭嫉、憍谄、覆藏所逼恼，都发起慈心。那时胜智愿菩萨现了神变之后，与四万二千菩萨在一念之间从那国土隐没，出现在这世界中，来到如来之所，头面礼足，在其来时的方位，以愿力化现莲花，坐在上面。

【按】“是时一切”之“是”，明本作“尔”。

#### 北方相庄严星宿聚王菩萨来集与娑婆之名

那时北方距此超过六万三千佛刹，有一个世界名为常庄严，那里现有佛，号为娑罗起王。那佛刹土从未听闻有女人之称，一切都是莲花化生，袈裟随身而有。那时佛为那些菩萨众宣说佛种性印法门。什么名为佛种性印？就是最初发菩提心；从此便具足菩萨戒，入菩萨藏，得陀罗尼，心无散乱，不离于舍，证入空性，正修无相、无所愿求，其性远离贪染，对蕴、界、处能够证入，所作随觉，乐求佛慧，对无生之性真实了知，证于诸法而无分别，具足正见，断除妄念，所以名为佛种性印。那时那大众中有一位菩萨，名为相庄严星宿聚王，本愿殊胜，若有众生见到他的身体，必定当得三十二相。那时那位菩萨遇到佛的光明以及听到其声，便前往佛所，顶礼双足，右绕三匝，说：“世尊！因为什么因缘而有这瑞相？”佛说：“善男子！在这南方超过六万三千佛刹，有一个世界名为娑婆，佛号为释迦牟尼，为了召集诸菩萨而现出这瑞相。”那位菩萨说：“为什么名为娑婆世界？”佛说：“那世界能堪忍贪、恚、愚痴以及种种苦恼，所以名为娑婆世界。”那位菩萨说：“娑婆世界的众生等，都能忍受恶骂、捶打等种种恼乱吗？”佛说：“善男子！那世界的众生少有能成就这样功德的，而多随顺贪、恚、愚痴、怨恨的缠缚。”那位菩萨说：“若是这样，那世界不应名为娑婆。”佛说：“相庄严星宿聚王！那佛刹土也有行菩萨乘的善男子以及善女人，曾供养无量诸佛，成就忍辱，将护众生，善于自我调伏；若有众生以种种苦恼来加害，都能含忍，终不放纵贪、恚、愚痴。善男子！由于有这样的诸善丈夫，所以那世界名为娑婆。又，那世界中也有众生具足众恶，少能悔过，其心粗猛，没有惭愧羞耻，不敬佛，不重法，不爱僧，当堕地狱、畜生、饿鬼；那释迦如来在这些下劣众生之中，都能忍受骂辱、嫌恨、诽谤、恼乱、恶言恐吓，心如大地，不可动摇，无所违逆；无论得到供养还是不得，心无高下，也无憎爱；所以那世界名为娑婆。”

【按】“动摇”，元、明本作“摇动”。

那时相庄严星宿聚王菩萨对佛说：“世尊！我们现在得大善利，不生在那弊恶下劣的众生之中。”佛说：“善男子！不要这样说。为什么？东北方有一个世界名为妙庄严忍，那里现有佛，号为大自在王，那国土的众生都具足一向的安乐，譬如比丘入于灭定，那里的安乐也是这样。若有众生在那佛土中亿百千年修种种梵行，不如在这娑婆世界中一弹指之顷对众生生起慈悲之心，所获的功德还多于那里，何况能在一日一夜安住清净之心。”

那时相庄严星宿聚王菩萨对佛说：“世尊！我们想前往娑婆世界，礼拜承事释迦如来以及诸菩萨，并想听法。”佛说：“可以去，现在正是时候。”那时相庄严星宿聚王菩萨便这样想：“现在我以什么神通之力前往那里礼拜释迦如来？”这样想了之后，在虚空中化成宝盖，覆盖这三千大千世界，百千万亿珠缨宝幡周匝垂布，在那盖中降下种种花，百千种音乐自然演奏；又令这会中的比丘、比丘尼、优婆塞、优婆夷、天、龙、夜叉、乾闼婆、阿修罗、迦楼罗、紧那罗、摩睺罗伽、人非人等，各自看见自身具足三十二相，显现于宝盖之中。那时相庄严星宿聚王菩萨现了神变之后，与十亿菩萨在一念之间从那国土隐没，出现在这世界中，来到如来之所，顶礼双足，右绕三匝，在其来时的方位，以愿力化现莲花，坐在上面。

【按】“珠缨”之“缨”，宋、元、明、宫本作“璎”。

#### 十方菩萨云集与弥勒请问

像这样乃至遍于十方，各有无量阿僧祇佛刹中的无量阿僧祇百千亿菩萨，看见大光明，听到謦欬之声，问了那些世尊，而来到这国土，顶礼佛足，各坐一旁，也是这样。又这世界中的帝释、梵王、护世、大威德天、诸龙、夜叉、乾闼婆、阿修罗、迦楼罗、紧那罗、摩睺罗伽等，都看见光明，都来到佛所，顶礼双足，退坐一旁。那时世尊现了神变之后，十方无量百千亿那由他佛刹中所有前来集会的菩萨，都看见这国土的功德庄严并佛的身量，菩萨、声闻以及受用之具，与自己本来的国土都同等，然而知道彼此的国土并不杂乱。

【按】“皆见此土”之“土”，明本作“上”。

那时弥勒菩萨便从座起，整理衣服，偏袒右肩，右膝着地，合掌向佛而说颂道：

```
名振十方智无量，
放大光明照世间，
一切众生共度量，
莫测人尊胜智慧。
十方无量亿菩萨，
为求法故咸来集，
而皆信乐诸法门，
愿佛演说令欢喜。
如来戒定及智慧，
名称普闻十方国，
演法无畏犹师子，
光遍虚空如日照。
一切天龙与罗刹，
及诸比丘比丘尼，
优婆塞众优婆夷，
合掌乐闻如来说。
过去未来及现在，
世尊于彼悉了知，
以胜解力拔群迷，
愿决疑惑令开晓。
```
（大意：名声振动十方，智慧无量，放大光明照耀世间，一切众生共同度量，也测不透人中尊的殊胜智慧。十方无量亿菩萨为了求法都来集会，都信乐种种法门，愿佛演说，令他们欢喜。如来的戒、定以及智慧，名称普闻于十方国土，演说法时无所畏惧，犹如师子，光明遍满虚空，如太阳照耀。一切天、龙与罗刹，以及诸比丘、比丘尼、优婆塞众、优婆夷，都合掌乐闻如来所说。过去、未来以及现在，世尊对于那些都完全了知，以殊胜的胜解之力救拔群迷，愿为决断疑惑，令其开晓。）

```
云何菩萨智慧行，
严净佛刹令光洁？
云何诸愿速成满？
今请如来为宣说。
云何无悭戒无缺，
能忍骂辱诸难事，
精进修行无懈倦，
解脱无量苦众生？
专心乐入三昧门，
游止清净禅宫殿，
处世利益而无染，
譬如莲花不著水？
云何智慧出世间，
开阐甚深微妙法，
降伏一切诸魔众，
速能具足奢摩他？
```
（大意：菩萨怎样行智慧之行，庄严清净佛刹，令其光洁？怎样令种种誓愿迅速成就圆满？现在请如来为我们宣说。怎样无悭、持戒无缺，能忍受骂辱等种种难事，精进修行而无懈倦，解脱无量受苦的众生？怎样专心乐入三昧之门，游止于清净的禅定宫殿，处于世间利益众生而无所染，譬如莲花不著于水？怎样以出世间的智慧，开阐甚深微妙之法，降伏一切魔众，迅速具足奢摩他？）
