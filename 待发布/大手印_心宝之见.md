# 心宝之见

阿阇黎卡纳巴 传　阿阇黎德达 造

## 题解

本篇出自德格版丹珠尔续部（རྒྱུད་འགྲེལ།）ཟི 函第46b叶第7行至第47a叶第6行，东北目录编号 D2431。全篇二十二句，每句约十五个音节，以“我是三界中独一无二的大勇士，世间人因愚痴而不了知，被愚痴之网所缚”为叠句。篇幅很短，所以把藏文原文全部保留在代码块中，按段落分开，每段后附汉译，疑难之处另以【按】说明。

梵文题名：Citta-ratna-dṛṣṭi-nāma（ཙིཏྟ་རཏྣ་དྲྀཥྚི་ནཱ་མ）。

藏文题名：སེམས་ཉིད་རིན་ཆེན་གྱི་ལྟ་བ（心性宝之见）。

【按】藏文题名直译是“心性宝之见”，本篇标题依通行译名作“心宝之见”。

【按】跋语说本篇“由阿阇黎卡纳巴传下，阿阇黎德达所造”。卡纳巴（ཀ་ན་པ），即黑行者（Kṛṣṇācārya、Kāṇha），在前面所译的《无二根本修习次第》跋语中称为“那波”，是恰雅歌集中署名最多的成就者。“德达”（དྷེ་ཏ）是音译，生平不详。跋语中“དྷེ་ཏ་ནས”的“ནས”，可能是作格助词的异用，也可能是名字的一部分。跋语没有记载译者。

【按】本篇通篇以第一人称“我”来唱，说一切神祇、一切宗派、三有、男女、上师弟子都是“我”的体性与幻化。这个“我”是心性本身的口吻，而不是外道所说的神我、梵我，也不是凡夫所执的自我。正因为这一点极易误解，所以在正文各段的按语中反复说明，读者阅读时务必留意。

## 正文

### 第一段：一切宗派皆是我的体性

```
བདག་ཉིད་བདེ་གཤེགས་ཁྱབ་འཇུག་དང་ནི་ལྷ་ཆེན་ཚངས་པ་རྣམས། །ཨ་ཏི་གཅེར་བུ་ཉི་མ་དང་ནི་གྲུབ་མཐའི་ངོ་བོ་དག། །
བདག་ནི་དཔའ་བོ་ཆེན་པོ་འཇིག་རྟེན་གསུམ་ན་གཅིག་པུ་ཡིན། །འཇིག་རྟེན་པ་ནི་རྨོངས་པས་མི་རྟོགས་གཏི་མུག་དྲ་བས་བཅིངས། །
བདག་ནི་དཔའ་བོ་ཆེན་པོ་འཇིག་རྟེན་གསུམ་ན་གཅིག་པུ་ཡིན། །
```

我自己就是善逝、毗湿奴、大天、梵天诸神；（也是）阿底、裸形者、太阳（崇拜者），以及一切宗派的体性。我是三界之中独一无二的大勇士；世间人因为愚痴而不了悟，被愚痴之网所束缚。我是三界之中独一无二的大勇士。

【按】本篇最需要注意的，是贯穿全篇的“我”（བདག）。依题名“心性宝之见”，这里说话的“我”，应当是心性本身，即人人本具的心性之宝，而不是外道所说的常住之“我”（神我），也不是凡夫执著的五蕴之我。作者是以心性的口吻来唱：一切显现、一切宗派、一切众生，都是心性的显现与游戏。读者千万不要把这里的“我”理解为实有的自我，否则就与佛法的无我义完全相违。这一解释是依题名与密乘道歌的通例推定的。

【按】“ཁྱབ་འཇུག”是毗湿奴（Viṣṇu），“ལྷ་ཆེན”是大天，即湿婆（Maheśvara），“ཚངས་པ”是梵天（Brahmā），都是印度教的主神。“ཨ་ཏི”（阿底）、“གཅེར་བུ”（裸形者，即耆那教天衣派）、“ཉི་མ”（太阳，大概指太阳崇拜者），都是当时印度的宗派。说这些都是“我（心性）的体性”，意思是：一切宗派所崇奉的对象，归根到底都不离心性的显现；并不是说这些宗派的见解都正确。

【按】这里的“阿底”与“裸形者”并列，看来是指某个外道宗派。前面所译甘巴拉的《不相属之见》第58句，也是“阿底与裸形者”并列，那里曾推测“阿底”或许指大圆满阿底瑜伽；对照本篇来看，“阿底”更可能是一个印度外道宗派的名称。确切所指仍然不明。

【按】叠句第二句“འཇིག་རྟེན་པ་ནི་རྨོངས་པས་མི་རྟོགས”，本段作“不了悟”（མི་རྟོགས），以下各段作“不了知”（མི་ཤེས），意思相近。本段的叠句第一句在段首、段尾各出现一次，原文如此。

### 第二段：三有即是我的游戏

```
སྲིད་པ་བདག་སྟེ་སྲིད་པར་རོལ་པ་བདག་གི་ངོ་བོ་ཉིད། །གར་བྱེད་མཉམ་ཉིད་ཀློང་དུ་འགྲན་ཟླ་མེད་པའི་རྣལ་འབྱོར་གནས། །
བདག་ནི་དཔའ་བོ་ཆེན་པོ་འཇིག་རྟེན་གསུམ་ན་གཅིག་པུ་ཡིན། །འཇིག་རྟེན་པ་ནི་རྨོངས་པས་མི་ཤེས་གཏི་མུག་དྲ་བས་བཅིངས། །
```

三有就是我，在三有中游戏的，就是我的体性；舞者安住于平等性的广界之中，是无与伦比的瑜伽。我是三界之中独一无二的大勇士；世间人因为愚痴而不了知，被愚痴之网所束缚。

【按】“སྲིད་པ་བདག་སྟེ”，“三有就是我”，依上一段按语，意思是：三有轮回的一切显现，都不离心性；在三有中游戏的，正是心性的妙用。

【按】“གར་བྱེད”，“舞者”，比喻心性的显现如舞蹈般自在变化，而舞者本身安住于平等性中不动。

【按】第7句德格版有异文“འདྲན”与“འགྲན”，依校正后的“འགྲན་ཟླ་མེད”（无与伦比）译出。

### 第三段：男女与成坏皆是我的幻化

```
སྐྱེས་པ་བུད་མེད་དག་ཏུ་སྣང་ཡང་བདག་གི་རྣམ་འཕྲུལ་ཡིན། །སྲིད་པ་ཆགས་པ་འཇིག་པ་དེ་ཡང་བདག་གི་རྣམ་འཕྲུལ་ཡིན། །
བདག་ནི་དཔའ་བོ་ཆེན་པོ་འཇིག་རྟེན་གསུམ་ན་གཅིག་པུ་ཡིན། །འཇིག་རྟེན་རྣམས་ནི་རྨོངས་པས་མི་ཤེས་གཏི་མུག་དྲ་བས་བཅིངས། །
```

显现为男人、女人，也都是我的幻化；三有的形成与坏灭，也都是我的幻化。我是三界之中独一无二的大勇士；世间人因为愚痴而不了知，被愚痴之网所束缚。

【按】“རྣམ་འཕྲུལ”，“幻化”“变现”，与前面所译《自性不成立口诀》结尾“这是心的幻化”用的是同一个词。

### 第四段：上师弟子皆是我

```
བླ་མ་སློབ་མ་བདག་ཉིད་བཤད་པར་བྱེད་པ་བདག་ཉིད་དེ། །དཔེ་དོན་བདག་ཉིད་སྡུག་བསྔལ་སྐྱོབ་པར་བྱེད་པ་བདག་ཉིད་ཡིན། །
བདག་ནི་དཔའ་བོ་ཆེན་པོ་འཇིག་རྟེན་གསུམ་ན་གཅིག་པུ་ཡིན། །འཇིག་རྟེན་རྣམས་ནི་རྨོངས་པས་མི་ཤེས་གཏི་མུག་དྲ་བས་བཅིངས། །
```

上师、弟子、我自己，以及宣说者，也都是我自己；喻与义、我自己，以及救度痛苦的，也都是我自己。我是三界之中独一无二的大勇士；世间人因为愚痴而不了知，被愚痴之网所束缚。

【按】这两句的意思是：能说的上师、所化的弟子、能喻的譬喻、所喻的意义、能救度者，都不离心性。这与大手印“自心即是上师”的说法相应。但这并不是说不需要上师；从心性的角度说一切不离自心，与在修道中依止上师，并不矛盾。

### 第五段：一即是多

```
ཁ་དོག་དུ་མར་སྣང་བ་དེ་ཡང་བདག་གི་ངོ་བོ་ཡིན། །ཀ་ན་སྨྲ་བར་བྱེད་པ་གཅིག་ཀྱང་དུ་མའི་ངོ་བོ་ཡིན། །
བདག་ནི་དཔའ་བོ་ཆེན་པོ་འཇིག་རྟེན་གསུམ་ན་གཅིག་པུ་ཡིན། །འཇིག་རྟེན་རྣམས་ནི་རྨོངས་པས་མི་ཤེས་གཏི་མུག་དྲ་བས་བཅིངས། །
བདག་ནི་དཔའ་བོ་ཆེན་པོ་འཇིག་རྟེན་གསུམ་ན་གཅིག་པུ་ཡིན། །
```

显现为种种颜色的，也是我的体性；卡纳所说的，虽然是一，也是多的体性。我是三界之中独一无二的大勇士；世间人因为愚痴而不了知，被愚痴之网所束缚。我是三界之中独一无二的大勇士。

【按】“ཀ་ན”，即卡纳巴（Kāṇhapa，黑行者），依跋语是本篇的传承上师，在这里出现，或许是以他的口吻来唱。“卡纳所说的虽是一，也是多的体性”，意思可能是：心性虽是一，却显现为一切多样的现象；一与多本来无二。

【按】本篇以“我是三界中独一无二的大勇士”结尾，首尾呼应。“独一无二”是就心性而说的，不是就个人的自我而说的。
