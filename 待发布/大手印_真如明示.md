# 真如明示

梅纪巴（阿阇黎无二金刚）造　据藏文译出

## 题解

《真如明示》（梵 Tattvaprakāśa，藏 de kho na nyid rab tu bstan pa，直译"真如之开示"）收于德格版丹珠尔续部释 ཝི 函第 120a 至 120b 页（东北目录 D2241），紧接在《真如宝鬘》（D2240）之后，同属梅纪巴的"无念法类"。跋语没有记载译者。

全篇十五颂六十句。可以看作《真如宝鬘》的一个补充：《真如宝鬘》判摄各宗的见解，本篇则集中回答一个问题——中观与瑜伽行宗（唯识）的根本分别究竟在哪里。作者的回答是：不在"离四边"，因为唯识师也说离四边的无二之识；而在于是否承许"无生"。

全篇大致可分为五部分：

第一颂礼敬。第二至五颂以眼翳者见空中毛发为喻：毛发本来没有，为了破除翳者的错觉，才说"没有"；而在真如中，既无可遮遣，也无可成立。第六、七颂说报身、化身依缘起与愿力利益众生，它们与法身不异，本性不造作。第八至十一颂辨中观与唯识：若不承许无生，中观便与唯识无别；单凭"离四边"也不能区分，因为唯识师同样主张离四边、无二、实有之识；中观所说的种种显现，是从真实际依缘起而生，不生、无实体，只是名言。第十二、十三颂转入密乘：自加持与光明二者合一，便离断见，这一果位无勤作地圆满佛位。第十四颂以龙树之说作结：诸法真如不生。第十五颂回向。

本篇第十颂"离四边的无二之识"一句，与《中观六颂》第一颂几乎同文，那里被判为有相论者的主张，可以互相参照。第十二颂涉及密乘圆满次第的名目，须依具德上师的灌顶与口授来理解。

体例：每颂先列藏文原颂于代码块中，再按完整的意义单元译出；为了便于理解而补的字，都放在方括号中。原文含混或可有两解之处，以"【按】"说明，不妄补内容。文末附通篇连读。

## 第一颂　礼敬智慧方便

```
སངས་རྒྱས་སྐུ་གསུམ་ངོ་བོ་ཅན། །
གང་གི་མཐུ་ལས་སྐྱེས་གྱུར་པ། །
སྲིད་དང་མྱ་ངན་འདས་པ་མཆོག །
ཤེས་རབ་ཐབས་བདག་ལ་ཕྱག་འཚལ། །
```

那以三身为本体的佛陀，是从它的力量而生起的；［它是］超胜于三有与涅槃的——我顶礼这智慧与方便的体性。

【按】"智慧与方便的体性"（shes rab thabs bdag），即智慧与方便无二，是佛的根本。第三句"超胜于三有与涅槃"（srid dang mya ngan 'das pa mchog），也可以理解为"三有与涅槃中的最胜者"，或"三有与涅槃［平等］的最胜者"；这里依前者，意思是不住于轮回，也不住于寂灭。

## 第二至五颂　眼翳见毛之喻

```
སྐྱེ་བོ་རབ་རིབ་ཅན་དག་ལ། །
མཁའ་ལ་སྐྲ་ཤད་སྣང་བ་ལྟར། །
དེ་བཞིན་མ་རིག་མུན་བསྒྲིབས་པའི། །
བྱིས་པ་རྣམས་ནི་འགྲོ་སྙམ་སེམས། །
```

就像患眼翳的人，会看见空中有毛发一样，同样，被无明黑暗所遮蔽的凡愚，会以为有"众生"［在轮回中流转］。

```
འཁྲུལ་པས་མཁའ་ལ་མཚོན་པ་ཡི། །
སྐྲ་ལ་དག་པའི་མིག་གིས་ལྟ། །
མཐོང་བ་དག་པའི་རྣལ་འབྱོར་པས། །
སྲིད་པ་ཐམས་ཅད་དེ་ལྟར་རྟོགས། །
```

就像以清净的眼睛，去看那被错觉的人指着空中［说有］的毛发一样，见地清净的瑜伽士，也是这样证悟一切三有的。

```
ཀྱེ་ལགས་ནམ་མཁའི་དཀྱིལ་ལྟོས་དང་། །
སྐྲ་ཤད་འཛིངས་པ་བདག་གིས་མཐོང་། །
དག་པའི་མིག་ཅན་དེས་སྨྲས་པ། །
ཡོད་མིན་ཁྱོད་ཀྱི་བློ་གྲོས་འཁྲུལ། །
```

［眼翳的人说：］"喂，你看天空的正中，我看见一团缠在一起的毛发！"那眼睛清净的人说："［那］并不存在，是你的心错乱了。"

```
རབ་རིབ་ཀྱིས་འཁྲུལ་བསལ་བའི་ཕྱིར། །
ཕྱི་ནས་ཡོད་མིན་ཞེས་བརྗོད་ཀྱི། །
གསལ་དང་མི་གསལ་སྟོང་པའི་ཕྱིར། །
དེ་ཉིད་དུ་ནི་དགག་གྲུབ་མེད། །
```

［他］只是为了消除眼翳造成的错觉，才随后说"没有"；而因为［显现的］明与不明都是空的，所以在真如之中，既没有遮遣，也没有成立。

【按】"眼翳见毛"（rab rib skra shad），是佛教论典中常用的比喻，比喻凡夫所见的轮回诸法本来没有。这四颂的要点在第五颂：说"没有"，只是对治错觉的方便；在真如中，本来就没有一个"毛发"可以被否定，所以连"没有"也不能执著。"随后"（phyi nas），意思是"有了错觉之后，才说没有"，强调否定是为对治而后起的；也可以理解为"从外面"，存疑。"明与不明"（gsal dang mi gsal），可以理解为清楚显现的与不清楚显现的，也可以理解为证悟与未证悟两种心境；这与《梦教示》第七段"明与不明，在真性中都不可得"是同一个说法。

## 第六、七颂　二身与法身不异

```
དེ་བཞིན་ཟག་པ་མེད་ཆོས་རྣམས། །
ལོངས་སྤྱོད་སྤྲུལ་པའི་སྐུ་དག་གི། །
རྟེན་འབྲེལ་སྨོན་ལམ་དག་གིས་ནི། །
སེམས་ཅན་དོན་དུ་རབ་ཏུ་འཇུག །
དེ་དག་དེ་ལས་ཐ་དད་མིན། །
དེ་དག་དེ་ཡི་རང་བཞིན་ཕྱིར། །
དེ་དག་རང་བཞིན་མ་བཅོས་གྲུབ། །
དེ་དབྱེས་སེམས་ཀྱི་དོགས་པ་སེལ། །
```

同样，报身与化身的无漏诸法，依缘起与愿力，为了众生的利益而广作事业。它们与那［法身］并非不同，因为它们就是那［法身］的本性；它们是以不造作的本性而成立的；分别［说明］它们，是为了消除心中的疑惑。

【按】"同样"（de bzhin），承接上文：正如真如中无遮无立，二身的显现也不是在真如之外另有的东西。"那"（de），从上下文看应指法身，或指上一颂所说的真如；这里补为"法身"。末句"分别说明它们，是为了消除心中的疑惑"，意思是：说三身有别，只是为了回应人们"佛既无生，如何利生"一类的疑问，并不是说三身真有分别。

## 第八至十一颂　中观与唯识的分别

```
གལ་ཏེ་སྐྱེ་མེད་མི་འདོད་ན། །
ལྡོག་པས་དངོས་ལ་ཐ་དད་པས། །
རྣལ་འབྱོར་སྤྱོད་གཞུང་ལས་གཞན་པའི། །
དབུ་མའི་དོན་དུ་ཇི་ལྟར་འགྱུར། །
```

如果不承许"无生"，那么［中观与唯识的分别］就只是在［同一］事物上以反体所作的区分，这又怎么能成为有别于瑜伽行宗论典的中观之义呢？

【按】"反体"（ldog pa，梵 vyāvṛtti），是因明的术语，指同一事物在概念上的不同侧面，例如同一个瓶，从"非非瓶"的角度说是瓶，从"非非无常"的角度说是无常；反体之别只是概念上的区分，不是实质的不同。这一颂的意思是：中观若不承许无生，与唯识的差别就只是名言上的，而没有实质的分别。这是依上下文的理解，第二句的语法也可以理解为"以反体而于事物上作区分"，意思相同。

```
གལ་ཏེ་མཐའ་བཞི་རྣམ་སྤངས་པས། །
དབུ་མའི་དོན་ནི་ཁྱད་འཕགས་ན། །
རྣམ་རིག་ལ་ཡང་ཐལ་བར་འགྱུར། །
དེ་ཡང་འདི་དག་རྣམ་སྤང་ཕྱིར། །
```

如果说，因为远离了四边，所以中观之义更为殊胜，那么这对唯识［宗］也同样适用，因为它也远离了这些［四边］。

```
མཐའ་བཞི་ལས་ནི་རྣམ་གྲོལ་བའི། །
ཤེས་པ་གཉིས་མེད་རྫས་བདེན་པ། །
བརྟགས་པས་སྟོང་ཞིང་གཉིས་སུ་མེད། །
རྣམ་རིག་སྨྲ་བའི་མཁས་པས་རིག །
```

那远离四边的、无二的、实体真实的识，空于遍计、无二——这是唯识论的智者们所了知的。

【按】这两颂说明："离四边"并不是中观独有的标志，因为唯识师也主张一种离四边、无二的识。不过唯识师同时承许这识是"实体真实"（rdzas bden pa）的，这正是它与中观的根本分别。"空于遍计"（brtags pas stong），即唯识三性中，依他起性空于遍计所执性。

这一颂"离四边的……识"，与《中观六颂》第一颂"有一种远离四边的、刹那刹那的识，它是实有的……这是有相论者的主张"几乎同文，两处可以互证：梅纪巴认为唯识师虽然也说离四边，但仍以识为实有。

```
ཡང་དག་མཐའ་ལས་སྣ་ཚོགས་འདི། །
རྟེན་ཅིང་འབྲེལ་ལས་འབྱུང་བར་འགྱུར། །
དེ་ནི་མ་སྐྱེས་རྫས་ཀྱིས་སྟོང་། །
མ་འདྲེས་མིང་ཙམ་པ་ཉིད་དོ། །
```

［而在中观看来，］这种种［显现］，是从真实际依缘起而生起的；它是不生的，空于实体，不相混杂，只是名言而已。

【按】这一颂是中观的正说，与上一颂唯识的"实体真实"相对：中观认为种种显现依缘起而生，所以不生、无实体，只是名言安立。"真实际"（yang dag mtha'），即实相的究竟边际。"不相混杂"（ma 'dres），可能是说种种显现各自宛然、互不混淆，虽无实体而不乱；也可能是说真如不与诸法相混。这里依前者理解，存疑。

## 第十二、十三颂　自加持与光明合一

```
བདག་བྱིན་བརླབ་དང་འོད་གསལ་བའི། །
དབྱེ་བ་ཀུན་མཁྱེན་གྱིས་གསུངས་པ། །
གང་ཚེ་དེ་དག་གཅིག་བསྟན་པ། །
དེས་ནི་ཆད་པར་ལྟ་བ་སྤངས། །
འབྲས་བུ་དེ་ཉིད་མི་མཐུན་ཕྱོགས། །
གང་ལ་ཆགས་པ་ཡོད་མིན་པ། །
འབད་མེད་སྦྱོར་བ་དེ་ཡིས་ནི། །
སངས་རྒྱས་གོ་འཕང་དེས་རྫོགས་བྱེད། །
```

一切智者所宣说的自加持与光明的分别：当［上师］开示它们是一体的时候，便由此而断除了断见。那果位本身，对任何违品都不贪著；以那无勤作的修持，就由此圆满了佛的果位。

【按】"自加持"（bdag byin brlabs）与"光明"（'od gsal），是无上瑜伽续圆满次第的名目，在龙树所传的《五次第》中，自加持次第即幻身，光明次第即证悟空性的光明；二者合一，就是双运次第。本颂说：开示自加持与光明是一体，就能断除断见，因为证悟光明不是一片空无，而是与如幻的身智不二。"违品"（mi mthun phyogs），指与证悟相违的种种障碍；第五、六句的语法较松散，也可以理解为"那果位本身［即是］违品，［而］对它没有贪著"，存疑。这些属于密法的修持，须依具德上师的灌顶与口授来理解，不可凭文字揣度。

## 第十四颂　龙树之说

```
དེ་བཞིན་གཤེགས་པས་ལུང་བསྟན་པའི། །
འཕགས་པ་ཀླུ་སྒྲུབ་ཀྱིས་བཞེད་པ། །
སངས་རྒྱས་ཆོས་ཀྱི་རྗེས་འབྲངས་ཉིད། །
ཆོས་ཀྱི་དེ་ཉིད་མ་སྐྱེས་པའོ། །
```

如来所授记的圣者龙树所主张的，正是随顺佛陀之法的［见解］：诸法的真如是不生的。

【按】"如来所授记的圣者龙树"，指《楞伽经》等经中佛陀预言龙树将出世弘扬大乘。这一颂以龙树之说作结，呼应第八颂：中观的根本在于"无生"。

## 第十五颂　回向

```
དེ་ཉིད་རབ་ཏུ་བསྟན་བྱས་ལས། །
བདག་གིས་བསོད་ནམས་གང་ཐོབ་པ། །
དེས་ནི་འཇིག་རྟེན་མ་ལུས་པ། །
ཟུང་དུ་འཇུག་པའི་སྣོད་གྱུར་ཅིག །
```

## 通篇连读

敬礼文殊童子！

那以三身为本体的佛陀，是从它的力量而生起的，它超胜于三有与涅槃——我顶礼这智慧与方便的体性。

就像患眼翳的人会看见空中有毛发一样，被无明黑暗所遮蔽的凡愚，会以为有众生在轮回中流转。

就像以清净的眼睛去看那被错觉的人指着空中说有的毛发一样，见地清净的瑜伽士，也是这样证悟一切三有的。

眼翳的人说："喂，你看天空的正中，我看见一团缠在一起的毛发！"那眼睛清净的人说："那并不存在，是你的心错乱了。"

他只是为了消除眼翳造成的错觉，才随后说"没有"；而因为显现的明与不明都是空的，所以在真如之中，既没有遮遣，也没有成立。

同样，报身与化身的无漏诸法，依缘起与愿力，为了众生的利益而广作事业。它们与法身并非不同，因为它们就是法身的本性；它们以不造作的本性而成立；分别说明它们，是为了消除心中的疑惑。

如果不承许无生，那么中观与唯识的分别就只是在同一事物上以反体所作的区分，这又怎么能成为有别于瑜伽行宗论典的中观之义呢？

如果说因为远离了四边，所以中观之义更为殊胜，那么这对唯识宗也同样适用，因为它也远离了这些四边。

那远离四边的、无二的、实体真实的识，空于遍计、无二——这是唯识论的智者们所了知的。

而在中观看来，这种种显现是从真实际依缘起而生起的；它不生，空于实体，不相混杂，只是名言而已。

一切智者所宣说的自加持与光明的分别：当开示它们是一体的时候，便由此断除了断见。那果位本身，对任何违品都不贪著；以那无勤作的修持，就由此圆满了佛的果位。

如来所授记的圣者龙树所主张的，正是随顺佛陀之法的见解：诸法的真如是不生的。

我开示真如所得的一切福德，愿以此使一切世间众生，都成为堪受双运的法器！

《真如明示》，阿阇黎无二金刚造，圆满。
