# 弥勒菩萨《瑜伽师地论》卷第十八（思所成地）

弥勒菩萨说　唐三藏法师玄奘奉诏译

## 本地分中思所成地第十一之三

### 四、思择诸法（续）

【按】遁伦《瑜伽论记》说：体义伽他十四段，上卷已释五段；本卷释第六至第十三段全文，以及第十四段“论议”的少分。

#### 建立体义伽他第六段（类）：奖胜类生三颂

```
谁奖胜类生　及开出离道
于何住何学　不惧后世死
戒慧自薰修　具定念正直
断诸愁炽燃　正念心解脱
能奖胜类生　及开出离道
住此于此学　不惧后世死
```

（大意：问：谁能奖导殊胜种类的众生，并开示出离之道？住于什么、学什么，才不惧怕后世的死？答：具戒、具慧、自身薰修，具定、具念、正直；断除一切愁忧与炽燃，正念，心得解脱。这样的人能奖导殊胜种类的众生，并开示出离之道；住于此、学于此，就不惧怕后世的死。）

【按】遁伦《瑜伽论记》说：这三颂中，第一颂是问，后二颂是答。问中有五：一、奖导胜生；二、开示出道；三、于何师学；四、住何法学；五、不惧死。答中，前一颂半回答前两问，标出九种功德，既然成为胜人，就能奖导胜生、开示出道；后半颂回答后三问。

现在这颂中所说的胜类，就是四种殊胜上等的种姓：一、婆罗门，二、刹帝利，三、吠舍，四、戍达罗。以法、以正、以制、以导来教化胜类众生，所以名为奖。这里显示：唯有佛世尊能以法、以正、以制、以导来教化胜类众生。由于这个因缘，世尊自己显示唯有自己是真正的奖导者，所以为那天人这样说：具戒、具慧，以自薰修。又唯有世尊能为四种殊胜上等种类的众生，宣说出离一切众苦的圣八支道，这里世尊也是自己显示是真正的宣说者。

【按】遁伦《瑜伽论记》引泰师说：奖有四义：一、以教法，二、说正确的因果，三、以戒律制约，四、以三乘引导。基师说：以法，是道理；以正，是顺益；以制，是轨范；以导，是奖劝。又说：以法是教，以正是理，以制是以这教与理来制御，以导是训示，而不是以威严刑罚。

怎样是具戒？就是佛世尊过去作菩萨时，弃舍上妙之欲，舍离在家，受持身语的一切律仪。

怎样是具慧？就是在受持身语律仪而住时，生起这样的念头，内心正确思惟，深心筹量，审谛观察：现在这世间多遭艰苦，就是生、老等等，如经中广说。

怎样是自薰修？就是在往昔无量的其余生中，经过三大阿僧企耶劫，对六波罗蜜多修习、善修习；由于那个因缘，现在没有老师而自然心趣出离，又对于众缘所生的诸行，能以微妙之智随之悟入。

怎样是具定？就是能乃至离无所有处之欲，证得非想非非想处。

怎样是具念？就是依这样所得的殊胜之定，为了断除见所断的诸烦恼，修习四念住；就以这样所修的念住为其导首，乃至修习三十七种菩提分法。

怎样是正直？就是他生起逆流而正直的圣八支道，能断见所断的一切烦恼，在逆流之道中得以预入其流。

怎样是永断一切愁忧与炽燃？就是从谛现观之时同时就成为不还者，又能永断五下分结。瞋恚类似于随顺愁忧，贪欲类似于随顺炽燃，这些都已永断。

怎样是正念？就是为了永断上分诸结，又进一步修习四种念住，乃至修习三十七种菩提分法。

怎样是心解脱？就是由于已永断上分结，对于两种障心善解脱，就是烦恼障与所知障。他的心这样善得解脱，便成为如来、应、正等觉，广说如经。

由于这个缘故，能奖导胜类众生，开示出离之道。所有四种胜类中，任何一种对这圣教爱乐正行，为了证得圣八支道而在三学中勤修学的人，他一定能证得圣八支道以及涅槃之果。由于证得了它，不惧怕未来的生老病死。

再者，现在应当略辨上面所说的义理。就是略显示：唯有佛世尊能使四类种姓迅速得到清净，因为他们若在这里能正确修行，不会徒劳无功。又显示如来的圣教是善说的正法与毗奈耶。又显示佛是天人的无上大师。应当知道这就是这里的略义。

#### 建立体义伽他第七段（举）：名誉珍财二颂

```
云何擅名誉　云何具珍财
云何获美称　云何摄亲友
持戒擅名誉　布施具珍财
谛实获美称　惠舍摄亲友
```

（大意：问：怎样能有好名誉？怎样能具足珍财？怎样能获得美称？怎样能摄受亲友？答：持戒能有好名誉，布施能具足珍财，谛实能获得美称，惠舍能摄受亲友。）

【按】“擅名誉”的“擅”字，宋、元、明、宫本以及知恩院本作“檀”。

怎样是持戒能有好名誉？就是如有一人，或男或女，具足尸罗以及贤善之法，乃至命终都断除杀罪、远离杀生，如经中广说；乃至十方所有沙门、婆罗门等，常常称叹。由于这个因缘，为诸国王、群臣、长者，乃至城邑聚落的人民所恭敬供养。

怎样是布施能具足珍财？就是如有一人，过去其余生中作了并增长了布施福业之事；由于这个因缘，今生生在巨富、有大财宝之家，乃至众多府库充盈积满。

怎样是谛实能获得美称？就是如有一人，不以虚假伪造的斗、秤、函等器具，不以谄诳、陵蔑、妄言等事来获取财宝；只以如法的作业技能，依法而不暴虐地获取财宝。他既然如此，众人都称扬说：“贤哉儒士！能以如法的作业技能获取财宝。”

怎样是惠舍能摄受亲友？就是如有一人，现前多有种种家产，远离悭吝的垢染，不吝惜资具，以正当的安乐使自己欢娱，乃至也使朋友、亲戚、耆长欢娱。那些人便相互佐助，为他获取财宝，守护并使之增殖。

再者，现在应当略辨上面所说的义理。就是略显示恭敬与利养两种因缘。持戒能有好名誉，显示恭敬的因缘；其余诸句，显示利养的因缘，就是由于因力、由于士用力、由于助伴力。应当知道这就是这里的略义。

【按】遁伦《瑜伽论记》说：因力，是布施；士用力，是谛实；助伴力，是惠舍。

#### 建立体义伽他第八段（池）：泉迳苦乐三颂

```
齐何泉止息　于何迳不通
世间诸苦乐　何处无余灭
若于是处所　眼耳及与鼻
舌身意名色　永灭尽无余
齐此泉止息　于斯迳不通
世间诸苦乐　是处无余灭
```

（大意：问：到什么地方泉水止息？在什么地方道径不通？世间的种种苦乐，在什么地方无余灭尽？答：若在某处，眼、耳、鼻、舌、身、意以及名色永远灭尽无余，到这里泉水止息，在这里道径不通，世间的种种苦乐，在这里无余灭尽。）

什么是泉？就是六触处。为什么？譬如泉池能生出种种水，系属于水的东西，都堪能接触受用；又能存养男女大小，下至禽兽，乃至只要一切尚未枯竭。六内触处也是这样，一切愚夫被六境界之触所接触受用；又能存养，乃至其中的种种贪爱之水尚未枯竭。

【按】遁伦《瑜伽论记》说：六处如泉，烦恼如水，是从泉中流出的。

什么是迳？迳有两种：一是烦恼迳，二是业迳。这里的迳，意思是说因。

什么是苦乐？就是或在现法中以六种触处为缘所生，或属于安适之受，或属于不安适之受；或在后法中，以烦恼所摄持的妙行与恶行为缘所生，或属于安适之受，或属于不安适之受。

在什么处所，这样的六处以及名色等无余灭尽？就是在无余依涅槃界中。如果是诸异生，泉、迳、苦乐一切都没有缺减，也还没有舍弃。如果是诸有学，已有缺减而尚未舍弃。如果是诸无学，迳以及未来的一切苦乐，既已缺减也已舍弃，不再现行；泉以及现法的一切苦乐，虽已缺减也已舍弃，然而由于还有余依，仍然现行。所以在无余涅槃界中，说它们一切无余灭尽。

再者，现在应当略辨上面所说的义理。就是略显示：现法中的因以及苦乐，后法中的因以及苦乐，在无余依涅槃界中都永远灭除。应当知道这就是这里的略义。

#### 建立体义伽他第九段（流）：越暴流五颂

【按】遁伦《瑜伽论记》说：这五颂分两部分：前两颂显示异生与有学渐次能越暴流；后三颂说明证得究竟之道，永越暴流。前两颂中，先问后答。答中，第一句说明异生由正信越过欲暴流，后三句都是有学越过其余三种暴流。

```
谁能越暴流　谁能超大海
谁能舍众苦　谁能得清净
正信越暴流　无逸超大海
精进舍众苦　智慧得清净
```

（大意：问：谁能越过暴流？谁能超过大海？谁能舍弃众苦？谁能得到清净？答：以正信越过暴流，以不放逸超过大海，以精进舍弃众苦，以智慧得到清净。）

现在这颂中，怎样是正信能越过暴流？就是如有一人，为了了知诸欲的过患，听闻佛所说或弟子所说的正法。听了这法之后，获得正信，便生起欲乐，为了断事欲与烦恼欲，于是能弃舍在家的事欲，以正信出家，趣入非家。出家之后，为了断除烦恼诸欲，远离而住。他由于炽然勤修精进，乃至修习正思惟，断除烦恼诸欲，得到离欲的定地。这样以正信为依、为导，便能越度诸欲的暴流。

怎样是不放逸能超过大海？就是对于那定始终不爱味，乃至也不坚著安住于其中；唯为了证得诸漏尽智而专注其心。由于这定心清净、鲜白、正直、调柔，能对四圣谛入于现观，乃至证得诸漏永尽。这样由于以不放逸为依、为导，能断色界、无色界所系的有暴流，以及断除一切无明与见两种暴流，所以名为超渡大海。

怎样是精进能舍弃众苦？就是如有一位已见谛迹的有学这样思惟：“我应当证得三界离欲，诸结永尽。”便达到远离，在那里勇猛精勤而住，不多让贪欲之缠安住其心。又能如实了知现在诸欲贪之缠的出离，从贪欲盖中清净修治其心，于是能断灭诸贪欲之缠，以及以贪欲缠为缘所生的心中种种忧苦。如贪欲盖，乃至疑盖，应当知道也是这样。这样以精进为依、为导，能舍弃众苦。

怎样是智慧能得到清净？就是他除灭了能染污心、乃至能障碍究竟涅槃的五种盖之后，就依于未至定，安住于未至定。以先前所得的苦、集、灭、道诸无漏智，在诸苦中思惟真实的苦，乃至在道中思惟真实的道，便得到无余的三界离欲，诸漏永尽。这样由于以先前所得的智慧为依、为导，能证得清净。

再者，现在应当略辨上面所说的义理。就是薄伽梵在这颂中，略显示异生先已离欲，后来在圣谛现观中得清净；以及显示有学以对诸圣谛的现观为先，然后离欲而得清净。应当知道这就是这里的略义。

```
谁超越暴流　昼夜无惛昧
于无攀无住　甚深无减劣
圆满众尸罗　具慧善安定
内思惟系念　能度极难度
诸欲想离染　亦超色界结
彼无攀无住　甚深无减劣
```

（大意：问：谁能超越暴流，昼夜没有惛昧，对于无攀无住的甚深之处没有减劣？答：圆满众多尸罗，具足智慧，善于安定，内心思惟，系念，能度过极难度的有顶。对诸欲想离于染著，也超越色界之结，他对于无攀无住的甚深之处没有减劣。）

现在这颂中，什么是暴流？就是四种暴流：欲流、有流、见流、无明流。

什么是无攀无住？就是诸爱永尽、离欲、寂灭、涅槃，以及灭尽定。为什么？所说的攀，是诸烦恼之缠；所说的住，是烦恼的随眠。在那处所两种都没有，所以说无攀无住，这是说涅槃无攀无住。又，想名为攀，受名为住；如果在某处两种都没有，就说那处无攀无住，这样显示灭想受定无攀无住。现在这义理中，意思取的是灭尽定。

怎样是圆满众多尸罗？就是善安住于身语律仪，修治清净的活命。

怎样是具慧？就是对苦圣谛如实了知，乃至对道圣谛也是这样。

怎样是善于安定？就是远离诸欲，乃至具足安住第四静虑，或者第一有的三摩钵底。

怎样是内心思惟？就是对二十二处数数观察，就是想：“我现在容貌服饰已改变常态，去除了俗人的形貌之好”，广说如经。

【按】遁伦《瑜伽论记》说：二十二处，如下文声闻地中广说。

怎样是系念？就是对二十二处数数观察时，依于沙门之想，恒常作、恒常转而现在前；由于这个因缘，为了断除其余的结，修习四念住。

怎样是能度极难度？就是由于一切结无余断除，能度过最极难度的有顶，因为那不是一切愚夫异生所能度过的。

怎样是对诸欲想得以离染？就是对下分诸结已断、已知。

怎样是超越色界诸结？就是对色界所系的上分诸结已断、已知。

怎样是对于无攀无住的甚深之处没有减劣？就是对于无色界或已离欲、或未离欲，已得到非想非非想处，堪能有力入灭尽定。有学与无学都可能有这种情况，所以不定说超越无色界之结。

再者，现在应当略辨上面所说的义理。就是薄伽梵在这颂中，略显示能得到最究竟之道，以及显示能证得第一住之道。应当知道这就是这里的略义。

【按】遁伦《瑜伽论记》说：能证得第一住之道，就是能证得灭尽定。

#### 建立体义伽他第十段（贪）：贪恚因缘四颂

```
贪恚何因缘　由何故欣戚
毛竖意寻思　如孩依乳母
润所生自生　如诺瞿陀树
别缚于诸欲　犹摩迦处林
是贪恚因缘　由斯故欣戚
毛竖意寻思　如孩依乳母
知彼彼因缘　生已寻除灭
超昔未超海　暴流无后有
```

（大意：问：贪与恚以什么为因缘？由于什么缘故而有欣喜、忧戚、身毛竖立、心意寻思，如孩子依于乳母？答：由润所生、由自种所生，如诺瞿陀树；分别系缚于诸欲，如摩鲁迦藤缠绕林木。这就是贪恚的因缘，由此而有欣喜、忧戚、身毛竖立、心意寻思，如孩子依于乳母。了知那种种因缘，生起之后随即除灭；超越了过去未曾超越的大海与暴流，不再有后有。）

【按】颂文作“摩迦”，长行作“摩鲁迦条”，指缠绕林木的藤葛之类。遁伦《瑜伽论记》说：这四颂中，第一颂是问，第二颂是答，第三颂是结，第四颂是对治除灭。

现在这颂中，什么是贪恚？就是如有一人，处在在家生活中，与可意的境界、可意的有情相遇，而生起贪著；与不可意的境界以及有情相遇，而生起瞋恚。

什么是欣戚？就是如有一人，对于佛所证的法毗奈耶，仓促地生起片刻的正信，不善观察前后得失，忽然自我激励，便弃舍家法，趣入非家。出家之后，与一般道俗混杂而住；于是对于过去未来的货财亲友追念思慕，忧戚缠心。

或者又有一人，不是由于正信，也不是由于自我激励而趣入非家；而是或被国王所驱迫，乃至或被不能活命的邪怖所恐吓，舍离在家。出家之后，从有正信的婆罗门、居士等那里，时时多获利养恭敬，深生爱味，私下想道：“我这一方法真是好妙诀，不劳耕种收获，不做商贾买卖，少受艰辛，足以活命。”他因为这样的利养恭敬，便自己欣悦，安然而住。

什么是毛竖以及意寻思？就是如有一人，不是由于自我激励，也不是为了活命而舍离在家；而是由于正信，捐弃家法，趣入非家。出家之后，不与道俗混杂而住，便达到远离，寂静闲居。他闲居的时候，或在尘雾之中，或在昏暗的夜分，看见大的云气，听到震雷之声；或遇到冰雹大雨、狮子虎豹；或遭遇凶恶狡猾的盗贼抢劫掳掠；或遇到非人前来扰乱逼迫，便生惊怖，身毛为之竖立。或者到了白天，对于那过去未来的妙欲与亲友，发起依于耽嗜的一切寻思，就是欲寻思，如经中广说，乃至与家世相应的寻思。这样已说了贪恚等事。

怎样是润生以及自生，犹如世间的诺瞿陀树？润名为爱水，以此为缘，能生起诸取。那贪恚等，一切都以此作为共缘。自，就是以贪恚为先、以寻思为后的各各差别的种子界性。

【按】遁伦《瑜伽论记》说：诺瞿陀树，本来从一粒种子生出，后来枝条长大，倒垂入地又生根；又有鸟吃了树子，落在树杈上，又生出许多树，根依附于树杈。这样辗转从本来一棵树生出许多树，水是它们的共缘。所以贪恚等都以润泽的爱作为共缘，以各自的种子作为别缘。

怎样是贪恚乃至寻思分别系缚于诸欲，犹如世间的摩鲁迦藤条缠绕林木？就是略说有六种别欲：

或有由身手之力所获得的现在事欲，就是在家者所有的诸欲；在这境界上，以此为缘，生起贪恚。

或有从他人那里所得的种种现在事欲，就是为了活命而出家者所有的诸欲；在这境界上，以此为缘，生起欣悦。

或有过去、未来的事欲，就是忽然自我激励而出家者所有的诸欲；在这境界上，以此为缘，生起忧戚。

或有其余的诸烦恼欲，略有两种，就是对于欲界的自体以及资养身命的。或有尚未断除的虚妄分别之贪，就是由正信而出家的人，寂静闲居，在尘雾与夜分所遭遇的种种事；在这境界上，以此为缘，便生惊怖，身毛为之竖立。或有尚未断除的虚妄分别之贪，就是这同一个补特伽罗到了白天，对于外在的色、声、香、味、触境，以此为缘，生起意地的一切寻思。

又有沙门或婆罗门，如实了知如前所说的贪与恚等以及它们的因缘，又能了知众缘所生之法的无常性之后，随其所生而不起贪著，随即弃舍、吐弃、断灭。由于离色界、无色界二界之贪，度过有暴流；由于离欲贪，度过欲暴流。这样的暴流过去未曾度过，现在既已度过，终究不会退转。

再者，现在应当略辨上面所说的义理。就是薄伽梵在这颂中，略显示三位：一是在家位，二是出家位，三是远离位。又略显示由共因缘与不共因缘所生的爱与恚，对于诸欲的两种别缚，以及断除的方便，和断除的胜利。应当知道这就是这里的略义。又这里面，贪、欣，以及依于耽嗜的一切寻思，应当知道属于爱品；恚、戚以及惊怖，应当知道属于恚品。

【按】遁伦《瑜伽论记》说：第四颂中，上半颂说明了知无常性之后不起贪著，是断除的方便；下半颂说明度过暴流之后终不退转，是断除的胜利。


#### 建立体义伽他第十一段（作）：真婆罗门五颂

```
应作婆罗门　谓断无纵逸
求弃舍诸欲　不悕望此有
若更有所作　非真婆罗门
当知婆罗门　于所作已办
诸身分劬劳　未极底未度
已得度住陆　无勤到彼岸
天汝今当知　此喻真梵志
谓永尽诸漏　得常委静虑
彼永断一切　愁忧及炽燃
恒住于正念　亦常心解脱
```

（大意：天人说：婆罗门应当作的，是断除放逸，求弃舍诸欲，不悕望这欲有。世尊答：如果还有更多应作之事，就不是真婆罗门；应当知道婆罗门是于所作已经办毕的。以诸身分劬劳，是尚未到底、尚未度过；已得度过、住于陆地，不再勤劳，是已到彼岸。天！你现在应当知道，这比喻真正的梵志：就是永尽诸漏者、得常委者、得静虑者；他永远断除一切愁忧与炽燃，恒常住于正念，也恒常心得解脱。）

【按】遁伦《瑜伽论记》说：这五颂中，第一颂是问，其余四颂是答。

现在这颂中，显示那天人依于世俗的诸婆罗门，向世尊说。就是说有种姓上的诸婆罗门，自称“我是真实的梵志”，计执梵世间为最究竟，悕求梵世，安住于色，常勤精进，心无懈倦，恒乐远离，寂静闲居，减省睡眠，修习静定，为的是断除事欲以及烦恼欲。由于那些种姓上的婆罗门计执梵世间为究竟，悕望梵世，不求欲有。

又显示如来依于第一义的婆罗门来回答那天人。如果婆罗门作了所应作的之后，还要屡屡再作，还有更胜上的应作之事，应当知道这不是真婆罗门。如果婆罗门证得了婆罗门所应作之事，超登一切萨迦耶的彼岸，安住于陆地，应当知道这是真婆罗门。

由此显示有学与无学都是婆罗门。有学有两种，就是对于欲界或尚未离欲，或已经离欲。

尚未离欲的，未得源底，未到彼岸，对于两种法还没有具足：一是尚未得到内心殊胜的奢摩他；二是虽已得到，增上慧法的毗钵舍那尚未善得清净。由于缺少内心的奢摩他，乘着如所得的圣道浮囊，为了证得内心的奢摩他，如运动双足一般勇猛精进；又为了使增上慧法的毗钵舍那善得清净，如运动双手一般勇猛精进。他这样勤修精进时，离欲界之欲，如同得到源底；证得阿罗汉，如同到达彼岸。

已经离欲的，已证得内心殊胜的奢摩他，也得到善净的毗钵舍那，唯为了进一步断除上分诸结而发勤精进，不是以诸身分精进。如果已经越度，成为阿罗汉，所作已办，离于勤劳功用，名为住于陆地，已到彼岸。

【按】遁伦《瑜伽论记》说：如果尚未离欲，为了度过欲流，运足动手发勤精进，名为未到底；如果已经离欲，名为得到源底，只需进而断除上分诸结，不必运手动足勤加精进，所以说“非诸身分”。

这就显示依于第一义的婆罗门略有三种：两种是有学，一种是无学。已究竟到达彼岸的婆罗门，名为永尽漏者。尚未离欲、以一切身分勤修精进的，名为得常委者。已经离欲、得到源底的，名为得静虑者。

得静虑者，由于永断一切下分结，已断除贪欲与瞋恚品的一切愁忧与炽燃。永尽漏者，由于永断修所断的诸烦恼，已善修习四种念住，恒常住于正念以及心解脱。他不是作了之后还要屡屡再作，也没有更胜的应作之事，所以说他名为第一义的真婆罗门。

#### 建立体义伽他第十二段（劬劳）：度暴流问答五颂

天人问：“苾刍！苾刍！已度暴流了吗？”

世尊告诉说：“是的，天！”

天人问：“无攀无住，已度暴流了吗？”

世尊告诉说：“是的，天！”

天人问：“苾刍！你现在是怎样无攀无住，已度暴流的？”

```
如如我劬劳　如是如是劣
如如我劣已　如是如是住
如如我住已　如是如是漂
天我如如舍劬劳
如是如是无减劣
如是广说鲜白品
此中祇焰颂应知
```

（大意：我越是劬劳，就越是减劣；越是减劣，就越是止住；越是止住，就越是漂溺。天！我越是舍弃劬劳，就越是没有减劣。这样广说清白品，应当知道这里是祇夜颂。）

【按】遁伦《瑜伽论记》说：这五颂中有三番问答。第一番问答说明佛已度暴流，天人称佛为苾刍；第二番问答说明佛无攀无住、已度暴流；第三番问答说明佛无攀无住、度暴流之相，其中先举障碍，后说对治。祇焰，就是应颂伽陀。

现在这颂中，无攀无住，就是涅槃、灭定，如前已说。

世尊依于过去示现修习菩萨行时，那些最极难行的苦行，不属于正确方便的勇猛精进；又依于示现坐菩提座时，对于不属正确方便的勇猛精进已断、已遍知，所以说这样的话：“天！你应当知道，我过去越是虚设劬劳，我就越是减劣；越是减劣，我就越是止住；越是止住，又越是被漂溺。”与此相反，应当知道是清白品。

这里显示：修苦行时，不属正确方便的勇猛精进，名为劬劳。行邪方便，善法退失，名为减劣。既已知道诸善法退失，停止邪方便，名为止住。舍弃诸苦行，另外寻求其他老师，于是在嗢达洛迦、阿逻茶等邪执之处随顺观察，所以名为漂溺。

后来又坐菩提座，弃舍一切不属正确方便的勇猛精进，一切善法于是得以增长。善法越是增长，就越是对于诸善法不生知足，无暇止住，对于所修所断辗转寻求更胜上微妙之法。既然由于这样不知足，就不再另求其余外道之师，无师自然修习三十七菩提分法，证得无上正等菩提，名为大觉者。这里的四种义，应当知道是依次配释“舍劬劳”等四句经文。

【按】遁伦《瑜伽论记》说：非方便，是尼健陀所行的每日只食麻麦的邪自苦行。嗢达洛迦，是猛盛的意思，就是旧译的郁头蓝子，世尊在他那里修非想定；阿逻茶，是逢遇的意思，就是旧译的阿蓝迦蓝，世尊在他那里修无所有处定。这显示苦行在乐行之前。四句依次是：坐菩提座下弃舍非方便精进，是第一句舍劬劳；善法得以增长，是第二句舍减劣；善法增长之后不知足，是第三句舍止住；由于不知足而不另求外道师，是第四句舍漂溺。

怎样又依于涅槃的无依无住来显示差别？就是不能度过诸烦恼的缠与随眠这暴流，略由四种原因。哪四种？就是最初有依于耽嗜的寻思。以依于耽嗜的寻思为依止，便有懈怠。又以懈怠为依止，住于异生之分。以住于异生之分为依止，随顺生死之流的贪爱势力，使人在五趣生死之河中顺流漂溺。由与此相反的四种原因，能度过暴流，应当如理了知。

怎样又依于想受灭定来显示差别？就是如有一人，先已证得想受灭定，又住于放逸，多住于想受，而不多住于诸想受之灭。由于这个因缘，退失灭定。由于退失，又回到并止住于下地的受生之因；由于住于那因，心便决定趣向那里所得之果。与此相反，应当知道是清白品的四句差别。

【按】遁伦《瑜伽论记》说：还复止住下地生因，就是退而重起第四静虑的烦恼；住于那因，便在欲界命终后生到第四静虑。如《对法论》说：“有没有圣弟子已离色界欲、得无色界寂静解脱定，后来又生到色界的？答：有，就是得灭尽定后退失，生到色界中。”这颂的意思是说：外道有邪劬劳等，我世尊已离生死的劬劳等；圣者退失时有劬劳等，不退的圣者一定已远离它们。

#### 建立体义伽他第十三段（得义）：独处寂静三颂

```
独臻阿练若　静虑弃珍财
为别有方求　为窥窬封邑
何不与人交　而绝无徒侣
得义心寂静　摧妙色魔军
我独处思惟　受最胜安乐
故不与人交　而绝无徒侣
```

（大意：天女问：你独自来到阿练若处，修习静虑，弃舍珍财，是另外有所图求，还是在窥伺封邑？为什么不与人交往，而断绝了一切徒侣？答：我已得义，心得寂静，摧伏了美妙色欲的魔军；我独处思惟，受最胜的安乐，所以不与人交往，而断绝了一切徒侣。）

【按】遁伦《瑜伽论记》说：这三颂中，前一颂半是问，后一颂半是答。

这是由天女所问的伽他。所说的得义，略有两种：一是证得沙门果之义，二是证得圣神通之义。由于第一种得义，超越一切生死大苦；由于第二种得义，证得八解脱，寂静思惟，现法乐住。又，由于第一种得义，降伏可爱妙色的魔军；由于第二种得义，独处思惟，受殊胜安乐。这里意在辩说圣神通之义。

为什么？就是如有一人，为了成办圣神通之义，为了使解脱清净圆满，依十遍处方便修行；由于这个因缘，使遍处定清净圆满，也使解脱辗转得以清净、圆满、鲜白，也能成办圣神通之义。他既已了知这已经成办，便自己通达“我的义已经办成，沙门果之义也已成就”，是真沙门。

他对于求财的人深深修习厌毁；对于诸城邑交游等处，了知其初、了知过患、了知出离，也能了知趣向出离之行。生起它们的因缘，名为初。无常、众苦、变坏之法性，名为过患。对欲贪调伏、断除、超越，名为出离。圣八支道，名为趣向出离之行。

如果有人对于这些不见其初，乃至不见趣向出离之行，由于这个因缘，对于具足珍财的有情等处不能厌毁，在城邑中交游，周旋不绝，却说那是心得寂静；对于出离在家、证得八解脱与静虑之定的人的内心寂静，反而生起诽谤。因此他对于内心寂静，不能善见、善知、善鉴、善达。第一义的内心寂静与此相反，就能善见乃至善达。

【按】遁伦《瑜伽论记》说：了知其初，是了知集谛之因；其下三种了知，依次是了知苦、灭、道。善见、善知、善鉴、善达，依次是集等四谛之智。

再者，现在应当略辨上面所说的义理。就是薄伽梵在这里略显示：诸受用欲的人、乐于杂住的人，不是第一义的内心寂静；如果有人证得八解脱定，远离诸爱味，名为第一义的内心寂静。应当知道这就是这里的略义。

#### 建立体义伽他第十四段（论议）之一：诸行无常颂

【按】遁伦《瑜伽论记》说：第十四段从“诸行无常”以下四十四颂，名为论议，因为是辩扬甚深之理，分为二十七段；本卷解释前五段，其余在下卷。

```
诸行无常　有生灭法
由生灭故　彼寂为乐
```

（大意：诸行无常，是有生灭之法；由于有生有灭，诸行寂灭才是安乐。）

现在这颂中，蕴以及取蕴都名为诸行。这里的意思，是在取蕴。这五取蕴略有三种，就是过去、未来、现在。

“诸行无常”，是说那些诸行本来没有而生起，生起之后随即灭去。如果是过去生、过去所得的诸自体中的一切诸蕴，由于都已过去，由于已经谢灭，由于生已没去，其体是无常。如果是未来生、未来所得的诸自体中的一切诸蕴，由于都尚未生，由于尚未生起，由于尚未灭没，由于可以生起，是有生之法。如果是现在生、现在所得的诸自体中，暂时住持、支持有情存活的一切诸蕴，由于都是死法，由于可被殒灭所灭，是有灭之法。

如果那些诸蕴在未来所得的自体中是有生之法，那么其中都没有任何所得的自体是常、是恒，乃至就会这样正住不变；只是刚一生起，生起之后随即灭去。如果诸有情在现法中永尽了未来诸蕴的因，由于一切未来自体的诸蕴都不再生起，名为彼寂。

又，这寂灭由两种因缘说为安乐：一是由于一切苦因已灭，一切粗重永远止息，在现法中安乐而住，所以说为安乐；二是由于未来生老病等一切众苦永得解脱，所以说为安乐。

再者，现在应当略辨上面所说的义理。就是薄伽梵在这里略说正见的依处以及正见之果。

又有另外的说法：就是略显示遍知的依处以及它的断灭。又略显示所遍知的法以及遍知。又略显示三世诸行所有的杂染，以及由于它们寂灭而有的清净。又略显示诸缘起之法以及缘起之灭。又略显示苦谛、灭谛。又略显示空与无愿两种解脱门的所依处所，以及显示无相这一解脱门的所依处所。

又略显示与圣谛现观相违的两种法得以断除的所依处。所说的两种法，一是随顺戏论，二是怖畏无戏论。又略显示不共于外道的两种对治之法。哪两种？一是所知无颠倒性，二是所证无颠倒性。

【按】遁伦《瑜伽论记》说：随顺戏论，是四种见，或苦谛下的一切烦恼；怖畏无戏论，是我见，或灭谛下的一切烦恼。这两种法与现观相违，其断除的依处就是苦谛与灭谛。所知无颠倒性，就是上半颂；所证无颠倒性，就是下半颂。外道执世间为常而诽谤涅槃，所以说这是不共的。

#### 建立体义伽他第十四段（论议）之二：无逸不死颂

```
无逸不死迹　放逸为死迹
无逸者不死　纵逸者常死
```

（大意：不放逸是不死之迹，放逸是死之迹；不放逸的人不死，放逸的人常死。）

现在这颂中，怎样是不放逸为不死之迹？就是如有一人，依四种所依建立四种守护，就是命护、身护、心杂染护、正方便护，这名为不放逸。以这不放逸为依、为持，涅槃资粮尚未圆满的，使它迅速圆满；已经圆满的，使他在现法中得般涅槃。

【按】“身护”的“身”字，宋、元、明、宫本作“力”。遁伦《瑜伽论记》也作“力护”，并说：由不放逸使命得保全，就立命护；由不放逸使身力得保全，就立力护；由不放逸使心离杂染，就立心杂染护；由不放逸修涅槃之道，就立正方便护。

怎样是放逸为死之迹？就是如有一位在家白衣，对诸欲境耽著受用，造作不善之业；或者有出家人，表现出四种无护，就是命无护，乃至正方便无护。这样的放逸通于两品，就是在家品与出家品。就以这放逸为依、为持，乐于受生之本的行，造作受生之本的业；因此而有生，生了之后寿尽而终，生了之后夭折而没。

怎样是不放逸的人不死，放逸的人常死？就是死有五种：一是调善死，二是不调善死，三是过去死，四是现在死，五是未来死。

如果是善于修习这不放逸的补特伽罗，在现在世由调善死而正在死时，就过去死而言，他已经死过，在过去世也是由不调善死而死；在现在世，不是由不调善死而死；在未来世，既不由调善死，也不由不调善死而死。所以名为不死。

如果是放逸的补特伽罗，在现在世由不调善死而正在死时，在过去世也是由不调善死而已经死过；在现在世，就由不调善死而死；在未来世，也将由不调善死而死。所以名为常死。

【按】遁伦《瑜伽论记》引景师说：阿罗汉今身虽然调善而死，这死也是由于过去不调善而死，所以有今天的死；在现在不是由不调善而死，在未来则两种都不由，因为不再受生。放逸的人现在不调善而死，也由于过去不调善而死，在现在与未来都是不调善而死。

再者，现在应当略辨上面所说的义理。就是薄伽梵在这里略显示：不放逸的人，是道谛、灭谛；放逸的人，是集谛、苦谛。又略显示处非处性、自业所作性：前半颂显示处非处性，后半颂显示自业所作性。又前半颂显示老师对于弟子作了所应作的，后半颂显示诸弟子们自己所应作的。

#### 建立体义伽他第十四段（论议）之三：寻思钻摇颂

```
众生寻思所钻摇
猛利贪欲随观妙
倍增染爱而流转
便能自为坚固缚
```

（大意：众生被寻思所钻凿摇动，有猛利的贪欲，随而观看美妙之相；加倍增长染爱而流转，便能自己作成坚固的系缚。）

现在这颂中，怎样是被寻思所钻凿摇动？就是如有一人，对于先前所得、先前所受用的诸欲境界，不正作意，生起不善的、依于耽嗜的诸恶寻思。

怎样是猛利的贪欲？就是如有一人，在过去其余生中修习贪欲，也多多修习；由于这个因缘，使他在这一生中，对于先前所得、先前所受用的诸欲境界，虽然正确作意，却被贪欲散坏其心。

怎样是随观净妙？就是如有一人，不善护其身，不摄诸根，不住正念，游行于聚落，看见非常年少、可爱美色的诸女人之后，便不如理地取其净妙之相；由于这个因缘，身心烧恼。

怎样是加倍增长染爱？就是由五种相貌，应当知道染爱在增长。哪五种？就是如有一人：即使对于下劣的诸欲境界，尚且生起猛利的诸贪欲之缠，耽著不舍，何况上妙的。又以非法、多以凶暴积集珍财，不以正法，也常摄受增上的众具。又对于轻贱无用之物尚且不肯舍，何况贵重的。虽然只为追求少劣的财物，尚且行众多的身语意之恶，何况多而殊胜的。又对于受持少许妙行，其心尚且没有趣向爱乐，何况广大的。又对于涅槃尚且不乐于听闻，何况想要证得。

怎样是坚固的系缚？就是由三种相，可知坚固的系缚：一是由于坚牢，二是由于被苦所触，三是由于长时随逐。在现法中，由于恶行之根贪、瞋、痴，可知系缚坚牢；在未来世，由于生在那落迦、傍生、鬼趣，可知被苦所触以及长时随逐。

再者，现在应当略辨上面所说的义理。就是略显示依于两种失坏之因，有两种失坏。

什么名为两种失坏之因？就是不正思惟之力与因力。什么名为两种失坏？就是方求失坏与受用失坏。

什么是不正思惟之力？就是随念先前所受用境界的因缘所生的不正思惟，或邪分别现前境界的因缘所生的不正思惟，或邪取其相的不正思惟，或就在那上面或住或行的不正思惟。

什么是因力？就是对可爱境界宿世串习的欲贪。

什么是方求失坏？就是如有一人，由于成就两种失坏之因，以非正法，或以凶暴，追求积集一切邪财。

什么是受用失坏？就是如有一人，对于先前所得的顺乐、顺苦、顺不苦不乐的诸境界中，或对其中一种生染、生著，广说乃至不知出离而受用；或对其中一种生起憎恚，被憎恚所蔽；或对其中一种生起愚痴，被愚痴所蔽。他由于这样被贪染所蔽，乃至被愚痴所蔽，行身语意的种种恶行；被贪、瞋、痴三种坚固的系缚所缠缚，也被那落迦、傍生、鬼等诸缚所缚。

又有另外的说法：就是被爱结所系的补特伽罗，略有七种杂染，应当知道都是贪爱所造作的，就是随念杂染、不自在杂染、境界杂染、热恼杂染、善趣相应杂染、恶趣相应杂染、诸见杂染。

什么是随念杂染？就是如有一人，不正确地随念先前所受用的可爱境界，悕望追求，使心散坏。

什么是不自在杂染？就是如有一人，由于宿世串习贪欲之法，今世贪欲本性猛利；虽然如理地对可爱境界随念作意，却有悕望追求的贪欲散坏其心。他由于贪欲极为猛利，心不自在。

什么是境界杂染？就是如有一人，游行于城邑等处，现前遇到容色端严的可爱境界；由于那境界极为端严，随着美妙之相，心识缠绵，因此生起悕望追求的种种贪爱。

什么是热恼杂染？就是如有一人，由于这三种能增长贪爱的杂染，使已有的贪爱辗转增盛；追恋过去已受用的境界，悕求未来当受用的境界，耽著现在正受用的境界，于是使身心周遍热恼。

什么是善趣相应杂染？就是正由于那贪爱集谛的增上力，行身语意的种种妙行，得生善趣，或天或人；他对于乐受耽著不舍，醉闷而住，专行放逸。

什么是恶趣相应杂染？就是正由于那贪爱集谛的增上力，行身语意的种种恶行，身坏命终堕入诸恶趣，生在那落迦等中；生在那里之后，便被种种极重的忧苦、恶心、愤心所扰恼。

什么是诸见杂染？就是正由于那贪爱集谛的增上力，遇到恶友宣说颠倒之法，为的是使人从杂染中得解脱。他虽然悕求从杂染中解脱，由于遇到这样颠倒所说之法，不能证得解脱；在六十二种见趣中，随其中一种邪见使之增长，因为对诸缘起之法愚痴增上。他由于被这样的见结所系，在五趣等生死大海中不得解脱。

#### 建立体义伽他第十四段（论议）之四：住法具戒颂

```
住法具尸罗　有惭言谛实
能保爱自身　亦令他所爱
```

（大意：住于正法，具足尸罗，有惭，言语谛实，能保爱自身，也为他人所爱。）

现在这颂中，怎样是住法？就是在如来所证、善说的正法毗奈耶中，以净信出家，乐修梵行。

怎样是具足尸罗？就是由于这样出家、这样爱乐，对于戒没有缺损，乃至没有杂染，相续而作、相续而转，对于诸学处能受能学。

怎样是有惭？就是对可惭之事生惭，对能生起恶不善法之事生惭，就是能随顺恶戒与穿穴之戒的因缘，即不正之相、不正的寻思，以及诸烦恼与随烦恼。

【按】“穴戒”的“穴”字，宋、元、明、宫本作“冗”，下同。遁伦《瑜伽论记》作“冗戒”，并说：能发起恶的身语，名为恶戒因缘，是染污恶劣的善戒，所以名为恶戒，并不是说戒体本身是恶；违犯诸善戒的根本，名为冗戒因缘。

怎样是言语谛实？就是发露诸恶，不隐藏诸恶。如果有所违犯，就在有智慧的同梵行者面前如实自举其罪，如法对治。

再者，现在应当略辨上面所说的义理。就是薄伽梵在这颂中，略显示由四种因所摄的尸罗清净：就是由于能正确受戒；由于受戒之后不使穿穴；由于远离穿穴之因；由于即使因无知、放逸而有穿穴，随即如法对治。应当知道这就是这里的略义。

#### 建立体义伽他第十四段（论议）之五：见他恶业颂

```
若见他恶业　能审谛思惟
自身终不为　由彼业能缚
```

（大意：如果看见他人的恶业，能审谛思惟，自己终究不去作，因为那业能系缚。）

现在这颂中，怎样是看见他人的恶业而审谛思惟？就是如有一位善男子或善女人，本性聪慧，成就如理谛观的法忍。看见他人因为现行恶行的缘故，便遭受种种挫辱鞭打，又被王家的人抓到国王那里，广说如经，乃至断命。看见之后便这样思惟：“看看这个人，在现法中造作这样的恶不善业，就在现法中又受到这样辛楚的果报。”乃至：“止住吧，止住吧！这样的恶不善业，终究不应为，终究不应作，终究不应行，终究不应犯。”

他又看见屠宰羊、鸡、猪的人，广说一切不律仪之众。不能由这样的作业技能、活命方术而乘坐象、马、车乘、辇舆，又不能由此获得广大的财宝库藏并使之不散失，而且被世间所诃毁；就连一般的佣仆俗人，尚且不让自己的身体与他们稍有接触，而远远避开，何况其余贤哲。看见之后便这样思惟，其余如前所说。

他又看见他人巨富，有大量财宝；然而由于懒惰，多住于放逸，经过日夜，积累岁月，所有的珍财、僮仆、基业，以及诸善法，渐渐衰退。看见之后便这样思惟，其余如前所说。

他又看见种种有情的身相差别：或有天生盲、天生聋、天生哑，或瞎、或跛、或患癣、或患癞，或者短寿、或形色丑恶、或多疾病、或生在贫贱之家、或亲属稀少、或智慧低劣、或是扇宅迦、或是半宅迦、或形类丑陋，其余的人则不是这样。看见之后便这样思惟：“看看这个人，先前造作种种恶不善业，现在受到这样的苦恶果报。”乃至：“止住吧，止住吧！这样的恶不善业……”其余如前所说。

他又看见他人聪慧，没有懒惰，具足勤勇，就是能作耕种、商贾、行船等事业，以及能正确从事言论事业。他虽然具足这样的勤勇，所作事业却渐渐衰损，终究没有成办。看见之后便这样思惟，其余如前所说。

他又看见两个人出家，趣入非家，共同修行梵行：一个人在衣服、饮食等利养上有所匮乏，另一个人则不是这样。看见之后便这样思惟，其余如前所说。

他又看见或是国王，或是与国王同等的人，把大地疆域全都征服，坚著不舍；只为了一个身体、一具骸骨，只为了现在少许的安乐，在身语意门中现行无量广大的恶行，损坏多生多身的安乐，将要受多生多身的大苦。看见之后便这样思惟：“看看这国王或与国王同等的人，实在愚昧，只知保爱一生一身，不知保爱多生多身；只爱现在短时的小乐，不爱未来长时的大乐，也并不是不爱多生的重苦。”乃至：“止住吧，止住吧！这样的恶不善业，终究不应为，终究不应作，终究不应行，终究不应犯。”

又有或善男子、或善女人，本性聪慧，获得天眼；用这天眼看见诸有情死时、生时，如经中广说，乃至生在大那落迦中。看见之后便这样思惟：“看看这个人，在现法中造作这样的恶不善业，使他受后法辛楚的果报。”乃至：“止住吧，止住吧！这样的恶不善业……”其余如前所说。

这样，或善男子、或善女人，看见他人所作的诸恶业之后，由四种行来谛善思惟、谛善观察。哪四种？

一是观察：或由于违越，或由于邪命，或由于放逸懈怠，在现法中造作种种恶不善业，就在现法中受到不可爱的果报。

二是观察：或有有情依于身相的差别，或有所作而不能如愿，或有所求而不能如愿，都是由于先前造作恶不善业，所以在现法中各自受到这样不可爱的果报。

三是观察：或有国王，或与国王同等的人，由于在现法中行诸恶业，比类可知未来必定要受种种不可爱的果报。

四是观察：诸有情类死时、生时，由于在现法中造作种种恶不善业，在后法中受到不可爱的果报。

他由于这样如实了知，终究不自己去作。

怎样是业缚？就是由于乐于诸业，由于业重，由于对于业的果报不得自在。

乐于诸业，就是如有一人，由于串习恶，爱乐诸恶；由于这个因缘，心不能进入诸善法。这是第一种业缚。

由于业重，就是如有一人，对于无间业，或者全部造作，或者没有全部造作；由于这个因缘，虽然欣乐在佛所证、善说的正法毗奈耶中出家，连暂时出家尚且不能得到，何况能获得沙门果证。这名为第二种业缚。

对于业的果报不得自在，就是如有一人，由于身语意恶行的因缘，生于诸恶趣；生在那里之后，不得自在，不能自主，长夜受苦；或者生在边地，那里完全没有四种贤善之众，就是苾刍，广说乃至邬波斯迦。这名为第三种业缚。

再者，现在应当略辨上面所说的义理。就是薄伽梵在这里略显示：依于诸有情的业以及业的果报如理思惟；以及显示以如理思惟为先的法随法行。应当知道这就是这里的略义。

瑜伽师地论卷第十八

## 本卷要义

本卷解释体义伽他第六段到第十三段，以及第十四段“论议”的前五段。

第六段“类”，说明唯有佛能奖导四姓、开示出离之道。论中以九种功德追述世尊成佛的次第：菩萨时具戒、具慧，三大劫修六度而自薰修，先以世间定离无所有处欲，见道时即成不还，再修念住断上分结，最后对烦恼障、所知障心善解脱。

第七段“举”，把世间的名誉与财富，归于持戒、布施、谛实、惠舍四因，所以佛法并不排斥世间的正当利养，只是要以正法得之。

第八段“池”，以泉比喻六触处、以迳比喻烦恼与业，说明异生“无缺无舍”，有学“缺而未舍”，无学“迳亦缺亦舍、泉虽缺舍犹现行”，到无余依涅槃界才一切灭尽。

第九段“流”，正信、不放逸、精进、智慧四法，分别对应异生先离欲后现观、有学先现观后离欲两条路；后三颂讲到灭尽定，说明“无攀无住”有涅槃与灭定两种解释，本处取灭定。

第十段“贪”，以诺瞿陀树比喻爱为共缘、种子为别缘，以藤缠林木比喻六种别欲，把在家人的贪恚、仓促出家者的忧戚、为活命出家者的欣悦、真心出家闲居者的惊怖与寻思，一一对出。

第十一段“作”，区分世俗的种姓婆罗门与第一义的婆罗门：未离欲的有学以手足勤劳，已离欲的有学已得源底，阿罗汉住于陆地、到达彼岸。

第十二段“劬劳”，是世尊亲述的修道经历：苦行越劬劳越减劣，转而依外道修定又被漂溺，坐菩提座舍弃非方便精进之后，善法增长而不知足，于是无师自证。

第十三段“得义”，说明独处寂静的真意，是沙门果义与圣神通义。

第十四段论议的前五颂中，“诸行无常”一颂，以三世分析生灭，以现法乐住和永脱当来众苦两种因缘说“彼寂为乐”；“无逸不死迹”一颂，以五种死分别无放逸者“不死”、放逸者“常死”；其后三颂，说寻思钻摇、坚固系缚与七种杂染，说四因清净尸罗，说由见他恶业四种观察而终不自作。“观观是人……止止如是恶不善业”的反复，是本卷最有警策力的文字。
