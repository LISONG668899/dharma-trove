# 离忧之见

阿阇黎马希拉 传　杜日 造

## 题解

本篇出自德格版丹珠尔续部（རྒྱུད་འགྲེལ།）ཟི 函第48a叶第4行至第48b叶第4行，东北目录编号 D2434。全篇五十二句，每句七个音节，另有礼敬和跋语。篇幅很短，所以把藏文原文全部保留在代码块中，按段落分开，每段后附汉译，疑难之处另以【按】说明。

梵文题名：Śoka-vinodi-dṛṣṭi-nāma（ཤོ་ཀ་བྷི་ནོ་བྷི་དྲྀཥྚི་ནཱ་མ），拼写似有讹变，照录不改。

藏文题名：མྱ་ངན་གྱི་ལྟ་བ（悲伤之见）。

【按】藏文题名只说“悲伤之见”（མྱ་ངན་གྱི་ལྟ་བ），梵文题名中的“śoka-vinodi”（若读作 śoka-vinoda）则有“遣除忧伤”之义，本篇标题依通行译名作“离忧之见”。从内容来看，全篇是弟子们哀悼上师逝世、并度脱上师仇敌的悲歌，藏文题名的“悲伤”更贴近正文；“离忧”或许是指在悲伤中见一切无实而离忧。两说并存。

【按】跋语说本篇“由阿阇黎马希拉（མ་ཧི་ལ）传下，杜日（དྷའུ་རི）所造”。依正文第47句“黑上师（ནག་པོ）”，本篇所哀悼的上师应是黑行者卡纳巴。诗中出现的马希拉、摩尼跋陀罗、达玛、杜玛，大概都是黑行者的弟子，其中有几位与八十四大成就者中的人物同名。“杜日”生平不详。这些对应都只是依名字推定。跋语没有记载译者。

【按】本篇记述弟子们以密法“度脱”加害上师的女子巴呼日的事。密乘中的“度脱”，是只有极高证量的成就者，以悲心将造极重恶业者的神识度脱至净土的特殊行为，在传统中受到极严格的限制，绝不是一般修行人可以效仿的，更不是对世间杀戮的认可。本篇是成就者故事中的悲歌，译出以供了解印度成就者的历史与道歌，读者务须从这一角度理解。

## 礼敬

```
བླ་མ་རྣམས་ལ་ཕྱག་འཚལ་ལོ། །
```

敬礼诸上师！

## 正文

### 第一段：与上师分离，显现隐没

```
བདག་གི་ཕུང་པོ་ངན་པ་འདི། །བླ་མ་ཧཾ་དང་བྲལ་འགྱུར་བས། །སྣང་བ་རྣམས་ནི་ནུབ་པར་འགྱུར། །བླ་མ་དམ་པའི་མྱ་ངན་གྱིས། །
མ་ཧི་ལ་དག་མྱ་ངན་གནས། །བླ་མ་ཡེ་ཤེས་མིག་མེད་པས། །ཕྱོགས་མཚམས་གང་ཡང་མཐོང་བ་མེད། །
```

我这恶劣的身蕴，因为与上师分离，一切显现都隐没了。因为（失去）殊胜上师的悲痛，马希拉陷在悲伤之中。没有了上师这智慧之眼，四方四隅什么也看不见了。

【按】本篇是一首哀悼上师逝世的悲歌。依跋语与第47句“黑上师（那波）”，所哀悼的上师应是黑行者卡纳巴（Kāṇha）。依藏传成就者传记，黑行者因受某位女子（一说是空行母或女巫）的加害而逝世，他的弟子们悲痛之余，以密法诛灭了那位加害者。本篇所唱的，应当就是这段故事。传记的细节各家说法不一，这里只作简要说明。

【按】第2句“བླ་མ་ཧཾ”，“ཧཾ”字所指不明：可能是上师名字的简称，也可能是种子字“吽”的异写，或有讹误。这里只译作“上师”。

【按】“མ་ཧི་ལ”（马希拉，Mahila），依跋语是本篇的传承上师，大概是黑行者的弟子之一。以下几位都是黑行者的弟子，在诗中各自表达哀痛。

### 第二段：摩尼跋陀罗之哭

```
བླ་མ་དམ་པའི་མྱ་ངན་གྱིས། །མ་ཎི་བྷ་དྲ་བདག་ནི་ངུ་། །སྙིང་རྗེ་རྔེ་ཆུང་དུགས་དཀར་ཕུབ། །རྣལ་འབྱོར་རྒྱལ་པོ་མཛེས་པའི་བདག། །
སྡིག་ཅན་གང་གིས་སྤྱན་དྲངས་ནས། །མ་ཎི་བྷ་དྲ་རེ་མ་དགའ། །
```

因为殊胜上师（逝去）的悲痛，我摩尼跋陀罗在哭泣。（上师）张开悲心的小鼓与白伞，是瑜伽之王、庄严之主——是哪个罪人把他带走了！摩尼跋陀罗啊，多么悲伤！

【按】“མ་ཎི་བྷ་དྲ”（摩尼跋陀罗，Maṇibhadrā），八十四大成就者中有一位同名的女成就者，可能就是这一位。

【按】“སྙིང་རྗེ་རྔེ་ཆུང”，“རྔེ་ཆུང”意思不明，依下文第30句的“达玛鲁鼓”，这里读作“རྔ་ཆུང”（小鼓）。“དུགས་དཀར་ཕུབ”，“张开白伞”，白伞是尊贵的标志，也是庇护众生的象征。

【按】“སྤྱན་དྲངས”，本义是“迎请”（敬语），这里用于“罪人把上师带走”，带有反讽的哀痛语气，意思是上师被罪人害死。

【按】“རེ་མ་དགའ”，是叠用的悲叹语，直译是“唉，不乐”，这里译作“多么悲伤”。

### 第三段：成就者坛城与达玛、杜玛之悲

```
གྲུབ་ཐོབ་བརྒྱད་ཅུ་རྩ་བཞི་ཡིས། །ནམ་མཁའི་དབྱིངས་སུ་དཀྱིལ་འཁོར་བཞེངས། །དེ་དབུས་བླ་མ་ནོར་བུ་བཞུགས། །སེམས་ཀྱི་གདུང་བས་བདག་ལུས་བསྲེགས། །
དྷ་མ་དྷཱུ་མ་རེ་མ་དགའ། །
```

八十四位成就者在虚空界中建起坛城，坛城中央安坐着珍宝上师。心中的焦苦焚烧着我的身体——达玛、杜玛啊，多么悲伤！

【按】“དྷ་མ་དྷཱུ་མ”（达玛、杜玛），八十四大成就者中有 Dhamapa 与 Dhūmapa 两位，名字相合，可能就是他们，依传记二人是兄弟。

### 第四段：于迦摩卢见上师融入

```
སྐད་ཅིག་གཅིག་ལ་ཀཱ་མ་རཱུ། །བླ་མ་ལོངས་སྤྱོད་ཐིམ་པར་མཐོང་། །སྣ་ཚོགས་སྐད་ཅིག་གཅིག་ལ་ནི། །རྣམ་པར་དངོས་མེད་མཐོང་འགྱུར་བས། །
བླ་མ་གཤེགས་པས་རེ་མ་དགའ། །
```

一刹那间，在迦摩卢，见到上师的报身融入（虚空）；种种（显现）在一刹那间，全都见为无实。上师逝去了，多么悲伤！

【按】“ཀཱ་མ་རཱུ”（迦摩卢），即迦摩缕波（Kāmarūpa），在今印度阿萨姆一带，是著名的密乘圣地。“བླ་མ་ལོངས་སྤྱོད་ཐིམ་པར་མཐོང”，“见上师报身融入”，意思大概是：上师逝世时，弟子们在定中见到上师的报身融入法界。“ལོངས་སྤྱོད”在这里读作“报身”（ལོངས་སྤྱོད་རྫོགས་སྐུ）的简称，也可以照字面理解为“受用”。

### 第五段：失去上师，四方黑暗

```
ནོར་དང་ལོང་ཚོ་ཐམས་ཅད་སྤངས། །སྲིད་ལ་ཆགས་པའི་ང་རྒྱལ་བཅོམ། །ནོར་བུ་བཟང་པོ་མ་ཧི་ལ། །དྷ་མ་དྷཱུ་མ་བདག་ཅག་གི། །
དཔལ་ལྡན་བླ་མ་མེད་འགྱུར་བས། །ཕྱོགས་མཚམས་ཐམས་ཅད་མུན་པས་ཁེབས། །
```

（我们）舍弃了一切财富与青春，摧毁了贪著三有的我慢——贤善的珍宝马希拉，还有达玛、杜玛，我们的吉祥上师不在了，四方四隅都被黑暗所覆盖。

### 第六段：火化上师，骨灰涂身

```
ཀྱེ་མ་གཉིས་མེད་ཌ་མ་རུ། །ནམ་མཁའི་དབྱིངས་སུ་གདུང་བྱས་ནས། །གདུང་བས་རྣལ་འབྱོར་བདག་ཅག་གིས། །བླ་མའི་གདུང་ཐལ་ལུས་ལ་བྱུགས། །
དེ་ཉིད་སྤྱི་བོར་བསྒོམ་བྱས་ནས། །སྙིང་རྗེས་བྷ་ཧུ་རི་བདག་གིས་བསད། །
```

唉！那无二的达玛鲁鼓（般的上师），在虚空界中火化之后，我们瑜伽士怀着悲痛，把上师的骨灰涂在身上，把它观想在头顶上；我以悲心，杀了巴呼日。

【按】“གཉིས་མེད་ཌ་མ་རུ”，“无二的达玛鲁鼓”，这里读作对上师的比喻，或者是上师所持的法器。“གདུང”既可以是“火化”“遗骨”，也可以是“悲痛”，第31、32句连用两次，可能带有双关。

【按】“བྷ་ཧུ་རི”（巴呼日），依传记大概就是加害黑行者的那位女子的名字，下文又作“བྷ་རི”（巴日），应是同一人。

【按】“སྙིང་རྗེས་བསད”，“以悲心杀”，这是密乘中所谓“度脱”（སྒྲོལ་བ）的说法：具有极高证量的瑜伽士，以悲心将造作极重恶业者的神识度脱至净土，断其继续造恶。这是密乘中极为特殊、只限于极高证量者的行为，在传统中受到严格的限制，绝不是一般修行人可以效仿的，更不能理解为对世间杀戮的认可。本篇是一首记述成就者故事的悲歌，读者务须从这一角度理解。

### 第七段：斥责上师的仇敌

```
བདུད་ཀྱིས་ཁྱེར་བའི་བྷ་རི་ཁྱོད། །བླ་མའི་སྐུ་དགྲ་ཁྱོད་ཡིན་ནོ། །བདག་ཅག་ཁྱོད་ཀྱི་མུན་པས་བསྒྲིབས། །བདག་ཅག་རྣམས་ཀྱིས་མདུན་མ་བྱས། །
```

被魔所驱使的巴日你啊，你就是上师的仇敌！我们被你的黑暗所遮蔽，我们不曾以你为伴。

【按】“མདུན་མ”，一般意思是“伴侣”“妻室”。“བདག་ཅག་རྣམས་ཀྱིས་མདུན་མ་བྱས”，这里依字面译作“我们不曾以你为伴”，意思可能是：我们与你毫无瓜葛。依某些传记，加害者与黑行者之间曾有某种因缘，这一句或许与此有关，但原文没有说明。

### 第八段：丧服、剃发、身瘦如骨

```
དུག་པོ་གྱོན་ཞིང་སྐྲ་རྣམས་བྲེགས། །དབྱུག་པ་དང་ནི་ཐོད་པ་ཐོགས། །མྱ་ངན་ལུས་རྣམས་ཀེང་རུས་འབྱུང་། །ཀྱེ་མ་རྣལ་འབྱོར་མི་རྟག་གོ། །
བདག་ཅག་རྣམས་ཀྱིས་བྷ་ཧུ་རི་བཅོམ། །
```

穿上粗衣，剃去头发，手持禅杖与颅器，悲伤得身体消瘦成了骨架。唉！瑜伽（之身）也是无常的啊！我们摧伏了巴呼日。

【按】“དུག་པོ”，字面是“毒的”，在这里应当是指粗陋的衣服（丧服），可能是“དུག་པ”或其他词的讹写。“དབྱུག་པ་དང་ཐོད་པ”，“禅杖与颅器”，是印度密乘瑜伽士的典型装束。

【按】“ཀྱེ་མ་རྣལ་འབྱོར་མི་རྟག་གོ”，“唉！瑜伽也是无常的”，意思可能是：即使是成就的瑜伽士，色身也是无常的。

### 第九段：马希拉的威猛与度脱

```
དེ་བྷི་བྷནྟུ་ཀོ་ཏི་ནས། །སྲི་མི་ལིའི་གནས་ཆེན་ཕྱེད་དང་གསུམ། །བླ་མ་ནག་པོའི་ལྟ་བ་ཡིས། །རྣལ་འབྱོར་དྲག་པོ་མ་ཧི་ལས། །
མཁའ་འགྲོ་དྲུག་ཅུ་རྩ་བཞི་སྐྲག། །སྲེ་མི་ལི་བཤགས་བྷ་ཧུ་རི་བསད། །ཀྱེ་མ་བླ་མའི་སྐུ་དགྲ་བསྒྲལ། །བདག་ཅག་མཁའ་སྤྱོད་གནས་སུ་འགྲོ། །
```

从德维潘图科蒂，到斯米利，（这）两个半大圣地中，以黑上师的见地，威猛的瑜伽士马希拉，使六十四空行母都感到畏惧；（我们）向斯米利忏悔，杀了巴呼日。唉！度脱了上师的仇敌，我们要前往空行刹土去了。

【按】第45、46句的地名“དེ་བྷི་བྷནྟུ་ཀོ་ཏི”与“སྲི་མི་ལི”，都是音译，所指不明；“ཕྱེད་དང་གསུམ”是“两个半”，意思是“两个半大圣地”，确切所指也不明。第50句又作“སྲེ་མི་ལི”，大概是同一个地名或人名。“བཤགས”可以是“忏悔”，也可以是“劈开、剖开”，这里取“忏悔”之义，意思不完全确定。

【按】“བསྒྲལ”是“度脱”，见第六段按语。“མཁའ་སྤྱོད་གནས”，“空行刹土”，是空行净土，也是密乘行者往生的所在。

## 通篇连读

我这恶劣的身蕴，因为与上师分离，一切显现都隐没了。因为（失去）殊胜上师的悲痛，马希拉陷在悲伤之中。没有了上师这智慧之眼，四方四隅什么也看不见了。

因为殊胜上师（逝去）的悲痛，我摩尼跋陀罗在哭泣。（上师）张开悲心的小鼓与白伞，是瑜伽之王、庄严之主——是哪个罪人把他带走了！摩尼跋陀罗啊，多么悲伤！

八十四位成就者在虚空界中建起坛城，坛城中央安坐着珍宝上师。心中的焦苦焚烧着我的身体——达玛、杜玛啊，多么悲伤！

一刹那间，在迦摩卢，见到上师的报身融入（虚空）；种种（显现）在一刹那间，全都见为无实。上师逝去了，多么悲伤！

（我们）舍弃了一切财富与青春，摧毁了贪著三有的我慢——贤善的珍宝马希拉，还有达玛、杜玛，我们的吉祥上师不在了，四方四隅都被黑暗所覆盖。

唉！那无二的达玛鲁鼓（般的上师），在虚空界中火化之后，我们瑜伽士怀着悲痛，把上师的骨灰涂在身上，把它观想在头顶上；我以悲心，杀了巴呼日。

被魔所驱使的巴日你啊，你就是上师的仇敌！我们被你的黑暗所遮蔽，我们不曾以你为伴。

穿上粗衣，剃去头发，手持禅杖与颅器，悲伤得身体消瘦成了骨架。唉！瑜伽（之身）也是无常的啊！我们摧伏了巴呼日。
