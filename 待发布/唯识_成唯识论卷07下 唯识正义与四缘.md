<div class="dt-subtitle">成唯识论白话译注（二十一）　卷第七之下<br>护法等菩萨造　唐　玄奘译</div>

一、第十七颂

前面已经详细分别了三能变的相状，三能变识是自己所变的见分、相分的所依。外人质问：怎么知道依识所变而假说我法，我法并非另外实有，由此一切唯有识？世亲菩萨用颂回答：

```
是诸识转变　分别所分别
由此彼皆无　故一切唯识
```

大意：诸识转变，显现为能分别和所分别；由此，离识的实我实法都不存在，所以一切唯有识。

二、“转变”的两种解释

论中解释：“诸识”，是指前面所说的三能变识及三能变识的心所，都能变现为似见分和似相分，所以立“转变”的名称。所变的见分称为“分别”，因为见分能取相；所变的相分称为“所分别”，因为相分是见分所取的。

由此正理，所执的实我实法，离开识所变，都决定不存在，因为离开能取和所取，没有别的东西；没有任何实物离开见、相二分而存在。所以一切有为法、无为法，无论实有或假有，都不离识。“唯”字是为了遮除离识的实物，不是遮除不离识的心所法等。

【译注】依《述记》，以上是护法论师的解释：“分别”是见分，“所分别”是相分，见相二分都是依他起的实有，离二分之外的“实我实法”才是无。

另一种解释：“转变”是指诸内识转起，显现为似我、似法的外境之相。能转变的称为“分别”，因为以虚妄分别为自性，就是三界的心王与心所。所执的境称为“所分别”，就是所妄执的实我实法之性。由此分别变现为似外境的假我假法之相，所分别的实我实法之性决定都没有，前面所引的教理已经广破。所以一切都唯有识，因为虚妄分别的存在是共许的。

“唯”字既然不遮除不离识的法，所以真空等也是有。由此远离增益和损减两边，唯识的意义成立，契合中道。

【译注】依《述记》，第二种解释是安慧论师一系的说法：见相二分都属遍计所执，只有能变的识体是依他起。两种解释都归结到“离识无实我法”，只是对见相二分的定位不同。

外人质问：由什么教理，唯识的意义得以成立？前面不是已经说过了吗？论主回答：说过了，还没有说透。破斥他人的主张，自己的主张并不因此就成立，所以应当更确切地陈述成立唯识的教理。

三、教证：经说与四智

如契经说：三界唯心。又说：所缘的境唯是识所现。又说：诸法都不离心。又说：有情随心的垢净而垢净。

又说：成就四种智慧的菩萨，能随之悟入唯识无境。

第一是相违识相智：同一处所，鬼、人、天等随业力差别，所见各不相同。境如果实有，怎能如此？

第二是无所缘识智：缘取过去、未来、梦境、镜像等，不是实有的境，识现前可得。过去未来梦像等境既然没有，其余的境也应如此。

第三是自应无倒智：愚夫的智慧如果能得到实在的境，愚夫就应自然成为没有颠倒，不需要用功就应得到解脱。

第四是随三智转智，又分三种。一是随自在者智转智：已经证得心自在的人，随意转变地等，都能成就。境如果实有，怎能被改变？二是随观察者智转智：得到殊胜禅定、修法观的人，随着观察一境，众多相状现前。境如果是实有，怎能随心而转？三是随无分别智转智：生起证实的无分别智时，一切境相都不现前。境如果是实有，怎能不现？

菩萨成就四智，对唯识的道理决定悟入。

【译注】“鬼人天所见各异”就是一水四见：同一条河，人见为水，鬼见为脓血，天见为琉璃，鱼见为宅舍。四智层层递进：境随业转、境可无而识有、执境就不能解脱、境随定慧而变乃至消失。

又有偈颂说：

```
心意识所缘　皆非离自性
故我说一切　唯有识无余
```

大意：心、意、识所缘的对象，都不离识的自性，所以我说一切唯有识，没有其余的东西。

诸如此类的圣教，确实的证据不止一处。

四、理证：四个论式

第一个论式：主张是，共许的眼等识，不直接缘取离开自体的色等。理由是，眼等识属于五识之一。例证是，如同其余四识。

第二个论式：主张是，其余的第六、七、八识，也不直接缘取离开自体的诸法。理由是，第六、七、八识是识。例证是，如同眼识等。

第三个论式：主张是，识的亲所缘，决定不离开识。理由是，亲所缘属于见分、相分二者之一。例证是，如同能缘的见分。

第四个论式：主张是，一切所缘之法，决定不离心王与心所。理由是，是所缘之法。例证是，如同相应的心所法。

【译注】四个论式环环相扣：前两个说一切识都只亲缘自体之内的相分；后两个说相分与所缘之法都不离识。合起来，就没有任何一法能离识而存在。

诸如此类的正理，确实的证据不止一处。所以对唯识应深信受持。

五、慈尊二颂：唯识契中道

```
我法非有，空识非无，
离有离无，故契中道。
```

大意：实我实法不存在，真空与识并非没有。远离执有和执无两边，所以契合中道。

慈尊弥勒菩萨依此说了两首偈颂：

```
虚妄分别有　于此二都无
此中唯有空　于彼亦有此
故说一切法　非空非不空
有无及有故　是则契中道
```

大意：虚妄分别是有的，在虚妄分别上，能取所取二者都没有。虚妄分别中只有空性，空性中也有虚妄分别。所以说一切法非空、非不空：虚妄分别有，二取无，空性有。如此就契合中道。

【译注】二颂出自《辩中边论》。三样东西三种判定：虚妄分别（依他起）是有，能取所取（遍计所执）是无，空性（圆成实）是有。“非空”因为有虚妄分别和空性，“非不空”因为二取全无。唯识的中道，就在三句判定的分寸之中。

二颂只是依染污的依他起而说，实际上也有清净的依他起。

六、八个疑难与回答

第一个疑难。外人质问：如果只是内识显现为似外境，为什么见到世间的有情和无情之物，处所决定、时间决定、众人共见而不是各自所见、作用确实，并不像梦境那样？论主回答：此一疑问，应当依《唯识二十论》的解释来回答。

【译注】《唯识二十论》以梦答前两点：梦中所见也有固定的处所和时间；以饿鬼同见脓河答第三点：同业者所见相同；以梦遗答第四点：梦境也有实际作用。

第二个疑难。外人质问：世尊为什么说十二处？论主回答：十二处都是依识所变，并非另外实有。为了令人悟入我空，说六根和六境两组法，如同为了遮除断见，说有情相续不断。为了令人悟入法空，又说唯识，让人知道外法也不存在。

第三个疑难。外人质问：唯识性难道不也是空？

论主回答：不是。

外人质问：为什么？

论主回答：因为唯识性不是所执着的对象。依识所变，虚妄执着的实法，在道理上不可得，所以说法空；并不是说没有离言的正智所证的唯识性，才说法空。如果唯识性没有，就没有俗谛；俗谛没有，真谛也就没有，因为真谛与俗谛互相依待而建立。否定二谛，就是恶取空，诸佛说恶取空的人不可救治。应知诸法有空的，有不空的。由此，弥勒菩萨说前面两首偈颂。

【译注】唯识不是虚无：说“空”只空掉执着出来的实我实法，识本身和识的真实性不空。把识也一起空掉，俗谛与真谛双双倒塌，就是恶取空。

第四个疑难。外人质问：如果一切色处也以识为体，为什么显现为色的相，同一类别地坚固常住、相续运转？

论主回答：由于名言熏习的势力而起，又作为染法与净法的依处。如果没有似色的显现，就没有颠倒，就没有杂染，也没有清净法。所以诸识也显现为似色。如偈颂说：

```
乱相及乱体　应许为色识
及与非色识　若无余亦无
```

大意：迷乱所现的相与迷乱的体，应当承认分别是似色之识与非色之识；如果没有似色之识，非色之识也就没有。

第五个疑难。外人质问：色等外境分明现前，是现量所证得的，怎能否定为没有？

论主回答：现量证知的时候，并不执着为外境；后来意识分别，虚妄地生起外境之想。所以现量的境是自己的相分，因为是识所变，也说为有。意识所执着的外在实有的色等，是虚妄计度出来的，所以说为没有。色等境不是色而似色，不是外而似外，如同梦中所缘，不可执着为真实的外色。

【译注】看见红色的那一刹那，只有红色的相，并没有“外面有一个红色的东西”的判断；“外面”是下一刹那意识加上去的。现量本身清白无辜，执着出在后面的分别上。

第六个疑难。外人质问：如果醒时的色都如同梦境，不离识，如同从梦中醒来，知道梦境唯心，为什么醒时对自己所见的色境，不知道是唯识？

论主回答：如同在梦中还没醒的时候，不能自知，要到醒的时候，才能追知。醒时的境色，应知也是如此：没有真正觉悟的时候，不能自知；到真正觉悟时，也能追知。

```
未得真觉，恒处梦中，
故佛说为生死长夜。
```

大意：没有得到真正的觉悟，就恒常处在梦中，所以佛说生死是漫漫长夜。

由此，没有真觉的人，不了知色境唯识。

第七个疑难。外人质问：外在的色实际上没有，可以不是内识的境；他人的心是实有的，怎能不是自己所缘？

论主回答：谁说他人的心不是自己识的境？只是不说他人的心是亲所缘。识生起时，没有实际的作用，不像手等直接抓取外物，也不像太阳等放出光芒直接照到外境；识只像镜子等，显现得似外境，称为了知他人的心，并不是直接能了知。直接了知的，是自己所变的影像。所以契经说：

```
无有少法能取余法，
但识生时似彼相现，名取彼物。
```

大意：没有任何一法能取另一法；只是识生起时，显现出似对象的相，就称为取到了那个对象。

缘取他人的心如此，缘取色等也是如此。

第八个疑难。外人质问：既然有他心等异于自识的境，怎能称为唯识？

论主回答：奇怪啊，固执的人处处生疑！唯识之教难道只说一个识？

外人质问：不然又是怎样？

论主回答：你应当仔细听。如果只有一个识，怎会有十方、凡圣、尊卑、因果等差别？谁为谁说法？说什么法？求什么果？所以“唯识”二字有深刻的意趣。

“识”字总括显示：一切有情各有八识、六位心所、所变的相分和见分、分位差别，以及空理所显的真如。八识是识的自相；心所与识相应；相分见分是识心王与心所二者所变；分位差别是识、心所、所变三者的分位；真如是识、心所、所变、分位四者的真实性。以上诸法，都不离识，所以总立“识”的名称。“唯”字只遮除愚夫所执着的离开诸识而实有的色等。

【译注】论主此段说破了“唯识”的全部内涵，也正好对应五位百法：心法（八识）、心所法（五十一）、色法（所变的相分）、不相应行法（分位）、无为法（真如）。“唯识”不是“只有一个识”，而是“一切法不离识”。

如果如此了知唯识之教的意趣，就能没有颠倒地善加具备资粮，迅速悟入法空，证得无上觉，救拔一切众生出离生死轮回。完全否定一切的恶取空者，违背教理，不能成就以上诸事。所以决定应当相信一切唯识。

七、第十八颂：无外缘，分别如何生起

外人质问：如果只有识，完全没有外缘，种种分别由什么而生起？世亲菩萨用颂回答：

```
由一切种识　如是如是变
以展转力故　彼彼分别生
```

大意：由一切种子识，种子如此如此转变成熟；又由现行诸识展转相助的力量，种种分别得以生起。

论中解释：一切种识，是本识中能生自果的功能差别。种子能生等流果、异熟果、士用果、增上果，所以称为一切种。除去离系果，因为离系果不是种子所生。离系果可以证得，不是种子的果，要现起圣道、断除烦恼系缚才能得到。离系果与种子也有展转的关系，不是颂中所说，颂中说的是能生分别的种子。

种子以本识为体，所以立“识”的名称，因为种子离开本识没有另外的体性。“种”“识”二字，用以简别不是种子的识，因为有的识不是种子，有的种子不是识。“种识”二字，显示的是识中的种子，不是持种的识，持种的识后文会说。

识中的种子，由其余诸缘的帮助，就“如是如是”地转变，即从生起的阶位转变到成熟的时候。重复说“如是”，显示转变的种子很多，就是一切种子包括三种熏习、共相与不共相等识中的种子，全都包括在内。

“展转力”，是指八种现行识，以及现行识相应的心所、见分、相分等，彼此都有互相帮助的力量。现行识等总称为“分别”，因为以虚妄分别为自性。分别的种类很多，所以说“彼彼”。

颂的意思是：即使没有外缘，由于本识中有一切种子的转变差别，以及现行的八识等展转相助的力量，种种分别也能生起，何必依靠外缘才生起分别？一切清净法的生起，应知也是如此，因为清净的种子与现行作为缘而生起。

外人质问：所说的种子与现行作为缘而生起分别，怎么了知其中缘生的相状？论主回答：缘大略有四种。

八、因缘

第一是因缘，就是有为法直接成办自己的果。因缘的体有两种：一是种子，二是现行。

种子，是本识中善、染、无记，以及各界各地的功能差别，能引生后念同类的功能，又能生起同时同类的现行果。种子只对后念种子与同时现行两种果才是因缘。

现行，是前七转识，以及前七转识相应的心所、所变的相分见分、性质、界地等，除去佛果的善法和极其微劣的无记法，其余的都能熏习本识，生起自类的种子。现行只对所熏的种子才是因缘。

第八识的心品不能熏，因为没有所熏的识；并不是只简别第八识作为所依而单独不能熏，第八识相应的心所也不能熏。佛果的善法极其圆满，极劣的无记法极其微弱，所以都不熏成种子。

同类的现行之间，互相都不是因缘，因为都从自己的种子而生。一切异类之间，互相也不是因缘，因为不是直接生起。

有人说异类与同类的现行之间互为因缘，应知是假说，或者是随转门。有人只说种子是因缘，是依显著殊胜而说，不是穷尽道理的说法，因为圣教说转识与阿赖耶识展转互为因缘。

九、等无间缘

第二是等无间缘，就是八种现行识及八识的心所，前一聚对后一聚自类，没有间隔，相等地开辟引导，令后一聚决定生起。

同类的多个种子同时运转，如同不相应法，不属于等无间缘。由此，八识之间不互为等无间缘。心所与心王恒常同时运转，又因为相应，和合似一，不可施设为分离殊异，所以心王与心所可以互作等无间缘。

入无余涅槃的心最极微劣，没有开导的作用，又没有将来应当生起的等无间法，所以不是等无间缘。

外人质问：怎么知道等无间缘如此？论主回答：论中有确切的说法：如果在某识等之后无间断，某识等决定生起，就说前一识是后一识的等无间缘。

依此意义，应当如此说：

阿陀那识，在三界九地中，都可以互作等无间缘，因为下地与上地、死与生，互相开导。有漏之后可以无间生起无漏，无漏之后决定不生起有漏，因为大圆镜智生起之后，必定不再断。善与无记之间也是如此。

外人质问：第八识在哪一界之后引生无漏？论主回答：或者在色界之后，或者在欲界之后。一切求佛果的凡夫，决定在色界之后引生无漏，因为必定生在净居天上的大自在宫得菩提。二乘回心趣向大菩提的人，决定在欲界之后引生无漏，因为回心后留下的身体只在欲界。二乘回心的人也必定前往大自在宫才能成佛，由本愿力所留的生身仍是欲界身。

有一家认为：色界也有声闻回心趣向大乘、发愿留身的，与教理都不相违，所以声闻的第八识无漏，在色界心之后也可以现前。五净居天没有回心的人，因为经中没有说五净居天的人发大心。

第七转识，在三界九地中，也可以互作等无间缘，因为随第八识的生处而系属。有漏与无漏可以互相生起，因为在十地中可以互相引生。善与无记之间也是如此。在无记中，染污与不染污也互相开导，因为生空智果的前后阶位可以互相引生。在欲界和色界，有漏可以与无漏互相生起；在无色界不可以，因为初地以上的菩萨不生到无色界。

第六转识，在三界九地中，有漏、无漏、善、不善等，各自都可以互作等无间缘，因为润生等阶位互相引生。初次生起无漏，只在色界心之后，因为顺抉择分的善根只在色界。

眼、耳、身三识在欲界和色界初禅二地，鼻、舌二识只在欲界一地，各自同类之间互作等无间缘。善等之间互相为缘，也是如此。

关于五识的有漏与无漏，有两家主张。第一家认为：五识的有漏与无漏，同类之间互作等无间缘，因为未成佛时可以互相生起。第二家，即护法论师，认为：无漏可以在有漏之后生起，无漏之后不可以生起有漏，因为无漏的五识只有佛才有。理由是：未成佛时的五色根决定是有漏，属于异熟识的相分；有漏的、不共的、同时同境的根，发起无漏的识，在道理上不相应，因为有漏根与无漏识对境的明暗不同。

十、所缘缘

第三是所缘缘，就是：某一法，是带有自己相状的心王或相应心所，所思虑、所依托的。所缘缘的体有两种：一是亲所缘缘，二是疏所缘缘。

如果与能缘的识体不相离，是见分等内在所思虑、所依托的，应知是亲所缘缘。如果与能缘的识体相离，作为本质，能令识生起内在所思虑、所依托的影像，应知是疏所缘缘。

亲所缘缘，一切能缘都有，因为离开内在所思虑、所依托的，能缘必定不生起。疏所缘缘，能缘有时有、有时无，因为离开外在所思虑、所依托的，能缘也可以生起。

【译注】亲所缘缘是心中的影像；疏所缘缘是影像所依托的本质。看他人时，自己心中的他人影像是亲所缘缘，他人自己识所变的身体是疏所缘缘。想象龟毛兔角时，只有影像，没有本质。

关于第八识心品的疏所缘缘，论中列出三家。

第一家认为：第八识只有亲所缘缘，因为随业因的力量任运变现。

第二家认为：第八识也决定有疏所缘缘，因为要依仗他人所变的本质，自己才能变现。

第三家，即护法论师，认为：两种说法都不合道理。自己和他人的身体与国土，可以互相受用，他人所变的，作为自己的本质。自己的种子对他人没有受用的道理，所以说他人所变的能作为自己所缘种子的本质，不合道理，因为一切有情的种子并不都相等。应当说，第八识心品的疏所缘缘，在一切阶位中有无不定。

第七识心品，在未转依位，因为是俱生的，必定依仗外在的本质，所以也决定有疏所缘缘。在已转依位，不一定有，因为缘取真如等，没有外在的本质。

第六识心品，行相猛利，在一切阶位中都能自在运转，所依仗的外在本质或有或无，所以疏所缘缘有无不定。

前五识心品，在未转依位，粗钝微劣，必定依仗外在的本质，所以也决定有疏所缘缘。在已转依位，不一定有，因为缘取过去、未来等，没有外在的本质。

十一、增上缘与二十二根

第四是增上缘，就是：某一法，有殊胜的势用，能对其余的法或顺或违。前面三缘也是增上，现在第四缘除去前三缘，取其余的，是为了显示诸缘差别的相状。

增上缘的顺违作用，在四处运转，因为生、住、成、得四种事各不相同。增上的作用随事很多，殊胜显著的只有二十二种，应知就是二十二根。

前五色根，以本识等所变的眼等净色为体性。男女二根属于身根，所以就以身根的一部分为体性。命根只依本识的亲种子的分位假立，没有另外的体性。意根总以八识为体性。五受根，随其所应，各以自己的受为体性。信等五根，就以信等五种及善念等为自性。

【译注】二十二根：眼、耳、鼻、舌、身、意六根；男根、女根；命根；苦、乐、忧、喜、舍五受根；信、精进、念、定、慧五根；未知当知根、已知根、具知根三无漏根。

未知当知根的体，依阶位有三种。

第一是根本位，在见道中，除去最后一刹那，因为还有未知的四谛理应当了知。

第二是加行位，即暖、顶、忍、世第一法四善根，因为加行位能就近引发根本位。

第三是资粮位，就是从为了得到四谛现观，发起决定殊胜的善法欲，直到还没有得到顺抉择分之前的一切善根，称为资粮位，因为资粮位能远远资助生起根本位。

在三个阶位中，以信等五根、意根、喜根、乐根、舍根，作为未知当知根的体性。加行等阶位中，对后面殊胜的法求证而愁戚，也有忧根；忧根不是真正的善根，所以多不说。

前三种无色定中有未知当知根，因为有殊胜的见道傍修而得。或者二乘回心趣向大乘的人，为了证得法空，在初地以前也生起九地所摄的生空无漏，都属于菩萨的未知当知根。菩萨见道中也有未知当知根，只说地前，因为见道时间短促。

从见道的最后一刹那，直到金刚喻定，一切信等无漏九根，都是已知根的体性。还没有离欲的人，对上地的解脱求证而愁戚，也有忧根；忧根不是真正的善根，所以多不说。

一切无学位的无漏九根，都是具知根的体性。

有顶有游观的无漏，不够明利，所以不是后三根。

二十二根的自性如此，其余诸门的意义，如论中所说可知。

【译注】三无漏根是修行进程的三个刻度：未知当知根是“将要知道而还没知道”，已知根是“已经知道而还在继续断惑”，具知根是“完全知道，无事可做”。三根的体都是同一组九根：信等五根，加意、喜、乐、舍。
