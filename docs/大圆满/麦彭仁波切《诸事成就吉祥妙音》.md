# 麦彭仁波切《诸事成就吉祥妙音》

这是麦彭仁波切所作的一首吉祥颂，可以唱诵。先迎请三根本圣众，接着依次称颂持明上师、三世善逝、本尊、正法、佛子、空行、护法的吉祥，每节以同一组四句作为叠句收束；后面是祈愿教法、施主和众生的吉祥，最后以法性真谛的吉祥圆满全篇。跋文说它写于绕迥火猴年五月十一日，写作地点是修行房“无死胜成洲”。

藏文依《局米旁大师教言集》录入本（MP248，页码19-21-1a至2b）整理。为了便于唱诵，汉译不照本论集的散文体例，而是两版并列：九言版一字对一音节，可以按藏文原曲唱，名号完整；七言版更合汉语的诗歌节奏，适合另配汉语曲调。叠句每次都完整写出（藏文原本用“༴”略写）。七言版装不下的名号，在【按】中补全。

༄༅། །བཀྲ་ཤིས་དོན་ཀུན་གྲུབ་པའི་དབྱངས་སྙན་ཞེས་བྱ་བ་བཞུགས་སོ། །

《诸事成就吉祥妙音》

ཨོཾ་སྭ་སྟི་བི་ཛ་ཡནྟུ།

嗡 梭斯德 毗杂扬度（愿吉祥胜利）！

ཆོས་དབྱིངས་ནམ་མཁའི་ཁྱོན་ཀུན་ཡོངས་ཁྱབ་པའི། །རབ་འབྱམས་རྩ་བ་གསུམ་གྱི་ལྷ་ཡི་ཚོགས། །ཏིལ་གྱི་གོང་བུ་བཞིན་དུ་བཞུགས་པ་ཡི། །རྒྱལ་བའི་དབང་པོ་རྣམས་ཀྱིས་དགོངས་པ་མཛད། །

九言：周遍法界虚空之边际，无边三根本诸圣尊众，密如胡麻遍满而安住，诸胜者王慈悲垂眷念。

七言：周遍法界虚空际，三根本尊无边众，密如胡麻遍满住，诸胜者王垂眷念。

ཡུམ་རྣམས་རིན་ཆེན་བུམ་པས་དབང་བསྐུར་ཞིང་། །སེམས་དཔའི་ཚོགས་ཀྱིས་བཀྲ་ཤིས་མེ་ཏོག་འཐོར། །ལྷ་མོ་རྣམས་ཀྱིས་རྡོ་རྗེའི་གླུ་དབྱངས་ལེན། །ཁྲོ་བོའི་ཚོགས་ཀྱིས་བགེགས་རྣམས་ཕ་མཐར་བསྐྲད། །

九言：诸佛母众以宝瓶灌顶，菩萨众撒吉祥妙花雨，诸天女众同唱金刚歌，忿怒尊众远逐诸障碍。

七言：诸佛母以宝瓶灌，菩萨众撒吉祥花，天女同唱金刚歌，忿怒众驱障天涯。

འཇིག་རྟེན་སྐྱོང་བའི་ཚོགས་ཀྱིས་མཆོད་ཅིང་བསྟོད། །ཀུན་ཀྱང་ཁྱེད་དགེ་བཞིན་བཀྲ་ཤིས་དཔལ་ཡོན་ཀུན། །དེང་འདིར་མངོན་པར་སྩོལ་བ་ཉིད་གྱུར་པས། །བཀྲ་ཤིས་རབ་མཆོག་བདག་གིས་བརྗོད་པར་བྱ། །

九言：护世天众供养且赞叹，悉皆欢喜赐汝诸吉祥，荣德于今现前而降临，最胜吉祥由我来宣说。

七言：护世众尊供且赞，悉皆欢喜向汝等，今时现赐诸吉祥，最胜吉祥我宣说。

【按】“ཀུན་ཀྱང་ཁྱེད་དགེ་བཞིན”，录入本如此，疑当作“ཁྱེད་ལ་དགྱེས་བཞིན”（于汝等欢喜），暂依此意译出，读法待核。存疑。

## 叠句诸节

དགའ་རབ་ཤྲཱི་སེང་པདྨ་ཐོད་ཕྲེང་རྩལ། །གྲུབ་མཆོག་བརྒྱད་དང་རྗེ་འབངས་ཉི་ཤུ་ལྔ། །གཏེར་སྟོན་བརྒྱ་རྩ་བཀའ་གཏེར་དག་སྣང་བརྒྱུད། །རིག་འཛིན་བླ་མའི་ཚོགས་ཀྱི་བཀྲ་ཤིས་དེས། །དེང་འདིར་མི་མཐུན་རྒུད་པ་ཀུན་ཞི་ནས། །མཐུན་རྐྱེན་ཚེ་བསོད་བདེ་ལེགས་གོང་དུ་འཕེལ། །ཇི་ལྟར་བསམ་པ་ཡིད་བཞིན་ལྷུན་གྱིས་གྲུབ། །ཕུན་ཚོགས་དཔལ་ཡོན་རྒྱས་པའི་བཀྲ་ཤིས་ཤོག །

九言：极喜狮子莲花颅鬘力，八大持明君臣二十五，伏藏百师教伏净传承，承持明上师众之吉祥。

九言叠句：今此一切违缘衰损息，顺缘寿福安乐日增长，所思所愿如意任运成，荣德圆满兴盛愿吉祥。

七言：极喜狮子颅鬘力，八大持明君臣众，伏藏百师三传承，持明上师之吉祥。

七言叠句：今时违缘衰损息，顺缘寿福安乐增，所思如意任运成，荣德圆满愿吉祥。

【按】首句是极喜金刚、吉祥狮子（师利星哈）、莲花颅鬘力（莲花生大士）三位，藏文原句本身也是略称，九言版作“极喜、狮子、莲花颅鬘力”，七言版再略去“莲花”；“伏藏百师”的“教伏净”指教传、伏藏、净相；次句“君臣众”指君臣二十五尊；第三句“三传承”指教传、伏藏、净相三种传承。

གདོད་མའི་མགོན་པོ་རིགས་ལྔ་གངས་ཆེན་མཚོ། །སྟོན་པ་བཅུ་གཉིས་སངས་རྒྱས་སྟོང་ལ་སོགས། །མཁའ་ཁྱབ་ཕྱོགས་བཅུའི་ཞིང་ན་བཞུགས་པ་ཡི། །དུས་གསུམ་བདེ་བར་གཤེགས་པའི་བཀྲ་ཤིས་དེས། །དེང་འདིར་མི་མཐུན་རྒུད་པ་ཀུན་ཞི་ནས། མཐུན་རྐྱེན་ཚེ་བསོད་བདེ་ལེགས་གོང་དུ་འཕེལ། །ཇི་ལྟར་བདམ་པ་ཡིད་བཞིན་ལྷུན་གྱིས་གྲུབ། ཕུན་ཚོགས་དཔལ་ཡོན་རྒྱས་པའི་བཀྲ་ཤིས་ཤོག །

九言：本初怙主五部大雪海，十二导师贤劫千佛等，遍空十方刹土中安住，承三世善逝圣众吉祥。

九言叠句：今此一切违缘衰损息，顺缘寿福安乐日增长，所思所愿如意任运成，荣德圆满兴盛愿吉祥。

七言：本初怙主五部佛，大雪海尊十二师，千佛遍住十方刹，三世善逝之吉祥。

七言叠句：今时违缘衰损息，顺缘寿福安乐增，所思如意任运成，荣德圆满愿吉祥。

【按】九言版各节末句的“承……吉祥”，对应原文“བཀྲ་ཤིས་དེས”（以此吉祥），由它引出后面四句叠句的愿文。“大雪海”是宁玛文献对五部佛的称号，唱时可断作“本初怙主、五部大雪海”。

རིགས་བརྒྱ་རིགས་ལྔ་རིགས་གསུམ་རིགས་མཆོག་གཅིག །སྒྲུབ་པ་སྡེ་བརྒྱད་བདུད་འདུལ་ཁྲོ་བོ་བཅུ། །ཞི་དང་ཁྲོ་ཚུལ་སྒྱུ་འཕྲུལ་དྲྭ་བའི་གར། །རབ་འབྱམས་ཡི་དམ་ལྷ་ཡི་བཀྲ་ཤིས་དེས། །དེང་འདིར་མི་མཐུན་རྒུད་པ་ཀུན་ཞི་ནས། མཐུན་རྐྱེན་ཚེ་བསོད་བདེ་ལེགས་གོང་དུ་འཕེལ། ཇི་ལྟར་བསམ་པ་ཡིད་བཞིན་ལྷུན་གྱིས་གྲུབ། །ཕུན་ཚོགས་དཔལ་ཡོན་རྒྱས་པའི་བཀྲིས་ཤོག །

九言：百部五部三部一胜部，八大修部伏魔十忿怒，寂忿幻化网中之妙舞，承无边本尊众之吉祥。

九言叠句：今此一切违缘衰损息，顺缘寿福安乐日增长，所思所愿如意任运成，荣德圆满兴盛愿吉祥。

七言：百部五部三一部，伏魔十忿八修部，寂忿幻化网中舞，无边本尊之吉祥。

七言叠句：今时违缘衰损息，顺缘寿福安乐增，所思如意任运成，荣德圆满愿吉祥。

【按】七言版首句是百部、五部、三部与最胜一部；“八修部”即修部八教。

སྡེ་སྣོད་གསུམ་དང་རྒྱུད་སྡེ་ཆེན་པོ་དྲུག །རྒྱུད་ལུང་མན་ངག་བཀའ་གཏེར་དག་སྣང་སོགས། །རྒྱལ་བ་རིག་འཛིན་བརྒྱུད་པའི་ཐུགས་ཀྱི་མཛོད། །ལུང་རྟོགས་དམ་པའི་ཆོས་ཀྱི་བཀྲ་ཤིས་དེས། །དེང་འདིར༴མཐུན་རྐྱེན༴ ཇི་ལྟར༴ ཕུན་ཚོགས༴

九言：三藏以及六大续部等，续教窍诀伏藏净相等，胜者持明传承意宝藏，承教证二种正法吉祥。

九言叠句：今此一切违缘衰损息，顺缘寿福安乐日增长，所思所愿如意任运成，荣德圆满兴盛愿吉祥。

七言：三藏六大续部等，续教窍诀伏藏等，胜者持明意宝藏，教证正法之吉祥。

七言叠句：今时违缘衰损息，顺缘寿福安乐增，所思如意任运成，荣德圆满愿吉祥。

【按】第二句原文是续、教、窍诀，以及教传、伏藏、净相，共六项；九言版容纳不下“教传”，以“等”字概括。

ཉེ་བའི་སྲས་མཆོག་བརྒྱད་དང་སེམས་མ་བརྒྱད། །སྐལ་བཟང་སེམས་དཔའ་སྟོང་ལ་སོགས་པ་ཡི། །ཕྱོགས་བཅུ་དུས་གསུམ་དག་གི་རྒྱལ་བའི་སྲས། །ཡོན་ཏན་རྒྱ་མཚོ་རྣམས་ཀྱི་བཀྲ་ཤིས་དེས། དེང་འདིར༴ མཐུན་རྐྱེན༴ ཇི་ལྟར༴ ཕུན་ཚོགས༴

九言：八大近子八位女菩萨，贤劫千尊菩萨圣众等，十方三世一切诸佛子，承功德海佛子之吉祥。

九言叠句：今此一切违缘衰损息，顺缘寿福安乐日增长，所思所愿如意任运成，荣德圆满兴盛愿吉祥。

七言：八大近子八天女，贤劫千尊菩萨等，十方三世诸佛子，功德海众之吉祥。

七言叠句：今时违缘衰损息，顺缘寿福安乐增，所思如意任运成，荣德圆满愿吉祥。

【按】七言版的“八天女”，原文作“སེམས་མ་བརྒྱད”，即八位女菩萨，在相关坛城中也称八供养天女。

རྡོ་རྗེ་ཕག་མོ་རིགས་ལྔའི་ཌཱ་ཀི་ནཱི། མཚོ་རྒྱལ་ལ་སོགས་ཐུགས་ཀྱི་དགྱེས་སྡེ་ལྔ། །གནས་ཡུལ་ཞིང་གི་དཔའ་བོ་རྣལ་འབྱོར་མ། །དཔལ་ལྡན་མཁའ་འགྲོའི་ཚོགས་ཀྱི་ཤིས་དེས། དེང་འདིར༴ མཐུན་རྐྱེན༴ ཇི་ལྟར༴ ཕུན་ཚོགས༴ །

九言：金刚亥母五部空行母，措嘉等五心意欢喜众，圣境刹土勇士瑜伽母，承具德空行众之吉祥。

九言叠句：今此一切违缘衰损息，顺缘寿福安乐日增长，所思所愿如意任运成，荣德圆满兴盛愿吉祥。

七言：金刚亥母五空行，措嘉等五心喜众，圣境勇士瑜伽母，具德空行之吉祥。

七言叠句：今时违缘衰损息，顺缘寿福安乐增，所思如意任运成，荣德圆满愿吉祥。

【按】“措嘉等五心喜众”，指以益西措嘉为首、令莲师心意欢喜的五位明妃。

སྡེ་དཔོན་སུམ་ཅུ་དྲེགས་ཆེན་བཅོ་བརྒྱད་དང་། །ཚངས་དབང་ཁྱབ་འཇུག་བརྒྱ་བྱིན་རྒྱལ་ཆེན་སོགས། །དུས་གསུམ་རྒྱལ་བའི་ཕྲིན་ལས་བཀའ་སྐྱོང་བ། །རྡོ་རྗེའི་ཆོས་སྐྱོང་ཚོགས་ཀྱི་བཀྲ་ཤིས་དེས། །དེང་འདིར༴ མཐུན་རྐྱེན༴ ཇི་ལྟར༴ ཕུན་ཚོགས༴

九言：三十部主十八大傲慢，梵自在遍入帝释天王，护持三世诸佛之事业，承金刚护法众之吉祥。

九言叠句：今此一切违缘衰损息，顺缘寿福安乐日增长，所思所愿如意任运成，荣德圆满兴盛愿吉祥。

七言：三十部主十八傲，梵天自在帝释等，护持三世佛事业，金刚护法之吉祥。

七言叠句：今时违缘衰损息，顺缘寿福安乐增，所思如意任运成，荣德圆满愿吉祥。

【按】七言版首句是三十部主与十八大傲慢；第二句原文是梵天、自在天、遍入天、帝释、四大天王等，九言版作“梵、自在、遍入、帝释、天王”，遍入即毗湿奴；七言版只列出一部分，以“等”字概括。

## 回向吉祥

བསྟན་འཛིན་ཞབས་བརྟན་བཤད་སྒྲུབ་བསྟན་པ་དང་། །བསྟན་པའི་སྦྱིན་བདག་རྣམས་དང་འགྲོ་བ་ཀུན། །བདེ་སྐྱིད་གོང་འཕེལ་ཆོས་ལྡན་བསམ་དོན་འགྲུབ། །ས་གསུམ་དཔལ་དང་ལྡན་པའི་བཀྲ་ཤིས་ཤོག །

九言：持教长住讲修教法兴，护教施主以及诸众生，安乐增长如法愿皆成，愿三地荣光具足吉祥。

七言：持教长住讲修兴，护教施主及众生，乐增如法愿皆成，三地荣光愿吉祥。

སྣང་སྲིད་རྣམ་དག་བདེ་བ་ཆེན་པོ་ལ། །།མི་ཤིས་རྒུད་པ་ཡེ་ནས་མི་མངའ་བའི། །བདེན་པ་དེ་ཡིས་མཁའ་ཁྱབ་འགྲོ་བ་ཀུན། །རང་བྱུང་ཡེ་ཤེས་རྟོགས་པའི་བཀྲ་ཤིས་ཤོག །

九言：显有本净大乐性之中，不祥衰损本来即无有，以此真谛愿遍空众生，证悟自生智慧愿吉祥。

七言：显有清净大乐中，不祥衰损本来无，以此真谛遍空众，证自生智愿吉祥。

མཉམ་ཉིད་ངང་ནས་ཕྱོགས་དུས་འགྲོ་ཀུན་ལ། །ཕན་དང་བདེ་བའི་ཕྲིན་ལས་ལྷུན་གྱིས་གྲུབ། །རྟག་ཁྱབ་མཚུངས་མེད་བཀྲ་ཤིས་དཔལ་གྱི་མཆོག །དེང་འདིར་མངོན་དུ་འགྱུར་བའི་བཀྲ་ཤིས་ཤོག །

九言：于平等中十方三时众，利乐事业自然任运成，常遍无等最胜吉祥荣，今时于此现前愿吉祥。

七言：平等性中十方众，利乐事业任运成，常遍无等胜吉祥，今时现前愿吉祥。

ས་གསུམ་དབང་བྱེད་སྲིད་གསུམ་བྲན་དུ་འཁོལ། །ཕྱོགས་ལས་རྣམ་རྒྱལ་སྣང་སྲིད་ཟིལ་གནོན་པའི། །ཨོ་རྒྱན་རིག་འཛིན་བརྒྱུད་པའི་རིང་ལུགས་གང་། །ཕྱོགས་དུས་ཀུན་ཏུ་རྒྱས་པའི་བཀྲ་ཤིས་ཤོག །

九言：威摄三地三有悉听遣，胜伏诸方威镇诸显有，邬金持明传承之宗风，十方三时广弘愿吉祥。

七言：威摄三地役三有，十方尊胜镇显有，邬金持明传承规，时方广弘愿吉祥。

ཅེས་པའང་རབ་ཚེས་མེ་སྤྲེལ་འོད་འབར་གདོང་པ་བཟང་པོའི་ཟླ་༥ཚེས་༡༡གཟའ་སྐར་སོགས་ཀྱི་ཆ་ཤིན་ཏུ་དགེ་བར་སྒྲུབ་ཁང་འཆི་མེད་མཆོག་གྲུབ་གླིང་དུ་མི་ཕམ་འཇམ་དཔལ་དགྱེས་པའི་རྡོ་རྗེའི་བློ་མཚོ་ལས་བྱུང་བ་ནོར་བུའི་གཏེར་ཆེན་པོ། བཀྲ་ཤིས་དང་དགེ་ལེགས་མི་ཟད་པ་གོང་ནས་གོང་དུ་འཕེལ་བར་བྱེད་པ་འདི་སྔ་འགྱུར་བ་རྣམས་ལ་དཔལ་དུ་གནས་པ། དེ་ཕྱིར་སྤེལ་བར་བགྱིས་ན་དོན་ཀུན་འགྲུབ་བོ། །

这一篇，是在绕迥火猴年“光燃妙面”五月十一日，星曜等极为吉祥之时，于修行房“无死胜成洲”，从麦彭文殊欢喜金刚的心湖中涌出的大宝藏。它能使吉祥与无尽善妙日益增长，是前译派诸师的荣耀所在；所以若加以弘扬，一切事义都将成就。

【按】“འོད་འབར་གདོང་པ་བཟང་པོ”，暂译“光燃妙面”，应是该火猴年的别称，具体所指待核。存疑。
