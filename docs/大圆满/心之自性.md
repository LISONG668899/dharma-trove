# 心之自性

麦彭仁波切 造

```
སེམས་ཀྱི་རང་བཞིན་སྟོང་གསལ་དབྱེར་མེད་པ། །
བརྗོད་མེད་རྡོ་རྗེ་ནམ་མཁའི་དཀྱིལ་ལྟ་བུ། །
```

心之自性，即是空明无二无别，不可言说，坚如金刚，犹如虚空之中央一般。

```
མཐོང་ཞིང་མཐོང་མཁན་ཉིད་ཀྱང་དེ་ཉིད་ལས། །
གཞན་ན་མེད་པར་ཐིག་ལེ་ཉག་གཅིག་ཀློང་། །
```

所见与能见者本身，亦复不离于此，别无他物可得，唯是唯一明点之广袤界域。

```
བལྟ་བྱ་ལྟ་བྱེད་བྲལ་ཡང་རང་གིས་རང་། །
ལྷག་མ་མེད་པར་དུས་གཅིག་མཐོང་བ་ལྟའི། །
མཐའ་དབུས་མེད་པའི་ཉམས་མྱོང་ཁྱད་པར་ཅན། །
```

所观与能观虽本自远离能所二取，然而自己以自己、毫无余剩地、于同一时中照见，此乃无边无中之殊胜觉受。

```
བྱར་མེད་བྱ་བ་ཟིན་པའི་འབྲས་ཅན་དེར། །
མཐོང་བ་ཅི་ཡང་མེད་ཀྱང་མཐོང་འདོད་ཀྱི། །
ལྟ་བ་ཚོལ་བའི་ཞེ་འདོད་གཏིང་ནས་ནི། །
ངང་གིས་ཞིག་པའི་བློ་བདེ་ཁོད་སྙོམ་ལ། །
```

于此无所作、所作已办之果位中，虽全然无有能见可言，然而想要得见之念、寻求见地之殷切希求，皆从其根本深处，自然消融，心中怡然安乐、平等坦荡。

```
རེག་པ་འཇམ་དཔལ་དཔའ་བོའི་འོད་བཟང་ཡིན། །
```

凡触及此境者，即是蒙受勇猛文殊之殊胜光明所照触。

于火鸡年七月十七日，麦彭书写而成。吉祥圆满！

---

## 译者说明

本篇依藏文原颂重新译出。所附英译将年份系为"火鼠年"（Fire Rat），然藏文原文明作"མེ་བྱ"（火鸡年／火鸟年），二者不同，此处依藏文原文译为"火鸡年"。"རྡོ་རྗེ་ནམ་མཁའི་དཀྱིལ"（金刚虚空之中央）一语，兼取金刚坚不可摧与虚空周遍无碍二义，喻心性本自坚固而又遍在无边，故合译为"坚如金刚，犹如虚空之中央"，以存原颂两重譬喻。
