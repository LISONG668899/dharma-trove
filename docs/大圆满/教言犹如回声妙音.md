# 教言犹如回声妙音

**堪钦阿旺巴桑（阿琼堪布）造**
汉译：据藏文原文，参英译本（Joseph McClellan、Ninjyed N.T. 合译，2025年）

（译注：此篇于较古之无年份版本中，紧接于《致却扎与旺秋然丹二人教言》之后，中间以分段符隔开，可知显系致同二位弟子之作；2017年版则仅依首句字词著录标题。故英译者另据末句拟一更契合之标题，今循此意汉译为"教言犹如回声妙音"。）

---

一切诸佛语自在——无量光佛，以稀有行谊无与伦比者，于雪域教法首开风气之先者——恩德无可比拟之湖生金刚（莲花生大士），我于您足下顶礼！

您亲手所书、充满慈爱关怀之信函，连同白银宝物等种种，以及您慈悲教示取舍之道者，一一呈现于我眼前，令我心意欢悦振奋。

（译注：所列礼物一句尚属存疑，译者推测此处系仅列举弟子闭关期间所赠礼物；至于所言"教诫"究竟何指尚不明朗，或是弟子搜集若干殊胜偈颂以博堪布之欢心。）

我亦自幼依止具德善知识，虽自以为于闻思上尚属精进如法，然以己智慧力所限，前译派宗义典籍甚深广博，纵欲如理通达实属不易；今且将自己些许所悟，呈供于您。

如同《华严经》中善财童子依止善知识慈氏（弥勒菩萨）之典范，愿我亦能于自心中屡屡审察，究竟是否确实如理修持而令己心满意足。

（译注：《华严经》中善财童子与弥勒菩萨一段之要略如下：善财童子于求法旅程将尽之时，被指引至未来佛、慈心化身之弥勒菩萨处。善财来到一座宏伟楼阁——毗卢遮那庄严藏楼阁，此楼阁象征菩萨所见之宇宙。善财思惟：此楼阁乃了悟一切法空、无相、无愿之菩萨所居，乃以利益众生为志、已离世间而复现身世间教化众生者之所居，乃观空而不堕空见、行无相而恒能开悟执相之人、修无愿而不舍利他大愿行者之所居；善财由此赞叹菩萨种种功德。此时弥勒菩萨出现，于大众前称扬善财，广赞发菩提心之功德。最后弥勒令善财入楼阁中，见其广大无边如虚空，庄严殊妙，内中复有无数同样庄严之楼阁，各各广大如虚空而彼此不相妨碍。语出柯里瑞〔Thomas Cleary〕《入不可思议解脱境界：华严宗导论》第7页。）

于前译派湖生金刚（莲师）自宗之中，稀有卓绝之萨霍尔堪布之戒行，与无与伦比、吉祥龙树菩萨之见地，此二者交融无二，已被封印为一脉相承之传承教敕；于此，我确实获得了些许真实理解。

（译注："萨霍尔堪布"指静命论师〔寂护，Śāntarakṣita〕；相传其出身印度东部萨霍尔古国王族，此国约当今比哈尔与孟加拉一带。）

纵然因闻学尚浅，未能详悉戒律开许与禁止之种种细微界限，然若能以对业果决无欺诳之决定信，于内心生起舍离损害他人及其因由之心念，则别解脱戒之一切要害，庶几皆可具足圆满——我如是思惟。

至于那些空口宣称"戒律乃教法之根本"、却行杀人劫马之事，将一生耗费于经商与虚言浮谈之中而放逸散乱者——对于这类人，我实无话可说。

空性——离于一切戏论之法性，与显现——决无欺诳之缘起，此二者并不相违，实乃相辅相成、彼此为伴而共同运行者；如是，我已善加照见前译派宗义之心要所在。

有为之善与无为之善，二者彼此并不相违；以空性与缘起无二平等之理，当知二者并非交替、各行其一。有为之善行，实无人能加以阻碍。

（译注："各行其一"对译"res 'jog"，此语更直译当作"轮替""一次仅取其一"。末句另有一读法，可作"有为之善行，无碍于任何人"，意谓不应轻贱世俗层面之戒行伦理。）

龙树菩萨之弟子、吉祥月称论师亦曾言："悲心、无二之智，及菩提心，即是佛子（菩萨）之因。"——于此说法之理由，究竟有谁敢加以非难？

（译注：此偈引自月称论师《入中论》第一品第一颂。巴麦嘎译经组〔Padmakara Translation Group〕将此偈全文译作："声闻及缘觉，皆从大能王〔佛〕而生；诸佛复从菩萨勇士而生；悲心、无二之智，及为利他故愿成佛之心，即是佛子之因。"参见其《入中论释》第一章第一节；另可参见亨廷顿《空性之空》第149页及宗萨钦哲仁波切《入中论导论》第H3节之异译。此外，末句所用动词"非难"，原文用一颇为罕见之古语"'gong ba"，后世多以"畏惧""胆怯"或"贬抑"取而代之；因原句主语以作格助词标示，故当择及物动词而译，即"非难""质疑"之意。）

至于应当如何确切辨明所破之显现方式，能如实照见离于二边之见地者——诸佛之主龙钦然绛巴尊者，于其《宗义宝藏》中开示：所应破除者，乃"实有"。

（译注：为便于理解，此处"确切辨明所破之显现方式"采较通俗之译法；若依中观论式之专门术语直译，当作"确定所破境之显现方式"。堪布阿琼所致信之弟子本对此类术语颇为熟稔，未必视为艰深名相，故从简处理。又，"所应破除者乃实有"一句，译者未能于龙钦巴原著中寻得逐字对应之原文；然"安立所破"实为佛教哲学文献中之一大主题，"实有"〔bden grub〕作为所破，于《宗义宝藏》通篇亦多有论及。例如龙钦巴云："凡依缘起而生起之法，其自性即离于实有，譬如影像。"〔巴伦《宗义宝藏》英译本第109页〕堪布阿琼于其《普贤上师言教》中，亦用与此处相同措辞，谓自我虽显现为实有，然实无实有可言（参见该书第211页及第311页注231）。同样，此类"实有当于见地中被破除"之说，亦遍见于龙钦然绛巴《休息三部》。例如于《心性休息》中云："所取境与能取心，非为二法，本自元成清净中无二；于此，取舍亦非二法，无有片面之肯定或否定；一切显现皆离于实有，一切生起本性即空，一切平等而离诸戏论。"〔巴麦嘎译《心性休息》第十章第26颂〕）

《休息〔三部〕》中同样说道："显现本身不缚人，执著于彼方为缚。"——断除对显现之实有执著，即是中道之路；能于"非一非多"之理中获得决定，即是所谓中观之见地。

（译注：此二句乃底洛巴对那洛巴所说之名言："孩儿，显现不缚汝，执著方缚汝；那洛巴，当断执著！"龙钦然绛巴曾于《休息三部·休息车》中引用此语，见龙钦然绛巴著作第77页。又，"非一非多"乃中观"四大理聚"之一，米滂仁波切与堪布诺登解释道："简言之，一切有为与无为诸法，皆不能证明具有任何真实之'一'；而'一'既不成立，则由'一'所构成之'多'，亦必然不得成立。"语出《中观四大理聚》，亚当·皮尔西英译。）

应成派与自续派二者，于所破之认定，以及安立名言之界限上，虽有细微与粗略之差别，然此二派之说纵使于诸宗义中如风声般人人称说，若仅止于人云亦云、依样复述，又有何益？

（译注：堪布阿琼于《四宗种子略说》一文中曾界定自续派："自续派侧重于与后得位相关、涉及主张之'名言胜义'，其法门主要适用于渐次修证之人，故此派将世俗又分为正世俗与邪世俗……依'非一非多'之理，内外诸法于胜义中皆无自性；然虽无实有，仍依缘起而不断显现，空性与缘起遂成无二一体。"其对应成派之描述则为："应成派之法门着重于远离一切主张之等引，主要适用于能顿超顿证之人；此派另立一微细所破，即自续派于世俗中执为存在、于胜义中执为不存在之执著，此种微细执著于应成派中即被视为所破。"）

至于安立名言之界限、此"名言量"一事，纵使高下诸乘各有其自宗之说甚多，然若执意证明唯此一宗为是、余者皆为致惑之因，岂不因此堕入邪见歧途？

（译注：裴悌〔Pettit〕解释道："中观论师依所量对境之别，将量分为世俗与胜义二种。依中观所言，凡世俗中存在者，皆离于自性。世俗诸法由世俗量所知；世俗量乃是了知因果等世间层面所必需者，且能辨别彻底虚妄（例如显现为蛇之假相）与实际情形（例如实为一条盘绕之绳）之别。世俗量所了知者，非诸法如何'存在'，而是诸法如何'显现'。一切诸法之自性即是空性，此乃胜义，由胜义量所了知；胜义量所关涉者，乃诸法实际存在之方式，无论其显现方式为何。"语出裴悌《米滂〈定解宝灯论〉》第108页。）

唯耽于方便道、而将其誉为"唉旺（EVAṃ）道"者——声势虚张而实修者寥寥；而对于基界与本智双运之道，我虽已如实获得决定，然对于宣扬秘密之事，仍心存疑虑而不敢轻率。

（译注：梵语"唉旺"表智慧与方便、空性与大乐、母续与父续等诸种双运之合一，此处"唉旺之道"用作金刚乘之代称；堪布阿琼既已劝诸弟子精勤研习教理，此处则提醒彼等：若耽溺繁多密法仪轨而未深入其内义，则不过徒然虚耗时光。于寻常语境中，"唉旺"仅表"如是"之义，如经典开首"如是我闻"。参见创古仁波切《空间之瞥见：女性原则与唉旺》；阿诺德《空间恒在》。又，"基界与本智双运之道"与米滂仁波切所述之胜义相合："显与空之双运，即是不可言诠、究竟之胜义，乃圣者无二智所行境。"语出裴悌第109页；此课题于多杰旺秋〔Dorji Wangchuk〕之论文《佛与成就者相遇之处：米滂之双运论哲学》中有详尽论述。再者，将秘密宣示给不适之听众，乃金刚乘十四条根本堕之一，参见《金刚乘根本堕摄义》，亚当·皮尔西英译，罗刹瓦之家网站，2017年。）

能令人证悟经、密二教决无相违之典籍，即是那部宏大之圣典——《如意宝藏论》——此论轻松畅达地为人解开诸佛之密意，圆满开示一介凡夫由始至终之修道次第。

（译注：龙钦然绛巴之《如意宝藏论》，共二十二品，连同其自释《白莲论》及相关诸论，"总摄大乘佛法之全体教理，阐明大乘与金刚乘之研习、抉择与修持之道"。语出图丹〔Thondup〕《大圆满之修持》第155页。）

望您明晓，凡似是而非、自相矛盾之诡辩逻辑，皆属人为造作之伪理。我如是致信，仅是聊供您赏玩品味而已；我对自宗并无贪恋，于他宗亦无嫌恶，纠缠于言辞之争辩，实乃幼稚愚童之行径耳。此信恰如岩崖回声之美妙音声一般，谨以恭敬之心，呈献于您。
