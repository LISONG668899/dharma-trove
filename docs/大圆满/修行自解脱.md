# 至极大圆满成佛之甚深方便——修行自解脱

## 心性窍诀总说

我们所说的"空性法身"，是一切上师、一切成就者共同的心誓所依；是过去、现在、未来三世一切诸佛的密意；是一切本尊的命脉；是一切空行母的心血；是一切护法安住的依处；是一切经续的精髓；是一切密咒、明咒的心要精华；是将大手印、大圆满、大中观三者合而为一而宣说的教法；是直指法身与自心无二无别的窍诀。它被称为"知一全解"，被称为"一法即足的法王"，被称为"诸法实相的大手印"。若于晨间证悟，即是晨间成佛；若于夜间证悟，即是夜间成佛——像这样，名号极为广大，意义也极为广大。而这一切名相所指的，其实就是：让自己这颗心保持在本然空性、毫不造作的状态之中，任凭它自然生起之处，直接安住——这便是它。

修行者，无论男女，如果希望证悟无误的真实见地，就应当让自心安住在本自空性、不加造作、鲜活明朗的状态之中。心若安住不动，就在安住不动之处，不加造作地安住；心若无所忆念，就在无所忆念之处，不加造作地安住。总而言之，不论心中生起什么，都要在其生起之处，不加造作地安住，不做任何取舍、遮止或成立。无论出现什么，都要在其出现之处，不加造作地安住。

不要把自己的心刻意收摄向内，也不要向外寻找什么作为观看的对象；只需让那能看、能想的心本身，不加造作地安住其处。同样，也不要把心刻意收摄向内，也不要向外寻找什么作为禅修的所缘；只需让那正在禅修的心本身，不加造作地安住其处。

自己的心，是寻找不到的——心的本性从来就是空性；不需要寻找，那个正在寻找的，正是它自己。只需让那寻找者本身，不散乱地安住其处。

无论心中生起"我明白了吗？""不明白？""是不是需要找到点什么？""对不对？"这类念头，都只需让那个正在这样想的心本身，不加造作地安住其处。无论生起好的还是坏的、善的还是恶的、欢喜还是悲伤，任何忆念，都不要取舍，只需让那忆念者本身，不加造作地安住其处。无论出现想要的还是不想要的，都只需在其出现之处，不加造作地安住。

正如口耳相传的窍诀中所说：

```
基无改即是大手印，
道无改即是大中观，
果无改即是大圆满。
```

### 遣除违缘、令自心不受障碍而不加造作

要略微遣除对上述"不加造作"的障碍，可以这样做：

当心念纷杂、粗猛躁动、东想西想之时，让身、语、意三门彻底放松；就在这松弛的状态中，对那纷乱、散逸的心加以看护、照料，不使它落入散乱，如此安住。

当心中生起细微而快速、似觉非觉的念头时，把觉性完全收拢、聚合起来，让它鲜活、清晰、锐利、崭新地安住，保持挺立、当下现前。

当心陷入沉没、昏暗、浑浊三种状态时，不要去寻求乐受或明受的觉受，也不加任何造作对治，只需任其安住本处即可。

当心中生起欢喜或悲伤时，不要散乱，只需让那个感到欢喜、感到悲伤的心本身，安住其处。

当欢喜、欣悦、称心如意、受人恭敬之事出现时，不要被"欢喜之魔"所掌控，扬扬得意、心浮气躁地任由自己飘飘然；而应当低下头，平息这份得意的显现，让身心在从容、松缓之中安住。

当生病、受苦、被偷盗抢劫、遭受恶言中伤、诽谤、殴打、遇到恶缘、忍受饥荒等种种逆境出现时，不要垂头丧气，不要面容失色，不要落泪；而应当保持欢喜畅快、精神饱满、面带微笑地安住。

### 揭示心的破绽——种种修行误区

有些男女大修行者，认为"我大概认不出心的本性了"而心生忧苦，泪水涟涟地流下来——其实完全不需要忧苦，没有什么是认不出来的。只需让那个认为"我认不出心性"的心本身，安住其处，那正是它自己（正是所要认的心性）。

有些大修行者说，护持对心性的认识非常困难——其实一点也不困难，这只是不懂如何禅修所致的过失。既不需要去寻找禅修，也不需要去求取、去成办、去奔波、去用功；只需让自己的心，任其所生、任其所现地安住，就足够了。自己的心，从本以来就是自己所固有，没有什么可以被抛弃、也没有什么可以被寻得，没有什么"有"，也没有什么"无"。这颗从本已然存在的心，忆念之时便忆念，不忆念之时便不忆念——这个"如是存在着"的状态，正是它自身。无论心中生起什么忆念，都不加造作，任其自然、不散乱地护持，这就足够了。安乐与轻松，自然会随之而来，力量自现。如果在修法上感到困难重重，那正是自己罪障深重的征兆。

有些大修行者，不让所需要的那颗心安住在它本处，反而对不需要的心，向外张望、向内搜寻，做种种探求。这样向外看、向内探，是无法认出心的，这是不解其义的过失。根本不需要向外看、向内探；只需让那个正在向外看、向内探的心本身，安住其处，那正是它自己。

有些大修行者，不让心在忆念时就安住于忆念、不忆念时就安住于不忆念，反而以为"它应该是从别处来的"，向外寻、向内探，结果反而认不出、证悟不了心的本性。根本不需要向外寻、向内探；只需让心在忆念时安住于忆念、不忆念时安住于不忆念，那正是它自己。

有些大修行者，不相信自己心的空性，怀疑"这是不是啊？"——这是不解其义的过失。不需要怀疑，自己的心从本以来就是空的，只需安住在这空性的状态之中，那正是它自己；若生起了怀疑，就让那怀疑本身，安住其处，那也正是它自己。

有些大修行者，不去看那能忆念的心本身，反而去看忆念所对之境——财物、田地、石头等等——这不是真正的见地，而是能所二取的见地。应当看着那能忆念的心本身，让它安住。

有些大修行者，不让显现与心保持无二无别地安住，反而追逐显现本身、随之而去——这不是真正的见地，而是二元显现的见地。不要向外追逐显现，也不要把外境硬拉扯成某种样子，而应让显现与心，无二无别地安住。

有些大修行者，不让心安住在自己本处，反而像猫盯着老鼠一样，紧盯着念头会不会生起——这不是真正的见地，而是在念头未生之前就预先迎候它。念头若生起，就在其生起之处安住；若不生起，就在其不生起之处安住。

有些大修行者，不懂得让心安住在自身本处，反而不断回顾、追随之前的念头而去——这不是真正的见地，而是"追截于忆念之后"。不要在忆念之后去追截它，而应让那个想要追截的心本身，安住其处。

有些大修行者，不让心安住在其自然所处、任运所现之处，反而渴求一种"美妙的禅修"，把心绷得紧紧的、板板正正地做出种种造作——这不是真正的见地，而是对心的做作、加工。不对心做任何加工、造作，而应让心，随其自然所处、任运所现之处安住。

有些大修行者，不容许任何念头生起，硬是用力压制、抓住心不放——这不是真正的见地，而是对心的压制、遮止。心若安住不动，就在安住不动之处安住；若躁动，就在躁动之处安住。

有些大修行者，像伺机猎杀猎物一般，紧张兮兮地严加看守自己的心——这不是真正的见地，而是"心的守候戒备"。应当在空性的状态中，鲜明清晰地安住。

有些大修行者，心想"这颗心的本身就是空性"，据此而修——这不是真正的见地，而是造作出来的空性禅修。应当让那个想着"这就是空性"的心本身，安住其处。

有些大修行者，当轻松、空明、鲜活清晰的觉受生起时便去观看，而当粗猛、纷扰、混浊、松垮空荡、无所可观的状态生起时便不去观看——这不是真正的见地，而是取舍。不做任何取舍，无论生起什么，都在其生起之处安住。

有些大修行者，善的念头生起时便去观看，恶的、丑陋的念头生起时便不去观看——这不是真正的见地，而是"取善舍恶"。不做取善舍恶，无论善念、恶念生起，都不散乱地安住其处。

有些大修行者，心情舒畅时就欢喜，粗猛的分别念生起时就对自己的心生起嗔恨——这不是真正的见地，而是不懂得护持一切显现本体的过失。当粗猛分别念生起之时，应当在放松、松缓的心境中，让那份躁动本身安住其处。

有些大修行者，不管需不需要，一概既不收紧也不放松——这不是真正的见地，这会让些微的造作趁虚而入，是不懂心之所住的过失。需要收紧、放松时就收紧、放松；不需要时，就不做任何收紧或放松，让心以其自然的样子鲜明清晰地安住。

有些大修行者，一想到美味可口的饮食便无法继续禅修，起身四处寻觅美味佳肴，享用一番——这样做，是无法成就"以禅悦为食"的良好禅修的；贪图口腹之欲、图求安逸享受，只会造就出一个可怜巴巴的所谓"大修行者"。因此，应当不贪著饮食美味，而以禅定的资粮为食。

有些大修行者，当安乐、受用、尊贵、赞誉等出现时，便无法继续禅修，欢天喜地、乐不可支；当痛苦、恶缘、疾病、诋毁、讥讽、口角是非等出现时，也无法继续禅修，面色如乌云密布一般阴沉，口中大倒苦水，眼泪直流——像这样，是无法成为一个能够苦乐平等、安然自在的良好修行人的；只会沦为被欢喜、痛苦这世间八法所左右、毫无佛法气息、可怜庸俗之人。因此，无论欢喜还是痛苦，都必须一律平等对待，将其转为道用。

## 心之解脱相

诶玛吙！

```
心之自性，从本以来即无实体；
纵然观察，也了无所见，唯成空性；
然而并非顽空，具有明觉、了了分明；
明空无二，遍及一切，犹如虚空；
纵然安住，也无所依，通透无碍；
纵然放任不管，它也自然回归本处；
虽无手足，却能奔驰周遍一切处；
纵然舍弃、任其而去，它也不曾离去，自然回归本处；
虽无眼目，却能了知一切；
所了知的这份显现，终归于空性；
心的本体，无法说"它就是这个";
虽无从指认，忆念、觉知却纷然显现；
说它"有"，则终归于空；
说它"无"，则忆念、觉知宛然显现；
显与空双运无别，光芒炽然；
空明即是法身，自身的光华了了分明；
具足五种智慧，极为广大圆满；
本净的实相与任运自成，
以及色身、刹土，无碍地显现；
母光明与子光明，融合为一体；
心的实相，本来便是如此——
诸位是否已经证悟？具证悟者们！
诸位是否已经了知？大了知者们！
瑜伽行者们，愿你们如实修持！
```

## 迷乱自解脱的窍诀——转毒为药

空性之中，本无吝啬；因迷乱之力，才生起吝啬。且不迷乱地照见这令吝啬生起的本体——照见之后，护持而不散乱，吝啬便自然消融，化归空性。安住在空性之中，不要散乱，这就是吝啬彻底清净的状态，此外再没有比这更殊胜的布施了。瑜伽士啊，若能证悟此理，何其稀有！

空性之中，本无贪执；因迷乱之力，才生起贪执。且不迷乱地照见这令贪执生起的本体——照见之后，护持而不散乱，贪执便自然消融，化归空性。安住在空性之中，不要散乱，这就是贪执彻底清净的状态，此外再没有比这更殊胜的持戒了。瑜伽士啊，若能证悟此理，何其稀有！

空性之中，本无嗔恨；因迷乱之力，才生起嗔恨。且不迷乱地照见这令嗔恨生起的本体——照见之后，护持而不散乱，嗔恨便自然消融，化归空性。安住在空性之中，不要散乱，这就是嗔恨彻底清净的状态，此外再没有比这更殊胜的安忍了。瑜伽士啊，若能证悟此理，何其稀有！

空性之中，本无懈怠；因迷乱之力，才生起懈怠。且不迷乱地照见这令懈怠生起的本体——照见之后，护持而不散乱，懈怠便自然消融，化归空性。安住在空性之中，不要散乱，这就是懈怠彻底清净的状态，此外再没有比这更殊胜的精进了。瑜伽士啊，若能证悟此理，何其稀有！

空性之中，本无散乱；因迷乱之力，才生起散乱。且不迷乱地照见这令散乱生起的本体——照见之后，护持而不散乱，散乱便自然消融，化归空性。安住在空性之中，不要散乱，这就是散乱彻底清净的状态，此外再没有比这更殊胜的禅定了。瑜伽士啊，若能证悟此理，何其稀有！

空性之中，本无愚痴；因迷乱之力，才生起愚痴。且不迷乱地照见这令愚痴生起的本体——照见之后，护持而不散乱，愚痴便自然消融，化归空性。安住在空性之中，不要散乱，这就是愚痴彻底清净的状态，此外再没有比这更殊胜的智慧了。瑜伽士啊，若能证悟此理，何其稀有！

空性之中，本无骄慢；因迷乱之力，才生起骄慢。且不迷乱地照见这令骄慢生起的本体——照见之后，护持而不散乱，骄慢便自然消融，化归空性。安住在空性之中，不要散乱，这就是骄慢彻底清净的状态，此外再没有比这更殊胜的知足少欲了。瑜伽士啊，若能证悟此理，何其稀有！

## 烦恼自解脱的窍诀——转恶念为智慧

以转烦恼为智慧的方式而言：在不散乱的状态中，本无痛苦；因迷乱之力，才生起痛苦。不散乱地照见这痛苦的本体——照见之后，不散乱地护持它，痛苦便消融不存，化归空性。在空明的状态中，不要散乱地安住，这就是痛苦彻底清净的状态，这便称为"大乐法身"。

在不散乱的状态中，本无烦恼；因散乱之过，才生起烦恼。不散乱地照见这烦恼的本体——照见之后，不散乱地修持，烦恼便消融于空性。在空性的状态中，不要散乱地安住，这就是烦恼彻底清净的状态，这便称为"无生法身"。

在不散乱的状态中，本无嗔恨；因散乱之过，才生起嗔恨。不散乱地照见这嗔恨的本体——照见之后，不散乱地修持，嗔恨便消融于空性。在空明的状态中，不要散乱地安住，这就是嗔恨彻底清净的状态，这便称为"大圆镜智"。

在不散乱的状态中，本无骄慢；因散乱之过，才生起骄慢。不散乱地照见这骄慢的本体——照见之后，不散乱地修持，骄慢便消融，趋于空明。在空明的状态中，不要散乱地安住，这就是骄慢彻底清净的状态，这便称为"平等性智"。

在不散乱的状态中，本无贪欲（执取）；因散乱之过，才生起贪欲。不散乱地照见这贪欲的本体——照见之后，不散乱地修持，贪欲便消融，趋于空明。在空明的状态中，不要散乱地安住，这就是贪欲彻底清净的状态，这便称为"妙观察智"。

在不散乱的状态中，本无嫉妒；因散乱之过，才生起嫉妒。不散乱地照见这嫉妒的本体——照见之后，不散乱地修持，嫉妒便消融，化归空性。在空明的状态中，不要散乱地安住，这就是嫉妒彻底清净的状态，这便称为"成所作智"。

【译注：此处"成所作智"，此前已有的英译中文转译本误重复作"平等性智"（与骄慢一句雷同），核对藏文原文为"བྱ་གྲུབ་ཡེ་ཤེས"，意为成所作智，与骄慢所转之"平等性智"（མཉམ་ཉིད་ཡེ་ཤེས）并非同一智慧，今据藏文订正，以符合密乘五毒转五智——嗔转大圆镜智、慢转平等性智、贪转妙观察智、嫉转成所作智、痴转法界体性智——的通常安立。】

在不散乱的状态中，本无迷惑（愚痴）；因散乱之过，才生起迷惑。不散乱地照见这迷惑的本体——照见之后，不散乱地修持，迷惑便消融于空性。在空明的状态中，不要散乱地安住，这就是迷惑彻底清净的状态，这便称为"法界体性智"。

在不散乱的状态中，本无沉没昏暗；因散乱之过，才生起沉没昏暗。不散乱地照见这昏沉的本体——照见之后，不散乱地修持，昏沉便消融，趋于空明。在空明的状态中，不要散乱地安住，这就是昏沉彻底清净的状态，这便称为"空明智慧"。

在不散乱的状态中，本无掉举散逸；因散乱之过，才生起掉举散逸。不散乱地照见这掉举的本体——照见之后，不散乱地修持，掉举便消融，趋于空明。在空明的状态中，不要散乱地安住，这就是掉举彻底清净的状态，这便称为"不动智慧"。

在不散乱的状态中，本无贪嗔痴三毒；因散乱之过，才生起三毒。不散乱地照见这三毒的本体——照见之后，不散乱地修持，三毒便消融，趋于空明。在空明的状态中，不要散乱地安住，这就是三毒彻底清净的状态，这便称为"三身智慧"。

## 为生起定解而说明心的种种来相

大修行者的心中，有时会毫无所思、空空荡荡，出现这种情形时，不要加以任何造作，让它鲜明地安住在自己的本处即可。

有时会出现一种鲜明清晰、安乐轻软的状态，出现这种情形时，就让那颗心鲜明、清晰地安住。

有时会出现心识一片昏黑、空茫混沌、怎么也清晰不起来的状态，出现这种情形时，要把觉性清晰地提振出来，让它赤裸、挺立地安住。

有时痛苦会强烈地袭上心头，出现这种情形时，要保持欢喜、轻松、愉悦、自在。

有时似乎只安住片刻便无法持久，隐隐约约地像有细念游移飘过，出现这种情形时，要把心稍稍收紧，同时内里保持松缓地安住。

有时心似觉非觉、忽隐忽现，出现这种情形时，要如同从酥油中拈出一根毛发一般，将清晰的觉性精细地提炼出来，不散乱、挺立分明地安住。

有时妄念纷飞、忽上忽下，连片刻也安住不住，出现这种情形时，要在身心放松的状态中，不落入散乱，善加照护、看管，让它安住。

有时会生不起禅修的兴致，心中郁郁、坐立难安，出现这种情形时，要恳切地祈祷上师，让显现安住在安乐、轻松、喜悦之中。

有时会生起圆满俱足的安乐与明性，欢喜洋溢，甚至想要手舞足蹈，出现这种情形时，不要让执著介入自己的心，只需彻底放松地安住。

以上这些心的种种来相，都是初学者尚未对实相获得决定见时才会出现的；对于已经能够获得决定见的人而言，是不会再出现这些的。这里稍加解释：当对实相获得决定的了悟之时，甚至不必再"看"，光明便会自然显现出来；甚至不必再"修"，心性自己就能持守本地；纵有散乱，也不算散乱，心性自己就能把持分寸；纵有变化，也不算变化，忆念与觉知遍满犹如虚空；不需要任何造作，便安住在光明的状态之中。自心那不散乱的法身，与诸佛密意的法身，在无二无别的光明中融合为一。当已经获得不散乱的自主之后，从空性法身的境界之中，任运自成的光明现前之时，自心与佛便无二无别，色身与刹土也会不间断地显现出来，没有希求、没有恐惧、没有我执，没有欢喜与忧愁，远离了取舍与种种疑虑——当自心真正获得决定之时，便会是这个样子。

## 如何在四种威仪中修持

大修行者行走之时，不像疯狂的人那样又跑又跳，而是在身心从容、松缓的状态中，护持自心，不使散逸，如此行走。

大修行者安坐之时，不让思绪如念珠般一颗接一颗地攀缘不断，而是端正身要，让自己的心赤裸裸地安住其中。

大修行者睡眠之时，不像陷入愚痴昏沉的尸体一般沉睡，而是以狮子卧的姿势躺下，让心不散乱地融入光明之中。

大修行者饮食之时，加持饮食化为甘露，观想自身即是空行母（有异本作"寂静忿怒本尊"）的坛城眷属，在心性不散乱的状态中受用饮食。

【译注：此句藏文原文有两种写法："空行之众"（མཁའ་འགྲོའི）与"寂静忿怒尊之众"（ཞི་ཁྲོའི），二者义近，皆指将饮食观修为供养清净圣众而受用，今依原文并存两说。】

无论行、住、卧、食，都应在空性无别的状态中而行；若想在临终之时不生疑悔，愿自心与佛无二无别，就必须如此修持。

## 修行必备之要点

- 必须懂得如何依止具足法相的上师；
- 必须舍弃世间纷繁复杂的种种事务；
- 必须具备能独自安住山林、堪忍苦行的毅力；
- 必须经历断除对饮食衣物贪执的苦行；
- 必须精进不懈，不容许有片刻的散乱；
- 必须具备远离一切能所二取的正见；
- 必须修持不散乱、遍满周遭的光明；
- 必须具足远离勤作与取舍的行持；
- 必须证得自心与佛无二无别的果位；
- 必须持守没有贪执、也没有虚伪掩饰的誓言；
- 必须远离渴求人人都喜爱、认同自己的骄慢之心。

有福缘的修行人啊，请务必依此实修，这些才是最为紧要的！

## 若想具备助修的殊胜盔甲，应当如此

- 不聚集众多仆从眷属、充当他们的头领；
- 不积聚巨额财物、充当它们的主人；
- 不豢养成群的牛马、为它们操心照料；
- 不做众多亲眷的领头人；
- 对怨敌与亲友，都不生起贪爱或嗔恨；
- 不从事耕作、手工等种种劳作；
- 不为求取受用、利养、声名而操持生计；
- 不为追求权势、名望而处心积虑。

如果不断除以上这些，自心便会被散乱所裹挟而去；若能断除这些，自心便能牢牢占据、稳固自身的据点；自心一旦稳固地占据自身，便是真实的成佛。

如今这样的时代里，纵然有善于教授的上师、善于修行的弟子，也仍有许多人未能证悟这颗自心，仍有许多人未能证悟真实的意义。心之本性空明的这份本体，并非只在某一人身上才能显现，而是对一切人都能显现；懂得这一点的人，可以广泛请教众人，便能得以明了。多多请教有智慧的人，理解自然就会到来；不要心怀疑虑，放下疑惑去修持。

【译注：此段藏文原意为"仍有许多人未能证悟自心"，此前已有的英译中文转译本将此处的意思译反，成了"众多亦证心本性""亦有证悟真实义"，与原意恰恰相反，今据藏文订正。】

## 致大修行者的一则重要教诫

还有一则对大修行者极为紧要的教诫，在此宣说：

如今这样的时代里，有些上师、有些弟子，上师教得不如法，弟子修得也不如法，以至于即便修行了七八十年，仍有许多人未能生起觉受与证悟，仍有许多人未能证悟真实的意义，仍有许多人把不是证悟的东西，当作证悟来炫示；有许多人在懵懂无知中盲目地修持，有许多人徒然耗费精进却毫无意义。

【译注：此处"修行了七八十年"，藏文原文明确作"七十至八十年"（བདུན་ཅུ་བརྒྱད་ཅུ），此前已有的英译中文转译本误作"八年"，与原意相差悬殊，今据藏文订正——正因是穷尽一生修行仍未必证悟，此语才更显得振聋发聩。】

所以，上师应当善于教授，弟子应当善于修持；不要自视甚高，而应向有智慧的人请教；不要凭自己臆想编造，应当对自心痛下决断，一刀两断地了断疑惑；不要自己蒙骗自己的头脑，应当做到毫无疑虑。

圆满。

再者，又说道：

啊吙！

自心本基的实相，远离一切戏论——这是见地；
建立起不灭、周遍的悲心坛城圣众——这是禅修；
将一切转为形形色色忿怒男女尊的游舞——这是行持；
愿此成为引导遍满虚空一切众生的殊胜吉祥！
