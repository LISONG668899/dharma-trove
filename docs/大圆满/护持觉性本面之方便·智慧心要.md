# 护持觉性本面之方便·智慧心要

麦彭仁波切 造

顶礼吉祥本初怙主！

护持觉性本面，有"识""圆满其力""获得坚固"三个阶段，依次而至。

## 一、识

首先，依上师之窍诀教授，将心意间之揣度分别尽皆断除、澄清提炼，直至赤裸照见觉性之本来面目。一旦决断确认之后，唯有自己护持此本体，方为至要；仅仅识得是不够的，必须圆满其力。

再者，虽然最初已识得觉性本面，然而若不能起初便善加安住，便会被分别念所间断，令觉性难以赤裸显现。因此，对分别念不加遮止、亦不加成立地任其安住，一再地令觉性安住于不加造作之状态中、并延长其时间，实为要点。

## 二、圆满其力

如是反复串习之后，分别念之波涛势力渐弱，觉性本面愈发明晰、护持亦渐趋轻易之时，于等持之中，应尽量安住于此之上；于后得位中，应依止忆念觉性本面之正念。

若能串习此理，觉性之力将渐趋圆满：

最初，纵然分别念生起，亦不需依赖其他对治之法加以遮止，只需任其安置于本位，片刻之间便能自然解脱，犹如蛇自解其身所打之结一般。

复次，随串习加深，纵然分别念生起而略有搅扰，也会当下自然消融，犹如于水面绘画一般。

于此境界中串习之后，纵然分别念生起，亦丝毫无损，对其生起与否再无希冀忧惧，犹如盗贼潜入空屋一般，生起无利无害之觉受。

## 三、获得坚固

于此境界中继续串习，力用臻于究竟圆满，终至分别念与阿赖耶（一切基）、连同令其动摇之气，一并融入不假造作之法身，觉性于其本位牢牢摄持。

犹如于黄金洲寻觅寻常土石，纵然寻觅，亦不可得一般，一切显现有法，无余悉皆显现为法身之刹土，转成周遍无边之清净之时，即称为"获得坚固"；于轮回涅槃、生死之希冀忧惧，皆从根本上彻底摧毁。

如是，昼间之显现分别，依次纳入觉性掌控之次第；夜间亦复如是，不需依赖其他窍诀教授，于梦境以及浅眠、沉眠中把握光明等，皆以同理类推而知。务必于尚未获得坚固之前，将无散乱之精进，如江河之流水般相续不断。

此乃麦彭所授之教言。愿善妙增长！

## 译者说明

本篇依藏文原文重新译出，为一篇论述大圆满立断修法中"护持觉性"之次第的散文体教言，非偈颂体，故译文亦依原文体例，以散文行文，不作分行处理。全文以"识、圆满其力、获得坚固"三阶段为纲，各阶段又以"蛇自解结""水面绘画""盗贼入空屋""黄金洲寻石"等譬喻层层递进，说明觉性护持由生疏到任运自在之进程，译文皆依原譬喻直译，以存其生动之喻意。
