# 无谬指认大圆满见地之道歌

堪布岗夏旺波 造

顶礼法王足下，以头顶礼；愿加持我照见光明！

呜呼，具善缘种姓之子啊！

```
བེ་ཕུར་ཐང་དུ་བརྡབ་པ་བཞིན། །
ལུས་པོ་གཡོ་འགུལ་མེད་པ་སྡོད། །
ལོག་བྲིས་ལྷ་སྐུའི་སྤྱན་ཕྱེ་བཞིན། །
མིག་གཉིས་འགྱེད་འཛུམ་མེད་པར་ཞོག །
རས་བལ་ཐང་ལ་བརྡལ་བ་བཞིན། །
ཤེས་པ་ལྷོད་ཀྱི་གློད་པ་ཞོག །
```

犹如木橛钉入平地一般，端身安坐，不动不摇；犹如壁画中佛像睁开之双眼，两眼既不睁大、亦不闭合，平视安住；犹如羊毛铺展于平地一般，令心识松坦、放松而安住。

```
བཞག་ཚེ་རྣམ་རྟོག་འགགས་ཤུལ་ན། །
སྤྲིན་མེད་མཁའ་ལྟར་གསལ་སང་ངེ། །
དྲི་མེད་ཤེལ་ལྟར་ཟངས་ཐལ་ལེ། །
འདུག་པ་དེ་ཀ་དོན་དམ་པའི། །
འོད་གསལ་རྫོགས་ཆེན་ལྟ་བ་ཡིན། །
དེའི་ངང་ལ་མཉམ་པར་ཞོག །
```

如是安住之时，分别念止息之后，犹如无云晴空一般明朗朗然，犹如无垢水晶一般透澈洞然；如是而住，此本身即是究竟胜义之光明大圆满见地。应于此境界中，等持而安住。

```
མཁའ་ལྟར་དག་པའི་འོད་གསལ་དེ། །
བྱིང་རྨུགས་གཉིས་ལ་མ་ཤོར་སྤོངས། །
དྭངས་ལ་མི་རྟོག་བསམ་གཏན་དང་། །
ནོར་ཉེས་ཆེ་བས་ནོར་མི་རུང་། །
```

此犹如虚空般清净之光明，切莫将其误认为沉没与昏沉；与澄澈无念之禅定相混淆之过失甚大，故万万不可有所混淆。

```
བཟང་ངན་རྣམ་རྟོག་ལངས་པའི་དུས། །
རྣམ་རྟོག་ཕྱིར་དུ་ཕར་མ་རྒྱུག །
ཚུར་ལ་བཀུགས་ནས་ངོ་མ་བལྟ། །
གང་ཡང་བྱ་རྩོལ་མ་བྱེད་པར། །
ཤེས་པ་ལྷོད་ཀྱིས་ཀློད་ལ་ཐོང་། །
རྣམ་རྟོག་རང་སར་ཞི་བར་འགྱུར། །
```

当善恶分别念生起之时，莫向外追逐此分别念，当将其收摄回内、直视其本面；不作任何造作勤求，令心识松坦、彻底放松，分别念便会于本位自然平息。

```
ཡུན་རིང་མཉམ་པར་བཞག་པའི་ཚེ། །
དཔེར་ན་ཆུ་རྙོག་དྭངས་པའི་ནང་། །
སྣ་ཚོགས་གཟུགས་སྙན་འཆར་བ་བཞིན། །
སེམས་ཉིད་ཇེ་དྭངས་ཇེ་གསལ་དུ། །
སོང་ནས་སྤྱན་དང་མངོན་ཤེས་སོགས། །
ཡོན་ཏན་མང་པོ་འབད་མེད་འཆར། །
```

长久等持安住之时，譬如浑浊之水澄清之后，种种悦意之影像得以显现一般，心性亦愈发澄澈、愈发明晰，由此，天眼与神通等种种功德，将无勤而显现。

```
ཨོ་རྒྱན་དངོས་སུ་བྱོན་ན་ཡང་། །
རྫོགས་ཆེན་ལྟ་བ་དེས་ལྷག་མེད། །
ཀློང་ཆེན་རབ་འབྱམས་བྱོན་ན་ཡང་། །
རྣམ་རྟོག་ལམ་འཁྱེར་དེ་ལྷག་མེད། །
རྗེ་འབངས་ཉེར་ལྔ་བྱོན་ན་ཡང་། །
ཉམས་མྱོང་གསུང་རྒྱུ་དེ་ལྷག་མེད། །
རྣལ་འབྱོར་ང་རང་ཉམས་མྱོང་དང་། །
འདྲ་ཡང་བསྒོམ་རྒྱུ་དེ་ལྷག་མེད། །
```

纵然邬金莲师亲自降临，于大圆满见地之上，亦无更胜于此者可说；纵然龙钦冉江亲自降临，于将分别念转为道用之法，亦无更胜于此者可说；纵然君臣二十五尊亲自降临，于所应宣说之觉受，亦无更胜于此者；瑜伽士我自己虽显现为具有觉受，然除此之外，亦无更胜之法可修。

```
སོ་སོར་རྟོགས་པས་དཔྱད་ན་ཡང་། །
རླུང་གིས་སྤྲིན་གཏོར་མཁའ་མཐོང་བཞིན། །
སེམས་ཉིད་སྟོང་གསལ་དེ་ཀ་མཐོང་། །
དེ་ལས་ལྷག་གཅིག་མཐོང་རྒྱུ་མེད། །
```

纵然以各别观察智加以分析，犹如风吹散云朵、照见虚空一般，所见者唯是此心性空明本身，除此之外，再无更胜一物可见。

```
མ་དཔྱད་རང་བབས་ངང་ལ་བཞག །
ཆུ་མ་རྙོག་ན་དྭངས་པ་བཞིན། །
སེམས་ཉིད་སྟོང་པ་དེ་ཀ་མཐོང་། །
དེ་ལས་ལྷག་གཅིག་མཐོང་རྒྱུ་མེད། །
```

不加观察，任运安住于本然境界，犹如水未搅动、自然澄清一般，所见者唯是此心性空性本身，除此之外，再无更胜一物可见。

```
ལྟ་བ་རྣམ་གྲངས་མང་ན་ཡང་། །
སེམས་ཉིད་སྟོང་པ་འཛིན་མེད་འདི། །
རྫོགས་ཆེན་ལྟ་བ་འཁྲུལ་མེད་ཡིན། །
```

见地之分类纵然繁多，然此无所执取之心性空性，即是大圆满无谬之见地。

```
རྣལ་འབྱོར་པ་དེ་འཆི་བའི་ཚེ། །
འཆི་བ་འོད་གསལ་ཟིན་པར་འགྱུར། །
འདི་ཐོས་རྒྱུད་ལ་ཕན་ཐོགས་ནས། །
འོད་གསལ་མངོན་དུ་འགྱུར་བར་ཤོག །
```

此瑜伽士临终之时，必将把握死亡之光明。愿闻此者，能有益于其相续，愿光明得以现前！

如是所说，乃愚昧老翁岗夏旺波所写，愿具有意义！

## 译者说明

本篇依藏文原文重新译出，参考但不依循已有中译本之措辞。此篇为一首指认大圆满见地之"道歌"（མགུར་མ），先以身、眼、心三要（端身如钉、目光如壁画佛眼、心识如摊开之羊毛）说明修持之外相，再以"分别念止息后明朗如晴空、透澈如水晶"指认见地本身，并特别提醒莫将此光明与沉没昏沉、或与寻常无念禅定相混淆——此为大圆满修法中极常见、亦极重要之辨析。末段以莲师、龙钦巴、君臣二十五尊等历代传承祖师为喻，反复申明"此见地之外，再无更胜者"，是藏文教言中常见的谦而不谦、以自信语气坚固所传之修辞方式，译文皆依原文直译，以存其语气。
