# 自证释疑金刚宝镜

麦彭仁波切 造

顶礼文殊师利！

```
ཐོས་ཆུང་མྱོང་བ་མེད་པ་རྣམས། །
རྫོགས་ཆེན་རང་རིག་ཅེས་པ་འདི། །
དབུ་མའི་མཉམ་བཞག་ཡེ་ཤེས་ལས། །
ས་མཚམས་དམན་པ་ཞིག་ཏུ་འཛིན། །
```

少闻寡学、又无实修体验之人，将大圆满所说之"自证"，执为较中观等持智慧更为低劣之一种境地。

```
ཀ་ཡེ་དབུ་མར་རློམས་ཁྱོད་ཀྱི། །
ཆོས་ཀྱི་དབྱིངས་ལ་མཉམ་བཞག་ཚེ། །
བློ་རྒྱུན་ཆད་དམ་མ་ཆད་འདོད། །
```

呜呼，自诩通达中观的你，请说说看：当安住于法界之等持时，心识之相续究竟是间断、还是不间断，你如何主张？

```
རྒྱུན་ཆད་འདུ་ཤེས་མེད་པའི་བསྒོམ། །
ཕྱི་མ་ལྟར་ན་བློས་ཆོས་ཉིད། །
ཉམས་སུ་མྱོང་བ་ཡོད་དམ་མེད། །
མེད་ན་ཆོས་ཉིད་ཇི་ལྟར་རྟོགས། །
```

若说是间断，那便成了无想之修；若依后一种说法［不间断］，那么以心识对法性是否有所体验？若说没有，那法性又如何能够证悟？

```
ཡོད་ན་དེ་འདྲའི་ཆོས་ཉིད་དེ། །
ཆོས་ཀུན་དེ་ཉིད་ཡིན་ཕྱིར་ན། །
ཡུལ་ཅན་དེའི་ངོར་ཆོས་ཅན་རྣམས། །
མ་འགག་སྣང་བ་ཡོད་དམ་མེད། །
```

若说有［体验］，那么如是之法性，因其即是一切诸法之真如自性故，于该能证之心识面前，一切诸法是否有不间断之显现？

```
ཡོད་ན་གཉིས་སྣང་ཇི་ལྟར་ནུབ། །
མེད་ན་ཡུལ་དང་བྲལ་བ་ཡི། །
བློ་ཡིས་ཉམས་སུ་མྱོང་ཞེས་པ། །
ཇི་འདྲ་ཞིག་ལ་མཛུབ་མོ་འཛུག །
```

若说有［显现］，那二元之显现又是如何隐没消失的？若说没有，那么所谓"脱离对境、唯以心识而体验"，究竟能指出个什么来？

```
ཡུལ་དང་ཡུལ་ཅན་བྲལ་བ་ཡི། །
སོ་སོ་རང་རིག་ཡེ་ཤེས་ཙམ། །
ཡིན་ཟེར་ན་ནི་དེ་དག་ལ། །
རང་རིག་ཅེས་སུ་མིང་འདོག་པ། །
ཡིན་ཕྱིར་རང་རིག་ཅེས་པ་འདི། །
```

若说：这不过是脱离能所（对境与有境）之别别自证智慧而已——若如此主张，那么对这一体验安立"自证"之名，也正因如此，此处所谓的"自证"，

```
སེམས་ཙམ་ལུགས་ཀྱི་གསལ་རིག་དང་། །
ཕྱི་དོན་མེད་པར་མ་ཤེས་པའི། །
ཤེས་པ་ཉི་ཚེའི་སྟོང་ཉིད་དུ། །
གོ་བ་གནས་ལུགས་མྱོང་མེད་གཏམས། །
```

便与唯识宗所说的明知明觉，以及尚未了达外境本无、只是心识片面之空性，混为一谈了——这样的理解，实乃从未体验过实相者的空谈戏论。

```
ཆོས་དབྱིངས་བསམ་མི་ཁྱབ་པའི་དོན། །
སོ་སོ་རང་གིས་ཉམས་མྱོང་བ། །
མཉམ་བཞག་ནམ་མཁའ་ལྟ་བུ་སྟེ། །
ཉི་ཚེའི་ཆོས་ཉིད་ག་ལ་ཡིན། །
```

法界不可思议之义，乃是各自亲身所体验，其等持之境犹如虚空一般，又怎会是片面局限之法性呢？

```
སེམས་ཙམ་རྣམ་ཤེས་བདེན་གྲུབ་འདོད། །
འདིར་ནི་རང་རིག་སྟོང་པ་ཆེ། །
མངོན་སུམ་མྱོང་བས་གྲུབ་པ་ཡིས། །
མཚན་མའི་དམིགས་གཏད་ཞིག་པ་ཡིན། །
```

唯识宗主张心识谛实成立，而此处所说之自证则是大空性；由现量体验而得成立，一切相状之执取所缘，皆已破除无余。

```
ཟུང་འཇུག་དབྱིངས་ལ་སུས་རེག་པ། །
དེས་ནི་ཆོས་ཀུན་དེ་ཉིད་མཐོང་། །
ཆོས་ཅན་རེ་རེའི་ཆོས་ཉིད་དག །
སོ་སོར་ཡོད་ན་ཐུག་པ་མེད། །
```

无论是谁，只要触及双运之法界，便能照见一切诸法之真如自性；若每一有法各有其别别不同之法性，则势必永无穷尽。

```
དེ་ཕྱིར་མྱོང་བའི་ཚུལ་གྱིས་ནི། །
ཟུང་འཇུག་དབྱིངས་ལ་མཉམ་གཞག་པས། །
ཡིད་དཔྱོད་གྲུབ་མཐས་བསྐལ་མང་དུ། །
གྲུབ་འབྲས་འདི་ན་མངོན་དུ་གྱུར། །
```

是故，以亲身体验之方式，等住于双运之法界当中，较之依分别心与宗派见地历经累劫方能成办者，此中之修证果实，便能当下现前。

如是所说，乃麦彭南杰于噶尔莫达仓山修行处，一次座间随心所至、信笔写下者。

---

## 译者说明

本篇依藏文原颂重新译出，参考但不依赖已有英译本之措辞。全篇以论辩体书写，逐层设问、层层推进，旨在破斥"大圆满之自证不及中观等持智慧"这一误解：作者先令持此见者自陈其中观等持是否有心识之相续、有无对法性之体验、有无二元显现，藉由层层追问，指出若离此体验而空谈"自证"，便与唯识宗尚执外境非有、心识为实之"明知"混同；而大圆满所说之自证，实为现量亲证、破尽一切相状执取之大空性，与唯识之见有本质之别。
