# 大圆满·直视本性

**献给初学者的切要引导**

**持明晋美林巴 造　白话译文**

---

顶礼本基自解脱的大圆满——以离于"能礼、所礼"分别之相的方式而顶礼。愿加持我，能在此时此刻，照见大圆满的真实意涵——那离于分别心的自明觉性的本来面目！

大圆满真实义所安立的地方，就是当下这个自心：未加任何造作、任运宽坦、丝毫没有经过整治雕琢的、清明的、赤裸裸的觉性——仅此而已，别无其他。

恒常地，无论是在饮食、睡眠、行走还是安坐之时，都不曾忘失，以这样的正念加以护持——这便叫做"修"。然而，只要还没有远离所知障，就不可能不与"乐、明、无念"这三种觉受相混杂。但即便如此，只要不是刻意用力、勉强执持的造作之念，而是从"认识自己本来面目"这个角度出发，只是保持不忘失而已——这样修习下去，终有一天，那超越了譬喻与名言的、胜义中离戏的真谛，便会自然显现出来。

再说，对初学者而言，暂且来说，由于恶劣的分别念大肆蔓延泛滥，往往会使正念涣散、走失。分别念以暗流的方式大量翻涌堆积之后，到了某个时刻，清晰的正念又会猛然重新现前，进而生起"我方才散乱走失了"这样的懊悔之心。但在那个时候，既不必去追究、了断先前那些分别念，也不必为自己的散乱而懊悔——只需就在那清晰正念猛然现前的当下这一点上，任运自然地延续护持下去即可。

"对分别念，不要舍弃'（视之）为法身'"——这句话虽然广为流传，但只要胜观的力用尚未真正圆满纯熟，若贸然这样去做，就必定会陷入一种"是这样又不是那样"、模糊不清、混沌一片的境地之中。所以，在最初的阶段，凡是分别念一生起，都只需赤裸裸地直视它，不做任何详加观察、分析、揣度，而只须将注意力转向那认知分别念的"当事者"本身——就好比老人看孩童玩耍嬉戏一样，既不去责难打扰，也毫不在意，一律以毫不在意、视之为不实的态度，稍稍搁置一旁即可。像这样长久地串习下去，终有一天，分别念便会转而以"修"的方式显现，进而达到"住"与"动"平等解脱的境地。

到了这个阶段，会依次出现"认出分别念之后、解脱为法身"，"分别念本身自然解脱为法身"，"分别念在无利无害之中解脱为法身"等等不同的层次——这些层次，必须由真正获得大圆满密意传承的殊胜善知识来加以分辨、区判。这里正含有一个最为关键的要点，使它有别于其他乘门以心识观察、分析的方式，将分别念视为法身的做法——追随那些已然证得窍诀部不共密意、登地菩萨们的见解宗规，便能证得他们所证悟的境地。

此后，当证悟了那超越取舍、离于戏论、犹如虚空一般的境界时，"能修者"以及作为对治的"正念觉知"，都消散无踪、了无所依；自己的心相续犹如虚空一般清净，疑惑以及"是与非"的种种束缚，也当下自行解脱——转向那不由任何人造作而成的、超越分别心的、赤裸坦露、辽阔广大的觉性之时，这正是佛陀所亲见的真谛，必定超越了单纯信解、伺察式的分析——正因如此，才断除了退转、堕回三界的岔路歧途。

到这个阶段，虽然已经证悟了本来清净的本然实相，从本以来即是如此，但如果还没有生起稳固的定解，还没有到达清净三地，就仍然很容易在"证得"与"退转"之间摇摆反复。所以，为了净除所知障，必须依止寂静之处，坚持到底、锲而不舍地修下去。

虽然大手印与大圆满这两者的续部与窍诀之中，除了"觉性一旦决断即自行解脱"之外，并没有明说道次第的详细安立，但过去出世的大成就者、大菩萨们，是依据后得位中觉性力用广大圆满的程度而着眼，分别在"一缘""离戏""一味""无修"这四个阶段之中，各自安立上、中、下三品之名，依此来计算、对应地道的高低次第——正如他们所开示的那样。

更进一步说，后世的修行人之中，有的会把"离戏"错误地理解成一种带有相状特征的东西；有的则是在修习"一缘"这种广大习气之时，便自满自负地以为自己已经做到了昼夜双运——归根结底，这些都只不过是被三种智慧（闻、思、修所生之慧）所舍弃、遗漏了的结果罢了。

与此相仿，能对"究竟解脱之基"以及"具足六种特法的普贤王如来密意的解脱之地"生起确定无疑的了知——这一层意涵，正是大圆满《秘密心髓》法门中特有的旁述要诀。想要真正理解这样的要点，就必须开启遍知龙钦巴尊者的秘密宝藏。为了后世那些相继出现、真正获得密意传承之转移的实修瑜伽士们，我——龙钦·南开南觉（虚空瑜伽士），便以当下这具有特殊清净所见、心量周遍犹如虚空一般的心境，将这些内容写成了临别遗教般的笔记纲要。

## 金刚歌舞

```
སྣང་བ་ནི་སྐྱེ་མེད་རིག་པ་ནི་ཡེ་གྲོལ།
ཤེས་པ་ནི་ཟང་ཐལ་ཟུང་འཇུག་ནི་སྒྲོ་བཏགས།
ཁྱབ་བརྡལ་གྱི་དྲན་པ་བཟོ་མེད་དུ་ཆམ་ཆམ།
གདོང་འདེད་ཀྱི་སྣང་བ་ཅེར་གྲོལ་དུ་ཐལ་ཐལ།
ཕྱོགས་ལྷུང་ནི་མི་འདུག་རྫོགས་ཆེན་གྱི་ལྟ་བ།
སྣང་སྟོང་དང་ཟུང་འཇུག་མིང་ཚིག་དང་ཐ་སྙད།
```

大意：显现本来无生，觉性本自解脱；了知本是通彻无碍，"双运"不过是强加上去的名言而已；周遍广布的正念，无造无作、坦然舒坦；那步步紧逼而来的显现之相，赤裸裸地当下解脱、荡然无碍——没有任何偏堕于一方，这便是大圆满的见地。"显空"与"双运"，说到底也不过都只是名相言辞、世俗名言罢了。

```
ཨ་ཧོ་ཡེ་སྤྲོས་བྲལ་ལ་སྒོམ་རྒྱུ་ནི་མི་གདའ།
སྲ་མཁྲེགས་ཀྱི་རྡོ་གདན་འགྱུར་མེད་ཀྱི་གདེང་ཆེན།
རས་དཀར་གྱི་གུར་ཆུང་འཁོར་བ་ཡི་འཇིགས་སྐྱོབས།
བཟོ་མེད་ཀྱི་མཆེད་ལྕམ་རང་གྲོལ་གྱི་ཚོམ་བུ།
```

大意：阿吙耶！在离戏之中，根本没有什么可以修持的对象。这坚硬的石座，正是那不变的、广大的自信；这白布搭成的小小帐篷，护佑我脱离对轮回的一切怖畏；这未经造作的兄弟姊妹，都是自解脱途上的伴侣、聚落。

```
ཨ་ཧོ་ཡེ་སྣང་སེམས་ནི་སུ་འདྲ་ལས་བདེ་འདུག
ལྟ་སྒོམ་ལས་འདས་པ་རྫོགས་པ་ཆེན་གྱི་རྣལ་འབྱོར།
བྱུང་རྒྱལ་གྱི་སྤྱོད་པ་ཚད་ཕེབས་ཀྱི་རིག་མདངས།
སྐྱིད་ཉལ་གྱི་ངང་དུ་སྣང་སེམས་ཁོ་ཁྲལ་ཁྲོལ།
རྟོགས་གྲོལ་ཁོང་ཉམས་ལེན་གྱི་མཐར་ཐུག་རང་ཡིན་ནོ།
```

大意：阿吙耶！这显现与心，是何等地安乐，超胜过一切！超越了见与修——这就是大圆满的瑜伽士。任运随缘、无所拘束的行止，正是觉性光华的圆满流露；安然舒卧之中，显现与心识，是那样地通透澄澈、了无挂碍——证悟与解脱融于内心的这份体验，正是一切修行最终的归趣所在。

```
ཐབས་ཤེས་ཀྱི་རྐང་པ་འདེགས་འཇོག་ཏུ་བསྒྱུར་ནས།
རི་སུལ་གྱི་བདེན་ཁྲོད་འབད་རྩོལ་གྱི་བསྙོགས་པས།
བྲག་སྐྱིབས་ཀྱི་བསྟི་གནས་རྟོག་བྲལ་གྱི་གནས་སུ།
ནམ་མཁའི་དང་རྣལ་འབྱོར་ཀློང་ཆེན་དང་མཇལ་ནས།
ཤུགས་འབྱུང་གི་ཉམས་རྟོགས་རྒྱང་གླུ་རུ་བླངས་ཡོད།
```

大意：我将方便与智慧这两只脚，交替举步而行，在山谷幽僻之处，勤加精进用功；栖身于岩洞荫蔽之所，那离于分别妄念的境地之中，我这"虚空瑜伽士"，得以与龙钦巴（无垢光尊者）真正相会——由此自然涌现的觉受与证悟，便谱写成了这一首悠远的"长调之歌"。

```
ཡེ་གདངས་ལ་བདེ་སྡུག་བླང་དོར་ནི་མ་གྲུབ།
སྣང་བ་ཡི་རྫུན་ཕུག་རིག་སྟོང་གི་ཚད་དུ།
མཉམ་རྫོགས་སུ་ཐིམ་པ་ཀུན་བཟང་གི་དགོངས་ཀློང་།
ཆམ་བརྡལ་གྱི་ཆོས་སྐུའི་རྒྱལ་སྲིད་དང་མཇལ་བྱུང་།
```

大意：在这本初的自然光华之中，苦乐、取舍，本来都无从成立；显现的虚妄假象，被穷究到觉空无别的边际之时，一切都消融于平等圆满之中——这正是普贤王如来密意的广阔境界；我由此得以与那舒展辽阔的法身王国，真正相会。

```
འདིར་འདུས་ཀྱི་སྐལ་ལྡན་མཆེད་ལྕམ་དེ་ཕོ་མོ།
འཁོར་བ་ལ་མ་ཞེན་འཛིན་མེད་ཀྱི་རིག་སྟོང་།
ཆམ་ཡངས་ཀྱི་རང་གཤིས་ལྷུག་པ་རུ་སྐྱོངས་དང་།
གདོད་མ་ཡི་གཞི་དབྱིངས་ལ་མཉམ་གྲོལ་དུ་ཆས་འགྲོ།
```

大意：在此聚集一处的、具足善缘的男女兄弟姐妹们——不要贪恋耽著于轮回，请护持这无所执取的觉空境界；让自己那舒展宽广的本性，任运坦然地安住护持；让我们一同启程，共赴那本初基界之中，同得平等解脱之地。

如是，即便是这一首金刚歌舞，也不过是如梦幻眼翳一般——我便这样怀着爱惜之心，将它写就了。
