# 扎西次仁《贡觉拉琼阿波尊者略传》

གོ་འཇོ་བླ་ཆུང་ཨ་ཕོའམ། ཐུབ་བསྟན་ཤེས་རབ་རྒྱ་མཚོ་མཆོག་གི་རྣམ་ཐར་ངོ་སྤྲོད་མདོར་བསྡུས་བཞུགས་སོ།

西藏文献图书馆扎西次仁撰于1997年

这篇关于贡觉拉琼阿波，也就是土登喜饶嘉措尊者的生平简介，分为三部分：第一，生平略述；第二，尊者著作的搜集与出版经过；第三，所收杂著的目录。

## 第一 生平略述

### 出生之地与家世

贡觉拉琼阿波，又名南喀却英，又名土登喜饶嘉措尊者。藏地向来分为三区：上部阿里三围，中部卫藏四如，下部多康六冈。六冈之中，尊者的家乡属于玛康冈的拉冈仁摩境内，是十八大雪（ཤོད་ཆེན་བཅོ་བརྒྱད）之一，名为玛雪贡觉。

当地有一座具足加持的镇边寺庙，名为多达拉康。又有相传由文成公主主持造立的圣观世音六字大明咒，字形高高隆起，历久不磨，镌刻精美，令人赞叹。又有普巴塘拉康，是莲花生大士开启普巴金刚威猛坛城、将一切危害雪域的恶毒违誓者全部降伏于誓言之下的殊胜圣地。玛雪扎西宗果一带，山谷上下游各处，遍布邬金莲师父母的修行圣地和具加持的隐秘圣地。这片地方被众多加持力强大的大小圣地环绕。

尤其是，玛康冈地脉的顶峰、吉祥之地的村落玛普雄，有一座高峻威严、令人望而生畏的山峰，山上住着护佑地方的大山神玛拉囊瓦玉孜（སྨར་ལྷག་སྣང་བ་གཡུ་རྩེ），是贡觉、玛康一带所有天神、龙族和地主神的首领与向导。在这座山脚下的上多珠（མདོ་དྲུག་སྟོད་པ）勒达村，有一户人家叫拉琼家。尊者就是这家父亲嘎丹桑波与母亲次旺措的儿子，生于第十五胜生周木蛇年，即公元1905年。

译注：拉琼（བླ་ཆུང）原是尊者家族的家名，原文作“拉琼家”（བླ་ཆུང་ཚང）。“阿波”（ཨ་ཕོ）是康区对男子的称呼，后文其弟也称“阿波旺扎丹增”。“玛康冈的拉冈仁摩”一句中，藏文 ཀེ་རེའི 一词含义未能确定，暂不译出，存疑。

### 幼年与早年求学

尊者从小天资聪颖，读书写字毫无障碍。十三岁起，在家乡的多宗寺显密广弘法洲（རྡོར་རྫོང་དགོན་མདོ་སྔགས་རབ་རྒྱས་ཆོས་གླིང）求法。这座寺院兼承吉祥竹巴噶举与密乘宁玛两派，奉行康巴噶寺（ཁམས་སྒར）清净的修持传统。尊者在这里领受了胜乐金刚、金刚亥母、不动佛、金刚手、加村宁波伏藏、敏珠林传承、却旺伏藏、北伏藏等法；诵经仪轨的唱腔、食子制作、酥油花装饰、法螺与嘉陵的吹奏等，只要一学就会。

十八岁起，尊者依止德格木桑地方的内嘉祖古·降央洛珠嘉措，学习白算与黑算两种历算、医学、诗学、《三十颂》与《音势论》、《入菩萨行论》、《三律仪》等，勤学了将近五年。

### 佐钦寺求法

此后，尊者进入德格佐钦寺如当邬金桑丹林的西日森哈佛学院，学习十三部大论，圆满完成学业。

在佐钦阎魔修行洞，尊者从堪钦拉贡，即白玛特秋洛丹贝桑波座前，领受了由持明无畏洲与遍知法王父子传下的引导传承：《七宝藏》、《四心滴》、《休息三论》、《自解脱三论》，阿里班钦《三律仪决定论》的本论与注释等，必读的核心论典都熟读精通。又领受了《吉祥幻化网秘密藏续》等显密教法完整的灌顶、传承与引导，前行《普贤上师言教》，以及引导文《智慧上师》的实修引导。又从堪布云嘎座前听受了《功德藏》两函的讲解。当时库努喇嘛丹增嘉参（1894—1977）是尊者的同学，二人一起复习了《三十颂》与《音势论》。

尊者在成就自在、第五世佐钦法王，部主白玛特秋丹增，又名土登却吉多杰·丹增晋美旺波（1872—1935）座前，领受了宁玛教传的灌顶与传承，以及《四心滴》的灌顶、传承和引导等大量教法，全部听闻修学圆满。

尊者在佐钦寺住了六年，从许多智者、成就者、持金刚上师处，领受成熟灌顶、解脱引导及助缘传承，闻思修三者都已圆满，心中的宝瓶被正法甘露完全充满。当时，以佐钦寺如当邬金桑丹林的三位殊胜化身持教者为首，德格噶陀、白玉、雪谦三大寺许多声名卓著的智者与成就者，尊者都依止了。从他们那里，凡是能够领受的，尊者都一一领受：佛陀的珍贵教法总体，特别是本派远传教传、近传伏藏、甚深净相所代表的密乘心要无垢教法的灌顶、传承、窍诀、实修引导和随许。又从不分宗派的诸位持教大德处，结下了各种法缘。

尊者在金刚乘坛城中成熟时所得的密名，叫作多吉勒饶德瓦匝（རྡོ་རྗེ་ལས་རབ་བདེ་བ་རྩལ）。

### 返乡与入藏

尊者向第五世佐钦法王土登却吉多杰请求，准许他回家乡贡觉的多宗寺。法王郑重吩咐说：“你应当留在这里，从西日森哈佛学院的辅导师开始，逐步升到堪布，在这里利益众生。”尊者坚决恳求：“这一次请允许我回家乡一趟。”于是佐钦仁波切以十三部大论为主，赠给他许多经书，并派驮马一直护送到金沙江边，给予了无上的照顾，这是大家都知道的。渡金沙江时出了一点意外，据说驮着经书的一匹马的货物落进了江里。

回到家乡后，尊者在多宗寺担任了三年洛本（教师）。此后不久，前往卫藏的法轮之城拉萨，大约是在水鸡年，即公元1933年前后，我是这样推测的。

在莲花生大士意的圣地喀曲（མཁར་ཆུ）的罗年洞（རོ་སྙོམས་ཕུག）修持耳传法门时，尊者亲眼见到一位瑜伽士，身色紫红，威严庄重，头发结成发辫，系着禅修带，身披红绸上衣，亲口传给他方便道的秘密口诀。尊者依此修持，证见了实义。为了不致遗忘，把这些内容写了下来，名为《隐义方便道深导·揭示密意心之明点》。

### 拉萨时期

在拉萨小昭寺附近名为“长石梯”（རྡོ་སྐས་རིང་མོ）的地方，有出身显贵富裕的王氏家族的卫地女子，空行德威多杰，又名色拉康卓·衮桑德炯却尼旺姆（1892—1940）。尊者与她的侄女央金卓嘎结为方便智慧双运的伴侣。恰扎桑杰多杰仁波切依止这位空行母为上师。据说她圆寂时安住禅定（图当），示现了无数稀有的事迹。

译注：原文“འདི་པས་སྐྱབས་རྗེ་བྱ་བྲལ་སངས་རྒྱས་རྡོ་རྗེ་བླ་མར་བསྟེན”，字面也可读作“她依止恰扎仁波切为上师”。色拉康卓年长恰扎仁波切二十一岁，一般记载也说恰扎仁波切曾随色拉康卓学法，故按后者译出。

木狗年，即1934年，尊者以帕巴辛衮（斯瓦扬布佛塔）为主，到尼泊尔各圣地朝礼。尊者平时保持隐蔽行止的瑜伽士作风，靠给察珠家做买卖维持生活。因此，除了几位知心好友以外，拉萨上上下下的人都称他“拉琼阿波啦”，只当他是个商人，不知道他的闻思和证悟。其实，尊者对新旧各派教传、伏藏、净相的成熟解脱、引导、传承，如海一般都已闻思究竟；尤其是在阿毗达磨藏和诗学两类论典方面，以无人可比的精通而闻名。

尊者住在拉萨期间，与从康区、果洛等地来求学朝圣的噶举派与宁玛派中，智尊贤三德具足的上师们，都有彼此深入的交往。后来，尊者结识了大学者安多根敦群培（1903或1905—1951），就疑难要点多次请教问答。又与娘绒祖古达瓦桑波一同，完整听受了根敦群培亲自从梵文译成藏文、以美妙诗句装饰的戏剧《沙恭达罗》的讲解。讲完之后，上师还送了肉饼作为礼物，诸如此类的事都有。

译注：《沙恭达罗》，藏文作 བྱ་ལེན་མ་མངོན་པར་ཤེས་པའི་ཟློས་གར，即迦梨陀娑的梵文名剧《沙恭达罗》（Abhijñānaśākuntalam）。

尊者住在拉萨期间，在桑耶寺从怙主敦珠晋扎耶喜多杰仁波切（1904—1987）座前，领受了《大宝伏藏》完整的灌顶与传承，以及白玛林巴伏藏法的灌顶与传承；又在宗萨蒋扬钦哲·确吉罗卓（1893—1959）座前，领受了《四心滴》等大量教法，都听闻修学圆满。

水马年，即1942年，尊者前往印度朝礼金刚座、瓦拉纳西、鹿野苑等圣地。水龙年，即1952年11月9日起，到水蛇年，即1953年1月21日止，尊者作为由政府、拉章及三大寺所派喇嘛、活佛、贵族和商界代表组成的“西藏致敬团与参观团”成员，在邦达·晋美等十二名代表带领下，到内蒙古自治区、东北、华北、华东、西北等地进行了官方参观访问。

译注：“政府、拉章及三大寺”，原文作 གཞུང་བླ་ས་གསུམ，按通常的“政府与三大寺”（གཞུང་ས་གསུམ）理解，其中 བླ 字确切所指存疑。

### 流亡印度

土猪年，即1959年，尊者流亡到印度。在噶伦堡，根敦群培的遗著《龙树意趣庄严论》，以及怙主敦珠仁波切的宁玛派教史《天王战胜之大鼓声》刻版付印时，尊者担任了校对。

铁牛年，即1961年，尊者新撰《大菩萨甘地尊者三密伟大功德赞·悦意白莲花蔓》，西孟加拉邦政府为此给予了隆重的嘉奖。这一年前后，锡金甘托克印度政治专员公署所属的印度政府新闻部门，多次邀请尊者担任月刊画报《进步》（ཡར་རྒྱས་གོང་འཕེལ）的藏文编辑，尊者都没有答应。尊者给怙主敦珠仁波切的公子申遍达瓦仁波切担任了大约三年藏文与佛法的老师。

由于嘉瓦仁波切发心和愿力的强大推动，土鸡年，即1969年，在印度喜马偕尔邦达兰萨拉建成大乘法洲寺（祖拉康）；铁狗年，即1970年，新造了释迦牟尼佛、圣观世音菩萨、莲师显有威镇三尊佛像及装藏。落成之后，水鼠年，即1972年，尊者为达兰萨拉大乘法洲寺的主尊莲师海生金刚像，撰写了专题赞辞，排成普贤轮格，名为《莲花盛开之游戏海》。

水牛年，即1973年5月，尊者前往不丹朝礼修行圣地之王门地的帕罗虎穴等圣地。

### 晚年与圆寂

木兔年，即1975年，不丹老王太后阿熙彭措却珍出资刊刻白玛林巴伏藏法二十余大函，尊者担任校对。藏历十一月里，尊者身体不适，染上了疾病，依照他自己的意愿，回到住处翁贝茶园（ཨོམ་འབེག་ཇ་ཞིང）。

大约十五天里，尊者因为腹泻而身体衰弱。大家恳切请他去医院，尊者说：“这一次医院也没有用，我不去。”于是开列了一张单子，写明某某藏药，派人到大吉岭去买。又吩咐请法友贡觉喇嘛彭措扎西来修消灾仪轨。尊者的弟弟旺扎丹增，按照尊者的一切吩咐办理。

最后，在七十一岁那年，第十六胜生周木兔年二月初五，公历1975年1月17日夜里两点，好像风逆上冲一样，尊者的呼吸一度中断，随后又恢复过来。尊者说：“煮一壶甜茶来。”按照吩咐，尊者喝了两小碗甜茶，吃了约半块饼干。然后吩咐说：“现在，如果我死了，三天之内不要移动遗体。之后火化等一切后事，该怎么办就怎么办。”贡觉喇嘛彭措扎西按照续部所说，为尊者念诵提醒教言。尊者没有任何痛苦，面带寂静的微笑，容光焕发，圆寂了。

译注：公历1975年1月17日，按藏历应是木虎年（1974）十二月初五。藏历木兔年（1975）新年在公历2月11日，原文“木兔年二月初五”与公历日期不合，原因待考。本稿照录原文，以公历日期为准。同理，上文说木兔年校对伏藏、藏历十一月患病，实际也应在木虎年（1974）年末。

此后，以宁玛前译教法的明灯、娘拉恰扎桑杰多杰仁波切（1913年生）为首，日沃齐喇嘛次旺拉嘉、贡觉喇嘛彭措扎西等约八位仪轨僧，以噶林寂忿仪轨为尊者修法。第三天火化遗体时，某一刻随着一声响动，大约手掌大小的一块头骨向前弹了出来。主持供养的丹杰拉把它接回来，重新放回火焰之中。总之，修持大圆满的种种征相都具足出现了。

这篇简短的生平介绍，是根据尊者的弟弟阿波旺扎丹增、门孜康的首席星算师扎通·强巴坚赞、康巴噶寺的贡觉格南等人所讲述的，按照所听闻的，粗略记录下来的。

译注：“贡觉格南”，原文作 གོ་འཇོ་དགེ་རྣམ，是简称，全名未详。

## 第二 著作的搜集与出版经过

流亡驻地的西藏文献图书馆，是嘉瓦仁波切看到极为迫切的需要而创办的。按照嘉瓦仁波切的恩德与教导，这里的全体工作人员一直在为保护西藏的根本文化而努力。在众多工作之中，图书馆不仅收集原有的典籍，还看到：后来在印度、尼泊尔、锡金、不丹等地出现的无与伦比的了义智者们，为未来的弟子留下了如眼饰般珍贵的著作，其中还没有刊印的，如果散佚了，凡是有心之人都会无法忍受。因此图书馆一心想着，要把爱护这些著作当作首要责任来承担。正当此时，铁猴年，即1980年，我被任命为西藏文献图书馆藏文出版部的主管。

与此同时，为了使我们不分宗派的佛法文化不致衰落，也为了把历代大德在讲、辩、著三方面所留下的珍贵著作都重新整理出版，图书馆全力以赴地开展工作。尤其是，当时在我们藏人社会里，前前后后、明里暗里到处有人议论，说达兰萨拉西藏文献图书馆的佛学班，以及编制藏文书目等工作的人员，全是偏袒格鲁派的人。为了使图书馆出版的书籍不再招致这样的批评，我们开始了一项计划，出版宗派与内容都不分门户的书籍。

我最初听说拉琼阿波的事迹和生平，是从挚友、西藏政府门孜康的首席星算师、已故的扎通·强巴坚赞（1939—1997）那里。同样在木虎年，即1974年初，西藏文献图书馆出版的第一部藏文佛学书籍，就是尊者所著《大菩萨甘地尊者三密伟大功德赞·悦意白莲花蔓》，用铅字排印。当时的校对等出版事务，全部由拉琼阿波的知心朋友、西藏文献图书馆的文化研究员纳吉·阿旺顿珠先生负责。那时我在学校里学完《诗镜》中章不久，出于新奇和喜爱，恳请把阿波啦的亲笔原稿送给我本人，纳吉先生就把它给了我。

另外，自流亡到达以来，从1960年（铁鼠年）年底到1970年（铁狗年）间，我们藏人老老少少和外国人，对安多根敦群培的生平都非常关注，满怀思慕。就在这时，西藏文献图书馆的文化研究员、智者自在堪尊桑波仁波切（1921年生），请拉琼阿波撰写根敦群培传。拉琼阿波于是在流亡藏人社会中第一个撰写了根敦群培的简传。水牛年，即1973年，西藏文献图书馆出版了堪尊桑波仁波切所编《八大修行传承车乘中前译密乘宁玛派上师传承及随行者传记·稀有海》，这篇简传就刊在下册第634至657页。拉琼阿波亲笔所写的根敦群培传，为了制书而排好铅字以后，当时我出于新奇，又有点像要和别人比一比似的，请求赐给我一份清样（གསལ་རིས），也承蒙慈悲赐予。这些我都妥善保存至今。

正如上面所说，我担任西藏文献图书馆藏文出版部的主管后，好友、已故的扎通先生到大吉岭度假时，我特地拜托他仔细打听：拉琼阿波的著作哪些已经刊印、哪些还没有刊印，现在都在哪里。

特别是在铁鸡年，即1981年，图书馆馆长嘉措次仁先生，批准搜集拉琼阿波现存的所有著作，以备将来出版等用途。于是好友、已故的扎通先生又一次度假，前往拉琼阿波遗属处（原文作 ཞལ་ལུས་གཟིམ་སྐུ་ལྷན་རྒྱས，确切所指存疑），借出拉琼阿波现存的全部著作，带回达兰萨拉，正如事先约定的那样。1981年11月20日，尊者之弟阿波拉琼·丹增旺扎先生出于和合的深厚心意，把这次准备出版的大小二十四篇著作，借给了我们。尊者的大部分著作，恐怕在1959年动乱时留在拉萨了。

图书馆的前任员工、已退休的已故强巴念扎先生，和通祖·洛桑丹增先生，帮忙抄写了书稿；本馆员工丹增央金把全部著作录入电脑；印版的校对、出版的准备等一切工作，由本馆藏文出版部的编辑助理、果芒格西阿旺隆多完成。对以上诸位，我们都深表感谢。
