# 本来实相金刚句

**（伏藏本文，仁增·晋美林巴 取藏）**

**白话译文**

---

顶礼吉祥普贤王如来。

首先，就"基"——也就是万法本始的这个层面而言，它本来的实相，是彻底远离一切戏论的；而这个"基"本身所显现出来的东西，也就是那能够觉知的觉性，其本身就是法身。至于"道"——也就是修行的层面而言，一切刻意的造作、勤劳用功，从本以来其实就是清净的（也就是说，本无所谓需要靠人为的努力去"制造"出清净来，清净本来就在那里）。能够现前证悟到这一点——也就是"基"的实相与"道"上一切造作本来清净这两点——本身，就已经是极为广大的解脱之地了。至于"果"——也就是最终所要证得的东西，它并不是与前面所说的"基"和"道"截然分开、另外单独存在的一个东西。

其次，当"果"本身，其实已经存在于"因"之中的这个�面向而言（也就是说，果并非另外从别处产生，而是因位当中本自具足的东西）：内心平稳、坦然，不作意地安住着，这本身就是"止"（奢摩他）；而心中忽然乍现出来的念头等等，其实正是觉性自身放射出来的光华、显现，并不是别的什么东西；对这一切能够清晰、赫然分明地觉照了知，这本身就是"观"（毗钵舍那）；而这一切在被赤裸裸地直视之下，自然而然地消融、隐没，回到那本来如是的状态之中，这便是本初的境界。

第三，就"三身"这个层面而言：本然地、原本地就这样安住着，不假造作，这便是法身；了了分明、清清楚楚地显现出来，这便是圆满受用的报身；至于"安住不动"与"生起变动"这两者，其实并没有真正的差别、并非彼此对立的两回事，这便是化身。所谓"三身"，说到底，指的正是这个觉性本身而已，并不是在觉性之外，另外还有三个不同的身可以分别去寻找。

第四，再进一步说：松坦、放松地安住着，却对"我正安住于此"这件事本身，毫无执著、毫无把持；心念清晰、赫然地生起、活动，却对这活动本身，没有加以辨认、追认、把捉；这活动鲜明、当下地自然解脱，却没有事后再补上一层"我已经解脱了"这样的了知、忆念——像这样，才叫做"三身任运自成"。

第五，就"见、修、行"这三者而言：没有一个可以单独立起来、当作对象去执持的"见地"，但同时又远离了昏沉与掉举这两种过失；没有一个可以刻意去营造、修持的"修法"，但却已然完全趣入、融汇于（本性）这个"母胎"一般的境地之中；没有一个可以刻意造作、表现出来的"行为"，但同时又远离了任何的执著与挂虑、系念——像这样的人，才称得上是真正的"瑜伽自在王"。

第六，这里要特别提醒一个容易被误解的地方：对于那忽然之间乍然生起的分别念头，如果只是去觉察、认知它，然后就在那个当下延续、护持这份觉知——这样做，其实仍然只是一种"混同、流失于分别念本身习性之中"的胜观而已（也就是说，这样的做法，本质上还只是在分别念的层面上打转，尚未真正超越它）。如果把这样的做法，冠上一个"觉性的后得智"这样的名称，反而会成为修行上的一种障碍、滞碍。这样的做法，并不是分别念真正解脱为法身。必须要直接了当地斩断分别念的根本命脉才行，不能仅仅停留在"认知、觉察它，并延续护持"这个层面上。

第七，觉性，从本以来，就是彻底远离一切戏论的；而"见""修""行"这些名言概念本身，以及对它们所生起的执著、执取，其所依托的根本、基础，本来就是不存在的，本来就已经是清净的。至于善的分别念、恶的分别念，以及无记（非善非恶）的分别念，都不堕于其中任何一边、任何一方；念头的"生起"与念头的"解脱"，这两者之间，并没有一个可以将它们截然划分开来的"裁判者"（也就是说，念头一生起，当下便已经是解脱了，并非先经历一个"生起"的阶段，再经历一个后续才到来的"解脱"阶段，二者本来同时、本来无二）。如果这份能了知的觉性，不曾迷失它自己本来的姿态、样貌，那么，除此之外，便再也不需要别的什么了。

最后总结说：纵然有幸遇见一百位博学而持戒精严的智者、一千位真正的成就者、一万位译师与班智达、十万条不同的窍诀教言，乃至千千万万、亿万部的论典——即便都一一得以亲见、值遇，也完全不需要再借助它们来进一步断除疑惑了（意思是说：上面所讲的这个道理，本身已经究竟圆满，不必再向外寻求任何其他的印证或决断）。

萨玛雅（誓言）！谛玛（封印）！

致我唯一的爱子——钦哲沃瑟（智悲光）：这是由了知觉性的普贤王如来本人，以加持密意传承的方式所赐予的教言，不要展示给一切人看，请将它秘藏于自己的心间。

如上所说这段教言，是在鄔金（邬金净土）色究竟天的岩洞之中，值神变月第二十六日、我正在闭黑关之时，众空行母云集聚会而来的那个时刻，我将它记录、写在了一张珍贵的浅色纸张之上的。这一份极为甚深的耳传口诀，是以"阿塘"（Atham）作为封印的。

唯此而已！唯此而已！

关于这篇文字义理的详细解释，见于遍知（龙钦巴）尊者本人的口传教言之中。

---

《本来实相金刚句》（终）
