# 蒋扬钦哲旺波《辨析宗义之言·了义耳饰》

这是蒋扬钦哲旺波（1820—1892）答复他人提问的一篇短论，通篇以偈颂写成，收在《钦哲旺波文集》第二函。题名中的耳饰是比喻：这番话如同一只耳环，献给听者的耳朵。

全篇的骨干是一句话：从声闻有部到大圆满，一切宗派都是证悟同一法性的方便。论中依次辨析外道、有部、经部、唯识、自续、应成，而后以大半篇幅讲萨迦道果，指出道果与唯识的分界、道果与大圆满的一味、道果与他空的不同，最后讨论佛智是有是无，归结到实修。

༄༅། །གྲུབ་པའི་མཐའ་རྣམ་པར་དབྱེ་བའི་གཏམ་ངེས་དོན་རྣ་ཆ་ཞེས་བྱ་བ་བཞུགས་སོ། །

辨析宗义之言·了义耳饰

ཆོས་ཉིད་འདུས་མ་བྱས་པ་ཡི། །རང་བཞིན་རྣམ་ཐར་སྒོ་གསུམ་ཞལ། །སེམས་ཀྱི་རྡོ་རྗེ་བླ་མ་ལ། །བཏུད་ནས་དྲིས་ལན་མདོ་ཙམ་དབྱེ། །

上师以无为法性为自性，以空、无相、无愿三解脱门为面容，上师即是自心的金刚。顶礼这样的上师之后，谨就所问略作分辨。

གཉིས་མེད་གསུང་བའི་དབང་ཕྱུག་གིས། །རིགས་ཅན་གསུམ་གྱི་གདུལ་བྱ་རྣམས། །རང་གི་བྱང་ཆུབ་ལ་འགོད་ཕྱིར། །རྒྱུ་འབྲས་ཐེག་པ་བསམ་ཡས་བསྟན། །

宣说无二的自在尊，为了将声闻、缘觉、菩萨三种种姓的所化众生，安置于各自的菩提果位，宣说了不可思议的因乘与果乘教法。

དེ་ཉིད་མ་རྟོགས་སེམས་ཅན་ཀུན། །གནས་སྐབས་འདོད་པའི་ཕྱོགས་བཟུང་ནས། །བསྟན་པ་དཀྲུགས་པ་ལྷ་ཆེན་པོའི། །རྣམ་ཐར་ཆོས་སུ་བཅོས་པ་ཡིན། །

没有了达这一密意的众生，执持自己一时所认同的一边，由此扰乱圣教。这实际上是把大天的行迹伪装成了佛法。

འདི་ན་ཉན་ཐོས་བྱེ་སྨྲ་ནས། །མཆོག་གསང་རྡོ་རྗེ་སྙིང་པོའི་བར། །ཆོས་ཉིད་གཅིག་གི་དེ་ཁོ་ན། །རྟོགས་པའི་ཐབས་སུ་ཡང་དག་བསྟན། །

其实，从声闻有部宗开始，一直到最胜秘密的金刚心髓，无一不是为了证悟唯一法性的真如而如理宣说的方便。

ཅི་ཕྱིར་རྟག་ཆད་སྨྲ་བ་ལ། །མངོན་པར་དགའ་བའི་མུ་སྟེགས་ཀུན། །རྟག་གཅིག་རང་དབང་ཅན་གྱུར་པའི། །གང་ཟག་བདག་ཉིད་ཡོད་པར་མཐུན། །

何以故？一切喜好宣讲常见与断见的外道，都一致承认有一个常、一、自主的补特伽罗我，也就是人我。

དེ་ལ་རང་སྡེ་སྨྲ་བ་ཡིས། །ཕུང་པོ་ཉིད་ལས་གཅིག་ཐ་དད། །དེ་ལས་གཞན་དུའང་མ་དམིགས་ཕྱིར། །མེད་པར་སྒྲུབ་པ་གཞིར་བྱས་ནས། །

内道诸宗则在五蕴上寻找这个我。说我与五蕴是一体，不可得。说我与五蕴是异体，也不可得。离开五蕴另外寻找，仍然不可得。内道诸宗便以成立人我不存在为共同的基础。

བྱེ་སྨྲས་གཟུང་ཡུལ་རྡུལ་ཕྲན་དང་། །འཛིན་ཤེས་སྐད་ཅིག་ཆ་མེད་དུ། །བདེན་གྲུབ་འདོད་པས་ཆོས་ཀྱི་བདག །རགས་པ་ཙམ་ཡང་སྤང་བ་མེད། །

声闻有部宗承认，所取境的极微尘不可再分，能取心识的最短刹那也不可再分，而且无分微尘与无分刹那都是真实成立的。所以，有部宗连粗分的法我也没有断除。

མདོ་སྡེ་པ་དག་ཕྱི་དོན་ཀུན། །སེམས་ཀྱི་སྣང་ཆ་ཡིན་མོད་ཀྱང་། །དེ་རྒྱུ་ཕྱི་དོན་ཉིད་འདོད་པས། །གཟུང་བའི་ཆོས་བདག་རགས་པ་སྤངས། །

经部宗认为，一切外境虽然都是心自身的显现分，但是这显现仍以外境本身为因。所以，经部宗断除了所取方面粗分的法我。

སེམས་ཙམ་གཟུགས་ཅན་ཕྱོགས་ཆ་དང་། །ཤེས་པ་དུས་ཆས་མ་གྲུབ་ཕྱིར། །གཟུང་འཛིན་བདེན་མེད་ངེས་རྙེད་ཀྱང་། །གཉིས་མེད་ཡོངས་གྲུབ་བདེན་པར་འདོད། །

唯识宗观察色法，抉择色法在空间上的方分不成立。观察心识，抉择心识在时间上的时分不成立。由此唯识宗确定能取与所取都不是真实的。然而，唯识宗仍然承认，远离能取所取的无二圆成实是真实存在的。

རང་རྒྱུད་སྨྲ་བས་རིག་ཆེན་ལྔས། །དེ་ཡང་བདེན་མེད་གཏན་དབབ་ནས། །དོན་དམ་ངོ་བོ་ཉིད་མེད་དང་། །ཀུན་རྫོབ་ཇི་ལྟར་སྣང་བཞིན་འཇོག །

中观自续派以五大因，将唯识宗所保留的圆成实也抉择为非真实成立。中观自续派由此安立：胜义中无有自性，世俗中如何显现就如何承认。

ཐལ་འགྱུར་བས་ནི་སྒྲོ་སྐུར་གྱི། །ཁས་ལེན་སྤྲོས་པ་ཀུན་སྤངས་ནས། །གཞན་གྱི་འདོད་པ་ནང་འགལ་བའི། །རིག་པས་བཅོམ་པའི་ཁྱད་པར་ལྡན། །

中观应成派舍弃属于增益与损减的一切戏论承许，以揭示他宗主张自相矛盾的正理，摧破他宗的种种主张。这是中观应成派的超胜之处。

དེ་དང་རྫོགས་པ་ཆེན་པོ་གཉིས། །ཆོས་ཉིད་བསམ་གྱིས་མི་ཁྱབ་པའི། །བློ་འདས་ངང་དུ་རོ་གཅིག་ཕྱིར། །ཤིན་ཏུ་མཉམ་གཞག་སེམས་ཀྱིས་ལྟོས། །

中观应成派与大圆满，在不可思议的法性、超越分别心的境界中，同为一味。对此，应当以深深入定之心观照。

སེམས་ཙམ་དྲི་མེད་དག་པ་དང་། །གཞན་སྟོང་སྨྲ་བ་མཚུངས་མིན་ཏེ། །སྔ་མས་རྣམ་ཤེས་ཕྱི་མ་ཡིས། །ཡེ་ཤེས་དོན་དམ་འདོད་ཕྱིར་རོ། །

无垢清净的唯识宗与他空派并不相同。唯识宗承认心识为胜义，他空派承认智慧为胜义。

ལམ་འབྲས་པ་དག་སྣང་བ་སེམས། །སེམས་སྣང་སྒྱུ་མ་དེ་ཉིད་ཀྱང་། །རང་བཞིན་མེད་པར་སྒྲུབ་པ་ལ། །རྟེན་འབྲེལ་བརྗོད་བྲལ་གཉིས་སུ་དབྱེ། །

萨迦道果派成立显现即是心，心的显现如同幻化，幻化本身也没有自性。对于成立无自性这一层，道果派又分为缘起与离言两门来说明。

འོན་ཀྱང་སྣང་བ་སེམས་ཙམ་དུ། །འདོད་པ་དངོས་པོར་སྨྲ་བ་དང་། །མཚུངས་སོ་སྙམ་པའི་ལོག་རྟོག་ནི། །རྣམ་དཔྱོད་ཞིབ་མོས་མ་བརྟགས་སྐྱོན། །

有人以为，主张显现唯心，就与主张诸法实有的实事师没有差别。这种错误的分别念，是由于没有以细致的智慧观察所致。

ཅི་ཕྱིར་རྡོ་རྗེ་གུར་ལས་ཀྱང་། །རིན་ཆེན་སེམས་ལས་ཕྱིར་གྱུར་པའི། །སངས་རྒྱས་མེད་ཅིང་གང་ཟག་མེད། །རྣམ་པར་ཤེས་པའི་གནས་དོན་ནམ། །ཕྱི་རོལ་གྱུར་པ་ཅུང་ཟད་མེད། །ཅེས་དང་།

何以故？《金刚帐续》中说，离开这珍宝之心，就没有佛陀，也没有众生。心识所依的处所和心识所缘的对境，在心之外丝毫也不存在。

སཾ་བུ་ཊི་ལས་ཀྱང་། ཕྱི་དང་ནང་གི་བདག་ཉིད་ཅན། །འདི་དག་ཐམས་ཅད་སེམས་སུ་བརྟག །སེམས་ལས་མ་གཏོགས་པ་ཉིད་ནི། །གཞན་ན་ཡོད་པ་མ་ཡིན་ནོ། །ཞེས་གསུངས་

《桑布扎续》中也说，内外一切具有体性的法，都应当观为自心。离开了心，在别处再也没有任何法存在。

དེ་ཡི་འཐད་པ་ཡང་། །མགོན་པོ་ཀླུ་སྒྲུབ་སྐྱོབ་ཉིད་ཀྱིས། །ཕྱི་རོལ་ཡུལ་ནི་རྣམ་གཅིག་ལ། །ཤེས་པ་ཐ་དད་རབ་འཇུག་སྟེ། །ཡིད་འོང་གཟུགས་ནི་གང་ཡིན་པ། །དེ་ནི་གཞན་ལ་གཞན་དུ་སྣང་། །བུད་མེད་ལུས་ནི་གཅིག་ཉིད་ལ། །དཀའ་ཐུབ་ཆགས་ཅན་ཁྱི་རྣམས་ཀྱིས། །མི་གཙང་འདོད་བྱ་བཟའ་བྱ་ཞེས། །རྣམ་པར་འདོད་པ་གསུམ་དུ་འགྱུར། །ཞེས་སོགས་རིག་པའི་ཚུལ་གྱིས་སྒྲུབ། །

对此，怙主龙猛菩萨也以正理作了说明。面对同一个外境，不同的心识会生起不同的认识。同一个悦意的色相，在不同人眼中，会显现成不同的样子。譬如同一个女人的身体，苦行者把这个身体看成不净之物，贪欲者把这个身体看成贪爱的对象，野狗把这个身体看成可以吞食的食物。同一个身体，就成了三种截然不同的认识。龙猛菩萨正是以这样的正理，成立了显现唯心的道理。

除此以外，有人认为，藏性只是在有垢心上，以正理遮破其真实成立而已。也有人立宗说，藏性唯一是真实成立的。依照清净的理路，可以指出，遮破实有而已的说法落于损减，真实成立的说法落于增益。然而，此处依中观之见，暂时不破也不立。

འབྲས་བུ་སངས་རྒྱས་ཡེ་ཤེས་ནི། །དབུ་མ་རང་རྒྱུད་སྨྲ་བ་ཡིས། །མེད་པར་འདོད་ཅིང་གཞན་སྟོང་པས། །རྟག་བརྟན་འགྱུར་བ་མེད་པར་སྨྲ། །

关于果位的佛智，中观自续派说佛智不存在，他空派说佛智常恒、坚固、不变。

ངེས་དོན་མཐར་ཐུག་ཐལ་འགྱུར་བས། །བློ་དང་ལྷན་ཅིག་མི་གནས་པའི། །བསམ་གྱིས་མི་ཁྱབ་སྤྱོད་ཡུལ་ཕྱིར། །ཡོད་མེད་ཁས་ལེན་བྲལ་བར་བཞེད། །

究竟了义的中观应成派则认为，佛智不与分别心共存，是不可思议的境界，因此远离有与无的一切承认。

མདོ་ལས་ཡེ་ཤེས་མེད་གསུངས་པ། །ཟག་པར་བཅས་པའི་ཆོས་ཁམས་དང་། །མཚུངས་ལྡན་མེད་པ་ཉིད་ལ་དགོངས། །དགོས་པ་རྟག་འཛིན་བཟློག་ཕྱིར་ཡིན། །

佛经中说无智，是说佛智不与有漏诸法相应，其必要是为了遮止常执。

ལ་ལར་ཡེ་ཤེས་ཡོད་གསུངས་པའང་། །བསམ་བརྗོད་ལས་འདས་ཡེ་ཤེས་ཀྱིས། །འཁོར་འདས་ཀུན་ལ་ཁྱབ་པར་དགོངས། །དགོས་པ་ཆད་མཐའ་བསལ་ཕྱིར་ཡིན། །

有些佛经中又说有智，是说超越思议言说的智慧周遍轮回与涅槃，其必要是为了遣除断边。

དོན་དུ་མཐའ་གཉིས་ལས་འདས་པའི། །ཁས་ལེན་བྲལ་བའི་གནས་ལུགས་ཉིད། །མངོན་སུམ་རང་ངོར་རྟོགས་ཙ་ན། །རྟག་ཆད་སྤྲོས་པ་དབྱིངས་སུ་གྲོལ། །

实际上，当亲自现量证悟超越二边、远离承认的实相时，常见与断见的一切戏论，便在法界中自然解脱。

འདི་དོན་ལེགས་པར་མཁྱེན་འདོད་ན། །དབེན་ཞིང་ཉམས་དགའི་ནགས་ཀླུང་དུ། །རྩེ་གཅིག་མཉམ་པར་བཞག་ལས་གཞན། །རྟོག་གེའི་འགལ་འདུས་ནམ་ཡང་མིན། །

若想善知这一意义，就应当在寂静悦意的山林中，一心安住于等持。仅凭分别念的辩论与分析，永远都无法契入。

དེ་ཉིད་ཕྱིར་ན་སྐལ་བཟང་ཁྱོད། །ཟབ་དོན་ཉི་གཞོན་བཅུད་འཐུངས་པས། །བློ་མཆོག་པད་དཀར་རྒྱས་པ་དང་། །སྒོམ་སྤངས་འབྲས་བུས་ཕྱུག་པར་མཛོད། །

因此，具有善缘的你，应当饮下如朝阳般的甚深义精华，令殊胜智慧如白莲般绽放，最终以修道所断尽除的果位而富足。

གང་གི་མཁྱེན་རབ་རྨད་བྱུང་བས། །དྲི་བ་མཐའ་ཀླས་སྩལ་མོད་ཀྱང་། །རྨོངས་དང་ལེ་ལོའི་གཞན་དབང་གིས། །རྒྱ་ཆེར་སྤྲོ་བའི་གོ་སྐབས་ཅི། །

你以稀有的智慧赐下了无边的提问，而我受愚昧与懈怠所牵制，哪里有机会广作阐述呢？

འོན་ཀྱང་མདོར་བསྡུས་ཕུལ་འདི་ལ། །ནོངས་པའི་ཚོགས་རྣམས་བསལ་བ་དང་། །དགེ་བས་ཡིད་ཅན་རྒྱ་མཚོ་ཀུན། །ཐམས་ཅད་མཁྱེན་པ་ཉིད་གྱུར་ཅིག །

即便如此，我仍然奉上这篇略答。其中若有种种过失，愿都能得以清净。以此善根，愿如海般的一切众生，都能成就遍知佛果。

སརྦ་དཱ་ཀ་ལྱཱ་ཎཾ་བྷ་བ་ཏུ།། །། ༈

愿恒时吉祥。
