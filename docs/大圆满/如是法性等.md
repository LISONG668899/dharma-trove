# 如是法性等

**堪布阿旺巴桑（阿琼堪布）造**
汉译：据藏文原文，参英译本（Joseph McClellan 译，2025年）

（译注：此系英译者所拟之暂定标题；此篇于堪布文集目录中，即依其起首数字，题作"如是等"〔'di ltar sogs〕。）

---

晋美林巴尊者于其《功德藏》中曾如是写道：

如是，法性之体性，虽说其"有"，然观之却不显现；虽说其"无"，却无有边际、未曾断绝；不堕于〔有、无〕二边之任何一方，亦无可执取之"中"可立——凡超越始终、生灭、去来、三时、边中及勤作成办者，对此更无有可解脱、能解脱之基。

因其犹如水面所绘图纹，自然而然、任运自解之故，故无须假借令其解脱之缘，此因是法乃周遍一切之故；以其无基无根之故（译注：堪布阿旺巴桑所据版本此处作"无基无根"，未明示此句之语法作用；晋美林巴原本《功德藏》此处则多一助词，表明此句乃为下文所述之理由），于超越言说、思维、表述之境界中（译注：堪布阿旺巴桑本此处用词表"于……中"；晋美林巴原本则用标示主题之助词），于自明与现量照见法性之殊胜观（毗钵舍那）二者本自俱生（同时而生）之中，烦恼与分别妄念之聚——从来未曾有过，亦从来未曾无过；非因舍弃而得以断除（译注：堪布阿旺巴桑本此句作命令式"莫舍弃！"；晋美林巴原本则作现在时"不因舍弃而断除"）；非因修炼净治而得以清净；非因转化而得以转变；非因解脱而得以解脱——若未能证悟此理，则所断与能断等一切二元对立之法，因其本质同一（译注："本质同一"对译"单一实质"〔rdzas gcig〕，此乃论典中常用以表"体性无别"之专门术语）之故，说清净与解脱为截然二事，实不应理。

（译注：由于此段行文至此似显突兀而止，堪布阿旺巴桑所摘录之底本——晋美林巴《功德藏》原书——于此句之后，尚有一段紧接之文字，足以厘清此段之意趣，兹录如下：

"若如是〔以为〕清净与解脱可分二事，乃因本智而作此二事，则心不得见本智，本智亦不得见心；既然彼二者不得俱时并存，如是言说实相违而不应理。同样，过去与未来彼此相违，故后者亦不能舍弃前者；因一者存在之时，另一者即已灭去；若二者同时并存，则先后混乱，便成'所断反成对治，对治反成所断'之荒谬，因彼二者乃于同一心相续中同时并存之故。"（晋美林巴，第628页）

此后，晋美林巴又引《日月和合续》一段偈颂以为佐证，译出如下：

"若不证悟如是真如，则〔烦恼分别〕犹如瑜伽士之身与其影子——因彼影自其身中天然而生，故并非因舍弃而得以断除；同样，亦非因修炼净治而得清净；亦不能因转化而得以转变。若不证悟不变之心要，则犹如水晶之岩或绿松石一般〔本自清净〕，实无可修炼、熬炼使其更为纯净者；此乃因其自性本自安住清净之故，具瑜伽者当善加审察此理。同样，此亦并非仅是寂止之一种状态。若不能以现量照见之殊胜观而知此理，则此不知，犹如须弥山王，无人能加以摧毁，亦不能借由对治而使其解脱。若不了知本自清净、无可寻求之自性，则犹如浑浊之水而妄求其澄清——纵使逐步澄清，此亦并非借次第净化而致；即便彼水已然澄澈，此亦并非法性本身。若不了知自显现之松坦自在，则如同凡庸愚人之显现一般，明执于外境之心，亦无从遣除。"（晋美林巴，第628—629页））

再者，可举以下偈颂（译注：此段无题、未标明出处之偈颂，未能于现存文献数据库中寻得来源；藏文原文所用"ཞེས"〔"如是说"〕一词，暗示此当为引文，而非作者自撰之偈颂）：

唉玛！心性本身，即是觉性之本体；不加造作、不受污染，任运安住于本位而放松！此未经造作之自心、赤裸之觉性，本来即与诸佛之密意平等无别。

如是所说。

无修之觉性，即大任运自成者，莫加整治造作，护持于觉性之境中而安住。

如是所说。
