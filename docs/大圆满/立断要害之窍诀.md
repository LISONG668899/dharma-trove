# 立断要害之窍诀

麦彭仁波切 造

德！顶礼文殊智慧勇识！兹宣说立断（且却）要害之窍诀：

```
ཤེས་པ་མ་བཅོས་རང་སོར་བཞག །
དེ་ཡི་གཤིས་ལ་བབ་ཀྱིས་བལྟ། །
```

心识不加造作，任其安住于本位；于其本然状态中，任运而观照。

## 一、见如山，任运而住

```
འདི་ཡིན་དེ་ཡིན་དམིགས་གཏད་ཀྱི། །
རྣམ་པ་གང་ཡང་མེད་པ་ལ། །
བརྗོད་བྲལ་དེ་ཉིད་མྱོང་བ་ཡི། །
རང་གདངས་འགགས་པ་མེད་པ་འདི། །
```

在既无"此为如是"、亦无"彼为如是"之执取所缘、任何行相皆无所有之中，有一种超越言诠、亲证真如之体验，其自然光辉从未间断。

```
རྣལ་མ་གཤིས་ཀྱི་བབ་ཡིན་པས། །
བསམ་གྱིས་མི་ཁྱབ་ཆོས་ཉིད་དོན། །
རང་བཞིན་འོད་གསལ་ལྷག་མཐོང་སྟེ། །
ལྟ་བ་རི་བོ་ཅོག་བཞག་ཡིན། །
```

此即是真实本然任运之状态，是不可思议之法性义，是本性光明之胜观。此见地，即所谓"见如山，任运而住"。

## 二、修如海，任运而住

```
དེ་ཡི་བབ་ལ་གནས་བཞིན་དུ། །
བསྒོམ་དུ་མེད་ལ་ཡེང་བ་མེད། །
དགག་སྒྲུབ་རྟོག་དཔྱོད་མི་གཞུག་པར། །
རྣལ་མ་རང་བབ་ལྷུག་པར་བཞག །
```

安住于此任运之状态中时，既无所谓修持，亦无所谓散乱；不落入遮破、成立、分别、观察，唯以真实任运、松坦之方式而安住。

```
བྱ་རྩོལ་འཆིང་བས་མ་བསླད་པའི། །
ཆོས་ཉིད་བབ་ཀྱི་བསམ་གཏན་ཏེ། །
རྣལ་འབྱོར་ནམ་མཁའི་རྒྱལ་པོར་གནས། །
སྒོམ་པ་རྒྱ་མཚོ་ཅོག་བཞག་ཡིན། །
```

此乃未被造作勤勉之系缚所染污的法性任运之禅定，安住于"虚空王"之瑜伽。此修持，即所谓"修如海，任运而住"。

## 三、行显现，任运而住

```
དེ་ལྟར་བཞག་ཚེ་ནང་དུ་ནི། །
སྣ་ཚོགས་རྣམ་རྟོག་རྒྱུ་བ་དང་། །
ཕྱི་རོལ་སྣང་བ་ཅི་ཤར་ཡང་། །
དགག་སྒྲུབ་མེད་པར་རང་སར་བོར། །
```

如是安住之时，于内，纵有种种分别念纷纭流转；于外，无论显现何种境相，皆不加遮破成立，任其舍置于本位。

```
གཤིས་ཀྱི་རང་བབ་མ་བརྗེད་ན། །
གང་ཤར་ཕན་གནོད་བྲལ་བར་སྣང་། །
བཟང་ངན་བླང་དོར་རྩིས་གདབ་མེད། །
སྤྱོད་པ་སྣང་བ་ཅོག་བཞག་ཡིན། །
```

若不忘失本然任运之状态，则无论显现何物，皆显现为无利无害；对善恶取舍不加计较。此行为，即所谓"行显现，任运而住"。

## 四、果觉性，任运而住

```
གོམས་ནས་སྣང་སྲིད་ཆོས་ཐམས་ཅད། །
རིག་སྟོང་ཐིག་ལེ་ཉག་གཅིག་པོ། །
དེ་ཡི་ངང་དུ་འུབ་ཀྱིས་རྫོགས། །
དེ་ནི་རྩོལ་མེད་ལྷུན་གྱིས་གྲུབ། །
```

串习之后，一切显现有之诸法，皆成为觉空无二之唯一明点，于此境界中一时圆满具足；此乃无勤而任运成就者。

```
རྩོལ་བས་སྤང་དང་བླང་བྱ་ཟད། །
འཁོར་འདས་རེ་དང་དོགས་པ་མེད། །
གདོད་མའི་རང་བཞིན་མངོན་གྱུར་པ། །
འབྲས་བུ་རིག་པ་ཅོག་བཞག་ཡིན། །
```

以勤作而生之取舍悉皆穷尽，对轮回、涅槃再无希冀与忧惧，本初之自性得以现前。此果位，即所谓"果觉性，任运而住"。

## 结语

```
ཅོག་བཞག་བཞི་ལྡན་མན་ངག་འདི། །
ཁྲེགས་ཆོད་དགོངས་པ་མཐར་ཐུག་སྟེ། །
གནད་དང་ལྡང་ན་ཡུད་ཀྱིས་གྲོལ། །
འཇམ་དཔལ་དཔལ་དང་ལྡན་པའི་མཆོག །
```

此具足四种任运而住之窍诀，乃立断密意之究竟；若能与要害相应契合，便能刹那间获得解脱，证得殊胜吉祥文殊师利之果位。

于水蛇年之月日，从麦彭·文殊喜之智慧海中流现而出。

## 译者说明

本篇依藏文原颂重新译出。"ཁྲེགས་ཆོད"（音译"且却"）为大圆满修法中"立断"一法，意为斩断妄念之根，直契本净觉性，故译为"立断"。全篇以"见、修、行、果"四支，各配以"ཅོག་བཞག"（任运而住／任其如是安放）一语作结，依次喻为"如山""如海""显现""觉性"，此四"任运而住"（藏文称"ཅོག་བཞག་བཞི"，四种任运）为大圆满立断法之纲要教授，故译文特意分为四节、逐节标出，以清眉目。
