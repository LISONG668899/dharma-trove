# 堪布阿琼一句教言

**（藏文：གདམས་ངག་ཚིག་གཅིག་མ）**

**堪布阿旺巴桑（阿琼堪布）造**
纽修堪仁波切 录
汉译：据藏文原文，参英译本

---

```
༄༅། །གདམས་ངག་ཚིག་གཅིག་མ་ནི། བླ་མ་ལ་ཕྱག་འཚལ་ལོ། འདིར་རྫོགས་པ་ཆེན་པོའི་སྐབས་ཀྱི་སེམས་ངོ་ཟེར་བ། སེམས་ཀྱི་གཤིས་རང་བབས་ཆོས་ཉིད་ཀྱི་ཐོག་ཏུ་མ་བཅོས་པར་བཞག་པ་སྟེ། མ་ཡེངས་སེམས་ཀྱི་རང་གིས་རང་ལ་བལྟ། ཞེས་ཁ་ནང་ལོག་གིས་ཤེས་པ་རང་གནས་ཐ་མལ་གྱི་ཤེས་པ་རྗེན་ལ་བུད་པ་ཞིག་འཆར་རྒྱུ་ཡོད་པ། ཟ་ཉལ་འགྲོ་འདུག་གི་དུས་ཐམས་ཅད་ན་མི་བརྗེད་པར་དྲན་པས་རྒྱང་འཚོ་བྱེད་ནས་མི་རྒན་གྱིས་བྱིས་པའི་རྩེད་མོ་མཐོང་བ་བཞིན། གྲོལ་སའི་ཆོས་སྐུ་ངོས་བཟུང་ནས། རྩལ་གྱི་རྣམ་རྟོག་ཤར་གྲོལ་རྗེས་མེད་ལམ་དུ་འཁྱེར་དགོས་སོ།། ཞེས་གདམས་ངག་ཚིག་གཅིག་མ་མཁན་ཆེན་ངག་དབང་དཔལ་བཟང་གིས་གསུངས་སོ།།
```

大意：一句教言。顶礼上师！此处所谓大圆满法门中之"识自心性"者，即是于心之本然体性、任运自成之法性上，不加丝毫造作而安住。所谓"心不散乱，以自心观自心"，正是以此向内返观之法，令自然安住之能知——赤裸平常心——得以显露、现前。

无论食、卧、行、住，一切时中，皆以正念不忘而远远看护，犹如老者旁观孩童游戏一般；既已识得那作为解脱之处的法身，则其力用所现之种种分别念，即应以"现即解脱、不留痕迹"的方式，携入道用。

此"一句教言"，乃大堪布阿旺巴桑（阿琼堪布）所说。
