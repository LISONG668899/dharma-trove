# 堪布阿琼所说五智

**（藏文：མཁན་ཆེན་ངག་དགའི་གསུང་རྒྱུན）**

**堪布阿旺嘎（阿旺巴桑，阿琼堪布）口传**
纽修堪仁波切 录
汉译：据藏文原文

---

```
༈ མཁན་ཆེན་ངག་དགའི་གསུང་རྒྱུན། ཆོས་ཐམས་ཅད་ཀྱི་གནས་ལུགས་སེམས་ཀྱི་དེ་ཁོ་ན་ཉིད་ཆོས་ཀྱི་དབྱིངས་མངོན་དུ་གྱུར་པ་ཆོས་དབྱིངས་ཡེ་ཤེས། དེ་ཡང་རིག་པ་རང་བྱུང་གི་གདངས་འགག་མེད་དུ་གསལ་བ་མེ་ལོང་ཡེ་ཤེས། ཆོས་ཐམས་ཅད་ཡེ་ནས་རིག་པ་ཆེན་པོར་རོ་མཉམ་པར་རྟོགས་པ་མཉམ་ཉིད་ཡེ་ཤེས། ཆོས་ཅན་ཀུན་རྫོབ་ཀྱི་ཆོས་ཐམས་ཅད་མ་འདྲེས་པར་རིག་རྩལ་ཤེས་རབ་ཀྱི་མཁྱེན་པས་རྟོགས་པ་སོ་སོར་རྟོགས་པའི་ཡེ་ཤེས། དེ་ཐམས་ཅད་བློའི་འབད་རྩོལ་དང་བྲལ་བར་ལྷུན་གྲུབ་ཆེན་པོར་གཟིགས་པ་བྱ་བ་གྲུབ་པའི་ཡེ་ཤེས་སོ།།
```

大意：大堪布阿旺嘎（阿琼堪布）之口传。

一切法之本住实相，即是心之真如、法界，此〔实相〕现前显露者，即是法界体性智。

而此〔法界之真如〕，以觉性自然生起之光辉、无碍明晰而显现者，即是大圆镜智。

证悟一切法本来即于大觉性中平等一味者，即是平等性智。

〔一方面〕不相混杂，以觉性力用所具之般若慧知，了知一切能依之世俗诸法各自差别之相者，即是妙观察智（译注：原文"རིག་རྩལ"意为觉性本具之力用、势能、创造性展现，指觉性自身所具、能了了分辨万法差别相之动能，而非某种外来之"能量"）。

以上诸智，皆离于心识之勤作造作，而以大任运自成之方式照见者，即是成所作智。
