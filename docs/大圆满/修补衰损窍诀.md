# 出自《龙钦心髓》：修补衰损与破损之窍诀

**（仁增·晋美林巴 取藏）**

**白话译文**

---

顶礼那自然本生的觉性之尊！

当趣入甚深的近修（接近）与成就之法门时，与那位曾为自己灌顶、传法的上师之间，如果有可能存在三昧耶方面的衰损、破坏，这会障碍、夺去修法所应结出的果实。所以，应当依照下面这个要害之处的窍诀去修持：

将那位曾赐予自己灌顶与传承的上师，观想为一切诸佛的总集之身，如是思惟之后，在自己的头顶之上，将他（或她）观想生起。在具足"四力"（也就是依止之力、追悔对治之力、遮止不再犯之力，以及现行对治之力）这几个要点的状态之中，先诵持三遍那传达《猛象奔突续》密意的《智慧殊胜身》祈祷文，随后尽自己所能地持诵百字明，最后再诵持元音辅音咒（阿里嘎里）以及缘起心咒的精要。

这样做完之后，安住在头顶上的那位上师，便依照自己平素所亲近、修持的是哪一位本尊，而循序渐次地转化为那位本尊之身。这时，观想自己领受了（宝瓶、密、慧、句）四种灌顶，并持诵本尊的根本心咒。随后，观想本尊融化为光明，融入自己身中；自己也随之融入那显空无二、离于言语诠说的境界之中，安住在那离于一切分别、赤裸裸的本然状态之中。

从这以后，无论是三昧耶的衰损、破坏，还是心中的怀恨、记恨之念，都永远不应当再让它们停留、安住在自己的心相续之中。

这是诸多要害窍诀之中（最为核心）的一条窍诀，是那总集一切部族、具足三身的上师，以密意传承加持的方式所降下、传授的教言。愿将它牢牢地楔入自己的心间！萨玛雅（誓言）！

---

《修补衰损与破损之窍诀》（终）
