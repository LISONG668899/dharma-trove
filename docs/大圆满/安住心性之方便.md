# 安住心性之方便

堪布岗夏旺波 造

```
ནང་གི་རིག་པ་ཁ་ཡན་ཐོང་། །
ཕྱི་རུ་སྣང་ལ་མ་ཞེན་པར། །
ཕྱི་ནང་མེད་པ་ཟང་ཐལ་ལེ། །
དགའ་སྡུག་གྲོལ་བ་ཨེ་མ་ཧོ། །
```

内在之觉性，任其开阔坦荡；于外在之显现，不生耽著；内外二者俱泯，通透洞然；苦乐悉皆解脱，稀有哉！

```
ཡེངས་བ་ཡོད་ན་སེམས་ཀྱི་ཆ། །
དགའ་སྡུག་ཡོད་ན་སེམས་ཀྱི་ཆ། །
རེ་དོགས་ཡོད་ན་སེམས་ཀྱི་ཆ། །
བཟང་ངན་སྣང་ན་སེམས་ཀྱི་ཆ། །
གཙང་བཙོག་སྣང་ན་སེམས་ཀྱི་ཆ། །
```

若有散乱，此乃心之一分；若有苦乐，此乃心之一分；若有希冀忧惧，此乃心之一分；若显现好坏，此乃心之一分；若显现净秽，此乃心之一分。

```
དེ་དུས་རྒྱུ་འབྲས་ཁྱད་མ་གསོད། །
སྤྱོད་པ་ཞིབ་ཞིབ་དམན་ས་བཟུང་། །
ཐོ་ཅོའི་རྩིང་སྤྱོད་མི་མཛད་པར། །
སྤྱོད་པ་མི་དང་བསྟུན་ནས་ནི། །
དགའ་སྡུག་ནང་ནས་སྦྱངས་ལ་ཤོག །
```

于此之时，切莫轻忽因果；行为当细致谨慎、甘处卑下之地，不应行放肆粗野之举，当使行为随顺世间人情，而将苦乐从内在加以净治。

```
ལམ་གྱི་ས་ཚོད་རང་ལ་དྲིས། །
ན་ཚ་སྡུག་བསྔལ་ཨེ་བཟོད་ལྟོས། །
བརྙས་བཅོས་ཁྱད་གསོད་ཨེ་བཟོད་ལྟོས། །
མ་བཟོད་ཕལ་པ་དང་མཚུངས་ན། །
ད་དུང་ལམ་རྩལ་མ་རྫོགས་རྟགས། །
```

修道之进度如何，当自己扪心自问：且看疾病痛苦能否安忍，且看受人轻蔑、欺侮、贬损能否安忍；若不能安忍、与凡俗之人无异，则表明道上之力用尚未圆满。

```
བླ་མ་ལྷ་ལ་གསོལ་བ་ཐོབ། །
དབང་བཞི་བླངས་ལ་ཐུགས་ཡིད་བསྲེ། །
འཛིན་མེད་ངང་དུ་ལྷོད་དེ་ཀློད། །
རྩོལ་མེད་ངང་དུ་ཤིག་གེ་ཞོག །
```

应当祈祷上师本尊，领受四灌顶，令上师之智慧心与自心相融；于无执之境界中放松坦然，于无勤之境界中彻底松开而安住。

```
སྐབས་སུ་རྒྱུ་འབྲས་བསླུ་མེད་བསམ། །
འགྲོ་བའི་སྡུག་བསྔལ་བདག་ལ་ལོངས། །
བདག་གི་བདེ་དགེ་གཞན་ལ་བྱིན། །
བདེ་སྡུག་གཏོང་ལེན་དམིགས་པ་གྱིས། །
```

有时应思惟因果决定不虚，将有情众生之痛苦由自己领受，将自己之安乐善根施予他人，修习以苦乐为所缘之施受法。

```
ངན་པ་མ་སྤངས་གང་དགར་ཀློད། །
བཟང་པོ་མ་རྩོལ་གང་དགར་ཀློད། །
བཟང་ངན་རེ་དྭོགས་མེད་པ་རུ། །
```

不刻意舍弃所谓不善者，任其随意松放；不刻意勤求所谓善者，亦任其随意松放；于善恶皆无希冀忧惧之中——

```
སུ་དང་འགྲོགས་ཀྱང་བདེ་བདེ་འདྲ། །
གང་དུ་བསྡད་ཀྱང་བདེ་བདེ་འདྲ། །
ཅི་ལྟར་བྱས་ཀྱང་བདེ་བདེ་འདྲ། །
```

无论与谁相伴，皆同样安乐；无论安住何处，皆同样安乐；无论行持何事，皆同样安乐。

```
རྒྱུ་འབྲས་ཇེ་ཞིབ་སོང་ནས་ནི། །
རང་དོན་བདག་འཛིན་ཆུང་ངུར་སོང་། །
དགའ་སྡུག་ཆགས་སྡང་ཆུང་ངུར་སོང་། །
ཤི་བའི་འཇིགས་པ་མི་དགོས་ཚེ། །
ཉམས་རྩལ་ཅུང་ཟད་རྫོགས་པའི་རྟགས། །
```

对因果愈发细致谨慎之后，自利与我执便逐渐减弱，对苦乐之贪著、嗔恨亦逐渐减弱；若已不需畏惧死亡之时，此即修行觉受与力用稍许圆满之征兆。

```
མདོར་ན་དུས་རྣམས་ཀུན་ཏུ་ནི། །
མ་བཅོས་རང་བབ་ཀློད་ཤེས་ན། །
དབྱིངས་ལས་སུ་ཡང་གཡོ་མ་མྱོང་། །
```

总而言之，于一切时中，若知晓不加造作、任运松坦，则从未曾自法界中有丝毫动摇。

```
དེ་སྐད་གང་ཤར་དབང་པོ་ཡི། །
སྨྱོན་ཚིག་ཐོལ་བྱུང་སོང་བ་དེ། །
ཁྱེད་ཀྱང་ང་དང་གཉིས་མེད་པས། །
འགྲོ་བ་ཡོངས་ལ་ཕན་ཐོགས་ཤོག། །།
```

如是所说，乃岗夏旺波随所显现、脱口而出之疯语。愿你与我无二无别，愿此利益一切有情！

## 译者说明

本篇依藏文原文重新译出，参考但不依循已有中译本之措辞。原文风格质朴直白，近乎口语教诫，故译文亦力求平实，不作雕琢。"སེམས་ཀྱི་ཆ"（心之一分）一语反复出现，指散乱、苦乐、希冀忧惧、净秽好坏等种种显现，皆不出自心之显现范畴，非有别体，故皆译为"心之一分"，以存原文复沓之节奏与教诫之力度。末句作者自称"疯语"（སྨྱོན་ཚིག），乃藏地大成就者常见之谦称，喻其教言乃随觉受直陈、不假雕饰之直指教授，故依原意直译，不作美化。
