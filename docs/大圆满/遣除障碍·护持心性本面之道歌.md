# 遣除障碍·护持心性本面之道歌

堪布岗夏旺波 造

顶礼殊胜导师上师足下！

```
ཁྱོད་ཀྱི་ཉམས་སུ་ལེན་རྒྱུ་ལ། །
བླ་མ་སངས་རྒྱས་དངོས་མཐོང་གིས། །
མོས་གུས་དྲག་པོས་གསོལ་བཏབ་ཅིང་། །
དབང་བཞི་བླངས་ལ་ཐུགས་ཡིད་བསྲེས། །
```

于你所应修持者而言：应将上师照见为真实之佛，以猛利之信解虔敬而祈祷，领受四种灌顶，令其智慧心与自心相融合。

```
ད་ལྟའི་ཐད་ཀའི་ཐ་མལ་གྱི། །
ཤེས་པ་གསལ་རིག་འདི་ཀ་ལ། །
ངན་རྟོག་འཇུར་བུའི་མ་བཅིངས་པར། །
འགྱུ་ཡིས་སྡུག་དང་གནས་ན་དགའ། །
```

于当下此刻之平常明晰觉知本身，不被恶劣分别念之纠结所缠缚；心动摇之时不生忧苦，心安住之时亦不生欢喜。

```
སྒྲིམ་ཀློད་བྱེ་བློ་མ་ཙམ་པར། །
གཤིས་ལུགས་ངང་དུ་བབ་ཀྱི་ལྷོད། །
```

不加区分紧、松，于本然实相之境界中，任运松坦。

```
རྣམ་རྟོག་ཕྱི་རུ་སྤྲོ་བ་དང་། །
རིག་པ་ནང་དུ་སྡུད་པ་སོགས། །
བཅས་བཅོས་དགག་སྒྲུབ་མི་བྱེད་པར། །
གཏད་མེད་ངང་དུ་ཁྲོ་ལེར་ཞོག །
```

分别念纵然向外散逸，亦不需将觉性收摄于内等——不作如是这般之遮止、成立、造作，只需于无所依托之境界中，坦然而住。

```
བལྟར་མེད་སེམས་ཀྱི་ཆོས་ཉིད་ལ། །
མཐོང་འདོད་རེ་བ་མ་ཆེ་བར། །
གང་ཤར་ཆོས་སྐུའི་ཡོ་ལངས་ཆེར། །
རྒྱ་གྲོལ་ཕྱལ་པར་ཀློད་ལ་ཐོང་། །
```

于此不可观见之心之法性，莫怀"欲求得见"之希冀；无论何念生起，皆是法身广大之游舞，应彻底解脱、坦荡松放。

```
ཚོགས་དྲུག་ལྷུག་པར་བུ་ཆུང་སེམས། །
བཟང་རྟོག་ཞེན་མེད་འཇའ་ཤར་འདྲ། །
ངན་རྟོག་སྦྲུལ་མདུད་རང་གྲོལ་བཞིན། །
རྣམ་ཀུན་བག་ཆགས་རྗེས་མ་འབྲང་། །
```

幼稚之心，无非即是六聚（六识）任运松坦而已；于生起之善念，不生执著，犹如空中彩虹之显现；于恶念，则如蛇自解其结一般自然解脱——一切种种，皆不随逐旧习气之后而行。

```
ཆགས་ན་ཆགས་མཁན་རྩ་བ་ཆོད། །
ཞེན་ན་ཞེན་མཁན་རྩད་ནས་ཕྱུང་། །
བྱིང་ན་རྩལ་སྦྱངས་ཉམས་བོགས་འབྱུང་། །
མཉམ་བཞག་རྗེས་ཐོབ་ངོ་བོ་ཁྱེར། །
```

若生贪著，当斩断能贪者之根本；若生耽执，当从根本上拔除能执者；若陷昏沉，当加以调练力用，令觉受得以增上；应将等持中之本体，携入后得位中。

```
དུས་རྒྱུན་ངེས་འབྱུང་སྐྱོ་ཤས་དང་། །
ཞེན་ལོག་དཀའ་སྤྱད་སྒྲུབ་ཚུགས་བརྟན། །
མོས་གུས་སྙིང་རྗེ་བསྐྱེད་རྫོགས་དང་། །
ཤི་ཡང་འགྱོད་མེད་ཚགས་ཚུད་མཛོད། །
```

恒常具足出离心与厌离、舍离贪执、堪忍苦行、修持稳固、信解虔敬、大悲心、生起次第与圆满次第，乃至纵然死亡亦无有悔恨——愿你能真实证得如是稳固之成就。

```
དེ་སྐད་དགེ་སྦྱོང་ཧྲལ་པོ་དེས། །
ལུང་དང་བླ་མའི་མན་ངག་དང་། །
རང་གི་མྱོང་བ་བསྟུན་ནས་བྲིས། །
དགེ་བས་ཁྱེད་ལ་ཕན་གྱུར་ཅིག །
```

如是所说，乃一衣衫褴褛之苦行僧，依教典、上师之窍诀教授，并结合自身之亲身体验而书写者。愿以此善根，利益于你！

如是所说，乃岗夏旺波所写。愿善妙！

## 译者说明

本篇依藏文原文重新译出，参考但不依循已有中译本之措辞。全篇脉络清晰：首以视上师为真佛、祈请灌顶为入门；次以"不缠缚、不忧喜、不分紧松"指授护持心性之要领；再以"六识任运松坦""善念如虹、恶念如蛇解结"说明念头自解之理；末以恒常具出离、虔敬、悲心、生圆次第稳固、临终无悔等，作为修行验相之衡量标准。作者自称"衣衫褴褛之苦行僧"，为岗夏旺波一贯之谦称风格，与其他篇目中"迷惑老乞丐""愚昧老翁"等自称一脉相承，译文皆依原意直译，不作美化。
