# 将大圆满自性义付诸修持的教言

*巴珠仁波切 造*

顶礼上师！

这不可思议的大圆满之深义，本来解脱、赤露自性，全知父子二位及其传承祖师，以及具德怙主——根本上师的足下，我在此恭敬顶礼。

远离功过、成立遮遣、取舍等一切分别，当下这个任运自然、坦然放松的心，就是未经丝毫造作、无有改变的觉性智慧；安住在这样的状态中，就是见与修双运。

只懂得如何"修"，却不懂得如何"解脱"，这样的禅定，经上说就如同色界天人的禅定一样（无法真正出离）。所以，证悟到什么程度并不重要，关键在于是否把握住了"解脱"这一点，这才是最要紧的。

靠着令心不动摇、安住一处的止的禅定，虽然能暂时压伏烦恼的势头，但如果不懂得"自解脱"这一密要，一旦遇到外缘触发，分别念这个毒素依然会苏醒发作。

如果懂得念头"自生自解"这一关要，那么取舍之类的分别念，就如同在水面上画图案一样，瞬间生起，随即消失，无法站住脚跟。

因为念头的生起与解脱同时发生，无法立足，所以即使恶念生起，也不会累积恶业；既然一刹那间已经证悟，那又谈得上对谁有利、对谁有害呢？

反过来说，如果不具备当下自解脱这一关要，潜藏在底层的分别念与烦恼便会连绵不断；就算能用正念认出它们，但好坏念头仍会引生希求与畏惧，依旧会累积业行，成为轮回之因。

所以，纵有上千次心安住的觉受体验，也比不上一刹那觉性自解脱来得殊胜。本来解脱、自然解脱、随生随解脱、赤裸解脱等等，名相虽异，实则见、修、行一切的关要都归于同一点，因此务必在"自解脱"这一关要上反复串习。

懂得这一关要，便无需另寻其他见修。此后，一切善念会源源不断生起而无所执著；即便精进行善，内心也不会生起自视高人一等的骄慢。一切恶念，都会像蛇结自然松解那样自行消散；五毒纵然生起，也在刹那间当下自解脱。介于善恶之间的中性念头，也会自然消融于觉性的广境之中，如鸟飞过天空，来去无迹。

轮回的根源，就是迷乱的分别念。若能对"将分别念带入道用而令其解脱"这一点具足把握，便可说轮回已在涅槃法界中解脱。

若不具备这种凭借解脱的信心、把握而将恶缘转为道用的关要，那么即便嘴上空谈自己已经证悟，也只会毫不掩饰地露出恶劣秉性的真面目——五毒的顽固执着，甚至比普通凡夫还重。之所以如此，正是不懂解脱分寸的过失所在。

所以，见修行一切的关要，最终都归结在对解脱方式的证悟与把握上；务必把证悟与外缘融合在一起、带入道用，这才是最珍贵的。

话虽如此，我自己心相续中其实并未真正具备这些境界，只是依凭全知上师——那位真正的佛陀化身——的教言，才写下这篇无有错谬的文字。这正是修持的关要所在，愿你铭记于心。

一切吉祥！
