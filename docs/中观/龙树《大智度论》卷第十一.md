# 龙树《大智度论》卷第十一

龙树菩萨造　后秦龟兹国三藏鸠摩罗什奉诏译

## 释初品中舍利弗因缘第十六

### 一、释“佛告舍利弗”

【经】

佛告舍利弗。

【论】

#### （一）何以告舍利弗：智慧第一

问：般若波罗蜜是菩萨摩诃萨的法，佛为什么告诉舍利弗，而不告诉菩萨？

答：舍利弗在一切弟子中智慧最为第一，如佛的偈中说：

```
一切众生智，　唯除佛世尊；
欲比舍利弗，　智慧及多闻；
于十六分中，　犹尚不及一。
```

大意：一切众生的智慧，除了佛世尊以外，想要与舍利弗的智慧与多闻相比，在十六分中还不及一分。

#### （二）八岁登座论议

再者，舍利弗智慧多闻，有大功德。刚满八岁，就能背诵十八部经，通晓一切经书的义理。当时，摩伽陀国有龙王兄弟二人：一名姞利，二名阿伽罗。按时降雨，国中没有荒年，人民感念龙王，常在仲春之月全体聚集到龙王所住之处，为龙王设大会，奏乐论义，整整一天。从古到今，这个集会从未中断，于是就以龙王的名字来命名这个法会。这一天按照常规，铺设四个高座：一个给国王，一个给太子，一个给大臣，一个给论议之士。

那时，八岁的舍利弗问众人：“这四个高座是为谁铺设的？”众人回答：“为国王、太子、大臣、论议之士。”这时，舍利弗观察当时的婆罗门等人，看他们的神情风度，没有胜过自己的，就登上论议之座，结跏趺坐。众人疑惑惊怪，有的说是愚昧小儿无知，有的说是智量过人。虽然也赞赏他的神异，却仍各怀自矜，以与小孩子论议为耻，不亲自与他说话，都派年少的弟子传话问他。舍利弗的回答旨趣深远，辞理超绝，当时的诸论师都赞叹从未有过，愚者智者、长幼大小全都折服。国王非常欢喜，当即命有司封赐一个村落，常年供给舍利弗。国王乘着象车，摇铃宣告一切人，十六大国、六大城中没有不欢庆喜悦的。

#### （三）与目连结友，删阇耶师临终而笑

这时，有一位占卜师的儿子，名叫拘律陀，姓大目揵连，舍利弗与他结交，彼此亲近。舍利弗以才智聪明受人敬重，目揵连以豪爽而最为尊贵。这两个人才智相当，德行相同；出行时一同游历，住下时一同居止；从小到大情谊深厚，约定终生相随。后来两人都厌离世间，出家学道，作了梵志的弟子。两人一心求入道之门，很久都没有验证，就去问老师。老师名叫删阇耶，回答说：“我求道以来，历经多年，不知道是有道果还是没有道果？是我不够资格吗？总之我也没有得到！”

有一天，老师病重，舍利弗站在床头边，大目连站在床脚边，老师喘息急促，生命将尽，却怜悯地笑了一笑。两人同心，一同问老师为什么笑。老师回答说：“世俗之人没有眼睛，被恩爱所侵害。我看见金地国的国王死了，他的大夫人自己投入焚尸的火中，想与国王同生一处，然而这两个人行业果报各不相同，受生之处相差悬殊。”这时，两人记下老师的话，想要验证其虚实。后来有金地的商人远道来到摩伽陀国，两人用这件事去验证，果然如老师所说，于是怅然叹息说：“我们是不够资格吗？还是老师对我们隐瞒了？”两人互相立誓说：“如果谁先得到甘露，一定要与对方同享其味。”

#### （四）闻阿说示一偈得初道

这时，佛度化了迦叶兄弟一千人，依次游历诸国，到了王舍城，住在竹园。这两位梵志师听说佛出世，一同进入王舍城，想打听消息。那时，有一位比丘名叫阿说示（五比丘之一），穿衣持钵，入城乞食。舍利弗看见他的仪容服饰与众不同，诸根寂静，就走上前去问他：“你是谁的弟子？老师是什么人？”阿说示回答：“释种太子厌离老、病、死之苦，出家学道，证得阿耨多罗三藐三菩提，就是我的老师。”舍利弗说：“请为我说说你老师的教法！”阿说示随即以偈回答：

```
我年既幼稚，　学日又初浅，
岂能宣至真，　广说如来义！
```

大意：我年纪还小，学道的日子又短浅，怎能宣说至真之理，广说如来的义理！

舍利弗说：“请简略说说其中的要点！”那时，阿说示比丘说了这首偈：

```
诸法因缘生，　是法说因缘，
是法因缘尽，　大师如是说。
```

大意：诸法从因缘而生，这法宣说的是因缘；这法也因因缘而灭尽，大师就是这样说的。

舍利弗听了这首偈，随即证得初道，回去告诉目连。目连见他容颜和悦，迎上前去对他说：“你得到甘露之味了吗？请为我说说！”舍利弗随即为他说了先前所听到的偈。目连说：“再为我说一遍！”舍利弗就又说了一遍，目连也证得初道。

#### （五）二人率弟子归佛，半月后证阿罗汉

两位老师与二百五十名弟子一同来到佛所。佛远远看见两人与弟子一同前来，告诉诸比丘：“你们看见这两个人走在诸梵志前面吗？”诸比丘说：“看见了。”佛说：“这两个人，是我弟子中智慧第一、神足第一的弟子。”大众一同前来，渐渐走近佛，到了之后稽首礼拜，在一旁站立，一同对佛说：“世尊！我们想在佛法中出家受戒！”佛说：“善来比丘！”当即须发自落，法衣着身，衣钵具足，受具足戒。过了半个月，佛为长爪梵志说法时，舍利弗证得阿罗汉道。之所以半个月后才证道，是因为这个人应当作随佛转法轮的老师，应当在有学之地亲自深入诸法，种种都知道，所以半个月后才证得阿罗汉道。像这样种种功德非常多，所以舍利弗虽然是阿罗汉，佛却以这甚深的般若波罗蜜之法，为舍利弗宣说。

### 二、何以初为舍利弗说，后为须菩提说

问：如果是这样，为什么开始少为舍利弗说，后来多为须菩提说？如果因为智慧第一，就应当多为舍利弗说，又为什么为须菩提说？

答：舍利弗在佛弟子中智慧第一；须菩提在弟子中，证得无诤三昧最为第一。无诤三昧的相，是常观察众生，不使众生心生恼乱，多行怜悯。诸菩萨弘发大誓愿以度众生，怜悯之相相同，所以命须菩提宣说。

#### （一）须菩提观空，是为最初礼佛

再者，这位须菩提喜好修行空三昧。如佛在忉利天结夏安居完毕，回到阎浮提。那时，须菩提住在石窟中，自己思惟：“佛从忉利天下来，我应当到佛所去，还是不去？”又想：“佛常说：如果有人以智慧眼观佛的法身，就是见佛中最殊胜的。”这时，因为佛从忉利天下来，阎浮提中四部众都聚集起来，诸天见到人，人也见到天。座中有佛，以及转轮圣王、诸天大众，法会庄严，前所未有！须菩提心想：“现在这大众虽然殊胜特异，其势不会久住，是磨灭之法，都归于无常。”因为这无常观的初门，完全了知诸法空无实体；这样观察时，当即证得道果。

那时，一切众人都想争先见佛，礼敬供养。有一位华色比丘尼，想除去作为女人要排在后面的名分，就化作转轮圣王以及七宝、千子，众人见了，都避开起座离去。化王到了佛所之后，恢复本身，作为比丘尼最先礼佛。这时，佛告诉比丘尼：“不是你最先礼我，是须菩提最先礼我。为什么？须菩提观诸法空，这才是见佛法身，得到真正的供养，是供养中最殊胜的，不是以致敬生身作为供养。”所以说须菩提常行空三昧，与般若波罗蜜的空相相应。所以佛命他宣说般若波罗蜜。

再者，佛因为众生信敬阿罗汉诸漏已尽，命阿罗汉宣说，大众就能得到清净的信心。诸菩萨的漏还没有断尽，如果以菩萨作证，人们不会相信。所以与舍利弗、须菩提共说般若波罗蜜。

### 三、舍利弗名字的由来

问：为什么名为舍利弗？是父母所起的名字，还是依其行持功德而立的名？

答：是父母所起的名字。

在阎浮提中第一安乐之处，有摩伽陀国，国中有一座大城名叫王舍，国王名叫频婆娑罗。有一位婆罗门论议师，名叫摩陀罗，国王因为这个人善于论议，赐封一座城邑，离城不远。这位摩陀罗于是成了家，妻子生了一个女儿，眼睛像舍利鸟的眼睛，就给这女儿取名为舍利。后来又生了一个男孩，膝骨粗大，名叫拘郗罗（拘郗罗，汉语意为大膝）。这位婆罗门有了家室，养育儿女，以前所学的经书都已荒废遗忘，又不学新的。

这时，南天竺有一位婆罗门大论议师，名叫提舍，对十八种大经全都通达。这个人进入王舍城，头上顶着火，用铜片包着肚子。有人问他缘故，他就说：“我所学的经书非常多，恐怕肚子会撑破，所以用铜片包着。”又问：“头上为什么顶着火？”他回答：“因为太黑暗了。”众人说：“太阳出来照耀光明，为什么说黑暗？”他回答：“黑暗有两种：一是日光照不到，二是愚痴的黑暗遮蔽。现在虽然有太阳的光明，愚痴却仍然一片漆黑。”众人说：“你只是还没有见到婆罗门摩陀罗，你如果见到他，肚子就会缩小，光明就会暗下去。”这位婆罗门径直走到鼓边，击打论议之鼓。

国王听到了，问这是什么人？众臣回答：“南天竺有一位婆罗门，名叫提舍，是大论议师，想找论议之处，所以击打论鼓。”国王非常欢喜，随即召集众人，告诉大家：“有能质难他的，就与他论议！”

摩陀罗听到这件事，自己心生疑虑：“我已经荒废遗忘，又不学新的，不知道我现在能不能与他论议？”勉强前来。在路上看见两头公牛正在互相顶撞，心中作想：“这头牛是我，那头牛是他，以此占卜，看谁能胜？”这头牛输了，摩陀罗就非常忧愁，自己心想：“这样的征兆，我将会输。”要进入大众时，看见一个妇人抱着一瓶水，正在他面前，跌倒在地，打破了水瓶。他又这样想：“这也不吉利。”非常不高兴。进入大众之后，看见那位论师，容貌神色，胜相具足，自知不如。事已至此，不得已，只好与他论议。论议一交锋，就落入败处。

国王非常欢喜，因为有大智慧的明人远道来到我国，又想为他封赐一个村落。诸臣议论说：“一个聪明人来了，就封赐一座城邑，有功之臣不加赏赐，只宠爱论议之人，恐怕不是安国保家之道！现在摩陀罗论议不如人，应当夺去他的封邑给胜者；如果以后再有胜过的人，就再给那个人。”国王采纳了他们的意见，随即夺去摩陀罗的封邑给了后来的人。

这时，摩陀罗对提舍说：“你是聪明人，我把女儿嫁给你，儿子也托付给你；我现在想远走他国，去追求我本来的志向。”提舍娶了他的女儿为妻。

他的妻子怀孕后，梦见一个人，身披甲胄，手执金刚，摧破众山，站在大山旁边。醒来后告诉丈夫：我梦见这样的情景。提舍说：“你会生个男孩，能摧伏一切论议师，只有一个人胜不过，将会作那个人的弟子。”

舍利怀孕之后，因为腹中孩子的缘故，母亲也变得聪明，非常善于论议。她的弟弟拘郗罗与姐姐谈论，每每被驳倒；知道姐姐所怀的孩子必定有大智慧，还没有出生就已经这样，何况出生之后？就舍家去求学，到了南天竺，不剪指甲，读十八种经书，全都通达，所以当时的人称他为长爪梵志。

姐姐的孩子出生之后，过了七天，用白毡包裹着，抱给他父亲看。父亲思惟：“我名叫提舍，随着我的名字，就叫他忧波提舍。”（忧波，汉语意为随；提舍，是星宿名）这是父母所起的名字。

众人因为他是舍利所生，都一同称他为舍利弗（弗，汉语意为子）。

再者，舍利弗世世的本愿，是在释迦文尼佛处作智慧第一的弟子，名叫舍利弗。这是本愿因缘的名字，所以名为舍利弗。

问：如果是这样，为什么不说“忧波提舍”，而只说“舍利弗”？

答：当时的人敬重他的母亲，在众女人中聪明第一，因为这个因缘，所以称为舍利弗。

### 四、释“欲以一切种知一切法，当习行般若波罗蜜”

【经】

“菩萨摩诃萨欲以一切种知一切法，当习行般若波罗蜜。”

【论】

“菩萨摩诃萨”的意义，如先前〈赞菩萨品〉中所说。

#### （一）一切种

问：什么名为“一切种”？什么名为“一切法”？

答：智慧之门名为“种”。有人以一种智慧门观察，有人以二、三、十、百、千、万乃至恒河沙等阿僧祇智慧门观察诸法。现在以一切智慧门进入一切种，观察一切法，这名为“一切种”。

如凡夫人有三种观察，为了求离欲界、离色界：观察欲界、色界粗恶、欺诳迷惑、浊重。

佛弟子有八种观察：无常、苦、空、无我、如病、如痈疮、如箭入体、恼患。

这八种观察进入四圣谛中，成为十六行相中的四种。

所谓十六行相：观察苦有四种：无常、苦、空、无我；观察苦因有四种：集、因、缘、生；观察苦尽有四种：尽、灭、妙、出；观察道有四种：道、正、行、迹。

出入息中又有十六行：一是观入息，二是观出息，三是观息长息短，四是观息遍身，五是除诸身行，六是受喜，七是受乐，八是受诸心行，九是无作喜，十是心作摄，十一是心作解脱，十二是观无常，十三是观散坏，十四是观离欲，十五是观灭，十六是观弃舍。

又有六种念：所谓念佛，佛是多陀阿伽陀、阿罗呵、三藐三佛陀，像这样等等十号。其余五念，如后面所说。

世间智、出世间智，阿罗汉、辟支佛、菩萨、佛的智慧，像这样等等以智慧了知诸法，名为“一切种”。

#### （二）一切法

所谓“一切法”，识所缘的法就是一切法。就是眼识缘色，耳识缘声，鼻识缘香，舌识缘味，身识缘触，意识缘法；缘眼、缘色、缘眼识；耳与声、鼻与香、舌与味、身与触也是这样；乃至缘意、缘法、缘意识，这名为“一切法”，这是识所缘的法。

再者，智所缘的法就是一切法。就是苦智知苦，集智知集，尽智知尽，道智知道，世间智知苦、集、尽、道，以及虚空、非数缘灭，这是智所缘的法。

再者，以二法摄一切法：色法与无色法；可见法与不可见法；有对法与无对法；有漏与无漏；有为与无为；心相应与心不相应；业相应与业不相应（丹本注：心法中除了思心所，其余都相应，业就是思，所以除去）；近法与远法等（丹本注：现在法以及无为法名为近法，未来、过去法名为远法），像这样种种二法，摄一切法。

再者，以三种法摄一切法：善、不善、无记；学、无学、非学非无学；见谛所断、思惟所断、不断。又有三种法：五众、十二入、十八界。以这样等等种种三法，摄尽一切法。

又有四种法：过去、未来、现在法、非过去未来现在法；欲界系法、色界系法、无色界系法、不系法；以善为因之法、以不善为因之法、以无记为因之法、非以善不善无记为因之法；缘缘法、缘不缘法、缘缘不缘缘法、亦非缘缘非不缘缘法；像这样等等四种法，摄一切法。

有五种法：色、心、心相应、心不相应、无为法；像这样等等种种五法，摄一切法。

有六种法：见苦所断法、见集所断法、见灭所断法、见道所断法、思惟所断法、不断法；像这样等等种种六法，乃至无量法，摄一切法。

这就是一切法。

#### （三）一人何能尽知一切法

问：诸法甚深微妙，不可思议，一切众生尚且不能知道，何况一个人想要尽知一切法？譬如有人想测量大地，计数大海的水滴，称量须弥山，知道虚空的边际，像这样等等事都不可知，怎能以一切种知一切法？

答：愚痴的黑暗遮蔽是极大的苦，智慧光明是最大的乐！一切众生都不要苦，只想求乐。所以菩萨求一切第一的大智慧，以一切种观察，想知道一切法。这位菩萨发大心，普遍为一切众生求大智慧，所以想以一切种知一切法。如医生为一人、二人治病，用一种、两种药就够了；如果想治一切众生的病，就需要一切种药；菩萨也是这样，想度化一切众生，所以想知道一切种、一切法。如同诸法甚深微妙无量，菩萨的智慧也甚深微妙无量，在先前回答“破一切智人”时已经广说过了，如匣子大，盖子也大。

再者，如果不以正理去求一切法，就不可得；如果以正理去求，就没有得不到的。譬如钻木取火，火就能得到；劈开柴薪去找火，火就找不到。如大地有边际，如果不是一切智人，没有大神力，就不能知道；如果神通力大，就能知道这三千大千世界大地的边际。现在这大地在金刚之上，三千大千世界四边就是虚空，这就是知道大地的边际。想称量须弥山，也是这样。想测量虚空，不是不能量，而是虚空没有法，所以不可测量。

### 五、释“舍利弗问佛”

【经】

舍利弗白佛言：“世尊！菩萨摩诃萨云何欲以一切种知一切法，当习行般若波罗蜜？”

【论】

#### （一）何以待问而说

问：佛要说般若波罗蜜，所以显现种种神变，显现之后就应当说，为什么要让舍利弗问了之后才说？

答：问了之后才说，佛法本来就应当如此。

再者，舍利弗知道般若波罗蜜甚深微妙，是无相之法，难解难知。他以自己的智力种种思惟：“如果观察诸法无常，这是般若波罗蜜吗？不是吗？”自己不能明了，所以发问。

#### （二）舍利弗于佛智如小儿：佛影覆鸽

再者，舍利弗不是一切智人，在佛的智慧中，譬如小孩子。

如《阿婆檀那经》中说：

佛住在祇洹，傍晚时经行，舍利弗跟随佛经行。这时有一只老鹰追逐一只鸽子，鸽子飞到佛身边停住，佛经行时从它旁边走过，佛的影子覆盖在鸽子身上，鸽子身体安稳，怖畏随即消除，不再出声。后来舍利弗的影子到了，鸽子就叫了起来，战栗恐怖如同起初一样。

舍利弗对佛说：“佛与我的身中都没有三毒，以什么因缘，佛的影子覆盖鸽子，鸽子就不出声，不再恐怖；我的影子覆盖在它身上，鸽子就叫起来，战栗如故？”

佛说：“你的三毒习气还没有除尽，所以你的影子覆盖时，它的恐怖不能消除。你观察这只鸽子宿世的因缘，有几世作鸽子？”

舍利弗当即进入宿命智三昧，观见这只鸽子从鸽子中来，像这样一世、二世、三世，乃至八万大劫，常作鸽子之身；超过这个限度，就不能再看见了。

舍利弗从三昧中起来，对佛说：“这只鸽子八万大劫中常作鸽子之身；在这之前，我就不能再知道了。”

佛说：“你如果不能尽知过去世，试着观察未来世，这只鸽子什么时候才能脱离鸽身？”

舍利弗随即进入愿智三昧，观见这只鸽子一世、二世、三世，乃至八万大劫，都没有脱离鸽身；超过这个限度，也不能知道了。从三昧中起来，对佛说：“我看见这只鸽子从一世、二世乃至八万大劫，都没有免脱鸽身；超过这个限度，就不能再知道了！我不知道过去、未来的边际，不知道这只鸽子什么时候才能脱离？”

佛告诉舍利弗：“这只鸽子除了声闻、辟支佛所知的限度之外，还要在恒河沙等大劫中常作鸽身，罪报受完才能出离。在五道中轮转，后来得生为人，经过五百世，才得到利根。那时有佛，度化无量阿僧祇众生，然后入无余涅槃。佛的遗法在世时，这个人作了持五戒的优婆塞，从比丘那里听到赞叹佛的功德，于是初次发心，愿意作佛。然后在三阿僧祇劫中修行六波罗蜜，十地具足，得以作佛，度化无量众生之后，入无余涅槃。”

这时，舍利弗向佛忏悔，对佛说：“我对一只鸟尚且不能知道它的本末，何况诸法？我如果早知道佛的智慧是这样的，为了佛的智慧，宁可进入阿鼻地狱受无量劫之苦，也不以为难。”

像这样等等，因为对诸法不能明了，所以发问。

## 释初品中檀波罗蜜义第十七

【经】

佛告舍利弗：“菩萨摩诃萨以不住法住般若波罗蜜中；以无所舍法具足檀波罗蜜，施者、受者及财物不可得故。”

【论】

### 一、般若波罗蜜是何等法：诸家异说

问：“般若波罗蜜”是什么法？

答：有人说：无漏慧根是般若波罗蜜之相。为什么？一切智慧中第一的智慧名为般若波罗蜜，无漏慧根是第一，所以无漏慧根名为般若波罗蜜。

问：如果菩萨还没有断除结使，怎能行无漏慧？

答：菩萨虽然还没有断除结使，修行的是“相似无漏的般若波罗蜜”，所以得名为行无漏般若波罗蜜。譬如声闻人修行暖法、顶法、忍法、世间第一法，先修相似无漏法，以后就容易生起苦法智忍。

又有人说：菩萨有两种：有断除结使而清净的，有未断结使而不清净的。断除结使而清净的菩萨，能行无漏般若波罗蜜。

问：如果菩萨断除结使而清净，又为什么还要行般若波罗蜜？

答：虽然断除了结使，十地还没有圆满，还没有庄严佛土，还没有教化众生，所以行般若波罗蜜。

再者，断结有两种：一是断除三毒之心，不执着人天中的五欲；二是虽然不执着人天中的五欲，对于菩萨功德果报所生的五欲，还不能舍离。这样的菩萨，应当行般若波罗蜜。

譬如长老阿泥卢豆，在林中坐禅时，净爱天女等以清净美妙之身来试探阿泥卢豆。阿泥卢豆说：“诸位姐妹变作青色来，不要杂色。”想观不净，却不能观成；变作黄、赤、白色，也是这样。这时阿泥卢豆闭眼不看，说：“诸位姐妹走远些！”这时天女随即消失不见。天上的福报之形尚且如此，何况菩萨无量功德果报的五欲？

又如甄陀罗王与八万四千甄陀罗来到佛所，弹琴歌颂，以供养佛。那时，须弥山王以及诸山树木、人民、禽兽，一切都随之起舞。佛身边的大众，乃至大迦叶，都在座上不能安坐。这时，天须菩萨问长老大迦叶：“您是年高德劭的长老，修行十二头陀法第一，为什么在座上不能安坐？”大迦叶说：“三界五欲不能动摇我；是这位菩萨神通功德果报之力，使我这样，并不是我心中有所动而不能安坐。譬如须弥山，四边起风，不能使它动摇；到了大劫尽时，毗蓝风刮起，就如同吹烂草一样。”

因为这件事，知道两种结使中有一种还没有断；这样的菩萨等，应当行般若波罗蜜。

这是阿毗昙中这样说的。

又有人说：般若波罗蜜是有漏的智慧。为什么？菩萨到了菩提树下才断除结使；以前虽然有大智慧、有无量功德，种种烦恼却还没有断除。所以说“菩萨的般若波罗蜜是有漏的智慧”。

又有人说：从初发心乃至菩提树下，这期间所有的智慧，名为般若波罗蜜。成佛时，这般若波罗蜜转名为萨婆若（一切智）。

又有人说：菩萨的有漏、无漏智慧，总名为般若波罗蜜。为什么？菩萨观察涅槃，行于佛道，因为这件事，菩萨的智慧应当是无漏的；因为还没有断除结使，事业还没有成办，所以应当名为有漏。

又有人说：菩萨的般若波罗蜜是无漏、无为、不可见、无对的。

又有人说：这般若波罗蜜是不可得之相，无论说有还是说无，说常还是说无常，说空还是说实。这般若波罗蜜不为阴、界、入所摄，非有为、非无为，非法、非非法，无取无舍，不生不灭，超出有无四句，恰恰无所执着。譬如火焰，四边都不可触摸，因为会烧伤手；般若波罗蜜之相也是这样不可触摸，因为会被邪见之火所烧。

### 二、诸说何者为实

问：上面种种人所说的般若波罗蜜，哪一种是真实的？

答：有人说：各有道理，都是真实的。如经中说：五百比丘各自解说二边与中道的意义，佛说都有道理。

有人说：最后的回答是真实的。为什么？因为不可破、不可坏。如果有法如毫毛那样少许是有的，就都有过失，可以被破；如果说无，也可以被破。在这般若中，有也是无，无也是无，非有非无也是无，像这样的言说也是无；这名为寂灭、无量、无戏论之法。所以不可破、不可坏，这名为真实的般若波罗蜜，最殊胜，没有超过的。如转轮圣王降伏一切敌人而不自高；般若波罗蜜也是这样，能破一切言语戏论，也并不认为自己有所破。

再者，从这以后，各品中以种种义门宣说般若波罗蜜，说的都是实相。以不住法住于般若波罗蜜中，能具足六波罗蜜。

### 三、释“不住法住般若波罗蜜中”

问：什么名为以不住法住于般若波罗蜜中，能具足六波罗蜜？

答：如这位菩萨观察一切法，非常非无常，非苦非乐，非空非实，非我非无我，非生灭非不生灭；这样住于甚深般若波罗蜜中，对于般若波罗蜜之相也不执取，这名为不住法住。如果执取般若波罗蜜之相，就是住法住。

【译注】“不住法住”是本卷乃至全论的枢纽语。住于般若，而连般若之相也不取，才是真住；一取般若之相，便成“住法住”，般若也就成了又一个所执之法。这与上文“末后答者为实”一致：般若能破一切戏论，“亦不有所破”。

问：如果不执取般若波罗蜜之相，心无所著，如佛所说：“一切诸法，以欲为根本。”如果不执取，怎能具足六波罗蜜？

答：菩萨因为怜悯众生，先立誓愿：我必定要度脱一切众生。以精进波罗蜜之力，虽然知道诸法不生不灭、如涅槃之相，仍然修行种种功德，具足六波罗蜜。为什么？因为以不住法住于般若波罗蜜中。

这名为“不住法住般若波罗蜜中”。

## 释初品中赞檀波罗蜜义第十八

### 一、檀的种种利益

问：布施有什么样的利益，所以菩萨住于般若波罗蜜中，檀波罗蜜就能具足圆满？

答：布施有种种利益：

布施是宝藏，常随人而行；布施能破苦，能给人快乐；布施是善于驾驭的御者，开示通往天界的道路；布施是善法的府库，能摄受诸善人（布施摄受善人，为善人作因缘，所以说“摄”）；布施是安稳，临命终时心不怖畏；布施是慈的相，能救济一切；布施是积集快乐的方法，能破除痛苦之贼；布施是大将，能降伏悭吝之敌；布施是美妙的果实，为天人所爱；布施是清净的道路，为贤圣所游；布施是积善福德之门；布施是成就事业、聚集大众的因缘；布施是善行与爱果的种子；布施是福业与善人之相；布施能破除贫穷，断除三恶道；布施能完全护持福乐之果；布施是涅槃的最初因缘，是进入善人群中的要法，是称誉赞叹的渊府，是入众无难的功德，是心不悔恨的居所，是善法道行的根本，是种种欢乐的林薮，是富贵安稳的福田，是得道涅槃的津梁，是圣人、大士、智者所行之道，是其余德行浅薄、见识寡少之人所效仿的。

### 二、火中出物之喻

再者，譬如失火的人家，聪明有智慧的人，清楚形势，趁火还没有烧到，赶快搬出财物；房屋虽然烧尽，财物却都还在，可以再修建房屋。好布施的人也是这样，知道身体危脆，财物无常，及时修福，如同从火中搬出财物；后世享受快乐，也如同那人重新修建家业，以福庆自慰。愚昧迷惑的人，只知道爱惜房屋，匆匆忙忙去救火，狂愚失智，不估量火势，猛风吹着烈焰，土石都烧焦了，片刻之间，荡然无存；房屋既没有救下，财物也都烧光了，饥寒冻饿，一生忧苦。悭吝的人也是这样，不知道身命无常，片刻难保，反而更加聚敛、守护、爱惜，死亡来临没有定期，忽然就逝去了，形体与土木同流，财物与废弃之物一同被抛弃，也如同那愚人一样忧苦失算。

再者，有大智慧的人、有心的人，才能觉悟，知道身体如幻，财物不可保，万物无常，唯有福德可以依恃，能带人出离痛苦，通向大道。

再者，大人有大心，能大布施，能自利利己；小人有小心，不能利益他人，也不能厚待自己。

再者，譬如勇士见到敌人，必定要将敌人吞灭；有智慧的人以慧心深入领悟道理，悭吝之贼虽然强大，也能挫败它，必定使之如意。遇到好的福田，遇到好的时节（时，是应当布施的时候。遇到了却不布施，名为失时），觉悟到事情与心相应，就能大布施。

### 三、布施的今世与后世果报

再者，好布施的人为人所敬，如同月亮初升，没有不喜爱的；好的名声美誉遍闻天下，为人所归仰，一切人都信任。好布施的人为贵人所念，为贱人所敬；临命终时心不怖畏，像这样的果报是今世所得；譬如树上开花，以后结出无量的大果，那是后世的福报。在生死中轮转，往来五道，没有亲人可以依恃，唯有布施；如果生在天上、人中，得到清净的果报，都是由于布施；象、马等畜生得到好的厩舍饲养，也是布施所得。

布施的功德是富贵欢乐；持戒的人得以生到天上；禅定与智慧使心清净，无所染着，得到涅槃之道。布施的福德，是涅槃之道的资粮；因为忆念布施而欢喜，因为欢喜而一心，以一心观察生灭无常，因为观察生灭无常而得道。

如人为了求荫凉而种树，或者为了求花，或者为了求果而种树；布施求报也是这样，今世、后世的快乐如同求荫凉，声闻、辟支佛道如同花，成佛如同果。

这是布施的种种功德。

## 释初品中檀相义第十九

### 一、檀的体性

问：什么名为“檀”？

答：檀名为布施；与心相应的善思，名为檀。

有人说：从善思所生起的身业、口业，也名为檀。

有人说：有信心、有福田、有财物，三件事和合时，心中生起舍法，能破除悭贪，这名为檀。譬如慈心之法，观察众生得乐而心生慈悲；布施这一心所法也是这样，三件事和合，心中生起舍法，能破除悭贪。

檀有三种：或者欲界系，或者色界系，或者不系（丹本注：圣人行布施，所以名为不系）。是心相应法，随心而行，与心共生，不是色法，能作缘。不是业，与业相应，随业而行，与业共生，不是前世业报所生。有两种修：行修、得修。有两种证：身证、慧证。或者是思惟所断，或者是不断，见谛所断的两种见都不能断它。欲界、色界的都是见谛所断；是有觉有观法；凡夫与圣人共同行持。像这样等等，阿毗昙中有广泛的分别解说。

### 二、净施与不净施

再者，布施有两种：有清净的，有不清净的。

不清净的布施，如只是随意施与而无所为；或者为了求财而施；或者因为愧对他人而施；或者为了避免被嫌责而施；或者因为畏惧而施；或者为了讨好他人而施；或者因为怕死而施；或者为了让狂人高兴而施；或者自以为富贵，理应布施；或者为了争胜而施；或者因为嫉妒瞋恨而施；或者因为憍慢自高而施；或者为了名誉而施；或者为了求咒愿而施；或者为了解除衰运、求得吉祥而施；或者为了聚众而施；或者以轻贱不敬的心而施。像这样等等种种，名为不清净的布施。

清净的布施，与上面这些相反，名为清净的布施。

再者，为了道而布施，生起清净心，没有种种结使，不求今世后世的果报，因为恭敬与怜悯而布施，这是清净的布施。清净的布施是趣向涅槃之道的资粮，所以说为了道而布施。如果还没有得到涅槃时，布施是人天果报快乐的因。清净的布施，如同花朵与璎珞，刚刚做成还没有败坏，香洁鲜明；为了涅槃而作清净的布施，得到果报之香，也是这样。

如佛说：“世间有两种人难得：一是出家人中的非时解脱比丘；二是在家白衣能清净布施的人。”这清净布施之相，乃至无量世，世世不会失去，譬如契约文书，终究没有失效的时候。这布施的果报，在因缘和合时便会出现。譬如树遇到时节会合，便有花叶果实；如果时节还没有到，有因而没有果。

### 三、布施能助涅槃

这布施之法，如果以之求道，能给人道。为什么？结使灭除名为涅槃。在布施时，种种烦恼变薄，所以能助成涅槃：对所施之物不吝惜，所以除去悭吝；敬念受施者，所以除去嫉妒；以正直之心布施，所以除去谄曲；一心布施，所以除去掉举；深思惟而布施，所以除去悔；观察受施者的功德，所以除去不恭敬；自己收摄其心，所以除去无惭；知道他人的好功德，所以除去无愧；不执着财物，所以除去贪爱；慈悯受施者，所以除去瞋恚；恭敬受施者，所以除去憍慢；知道是在行善法，所以除去无明；相信有果报，所以除去邪见；知道必定有果报，所以除去疑。像这样等等种种不善的烦恼，布施时都变薄了；种种善法都能得到：布施时六根清净，善欲之心生起；因为善欲之心生起，所以内心清净；因为观察果报功德，所以信心生起；因为身心柔软，所以喜乐生起；因为喜乐生起，所以得到一心；因为得到一心，所以真实智慧生起。像这样等等种种善法都能得到。

再者，布施时心中生起相似的八正道：因为相信布施的果报，所以得正见；在正见中思惟不乱，所以得正思惟；因为清净地说话，所以得正语；因为身行清净，所以得正业；因为不求回报，所以得正命；因为勤心布施，所以得正方便；因为忆念布施不废，所以得正念；因为心安住不散，所以得正定。像这样等等相似的三十七品善法，在心中生起。

### 四、布施是三十二相的因缘

再者，有人说：布施是得到三十二相的因缘。为什么？

布施时心意坚固，所以得足下安立相；布施时以五件事围绕，因为受施者成为眷属的业因缘，所以得足下轮相；以大勇猛之力布施，所以得足跟广平相；以布施摄受他人，所以得手足缦网相；以美味饮食布施，所以得手足柔软相、七处隆满相；以布施延益他人寿命，所以得长指相、身不曲相、大直身相；布施时说“我会给你”，布施之心越来越增长，所以得足趺高相、毛上向相；布施时受施者有所求，一心好好听着，殷勤嘱咐，使对方必定迅速得到，所以得伊泥延鹿腨相；不瞋恚、不轻视求施者，所以得臂长过膝相；如求施者的心意布施，不等对方开口，所以得阴藏相；以好的衣服、卧具、金银珍宝布施，所以得金色身相、薄皮相；布施使受施者独自得到自在受用，所以得一一孔一毛生相、眉间白毫相；求施者有所求，当即说会给，因为这种业，所以得上身如狮子相、肩圆相；给病人施药，给饥渴者饮食，所以得两腋下满相、味中最上味相；布施时劝人行施并安慰对方，开启布施之道，所以得肉髻相、身圆如尼拘卢树相；有来乞求的，心中想给时，以柔软真实的言语，必定给予而不落空，所以得广长舌相、梵音声相、如迦陵毗伽鸟声相；布施时说如实之语、利益之语，所以得狮子颊相；布施时恭敬受施者，心清净，所以得牙白相、齿齐相；布施时说真实语、和合语，所以得齿密相、四十齿相；布施时不瞋不着，平等看待对方，所以得青眼相、眼睫如牛王相。

这是种植三十二相的因缘。

再者，以七宝、人民、车乘、金银、灯烛、房舍、香花布施，所以得作转轮王，七宝具足。

### 五、施福增多的种种因缘

再者，布施得其时，果报也会增多。如佛说：“布施给远行的人、远来的人、病人、看护病人的人，在风寒等种种灾难时布施，这是适时的布施。”

再者，布施时随当地所需而施，所以得到的果报增多。

再者，在旷野道路中布施，所以得福增多；常常布施而不废止，所以得报增多；按照求施者所想要的而布施，所以得福增多；所施之物贵重，所以得福增多，如以精舍、园林、浴池等布施；如果布施给善人，所以得报增多；如果布施给僧众，所以得报增多；如果施者与受者都有德（丹本注：如菩萨及佛以慈心布施，这是施者；如果布施给佛及菩萨、阿罗汉、辟支佛，这是受者），所以得报增多；以种种方式迎送、恭敬受施者，所以得福增多；以难得之物布施，所以得福增多；随自己所有之物全都能布施，所以得福增多。

譬如大月氏国弗迦罗城中，有一位画师，名叫千那。他到东方多刹陀罗国，作客画画十二年，得到三十两金子，带回本国。在弗迦罗城中，听到击鼓举行大会的声音，前往观看，见到众僧，信心清净，就问维那：“这些大众要多少钱物，才够一天的饭食？”维那回答：“三十两金子，足够一天的饭食。”画师随即把所有的三十两金子交给维那，说：“请为我设一天的饭食，我明天来。”空着手回家，他的妻子问他：“十二年做工，得到了什么？”他回答：“我得到三十两金子。”妻子又问：“三十两金子现在在哪里？”他回答：“已经种在福田中了。”妻子说：“什么福田？”他回答：“布施给众僧了。”妻子就把丈夫绑起来送到官府治罪，断案的大官问是什么事？妻子说：“我丈夫狂痴，十二年做工得到三十两金子，不怜悯妻儿，全都给了别人；依照官府的法规，就把他绑送来了。”大官问她的丈夫：“你为什么不供养妻儿，竟然把钱给了别人？”他回答：“我前世不行功德，今世贫穷，受种种辛苦；今世遇到福田，如果不种福，后世又会贫穷，贫穷相续，没有脱离的时候。我现在想一下子舍弃贫穷，所以把金子全都布施给了众僧。”大官是一位优婆塞，信佛清净，听了这话，赞叹说：“这非常难得！勤苦得到这点钱物，全都布施给僧众，你是善人！”当即脱下身上的璎珞以及所乘的马，并一个村落，布施给这位穷人，对他说：“你刚刚布施众僧，众僧还没有吃，这是谷种还没有种下，芽就已经长出来了，大果还在后世！”所以说“以难得之物全都用来布施，福德最多”。

### 六、世间檀与出世间檀，声闻檀与菩萨檀

再者，有世间的布施，有出世间的布施；有圣人所称赞的布施，有圣人所不称赞的布施；有佛菩萨的布施，有声闻的布施。

什么是世间的布施？

凡夫人的布施，以及圣人以有漏心所作的布施，这名为世间的布施。

再者，有人说：凡夫人的布施，是世间的布施。

圣人虽然以有漏心布施，因为结使已断，所以名为出世间的布施。为什么？因为这些圣人得到了无作三昧。

再者，世间的布施不清净，出世间的布施清净。有两种结使：一种属于爱，一种属于见。被这两种结使所驱使，是世间的布施；没有这两种结使，是出世间的布施。

如果有三种障碍系缚其心，就是世间的布施。为什么？因缘所生的诸法实际上没有吾我，却说是我给予、他接受，所以名为世间的布施。

再者，“我”没有确定的所在：我认为是“我”，他人认为不是；他人认为是“我”，我认为不是。因为这样不确定，所以没有真实的我。所布施的财物，是从因缘和合而有，没有一个法是能单独得到的。如同绢、如同布，因为众多因缘和合而成，除去丝、除去线，就没有绢、布；诸法也是这样，一相即是无相，相常自空。人们作想念，计度为有，颠倒而不真实，这是世间的布施。

心中没有这三种障碍，如实知道诸法之相，心不颠倒，这是出世间的布施。

【译注】“三碍”就是卷四所说的施者、受者、施物三事。卷四说三事“不可得”，本卷进一步说明为什么不可得：“我”无定处，此以为我、彼以为非；财物如绢布，除丝除缕则无。所以心中不被三事所碍，才是出世间檀，才能如经文所说“以无所舍法具足檀波罗蜜”。

出世间的布施为圣人所称赞，世间的布施为圣人所不称赞。

再者，清净的布施，不夹杂结使污垢，契合诸法实相，为圣人所称赞；不清净的布施，夹杂结使，以颠倒心执着，为圣人所不称赞。

再者，与实相智慧和合的布施，为圣人所称赞；如果不是这样，就为圣人所不称赞。

再者，不是为了众生，也不是为了知道诸法实相而布施，只求脱离生、老、病、死，这是声闻的布施；为了一切众生而布施，也为了知道诸法实相而布施，这是诸佛菩萨的布施。

对种种功德不能具足，只想得到少许的部分，这是声闻的布施；想使一切种种功德都具足圆满，这是诸佛菩萨的布施。

因为畏惧老、病、死而布施，这是声闻的布施；为了助成佛道、为了教化众生，不畏惧老、病、死，这是诸佛菩萨的布施。

### 七、外布施：韦罗摩菩萨大施

这里应当说菩萨的本生经，如《阿婆陀那经》中说：从前阎浮提中有一位国王，名叫婆萨婆。那时有一位婆罗门菩萨，名叫韦罗摩，是国王的老师，教国王作转轮圣王之法。韦罗摩财富无量，珍宝具足，这样思惟：“人们说我是贵人，财富无量，能饶益众生，现在正是时候，应当大布施。富贵虽然快乐，一切都是无常的，为五家所共有，使人心散乱，轻浮不定，譬如猕猴不能片刻安住；人命逝去迅速，比闪电消失还快，人身无常，是众苦的渊薮。因为这个缘故，应当行布施。”

这样思惟之后，亲自写了文书，普遍告知阎浮提的诸婆罗门以及一切出家人：“愿各位屈尊，来我家集会，我要设大布施。”准备了整整十二年：饭汁之多可以行船，以酪为池，米面堆成山，酥油流成渠，衣服、饮食、卧具、汤药，都极为精妙。过了十二年，准备布施：八万四千头白象，披着犀甲，以金装饰，以名贵宝物作璎珞，竖起大金幢，以四宝庄严；八万四千匹马，也披着犀甲，以金装饰，以四宝交错为络。八万四千辆车，都以金、银、琉璃、颇梨宝物装饰，覆盖着狮子、虎、豹的皮，或者以白色的剑婆罗宝物（此处原文二字缺损）杂饰，作为庄严；八万四千张四宝床，铺着杂色的锦褥、种种垫褥，柔软细滑，用作装饰，红色的枕头、锦缎的被子放在床的两头，美妙的衣服、华丽的服饰也都齐备；八万四千个金钵盛满银粟，银钵盛满金粟，琉璃钵盛满颇梨粟，颇梨钵盛满琉璃粟；八万四千头乳牛，每头牛出乳一斛，以金装饰牛的蹄角，披上白毡；八万四千位美女，端正有福德，都以白珠与名贵宝物作璎珞装饰身体。简略地举出要点，像这样种种，不可胜记。那时，婆罗婆王以及八万四千诸小国王，连同诸臣民、豪杰、长者，各以十万旧金钱赠送劝助，共同举办这场法祠。布施准备具足之后，释提婆那民来对韦罗摩菩萨说了这首偈：

```
天地难得物，　能喜悦一切；
汝今皆以得，　为佛道布施！
```

大意：天地间难得的东西，能使一切众生喜悦；你现在都已得到，是为了佛道而布施！

那时，净居诸天现身赞叹，说了这首偈：

```
开门大布施，　汝所为者是；
怜愍众生故，　为之求佛道！
```

大意：打开大门广作布施，你所做的正是如此；因为怜悯众生，为众生求佛道！

这时，诸天这样思惟：“我们应当封闭他的金瓶，使瓶中的水流不下来。为什么？因为有布施的人，却没有福田。”

这时，魔王对净居天说：“这些婆罗门都是出家持戒、清净入道的，为什么说没有福田？”净居天说：“这位菩萨是为了佛道而布施，现在这些人都是邪见之人，所以我说没有福田。”魔王对净居天说：“怎么知道这个人是为了佛道而布施？”

这时，净居天化作婆罗门身，拿着金瓶，执着金杖，来到韦罗摩菩萨处，说：“你作大布施，难舍能舍，想求什么？想作转轮圣王，有七宝、千子，统治四天下吗？”菩萨回答：“不求这件事！”“你想求作释提婆那民，作八千那由他天女之主吗？”回答说：“不！”“你想求作六欲天主吗？”回答说：“不！”“你想求作梵天王，主宰三千大千世界，作众生的祖父吗？”回答说：“不！”“你想求什么？”这时，菩萨说了这首偈：

```
我求无欲处，　离生老病死，
欲度诸众生，　求如是佛道！
```

大意：我求的是无欲之处，离开生老病死；想要度化一切众生，求这样的佛道！

化作的婆罗门说：“布施主！佛道难以得到，要受极大的辛苦；你心性柔软，习惯于安乐，必定不能求成这条道。如我先前所说的转轮圣王、释提婆那民、六欲天王、梵天王，这些都容易得到，不如求这些！”菩萨回答：你听我一心立下的誓言：

```
假令热铁轮，　在我头上转，
一心求佛道，　终不怀悔恨！
若使三恶道，　人中无量苦，
一心求佛道，　终不为此转！
```

大意：即使有烧热的铁轮在我头上旋转，我一心求佛道，终究不会心怀悔恨！即使有三恶道与人间无量的苦，我一心求佛道，终究不会因此而退转！

化作的婆罗门说：“布施主！善哉！善哉！求佛就应当这样。”便以偈赞叹：

```
汝精进力大，　慈愍于一切，
智慧无罣碍，　成佛在不久！
```

大意：你的精进之力强大，慈悯一切众生，智慧没有障碍，成佛已经不远了！

这时，天上降下众花，供养菩萨。那些封闭瓶水的净居天，随即隐没不见。

菩萨这时来到婆罗门上座前，用金瓶倒水，水被封住，流不下来。众人疑惑惊怪：“这种种大布施，一切都已具足，布施主的功德也很大，现在为什么瓶中的水流不下来？”菩萨自己心想：“这不是别的事，莫非是我的心不清净？还是所施之物不具足？为什么会这样？”自己检视祭祀经中的十六种书，清净无瑕。这时，诸天对菩萨说：“你不要疑悔！你没有什么没办好的！是这些婆罗门邪恶不清净的缘故。”随即说偈：

```
是人邪见网，　烦恼破正智，
离诸清净戒，　唐苦堕异道！
```

大意：这些人陷在邪见之网中，烦恼破坏了正确的智慧，远离种种清净的戒律，白白受苦，堕入外道！

所以水被封住流不下来。说完这话，诸天忽然不见了。那时，六欲天放出种种光明，照耀整个法会，对菩萨说偈：

```
邪恶海中行，　不顺汝正道；
诸受施人中，　无有如汝者！
```

大意：这些人在邪恶之海中行走，不随顺你的正道；在所有受施的人中，没有一个比得上你！

说完这话，诸天忽然不见了。这时，菩萨听了这首偈，自己心想：“法会中确实没有与我相等的人，水被封住流不下来，大概就是因为这个吧？”随即说偈：

```
若有十方天地中，　诸有好人清净者，
我今归命稽首礼！　右手执瓶灌左手，
而自立愿我一人，　应受如是大布施！
```

大意：如果十方天地之中有种种好人、清净的人，我现在归命稽首礼敬！我右手执瓶，灌在左手上，自己立愿：唯有我一人，应当受这样的大布施！

这时，瓶中的水涌到虚空中，从上面流下来，灌在菩萨的左手上。这时，婆萨婆王见到这感应，心生恭敬，说偈：

```
大婆罗门主，　清琉璃色水，
从上流注下，　来堕汝手中！
```

大意：大婆罗门主啊，清澈如琉璃色的水，从上方流注而下，落在你的手中！

这时，大婆罗门众生起恭敬之心，合掌作礼，归命菩萨。菩萨这时说了这首偈：

```
今我所布施，　不求三界福；
为诸众生故，　以用求佛道！
```

大意：我现在所作的布施，不求三界中的福报；为了一切众生，用来求佛道！

说完这首偈，一切大地、山川、树木都六次震动。韦罗摩本来认为这些大众应当受供养，所以施与；既然知道这些大众没有堪受的，现在是因为怜悯，把所备之物施与他们。

像这样种种布施的本生因缘，这里应当广说。这是外布施。

### 八、内布施：剜身燃灯、鸽身投火

什么名为内布施？不吝惜身命，布施给众生。

如本生因缘中说：释迦文佛本来作菩萨时，作一位大国王，那时世间没有佛、没有法、没有比丘僧，这位国王四处寻求佛法，始终得不到。这时有一位婆罗门说：“我知道佛的偈，如果供养我，就给你。”国王随即问他：“要什么样的供养？”婆罗门回答：“你能在自己身上割破肌肉作灯芯来供养我，就给你。”国王心想：“我这身体危脆不净，世世受苦，不可计数，从来没有为法而用，现在才第一次用得上，一点也不吝惜！”这样想完，叫来旃陀罗，遍割身上的肉作灯芯，用白毡缠住肉，以酥油浇灌，同时遍身点燃，全身都燃烧起来，婆罗门这才给了他一首偈。

又，释迦文佛本来作一只鸽子，在雪山中。当时下大雪，有一个人迷了路，困厄辛苦，饥寒交迫，生命危在旦夕。鸽子看见这个人，就飞去寻找火种，为他聚集柴薪点燃；又自己投身火中，布施给这个饥饿的人。

像这样以头、目、髓、脑布施众生的种种本生因缘经，这里应当广说。像这样等等种种，名为内布施。

像这样内外布施无量，这名为檀相。

## 释初品中檀波罗蜜法施义第二十

### 一、什么是法施

问：什么名为法布施？

答：有人说：常以好的言语，有所利益，这是法施。

再者，有人说：以诸佛所说的妙善之法，为人演说，这是法施。

再者，有人说：以三种法教人：一是修妒路，二是毗尼，三是阿毗昙，这是法施。

再者，有人说：以四种法藏教人：一是修妒路藏，二是毗尼藏，三是阿毗昙藏，四是杂藏，这是法施。

再者，有人说：简略地说，以两种法教人：一是声闻法，二是摩诃衍法，这是法施。

问：如提婆达多、呵多等人，也以三藏、四藏、声闻法、摩诃衍法教人，自身却堕入地狱，这是怎么回事？

答：提婆达多邪见之罪多，呵多妄语之罪多，不是为了道而作清净的法施，只是求名利、恭敬与供养。因为恶心之罪，提婆达多活着就堕入地狱，呵多死后堕入恶道。

再者，不只是言说就名为法施；常以清净之心与善思来教导一切众生，这名为法施。譬如财施，不以善心，就不名为福德；法施也是这样，不以清净之心与善思，就不是法施。

再者，说法的人能以清净之心与善思，赞叹三宝，开示罪福之门，显示四真谛，教化众生，使众生进入佛道，这是真正清净的法施。

再者，简略地说，法有两种：一是不恼害众生，以善心慈悯，这是佛道的因缘；二是观察了知诸法真空，这是涅槃道的因缘。在大众中生起慈悯哀怜之心，宣说这两种法，不是为了名闻、利养与恭敬，这是清净的佛道法施。

### 二、口出妙香的说法比丘

如经中说：阿输伽王一天之中建造八万座佛塔，虽然还没有见道，对佛法却稍有信乐，每天请诸比丘入宫供养，每天依次留下一位法师说法。

有一位通晓三藏的年少法师，聪明端正，按次序轮到他说法，坐在国王身边，口中有奇异的香气；国王非常疑怪，以为他不端正，想用香气来打动王宫中的人，对比丘说：“你口中是什么？张开口给我看看。”比丘随即张开口，口中什么也没有；给他水漱口，香气依然如故。国王问：“大德！这香气是新近才有的，还是以前就有？”比丘回答：“像这样很久就有了，不是现在才有。”又问：“有这香气多久了？”比丘以偈回答：

```
迦叶佛时，　集此香法，　如是久久，
常若新出。
```

大意：在迦叶佛时，积集了这香气之法，像这样经过很久很久，常常如同新出的一样。

国王说：“大德！说得太简略，我不理解，请为我详细演说！”比丘回答：“请国王一心好好听我说：我从前在迦叶佛的法中作说法比丘，常在大众之中欢喜演说迦叶世尊的无量功德、诸法实相、无量法门，殷勤赞叹，教诲一切众生；从那以后，常有妙香从口中出来，世世不断，常如今日一样。”并说了这首偈：

```
草木诸华香，　此香气超绝，
能悦一切心，　世世常不灭。
```

大意：比起草木种种花的香气，这香气超绝无比，能使一切人心中喜悦，世世常存不灭。

这时国王惭愧与欢喜交集，对比丘说：“真是未曾有！说法的功德，大果竟然如此！”比丘说：“这只名为花，还不是果。”国王说：“那果是怎样的？愿为我演说！”比丘回答：“果简略地说有十种，请国王仔细听！”随即说偈：

```
大名闻端政，　得乐及恭敬，
威光如日月，　为一切所爱，
辩才有大智，　能尽一切结，
苦灭得涅槃，　如是名为十。
```

大意：大名声、端正、得乐、受恭敬、威光如同日月、为一切人所爱、有辩才、有大智慧、能断尽一切结使、苦灭而得涅槃，这名为十种果。

国王说：“大德！赞叹佛的功德，怎能得到这样的果报？”那时，比丘以偈回答：

```
赞佛诸功德，　令一切普闻，
以此果报故，　而得大名誉。
赞佛实功德，　令一切欢喜，
以此功德故，　世世常端正。
为人说罪福，　令得安乐所，
以此之功德，　受乐常欢豫。
赞佛功德力，　令一切心伏，
以此功德故，　常获恭敬报。
显现说法灯，　照悟诸众生，
以此之功德，　威光如日曜。
种种赞佛德，　能悦于一切，
以此功德故，　常为人所爱。
巧言赞佛德，　无量无穷已，
以此功德故，　辩才不可尽。
赞佛诸妙法，　一切无过者，
以此功德故，　大智慧清净。
赞佛功德时，　令人烦恼薄，
以此功德故，　结尽诸垢灭。
二种结尽故，　涅槃身已证，
譬如澍大雨，　火尽无余热。
```

大意：赞叹佛的种种功德，使一切人普遍听闻，以这果报，得到大名誉。赞叹佛真实的功德，使一切人欢喜，以这功德，世世常端正。为人宣说罪福，使人得到安乐之处，以这功德，享受快乐，常常欢悦。赞叹佛的功德力，使一切人心悦诚服，以这功德，常获得恭敬的果报。显现说法的明灯，照亮并觉悟一切众生，以这功德，威光如同太阳照耀。以种种方式赞叹佛德，能使一切人喜悦，以这功德，常为人所爱。以巧妙的言辞赞叹佛德，无量无穷，以这功德，辩才不可穷尽。赞叹佛的种种妙法，一切都不能超过，以这功德，大智慧清净。赞叹佛的功德时，使人的烦恼变薄，以这功德，结使断尽，种种污垢灭除。因为两种结使都已断尽，已经证得涅槃之身，譬如降下大雨，火被浇灭，没有残余的热。

比丘又告诉国王：“如果还有不明白的，现在正是发问的时候，我当以智慧之箭破除你的疑惑之军。”国王对法师说：“我心中喜悦开悟，没有什么疑惑了。大德是有福之人，善于赞叹佛。”

像这样等等种种因缘，说法度人，名为法施。

### 三、财施与法施何者为胜

问：财施与法施，哪一种更殊胜？

答：如佛所说：“两种布施之中，法施更为殊胜。”为什么？

财施的果报在欲界中；法施的果报，或者在三界中，或者出离三界。再者，口中所说清净，深得正理，心中也得到正理，所以能出离三界。

再者，财施有限量，法施无限量。财施有穷尽，法施无穷尽；譬如以柴薪添火，火光越来越亮。

再者，财施的果报，清净少而污垢多；法施的果报，污垢少而清净多。

再者，如果作大的财施，必定要依靠众人之力；法施出自心中，不依靠他人。

再者，财施能使四大与诸根增长；法施能使无漏的根、力、觉、道具足。

再者，财施之法，有佛无佛，世间常有；法施，唯有佛出世时才会有。

所以应当知道法施非常难。怎么难？乃至有相的辟支佛也不能说法，只是乞食，以飞腾变化来度人。

再者，从法施中能出生财施，以及诸声闻、辟支佛、菩萨与佛。

再者，法施能分别诸法：有漏法、无漏法，色法、无色法，有为法、无为法，善、不善、无记法，常法、无常法，有法、无法。一切诸法实相清净，不可破、不可坏。像这样等等法，简略地说是八万四千法藏，广泛地说则无量。像这样等等种种，都是从法施中分别了知的。所以法施更为殊胜。

这两种布施和合，名为布施之行。

以这两种布施发愿求作佛，就能使人到达佛道，何况其余的果报！

### 四、四种舍何以只说二种

问：四种舍名为檀，就是财舍、法舍、无畏舍、烦恼舍。这里为什么不说另外两种舍？

答：无畏舍与尸罗（持戒）没有区别，所以不说；因为有般若，所以不说烦恼舍。如果不说六波罗蜜，就应当具足地说这四种舍。

## 本卷要义

本卷是全论释经正文的真正开端：佛的神变铺陈完毕，第一句经文“佛告舍利弗”终于出现。龙树先为舍利弗立传，八岁登座、阿说示一偈得初道、半月后证阿罗汉，然后立刻点出舍利弗的局限：佛影覆鸽则鸽安，舍利弗影覆则鸽怖，因为三毒习气未尽；入宿命智、愿智三昧，前后只见到八万大劫，过此即不能知。舍利弗当下忏悔：“我于一鸟尚不能知其本末，何况诸法？”经中以智慧第一的声闻作为当机，正是要在声闻智慧的尽头，显出般若的所在。须菩提观无常而入空，佛说他“最初礼我”，这一则也说明，见佛法身靠的是观诸法空，不是先到佛前礼拜生身。

“以一切种知一切法”一段，龙树列出了声闻的种种观行与阿毗昙的种种法数：八种观、十六行相、安般十六行、二法乃至六法摄一切法。随即面对“一人何能尽知”的问难，给出两个回答：菩萨为一切众生求智慧，正如医生要治一切病就需一切药；以理求法则无不可得，如钻木得火，析薪则不得。更紧要的是“欲量虚空，非不能量，虚空无法故不可量”，这一句已把“知一切法”引向般若的方向：所谓尽知，不是遍历无穷的对象，而是看清一切法本无可量的实体。

檀波罗蜜品开头的经文是全论第一次正面说六度：“以不住法住般若波罗蜜中，以无所舍法具足檀波罗蜜，施者、受者及财物不可得故。”龙树先罗列诸家对般若的定义，有漏、无漏、有为、无为各执一端，再以“末后答者为实”收束：般若“有亦无，无亦无，非有非无亦无，如是言说亦无”，能破一切戏论，“亦不有所破”。不住法住，就是住在般若中而连般若之相也不取；菩萨正因为不取，才能以本愿与精进的力量，在知诸法不生不灭的同时广行功德，具足六度。

赞檀、檀相、法施三品看似是布施的百科全书，实际有一条清楚的主线：布施从世间福业一步步被提升为趣向涅槃之道。净施能使悭、嫉、谄、掉、悔等十余种烦恼变薄，生起相似八正道，乃至成为三十二相的因缘；世间檀与出世间檀的分界在于“三碍”，“我无定处，此以为我、彼以为非”，财物如绢布除丝缕则无，心无三碍才是出世间檀。韦罗摩大施一段，十二年所备的象马金钵美女，最终因受者邪见而瓶水不下，只能自灌左手；画师千那十二年所得三十两金一日施尽，大官却说“谷子未种，牙已得生”。龙树借这两个故事说明，布施的分量不在财物的多少，而在施者的心与福田的清净。最后法施胜财施的诸条理由，归于一点：财施有佛无佛常有，法施唯佛世乃有；一切诸法实相的分别了知，都从法施中来。
