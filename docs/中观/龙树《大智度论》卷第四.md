# 龙树《大智度论》卷第四

龙树菩萨造　后秦龟兹国三藏法师鸠摩罗什奉诏译

## 初品中菩萨释论第八

【经】

复有菩萨摩诃萨。

【论】

问：如果从上往下排列，应当先说菩萨，再依次说比丘、比丘尼、优婆塞、优婆夷，因为菩萨仅次于佛；如果从下往上排列，应当先说优婆夷，再依次说优婆塞、比丘尼、比丘、菩萨。现在为什么先说比丘，再说其余三众，最后才说菩萨？

答：菩萨虽然应当次于佛，因为诸烦恼还没有断尽，所以先说阿罗汉。诸阿罗汉智慧虽少，却已经成熟；诸菩萨智慧虽多，烦恼却没有断尽，所以先说阿罗汉。

佛法有两种：一是秘密，二是现示。

在现示的佛法中，佛、辟支佛、阿罗汉都是福田，因为烦恼已经断尽无余。

在秘密的佛法中，说诸菩萨证得无生法忍，烦恼已断，具足六神通，利益众生。

因为依现示之法，所以先说阿罗汉，后说菩萨。

【译注】“秘密”与“现示”是本论判教的一对要语：依现示（显露）的教法，只有烦恼断尽的佛、辟支佛、阿罗汉是福田，菩萨烦恼未尽，排在后面；依秘密的教法，得无生法忍的菩萨烦恼已断，具六神通，实际上超过声闻。经文排列依现示，菩萨的实际地位依秘密，两者并不矛盾。

再者，菩萨以方便力，示现进入五道，享受五欲，引导众生；如果把菩萨排在阿罗汉之上，诸天与世人会生起疑惑，所以放在后面说。

问：放在阿罗汉之后可以理解，为什么还放在优婆塞、优婆夷之后？

答：四众虽然诸漏还没有断尽，不久就会断尽，所以通称为声闻众。

如果在四众中间说菩萨，就不方便。比如比丘尼得到无量律仪，本应排在比丘之后、沙弥之前；佛因为仪轨上不方便，把比丘尼排在沙弥之后。这些菩萨也是这样，虽然应当排在有学的三众之上，因为不方便，所以放在后面说。

再者，有人说：“菩萨的功德与智慧超过阿罗汉、辟支佛，所以另外单独说。”

问：声闻经中只说四众，这里为什么另外说菩萨众？

答：有两种道：一是声闻道，二是菩提萨埵道。

比丘、比丘尼、优婆塞、优婆夷四众，是声闻道；菩萨摩诃萨，是菩提萨埵道。

所以，在声闻法中，经的开头没有说佛在某处某处住，与多少菩萨在一起；只说佛在某处某处住，与多少比丘在一起。如说：“佛在波罗奈，与五比丘在一起；佛在伽耶国中，与一千比丘在一起；佛在舍婆提，与五百比丘在一起。”像这样种种经的开头，都不说与多少菩萨在一起。

问：菩萨有两种：出家的和在家的。在家菩萨，总括在优婆塞、优婆夷之中；出家菩萨，总括在比丘、比丘尼之中。现在为什么另外说？

答：菩萨虽然总括在四众之中，应当另外说。为什么？菩萨必定落在四众之中，而四众却有不落在菩萨之中的。

是哪些人？有声闻人、辟支佛人、求生天的人、求安乐活命的人，这四种人不落在菩萨之中。为什么？因为这些人没有发心说：“我当作佛。”

再者，菩萨证得无生法忍，一切名字与生死之相都已断除，出离三界，不落在众生之数中。为什么？声闻人证得阿罗汉道，灭度之后，尚且不落在众生之数中，何况菩萨？

如《波罗延经》中优波尸所问的偈说：

```
已灭无处更出不？　若已永灭不出不？
既入涅槃常住不？　惟愿大智说其实！
```

大意：已经灭度的人，没有一处再出现吗？如果已经永远寂灭，就不再出现了吗？既然入了涅槃，是常住吗？唯愿大智者说出其中的真实！

佛回答说：

```
灭者即是不可量，　破坏因缘及名相，
一切言语道已过，　一时都尽如火灭。
```

大意：灭度的人就是不可测量的，已破除因缘与名相，已超越一切言语之道，一时全都穷尽，如同火灭。

阿罗汉尚且断除了一切名字，何况菩萨能破除一切诸法，知道实相，证得法身，而不断除名字吗？

所以，在摩诃衍中，于四众之外另说菩萨。

问：为什么大乘经的开头，菩萨众与声闻众两种都说；声闻经的开头只说比丘众，不说菩萨众？

答：为了辨明两种乘的意义：佛乘与声闻乘。声闻乘狭小，佛乘广大；声闻乘自利、为自己，佛乘利益一切。

再者，声闻乘多说众生空，佛乘说众生空与法空。

像这样种种分别说明这两种道，所以摩诃衍经中，声闻众、菩萨众两种都说。如赞摩诃衍的偈中说：

```
得此大乘人，　能与一切乐，
利益以实法，　令得无上道！
得此大乘人，　慈悲一切故，
头目以布施，　舍之如草木！
得此大乘人，　护持清净戒，
如牦牛爱尾，　不惜身寿命！
得此大乘人，　能得无上忍，
若有割截身，　视之如断草！
得此大乘人，　精进无厌惓，
力行不休息，　如抒大海者！
得此大乘人，　广修无量定，
神通圣道力，　清净得自在！
得此大乘人，　分别诸法相，
无坏实智慧，　是中已具得！
不可思议智，　无量悲心力，
不入二法中，　等观一切法。
驴马驼象乘，　虽同不相比；
菩萨及声闻，　大小亦如是。
大慈悲为轴，　智慧为两轮，
精进为驶马，　戒定以为衔，
忍辱心为铠，　总持为辔勒，
摩诃衍人乘，　能度于一切！
```

大意：得到这大乘的人，能给予一切众生安乐，以真实之法利益众生，使众生得到无上道！得到这大乘的人，因为慈悲一切，以头目布施，舍弃得如同草木！得到这大乘的人，护持清净戒，如同牦牛爱惜尾巴，不惜身体寿命！得到这大乘的人，能得无上的忍，如果有人割截身体，看待如同割断青草！得到这大乘的人，精进不知厌倦，努力修行不休息，如同要舀干大海的人！得到这大乘的人，广修无量禅定，神通与圣道之力清净而自在！得到这大乘的人，分别诸法之相，不可破坏的真实智慧，在这里已经具足！具有不可思议的智慧、无量的悲心之力，不落入二法之中，平等观照一切法。驴、马、骆驼、大象所拉的车乘，虽然同是车乘，却不可相比；菩萨与声闻的大小，也是这样。以大慈悲为车轴，以智慧为两个车轮，以精进为快马，以戒定为马衔，以忍辱心为铠甲，以总持为缰绳，摩诃衍人所乘的车，能度一切众生！

问：如同声闻经开头只说比丘众，摩诃衍经的开头为什么不只说菩萨众？

答：摩诃衍广大，一切乘、一切道都可以纳入摩诃衍；声闻乘狭小，容纳不下摩诃衍。譬如恒河容纳不下大海，因为恒河狭小；大海能容纳一切河流，因为大海广大。摩诃衍之法也是这样。如偈中说：

```
摩诃衍如海，　小乘牛迹水；
小故不受大，　其喻亦如是。
```

大意：摩诃衍如同大海，小乘如同牛蹄印中的积水；因为小，所以容纳不下大，这个譬喻正是如此。

问：什么叫“菩提”？什么叫“萨埵”？

答：“菩提”是诸佛之道；“萨埵”或者指众生，或者指大心。这个人想要得到诸佛之道的一切功德，心不可断、不可破，如同金刚山，这名为大心。如偈中说：

```
一切诸佛法，　智慧及戒定，
能利益一切，　是名为菩提。
其心不可动，　能忍成道事，
不断亦不破，　是心名萨埵。
```

大意：一切诸佛之法，智慧与戒定，能利益一切众生，这名为菩提。这颗心不可动摇，能忍受成就佛道的种种事，不断也不破，这颗心名为萨埵。

再者，称赞好法名为“萨”，好法的体相名为“埵”。菩萨的心自利利他，度化一切众生，知道一切法的实性，行阿耨多罗三藐三菩提之道，为一切贤圣所称赞，这名为“菩提萨埵”。为什么？在一切诸法中，佛法第一；这个人想要取得这佛法，所以为贤圣所赞叹。

再者，这样的人为了使一切众生脱离“生”“老”“死”，所以寻求佛道，这名为“菩提萨埵”。

再者，三种道都是菩提：一是佛道，二是声闻道，三是辟支佛道。辟支佛道、声闻道虽然也得到菩提，却不称为菩提；佛功德中的菩提，才称为“菩提”。这名为“菩提萨埵”。

问：到什么程度，才名为“菩提萨埵”？

答：有大誓愿，心不可动摇，精进不退，具足这三件事，名为“菩提萨埵”。

再者，有人说：“初发心立愿：‘我当作佛，度一切众生。’从那时起，就名为‘菩提萨埵’。如偈中说：

```
若初发心时，　誓愿当作佛，
已过诸世间，　应受世供养。
```

“大意：在初发心时，立誓愿当作佛，这个人已经超过一切世间，应当受世间的供养。

“从初发心，到第九无碍道，进入金刚三昧，这中间名为菩提萨埵。”

菩提萨埵有两种：有“鞞跋致”（退转），有“阿鞞跋致”（不退转），如同退法阿罗汉与不退法阿罗汉。阿鞞跋致菩提萨埵，名为真实菩萨；因为有真实菩萨，其余退转的菩萨也都名为菩萨。譬如证得四道果的人名为真实僧；因为有真实僧，其余未得道的人也都可以名为僧。

问：怎样知道菩萨是鞞跋致还是阿鞞跋致？

答：《般若波罗蜜经·阿鞞跋致品》中，佛亲自说了阿鞞跋致的相：这样的相是退转，这样的相是不退转。

再者，如果菩萨对一种法好好修习、好好忆念，这名为阿鞞跋致菩萨。哪一种法？常一心积集诸善法。如经中说：“诸佛因为一心积集诸善法，所以证得阿耨多罗三藐三菩提。”

再者，有菩萨得到一种法，就是阿鞞跋致的相。哪一种法？正直的精进。如佛问阿难：“阿难！你说精进吗？”“是的，世尊！”“阿难！你赞叹精进吗？”“是的，善逝！”“阿难！常行、常修、常念精进，乃至能使人证得阿耨多罗三藐三菩提。”如经中广说。

再者，如果得到两种法，这时就是阿鞞跋致的相。哪两种法？如实知道一切法空，同时又忆念、不舍弃一切众生。这样的人名为阿鞞跋致菩萨。

再者，得到三种法：一是一心发愿想成就佛道，如同金刚，不可动、不可破；二是对一切众生的悲心，彻骨入髓；三是得到般舟三昧，能见到现在诸佛。这时名为阿鞞跋致。

再者，阿毗昙中，迦旃延尼子的弟子们说：

“什么叫菩萨？自己觉悟，又能使他人觉悟，这名为菩萨。”

“必定当作佛，这名为菩萨。”

“菩提是漏尽之人的智慧；这个人从智慧中生，为有智慧的人所护持，为有智慧的人所养育，所以名为菩萨。”

又说：“发了阿鞞跋致之心，从此以后名为菩萨。”

又说：“如果离开五种法，得到五种法，这名为菩萨。哪五种法？

“离开三恶道，常生在天上、人间；离开贫穷下贱，常得尊贵；离开非男之身，常得男子之身；离开种种形体残缺丑陋，诸根具足；离开舍弃与喜忘，常忆宿命，得到宿命智慧，常远离一切恶法，远离恶人，常求道法，摄受弟子。

“这样名为菩萨。”

又说：“从种下三十二相之业开始，名为菩萨。”

问：什么时候种三十二相之业的因缘？

答：过了三阿僧祇劫之后，才种三十二相之业的因缘。

问：多长时间名为“阿僧祇”？

答：天上、人间能懂算数的人，算到极数之后再也不能知道，这名为一阿僧祇。比如：

一乘一名为二，二乘二名为四，三乘三名为九，十个十名为百，十个百名为千，十个千名为万，千万名为亿，千万亿名为那由他，千万那由他名为频婆，千万频婆名为迦他，超过迦他名为阿僧祇。

这样数三阿僧祇：如果行满一阿僧祇，就行第二阿僧祇；第二阿僧祇满了，就行第三阿僧祇。譬如算数之法，从一算到百，百算完了，又回到一。菩萨也是这样，一阿僧祇过了，又从一开始。

在第一阿僧祇中，心里自己不知道我会不会作佛；在第二阿僧祇中，心里虽然知道我必定作佛，口中却不说我当作佛；在第三阿僧祇中，心里了了分明地自知能作佛，口中自己说出，无所畏难：“我在来世当作佛。”

释迦文佛从过去的释迦文佛，到剌那尸弃佛，为第一阿僧祇；在这期间，菩萨永远离开了女人之身。

从剌那尸弃佛到燃灯佛，为第二阿僧祇；在这期间，菩萨以七枝青莲花供养燃灯佛，铺下鹿皮衣，散开头发遮盖泥地，这时燃灯佛就为菩萨授记：“你在来世当作佛，名叫释迦牟尼。”

从燃灯佛到毗婆尸佛，为第三阿僧祇。

过了三阿僧祇劫，这时菩萨种三十二相之业的因缘。

问：三十二相之业，在什么地方可以种？

答：在欲界中种，不在色界、无色界；在欲界五道中，在人道中种；在四天下中，在阎浮提中种；以男子之身种，不以女人之身；在佛出世时种，佛不出世时不能种；缘佛身而种，缘其余的不能种。

问：这三十二相之业的因缘，在身业、口业、意业中，以哪一种业来种？

答：以意业种，不以身业、口业。为什么？因为意业锐利。

问：意业有六识，这三十二相之业，是以意识种，还是以前五识种？

答：以意识种，不以前五识。为什么？前五识不能分别，所以以意识种。

问：最先种哪一种相？

答：有人说：“最先种足下安立相。为什么？先要立稳，然后才能种其余的相。”

有人说：“最先种绀青眼相，得到这眼相，以大慈观察众生。”

这两种说法虽然有人这样说，却不一定如此。哪一种相的因缘和合了，就是最先种的，何必一定以足安立相为最先。

问：是以一个思种一相，还是以多个思种一相？

答：以三十二个思种三十二相，一个思种一个相，每一个相以一百福德来庄严。

问：多少名为一福德？

答：有人说：“有业报能作转轮圣王，在四天下享受福乐、得到自在，这名为一福德。这样一百个福德成就一相。”

又有人说：“作释提桓因，在两层天中得到自在，这名为一福德。”

又有人说：“作他化自在天王，在欲界中得到自在，这名为一福。”

又有人说：“除了补处菩萨，其余一切众生所得的福报，这名为一福。”

又有人说：“天地劫尽之后，因为一切众生共同的福德，三千大千世界作为果报而成立，这名为一福。”

又有人说：“这福德不可量，不能用譬喻知道。比如三千大千世界一切众生都是瞎子，没有眼睛，有一个人能医治使之痊愈，这是一福。一切人都中了毒药，一个人能医治使之痊愈；一切人都应当死，一个人能救他们脱离；一切人都破戒、破正见，一个人能教他们得到清净的戒与正见；像这样等等是一福。”

又有人说：“这福德不可量，不能用譬喻知道。这位菩萨进入第三阿僧祇中，以心思大行种这三十二相的因缘。所以，这福德没有人能量，唯有佛能知道。”

问：菩萨要多长时间才能种完三十二相？

答：最慢一百劫，最快九十一劫。释迦牟尼菩萨用九十一大劫修成三十二相。

如经中说：“过去久远之时，有佛名叫弗沙。当时有两位菩萨：一名释迦牟尼，一名弥勒。弗沙佛想观察释迦牟尼菩萨的心是否已经纯熟，随即观察，知道释迦牟尼菩萨的心还没有纯熟，而弟子们的心都已纯熟。又观察到弥勒菩萨的心已经纯熟，而弟子们还没有纯熟。这时，弗沙佛这样思惟：‘一个人的心容易迅速转化，众人的心难以迅速调治。’这样思惟完毕，弗沙佛想让释迦牟尼菩萨迅速成佛，就登上雪山，在宝窟中入火定。这时，释迦牟尼菩萨作外道仙人，上山采药，看见弗沙佛坐在宝窟中，入于火定，放出光明。见到之后，心中欢喜信敬，翘起一只脚站立，叉手向佛，一心观看，眼睛不曾眨动，七日七夜，以一首偈赞佛：

```
天上天下无如佛，　十方世界亦无比，
世界所有我尽见，　一切无有如佛者！
```

“大意：天上天下没有像佛一样的，十方世界也没有能与佛相比的；世界上所有的一切我都见过了，一切之中没有像佛一样的！

“七日七夜谛观世尊，眼睛不曾眨动，因此超越了九劫，在九十一劫中证得阿耨多罗三藐三菩提。”

问：如果释迦牟尼菩萨聪明多识，能作种种好偈，为什么七日七夜只以一首偈赞佛？

答：释迦牟尼菩萨看重的是心思，不看重言辞多少。如果再用其他偈赞佛，心或许会散乱，所以七日七夜只以一首偈赞佛。

问：释迦牟尼菩萨为什么自心没有纯熟而弟子纯熟？弥勒菩萨为什么自心纯熟而弟子没有纯熟？

答：释迦牟尼菩萨饶益众生的心多，为自己的心少；弥勒菩萨为自己的多，为众生的少。

从毗婆尸佛到迦叶佛，其间九十一大劫，种三十二相之业的因缘积集完毕，六波罗蜜圆满。哪六种？檀波罗蜜、尸罗波罗蜜、羼提波罗蜜、毗梨耶波罗蜜、禅波罗蜜、般若波罗蜜。

问：檀波罗蜜怎样圆满？

答：一切都能布施，没有任何障碍，乃至以身布施时，心中也毫无吝惜。譬如尸毗王以身布施救鸽。释迦牟尼佛前身作国王，名叫尸毗。这位国王得到归命救护陀罗尼，大精进，有慈悲心，看待一切众生如同母亲爱护孩子。当时世间无佛，释提桓因寿命将尽，即将堕落。

释提桓因自己心想：“哪里有佛、有一切智人？”到处去问难，都不能断除疑惑，知道这些人全都不是佛，就回到天上，忧愁地坐着。

巧于变化的工匠毗首羯磨天问：“天主为什么忧愁？”

释提桓因回答：“我寻求一切智人而找不到，所以忧愁。”

毗首羯磨说：“有一位大菩萨，布施、持戒、禅定、智慧都已具足，不久就会作佛。”

帝释以偈回答：

```
菩萨发大心，　鱼子庵树华，
三事因时多，　成果时甚少！
```

大意：菩萨发大心，鱼产卵，庵摩罗树开花，这三件事在作因时很多，到成果时却极少！

毗首羯磨回答：“这位优尸那种族的尸毗王，持戒、精进，大慈、大悲，有禅定、有智慧，不久就会作佛。”

释提桓因对毗首羯磨说：“我们应当去考验一下，看看尸毗王是否有菩萨之相。你变作鸽子，我变作老鹰，你假装惊怖，飞入国王的腋下，我就去追你。”

毗首羯磨说：“这是一位大菩萨，怎么能用这种事去恼害？”

释提桓因说偈：

```
我亦非恶心，　如真金应试；
以此试菩萨，　知其心定不。
```

大意：我也不是出于恶心；如同真金应当经受检验，用这件事来考验菩萨，看菩萨的心是否坚定。

说完这首偈，毗首羯磨随即把自身变作一只红眼红脚的鸽子，释提桓因把自身变作一只老鹰，急速飞去追鸽子。鸽子径直飞入国王的腋下，全身颤抖惊怖，眼珠乱转，叫声急促。

这时，许多人互相说道：

```
是王大慈仁，　一切宜保信，
如是鸽小鸟，　归之如入舍；
菩萨相如是，　作佛必不久。
```

大意：这位国王大慈大仁，一切众生都应当信赖依靠；像鸽子这样的小鸟，投靠国王如同回到自己的家；菩萨之相就是这样，必定不久就会作佛。

这时，老鹰停在附近的树上，对尸毗王说：“把我的鸽子还给我，这是我所得的！”

国王对老鹰说：“是我先得到这只鸽子，不是你得到的；我初发心时就已接受了它，一切众生我都要度化。”

老鹰说：“国王想度化一切众生，我难道不是一切众生之一吗？为什么唯独不怜悯我，夺走我今天的食物？”

国王回答：“你需要什么食物？我曾立誓：‘凡有众生来投靠我，必定救护。’你需要什么食物，我也会供给你。”

老鹰说：“我需要刚杀的热肉。”

国王心想：“这很难得到，除非杀生，否则无从得到！我怎能杀一个去给另一个！”

国王思惟之后心意已定，就自己说偈：

```
是我此身肉，　恒属老病死，
不久当臭烂，　彼须我当与。
```

大意：我这身上的肉，永远属于老、病、死，不久就会腐臭溃烂；老鹰需要，我就应当给予。

国王这样思惟之后，叫人拿刀来，自己割下大腿上的肉给老鹰。

老鹰对国王说：“国王虽然把热肉给我，应当讲道理，让肉的轻重与鸽子相等，不要欺骗我！”

国王说：“拿秤来！”

用肉与鸽子相称，鸽子的身体越来越重，国王的肉越来越轻。国王叫人割下两条大腿的肉，还是轻，不够；接着割下身体两侧（此处原文一字缺损）、两胯、两乳、颈项与脊背的肉，全身的肉都割尽了，鸽子的身体仍然更重，国王的肉仍然更轻。

这时，近臣与内眷张起帐幔，把围观的人挡在外面：“国王现在这个样子，没有什么可看的！”

尸毗王说：“不要遮挡众人，让大家进来看！”并说偈：

```
天人阿修罗，　一切来观我！
大心无上志，　以求成佛道。
若有求佛道，　当忍此大苦；
不能坚固心，　则当息其意。
```

大意：天、人、阿修罗，一切都来看我！我以大心与无上之志，来求成就佛道。如果有人求佛道，应当忍受这样的大苦；不能使心坚固的人，就应当息灭求佛道的念头。

这时，菩萨用沾满鲜血的手攀住秤，想要爬上去，定下心来，要以整个身体去与鸽子相称。

老鹰说：“大王！这件事难以办到，何必这样？把鸽子还给我吧！”

国王说：“鸽子来投靠我，我终究不会给你。我在过去丧失身命无数，对任何人都没有益处；现在想以这个身体换取佛道。”

国王用手攀着秤，那时菩萨肉尽筋断，不能控制自己，想要上去，却跌落下来。

菩萨自己责备自己的心说：“你应当自己坚强，不要迷闷！一切众生都堕在忧苦的大海中，你一个人立誓要度化一切众生，为什么懈怠迷闷！这点苦非常少，地狱的苦多；以这苦与地狱之苦相比，十六分中还不及一分！我现在有智慧、精进、持戒、禅定，尚且以这苦为患，何况地狱中没有智慧的人？”

这时，菩萨一心想要上去，又再攀秤，对人说：“扶我上去！”这时，菩萨心意坚定，毫无悔意。

诸天、龙王、阿修罗、鬼神、人民都大加赞叹说：“为了一只小鸟竟然这样，这件事真是稀有！”

当即大地六种震动，大海波涛翻涌，枯树开花，天上降下香雨，散下名花，天女歌唱赞叹：“必定能成佛！”

这时，四方的神仙都来赞叹说（原文此处有“念我”二字，义不明）：“这是真菩萨，必定早日成佛。”

老鹰对鸽子说：“考验到底，竟这样不惜身命，这是真菩萨！”

随即说偈：

```
慈悲地中生，　一切智树牙，
我曹当供养，　不应施忧恼！
```

大意：从慈悲的大地中，生出一切智之树的嫩芽，我们应当供养，不应当施加忧恼！

毗首羯磨对释提桓因说：“天主！你有神力，可以让这位国王的身体恢复原状。”

释提桓因说：“不需要我。这位国王自己立下誓愿，以大心欢喜，不惜身命，感发一切众生，使众生求佛道。”

帝释对人王说：“你割肉这样辛苦，心中不恼恨、不沉没吗？”

国王说：“我心中欢喜，不恼恨，不沉没。”

帝释说：“谁会相信你的心不沉没呢？”

这时，菩萨立下真实誓愿：“我割肉流血，不瞋不恼，一心不闷，以求佛道；如果这是真的，我的身体应当立即恢复原状。”刚说出这话，身体就恢复如初。

人与天见到这情景，都大为悲喜，赞叹从未有过：“这位大菩萨必定会作佛，我们应当尽心供养。愿您早日成就佛道，那时应当记念我们！”

这时，释提桓因与毗首羯磨各自返回天上。

像这样种种的相，就是檀波罗蜜圆满。

问：尸罗波罗蜜怎样圆满？

答：不惜身命，护持清净戒律，如须陀须摩王，因为劫磨沙波陀大王的缘故，乃至舍弃生命也不违犯禁戒。

从前有一位须陀须摩王，这位国王精进持戒，常依实语。早晨乘车，带着众宫女进入园林游玩。出城门时，有一位婆罗门来乞讨，对国王说：“国王是大福德之人，我身贫穷，请怜悯我，赐给我一些！”

国王说：“好！遵照你的请求，我会布施给你，等我出游回来。”说完这话，就进入园林沐浴嬉戏。

这时，有一位长着两只翅膀的国王，名叫鹿足，从空中飞来，在宫女之中把须陀须摩王捉走，譬如金翅鸟从海中捉走龙。宫女们啼哭，整个园林一片号哭之声；城内城外都受到惊动，骚乱悲惶。鹿足王背着须陀须摩王腾跃虚空，到了自己的住处，把须陀须摩王放在九十九位国王之中。

须陀须摩王泪落如雨，鹿足王对须陀须摩王说：“大刹利王！你为什么像小孩子一样啼哭？人生有死，聚合有离。”

须陀须摩王回答：“我不怕死，非常怕失信。我从出生以来，从来不说妄语。今天早晨出门时，有一位婆罗门来向我乞讨，我当时答应他：‘回来时就布施给你。’没有考虑到无常，辜负了那人的心，自己招来欺骗的罪过，所以啼哭！”

鹿足王说：“你的意思既然是这样，怕说妄语，就放你回去七天，布施婆罗门完毕，就回来。如果过了七天不回来，我有两翅之力，捉你并不难。”

须陀须摩王得以回到本国，随意布施，立太子为王，大会人民，向人民忏悔道歉说：“我的智慧不能周全照顾万物，治国不能如法，请大家宽恕！像我今天这样，身体已经不属于自己，正要回去了。”

全国人民与诸亲属都叩头挽留：“愿大王留意，以慈悲荫护这个国家，不要顾虑鹿足鬼王！我们会建造铁屋，布置奇兵，鹿足即使有神通，也不怕他！”

国王说：“不可以这样！”并说偈：

```
实语第一戒，　实语升天梯，
实语小而大，　妄语入地狱。
我今守实语，　宁弃身寿命，
心无有悔恨。
```

大意：实语是第一戒，实语是升天的阶梯；实语使小人成为大人，妄语使人堕入地狱。我如今守持实语，宁可舍弃身体寿命，心中也没有悔恨。

这样思惟之后，国王随即出发，到了鹿足王处。鹿足王远远看见，欢喜地说：“你是说实话的人，不失信约。一切人都爱惜身命，你从死里逃脱了，还回来践约，你是大人！”

那时，须陀须摩王赞叹实语：“说实话的才是人，不说实话的不是人。”像这样种种赞叹实语，呵斥妄语。鹿足王听了，信心清净，对须陀须摩王说：“你说得好，现在放你走；你既然得以脱身，九十九位国王也一并布施给你，随意各自返回本国。”说完这话，一百位国王各自得以回去。

像这样种种本生中的相，就是尸罗波罗蜜圆满。

问：羼提波罗蜜怎样圆满？

答：如果有人来辱骂、殴打、割剥、肢解、夺命，心中不起瞋恚。如羼提比丘被迦梨王截断手、足、耳、鼻，心坚定不动。

问：毗梨耶波罗蜜怎样圆满？

答：如果有大心与勤力，如同大施菩萨，为了一切众生，以这一个身体，发誓要舀干大海，心意坚定，毫不懈怠。也如同赞叹弗沙佛时，七日七夜翘着一只脚，眼睛不眨。

问：禅波罗蜜怎样圆满？

答：如一切外道在禅定中得到自在。又如尚阇梨仙人坐禅时，没有出入的呼吸，鸟在尚阇梨仙人的螺髻中生下小鸟，尚阇梨仙人不动不摇，直到小鸟飞走。

问：般若波罗蜜怎样圆满？

答：菩萨以大心思惟分别，如劬嫔陀婆罗门大臣，把阎浮提大地分作七份，若干大城、小城、聚落村民，全都分作七份。般若波罗蜜就是这样。

这位菩萨六波罗蜜圆满，在迦叶佛处作弟子，持清净戒，修行功德，生到兜率天上。

问：菩萨为什么生在兜率天上，不生在更高的天，也不生在更低的天？菩萨有大福德，应当可以自在受生。

答：有人说：因为因缘之业成熟，应当生在这里。

再者，下面诸天中结使厚重浑浊，上面诸天中结使锐利；兜率天上结使不厚也不锐利，因为智慧安稳。

再者，菩萨不想错过佛出世的时间。如果生在下面诸天，寿命短，寿终时佛还没有出世；如果生在上面诸天，寿命长，寿命还没有尽，就已经错过了佛出世的时间；兜率天的寿命，与佛出世的时间正好相合。

再者，佛常居中道。兜率天在六欲天与梵天之中，上面三层，下面三层。菩萨从兜率天下生，必定生在中国，于中夜降神入胎，于中夜出离迦毗罗婆国，行于中道而证得阿耨多罗三藐三菩提；以中道为人说法，于中夜入无余涅槃。因为喜好中道之法，所以生在中间的天上。

这样，菩萨生在兜率天上之后，

以四种观察来观察人间：一是观察时间，二是观察国土，三是观察种姓，四是观察出生之处。

怎样观察时间？有八种时期，佛在其中出世：第一，人寿八万四千岁时；第二，人寿七万岁；第三，人寿六万岁；第四，人寿五万岁；第五，人寿四万岁；第六，人寿三万岁；第七，人寿二万岁；第八，人寿一百余岁。菩萨这样想：人寿百岁，佛出世的时间到了。这名为观察时间。

怎样观察国土？诸佛常生在中国，那里多有金银宝物，饮食丰美，国土清净。

怎样观察种姓？佛生在两种种姓中：或者是刹利，或者是婆罗门。因为刹利种势力大，婆罗门种智慧大。随着当时所尊贵的种姓，佛就生在其中。

怎样观察出生之处？什么样的母亲能怀那罗延力的菩萨，又能自己守护清净戒？这样观察完毕，只有中国迦毗罗婆净饭王的王后能怀菩萨。这样思惟之后，从兜率天下降，不失正慧，进入母胎。

问：为什么一切菩萨的最后身都从天上来，不从人间来？

答：因为乘着上道而来，六道之中天道最上。

再者，从天上下降时，有种种瑞应，前所未有；如果从人道来，人道不能有这些瑞应。

再者，因为人们敬重天。

问：一切人都以染垢之心相续进入母胎，与一切邪慧相应，为什么说菩萨以正慧入母胎？

答：有人说：在相续的时候，一切众生都以邪慧之心进入母胎，菩萨忆念不失，所以名为正慧入母胎。

住在中阴时，就知道住在中阴；入胎时，知道入胎；在歌罗罗时，知道住在歌罗罗（受胎第一个七日，父精母血和合之时）；在頞浮陀时，知道住在頞浮陀（第二个七日，形如水泡之时）；在伽那时，知道住在伽那（第三个七日，如凝结的酪之时）；在五疱时，知道住在五疱；出生时，知道出生。在这些阶段中忆念不失，这名为正慧入母胎。

再者，其余的人住在中阴时，如果是男性，就对母亲生起欲染之心：“这女人与我交合。”对父亲生起瞋恚；如果是女性，就对父亲生起欲染之心：“这男人与我交合。”对母亲生起瞋恚。这样的瞋恚心、欲染心，菩萨没有。

菩萨先已了知这是父亲，这是母亲；这父亲、这母亲能长养我的身体，我依靠父母所生之身，证得阿耨多罗三藐三菩提。以这样的清净心忆念父母，相续入胎，这名为正慧入母胎。

这位菩萨住胎满十个月，正慧不失忆念。出胎后，行走七步，开口说：“这是我的最后身。”

后来，净饭王把太子带给相师看：“你看我的儿子真有三十二大人相吗？如果三十二相具足，应当有两种前途：如果在家，就会作转轮圣王；如果出家，就会成佛。”

诸相师说：“地天太子确实有三十二大人相；如果在家，就会作转轮王；如果出家，就会成佛。”

国王说：“是哪三十二相？”

相师回答：

第一，足下安平立相：脚底完全贴地，中间没有空隙，容不下一根针。

第二，足下二轮相：千辐、轮辋、轮毂三者具足，自然成就，不靠人工；诸天的工匠毗首羯磨也不能变化出这样的妙相。

问：为什么不能？

答：这毗首羯磨是诸天的工匠，所具有的不是隐没不显的智慧；这轮相却是善业的果报。

这天上的工匠，所得的是生来就有的果报智慧；这轮相是修行善根的智慧所得。

这毗首羯磨的智慧只是一世所得；这轮相却是从无量劫的智慧所生。

所以，毗首羯磨尚且不能变化出来，何况其余的工匠？

第三，长指相：手指纤长端直，依次匀称美好，指节错落有致。

第四，足跟广平相。

第五，手足指缦网相：如同雁王，张开手指就显现，不张开就不显现。

第六，手足柔软相：如同细软的劫波毳，胜过身体其余部分。

第七，足趺高满相：以脚踏地，不宽不窄。脚底的颜色如同红莲花，脚趾间的网与脚边的颜色如同真珊瑚，趾甲如同纯净的赤铜，脚背上是真金色，脚背上的毛是青色的毗琉璃色。双脚庄严美好，譬如用杂宝装饰的鞋子，种种装饰。

第八，伊泥延膊相：如同伊泥延鹿的小腿，依次匀称而纤细。

第九，正立手摩膝相：身体不俯不仰，站立时手掌能摸到膝盖。

第十，阴藏相：譬如调伏良善的象宝、马宝。

问：如果菩萨证得阿耨多罗三藐三菩提，诸弟子以什么因缘见到阴藏相？

答：为了度化众人、断除众人的疑惑，所以显示阴藏相。

又有人说：佛化作马宝、象宝，指给诸弟子看，说：我的阴藏相也是这样。

第十一，身广长等相：如同尼拘卢陀树，以菩萨身体的中心为准，四边的量都相等。

第十二，毛上向相：身上的毛都向上生长，而且柔细。

第十三，一一孔一毛生相：毛不杂乱，青琉璃色，毛向右旋转而向上。

第十四，金色相。

问：是怎样的金色？

答：如果铁放在金子旁边，铁就显不出光彩；现在的金子与佛在世时的金子相比，现在的金子就显不出光彩；佛在世时的金子与阎浮那金相比，就显不出光彩；阎浮那金与大海中转轮圣王所行道路上的金沙相比，就显不出光彩；金沙与金山相比，就显不出光彩；金山与须弥山相比，就显不出光彩；须弥山的金与三十三天的璎珞金相比，就显不出光彩；三十三天的璎珞金与焰摩天的金相比，就显不出光彩；焰摩天的金与兜率陀天的金相比，就显不出光彩；兜率陀天的金与化自在天的金相比，就显不出光彩；化自在天的金与他化自在天的金相比，就显不出光彩；他化自在天的金与菩萨的身色相比，就显不出光彩。这样的颜色，名为金色相。

第十五，丈光相：四边都有一丈的光明，佛在这光明中端严第一，如同诸天、诸王的宝光明净。

第十六，细薄皮相：尘土不沾身，如同莲花叶不沾尘水。如果菩萨在干燥的土山中经行，土不沾脚；随蓝风刮来，把土山吹破，散为尘土，乃至没有一粒尘土沾在佛身上。

第十七，七处隆满相：两手、两足、两肩、颈项，七处都隆起饱满、端正，颜色洁净，胜过身体其余部分。

第十八，两腋下隆满相：不高也不深。

第十九，上身如狮子相。

第二十，大直身相：在一切人中，身体最大而且端直。

第二十一，肩圆好相：一切修治过的肩膀都比不上。

第二十二，四十齿相：不多不少。其余的人有三十二颗牙齿，全身三百多块骨头，头骨有九块；菩萨有四十颗牙齿，头骨只有一块。菩萨齿骨多，头骨少；其余的人齿骨少，头骨多。所以与其余的人身体不同。

第二十三，齿齐相：诸齿相等，没有粗细，不凸出也不凹进。又有齿密相，不知道的人以为只有一颗牙齿，齿间容不下一根毫毛。

第二十四，牙白相：白得胜过雪山王的光芒。

第二十五，狮子颊相：如同兽中之王狮子那样平广的面颊。

第二十六，味中得上味相。

有人说：佛把食物放入口中，一切食物都成为最上之味。为什么？因为一切食物中都有最上之味的因；没有这个相的人，不能发起这个因，所以得不到最上之味。

又有人说：菩萨把食物放入口中时，咽喉两边有两处流注甘露，调和诸味；因为这味道清净，所以名为味中得上味。

第二十七，大舌相：菩萨的大舌从口中伸出，能覆盖整个面部，直到发际；收回口中，口也不满。

第二十八，梵声相：如同梵天王有五种声音从口中发出：第一，深远如雷；第二，清澈远闻，听者喜悦；第三，入人心中，使人敬爱；第四，明白易懂；第五，听者不厌。菩萨的音声也是这样，五种声音从口中发出。又有迦陵频伽声相，如同迦陵频伽鸟的声音可爱；又有鼓声相，如同大鼓之音深远。

第二十九，真青眼相：如同上好的青莲花。

第三十，牛眼睫相：如同牛王的眼睫毛，长而美好，不乱。

第三十一，顶髻相：菩萨头顶上有骨髻，如同拳头大小。

第三十二，白毛相：白毫生在眉间，不高不低，洁白清净，向右旋转，舒展开来长五尺。

相师说：“地天太子的三十二大人相就是这样，菩萨具足这些相。”

问：转轮圣王有三十二相，菩萨也有三十二相，有什么差别？

答：菩萨的相，有七件事胜过转轮圣王的相。菩萨的相：一是清净美好，二是分明，三是不失其位，四是具足，五是深入，六是随智慧而行、不随世间，七是随顺远离。转轮圣王的相不是这样。

问：为什么名为“相”？

答：因为容易辨识，所以名为“相”；如同水与火不同，凭相就知道。

问：菩萨为什么有三十二相，不多也不少？

答：有人说：“佛以三十二相庄严身体，是为了端正不乱。如果少了，身体就不端正；如果多了，佛身之相就会杂乱；这三十二相端正不乱，不可增加，不可减少。如同佛法不可增、不可减，身相也是这样。”

问：菩萨为什么以相好庄严身体？

答：有人见到佛的身相，心中得到清净信心，所以以相好庄严身体。

再者，诸佛在一切事上都殊胜：身色、威力、种姓、家属、智慧、禅定、解脱，种种事都殊胜；如果佛不庄严身相，这方面就有所欠缺。

再者，有人说：“阿耨多罗三藐三菩提要住在这个身中；如果身相不庄严，阿耨多罗三藐三菩提就不住在这个身中。譬如有人想娶豪门贵族的女子，这女子派使者对那人说：‘如果想娶我，应当先把房间装饰好，除去污秽，涂抹香泥，熏上香气，安置床榻、被褥、坐垫、帷帐、幔幕、幡盖、花香，一定要庄严装饰好，然后我才到你家。’阿耨多罗三藐三菩提也是这样，派智慧作使者，在未来世中来到菩萨处，说：‘如果想得到我，先修相好来庄严自己，然后我才住在你身中；如果不庄严身体，我就不住。’所以，菩萨修三十二相来庄严身体，为的是证得阿耨多罗三藐三菩提。”

这时，菩萨渐渐长大，见到老、病、死之苦，生起厌患之心，半夜出家，苦行六年，吃了难陀婆罗门女所供养的、能增益身体十六种功德的石蜜乳糜。吃完之后，在菩提树下破除一万八千亿鬼兵魔众，证得阿耨多罗三藐三菩提。

问：得到什么功德，所以名为佛？

答：得到尽智、无生智，所以名为佛。

再者，有人说：“得到佛的十力、四无所畏、十八不共法、三达、无碍、三意止（一是受教导、恭敬尊重佛的，佛不因此欢喜；二是不受教导、不恭敬尊重佛的，佛不因此忧愁；三是对恭敬尊重的与不恭敬尊重的，心无差别）、大慈、大悲、三十七道品，一切诸法的总相与别相全都知道，所以名为佛。”

问：为什么未得佛道时名为菩萨，得了佛道就不名为菩萨？

答：未得佛道时，心中爱着追求，想要取得阿耨多罗三藐三菩提，所以名为菩萨；已经成就佛道，又得到佛种种殊胜的大功德，所以另有不同的名字，名为佛。

譬如王子还没有作国王时，名为王子；已经作了国王，就不再叫王子。既然已经是国王，虽然仍是王子，却不称为王子。菩萨也是这样，未得佛道，名为菩萨；已得佛道，名为佛。

在声闻法中，摩诃迦旃延尼子的弟子们，所说的菩萨相的意义就是这样。

摩诃衍人说：这些迦旃延尼子的弟子是生死中人，不诵不读摩诃衍经，不是大菩萨！不知道诸法实相，自恃根性锐利、有智慧，在佛法中作论议；对诸结使、智、定、根等作义理解释，尚且处处有过失，何况想作菩萨的论议？譬如力气小的人，跳小水沟尚且跳不过去，何况大河？到了大河中，就知道会淹没了。

问：有什么过失？

答：如上面说：“过了三阿僧祇劫，才名为菩萨。”在三阿僧祇劫中，菩萨以头、目、髓、脑布施，心中毫无后悔，这是阿罗汉、辟支佛所不能及的。如从前菩萨作大商主，渡大海时，恶风吹坏了船。菩萨对众商人说：“抓住我的头发、手、脚，我会把你们渡过去。”众人抓住之后，菩萨用刀自杀。大海之法不停留死尸，随即疾风把菩萨的尸体连同众人吹到岸边。有这样的大慈，却说不是菩萨，那么谁才是菩萨？

第二阿僧祇劫修行圆满、还没有进入第三阿僧祇劫时，菩萨在燃灯佛处受记为佛，当即上升虚空，见到十方诸佛在虚空中站立，赞叹燃灯佛。燃灯佛说：“你过一阿僧祇劫，当得作佛，名叫释迦牟尼。”得到这样的授记，却说那时还不是菩萨，这难道不是大过失吗！

迦旃延尼子的弟子们说：“三阿僧祇劫中还没有佛的相，也没有种下佛相的因缘，怎能知道是菩萨？一切法都是先有相，然后才可以知道其真实；如果没有相，就不能知道。”

摩诃衍人说：“受记为佛，上升虚空，见到十方诸佛，这难道不是大相吗？被佛授记当得作佛，能作佛，这就是大相；舍弃这大相，却去取三十二相！

“三十二相，转轮圣王也有，诸天魔王也能变化出这些相。难陀、提婆达多等都有三十种相；婆跋隶婆罗门有三种相；摩诃迦叶的妻子有金色相；乃至今世的人也各自有一种相、两种相，或者青眼，或者长臂，或者上身如狮子；像这样种种，或多或少，你为什么看重这些相？

“哪部经中说三阿僧祇劫中菩萨不种相的因缘？如难陀为毗婆尸佛沐浴，发愿得到清净端正；在一座辟支佛塔中，用青黛涂墙，画辟支佛像，并因此发愿：‘愿我恒常得到金色身相。’又建造迦叶佛塔的中层；因为这三种福德因缘，世世享乐，所到之处，恒常端严。这福德的余报，使难陀生在迦毗罗婆释迦族中，作佛弟子，得到三十种大人相，清净端正，出家证得阿罗汉道。佛说在五百弟子中，难陀比丘端正第一。这些相容易得到，为什么说‘在九十一大劫中种，在剩下的一生中得到’？这是大过失！

“你说：‘第一阿僧祇劫中，不知道会不会作佛；第二阿僧祇劫中，知道会作佛，却不自己说出；第三阿僧祇劫中，知道能作佛，能为人说。’

“佛在哪里说过这话？哪部经中有这话？是在声闻法三藏中说的，还是在摩诃衍中说的？”

迦旃延尼子的弟子们说：“虽然佛口所说的三藏中没有说，按义理应当如此！《阿毗昙鞞婆沙·菩萨品》中是这样说的。”

答：摩诃衍中说：“初发心时，就知道我当作佛。”如阿遮罗菩萨在长手佛处初发心时，直到在金刚座上成就佛道，这中间颠倒不净之心不再生起。

如《首楞严三昧经》中说，有四种菩萨、四种授记：有未发心就授记的；有刚发心就授记的；有当面授记，他人都知道而自己不知道的；有当面授记，他人与自己都知道的。你怎么说“在第二阿僧祇劫中，知道受记却不自己说出”？

再者，佛说：“无量阿僧祇劫中作功德，想要度化众生。”为什么说“三阿僧祇劫”？三阿僧祇劫是有量、有限的。

问：摩诃衍中虽然有这些话，我也不能全信。

答：这是大过失！这是佛的真法，佛口所说，你却不能信受！你本是从摩诃衍中出生的，怎么说我不能全信？

再者，摩诃衍的论议，这里应当广说。

再者，你说三十二相之业的因缘，在欲界中种，不在色界、无色界中种。无色界中因为没有身体、没有色，而这三十二相是身体的庄严，所以不能在其中种，还可以说得过去；色界中为什么不能种？色界中有很多梵王，常常劝请佛初转法轮，这些梵王智慧清净，能求佛道，为什么说不能种三十二相的因缘？

又说：“在人道中能种，不在其余诸道。”如娑伽度龙王是十住菩萨，阿那婆达多龙王是七住菩萨，罗睺阿修罗王也是大菩萨，又为什么说“其余诸道不能种三十二相的因缘”？

你说：“在人道中的阎浮提种，郁怛罗曰不能种。”这有道理，因为那里的人没有吾我，执着享乐，根性不利。

瞿陀尼、弗婆提两处，福德、智慧、寿命都胜过阎浮提，为什么不能种？

再者，你说：“一个思种一个相。”这心在一弹指之间有六十次生灭，一念之中不停住，不能分别，怎能种大人相？这大人相不应当以不明了的心来种，所以要多个思和合，才能种一个相。如同重物一个人担不动，必须多人合力。同样，种相要得到大心、多个思和合，才能种成。所以名为百福相。以一百个大心之思种下福德，这名为百福相，不应当一个思种一个相。其余的事尚且不能以一个思成就一件事，何况百福相！

为什么说“释迦文尼菩萨心未纯熟，弟子心纯熟；弥勒菩萨心纯熟，弟子心未纯熟”？这话出自哪里？三藏中、摩诃衍中都没有这件事，这话是你自己心里想出来的。你只看到释迦文尼菩萨在宝窟中见到弗沙佛，七日七夜以一首偈赞叹；弥勒菩萨也以种种方式赞叹弗沙佛，只是阿波陀那经中没有说，你不知道而已。没有因缘根据，你就说“弥勒的弟子心未纯熟”，这些都是违背事实的过失！

你说菩萨一切东西都能布施，毫无爱惜，如尸毗王为了鸽子割肉给老鹰，心不悔恨。如以财宝布施，名为下等布施；以身体布施，名为中等布施；在种种布施中心不执着，才是上等布施。你为什么把中等布施赞叹为檀波罗蜜圆满？这种布施，心虽然大，多有慈悲，却有的有智慧，有的没有智慧。如同有人为了父母亲属不惜身命，或者为了主人不惜身命。所以知道，为了鸽子不惜身命，是中等布施。

问：菩萨为一切众生作父母、作主人，是为了一切人；所以，不只是不惜身命就算檀波罗蜜圆满。

答：虽然是为了一切众生，这样的心却不清净：不知道自身没有吾我；不知道受施的人没有人、没有主；不知道所布施之物的实性，不可说是一，也不可说是异。在这三件事上心有执着，就是不清净，只能在世间中得到福德果报，不能直达佛道。如般若波罗蜜中所说，三件事都不可得，也不执着，这才是具足檀波罗蜜圆满。

【译注】这是全卷的转折点。前面依迦旃延尼子弟子所说，以尸毗王割肉为檀波罗蜜满；这里摩诃衍人判为“中布施”，理由不在舍得不够，而在施者、受者、施物三事上心有所著。施者无我、受者无人、施物实性不可说一异，三事皆不可得而又不执着“不可得”，布施才成为波罗蜜。般若在六度中的地位，在这里第一次被点明。

同样，乃至般若波罗蜜，你说：“能把大地、城郭、聚落分作七份，这是般若波罗蜜圆满。”这般若波罗蜜无量无边，如同大海之水，诸天、圣人、阿罗汉、辟支佛，乃至初行菩萨，尚且不能知道般若的边际，唯有十地菩萨才能知道，你怎么说“能把大地、城郭、聚落分作七份，就名为般若波罗蜜圆满”？这件事是算数之法；能分大地，只是世俗般若波罗蜜中的少许部分，譬如大海水中的一滴两滴。

真实的般若波罗蜜名为三世诸佛之母，能显示一切法的实相。这般若波罗蜜没有来处，没有去处，在一切处寻求都不可得；如幻、如响、如水中之月，一见就失去。诸圣人因为怜悯众生，般若虽然只是一相，却以种种名字来宣说这般若波罗蜜，这是诸佛智慧的宝藏。你的说法是大过失！

你说四种观察：“观察时间、观察国土、观察种族、观察出生之处。

“人寿八万岁时佛出世，七万、六万、五万、四万、三万、二万岁时佛出世，人寿百岁时是佛出世之时。”如果诸佛常怜悯众生，为什么只在这八种时期中出世，其余时期不出世？佛法不等待时机，如同好药，服用时就能治病，佛法也是这样，不等待时机。

问：菩萨虽然怜悯众生，诸佛虽然不等待时机，然而人寿超过八万岁时，人寿命长、快乐多，染爱等结使厚重，根性迟钝，不是可以教化的时候。人寿百岁以后，人寿命短、痛苦多，瞋恚等结使更加厚重。这快乐的时候与痛苦的时候，都不是得道的时候，所以佛不出世。

答：诸天寿命超过千万岁，有前世的因缘，虽然快乐多、染爱厚，也能得道，何况人间并不那么快乐！人身有三十六种不净，容易教化，所以人寿超过八万岁时，佛也应当出世。这时，人们没有疾病、心中安乐，所以人人根性锐利、有福德；有福德、根性锐利，应当容易得道。

再者，狮子鼓音王佛时，人寿十万岁；明王佛时，人寿七百阿僧祇劫；阿弥陀佛时，人寿无量阿僧祇劫；你怎么说“人寿超过八万岁时佛不出世”？

问：摩诃衍经中有这些事，我们的法中没有十方佛，只有过去的释迦文尼、拘陈若等一百位佛，未来的弥勒等五百位佛。

答：摩诃衍论中，以种种因缘说三世十方佛。为什么？十方世界都有老、病、死、淫、怒、痴等种种苦恼，所以佛应当出现在那些国土。如经中说：“没有老、病、死、烦恼，诸佛就不出世。”

再者，病人多，就应当有很多医师。

你们声闻法的《长阿含》中，毗沙门王以偈对佛说：

“稽首过去、未来、现在诸佛，也归命释迦文佛。”

你们的经中说：“对‘过去、未来、现在诸佛’说稽首；对‘释迦文尼佛’说归命。”因此可知现在还有其他的佛。如果其他国土没有佛，为什么前面稽首三世诸佛，后面另外归命释迦文尼佛？这位毗沙门王还没有离欲，在释迦文尼佛处得道，敬爱之心深重，所以归命；对其余诸佛，只是稽首。

问：佛亲口说：“一个世间不会同时有两位佛出世，也不会同时有两位转轮王出世。”所以，现在不应当有其他的佛。

答：虽然有这话，你却不理解其中的意义。佛说：“在一个三千大千世界中，不会同时有两位佛出世。”并不是说“十方世界中没有现在佛”。如同在一个四天下世界中，不会同时有两位转轮圣王出世，因为这样的大福德之人，没有怨敌与之共存于世。所以，一个四天下只有一位转轮圣王。佛也是这样，在一个三千大千世界中，不会有两位佛出世。佛与转轮圣王，经中说的是同一种道理，你为什么相信其他四天下还有转轮圣王，却不相信其他三千大千世界中还有佛？

再者，一位佛不能度尽一切众生；如果一位佛能度尽一切众生，就可以不需要其余的佛，只要一位佛出世就够了。诸佛之法，度化了可度的众生之后就灭度了，如同蜡烛燃尽，火就熄灭，因为有为法无常、性空。所以，现在应当还有其他的佛。

再者，众生无量，苦也无量，所以应当有大心菩萨出世，也应当有无量的佛出世，度化众生。

问：如经中说：在无量岁月中，佛偶尔才出世一次，譬如优昙婆罗树的花偶尔才开一次。如果十方佛充满，佛就容易出世、容易遇到，不能说难以值遇了！

答：不是这样！是就一个大千世界中而言，佛在无量岁月中偶尔才出世，不是说在一切十方世界中都难。也是因为罪人不知道恭敬，不勤精进求道，所以对这些人说：“佛在无量岁月中偶尔才出世一次。”又因为这些众生由于种种罪报，堕在恶道中，无量劫中连佛的名字都听不到，何况见佛？为了这些人，才说佛出世难。

问：如果现在十方有很多佛与菩萨，如今一切众生罪恶苦恼，为什么不来度化？

答：众生无量阿僧祇劫以来罪垢深厚，虽然有种种其余的福德，却没有见佛的功德，所以见不到佛。如偈中说：

```
好福报未近，　衰罪未除却，
现在不能见，　大德有力人。
大德诸圣人，　心亦无分别，
慈悲一切人，　一时令欲度。
众生福德熟，　智慧根亦利，
若为现度缘，　即时得解脱。
譬如大龙王，　随愿雨众雨，
罪福随本行，　各各如所受。
```

大意：好的福报还没有临近，衰败的罪业还没有除去，所以现在不能见到大德、有力的圣人。大德诸圣人心中也没有分别，以慈悲对待一切人，想要同时度化一切人。众生福德成熟、智慧根锐利，如果为之显现得度的因缘，当即就能得到解脱。譬如大龙王随着众生的愿望降下种种雨，罪与福随着各自本来的行为，各自如其所受。

问：如果自己有福德、自己有智慧，这样的人佛能度化；如果没有福德、智慧，佛就不度化。如果是这样，自己有福德、智慧，就不必等佛来度化了！

答：这福德与智慧，正是从佛的因缘而生。如果佛不出世，诸菩萨以十善因缘、四无量心、后世罪福之报等种种因缘教导众生。如果没有菩萨，也有种种经中所说的道理，人得到这些法，就能修行福德的因缘。

再者，人虽然有福德、智慧，如果佛不出世，只能在这世间中受报，不能得道；如果佛出世，才能得道，这是大利益。譬如人虽然有眼睛，太阳不出来时，什么也看不见，必须有太阳的光明，才能看见东西，不能说“我有眼睛，要太阳做什么”！如佛说：“有两种因、两种缘，能生起正见：一是从他人听闻佛法，二是自己在内心如法思惟。”因为有福德，能生起善心；因为根性锐利、有智慧，能如法思惟。所以知道是从佛那里得度的。

像这样种种，迦旃延尼子弟子们的说法多有违错！因为要作般若波罗蜜的论议，所以不能再广泛论述其余的事了。

## 本卷要义

本卷的结构本身就是一番论议。前大半卷，龙树完整地铺陈迦旃延尼子弟子所说的菩萨：三阿僧祇劫，初劫不知、二劫知而不说、三劫知而自说；三阿僧祇之后再以百劫种三十二相，一思种一相，一相百福庄严；六度各以一则本生为“满”的标准，尸毗割肉是檀满，须陀须摩守信是戒满，劬嫔陀分地作七分是般若满。这套说法有次第、有数目、有故事，自成一个严整的体系。然后摩诃衍人逐条破斥，指出整个体系的根病：把菩萨安立在“相”上。迦旃延尼子弟子说得明白，“一切法先有相，然后可知其实，若无相则不知”，所以三十二相未种，就不能算菩萨。

摩诃衍人的回答，把菩萨的根据从身相移到了发心与授记。燃灯佛授记、上升虚空见十方佛，这才是“大相”；三十二相，转轮王有，魔王能化，难陀凭三种小福就得了三十相。菩萨之所以为菩萨，在“初发心时，誓愿当作佛”，在大商主以身渡众的大慈，不在身上长出了什么。卷首龙树先立“秘密”与“现示”二门，也是同一个意思：依现示，菩萨烦恼未尽，排在比丘四众之后；依秘密，得无生法忍的菩萨早已超出众生数。凡是从外相上衡量菩萨的，都只看到了现示的一面。

全卷真正的枢纽在檀波罗蜜的重判。尸毗王血涂手攀秤，肉尽筋断仍要上秤，论中写得惊心动魄，龙树却判之为“中布施”。原因不是舍得不够彻底，而是心中仍有施者、受者、施物三事可得：不知己身无我，不知受者无人，不知施物实性不可说一异。三事不可得，又不著于不可得，布施才成为波罗蜜。同样，能把大地分作七分只是算数，是世俗般若的一滴两滴；真实般若“无来处，无去处，一切处求不可得，如幻、如响、如水中月”。六度之所以称为波罗蜜，不在于每一度做到了多么极端，而在于般若贯入其中。本卷是全论中般若第一次以这种方式落到菩萨行上。

后段破“佛出世待时”“现在无十方佛”，用的仍是同一种眼光：小乘把佛的出现框在一个世界、八种时节、一百位佛的数目里，摩诃衍则说“佛法不待时，如好药服时便差病”，众生无量，苦无量，佛亦无量。众生见不到佛，不是佛不在，是自己“无见佛功德”。最后一问把这层意思收得很稳：既然要有福德智慧才能得度，何必要佛？龙树答，人有眼，无日亦不能见。福德智慧本身就从佛的因缘出，佛的出世是众生得度的必要条件，众生自身的善根是相应的眼目，两者和合，才有“二因二缘，能生正见”。
