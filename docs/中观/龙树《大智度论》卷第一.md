# 龙树《大智度论》卷第一

龙树菩萨造　后秦龟兹国三藏法师鸠摩罗什奉诏译

## 摩诃般若波罗蜜经释论序

长安释僧叡述

万有依靠“生而又生”得以生起，能生的那个“生”，本身却是无生；种种变化在事物的开端露出征兆，那个开端，本身却是无始。既然如此，无生、无始，正是万物的本性。生与始从未扰动这个本性，万有却在外面纷然陈列，悔恨与过失却在内心滋生，这只能归于邪思了！正觉者看见邪思是自己生起的，所以为众生说了阿含；知道执滞于有是由迷惑而来，所以用般若来照破。

般若的照，本来希微幽寂，渡口与岸际浩渺无边，道理超出文字之外，旨趣断绝于思虑的境界。用言语去求般若，就违背般若的深；用心智去测度般若，就失掉般若的旨。二乘人之所以在三藏中颠沛，杂学之人之所以像鱼跃不过龙门、在龙门下曝鳃露鳞，难道不正是这个缘故吗！

因此马鸣出世于正法的余期，龙树诞生于像法的末期。正法余期容易弘扬，所以马鸣只需振起佛陀的遗风，拂拭使其光亮而已。像法末期头绪繁多，所以龙树寄迹为凡夫，示现渐次觉悟来引导众生；又借照龙宫，开朗探求玄理的智慧；托言听闻了幽深秘藏，穷尽微妙言教的精妙。于是以般若智典为法度，造了这部释论。这部论开辟平坦大路，使大乘的车驾并轨直入；辨明实相，使妄见的迷惑不必远行，就自然回复正道。

这部论的作法是：开头先拟议，必定标举众家异说，以穷尽其美；最后完成时，就举出无所执着，以穷尽其善。经文解释不尽的，就另立论议来阐明；论议还没有辨清的，就寄托于折中之说来裁定。使这部灵妙的经典没有难以晓喻的篇章，千载之后的人能领悟作者的本旨，这实在是龙树这样的人的功劳啊！

有一位鸠摩罗耆婆法师，少年时就传出聪慧的名声，长大后汇集了卓越超拔的赞誉。才华一显，便高标万里；言辞一发，英辩能使荣者枯、枯者荣。法师常依这部论，作为深渊之镜、登高之凭，用来阐明宗旨。姚秦弘始三年，岁在星纪，十二月二十日，法师从姑臧来到长安。秦王虚怀以待的心早已蕴积，往日仰慕的心，见面之后何止喜悦而已！秦王与法师相对晤谈，就整日流连；研究精微、探到穷尽，就终年忘了疲倦。

秦王又觉得：晤谈的功夫虽深，可惜只有两人心心相契，不够广大；探到穷尽处的要义虽玄，可惜作为津梁渡人的态势还不普遍。于是怀着莫逆的情谊，一同弘扬物我两忘的智慧，召集京城中修学义理的沙门，又命令公卿中能赏识契会的人士，共五百余人，聚集在渭水之滨的逍遥园堂。皇帝的车驾停驻在大河岸边，禁卫在林间止息了警戒。秦王亲自披览玄妙篇章，依照梵本考正名相；咨询通达津要之处，为后来践行的人铺平道路。

经本审定之后，才译出这部释论。论的略本有十万偈，每偈三十二字，合计三百二十万言。梵语与汉语既有差异，又有繁简的不同，删去三分之二，得到这一百卷。《大品》经文三十万言中的玄妙篇章、婉曲旨意，借这部论都朗然可见；归向之路直接通达，不再有误入歧途的疑虑；就文字去求，也无可挑剔。

所以天竺的传记说：“在像法与正法的末期，若没有马鸣、龙树，修道学法之门就都要沉沦丧亡了！”这是什么缘故？实在是因为正法、像法两个时期的末世，微妙之法衰微，邪法盛行，虚妄言论与真实教法同时兴起，险峻小径与平坦大路争夺车辙；初入门的人被邪法所化而流离，向往道的人被迷惑而飘散。若不是马鸣、龙树这两位大匠，谁能匡正呢！因此天竺各国为两位大士建立庙宇，尊崇如佛。又称颂两位大士说：“智慧之日已经西沉，此人使智慧之日重新照耀；世人昏睡已久，此人唤醒世人觉悟。”如此看来，真可说功德达到十地，道行等同补处菩萨了！传记这样称颂，不也理所当然吗！真是幸运啊！在远离天竺中土的这片边地，忽然得到了完整的这部论。

梵文原本委曲详尽，各品都像初品那样。法师因为秦人喜好简约，就裁剪删略了。如果完整翻译全文，将近一千余卷。法师对秦地语言只掌握大体，只能依一种译法翻出；方言殊异的妙处，仍有隔阂而未能贯通。言语若不能相互晓喻，情意就无从相应。情意不能相应，就无法把领悟的心怀寄托在文字之外；言语不能晓喻，又怎能把殊异的路径会归于一致？道理本来就是如此。进一步想停下笔来争辩是非，就会整日交相争论而终究一事无成；退一步想简化以求方便，又要背负穿凿附会的讥评，而且不止一两次。所以只依照译出的原样记录下来，全不加修饰。但愿明达觉悟的贤者，略过文辞，汲取其中的玄理！

## 初序品中缘起义释论第一

```
智度大道佛从来，　智度大海佛穷尽，
智度相义佛无碍，　稽首智度无等佛。
有无二见灭无余，　诸法实相佛所说，
常住不坏净烦恼，　稽首佛所尊重法。
圣众大海行福田，　学无学人以庄严，
后有爱种永已尽，　我所既灭根亦除；
已舍世间诸事业，　种种功德所住处，
一切众中最为上，　稽首真净大德僧。
一心恭敬三宝已，　及诸救世弥勒等；
智慧第一舍利弗，　无诤空行须菩提。
我今如力欲演说，　大智彼岸实相义，
愿诸大德圣智人，　一心善顺听我说！
```

大意：智度这条大道，是佛所从来的道路；智度这片大海，唯有佛穷尽其底；智度的相与义，佛通达无碍。我稽首礼敬在智度上无与等者的佛。有、无两种见解，灭尽无余；诸法实相，是佛所宣说；常住不坏，能净除烦恼。我稽首礼敬佛所尊重的法。圣众如大海，是行持者的福田，以有学、无学圣者为庄严；后有的爱欲种子已永远断尽，我所既已灭除，我执的根也已拔掉；已舍弃世间种种事业，是种种功德安住之处，在一切众中最为上首。我稽首礼敬真实清净的大德僧。一心恭敬三宝之后，也恭敬救度世间的弥勒等诸大菩萨，恭敬智慧第一的舍利弗，恭敬住于无诤、行于空性的须菩提。我如今随自己的力量，想要演说抵达大智彼岸的实相之义，愿诸位大德、圣智之人，一心善顺地听我宣说！

问：佛以什么因缘，宣说《摩诃般若波罗蜜经》？诸佛不会无事或者为了小因缘就自己开口说法，譬如须弥山王不会无事或者为了小因缘就动摇。如今有什么大因缘，佛要宣说《摩诃般若波罗蜜经》？

答：佛在三藏中，广泛引用种种譬喻，为声闻说法，没有说菩萨道。只有《中阿含经·本末经》中，佛为弥勒菩萨授记说：“你在未来世，当得成佛，名号叫弥勒。”这部经也没有说种种菩萨行。佛如今想为弥勒等菩萨广说种种菩萨行，所以宣说《摩诃般若波罗蜜经》。

再者，有些菩萨修念佛三昧，佛想让这些菩萨在念佛三昧上得到增益，所以宣说《般若波罗蜜经》。如《般若波罗蜜经·初品》中说：“佛显现神足，放出金色光明，遍照十方恒河沙数的世界，示现广大身相，清净光明，种种妙色充满虚空。佛在大众中，端正殊妙，无人能及，譬如须弥山王处在大海之中。”诸菩萨见到佛的神变，念佛三昧加倍增益。因为这件事，佛宣说《摩诃般若波罗蜜经》。

再者，菩萨初生时，放大光明，普遍十方，行走七步，向四方观察，作狮子吼，说偈言：

```
我生胎分尽，　是最末后身；
我已得解脱，　当复度众生。
```

大意：我受胎而生的分已经穷尽，这是最后一次受身；我已经得到解脱，还要再去度化众生。

菩萨立下这个誓愿后，身体渐渐长大，想舍离亲属，出家修无上道。菩萨半夜起来观察，看见那些伎乐侍从、后妃宫女，形状如同发臭的尸体。菩萨随即命令车匿给白马备上鞍具，夜半越过城墙，走了十二由旬，到达跋伽婆仙人所住的林中，用刀剃去头发，用上妙的宝衣换来粗布僧伽梨。菩萨在尼连禅河边苦行六年，每天只吃一粒麻，或者只吃一粒米等。菩萨自己思念说：“这里不是道！”那时，菩萨舍离苦行之处，来到菩提树下，坐在金刚座上。魔王率领十八亿万魔众来破坏菩萨，菩萨凭借智慧与功德的力量，降伏魔众之后，随即证得阿耨多罗三藐三菩提。

这时，三千大千世界之主梵天王，名叫式弃，与色界诸天等，以及帝释天与欲界诸天等，连同四天王，都来到佛的处所，劝请世尊初转法轮。同时，菩萨也忆念自己本来所发的誓愿，又因为大慈大悲，所以接受劝请而说法。诸法中最甚深的，就是般若波罗蜜。因此，佛宣说《摩诃般若波罗蜜经》。

再者，有人怀疑佛没有证得一切智。为什么会怀疑？诸法无量无数，一个人怎能知道一切法？佛安住在般若波罗蜜的实相之中，实相清净如虚空，佛在无量无数的法中，自己发出诚实之言：“我是一切智人，要断除一切众生的疑惑。”因此宣说《摩诃般若波罗蜜经》。

再者，有些众生本来应当得度，因为佛的大功德与智慧无量，难知难解，这些众生就被恶师迷惑，心沉没在邪法中，不能进入正道。为了这类人，佛生起大慈心，伸出大悲之手接引，使这些众生进入佛道。所以佛自己显现最妙的功德，发出大神力。如《般若波罗蜜经·初品》中说：“佛入三昧王三昧，从三昧起，以天眼观察十方世界，全身毛孔都在微笑；从足下的千辐轮相，放出六百千万亿种种色光明；从足趾往上到肉髻，处处各放六百千万亿种种色光明，普照十方无量无数如恒河沙的诸佛世界，都令大放光明。”佛从三昧起，想宣示一切诸法实相，断除一切众生的疑结，所以宣说《般若波罗蜜经》。

再者，有些邪恶的人怀着嫉妒心，诽谤说：“佛的智慧并不超出常人，只是用幻术迷惑世人。”为了断除这些人贡高的邪慢之心，佛显现无量神力、无量智慧力，在《般若波罗蜜经》中亲自说：“我的神德无量，在三界中独尊，覆护一切众生。如果有人对我生起一念恶心，所获罪业无量；生起一念清净信心，就会享受人天之乐，必定得到涅槃之果。”

再者，佛为了让人信受佛法，说：“我是大师，具有十力、四无所畏，安立在圣主的住处，心得自在，能作狮子吼，转妙法轮，在一切世界中最尊最上。”

再者，佛世尊为了让众生欢喜，宣说这部《般若波罗蜜经》，说：“你们应当生起大欢喜！为什么？一切众生都落入邪见之网，被异学恶师迷惑，我已从一切恶师的邪网中出离。具足十力的大师难以值遇，你们如今已经遇到。我随时开启三十七道品等种种深妙法藏，任凭你们采取。”

再者，一切众生被结使之病所苦恼，从无始生死以来，没有人能医治这种病，众生常被外道恶师所误。佛说：“我如今出世作大医王，汇集种种法药，你们应当服用。”所以佛宣说《摩诃般若波罗蜜经》。

再者，有人心想：“佛与常人相同，也有生死，真实地受饥渴、寒热、衰老、疾病之苦。”佛想断除这种想法，所以宣说《摩诃般若波罗蜜经》，开示说：“我的身不可思议。梵天王等是诸天的祖父，在恒河沙数的劫中想要思量我的身、寻究我的声音，都不能测度，何况我的智慧与三昧？”如偈中说：

```
诸法实相中，　诸梵天王等，
一切天地主，　迷惑不能了！
此法甚深妙，　无能测量者，
佛出悉开解，　其明如日照。
```

大意：在诸法实相中，诸梵天王等一切天地之主，都迷惑而不能了知！此法甚深微妙，没有谁能测量；佛出世后，全都开示解说，光明如同太阳普照。

又如佛初转法轮时，当时有一位菩萨从他方世界来，想测量佛身的高度，往上越过虚空中无量佛国，到了华上佛的世界，看见佛身依然如故。这位菩萨说：

```
虚空无有边，　佛功德亦尔；
设欲量其身，　唐劳不能尽！
上过虚空界，　无量诸佛土，
见释师子身，　如故而不异！
佛身如金山，　演出大光明，
相好自庄严，　犹如春华敷。
```

大意：虚空没有边际，佛的功德也是如此；即使想测量佛身，也只是白费力气，无法量尽！我往上越过虚空界无量佛土，看见释迦狮子的身相，依然如故，毫无差别！佛身如同金山，放出大光明，以相好自然庄严，犹如春天的花朵盛开。

如同佛身无量，佛的光明、音声也同样无量；戒、定、慧等诸佛功德，全都无量。如《密迹经》中所说的三密，这里应当广说。

再者，佛初生时，落地就走七步，亲口说话，说完就沉默了，与普通婴孩一样，不走也不说话，吃奶三年，由诸位母亲养育，渐次长大。其实佛身无数，超过一切世间，为了众生，才示现得如同凡人。凡人出生时，身体各部分、诸根以及意识都还没有成熟，坐、卧、行、住四种威仪，言谈与沉默等种种为人之事，都还不会；随着日月年岁过去，渐渐学习，才能具备为人之事。

有人会觉得奇怪：如今佛为什么出生就能说能走，后来反而又不能了？答案正在这里：佛以方便力示现常人之事，如同常人的威仪，是为了让众生信受甚深之法。如果菩萨出生后就一直能走能说，世人就会这样想：“现在见到的这个人，世上从未有过，必定是天、龙、鬼、神。这个人所学的法，必定不是我们所能企及的。为什么？我们是生死肉身，被结使与业力牵引，不得自在，像这样深的法，谁能达到？”世人就会因此自我断绝，不能成为贤圣之法的法器。为了这些人，菩萨在岚毗尼园中出生。

菩萨虽然当下就能到菩提树下成佛，却以方便力，示现为孩童、幼小、少年、成人，在各个时期依次经历嬉戏、学习技艺、享用五欲，具足为人之事。后来渐渐见到老、病、死之苦，生起厌离之心，于半夜越城出家，到郁陀伽阿罗逻仙人处，示现作弟子，却不修行仙人之法。菩萨虽然常常运用神通，自己忆念宿命，知道自己在迦叶佛时已经持戒修道，如今却示现修苦行六年来求道。菩萨虽然是三千大千世界之主，却示现破除魔军，成就无上道。

佛是为了随顺世间法，才示现这些种种变化。如今在《般若波罗蜜经》中，佛显现大神通与智慧力，所以众人应当知道：佛身无数，超过一切世间。

再者，有些可以度化的人，有的落在二边之中：有的因为无智，只求身体安乐；有的为了求道，执着于修苦行。这样的人，在第一义中，失去了通往涅槃的正道。佛想拔除这两边，使人进入中道，所以宣说《摩诃般若波罗蜜经》。

再者，佛为了分别生身与法身，以及供养生身、法身各自的果报，宣说《摩诃般若波罗蜜经》，如〈舍利塔品〉中所说。

再者，佛为了说明阿鞞跋致（不退转菩萨），以及阿鞞跋致的相貌，宣说此经；又为了说明魔的幻化与种种魔事，宣说此经。

再者，佛为了让未来世的人有供养般若波罗蜜的因缘，又为了授予三乘人记别，宣说这部《般若波罗蜜经》。如佛告诉阿难：“我涅槃之后，这部般若波罗蜜将流传到南方，再从南方到西方，后五百年中将到北方。那里有很多信法的善男子、善女人，用种种花香、璎珞、幢幡、伎乐、灯明、珍宝等财物来供养；或者自己书写，或者教人书写，或者读诵、听闻、讲说，正确忆念、如法修行，以法来供养。这些人以这样的因缘，享受种种世间之乐，最后得三乘道果，入无余涅槃。”像这样，观察经中各品所说的因缘之事，就知道佛为何宣说《般若波罗蜜经》。

再者，佛想说明第一义悉檀的相，所以宣说这部《般若波罗蜜经》。悉檀有四种：一是世界悉檀，二是各各为人悉檀，三是对治悉檀，四是第一义悉檀。依这四悉檀，一切十二部经、八万四千法藏，全都真实，彼此没有相违背的地方。佛法中，有的话依世界悉檀而真实，有的话依各各为人悉檀而真实，有的话依对治悉檀而真实，有的话依第一义悉檀而真实。

【译注】悉檀，梵语siddhānta，意为成立的宗旨、确定的道理。四悉檀是本论判摄一切佛语的总纲：佛说的每一句话，都要先问是在哪一种悉檀上说的，才能判定这句话在什么意义上是真实的。经中看似互相矛盾的说法，放回各自的悉檀，便各得其所。

所谓世界悉檀：有些法是由因缘和合而有的，没有另外独立的自性。譬如车，是车辕、车轴、车辐、车辋等和合而有，离开这些部件，另外没有车。人也是这样，是五众（五蕴）和合而有，离开五众，另外没有人。

如果没有世界悉檀，佛是说实话的人，怎么会说：“我以清净天眼，看见众生随着善恶之业，在此处死、在彼处生，承受果报；造善业的生在天人之中，造恶业的堕入三恶道”？

再如经中说：“一人出世，众人蒙受福庆，得到福乐与饶益，这人就是佛世尊。”

又如《法句经》中说：“神我自己能救自己，别人怎能救得了！神我自己行善、具智，最能自己救度自己。”

又如《瓶沙王迎经》中，佛说：“凡人没有听闻佛法，凡人执着于我。”

又如《佛二夜经》中说：“佛从初得道之夜，到般涅槃之夜，这两夜之间所说的经教，全都真实，没有颠倒。”

如果真的没有人，佛怎么会说“我以天眼看见众生”？所以应当知道，说“有人”，是依世界悉檀说的，不是依第一义悉檀说的。

问：第一义悉檀是真实的，因为真实，才叫作“第一”，其余三种悉檀不应是真实的。

答：不是这样！这四种悉檀各自都有其真实。比如：真如、法性、实际，依世界悉檀说是无，依第一义悉檀说是有。人等也是这样，依世界悉檀说是有，依第一义悉檀说是无。为什么说人在世界悉檀上是有？因为五众的因缘存在，所以有人等。譬如乳，因为色、香、味、触的因缘存在，所以有乳；如果乳真的是无，乳的因缘也应当是无。如今乳的因缘确实存在，所以乳也应当是有，不像一个人的第二个头、第三只手，根本没有因缘，只有一个假名。像这样的相，名为世界悉檀。

【译注】这里的两层“有”是互相翻转的：真如、法性、实际，在世间的眼光里看不见，所以说是无，在第一义中却是真有；人、车、乳，在世间是有，在第一义中却是无。龙树同时划清了另一条界线：人、乳这类假名，有因缘支撑，与“第二个头、第三只手”这类连因缘都没有的空名不同。世界悉檀的真实，正是因缘和合之有的真实。

什么是各各为人悉檀？观察每个人的心行，为这个人相应地说法。对同一件事，有时说有，有时说没有。

如经中说：“由于杂报之业，众生杂生于世间，得到杂触，感受杂受。”

另有《破群那经》中说：“没有人得触，没有人得受。”

问：这两部经的说法怎样会通？

答：有人怀疑有没有后世，不信罪福，作不善之行，堕入断灭见。佛为了断除这种人的疑惑，使这种人舍弃恶行，拔除这种人的断见，所以说众生杂生于世间，得到杂触、感受杂受。破群那则执着有我、有神我，堕入常见。破群那问佛：“大德！是谁在受？”如果佛说“某某人在受”，破群那就会堕入常见，我见加倍牢固，不能再转移。所以佛不说有受者、有触者。像这样的相，名为各各为人悉檀。

什么是对治悉檀？有的法，就对治来说是有，就实性来说是无。

譬如性质重、热、腻、酸、咸的药草饮食等，对于风病就称为药，对于其他病就不是药；性质轻、冷、甘、苦、涩的药草饮食等，对于热病就称为药，对于其他病就不是药；性质轻、辛、苦、涩、热的药草饮食等，对于冷病就称为药，对于其他病就不是药。

佛法中医治心病也是这样：

修不净观的思惟，对于贪欲病称为善对治法，对于瞋恚病就不称为善，不是对治法。为什么？观察身体的过失，名为不净观；瞋恚的人如果再去观察过失，就会增长瞋恚之火。

修慈心的思惟，对于瞋恚病称为善对治法，对于贪欲病就不称为善，不是对治法。为什么？慈心是在众生身上寻求好处、观察功德；贪欲的人如果再去寻求好处、观察功德，就会增长贪欲。

修因缘观，对于愚痴病称为善对治法，对于贪欲、瞋恚病就不称为善，不是对治法。为什么？因为先前邪观，所以生起邪见，邪见就是愚痴。

问：佛法中说十二因缘甚深，如经中说：“佛告诉阿难：‘这因缘法甚深，难见难解，难觉难观，心思细密、智慧善巧的人才能理解。’”愚痴的人对浅近的法尚且难以理解，何况甚深的因缘？如今为什么说“愚痴的人应当观因缘法”？

答：这里说的愚痴人，不是指像牛羊那样的愚痴，而是指想求真实之道，却因为以邪心观察，生起种种邪见的人。这样的愚痴人，应当观因缘，这就名为善对治法。如果是行瞋恚、淫欲的人，一心求乐、一心恼害他人，对这种人来说，因缘观既不是善法，也不是对治法；不净观与慈心的思惟，对贪欲、瞋恚这两种人来说，才是善法，才是对治法。为什么？因为不净观与慈心观这两种观，能拔除瞋恚与贪欲的毒刺。

再者，执着常的颠倒众生，不知道诸法只是相似相续而有。这样的人修无常观，是对治悉檀，不是第一义。为什么？因为一切诸法自性空。如偈中说：

```
无常见有常，　是名为颠倒；
空中无无常，　何处见有常？
```

大意：在无常中见到常，名为颠倒；在空性中，连无常都没有，又在哪里见到常？

问：一切有为法都与无常之相相应，这是第一义，为什么说无常不是真实？一切有为法都有生、住、灭三相，先生，次住，后灭，为什么说无常不是真实？

答：有为法不应当有三相。为什么？因为三相不真实。如果诸法的生、住、灭是有为之相，那么现在这个“生”本身也应当有生、住、灭三相，因为“生”本身也是有为之相；这样，每一处都应当再有三相，就会无穷无尽。住、灭也是这样。如果说生、住、灭各自不再有生、住、灭，那么生、住、灭就不应称为有为法。为什么？因为没有有为法的相。所以，诸法无常，不是第一义。

再者，如果一切法的实性是无常，就没有行为、业与果报。为什么？无常就是生灭消失，譬如腐烂的种子不能生出果实。这样就没有行为与业，没有行为与业，怎么会有果报？如今一切贤圣之法都有果报，善于运用智慧的人都信受，不应说没有。所以，诸法并非以无常为自性。以这样无量的因缘来说，不能说诸法的自性是无常。

一切有为法是无常，同样，一切有为法是苦、是无我等，也是这样，都是对治悉檀。

像这样的相，名为对治悉檀。

什么是第一义悉檀？一切法的自性，一切论议与言语，一切说是法、说非法的主张，每一种都可以被分别、破斥、拆散；唯有诸佛、辟支佛、阿罗汉所行的真实法，不可破，不可散。上面三种悉檀中不能通达的地方，在第一义悉檀中全都通达。

问：怎样通达？

答：所谓通达，是离开一切过失，不可变易，不可胜过。为什么？除了第一义悉檀，其余一切论议、其余三种悉檀，都可以被破斥。如《众义经》中所说的偈：

```
各各自依见，　戏论起诤竞，
若能知彼非，　是为知正见。
不肯受他法，　是名愚痴人，
作是论议者，　真是愚痴人。
若依自是见，　而生诸戏论，
若此是净智，　无非净智者。
```

大意：人人各自依靠自己的见解，生起戏论，引发争竞；能够知道这些执见的错误，才是懂得正见。如果说不肯接受别人之法的人就是愚痴人，那么作这种论议的人，自己就真是愚痴人。如果依着自以为是的见解生出种种戏论，这样就算是清净智慧，那么天下就没有人不是清净智慧了。

在这三首偈中，佛说的是第一义悉檀的相。

就是说：世间众生各自依靠自己的见解、自己的法、自己的论议，而生起争竞；戏论就是争竞的根本，戏论依诸见而生。如偈中说：

```
有受法故有诸论，　若无有受何所论？
有受无受诸见等，　是人于此悉已除。
```

大意：因为有所领受、执取于法，才有种种论议；如果没有执取，还论什么？执取与不执取等种种见解，证悟之人对这些已经全部除尽。

修行人能如实了知这个道理，对一切法、一切戏论，不执取，不染着，不认为某一说法是真实，不与人争竞，就能尝到佛法的甘露味。如果不是这样，就是谤法。

如果说不接受他人之法、不认识也不取纳他人之法的，就是无智之人，那么一切论议之人都应当是无智之人。为什么？因为各家都彼此不接受对方的法。所谓有人自认为自己的法是第一义、是清净，别人的说法都是虚妄、不清净。

譬如世间治理国家的法，治理国家的人用刑罚、杀戮等种种不清净的手段，世间人信受奉行，认为真实清净；在其余出家的善人、圣人中看来，这却是最不清净的。

外道出家人的法，比如在五种热火中单脚站立、拔除头发等，尼犍子这一类人认为是妙慧，其他人却说这是愚痴之法。像这样，种种外道出家人，以及在家婆罗门的法，各家都认为自己的好，其余的都是虚妄。

佛法中也有犊子部比丘说：“就像四大和合而有眼法，同样，五众和合而有人法。”

《犊子阿毗昙》中说：“五众不离人，人不离五众；不可说五众就是人，也不可说离开五众另有人；人是第五类不可说法藏所摄。”

说一切有部的修行人说：“神我、人，在一切种类、一切时间、一切法门中寻求，都不可得，譬如兔角、龟毛，永远是无。再者，十八界、十二入、五众是实有的，而其中没有人。”

佛法中还有方广道人说：“一切法不生不灭，空无所有，譬如兔角、龟毛，永远是无。”

像这样一切论议师，各自守着自己的法，不接受别家的法，说：“这是真实的，其余都是虚妄。”这些论议师领受自己的法，供养自己的法，修行自己的法，对别家的法不接受、不供养，并且挑出过失。

如果这样就算是清净、得到第一义之利，那么一切人就没有不清净的了。为什么？因为一切人都爱自己的法。

问：如果一切见解都有过失，那么第一义悉檀是什么？

答：超过一切言语之道，心的活动之处灭尽，遍一切处而无所依，不显示任何法，是诸法实相：没有开始、没有中间、没有终结，不穷尽，不毁坏。这就名为第一义悉檀。如摩诃衍（大乘）义的偈中说：

```
语言尽竟，　心行亦讫；　不生不灭，
法如涅槃。　说诸行处，　名世界法；
说不行处，　名第一义。

一切实一切非实，　及一切实亦非实，
一切非实非不实，　是名诸法之实相。
```

大意：言语穷尽，心行也已止息；不生不灭，诸法如同涅槃。宣说心行所能到之处，名为世界法；宣说心行所不能到之处，名为第一义。一切是实，一切非实，一切亦实亦非实，一切非实非不实，这名为诸法的实相。

【译注】后一偈的四句，依青目释《中论·观法品》，是佛随众生根机次第开示的四种说法，不是四种并列的见解。在第一义中，这四句都可以说，也都不执取，所以名为实相。本论下文说“离四句”，指的是离开对四句的执取，并非禁止四句的言说。

像这样，处处经中都在说第一义悉檀。这个道理甚深，难见难解。佛想宣说这个道理，所以宣说《摩诃般若波罗蜜经》。

再者，佛想让长爪梵志等大论议师对佛法生起信心，所以宣说这部《摩诃般若波罗蜜经》。有一位梵志号称长爪，还有一位名叫先尼婆蹉衢多罗，还有名叫萨遮迦、摩揵提等的梵志。这些阎浮提的大论议师说：“一切论都可以被破斥，一切言语都可以被毁坏，一切执着都可以被扭转，所以没有任何真实的法值得信奉、值得恭敬。”

如《舍利弗本末经》中说：舍利弗的舅舅摩诃俱絺罗，与姐姐舍利辩论，辩不过姐姐。俱絺罗心想：“这不是姐姐的力量，必定是姐姐怀了有智慧的孩子，借母亲的口说出来。还没出生就这样，等到出生长大，那还得了？”俱絺罗这样想过之后，生起憍慢心，为了广学论议，出家作了梵志。俱絺罗到南天竺国，开始研读经书。众人问俱絺罗：“你立志追求什么？学习什么经？”长爪回答：“十八种大经，我要全部读完。”众人对长爪说：“用尽你一生的寿命，还不能通晓其中一种，何况全部读完？”长爪心想：“过去我起憍慢，被姐姐胜过，如今这些人又轻视侮辱我。为了这两件事，我自立誓言：不把十八种经书读完，我就不剪指甲。”人们见俱絺罗指甲很长，就叫俱絺罗为长爪梵志。

长爪梵志凭借种种经书所成的智慧力量，用种种方式讥讽质难：这是法，那是非法；这是应当，那是不应当；这是实，那是不实；这是有，那是无，以此破斥他人的论议。譬如力大的狂象，冲撞践踏，无人能制。长爪梵志像这样凭论议之力降伏了众论师之后，回到摩伽陀国王舍城的那罗聚落，回到自己出生的地方，向人打听：“我姐姐生的孩子，现在在哪里？”有人告诉长爪梵志：“你姐姐的儿子，才八岁就读完一切经书；到十六岁，论议胜过所有的人。有一位释种出家人，姓瞿昙，收了这孩子作弟子。”长爪梵志听了，立即生起憍慢与不信之心，说：“像我姐姐的儿子这样聪明，那个人用什么手段，诱骗他剃了头作弟子？”说完，长爪梵志径直前往佛的处所。

那时，舍利弗受戒才半个月，站在佛身边侍立，拿着扇子为佛扇风。长爪梵志见到佛，问讯完毕，在一旁坐下，心想：“一切论都可以被破斥，一切言语都可以被毁坏，一切执着都可以被扭转，那么其中什么是诸法实相？什么是第一义？什么是自性？什么是相？什么是不颠倒？”长爪梵志这样思惟，就像在大海中想探尽海的边际与底部，求了很久，也找不到一个真实可以安心的法。长爪梵志又想：“瞿昙用什么论议之道，得到了我姐姐的儿子？”想完，长爪梵志对佛说：“瞿昙！我一切法都不接受。”

佛问长爪梵志：“你一切法都不接受，那么‘一切法都不接受’这个见解，你接受不接受？”佛这一问的意思是：你已经喝下了邪见之毒，如今吐出的正是这毒气。所以佛问：“‘一切法都不接受’这个见解，你接受不接受？”

那时，长爪梵志就像良马看见鞭影就觉醒、随即走上正道一样，佛的话如同鞭影进入心中，长爪梵志随即舍弃贡高，惭愧低头，这样思惟：“佛把我放在两个必输的门里。如果我说‘这个见解我接受’，这个输门是粗显的，很多人都看得出来：既然自称一切法都不接受，如今又接受这个见解，这是当面说谎，是粗显的输门，很多人都知道。第二个输门比较细微，我想选这一个，因为不会有很多人看出来。”想完，长爪梵志回答佛：“瞿昙！一切法都不接受，这个见解我也不接受。”

佛对长爪梵志说：“你一切法都不接受，这个见解也不接受，那就是一无所受，与众人没有什么不同，凭什么自高自大、生起憍慢？”于是，长爪梵志无言以对，自知已经输了，随即对佛的一切智生起恭敬与信心，自己思惟：“我已经输了，世尊却不张扬我的失败，不评说是非，也不放在心上。佛的心柔和，第一清净；一切言语论议之处都已灭尽，证得了广大甚深之法，这才是值得恭敬之处。佛的心第一清净。”

佛说法断除了长爪梵志的邪见，长爪梵志当即在座位上远尘离垢，在诸法中得到法眼净。这时，舍利弗听到佛的这番话，证得阿罗汉果。长爪梵志后来出家作沙门，成为具大力的阿罗汉。

如果长爪梵志没有听闻到般若波罗蜜的气息，没有听闻这离开四句、与第一义相应的法，连少许的信心都生不起来，何况出家证得道果？佛为了引导这类大论议师、利根之人，所以宣说这部《般若波罗蜜经》。

再者，诸佛有两种说法方式：一是观察众生的心，随着可度之人而说；二是观察诸法的实相而说。如今佛想宣说诸法实相，所以宣说这部《摩诃般若波罗蜜经》。如〈相不相品〉中，诸天子问佛：“这般若波罗蜜甚深，以什么为相？”佛告诉诸天子：“空就是般若的相，无相、无作之相、无生灭之相、无行之相，常不生、如性之相、寂灭之相等。”

再者，有两种说法：一是诤处，二是不诤处。诤处，如其余经中所说；如今想阐明无诤之处，所以宣说这部《般若波罗蜜经》。有相与无相，有物与无物，有依与无依，有对与无对，有上与无上，世界与非世界，也是这样，执取其中一边，就是诤处。

问：佛有大慈悲心，只应当说无诤之法，为什么要说诤法？

答：无诤之法都是无相，永远寂灭，不可言说。如今佛说布施等，以及无常、苦、空等诸法，都是为了趣向寂灭、不起戏论而说的。利根的人懂得佛的用意，不起争执；钝根的人不懂佛的用意，取着法相、心生执着，所以起争执。这部般若波罗蜜，因为诸法毕竟空，所以是无诤之处；如果毕竟空还可以得到、可以争论，就不叫毕竟空了。所以，《般若波罗蜜经》名为无诤之处，因为有与无两边都已寂灭。

再者，其余经中多用三种法门来说诸法，就是善门、不善门、无记门。如今佛想说既非善门、也非不善门、也非无记门的诸法之相，所以宣说《摩诃般若波罗蜜经》。学法、无学法、非学非无学法；见谛所断法、思惟所断法、无所断法；可见有对法、不可见有对法、不可见无对法；上法、中法、下法；小法、大法、无量法：像这样的种种三法门，也都是如此。

再者，其余经中说四念处，是依随声闻的法门：比丘观察自身内的三十六种不净物，以除去贪欲之病；同样观察他人之身，观察内外之身。如今佛想在四念处上，用另一种法门来说般若波罗蜜，如经中所说：菩萨观察自身，对身不生起觉观，不得身，因为无所得。同样观察他人之身，观察内外之身，对身不生起觉观，不得身，因为无所得。在身念处中观身，而不生起对身的觉观，这件事非常难。受、心、法三种念处也是如此。四正勤、四如意足、四禅、四谛等种种四法门，也都是如此。

再者，其余经中佛说五众是无常、苦、空、无我之相；如今佛想对这五众说另一种法门，所以宣说《般若波罗蜜经》。如佛告诉须菩提：“菩萨如果观色是常而行，就不是行般若波罗蜜；观受、想、行、识是常而行，就不是行般若波罗蜜；观色是无常而行，也不是行般若波罗蜜；观受、想、行、识是无常而行，也不是行般若波罗蜜。”五受众、五道等种种五法门，也是如此。其余六、七、八法门，乃至无量法门，也都是如此。

正如摩诃般若波罗蜜无量无边，佛宣说《般若波罗蜜经》的因缘也无量无边。这件事太广，如今简略地说完了摩诃般若波罗蜜的缘起之法。

## 初品“如是我闻一时”释论第二

【经】

如是我闻：一时。

【论】

### 如是

问：诸佛的经，为什么开头都称“如是”？

答：佛法如大海，以信能进入，以智能渡过。“如是”的意义，就是信。如果一个人心中有清净的信，这个人就能进入佛法；如果没有信，这个人就不能进入佛法。不信的人说：“这件事不是这样。”这是不信的相。有信的人说：“这件事就是这样。”譬如牛皮还没有鞣软，就不能弯折；没有信的人也是这样。譬如牛皮已经鞣软，就可以随用途制作器物；有信的人也是这样。

再者，经中说：“信如同手。譬如人有手，进入宝山中，就能随意取宝；有信也是这样，进入佛法中无漏的根、力、觉、道、禅定的宝山，就能随意取得。没有信如同没有手，没有手的人进入宝山，什么也取不到；没有信也是这样，进入佛法宝山，一无所得。”佛说：“如果人有信，这个人就能进入我的大法海中，能得沙门果，不会白白剃头、穿染色的袈裟。如果没有信，这个人就不能进入我的法海，就像枯树不开花、不结果，得不到沙门果；即使剃了头、穿了染衣，读了种种经，能质难、能答辩，在佛法中也是空无所得。”所以，“如是”的意义放在佛法的开头，因为这是善信的相。

再者，佛法深远，唯有佛才能知。人只要有信，即使还没有成佛，凭着信的力量也能进入佛法。如梵天王劝请佛初转法轮，用偈请佛：

```
阎浮提先出，　多诸不净法；
愿开甘露门，　当说清净道！
```

大意：阎浮提先前流行的，多是种种不清净之法；愿佛开启甘露之门，宣说清净之道！

佛以偈回答：

```
我法甚难得，　能断诸结使，
三有爱著心，　是人不能解！
```

大意：我的法极难证得，能断除一切结使；心中贪爱执着三有的人，不能理解我的法！

梵天王对佛说：“大德！世间众生的智慧，有上、中、下之分。心地善良柔软、正直的人，容易得度；这样的人如果听不到佛法，就会退堕到种种恶道苦难之中。譬如水中的莲花，有的初生，有的成熟，有的还在水中未出水面，如果得不到日光照耀，就不能开放。佛也是这样，佛以大慈悲怜悯众生，所以应当为众生说法。”佛忆念过去、未来、现在三世诸佛之法，都是为度化众生而说法，心想：“我也应当这样。”佛这样思惟完毕，接受梵天王等诸天的劝请而说法。那时，世尊用偈回答：

```
我今开甘露味门，　若有信者得欢喜；
于诸人中说妙法，　非恼他故而为说。
```

大意：我如今开启甘露味之门，凡有信心的人都能得到欢喜；我在众人之中宣说妙法，不是为了恼害他人而说。

佛在这首偈中，没有说布施的人得欢喜，也没有说多闻、持戒、忍辱、精进、禅定、智慧的人得欢喜，唯独说有信的人得欢喜。佛的意思是这样：“我第一甚深的法微妙，无量无数，不可思议，不动、不依、不着，是无所得之法，不是一切智人就不能理解。”所以佛法中以信力为最初，信力能使人进入佛法，布施、持戒、禅定、智慧等都不能使人最初进入佛法。如偈中说：

```
世间人心动，　爱好福果报，
而不好福因，　求有不求灭。
先闻邪见法，　心著而深入，
我此甚深法，　无信云何解？
```

大意：世间人的心随境动摇，爱好福德的果报，却不爱好种福的因；追求三有，不求寂灭。先前听闻邪见之法，心已执着而深入其中。对我这甚深之法，没有信心，怎能理解？

如提婆达多的大弟子俱迦梨等人，因为没有信法，堕入恶道之中。俱迦梨没有信，在佛法中想凭自己的智慧去求，求不到。为什么？因为佛法甚深。如梵天王教导俱迦梨的偈：

```
欲量无量法，　智者所不量，
无量法欲量，　此人自覆没！
```

大意：想测量无量之法，这是智者不会去测量的；对无量之法偏要测量，这个人只会自己沉没！

再者，“如是”的意义是：如果一个人心地善良正直、有信，这个人就可以听法；如果没有这样的相，就不能理解。如偈中说：

```
听者端视如渴饮，　一心入于语议中，
踊跃闻法心悲喜，　如是之人应为说。
```

大意：听法的人端正注视，如同口渴的人饮水，一心投入所说的义理之中，听法时欢欣踊跃，心中悲喜交集，对这样的人才应当说法。

再者，“如是”的意义放在佛法开头，因为现世之利、后世之利、涅槃之利，一切利益的根本，都以信为大力。

再者，一切外道出家人，心里认为自己的法微妙，第一清净。这样的人自赞自己所行之法，毁谤他人之法，所以现世就互相打斗争执，后世堕入地狱，受种种无量的苦。如偈中说：

```
自法爱染故，　呰毁他人法，
虽持戒行人，　不脱地狱苦！
```

大意：因为爱染自己的法，诋毁他人的法，即使是持戒修行的人，也免不了地狱之苦！

佛法中，舍弃一切爱、一切见、一切吾我与憍慢，全都断除，不再执着。如《筏喻经》中说：“你们如果理解我说的筏喻之法，那时连善法都应当舍弃，何况不善法？”佛自己对般若波罗蜜，尚且不念、不依，何况对其余的法会有依恋执着？所以，佛法开头称“如是”。佛的意思是这样：“我的弟子不爱法，不染法，不结党派，只求离苦解脱，不对诸法之相作戏论。”如《阿他婆耆经》中摩犍提质难的偈说：

```
决定诸法中，　横生种种想，
悉舍内外故，　云何当得道？
```

大意：对于已经确定的诸法，你却横生种种想法；把内外一切全都舍弃，又怎能得道？

佛回答说：

```
非见闻知觉，　亦非持戒得；
非不见闻等，　非不持戒得。
如是论悉舍，　亦舍我我所，
不取诸法相，　如是可得道。
```

大意：道不是靠见、闻、知、觉得到的，也不是靠持戒得到的；也不是离开见闻等、离开持戒能得到的。这样的种种论议全都舍弃，也舍弃我与我所，不取诸法之相，这样才可以得道。

摩犍提问道：

```
若不见闻等，　亦非持戒得；
非不见闻等，　非不持戒得。
如我心观察，　持哑法得道！
```

大意：如果道既不靠见闻等，也不靠持戒得到；又不是离开见闻、离开持戒能得到，依我心里观察，那就是持守哑法、一言不发才能得道了！

佛回答说：

```
汝依邪见门，　我知汝痴道。
汝不见妄想，　尔时自当哑！
```

大意：你依靠的是邪见之门，我知道你走的是愚痴之道。等你见不到妄想的时候，自然就哑然无言了！

再者，“我的法真实，别人的法虚妄；我的法第一，别人的法不实”，这是争斗的根本。如今“如是”的意义，是向人显示无诤之法：听闻他人所说，宣说的人也没有过失。所以诸佛的经，开头都称“如是”。

“如是”的意义，简略地说完了。

### 我

“我”字，现在来说。

问：如果佛法中说一切法空，一切法中都没有吾我，为什么佛经开头说“如是我闻”？

答：佛的弟子们虽然知道无我，却随顺世俗的说法而说“我”，并不是真实的我。譬如用金钱买铜钱，没有人会笑话。为什么？买卖之法本来就该这样。说“我”也是这样，在无我之法中说“我”，是随顺世俗，不应该质难。如《天问经》中的偈说：

```
有罗汉比丘，　诸漏已永尽，
于最后边身，　能言吾我不？
```

大意：有一位阿罗汉比丘，诸漏已经永远断尽，在最后一生的身中，还能说“我”吗？

佛回答说：

```
有罗汉比丘，　诸漏已永尽，
于最后边身，　能言有吾我。
```

大意：有一位阿罗汉比丘，诸漏已经永远断尽，在最后一生的身中，能够说“我”。

在世界法中说“我”，不是在第一实义中说“我”。所以，诸法空、无我，依世界法的缘故，虽然说“我”，也没有过失。

再者，世间的言语有三种根本：一是邪见，二是慢，三是名字。其中两种不清净，一种清净。一切凡人的言语有三种：邪见、慢、名字；见道的有学圣者有两种：慢、名字；诸圣人只有一种：名字。圣人内心虽然不违背真实之法，却随顺世间人而共同沿用这些言语，除去世间的邪见，所以随顺世俗而不起争执。因此，除去两种不清净的言语，本着随顺世间，只用名字这一种言语。佛的弟子随顺世俗而说“我”，没有过失。

【译注】这三种言语的根本，是本卷解“我”字的要害。同一个“我”字，凡夫说出时夹带着我见与我慢，有学圣者说出时，我见已断，我慢的习气还在，阿罗汉与佛说出时，只是一个称呼。所以问题不在说不说“我”，而在说“我”的那颗心里还剩下什么。

再者，如果有人执着“无吾我”之相，说这才是真实，其余都是虚妄，这样的人就应当被质难：“你主张一切法的实相是无我，为什么又说‘如是我闻’？”如今诸佛弟子，对一切法空、无所有，心中都不执着，也不说执着于诸法实相，何况会对无我之法心生执着？所以，不应当质难为什么说“我”。如《中论》中的偈说：

```
若有所不空，　应当有所空，
不空尚不得，　何况得于空？
凡人见不空，　亦复见于空，
不见见无见，　是实名涅槃。
非二安隐门，　能破诸邪见；
诸佛所行处，　是名无我法。
```

大意：如果有什么是不空的，才应当有什么是空的；不空尚且了不可得，何况能得到空？凡人见到不空，也同样见到空；既不见“见”，也不见“无见”，这才真正名为涅槃。这不落二边的安稳之门，能破除种种邪见；这是诸佛所行之处，名为无我之法。

“我”的意义，简略地说完了。

### 闻

“闻”字，现在来说。

问：所谓“闻”，是怎样闻？是用耳根闻？用耳识闻？还是用意识闻？

如果是耳根闻，耳根没有觉知，就不应当能闻。

如果是耳识闻，耳识只有一念，不能分别，就不应当能闻。

如果是意识闻，意识也不能闻。为什么？先由前五识认识五尘，然后意识才认识；意识不能认识现在的五尘，只能认识过去、未来的五尘。如果意识能认识现在的五尘，那么盲人、聋人也应当能认识声音与色相。为什么？因为盲人、聋人的意识并没有损坏。

答：不是耳根能闻声，也不是耳识，也不是意识。能闻声这件事，是众多因缘和合而得以闻声的，不能说某一个法能闻声。为什么？耳根没有觉知，所以不应当能闻声；识没有色、没有对碍、没有处所，所以也不应当能闻声；声音没有觉知，也没有根，所以不能知道声音。闻声的时候，耳根没有损坏，声音到达可以听到的地方，心意想要听，根、尘、意三者和合，所以耳识生起；随着耳识，意识随即生起，能分别种种因缘，于是得以闻声。所以不应当这样质难：“是谁在闻声？”佛法中也没有任何一个法能作、能见、能知。如偈中说：

```
有业亦有果，　无作业果者，
此第一甚深，　是法佛能见。
虽空亦不断，　相续亦不常，
罪福亦不失，　如是法佛说。
```

大意：有业，也有果，却没有造业者、受果者，这是第一甚深之处，唯有佛能照见。虽然是空，却不断灭；虽然相续，却不是常；罪与福也不会失坏。这样的法，是佛所宣说。

“闻”的意义，简略地说完了。

### 一

“一”字，现在来说。

问：佛法中，数、时等法实际上是无，因为数、时不被五阴、十二入、十八持（十八界）所摄。为什么说“一时”？

答：随顺世俗而说“一时”，没有过失。譬如用泥土、木头等画塑天神的像，因为忆念天神而礼拜，没有过失。说“一时”也是这样，虽然实际上没有“一时”，随顺世俗说“一时”，没有过失。

问：不应当没有“一”！

佛自己说：“一人出世间，众人得到安乐，这是什么人？就是佛世尊。”

又如偈中说：

```
我行无师保，　志一无等侣，
积一行得佛，　自然通圣道。
```

大意：我修行没有师傅保护，心志专一，没有同伴；积累专一的修行而成佛，自然通达圣道。

像这样，佛处处说“一”，所以应当有“一”。

再者，因为有“一”这个法和合在物上，物才称为“一”。如果真的没有“一”这个法，为什么对一个物生起一个心念，不是两个、三个？对两个物生起两个心念，不是一个、三个？对三个物生起三个心念，不是两个、一个？如果真的没有种种数，那么对一个物应当会生起两个心念，对两个物应当会生起一个心念；三、四、五、六等也都会如此错乱。所以，可以确定一个物上有“一”这个法，因为“一”这个法和合在物上，所以对一个物生起一个心念。

答：如果“一”与物是同一，或者“一”与物是相异，两种都有过失。

问：如果是同一，有什么过失？

答：如果“一”与“瓶”是同一个意义，就像因提梨与释迦（都是帝释天的名号）是同一个意义。如果这样，凡是有“一”的地方，就都应当是瓶；譬如凡是有因提梨的地方，处处也就有释迦。

那么现在衣服等各种物品都应当是瓶，因为“一”与“瓶”是同一的。这样，处处的“一”都应当是瓶；瓶、衣服等全都成了同一个物，没有分别。

再者，“一”是数法，“瓶”也应当是数法。瓶体有五种法，“一”也应当有五种法。瓶有色、有对碍，“一”也应当有色、有对碍。

如果处处的“一”不称为瓶，那么现在就不应当说“瓶”与“一”同一！如果说“一”时不涵摄瓶，那么说“瓶”时也不涵摄“一”。

因为“瓶”与“一”不异，那么想说“一”时，就应当说成瓶；想说“瓶”时，就应当说成“一”，这样就错乱了。

问：同一有这样的过失，相异又有什么过失？

答：如果“一”与瓶相异，瓶就不是“一”；如果瓶与“一”相异，“一”就不是瓶。如果瓶与“一”结合，瓶就称为“一”，那么“一”与瓶结合，为什么不把“一”称为瓶？所以不能说瓶与“一”相异。

问：虽然因为与“一”这个数结合，瓶成为“一”，但“一”并不因此成为瓶。

答：诸数以“一”为开端。“一”与瓶相异，所以瓶不能成为“一”；“一”既然没有，“多”也就没有。为什么？因为先有“一”，后才有“多”。这样，在相异中，“一”也不可得。所以，在同一、相异两门中寻求“一”这个法，都不可得；既然不可得，怎么会被五阴、十八界、十二入所摄？只是佛的弟子随顺世俗的言语，称为“一”，心里实际上不执着，知道数法只是名字上的有。所以，佛法中说一人、一师、一时，不会落入邪见的过失。

“一”的意义，简略地说完了。

### 时

“时”字，现在来说。

问：天竺称“时”的名词有两种：一叫迦罗，二叫三摩耶。佛为什么不说迦罗，而说三摩耶？

答：如果说迦罗，同样也会有疑问。

问：因为说起来轻便容易，应当说迦罗。迦罗只有两个字，三摩耶有三个字，说起来繁重困难。

答：为了除去邪见，所以说三摩耶，不说迦罗。

【译注】迦罗（kāla）是当时外道立为实有之法的“时”，被看作万物生成的因；三摩耶（samaya）意为时节、时分，只是就事相的推移而说的假名。佛舍去轻便的迦罗，选用繁重的三摩耶，本身就是一次破执：经题的第一个时间词，已经不给“实有之时”留下立足之地。

问：有人说：“一切天地间的好与丑，都以时为因。如《时经》中的偈说：

```
时来众生熟，　时至则催促，
时能觉悟人，　是故时为因。
世界如车轮，　时变如转轮，
人亦如车轮，　或上而或下。
```

大意：时节到来，众生成熟；时节一到，便催促万物；时能使人觉悟，所以时是万物之因。世界如同车轮，时的变迁如同轮在转动，人也如同车轮，有时在上，有时在下。”

又有人说：“天地间的好丑一切事物虽然不是时所造作，但时是不变的因，是实有的。时法微细，不可见、不可知，但凭着花、果等结果，可以知道有时。往年、今年，久与近，慢与快，见到这些相，虽然见不到时本身，也可知道有时。为什么？因为见到果，就知道有因。所以有时法；时法不会毁坏，所以是常。”

答：比如泥团是现在时，土尘是过去时，瓶是未来时。按你们的说法，时的相是常，那么过去时就不能变成未来时。依你们经书的说法，时是一个东西，那么过去世既不能变成未来世，也不能变成现在世，否则就犯了三世相杂的过失。过去世中也没有未来世，所以就没有未来世；现在世也是如此。

问：你既然承认土尘是过去时，如果有过去时，就必定应当有未来时，所以时法是实有的。

答：你没有听到我先前说的吗？未来世是瓶，过去世是土尘。未来世不能变成过去世；土尘落在未来世的相中，就是未来世之相的时，怎么能称为过去时？所以，过去时也没有。

问：为什么说没有时？必定应当有时。现在有现在的相，过去有过去的相，未来有未来的相。

答：如果让三世一切时都各有自相，那就应当全都是现在世，没有过去时、未来时。如果现在就有未来，那就不叫未来，应当叫现在。所以，这话不对！

问：过去时、未来时并不在现在的相中运行：过去时在过去世中运行，未来时在未来世中运行。所以，各自的法相上都有时。

答：如果过去时又再过去，就破坏了过去的相；如果过去时不过去，就没有过去的相。为什么？因为舍弃了自相。未来世也是这样。所以，时法不是实有的，怎么能生出天地间的好丑以及花果等种种事物？像这样，为了除去种种邪见，佛不说迦罗之时，而说三摩耶。见到五阴、十八界、十二入的生灭，假名为时，另外没有一个时。

所谓方位、时间、分离、结合、一、异、长、短等名字，出自凡人之心的执着，凡人认为这些都是实有之法。所以，要除弃这些世间的名字言语之法。

问：如果没有时，为什么允许“时食”、遮止“非时食”，并以此作为戒律？

答：我先前已经说过：“世间名字之法是有，时却不是实法。”你不应当质难！再者，这是律中制定戒条之法，在世间中是真实的，并不是第一实法之相，因为吾我之法相实际上不可得；制戒也是为了避免众人的瞋怒呵责，也是为了护持佛法使之长久住世，为了确定弟子们的礼法。三界世尊制定这些戒律，对于戒律，不应当去追究：有什么实体？有什么名字等？什么相应？什么不相应？什么法是这样的相？什么法不是这样的相？所以，这件事不应当质难！

问：如果“非时食”“时药”“时衣”中的“时”，都是柯逻（迦罗），为什么不说三摩耶？

答：这是在律中所说的，在家白衣都不得听闻，外道又从哪里能听闻而生起邪见！其余的经，一般人都能听闻，所以说三摩耶，使听者不生邪见。三摩耶是权设的名称，“时”也只是假名的称呼。再者，佛法中多说三摩耶，少说柯逻；因为说得少，不应当质难。

“如是”“我”“闻”“一”“时”这五个词，各自的意义简略地说完了。

## 本卷要义

缘起二十余条，看似散列，其实一条线贯穿始终：佛要说的，是众生测度不到、也执取不住的东西。前半段反复说佛身不可测、一切智不可疑、出生即能行能语却示现如同常人，破的是众生对佛的低估。后半段转入四悉檀、长爪梵志、诤与无诤、三门四门五门的“异门”，破的是众生对法的占有。众生进入佛法时，最先带进来的正是这两样：用凡情量佛，用见解抓法。般若必须宣说，因缘就在这里。

四悉檀是全卷的枢纽。龙树没有把佛语分成真话与方便话，而是说四种悉檀“各各有实”。人在世界悉檀上真有，在第一义上真无；真如在世界悉檀上无，在第一义上有。无常观在对治上是良药，在第一义上不是诸法的实性，若把无常立为实性，连业与果报都无从成立。由此可以看清第一义悉檀的身份：第一义并不是第四种立场，与前三种争高下；第一义是“三悉檀中所不通者，此中皆通”的那个所在。一切论议都可破可散，诸圣所行之法不可破不可散，原因不在第一义最强，原因在第一义不立一宗，本来就没有可以被破的东西。

长爪梵志一段，是第一义悉檀的现场演示。长爪的“一切论可破”，已经走到怀疑的尽头，表面上与般若的“不受”几乎一样。佛只问一句：“这个见解你受不受？”“一切不受”一旦被当作立场来持守，就又是一个见；连这个见也放下，就与众人无异，憍慢再无依托。般若与怀疑论的分界，就在这一问上：怀疑论破尽一切，却还守着“破尽”这个位置；般若连这个位置也不守。所以龙树说，长爪若没有听闻般若的气分，“小信尚不得”。怀疑到底的人，唯有遇到不立宗的法，才肯低头。佛“不彰我负”，也不只是宽厚，无诤之法本来就没有赢家。

“如是我闻一时”五个字的解释，是龙树把同一个方法落到最平常的字上。“如是”是信，而佛法所要的信，内容恰恰是不爱自法、不毁他法，信在这里既是入门，也就是无诤。“我”是随俗的名字，要紧处不在说不说“我”，在说“我”的那颗心里还剩下邪见、慢，还是只剩名字。“闻”是根、尘、意和合，没有一法能闻；“一”在同一、相异两门中求不可得；“时”只是五阴、十八界、十二入生灭上的假名，所以佛特意选用三摩耶，不用迦罗。五个字逐一解开，又逐一照用：世俗名言一个不废，心中一个不着。缘起段立下的四悉檀，就在经文第一行上实地施行了一遍。

本卷最后落在戒律的“时食”上，看似琐碎，收束却极稳。律中的“时”是世界中实，为护持佛法久住、为免众人讥呵、为确定弟子礼法而立，不必追问“时”在第一义中有无实体。空性不拆毁戒律，戒律也不必冒充实法。般若的毕竟空，从第一卷起就不是取消世间，而是让世间的一切，各自回到各自真实的那一层。
