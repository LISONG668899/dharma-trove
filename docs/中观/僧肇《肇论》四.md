# 僧肇《肇论》四　刘遗民书问与答书

按：《般若无知论》写成后，道生法师把论带到南方庐山。庐山慧远门下的居士刘遗民读后，与慧远一起详读，写信向僧肇提了三个疑问。僧肇回信逐一作答。刘遗民问得精，僧肇答得透，这一来一回，把《般若无知论》最难的地方又磨了一遍。

## 刘遗民书问

遗民合掌致敬。近来饱闻您的美名，心怀遥望。岁末尚未严寒，您身体如何？音信阻隔，更增怀念。弟子在草泽中久病，常有疲病。借慧明道人北游的机会，略通情意。古人不因形迹疏远而交情淡薄，悟境相通就是亲近。所以江山遥远，当年未曾见面，企慕风范、以心镜映照您的形迹，伫立喜悦的心情，确实深切。遥远无缘相见，只能望霞长叹。望您顺应时节，爱惜身体，希望借着行旅之便，多有问候。伏愿那边大众康和，外国法师鸠摩罗什安好。上人以悟发之器，遇到深渊般的对答，想必开究之功，足以思过半。所以每想到分隔之远，愤愧何深。

这里山中僧众清净如常，道戒更加精进，禅隐之余，就研究讲习，恂恂穆穆，实在可乐。弟子既已遂了夙愿，又看到这样的上轨，感寄之诚，日月铭记。远法师近来一直安好，思业精深，日夜勤勉，若不是道用潜流、理为神御，谁能在年过六十，还有如此湛然之气的精勤？所以依凭安慰之情既深，仰慕感谢更甚。

去年夏末，才见到道生上人出示的《般若无知论》，才思运用清俊，旨趣深沉允当，推究圣文，婉转而有归宿。披阅品味，殷勤不能释手。真可谓沐浴心于方等之渊，悟怀于绝冥之所。若此辨能通，般若众流，几乎不言而会，能不欣喜吗？能不欣喜吗？道理微妙，言辞就艰险；唱得独特，应和就稀少。若不是超绝言象之表的人，就会执着形象，导致乖离。弟子认为回答"以缘求智"那一章，婉转穷尽，极为精巧，无可挑剔。愚暗的人难以顿时明白，还有一两处余疑，现在另外列出，想您从容之暇，再能略为解释。

论序说：般若之体，非有非无，虚不失照，照不失虚，所以说不动等觉而建立诸法。下章说：异于人的是神明，所以不可以事相求之。又说：用即寂，寂即用；神弥静，应逾动。圣心冥寂，理极同于无，不疾而疾，不徐而徐。所以知不废寂，寂不废知，未始不寂，未始不知。所以圣人运物成功、化世之道，处在有名之中，远与无名相同。这道理的玄妙，确实常常使人迷昧。

第一个疑问：如今谈论的人，疑于高论的宗旨，想求圣心与常人的差异：是说圣心穷尽灵妙、极尽诸数，妙尽而冥符真理呢？还是说圣心体性自然，灵妙淡泊，独自感应呢？若是穷灵极数、妙尽冥符，那寂照之名，就是定慧之体。若是心体自然、灵泊独感，那对群数的应会，就几乎止息了。心数既玄，孤运其照，神淳于化表，慧明独存，应当有深刻的证据，可以试为辨明。

第二个疑问：疑者认为，抚会应机、睹见变化的知，不可以说是没有。论旨说本无惑取之知，没有解释不取的道理。弟子认为应先确定圣心应会之道：是只照无相呢？还是遍睹种种变化？若睹见变化，就异于无相；若只照无相，就无会可抚。既然无会可抚，又有抚会之功，意思还不明白，希望再加教诲。

第三个疑问：论中说：无当，则物无不当；无是，则物无不是。物无不是，所以是而无是；物无不当，所以当而无当。弟子认为，无当而物无不当，正是至当；无是而物无不是，正是真是。哪有真是而非是、至当而非当，论中为什么说当而无当、是而无是呢？若说至当不是常当，真是不是常是，那是悟者与惑者的言语本来不同，所以论旨不明。愿再加譬喻，以除迷惑。

论到的那天，弟子就与远法师详细审阅，法师也很领会其意，标位似乎各有根本，或许不一定道理完全相同。近来又把论分给诸位有心人，常有击节赞赏的，遗憾不能与作者同时。

按：刘遗民的三个疑问，每一个都是一道两难，读者先把两难看清楚：

- 第一问：圣心的寂照，是修定修慧修到极点的成果，还是心体本来自然？若是修出来的，寂照就只是定慧的另一个名字；若是本来自然，圣心就没有理由去应会众生。
- 第二问：圣心照的是无相，还是看见种种变化？看见变化，就有了相；只照无相，就无法应会众生。
- 第三问：论中说"无是"才是"真是"，那就应该承认有一个"真是"。论中为什么偏要说"是而无是"？

## 僧肇答书

未曾见面，伫想劳神。慧明道人到来，得到去年十二月的信和问。翻来覆去披寻，欣喜如同暂时相对。凉风应节，近来如何？贫道多病，信使南返，不能详述。八月十五日，释僧肇答。

服饰形象不同，妙期不二；江山遥远，理契就是邻居。所以望途致想，虚怀有寄。您既遂了嘉遁之志，标举越俗之美，独自恬淡于事外，欢乐满足于方寸，每一次言谈，何尝不深远。譬如林下雅咏，高致悠然。清散未期，望厚自保重。每借行旅之便，多有问候。愿那边山僧无恙，道俗都好。

得知远法师安好，以为欣慰。未能亲承教诲，服膺远公的高轨，企仰已久。远公年过六十，湛然之气更加严厉，在幽岩中培养徒众，守一于冲虚的山谷，远近仰咏，何其美好。贫道也常翘首遥想那一隅，悬望荫庇于霄岸，无由表达敬意，感慨良深。您终日清谈，想必快有悟心之欢。

这里大众如常，什法师安好。秦王道性自然，天机超俗，以三宝为城堑，以弘道为要务。由此异典胜僧，从远方而来，灵鹫山之风，荟萃此土。支法领远行求法，是千载的津梁。法领从西域回来，得到方等新经二百余部，请来大乘禅师一人、三藏法师一人、毗婆沙法师二人。什法师在大石寺翻出新到诸经，法藏渊旷，日有异闻。禅师在瓦官寺教习禅道，门徒数百，日夜不懈，雍雍肃肃，实在可喜。三藏法师在中寺翻出律藏，本末精悉，如睹最初制戒。毗婆沙法师在石羊寺出《舍利弗阿毗昙》胡本，还未翻译，时时问及论中之事，发言新奇。贫道一生，忝参嘉运，遇此盛化，只恨未见释迦祇洹之集，其余还有什么遗憾？感慨的是不能与清胜君子同此法集。

道生上人近来在此，同住数年，言谈之际，常常称咏您。道生中途回南，您得与相见，贫道未曾再近问候，惆怅何言。威道人来，得到您的《念佛三昧咏》，又得远法师的《三昧咏》及序。这些作品兴寄既高，辞致清婉，能文之士都称其美，可谓游涉圣门、叩问玄关之唱。您与远法师应常有文集，带来的为何这样少？什法师于午年译出《维摩经》，贫道当时参与听讲，参承之暇，就条记成言，作为注解，文辞不够文雅，义理有所本。今托信使带一本往南，您闲时可取来看看。

来问婉转恳切，难做一个善于应和的人。贫道思不及微，又拙于笔语，并且至趣无言，言必乖趣，喋喋不休，到底能辨明什么？姑且用狂言，酬答来意。

来信说：圣心冥寂，理极同无，处在有名之中，远与无名相同，这道理的玄妙，常使人迷昧。贫道认为，以此为怀，自可忘言内得，取定于方寸，又何必以人情的差异，来求圣心的差异呢？

### 答第一问

来信说：谈者认为，若是穷灵极数、妙尽冥符，寂照之名就是定慧之体；若是心体自然、灵泊独感，群数之应就几乎止息了。

贫道认为：妙尽冥符，不可以用定慧来命名；灵泊独感，不可说群数之应止息。两种说法不同，妙用常常是一。在常人这边看，就有差别；在圣人那边，没有差别。为什么？圣人玄心默照，理极同于无。既然说同，就没有不同的地方，哪里有同于无之极、又有定慧之名？定慧之名，不是在"同"之外另立的称呼。若名称生于"同"之内，有名称就不是同；若名称生于"同"之外，名称就不是圣心本身。又，圣心虚微，妙绝常境，感无不应，会无不通，冥机潜运，其用不勤，群数之应，又为何会止息？

心之所以有，是因为有一个"有"。有不能自己成为有，所以圣心不有那个有；不有那个有，所以有就是无有；有就是无有，所以也无"无"；无"无"，所以圣人不有不无；不有不无，圣人的神才是虚的。为什么？

夫有也无也，心之影响也；言也像也，影响之所攀缘也。

（大意：有与无，是心投出的影子和回声；言语与形象，是攀缘在影子和回声上的东西。）

有无既废，心就没有影子回声；影子回声既然沉没，言象就无法测度；言象无法测度，道就超绝于一切方所；道超绝于一切方所，所以能穷灵极数；穷灵极数，就叫作妙尽。妙尽之道，本于无所寄托。无所寄托在于冥寂；冥寂断绝，所以以虚通之。妙尽存于极数；极数，所以以数应之。以数应之，所以动与事会；以虚通之，所以道超名外。道超名外，因而称为无；动与事会，因而称为有。称为有，是为了应对世人"真有"的观念，勉强这样说罢了，圣心哪里是这样？

所以经说：圣智无知而无所不知，无为而无所不为。这无言无相寂灭之道，岂是有就成为有，无就成为无，动就乖违静，静就废弃用？如今谈者，多依言语确定宗旨，在大方之中寻求一隅，怀着先入之见来标举玄理，认定所存的见解必然恰当。所以听说圣人有知，就说圣人有心；听说圣人无知，就说圣人等同太虚。有无之境，是边见所存，岂是处中不二之道？

为什么？万物各异，本性常一。不可以把万物当作物，万物又不是非物。把物当作物，名相就纷然各异；不把物当作物，物就当下即真。所以圣人不把物当作物，也不把物当作非物。不把物当作物，物不是有；不把物当作非物，物不是无。非有，所以不取；非无，所以不舍。不舍，所以妙存即真；不取，所以名相无从依附。名相无从依附，不是有知；妙存即真，不是无知。所以经说：般若于诸法，无取无舍，无知无不知。这是攀缘之外、绝心之域，想用有无来诘问，不是太远了吗？

请问陈说有无的人：智的生起，止于相内；法本无相，圣智知什么？世人所说的无知，等同木石、太虚等无情之类；圣智灵鉴幽烛，照见形于未兆，道无隐藏的机微，怎能说无知？况且圣智的无知，生于无知：没有一个"无知"，也没有一个"有知"。没有"有知"，叫作非有；没有"无知"，叫作非无。所以虚不失照，照不失虚，淡然永寂，无执无拘，谁能动之令有，静之使无？

所以经说：真般若非有非无，无起无灭，不可说示于人。为什么？说非有，是说不是"是有"，不是说"是非有"；说非无，是说不是"是无"，不是说"是非无"。非有，也非非有；非无，也非非无。所以须菩提终日说般若，说无所说。这是绝言之道，知识如何传达？希望参玄的君子，能有所会。

按：七寸在"有也无也，心之影响也"。刘遗民的问题本身预设了：圣心要么是修出来的，要么是本来自然的，两者必居其一。僧肇说，"修出来的有"和"本来自然的无"，都是心投出的影子。圣心不在影子里，所以两个选项都套不上圣心。"非有非非有"也不是在有无之外另立第三个立场，第三个立场仍然是影子。

### 答第二问

来信又说：应先确定圣心应会之道，是只照无相，还是遍睹种种变化？

谈者似乎认为，无相与变化旨趣不一：睹见变化就异于无相，照无相就失去抚会。如此，"即真"的意义或许有所滞碍。经说：色不异空，空不异色，色即是空，空即是色。若照来信的意思，观色与空时，应当一心见色，一心见空。若一心见色，就只有色，没有空；若一心见空，就只有空，没有色。如此空与色两边并陈，确定不了根本。

所以经说"非色"，确实是在色上说非色，不是在非色上说非色。若在非色上说非色，太虚就是非色，非色还说明什么？若在色上说非色，非色就不异于色；非色不异于色，色就是非色。所以知道：

变即无相，无相即变。

（大意：变化就是无相，无相就是变化。）

众生之情不同，所以教迹有异。考察玄籍，依据圣意，岂有真伪两种心、空有两种照？所以照无相，不失抚会之功；睹变动，不违无相之旨。造作于有，不异于无；造作于无，不异于有。未尝不有，未尝不无。所以说不动等觉而建立诸法。由此推之，寂与用有何妨碍？怎么说睹见变化的知，异于照见无相的照？

恐怕谈者以为空有是两种心，静躁是两种作用，所以说睹见变化的知不可说没有。若能舍弃自心于封域之内，寻求玄机于事外，齐万有于一虚，晓得至虚不是无，就会说：至人终日应会，与物推移，乘运抚化，从来不是有。圣心如此，有什么可取？还说没有解释不取的道理？

按：七寸在于"在色上说非色"。刘遗民把"照无相"和"看见变化"当成两种心，一种住在空里，一种住在色里。僧肇用"色即是空"来答：非色就在色上，不在色之外另找一个非色。所以看见变化的当下，就是照见无相。不需要两种心，也不需要来回切换。

### 答第三问

来信又说：无是乃所以为真是，无当乃所以为至当。

也可以照来信说的那样。若能无心于为是，就在无是中是；无心于为当，就在无当中当。这样终日是，不违无是；终日当，不违无当。只怕在无是中有一个"是"，在无当中有一个"当"，这才是祸患。为什么？若真是可以被认定为是，至当可以被认定为当，名相就显形，美恶就产生，生生奔竞，谁能止息？

所以圣人空洞其怀，无识无知，居于动用之域，止于无为之境；处于有名之内，宅于绝言之乡；寂寥虚旷，不能以形名得到，如此而已。来信说真是可以认定为是、至当可以认定为当，贫道不能明白来信的意思。恐怕是与当的产生，是物认为如此，圣心本身并不如此，何足以认定为如此？

言语与行迹的兴起，是不同道路产生的原因。言有所不能言，迹有所不能迹。所以：

善言言者，求言所不能言；善迹迹者，寻迹所不能迹。

（大意：善于用言说的人，求言说所不能言说的；善于循行迹的人，寻行迹所不能显示的。）

至理虚玄，起心思量已经差了，何况有言语？恐怕所示更远。希望通心的君子，能相期于文字之外。

按：七寸在"有是于无是"。刘遗民想把"无是"升格为"真是"，承认有一个最高的"是"。僧肇说：一旦有一个可以被认定的"真是"，名相就又出来了，美恶也出来了，争竞也出来了。"真是"就在"无是"之中，不能把"无是"本身立成一个"是"。《般若无知论》第八难分"无知"与"知无"，第六难说"以无相为无相，无相即为相"，与这一答是同一个道理：不要把否定立成一个新的肯定。
