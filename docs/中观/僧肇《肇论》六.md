# 僧肇《肇论》六　涅槃无名论（下）

## 九折十演（续）

### 难差第八（有名折）

有名说：涅槃既然断绝图度之域，就超出六境之外，不出不在，玄道独存。这是穷理尽性的究竟之道，妙一无差，道理确实如此。《放光般若经》说：三乘之道，都因无为而有差别。佛说：我从前为菩萨时，名叫儒童，在然灯佛处已入涅槃。儒童菩萨当时在七住初获无生忍，又进修三位。若涅槃是一，就不应有三；若有三，就不是究竟。究竟之道，又有升降的不同，众经说法各异，怎样取其中正？

按：有名的第四折：涅槃既然只有一个，为什么有声闻、缘觉、菩萨三乘的差别？为什么菩萨证了无生忍还要继续往上修？

### 辩差第九（无名演）

无名说：究竟之道，理上没有差别。《法华经》说：第一大道，没有两个正道。佛以方便为懈怠的人，在一乘道上分别说三。三车出火宅，就是这件事。因为同样出离生死，所以同称无为；所乘不一，所以有三个名称。总括其会归，只有一个。

问难说：三乘之道，都因无为而有差别。这是人有三种，在无为上分成三，不是无为本身有三。所以《放光般若经》问：涅槃有差别吗？答：无差别。差别在于如来结习都尽，声闻结习不尽。请用近处的比喻，说明远处的旨趣：

如人斩木，去尺无尺，去寸无寸。修短在于尺寸，不在无也。

（大意：好比砍木头，砍掉一尺，就没了一尺；砍掉一寸，就没了一寸。长短的差别在于砍掉了一尺还是一寸，不在于"没了"本身。）

众生万端，识根不一，智鉴有深浅，德行有厚薄，所以同到彼岸，升降不同。彼岸哪里有异？差异在自己。如此，众经所辨不同，旨趣并不违背。

按：辩差第九，七寸在斩木之喻。"无"本身没有大小，有大小的是被去掉的那一部分。三乘断的烦恼多少不同，所以显出差别；涅槃作为"断尽之处"，本身没有差别。差别在人，不在无为。

### 责异第十（有名折）

有名说：同出火宅，免于祸患是一样的；同出生死，无为是一样的。论中说彼岸无异，差异在自己。彼岸，就是无为之岸；"自己"，就是体证无为的人。请问：自己与无为，是一还是异？若自己就是无为，无为也就是自己，就不能说无为无异、差异在自己。若自己异于无为，自己就不是无为，无为自是无为，自己常是有为，冥会的旨趣，又滞而不通了。如此，自己与无为，是一也没有三，是异也没有三，三乘之名从何而生？

按：有名的第五折很尖锐：人与涅槃，是一还是二？若是一，人的差别就是涅槃的差别；若是二，人永远到不了涅槃。

### 会异第十一（无名演）

无名说：停在这里就是这里，到了那里就是那里。所以同于得的人，得也得到他；同于失的人，失也失去他。我到了无为，我就是无为。无为是一，为什么不能有不一？

譬犹三鸟出网，同适无患之域。无患虽同，而鸟鸟各异。

（大意：好比三只鸟逃出罗网，同到没有祸患的地方。没有祸患这一点相同，鸟与鸟各不相同。）

不可以因为鸟与鸟各异，就说无患也异；又不可以因为无患是一，就把众鸟也看成一只。如此，鸟就是无患，无患就是鸟。无患哪里有异？差异在鸟。

三乘众生也是如此，同样超越妄想的樊笼，同到无为之境。无为相同，所乘各异。不可以因为所乘各异，就说无为也异；又不可以因为无为是一，就把三乘也看成一。如此，我就是无为，无为就是我。无为哪里有异？差异在我。所以无患相同，飞升的虚空有远有近；无为是一，幽深的鉴照有浅有深。无为就是乘，乘就是无为。不是我异于无为，是因为还没有穷尽无为，所以有三。

按：会异第十一，七寸在"未尽无为，故有三耳"。有名逼问一与异，无名用三鸟作答：鸟逃出网，就在"无患"之中，鸟与无患不是两个；三只鸟飞得远近不同，是鸟的差别。人证入无为，就在无为之中；证得深浅不同，是人的差别。差别出在"还没有穷尽"，不出在无为本身。

### 诘渐第十二（有名折）

有名说：万累滋长，根本在于妄想；妄想既然祛除，万累就都止息。二乘得尽智，菩萨得无生智，这时妄想都尽，结缚永除。结缚既除，心就无为；心既无为，理上就没有余翳。经说：诸圣智慧不相违背，不出不在，其实都是空。又说：无为大道，平等不二。既然说无二，就不容心有差异。不体证则已，体证就应穷尽微细。论中说体证了还未穷尽，我还不明白。

按：有名的第六折：妄想要么断了，要么没断，哪有"断了一部分"？证悟应当是一次性的，为什么还有渐次？

### 明渐第十三（无名演）

无名说：无为无二，确实如此。结使是重重的迷惑，说能一下子全部断尽，我还不能认同。经说：三箭射中靶子，三兽渡过河流。射中与渡过没有差异，深浅有别，是因为力量不同。三乘众生，同渡缘起之津，同鉴四谛之的，断绝虚伪，契入真实，同升无为。所乘不一，也是因为智力不同。

群有很多，数量终有边际。即使智慧像舍利弗，辩才像富楼那，穷尽才智思虑，也看不到群有的边际。何况虚无之数、重玄之域，其道无涯，想要一下子全部穷尽？《老子》不是说吗：为学日益，为道日损。为道，是为于无为。为于无为，又说日损，这哪里是一下子得到的意思？要损之又损，以至于无可损。经中以萤火与日光相比喻，智慧作用的大小就可以知道了。

按：明渐第十三，七寸在"三箭中的，三兽渡河"。三支箭都射中了靶，射入的深浅不同；三只兽都渡过了河，兔子浮水，马蹄半沉，大象踏到河底。中靶与渡河是一样的，深浅是力量的差别。证悟的方向一样，证悟的深浅一层层不同，所以说"损之又损"。

### 讥动第十四（有名折）

有名说：经中说法身以上入无为境，心不可以智知，形不可以像测，体绝阴入，心智寂灭。经中又说进修三位，积德更广。进修源于爱好崇尚，积德生于涉入追求。爱好崇尚就有取舍之情现前，涉入追求就有损益交互陈列。既然以取舍为心，以损益为体，又说体绝阴入、心智寂灭，经文前后乖违，旨趣各异，又会合在一个人身上，无异于指南为北，来晓谕迷路的人。

按：有名的第七折：法身菩萨已经心智寂灭，为什么还要"进修""积德"？修就有取舍，有取舍就不是寂灭。

### 动寂第十五（无名演）

无名说：经中说圣人无为而无所不为。无为，所以动的当下常寂；无所不为，所以寂的当下常动。寂的当下常动，所以物不能使圣人成为一；动的当下常寂，所以物不能使圣人成为二。物不能使圣人成为二，所以越动越寂；物不能使圣人成为一，所以越寂越动。所以为就是无为，无为就是为，动与寂名称不同，不可以说有异。

《道行般若经》说：心亦不有亦不无。"不有"，不像有心那样的有；"不无"，不像无心那样的无。为什么？有心的是普通众生，无心的是太虚。众生止于妄想，太虚断绝灵照。怎么可以用止于妄想、断绝灵照来标举神道、谈论圣心？所以圣心不有，不可以说是无；圣心不无，不可以说是有。不有，所以心想都灭；不无，所以理无不契。理无不契，所以万德弘广；心想都灭，所以功成而非我。所以应化无方，从未有为；寂然不动，从未不为。经说：心无所行，无所不行。确实如此。

儒童菩萨说：我在过去无数劫中，国土、财物、身命，施舍给人无数，是以妄想心布施，不算是布施。如今以无生心，用五朵花供佛，才叫作布施。又有空行菩萨，入空解脱门，才说现在是行持的时候，不是证入的时候。所以：

心弥虚，行弥广，终日行，不乖于无行者也。

（大意：心越虚空，行越广大；终日在行，不违背无行。）

所以《贤劫经》称颂无所舍的布施，《成具光明经》赞美不为之为，禅经宣扬无缘之慈，《思益经》演说不知之知。圣旨虚玄，文字不同，所辨相同。怎能因为有为就认定是有为，因为无为就认定是无为？菩萨住于尽与不尽的平等法门，不尽有为，不住无为，就是这件事。用南北作比喻，完全不是领会的说法。

按：动寂第十五，七寸在"心弥虚，行弥广"。有名以为修行一定要有取舍之心，所以修行与寂灭是对立的。无名举儒童菩萨为例：过去以妄想心布施，施得再多也不算真布施；以无生心献五朵花，才是真布施。心空了，行才真正广大起来；行越广大，心越不需要执着。这也正是大颠"应机随照，泠泠自用"的意思。

### 穷源第十六（有名折）

有名说：没有众生，就无法驾驭三乘；没有三乘，就无法成就涅槃。所以必定先有众生，后有涅槃。如此，涅槃有开始；有开始必定有终结。经说涅槃无始无终，湛若虚空，那么涅槃就是先有的，不是学了以后才成就的。

按：有名的第八折，拿时间来逼问：涅槃若是修成的，就有开始，有开始就有结束；涅槃若是本有的，修行又有什么用？

### 通古第十七（无名演）

无名说：至人空洞无象，万物无一不是至人所造。

会万物以成己者，其唯圣人乎？

（大意：会合万物来成就自己的，只有圣人吧？）

为什么？非理不圣，非圣不理。理而为圣，圣不异于理。所以天帝问：般若当于何处求？须菩提说：般若不可在色中求，也不离色中求。又说：见缘起就是见法，见法就是见佛。这就是物我不异的明证。

所以至人在未兆之时收敛玄机，在即化之中藏冥运；总合六合以镜照其心，统一去来以成就其体。古今相通，始终相同，穷本极末，没有两样，浩然大均，这就叫作涅槃。经说：不离诸法而得涅槃。又说：诸法无边，所以菩提无边。由此知道，涅槃之道在于妙契；妙契之致，本于冥一。如此，物不异于我，我不异于物，物我玄会，归于无极。进不在先，退不在后，岂容有终始于其间？天女说：耆年的解脱，又有多久呢？

按：通古第十七，七寸在"古今通，始终同"。有名把涅槃放在时间线上，问涅槃从哪一刻开始。无名说：涅槃不在时间线上，"开始"与"结束"本身就是要被超越的有无之数。天女反问舍利弗"你的解脱有多久"，意思是解脱根本不能用长短来量。

### 考得第十八（有名折）

有名说：经说众生之性，极于五阴之内；又说得涅槃的人五阴都尽，譬如灯灭。如此，众生之性在五阴之内全部穷尽，涅槃之道独立于三有之外，遥远地分属两个领域，不再是众生得到涅槃。若真有得，众生之性就不止于五阴；若众生之性必止于五阴，五阴就不会都尽；五阴若都尽，谁去得涅槃？

按：有名的最后一折最致命：众生就是五阴；涅槃要五阴灭尽；五阴灭尽，众生也没了。那么，是谁得涅槃？

### 玄得第十九（无名演）

无名说：真由离而起，伪因着而生。着，所以有得；离，所以无名。所以效法真的人同于真，效法伪的人同于伪。

子以有得为得，故求于有得耳；吾以无得为得，故得在于无得也。

（大意：你以有所得为得，所以去求一个有所得；我以无所得为得，所以得就在无所得之中。）

而且谈论，必先确定根本。既然论涅槃，不可以离开涅槃来谈涅槃。若就涅槃本身来立言，谁单单不是涅槃，还想去得到涅槃？为什么？涅槃之道，妙尽常数，融冶天地，荡涤万有，平等天人，同一异，向内观看不见自己，向内倾听听不到自我，未尝有得，未尝无得。

经说：涅槃不是众生，也不异于众生。维摩诘说：若弥勒得灭度，一切众生也应当灭度。为什么？

一切众生，本性常灭，不复更灭。此名灭度，在于无灭者也。

（大意：一切众生，本性一向寂灭，不需要再灭一次。这叫作灭度，灭度就在本来无可灭之处。）

如此，众生不是众生，谁是得到涅槃的人？涅槃不是涅槃，什么是可以得到的东西？《放光般若经》问：菩提从有中得吗？答：不是。从无中得吗？答：不是。从有无中得吗？答：不是。离开有无得吗？答：不是。那么完全没有得吗？答：不是。这是什么意思？答：因为无所得，所以是得。所以得无所得。无所得叫作得，谁单单不是这样呢？

所以玄道在于绝域，所以不以得来得到；妙智存于物外，所以不以知来知道；大象隐于无形，所以不以见来见到；大音匿于希声，所以不以闻来听闻。所以能囊括终古，导达群方，化育苍生，疏而不漏。汪哉洋哉，哪一样不由此而来？所以梵志说：我听说佛道，义理弘深，汪洋无涯，无不成就，无不度生。如此，三乘之路开启，真伪之途辨明，贤圣之道存续，无名之致显现了。

按：玄得第十九回答"谁得涅槃"，是全论的终点，七寸有两处。第一处在"子以有得为得，吾以无得为得"：有名一直在找一个"得涅槃的人"和一个"被得到的涅槃"，这本身就是"有得"的思路。第二处在"一切众生，本性常灭，不复更灭"：众生本来就寂灭，涅槃不是把五阴灭掉以后才出现的东西，所以不需要一个五阴灭尽之后还剩下来去领取涅槃的人。

这正是"不寻觅解脱之解脱"。本来解脱，所以不须另得；一旦以为要另得一个解脱，就成了"有得"，就落入不解脱。最后"不得以得之，不知以知之，不见以见之，不闻以闻之"四句，把《般若无知论》与《涅槃无名论》合在一起：能证的般若不以知知，所证的涅槃不以得得。

## 全书结语

按：《肇论》读到这里，可以把五个部分连成一条线：

- 宗本义说：一切法缘会而生，性常自空。
- 物不迁论说：没有一个东西从过去走到现在，所以世间的流动当下就是静。
- 不真空论说：万物不真，所以空；空不在万物之外，触事而真。
- 般若无知论说：能照的智慧没有一个取相的知，所以无所不知。
- 涅槃无名论说：所证的涅槃不能以有无、始终、得失来命名，众生本性常灭，得无所得。

五个部分讲的是同一件事：没有一个东西可以抓住，当下的一切照用宛然。俗谛上，事物在动，没有东西在走；真谛上，万物显现，没有东西是真；智慧上，照得清清楚楚，没有一个知；果位上，涅槃圆满，没有一个得者。
