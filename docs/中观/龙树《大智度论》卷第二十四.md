# 龙树《大智度论》卷第二十四

圣者龙树造　后秦龟兹国三藏鸠摩罗什译

## 初品十力释论第三十九

【经】“舍利弗！菩萨摩诃萨想要遍知佛的十力、四无所畏、四无碍智、十八不共法、大慈大悲，应当修习般若波罗蜜！”

【论】

### 一、何以先说声闻法而后说佛法

问：这十力、四无所畏等，是佛的无上之法，应当先说，为什么先说九相、八念等？

答：六波罗蜜是菩萨所应当用的，先前已经说过。

三十七品乃至三无漏根，是声闻法。

菩萨修行这六波罗蜜而得力，想要超过声闻、辟支佛地，也想教化趣向声闻、辟支佛的人，使他们进入佛道；所以呵责这小乘法舍弃一切众生，无所利益。

如果诸声闻人说：“你是凡夫，还没有断结使，不能修行这法，所以是空口呵责！”

所以佛说：“菩萨应当具足三十七品等诸声闻法，因为不可得。”

虽然修行这些法，因为不可得，为了众生行邪行，所以修行这正行，常不舍弃。

这些法是不可得的空，也不迅速取涅槃之证。

如果菩萨不理解、不修行这小乘而只是呵责，谁会肯相信？

譬如释迦牟尼佛，如果先不修六年苦行，就呵责苦行不是道，没有人会信受！所以亲自修行苦行，超过其他的人；成佛道时，呵责这苦行之道，人们都信受。

所以在六波罗蜜之后，接着修行声闻法。

再者，这不只是声闻法，在这法中和合了不舍众生之意，具足一切佛法，因为以不可得的空智，所以名为菩萨法。

#### （一）具足而不入声闻位

问：如果菩萨具足三十七品等诸法，为什么不进入声闻的法位？

答：“具足”，是具足观察了知而不取证；清清楚楚地观察了知，所以名为“具足”。

如佛说：

```
一切畏杖痛，　　莫不惜寿命；
恕己可为喻，　　杖不加群生。
```

大意：一切众生都畏惧杖打之痛，没有不爱惜寿命的；推己及人，以自己为比喻，就不以杖加于众生。

虽然说“一切都畏惧杖打之痛”，但无色界众生没有身体；色界虽然有身体，却没有鞭杖；欲界中诸佛、转轮圣王、夜摩天以上，都不畏惧杖打。这是为了会遭到杖打的众生，所以说“一切”。

“具足”也是这样，不是为了求证、执着于法，所以说“具足”。

再者，我先前说过，因为不舍众生，与不可得的空智和合，所以不堕入声闻地。

#### （二）“应具足”与“当学”之别

问：从六波罗蜜到三无漏根，只说“应当具足”；从这以后，为什么都说“想要得到、想要知道这事，应当修习般若波罗蜜”？

答：声闻法有量有限，所以说“应当具足”；从这以下，是诸佛之法，甚深无量，菩萨还没有得到，所以说“想要得到这事，应当学般若波罗蜜”。

再者，声闻法容易理解、容易知道，所以说“具足”；菩萨法、佛法难以理解、难以知道，所以说“应当学”。

再者，声闻法是总相的：只知苦，知苦之因，知苦之灭，知灭苦之道。

譬如两种医生：一种只知道病、知道病因、知道病愈、知道治病之药，却不知道一切病、不知道一切病因、不知道一切病的痊愈、不知道一切治病之药。或者只知道治人的病，不知道治畜生的病；或者能治一个国家的病，不能治其他国家的病；有的能治几十种病，不能全部知道四百零四种病。病因、病愈、治病之药，也是这样。另一种是在四方面都遍知，遍知药，遍知病。

声闻人如小医生，不能遍知；菩萨摩诃萨如大医生，没有不知道的病，没有不认识的药。所以，声闻法应当具足，菩萨法应当学。

### 二、十力

佛有十力：

如实了知是处与非处，这是第一力。

了知众生过去、未来、现在的诸业、诸受，了知造业之处，了知因缘，了知果报，这是第二力。

对诸禅、解脱、三昧、定，以及其垢、净的分别之相如实了知，这是第三力。

对其他众生诸根的上下之相如实了知，这是第四力。

了知其他众生的种种欲乐，这是第五力。

了知世间种种无数的性，这是第六力。

了知一切道所至之处的相，这是第七力。

了知种种宿命，其共相、共因缘，一世、二世乃至百千世劫；初劫尽时，我在那众生中，是怎样的姓名、饮食、苦乐、寿命长短，在那里死而在这里生，在这里死又在这里生；在这里生时的姓名、饮食、苦乐、寿命长短也是这样，这是第八力。

佛的天眼清净，超过诸天与人的眼睛，看见众生死时、生时，端正、丑陋，或大、或小，或堕入恶道、或堕入善道，像这样以业的因缘受报：这些众生恶的身业成就、恶的口业成就、恶的意业成就，毁谤圣人，邪见、邪见之业成就；因为这因缘，身坏死时进入恶道，生在地狱中。这些众生善的身业成就、善的口业成就、善的意业成就，不毁谤圣人，正见、正见之业成就；因为这因缘，身坏死时进入善道，生在天上，这是第九力。

佛因为诸漏已尽，无漏的心解脱、无漏的智慧解脱，在现世法中自己证知：我生已尽，持戒已作，后有已尽，如实了知，这是第十力。

#### （一）何以说十力

问：这十力，菩萨还没有得到，声闻、辟支佛不能得到，现在为什么说？

答：声闻人虽然不能得到，如果听说这十力的功德，作这样的念头：“佛有这样的大功德”；自己庆幸说：“我们得到善利，蒙受的利益不少，得以信心清净，进入灭尽苦的道。”

诸菩萨听了，勤修菩萨道，将会得到这样十力等大功德之果。

再者，有声闻人以及菩萨修念佛三昧，不只是念佛身，应当念佛种种功德法身。

应当作这样的念头：佛因为对一切种、一切法都能理解，所以名为“一切智人”；因为对一切法如实善于分别解说，所以名为“一切见人”；因为对一切法现前了知，所以名为“一切知见无碍人”；因为对一切众生平等之心，所以名为“大慈悲人”；因为有大慈悲，所以名为“世救”；因为从如实之道而来，所以名为“如来”；因为应当接受一切世间的供养，所以名为“应供人”；因为成就不颠倒的智慧，所以名为“正遍知”；因为戒、定、慧智成就，所以名为“明行”；因为成就而不再还来，所以名为“善逝”；因为知道世间的总相、别相，所以名为“世间解”；因为善于宣说出世间的安稳之道，所以名为“无上调御师”；因为以三种教法度化众生，所以名为“天人师”；一切世间都在烦恼之睡中，能自己觉醒也能使人觉醒，所以名为“觉人”；因为一切所愿都具足，所以名为“有德”；因为十力成就，所以名为“坚誓”；因为得到四无畏，所以名为“人狮子”；因为得到无量甚深的智慧，所以名为“大功德海”；因为一切记说都无碍，所以名为“如风”；因为对一切好丑都没有憎爱，所以名为“如地”；因为烧尽一切结使之薪，所以名为“如火”；因为善于断除一切烦恼习气，所以名为“具足解脱”；因为住在最上之处，所以名为“世尊”。

佛有这样等等诸功德，所以应当念佛。

所以，菩萨摩诃萨想要得到佛的十力、四无所畏、十八不共法，应当学般若波罗蜜。

再者，佛在王舍城耆阇崛山中说这般若波罗蜜时，佛的四部众以及诸外道，在家、出家，诸天、龙、鬼神等种种大众集会。佛入三昧王三昧，放大光明，遍照恒河沙数世界，大地六种震动，说这般若波罗蜜、六波罗蜜，乃至三无漏根。

这其中有众生怀疑：佛有什么力、有几种力，能作出这样不可思议的感动与利益？

佛知道众生心中有这样的怀疑，所以说：我有诸法实相的智慧之力，这力有十种，用这十种智慧，所以能作出这样的感动与变化，也能超过这些所作。所以说“想要得到十力，应当学般若波罗蜜”。

再者，佛弟子世世种下善根，因为少许罪业的因缘，堕入外道。诸外道常说：“佛并没有真实的功德之力，是以幻术之力诳惑人心。”堕入外道的佛弟子心中怀疑：“如果是这样，佛就不是大人。”为了灭除这恶意的毁谤，所以说：“我确实有十力、四无所畏，所以度化众生，不是幻术欺诳。”

再者，诸菩萨修菩萨道，苦行之事难以办到、难以成就，所以想要懈怠休息；因此佛说：“修行这十力，将得到无量的果报。”譬如商队之主安慰商人说：“你们千万不要疲倦，精勤努力，到达宝山，将得到七宝、如意宝珠。”佛也是这样安慰诸菩萨说：“不要疲倦厌烦，应当勤奋精进，修菩萨道；修行这十力，将得到无量的果报。”

像这样等等种种利益的因缘，所以说十力等。

#### （二）佛有无量力，何以只说十力

问：佛有无量的力，为什么只说十力？

答：诸佛虽然有无量的力，为了度人的因缘，说十力，足以成办其事：

以是处非处智力，分别衡量众生，这是可度的，这是不可度的；以业报智力，分别衡量这人有业障，这人有报障，这人无障；以禅定解脱三昧智力，分别衡量这人执着禅味，这人不执着禅味；以上下根智力，分别衡量众生智力的多少；以种种欲智力，分别衡量众生所喜乐的；以种种性智力，分别衡量众生深心所趣向的；以一切至处道智力，分别衡量众生的解脱之门；以宿命智力，分别众生先前从何而来；以生死智力，分别众生所生之处的好丑；以漏尽智力，分别衡量众生得涅槃。

佛用这十种力度脱众生，审察而不出错，都得以具足。所以，佛虽然有无量的力，只说这十力。

再者，这是处非处力，确定知道从这因缘出这果报，这其中总摄了其余九力；为了度化众生，所以在第一力中分别出九种。

为什么？这世间众生，眼前看见谷子从种子长出，尚且不能了知其理，何况心与心所法的因缘果报？

佛对内外的因缘果报都清清楚楚地遍知，所以名为力。

佛知道这众生因为业与烦恼的因缘所以被缚，因为清净的禅定、三昧、解脱的因缘所以得解；对一切众生三世的三种诸业、诸烦恼，其轻重、深浅、粗细，佛都遍知，所以名为力。

对一切众生的诸禅定、解脱、三昧，其大小、深浅以及解脱的因缘，佛都遍知，所以名为力。

钝根众生为了后世之身而作罪福之业的因缘；利根之人为了不再受生而积集诸业；佛都知道这上下根的好丑之相，所以名为力。

知道一切众生两种欲乐，作为上下根的因缘；这两种欲乐，善与恶种种差别，佛都遍知，所以名为力。

两种欲乐是由两种性的因缘而来，遍知众生深心所趣向的，所以名为力。

一切众生因为种种性的因缘，行两种道，就是善道与恶道，种种门所至之处，佛都遍知，所以名为力。

对过去、未来世中的因缘果报，智慧无碍，这名为宿命智力、生死智力。

知道过去、未来的因果之后，完全知道以方便破坏因缘果报的相续，这名为漏尽力。

佛知道三世中的两种因缘，分别衡量众生的根、欲、性，为了漏尽而说法，这是漏尽力。

### 三、是处非处力

问：什么是“是处非处力”？

答：佛知道一切诸法因缘果报的确定之相：从这因缘生出这样的果报，从这因缘不生出这样的果报。为什么？

#### （一）《多性经》中佛口自说

如《多性经》中说是处非处之相：

女身作转轮圣王，没有这个道理。为什么？因为一切女人都隶属于男子，不得自在。女人尚且不能作转轮圣王，何况作佛！如果女人得到解脱涅槃，也是依靠男子而得，没有自然得道的。

两位转轮圣王同时出世，没有这个道理。为什么？因为没有怨对之业的成就。两位转轮圣王尚且不同世，何况两尊佛！

恶业而能得到乐报，没有这个道理；恶业尚且不能得到世间之乐，何况出世间之乐！

如果恶行而能生天，没有这个道理；恶行尚且不能生天，何况涅槃！

五盖覆盖其心而散乱，离开修习七觉而能得涅槃，没有这个道理；五盖覆盖其心、离开修习七觉，尚且不能得到声闻道，何况佛道！心中没有覆盖，佛道尚且可以得到，何况声闻道！

像这样等等是处非处，是《多性经》中佛亲口所说。

#### （二）论师依佛语广说

诸论议师之辈，依据这佛语，更加广说是处非处：

如果说佛有缺失罪过，如果诸贤圣去求外道之师，如果诸贤圣自己说我是佛，如果诸贤圣堕入恶道，如果见谛所断的结使再生起，如果诸贤圣覆藏罪过，如果须陀洹有第二十五有，都没有这个道理；如贤圣的分别中详细说明。

五逆之人、五种黄门、堕入四恶道的众生、郁多罗越人、魔的眷属、被三障所遮的人，如果说能得道，都没有这个道理！

轻视说法者，轻视法、轻视自己，破戒、愚痴，如果说能得到具足的法喜，也没有这个道理！

自己说我是佛，这身口之恶不悔而想见佛；如果有破僧之罪不悔而想见佛；邪定之人进入正定，正定之人进入邪定，正定之人进入不定；除了佛法之外另有真正得道的人；应当得道之身如果死去，都没有这个道理！

除了因缘所生的识，在名色之外另有法，没有这个道理！

佛派遣使者，事情还没有完成，如果被阻碍，没有这个道理！

入慈三昧时，如果因他人因缘而死；入灭尽定、在见谛道中时，如果死去，都没有这个道理！

如果有人杀害佛以及佛母，没有这个道理！

转轮圣王的女宝、象宝、马宝、主藏臣、主兵臣，如果在胎中死去，母子夭亡，都没有这个道理！

郁多罗越人、女宝、佛母，命终之后下一身进入恶道，都没有这个道理！

有为法是常，涅槃是无常，凡夫能断除非有想非无想处的结使，在一切取相的禅定中修圣道，无漏道是有漏之因，如果地是湿相、水是坚相、火是冷相、风是住相，都没有这个道理！

无明不能生诸行，乃至生不能生老死，没有这个道理！

两个心同时生起；五识身能分别取相，或执着、或离开；如果眼能生起身业、口业；如果眼能入禅定；没有这个道理！

只有五识相续生起而不生意识；只在五识身中有执着的相续；只有五识身能缘名、能缘相、能缘无色法，能缘过去、未来，能缘离开三世之法；只在五识身中有增语触、明触，修禅定，或者受善律仪、不善律仪，或者有忧喜；或者有无觉无观；或者增益诸根，都没有这个道理！鼻识、舌识有隐没无记；凡夫的第六识离开我执而行，没有这个道理！

像这样等等无量的非处，是处也是这样。

佛知道是处、非处，分别衡量，对可度的人为他说法，对不可度的人为他作因缘。

譬如良医，知道病可治、不可治。声闻、辟支佛所知的少，因为少，所以或者不应当度的想去度，如首罗；应当度的却不度，如舍利弗所不度的人就是。

佛没有这样的事，无能破坏，无能胜过，因为完全遍知，这名为第一力。

【译注】是处非处力列于十力之首，论主说它总摄其余九力，“定知从是因缘出是果报”，其余九力只是为度众生而从中分出。所列诸“无是处”，一部分是《多性经》佛口自说，一部分是论师依佛语广说，其中有关女身、转轮王同世等语，是当时经论的定说，照原文译出。论主最后落在“可度者为说法，不可度者为作因缘”，并以舍利弗不度之人为例，说明此力是佛度生的根本判断。

### 四、业报智力

“业报智力”，是身口所作的业，以及由此所生的无作业（无表业）、所受的戒业，也有恶业，日夜随之而生的业，由之而生的罪福之业；这些业，佛略说为三处所摄，这名为一切业相。

#### （一）三世业报

佛知道一切众生：有业在过去，报也在过去；有业在过去，报在现在；有业在过去，报在未来；有业在过去，报在过去、现在；有业在过去，报在过去、未来；有业在过去，报在现在、未来；有业在过去，报在过去、未来、现在。现在之业也是这样。

再者，在善心中受善、不善、无记业的果报；不善心、无记心也是这样。

再者，因为乐业的因缘，所以受乐报；因为苦业的因缘，所以受苦报；因为不苦不乐业的因缘，所以受不苦不乐报。

因为现报业的因缘，所以受现报；因为生报业的因缘，所以受生报；因为后报业的因缘，所以受后报。

因为不净业的因缘，所以受恼害之报；因为净业的因缘，所以受无恼之报；因为杂业的因缘，所以受杂报。

#### （二）必受报业与不必受报业

再者，有两种业：必定受报的业，不必定受报的业。

必定受报的业，不可得以脱离，或者待时、待人、待处而受报。如人应当与转轮圣王共同享福，要等转轮圣王在好的时世出现，这时才受，这是待时；待人，人就是转轮圣王；待处，是转轮圣王出现之处。

再者，这必定受报的业，不待技能功劳，无论好丑，不求自来。如生在天上的人，福乐自然到来；地狱中的人，罪苦自然追来。不待因缘，因为这业深重。

再者，必定受报的业，如毗琉璃的军队杀了七万二千位得道之人以及无量持五戒的优婆塞，连目连等大神通之人也不能救。如薄拘罗，被后母投入火中、汤中、水中而不死。如佛游化诸国，虽然出家乞食，不需要膳食供养，却有五百辆车载着国王的食物，叶中生出粳米，随着饭食有百味之羹。像这样等等善恶之业必定受报。

其余的不必定受报。

欲界有三种受业报之处：乐受业、苦受业、不苦不乐受业。

色界有两种受业报之处：乐受业、不苦不乐受业。

无色界有一种受业报之处：不苦不乐受业。

或者待事的，依于这事而得以受业报。

如弗迦罗婆王的池中，生出千叶金色莲花，大如车轮，因为这次大会的快乐，许多人出家得道。

#### （三）佛知造业的处、时、事、因缘

佛知道一切众生造诸业之处，或在欲界、色界、无色界。

如果在欲界，在哪一道中；如果在天道，在哪一天中；如果在人中，在哪一天下；如果在阎浮提，在哪一国；如果在这国，在哪一城、哪一聚落、哪一精舍、哪一块土地；如果在这城，在哪一里、哪一巷、哪一舍、在什么地方。

知道这业在什么时候作的，过去一世、二世乃至百千万世。

这业的果报，有多少已经受了、多少还没有受；多少必定受、多少不必定受。

知道善与不善所用的事物，就是刀杖、教唆命令杀害等，自己杀，派人杀；其余的恶业也是这样。善业也是这样，知道这样布施、持戒、修善。

布施中，所施的是什么土地、房舍，衣服、饮食，医药、卧具，七宝财物。

持戒中，有受戒，自然戒，心生之戒，口说之戒，一行戒，少分戒，多分戒，满分戒；一日戒，七善道戒，十戒，具足戒，定共戒。

善福中，修初禅，二禅、三禅、四禅；慈心、悲心、喜心、舍心。像这样等等善业的因缘。

或者悭贪，或者瞋恚，或者怖畏，或者邪见，或者恶知识等，种种恶业的因缘。福业的因缘：或者信，或者怜悯，或者恭敬，或者禅定，或者智慧，或者善知识等，种种善业的因缘。这些业是自在的，一切天与人都不能转变这些业相，在亿千万世中常随逐众生而不舍离，如债主追随欠债的人；得到因缘具足，便给予果报。如地中的种子，得到因缘、时节和合，便生长。

这业能使众生在六道中受生，比箭还快。一切众生都有诸业的果报之分，如父母遗留的财产，诸子都应当分得一份。这业的果报时候到了，不可遮止，如劫尽之火；随着众生应当受生之处，处处安置，如大国王随其所应而给予官职。人命终时，这业来覆盖其心，如大山遮蔽事物。

这业能给予种种身形，如画师作种种画像。

如果人以正行作业，就给予好的果报；如果以邪行作业，就给予恶的果报。如人侍奉国王，随其所作之事而得报酬。

像这样等等分别诸业之相与果报。

#### （四）行恶生好处、行善生恶处

再者，如《分别业经》中，佛告诉阿难：“行恶的人生在好处，行善的人生在恶处。”

阿难说：“这是怎么回事？”

佛说：“恶人今世的罪业还没有成熟，宿世的善业已经成熟，因为这个因缘，现在虽然作恶，却生在好处。

“或者临死时，善的心与心所法生起，因为这个因缘，也生在好处。

“行善的人生在恶处，是今世的善还没有成熟，过去世的恶已经成熟，因为这个因缘，现在虽然行善，却生在恶处。或者临死时，不善的心与心所法生起，因为这个因缘，也生在恶处。”

问：成熟与不成熟的道理可以如此；临死时那一点点时间的心，怎么能胜过终身所行之力？

答：这心虽然时间很短，心力却猛利，如火、如毒，虽然少却能成大事。这垂死时的心，因为决定而猛健，所以胜过百年所行之力；这最后的心名为大心，因为舍弃身体与诸根，事情紧急。

如人上阵，不惜身命，名为勇健。如阿罗汉舍弃对这身体的执着，所以得阿罗汉道。

像这样等等种种罪福业报，以及辗转的果报，也应当这样了知。

声闻人只知道恶业得罪报、善业得福报，不能这样细致地分别；佛完全遍知这业以及业报，智慧的势力无碍无尽，无能破坏，这名为第二力。

### 五、禅定解脱三昧净垢分别智力

“禅定解脱三昧净垢分别智力”：“禅”名为四禅，佛知道这禅是佐助道的法，其名相、义分，次第熏修，有漏、无漏，有学、无学，净、垢，味着、不味着，深浅的分别等。

“八解脱”，如禅中所分别的相。

说“禅”，摄一切色界定；说“解脱”，摄一切定。

禅波罗蜜就是诸解脱。

禅、定、三昧、解脱，都名为定；定名为心不散乱。

“垢”名为爱、见、慢等诸烦恼；“净”名为真正的禅定，不夹杂爱、见、慢等烦恼，如真金。

“分别”，名为诸定中有一心而行、不一心而行，常行、不常行，难入、易入，难出、易出，别取相、总取相，转治、不转治。转治，如对淫欲修慈心，对瞋恚之人修不净观，对愚痴之人思惟有边无边；在掉戏心中用智慧分别诸法，在沉没心中想收摄其心。如果不是这样，名为不转治。

这定中应当分别时机以及住处：

如果身体瘦弱，这不是修定的时机。如菩萨苦行时作这样的念头：“我现在不能生起禅定。”如果在人多之处，也不是修定的地方。

再者，佛知道这禅会退失，这禅会安住，这禅会增益，这禅能到达涅槃。

再者，佛知道这人难入定难出定，易入易出，易入难出，难入易出。

佛知道这人应当得到这样的禅，知道这人会失去禅而享受五欲，知道这人享受五欲之后又会得禅，依这禅得阿罗汉。

像这样等等一切诸禅定、解脱，就是三昧。这禅定，佛以甚深的智慧完全了知，无能破坏，无能胜过，这名为第三力。

### 六、知众生上下根智力

“知众生上下根智力”：佛知道众生是利根、钝根、中根。利的智慧名为上，钝的智慧名为下；佛用这上下根智力，分别一切众生是利根、是中根、是钝根。

这人有这样的根，今世只能得初果，不能得其余的果；这人只能得第二、第三、第四果。

这人只能得初禅；这人只能得第二、第三、第四禅，乃至灭尽定也是这样。

这人当作时解脱之证；这人当作不时解脱之证。

这人能得在声闻中第一；这人能得在辟支佛中第一；这人具足六波罗蜜，能得阿耨多罗三藐三菩提。

这样了知之后，或者为他略说而得度，或者为他广说而得度，或者为他略说与广说而得度；或者以软语教导，或者以苦切之语教导，或者以软语与苦语兼用来教导。

佛也分别：这人有其余的根，应当使他增生信根；这人应当使他生起精进、念、定、慧根。这人用信根进入正位；这人用慧根进入正位。

这人利根，被结使所遮障，如鸯群梨摩罗等；这人利根，不被结使所遮障，如舍利弗、目连等。

知道有根虽然钝而无遮障的，如周利般陀伽；有根钝而有遮障的。

知道这人见谛所断方面根钝，思惟所断方面根利；或者思惟所断方面根钝，见谛所断方面根利。

这人一切根同样钝、同样利；这人一切根不同样钝、不同样利。

这人先前的因力大；这人现在的缘力大。

这人想要被缚却得到解脱；这人想要解脱却被缚。譬如鸯群梨摩罗，想要杀母、害佛，却得到解脱；如一位比丘得到四禅，因为增上慢，反而进入地狱。

知道这人必定堕入恶道；这人难以出离。这人容易出离；这人很快出离；这人很久很久才出离。

像这样等等一切众生上下根之相，都完全遍知，无能破坏、无能胜过，这名为第四力。

### 七、知众生种种欲智力

“知众生种种欲智力”。

“欲”名为信、喜、好乐。

好五欲的，如孙陀罗难陀等；好名声的，如提婆达多等；好世间财利的，如须弥刹多罗等；好出家的，如耶舍等；好信的，如跋迦利等；好持戒的，如罗睺罗等；好布施的，如施跋罗（丹本注：佛姑甘露女所生）；好头陀远离的，如摩诃迦叶；好坐禅的，如隶跋多等；好智慧的，如舍利弗等；好多闻的，如阿难等；好通晓毗尼的，如优婆离等。像这样，佛弟子各自有所喜好。凡夫也各自有所喜好：或者有喜好淫欲的，或者有喜好瞋恚的。

再者，佛知道这人多欲、多瞋、多痴。

问：什么是多欲、多瞋、多痴之相？

答：如《禅经》中所说的三毒之相，这里应当详细说。

知道这样的相之后，多淫欲的人以不净法门对治，多瞋的人以慈心法门对治，多愚痴的人以因缘法门对治。

像这样随着其欲乐而说法：就是善的欲乐，随其心而为他说，如船顺流而行；恶的欲乐，以苦切之语教导，如以楔子退出楔子。在这欲智中，佛完全遍知，无能破坏、无能胜过，这名为第五力。

### 八、性智力

“性智力”：佛知道世间种种差别之性。“性”名为积习，相状从性而生，欲乐随性而作为行；或者有时从欲乐而成为性，欲乐串习而成为性。“性”名以深心为事，“欲”名随缘而起，这是“欲”与“性”的分别。

世间种种差别，是各自的性，多种性，无量不可数，这名为世间的差别。

有两种世间：世界世间，众生世间；这里只说众生世间。

佛知道众生有这样的性、这样的欲乐，从这处而来，或成就善根、或成就不善根，可度、不可度，定、不定，必定、不必定，行何种行、生在何处、在何地。

再者，佛知道这众生种种性之相，就是随其所趣向的，在这样的方面偏多，这样地看重，这样的深心之事，这样的欲乐，这样的业，这样的行，这样的烦恼，这样的礼法，这样的定，这样的威仪，这样的知，这样的见，这样的忆想分别；有多少结使已经生起，有多少结使还没有生起；随着所执着而生起欲乐，随着欲乐而染污其心，随着染心而有所趣向，随着趣向而有所看重，随着所看重而常有觉观，随着觉观而作戏论，随着戏论而常念，随着念而发起行动，随着行动而造作业，随着造作业而有果报。

再者，佛用这种种性智力，知道这众生可度，这不可度；这今世可度，这后世可度；这当即可度，这另外的时候可度；这当面可度，这眼睛看不到时可度；这人佛能度，这人声闻能度，这人共同可度；这人必定可度，这人必定不可度；这人略说可度，这人广说可度，这人略说与广说可度；这人赞叹可度，这人折伏可度；这人迎接可度，这人弃舍可度；这人以细微之法可度，这人以粗显之法可度；这人以苦切可度，这人以软语可度，这人以苦切与软语可度。

这是邪见，这是正见；这执着过去，这执着未来；这执着断灭，这执着常；这执着有见，这执着无见；这想要受生，这厌离受生；这求富贵之乐，这执着深厚的邪见；这说无因无缘，这说邪的因缘，这说正的因缘；这说无作业，这说邪的作业，这说正的作业；这说不求，这说邪求，这说正求；这看重我，这看重五欲，这看重得利，这看重饮食，这看重说笑娱乐之事；这乐于大众，这乐于喧闹，这乐于远离；这多行于爱，这多行于见；这好信，这好慧；这应当守护，这应当舍弃；这看重持戒；这看重禅定，这看重智慧；这容易觉悟，这要讲说才觉悟；这可以引导，这能逐句理解；这是利根，这是钝根，这是中根；这容易出离容易拔济，这难以出离难以拔济；这畏惧罪过，这罪过深重；这畏惧生死，这不畏惧生死；这多欲，这多瞋，这多痴；这多欲与瞋，这多欲与痴，这多瞋与痴，这多欲、瞋、痴；这烦恼薄，这烦恼厚；这垢少，这垢多；这是覆慧，这是衣裓慧，这是广慧；这人善知五众之相，十二入、十八界、十二因缘；是处、非处，苦、集、灭、道；善知入定、出定、住定。

再者，佛知道：这是欲界众生，这是色界、这是无色界众生；这是地狱、畜生、饿鬼、人、天；这是卵生、胎生、湿生、化生；这是有色、这是无色，这是有想、这是无想；这是短命，这是长命；这只是还没有离欲的凡夫，这是离开下地之欲、还没有离开禅之欲的凡夫，像这样乃至非有想非无想；这是向道的，这是得果的；这是辟支佛，这是诸佛的无碍解脱。像这样等等种种分别：五道，四生，三聚，假名，障碍，众、入、界，善根、不善根，诸结使，地，业果，这可度、这不可度，灭、智的分别。

以这样等等分别，了知世间种种差别之性，得到无碍解脱。像这样等等种种差别，佛完全遍知，无能破坏、无能胜过，这名为第六力。

### 九、一切至处道智力

“一切至处道智力”。

有人说：业就是道。为什么？因为业的因缘，遍行于五道。有业能断，业能有所到达，就是三种圣道分以及无漏的思。所以，诸业是一切至处道。

再者，有人说：住于五别五智三昧（丹本注：无漏三昧，禅的五支），一切处利益之事都能办成。

又有人说：第四禅就是。为什么？第四禅是一切诸定所至之处。如诸经中说：这善心、定心、不乱心、摄心，都进入第四禅中。

再者，有人说：如身念处就是至处道，是诸道利益的根本。

又有人说：一切圣道就是；用这圣道得以随意获得利益。

又有论者说：一切善道、一切恶道、一切圣道，各自知道诸道所至之处。如《毛竖经》中所说。

佛完全遍知，无能破坏、无能胜过，这名为第七力。

### 十、宿命智力

“宿命智力”，宿命有三种：有通，有明，有力。

凡夫只有通，声闻人也有通、也有明，佛也有通、也有明、也有力。为什么？

凡夫只知道宿命所经历的，不知道业因缘的相续；所以凡夫只有通，没有明。

声闻人因为知道集谛，清清楚楚地知道业因缘相续而生；所以声闻人也有通、也有明。如果佛弟子先前作凡夫时得到宿命智，进入见谛道中知道集的因缘，在第八无漏心时得以断除见惑，所以通转变为明。为什么？“明”名为见到根本。如果佛弟子先得到圣道，后来宿命智生起，也因为知道集的因缘之力，所以通转变为明。

问：如果佛本来作菩萨时，先得到宿命智；诸菩萨离开无所有处的烦恼，后来才进入圣道；为什么佛说“我初夜得到第一明”？

答：那时还不是明；佛在大众中说我那时得到这明，是向众人显示说：这明是初夜得到的。

譬如国王还没有作王时生了儿子，后来作王时，人们问：“王子是什么时候生的？”回答说：“王子是某时生的。”这儿子出生时国王还没有作王，因为现在是王，所以称他为王子，说“王子是那时生的”。

佛也是这样，宿命智生起时，那时还不是明，只名为通；后夜时因为知道集的因缘，所以通转变为明；后来在大众中说：“我初夜时得到这明。”

问：“通”、“明”的意义是这样，怎样是“力”？

答：佛用这明，了知自身以及众生在无量无边世中宿命因缘所经历的，种种都完全遍知，这是“力”。

这名为第八力。

### 十一、生死智力

“生死智力”，是佛用天眼，见众生生死之处。

凡夫用这天眼，最多见到四天下；声闻人最多横向见到小千世界，上下也普遍见到。

问：大梵王也能见到千世界，有什么不同？

答：大梵王站在千世界的中央，就能普遍见到；如果站在边上，就见不到其他地方。

声闻人则不是这样，在所住之处，常能见到千世界。

辟支佛见到百千世界，诸佛见到无量无边的诸世界。

凡夫的天眼智，是通而不是明，也是这样，只见到现有的事，不能见到随着业因缘而受生，如宿命中所说。

再者，得天眼的人中最第一的是阿泥卢豆，以色界四大所造之色，半个头清净，就是天眼；佛的天眼，四大所造之色遍满全头清净，这是差别。

再者，声闻人在所住的三昧中得到天眼，就只在所住的三昧中能见：或者有觉有观三昧，或者无觉有观三昧，或者无觉无观三昧；佛随着所入的三昧而住，想见就都能见；如果依无觉无观三昧得到天眼，入有觉有观三昧，或无觉有观三昧中也能见。

再者，声闻人用这天眼见物时，所住的三昧中，心进入其他三昧，天眼就灭了；佛则不是这样，心虽然进入其他三昧，天眼不灭。

这智慧遍知一切众生生死所趣，无能破坏、无能胜过，这名为第九力。

### 十二、漏尽智力

“漏尽智力”：

问：九力的智慧分别有差别，漏尽则相同，一切声闻、辟支佛与佛有什么不同？

答：虽然漏尽是相同的，智慧的分别却有很大差别。

声闻中力量最大的，对思惟所断的结使，在生分、住分、灭分三个时分中断除；佛则不是这样，在一个生分时就全部断尽。

声闻人见谛所断的结使在生起时断，思惟所断的在三个时分中灭；佛则对见谛所断、思惟所断，没有差别。

声闻人初入圣道时，进入时与通达时不同；佛则在一心中既进入也通达，一心中得一切智，一心中破一切障，一心中得一切佛法。

再者，诸声闻人有两种解脱：烦恼解脱，法障解脱；佛有一切烦恼解脱，也有一切法障解脱。

佛自然得到智慧；诸声闻人随着教导、依道而行而得到。

又有人说：如果佛以智慧断除一切众生的烦恼，佛的智慧也不钝、不减。譬如烧热的铁丸，放在少许棉花上，虽然烧了这棉花，火的热势不减；佛的智慧也是这样，烧尽一切烦恼，智慧之力也不减。

再者，声闻只知道自己漏尽；诸佛自己知道漏尽，也知道他人漏尽，如《净经》中所说。

再者，唯独佛知道众生心中分别有九十八使、一百九十六缠，除了佛没有人知道。

佛也唯独知道在苦法智、苦比智中断除多少结使之性，乃至道比智也是这样；思惟所断，在九解脱道中也是这样。

佛完全遍知一切众生这样的事；声闻如果少知少说，都是随着佛语。

佛这样漏尽智慧的力势，无能破坏、无能胜过，这名为第十力。

### 十三、十力的总说

#### （一）何力最胜

问：这十力中哪一种最殊胜？

答：各自在自己的事中为大，如水能浸湿，火能燃烧，各自有其力。

有人说：第一力为大，因为能摄十力。

有人说：漏尽力为大，因为事已办成、得涅槃。

论者说：这十力都以无碍解脱为根本，以无碍解脱为增上。

#### （二）何以自说十力

问：如果这十力唯独是佛的事，弟子今世没有人能得到，佛为什么说？

答：为了断除人们对十力的怀疑，为了使无智之人的心决定坚固，为了使四众欢喜，说：“我们的大师唯独有这样的力，不与一切众生共有。”

又诸外道之辈说：“憍昙氏沙门常住在寂静之处，智慧萎缩隐没。”

所以佛发至诚之言：“我的十种智力、四无所畏，安立具足；在大众中，说具足的智慧，教化众生，如狮子吼，转梵轮，一切外道以及天、世人没有能转的。”为了止息这毁谤，所以说这十力。

问：好人的法则，对一件事的智慧尚且不应当自我赞叹，何况无我、无所执着的人而自我赞叹十力？

如偈中说：

```
自赞、自毁，　　赞他、毁他，　　如是四种，
智者不行！
```

大意：自我赞叹、自我贬毁、赞叹他人、毁谤他人，这四种事，智者不作！

答：佛虽然无我、无所执着，有无量的力，因为大悲，为了度化众生，只说十力，不是为了自我赞叹。譬如好的商队导师，看见诸恶贼诳骗诸商人，指示错误的道路；导师怜悯，所以对诸商人说：“我是说实话的人，你们不要跟随诳惑你们的人！”又如诸劣医等诳骗诸病人；良医怜悯他们，对众病人说：“我有良药能除你们的病，不要相信欺诳而使自己困苦！”

再者，佛的功德深远，如果佛自己不说，就没有人知道；为众生少说一些，利益却非常多。所以佛自己说这十力。

再者，有可度的人，必定应当为他说；在所应当说的之中，依次应当说十力；如果不说，他就不能得度，所以自己说。

譬如日月出来时，不作这样的念头：“我照耀天下，应当有名声！”日月既然出来，必定自然有名声；佛也是这样，不是为了有名声才自己说功德。佛以清净的言语说法，光明破除众生的愚痴黑暗，自然有大名声。

所以，佛自己说十力等诸功德，没有过失。

“力”名为能有所成办：用这十种力增益智慧，所以能破论议师；用这十种力增益智慧，所以能善于说法；用这十种力增益智慧，所以能摧伏不顺从的人；用这十种力增益智慧，所以在诸法中得到自在，如大国之主在臣民大众中得到自在。

这是以声闻法略说十力的意义。

【译注】卷末一句“是为以声闻法略说十力义”，提示本卷所说十力是依声闻法相的解释：各力的所知、漏尽时声闻三时断与佛一生分时尽断的差别、通明力三分等。论主在答“何力最胜”时另立一义：“是十力皆以无碍解脱为根本，无碍解脱为增上”，这是本卷里最接近大乘的一句，与经文“欲遍知十力当习行般若波罗蜜”相照，十力的根本不在各自所知的广狭，而在无碍。

## 本卷要义

本卷经文转入佛的不共功德：欲遍知十力、四无所畏、四无碍智、十八不共法、大慈大悲，当习行般若波罗蜜。论主先回答一个次第问题：为什么先说九相、八念等声闻法，后说佛法？因为菩萨若不解不行小乘而但呵之，无人肯信，如佛若不先修六年苦行而呵苦行非道，人亦不信；而菩萨行声闻法，是“具足观知而不取证”，与不舍众生意、不可得空智和合，所以不堕声闻地。经文前说“应具足”，此后说“当学”，因为声闻法有量有限、如小医但知数十种病，佛法甚深无量、如大医无病不知、无药不识。

十力为什么只说十种，论主答得极为切要：佛有无量力，但度人之事，十力已足以成办：以是处非处力知可度不可度，以业报力知业障报障，以禅定力知着味不着味，以根力知智力多少，以欲力知所乐，以性力知深心所趣，以至处道力知解脱门，以宿命力知从何来，以生死力知生处好丑，以漏尽力知得涅槃。而第一力总摄九力，因为世人眼见谷从种出尚不能知其理，何况心与心所的因缘果报。是处非处一节列出大量“无是处”，论主最后说，佛知此而对可度者说法、对不可度者作因缘，声闻所知少，或不应度而欲度，或应度而不度。

业报智力一节，论主最用力处是业的不可转：三世业报的种种组合、必受报业待时待人待处、毗琉璃杀释种目连不能救，而“是业自在，一切天及人无能转者，于亿千万世常随逐众生不舍，如债主随人”。《分别业经》行恶人生好处、行善人生恶处一段，论主补出临死一念的分量：此心时顷虽少而猛利如火如毒，因为舍身及诸根事急，所以胜百岁行力，如人入阵不惜身命名为健。

根、欲、性三力，论主写得最为细密，几乎是一幅众生心性的地图：利根而为结使所遮如鸯掘魔罗，根钝而无遮如周利般陀伽；欲缚而得解，欲解而得缚；欲是随缘而起，性是积习深心，从所着生欲、从欲染心，一路推到作业与果报；佛据此知是人今世可度、后世可度、佛能度、声闻能度、略说可度、广说可度、赞叹可度、折伏可度。宿命一力分通、明、力三层：凡夫有通而不知业因相续，声闻知集谛而通变为明，佛遍知自他无量世因缘而为力。天眼、漏尽两力则从所见广狭、入他三昧而天眼不灭、一生分时尽断诸结、一心中入达一切佛法等处分出佛与二乘的差别。

最后论主回应“佛无我何以自赞十力”之难：如导师见恶贼诳商人示以非道，必须说“我是实语人”；如良医见弊医诳病人，必须说“我有良药”；又如日月出时不念名称而自有名称。“力”名能有所办，十力增益智慧，能破论师、能好说法、能摧伏不顺、于诸法得自在。论主又说十力皆以无碍解脱为根本，这一句是全卷由声闻法义通向般若的关节。
