# 龙树《大智度论》卷第二十三

圣者龙树造　后秦龟兹国三藏鸠摩罗什译

## 初品中十想释论第三十七

【经】“十想：无常想、苦想、无我想、食不净想、一切世间不可乐想、死想、不净想、断想、离欲想、尽想。”

【论】

### 一、念、想、智之别

问：这一切修行之法，为什么有时名为“智”？有时名为“念”？有时名为“想”？

答：初学善法时，为了不失去它，只名为“念”；能转变其相、转变其心，所以名为“想”；决定了知而无所怀疑，所以名为“智”。

### 二、无常想

观察一切有为法无常，与智慧相应之相，这名为“无常想”。

一切有为法无常，是因为新新生灭，因为隶属于因缘，因为不会增长积聚。

再者，生时无所从来，灭时也无所去，所以名为无常。

再者，因为两种世间无常，所以说无常：一是众生无常，二是世界无常。

如偈中说：

```
大地草木皆磨灭，　　须弥巨海亦崩竭，
诸天住处皆烧尽，　　尔时世界何物常？
十力世尊身光具，　　智慧明照亦无量，
度脱一切诸众生，　　名闻普遍满十方，
今日廓然悉安在？　　何有智者不感伤！
```

大意：大地草木都会磨灭，须弥山与大海也会崩坏枯竭，诸天的住处都被烧尽，那时世界上还有什么是常住的？具足十力的世尊，身光圆满，智慧的光明照耀无量，度脱一切众生，名声普遍充满十方；如今空空荡荡，都在哪里？哪有智者不为之感伤！

像这样，舍利弗、目犍连、须菩提等诸圣人，转轮圣王、诸国王，常乐的天王以及诸天，神圣的功德、尊贵的地位也都会穷尽，如大火焰的光明忽然熄灭。

世间转变败坏，如风中之灯，如险岸边的树，如漏器盛水，不久就会空竭。

像这样，一切众生以及众生的住处都是无常，所以名为无常。

#### （一）菩萨何以行无常想

问：菩萨为什么修行这无常想？

答：因为众生执着常的颠倒，受种种苦，不能免于生死。修行者得到这无常想，教化众生说：“诸法都是无常，你们不要执着常的颠倒，错失修道的时机！诸佛的上妙之法，就是四真谛；四谛中苦谛为首，苦谛的四行相中，无常行为首。”所以菩萨修行无常想。

#### （二）具足无常想

问：有人看见无常之事到来，反而更加坚固执着。如一位国王的夫人，是从地中生出的宝女，被十头罗刹劫走，将要渡过大海；国王非常忧愁！有智慧的大臣劝谏说：“大王智慧与力量具足，夫人不久就会回来，为什么忧愁？”国王回答：“我所以忧愁，不是担心我的妻子找不回来，只是怕壮年时光容易过去；也如人喜爱好花好果，看到它们将要凋谢时，便更加生起执着。”像这样知道无常反而更生起诸结使，怎么说“无常能使心生厌离，破除诸结使”？

答：这样见到无常，只是知道无常的一小部分，是不具足的，与禽兽见到无常没有差别。所以，佛告诉舍利弗：“应当具足修习无常想。”

问：什么是“具足的无常想”？

答：观察有为法念念生灭，如风吹尘土，如山上流水，如火焰随生随灭。一切有为法，不牢固、不坚强，不可取，不可执着，如幻、如化，诳惑凡夫。由这无常而得以进入空门；在这空中一切法不可得，所以无常也不可得。为什么？在一念之中，生、住、灭之相不可得：生时不能有住、灭，住时不能有生、灭，灭时不能有生、住。生、住、灭之相，因为性相相违，所以不存在；因为它们不存在，所以无常也不存在。

问：如果没有无常，佛为什么在苦谛中说无常？

答：凡夫因为生起邪见，认为世间是常；为了灭除这常见，所以说无常，不是因为无常是真实的而说。

再者，佛未出世时，凡夫只用世俗之道遮止诸烦恼；现在想要拔除诸烦恼的根本，所以说这无常。

再者，诸外道之法，只以形体离开五欲，就认为是解脱；佛说因为邪相的因缘所以被缚，观察无常的正相所以得解脱。

又有两种观察无常之相：一是有余，二是无余。

如佛说：“一切人与物都灭尽了，只有名字还在，这名为有余；如果人与物灭尽，名字也灭了，这名为无余。”

又有两种观察无常之相：一是身死而尽灭，二是新新生灭。

#### （三）无常想即是道

再者，有人说：持戒最重要。为什么？依靠持戒的因缘，依次得以漏尽。

有人说：多闻最重要。为什么？依靠智慧，能有所得。

有人说：禅定最重要，如佛所说，定能得道。

有人说：十二头陀最重要。为什么？能清净戒行。

像这样各自以自己所行的为尊贵，不再勤求涅槃。

佛说：“这些功德，都是趣向涅槃的一部分；如果观察诸法无常，这才是真正的涅槃之道。”像这样等等种种因缘，诸法虽然是空，仍然说这无常想。

再者，无常想就是圣道的另一个名称。

佛以种种不同的名称说道：或说“四念处”，或说“四谛”，或说“无常想”。如经中说：“善修无常想，能断除一切欲爱、色爱、无色爱，掉举、慢，无明灭尽，能除去三界的结使。”所以，就名为道。

这无常想，或有漏、或无漏：真正得到无常的是无漏，初学无常的是有漏。

摩诃衍中，诸菩萨心胸广大，以种种方式教化一切众生，所以这无常想也有漏、也无漏；如果是无漏，在九地中；如果是有漏，在十一地中。以三界的五受众为所缘；与四根相应，除去苦根；凡夫、圣人都能得到。像这样等等种种因缘，说无常想的功德。

【译注】论主讲“具足无常想”极见分寸：见花果将谢而更生执着，只是无常的少分，与禽兽无异；具足的无常想，是观念念生灭而入空门，空中一切法不可得，所以无常也不可得，生住灭三相一念之中性相相违。随后又说佛说无常是为破常见，不是因为无常为实；然而诸法虽空，仍说无常想，因为它就是圣道的别名，持戒、多闻、禅定、头陀都只是趣涅槃之分。这一正一反，与前卷三法印“生灭与无生灭其实是一”前后相承。

### 三、苦想

“苦想”，修行者作这样的念头：“一切有为法，因为无常，所以是苦！”

#### （一）圣人有身苦而无心苦

问：如果有为法因为无常所以是苦，诸贤圣的有为无漏法，也应当是苦！

答：诸法虽然无常，爱着的人就生苦，无所执着的人就无苦！

问：有些圣人虽然无所执着，也都有苦，如舍利弗的风热病苦，毕陵伽婆蹉的眼痛之苦，罗婆那跋提（音声第一者）的痔病之苦，为什么说“无苦”？

答：有两种苦：一是身苦，二是心苦。

这些圣人因为智慧之力，不再有忧愁、嫉妒、瞋恚等心苦；已经受了由前世业因缘而由四大所造的身体，有老病、饥渴、寒热等身苦；在身苦中也很少很轻。如人清清楚楚地知道欠了别人的债，偿还时不以为苦；如果人不记得欠债，债主强行夺取，就生起瞋恼而受苦。

问：苦受是心与心所法，身体如草木，离开心就无所觉知，为什么说“圣人只受身苦”？

答：凡夫受苦时，心中生起愁恼，被瞋使所驱使，心只趣向五欲。如佛所说：“凡夫除了五欲，不知道还有出离苦的方法；在乐受中，被贪欲使所驱使；在不苦不乐受中，被无明使所驱使；凡夫受苦时，内受三毒之苦，外受寒热、鞭杖等苦。如人内热盛，外热也盛。”如经中说：“凡夫失去所爱之物，身心都受苦，如两支箭同时射中；诸贤圣人没有忧愁之苦，只有身苦，再没有其他的苦。”

再者，与五识相应的苦，以及外在因缘的杖打、寒热等苦，这名为身苦；其余的名为心苦。

再者，我说“有为无漏法，因为不执着，所以不是苦”；圣人的身体是有漏的，有漏法就是苦，有什么过失？这是最后之身所受的苦，也很微少。

#### （二）道虽无常而非苦

问：如果“无常就是苦”，道也是苦，怎么能以苦来离苦？

答：“无常就是苦”，是就五受众而说的；道虽然是造作之法，所以无常，却不名为苦。为什么？因为它能灭苦，不生起诸执着，与空、无我等诸智慧和合，所以只是无常而不是苦。如诸阿罗汉得道时说偈：

```
我等不贪生，　　亦复不乐死；
一心及智慧，　　待时至而去！
```

大意：我们不贪着生，也不乐于死；以一心与智慧，等待时候到来而离去！

佛入涅槃时，阿难等诸未离欲的人，因为还没有善修八圣道，都哭泣忧愁；诸已离欲的阿那含，都惊愕；诸漏尽的阿罗汉，其心不变，只说“世间之眼灭得太快了！”因为得道之力，虽然从佛那里得到大利益，知道尊重佛的无量功德，也不生苦。所以知道道虽然无常，因为不是苦的因缘，所以不名为苦；只有五受众是苦。为什么？因为爱着，因为无常败坏。如受念处中苦的意义，这里应当详细说。

再者，苦，是有身体就常是苦，因为被愚痴覆盖而不觉察。如偈中说：

```
骑乘疲极故，　　求索住立处；
住立疲极故，　　求索坐息处；
坐久疲极故，　　求索安卧处；
众极由作生，　　初乐后则苦。
视眴息出入，　　屈伸坐卧起，
行立及去来，　　此事无不苦！
```

大意：骑乘疲倦了，就想找地方站一站；站累了，就想找地方坐下休息；坐久了累了，就想找地方安卧；种种疲倦都由动作而生，起初快乐，后来就苦。眨眼、呼吸出入、屈伸、坐卧起身、行走站立、来来去去，这些事没有不苦的！

#### （三）五受众一切皆苦

问：这五受众，是一切都是苦？还是因为以苦想观察才是苦？如果一切都是苦，佛为什么说“有三种受：苦受、乐受、不苦不乐受”？如果因为苦想才是苦，为什么说“苦谛是真实的苦”？

答：五受众一切都是苦。凡夫因为四颠倒的因缘，被欲望所逼迫，以五欲为乐；如人涂疮，大痛暂时止息，就以为是乐，疮并不是乐。佛说三种受，是为了随顺世间，在真实之法中并不是乐！

如果五受众中确实有乐，佛为什么说“灭除五受众名为乐”？

再者，随着所嗜好的，心中乐着就生乐，并没有一定。乐如果真实确定，就不待心的执着；如火确实是热的，不待执着就是热的。因为乐没有一定，所以名为苦。

再者，世间颠倒之乐，能招致今世、后世无量的苦果报，所以名为苦。譬如大河水中放了少许毒，不能使水改变；世间颠倒之乐这毒药，在一切大苦之水中就显不出来了。如偈中说：

```
从天下生地狱时，　　忆本天上欢乐事，
宫观婇女满目前，　　园苑浴池以娱志。
又见狱火来烧身，　　似如大火焚竹林，
是时虽见天上乐，　　徒自感结无所益！
```

大意：从天上堕下生到地狱时，回忆起原来天上的欢乐之事，宫殿楼观、婇女满目，园苑浴池用来娱乐心志。又看见地狱之火来烧身，就如大火焚烧竹林；这时虽然想起天上之乐，也只是徒然感伤郁结，毫无益处！

这苦想的所摄、所缘，如无常想。

像这样等等种种分别苦，名为“苦想”。

### 四、无我想

“无我想”，苦就是无我。为什么？

五受众中全都是苦相，没有自在；如果没有自在，就是无我；如果有我而自在，就不应当使身体有苦。如偈中说：

```
诸有无智人，　　身心计是我，
渐近坚著故，　　不知无常法。
是身无作者，　　亦无有受者，
是身为无生，　　而作种种事。
六情尘因缘，　　六种识得生，
从三事和合，　　因缘触法生；
从触法因缘，　　受念业法生。
如珠日草薪，　　和合故火生，
情尘识和合，　　所作事业成；
相续相似有，　　如种有牙茎！
```

大意：一切无智的人，把身心执计为我，渐渐亲近而坚固执着，所以不知道无常之法。这身体没有作者，也没有受者；这身体本无生，却作种种事。以六根与六尘为因缘，六种识得以生起；从这三事和合，以因缘生起触法；从触法的因缘，生起受、念、业等法。如火珠、日光、草与柴和合，所以火生起；根、尘、识和合，所作的事业就成就；相续相似而有，如种子而有芽与茎！

再者，因为我相不可得，所以无我。一切法因为有相，所以知道它有，如看见烟、感觉到热，所以知道有火；在五尘中各自有分别，所以知道有根；因为种种思惟衡量诸法，所以知道有心与心所法。这我没有相，所以知道无我。

#### （一）诸相皆是识相

问：有出入的气息，就是我相；眨眼、寿命之心、苦乐、爱憎、精勤等是我相。如果无我，谁有这出入息、眨眼、寿命之心、苦乐、爱憎、精勤等？应当知道有我，因为它在内中发动。

寿命之心也是我之法；如果无我，就如牛没有驾驭者；因为有我，所以能制伏其心使之入法，不放逸。如果无我，谁来制御其心？

受苦乐的就是我；如果无我，就像树木，就不应当分别苦乐！爱憎、精勤也是这样。

我虽然微细，不能以五根知道它，因为这些相，可以知道它存在。

答：这些相都是识的相。有识，就有出入息、眨眼、寿命等；如果识离开身体就没有了。你们的我是常、遍的，那么死人也应当有眨眼、出入息、寿命等！

再者，出入息等是色法，随着心与风的力量而发动，这是识的相，不是我的相。

寿命是心不相应行，也是识的相。

问：如果入无心定中，或者睡眠无梦时，气息也出入，有寿命，为什么说“都是识的相”？

答：无心定等，识虽然暂时没有，不久必定又会生起，因为识不舍离身体；有识的时间多，无识的时间少，所以名为识的相。如人出门远行，不能说他的家没有主人。

苦乐、憎爱、精勤等，是与心相应、共同所缘、随心而行的；心有就有，心无就无。所以，这是识的相，不是我的相。

#### （二）我常与无常皆不可

再者，如果有我，我有两种：或常、或无常，如偈中说：

```
若我是常，　　则无后身；
常不生故，　　亦无解脱！
```

```
亦无妄无作，　　以是故当知：
无作罪福者，　　亦无有受者；
舍我及我所，　　然后得涅槃。
若实有我者，　　不应舍我心！
若我无常者，　　则应随身灭；
如大岸堕水，　　亦无有罪福。
```

大意：如果我是常，就没有后身；因为常而不生，所以也没有解脱！也没有妄作、没有造作，所以应当知道：没有造作罪福的人，也没有领受罪福的人；舍弃我与我所，然后才能得到涅槃。如果确实有我，就不应当舍弃我心！如果我是无常的，就应当随身体而灭；如大河岸崩塌堕入水中，也就没有罪福了。

像这样，我以及知者、不知者，作者、不作者，如檀波罗蜜中所说。因为得不到这我相，所以知道一切法中无我；如果知道一切法中无我，就不应当生起我心。

如果无我，也就没有我所之心；我与我所都离开了，就没有系缚；如果没有系缚，就是涅槃。所以修行者应当修行无我想。

#### （三）无常、苦、无我三相分别

问：这无常、苦、无我，是一件事？还是三件事？如果是一件事，就不应当说三；如果是三件事，佛为什么说“无常就是苦，苦就是无我”？

答：是一件事，就是领受有漏法。

因为观门的分别，所以有三种不同：与无常行相相应的，是“无常想”；与苦行相相应的，是“苦想”；与无我行相相应的，是“无我想”。无常使人不入三界；苦使人知道三界的罪过；无我则使人舍离世间。

再者，无常使人生起厌离之心；苦使人生起畏怖；无我使人拔出而得解脱。

无常，是佛说五受众是无常；苦，是佛说无常就是苦；无我，是佛说苦就是无我。

无常，是佛显示五受众灭尽之相；苦，是佛显示如箭射入心中；无我，是佛显示舍离之相。

无常，显示断除爱；苦，显示断除我执的习气与慢；无我，显示断除邪见。

无常，遮止常见；苦，遮止以今世为涅槃之乐的见解；无我，遮止执着之处。

无常，是指世间所可执着的常法；苦，是指世间认为快乐之处；无我，是指世间所执计为牢固之我的。

这是三相的分别之想。

无我想的所缘、所摄种种，如苦想中所说。

### 五、食厌想

“食厌想”，是观察这食物从不净的因缘而生。如肉从精血与水道而生，是脓虫的住处；如酥、乳、酪，是血变化所成，与烂脓没有差别；厨师的污垢，种种不净。如果放入口中，脑中有烂涎，从两道流下，与唾液和合，然后成为味道，其样子如同呕吐之物，从腹门进入；地大使之停住，水大使之烂软，风大使之运动，火大使之煮熟，如锅中煮熟的粥，渣滓沉在下面，清的在上面；譬如酿酒，渣滓为屎，清的为尿。腰部有三个孔，风吹动油腻的汁液，散入百脉，与原先的血和合，凝结变化为肉。从新的肉生出脂、骨、髓，从这其中生出身根；从新旧之肉和合生出五根，从五根生出五识；五识之后依次生起意识，分别取相，衡量好丑；然后生起我、我所之心等诸烦恼，以及诸罪业。观察食物这样的本末因缘，种种不净。知道内在的四大与外在的四大没有差别，只因为我见的缘故，勉强认为是我所有。

再者，思惟这食物，开垦种植、耘田除草，收获踩踏整治，舂磨淘洗，烧火煮熟才成，用功非常重；算起一钵饭，耕作的人流的汗聚集起来，衡量一下，食物少而汗水多。这食物制作的功夫这样重，辛苦这样多，入口吃下，就成为不净，一文不值，一夜之间就变成屎尿。本来是美味，为人所嗜好；变成不净，就厌恶得不想看。

修行者自己思惟：“这样粗劣的食物，我如果贪着，当堕地狱吞烧红的铁丸；从地狱出来，当作畜生：牛、羊、骆驼，偿还宿世的债；或者作猪狗，常吃粪便。”这样观察食物，就生起厌离之想；因为厌离食物，所以对五欲都生厌离。

#### 婆罗门食痈脓饼

譬如一位婆罗门修习洁净之法，因为有事要到一个不净的国家；他自己想：“我怎样才能免于这里的不净？只有吃干的食物，才能得以清净。”看见一位老妇卖白髓饼，就对她说：“我因为有事要在这里住一百天，你常做这种饼送来，我会多给价钱！”老妇每天做饼送给他；婆罗门贪着，吃饱了很欢喜。老妇做的饼，起初白净；后来变得没有颜色、没有味道。他就问老妇：“为什么这样？”老妇说：“因为痈疮好了。”婆罗门问：“这话是什么意思？”老妇说：“我家主人的夫人在隐秘处生了痈，用面、酥、甘草敷在上面，痈熟了，脓流出来，和着酥做成饼；每天都这样，我用这个做饼给你，所以饼好吃；现在夫人的痈好了，我到哪里再去得到？”婆罗门听了，两拳打头，捶胸呕吐：“我怎么破了这清净之法？我完了！”丢下事务，跑回本国。

修行者也是这样，执着这饮食，欢喜乐吃，看到它的好颜色、细滑，香美可口，不观察其不净；后来受苦报，后悔又怎么来得及！如果能这样观察食物的本末，生起厌恶厌离之心；因为离开对食物的欲望，其余四欲也都舍弃，对欲界中的快乐全都舍离；断除这五欲，五下分结也断了。

像这样等等种种因缘的恶与罪，不再乐着，这名为“食厌想”。

#### 十想的次第

问：无常、苦、无我三想，与无漏智慧相应；食厌等四想，与有漏智慧相应；按次第应当在前，现在为什么在后面说？

答：佛法有两种道：见道，修道。

在见道中用这三想，破除诸邪见等，得到圣果，还没有离欲；为了离欲，所以在三想之后接着说这食厌等四想，得以离开淫欲等诸烦恼。

最初三想显示见谛道，中间四想显示有学的修道，最后三想显示无学道。

最初修习身念处时，虽然有食厌想，因为作用少，所以佛不说。现在为了须陀洹、斯陀含度脱欲界，所以在无我想之后接着说食厌等四想。

### 六、一切世间不可乐想

“一切世间不可乐想”，如果念世间的色欲滋味、车乘、服饰、房舍楼观、园宅，种种乐事，就生起乐想；如果念世间种种罪恶之事，心中就生起厌离之想。什么是恶事？恶事有两种：一是众生，二是土地。

#### （一）众生之恶

众生有八苦之患：生、老、病、死，恩爱别离，怨憎同处，所求不得，简要地说，五受众苦。

众生的罪过：因为淫欲多，不分好丑，不听从父母、师长的教诲，没有惭愧，与禽兽没有差别。因为瞋恚多，不分轻重，瞋毒狂发，乃至不接受佛语，不想听法，不畏惧恶道；横加杖打，不知他人之苦；进入大黑暗之中，一无所见。因为愚痴多，所求不依正道，不认识事物的因缘，如挤牛角求奶；被无明覆盖，虽然蒙日光照耀，永远一无所见。因为悭贪多，家如坟墓，人们不愿前往。因为憍慢多，不敬贤圣，不孝父母，骄纵放逸而自毁，永远一文不值。因为邪见多，不信今世、后世，不信罪福，不可与他共处。像这样等等，因为诸烦恼多，所以败坏而一文不值。

因为恶业多，造无间罪：或者杀害父母，或者伤害贤圣。或者为了一时的荣贵，谗害忠贞之人，残害亲戚。

再者，世间众生，善良美好的少，粗劣丑恶的多。或者有时虽然有善行，却贫贱鄙陋；或者虽然富贵端正，所行却不善；或者虽然好布施，却贫乏无财；或者虽然富有财宝，却悭惜贪着，不肯布施；或者看见有人有所思虑，沉默不语，便说他骄傲自负，不屈身待人；或者看见有人好屈身待人，恩惠普遍滋润，便说他欺诳、谄媚、装饰；或者看见有人能言善辩，便说他依恃小智而骄慢；或者看见质朴正直的好人，便一起欺诳戏弄他，拉扯欺凌；或者看见善心柔和的人，便一起轻视欺凌践踏，不以道理对待；如果看见持戒清净的人，便说他所行矫情怪异，轻贱不屑。

像这样等等众生的粗劣丑恶，没有一样可乐的。

#### （二）土地之恶

土地之恶：一切土地，多有衰败而无吉祥，寒热饥渴；疾病恶疫，毒气侵害，老、病、死的畏惧，无处没有。身体所去之处，众苦都随着，无处可以免除！即使有美好的国家，丰饶安乐稳定，也多被诸烦恼所恼乱，就不名为乐土。一切处都有两种苦：身苦、心苦，没有一个国家没有。如偈中说：

```
有国土多寒，　　或有国多热，
有国无救护，　　或有国多恶，
有国常饥饿，　　或有国多病，
有国不修福，　　如是无乐处。
```

大意：有的国土多寒冷，有的国家多炎热；有的国家没有救护，有的国家多恶人；有的国家常常饥饿，有的国家多疾病；有的国家不修福德，像这样没有一处是快乐的地方。

众生与土地有这样的恶，思惟世间没有一样可乐的。

欲界的恶事是这样。

上二界死时、退失时，生起的大懊恼比下界还厉害；譬如从极高处坠落，摔得粉碎烂坏！

问：无常想、苦想、无我想、一切世间不可乐想，有什么不同而分别说？

答：有两种观察：总观，别观。前面是总观，这里是别观。

又有两种观察：法观、众生观。前面是呵责一切法的观察，这里是观察众生罪恶的不同。

再者，前面是无漏道，这里是有漏道。

前面是见谛道，现在是思惟道。

像这样等等种种差别。

这想在一切地中所摄，以三界之法为所缘。

这名为“一切世间不可乐想”。

### 七、死想、不净想

“死想”，如念死中所说。

“不净想”，如身念处中所说。

### 八、断想、离想、尽想

“断想”、“离想”、“尽想”，以涅槃之相为所缘。

因为断除诸结使，所以名为“断想”；因为离开结使，所以名为“离想”；因为尽除诸结使，所以名为“尽想”。

问：如果是这样，一种想就够了，为什么说三种？

答：如前面一法作三种说：无常就是苦，苦就是无我；这里也是这样，因为一切世间罪恶深重，所以以三种方式呵责。如砍伐大树，不能一下砍断。涅槃是微妙之法，从前所未曾得到的，所以种种赞叹，名为“断想”、“离想”、“尽想”。

再者，因为断除三毒，所以名为“断”；因为离开爱，所以名为“离”；因为灭除一切苦，不再生起，所以名为“尽”。

再者，修行者在暖法、顶法、忍法、世间第一法中，以正确的智慧观察，远离诸烦恼，这名为“离想”；得到无漏道，断除诸结使，这名为“断想”；入涅槃时，灭除五受众，不再相续，这名为“尽想”。

“断想”是有余涅槃；“尽想”是无余涅槃；“离想”是两种涅槃的方便之门。

这三想有漏、无漏，所以在一切地中所摄（十想到此结束）。

## 初品中十一智释论第三十八（丹本注：三三昧义、三根义合在此品）

【经】“十一智：法智、比智、他心智、世智、苦智、集智、灭智、道智、尽智、无生智、如实智。”

【论】

### 一、十一智释名

“法智”，是对欲界所系之法的无漏智，对欲界所系之因的无漏智，对欲界所系之法的灭的无漏智；对断除欲界所系之法的道的无漏智，以及法智品中的无漏智。

“比智”，是对色界、无色界中的无漏智，也是这样。

“他心智”，是了知欲界、色界所系的现在他人的心与心所法，以及无漏心与心所法的少分。

“世智”，是诸有漏的智慧。

“苦智”，是观察五受众无常、苦、空、无我时所得的无漏智。

“集智”，是观察有漏法之因的因、集、生、缘时的无漏智。

“灭智”，是观察灭、止、妙、出时的无漏智。

“道智”，是观察道、正、行、达时的无漏智。

“尽智”，是“我已见苦，已断集，已证灭，已修道”；这样念时，无漏的智慧、见、明、觉。

“无生智”，是“我已见苦，不再更见；已断集，不再更断；已证灭，不再更证；已修道，不再更修”；这样念时，无漏的智慧、见、明、觉。

“如实智”，是对一切法的总相、别相，如实正确地了知，没有挂碍。

### 二、诸智的所缘、相摄、相应等（阿毗昙分别）

这法智缘欲界所系之法、欲界所系之法的因、欲界所系之法的灭、断除欲界所系之法的道。

比智也是这样。

世智缘一切法。

他心智缘他人有漏、无漏的心与心所法。

苦智、集智缘五受众；灭智缘灭尽；道智缘无漏五众。

尽智、无生智都缘四谛。

十智中，一种是有漏，八种是无漏，一种应当分别：他心智，缘有漏心时是有漏，缘无漏心时是无漏。

法智，摄法智，以及他心智、苦智、集智、灭智、道智、尽智、无生智的少分。

比智也是这样。

世智，摄世智以及他心智的少分。

他心智，摄他心智，以及法智、比智、世智、道智、尽智、无生智的少分。

苦智，摄苦智，以及法智、比智、尽智、无生智的少分。

集智、灭智也是这样。

道智，摄道智，以及法智、比智、他心智、尽智、无生智的少分。

尽智，摄尽智，以及法智、比智、他心智、苦智、集智、灭智、道智的少分。

无生智也是这样。

九智与八根相应，除去慧根、忧根、苦根。

世智与十根相应，除去慧根。

法智、比智、苦智，与空三昧相应。

法智、比智、灭智、尽智、无生智，与无相三昧相应。

法智、比智、他心智、苦智、集智、道智、尽智、无生智，与无作三昧相应。

法智、比智、世智、苦智、尽智、无生智，与无常想、苦想、无我想相应。

世智与中间四想相应；法智、比智、灭智、尽智、无生智，与后三想相应。

有人说：世智有时与离想相应。

法智缘九智，除去比智；比智也是这样。

世智、他心智、尽智、无生智，缘十智。

苦智、集智，缘世智以及有漏的他心智。

灭智不缘智。

道智缘九智，除去世智。

法智、比智：有十六行相。

他心智有四行相。

苦、集、灭、道智，各有四行相。

尽智、无生智，都有十四行相，除去空相、无我相。

在暖法、顶法、忍法中，世智有十六行相；在世间第一法中，世智有四行相，除去无相（原文小注：即转相观相，旧译为十六圣行）。

初入无漏心时，成就一种世智；第二心增加苦智、法智；第四心增加比智；第六心增加集智；第十心增加灭智；第十四心增加道智。如果是离欲的人，增加他心智；无学道增加尽智；得不坏解脱，增加无生智。

初无漏心中不修智；第二心中，现在、未来修二智；第四心中，现在修二智，未来修三智；第六心中，现在、未来修二智；第八心中，现在修二智，未来修三智；第十心中，现在、未来修二智；第十二心中，现在修二智，未来修三智；第十四心中，现在、未来修二智；第十六心中，现在修二智，未来修六智；如果已离欲，修七智。

须陀洹想离欲界结使，在十七心中修七智，除去他心智、尽智、无生智。在第九解脱心中修八智，除去尽智、无生智。

信解脱之人转为见得，在双道中修六智，除去他心智、世智、尽智、无生智。

离七地之欲时，在无碍道中修七智，除去他心智、尽智、无生智；在解脱道中修八智，除去尽智、无生智。

离有顶之欲时，在无碍道中修六智，除去他心智、世智、尽智、无生智；在八解脱道中修七智，除去世智、尽智、无生智。

无学的初心第九解脱，不时解脱的人修十智，以及一切有漏、无漏善根；如果是时解脱的人，修九智，以及一切有漏、无漏善根。

像这样等等种种，以阿毗昙门详细分别。

“如实智”的分别之相，在这《般若波罗蜜经》后面的品中详细说。

### 三、另一种解释

再者，有人说：

“法智”，是了知欲界五众无常、苦、空、无我，了知诸法因缘和合而生，就是以无明为因缘有诸行，乃至以生为因缘有老死。如佛为须尸摩梵志所说：“先用法智分别诸法，后用涅槃智。”

“比智”，是了知现在的五受众无常、苦、空、无我；过去、未来以及色界、无色界中的五受众，也是无常、苦、空、无我。譬如看见现在的火热能烧，以此比知过去、未来以及其他国家的火也是这样。

“他心智”，是了知其他众生的心与心所法。

问：如果是了知他人的心与心所法，为什么只名为“知他心”？

答：因为心是主，所以只名为知他心；如果说了心，应当知道已经说了心所法。

“世智”，名为假智。圣人在实法中了知，凡夫只在假名中了知，所以名为假智。如栋梁、椽子、墙壁名为房屋，只知道这事，不知道真实的意义，这名为世智。

“苦智”，是用苦的智慧呵责五受众。

问：五受众也是无常、也是苦、也是空、也是无我，为什么只说“苦智”，不说“无常智、空智、无我智”？

答：为了苦谛，所以说“苦智”；为了集谛，所以说“集智”；为了灭谛，所以说“灭智”；为了道谛，所以说“道智”。

问：五受众有种种过恶，为什么只说苦谛，不说无常谛、空谛、无我谛？

答：如果说无常、空、无我谛，也不破坏法相；因为众生多执着乐、畏惧苦，佛呵责世间一切都是苦，想使他们舍离。对无常、空、无我，众生不大畏惧，所以不说。

再者，在佛说法中，五受众有另一个名称，名为苦；所以只说苦智。

这苦智，或有漏、或无漏：如果在暖法、顶法、忍法、世间第一法中，是有漏；如果进入见谛道，是无漏。为什么？从暖法到世间第一法中，以四种行相观察苦。

“集智”、“灭智”、“道智”也是这样。

再者，“苦智”名为了知苦相实际上不生。

“集智”名为了知一切法本来离散，没有和合。

“灭智”名为了知诸法常寂灭，如涅槃。

“道智”名为了知一切法常清净，无正无邪。

“尽智”名为了知一切法无所有。

“无生智”名为了知一切生法不实、不定，所以不生。

### 四、如实智

“如实智”，是十种智所不能了知的，以如实智所以能知。

十智各有其相，各有其所缘，各有区别，各有观法；这如实智中无相、无所缘、无分别，灭除诸观法，也不存有观。

十智中有法眼、慧眼；如实智中唯有佛眼。

十智，阿罗汉、辟支佛、菩萨共有；如实智唯独佛有。为什么？唯独佛有不诳之法。所以，知道如实智唯独佛有。

再者，这十智进入如实智中，失去原来的名字，唯有一个实智。譬如十方诸流水，都流入大海，舍弃原来的名字，只名为大海。

【译注】十一智前十种是阿毗昙通义，论主照录其所缘、相摄、相应、行相与见道十六心中的增修；而“如实智”一智，独唯佛有，无相、无缘、无别，灭诸观法，不有观。随后另一家的解释更进一层：苦智知苦相实不生，集智知一切法离无和合，乃至无生智知一切生法不实不定故不生，是以般若的眼光重读十智。末以十方诸流入海、失本名字为喻，说十智入如实智中唯有一实智。

像这样等等种种分别十一智的意义，这里略说（丹本注：十一智到此结束）。

## 三三昧

【经】“三三昧：有觉有观三昧，无觉有观三昧，无觉无观三昧。”

【论】

### 一、三昧释名

一切禅定收摄其心，都名为三摩提，汉语意为正心行处。这心从无始世界以来，常弯曲不正，得到这正心行处，心就端直；譬如蛇行走常是弯曲的，进入竹筒中就直了。

这三昧有三种：

欲界、未到地、初禅，与觉观相应，所以名为“有觉有观”；二禅中间（中间禅）只与观相应，所以名为“无觉有观”；从第二禅乃至有顶地，不与觉观相应，所以名为“无觉无观”。

### 二、何以只说觉观

问：与三昧相应的心所法，乃至有二十种，为什么只说“觉”、“观”？

答：这觉观扰乱三昧，所以说它。这两件事虽然是善，却是三昧之贼，难以舍离。

有人说：心有觉观的就没有三昧；所以佛说有觉有观三昧，只是不牢固；觉观的力量微小时，这时可以有三昧。这觉观能生三昧，也能坏三昧；譬如风能生雨，也能坏雨。三种善的觉观，能生初禅；得到初禅时生起大欢喜，因为觉观，心散乱又失去了；所以只说“觉”、“观”。

问：觉与观有什么差别？

答：粗的心相名为“觉”，细的心相名为“观”；最初对所缘心中发起之相名为“觉”，后来分别衡量好丑名为“观”。

有三种粗觉：欲觉，瞋觉，恼觉。

有三种善觉：出要觉，无瞋觉，无恼觉。

有三种细觉：亲里觉，国土觉，不死觉。

六种觉妨碍三昧，三种善觉能开启三昧之门。

如果觉观过多，反而失去三昧；如风能使船前进，风太大就毁坏船。

像这样种种分别“觉”、“观”。

### 三、三法、三地与三三昧

问：经中说三种法：有觉有观法，无觉有观法，无觉无观法；有觉有观地，无觉有观地，无觉无观地。现在为什么只说三种三昧？

答：取其中微妙而可用的。

有觉有观法，是欲界、未到地、初禅中与觉观相应的法，或善、或不善、或无记。

无觉有观法，是中间禅中与观相应的法，或善、或无记。

无觉无观法，是离开觉观之法，一切色法、心不相应行以及无为法。

有觉有观地，是欲界、未到地、梵世（初禅天）。

无觉有观地，是中间禅，善修这地，作大梵王。

无觉无观地，是一切光音天、一切遍净天、一切广果天、一切无色地。

在其中上妙的是三昧。什么是三昧？

从空等三三昧，乃至金刚三昧，以及阿罗汉、辟支佛的诸三昧；观十方佛三昧，乃至首楞严三昧；从断一切疑三昧，乃至三昧王等诸佛三昧。

像这样等等种种分别，略说三三昧的意义完毕。

## 三根

【经】“三根：未知欲知根，知根，知已根。”

【论】

### 一、三根释名

“未知欲知根”，是无漏的九根和合，信行、法行之人在见谛道中，名为“未知欲知根”，就是信等五根，喜根、乐根、舍根，意根。

信解、见得之人在思惟道中，这九根转名为“知根”。

在无学道中，这九根名为“知已根”。

### 二、何以二十二根中只取三根

问：为什么在二十二根中只取这三根？

答：锐利、明了、自在之相，这名为“根”；其余十九根，根的相不具足，所以不取。这三根锐利，能直接进入涅槃，在诸有为法中为主，所以得到自在，能胜过诸根。

再者，十根只是有漏而自然得到，没有什么利益；九根不确定，或有漏、或无漏；所以不说菩萨应当具足。

问：十想也是有漏、也是无漏，为什么说应当具足？

答：十想都是助道求涅槃之法；信等五根虽然是善法，却不都是求涅槃。如阿毗昙中说：“谁成就信等五根？是不断善根的人。”

再者，如果五根清净转为无漏，三根中已经包括了。这三根中必定有意根，三受中必定有一受；所以只说三根。

再者，二十二根有善、有不善、有无记，夹杂在一起，所以不说应当具足。

这三根，为受众、行众、识众所摄。

未知欲知根在六地中，知根、知已根在九地中。

三根缘四谛；与六种想相应。

未知欲知根，是三根之因；知根，是二根之因；知已根，只是知已根之因。

未知欲知根之后，依次生起两种根；知根之后，或者生起有漏根，或者生起知根，或者生起知已根；知已根之后，或者生起有漏根，或者生起知已根。

像这样等等，以阿毗昙门详细分别说明。

### 三、摩诃衍的三根

再者，未知欲知根，所欲知的是诸法实相；因为未知而欲知，所以生起信等五根；以这五根之力，能得到诸法实相。

如人最初入胎时得到两种根：身根、命根；那时如一团肉，还没有具足诸根，不能有所分别了知；五根成就之后，能了知五尘。菩萨也是这样，初发心想作佛，还没有具足这五根，虽然有愿想知道诸法实相，却不能知道。菩萨生起这信等五根，就能了知诸法实相。

如眼，是四大以及四大所造之色和合，名为眼；先前虽然有四大、四大所造之色，因为还没有清净，所以不名为眼根；不断善根的人虽然有信，因为还没有清净，所以不名为根。

如果菩萨得到这信等五根，这时能信诸法实相：不生不灭，不垢不净，非有非无，非取非舍，常寂灭，真实清净，如虚空，不可指示、不可言说，超过一切言语之道，出离一切心与心所法，所行如涅槃，这就是佛法。

菩萨因为信根之力，能够领受；因为精进根之力，勤行而不退不转；因为念根之力，不让不善法进入，收摄诸善法；因为定根之力，心散在五欲中时，能收摄于实相中；因为慧根之力，在佛的智慧中或多或少得到义味而不可破坏。

五根所依的意根，必定与受同在，或喜、或乐、或舍。

依这些根进入菩萨位，乃至还没有得到无生法忍之果，这名为“未知欲知根”。

在这其中清清楚楚地了知诸法实相，所以名为“知根”。从这里得到无生法忍之果，住在阿鞞跋致地（不退转地）而得受记，乃至圆满十地、坐道场、得金刚三昧，在这其间，名为“知根”。

断除一切烦恼与习气，得阿耨多罗三藐三菩提，对一切可知之法智慧遍满，所以名为“知已根”（丹本注：三根到此结束）。

## 本卷要义

本卷释十想、十一智、三三昧与三根，四组法相连读，可以看出一条次第：十想是助道求涅槃的观门，十一智是观门所成的智慧，三三昧说的是这些智慧所依的定心，三根则把整个修道历程按见道、修道、无学道排出来。

十想一品，论主先区分念、想、智：初习为不失故名念，能转相转心名想，决定无疑名智。无常想讲得最透：见花果将谢而更生执着，只是知无常的少分；具足的无常想，是观念念生灭而入空门，空中无常也不可得，因为一念之中生住灭三相性相相违。然而佛仍说无常想，因为它是圣道的别名，持戒、多闻、禅定、头陀都只是趣涅槃之分。苦想区分身苦与心苦：圣人无心苦，只有宿业所成之身的苦，如了知负债而偿之不以为苦；道虽是作法而无常，因能灭苦、不生诸著，所以不名为苦。无我想则说出入息、视眴、寿命、苦乐、爱憎等一切被认作我相的，其实都是识相，有识则有，识离则无，如人出行不可言家无主。

食厌想以食物的本末因缘为观：从耕作的汗水到入口成涎、入腹成糜、清浊分为屎尿、凝变为肉而生诸根诸识、乃至生我我所心与诸罪业，婆罗门食痈脓饼的故事尤其令人难忘。十想的次第由此显出：初三想示见谛道，破诸邪见；中四想示学人的修道，为离欲；后三想断、离、尽示无学道，缘涅槃相，如伐大树不可一下而断。不可乐想则从众生之恶与土地之恶两面写世间无一可乐，众生的善恶颠倒之见一段，读来极为切实。

十一智前十智依阿毗昙法相详列，而如实智独唯佛有：无相、无缘、无别，灭诸观法亦不有观。另一家的解释更以般若重读十智，苦智知苦相实不生，集智知一切法离无和合，道智知一切法常清净无正无邪。十智入如实智，失本名字，唯有一实智，如十方众流入海。三三昧说觉观能生三昧也能坏三昧，如风能使船，风过则坏船；三根则以人初入胎唯有身命二根、五根具足方知五尘为喻，说菩萨未具信等五根，虽愿欲知诸法实相而不能知，具足五根则能信受实相不生不灭、如虚空、出一切心心数法。从入菩萨位到无生法忍是未知欲知根，从无生忍到金刚三昧是知根，断一切烦恼习、智慧遍满一切可知法是知已根，二乘的三根在这里被铺展为整个菩萨道。
