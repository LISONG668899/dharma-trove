中观四大正因如下：

- 观察因的金刚屑因
- 观察果的破有无生因
- 观察体性的离一多因
- 观察一切的大缘起因

**【译注】** 这四大因是应成中观（以月称论师为宗的中观见地）用来抉择"万法无自性"最常用的四套推理工具，各自从不同的角度下手：金刚屑因专破"因"上的执著，破有无生因专破"果"上的执著，离一多因直接观察事物本身的"体性"，大缘起因则是从整体上说明一切法皆是缘起，因而无自性。四者角度不同，但都指向同一个结论：万法没有独立、真实、不待他缘的自性。

---

## 一、观察因：金刚屑因

**【译注】** "金刚屑因"这个名字的意思是：像金刚粉末一样，能把一切坚固的执著碾碎。它专门针对"果是从因产生的"这个我们习以为常的观念，逐一审察：因生果，到底是怎么个"生"法？下面依次破斥四种可能——自生、他生、共生、无因生，合称"破四边生"。

### （一）破四边生

#### 1. 破自生

仅就世俗名言而言，果确实从因而生，这是不争的事实。然而若以胜义理论加以审察，则所谓"生"根本无从观察到。假如存在一种能够经得起正理推敲的"生"，那它必然属于以下四种方式之一：自生、他生、自他共生、无因生。但这四种生都不合理。

如《中观根本慧论》（《中论》）所说：

```
诸法不自生，亦不从他生，
不共不无因，是故知无生。
```

为什么呢？首先，事物从自身而生，在道理上说不通。因为一个事物一旦以其自身特有的体性而存在，就没有必要再重新生起。这就好比一个孩子既已降生，就不会再生一次。比如一粒种子，如果要从自身再度产生自身，那就会无穷无尽地反复生下去，芽、茎等后续阶段永远不会出现。

主张自生的数论派认为：就像从泥土这一本体中能制作出瓶子等不同形态一样，种子等诸法本是同一本体，只是舍弃了种子的显现形态，转变为芽的显现形态而已。但如果把种子和芽这些阶段——尽管在"当下是否存在"、颜色、形状等方面明明有差别——硬说成是"一体"，那就会被应成论法（归谬法）所破斥：按此逻辑，火与水、善与恶也应该是一体了。

**【译注】** "数论派"是古印度一个非佛教哲学流派，主张世间万法都是从一个根本的"自性"（原质，prakṛti）中展开变化出来的，就像泥土可以捏成瓶、盆各种形状一样，所以他们承认"自生"——果本来就潜藏在因里，只是换了个显现形式。"应成论法"（归谬法）是佛教因明中常用的一种论辩方式：先假设对方的主张成立，然后推出一个荒谬的、对方自己也不能接受的结论，从而反过来证明原来的主张不成立——这里就是先假设"种子和芽是同一体"，然后推出"那么水火、善恶也该是一体"这个荒谬结论，以此说明"自生"讲不通。

你或许会说：种子和芽不同于火和水，因为它们属于同一相续。然而所谓"相续"，不过是对刹那刹那的现象基于前后相似性的不间断延续而安立的假名，并非实有。

**【译注】** "相续"是佛教里一个很关键的概念，指一系列前后相似、连续不断的刹那生灭现象，比如一条河流看似是"同一条河"，其实每一刹那的水都不同，只是相似相续，我们才安立"河流"这个概念。这里说：种子和芽之所以让人觉得是"一体"，只是因为它们前后相续、相似，这只是名言上的假立，并不代表背后真有一个不变的实体在贯穿始终。

如《入中论》所说：

```
若计已生复更生，实生芽等不可得，
种于世末不应尽，种生何殊芽色形。
```

（大意：如果认为已经产生的东西再度产生，那么芽等的真实生起永远不可能发现。种子将一直重复生自己直到世界末日。对你们来说，作为能生之因的种子与所生之芽在形状、颜色、味道、功能、成熟等方面应当没有差别。）

```
种若未变即为芽，芽时非有种子名，
或二一故芽存时，种亦应被见，不成。
```

（大意：如果你们的种子与芽没有差别，那么种子存在时就不应该有"芽"这个说法；或者，既然二者一体，那芽存在时种子也应该被看到——这都说不通。）

又说：

```
因灭方见果，故同不成立，
此种世亦遮。
```

（大意：唯有因消失之后才能见到果，所以"因果一体"的说法连世间人也不会接受。）

不仅经论如此阐述，世间人的直接经验也表明：因消失之后，果才出现。既然连世间人都不会承认因即是果，那么自生在世俗、胜义两个层面上都不存在。

#### 2. 破他生

你或许同意自生不合理，而认为：就像孩子从母亲而生、芽从种子而生一样，生只能是从"他"而生。诚然，因和果在名言上确实被称为"他"，但这种"他生"同样经不起正理的推敲。

如果因与果在本质上确实是截然不同的"他体"，那果就不需要依赖因，二者的能力也应该对等。一个事物已经存在，就不必再从另一事物而生——就像两个已经出生的人不会彼此依赖对方来"出生"。

如果一物可以从另一物（作为"他"的他物）而生，那就应该任何东西都能从任何东西产生——比如黑暗应该能从酥油灯产生，因为它们之间同样是"他"的关系。

**【译注】** 这一条破的关键是"真实的他体"。世俗上说种子和芽是"他"（不同的东西），这没有问题；但如果说它们是**胜义上真实独立、毫不相干的两个实体**，那么"他"和"他"之间的关系就没有任何特殊性可言了——灯和黑暗也是"他"，为什么灯不能生出黑暗？可见，仅凭"他"这一点是不能建立生起关系的，除非承认因果之间有某种缘起的联系——而那已经不是"真实他体"意义上的"他生"了。

如《入中论》所说：

```
若谓依他而生者，火焰亦应生黑暗。
```

又说：

```
因果全然是他者，终不合理。
若因果全然为他，因则等同非因。
```

你或许会说："在真正不同的事物（如光明和黑暗）之间，因果关系固然不可预测。但种子和芽之间存在着特殊的'能生所生'关系——前因产生后果，所以不会出现任何东西都能产生任何东西、比如黑暗从火焰中生出的问题。"

对此，《入中论》说：

```
大麦花蕊金夏花，非生稻芽汝许之，
以无功能非同续，非相同故。稻种亦，
是他故应知亦尔。
```

（大意：大麦、花蕊、金夏花等不能产生稻芽，你们也承认这一点，理由是它们没有那种能力、不属于同一相续、类型不同。但稻种与稻芽如果在胜义分析中被确立为真正的"他体"，道理完全一样——它们同样不能归属于同一相续。）

虽然这并不影响最终的结论——即一个事物的能生者在胜义上绝不可能属于该事物的同一相续——但在世俗层面，由于诸法并非本质上的"他体"而是缘起互依的，所以将能生者归入同一相续在名言上是可以安立的。

进一步说，在任何特定时刻，种子和芽二者必有一个是不存在的——尚未生起或已经灭去——那么"能作用者"和"被作用者"的关系如何成立呢？这些不过是假名施设而已。

"虽然种子和芽不同时存在，但并无过失，因为它们就像天平的两端那样——此起彼落。"如果你这样主张，那么种子正在灭去时趋向毁灭，虽然当下存在却不会延续到下一刹那；而芽正在生起时趋向产生，尚未与种子同时存在。因此，二者之间根本没有任何"接触"的可能，天平的比喻毫无意义。

《入中论》说：

```
眼识若异于俱生之因——
眼根及同起受想等，
已是他故何须更生？
若未存在，前说过已述。
```

（大意：如果眼识已经作为"他体"而存在——区别于它自身的俱生因，即眼根、所缘境及同时生起的受、想等心所——那它何必还要被产生呢？如果它尚不存在，那所谓的"他体"关系就无从成立，前面已说明了其中的过失。）

**【译注】** 这里举"眼识"为例，是把破他生的道理从"前后异时的因果"（种子和芽）延伸到"同时并存的因果"（比如眼识生起的当下，眼根、境相、受、想等心所是同时具足的）。"心王"指识本身（比如眼识），"心所"指伴随识而起的种种心理作用（如受、想）。这一段是说：无论异时还是同时的因果关系，只要坚持"因果是真实的他体"，就都免不了这些过失。

因此，同时存在的心王与心所、四大种等，只是在名言上安立为因果关系。如果心王与心所等是以真实"他体"的方式产生的，就会落入前面所述的种种过失。

**【译注】** "四大种"指地、水、火、风四种构成物质的基本元素，佛教用它来解释一切色法（物质现象）的生成，这里只是举例说明"同时因果"的另一种情况。

所以，关于芽从种子而生之类的现象，龙树菩萨说：

```
已坏及未坏，种中无有芽，
佛说一切生，如同幻化起。
```

意思是说，缘起显现经不起正理的推敲。以寻究胜义的理论来考察时，连所谓"生"的丝毫影子都不可得。然而，在不加分析的情况下，就像梦中的显现一样，芽确实看起来是从种子产生的，这只是世俗层面的安立方式。

同理，仅在世俗名言上，可以说相似相续有住有灭；但在胜义上，既然最初没有观察到任何"生"，最后也不可能有真实的"灭"，中间也不会有真实的"住"。因此，诸法远离生、住、灭三者。

所以，从二谛无违双运的角度来看，一切显现恰如幻化、梦境、乾闼婆城、水中月影等比喻所示。

**【译注】** "二谛"指世俗谛与胜义谛。世俗谛是指未经胜义理论审察、随顺凡夫认知而安立的种种显现（种子生芽、人有生死等）；胜义谛是指以理智推究到底所见的实相——万法无自性、空性。"二谛无违双运"是说：世俗层面的因果显现和胜义层面的空无自性，二者并不矛盾，恰恰是同一件事的两面——正因为是缘起假立（世俗），所以才是空性（胜义）；正因为是空性，所以才能有缘起的显现，这就是中观最核心的"显空不二"。"乾闼婆城"是佛经中常用的比喻，指海市蜃楼一类的幻景，看似有城郭楼台，实际并无实体，用来比喻诸法虽显现宛然而无自性。

如此以胜义理论进行分析，由于一切法缺乏自性这一关键要点，种子和芽等无论以真实"一体""他体"或任何方式，都不能成立其本质。

其他佛教内道的实有论者或许会说："虽然其余三种生——自生等——可以被破斥，但如果我们不承认他生，岂不是与'芽从种生、酥从奶出'等世间常识相矛盾？"并无矛盾。实际上，运用正理加以审察，不仅在胜义上，即便在世俗上，"生"也从未被真实观察到。如果"生"在世俗上可以被观察到并得到证实，那就会导致如下过失：五蕴、诸界等世俗谛法将变得不受胜义分析的影响；真实的"生"将无法被破除；圣者的根本定将变成摧毁先前已存在的世俗法的因——这就会堕入将实有说为非有的损减边。无论如何，这种主张都是不可能成立的。

**【译注】** "实有论者"指佛教内部承认某些法（比如极微尘、刹那心识）是真实、有自性存在的宗派，比如说一切有部、经量部等，他们和主张一切法皆无自性的中观应成派立场不同。"五蕴"指色、受、想、行、识，是佛教对一切身心现象的基本分类；"诸界"指十八界（六根、六境、六识），也是对一切法的分类方式，这里泛指世俗谛所摄的一切现象。"圣者的根本定"指圣者安住于胜义空性中的等持（禅定）状态，"损减边"是指把本来在世俗上存在、起作用的东西，错误地说成完全不存在——这是一种极端的错误见解，中观要避免的正是这种"把缘起也否定掉"的断灭见。

总而言之，从胜义分析的角度，任何法都无法被观察为真实存在；从观察世俗的理论角度，诸法是可以显现的。这两点相互一致、融为一体的实相——这就是离边中观的主张。

然而，实有论者并不同意这一点。他们认为空性与缘起显现是相互对立的。他们以为：凡被胜义分析所遮遣的，在世俗上也必定完全不存在，就像兔角一样。或者反过来，凡在世俗上存在的（如柱子、瓶子），就永远不可能被胜义正理所遮遣。他们设想出某种独立于作为遮遣基础的世俗法之外的所遮（即"谛实有"），并把空性——在他们看来不过是遮遣一个叫做"谛实"的独立事物——和作为遮遣基础的显现视为正相违，就像兔角之全然不存在与牛角之实有那样截然对立。然后，他们把这二者"绑定"在某个实体（如瓶子）上，宣称这就是"双运"——这实质上等于主张空性是一种"非遮"（肯定性否定），最终并未超越实有论者的见解。这一点，前辈大德们早已精辟地指出过。

**【译注】** 这一段是在辨别中观应成派与其他宗派对"空性"理解的根本差异。"所遮"指被否定、被遮破的对象；"谛实（有）"指真实、独立、不待他缘而有的自性。有些宗派把"空性"理解成：瓶子本身照样真实存在，只是在它上面"另外"否定掉一个叫"谛实"的东西——这样一来，空性和显现就变成了绑在一起的两块拼图（"非遮"式的空性），而不是"显现本身当下即是空性"。这不是应成中观的见地。应成派认为，空性不是在显现之外另立一个被否定的对象，而是就"显现"本身而言，找不到它有任何独立自性可得——显即是空，并非"显"之外还有个"空"需要外加。"非遮"和"遮"是因明学中对否定命题的两种分类：单纯否定而不暗示任何肯定内容的叫"无遮"，否定的同时又暗示某种肯定内容的叫"非遮"。这里批评的对象，是把空性理解成了一种"非遮"式的、暗中肯定了某种独立自性空的东西，这仍然没有跳出对"实有"的执著模式。

#### 3. 破自他共生

主张原质（自性）和大自在天的数论派同时承认自生和他生（即从自他二者共同而生），但这种主张兼具前述两种立场的过失。如《入中论》所说：

```
俱生亦非正理性，已说过故。
```

因此，从世俗、胜义任何一个层面来看，这种主张都不成立。

**【译注】** "大自在天"是印度教中被视为创造万物的神祇，某些外道认为世间万法由大自在天和原质共同作用而生，这属于"共生"的主张——本质上就是把前面自生、他生各自的过失加在一起，并没有解决任何问题。

#### 4. 破无因生

至于那种认为既不从自生、也不从他生、也不从二者共生，而主张无因而生的观点——《入中论》说：

```
若世无因则应知，如空莲华色与香，
然世品类繁多有，如自心然从因知。
```

（大意：如果世间万物没有任何因，那它们就应该像虚空中不存在的莲花的香气和颜色一样不可得。但世间万物以丰富多样的面貌呈现，所以应当知道——正如自己的心一样——它们都是从因而生的。）

这一点在前文讨论各宗派见解时已作了详细破斥，说明了无因生如何导致"常有"或"断无"的过失。

如此，以破四边生的正理如法审察时，任何法在最初都不可得见其"生起"，因此也不可能有中间的"安住"和最终的"消灭"。于是，在这些不断显现的世俗相对现象上，"胜义生"等八边（生、灭、常、断、来、去、一、异）的戏论悉皆寂灭。这应当被理解为显空双运。这在《入中论》中有更为详尽的阐述。

**【译注】** "八边戏论"出自龙树菩萨《中论》开篇著名的"八不"：不生不灭、不常不断、不一不异、不来不去。"戏论"指概念思维、语言分别所生起的种种虚妄执著。这里说：既然连最初的"生"都找不到真实自性，那么以"生"为前提而安立的"住""灭"等其余七边自然也都无从谈起，一切概念分别在胜义理智前统统寂灭，这就是"八不中道"的意思。

### （二）破四句生

以正理观察时，"生"不可能以下述四种方式中的任何一种而成立：

- 多因生一果
- 多因生多果
- 一因生多果
- 一因生一果

**【译注】** 上面"破四边生"是从因和果各自的角度分别破斥（自生、他生……），这一节"破四句生"则是把"因"和"果"两边的"一"与"多"排列组合起来考察，一共四种可能，逐一破除。这一条推理稍微复杂，读者可以只抓住核心思路：无论怎样组合"一"与"多"，都预设了先要有一个真实成立的"一"（单一体）作为基础，而下文"离一多因"会证明"真实的一"根本找不到，所以这四句排列组合，从根子上就立不住。

你或许认为：只有多种不同的因——如所缘色法、无损的根、紧接其前的意识、无障碍的显现以及容受的空间——才能产生单一的眼识这一结果。

**【译注】** 这里以"眼识"的生起为例来展开讨论。按照佛教因明的说法，眼识的生起需要多种条件共同具足：所缘的境（色法）、健全的眼根、前一刹那的意识（等无间缘）、光线通畅无障碍、以及一定的空间距离，这些合称"生眼识的多种因缘"。下面就以此为例，逐一检验"多因生一果"等四种可能是否合理。

如果是这样——多种不同的因只产生一个结果——那么所缘、根等虽然产生了眼识，但该眼识之所以为"一"，却找不到任何因。同理，只要单一的因不能产生单一的果，则无论是"一"还是"多"，都找不到其成因。既然所有可知的事物不外乎"一"或"多"，那么凡是一或多的事物要么永恒如此、要么永远不会在任何时处出现——因为一和多都没有成因。

你或许认为：多因产生多果。比如：想看的即时动机产生心识性质的眼识；眼根的支持产生对境的了别；显现的对境（如瓶子）产生自身特有的心相。如果是这样，既然眼识由这些不同的因所产生而具有上述种种特征（心识性、了别境相等），那么那个眼识就会变成多个——与上述特征数目相等。如果你接受这一点，那么作为结果的眼识其实并非由这些因（如动机等）所产生；那些特征如心识性、具境相等各自单独产生，而这些特征的拥有者——眼识本身——就没有任何因，因而也不是由任何东西产生的。

你或许会回应说：了别境相等方面并非各自独立，它们不外乎就是识。但那样的话，说"多因生多果"就毫无意义了——它变成了"多因生一果"，而这种主张（因为一和多都无因，故事物要么永存要么永不存在）的问题前面已经解释过了。

你或许认为这样没有过失，因为这些方面与方面的拥有者（识）本质上同一，只是在概念区分上被安立为别别不同。如果是这样，那么如动机等因就只对概念区分——即心识性等假立法——起作用，而实质存在的识本身就不是由任何因产生的，识就变成无因了。

如果你主张果的本体为一而方面为多，那就会导致"能依"（属性）与"所依"（属性之拥有者）相分离的过失。

**【译注】** "能依"与"所依"，"能依"指依附于某个基础之上的属性、特征，"所依"指承载这些属性的基础本身（比如识本身是所依，心识性、了别境相是能依的属性）。这里的过失是说：如果承认识本身是一个整体（一），而它的种种属性、特征是多个（多），那么这个"多"就必须依附在那个"一"上才能安立，可是上面已经说明因缘只能产生"多"这些属性，却无法解释那个作为承载者的"一"（识本身）是怎么产生的，于是能依和所依就脱节了，无法圆融安立。

你或许认为：蓝花这一个因产生多个果——比如该花自身后续的"同类"以及众生的眼识。那么请问：该因（蓝花）是完全独立地、不依赖其他助缘而产生这些果的呢，还是与根等其他助缘共同作用的？

第一种情况，如果完全独立产生，由于它不可能产生多个果，那就意味着无因生。同理，一个因也无法独立完成产生一个果的功能，于是一和多都缺乏成因，又回到了前面所说的无因生的过失。

第二种情况，如果蓝花等所缘依赖显现、根、意等其他因来产生眼识，你说还有其他因参与，那么结果就不再是"一"了——因为它由所缘、根、意等多种因各自赋予了不同的特征。

那么，如果说一因只产生自己的一个果呢？这样的话，眼根这一因只能产生自己后续的"同类"，永远无法执行产生其他东西（比如直接了别对境的眼识）的功能，那么有情的眼识、耳识等就没有任何因，这些果就不可能存在——荒谬的结论是所有人都会又聋又瞎。

如《中观二谛论》（智藏菩萨著）所说：

```
多法不生一，多法不生多，
一法不生多，一法不生一。
```

以上正是依据这些道理而说的。

此外，对于主张多因（如显现、根、意等）生一果（如眼识）的人，还可以进一步论证：即便承认眼识作为结果没有多方面而是单一的，但任何可知的事物都不可能是真正单一的——比如，离开了遍行心所等伴随心所的眼识是不可能存在的。

**【译注】** "遍行心所"是唯识学中的术语，指作意、触、受、想、思五种心所，据说与一切心识活动都相应、普遍存在，因此叫"遍行"。这里举遍行心所为例，说明即便是看似单一的"眼识"，其实也总是伴随着其他心理活动一起生起，找不到一个真正孤立、不可再分的"单一"眼识。

你或许认为多因生多果，但既然多因不可能只产生一个果，说"多个果的聚合"也就毫无意义。单一的法不成立时，由单一所组成的"多"也不会成立，也不会存在。

主张一因生多果同样站不住脚，因为它预设了一个不可分割的单一之因，而这是不可能的。可以看到，一粒种子如果不依赖土壤、水分、温暖、时间等其他条件，就不可能单独产生其果——芽。

一因生一果也不成立，因为这与直接经验相矛盾——我们亲眼看到，从种子、水、肥料、热、湿等多种因缘中，依次产生芽、花、果等多样结果。

因此，彻底审察之下，无论作为因还是果的事物，一个真正缺乏多方面特征的"一"根本无法成立。而如果"一"不成立，那必然由"一"所组成的"多"也同样不成立。

尽管如此，就像"芽"这样的事物，虽然由颜色、形状等多个部分构成，基于类别相同等因素仍被安立为"一个芽"。同样，一个如微尘那样的"单一"法，当依其物质、方位等特征来分析时又被安立为"多"。这些仅仅是凭借缘起力或"观待假立"而在世俗中安立为因和果的。以胜义理论来观察，无论一、多等四句中的哪一种都不可成立。因此，这些经不起审察的世俗法应当被理解为恰如梦中的显现。

**【译注】** "观待假立"是中观应成派解释一切世俗安立最核心的原理之一：万法并非各自独立、自体成立，而是相互"观待"（依赖、比对）才被概念安立出来的——比如"长"是观待"短"才安立的，"一个芽"是观待其各个部分的组合、观待与其他芽的类别相同才被称为"一"。世俗中因果、一多等安立，都是这种"观待假立"的产物，一经胜义理智审察，就找不到独立自性。

虽然有时此正理被称为"观察因果二者：破四句生"，从而算作五大正因——这样解释最终也无大矛盾——但将它归入"观察因"的类别从而保持四大正因的框架，似乎更为合理。

另外还有一些观察因、果和体性的其他论证，比如过去、现在、未来三时的分析：过去已生之果早已生起并已灭尽，所以不是"正在生"；未来之果尚未在当下生起，所以不是"正在生"；现在之果已经成立为自身的体性，再度产生就毫无意义。

## 二、观察果：破有无生

**【译注】** 前面"金刚屑因"是从"因"这一头去审察生起是否合理，这一节"破有无生"则换个角度，从"果"这一头去审察：所生的那个结果，到底是本来就有、还是本来完全没有？

### （一）正说

关于所生之果，如果考察它是已存在的果在生起，还是不存在的果在生起，或者二者兼具，或者二者皆非——《入中论》说：

```
有生岂须生？无亦何所生？
有无亦何为？非二亦何为？
```

如果你认为所生之果是一个"已有之物"在发展，这不合理。为什么呢？如果它已经存在，就意味着它已经确立了自身作为芽等的体性，既已存在，就不需要再被重新产生。好比青稞成熟一次后，不需要再成熟一遍。如果已存在之物仍须被产生，就会导致无穷生起的过失。

"那么，是不存在之物被产生。"你或许这样认为。但那样的话，就不可能被产生。比如，即使有人竭尽全力汇集百千因缘，也永远无法在兔子头上生出角来。

你或许认为：像芽这样的果，以前是不存在的，但被种子等因重新造作为存在之物。并非如此。"存在"和"不存在"是互相矛盾的，它们永远不可能在同一个实体上同时成立。就真实的事物而言，没有任何法是先前不存在、后来变成存在的。因缘不可能把无为虚空变成有为实有之法的体性。

**【译注】** "无为"指不依因缘造作、本自如此的法（如虚空、涅槃），"有为"指由因缘和合而生、会生灭变化的法（如瓶子、芽）。这里说：如果果原本彻底是"无"（像虚空一样什么都没有），那因缘再怎么努力也不可能把这种"绝对的无"变造成"有"，因为"有""无"两个属性是互不相容、非此即彼的，不可能有一个中间的过渡状态让它们对调。

因此，仅仅在世俗名言上，果基于因而显现。在因缘尚未聚合之前，它没有显现；当因缘聚合时，它显现了。心将这前后两个阶段联系起来，于是才有了"这以前不存在，现在正在生起"这样纯粹概念性的表述。

同样，心将先后不同的时刻联系起来，针对某个现象而想："这以前存在，后来不存在了。"

这样，作为世俗实体的诸法，纯粹凭缘起之力而显现。实际上，根本没有任何存在的法转变为不存在，也没有任何不存在的法转变为存在。

有为法的新生与最终坏灭、"同类"相续的延续与中断、对人我和法我的执取与无我的证悟——情况都与上述"有"与"无"的分析相类似。它们全都只是世俗相对层面的显现，在胜义上，它们空无自身的本质。在万法的真实本性中，没有所谓"有变为无"或"无变为有"的转换，没有来去，没有生灭，没有增减可言。

**【译注】** "人我"指众生对"有一个真实独立的自我"的执著（我执），"法我"指对一切现象背后有真实自性的执著（法执）。这里说：不但"果的生起"经不起有无二边的推敲，就连众生"执我"和圣者"证无我"这样的凡圣转变，究其胜义实相，也同样找不到一个真实的"有变无"或"无变有"的转换过程可得——一切都只是世俗层面的缘起显现。

### （二）断疑

你或许会想：既然已有之果不生、不存在之果也不生，而除此二者之外不可能有第三种生的方式，那么究竟应该怎样安立果的产生呢？应当这样安立：果的产生不外乎是缘起的无欺显现。以"有"或"无"来分析时，它以任何方式都不可成立，恰如幻化等比喻所示。

"既有又无"不可能是可知法的状态，因为有和无正相违。"非有非无"也不可能，因为在这两个正相违的选项之间不可能存在第三种可能。

"那么，"你或许会想，"正如在这里'非有非无'的选项不可能成立一样，在远离'有、无'等四边戏论的语境中，也不可能有'非有非无'的选项。"你还可能认为："正如在不加限定地说'非有非无'时，在正相违的二者之间不可能有第三种选择，那么法性也可以通过这两重否定来了解，而'一切皆非'的实际内容到底是什么并无实质意义。因此，除了'什么都不承认'这种近乎诡辩的立场之外，我们自宗对万法实际的样貌并不做任何确定性的表述。"这或许是初学者的想法，但事实完全不是这样。

**【译注】** 这一段是在破斥一种对中观空性的常见误解——以为中观最后就是"什么都不承认""什么都说不清楚"的诡辩、虚无主义。作者接下来解释：真正远离四边戏论的空性境界，不是概念游戏，而是一种可以亲证的、明明白白的智慧境界。

只要还维持着概念所缘的基础，就不可能有一种认知能够彻底遣除四边。因此，凡是通过特定的区分而作出的主张——比如"这间屋子里没有蛇，但有瓶子"——都涉及特定的概念所缘，因而并未超越常规的概念思维范畴。在一切概念攀缘都已息灭的真实"离戏"境界中，对四边没有任何主张或概念所缘。尽管如此，这完全不同于尚未证悟胜义实相的蒙昧无明状态，也不同于无意识的昏迷。这是一种难以言说、难以比喻的境界——如罗睺罗在《赞般若波罗蜜多偈》中所说——超越言说、超越思量、超越描述。它是各别自证智所觉知的"离戏"境界，一切疑惑在其中彻底斩断。这是远离二取（能取、所取）、但自然光明如朗朗晴空的无分别智。

**【译注】** "四边"即有、无、亦有亦无、非有非无这四种概念上的极端；"离戏"指远离一切概念戏论、语言分别的境界；"各别自证智"指圣者亲证的、无法用语言概念完全传达、只能各自内证的智慧；"二取"指能取（认知的主体）与所取（被认知的对象）的分别对立，这是凡夫心识运作的基本模式，而圣者的根本智则超越了这种能所对立，是"无分别智"。这一段的重点是：中观所说的"空性"不是逻辑上的一个死角，也不是什么都不知道的糊涂状态，而是一种超越概念、需要亲自禅修体证的智慧境界，只能自己证悟，无法单靠语言文字完全传达，但这与愚昧无知、昏迷失念截然不同，是清明、朗然的觉智。

## 三、观察体性：离一多因

**【译注】** 前两大因都是围绕"因果生起"来破的，这一大因不谈因果，直接对准每一个具体事物本身，问一个最根本的问题：这个东西，到底是不是一个真正独立、不可再分的"一"？这条理路的推理相对简单直白，是最常被单独拿来教学的一支。

首先，对一切有为法和无为法的体性加以审察，看是否存在真正的"一"。

就五蕴中具有色相的有为法而言，可以分为上、下、四方、四隅和中央。由此可知，对于瓶子这样的事物，所谓"一"不过是对作为安立基础的各种特征施加的概念假名。真正的"一"不成立，其组成部分也同样如此。身体和四肢也以同样的方式被分为部分。

**【译注】** "色相"指有形状、占空间、可以被眼睛看见（或触觉感知）的物质现象；"上下四方四隅"泛指空间方位，说明任何一个有形体的东西，只要占据空间，就必定可以按方位切分出部分——瓶子有瓶口、瓶身、瓶底，身体有头、躯干、四肢，都不是真正不可分割的"一"。

总之，一切具有色相、由物质微尘组成的法，分解到其基础——即极微尘。按照前面解释的逻辑，对于那最微小的极微尘来说，要被各方向的微尘所围绕就必须有面向（有方分），有方分就有部分，如此无穷推下去。如果极微尘没有方分，那么无论聚集多少极微尘，也永远不会变大。因此，一切色法都不具备真正的"一"。

**【译注】** "极微尘"是古代印度哲学（包括某些佛教宗派）设想的物质最小单位，理论上不可再分。"方分"指方向性的部分，即东西南北、上下等空间朝向的差别。这里的推理是：如果一个极微尘要被周围的其他微尘所环绕接触，那么它就必须有"朝向东边的那一面"和"朝向西边的那一面"之分，这就已经有了方分、有了部分，就不是真正不可分割的"一"了；反过来，如果极微尘完全没有方分（不能被分出任何朝向），那么无数个这样的"无方分极微尘"叠加在一起，也永远不可能拼出一个有体积、占空间的粗大物体（因为它们没有"面"可以彼此靠拢延展）。所以，无论承不承认极微尘有方分，"真实不可分的最小物质单位"这个假设都站不住脚——这是佛教中观（以及唯识学在极成方面也常用）破斥"实有极微尘"最经典的推理。

此外，八识或六识聚也不可能被确立为真正的"一"，因为它们包含种种不同的认知活动和心所，取不同的相分为所缘，从四缘的聚合中以不同的形态生起，然后灭去。

**【译注】** "八识"是唯识学的分类：眼、耳、鼻、舌、身、意六识，加上末那识（第七识，恒执自我）、阿赖耶识（第八识，藏识），合称八识；不承许后二识的宗派则只讲"六识"。"相分"是唯识学术语，指心识所显现、所缘取的境相（区别于能缘的"见分"）。"四缘"指佛教因明中说明一切法生起所需的四种条件：因缘、等无间缘、所缘缘、增上缘。这一段是把"破一多"的分析，从物质领域（色法）延伸到心识领域：无论哪种识，都伴随着各种不同的心理活动（心所）、缘取不同的境相、依靠多种条件的聚合才能生起，找不到一个真正单一、不可再分的"识"存在。

通过分析一切由自因生灭的事物，即使最微细的不可分割的刹那也无法成立。因此，心和色所摄的一切法都不具备任何真正的"一"。至于不相应行法，它们不过是在心色"场合"上的假名施设，缺乏任何本质。无为法是对所遣品（所否定对象）被遣除之面相的假名施设，同样缺乏任何本质。

**【译注】** 这里进一步把分析推向时间维度：即便是最短的一"刹那"，理论上也可以再分出前段、后段，找不到一个绝对不可再分的最小时间单位。"不相应行法"是唯识学百法体系中的一类特殊法，既不属于纯粹的物质（色法），也不属于纯粹的心理活动（心所法），而是依托心、色等法上，为了描述某些抽象关系或状态而假立的概念，比如"得"（获得）、"相续"、"时间""数目"等，这些本身没有独立实体，只是概念上的假立。"无为法"（如虚空、择灭无为）则是通过"遮遣"某个所否定的对象（比如遮遣"有为造作"）之后所安立的一种状态描述，同样没有独立自体可得——这一段的意思是：不仅色法、心法找不到真正的"一"，连不相应行法、无为法这些更抽象的范畴，细究之下也都只是概念假立，没有实在本质。

总之，一切有为法和无为法都无法呈现出任何真正的"一"。"一"既不成立，由"一"所组成的"多"也必然不成立。除了真正的"一"或"多"之外，没有其他真实存在的方式。因此，必然证明人和法都没有自性——如《中观庄严论》中更详尽的阐述。

**【译注】** 这一大因的结论直接指向"人无我、法无我"——不但外在的物质现象（法）没有真实的"一"，我们执著为"我"的这个身心组合，细究起来同样找不到一个独立、单一、不可分割的"我"存在，这正是佛教"无我"见地在中观因明上的推理依据。静命论师（寂护）所著的《中观庄严论》，就是以"离一多因"作为核心推理，系统抉择万法无自性的重要论典。

## 四、观察一切：大缘起因

**【译注】** 前三大因（金刚屑因、破有无生因、离一多因）侧重点各不相同，但共同的作用是"破"——层层剥除我们对"因""果""体性"各方面真实存在的执著。这第四大因换了一个角度，正面说明：一切法之所以没有自性，根本原因就在于它们是"缘起"的——因为依赖因缘条件才能显现，所以从一开始就没有独立不变的本质。这一因因此被称为"因中之王"，因为前面所有的破法，归根结底都是在说明"缘起"这个道理。

一切法并非以自身固有的体性而产生，而是由因缘和合而现前的；缺乏因缘时就不会生起。即使在它们显现的时候，也是在缺乏自性的状态下显现的，因为它们犹如影像一般，是由因缘所造作的。远离"常""断""来""去""生""灭""一""异"等一切戏论，它们在缺乏真实性的状态下显现。

如此，运用随顺万法实际本性的胜义理论来抉择时，发现它们不过是无欺的缘起。否则，如果它们以任何方式被真实成立——比如依四边而生、依四句而生、是有是无、是常是无常等——那就不适合作为世俗的解释方式，反而会损减一切世俗安立。

对于中观宗而言，不实的缘起幻化显现与空性在同一实相中呈现，因此一切"唯现"的世俗安立都极为合理。正因如此，世间的一切世俗安立，以及出世间的四谛、三宝等世俗安立，都完美地得以确立。

**【译注】** "唯现"指诸法仅仅是显现而已，没有背后独立存在的实体作支撑；"四谛"指苦、集、灭、道，是佛陀初转法轮宣说的根本教法；"三宝"指佛、法、僧。这一段是在澄清一个常见的疑虑：如果说一切法都无自性、都是空性，那佛教自身讲的因果业报、四谛三宝这些道理，岂不是也都成了空谈？作者的回答是：恰恰相反——正因为诸法是缘起假立而非真实自性成立，所以世俗因果、四谛三宝等安立才不会与胜义空性相冲突，才能够"如幻"般真实起作用。如果诸法真有自性，因果反而无法安立（因为自性是独立不变的，不需要也无法依因缘变化）。

这一正理之王——大缘起因——涵摄了所有其他胜义正理，如金刚屑因等，因为它们全都关涉缘起在未经审察时似乎真实的显现。一经分析，任何因、果或体性都不可成立。广泛展开此缘起义理论的论述，见于《中观根本慧论》（《中论》）等论典。

## 结语

因此，在世俗层面，因、果和体性以那样的方式显现，并被安立相应的名言。在胜义层面，因、果和体性没有任何真实自性，即是以三解脱门（空、无相、无愿）为体性的空性。二谛如此不可分离的空性，就是法界——中观道所应证悟的对象。它是一切所证中的至尊，是诸佛及佛子的"母亲"。

**【译注】** "三解脱门"指空、无相、无愿（无作）三种趣入解脱的禅观法门：观诸法自性空为"空解脱门"，观诸法离一切相为"无相解脱门"，观诸法无可希求造作为"无愿解脱门"，三者本质上是从不同侧面表达同一空性。"法界"指诸法的真实本性、终极实相，是大乘佛教修道所要证悟的核心对象。"诸佛及佛子的母亲"是大乘经典中常见的比喻，指般若空性智慧能出生一切诸佛与菩萨的功德，如同母亲孕育儿女一般，因此《般若经》系统常被尊称为"佛母"。

显空二谛无二平等的这一要义，犹如虚空，超越概念思维的范畴，不可思议、不可言说；然而，以无分别智慧，能够以清净的自知自证方式而修持。在后得位，对"一切法虽然显现但缺乏真实性"怀有确定的信解——正如幻化、梦境、影像、化现等比喻所示。以善加辨别二谛的智慧，对基、道、果的一切类别获得无颠倒的证悟。

**【译注】** "后得位"是与"根本定"相对的修道阶段术语：圣者安住于空性禅定中不起任何分别念，称为"根本定"（或"入定"）；从定中出来、恢复日常概念性认知活动的阶段，称为"后得位"（或"出定"）。在根本定中亲证离戏空性，在后得位中则以"如幻"的智慧看待一切显现——虽然照常起种种分别、照常面对生活中的种种境界，但内心对"这一切都没有真实自性、如梦如幻"保持清晰的定解，不再被表相迷惑。"基、道、果"是藏传佛教教理体系常用的框架："基"指诸法的本来实相（见地所依），"道"指依此见地而修的种种法门次第，"果"指修行圆满所证得的果位（如佛果）——以二谛智慧贯通基道果的一切内容，即是对佛法完整体系的无颠倒证悟。

如此通达空性之义，大乘道果的一切功德将由此而生。
