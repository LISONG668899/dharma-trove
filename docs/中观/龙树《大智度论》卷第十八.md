# 龙树《大智度论》卷第十八

龙树菩萨造　后秦龟兹国三藏鸠摩罗什奉诏译

## 释初品中般若波罗蜜第二十九

【经】“因为对一切法都不执着，所以应当具足般若波罗蜜。”

【论】

### 一、何名般若波罗蜜

问：什么名为般若波罗蜜？

答：诸菩萨从初发心求一切种智，在这其间，了知诸法实相的智慧，就是般若波罗蜜。

问：如果是这样，就不应当名为波罗蜜。为什么？因为还没有到达智慧的边际。

答：佛所得的智慧是真实的波罗蜜；因为这波罗蜜的缘故，菩萨所行的也名为波罗蜜，这是在因上说果。这般若波罗蜜，在佛心中改名为一切种智。菩萨修行智慧，求度到彼岸，所以名为波罗蜜；佛已经度到彼岸，所以名为一切种智。

#### （一）前灯后灯之喻

问：佛已断尽一切烦恼以及习气，智慧之眼清净，应当如实得到诸法实相；诸法实相就是般若波罗蜜。菩萨还没有断尽诸漏，慧眼还不清净，怎么能得到诸法实相？

答：这意义在后面的品中会详细说，现在只略说。如人入海，有刚刚进入的，有穷尽其底的，深浅虽然不同，都名为入。佛与菩萨也是这样，佛则穷尽其底；菩萨还没有断尽诸烦恼与习气，势力小，所以不能深入。如后面的品中所说的譬喻：如人在暗室中点灯，照见诸器物，都分明了然；再有一盏大灯，就更加明亮清楚。由此可知，后一盏灯所破除的黑暗，原本与前一盏灯同时存在；前一盏灯虽然与黑暗共存，却也能照物。如果前一盏灯没有黑暗，后一盏灯就无所增益。诸佛与菩萨的智慧也是这样：菩萨的智慧虽然与烦恼、习气同在，却能得到诸法实相，如前一盏灯也能照物；佛的智慧断尽诸烦恼与习气，也得到诸法实相，如后一盏灯更加明了。

【译注】前灯后灯之喻回答的是一个关键难题：菩萨未尽诸漏，何以能得诸法实相？论主不说菩萨所得是另一种较低的实相，而说同一实相，前灯与暗共住而照物，后灯尽暗而倍明。所以菩萨的般若与佛的一切种智，所照是一，深浅有别，这正是前文“因中说果”得以成立的根据。

#### （二）何谓诸法实相：赞般若波罗蜜偈

问：什么是诸法实相？

答：众人各自说诸法实相，都自以为真实。这里所说的实相，是不可破坏，常住不变，没有能造作它的。如后面的品中，佛对须菩提说：“如果菩萨观察一切法，非常非无常，非苦非乐，非我非无我，非有非无等，也不作这样的观察，这名为菩萨修行般若波罗蜜。”这意思是：舍弃一切观察，灭除一切言语，离开种种心行，从本以来，不生不灭，如涅槃之相；一切诸法之相也是这样，这名为诸法实相。如〈赞般若波罗蜜偈〉中说：

```
般若波罗蜜，　　实法不颠倒，
念想观已除，　　言语法亦灭。
无量众罪除，　　清净心常一，
如是尊妙人，　　则能见般若。
如虚空无染，　　无戏无文字，
若能如是观，　　是即为见佛。
若如法观佛，　　般若及涅槃，
是三则一相，　　其实无有异。
诸佛及菩萨，　　能利益一切，
般若为之母，　　能出生养育。
佛为众生父，　　般若能生佛，
是则为一切，　　众生之祖母。
般若是一法，　　佛说种种名，
随诸众生力，　　为之立异字。
若人得般若，　　议论心皆灭；
譬如日出时，　　朝露一时失。
般若之威德，　　能动二种人：
无智者恐怖，　　有智者欢喜。
若人得般若，　　则为般若主，
般若中不著，　　何况于余法！
般若无所来，　　亦复无所去，
智者一切处，　　求之不能得。
若不见般若，　　是则为被缚；
若人见般若，　　是亦名被缚。
若人见般若，　　是则得解脱；
若不见般若，　　是亦得解脱。
是事为希有，　　甚深有大名，
譬如幻化物，　　见而不可见。
诸佛及菩萨，　　声闻辟支佛，
解脱涅槃道，　　皆从般若得。
言说为世俗，　　怜愍一切故，
假名说诸法，　　虽说而不说。
般若波罗蜜，　　譬如大火焰，
四边不可取，　　无取亦不取，
一切取已舍，　　是名不可取，
不可取而取，　　是即名为取。
般若无坏相，　　过一切言语，
适无所依止，　　谁能赞其德？
般若虽叵赞，　　我今能得赞，
虽未脱死地，　　则为已得出。
```

大意：般若波罗蜜是真实之法，不颠倒；念、想、观都已除去，言语之法也已灭尽。无量众罪除去，清净之心常一，这样尊贵美妙的人，才能见到般若。如虚空一样无染，无戏论、无文字，如果能这样观察，这就是见佛。如果如法地观察佛、般若与涅槃，这三者就是一相，实际上没有差别。诸佛与菩萨能利益一切众生，般若是他们的母亲，能出生、养育他们；佛是众生之父，般若能生出佛，所以般若是一切众生的祖母。般若是一法，佛说了种种名称，随着众生的能力，为他们立了不同的名字。如果人得到般若，议论之心都会灭尽，譬如太阳出来时，朝露同时消失。般若的威德能震动两种人：无智者恐怖，有智者欢喜。如果人得到般若，就成为般若之主；对般若尚且不执着，何况其余的法！般若无所从来，也无所去，智者在一切处求它都不能得到。如果不见般若，就是被缚；如果见般若，也名为被缚。如果见般若，就得解脱；如果不见般若，也得解脱。这件事最为稀有，甚深而有大名，譬如幻化之物，见到却又不可见。诸佛、菩萨、声闻、辟支佛的解脱涅槃之道，都从般若而得。言说是世俗，为了怜悯一切众生，以假名说诸法，虽然说了却等于没说。般若波罗蜜譬如大火焰，四边都不可取；无所取，也不是不取；一切取都已舍弃，这名为不可取；不可取而取，这就名为取。般若没有可坏之相，超过一切言语；本来无所依止，谁能赞叹它的功德？般若虽然不可赞叹，我现在却能够赞叹，虽然还没有脱离死地，却已经算是得出了。（偈中“见般若”与“不见般若”缚、脱四句互反，是以取相与不取相分说：取相而见、执无而不见皆缚，不取相而见、不着而不见皆脱；“不可取而取”二句同此。此为依上下文的理解，原偈不自释。）

## 释般若相义第三十

### 一、何以独称般若为“摩诃”

问：为什么唯独称般若波罗蜜为“摩诃”，而不称其余五波罗蜜？

答：“摩诃”，汉语意为大；“般若”意为慧；“波罗蜜”意为到彼岸；因为它能到达智慧大海的彼岸，到达一切智慧的边际，穷尽其极，所以名为到彼岸。

一切世间之中，十方、三世，诸佛第一大，其次有菩萨、辟支佛、声闻；这四种大人都从般若波罗蜜中生，所以名为大。

再者，它能给众生大果报，无量无尽，常不变异，就是涅槃；其余五波罗蜜不能这样。布施等离开般若波罗蜜，只能给予世间的果报，所以不得名为大。

### 二、三乘智慧

问：什么是智慧？

答：般若波罗蜜摄一切智慧。为什么？菩萨求佛道，应当学一切法，得一切智慧，就是声闻、辟支佛、佛的智慧。

这智慧有三种：学、无学、非学非无学。

非学非无学的智慧，如干慧地、不净观、安那般那、欲界所系的四念处，暖法、顶法、忍法、世间第一法等。

学的智慧，是苦法智忍的智慧，乃至向阿罗汉的第九无碍道中的金刚三昧智慧。

无学的智慧，是阿罗汉第九解脱道的智慧；从此以后，一切无学的智慧，如尽智、无生智等，这是无学智慧。

求辟支佛道的智慧也是这样。

#### （一）辟支佛：因缘觉与独觉

问：如果辟支佛道也是这样，怎样分别声闻与辟支佛？

答：道虽然是一种，而运用智慧有所不同。如果诸佛不出世、佛法已灭，这人因为前世的因缘，独自生出智慧，不从他人听闻，自己以智慧得道。

如一位国王，出到园中游戏。清晨看见林树花果茂盛，非常可爱。国王吃完饭睡下，国王的诸夫人、宫女都一起采花，毁折了林树。国王醒来，看见林子毁坏，自己觉悟：一切世间无常变坏，都是这样。这样思惟之后，无漏道心生起，断除诸结使，得辟支佛道，具足六神通，当即飞到闲静的林间。像这样等等因缘，由前世的福德、愿行、果报，今世见到少许因缘，就成就辟支佛道，这就是不同之处。

再者，辟支佛有两种：一名独觉，二名因缘觉。

因缘觉如上面所说。

独觉，是这人今世成道，自己觉悟而不从他人听闻，这名为独觉辟支迦佛。

独觉辟支迦佛有两种：一种本来是有学之人，生在人中；这时无佛，佛法已灭。这位须陀洹已经满了七生，不应当有第八生，自己得以成道。这人不名为佛，不名为阿罗汉，名为小辟支迦佛，与阿罗汉没有差别；或者有不如舍利弗等大阿罗汉的。

大辟支佛，也在一百劫中作功德，增长智慧，得到三十二相的一部分：或者有三十一相，或者三十、二十九相，乃至一相。在九种阿罗汉中，智慧锐利殊胜，对诸深法的总相、别相都能契入；久修禅定，常乐独处。这样的相，名为大辟支迦佛，这就是不同之处。

#### （二）佛道智慧

求佛道的人，从初发心时发愿：“愿我作佛，度脱众生，得一切佛法，行六波罗蜜，破魔军众以及诸烦恼，得一切智，成就佛道，乃至入无余涅槃。”随本愿而行，从这其间所有的智慧，总相、别相一切都了知，这名为佛道的智慧。

这三种智慧都能了知，都到达其边际，所以说“到智慧边”。

### 三、外道智慧非实

问：如你所说，一切智慧都应当包括在内，无论世间还是出世间，为什么只说“三乘智慧都到达其边际”，不说其余的智慧？

答：三乘是真实的智慧，其余的都是虚妄的，菩萨虽然了知，却不专门修行。

如除了摩梨山，一切地方都不出栴檀木；如果其余地方有好的言论，都是从佛法中得来的。如果不是佛法，起初听起来好像不错，久了就不妙了。譬如牛乳、驴乳，颜色虽然相同；牛乳搅拌就成酥，驴乳搅拌就成尿。

佛法之语与外道之语，在不杀、不盗、慈悯众生、摄心、离欲、观空上虽然相同；然而外道之语起初虽然好像美妙，穷究其最终归宿，就是虚诳。

#### （一）外道着我，戒福无据

一切外道都执着我见；如果真的有我，应当落入两种情况之一：或者是可坏之相，或者是不可坏之相。

如果是可坏之相，应当如牛皮；如果是不可坏之相，应当如虚空。这两种情况下都没有杀生之罪，也没有不杀之福。

如果如虚空，雨露不能滋润，风热不能吹干，这就落入常相。

如果是常，苦不能使之恼，乐不能使之悦；如果不受苦乐，就不应当避祸就福。

如果如牛皮，就会被风雨所坏；如果会坏，就落入无常；如果是无常，就没有罪与福。

外道之语如果真是这样，哪里会有不杀为福、杀生为罪？

#### （二）外道禅定智慧之失

问：外道的戒与福，所失如此，他们的禅定、智慧又怎样？

答：外道以我心追逐禅定，因为多有爱、见、慢，因为不舍一切法，所以没有真实的智慧。

问：你说“外道观空”，观空就是舍弃一切法，为什么说“因为不舍一切法，所以没有真实的智慧”？

答：外道虽然观空，却取空相；虽然知道诸法空，却不自知我空，因为爱着观空的智慧。

问：外道有无想定，心与心所法都灭了；都灭了，就没有取相、爱着智慧的过失！

答：无想定的力量，是强行使心灭，不是真实智慧的力量。

又在这其中生起涅槃之想，不知道它是和合造作之法，所以落入颠倒之中！这其中心虽然暂时灭了，得到因缘又会生起。譬如人在无梦的睡眠中，心想不起作用，醒来又有了。

问：无想定的过失如此，还有非有想非无想定，这其中没有一切妄想，也不像勉强作无想定那样灭想，这其中是以智慧之力而无想！

答：这其中有想，只是细微所以不觉察。如果无想，佛弟子又何必再求真实智慧？在佛法中，这非有想非无想中的识，依于四众而住；这四众隶属于因缘，所以无常；无常所以苦；无常、苦所以空；空所以无我；空、无我所以可舍。

你们因为爱着智慧，所以不能得涅槃。譬如尺蠖，屈曲安住后足，然后向前伸出前足；所缘之处到了尽头，再没有前进之处，就退回来。外道依止初禅，舍弃下地之欲，乃至依止非有想非无想处，舍弃无所有处；上面再无所依，所以不能舍弃非有想非无想处。因为再没有可依之处，恐惧失去我，害怕落入一无所得之中。

#### （三）外道戒法有开缘，佛法则不然

再者，外道经中有允许杀、盗、淫、妄语、饮酒的：说为天祠而咒杀无罪；为了修道，如果遭遇急难，想保全自身而杀小人无罪。

又说有急难时为了修道，除了金子，其余东西可以偷取以自救，以后再除去这罪殃。

除了师长之妻、国王夫人、善知识之妻、童女，其余的人在逼迫急难时，可以邪淫。

为了师长以及父母，为了自身、为了牛、为了作媒，允许妄语。

在寒冷之地，允许饮石蜜酒；在天祠中，或者允许尝一滴、两滴酒。

佛法中则不是这样！

对一切众生以慈心平等看待，乃至蚂蚁也不夺其命，何况杀人！

一针一线都不取，何况多物！

无主的淫女，连手指都不触碰，何况他人的妇女！

戏笑时也不得妄语，何况故意妄语！

一切酒、一切时都不得饮，何况在寒冷之地、天祠之中！

你们外道与佛法相差悬殊，有如天地！

你们外道之法，是生起诸烦恼之处；佛法则是灭除诸烦恼之处，这是大不相同的。

### 四、入佛法三门：蜫勒门、阿毗昙门、空门

诸佛之法无量，有如大海，随众生之意，作种种说法：或说有，或说无；或说常，或说无常；或说苦，或说乐；或说我，或说无我；或说勤行三业、摄集诸善法，或说一切诸法无作之相。像这样等等种种不同的说法，无智的人听了，以为乖违错乱；智者进入三种法门，观察一切佛语都是真实之法，不相违背。

哪三门？一是蜫勒门，二是阿毗昙门，三是空门。

问：什么名为蜫勒？什么名为阿毗昙？什么名为空门？

#### （一）蜫勒门：随相门、对治门

答：蜫勒有三百二十万言，是佛在世时大迦栴延所造；佛灭度后，人寿渐减，记忆力弱，不能广泛诵持，诸得道之人撰为三十八万四千言。

如果人进入蜫勒门，论议就无穷无尽；其中有随相门、对治门等种种诸门。

随相门，如佛所说偈：

```
诸恶莫作，　　诸善奉行，　　自净其意，
是诸佛教。
```

大意：一切恶不要作，一切善要奉行，自己净化其心意，这是诸佛的教法。

这其中应当说尽一切心所法，现在只说“自净其意”，就知道诸心所法都已说了。为什么？因为同相、同缘。

如佛说四念处，这其中不离四正勤、四如意足、五根、五力。为什么？四念处中：四种精进就是四正勤；四种定就是四如意足；五种善法就是五根、五力。佛虽然不说其余诸门，只说四念处，应当知道已经说了其余诸门。

如佛在四谛中，或说一谛，或说二谛、三谛。如马星比丘为舍利弗说偈：

```
诸法从缘生，　　是法缘及尽。
我师大圣王，　　是义如是说。
```

大意：诸法从因缘而生，这法的因缘以及它的灭尽，我的老师大圣王，就是这样说这个道理的。

这偈只说了三谛，应当知道道谛已经在其中，因为不相分离；譬如一人犯了事，全家受罪。

像这样等等，名为随相门。

对治门，如佛只说四颠倒：常颠倒、乐颠倒、我颠倒、净颠倒。

这其中虽然不说四念处，应当知道已经有四念处的意义。譬如说了药，就知道了病；说了病，就知道了药。

如果说四念处，就知道已经说了四颠倒；四颠倒就是邪相。

如果说了四颠倒，就已经说了诸结使。为什么？说了根本，就知道枝条都包括了。

如佛说一切世间有三毒；说了三毒，应当知道已经说了三分（戒、定、慧）与八正道。

如果说了三毒，应当知道已经说了一切诸烦恼之毒。十五种爱是贪欲之毒，十五种瞋是瞋恚之毒，十五种无明是愚痴之毒，诸邪见、憍慢、疑属于无明。

像这样一切结使，都归入三毒。用什么来灭除它们？三分与八正道。

如果说了三分与八正道，应当知道已经说了一切三十七道品。

像这样等等种种相，名为对治门。

像这样等等诸法，名为蜫勒门。

#### （二）阿毗昙门

什么名为阿毗昙门？或者佛自己说诸法的意义，或者佛自己说诸法的名称，诸弟子以种种方式集录述说，解释其意义。

如佛说：“如果有比丘对诸有为法不能正确忆念，想得世间第一法，没有这样的道理。

“如果没有得到世间第一法，想进入正位（见道），没有这样的道理。

“如果没有进入正位，想得须陀洹、斯陀含、阿那含、阿罗汉，没有这样的道理。

“有比丘对诸有为法正确忆念，得到世间第一法，这是有道理的。

“如果得到世间第一法，就进入正位；进入正位，得须陀洹、斯陀含、阿那含、阿罗汉，这必定是有道理的。”

如佛直接说了世间第一法，没有说它的相与义、属于哪一界所系、以何为因、以何为缘、有何果报。从世间第一法，以至种种声闻所行之法，乃至无余涅槃，一一分别其相与义，像这样等等，这名为阿毗昙门。

#### （三）空门：生空、法空

空门，是生空（众生空）、法空。

如《频婆娑罗王迎经》中，佛告诉大王：“色生时只是空在生，色灭时只是空在灭。诸行生时只是空在生，灭时只是空在灭。这其中没有吾我，没有人、没有神我，没有人从今世到后世；除了因缘和合的名字等众生，凡夫愚人追逐名字而寻求实体。”像这样等等经中，佛说生空。

法空，如《佛说大空经》中，十二因缘，从无明乃至老死：

如果有人说“这是老死”，或说“谁老死”，都是邪见。生、有、取、爱、受、触、六入、名色、识、行、无明，也是这样。

如果有人说“身就是神我”，或说“身与神我相异”，这两种说法虽然不同，同样是邪见。佛说：“身就是神我，这样的邪见，不是我的弟子；身与神我相异，也是邪见，不是我的弟子。”

这经中，佛说法空。

如果说“谁老死”，应当知道这是虚妄的，这名为生空；如果说“这是老死”，应当知道这是虚妄的，这名为法空。乃至无明也是这样。

再者，《佛说梵网经》中的六十二见：

如果有人说“神我是常，世间也是常”，这是邪见；如果说“神我无常，世间无常”，这也是邪见；“神我与世间亦常亦无常”、“神我与世间非常亦非非常”，都是邪见。

因此，知道诸法都空，这才是真实。

#### （四）无常亦非实：对治悉檀

问：如果说“神我是常”，应当是邪见，为什么？因为神我的本性不存在。

如果说“世间是常”，也应当是邪见，为什么？世间实际上都是无常，因为颠倒，所以说“有常”。

如果说“神我无常”，也应当是邪见，为什么？因为神我的本性不存在，不应当说“无常”。

如果说“世间无常”，不应当是邪见，为什么？一切有为法的本性，实际上都是无常。

答：如果一切法实际上都是无常，佛为什么说“世间无常，这名为邪见”？所以可知并不是真实地是无常。

问：佛处处说观察有为法无常、苦、空、无我，使人得道，为什么说“说无常就落入邪见”？

答：佛处处说无常，也处处说不灭。如释种摩诃男王来到佛那里，对佛说：“这迦毗罗城人众繁多，我有时遇到奔驰的车、脱缰的马、发狂的象、斗殴的人，便失去念佛之心；这时自己想：‘我现在如果死了，会生到哪里？’”佛告诉摩诃男：“你不要怖畏！你那时不会生在恶趣，必定到善处。譬如树木常常向东弯曲，如果有人砍伐，必定向东倒下；善人也是这样，如果身坏死亡之时，善的心意识长夜以信、戒、闻、施、慧熏习其心，所以必定得到利益，上生天上。”

如果一切法念念生灭无常，佛为什么说“以诸功德熏习其心，所以必定得以上生”？因此，知道不是无常之性。

问：如果无常不是真实的，佛为什么说无常？

答：佛随众生所应而说法，为了破除常颠倒，所以说无常；因为人们不知道、不相信有后世，所以说“心去到后世，上生天上，罪福业的因缘，百千万劫不失”。这是对治悉檀，不是第一义悉檀。诸法实相，非常非无常。佛也处处说诸法空，在诸法空中也没有无常。所以说“世间无常是邪见”。

所以名为法空。

#### （五）论力梵志问一究竟道

再者，毗耶离城有一位梵志，名叫论力，诸梨昌族人重金雇他，让他与佛辩论。他收了雇金之后，当夜就构思了五百个诘难，第二天早上与诸梨昌一起来到佛那里，问佛说：“是一个究竟道？还是众多究竟道？”

佛说：“一个究竟道，没有众多。”

梵志说：“佛说只有一个道，诸外道之师各自都有究竟道，这是众多而不是一个！”

佛说：“这些虽然各有众多，都不是真实之道。为什么？因为一切都以邪见执着，所以不名为究竟道。”佛问梵志：“鹿头梵志得道了吗？”梵志回答：“在一切得道者中，他是第一。”这时长老鹿头梵志比丘正在佛身后为佛扇扇。佛问梵志：“你认识这位比丘吗？”梵志认识他，惭愧地低下头。这时佛说〈义品〉偈：

```
各各谓究竟，　　而各自爱著，
各自是非彼，　　是皆非究竟！
是人入论众，　　辩明义理时，
各各相是非，　　胜负怀忧喜。
胜者堕憍坑，　　负者堕忧狱；
是故有智者，　　不随此二法。
论力汝当知，　　我诸弟子法，
无虚亦无实，　　汝欲何所求？
汝欲坏我论，　　终已无此处，
一切智难胜，　　适足自毁坏！
```

大意：各自认为自己是究竟，各自爱着自己的见解，各自以己为是、以彼为非，这些都不是究竟！这些人进入辩论的大众中，辩明义理时，各自相互是非，胜负之间怀着忧喜：胜者堕入憍慢之坑，负者堕入忧愁之狱；所以有智慧的人，不随顺这两种法。论力你应当知道，我诸弟子的法，无虚也无实，你想求什么？你想破坏我的论，终究没有这样的事；一切智难以胜过，只足以毁坏你自己！

像这样等等，在处处声闻经中，说诸法空。

#### （六）摩诃衍空门：诸法性常自空

摩诃衍（大乘）的空门，是一切诸法，其性常自空，不是因为以智慧方便观察才空。如佛为须菩提说：“色，色自空；受、想、行、识，识自空；十二入、十八界、十二因缘、三十七道品、十力、四无所畏、十八不共法、大慈大悲、萨婆若，乃至阿耨多罗三藐三菩提，都自空。”

#### （七）真空与邪见之别

问：如果一切诸法之性常自空、真空、无所有，怎么不落入邪见？邪见名为无罪无福、无今世后世，与这没有差别！

答：主张无罪无福的人，不说没有今世，只说没有后世；如草木之类，自生自灭。或者人出生，或者人被杀，止于现在，再没有后世之生；而不知道观察身内身外所有的自相都空，这就是差别。

再者，邪见的人多行众恶，断诸善事；观空的人对善法尚且不想执着去作，何况作恶！

问：邪见有两种：有破因又破果的，有破果而不破因的。如你所说的，是破果而不破因。

破因又破果的，说无因无缘、无罪无福，这就是破因；说无今世、后世、罪福之报，这就是破果。观空的人说一切皆空，那么罪福、因果都没有了，与这有什么不同？

答：邪见的人对诸法加以断灭而使之空；摩诃衍的人了知诸法真空，不破不坏。

问：这邪见有三种：

一是破罪福之报而不破罪福；破因缘之果报而不破因缘；破后世而不破今世。

二是破罪福之报也破罪福；破因缘之果报也破因缘；破后世也破今世，但不破一切法。

三是破一切法，都使之无所有。

观空的人也说真空无所有，与第三种邪见有什么不同？

答：邪见是破坏诸法而使之空；观空的人了知诸法真空，不破不坏。

再者，邪见的人说诸法都空无所有，取诸法的空相而作戏论；观空的人了知诸法空，不取相、不戏论。

再者，邪见的人虽然口说一切空，然而在可爱之处生爱，可瞋之处生瞋，可慢之处生慢，可痴之处生痴，自己欺骗自己；如佛弟子真实了知空，心不动摇，一切结使生起之处不再生起。譬如虚空，烟火不能染污，大雨不能淋湿；这样观空，种种烦恼不再附着于其心。

再者，邪见的人说无所有，不是从爱的因缘中出离；真空之名，是从爱的因缘中生出，这是差别。（此句文义不甚明，照原文直译，存疑。）

四无量心等诸清净法，因为所缘不实，尚且不能与真空智慧相等，何况这邪见？

再者，这种见名为邪见，真空之见名为正见。行邪见的人，今世是弊恶之人，后世当入地狱；行真空智慧的人，今世得到赞誉，后世得以作佛。譬如水与火的差异，也如甘露与毒药，又如以天食须陀来比臭粪！

再者，真空中有空空三昧；邪见之空虽然有空，却没有空空三昧。

再者，观真空的人，先有无量的布施、持戒、禅定，其心柔软，诸结使淡薄，然后得到真空；邪见中没有这些事，只是想以忆想分别、以邪心取空。

譬如乡下人起初不认识盐，看见贵人把盐放在种种肉菜中吃，问他：“为什么这样？”贵人说：“这盐能使诸物味美。”这人便想：这盐能使诸物味美，它自己的味道必定更多更美；便空手抓盐，满口吃下去，咸苦伤口；就问：“你为什么说盐能使味美？”贵人说：“痴人！这要衡量多少，调和才能味美，怎么能光吃盐？”

无智的人听说空解脱门，不修行诸功德，只想得到空，这是邪见，断诸善根。

像这样等等意义，名为空门。

#### （八）以般若入三门则不相违

如果人进入这三门，就知道佛法的意义不相违背。能知道这件事，就是般若波罗蜜的力量，对一切法无所挂碍。如果没有得到般若波罗蜜之法，进入阿毗昙门就落入有中，进入空门就落入无中，进入蜫勒门就落入有无之中。

【译注】三门之说是本卷的一个纲领：蜫勒门以随相、对治贯通诸法，阿毗昙门逐一分别相义，空门说生空、法空；佛语或说有、或说无、或说常、或说无常，入此三门便知不相违背。但论主随即点明，三门本身也可以成为执着处，离开般若，入阿毗昙则堕有，入空门则堕无，入蜫勒则堕亦有亦无。所以空门并不等于般若，般若是使人出入诸门而不着的那一力。

### 五、知一切法一相与种种相

再者，菩萨摩诃萨修行般若波罗蜜，虽然知道诸法一相，也能知道一切法的种种相；虽然知道诸法种种相，也能知道一切法一相。菩萨这样的智慧，名为般若波罗蜜。

问：菩萨摩诃萨怎样知道一切法的种种相？怎样知道一切法一相？

#### （一）一相：有相、无相、一、因、相

答：菩萨观察诸法之相，就是有相。因为这“有”，在诸法中有心生起，像这样等等，一切都有。

问：对于无法，怎么会有心生起？

答：如果说“无”，这件事就是有法。

再者，菩萨观察一切法一相，就是无相。如牛中没有羊相，羊中没有牛相；像这样等等，诸法中各自没有他法之相。如先前说因为有，所以有心生起，这法与“有”相异；因为相异，就应当是无。如果有法就是牛，羊也应当是牛。为什么？因为“有法”是没有差异的。如果相异就是无，像这样等等，一切都无。

再者，菩萨观察一切法是一，因为这“一”法，在诸法中有一心生起。诸法各自都有一相，合众多的一，所以名为二、名为三；一是实，二、三是虚。

再者，菩萨观察诸法有所因而有，如人身无常，为什么？因为有生灭之相。一切法都是这样，有所因而有。

再者，一切诸法是无所因而有的，如人身无常，因为生灭；因为生灭，所以知道无常。这因又应当有因，这样就无穷；如果无穷，就是无因；如果这因再没有因，这无常之因也不成为因，像这样等等，一切都是无因。

再者，菩萨观察一切法都有相，没有法是无相的，如：地，是坚、重之相；水，是冷、湿之相；火，是热、照之相；风，是轻、动之相；虚空，是容受之相；分别觉知，是识之相。有此有彼，是方位之相；有久有近，是时间之相；以浊恶之心恼害众生，是罪之相；以清净善心怜悯众生，是福之相；执着诸法，是缚之相；不执着诸法，是解脱之相；现前了知一切法而无碍，是佛之相。像这样等等，一切各有其相。

#### （二）无相：破地相

再者，菩萨观察一切法都无相，这些相从因缘和合而生，因为没有自性，所以无。

如地，是色、香、味、触四法和合，所以名为地；不只是因为色而名为地，也不只是因为香、只是因为味、只是因为触而名为地。

为什么？如果只是色是地，其余三者就不应当是地，地就没有香、味、触；香、味、触也是这样。

再者，这四法怎么能成为一法？一法怎么能成为四法？因此，不能以四法为地，也不能离开四法而有地。

问：我不是以四法为地，只是因为四法，地法才生，这地住在四法之中！

答：如果从四法而生地，地与四法就是相异的。如父母生子，子与父母相异。

如果是这样，现在眼见色、鼻知香、舌知味、身知触，地如果异于这四法，就应当另有不同的根、不同的识来知它；如果没有另外不同的根、不同的识来知它，就没有地。

问：如果上面所说的地相有过失，应当如阿毗昙所说的地相：地名为四大所造之色，只有地种是坚相，地是可见之色！

答：如果地只是色，先前已经说了它的过失。

又地是坚相，但眼睛所见的色，如水中之月、镜中之像、草木之影，就没有坚相；坚是由身根触知的。

再者，如果眼见之色是地，坚相是地种；眼见之色也是水、火，湿相、热相是水种、火种。如果是这样，风与风种也应当分别，却不加分别！如说：“什么是风？是风种；什么是风种？是风。”如果是一物，不应当作两种回答；如果是不异的，地与地种就不应当相异。

问：这四大各自不相分离，地中有四大，水、火、风中各有四大。只是地中地大多，所以以地为名；水、火、风也是这样。

答：不对！为什么？

如果火中有四大，应当都是热的，因为没有不热的火。

如果其余三大在火中不热，就不名为火；如果热，就舍弃了自己的本性，都名为火。

如果说因为细微所以不可知，那就与没有无异。如果有粗的可以得到，就知道有细的；如果没有粗的，也就没有细的。

像这样种种因缘，地相不可得；如果地相不可得，一切法相也不可得；所以一切法都是一相。

#### （三）无相亦自灭

问：不应当说无相。为什么？对诸法来说，无相就是相。

如果没有无相，就不能破一切法相，为什么？因为没有无相。

如果有这无相，就不应当说“一切法无相”！

答：以无相来破诸法之相。

如果有“无相”这一相，就落入诸法相之中；如果不落入诸法相之中，就不应当这样诘难！

无相破除了诸法之相，也自灭其相；譬如前面燃火的木头，烧尽诸柴之后，自己也烧尽了。所以圣人修行无相无相三昧，因为要破除无相。

再者，菩萨观察一切法不合、不散，无色、无形，无对、无示、无说，一相，就是无相。像这样等等，是诸法一相。

#### （四）种种相：无量法门

怎样观察种种相？

一切法摄入二法之中，就是名与色，色与无色，可见与不可见，有对与无对，有漏与无漏，有为与无为等，二法有一百零二种法门，如〈千难品〉中所说。

再者，有二法：忍辱、柔和。

又二法：亲敬、供养。

二施：财施、法施。

二力：智慧分别力、修道力。

二具足：戒具足、正见具足。

二相：质直相、柔软相。

二法：定、智。

二法：明、解说。

二法：世间法、第一义法。

二法：念、巧慧。

二谛：世谛、第一义谛。

二解脱：待时解脱、不坏心解脱。

二种涅槃：有余涅槃、无余涅槃。

二究竟：事究竟、愿究竟。

二见：知见、断见。

二具足：义具足、语具足。

二法：少欲、知足。

二法：易养、易满。

二法：法、随法行。

二智：尽智、无生智。

像这样等等，分别无量的二法门。

再者，知三道：见道、修道、无学道。

三性：断性、离性、灭性。

三修：戒修、定修、慧修。

三菩提：佛菩提、辟支迦佛菩提、声闻菩提（原文小注：不再有学，是智慧满足之名）。

三乘：佛乘、辟支迦佛乘、声闻乘。

三归依：佛、法、僧。

三住：梵住、天住、圣住。

三增上：自增上、他增上、法增上。

诸佛三不护：身业不护、口业不护、意业不护。

三福处：布施、持戒、善心。

三器仗：闻器仗、离欲器仗、慧器仗。

三轮：变化轮、示他心轮、教化轮。

三解脱门：空解脱门、无相解脱门、无作解脱门。

像这样等等无量的三法门。

又知四法：四念处、四正勤、四如意足、四圣谛、四圣种、四沙门果、四知、四信、四道、四摄法、四依、四通达善根、四道、四天人轮、四坚法、四无所畏、四无量心，像这样等等无量的四法门。

又知五无学众、五出性、五解脱处、五根、五力、五大施、五智、五阿那含、五净居天处、五治道、五智三昧、五圣分支三昧、五如法语道，像这样等等无量的五法门。

又知六舍法、六爱敬法、六神通、六种阿罗汉、六地见谛道、六随顺念、六三昧、六定、六波罗蜜，像这样等等无量的六法门。

又知七觉支、七财、七依止、七想定、七妙法、七知、七善人去处、七净、七财福、七非财福、七助定法，像这样等等无量的七法门。

又知八圣道分、八背舍、八胜处、八大人念、八种精进、八丈夫、八阿罗汉力，像这样等等无量的八法门。

又知九次第定、九名色等减（原文小注：从名色至生死为九）、九无漏智（原文小注：得尽智，所以除去等智）、九无漏地（六禅、三无色）、九地思惟道，像这样等等无量的九法门。

又知十无学法、十想、十智、十一切入、十善大地、佛十力，像这样等等无量的十法门。

又知十一助圣道法，又知十二因缘法，又知十三出法、十四变化心、十五心见谛道、十六安那般那行、十七圣行、十八不共法、十九离地。思惟道中有一百六十二道，能破烦恼之贼。一百七十八沙门果：八十九有为果、八十九无为果。像这样等等种种无量的不同之相的法，其生、灭、增、减，得、失、垢、净，都能了知。

#### （五）入自性空而分别诸法

菩萨摩诃萨知道这些法之后，能使诸法入于自性空，而对诸法无所执着，超过声闻、辟支佛地，进入菩萨位中；进入菩萨位中之后，因为大悲怜悯，以方便力分别诸法的种种名字，度化众生，使他们得到三乘。譬如有技艺的人，以药力能使银变为金，金变为银。

问：如果诸法之性是真空，为什么要分别诸法的种种名字？为什么不只说真空之性？

答：菩萨摩诃萨不说空是可得、可执着的；如果空是可得、可执着的，就不应当说诸法种种不同之相。

不可得之空，是无所挂碍的；如果有挂碍，这就是可得，不是不可得之空。

如果菩萨摩诃萨知道不可得之空，还能分别诸法，怜悯度脱众生，这是般若波罗蜜的力量。

简要地说，诸法实相就是般若波罗蜜。

### 六、此经实相何以独名般若波罗蜜

问：一切世俗经书，以及九十六种出家外道的经中，都说有诸法实相；又声闻法的三藏中，也有诸法实相，为什么不名为般若波罗蜜？而这部经中的诸法实相，唯独名为般若波罗蜜？

答：世俗经书中所说，是为了安定国家、保全家族、身体、性命、寿命、安乐，所以不是真实的。

外道出家，落入邪见之法中，因为心中爱着，所以也不是真实的。

声闻法中虽然有四谛，以无常、苦、空、无我观察诸法实相，但因为智慧不具足、不锐利，不能为一切众生，不是为了得到佛法，所以虽然有真实的智慧，不名为般若波罗蜜。如经中说：“佛入出诸三昧，舍利弗等乃至连它们的名字都没有听说过，何况能知道！”为什么？诸阿罗汉、辟支佛初发心时，没有大愿，没有大慈大悲，不求一切诸功德，不供养一切三世十方诸佛，不审察求知诸法实相；只是想求脱离老、病、死之苦。

诸菩萨从初发心，发弘大誓愿，有大慈悲，求一切诸功德，供养一切三世十方诸佛，有大锐利的智慧，求诸法实相。除去种种诸观，就是净观、不净观，常观、无常观，乐观、苦观，空观、实观，我观、无我观。舍弃像这样等等以妄见心力所作的诸观，只观察外缘中的实相：非净、非不净，非常、非非常，非乐、非苦，非空、非实，非我、非无我。像这样等等诸观，不执着、不可得；这是就世俗法说，不是第一义。周遍清净，不破不坏，是诸圣人所行之处，这名为般若波罗蜜。

### 七、如何得般若波罗蜜

问：已经知道般若的体相是无相、无得之法，修行者怎样能得到这法？

答：佛以方便说法，修行者如所说而行，就能得到。

譬如悬崖险道，借助梯子能上去；又如深水，凭借船只得以渡过。

#### （一）依次行五度而得般若

初发心的菩萨，或者从佛听闻，或者从佛弟子听闻，或者在经中听闻：一切法毕竟空，没有决定之性可取可着，这是第一实法，灭除诸戏论。

涅槃之相是最安稳的；然而我想度脱一切众生，怎么能独自取涅槃？我现在福德、智慧、神通之力还不具足，不能引导众生，应当具足这些因缘，修行布施等五波罗蜜：

以财施的因缘，得到大富；以法施的因缘，得到大智慧；能以这两种布施，引导贫穷的众生，使他们进入三乘之道。

以持戒的因缘，生在人天之中尊贵，自己脱离三恶道，也使众生免于三恶道。

以忍辱的因缘，遮障瞋恚之毒，得到身色端正，威德第一，见者欢喜，恭敬信服，何况说法！

以精进的因缘，能破除对今世、后世福德与道法的懈怠，得到金刚之身、不动之心；以这身、心，破除凡夫的憍慢，使他们得到涅槃。

以禅定的因缘，破除散乱之心，离开五欲的罪恶之乐，能为众生说离欲之法。禅是般若波罗蜜的依止之处，依于这禅，般若波罗蜜自然而生。如经中说：“比丘一心专注于定，能观察诸法实相。”

再者，知道欲界中多以悭吝、贪婪的罪业关闭诸善之门；修行檀波罗蜜时，破除这两件事，打开诸善之门。

想要使善门常开，所以修行十善道的尸罗波罗蜜。

还没有得到禅定、智慧，还没有离欲，所以会破坏尸罗波罗蜜，因此要修行忍辱。

知道上面三件事能打开福德之门。

又知道这福德的果报是无常的，在天人中受乐，还会再堕入苦中；厌离这无常的福德，所以求实相般若波罗蜜。怎样才能得到？必定要以一心，才能得到。如穿取龙王的宝珠，一心观察，能不触动龙，就能得到价值等同阎浮提的宝珠。

一心禅定，要除去五欲、五盖；想得到心中之乐，就要大用精进，所以在忍辱之后说精进波罗蜜。如经中说：“修行者端身正坐，系念在前，专精求定；即使肌骨枯朽，也终不懈退。”所以以精进修禅。如果有财而布施，不足为难；因为畏惧堕入恶道、恐怕失去好名声，持戒、忍辱也不为难。所以在上面三度中不说精进。现在为了般若波罗蜜的实相，从心中求定，这件事难，所以必须精进。

这样修行，能得到般若波罗蜜。

#### （二）一度乃至多度皆可得般若

问：一定要修行五波罗蜜，然后才能得到般若波罗蜜吗？也有修行一、二种波罗蜜就得到般若波罗蜜的吗？

答：诸波罗蜜有两种：

一是在一种波罗蜜中，相应随行而具足诸波罗蜜；二是随时分别修行波罗蜜。

以多的那一种受名。譬如四大共同和合，虽然不相分离，以多的那一大为名。

相应随行的，一种波罗蜜中具足五波罗蜜，这是不离五波罗蜜而得般若波罗蜜。

随时得名的，或者因一种、因两种而得般若波罗蜜。

如果有人发阿耨多罗三藐三菩提心而布施，这时推求布施之相，不一不异，非常非无常，非有非无等，如破布施中所说。因为布施的实相，了解一切法也是这样，这名为因布施而得般若波罗蜜。

或者有人持戒不恼害众生，心中无悔；如果取相生起执着，就会引起诤竞。这人虽然先前不瞋众生，因为对法有憎爱之心，所以就瞋众生。所以如果想要不恼害众生，应当修行诸法平等；如果分别这是罪、这是无罪，就不是修行尸罗波罗蜜。为什么？憎恶罪、爱着无罪，心就自高，又落入恼害众生之道中。所以菩萨观察有罪者、无罪者，心中无憎无爱；这样观察，这是只修行尸罗波罗蜜而得般若波罗蜜。

菩萨作这样的念头：“如果没有得到法忍，就不能常忍。一切众生在还没有被逼迫时能忍，苦来切身时就不能忍。譬如囚犯畏惧杖打，却去受死亡之苦。因为这个因缘，应当生起法忍：没有打的人、骂的人，也没有受的人，只是由于前世颠倒果报的因缘，所以名为受。”这时不分别忍的事、忍的法，深入毕竟空，这名为法忍。得到这法忍，常常不再瞋恼众生；与法忍相应的智慧，就是般若波罗蜜。

精进常在一切善法中，能成就一切善法。如果以智慧衡量分别诸法，通达法性，这时精进助成智慧。又了知精进的实相，离开身心，如实不动，这样的精进能生般若波罗蜜。其余的精进如幻、如梦，虚诳不实，所以不说。

如果以深心收摄其念，能如实见到诸法实相。诸法实相，不能以见、闻、念、知而得到。为什么？六根、六尘都是虚诳的因缘果报；这其中所知所见，也都是虚诳的。这虚诳的知，都不可信；可信的，唯有诸佛在阿僧祇劫中所得的实相智慧。以这智慧，依于禅定一心，观察诸法实相，这名为在禅定中生起般若波罗蜜。

或者有人离开五波罗蜜，只是听闻、读诵、思惟、衡量，通达诸法实相，这是在方便智中生起般若波罗蜜。

或者从二种、或三种、四种波罗蜜生起般若波罗蜜。

如听闻说一谛而成就道果，或者听闻二谛、三谛、四谛而得道果。有人对苦谛迷惑多，所以为他说苦谛而得道；其余三谛也是这样。或者有人对四谛都迷惑，所以为他说四谛而得道。如佛对比丘说：“你如果能断除贪欲，我保证你得阿那含道。”如果断除了贪欲，应当知道瞋、痴也断了。

六波罗蜜中也是这样，为了破除过多的悭贪，所以说布施之法，应当知道其余的恶也被破除了。为了破除种种杂恶，所以完整地说六度。所以或者一一单行，或者合起来行；普遍为一切人而说六波罗蜜，不是为一个人。

#### （三）不行一切法而得般若

再者，如果菩萨不行一切法，因为不得一切法，所以得般若波罗蜜。为什么？

诸行都是虚妄不实的，或者在近处有过，或者在远处有过：

如不善法，在近处就有过罪；善法久后变异时，执着的人能生起忧苦，这是在远处有过罪。

譬如美食、恶食，都掺了毒：吃恶食当时就不愉快；吃美食当时甘美愉悦，久后都会夺命，所以二者都不应当吃！善与恶的诸行也是这样。

问：如果是这样，佛为什么说三种行：梵行、天行、圣行？

答：行于无行，所以名为圣行。为什么？因为一切圣行中都不离三解脱门。

梵行、天行中，是因为取众生相而生起的，虽然行的时候没有过失，以后都有过失。又就当下求其真实，都是虚妄；如果贤圣以无着之心修行这两种行，就没有过咎。

如果能这样行于无行之法，都无所得，颠倒虚妄的烦恼毕竟不生。如虚空清净，所以得到诸法实相；以无所得为得，如无所得般若中所说：色等法不是因为空才空，从本以来常自空。色等法不是因为智慧达不到所以无所得，从本以来常自无所得。

所以不应当问“修行几种波罗蜜才得到般若波罗蜜”。诸佛怜悯众生，随顺世俗，所以说行，这不是第一义。

#### （四）两种无所得

问：如果无所得、无所行，修行者为什么还要求它？

答：无所得有两种：一是世间想有所求，不能如意，这是无所得；二是在诸法实相中，领受决定之相不可得，所以名为无所得；并不是没有福德智慧、不增益善根。

如凡夫分别世间法，所以有所得；诸善功德也是这样，随顺世间心，所以说有所得，在诸佛心中则无所得。

这是略说般若波罗蜜的意义，后面会详细说。

## 本卷要义

本卷正式进入般若波罗蜜。论主开头就把一个容易被跳过的难题摆出来：菩萨尚未尽漏、慧眼未净，怎能得诸法实相？答案是前灯后灯：同一个暗室，前灯与暗共住而能照物，后灯尽暗而倍明。菩萨的般若与佛的一切种智所照是一，深浅不同，所以菩萨所行也可称波罗蜜，是因中说果。随后的实相定义极简：舍一切观，灭一切言语，离诸心行，不生不灭如涅槃相；而《赞般若偈》以见与不见皆缚、见与不见皆脱、不可取而取，把这一点推到言语的边缘。

般若何以独称“摩诃”，论主的回答是它出生四种大人，又能与众生常不变异的涅槃果；而何为智慧，则先摄三乘：学、无学、非学非无学，辟支佛的因缘觉与独觉、小辟支与大辟支，佛道智慧总相别相尽知。这里论主对外道智慧的批评颇见分量：外道观空而取空相，知法空而不知我空，爱着观空的智慧；无想定是强令心灭，非想非非想处如尺蠖到了枝头，再无可依，只因怕失去我而不能舍。外道戒法处处有开缘，佛法则蚁子不杀、一针不取、戏笑不妄语，一切酒一切时不饮。

三门之说是本卷的纲领。蜫勒门以随相、对治贯通诸法，说一即知其余；阿毗昙门逐一分别相义；空门说生空、法空，佛说“世间无常”也是邪见，因为无常只是对治悉檀，诸法实相非常非无常。摩诃衍的空门更进一层，诸法性常自空，不待智慧观察才空。真空与邪见的分别，论主讲得极细：邪见破诸法令空，真空不破不坏；邪见取空相而戏论，真空不取相；邪见口说空而爱瞋如故，真空则结使生处不复生；真空前有无量施戒禅定使心柔软，邪见只是空抄盐满口食之。而三门本身若离般若，入阿毗昙则堕有，入空门则堕无，入蜫勒则堕亦有亦无。

知一相与知种种相，是般若波罗蜜的另一面。一相之观，论主以破地相为例：地不可即四法、不可离四法、不可异于四法，地相不可得，则一切法相不可得；而无相本身也须破，如火烧尽薪后自身亦灭，所以有无相无相三昧。种种相之观，则一口气列出从二法门到一百七十八沙门果的无量法门。两者合起来，就是“令诸法入自性空，而能以方便力分别诸法种种名字”，如工巧以药力令银变金、金变银。论主说得透：若空是可得可着，就不应说种种异相；正因为空不可得、无所挂碍，菩萨才能还来分别诸法、度脱众生。

如何得般若，论主一面依次说五度如何为般若作准备，施开善门、戒令常开、忍护戒、精进修禅、禅为般若依止；一面又说一度、二度乃至离五度而闻思通达，都可得般若，因为每一度推到实相处，都是般若。最后一转最深：不行一切法，不得一切法，才得般若；善行与恶行如美食恶食俱杂毒，唯有行无行的圣行不离三解脱门。所以不应问行几度得般若，诸佛随俗说行，非第一义；而无所得也不是什么都没有，只是在实相中不受决定之相，福德智慧照样增益。
