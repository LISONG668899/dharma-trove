# 因缘心论

龙树菩萨 造

说明：本篇据《大正藏》第三十二册 No. 1654《因缘心论颂》《因缘心论释》译出。颂文保留原文，释论译为现代白话。龙树菩萨以七个偈颂，把十二缘起归摄为烦恼、业、苦三类，说明三者辗转相生、轮回不息，又以八个譬喻说明：没有任何实法从此世迁移到后世，而前后相续又分毫不爽。最后指出，于缘起见真，即得解脱。颂文第三首第三句，大正藏颂本作“一复生于三”，释文作“七复生于三”，今依释文。

## 一、因缘心论颂

<p class="dt-verse">差别十二支　能仁说缘生<br>于烦恼业苦　三中俱摄尽<br><br>初八九烦恼　二及十是业<br>余七皆是苦　十二唯三摄<br><br>从三生于二　从二生于七<br>七复生于三　此有轮数转<br><br>诸趣唯因果　此中无众生<br>唯从于空法　还生于空法<br><br>诵灯镜及印　火精种梅声<br>诸蕴相续结　不移智应察<br><br>于甚微细事　若有见断者<br>彼不善因缘　未见缘生义<br><br>此中无可见　亦无少安立<br>于真以观真　见真而解脱</p>

## 二、因缘心论释

### 请问缘起

有一位沙门，乐于听闻佛法，能够专心谛听，善于忆持，能够领悟，能够观察，并且具足简择取舍的智慧。他来到导师面前，就如来的教法这样请问：

“薄伽梵！能仁所宣说的缘起，有十二个差别支分，这十二支归摄在哪些类别之中？我很想听闻。”

导师知道他问的是真实义理，便告诉他：这十二支，在烦恼、业、苦三者之中全部摄尽。这是一句分辨精当、切中要害的话。

### 释颂中的名词

“十二”，是十加二，所以叫十二支。各支互不相同，所以叫“差别”。就像一辆车由各个部件组成，每一部分称为一支，缘起的各个环节也称为“支”。能够寂静身口，所以称为“能仁”。“能仁说”的“说”，是宣畅解释的意思，是“说”的另一种表达。

这十二支，不是由自性、命定、士夫（神我）、假相、自在天、时间、自然、随欲、造物主、偶然等所生，而是由因缘所生。这十二差别支，在烦恼、业、苦之间辗转相依，就像一束芦苇彼此倚靠而立，在这三类中全部摄尽。“尽”就是毫无遗余的意思。

### 十二支如何归摄于三类

问：哪些是烦恼？哪些是业？哪些是苦？这十二差别支，各归属哪一类？

答：颂中说“初八九烦恼”。十二支中，第一支是无明，第八支是爱，第九支是取，这三支属于烦恼。

问：哪些是业？

答：颂中说“二及十是业”。第二支是行，第十支是有，这两支属于业。

颂中又说“余七皆是苦”。除去烦恼和业所摄的五支，其余七支属于苦，应当了知，也就是识、名色、六入、触、受、生、老死。“皆”是总括之词，把爱别离苦、怨憎会苦、求不得苦也一并摄在其中。所以这十二支法，在业、烦恼、苦中全部摄尽。“唯”是遮止的意思，表示经中所说的缘起法，在这三类中已经摄尽，再没有其余。

### 烦恼、业、苦如何相生

问：这个道理已经明白了。那么烦恼、业、苦三者，又是怎样相生的？请为我解说。

答：颂中说“从三生于二”，就是从三种烦恼生出两种业。“从二生于七”，就是从两种业生出前面所说的七种苦。“七复生于三”，就是从七种苦又生出种种烦恼，再从三种烦恼生出两种业。“此有轮数转”，“有”有三种，就是欲有、色有、无色有。众生在三有之中不停息地流转，各类凡夫世间就这样自己流转漂浪。

“此”字表示不定的意思：众生并不是按固定次序依次生于诸有之中，所以说是不定的。

### 唯有因果，并无众生

问：那个能够自主的众生，也就是“我”，到底是什么？它起什么作用？

答：颂中说“诸趣唯因果，此中无众生”。六道诸趣之中，只有因和果。除了假名之外，其中并没有真实的众生，这才是真实义。众生只是假立而有，而假立的境界并不成为实在之物。

### 谁从此世到后世

问：如果是这样，那么是谁从此世去到后世呢？

答：没有任何一个法，哪怕微细到极微，从此世迁移到后世。尽管如此，颂中说“唯从于空法，还生于空法”：从无我、无我所的烦恼和业这五种空因，还生出同样无我、无我所的七种苦果。因是无我、无我所，果也是无我、无我所。虽然如此，从自性无我之法，仍然生出自性无我之法，应当这样了知。所以作如此宣说。

### 八个譬喻

问：从自性无我之法，还生出自性无我之法，有什么譬喻可以说明？

答：颂中说“诵灯镜及印，火精种梅声”。应当了知，通过这些譬喻，以及其他类似的譬喻，可以成立诸法自性无我，同时成立后世的存在。

譬如老师念诵经文，弟子跟着学诵。如果说老师的念诵转移到了弟子那里，那么老师此后就应当不再有这段念诵了，可事实并非如此，所以说老师的念诵没有转移过去。另一方面，弟子的念诵也不是从别处得来的，否则就成了无因无果。

临终的心识也和老师的念诵一样。如果说临终心识原封不动地去到后世，就犯了常见的过失，所以它并不迁移到后世。然而后世的心识也不是从别处得来的，否则就成了无因无果。

老师的念诵与弟子的念诵，说是同一个也不对，说是不同的两个也不对，难以施设为一或为异。同样，依靠临终心识，结生的心识得以生起，二者之间也是说一不得、说异不得，难以施设。

其余譬喻也是如此：从一盏灯点燃另一盏灯；依靠面孔，镜中现出影像；从印章印出印文；从火精（聚日取火的火珠）引出火来；从种子生出幼芽；看到梅子，口中生出津液；从声音发出回响。这些都是前后相续，说一不得，说异不得，难以施设。

### 诸蕴相续，不移而生

颂中接着说“诸蕴相续结，不移智应察”。“蕴”就是色、受、想、行、识五蕴。“相续结”，就是从前因所生出的后果。没有任何一个法，哪怕微细到极微，从此世迁移到后世。众生之所以流转，是从虚妄分别的习气而生起的。

后面说“智应察”的“应”，是指逆观，应当知道它的意思是反过来观察：应当观察诸法无常、苦、空、无我。这样观察的人，就不会对诸事愚痴。不愚痴，就不会生贪；没有贪，嗔也就不生；没有嗔，就不造业；不造业，就不会有取；没有取，就不会造作后有；没有后有，就不会再受生；不再受生，身心的痛苦也就不会生起。

如此，不再积集烦恼与业这五种因，后世余处的苦果也就不会生起。这个果，就是解脱。因此，这样观察能够断除断见、常见等种种恶见。

### 结颂

这里有两个偈颂：

<p class="dt-verse">于甚微细事　若有见断者<br>彼不善因缘　未见缘生义<br><br>此中无可见　亦无少安立<br>于真以观真　见真而解脱</p>

前一颂是说：哪怕对极其微细的事物，只要有人认为它会断灭，这个人就是不善于因缘，没有见到缘起的真义。

后一颂是说：缘起之中，没有一个实法可以见到，也没有一丝一毫可以安立。以真实的智慧观照真实，见到真实，就得解脱。
