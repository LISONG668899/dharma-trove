# 龙树《大智度论》卷第五

龙树菩萨造　后秦龟兹国三藏法师鸠摩罗什奉诏译

## 初品中摩诃萨埵释论第九

【经】

摩诃萨埵。

【论】

问：什么叫“摩诃萨埵”？

答：“摩诃”是大；“萨埵”指众生，或者指勇心。这个人的心能成办大事，因为有不退不还的大勇心，所以名为“摩诃萨埵”。

再者，“摩诃萨埵”在众多众生中最为上首，所以名为“摩诃萨埵”。

再者，在众多众生中生起大慈大悲，成立大乘，能行大道，能到达最大之处，所以名为“摩诃萨埵”。

再者，成就大人之相，所以名为“摩诃萨埵”。

摩诃萨埵之相，如赞佛的偈中说：

```
唯佛一人独第一，　三界父母一切智，
于一切等无与等，　稽首世尊希有比！
凡人行惠为己利，　求报以财而给施，
佛大慈仁无此事，　怨亲憎爱以等利！
```

大意：唯有佛一人独为第一，是三界的父母、一切智者，在一切平等之中无与伦比，我稽首礼敬稀有无比的世尊！凡人施恩是为了自己的利益，为了求回报才以财物施予；佛以大慈大仁，没有这样的事，对怨家与亲人、憎恶与爱念，都平等地给予利益！

再者，必定能说法破除一切众生以及自身的大邪见、大爱慢、大我心等种种烦恼，所以名为“摩诃萨埵”。

再者，众生如同大海，没有开始、没有中间、没有终结；即使有明智的算师在无量岁月中计算，也不能算尽。

如佛对无尽意菩萨说：“譬如十方一切世界，乃至虚空的边际，合成一片大水；让无数无量的众生，共同拿一根头发取走一滴水而离去；又有无数的众生，像前面一样共同拿一根头发取走一滴水而离去；这样使那片大水全部取尽，众生仍然没有穷尽。”这样的众生无边、无量、不可计数、不可思议，摩诃萨埵都能救济，使众生离开苦恼，安置在无为安稳的快乐之中。因为有这样的大心，想度化众多众生，所以名为“摩诃萨埵”。

如《不可思议经》中，沤舍那优婆夷对须达那菩萨说：诸位菩萨摩诃萨，不是为了度化一个人而发阿耨多罗三藐三菩提心，也不是为了二人、三人乃至十人，不是为了百人、千人、万人、十万人、百万人，不是为了一亿、十亿、百亿、千亿、万亿乃至亿亿人。不是为了阿由他亿众生而发心，不是为了那由他亿，不是为了阿耶陀众生；以下依次是更大的数目，菩萨发心都不是为了这样的数目：不是频婆罗，不是歌歌罗，不是阿歌罗，不是簸婆罗，不是摩波罗，不是波陀，不是多婆，不是鞞婆呵，不是怖摩，不是念摩，不是阿婆迦，不是摩伽婆，不是毗罗伽，不是僧伽摩，不是毗萨罗，不是谓阎婆，不是鞞阇迦，不是鞞卢呵，不是鞞跋帝，不是鞞伽多，不是兜罗，不是阿婆罗那，不是他婆罗，不是鞞婆耶婆，不是藐写，不是钝那耶写，不是□婆罗，不是鞞婆罗，不是菩遮多，不是阿跋伽陀，不是鞞施他，不是泥婆罗，不是□犁浮陀，不是波摩陀夜，不是比初婆，不是阿犁浮陀，不是阿犁萨写，不是□云迦，不是度于多，不是呵楼那，不是摩楼陀，不是叉夜，不是乌罗多，不是末殊夜摩，不是三摩陀，不是毗摩陀，不是波摩陀，不是阿满陀罗，不是婆满多罗，不是摩多罗，不是□兜末多罗，不是鞞摩多罗，不是波罗多罗，不是尸婆多罗，不是□罗，不是为罗，不是提罗，不是枝罗，不是翅罗，不是尼罗，不是斯罗，不是波罗，不是弥罗，不是婆罗罗，不是迷楼，不是企卢，不是摩屠罗，不是三牟罗，不是阿婆夜，不是剑摩罗，不是摩摩罗，不是阿达多，不是□楼，不是鞞楼婆，不是迦罗跋，不是呵婆跋，不是鞞婆跋，不是婆婆，不是阿罗婆，不是娑罗婆罗，不是迷罗浮罗，不是摩遮罗，不是陀摩罗，不是波摩陀，不是尼伽摩，不是阿跋多，不是泥提舍，不是阿叉夜，不是三浮陀，不是婆摩摩，不是阿婆陀，不是沤波罗，不是波头摩，不是僧佉，不是伽提，不是沤波伽摩，不是阿僧祇，不是阿僧祇阿僧祇，不是无量，不是无量无量，不是无边，不是无边无边，不是无等，不是无等无等，不是无数，不是无数无数，不是不可计，不是不可计不可计，不是不可思议，不是不可思议不可思议，不是不可说，不是不可说不可说。（数名中“□”处，底本原字缺损。）

不是为了一个国土微尘数那么多的众生而发心，不是为了二个、三个乃至十、百、千、万、亿、千万亿、阿由陀、那由他，乃至不可说不可说国土微尘数那么多的众生而发心。

不是为了一个阎浮提微尘数那么多的众生而发心，不是为了瞿陀尼、郁怛罗曰、弗婆提微尘数那么多的众生而发心。

不是为了小千世界、中千世界、大千世界微尘数那么多的众生而发心；不是为了二个、三个乃至十、百、千、万、亿、阿由他、那由陀，乃至不可说不可说三千大千世界微尘数那么多的众生而发心。

不是为了供养、供给一位佛而发心，乃至不是为了供养、供给不可说不可说诸佛而发心；不是为了供养、供给一个国土微尘数那么多的诸佛而发心，乃至不是为了供养、供给不可说不可说三千大千世界微尘数那么多的诸佛而发心。

不是为了清净一个佛土而发心，乃至不是为了清净不可说不可说三千大千世界微尘数那么多的佛土而发心。

不是为了受持一位佛的法而发心，乃至不是为了受持不可说不可说三千大千世界微尘数那么多诸佛的法而发心。

不是为了使一个三千大千世界中佛种不断而发心，乃至不是为了使不可说不可说三千大千世界微尘数那么多的三千大千世界中佛种不断而发心。

不是为了分别了知一位佛的愿而发心，乃至不是为了分别了知不可说不可说三千大千世界微尘数那么多诸佛的愿而发心。

不是为了庄严一个佛土而发心，乃至不是为了庄严不可说不可说三千大千世界微尘数那么多的佛土而发心。

不是为了分别了知一位佛法会中的弟子众而发心，乃至不是为了分别了知不可说不可说三千大千世界微尘数那么多佛会中的弟子众而发心。

不是为了护持一位佛的法轮而发心，乃至不是为了护持不可说不可说三千大千世界微尘数那么多诸佛的法轮而发心。

不是为了知道一个人的种种心，不是为了知道一个人的种种根，不是为了知道一个三千大千世界中诸劫的次第相续，不是为了分别断除一个人的种种烦恼而发心，乃至不是为了分别断除不可说不可说三千大千世界微尘数那么多人的种种烦恼而发心。

这些菩萨摩诃萨发愿说：要教化尽一切十方众生，要供养、供给尽一切十方诸佛，愿使一切十方诸佛国土清净，以坚固的心受持一切十方诸佛的法，因为要分别了知一切诸佛国土，要尽知一切诸佛的弟子众，要分别了知一切众生的种种心，要知道并断除一切众生的种种烦恼，要尽知一切众生的种种根，所以诸菩萨发心求作阿耨多罗三藐三菩提。像这样以十门为首，乃至百千万亿阿僧祇门，都是道法之门，菩萨应当知道、应当进入！简略地说，这就是诸菩萨的真实之道。一切诸法都能进入、都能了知，因为以智慧了知，因为在一切佛土的菩萨道中庄严。

沤舍那说：“善男子！我的愿是这样：从有世界以来，一切众生都清净，一切烦恼全都断除。”须达那问：“这是什么解脱？”沤舍那回答：“这名为无忧安稳幢。我只知道这一个解脱门，不知道诸菩萨的大心：诸菩萨的心如同大海水，能受持一切诸佛之法；诸菩萨的心不动，如同须弥山；诸菩萨如同药王，能除去一切烦恼；诸菩萨如同太阳，能照除一切黑暗；诸菩萨如同大地，能含容承载一切众生；诸菩萨如同风，能利益一切众生；诸菩萨如同火，能烧尽一切外道与种种烦恼；诸菩萨如同云，能降下法雨；诸菩萨如同月亮，福德光明能照耀一切；诸菩萨如同释提桓因，守护一切众生。这菩萨道法甚深，我怎能全都知道！”

因为这些菩萨生起大愿，想要成办大事，想要到达大处，所以名为“摩诃萨埵”。

再者，在这部《般若波罗蜜经》中，佛亲自说摩诃萨埵之相：“这样这样的相，就是摩诃萨埵之相。”

舍利弗、须菩提、富楼那等诸大弟子，也各自在相关的品中说过，这里应当广说。

## 初品中菩萨功德释论第十

【经】

皆得陀罗尼及诸三昧，行空、无相、无作，已得等忍。

【论】

问：为什么按这三件事的次第来赞叹菩萨摩诃萨？

答：为了显示诸菩萨真实的功德，应当赞叹的就赞叹，应当信受的就信受；以一切众生所不能相信的甚深清净之法来赞叹菩萨。

再者，前面先说了菩萨摩诃萨的名字，还没有说为什么称为菩萨摩诃萨；因为得到诸陀罗尼、三昧以及忍等种种功德，所以名为菩萨摩诃萨。

问：已经知道次第的意义了，为什么名为“陀罗尼”？陀罗尼是怎样的？

答：“陀罗尼”，汉语意为能持，或者意为能遮。

所谓能持：积集种种善法，能持守使之不散不失。譬如完好的器皿盛水，水不会漏散。

所谓能遮：不善根的恶心生起时，能遮止使之不生；如果想作恶造罪，能持住使之不作。这名为陀罗尼。

这陀罗尼，或者与心相应，或者与心不相应；或者有漏，或者无漏；是无色、不可见、无对；为一持、一入、一阴所摄，就是法持、法入、行阴；为九种智所知（丹本注：除去尽智）；为一种识所识（丹本注：就是意识）。阿毗昙法中，陀罗尼的意义是这样。

再者，得到陀罗尼的菩萨，对一切所听闻的法，凭借念力，都能受持而不忘失。

再者，这陀罗尼之法常常追随菩萨，譬如隔日发作的疟疾；这陀罗尼不离开菩萨，譬如鬼附在身上；这陀罗尼常随菩萨，如同善律仪、不善律仪常随其人。

再者，这陀罗尼扶持菩萨，不让菩萨堕入声闻、辟支佛二地之坑；譬如慈父爱子，孩子将要掉进坑里，父亲把孩子拉住，不让孩子掉下去。

再者，菩萨因为得到陀罗尼的力量，一切魔王、魔民、魔人都不能动摇、不能破坏、不能胜过；譬如须弥山，凡人用口吹气，不能使须弥山动摇。

问：这陀罗尼有几种？

答：这陀罗尼有很多种。

一种名为闻持陀罗尼。得到这种陀罗尼的人，对一切言语与诸法，耳朵所听到的，都不忘失。这名为闻持陀罗尼。

又有分别知陀罗尼。得到这种陀罗尼的人，对诸众生、诸法的大小好坏，都能分别了知。

如偈中说：

```
诸象马金，　木石诸衣，　男女及水，
种种不同。　诸物名一，　贵贱理殊，
得此总持，　悉能分别。
```

大意：种种象、马、金、木、石、衣服、男女与水，各各不同；诸物名称虽同，贵贱之理却有差异；得到这种总持，都能一一分别。

又有入音声陀罗尼。菩萨得到这种陀罗尼，听到一切言语声音，不喜也不瞋。即使一切众生在恒河沙数的劫中以恶言辱骂，心中也不憎恨。

问：菩萨诸漏还没有断尽，怎能在恒河沙数的劫中忍受这些恶言？

答：我先前已经说了：因为得到这种陀罗尼的力量，所以能够这样。

再者，这位菩萨虽然诸漏还没有断尽，有大智慧、根性锐利，能以思惟除去瞋心。菩萨这样想：如果耳根没有接触到声音，恶声又能落在谁身上？又如骂人的声音，听到就直接过去了，如果不去分别，谁会生气？凡人心中执着吾我，分别是非，所以生起瞋恨。

再者，如果人能知道种种言语随生随灭，前后不同时存在，就不会瞋恚。也知道诸法内里没有主宰，那么是谁在骂，谁在瞋？如果有人听到异地的语言，这里认为是好话，那里却认为是恶语，好恶没有定准，即使被骂也不会瞋恚。如果人知道语言声音没有定准，就不会因此瞋或喜。如亲爱的人骂自己，虽然被骂也不恨；不亲近的人说恶言，听了就生气。如遇到风雨，就进屋撑伞；如地上有刺，就穿上靴鞋；天气大寒就烧火，天气炎热就求水；对这些祸患，只是寻求遮挡的方法，而不对风雨荆棘生气。辱骂等种种恶事，也是这样，只以慈悲止息这些恶事，不生瞋心。

再者，菩萨知道诸法不生不灭，其本性都是空。如果有人瞋恚辱骂，或者殴打，或者杀害，都如梦如化，是谁瞋，是谁骂？

再者，如果有恒河沙数劫那么多的众生，赞叹菩萨，以衣食、卧具、医药、花香、璎珞供养，得忍的菩萨心也不动，不喜也不执着。

问：已经知道菩萨种种不瞋的因缘，还不知道为什么真实赞叹菩萨的功德，菩萨也不喜？

答：菩萨知道种种供养恭敬都是无常的；现在因为有某种因缘，人们来赞叹供养；以后有了别的因缘，人们就会瞋恚，或者殴打，或者杀害，所以不喜。

再者，菩萨这样想：“因为我有功德智慧，人们才来赞叹供养；这是赞叹功德，不是赞叹我，我为什么要喜？”

再者，这些人是为了自己求果报，才对我造作因缘，供养我来作功德；譬如人种谷，灌溉修整，土地也不会因此欢喜。

再者，如果有人供养我，我如果欢喜接受，我的福德就会变薄，他人所得的福德也会减少，所以不喜。

再者，菩萨观察一切法如梦如响，是谁赞叹，是谁欢喜？我在三界中还没有得到解脱，诸漏还没有断尽，还没有得到佛道，怎能因为得到赞叹而欢喜？如果有谁应当欢喜，只有佛一人。为什么？因为佛的一切功德都已圆满。

所以，菩萨得到种种赞叹、供养、供给，心中不生欢喜。像这样等等的相，名为入音声陀罗尼。

又有名为寂灭陀罗尼、无边旋陀罗尼、随地观陀罗尼、威德陀罗尼、华严陀罗尼、音净陀罗尼、虚空藏陀罗尼、海藏陀罗尼、分别诸法地陀罗尼、明诸法义陀罗尼。

像这样，简略地说有五百陀罗尼门，如果广说就无量。所以说诸菩萨都得到陀罗尼。

所谓“诸三昧”，就是三三昧：空、无作、无相。

有人说：“观察五阴无我、无我所，这名为空；住在这空三昧中，不为后世生起三毒，这名为无作；因为缘于离开十种相，就是五尘、男、女、生、住、灭，这名为无相。”

有人说：“住在这三昧中，知道一切诸法的实相，就是毕竟空，这名为空三昧。

“知道这空之后，就是无作。怎样是无作？不观察诸法是空还是不空、是有还是无等等。如佛所说《法句》中的偈：

```
见有则恐怖，　见无亦恐怖，
是故不著有，　亦复不著无。
```

“大意：见到有，就会恐怖；见到无，也会恐怖。所以不执着有，也不执着无。

“这名为无作三昧。

“怎样是无相三昧？一切法都没有相，对一切法不领受、不执着，这名为无相三昧。如偈中说：

```
言语已息，　心行亦灭，　不生不灭，
如涅槃相。
```

“大意：言语已经止息，心行也已灭除，不生不灭，如同涅槃之相。”

再者，十八空，这名为空三昧；在种种有（丹本注：五道中的生有、本有、死有、中有、业有）中心无所求，这名为无作三昧；一切诸相都已破除，不再忆念，这名为无相三昧。

问：有种种禅定之法，为什么唯独称举这三三昧？

答：在这三三昧中思惟，接近涅槃，能使人心不高不下，平等不动，其余禅定不是这样。所以唯独称举这三三昧。

在其余禅定中，有的爱多，有的慢多，有的见多；这三三昧中有第一真实的意义与真实的利益，能得到涅槃之门。所以在诸禅定法中，以这三种空法为三解脱门。也名为三三昧，因为这三三昧是真实的三昧，其余的定也因此得以名为定。

再者，除了四根本禅之外，从未到地乃至有顶地，名为定，也名为三昧，却不名为禅；四禅名为定，也名为禅，也名为三昧；其余诸定也名为定，也名为三昧，如四无量、四空定、四辩、六通、八背舍、八胜处、九次第定、十一切处等诸定法。

又有人说：“一切三昧法有二十三种。”

有人说：“有六十五种。”

有人说：“有五百种。”

摩诃衍最大，所以有无量三昧，如遍法性庄严三昧、能照一切三世法三昧、不分别知观法性底三昧、入无底佛法三昧、如虚空无底无边照三昧、如来力行观三昧、佛无畏庄严力频申三昧、法性门旋藏三昧、一切世界无碍庄严遍月三昧、遍庄严法云光三昧，菩萨得到这样等等无量的三昧。

再者，《般若波罗蜜经·摩诃衍义品》中，简略地说有一百零八种三昧，最初名为首楞严三昧，乃至虚空不著不染三昧；广说则有无量三昧。所以说诸菩萨得到诸三昧。

所谓“行空、无相、无作”：

问：前面说菩萨得到诸三昧，为什么又说“行空、无相、无作”？

答：前面说的是三昧的名字，还没有说三昧的相；现在要说三昧的相，所以说“行空、无作、无相”。如果有人行空、无相、无作，这名为得到实相三昧。如偈中说：

```
若持戒清净，　是名实比丘。
若有能观空，　是名得三昧。
若有能精进，　是名行道人。
若有得涅槃，　是名为实乐。
```

大意：如果持戒清净，名为真实的比丘；如果能观空，名为得到三昧；如果能精进，名为修道的人；如果得到涅槃，名为真实的快乐。

所谓“已得等忍”：

问：什么是“等”？什么是“忍”？

答：等有两种：众生等，法等。

忍也有两种：众生忍，法忍。

什么是众生等？

对一切众生，平等的心、平等的念、平等的爱、平等的利益，这名为众生等。

问：因为慈悲之力，对一切众生应当平等忆念，却不应当平等看待。为什么？

菩萨行真实之道，不颠倒，如诸法之相；怎能对善人与不善人、大人与小人、人与畜生，一样平等地看待？

不善人中确实有不善之相，善人中确实有善相，大人与小人、人与畜生也是这样。如同牛相住在牛中，马相住在马中，牛相不在马中，马相不在牛中，因为马不会变成牛；众生各有各的相，怎能一样平等地看待而不落入颠倒？

答：如果善相、不善相是真实的，菩萨这样看待就会落入颠倒。为什么？因为破坏了诸法之相。然而诸法并没有真实的善相、真实的不善相，不是多相、不是少相，不是人、不是畜生，不是一、不是异。所以你的质难不成立。如说诸法之相的偈：

```
不生不灭，　不断不常，　不一不异，
不去不来；　因缘生法，　灭诸戏论，
佛能说是，　我今当礼。
```

大意：不生不灭，不断不常，不一不异，不去不来；宣说因缘所生之法，灭除一切戏论，佛能宣说这样的法，我如今应当礼敬。

再者，对一切众生，不执着种种相、众生相、空相，一样平等，没有差异；这样观察，名为众生等。

如果有人在这当中心平等无碍，直入而不退，这名为得到等忍。

得到等忍的菩萨，对一切众生不瞋不恼，如同慈母爱护孩子。如偈中说：

```
观声如呼响，　身行如镜像；
如此得观人，　云何而不忍？
```

大意：观察声音如同呼喊的回响，身体的行为如同镜中之像；能这样观察的人，怎会不能忍？

这名为众生等忍。

什么叫法等忍？善法与不善法、有漏与无漏、有为与无为等法，这样的诸法，进入不二之法门，进入真实法相之门；这样进入之后，在其中深入诸法实相时，心忍可而直入，无诤无碍，这名为法等忍。如偈中说：

```
诸法不生不灭，　非不生非不灭，
亦不生灭非不生灭，　亦非不生灭，
非非不生灭。
```

大意：诸法不生不灭；也非不生、非不灭；也不是既生灭又非不生灭；也不是不生灭；也不是“非不生灭”。

已得解脱（丹本注：从邪见中得以远离，所以说解脱），对于空与非空（丹本注：对空也不执取，所以说“非”），这些全都舍弃，灭除一切戏论，言语之道断绝，深入佛法，心通达无碍，不动不退，名为无生忍，这是助成佛道的最初之门。

【译注】这里是本论第一次正面说“无生忍”。前面的偈层层否定，生灭、不生灭、非不生灭，乃至否定之否定，一句也不留；接着丹本注点出“于空不取”，说明连“空”也一并舍弃。法等忍之所以称为“等”，是因为善恶、有漏无漏、有为无为都在不二门中平等，心于其中忍可不动；这里的“忍”字，是对实相的安住与认可，并不是勉强忍耐。

所以说“已得等忍”。

【经】

得无碍陀罗尼。

【论】

问：前面已经说诸菩萨得到陀罗尼，现在为什么又说“得无碍陀罗尼”？

答：因为无碍陀罗尼最大。如同在一切三昧中，三昧王三昧最大，如同人中之王；如同在诸解脱中，无碍解脱最大（丹本注：这是成佛得道时所得的）。同样，在一切诸陀罗尼中，无碍陀罗尼最大，所以再次说明。

再者，前面说诸菩萨得到陀罗尼，不知道是哪一种陀罗尼。有小陀罗尼，如转轮圣王、仙人等所得到的：闻持陀罗尼、分别众生陀罗尼、归命救护不舍陀罗尼；像这样等等的小陀罗尼，其余的人也有。这无碍陀罗尼，外道、声闻、辟支佛、新学菩萨都得不到；唯有具无量福德、智慧、大力的诸菩萨才独有这种陀罗尼，所以另外说明。

再者，这些菩萨自利已经具足，只想利益他人，说法教化无穷无尽，以无碍陀罗尼为根本。所以诸菩萨常行无碍陀罗尼。

【经】

悉是五通。

【论】

五通就是：如意通、天眼通、天耳通、他心智通、自识宿命通。

什么是如意通？如意有三种：能到、转变、圣如意。

能到有四种：

一是身体能飞行，如同鸟一样无碍；二是把远处移到近处，不用前往就已到达；三是在此处消失，在彼处出现；四是一念之间就能到达。

所谓转变：大的能变作小的，小的能变作大的，一个能变作多个，多个能变作一个，种种事物都能转变。外道所作的转变，最久不超过七天；诸佛与佛弟子的转变自在，没有长久短暂的限制。

所谓圣如意：对于外六尘中不可爱、不清净的事物，能观想使之清净；对于可爱、清净的事物，能观想使之不清净。这圣如意法，唯有佛独有。

这如意通，从修习四如意足而生；这如意足通等，因为缘于色，所以依次第而生，不能一时同得。

所谓天眼通：在眼中得到色界四大所造的清净色，这名为天眼。天眼所见，是自身所在之地以及下地六道中的众生与诸物，无论是近是远、是被遮覆还是微细的种种色，没有不能照见的。

天眼有两种：一是从果报得到的，二是从修行得到的。

这五通中的天眼是从修行得到的，不是从果报得到的。为什么？因为是常常忆念种种光明而得到的。

再者，有人说：“这些菩萨因为得到无生法忍的力量，不为六道所摄，只是为了教化众生，以法身显现于十方三界之中；尚未得到法身的菩萨，天眼或者从修行得到，或者从果报得到。”

问：这些菩萨的功德胜过阿罗汉、辟支佛，为什么只赞叹与凡夫共有的天眼这种小功德，不赞叹菩萨的慧眼、法眼、佛眼？

答：有三种天：一是假号天，二是生天，三是清净天。转轮圣王与其余诸大王等，名为假号天；从四天王天乃至有顶天的受生之处，名为生天；诸佛、法身菩萨、辟支佛、阿罗汉，名为清净天。这清净天从修行所得的天眼，名为天眼通。佛与法身菩萨的清净天眼，是一切离欲而得五通的凡夫所不能得到的，声闻、辟支佛也得不到。为什么？小阿罗汉稍微用心，能见一千世界；大大用心，能见二千世界。大阿罗汉稍微用心，能见二千世界；大大用心，能见三千大千世界。辟支佛也是这样。

这名为天眼通。

什么叫天耳通？在耳中得到色界四大所造的清净色，能听到一切声音：天上的声音、人间的声音、三恶道的声音。

天耳通怎样从修行得到？常常忆念种种声音，这名为天耳通。

什么叫识宿命通？常常忆念过去的事：从日、月、年、岁，追溯到在胎中，乃至过去世中的一世、十世、百世、千万亿世，乃至大阿罗汉、辟支佛能知八万大劫，诸大菩萨与佛能知无量劫。这名为识宿命通。

什么叫知他心通？知道他人的心是有垢还是无垢；因为常常观察并忆念自己的心在生、住、灭时的情形，所以得到。

再者，观察他人喜悦的相、瞋恚的相、惊怖的相、畏惧的相，见到这些相之后，再知道他人的心，这是他心智的入门。

五通简略地说完了。

【经】

言必信受。

【论】

天、人、龙、阿修罗等，以及一切大人，都信受菩萨的话，这是不说绮语的果报。

说绮语的人所得的果报是：即使说的是实话，一切人也都不信受。如偈中说：

```
有堕饿鬼中，　火炎从口出，
四向发大声，　是为口过报！
虽复多闻见，　在大众说法。
以不诚信业，　人皆不信受。
若欲广多闻，　为人所信受，
是故当至诚，　不应作绮语！
```

大意：有人堕在饿鬼中，火焰从口中喷出，向四方发出大声嚎叫，这是口业过失的果报！有的人虽然多闻多见，在大众中说法，因为不诚信的业，人们都不信受。如果想要广博多闻、为人所信受，就应当至诚，不应当说绮语！

【经】

无复懈怠。

【论】

懈怠之法，对在家人，破坏财利与福利；对出家人，破坏生天之乐与涅槃之乐。在家与出家的名声都因此灭失，最大的损失、最大的盗贼，莫过于懈怠。如偈中说：

```
懈怠没善心，　痴暗破智明，
妙愿皆为灭，　大业亦已失！
```

大意：懈怠淹没善心，愚痴的黑暗破坏智慧的光明，美妙的誓愿都因此熄灭，伟大的事业也因此丧失！

所以说“无复懈怠”。

【经】

已舍利养、名闻。

【论】

这利养之法如同盗贼，破坏功德的根本。譬如天降冰雹，伤害五谷；利养与名闻也是这样，破坏功德的幼苗，使之不能增长。如佛所说的譬喻：如同用毛绳捆人，割断皮肤，截断骨头；贪求利养的人断绝功德的根本，也是这样。如偈中说：

```
得入栴檀林，　而但取其叶；
既入七宝山，　而更取水精；
有人入佛法，　不求涅槃乐，
反求利供养，　是辈为自欺！
是故佛弟子，　欲得甘露味，
当弃舍杂毒，　勤求涅槃乐！
譬如恶雹雨，　伤害于五谷；
若著利供养，　破惭愧头陀。
今世烧善根，　后世堕地狱；
如提婆达多，　为利养自没。
```

大意：进入栴檀林，却只摘取树叶；进入七宝山，却去拿水晶；有人进入佛法，不求涅槃之乐，反而求利养供养，这些人是在自欺！所以佛弟子想要得到甘露之味，应当舍弃杂毒，勤求涅槃之乐！譬如恶劣的冰雹，伤害五谷；如果执着利养供养，就会破坏惭愧心与头陀行。今世烧毁善根，后世堕入地狱，如同提婆达多，因为利养而自己沉沦。

所以说“已舍利养、名闻”。

【经】

说法无所悕望。

【论】

菩萨以大慈怜悯，为大众说法，不是为了衣食、名声、势力而说；因为大慈悲，因为心清净，因为得到无生法忍。如偈中说：

```
多闻辩慧巧言语，　美说诸法转人心，
自不如法行不正，　譬如云雷而不雨。
博学多闻有智慧，　讷口拙言无巧便，
不能显发法宝藏，　譬如无雷而小雨。
不广学问无智慧，　不能说法无好行，
是弊法师无惭愧，　譬如小云无雷雨。
多闻广智美言语，　巧说诸法转人心，
行法心正无所畏，　如大云雷澍洪雨。
法之大将持法镜，　照明佛法智慧藏，
持诵广宣振法铃，　如海中船渡一切。
亦如蜂王集诸味，　说如佛言随佛意，
助佛明法度众生，　如是法师甚难值！
```

大意：多闻、善辩、有智慧、言语巧妙，能把诸法说得很美、转动人心，自己却不如法修行、行为不正，譬如有云有雷却不下雨。博学多闻、有智慧，却口才笨拙，没有善巧方便，不能显发法宝之藏，譬如没有雷却下小雨。既不广学，也没有智慧，不能说法，也没有好的德行，这样卑劣的法师毫无惭愧，譬如小云既无雷也无雨。多闻、广智、言语美妙，能巧说诸法、转动人心，依法修行、心地正直、无所畏惧，如同大云响雷、降下大雨。这样的人是法的大将，手持法镜，照亮佛法的智慧宝藏；受持诵读、广为宣说、摇动法铃，如同海中的船，渡化一切众生。又如蜂王采集百花之味，所说如同佛语，随顺佛意，帮助佛阐明佛法、度化众生，这样的法师非常难遇！

【经】

度甚深法忍。

【论】

什么是“甚深法”？

十二因缘，这名为甚深法。如佛告诉阿难：“这十二因缘法甚深，难解难知！”

再者，永远离开依过去世、未来世所生的六十二种邪见之网，这名为“甚深法”。如佛对比丘们说：“无闻的凡夫如果想赞叹佛，所赞叹的非常小，就是赞叹佛的戒清净，或者赞叹佛离诸欲。如果能赞叹这甚深难解难知之法，才是真正赞叹佛。”这里应当广说《梵网经》。

再者，三解脱门，这名为甚深法。如佛说般若波罗蜜时，诸天赞叹说：“世尊！这法甚深！”佛说：“所谓甚深法，空就是其义，无作、无相就是其义。”

再者，了解一切诸法之相，真实不可破、不可动，这名为“甚深法”。

再者，除去内心想象与智力的作用，只以定心安住在诸法清净的实相之中。譬如热病之气旺盛的人，看到不是黄色的东西也看成黄色；因为心中想象与智力的作用，对诸法辗转作种种观察，这名为浅法。譬如人的眼睛清净、没有热气，就如实地看到黄色是黄色；同样，除去内心想象与智力的作用，慧眼清净，就能见到诸法实相。譬如真正的水晶，黄色的东西放在旁边，水晶就随之变成黄色，青、赤、白色也都随之变色；心也是这样，凡夫因为内心想象与智力的作用，看到诸法种种不同的相。观察诸法实相，非空非不空，非有非不有；在这法中深入而不退转，没有障碍，这名为度甚深法忍。“度”的意思是得到甚深之法，具足圆满，没有障碍，得以度到彼岸，这名为度。

【译注】“内心想智力”是本段的要害：凡夫所见的种种法相，是心中的想与分别之智投射上去的，如同热病者见物皆黄，如同水晶随所近之色而变色。甚深法忍的入处，不是再添一种更高明的观法，而是把这层想与智的作用除去，让心以定安住，实相自然如实显现。

【经】

得无畏力。

【论】

诸菩萨成就了四无所畏之力。

问：菩萨所作之事还没有完成，还没有得到一切智，为什么说得到四无所畏？

答：无所畏有两种：菩萨的无所畏，佛的无所畏。这些菩萨虽然还没有得到佛的无所畏，却已得到菩萨的无所畏，所以名为“得无畏力”。

问：什么是菩萨的四无所畏？

答：第一，因为一切所闻都能受持，因为得到诸陀罗尼，因为常常忆念而不忘，所以在大众中说法无所畏惧。

第二，因为知道一切众生想要解脱的因缘、诸根的利钝，随其所应而为之说法，所以菩萨在大众中说法无所畏惧。

第三，不见东方、南方、西方、北方、四维、上下，有人来质难，使我不能如法回答；连少许这样的相都不见，所以在大众中说法无所畏惧。

第四，一切众生听受、质难，菩萨都能随意如法回答，能巧妙地断除一切众生的疑惑，所以菩萨在大众中说法无所畏惧。

【经】

过诸魔事。

【论】

魔有四种：一是烦恼魔，二是阴魔，三是死魔，四是他化自在天子魔。

这些菩萨因为得到菩萨道，所以破除烦恼魔；因为得到法身，所以破除阴魔；因为得道、得到法性身，所以破除死魔；因为常常一心，在一切处心不执着，进入不动三昧，所以破除他化自在天子魔。所以说“过诸魔事”。

再者，在这部《般若波罗蜜经·觉魔品》中，佛亲自说了魔业与魔事。这些魔业、魔事都已超过，所以名为“已过魔事”。

再者，除了诸法实相之外，其余的一切法都名为魔。如种种烦恼、结、使，欲、缚、取、缠；阴、界、入；魔王、魔民、魔人，像这样等等全都名为魔。

问：哪里说欲、缚等种种结使名为魔？

答：《杂法藏经》中，佛以偈对魔王说：

```
欲是汝初军，　忧愁军第二，
饥渴军第三，　爱军为第四、
第五眠睡军，　怖畏军第六，
疑为第七军，　含毒军第八，
第九军利养、　著虚妄名闻，
第十军自高、　轻慢于他人。
汝军等如是，　一切世间人，
及诸一切天，　无能破之者。
我以智慧箭，　修定智慧力，
摧破汝魔军，　如坏瓶没水。
一心修智慧，　以度于一切；
我弟子精进，　常念修智慧，
随顺如法行，　必得至涅槃。
汝虽不欲放，　到汝不到处！
是时魔王闻，　愁忧即灭去；
是魔恶部党，　亦覆没不现！
```

大意：佛对魔王说：欲是你的第一军，忧愁是第二军，饥渴是第三军，爱是第四军，睡眠是第五军，怖畏是第六军，疑是第七军，含藏毒害是第八军，利养与执着虚妄名闻是第九军，自高自大、轻慢他人是第十军。你的军队就是这样，一切世间人与一切诸天，没有能破除你的军队的。我以智慧之箭，以修定与智慧之力，摧破你的魔军，如同毁坏的瓶子沉入水中。我一心修习智慧，以此度化一切众生；我的弟子精进，常念修习智慧，随顺如法而行，必定能到达涅槃。你虽然不想放过他们，他们终会到达你到不了的地方！这时魔王听了，忧愁地随即消失；魔的恶党也都覆没不见！

这名为诸结使魔。

问：五众、十八界、十二入，在哪里说是魔？

答：在莫拘罗山中，佛教导弟子罗陀：色众是魔，受、想、行、识也是这样。

再者，如果想造作未来世的色身，这是动处；如果想造作无色之身，这也是动处；如果想造作有想、无想、非有想非无想之身，这是一切动处。动是魔的系缚，不动就不被系缚，就能从恶中得到解脱。这里说众、界、入是魔；至于自在天子魔、魔民、魔人，本来就是魔，不必再说。

问：为什么名为魔？

答：因为夺取慧命，破坏道法功德的善本，所以名为魔。诸外道称魔为欲主，也称为花箭，也称为五箭（丹本注：就是五欲之箭），因为魔破坏种种善事。在佛法中名为魔罗，魔的业、魔的事，名为魔事。是什么样的魔事？如〈觉魔品〉中所说。

再者，人在世间辗转承受苦乐，是结使的因缘，也是魔王之力的因缘。这魔名为诸佛的怨仇、一切圣人的盗贼，破坏一切逆生死之流而上的人所作的事，不喜欢涅槃，这名为魔。

这魔有三类事：

嬉笑言语、歌舞、邪视，像这样等等从爱而生；捆绑殴打、鞭笞拷打、刺割砍截，像这样等等从瞋而生；烤炙身体、自己受冻、拔除头发、自己挨饿、投入火中、跳入深渊、跳下山崖，像这样等等从愚痴而生。

有大过失、不清净、染着世间，都是魔事。憎恶利益，不用涅槃以及涅槃之道，也是魔事。沉没在大苦海中，自己却不觉知。像这样无量无边，都是魔事。

这些都已舍弃，这就是“过诸魔事”。

【经】

一切业障悉得解脱。

【论】

从一切恶业中得到解脱，这名为“业障得解脱”。

问：障有三种：烦恼障、业障、报障；为什么舍弃两种障，只说业障？

答：因为三障中业力最大。积集的诸业，乃至百千万劫中，不失、不烧、不坏，到给予果报时也不会消亡。

这些业能长久存在，因缘和合时就给予果报；如同谷物草木的种子在地中，得到适当的时节就会生长，不失不坏。

诸佛具一切智，第一尊重，如同须弥山王，尚且不能转变这些业，何况凡人！如偈中说：

```
生死轮载人，　诸烦恼结使，
大力自在转，　无人能禁止。
先世业自作，　转为种种形，
业力最为大，　世间中无比！
先世业自在，　将人受果报，
业力故轮转，　生死海中回。
大海水干竭，　须弥山地尽，
先世因缘业，　不烧亦不尽。
诸业久和集，　造者自逐去，
譬如责物主，　追逐人不置。
是诸业果报，　无有能转者，
亦无逃避处，　非求哀可免。
三界中众生，　追之不暂离，
如珂梨罗刹，　是业佛所说。
如风不入实，　水流不仰行，
虚空不受害，　无业亦如是。
诸业无量力，　不逐非造者；
果报时节来，　不亡亦不失。
从地飞上天，　从天入雪山，
从雪山入海，　一切处不离。
常恒随逐我，　无一时相舍，
直至无失时，　如星流趣月。
```

大意：生死之轮载着人，种种烦恼结使以大力自在地转动，无人能够禁止。前世自己造的业，使人转生为种种形体；业力最大，世间无可比拟！前世的业自在地牵引人去承受果报，因为业力，人在生死大海中轮转往复。即使大海干涸、须弥山与大地都毁尽，前世因缘所造的业，也不会被烧毁，不会穷尽。诸业长久积集，紧追造业的人而去，譬如债主追讨债务，追着人不放。这些业的果报，没有谁能转变，也没有逃避之处，不是哀求就能免除。三界中的众生，业追着不暂离，如同珂梨罗刹一般，这是佛所说的业。如同风吹不进实心的物体，水流不会倒流向上，虚空不会受到伤害，没有业的人也是这样，业奈何不了。诸业有无量之力，却不追逐不是造业的人；果报的时节到来，不会消亡，也不会丢失。即使从地上飞到天上，从天上进入雪山，从雪山进入大海，在一切处业都不离开。业常恒追随着我，没有一时相舍，直到果报受尽才止息，如同流星奔向月亮。

所以说“一切诸业障悉得解脱”。

【经】

巧说因缘法。

【论】

十二因缘所生之法，以种种法门能巧妙宣说烦恼、业、事，诸法依次辗转相续而生，这名为十二因缘。其中，无明、爱、取三支，名为烦恼；行、有二支，名为业；其余七支，名为体事。

这十二因缘中，最初两支属于过去世，最后两支属于未来世，中间八支属于现在世。

简略地说，就是三件事：烦恼、业、苦。这三件事辗转相互为因缘：烦恼是业的因缘，业是苦的因缘，苦是苦的因缘，苦是烦恼的因缘，烦恼是业的因缘，业是苦的因缘，苦是苦的因缘，这名为辗转相互为因缘。

过去世的一切烦恼，名为“无明”。

从无明生起业，能造作世界之果，所以名为“行”。

从行生起染垢之心，是最初受身之因，如同牛犊认识母牛，因为自然相识，所以名为“识”。

这识共同生起无色的四阴，以及识所依住的色，这名为“名色”。

在这名色中生起眼等六情，这名为“六入”。

根、尘、识和合，这名为“触”。

从触生起“受”。

在受中心生执着，这名为“渴爱”。

因为渴爱的因缘而追求，这名为“取”。

从取造作后世因缘的业，这名为“有”。

从有再承受后世的五众，这名为“生”。

从生之后五众成熟而坏灭，这名为“老死”。

老死生起忧、悲、哭泣，种种愁恼，众苦和合聚集。

如果一心观察诸法实相清净，无明就灭尽；无明灭尽，所以行灭尽；乃至众苦和合聚集全都灭尽。

这十二因缘之相，能这样以方便不执着邪见，为人演说，这名为“巧”。

再者，在这十二因缘观中，断除对法的爱，心不执着，知道实相，这名为“巧”。如《般若波罗蜜经·不可尽品》中，佛告诉须菩提：“痴如同虚空，不可尽；行如同虚空，不可尽；乃至众苦和合聚集如同虚空，不可尽。菩萨应当这样了知！这样了知的人，是为了舍离痴的边际，应当无所入。这样观察十二因缘生起的人，就是坐于道场，得萨婆若（一切智）。”

【经】

从阿僧祇劫已来，发大誓愿。

【论】

“阿僧祇”的意义，在〈菩萨义品〉中已经说过。

“劫”的意义，佛以譬喻说：“有一座四千里的石山，有一位长寿的人每过一百年，拿细软的衣服来拂拭一次，直到这座大石山被拂拭尽了，劫还没有尽。有一座四千里的大城，城中装满芥子，不刮平，堆得冒尖；有一位长寿的人每过一百年来取走一粒芥子，芥子都取尽了，劫还没有尽。”

菩萨就在这样无数的劫中，发大正愿，度脱众生。

“愿”的意思是大心的要誓：必定度化一切众生，断除种种结使，成就阿耨多罗三藐三菩提，这名为“愿”。

【经】

颜色和悦，常先问讯，所语不粗。

【论】

因为瞋恚的根本已经拔除，因为嫉妒已经除去，因为常修大慈、大悲、大喜，因为四种邪语已经断除，所以颜色和悦。

如偈中说：

```
若见乞道人，　能以四种待：
初见好眼视，　迎逆敬问讯，
床座好供养，　充满施所欲；
布施心如是，　佛道如在掌。
若能除四种，　口过妄语毒，
两舌、恶、绮语，　得大美果报。
善软人求道，　欲度诸众生，
除四邪口业，　譬如马有辔！
```

大意：如果见到乞讨的修道人，能以四种方式对待：初见时以善意的眼光看他，上前迎接并恭敬问讯，以床座好好供养，满足他所想要的布施。布施之心能这样，佛道就如同在掌中。如果能除去四种口业的过失，就是妄语之毒、两舌、恶口、绮语，就能得到大而美好的果报。善良柔和的人求道，想度化众生，除去四种邪恶的口业，就像马有了缰绳！

【经】

于大众中得无所畏。

【论】

因为有大德，因为有坚实的功德与智慧，因为得到最上的辩才陀罗尼，所以在大众中得无所畏。

如偈中说：

```
内心智德薄，　外善以美言；
譬如竹无内，　但示有其外。
内心智德厚，　外善以法言；
譬如妙金刚，　中外力具足。
```

大意：内心的智慧与德行浅薄，外表却善于用美言修饰，譬如竹子内里是空的，只是显示出外表。内心的智慧与德行深厚，外表善于用如法的言语，譬如美妙的金刚，内外的力量都具足。

再者，因为成就了无畏之法，端正、贵族、大力、持戒、禅定、智慧、言语论议等都已成就，所以无所畏惧。因此，在大众中无所畏惧。

如偈中说：

```
少德无智慧，　不应处高座，
如豺见师子，　窜伏不敢出。
大智无所畏，　应处师子座，
譬如师子吼，　众兽皆怖畏！
```

大意：德行少、没有智慧的人，不应当坐上高座，就像豺狼见到狮子，逃窜躲藏，不敢出来。有大智慧、无所畏惧的人，才应当坐上狮子座，譬如狮子吼叫，众兽都恐惧！

因为积集了无量无边的智慧与福德之力，所以无所畏惧。

如偈中说：

```
若人灭众恶，　乃至无小罪，
如是大德人，　无愿而不满。
是人大智慧，　世界中无恼，
是故如此人，　生死涅槃一。
```

大意：如果人灭除一切恶，乃至连小罪也没有，这样的大德之人，没有什么愿望不能满足。这个人有大智慧，在世间中没有烦恼，所以这样的人，看待生死与涅槃是一样的。

再者，因为唯独得到菩萨的无所畏，如《毗那婆那王经》中所说。菩萨唯独得到四无所畏，如先前所说。

【经】

无数亿劫说法巧出。

【论】

不放逸等种种善根，菩萨自身好好修习。这些菩萨，不是一世、二世、三世、四世，乃至无量阿僧祇劫中积集功德与智慧。如偈中说：

```
为众生故发大心，　若有不敬生慢者，
其罪甚大不可说，　何况而复加恶心！
```

大意：为了众生而发大心的人，如果有人对这样的人不恭敬、生起傲慢，罪过非常大，无法言说，何况再加上恶心！

再者，这些菩萨在无数无量的劫中，修身、修戒、修心、修慧；在生灭、缚解、逆顺之中，自己了了分明地知道诸法实相。

有三种理解：听闻的理解、义理的理解、证得的理解。在种种说法的法门中，没有障碍，都得到说法的方便与智慧波罗蜜。这些菩萨所说的，如同圣人所说，都应当信受。如偈中说：

```
有慧无多闻，　是不知实相；
譬如大暗中，　有目无所见。
多闻无智慧，　亦不知实义；
譬如大明中，　有灯而无目。
多闻利智慧，　是所说应受。
无慧亦无闻，　是名人身牛。
```

大意：有智慧而不多闻，不能知道实相，譬如在大黑暗中，有眼睛却什么也看不见。多闻而没有智慧，也不能知道真实的义理，譬如在大光明中，有灯却没有眼睛。既多闻又有锐利的智慧，这样的人所说的应当信受。既没有智慧，也不多闻，这名为长着人身的牛。

问：应当说“无数亿劫巧说法”，为什么又说“出”？

答：在无智的人中与弟子中说法容易；在多闻、智慧锐利、善于论议的人中说法难。

如果是小智慧的法师，在这样的场合就会退缩；如果是大学多闻的人，在质难之中胆大而欣喜，在一切大众中有大威德。如《天会经》中的偈说：

```
面目齿光明，　普照于大会；
映夺诸天光，　种种皆不现。
```

大意：面目与牙齿放出光明，普照整个大会；映夺诸天的光芒，使诸天种种光芒都显现不出来。

所以名为“在无数亿劫巧说法中能够超出”。

## 本卷要义

摩诃萨埵的“大”，本卷从数目上一路推到数目之外。众生如大海，十方虚空合为一水，以发取滴，水尽而众生不尽；沤舍那列出上百个数名，从一人、十人一直数到“不可说不可说”，每一个都说“非为此故发心”；然后再一层层推到国土微尘、三千大千世界微尘、供养诸佛、清净佛土、护持法轮、断尽众生烦恼。数目越推越大，结论却是同一句：菩萨不是为任何一个可以数尽的数目发心。大心之所以大，在于没有边界可以给它划定；这正呼应了卷一的“如般若波罗蜜无量无边”。

菩萨功德一品里，陀罗尼、三昧、等忍三者构成一条由外而内的路。陀罗尼是“能持、能遮”，持善不散，遮恶不生；入音声陀罗尼一段说得最细：被骂不瞋，被赞也不喜，因为声随生随灭、前后不俱，因为赞叹的是功德不是我，因为一切法如梦如响。三三昧给出了这条路的心要：空是不得我与我所，无作是不观诸法若空若不空，无相是一切法不受不著；连“空”也不作为可求之物。到等忍，龙树面对了一个尖锐的问题：善人恶人、人与畜生明明不同，平等看待岂不颠倒？回答是，如果善相、不善相真实，平等看待才是颠倒；正因为诸法没有实在的善相、恶相，平等看待才是如实。众生等与法等，就是把空三昧落实到对待众生与对待诸法上；心于此直入不退，名为无生忍，“是助佛道初门”。

“度甚深法忍”一段，是本卷最透的地方。龙树把甚深法从十二因缘、离六十二见、三解脱门一路推到一个具体的心理机制：“内心想智力”。凡夫所见的诸法差别，如热病者见物皆黄，如水晶随邻近之色而变色；不是诸法本来如此，是心的想与分别投射上去的。除去这层作用，定心住于实相中，慧眼清净，诸法“非空非不空，不有非不有”自然显现。这把前面三三昧的抽象表述，落在了每个人都能对照的经验上。

后半段的五通、无畏、过魔、业障、因缘，看似一串零散的赞辞，其中有两处值得停下来。一是“除诸法实相，余残一切法尽名为魔”：魔不只是他化自在天子，连五众、界、入，连想要造作未来色身、无色身的动念，都是魔缚，“动是魔缚，不动则不缚”。二是业障的偈颂把业力说得极重，“诸佛一切智，尚不能转是诸业”，紧接着却是“巧说因缘法”：一心观诸法实相清净，无明尽则众苦尽，痴如虚空不可尽，作此观者即坐道场。业是实受的，因缘却是可以看穿的；看穿业的不是另一种力量，而是对十二因缘如虚空的了知。
