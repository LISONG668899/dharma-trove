# 龙树《大智度论》卷第二

龙树菩萨造　后秦龟兹国三藏法师鸠摩罗什奉诏译

## 初品总说“如是我闻”释论第三

“如是我闻：一时”，现在来总说。

问：诸佛是一切智人，自然无师，不随他人教导，不领受他人之法，不用他人之道，不是从他人那里听来再说法，为什么经中说“如是我闻”？

答：正如你所说，佛是一切智人，自然无师，不应当是从他人听闻佛法再去宣说。

然而佛法不只是佛亲口所说的才是。一切世间真实的善语、微妙的好语，都出自佛法之中。

如佛在律中说：“什么是佛法？佛法由五种人宣说：一是佛亲口所说，二是佛弟子所说，三是仙人所说，四是诸天所说，五是化人所说。”

再者，如《释提桓因得道经》中，佛告诉憍尸迦：“世间真实的善语、微妙的好语，都出自我的法中。”

如赞佛的偈中说：

```
诸世善语，　皆出佛法，　善说无失，
无过佛语。　余处虽有，　善无过语，
一切皆是，　佛法之余。　诸外道中，
设有好语，　如虫食木，　偶得成字。
初中下法，　自共相破，　如铁出金，
谁当信者？　如伊兰中，　牛头栴檀；
如苦种中，　甘善美果。　设能信者，
是人则信，　外经书中，　自出好语。
诸好实语，　皆从佛出，　如栴檀香，
出摩梨山，　除摩梨山，　无出栴檀。
如是除佛，　无出实语。
```

大意：世间一切善语，都出自佛法；说得善妙而没有过失的，没有超过佛语的。别处即使也有善妙无过的话，全都是佛法的余绪。外道之中即使偶有好话，也像虫子蛀木头，偶然蛀成了字。外道之法，开头、中间、结尾自相矛盾，互相破坏，好比说铁里能炼出金子，谁会相信？好比说臭秽的伊兰林中长出牛头栴檀，苦种子里结出甘美的果实。如果有人能信这些，这人才会相信外道经书里能自己生出好话。一切好的真实之语，都从佛出；如同栴檀香出自摩梨山，除了摩梨山，别处不出栴檀。同样，除了佛，别处不出真实之语。

再者，“如是我闻”，是阿难等佛的大弟子们所说，因为契入佛法之相，所以称为佛法。

佛将要般涅槃时，在拘夷那竭国的娑罗双树之间，头向北方卧下，即将入于涅槃。那时，阿难对亲属的爱还没有除去，因为还没有离欲，心沉没在忧愁的大海里，不能自拔。那时，长老阿泥卢豆对阿难说：“你是守护佛法宝藏的人，不应当像凡人那样自己沉没在忧愁的大海里！一切有为法都是无常之相，你不要忧愁！再说，佛亲手把法托付给你，你现在愁闷，就会耽误所受托的大事。你应当问佛：佛般涅槃之后，我们怎样修道？谁来作老师？恶口的车匿，怎样与他共住？佛经的开头应当说什么话？像这样种种未来的事，都应当问佛。”

阿难听了这些话，闷乱的心稍稍清醒，得到正念与道力的帮助，在佛最后所卧的床边，以这些事请问佛。

佛告诉阿难：“无论是现在，还是我去世之后，都要依止自己，依止法，不依止其他。比丘怎样依止自己、依止法、不依止其他？比丘观察自身，常当一心运用智慧，勤修精进，除去对世间的贪爱与忧恼；观察他身、观察内外身，也是这样；受念处、心念处、法念处，也同样如此。这就叫比丘依止自己、依止法、不依止其他。从今天起，解脱戒经就是你们的大师；依照解脱戒经所说的身业、口业，应当如此奉行。车匿比丘，在我涅槃之后，要按梵法对待他，也就是大众都不与他说话；如果他的心柔软调伏了，应当教他《删陀迦旃延经》，他就可以得道。再者，我在三阿僧祇劫中所积集的法宝之藏，这宝藏的开头应当这样说：‘如是我闻：一时，佛在某方某国土、某处树林中。’为什么？过去诸佛的经，开头都称这句话；未来诸佛的经，开头也都称这句话；现在诸佛最后般涅槃时，也都教弟子称这句话。如今我般涅槃之后，经的开头也应当称‘如是我闻：一时’。”

所以应当知道，“如是我闻”是佛所教，不是佛自己说“如是我闻”。佛是一切智人，自然无师，所以不应当说“我闻”。如果是佛自己说“如是我闻”，那就意味着佛有所不知，才可以有这个质难。现在是阿难问佛，佛教了这句话，“如是我闻”是弟子所说，没有过失。

再者，为了让佛法长久住世，长老摩诃迦叶等诸阿罗汉问阿难：“佛最初在什么地方说法？说的是什么法？”阿难回答：“如是我闻：一时，佛在波罗奈国仙人鹿林中，为五比丘宣说苦圣谛。佛说：‘我本来不是从他人那里听闻，而是在法中正确忆念，生起了眼、智、明、觉。’”这部经，这里应当广说。

如《集法经》中广说：佛入涅槃时，大地六种震动，诸河倒流，狂风暴起，黑云四合，恶雷闪电，冰雹骤雨猛然落下，处处流星飞坠；狮子与猛兽咆哮嚎叫；诸天与世人都放声痛哭。诸天与人都说：“佛取涅槃，怎么这样快！世间的眼睛灭了！”就在这时，一切草木、药树、花叶同时破裂；诸须弥山王全都倾斜摇动，海水波涛翻涌，大地剧烈震动，山崖崩落；树木摧折，四面起烟，非常可怕。池塘江河全都浑浊翻腾；彗星在白天出现。人们啼哭，诸天忧愁，诸天女们郁闷哽咽，涕泪交流。诸有学圣者默然不乐；诸无学圣者忆念有为诸法一切无常。像这样，天、人、夜叉、罗刹、乾闼婆、甄陀罗、摩睺罗伽以及诸龙等，都极大忧愁。

诸阿罗汉已经度过老病死的大海，心里想：

```
已渡凡夫恩爱河，　老病死券已裂破；
见身箧中四大蛇，　今入无余灭涅槃！
```

大意：我已渡过凡夫的恩爱之河，老病死的债券已经撕破；看清身体这个箱子里装着四大毒蛇，如今要入无余涅槃了！

诸大阿罗汉各自随意，在山林、流泉、溪谷之中，处处舍身而般涅槃；还有些阿罗汉在虚空中飞腾而去，如同雁王一般，显现种种神力，使众人的心生起清净信心，然后般涅槃。六欲天乃至遍净天等诸天，看见诸阿罗汉都取灭度，各自心想：“佛日已经落下，具足种种禅定、解脱、智慧的弟子们，光明也随之熄灭了。这些众生有种种淫欲、瞋怒、愚痴之病，能施法药的医师们如今迅速灭度，谁来医治？从无量智慧大海中生出的弟子莲花，如今已经干枯；法树摧折，法云散灭；大智象王已经逝去，小象也随之而去；法的商人已经离开，向谁去求法宝？”如偈中说：

```
佛已永寂入涅槃，　诸灭结众亦过去；
世界如是空无智，　痴冥遂增智灯灭！
```

大意：佛已永远寂灭，入于涅槃，断尽结使的圣众也已逝去；世界就这样空无智慧，愚痴的黑暗日益增长，智慧之灯熄灭了！

那时，诸天礼摩诃迦叶的双足，说偈：

```
耆年欲恚慢已除，　其形譬如紫金柱，
上下端严妙无比，　目明清净如莲华！
```

大意：长老已经除尽贪欲、瞋恚与我慢，身形好比紫金柱，上下端严，微妙无比，双目明亮清净，如同莲花！

诸天这样赞叹之后，对大迦叶说：“大德迦叶！您知道吗？法船将要破了，法城将要倒了，法海将要干了，法幢将要倒了，法灯将要灭了；说法的人将要离去，修道的人渐渐稀少，恶人的势力日益强盛。您应当以大慈心建立佛法！”

那时，大迦叶的心如同大海，澄静不动，过了很久才回答：“你们说得好！确实如你们所说，世间不久就会无智而盲暗。”于是大迦叶默然接受了诸天的劝请。那时，诸天礼大迦叶的双足，忽然不见，各自返回。

这时，大迦叶思惟：“我现在怎样才能让这三阿僧祇劫才得到的难得佛法长久住世？”这样思惟完毕，心想：“我知道怎样能使佛法长久住世：应当结集修多罗、阿毗昙、毗尼，作为三法藏。这样，佛法就可以长久住世，未来世的人可以领受奉行。为什么要这样做？佛世世勤苦，慈悯众生，学得这法，为人演说；我们也应当承接佛的教化，宣扬开导。”

这时，大迦叶说完这番话，站在须弥山顶，敲击铜犍椎，说偈：

```
佛诸弟子！　若念于佛，　当报佛恩，
莫入涅槃！
```

大意：佛的诸位弟子！如果忆念佛，就应当报答佛恩，不要入涅槃！

犍椎的声音与大迦叶的话声，遍及三千大千世界，全都听闻知晓；凡是得到神通力的弟子，都来集会到大迦叶的处所。那时，大迦叶告诉与会大众：“佛法将要灭了。佛从三阿僧祇劫以来，种种勤苦，慈悯众生，学得此法。佛般涅槃之后，诸弟子中知法、持法、诵法的人，也都随佛灭度；佛法如今将要灭了，未来的众生非常可怜，失去智慧之眼，愚痴盲暗。佛以大慈悲怜悯众生，我们应当承接佛的教化，等结集经藏完毕，再随意灭度。”

前来集会的大众，都接受教诲而留住。那时，大迦叶选出一千人，除了善人阿难之外，全都是阿罗汉，得六神通，得共解脱、无碍解脱；全都得三明，禅定自在，能逆行、顺行诸三昧，全都无碍。这些阿罗汉诵读三藏，通晓内外经书，外道各家的十八种大经，也全都读过、通晓；都能论议，降伏异学。

问：当时有这样无数的阿罗汉，为什么正好只选一千人，不多选一些？

答：频婆娑罗王得道时，八万四千官员属下也都得道。当时，频婆娑罗王敕令宫中，常设饭食，供养一千人；阿阇世王继承了这个做法，没有中断。那时，大迦叶思惟：“如果我们常常出外乞食，就会有外道强行前来质难，荒废了结集法藏的大事；如今王舍城常设饭食，供给一千人，可以在这里住下结集经藏。”因此只选一千人，不能多选。

这时，大迦叶与一千人一起，来到王舍城耆阇崛山中，告诉阿阇世王：“请供给我们饮食，每天送来。我们现在要结集经藏，不能到别处去。”

在这里结夏安居三个月。初十五日说戒的时候，召集和合僧众。大迦叶入禅定，以天眼观察：现在这大众之中，谁的烦恼还没有断尽，应当被逐出？只有阿难一人烦恼未尽，其余九百九十九人，诸漏已尽，清净无垢。大迦叶从禅定中出来，在大众中亲手牵着阿难出去，说：“现在要在清净的大众中结集经藏。你的结使还没有断尽，不应当留在这里！”

这时，阿难惭愧羞耻，悲伤哭泣，自己心想：“我二十五年随侍世尊，在世尊左右供给服侍，从来没有遭受过这样的苦恼。佛实在是大德，慈悲宽忍。”想完，阿难对大迦叶说：“我有能力，早就可以得道。只是依诸佛之法，阿罗汉不能在佛左右供给使唤；所以我留着残余的结使，没有全部断尽。”

大迦叶说：“你还有罪！佛的本意不想允许女人出家，你殷勤劝请，佛才允许女人入道；因此佛的正法过了五百年就衰微了。这是你的突吉罗罪！”阿难说：“我怜悯瞿昙弥；而且三世诸佛之法都有四部众，我的释迦文佛怎能唯独没有？”

大迦叶又说：“佛将要涅槃时，在拘夷那竭城附近，背痛，把郁多罗僧衣叠成四层铺着卧下，对你说：‘我要水。’你没有供给。这是你的突吉罗罪！”阿难回答：“那时有五百辆车截流渡河，把水搅浑了，所以我没有去取。”大迦叶又说：“即使水浑浊，佛有大神力，能使大海的浊水变得清净。你为什么不给？这是你的罪，你去作突吉罗忏悔！”

大迦叶又说：“佛问你：如果有人善修四神足，可以住寿一劫，或者不到一劫；佛善修四神足，若想住寿一劫，或者不到一劫，都可以。你默然不回答。佛问你到第三次，你还是默然。你如果回答佛：佛善修四神足，应当住世一劫，或者不到一劫。正是因为你，才使佛世尊早入涅槃。这是你的突吉罗罪！”阿难说：“是魔遮蔽了我的心，所以没有说话；我不是以恶心而不回答佛。”

大迦叶又说：“你为佛叠僧伽梨衣时，用脚踩在衣上。这是你的突吉罗罪。”阿难说：“那时刮起大风，没有人帮我拿住衣服，风把衣服吹来，落在我脚下，并不是我不恭敬，故意踩佛的衣服。”

大迦叶又说：“佛的阴藏相，在佛般涅槃之后，你拿来给女人看，这是多么可耻的事！这是你的突吉罗罪！”阿难说：“那时我想：‘如果女人们看见佛的阴藏相，就会对自己的女人身形感到羞耻，想要得到男子之身，修行佛的相好，种下福德之根。’所以我让女人看，并不是无耻而故意破戒。”

大迦叶说：“你有六种突吉罗罪，都应当在僧众中悔过！”阿难说：“是！随长老大迦叶与僧众的教导！”这时，阿难长跪合掌，偏袒右肩，脱下革屣，忏悔六种突吉罗罪。大迦叶在僧众中亲手牵着阿难出去，对阿难说：“断尽你的诸漏，然后再进来；残余的结使没有断尽，你不要来！”说完这话，就自己关上了门。

那时，诸阿罗汉商议说：“谁能结集毗尼法藏？”长老阿泥卢豆说：“舍利弗是第二佛，有一位好弟子，名叫憍梵波提（汉语意为牛呞，牛反刍），性情柔软和雅，常住在闲静之处，心住寂静安稳，能通晓毗尼法藏；现在住在天上尸利沙树园中，可以派人去请来。”

大迦叶对下座比丘说：“按次序，你应当担任僧众的使者。”下座比丘问：“僧众有什么差使？”大迦叶说：“僧众派你到天上尸利沙树园中，憍梵波提阿罗汉的住处。”这位比丘欢喜踊跃，接受了僧众的命令，问大迦叶：“我到憍梵波提阿罗汉那里，要陈说什么事？”大迦叶说：“到了之后，告诉憍梵钵提：大迦叶等漏尽阿罗汉，都已在阎浮提集会，僧众有重大法事，你赶快来！”

这位下座比丘头面礼拜僧众，右绕三圈，如同金翅鸟一般飞腾虚空，到了憍梵波提的住处，头面作礼，对憍梵波提说：“柔善的大德！少欲知足，常在禅定！大迦叶问候您，并有话转告：现在僧众有重大法事，请赶快下来，观看众宝的聚会。”这时，憍梵波提心中有所觉察，生起疑惑，对这位比丘说：“僧众该不会是有争斗之事，叫我去吧？没有人破坏僧团吧？佛日灭度了吗？”这位比丘说：“确实如您所说，大师佛已经灭度了。”憍梵波提说：“佛灭度得太快了，世间的眼睛灭了！能追随佛转法轮的大将，我的和上舍利弗，现在在哪里？”比丘回答：“先已入涅槃了。”憍梵波提说：“大师与法将各自离去，还能怎么办！摩诃目犍连现在在哪里？”这位比丘说：“也已经灭度了。”憍梵波提说：“佛法将要离散，大人已经逝去，众生真可怜。”又问：“长老阿难现在在做什么？”这位比丘说：“长老阿难在佛灭度之后，忧愁、啼哭、迷闷，不能自我宽解。”憍梵波提说：“阿难懊恼，是因为有爱结，与所爱别离就生苦。罗睺罗又怎样？”比丘回答：“罗睺罗已经证得阿罗汉，所以无忧无愁，只是观察诸法的无常之相。”憍梵波提说：“难断的爱已经断了，所以没有忧愁。”憍梵波提又说：“我失去了离欲的大师，还住在这尸利沙树园中做什么？我的和上与大师都已灭度，我现在不能再下到阎浮提，就在这里般涅槃。”

说完这话，憍梵波提进入禅定，踊身虚空，身放光明，又出水出火，手摸日月，显现种种神变；从心中出火焚烧自身，身中流出四道水，流下来，一直流到大迦叶的处所。水中有声音，说偈：

```
憍梵钵提稽首礼，　妙众第一大德僧，
闻佛灭度我随去，　如大象去象子随！
```

大意：憍梵钵提稽首礼拜微妙众中第一的大德僧众；听闻佛已灭度，我也随佛而去，如同大象离去，小象随行！

那时，下座比丘带着憍梵波提的衣钵回到僧众之中。

在这期间，阿难思惟诸法，寻求断尽残余的漏。阿难那一夜坐禅、经行，殷勤求道。阿难智慧多，定力少，所以没有立即得道；定与智均等的人，才能迅速得道。后夜将尽时，阿难疲倦至极，想要躺下休息，退身卧向枕头，头还没有碰到枕头，豁然开悟，如同闪电一现，暗中的人看见了道路。阿难就这样进入金刚定，摧破一切烦恼之山，得三明、六神通、共解脱，成为具大力的阿罗汉。

原文：头未至枕，廓然得悟。（头还没有碰到枕头，豁然开悟。）

【译注】阿难通宵用功而不得入，论中先已点明原因：“智慧多，定力少”，又说“定智等者，乃可速得”。阿难疲极放身、头未至枕的一刹豁然得悟，正落在这两句话上。

阿难当夜就来到僧堂门前，敲门呼喊。大迦叶问：“敲门的是谁？”阿难回答：“我是阿难。”大迦叶说：“你为什么来？”阿难说：“我今夜已经断尽诸漏。”大迦叶说：“不给你开门，你从门的钥匙孔中进来！”阿难回答：“可以！”随即以神力从门的钥匙孔中进入，礼拜僧众的双足，忏悔说：“大迦叶不要再责备我了！”

大迦叶用手抚摸阿难的头，说：“我是特意为了你，好让你得道；你心中没有嫌恨，我也同样没有，你自己就可以证知这一点。譬如用手在虚空中画，什么也沾染不上；阿罗汉的心也是这样，在一切法中得无所着。回到你本来的座位上吧。”

这时，僧众又商议说：“憍梵波提已经取灭度了，还有谁能结集法藏？”长老阿泥卢豆说：“这位长老阿难，在佛弟子中常常侍奉在佛身边，听闻经典能够受持，佛常常赞叹称誉；这位阿难能结集经藏。”这时，长老大迦叶抚摸阿难的头说：“佛嘱托你，让你受持法藏，你应当报答佛恩！佛在什么地方最初说法？佛的诸大弟子中能守护法藏的人，都已灭度，只剩你一人还在。你现在应当随顺佛心，为了怜悯众生，结集佛的法藏。”这时，阿难礼拜僧众之后，坐上狮子座。当时大迦叶说偈：

```
佛圣师子王，　阿难是佛子，
师子座处坐，　观众无有佛。
如是大德众，　无佛失威神，
如空无月时，　有宿而不严。
汝大智人说，　汝佛子当演，
何处佛初说，　今汝当布现！
```

大意：佛是圣者中的狮子王，阿难是佛子，坐在狮子座上，环视大众，却没有了佛。这样的大德众，没有了佛，就失去了威神，如同夜空没有月亮时，虽有星宿，却不庄严。你这大智之人，你这佛子，应当宣说演述：佛最初在何处说法，现在你应当一一展现出来！

这时，长老阿难一心合掌，面向佛涅槃的方向，这样说：

```
佛初说法时，　尔时我不见，
如是展转闻：　佛在波罗柰，
佛为五比丘，　初开甘露门，
说四真谛法：　苦集灭道谛。
阿若憍陈如，　最初得见道；
八万诸天众，　皆亦入道迹！
```

大意：佛最初说法的时候，那时我没有亲见，是这样辗转听闻的：佛在波罗奈，为五比丘初开甘露之门，宣说四真谛法，就是苦、集、灭、道四谛。阿若憍陈如最先得见道谛；八万诸天大众，也都入了圣道之迹！

这一千位阿罗汉听了这些话，上升到虚空中七棵多罗树的高度，都说：“唉！无常的力量真大，像我们亲眼看见佛说法，现在却要说‘我闻’了！”便说偈：

```
我见佛身相，　犹如紫金山，
妙相众德灭，　唯有名独存。
是故当方便，　求出于三界，
勤集诸善根，　涅槃最为乐！
```

大意：我们曾亲见佛的身相，如同紫金山一般，如今妙相与众德都已灭去，只剩下名号独存。所以应当善用方便，求出三界，勤集种种善根，涅槃才是最上之乐！

那时，长老阿泥卢豆说偈：

```
咄世间无常！　如水月芭蕉，
功德满三界，　无常风所坏！
```

大意：唉，世间无常！如同水中之月、芭蕉之茎，即使功德充满三界，也被无常之风所摧坏！

那时，大迦叶又说偈：

```
无常力甚大，　愚智贫富贵，
得道及未得，　一切无能免！
非巧言妙宝，　非欺诳力诤，
如火烧万物，　无常相法尔。
```

大意：无常的力量极大，愚人与智者、贫穷与富贵、已得道与未得道，一切都不能免脱！不是巧妙的言辞与珍宝能够贿免，也不是欺诳与力争能够逃脱；如同大火焚烧万物，无常之相本来就是如此。

大迦叶对阿难说：“从《转法轮经》到《大般涅槃经》，结集为四阿含：增一阿含、中阿含、长阿含、相应阿含。这名为修多罗法藏。”

诸阿罗汉又问：“谁能明了地结集毗尼法藏？”大家都说：“长老优波离，在五百阿罗汉中持律第一，我们现在就请长老优波离。”随即请长老优波离说：“请起身，坐上狮子座！请说：佛在什么地方最初说毗尼、制定戒律？”优波离接受僧众的教命，坐上狮子座，说：“如是我闻：一时，佛在毗舍离。那时，须提那迦兰陀长者之子最初行淫欲，因为这个因缘，佛制定了第一条大罪。二百五十戒的意义，分作三部，又有七法、八法、比丘尼毗尼、增一、优波离问、杂部、善部；像这样共八十部，作为毗尼藏。”

诸阿罗汉又思惟：“谁能明了地结集阿毗昙藏？”心想：“长老阿难，在五百阿罗汉中理解修多罗的义理第一，我们现在就请长老阿难。”随即请阿难说：“请起身，坐上狮子座！佛在什么地方最初说阿毗昙？”阿难接受僧众的教命，坐上狮子座，说：“如是我闻：一时，佛在舍婆提城。那时，佛告诉诸比丘：凡有五怖、五罪、五怨，不除去、不灭尽的人，因为这个因缘，此生身心承受无量痛苦，后世又堕入恶道之中。凡没有这五怖、五罪、五怨的人，因为这个因缘，今生身心享受种种安乐，后世生到天上安乐之处。哪五种怖畏应当远离？一是杀生，二是偷盗，三是邪淫，四是妄语，五是饮酒。”像这样等等，名为阿毗昙藏。

三法藏结集完毕，诸天、鬼神、诸龙、天女，以种种供养，降下天花、天香、幡盖、天衣，为的是供养法。于是说偈：

```
怜愍世界故，　集结三藏法；
十力一切智，　说智无明灯！
```

大意：为了怜悯世间，结集了三藏之法；这是具足十力的一切智者所说的、破除无明的智慧明灯！

问：八犍度阿毗昙、六分阿毗昙等，是从哪里出来的？

答：佛在世时，法没有违错；佛灭度后，最初结集法藏时，也像佛在世时一样。佛灭后一百年，阿输迦王举办般阇于瑟大会，诸大法师论议的见解不同，所以有了各别部派的名字。从那以后辗转流传，到了一位姓迦旃延的婆罗门出家人，智慧锐利，读遍三藏与内外经书，为了解释佛语，造了《发智经八犍度》，第一品讲的是世间第一法。后来迦旃延的弟子们，因为后人不能完全理解《八犍度》，又造了鞞婆沙（广解）。

有人说：六分阿毗昙中，第三分八品，名为〈分别世处分〉（这是依《楼炭经》而作，在六分中是第三分），是目犍连所造；六分中的第一分八品，四品是婆须蜜菩萨所造，四品是罽宾阿罗汉所造；其余五分是诸论议师所造。

有人说：佛在世时，舍利弗为了解释佛语而造阿毗昙；后来犊子部的修行人等读诵流传，一直到现在名为《舍利弗阿毗昙》。

摩诃迦旃延在佛在世时，为了解释佛语而造蜫勒（汉语意为箧藏），一直到现在流行于南天竺。

这些都是为了广泛解释佛语。比如说五戒：其中几种有色，几种无色？几种可见，几种不可见？几种有对，几种无对？几种有漏，几种无漏？几种有为，几种无为？几种有果报，几种无果报？几种是善，几种不善？几种有记，几种无记？像这样等等，名为阿毗昙。

再者，七使：欲染使、瞋恚使、有爱使、憍慢使、无明使、见使、疑使，这是七使。七使中，几种系属欲界，几种系属色界，几种系属无色界？几种见谛所断，几种思惟所断？几种见苦所断，几种见集所断，几种见灭所断，几种见道所断？几种是遍使，几种不是遍使？

十智：法智、比智、世智、他心智、苦智、集智、灭智、道智、尽智、无生智。这十智中，几种有漏，几种无漏？几种有为，几种无为？几种缘有漏，几种缘无漏？几种缘有为，几种缘无为？几种缘欲界，几种缘色界，几种缘无色界？几种缘不系法？几种在无碍道中修，几种在解脱道中修？证得四果时，得到几种、失去几种？

像这样分别一切法，也名为阿毗昙。

阿毗昙有三种：一是阿毗昙身及义，略说有三十二万言；二是六分，略说有三十六万言；三是蜫勒，略说有三十二万言。

蜫勒的方法是广泛比较诸事，按类归属，与阿毗昙的分别门不同。

“如是我闻一时”的总义，简略地说完了。

## 初品中“婆伽婆”释论第四

【经】

婆伽婆。

【论】

现在来解说。

解释：为什么名为“婆伽婆”？

“婆伽婆”这个词，“婆伽”意为“德”，“婆”意为“有”，合起来就是“有德”。

再者，“婆伽”意为“分别”，“婆”意为“善巧”，善巧地分别诸法的总相与别相，所以名为“婆伽婆”。

再者，“婆伽”意为“名声”，“婆”意为“有”，合起来就是“有名声”，没有谁得到的名声能像佛那样。转轮圣王、帝释、梵天、护世四天王，都比不上佛，何况其余的凡夫庶民！为什么？转轮圣王与结使相应，佛已远离结使；转轮圣王沉没在生、老、病、死的泥潭中，佛已得度；转轮圣王是恩爱的奴仆，佛已永远远离；转轮圣王处在世间的旷野灾患之中，佛已得以远离；转轮圣王处在无明的黑暗中，佛处在第一光明中；转轮圣王最多统领四天下，佛统领无量世界；转轮圣王在财物上自在，佛在心上自在；转轮圣王贪求天上的快乐，佛连有顶天的快乐也不贪着；转轮圣王向外求乐，佛内心自乐。因为这些因缘，佛胜过转轮圣王。其余帝释、梵天、护世四天王，也是如此，只是比转轮圣王稍胜一些。

再者，“婆伽”意为“破”，“婆”意为“能”，这个人能破除淫欲、瞋怒、愚痴，所以称为“婆伽婆”。

问：阿罗汉、辟支佛也破除了淫欲、瞋怒、愚痴，与佛有什么不同？

答：阿罗汉、辟支佛虽然破除了三毒，三毒的习气没有除尽。譬如香放在器皿中，香虽然拿出去了，余下的气味仍在；又如草木柴薪被火烧，冒出烟来，炭与灰却烧不尽，因为火力弱。佛的三毒永远断尽，没有剩余，譬如劫末之火焚烧须弥山，一切大地全都烧尽，没有烟，也没有炭。如舍利弗有瞋恚的余习，难陀有淫欲的余习，必陵伽婆蹉有我慢的余习；譬如人被锁链锁住，刚解脱时走路还不灵便。

当时佛从禅定中起身经行，罗睺罗跟随佛经行。佛问罗睺罗：“为什么这样消瘦？”罗睺罗说偈回答佛：

```
若人食油则得力，　若食酥者得好色，
食麻滓菜无色力，　大德世尊自当知！
```

大意：人吃油就有力气，吃酥就有好气色；吃麻渣和菜蔬，就既没有气色也没有力气，大德世尊自然知道！

佛问罗睺罗：“这大众中谁是上座？”罗睺罗回答：“是我的和上舍利弗。”佛说：“舍利弗吃了不清净的食物。”那时，舍利弗辗转听到这句话，当即把吃下的食物吐出来，自己立誓说：“从今天起，不再接受别人的邀请应供。”这时，波斯匿王、长者须达多等人来到舍利弗处，对舍利弗说：“佛不会无缘无故接受别人的邀请；大德舍利弗又不接受邀请，我们这些在家白衣怎能得到广大清净的信心？”舍利弗说：“我的大师佛说：舍利弗吃了不清净的食物。所以我现在不能接受邀请。”于是波斯匿王等人来到佛处，对佛说：“佛不常接受别人的邀请，舍利弗又不接受邀请，我们的心怎能得到广大的信心？愿佛敕令舍利弗恢复接受邀请！”佛说：“舍利弗心意坚定，不可转移。”佛当时引述本生因缘说：

“从前有一位国王被毒蛇咬了，国王快要死了，召来诸位良医医治蛇毒。当时诸医说：‘要让这条蛇把毒吸回去，毒气才能除尽。’于是诸医各自施展咒术，咬国王的那条蛇随即来到国王处。诸医堆起柴薪点上火，命令蛇说：‘把你的毒吸回去！否则，就要进入这火中！’毒蛇心想：‘我既然已经吐出了毒，怎能再吸回来？这比死还难受！’毒蛇思惟定了，当即进入火中。那时的毒蛇，就是舍利弗。舍利弗世世心意坚定，不可动摇。”

再者，长老必陵伽婆蹉常患眼痛。这个人乞食，常常要渡恒河，到了恒河边就弹指说：“小婢！停住，不要流！”河水随即分开两边，必陵伽婆蹉得以过河乞食。恒河神来到佛处，对佛说：“佛弟子必陵伽婆蹉，常骂我说：‘小婢！停住，不要流！’”佛告诉必陵伽婆蹉：“向恒河神忏悔道歉！”必陵伽婆蹉当即合掌对恒河神说：“小婢不要生气！现在向你忏悔道歉！”这时大众都笑了：“怎么一边忏悔道歉，一边又骂？”佛对恒河神说：“你看见必陵伽婆蹉合掌向你忏悔道歉了吗？忏悔道歉时没有傲慢，却说出这样的话，应当知道这不是恶意。这个人五百世以来，常生在婆罗门家，常自以为高贵，轻视他人，这是本来的习气，只是嘴上说说而已，心里并没有傲慢。”

像这样，诸阿罗汉虽然断除了结使，仍有残余的习气。至于诸佛世尊，如果有人用刀割佛的一只手臂，另有人用栴檀香泥涂佛的另一只手臂，佛看这两人如同看左右两只眼睛，心中没有憎恨也没有爱着，所以永远没有残余的习气。

栴阇婆罗门女把木盆绑在腹部诽谤佛，在大众中说：“你让我怀了身孕，为什么不担忧？还不给我衣食！你这样没有羞耻，还欺骗迷惑别人！”这时，五百位婆罗门师等都举手高喊：“是的！是的！我们都知道这件事。”这时，佛面不改色，也没有惭愧之色。这件事随即真相大白，大地大动，诸天前来供养，散下众多名花，赞叹佛的功德，佛也没有欢喜之色。

再者，佛吃马麦，也不忧愁；天王献上百味具足的饮食，佛也不因此喜悦，一心平等，没有两样。

像这样，在种种饮食、衣被、卧具，赞叹与呵斥、轻慢与恭敬等种种事情中，佛的心都没有变化。譬如真金，经过烧炼、锻打、打磨，都没有增加，也没有减少。

所以，阿罗汉虽然断除结使、证得道果，仍有残余的习气，不能称为婆伽婆。

问：婆伽婆只有这一个名号，还是另有其他名号？

答：佛的功德无量，名号也无量；这个名号是取其中最大的，因为人们大多知道。另有不同的名号，名为“多陀阿伽陀”等。

为什么名为“多陀阿伽陀”（如来）？

如诸法实相而理解，如诸法实相而宣说；如同诸佛从安稳之道而来，佛也这样而来，不再去往后有之中，所以名为“多陀阿伽陀”。

又名“阿罗呵”。为什么名为“阿罗呵”？

“阿罗”意为“贼”，“呵”意为“杀”，这就叫“杀贼”。如偈中说：

```
佛以忍为铠，　精进为刚甲，
持戒为大马，　禅定为良弓，
智慧为好箭；　外破魔王军，
内灭烦恼贼，　是名阿罗呵。
```

大意：佛以忍辱为铠，以精进为坚甲，以持戒为大马，以禅定为良弓，以智慧为利箭；对外破除魔王的军队，对内灭除烦恼之贼，这名为阿罗呵。

再者，“阿”意为“不”，“罗呵”意为“生”，这就叫“不生”。因为佛心的种子，在后世的田中，不再生出无明的糠壳。

再者，“阿罗呵”意为“应受供养”。佛的一切结使已经除尽，得到一切智慧，所以应当受一切天地众生的供养。因此，佛名为“阿罗呵”。

又名“三藐三佛陀”。为什么名为“三藐三佛陀”？

“三藐”意为“正”，“三”意为“遍”，“佛”意为“知”，这就叫正遍知一切法。

问：怎样是正遍知？

答：

```
知苦如苦相，　知集如集相，
知灭如灭相，　知道如道相。
```

大意：如苦的真实之相而知苦，如集的真实之相而知集，如灭的真实之相而知灭，如道的真实之相而知道。

这名为“三藐三佛陀”。

再者，知道一切诸法真实不坏之相，不增不减。什么是不坏之相？心的活动之处灭尽，言语之道断绝，超过诸法，如涅槃之相，不动。所以名为“三藐三佛陀”。

再者，一切十方诸世界的名号，六道所摄众生的名号；众生前世的因缘，未来世的生处；一切十方众生的心相、种种结使、种种善根、种种出离之道；像这样一切诸法全都知道，这名为“三藐三佛陀”。

又名“鞞侈遮罗那三般那”，汉语意为明行具足。

为什么名为“明行具足”？

宿命、天眼、漏尽，名为三明。

问：神通与明有什么不同？

答：只是知道过去宿命之事，这叫“通”；知道过去的因缘与行业，这叫“明”。

只是知道众生在此处死、在彼处生，这叫“通”；知道众生所行之业的因缘，因果相会不会错失，这叫“明”。

只是断尽结使，却不知道还会不会再生，这叫“通”；如果知道漏已断尽，不再受生，这叫“明”。

这三明，是大阿罗汉、大辟支佛所证得的。

问：如果这样，与佛有什么不同？

答：阿罗汉、辟支佛虽然证得三明，明不圆满；佛的三明全部圆满，这就是不同。

问：怎样是不圆满？怎样是圆满？

答：诸阿罗汉、辟支佛的宿命智，知道自身与他人的宿命，却不能普遍；有的阿罗汉能知道一世，或二世、三世，十劫、百劫、千劫、万劫，乃至八万劫，超过这个限度就不能再知道，所以不圆满。天眼明观察未来世，也是这样。佛在一念的生、住、灭之中，对诸结使的各个部分，生时如何，住时如何，灭时如何，都了了分明。在苦法忍、苦法智中所断的结使，佛全都觉了；知道这样的结使解脱之后，得到多少有为法的解脱，得到多少无为法的解脱，乃至到道比忍为止，见谛道的十五心中，佛全都知道。这些是声闻、辟支佛所不能觉知的，因为见道的时间极短、极快。像这样，佛知道过去众生的因缘与漏尽，对未来、现在也是这样知道。所以佛名为“明行具足”。

“行”指身业、口业，唯有佛的身业、口业具足圆满，其余的人都有缺失，这名为明行具足。

又名“修伽陀”：“修”，汉语意为“好”；“伽陀”，有时译为“去”，有时译为“说”，合起来就是“好去”“好说”。

所谓好去：在种种甚深三摩提、无量大智慧之中而去。如偈中说：

```
佛一切智为大车，　八正道行入涅槃。
```

大意：佛以一切智为大车，沿着八正道而行，进入涅槃。

这名为好去。

所谓好说：如诸法实相而说，不执着对法的爱而说。佛观察弟子的智慧力：知道有的人，即使用尽一切方便、神通、智力去度化，也无可奈何；知道某人可以度化，是快是慢；某人应当在某处得度；某人应当为之说布施，或说持戒，或说涅槃；某人应当为之说五众、十二因缘、四谛等诸法，才能入道。像这样，佛知道弟子的种种智力而为之说法，这名为好说。

又名“路迦惫”：“路迦”，汉语意为“世”，“惫”意为“知”，这就叫知世间。

问：怎样是知世间？

答：知道两种世间：一是众生世间，二是非众生世间。并且如实相而知世间、知世间之因、知世间之灭、知出世间之道。

再者，知世间，不像世俗那样知，也不像外道那样知；知道世间无常所以是苦，是苦所以无我。

再者，知世间之相，非有常、非无常，非有边、非无边，非去、非不去，对这样的相也不执着，清净、常不坏之相，如同虚空，这名为知世间。

又名“阿耨多罗”，汉语意为“无上”。

怎样是无上？

涅槃之法无上。佛自己知道这涅槃，不是从他人那里听来的，也引导众生到达涅槃。如同诸法中涅槃无上，众生中佛也无上。

再者，在持戒、禅定、智慧、教化众生上，一切人都没有能与佛相等的，何况能超过佛？所以说无上。

再者，“阿”意为“无”，“耨多罗”意为“答”。一切外道之法，都可以被答复、可以被破斥，因为不真实、不清净；佛法不可答复、不可破斥，因为超出一切言语之道，又真实清净，所以名为“无答”。

又名“富楼沙昙藐婆罗提”：“富楼沙”，汉语意为“丈夫”；“昙藐”意为“可化”；“婆罗提”意为“调御师”，合起来就是“可化丈夫调御师”。

佛以大慈、大悲、大智，有时说柔软美妙的话，有时说严厉恳切的话，有时柔软与严厉相杂而说，用这些方式调御众生，使众生不失正道。如偈中说：

```
佛法为车弟子马，　实法宝主佛调御，
若马出道失正辙，　如是当治令调伏。
若小不调轻法治，　好善成立为上道，
若不可治便弃舍，　以是调御为无上。
```

大意：佛法是车，弟子是马，真实法宝之主，就是驾御的佛。马如果偏出道路、失去正辙，就要这样整治，使马调伏。稍有不调，就用轻法整治；良善的，就成就为上道之器；实在不可整治的，就舍弃。所以佛的调御是无上的。

再者，调御师有五种：最初是父母、兄姊、亲属；其次是官府之法；再次是师长之法：这三种是今世的整治；以后是阎罗王在后世的整治。佛以今世之乐、后世之乐与涅槃之乐利益众生，所以名为“师”。前四种整治人的方法，不久就会终了败坏，不能常久、真实地成就人；佛以三种道成就人，人常随道而不失。如同火的自相不会舍离，直到火灭为止；佛使人得到善法也是这样，至死不舍。所以，佛名为可化丈夫调御师。

问：女人，佛也度化她们得道，为什么只说丈夫？

答：因为男尊女卑，女从男，男子是家业之主。

再者，女人有五种障碍：不能作转轮王、帝释天王、魔天王、梵天王、佛，所以不说。

再者，如果说佛是女人的调御师，显得不够尊重。如果说丈夫，就一切都摄入了。譬如国王到来，不会独自一人来，必定有侍从。同样，说“丈夫”，二根之人、无根之人以及女人，全都摄入了，所以说“丈夫”。

因为这些因缘，佛名为可化丈夫调御师。

又名“舍多提婆摩奴舍喃”（“奴”字原文作一罕见字，对音梵语manuṣyāṇām）：“舍多”，汉语意为“教师”；“提婆”意为“天”；“摩奴舍喃”意为“人”，合起来就是“天人教师”。

为什么名为天人教师？

佛开示引导：这是应当做的，那是不应当做的；这是善，那是不善。人随着佛的教导而行，不舍弃道法，就得到烦恼解脱的果报，这名为天人师。

问：佛也能度化堕在其余道中受生的龙、鬼、神等，为什么只说天人师？

答：度化其余道中受生者少，度化天、人中受生者多。譬如白皮肤的人，虽然有黑痣，也不叫黑人，因为黑的部分少。

再者，人道中结使较薄，容易生起厌离心；天道中智慧锐利。所以在这两处容易得道，其余诸道就不是这样。

再者，说“天”就摄尽一切天，说“人”就摄尽一切地上的生命。为什么？天上以天为大，地上以人为大。所以说“天”就摄尽天上，说“人”就摄尽地上。

再者，人道中能受戒律仪，能得见谛道、思惟道以及诸道果。有人说：其余诸道中都得不到；有人说：其余诸道中能得到少许。天、人之中容易得、得得多，所以佛是天人师。

再者，人道中行乐因的多，天道中受乐报的多；善法是乐的因，乐是善法的报。其余诸道中，善因与乐报都少，所以佛是天人师。

又名“佛陀”（汉语意为“知者”）。知道什么法？知道过去、未来、现在，众生数、非众生数，有常、无常等一切诸法。佛在菩提树下了了觉知，所以名为佛陀。

问：其余的人也知道一切诸法，如摩醯首罗天（汉语意为“大自在”），八臂，三眼，骑白牛；如韦纽天（汉语意为“遍闷”），四臂，拿着螺贝，持着轮宝，骑金翅鸟；如鸠摩罗天（汉语意为“童子”），这位天神擎着鸡，持着铃，拿着红幡，骑孔雀。这些都是诸天中的大将。像这些诸天，各自都说自己最大，都自称是一切智者。有人作他们的弟子，学习他们的经书，也领受他们的法，说他们是一切智者。

答：这些天神不应当是一切智者。为什么？因为心中执着瞋恚与憍慢。如偈中说：

```
若彩画像及泥像，　闻经中天及赞天，
如是四种诸天等，　各各手执诸兵杖。
若力不如畏怖他，　若心不善恐怖他，
此天定必若怖他，　若少力故畏怖他。
是天一切常怖畏，　不能除却诸衰苦。
有人奉事恭敬者，　现世不免没忧海。
有人不敬不供养，　现世不妨受富乐。
当知虚诳无实事，　是故智人不属天。
若世间中诸众生，　业因缘故如循环，
福德缘故生天上，　杂业因缘故人中，
世间行业属因缘，　是故智者不依天！
```

大意：无论是彩画的天像、泥塑的天像，还是经中所听说的天、人们所赞颂的天，这四种天，个个手中都拿着兵器。拿兵器，或者是因为力量不如别人而畏惧别人，或者是因为心不善而想恐吓别人；这些天神必定不是要恐吓别人，就是因为力量弱小而畏惧别人。这些天神一切时中常怀怖畏，不能除去种种衰败痛苦。有人奉事恭敬这些天神，现世仍免不了沉没在忧愁的大海里；有人不恭敬也不供养，现世照样享受富乐。应当知道，这些都是虚诳，没有实事，所以有智慧的人不归属于天。世间众生因为业的因缘，如同循环往复：以福德因缘生到天上，以杂业因缘生在人中；世间的行为与业都属于因缘，所以有智慧的人不依靠天！

再者，这三位天神，喜爱谁，就想让谁一切愿望都满足；憎恶谁，就想让谁七世灭绝。佛不是这样。佛还在作菩萨、不惜身命的时候，如果有怨家盗贼来要杀害，尚且以自己的身肉、头目、髓脑去供养，何况成佛之后？所以唯独佛应当受“佛”的名号；应当归命于佛，以佛为师，不应当奉事天神。

再者，佛具有两件事：一是大功德与神通力，二是第一清净之心，诸结使都已灭尽。

诸天虽然有福德与神力，因为结使没有灭尽，心不清净；心不清净，所以神力也小。

声闻、辟支佛虽然结使已灭、心已清净，因为福德薄，所以力量也小。

佛这两种法都圆满具足，所以称为胜过一切人；其余的人都不能胜过一切人。

婆伽婆名为“有德”，先前已经说过了。

又名“阿婆磨”（汉语意为无等）；又名“阿婆摩婆摩”（汉语意为无等等）；又名“路迦那他”（汉语意为世尊）；又名“波罗伽”（汉语意为度彼岸）；又名“婆檀陀”（汉语意为大德）；又名“尸梨伽那”（汉语意为厚德）；像这样有无量名号。父母所起的名字叫悉达陀（汉语意为成利）；得道时，因为知道一切诸法，名为佛，应当受诸天与世人的供养。像这样，得名为大德、厚德。像这样种种名号，都是随着功德而立名。

问：你喜爱刹利种姓、净饭王的儿子、名叫悉达多的这个人，所以大加称赞，说他是一切智者。一切智人，根本没有！

答：不是这样！你因为邪恶，所以嫉妒、瞋恨佛，说出妄语。确实有一切智人。为什么？佛在一切众生中，身色容貌端正无比，相好、功德、三明具足，胜过一切人。即使是下等的人，见到佛的身相，也知道佛是一切智人，何况大人？如《放牛譬喻经》中说：

摩伽陀国王频婆娑罗，邀请佛与五百弟子安住三个月。国王需要新鲜的乳、酪、酥来供养佛与比丘僧，就叫放牛人搬到附近来住，每天送来新鲜的乳、酪、酥，直到三个月结束。国王怜悯这些放牛人，对放牛人说：“你们去见佛，回来再去放牛。”这些放牛人前往佛处，在路上互相议论：“我们听人说佛是一切智人，我们是低下卑微的小人，怎能辨别是不是真的一切智人！婆罗门们喜好酥酪，常来往于放牛人之间，与放牛人交好，放牛人因此听说了婆罗门种种经书的名字。所以知道四违陀经中有治病法、战斗法、星宿法、祭天法、歌舞法、论议难问法等，像这样六十四种世间技艺，净饭王的儿子广学多闻，如果懂得这些，也不算难事。净饭王的儿子从出生以来没有放过牛，我们就拿放牛的秘法去问他。如果能解答，就真是一切智人。”

放牛人这样议论之后，向前走进竹园，看见佛的光明照耀在林间。放牛人走上前去寻找佛，看见佛坐在树下，形状如同金山；又如同把酥投入火中，火焰极其明亮，好似熔化的金子，散布在竹林之上，紫金色的光芒，怎么看都看不够。放牛人心中大为欢喜，互相说道：

```
今此释师子，　一切智有无，
见之无不喜，　此事亦已足。
光明第一照，　颜貌甚贵重，
身相威德备，　与佛名相称。
相相皆分明，　威神亦满足，
福德自缠络，　见者无不爱；
圆光身处中，　观者无厌足！
若有一切智，　必有是功德。
一切诸彩画，　宝饰庄严像，
欲比此妙身，　不可以为喻！
能满诸观者，　令得第一乐，
见之发净信，　必是一切智！
```

大意：如今这位释迦狮子，不论是否真是一切智者，见到的人没有不欢喜的，单凭这一点就已足够。光明第一照耀，容貌极其尊贵，身相与威德完备，与“佛”的名号相称。每一种相好都分明，威神也圆满，福德自然缠绕周身，见到的人没有不爱敬的；身处圆光之中，观看的人看不够！如果有一切智，必定有这样的功德。一切彩画、珍宝装饰的庄严之像，想与这微妙之身相比，都无法作比喻！能满足一切观看者，使其得到第一的快乐，见到就生起清净信心，必定是一切智者！

放牛人这样思惟之后，礼佛而坐，问佛：“放牛人成就几种法，能使牛群繁衍增长？有几种法不成就，使牛群不增长、不得安稳？”佛回答：“有十一种法，放牛人成就了，能使牛群繁衍增长。哪十一种？

“知道颜色，知道相貌，知道刮刷，知道遮盖伤疮，知道生烟，知道好的道路，知道适宜牛的处所，知道好的渡口，知道安稳之处，知道留乳，知道养护牛王。

“如果放牛人知道这十一种法，就能使牛群繁衍增长。比丘也是这样，知道十一种法，就能增长善法。

“怎样是知道颜色？知道黑色、白色、杂色。比丘也是这样，知道一切色都是四大与四大所造色。

“怎样是知道相貌？知道牛吉祥与不吉祥的相貌；与别的牛群混在一起，凭相貌就能认出。比丘也是这样，看见善业的相，就知道这是智者；看见恶业的相，就知道这是愚人。

“怎样是刮刷？因为种种虫子吸血，就会使伤疮扩大；刮刷就能除去祸害。比丘也是这样，邪恶的觉观之虫吸食善根之血，使心的伤疮扩大；除去这些虫子，就安稳了。

“怎样是遮盖伤疮？用衣服或草叶遮盖，防止蚊虻与恶刺。比丘也是这样，以正念观法，遮盖六情的伤疮，不让烦恼、贪欲、瞋恚这些恶虫与荆棘所伤。

“怎样是知道生烟？为了驱除蚊虻；牛远远看见烟，就会走向屋舍。比丘也是这样，依所听闻的法而说，驱除结使的蚊虻；以说法之烟，引导众生进入无我、实相、空性的屋舍之中。

“怎样是知道道路？知道牛往来所走的好路与坏路。比丘也是这样，知道八圣道能到达涅槃，远离断见、常见的恶道。

“怎样是知道适宜牛的处所？能使牛繁衍增长、少生疾病。比丘也是这样，在宣说佛法时，得到清净的法喜，种种善根增长兴盛。

“怎样是知道渡口？知道容易下水、容易渡过、没有波浪与恶虫的地方。比丘也是这样，能到多闻比丘处请问佛法；说法的人知道对方心性的利钝、烦恼的轻重，使对方进入好的渡口，安稳地得度。

“怎样是知道安稳之处？知道所住之处没有虎、狼、狮子、恶虫、毒兽。比丘也是这样，知道四念处安稳，没有烦恼、恶魔、毒兽；比丘进入四念处，就安稳无患。

“怎样是留乳？母牛爱念小牛，所以给小牛喂奶；留下余乳，母牛就欢喜，小牛的奶也不会断，牛主与放牛人每天都有收益。比丘也是这样，居士白衣施给衣食，应当知道节制分量，不让施主竭尽，施主就会欢喜，信心不断，受施的人也不匮乏。

“怎样是知道养护牛王？诸大公牛能守护牛群，所以应当养护，不让大公牛消瘦，给大公牛喝麻油，用璎珞装饰，用铁角作标志，为大公牛按摩刷洗、赞美称誉等。比丘也是这样，僧众中有威德的大人，护持增益佛法，摧伏外道，能使八众种下种种善根，应当随其所宜，恭敬供养等。”

放牛人听了这番话，这样思惟：“我们所知道的不过三四件事，放牛的师傅们最多也不过五六件事，现在听佛这样说，真是叹为未曾有！既然知道这些事，其余的事也一定都知道，实在是一切智人，不再怀疑了。”

这部经，这里应当广说。因此，知道有一切智人。

问：世间不应当有一切智人。为什么？因为没有人见过一切智人。

答：不是这样！不见有两种，不能因为不见，就说没有。

第一种：事情实际存在，因为有因缘遮蔽，所以不见。譬如人类姓族最初的起源，雪山有多少斤两，恒河边的沙有多少数量，都是存在而不可知的。

第二种：实际没有，因为没有，所以不见。譬如第二个头、第三只手，不是有因缘遮蔽而不见。

同样，一切智人是因为因缘遮蔽，你才看不见，并不是没有一切智人。什么是遮蔽的因缘？你还没有得到四种不坏信，心执着于邪恶，因为这些因缘遮蔽，你看不见一切智人。

问：因为所要知道的范围无量，所以没有一切智人。诸法无量无边，许多人合起来尚且不能知道，何况一个人？所以没有一切智人！

答：正如诸法无量，智慧也无量、无数、无边；就像匣子大，盖子也大；匣子小，盖子也小。

问：佛只说佛法，不说其余经典。比如医药方书、星宿、算术、世间典籍等法；如果是一切智人，为什么不说？由此知道佛不是一切智人。

答：佛虽然知道一切法，有用的才说，没有用的就不说；有人问才说，没人问就不说。

再者，一切法简略地说有三种：一是有为法，二是无为法，三是不可说法。这三种已经摄尽一切法。

问：因为佛不回答十四难，所以知道佛不是一切智人。哪十四难？

世界及我是常；世界及我是无常；世界及我亦常亦无常；世界及我非常非无常；世界及我有边；无边；亦有边亦无边；非有边非无边；死后有神我去往后世；死后没有神我去往后世；死后亦有神我去亦无神我去；死后非有神我去亦非无神我去往后世；身就是神我；身与神我相异。

如果佛是一切智人，这十四难为什么不回答？

答：因为这些事没有实义，所以不回答。说诸法是常，没有这个道理；说诸法断灭，也没有这个道理。所以佛不回答。譬如有人问：挤牛角能挤出几升奶？这是不成问题的问题，不应当回答。

再者，世界没有穷尽，如同车轮，没有开始，没有结束。

再者，回答这些问题没有利益，只有过失，会使人堕入邪恶之见。佛知道十四难总是遮蔽四谛与诸法实相。譬如渡口有恶虫的水域，不应当带人从那里渡过；安稳无患之处，才可以指示给人，让人渡过。

再者，有人说：这些事除了一切智人，没有人能理解；一般人既然不能理解，所以佛不回答。

再者，如果有人把无说成有，把有说成无，这叫不是一切智人；一切智人，有就说有，无就说无。佛对于有，不说无；对于无，不说有，只是宣说诸法实相，怎么不能称为一切智人？譬如太阳，不把高处变低、低处变高，也不把地面变平，只是平等地照耀。佛也是这样，不是让有变成无，也不是让无变成有，常常以真实智慧之光照耀诸法。如一位修道人问佛：“大德！十二因缘是佛造作的吗？还是他人造作的？”佛说：“我不造作十二因缘，其他人也不造作。有佛也好，无佛也好，以生为缘有老死，这个法常住不变。”佛能宣说以生为缘有老死，乃至以无明为缘有诸行。

再者，十四难中，如果回答，就有过失与罪咎。如果有人问：“石女、阉人的儿子，是高是矮，是美是丑，像什么样子？”这不应当回答，因为根本没有这个儿子。

再者，这十四难是邪见，不是真实。佛常依真实而说，所以搁置不答。

再者，搁置不答，本身就是回答。有四种回答方式：一是决定回答，如问“佛是第一吗？涅槃安稳吗？”就决定回答“是”；二是分别解义回答；三是反问回答；四是搁置回答。十四难，佛用的是搁置回答。

【译注】十四难都预设了“世界”“我”“如来”是实有之物，再问这个实有之物是常还是断、有边还是无边。预设本身不成立，任何一种回答都会把预设当真，所以龙树以石女之子、牛角之乳作比。“置答”并不是佛答不出，搁置正是对预设的拒绝，所以论中说“置不答，是为答”。

你说没有一切智人，这话有言无义，是大妄语。确实有一切智人。为什么？因为佛得到十力：知道是处与非处，知道因缘与业报，知道诸禅定与解脱，知道众生诸根的善恶，知道种种欲乐与胜解，知道种种世间无量的性，知道一切所至之处的道路，忆念知道前世所行之处，分明证得天眼，知道一切漏已尽；又分明知道清净与不清净，宣说一切世界中最上之法，证得甘露味，证得中道，知道一切有为法、无为法的实相，永远离开三界的贪欲。因为这样种种因缘，佛是一切智人。

问：有一切智人，是什么人？

答：是第一大人，三界之尊，名叫佛。如赞佛偈中说：

```
顶生转轮王，　如日月灯明；
释迦贵种族，　净饭王太子。
生时动三千，　须弥山海水；
为破老病死，　哀愍故生世。
生时行七步，　光明满十方；
四观发大音，　我生胎分尽。
成佛说妙法，　大音振法鼓；
以此觉众生，　世间无明睡。
如是等种种，　希有事已现；
诸天及世人，　见之皆欢喜！
佛相庄严身，　大光满月面；
一切诸男女，　视之无厌足！
生身乳餔力，　胜万亿香象；
神足力无上，　智慧力无量。
佛身大光明，　照曜佛身表；
佛在光明中，　如月在光里。
种种恶毁佛，　佛亦无恶想；
种种称誉佛，　佛亦无喜想。
大慈视一切，　怨亲等无异；
一切有识类，　咸皆知此事。
忍辱慈悲力，　故能胜一切；
为度众生故，　世世受勤苦。
其心常一定，　为众作利益。
智慧力有十，　无畏力有四，
不共有十八，　无量功德藏。
如是等无数，　希有功德力，
如师子无畏，　破诸外道法，
转无上梵轮，　度脱诸三界。
```

大意：佛出自顶生转轮王的世系，如日月灯明一般光耀；是释迦尊贵的种族，净饭王的太子。佛出生时，三千世界、须弥山与大海之水都为之震动；为了破除老病死，出于哀悯而降生于世。出生时行走七步，光明充满十方，向四方观察，发出大音声：“我受胎而生的分已经穷尽。”成佛之后宣说妙法，大音声如擂响法鼓，以此唤醒世间众生无明的沉睡。像这样种种稀有之事已经显现，诸天与世人见到都欢喜！佛以相好庄严其身，大光明照耀如满月的面容，一切男女看了都看不够！佛的生身，吃奶长大的力气，胜过万亿香象；神足之力无上，智慧之力无量。佛身的大光明，照耀在佛身之外；佛在光明之中，如同月亮在光晕里。种种恶言毁谤佛，佛也没有恶念；种种言辞称誉佛，佛也没有喜念。佛以大慈平等看待一切，怨家与亲人没有差别，一切有情识的众生都知道这件事。凭着忍辱与慈悲之力，所以能胜过一切；为了度化众生，世世承受勤苦。佛的心常常专一安定，为众生作利益。智慧之力有十种，无畏之力有四种，不共之法有十八种，是无量功德的宝藏。像这样无数稀有的功德力量，如同狮子无所畏惧，破除种种外道之法，转无上的梵轮，度脱三界众生。

这名为“婆伽婆”。

“婆伽婆”的意义无量，如果广说，就会荒废其余的事，所以简略地说。

## 本卷要义

“如是我闻”这四个字，本卷读出了一层很深的意味。佛是一切智人，自然无师，佛的言教不可能是“闻”来的；“我闻”只能出自弟子之口，也只能出现在佛不在之后。佛临终教阿难“自依止，法依止，不余依止”，又说“解脱戒经即是大师”，同时亲口定下经首“如是我闻”。三件事是一件事：老师走了，法要成为依止，法就必须以“我闻”的形态被接住、传下去。所以千位阿罗汉听阿难说出“如是展转闻”，会飞升虚空，叹息“如我等眼见佛说法，今乃言我闻”。经首这一句，从诞生的那一刻起就带着佛的不在，也带着法的接续。

结集一段，大迦叶对阿难的严厉，表面是数落六种突吉罗罪，实际是不许一个结使未尽的人坐进清净众中。论中把阿难迟迟不能证果的原因说得很清楚：多闻第一，智慧多而定力少。结集法藏，要的是闻持，更要的是离结；佛的法藏最终交到阿难手中，正是在阿难从钥匙孔进门之后。迦叶那句“我故为汝，使汝得道；汝无嫌恨，我亦如是”，配上“手画虚空，无所染著”，把这场冲突本身也化成了阿罗汉心的一个示现：责难与受责，都不留痕迹。

“婆伽婆”的诸义中，龙树最着力的是“破”：佛与阿罗汉同样破了三毒，差别在残气。舍利弗一听“食不净食”就吐食立誓，宁入火也不收回毒的蛇心；必陵伽婆蹉合掌认错，嘴里还是“小婢”。这些残气都不是恶心，而是多生熏成的惯性。佛的不同，不在断得更多，而在惯性也尽了：一臂刀割、一臂涂香，如看左右两眼；被栴阇女当众诬陷，无异色也无惭色，真相大白、天花遍洒时，也无喜色。如来、应供、正遍知等诸名号，都是从这一点向外展开的不同侧面。其中“三藐三佛陀”释为“心行处灭，言语道断”，“阿耨多罗”释为“无答”，佛法之所以不可答、不可破，是因为出一切语言道，这与卷一的第一义悉檀“不可破，不可散”正是同一处。

一切智的论证，是本卷的另一条主线。龙树没有用“佛无所不答”来证明一切智，恰恰相反，用的是佛的“不答”。十四难都预设了一个实有的世界与我，再问这个实有之物是常是断；佛知道这些问题没有对象，如问石女之子的长短，所以置而不答。一切智的标志，在于有说有、无说无，如日光平等照物，不把高处压低，也不把低处填平。放牛人一段把这层意思说得最亲切：佛并没有去证明自己懂星宿、医方，只是把放牛的十一件事，一件件说成比丘增长善法的路。一切智不是知识的堆积，而是知道每一件事在解脱道上该放在哪里；有用才说，无用不说，正是从这里来的。
