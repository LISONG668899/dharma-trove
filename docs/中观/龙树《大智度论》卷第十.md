# 龙树《大智度论》卷第十

龙树菩萨造　后秦龟兹国三藏法师鸠摩罗什奉诏译

## 初品中十方菩萨来释论第十五之余

### 一、释“宝积佛报普明：是释迦牟尼佛神力”

【经】

宝积佛报普明言：“善男子！西方度如恒河沙等世界，有世界名娑婆，是中有佛，号释迦牟尼，今现在欲为诸菩萨摩诃萨说般若波罗蜜，是其神力。”

【论】

#### （一）佛常在定，何以答问

问：佛譬如须弥山，不为大海的水波所动摇，现在为什么回答普明？

回答就是动的相。摄心就无言，散心才有说。说法从觉观而生，觉观是粗事，佛不应当有这粗事！

答：佛虽然入于深禅定，不为世间之事所动，如今是以大慈悲心怜悯众生，为众生说法，断除疑惑。

如须弥山王，小风不能使它动摇，如果随蓝风刮来，就会大动而散；佛也是这样，有大慈悲之风吹来，怜悯之心一动，就散身无数，进入五道教化众生，或者作天身，乃至作畜生之身。

再者，佛实际上不动，常在禅定中，因为前世福德的因缘，身边自然出声，应物如响；如同天上的伎乐，自然发出声音。

又如摩尼珠，随人所想要的，种种给予，如果想要衣服、饮食、音乐，任意所需，自然都能得到；佛也是这样，从佛身边的诸毛孔中自然有声音，随众生之心而说法，这其中佛没有忆想，也没有分别。

#### （二）佛的三密

如《密迹金刚经》中说，佛有三密：身密、语密、意密。一切诸天与人都不理解、不知道。

在同一法会中，有的众生见佛身是黄金色、白银色、种种杂宝色；有人见佛身高一丈六尺，有的见到一里、十里、百千万亿，乃至无边无量，遍满虚空，像这样等等名为身密。

所谓语密，有人听到佛的声音传到一里，有人听到十里、百千万亿、无数无量，遍满虚空；在同一法会中，有人听到说布施，有人听到说持戒，有人听到说忍辱、精进、禅定、智慧，像这样乃至十二部经、八万法聚，各自随心所闻，这名为语密。

这时目连心想：“想知道佛的声音能传多远。”

随即以自己的神足之力，到了无量千万亿佛世界才停下，听到佛的声音仍如在近处一样，毫无差别。

在目连停下的那个世界，那里的佛与大众正在进食。

那国土的人身形高大，目连站在他们的钵边上，那位佛的弟子问他们的佛：“这个头上的小虫是从哪里来的？穿着沙门的衣服在走动！”

那位佛回答：“不要轻视这个人！这是从东方经过无量佛土，有一位佛名叫释迦牟尼，这人是那位佛有神足的弟子。”

那位佛问：“目度伽略子！你为什么来这里？”

目连回答：“我追寻佛的音声，所以来到这里。”

那位佛告诉目连：“你追寻佛的声音，经过无量亿劫，也不能找到它的边际。”

再者，佛出世是为了断除众生的疑惑而说法，这不应当质难！如同不应当问：“灯为什么除去黑暗？”佛也是这样，不应当问佛为什么回答！

#### （三）诸佛平等，何言“是彼神力”

问：诸佛平等，所以名为等觉，现在为什么称说“是那位佛的神力”？

答：为了显示没有吾我，灭除彼此之间的嫉妒与我慢。

再者，世间有些天神常求尊胜，因为憍慢之法，自称天地人物都是自己化作的。如梵天王对诸梵天说：“是我造作了你们。”

毗纽天说：“世间有大富贵、有名声的人，都是我身威德之力的一分，我能成就世间，也能破坏世间，世间的成与坏都是我所造作。”

有这样的天神，破坏因缘法相；诸佛说实语，不破坏因缘法相，所以说“是那位佛的神力”。

### 二、释“普明欲往见释迦牟尼佛”

【经】

是时，普明菩萨白宝积佛言：“世尊！我今当往见释迦牟尼佛，礼拜、供养；及见彼诸菩萨摩诃萨绍尊位者，皆得陀罗尼及诸三昧，于诸三昧而得自在。”

【论】

#### （一）菩萨三事无厌

问：如果诸佛的持戒、禅定、智慧、度人都相等，这位普明菩萨为什么还想来见释迦牟尼佛？

答：诸菩萨常想见佛而无厌足，听法而无厌足，见诸菩萨僧而无厌足；诸菩萨对于世间法都已厌患，对于上面这三件事，心无厌足。

如手居士从净居天来，想要见佛，他的身体微细，几乎消失，譬如融化的酥油，不能站立在地上。

佛对手居士说：“你化作粗身，观想这地的相！”居士随即依佛所说，化作粗身，观念这地的相，头面礼佛双足，在一旁站立。

佛问居士：“你因为哪几件事无厌足，生到净居天？”

居士回答：“我因为三件事无厌足，生到净居天：一是见诸佛、供养诸佛无厌足，二是听法无厌足，三是供给僧众无厌足。如佛在阎浮提时，四部众常跟随佛，听法、问法；我在净居天中，诸天也常跟随我听法、问法。”

声闻尚且听法无厌足，何况法性身菩萨？

所以普明菩萨来见释迦牟尼佛。

“及见此间诸菩萨摩诃萨绍尊位者，皆得陀罗尼及诸三昧”，如先前〈赞菩萨品〉中所说。

#### （二）佛三昧与菩萨三昧：文殊不能令女人出定

“于诸三昧而得自在”：

问：如唯有佛一人在一切三昧中得自在，为什么说“菩萨也在一切三昧中得自在”？

答：有两种三昧：一是佛三昧，二是菩萨三昧。

这些菩萨在菩萨三昧中得自在，不是在佛三昧中。

如《诸佛要集经》中说：

文殊尸利想去见诸佛集会，不能到达。诸佛各自回到本处之后，文殊尸利来到诸佛集会之处，有一位女人在靠近那位佛的地方坐着，入于三昧。文殊尸利进入，礼佛足之后，对佛说：“为什么这位女人能靠近佛坐，而我不能？”

佛告诉文殊尸利：“你唤醒这位女人，使她从三昧中起来，你自己问她。”文殊尸利随即弹指唤她，唤不醒；大声呼喊，也唤不醒；拉着她的手牵她，也唤不醒；又以神足震动三千大千世界，仍然唤不醒。

文殊尸利对佛说：“世尊！我不能使她醒来。”

这时，佛放大光明照耀下方世界，那里有一位菩萨，名叫弃诸盖，随即从下方出来，来到佛所，头面礼佛双足，在一旁站立。

佛告诉弃诸盖菩萨：“你唤醒这位女人！”弃诸盖菩萨随即弹指，这女人就从三昧中起来了。

文殊尸利对佛说：“以什么因缘，我震动三千大千世界，不能使这女人出定；弃诸盖菩萨一弹指，她就从三昧中起来了？”

佛告诉文殊尸利：“你因为这女人而初发阿耨多罗三藐三菩提心，这女人是因为弃诸盖菩萨而初发阿耨多罗三藐三菩提心。所以你不能使她醒来。你在诸佛三昧中的功德还没有圆满。这些菩萨在菩萨三昧中得自在，在佛三昧中只是或多或少地进入，还没有得到自在。”

### 三、释“宝积佛以千叶金色莲华与普明”

【经】

佛告普明：“欲往随意，宜知是时。”

尔时，宝积佛以千叶金色莲华与普明菩萨而告之曰：“善男子！汝以此华散释迦牟尼佛上。生彼娑婆世界诸菩萨，难胜难及，汝当一心游彼世界！”

【论】

#### （一）何言“欲往随意，宜知是时”

问：佛为什么说“欲往随意，宜知是时”？

答：因为佛对弟子的爱已经断除，对弟子心不执着。

再者，这位菩萨还没有得到一切智，还没有得到佛眼，所以心中或多或少有疑惑，认为释迦牟尼佛功德大，所得的利益或许更殊胜，所以对他说：“想去就随意。”

再者，这位菩萨远远看见释迦牟尼佛身形小，心中生起小小的我慢，说那位佛不如这位佛。所以佛告诉他：“你去了，不要看佛身，不要想世界，只听佛说法！”

再者，这个世界离娑婆世界极远，在最东边。这些菩萨听到释迦牟尼佛所说的诸法之相，与宝积佛所说的诸法之相完全相同，就会说：“世界虽然遥远，法相却没有不同！”信心更加增长，心更加坚固。

再者，因为前世的因缘，虽然生在远处，也应当来听法；譬如用绳子系住雀鸟的脚，雀鸟虽然远飞，一收绳子就回来了。

再者，这娑婆世界中的菩萨，看见普明从远处来听法，就会这样想：“他从远处来，何况我生在这个世界中，怎能不听法？”

像这样种种因缘，所以佛说：“欲往随意，宜知是时。”

#### （二）诸佛何以以华为信、相互供养

问：诸佛的力量相等，不再求福，为什么以花作为信物？

答：因为随顺世间法而行；如两位国王力量势力虽然相同，也会互相赠送礼物。

再者，为了显示善良柔和之心，所以以花为信物。世间法中，使者从远方来，必定应当带有信物；佛随顺世间法，所以送去信物。

再者，诸佛恭敬法，所以供养法，以法为师。为什么？因为三世诸佛都以诸法实相为师。

【译注】“三世诸佛，皆以诸法实相为师”，与本卷后文佛初成道时“我行摩诃般若波罗蜜，今自致作佛，是我所尊，即是我师”前后呼应。佛无人可师，所师的是法；诸佛彼此供养，供养的也是法。

问：为什么不供养自己身中的法，而供养他人的法？

答：随顺世间法，如比丘想供养法宝，不供养自己身中的法，而供养其余持法、知法、解法的人；佛也是这样，虽然自己身中有法，却供养其余诸佛的法。

问：如果佛不求福德，为什么要供养？

答：佛从无量阿僧祇劫中修种种功德，常行种种善，不只是为了求果报，而是因为恭敬功德，所以作供养。

如佛在世时，有一位盲比丘，眼睛看不见，用手缝衣服，这时针上的线脱了，他就说：“谁爱福德？为我穿针！”

这时佛来到他那里，对比丘说：“我是爱福德的人，来为你穿针！”

这位比丘认出佛的声音，赶快起身穿好衣服，礼佛双足，对佛说：“佛的功德已经圆满，为什么说爱福德？”

佛回答：“我虽然功德已经圆满，我深知功德之恩、功德的果报、功德的力量，使我在一切众生中得到最第一。因为这功德，所以我爱福德。”

佛为这位比丘赞叹功德之后，接着随顺其意为他说法。这位比丘证得法眼净，肉眼也更加明亮了。

再者，佛虽然功德已经圆满，再无所需，为了教化弟子，对弟子说：“我尚且作功德，你们为什么不作？”

如伎乐之家一位百岁的老翁在跳舞，有人呵斥他说：“老翁已经一百岁了，还跳什么舞？”老翁回答：“我不需要跳舞，只是想教子孙罢了！”佛也是这样，功德虽然圆满，为了教导弟子作功德，所以作供养。

问：如果是这样，宝积佛为什么不自己远远地把花散在释迦牟尼佛上，而要派人去供养？

答：为了让此方诸菩萨信受普明。

再者，佛所派遣的使者，水、火、兵器、毒药等百千种伤害，终究不能伤到他；道路遥远，想让他平安。

#### （三）何以以莲华为信

问：为什么不以好的宝物、深经，或者佛菩萨的宝物（意思是这宝物诸天也见不到，能出生种种妙物，如同摩尼珠宝，所以名为佛宝）作为信物，而用莲华？莲华是小东西，怎么足以作为信物？

答：佛不需要东西，佛宝、天宝尚且不需要，何况人间的宝物？因为不需要，所以不送；也因为佛自己同样都有，所以不送。深经也是这样。

再者，诸经对佛来说并不甚深，“甚深”的称呼出自凡人。凡人所疑惑的，对佛没有障碍；凡人觉得难的，佛都觉得容易。

再者，花香清妙，适宜作为供养；如人献礼赠送，必定用珍异之物。

问：为什么正好用莲华，不用其他东西？

答：供养只用花香、幡盖；花有两件事：有色、有香。

问：其余的花也有香有色，为什么只用莲华供养？

答：如《华手经》中说：十方佛都以花供养释迦文佛。

再者，莲华有三种：一是人间的花，二是天上的花，三是菩萨的花。

人间的花，大的莲华有十余片花叶；天上的花有一百片花叶；菩萨的花有一千片花叶。

那个世界中有很多金色光明的千叶莲华；娑婆世界中只有化现的千叶莲华，没有水中生长的，所以送来。

这莲华有千叶、金色，如上面“舌相”中所说。

#### （四）何以令散佛上

问：佛为什么让普明把花散在佛上？

答：供养之法，有花香、幡盖：幡盖应当悬在上方，干香应当焚烧，湿香应当涂地，末香与花应当散洒。

问：为什么不只是奉上而已，还要亲自散在佛上？

答：亲手供养是身业，以柔和的言语问讯是口业，能发起身、口二业的是意业。

这三业所得的功德牢固，为佛道作因缘。

#### （五）何言“一心敬慎”：优波鞠与老比丘尼

问：为什么说“你应当一心敬慎，娑婆世界中的诸菩萨难及难胜”？

答：佛、辟支佛、阿罗汉等一切贤圣，都一心敬慎。

魔、魔民，以及内身的结使，种种前世的罪报，都是盗贼；因为接近这些盗贼，所以应当一心敬慎；譬如走在盗贼之中，如果不自己谨慎防护，就会被盗贼所擒。

所以说“一心敬慎，以游彼界”。

再者，因为人心大多散乱，如狂如醉；一心敬慎，就是种种功德的初门。

摄心就得禅定，得禅定就得真实智慧，得真实智慧就得解脱，得解脱就能尽苦。像这样的事，都从一心而得。

如佛般涅槃后一百年，有一位比丘名叫优波鞠，是得六神通的阿罗汉，在当时是阎浮提的大导师。

那时有一位比丘尼，年一百二十岁，这位比丘尼年少时见过佛。

优波鞠要到她的住处，想问佛的容貌仪态，先派弟子去。弟子对比丘尼说：“我的大师优波鞠想来见你，问佛的容貌仪态。”

这时，比丘尼用钵盛满麻油，放在门扇下面，来试验优波鞠，看他的威仪是否安详审慎。

优波鞠进门，缓缓推开门扇，麻油洒出了少许。

坐下之后，优波鞠问比丘尼：“你见过佛吗？佛的容貌仪态是怎样的？请为我说说！”

比丘尼回答：“我那时年纪小，看见佛来到村落，众人说佛来了，我也随众人出去，看见光明就礼拜。头上的金钗掉在地上，在很暗的树林下面，佛的光明照过来，幽暗隐蔽之处全都看得见，当即找到了金钗。从那以后，我就作了比丘尼。”

优波鞠又问：“佛在世时，比丘的威仪礼法是怎样的？”

比丘尼回答：“佛在世时，六群比丘无羞无耻，最为弊恶；然而威仪法则胜过你今天，怎么知道呢？六群比丘进门不会使油洒出来。这些人虽然弊恶，却知道比丘的仪法，行、住、坐、卧，不失法则；你虽然是六神通阿罗汉，却不如他们！”

优波鞠听了这话，非常惭愧！

所以说“一心敬慎”。

一心敬慎，是善人之相。

#### （六）娑婆菩萨何以难近

再者，为什么说“一心敬慎，这些菩萨难胜难及，难破难近”？

譬如大狮子王，难胜难破；又如白象王与龙王，如同大火焰，都难以接近。

这些菩萨因为有大福德智慧之力，如果有人想胜过他们、破坏他们，是不可能的，只会自己被破，所以说“难近”。

问：一切大菩萨都有大功德，智慧根利，都难以接近，为什么唯独说“娑婆世界中的菩萨难近”？

答：确实如你所说。

只是因为多宝世界中的菩萨从远方来，看见这个世界不如自己的世界，石沙秽恶，菩萨身形小，一切事都不如，必定会生起轻慢，所以佛说：“一心敬慎，那些菩萨难以接近。”

再者，生在快乐之处的人，大多不勇猛、不聪明、少智慧。如郁怛罗卫的人，因为太快乐，没有出家，没有受戒；诸天中也是这样。

这娑婆世界中，快乐的因缘少，有三恶道、老病死，在这片土地上谋生的方法艰难，所以容易生起厌离心。

见到老、病、死到来，心中大为厌患；见到贫穷的人，知道是前世因缘所致，心中生起很大的厌离。所以智慧根性锐利。

那里的菩萨，在七宝世界中，有种种宝树，心中想要饮食，随意就能得到，像这样就很难生起厌离心，所以智慧不能非常锐利。

譬如锋利的刀，放在好的饮食中，刀就会生出污垢，饮食虽好，却与刀不相宜；如果用石头磨刀，用油脂与灰擦拭磨亮，污垢除去，刀就锋利了。这些菩萨也是这样，生在杂恶的世界中，智慧锐利，难以接近。如人从小勤苦，就多有所能，也多有所堪；又如养马而不骑，马就什么也承担不了。

再者，这娑婆世界中的菩萨，方便多，所以难近，其他地方不是这样。

如佛说：“我自己忆念宿世，一天之中以千条性命布施他人。为了度化众生，虽然种种功德、六波罗蜜等一切佛事都已具足，却不作佛，常以方便度脱众生。”

因为这件事，所以“这娑婆世界中的菩萨难以接近”。

### 四、释“普明与诸菩萨、童男童女俱共发引”

【经】

尔时，普明菩萨从宝积佛受千叶金色莲花，与无数出家、在家菩萨，及诸童男、童女，俱共发引。

【论】

#### （一）凭谁之力而来

问：这位普明菩萨有大力神通，所以应当能来；这些出家、在家菩萨以及童男、童女，怎能自己来到？

多宝世界在最东边，路途遥远，是用自己的力量来的？

是宝积佛的力量？

是普明菩萨的力量？

还是释迦牟尼佛的力量？

答：是这四种力量都有。

这些出家、在家菩萨，有的是不退转、成就五神通的菩萨，有四如意足，好好修习过前世与释迦牟尼佛的因缘，也用自己的力量；也是普明菩萨的力量。为什么？这其中力量弱小的，因为普明菩萨的力量，所以能来。如转轮圣王飞上天时，四种兵以及种种宫殿、畜兽，一切都随之飞起；因为转轮圣王功德大，能使一切都随从飞行。这里也是这样，力量弱小的，因为普明菩萨的力量，也都能来。

也是宝积佛的力量，以及释迦牟尼佛的光明照耀。

如果自己没有力量，只要有释迦牟尼佛的光明照耀，也应当能来，何况有三种力量！

#### （二）何以多将眷属

问：这位普明菩萨为什么不独自来，而要带着很多人？

答：因为随从翼护是适宜的；譬如国王出行时，必定有随从。

再者，这些人是与普明菩萨及释迦牟尼佛有因缘的人。为什么？那大众之中有两类人一同来，所以知道有因缘的来，没有因缘的留下。

#### （三）七众与童男童女

问：这位菩萨为什么与在家、出家人以及童男、童女一同来？

答：佛的弟子有七众：比丘、比丘尼、学戒尼、沙弥、沙弥尼、优婆塞、优婆夷。

优婆塞、优婆夷是在家人，其余五众是出家人。

出家与在家之中又有两种：大的与小的。小的，就是童男、童女；其余的是大的。

问：大的应当来，小的怎能来？

答：在于功德，不在于大小。如果失去功德之利，行不善法，即使年老也是小；如果有功德之利，行善法，即使年小也是大。

再者，这些小孩子从远处来，人们见了就赞叹：这么小就能这样，为了法远道而来！也显示佛法不论大小都可以奉行。外道法中，婆罗门才能修行其法，不是婆罗门就不能修行；佛法没有大小、没有内外，一切人都可以修行。

譬如服药，以除病为主，不选择贵贱大小。

### 五、释“供养东方诸佛”

【经】

皆供养、恭敬、尊重、赞叹东方诸佛。

【论】

#### （一）菩萨供养法

问：如果都要供养东方诸佛，诸佛非常多，什么时候才能供养完，来到此方？

答：这些菩萨不是用人、天的方式供养，而是自行菩萨的供养之法。

菩萨的供养之法，是身入禅定，身体一直向前行进，从身边化出无量的身，化作种种供养之物，充满诸佛世界。譬如龙王行走时，从身上出水，普遍降雨于天下。

#### （二）中途何以供养诸佛：药王菩萨燃身

问：这些菩萨要去见释迦牟尼佛，为什么在中途供养诸佛？

答：诸佛是第一福田，如果供养，就得大果报。譬如人广泛耕种田地，是为了多得谷物。

诸菩萨看到供养诸佛能得佛果之报，所以供养。

再者，菩萨常敬重佛，如同人敬重父母。诸菩萨蒙佛说法，得到种种三昧、种种陀罗尼、种种神力，知恩，所以广作供养。如《法华经》中说：

药王菩萨从佛那里得到一切变现色身三昧，这样思惟：“我应当怎样供养佛与法华三昧？”

随即飞到天上，以三昧之力，降下七宝、花香、幡盖，供养佛。出了三昧之后，心意还不满足。在一千二百年中，服食种种香，饮种种香油，然后用天上的白毡缠身而焚烧，自己立誓说：“使我身体的光明，照耀八十恒河沙等佛世界！”

这八十恒河沙等世界中的诸佛赞叹说：

“善哉！善哉！善男子！以身供养，这是第一！胜过以国城妻子供养百千万倍，不可以譬喻来比拟。”药王菩萨的身体燃烧了一千二百年都没有熄灭。

再者，供养佛能得到无量的名声与福德利益，种种不善之事都能灭除，种种善根得以增长，今世、后世常得供养的果报，久后得以作佛。

像这样供养佛，得到种种无量的利益。所以诸菩萨供养佛。

### 六、释“到已，头面礼佛足，一面立”

【经】

持诸华香、璎珞、末香、泽香、烧香、涂香、衣服、幢盖，向释迦牟尼佛所。

到已，头面礼佛足，一面立。

【论】

#### （一）头面礼足

问：应当说“礼”，为什么名为“头面礼足”？

答：人身中第一尊贵的是头，五根所依附，而且在最上面；脚是第一卑贱的，踩在不净之处，在最下面。

所以以最尊贵的去礼最卑贱的，是为了尊重供养。

再者，礼有下、中、上：下等是作揖，中等是跪拜，上等是稽首；头面礼足，是上等的供养。

所以佛的毗尼中，下座比丘以两手捧着上座比丘的双足，以头面礼拜。

#### （二）何以一面立

问：有四种身体威仪：坐、立、行、卧，为什么“在一旁站立”？

答：因为是来到这里，所以不应当行走；因为是恭敬供养，所以不应当躺卧，这件事很容易明白，何必问？应当问的是“或坐或立”。

坐，对于供养来说不够庄重；立，是恭敬供养之法。

再者，在佛法中，诸外道出家人以及一切在家人，来到佛所都坐下。

外道是他宗之法，轻视佛，所以坐；在家人如同客人，所以坐；一切五众弟子身心都归属于佛，所以站立。

如果是已得道的诸阿罗汉，如舍利弗、目连、须菩提等，所作已办，所以允许坐；其余的人虽然证得前三果，也不允许坐，因为大事还没有办完，结使之贼还没有破除。譬如国王的臣子，有大功勋才能得座。这些菩萨中虽然有在家人，因为从远方来供养佛，所以站立。

### 七、释“宝积如来致问世尊”

【经】

白佛言：“宝积如来致问世尊：少恼、少患、兴居轻利，气力安乐不？”又以此千叶金色莲华，供养世尊。

【论】

#### （一）佛一切智，何以问讯

问：宝积佛具一切智，为什么还要“问讯释迦牟尼佛少恼、少患，兴居轻利，气力安乐不”？

答：诸佛之法本来就是这样，知道了还故意问。

如毗尼中，达贰迦比丘建造了一座赤色的瓦窟，佛看见后，明知而问：“阿难！这造的是什么？”

阿难对佛说：“这是陶匠之子出家，名叫达贰迦，建造了小草屋，常被放牛的人破坏，三次建造三次被破坏，所以造了这座瓦屋。”

佛对阿难说：“拆掉这座瓦窟！为什么？外道们会说：佛大师在世时，就有了漏失之法！”

像这样，处处都是明知而故问。

再者，佛虽然具一切智，随顺世间法，世人互相问讯，佛也问讯；佛生在人间，受人间之法，寒热、生死与人相同，问讯之法也应当相同。

再者，世间中极贵与极贱之人不应当互相问讯；诸佛力量相等，所以应当互相问讯。

再者，这多宝世界清净庄严，佛身的色像光明也大，如果不问讯，人们会认为是轻慢。

又想显示诸佛世界、身色、光明虽然种种殊胜，智慧、神力却都相等，没有差别，所以问讯。

#### （二）问讯诸语之义

问：为什么问“少病少恼吗”？

答：有两种病：一是外因缘的病，二是内因缘的病。

外在的，如寒热、饥渴、兵刃、刀杖、坠落、塌压，像这样等等种种外在的祸患，名为恼。

内在的，如饮食不节制，起卧无规律，四百零四种病，像这样等等种种，名为内病。

这两种病，凡有身体都会受苦，所以问“少恼、少患吗”。

问：为什么不问“无恼、无病”，而问“少恼、少患”？

答：圣人确实知道“身体是苦的根本，没有不病的时候”。为什么？

这是四大和合而成身体。地、水、火、风，性质不相宜，各自互相伤害。譬如毒疮，没有不痛的时候，如果用药涂抹，可以稍稍减轻，却不能痊愈；人身也是这样，常病常治，治了才能活，不治就死。所以不能问“无恼、无病”。

外在的祸患，常有风、雨、寒、热为恼。

又有身体的四种威仪：坐、卧、行、住，久坐就极为疲恼，久卧、久住、久行都会疲恼。所以问“少恼、少患”。

问：问“少恼、少患”就够了，为什么又说“兴居轻利”？

答：人虽然病好了，还没有完全恢复，所以问“兴居轻利”。

问：为什么说“气力安乐吗”？

答：有人病好了，虽然能行走坐起，气力还不足，不能办事、作为，提轻举重，所以问“气力”。

有人虽然病好了，能举重提轻，却还没有得到安乐，所以问“安乐吗”。

问：如果没有病、有气力，为什么还没有得到安乐？

答：有人贫穷、恐怖、忧愁，不得安乐，所以问“得安乐吗”。

再者，有两种问讯之法：问讯身体，问讯心。

如果说“少恼、少病，兴居轻利，以及气力”，这是问讯身体。

如果说“安乐吗”，这是问讯心。

种种内外的病，名为身病；淫欲、瞋恚、嫉妒、悭贪、忧愁、怖畏等种种烦恼，九十八结，五百缠，种种欲愿等，名为心病。

为了逐一问讯这些病，所以说“少恼、少病，兴居轻利，气力安乐吗”。

#### （三）佛何以受人法问讯

问：人与人问讯应当这样，诸天尚且不应当这样问讯，何况是佛？

答：佛身有两种：一是神通变化身，二是父母所生身。

父母所生身，受人间之法，不如天身，所以应当依人间之法问讯。

问：一切贤圣心无所著，不贪恋身体，不吝惜寿命，不厌恶死，不喜悦生，如果是这样，何必问讯？

答：因为随顺世间法，所以受人间之法的问讯。宝积佛派人问讯，也是依人间之法。

“千叶金色莲华”，如上面所说。

### 八、释“释迦牟尼佛受华，散东方诸佛”

【经】

尔时，释迦牟尼佛受是千叶金色莲华已，散东方恒河沙等世界中佛。

【论】

#### （一）佛无胜者，何以供养诸佛

问：佛没有能胜过的，如今为什么向东方诸佛散花供养？

如佛初得道时，自己心想：“人如果没有所尊敬的，事业就不能成就，现在十方天地中谁可以尊敬奉事，我想以之为师而奉事？”

这时，梵天王等诸天对佛说：“佛是无上的，没有超过佛的。”

佛也自己以天眼观察三世十方天地，没有胜过佛的，心中自己想：“我修行摩诃般若波罗蜜，如今自己成就作佛，这就是我所尊敬的，就是我的老师，我应当恭敬、供养、尊事这法。”

譬如有一种树，名叫好坚，这树在地中一百年，枝叶都已具足，一天之中长出地面，高达一百丈；这树长出之后，想找一棵大树来荫蔽自己。这时林中有一位神对好坚树说：“世上没有比你更大的，众树都应当在你的荫蔽之下。”

佛也是这样，无量阿僧祇劫在菩萨地中生长，一天在菩提树下金刚座上坐，如实知道一切诸法之相，成就佛道。这时自己心想：“谁可以尊事作为老师，我应当承事、恭敬、供养。”

这时，梵天王等诸天对佛说：“佛是无上的，没有超过佛的。”

如今为什么还要供养东方诸佛？

答：佛虽然无上，三世十方天地中没有超过佛的，却行供养。供养有上、中、下：

供养不如自己的，是下等供养；供养胜过自己的，是上等供养；供养与自己相等的，是中等供养。

诸佛互相供养，是中等供养。

如大爱道比丘尼与五百位阿罗汉比丘尼等，在同一天的同一时间入涅槃。

这时，证得三果的诸位优婆塞抬起五百张床；四天王抬起佛的乳母大爱道的床；佛亲自在前面捧着香炉烧香供养。

佛对比丘们说：“你们帮我供养乳母之身。”

那时，诸阿罗汉比丘各自以神足之力，到摩梨山上取来牛头栴檀香木，帮佛堆积火化的柴堆，这是下等供养。

所以，佛虽然不求果报，却行平等的供养。

再者，唯有佛应当供养佛，其余的人不知道佛的功德。如偈中说：

```
智人能敬智，　智论则智喜；
智人能知智，　如蛇知蛇足！
```

大意：有智慧的人能尊敬智慧，谈论智慧时，有智慧的人就欢喜；有智慧的人能了知智慧，如同蛇知道蛇的足迹！

所以诸佛的一切智，能供养一切智。

#### （二）十方诸佛世世劝助：七住菩萨欲入涅槃

再者，这十方诸佛世世劝助释迦牟尼佛。

如七住菩萨，观察诸法空无所有，不生不灭。

这样观察之后，在一切世界中心不执着，想放舍六波罗蜜而入涅槃。譬如有人在梦中造筏，渡大河，手脚疲劳，生起厌患之想。在河中央时从梦中醒来，自己心想：“哪里有河可渡？”这时，勤劳之心全都放下了。

菩萨也是这样，立于七住之中，得无生法忍，心行都止息了，想入涅槃。

那时，十方诸佛都放光明，照耀菩萨之身，以右手摩菩萨的头，说：“善男子！不要生起这样的心！你应当忆念你的本愿，想要度化众生。

“你虽然知道空，众生却不理解，你应当积集种种功德，教化众生，共同入涅槃！

“你还没有得到金色身、三十二相、八十种随形好、无量光明、三十二业。

“你现在才刚得到一个无生法门，不要就这样大欢喜！”

这时，菩萨听了诸佛的教诲，又生起本来的心，修行六波罗蜜以度化众生。

【译注】七住菩萨得无生法忍后“欲入涅槃”，是大乘菩萨道上最关键的一处险关：证空越深，越容易像梦中渡河者醒来一般，觉得无河可渡、无人可度。十方诸佛摩顶的三句话，正是对治这一关的：念本愿，众生未解，汝今始得一无生法门。所以诸佛对释迦牟尼佛有劝助之恩。

像这样，在初得佛道时，得到这样的佐助。

#### （三）分一法为三乘，十方诸佛赞叹

又佛初得道时，心中思惟：“这法甚深，众生愚蒙福薄，我又生在五恶之世，现在该怎么办？”想完，心想：我应当把一法分作三分，分为三乘来度化众生。

正这样思惟时，十方诸佛都显现光明，赞叹说：“善哉！善哉！我们也在五恶世中，把一法分作三分来度化众生。”

这时，佛听到十方诸佛的话音，随即大为欢喜，称念：“南无佛！”

像这样，十方佛处处劝助，为佛作大利益；因为知恩深重，所以供养。

#### （四）二俱清净之施，福德最大

以花供养十方佛，是最上的福德，没有超过这福德的。为什么？这花是宝积佛的功德力所生，不是水中生长的花。

普明是十住法身菩萨，送这花来，奉上释迦牟尼佛。

释迦牟尼佛知道十方佛是第一福田，所以以此供养，这福德加倍更多。为什么？因为是佛亲自供养佛。

佛法中有四种布施：一是施者清净，受者不清净；二是施者不清净，受者清净；三是施者清净，受者也清净；四是施者不清净，受者也不清净。

现在施给东方诸佛，这是施受二者都清净，这福德最大。

所以佛亲自供养十方佛。

问：一切圣人不受果报，以后不再受生，为什么说这布施的福德最大？

答：这福德虽然没有人受，其相自然是大的；如果有人受，其果报无量。

诸圣人知道有为法都是无常、空的，所以舍弃而入涅槃，这福德也一并舍弃；譬如烧红的金丸，虽然眼睛看着美好，却不能用手触摸，因为会烧伤人手。

再者，如人有疮，就需要用药涂抹；如果没有疮，药就无处可用。人有身体也是这样，常被饥、渴、寒、热所逼迫，也如同疮发作；用衣被饮食，温暖调适，如同用药涂疮。

如愚痴的人，因为贪着药，就不去除疮；如果没有疮，药也就没有用。

诸佛以身体为疮，舍弃了身体这个疮，所以也不受果报之药。

所以，虽然有大福德，也不受果报。

### 九、释“所散莲华满东方世界，华上菩萨说六度”

【经】

所散莲华，满东方如恒河沙等诸佛世界。

【论】

问：花少而世界多，怎能充满？

答：因为佛的神通力，如上面所说八种自在变化之法：

大能使之变小，小能使之变大，轻能使之变重，重能使之变轻，自在无碍，随意所到，能震动大地，所愿都能成办。

诸大圣人都得到这八种自在，所以佛能以少许的花充满东方如恒河沙等世界。

又以此向众生显示未来的福报，如同这少许的花，充满东方世界。

又劝勉东方的菩萨，说：“在佛田中种福，所得的果报，也如同这些花遍满无量国土；你们虽然从远方来，应当欢喜，遇到这大福田，果报无量！”

【经】

一一华上皆有菩萨，结跏趺坐说六波罗蜜；闻此法者，毕至阿耨多罗三藐三菩提。

【论】

问：上面佛以舌相光明化作千叶宝华，每一朵花上都有坐着的佛；现在为什么每一朵花上都有坐着的菩萨？

答：上面是佛所化的花，所以有坐着的佛；这是普明菩萨所供养的花，所以有坐着的菩萨。

再者，上面的众生应当见到坐佛而得度；现在这些众生应当见到坐着的菩萨而得度。

结跏趺坐，说六波罗蜜，听闻此法的人终究到达阿耨多罗三藐三菩提，如先前所说。

### 十、释“诸菩萨、童男童女供养释迦牟尼佛”

【经】

诸出家、在家菩萨，及诸童男、童女，头面礼释迦牟尼佛足，各以供养具，供养恭敬，尊重赞叹释迦牟尼佛。

是诸出家、在家菩萨，及诸童男、童女，各各以善根福德力故，得供养释迦牟尼佛多陀阿伽度、阿罗呵、三藐三佛陀。

【论】

如偈中说：

```
诸圣所来道，　佛亦如是来；
实相及所去，　佛亦尔无异；
诸圣如实语，　佛亦如实说：
以是故名佛，　多陀阿伽度。
忍铠心坚固，　精进弓力强，
智慧利劲箭，　破憍慢诸贼。
应受天世人，　一切诸供养，
以是故名佛，　以为阿罗诃。
正知苦实相，　亦实知苦集，
知苦灭实相，　亦知苦灭道。
真正解四谛，　定实不可变，
是故十方中，　号三藐三佛。
得微妙三明，　清净行亦具，
是故号世尊，　鞞阇遮罗那。
解知一切法，　自得妙道去，
或时方便说，　愍念一切故。
灭除老病死，　令到安隐处，
以是故名佛，　以为修伽陀。
知世所从来，　亦知世灭道，
以是故名佛，　为路迦鞞陀。
禅戒智等眼，　无及况出上，
以是故名佛，　为阿耨多罗。
大悲度众生，　软善教调御，
以是故名佛，　富楼沙昙藐。
智慧无烦恼，　说最上解脱，
以是故名佛，　提婆摩奴舍。
三世动不动，　尽及不尽法，
道树下悉知，　是故名为佛。
```

大意：诸圣者从哪条道路来，佛也从这条道路来；实相与所去之处，佛也是这样，没有不同；诸圣者说如实之语，佛也如实宣说，所以名为多陀阿伽度（如来）。以忍辱为铠甲，心坚固；以精进为弓，力量强大；以智慧为锐利有力的箭，破除憍慢等种种盗贼；应当受天上世间一切的供养，所以名为阿罗诃（应供）。正确知道苦的实相，也如实知道苦的集起，知道苦灭的实相，也知道苦灭之道；真正理解四谛，确定真实、不可改变，所以在十方之中号为三藐三佛（正遍知）。得到微妙的三明，清净之行也具足，所以号为鞞阇遮罗那（明行足）。理解一切法，自己得到妙道而去，有时以方便说法，因为怜悯一切众生；灭除老病死，使众生到达安稳之处，所以名为修伽陀（善逝）。知道世间从哪里来，也知道世间灭尽之道，所以名为路迦鞞陀（世间解）。在禅定、持戒、智慧等方面，无人能及，何况超过，所以名为阿耨多罗（无上士）。以大悲度化众生，以柔和善巧教导调御，所以名为富楼沙昙藐（调御丈夫）。智慧而无烦恼，宣说最上的解脱，所以名为提婆摩奴舍（天人师；“奴”字原文作一罕见字）。三世之中动与不动、尽与不尽之法，在菩提树下全都知道，所以名为佛。

### 十一、释南、西、北、下、上五方诸菩萨来

【经】

南方度如恒河沙等诸佛世界，其土最在边，世界名离一切忧，佛号无忧德，菩萨名离忧。

西方度如恒河沙等诸佛世界，其世界最在边，世界名灭恶，佛号宝山，菩萨名仪意。

北方度如恒河沙等诸佛世界，其世界最在边，世界名胜，佛号胜王，菩萨名得胜。

下方度如恒河沙等诸佛世界，其世界最在边，世界名善，佛号善德，菩萨名华上。

上方度如恒河沙等诸佛世界，其世界最在边，世界名喜，佛号喜德，菩萨名得喜。

如是一切，皆如东方。

【论】

#### 破“方”为实法

问：如佛法中，实际上没有诸方的名称。为什么？方不被五众、十二入、十八界所摄，四法藏中也没有。

说方是实法，以因缘去寻求也不可得，现在为什么这里说十方诸佛、十方菩萨来？

答：因为随顺世俗法所流传，所以说“方”；寻求“方”的实体，是不可得的。

问：为什么说没有方？你的四法藏中不说，我的六法藏（胜论的六句义）中说。

你的众、入、界中不摄，我的陀罗骠（实体）中摄。

这“方”法，因为有常相，因为有相，所以既是有，也是常。如经中说：“日出之处是东方，日没之处是西方，日行之处是南方，日不行之处是北方。”

太阳有三分相合：或者先前相合，或者现在相合，或者以后相合。随着方位与太阳的分合，最初相合的是东方，南方、西方也是这样。太阳不行之处是无分。

彼处与此处，彼与此是“方相”；如果没有“方”，就没有彼与此；彼与此是“方相”，而不是“方”本身。

答：不对！须弥山在四洲之中，太阳绕着须弥山运行，照耀四天下：

郁怛罗越正当日中时，正是弗婆提日出之时，对弗婆提人来说是东方；弗婆提正当日中时，正是阎浮提日出之时，对阎浮提人来说是东方。

这实际上没有开端，为什么？因为一切方都是东方，都是南方，都是西方，都是北方。

你说“日出之处是东方，日行之处是南方，日没之处是西方，日不行之处是北方”，这件事不对！

再者，有的地方太阳不与之相合，这就不是“方”，因为没有“方相”。

问：我说的是一个国家中的“方相”，你用四个国家来质难，所以东方并非没有开端。

答：如果在一个国家中，太阳与东方相合，这就是有边；因为有边，所以无常；因为无常，所以不能周遍。

所以，“方”只有名称而没有实体。

### 十二、释“三千大千世界变成为宝”

【经】

尔时，是三千大千世界，变成为宝，华遍覆地，悬缯幡盖，香树、华树，皆悉庄严。

【论】

#### （一）谁之神力，为何庄严

问：这是谁的神力，使大地成为宝地？

答：这是佛无量神力的变化所为。

有人以咒术、幻法，以及诸鬼神、龙王、诸天等，能变化少许事物；使三千大千世界都成为珍宝，其余的人以及梵天王都不能做到。

佛进入四禅中的十四种变化心，能使三千大千世界的花香树木、一切土地都庄严起来；使一切众生都和睦同心，心转为善。为什么？

庄严这个世界，是为了宣说般若波罗蜜。

也是为了十方诸菩萨作为客人到来，以及诸天与世人，所以庄严。

如人邀请贵客，如果是一家邀请，就庄严一家；如果是一国之主，就庄严一国；如果是转轮圣王，就庄严四天下；如果是梵天王，就庄严三千大千世界。佛是十方无量恒河沙等诸世界之主，因为这些他方菩萨以及诸天、世人作为客人到来，所以庄严。

也是为了使此方与彼方的众人见到这变化庄严，就生起大心，生起清净欢喜之心；从大心发起大业，从大业得到大报，受大报时又生起大心，像这样辗转增长，得以成就阿耨多罗三藐三菩提。

所以把这世界全都变为宝。

#### （二）宝的种类与出处

什么名为宝？

宝有四种：金、银、毗琉璃、颇梨。

又有七种宝：金、银、毗琉璃、颇梨、砗磲、玛瑙、赤真珠（这种珠极为珍贵，不是珊瑚）。

又有宝物：摩罗伽陀（这珠从金翅鸟口边出来，绿色，能避一切毒）、因陀尼罗（天青珠）、摩诃尼啰（大青珠）、钵摩罗伽（赤光珠）、越阇（金刚）、龙珠、如意珠、玉贝、珊瑚、琥珀等种种，名为宝。

这宝有三种：人宝、天宝、菩萨宝。

人宝力量小，只有清净的光色，能除毒、除鬼、除暗，也能除去饥、渴、寒、热等种种苦事。

天宝也大，也胜过常物，随逐天身，可以使唤，可以与之说话，轻而不重。

菩萨宝胜过天宝，能兼有人宝、天宝的作用；又能使一切众生知道在此处死、在彼处生的因缘本末，譬如明镜照见面像。

再者，菩萨宝殊胜，能发出种种法音；如果用作首饰宝冠，就能向十方无量世界诸佛上方降下幢幡、花盖等种种供养之具，以供养佛。

又能降下衣被、卧具等生活所需之物，种种事物，随众生所需全都降下，施给众生；像这样等等种种宝物，用来除去众生的贫穷苦厄。

问：这些珍宝从哪里出产？

答：金子出自山石、沙子、赤铜中，真珠出自鱼腹中、竹中、蛇脑中，龙珠出自龙脑中，珊瑚出自海中的石树，生贝出自虫类的甲壳中，银子出自冶炼的矿石，其余琉璃、颇梨等都出自山洞中。

如意珠出自佛舍利；如果佛法灭尽时，诸舍利都会变为如意珠；譬如超过千年的冰，化为颇梨珠。

像这样等等宝物，是人间常有的宝物。

佛所庄严的一切世界，最为殊胜，是诸天所不能得到的。为什么？因为是从大功德所生。

种种花与幡，如先前所说。

所谓“香树”，名为阿伽楼（蜜香树）、多伽楼（木香树）、栴檀，像这样等等种种香树。

所谓“华树”，名为占匍（黄花树）、阿输迦（无忧花树）、婆呵迦罗（赤花树），像这样等等种种花树。

### 十三、释“譬如华积世界”

【经】

譬如华积世界，普华世界，妙德菩萨，善住意菩萨，及余大威神诸菩萨，皆在彼住。

【论】

问：为什么说“譬如华积世界”？

答：那个世界常有清净的花，这个世界只是一时变化，所以用来作比喻。

譬喻之法，是以小喻大。如人面容美好，譬如满月。

问：还有十方其他清净世界，如阿弥陀佛的安乐世界等，为什么只以普华世界为比喻？

答：阿弥陀佛的世界不如华积世界。为什么？法积比丘，佛虽然带他到十方观看清净世界，因为他的功德力薄，不能见到上妙的清净世界，所以他所成就的世界不如华积世界。

再者，当佛变化这个世界时，正好与华积世界相似。所以说“譬如华积世界”。

问：还有其余的大菩萨，如维摩诘、观世音、遍吉菩萨等，为什么不说这些菩萨住在那里，而只说文殊尸利、善住意菩萨？

答：这位遍吉菩萨，每一个毛孔中常现出诸佛世界以及诸佛菩萨，遍满十方以教化众生，没有固定的住处。文殊尸利分身变化进入五道之中，或者作声闻，或者作缘觉，或者作佛身，如《首楞严三昧经》中说：“文殊师利菩萨过去世作龙种尊佛”，“七十二亿世作辟支迦佛”，这是可以言说的。

遍吉菩萨不可测量、不可言说，住处不可知；如果说住，就应当在一切世界中住，所以不说。

再者，“及诸大威神菩萨”，也应当是总括地说遍吉等诸大菩萨。

### 十四、释“一切世界众皆集”

【经】

尔时，佛知一切世界，若天世界，若魔世界，若梵世界；若沙门、若婆罗门、及天，若揵闼婆、人、阿修罗等，及诸菩萨摩诃萨绍尊位者一切皆集。

【论】

#### （一）何以不尽来

问：佛的神力无量，十方一切众生如果全都来会，一切世界就应当空了；如果不来，佛的无量神力就有做不到的！

答：不应当全都来。为什么？

诸佛世界无边无量，如果全都来了，就成为有边。

又十方各有佛，也在宣说般若波罗蜜。如那部《般若波罗蜜经·四十三品》中说：“十方各有千佛显现，都在宣说般若波罗蜜。”所以不应当全都来。

问：如果十方诸佛都在说般若波罗蜜，十方诸菩萨为什么还要来？

答：如“普明菩萨来”一章中已经说过，是因为与释迦牟尼佛有因缘所以来。

再者，这些菩萨有本愿：如果有宣说般若波罗蜜的地方，我应当去听受、供养，所以远道而来。

想以身体之力积集功德；也向众生显示：“我从远方来供养法，你在这个世界中，为什么不供养？”

问：佛对法不执着，为什么七次显现神力而使众生大集？

答：这般若波罗蜜甚深，难知难解，不可思议，所以广集诸大菩萨，使新发意的人心中得到信乐。譬如小人所说的话不被人相信，贵重的大人说的话，人们必定信受。

#### （二）天、魔、梵三世界

问：为什么说“若天世界，若魔世界，若梵世界”？只应当说“天世界、人世界”就够了。为什么？十号中说“天人师”，所以应当只说“天、人”而已。

答：诸天有天眼、天耳，根性锐利，智慧多，自己知道要来，所以说“天世界”。

问：如果天世界已经摄入魔与梵，为什么另外说“若魔、若梵”？

答：天中有三位大主：释提婆那民，是两处天的天主；魔王，是六欲天之主；梵世界中，大梵天王为主。

问：如夜摩天、兜率陀天、化乐天都有天主，为什么只说三位天主？

答：释提婆那民依地而住，佛也在地上住，他常来佛所，很有名声，人们大多认识他。

魔王常来扰乱佛，又是一切欲界之主；夜摩天、兜率陀天、化乐天都隶属于魔王。

再者，说天世界，三界之天都摄在其中；一切欲界以魔为主，所以另外说。

再者，魔常扰乱佛，如今来听般若波罗蜜，其余的人信心就更加增长。

问：色界中有很多天，为什么只说“梵世界集”？

答：上面诸天没有觉观，不喜欢散乱之心，又难以听闻。

梵世界有四种识，容易听闻。又因为梵世界近。

再者，梵名为离欲清净，现在说梵世界，已经总括地说了色界诸天。

再者，其余的天还没有人民时，劫初生成之际，梵天王独自在梵宫中，寂寞无人，心中不悦，自己生起念头：“这里为什么不生出人民？”这时光音天寿命已尽的天人，随着梵王的念头来此受生。

梵王就自己心想：“这些天人先前没有，随着我的念头而生，是我能生出这些天人。”

诸天这时也各自心想：“我们从梵王而生，梵王是我们的父亲。”

所以只说“梵世界”。

再者，二禅、三禅、四禅的天人，在欲界见佛听法，或者劝助菩萨，所用的眼识、耳识、身识都在梵世界中取。所以另外说“梵世界”。

#### （三）沙门、婆罗门与天

问：为什么只说“诸沙门、婆罗门”，不说国王、长者以及其余人众？

答：有智慧的人分为两类：沙门与婆罗门。

出家的名为沙门，在家的名为婆罗门。其余的人心存世间的快乐，所以不说。

婆罗门大多学习智慧、求福，出家人一切都为了求道，所以只说沙门、婆罗门。

在家之中七世清净，生满六岁都受戒，名为婆罗门。

这些沙门、婆罗门中有道德智慧，所以说。

问：先前已经说了天世界，现在为什么又说“天”？

答：天世界是四天王天、忉利天；魔是他化自在天；梵是色界。

现在说“天”，是欲界中的夜摩天、兜率陀天、化乐天、爱身天等；爱身天在六欲天之上，形色极其美妙，所以名为爱身。

#### （四）揵闼婆、人、阿修罗

问：为什么只说“揵闼婆”，不说其余的鬼神以及龙王？

答：这揵闼婆是诸天的乐师，随逐诸天，心性柔软，福德力量比诸天稍小。

诸鬼神，归在鬼神道中；龙王，归在畜生道中。

甄陀罗也是天上的乐师，都隶属于天，与天同住共坐，饮食伎乐都与天相同。

这揵闼婆王名叫童笼磨（汉语意为树）。

这揵闼婆、甄陀罗常在两处居住，平常居住在十宝山之间；有时到天上为诸天奏乐，这两种常常轮番上下。

人生在四天下，生有四种，寿命最长的乃至无量岁，最短的乃至十岁。

阿修罗心恶好斗，却不破戒，大修布施之福，生在大海边居住，也有城郭宫殿。

这阿修罗王名叫毗摩质多、婆梨、罗睺罗，像这样等等名为阿修罗王。

如经中说：

有一次，罗睺罗阿修罗王想要吞食月亮，月天子恐惧，急速来到佛所，说偈：

```
大智成就佛世尊，　我今归命稽首礼；
是罗睺罗恼乱我，　愿佛怜愍见救护！
```

大意：大智成就的佛世尊，我如今归命稽首礼敬；这罗睺罗恼乱我，愿佛怜悯，救护我！

佛对罗睺罗说偈：

```
月能照暗而清凉，　是虚空中大灯明，
其色白净有千光，　汝莫吞月疾放去！
```

大意：月亮能照亮黑暗而且清凉，是虚空中的大灯明，颜色洁白清净，有千道光芒，你不要吞月，赶快放开！

这时，罗睺罗恐惧流汗，随即急忙放开月亮。

婆梨阿修罗王看见罗睺罗惶恐地放开月亮，说偈问道：

```
汝罗睺罗何以故，　惶怖战栗疾放月？
汝身流汗如病人，　心怖不安乃如是！
```

大意：你罗睺罗为什么惶恐战栗，急忙放开月亮？你身上流汗如同病人，心中恐怖不安竟然到这种地步！

罗睺罗那时说偈回答：

```
世尊以偈而敕我，　我不放月头七分，
设得生活不安隐，　以故我今放此月！
```

大意：世尊以偈命令我，我如果不放开月亮，头就会裂成七分，即使能活下来也不得安稳，所以我现在放开了这月亮！

婆梨阿修罗王说偈：

```
诸佛甚难值，　久远乃出世，
说此清净偈，　罗睺即放月。
```

大意：诸佛非常难以值遇，久远才出世一次；说了这清净的偈，罗睺罗随即放开了月亮。

#### （五）三恶道何以不说；五道与六道

问：为什么不说地狱、畜生、饿鬼？

答：地狱大苦，心乱，不能受法；畜生愚痴覆心，不能受教化；饿鬼被饥渴之火焚烧身体，所以不能受法。

再者，畜生、饿鬼中，或多或少也有来听法的，只是生起福德之心而已，不堪受道，所以不说。

问：如果是这样，揵闼婆、阿修罗也不应当说。为什么？因为已经摄在鬼神道中了。

答：佛没有说“摄”，你现在为什么说“摄”？这是迦旃延子等人的说法。

如阿修罗的力量与天相等，有时战斗还胜过天。

揵闼婆是诸天的乐师，与天同享福乐，有智慧，能分别好丑，为什么不能接受道法？如《杂阿含·天品》中说：

“富那婆薮鬼神之母，佛游行时住宿在她那里。

“那时，世尊宣说上妙的甘露之法，她的一女一男两个孩子啼哭，母亲说偈止住他们：

```
汝郁怛罗勿作声，　富那婆薮亦莫啼！
我今闻法得道证，　汝亦当得必如我。
```

“大意：你郁怛罗不要出声，富那婆薮也不要啼哭！我如今听法，得到道证；你们以后也必定会得到，如同我一样。”

因为这件事，知道鬼神中也有得道的。

再者，摩诃衍中的密迹金刚力士，在诸菩萨中也是殊胜的，何况其余的人？

如屯仑摩甄陀罗王、揵闼婆王来到佛所，弹琴赞佛，三千世界都为之震动，乃至摩诃迦叶也不能安坐。

像这样的人，怎能说不能得道？

如诸阿修罗王、龙王都到佛所，向佛请问深法，佛随其所问，回答深义，为什么说不能得道？

问：在五道众生中，佛是天人师，不说三恶道，因为三恶道没有福德，没有受道的分。这些龙与鬼，都堕在恶道之中。

答：佛也没有分明地说五道；说五道的，是一切有部的僧人所说；婆蹉弗妒路部的僧人说有六道。

再者，应当有六道。为什么？

三恶道一向是罪报之处；如果是福多罪少的，名为阿修罗、揵闼婆等，受生之处应当另外区分，所以应当说六道。

再者，三恶道中也有受道的福德，因为少，所以说没有。

“及诸菩萨绍尊位”，如先前所说。

## 本卷要义

十方菩萨来品的大部分篇幅，是在一位远来的菩萨身上展开的。普明从最东边的多宝世界出发，宝积佛只交给他一朵千叶金莲，叮嘱三件事：欲往随意；不要看佛身小、世界秽恶，只听佛说法；一心敬慎，娑婆菩萨难胜难及。龙树逐一解开其中用意。远道而来本身就是一种教化：东方菩萨听到释迦所说法相与宝积所说“正同”，便知“世界虽远，法相不异”；此土菩萨见远客来听，便惭愧“况我生此而不听法”。整段故事的落点，是让人在佛土的净秽、佛身的大小之外，看见法的同一。

诸佛之间的往来，龙树都放在“随世间法”与“以法为师”这两个根据上。诸佛力等，不须信物，却仍以华为信，如二国王相赠；诸佛不求福德，却仍互相供养，因为“三世诸佛皆以诸法实相为师”。佛初成道时遍观十方无可师者，便说“我行摩诃般若波罗蜜，今自致作佛，是我所尊，即是我师”。盲比丘穿针一事，佛自称“爱福德人”，理由是“深知功德恩”；百岁老翁起舞，为的是教子孙。佛的一切供养，都是在法与功德面前保持恭敬，并以此示范给弟子。

本卷有两处深入菩萨道的要害。一是文殊不能令女人出定，弃诸盖一弹指便起，原因只在发心的因缘：文殊于佛三昧中“功德未满”，菩萨在菩萨三昧中自在，佛三昧中只能“少多入”。二是七住菩萨得无生法忍后欲入涅槃，如梦中渡河者醒来，觉得无河可渡；十方诸佛摩顶，提醒他本愿、众生未解、自己“始得一无生法门”。这两处合起来，勾出了菩萨与佛之间真实的距离：不是知空与不知空的差别，而是知空之后能否不舍众生、继续积集功德。娑婆菩萨之所以“难近”，也在这里：苦多乐少，易生厌离，智慧如刀经石磨而利；又如佛自说，诸功德、六度、一切佛事已具，而不作佛，恒以方便度众生。

卷末的论议仍不离中观的本色。“方”不被众、入、界所摄，胜论立方为实有、常住，龙树以须弥四洲日出互为东方破之：一切方皆东方，皆南方，所以方“但有名而无实”，经中说十方佛来，只是随俗传说。大集一段同样如此：十方众生不尽来，若尽来便成有边；十方各有佛说般若，诸菩萨仍远来，是为与释迦的因缘与本愿。最后关于五道、六道的辨析，龙树明说“佛不说摄”，五道是一切有部所说，六道是犊子部所说，又引鬼神母闻法得道、甄陀罗弹琴动三千世界为证，指出得道与否不能单凭道趣的划分来判定。
