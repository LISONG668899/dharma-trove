# 僧肇《肇论》二　不真空论

## 不真空论第二

至虚无生，是般若玄鉴的妙趣，是万有的宗极。若不是圣明特达之人，怎能契神于有无之间？所以至人把神心通于无穷，无穷也不能使至人滞碍；把耳目用到极致，声色也不能制约至人。原因就在于至人即万物之自虚，所以万物不能牵累至人的神明。

所以圣人乘真心而顺理，就无滞不通；审察一气以观变化，所以所遇皆顺适。无滞不通，所以能混杂而致纯；所遇顺适，所以触物而一。如此，万象各不相同，万象不能自己成为相异。万象不能自异，可知象不是真象。象不是真象，所以象现前的当下，不是真象。如此物我同根，是非一气，潜微幽隐，几乎不是众人之情所能穷尽。

按：全论的总纲已经亮出来：即万物之自虚。万物自己就是虚，圣人不需要另外去制造一个空。后面破三家、立正义，都为证明这一句。

所以近来谈论到"虚宗"，常有不同。以不同去求同，有什么物可以相同？所以众论竞起，所说的性没有相同。为什么？

心无宗：在万物上无心，万物未尝无。心无宗的长处在于神静，短处在于没有看到物虚。

即色宗：阐明色不能自己成为色，所以色现前的当下，不是色。说色，只应当是色当下即色，岂待有个使色成为色的东西，然后才是色？即色宗只说到了色不自色，没有领会色本身就是非色。

本无宗：情志崇尚于无，言语常常归向于无。所以说"非有"，就认为有即是无；说"非无"，就认为无也是无。追寻经文立言的本旨，"非有"只是说不是真有，"非无"只是说不是真无。何必把"非有"理解成没有这个有，把"非无"理解成没有那个无？本无宗只是偏好无的谈论，哪里是顺通事实、切合物情？

按：三家各错在哪里，要一眼看清。心无宗只空了心，没有空物。即色宗看到了色要依缘才成立，停在色的成因上，没有看到色当下就是非色。本无宗把"非有非无"读成了"什么都没有"。三家共同的病是没有做到"即物"：心无宗离开物谈空，即色宗停在物的成因上，本无宗跑到了无的一边。

以物去称呼物，所称呼的就可以是物；以物去称呼非物，所以有物，不是物。所以物不就名而成实，名不就物而达真。如此，真谛独静于名教之外，岂是文字言说所能辨明？僧肇不能沉默，姑且托言模拟，试着论述。

《大智度论》说：诸法亦非有相，亦非无相。《中论》说：诸法不有不无，是第一真谛。追寻"不有不无"，难道是说要涤除万物、杜塞视听、寂寥虚豁，然后才是真谛吗？

诚以即物顺通，故物莫之逆；即伪即真，故性莫之易。性莫之易，故虽无而有；物莫之逆，故虽有而无。

（大意：真谛在当下的物上顺而通之，所以物不违逆真谛；虚假的当下就是真实，所以本性不变。本性不变，所以说无的当下就有；物不违逆，所以说有的当下就无。）

有的当下就无，叫作非有；无的当下就有，叫作非无。如此，物是有的，物不是真物。物不是真物，又拿什么来称为物呢？所以经说：色之性空，非色败空。用来说明圣人对于物：

即万物之自虚，岂待宰割以求通哉？

（大意：圣人就在万物本身的虚空上见空，哪里需要把万物切割分解，才求得通达？）

所以《维摩经》说病时有"不真"之谈，《超日明三昧经》有"即虚"之称。三藏文字不同，统摄三藏的是同一个道理。

按：七寸在"色之性空，非色败空"。空不是色坏掉以后剩下的空，是色正好好地显现着，本性就是空。心无宗、本无宗都想把物"拿掉"来见空，僧肇说不用拿，也拿不掉，物本身就是虚的。

《放光般若经》说：第一真谛，无成无得；世俗谛中，便有成有得。有得，是无得的伪号；无得，是有得的真名。从真名一边说，真谛不是有；从伪号一边说，俗谛不是无。所以说真，从来没有一个有；说伪，从来不是没有。两种说法从来不是一回事，两种道理从来没有差别。所以经中问：真谛与俗谛有差异吗？答：无异。经文直接以真谛阐明非有，以俗谛阐明非无，岂是因为谛有两种，就把物也分成两种？

如此，万物确实有其所以不有，有其所以不无。有其所以不有，所以有的当下非有；有其所以不无，所以无的当下非无。无的当下非无，所以无不是断绝的虚空；有的当下非有，所以有不是真有。若有不就是真，无不抹去痕迹，有与无名称不同，旨趣一致。

按：七寸在于看清二谛不是两层世界。同一个物，就"不是真有"这一面说，叫真谛；就"不是空无"这一面说，叫俗谛。物只有一个，说法有两种。

所以宝积童子赞叹：说法不有亦不无，以因缘故诸法生。《璎珞经》说：转法轮者，亦非有转，亦非无转，叫作转无所转。这些都是众经的微妙之言。为什么？若说物无，邪见就不算迷惑；若说物有，常见就是正确。正因为物非无，所以邪见是迷惑；正因为物非有，所以常见不正确。如此，非有非无，确实是真谛之谈。

所以《道行般若经》说：心亦不有亦不无。《中论》说：

物从因缘故不有，缘起故不无。

（大意：物依因缘而有，所以不是真有；物依缘而起，所以不是真无。）

寻求其理，确实如此。为什么这样说？有若是真有，有自然常有，岂待缘而后有？譬如真无，无自然常无，岂待缘而后无？若有不能自己成为有，要待缘而后有，可知有不是真有。有不是真有，所以有现前时，也不可称为有。说"不无"：无是湛然不动的，才可以叫作无；万物若是无，就不应生起，生起了就不是无，以此说明缘起，所以不无。

按：七寸在"缘"一个字。缘起一个事实，同时证明两边：要等缘才有，证明不是真有；缘一到就起，证明不是真无。断见和常见，被同一个事实一齐破掉。

所以《大智度论》说：一切诸法，因一切因缘，所以应当说有；一切诸法，因一切因缘，所以不应当说有。一切无法，因一切因缘，所以应当说有；一切有法，因一切因缘，所以不应当说有。追寻论中有无之言，难道只是正反对立的论说吗？若应当是有，就是有，不应当说无；若应当是无，就是无，不应当说有。论中说有，是借有来说明非无；借无来辨明非有。事只有一件，称呼有两种。文字看似不同，若领会其所同，就没有差异而不同。

如此，万法确实有其所以不有，不可得而有；有其所以不无，不可得而无。为什么？

欲言其有，有非真生；欲言其无，事象既形。象形不即无，非真非实有。然则不真空义，显于兹矣。

（大意：想说万法是有，万法的有不是真实的生起；想说万法是无，事物的形象已经显现。形象显现，就不是无；形象不是真实，就不是实有。不真空的意义，就显现在这里。）

按：论名"不真空"，就在这里点题。"不真"，所以"空"。不真，守住了非有；有形象显现，守住了非无。只说"空"，读者容易滑到断灭；只说"有"，读者容易滑到常见。"不真空"三个字把两边一起守住。

所以《放光般若经》说：诸法是假号，不真实，譬如幻化的人。幻化的人是有的，幻化的人不是真人。

以名求物，物无当名之实；以物求名，名无得物之功。物无当名之实，非物也；名无得物之功，非名也。是以名不当实，实不当名。名实无当，万物安在？

（大意：依名去寻物，物没有与名相当的实体；依物去寻名，名没有抓住物的功能。物没有与名相当的实体，就不是物；名没有抓住物的功能，就不是名。所以名不当实，实不当名。名实互不相当，万物在哪里？）

所以《中论》说：物本无彼此，人以此为此，以彼为彼；对方也以此为彼，以彼为此。此与彼不能定于一个名称，迷惑的人怀着"必然如此"的心。如此，彼与此本来就不是有，迷惑的人本来也不是没有。既然悟到彼与此不是有，有什么物可以是有？所以知道万物不是真的，是假号由来已久。所以《成具光明经》立"强名"之文，《庄子》有"指马"之喻。如此，深远之言，何处不在？

按：七寸在"名实无当"。人以为名字抓住了东西，东西也撑得起名字。僧肇用"此彼"做例子：同一个位置，我叫"这里"，对面的人叫"那里"，名称跟着观看的人走，不跟着东西走。名称跟着人走，东西也就没有一个固定的"实"。

所以圣人乘千化而不变，履万惑而常通，因为圣人即万物之自虚，不借一个虚来使物成为虚。所以经说：甚奇世尊，不动真际为诸法立处。不是离开真际来安立诸法，安立诸法之处就是真际。

然则道远乎哉？触事而真。圣远乎哉？体之即神。

（大意：道远吗？触到的每一件事都是真。圣远吗？体会到了就是神。）

按：最后一句是全论的落脚处。前面所有论证，都是为了让人敢于相信：真不在万物之外，就在每一件事上。"立处即真"，不需要离开当下去找真谛。
