# 中观甚深观修引导

麦彭仁波切 造

顶礼文殊师利！

```
དཔྱོད་པ་རྣམ་སྦྱོང་སྔོན་སོང་ནས། །
གང་ཟག་བདག་མེད་ཚུལ་ལ་ནི། །
ངེས་ཤེས་གནད་དུ་འབྲོང་བའི་ཚེ། །
```

首先经由观察抉择而净治己心，当对人无我之理，定解已深入要害之时，

```
བདག་ཅེས་ཕུང་པོ་ལ་བརྟེན་ནས། །
མ་བརྟག་རྟོག་པས་བརྟག་པ་ལྟར། །
ཕུང་པོ་ལྔ་དང་འདུས་མ་བྱས། །
ཆོས་རྣམས་ཐམས་ཅད་དེ་བཞིན་དུ། །
རྟོག་པས་བརྟགས་ཏེ་འདི་འདི་ཞེས། །
སྣ་ཚོགས་ཆོས་སུ་བཟུང་མོད་ཀྱི། །
```

应思惟：所谓"我"，乃是依于蕴聚、由未经观察之分别心所安立者；五蕴以及无为法，一切诸法亦同样如此，皆由分别心安立、称为"此""彼"，虽被执取为种种不同之法，

```
བརྟག་དོན་བཙལ་ན་མི་རྙེད་དེ། །
ཆ་མེད་གཉིས་ཀྱི་མཐར་ཐུག་བར། །
ཕྲ་ཞིང་ཕྲ་བའང་མ་གྲུབ་བཞིན། །
རྟེན་ཅིང་འབྲེལ་འབྱུང་དབང་གིས་སྣང༌། །
```

然若以观察加以寻求，皆了不可得；乃至无分刹那与无分微尘之究竟边际，纵是极其微细者亦不能成立，唯依缘起之力而如是显现。

```
དངོས་པོ་བརྟེན་ནས་སྐྱེས་པ་སྟེ། །
དངོས་མེད་བརྟེན་ནས་བརྟག་པ་ཡིན། །
དངོས་དང་དངོས་མེད་གང་ལ་ཡང༌། །
མ་བརྟག་དེ་དང་དེ་འཛིན་གྱིས། །
```

有事物依缘而生，无事物则依缘而假立；无论是有事物、还是无事物，若不加观察，便执之为"此""彼"，

```
བརྟག་ཅིང་དཔྱད་པར་གྱུར་པའི་ཚེ། །
གཞི་མེད་རྩ་བ་བྲལ་བཞིན་དུ། །
མེད་སྣང་སྒྱུ་མ་རྨི་ལམ་དང༌། །
ཆུ་ཟླ་བྲག་ཆ་དྲི་ཟའི་གྲོང༌། །
མིག་ཡོར་སྨིག་རྒྱུ་ལ་སོགས་བཞིན། །
```

然而一旦加以观察抉择，便如无基无根一般，无实而显现，犹如幻化、梦境、水中月、回声、乾闼婆城、眼翳幻影、阳焰等一般。

```
སྟོང་བཞིན་སྣང་ལ་སྣང་བཞིན་སྟོང༌། །
སྣང་སྟོང་སྒྱུ་མའི་ཚུལ་དུ་བསྒོམ། །
```

虽空而显现，虽显现而空，应如是修习：显空双运，犹如幻化。

```
འདི་ནི་རྣམ་གྲངས་པའི་དོན་དམ། །
རྟོགས་པའི་བློ་ཡི་ངེས་ཤེས་ཅན། །
རྗེས་ཐོབ་སྒྱུ་མའི་ཚུལ་མཐོང་བའི། །
ཤེས་རབ་དྲི་མེད་ཡིན་མོད་ཀྱང༌། །
```

此乃分类而说之胜义，是具足证悟之定解心；于后得位中照见诸法如幻之无垢智慧，虽然如是，

```
གཟུང་བའི་དམིགས་པ་མ་བྲལ་ཞིང༌། །
འཛིན་པའི་རྣམ་པ་མ་ཞིག་ལ། །
ཀུན་ཏུ་རྟོག་ལས་མ་བརྒལ་ཕྱིར། །
སྤྲོས་བྲལ་ཆོས་ཉིད་མཐོང་བ་མིན། །
```

然仍未脱离对所取之执取所缘，能取之行相亦未坏灭，因其尚未超越遍计分别之故，尚非照见离戏之法性。

```
དེ་འདྲའི་ངེས་ཤེས་སྐྱེས་པའི་ཚེ། །
སྒྱུ་མ་ཙམ་དུ་འཛིན་པ་ཡང༌། །
རྟོག་པས་བརྟགས་ཏེ་གཟུང་མོད་ཀྱི། །
གཟུང་བྱའི་ངོ་བོ་མ་གྲུབ་ལ། །
```

当生起如是定解之时，纵然执为唯是幻化，此执著亦是由分别心所安立而执取者；所取之自性既不成立，

```
འཛིན་པའི་སེམས་ཀྱང་མི་རྙེད་པས། །
འཛིན་མེད་ལྷུག་པའི་གཤིས་སུ་བཞག །
```

能取之心亦复不可得，故应安住于无执、松坦之本然状态。

```
དེ་ལྟར་བཞག་ཚེ་ཕྱི་ནང་གི ། །
སྣང་བ་ཐམས་ཅད་མ་འགགས་ཀྱང༌། །
དེ་འཛིན་མེད་པའི་གཤིས་ལུགས་སུ། །
ཆོས་སུ་བཏགས་པ་ཇི་སྙེད་པ། །
```

如是安住之时，外内一切显现纵然并未间断，然于此无执之本然状态中，凡被安立为"法"者，无论多少，

```
ཡེ་ནས་མ་སྐྱེས་མ་འགགས་པས། །
གཟུང་དང་འཛིན་པ་རྣམས་བྲལ་བའི། །
མཉམ་པ་ཉིད་ཀྱི་དབྱིངས་སུ་མཉམ། །
```

皆本自无生、无灭，由此脱离能取与所取，于平等性之法界中，平等一如。

```
ཡོད་མེད་ལ་སོགས་ཁས་ལེན་བྲལ། །
བརྗོད་མེད་དོན་གྱི་རང་བབས་ལ། །
ཐེ་ཚོམ་མེད་པའི་ཉམས་མྱོང་འཆར། །
```

远离"有""无"等一切承许，于不可言说之义的自然本状之中，生起无有疑虑之亲身体验。

```
དེ་ནི་ཆོས་ཀུན་ཆོས་ཉིད་དེ། །
རྣམ་གྲངས་མིན་པའི་དོན་དམ་པ། །
སོ་སོ་རང་གི་རིག་བྱ་བ། །
མཉམ་གཞག་མི་རྟོག་ཡེ་ཤེས་ཡིན། །
```

此即一切诸法之法性，是非分类之真实胜义谛，是各自内证所应了知者，即是等持无分别之智慧。

```
དེ་ཡི་ངང་ནས་གོམས་པ་ན། །
སྟོང་དང་རྟེན་འབྱུང་ཟུང་འཇུག་པ། །
བདེན་གཉིས་དབྱེར་མེད་གནས་ལུགས་དོན། །
དབུ་མ་ཆེན་པོའི་རྣལ་འབྱོར་ཡིན། །
```

于此境界中串习之时，空性与缘起双运、二谛无别之实相义，即是大中观之瑜伽。

```
དོན་དེ་སེམས་ཀྱི་སྤྱོད་ཡུལ་དང༌། །
བྲལ་བ་གཉིས་མེད་ཡེ་ཤེས་ནི། །
མྱུར་བ་ཉིད་དུ་མངོན་བྱེད་པར། །
འདོད་ན་སྔགས་ཀྱི་མན་ངག་བསྒོམ། །
```

若欲将此超越心识行境、远离二取之无二智慧，迅速地令其现前，则应修持密咒之窍诀教授。

```
འདི་ནི་དབུ་མའི་སྒོམ་རིམ་གྱི། །
ཟབ་གནད་མཐར་ཐུག་ཡིན་པའི་ཕྱིར། །
```

此即是中观修习次第中最为究竟甚深之要害所在。

```
དང་པོ་སྤྱོད་པ་རྣམ་སྦྱངས་ནས། །
རིམ་པར་མྱོང་བས་གཏན་ལ་དབབ། །
སྣང་སྟོང་སྒྱུ་མའི་ངེས་ཤེས་ཀྱིས། །
ལམ་ནས་གསལ་བཞག་མེད་པའི་དོན། །
```

首先净治行为，依次第以亲身体验而抉择确定；以显空如幻之定解，于道上明晰安住无所增减之义，

```
ཤེས་རབ་ཕ་རོལ་ཕྱིན་པའི་དབྱིངས། །
མཉམ་པ་ཉིད་དུ་རྣམ་པར་གྲོལ། །
```

于般若波罗蜜多之法界中，即于平等性中获得解脱。

```
སྐོམ་པའི་གདུང་བའི་ཕྱོགས་གང་ན། །
ཆུ་ཡོད་གོ་ཡང་སྐོམ་མི་སེལ། །
དེ་ཕྱིར་བཏུང་ན་སེལ་བ་ལྟར། །
གོ་མྱོང་དེ་འདྲར་མདོ་ལས་གསུངས། །
```

于口渴煎熬难耐之处，纵然听闻"有水"，亦不能止渴；唯有饮之，方能止渴——闻与证之别，经中亦如是宣说。

```
དེ་ཕྱིར་རིགས་པ་མང་པོ་ཡིས། །
རང་ཉིད་ངལ་བའི་གོ་སྐོམ་ལ། །
རེས་འཇོག་མི་དགོས་རིམ་བསྒོམས་ན། །
ཟབ་མོའི་བཟོད་པ་མྱུར་དུ་ཐོབ། །
```

是故，若以繁多理证令自身疲惫不堪，唯余闻慧之渴者，不需时断时续，若能依次第而修，便能迅速获得甚深之忍。

```
འཇམ་དཔལ་དགྱེས་པའི་རྡོ་རྗེ་ཡིས། །
ཆུ་འབྲུག་མགོ་ཟླའི་ཚེས་ཉེར་དགུར། །
ཤར་མར་བྲིས་འདིས་འགྲོ་ཀུན་གྱིས། །
ཟབ་མོ་དབུ་མའི་དོན་རྟོགས་ཤོག །
```

文殊喜金刚，于水龙年十一月二十九日，随心所至而书此文，愿一切众生皆能证悟甚深中观之义！

吉祥圆满！

## 译者说明

本篇依藏文原颂重新译出，参考但不依赖已有英译本之措辞。全文次第分明：先由人无我、法无我之抉择入手，经"显空如幻"之相似胜义（分类胜义），进而超越能取所取之戏论，安住于离戏平等法界之非分类胜义，末以密咒窍诀作为迅速现证之增上方便，并以"闻水不能止渴、饮水方能止渴"之喻，说明闻思之理解与亲身修证二者之别，劝勉学人依次第实修，而非止于理证之思辨。
