# 僧肇《肇论》一　宗本义与物不迁论

## 慧达序

小招提寺沙门慧达作

慧达愚钝，冒昧为长安释僧肇法师所作的《宗本义》《物不迁论》等四论通作一序。末世弘扬经典，本当由四依菩萨来承担；四依菩萨的教法传到这片土地，也属于同样的情形。至于弥天大德道安法师与鸠摩罗什沙门，都开创宗义，图辨事理，宣扬阐述，所事奉的是玄虚之道。唯有这部论，堪比圣人默然所宗的根本。

从道安、罗什以下，历代古今，凡是在僧传中著名的，以及僧传所不载的，释僧睿等三千余位僧人，清信檀越谢灵运等八百来人，其中能辨正方言、节制文章层次、善于核实名教、精细搜求义理的，汇集这许多贤者的言论加以统摄，有一位美好的人物，超越言说，兼通沉默：标举本体，句句深达佛心；阐明末用，言言遍通众教。确实是大乘的美好典籍，方等的博大之书。

自古至今著文著笔，仔细检汰名贤所作的诸论，或六七宗，乃至十二家，都评判其好坏，辨明其得失，唯有这部法典没有那样的毛病。确实因为僧肇胸怀宽广，不知系属于哪一家。好比深渊大海，数量超过九流；挺拔清虚，萧然物外。了解僧肇的人很少，世人把僧肇的学问归于采撷罗什之说；如果世人说不了解，僧肇就更显珍贵了。

慧达有幸生逢这样的正音，欢喜不已，如赴盛宴不知疲倦，每次披阅，都不禁手舞足蹈，发誓生生世世尽命弘扬阐述。慧达对僧肇的遗文尚且如此，对《中论》《百论》《十二门论》，以及方等深经，怎能不加倍用心呢？

世俗传言都说：僧肇所作，依据的是《成实论》的真谛、《地论》的通宗，又借助了庄子、老子的放浪之说。这实在是大害之言，欺诬亡者，属于街巷鄙陋之音，不值得拾取。神道无形，心之敏妙难以描绘；文字受拘束，义理深远，所以众多端绪容易被曲解。僧肇这样用心，岂是徒然？确实有其缘由。若有人一味轻狎其言，慧达愿生生世世不与这人见面，等获得无生忍心，再回来度这人。

慧达在讲席间留连二十余年，常遇重席讲论，最后读到此论，姑且寄上一篇序文，把所悟寄托在序中。与慧达同道的贤者，其余的请待后来的明哲。

大分深义，号为本无，所以立言宗旨，标举实相。开显空法之道，莫过于真俗二谛，所以依次解释二谛，彰显佛的教门。圆满正确的因，是无上般若；究竟至极的果，唯有涅槃。所以最后开启重玄，阐明众圣所居之处。以性空比拟本体，本体其实无可称说；说本体，本来绝于言说，不是心行所及之处。《物不迁论》对应俗谛，俗谛本来不生；《不真空论》以不真为真，真谛也只是名言所说。若能放旷荡然，崇奉这一道，清净耳根，虚怀以待，二谛也无可言说。如此，净照之功显著，所以说般若无知；无名之德兴起，所以说涅槃不可称名。

慧达认为这样的说法周遍圆满，穷尽佛法渊海，浩博无涯，穷究法的体相。言辞简约，义理丰富；文采华美，道理精到；语势连环，意趣孤高。可谓绝妙好辞，莫不竭尽于这部大论。所以鸠摩罗什赞叹说：解空第一，就是僧肇其人。罗什的赞叹有其来由，彰显于书翰之中。《宗本义》萧然简要，无人能够诘难；《物不迁论》等四论用以开示接引，以问答剖析精微，所以称为论。

按：慧达序最有用的是最后两段，交代了《肇论》的结构。读者先把结构记住，后面就不会迷路：

- 宗本义：全书总纲，五个名称说同一件事。
- 物不迁论：讲俗谛。世间看似流动，没有一个东西从过去搬到现在。
- 不真空论：讲真谛。万物都不是真有，所以是空。
- 般若无知论：讲能证的智慧。智慧照见一切，没有一个取相的知。
- 涅槃无名论：讲所证的果。涅槃不能用有、无来命名。

## 宗本义

本无、实相、法性、性空、缘会，五个名称说的是同一个义理。为什么？

一切诸法，缘会而生。缘会而生，则未生无有；缘离则灭。如其真有，有则无灭。

（大意：一切诸法都是因缘聚合而生。既然因缘聚合才生，因缘未聚、尚未生起时，就没有这个法；因缘一散，这个法就灭。假如一个法是真实存在的，真实存在的东西就不会灭。）

由此推知：现在显现为有的时候，有的当下，本性常空。本性常空，所以叫作性空。性空，所以叫作法性。法性如此，所以叫作实相。实相本身就是无，并不是经过推求才使实相成为无，所以叫作本无。

按：七寸在"如其真有，有则无灭"。凡是会灭的东西，都证明自己从来不是真有。灭并不是把有变成无。灭让人看到：那个东西本来就不真。所以空不需要等东西坏掉才成立，东西正在显现的时候，已经是空。"非推之使无"说的也是这一点：空不是推理制造出来的结论，推理的作用，是让人看见本来如此。

所谓"不有不无"，"不有"不是常见所执的有，"不无"不是邪见、断见所执的无。若以有为有，就会以无为无。不存一个"无"来观法，才可以说认识了法的实相。观有的时候，不取有之相。所以法相是无相之相。

圣人之心，为住无所住矣。

（大意：圣人的心，安住在无所住之中。）

按："若以有为有，则以无为无"是一针见血的一句。执有和执无是一对。执有的人一旦破了有，就会转过来执无。所以僧肇说"不存无以观法"：连"无"也不拿来当观法的工具。

三乘都是通过观性空而得道。性空就是诸法实相。见到法的实相，所以叫作正观；与正观不同，便是邪观。假设二乘不见此理，就是颠倒。所以三乘观法没有差异，差别在于心量有大小。

沤和般若，是大智慧的名称。诸法实相，叫作般若；能不取证，是沤和的功用。适应教化众生，叫作沤和；不染尘累，是般若的力量。般若之门观空，沤和之门涉有。涉入有，从未迷失空性，所以常处于有中，不被染污；不厌离有，同时观空，所以观空，不取证。这就叫作：

一念之力，权慧具矣。

（大意：一念的力量，方便与智慧同时具足。）

原文在这里把这句重复一遍，并说：好好思考，就清清楚楚可以理解。

按：七寸在"一念"。般若与方便不是先后两个阶段，是同一念的两面。观空的同时在涉有，所以不堕入二乘的取证；涉有的同时在观空，所以不被世间染污。

泥洹尽谛，只是结使断尽而已，生死永灭，所以叫作"尽"；并没有另外一个叫作"尽"的处所。

按：涅槃不是一个地方。宗本义的最后一句，为全书最后的《涅槃无名论》埋下伏笔。

## 物不迁论第一

生死交替，寒暑更迭，认为有物在流动，这是人之常情。僧肇认为不是这样。为什么？《放光般若经》说：法无去来，无动转者。寻求不动的作用，难道要舍弃动来求静吗？

必求静于诸动。必求静于诸动，故虽动而常静；不释动以求静，故虽静而不离动。

（大意：一定要在种种动之中求静。在动之中求静，所以动的当下常静；不舍弃动去求静，所以静的当下不离开动。）

所以动与静从来没有不同，迷惑的人看成不同。于是真实之言滞于争辩，宗旨之路屈于好异，静与躁的极致，很难说清楚。为什么？谈真就违逆世俗，顺俗就违背真理。违背真理，所以迷失本性不能回返；违逆世俗，所以言语平淡无味。于是中等根器的人分不清存亡，下等根器的人拍手大笑，不屑一顾。近在眼前又不可知的，就是物性吧。僧肇不能自已，姑且寄心于动静之际，不敢说一定如此，试着论述。

按：七寸在开头一句"必求静于诸动"。僧肇不是要在动的背后找一个不动的东西。僧肇要在动的当下看出静。整篇论都只证明一件事：动和静是同一个事实的两种看法。

《道行般若经》说：诸法本来无所从来，去也无所至。《中论》说：观察去的地方，知道去者，去者到不了所去的地方。经论的说法都是即动而求静，由此知道物不迁移，十分明白。

世人所说的动，根据是过去的物不到今天，所以说动，不是静。僧肇所说的静，根据也是过去的物不到今天，所以说静，不是动。说动不是静，因为过去之物不来；说静不是动，因为过去之物不去。所依据的事实从来没有不同，所得的见解从来不同。违逆真理就叫塞，顺应真理就叫通。如果得到其中的道理，还有什么滞碍？

按：全论的七寸在这一段。世人和僧肇用的是同一个前提："昔物不至今"。世人推出：过去的东西已经没了，所以有变动。僧肇推出：过去的东西从来没有来到今天，也就从来没有离开过去；没有任何东西从过去走到今天，所以没有一个东西在动。动要成立，需要一个"从过去走到现在的东西"。找不到这个东西，动就不成立。

可悲啊，人情的迷惑由来已久，眼睛对着真理，不能觉察。世人既然知道往昔之物不会来到今天，又说今天之物可以往去。往物既然不来，今物又往哪里去？为什么？

求向物于向，于向未尝无；责向物于今，于今未尝有。

（大意：在过去寻找过去之物，过去之物在过去从来不是没有；在今天寻找过去之物，过去之物在今天从来不曾有。）

今天不曾有，说明物不来；过去不曾无，所以知道物不去。反过来寻求今天之物，今天之物也不往。这就是：

昔物自在昔，不从今以至昔；今物自在今，不从昔以至今。

（大意：过去的物自己在过去，不是从今天去到过去；今天的物自己在今天，不是从过去来到今天。）

所以孔子对颜回说：我们擦肩而过，转眼你已是新人，不是旧人了。如此，物不相往来，就很明白了。既然连往返的一丝迹象都没有，有什么物可以动呢？那么：

旋岚偃岳而常静，江河竞注而不流，野马飘鼓而不动，日月历天而不周。

（大意：吹倒山岳的旋风常静，竞相奔流的江河不流，飘荡的游气不动，运行天空的日月不周转。）

又有什么奇怪的呢？

按：四句看起来最反常，也最好懂。旋风的每一刹那，各在各的刹那，没有"同一阵风"从这一刹那搬到下一刹那。所以说旋风"偃岳"是真的，说旋风"常静"也是真的。

噫！圣人说：人命逝去的速度，比河流还快。所以声闻悟无常而成道，缘觉觉缘离而即真。假如万动不是变化，怎么能寻变化而登道？再仔细寻思圣人之言，微妙隐晦难测：似动而静，似去而留，可以神会，难以事求。所以说"去"不一定是去，用来防止常人执常的想法；说"住"不一定是住，用来破除常人所谓的"往"。哪里是说去了就可以遣除、住了就可以留住呢？

所以《成具光明经》说：菩萨处在计常的众生之中，演说非常之教。《大智度论》说：诸法不动，无去来处。这些都是引导各方众生，两种言说汇归一处。难道因为文字不同，就违背旨趣吗？所以说常，不住；称去，不迁。不迁，所以往的当下常静；不住，所以静的当下常往。静的当下常往，所以往了不迁；往的当下常静，所以静了不留。

按：七寸在于看清，佛说无常和说不迁并不矛盾。说"去"，破常见：没有一个东西留下来。说"不迁"，破动见：也没有一个东西走掉。两种说法破的是同一个错误，就是以为有一个实在的东西，或者留着，或者走了。

庄子说"藏山于泽"，夜半有力者背着跑了；孔子临河叹逝。两位都是感叹往者难留，难道是说排除今天就可以往去？所以观察圣人之心，不同于常人所见。为什么？常人认为少年与壮年是同一个身体，百岁是同一个形质，只知道年岁流逝，不觉得形体也随之变化。所以有个梵志出家，白发时回来，邻居见了说：从前那个人还在吗？梵志说：

吾犹昔人，非昔人也。

（大意：我像从前那个人，又不是从前那个人。）

邻居都惊愕，不认可梵志的话。所谓有力者背着跑了，昧者不觉，说的就是邻居一类人吧。

按：梵志一句话把两种错误同时破了。"犹昔人"破断见，"非昔人"破常见。

所以如来依众生所滞，就用方便言语辨除迷惑，乘不二之真心，吐不一之殊教。看似乖违、又不可说成两样的，只有圣言吧。所以谈真时有"不迁"之称，导俗时有"流动"之说。千途异唱，会归同一旨趣。征引文字的人听到"不迁"，就以为过去之物不到今天；听到"流动"，就以为今天之物可以到过去。既然说是古今，还想让古今迁移，是为什么？

所以说往不一定往，古今常存，因为不动；称去不一定去，说的是不从今到古，因为不来。不来，所以不驰骋于古今；不动，所以各自性住于一世。如此，群籍文字不同，百家说法各异，如果得到会通处，文字的不同又怎能迷惑人？

所以世人说住，僧肇说去；世人说去，僧肇说住。去与住名称不同，旨趣一致。所以经说：正言似反，谁当信者？经文的话有来由。为什么？世人在今天求古，说古不住；僧肇在古中求今，知道今不去。今若到古，古应有今；古若到今，今应有古。今天没有古，从而知道古不来；古时没有今，从而知道今不去。

若古不至今，今亦不至古，事各性住于一世，有何物而可去来？

（大意：如果古不到今，今也不到古，每件事各自住在自己的那一刹那，有什么东西可以去来？）

按："事各性住于一世"最容易被误读成"每个时刻的事物都实实在在地住着"，那就成了三世实有。明代镇澄作《物不迁正量论》，正是从这里批评僧肇。读《物不迁论》要配合《宗本义》：性住的"性"，就是性空的性。每一刹那各住其位，住在其位的事物本身缘会而生、性常自空。僧肇说"住"，用来破"去"；说"不至今"，用来破"常"。住与不至今合在一起，才是不迁。

所以四时如风驰，天象如电卷，若得其意于毫微之间，再快也不转。所以如来功德流传万世而常存，道通百劫而更加坚固。成山借助最初一筐土，长途托付最初一步，因为功业不会朽坏。功业不可朽，所以功业在过去，不化；不化所以不迁；不迁，道理就湛然明白了。所以经说：三灾弥漫，行业湛然。经文的话确实可信。为什么？

果不俱因，因因而果。因因而果，因不昔灭；果不俱因，因不来今。不灭不来，则不迁之致明矣。

（大意：果不与因同时存在，果因为有因才成为果。果因因而成，说明因在过去并没有灭掉；果不与因同时，说明因没有来到今天。因既不灭，又不来，不迁的道理就明白了。）

还有什么可疑惑于去留、徘徊于动静之间的呢？如此，乾坤倒覆，不要说不静；洪水滔天，不要说是动。

苟能契神于即物，斯不远而可知矣。

（大意：只要能在当下的事物上契会神理，不迁的道理近在眼前，可以知道。）

按：因果是不迁最好的证明。因如果灭尽，果就无从生起；因如果来到果的时间里，因和果就同时并存，也不成因果。因在因的位置上，功用不失；果在果的位置上，不与因混。修行的功德一点不会丢失，正是因为不迁。最后一句"契神于即物"把整篇收回到修行：不迁不是推论出来的结论，是在眼前的事物上直接看到的。
