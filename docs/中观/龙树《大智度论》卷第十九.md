# 龙树《大智度论》卷第十九

龙树菩萨造　后秦龟兹国三藏鸠摩罗什奉诏译

## 释初品中三十七品义第三十一

【经】“菩萨摩诃萨以不住之法住在般若波罗蜜中，因为不生，所以应当具足四念处、四正勤、四如意足、五根、五力、七觉分、八圣道分。”

【论】

### 一、菩萨何以学三十七品

问：三十七品是声闻、辟支佛之道，六波罗蜜是菩萨摩诃萨之道，为什么在菩萨道中说声闻之法？

答：菩萨摩诃萨应当学一切善法、一切道。如佛告诉须菩提：“菩萨摩诃萨修行般若波罗蜜，全部学习一切善法、一切道，就是从干慧地乃至佛地。”这九地应当学习而不取证，佛地既学也证。

再者，哪里说过三十七品只是声闻、辟支佛之法，不是菩萨道？在《般若波罗蜜经·摩诃衍品》中，佛说四念处乃至八圣道分就是摩诃衍；三藏中也没有说三十七品唯独是小乘法。

佛因为大慈，说三十七品这涅槃之道，随着众生的愿望，随着众生的因缘，各自得到各自的道。

想求声闻的人，得声闻道；种了辟支佛善根的人，得辟支佛道；求佛道的人，得佛道。随其本愿，诸根的利钝，以及有大悲、无大悲而有不同。

譬如龙王降雨，普降天下，雨并无差别。大树、大草，因为根大，所以多受雨水；小树、小草，因为根小，所以少受。

#### （一）仰射空中，箭箭相柱

问：三十七品，虽然没有地方说唯独是声闻、辟支佛道而不是菩萨道，但以义理推究可知：菩萨久住生死，往来五道，不急于取涅槃；而这三十七品只说涅槃之法，不说波罗蜜，也不说大悲，所以知道不是菩萨道。

答：菩萨虽然久住生死之中，也应当知道什么是实道、什么不是实道，这是世间、这是涅槃。知道这些之后，立下大愿：众生可怜，我应当把他们拔出，安置在无为之处；以这真实之法修行诸波罗蜜，能到达佛道。菩萨虽然学习、了知这法，因为还没有具足六波罗蜜，所以不取证。

如佛说：“譬如仰面向空中射箭，箭箭相互支撑，不让它们落地；菩萨摩诃萨也是这样，以般若波罗蜜之箭射向三解脱门的虚空中，又以方便之箭射般若之箭，使它不坠落在涅槃之地。”

再者，如果如你所说，菩萨久住生死之中，应当承受种种身心苦恼，如果没有得到真实智慧，怎么能忍受这些事？所以，菩萨摩诃萨求这道品的真实智慧时，以般若波罗蜜之力，能把世间转为道果涅槃。为什么？三界世间都从和合而生，和合而生的没有自性，没有自性就是空，空所以不可取，不可取之相就是涅槃。

所以说菩萨摩诃萨以不住之法住在般若波罗蜜中，因为不生，所以应当具足四念处。

#### （二）世间即是涅槃

再者，声闻、辟支佛法中，不说世间就是涅槃。为什么？因为智慧不能深入诸法。菩萨法中，说世间就是涅槃，因为智慧深入诸法。

如佛告诉须菩提：“色即是空，空即是色；受、想、行、识即是空，空即是受、想、行、识；空即是涅槃，涅槃即是空。”

《中论》中也说：

```
涅槃不异世间，　　世间不异涅槃。
涅槃际世间际，　　一际无有异故。
```

大意：涅槃与世间没有差别，世间与涅槃没有差别；涅槃的边际与世间的边际，是同一个边际，没有不同。

菩萨摩诃萨得到这实相，所以不厌世间，不乐涅槃；三十七品是真实智慧的根基。

【译注】本节回答“三十七品是小乘法”之难，要点有二：一是箭箭相柱之喻，般若之箭射入三解脱门的空中，方便之箭又射般若之箭，使之不堕涅槃地，所以菩萨学道品而不取证；二是“世间即是涅槃”，二乘智慧不深入诸法，所以世间与涅槃两分，菩萨深入诸法，知二者一际，所以道品在菩萨手中成为“实智之地”而不是出离之门。经文“以不住法住般若波罗蜜中，不生故”一语，正是这两层的总纲。

### 二、何以说三十七品

问：四念处就能具足得道，为什么说三十七品？如果你说略说是四念处、广说是三十七品，这不对！为什么？如果是广说，应当无量！

答：四念处虽然具足能得道，也应当说四正勤等诸法。为什么？众生的心种种不同，结使也种种不同，所乐所解之法也种种不同。佛法虽然是一实一相，为了众生，在十二部经、八万四千法聚中作这样的分别说。如果不是这样，初转法轮说四谛就足够了，不需要其余的法。

因为有众生厌苦着乐，为这些众生说四谛。

身心等诸法都是苦，没有乐；这苦的因缘，是由于爱等诸烦恼；这苦所灭尽之处，名为涅槃；以方便到达涅槃，这就是道。

有众生念头多、心散乱颠倒，执着于这身、受、心、法而作邪行，为这些人说四念处。

像这样等等诸道法，各自为众生而说。

譬如医师，不能以一种药治众病；众病不同，药也不一。佛也是这样，随着众生种种心病，以众药来治。

或者说一法来度众生。如佛告诉一位比丘：“不是你的东西不要取！”比丘说：“已经知道了！世尊！”佛说：“怎么知道的？”比丘说：“诸法不是我的东西，不应当取。”

或者以二法度众生：定与慧；或者以三法：戒、定、慧；或者以四法：四念处。

所以四念处虽然可以得道，其余诸法修行不同，分别的多少不同，观法也不同，所以应当说四正勤等其余诸法。

再者，诸菩萨摩诃萨信力大，为了度一切众生，所以佛在这里一时之间说了三十七品；如果说其他的道门，十想等都包括在三十七品中。

这三十七品，如众药和合，足以治疗一切众生的病，所以不用多说。

如佛虽然有无量的力，只说十力，对度众生的事就足够了。

#### （一）三十七品以十法为根本

这三十七品，以十法为根本。

哪十法？信、戒、思惟、精进、念、定、慧、除、喜、舍。

信，是信根、信力；戒，是正语、正业、正命；精进，是四正勤、精进根、精进力、精进觉、正精进；念，是念根、念力、念觉、正念；定，是四如意足、定根、定力、定觉、正定；慧，是四念处、慧根、慧力、择法觉、正见。

这些法：念随顺智慧，在所缘中止住，这时名为念处。破除邪法，在正道中行，所以名为正勤。收摄其心安稳于所缘中，所以名为如意足。以柔软的智慧之心得到，所以名为根。以锐利的智慧之心得到，所以名为力。在修道中起作用，所以名为觉。在见道中起作用，所以名为道。

#### （二）三十七品的次第

问：应当先说道，为什么？行道之后才能得到诸善法；譬如人先走路，然后才能到达目的地。现在为什么颠倒，先说四念处，后说八正道？

答：不是颠倒。三十七品，是最初想要入道时的名字。

如修行者到师长那里，听闻道法时，先用念来持守这法，这时名为念处。

持守之后，从法中求果，所以精进修行，这时名为正勤。

因为精进多了，心就散乱，收摄其心使之调柔，所以名为如意足。

心调柔之后，生起五根。

诸法实相甚深难解，因为有信根所以能信，这名为信根；不惜身命，一心求道，这名为精进根；常念佛道，不念其余的事，这名为念根；常收摄其心在道中，这名为定根；观察四谛实相，这名为慧根。

这五根增长，能遮挡烦恼；如大树的力量能遮挡水流。这五根增长时，能转入深法，这名为力。

得到力之后，分别道法有三部分：

择法觉、精进觉、喜觉，这三法，在行道时如果心沉没，能使之振起。

除觉、定觉、舍觉，这三法，如果行道时心动摇散乱，能收摄使之安定。

念觉在两处都起作用，能积集善法，能遮挡恶法；如守门人，有利的让他进来，无益的赶出去。

如果心沉没时，以念觉用前三法使之振起；如果心散乱时，以念觉用后三法使之收摄。从无觉到真实之觉，这七件事能使人到达，所以名为觉分。

得到这些法，安稳具足之后，想要进入涅槃无为之城，所以修行这些法，这时名为道。

### 三、四念处

问：什么是四念处？

答：身念处，受、心、法念处，这是四念处。

观察这四法，各有四种观：观身不净，观受是苦，观心无常，观法无我。这四法虽然各有四种观，身应当多观不净，受多观苦，心多观无常，法多观无我。

为什么？凡夫还没有入道时，在这四法中，以邪行生起四种颠倒：在诸不净法中起净颠倒，在苦中起乐颠倒，在无常中起常颠倒，在无我中起我颠倒。为了破除这四种颠倒，所以说这四念处；为了破除净颠倒，说身念处；为了破除乐颠倒，说受念处；为了破除常颠倒，说心念处；为了破除我颠倒，说法念处。

所以说四种，不少也不多。

#### （一）身念处：五种不净

问：怎样得到这四念处？

答：修行者依净戒而住，一心修行精进，观察身体的五种不净之相。

哪五种？一是生处不净，二是种子不净，三是自性不净，四是自相不净，五是究竟不净。

##### 1. 生处不净

什么名为生处不净？

头、足、腹、脊、胁、肋等诸不净之物和合，名为女身。其内有生脏、熟脏、屎尿等不净，在外有烦恼与业的因缘之风，吹动识的种子，使之进入生熟二脏之间。或八个月，或九个月，如在屎尿坑中。如偈中说：

```
是身为臭秽，　　不从花间生，
亦不从瞻卜，　　又不出宝山。
```

大意：这身体是臭秽的，不是从花间所生，也不是从瞻卜花中生，又不是出自宝山。

这名为生处不净。

##### 2. 种子不净

种子不净：父母以妄想邪忆念之风吹动淫欲之火，血髓膏脂流动，受热变为精。由于宿世业行的因缘，识的种子住在赤白二精之中，这名为身体的种子。如偈中说：

```
是身种不净，　　非余妙宝物，
不由净白生，　　但从尿道出！
```

大意：这身体的种子不净，不是其他美妙的宝物，不是由清净洁白之物所生，只是从尿道中出来的！

这名为种子不净。

##### 3. 自性不净

自性不净：从脚到头顶，四周一层薄皮，其中所有的不净之物充满；用衣服装饰，以洗浴、花香打扮，以上等的饭食、各种美味佳肴喂养，经过一夜，都变为不净。即使穿上天衣、吃天食，因为身体本性的缘故，也都变为不净，何况人间的衣食？如偈中说：

```
地水火风质，　　能变除不净，
倾海洗此身，　　不能令香洁！
```

大意：地、水、火、风这四大之质，能够改变消除不净之物；然而倾尽大海之水来洗这身体，也不能使它香洁！

这名为自性不净。

##### 4. 自相不净

自相不净：这身体九孔常流出不净，眼中流出眼屎、泪水，耳中出耳垢，鼻中流涕，口中吐出涎唾，大小便道常排出屎尿，以及诸毛孔流出汗水等不净。如偈中说：

```
种种不净物，　　充满于身内；
常流出不止，　　如漏囊盛物。
```

大意：种种不净之物，充满在身体之内，常常流出不止，如同漏底的袋子装着东西。

这名为自相不净。

##### 5. 究竟不净

究竟不净：这身体如果投入火中就成为灰，如果被虫吃就成为屎，在地上就腐坏为土，在水中就膨胀烂坏，或者被水虫所吃。一切死尸之中，人身最不净。不净之法，在九相中会详细说。如偈中说：

```
审谛观此身，　　终必归死处。
难御无反复，　　背恩如小人。
```

大意：仔细观察这身体，终究必定归于死亡；它难以驾驭，反复无常，背弃恩义，如同小人。

这名为究竟不净。

再者，这身体出生时、死亡时，所接近身体的物品，所安置身体的处所，都成为不净；如香美的净水，随着百川流动，进入大海之后，就变成咸苦。

身体所吃的种种美味，好色、好香、细滑的上等饭食，进入腹中这大海，就变成不净。这身体就是这样从生到死，常有不净，非常可厌！

##### 6. 身苦、无常、无我

修行者思惟：这身体虽然不净，如果稍有常住，还算好些，但它又是无常的。

虽然不净、无常，如果稍有快乐，还算好些，但它又是大苦。

这身体是众苦生起之处，如水从地中生，风从空中出，火因木而有；这身体也是这样，内外诸苦都从身体而出。

内苦名为老、病、死等，外苦名为刀杖、寒热、饥渴等；因为有这身体，所以有这些苦。

问：身体不只是苦的本性，也从身体而有乐；如果没有身体，随意的五欲由谁来享受？

答：四圣谛中的苦，圣人知道它确实是苦，愚夫却认为是乐；圣人所说真实可依，愚人所惑应当舍弃。

这身体确实是苦，因为止息了大苦，所以把小苦当作乐。譬如应当被处死的人，得到以刑罚代替死刑，非常欢喜；刑罚实际上是苦，因为代替了死，所以认为是乐。

再者，新的苦被当作乐，旧的苦才被当作苦：如刚坐下时快乐，久了就生苦；刚开始走、站、卧也快乐，久了也成为苦。屈伸、俯仰、眨眼、喘息，苦常随身；从初受胎，出生到死亡，没有快乐的时候。

如果你认为享受淫欲是乐，那是因为淫欲之病重，所以追求外在的女色，得到的越多，患病越重。如患疥疮的人，向火搔痒烘烤，当时有小小的快乐，大痛却更加深重；这样的小乐，也是因为病的因缘才有，不是真实的乐，没有病的人看到，会生起慈悯之心。离欲的人看着沉溺淫欲的人，也是这样，怜悯他们这样狂惑，被欲火所烧，受得越多，苦也越多。

像这样等等种种因缘，知道身体的苦相、苦因。修行者知道身体只是不净、无常、苦的东西，不得已而养育它；譬如父母生了孩子，孩子又顽劣暴戾，因为是自己所生，必定要养育成人。身体实际上没有我，为什么？因为不自在。譬如患风病的人，不能俯仰行走；患咽喉阻塞的人，不能说话。所以知道身体不自在。如人有东西，可以随意取用；身体却不能这样，因为不自在，所以确知无我。

修行者思惟这身体是这样不净、无常、苦、空、无我，有像这样等等无量的过恶。像这样等等种种观察身体，这名为身念处。

#### （二）受念处

得到这身念处的观察之后，又思惟：众生因为什么因缘贪着这身体？因为乐受。

为什么？

从内六根、外六尘和合，生起六种识。六种识中生起三种受：苦受、乐受、不苦不乐受。这乐受是一切众生所想要的，苦受是一切众生所不想要的，不苦不乐受则不取也不弃。如偈中说：

```
若作恶人及出家，　　诸天世人及蠕动，
一切十方五道中，　　无不好乐而恶苦。
狂惑颠倒无智故，　　不知涅槃常乐处！
```

大意：无论作恶之人还是出家之人，诸天、世人以及蠕动的小虫，在一切十方五道之中，没有不喜好快乐而厌恶痛苦的。因为狂惑颠倒、没有智慧，所以不知道涅槃这常乐之处！

修行者观察这乐受，如实了知它，没有乐，只有众苦。为什么？乐名为真实的乐，没有颠倒。一切世间的乐受，都从颠倒而生，没有真实的。

再者，这乐受，虽然是想求乐，却能得到大苦。

如偈中说：

```
若人入海遭恶风，　　海浪崛起如黑山；
若入大阵斗战中，　　经大险道恶山间。
豪贵长者降屈身，　　亲近小人为色欲。
如是种种大苦事，　　皆为著乐贪心故！
```

大意：有人入海遇到恶风，海浪耸起如黑山；有人进入大阵战斗之中，经过险道与恶山之间；豪贵的长者降低身份，为了色欲去亲近小人。像这样种种大苦之事，都是因为执着快乐的贪心！

因此，知道乐受能生起种种苦。

再者，佛虽然说了三种受，有乐受，因为乐少，所以名为苦；如一斗蜜投入大河，就失去了它的味道。

问：如果世间之乐因为颠倒的因缘所以是苦，诸圣人从禅定所生的无漏之乐，应当是真实的乐。为什么？这乐不是从愚痴颠倒而有，这怎么会是苦？

答：这不是苦！

佛虽然说无常就是苦，是就有漏法而说苦。为什么？

凡夫对有漏法心生执着，因为有漏法无常、失坏，所以生苦；对无漏法心不执着，所以虽然无常，不能生起忧悲苦恼等，所以不名为苦，也因为诸使不能驱使它。

再者，如果无漏之乐是苦，佛就不必另外说道谛，因为它已被苦谛所摄。

问：有两种乐：有漏之乐，无漏之乐。有漏之乐下贱弊恶，无漏之乐上妙。为什么在下贱之乐中生起执着，在上妙之乐中却不生执着？在上妙之乐中生起的执着应当更多，如对金银宝物，贪着应当更重，怎么能与草木相同？

答：无漏之乐上妙而智慧多，因为智慧多，所以能离开这执着。有漏之乐中爱等结使多，爱是执着的根本；真实的智慧能离开它，所以不执着。

再者，无漏的智慧，常观察一切无常；因为观察无常，所以不生起爱等诸结使。譬如羊靠近老虎，即使得到好草美水也不能长肥；这样，诸圣人虽然享受无漏之乐，因为无常与空的观察，所以不生染着的油脂。

再者，无漏之乐不离三三昧、十六圣行，常常没有众生之相。如果有众生之相，就生执着之心；所以无漏之乐虽然上妙，也不生执着。

像这样种种因缘，观察世间的乐受是苦，观察苦受如箭，观察不苦不乐受是无常败坏之相。这样，在乐受中不生欲着，在苦受中不生瞋恚，在不苦不乐受中不生愚痴，这名为受念处。

#### （三）心念处

修行者思惟：因为乐而贪着身体，是谁在受这乐？思惟之后，知道是由心来受，众生因为心狂颠倒，所以受这乐。

应当观察这心是无常生灭之相，一念都不停住，没有能受乐的；人因为颠倒，所以认为得以受乐。为什么？

最初想要受乐时的心，与乐生起时的心不同，各自互不相及，怎么能说心在受乐？

过去之心已经灭了，所以不受乐；未来之心还没有生，所以不受乐；现在之心一念停住的时间极快，所以不觉得受乐。

问：过去、未来之心不应当受乐，现在之心一念停住时应当受乐，为什么说“不受”？

答：我已经说了，它过去得极快，所以不觉得受乐。

再者，诸法因为是无常之相，所以没有停住的时候；如果心有一念停住，第二念时也应当停住，这就是常住，没有灭相。如佛说：“一切有为法有三相。”住相之中也有灭相；如果没有灭，就不应当是有为之相。

再者，如果法后来有灭，应当知道最初就已经有灭。譬如人穿新衣，如果穿的第一天不旧，第二天也不应当旧，这样乃至十年，应当常新；不应当旧，而实际上已经旧了。应当知道旧与新同时就有，只是微细所以不觉察；旧的事实已经形成，才觉察知道。因此，知道诸法没有停住的时候。心怎么能在停住时受乐？如果没有停住而说受乐，这事不对！

所以，知道没有真实受乐的人；只是世俗法中，因为诸心相续，所以认为是同一个相在受乐。

问：怎样知道“一切有为法无常”？

答：我先前已经说过，现在再回答。

这有为法一切都隶属于因缘，所以无常；因为先无今有、今有后无，所以无常。

再者，因为无常之相常随逐有为法，因为有为法无有增减，因为一切有为法相互侵克，所以无常。

再者，因为有为法有两种老常随逐：一是将老，二是坏老。

有两种死常随逐：一是自死，二是他杀。

因此，知道一切有为法都是无常。

在有为法中，心的无常最容易认识。

如佛说：“凡夫有时知道身体无常，却不能知道心无常。如果凡夫说身体是常，还算好些；以心为常，是大迷惑！为什么？身体或者住十年、二十年；这心却是一日一月、一时一刻、须臾之间就过去了，生、灭各异，念念不停；想要生起时，生起的是另一个；想要灭去时，灭去的也是另一个，如幻化之事，其实相不可得。”

像这样无量因缘，所以知道心无常，这名为心念处。

#### （四）法念处：破我

修行者思惟：这心属于谁？谁驱使这心？观察之后，不见有主宰；一切法因为因缘和合，所以不自在；不自在，所以没有自性；没有自性，所以无我。如果无我，谁来驱使这心？

问：应当有我！为什么？心能驱使身体，也应当有我能驱使心。譬如国王驱使将领，将领驱使士兵；这样应当有我驱使心，有心驱使身体，为了享受五欲之乐。

再者，因为各自都有我心，所以知道确实有我。如果只有身体，因为心颠倒而执计有我，为什么不在他人身中生起我执？

因为这样的相，知道各自都有我。

答：如果心驱使身体，有我驱使心，就应当另有驱使我的人！

如果另有驱使我的人，这就是无穷。又如果另有驱使我的人，就有两个神我。

如果再没有驱使我的人，只是我能驱使心，那也应当只是心能驱使身体。

如果你认为心隶属于神我，除去心，神我就无所知。

如果无所知，怎么能驱使心？

如果神我有知的相，又何必用心？

因此，知道只是心有识的相，所以自己能驱使身体，不必依靠神我。如火的本性能烧物，不必依靠人。

问：火虽然有燃烧之力，没有人就不能使用；心虽然有识的相，没有神我就不能驱使。

答：诸法因为有相，所以有；这神我因为无相，所以无。你虽然想以气息出入、苦乐等作为神我之相，这事不对！为什么？出入息等是身体之相，受苦乐等是心之相，怎么能以身、心作为神我之相？

再者，有时火自己能烧，不依靠人。只是因为名称，才名为人在烧。你的论点落入负处，为什么？神我就是人，不应当以人来比喻人。

又你说：“因为各自都有我心，所以知道确实有我；如果只有身体，因为心颠倒而执计有我，为什么不在他人身中生起我执？”

你对有我、无我还没有弄清楚，却问“为什么不在他人身中生起我执”？自身、他身都是从我而有，而我也不可得。无论色相、无色相，常、无常，有边、无边，有去者、不去者，有知者、不知者，有作者、无作者，有自在者、不自在者，像这样等等我之相，都不可得；如上面〈我闻品〉中所说。

像这样等等种种因缘，观察诸法从和合因缘而生，没有真实之法是我，这名为法念处。

#### （五）性念处、共念处、缘念处（阿毗昙分别）

这四念处有三种：性念处、共念处、缘念处。

什么是性念处？

观察身体的智慧，是身念处；观察诸受的智慧，名为受念处；观察诸心的智慧，名为心念处；观察诸法的智慧，名为法念处。这是性念处。

什么名为共念处？

以观身为首，因缘所生之道，无论有漏或无漏，是身念处；以观受、观心、观法为首，因缘所生之道，无论有漏或无漏，名为受、心、法念处。这是共念处。

什么是缘念处？

一切色法，就是十入以及法入的少分，这名为身念处；六种受：眼触所生之受，耳、鼻、舌、身、意触所生之受，这名为受念处；六种识：眼识，耳、鼻、舌、身、意识，这名为心念处；想众、行众以及三种无为法，这名为法念处。这名为缘念处。

##### 1. 性念处

这性念处，因为是智慧之性，所以无色；不可见；无对。或有漏，或无漏；有漏的有报，无漏的无报。都是有为法，因缘所生；为三世所摄；为名所摄；为外入所摄。

以慧了知。有漏的是断知，无漏的不是断知；有漏的可断，无漏的不可断。是修法；是无垢法；是果也有果；一切都不是受法；不是四大所造；是有上法。有漏的念处是“有”，无漏的念处是“非有”。都是相应因。

四念处摄六种善中的一种，即行众的善分；行众的善分也摄四念处；与不善、无记、漏不相摄。

或者有是四念处而不是有漏的，或者有是有漏而不是四念处的；或者有是四念处也是有漏的，或者有不是四念处也不是有漏的。

是四念处而不是有漏的，是无漏性的四念处。

是有漏而不是四念处的，是除了有漏性四念处以外，其余的有漏部分。

是四念处也是有漏法的，是有漏性的四念处。

不是四念处也不是有漏法的，是除了无漏性四念处以外，其余的无漏法。

无漏的四句，也是这样。

##### 2. 共念处

共念处，在共念处中，身业、口业是色，其余的不是色；一切都不可见；都无对。或有漏，或无漏。都是有为。有漏的念处有报，无漏的念处无报。因缘所生，为三世所摄；身业、口业为色所摄，其余的为名所摄。心、意、识为内入所摄，其余的为外入所摄。

以慧了知。有漏的是断知，无漏的不是断知；有漏的可断，无漏的不可断。都是修法；都是无垢法。是果也有果；一切都不是受法。身业、口业是四大所造，其余的不是四大所造。都是有上法。有漏的念处是“有”，无漏的念处是“非有”。身业、口业以及心不相应诸行，不是相应因；其余的是相应因。

五善分摄四念处，四念处也摄五善分，其余的不相摄；与不善、无记、漏法不相摄。

或者有是四念处而不是有漏的，或者有是有漏而不是四念处的；或者有是四念处也是有漏的，或者有不是四念处也不是有漏的。

是四念处而不是有漏的，是无漏的四念处。

是有漏而不是四念处的，是除了有漏的四念处以外，其余的有漏法。

是四念处也是有漏的，是有漏的四念处。

不是四念处也不是有漏的，是虚空、数缘尽（择灭）、非数缘尽（非择灭）。

或者有是四念处而不是无漏的，或者有是无漏而不是四念处的；或者有是四念处也是无漏的，或者有不是四念处也不是无漏的。

是四念处而不是无漏的，是有漏的四念处。

是无漏而不是四念处的，是三种无为法。

是四念处也是无漏的，是无漏的四念处。

不是四念处也不是无漏的，是除了有漏的四念处以外，其余的有漏法。

##### 3. 缘念处

这缘念处，在缘念处中：

一种念处是色，三种念处不是色。

三种不可见，一种应当分别：身念处有可见的、有不可见的；可见的是一入，不可见的是九入以及一入的少分。

三种无对，一种应当分别：身念处有对的是十入，无对的是一入的少分。

身念处有漏的是十入以及一入的少分，无漏的是一入的少分；受念处，与有漏意相应的是有漏，与无漏意相应的是无漏；心念处也是这样；法念处，有漏的想众、行众是有漏；无漏的想众、行众以及无为法，是无漏。

三种是有为，一种应当分别：法念处的想众、行众是有为，三种无为法是无为。

不善的身念处以及善的有漏身念处是有报，无记的身念处以及无漏的是无报；受念处、心念处、法念处也是这样。

三种从因缘生，一种应当分别：法念处中有为的从因缘生，无为的不从因缘生。

三种为三世所摄，一种应当分别：法念处中有为的为三世所摄，无为的不为三世所摄。

一种念处为色所摄，三种为名所摄。

一种念处为内入所摄；受念处、法念处为外入所摄；一种应当分别：身念处或为内入所摄，或为外入所摄；五内入是为内入所摄，五外入以及一入的少分是为外入所摄。

以慧了知。有漏的是断见，无漏的不是断见。有漏的可断，无漏的不可断。

修应当分别：身念处中善的应当修，不善以及无记的不应当修；受念处、心念处也是这样；法念处中有为的善法应当修，不善、无记以及数缘尽不应当修。

垢应当分别：身念处中隐没的是垢，不隐没的不是垢；受、心、法念处也是这样。

三种念处是果也有果；一种应当分别：法念处或者是果而非有果，或者是果也有果，或者非果非有果；数缘尽，是果而非有果；有为的法念处，是果也有果；虚空、非数缘尽，是非果非有果。

三种不是受法；一种应当分别：身念处中堕在身数之中的是受法，不堕在身数之中的不是受法。

三种不是四大所造，一种应当分别：身念处的九入以及二入的少分，是四大所造；一入的少分，不是四大所造。

三种念处是有上法，一种应当分别：法念处中有为法以及虚空、非数缘尽，是有上；涅槃是无上。

四念处如果是有漏，就是“有”；如果是无漏，就是“非有”。

两种念处是相应因，一种念处是不相应因；一种应当分别：受念处、心念处，是相应因；身念处，是不相应因；法念处中，想众以及相应的行众是相应因，其余的是不相应因。

四念处的部分摄六种善法，六种善法也摄四念处的部分。不善的部分、无记的部分，也是这样随其种类而相摄。

三种漏摄一种念处的部分，一种念处的部分也摄三种漏。

有漏摄四念处的部分，四念处的部分也摄有漏。

无漏摄四念处的部分，四念处的部分也摄无漏。

像这样等等意义，在〈千难〉中有详细的说明。

【译注】本节自“是四念处有三种”至“〈千难〉中广说”，是阿毗昙家以种种门（色非色、可见不可见、有对无对、有漏无漏、有为无为、有报无报、三世摄否、名色摄、内外入摄、断与修、垢与无垢、果与有果、受与非受、大种所造与否、有上无上、相应因与否，以及四句料简）分别四念处的标准体例。译文逐句直译，不作展开；读者把握“性念处是智慧本身，共念处是以智慧为首的诸法，缘念处是所缘的身受心法”这一纲领即可。

#### （六）内外身、受、心、法

问：什么是内身？什么是外身？如果内身、外身都已经包括尽了，为什么还要说内外身观？

答：内名为自身，外名为他身。

自身有两种：一是身内的不净，二是身外的皮、毛、爪、发等。

再者，修行者观察死尸膨胀、烂坏，取这相，自己观察自身也是这样的相：这样的事，我还没有离开这法。死尸是外身，修行者的身体是内身。如修行者有时看见端正的女人而心生执着，当即观察她的身体不净，这是外；自己知道我的身体也是这样，这是内。

再者，眼等五根为内身，色等五尘为外身；四大为内身，四大所造之色为外身；能觉知苦乐之处为内身，不能觉知苦乐之处为外身；自身以及眼等诸根，是内身；妻子、财宝、田宅、所用之物，是外身。

为什么？因为一切色法都是身念处所观。

修行者推求这内身，有净、常、乐、我吗？仔细推求，都不可得，如先前所说的观法。内观不能得到，外面或许有吧？为什么？外物是一切众生执着之处。观察外身时，也不可得。

又作这样的念头：“我内观得不到，外面或许有吧？”外观也同样得不到，自己想：“我或许有误，现在应当把内外合起来观察。”观内、观外，这是别相；同时都观，这是总相。

总观、别观，都完全不可得，所观之事就完成了。

问：身念处可以有内外，诸受是外入所摄，怎么能分别有内受、外受？

答：佛说有两种受：身受、心受。身受是外，心受是内。

又与五识相应的受是外，与意识相应的受是内。

以十二入为因缘，所以诸受生起。由内六入部分所生的受是内，由外六入部分所生的受是外。

粗的受是外，细的受是内。

两种苦：内苦、外苦。

内苦有两种：身苦、心苦。

身苦，是身痛、头痛等四百零四种病，这是身苦；心苦，是忧、愁、瞋、怖、嫉妒、疑，像这样等等是心苦。

二苦和合，这是内苦。

外苦有两种：

一是国王、胜过自己的人、恶贼、狮子、虎狼、蚖蛇等的逼害；二是风雨、寒热、雷电、霹雳等。

这两种苦，名为外受。

乐受、不苦不乐受，也是这样。

再者，缘内法的是内受；缘外法的是外受。

再者，一百零八种受，是内受；其余的是外受。

问：心是内入所摄，怎么说观外心？

答：心虽然为内入所摄，因为缘外法，所以名为外心；因为缘内法，所以是内心。

意识是内心，五识是外心。

收摄其心入禅是内心，散乱心是外心。

与内五盖、内七觉相应的心，是内心；与外五盖、外七觉相应的心，是外心。

像这样等等种种分别内外，这是内心、外心。

问：法念处是外入所摄，怎么说观内法？

答：除了受，其余的心所法中，能缘内法的心所法是内法；缘外法的心所法以及无为法、心不相应行，是外法。

再者，意识所缘的法，名为法，如佛所说：“依缘而生意识。”这其中除了受，其余的心所法是内法，其余的心不相应行以及无为法，是外法。

### 四、四正勤

四正勤有两种：一是性正勤，二是共正勤。

性正勤，是为了道而作的四种精进：遮止两种不善法，积集两种善法。

观察四念处时，如果有懈怠心、五盖等诸烦恼覆盖其心，离开信等五种善根时，对于不善法，已经生起的为了断除、还没有生起的不使它生起，勤加精进。

对于信等善根，还没有生起的为了使之生起、已经生起的为了使之增长，勤加精进。

因为精进之法在四念处中多，所以得名为正勤。

问：为什么在七类法中，这四种名为“正勤”，后面八种名为“正道”，其余的不名为“正”？

答：四种精进，心勇猛发动，因为怕出错，所以说“正勤”；行道趣向于法，因为怕落入邪法，所以说“正道”。

性，是四种精进的本性；共，是以四种精进之性为首，因缘所生之道。

或有漏、或无漏，或有色、或无色，如上面所说。

### 五、四如意足

修行四正勤时，心稍有散乱，所以以定来收摄其心，所以名为如意足。

譬如美食，少了盐就没有味道，得到盐就味道充足而如意。

又如人有两只脚，又得到好马好车，想去哪里就能到哪里。

修行者这样得到四念处的真实智慧，在四正勤中正确精进；因为精进，所以智慧增多，定力稍弱，得到四种定来收摄其心，所以智慧与定力均等，所愿都能得到，所以名为如意足。

问：四念处、四正勤中已经有定，为什么不名为如意足？

答：那里虽然有定，智慧、精进之力多，定力弱，所以修行者不能如意如愿。四种定：以欲为主而得定；以精进为主而得定；以定为因缘所生之道，或有漏、或无漏。

以心为主而得定；以思惟为主而得定；以定为因缘所生之道，或有漏、或无漏。

共同的善五众，名为共如意足。

以欲为主等四种定，名为性如意足。

四正勤、四如意足，如性念处、共念处中那样，详细分别说明。

### 六、五根、五力

五根：相信道以及助道的善法，这名为信根；修行者修行这道与助道之法时，勤求不息，这名为精进根；念道以及助道之法，再没有其他念头，这名为念根；一心念而不散，这名为定根；为了道以及助道之法，观察无常等十六行相，这名为慧根。

这五根增长，不被烦恼所破坏，这名为力，如五根中所说。

这五根、五力，为行众所摄；常常共同相应，随心而行，是心所法，与心同生、与心同住、与心同灭。如果有这些法，心就落入正定；如果没有这些法，心就落入邪定。

### 七、七觉分

七觉分，如先前所说的意义。

问：先前虽然说了意义，却不是以阿毗昙法来说的。

答：现在再说，如四念处的意义那样。

这七觉分，无色，不可见，无对，无漏，有为，因缘所生，为三世所摄，为名所摄，为外入所摄。

以慧了知，不是断见，不可断，是修法，是无垢法，是果也有果，不是受法，不是四大所造，是有上法，是非有，是相应因。

二种善分摄七觉分，七觉分摄二种善分；与不善、无记、漏、有漏法不相摄。

无漏的二分摄七觉分，七觉分摄无漏的二分。

像这样等等种种，如〈千难〉中详细说明。

### 八、八圣道分

八圣道分，如先前所说。

正见是智慧，如四念处、慧根、慧力、择法觉中所说。

正思惟，是观察四谛时与无漏心相应，思惟发动，觉知衡量。

正方便（正精进），如四正勤、精进根、精进力、精进觉中所说。

正念，如念根、念力、念觉中所说。

正定，如如意足、定根、定力、定觉中所说。

正语、正业、正命，现在来说：

除去四种邪命，收摄口业，以无漏智慧除去、舍弃、远离其余的口之邪业，这名为正语。

正业也是这样。

五种邪命，以无漏智慧除去、舍弃、远离，这是正命。

问：什么是五种邪命？

答：一是修行者为了利养，诈现奇异特别之相；二是为了利养，自己宣说自己的功德；三是为了利养，占相吉凶，为人解说；四是为了利养，高声显示威势，使人畏敬；五是为了利养，称说自己所得的供养，以打动人心。

因为以邪的因缘维持生命，所以这是邪命。

这八正道有三分：三种为戒分，三种为定分，两种为慧分。

慧分、定分的分别，如先前所说。

戒分，现在来说：

戒分是色性，不可见，无对，无漏，有为，无报，因缘所生，为三世所摄，为色所摄而不为名所摄，为外入所摄。

以慧了知，不是断见，不可断，是修法，是无垢法，是果也有果，不是受法，是四大所造，是有上法，是非有法，是相应因。

一种善分摄三种正道，三种正道摄一种善分；与不善、无记、漏、有漏不相摄。

无漏的一法摄三种正道，三种正道也摄无漏的一法。

像这样等等种种分别，如《阿毗昙》中详细说明。

#### 诸地中道品的多少

这三十七品，在初禅地中全都具有；在未到地中有三十六种，除去喜觉；在第二禅中也有三十六种，除去正行；在中间禅、第三禅、第四禅中有三十五种，除去喜觉，除去正行。

在三无色定中有三十二种，除去喜觉、正行、正语、正业、正命；在有顶中有二十二种，除去七觉分、八圣道分。

在欲界中有二十二种，也是这样。

这是声闻法中所分别的意义。

### 九、摩诃衍的三十七品

问：摩诃衍所说的三十七品的意义是怎样的？

#### （一）菩萨身念处

答：菩萨摩诃萨修行四念处，观察这内身无常、苦，如病、如痈，如火焰的聚集，败坏，不净充满，九孔流出不净，这是一座会行走的厕所。这样观察身体，污秽流溢，没有一处干净；骨头是干的，外面涂着肉，筋缠绕着，皮包裹着。由前世所受有漏业的因缘，以及今世的沐浴、花香、衣服、饮食、卧具、医药等所成就。如车有两个轮子，因为牛力牵引，才能到达某处。以前世、今世两世的因缘成就这身体之车，被识之牛所牵引，周旋往返。

这身体是四大和合所造，如水沫的聚集，虚而不坚固。

这身体无常，久了必定破坏。

这身体之相，在身中不可得，也不在外，也不在中间。

身体不能自己觉知，无知无作，如墙壁瓦石。

这身体中没有确定的身相，没有造作这身体的人，也没有驱使造作的人。

这身体的前际、后际、中际，都不可得。

八万户虫、无量的疾病，以及饥渴、寒热、刑罚残害等，常恼害这身体。菩萨摩诃萨这样观察身体，知道不是我的身体，也不是他人所有；不得自在，有作的也有不作的。这身体，身相是空的，从虚妄因缘而生；这身体是假有，隶属于本来的业因缘。

菩萨自念：我不应当吝惜身命。为什么？

这身相不合不散，不来不去，不生不灭，无所依倚。循身观察这身体，因为无我、无我所，所以是空；因为空，所以没有男女等诸相；因为无相，所以不作愿求。这样观察，得以进入无作的智慧之门。知道身体无作、无作者，只是从诸法因缘和合而生。造作这身体的诸因缘，也是从虚妄颠倒而有；这因缘之中也没有因缘之相，这因缘所生也没有生相。这样思惟，知道这身体从本以来没有生相，知道这身体无相、无可取。因为无生，所以无相；因为无相，所以无生；只是诳惑凡夫，所以名为身。

菩萨这样观察身体的实相时，离开种种染欲与执着，心常系念于身，作循身观，这名为菩萨的身念处。

观外身、观内外身也是这样。

#### （二）菩萨受念处

菩萨怎样观察诸受？

观察内受，这受有三种：或苦、或乐、或不苦不乐。

这些受无所从来，灭也无所去，只是从虚诳颠倒的妄想而生，是果报，隶属于前世的业因缘。这菩萨这样推求诸受，不在过去，不在未来，不在现在；知道这些受是空、无我、无我所，是无常、破坏之法。

观察这三世诸受：空、无相、无作，进入解脱之门。

也观察诸受的生灭；也知道诸受不合不散、不生不灭，这样进入不生之门。

知道诸受不生，所以无相；因为无相，所以不生；这样了知之后，系心于所缘之中。如果有苦、乐、不苦不乐来，心不领受、不执着、不作依止。像这样等等因缘观察诸受，这名为受念处。

观外受、观内外受也是这样。

#### （三）菩萨心念处

菩萨怎样观察心念处？

菩萨观察内心，这内心有三相：生、住、灭；作这样的念头：

这心无所从来，灭也无所去，只是从内外因缘和合而生。

这心没有确定真实之相，也没有真实的生、住、灭，也不在过去、未来、现在世中。

这心不在内、不在外、不在中间。

这心也无性无相；也没有生它的人，没有使它生的人。

外有种种杂乱的六尘因缘，内有颠倒的心相；因为生灭相续，所以勉强名为心。

这样，在心中真实的心相不可得。

这心性不生不灭，常是清净之相；因为客尘烦恼之相附着，所以名为不净之心。

心不能自知，为什么？因为这心的心相是空的。

这心从本到末没有实法，这心与诸法无合无散，也没有前际、后际、中际，无色、无形、无对，只是从颠倒虚诳而生。

这心空、无我、无我所，无常、无实，这名为随顺心观。

知道心相无生，进入无生之法中。为什么？这心无生，无性无相，智者能知。

智者虽然观察这心的生灭之相，也得不到真实的生灭之法；不分别垢净，而得心清净。

因为这心清净，所以不被客尘烦恼所染。

像这样等等观察内心。观外心、观内外心，也是这样。

【译注】菩萨心念处中“是心性不生不灭，常是净相，客烦恼相著故，名为不净心”一语，与声闻心念处“观心无常”的路数相对：声闻观心念念生灭以破常倒，菩萨则观心无来无去、不在三世、不在内外，心相空而不自知，于是说心性本净、客尘所染。论主随即说“不分别垢净而得心清净”，可见这里的“净”不是与垢相对的另一种相，而是心相空本身。

#### （四）菩萨法念处

菩萨怎样观察法念处？

观察一切法，不在内，不在外，不在中间；不在过去、未来、现在世中；只是从因缘和合的妄见而生，没有真实确定的，没有“这是法”“这是谁的法”。诸法之中，法相不可得，也没有法或合或散。一切法无所有，如虚空；一切法虚诳，如幻；诸法之性清净，互不污染。诸法无所领受，因为诸受无所有；诸法无所知，因为心与心所法是虚诳的。这样观察时，不见有法，无论一相或异相，观察一切法空、无我。

这时作这样的念头：

一切诸法因为是因缘所生，所以没有自性，这就是真实的空；因为真实的空，所以没有相；因为没有相，所以无作；因为无作，所以不见法或生或灭；住在这智慧中，进入无生法忍之门。

这时虽然观察诸法的生灭，也进入无相之门。为什么？一切法离开诸相，这是智者所了解的。

这样观察时，系心于所缘之中，随顺诸法之相，不念身、受、心、法，知道这四法没有处所，这是内法念处。

外法念处、内外法念处也是这样。

四正勤、四如意足，也应当这样分别，观察其空而无处所。

#### （五）菩萨五根、五力

什么是菩萨所行的五根？

菩萨摩诃萨观察五根、修习五根。

信根：相信一切法从因缘而生，从颠倒妄见之心而生，如旋转的火轮，如梦如幻。相信诸法不净，无常、苦、无我，如病、如痈、如刺，是灾变败坏之物。

相信诸法无所有，如空拳诳骗小孩。

相信诸法不在过去，不在未来，不在现在，无所从来，灭无所去。

相信诸法空、无相、无作，不生不灭，没有信之相，也没有相；而相信持戒、禅定、智慧、解脱、解脱知见。

因为得到这信根，所以不再退转。以信根为首，善于安住持戒；安住持戒之后，信心不动不转。一心相信依于业的果报，离开诸邪见；不再相信其他的言论，只接受佛法，相信众僧。

住在真实之道中，直心柔软而能忍，通达无碍，不动不坏，得力而自在，这名为信根。

精进根：昼夜常修精进，除去五盖，摄护五根。对诸甚深的经法，想要得到、想要知道、想要修行、想要背诵、想要读，乃至想要听闻。

如果有诸不善的恶法生起，使之迅速灭除；还没有生起的，使之不生。

还没有生起的诸善法，使之生起；已经生起的，使之增长广大。

也不厌恶不善法，也不爱着善法，得到平等的精进，直进而不退转。

因为得到正精进与定心，所以名为精进根。

念根：菩萨常一心念，想要具足布施、持戒、禅定、智慧、解脱；想要清净身口意业，在诸法生、灭、住、异的智慧中，常一心念。一心念苦、集、灭、道；一心念分别根、力、觉、道、禅定、解脱，以及其生灭、入出；一心念诸法不生不灭，无作无说，为了得到无生的智慧、具足诸佛之法；一心念不使声闻、辟支佛之心得以进入。常念不忘这样甚深清净的诸法，因为观行而得，所以得到这样自在的念，这名为念根。

定根：菩萨善于取定之相，能生起种种禅定。清清楚楚地了知定的门径，善知入定，善知住定，善知出定。对定不执着、不味着，不作依止。善知所缘，善知坏缘，自在地游戏于诸禅定，也知无所缘之定，不随他人之语。不专门随着禅定而行，自在出入而无碍，这名为定根。

慧根：菩萨为了灭尽苦，成就圣者的智慧。这智慧是为了离开诸法，为了涅槃。以智慧观察一切三界无常，被三衰、三毒之火所烧。观察之后，在三界之中，智慧也不执着一切三界，转为空、无相、无作解脱门。一心为了求佛法，如救头上的火。这菩萨的智慧无人能破坏，在三界中无所依，在随意的五欲之中，心常远离。因为慧根之力，积聚无量功德，对诸法实相锐利地契入，无疑无难。对世间无忧，对涅槃无喜，因为得到自在的智慧，所以名为慧根。

菩萨得到这五根，善于了知众生诸根之相：

知道染欲众生之根，知道离欲众生之根；知道瞋恚众生之根，也知道离瞋恚众生之根；知道愚痴众生之根，也知道离愚痴众生之根；知道将要堕入恶道的众生之根，知道将要生在人中的众生之根，知道将要生在天上的众生之根；知道钝的众生之根，知道利的众生之根；知道上、中、下众生之根；知道有罪众生之根，知道无罪众生之根；知道逆、顺众生之根；知道常生在欲界、色界、无色界的众生之根；知道善根深厚、善根浅薄的众生之根；知道正定、邪定、不定的众生之根；知道轻躁的众生之根，知道持重的众生之根；知道悭贪的众生之根，知道能舍的众生之根；知道恭敬的众生之根，知道不恭敬的众生之根；知道持净戒、不持净戒的众生之根；知道瞋恚、忍辱的众生之根；知道精进、懈怠的众生之根；知道乱心、摄心，愚痴、智慧的众生之根；知道无畏、有畏的众生之根；知道增上慢、不增上慢的众生之根；知道行正道、邪道的众生之根；知道守护诸根、不守护诸根的众生之根；知道求声闻的众生之根，知道求辟支佛的众生之根，知道求佛道的众生之根。

在了知众生诸根之中，因为得到自在的方便之力，所以名为知根。

菩萨修行这五根，使之增长，能破除烦恼，度化众生，得到无生法忍，这名为五力。

再者，天魔外道不能阻挠破坏，这名为力。

#### （六）菩萨七觉分

七觉分：菩萨对一切法不忆不念，这名为念觉分。

在一切法中，推求善法、不善法、无记法都不可得，这名为择法觉分。

不入三界，破坏诸界之相，这名为精进觉分。

对一切造作之法，不生执着之乐，因为忧喜之相已坏，这名为喜觉分。

在一切法中，除去心的所缘，因为所缘不可得，这名为除觉分。

知道一切法常是定相，不乱也不定，这名为定觉分。

对一切法不执着、不依止，也不见这舍心，这名为舍觉分。

菩萨观察七觉分是空，就是这样。

问：这七觉分为什么说得简略？

答：七觉分中，念、慧、精进、定，上面已经详细说过。另外三觉现在来说：

菩萨修行喜觉分，观察这喜不是真实的。为什么？这喜从因缘而生，是造作之法、有法、无常之法、可执着之法。

如果生起执着，这是无常之相，变坏时就生忧；凡夫因为颠倒，所以心中执着。

如果知道诸法实际是空，这时心生悔意：我是受了虚诳。如人在黑暗中被饥渴所逼，吃了不净之物，白天看见了，才发觉不对。

如果这样观察，在真实智慧中生起喜，这是真正的喜。

得到这真正的喜，先除去身的粗重，其次除去心的粗重，然后除去一切法相，得到快乐遍满身心之中，这是除觉分。

既得到喜、除，就舍弃诸观行，就是无常观、苦观、空无我观、生灭观、不生不灭观，有观、无观，非有非无观；像这样等等戏论全都舍弃。为什么？

无相、无缘、无作、无戏论，常寂灭，这才是真实的法相。如果不修行舍，就会有种种诤论。

如果以“有”为实，就以“无”为虚；如果以“无”为实，就以“有”为虚；如果以“非有非无”为实，就以“有无”为虚；对“实”爱着，对“虚”憎恚，生起忧喜之处，怎么能不舍？

得到这样的喜、除、舍，七觉分就具足圆满。

#### （七）菩萨八圣道分

八圣道分：正见、正方便、正念、正定，上面已经说过；正思惟现在来说：

菩萨对诸法空无所得，安住在这样的正见中，观察正思惟之相。知道一切思惟都是邪思惟，乃至思惟涅槃、思惟佛，也都是这样。为什么？断除一切思惟分别，这名为正思惟。

种种思惟分别，都是从不实、虚诳、颠倒而有，分别思惟之相都不存在。菩萨住在这样的正思惟中，不见是正是邪，超过种种思惟分别，这是正思惟。

一切思惟分别全都平等；因为全都平等，所以心不执着；像这样等等名为菩萨正思惟之相。

正语：菩萨知道一切言语都是从虚妄不实、颠倒取相的分别而生，这时菩萨作这样的念头：

言语中没有言语之相，一切口业灭除，了知诸言语的实相，这是正语。

这些言语都无所从来，灭也无所去，这是菩萨修行正语之法。

凡有所说，都住在实相中而说；所以诸经中说：“菩萨住在正语中，能作清净的口业。”了知一切言语的真相，虽然有所说，也不落入邪语。

正业：菩萨知道一切业的邪相，虚妄不实，都是无作之相。为什么？没有一种业可以得到确定之相。

问：如果一切业都空，佛为什么说布施等是善业？杀害等是不善业？其余的动作是无记业？

答：诸业之中，连一种都没有，何况有三种？为什么？如行走时，已经走过之处就没有去的业，还没有到达之处也没有去的业，现在正在去之时也没有去的业；所以没有去的业。

问：已经走过之处应当没有，还没有到达之处也应当没有，现在正在去之处应当是有去！

答：现在正在去之处也没有去。为什么？除去去的业，现在正在去之处不可得；如果除去去的业，现在正在去之处仍可得，那么其中应当有去，然而并不是这样。除去现在正在去之处，就没有去的业；除去去的业，就没有现在正在去之处；这两者相互依待为缘，所以不能只说现在正在去之处有去。

再者，如果现在正在去之处有去的业，离开去的业，应当有现在正在去之处；离开现在正在去之处，应当有去的业。

问：如果是这样，有什么过失？

答：同时就有两个去的业。如果有两个去的业，就有两个去者。为什么？除去去者，就没有去。如果除去去者，现在正在去之处不可得；因为没有现在正在去之处，所以也没有去者。

再者，不去的人也不去，所以没有去的业。如果除去去者与不去者，再没有第三种去者。

问：不去的人不去，应当如此；去的人为什么说不去？

答：除去去的业，去者不可得；除去去者，去的业不可得。像这样等等一切业空，这名为正业。诸菩萨进入一切诸业平等之中，不以邪业为恶，不以正业为善，无所作，不作正业，不作邪业，这名为真实的智慧，就是正业。

再者，在诸法平等之中，无正无邪，如实了知诸业。如实了知之后，不造作也不止息，这样的智者常有正业，没有邪业，这名为菩萨的正业。

正命：一切资生活命的用具，都是正而不邪的。住在不戏论的智慧中，不取正命，不舍邪命，也不住在正法中，也不住在邪法中。常住在清净的智慧中，进入平等的正命，不见命，不见非命，修行这样的真实智慧，所以名为正命。

如果菩萨摩诃萨能这样观察三十七品，就能超过声闻、辟支佛地，进入菩萨位中，渐渐得以成就一切种智。

## 本卷要义

本卷释“以不住法住般若波罗蜜中，不生故，应具足三十七品”。开头就要回答一个尖锐的质疑：三十七品是二乘的涅槃道，不说波罗蜜，不说大悲，菩萨何必学？论主的回答有三层：经论从未说三十七品独属小乘，龙王降雨普同，大小草木各随根受；菩萨久住生死，正需要知道何者是实道，否则无从忍受种种苦恼；更深的是，菩萨以般若力把世间转为涅槃，因为三界和合生、无自性、空、不可取，不可取相即是涅槃。所以论主引“色即是空”与《中论》“涅槃际世间际，一际无有异”，说菩萨得此实相，不厌世间、不乐涅槃，三十七品成为实智之地。箭箭相柱之喻，正是菩萨学道品而不堕涅槃地的写照。

三十七品为何是三十七而不是四念处一门，论主的回答始终落在众生的差别上：心病种种，药亦种种，或一法、二法、三法、四法得度。其根本只是十法：信、戒、思惟、精进、念、定、慧、除、喜、舍。次第的说明尤为清楚：听法时以念持之名念处，求果而精进名正勤，精进多则心散，以定调柔名如意足，心调柔而生五根，根增长遮烦恼名力，心没时以择法、精进、喜振起，心散时以除、定、舍收摄，念觉两处都用，如守门人；安稳具足而入涅槃城，名为道。

声闻的四念处观，论主讲得极其细密：身五种不净，生处、种子、自性、自相、究竟；受是苦，世间乐只是以小苦止大苦、新苦为乐故苦为苦，而无漏乐因无常空观不生染着之脂，如羊近虎；心无常，过去已灭、未来未生、现在一念去疾，新衣初著已有故相；法无我，若我使心则更须有使我者，无穷而有二神。其后的性念处、共念处、缘念处与诸门分别，是阿毗昙的标准体例，论主照录而以“〈千难〉中广说”收住。

摩诃衍的三十七品是本卷真正的落点。同样是四念处，菩萨观身不只是不净，而是身相不在内外中间、无作者、无生相，“但诳凡夫故名为身”；观受无所从来、灭无所至，入不生门；观心则说“心性不生不灭，常是净相，客烦恼相著故名不净心”，而又“不分别垢净而得心清净”；观法则不念身受心法，知四法无处所。五根中的信根，信诸法空无相无作，而仍信戒定慧解脱；七觉分中的念觉是于一切法不忆不念，择法是求善恶无记不可得，舍觉是不见舍心。喜、除、舍一段尤其透彻：连无常观、空观、不生不灭观、非有非无观也要舍，因为以某一者为实，便以另一者为虚，爱憎由此而生。

八正道中的正思惟、正语、正业、正命，在菩萨这里都翻到了另一面：一切思惟皆是邪思惟，乃至思惟涅槃、思惟佛，断一切思惟分别名正思惟；语中无语相名正语；正业则用《中论》“去来”的论证，已去、未去、去时皆无去业，去者与去业相待而俱不可得，不以邪业为恶、不以正业为善，不造不休；正命则不取正命、不舍邪命，不见命、不见非命。同样的三十七个名目，声闻依之出离，菩萨依之入平等，这就是经文“不住法住般若中，不生故具足”的意思。
