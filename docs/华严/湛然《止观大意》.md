# 湛然《止观大意》

唐天台沙门释湛然述

员外李华想知道《摩诃止观》的大意，湛然略述其纲要作答。

## 一、教观门户

先略述本宗教观门户的大概。本宗教门以龙树为始祖。慧文大师只是揭示了向内观照视听的法门而已。到了南岳慧思、天台智者两位大师，又因法华三昧而发陀罗尼，开拓义理之门，观法才周详完备。解释诸经，都以五重玄义来解，以十义融通观法；修观则用五科方便、十乘轨行。

所谓五重：在解释一切经的经文之前，先以五义作玄释，名目相通，义理各异，以总冠别，就是释名、出体、明宗、辨用、判教。《法华经》以前的诸教，尚未合于五重，都是粗；到了《法华经》，名、体、宗、用、教全都是妙。详见《法华玄义》十卷的细释。

所谓十义：

第一，先阐明道理寂绝、亡言离相、不可思议。于一寂之理，不分而分，开出诸谛，就是四种四谛、七种二谛、五种三谛等。或开或合，权实的道理清清楚楚。

第二，能诠的教门，纲目分明，包括秘露，就是渐、顿、不定、秘密，以及藏、通、别、圆。得此八意，一代声教的化导之道便可了知。

第三，经论之间有矛盾，言义相违，不可以情识疏通，不可以博学解释，自古以来执诤不休，历代不止。如今用四悉檀的意趣来会通，无滞不融，取舍自在。

第四，巧破执著，善用诸句，破除能执著之心。依所破之惑，或单或复或具足，无言穷逐，破到尽头。

第五，结正法门，对当行位，使依教修行有方便，依行证果有阶差，贤圣不相混滥，免生增上慢。

第六，随拈一句，纵横无碍，而头绪次第宛然成章。

第七，开章分段，钩锁相承，决疏文势，前后衔接。

第八，随文解释经文，须义顺理当。

第九，翻译方言，令名义通畅不壅塞。

第十，于一一句下，以理观消释，通达观门，与经相合，印心成行，不是数他人的珍宝。

若解释《法华经》，更须明了权实与本迹，才可立行。此经独得称妙，才可依此建立观门的意趣。

所谓五方便与十乘轨行，就是圆顿止观。圆顿止观全依《法华经》而立：

圆顿止观，即法华三昧之异名耳。

（大意：圆顿止观，不过是法华三昧的另一个名称。）

若想修此圆顿三昧，须具足圆满的十乘，才名为圆行。《方便品》的法文虽然简略，《譬喻品》中大白牛车之喻，已经具足了十乘之义。

## 二、前二卷：五略

《摩诃止观》十卷大分为二：前二卷略释纲纪，后八卷广明行相。前面的略明，又开为五：发圆心、修圆行、感圆果、起八教、归三德。

### 发圆心

发圆心在第一卷。约四弘誓、四谛、六即，来简别偏圆发心之相。四弘誓是能发之誓，四谛是所依之境，六即是所经历之位。

誓若无境，名为狂愿；境不辨位，凡圣不分。

（大意：发誓若没有所依之境，名为狂愿；有境而不辨位次，凡圣就分不清了。）

依境发誓：众生无边誓愿度，依苦谛境；烦恼无数誓愿断，依集谛境；法门无尽誓愿知，依道谛境；佛道无上誓愿成，依灭谛境。《涅槃经》中四谛开为四重，所以弘誓也有四番。如今简偏从圆，以圆教的四愿融摄前三种愿，无非法界，所以依法界起于妙愿。初心便遍摄所观之惑与法界，遍习佛法，与三身平等而证。

已发圆心，却还未知圆心：是初心为是，还是后心为是？是初即是后，还是初异于后？若初心不是、后心才是，或初心异于后心，都不是圆融。所以辨六即，以判是非，就是理即、名字即、观行即、相似即、分真即、究竟即。

即故初后俱是，六故初后不滥。理同故即，事异故六。

（大意：因为是"即"，所以初心与后心都是；因为分"六"，所以初心与后心不相混滥。理上相同，所以说即；事上有别，所以分六。）

凡诸经中带有"即"字的说法，如"生死即涅槃"之类，都以六位来甄别，使始终理同，而初后不滥。

### 修圆行

修圆行等其余四项，都在第二卷。

修圆行，就是以四种三昧遍摄众行。若无殊胜之行，殊胜之果便难以阶及。

一、常坐三昧：出自《文殊问般若经》《文殊说般若经》两部般若经，也名一行三昧，因为唯专念法界。以九十日为一期。

二、常行三昧：出自《般舟三昧经》，也名佛立三昧，成就时见十方佛在室中站立。也以九十日为一期。

三、半行半坐三昧：出自《法华经》与《方等经》。法华三昧以三七二十一日为一期，方等三昧不限时节。

四、非行非坐三昧：也名随自意三昧，因为意起即观。方法出自《请观音经》等诸大乘经，通于行住坐卧四威仪及种种作务，即使在公私匆遽之间，也可以修。

这四种三昧，行仪不同，所依之理相同，所以同用十乘之法。

### 感圆果

由修诸行，得入圆教之位：近的在初住，名无生法忍；远的期于妙觉，名寂灭忍。初住的功能，具如《华严经》赞叹初住之文所说，那就是它的相状。岂可草率地自称已证真理？乃至妙觉，广如经中所说。

### 起八教

既已入位，便八相成道，现十法界身，能随顺众生根机，运用藏、通、别、圆四教，以及渐、顿、秘密、不定四教，以五时利益众生，贯穿一代始终。

### 归三德

众生的机缘息了，宜当归于三德。三德是什么？就是秘密藏。所以《涅槃经》说：安置诸子秘密藏中，我亦不久自住其中。

## 三、第三、四卷：止观体相与二十五方便

第三卷以下，广释行相，开演前面的五略，使人易于修行。先释止观之名，辨止观之体，明止观摄一切法，判法之偏圆，这四项都在第三卷。

其次为正修作前方便，都在第四卷，就是二十五法，总为五科。

第一，具五缘：一、衣食具足，以离开希望之缘；二、持戒清净，以离开恶道之因；三、闲居静处，以离开愦闹之事；四、息诸缘务，以舍弃猥杂之业；五、亲近善知识，以有咨问决疑之处。文中每一项都有事、理两种具足。

第二，诃五欲：色、声、香、味、触。正报与依报各具这五种，都能令行者生起欲心，所以须诃斥灭除。文中有事、理两种诃斥。

第三，弃五盖：缘已具足、欲已无有，才堪入观；观还未相应时，有五法覆蔽其心，就是贪欲、嗔恚、睡眠、掉悔、狐疑。由修观而引起的，比平常更加厉害，损害寂照，觉察到了就须弃除。文中各有事、理两种弃除。

第四，调五事：盖已除去仍不能入观，应当是身等五法未调。身、息、心三者，在定内合起来调，使身不宽不急，息不涩不滑，心不浮不沉；眠、食二法，在定外分别调，睡眠不节省也不放纵，饮食不饥也不饱。

第五，行五法：前四科虽已具足，还必须这五法，才能成为修行的先导。一、乐欲，须有希慕；二、专念，须能忆持；三、精进，须能相续；四、巧慧，须能善巧回转；五、一心，无有他求。

具足这些方便，正观才可获得。

## 四、第五至七卷：十乘观法

正观是什么？就是十法。若无这十法，名为坏驴车。这十法虽然都是圆常之法，修行人却有三根不等：上根只用一法，中根用二法乃至七法，下根才须具足十法。

### 第一，观不思议境

上根的一法，就是观不思议境。境是所观，观是能观。所观的是什么？就是阴、界、入，不出色与心。色由心造，全体是心。所以经中说：三界无别法，唯是一心作。这能造之心，具足诸法：有漏、无漏、非漏非无漏等，因、果、非因非果等。所以经中又说：心佛及众生，是三无差别。众生是理具，诸佛是已成，已成与理具，无不性等。

```
一一心中一切心，一一尘中一切尘。
一一心中一切尘，一一尘中一切心。
一一尘中一切刹，一切刹尘亦复然。
诸法诸尘诸刹身，其体宛然无自性。
无性本来随物变，所以相入事恒分。
故我身心刹尘遍，诸佛众生亦复然。
一一身土体恒同，何妨心佛众生异。
异故分于染净缘，缘体本空空不空。
三谛三观三非三，三一一三无所寄。
谛观名别体复同，是故能所二非二。
```

（大意：每一心中有一切心，每一尘中有一切尘；每一心中有一切尘，每一尘中有一切心；每一尘中有一切刹土，一切刹土与微尘也是如此。诸法、诸尘、诸刹与身，其体宛然而无自性；正因无自性，本来随物变现，所以虽互相涉入，事相却恒常分明。因此我的身心遍于刹土微尘，诸佛与众生也是如此；一一身土，体性恒同，又何妨心、佛、众生各有不同？有不同，所以分出染净之缘；缘的体性本空，空而又不空。三谛三观，三而非三，三即一、一即三，无所寄托；谛与观名称有别，体性相同，所以能观与所观，二而不二。）

三观的名义出自《璎珞经》等，三谛的名义出自《仁王经》等。

这样观时，名为观心性。

随缘不变故为性，不变随缘故为心。

（大意：随缘而不变，所以叫作性；不变而随缘，所以叫作心。）

所以《涅槃经》说：能观心性，名为上定。上定，名为第一义；第一义，名为佛性；佛性，名为毗卢遮那。这遮那之性，具足三佛性。遮那遍一切处，所以三佛也遍。由此可知，三佛唯在一刹那；三佛既遍，刹那也就遍了。

这样观，名为观烦恼，名为观法身。这观法身，就是观三身，就是观刹那，就是观海印藏，就是观真如，就是观实相，就是观众生，就是观己身，就是观虚空，就是观中道。

故此妙境为诸法本，故此妙观是诸行源。

（大意：所以这妙境是一切法的根本，这妙观是一切行的源头。）

这样才远离偏、小、邪、外，所以居于十法之首。上根人一观，横竖该摄，便识得无相之中众相宛然，即破无明，登于初住；或者至少进入内凡、外凡之位。所以《法华经》譬喻说：其车高广，乃至坐于道场。中根人还未领悟，须再修以下诸法。

### 第二，起慈悲心

观境不能领悟，须加以发心。这人无始以来已经起过弘誓，所以古人说：发僧那于始心，终大悲以赴难。僧那就是弘誓，赴难就是入恶道救度众生。如今由于观境不契于理，须重新发誓：于静心中思惟彼我，痛切自他，无量劫来沉沦生死，纵然发过小志，也迷失了菩提心；我如今虽然知道了，行持却还未完备。所以重发誓言：

众生无边誓愿度，因为生死即涅槃；
烦恼无数誓愿断，因为烦恼即菩提；
法门无尽誓愿知，因为即惑成智；
佛道无上誓愿成，因为即生成灭。

作这样的思惟，豁然大悟，冥契所照之境，进入凡圣之位。所以譬喻说：张设幰盖等。若仍不能入，是因为心不安。

### 第三，善巧安心

先总说，后别说。

总的来说：以法界为所安，以寂照为能安。若知道烦恼与生死本性清净，名之为寂；本性如空，名之为照。这烦恼生死，又名法界。即此法界，体用互显：体是所安的法界，用是能安的寂照。体名平等法身，也具足三德；用名般若、解脱，也具足三德。体用不二，三德之理平等，以冰水、藤蛇之喻，其意可知。

别的来说：虽然安了心，却越加昏暗散乱，这是因为无始以来的习性各不相同。所以如今顺其习性来安：或宜听，或宜思，或宜寂，或宜照；随其所乐，随其对治，随第一义。为什么？有人因寂照而善根增长，有人却不增长；有人因寂照而烦惑破坏，有人却不破；见理也是如此。有人闻思相互转换，有人闻思相互资助，不能一时具足，仔细寻求才能明白。所以譬喻说：安置丹枕，这是车内之枕。若仍不能入，是因为破法不遍。

### 第四，破法遍

众教诸门，大体各有四门，乃至八万四千种不同，无不以无生为首。如今且从初门入手：于无生门中遍破诸惑，再以无生度入其余诸门，纵横俱破，令人认识其体周遍。所以譬喻说：其疾如风。此门最广，这里不能具述。若仍不能入，应当寻察通塞。

### 第五，识通塞

虽然知道生死烦恼是塞，菩提涅槃是通，还须知道：于通处又起了塞，这塞须破；于塞处得到了通，这通须护。好比把将领当成了贼，这贼岂能留存？若把贼当成了将领，这将领岂能被破？节节检校，不令生著；一著就名为塞。破塞存通，不只一条路，凡是有心都是如此，念念常须检校通塞。所以譬喻说：安置丹枕，这是车外之枕。若仍不能入，是因为道品不均。

### 第六，道品调适

依门遍破，于理却仍暗昧，须以七科道品次第调试。若不这样，这些道品又是为谁施设的呢？以破法遍之门，虽然观阴境，阴上还没有分出念处之名，何况其余六科？展转调停，所以用此门来检校选择，就是念处、正勤、如意足、根、力、七觉支、八正道。

初念处，就是身、受、心、法四法，都在法性心中以三谛推检。先观身：身是色法，观法性之色，一色即一切色，一切色即一色；双照一与一切，双非一与一切；能所三一，具如前面妙境中所说。受等三法，可以类推。其余六科，不能一一细说。所以譬喻说：有大白牛等。以上六门，名为正行。若仍不能悟，是因为事恶帮助蔽覆了理善。

### 第七，助道对治

《涅槃经》说：众生烦恼非一种，佛说无量对治门。不相信有对治的人，当知此人还不懂正行。若认识到自己正行未能辨明，是因为事恶帮助理恶，共同蔽覆理善，令它不能现前。理善，是法界常住；事善，是布施等六度；理恶，是微细无明；事恶，是六种重蔽。由修止观，这六蔽会现起，就是悭贪、破戒、嗔恚、懈怠、乱想、愚痴。

具足这六恶，却说内有胜法，或说常自相应。若真的相应，就同于法身，应当无有方所，说法必定契机。若只是暂时相应，又重新起恶，就根本没有这个道理，那就与成佛之后还作众生一样，自相妨碍。若说曾经契合过，也同样妨碍。若说知道了理就不妨碍起恶，那也应当说知道了"富"就免了贫，知道了"药"就免了病。事恶若去，理善便容易明了，同时仍请圣者加被，助我显理。

若有人说：那么只要观恶即是道，哪有恶能蔽理？这个道理不对。

若恶已成道，道即法身；法身未契，由即观微故。

（大意：若恶已经成为道，道就是法身；法身之所以还未契合，是因为"即"的观照还微弱的缘故。）

所以先修事度，以治事恶；事恶倾去，理善才能生起。所以修观的人，须以事恶来检点自己，以六即来判定位次。理善明了，事恶必定消亡。须知理明的位次在哪里，于是以小助大，以偏助圆。何况还有转治、兼治、具治、第一义治等，不能一时说尽。所以譬喻说：又多仆从而侍卫之。若没有仆从，车子倾覆还有什么可疑？中根人用观，到此为极。

### 第八，知次位

下根人障重，不但正行助行不明，反而生起上慢，以为自己与佛平等，未得谓得，未证谓证。须知次位，使朱紫不乱。大小乘的真位与似位，不证不能明了，所以三世诸佛都阐明诸位。若未证得而说证得，不但失位，还会堕入地狱。所以小乘经中，有得四禅的比丘以为得了四果；大乘经中，有魔给菩萨授不退转记。若生取著，必同魔属，尚且不如人天，又何关至道？

所以大小乘经论都阐明次位，又宣说深位的胜妙功德，引接初学，令其欣慕；又有人喜闻长远之位，生起增上信心，立难行之行，破大烦恼，见第一义。所以譬喻说：游于四方，比喻住、行、向、地四位。虽知次位，若不能忍受违顺之境，就须明安忍。

### 第九，能安忍

圆顿行人初入外凡位时，外面招来名利，里面动起宿障。宿障纵然薄，名利却更加到来，被众人围绕，废损自己的修行，因此破败，岂能进道？外人看他，还以为是大圣，就像树里藏着蝎子，外表看似完好，内里已经空了。唯当自勉，不为所动，得入内凡，名为相似位。若一味停住在相似位，名为法爱。

### 第十，离法爱

已得相似位的六根互用，已破见思、尘沙两种惑，永不堕入苦道；却爱著这相似位，名为顶堕。这与小乘退堕后造五逆不同，因为内外凡位在诸教中各有区别。若修离爱，进入铜轮位，名为十住。分身于百界，一多相即；身土既然如此，自他也是如此。以十身利益众生，以四土摄受万物。初住的功德，具如《华严经·贤首品》所广说。

以上从第五卷初到第七卷末，阐明正修行，从初心直到初住。

## 五、第八至十卷：十境

第八卷以下，阐明观阴入界之后，又引发宿习，再用观来观这些宿习。若用上面十种观法，还未能入位，必定引发宿习，就是烦恼、病患、业相、魔事，都在第八卷；禅定境在第九卷；诸见境在第十卷。其余上慢境、藏通两教的二乘境、藏通别三教的菩萨境，因为时近夏末，所以略而不说，可以从前面诸文类推。

宿习若起，不可不识。若事先知道了，就任它变化作怪。这些境界的发起也没有一定，随过去世中近而熟的，今世先现前。文中暂且依次第而说。凡有所起，只以寂照来止观它，令它等同法界，一相无相，无不都用十乘观法。

烦恼境：无始以来积集的重惑，如今因为修观，这惑比平常更甚，不可控制。

病患境：由于观阴入之惑，激动了四大，要认识它的根由，看宜用何法医治，或用内观之力，或用方术，或用医药，然后再用观。

业相境：有漏之业，有的已经受报，不再引发；有的还未受报，在静心中忽然一齐引发。发起的相虽然很多，不出六蔽与六度，各有六相，有的因止而生，有的因观而生。

魔事境：由于观诸境，惑虽未破，天魔还是怕行者出离他的境界，空了他的宫殿，化了他的民属，于是来与行者作战争斗，所以魔民魔主都来了，这就是四魔中的天子魔。乃至人间的鬼魅（原文此处有缺字）、夜叉、时媚等，都受天魔管属，为它巡逻，防遏行者，不许出界。所以《大品般若经》说：菩萨不说魔事，名为菩萨旃陀罗。

禅定境：根本四禅、十六特胜、通明禅、九想、八背舍，乃至念佛、神通等，随近而熟者发起其相。这些相最难辨认。

诸见境：乃至一百四十种见。

上慢境：已经伏住诸见，便以为造诣已深，滥居上位，所以须要认识。

二乘境：昔日所发的小乘之志，由宿习而生。

菩萨境：藏、通、别三教菩萨之心，由宿习而现。

以上诸境，都须以观力来调伏，详见本文，不能一一抄录。

## 六、结语

所以本宗观法入道的次第，与诸家之说稍有不同，因为依附诸经而成就行相，内顺观道，外扶教门。

依而修行，必不空过；纵此生未获，为种亦强。

（大意：依此修行，必定不会白费；纵然此生未能证得，作为种子也非常坚强。）

意气博达，该括包笼，尽未来际，不再更改。若依之修行，都须口诀，才能成就本宗的行相。

湛然所见暗短，禀承无功。本文三百余纸，这里略述，多有不周。虽勉力应命，实在怕失了大师的深旨。凡有不到之处，敢望通融宽恕。

《止观大意》竟。
