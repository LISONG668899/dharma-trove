# 法藏大师华严论释精华（八）

## 十玄门下篇：托事显法、十世隔法、主伴圆明

原典：法藏大师《华严经探玄记》卷一，第九门“显义理分齐”，十玄门及“缘起相由”中的“同异圆备义”；《华严经旨归》“显经义第七”。

本期接续前两期的十玄门，依次说明第八、第九、第十门。主要依据《探玄记》的十玄名义和缘起理路，以《华严经旨归》莲华叶的例子互相阐明。下文均以白话销文为主；所列小标题及按语仅为阅读辅助，不属于原论原有分段。引自两书的论证分别注明来源。

## 一、托事显法生解门

前面已经说明，诸法并不是各自孤立而成立。每一法都与一切相关诸法处在同一广大缘起中；从一多相容、诸法相即，到微细相容与因陀罗网的重重无尽，都已经显示这一点。既然如此，随举任何一件具体事物，都可以由此显示圆融无碍的法界。所谓托事显法生解，就是依托一事，令人生起对这一法界法门的理解。

《探玄记》在解释“缘起相由”最后一义时说：由于这整个广大缘起法，当体就是无碍法界的法门，所以有托事显法门。这里所举的“事”，并不是离开法界之外、另外借来做比喻的物件；所显的“法”，也不是与这件事分离、藏在别处的道理。正由于此事本身处于无碍缘起之中，依此便能显示法界。

《华严经旨归》进一步以一片莲华叶说明：这一片莲华叶既然具足十种无碍，其余一切具体事物，也应当如此理解。由此，见这一片莲华叶，就是见无尽法界；并不是借它作为一个符号，另外表示某个与它分开的法界。

原论说：“是故见此华叶，即是见于无尽法界，非是托此别有所表。”

白话说，见到这一片莲华叶，在圆教所说的无碍义理中，就是见到它所具足的无尽法界；不是先见到一片叶子，然后再把叶子当作象征，去猜想一个离开叶子而存在的法界。因为这一法从来不离其他诸法而成立，而且诸法的相即相入、重重无尽，原本就在这一缘起法中显示。

这一门强调依一事便能显法。然而，不能因为随举一事都能显法，就认为各种事物的差别、作用和安立都被取消。正是诸法各自具有差别，而又都不脱离广大缘起，才能随一事显示无碍之义。

## 二、十世隔法异成门

前面各门既已显示法法相摄、无碍自在，那么依诸法而安立的时间，也不能离开诸法另外成为一个固定不变、独立存在的实体。《华严经旨归》说，时间并没有离开诸法而独立成立的自体，时间是依莲华叶等法而安立的。莲华叶所表示的法既然无碍，依它而立的时间，也随之显示无碍。

大师以一片莲华叶为例：就空间说，这片叶子横遍十方；就时间说，又贯通九世。九世是怎样安立的呢？过去一世中，又有过去、现在、未来三世；现在一世中，也有过去、现在、未来三世；未来一世中，同样具有过去、现在、未来三世。三个三世，共为九世。

这九世又总摄于一念中。把九世的差别与总摄九世的一念合起来，就称为十世。九世是从种种时间差别而言，一念是从总摄而言；所谓十世，既保留前后差别，也不妨碍一念总摄九世。

大师说，这一道理在《离世间品》中有详细说明。他又引经意说，可以把过去的一切劫安置在未来与现在，也可以把未来的一切劫回置过去；又说无量无数劫能够成为一念顷。这里是从圆教无碍的义理说明劫与念，并非单纯改变日常时间单位的长短。

原论说：“又以时无别体，依华以立，华既无碍，时亦如之。”

白话说，时间本身并没有一个可以离开具体诸法、单独找到的实体。它是依诸法而建立的。所依的莲华叶既显示无碍，那么依莲华叶建立的时间，也应当从无碍的角度理解。

《探玄记》在“缘起相由”的最后一义中同样解释：由于这一大缘起融通自在，依这些诸法所辨别的时间，也随诸法而融通无碍，所以建立十世门。

因此，十世并不是把过去、现在、未来混成一个毫无区别的时间；如果没有九世的差别，就没有所谓总别相摄。也不是先把时间假定成一个独立的实体，再使这个实体穿越、容纳其他时间。大师所说明的次第，是由法的无碍，进而说明依法安立之时的无碍；既不破坏时间的差别，也不把差别执为绝对隔绝。

## 三、主伴圆明具德门

《华严经旨归》仍然以一片莲华叶为例。这片叶子不可能孤立而生起，必然与无量眷属相互关联。经中说，这朵莲华有如世界海微尘数的莲华作为眷属。华严圆教中所说的一切法，也都是互为主伴，具足圆满功德。

这里的主与伴，不是说某一法永远占据中心，其他法永远处在从属地位。而是随举一法作为所说、所观、所显的中心，其余相应诸法便从与此法的关系上成为眷属。再从另一法立为中心，也可以依这一法重新显示相应的主伴关系。

《探玄记》对此指出：整个法门同处一个缘起之中，彼此相带而起，所以随有一门，必具一切，由此建立主伴门。

原论说：“由此法门同一缘起相带起故，随有一门，必具一切，故有主伴门也。”

白话说，因为这些法门同属一个广大缘起，彼此相互联系、相互带起，所以只要举出其中一门，便不能离开其他一切相关法门。随以哪一门为主，其余法门都与它相应，这就叫主伴圆明具德。

《华严经旨归》以莲华叶说明这一门，并没有停在莲华叶本身。它进而指出，华严圆教所有诸法，皆互为主伴，功德具足。这就是为什么见此一华叶，可以说是见无尽法界，而不是从叶子另外寻找所表之法。

主伴门因此与前面同时具足相应门相互贯通，但侧重点不同。同时具足重在说明诸门同一缘起、同时相应；主伴圆明则是随举一门，显出这一门与其余一切门相应、共同成就的关系。主伴虽有不同安立，不妨碍整个法界的无碍圆融。

## 四、三门与前七门怎样相连

《探玄记》在“缘起相由”的第十义“同异圆备”中，对十玄门的关系作了简要而连续的说明。这里应当依大师自己的推导重读一遍。

前九种缘起义合为一个大缘起，于是种种义门能够同时具足。由于一缘既住自身分位又普遍相应，所以有广狭自在；由于分别就体、就用观察，所以有相即与相入；由于一法摄多时有显与隐，多法摄一也有显与隐，所以有隐显门。又由于异体相入与同体相入相互摄持，便显示微细相容；异体相入又带着同体相入，便有重重无尽的因陀罗网门。

从这里再向下观察：这一广大缘起既然就是无碍法界，便有托事显法门；既然诸法融通自在，依诸法安立的时间，也随之融通，便有十世门；既然所有法门同在一大缘起之中，彼此相带而起，随举一门便具其余诸门，便有主伴门。

大师最后把这些义理归结为同一广大缘起，并不是要另外建立一个总的实体，将诸法从外面统合起来，而是说明十种无碍法门并不彼此分离。各门虽然分别从空间、时间、一多、体用、隐显、相容、相即、重重相摄等不同角度开示，但所显示的都是同一无碍缘起。

## 五、《华严经旨归》对十玄门的总收

法藏大师在《华严经旨归》结束莲华叶十无碍的说明时指出：一片莲华叶既然具足这十种无碍，其余一切事法也都是如此。并且，不仅具体事相如此，前面所说的教义、理事、境智、行位、因果、依正、体用、人法、逆顺、应感十对法中，每一法也同样具有十种无碍，应当依此理解。

这就是说，十玄门并不限于一片莲华叶，也不限于佛土、世界、微尘等外在境相。凡经中所说的教理、智慧、行位、因果、佛身、众生根机及圣者应现，都可以依十玄无碍观察。

至此，从同时具足相应门，到主伴圆明具德门，十玄门在名义和主要譬喻上已经依次讲完。以下有关佛身、说经时处、说经仪式及圆融修证的论述，仍应继续依两部原论翻译，因为这些内容正是法藏大师把十玄无碍显示于佛果起用和普贤行的具体所在。
