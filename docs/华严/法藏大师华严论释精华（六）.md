# 法藏大师华严论释精华（六）

十玄门上篇：同时具足、广狭自在、一多相容、诸法相即

原典范围：法藏大师《华严经探玄记》卷一，第九门“显义理分齐”中十玄总标及前四门；《华严经旨归》“显经义第七”中“所显理趣”的相关四义，并参照该门“所标之法”十对法。以下以白话译文为正文，按大师原文推进。两书重复的内容分别标出，以便读者看到它们怎样彼此发明。原文关键术语保留，不把两书拼成同一段原文。本文属于所选原典段落的白话翻译，并非十玄论证的全部；大师关于缘起相由十义的论证，已在第四期另译。

## 一、十玄门总说：每一门都具足其他诸门

〔《探玄记》卷一，第九门〕

华严经所说明的义理，广大深远，如大海一般，佛陀教法的言语文字也浩瀚无量。现在略举十门，总摄其中的纲要。

第一，同时具足相应门；第二，广狭自在无碍门；第三，一多相容不同门；第四，诸法相即自在门；第五，隐密显了俱成门；第六，微细相容安立门；第七，因陀罗网法界门；第八，托事显法生解门；第九，十世隔法异成门；第十，主伴圆明具德门。

这十门共同属于同一个缘起，彼此没有障碍，圆融相摄。随便举出其中任何一门，其余诸门都在其中具足。应当依此思维。

先说第一门的十种具足。它包括教与义、理与事、境与智、行与位、因与果、依报与正报、体与用、人和法、逆与顺、应与感。最后这一对应感，是说众生有不同的根机和感召，如来便随之回应，所以经中说，如来示现种种为一切众生所喜乐的境界。

这十对法同时相应，构成一个缘起。随便举出其中任何一法，其他一切义都在其中具足。第一门如此，其余广狭等九门也都各自具足这十对法，不过随所讨论的玄门不同，显现的义理侧重点有所不同。因此，每一门都可以展开十门、百门、千门等层层义理。

现在暂且就一个具体事物，来显示这些十对法。其他一切事物，也都可以照此理解。

譬如经中一片莲华叶：这片莲华叶能够表示法义，使人由此生起理解，这是“教”；莲华叶所显示的真实意义，就是“义”。莲华的形相，是“事”；莲华的体性，就是“理”。莲华是智慧所观察的境，同时又可以说是能观的智慧，因为在这部经中，可以把内在的修行显示为外在的事相。莲华所表示的行门积聚而成就修道位次，所以行与位都在其中。作为因行的莲华，汇集而成佛果，所以因果也在其中。莲华台是所依之处，也可摄入正报，因为经中有所说国土身等义。莲华之体同于真实法性，它的作用则随众生根机而显现，所以体用都具足。若总摄这些义理而就能修能证者来说，便是“人”；就所显法门来说，仍是“法”。顺逆也都可以就莲华说明：有逆行示现的五热，也有顺理修习的十度。它既随众生根机而应现，也有感召诸佛菩萨的意义。

一片莲华既可以具足这十对法，其余一切事法也应如此理解。不仅具体事物如此，教、义等一切法，也都应以同样道理观察。既然一片莲华叶具足自身的十对法，它也具足前面所列十玄门。

## 二、第一门：同时具足相应

〔《探玄记》卷一〕

为什么说这片莲华叶具足第一门？因为前面所说十种法义，都在这一片莲华叶中同时相应、具足圆满，没有先后缺少，所以叫作“同时具足相应门”。

〔《华严经旨归》“显经义第七”：对十对法的总说明〕

华严经所显示的法义，广大得难以穷尽。为便于说明，可以先分成两类，各举十门。第一类是经中所标示的诸法。它们广博无涯，现在归纳为十对：无尽言教及其所诠的义理，是教义一对；缘起的种种事相和它所依的真实理性，是理事一对；所观的真俗妙境与能观的普贤大智，是境智一对；普贤的广大行海及菩萨五位相互含摄，是行位一对；菩萨能生与能了的种种因、如来智慧与断障的果，也就是普贤圆满因行和卢舍那圆满佛果，是因果一对。

莲华藏世界以及树形等种种无边世界海，与诸佛菩萨周遍法界、无碍住持的身云，是依正一对。这部经里随举一法，内在都同于真实本性，外在又能适应众生根机，没有一法不具足体与用，这是体用一对。佛、菩萨、师长、弟子等人，能显示宣说法界的无量法门，是人法一对。经中既有五热等逆行的示现，也有布施、持戒等随顺正理的修习，是逆顺一对。众生根性欲乐、感应情况千差万别，圣者随感而起的示现也无边无量，是应感一对。

这十对法同时相应，成为一个缘起，彼此圆融而无障碍。在其中任何一处，都具足其他一切。这就是本经所包含的法义。

## 三、第二门：广狭自在无碍

〔《探玄记》卷一〕

还是就前面那片莲华叶来说。它普遍周遍整个法界，却不破坏自己作为一片莲华叶的本来分位和界限。因为它虽有自身的分限，而这分限又并不成为阻碍周遍法界的固定界限；虽然无有障碍的分限，也并不妨碍它保持自身的分位。所以广与狭自在圆融，彼此无碍。

经中说，这朵大莲华的叶片，普遍覆蔽一切法界。

由此观察，可以有六种说法：或者只从广大方面说，它广大无边；或者只从它自身的分位说，界限历然分明；或者广大与狭小同时成立；或者广狭二相都不可执取；或者前面四种义理总合具足。这五种属于可以理解、分别阐明的境界。再进一步，或者连前五种说法也都超越，不以分别概念固定它，这属于实际修行所证的境界。后面诸门也都可以照此理解。

〔《华严经旨归》“显经义第七”〕

这一片莲华叶，必定遍满一切处，没有边际，却仍然不坏它原有的分位和界限。因此，有分限即不为分限所限，广大与狭小彼此无碍。经中说，这些莲华叶普遍覆蔽法界。这里所说明的，就是广狭无碍。

## 四、第三门：一多相容不同

〔《探玄记》卷一〕

还是这一片莲华叶。它舒展开自己的作用，遍入整个法界的一切差别诸法中；与此同时，又能摄取这一切诸法，使它们进入自己之内。向外舒展而遍入一切，与向内摄取一切，二者同时成立，没有障碍，所以称为圆融。若进一步分别，也可以说成四句、六句等，按照前面广狭无碍的方式思维即可。

经中说，以一个佛国土充满十方世界，又使十方世界进入一个佛国土，双方都没有遗漏。

〔《华严经旨归》“显经义第七”：一多及相入两义〕

这一片莲华叶，具有无边功德，因此不能把它限定成一个孤立的“一”；它的诸多义相又圆融无二，因此也不能把它判定为彼此隔绝的“多”。一就是多，多也就是一；一与多并不是两个相互隔绝的实体，共同显现在这一片莲华叶上。经中说，知道一就是多，多就是一。这是“一多无碍”的道理。

进一步说，这片莲华叶能够舒展自身，遍入一切差别诸法；又能够摄取一切差别诸法，让它们进入自己之内。因此，舒展与摄取恒常同时，没有障碍。经中说，以一佛国土充满十方，又使十方世界入于一佛国土，没有遗漏。这就是“相入无碍”的道理。

按语：《探玄记》以“一多相容不同门”为标题，着重以舒展与摄取说明相入；《旨归》则把“一多无碍”与“相入无碍”分别列为两义。这里依两书各自的分科译出，不把两种分法强行合并。“不同”意味着一与多的差别相并未被混同或抹去。

## 五、第四门：诸法相即自在

〔《探玄记》卷一〕

这一片莲华叶，可以舍去单独执取自身的立场，与其他一切法相同；于是整个莲华叶全体就是其他一切法。同时，它又能把其他诸法统摄过来，使其他一切法与自身相同；于是其他一切法全体就是这一片莲华叶。因此，一与多相即，没有障碍。至于就理解与修行的境界而分别出的六句，也与前面相同。

经中说，知道一就是多，多就是一。

〔《华严经旨归》“显经义第七”：相是无碍〕

这一片莲华叶，必定能够舍去对自己独立成立的执取，完全与其他诸法相同；如此一来，它的全体就是那一切诸法。与此同时，它又能摄取其他诸法，使那些法与自己相同，所以其他一切法的全体，也就是这一片莲华叶自身。

这样，自己就是他者，他者就是自己。当从自己即是他者这一面来说，自己作为一个独立于他者的实体便不可成立；当从他者即是自己这一面来说，他者作为一个独立于自己的实体便不可成立。自己与他者的成立和不成立，都在这种相即关系中同时显示。经中说，长劫就是短劫，短劫就是长劫。这就是“相是无碍”的道理。

按语：“相入”侧重诸法彼此遍入、容纳的作用关系；“相即”侧重一法全体即另一法的体性关系。法藏大师在《探玄记》卷一后文“缘起相由十义”中，分别通过“有力、无力”与“有体、无体”建立两者，此处不以现代的物理空间含摄替代大师原义。
