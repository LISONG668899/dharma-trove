# 憨山《观楞伽经记》（四）百八句皆非与诸识生灭

## 依心真如门总答百八句

【经文】不生句。生句（唐译云生句非生句）。常句。无常句。相句。无相句（魏译云生见不生见，常见无常见，相见无相见）。

【憨山记】这是总依心真如门来回答。大慧所问的义理虽多，总不出生与无生、常与无常、相与无相之法。所以世尊牒述所问之后，又综合其大义加以破斥：上面这百八句，若依诸佛所说的"不生"之义，那么这生法当下就是不生，因为生本来不生；所说的"真常"之义，这无常当下就是真常，因为诸法当体真常；所说的"相"，诸法本来无相。这是顺着魏、唐二译以"生句"为首来解释。

若依此译以"不生句"为首来解释，意思是：诸佛所说的真实无生，不容起任何见解。所以下文说"一切法不生，不应立宗"。意思是你才作"不生"之见，早已堕入生法；才作"常"见，早已堕入无常。为什么？因为在真如界中不容拟议，举心即错，动念即乖；相本无相，所以说"不生句、生句"等。从这里往后，凡有所分别，都与真如实相之理不相应，所以一一斥之为"非"。

永嘉大师说：「一切数句非数句，与吾灵觉何交涉」（大意：一切句数都不是句数，与我的灵觉有什么交涉）？又如《法华经》所说"不如三界见于三界，非实非虚，非如非异"。这正是诸佛所证的自觉圣智境界，所以不是妄想分别所能到达的。所以宗门说：「三句明一句，一句明三句，三一不相关，分明向上路」（大意：三句说明一句，一句说明三句，三与一互不相干，分明就是向上之路）。了达这一点，才可以观《楞伽》。

【经文】住异句非住异句，刹那句非刹那句，自性句离自性句，空句不空句（魏译云离自性见非离自性见空见不空见，唐译云自性句非自性句）。

【憨山记】这几句连同上面三句，是佛自己遣除自己的话。前面牒文开头说"生及与不生，涅槃空刹那，趣至无自性"。世尊的意思是：之前因为大慧执著有世间、出世间的生住异灭来发问，所以我姑且用这些句义来破他的执情，并不是实法。因为真如理中本无言说，所以这里回答说这些也都"非"，意思是不但无生，连住、异、灭也都不可得，刹那生灭也不可得。

上面的"常句"就是指涅槃。"自性句离自性句"，魏译作"离自性见、非离自性见"。前面说"趣至无自性"，"趣至"犹如说究竟，是说世间出世间法究竟都无自性；这里说连"离自性"这句也了不可得，所以都说"非"。这些是佛自遣之辞，以下都是遣除大慧所执之辞。

【经文】断句不断句，边句非边句，中句非中句，常句非常句。

【憨山记】这是通斥世间、出世间的邪正之法。前面的常、无常句，是涅槃的真常与生死的无常；这里的"常句"，是外道的断常二见，即执定死后常存或不常存，所以斥之。"中"是出世间的一乘中道法；"边"是空有二边，是出世间的三乘法；"断常"是世间外道的邪见法。在真如理中，圣凡不立，迷悟皆空，所以都说"非"。

【经文】缘句非缘句。因句非因句。烦恼句非烦恼句。爱句非爱句。方便句非方便句。巧句非巧句（唐译云善巧句非善巧句）。净句非净句。成句非成句。譬句非譬句。弟子句非弟子句。师句非师句。种性句非种性句。三乘句非三乘句。所有句非所有句（魏译云寂静见非寂静见唐译云无影像句非无影像句）。愿句非愿句。三轮句非三轮句。相句非相句（唐译云标相句非标相句）。有品句非有品句（唐译云有句非有句无句非无句）。俱句非俱句。缘自圣智现法乐句非现法乐句（唐译云自证圣智句非自证圣智句现法乐句非现法乐句）。刹土句非刹土句。阿㝹句非阿㝹句（唐释云尘句非尘句）。水句非水句。弓句非弓句。实句非实句（唐译云大种句非大种句）。数句非数句（唐译云算数句非算数句）。数句非数句。

【憨山记】最后这一句"数句非数句"，魏、唐二译都没有。旧注把这里的"数"字读作上声（动词，计数），这不对。前一个"数句"，是牒"阿㝹"以下世尊所补的三十二句，都是算数；后一个"数句"，是说真如理中本无这些数量，正所谓"一切数句非数句"。

【经文】明句非明句（唐译云神通句非神通句）。虚空句非虚空句。云句非云句。工巧伎术明处句非工巧伎术明处句。风句非风句。地句非地句。心句非心句。施设句非施设句。自性句非自性句（唐译云体性句非体性句）。阴句非阴句。众生句非众生句。慧句非慧句。涅槃句非涅槃句。尔焰句非尔焰句（唐译云所知句非所知句）。外道句非外道句。荒乱句非荒乱句。幻句非幻句。梦句非梦句。焰句非焰句（二译皆云阳焰）。像句非像句。轮句非轮句（唐译云火轮句）。犍闼婆句非犍闼婆句。天句非天句。饮食句非饮食句。婬欲句非婬欲句。见句非见句。波罗蜜句非波罗蜜句。戒句非戒句。日月星宿句非日月星宿句。谛句非谛句。果句非果句。灭起句非灭起句（唐译云灭句非灭句。起句非起句）。治句非治句（唐译云医方句）。相句非相句。

【憨山记】所答中共有三个"相句"。旧注说：第一个是名相的相，第二个是标相的相，这里是占相的相，因为前面有"医方"一句冠在上头。这不对。占相总归在五明之中，而这里的医方句，是回答前面另有的医方之问，比喻佛应机说法，不是世俗的医方，前面已经详细说明，所以这里不是占相之相。

前面大慧的问义中有三种"相"句，所以这里依次回答。第一，问"何故刹土化相及诸外道"，这是通问十法界依正、圣凡的名相因何而有，所以第一次答"相句无相句"，意思是那些凡圣依正之相本来无相。第二，问"云何建立相"，意思是心既无相，为何建立我、人、众生、寿者之相，所以这里答"标相句非标相句"，"标"就是建立的意思，是说那建立也本无建立之相。第三，问"众生生诸趣，何相何像类"，"相"是众生的形状，"像"是肢体的样貌，所以这里回答的意思是：众生本无众生之相，又哪里有肢分？所以说"相句非相句"，下面紧接着说"支分"。

【经文】支句非支句（唐译云支分句）。巧明处句非巧明处句（唐译无此句）。禅句非禅句。迷句非迷句。现句非现句。护句非护句。族句非族句（唐译云种族句）。仙句非仙句。王句非王句。摄受句非摄受句。宝句非宝句。记句非记句。一阐提句非一阐提句。女男不男句非女男不男句。味句非味句。事句非事句。身句非身句。觉句非觉句。动句非动句。根句非根句。有为句非有为句。无为句非无为句。因果句非因果句。色究竟句非色究竟句。节句非节句（唐译云时节句）。丛树葛藤句非丛树葛藤句。杂句非杂句（唐译云种种句）。说句非说句（唐译此下有决定句非决定句）。毗尼句非毗尼句。比丘句非比丘句。处句非处句（二译皆云住持句非住持句）。字句非字句（唐译云文字句）。

【憨山记】以上依一心真如门回答百八句已经完毕。之所以都说"非"，是因为真如性中本来没有这些句数。所以《起信论》说：「当知真如自性，非有相，非无相，非非有相，非非无相，非有无俱相；非一相，非异相，非非一相，非非异相，非一异俱相。从本以来，一切染法，及一切众生妄心分别，皆不相应故」（大意：应当知道，真如自性不是有相，不是无相，不是非有相，不是非无相，也不是有无俱相；不是一相，不是异相，不是非一相，不是非异相，也不是一异俱相；从本以来，一切染法和众生妄心的分别都与它不相应）。真如即是真心，常恒不变，净法满足，也没有相可取，因为它是离念的境界，唯有证悟才能相应。所以这里回答说一切皆非。

前文已经一一详细牒述大慧的问辞，这里又一一重叠其句而斥之为非，这是西域的文势如此：凡有所问，必定完整牒述其辞再作回答。话虽似重复，义实直截，都是指归第一义谛的离言说处。每一组中，上一句是重叠所问，下一个"非"字句就是破斥。马鸣菩萨依这部《楞伽》等百部大乘经造《起信论》，论中立义分为一心二门，所以我现在也依此论为宗，后面多加引用。

【经文】大慧，是百八句先佛所说，汝及诸菩萨摩诃萨应当修学。

【憨山记】这是总结劝修。前面说"此上百八句，如诸佛所说"，一切皆非，所以这里总结说：这百八句是过去先佛所说，你和诸菩萨都应当这样修学。

## 转入心生灭门

憨山科判说：以上第一部分"直指一心真如，以显三界唯心"已经讲完。以下是第二部分"曲示一心生灭，以显万法唯识"，共分八科。第一科是"明真妄因依，广示八识，以显生灭因缘相"，其中又分两段：先略明唯识，以分别邪正之因；再广明八识，以显示识与智之相。前一段又分三层：一是以法显示真唯识量，以辨邪宗；二是以喻成立，预先破除二见；三是正式拣辨邪宗。

## 诸识有二种生住灭

【经文】尔时，大慧菩萨摩诃萨，复白佛言：世尊，诸识有几种生、住、灭？佛告大慧：诸识有二种生、住、灭，非思量所知。

【憨山记】从这里直到经终，都是依心生灭门来显示万法唯识，最初是以法显示真唯识量。

有人问：大慧承蒙佛回答百八句一切皆非之后，忽然又问"诸识有几种生住灭"，是为什么？

答：马鸣菩萨依此经造《起信论》，依一心法立二种门：一是心真如门，二是心生灭门。依心生灭门有觉与不觉二义；依不觉义，生起三细、六粗等相，总摄世间与出世间法，直指一心是迷与悟的根源。所以此经说"五法、三自性皆空，八识、二无我俱遣"。五法，是名、相、妄想、正智、如如；三自性，是妄想自性、缘起自性、成自性。因为依一心而有迷悟之别，所以有这八种名目。迷了一心，就把正智、如如转成名、相、妄想，这样诸法就是妄想缘起；悟了一心，就把名、相、妄想转为正智、如如，这就是所谓"成"。

此品名为"佛语心"，就是所谓寂灭一心，名为真如。《起信论》说：「心真如者，即是一法界大总相法门体，所谓心性不生不灭。一切诸法唯依妄念而有差别，若离心念，则无一切境界之相」（大意：心真如，就是一法界大总相法门的本体，即心性不生不灭；一切诸法只是依妄念才有差别，若离开心念，就没有一切境界之相）。由此可知，前面大慧所问的，是依名相妄想境界边的事，所以才有世间出世间种种诸法，成为百八见；而世尊直指一心真源，离言说相、离名字相、离心缘相，所以牒述之后斥之为"一切皆非"。这就是说，前面的经文正是依一心真如门而说的。

若依真如门，就离开言说相，因为三界唯心，只有智证现量，不容有说。所能说的，都是生灭门中依妄想缘起边的事，因为凡落言诠，就属于比量。从这里以下，都依生灭门来显示缘起的差别。诸法都是唯识所现，所以说"万法唯识"。然而识如幻如梦，只是一心；心寂而知，真妄都离，就名为自觉圣智，以此成立真唯识量。所以大慧领会了一心离言的宗旨之后，紧接着就问诸识有几种生住灭。

正因为不生不灭与生灭和合，成为第八阿赖耶识，所以在生灭门中，首先问诸识有几种生住灭，而回答说有两种生住灭。因为生即无生，住本无住，灭而不灭，所以说"非思量所知"。

【经文】诸识有二种生，谓流注生及相生。有二种住，谓流注住及相住。有二种灭，谓流注灭及相灭。

【憨山记】这是通指八识都有粗、细两种四相。有的解经者说，流注生住灭单属第八识，相生住灭则属前七识。现在谛观经意，"诸识"这句话，是说八个识中都有粗细四相。因为八识都有思量了别的作用，随见随即分别，这种行相粗显，所以说"相生、住、灭"；究其根底，都是第八识的精明应缘的业用，三相隐微，同一类相续，所以说"流注"。

虽然有八识的分位，其实总都是一类微细的流注，种子与现行交相熏发，甚深微细，不可思议。所以《解深密经》说：「陀那微细识，习气成瀑流」（大意：阿陀那识极其微细，一切习气种子如瀑流般奔流不息）。所以说诸识有两种生住灭。《密严经》说：「八种流注心，虽无若干体，或随缘顿起，或时而渐生，如波涛依水」（大意：八种流注之心，虽然没有多个本体，有时随缘一齐生起，有时渐次而生，就像波涛依水而起）。波涛比喻相，水比喻流注，二者不相离，所以下文说"非一非异"。

## 诸识有三种相

【经文】大慧！诸识有三种相，谓：转相、业相、真相。

【憨山记】这是解释八识的体相，以说明依生灭门有觉与不觉之义。"真相"是本觉真心，"转相""业相"是无明不觉。

有人问：《起信论》所列的三细是业相、转相、现相，此经的三相却以转相为首，业相次之，再接以真相，而且说"诸识"都有三种相，为什么？

答：此经是说八个识中都具有三相，不同于《起信论》中三细单属第八识。《起信论》说：一是无明业相，因为依不觉而心动，名为业，这单指无明；二是能见相，因为依动而能见，名为转相；三是境界相，因为依能见而境界妄现，能现一切境界，如镜现像，名为现相。这是论的意思。此经与论意不同，它以"转"为首，这个"转"不是三细中的转相，而是解释前面诸识各有两种生住灭之义：依此生灭，刹那刹那念念流转，这个转相就是前面的流注生灭，已经具备论中的三细。而这里的"业"字，是业力造业的业，就是前面的相生住灭，六粗相都包含其中。

人们不知道，念念生灭、起惑造业的，都是真心。所以先举转相、业相，再接以真相，要在即妄明真。这正是论中所说依生灭门有觉与不觉之义。下文说："种种诸识浪，腾跃而转生，譬如海波浪，是则无差别。诸识心如是，异亦不可得。"又说："藏识如巨海，业相犹波浪。"唐译作"转识同波浪"。由此可知，转相、业相是解释两种生灭之义。

若依三性来解释：转相是依他起性，如波浪依海水而起；业相是遍计执性，如只见波浪汹涌，不知是水；真相就是圆成实性，实在只是一海之水。这个真相就是本觉真如，正是随缘而不变的。

又问：马鸣依《楞伽》等经造《起信论》，三细尤其是论中说明生起的纲要，为何突然说不同？

答：这里是通说八识之相，因为经中说"诸识有三种相"。至于三细、六粗以及下文的不思议熏变等，自有明文。

## 略说三种识

【经文】大慧！略说有三种识，广说有八相。何等为三？谓真识、现识及分别事识。大慧！譬如明镜持诸色像，现识处现亦复如是。

【憨山记】这是解释前面"诸识"的名目。前面说"诸识"，不知识有几种，所以这里解释说：略说有三种，广说有八种。魏译作"略说有二：一了别识，二分别事识"；唐译作"略则惟二，谓现识及分别事识"，都缺了"真识"二字。

这里的"真识"，就是不生不灭的如来藏清净真心，也就是真如。真如也称为识，是因为它有照境的作用。这里的"现识"就是第八识，所以《起信论》说："以依阿赖耶识，说有无明不觉而起，能见、能现、能取境界"，也名为智识。这里的"分别事识"，就是前七识。若以镜像为喻，八识一体，无二无别。所以《起信论》说：「现识者，所谓能现一切境界，犹如明镜现于色像，现识亦尔，随其五尘对至即现，无有前后，以一切时任运而起，常在前故」（大意：现识能现出一切境界，就像明镜现出各种色像；现识也是如此，五尘一到面前就当即现出，没有先后，因为它在一切时中任运生起，常在现前）。

由此看来，此经的三种识是真妄对立而说，要显示识就是真如，所以下文说"如来藏名识藏"。魏、唐二译只说两种，是因为了别识与现识是真妄合说。之所以合说，是因为不生不灭与生灭和合，成为阿梨耶识。所以经中说：「佛说如来藏，即是阿赖耶」（大意：佛所说的如来藏，就是阿赖耶识）。《宗镜录》说：「此经直指八识即真，不比他经别立九识」（大意：这部经直接指出八识就是真心，不像其他经那样另立第九识），所以说是真妄合说。
