# 憨山德清《初心修悟法要》

出自《憨山老人梦游集》卷二〈答郑昆岩中丞〉，圣严法师选辑时题为《初心修悟法要》。

## 一、如何修悟

说到这一段大事因缘（明心见性、了脱生死的根本大事），虽然人人本来具足，个个现成，不欠丝毫，无奈无始劫以来，爱根种子、妄想情虑熏染得太深太厚，障蔽了本来的妙明真心，不能得到真实受用。一向只在身心世界的妄想影子里讨生活，所以流浪生死，轮回不息。

佛祖出世，千言万语，种种方便，说禅说教，无非是随顺众生的根机，作为破除执著的工具，本来没有实法给人。

所谓"修"，只是随顺自心，净除妄想习气的影子，在这上面用力，所以叫做修。如果一念妄想顿歇，彻见自心本来圆满、光明广大、清净本然，了无一物，这就名为"悟"。并不是在这心之外，另有可修可悟的东西。

因为心体如同明镜，妄想攀缘的影子，正是真心上的尘垢。所以说"想相为尘，识情为垢"。如果妄念消融，本体自然显现。譬如磨镜，垢去明现，法尔如此（法性本来就是这样）。

然而我们积劫以来习染坚固，我爱根深，难以拔除。今生有幸，以本具的般若智慧作为内熏之因，又借善知识的开示引发作为外缘，自知本有，发心趣向，立志要把无量劫来的生死根株一时顿拔，这哪里是小事？如果不是大力量的人，赤身担荷，单刀直入面对千军万马，实在是难之又难。古人说"如一人与万人敌"，并非虚语。

## 二、修悟下手处

末法时代修行的人多，得真实受用的少；费力的多，得力的少。这是为什么？都是因为没有找到直截了当的下手处，只在从前的闻见知解、言语文字上，用识情（分别意识）去揣摩卜度，强行压捺妄想，在光影门头（虚浮的表面境界）上做功夫。

先把古人的玄言妙语蕴在胸中，当作实法，拿来作为自己的知见，殊不知这其中一点也用不上。这正是所谓"依他作解，塞自悟门"（依靠别人的言教作解会，反而堵塞了自己的悟门）。

如今做功夫，先要铲除知解，的的确确只在一念上做。要谛信自心本来干干净净，寸丝不挂，圆圆明明，充满法界。本来没有身心世界，也没有妄想情虑。就是这一念，本自无生。眼前种种境界，都是虚幻不实的，只是真心中所现的影子。

如此勘破之后，就在妄念起灭之处一觑觑定，看它从何处起、向何处灭。这样着力一拶（逼拶推究），任凭是何等妄念，一拶便粉碎，当下冰消瓦解。

切不可随它流转，也不可让它相续。永嘉大师所说的"要断相续心"，就是指这个。因为虚妄浮心本无根绪，切不可当作实事横在胸中。它一起来，便喝一声"咄"，一咄就消。切不可强行压捺，否则反被它驱使，如同按水上的葫芦，按下去又浮起来。

只要把身心世界撇向一边，单单的的提起这一念，如同横空宝剑，任凭是佛是魔，一齐斩绝，如斩乱丝。赤体着力推究下去，这就是所谓"直心正念真如"。所谓正念，就是无念。能观无念，可以说是趣向佛智了。

## 三、谛信唯心法门

修行最初发心，要谛信唯心法门。佛说"三界唯心，万法唯识"，多少佛法，只是解说这八个字，分明要人人信得过去。

总而言之，圣凡两途，只是自心中迷悟两条路。一切善恶因果，除了这个心，没有片事可得。我们妙性天然，本来不属于悟，又何曾可以迷？如今说迷，只是不了悟自心本无一物，不通达身心世界本空，被它障碍，所以说为迷。

一向把妄想生灭的心当作真心，所以对六尘境缘的种种幻化都认作实有。如今发心趣向，是返流向上的一着，全要把从前的知解尽情脱去，一点知见巧法也用不上。

只是把自己现前的身心世界一眼看透，全是自心中所现的浮光幻影，如镜中像，如水中月。观一切音声，如风过树梢；观一切境界，似云浮虚空，都是变幻不实的。不只外境如此，就是自心的妄想情虑、一切爱根种子、习气烦恼，也都是虚浮幻化不实的。

如此深观，凡有一念生起，一定要勘它的下落，切不可轻易放过，也不可被它瞒昧。这样做功夫，才稍稍接近真切。除此之外，另外去扯些玄妙知见、巧法来凑泊，全没交涉。

## 四、念佛审实话头

就连说"做功夫"本身，也是不得已而说的。譬如用兵，"兵者不祥之器，不得已而用之"（《老子》语）。古人说参禅提话头，都是不得已。

公案虽然很多，唯独"念佛"审实的话头，在尘劳之中最容易得力。虽说容易得力，也不过像敲门的瓦子，终究要抛却，只是少不得用一番罢了。

如今用这话头做功夫，须要信得过、靠得定、咬得住，决不可犹豫。不得今日这样，明日又那样，又恐怕不得开悟，又嫌不够玄妙。这些思量计算都是障碍，先要说破，临时才不生疑虑。

至于功夫做得力之处，外境进不来，唯有心内的烦恼无端横生，或者欲念横发，或者心生烦闷，或者起种种障碍，以致心疲力倦，无可奈何。这是第八识中含藏的无量劫来习气种子，今日被功夫逼急，都现出来了。

这里最要分清楚：先要识得破、透得过，决不可被它笼罩，决不可随它调弄，决不可当作实事。只须抖擞精神，奋发勇猛，提起本参话头，就在这些念头起处，一直挨追下去："我这里本来没有此事，问你从何处来？毕竟是什么？"一定要见个下落。

如此一拶下去，只教神鬼皆泣，灭迹潜踪，务必赶尽杀绝，不留寸丝。这样着力，自然得见好消息。

如果一念拶得破，一切妄念一时脱落，如空花影落，阳焰波澄（空中花影自然消落，阳焰的波纹自然澄清，比喻虚幻妄想自然消散）。过了这一番，便得无量轻安、无量自在，这就是初心得力之处。

但不可执为玄妙。得了轻安自在时，又不可生欢喜心。如果生欢喜心，欢喜魔便附在心上，又多了一层障碍。

## 五、礼佛忏悔与持咒

至于藏识（第八识）中的习气爱根种子，坚固深潜，话头用力不到、观心照不及之处，自己下手不得，就须要礼佛、诵经、忏悔，又要密持咒心（指楞严咒心），仗佛的密印来消除它。

因为诸密咒都是佛的金刚心印，我们用它，如同手执金刚宝杵，摧碎一切物，物遇到它便化为微尘。从上佛祖的心印秘诀，都不出于此。所以说"十方如来，持此咒心，得成无上正等正觉"。

然而佛是明说的，祖师门下怕人落入常情，所以秘而不言，并非不用。这须要每天有定课，久久纯熟，得力很多，但不可希求神应。

## 六、解悟与证悟

凡修行人，有先悟后修的，有先修后悟的。然而悟有解悟与证悟的不同。

如果是依佛祖言教明心，这是解悟，大多落在知见上，在一切境缘中多不得力。因为心境对立，不得混融，处处成为障碍，多有妨碍。这名为"相似般若"，不是真参。

如果是证悟，是从自己心中朴朴实实地做下去，逼拶到山穷水尽之处，忽然一念顿歇，彻了自心，如同在十字街头见了亲爹一般，更无可疑；如人饮水，冷暖自知，也无法吐露给人。这才是真参实悟。

然后就以悟处融会心境，净除现前的业流识浪、妄想情虑，都熔成一味真心，这就是证悟。

证悟也有深浅不同。如果从根本上做功夫，打破第八识的窠臼，顿翻无明的窟穴，一超直入，更无剩法，这是上上利根所证的深境界。其余渐修的人，所证则浅。

最怕得少为足，切忌堕在光影门头。为什么？因为第八识根本未破，纵有作为，都是识神（分别意识）边事。如果以此为真，大似认贼为子。古人说：

```
学道之人不识真，只为从前认识神。
无量劫来生死本，痴人唤作本来人。
```

大意是：学道的人认不得真心，只因一向把识神当作自己；这识神本是无量劫来的生死根本，愚痴的人却把它唤作本来面目。这一关最要透过。

所谓顿悟渐修，是先已悟彻，但还有习气未能顿净，就在一切境缘上，以所悟之理起观照之力，历境验心。融得一分境界，证得一分法身；消得一分妄想，显得一分本智。这又全在绵密功夫，在境界上做出来，更为得力。

## 七、修行六要

凡是利根、信心勇猛的人，修行肯做功夫，事障容易除，理障难遣。其中的病痛，略举一二。

### 第一，不得贪求玄妙

此事本来平平贴贴、实实落落，一味平常，更无玄妙。所以古人说"悟了还同未悟时"：悟了以后，人依然是旧时那个人，只是行履处已不是旧时那样了。

由于我们知解习气未净，内熏般若，般若被习气所熏，起种种幻化，生出许多巧见，缠绵在心，自以为是玄妙，深入不舍。

这正是识神影明（分别意识放出的虚幻光影），是分别妄见的根，也叫做见刺（知见的毒刺）。它与前面粗浮的妄想不同，是微细流注的生灭，也叫做智障，正是障碍正知见的。如果有人认它为真，就会起种种狂见，这是最要忌讳的。

### 第二，不得将心待悟

我们妙圆真心本来绝待（超越一切对待），只因妄想凝结，心境根尘对待角立，所以起惑造业。

如今修行人，只一念放下身心世界，单单提起这一念向前，切莫管悟与不悟，只管念念步步做下去。功夫到了，自然得见本来面目，何须早早盘算？

如果将心待悟，这个"待"心便是生死的根株，等到劫尽也不能悟。因为不了悟绝待真心，以为另有什么可待。这待心不除，容易生疲厌，多成退堕，譬如寻物不见，便起休歇之想。

### 第三，不得希求妙果

众生生死的妄心，原本就是如来的果体。如今在迷，把诸佛的神通妙用变作妄想情虑、分别知见，把真净法身变作生死业质，把清净妙土变作六尘境界。

如今做功夫，如果一念顿悟自心，就如大冶洪炉，陶熔万象。这身心世界，原是如来果体；这妄想情虑，原是神通妙用。只是换了名字，本体并没有改变。所以永嘉大师说：

```
无明实性即佛性，幻化空身即法身。
```

大意是：无明的真实本性就是佛性，如幻的空身就是法身。

如果能悟此法门，取舍之情顿忘，欣厌之心顿歇，步步都是华藏净土，心心都是弥勒下生。如果存心先求妙果，这希求之心便是生死的根本，妨碍正知见，越求越远，求得力疲，就生厌倦了。

### 第四，不可自生疑虑

凡做功夫，一向放下身心，屏绝见闻知觉，脱去旧时的步子。往前看渺渺茫茫，没有安身立命之处；前进没有新的证悟，后退又失去了原来的居处。

这时如果前后筹虑，便生疑心，起无量思算，计较得失，或者另生臆见，动发邪思，妨碍正知见。这须要勘破，决定直入，不再顾虑。

大概功夫做到做不下去的时候，正是得力之处。更加振作，就不会退屈；不然，就堕入忧愁魔了。

### 第五，不得生恐怖心

功夫念力急切，逼拶妄想，一念顿歇，忽然身心脱空，便见大地无寸土，深至无极，于是生大恐怖。在这里如果不能勘破，就不敢向前。

或者把这豁达空（空无所有的境界）当作胜妙境界。如果认了这个空，就起大邪见，拨无因果（否定因果）。这里最为危险。

### 第六，决定信自心是佛

佛没有别的佛，唯心就是。佛的真法身犹如虚空，如果通达妄相本来虚假，本有的法身自然显现，光明寂照，圆满周遍，无欠无余。

更莫把心向外驰求。如果舍此心而另求，心中就会变起种种无量梦想境界，这正是识神变现，切不可作奇特想。

我们清净心中本无一物，更无一念，凡起心动念，就乖背了法体。

如今做功夫的人，总不知道自心妄想原是虚妄，把妄想误认为真实，专门和它作对头。如同小孩子戏弄灯影，越戏越没交涉，弄久了反而自生怕怖。

又有一类人害怕妄想，恨不得一把捉住抛到一边。这如同捕风捉影，终日和它纠缠，费尽力气，没有一念休歇之时。缠绵日久，信心日疲，便说参禅不灵验，于是或生毁谤之心，或生怕怖之心，或生退堕之心。这是初心人的通病。

这没有别的原因，都是因为不通达常住真心、不生灭性，只把妄想认作实法。这里切须透过。

要透过这一关，自有向上一路：只须"离心意识参，离妄想境界求"。但有一念起处，不管是善是恶，当下撇开，切莫和它作对，谛信自心中本无此事。

只把本参话头着力提起，如金刚宝剑，魔来佛来，一齐挥斩。这里最要大勇猛力、大精进力、大忍力。决不得思前算后，决不得怯弱。只要直心正念，挺身向前，自然巍巍堂堂，不被这些妄想缠绕。

如同脱韝之鹰（韝音沟，猎人臂上架鹰的皮套；脱韝之鹰，就是脱离臂套、振翅高飞的猎鹰），十二时中，在一切境缘上自然不被牵绊，自然得大轻安、大自在。这是初心第一步功夫得力之处。

## 八、结语

以上数则，很像画蛇添足，只是一时方便之语，本非究竟，也不是实法。因为在迷路边上，出门一步，恐怕落入差别歧径，枉费心力，虚丧光阴，必须真正从一门超出妙庄严路。所谓"行步平正，其疾如风"，这样的行履，可以日劫相倍（一日的功夫抵得上一劫之功）。

要紧的是，佛祖向上一路，本不涉程途；但在初心方便上，也须从这里透过才行。
