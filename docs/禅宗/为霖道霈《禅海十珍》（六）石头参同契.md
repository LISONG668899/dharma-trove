# 为霖道霈《禅海十珍》（六）石头参同契

## 第六珍　石头希迁禅师参同契

《参同契》共四十四句，五言为句，二百二十字。下面按意义单元分段，保留原文，后附大意。

竺土大仙心，东西密相付。人根有利钝，道无南北祖。

（大意：天竺大仙释迦的心法，在东西之间秘密相付。人的根器有利有钝，道却没有南宗北宗之分。）

灵源明皎洁，枝派暗流注。执事元是迷，契理亦非悟。

（大意：灵妙的本源明亮皎洁，枝派在暗中流注。执著于事，原本是迷；契合于理，也不是悟。）

门门一切境，回互不回互。回而更相涉，不尔依位住。

（大意：六根门头的一切境界，既相互交涉，又各不交涉；交涉时更互相涉入，不交涉时就各依其位而住。）

色本殊质象，声元异乐苦。暗合上中言，明明清浊句。

（大意：色本来质地形象各异，声原本有乐有苦之别。暗处合于上、中的言语，明处分辨清浊的语句。）

〔存疑："上中言""清浊句"所指不明。旧注或说"上中"指上、中、下的言教，或说指清浊有别的语句，暗为平等之理，明为差别之事。大意只是一种读法。〕

四大性自复，如子得其母。火热风动摇，水湿地坚固。眼色耳音声，鼻香舌咸醋。

（大意：四大各自复归其性，如同孩子回到母亲身边：火性热，风性动摇，水性湿，地性坚固；眼对色，耳对声，鼻对香，舌对咸酸。）

然依一一法，依根叶分布。本末须归宗，尊卑用其语。

（大意：然而一一诸法，都依于根而有枝叶分布；本与末都须归于宗，尊与卑各用其相应的言语。）

当明中有暗，勿以暗相遇。当暗中有明，勿以明相睹。明暗各相对，比如前后步。

（大意：正当明处就有暗，不要以暗去相遇；正当暗处就有明，不要以明去相见。明与暗各自相对，好比前后两步。）

万物自有功，当言用及处。事存函盖合，理应箭锋拄。

（大意：万物各有其功用，应当说明它的作用与所在之处。事上要如匣与盖相合，理上要如两支箭的箭锋在空中相抵。）

〔存疑："箭锋拄"用纪昌与飞卫箭锋相抵的典故，喻理上相契无间；但"事""理"二句与上下文的具体连接，旧注说法不一。〕

承言须会宗，勿自立规矩。触目不会道，运足焉知路。

（大意：听到言语，须领会宗旨，不要自立规矩。触目所见而不会道，迈步行走又怎知道路？）

进步非近远，迷隔山河固。谨白参玄人，光阴莫虚度。

（大意：向前进步无所谓远近，一迷就隔着坚固的山河。谨告参玄之人，光阴莫要虚度。）

## 道霈论曰

石头和尚因读《肇论》，读到"会万物为己者，其唯圣人乎"这句话，于是悟到圣人无己，而无所不是己。又梦见与六祖同乘一只灵龟，游于性海，这就是《参同契》所以创作的缘由。

〔译注：原文作"同乘灵智"，石头传记中的梦作"同乘一龟"，"智"疑为"龟"之误，译文依传记。〕

《参同契》句句皆是法，是要人承言会宗、触目会道而已。除此之外，别无一法给人。

## 译者附说

"参同契"三字，原是东汉魏伯阳讲丹道的书名，石头借来作题。"参"是参差，指万象差别；"同"是同一，指本体平等；"契"是契合。全篇讲的就是差别与平等怎样相契：明暗、回互、本末、尊卑、事理，都是同一件事的两面。

这一篇是曹洞宗的源头之一。后面洞山的《宝镜三昧》讲"偏正回互"，同安的《十玄谈》与洞山五位相合，浮山九带中的"理贯""事贯""理事纵横"，都可以溯源到这里的"回互不回互"与"明暗各相对"。道霈把它放在临济法语之前、洞山宝镜之前，正是要读者先在这里认得曹洞的根。
