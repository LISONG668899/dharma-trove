# 憨山《观楞伽经记》（十六）四种禅与涅槃神力

## 邪正二因：四种禅

憨山科判说：以上辨行门中，第一段总示正行的方法完毕。其次略示邪正因果之相，分四层。先略示二因，先显示外道、二乘的邪因禅。

【经文】复次，大慧！有四种禅。云何为四？谓愚夫所行禅、观察义禅、攀缘如禅、如来禅。云何愚夫所行禅？谓声闻、缘觉、外道修行者，观人无我性、自相、共相、骨璅无常、苦、不净相，计著为首，如是相不异观（唐译云如是观察坚著不舍），前后转进相不除灭（唐译云渐次增进至无想灭定），是名愚夫所行禅。

【憨山记】这是略明邪正二因，先显示外道、二乘的邪因。如来说法之所以不同于外道，是因为因行不同。所以这里特别说四种禅，以拣别邪正二因，要让修行人知道如何选择。禅，是入理的方便，就是所谓因行。

二乘与外道不通达自心现量、真无我之理，虽然观我空，因为取著没有忘掉，反而更增我见，所以"相不除灭"。因为因地不真，所以果报迂曲，他们的涅槃也不真实，这名为愚夫所行禅。

【经文】云何观察义禅？谓人无我自相共相，外道自他俱无性已（唐译云谓知自共相人无我已，亦离外道自他俱作），观法无我彼地相义渐次增进（唐译云于法无我诸地相义随顺观察），是名观察义禅。

【憨山记】这名为菩萨修行的方便，以显示正因。从三贤以上直到七地，行相都在此列。所谓"分别二障极喜无，法执俱生地地除"，所以说"观法无我，彼地相义渐次增进"。

【经文】云何攀缘如禅（魏译云观真如禅，唐译云缘真如禅）？谓妄想、二无我妄想、如实处不生妄想，是名攀缘如禅。

【憨山记】这是说明八地以上直到解脱道的行相。唐译作："若分别无我有二，是虚妄念；若如实知，彼念不起。"意思是若分别实有二无我之理，就是妄想，所以说"妄想二无我妄想"；若称实而观，人与法本来没有，如今又哪来"二"？平等如如，分别不起。所以魏译作："不住分别心中，得寂静境界，是名观真如禅。"以上是三乘的行相。

【经文】云何如来禅？谓入如来地，得自觉圣智相三种乐住，成办众生不思议事，是名如来禅。

【憨山记】这是最上一乘的行相。所说的如来禅，不是如来所行的禅，而是以如来果地之觉为本因心，就是所谓"以不生灭心为本修因"，所以说"入如来地，得自觉圣智"，就是前面所说的修行者大方便。上面两种禅虽然称为正行，仍属渐修；这一种则是顿悟一心，顿登佛地，三德秘藏一念顿得，就能成办众生不思议之事，所以名为如来清净禅。

这正是达摩所传的禅宗，三世诸佛、历代祖师的心印。此经所指示的旨趣就在这里，岂是外道、二乘的邪禅以及妄想攀缘作证的人所能比的？所以要让修行人必定以此为真因，才能得到如来无上大涅槃果。因为因真果正，这就是如来说法不与外道恶见相同的原因。

【经文】尔时，世尊欲重宣此义，而说偈言：愚夫所行禅，观察相义禅，攀缘如实禅，如来清净禅。

【憨山记】这是通颂四种禅相，下面拣别邪正。

【经文】譬如日月形，钵头摩深险，如虚空火尽，修行者观察。如是种种相，外道道通禅，亦复堕声闻，及缘觉境界。

【憨山记】这是颂外道、二乘的邪禅行相，告诫修行人不可误堕。外道所计的神我，所以入定时观见如日月之形，明净朗耀，或见如红莲华在海中，以此为真。二乘妄计五蕴实有自相共相，所以作无常、苦、空等观，灰身泯智，同于虚空，如薪尽火灭，以此为涅槃。所以告诫说：修行者观察时，纵然见到这样种种境相，决不可误堕其中。

【经文】舍离彼一切，则是无所有。一切刹诸佛，以不思议手，一时摩其顶，随顺入如相。

【憨山记】这是颂显正行。意思是要让修行人不但舍弃外道、二乘的邪禅，不可亲近修习；若依佛的教门了达唯心现量，就连观察义禅、攀缘如禅这两种渐行也不必亲近修习，所以说"舍离彼一切，则是无所有"。因为依无所有观，就能顺入真如，这名为如来清净无相禅。修行人依此才名为正行，就能顿契佛心，所以立即感得十方诸佛以不思议之手一时为他摩顶。

以上略明邪正因行的不同。以下略明邪正果相的不同。

## 邪正二果：如来涅槃

【经文】尔时大慧菩萨摩诃萨复白佛言：世尊！般涅槃者，说何等法谓为涅槃？

【憨山记】上面说明因行不同，这里说明果相也不同。大慧听说因行不同，于是问：世尊既然以如来清净禅为因行，不知以什么法为果相？所以这里请问涅槃，以显示果德的不同。

【经文】佛告大慧：一切自性习气藏意意识，见习转变名为涅槃，诸佛及我涅槃自性空事境界。

【憨山记】这是说明转生死为涅槃，以显示如来的真果。唐译作："一切识自性习气，及藏识、意、意识见习转已，我及诸佛说名涅槃，即是诸法性空境界。"意思是一切识的自性习气，以及心意识的见习无明，都是生死之因；若了达它们性空，生死当体就转为涅槃，就是诸法性空的境界。而外道与二乘妄有所证得，执为涅槃，因为他们因地不真，所以所取的涅槃也不是究竟，因为没有离开生死之因。

【经文】复次，大慧！涅槃者，圣智自觉境界，离断常妄想性非性。云何非常？谓自相共相妄想断故非常。云何非断？谓一切圣去来现在得自觉故非断。大慧！涅槃不坏不死，若涅槃死者复应受生相续，若坏者应堕有为相，是故涅槃离坏离死，是故修行者之所归依。

【憨山记】这是显示涅槃之相。因为涅槃是自觉圣智的境界，不是外道、二乘的妄想境界，离开断常、有无的分别。因为离开凡夫的假我和外道的神我，所以"非常"；因为离开外道的豁达空和二乘的断灭，所以"非断"。因为不坏，所以不灭；不死，所以不生。不灭，所以是众圣的灵府；不生，所以是群生的安宅。所以说"一切圣去来现在得自觉"，是"修行者之所归依"。这里凡夫妄认五蕴假我为自相，外道妄立神我主谛为共相。

【经文】复次，大慧！涅槃非舍非得、非断非常、非一义非种种义，是名涅槃。

【憨山记】这是总结显示涅槃的正义。三乘妄见有取有舍，外道妄执断常、一异，都是妄见分别如来自性清净大涅槃之相；离开这些过失，一切皆非。所以六祖说：

「无上大涅槃，圆明常寂照。凡愚谓之死，外道执为断。诸求二乘人，目以为无作。尽属情所计，六十二见本。妄立虚假名，何为真实义？惟有过量人，通达无取舍。以知五蕴法，及以蕴中我，外现众色像，一一音声相，平等如幻梦，不起凡圣见，不作涅槃解，二边三际断。常应诸根用，而不起用想；分别一切法，不起分别想。劫火烧海底，风鼓山相击，真常寂灭乐，涅槃相如是。」

这一偈的大意是：无上大涅槃圆满明净，常寂而照；凡夫愚人说它是死，外道执为断灭，求二乘的人把它看作无为。这些都是情识所计度的，是六十二种邪见的根本，妄立虚假的名字，哪里是真实之义？唯有超越常量的人，通达而无取无舍。他知道五蕴之法以及五蕴中的"我"，外现的种种色像、一一音声之相，都平等如梦如幻，不起凡圣之见，也不作涅槃之解，二边与三际都断。常应诸根之用，却不起"用"的念想；分别一切法，却不起分别之想。即使劫火烧到海底，大风鼓动群山相击，那真常寂灭之乐依然如此，这就是涅槃之相。

看六祖说涅槃之相，就像看掌中的庵摩勒果一样清楚。这就是所谓转心、意、意识的见习而为涅槃，进入诸法性空的境界。

【经文】复次，大慧！声闻、缘觉涅槃者，觉自相、共相，不习近境界（唐译云舍离愦闹），不颠倒见，妄想不生，彼等于彼作涅槃觉。

【憨山记】这是说二乘涅槃是假果。二乘虽然超过外道的邪见，但也不是究竟，正所谓"但尽生死，谓为解脱"。所以魏译作："声闻辟支佛，非究竟处生涅槃想。"

以上显示两种果完毕。以下略示应当转变的两种自性。

## 当转二性：言说自性与事自性

【经文】复次，大慧！二种自性相。云何为二？谓言说自性相计著、事自性相计著。言说自性相计著者，从无始言说虚伪习气计著生。事自性相计著者，从不觉自心现分齐生。

【憨山记】这是解释上面"一切自性习气"之相，略示应当转变的两种自性，以说明果德不同的原因。如来的涅槃之所以不同于外道、二乘，是因为如来转一切自性习气为涅槃，外道与二乘执有自性为涅槃，所以不同。所以这里特别显示两种自性相，要让人知道所要转的是什么。

言说自性：《法华经》说："诸法寂灭相，不可以言宣。"三界本无实法，唯以名言为体，只有言说，全无实义。凡夫外道不知名言性空，妄计言说音声有真实的自体，依之分别，造种种业，由来已久，所以说"从无始言说虚伪习气生"。若了达音声如回响，言说性空，如风吹树木孔窍发声，太虚本来寂灭；分别不起，法性就湛然，唯一圆明，了无尘习。这就是所谓转言说自性而为涅槃。外道不知这样出离，妄起诸见，所以他们所计的涅槃，都是从计著言说自性的无始虚伪习气所生，不是真实。

事自性：经中说："三界上下法，唯是一心作。"因为诸法唯心所现，如镜中像，本非实有，只是一心，更无别法。二乘不了唯心，向心外取法，妄计诸法实有自体；因为不通达诸法本来寂灭之相，所以妄见有生死可厌、涅槃可证。所以他们所证的涅槃，都是计著事自性相，从不觉自心现分齐所生，不是真灭。由于因不是真因，所以果不是究竟。这就是如来说涅槃之所以不同于外道。

## 感应二征：两种神力

憨山科判说：以下略示感应二征。

【经文】复次，大慧！如来以二种神力建立（唐译云神力加持），菩萨摩诃萨顶礼诸佛，听受问义。云何二种神力建立？谓三昧正受，为现一切身面言说神力，及手灌顶神力。

【憨山记】这是略示感应二征。意思是修行人内具真因，外感胜缘，借助两种神力加持，所以不堕外道、声闻、辟支佛地，用意是令修行人生起决定信，趣向究竟果。看看正法住世时的诸大菩萨，都是久植善根、亲承佛足，而且凡所行证都仗如来神力加持，何况末法时期呢？可悲啊！去圣时遥，魔强法弱，我们善根浅薄，若不仰仗诸佛愿力加持，想出离生死、破除魔冤，实在很难。

加持有两种：一是诸佛的大愿力，二是修行者的大信力。《法华经》说："若有修行此经法者，我尔时为现清净光明身"等，这是佛的愿力。《楞严经》说："若有末世欲坐道场，先持比丘清净禁戒，诵此心佛所说神咒，建立道场，求于十方现住国土无上如来，放大悲光来灌其顶，我自现身至其人前，摩顶安慰，令其开悟。"这是修行人的信力。此经虽然单说愿力，用意是令人增长决定的信力。

加持又有两种：一是冥加，二是显加，这里两种都是显加。说"三昧正受，为现身面言说"等，是修行人入三昧中，才得到两种神力加持，绝不是散乱心所能得到的。所以前面说："舍离彼一切，则是无所有，一切刹诸佛，以不思议手，一时摩其顶，随顺入如相。"

【经文】大慧！菩萨摩诃萨初菩萨地住佛神力，所谓入菩萨大乘照明三昧。入是三昧已，十方世界一切诸佛，以神通力为现一切身面言说（唐译云十方诸佛普现其前），如金刚藏菩萨摩诃萨，及余如是相功德成就菩萨摩诃萨。大慧！是名初菩萨地菩萨摩诃萨得菩萨三昧正受神力，于百千劫积习善根之所成就。

【憨山记】这是现身面言说的神力。说登地才加持、三贤不受加持，是因为三贤还没有入真如无相三昧。而一登初地就加持，是因为多劫积习善根所成就，并不只是这一时之事。所以从上诸祖虽然一念顿悟自心，不从人得，也是因为多劫积习般若善根，久为诸佛护念，内熏的功夫足了，所以外感加持，岂是浅薄的人所能得到的？

【经文】次第诸地对治所治相，通达究竟至法云地，住大莲华微妙宫殿，坐大莲华宝师子座，同类菩萨摩诃萨眷属围绕，众宝璎珞庄严其身，如黄金薝卜日月光明，诸最胜子从十方来，就大莲华宫殿座上而灌其顶，譬如自在转轮圣王及天帝释太子灌顶，是名菩萨手灌顶神力。

【憨山记】这是灌顶神力的加持。法身流转五道，称为众生；因为被二障所缠，所以法身隐而不显，这样就只有执持之力，而不能感得加持之力。如今修行人入大乘照明三昧，以三昧之力顿断粗重的三障，证平等真如，得法性身，与十方诸佛气分交接，所以立即感得诸佛现身说法、神力加持。由内外交熏，净治微细二障，究竟无余，一念顿证二转依果。因为法性圆明，与十方诸佛同体无二，所以感得灌顶神力加持。

【经文】大慧，是名菩萨摩诃萨二种神力。若菩萨摩诃萨住二种神力，面见诸佛如来；若不如是，则不能见。

【憨山记】这是总结两种加持，以说明三种佛性之义。佛性有三种：正因、缘因、了因。众生虽然各各具有正因佛性，若不遇真善知识以方便善巧助发，也不能了了明见。譬如国王想求箜篌之声，断其弦、剖其木去求，毕竟得不到，因为没有善巧方便之缘。那些外道与二乘也同样禀有正因佛性，只因被恶见熏习，妄执两种自性为涅槃，虽想求之，反而增长邪执，毕竟不能明见佛性，所以说"若不如是，则不能见"。

意思是：外道与二乘若果真是真果，必定能得到这样感应加被之力；如今既然不能，可见果不是真的。《法华经》说："若得作佛时，具相三十二，天人夜叉众，龙神等恭敬，是时乃可谓，永尽灭无余。"如今既然不是这样，足以知道不是真灭。

【经文】复次，大慧！菩萨摩诃萨凡所分别三昧神足诸法之行，是等一切悉住如来二种神力。（唐译云：诸菩萨摩诃萨入于三昧现通说法，如是一切皆由诸佛二种神力。）大慧！若菩萨摩诃萨离佛神力能辩说者，一切凡夫亦应能说。所以者何？谓不住神力故。

【憨山记】这是说菩萨能明见佛性，所以凡所动静作为，都住于如来的两种神力。一切凡夫同样禀有佛性，却不能说法，是因为日用而不知；由于不知，所以只是不住于神力，并不是没有加持，因为如来不舍弃任何一个众生。庞居士说：

「野老负薪归，村妇连宵织，看他家事忙，且道凭谁力？问渠渠不知，特地生疑惑，伤嗟今古人，几个知恩德？」

大意是：乡野老人背柴回家，村妇通宵织布，看他们家事忙碌，试问凭的是谁的力量？问他们，他们不知道，反而生起疑惑；可叹古往今来的人，有几个知道这份恩德？

所以《华严经》中四十二种法门，都是菩萨承佛神力而说的；至于不同类的众生都能说法，各得一种法门，也是由于住于如来的两种神力。

【经文】大慧！山石、树木及诸乐器、城郭、宫殿，以如来入城威神力故，皆自然出音乐之声，何况有心者！聋、盲、喑、哑无量众苦皆得解脱，如来有如是等无量神力利安众生。

【憨山记】这是反过来显示如来并非不加被众生，只是众生不了自心，所以得不到如来真实的受用，绝不是如来舍弃众生，所以说"有无量神力利安众生"。由此看来，无情之物受了加持尚且发出声音，何况那些外道、二乘这些有情呢？所以说舍善根的一阐提，又因如来神力，有时善根生起，这并不是毕竟不加持，譬如日光对于天生的盲人，也没有不利益的。

【经文】大慧菩萨复白佛言：世尊！以何因缘，如来、应供、等正觉，菩萨摩诃萨住三昧正受时，及胜进地灌顶时，加其神力？佛告大慧：为离魔业烦恼故，及不堕声闻地禅故，为得如来自觉地故，及增进所得法故，是故如来、应供、等正觉，咸以神力建立诸菩萨摩诃萨。若不以神力建立者，则堕外道恶见妄想，及诸声闻众魔希望，不得阿耨多罗三藐三菩提。以是故，诸佛如来咸以神力摄受诸菩萨摩诃萨。

【憨山记】这是承接上面而发问。大慧的意思是：如来既然有无量神力利安众生，为什么单说加持地上菩萨，而不说其余众生？所以世尊回答：

因为登地菩萨初入真见道，有相之观还多，若不加持，就堕入魔业。所以《华严经》说，菩萨有十种魔，忘失菩提心而修诸善根，这是魔业。所以初地若不加持，就堕入魔业。七地菩萨还没有离开心量，若不被加持，就堕入外道邪径。八地菩萨纯是无相观，味著三昧，不起度生之心，所以十方诸佛三加七劝，把他从寂定中拔出，说："起来，善男子！不要乐住三昧，你的三昧二乘也能得到。"所以这时若不加持，就堕入二乘禅，不能到达如来的自觉地。十地以上的金刚喻定，还有最极微细的二障，所以胜进之时若不加持，就不能顿断极微的二障，不能顿得无上菩提。

所以诸佛如来都以神力摄受诸菩萨；因为地前的不是真修，所以不摄受。可叹那些外道与二乘，既不能以不生灭心为本修因，又不能蒙受十方如来的神力加持，怎能得到究竟真常之果？所以他们甘心堕落沉沦，乐于鄙陋之事，也就理所当然了。由此可知，《圆觉经》的三期道场、《楞严经》的坛场，并不是白白设立的，修行人应当深深认识这一点。

【经文】尔时，世尊欲重宣此义，而说偈言：神力人中尊，大愿悉清净。三摩提灌顶，初地及十地。
