# 《南阳和尚问答杂征义》

荷泽神会大师答问，前唐山县主簿刘澄集录。"南阳和尚"即神会大师，他于开元八年（720）奉敕配住南阳龙兴寺，在南阳一带弘法多年。本书记录他与王公大臣、各方法师问答的言语，是神会语录最早的结集。

## 版本说明

神会的语录，今存三个敦煌写本：

一是巴黎国家图书馆藏伯希和写本 P.3047，前部残缺，没有标题，胡适先生1930年校写刊行，拟题"神会语录"。

二是日本石井光雄旧藏写本，首尾完整，五百余行，卷末有唐贞元八年（792）在北庭校勘的题记，同样没有标题，后来由铃木大拙等校订出版。

三是伦敦大英博物馆藏斯坦因写本 S.6557，1957年由日本入矢义高先生发现。这个写本卷首保存了编者刘澄的序文（只存后半），序中明说书名为"问答杂征义"。日本入唐僧圆仁于开成三年（838）所编的《入唐新求圣教目录》中，正著录有"南阳和尚问答杂征义一卷，刘澄集"，二者正相吻合，这部语录的原名与编者由此得以确定。

S.6557 尾部残缺，只存十四段，约为石井本的三分之一，但它保存了原题与原序，被认为最接近刘澄最初结集的面貌。本篇即据胡适先生1960年校写的 S.6557 本（收入《大藏经补编》第二十五册）译出。原文中方括号内的字，是校者据他本补入的。

## 刘澄序（残存后半）

……教化遍满法界。南天竺传来心印，东土依为正宗。法不会凭空流传，必定有所寄托，南阳和尚正是其中最盛的一位。他禀承六代祖师为先师，位居第七，作当今的教主。

学人向往他，如同归依父母；向他问法请益的，连王公也不例外，淡然相待。他像高悬的明镜，照得人须眉毕现，丑陋无可隐藏；又像深不可测的大海，洪波涌起，却澄澈涟漪。他的偈颂比贯串的花鬘更美妙，他的开示清朗，顿成圆满的果德。

贵贱之人虽然都来问法，但所记录的大多遗忘了。如果不集录成书，恐怕连片纸只字都留不下来。于是又访求得到记录的人，把它们缀集在后面，编成一卷，名为《问答杂征义》。只给同修的兄弟们看，其余的人就不预闻了。

前唐山县主簿刘澄集

## 一、本有今无偈

作本法师问："《涅槃经》中说：'本有今无，本无今有，三世有法，无有是处。'这是什么意思？"

神会答："承蒙法师发问，神会对此也有疑问。"

又问："疑的是什么？"

答："自从佛法东传以来，所有的大德都把'断烦恼'当作这首偈中的'本'来解释，所以我生起怀疑。"

问："你根据什么道理，怀疑把烦恼当作'本'呢？"

又答："根据《涅槃经》第九〈菩萨品〉，文殊师利菩萨说：'纯陀心中怀疑如来常住，是因为得知见佛性的力量。如果见到佛性才是常，那么本来没见到的时候，应是无常；如果本来无常，后来也应如此。为什么呢？世间的事物本无今有，已有还无，像这样的东西都是无常的。'

"检验这段经文，文殊所提出的纯陀之疑，是怀疑佛性不是常住之法，并不是问烦恼。为什么古今大德都把断烦恼当作'本'呢？所以我才生疑。"

问："那么'本有今无偈'究竟是什么意思？"

答："依据《涅槃经》的意义，'本有'，是本有佛性；'今无'，是今无佛性。"

问："既然说本有佛性，为什么又说今无佛性？"

答："说'今无佛性'，是因为佛性被烦恼遮盖，见不到，所以说无。'本无今有'：'本无'，是本来没有烦恼；'今有'，是今天具有烦恼。即使经过恒河沙数的大劫，烦恼也只是今有。'三世有法，无有是处'，是说佛性不属于三世相续之法。"

问："为什么佛性不属于三世？"

答："佛性的本体是常，所以不是生灭法。"

问："什么才是生灭法？"

答："三世就是生灭法。"

问："佛性与烦恼是同时具有，还是不同时？"

答："同时具有。虽然同时，生灭法有来有去，佛性无来无去，因为佛性是常，就像虚空：明暗有来去，虚空没有来去。因为佛性没有来去，所以三世之中，没有不生灭的法。"

问："佛性与烦恼既然同时具有，为什么单单断定烦恼不是本呢？"

答："譬如金子和矿石同时生成，遇到冶金师傅，放入炉中冶炼，金子和矿石就各自分开了。金子越炼越精，矿石再炼就变成灰土。《涅槃经》说，金子比喻法性，矿石比喻烦恼。诸大乘经论都明白地说烦恼是客尘，所以不能称它为本。

"如果把烦恼当作本，烦恼是黑暗，怎能从黑暗得到光明？《涅槃经》只说以明破暗，不说从暗得明。如果暗能破明，经论中应当自有这样的说法；经论中既然没有，这种说法从何而立？如果把烦恼当作本，就不应断烦恼而求涅槃。"

问："那为什么经中又说'不断烦恼而入涅槃'？"

答："这是说，推究烦恼的本性，本来就无可断。如果认为烦恼的本性就是涅槃，就不应劝众生具修六波罗蜜，断一切恶，修一切善。把烦恼当作本，就是弃本逐末。

"《涅槃经》说：'一切众生本来涅槃，无漏智性本自具足。譬如木性与火性同时而生，遇到燧人氏钻木摇动，火与木当时就各自分开。'经中说的木，比喻烦恼；火，比喻佛性。《涅槃经》又说'以智慧之火烧烦恼之薪'，又说'智慧就是佛性'。经中具有这些文句，可见烦恼不是本。"

问："那为什么《涅槃经》第十五〈梵行品〉中说：'本有者，本有烦恼；今无者，今无大般涅槃；本无者，本无摩诃般若；今有者，今有烦恼'？"

答："这是对五阴色身而说的，所以说烦恼为本。经中又说：'佛言：善男子，这是为了化度众生而作这样的说法，也是为声闻、辟支佛而作这样的说法。'

"又第三十六〈憍陈如品〉中，梵志问佛：身与烦恼，哪一个在先？佛说：说身在先不可以，说烦恼在先也不可以，要因为有烦恼，然后才有身。检验这段经文，可知这是说烦恼是身的根本，不是相对佛性而说的。

"经中又说：'因为有佛性，才能称为常；因为是常，才能称为本。'佛性不是本无今有。第十五卷说：'佛性无得无生。为什么？因为它非色非不色，不长不短，不高不下，不生不灭。因为不生灭，所以称为常；因为是常，所以称为本。'

"第十九卷说：'譬如暗室中有七宝，人也知道有，因为黑暗看不见。有智慧的人点起明灯，拿去照，全都看见了。这人见到七宝，终究不会说它们是今天才有的。法性也不是今天才有，因为烦恼的黑暗看不见，就说它本无今有。又如盲人看不见日月，遇到良医治好了，就能看见，便说日月本无今有。其实是因为眼盲看不见，日月本来就有。'

"第二十五卷说：'一切众生未来之世必定证得阿耨多罗三藐三菩提，这名为佛性。一切众生现在具有烦恼诸结，所以看不见，就说本来没有。'

"又第十九卷说：'有佛无佛，性相常住。因为众生被烦恼遮覆，看不见涅槃，就以为没有。应当知道涅槃是常住之法，不是本无今有。'

"佛性不是五阴、十八界、十二入，不是本无今有，也不是已有还无。依靠种种善缘，众生得以见到佛性；因为能见到佛性，所以知道它本来就有。"

问："既然说本来就有，为什么自己不能见到，还要借助因缘？"

答："就像地下有水，如果不施功挖掘，终究得不到；也像摩尼宝珠，如果不加磨治，终究不能明净，因为不明净，人们就说它不是宝。《涅槃经》说，一切众生如果不依靠诸佛菩萨善知识的指授，终究不能见到；自己见到，那是没有的事。因为见不到，就说本来没有佛性。佛性不是本无今有的。"

## 二、何为常义

真法师问："什么是常的意义？"

答："无常就是常的意义。"

问："我问的是常的意义，为什么回答无常就是常的意义？"

答："因为有无常，才开始说常。如果没有无常，也就没有常的意义。因为这个道理，才能称为常。譬如长因短而生，短因长而立，如果没有长，短也立不起来。事相既然相同，道理又有什么不同呢？

"又，法性的本体不可得，这是常的意义。虚空也是常的意义。"

问："为什么虚空是常的意义？"

答："虚空没有大小，也没有中边，所以称为常的意义。所谓法性的本体不可得，这是'不有'；能见那不可得的本体湛然常寂，这是'不无'，这就是常的意义。

"如果依有无来论，就是这样。如果就法性本体来说，于无也不是无，于有也不是有，恒沙功德本自具足，这就是常的意义。

"又，不大不小是常的意义。虚空没有大，不能说它大；虚空没有小，不能说它小。现在所说的大，是相对于小而说的大；所说的小，是相对于大而说的小。这对未明了的人，就用常与无常来论说；如果就法性之理来说，也没有常，也没有无常，因为没有无常，才能称为常。"

## 三、王赵公问三车义

户部尚书王赵公（王琚，封赵国公）以偈问《法华经》中三车的道理，神会也以偈作答：

```
问：宅中无三车，露地唯得一。不知何所用，而说此三车？
答：三车在门外，说即在宅中。诸子闻说时，已得三车讫。
```

大意是：王赵公问：火宅中并没有三车，到了露地也只得到一辆大白牛车，那么说三车有什么用？神会答：三车说在门外，其实说的时候就在宅中；诸子听到父亲说时，就已经得到三车了。

```
问：今者在门外，先是乘车出。宅中既得车，出外何须索？
答：诸子虽得讫，不知车是车。既不自证知，所以门外索。
```

大意是：问：现在到了门外，原是乘车出来的；既然在宅中已经得到车，出来后何必再索要？答：诸子虽然已经得到，却不知道车就是车；既然自己不能证知，所以在门外索要。

王赵公又问："哪里有人得了道果，自己却不知道的呢？"

神会答："经中下文说，自己所得的功德，仍不自觉知。"

```
问：诸子不自知，容可门外索。父应知子得，何须更与车？
答：诸子不自知，所以门外索。长者今与车，还是先与者。
```

大意是：问：诸子自己不知道，在门外索要还说得过去；父亲应当知道儿子已经得到，何必再给车？答：正因为诸子自己不知道，所以在门外索要；长者现在所给的车，仍是先前给过的那一辆。

```
问：三车本无实，所说乃权宜。与者是旧车，那应得假物？
答：长者意在一，方便权说三。前者说三车，三车本是一。
```

大意是：问：三车本来不是实有，所说的只是权宜；所给的既是旧车，怎么得到的反而是假物？答：长者的本意在一乘，只是方便权说三乘；先前所说的三车，本来就是一车。

```
问：一车能作三，三车能作一。何不元说一，辛苦说三车？
答：若为迷人说，三便作三车。若约悟人解，即三便是一。
```

大意是：问：一车能分作三车，三车能合为一车，为什么不一开始就说一车，要辛苦地说三车？答：如果对迷人说，三就成了三车；如果就悟人的理解来说，三就是一。

## 四、崔齐公问出定

崔齐公（崔日用，封齐国公）问："禅师坐禅，一入定以后，要过多久才出定？"

答："神妙之心没有方所，有什么定可入呢？"

又问："既然说没有定，凭什么说用心？"

答："我现在连定都不立，谁说用心？"

问："心与定都没有，怎样才能得道？"

答："道就是这样的道，并没有一个'怎样的道'。"

问："既然没有'怎样的道'，又从哪里得到'这样的道'？"

答："现在说'这样的道'，是因为有'怎样的道'。如果说没有'怎样'，'这样'也就不存在了。"

## 五、简法师问中道

庐山简法师问："什么是中道的意义？"

答："边的意义就是。"

问："现在问中道的意义，为什么回答边的意义就是？"

答："现在说中道，要因边的意义才能立。如果不立边，中道也立不起来。"

## 六、苏晋问大乘与最上乘

礼部侍郎苏晋问："什么是大乘？什么是最上乘？"

答："菩萨就是大乘，佛就是最上乘。"

问："大乘与最上乘有什么差别？"

答："所谓大乘，如菩萨行布施波罗蜜，观施者、受者、施物三事体空，乃至六波罗蜜也都是这样，所以名为大乘。所谓最上乘，只是见到本自性空寂，就知道三事本来自性空，不再起观，乃至六度也是这样，这名为最上乘。"

又问："需要借助缘起吗？"

答："这里不立缘起。"

问："如果没有缘起，怎么能知道？"

答："本来空寂的本体上，自有般若智能知，不借助缘起。如果立缘起，就有次第了。"

问："那么，就不再需要修一切行了吗？"

答："如果得到这样的见地，万行都已具备。"

又问："见到这本性的人，如果生起无明，会成为业结吗？"

答："虽然有无明，却不成业结。"

问："为什么不成？"

答："只要见到本性的体不可得，业结本来就不生。"

## 七、李峻问安禅师二语

润州刺史李峻说："我见到有一位山中僧人礼拜嵩山慧安禅师，禅师说：'趁粥道人！'（赶来吃粥的修道人）又有一位授记寺的僧人礼拜慧安禅师，禅师说：'惜粥道人！'（舍不得粥的修道人）请问这两句是什么意思？"

答："这两种都要遣除。"

问："怎样遣除？"

答："只要离开，就是遣除。"

问："怎样离开？"

答："我现在就这样离开，并没有一个'怎样离开'。"

问："是用心离，还是用眼离？"

答："现在就这样离，也没有心离、眼离。"

问："心和眼都不见，那应该是盲人了？"

答："是盲人自己说盲，别人有眼的自然不盲。经中说：'是盲者过，非日月过。'（看不见是盲人的过失，不是日月的过失）"

## 八、张燕公问无念

张燕公（张说，封燕国公）问："禅师常说无念法，劝人修学，不知道无念法是有还是无？"

答："无念法不说有，也不说无。"

问："为什么无念不说有无？"

答："如果说它有，却不同于世间的有；如果说它无，却不同于世间的无。所以无念不同于有无。"

问："那叫它作什么？"

答："不叫它作什么。"

问："那它是怎样的？"

答："也不是怎样的。所以无念不可说。现在说它，是因为回答提问；如果不是回答提问，始终没有言说。譬如明镜，如果不对着物像，镜中终究不现影像；现在说现影像，是因为对着物，所以现出影像。"

问："如果不对着物像，镜子照还是不照？"

答："现在说照，不论对与不对，都是常照。"

问："既然没有形像，又没有言说，一切有无都不能立，现在说照，又是什么照？"

答："现在说照，是因为镜子明亮，所以有自性的照；因为众生心净，自然有大智慧光，照遍无余世界。"

问："既然如此，什么时候才能得到？"

答："只要见到无。"

问："既然是无，见的是什么东西？"

答："虽然见，却不叫它作是什么东西。"

问："既然不叫它作是什么东西，凭什么叫见？"

答："见到无物，就是真见、常见。"

## 九、问远法师生灭

和上问远法师（崇远法师）："您曾讲过《大般涅槃经》吗？"

远法师说："讲过《大般涅槃经》几十遍了。"

和上又说："一切大小乘经论都说，众生之所以不得解脱，是因为有生、灭二心。《涅槃经》说：

```
诸行无常，是生灭法。生灭灭已，寂灭为乐。
```

"请问：生和灭，可灭还是不可灭？是拿生去灭灭，还是拿灭去灭生？是生能自己灭生，还是灭能自己灭灭？请法师一一详细回答。"

（偈的大意是：一切有为之行都是无常，是生灭之法；生与灭都灭尽了，寂灭才是安乐。）

远法师说："我也见到诸经论这样说，至于这个道理，实在不能明了。禅师如果明了这个道理，请为大众说。"

和上说："我不推辞为大家说，只怕没有人能理解。"

法师说："在场道俗有一万多人，难道没有一个人能理解？"

和上说："看你见不见。"

法师说："见的是什么？"

和上说："果然不见。"

法师听了这话，结舌无对。这不只是他一人理屈词穷，连他的门徒也都失了志气。胜负既已分明，道俗大众嗟叹而散。

## 十、问澄禅师修定见性

和上问澄禅师（慧澄禅师）："修什么法能够见性？"

澄禅师答："先须学坐修定，得定以后，由定发慧，因为有智慧，就能见性。"

问："修定的时候，难道不需要作意吗？"

答："是的。"

问："既然是作意，就是识定，怎能见性？"

答："现在说见性，就须要修定；如果不修定，怎能见性？"

问："现在修定，原本就是妄心。以妄心修定，怎能得定？"

答："现在修定得定的人，自有内外照；因为内外照，所以能见到净；因为心净，就是见性。"

问："现在说见性，性没有内外。如果说因为内外照，原本就是妄心，怎能见性？经中说：

```
若学诸三昧，是动非坐禅。心随境界流，云何名为定？
```

"如果认为这种定是对的，维摩诘居士就不应该诃斥舍利弗的宴坐了。"

（偈的大意是：如果去修学种种三昧，那是动，不是坐禅；心随着境界流转，怎能叫做定？）

## 十一、问诸学道者用心

和上问诸位学道的人："现在所说的用心，是作意，还是不作意？如果不作意，就和聋子、俗人没有分别；如果说作意，就是有所得。有所得，就是系缚，怎么能得解脱？

"声闻人修空住于空，就被空所缚；修定住于定，就被定所缚；修静住于静，就被静所缚；修寂住于寂，就被寂所缚。所以《般若经》说：'若取法相，即著我、人、众生、寿者。'

"《维摩经》说：'调伏心者，是声闻法；不调伏心者，是愚人法。'你们用心是在调伏，怎能名为解脱？须陀洹也调伏，斯陀含也调伏，阿那含、阿罗汉也调伏，非想定及非非想定也调伏，四禅也调伏，四圣、三贤都在调伏。要怎样分辨呢？像这样的定，都还不是真正的解脱法。"

## 十二、神足师问识心

神足师问："真如的本体，就是本心，又没有青黄等相，怎样才能认识？"

答："我的心本来空寂，不觉之间妄念生起。如果觉察到妄念，觉与妄就都一起灭了。这就是识心。"

问："虽然有觉照，仍然同于生灭。现在说什么法，才能不生灭？"

答："只因为心起，才有生灭。如果起心既然灭了，生灭自然消除，无相可得，只是假说觉照。觉照既然灭了，生灭自然没有，就是不生灭。"

## 十三、崇远法师问空

崇远法师问："什么是空？如果说有空，就仍同于有质碍的东西；如果说没有空，又归依于何处呢？"

答："只因为还没有见性，所以说空。如果见到本性，连空也不存在。这样见，就名为归依。"

## 十四、诵持《金刚经》，直入一行三昧

和上告诉各位知识："如果想要了达甚深法界，直入一行三昧，先须诵持《金刚般若波罗蜜经》，修学般若波罗蜜。

"《金刚般若波罗蜜经》说：'须菩提，如果有人以充满无量阿僧祇世界的七宝布施，若有善男子、善女人发菩萨心，诵持此经，为人演说，他的福德胜过前者。怎样为人演说？不取于相。'

"怎样是不取于相？就是如如。怎样是如如？就是无念。怎样是无念？就是不念有无，不念善恶，不念有边际、无边际，不念有限量、无限量；不念菩提，不以菩提为念；不念涅槃，不以涅槃为念，这就是无念。这无念，就是般若波罗蜜；般若波罗蜜，就是一行三昧。"
