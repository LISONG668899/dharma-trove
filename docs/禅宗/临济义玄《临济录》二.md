# 临济义玄《临济录》二　示众

师示众说：如今学道的人，且要自信，莫向外觅。若向外觅，总是攀上那些闲尘境，全不辨邪正。比如有祖有佛，都是教迹中的事。有人拈起一句话，或从隐显中说出来，便即生疑，照天照地，到处寻问，也大茫然。大丈夫儿，莫只管论主论贼，论是论非，论色论财，说闲话过日子。

山僧这里不论僧俗，凡有来者，全都认得他，任他从什么地方出来。只要有声名文句，都是梦幻。却见到那个乘境而来的人，才是诸佛的玄旨。佛境不能自称"我是佛境"，还是这个无依道人乘境出来。若有人出来问我求佛，我就应清净境出；有人问我菩萨，我就应慈悲境出；有人问我菩提，我就应净妙境出；有人问我涅槃，我就应寂静境出。境有万般差别，人却不别。所以应物现形，如水中月。

道流！你若想如法，直须是大丈夫儿才行；若萎萎随随，就不行了。有裂缝的破器，不堪贮存醍醐。像大器者，直要不受人惑，随处作主，立处皆真。凡有来者，都不接受。你一念疑，魔就入心。如菩萨起疑时，生死魔便得其便。只要能息念，更莫外求，物来则照。你只要相信现今作用的这个，一件事也没有。你一念心生出三界，随缘被境，分为六尘。你如今应用处，欠少什么？一刹那间，便入净入秽，入弥勒楼阁，入三眼国土，处处游履，唯见空名。

有人问：如何是三眼国土？师说：我和你入净妙国土中，穿清净衣，说法身佛；又入无差别国土中，穿无差别衣，说报身佛；又入解脱国土中，穿光明衣，说化身佛。这三眼国土，都是依他变现。

依经论家，以法身为根本，报身、化身为作用。依山僧的见处，法身不会说法。所以古人说：身依义立，土据体论。法性身、法性土，明知是建立之法、依通的国土。空拳黄叶，用来哄小儿；蒺藜菱刺，在枯骨上找什么汁？心外无法，内也不可得，求什么东西？

你们诸方说：有修有证。莫错！即使有修得的，都是生死业。你说六度万行齐修，我看都是造业。求佛求法，就是造地狱业；求菩萨也是造业；看经看教也是造业。佛与祖师是无事人，所以有漏有为、无漏无为，都是清净业。

有一类瞎秃子，吃饱了饭，便坐禅观行，把捉念头，不让它起，厌喧求静，这是外道法。祖师说：你若住心看静，举心外照，摄心内澄，凝心入定，这一类都是造作。

是尔如今与么听法底人，作么生拟修他、证他、庄严他？渠且不是修底物，不是庄严得底物。

（大意：就是你如今这样听法的人，怎么打算去修他、证他、庄严他？他不是可修的东西，也不是可庄严的东西。）

若教他去庄严，一切东西都可以庄严了。你且莫错。

道流！你们把这一类老师口里的话当成真道，说：善知识不可思议，我是凡夫心，不敢测度那些老宿。瞎汉！你一生只作这种见解，辜负了这一双眼。冷噤噤地，如冻冰上的驴驹一样。还说：我不敢毁谤善知识，怕生口业。

道流！大善知识才敢毁佛毁祖，是非天下，排斥三藏教，骂辱诸小儿，在逆顺之中觅人。所以我在十二年中，求一个业性，像芥子那么一点也不可得。若像新媳妇一般的禅师，就怕被赶出院，不给饭吃，不安不乐。自古先辈，到处人都不信，被递送出去，才知是贵。若到处人都肯定，能作什么用？所以狮子一吼，野干脑裂。

道流！诸方说有道可修，有法可证。你说证什么法、修什么道？你如今用处欠少什么东西？要修补哪里？后生小阿师不会，便信这类野狐精魅，许他说事，系缚人，说什么理行相应、护惜三业，才得成佛。这样说的人，多如春天的细雨。古人说：路上遇到达道的人，第一不要对他说道。所以说：

```
若人修道道不行，万般邪境竞头生。
智剑出来无一物，明头未显暗头明。
```

（大意：若有人着意去修道，道反而行不通，种种邪境争先生起。智慧之剑一出，本无一物；明的一头还未显，暗的一头已经明了。）

所以古人说：平常心是道。大德！要觅什么东西？

现今目前听法无依道人，历历地分明，未曾欠少。

（大意：当下目前这个听法的无依道人，历历分明，从来不曾欠少。）

你若想与祖佛不别，只要这样见，不用疑误。你心心不异，名为活祖。心若有异，则性相分别；心不异故，性相不别。

有人问：如何是心心不异处？师说：你打算问，早已异了，性相各分了。道流莫错！世间与出世间诸法，都无自性，也无生性，只有空名，名字也空。你只管认那些闲名为实，大错了。即使有，都是依他变现之境：有个菩提依、涅槃依、解脱依、三身依、境智依、菩萨依、佛依。你向依他变现的国土中，觅什么东西？乃至三乘十二分教，都是擦不净的旧纸。佛是幻化身，祖是老比丘。你还是娘生的吗？你若求佛，就被佛魔所摄；你若求祖，就被祖魔所缚。你若有求，都是苦，不如无事。

有一类秃比丘对学人说：佛是究竟，在三大阿僧祇劫修行果满，才得成道。道流！你若说佛是究竟，为什么八十年后，在拘尸罗城双林树间侧卧而死去？佛如今在哪里？明知与我们生死不别。你说三十二相、八十种好是佛，转轮圣王也应是如来了。明知是幻化。古人说：

```
如来举身相，为顺世间情，恐人生断见，权且立虚名。
假言三十二，八十也空声。有身非觉体，无相乃真形。
```

（大意：如来示现身相，是为了随顺世间人情，怕人生起断见，暂且立个虚名。三十二相是假说，八十种好也是空声。有身并非觉体，无相才是真形。）

你说佛有六种神通，不可思议。一切诸天、神仙、阿修罗、大力鬼也有神通，难道也是佛吗？道流莫错！比如阿修罗与天帝释作战，战败了，带领八万四千眷属躲进藕丝孔中，莫非是圣人吗？像山僧所举的，都是业通、依通。佛的六通不是这样：入色界不被色惑，入声界不被声惑，入香界不被香惑，入味界不被味惑，入触界不被触惑，入法界不被法惑。所以通达色声香味触法六种都是空相，不能系缚这个无依道人。虽是五蕴有漏之身，便是地行神通。

道流！真佛无形，真法无相。你只在幻化上头作模作样，即使求得，都是野狐精魅，并不是真佛，是外道见解。真学道的人，并不取佛，不取菩萨罗汉，不取三界殊胜，迥然独脱，不与物拘。乾坤倒覆，我更不疑；十方诸佛现前，没有一念心喜；三涂地狱顿现，没有一念心怖。为什么这样？我见诸法空相：变即有，不变即无。三界唯心，万法唯识，所以梦幻空花，何劳把捉？

唯有道流目前现今听法的人，入火不烧，入水不溺，入三涂地狱如游园观，入饿鬼畜生而不受报。为什么这样？因为没有可以嫌弃的法。你若爱圣憎凡，就在生死海里沉浮。

烦恼由心故有，无心烦恼何拘。不劳分别取相，自然得道须臾。

（大意：烦恼因心而有，无心时烦恼又怎能拘束？不用分别取相，自然须臾之间得道。）

你打算到处奔波去学得，在三大阿僧祇劫中终归生死，不如无事，到丛林中床角头盘腿坐着。

道流！比如诸方有学人来，主客相见了，便有一句话，辨别前面的善知识。学人拈出个机权语路，向善知识嘴角边掷过去，看你识不识。你若识得是境，拿起便抛进坑里。学人便恢复平常，然后又讨善知识的话，善知识依前夺之。学人说：上智啊，真是大善知识！善知识便说：你太不识好恶了。

又如善知识拿出个境块子，在学人面前弄。前面的学人辨得，下下作主，不受境惑。善知识便现半身，学人便喝。善知识又入一切差别语路中摆弄，学人说：不识好恶的老秃奴！善知识赞叹说：真正道流。

像诸方的善知识不辨邪正，学人来问菩提涅槃、三身境智，瞎老师便给他解说；被学人骂了，便拿棒打他，说他无礼。这是你善知识没眼，不得怪他。有一类不识好恶的秃奴，就指东划西，说好晴好雨，说好灯笼露柱。你看眉毛还剩几根？这里头有机缘，学人不会，便即心狂。这一类都是野狐精魅魍魉，被好学人暗暗微笑，说：瞎老秃奴，惑乱天下人。

道流！出家儿且要学道。比如山僧，往日曾在毗尼中留心，也曾在经论中寻讨，后来才知道那是济世的药方、表显之说，于是一时抛却，就去访道参禅。后来遇到大善知识，才道眼分明，开始认识天下老和尚，知其邪正。这不是娘生下来就会，还是体究练磨，一朝自省。

道流！你想得如法见解，只是莫受人惑，向里向外，逢着便杀：

逢佛杀佛，逢祖杀祖，逢罗汉杀罗汉，逢父母杀父母，逢亲眷杀亲眷，始得解脱，不与物拘，透脱自在。

（大意：遇到佛就杀佛，遇到祖就杀祖，遇到罗汉就杀罗汉，遇到父母就杀父母，遇到亲眷就杀亲眷，这样才得解脱，不被外物拘系，透脱自在。所杀的，是对一切所依的执取。）

像诸方学道的人，没有不依物出来的。山僧在这里从头打：从手上出来，就在手上打；从口里出来，就在口里打；从眼里出来，就在眼里打。没有一个独脱出来的，都是攀上古人的闲机境。山僧无一法与人，只是治病解缚。你们诸方道流，试着不依物出来，我要与你商量。十年五年，没有一人，都是依草附叶的竹木精灵、野狐精魅，向一切粪块上乱咬。瞎汉！枉消了十方信施，说"我是出家儿"，却作这样的见解。我对你说：无佛，无法，无修，无证。你只管到处想求什么东西？瞎汉，头上安头！你欠少什么？

道流！是你目前用的这个，与祖佛不别。只是不信，便向外求。莫错！向外无法，内也不可得。你取山僧口里的话，不如休歇无事去。

已起者莫续，未起者不要放起，便胜尔十年行脚。

（大意：已经起来的念头不要接续，还没起来的不要放它起来，这就胜过你十年行脚。）

依山僧的见处，没有那么多种种，只是平常穿衣吃饭，无事过时。

你们从诸方来的人，都是有心：求佛求法，求解脱，求出离三界。痴人！你要出三界，到什么地方去？佛祖是赏系人的名句。你想认识三界吗？不离你如今听法的心地。你一念心贪是欲界，你一念心嗔是色界，你一念心痴是无色界，这是你屋里的家具。三界不会自己说"我是三界"，还是道流目前灵灵地照烛万般、酌度世界的人，给三界安了名字。

大德！四大色身是无常的，乃至脾胃肝胆、发毛爪齿，唯见诸法空相。你一念心歇得处，叫作菩提树；你一念心不能歇得处，叫作无明树。无明无住处，无明无始终。你若念念心歇不得，便上了无明树，便入六道四生，披毛戴角。你若歇得，便是清净身界。

尔一念不生，便是上菩提树。

（大意：你一念不生，就是上了菩提树。）

三界中神通变化，意生化身，法喜禅悦，身光自照；想衣服，罗绮千重；想饮食，百味具足；更无横病。菩提无住处，所以无得者。

道流！大丈夫汉还疑个什么？目前用处，更是谁？把得便用，莫着名字，这叫作玄旨。这样见得，就没有可以嫌弃的法。古人说：

```
心随万境转，转处实能幽。随流认得性，无喜亦无忧。
```

（大意：心随万境而转，转处实在幽深；在随流之中认得本性，便无喜也无忧。）

道流！像禅宗的见解，死活分明，参学的人大须仔细。比如主客相见，便有言论往来：或应物现形，或全体作用，或把机权喜怒，或现半身，或乘狮子，或乘象王。

如果有真正的学人，便喝，先拈出一个胶盆子来粘人。善知识不辨是境，便在那境上作模作样。学人便喝，前面的人却不肯放下，这是膏肓之病，无法医治，叫作"客看主"。

或者善知识不拈出东西，随学人问处便夺。学人被夺，抵死不放，这是"主看客"。

或者有学人，应一个清净境出现在善知识面前。善知识辨得是境，拿起抛向坑里。学人说：好个善知识！善知识便说：咄！不识好恶。学人便礼拜。这叫作"主看主"。

或者有学人，披枷带锁出现在善知识面前，善知识再给他加一重枷锁，学人欢喜，彼此不辨，叫作"客看客"。

大德！山僧这样所举的，都是辨魔拣异，知其邪正。

道流！实情很难，佛法幽玄，理解起来也还过得去。山僧整天给他们说破，学人全不在意，千遍万遍在脚底踏过，黑漆漆地，没有一个形段，历历孤明。学人信不及，便在名句上生解。年过半百，只管到处背着死尸走，挑着担子天下走，讨草鞋钱的日子总会到来。

大德！山僧说向外无法，学人不会，便向里作解，倚壁而坐，舌拄上腭，湛然不动，以此为祖门佛法。大错！你若取这不动的清净境为是，你就是认无明为主人。古人说：湛湛的黑暗深坑，实在可怖畏。就是这个。你若认那动的为是，一切草木都会动，应该也是道吧？所以动的是风大，不动的是地大，动与不动都无自性。你若向动处捉他，他向不动处立；你若向不动处捉他，他向动处立。譬如潜在泉中的鱼，鼓起波浪而自己跃出。大德！动与不动是两种境，还是无依道人在用动、用不动。

诸方学人来，山僧这里作三种根器的判断：如中下根器来，我便夺其境，而不除其法；或中上根器来，我便境法俱夺；如上上根器来，我便境、法、人俱不夺；如有出格见解的人来，山僧这里便全体作用，不经历根器。

大德！到这里，学人着力处不通风，石火电光，早已过了。学人若眼睛一动，便没交涉。

拟心即差，动念即乖。有人解者，不离目前。

（大意：一拟心就差了，一动念就乖了。能领会的人，不离目前。）

大德！你挑着钵囊屎担子，到处奔走求佛求法。如今这样驰求的，你还认识他吗？活泼泼地，只是没有根株，拥不聚，拨不散，求着就转远，不求还在目前，灵音在耳。若人不信，徒劳百年。

道流！一刹那间，便入华藏世界，入毗卢遮那国土，入解脱国土，入神通国土，入清净国土，入法界，入秽入净，入凡入圣，入饿鬼畜生，处处讨觅寻找，都不见有生有死，唯有空名。幻化空花，不劳把捉，得失是非，一时放却。

道流！山僧的佛法的的相承，从麻谷和尚、丹霞和尚、道一和尚、庐山和尚、拽石头和尚（石巩）而来，一路行遍天下，无人信得，尽皆起谤。

像道一和尚的用处，纯一无杂，学人三百五百，全都不见他的意旨。像庐山和尚，自在真正，顺逆用处，学人测不到边际，全都茫然。像丹霞和尚，玩珠隐显，来的学人都被骂。像麻谷的用处，苦如黄檗，近前都不得。像石巩的用处，向箭头上觅人，来的人都害怕。

像山僧今日的用处，真正成坏，玩弄神变，入一切境，随处无事，境不能换。只要有来求的，我便出来看他，他不识我。我便穿上几种衣服，学人生解，一向入我的言句。苦哉！瞎秃子、无眼人，拿我所穿的衣服，认青黄赤白。我脱掉衣服，入清净境中，学人一见，便生欣羡。我又脱掉，学人失心，茫然狂走，说"我无衣"。我就对他说：你认识我这个穿衣的人吗？他忽然回头，认得我了。

大德！你莫认衣。衣不能动，人能穿衣。有个清净衣，有个无生衣、菩提衣、涅槃衣，有祖衣，有佛衣。大德！只要有声名文句，都是衣的变化。从脐轮气海中鼓动，牙齿敲磕，成其句义，明知是幻化。大德！外面发出声语之业，内里表示心所之法，以思而有念，都是衣。你只管认他所穿的衣为实解，纵经尘劫，也只是通达了衣，三界循环，轮回生死。不如无事。相逢不相识，共语不知名。

如今学人不得力，是因为认名字为解。在大册子上抄死老汉的话，三重五重包裹起来，不让人看，说是玄旨，当宝贝保重。大错！瞎汉！你向枯骨上找什么汁？有一类不识好恶的人，在教中取意度商量，成其句义，如把屎块子含在口里，吐过去给别人，犹如俗人玩传口令的游戏一样，一生虚过。说"我出家"，被人问着佛法，便杜口无词，眼似漆黑的烟囱，口如扁担。这一类人，即使逢弥勒出世，也被移置他方世界，寄在地狱受苦。

大德！你奔波往诸方，要找什么东西？踏阔了你的脚板。没有佛可求，没有道可成，没有法可得。

```
外求有相佛，与汝不相似。欲识汝本心，非合亦非离。
```

（大意：向外求有相的佛，与你本来不相似；想认识你的本心，非合也非离。）

道流！真佛无形，真道无体，真法无相，三法混融，和合一处。辨既辨不得，叫作忙忙业识众生。
