# 为霖道霈《禅海十珍》（五）永嘉证道歌

## 第五珍　永嘉真觉禅师证道歌

《证道歌》全篇以七言为主，间以"三三七"句式。下面按意义单元分段，保留原文，后附大意。

君不见绝学无为闲道人，不除妄想不求真。无明实性即佛性，幻化空身即法身。法身觉了无一物，本源自性天真佛。五阴浮云空去来，三毒水泡虚出没。

（大意：你没看见那绝学无为的闲道人吗？他不除妄想，也不求真。无明的实性就是佛性，幻化的空身就是法身。觉了法身，本无一物，本源自性就是天真佛；五阴如浮云空自来去，三毒如水泡虚自出没。）

证实相，无人法，刹那灭却阿鼻业。若将妄语诳众生，自招拔舌尘沙劫。顿觉了，如来禅，六度万行体中圆。梦里明明有六趣，觉后空空无大千。

（大意：证得实相，就没有人与法，刹那间灭尽阿鼻地狱的业；我若以妄语欺骗众生，甘受尘沙劫拔舌之报。顿然觉了如来禅，六度万行都在本体中圆满；梦里明明有六道，醒后空空连大千世界也没有。）

无罪福，无损益，寂灭性中莫问觅。比来尘镜未曾磨，今日分明须剖晰。谁无念，谁无生，若实无生无不生。唤取机关木人问，求佛施功早晚成。

（大意：无罪无福，无损无益，在寂灭性中不要去寻觅；从前蒙尘的镜子未曾磨过，今天要分明剖析。谁是无念？谁是无生？若真是无生，就无所不生；叫来机关木人问问看，靠用功求佛，几时能成？）

放四大，莫把捉，寂灭性中随饮啄。诸行无常一切空，即是如来大圆觉。决定说，表真乘，有人不肯任情征。直截根源佛所印，摘叶寻枝我不能。

（大意：放下四大，不要把捉，在寂灭性中随缘饮食；诸行无常、一切皆空，就是如来的大圆觉。我决定地说，表的是真乘，有人不肯，任他来诘问；直截根源，是佛所印可的，摘叶寻枝的事我做不来。）

摩尼珠，人不识，如来藏里亲收得。六般神用空不空，一颗圆光色非色。净五眼，得五力，唯证乃知谁可测。镜里看形见不难，水中捉月争拈得。

（大意：摩尼宝珠，人都不识，我在如来藏里亲自收得；六根的神用，空而不空，一颗圆光，是色又非色。净五眼、得五力，唯有亲证才知，谁能测度？镜里看形不难，水中捉月怎拿得到？）

常独行，常独步，达者同游涅槃路。调古神清风自高，貌悴骨刚人不顾。穷释子，口称贫，实是身贫道不贫。贫则身常披缕褐，道即心藏无价珍。

（大意：常独行独步，通达的人同游涅槃之路；格调古朴、神情清澈，风骨自高，容貌憔悴、骨气刚硬，世人不屑一顾。穷释子口称贫，其实是身贫道不贫；贫则身披破衣，道则心藏无价之宝。）

无价珍，用无尽，利物应时终不吝。三身四智体中圆，八解六通心地印。上士一决一切了，中下多闻多不信。但自怀中解垢衣，谁能向外夸精进。

（大意：无价之宝用之无尽，利物应时从不吝惜；三身四智在本体中圆满，八解脱六神通是心地之印。上士一决断就一切了，中下根人闻得多却多不信；只管自己解开怀中的垢衣，谁还向外夸耀精进？）

从他谤，任他非，把火烧天徒自疲。我闻恰似饮甘露，销融顿入不思议。观恶言，是功德，此则成吾善知识。不因讪谤起怨亲，何表无生慈忍力。

（大意：任他毁谤非议，拿火烧天只是自己疲累；我听来恰似饮甘露，消融之间顿入不思议。把恶言看作功德，它就成了我的善知识；若不因讪谤而心无怨亲，又怎能显出无生的慈忍之力？）

宗亦通，说亦通，定慧圆明不滞空。非但我今独达了，河沙诸佛体皆同。师子吼，无畏说，百兽闻之皆脑裂。香象奔波失却威，天龙寂听生欣悦。

（大意：宗也通，说也通，定慧圆明而不滞于空；不但我今天独自通达，恒河沙数诸佛本体都相同。如狮子吼，无畏地说，百兽听了脑裂；香象奔逃失了威风，天龙静听而生欢喜。）

游江海，涉山川，寻师访道为参禅。自从认得曹溪路，了知生死不相干。行亦禅，坐亦禅，语默动静体安然。纵遇锋刀常坦坦，假饶毒药也闲闲。

（大意：游江海、涉山川，寻师访道为参禅；自从认得曹溪之路，才知生死与我不相干。行也是禅，坐也是禅，语默动静，本体安然；即使遇到刀锋也坦然，即使饮下毒药也悠闲。）

我师得见然灯佛，多劫曾为忍辱仙。几回生，几回死，生死悠悠无定止。自从顿悟了无生，于诸荣辱何忧喜。入深山，住兰若，岑崟幽邃长松下。优游静坐野僧家，阒寂安居实萧洒。

（大意：我师释迦得见燃灯佛，多劫曾作忍辱仙人。几回生、几回死，生死悠悠没有止境；自从顿悟无生，对荣辱还有什么忧喜？入深山，住兰若，在高峻幽深的长松之下，野僧优游静坐，寂静安居，实在潇洒。）

觉即了，不施功，一切有为法不同。住相布施生天福，犹如仰箭射虚空。势力尽，箭还坠，招得来生不如意。争似无为实相门，一超直入如来地。

（大意：觉了就完，不须施功，与一切有为法不同。住相布施只得生天之福，好比仰天射箭；力尽箭落，招得来生不如意。怎比得上无为实相之门，一超直入如来地？）

但得本，莫愁末，如净琉璃含宝月。既能解此如意珠，自利利他终不竭。江月照，松风吹，永夜清宵何所为。佛性戒珠心地印，雾露云霞体上衣。

（大意：只要得了根本，不愁枝末，如净琉璃含着宝月；既能解得这如意珠，自利利他终不穷竭。江月照，松风吹，长夜清宵做什么？佛性戒珠是心地之印，雾露云霞是身上之衣。）

降龙钵，解虎锡，两股金环鸣历历。不是标形虚事持，如来宝杖亲踪迹。不求真，不断妄，了知二法空无相。无相无空无不空，即是如来真实相。

（大意：降龙的钵，解虎斗的锡杖，两股金环历历作响；不是为了标榜外形而空拿着，是如来宝杖的亲传踪迹。不求真，不断妄，了知真妄二法空无相；无相、无空、无不空，就是如来的真实相。）

心镜明，鉴无碍，廓然莹彻周沙界。万象森罗影现中，一颗圆明非内外。豁达空，拨因果，漭漭荡荡招殃祸。弃有著空病亦然，还如避溺而投火。

（大意：心镜明亮，照见无碍，廓然莹彻，周遍沙界；森罗万象在其中现影，一颗圆明，不属内外。若执豁达空，拨无因果，就茫茫荡荡招致殃祸；弃有著空，病也一样，好比避开溺水却投入火中。）

舍妄心，取真理，取舍之心成巧伪。学人不了用修行，真成认贼将为子。损法财，灭功德，莫不由斯心意识。是以禅门了却心，顿入无生知见力。

（大意：舍妄心、取真理，这取舍之心就成了巧伪；学人不了这一点而用功修行，真是认贼作子。损法财、灭功德，无不由这心意识；所以禅门了却此心，顿入无生的知见之力。）

大丈夫，秉慧剑，般若锋兮金刚焰。非但能摧外道心，早曾落却天魔胆。震法雷，击法鼓，布慈云兮洒甘露。龙象蹴踏润无边，三乘五性皆惺悟。

（大意：大丈夫手持慧剑，般若为锋，金刚为焰；不但能摧外道之心，早已吓破天魔之胆。震法雷、击法鼓，布慈云、洒甘露，龙象蹴踏，润泽无边，三乘五性都得醒悟。）

雪山肥腻更无杂，纯出醍醐我常纳。一性圆通一切性，一法遍含一切法。一月普现一切水，一切水月一月摄。诸佛法身入我性，我性还共如来合。

（大意：雪山的肥腻草毫无杂质，纯出醍醐，我常受用。一性圆通一切性，一法遍含一切法；一月普现于一切水，一切水中之月都摄于一月；诸佛法身入我本性，我性又与如来相合。）

一地具足一切地，非色非心非行业。弹指圆成八万门，刹那灭却三祇劫。一切数句非数句，与吾灵觉何交涉。不可毁，不可赞，体若虚空勿涯岸。不离当处常湛然，觅则知君不可见。

（大意：一地具足一切地，非色非心非行业；弹指间圆成八万法门，刹那间灭尽三大阿僧祇劫。一切名数言句都非名数言句，与我灵觉有什么相干？不可毁，不可赞，本体如虚空没有边际；不离当处，常自湛然，一去寻觅，就知你见不着。）

取不得，舍不得，不可得中只么得。默时说，说时默，大施门开无壅塞。有人问我解何宗，报道摩诃般若力。或是或非人不识，逆行顺行天莫测。吾早曾经多劫修，不是等闲相诳惑。

（大意：取不得，舍不得，在不可得中就这样得了。默时就是说，说时就是默，大布施之门敞开，毫无壅塞。有人问我解什么宗，我答是摩诃般若之力；或是或非，人们不识，逆行顺行，天也莫测；我早已历经多劫修行，不是随便诳惑人的。）

建法幢，立宗旨，明明佛敕曹溪是。第一迦叶首传灯，二十八代西天记。法东流，入此土，菩提达磨为初祖。六代传衣天下闻，后人得道无穷数。

（大意：建法幢，立宗旨，明明是佛所敕、曹溪所传。第一代迦叶首先传灯，西天记有二十八代；法流东土，菩提达磨为初祖，六代传衣天下闻名，后人得道的无数。）

真不立，妄本空，有无俱遣不空空。二十空门元不著，一性如来体自同。心是根，法是尘，两种犹如镜上痕。痕垢尽除光始现，心法双亡性即真。

（大意：真不立，妄本空，有无都遣除，连不空之空也遣除；二十空门原不执著，一性与如来本体自然相同。心是根，法是尘，两者都如镜上的痕迹；痕垢除尽，光才显现，心法双亡，本性即真。）

嗟末法，恶时世，众生福薄难调制。去圣远兮邪见深，魔强法弱多怨害。闻说如来顿教门，恨不灭除令瓦碎。作在心，殃在身，不须怨诉更尤人。欲得不招无间业，莫谤如来正法轮。

（大意：可叹末法恶世，众生福薄难以调伏；离圣人远了，邪见深重，魔强法弱，多有怨害。听说如来顿教法门，恨不得把它砸成瓦片。造作在心，祸殃在身，不必怨天尤人；要不招无间地狱之业，就不要毁谤如来正法轮。）

栴檀林，无杂树，郁密深沉师子住。境静林闲独自游，走兽飞禽皆远去。师子儿，众随后，三岁即能大哮吼。若是野干逐法王，百年妖怪虚开口。

（大意：栴檀林中无杂树，郁密深沉，狮子居住；境静林闲独自游行，走兽飞禽都远远避开。狮子儿随群在后，三岁就能大声哮吼；若是野狐追随法王，百年妖怪也只是空张口。）

圆顿教，勿人情，有疑不决直须争。不是山僧逞人我，修行恐落断常坑。非不非，是不是，差之毫厘失千里。是即龙女顿成佛，非即善星生陷坠。

（大意：圆顿之教，不讲人情，有疑不决，就要直下辩明；不是山僧逞人我之见，是怕修行人落入断常之坑。非与不非，是与不是，差之毫厘，失之千里；是，则龙女顿时成佛；非，则善星比丘生身陷入地狱。）

吾早年来积学问，亦曾讨疏寻经论。分别名相不知休，入海算沙徒自困。却被如来苦诃责，数他珍宝有何益。从来蹭蹬觉虚行，多年枉作风尘客。

（大意：我早年积累学问，也曾讨寻疏钞经论；分别名相不知休止，入海算沙，徒然自困。却被如来痛加诃责：数别人的珍宝有什么用？回想从前蹉跎，觉得白走了路，多年枉作风尘之客。）

种性邪，错知解，不达如来圆顿制。二乘精进勿道心，外道聪明无智慧。亦愚痴，亦小騃，空拳指上生实解。执指为月枉施功，根境法中虚捏怪。不见一法即如来，方得名为观自在。

（大意：种性邪了，知解就错，不通达如来圆顿的法度；二乘精进却无道心，外道聪明却无智慧。又愚痴又幼稚，在空拳和指头上生出实解；执指为月，枉费功夫，在根境法中虚自捏造怪事。不见一法，就是如来，才可名为观自在。）

了即业障本来空，未了还须偿宿债。饥逢王膳不能餐，病遇医王争得差。在欲行禅知见力，火中生莲终不坏。勇施犯重悟无生，早时成佛于今在。

（大意：了悟时，业障本来是空；未了时，还须偿还宿债。饿了遇到王者的膳食却不能吃，病了遇到医王又怎能痊愈？在欲中行禅，靠的是知见之力，如火中生莲终不坏灭；勇施比丘犯了重戒而悟无生，早已成佛，至今犹在。）

师子吼，无畏说，深嗟懵懂顽皮靼。只知犯重障菩提，不见如来开秘诀。有二比丘犯淫杀，波离萤光增罪结。维摩大士顿除疑，还同赫日销霜雪。

（大意：狮子吼，无畏说，深叹那些懵懂如顽皮的人，只知犯重戒障碍菩提，不见如来开示的秘诀。有两位比丘犯了淫杀，优波离以萤火般的小智反而增加他们的罪结；维摩大士顿时为他们除去疑悔，如同烈日消融霜雪。）

不思议，解脱力，妙用恒沙也无极。四事供养敢辞劳，万两黄金亦销得。粉骨碎身未足酬，一句了然超百亿。

（大意：不思议的解脱之力，妙用如恒沙无穷无尽；四事供养岂敢辞劳，万两黄金也受得起；粉骨碎身也不足以报答，一句了然，超过百亿。）

法中王，最高胜，河沙如来同共证。我今解此如意珠，信受之者皆相应。了了见，无一物，亦无人，亦无佛。大千沙界海中沤，一切圣贤如电拂。

（大意：这法中之王，最为高胜，恒河沙数如来共同证得；我今解得这如意珠，信受的人都能相应。了了分明地见，无一物，也无人，也无佛；大千沙界如海中水泡，一切圣贤如电光一闪。）

假使铁轮顶上旋，定慧圆明终不失。日可冷，月可热，众魔不能坏真说。象驾峥嵘谩进途，谁见螳螂能拒辙。大象不游于兔径，大悟不拘于小节。莫将管见谤苍苍，未了吾今为君诀。

（大意：即使烧红的铁轮在头顶旋转，定慧圆明终不失去；太阳可以变冷，月亮可以变热，众魔不能破坏真实之说。大象驾车，巍然前进，谁见过螳螂能挡住车轮？大象不走兔子的小路，大悟不拘于小节；不要以管窥之见去毁谤苍天，你若未了，我今天为你决断。）

## 道霈论曰

永嘉真觉禅师童年出家，遍探三藏，精通天台圆妙法门，在行住坐卧四威仪中常冥合于禅观。因读《维摩诘经》廓然大悟，于是到曹溪印定宗旨。看他振锡绕祖、回答六祖的几句话，只在寻常应对之间，就直超格外，深入堂奥，六祖怎能不深深印可？仅留住一夜，当时号称"一宿觉"，不是虚名。

他于是作《证道歌》一首，发明禅宗教外别传之道，拣去权浅之病，都是从自证的心中流出。其摧邪显正，如出匣的镆铘宝剑，光芒烛天，势不可犯，自有宗门以来，仅见此一篇。

我因此想到，古今得道的人很多，就像大海之水，阿修罗以及鱼龙虾蟹，任其所饮，各满其量而已；至于永嘉，可以说是掀翻大海，倾竭无余，真是禅关的枢要、别传的显诀。此歌传到西天，当地人共同赞美，称为《证道经》，并非虚言。
