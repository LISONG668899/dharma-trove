# 永明延寿《宗镜录》自序

慧日永明寺主智觉禅师延寿 撰

众生本有的真实源头，是湛然寂静的；觉悟的大海，本来澄明清净。它超越了一切名称和概念，没有能认识和所认识的分别痕迹。

可是众生在最初的一念之间，忽然不觉而妄动了心念。这就成为业识（因业力而生的分别心识）生起的源头，也是"觉明为咎"（《楞严经》说的：本来觉性光明，却因一念妄动，明觉反而成为过失）的开始。

因为有了能明之心，就产生了能照的作用，于是"见分"（能认识的心）立刻兴起；随着能照的功能建立，"相分"（所认识的境界）也跟着布列。就像镜子中显现影像一样，我们的身体（根身）顿时现前。接着，随着妄想分别，世界就呈现出种种差别；再因为有了执取的心智，爱憎之情就各不相同了。

从此以后，众生就遗失了真性、迷失了本心，执着于名相、追逐于虚妄。情执的尘垢越积越厚，分别识心的波浪相续不断。真正的觉性被锁在无明的梦夜之中，众生沉迷在三界（欲界、色界、无色界）的轮回里；智慧之眼被昏暗遮蔽，在九类众生（胎、卵、湿、化等十二类生的另一种归纳）中匍匐流转。

于是被业力绳索捆绑，承受种种痛苦；解脱之门，完全迷失了。在本来无身之处，妄受身形；在本来无趣（六道）之处，妄立诸道。就依止的环境来说，分成了二十五有（三界中的二十五种生存状态）；就正报身相来说，具有十二类生（胎生、卵生、湿生、化生等十二种生命形态）。这一切，都是因为情想的缘故，才导致依报（生存环境）和正报（身心）的种种差别。

在本来不变的境界上，却虚妄地承受轮回；在本来没有束缚的法中，自己给自己制造枷锁。就像春天的蚕吐丝作茧把自己裹住，像秋天的飞蛾扑火把自己烧死一样。用"二见"（我见和我所见，或常见和断见）和妄想织成的丝线，把自己缠绕在苦聚（五蕴和合的苦报身）的业质上；用无明和贪爱长出的翅膀，扑向生死轮回的火轮。用虚幻如山谷回响的言语声音，谈论四生（胎、卵、湿、化四种出生方式）众生的美丑；用妄想心当作镜子，映现出三有（欲有、色有、无色有，即三界）的种种形相。

然后，顺境逆境的分别念像风一样吹动觉性的大海；贪心、痴心、爱欲像水一样滋润痛苦的种子。一直向外追逐尘境，不知道回归根本。发起颠倒错乱的知见，遮蔽了自己的真心；建立起虚幻不实的色相声音，误以为是心外的实法。

从此，一粒微尘沾染上境界，就渐渐堆积成高耸入云的山峰；一滴水兴起波浪，最终也会掀起吞没大船的巨浪。

此后，若想返本还原、回归觉性，就因为众生根机有利有钝的差别，所以在一真法界当中，开演出三乘（声闻、缘觉、菩萨）和五性（定性声闻、定性缘觉、定性菩萨、不定种性、无种性）的不同：有的通过证悟空性而得果，有的通过了达因缘而入真；有的需要三大阿僧祇劫（无量劫）的熏修磨炼，逐渐具足各种修行法门；有的只需一念圆修，便顿时成就佛道。

由此可见：证悟的方式虽然有差异，但所证的一心本性并没有分别。只是因为修证的不同，才成立了"凡夫"和"圣者"的名字，似乎有了"真"和"俗"的相貌区分。

如果要穷究最幽微处、洞达最根本处、究竟宗旨、通达源头，那么——根本之性本来空寂，毕竟寂灭。没有上升和沉沦的差异，没有系缚和解脱的分别。既没有住在世间的人，也没有入于涅槃的人。二边平等，一道清虚。识和智都空了，名和体都寂了。什么都没有，只是一个真心。能够通达它的人，叫做"见道之人"；迷昧不知它的人，就是生死轮回的开始。

另外还有外道邪见的人和小乘权教的修行人，他们不了解生死痛苦的病根在哪里，不知道人我执见的源头是什么。他们只想躲避喧闹、排斥动相，破除名相、分析微尘，虽然自以为品味到了寂静、融入了虚空，却不知道这样做其实是在埋没真性、拒绝觉悟。

这就好比不去找眼睛里的"翳病"（眼病，比喻无明），只想灭掉灯上看到的"重光"（眼有病时看灯会看到双重光影）；不去穷究心识里那个如幻的身体，却空自躲避太阳下的影子。这样劳心费力、白费功夫，跟用水帮助结冰、往火里添柴有什么区别呢？

要知道：重光是因为眼病才有的，虚影是跟着幻身才生的——治好眼病，重光自然消失；灭掉幻身，虚影自然不见。

如果能够回光返照、反观自心，那么佛眼就会明亮而业障的影子全都空掉，法身就会显现而尘世的痕迹彻底断绝。用自己觉悟的智慧之刃，剖开缠绕在里面的心珠（本具的觉性如宝珠，被烦恼缠绕住了）；用当下一念的慧锋，斩断尘境中的执见之网。

这正是穷究心源的要旨，通达识性的关键。话虽然说得简略，道理却很丰富；文辞虽然质朴，义理却很精深。打开通向正智之门的疑关，铲除真觉源头的妄想杂草。治愈深入骨髓的顽疾，截断根深蒂固的执着。

于是，物和我遇到智慧之火的光焰，就融化在"唯心"这个大熔炉里；名相遭遇慧日的光明，就消融在"一真"这个大海中。

这是内证的境界，哪里是文字语言所能表达的呢？思维分析无法穷尽它，见闻觉知无法触及它。

现在是为那些还没有见道的人，演说那"无见之妙见"（不用眼睛见的真正的见）；为那些还没有闻法的人，引入那"不闻之圆闻"（不用耳朵闻的真正的闻）；为那些还没有了知的人，宣说那"无知之真知"（不用分别心知的真正的知）；为那些还没有解悟的人，成就那"无解之大解"（超越理解的真正的悟）。

所期望的是：通过手指看到月亮（"因指见月"，比喻借助言教悟入真理），捉到兔子就忘掉捕兔的网（"得兔忘蹄"，比喻得到真义就不再执着文字）；抱持一心、冥契宗旨；放下言语、直契义理。明白万事万物都是由自己的心显现的，了悟妙觉（圆满的觉悟）就在自己身上。

可以说：搜寻挖掘玄妙的根源，磨砺开发义理的宝藏；挑出禅宗的骨髓精华，标明教理的纲领要目。残余的疑惑、细微的瑕疵，一经触碰就圆满清净了；深奥的宗旨、微妙的义理，一经举念就全部彰显了。能够摧毁"七慢"（七种傲慢心）堆成的大山，永远堵塞"六衰"（六根门头能令人衰损堕落的境界）的道路。世间烦恼和外道邪见，全都听从指挥；生死魔军，完全消失无踪。显示大自在的力量，宣扬大威德的光明；呈示真实的宝珠，取用无穷无尽；倾倒秘密的宝藏，救济众生何曾有限！

可以说：在各种香中，这是焚烧牛头旃檀（最名贵的檀香）；在各种宝中，这是探取骊龙颔下的明珠（传说龙颔下有宝珠）；在各种花中，这是采摘灵瑞的奇葩；在各种光明中，这是神妙的光耀；在各种饮食中，这是品尝乳糜（《涅槃经》说的最上美食）；在各种水中，这是饮用甘露；在各种药中，这是服用九转金丹（道家说的最灵验的仙丹）；在各种君主中，这是遇到圣王。

所以法性这座山高耸起来，一下子就让其他群峰都落下去了；醍醐（佛法最上乘法的比喻）这片海广阔起来，一下子就吞纳了众多河流的波浪。就像夜晚的明月升起光辉，比下去了小乘的星星点点；就像早晨的太阳绽放光彩，驱散了外道的昏暗蒙昧。

又好比贫穷缺乏法财的人，遇到了大宝藏；渴求甘露的人，来到了清凉池。成为众生所敬仰的天中天，作为菩萨们真慈的大父。抱着膏肓之疾（难治的重病），遇到了善见药王（传说中的名医）；迷失在危险难行的路上，遇到了明白通达的好向导。长久住在黑暗的屋子里，忽然见到了宝炬的光明；一直处于赤身裸体的状态，顿时获得了天衣的妙服。不用去求就自然得到，不用费力就顿时成就。

所以要知道：无量无边的国土中，很难听到这个法门的名字；恒河沙数的劫数里，很少有人能够传持这个教法。因为上面所说的这些因缘，所以把这部书命名为"心镜"——显现出一条清虚可鉴的道路，辟除一切邪见而毫发不容。它的微妙本体没有偏私，圆满的光明不在心外。无边的义海，都在它的观照之中；万象的形容，全部进入它的照临之内。

这正是六祖曹溪惠能大师一味之旨、历代祖师共同传授的法门；这也是释迦如来在鹄林（拘尸那城的娑罗双树林，佛涅槃处）所说的不二之宗、众多经典共同叙述的道理。可以说是：万善的渊府（深广的府库），众圣的玄源（玄妙的根源），"一字"（一心）的宝王，群灵的元祖。

因此，心外所求的境界，它的文辞和道理都是虚妄的；心识所现的一切，才有考察的依据。一心这个"海印三昧"（大海能印现万象的三昧），可以衡定圆顿的宗旨；八识（眼、耳、鼻、舌、身、意、末那、阿赖耶八种心识）这盏智慧之灯，能够照破邪见的昏暗。

实在可以说：这是一切有情的灵府，万法的义宗。它变化无穷，收放自如。随着因缘而显现踪迹，随着事物而安立名称。

诸佛体证了它，就叫做"三菩提"（正觉）；菩萨修行它，就叫做"六度行"（布施、持戒、忍辱、精进、禅定、智慧）。海慧菩萨变化它而成为水；龙女献持它而成为宝珠（《法华经》龙女献珠成佛的故事）。天女散布它而成为不著的花（《维摩经》天女散花的故事）；善财童子寻求它而成为如意宝（《华严经》善财童子五十三参的故事）。缘觉悟入它而成为十二因缘，声闻证得它而成为四谛人空（声闻证得四谛而了知人我本空）。外道执取它而成为邪见之河，凡夫执着它而成为生死之海。

论它的本体，则微妙契合究竟的真理；论它的事相，则深刻符合正确的因缘。然而，虽然标示了法界的总门，但还必须辨明一乘的别旨。种种性相的义理，只有在大觉（佛）的境界才能圆融通达；重重无尽的法门，只有具足一切种智（佛的智慧）才能微妙透彻。

但是因为众生的根机羸弱，难以观照；学问浅薄，难以周遍。不知道"性门"和"相门"正是自己这颗心的"体"和"用"。如果只有用而失去了恒常的体，就像没有水却有波浪一样荒谬；如果得到了体却缺少妙用之门，就像没有波浪的死水一样偏枯。然而，从来没有无波的水，也从来没有不湿的波。波能彻达水的源头，水能穷尽波的末端；就像性能穷尽于相的表面，相能通达于性的根源。必须知道：体和用是相辅相成的，性和相是互相显发的。

现在就细致地说明总相和别相，广泛地辨别相同和差异。研究每一法的根源，搜寻一切缘的本末。这样就可以称为"宗镜"了，用它来鉴照幽微的道理。没有一法能够逃出它的照鉴，那么千差万别的事相就都能普遍会归了。

于是我编排收罗了广博的义理，节录撮取了精要的文句。展开来铺陈在一百卷之中，收卷来归摄在一心之内。能够让难以思议的教海，在指掌之间念念圆明；无穷无尽的真宗，在目睹之时心心契合。就像神珠在手，永远不用再向外寻求；就像觉树垂下荫凉，一切虚妄的影迹全都消失。在春天的池塘里获得真宝，砾石瓦砾就浑然不见了；在古镜面前找回了本来面目，狂乱的心就顿时止息了。

可以深深挑出知见的刺，永远截断疑惑的根。不用运作一毫的功夫，就完全打开宝藏；不用耗费刹那的力气，就顿时获得玄珠。这就叫做"一乘大寂灭场，真阿兰若正修行处"（《法华经》语，真正寂静的道场）。这是如来亲自到达的境界，诸佛本来安住的法门。

因此普遍劝勉后来的贤者，仔细地观览体会。这样就能让智慧穷尽性海，让学问洞达真源。

这个"识"、这个"心"，是最尊贵、最殊胜的——

- 说"此识"，是十方诸佛所证悟的；
- 说"此心"，是如来一代时教所诠释的；
- 说"唯尊"，是教、理、行、果所归向的；
- 说"唯胜"，是信、解、证、入所趋赴的。

历代贤者依据它来解释，所以论述有千章之多；诸位圣者体悟它来弘扬，所以辩才成就四无碍（法、义、辞、乐说四种无碍辩才）。

所以我采集奇妙、提举殊异，研究精微、洞察幽深。独自举起宏大的纲领，大大张开正确的法网。打捞五乘（人、天、声闻、缘觉、菩萨）根机的大地，升腾到第一义谛的天空。广泛地证明这个宗旨，利益众生没有穷尽。

于是正法能够久住于世，摧毁外道的邪见丛林；能够广泛济度众生，堵塞小乘的错乱车辙。这样，没有邪见不被纠正，没有虚伪不被空掉。因为自利的缘故，开发出智德的源头；因为利他的缘故，建立起恩德的事业。成就智德的缘故，慈心就能兴起无缘大慈的教化；成就恩德的缘故，悲心就能包含同体大悲的心怀。因为同体的缘故，心虽起而实无心；因为无缘的缘故，化虽成而成大化。心起无心的缘故，有什么快乐不愿给予众生呢？化成大化的缘故，有什么痛苦不愿代众生承受呢？什么快乐都愿意给，所以利根钝根平等看待；什么痛苦都愿意收，所以怨家亲人普遍救度。

于是"三草二木"（《法华经》比喻五乘众生如大中小三草、大小二木），都归于一地的荣养（同一大地的滋养）；邪种焦芽（比喻外道和小乘定性），也同沾一雨的滋润。这真是尽善尽美，无与伦比。可以说是：总括尽了因地的法门，搜寻穷了果海的境界。

所以那些刚刚发菩提心的人、刚刚寻求般若智慧的人，了解了成佛的来龙去脉，就能顿时圆满而没有滞碍；明白了回归本性的道路，就能直接前进而不再怀疑。

如果离开这个宗旨另外去修，跟随别人的错误见解，就像磨牛角想取牛奶、爬树想捉鱼一样（"构角取乳、缘木求鱼"，比喻方法完全错误），即使经历三大阿僧祇劫，最终也一无所得。

如果依照这个宗旨，信受奉持，就像快船顺流而下，没有任何阻碍，又遇到顺风相助，再加上奋力划桨，那就能很快到达宝城（比喻佛果），忽然登上觉悟的彼岸。可以说是：资粮容易办好，道果率先成就。穿上迦叶尊者传承的衣（禅宗传法的信物），坐上释迦如来法空的座，登上弥勒菩萨毗卢遮那佛的楼阁（《华严经》善财童子参访弥勒菩萨的故事），进入普贤菩萨遍一切处的法身。

能够让打工的贱人，完全继承长者的家业（《法华经》穷子喻）；能够让沉滞于空理的小果声闻，顿时获得如来的授记。没有一个法门不通向这个道，也没有一法不契合这个宗。过去的诸佛，因为这个而成佛；未来的菩萨，依靠这个而证真。那么，有哪一个法门不能打开呢？有哪一个义理不能显现呢？

没有一种色法不是"三摩钵地"（正定），没有一种声音不是"陀罗尼门"（总持法门）。尝一滴水就能遍尝醍醐的味道，闻一缕香就能全部进入法界。风吹的树枝、月照的水洲，都可以传达心法；烟雾缭绕的岛屿、云气笼罩的树林，都能提示妙旨。步步都踏在金色的境界上，念念都嗅着薝卜花（栀子花，常用来比喻佛法的清香）的芬芳。捧一掬沧海之水就已经得到了百川的滋味，登上须弥山顶就看到一切都同一颜色。

眼睛豁然开朗，好像"众盲摸象"（《涅槃经》的比喻）的盲人忽然睁开眼睛看到了真象，完全恢复了自己本来的宗旨；心念寂然回归，好像寻找宝珠的人（"衣里明珠"的比喻）忽然发现珠子就在自己衣服里，一切都回归了本来的法性。

于是邪见的高山坍塌了，苦海的波涛平息了。智慧的船桨因此而安稳地航行，妙觉的高峰因此而巍然耸立。

现在详细考察祖师和佛陀的根本用意，以及经典和论著的正确宗旨。删除繁杂的文字，只采集精要的旨趣。借助设问和回答的形式，广泛引用证据加以说明。以一心为宗旨，照见万法如同明镜。 编排联结古圣先贤著作的深义，节录概括三藏宝典的圆满诠释。共同来显扬这个道理，所以称之为"录"。

全书分为一百卷，大致有三个部分：

- 第一，标宗章：首先树立正宗，作为归趣；
- 第二，问答章：其次展开问答，用来消除疑惑；
- 第三，引证章：最后引用圣言，成就圆满的信心。

以这样的微妙善法，普遍布施给一切众生，共同报答佛陀的恩德。愿此宗旨永远流传！
