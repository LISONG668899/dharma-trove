# 憨山《观楞伽经记》（五）八识因缘与破外道异因

## 二识展转为因

【经文】大慧，现识及分别事识，此二坏不坏相展转因。

【憨山记】这是解释八识生起之相，以显示本来没有两个本体。"展转因"，是说前七转识与第八识互相为因：由前七识的现行熏成种子，而第八识中的种子又熏起现行。所以《成唯识论》说：「诸法于藏识，识于法亦尔，更互为因性，亦常为果性」（大意：诸法对于藏识，藏识对于诸法，都是这样，互相为因，也常互相为果）。可坏的是妄识，不可坏的是真识。魏译作："彼二种识无差别，递共为因。"唐译作："此二识无异，相互为因。"

## 现识之因：不思议熏变

【经文】大慧！不思议熏及不思议变，是现识因。

【憨山记】这是特别说明第八识生起之因，以阐明前面两种生中的流注生，显示三细相。"不思议熏变是现识因"，是无明熏习真如，成为八识之因，这就是所谓流注生。

《起信论》说："以依真如法故，有于无明，为诸染因。"这相当于业相。"以有无明染法因故，即熏习真如；以熏习故，则有妄心；以有妄心，即熏习无明。"这相当于转相。"不了真如法故，不觉念起，现妄境界。"这相当于现相。这就是因无明熏习之力，令真如变为现识，正是无明不觉而生三细。

所谓"不思议熏变"：真如本来不可熏而被熏，所以名为不思议熏；真如之体本自不变，而如今随无明之缘而成就种种法，所以称为不思议变。魏译作"了别识不可思议熏变因"，唐译作"现识以不思议熏变为因"。只因三细之相隐微，所以用不思议熏变来解释流注生。

## 分别事识之因

【经文】大慧，取种种尘及无始妄想熏，是分别事识因。

【憨山记】这是说明前七转识生起之因，以阐明相生，显示六粗相。《起信论》说：「以有妄境界染法缘故，即熏习妄心，令其念著，造种种业，受于一切身心等苦」（大意：因为有虚妄境界这一染法之缘，就熏习妄心，使它念念执著，造作种种业，承受一切身心等苦）。这正是六粗相。

"取种种尘及无始妄想熏"，是指妄想习气种子，即第八识所藏的种子，由此熏起前七识的根与境的现行，又把它们执取为实我实法，所以说"取种种尘及无始妄想熏"。这就是第八识与前七识互为因，即所谓相生。然而"妄想熏"又是相生中的流注生。所以《起信论》说：「无明熏习义有二种：一者根本熏习，以能成就业识义故；二者所起见爱熏习，以能成就分别事识义故」（大意：无明熏习有两种：一是根本熏习，能成就业识；二是由此所起的见爱熏习，能成就分别事识）。前面的不思议熏是根本熏习，这里则是见爱熏习。

## 相灭

【经文】大慧！若覆彼真识种种不实诸虚妄灭，则一切根识灭，是名相灭。

【憨山记】这是解释前面两种灭中的相灭。"覆"是返的意思，就是返流全一，顿契真如，那么一切尘垢当下销亡，根、尘、识、心应时脱落，这名为相灭。唐译作："阿赖耶识虚妄分别种种习气灭，即一切根识灭，是名相灭。"生起时是从细到粗，所以先有流注生；如今灭时是从粗到细，所以先说相灭。

## 相续灭

【经文】大慧，相续灭者，相续所因灭则相续灭，所从灭及所缘灭则相续灭。大慧，所以者何？是其所依故。依者，谓无始妄想熏；缘者，谓自心见等识境妄想。

【憨山记】这是解释前面两种灭中的流注灭。"相续"就是流注的意思。第八识本来湛然如深渊，没有生灭，只因前七识之风鼓动熏习成种，才有生灭。这生灭既然因前七转识而生，如今所因的前七识灭了，这流注相续自然就灭了，所以说"相续所因灭则相续灭"。这是解释流注生灭中的流注灭。

"所从灭及所缘灭则相续灭"，是解释相生灭中的流注灭。第七转识本来没有生灭，只因内有根本无始无明习气的熏习，外有六尘境界之风吹动，心海内外交扇，所以起七识的波浪。如今内门所从的无明既然灭了，外门的境界之风就停息，心体湛然如渊，波浪自然平息，七识当下就无生了。所从与所缘既灭，相续随即就灭，是因为一切动相都依无明而起，所以解释说"是其所依故"。

"依"，是无始妄想熏习。无始妄想就是根本无明，也就是现在所说的七识结生相续，因此熏习第八识，使第八识不能转成智慧，常在缠缚之中。"缘"，是指自心见等识境妄想，也就是根身器界。根身器界本是第八识所变的相分，又成为第八识见分所缘的境界，这正是《成唯识论》所说的因缘依。

如今说相续所因灭，则生灭之情消亡；所缘灭，则根尘自然泯除。这样，第八识的无明，宛然就是平等如如、不生灭的正智了。所以《起信论》说：「唯痴灭故，心相随灭」（大意：只要愚痴灭了，心的种种相随之而灭）。前面生起时是互相生起，如今灭时也是互相灭除。

以上以法显示真唯识量完毕。以下以比喻成立，预先破除二见。

## 泥团微尘之喻

【经文】大慧，譬如泥团、微尘非异非不异，金庄严具亦复如是。大慧，若泥团、微尘异者，非彼所成而实彼成，是故不异；若不异者，则泥团、微尘应无分别。

【憨山记】这是以比喻成立前面的真唯识量，并预先破除外道一异、断常二见的执著。"譬如泥团微尘"，正是显示不生不灭与生灭和合，成为第八阿赖耶识，以显示真与妄非一非异，也显示圣凡之相也是这样，所以又以金与庄严具来比喻。因为那些外道另立异因，为了破他们的见解，所以用这个比喻来开示。

【经文】如是，大慧，转识、藏识真相若异者，藏识非因。

【憨山记】这是正式解释"不异"，以破外道妄执另有一法作为生因。意思是：前七识与第八识若是异体，第八识就不应该作前七识的生起之因；如今既然是前七识的因，就知道不异。因为前七识的真相，原本就是第八识的精明之体；第八识的真相，原本就是真如。所以魏、唐二译只有"转识、藏识"，没有"真相"二字。

那两种译本只说八识不异，而此译加上"真相"二字，要阐明真与妄不异，从而显示妄即是真，所以此译的义理自足。"真相"就是第八识的自体，即本觉真如。现在说藏识为因，是说如来藏不仅是生死之因，也是涅槃之因。后文说："如来之藏是善不善因，能遍兴造一切趣生。"

【经文】若不异者，转识灭，藏识亦应灭，而自真相实不灭。是故，大慧，非自真相识灭，但业相灭；若自真相识灭者，藏识则灭。大慧，藏识灭者，不异外道断见论议。

【憨山记】这是解释"不一"，以破外道的断灭见。意思是：若八识是一体，那么前七识灭时，第八藏识也应当灭；藏识若灭，谁来证无生？所以八识只是灭除戏论和虚妄习气，才叫做灭，其实八识的自体本觉真如，真实不灭。所以说"非自真相识灭"。

《起信论》说：「所言灭者，唯心相灭，非心体灭」（大意：所说的灭，只是心相灭，不是心体灭）。又说："唯痴灭故，心相随灭，非心智灭。"这里的"业相"，就是前面三相中的业相，通指无明惑业，名为业相。意思是：可以灭的，只是虚妄习气和惑业而已，真相岂能灭？所以经中又说："自真相若灭者，藏识则灭；藏识若灭者，不异外道断见论议。"唐译作："识真相不灭，但业相灭；若真相灭者，藏识应灭；若藏识灭者，即不异外道断灭论。"

以上预先破除二见完毕。以下正式拣辨邪宗。

## 外道的断灭论

【经文】大慧，彼诸外道作如是论，谓摄受境界灭，识流注亦灭；若诸流注灭者，无始流注应断。

【憨山记】这是举出外道的断灭论，以拣辨邪宗。唐译作："彼外道作如是说：取境界相续识灭，则无始相续识灭。""取境界相续识"，就是前六识以及第七识的粗相；"流注"，就是第八识自体以及第七识的细相。那些外道只见前六、七识的粗相灭了，就说八识全都灭了，这就是断佛种性的见解。所以佛破斥说："若识流注灭者，则无始流注应断。"这正是反过来显示前文所说"但业相灭，真相不灭"。这个不灭的，《宗镜录》称为"真常流注"。

外道说八识一齐灭，是因为不知第八阿赖耶识是生因，以为另有一法作为生生之因，所以佛在下面举出他们的计执。

## 外道所计的异因

【经文】大慧，外道说流注生因，非眼识色明集会而生，更有异因。大慧，彼因者，说言若胜妙、若士夫、若自在、若时、若微尘。

【憨山记】这是举出外道妄计的生因。唐译作："彼诸外道说相续识从作者生，不说眼识依色光明等缘和合而生，唯说作者为生因故。作者是何？彼所计胜性、丈夫、自在、时及微尘，为能作者。"这正是外道不知唯识是生起诸法之因，而在识之外另立胜性等作为生起之因，就是所谓"异因"。

西域外道所计虽有多种，总不出断、常二见。依《成唯识论》所破，有七种，而此经中世尊只指出五种。论中七种是：

第一，数论师计二十五谛：以神我为冥初主谛，从冥谛生觉，从觉生我心，从我心生五尘，从五尘生五大，从五大生十一根，共二十五法，而以神我为胜性。此经中的"胜妙"，就是他们的神我。

第二，胜论师计六句义为生生之因，即实、德、业、大有、和合、同异，妄指这六句都有实性，一切法都从这六句生起；又从"实"句中执有九法，即地、水、火、风、空、时、方、和合等〔译注：原文如此，与《成唯识论述记》所列九实（地水火风空时方我意）不尽相同〕；又计极微成就器世界，所以计极微常住不灭。此经中的"时"与"微尘"，就是胜论所计的。

第三，有外道计大自在天体实、遍、常，能生诸法。此经中的"自在"，就是他们所计的。

第四，有一类外道计大梵、时、方、本际、自然、虚空、我等七法常住实有，具诸功能，能生一切法。此经中的"士夫"就是大梵，说大梵天能生一切；此经中的"时"，也就是实句九法中的时。

第五、第六，有两种声论师计声是常住，能为定量，表诠诸法：一是待缘而生，二是待缘而显。说声是常住的，一定能表诠一切诸法。

第七，有顺世外道，计四大是实是常，能生有情；说极微实常，能生粗色。此经中的"微尘"，也是计极微的。

依这七种来看，世尊所指的五种，只缺了两种声论师，后面以因、缘二种自性补足。

诸外道品类虽多，所执的法不过四种：定一，如数论等；定异，如胜论等；亦一亦异，如无惭外道等；非一非异，如邪命外道等。这些都是不通达唯识真妄非一非异的真实道理，妄执定一定异，作这样的矫乱议论，横生断常二见。

这里只举出定一、定异两种邪见，而佛预先以泥团微尘非一非异的比喻加以破斥。而且这两种都是断见。为什么？若说定一，那么七识灭时八识也随着灭，就堕入断见；若说定异，那么相续识灭了，另有异因；既然立了异因，就是无因，也是断见。

那么，世尊所指的胜性等五种，在这里是断见，在《成唯识论》中却都是执常见的，为什么？因为他们所执的常，就是这里所说的断。为什么？因为外道不知唯识的真常道理，说八识全都是断灭的，又另外执著异法当作真常。这样一来，他们既然执异法为常，本有的真常识性反而成了断灭。所以他们执为常的，正堕入这里的断，正是以无常为常、以常为无常，实在是颠倒之见。这个道理深玄，知道的人很少。

## 外道的七种自性

【经文】复次，大慧！有七种性自性，所谓：集性自性、性自性、相性自性、大种性自性、因性自性、缘性自性、成性自性。

【憨山记】这是举出外道妄计的宗论。魏译作"外道有七种自性"。看这"外道"二字可知：前面说外道认为诸法不从识生，另有异因，妄说胜妙等五种是实是常、能生诸法；由此看来，前面五种是指他们所执的法，而这七种自性是举出他们所立的教有七种。这七种都是妄计离开识另有自性。依《成唯识论》的义理解释如下：

"集性自性"，"集"是集聚，指数论师所立的二十五法。论中说："然大等法，三事合成。"又说："大等诸法，多事合成，如军林等。"因为他们所执的五大、十一根，是从最初的觉、我心、五尘三事集聚生起的，所以叫集性自性。

"性自性"，就是立胜性为自性的那一派。

"相性自性"，"相"是质碍之色，指胜论师所立的六句，以实、德、业、大有、和合、同异以及四大极微等质碍之法作为生起之因。

"大种性自性"，指顺世外道所立的四大是常、能生诸法，就是前面所说微尘能生粗色。

"因性自性""缘性自性"，这两种就是两种声论师所立的：一是待缘而生，以声为生法之因，这是单以声为因，所以叫因性自性；二是待缘而显，以生声之缘为因，所以叫缘性自性。

"成性自性"，指六句义中的和合句。他们执著诸法和合而成，所以叫成性自性。

这七种自性总不出四句，即自生、他生、共生、无因生。因性自性即自生；大种性自性、缘性自性即他生；集性自性、相性自性、成性自性即共生；性自性即无因生〔译注：此句原文句读不清，今依文意断为此读〕。总之，不出断、常二见，都是妄想邪执，不同于我的第一义。所以下文说："我有七种第一义。"

## 七种第一义

以上辨邪宗完毕，以下显示七种圣义，以区别于邪见。

【经文】复次，大慧！有七种第一义，所谓：心境界、慧境界、智境界、见境界、超二见境界、超子地境界、如来自到境界。大慧！此是过去未来现在诸如来、应供、等正觉性自性第一义心，以性自性第一义心，成就如来世间出世间出世间上上法圣慧眼，入自共相建立，如所建立，不与外道论恶见共。

【憨山记】这是举出如来的正教量，以第一义为宗，不同于外道的恶见之论。魏译作"我有七种第一义"等，意思是：我这七种境界，乃是过去、未来、现在诸如来、应供、等正觉的性自性第一义心；以这性自性第一义心，成就如来世间、出世间最上之法，是圣慧眼证入自相共相所建立的。"如"是相称的意思，是说我所建立的是称性而建立，不与外道的恶见相同。"入"是证入；"自相"指一心真如；"共相"指八识因缘。意思是：我已证入唯心唯识，以此建立世间出世间最上的法门，不像外道那样妄立异因作为生法之本，所以说"不与外道恶见共"。

【经文】大慧，云何外道论恶见共？所谓自境界妄想见不觉识，自心所现分齐不通。

【憨山记】这是牒释上面外道恶见的原因。佛是说：我的七种第一义境界，是圣慧眼所观的真知见之力；那些外道的恶见，是随自己的妄想境界所见，不觉知那是自心妄想所现的分齐，所以作这七种邪执断常，以为定一定异而不能通达。

【经文】大慧，愚痴凡夫性、无性、自性第一义，作二见论。

【憨山记】这是总结外道的恶见，在第一义中作二见之论。魏译作："诸愚痴凡夫，无有实体以为第一义，说二见论。"意思是：由于不通达诸法无性，妄立自性，随着愚痴颠倒的妄见，所以在第一义中作二见之论。

从前面"彼诸外道作如是论"以来到这里，通举外道一异、断常二见都不真实。立了真唯识量之后，接下来痛斥外道二见的因与果都不真实，是由于不通达唯心所现，所以妄执是有是无，成了断灭戏论。然后完整显示唯心观门，要让修行人依不生灭心，了达唯心如幻的境界而观，必定获得常住的二转依果。
