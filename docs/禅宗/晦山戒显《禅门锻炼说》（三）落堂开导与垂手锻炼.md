# 晦山戒显《禅门锻炼说》（三）落堂开导与垂手锻炼

## 落堂开导第四

已经入室，搜刮精当，路头不会错了。然而学人参究，如逆水行舟，没有人推挽，就退多进少；又像临河想跳，没有人怂恿，就会犹豫退缩。所以堂中开导，最为急务。开导不是三五天说一回就够了，必须一天三时勤勤开导。

开导的方法，要看他的机宜，观他的勤惰，切中他的缓急。事虽难定，略说端绪，大约有四：一是激发立志，二是指示参法，三是警策疲怠，四是防护魔病。而最忌讳的，是扯葛藤、说道理。

### 一、激发立志

世间的技艺行业，不立志坚强，必不肯身受勤苦；不受勤苦，必不能精通其业。何况断情识、明心性、出生死、成佛祖的大道？所以要下参究之初，先让他树铁石之心，发金刚之誓作为前导：宁可骨断筋枯，不洞明大事不止；宁可丧身舍命，不彻透牢关不休。具备这透脱生死的坚固誓愿，所发的疑情必定真；办得这担荷佛祖的刚强志气，所下的参究必定有力。疑情真、参究有力，哪有不究竟彻悟的？

### 二、指示参法

古人说：「大疑大悟，小疑小悟，不疑不悟。」所以疑有十分，悟就有十分。世上有人教人死守话头、不起疑情，这是参禅的大病。参禅虽然不可胡乱揣度，也不可死守话头。只守话头，所系的是枯桩，所沉的是死水，所磨的是刀背而已。若不发起真疑、让机轮在内里转起来，即使坐到驴年，也不得悟。

学人喜欢走这条路，就沉空滞寂，久而久之以窠臼为乐，竟不相信有悟了。师家喜欢这样教人，就以枯木堂里的禅为究竟，听说别家有人在机锋下省发，必然生谤。哪里知道事情大不然。

「盖生死心切则生疑，疑生悟。」（大意：生死之心迫切，就生疑；疑，就生悟。）

所以长老在禅众静坐时，要指示他们放下万缘，寸丝不挂，在话头上半截的关窍处锐意研穷；研穷无路，然后并心于下半句，尽力挨拶；挨拶力竭，再从头起。久久情识尽、知见忘，悟道就容易了。这是不变的参法。

### 三、警策疲怠

参太平禅的，从容和缓，半浮半沉，如水泡石头，不进不退；即使苦参，工夫也难成片；即使成片，也急切不得省悟，因为没有人鞭策激发。参猛利禅的，虽然容易省悟，但正参时，上根利智有进无退，中下根器猛利一回，筋力就倦怠了，易进也易退，所以须长老勤勤鞭策。

鞭策之法：宁紧峭，不宽松；宁毒辣，不平顺；宁斩钉截铁，不拖泥带水。时时用苦言厉语，往痛处下锥，只要有血性的人，必定愤怒而向前。

### 四、防护魔病

初机的识性狂乱万端，所以开示话头必须上半截有关锁。关锁缜密，搜剔精严，意地里的邪思就带不进影子，所以学人只有悟道，没有著魔。万一师家不观根器，授话不重关锁，任他业识纷飞、狂乱思维，熟人熟境就暗地奔腾，异见异闻扰乱识田；初参学人没有智慧照破，没有道力摄持，或疑或怖，或喜或悲，突然发作，魔事就起来了。魔事一起，长老又没有善巧去疗治，只用五处捆绑、百千捶打，往往至于丧身殒命，岂不可悲！这就是所谓"虽是善因，而招恶果"。若长老勤勤开导、用心防范，就没有这种祸患了。

致病的原因很多，不能尽举，最容易犯的，莫过于在胸前憋气以为勇猛，以及灰心冷坐以求澄湛，这两种最甚。

「盖参禅秘要，只在真实腾疑，而不在乎迸气。」（大意：参禅的秘诀，只在真实地发起疑情，而不在憋气。）

元代以来有些邪师，多教人竖起脊梁、咬定牙关、紧捏双拳、高撑两眼，内里其实没有真疑，外面却装出猛状，天天用硬气塞住胸膛，势必导致心痛咯血。何况这样死挺的模样，又岂能持久？这是一大病。

其次是坐冷禅的，也不起真疑、死心参究，一上禅床，只是千方百计地排遣，消归无事；念头一起，就默念几遍"一口气不来"之类的话，于是认为四大非有、万法俱空，灰心泯智，澄湛不摇，以为工夫。甚至劝他经行，他怕把心念丢了，寸步不移。坐到年深日久，血脉不舒，容易浮肿，也多生火证。这实在是病入膏肓，世间医生都束手无策。

要除这些祸患，全在善知识不惜疲劳，每天到堂中勤行开导：或激发他的坚志，或指示他真参，或警策他的疲怠，再进一步摧荡他的识情，刬除他的知见，扫除他的岔路，剿绝他的病根，魔病众患就无从发作，学人的真悟也就不难指望了。

## 垂手锻炼第五

俗话说：「不入虎穴，争得虎子？」身为长老而不得锻炼之法，即使龙象当前，也都成了废器，积几十年也不得一人省发。即使有一个半个，也是碰巧撞着，如虫蛀木头偶尔成字，不是锻炼之功。若明白锻炼，即使中下资质，逼拶得法，一期之中人多的话，可以使几十人省发。大慧锻五十三人而悟了十三人，圆悟在金山一夜省发十八人，虽然说来惊人，古今确有此事。

哪里的地没有水？不凿就不涌出；哪块木石没有火？不钻不击就不发出。众生都具佛性，就像地中有水、木石中有火，不得善知识以妙密机用、毒辣钳锤去疏浚它、敲磕它，却想等他桶底脱落、自透牢关，即使上上根器，也必望崖而返。所以垂手锻炼，不可不讲。

然而真要锻炼人材，长老必苦，执事必劳。禅制之中，长老须时时在堂，与大众一起起坐；即使做不到，也必须一天三五次在堂，随众行坐。

锻炼的工具，在于善用竹篦子。竹篦起于首山，盛行于大慧，再兴于三峰，是历代老古锥锻炼衲子的器具，不是新创的。竹篦长须五尺，宽仅一寸，稍稍削圆，去其锐角，就便捷好用。至于拄杖子，用来设法接机可以，用来锻炼决不可，即使用了也不灵。至于铜铁如意，只是用来降伏禅众，稍一靠近就头破脑裂，不是锻炼之物。

用竹篦，功在便于逼拶，妙在敲击。禅众坐时，执之巡香；行时，握之为利器。三板止静，长老必先开示，如前所说，不必赘述。香烧到一半，就鸣引磬，令禅众经行。经行之法，先缓后急，渐归紧凑。长老也频频握着竹篦，随众绕行。

当经行到最猛利的时候，就用兵家之法，出其不意，攻其无备：或拦胸把住，逼他下语；或劈头一棒，审问他的本参。等他开口，再夺贼的枪来杀贼；伺他转变，更拿锥子往深处锥。雷崩电闪之时，别让他停下来长出心机；交错纠缠之处，再来一次夺食驱耕。或舍棒用掌，短兵相接；或声东击西，从小道出奇兵；或照用同时，矢石交攻；或棒喝俱行，炮弩齐发。

工夫未到头，就千锤千炼；偷心未死尽，就百纵百擒。务必把学人旷劫以来的识情影子、知见葛藤，挖出窝穴，斩断根株，使他无处藏身，渐渐到了悬崖撒手的地步。一锥一扎，机候到了的人，不难"啐地断，嚗地折"。这不就是背水列阵中所谓"置之死地而后生，置之亡地而后存"吗？锻炼禅众，也就是这样。

长老这样为众，也可以说难了。然而得了此道，就容易出人，也可以说妙了。天下事没有难而不妙的，也没有妙而不难的。在虎脖子上解铃，在龙下巴下夺珠，乃至擒贼擒王，都是极妙极难之事，而走险出奇的人从不缺乏，为何偏偏法门不能这样？

然而天下主法的人，固守成规，贪图简易，以为禅门的格局就该如此。骤然听到我的说法，必定非议说："这是杜撰！哪有长老那么尊贵，天天在禅堂里与衲子眉毛相抵，做这种相攻相扑之事的？"

我说：这是明于小而暗于大。沿袭禅门通套而不用锻炼，长老身安体尊，好是好了，可是终年寂寞，不省发一人，不但佛祖慧命无传，而且门庭冷落，身后断绝，转眼之间祖庭长满蔓草，又哪里见得有体面？舍去禅门成格而勤加垂手，长老体亵身劳，苦是苦了，可是炉鞴雄强，人材奋起，不但卸下了师承的担子，慧命有传，法门光大，到了晚年更见身安道隆，又怎能说没有体面？两相比较，谁得谁失，谁胜谁劣？

何况人的强弱在于各人，寿命长短有定数，长老必不会因尊居丈室而增寿，也必不会因锻炼劳苦而减寿。放眼看去，长老迁化、坟上宿草已长、墓木已拱的，不知有多少，难道都是因为锻炼的缘故？

所以垂手锻炼之法，极迅速极灵验，我把它比作百步穿杨的箭、神臂弓。其中还有未尽之处，就是后面策发、回换、斩关三篇。
