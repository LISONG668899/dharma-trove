# 晦山戒显《禅门锻炼说》（七）简练才能

## 简练才能第十二

明教契嵩说：「尊莫尊乎道，美莫美乎德。」道德是世间与出世间的大宝，没听说是靠才能的。与其有才而无德，宁可有德而无才。世法尚且如此，何况希求佛祖之道、出离生死、锤炼神明、归于寂灭的人？所学的是什么事，还问什么才能？

然而安于质朴守拙、闭门少事，独善其身是可以的；若要主持丛林、统领衲子，肩负法门重任，竖起佛祖高幢，没有长才异能、平素经过简练，怎能胜任而光大？所以治理丛林，不可没有才；也不可有恃才之人。恃才的人一进来，为害不小。所以推举人才，又不可不论德。佛祖门庭不像世法用人，可以使贪使诈，即使放荡不羁之才、不受驾驭之器，也可以权衡驾驭。

其中最难的是：造物生人，全才少，偏才多；才德兼备的少，不兼的多。

看一个人，真诚厚重，言行规矩，好参学，好修持，他的德足以服众；可是一委以事务，就前后失据，顾此失彼，一筹莫展。他所短的是才，不是德。

看一个人，敏捷能干，果敢向前，能文能武，他的才足以应变；可是一授以事权，就妒贤嫉能，搅乱大众，种种恶行无不暴露。他所缺的是德，不是才。

身为长老，谁不重德？可事情又不能不办。谁不爱才？可坏事的人又不能不去。贵在有方法去陶熔、去裁剪、去琢磨，使刚柔都能效用，敏钝都无废材，这就叫"简练以执事"。

执事有大有小，有内有外，有左有右，有文有武，主持丛林缺一不可。百丈看到这一点，建立清规时，先定头首十局，再及于各职，就像朝廷用人，星罗棋布，丝连绳牵，务必使头目相卫、指臂相护。用得恰当，丛林就整肃，法道就施行。这不是故意抑扬高下，而是因为人的材质有良有劣，天资有厚有薄，能力有胜有劣，器量有宽有窄，一概因其所能而使用，人才就各得其当。

然而丛林又是陶熔人根、变化气质的地方，不宜听其自然，必须多设炉鞴，拔擢优秀的以激励大众，淘汰懒惰的以惩戒其余，赏罚分明，能事就出来了。这是治理丛林的大纲，不可紊乱。

至于头角英异、根本纲宗已明、可望成为法门种草的人，简练更应周备，不可轻易放行。

东序（执掌事务的一列）由下而上：悦众掌管讽诵，直岁总领众务，典座主理厨事，知库管理账目，副寺协助总理，维那整饬堂规，监院、都寺担任院务。稍不历练，纷繁事务一到眼前，必然荒废而不能治理。

西序（辅佐法务的一列）由卑而尊：侍者亲近长老，或掌烧香，或掌衣钵，或掌汤药，记录书信，都是为了便于学习；知客掌接待，知浴兴普行，知藏掌经藏，书记掌文墨；禅堂中的板首是堂主，后堂层层而上是西堂、首座。四位板首所掌的，是以规矩佛法辅佐长老，锻炼禅众以接引来学，事情就齐备了。

古人说：「不遇盘根错节，无以别利器。」纵有能人，不历执事，怎能陶炼德器、博综智能？不是粗疏放任，就是掣肘无才，以这样的人主持丛林，怎能不败事决裂？

况且历来古锥磨砺人才，丛林事务无不让他经历：沩山古佛，百丈命他做典座；雪峰大老，德山委他做饭头；乃至杨岐做库司，仰山、雪窦做知客，云峰做化主，五祖做磨头，大慧管东司（厕所），百灵做知浴，圆通管知众，回石做监修，权做直岁，匡做桶头，洞山管香灯，大伯做知随，陆沉下板。他们都率先苦行，都是为了养其器量、老其才干，以斧斤修整其材质，以霜雪锤炼其筋骨，使他们能任重致远，成为法门的柱石。

〔译注：此段列举诸祖所任执事，原文人名多用简称（如"权直岁""匡桶头""大伯知随"），部分人物难以确指，译文照原文顺序转述。〕

唯独付授法脉一事，常常不从一般执事中选，而必从首座、西堂中选，为什么？既然指望他荷担法门，必须能锻炼衲子，才可利益将来；既然期望他主持丛林，必须能当场哮吼，才可绍续慧命。若不在当板首时让他熟炼钳锤，使爪牙毒辣；推举他秉拂说法，使声名远播，一旦居此位、行此令，怎能不捉襟见肘？

可叹近世法门不讲锻炼，急于收人。衲子入门，草草付授；即使任过执事，也不循资历，轻易打发。到了各丛林，就说：某人以侍者身份付了法，某人以知客身份付了法，某人以寮元、直岁身份付了法，乃至某某以禅众身份付了法。竟不命他掌管职事，不以盘根错节考验他，不举他为板首以锐利其爪牙、锻炼其才能、积蓄其声望。对事务一窍不通，就盖一个印子；明知软弱，只搭一个虚名。不但误了天下苍生，自欺欺人，而且门庭倒塌而不可扶持，有什么可取的？

要知道自古没有容易做的佛祖，也没有无能的长老。长老是为人天作典范、统领龙象的，是英灵的标准、文武的权衡，必须有道德可以训人，也有才能可以治事。虽然潜行密用、如愚若鲁，一当大任，就经纬分明、剖析精当，目无全牛，这岂不是师家炉鞴周正、早加简练的结果？

「故锻炼初机，冀其开眼，莫善于敲击；锻炼老参，期其成器，莫精于简练。」（大意：所以锻炼初机，希望他开眼，没有比敲击更好的；锻炼老参，期望他成器，没有比简练更精的。）

不由这条路，却指望英贤辈出、蹴踏祖庭，纵然侥幸有之，也不是常法。孔子说："以不教民战，是谓弃之。"（用未经训练的百姓去作战，就是抛弃他们。）可为之痛哭流涕、长声叹息的，就是这个。
