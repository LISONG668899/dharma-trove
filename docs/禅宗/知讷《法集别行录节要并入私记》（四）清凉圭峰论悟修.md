# 知讷《法集别行录节要并入私记》（四）清凉圭峰论悟修

## 澄观论悟修顿渐诸门

澄观《贞元疏》说：若说明悟的相状，不出两种：一是解悟，即明了性相；二是证悟，即心造玄极。若说明顿渐，则有多门。

若说顿悟渐修，这是就解悟而言：豁然了达心性之后，渐渐修学，令行与悟契合。悟如日照，顿时照亮万法；修如拂镜，渐渐莹洁，渐渐明亮。

若说渐修顿悟，是先摄境归于唯心，次观心本清净，后心境双寂，一念瞥起而不生，前后际断，湛然如静止的大海，广阔若虚空。这是就证而名为悟：修如磨镜，悟似镜明。

若说渐修渐悟，也是证悟：修与悟都像登台，脚步越来越高，所见越来越远。

若说顿悟顿修，这通三义。若是先悟后修：廓然顿了，名为悟；不看不澄，不收不摄，旷然合道，名为修。这是解悟，以定为门，也如不拂不磨而镜自明。若说先修后悟：依前而修，忽然见到心性，名为悟，这是证悟：修如服药，悟如病除。若说修悟一时：无心忘照，任运寂知，定慧双运，如明镜无心，顿照万象，这就悟通解证。

又说：若说本具一切佛德，名为悟；一念具足十度万行，名为修：修如饮大海水，悟如得百川之味。这也通于解证。

## 知讷辨：名同义别

以上所录，是清凉所说明的修证顿渐之义。顿、渐二门各有三义，解释如前。其中的"顿悟渐修"，与此录中所立的名目全同，义理趋向却全然不同。为什么？清凉是以悟从修，立于渐门；圭峰是以修从悟，立于顿门。各有旨趣，两不相妨。然而悟若是彻悟，岂会滞于渐修？修若是真修，岂会离于顿悟？由此可知，离文取义，不滞名言，才是要紧。

清凉取顿宗"顿悟"之名，立于渐门，这既不是渐修功熟之后的顿悟，也不是凡夫当机发起的顿悟，只是信解烦恼心中本有觉性，如镜有明性，决定无疑，名为解悟。若不是这样，清凉岂会把真实悟解烦恼本空的人归入渐门，又说"修如拂镜，渐莹渐明"？

圭峰取渐宗"渐修"之言，归属顿门，这既不是见有烦恼可断的渐修，也不是只取无念之修而功行不能一时圆毕，就姑且称之为渐修。此门旨趣甚深，如前面录中所说。

圭峰在《禅源诸诠集》中又阐明顿悟渐修，义理非常详细。如说：若顿悟自心本来清净，原无烦恼，无漏智性本自具足，此心即佛，毕竟无异，依此而修，就是最上乘禅，也名如来清净禅，也名一行三昧，也名真如三昧，这是一切三昧的根本。若能念念修习，自然渐得百千三昧。达摩门下辗转相传的，就是此禅。

如今的禅者不审察这段文字的始终之义，只依据"本无烦恼"就不立修证，妄自揣度古人所行，反而堕入"人人无分"的过失。这全是因为没有探究悟与修二义似相反而实相符的缘故。

## 悟后修门的二义

依这段文义深细思量，悟后修门有二义。

第一，"依此而修"以下，是依自心本无烦恼之义，不看不澄，旷然合道，任运而修。这叫做根本一行三昧，也就是清凉所立的"顿修"。

第二，"若能念念"以下，是从根本三昧中任运寂知，众行由此而起，悲愿相资，念念修习百千三昧，身智光明通达，渐渐自在，普利群生，同于卢舍那佛。录中所立的"渐修"，正是指这个。这是圆渐，不是渐圆。因为它不离本所悟的自心真法界的圆修，也不离无念修中的办事修。

不只《禅源集》有此说明，录中也有这两种修的意思。如荷泽宗说："若遇善友开示，顿悟空寂之知；知且无念无形，谁为我相人相？觉诸相空，心自无念；念起即觉，觉之即无，修行妙门，唯在此也。"（原注：这只是体达之"无"，不是断灭之"无"。）这正是悟后的无念修。又说："虽备修万行，唯以无念为宗；但得无念，则爱恶自然淡薄，悲智自然增明，乃至应用无穷，名之为佛。"这正是不离根本一行三昧，自然渐得百千三昧，广度众生之意。所以可知，"顿悟渐修"名字虽同，二师所立的顿渐却迥然不同。

若就性具门说，初悟之时，十度万行一念具足，度化众生已经圆满；若就现行门说，岂能没有生熟之别？诸方都说"功未齐于诸圣"（大意：功行尚未与诸圣齐等），就是这个意思。

又，疏中所说的顿悟顿修，其中所谓顿修，是以不看不澄、旷然合道为修，也就是圭峰所立先悟后修二义中的根本无念修。推求其意，前面所说三义中的第三义"无心忘照，任运寂知"，兼具无念修与办事修二义，只是顿修办事隐而不显。

疏中又说："若说本具一切佛德名为悟，一念具足十度万行名为修，也通解证。"其中所说的办事有二义：若就解悟说，是性具门，并非功行一时圆毕；若就证悟说，才是现行门，是顿修办事。

## 圭峰论化仪顿与逐机顿

圭峰不只说明悟后渐修，也有顿悟顿修、办事顿毕之说（顿悟顿修之说，后面再详细说明）。不过他判定这是"多生渐熏而发现"，就佛的教法而言，属于华严化仪顿，所被的是缘熟菩萨一类，不是如今所崇尚的。如今所崇尚的顿悟渐修，就教而言，是逐机顿所被，是凡夫中上根利智者所行。以下略引明证，令初心者知其纲要，发正信心，速证菩提。如《禅源集》说：

只因世尊说教的仪式不同，有称理顿说，有随机渐说，所以又名顿教、渐教。渐教，是为中下根人说人天乘、小乘阿含等经、婆沙等论（原注：乃至法相宗的《解深密》等经、《瑜伽》《唯识》等论，破相宗的诸部般若经、《中》《百》《门》等论），等他们根器成熟，才为他们说了义之教，就是《法华》《涅槃》等经。

顿教又有二：一是逐机顿，二是化仪顿。逐机顿，是遇到凡夫中的上根利智，直示真法，闻即顿悟，全同佛果，如《华严》中说"初发心时即得阿耨菩提"，《圆觉》中说"观行即成佛道"。然后才同前面渐教中的行门，渐除凡夫习气，渐现圣德，就像风激大海，不能现出影像，

（知讷夹注：说"然后才同前面渐教"，是因为这圆顿门中，也有先修渐行、后来回心顿悟的人。所以若把整段文意理解为先渐除渐现、然后才顿悟，那就完全成了渐教中功熟证悟的人，怎能说《华严》《圆觉》所被的是先悟后修的上根凡夫呢？应当知道，此教所正为的根机，既不是前面的中下根，也不是后面的根熟菩萨。）

风若顿然止息，波浪就渐渐平静，影像就显现出来。（原注：如《华严》中的一部分〔《华严》具足二种顿，摄受两种根机〕，以及《圆觉》《佛顶》《密严》《如来藏》等经，就是这一类。）遇机即说，不定在初在后。

化仪顿，是佛初成道时，为宿世因缘成熟的上根之流，一时顿说性相事理、众生万惑、菩萨万行、贤圣地位、诸佛万德。因该果海，初心即得菩提；果彻因源，位满仍称菩萨。这唯有《华严》一经及《十地》一论名为顿教，其余经论都不完备。

其中所说诸法，是全一心之诸法；所说一心，是全诸法之一心。性相圆融，一多自在，所以诸佛与众生交彻，净土与秽土融通，法法彼此互收，尘尘都包含世界，相入相即，无碍熔融，具足十玄门，重重无尽，名为无障碍法界。

## 知讷私记：自心是法界之都

如今的人听说自心自性，以为浅近；听说无障碍法界，以为深远，却不知自心正是法界之都、生佛之源。若能返照，情量尽了，法界就圆满显现。只怕不善用心，滞在寂静之中罢了。

《华严锦冠》以观心解释"大方广佛华严经"说：若就教诠义，有多门；若不摄归一心，与我又有何干？所谓"大"，就是心体，心体无边，所以名为大；"方"是心相，心具足德相之法；"广"是心用，心有称体之用；"佛"是心果，心得解脱处名为佛；"华"是心因，心所引发的万行，以华为喻；"严"是心功，心能善巧庄严，所以称为严；"经"是心教，心起名言，诠显此理，所以名为经。「然心之一字，虽非一切，能为一切」（大意：这一个"心"字，虽然不就是一切，却能成为一切）。观者以三大之中具足四法界，对那四法界，所以成就四种观。法本来如此，所以依法而观。若依此悟解，念念就是华严法界，念念就是毗卢遮那法界。

这一解释很详细，是就心的义用说为四法界，其实只是一真法界。若把心做成四种观，终究不能相应。清凉在《心要笺》中不是说吗：「唯忘怀虚朗，消息冲融，其犹透水月华，虚而可见；无心鉴像，照而常空矣」（大意：只要忘怀而虚朗，动静冲和融通，就像透入水中的月光，虚而可见；又如无心的明镜照像，照而常空）。天台三观门也说：说的时候有三个名字，照的时候不作三或一的理解，只是念念见自心性，任运非三非一。迷者不辨说门与观门的分别，随着言教义理运起无限思想，就以为这是观心，实在是迷惑了。
