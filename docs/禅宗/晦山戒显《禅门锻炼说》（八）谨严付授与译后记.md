# 晦山戒显《禅门锻炼说》（八）谨严付授与译后记

## 谨严付授第十三

锻炼之说，已在前面陈述完了。然而要善始善终，流传就应当谨慎。为什么？只要有佛性，都可受锻炼；受了锻炼，人都可省发。然而人人可以省发，却不必人人都可付授。

古人说："上根利智，方可参禅。"我曾斥这话不对。炉鞴本是用来熔钝铁的，良医本是用来治病人的。不明锻炼，即使上根利智也成废器，何况在此之下的人？善于锻炼，即使钝铁病人也成良材，何况在此之上的人？

「有心皆可以作佛，有性皆可以悟道。」（大意：凡有心的都可以作佛，凡有佛性的都可以悟道。）

只在善知识搜罗抉剔、刮垢磨光，垢尽明现，如磨镜之喻。如今不怪锻炼无方，却一概说中下根器与参学无分，这是万古不破的迷惑，是我切齿痛恨的。

然而说一经省发就都可付授，这又是知其一不知其二。学人要到堪付授的地步，必须道眼可以继承宗祖，行德可以作人天典范，学识可以启迪后进，爪牙可以擒拿衲子，然后才命他出世、责他为人，如以印传印，印文酷肖，法门才可依赖。即使在末法时代，全才难得，奇器难求，也必须长久同住，熟知其心行；纵然不能超宗越格，也不至于方底圆盖，必有几种擅长、稍近规矩的才可以。即使不能做长老而做静主（隐修者），也必须道眼明、人品正，具佛祖刚骨，孤介自守，不犯人家苗稼的才行。断不是庸陋愚劣、险诈邪僻之辈所宜插足的。

然而法门到了今天，流弊说不尽。常见主法的人只守死法，不苦身锻炼，求人省发实在难。因为省发的人难求，又怕法脉断绝，见到一知半解的，不得不急急付授。这有两个缘故：

一是只重根本，不重纲宗，没有擒拿移换人的手段，那些只得一橛头禅、口角滑利的，都能偷关而过，下半截深细的锻炼竟置之不问。这是笼统门头容易付授的缘故。

二是长老虽想在竹篦下择器，既不能出人，又不甘心寂寞，明知外来生人一知半解不够格，却势不能留难，稍一拣择，那人必掉头而去。这是不知锻炼以至于泛滥的缘故。

依我说：省发是容易得的，却把它看得难如龟毛兔角；付授是应当难的，却看得容易如起个法名、收个戒子，岂不是大颠倒？若真希望曹溪正脉源深流长、列祖慧命真传正授，那么法嗣出行时，应当嘱咐又嘱咐，令其慎重又慎重，共同坚固壁垒、加高堤防，不让只得影响音闻的人一传再传，渐至溃围乱正，法门就不致败坏。

有人问：有前辈尊宿严守关钥，至死不付一人，如何？答：这必是善知识感愤时风、矫枉过正，万不得已才这样，但也不是中道。佛祖慧命递代相承，传衣传法，是千万世的光明种子。泛滥付授固然不对，又岂能以毕竟断绝为对？世尊与西天列祖每当传法，必苦口叮咛："传示将来，毋令断绝。"只是其间或有人或无人，或多付或少付，各有定分，不可勉强，贵在得当而已。

马祖出了八十四位善知识，各为宗主，无不当器。后来称人才极盛的，是云门、洞山、法眼、汾阳、黄龙慧南、真净克文、东山法演、圆悟、大慧；大慧付授，世谱列有九十多人，没有人议论诸老滥付。单传衣钵的，如风穴、杨岐、白云、应庵、密庵等，虽是孤承一脉，却能光大家业，也未曾以断绝为高。

若一定以断绝为高，那么四祖何必从庐山远到牛头？南岳何必磨砖？船子何必覆舟？风穴何必痛哭？大阳何必把顶相、皮履、直裰寄给浮山，让他代求法器？只因善知识行事，或开张，或守成，或补救，因时施设，各有苦心，不可轻议。

时运正盛时，佛祖挺生，龙象聚集，有智慧超过师父的，至少也有见地与师齐的。广大门庭，无一不是法器，即使付几十人乃至上百人也不为多。法当开张，不得不开张。

时运衰季时，师家缺乏辨验，学人追逐虚名，有付了几人而无一人当器的，有付了几十人而无一人周正出世的，羊质虎皮，彼此哄诱，即使只付一人也已经不对了。于是真善知识宁可断绝而走孤高之路，作为补救。法当补救，不得不补救。

开张的善知识处其易，补救的善知识处其难；易有易的功勋，难也有难的利益。补救的善知识虽说不付，却是中流砥柱，道眼具存，历百世而光明洞然，能说是断绝吗？泛滥的门庭虽多付，却如日中浇瓜，结果在哪里？转眼就败坏狼藉，能说是接续吗？

总之，明纲宗、知锻炼，初步就不难出人，悟后也不轻易放过，谨慎与流传都是法门之幸。毁纲宗、忽锻炼，流传就有滥觞之过，太慎又有断绝之忧，都不是法门之福。

虽然如此，善知识为佛祖入草求人、为人天开凿眼目：

「宁慎无滥，宁少而真，毋多而伪。」（大意：宁可谨慎，不可泛滥；宁可少而真，不可多而伪。）

不让稂莠稊稗混乱嘉种，慧命必定永远昌大。所以我苦口力陈锻炼，而以嘱咐慎重流传作结，作为末后一句。

重纲宗、勤锻炼、持谨慎，这三法都是世人未闻而难行的。再三说这些，必定触犯忌讳。然而要使正眼流通、儿孙得力，道必定由此而行。俗话说："当言不避截舌。"孔子说："知我者，其惟《春秋》乎！罪我者，其惟《春秋》乎！"我姑且存此说以求正于来者，千百世后再有扬子云那样的人出来，必定知道扬子云。

## 跋

我实在见到近来禅门死守成规，不懂烹炼锻冶，常致真宗寂寥、法流断绝，万不得已，才立此新法，姑且死马当活马医。

若论本分一着，在言前荐得，尚是滞壳迷封；在句下精通，已是触途狂见。悟虽不是没有，无奈已落在第二头。急急地讲钳锤、论锻炼，岂不是头上安头、梦中说梦？那些弄泥团的汉子将来把它认作实法，不知通变，就连累山僧活陷铁围山了。

耽源的九十七圆相，若遇到仰山，一把火烧掉。山僧合掌说："作家！作家！"这才真能善用孙武子而不做纸上谈兵的赵括。果真有这样的人，我只能举手加额，远远盼望了。

晦山老人又书于黄梅四祖方丈。

## 译后记

译完这十三篇，最深的印象是：这不是一部"教人参禅"的书，而是一部"教禅师怎样当禅师"的书。

禅籍中讲学人怎样用功的话很多，《禅关策进》、博山《参禅警语》都是名篇；但站在住持的位置上，把从接人到传法的每一个环节都写透的，戒显这部书几乎是独一份。他要求长老先发誓忍苦，认得每个禅人的名号、相貌与本参，一天三时下堂开导，握着竹篦随众经行，在最猛利处出其不意地逼拶；又要懂纲宗才能回换，重操履才能服人，通内外学才能利生，经执事才能主事，最后还要守住付法这道关。每一条都落在实处，没有一句空话。

书中最锐利的，是对两种"死禅"的批判。一种是元明以来的"冷禅"：灰心冷坐、不起疑情，以坐得久为工夫，提起"悟"字就如犯国禁。一种是"一橛禅"：得一点光影就承当，不研纲宗，作用是性，豁达空，最后流于不择饮啖、不顾罪福。前者是不敢悟，后者是假悟。这两种病，与憨山在《观楞伽经记》中痛斥的"拨无因果"、在《观老庄影响论》中数落的"儱侗真如，颟顸佛性"，其实是同一种病在不同时代的面目。

戒显开出的药方是"重纲宗、勤锻炼、持谨慎"。三者中最见三峰家风的是纲宗。他说"未悟之纲宗不必有，既悟之纲宗不可无"，又说"穷尽万法而不留一法，是真直捷"，把禅宗"不立文字"从一句口号还原为一个过程：先要透过根本，再要透过纲宗，最后连纲宗也骂除。这与楞伽的"宗通"与"说通"恰好相应：没有宗通，说通就是葛藤；没有说通，宗通就成了一橛。

书中兵家气很重，读来有时让人心惊："其心至慈，其用至毒。"然而通读下来，可以看到这份毒辣背后的悲心。他说中下根器也能悟道，"上根利智方可参禅"是"万古不破之惑"，是他"切齿"的；他说长老若不锻炼人，就是"盗名""窃位"。他把一生的心血写成兵书，到最后却在跋中说，这一切都是"头上安头、梦中说梦"，倘若遇到仰山，"一火焚之"，他还要合掌称赞"作家"。立了法，又亲手破了法，这才是禅门真正的兵法。

今天，禅七在各地道场又兴盛起来，"锻炼"二字的分量却常被忽略。愿这部三百多年前的兵书，能让带众的人知道肩上的担子，也让参禅的人知道：所谓"啐地断，嚗地折"，从来不是一个人枯坐出来的。
