# 为霖道霈《禅海十珍》（八）洞山宝镜三昧

## 第八珍　洞山良价禅师宝镜三昧

《宝镜三昧》四言为句，共九十四句。下面按意义单元分段，保留原文，后附大意。

如是之法，佛祖密付。汝今得之，宜善保护。

（大意：这样的法，是佛祖秘密传付的；你如今得到了，应当好好保护。）

银碗盛雪，明月藏鹭。类之弗齐，混则知处。

（大意：如银碗盛雪、明月中藏着白鹭，看似同类，其实不齐；混在一起，就知其所在。）

〔存疑："类之弗齐，混则知处"二句，旧注有"似同而实异，混处方显"与"混同时自知所在"两种读法，未能确定。〕

意不在言，来机亦赴。动成窠臼，差落顾伫。背触俱非，如大火聚。但形文彩，即属染污。

（大意：意不在言语，来机却也随之相应；一动就成窠臼，一差就落入犹豫顾望。背离也不对，触著也不对，如同大火团；只要显出一点文彩，就属于染污。）

夜半正明，天晓不露。为物作则，用拔诸苦。虽非有为，不是无语。

（大意：半夜里正明，天亮了反而不露；为万物作法则，用以拔除诸苦。虽然不是有为，却也不是无语。）

〔存疑："夜半正明，天晓不露"是曹洞以明暗喻正偏的说法，确切所指难以坐实。〕

如临宝镜，形影相睹。汝不是渠，渠正是汝。

（大意：如面对宝镜，形与影相互照见；你不是他，他正是你。）

如世婴儿，五相完具。不去不来，不起不住。婆婆和和，有句无句。终不得物，语未正故。

（大意：如世间的婴儿，五相完具，不去不来，不起不住，咿咿呀呀，有句也似无句；终究说不出一物，因为言语还未端正。）

重离六爻，偏正回互。叠而为三，变尽成五。

（大意：如《易》的重离卦，六爻之中偏与正互相回互；叠起来成三，变化穷尽成五。）

〔存疑：此四句以《易》离卦喻偏正五位，历来注家推演方法各异，如何"叠而为三，变尽成五"，没有定说。大意只录字面。〕

如荎草味，如金刚杵。正中妙挟，敲唱双举。通宗通途，挟带挟路。错然则吉，不可犯忤。

（大意：如五味子一草具五味，如金刚杵两头一体；正中妙在兼挟，敲与唱同时并举；通宗也通途，挟带着也挟着路。交错得当就吉，不可冒犯违逆。）

〔存疑："挟带挟路""错然则吉"二句尤难解，大意只是字面串讲，未敢定其所指。〕

天真而妙，不属迷悟。因缘时节，寂然昭著。细入无间，大绝方所。毫忽之差，不应律吕。

（大意：天真而妙，不属迷也不属悟；因缘时节，寂然而又昭著。细可入于无间，大则超越方所；有毫厘之差，就不合音律。）

今有顿渐，缘立宗趣。宗趣分矣，即是规矩。宗通趣极，真常流注。

（大意：如今有顿有渐，是因此而立宗与趣；宗与趣一分，就成了规矩。宗通达了，趣到极处，真常仍在流注。）

外寂中摇，系驹伏鼠。先圣悲之，为法檀度。随其颠倒，以缁为素。颠倒想灭，肯心自许。

（大意：外面寂静，内里摇动，如拴住的马驹、伏着的老鼠。先圣悲悯这种情形，为之施法；随顺众生的颠倒，以黑为白。颠倒之想灭了，才肯心自许。）

要合古辙，请观前古。佛道垂成，十劫观树。如虎之缺，如马之馵。

（大意：要合于古人的轨辙，请看前古：大通智胜佛佛道将成，十劫观树而坐；如有缺的虎、左后足白的马，都是有所欠缺之相。）

〔存疑："如虎之缺，如马之馵"为何用来接"十劫观树"，旧注说法不一，大意只录字面。〕

以有下劣，宝几珍御。以有惊异，黧奴白牯。

（大意：因为有下劣的根器，所以给以宝几珍御；因为有惊异的人，所以示以黑狸白牛。）

〔存疑："宝几珍御""黧奴白牯"的确切取义难以坐实，一般理解为随根器施设：对劣根示以尊贵之相，对惊异者示以平常之物。〕

羿以巧力，射中百步。箭锋相值，巧力何预。

（大意：后羿凭巧力，百步之外射中；至于两箭箭锋相抵，又与巧力何干？）

木人方歌，石女起舞。非情识到，宁容思虑。

（大意：木人正在唱歌，石女起身跳舞；这不是情识所能到的，哪容思虑？）

臣奉于君，子顺于父。不顺非孝，不奉非辅。

（大意：臣奉于君，子顺于父；不顺就不是孝，不奉就不是辅佐。）

潜行密用，如愚若鲁。但能相续，名主中主。

（大意：潜行密用，如愚如鲁；只要能相续不断，就名为主中之主。）

## 道霈论曰

《宝镜三昧》是洞山宗的源头。开头就说：「如是之法，佛祖密付。汝今得之，宜善保护。」可见此法是为"知有"的人说的，只是让他们好好保护而已。一不善于保护，就不相应，就是所谓「毫忽之差，不应律吕」。

文中立宗趣、设规矩，讲臣奉君、子顺父，涤除法执，无非是让知有的人保护此法。如空中鸟迹，迹迹皆空，原无实法。若不知有，只在言句上穿凿，那就是剑早已落水，才去刻舟求剑，可悲啊！

## 译者附说

《宝镜三昧》是曹洞宗的根本典籍，相传是云岩昙晟密授洞山良价的。全篇的骨架是"偏正回互"："汝不是渠，渠正是汝"讲的是现象与本体既不相同又不相离；"重离六爻""叠而为三，变尽成五"讲的是从中推出的五位。

道霈的论抓住了开头四句："如是之法，佛祖密付，汝今得之，宜善保护。"在他看来，这首长偈不是给初学者讲道理的，而是给已经"知有"、见了本来面目的人讲怎样保任。所以后半篇说"潜行密用，如愚若鲁，但能相续，名主中主"，保任的功夫全在"相续"二字。这与前面晦山《禅门锻炼说》强调"悟后精严操履"、道霈自己被永觉"翻案不许"的经历，正是同一个道理：见道之后，才真正开始。
