# 荷泽神会《顿悟无生般若颂》

## 题解

这篇短文是荷泽神会大师亲撰的禅宗纲要，敦煌写本 S.5619 题作《顿悟无生般若颂》。北宋道原《景德传灯录》卷三十收入时，改题为〈荷泽大师显宗记〉，后世通行的就是这个题名。

《景德传灯录》卷五的神会传说，慧能大师灭度后二十年间，曹溪顿教的宗旨在南方沉废，嵩岳渐门在长安、洛阳一带盛行；神会于是入京，"天宝四年方定两宗，乃著《显宗记》，盛行于世"。天宝四载（745），正是兵部侍郎宋鼎请神会入住东都荷泽寺的那一年。

全文不过九百字，用四六骈文写成。前半以"无念为宗，无作为本，真空为体，妙有为用"立纲，阐明真空妙有、般若与涅槃、知与见、定与慧的不二；后半叙述从世尊、西天二十八祖到达摩的传承，说明"内传心印，外传袈裟"的意义，以显南宗的正统。所以题名"显宗"。文中"无住之心""如来知见""知即知心空寂"等语，与《坛语》《问答杂征义》一脉相承。

今据《大正藏》第五十一册《景德传灯录》卷三十所收本译出。

## 一、宗、本、体、用

"无念为宗，无作为本；真空为体，妙有为用。"

以无念为宗旨，以无作为根本，以真空为本体，以妙有为作用。

真如本是无念，不是起心想念所能知道的；实相本是无生，岂是色身与妄心所能见到的？

"无念念者，即念真如；无生生者，即生实相。"以无念之念去念，就是念真如；以无生之生而生，就是生实相。

无住而住，就常住于涅槃；无行而行，就超越到彼岸。如如不动，而动用无穷；念念无所求，所求的本来就是无念。

## 二、即定无定，即慧无慧

菩提无所得，却能清净五眼（肉眼、天眼、慧眼、法眼、佛眼），了达三身（法身、报身、化身）；般若无所知，却能运用六神通，弘扬四智（大圆镜智、平等性智、妙观察智、成所作智）。

由此可知："即定无定，即慧无慧，即行无行。"就在定中而无定相，就在慧中而无慧相，就在修行中而无修行之相。

自性等同虚空，本体同于法界，六度从此圆满，三十七道品于是没有亏缺。

## 三、心本无作，道常无念

由此可知，我与法的本体都是空，有与无双双泯灭；心本来无所造作，道恒常无念。

无念无思，无求无得，不在彼也不在此，不去也不来。

体悟三明（宿命明、天眼明、漏尽明），心通八解脱；功德成就如来十力，富有七圣财（信、戒、惭、愧、闻、舍、慧七种圣财）。进入不二法门，获得一乘之理。

妙中之妙，就是微妙的法身；天中之天，就是金刚般若之慧。湛然常寂，而应用无方。

## 四、真空妙有，般若涅槃

"用而常空，空而常用。"起用之时常是空，空寂之中常起用。

"用而不有，即是真空；空而不无，便成妙有。"起用而不落于有，就是真空；空寂而不落于无，便成妙有。

妙有，就是摩诃般若；真空，就是清净涅槃。

般若是涅槃的因，涅槃是般若的果。般若无所见，却能见涅槃；涅槃无所生，却能生般若。

涅槃与般若，名称不同而本体相同，只是随着意义而立名，所以说"法无定相"。

## 五、如来知见：知心空寂，见性无生

涅槃能生般若，就名为真佛法身；般若能建立涅槃，所以号为如来知见。

"知即知心空寂，见即见性无生。"所谓知，是知道心本空寂；所谓见，是见到自性无生。

知与见分明，不一也不异。所以能动与寂常是妙用，理与事都是如如。如如，就处处都能通达，就是理事无碍。

## 六、心境双亡，体用不异

六根不被染污，就是定慧的功用；六识不生妄念，就是如如的力量。

心如如不动，境界自然谢落；境界灭了，心也空了。心与境双双泯亡，本体与作用就没有差异。

真如本性清净，智慧的鉴照无穷无尽，就像水中现出千月，能见闻觉知；见闻觉知，却常是空寂。空，就是无相；寂，就是无生。

不被善恶所拘束，不被静乱所摄持；不厌离生死，也不贪乐涅槃。"无不能无，有不能有"：说无，却不能说它全无；说有，却不能说它实有。

行住坐卧，心不动摇；一切时中，获得无所得。

## 七、西天东土，代代相承

三世诸佛的教旨就是这样，菩萨以慈悲心辗转相传。

自从世尊灭度以后，西天二十八祖共同传承这无住之心，同说如来知见。传到达摩祖师，来到中土，作为此方的初祖，代代相承，至今不绝。

所传的秘密教法，必须遇到合适的人才能传。就像转轮圣王髻中的明珠，终究不会随便给人（这是《法华经》中的譬喻：转轮王髻中的明珠，只赐给立有大功的人）。必须福德、智慧两种庄严具足，行持与见解相应，才能建立此法。

## 八、衣为法信，法是衣宗

"衣为法信，法是衣宗。"袈裟是传法的信物，法是袈裟的宗旨。传承只讲衣与法相传，此外没有别的法。

"内传心印，印契本心；外传袈裟，将表宗旨。"在内传授心印，印证契合本心；在外传授袈裟，用来表明宗旨。

没有袈裟，就不传这个法；不是这个法，就不受这件袈裟。袈裟是作为法之信物的袈裟，法是无生之法。

无生，就是没有虚妄，也就是空寂之心。知道心本空寂，就了达法身；了达法身，就是真正的解脱。
