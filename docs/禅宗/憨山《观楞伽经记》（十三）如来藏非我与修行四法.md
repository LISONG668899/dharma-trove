# 憨山《观楞伽经记》（十三）如来藏非我与修行四法

【经文】观楞伽阿跋多罗宝经记卷第三。宋天竺三藏沙门求那跋陀罗译。明建邺海印沙门释德清笔记。一切佛语心品第二之上

憨山科判说：前面显理之中，先说明寂灭一心，已经完毕。以下显示如来藏性。

## 如来藏是否同于外道之我

【经文】尔时大慧菩萨摩诃萨白佛言：世尊！世尊修多罗说如来藏自性清净，转（二译皆作具）三十二相，入于一切众生身中。如大价宝垢衣所缠，如来之藏常住不变亦复如是。而阴界入垢衣所缠，贪欲恚痴不实妄想尘劳所污，一切诸佛之所演说。云何世尊同外道说我，言有如来藏耶？世尊！外道亦说有常作离者，于求那周遍不灭。世尊！彼说有我。

【憨山记】这是将要显示如来藏性真常无我，以破外道妄计的神我，所以发出这一问。

前面说"寂灭者名为一心，一心者名如来藏"。这藏体从本以来不与一切染法相应，所以说"自性清净"。诸佛证得它，称为菩提涅槃，成就三十二种妙相；众生迷失它，就成为生死烦恼，作八万四千尘劳。这样看来，众生日用中现证的，全是如来的果德，所以说"转三十二相，入于一切众生身中"。只因被五阴之垢所蔽，被贪痴妄想所污，所以如同价值连城的宝珠被脏衣所缠裹，其实自性常住不变。这是一切诸佛大乘了义的究竟之谈，就是所谓常住一心、法身真我。

大慧因此生疑说：世尊向来斥责外道妄计神我，说那是邪见；如今说有如来藏常住真我，岂不同于外道所说的我？而且世尊说如来藏体常住周遍、离于自性、不生不灭，而外道也说有常住的作者，离于求那，周遍不灭，这样外道所说的我，与佛所说并无分别。况且世尊前面说"空、无生、无二、离自性相，普入一切修多罗"，如今又说有如来藏之义，这是与圣教相违，也是自语相违。

外道所计的我，其义有三：一是体常，名为作者；二是虽在五阴之中，却离于求那（德性），另有自性；三是遍历诸趣，实在不生不灭。他们的话虽然相似，其义却全然不同，实在是邪见。所以说：「学道之人不识真，只为从前认识神；无量劫来生死本，痴儿认作本来人」（大意：学道的人不识真心，只因从前把识神当作自己；这识神是无量劫来生死的根本，愚痴的人却把它认作本来面目）。

此经以破邪为用，意思是这一邪见一破，就名为正智，就可以顿证一心。所以大慧在显理究竟之处，提出这一问。

【经文】佛告大慧：我说如来藏，不同外道所说之我。大慧！有时说空、无相、无愿、如、实际、法性、法身、涅槃、离自性、不生不灭、本来寂静、自性涅槃，如是等句说如来藏已，如来、应供、等正觉，为断愚夫畏无我句故，说离妄想无所有境界如来藏门。大慧！未来现在菩萨摩诃萨，不应作我见计著。

【憨山记】这是说法本离言、应机而说，以显示藏性无我。意思是如来说法不同于外道执一的论说，只是顺着众生所执之情，随宜加以击破。所以，为执著有相、有所希求的人，说空、无相、无愿三解脱；为执著假法的人，说如、实际；为执著差别的人，说平等法性；为执著妄身的人，说法身；为乐著生死的人，说涅槃；为认生灭为心性的人，说离自性、不生不灭；为厌恶喧嚣的人，说本来寂静；为厌离生死的人，说自性涅槃。像这些句子，都是如来藏的异名，所以说"如是等句说如来藏已"。

为执著四大假我和认取神我的人说无我，其中有愚夫一听说无我就生起恐怖，所以如来才说"离妄想无所有境界，名如来藏自性清净"。这也是随顺方便，本无实法，所以你们应当依于义理，不要执著言说，不应作我见计著。

前面说三乘是权、一乘是实；这里说法身、涅槃、如来藏等名，仍然是方便建立。正所谓"我大乘非乘"，以显示寂灭心源，言语思维之路都断绝，真与妄两忘，才是自觉圣智的究竟之处。

【经文】譬如陶家，于一泥聚，以人工、水、木、轮、绳方便，作种种器。如来亦复如是，于法无我，离一切妄想相，以种种智慧善巧方便，或说如来藏，或说无我。以是因缘故，说如来藏，不同外道所说之我，是名说如来藏。开引计我诸外道故，说如来藏，令离不实我见妄想，入三解脱门境界，希望疾得阿耨多罗三藐三菩提。

【憨山记】这是以比喻显示法因根机而不同。《维摩经》说：「说法不有亦不无，以因缘故诸法生」（大意：所说的法既不是有，也不是无，因为因缘的缘故，诸法才生起）。如陶家做器皿，泥本来是一，随缘而器皿不同，以此比喻法本来不异，差异在于根机。所以唐译作："如来亦尔，于远离一切分别相无我法中，以种种智慧方便善巧，或说如来藏，或说为无我，种种名字各有差别。"

"种种智慧善巧方便"，《法华经》说："诸佛智慧甚深无量，其智慧门难解难入。"意思是如来具有权、实二智：种种智慧，是一切种智、根本实智；善巧方便，是后得权智。如来以实智证理，所以法无不彻；以权智说法，所以机无不宜。所说之法引导众生，都令到达一切智地。所以说如来为开引计我的诸外道而说如来藏，令他们离开不实的我见妄想，入三解脱门，速得无上菩提，岂同于外道所说的我？

三解脱：如来藏自性清净，所以叫空；离一切相，所以叫无相；众生自性本自具足，不假外求，所以叫无愿。旧注引《华严经》的三解脱：菩萨观缘起而知自性空，得空解脱；观十二有支自性灭，得无相解脱；入空而无愿求，唯为教化众生，得无愿解脱。然而《华严》是就观行而言，重点在行；这里是就本体而言，重点在理。名同义别，学者应当知道。

【经文】是故，如来、应供、等正觉作如是说如来之藏，若不如是则同外道。是故，大慧！为离外道见故，当依无我如来之藏。

【憨山记】这是总结成立正义，告诫人离开过失。意思是如来说法，是以实相印印定诸法，所以无论说什么，都与实相不相违背；外道没有这法印，所以说"若不如是则同外道"。唉！如来若没有这法印，也就同于外道了。这是要痛切地让识法的人警惕。如来藏是佛性在缠的名称，意思是众生的识藏就是如来，所以叫"如来之藏"，这是依主释。

【经文】尔时，世尊欲重宣此义，而说偈言：人相续阴缘与微尘，胜自在作心量妄想。

【憨山记】这是通颂无我。"人相续阴缘"，是凡夫所计五阴缘生的假我；微尘、胜性、大自在等，是外道所计的神我。这些都是心量的妄想分别，其实本来都无我。

憨山科判说：前面从初卷分别自性章以来到这里，通依三门辨邪正因果，其中第一段"破邪显正以显示常住真理"完毕。

## 转入行门：请说修行大方便

憨山科判说：以下依理勘订，以辨邪正二行，分四段。第一段总示正行的方法，又分四层。首先是能观之智，有四种。

【经文】尔时大慧菩萨摩诃萨观未来众生，复请世尊：惟愿为说修行无间，如诸菩萨摩诃萨修行者大方便。

【憨山记】这是正式请问修行。前面一路开示显理，已经究竟，所以大慧到这里请问行门。

有人问：前面所说的唯心识观、圣智三相、二无我观等，都是行门，为什么特别指这里为行？

答：此经直指一心，是顿教大乘，说生死即涅槃、烦恼即菩提，所以依五法、三自性、八识、二无我来说。如来藏随染净之缘成就世间出世间法：随业、爱、无知等染缘而起，如如、正智就成了名相、妄想，成为实我实法，所以有生死；若观缘生无性，名相、妄想就成了如如、正智，我与法都空，就是涅槃。唯是这一心的转变，更无别法。

前面虽然节节说观，那是世尊直指当机，要令他们当下顿见诸法缘生无性，顿悟无生，是借观来明心，重点在显理。如今从生灭会归一心真源，显理已到极处，所以大慧因前面的五无间种性，观察到未来众生也有可以成熟的顿根之人，所以这里特别请问"修行无间"，也如前面为诸菩萨所说的修行大方便门，令他们顿悟。前面是借观显理，这里是因机设行，所以重点在行。

依无间之理修无间之行，因无间之行证无间之理，唯此一心当下顿证，所以人、法、因、果都称"无间"，这实在是此经的宗趣。

## 修行者大方便：成就四法

【经文】佛告大慧：菩萨摩诃萨成就四法，得修行者大方便。云何为四？谓善分别自心现观，外性非性离生住灭，见得自觉圣智善乐，是名菩萨摩诃萨成就四法，得修行者大方便。

【憨山记】这是正式显示行相，能观之智有四种。未来的根机，若不是上根大智，不能顿入唯心法门，所以说"菩萨摩诃萨成就四法，得修行者大方便"。所以第二十七祖般若多罗嘱咐达摩说："震旦众生多有大乘根器，你应当去那里度人无量。"所以初祖西来，不立文字，直指人心，见性成佛。所以自曹溪以下，《传灯录》所载的，都是成就四法、得修行大方便的人。只要有丝毫不透，就是"有间"，不足以称为大方便。

【经文】云何菩萨摩诃萨善分别自心现？谓如是观三界唯心分齐，离我、我所，无动摇、离去来，无始虚伪习气所熏，三界种种色行系缚、身财建立、妄想随入现，是名菩萨摩诃萨善分别自心现。

【憨山记】这是解释四法中的第一句。意思是观三界诸法唯是一心，离我与我所，本来没有动作、去来之相；只因无始虚伪执著的习气所熏，所以三界种种色行系缚、身财住处，随着妄想分别而显现。唐译作"色行名言系缚"，意思是三界只以名言为体。若了达妄想无性，三界顿时空掉。这相当于空观。

【经文】云何菩萨摩诃萨善观外性非性？谓焰梦等一切性，无始虚伪妄想习因，观一切性自性。菩萨摩诃萨作如是善观外性非性（唐译云：如是观察一切法时，即是专求自证圣智），是名菩萨摩诃萨善观外性非性。

【憨山记】这是解释第二句。由于观察三界一切诸法既然唯心所现，那么虽有而不实，当体虚假，如阳焰、梦境、毛轮等，本自非有，只因妄想习气才有。由于妄想无性，一切法都无性了。无性所以是假，这相当于假观。

【经文】云何菩萨摩诃萨善离生、住、灭见？谓如幻梦一切性自他俱性不生，随入自心分齐故，见外性非性、见识不生及缘不积聚、见妄想缘生，于三界内外一切法不可得，见离自性生见悉灭，知如幻等诸法自性得无生法忍，得无生法忍已离生、住、灭见，是名菩萨摩诃萨善分别离生、住、灭见。

【憨山记】这是解释第三句。因为心与境相对待，所以生灭之见不忘。心本来无生，因境而有。如今观一切境界如幻如梦不实，那么诸法当体不生，因为是唯心所现，所以不生。既然唯心所现，外境顿时空掉，这是"他不生"。外境既空，内识就不起，所以说"见识不生"，这是"自不生"。既没有对着心的境，也没有了别境的心，当体无生，又以什么因缘能生？所以说"缘不积聚"，这是"不共生"。由于三界诸法都从缘起，所以说"见妄想缘生"，所以不是无因生。

如今观因缘体空，三界内外一切诸法都不可得。因为了达诸法无实体，生见全都灭了，就证得如幻境界，得无生法忍，离生灭之见。生灭既灭，寂灭现前，这相当于中道观。《中论》说：「因缘所生法，我说即是空，亦名为假名，亦名中道义」（大意：因缘所生的法，我说它就是空，也叫做假名，也就是中道之义）。

这里只是直观诸法唯自心现，缘生无性，顿证无生；就义理而言，类比于三观，不像其他经中所说的那样历别次第。上面三句属于因，下面一句属于果，因为意生身是因上面三观而证得的。

【经文】云何菩萨摩诃萨得自觉圣智善乐？谓得无生法忍，住第八菩萨地，得离心意意识、五法、自性、二无我相，得意生身。

【憨山记】这是解释第四句，圆成一心自觉圣智之义。意思是八地以前，还没有离开心意识，仍属于对治生灭的境界；到了得无生法忍、住八地以上，五法、三自性、八识、二无我一切都离开，正所谓"生灭灭已，寂灭为乐"，所以说"得自觉圣智善乐"。因为无生而无不生，所以得意生身，身与土、自与他，无障无碍。

## 意生身

【经文】世尊！意生身者何因缘？佛告大慧：意生身者，譬如意去迅疾无碍，故名意生。譬如意去石壁无碍，于彼异方无量由延，因先所见忆念不忘，自心流注不绝于身无障碍生。大慧！如是意生身得一时俱，菩萨摩诃萨意生身，如幻三昧力自在神通妙相庄严圣种类身一时俱生，犹如意生无有障碍，随所忆念本愿境界，为成就众生得自觉圣智善乐。

【憨山记】这是解释行成得果之相。唐译作："譬如心意于无量百千由旬之外，忆先所见种种诸物，念念相续疾诣于彼，非是其身及山河石壁所能为碍。意生身者亦复如是，如幻三昧力通自在诸相庄严，忆本成就众生愿故，犹如意去生于一切诸圣众中。"前面二无我中见法无我、住灌顶位、超佛子地、当得如来自在法身，以及唯心观成就、圣智三相等，节节都在说明这一义。

【经文】如是菩萨摩诃萨得无生法忍，住第八菩萨地，转舍心意意识、五法、自性、二无我相身，及得意生身，得自觉圣智善乐，是名菩萨摩诃萨成就四法得修行者大方便，当如是学。

【憨山记】这是总结劝修。《华严经》中九地圣人现十法界身，说法度生，庄严佛土，承事诸佛，作大佛事，就是所谓得意生身。这里说八地得意生身，是因为《华严》是依行布门的断证来说：由八地断俱生我执，已证平等真如，著于三昧之乐；能舍三昧之乐，发度生之愿，所以能现十法界身，说法度生，如意自在，名为意生身，所以到九地才得。

这里是就顿机而言：只要能一念顿证无生，离开心意识境界，从凡夫位就进入佛的境界，对应于位次，正当八地而已，并不是说渐断渐证、依次到达。所以下文说："初地即为八，无所有何次？"所谓得诸法正性的人，不从一地到另一地，这里只是就通相来说。正所谓顿悟一心，顿登佛地；虽说诸地，只是借位次来显示悟的深浅，并不是实有阶级次第。古德说：「圣谛亦不为，何阶级之有」（大意：连圣谛都不去作，哪里还有什么阶级）？
