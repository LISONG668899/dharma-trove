# 荷泽神会《菩提达摩南宗定是非论》下篇

开元二十年（732）滑台大会上，荷泽神会大师与崇远法师论辩，弟子独孤沛编集成论。题解与上卷、下卷前半的论辩部分，见上篇。本篇接续下卷后半：神会宣说般若法门与"无念"、高声说偈发愿，以及独孤沛的赞论与后序赞颂。底本为胡适先生据敦煌写本 P.2045、P.3488 校写之本。

## 下卷（续）

### 修般若波罗蜜

远法师问："禅师修什么法？行什么行？"

和上答："修般若波罗蜜法，行般若波罗蜜行。"

远法师问："为什么不修其他的法、不行其他的行，唯独修般若波罗蜜法、行般若波罗蜜行？"

和上答："修学般若波罗蜜法，能摄一切法；行般若波罗蜜行，是一切行的根本。"

```
金刚般若波罗蜜，最尊最胜最第一。
无生无灭无去来，一切诸佛从中出。
```

大意是：金刚般若波罗蜜，最尊贵、最殊胜、最为第一；它无生无灭，无去无来，一切诸佛都从中出生。

和上说："告诉各位知识，如果想要了达甚深法界，直入一行三昧，先须诵持《金刚般若波罗蜜经》，修学般若波罗蜜法。

"为什么？诵持《金刚般若波罗蜜经》的人，应当知道这人不是从小功德来的。譬如帝王生了太子，如果说他和普通人一样，那是没有的事。为什么？因为他是从最尊最贵的地方来的。诵持《金刚般若波罗蜜经》的人也是这样。

"所以《金刚般若波罗蜜经》说：'不于一佛、二佛、三四五佛而种善根，已于无量百千万亿佛所种诸善根，闻是章句，乃至一念生净信者，如来悉知悉见。'何况书写、受持、读诵、为人演说？

"所以《胜天王般若经》中，胜天王问：'菩萨摩诃萨怎样学般若波罗蜜，通达甚深法界？'佛告诉胜天王：'大王，就是如实。''世尊，什么是如实？''大王，就是不变异。''世尊，什么是不变异？''大王，所谓如如。''世尊，什么是如如？''大王，这可以用智慧去知，不是言语所能说的。为什么？它超过一切文字，无此无彼，离相无相，远离思量，超过觉观的境界，这就是菩萨了达甚深法界。'

"般若波罗蜜，没有一法可以作它的譬喻。如果善男子、善女人信受《金刚般若波罗蜜经》，所获得的功德不可思量。假如这功德有色有形，整个虚空界也容纳不下。以般若波罗蜜如实见，名为证；以智慧通达，名为至。假使一切众生都住于十地，进入种种三昧去观察，也决定不能测量如来。

"善知识，必须诵持《金刚般若波罗蜜经》。这部经号称一切诸佛之母，也是一切诸法的祖师。恒沙三昧、八万四千诸波罗蜜门，都从般若波罗蜜生出，所以必须诵持此经。

"为什么？般若波罗蜜是一切法的根本。譬如大摩尼宝在大海之中，大海中所有的一切宝物，都依靠摩尼宝的力量而得以增长。为什么？因为这大宝有威德之力。修学般若波罗蜜也是这样，一切智慧都依靠般若波罗蜜而得以增长。

"如果不诵般若波罗蜜经，就像皇太子舍弃他的父王，到别人那里去求得王位，那是没有的事。所以《小品般若经》说：'再者，须菩提，其他诸经不能到达一切智。如果菩萨舍弃般若波罗蜜而去读诵其他经典，这菩萨就是舍本而取枝叶。'

"所以《胜天王般若经》中，佛告诉胜天王：'菩萨摩诃萨修学一法而通达一切法，那就是般若波罗蜜。'般若波罗蜜又号称一切诸佛的秘密藏，又号称总持法，也是大神咒，是大明咒，是无上咒，是无等等咒，能除一切苦，真实不虚。三世诸佛都依般若波罗蜜多，得阿耨多罗三藐三菩提。

"所以《金刚般若波罗蜜经》说，像恒河中的沙，一粒沙为一条恒河，以那么多恒河沙数的三千大千世界的七宝布施，不如在这部经中乃至受持四句偈等，这功德胜过前面的福德，前者百分不及一，百千万亿分，乃至算数譬喻都不能及。

"各位学道的人，《金刚般若波罗蜜经》所在之处，一切世间的天、人、阿修罗都应当供养。为什么？因为这部经所在之处，那里就尊贵；经在人身上，人也就尊贵。为什么？因为诵持《金刚般若波罗蜜经》的人，能成就最上第一希有之法。处处只要有《金刚般若波罗蜜经》的经卷，一切诸佛都恭敬这般若波罗蜜经卷，就像佛弟子恭敬佛一样。为什么？经中说：'诸佛之师，所谓法也。'因为法是常住的，诸佛也是常住的。

"所以《金刚般若波罗蜜经》说：早晨以恒河沙数的身命布施，中午又以恒河沙数的身命布施，傍晚也以恒河沙数的身命布施，像这样经过无量百千万亿劫以身命布施，不如听闻这部经典，信心不逆，何况书写、受持、为人解说？

"所以《金刚般若波罗蜜经》是如来为发大乘心的人说的，为发最上乘心的人说的。为什么？譬如大龙王不在阎浮提降雨，如果在阎浮提降雨，一切都会像漂浮的落叶一样被冲走；如果降雨在大海中，大海不增不减。所以大乘的人、最上乘的人，听说《金刚般若波罗蜜经》，不惊、不怖、不畏、不疑，应当知道这善男子、善女人从无量久远劫以来，常供养无量诸佛及诸菩萨，修学一切善法，今天得以听闻般若波罗蜜，才不生惊疑。

"所以经中说，如果有人用一切珍宝造七宝塔，充满三千大千世界，高到梵天，不如诵持《金刚般若波罗蜜经》，修学般若波罗蜜。

"如果有人教化三千大千世界微尘数的众生，全都证得须陀洹果，不如诵持《金刚般若波罗蜜经》；教化他们全都证得斯陀含果、阿那含果、阿罗汉果、辟支佛道，都不如诵持《金刚般若波罗蜜经》。如果有人教化三千大千世界微尘数的众生，全都证得十信心、十住心、十行心、十回向心，也不如诵持《金刚般若波罗蜜经》。为什么？因为这部经有不可思议、不可称量、无有边际的不可思议功德，能成就诸佛甚深无上的智慧。

"所以告诉各位知识，如果有人犯了阿鼻地狱的一切极恶重罪，无处忏悔、不能消灭，必须诵持《金刚般若波罗蜜经》，修学般若波罗蜜，应当知道这人的罪就会消灭。为什么？譬如一切杂色的鸟飞到须弥山下，就与山同成一种颜色。为什么？因为这山有威德力。诵持《金刚般若波罗蜜经》的威德力也是这样。

"各位知识，如果诵持《金刚般若波罗蜜经》而还不能进入一行三昧，是因为前世有重罪业障，更须诵持此经。由于此经的威德力，感得世人的轻贱，现世轻受。因为轻受，因为被轻贱，前世的重罪业障就消灭了；因为消灭了，就能进入一行三昧。

"所以《胜天王般若经》中，佛告诉文殊师利：'假如把四天下全都化为微尘，有那么多微尘数的诸佛如来，如果有恶人把他们全部杀害，文殊师利，你认为怎样？这人的罪多不多？'文殊师利菩萨对佛说：'世尊，这罪不可听闻，不可计算，不可思量。'佛告诉文殊师利菩萨：'如果又有人障碍这部经典，毁谤不信，他的罪比前者还重，前者百分不及一，千分万分不及一，乃至算数譬喻都不能及。'

"所以《金刚般若波罗蜜经》中，佛自己说：我回忆过去无量阿僧祇劫，在燃灯佛之前，得以遇到八百四千万亿那由他诸佛及佛弟子，一一供养承事，没有空过的，却不能得到菩提授记。为什么？因为有所得。后来在燃灯佛那里得到菩提授记，是因为读诵《金刚般若波罗蜜经》，修学般若波罗蜜，获得无所得，才得到菩提授记，如今得以成佛，号释迦牟尼。如果拿供养诸佛的功德，与诵持这部《金刚般若波罗蜜经》并为他人宣说所得的功德相比较，前者百分不及一，百千万亿分，乃至算数譬喻都不能及。

"所以《胜天王般若经》说：'大王，譬如四大依虚空而立，虚空却再没有所依。烦恼也是这样，依法性而住，法性却无所依。大王，菩萨摩诃萨学般若波罗蜜，就是如实观知。'

"《胜天王般若经》又说：以无量阿僧祇劫三千大千世界的微尘，一粒微尘为一个三千大千世界，那么多微尘数三千大千世界中充满七宝，堆积到色究竟天，布施给微尘数三千大千世界那么多的圣人，功德多不多？文殊师利菩萨说：'世尊，前面的福德已经不可思量，何况这个功德？'佛告诉文殊师利菩萨：'如果善男子、善女人流通这部般若波罗蜜经，为他人宣说，这功德胜过前者，前者百分不及一，千万分不及一，乃至算数譬喻都不能及。'"

### 无念即是般若波罗蜜

"所以《金刚般若波罗蜜经》说：'须菩提，若有人以满无量阿僧祇世界七宝持用布施，若有善男子、善女人发菩萨心者，持于此经，为人演说，其福胜彼。'

"怎样为人演说？不取于相。

"怎样是不取于相？就是如如。

"怎样是如如？就是无念。

"怎样是无念？就是不念有无，不念善恶，不念有边际、无边际，不念有限量、无限量；不念菩提，不以菩提为念；不念涅槃，不以涅槃为念，这就是无念。这无念，就是般若波罗蜜；般若波罗蜜，就是一行三昧。

"各位善知识，如果还在修学的阶段，心中若有念头生起，当下就觉照它。起心既然灭了，觉照也自然消亡，这就是无念。这无念，就是没有一个境界；如果有一个境界，就与无念不相应。所以各位知识，如实见的人，了达甚深法界，这就是一行三昧。

"所以《小品般若波罗蜜经》说：'善男子，这就是般若波罗蜜，就是对一切法无所念。我们住于无念法中，得到这样的金色身、三十二相、大光明、不可思议的智慧、诸佛无上的三昧、无上的智慧，穷尽一切功德的边际。这些功德，诸佛来说尚且说不尽，何况声闻、辟支佛能知道？'

"见无念的人，六根不被染污；见无念的人，趣向佛的知见；见无念的人，名为实相；见无念的人，就是中道第一义谛；见无念的人，恒沙功德一时平等具备；见无念的人，能生一切法；见无念的人，能摄一切法。"

### 和上高声说偈并发誓愿

和上在大众中的法座上高声说：

```
我今能了如来性，如来今在我身中。
我与如来无差别，如来即我真如海。
```

大意是：我现在能了知如来之性，如来此刻就在我身中；我与如来没有差别，如来就是我的真如之海。

和上又发愿说：

"敬白十方诸佛、诸大菩萨摩诃萨、一切贤圣：今天我舍弃身命，编修这部'顿悟最上乘论'，愿一切众生听到赞叹金刚般若波罗蜜，决定深信，堪能不退。

"今天舍弃身命，愿尽未来劫常常赞叹金刚般若波罗蜜，愿一切众生听到赞叹般若波罗蜜，就能读诵受持，堪能不退。

"今天舍弃身命，愿尽未来劫常常赞叹金刚般若波罗蜜，愿一切众生听到赞叹般若波罗蜜，就能决定修行般若波罗蜜，堪能不退。

"愿我尽未来劫常常舍弃身命供养金刚般若波罗蜜；愿我堪能成为般若波罗蜜之主，常为一切众生宣说金刚般若波罗蜜；愿一切众生听说金刚般若波罗蜜，获得无所得！

"愿我尽未来劫为一切众生常常舍弃身命，守护金刚般若波罗蜜；愿一切众生依靠般若波罗蜜，获得无所得，一时成佛！"

### 生灭可灭不可灭

和上问远法师："您曾讲过《大般涅槃经》吗？"

法师说："讲过《大般涅槃经》几十遍了。"

和上说："一切大小乘经论都说，众生之所以不得解脱，是因为有生、灭二心。《涅槃经》又说：'诸行无常，是生灭法；生灭灭已，寂灭为乐。'请问：生和灭，可灭还是不可灭？是拿生去灭灭，还是拿灭去灭生？是生能自己灭生，还是灭能自己灭灭？请法师一一详细回答。"

法师说："我也见到诸经论这样说，至于这个道理，实在不能明了。禅师如果明了这个道理，请为大众说。"

和上说："我不推辞为大家说，只怕没有人能理解。"

法师说："在场道俗有一万多人，难道没有一个人能理解？"

和上说："看你见不见。"

法师说："见的是什么？"

和上说："果然不见！"

法师听了这话，结舌无对。这不只是他一人理屈词穷，连他的门徒也都失了志气。胜负既已分明，道俗大众嗟叹而散。

## 独孤沛赞论

和上以禅定之池、智慧之水，长久滋润心源；以戒律之藏、慈悲之灯，圆满照明身心。他指授不可思议之法，为而无所为；称赞离相法门，说而无所说。六念、九次第定，实理在心中融通；三藏、五乘，真如本体都已了解。所以他一入讲论之处，邪见的旗幢必定被摧倒；判定是非的关头，胜利的旗幡常常竖立。他就像空山中的回响，随声应答而无所起；又像明镜照形，鉴照有色之物而现出形相。

某乙（独孤沛自称）忝列学侣，滥充门徒，不自量自己的庸陋，斗胆申述愚拙之见。

这些年修习道业，希望有所得，却总是失去；听了这个法门，才知道止息追求，反而得到。依着无住之理，理上住的意义宛然分明；起有见之法，法中的见心又在哪里？迷恋快乐的时候，快乐中的痛苦是往昔；觉悟痛苦的时候，痛苦中的快乐是今日！常恨不曾遇到激励，如今更得以赞扬，于是恭谨地记录所闻，珍藏在箱箧之中。

```
发心毕竟二不别，如是二心先心难。
自未得度先度他，是故我礼初发心。
初发已为天人师，胜出声闻及缘觉。
如是发心过三界，是故得名最无上。
```

大意是：初发心与究竟成佛，二者没有分别，而两心之中，初发之心更难。自己还没有得度，先去度他人，所以我礼敬初发心。初发心时就已是天人之师，胜过声闻和缘觉；这样的发心超过三界，所以名为最无上。（此偈出自《涅槃经》迦叶菩萨赞佛之偈，《坛语》中也曾引用。）

## 后序与赞颂

所谓《菩提达摩南宗定是非论》，是叙述六代大德师师相授，法印相传，代代相承，本宗没有更替。自达摩大师以后，一代只许一人；中间如果有两三人，就是谬行佛法。何况如今天下教禅的人无数，真正学禅的人却极少，都没有禀承，凭什么立教？只是拿鸡冒充凤凰来欺诳人，拿蒲草冒充干肉来欺骗人，把鱼目装饰成珍珠，把夜光当作宝贝。

我们的和上，正处在正法衰微之日、邪法纷乱之时，知道要用后医的根本药方，就应当丢弃先医的乳药（《涅槃经》中的譬喻：先医以乳药治一切病，后医知病而用药），重新弘扬真实的教法，止息世间的纷纭。他知道摸珠的人所摸的不是真珠，只是空自寻觅水中之月；见到学道的人所学的不是真道，只是徒然走向宝山而空手。这实在是玩弄影子而劳累形体，扬起声音而想止住回响。

所以编修这部论，略作指南，使大道遍及苍生，正法流布天下。这部论先陈述激烈论辩的问答之事，使学人在疑惑处得以辨明；后叙述师资传授的话语，以断除疑惑。仔细审察这部论，真是不可思议。听到的人都说从前没有听过，见到的人都说从前没有见过。这就像宅中的宝藏忽然自己打开，苦海中的渡船不期而至。

唉！六代传法的信物，如今在韶州；四众学徒，却空自游走在嵩山。这真可说是鱼游在水中，却到高山上去张网！

当时有同学互相议论说："嵩山普寂和上，如同一佛出世，是帝王之师，天下仰慕其德，四海归依于他。什么人敢说他是？什么人敢说他非？"

同学中有一位长老回答说："住口！这样的事不是你所能知道的，这样的事不是你所能企及的。你只知道看重耳闻而轻视眼见，看重古人而轻视今人！只认识涓涓细流，哪里知道大海！我们的和上承接六代之后，付嘱分明，所立的宗旨本体又与诸家不同。"

众人弹指，都说："善哉！有什么差别？"

长老答道："不必再细说了。和上的言教，指授甚深，不可以用智慧去知，不可以用心识去识。即使是三贤十圣，谁能辨其深浅？声闻缘觉，也不知它的边际。开元二十年正月十五日，和上与远法师论议，心地略为开显，气势凌云，发言惊众，道俗都互相说'这是达摩的后身！'所有对答的宏论，于是编成了这部论。"

论中说："今天设无遮大会，不是为了功德，是为天下学道的人确定是非，为天下用心的人辨明邪正。"是非邪正，都明文记载；又叙述本宗的传承，传给后代。普寂和上虽然在世时也广济众生，但因为与曹溪不同，所以在南宗之中叙述此论。今日很少听到这样的事，欢喜踊跃，难以自胜，姑且自不量力，写成赞颂：

```
论之标首，达摩大师。次叙正宗，光赞本枝。
梁朝兴日，天竺来仪。遗言我法，六后陵迟。
其道玄远，人莫能知。唯我和上，今日行之。
```

大意是：论的开篇，标举达摩大师；接着叙述正宗，光大赞扬本宗的根本与枝叶。梁朝兴盛之时，达摩从天竺来到中土，留下预言：我的法到第六代之后将会衰微。此道玄远，无人能知，唯有我们的和上，今日行持它。

```
论称六代，代有一人。但以心契，法无有亲。
唯有大事，四海之珍。递相付嘱，非不殷勤。
袈裟表信，息世疑津。天下无比，谁与为邻？
```

大意是：论中说六代祖师，每代只有一人；只以心相契合，法上没有亲疏。唯有这件大事，是四海之内的至宝，代代付嘱，无不殷勤；以袈裟表示凭信，止息世人的疑惑。此法天下无比，谁能与之并列？

```
大乘大论，流行四方。法幢再建，慧日重光。
爱河舟楫，苦海津梁。闻者见者，得悟真常。
大道行矣，正教其昌！无我无人，善恶不亡。
```

大意是：这部大乘的大论，流行于四方；法幢重新竖立，慧日再放光明。它是爱河中的舟楫，苦海上的桥梁，听到的、见到的人，都能悟得真常。大道得以通行，正教从此昌盛！其中无我无人，而善恶因果并不失坏。

```
敬寻斯论，妙理玄通。先陈问答，后叙正宗。
无念无能，言空不空。非色非相，无德无功。
达人乃见，有缘始逢。禅门顿教，诸家不同。
```

大意是：恭敬地探寻这部论，妙理玄妙通达。先陈述问答，后叙述正宗。所说的是无念、无所能，说空而不落于空；非色非相，无德无功。唯有通达的人才能见到，有缘的人才能遇到。禅门的顿教，与诸家都不相同。

```
论之兴也，开元二十。比日陵迟，今年法立。
本元清净，非关积习。彼岸坐登，禅门顿入。
德超河洛，芳流京邑。朗月孤悬，众星无及。
```

大意是：这部论的兴起，在开元二十年。往日佛法衰微，今年正法建立。本来就是清净的，与积累修习无关；彼岸当下就能登上，禅门可以顿然契入。和上的德行超越河洛，芳名流传京城，就像一轮明月孤悬天空，群星都无法企及。

《菩提达摩南宗定是非论》一卷终。
