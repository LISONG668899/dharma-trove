# 为霖道霈《禅海十珍》（七）临济法语

## 第七珍　镇州临济义玄和尚法语

如今学人，首先要明白自己真正的见解。若得了自己的见解，就不被生死所染，去住自由，不必求那殊胜，殊胜自然具备。

如今的道流，要不滞于迷惑，要用就用。如今不得，病在哪里？「病在不自信处。」自信不及，就忙忙乱乱地随一切境转。

大德！若能歇得念念驰求之心，便与祖师无别。你想认识祖师吗？就是你眼前听法的那个。学人信不及，就向外驰求，求得的也只是文字学，与那祖师相去甚远。不要错了！

大德！此时不遇，万劫千生轮回三界，追逐好恶之境，到驴牛肚里去了。如今诸人与古圣有什么分别？你欠少什么？六根的神光，从未间断。若能这样见，就是一生无事之人。

「一念净光，是汝屋里法身佛；一念无分别光，是汝报身佛；一念无差别光，是汝化身佛。」（大意：一念清净之光，是你家里的法身佛；一念无分别之光，是你的报身佛；一念无差别之光，是你的化身佛。）

这三身，就是今天眼前听法的人。因为不向外求，才有这三种功用。依教中说，三身被称为极则；依山僧说，三身只是名言。所以说：「身依义而立，土据体而论。」（大意：佛身是依义理而安立的，佛土是依本体而论说的。）法性身、法性土，明明知道都是光影。

〔存疑："身依义而立，土据体而论"二句出自旧论，临济引来说明三身三土都是名言施设；原句出处与确切含义，未能考定。〕

大德，要认取那玩弄光影的人，他是诸佛的本源，是一切道流的归宿之处。

大德，四大之身不会说法听法，虚空不会说法听法，是你眼前历历孤明、没有形段的那个会说法听法。所以山僧对你们说：五蕴身田内有一个无位真人，堂堂显露，没有一丝一毫的间隔。为何不认取？

「心法无形，通贯十方。在眼曰见，在耳曰闻，在手执捉，在足运奔。心若不生，随处解脱。」（大意：心法没有形相，通贯十方；在眼叫见，在耳叫闻，在手执捉，在脚奔走。心若不生，随处都是解脱。）

山僧的见处：坐断报身、化身佛的头；十地满心的菩萨，好比雇工；等觉、妙觉，如披枷带锁；罗汉、辟支佛，犹如粪土；菩提涅槃，是拴驴马的橛子。为什么这样？因为不通达三大阿僧祇劫本空，才有这些障隔。若是真正的道流，全都不是这样。

如今略为诸人大约说破，你们自己看看时光远近，可惜啊！各自努力。珍重！

## 道霈论曰

滹沱老人（临济）的法语，《景德传灯录》在"诸方广语"中只录了这一篇，因为这是根本之言，留作后人入道的捷径。

若领悟不真，就堕于古人所呵斥的"认识神"，那是后人的过失，不是临济的过错。这就在于智者具足择法之眼，善自拣择了。

## 译者附说

临济这篇法语，核心只有两个字：自信。"病在不自信处"，所以向外驰求；"歇得念念驰求心，便与祖师不别"。他把三身佛、无位真人都落在"目前听法底人"身上，再把十地、等妙二觉、菩提涅槃一齐扫倒。

道霈的论很短，却点了最要紧的一处：读这篇最容易犯的病，是把"目前历历孤明"的那个认作真我，也就是"认识神"。长沙景岑有偈："学道之人不识真，只为从前认识神。"憨山在《观老庄影响论》里也引过这首偈。临济说的"弄光影人"，不是光影本身；能分清这一点，才算读懂了这一篇。道霈把临济放在石头与洞山两篇曹洞宗典之间，也可见他作为曹洞宗匠，对临济家风的尊重。
