# 憨山《观楞伽经记》（二十四）三种意生身与五无间

【经文】观楞伽阿跋多罗宝经记卷第五。宋天竺三藏沙门求那跋陀罗译。明建邺海印沙门释德清笔记。一切佛语心品第三之上

憨山科判说：以下举果验因，以显示一乘真因之相，分两段。首先举出意生身的真果之相。

## 意生身分别通相

【经文】尔时，世尊告大慧菩萨摩诃萨言：意生身分别通相，我今当说。谛听，谛听！善思念之。大慧白佛言：善哉！世尊！唯然受教。

【憨山记】这是再次辨明果德，以验证真因之相。由于前面经文第二卷开头，大慧问无间行，如来回答说：成就四法，得修行者大方便，乃至得无生法忍，住第八地，得离心意识、五法、自性、二无我相，得意生身。其次从说因缘以下，直到经文第二卷终，通明缘起妄想无性，以显示离心意识、五法、三自性、二无我相。广释无间大方便行之后，意在说明行成得果，所以这里就说意生身的差别相。

前面世尊自己解释说："意生身者，譬如意去，迅疾无碍，故名意生。"因为前面只说是八地所得，所以名为通相；如今说地地都能得，所以说"分别"，是通相中的差别相，有三种。

【经文】佛告大慧：有三种意生身。云何为三？所谓三昧乐正受意生身、觉法自性性意生身、种类俱生无行作（二译皆云无作行）意生身。修行者了知初地上上增进相，得三种身。

【憨山记】这是列出意生身差别的名称。三昧乐正受意生身，是从初地到七地所得；觉法自性性意生身，是从八地到十地所得；种类俱生无行作意生身，是从等觉入妙觉所证。其相自有深浅差别。

梵语三昧，意为正定，因为智体不动，名为正定，以拣别偏邪，就是所谓首楞严大定。正受，因为不受诸受，名为正受，是正定中的受用。因为以三昧之乐为受用，所以说"三昧乐正受"。

【经文】大慧，云何三昧乐正受意生身？谓第三、第四、第五地三昧乐正受故，种种自心寂静安住，心海起浪，识相不生，知自心现境界性非性，是名三昧乐正受意生身。

【憨山记】这是解释第一种身相。意思是初登地时证平等真如，直到七地穷尽真如之际，已经舍了藏识，所以说"种种自心寂静"；七识的波浪不生，所以说"安住心海起浪，识相不生"；已经断了俱生我执，我执既断，境界就无所依，所以说"知自心现境界性非性"。这是由定力所维持的，也名为力持身，所以说三昧乐正受意生身。七地证得此身，而经中说三、四、五地，是举中间以概括前后。

【经文】大慧！云何觉法自性性意生身？谓第八地观察觉了如幻等法，悉无所有身心转变（唐译云了法如幻皆无有相心转所依），得如幻三昧及余三昧门无量相力自在明（唐译云能现无量自在神通），如妙华庄严迅疾如意，犹如幻梦水月镜像，非造非所造如造所造，一切色种种支分具足庄严（魏译云非四大生似四大相具足身分），随入一切佛刹大众，通达自性法故，是名觉法自性性意生身。

【憨山记】这是解释第二种身相。意思是八地菩萨证一心真如，进到九地发起真如之用，得如幻三昧，在一心转变中能现无量自在神通，一时俱发，如花开放，譬如意念穿过石壁毫无障碍，所以说"迅疾如意"。非身而现身，所以如幻梦、水月、镜像；非四大所生而似四大之相，身分宛然，所以说"具足庄严"。进到十地，随所忆念的本愿化度众生，所以说"随入一切佛刹大众"；十方诸佛所有的法云法雨都能含受，所以说"通达自性法故"。这名为觉法自性性意生身。

【经文】大慧！云何种类俱生无行作意生身？所谓觉一切佛法缘自得乐相（唐译云了达诸佛自证法性），是名种类俱生无行作意生身。

【憨山记】这是解释第三种身相。前面十地菩萨对于诸佛之法只能领受而已；如今从等觉入妙觉，就能了达诸佛自证的法相，已经得到诸佛自觉圣智的善乐，深入妙庄严海，又逆流而出，现十法界身，无思而应，就是所谓"妙相庄严圣种类身一时俱现"，犹如意生，身土自他没有障碍，所以说"觉一切佛法，种类俱生无行作意生身"。

"缘自得乐相"，就是所谓"生灭灭已，寂灭为乐"，是诸佛自证所受用的法乐。所以观音大士以如幻闻熏闻修金刚三昧之力，生灭既灭，寂灭现前，忽然超越世间出世间，上与十方诸佛同一慈力，下与六道众生共一悲仰，所以能一身普现，得三十二应、四不思议、十四无畏、十九说法，正是得了这种类俱生无行作意生身。

【经文】大慧，于彼三种身相观察觉了，应当修学。尔时，世尊欲重宣此义，而说偈言：非我乘大乘（魏译我乘非大乘，唐译我大乘非乘），非说亦非字，非谛非解脱，非无有境界。然乘摩诃衍，三摩提自在，种种意生身，自在华庄严。

【憨山记】这首偈总结前面所说"大乘非乘"，只是所证的三种意生身而已，并不是实有大乘可得。

外道与二乘修行得不到如来的真三摩地，只因名言习气，对所取的妄有证得，所以外道妄立神我冥谛，二乘妄取孤调解脱以为究竟。所以世尊一路破斥他们的偏邪，显示真因正果。到这里广明三种意生身之后，以偈总结前义说：我说的大乘，不是实有大乘可乘，也不是言说文字所能到达，也不是外道的冥谛神我，也不是二乘的孤调解脱；一切都离开，却也不是断灭，所以说"非无有境界"。我所乘的，只是乘摩诃衍止观之力，以此证得三种意生身，如此而已。

前面说外道有四种涅槃，而我所说的"妄想识灭名为涅槃"，可以以此来证明。这就是转八识成四智，如今把四智收束为三身：

三昧乐意生身，是依第六识起人法二空之智，证平等真如，转第七识为平等性智，这就是从五蕴妄身证得素法身。然而这法身还不能纯净，入定就明，出定就昧，所以只得三昧乐正受意生身。

到了舍弃三昧之乐，进入九地、十地，广修称真度生的事业，观机说法，利乐有情，万行庄严，这是从平等真如发起大利用，是依平等性智起妙观察智，得如幻三昧，应十地的根机，现广大尊特的他受用报身，所以说觉法自性性意生身。所以如幻梦、水月、镜像，因为万德圆备，所以如妙华庄严的实报身。

至于以金刚心断那生相无明，转第八识成大圆镜智，那么前五识也一时俱转，成为成所作智，就在那有作之中成就无作，所以说种类俱生无行作意生身。因为依大圆镜智平等显现，所以千种万类之身一时普应。到这里，没有一物不彰显毗卢遮那的妙体，没有一时不修普贤的行门，这是从法身、报身二身而垂示他受用身以及大小随类化身。

这是由于转心、意、意识、藏识为大涅槃，四智三身一念顿得，这岂是那些外道、二乘以无因、邪因所能得到的？所以这里总结说"我大乘非乘"等。一路所谈，到这里汇聚到了极处，修行人应当认识这通途的大旨，请深观之，决不可执守愚昧，于宗通与说通有所偏废。因为前面说意生身是依无间行而得的，所以下面问五无间行，正是显示转心、意、意识、藏识为大涅槃。

以上辨明真果之相。

## 内五无间：真因之相

憨山科判说：以下显示五无间行，以辨明真因之相。

【经文】尔时大慧菩萨摩诃萨白佛言：世尊！如世尊说：若男子女人行五无间业，不入无择（魏译云无间）地狱。世尊！云何男子女人行五无间业，不入无择地狱？

【憨山记】由于前面问修无间行，佛回答以四种法，就得意生身；这里广明三种意生身、辨明果相之后，随之而问无间行的差别相，以辨明真因。大慧的意思是：五无间业是入无间地狱之因，而世尊又说行五无间业有不入无间地狱的，不知是什么样的五无间业不入无间地狱？所以特别请问，要让修行人知道如何选择。而且意在显示：依智而得意生身，依识而得五蕴身；如今转识成智，就是那五蕴妄身转为意生法身。所以依次说明。

【经文】佛告大慧：谛听谛听，善思念之，当为汝说。大慧白佛言：善哉世尊！唯然受教。佛告大慧：云何五无间业？所谓杀父母，及害罗汉，破坏众僧（魏唐二译皆云破和合僧），恶心出佛身血。大慧！云何众生母？谓爱更受生贪喜俱（魏译云更受后生贪喜俱出），如缘母立（二译此下俱有何者为父四字），无明为父，生入处聚落，断二根本，名害父母。

【憨山记】这是说贪爱与无明是生死之根，能断这两者，生死就永断，顿证一乘，就能把五蕴业识之身转成清净法身，所以名为杀父母，是无间行。

"爱更受生"，是发业的无明，意思是爱欲为生死的根本。"贪喜俱出"，是润生的无明，意思是将要受生时，以爱为因缘，见到所爱的境界，又发爱涎，取所爱之境，流爱成种，纳想成胎，所以说"贪喜俱出"。因为贪依爱而生，结生相续，所以说"如缘母立"。然而单有爱不能生，要与润生无明和合，才能生起名色之芽，成就六种受用之根，所以说"无明为父，生入处聚落"。"入处"是六入处、十二处；"聚落"是五蕴身。

由于痴与爱发业润生，所以有生死，这样生死实在是从这两个根本而生；若能断它们，生死顿断，就在这五蕴业身上，当下转为清净法身了。

【经文】彼诸使不现，如鼠毒发，诸法究竟断，彼名害罗汉。

【憨山记】这是说能断微细的结习，所以名为害阿罗汉，是无间行。旧注说：老鼠咬人，疮虽已愈，其毒遇雷就发作；阿罗汉的诸使也是这样，虽隐而不现，遇缘就发。能断微细的习气使，名为害罗汉。阿罗汉之名，正是因为未断习气而立的；如今能断那习气，阿罗汉就当得如来法身了。

【经文】云何破僧？谓异相诸阴和合积聚，究竟断彼，名为破僧。

【憨山记】这是说破诸阴的和合，名为破僧，是无间行。"异相"就是色、受、想、行、识。诸阴和合积聚而成为人；僧以和合为义，这里把阴称为僧，是因为它虚妄和合，所以能断那诸阴的聚集，名为破和合僧。诸缘和合既断，本有的法身就自然显现，这就是即缘生而证实相。

【经文】大慧！不觉外自共相，自心现量七识身，以三解脱无漏恶想，究竟断彼七种识佛（二译皆作八识），名为恶心出佛身血。

【憨山记】这是说转识成智，所以名为出佛身血，是无间行。第八识原本是诸佛如来的根本法身，只因被前七转识妄执实有的见习所染污，所以称为"血"。如今能以空、无相、无愿三种无漏智，断那七识的染污无知，名为出佛身血，那第八识就转为根本正智，而得如来清净法身了。

【经文】若男子、女人行此无间事者，名五无间，亦名无间等。

【憨山记】这是总结无间行。意思是能行这五无间，就名为证无间等的真实之法。所以魏译作"名证如实法"，唐译作"即得现证实法"。

## 外五无间

【经文】复次，大慧！有外五无间今当演说，汝及余菩萨摩诃萨闻是义已，于未来世不堕愚痴。

【憨山记】这是防止邪见。意思是行内五无间，就证圣智法门；行外五无间，必定入无间地狱。所以世尊又说外五无间业，告诫后世众生知道这个道理，不堕于愚痴的迷惑。

【经文】云何五无间？谓先所说无间。若行此者，于三解脱一一不得无间等法。

【憨山记】这是说行外五无间，不但在三解脱上一一都不能证真实之法，还要入无间地狱、受无间之苦。"先所说"，就是指上面世俗所说的五无间之事。

【经文】除此已，余化神力现无间等，谓声闻化神力、菩萨化神力、如来化神力。为余作无间罪者，除疑悔过，为劝发故，神力变化现无间等，无有一向作无间事不得无间等。

【憨山记】这是解释疑问。恐怕有人怀疑：可有造五无间业而不入无间地狱的？所以唐译解释说："唯除如来、诸大菩萨及大声闻，见其有造无间业者，为欲劝发，令其改过，以神通力示其同事，寻即悔除，证于解脱。"这些都是化现，不是实造；没有一向实造无间之事而不入无间地狱的。这是说因果报应没有一毫差错。

【经文】除觉自心现量，离身、财妄想，离我、我所摄受；或时遇善知识，解脱余趣相续妄想。

【憨山记】这是说能观罪性本空，也能解脱五无间。意思是凡是造五无间业的，没有不入地狱的；唯有了悟自心现量，通达身心本空，离开我与我所分别执著的人；或者是多生曾种般若之缘、因缘成熟，如今遇到善知识开导，顿悟自心，离开诸妄想，永断诸趣生死根本的人，这些人不堕；除此以外，没有不堕的。

【经文】尔时，世尊欲重宣此义，而说偈言：贪爱名为母，无明则为父，觉境识为佛，诸使为罗汉，阴集名为僧，无间次第断。

【憨山记】这是颂以无间之智次第断那无明、贪爱等，所以是无间行。

【经文】谓是五无间，不入无择狱。

【憨山记】长行的正意是说明五无间行能证真实之法，只是因为解释疑问才说外五无间，所以这里不颂外五无间。

憨山科判说：以上两章，举果验因，显示一乘真因之相，完毕。以上大科第二"返妄归真"中，第一段"辨邪正，顿示一乘理行因果相"里的"辨明因地心"已经完毕，经文从初卷五法章开始，到这里约一万七千多字。以下辨明果地觉，分三层。
