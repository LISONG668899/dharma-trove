# 《五位旨诀》议论

## 一、题解与文献

《五位旨诀》出自《抚州曹山元证禅师语录》。曹山本寂（840—901）是洞山良价的嗣法弟子。洞山立偏正五位，曹山承之而作铨量，配以《易》之卦象、君臣之名分，遂成曹洞一宗辨验学人的家法。

读这一篇，先要把一个常见的误会去掉：这里的"正""偏"不是正确与偏邪。曹山自己讲得极明白，正位就是空界，本来无物；偏位就是色界，有万象形。所以"正"指本体、空、理、平等一味，"偏"指现象、作用、事、差别万象。

曹山又以君臣配之。他说，臣向君是偏中正，君视臣是正中偏，君臣道合是兼带语。这是解释整套五位最可靠的祖师原话，比后代任何注疏都直接。

另有一处版本问题须先交代。第四位，语录此处作"偏中至"，而洞山《五位颂》传本多作"兼中至"，历代曹洞家为这一字争论不休。这不是纯粹的校勘趣味：若作"兼中至"，则第四位已入兼带，与第五位构成"至—到"的深浅；若作"偏中至"，则四位仍在偏正对举之内，直到第五位才连框架一齐脱落。本篇依语录原文作"偏中至"，取后一种结构；两读各有其理，学者不妨并存。

又，原文"太过"即《易》之**大过卦**，古书"太""大"通用。

## 二、原文

```
正中来者，太过也，全身独露，万法根源，无咎无誉。偏中至者，中孚也，随物不碍，木舟中虚，虚通自在。正中偏者，巽也，虚空破片，处处圆通，根尘寂尔。偏中正者，兑也，水月镜像，本无生灭，岂有踪迹。兼中到者，重离也，正不必虚，偏不必实，无背无向。

又曰：心机泯绝，色空俱忘（是云正）；到头无讳，曾无变动（是云中）；更无覆藏，全体露现（是云偏），是曰正中偏。山是山，水是水，无人安名字，无物堪比伦，是曰偏中正。净裸裸、赤洒洒，面目堂堂，尽天尽地，独尊无二，是曰正中来。宛如寰中天子，不借禹汤尧舜令，眼见耳闻，终不借他力，耳之不入声中，声之不塞耳根，里头才转身，尘中未带名，是曰偏中至。不是心，不是境，不是事，不是理，从来离名状，天真忘性相，是曰兼中到。
```

## 三、白话译文

**第一节，以五卦标示五位。**

所谓正中来，取象于大过卦。本体全身赤露地现前，是一切万法的根源；然而到了这个地方，说不上有什么过失，也说不上有什么可称赞的功德。

所谓偏中至，取象于中孚卦。在一切境界、一切见闻作为之中随缘而行，却无一物能真正挂碍。就像木舟因为中间是空的，才能载物涉水、转向自在——虚，所以通；通，所以自在。

所谓正中偏，取象于巽卦。从空寂本体上看去，眼前每一件具体事物都像是虚空的一片片当处显现；差别历然，而处处不隔法界，故处处圆通。此时六根六尘依旧现前，只是不再互相黏着追逐，所以说"寂"。

所谓偏中正，取象于兑卦。就在万象差别之中，彻见诸法如水中月、镜中像：明明显现，而从未真实地生起过；既无实生，哪里还有一个实灭之物留下踪迹。

所谓兼中到，取象于重离卦。到这里，正不必一定说成虚空寂灭，偏也不必一定说成真实有物；没有一边可背弃，也没有一边须趋向。

**第二节，曹山撤去卦象，直说境界。**

一切攀缘筹度的心机彻底歇下，连"色"与"空"这一对概念也一并忘却，这叫作"正"。彻到底了，无一物须要回避遮讳，也从来不曾有过什么本质上的变动，这叫作"中"。而这并非死寂：毫无隐藏，全体已经现成地露在眼前万象之中，这叫作"偏"。三者合说，就是正中偏。

山只是山，水只是水。没有一个人在背后替它们安一个本质性的名字，也没有另一个东西可以拿来比拟它、定义它。这就是偏中正。

净裸裸、赤洒洒，本来面目堂堂现前，尽天尽地更无第二物与之相对。这就是正中来。

好比天下的天子，自有王权，不必借禹、汤、尧、舜的诏令才作得主。眼见耳闻，都是本具现成的作用，不假外力。耳听声，而不曾陷进声里去；声入耳，也不曾把这个"听"堵满占尽。在根本处才一转身，就已经在万境中起用了；虽入尘境，却连一个名言概念都还没有沾上。这就是偏中至。

到最后，说它是心也不对，是境也不对；归之于事相不对，归之于理体也不对。它本来就超出一切名称形容之外；天然如此，不假造作，连"性"与"相"的分判也忘掉了。这就是兼中到。

## 四、卦象何以如此配

《宝镜三昧》讲"重离六爻，偏正回互，叠而为三，变尽成五"，说的正是这一套图式的来历。

离卦外二阳而中一阴，本是"中虚"之象。重离六爻，取中间四爻互体，得巽与兑；巽兑上下相叠，又成大过（巽下兑上）与中孚（兑下巽上）；连本位重离，恰好五个，所以说"变尽成五"。

配位之理，是以阴爻表正（体、空），阳爻表偏（用、色）。巽一阴在下、二阳在上，正在内而偏现于外，故为正中偏。兑一阴在上、二阳在下，通身是偏而正露于顶，故为偏中正。大过初、上二爻皆阴而中四爻皆阳，正在两端、用力全在中间，本体自中而出，故为正中来。中孚三、四居中为阴而外四爻皆阳，正隐于中心、作用遍于外围而中恒虚，故为偏中至。重离二、五皆阴，正偏交错而均，无所偏重，故为兼中到。

三处取象尤其精细，值得点出：

其一，"木舟中虚"直接来自《易·中孚·彖》"利涉大川，乘木舟虚也"。曹山不是随手打个比方，是就着卦辞说法——舟能涉川，正因其虚。

其二，"无咎无誉"是《易》中成语（如坤卦六四"括囊，无咎无誉"）。大过《大象》又说"君子以独立不惧，遁世无闷"，与"全身独露"的孤峻恰相印。

其三，兑为泽，泽面映月，故偏中正取"水月镜像"；巽为风、为入，无孔不入，故正中偏说"处处圆通"；离为丽（附着）、为明，重明相继而无实体，故兼中到说"无背无向"。

须补一句：各家配卦小有出入，后代注家亦有异说。卦只是"回互"的图式，不是定量，不必执卦以求道。

## 五、逐位解读

### 正中来：本体活了，而不居尊贵

"全身独露"是禅门重语。它不是说有一个藏在万法背后的真我终于露面了；恰恰相反，是因为遮蔽性的分别脱落，所以山河大地、见闻觉知，无一处不是全体的当处露现。

难在"无咎无誉"。只要心里还留着"这个境界殊胜""这是清净""这是佛境界"，就已经从全体中割出一小块来评价全体了。法性不是一件值得赞叹的东西，它甚至不站在任何价值判断的对面。

曹山另有"三种堕"之说，其中一种叫尊贵堕——知有本分事而不受，不肯坐在尊贵位上。正中来的"无咎无誉"，正是这个不肯坐。

### 偏中至：虚故能通，通故无碍

普通人以为修空是"越没有念头越高级"。曹山用木舟一喻把这条路堵死：木舟有用，不在木实，而在中虚；杯能盛水因其空，室能住人因其空，耳能闻声不因塞满声音，正因不住声音。

所以"虚"不是空洞麻木、不辨差别，而是因不固着，故具足一切作用。境来能应，境去不留。

### 正中偏：虚空破片，根尘寂尔

"虚空破片"不能读成虚空真被砸碎。它是一句锋利的机语：眼前一杯茶、一个声音、一念烦恼，看似都是局部有限的"片段"，然而诸法既无自性，任何片段就不曾脱离法性另有一个自己的实体。

这里须防一个细病：不要把"虚空、法性"想成一个大总体，把桌子、声音、念头想成里面的小碎片——那是把法性实体化了。严格依中观说，应当是：一一事相当体无自性，正因无自性，所以一一事相与法界不隔。

"根尘寂尔"的"寂"也不是六根六尘消失，是根不再抓尘、尘不再压根。这一句与后文"耳之不入声中，声之不塞耳根"互相解释。

### 偏中正：显现完全成立，实体完全不成立

很多人把"如幻"读成"世界是假的"，错了。水中月不是不存在，你看得清清楚楚；镜中像也不是漆黑一片，恰因镜明，影像才格外鲜明。

"水月镜像"的真意是：显现完全成立，实体完全不成立。生时觅不到所生，住时觅不到所住，灭时觅不到所灭——这就是"本无生灭，岂有踪迹"。

所以偏中正不是躲开世界去别处找空性，而是就在声中、色中、念中当下识得。名言尽可安立，自性不令成立。

### 兼中到：把梯子踢掉

前面为接引方便，只好说正即空、偏即有。但若最后还认定正一定是空、偏一定是有，五位就被重新做成了一种二元论。

所以曹山亲手撤梯：正不必虚，偏不必实。真正的不二，不是"一个空性加一个显现，再把二者合起来"；而是所谓空，本来就是显现之空；所谓显，本来就是空性之显。既如此，便没有一个轮回须要背弃到别处去，也没有一个涅槃须要趋向到别处去，故曰无背无向。

这不是说轮涅无别。是说：此处当体迷即轮回，此处当体透即涅槃，并无两个地点。曹山论兼带，说它冥应众缘而不堕诸有，非染非净，非正非偏，正是此意。

## 六、第二节几处最吃紧的话

**色空俱忘。** 不是色不存在、空也不存在，而是不再靠"色""空"这两个概念去认识实相。初学说色是有、空是无；进而知色即是空；再进，心里仍念着"这个色其实是空"——这仍是极细的"以空看色"。真正色空俱忘，是见杯子时不必在脑中另加一句"杯子是空性的"，因为杯子当体一毫也没有离开空性。而"全体露现"一句紧接其后，正防人堕入断灭。

**山是山，水是水。** 这句最易读浅。凡夫也说山是山，但凡夫的山水被名称、用途、爱憎、实体感层层包裹。曹山这里是：山现前而无一"山之自性"可得，水现前而无一"水之实体"可取。山仍完整，水仍完整，只是再没有一个概念框架能把它钉死。"无人安名字"不是不许叫它山，而是名字可用，却不能成为实相。

**独尊无二。** 不可读成"有一个宇宙大我唯一真实"。禅宗若在这里立一个大我，前面所破全成白费。它的意思是：当下经验中再也找不到"觉性"与"境界"的二元对立——听声时，没有一个独立的听者站在里面，也没有一个独立的声音站在外面，而听得分明。所以无二不是把二合成一件东西，是二不可得，一亦不可立。

**不借他力。** 不是否定佛力、师承、因缘，而是说觉知本身不是后来制造出来的。你听见声音以前，需要先造一个"听"吗？不需要，声一来已经听见。眼前现色，需要先下令"现在开始看"吗？也不用。见闻觉知本自现成，所以借天子作比：真王不必凭前代圣旨才成其为王。

**耳之不入声中，声之不塞耳根。** 这是全篇最堪下手的一句。凡夫听一句恶言，声早已灭，心却跟进去半天，这叫耳入声中；把意义、我执、旧账、情绪统统塞进那一瞬的声响里，这叫声塞耳根。偏中至的人听得比凡夫还清楚，但声音没有能力把觉知带走：声当下现，当下自解。

要紧的是，这不是强忍不反应，也不是"我得保持觉照，不能被声音带走"——那还是我、觉照、声音三层东西相持。曹山切得更早：耳根本不曾进去，声也本不曾堵住，二者从一开始就没有真正黏在一起。

**里头才转身，尘中未带名。** "转身"是禅门要语。悟得本体之后若只守本体，便成死水，所以必须转身：从无相转入有相，从空寂转入见闻觉知，从法身起用。但一入万境，又不许被万境重新套住，所以说"尘中未带名"——根本处才一发动便已在万法中，而入万法时尚未沾染名言。这不是婴儿式的无知：他知道杯子是杯子，会用杯子，甚至比凡夫判断更准；只是心不在杯子上另造一个独立真实自性成立的东西。用而不住，用而无迹，这才是曹洞所谓"活"。

**不是心，不是境，不是事，不是理。** 到最后，连教学用的一切工具都要撤：前教正即理、偏即事，此云不是事不是理；前教体用，此云体用俱不可得；前教性相，此云天真忘性相。所以曹洞的最高处不是"我终于理解了空有不二"，而是连"空有不二"都不再是你心里的一件东西。若还时时自念"这是现空双运""这是体用不二"，仍在名状之中；最高处甚至不必告诉自己"我现在正无分别"。

## 七、以洞山颂互证

洞山《五位颂》传本如下，与曹山此篇对读，其义自明。

```
正中偏：三更初夜月明前，莫怪相逢不相识，隐隐犹怀旧日嫌。
偏中正：失晓老婆逢古镜，分明觌面别无真，休更迷头犹认影。
正中来：无中有路隔尘埃，但能不触当今讳，也胜前朝断舌才。
兼中至：两刃交锋不须避，好手犹如火里莲，宛然自有冲天志。
兼中到：不落有无谁敢和，人人尽欲出常流，折合还归炭里坐。
```

大意可作如是通：第一颂说体中现用，虽相逢而不相识，习气犹存痕迹；第二颂说于现象中照见本来，觌面无别有一真，切莫认影为头；第三颂说无中有路，能不犯当今名讳，胜过一切辩才；第四颂说于万境交锋处不须回避，火中生莲，正是用得活时；第五颂说不落有无，人人欲出常流，末后却仍旧回来炭里坐地——彻底处正是平常处。

又须辨明：曹洞另有"功勋五位"（向、奉、功、共功、功功），那是就修行用功的次第说；此篇偏正五位则是就体用回互、勘验悟境说。两套不可混为一谈。

## 八、落到实修，可以自照的五条

一，见境之时，能不能不离境而知其无自性？这检验偏中正。

二，安住空寂之时，会不会贪恋清净、无念、寂灭？若会，尚未到正中来。

三，起心动念、开口做事之后，那本来的明空还在不在？一做事就失掉，说明体用犹分。

四，声音、情绪、念头生起时，是它自现自解，还是你另造一个觉知去对治它？前者近于"耳不入声中，声不塞耳根"，后者仍有能治所治。

五，心底是否仍暗藏一个"本体、觉性、法性、明空"作为最后的真实？若有，兼中到尚未透。

## 九、曹山最防的是顽空

曹山有一句极要紧的诫语：学者先须识自宗，莫将真际杂顽空。

顽空就是死空、无知觉之空、把一切灭尽之后剩下的那片空白。若把"心机泯绝""色空俱忘""净裸裸赤洒洒"读成没有念头、什么都不知道、呆在一片巨大的寂静里，恰好整个错掉。曹山随后特意用"眼见耳闻，终不借他力"把这个漏洞堵死。

真正的正不是摧毁偏，真正的空不是消灭显现，真正的寂不是失去明。这是全篇的骨髓。

## 十、与大圆满见地的比较

以下比较，取其可互照处，亦标其不可混同处。两宗各有自宗的完整脉络，比较是为了照见各自的锋刃，不是为了把一套折算成另一套。

**可以互照的地方。**

其一，正与偏之回互，与本净、任运二者无别的说法，在结构上相近。曹山说正位空界本来无物、偏位色界万象有形，而终以"正不必虚，偏不必实"撤去二分；大圆满亦说体性本净、自性任运二者非一非异，不许在本净上另立一个任运，也不许把显现从本净中割出。

其二，"全身独露"与直指心性的旨趣相通。二者都不是取得一个新境界，而是遮蔽脱落后的本来现成。

其三，"耳之不入声中，声之不塞耳根"，与六聚自解脱、显即自解的下手处极相近。声只是声，轮回真正烧起来是在其后的取著、认领、增殖；曹山切在更早处——尘中未带名。

其四，"无背无向"与无取无舍相应；"兼中到"之连心境事理、性相框架一并脱落，与离戏、乃至见修行果亦不可得的说法相应。这一点与《一决一切解脱》一类教授的题旨最为贴近。

其五，防顽空一节尤堪对读。曹山诫"莫将真际杂顽空"，大圆满亦极力破断空、破无记昏住、破把空性当作所缘境来守。两家所治，是同一个病。

**不可混同的地方。**

第一，教理骨架不同。大圆满于本性上立体性本净、自性任运、大悲周遍三分，明分是有正面教理地位的；曹洞唯正偏二分，"明"只散在"露""明历历"一类机语中，不别立为教理支柱。以本净配正、以任运配偏，可以助解，不可当作等式。

第二，"位"与"分"不同。曹洞的正偏是"位"——是语言与勘验中的位置，可移可换，可撤可立；大圆满的本净与任运是"分"——是一体上不可相离的功德面。位可迁移，分不可分离。混淆此点，比较即成错位。

第三，宇宙论的有无。大圆满有基位起现、迷悟分歧、任运八门的一整套教理展开；曹洞的"从体起用"是接引之语，并不建立基现开显的次第。"正中来"是修行人的悟境从守空转活，"基现"是法尔本有的显现——二者不可径直换算。

第四，道次与定量不同。大圆满有彻却、托噶的实修分工，托噶更有四相为定量；五位则是勘验悟境的尺子、接机的权巧，不是果位阶梯。以五位配四相，最易生误。

第五，传承方式不同。大圆满以上师直指、灌顶、誓言为轨；曹洞以机锋往来、偏正回互的语言训练为轨。曹山设五位，本意就是要在言语上勘验人有没有真透。

第六，思想史来源不同。偏正回互的直接源头在石头《参同契》，兼受华严理事无碍、事事无碍与《易》学熏染，不是印度中观—如来藏系的原型结构。援大圆满以解曹洞，须自觉这是比较而非训诂。

**最须警觉的一处。**

曹洞在最高处不许留任何一法，连"体用不二"也不许留；大圆满则于离戏之外，仍许一个明空无别的觉性作为道之所依——它不是实法，却是有定量、可决定、须护持的。这一分寸若不分清，容易生出两种偏差：或以禅门的扫荡去破大圆满之所立，说彼犹有所住；或以大圆满之所立去坐实禅门的扫荡，把"全身独露"读成一个实体本觉。二者皆失。

各安其位地说：曹洞的锋刃在"不许你在任何名相上停住"，大圆满的锋刃在"必须先决定认得它，然后一切自解"。前者防执，后者防迷。学人于此不必调和，只须知其所长而各用其药。

## 十一、余论

从曹山自说的"正位空界本来无物、偏位色界万象有形"，一路推到"正不必虚，偏不必实"，整套五位的玄机其实只是一件事：先用正偏教你认路，最后把正偏本身撤掉；先教你见体，再逼你转身起用；末后连"我正从体起用"的痕迹也不许留。

若删到只剩四句，我会留这四句。水月镜像，本无生灭，岂有踪迹——这是见。正不必虚，偏不必实，无背无向——这是破见。耳之不入声中，声之不塞耳根——这是修。不是心，不是境，不是事，不是理，从来离名状，天真忘性相——这是连修证框架本身也脱落。

再往下挖，最有价值的不是泛讲曹洞宗风，而是把洞山《宝镜三昧》、洞山《五位颂》与曹山此篇三者逐句互证。如此则正中偏、偏中正、正中来、偏中至、兼中到五位彻底打通，不至于停在辞典式的解释上。
