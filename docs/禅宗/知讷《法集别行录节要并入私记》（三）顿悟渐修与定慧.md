# 知讷《法集别行录节要并入私记》（三）顿悟渐修与定慧

## 人有顿悟渐修两门

宗密说：其次说明顿悟、渐修两门。真如之理，尚且无佛无众生，何况有师资传授？如今既然从佛以来祖祖相传，就可以知道，就人而言，有修证趣入之门。既然是就人而论，就有迷悟凡圣：从迷而悟，是顿；转凡成圣，是渐。

## 顿悟：大官梦狱之喻

所谓顿悟：众生无始以来迷倒，认这四大为身，认妄想为心，统统认作"我"。若遇到善友，为他宣说上面不变随缘、性相体用之义，忽然悟到灵明知见是自己的真心，心本恒常寂静，无边无相，就是法身；身心不二，这是真我，与诸佛分毫不差，所以叫做顿。

比如有一位大官，梦见自己身在牢狱，戴着枷锁，种种忧苦，百般设法求出；遇人唤醒，忽然觉悟，才见自身原来就在自家，安乐富贵，与朝中同僚毫无差别。

大官，比喻佛性；梦，比喻迷；牢狱，比喻三界；身，比喻阿赖耶识；枷锁，比喻贪爱；种种忧苦，比喻受报；百般求出，比喻问法勤修；遇人唤醒，比喻善知识；忽然觉悟，比喻闻法心开；才见自身，比喻法身真我；原在自家，就是经中所说的"毕竟空寂舍"；安乐，比喻寂灭为乐；富贵，比喻心体上本有恒沙功德妙用；与诸位同僚无异，比喻与诸佛的真性相同。

依这法喻，一一分明，足以辨别梦与醒。身心的本源虽然是一，论其相用，颠倒与正位却悬殊，醒来之后不可再做梦中的事。官，比喻心源虽一，迷悟却悬殊。梦中拜相（比喻迷时修得大梵天等果位），不及醒时作个县尉（比喻悟后初入十信位）；梦中得到七宝（比喻迷时修无量功德），不及醒时得到百钱（比喻悟时持五戒十善）。这都因为一妄一真的缘故。（原注：诸教都说，以满三千大千世界七宝布施，不如听闻一句偈，正是此意。）如今既然有师资传授，就必须简别颠倒与正位。

## 知讷私记：不自屈，不自高

知讷私记说：愿诸位求道的人，在这顿悟门上反复思量。法喻分明，应在一切时中自己验证；若没有悟解之处，修行岂能称为真修？

我看到学教的人，滞在权教所说上，把真妄执为两截，自生退屈；或者口谈事事无碍，却不修观行，不信有自心悟入的秘诀。一听到禅者说"见性成佛"，就以为不出顿教的离言之理，却不知其中有圆悟本心、不变随缘、性相体用、安乐富贵同于诸佛的意趣，这怎能算有智慧的人？

又看到学禅的人，只知道过量之机不踏阶梯、径登佛地的道理，不信此录中有"悟解之后初入十信位"的话。因此才有一点自心开发处，就不知解行的深浅、染习的起灭，多生法慢，所说言句越分过头。《华严论》也说：「大心凡夫，于信因中契诸佛果德，分毫不谬，方成信也」（大意：发大心的凡夫，在信心这个因地中契合诸佛的果德，分毫不差，才算成就了信）。若知此意，就不自屈，也不自高，这才是得了意的修心人。下面所说的渐修，是圆满的渐修，务必仔细审察。

## 渐修：水与波浪之喻

宗密说：其次说明渐修。虽然顿悟法身真心与诸佛全同，然而多劫以来妄执四大为我，习气已成本性，难以一下除尽，所以必须依悟渐修，损之又损，乃至无可再损，就名为成佛。并不是此心之外另有佛可成。不过，虽说是渐修，因为先已悟到烦恼本空、心性本净，所以对于恶，断而无断；对于善，修而无修，这才是真修真断。

有人问：悟了还要修，照前面的梦喻，岂不像醒来之后还要求出狱、脱枷锁？

答：前面只比喻顿悟之义，不比喻渐修之义。因为法有无量义，世间事物却只有一义。《涅槃经》虽然只谈佛性，而八百种比喻各有配合，不可乱用。现在说明渐修的比喻：

比如水被风激荡，成了许多波浪，便有漂溺之灾；或被阴寒之气侵入，结成冰凌，就阻碍了灌溉与洗涤的作用。然而水的湿性，无论动静凝流，从未改变。

水，比喻真心；风，比喻无明；波浪，比喻烦恼；漂溺，比喻轮回六道；阴寒之气，比喻无明贪爱的习气；结成冰凌，比喻坚执四大，成为质碍；阻碍灌溉洗涤之用：灌溉，比喻降下大法雨，滋润群生，长养道芽；洗涤，比喻荡除烦恼；迷时这两样都做不到，所以说"阻碍"。水的湿性虽然动静凝流而未曾改变，是说：贪嗔时也知，慈济时也知，忧喜哀乐变动不居，却未尝不知，所以说"不变"。

如今顿悟本心常知，就像认识了不变的湿性；心既然不再迷，就不是无明，如同风顿然止息；悟后攀缘自然渐渐止息，如同波浪渐渐平静；以戒定慧资熏身心，渐渐自在，乃至神变无碍，普利群生，名之为佛。

## 牧牛子引澄观《贞元疏》

牧牛子说：若论修证的顿渐，义理头绪繁多；撮其枢要，不出此录中的顿悟渐修。审察诸师所说，分列名义，开合各有不同。比如澄观《贞元疏》说：

第五，辨明修证的浅深。一部经内上下诸文，都在说明修证；恐怕文字浩博，现在再撮其要。自从世尊法眼晦迹于双林，诸圣传灯，明明不绝，以圣教为龟鉴，以心契为冥符，所以说"以心传心，不在文字"。若能领会文字之外的意旨，又何必担忧文字？

（知讷注：审察此文之意，是说依《华严》一经修证，心若冥符，就与禅门见性之旨相同。以下广为说明，务必仔细审察。）

自从一味之法汩乱，南北分流，在能诠与所诠上，成了定、慧两种学问。慧学又分性、相；定学则有顿、渐之不同。性相二学的会通，如前所说；顿渐的不同，现在略说：说渐的，是看心修净，以方便通经，或者顿悟渐修，或者渐修顿悟；说顿的，是直指心体，或者顿毁语言，或者顿悟顿修，或者无修无悟。虽有这些不同，都是要识心，都期望见理。顿渐的分属各有差异，后面再会通解释。

至于所悟的内容：或说心体离念、本性清净、不生不灭，多属渐门；或说无住空寂、真知绝相，或即心即佛、非心非佛，多属顿门。但都不离心的性相，都可以通用。

若说明能悟的方法，入法虽有千门，却不离定慧。为什么？心就像水与火，澄之聚之，其用就全；搅之散之，其用就薄。所以波摇则影碎，水浊则影昏；清明澄静，大小都能照见。无定无慧，是狂是愚；偏修一门，是渐是浅；若并运双寂，才是正门，成两足尊，非此不可。

若说不起心为修道，是以定为门；若说看心、观心、求心、融心，是以慧为门；若说无念无修、拂迹显理，是以定为门；若说知心空寂、知见无念，是以慧为门；若说寂照，或知无念，就是定慧双明；若说扬眉瞪目都称为道，就此名为修，这通二义：一是令人知道触目都是道，这是慧门；二是令心无所住着，这是定门。其余可以类推，都不出定慧。

## 知讷辨澄观定慧之说

牧牛子知讷常遗憾讲经法师不学禅法。等到读澄观所撰《贞元疏》，读到辨修证门这一段，喜其能合明禅旨，所以录在这里。其中所悟的心之性相、能悟的定慧二门，并不是此录中所要对辨的紧要之义；但恐怕学教的人以为这段文字已经把禅法全部收尽，所以略辨得失，令人生起正信。

就能悟门说明定慧，即"心如水火，澄之聚之"等，这是佛祖因地修行的大意。然而禅门中，凡是有能悟所悟、有修治之门的，属于渐宗，称为离垢定慧；以心地无痴无乱、离开能观所观的，名为顿宗，称为自性定慧。两者行相不同，辨明而修，才算适宜。

又，疏中把禅门的无念无修、拂迹显理等归入定门，把看心观心等名为慧门，把寂照、知无念等作为定慧双明。然而禅门之中，只有北宗的定慧有渐次先后之义；顿宗全没有单修一边的样子，何况拂迹显理之门，哪里有定与慧的名迹？清凉并非不知，只是姑且按言迹来区分，让泛泛的学人知道修行不出定慧罢了。

心有法与义的差别。宗师依据法而离开言说，用无迹之言令人破执显宗，这叫做迹绝于意地，理显于心源。学者因宗师激发，顿悟一法，心的义用自然显发出来；所以在破执显宗门中，没有"这是定、这是慧"这类随义而立的说法。至于定慧双明门，只说"寂照"或"知无念"等，修心的人依此很难趣入，现在略加阐明。

渐宗的观心门，先以寂寂对治缘虑，后以惺惺对治昏沉；虽有先后，也须惺寂等持；虽然等持，却只是取静为行。曹溪六祖说：「吾说一切法，不离自性；离体说法，迷却汝性」（大意：我所说的一切法都不离自性，离开本体说法，就迷失了你的自性）。又说："心地无非自性戒，心地无痴自性慧，心地无乱自性定。"又说："学道之人作意，不要说先定发慧、先慧发定；作这种见解的，法就有了二相。"又说："自悟修行，不在于静；若在静上分先后，就是迷人，胜负之心不断，反生法我，不离四相。"〔译注："不在于静"，辛本作"诤"，通行本《坛经》亦作"诤"；然知讷下文据"静"字立论，故依底本〕

所以可知，渐宗虽说惺寂等持，因为把这二义归属功行门，所以有先后渐次，仍是取静为行，不离法爱与人我之相。顿宗所修的定慧，是自性中本具的二义，没有能观所观，只是自悟修行，所以无先后；无先后，所以无动静；无动静，所以无法我；无法我，才可称为称真之行。这样修行，才是"正门，成两足尊"，不是认名执相之流所能见、所能行的。

又，疏中引禅门扬眉瞪目的作用，说"这通定慧二义"。若就功行门的义用来说，定慧是诸圣修因的大意，是经论共通的宗旨。然而禅门达者扬眉瞬目、当下显道的作略，本不是义理所能传，是达士相逢、在文字之外相见、以心传心的作用。所以先德说：「妙旨迅速，言说来迟；才随语会，迷却神机。扬眉当问，对面熙怡；是何境界，同道方知」（大意：妙旨迅疾，言说总是来迟；一随着语句去会，就迷失了神机。对面扬眉相问，彼此欢然，这是什么境界，唯有同道才知）。照这样说，若与达人相见时，不知教外传心之旨，却说"这是定、这是慧"，岂不是让人堕入义用、迷却神机？清凉并非不知此旨，只是姑且针对那些迷失宗旨的人，令他们专修定慧罢了。

## 无心合道门：引《宗镜录》

禅门在修定慧之外，又有无心合道门，略录于此，让学教的人知道格外还有一门，从而生起正信。如《宗镜录》说：

如前所述的安心之门，直下相应，并不先立定慧。（原注：先明定慧，后显无心。）定是自心之体，慧是自心之用。定即是慧，所以体不离用；慧即是定，所以用不离体。双遮则二者俱泯，双照则二者俱存；体用相成，遮照无碍。这定慧二门，是修行的要领，佛祖的大旨，经论共同的诠说。

如今依祖师之教，更有一门，最为省要，就是无心。为什么？有心则不安，无心则自乐。所以先德有偈说：「莫与心为伴，无心心自安；若将心作伴，动即被心谩」（大意：不要拿心作伴，无心时心自然安；若拿心作伴，一动就被心欺瞒）。所以阿难执有而无依据，七处征心，茫然无措；二祖体会无心而自得安宁，言下成道。若不直了无心之旨，纵然对治折伏，那不安之相常在眼前；若了达无心，处处无滞，没有一尘与之作对，何须劳神遣荡？没有一念生情，不必借助忘缘之力。

由此当知，祖师无心合道，不被定慧所拘。为什么？定学是称理摄散，所以有忘缘之力；慧学是择法观空，所以有遣荡之功。如今直了无心、处处无滞，是因为无障碍解脱智现前，一尘一念都不是外来，都不是别事，何须枉费功力？自性定慧尚且滞留在义用之迹上，何况离垢门，又怎能到达这里？所以石头和尚说：「吾之法门，先佛传授，不论禅定精进，唯达佛之知见」（大意：我的法门是先佛传授，不论禅定精进，只要通达佛的知见）。这无心合道，也是从径截门得入。其中看话下语的方便妙密，不能一一陈述，只是难遇知音罢了。

以下才是正要辨明的悟修顿渐之义。
