# 憨山《观老庄影响论》（二）论教乘与论工夫

## 论教乘

有人问：三教圣人本来是同一个道理，果真如此吗？

我回答：若以"三界唯心，万法唯识"来观，不但三教本来一理，没有一事一法不是由这一心所建立的；若以平等法界来观，不但三位圣人本来一体，没有一人一物不是毗卢遮那海印三昧的威神所现。所以说：「不坏相而缘起，染净恒殊；不舍缘而即真，圣凡平等。」（大意：不破坏诸相而随缘生起，染与净始终分明；不舍弃诸缘而当下即真，圣与凡本来平等。）只是在施设上有圆融与行布、人与法、权与实的不同而已。

圆融，是说一切诸法只是一心，染净融通，无障无碍。行布，是说十法界、五乘、五教，在理事、因果上有深浅不同。十法界，就是四圣与六凡；五教，就是小教、始教、终教、顿教、圆教；五乘，就是人乘、天乘、声闻乘、缘觉乘、菩萨乘，佛则是最上一乘。

这五乘各有修行进趣，因果阶次条理分明。人乘，就是天地之间、四海之内由君长统治的众生，所修以五戒为本。天乘，欲界诸天由帝释统领，所修以上品十善为本；色界诸天由梵王统领，无色界诸天由空定所持，所修以上品十善为基础，再加有漏禅定、九次第定。这两乘是三界之内的因果。声闻以四谛为本，缘觉以十二因缘为本，菩萨以六度为本，这三乘是三界之外的因果。佛则圆悟一心，妙契法身、般若、解脱三德。

合起来是一，所以叫圆融；分开来是五，所以叫行布。这些义理诸经都有记载。由此看来，五乘之法都是佛法，五乘之行都是佛行。只因众生根器有大有小，所以圣人设教有浅有深，无非应机施设，就是所谓"教不躐等"之意。

由此可以证知：

「孔子人乘之圣也，故奉天以治人；老子天乘之圣也，故清净无欲，离人而入天。」（大意：孔子是人乘的圣人，所以敬奉天道来治理人事；老子是天乘的圣人，所以清净无欲，离开人道而入于天道。）

声闻、缘觉是超越人天的圣人，所以高超三界，远越四生，舍弃人天而不入。菩萨是超越二乘的圣人，出离人天而又入于人天，所以往来三界，救度四生，出真而入俗。佛则是超越圣凡的圣人，所以能圣能凡，在天就是天，在人就是人，乃至分形于异类，无往而不入。能圣能凡的，岂是圣凡所能做到的？

据实而观，一切无非佛法，三教无非圣人。若人若法，都统属一心；若事若理，无障无碍，这就名为佛。所以圆融不妨碍行布，十法界森然分明；行布不妨碍圆融，一际平等。又哪里有彼此之分、是非之辩？所以经中说：或以边地之语说四谛，或以随俗之语说四谛。人天之教，就是随俗而说的四谛。推原孔老二圣，岂不是我佛秘密派遣的两个人，作为佛法的前导吗？这样说来，人与法都是权巧施设。

正因为在建化门头不坏因果之相，三教之学都是为了防护学者之心，由浅及深，由近至远。

所以孔子要人不做虎狼禽兽之行，就以仁义礼智来提携，姑且使人舍恶从善，由物而入于人；修先王之教，明赏罚之权，作《春秋》以明治乱之迹，正人心，定上下，以立君臣父子之分，定人伦之节。他的法严，他的教切，近于人情而容易施行。只因当时正值人欲横流，所以孔子汲汲奔走仍觉艰难。我想中国若没有孔子，人不沦为夷狄禽兽的就很少了。

虽然如此，这是孔子的"迹"本来如此，他的"心"难道全是如此吗？他明明说过「毋意，毋必，毋固，毋我」。看他济世之心，岂不是依菩萨乘而说治世之法吗？佛经中称他为"儒童"，确有缘由。而学者不见圣人之心，以为孔子之道仅此而已，于是执持先王之迹来博取功名，坚固我执，放纵贪欲而成为一生的拖累，甚至拿仁义作为盗贼的资本、开启争斗之祸的也有。

所以老子怜悯这种情形，说：这是尊尚圣人、运用智巧的过失。若能绝圣弃智，百姓就得百倍之利；剖斗折衡，百姓就不争了。贪欲之害真是太大了！所以说：「不见可欲，使心不乱。」所以老子的教法，离欲清净，以静定持心，不役于外物，淡泊无为，这是天乘之行，使人学此而离人入天。因为他的话深沉，学者难以明白，所以庄子起来大加发扬。

因为人的固执很深，所以庄子说得很激切。至于非议尧舜、轻视汤武，并不是说大话，是"绝圣弃智"的意思；把治道推到上古、把大道推过羲皇，并不是漫谈，是极言有为的害处；诋毁孔子，并不是诋毁孔子，而是诋毁那些只学孔子之迹的人，而且这也不是实话，而是破执之言。所以庄子自己说：「寓言十九，重言十七。」他呵斥教化、劝人远离，堕形泯智，用意是让人离人入天，除去贪欲的拖累。

至于精研世故，曲尽人情，打破我执的牢关，超越生人的大限，寓言曼衍，比事类辞，精切著明，微妙玄通，深不可测，这正是说人天之法而具无碍之辩的人。这岂不是现婆罗门身而说法吗？他的游戏何其广大！把尘世看作糠秕，把死生视为幻化，解脱物累，逍遥自在，他超世的气量何等之大！

我曾说：五霸僭窃之后，处士横议，仁义之途被堵塞，若不是孟子起来大力辟斥，我想天下后世早已左衽为夷了。当群雄互相吞噬最激烈的时候，举世颠倒昏昧，丧生于物欲、奔驰不返的人太多了，若不是庄子这位老人奋起其间，后世纵有高洁之士，也不会知道轩冕原来是桎梏。两人济世之功，又怎样比较呢？

然而庄子的工夫是从静定而入的，他的文字是从三昧中流出的。后人以一隅之见去窥测其人，以浊乱之心去读他的书，茫然不知归趣。若不见其心而只观其言，难怪会惊怖而不得其门而入。庄子自己也说：「万世之后而一遇大圣，知其解者，是旦暮遇之也。」然而他所期待的大圣，不是佛又是谁？若说庄子是我佛破执的前锋，这话是可信的。世人对庄子尚且入不了，又怎能入于佛法？

## 论工夫

我佛教中五乘进修的工夫，虽然各自事行不同，但修心都以止观为根本。所以佛教的止观，有大乘、小乘、人天乘之别，以及四禅、八定、九通明禅等。

孔子说「知止而后有定」，又说「自诚明」，这是人乘的止观。

老子说「常无欲以观其妙，常有欲以观其徼」，又说「万物并作，吾以观其复」。庄子也说「莫若以明」，又说「圣人不由而照之于天」，又说「人莫鉴于流水，而鉴于止水，惟止能止众止」，又说「大定持之」，至于「百骸九窍赅而存焉，吾谁与为亲」，又说「咸其自取，怒者其谁耶」。至于黄帝的退居、颜回的心斋、丈人承蜩的比喻、孔子论梦觉，这些静定工夫，都是释形去智、离欲清净，就是所谓「厌下苦粗障，欣上净妙离」，希望离人而入天。依佛教所明，这是舍弃欲界之生而生于初禅的工夫。所以庄子说：「宇泰定者，发乎天光。」这是天乘的止观。

《首楞严经》说：一切世间修心之人，爱染不生，不留欲界，这人应念身为梵众；欲习既除，离欲之心显现，这人应时能行梵德，名为梵辅；清净禁戒，加以明悟，这人应时能统梵众，为大梵王。这三种胜流，一切烦恼不能逼迫，虽然不是正修真三摩地，但清净心中诸漏不动，名为初禅。乃至澄心不动，湛寂生光，倍倍增胜，经历二禅、三禅、四禅，精见现前，陶铸无碍，以至究竟群几，穷尽色性之性，入无边际，名为色究竟天。这就是证据。

由此看来，老子之学，说「大患莫若于有身」，所以灭身以归于无；说劳形没有比有智更甚的，所以释智以沦于虚。这有点像二乘。而且他出于无佛之世，观察变化而知空无，有点像独觉。推原他所宗的虚无自然，就属于外道。看他慈悲救世之心，人天交归，有无双照，又像菩萨。

「盖以权论，正所谓现婆罗门身而说法者；据实判之，乃人天乘精修梵行而入空定者是也。」（大意：从权巧方面论，老子正是所谓现婆罗门身而说法的人；据实判定，则是人天乘中精修梵行而入于空定的人。）

老子之所以能济世，是因为大梵天王是娑婆世界之主，统领世界，说十善法，救度众生。据《华严经》，地上菩萨作大梵王；而梵众都是实行的天人，是由人乘而修天行的，老子正是这一类，毫无疑问。所以我说：庄子的言论纯是探究天人之际，不是孟浪之谈。
