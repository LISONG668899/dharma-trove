# 普庵老人语录白话译解

## 兼论永嘉三关：印证，还是引导？

---

## 一、缘起

普庵印肃禅师是南宋时期的一位大德。这一段语录，记录的是他在一次夜参之中，面对同门禅匠一个极为体贴、极为合情合理的建议，突然一声长叹、断然否定的经过。

它之所以值得反复咀嚼，不在于言辞的锋利，而在于：**被否定的那个建议，本身并没有错。**正因为它没有错，普庵老人这一句"不是这个道理"，才格外值得追问下去——他到底在否定什么？

---

## 二、原文与白话

### 1. 老人的日常

原文如下：

```
普庵老人，自解活计之后，了本无为，日用唯以佛之知见，示悟众生，以为佛事。
十二时皎皎地，无丝发许，作得间隔，不动道场，遍十方界。
```

白话：普庵老人自从彻底明白了自己的"活计"——也就是本分事、自家安身立命之处——之后，便了达"本来无为"这个道理。这不是说什么都不做，而是了知一切造作本来了不可得。

他平日里，唯独以"佛之知见"，也就是众生本具的觉性，来开示、点醒众生，把这当作自己的全部佛事。

**关键在"十二时皎皎地"这一句。**十二个时辰，也就是一天到晚，无论行住坐卧，他的心地都是明明朗朗的，中间没有一丝一毫的间隔断续。

这不是说他刻意保持觉知不断，而是说他早已契入那个"不动道场，遍十方界"的本地风光——道场从来没有挪动过一步，却又周遍十方一切世界。不动而遍，正因为不动才能遍；若真有一个可以挪动的"道场相"，反而哪儿也去不了。

### 2. 宪公的建议

有一天夜参之时，宪公禅师——一位得道的禅匠、通达全体大道的智者——向普庵老人提出了一个建议。

宪公讲：和尚您是身怀大道之人，从来不曾违背随缘应机的本分，可是这样南北往返、四处辛劳，谁又能长久忍受下去呢？

他接着说：不如向十方的护法檀越们恳求募化，多招纳一些人手，找一个能够操持杂务的人来管理事务；等到有信众来请修法事、祈福禳灾的时候，也好有人应付。

宪公最后讲：这样一来，前来参学的人也能早晚得到照应，不至于空过光阴，也免得您自己被这些琐碎的机务缠住脚跟——这样安排，可以吗？

这番话的出发点，是一片好意。见普庵老人四处奔波弘法、事必躬亲，心疼他辛苦，想帮他找个帮手、募些资粮，把寺务法事这些"外围工作"分担出去，让老人专心于"应缘"这件大事。

这是一个非常合情合理、也非常"实际"的建议。

### 3. 一声长叹

原文只有短短一句：

```
师默然不答，良久嘘气一声云："不是这个道理。"
```

普庵老人听了，沉默不答。过了很久，才长长嘘出一口气，说："不是这个道理。"

**这一声长叹和这五个字，是整段公案的转折点。**

宪公的建议在世间法上、乃至在住持道场的实际运作上，没有任何问题——甚至可以说是很体贴、很周到的安排。但普庵老人一句"不是这个道理"，是把话头从"如何把佛事办得更妥善"，一下子拉回到了"什么才是真正的佛事"这个根本问题上。

这里的关窍在于：**不是反对募化、反对招人办事，而是要看清楚，这些外在的经营筹划，跟"了本"这件生死大事，根本不是同一个层次的事，不能拿前者去替代、去消解后者的急迫性。**

### 4. 老卢与庞老

接下来是全篇最重的一段。原偈如下：

```
老卢得法非僧相，庞老通明岂离家？
大事未成俱业网，除非了本是生涯。
```

白话：当年六祖惠能（俗姓卢，人称"老卢"）得法的时候，还只是个在碓房舂米的行者，并没有出家人的僧相；庞蕴居士通达明悟大道，也并没有离开在家的身份。

由此可知：了脱生死这件大事，跟你剃不剃头、受不受戒、有没有一个如法的僧相，根本不是同一件事。真正决定的，是有没有"通明""得法"。

如果生死大事没有了办，那么无论你披不披袈裟、住不住道场，一切所作所为都仍旧落在业力的罗网之中。除非真正"了本"，否则你所过的这一生，说到底也只是在业网里讨生活而已。

**这里的推理关键是：普庵老人要证明的，是"僧相"跟"了本"之间没有必然关系。**

这不是在否定出家、否定戒律，而是在釜底抽薪地拆穿一个常见的错觉——很多人以为，只要把外在的架子搭起来，剃头、受戒、有道场、有信施供养，修行这件事就有了保障。

普庵老人恰恰要说：外在的架子搭得再齐全，若本没有了，你所做的这一切仍旧是在业网中打转。这跟宪公方才提议的募化、招人、办法事，是同一个性质的事——都属于事相上的周全，跟"了本"这件根本大事，隔着一层。

### 5. 最重的一棒

原文如下：

```
诸仁者，此段大事，从来千圣不曾踏着。
若不达本明心，妄觅一片袈裟，裹却一个凡夫身，剃了头受却戒，
谤正法虚贪信施，受人供养，成诸大业，永堕三途，
万劫千生，不得出离，诚非小事。
```

白话：各位仁者，这件了脱生死的大事，自古以来纵然是千位圣人，也从来没有真正"踏"到过它。

这句话的意思是：这件事根本不是靠脚"走到"、靠功夫"堆积"出来的。它不是一个可以被外在地"抵达"的目标，凡是想用世间因果次第的方式去够到它的，都还没有真正契入。

普庵老人接着讲：如果不能通达根本、明了自心，却只顾着到处寻觅一件袈裟，把这凡夫的身子一裹，剃了头、受了戒——这样一来，反而是在毁谤正法、虚妄地贪着信众的供养，白白受人恭敬礼拜，还自以为成就了一番大事业。

他最后说：这样的果报，是要永远堕落三恶道，历经万劫千生也难以出离的，这实在不是一件小事。

**这一段是最重的棒喝，也是最容易被误读的地方。**

普庵老人的意思不是"外相无用"，而是：**若只有外相而没有"达本明心"这个内核，那么所谓的受供养、办佛事、成就大业，不但没有功德，反而是在造"谤正法、虚贪信施"的重业。**

这与华严宗一个反复出现的逻辑完全一致——**有相而无性，则相即成障；唯了自性，相方能转成用。**没有见性做底子的一切庄严事相，非但不是庄严，反而是陷阱。

### 6. 什么叫"信"

原文如下：

```
佛语不虚，果报历然。
信者，信自心清净，即得作佛；
不信者，背失本源，永沉苦海，生死何休。
```

白话：佛所说的话从来不是虚妄的，因果报应历历分明，丝毫不爽。

所谓"信"，是相信自己这颗心本来清净，当下即可以此成佛；所谓"不信"，就是背离、迷失了这个本源，永远沉沦在苦海之中，生死轮转，哪里有个尽头呢？

**这里把"信"重新定义了。**不是信一个外在的教条或权威，而是信"自心清净、即得作佛"这一件事本身。

这也正是这一整段开示的核心：了本明心，不是要去别处求一个什么，恰恰是要回头认取自己本有的这一份清净。

### 7. 自己拆自己

原文如下：

```
我说本无说，君知本不知。
如如方合道，合道不可思议。
蒙妙意，为拈出永嘉大师三关，
不觉潦倒，哆哆和和，又与么去也。
```

白话：我说，其实本来就无所说——因为真正的法，说不到，也说不着。你们如果说自己"知道"了，那这个"知"，本身也不是真知。

为什么？因为只要还落在"我说""你知"这样一个能所对立的框架里，就已经不是那个"如如"的本地风光了。唯有"如如"，也就是不动不摇、不落能所的这个本然状态，才真正契合大道；而这个"合道"的境界本身是不可思议的，不是言语思维所能到达的。

普庵老人最后讲：承蒙大家的美意，我才拈出永嘉大师的"三关"来讲一讲；可这么一讲，不知不觉又落入了絮絮叨叨、拖泥带水的言语之中，也就只好这样将就着说下去了。

**结尾这一句，是普庵老人最见功力的地方。**

他一边说法，一边当场拆穿自己正在说的这个"说法"行为本身。"我说本无说，君知本不知"，正是华严"显无知"一门的现成注脚：尘即是知，不须更以一个"不知"去知那个"无知"——只是说没有能所对立的那种知，并不是说什么都不知道。

讲到这里，他索性连自己这一番苦口婆心的开示也一并放下。"不觉潦倒，哆哆和和，又与么去也"，看似自嘲，其实极为高明：**他不许听者把他刚才这番话，也变成一个新的、可以死死抓住的"法"。**

这一收，把整段开示从"教诲"提升成了"演示"——不但用言语告诉你"了本"是什么，还当场用这一句自嘲，向你演示了一遍什么叫"言语道断，心行处灭"。

## 三、永嘉三关

### 1. 一个必须先说明的文献问题

普庵老人在结尾处拈出的"永嘉大师三关"，需要先做一点考订，否则容易以讹传讹。

**目前并没有一部题为《永嘉三关》、由永嘉玄觉本人所撰的独立文献。**能查到的是两条不同的线索，容易被混为一谈。

第一条，"三关"——初关、重关、末后牢关——是禅宗后世（宋元以后）通行的修证阶位术语，泛用于评判各家悟境深浅，并非永嘉专属。虚云、来果、元音老人等近代大德都各有阐释，彼此说法并不一致。

第二条，今人有把《六祖坛经·机缘品》所载永嘉参六祖"一宿觉"公案，逐句标注为"见性关""般若关"的做法。这是**现代注家对坛经原文的一种事后诠释框架**，坛经原文本身并无"三关"之名。

因此，普庵老人这里所说的"永嘉大师三关"，最有可能指的就是《坛经》里那段一问一答的公案本身。这是唯一可以确证、有原文可查的部分，下面据此展开。

### 2. 公案原文

《六祖坛经·机缘品第七》记载如下：

```
（永嘉玄觉）绕师三匝，振锡而立。
师曰："夫沙门者，具三千威仪，八万细行。大德自何方而来，生大我慢？"
觉曰："生死事大，无常迅速。"
师曰："何不体取无生，了无速乎？"
曰："体即无生，了本无速。"
师曰："如是，如是！"
玄觉方具威仪礼拜。须臾告辞。
师曰："返太速乎？"
曰："本自非动，岂有速耶？"
师曰："谁知非动？"
曰："仁者自生分别。"
师曰："汝甚得无生之意。"
曰："无生岂有意耶？"
师曰："无意，谁当分别？"
曰："分别亦非意。"
师曰："善哉！少留一宿。"时谓一宿觉。
```

### 3. 逐回合白话解读

**第一回合：见地初勘**

永嘉玄觉绕着六祖走了三圈，把锡杖往地上一顿，站定不动，没有礼拜。

六祖便问：出家人应当具足三千威仪、八万细行，大德您从哪里来，怎么这般傲慢无礼？

这一句不是真的责怪他没礼貌，而是故意用世俗规矩来勘验——看永嘉是被外相戒律捆住的凡夫，还是真已见性、不再着相的人。

玄觉答：生死是天大的事，无常来得很快啊。

这一答看似答非所问，实则一语双关。他把六祖的责难直接接到"生死无常"这件根本大事上，等于说：我没工夫在这些外在威仪上兜圈子，我心心念念的是了脱生死这件事。

这正是普庵老人"大事未成俱业网"一句的原型——外在的威仪细行，若不能了生死，终究是次要的。

**第二回合：般若一击**

六祖顺势追问：那你为什么不去体认"无生"的道理，了达"没有什么快慢"这件事呢？

**这一问是往上一逼。**永嘉那句"生死事大，无常迅速"，其实还带着"急迫感"与"时间感"——"快"和"慢"，正是从"有生有灭"这个前提里生出来的分别。若真见了无生，哪里还有什么快慢可言？

永嘉答："体即无生，了本无速。"体悟到的，本来就是无生；了达的，本来就没有"速"这回事。

**这一句是把六祖抛出来的陷阱当场拆穿。**他没有说"我已经证到无生了"，而是说"体即无生"——能体、所体，当下不二；无生不是一个被证得的果，而是本来如此的事实。

这正好呼应华严"达无生"一门的说法：了知生本无性，才是无生；不是撇开缘生，另外去说一个无生。六祖听了，只应一句"如是，如是"，印可了。

**第三回合：动静勘验**

玄觉这才补上正式的礼拜，礼拜完很快就要告辞。

六祖说：回去得也太快了吧？——这是用"速"字再勘一次，看永嘉刚才那句"了本无速"，是不是真功夫。

永嘉答："本自非动，岂有速耶？"本来就没有"动"这回事，哪里谈得上快呢？

六祖再逼一层：那你怎么知道"不是动"的？

永嘉答："仁者自生分别。"是您自己起了分别心，才有动与不动的问题。

**这一句最见功夫。**他没有正面辩护"我真的不动"，而是直接把"动／不动"这一对分别概念，还给了提问的人本身。分别之心一旦生起，才有动静快慢的对立；分别心不生，动静本自不二。

**第四回合：连"分别"也不许立**

六祖印可：你确实深得"无生"的旨意了。

永嘉又追一句："无生岂有意耶？"——无生哪里还有个"意"可得呢？

六祖再逼："无意，谁当分别？"——没有意，那是谁在这里分别来分别去？

永嘉答："分别亦非意。"分别的当下，本身也没有一个能分别的固定主体。

六祖大喜，说：好啊，你就在这儿留宿一晚吧。世称"一宿觉"，由此而来。

## 四、一个值得追问的疑点：印证，还是引导？

### 1. 通说与疑点

历来主流说法几乎一致：永嘉见六祖之前已经开悟，此行只是求印证，六祖当场予以认可。

但如果紧贴文本的呼吸节奏读下去，会发现一个真实的缝隙：**这四个回合，究竟是"确认一个已完成的答案"，还是"层层逼出一个更精微的答案"？**

### 2. 支持"实质引导"的三点

**第一，第二回合的追问是真实的拈提，不是走过场。**六祖没有说"好，你懂了"，而是精准指出：您方才那句"无常迅速"，其实还暗中承认了"快慢"这把尺子的存在。这一问如果永嘉答不上来，或者只能重复"生死事大"这套话，就露馅了。

**第二，永嘉的第二答不是重复，是当场的语言创造。**"体即无生，了本无速"，是把六祖抛出来的那把尺子接住、拆掉、再吐出来。**如果他见六祖之前就已经证悟圆满，这句更精微的表达，为什么不在第一句就直接说出来，而要等六祖逼问一句才补上？这个先后顺序，本身就是最有力的证据。**

**第三，后两个回合是层层加码，不是反复盖章。**"返太速乎"是在具体情境里再验"无速"是否只是嘴上说说；"谁知非动"逼问是否还残留一个"能知不动"的旁观者；"无意谁当分别"逼问是否还残留一个分别背后的固定主体。每一层追问，针对的都是前一层回答里还没扫干净的一丝微细执着。若只是印证，一问一答足矣，何必四问四答？

### 3. 支持"已悟印证"的一面

公平起见，通说也不是全无根据。《坛经》原文说他"绕师三匝，振锡而立"，这个不礼拜的姿态在禅门语境里通常表示：来者不是来求法的，是来对机的，隐含着"我已经有个见处，来请你验一验"的自信。

所以传统上把这一段读作"印证"也有文本依据——**六祖的追问，完全可以理解为精准的验货手法：用最刁钻的角度去戳，戳不破才叫真货，而不是"教"出来的。**

### 4. 用华严的"生因了因"化解这个二元对立

这两种读法的分歧，其实落在一个更深的问题上：**"印证"本身，是不是就必然包含"逼出更精微表达"这一层作用？**

法藏在《华严经义海百门·体用显露门》中区分"生因"与"了因"：由智慧显发本有的，是了因；依此修起解行、生起力用的，是生因。他随即讲：生即无生，还同法体；了亦非了，岂等缘生；生之与了，无有差别。

用这个框架回看永嘉这段公案——六祖的四问，到底是"生因"（真正生起一个此前没有的证悟），还是"了因"（只是把本有的东西照亮显发）？

**华严的答案是：这个二分本身就要被拆掉。**

从"了"的角度看，六祖是把永嘉本有的见地一层层照显出来；从"生"的角度看，这照显的每一步，又实实在在地"生"出了一句永嘉此前不曾说出、甚至不曾如此清晰想过的话。

法藏说"生即无生，了则无生，体即无生，生还为了"——**这正是这个问题最恰当的答案：不必在"永嘉早已圆满自足"与"六祖当场实质引导"这两极之间选边站，因为在这四问四答的当下，"生"与"了"本来就是同一件事的两面。**

---

## 五、为什么普庵老人偏偏拈出这一段

回到文章开头那个问题：普庵老人棒喝宪公之后，为什么单单要拈出永嘉这段公案？

因为它本身就是"了本无为"最生动的现场演示。

永嘉在六祖面前，连"威仪细行"这个外在如法、连"礼拜的快慢"这个修行姿态，都被一层层逼问、拆穿，直到最后连"分别"这个动作本身，也不许立为一个"意"。

这正是普庵老人自己刚说完"我说本无说，君知本不知"之后，紧接着要拈出这段公案的用意所在——**层层逼拶，不许你在任何一个关口上落脚安住。**

宪公想为老人搭一个更稳妥的架子，让弘法这件事有个着落；普庵老人的回答，是把所有可以着落的地方，连同自己刚刚说过的这番话，一并抽掉。

**不是"了本无为"之后就无事可做，而是：做的时候，不许有一个地方是可以停下来住着的。**
