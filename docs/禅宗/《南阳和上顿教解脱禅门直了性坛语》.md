# 《南阳和上顿教解脱禅门直了性坛语》

唐代荷泽神会大师说，门人记录。"南阳和上"即神会大师：他于开元八年（720）奉敕配住南阳龙兴寺，在南阳前后约十年，所以人称"南阳和尚"。本篇是他登坛为大众授菩萨戒、开示顿教法门的讲词，故名"坛语"。

此本久已失传，二十世纪才在敦煌写本中重新发现。今据巴黎国家图书馆藏伯希和敦煌写本 P.2045 第二件为底本，以北京图书馆藏敦煌本参校，即胡适先生1958年的校写本（收入《大藏经补编》第二十五册）译出。

## 神会大师的七祖地位——据宗密大师的论述

### 宗密与荷泽法脉

圭峰宗密大师（780—841）是华严宗五祖，也是荷泽宗的传人。据他在《禅门师资承袭图》中所列的法系，他上承荷泽神会、磁州智如、益州南印（惟忠）、遂州道圆，是神会的第四代法孙。宗密在《圆觉经大疏钞》《禅门师资承袭图》《禅源诸诠集都序》中，多次系统地记述了神会的生平、禅法，以及被朝廷立为禅宗第七祖的经过。这是唐代关于神会最详细、也最接近当时的记载。

### 《圆觉经大疏钞》：此方七祖，神会第七

宗密在《圆觉经大疏钞》卷三之下叙述禅宗传承时说，西域有二十八祖，此方有七祖，相承传法，如一灯燃百千灯，冥暗都得光明，光明永无穷尽。他从迦叶尊者第一，一一列到西天第二十八祖达磨多罗；达摩来到东土，又为此方第一，慧可第二，僧璨第三，道信第四，弘忍第五，慧能第六，神会第七。

疏文接着说，从西域的迦叶到此方的达摩，乃至神会，每一代都只委嘱一人继嗣，此外屡有旁出的支派。

### 宗密所记神会大师生平

在"神会第七"这一条下，宗密以长注记述神会的事迹，大意如下。

神会大师承嗣南宗慧能和尚之后，住在东京洛阳荷泽寺，时人都称他为"荷泽和上"。他头顶相貌异于常人，骨气殊众，辩才难测。他先在北宗神秀门下三年，神秀奉敕入京后，他便往岭南参礼慧能。在慧能门下，他苦行供养，负薪担水，诵经持律，精勤异常。

宗密在慧能条下又补充说：神会十四岁时去参见慧能，以"无住为本，见即是性"作答，慧能对他多番勘验，夜里唤来细问，两心相契，师资道合。后来神会北游，增广见闻，在长安受具足戒；唐中宗景龙年间又回到曹溪，慧能知道他已经纯熟，便默授密语。

慧能灭度以后二十年间，曹溪顿教的宗旨在南方湮没，北宗渐门在北方极盛。神秀的弟子普寂禅师自称"七祖"，号为"二京法主、三帝门师"，朝臣归崇，敕使护卫，声势浩大，无人敢与之抗衡。岭南一宗几乎甘于毁灭，传法的信衣也屡次被人暗中图谋。

宗密说，神会亲承慧能付嘱，不敢因循，于是径直进入东都，当面与北宗相抗，诘问普寂。他在洛阳质问北宗传衣的来由，又在滑台大会上辨明南北两宗的真伪，与崇远法师等人当众论辩，事情都详载于《南宗定是非论》中。

此后他屡遭危难，宗密说他"三度几死"，甚至曾改穿商旅的丧服，扮作挑担执秤的人才得脱身，种种艰难，都详载于祖传之中。宗密认为，达摩"六代之后，命如悬丝"的预言，在这里应验了。

后来神会在南阳为王赵公解答"三车"之义，名声渐渐传到名贤之间。天宝四载（745），兵部侍郎宋鼎请他入住东都。从此曹溪的了义大播于洛阳，荷泽的顿门流布于天下。

然而北宗门下势力极大。天宝十二年（753），神会被人诬告聚众，奉敕贬到弋阳郡，又移武当郡；十三载量移襄州，同年七月又敕移荆州开元寺。宗密说，这些都是北宗门下所为。

乾元元年（758）四月以后，神会多次告诫门人，令他们问法，再三深叹"无为一法"。五月十三日中夜示寂，世寿七十五岁。次年迁葬于东京龙门，建塔供养。

此后朝廷屡加旌表：宝应二年（763），敕令在塔所建宝应寺；大历五年（770），敕赐祖堂匾额，称"真宗般若传法之堂"；大历七年（772），敕赐塔额，称"般若大师之塔"。

最关键的是贞元十二年（796）。宗密记载："敕皇太子集诸禅师楷定禅门宗旨，遂立神会禅师为第七祖。"意思是唐德宗命皇太子召集各方禅师，审定禅门的宗旨，于是立神会禅师为禅宗第七祖。宗密说，宫内神龙寺有敕立的碑记为证，德宗御制的七祖赞文也流行于世。

### 《禅门师资承袭图》：师承是傍，法门是渐

《禅门师资承袭图》是宗密回答裴休问禅宗法系的文书，其中对荷泽宗的地位说得更直接。

宗密说，荷泽宗完全就是曹溪之法，没有别的教旨；只是为了与洪州宗等旁出的支派区别，才另标荷泽宗之名。慧能和尚灭度后，北宗渐教大行，成了顿门弘传的障碍，曹溪传授的碑文也已被磨改，所以二十年间宗教沉隐。

天宝初年，荷泽入洛，大力弘扬顿门，才显出神秀门下"师承是傍，法门是渐"，也就是说，神秀一系在师承上是旁支，在法门上是渐修。南北二宗并行，时人要分辨它们的不同，"南宗""北宗"的名称就从这时开始。

宗密在这里还设了一问："既然荷泽是第七祖，为什么不立第八、第九、第十祖？既然后来不再立，何不依传衣为凭，只到第六祖为止？"

他回答说：若依真谛，本来没有名数，连"一"都不存在，哪里有六、七之说？现在是依俗谛，师资相传是顺世之法，有它所表示的意义。比如国家立七庙，七月而葬，丧服及于七代，福德资及七祖；经中说七佛，持念的遍数、坛场的物色作法、礼佛请僧的数目，都止于七，多则二七乃至七七，不止于六，也不到八、九。如今传法的仪式，是顺世而令人生信，有什么可怀疑的呢？

接着他再次记载：所以德宗皇帝在贞元十二年，敕皇太子召集诸位禅师，审定禅门宗旨，搜求传法的旁正，于是降敕立荷泽大师为第七祖；宫内神龙寺现有铭记，御制的七代祖师赞文也流行于世。

### 宗密对荷泽禅法的判摄

宗密推尊神会，不只在法统，更在禅法。《圆觉经大疏钞》把当时禅门分为七家，前六家各有所偏；第七家"寂知指体，无念为宗"，宗密说"是南宗第七祖荷泽大师所传"。

他解释这一宗的要旨：万法既然是空，心体本来寂静；寂静就是法身，即寂而知，这知就是真智，也名菩提、涅槃。这是一切众生本源清净的心，是自然本有之法。既然悟到此心本寂本知，就应当称本用心，不再生起妄念；只要没有妄念，就是修行，所以这一门以无念为宗。

宗密认为，前六家都还没有指出灵明的心体，唯有第七家直指寂知；而以寂知为本，随缘修习前六家的种种方便，那六家就都成了随病对治的妙门。他又多次引用神会"知之一字，众妙之门"一语，认为恒沙佛法都由此成立。

在《禅门师资承袭图》中，宗密评价荷泽宗"尤难言述"，说它正是释迦降世、达摩远来的本意。用前面诸宗来看荷泽，荷泽与它们迥然不同；用荷泽来统摄诸宗，诸宗又全同于荷泽。

### 史料对勘

关于神会的生平，史料记载不尽一致。北宋赞宁《宋高僧传》卷八〈唐洛京荷泽寺神会传〉说他俗姓高，襄阳人，于上元元年（760）示寂，世寿九十三岁。宗密《禅门师资承袭图》所引祖传也说他俗姓高；《圆觉经大疏钞》写本此处作"嵩""万"，当是传抄之误。

至于卒年，1983年在洛阳龙门出土了〈荷泽大师神会塔铭〉，学界据此确定了神会的卒年。塔铭所记与宗密"乾元元年五月十三日示灭，年七十五"一致，可见宗密的记载相当可靠。

还须说明，神会"第七祖"的地位，主要见于荷泽一系及宗密的记载。宗密本人是荷泽传人，推尊祖师，自有宗派立场。中唐以后，洪州、石头两系大盛，宋代的《景德传灯录》等灯录以慧能之下的南岳、青原为正脉，神会被列为六祖旁出的法嗣，七祖之说在后世禅门就不再通行了。然而贞元十二年敕立七祖、御制赞文，宗密两处记载都言之凿凿，在唐代确曾是朝廷认可的定论。

## 一、发心与忏悔

无上菩提之法，诸佛都深深赞叹，不可思议。

各位知识（善知识，神会对听众的称呼），既然你们一一都能来到这里，各自都已发起无上菩提心。

诸佛菩萨、真正的善知识，极其难以遇到。过去不曾听闻的，今天得以听闻；过去不曾遇到的，今天得以遇到。

《涅槃经》中，佛问迦叶菩萨："从兜率天上放下一粒芥子，要投中阎浮提地上的一个针尖，这难不难？"迦叶菩萨说："甚难，世尊。"佛告诉迦叶："这还不算难。以正因正缘得以相遇，这才是难。"

什么是正因正缘？各位知识，发无上菩提心，是正因；诸佛菩萨、真正的善知识把无上菩提法投入各位心中，使各位得到究竟解脱，是正缘。能这样相遇，是最好的。

各位知识，凡夫口中有无量的恶言，心中有无量的恶念，久久轮转生死，不得解脱。所以每个人都须要自己发菩提心。现在为各位知识忏悔，大家各自礼佛：

```
敬礼过去尽过去际一切诸佛！
敬礼未来尽未来际一切诸佛！
敬礼现在尽现在际一切诸佛！
敬礼尊法般若修多罗藏！
敬礼诸大菩萨，一切贤圣僧！
```

大意是：礼敬过去、未来、现在三世一切诸佛，礼敬般若经藏，礼敬诸大菩萨与一切贤圣僧。

大家各自至心忏悔，使各位知识身口意三业清净：

```
过去未来及现在，身口意业四重罪，我今至心尽忏悔，愿罪除灭永不起！
过去未来及现在，身口意业五逆罪，我今至心尽忏悔，愿罪除灭永不起！
过去未来及现在，身口意业七逆罪，我今至心尽忏悔，愿罪除灭永不起！
过去未来及现在，身口意业十恶罪，我今至心尽忏悔，愿罪除灭永不起！
过去未来及现在，身口意业障重罪，我今至心尽忏悔，愿罪除灭永不起！
过去未来及现在，身口意业一切罪，我今至心尽忏悔，愿罪除灭永不起！
```

大意是：过去、未来、现在三世之中，身口意所造的四重罪、五逆罪、七逆罪、十恶罪、深重的业障，乃至一切罪业，我今天至心全部忏悔，愿罪业消灭，永不再起。

## 二、三学等与持戒

现在各位知识已经来到这个道场，各自发起无上菩提心，求无上菩提法。

如果求无上菩提，就须相信佛语，依照佛的教导。佛说了什么呢？经中说："诸恶莫作，诸善奉行，自净其意，是诸佛教。"过去一切诸佛都是这样说的：诸恶莫作是戒，诸善奉行是慧，自净其意是定。

各位知识，要戒定慧三学平等，才名为佛教。什么是三学平等？就是戒、定、慧。妄心不起，名为戒；没有妄心，名为定；知道心中没有妄心，名为慧。这名为三学平等。

各位都须要护持斋戒。如果不持斋戒，一切善法终究不能生起。如果求无上菩提，要先护持斋戒，才能得入。如果不持斋戒，连生疥癞的野狐之身尚且得不到，哪里能获得如来的功德法身？各位知识，学无上菩提，却不清净三业，不持斋戒，说自己能证得，那是没有的事。

要借助有作的戒、有作的慧，来显发无作的戒、无作的慧。定却不是这样：如果修有作的定，就只是人天的因果，与无上菩提不相应。

各位知识，你们久久流浪生死，经过恒河沙数的大劫，不得解脱，是因为不曾发无上菩提心，所以就遇不到诸佛菩萨、真正的善知识；即使遇到了诸佛菩萨、真正的善知识，又不能发无上菩提心。流转生死，经无量恒河沙大劫不得解脱，原因全在这里。

## 三、发菩提心，不住二乘之定

即使有人发心，也只发了二乘、人天的心，人天的福报享尽了，仍免不了再堕落。

诸佛出世，多如恒河沙；诸大菩萨出世，多如恒河沙；每一位诸佛菩萨善知识出世度人，也都多如恒河沙。为什么我们遇不到诸佛菩萨善知识，到今天还流浪生死、不得解脱？实在是因为过去与诸佛菩萨、真正的善知识，连一念最上乘菩萨的因缘都没有结下。

或者有的善知识，不明了无上菩提法，竟把二乘声闻法和人天法教给各位，这就像把污秽的食物盛在宝器之中。什么是宝器？各位知识，发无上菩提心就是宝器。什么是秽食？二乘与人天之法就是秽食。这样虽然获得少许善报，得以生天，天福享尽，仍和今天的凡夫一样。

各位知识，今天发心学与般若波罗蜜相应之法，超过声闻、缘觉等，与释迦牟尼佛为弥勒菩萨授记没有差别。

二乘人执著于"定"，在定中经历劫数：须陀洹在定中八万劫，斯陀含在定中六万劫，阿那含在定中四万劫，阿罗汉在定中二万劫，辟支佛在定中一万劫。为什么呢？他们住在这定中，等劫数满足了，菩萨摩诃萨才应机为他们说法，他们才开始发菩提心，和今天各位知识发菩提心没有分别。当二乘人在定中时，即使为他们说无上菩提法，他们也终究不肯领受。经中说，天女对舍利弗说："凡夫对佛法还有反复（还能回心向大），声闻却没有。"

既然已经登上这个坛场学修般若波罗蜜，愿各位知识心口一致发无上菩提心，不离座下，就悟入中道第一义谛。

求解脱的人，要远离身、意、识，远离五法、三自性、八识、二无我，远离内外之见，也不在三界中现身意，这才是"宴坐"。这样坐，佛就印可。六代祖师以心传心，正因为它离于文字。从上以来相承，也都是这样。

## 四、人人本有佛性

各位知识，每个人身中都具有佛性。善知识并不把佛的菩提法给人，也不替人安心。为什么呢？《涅槃经》说："早已授仁者记。"（早就为你们授过成佛之记了）一切众生本来就是涅槃，无漏的智性本自具足。

为什么见不到？今天流浪生死、不得解脱，是因为被烦恼遮覆，所以不能得见。要靠善知识指授，才能得见；见了，就离开流浪生死，得到解脱。

## 五、除去妄心：粗妄与细妄

各位知识，以前所学的一切，暂且都放下，不要用它来看。

各位知识中，学禅已经五年、十余年、二十年的人，听到这话一定深感惊怪。这里所说的"除"，只是除去妄心，不是除去法。如果是正法，十方诸佛来除也除不掉，何况今天的善知识能除得掉？就像人在虚空中行住坐卧，都离不开虚空。无上菩提法也是这样，除不掉的；一切施为运用，都不离法界。经中说："但除其病，不除其法。"

各位知识仔细听，为你们说什么是妄心。

什么是妄心？你们今天既然来到这里，心中贪爱财色男女，挂念园林屋宅，这是"粗妄"，你们应当没有这种心了。但还有"细妄"，你们自己不知道。

什么是"细妄"？心里听说菩提，就起心去取菩提；听说涅槃，就起心去取涅槃；听说空，就起心去取空；听说净，就起心去取净；听说定，就起心去取定。这些都是妄心，也是法缚，也是法见。

如果这样用心，就不得解脱，不是本来寂净的心。作意住于涅槃，就被涅槃所缚；住于净，就被净所缚；住于空，就被空所缚；住于定，就被定所缚。这样用心，都是障碍菩提道。

《般若经》说："若心取相，即著我、人、众生、寿者。离一切诸相，即名诸佛。"也就是要离开法相。《维摩经》说："什么是病本？是因为有攀缘。怎样断攀缘？以无所得。无所得，就没有病本。"学道的人如果不认识细妄，怎么能出离生死大海呢？

各位知识，各自用心仔细听，简择一下自己本来清净的心：听说菩提，不作意去取菩提；听说涅槃，不作意去取涅槃；听说净，不作意去取净；听说空，不作意去取空；听说定，不作意去取定。这样用心，就是寂静涅槃。

经中说："断烦恼者，不名涅槃；烦恼不生，乃名涅槃。"譬如鸟在虚空中飞，如果停住在空中，必定有坠落的危险。学道的人修无住心，如果心住在法上，就是住著，不是解脱。经中说："更无余病，唯有空病；空病亦空。"连能空的、所空的也都是空。

经中说："常行无念实相智慧。"如果以法界去证法界，就是增上慢人。

## 六、不凝心住心，于无住处立知

各位知识，一切善恶，都不要思量。不得凝心住心，也不得拿心去直视心，否则就落在直视上住著，不中用。不得垂眼向下，否则就落在眼上住著，不中用。不得作意摄心，也不得远看近看，这些都不中用。经中说："不观是菩提，无忆念故。"这就是自性空寂的心。

（以下是神会与听众的问答。）

问：心有是非吗？答：没有。

问：心有来去之处吗？答：没有。

问：心有青黄赤白吗？答：没有。

问：心有住处吗？答：心没有住处。

和上说：心既然无住，你知道心无住吗？答：知道。

问：知，还是不知？答：知。

现在推到无住之处，就立一个"知"，这是为什么呢？

无住，就是寂静；寂静的本体，就名为定。从这本体上有自然智，能知本来寂静的本体，名为慧。这就是定慧平等。经中说："寂上起照。"就是这个意思。

无住心不离知，知不离无住。知道心无住，此外再没有别的知。

《涅槃经》说："定多慧少，增长无明；慧多定少，增长邪见；定慧等者，明见佛性。"现在推到无住之处，就立知；知道心空寂，就是用处。《法华经》说："即同如来知见，广大深远。"心无边际，同于佛的广大；心无限量，同于佛的深远，再没有差别。

看诸菩萨行甚深般若波罗蜜多，佛是怎样推究菩萨的病处的。《般若经》说："菩萨摩诃萨应如是生清净心：不应住色生心，不应住声香味触法生心，应无所住而生其心。"所谓"无所住"，就是现在为各位推出来的无住心；所谓"而生其心"，就是知道心无住。

本体空寂。从空寂的本体上起知，善于分别世间的青黄赤白，这是慧；不随分别而起，这是定。

如果像"凝心入定"那样，就落入无记空；出定以后，起心分别世间一切有为法，称此为慧，经中把这叫做妄心。这样就是慧的时候没有定，定的时候没有慧。这样理解的，都离不开烦恼。

所谓"凝心入定，住心看净，起心外照，摄心内证"，都不是解脱心，也是被法所缚的心，不中用。

《涅槃经》中，佛告诉琉璃光菩萨："善男子，你不要入甚深的空定。为什么？因为这会令大众迟钝。如果入定，一切般若波罗蜜就都不能了知了。"

只要自己知道本体寂静，空无所有，也没有住著，等同虚空，无处不遍，这就是诸佛的真如身。真如是无念的本体，因为这个道理，所以立"无念"为宗。

如果见到无念的人，虽然具有见闻觉知，却常常空寂，戒定慧三学一时齐等，万行全都具备，就同于如来知见，广大深远。为什么说深远？"以不见性，故言深远。若了见性，即无深远。"因为没有见性，所以说深远；如果明了见性，就没有深远可言了。

## 七、六根中得解脱

愿各位至心谛听，使各位知识得"顿悟解脱"。

如果眼见色时，善于分别一切色，却不随分别而起，就在色中得自在，在色中得解脱，色尘三昧具足。

耳闻声时，善于分别一切声，却不随分别而起，就在声中得自在，在声中得解脱，声尘三昧具足。

鼻闻香时，善于分别一切香，却不随分别而起，就在香中得自在，在香中得解脱，香尘三昧具足。

舌尝味时，善于分别一切味，却不随分别而起，就在味中得自在，在味中得解脱，味尘三昧具足。

身觉种种触时，善能分别触，却不随分别而起，就在触中得自在，在触中得解脱，触尘三昧具足。

意分别一切法时，却不随分别而起，就在法中得自在，在法中得解脱，法尘三昧具足。

这样诸根善于分别，就是本慧；不随分别而起，就是本定。

## 八、定慧双修：灯光之喻

经中说："不舍道法而现凡夫事，是为宴坐。"在世间种种运作施为，却不在事上生念，这就是定慧双修，二者不相分离。定不异于慧，慧不异于定，就像世间的灯与光不相分离。

即灯之时，就是光的本体；即光之时，就是灯的作用。即光之时不异于灯，即灯之时不异于光；即光之时不离于灯，即灯之时不离于光；即光之时就是灯，即灯之时就是光。

定慧也是这样：即定之时，就是慧的本体；即慧之时，就是定的作用。即慧之时不异于定，即定之时不异于慧；即慧之时就是定，即定之时就是慧。即慧之时无有慧，即定之时无有定。这就是定慧双修，不相分离。

最后两句（即慧之时无有慧，即定之时无有定），就是维摩诘居士默然无言、直入不二法门。

## 九、烦恼即菩提：虚空之喻

为各位知识简明说一下"烦恼即菩提"的道理，以虚空为比喻。

虚空本来没有动静。光明来了，是光明中的虚空；黑暗来了，是黑暗中的虚空。暗中的虚空不异于明中的虚空，明中的虚空不异于暗中的虚空。明暗在虚空中自来自去，虚空本来没有动静。烦恼与菩提，道理也是这样：迷与悟虽然有别，菩提的本性原本不异。

经中说："如自观身实相，观佛亦然。"知道心无住，就是观。过去诸佛的心，也和各位知识今天的无住心没有分别。经中说："我观如来，前际不来，后际不去，今则无住。"

求法的人，不执著于佛而求，不执著于法而求，不执著于僧而求。为什么？因为众生心中各自都有佛性。各位知识，起心向外求的，就名为邪求。

《胜天王般若经》中，佛说："大王，就是如实。"胜天王问："世尊，什么是如实？"佛说："大王，就是不变异。"又问："世尊，什么是不变异？"佛说："大王，就是如如。"又问："世尊，什么是如如？"佛说："大王，这可以用智慧去知，不是言语所能说的。离相无相，远离思量，超过觉观的境界。这就是菩萨了达甚深法界，就同于佛的知见。"

## 十、知与见

各位知识，你们自身中有佛性，但还不能了了分明地见到。为什么呢？

比如你们在这里各自想着家中的住宅、衣服、卧具以及一切物品，都知道它们在那里，一点也不怀疑，这名为"知"，不名为"见"。如果走到家中，亲眼见到上面所说的那些东西，才名为"见"，不名为"知"。现在你们所觉知的，都是依照别人所说，"知道"身中有佛性，还不能了了分明地"见"到。

只要不作意，心无所起，这就是真无念。究竟来说，见不离知，知不离见。

一切众生本来无相，现在所说的相，都是妄心。心如果无相，就是佛心。如果作意让心不起，这是识定，也名为法见、心自性定。

马鸣菩萨说："若有众生观无念者，则为佛智。"所以现在所说的般若波罗蜜，是从生灭门顿入真如门，再没有前照后照、远看近看，这些心都没有，乃至七地以前的菩萨都一概越过，唯指佛心，即心是佛。

## 十一、中道亦不立

经中说："当如法说：口说菩提，心无住处；口说涅槃，心唯寂灭；口说解脱，心无系缚。"

刚才为各位指出的无住心，你们知道吗？答：知道。

《涅槃经》说，这就是第一义空。如果三处都空，就是本体空寂。唯有中道，也不在其中。中道是因两边而立的，就像三根手指并在一起，要因为两边，才能立出中指；如果没有两边，中指也就没有了。经中说："虚空无中边，诸佛身亦然。"诸佛的解脱法身，也像虚空一样没有中边。

各位知识，常须这样理解。现在把无上道法交付给各位知识。如果领会了这些话，六波罗蜜、恒沙诸佛、八万四千三昧门，一时都灌入各位的身心。

《维摩经》说："菩提不可以身得，不可以心得。寂灭是菩提，灭诸相故。"所谓"不可以身得"，是说心不在外；"不可以心得"，是说身不在内；"寂灭是菩提"，是说中间也没有处所；"灭诸相故"，是说一切妄念不生。这时照体独立，神妙无方。各位知识，应当这样用心。

上根上智的人，听说般若波罗蜜，就能领受，依法修行。中根的人，虽然还没有得到，如果勤加请问，也能得入。下根的人，只要至诚信受而不退转，将来也能进入大乘十信位中。

## 十二、非垢非净，去来皆病

学道的人如果拨开妄想去取清净，这是从垢得来的净，不是本来就净。《华严经》说："譬如擦拭有污垢的手巾，先用灰汁浸，然后用清水洗。这虽然洗净了，还不名为净。为什么？因为这净是因垢而得的，所以仍然不净。"《维摩经》说："非垢行，非净行，是菩萨行。"

各位知识，不用心的时候，如果有妄念生起，思忆远近的事，不必把它收摄回来。为什么呢？心跑出去既然是病，收摄回来也还是病，去来都是病。经中说："诸法无来去。"法性遍一切处，所以法没有去来。

如果有妄念生起，当下就觉；一觉，妄念就灭，这就是本性的无住心。有与无双双遣除，境与智一起泯亡，不作意，就是自性菩提。

即使是微细的心，也用不上。本体空寂，没有一物可得，这名为阿耨多罗三藐三菩提。《维摩经》说："从无住本，立一切法。"菩萨的戒光也是这样，自性空寂，没有形相。

《涅槃经》中迦叶菩萨赞叹初发心说：

```
发心毕竟二不别，如是二心先心难。
自未得度先度他，是故敬礼初发心。
初发已为天人师，胜出声闻及缘觉。
如是发心过三界，是故得名最无上。
```

大意是：初发心与究竟成佛，二者没有分别，而两心之中，初发之心更难。自己还没有得度，先去度他人，所以要敬礼初发心。初发心时就已是天人之师，胜过声闻和缘觉；这样的发心超过三界，所以名为最无上。

## 十三、普说无私，勤作功夫

其他各家被人借问时，往往隐而不说。我在这个法门中，完全不是这样，人多人少，都普遍宣说。

如果从老师处受得禅法，所学的都要各自审度明白，只求心地通达。如果心地通达，一切经论的义理没有不通的。

佛在世时，也有上、中、下根的众生投佛出家。过去诸佛说法，都是对着天龙八部大众说的，不私下说，不偷偷说。譬如正午的太阳，无处不照；又如龙王降雨，平等无二，一切草木各随其类得到滋润。诸佛说法也是这样，都以平等心说，以无分别心说，上中下根的大众各自领解。经中说："佛以一音演说法，众生随类各得解。"

各位知识，如果学般若波罗蜜，须要广读大乘经典。看到那些教禅的人，不许人顿悟，说一定要随着种种方便才能开悟，这是最下品的见解。明镜可以照见容貌，大乘经可以端正人心。

第一不要怀疑。依照佛语，应当清净三业，才能进入大乘。这个顿门，完全依照如来所说，依此修行，必定不会误人。勤作功夫。有疑问的，来相问。好去！

## 附录：南宗定邪正五更转

敦煌写本 P.2045 在《坛语》之后，接抄有《南宗定邪正五更转》五章和五言律诗一首，没有署名。其中"凝心""住心看净""看则住心便作意"等语，与《坛语》的思想和用语处处相合，胡适先生因此推断也是神会的作品。这是推断，并无明文，姑附于此。

"五更转"是唐代流行的民间曲调，从一更唱到五更，每更一章。

```
一更初。妄想真如不异居。迷则真如是妄想，悟则妄想是真如。
念不起，更无余。见本性，等空虚。有作有求非解脱，无作无求是功夫。
```

大意是：妄想与真如本不分居，迷时真如就是妄想，悟时妄想就是真如。一念不起，更无别物；见到本性，等同虚空。有作有求不是解脱，无作无求才是功夫。

```
二更催。大圆宝镜镇安台。众生不了攀缘病，由斯障闭不心开。
本自净，没尘埃。无染著，绝轮回。诸行无常是生灭，但观实相见如来。
```

大意是：大圆宝镜本来安放在台上。众生不明白攀缘之病，因此障蔽，心不得开。心本自清净，没有尘埃；没有染著，就断绝轮回。诸行无常是生灭法，只要观照实相，就见如来。

```
三更侵。如来智慧本幽深。唯佛与佛乃能见，声闻缘觉不知音。
处山谷，住禅林，入空定，便凝心。一坐还同八万劫，只为担麻不重金。
```

大意是：如来的智慧本来幽深，唯有佛与佛才能见到，声闻缘觉不是知音。住在山谷禅林，入空定，凝住其心，一坐下去就像二乘人在定中八万劫一样，只因为舍不得肩上的麻，不看重眼前的金子。（"担麻弃金"是佛经中的故事：二人同行，先拾得麻，后遇到金银，一人弃麻取金，一人嫌负担已久，执意担麻不放。这里讥讽执守凝心入定、不肯舍弃的修行人。）

```
四更兰。法身体性不劳看。看则住心便作意，作意还同妄想团。
放四体，莫攒玩。任本性，自公官。善恶不思即无念，无念无思是涅槃。
```

大意是：法身的体性不必去看，一看就是住心，就是作意，作意仍和一团妄想一样。放松四体，不要刻意把玩，任运本性，它自会作主。善恶都不思量，就是无念；无念无思，就是涅槃。

```
五更分。菩提无住复无根。过去舍身求不得，吾师普示不忘恩。
施法药，大张门，去障膜，豁浮云，顿与众生开佛眼，皆令见性免沉沦。
```

大意是：菩提无住，也无根可寻。过去舍身去求也求不到，我的老师普遍开示，此恩永不敢忘。他施与法药，大开法门，除去眼中的障膜，拨开浮云，一下子为众生打开佛眼，使大家都见性，免于沉沦。

```
真乘实罕遇，至理信幽深。
欲离相非相，还将心照心。
髻中珠未得，衣里宝难寻。
为报担麻者，如何不重金！
```

大意是：真正的大乘实在难遇，至理确实幽深。想要离开相与非相，却还拿心去照心；髻中的明珠还没有得到，衣里的宝珠也难以寻见。奉告那些执意担麻的人：为什么不看重真金呢！
