# 憨山《观楞伽经记》（二十八）圣智五难与不立无生宗

【经文】观楞伽阿跋多罗宝经记卷第六。宋天竺三藏沙门求那跋陀罗译。明建邺海印沙门释德清笔记。一切佛语心品第三之下

憨山科判说：前面破二执、通断二障已经完毕。以下双遣智与境，以说明无智亦无得，分二：先遣所观之境，次遣能观之智。遣境之中又分二：先遣事境，次遣理境。

## 遣所观事境：大慧五难

【经文】大慧复白佛言：如世尊所说：以彼彼妄想，妄想彼彼性，非有彼自性，但妄想自性耳！

【憨山记】这是顺着佛的话复述，将要发起诘难。由于佛先前说诸法本无自性，只是妄计有自性而已，所以这里复述。"彼"，指彼彼种种。唐译说："如世尊说：由种种心分别诸法，非诸法有自性，但妄计耳。"这是复述佛说，下面就义理立难。

【经文】世尊！若但妄想自性非性、自性相待者，非为世尊如是说烦恼清净无性过耶？一切法妄想自性非性故。

【憨山记】这是诘难染与净都无，成断灭之过。佛将要显示境空而智有，所以先遣事境。

大慧因为听佛说诸法都无自性，只是妄想，心想：若诸法只是妄想分别，没有实体相对待，那就是根本没有诸法之性了。若诸法果真绝无自性，岂不是世尊说众生的染习烦恼与如来的清净涅槃全都无性？若染净都无，就堕于断灭之过。为什么？因为世尊说一切法只是妄想分别，没有实体。这是怀疑境空了心也断了。"非为"，犹如说"岂不是"。下面佛回答：妄境虽空，圣智实有。

【经文】佛告大慧：如是，如是，如汝所说。大慧，非如愚夫性自性妄想真实，此妄想自性非有性自性相。然，大慧，如圣智有性自性，圣知、圣见、圣慧眼，如是性自性知。

【憨山记】这是说遍计所执本无，圆成实性实有，不堕断灭之过。

"如是如是"，是姑且认可的话。意思是：若果真如大慧所说，那就是断灭之过了。佛说：我说诸法无性，是因为诸法本来寂灭，不是像凡愚分别的那样有真实之事。所以唐译说："一切凡愚分别诸法，而诸法性非如是有，此但妄执，无有性相。"所以说"此妄想自性非有性自性相"。意思是这些法只是妄想分别而有自性，其实没有像他所分别的那种性自性相，所以说"然"。

所说的诸法无性，只是无遍计的妄想，哪里是绝无真性？比如自觉圣智确实有性自性之事，这是圣知、圣见、圣慧眼明知明见有性自性的，不是绝无，谁说是断灭？这就是依他、遍计执为无，圆成为实有，只是"相有性无，情有理无"罢了。所以《唯识三十颂》说：「由彼彼遍计，遍计种种物，此遍计所执，自性无所有。依他起自性，分别缘所生，圆成实于彼，常远离前性。」

【经文】大慧白佛言：若使如圣，以圣知、圣见、圣慧眼，非天眼、非肉眼，性自性如是知，非如愚夫妄想。世尊，云何愚夫离是妄想？不觉圣性事故。

【憨山记】这是承接上面所说有圣智之事，诘难世尊也堕于有见，这是难其自语相违。

大慧的意思是：若在妄想之外果真有圣智之事，允许圣知、圣见、慧眼明知明见，只是不是天眼、肉眼所能知见，也不是愚夫的妄想境界，那么愚夫中能离妄想的人，也应当许他知见了，为什么愚夫离了这妄想却不觉圣性之事？大慧心中认为二乘就是愚夫中能离妄想的人，为什么世尊往往呵斥他们不见佛性？意在诘难其自语相违。以下辗转发起五难，以成立"堕有"之过。

【经文】世尊！彼亦非颠倒非不颠倒。所以者何？谓不觉圣事性自性故，不见离有无相故。

【憨山记】这是诘难凡圣不分。"非颠倒"是圣人，"非不颠倒"是凡愚。

大慧的意思是：若圣智实有，却不是知觉的境界，那么凡愚不知，也可以称为圣人了，所以说"彼亦非颠倒"。无奈凡愚现前不觉、不能明见，这又不是"非不颠倒"。为什么？既说有圣智之事，又不是所知之境，如今凡夫既然对此"不知"，就不可称为凡；可是它明明有而凡夫不能知，又不可称为圣。这就堕于凡圣不分之过了。

【经文】世尊！圣亦不如是见，如事妄想，不以自相境界为境界故。世尊！彼亦性自性相，妄想自性如是现，不说因无因故，谓堕性相见故。

【憨山记】这是诘难圣人若有所见，也堕于凡情。

意思是：凡愚执著，以自己的境界为境界；圣人的智照与凡夫不同，所以说"圣亦不如是见，如事妄想"。之所以不同，是因为不以自境界为境界。如今若圣人实有圣智作为自己的境界，就免不了执著，正是所谓「若存圣解，即堕凡情」，也就同于凡夫的妄见了。

圣之所以同于凡，是因为那圣智境界被执为有自体，许它明知明见。既然可以知见，也就同于凡夫的妄想境界了。所以说"彼亦性自性相，妄想自性如是现"，"彼"指圣智境界。为什么？因为在佛法中，不论有因无因，只要有可知可见的，就堕于有法。如今圣智既有可见，岂不同于凡夫的妄见？所以说"谓堕性相见故"。

憨山科判说：以上立难。以下指出过失。

【经文】异境界，非如彼等如是无穷过。世尊！不觉性自性相故。

【憨山记】这是解释上面的难义，以成立过失。

凡夫的境界种种差别，不比圣智境界平等一如，所以说"异境界非如"。"彼等"的意思是：纵然许圣智境界与凡夫相同，就堕于"多因只感一果"之过。这样因异而果一，因果不分，坏乱三界之相，招致无穷过失。为什么？因为坏乱诸法之相，因果混淆，所以说"不觉性自性相故"。"不觉"是不知，犹如说不能辨别。

【经文】世尊，亦非妄想自性、因性、自性相，彼云何妄想非妄想如实知妄想？

【憨山记】这是顺着前面"妄想无性、圣智有知"的话来立难。前面三难，都是难"无所知之境"；这一难，是难"无能知之心"。

世尊前面说"妄想无性"，又说"如实而知妄想无性者，是名圣智"。大慧的意思是：妄想之所以无性，是因为不觉性自性相；若不觉性自性相，那么妄想自性也不是因诸法的性自性相而有，所以说"亦非妄想自性因性自性相"。妄想既不因诸法而有，就是没有所知之境；既没有所知之境，就没有能知之心；既没有能知之心，圣智也就无知了。那无知的圣智，怎能分别那无可分别的妄境，而说圣智如实而知妄想？所以说"彼云何妄想非妄想如实知妄想"，"彼"指圣智。

意在诘难：若有可知之境，妄想就不是无性；若无可知之境，圣智就不是有知。况且有知就不是真知；不真就是妄，妄就不能如实知。世尊为什么说有圣智之事，能如实知妄想？这样心与境互相成立，进退都不对，又堕于自语相违，就是所谓招致无穷过失。

【经文】世尊！妄想异（二译皆云妄想相异），自性相异。世尊！不相似因妄想自性相，彼云何各各不妄想，而愚夫不如实知？然为众生离妄想故，说如妄想相不如实有。

【憨山记】这是转承上面"圣智如实知妄想"之意，从真妄一异的角度诘难。

意思是：圣智唯一，真而不二；妄想则心境多种，所以说"妄想相异，自性相异"。妄想之所以种种差别，是因为诸法有种种差别，心因境而有。因为有种种境，就有种种心，各各妄想分别各各诸法，所以说"不相似因妄想自性相"。

既然妄想的心与境各各不同，而圣智唯一，只能照一种境，怎能对各各心境不起妄想而说是如实知？若圣智明知明见各各心境就算如实知，那么愚夫分别各各心境也应当是如实知了，为什么又说愚夫不如实知？若圣智果真如实知妄想，那就是圣智实有，妄想的心境也实有了。世尊为什么又为了让众生离妄想，说诸法的妄想相不如实有？

上一难是说：圣智若有知，圣就堕于凡情。这一难是说：妄想若被如实知，凡就同于圣解。这样不但真妄不分，还又堕于多种过失。为什么？若圣智实有，就堕于有见；若妄想不实有，又堕于自语相违之过，因为说过圣智如实知妄想。

憨山科判说：以上立难。以下正面显示过失。

【经文】世尊！何故遮众生有无有见事自性计著、圣智所行境界计著堕有见？

【憨山记】这是承上二难，归结到世尊也堕有见之过。意思是：世尊若一定说圣智之事是实有，就堕于执有之过。世尊为什么只遮止众生对有无见事自性的计著，自己却对圣智所行境界反生计著而堕于有见？

【经文】说空法非性，而说圣智自性事。

【憨山记】这是总结五难，以成立世尊也堕于有无二见。意思是：世尊说诸法妄想空无自性，这是堕于无；说圣智自性事，这是堕于有。那么世尊也堕于有无二见，为什么只遮止众生？

然而上面五难，都是常情所会怀疑的，就是所谓"如言取义"的人。大慧怜愍这些人，所以预先为他们设难，希望世尊决择，以除去长夜的疑惑，并不是大慧愚顽而生起种种谬计。凡是诸难的用意都可以依此类推，读者应当知道。

【经文】佛告大慧：非我说空法非性，亦不堕有见说圣智自性事，然为令众生离恐怖句故。众生无始以来，计著性自性相圣智事，自性计著相见说空法。大慧！我不说性自性相。

【憨山记】这一段连同下文，总答五难之意。大慧设难，虽然辗转有五，正意只是诘难世尊也堕于有无之见。所以世尊回答：我说空法不堕无见，说圣智事也不堕有见。

我之所以说圣智自性事，是因为众生听说诸法无性，就生起断灭的恐怖，所以我说圣智事是实有，是为了让众生离开断灭的恐怖，不是我堕于有见。我之所以说空法，是因为众生无始以来妄计诸法，执有性自性相，而对圣智离相的境界也执为相见，妄生取著，所以我说空法，令他们舍离有无二见，不是我堕于无见。

而我所说的，不但说生死法无自性，圣智事也无自性相，所以说"我不说性自性相"。这就是所谓「若有若无有，是二悉皆离」。所以下文说：

【经文】大慧，但我住自得如实空法，离惑乱相见，离自心现性非性见，得三解脱如实印所印，于性自性得缘自觉观察住，离有无事见相。

【憨山记】这是总结答意，以显示言语不生心。

意思是：我不说诸法定有定无，只说我所住的自得如实证法，令听者闻后离开惑乱的妄想相见，不生恐怖，得见真如无相境界，知道所见的心外无法，所以说"离自心现性非性见"；悟得三解脱门，获得如实之印，印定诸法。而以自觉圣智观察，见法自性，远离有无一切执著，所以说"于性自性得缘自觉观察住，离有无事见相"。我所说的法，只是为了令众生如此而已，不是我堕于有无之见。

所以《净名经》说：「说法不有亦不无，以因缘故诸法生。」如来说法，应机破执，原无定法，这是三世如来说法的仪式。

憨山科判说：以上遣所观事境完毕。以下遣所观理境。

## 遣所观理境：不应立"一切法不生"宗

【经文】复次，大慧！一切法不生者，菩萨摩诃萨不应立是宗。

【憨山记】这是说明一切诸法本自无生，意在告诫听者不应起见，以显示境绝。

世尊特别这样猛然告诫，用意很深远。因为一切外道、二乘都堕于生灭的见网，不能出离，所以世尊在楞伽会上单显无生，破他们的生见。所以初卷显理究竟时，特别说"空、无生、无二、离自性相"，教以"当依于义，莫著言说"，来作总结开示。

等到大慧不能离言说相，又以言说、第一义等种种疑难，乃至以"常声"为请，佛以"无生如幻"回答。而大慧又疑佛自语相违，佛又特别开示名句形身本无自体，以显示如来不说之说。恐怕他不通达无说之义，又明白告以四种记论，于是直指说"一切法不生"，不容起见，以显示离言说相。这是世尊极尽为人披肝露胆之处。

可是大慧终究生灭心不亡，一重重起见，世尊已一重重破斥。到了上面又以相续、解脱为请，世尊回答说一切相续不生，本无相续不相续相。到这里，不但生灭之见枯竭，而且令圣凡情尽，可谓百尺竿头更进一步了。可是大慧仍然缠绵不已，甚至怀疑佛也堕于有无二见。世尊回答说：我虽说空说有，却不堕有无，因为意不在言。我说法，以如实印印定诸法，以显示言语不生心。到这里，无生之旨已经像黑白分明一样灿然。

然而世尊预见听者又会随语生解，一定会执"无生"为实有，立定一个"无生"的主意而起臆见，这样又堕于外道邪见了。所以在这紧要处一提，猛然斥而诫之说：我说一切法不生，我的弟子不应立这个宗。因为在此法中，才有丝毫意见，便落入生死窠臼，就成了佛法中的外道。

所以六祖对永嘉说：「汝甚得无生意。」永嘉说：「无生岂有意耶？」六祖说：「无意谁当分别？」永嘉说：「分别亦非意。」六祖说：「如是，如是。」

【经文】所以者何？谓宗一切性非性故，及彼因生相故。

【憨山记】这是征问并解释外道所立的不生宗有两种过失。

外道所计不出断常二见，所以所立的不生宗有两种：一是妄计诸法断然灭尽，以此为不生，所以说"一切性非性故"，这是断见。二是计另有一个异因能生诸法，称为作者，如中国庄周所说「生生者不生」，认为由那不生者能生万法，正如印度所说的作者不生而为生因。他们若说不生者是生因，那这个因就是生相了，所以说"及彼因生相故"，这是常见。这是指出其宗体，下面显示其过失。

【经文】说一切法不生宗，彼宗则坏彼宗。一切法不生彼宗坏者，以宗有待而生故。

【憨山记】这是指出外道所立之宗有"能别不极成"的过失。〔译注：CBETA 此句断作"有能别不？极成过也"，当连读为因明宗过之"能别不极成"。〕

佛说外道所立的不生宗，自己就坏了不生之义。为什么？因为其宗有待而生。他们两种"不生"之义，都是有待而成的。断见的不生有待：要待诸法灭尽，才显出不生之义。常见的不生有待：要待有生法，才显出不生。既然都是有待的，哪里是真不生？所以《中论》说：「若法因待成，是法还成待。」名虽不生，还是成了生法。所以其宗自坏不生之义，也名为"自教相违"。

【经文】又彼宗不生，入一切法故不坏。相不生故，立一切法不生宗者，彼说则坏。

【憨山记】这是指出其宗过失的缘由，并以正法来拣别。

其宗之所以坏，是因为其宗所立的"不生"，堕入有无断常等一切法中。一切法都是生灭无常，而他们依有无来立宗，其实没有出离生法；虽然口说不生，义理实际上是生。所以堕于自教相违之过，是违背自宗，所以说"彼宗不生，入一切法故"。

若以正法拣别：我的法以"不坏相"为不生，因为生即无生；而他们以"坏相"为不生。既然是坏相，就是无常，哪里是真无生？他们的坏相，一是以断灭为不生，这是坏了生相；一是以不生能生，这是坏了不生相。如今以我的不坏相之法来拣别，所以他们所立的一切法不生宗，其说就坏了，因为他们的妄计不出有无生法。所以下文说出其缘由。

【经文】大慧，有无不生宗，彼宗入一切性有无相不可得。

【憨山记】这是说其宗之所以坏的缘由。我说其宗则坏，是因为他们计有无都不生，依此立宗。然而一切生灭之法不出有无，那么他们所立之宗就落入一切法中了。而且诸法本无，若有若无都不可得；有无既不可得，他们又依何处立宗？所以我说其宗则坏。唐译说："彼宗有无法皆不生，此宗即入一切法中，有无相亦不生故。""亦不生"，是说有无也本来不有。

【经文】大慧！若使彼宗不生，一切性不生而立宗，如是彼宗坏，以有无性相不生故，不应立宗。五分论多过故，展转因异相故，及为作故，不应立宗分。

【憨山记】这是以正教的因明拣别那邪宗，成立其过失，总结不许立宗之义。

"若使"，犹如"设使"。佛说：设使他们依一切性而立宗，其宗就自坏，因为一切法的有无性相本自不生。一切诸法本自无生，又何必用他们来立宗？所以他们不应依此立宗。而且他们所立之宗，若用正教因明的五分来勘验，就犯了多种过失：辗转的因相与宗不合，多有异相；不但因不合宗，宗的自体也不能成立。为什么？因为他们计作者为不生。所以我教诸弟子，对于无生之义不应再立宗分。

"五分论多过"：五分就是一宗、二因、三喻、四合、五结。"多过"是宗有九过，因有十四过，同喻有五过，异喻有五过，共三十三过。外道所立的三支，若以正法拣辨，只要有一过未遣除，就属邪宗。因为因与喻只是用来成立宗体的，所以因不能转、喻不齐，都不能成宗。所以"展转因异相及为所作故"就成多过，所以不应立宗。

五分之义详载于《因明入正理论》，因为义广，恐怕繁琐，不能全部列出。懂得这个，就能定佛法的纲宗，摧伏邪见。读者应当探讨此论，或许能得其要旨。

【经文】谓一切法不生，如是一切法空，如是一切法无自性，不应立宗。

【憨山记】这是总结前义。前面说"空、无生、无二、离自性相"，如今说不生既不应立宗，那么空、无性也都不应立宗。因为只有言说而都无实义，凡所分别都不是如实知见。

【经文】大慧！然菩萨摩诃萨说一切法如幻梦，现不现相故，及见觉过故，异说一切法如幻梦性，除为愚夫离恐怖句故。大慧！愚夫堕有无见，莫令彼恐怖远离摩诃衍。

【憨山记】这是如来教诸菩萨说法的规式。

问：菩萨对于不生之法既然不应立宗，应当说什么法？答：菩萨应当说一切法如幻如梦，现而不现。幻梦虽现，其实不现，意在显示诸法虽生，其实无生。诸法本自不生，而现有生，不是法在生，而是众生见觉之过，妄见有生。所以应当说一切法如幻梦之性，不可说诸法实有不生。

然而也有说"不生"的，那是为了令愚夫离开恐怖，不得已而以"不生"之句截断他们的生见。因为一切法不生，不容有说，起心动念就堕于生死。为愚夫说不生，是因为愚夫一向坚执有无实法，一旦说如幻梦，便生恐怖，就远离大乘，断佛种性。若不以不生之句随机开导，他们就与佛法绝缘，菩萨也失去了慈悲。所以说"愚夫堕有无见，莫令彼恐怖远离摩诃衍"。摩诃，汉译为大；衍，汉译为乘。菩萨这样说法，就得到二通之相了。

【经文】尔时，世尊欲重宣此义，而说偈言：无自性无说，无事无相续，彼愚夫妄想，如死尸恶觉（唐译云恶觉如死尸）。一切法不生，非彼外道宗，至竟无所生，性缘所成就。一切法不生，慧者不作想，彼宗因生故，觉者悉除灭。

【憨山记】这是通颂五难一章：空、无生、无自性，本离言说相、离心缘相，以说明外道不应立宗。

"无事"就是空；因为诸法本空，所以无相续。只是愚夫妄想，于不实之中计以为实，这样的恶觉如死尸一般无知，只是徒增秽污。这样看来，空无自性不可思议，而不生之义，哪容外道妄计而作为宗？他们所立的不生，至于毕竟断灭、无所生之法，因为不通达"缘生无性，无性缘生"，所以说"至竟无所生性"。

"缘所成就"下句的"性"字，义贯上句来读；"所成就"的"所"字，当作"不"字看。所以唐译说："以彼所有生，非缘所成故。"

然而一切法不生之义，唯在有智之人忘心默契而已，不应作想。何况他们的宗是因生相而立的，哪里是真不生？所以"觉者悉除灭"，因为他们的不生也是生相。

【经文】譬如翳目视，妄见垂发相，计著性亦然，愚夫邪妄想。施设于三有，无有事自性，施设事自性，思惟起妄想。相事设言教，意乱极震掉，佛子能超出，远离诸妄想。

【憨山记】这是颂诸法本无，只是妄想才有，以告诫佛弟子不应起见。空中本无毛轮，因眼有翳才有；比喻真如中本无三界诸法，因妄想而计有。愚夫只执假名，动乱心识；具正知见的人应当远离。所以唐译说：「三有唯假名，无有实法体，由此假施设，分别妄计度。假名诸事相，动乱于心识，佛子悉超过，游行无分别。」

【经文】非水水想受，斯从渴爱生，愚夫如是惑，圣见则不然。圣人见清净，三脱三昧生，远离于生灭，游行无所有。修行无所有，亦无性非性，性非性平等，从是生圣果。

【憨山记】这是颂说明三界之相没有不同，只是圣凡之见各异。三界本无实法，而愚夫妄见为实有，如同阳焰不是水而作水想，这是从渴爱所生。愚夫如此，圣智哪会这样？因为圣见清净，所见的三界空洞无物，当下便证解脱三昧，远离生灭。唐译说："常行无相境。修行无相境，亦复无有无，有无悉平等，是故生圣果。"由于凡夫所见有差别，所以有业果相续；圣人所见三界无异，所以生圣果。所以经中说：「不如三界，见于三界。」

【经文】云何性非性？云何为平等？谓彼心不知，内外极漂动，若能坏彼者，心则平等见。

【憨山记】这是颂征问并解释上义，以说明圣凡平等。三界是一，为什么凡愚见有见无？为什么圣人见平等？因为愚夫不了三界本空，妄计心境为实有，所以内外极其漂动。若能了达这一点，当下就平等了。平等，是寂灭的异名。就是所谓「未达境唯心，起种种分别；达境唯心已，分别即不生」。

憨山科判说：以上遣所观之境完毕。
