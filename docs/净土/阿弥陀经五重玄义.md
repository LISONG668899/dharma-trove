# 阿弥陀经五重玄义

明·蕅益智旭大师 著

## 缘起

诸佛怜悯众生的迷惑沉沦，根据不同根机施设教化。归元虽无二路，方便却又多门。一切方便门中，最直接最圆满的，就是念佛求生净土。在一切念佛法门中，最简单最稳当的，就是信愿专持佛号。

净土三经都在世间流传，但古大德独将《阿弥陀经》列为日课。这是看出持名一法，普遍适合上中下三根，事理无不包摄，宗门教下无不统摄，不可思议。

古来注疏，历代不乏其人，但年久湮没，留存不多。云栖大师的《疏钞》，广大精微；幽溪大师的《圆中钞》，高深博大。皆如日月当空，有目共睹。只是文字丰富义理深繁，边际难测，初学者信愿难以据之建立。

我不揣愚钝，再作要解。不敢与二位前辈标异，也不必强求一致。譬如侧看成峰，横看成岭，虽都不尽庐山真面目，但各自亲见庐山之一分。

以下解释阿弥陀经的五重玄义。

## 第一　释名

此经以能说、所说者立名。佛者，此土本师释迦牟尼佛，乘大悲愿力，降生五浊恶世，自觉觉他，一切法无不遍知遍见。

说者，表达心中所怀。佛以度众生为本怀，众生成佛机缘成熟，为其说难信之法，令得究竟解脱，所以欢悦而说。

阿弥陀是西方净土导师，以四十八愿接引信愿念佛众生往生极乐，永登不退转位。梵语阿弥陀，译为无量寿、无量光。总之功德智慧、神通道力、依正庄严、说法化度，样样无量。

一切佛说，通称为经。通名别名合成《佛说阿弥陀经》之名。

## 第二　辨体

大乘经典都以实相为正体。我们现前一念心性，不在内外中间，不属过去未来现在三世，不是色相，不是诸法。寻觅实相不可得，却不能说其空无；实相能生万法，却不能说其实有。

实相离一切攀缘思虑分别和语言文字相，而攀缘分别、语言文字，也不是离开心性实相另外有个自体。总之，离一切相，即一切法，离一切相故说无相，即一切法，故说无不相，必然显现为相，勉强称之为实相。

实相本体，非寂非照，却寂而恒照，照而恒寂。照而寂强名为常寂光净土，寂而照强名为清净法身。又照而寂强名为法身，寂而照强名为报身。性德寂照名法身，修德寂照名报身。修德照寂名佛陀自受用身，修德寂照名种种应化身。

寂照不二、身土不二、性修不二、真应不二，都是实相。实相无二，也无不二。所以全体显现为依正、法报、自他，乃至能说所说等等，皆是实相大印所摄。

## 第三　明宗

宗是修行要径，会合本体的关键，种种行持的纲领。所以辨明正体之后要再说明修行要点。

此经以信愿持名为修行宗要。无信不足以启愿，无愿不足以导行，无持名妙行，不足以满愿证信。

经中先陈述净土依正庄严以策励信心，接着劝发往生之愿导引行持，再示以持名念佛为修，直登不退转之圣位。

信要信六个方面：信自、信他、信因、信果、信事、信理。

信自者，信我现前一念心，本非肉团心脏，也非虚妄缘影。竖穷三际无初后，横遍十方无边涯。终日随缘而不变。十方国土，无论垢净，原是我一念心所显现。我虽昏迷颠倒，若一念回心，决定往生自心本具之极乐，不应疑虑。

信他者，信本师佛陀决无妄语，弥陀世尊决无虚愿，六方诸佛广长舌决无二话。随顺诸佛真实教诲，决心求生，不再疑惑。

信因者，深信散心念佛，尚可熏就成佛种子，何况一心不乱，岂有不生净土之理。

信果者，深信净土诸善聚会，都从念佛三昧产生。如种瓜得瓜，种豆得豆，如影随形，功不唐捐。

信事者，深信现前一念无穷尽，所以依心显现的十方世界也无穷尽。确有极乐净土在十万亿土外，极其清净庄严，并非传说。

信理者，深信十万亿国土，实不出我现前一念心外，因为心性本无内外。又深信西方依正主伴，都是我一念心中所现影像。全事即理，全妄即真，全修即性，全他即自。我心周遍，佛心也周遍，众生心也周遍。如一室千灯，光光互遍，重重交摄，不相妨碍。

如此信后，此娑婆世界是自心感召之秽土，自心既秽，理应厌离；彼极乐世界是自心感召的净土，自心既净，理应欣求。厌恶秽土要舍到究竟才无可舍，欣慕净土要取到究竟才无可取。

《妙宗钞》讲：取舍若到极处，与不取舍并无不同。

假如不在事相上取舍，只崇尚不取不舍，就是执理而废事。既废了事相，理便不圆满。若通达全事即理，则取也是理，舍也是理。一取一舍，无非法界。所以信后要发愿往生。

说到执持名号一心不乱，名号能召感功德，阿弥陀佛功德不可思议，故其名号也不可思议。名号功德不可思议，所以散心念佛成就佛种，专心执持必登不退之位。

诸经开示净土修行，千差万别。如观像观想、礼拜供养、五悔六念等，每种修成都能往生。唯独持名念佛这一法，摄根机最广，下手最容易。所以佛陀慈悲，无问而自说，特向大智舍利弗开示。此法，可说是方便中第一方便，了义中无上了义，圆顿中最极圆顿。

清水珠投入浊水中，浊水不得不清；佛号投入乱心中，乱心不得不成佛。

信愿持名，乃是一乘之真因；四种净土，乃是一乘之妙果。举因果必随之，故以信愿持名为本经之宗旨。

## 第四　明力用

此经以往生不退为力用。往生有四土，各论九品。略说往生四土的情况：

执持名号未断见思惑，随散心定心之差别，在同居土分三辈九品。若持名念佛到事一心不乱，见思惑自然脱落，往生方便有余净土。若达到理一心不乱，破无明一品至四十一品，往生实报庄严净土，也部分证得常寂光净土。若无明断尽，就是最上实报，究竟寂光。

不退有四义。一、念不退，破无明、显佛性，直生实报分证寂光；二、行不退，见思惑、尘沙惑已破，往生方便土进趋极果；三、位不退，带业往生同居土，莲花托质永离退缘。

四、毕竟不退，不论至心念、散心念、有心无心、理解不解，只要弥陀名号或六方佛名、此经名字一经于耳，哪怕千万劫后，毕竟因此而得度脱。如闻涂毒鼓远近皆丧，食少金刚决定不消。

再者，带业往生同居净土证位不退的，都与如弥勒般的补处菩萨为伴，也都一生必补佛位。上善聚会一处，虽生同居，已横超上三土；一生补佛，虽是位不退，已圆证三不退。

这样的力用，是千经万论所未曾有的。比起那顿悟正因只是出尘阶梯，要生生不退才可期佛果的，不可同日而语。宗门教下人士，怎能不深思呢？

## 第五　教相

此经属大乘经藏。又是佛陀无问自说，彻底大慈所加持。能让末法多障有情，依此直登不退圣位。所以将来经法灭尽时，特留此经住世百年，广度含识。

阿伽陀药万病总治，绝待圆融不可思议。《华严》奥藏，《法华》秘髓，一切诸佛心要，菩萨万行司南，都不出此范围。想要广泛赞叹，穷劫也说不尽。有智慧者自当了知。
