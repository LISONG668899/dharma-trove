# 乾隆大藏经

《乾隆大藏经》，又称《龙藏》，清雍正十一年（1733）开雕，乾隆三年（1738）完成，共收经、律、论及中土撰述一千六百六十九部。下列各部类按龙藏原有的编次排列，点进去可以看到所收各经，点经名即可阅读原文。阅读时可以选中文字划线收藏，也可以随时切换简体、繁体。
