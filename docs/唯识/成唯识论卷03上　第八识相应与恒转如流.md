<p class="dt-title">第八识相应与恒转如流</p>

<div class="dt-subtitle">成唯识论白话译注（七）　卷第三之上<br>护法等菩萨造　唐　玄奘译</div>

本篇要目：一、五遍行心所：触与作意　二、受、想、思　三、“相应”的含义与唯舍受　四、不与别境、善、染等心所相应　五、无覆无记　六、“触等亦如是”　七、恒转如瀑流　八、破有部与经部的因果说，立大乘缘起正理

一、五遍行心所：触与作意

外人质问：阿赖耶识与几种心所相应？论主回答：阿赖耶识恒常与触、作意、受、想、思相应。阿赖耶识从无始以来，直到转依之前，在一切阶位中，恒常与五种心所相应，因为五种心所属于遍行心所。

触的定义是：根、境、识三者和合，相似于和合时的变异，令心王与心所接触境界，是触的自性；作为受、想、思等的所依，是触的作用。

根、境、识三者互相随顺，所以称为“三和”。触依三和而生，又令三和和合，所以说触就是三和。三者和合时，都具有顺生心所的功能，称为“变异”。触相似于变异而生起，所以称为“分别”。

【译注】依《述记》，“分别”在此是“相似”的意思，不是思量分别。触与三和合时生起心所的功能相似，所以说“分别变异”。

根的变异力量引生触时，胜过识和境，所以《集论》等只说“分别根之变异”。

令一切心王和心所和合，共同接触同一境，是触的自性。触既然相似于顺生心所的功能，所以以作为受等的所依为作用。《起尽经》说：受蕴、想蕴、行蕴，一切都以触为缘。由此说：识、触、受等，分别由二、三、四种因素和合而生。

【译注】识由根、境二者和合而生；触由根、境、识三者和合而生；受由根、境、识、触四者和合而生。

《瑜伽师地论》只说触是受、想、思的所依，因为思在行蕴中最为主要，举思就统摄了其余的行蕴。《集论》等说触是受的所依，因为触生受最为切近和殊胜：触所取的可意等相，与受所取的顺益等相，极为邻近，引发作用最强。

触的自性是实有，不是假有。理由是：触属于“六六法”中的心所；触属于四食之一；触能作为受的缘。如同受等心所，触不就是三和本身。

【译注】经部认为触就是根、境、识三者的和合，不另有自体。论主立触为实有的心所。“六六法”指六内处、六外处、六识身、六触身、六受身、六爱身。

作意的定义是：能警觉心，是作意的自性；对所缘境引导心，是作意的作用。作意警觉应当生起的心的种子，引导心趋向境界，所以称为作意。作意也能引起心所，心是主，所以只说引心。

有人说：作意令心回转趋向别的境界；或者，作意在一个境界上把持心令心安住。论主破斥：两种说法都不合道理。照第一种说法，作意只在转换境界时才有，就不是遍行；照第二种说法，作意与定没有区别。

二、受、想、思

受的定义是：领纳顺境、违境、非顺非违境的相，是受的自性；生起爱，是受的作用。受能引起希望相合、希望相离、既不希望相合也不希望相离的欲。

有人说：受有两种。第一种是境界受，领纳所缘境。第二种是自性受，领纳与受同时俱生的触。只有自性受是受的自相，因为境界受与其余心所共有领纳所缘的相。

【译注】依《述记》，二受说是正理师的主张，即众贤论师一系。

论主破斥：二受说不合道理，因为受决定不缘取与受同时俱生的触。如果说受相似于触而生，就称为领纳触，那么一切相似于因的果，都应是受的性质。受既然以触为因，就应称为“因受”，怎能称为“自性受”？

正理师辩解：如同国王享用各国城邑的赋税，受能领纳触所生的受体，所以称为自性受。论主回答：国王之喻也不合道理，违背了正理师自己的主张，因为正理师不承认心能自证。

正理师辩解：受不舍弃自己的自性，所以称为自性受。论主回答：照此道理，一切法都不舍弃自己的自性，一切法都应是受的自性。所以正理师所说，只能诱哄婴儿。

论主正面说明：境界受并不与其余心所共有。领纳顺、违等相，决定属于受自己，称为境界受，因为领纳顺违是受独有的作用。

想的定义是：对境界摄取影像，是想的自性；施设种种名言，是想的作用。要先安立境界的界限相状，才能随之生起种种名言。

思的定义是：令心造作，是思的自性；对善品等驱使心，是思的作用。思能取境界正确的因相等，驱使自心造作善等行为。

五种心所既然都属于遍行，所以决定与藏识相应。遍行的含义，后文会详细解释。

三、“相应”的含义与唯舍受

触等五种心所，与异熟识的行相不同；触等五心所与异熟识的时间相同、所依相同，所缘相似、体数相等，所以称为相应。

【译注】相应有四个条件：同一时间生起；依同一个根；所缘的影像相似；心王一个，每种心所也各一个，体数相等。

阿赖耶识的行相极不明了，不能分别违境和顺境的相，微细地、同一类别地相续运转，所以只与舍受相应。

阿赖耶识相应的受只是异熟，随着过去引业而运转，不待现前的因缘，只随善恶业的势力运转，所以只是舍受。苦受与乐受是异熟生，不是真异熟，因为苦受与乐受要等待现前的因缘，所以不与阿赖耶识相应。

阿赖耶识恒常没有转变，有情恒常执为自己内在的我。阿赖耶识如果与苦受、乐受相应，就有转变，有情怎能执为我？所以阿赖耶识只与舍受相应。

外人质问：阿赖耶识既然只与舍受相应，阿赖耶识怎能也是恶业的异熟？论主回答：既然承认善业能感招舍受，恶业也应能感招舍受，因为舍受不违背苦品和乐品，如同无记法，善业恶业都能感招。

四、不与别境、善、染等心所相应

外人质问：阿赖耶识为什么不与别境等心所相应？论主回答：因为别境心所与阿赖耶识的行相互相违背。

欲，对所喜好的事物希望而运转；阿赖耶识任运而转，没有任何希望。

胜解，对已决定的事物印可执持而运转；阿赖耶识瞢昧，没有任何印持。

念，对曾经熟习的事物明白记忆而运转；阿赖耶识昏昧微弱，不能明白记忆。

定，令心专注于一个境界；阿赖耶识任运而转，刹那刹那各别缘取。

慧，对功德与过失等事物简择而运转；阿赖耶识微细昏昧，不能简择。

所以阿赖耶识不与别境心所相应。阿赖耶识只是异熟性，所以也不与善心所、染污心所等相应。恶作等四种不定心所，即使属于无记性的，也因为有间断，决定不是异熟，所以也不与阿赖耶识相应。

五、无覆无记

法有四种：善、不善、有覆无记、无覆无记。

外人质问：阿赖耶识属于哪一种？论主回答：阿赖耶识只是无覆无记，因为阿赖耶识是异熟性。

异熟如果是善，或者是染污，流转和还灭就都不能成立：恒常是善，就不会流转生死；恒常是染污，就不能还灭解脱。阿赖耶识是善法和染法的所依，如果阿赖耶识是善或是染，就与另一方互相违背，不能同时作为善染二者的所依。阿赖耶识是所熏，如果阿赖耶识是善或是染，就如同极香或极臭的东西，不能再接受熏习；没有熏习，染净的因果都不能成立。所以阿赖耶识只是无覆无记。

“覆”是指染污法，因为染污法障碍圣道，又能遮蔽心，令心不清净。阿赖耶识不是染污，所以称为“无覆”。

“记”是指善和恶，因为善和恶有可爱或不可爱的果报，以及殊胜的自体，可以标记、分别。阿赖耶识不是善也不是恶，所以称为“无记”。

【译注】“记”的意思是可以预先标记将招什么果。善可以记为将招可爱果，恶可以记为将招不可爱果；阿赖耶识既不招乐果也不招苦果，无从标记，所以称为无记。

六、“触等亦如是”

颂中“触等亦如是”，是说如同阿赖耶识只属于无覆无记性，触、作意、受、想、思也是如此，因为一切相应的法，性质必定相同。

触等五心所如同阿赖耶识，也是异熟，所缘与行相都不可知，缘取三种境，与五法相应，是无覆无记，所以颂中说“触等亦如是”。

有一家论师认为：触等五心所如同阿赖耶识，也是异熟，也是一切种，乃至也是无覆无记，因为颂中说“亦如是”，没有加以简别。

论主破斥：触等持种的说法不合道理。原因如下。

触等心所依于识，不自在，如同贪、信等心所，不能接受熏习，怎能如同识一样执持种子？

触等如果也能接受熏习，一个有情就应有六种种子的体。如果一个有情有六种种子，果法生起时，从哪个种子生？道理上不能说从六个种子生起，因为从没见过多个种子生出一株芽。如果说果法只从一个种子生起，其余五个种子就无用了。也不能说六个种子依次生果，因为六个种子同时熏成，势力相等。也不能说六个果同时生起，否则一个有情在一刹那中，就会有六个眼识同时生起。

持此说的论师辩解：谁说触等也能接受熏习、执持种子？论主回答：如果触等不能受熏持种，怎能说触等如同识一样称为一切种？

持此说的论师辩解：触等五心所有似种子的相，所以称为一切种。理由是：触等与识的所缘相等；无色界的触等也有所缘；一切心法必定有亲所缘缘，所以触等必定以似种子的相为所缘。似种子的相，不作为因缘生起现行识等，如同触等心所上显现的似眼根等，不是识的所依；也如同画出来的火，没有能烧的作用。

论主破斥：似种相的辩解不合道理。触等所缘似种子等相的意义，应放在后面“执受处”中，与识相类比。所以颂中前面所说的“一切种”，决定是指受熏、能持种子的意义。不然的话，本颂就有重复的过失。

持此说的论师所说“亦如是”没有简别，一切都可类比，决定不能作为证据。不然的话，触等五心所也应能了别，触等也应与触等相应。由此可知，“亦如是”是随其所应而说，并不是指一切方面都相同。

七、恒转如瀑流

外人质问：阿赖耶识是断灭还是常住？论主回答：阿赖耶识非断非常，因为阿赖耶识“恒转”。

“恒”是说，阿赖耶识从无始以来，同一类别地相续，恒常没有间断，因为阿赖耶识是施设三界、五趣、四生的根本，阿赖耶识体性坚固，能执持种子令种子不失。

“转”是说，阿赖耶识从无始以来，念念生灭，前后变异，因灭果生，不是常住、不是单一，所以可以被前七转识熏成种子。

“恒”字遮除断灭，“转”字表示非常住。阿赖耶识如同瀑流，因果法尔如此。

瀑流的水，非断非常，长时相续，所到之处有所漂没；阿赖耶识也是如此，从无始以来，生灭相续，非常非断，漂没有情，令有情不能出离。

瀑流即使被风等吹击，生起种种波浪，水流不断；阿赖耶识也是如此，即使遇到众缘，生起眼识等，阿赖耶识恒常相续。

瀑流漂荡水中上下的鱼、草等物，随着水流不舍离；阿赖耶识也是如此，与内在的习气和外在的触等心所，恒常一起随转。

以上的法与喻，意在显示阿赖耶识无始以来因果非断非常的道理。阿赖耶识的体性从无始以来，刹那刹那，果生因灭。

```
果生故非断，因灭故非常。
非断非常，是缘起理。
```

大意：后果生起，所以不是断灭；前因灭去，所以不是常住。非断非常，就是缘起的道理。

所以说阿赖耶识“恒转如流”。

八、破有部与经部的因果说，立大乘缘起正理

说一切有部质问：你们认为过去和未来不是实有，说非常还可以；说非断，怎能成立？断灭怎能成为缘起的正理？

论主反问：过去和未来如果是实有，可以承认非断，怎能说非常？常住也不能成为缘起的正理。

有部质问：难道指出别人的过失，自己的主张就成立了？论主回答：不摧破邪说，就难以显示正理。

论主正面说明：前因灭去时，后果立即生起，如同秤的两头，一头低下、一头扬起，同时发生。因果如此相续，如同水流，何必依靠过去和未来才成立非断？

有部质问：现在有因时，后果还没有生，因是谁的因？现在有果时，前因已经灭了，果是谁的果？既然没有因果，谁能远离断常？

论主反问：如果有因时已经有了后果，果既然本来就有，何必等待前因？因的意义既然不存在，果的意义怎能存在？没有因也没有果，难道就远离断常了？

有部辩解：我们的因果意义，是依法的作用而成立的，所以你的诘难与我宗无关。论主回答：法的体既然本来就有，法的作用也应本来就有，因为作用所等待的因缘也本来就有。由此，你们所说的因果决定不能成立。

应当相信大乘缘起的正理。缘起的正理深妙，远离言说，因果等名言都是假立施设。观察现在之法有引生后法的作用，就假立一个“当来之果”，对照着说“现在之因”。观察现在之法有酬报前法的相状，就假立一个“过去之因”，对照着说“现在之果”。所谓“假立”，是说现在的识显现出似过去、似未来的相。依现识假立，因果的道理就清楚显明，远离断常二边，契合中道。一切有智慧的人，都应顺此修学。

【译注】观现在法假立因果的一段，说破了唯识的时间观：过去与未来都不是另外存在的实体，只是现在一念识上显现的影像。现在之法带着“酬前”的相，就说有过去之因；带着“引后”的作用，就说有未来之果。因果始终只落在现在一念之中。

其余部派说：即使没有过去和未来，仍然有因果恒常相续的意义。现在之法即使极为迅速，也有初生和后灭两个时刻。生的时刻酬报前因，灭的时刻引生后果。时刻有两个，体只有一个。前因正在灭时，后果正在生；体相不同，都是实有。两时一体的因果不是假立施设，又远离断常，也没有前面的难题。有智慧的人，谁会舍弃两时一体的主张而相信别的？

论主破斥：其余部派的说法只有空话，毫无实义。一念之中怎能有两个时刻？生与灭互相违背，怎能同在现在？灭如果在现在，生就应在未来。有，所以称为生，生既然在现在；无，所以称为灭，灭怎能不在过去？灭如果不是无，生就应不是有。生既然是现在的有，灭就应是现在的无。生与灭两相互相违背，怎能体是一个？如同苦与乐，从未见过同体的事。生与灭如果同时，就不应有两个时刻；生与灭如果异体，怎能说体相同？所以，生与灭两个时刻同在现在、同依一个体，在道理上必定不能成立。

经部师等所说的因果相续，在道理上也不能成立，因为经部师等不承认有能执持种子的阿赖耶识。由此，应当相信大乘所说因果相续的缘起正理。

以上卷第三之上译毕。
