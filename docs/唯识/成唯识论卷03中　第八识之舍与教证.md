一、阿罗汉位舍

外人质问：阿赖耶识从无始以来恒转如流，到什么阶位才究竟舍弃？论主回答：到阿罗汉位才究竟舍弃。

诸圣者断除烦恼障，究竟断尽时，称为阿罗汉。烦恼障断尽时，阿赖耶识中的烦恼粗重永远远离，所以说“舍”。

颂中所说的阿罗汉，通指三乘无学果位，因为三乘无学都已永远杀害烦恼贼，都应受世间的妙供养，都永远不再受分段生死。

【译注】“阿罗汉”的梵语含义有三：杀贼、应供、不生。论中三个理由正与三义相应。

外人质问：怎么知道阿罗汉通指三乘？论主回答：《瑜伽师地论·摄抉择分》说，诸阿罗汉、独觉、如来，都不成就阿赖耶识。《集论》又说，诸菩萨得菩提时，一下子断尽烦恼障和所知障，成为阿罗汉和如来。

二、不退菩萨也不成就阿赖耶识

外人质问：如果只有阿罗汉才舍阿赖耶识，菩萨的烦恼种子还没有永远断尽，不是阿罗汉，就应都成就阿赖耶识。为什么《摄抉择分》又说，不退菩萨也不成就阿赖耶识？

论主回答：《摄抉择分》是说，二乘无学果位回心趣向大菩提的人，必定不会退转而生起烦恼障，因为趣向菩提，就转名为不退菩萨。回心的不退菩萨不成就阿赖耶识，就包括在阿罗汉中。所以《摄抉择分》的论文与“阿罗汉位舍”并不矛盾。

另外，不动地以上的菩萨，一切烦恼永不现行；在法流中任运而转；能在一种行中生起一切行；刹那刹那转增进步。到不动地才称为不退菩萨。不动地以上的菩萨，异熟识中的烦恼种子还没有断尽，缘取异熟识的我见、我爱等，已不再把异熟识执藏为自己内在的我，因此永远舍弃“阿赖耶”的名称，所以说不成就阿赖耶识。不动地以上的菩萨，也称为阿罗汉。

【译注】不动地是第八地。八地以上，第七识中的俱生我执永不现行，阿赖耶识不再被执为我，所以“阿赖耶”之名在八地舍去。八地舍名是论主所立的正义。

三、破“初地以上已舍阿赖耶名”

有一家论师认为：初地以上的菩萨，已证得二空所显的真理；已得到根本智和后得智两种殊胜智；已断除分别起的烦恼障和所知障；能在一种行中生起一切行；即使为了利益众生而生起烦恼，也不造作烦恼的过失。所以初地以上的菩萨也称为不退菩萨。初地以上的菩萨，俱生烦恼还没有断尽，缘取阿赖耶识的分别我见、我爱等，已不再把阿赖耶识执藏为自己内在的我，因此也舍弃“阿赖耶”的名称，所以说不成就阿赖耶识，也称为阿罗汉。所以《集论》说：十地菩萨还没有永远断除一切烦恼，十地菩萨的烦恼如同被咒语和药物所制伏的毒，不起一切烦恼的过失，在一切地中如同已断烦恼的阿罗汉，所以也称为阿罗汉。

论主破斥：初地舍名之说不合道理。七地以前，菩萨还有俱生的我见、我爱等，执藏阿赖耶识为自己内在的我，怎能已经舍弃“阿赖耶”的名称？

如果以分别起的我见、我爱等不再执藏，就称为舍，那么预流果等有学位，也应已舍弃“阿赖耶”的名称。如果承认，就违背了诸论的说法。

持此说的论师辩解：地上菩萨所起的烦恼，都由正知摄持，不成为过失，预流果等不可能由正知摄持烦恼，怎能用预流果来类比菩萨？

论主回答：地上菩萨在前六识中所起的烦恼，由正知摄持，不成为过失；地上菩萨的第七识在有漏心位，任运现行，执藏阿赖耶识，第七识执藏的情形与预流果等怎能不同？由此可知，“初地以上已舍阿赖耶名”的说法不合道理。

阿罗汉断尽阿赖耶识中的烦恼粗重，究竟断尽，不再执藏阿赖耶识为自己内在的我，因此永远失去“阿赖耶”的名称，称为舍。并不是舍弃整个第八识的体，否则阿罗汉就没有识来执持种子，当下就入无余涅槃了。

【译注】“舍”只是舍名，不是舍体。所舍的是“被执为我”的那一层身份；第八识本身在阿罗汉位、菩萨位、佛位始终存在，名称随状态改变。

四、第八识的七种名称

第八识，一切有情都成就，随着不同的意义，立种种名称。

称为“心”，因为种种法熏习的种子在第八识中积集。

称为“阿陀那”，因为第八识执持种子和诸色根，令种子和色根不坏。

称为“所知依”，因为第八识能作为染净一切所知诸法的依止。

称为“种子识”，因为第八识能普遍任持世间、出世间的一切种子。

以上四种名称，通于一切阶位。

称为“阿赖耶”，因为第八识摄藏一切杂染品法，令杂染法不失；又被我见、我爱等执藏为自己内在的我。“阿赖耶”的名称，只在凡夫和有学位存在。无学位和不退菩萨，不再有杂染法执藏的意义，所以不称为阿赖耶。

称为“异熟识”，因为第八识是能牵引生死的善业与不善业所感的异熟果。“异熟识”的名称，只在凡夫、二乘和诸菩萨位存在。如来地不再有异熟无记法，所以不称为异熟识。

称为“无垢识”，因为第八识是最极清净的一切无漏法的所依。“无垢识”的名称，只在如来地才有。菩萨、二乘和凡夫位，第八识执持有漏种子，可以接受熏习，还没有得到善净的第八识。如契经说：

```
如来无垢识　是净无漏界
解脱一切障　圆镜智相应
```

大意：如来的无垢识，是清净无漏之界，解脱一切障碍，与大圆镜智相应。

“阿赖耶”的名称过失最重，又最先被舍，所以颂中特别说“阿罗汉位舍”。

异熟识的体，菩萨在将得菩提时舍弃，声闻、独觉在入无余依涅槃时舍弃。无垢识的体，没有舍弃的时候，因为利益安乐有情没有穷尽的时候。

“心”等名称通于一切阶位，随其意义而说。

【译注】七个名称，可依三个阶段来记：“阿赖耶”到八地或阿罗汉位为止；“异熟识”到成佛为止；“无垢识”从成佛开始，永无穷尽。“心”“阿陀那”“所知依”“种子识”四名贯通始终。

五、有漏与无漏二位

第八识总共有两个阶位。

第一是有漏位。有漏位的第八识属于无记性，只与触等五种心所相应，只缘取前面所说的执受与处两种境。

第二是无漏位。无漏位的第八识只属于善性，与二十一种心所相应，即遍行五、别境五、善十一。

理由如下：遍行五种，与一切心恒常相应。无漏位的第八识，常乐于证知所观的境，所以有欲；对所观的境恒常印持，所以有胜解；对曾经领受的境恒常明记，所以有念；世尊没有不定的心，所以有定；对一切法恒常抉择，所以有慧；极清净的信等恒常相应，所以有善十一；没有染污，所以没有烦恼和随烦恼；没有散动，所以没有不定心所。

无漏位的第八识也只与舍受相应，因为任运恒时平等而转。无漏位的第八识以一切法为所缘境，因为大圆镜智普遍缘取一切法。

六、教证之一：《阿毗达磨经》二颂

外人质问：怎么知道第八识离开眼等识另有自体？论主回答：以圣教和正理作为决定的标准。

先说圣教。大乘《阿毗达磨经》中说：

```
无始时来界　一切法等依
由此有诸趣　及涅槃证得
```

大意：从无始以来就有的界，是一切法平等的所依；由于有无始之界，所以有生死诸趣，也有涅槃的证得。

第八识的自性微细，所以用作用来显示第八识。颂中前半，显示第八识作为因缘的作用；后半，显示第八识为流转和还灭作依持的作用。

“界”是因的意思，就是种子识。种子识从无始以来展转相续，亲生诸法，所以称为因。

“依”是缘的意思，就是执持识。执持识从无始以来，与一切法平等作为依止，所以称为缘。执持识能执持诸种子，又作为现行法的所依，就是变现为诸法，又作为诸法的依止。

变现为诸法，是说第八识变现为器世间和有根身。作为诸法的依止，是说第八识作为前七转识的所依：第八识能执受五色根，眼等五识依五色根而转；第八识又作为末那识的依止，第六意识依末那识而转。末那识和意识属于转识，如同眼等识依于同时的根，第八识既然也是识，也应以第七识作为同时的所依。

以上是第八识作为因缘的作用。

“由此有”，是说由于有第八识。“有诸趣”，是说有善趣和恶趣。由于有第八识，执持一切顺流转的法，令有情流转生死。惑、业、生都是流转，诸趣是果，最为殊胜，所以特别说“诸趣”。或者，“诸趣”一词，通指能趣与所趣，诸趣的资具也可以称为趣。一切惑、业、生都依第八识，以上是第八识为流转作依持的作用。

“及涅槃证得”，是说由于有第八识，所以有涅槃的证得。由于有第八识，执持一切顺还灭的法，令修行者证得涅槃。

“及涅槃证得”一句有三种解释。第一种：颂中只说能证得涅槃的道，因为涅槃本身不依第八识而有。第二种：颂中只说所证得的涅槃，因为涅槃是修行者真正所求的。第三种：颂中同时说涅槃与道，因为二者都属于还灭一类：“涅槃”显示所证的灭，“证得”显示能得的道。由能断的道，断除所断的惑，到究竟尽时，证得涅槃。能断、所断、证得，都依第八识，以上是第八识为还灭作依持的作用。

另外，颂中第一句显示第八识的自性无始以来恒常存在，后三句显示第八识总别地作为杂染法和清净法的所依。杂染法是苦谛和集谛，就是所趣的生，以及能趣的业和惑。清净法是灭谛和道谛，就是所证的涅槃和能证的道。杂染法和清净法都依第八识而有，依转识等不能成立。

或者，第一句显示第八识的体无始相续，后三句显示第八识作为三种自性的所依，即依他起性、遍计所执性、圆成实性，依次对应。

颂中所说的一切意义，离开第八识都不能成立。

《阿毗达磨经》中又说：

```
由摄藏诸法　一切种子识
故名阿赖耶　胜者我开示
```

大意：一切种子识能摄藏诸法，所以称为阿赖耶；对殊胜的人，我才开示。

本识具有一切种子，所以能摄藏一切杂染法，依此建立“阿赖耶”的名称。阿赖耶识摄藏诸法，不同于数论的自性转变为大等二十三法，因为种子与果法的体不是一，能依与所依都是生灭的。第八识与杂染法互相摄藏，又被有情执藏为我，所以称为阿赖耶。

已入见道的诸菩萨，得到真实的现观，称为“胜者”。胜者能证解阿赖耶识，所以世尊专为胜者开示。或者，一切菩萨都称为胜者，见道以前未能证解阿赖耶识，能信解并求阿赖耶识的转依，所以也为未入见道的菩萨说。

前七转识没有摄藏诸法的意义。

七、教证之二：《解深密经》与《入楞伽经》

《解深密经》也说：

```
阿陀那识甚深细　一切种子如瀑流
我于凡愚不开演　恐彼分别执为我
```

大意：阿陀那识极其深细，一切种子如同瀑流；我对凡夫和愚者不开演，恐怕凡愚分别执为自我。

第八识能执持诸法种子，能执受色根和根所依处，也能执取结生相续，所以称为阿陀那。

无种性的有情不能穷究阿陀那识的底，所以说“甚深”；趣寂种性的二乘不能通达阿陀那识，所以说“甚细”。阿陀那识是一切法的真实种子，遇到缘的激发，就生起转识的波浪，恒常没有间断，如同瀑流。

“凡”就是无种性的有情，“愚”就是趣寂种性的二乘。世尊恐怕凡愚对阿陀那识起分别执着，执为自我，堕落恶趣，障碍生起圣道，所以不为凡愚开演。只有第八识具有甚深细、如瀑流的相状。

【译注】“趣寂”指一心趣向寂灭涅槃的声闻、独觉定性种性。

《入楞伽经》也说：

```
如海遇风缘　起种种波浪
现前作用转　无有间断时
藏识海亦然　境等风所击
恒起诸识浪　现前作用转
```

大意：如同大海遇到风，生起种种波浪，波浪现前起作用，没有间断的时候。藏识之海也是如此，被境界等风吹击，恒常生起诸识的波浪，现前起作用。

眼等诸识，没有如同大海恒常相续、生起诸识波浪的作用，所以可知另有第八识。

以上无量大乘经中，都另外说有第八识。

八、大乘真是佛说的七种理由

外人质问：小乘不承认大乘经，怎能用大乘经来证明？

论主回答：一切大乘经都随顺无我，违背数取趣，即实我；舍弃流转，趋向还灭；赞叹佛法僧，毁斥外道；表明蕴等诸法，遮止自性等外道主张。乐于大乘的人承认大乘经能显示无颠倒的道理，因为大乘经属于契经，如同《增一阿含经》等，属于至教量。

弥勒菩萨又以七种理由，证明大乘经真是佛说。

第一，先前没有预记。如果大乘经是佛灭度后，有人为了破坏正法而说的，世尊为什么不像预记其他将来可怕的事那样，预先作出记别？

第二，本来同时流行。大乘与小乘的经教本来同时流行，凭什么知道唯独大乘不是佛说？

第三，不是他人的境界。大乘所说广大甚深，不是外道等的思量境界，外道的经论中从未说过；即使为外道说，外道也不会信受。所以大乘经不是“非佛说”。

第四，应当极成。如果说大乘是过去的其他佛所说，不是现在的释迦佛所说，那么大乘教是佛所说，道理就已极成。

第五，有与无的道理。如果有大乘，就应相信诸大乘教是佛所说，因为离开大乘就找不到大乘。如果没有大乘，声闻乘教也不应存在，因为离开大乘，决定没有成佛的道理；没有佛，谁出世宣说声闻乘？所以说声闻乘是佛所说、大乘不是佛所说，不合正理。

第六，能够对治。依大乘经勤修的人，都能引生无分别智，能正确对治一切烦恼，所以应相信大乘是佛所说。

第七，意义异于文字。大乘所说的意趣甚深，不可随文字取义，便生毁谤，说不是佛语。

所以大乘真是佛说。如《大乘庄严经论》的颂总括七种理由说：

```
先不记俱行　非余所行境
极成有无有　对治异文故
```

大意：先前没有预记，大小乘同时流行，不是外道的境界，佛说之义极成，有大乘才有小乘，能对治烦恼，意义异于文字。以此七因，证明大乘是佛说。

九、小乘诸部的密意说

小乘其余部派的经中，也以密意说阿赖耶识另有自性。

大众部的《阿笈摩》中，以密意称第八识为“根本识”，因为第八识是眼识等的所依止，譬如树根是茎等的根本。眼等识没有根本的意义。

上座部经和分别说部论师，都以密意称第八识为“有分识”。“有”指三有，即三界；“分”是因的意思。只有第八识恒常周遍，作为三有的因。

化地部称第八识为“穷生死蕴”。离开第八识，没有别的蕴法能穷尽生死边际，没有间断的时候。无色界中，色法间断；无想天等，其余的心等都灭了；不相应行离开色心等，没有另外的自体，不相应行无自体已经极成。所以只有第八识称为穷生死蕴。

说一切有部的《增一经》中，也以密意称第八识为阿赖耶，说“爱阿赖耶、乐阿赖耶、欣阿赖耶、喜阿赖耶”。阿赖耶识是贪爱总缘、别缘三世之境的对象，所以立爱、乐、欣、喜四个名称。有情执阿赖耶识为真正的自内我，在未断我执之前，恒常生起爱着。所以阿赖耶识是真正的爱着之处，不应执着其余的五取蕴等为真正的爱着处。

【译注】下面论主逐一排除其余对象，证明唯有阿赖耶识才是贪爱真正、恒常的落脚处。

生在一向苦受处的有情，对其余五取蕴不生爱着，恒常厌恶，心想：我什么时候才能舍弃此生的生命、众同分与受苦的身心，让我自在地享受快乐？所以其余五取蕴不是真正的爱着处。

五欲也不是真正的爱着处，因为离欲的人不贪着五种妙欲，爱我之心照样生起。

乐受也不是真正的爱着处，因为离开第三禅染的人厌离乐受，爱我之心照样生起。

身见也不是真正的爱着处，因为相信无我的有学对身见不生贪着，对内我的爱照样生起。

转识等也不是真正的爱着处，因为求灭心的有学厌离转识等，爱我之心照样生起。

色身也不是真正的爱着处，因为离开色染的人厌离色身，爱我之心照样生起。

不相应行离开色心等，没有另外的自体，所以也不是真正的爱着处。

凡夫和有学生起我爱时，对其余诸蕴或爱或不爱，对阿赖耶识的我爱决定生起。所以只有阿赖耶识是真正的爱着处。由此，有部经中所说的“阿赖耶”，决定只是显示阿赖耶识。

以上卷第三之中译毕。

下一篇：卷03下　第八识理证之一。论主转入正理证明，依经中所说，逐一论证：持种心、异熟心、趣生体、有执受、持寿暖识、生死时心、识与名色互为缘，若没有第八识，都不能成立。
