一、第一证：不共无明

前面已经引了圣教，现在显示正理。

契经说：不共无明微细恒行，覆蔽真实。如果没有第七识，经中所说的不共无明就不应存在。

一切凡夫在一切时分，恒常生起迷于真理的不共无明，覆蔽真实的义理，障碍圣慧之眼。如偈颂说：

```
真义心当生　常能为障碍
俱行一切分　谓不共无明
```

大意：证悟真义的心将要生起时，常常能够障碍；在一切时分中与心同行，称为不共无明。

所以契经说：凡夫恒常处在长夜之中，被无明所盲，昏醉缠心，从来没有醒觉。如果凡夫位有暂时不起无明的时候，就违背了经义。同在凡夫位，迷于真理的无明有时运转、有时不运转，不合道理。依六识，不共无明都不能成立，因为六识有间断，不共无明恒常染污。承认有末那，就没有间断的过失。

二、“不共”的含义

外人质问：染污的末那恒常与四种烦恼相应，与末那俱起的无明，为什么称为“不共”？论中列出三家。

第一家认为：与末那俱起的我见、我慢、我爱，不是根本烦恼，所以与末那俱起的无明称为不共，有什么过失？

第二家破斥：第一家的说法与道理和圣教都相违。纯随烦恼中没有说我见、我慢、我爱三种；我见、我慢、我爱属于根本烦恼；处处都说染污末那与四种根本烦恼恒常相应。

第二家立义：应当说四种烦恼中，无明是主。我见等三种与无明同时俱起，无明仍称为不共，因为末那从无始以来，恒常在内昏迷，从不省察，痴的力量最为增上。与无明俱起的我见等，应称为相应；如果我见等作为主时，也应称为不共，如同无明，承认我见等作主时名不共，也没有过失。

第三家认为：末那俱起的痴称为不共，如同佛的不共法，只有第七识才有。

外人质问：照此说法，其余诸识相应的烦恼，第七识中没有的，也应称为不共？第三家回答：依殊胜的意义立“不共”的名称，并不是彼此所没有的都称为不共。第七识相应的无明，无始以来恒常运转，障碍证悟真义的智慧，如此殊胜的作用，其余诸识没有，只有第七识才有，所以称为不共。

外人质问：既然如此，与末那俱起的另外三种烦恼也应称为不共？第三家回答：无明是主，唯独得到“不共”的名称；或者，也承认其余三种称为不共，只是为了对照其余诸识中的痴，所以只说无明。

不共无明总共有两种。第一种是恒行不共，其余诸识所没有，就是第七识相应的无明。第二种是独行不共，第七识中没有，就是第六识中不与贪等俱起、单独生起的无明。所以《瑜伽师地论》说：无明有两种，与贪等俱起的，称为相应无明；不与贪等俱起的，称为独行无明。

独行无明中作为主的，只属于见道所断。如契经说：诸圣者有学，不共无明已永远断除，所以不造新业。独行无明中不作为主的，也属于修道所断，因为忿等随烦恼都通于见道所断和修道所断。

恒行不共无明，其余部派没有；独行不共无明，大乘与其余部派都有。

【译注】两种“不共”含义不同：恒行不共的“不共”，是“只有第七识才有”；独行不共的“不共”，是“不与其他烦恼共起”。前者是本节论证的重点：一种时时不断、比任何粗显烦恼都更深的无明，只能安在第七识上。

三、第二证：意识的不共所依

契经又说：眼根与色境为缘，生起眼识；乃至意根与法境为缘，生起意识。如果没有第七识，经中所说作为意识之缘的意根就不应存在。

如同五识必定有眼等增上的、不共的、同时的所依，意识既然属于六识，在道理上应承认意识也有增上、不共、同时的所依。如果没有第七识，意识的不共所依怎能存在？

不能说色法是意识的所依，因为意识不是色法；如果意识以色法为所依，意识就应如同五识，没有随念分别和计度分别两种分别。

也不能说五识没有同时的所依，因为五识与五根同时运转，如同芽与芽的影子同时存在。识与根既然必定缘取同一境界，就如同心王与心所，决定同时。

由此道理，大家共许的意识，如同眼等识，必定有不共的、能显示自己名称的、不属于等无间缘的增上所依，因为意识属于大家共许的六识之一。

【译注】“能显示自己名称的所依”：眼识因眼根而得名，意识也应因一个同时存在的意根而得名，同时的意根就是第七识。前一刹那已灭的意，属于等无间缘，不能作为同时的所依。

四、第三证：思量名意

契经又说：思量称为意。如果没有第七识，经中所说的意就不应存在。

意识现前时，作为等无间缘的前念之意已经灭了，不存在；过去和未来在道理上不存在，所以前念之意的思量作用决定不能成立。既然如此，怎能称为意？

如果说是假说，在道理上也不对，因为没有真正的思量，假说依据什么而立？

如果说前念之意在现在时曾经有思量，那时前念之意称为识，怎能说为意？

所以可知，另有第七末那，恒常审察思量，才真正称为意。已灭的前念之意，依第七末那假立“意”的名称。

五、第四证：二定的差别

契经又说：有无想定和灭尽定。如果没有染污的末那，二定就应没有差别。

无想定和灭尽定都灭除了六识及六识的心所，体和数都没有不同。如果没有染污的末那，二定中一个有、一个无，二定有什么差别？

如果说二定在加行、界地、所依等方面有差别，在道理上也不对，因为二定差别的原因，正是由于有染污末那；如果没有染污末那，二定差别的原因也就不存在。所以决定应另有染污末那。

【译注】无想定是凡夫所修，定中末那的我执仍在；灭尽定是圣者所修，定中染污末那已被伏灭。两种定的根本差别，就在于有没有染污末那。

六、第五证：无想天中的我执

契经又说：无想天的有情，在一期生命中，心王与心所都灭了。如果没有第七识，无想天的有情就应没有染污。

无想天的有情长时间没有六转识，如果没有末那，就没有我执。在其余各处，具足烦恼系缚的有情，不会在一期生命中完全没有我执。无想天的有情如果没有我执，就应如同涅槃，就不会被圣贤共同诃斥厌弃。

外人辩解：无想天的有情在初生和临终时有转识，所以没有无我执的过失。论主回答：中间长时间没有我执，仍有过失。

外人辩解：过去和未来有我执，所以没有无我执的过失。论主回答：过去和未来既非现在，也非常住，不存在，仍有过失。

外人辩解：无想天的有情成就我执的“得”。论主回答：所得的我执没有，能得的“得”也就没有；不相应法前面已经遮破。

外人辩解：无想天的有情有我执的熏习种子。论主回答：没有藏识，熏习也就没有；其余诸法接受熏习，前面已经辨明不合道理。

所以应另有染污的末那，在无想天中恒常生起我执。由此，圣贤共同诃斥厌弃无想天。

七、第六证：凡夫三性心中恒带我执

契经又说：凡夫在善心、染心、无记心时，恒常带着我执。如果没有第七识，经中所说的恒带我执就不应存在。

凡夫起善、恶、无记三性心时，外在造作种种行为，内在恒常执着自我。由于执着自我，令六识中所起的布施等行为，不能忘掉相状。

所以《瑜伽师地论》说：染污末那是诸识的依止，染污末那未灭时，相了别的系缚不能解脱；末那灭了之后，相缚才得解脱。

所谓“相缚”，是说对境界的相不能了达为如幻事等，由此被见分和相分所拘束，不得自在，所以称为相缚。依相缚的意义，有偈颂说：

```
如是染污意　是识之所依
此意未灭时　识缚终不脱
```

大意：染污的意，是诸识的所依；染污的意未灭时，诸识的系缚终究不能解脱。

【译注】“施等不能亡相”说破了凡夫修善的根本局限：布施时心中总有“我在布施”“有人接受”“有物被施”的相，三相不亡，善行就是有漏。三相俱亡，要等末那的我执灭去。

八、有漏的成立

在善心和无覆无记心时，如果没有我执，善心等就不应是有漏。理由如下。

同一身心相续中，六识的烦恼与善心等不同时俱起。过去和未来的烦恼缘缚，在道理上不存在。善心不能由于他人的烦恼而成为有漏，否则也可以由于他人的智慧而成为无漏。

也不能说另有一种随眠，是不相应行，现前相续生起，由此善心等成为有漏，因为不相应行不是实有，已经极成。

也不能说善心等从有漏种子生起，所以成为有漏。因为有漏种子最初没有原因可以成为有漏；不能由于有漏种子，善心就成为有漏，否则有学的无漏心也应成为有漏，因为有学的无漏心中也有有漏种子。

由烦恼引发的布施等业，与烦恼不同时俱起，所以烦恼不是布施等业成为有漏的正因，因为“有漏”的名称，表示与漏同时俱起。无记的业不由烦恼引发，又怎能成为有漏？

论主正面说明：一切有漏法，都是由于与自身现行的烦恼同生同灭、互相增益，才成为有漏。由此熏成有漏法的种子，后来现起时，有漏的意义就成立了。凡夫如此，有学也是如此。无学的有漏法，不与漏俱起，从过去的有漏种子生起，所以成为有漏，在道理上没有违背。

由于有末那恒常生起我执，令善等法成为有漏。如果没有末那，善等法决定不是有漏。所以可知，另有第七识。

【译注】“漏”是烦恼的异名。一个善念之所以是“有漏”的，是因为同一刹那心底有末那的我执相伴。前六识的烦恼不能与善心同时，唯有恒时不断的末那我执能满足“同时俱起”的条件。

证明有第七识的道理很多，随着《摄大乘论》略述六种。一切有智慧的人都应随顺信学。

有些经中只说六识，应知是随顺小乘的方便说法，或者是随着所依的六根而说六识。识的种类，实际上有八种。

九、第三能变：第八颂与六识的名称

以上已经说完第二能变。外人质问：第三能变的相状是怎样的？世亲菩萨用颂回答：

```
次第三能变　差别有六种
了境为性相　善不善俱非
```

大意：第三能变有六种差别，以了别境界为自性和行相，通于善、不善、非善非不善三性。

论中解释：在思量能变识之后，应说明了境能变识的相状。了境能变识的差别总有六种，因为随着六根和六境的种类不同，称为眼识乃至意识。

六识随根立名，因为根具备五种意义：依、发、属、助、如根。

【译注】五义分别是：识依于根，根能发起识，识属于根，识助根，识如根。五义都显示根与识的密切关系，所以六识随根立名。五义的细节，《述记》有详释，此处不展开。

六识都依意根运转，随着不共的所依而立“意识”之名，如同五识，名称不会混淆。或者，只依意根，所以称为意识。辨析识的得名时，心和意不属于此例。

或者称为色识乃至法识，随境立名，因为随顺“识”的含义：对六种境界了别，称为识。色等五识只了别色等，法识能普遍了别一切法；或者，能了别法境，唯独得到“法识”的名称。所以六识的名称没有混淆的过失。

以上随境立六识名，是依五色根未自在的阶位而说。如果得到自在，诸根互用，一根所发的识能缘取一切境界，只可随根立名，没有混淆的过失。

《大乘庄严经论》说：如来的五根，每一根都在五境上运转。《庄严论》只是依粗显的同类境而说。《佛地经》说：成所作智抉择有情心行的差别，起身语意三业的变化，作四种记别等；如果五识不普遍缘取一切，就没有抉择心行、起化作记的能力。六转识的所依和所缘粗显，各家共许，所以颂中不说。前面随着方便已经说了六识的所依，下面随着方便说六识的所缘。

十、了境为性相

颂中“了境为性相”，同时显示六识的自性和行相：识以了别境界为自性，又以了别境界为行相。由此也兼带解释了所立的名称：能了别境界，称为识。

如契经说：什么是眼识？就是依于眼根，了别诸色。乃至什么是意识？就是依于意根，了别诸法。经中只说不共的所依，以及未转依阶位见分所了别的境。其余的所依和所了别，前面已经说过。

十一、六识的三性

外人质问：六转识属于什么性质？论主回答：属于善、不善、俱非三性。“俱非”就是无记，非善非不善，所以称为俱非。

能为此世和他世带来顺益，称为善。人天的乐果在此世能带来顺益，不能为他世带来顺益，所以不称为善。

能为此世和他世带来违损，称为不善。恶趣的苦果在此世带来违损，不能为他世带来违损，所以不称为不善。

在善与不善、利益与损害的意义中，不能记别，所以称为无记。

【译注】唯识判善恶的标准是“二世”：只有能延续到来世的利益才是善，只有能延续到来世的损害才是不善。人天乐果、恶趣苦果本身只是果报，不再生出新的果报，所以都是无记。

六转识如果与信等十一种善心所相应，就属于善性；与无惭等十种心所相应，就属于不善性；都不相应，就属于无记性。

十二、六识三性能否同时

关于六识的三性能否同时，论中列出两家。

第一家认为：六识的三性不同时俱起，因为六识同向外门运转，三性互相违背。五识必定由意识导引，与意识同时生起，同缘一境，才成为善或染。如果承认五识的三性同时运转，意识那时就应通于三性，意识通三性违背正理，所以决定不同时俱起。《瑜伽师地论》等说藏识一时与转识相应、三性同时俱起，是依多念而说，如同说“一心”并非只有一次生灭，所以没有矛盾。

第二家，即护法论师，认为：六识的三性可以同时俱起，因为率尔心和等流心的眼等五识，或多或少可以同时生起。五识与意识决定同时生起，善等性质不一定相同。第一家所设的责难，对此毫无作用。

所以《瑜伽师地论》说：如果遇到声音的缘而从定中出来，与定相应的意识同时运转，另有耳识生起；并不是只有与定相应的意识能取到声音。否则，对声音没有领受，就不应出定。并不是取到声音时就出定，领受声音之后，如果有希望，然后才出定。

在定中的耳识，率尔听到声音，在道理上应不是善，因为未转依的人，率尔堕入的心决定是无记。由此确实证明，与五识俱起的意识，不一定与五识同为善等性质。

诸处只说与五识俱起的意识也缘取五境，没有说与五识同一性质。《杂集论》说等引位中没有五识，是依多数情况而说。

如果五识中三性同时运转，意识偏向专注于哪一识，就与哪一识同性；没有偏注时，意识就是无记性。所以六转识的三性可以同时俱起。

在得自在的阶位，六识只属于善性，因为佛的色心等属于道谛，又已经永远灭除了戏论的种子。

【译注】护法论师的证据很具体：入定的人听到声音，定中的意识仍是善，耳识率尔闻声是无记，二者同时并存。人在同一刹那里，可以一边心中善念专注，一边耳朵无记地听到声响。

以上卷第五之中译毕。
