总标纲要分第一

一、世亲菩萨释论开头的长偈

【按】下面的长偈出自世亲菩萨《摄大乘论释》的开头，不是无著菩萨的论文。世亲菩萨在长偈中礼敬三宝，称叹无著菩萨，说明自己作释的缘由。长偈依意义分为六段，每段之后给出大意。

第一段，礼敬佛宝：

```
诸破所知障翳暗
尽其所有如所有
诸法真俗理影中
妄执竞兴于异见
斯由永离诸分别
无垢清净智光明
获得最胜三菩提
惑障并习断常住
能无功用于十方
随诸有情意所乐
开示殊胜极广大
三种解脱等方便
由无分别有大悲
生死涅槃俱不住
由摄妙慧巧方便
究竟至极自他利
```

大意：诸法有真谛与俗谛的道理，有尽所有性（诸法的全部差别）与如所有性（诸法的真实本性）。世间的人在诸法上妄生执着，种种异见竞相兴起。诸佛永远远离一切分别，以无垢清净的智慧光明，破除了遮蔽所知的所知障黑暗，获得最殊胜的菩提，断尽烦恼障、所知障以及习气，常住不变。诸佛不用功用，就能在十方随顺有情的意愿，开示殊胜广大的三解脱门等方便。诸佛由无分别智而不住生死，由大悲而不住涅槃，摄持妙慧与善巧方便，自利与利他都达到究竟。

第二段，礼敬法宝：

```
如是世尊等所觉
等所开示微妙法
若能于此善修行
必获寂然甘露迹
诽谤决定没无底
甚久无能大苦海
```

大意：诸佛同样证悟、同样开示的微妙之法，有人善能依法修行，必定获得寂静的甘露境界，也就是涅槃。有人诽谤此法，必定沉没在无底的大苦海中，极长的时间无力出离。

第三段，礼敬僧宝：

```
学无学僧居道果
普胜一切所余僧
善逝无垢功德河
真实于中而沐浴
为世无上良福田
虽复投于微少善
而便广大如地空
慧者由斯得解脱
```

大意：有学、无学的圣僧安住于圣道与圣果，胜过其余一切僧众，在善逝无垢的功德河中真实沐浴，是世间无上的良福田。在圣僧福田中种下微少的善根，善根也会变得广大，如同大地与虚空。有智慧的人依靠圣僧福田而得解脱。

第四段，归命礼敬：

```
故我至诚身语思
频修无倒归命礼
```

大意：因此，我以至诚的身、语、意，屡屡以无颠倒的心归命礼敬三宝。

第五段，叹时世浑浊，称叹无著菩萨：

```
轨范诸师今减少
真法正理多浑浊
皆由聪睿邪慢人
依自寻思失教证
我师于此非前后
逢事圣者大慈尊
依止无动出世间
放大法光三摩地
阐扬妙法流清誉
如日舒光遍十方
文光无垢最甚深
诸了义经所随顺
广大句义皆微妙
悉以绮饰自庄严
能令聪敏者融心
无谄无憍生爱敬
极难通法慧无滞
不住利养称誉中
于乐常无染著心
故名决定称自德
诸贤圣者常亲近
一切世间无不知
无著名称普皆闻
功德显然同所赞
```

大意：现在能为人师范的轨范师越来越少，真实的法和正确的道理多半已经浑浊，原因在于一些聪明而带着邪慢的人，只依自己的寻思揣度，丢掉了圣教和证悟的依据。我的老师无著菩萨亲近承事圣者大慈尊慈氏菩萨，依止不动摇的出世间“放大法光三摩地”，阐扬妙法，美名如日光遍照十方。无著菩萨的文字明净无垢，极其深奥，随顺一切了义经，句义广大微妙，以华美的文辞庄严，能使聪敏的人心意融通，没有谄曲和骄慢，生起敬爱。极难通达的法，无著菩萨都能通达无碍。无著菩萨不住于利养和称誉，对安乐没有染著之心，所以“无著”的名号确实与无著菩萨的功德相称。诸位贤圣常常亲近无著菩萨，世间无人不知，无著菩萨的名号普遍传闻，功德为大家共同称赞。

第六段，说明作释的缘由：

```
无尽辩者等所雨
甘露文义微妙法
多从彼闻自力微
少受犹如乞雨鸟
从广抉择集少分
以言略释摄大乘
愿此所作遍饶益
怖于极大文海者
```

大意：无著菩萨等具有无尽辩才的大士，如降雨一般宣说甘露般的文句、义理与微妙之法。我从无著菩萨那里听受了很多，自己的能力微薄，所得不多，如同仰天乞求雨滴的鸟。我从广大的抉择之中收集少分，用言语简略解释《摄大乘论》。愿我所作的释论，普遍利益那些面对浩瀚文海而心生怖畏的人。

【译注】乞雨鸟，传说中只饮天上雨水的鸟，世亲菩萨借以自比只能承接无著菩萨所降的法雨。长偈中“我师于此非前后”一句，“非前后”的确切含义两家释论都没有解释，大意中略去，存疑。

二、论的缘起

在《阿毗达磨大乘经》中，一位已经善能悟入大乘的菩萨，在薄伽梵面前，为了显示大乘的体性广大，说道：依大乘而言，诸佛世尊有十相殊胜的殊胜语。

【按】世亲菩萨在释论中，接着广泛解说了三藏。三藏是素怛缆藏（经）、毗奈耶藏（律）、阿毗达磨藏（论）；三藏又因下乘、上乘的差别成为声闻藏和菩萨藏；三者称为“藏”，是因为能摄持一切应知的义理。世亲菩萨说，建立三藏有九种因缘：为对治疑惑立经藏，为对治耽著欲乐与自我苦行两边立律藏，为对治执取己见立论藏；经藏宣说三学，律藏成办戒学与定学，论藏成办慧学；经藏宣说法与义，律藏成满法与义，论藏对法与义抉择善巧。三藏都为解脱生死，解脱依熏、觉、寂、通四者：听闻熏习内心，思惟而觉悟，修止而寂静，证观而通达。世亲菩萨又说三藏各有四义：经有依、相、法、义；论有对、数、伏、通；律有犯罪、等起、还净、出离。以上都是世亲菩萨对三藏的通论，不是《摄大乘论》本文的内容。

【按】印顺法师《摄大乘论讲记》说明了“阿毗达磨”在本论中的含义：无著菩萨师资把阿毗达磨解说为对法、数法、伏法、通法，其中对法最重要，是现观现证之法；在大乘法中，阿毗达磨就是无分别智，对观所应知的法性，对向无住涅槃。印顺法师又认为，阿毗达磨本是大小乘论藏的通名，一部大乘经称为阿毗达磨，是因为此经由菩萨宣说。

【按】印顺法师《摄大乘论讲记》说，“体大”可以理解为“大体”：小乘学者认为小乘法之外没有大乘法的体，无著菩萨要显示的是，离开小乘法之外，大乘确实有独立的法体。

三、十相殊胜

第一是所知依殊胜的殊胜语。第二是所知相殊胜的殊胜语。第三是入所知相殊胜的殊胜语。第四是彼入因果殊胜的殊胜语。第五是彼因果修差别殊胜的殊胜语。第六是在修差别之中，增上戒殊胜的殊胜语。第七是在修差别之中，增上心殊胜的殊胜语。第八是在修差别之中，增上慧殊胜的殊胜语。第九是彼果断殊胜的殊胜语。第十是彼果智殊胜的殊胜语。诸佛世尊在契经中所说的种种文句，由上面所说的十种殊胜，显示大乘真是佛语。

【按】印顺法师《摄大乘论讲记》说，两个“殊胜”各有所指：前一个殊胜是所显示的法殊胜，后一个殊胜是能显示的语教殊胜。法殊胜，所以语教也殊胜。

【世亲释】所知，是应当可以了知的法，就是杂染法和清净法，也就是三种自性。“依”是因的意思。所知依本身就是殊胜，所以称为所知依殊胜。入所知相，就是悟入所知相，也就是唯识性。彼入因果：能入所知相称为彼入，也就是悟入唯识；因是加行时修习的世间布施等波罗蜜多，果是通达唯识时成就的出世间布施等波罗蜜多。彼因果修差别：修是反复数习，反复数习在诸地中展转增上，越来越殊胜，所以称为差别，就是十地。增上戒，是依戒而学，就是菩萨律仪，对一切不善不再有造作之心。增上心，是在内心而学，或依心而学，就是种种三摩地。增上慧，是趣向证悟的智慧，或依慧而学，就是无分别智。断殊胜，是以最殊胜的品类，从自身之内舍弃烦恼障与所知障，就是无住涅槃。智殊胜，是没有障碍的智慧：无分别智还有所对治的障，佛智已经离开一切障及随眠，所以佛智比无分别智更为殊胜。

四、十处唯大乘中有说

又如何能够显示：上面所说的十处，在声闻乘中从来没有见到宣说，只在大乘中处处可以见到宣说？阿赖耶识称为所知依的体。三种自性，第一依他起自性，第二遍计所执自性，第三圆成实自性，称为所知相的体。唯识性称为入所知相的体。六波罗蜜多称为彼入因果的体。菩萨十地称为彼因果修差别的体。菩萨律仪称为增上戒的体。首楞伽摩、虚空藏等诸三摩地称为增上心的体。无分别智称为增上慧的体。无住涅槃称为彼果断的体。三种佛身，第一自性身，第二受用身，第三变化身，称为彼果智的体。上面所说的十处，显示大乘不同于声闻乘，又显示大乘最为殊胜。世尊只为菩萨宣说十处。所以应当了知：只依大乘而言，诸佛世尊有十相殊胜的殊胜语。

【世亲释】声闻远离常、乐、我、净四种颠倒的分别，称为无分别；菩萨远离一切法的分别，称为无分别。两种无分别的差别就在于此。

五、十处证明大乘真是佛语

又如何由十相殊胜的如来语，显示大乘真是佛语，遮止“声闻乘就是大乘”的说法？因为十处在声闻乘中从来没有见到宣说，只在大乘中处处可以见到宣说。十处最能引生大菩提，是善成立、随顺、无违的，是为了证得一切智智。关于十处，有两首颂：

```
所知依及所知相
彼入因果彼修异
三学彼果断及智
最上乘摄是殊胜
此说此余见不见
由此最胜菩提因
故许大乘真佛语
由说十处故殊胜
```

大意：所知依、所知相、彼入、彼入因果、彼修差别、三学、彼果断与彼果智，十处摄在最上乘之中，所以殊胜。十处在大乘中见到宣说，在其余乘中见不到宣说。十处是最殊胜的菩提之因，所以许可大乘真是佛语。大乘宣说十处，所以殊胜。

【无性释】有人会质难：胜论的“六句义”在声闻乘中也从来没有宣说，在胜论的论典中处处可见，难道胜论也是佛语？所以论中不只说“声闻乘中不见”，接着又说十处“最能引大菩提”“善成立、随顺、无违”。胜论的六句义不能引生大菩提，所以不是佛语。

六、十处的次第

又为什么按照上面的次第宣说十处？诸菩萨首先要善知诸法的因，才能在缘起上得到善巧。其次要善知从缘所生诸法的相，善能远离增益和损减两边的过失。其次，善于修习的菩萨，要正确通达善所取相，使心从诸障中得到解脱。其次，通达所知相以后，菩萨在加行位所修的六波罗蜜多，由于已经证得唯识，要进一步成满，增上意乐因而得到清净。其次，清净意乐所摄的六波罗蜜多，在十地中有分分的差别，要勤加修习，需要经历三大阿僧祇劫。其次，菩萨的三学要令圆满。三学圆满以后，三学之果的涅槃和无上正等菩提，就要现前证得。所以十处按照上面的次第宣说。

【无性释】把本来没有的强立为有，称为增益；把本来有的强行否定为无，称为损减。增益和损减都称为“边”，是坠堕的意思，两边一起，就失坏了中道。对遍计所执只有增益，没有损减，因为遍计所执根本没有，要对“有”才能损减；对依他起既没有增益，也没有损减，因为依他起有体，又只是虚妄而有；对圆成实没有增益，只有损减，因为圆成实是真实有。世亲释同。

七、一切大乘尽摄于十处

又，在十处的宣说之中，一切大乘都已得到究竟。

【世亲释】一切大乘到十处为止，已经说尽。如果要说缘起，就摄入阿赖耶识。如果要说诸法的相，就摄入三自性。如果要说证得，就摄入唯识性。如果要说波罗蜜多，就摄入波罗蜜多。如果要说诸地，就摄入诸地。如果要说诸学，就摄入三学。如果要说断与智，就摄入无住涅槃和三种佛身。到十处为止，就是一切佛语。
