〔译注：本篇译第五门"得舍分齐"的开头部分，即"得具足别解脱戒的各种因缘"。窥基逐一比对四部广律（《十诵》《四分》《僧祇》《五分》）与五部律论（《毗尼母论》《摩得勒伽论》《善见论》《萨婆多论》《明了论》）所说的得戒方式，如自然得、见谛得、善来得、自誓得、论议得、受重法得、遣信得、边地五人得、中国十众得、三归得等，说明各部增减的缘由。〕

第五门　得与舍的分齐

分两部分：一是得，二是舍。

"得"中又分两部分：一是得戒的因缘，二是得戒的时节。

得戒的因缘又分两种：

1. 差别缘：只在具足别解脱戒。
2. 无差别缘：通于一切戒。

差别缘有两种：

1. 得具足别解脱戒的因缘。
2. 以羯磨得别解脱戒的因缘。

第一种因缘，通于佛和弟子；羯磨不通于佛以及独觉。两种都通于佛在世和佛灭后。

一、得具足别解脱戒的因缘

关于得具足别解脱戒的因缘，诸教说法不同，四部律、五部论，各宗说法各异。

（一）四部律

1. 《十诵律》：十种得戒

《十诵律》属于萨婆多宗，与《俱舍论》第十四卷、《律毗婆沙》、《杂阿毗昙心论》、《顺正理论》、《显宗论》、《大毗婆沙论》相同。

《十诵律》说："佛在竹园，告诉诸比丘：有十种受具足戒。"

一、自然得。就是佛和独觉，在尽智心的阶位自然得戒。

问：为什么承认有阿罗汉沙弥，可以通于没有戒；不承认独觉也通于没有戒，都是自然得？

答：因为独觉是利根。

二、见谛得。《俱舍论》等说：就是进入正性离生，也就是五比丘。

问：为什么比丘初入见道有最初得戒的，诸比丘尼最初得戒，没有见谛得的？

答：因为胜劣不同。

问：如果这样，就应当因为佛殊胜，所以佛在见谛时得戒；弟子低劣，所以在无学时得戒。为什么佛以及独觉只在尽智时得戒，初转法轮时五比丘在见谛时得戒？

答：五比丘最初理解佛法，信法增上；其余的人不是这样。

三、善来得。《俱舍论》等说：佛命"善来"，就是耶舍等。只有佛自己能作，其余的人不能，因为圆满之道所覆被。

四、自誓得。《俱舍论》等说：信佛为大师，就是大迦叶。

问：为什么《四分律》中，迦叶自己说"佛为我建立善根，上受具足"？

答：因为宗派不同。

问：其余的人为什么不能自誓得戒？

答：因为信心不够增上。

五、论议得。《俱舍论》等说：善巧酬答所问，就是苏陀夷。苏陀夷年仅七岁，佛问："你的家在哪里？"苏陀夷回答佛说："三界无家。"佛赞叹苏陀夷聪明，善于回答所问，年龄未满，也令僧众为苏陀夷授戒。并不是回答的时候就当下得戒。

问：为什么舍利弗不这样得戒？

答：因为佛命舍利弗"善来"。《西域记》中说，目连、舍利弗都是善来得戒。

六、受重法得。《俱舍论》等说：敬受八尊重法，就是大生主（摩诃波阇波提）。《十诵律》说：优婆离问："波阇波提受八重法，就是出家成为比丘尼；其余的比丘尼怎样得戒？"佛说："应当现前作白四羯磨。"

问：如果这样，当时比丘尼众还没有满足人数，诸比丘尼后来怎样得戒？如果承认最初受八尊重法的，另外还有其他比丘尼，就违背《十诵律》所说的令作羯磨。萨婆多师怎样解释？

答：《萨婆多论》说："十四年以前，以八敬法度化女人；十四年以后，以羯磨度化。"这样就没有这个过失。《五分律》也说：五百位比丘尼也是以八敬法得戒。

七、遣信得。《俱舍论》等说：就是法授尼。《五分律》说：淫女半迦尸想要前往兰若住处受具足戒，有盗贼想在路上埋伏，劫取这个女子。女子听说这件事，当时不敢前去。佛听许遥遣使者为她授具足戒。

先在比丘尼众中作完本法，把受戒的人安置在一个处所。带着十位比丘尼前往兰若处，礼拜僧众的双足。比丘尼羯磨师代为向僧众乞戒，僧众的羯磨师乃至为她作完白四羯磨以后，和尚、阿阇梨带着十位比丘尼回到原处，叫受戒的人礼拜大众的双足，在羯磨师前长跪合掌，为她宣说僧众的白四羯磨，让她听完，具足宣说二八、两四，就是八堕、四喻、八不可越、四依，乃至其余还不知道的，和尚应当为她宣说。

八、边地五人得。《俱舍论》等说：持律者作为第五人。

这里有一种解释说：因为没有僧众，最少仍需五人，四人成为僧，一人作羯磨，所以称为"持律者作为第五人"，和尚不算在数内，与《僧祇律》相同。如果少于五人，就不能成就，因为缺少法事。

这种解释有问题：如果这样，就应当四人作羯磨，一人作表白"大德僧听"，其余三人不是僧；或者应当自己表白，因为要四人才成为僧。所以五人之中，一人主持羯磨，一人作为和尚，羯磨中要牒出和尚的名字，其余三人是僧的本体，是正式所和合表白的。边地最少仍需五人，才能办成法事。

《摩得勒伽论》说："边地僧众多，只取五人，就可以称为受具足戒，僧众得到可呵责的罪。"

九、羯磨得（中国十众）。《俱舍论》等说：十众，就是在中国（印度中部）。那部律通说僧、尼得戒，所以说"羯磨"。比丘尼受戒，二部僧众最少仍各需十人，因为比丘尼犯戒的因缘多，必须在二部僧众前对受才能得戒，简择所适宜的，让她们生起羞耻，不敢犯戒。论中只依据比丘僧，所以说"十众"；又依论说，二部各十人，合称为十众，就像边地五人，也不相违。

十、三归得。《俱舍论》等说：三次说归依佛、法、僧，就是六十贤部。就是有六十位仁贤的大众共同集会，佛派遣无学圣者为这些贤众宣说三归，便得具足戒。《毗尼母论》说："诸阿罗汉教这些贤众剃发、染衣，归伏三宝，归依的心成就，就发起具足戒。"所以称为三归得，也称为三语得。

问：为什么诸比丘尼没有三归得？

答：因为没有贤众。

2. 《四分律》：五种得戒

《四分律》属于法藏部，说五种得戒：

1. 善来。
2. 上法。古来相传的解释说：成就无学，证得有余涅槃，称为上法，就得戒。所以《四分律》说："如果修道成就阿罗汉果，就称为出家受具足戒。"阿罗汉沙弥不是这一宗的义理。
3. 三归。
4. 八敬。
5. 羯磨。

这一宗的意思是：自然得就是上法，因为得无学果就成为受具足戒，不只属于佛以及独觉。

见谛得就是善来得。律中自己说：六群比丘互相议论说："迦叶不如憍陈如以善来受戒，不如毗舍离跋耆子以三归受戒，也不如婆卢波斯那以羯磨受戒，怎么能与诸比丘一起布萨、羯磨？"迦叶回答说："我在多子塔边，世尊为我建立善根，第一受具足戒。"所以最初见谛就是善来。由此也没有"信佛为大师"的得戒，因为迦叶自己说是上法得戒。

问答、遣信、边地五人、中国十众，都作羯磨，都属于羯磨所摄，所以只说五种。

3. 《僧祇律》：四种得戒

《僧祇律》属于大众部，说四种得戒。那部律说："成道五年，比丘清净；从此以后，渐渐作非法，随着事情制立，说木叉戒四种受具足法。"

1. 自觉具足：就是佛自己觉悟，最初证菩提，善受具足戒。
2. 善来：佛自己觉悟以后，在竹林园告诉诸比丘："如来处处度人，你们应当效法如来度人。"诸比丘由此也以善来度人。当时诸比丘以善来度人，不能如法，被世人讥嫌。舍利弗默然，举出这件事请问佛：同称为善来，有如法的，有不如法的，怎样让比丘善受具足戒，都如法？佛因此制定十众。
3. 十众：那部律说："和尚不在十众之内，称为受具足戒，合起来十一人。"《四分律》等只说十众，和尚在其中。
4. 五众。

那部律最初标举四种受具足戒，后来又说：大爱道比丘尼说："佛为比丘尼制定八法，我们可以广泛听闻吗？"佛为她们具足宣说八相。八相之中，前六相与《四分律》不同，后两种法相同。以这个道理推究，应当有第五种受八重法得戒，不然的话，诸比丘尼最初怎样得戒？前面只说比丘僧，所以只有四种。

这一宗的意思是：见谛、信佛为大师两种，也是自觉得，因为得阿罗汉就成为受具足戒，从佛立名，称为自觉。问答、遣信不异于中国十众，因为都是十众。没有三归得，所以不说。

4. 《五分律》：五种得戒

《五分律》属于化地部，律中有五种受具足：

1. 自然
2. 善来
3. 三归
4. 八不可越
5. 羯磨

八不可越，那部律兼及五百位比丘尼。那部律说："为你们制定八不可越法，如果能奉行，就是受具足戒。"大爱道说："如果佛说八不可越法，我和五百人应当一起顶受。"佛又说："爱道以及舍夷族的诸比丘尼，也得戒。"

这一宗的意思是：见谛、信佛为大师两种，都是自然得。问答、遣信、边地五人、中国十众四种，都就是羯磨，不另外说。这里的"自然"与《四分律》的"上受具足"，名称不同，以义理推究，与《四分律》也稍有相同。

（二）五部律论

1. 《毗尼母论》

二众各有五种，合起来是十种。

比丘的五种：

1. 善来。
2. 建立善根上受具足：就是得阿罗汉果。
3. 敕听：就是论议，言下即得。
4. 三语：就是三归。
5. 羯磨。

见谛、信佛为大师，自然得，都属于上受所摄；边地五人、中国十众就是羯磨。

比丘尼也有五种：

1. 善来。
2. 上受具足。
3. 师法：就是八敬。
4. 遣信。
5. 羯磨。

合起来有七种：一善来，二上受，三敕听，四三归，五八敬，六遣信，七羯磨。

2. 《摩得勒伽论》

十种得戒：

1. 无师：就是自然。
2. 见谛。
3. 问答：就是须陀夷。
4. 三归。
5. 自誓：就是迦叶。
6. 五众。
7. 十众。
8. 八重法：就是大生主。
9. 遣信。
10. 二部：就是诸比丘尼。

这一宗乍看与萨婆多相同，只是没有善来，因为来者舍去俗相，后来再为他授戒。边地五人、中国十众只在比丘僧中，所以比丘尼加上二部众，就是十众、二十众。

3. 《善见论》

八种得戒：

1. 善来。
2. 三归。
3. 敬授：就是见谛，因为佛教导以后，恭敬接受佛语，便得戒。
4. 问答。
5. 受重法。
6. 遣使。
7. 八语：就是比丘尼，在二部众中。以义理推究，遣信就是十二语。
8. 白四羯磨：白四就是四语。

这是说弟子，没有自然得。信佛为大师就是羯磨，因为羯磨以后才得戒。或者信佛为大师就是敬受得。边地五人、中国十众就是羯磨。

4. 《萨婆多论》

七种受具足：

1. 见谛
2. 善来
3. 三语
4. 三归
5. 自誓
6. 八法
7. 白四

这是说弟子，所以没有自然得。三语就是遣信，这是从最初的一种到那一种，由后面的一种来作。问答、边地五人、中国十众，都是白四羯磨。这是萨婆多宗，与《俱舍论》等相同，增减的数目不同，体性没有差别。

〔存疑：原文「三语即遣信。此初一至彼一来后一」，文意难解，此处依字面翻译。〕

5. 《明了论》

三乘得戒，合起来有九种圆德。"圆德"是四万二千功德，没有不具足圆满的，称为圆德。

声闻有七种：

比丘有四种：

1. 善来。
2. 三归。
3. 略羯磨：佛初成道时，听闻佛法而得戒，所以称为略羯磨，就是见谛得。
4. 广羯磨：信佛为大师，以及论议、边地五人、中国十众，都属于广羯磨所摄。

比丘尼有三种：

1. 善来。
2. 遣使：就是法授尼。瞿娄多达磨敬尊重法，佛派遣阿难传话，遥为授戒。
3. 广羯磨：就是遣信、二部等。

以上七种是声闻得戒。第八种是独觉，由有量的功德而得；第九种是佛，由无量的功德而得。这两种都是自然得。

（三）大乘的取舍

大乘中没有另外的教文，大多暂且采用萨婆多宗的十种得戒。不过敬受八法不只是大生主，这不只同于《萨婆多论》，也同于《五分律》。佛说："爱道以及舍夷族的诸比丘尼，也敬受八不可越法而得戒。"

以上是得具足别解脱戒的因缘。
