<p class="dt-title">念佛、净土与三身</p>

<div class="dt-subtitle">摄大乘论白话译注　第十九篇　彼果智分之三<br>无著菩萨造　唐　玄奘译　附世亲释、无性释</div>

本篇要目：一、念佛法身的七种念　二、清净佛土　三、法界的五种业　四、一乘的意趣　五、同一法身而有多佛　六、佛非毕竟涅槃，非毕竟不涅槃　七、受用身不是自性身　八、变化身不是自性身　九、如来身常　十、化身非毕竟住　十一、法身无别无量，仍须勤修　十二、结语

一、念佛法身的七种念

如果诸菩萨忆念佛的法身，应当由几种念来修习？简略说，菩萨忆念佛的法身，应当由七种念来修习。

第一，应当忆念：诸佛对一切法得自在而转，因为对一切世界得到无碍的神通。关于第一念，有一颂：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">有情界周遍<br>具障而阙因<br>二种决定转<br>诸佛无自在</div>

大意：有情界周遍各处，有的具有障碍，有的缺少因，在两种决定而转的情况下，诸佛也没有自在。

【世亲释】诸佛对一切法自在而转，为什么一切有情不得涅槃？有情有业等障碍，称为“具障”，即使无量佛出世，也不能令他们得涅槃。有情没有涅槃法，称为“阙因”，就是没有涅槃之因、没有种性。“二种决定”，是作业决定与受异熟决定：生为顽愚等身，是异熟障决定；当堕捺落迦等，是受异熟决定。诸佛在上述情况下没有自在。

第二，应当忆念：如来其身常住，因为真如无间地解脱垢染。

第三，应当忆念：如来最胜无罪，因为一切烦恼与所知障都已离系。

第四，应当忆念：如来没有功用，因为不作功用，一切佛事都没有休息。

第五，应当忆念：如来受大富乐，因为清净佛土是大富乐。

第六，应当忆念：如来远离诸染污，因为生在世间，一切世间法都不能染污。

第七，应当忆念：如来能成大事，因为示现等觉、般涅槃等，令一切未成熟的有情成熟，令已成熟的有情解脱。

关于七种念，有两颂：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">圆满属自心<br>具常住清净<br>无功用能施<br>有情大法乐<br>遍行无依止<br>平等利多生<br>一切佛智者<br>应修一切念</div>

大意：圆满属于自心，具足常住与清净，无功用，能施予有情大法乐，遍行而无依止，平等利益众多有情。一切佛的智者，应当修习一切念。

【世亲释】两颂依次显示七种圆满：随属自心圆满，其身常住圆满，具足清善圆满（就是最胜无罪），无功用圆满，施大法乐圆满（就是在清净佛土受大法乐），离诸染污圆满（就是遍行而无所依止，因为有所依止而遍行就有苦难，无所依止而遍行，佛常无苦，离染而遍行），平等多利圆满（就是能成大事，成熟、解脱诸有情）。

二、清净佛土

又，诸佛清净佛土的相是什么？应当了知，如菩萨藏《百千契经》序品中所说：薄伽梵安住于最殊胜光耀、七宝庄严的大宫殿中。大宫殿放大光明，普照一切无边世界；无量方所，妙饰间列；周圆无际，其量难测；超过三界所行之处；由胜出世间的善根所起；以最极自在的净识为相；是如来所都之处；诸大菩萨众所云集；无量天、龙、药叉、健达缚、阿素洛、揭路荼、紧捺洛、莫呼洛伽、人、非人等常所翼从；由广大法味喜乐所持；作诸众生的一切义利；蠲除一切烦恼灾横；远离众魔；超过一切庄严，是如来庄严的所依处；以大念慧行为游路；以大止妙观为所乘；以大空、无相、无愿解脱为所入之门；由无量功德众所庄严；由大宝花王所建立。

如上所示现的清净佛土，有显色圆满，形色圆满，分量圆满，方所圆满，因圆满，果圆满，主圆满，辅翼圆满，眷属圆满，任持圆满，事业圆满，摄益圆满，无畏圆满，住处圆满，路圆满，乘圆满，门圆满，依持圆满。

又，受用上面的清净佛土，一向净妙，一向安乐，一向无罪，一向自在。

【世亲释】经文各句与十八种圆满的对应：“最胜光耀，七宝庄严，放大光明，普照一切无边世界”，是显色圆满。“无量方所，妙饰间列”，是形色圆满。“周圆无际，其量难测”，是分量圆满。“超过三界所行之处”，是方所圆满。“胜出世间善根所起”，是因圆满，善根就是出世间的无分别智与后得智。“最极自在净识为相”，是果圆满。“如来所都”，是主圆满。“诸大菩萨众所云集”，是辅翼圆满。“天龙等常所翼从”，是眷属圆满。“广大法味喜乐所持”，是任持圆满，就是饮食。“作诸众生一切义利”，是事业圆满。“蠲除一切烦恼灾横”，是摄益圆满。“远离众魔”，是无畏圆满，没有烦恼魔、蕴魔、死魔、天魔四魔，所以无畏。“超过一切庄严，如来庄严之所依处”，是住处圆满。“大念慧行为游路”，是路圆满，就是大乘中的闻、思、修慧。“大止妙观为所乘”，是乘圆满。“大空无相无愿解脱为所入门”，是门圆满。“无量功德众所庄严，大宝花王之所建立”，是依持圆满，如同大地依风轮而住，净土依大红莲华而住。

【世亲释】“一向净妙”，净土中没有粪秽等不净之物。“一向安乐”，只有乐受，没有苦受，也没有不苦不乐受。“一向无罪”，没有不善，也没有无记。“一向自在”，不待外缘，一切所欲都随自心而成。

三、法界的五种业

又应当了知，诸佛的法界在一切时中能作五种业。第一，以救济一切有情的灾横为业，因为有情暂见佛时，就能救济盲、聋、狂等灾横。第二，以救济恶趣为业，因为拔诸有情出离不善处，安置于善处。第三，以救济非方便为业，因为令诸外道舍弃以非方便求解脱的行为，安置于如来的圣教中。第四，以救济萨迦耶为业，因为授与能超越三界的道。第五，以救济乘为业，因为拯拔想趣向其余乘的菩萨，以及不定种性的诸声闻等，安置他们修习大乘行。应当了知，在上面五种业中，诸佛的业用平等。关于五种业，有一颂：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">因依事性行<br>别故许业异<br>世间此力别<br>无故非导师</div>

大意：世间由于因、依、事、性、行的差别，所以许可业有差异；导师诸佛没有上述差别之力，所以诸佛的业没有差异。

【世亲释】世间由于因不同，有生于捺落迦、生于天、生于人乃至饿鬼的差别；依，是身体；事，是经商、务农等事务；性，是意趣；行，是所作的行业。世间由于上述差别，业有差异。诸佛作业都无功用，没有因等差别之力，所以导师的业没有差异。

四、一乘的意趣

如果与上述功德圆满相应的诸佛法身，不与声闻、独觉乘共通，佛以什么意趣说一乘？关于一乘，有两颂：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">为引摄一类<br>及任持所余<br>由不定种性<br>诸佛说一乘<br>法无我解脱<br>等故性不同<br>得二意乐化<br>究竟说一乘</div>

大意：为了引摄一类不定种性的声闻，以及任持其余不定种性的菩萨，诸佛说一乘。又由于法平等、无我平等、解脱平等，由于种性不同，由于得到两种意乐，由于变化，由于究竟，诸佛说一乘。

【世亲释】“引摄一类”，是引摄不定种性的声闻等，令其趣入大乘。“任持所余”，是任持不定种性的菩萨，令其安住大乘，不以声闻乘般涅槃。“法等”，法是真如，声闻等同所归趣，所趣平等。“无我等”，声闻与菩萨都没有补特伽罗我，说“这是声闻、这是菩萨”不合道理。“解脱等”，声闻等对烦恼障同样得解脱，如世尊说“解脱与解脱没有差别”。“性不同”，不定种性的声闻等也将成佛。“得二意乐”：一是摄取平等意乐，摄取一切有情，认为“彼即是我，我即是彼”，自己成佛，彼也成佛；二是法性平等意乐，诸声闻在法华会上蒙佛授记，得到“诸佛法性即我法性”的意乐，此时尚未得法身。“化”，佛化作声闻，如世尊说“我忆往昔无量百次依声闻乘而般涅槃”，令声闻乘所化有情见此而得涅槃。“究竟”，只有一乘最为究竟，过此更无胜乘；声闻乘等之上还有佛乘。

五、同一法身而有多佛

上面所说，诸佛同一法身，佛有多位，以什么因缘可以理解？关于多佛，有一颂：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">一界中无二<br>同时无量圆<br>次第转非理<br>故成有多佛</div>

大意：一个世界中没有两佛同时出现；同时有无量菩萨的资粮圆满；次第转成佛不合道理；所以成立有多佛。

【世亲释】诸佛都以同一法界为体，所以可说一佛；一时一世界中没有两佛同现，所以可说一佛。无量菩萨在同一时间资粮圆满，如果同时圆满而不能成佛，资粮就空无果；诸菩萨修资粮时，不是依次第前后圆满，所以成佛也没有次第前后，同时有众多佛。

六、佛非毕竟涅槃，非毕竟不涅槃

应当如何了知：在法身中，佛不是毕竟入于涅槃，也不是毕竟不入涅槃？关于涅槃，有一颂：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">一切障脱故<br>所作无竟故<br>佛毕竟涅槃<br>毕竟不涅槃</div>

大意：由于解脱一切障，佛毕竟涅槃；由于所作之事没有穷尽，佛毕竟不涅槃。

【世亲释】有的部派说诸佛没有毕竟涅槃，有的声闻部派说诸佛有毕竟涅槃，此颂显示两种意趣。佛对一切有情，未成熟的令其成熟，已成熟的令其解脱，是所应作之事，所应作之事没有究竟之期，所以佛毕竟不入涅槃；否则如同声闻毕竟涅槃，本愿就空无果。

七、受用身不是自性身

为什么受用身不就是自性身？由于六种原因：第一，因为受用身是可见的色身。第二，因为可见无量佛众会的差别。第三，因为随胜解而见，可见自性不决定。第四，因为各别而见，可见自性变动。第五，因为菩萨、声闻和诸天等种种众会间杂，可见。第六，因为阿赖耶识与诸转识的转依不合道理，可见。所以，佛的受用身就是自性身，不合道理。

【世亲释】第三，如契经说，有人见佛身唯是黄色，有人见佛身唯是青色，自性身不应当如此不决定。第六，转阿赖耶识得自性身，如果受用身就是自性身，转诸转识又得什么身？由六种原因不合道理，所以受用身与自性身不能成为一身。

八、变化身不是自性身

为什么变化身不就是自性身？由于八种原因：

诸菩萨从久远以来已得不退定，在睹史多天和人中受生，不合道理。

又，诸菩萨从久远以来常忆宿住，对书算数印、工巧论议，以及受用欲尘之行，不能正知，不合道理。

又，诸菩萨从久远以来已知恶说与善说的法教，前往外道处，不合道理。

又，诸菩萨从久远以来已能善知三乘正道，修习邪苦行，不合道理。

又，诸菩萨舍下百拘胝的诸赡部洲，只在一处成等正觉、转正法轮，不合道理。如果离开示现成等正觉，只以化身在其余处所施作佛事，那么就应当只在睹史多天成等正觉，为什么不施设遍于一切赡部洲中同时有佛出世？既然不作此种施设，就是无教无理。有众多化身，不违背“无二如来出现于世”的经说，因为一个四大洲摄为一个世界，如同两位转轮王不同时出世。关于化身，有一颂：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">佛微细化身<br>多处胎平等<br>为显一切种<br>成等觉而转</div>

大意：佛的微细化身，在众多处所同时平等地入胎，为了显示一切种类的佛事，示现成等正觉而转。

为了利乐一切有情，发愿修行，证得大菩提，而后毕竟涅槃，不合道理，因为愿与行都没有果，成为过失。

【世亲释】菩萨已经多劫得不退定，尚且不应生于睹史多天，何况人中；现在世间受生的是变化身。菩萨三无数劫勤修福慧，最后身证菩提时，对书算、善说恶说、邪苦行都不能正知，不合道理，所以是为调伏有情而示现。如果有的部派主张佛只在一处真证等觉，其余处所只是化现，为什么不主张佛住在睹史多天真证等觉，在一切四大洲示现化身？经中说“无二如来俱时出现”，与说两位转轮王不同时出世一样，是就一个四大洲而说，不是就一个佛土而说。颂中所说的是：佛示现住在睹史多天、从天而没、入母胎等时，同时化作舍利弗尊者等无量眷属，也示现入胎、出生等事，以显示一切种类殊胜的佛事。

【译注】“成为过失”，论本作“成遇失”，依世亲释作“过失”。

九、如来身常

佛的受用身和变化身既然是无常的，为什么经中说如来身常？因为受用身和变化身所依的法身是常。又，等流身（受用身）和变化身，因为恒常受用，没有休止；屡屡示现化身，没有永绝。如同说“常受乐”、说“常施食”，如来身常，应当了知也是如此。

十、化身非毕竟住

由于六种原因，诸佛世尊所现的化身不毕竟安住：第一，所作已经究竟，因为成熟的有情已经解脱。第二，为了令有情舍离不乐涅槃之心，为了求如来常住之身。第三，为了令有情舍离轻毁诸佛之心，令有情领悟甚深的正法教。第四，为了令有情对佛深生渴仰，恐怕常常见佛的人生起厌怠。第五，为了令有情对自身发起勤精进，因为知道正说者难以遇到。第六，为了令诸有情极速成熟，令有情自己精进，不舍善轭。关于化身非毕竟住，有两颂：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">由所作究竟<br>舍不乐涅槃<br>离轻毁诸佛<br>深生于渴仰<br>内自发正勤<br>为极速成熟<br>故许佛化身<br>而非毕竟住</div>

大意：由于所作已经究竟，为令有情舍离不乐涅槃之心，远离轻毁诸佛，深生渴仰，内自发起正勤，为了极速成熟，所以许可佛的化身不毕竟安住。

十一、法身无别无量，仍须勤修

诸佛的法身，从无始时来没有差别、没有限量，不应当为了证得法身而另作功用。关于此难，有一颂：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">佛得无别无量因<br>有情若舍勤功用<br>证得恒时不成因<br>断如是因不应理</div>

大意：诸佛证得无别无量的法身，是有情勤修的因；有情如果舍弃勤修功用，诸佛的证得永远不能成为有情的因；断除勤修之因，不合道理。

【世亲释】有人质难：诸佛法身从无始时来无别无量，能为有情作证得之因，成办有情的利乐，有情为证佛果，不应当再作正勤功用。答：诸佛的证得，恒常作为有情求佛果而勤精进之因；有情如果舍弃勤修功用，诸佛的证得就永远不能成为因。又，诸菩萨悲愿缠心，怜愍有情如同独子，有情处在大牢狱中受尽艰辛，菩萨如果作此想：“其余菩萨能作，我可以不作”，不合道理；应当恒常作此想：“其余菩萨作也好，不作也好，我必定要作。”所以不应当断除勤修之因。

十二、结语

《阿毗达磨大乘经》中的《摄大乘品》，我阿僧伽简略解释完毕。

【译注】阿僧伽，就是无著菩萨的梵名。

全论正文至此结束。下一篇：译后语。
