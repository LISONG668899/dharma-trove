第一门　结集缘起

一切经中，另外有一卷，名为《结集三藏传》，还有《付法藏传》、《大智度论》第二卷、真谛三藏《部执论疏》第二卷、《大唐西域记》第九卷，以及《四分律》等。现在一并详细审察，合集起来叙述。如果各家分别详录，恐怕文字繁广，学人难以了知。

一、结集的地点

《大唐西域记》说：在摩揭陀国正中，是古代先王建都的地方，出产殊胜吉祥的茅草，称为"上茅城"，也就是矩奢揭罗补罗城。高山四面环绕，作为外城。西面通向峡谷小路，北面开辟山门。城东西长，南北窄，周长一百五十多里。

内城的遗址周长三十多里。从山城北门走一里多，到迦兰陀竹园。从竹园向西南走五六里，在南山的北面，大竹林中有一个大石室，是大迦叶波结集的地方。未生怨王为结集的人建造了许多殿堂屋宇，就在山城北门外西南方向、山的北面。

关于结集地点，诸家的说法：

1. 真谛说在王舍城的七叶岩。
2. 《结集三藏传》说在僧伽尸城北。
3. 《西域记》所说如上。

这三种说法是相同的。《大智度论》说在耆阇崛山结集，这是不对的。耆阇崛山在王宫城正北十四五里，连接北山的南面；结集是在大城北门外，遗迹现在还存在。所以可知《大智度论》的说法不对。三种文字名称不同，处所没有差别。

二、佛入灭时的景象与诸天请法

《大智度论》第十一卷说：佛入灭的时候，大地六种震动，诸河倒流，暴风、黑云、雷电、冰雹、大雨，流星处处坠落，狮子和猛兽咆哮呼叫，天人号啕大哭。诸天人等都说："佛取涅槃，怎么这样快！"这时的灾变无量无边，许多大圣人也都入了寂灭。

《西域记》说：当时大迦叶在山林中静坐，忽然光明照耀，又看到大地震动，说："这是什么征兆？"出现这样的异象，于是以天眼观察，看见佛世尊在双林之间入般涅槃。

《大智度论》说：六欲天乃至遍净天的诸天子等，看见诸阿罗汉都入般涅槃，心中想："佛日已经灭了，诸弟子等也随着隐没。"乃至广说："象王已经去世，小象也随之而去；法商已经离开，向谁求取法宝？"

这时诸天礼拜迦叶的双足，说偈：

「耆年欲恚慢已除，其形譬如紫金柱，上下端严妙无比，眼目清净如莲华。」（大意：长老的贪欲、嗔恚、我慢都已除尽，身形好比紫金柱，上下端严，妙好无比，眼目清净如同莲花。）

诸天对迦叶说："仁者知道吗？法船破了，法城倒了，法海干了，法幢倒了，法灯将要熄灭，说法的人将要离去，行道的人少了，恶人渐渐增多。您应当以大慈心建立佛法。"

这时大迦叶心如大海，澄静不动，过了很久才回答："确实如你们所说。"默然接受了诸天的请求。诸天礼足以后，忽然不见了。

三、迦叶以药槽救阿阇世王

真谛三藏《部执论疏》第二卷说：

佛般涅槃以后过了七日，迦叶召集徒众，要前往拘尸那城。路上遇到一位外道，名叫优婆柯，汉译为"近性"。迦叶问："你从哪里来？"外道回答："我从世尊涅槃的地方来。佛般涅槃已经七日了，无量的天人烧香散花，设置种种供养。我在佛所拾得这朵曼陀罗花。"说着拿给迦叶看。

迦叶前往未生怨王那里，对国王说："我需要八个槽，希望大王派人取来。"国王依照吩咐办了。迦叶又要国王的御医，国王也依命派来。迦叶问御医各种药物：什么药治风病，什么药疗疮伤，又向国王索取这些药，国王都随着给了。迦叶把药磨成粉末，煮成膏，放入八个槽中。

当天，迦叶告诉阿阇世王："佛般涅槃已经七日了。"国王听到这话，昏绝而死。迦叶把国王依次安放在槽里，到第八个槽，国王才活过来，这是凭借药物的殊胜力量，使国王得以苏醒。迦叶这样告诉了三次，国王一听就昏死，迦叶依次把国王安放在槽中，像前面一样救活。

迦叶为国王说："一切有为法都归于磨灭，都是无常，如来也是一样。大王不要忧恼，应当弘扬正法来报答佛恩，应当与眷属一起前往佛所。"

国王与眷属，连同大迦叶，在屈伸手臂那样短的时间内到达拘尸城。国王见到佛，又昏绝而死。迦叶又把国王放到药槽中，乃至到第八个槽，国王才活过来。佛从衣外伸出双足，接受迦叶的礼拜。

四、迦叶劝阻诸圣入灭，发起结集

四部弟子看见佛涅槃，在迦叶还没有到来之前，都没有入寂灭。迦叶到了以后，再没有可等待的，无量圣人也入了般涅槃。入涅槃的人多了，就没有圣人住持；没有住持，恐怕正法灭尽。

迦叶便对还没有入灭的人说："诸位圣者暂时不要入灭。我们应当报答佛法的恩德，撰集如来所说的三藏来利益众生。如果不听从我的话，犯突吉罗罪。"这样一一告知，入灭的人就少了。

《西域记》说：当时大迦叶对徒众说："智慧之日沉没，世界一片黑暗；善导师远去，众生颠倒坠落。"懈怠的比丘互相庆贺说："如来寂灭了，我们安乐了；如果有所违犯，谁能呵斥制止？"迦叶听了，更加悲伤，想要结集法藏，依法来治理违犯。

真谛说：迦叶有两个弟子，一个叫难陀，一个叫优婆难陀，看见佛涅槃，生起大欢喜。当时四部大众把这件事告诉迦叶，迦叶呵责二人，驱逐出众，下定决心结集。

《结集三藏传》说：四部人天把佛的舍利分为八份，连同焚化佛身的灰炭，以及安放佛身的床，建起了十座塔。

五、召集大众

《大智度论》《西域记》说：摩诃迦叶在须弥山顶敲击铜犍椎，说偈：

「佛诸弟子，若念于佛，当报佛恩，莫入涅槃。」（大意：佛的诸弟子，如果怀念佛，应当报答佛恩，不要入涅槃。）

犍椎的声音传达迦叶的话，遍满三千大千世界，都听到了。得到神通的诸大弟子，都来集会到迦叶那里。迦叶告诉大众："佛法将要灭了，诸大弟子中知法、持法的人，也随着灭度。未来的众生非常可怜。结集完毕以后，再随各人的意愿灭度。"来的大众都依教住世。

关于参加结集的人数，诸家说法不一：

1. 《大智度论》《西域记》：得到九百九十九人，只差阿难。
2. 真谛说：得到四百九十九人，只差庆喜（阿难）。
3. 《结集三藏传》说：得到八万人，都是无漏圣者。这部传是通说有学和无学。
4. 《四分律》说：先有五百人，后来富楼那到来，又有五百人，前后分别。

六、结集的时间与供养

真谛说：在夏季四月十五日安居期间，阿阇世王作大施主。如来在世的时候，诸弟子等早晚礼拜如来；现在夏安居，分为早、晚和中午三个时段，礼拜供养舍利。

《大智度论》说：频婆娑罗王得道，八万四千眷属也随之得道。频婆娑罗王下令宫中常设饮食，供养一千人。所以阿阇世王没有断绝这个做法。圣者很多，只留下一千人来结集。如果留的人多，要到外面乞食，恐怕外道来论议，妨碍废弃结集法事。当时大迦叶与一千人到了结集的地方，对阿阇世王说："请供给我们饮食。"这时是夏安居三月初十五日说戒的时候。《西域记》说是夏安居开始的十五日集会。

七、迦叶驱出阿难，责阿难诸罪

《大智度论》说：迦叶入定，观察大众中谁还没有漏尽，只看见阿难还处在有学地。迦叶从禅定中起来，把阿难拉出去，说："你的结使还没有断尽，不应当住在这里。"

阿难羞耻哭泣，心中想："我二十五年随侍在佛身后，在左右供给，从来没有受过这样的苦。"阿难对迦叶说："我有能力，早就可以得道。只是依照诸佛的法规，阿罗汉不得作供给左右的侍者，所以我故意留下残余的结使。"

大迦叶说："你还有罪过。"

1. 佛的本意不想让女人出家，你殷勤请佛开许，因为这件事，正法衰减了五百年。你现在应当作突吉罗忏悔。阿难回答："我怜愍瞿昙弥。并且一切佛的佛法中都有四部众，怎么能只有我们的佛没有？"《四分律·杂犍度》末尾说：大爱道比丘尼对佛有恩，佛小时候失去母亲，是大爱道收养了佛，所以可以允许大爱道出家。

2. 迦叶又说："佛将要涅槃的时候，接近拘夷那竭城，背痛，把郁多罗僧叠成四层铺着躺下，说'我需要水'，你没有供给。"阿难回答："那时有五百辆车截流渡河，使河水浑浊，所以没有取水。"迦叶又说："即使水浑浊，佛有神力，能让大海的浊水还原清净，你为什么不取？这是你的罪过，应当作突吉罗忏悔。"《四分律》说：天神也能让水变清。

3. 迦叶又说："佛问你：'如果有人能修四神足，可以住寿一劫，或者少于一劫，我就善于修四神足。'你没有回答。这样问了三次，你都默然。由于你的缘故，佛早早入了涅槃。应当作突吉罗忏悔。"阿难回答："那是被魔遮蔽的缘故，不是我有恶心。"

4. 迦叶又说："你折叠佛的衣服时，为什么用脚踩踏僧伽梨？应当作突吉罗忏悔。"阿难回答："当时刮起大风，没有人帮忙，风把衣服吹落到我的脚下，不是不恭敬而故意踩踏佛衣。"《四分律》说：是给佛缝衣服时踩在佛衣上。

5. 迦叶又说："佛的阴藏相，在佛般涅槃以后，你拿给女人看。这是让佛蒙羞的事，你应当作突吉罗忏悔。"阿难回答："当时我想：如果女人们看见佛的阴藏相，就会自己感到羞耻，觉得女身丑陋，想要得到男身，修行佛的相好，种下各种善根，所以我给女人们看。并不是不知羞耻而故意破戒。"

各家所说罪数的差别：

1. 《四分律》中没有第五种，另外有三种：不问微细戒是一种；佛派阿难作侍者，阿难不肯，是一种；女人沾污佛足，是一种。合起来成为八种。
2. 《结集三藏传》中只说四种：请度女人、踩踏佛衣、索水不给，以及不问微细戒。
3. 《大智度论》说："大迦叶说：你这六种罪应当忏悔。阿难说：好。长跪忏悔。"论中说有六种，文中只列出五种，文字似乎有脱漏。

《四分律》说：阿难回答："我不认为这是罪，只是相信上座的话，所以忏悔。"忏悔完毕，迦叶把阿难拉出去，对阿难说："你得到漏尽以后再进来。"迦叶说完，就自己关上门。

八、憍梵波提入灭

大众商议结集毗尼。阿那律说："舍利弗的弟子憍梵波提，能通晓毗尼，现在住在天上的尸利沙树园中。请派使者去请来。"

迦叶派使者去召唤憍梵波提，说："阎浮提的僧众有大法事，现在赶快召唤你，你可以快来。"使者就礼拜僧众的双足，礼拜完毕，像鸟一样飞过虚空，到了尸利沙园，依照所说的话请憍梵波提。

憍梵波提问使者："莫非有斗诤，所以来唤我？没有破僧的人吧？"使者回答："没有。""佛日灭了吗？"使者回答："是的，佛已经灭度了。"憍梵波提说："佛灭度得怎么这样快！我的和尚舍利弗现在在哪里？"使者回答："和尚也已经涅槃了。"又问大目犍连，回答也是这样："已经灭度了。"

憍梵波提说："佛法将要离散，大人们都过去了，众生可怜。阿难、罗睺罗现在在哪里？"使者回答："阿难看见佛涅槃，忧愁啼哭，不能自解。罗睺罗证得阿罗汉，只是观察无常。"

憍梵波提说："我失去了离欲的大师，和尚也灭度了，住世又有什么益处？"随即生起神变，入了涅槃。身体化出水来，分四道流下，流到迦叶那里。水中有声音说偈：

「憍梵钵提稽首礼，妙智第一大德僧。闻佛灭度我随去，如大象去象子随。」（大意：憍梵钵提稽首礼拜具有第一妙智的大德僧众。听到佛灭度，我也随着去了，就像大象离去，小象也随之而去。）

这时使者拿着憍梵波提的衣钵回到僧众中。

《结集三藏传》说：当时阿那律对迦叶说："憍梵比丘在忉利天，是无漏的阿罗汉，现在没有来集会。"迦叶命人召请，憍梵波提不肯来，说："世尊涅槃了，世间空了，还求什么？"

九、阿难证果

《大智度论》说：这时阿难希求漏尽，殷勤用功，疲惫到极点，想躺下休息，头还没有靠到枕头，豁然得道，就像太阳破除黑暗，三明六通全都具足。夜里阿难到僧堂，绕着门呼唤。迦叶让阿难从门锁孔中进来，礼拜僧众。

《结集三藏传》说：阿难当时坐在一棵树下，灭除结使，漏尽成就。无数诸天围绕阿难，来到大会，阿难如狮子一样无所畏惧。迦叶远远看见，八万多大众合掌站立迎接。迦叶举手说："善来，阿难。"阿难便坐上高座，整理众僧。

十、《结集三藏传》所载阿难降魔与四藏结集

迦叶高声大召众生："想要度脱世间的人，都来到这里。佛所说的种种法，能除众生的苦，阿难将要宣说，十方都将听闻。"天、龙、鬼神、四部弟子、四果圣人、诸王和兵众，听到声音都来了。大众依次而坐，方圆十二由旬。

阿难在大众中，如同满月光明。帝释在右，梵天在左，侍奉阿难，就像佛在世时一样。这时帝释说偈赞叹，一切天子都欢喜，就像佛转法轮时大众围绕一样。阿难无所畏惧，容貌巍巍，如日光明；刚刚断尽结使，仪态如同山顶；颈项有圆光，照耀大会。大众看见，都赞叹不已。

魔王听到这个名声，带着妻子、臣属和兵众也来到这里。波旬心中想："一位佛灭度了，又有三人出现：阿难断尽结使，迦叶头顶有光，阿那律以天眼彻视大千世界。瞿昙涅槃，我以为得以解脱，这三人的德行，影响非常大。佛法已经衰微，没有怨仇对手，我应当设法消灭这残存的佛法、四部弟子以及诸国王。"

魔王于是发出命令，令狮子将军迅速用四种兵灭除佛法。随即化出四种兵和将领，围绕大会，发出可怕的声音，收捕出家人和清信男女，诛杀诸王，毁坏道场。大会众人惊愕，四部大众心想："这是从哪里来的？"诸王听到声音，都心怀惊疑，各自整备兵器。

阿难思惟："是谁来扰乱？"观察这些兵众，才知道是魔所为。阿难便笑了，命诸王停下车驾，说："这些乱兵，我自己来降伏。"

这时阿难以智慧力，摩诃迦叶以精进力，伸手捉住魔王，把三具尸体系在魔王颈上：第一是人尸，第二是狗尸，第三是蛇尸，膨胀腐臭，难以接近。魔王于是低头降伏，请求迦叶放了自己，说："阿罗汉应当为难人吗？迦叶，我从前极力扰乱佛世尊，从来没有像今天这样受困。"

迦叶回答："佛因为哀愍你，始终不加害。我们结集法藏，想让佛法长久兴盛，你为什么来扰乱我们的大众？"魔王就合掌对阿难说："暂且放了我，我不再扰人。"阿难、迦叶一起让魔王发誓："如果再扰乱大众，尸体还挂在你颈上。"三具尸体化去，波旬得以脱身，站立在一边。诸天称赞："殊胜！善哉！"

迦叶命令大众都应当静听。诸王都起身合掌侍立。阿难长叹一声，像狮子振奋伸展一样，环顾四方众生，说出"闻如是"以及"一时"以后，大地为之震动，一亿天人都得到法眼。

结集诸经，作为一藏；律作为第二藏；大法作为第三藏；收录各种其他的法，合集众多杂说，又作为一藏，名为杂藏。听闻这些法以后，天神和人中，三千比丘都得到漏尽，八千人得不还果，一万人得一来果，无数天人得见道迹。结集法藏完毕，天人各自回去，四部弟子都回到本处。

窥基按：验证这里结集四藏，就是大众部的义理。四藏都是阿难结集的。

十一、《大智度论》所载三藏结集

《大智度论》说：迦叶用手摩阿难的头顶，让阿难结集法藏。阿难合掌朝向佛涅槃的方向，说偈：

「佛初说法时，尔时我不见。如是展转闻，佛在波罗奈，为五比丘众，转四谛法轮。」（大意：佛最初说法的时候，那时我没有亲见。是这样辗转听闻的：佛在波罗奈，为五比丘众转四谛法轮。）

《转法轮经》也有这首偈。这一千位阿罗汉听到这话，上升虚空七多罗树高，说："无常的力量真大！我们亲眼见佛自己说法，现在要说'我闻如是'。"无灭（阿那律）、迦叶等圣者也都说偈，说无常的力量很大。

阿难这样结集了四阿含，就是增一阿含、中阿含、长阿含、杂阿含，称为修妒路（经藏）。

迦叶又让优婆离结集毗尼藏，开头说："如是我闻，一时佛在毗舍离……"乃至广说。

又让阿难结集阿毗昙藏，开头说："如是我闻，一时佛在舍卫城。佛告诸比丘：有五种怖畏、五种罪、五种怨，不除不灭，因为这个因缘，在此生中受无量苦，后来堕入恶道……"乃至广说。

结集法藏完毕，诸天、龙神等作种种供养，雨下天花、天香，用一切物品供养，说偈：

「怜愍世间故，结集三法竟。十力一切智，说智无明灯。」（大意：为了怜愍世间，三藏法已经结集完毕。具足十力的一切智者，所说的智慧，是照破无明的明灯。）

《大智度论》又说：弥勒菩萨、文殊菩萨带着阿难，在铁围山之间结集大乘三藏，作为菩萨藏。

十二、《西域记》所载三藏结集

《西域记》说：夏安居开始的十五日，大迦叶波说偈：

「善哉谛听！阿难闻持，如来称赞，集素呾缆藏。我迦叶波集阿毗达磨藏。优波离持律明究，众所知识，集毗奈耶藏。」（大意：善哉，仔细听！阿难多闻总持，受如来称赞，结集素呾缆藏。我迦叶波结集阿毗达磨藏。优波离持律明白究竟，大众所共知，结集毗奈耶藏。）

雨季三个月结束，三藏结集完毕。西域相传，大乘三藏也在这座山的同一处结集，就是阿难、妙吉祥等诸大菩萨结集大乘三藏。

十三、真谛《部执论疏》所载：上座部与大众部的由来

真谛《部执论疏》说：迦叶让阿难诵出五阿含，结集为经藏；让富楼那诵出阿毗昙，称为对法藏；让优波离诵出毗奈耶，称为律藏。

这时有无量比丘来，想要听法。迦叶不允许，让这些比丘住在结界之外。界外的比丘各自如法诵出三藏。有一位阿罗汉，念佛法的恩德，念众生的苦，常常流泪，所以名叫婆师婆，作为大众的主持，教授众人。

迦叶不允许后来的人进入大众，有两个原因：

1. 羯磨已经完成，不允许后来的人进入大众，恐怕破坏羯磨，得偷兰遮罪。
2. 不让大众混杂。只有这五百人与大迦叶能够相互领解，其余的人不能，所以不允许进入大众。

两处各自结集，情见还没有分裂，仍然同一理解。夏安居结束，法事又一起进行。阿阇世王置办衣钵，布施给圣众。界外的大众，人数很多，所以当时都称为"大众"；界内的大众以迦叶为上首，世尊自己说过迦叶是上座，佛灭以后迦叶是弟子们的依止，所以当时都称为"上座"。

那一年十二月，未生怨王去世，摩诃迦叶进入狼迹山，大众便散去了。依《西域记》，迦叶进入的是鸡足山，不是狼迹山。

十四、《四分律》所载

《四分律》说：在王舍城结集三藏，没有另外说具体处所。最初只有五百大阿罗汉，阿难结集两藏，优波离结集毗奈耶藏。后来富楼那与五百大阿罗汉来到，请迦叶重新结集，仍然是阿难结集两藏。最初五百人结集，与真谛法师所说相同；后来成为一千人，与《西域记》《大智度论》相同。

十五、诸家异说的部派归属

1. 《结集三藏传》是大众部的义理。既然采用界外的大众，所以不分两处结集。
2. 《四分律》是法藏部的义理。
3. 真谛法师所说是萨婆多部的义理。
4. 《西域记》中所说是大乘的正说。
5. 不知道《大智度论》是哪一部派的说法。

结集的处所既然不同，人数又不相同，不同部派的说法各异，不可以勉强调和会通。诸位学人应当如理了知。

以上总的是第一门，结集缘起。
