〔译注：本篇译《诸乘义林》后两门：彰显废立的理由、问答抉择。窥基在这里系统论证"一乘是方便，五性各别是真实"，并会通《法华经》《胜鬘经》《涅槃经》的说法。〕

第四门　彰显废立的理由

一、为什么立一乘

问：有决定种性的二乘，有无种性的人天乘，成为五乘，为什么又立一乘？

答：立一乘有十种意义。如《摄大乘论》第十卷说：

「为引摄一类，及任持所余，由不定种姓，诸佛说一乘。法、无我、解脱等故，姓不同，得二意乐，化，究竟说一乘。」（大意：为了引摄一类众生，以及任持其余众生，由于有不定种性，诸佛宣说一乘。因为法平等，无我平等，解脱平等，种性不同，得到两种意乐，示现变化，究竟只此一乘，所以宣说一乘。）

这里的十种原因是：

一、为了引摄一类不定种性的声闻，让这些声闻依大乘而般涅槃。

二、为了任持其余不定种性的菩萨。恐怕这类菩萨对大乘的精进暂且毁坏，退而依声闻乘般涅槃。《法华经》说：「新发意菩萨闻是法已，疑网皆除。」（大意：新发心的菩萨听闻此法以后，疑网都消除了。）这里只说第六住以前的菩萨，因为这个阶段的菩萨还会退转。

三、法平等。乘有差别，所趣向的真如没有差别。《法华论》的解释也与此相同。

四、无我平等。如果有实在的补特伽罗，可以有乘的差别；无我既然没有差别，所以说一乘。

五、解脱平等。三乘都在烦恼障中得到解脱，解脱没有差别。

六、种性不同。声闻之中，不定种性有差别。这类声闻身中，兼具声闻种性和佛种性。因为有佛种性，所以说一乘。

七、八、得到两种意乐：

1. 诸佛对于一切有情，得到同一自体的意乐，说"我就是那个有情，那个有情就是我"。我既然成佛，那个有情也会成佛。
2. 世尊在法华会上为诸声闻授佛记，是为了让声闻摄得这样的意乐："我们与佛平等无二。"并且法华会上有些菩萨，与这些声闻同名，也得到授记。所以佛的一句话包含两种利益：诸声闻得到与佛同一自体的意乐，诸菩萨得到授记。

九、示现变化。如世尊所说：「汝等苾刍，我忆往昔无量百返依声闻乘而般涅槃。」（大意：诸位比丘，我回忆往昔，曾经无数百次依声闻乘而般涅槃。）佛既然已经成佛，怎么会又依声闻乘般涅槃？这是为了调伏所化度的声闻。佛和菩萨等，自己化现身形，作为声闻的同类，示现般涅槃，经过百千劫沉醉于寂灭之酒，然后才从涅槃中起来，现前接受佛的授记。让那些不定种性的声闻都生起这样的心："往昔那些尊长入了涅槃的，现在都又起来，现前接受佛的授记，何况我们，怎么能不希求作佛而入涅槃？"这也是为了降伏那些声闻：佛说"我也得到了你们的涅槃"。

十、究竟。除了一乘以外，没有其他更殊胜的乘；依理而言，一乘最究竟、最殊胜。

二、《法华论》四种声闻与十因的对应

《法华论》中说四种声闻，只为不定种性和应化的声闻授记：

1. 不定种性，就是十因中的第一、第二，以及第八的一小部分。
2. 应化，就是第九。

其余六种以及第八的另一小部分，是依别的意义宣说一乘，并非都是为不定种性和应化者；也不是说无种性的众生能够作佛，所以称为一乘。

《显扬圣教论》第二十卷的六种意义，包含在这十种意义中，不需要另外说明。

三、《法华经》一乘与《胜鬘经》一乘的方便与真实

《法华经》开方便门，显真实相，以二乘为方便，以一乘为真实。

依照《胜鬘经》，"如果如来随着众生的意欲，方便宣说，就只有一乘，没有二乘"。这里的意思是显示：摄二乘归入大乘而说一乘，是随他意语，因为那些众生适合听闻，所以也是方便说有一乘，并不是真实。原因有二：

1. 决定种性的声闻不授记，所以并非唯一一乘。
2. 无种性的有情不能成佛。

《法华经》这一会，是对不定种性的根机，以二乘为方便，以一乘为真实。《胜鬘经》中，道理周全完备，根机中有不定种性，以四乘为真实，所以说一乘是方便说、随他意语。两经并不相违。

两经一乘的区别：

1. 《法华经》的一乘，只依"摄入"来说，体性和作用狭小，所以是方便说。《胜鬘经》的一乘，"出生"和"摄入"两方面都周全完备，所以是真实。
2. 《法华经》的一乘，只以有种性者为所依，所以是方便。《胜鬘经》的一乘，也以无种性者为所依，所以是真实。
3. 《法华经》只谈不定种性，所以是方便。《胜鬘经》也谈决定种性，所以是真实。

《法华经》这样说，是因为那一会的听众适合听闻。

4. 《法华经》分明地以智慧为一乘，隐约地说真如。经中说化城，也不是真实的灭；说大涅槃，都作为宝所，没有分明地说真涅槃。因为二乘所得的涅槃都称为化城，菩提完全没有得到，所以显明地以智慧为一乘，让二乘欣求。《胜鬘经》则以真理为一乘，不单说智慧，所以摄入、出生两方面都说尽了。

佛果的涅槃和菩提，都是一乘。《胜鬘经》是了义的狮子吼说；《法华经》是隐密地宣说一乘。

5. 总说声闻有四种。在法华会最初，有三种声闻，只除去趣寂声闻。增上慢声闻后来起座离去，之后才为两种声闻授记。

〔存疑：原文「其增上慢后起已去方为二记」，"后起已去"或指五千增上慢起座退席；"方为二记"或指此后只为退菩提心、应化两种声闻授记。此处依这个理解翻译。〕

由于这样的道理，《法华经》说一乘，与其余经教并不相违。

四、为什么立二乘

说二乘的时候，不说独觉，只说上乘和下乘，原因有几点：

1. 如佛十力中的根上下智力，根机不超过上、下两种。根机和教法都是两类。
2. 声闻和独觉都有决定种性和不定种性。初发心时都依靠听闻佛的声教；究竟成果时，也有一小部分依靠声教。不定种性的人，以佛道之声让一切众生听闻，都可以称为声闻。
3. 独觉没有很多另外的教法，所以归类于下乘和声闻乘，不另外说明。

又称为大、小二乘，是因为把声闻、独觉两乘合起来，两者的种类相同。

五、为什么立三乘

问：为什么三乘中，把决定种性和不定种性合起来，成为三乘？

答：不定种性中，有的具足两种种性，有的具足三种种性，种性的差别，究竟得果不超过三乘。人天乘浅近，不是究竟的运载，所以也不说。

六、为什么立四乘

1. 《胜鬘经》的四乘中，不说不定种性，因为究竟来说也只是三乘所摄尽，所以略去不说。合人、天为一乘，是因为人、天都没有三乘种性，同属浅近一类。
2. 《大般若经》的四乘中，不说无种性，因为无种性不是究竟的运载。开出不定种性，是因为不定种性听闻经中殊胜的功德，所修的方便不同，显示不定种性究竟能得涅槃。

七、为什么立五乘

问：为什么《楞伽经》《称赞大乘功德经》另说五乘？

答：决定种性和不定种性有四种差别；人、天同属浅近一类。

其余地方说人、天各为一乘而成五乘，是因为人、天受果有差别，所趣的类别不同；把不定种性合入三乘，因为不定种性不超出三乘。

八、为什么不立六乘、七乘

问：为什么不把有种性开为四乘、无种性开为两乘，成为六乘？

答：诸教只说五种种性的差别，类别只有五种。假如立六乘，道理上也没有违背，只是没有经文证明。不说七乘等，因为再没有其他类别了。

第五门　问答抉择

问一：一乘与五性的矛盾

问：这里的一乘之理，应当只有一乘，没有第二乘、第三乘。《法华经》说：「声闻若菩萨，闻我所说法，乃至于一偈，皆成佛无疑。」（大意：无论声闻还是菩萨，听闻我所说的法，乃至只有一偈，都毫无疑问能够成佛。）《涅槃经》也说：「凡有心者，悉皆当得无上菩提。」（大意：凡是有心的众生，都将证得无上菩提。）为什么说一乘只是为了引摄不定种性？五乘一切有情都有佛性，究竟都到达大乘的极果，为什么究竟还有人天乘不归于佛？

答：《摄大乘论》以十种原因说佛宣说一乘；《显扬圣教论》第二十卷以六种原因说佛宣说一乘，前面已经辨明。现在解释其中的用意：依据实际来说，五乘各不相同，如前面所引的教理所成立。为了引摄一类众生，所以说一乘；不是说乘只有一种，没有第二乘、第三乘等。

《法华论》说，声闻有四种：

1. 趣寂声闻
2. 退菩提心声闻，也称为回向菩提心声闻
3. 应化声闻
4. 增上慢声闻

《法华经》只为化导退菩提心声闻和应化声闻，世尊为这两种授记，不为其余两种授记。

应化声闻，就是经中所说"沉醉于三昧之酒，经过劫数不觉醒，后来从三昧中起来，才发起大心"的声闻。佛和菩萨等作这样的变化身形，作为声闻一类，让其他声闻想："先前的圣者入灭，经过劫数这样久，现在还发心，何况我们？"所以为应化声闻宣说一乘，授记作佛。《摄大乘论》十因中的第九"化"，就是这个意思。

舍利弗等先前发了大心，因为布施眼睛的事退转，转求小果。现在为舍利弗等宣说一乘，授记作佛，所以说也是为退菩提心的声闻宣说一乘等。不这样理解，就违背了《楞伽经》《大乘庄严经论》所说的五种种性。

《涅槃经》又说：「我于一时说一乘、一道、一行、一缘，说须陀洹乃至阿罗汉等皆得佛道。我诸弟子不解我意，于大众中唱如是言：如来说须陀洹乃至阿罗汉皆得佛道。」（大意：我曾在某时宣说一乘、一道、一行、一缘，说须陀洹乃至阿罗汉等都能得到佛道。我的弟子们不理解我的意思，在大众中宣唱说："如来说须陀洹乃至阿罗汉都能得到佛道。"）如果一切声闻都能作佛，这些弟子就是理解了佛意，为什么称为"不理解我的意思"？所以可知，只应当像这里所说的那样理解。

问二："无二亦无三"是否破三乘

问：《法华经》自己说：「十方佛土中，唯有一乘法，无二亦无三，除佛方便说。」（大意：十方佛国土中，只有一乘法，没有二乘，也没有三乘，除了佛的方便说。）这就是破二乘、破三乘而阐明一乘。为什么说有三乘、五乘的差别？

答：依照梵本，这首经颂应当说"没有第二，没有第三"。数三乘时，独觉是第二，声闻是第三。为了引摄不定种性、任持其余菩萨，方便说没有第二、第三，并不是真的破除。

一、《法华经》自己说：「唯此一事实，余二即非真。终不以小乘，济度于众生。」（大意：只有这一件事真实，其余二乘不真实。终究不以小乘济度众生。）如果是破三乘，为什么说"其余二乘不真实""不以小乘济度"？也应当说"不以大乘济度"。经中既然只说"其余二乘不真实""不以小乘济度"，明确可知大乘不是所破的对象。

二、《法华经》又说："尚且没有二乘，何况有三乘。""二"是指第二，"三"是指第三，不是指二乘、三乘称为"二""三"。

三、《胜鬘经》说："声闻乘、辟支佛乘，就是大乘。"又说："大乘就是一乘。"所以只是会通不定种性的二乘，并不会通决定种性的二乘，何况会通大乘？并且说"没有三乘"，是显示三乘就是一乘，不是破除大乘而只有一乘。这个道理有什么差错？

四、如果是会通而破除三乘：三乘中的大乘，就是火宅内所许诺的牛车；出门以后，长者等所给予的也都是牛车。如果破除前面的牛车，之后另外给予牛车，两种牛车有什么差别？

五、三乘中的大乘，就是顿悟菩萨。会通而令顿悟菩萨进入一乘，难道是让顿悟菩萨变成渐悟菩萨吗？

六、大乘和一乘，解和行有什么差别，要说"舍三乘而趣向一乘"？

七、"新发意菩萨疑网都消除"，就是十因中的"任持其余"。未说一乘以前，这类菩萨对大乘的精进暂且毁坏，生起疑惑，将要退转；现在听闻一乘，消除了疑惑。这是舍弃下位而趣向上阶，不是舍弃大乘而进入一乘。不然的话，十地菩萨舍下地趣上地，都应当也称为"破三归一"了。并且也应当说"其余三乘不真实"，为什么只说"二乘"？

八、《胜鬘经》又说："如果如来随着众生的意欲，方便宣说，就是大乘，没有二乘。"所以会通二乘归入一乘，是方便说，不是真实之理。

九、经中说"开方便门，显真实相"，所以说有不定种性的二乘，是方便门，为了远远地引导不定种性进入真实。现在宣说一乘，让二乘趣向极果，称为真实。并不是说全然没有二乘、只有一乘才称为真实。所以《法华经》说"密遣二人，眇目矬陋"，只说两人，不说三人。又说"为了休息，所以说二乘"，不说三乘。

十、有人说：回心菩萨迂回进入大乘的位次，称为"大乘"；直往菩萨所进入的大乘位次，称为"一乘"。经论中的一乘，实际上是为不定种性而说。这种解释没有典据，没有见到可信的经文。《法华经》的一乘，难道是由直往菩萨来说的吗？现在直往、回心两种行人入大乘后的位次，有什么差别？所以可知，佛是方便地隐去二乘而宣说一乘，因为化度那一会的听众适合听闻。

十一、有人说：小乘执着佛修满三大阿僧祇劫以后仍然是凡夫，要经过三十四念才成就菩提位。现在为了破除这种执着，所以说一乘也是破三乘。这种说法不对。这种执着是佛灭度以后小乘的偏曲见解，佛在世的时候哪里有人作这样的佛执，以为是真实？所以佛现在所破的，只是二乘。

问三：乘与藏的数目为什么不同

问：为什么立一乘、五乘，不说一藏、五藏；说有六藏，不说六乘？《阿阇世王经》等所说的二藏、三藏，又与二乘、三乘相同？

答：乘是运载的意思，就根机和修行来说明乘；藏是含容的意思，以教法对应道理而立为藏。所以一乘、五乘与六藏不相同。经中所说的二藏、三藏与二乘、三乘，是以根机和修行彰显运载，对应根机和道理辨明教法，所以可以相同。不可以让乘与藏全部相同或全部相异，只是随宜暂且区分乘和藏，有这样的相同和相异。总的来说，乘与藏有可以相同的地方，在道理上没有差错，只是没有见到经文。

另外，依照《菩萨藏经》第一卷所说，十度与十弊相互对治，数目相等；四轮与八难相互对治，数目不相等。所以不应当一律要求数目相同。

问四：如来已度，为什么还立佛乘

问：乘是运载、度脱的意思。菩萨可以有乘；如来已经度脱，应当不立佛乘。

答：自度、度他都可以称为乘。菩萨具足自度、度他两种度；佛只度他，不需要自度，这又何妨立为佛乘？

问五：佛乘、菩萨乘、声闻乘的名称

问：为什么有的地方说佛乘也称为菩萨乘，又只称声闻乘，不称独觉乘？

答：

1. 以果位相对，只说佛乘。
2. 自运、运他两种运载可以修习，所以说菩萨乘。
3. 修行等广大，所以称为大乘。
4. 遮除其余两乘，所以也称为一乘。
5. 独觉没有另外的教门，初业也是由听闻声教而起，所以称为声闻乘，不称独觉乘。
6. 二乘通论，总称为小乘，因为声闻、独觉的根机、修行等同样狭小低劣。

这些说法并不相违。

问六：为什么称菩萨藏，不称佛藏

问：既然以果位相对称为佛乘，也应当以果位相对称为佛藏，为什么只称菩萨藏，不称佛藏？声闻、独觉都得到"藏"的名称。

答：这到《诸藏章》中自然会详细解释。

问七：教、理、行、果作为一乘体的同与异

问：教、理、行、果都是一乘的体性，是相同还是相异？

答：

1. 一雨普润：教法相同，根机相异。
2. 三兽渡河：真理相同，所证相异。
3. 六处大因：修行相同，所修相异。
4. 三车诱引：果位相同，施设相异。

或相异，或相同，不必勉强确定标准。《胜鬘经》会通因和果；《法华经》会通教、行、果三者：一雨是教，九部是行，三车是果。显明地只说教、行、果三者，隐密地实际有四者，理也在其中。如《涅槃经》所说的同异。

（《诸乘义林》终）
