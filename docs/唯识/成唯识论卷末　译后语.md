<p class="dt-title">一条大理路：成唯识论译后语</p>

<div class="dt-subtitle">成唯识论白话译注　译后语<br>护法等菩萨造　唐　玄奘译</div>

本篇要目：一、论主自己说话的地方　二、论主对圣教的珍惜　三、论主对后学的期许　四、全论的一条大理路　五、十二个关键结论　六、贯穿全论的四种方法　七、翻译中的几点发现　八、翻译体例回顾　九、底本订正与待核清单

一、论主自己说话的地方

《成唯识论》大部分篇幅在列举各家、辨析是非。读完三十篇可以发现，论中有些段落，论主不转述“有义”，也不与外人问答，直接说出自己的判断、总结和叮咛。

先说明一点。论主是护法等十位论师，经玄奘大师糅译为一部论。哪一句原属护法论师的释论，哪一句是大师糅译时的措辞，今天已无法逐句分辨。可以确定的是：十家释论四千五百颂，大师只取一部，以护法为正义，论主的判断、总结与叮咛都保留在各个关键段落的结尾。论主说的话，就是大师选定的话。

论主自己说话的地方，有四类。

第一类是判定。几家并列之后，论主用一句话判定取舍：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">若作是说，妙符理教。（卷四，俱有依）<br>若作是说，善顺教理。（卷四，末那所缘）<br>若作是说，不违理教。（卷四，末那心所）<br>故自类依深契教理。（卷四，开导依）<br>由此应知，诸法种子各有本有、始起二类。（卷二，种子）</div>

大意：依护法的说法，才巧妙地符合道理和圣教。

五句判定，用的标准始终是“理”与“教”两样。合乎道理而没有圣教依据，不取；有圣教文字而道理说不通，也不取。全论判定是非的标准，就在“理教”二字。

第二类是总结。一大段辨析之后，论主直接说出结论：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">我法非有，空识非无，离有离无，故契中道。（卷七）<br>真如亦是假施设名。（卷二）<br>若执唯识真实有者，如执外境，亦是法执。（卷二）<br>是谓大乘真俗妙理。（卷七）</div>

大意：实我实法不存在，真空与识并非没有，远离有无两边，契合中道。真如也只是假立的名字。执着唯识实有，也是法执。依世俗与胜义两层分说，就是大乘真俗的妙理。

第三类是说明破与立的关系。论主两次说明，破了之后为什么还要立：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">岂斥他过，己义便成？若不摧邪，难以显正。（卷三）<br>虽说未了，非破他义己义便成，应更确陈成此教理。（卷七）</div>

大意：难道指出别人的过失，自己的主张就成立了？不摧破邪说，又难以显示正理。前面已经说过，还没有说完整；破了他人的主张，自己的主张并不因此成立，应当更确切地陈述成立唯识的教理。

论主清楚地知道，前面六卷大半在破，破得再彻底，也不等于立。所以到卷七，论主郑重地另起一段，以教证、四智、四个论式正面成立唯识。“若不摧邪”与“应更确陈”两句，是整部论“先破后立”结构的自我说明。

第四类是顾念读者。论主四次说：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">证此识有，理趣无边，恐厌繁文，略述纲要。（卷四）<br>如是等教诸部皆有，恐厌广文，故不繁述。（卷五）<br>如是三性义类无边，恐厌繁文，略示纲要。（卷八）<br>此十义类差别无边，恐厌繁文，略示纲要。（卷九）</div>

大意：道理无边无际，恐怕读者厌烦繁文，只略说纲要。

论主四次说“恐厌繁文”，值得特别留意。后世对《成唯识论》的注疏，篇幅动辄数十倍于本论，读者望而生畏。论主自己造论时，一再只说纲要。本论的本怀，原本就是“要言不烦”。本次译注之所以只在真正卡住的地方加短注，不作讲义式的发挥，也正是想随顺论主“略示纲要”的心意。

二、论主对圣教的珍惜

论主对圣教的珍惜，在论中有几处清楚的流露。

其一，以圣教与正理并为定量。凡证成一个关键主张，论主都先说“圣教正理为定量故”，先引经，再说理。第八识的证明，先引《阿毗达磨经》《解深密经》《入楞伽经》，再立十条正理；第七识的证明，先引《入楞伽经》《解脱经》，再立六条正理；唯识的成立，先引四智与经偈，再立四个论式。经不是装饰，是根据；理不是附会，是印证。

其二，为大乘经辩护。卷三中，论主特别停下来，以弥勒菩萨的七种理由证明大乘真是佛说，最后一条说：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">大乘所说意趣甚深，不可随文而取其义，便生诽谤，谓非佛语。</div>

大意：大乘经所说的意趣甚深，不可以随着文字表面取义，就生起诽谤，说大乘经不是佛语。

弥勒菩萨的第七条理由护持的是经典，也护持读经的人：经义甚深，读不懂时，责任在读者，不在经典。

其三，防止圣教被误读。卷九解释三无性时，论主特别叮咛：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">三颂总显诸契经中说无性言非极了义，<br>诸有智者不应依之总拨诸法都无自性。</div>

大意：三首颂总显诸契经中说“无自性”的话不是究竟了义；一切有智慧的人，不应依“无自性”的文字全盘否定诸法。

论主珍惜般若经，也珍惜读般若经的人，不愿后学因为一句“一切法无自性”而落入断灭。

其四，对邪说的严峻。论主对诸外道的结论是：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">是故彼言唯矫避过，诸有智者勿谬许之。（卷一）</div>

大意：所以外道的说法只是巧妙回避过失，一切有智慧的人，不要错误地接受。

对恶取空，论主说得更重：否定二谛，“诸佛说为不可治者”。珍惜圣教，所以不容圣教被曲解。

三、论主对后学的期许

论主对后学的期许，散在全论各处，读到时往往一笔带过。集中起来看，是一条清楚的线索。

开篇的归敬颂，第一句敬佛，第四句就是众生：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">我今释彼说，利乐诸有情。</div>

造论的三重缘起，第一重就是“为于二空有迷谬者生正解故”，是为迷惑的人而写。

在关键处，论主一再叮咛：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">诸有智者应顺修学。（卷三，缘起正理）<br>诸有智人应深信受。（卷四，第八识）<br>诸有智者应随信学。（卷五，第七识）<br>故于唯识应深信受。（卷七）<br>故定应信一切唯识。（卷七）</div>

“诸有智者”四字，不是对聪明人的恭维，是论主对读者的信任：论主相信读者能够依理而信，依信而学。

最深切的期许，在卷七成立唯识的结尾：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">若如是知唯识教意，便能无倒善备资粮，<br>速入法空，证无上觉，救拔含识生死轮回。</div>

大意：如果如实了知唯识之教的意趣，就能没有颠倒地善加具备资粮，迅速悟入法空，证得无上觉，救拔一切众生出离生死轮回。

论主期许的不是读者理解唯识，是读者凭唯识成佛，再去救度众生。

卷九点出全论的宗旨：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">成立唯识，意为有情证得如斯二转依果。</div>

大意：成立唯识的用意，是为了令有情证得大涅槃与大菩提两种转依之果。

卷十几乎到了最后，论主又补上一句，说出佛为什么要说“唯识”：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">或诸愚夫迷执于境，起烦恼业，生死沉沦，不解观心，勤求出离；<br>哀愍彼故，说唯识言，令自观心，解脱生死。</div>

大意：一切愚夫迷执外境，起烦恼造业，在生死中沉沦，不懂得回观自心；佛哀愍愚夫，所以说“唯识”，令愚夫自己观心，解脱生死。

全论以回向颂作结：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">所获功德施群生，愿共速登无上觉。</div>

从“利乐诸有情”开始，到“愿共速登无上觉”结束。中间十卷的精密辨析，开头和结尾都是为了众生。利乐有情是论主的本怀，也是玄奘大师糅译此论、留给东土的本怀。

四、全论的一条大理路

《成唯识论》篇幅浩大，抓住一条主要的理路，就能读通全论。全论的理路可以用七个问题贯穿起来。

第一问：世间和圣教都说有“我”有“法”，“我”和“法”从哪里来？

答：都是依识所变现而假立的。识体转起时，显现为见分和相分，依见相二分施设我和法。外境随情执而施设，所以不像识那样存在；识依因缘而生，所以不像外境那样不存在。（卷一）

第二问：能变现的识是哪些？

答：只有三类：第八异熟识，第七思量识，前六了境识。（卷二至卷七）第八识藏一切种子，恒转如瀑流；第七识恒审思量，执第八识为我；前六识了别境界，与五十一种心所相应。八识同时运转，非一非异。

第三问：既然只有识，为什么说“一切唯识”？

答：诸识转变为能分别和所分别，离开识所变的二分，实我实法都不存在。“唯”字只遮除离识的实物，不遮除不离识的心所、见相二分和真如。（卷七）

第四问：没有外缘，种种分别、生死相续怎样成立？

答：由本识中一切种子的转变，以及现行诸识展转相助，分别得以生起；四缘在识内就能具足。由业习气与二取习气，前一期异熟尽了，后一期异熟又起，生死相续。（卷七至卷八）

第五问：佛为什么又说三性、又说一切法无自性？

答：三性都不离识。识所执的实我实法是遍计所执，根本没有；识本身依缘而起，是依他起，如幻而有；依他起上离开遍计所显的真如，是圆成实。依三性立三无性，“无自性”不是全无。圆成实就是唯识的真实性。（卷八至卷九）

第六问：怎样悟入唯识？

答：经五个阶位：资粮位深信，加行位观二取空，通达位无所得而真住唯识，修习位反复修无分别智、舍二障粗重，究竟位证得转依。（卷九至卷十）

第七问：悟入之后得到什么？

答：转舍遍计所执，转得圆成实；转烦恼障得大涅槃，转所知障得大菩提；转八识成四智；成就三身，穷未来际利乐有情。（卷十）

七个问题前后相续：从“我法何来”出发，经过“识怎样变现”“为何唯识”“无外缘怎样成立”“空有怎样安立”，走到“怎样修证”“证得什么”。前面是唯识相，中间是唯识性，最后是唯识位。三十颂的结构，就是按七个问题的次第安排的。

五、十二个关键结论

读完全论，以下十二个结论是必须掌握的。每一条都注明出处，读者可回原篇细读。

一、我法皆是假立。“我谓主宰，法谓轨持”，主体与对象都依识所变而假立。（卷一上）

二、境假识有。“境依内识而假立故唯世俗有，识是假境所依事故亦胜义有。”说境空，说识有，同时遮除增益和损减。（卷一上）

三、心识四分。每一念心都有相分、见分、自证分、证自证分，第三、第四分互证，没有无穷后退。（卷二下）

四、种子本有新熏。一切种子各有本有和始起两类；种子须具六义，熏习须所熏、能熏各具四义。（卷二中、卷二下）

五、因果只在现在。过去未来没有实体，“观现在法有引后用，假立当果；观现在法有酬前相，假立曾因”。（卷三上）

六、末那是我执之根。末那识恒审思量，执第八识见分为我，与我痴、我见、我慢、我爱恒常俱起；一切善心之所以有漏，正因为心底有末那的我执相伴。（卷四下、卷五中）

七、法执先于我执。“如夜迷杌等，方谓人等”：先把树桩认作实物，才会把实物认作人。（卷五上）

八、唯识不是只有一识。“识”总摄八识、心所、相见二分、分位、真如五类，正对五位百法；“唯”只遮离识的实物。（卷七下）

九、唯识也不可执。“若执唯识真实有者，如执外境，亦是法执。”加行位“现前立少物”，仍非真住唯识。（卷二上、卷九上）

十、三性定位一切法。遍计所执无，依他起如幻有，圆成实真实有；三性非异非不异；不见真如，就不能如实见到缘起如幻。（卷八下）

十一、转依是修证的全部归宿。转舍遍计、转得圆成；涅槃是“显”，菩提是“生”；转识成智，转的是主导者，不是换掉一样东西。（卷九中、卷十中）

十二、众生见佛也是自识变现。诸佛的变现只是增上缘，“令所化生自识变现”。唯识的道理一直贯彻到见佛闻法。（卷十下）

六、贯穿全论的四种方法

论主处理问题，反复使用四种方法。认出中道、真俗、理教、破立四种方法，读任何一段都能明白论主在做什么。

第一，中道。全论至少有四处明言中道：卷一说境空识有，“由此便遮增减二执”；卷三说阿赖耶识恒转如流，“远离二边，契会中道”；卷七说唯识，“我法非有，空识非无，离有离无，故契中道”；卷七引慈尊二颂，“非空非不空，是则契中道”。每一处都是一面破实有，一面破断灭。

第二，真俗两层。凡是可能陷入“一”或“异”两边的问题，论主都分两层说：心所与心王，依世俗离心有别自性，依胜义非离非即；八识，“俗故相有别，真故相无别”；唯识的相与性，依世俗说唯识相，依胜义说唯识性。两层分开，就不会执一边而废另一边。

第三，理教双证。所有关键主张都有经证和理证两种根据，判词也总是“理教”并举。

第四，先破后立。卷一至卷二上破外道和小乘的实我实法；卷二中至卷七中立三能变；卷七下正式成立唯识；卷八以下立三性与修证。论主自己说明了先破后立的结构：“若不摧邪，难以显正”；“非破他义己义便成，应更确陈成此教理”。

七、翻译中的几点发现

逐句翻译一遍，有几点感受，平时读原文不容易发现，记在译后语中，供读者参考。

第一，“唯识”一名，在全论中被反复放下。卷二说执唯识实有也是法执；卷九说加行位举着“唯识性”仍是有所得；卷十说佛说唯识是为了令愚夫回头观心，“非谓内境如外都无”。论主建立唯识，又始终不让读者执着唯识。读者如果只记住“万法唯识”四字，而没有记住唯识不可执，就没有读懂本论。

第二，安慧与护法的分歧，是读懂全论的关键。两家最根本的分歧在见相二分：安慧以为见相二分本身就是遍计所执，只有识体是依他起；护法以为见相二分也是缘生的依他起，虚妄只在把影像执为心外实物的那一层。卷七“转变”的两种解释、卷八遍计所执与依他起的分界，都源于见相二分的分歧。玄奘大师以护法为正义，所以本论的唯识不是“心中所现都是假的”，而是“心中所现如实地是心中所现，执为心外才是假的”。

第三，论主的时间观极为彻底。卷三破有部三世实有、破余部一念两时之后，论主把因果完全建立在现在一念上：过去之因与未来之果，都是现在识上显现的相。读到卷八十二有支“一重因果足显轮转，施设两重实为无用”，正是现在一念时间观的延伸。

第四，菩萨道与二乘道的分别，在一个微妙之处。卷八和卷九说：菩萨见道后有能力断烦恼，故意留下烦恼的种子作为受生之缘；菩萨留身度众，又要借助所知障中“执有情实有、菩提实有”的一分，悲愿才能猛利。所知障在菩萨道上反成助缘，直到成佛才与烦恼障一并断尽。故留烦恼与借助所知障两义，最能显示唯识修道论的慈悲与精密。

第五，论中所有的“有义”，读到最后都归于一家之说。沈玄明《后序》说本论“文同义异，若一师之制”。逐句翻译之后，可以确认沈玄明的评语并非溢美：十家的意见被安排在各自的位置上，有破有立，有取有舍，最后都汇入护法的正义，又都以“理教”为标准，读来确如一位论师在次第论证。十家归于一家之说，是玄奘大师糅译之功。

八、翻译体例回顾

本译注依导论所立的体例进行。

逐句翻译，不删减，不概括，不另作讲义式的发挥。

“有义”处依窥基大师《成唯识论述记》点出论师名字；归属不能确定的，只依次称“第一家”“第二家”，不强配人名。判词明确的正义，归护法论师。

外人提问译为“外人质问”，对方辩解译为“某某辩解”，论主回答译为“论主回答”，让每一句都有说话人。

因明论式改写为“主张是……理由是……例证是……”。

古文与梵文的倒装一律改为现代语序；“此”“彼”“其”一律换成所指的名称；不用转折句式，直接陈述。

名相保留玄奘大师原词，初见时就地说明。

颂文、经偈和论中特别精要的语句，保留原文，放在格式框中，附大意。

译注只在真正卡住的地方加，力求一两句说明白；举例只用论中、经中或论师注疏本有的例子，不另造现代比喻。

九、底本订正与待核清单

底本为大正藏第三十一册第一五八五号的电子文本。翻译中径改的错字如下：“噁心”作“恶心”，“唸唸”作“念念”，“髮”作“发”，卷五“末耶”作“末那”，卷一“何所??少”作“何所阙少”，卷七“纯苦趣中意若俱故”作“意苦”。另有一处依文义订正并在译注中说明：卷六“贪与瞋痴定不俱起”，作“贪与瞋疑”。

以下各处，译注中依窥基大师《述记》或通行说法作了论师归属或解释，翻译时未能逐字核对《述记》原文，发布前宜再核：

导论：神昉、嘉尚、普光、窥基四人同译，后独留窥基；护法释本得自玄鉴居士。

卷一上：三种实我分属数论胜论、无惭外道、兽主遍出；“不可说我”属犊子部、正量部。

卷一中：声常二家属婆罗门与声显论；极微常住属顺世外道等。

卷一下：身表以形为体属有部、以动为体属正量部；和合说属经部，极微说属有部旧说，和集说属众贤。

卷二上：“假说难”的问难者站在胜论立场。

卷二下：生因、引因的例子；“一水四见”的注；四分说依次属安慧、难陀、陈那、护法。

卷三上：二受说属正理师。

卷三下：善业者冷触从下起、恶业者从上起；恶取空指清辨论师一系。

卷四中、卷四下：“依彼转”两家属难陀、护法；末那所缘四家属难陀、火辨、安慧、护法。

卷六下：“梵于释子起谄诳”所指马胜比丘事。

卷七上：《瑜伽》“五种性不成”一颂的大意。

卷七下：“转变”两解属护法、安慧。

卷八中：“若二三七各定同世”的解读。

卷八下：能遍计两家、遍计所执与依他起分界两家，前家属安慧，后家属护法。

卷十下：“不尔应无五十二等”一句，标为存疑。

十卷正文三十篇，导论一篇，译后语一篇，至此全部完成。愿读者依此译注，直入论文，不再为古文所阻；读懂之后，再回到玄奘大师的原文，体会一字千训之妙。
