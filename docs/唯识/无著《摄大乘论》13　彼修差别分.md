彼修差别分第六

一、菩萨十地

上面已经说了彼入的因果，彼修的差别应当如何看待？由菩萨的十地。十地是什么？第一，极喜地；第二，离垢地；第三，发光地；第四，焰慧地；第五，极难胜地；第六，现前地；第七，远行地；第八，不动地；第九，善慧地；第十，法云地。

二、十相所知法界与十种无明

上面的诸地安立为十，应当如何看待？为了对治十种无明所治之障。所以如此的理由是：对十相所知的法界，有十种无明所治之障安住。

十相所知法界是什么？在初地中，由遍行之义；在第二地中，由最胜之义；在第三地中，由胜流之义；在第四地中，由无摄受之义；在第五地中，由相续无差别之义；在第六地中，由无杂染清净之义；在第七地中，由种种法无差别之义；在第八地中，由不增不减之义、相自在依止之义、土自在依止之义；在第九地中，由智自在依止之义；在第十地中，由业自在依止之义、陀罗尼门与三摩地门自在依止之义。关于十相法界，有三颂：

```
遍行最胜义
及与胜流义
如是无摄义
相续无别义
无杂染净义
种种无别义
不增不减义
四自在依义
法界中有十
不染污无明
治此所治障
故安立十地
```

大意：遍行之义、最胜之义、胜流之义、无摄受之义、相续无差别之义、无杂染清净之义、种种法无差别之义、不增不减之义、四种自在依止之义，法界中有十相，对应有十种不染污的无明；为了对治所治的十障，所以安立十地。

又应当了知：上面的无明，对声闻等不是染污，对诸菩萨是染污。

【世亲释】十种所治之障是：第一，异生性。第二，对诸有情身等的邪行。第三，迟钝性，对闻、思、修有所忘失。第四，微细烦恼现行，属于俱生身见等所摄，因为是最下品、不作意而缘、远随现行，所以称为微细。第五，对下乘般涅槃的意乐。第六，粗相现行。第七，细相现行。第八，对无相起作行。第九，对饶益有情之事不起作行。第十，对诸法未得自在。

【世亲释】十相法界的意义是：遍行，法界遍一切行，没有少许法不是无我。最胜，法界在一切法中最为殊胜。胜流，大乘教法从法界流出，最为殊胜。无摄受，证法界时，没有计我所、摄我所，如同北俱卢洲人没有系属。相续无差别，法界的体没有差异，不像眼等随有情相续而各异。无杂染清净，法界本来没有杂染，性无染，所以也没有清净。种种法无差别，契经等法有种种差别安立，法界没有差异。不增不减，杂染减时法界没有减，清净增时法界没有增。相自在依止，法界是于诸相得自在的所依，随所欲之相即现前。土自在依止，法界是于所现佛土得自在的所依，如欲令土成为金等宝，随意而成。智自在依止，法界是无碍辩智自在的所依。业自在依止，法界是身等业自在的所依，以及陀罗尼门、三摩地门自在的所依。如此了知，就依次得入各地。

【世亲释】无明对声闻不是染污，因为声闻不欲入诸地。初地中已经能通达一切地，为什么还要依次安立诸地？初地已经通达一切地，由住于一地而得安住于一地，由安住之力，建立诸地。

三、十地的名义

又，为什么初地称为极喜？因为在初地最初得到能成办自他义利的殊胜功能。为什么二地称为离垢？因为远离犯戒之垢。为什么三地称为发光？因为是不退转的等持、等至的所依止，是大法光明的所依止。为什么四地称为焰慧？因为诸菩提分法能焚灭一切障。为什么五地称为极难胜？因为真谛智与世间智互相违背，把难以相合的两者合起来使之相应。为什么六地称为现前？因为以缘起智为所依止，能令般若波罗蜜多现在前。为什么七地称为远行？因为到达有功用行的最后边际。为什么八地称为不动？因为一切相与有功用行都不能动摇。为什么九地称为善慧？因为得到最殊胜的无碍智。为什么十地称为法云？因为得到总缘一切法的智慧，含藏一切陀罗尼门、三摩地门，如同大云，能覆盖如虚空般广大的障；又因为能令法身圆满。

【世亲释】初地称为极喜，因为初得能办自他俱利的殊胜堪能；声闻等真现观时只得自利的堪能，不得利他，所以不生如此的欢喜。二地称为离垢，因为在二地性戒成就，不像初地还要思择护戒。五地称为极难胜，因为了知真谛的智是无分别的，了知世间工巧论议等的智是有分别的，两者相违，修令相合，能合难合，所以称为极难胜。七地称为远行，因为在七地，有功用行得到究竟；一切相不能动摇，对于无相，仍称为有行；到八地，无分别智任运流行，所以不动。十地称为法云，因为总缘一切法的智如同大云，陀罗尼门、三摩地门如同净水，智慧含藏诸门，如同云中含水；又如大云遍满虚空，此智遍满诸菩萨所依的法身。

四、得地的四相

得到诸地应当如何看待？由四种相：第一，得胜解，就是对诸地得到深信解。第二，得正行，就是得到与诸地相应的十种正法行。第三，得通达，就是在初地通达法界时，普遍通达一切地。第四，得成满，就是修习诸地到达究竟。

五、修地的五相与五果

修习诸地应当如何看待？诸菩萨在每一地中修习奢摩他、毗钵舍那，由五种相修习。五种是：集总修，无相修，无功用修，炽盛修，无喜足修。

上面五种修习，令诸菩萨成办五种果：念念之中消融一切粗重的依止；远离种种相，得到法苑之乐；能正确了知周遍、无量、无分限之相的大法光明；随顺清净之分、无所分别的无相之行现前；为了令法身圆满成办，能正确摄受后后的殊胜之因。

【世亲释】“粗重”，是烦恼障与所知障从无始以来的熏习种子；由缘总法的止观智力，念念使二障之聚破坏或羸损，称为消融。“法苑之乐”，契经等法有种种性，远离种种性之想，就证得法苑之乐，法中可以安居，所以称为苑。“大法光明”，是正确了达十方无边、无分限之相，如同善于熟诵的文字所生的光明。“随顺清净之分”，此中指所得的佛果。“后后的殊胜之因”：第十地的法身称为圆满，第十一佛地的法身称为成办，一切因中，能生佛地的因最为殊胜。

六、十地别修十波罗蜜多

由于增胜的缘故，说在十地中分别修习十种波罗蜜多。前六地所修的六种波罗蜜多，如前已说。后四地所修的四种：第一，方便善巧波罗蜜多，就是以前六种波罗蜜多所积集的善根，与诸有情共同回求无上正等菩提。第二，愿波罗蜜多，就是发种种微妙大愿，引摄当来波罗蜜多的殊胜众缘。第三，力波罗蜜多，就是由思择、修习二种力量，令前六种波罗蜜多无间现行。第四，智波罗蜜多，就是由前六种波罗蜜多成立妙智，受用法乐，成熟有情。

又，上面四种波罗蜜多，应当了知是般若波罗蜜多中的无分别后得智所摄。又，在一切地中，并不是不修习一切波罗蜜多。上面的法门，是波罗蜜多藏所摄。

【世亲释】“由于增胜”：初地中布施波罗蜜多最为增胜，其余波罗蜜多并非不修，随力随分而修；乃至第十地中智波罗蜜多最为增胜。在说十种波罗蜜多的地方，只有无分别智称为般若波罗蜜多，其余方便善巧等四种属于后得智所摄。方便善巧显示般若与大悲：由大悲，回求无上菩提，不求帝释等富乐之果；由了知，不起烦恼；具足方便善巧，不舍生死而不被染污。力波罗蜜多：即使还没有修习之力，由思择之力精进修习，也能令波罗蜜多无间现行。

七、经三无数大劫

又，要经过多少时间，修行诸地才能圆满？有五种补特伽罗，经过三无数大劫：胜解行补特伽罗，经第一无数大劫修行圆满。清净增上意乐行补特伽罗，以及有相行、无相行补特伽罗，在前六地和第七地，经第二无数大劫修行圆满。无功用行补特伽罗，从第八地以上到第十地，经第三无数大劫修行圆满。关于修行时劫，有一颂：

```
清净增上力
坚固心升进
名菩萨初修
无数三大劫
```

大意：具足清净的增上之力，以坚固之心升进，称为菩萨的最初修习，从此开始计算三无数大劫。

【世亲释】五种补特伽罗其实只是同一人，由于位次的差别而立为五种，如同预流、一来、不还。胜解行补特伽罗在胜解行地，经第一无数大劫修行圆满；通达真如后，成为清净增上意乐行补特伽罗，遍于十地；在前六地称为有相行，在第七地称为无相有功用行，经第二无数大劫；入第八地称为无功用行，到第九、第十地无功用行才成满，经第三无数大劫。

【世亲释】无始生死以来，屡修布施等，屡值诸佛，从什么时候起算三无数劫的最初？颂中“清净增上力”，是善根力与大愿力：由善根力，所治不能降伏；由大愿力，常遇善知识。“坚固心升进”，是发起牢固之心，起增进之行：所发的大菩提心，诸恶友之力不能使之舍弃；现在及生生之中，善法常增，终无退减。
