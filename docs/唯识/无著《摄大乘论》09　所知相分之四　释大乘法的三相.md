<p class="dt-title">释大乘法的三相</p>

<div class="dt-subtitle">摄大乘论白话译注　第九篇　所知相分之四<br>无著菩萨造　唐　玄奘译　附世亲释、无性释</div>

本篇要目：一、造大乘法释的三相　二、说缘起　三、说从缘所生法相　四、说语义：由德处　五、说语义：由义处

一、造大乘法释的三相

如果有人想要造大乘法的解释，简略依三相造释：第一，说缘起；第二，说从缘所生的法相；第三，说语义。

二、说缘起

说缘起，如颂所说：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">言熏习所生<br>诸法此从彼<br>异熟与转识<br>更互为缘生</div>

大意：由言说熏习所生的诸法，转识从熏习而生，熏习从转识而生。异熟识与转识，互相为缘而生。

【世亲释】“由言说熏习所生的诸法”：外在的分别熏习在阿赖耶识中，以熏习为因，一切法得以生起，就是转识的自性。“此从彼”：分别熏习又以转识诸法为因。所以颂文显示阿赖耶识与转识互为因。

三、说从缘所生法相

又，转识之相的法，以有相、有见的识为自性。又，转识以依处为相，以遍计所执为相，以法性为相，由此显示三自性的相。如颂所说：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">从有相有见<br>应知彼三相</div>

大意：从有相、有见的识，应当了知三种自性之相。

【译注】“依处为相”就是依他起，“遍计所执为相”就是遍计所执，“法性为相”就是圆成实。

又，应当如何解释三相？遍计所执相，在依他起相中实际上无所有；圆成实相，在依他起相中实际上是有。由于遍计所执与圆成实两者，一是非有一是有，一是非得一是得，未见真理者与已见真理者，在同一时间。在依他起自性中，没有遍计所执，有圆成实；依他起转起时，如果得到遍计所执，就不得到圆成实；如果得到圆成实，就不得到遍计所执。如颂所说：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">依他所执无<br>成实于中有<br>故得及不得<br>其中二平等</div>

大意：在依他起中，遍计所执没有，圆成实是有。所以，在依他起中，得与不得，对两种人同时平等成立。

【世亲释】未见真理的人，在同一刹那得到遍计所执，不得到圆成实；已见真理的人，在同一刹那得到圆成实，不得到遍计所执。颂中“其中”指依他起中，“二”指未见真理与已见真理的两种人。愚夫由于颠倒执着，如此见；圣者由于正见，如此见。

四、说语义：由德处

说语义，就是先说最初一句，后面以其余的句子分别显示最初一句。或者由德处，或者由义处。

由德处，比如说佛的功德：“最清净觉，不二现行，趣无相法，住于佛住，逮得一切佛平等性，到无障处，不可转法，所行无碍，其所安立不可思议，游于三世平等法性，其身流布一切世界，于一切法智无疑滞，于一切行成就大觉，于诸法智无有疑惑，凡所现身不可分别，一切菩萨等所求智，得佛无二住胜彼岸，不相间杂如来解脱妙智究竟，证无中边佛地平等，极于法界，尽虚空性，穷未来际。”

“最清净觉”一句，应当了知由其余的句子分别显示。以其余各句分别显示最初一句，才成为善说法性。

“最清净觉”，就是佛世尊最清净的觉，应当了知由佛的二十一种功德所摄。二十一种功德是：

第一，对所知一向无障碍而转的功德。第二，对有、无无二之相的真如，最胜清净能入的功德。第三，无功用而佛事不休息、安住的功德。第四，在法身中，所依、意乐、作业无差别的功德。第五，修习一切障的对治的功德。第六，降伏一切外道的功德。第七，生在世间，不被世间法所碍的功德。第八，安立正法的功德。第九，授记的功德。第十，在一切世界示现受用身、变化身的功德。第十一，断疑的功德。第十二，令入种种行的功德。第十三，对当来法生起妙智的功德。第十四，如众生的胜解而示现的功德。第十五，以无量所依调伏有情、加行的功德。第十六，平等法身波罗蜜多成满的功德。第十七，随众生的胜解示现差别佛土的功德。第十八，三种佛身方所无分限的功德。第十九，穷尽生死之际，常现利益安乐一切有情的功德。第二十，无尽的功德。第二十一，究竟等功德。

【世亲释】经文各句与二十一种功德的对应如下。“不二现行”，是对所知一向无障碍而转的功德，因为没有障与无障二种现行，不同于声闻、独觉的智有障也有无障。“趣无相法”，是能入真如的功德，真如称为无相法。“住于佛住”，是佛事不休息的功德。“逮得一切佛平等性”，是法身中所依、意乐、作业无差别的功德。“到无障处”，是修习一切障对治的功德。“不可转法”，是降伏一切外道的功德。“所行无碍”，是不被利、衰等世间八法所染的功德。“其所安立不可思议”，是安立正法的功德，因为契经等正法无量，非愚夫所能了解。“游于三世平等法性”，是授记的功德。“其身流布一切世界”，是示现受用身、变化身的功德。“于一切法智无疑滞”，是断疑的功德。“于一切行成就大觉”，是令入种种行的功德。“于诸法智无有疑惑”，是了知当来法如何生起的妙智功德。“凡所现身不可分别”，是如胜解而示现的功德。“一切菩萨等所求智”，是以无量菩萨为所依、调伏有情的功德。“得佛无二住胜彼岸”，是平等法身波罗蜜多成满的功德。“不相间杂如来解脱妙智究竟”，是随胜解示现差别佛土的功德，此中“解脱”就是胜解。“证无中边佛地平等”，是三身方所无分限的功德。“极于法界”，是穷生死际常现利乐有情的功德。“尽虚空性”，是无尽的功德，因为佛智如虚空无尽。“穷未来际”，是究竟的功德，佛智穷未来际，没有间断。“最清净觉”一句，在每一句中都普遍相应。

五、说语义：由义处

又，由义处，比如经中说：“如果诸菩萨成就三十二法，才称为菩萨。”三十二法是：

对一切有情起利益安乐的增上意乐；令有情入一切智智；自知“我今凭借什么智慧”；摧伏慢心；坚牢的殊胜意乐；非虚假的怜愍；对亲人与非亲人平等心；永作善友，直到涅槃为最后边际；应量而语；含笑先言；无限的大悲；对所承担的事无退弱；无厌倦之意；听闻义理无厌；对自己所作之罪深见过失；对他人所作之罪不瞋而教诲；在一切威仪中恒常修治菩提心；不希求异熟而行布施；不依一切有趣而受持戒；对诸有情没有恚碍而行忍；为摄受一切善法而勤精进；舍弃无色界而修静虑；与方便相应而修般若；以四摄事摄受方便；对持戒与破戒的善友无二；以殷重心听闻正法；以殷重心住阿练若；不爱乐世间杂事；对下劣乘从不欣乐；在大乘中深见功德；远离恶友；亲近善友；恒常修治四梵住；常游戏五神通；依趣于智；对住于正行与不住于正行的诸有情类都不弃舍；言语决定；尊重谛实；大菩提心恒为首要。

上面诸句，应当了知都是最初一句“对一切有情起利益安乐增上意乐”的差别。

“利益安乐增上意乐”一句，应当了知有十六种业的差别。十六种业是：第一，展转加行业。第二，无颠倒业。第三，不待他请自然加行业。第四，不动坏业。第五，无求染业，有三句差别，就是无染系、对恩与非恩无爱无恚、在生生中恒常随转。第六，相称的语业与身业，有二句差别。第七，对乐、对苦、对不苦不乐平等业。第八，无下劣业。第九，无退转业。第十，摄方便业。第十一，厌恶所治业，有二句差别。第十二，无间作意业。第十三，胜进行业，有七句差别，就是六波罗蜜多的正加行与四摄事的正加行。第十四，成满加行业，有六句差别，就是亲近善士、听闻正法、住阿练若、离恶寻思、作意功德（此有二句差别）、助伴功德（此有二句差别）。第十五，成满业，有三句差别，就是无量清净、得大威力、证得功德。第十六，安立彼业，有四句差别，就是御众功德、决定无疑的教授教诫、财法同摄、无杂染心。上面诸句，应当了知都是最初一句的差别。如颂所说：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">由最初句故<br>句别德种类<br>由最初句故<br>句别义差别</div>

大意：由最初一句，其余各句分别显示功德的种类；由最初一句，其余各句分别显示义理的差别。

【世亲释】十六种业与三十二法的对应，择要如下。展转加行业，就是令有情入一切智智，展转化导，如同一灯传燃千灯。无颠倒业，就是自知“我今凭借什么智慧”：有人怀着利益之心而劝人饮酒等，是颠倒；有正智如实自知，才能称量教导有情。不待他请自然加行业，就是摧伏慢心，所以不待劝请自为说法。相称语身业，就是应量而语、含笑先言：应量而语只说法语，是语业；含笑舒颜而往来作饶益之事，是身业。平等业，就是无限大悲：对有苦的有情悲愍其苦苦，对有乐的有情悲愍其坏苦，对不苦不乐的有情悲愍其行苦。厌恶所治业，就是对自罪深见过失、对他罪不瞋而诲。依趣于智，是依智不依识，由内智现见而安住于法。御众功德，是对破戒者也不弃舍、不摈出，令其出离不善、安住于善。财法同摄，是言语诚谛，以法摄取，衣服等财也同样布施。
