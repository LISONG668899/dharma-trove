第六门　诸藏与十二分教相摄的宽狭

先以诸藏对照十二分教的通相来相摄，后以诸藏对照十二分教的别相来相摄。

一、依通相相摄

依通相相摄，有三种：先以二藏对照，次以三藏对照，后以六藏对照。

（一）二藏对照

二藏之中，都有十二分教。

1. 《瑜伽师地论》第二十一卷，佛为声闻宣说十二分教，一一具足列出。
2. 《涅槃经》第三卷说："护持大乘的人受持九部。"经中自己说九部，就是除去因缘、譬喻、论议。并没有说声闻没有这九部，所以可知声闻具有十二部。不可以说除去这九部，其余三部称为声闻，因为声闻藏中也有契经、应颂等。
3. 《瑜伽师地论》第二十五卷说声闻藏中没有方广，是因为声闻没有能得到无上果，所以说"无"；依照实际道理，声闻藏中也通于有方广。
4. 《法华经》第一卷说小乘有九部："我此九部法，随顺众生说，入大乘为本，以故说是经。"（大意：我这九部法，随顺众生宣说，以进入大乘为根本，所以宣说这部经。）经中自己说九部，就是除去记别、自说、方广。并不遮止大乘具有十二部。

所以可知，二藏所取的部数，互相不遮止。由此应当作四句分别：

1. 大乘全部，不是小乘，如《法华经》所说。
2. 小乘全部，不是大乘，如《涅槃经》所说。
3. 二乘都不全，合两乘的少分。
4. 二乘都全，合两乘的全分。

所以二藏中都具足十二分教。

（二）三藏对照

既然承认契经、缘起、论议的通相，都有十二分教，所以三藏都与十二分教相摄，如前面所引教理广泛成立。三藏中每一藏都具有十二分。

1. 记别的意义既然具有三种，随其所应，属于毗奈耶所摄。
2. 菩萨戒等既然称为方广，属于毗奈耶所摄，道理上也不相违。
3. 因请、因事宣说种种深理，所以因缘经也通于对法藏。
4. 既然从"如是"开始，到"奉行"结束，都是修多罗，所以可知三藏都有十二分。

（三）六藏对照

既然说通相的十二分互相通摄，所以六藏中都有十二分。正法广泛陈述，称为方广，所以方广通于声闻藏。记别诸弟子死生的事，通于声闻藏中的毗奈耶。

以上总说依通相的相摄。

二、依别相相摄

依别相相摄，也有三种：先以二藏对照，次以三藏对照，后以六藏对照。

（一）二藏对照：四处经论的不同说法

1. 《涅槃经》第三卷说：大乘有九部，只是没有因缘、譬喻、论议；小乘具足十二部，因为经文不遮止，所以说具有。《瑜伽师地论》第二十一卷说小乘具有十二部。
2. 《法华经》说：小乘有九部，就是除去记别、自说、方广；大乘有十二部。
3. 《瑜伽师地论》第三十八卷说：方广分只属于菩萨藏，其余各分有声闻藏。这是说大乘具有十二部，小乘有十一部，只除去方广。
4. 《瑜伽师地论》第八十五卷说：十二分中除去方广分，其余的称为与声闻乘相应的契经；只有方广分，单独称为与大乘相应的契经。这是说小乘有十一部，大乘只有方广。

四处文字不同，各有不同的用意。这里都是依照别相门来说的。

第一，会通《涅槃经》说大乘没有因缘、譬喻、论议：

1. 《涅槃经》依照"因有人犯过而制戒"说为因缘。诸大菩萨本来没有犯过，不因此制戒，所以说没有因缘；并不是没有因请问、因事而说法的因缘经。
2. 宣说譬喻比况，是为了开导中、下根人。诸大菩萨大多是利根，不需要譬喻，听闻佛法就能理解，所以说没有譬喻；道理上并非没有，因为现见诸大乘经中，有很多宣说譬喻的。
3. 诸大菩萨的根性都是利根，举出宗旨就能理解，不需要征问诘难才生起智慧，所以说没有论议；实际道理上并非没有，因为《解深密经》《瑜伽师地论》等是大乘，说明论议经通于大乘。

问：既然说菩萨因为是利根，不需要论议，应当也没有应颂，因为不需要重说。

答：为了利益后来的人，需要以偈颂重说，并不是前面的菩萨需要重颂。

《涅槃经》一往依照这种别义，说大乘中没有这三分，实际上具有。又，护法的人诵持三藏，大多只诵素呾缆藏，不诵其余两藏，所以只说九部，略去其余三部；其余三部就是律、论两藏所摄。实际道理上，大乘并非没有十二部，因为诸圣教中都说大乘有这三部。

第二，会通《法华经》说小乘没有记别、自说、方广：

1. 《法华经》依照为弟子授得成佛之记，称为记别。说声闻没有记别，是因为声闻不求大菩提。就像拿珍宝给愚人看，愚人便会发笑；声闻听到成佛授记，也是这样。所以说没有。至于记别诸弟子死生的事等，实际道理上也有。
2. 声闻人大多听闻浅法，如果不等待请问就说，憍慢便会生起，所以说没有自说；实际上也有。
3. 声闻法只证小果，不能得到无上正等菩提，理不是至极，行不能包含弘大，所以说没有方广；实际上也有，因为正法广泛陈述就称为方广。

另外，《法华经》这一会的宗旨在宣说一乘，为了引导一切不定种性的声闻趣向佛果。

1. 这类声闻以前没有听闻授记自己能够成佛，现在回心以后才能听闻，所以说声闻略去记别。
2. 《方便品》开头显示法的深妙，想让声闻生起尊重之心，没有请问不说，三次请问才说，所以说声闻略去自说。
3. 恐怕声闻等对先前听闻的四谛等法生起"无上"的想法，现在显示四谛等法不是无上大法，无上大法只有大乘，所以说声闻略去方广。

《法华经》一往化导不定种性的人，依一种意义，说声闻人只有九部，实际上可以具有十二部。

第三，会通《瑜伽师地论》第三十八卷：

1. 《瑜伽师地论》第三十八卷与《法华经》相同，也是依照小乘的理和教不殊胜，不能得到菩提，称为没有方广，有十一部。
2. 小乘经中也记别弟子死生的事，分明显示诸法的密意，所以也有记别。
3. 小乘经中也显示佛的慈悲以及所有法相，不待请问而自己宣说，如最初转法轮，所以有自说。这与《法华经》略去记别、自说两分不同。

说大乘中有十二部：

1. 大乘经中也有因请问、因事而说法，所以有因缘。又《胜鬘经》说"毗尼就是大乘学"，所以有因缘。
2. 显示法的深难，也有比况的说法，所以有譬喻。
3. 法相幽深，往复问答才能明了，所以有论议。

所以说大乘具有十二部。

第四，会通《瑜伽师地论》第八十五卷：

1. 第八十五卷的文义与第三十八卷相同。只是因为十一分已经作为声闻藏，相对之下，只说方广一分作为菩萨藏，实际上菩萨具足十二分。
2. 第八十五卷所说的方广，是通相的方广，摄持十二分，所以不需要再说其余十一分称为菩萨藏。
3. 声闻藏中，第八十五卷说无论通相还是别相都没有方广，所以必须除去方广。

这就是四处文字不同的用意。

以上第一，二藏对照完毕。

（二）三藏对照

三藏有两种：

1. 《普曜经》中的三藏，就是菩萨、独觉、声闻三藏。
2. 素呾缆、毗奈耶、阿毗达磨三藏。

独觉的教法没有各别的部类，不可以另外说有十二分教的差别，只与声闻相同。声闻、菩萨在前面二藏中已经解释完毕。

《显扬圣教论》第六卷、《瑜伽师地论》第二十五卷说：

1. 十二分中，契经、应颂、记别、讽诵、自说、譬喻、本事、本生、方广、希法，是素呾缆藏。
2. 所说的因缘，是毗奈耶藏。
3. 所说的论议，是阿毗达磨藏。

这是说十部是素呾缆，只说一部是毗奈耶，只说一部是对法藏。素呾缆中具足十二分；因事而制戒，正是毗奈耶；论难甚深，也只是对法。所以略去这两部，不作为素呾缆。素呾缆中并非没有这两部。

譬喻、本事、本生三种，实际道理上也通于毗奈耶所摄。《大乘阿毗达磨杂集论》说这三种是毗奈耶藏，因为律中多说譬喻等，属于眷属所摄，自性上就不是毗奈耶。《显扬圣教论》等依照自性，不属于毗奈耶所摄，所以说这三种是素呾缆；《杂集论》依照眷属，说是毗奈耶。各就一边来说，并不相违。

以上总的是三藏对照。

（三）六藏对照

《大乘阿毗达磨杂集论》第十一卷说：

1. 契经、应颂、记别、讽诵、自说，属于声闻藏中的素呾缆所摄。
2. 缘起、譬喻、本事、本生，属于菩萨、声闻二藏中的毗奈耶藏，连同眷属所摄。因缘一种正是毗奈耶，譬喻等三种是毗奈耶的眷属。
3. 方广、希法，属于菩萨藏中的素呾缆所摄。方广广博，正是菩萨藏；希法难以思议，也是菩萨藏。
4. 论议一种，通于二藏中的阿毗达磨藏所摄。

这里的意思是说，十二分教在六藏中：

1. 五分只属于声闻素呾缆所摄。
2. 四分通于二藏的毗奈耶所摄。
3. 两分只属于菩萨素呾缆所摄。
4. 一分通于二藏的阿毗达磨。

依照这个说法，声闻只有十种，菩萨藏内只有七种。依据实际：

1. 前五分也通于菩萨素呾缆所摄。因为声闻中略去方广，只说这五分作为声闻素呾缆所摄，并不是菩萨中没有这五分，因为《瑜伽师地论》第三十八卷说十二分都通于菩萨藏。
2. 缘起等四分，也不是二藏中的素呾缆所不摄。因为以自性和助伴说为毗奈耶，所以略去不说为二藏的素呾缆。只说因犯过而制戒，称为因缘；因缘的自性属于毗奈耶所摄，眷属随着也属于毗奈耶藏所摄。《涅槃经》说从"如是"开始到"奉行"结束都是修多罗经，《瑜伽师地论》第二十五卷说十部称为素呾缆，所以譬喻等三种也是素呾缆。因请问、因事而说法称为因缘，所以也说为素呾缆。这三种相随，也属于毗奈耶所摄。
3. 声闻藏的素呾缆中，也并非没有方广、希法。因为《涅槃经》不遮止十二分都通于声闻而有，正法广陈的意义也相通。又说十一分作为声闻藏，所以可知希法也通于声闻素呾缆。现在以理极至、能得菩提称为方广，只以宣说诸佛菩萨的大威神称为希法，所以说声闻素呾缆中没有这两分，实际道理上都有，如前面已经说过。并且没有方广，是诸文共同的说法；没有希法，是因为希法属于眷属所摄，只在菩萨藏中，实际上是相通的。
4. 论议大多只是对法；或者就弟子所造的论等称为论议，所以只摄在阿毗达磨中。实际道理上，论议也通于二藏的素呾缆。

这是以菩萨、声闻的素呾缆藏对照其余各分作简别，最初的文句暂且举出一边的意义。又以二藏各自的毗奈耶、阿毗达磨，与十二部互相对照，意义都可以相通而有。如果随别义相对作简别，依义推知即可，恐怕文字繁广，所以略去不述。

三、《涅槃经》"从十二部出修多罗"的解释

《涅槃经》说："从十二部出修多罗，从修多罗流出方广。"

1. 这是从别相中流出总相。从"如是"开始到"奉行"结束都是修多罗，所以说从十二分出修多罗。
2. 又从总相中流出总相。方广也具有十二分，所以说从修多罗流出方广。

又有一种解释说：先从别相出总相，后从总相出别相，想要显示总相和别相互相流出。

四、依别相的正说

现在依照诸文，依别相正说，应当这样说：

1. 方广只属于菩萨素呾缆所摄。
2. 论议通属于菩萨、声闻的阿毗达磨。
3. 因缘也通属于声闻、菩萨的毗奈耶所摄。
4. 契经、应颂、记别、讽诵、自说、希法这六种，也通属于声闻、菩萨藏中的素呾缆所摄。
5. 譬喻、本事、本生三种，通属于声闻和菩萨藏，属于素呾缆和毗奈耶两藏所摄。

《大乘阿毗达磨杂集论》所说的，是依据别义，并不违背义理和经文。这是依多分来说；或者方广分也通于两种。这样所说，不违背诸教。

如果依通门相对相摄，以藏分部，成为三十六种；以部分藏，也是三十六种。如果以别相相摄为门，以藏分部等，随应广说。

五、三藏的修多罗与十二分的修多罗：四句分别

由此，三藏与十二分中的修多罗等，互有宽狭，作四句分别：

1. 是三藏中的修多罗，不是十二分中的修多罗：就是应颂等属于修多罗藏的部分，因为十二分中是就别相来说的。
2. 是十二分中的修多罗，不是三藏中的修多罗藏：就是通相的修多罗中的因缘、论议等。
3. 两者都是：就是别相的修多罗，进入修多罗藏中的。
4. 两者都不是：就是十二分中别相的缘起等，三藏中别相的毗奈耶等，或者外道的典籍。

其余各藏中互相作四句的，名称既然不同，只是体性有宽狭，也可以作四句，依义理应当了知。

以上所辨相摄的意义合起来，是第六门，十二分教与诸藏相摄的宽狭。

第七门　问答分别

问一：为什么各分的名称不相混用

问：十二分教中，为什么长行简略宣说的，最初称为契经，不称为论议；乃至循环研究审核的，最后称为论议，不称为契经？

答：各种教法的得名，随着意义的增上。简略宣说、贯穿、长行增上的，只称为契经，不称为论议教等；问答、循环、研究审核增上的，只称为论议，不称为契经。

问二：十二分教的次第

问：为什么契经在最初，乃至论议在最后，是这样的次第？

答：这是依照文和义的先后相对，来辨明次第。

1. 契经。以贯穿的长行简略宣说，义理还没有了然。
2. 应颂。所以有应颂，一对一地说明完毕。
3. 记别。长行中有记别的事，所以其次是记别。
4. 讽诵。偈颂中又有不是重颂的，所以其次是讽诵。
5. 自说。前面的长行和后面的偈颂，有没有因由而说的，所以其次是自说。
6. 缘起。有有因由而说的，所以其次是缘起。
7. 譬喻。前面的长行和偈颂，既然只有法说，后面有喻说，所以其次是譬喻。
8. 本事。法说和喻说中，有说弟子以及佛自身往世之事的意思，先说他人，后说自己，所以其次是本事。
9. 本生。其后是本生。
10. 方广。前面诸法，理有正与不正，教行有宽与狭。理不正、教行狭的，就是前面所说的九分教；理正而方、教行宽广的，称为方广，所以接着说方广。
11. 希法。理和教既然有宽广的，所说的事也有前所未曾有的，所以其次是希法。
12. 论议。上面十一分，只是随所适宜，方便引导宣说，对于深奥的法相还没有能研究。为了显示深理，究问推寻，所以其次是论议。

所以十二分教有这样的次第，这也是废立增减的缘由。

（《十二分章》终）
