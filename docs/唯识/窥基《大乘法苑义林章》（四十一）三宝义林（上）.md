<div class="dt-subtitle">大乘法苑义林章白话译注（四十一）<br>唐　窥基　撰</div>

〔译注：《三宝义林》是全书第二十四章，卷六的开篇，讨论佛、法、僧三宝的种类、体性与名义。窥基把三宝分为六类：同体、别体、一乘、三乘、真实、住持。其中真实僧宝是否包括持戒的异生，以及破戒比丘是否算作住持僧宝，窥基都引《十轮经》详细辨析。原文约六千四百字，分两篇。本篇译前三门：明种类、出体性、释名字。〕

三宝，简略用六门分别：

1. 说明种类
2. 出体性
3. 解释名字
4. 辨明废立
5. 显示差别
6. 解释妨难

第一门　说明种类

有六种类：

1. 同体
2. 别体
3. 一乘
4. 三乘
5. 真实
6. 住持

一、同体三宝

《胜鬘经》说："归依第一义的，是究竟的归依，与如来没有差异，与另外两种归依没有差异，如来就是三归依。"

《涅槃经》第十卷说："如果能计执三宝常住，同于真谛，这就是诸佛最上的誓愿。"又说："如果对三宝修习差异之相，应当知道这个人所有的禁戒都不具足，尚且不能得到二乘的菩提，何况能得到大菩提。"又说："佛就是法，法就是僧，乃至佛性就是法身。"所以说同体。

二、别体三宝

《涅槃经》第五卷，佛说："憍昙弥，不要供养我，应当供养僧。如果供养僧，就得以具足供养三归。"

摩诃波阇波提说："众僧之中没有佛，没有法，为什么说供养众僧，就得以具足供养三归？"

佛又告诉她说："你随顺我的话，就是供养佛；为了解脱，就是供养法；众僧接受，就是供养僧。所以三归不得为一。善男子，如来有时说一为三，说三为一，这样的意义是诸佛的境界，不是声闻、缘觉所能了知的。"

三、一乘三宝

《胜鬘经》说："宣说一乘道法，得到究竟的法身，在此之上再没有宣说一乘法的事。三乘的大众，有恐怖的归依，不是究竟的归依。"

《显扬圣教论》说："善逝善说妙三身，无畏无流证教法，上乘真实牟尼子，我今至诚先赞礼。"（大意：善逝善于宣说微妙的三身，无畏无漏的证法与教法，上乘真实的牟尼弟子，我现在至诚，先赞叹礼敬。）

《佛地经论》说："稽首无上良福田，三身、二谛、一乘众。"（大意：稽首礼敬无上的良福田：三身佛宝、二谛法宝、一乘僧众。）

《法华经》也说："十方佛土中，唯有一乘法"等。

四、三乘三宝

《胜鬘经》说："对于还没有得度的世间、没有依怙的世间，与后际相等，作无尽的归依、常住的归依的，就是如来应正等觉。法，就是宣说一乘道；僧，就是三乘大众。"

那段经文的意思是说：为三乘的人所显现的三身，称为佛宝；二乘所修的教、理、行、果，是一乘的方便，称为一乘道法，因为最终归于一乘。

《杂集论》序说："敬礼如是大觉尊、无等妙法诸圣众。"又说："这三种佛身是差别的意义，应当知道这里也赞叹法、僧的功德。法宝，是自性、因、果等意义所摄；僧宝，是随着这法修学所生的。"诸言所表的是一切三宝，安慧的意思与天亲所说相同，心无偏党，有力量的都恭敬，所以说"诸圣众"等。《摄大乘论》也说："稽首大觉诸如来、无等妙法、真圣众。"没有另外的简别，所以通于三乘。

五、真实三宝

三身是佛宝；一切无漏的教、理、行、果，三乘的法宝；一切住向、住果、住道的三乘圣众，称为僧宝。大乘、小乘相同，是真实的三宝。

（一）《十轮经》的三种沙门

《十轮经》第五卷说，沙门有四种：

1. 胜道沙门：三乘的无学，已经离开有支；或者大菩萨，不借助其他的缘，对一切法知见没有障碍，摄受、利乐一切有情，都属于胜道沙门所摄，都只是胜义僧。
2. 示道沙门：胜义僧以及世俗僧中，有的也属于示道沙门所摄。如果有成就别解脱戒的真善异生，乃至具足世间正见，由于记说、变现的力量，能广泛为他人宣说开示各种圣道之法，称为最下品的示道沙门。预流果是第二，一来果是第三，不还果是第四，十地菩萨称为第五种示道沙门。
3. 命道沙门：如果有成就别解脱戒，轨则、所行清净具足，以道活命，所以称为命道。又，大菩萨为了利益有情，具足修行六波罗蜜，也称为命道。

这样胜道、示道、命道三种沙门，称为世间真实的福田。

（二）真实僧宝是否包括异生：两种说法

依那部经所说：真善的异生，持别解脱戒，具足正见，宣说圣道之法，称为示道沙门；前面的异生等具足戒的六支，称为命道沙门。这两种沙门，得称为世间真善的福田，所以真实三宝通于异生。

或者不是这样。圣道现前，断灭烦恼，内在的理上没有诤论，外在的事上和合，可以称为僧宝。即使不是沙门，安住于圣道的，因为在理上没有诤论，都称为僧宝，与各位沙门的种类相同。如果各种异生安住于戒、安住于见，也属于真实僧宝所摄，那么不是沙门而安住于戒、见的一类，也属于僧宝所摄了；在理和事两方面都不是和合，怎么称为僧？福田与僧宝，两种意义不同，所以不是异生是福田，也属于真实僧宝所摄。如果承认异生的两种沙门是真实僧宝，是因为事上和合，其余的类不是这样。

两种说法中，后一种说法较好。

六、住持三宝

（一）住持佛宝

世尊最后将要般涅槃的时候，在忉利天安居说法。优填王等思念仰慕佛的金容，雕刻旃檀为像，作为供养。佛从忉利天沿着宝阶下来，旃檀像起立礼拜迎接。世尊摩着像的头顶，授记佛像说："未来住持，广作佛事。"

所以《华严经》说十种佛，前五种世俗佛中有住持佛。又其余的经说："那些还没有得度的，也都已经作了得度的因缘。"就是舍利、遗形以及佛像，都属于住持佛宝所摄。

（二）住持法宝

佛灭度以后，法有三个时期，就是正法、像法、末法：

1. 具足教、行、证三者，称为正法。
2. 只有教、行，称为像法。
3. 有教而没有其余的，称为末法。

这教、行二者中有漏所摄的，以及贝叶文字，都是住持法宝，因为无漏的三法是真实法宝。

（三）住持僧宝

示道、命道两种沙门中，异生具足戒、具足见等一类，在正法、像法、末法时期能住持佛法的，是住持僧。

（四）污道沙门是否为住持僧

又《十轮经》说四种沙门中，第四种称为污道沙门，不是真实的，也得堕在福田之数中。

1. 无惭愧的僧，在我的正法中，也称为死尸，在清净的大众之海中，应当摈弃，因为不是圣器。我对那些人不称为大师，那些人对我也不是弟子。
2. 有无惭的僧，对我的舍利、我的形像，以及我的法、僧、圣所爱戒，深深生起敬信，自己没有邪见，也令他人没有邪见；能宣说正法，赞叹而不毁谤；常发正愿，随犯数数忏悔，业障都除。应当知道这个人信三宝、戒的力量，胜过各种外道多百千倍，转轮王也不及，何况其余的有情。所以劝有情这样说："在我的法中剃除须发的，我终究不允许毁辱、惩罚。"这些出家人，三世诸佛慈悲护念，所以轻毁这些出家人，就是毁谤诸佛。
3. 有无惭的僧，毁破禁戒，不是圣法之器，自己生起邪见，也令他人生起；诽毁三乘，不赞叹一乘。这样破戒、恶行的比丘，诳惑有情，令生起恶见，师长和弟子都断善根，当堕地狱。就像死尸膨胀烂臭，如果与之交游、共住、同事，臭秽熏染，失去圣法之财，师长和弟子都断善根，当堕地狱。

所以，如果没有前三种沙门，在污道沙门中，寻求破了戒而不坏正见的人，亲近承事，听闻法要；不应当亲近戒、见都已毁坏的恶行比丘。

观察前面经文的意思：第一种无惭者（第2条所说的），也得称为住持僧宝，以及上座等的僧像也是这样。

那部经第四卷说："如果有比丘对各种根本性重罪中，随犯一种，称为破戒、恶行的比丘，这样的比丘在亲教和合僧中所得的律仪仍然没有断绝，乃至还没有弃舍所学的尸罗，仍然有白法的香气随逐。各位国王等没有律仪，不应当轻慢以及加以惩罚。那人不是法器，杂秽清净的大众，因为不舍戒，所以仍然胜过一切在家白衣。犯性罪的尚且应当这样，何况犯其余各种小的遮罪。"

这段文就是第一种无惭僧：毁坏了戒而有正见，所以得以有戒。后一种无惭者（第3条所说的），善根既然断了，戒也随之没有，不属于住持僧所摄。住持僧令他人生起善根，法随之而有；那种人令善根灭失，法随之而灭，所以不属于住持僧所摄。

第二门　出体性

一、同体三宝

同体三宝，就是清净法界、真如法身。

《涅槃经》说："佛就是法，法就是僧，僧就是常，常就是虚空，虚空就是佛性，佛性就是法身。"

《说无垢称经·入不二法门品》中，寂静根菩萨说："佛、法、僧宝分别为二。如果了知佛性就是法性，法就是僧性，这样三宝都是无为相，与虚空相等，诸法也是这样。通达这个，称为悟入不二法门。"

二、别体三宝

1. 佛宝：以三身佛为自性，如《三身义林》所说。

2. 法宝：以三乘无漏所摄的教、理、行、果四法为体性。
   - 教：就是音声、名、句、文身，如《总料简章》所说。
   - 理：就是二谛、四谛等理，这有两种：一是根本智的境界，是诸法的实性，就是二空之理；二是后得智的境界，变现似那实性，就是十六行相的谛理等。
   - 行：就是三乘因位圣者所生起的自利利他诸行。
   - 果：就是三乘无学所得的两种转依果。

   《杂集论》序中，只说根本智的境界真如称为理法宝，略去后得智所变现的境界之理；只说大乘十地的因行，不说二乘因位所修的行；只说大乘的有为果法，不说其余的变化身等也属于果法所摄。法的体性是这样。

   如果分别说：因位所证的理，是理法宝；因位圣者所修的行，是行法宝；无学位中的两种转依果，是果法宝；所有的言教，是教法宝。差别的法体，称为法宝。

3. 佛宝、僧宝的体性：通于五聚法、能依的功德意义，以及假者，随其所应，称为佛宝、僧宝。五蕴假者以及法身的意义，是佛宝；只取假者，作为僧宝。这是三宝的差别。

（一）僧宝的范围

三乘的圣众，具足理和、事和，称为僧宝，因为具足无漏的戒、见等；能依的假者，才称为僧宝。

1. 十地菩萨既然都是圣位，大多同类一起出现。
2. 麟角喻独觉、天趣也是这样，因为独胜、部行是僧的种类。《报恩经》中，鹿女夫人的五百位太子出家修道，同一时间得辟支佛果，不从师受，称为独觉；有多人一同出现，称为部行。
3. 如上二界、六欲天等的第二果、第四果圣者，没有出家的形像，在事上不和合，因为在理上没有诤论，是僧的种类，都称为僧宝。

这不同于其他宗派，以有漏的身器作为无漏的所依，供养以及损害，所以生起罪福。

（二）唯取圣者

《瑜伽师地论》第六十四卷说：先受归依三乘，都取见道以上。声闻有五种证得：一地，二智，三净，四果，五功德的证得。地，就是见地、修地以及究竟地。独觉有三种，乃至大乘八种也是这样。只取圣者，不取凡夫。

《遗教经论》说："增长修行者，世及出世间，我等皆南牟。"（大意：增长修行的人，无论世间、出世间，我们都礼敬。）二乘圣者称为世间修行者。

三、一乘三宝

一乘三宝，是根本一乘所有的三宝。不定种性的人方便所修的法和僧，也属于一乘三宝的体性所摄。《法华经》说羊车、鹿车两种车是牛车的因，化城也是宝所的方便。

所以《胜鬘经》说："正法住、正法灭、波罗提木叉、毗尼、出家、受具足，这六处是为大乘而说。"前四种是法，后两种是僧，所以是一乘的方便，这两种宝也属于一乘所摄。这个意义详细如《诸乘义林》所说。

决定种性的法、僧二宝后来不归于大乘，由于法等平等，也称为一乘，如《摄大乘论》等十种意义中所说。

四、三乘三宝

1. 佛宝：三身佛宝，称为三乘的佛。教法的施设各有不同，不是宗旨所要说明的，不需要另外解释。自受用身、自性身等，是大乘的佛宝；变化身只是二乘的佛宝。初地以前的大众、十地菩萨也能见到变化身，变化身不是大乘的佛，因为那初地以前的大众不属于大乘僧宝所摄，为那些僧众所显现的，是那些僧众的佛。如果承认异生也属于僧宝所摄，就没有这个意义。

2. 法宝：根本大乘以及方便修习的教、理、行、果，是大乘的法宝。麟角喻独觉以及其余决定种性所修的四法，各随所应，是二乘的法宝。

3. 僧宝：随着这些所修的无漏四法，能修的假者，各自就是那三乘的僧宝。

五、真实三宝

真实三宝，就是前面所说同体、别体、一乘、三乘所有三宝的真实意义。只取圣位称为僧宝：理和以上，烦恼断灭，得道得果，可贵可珍，正当称为僧宝。四种沙门中，第一种胜道沙门全部是僧宝，示道、命道各取少分。圣者的种类属于僧宝所摄。异生中的示道、命道沙门，具足戒、见，能生起利益众生，是真实的福田，不属于僧宝所摄，因为没有圣道。福田的意义宽，宝的意义局限。

六、诸类三宝与四谛

1. 同体三宝，废诠谈实，不属于四谛所收；依诠显旨，属于灭谛所摄。
2. 别体、一乘、三乘、真实三宝，都通于灭谛、道谛。
3. 依下面的住持三宝，也属于苦谛、集谛所摄。

七、住持三宝

1. 住持佛宝：只以四处为体性，因为舍利以及佛像以色、香、味、触为自性。
2. 住持法宝：通以五蕴为体性。教是声处和法处；贝叶文字是四处；行是三业，或者以五蕴为体性。所以这法宝以五蕴、七处为自性，因为只是有漏。
3. 住持僧宝：上座等的僧像，以四处为体性。示道、命道两种沙门中的各种异生，以及第四种污道沙门中，毁坏了戒而有正见、不断善根、忏悔罪过的一类，五蕴假者，通以十二处为自性。

第三门　解释名字

一、通名

"三"是数目，就是佛、法、僧。这三种称为"宝"，合起来有六种意义。

《宝性论》问："以什么意义，佛、法、众僧称为宝？"偈说："真宝世希有，明净及势力，能庄严世间，最上不变等。"（大意：真正的宝在世间稀有，明净，有势力，能庄严世间，最为上妙，不会改变。）依那六种相似相对，佛、法、众僧称为宝：

1. 世间难得：没有善根的众生，百千万劫不能得到。这真实的宝，世间稀有。
2. 无垢：因为离开一切有漏诸行，极为明净。
3. 威德：具足六种神通，威德自在，有势力。
4. 庄严世间：因为能庄严出世间法，这也能庄严世间。
5. 胜妙：因为是出世间法，极为最上。
6. 不可改异：因为得到无漏，世间八法不能倾动，恒常不变。

就像世间的七种珍宝具有这六种相，三宝的体性也是这样，所以都称为宝。这是带数释。"相似相对"是譬喻的意义。

二、别名

（一）佛

梵语"馞陀"（buddha），讹略称为"佛"。

《涅槃经》说："佛名为觉，既自己觉悟，又能觉悟他人。譬如有人觉知有贼，贼就无能为力。菩萨能觉知无量的烦恼，既觉了以后，令各种烦恼无所能为，所以称为佛。"

《菩萨地》说："对三聚法平等开觉，所以称为佛。"

《佛地经论》说："具足两种智慧，能觉悟自己和他人。"有觉悟的人，总的有各别的智慧，依主释立名。

（二）法

梵语"达磨"（dharma），称为"法"。

《分广经》说："轨则称为法。"《成唯识论》说："法是轨持的意思，能任持自相，作为轨则令人生起理解。"《涅槃经》说："法名为不觉。"

（三）僧

梵语"僧伽"（saṃgha），称为"众"，因为在理上、在事上没有乖违诤论。这有三种：

1. 理和僧：三人以上才称为僧，麟角喻独觉以及其余的圣者，即使独自一人出现，因为是那一类的种类，也得称为僧。
2. 事和僧：三人以上都是僧的体性，从多数来论。那个国家的语法，一称为一，二称为双（原文作"身"，疑误），三以上都称为多。比如办理法事要四人才成就，一个人表白说"大德僧听"，所和合的三人得称为僧。如果四人是僧，难道能表白的人自己向自己表白吗？是为了显示和合从多人，所以三人以上都得称为僧。
3. 辨事僧：就是四人、五人、十人、二十人，能表白的、所表白的之中具足和合，办理法事，不是这样的和合体。

这法、僧的名称，都不作六合释，因为只是一个字的名称，没有简别。如果加上"宝"字，三种都是持业释。
