<p class="dt-title">不定心所与心所一异</p>

<div class="dt-subtitle">成唯识论白话译注（十九）　卷第七之上<br>护法等菩萨造　唐　玄奘译</div>

本篇要目：一、第十四颂后半与“不定”的含义　二、悔（恶作）　三、睡眠　四、悔与眠的体：四家　五、寻与伺　六、“二各二”的三家解释　七、不定心所的假实与相应　八、寻伺是否与五识俱起　九、不定心所与诸受、善、烦恼、随烦恼　十、不定心所的三性、三界、所断　十一、心所与心王是一还是异

一、第十四颂后半与“不定”的含义

前面已经说完二十种随烦恼的相状。外人质问：不定心所有四种，相状是怎样的？世亲菩萨用颂回答：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">不定谓悔眠　寻伺二各二</div>

大意：不定心所有悔、眠、寻、伺四种；“二各二”显示悔眠与寻伺两组各有染与不染两类。

论中解释：悔、眠、寻、伺，对善、染等都不一定，不像触等决定遍于一切心，也不像欲等决定遍于一切地，所以立“不定”的名称。

【译注】依前面的“四一切”来看：遍行四个一切都具；别境有一切性和一切地；不定心所只有一切性，即通于善、恶、无记三性，所以称为不定。

二、悔（恶作）

悔，就是恶作。对所造作的恶业追悔，是悔的自性；障碍止，是悔的作用。

“恶作”的名称，是在果上假立因的名称：先有所厌恶的作为，后来才追悔。

【译注】“恶作”本义是“厌恶所作”，即对自己做过的事起厌恶，厌恶是因；由厌恶而追悔，追悔是果。悔心所的体是追悔，借用了在前的“恶作”之名。

后悔先前没有做，也属于恶作。例如追悔说：“我先前没有做那件事，是我的过错。”

三、睡眠

眠，就是睡眠。令身体不自在，昧略，是睡眠的自性；障碍观，是睡眠的作用。

睡眠时，身体不自在，心极其昏暗微弱，只从意识一门运转。“昧”字用以简别在定中，因为定中的心是明了的；“略”字用以区别醒觉时，因为醒觉时的心是广博的。如此就显示睡眠并非没有体和作用。

无心的阶位，也假立“睡眠”的名称，如同其余的盖和缠，睡眠与心相应。

【译注】睡眠属于五盖之一、十缠之一，盖和缠都是与心相应的心所。熟睡无梦时，心已不起，那时说“睡眠”只是假名。

四、悔与眠的体：四家

关于悔与眠的体，论中列出四家。

第一家认为：悔与眠只以痴为体，因为论中说悔眠是随烦恼，又是痴的一分。

第二家认为：不对，因为悔眠也通于善。应当说，染污的悔眠以痴为体，清净的悔眠以无痴为体。论中是依染污的部分，说悔眠是随烦恼和痴的一分。

第三家认为：第二家的说法也不合道理，因为无记的悔眠，既不以痴为体，也不以无痴为体。应当说，恶作以思和慧为体，因为恶作明了地思择所作的业；睡眠合用思和想为体，因为睡眠中思和想构造种种梦境之相。论中都说悔眠是世俗有。染污的悔眠是痴的等流，如同不信等，说为痴的一分。

第四家，即护法论师，认为：第三家的说法在道理上也不对，因为思、慧、想不是缠的体性，悔眠属于缠。应当说，悔与眠各自另有体，因为与其余心所的行相不同。论中随着痴的相，说悔眠是世俗有。

五、寻与伺

寻，就是寻求。令心匆促，对意言境粗略地运转，是寻的自性。

伺，就是伺察。令心匆促，对意言境细致地运转，是伺的自性。

【译注】“意言境”是意识中以名言为媒介显现的境界。寻是在名言中粗略地寻找，伺是在名言中细致地审察。如同找东西，先四处翻看，再一样样细看。

寻与伺，都以作为身心安住与不安住的分位所依为作用。

寻与伺都以思和慧的一分为体，因为对意言境，不深入推度与深入推度，意义种类有别。离开思和慧，寻与伺两种的体性差别不可得。

六、“二各二”的三家解释

颂中“二各二”的含义，论中列出三家。

第一家认为：寻和伺各有染污与清净两类差别。

第二家认为：第一家的解释不合正理，因为悔眠也有染污与清净两类。应当说，如前面的一切染污心所，有的是烦恼性，有的是随烦恼性；寻伺二者各有不善和无记两类；或者各有缠和随眠两类。

第三家，即护法论师，认为：第二家的解释也不合道理，因为“二各二”放在不定四种之后。应当说，第一个“二”显示两种“二”：一是悔和眠，二是寻和伺。两组种类各别，所以用一个“二”字，显示两组二种。“各二”是说两组各有两类，即染污与不染污，不像善心所和染污心所，各自只有一类。或者，“各二”只是为了简别染污，因为有些地方也说悔眠寻伺是随烦恼。为了显示“不定”的含义，说“二各二”，所以颂中放置“二各二”三字，深有用意。

七、不定心所的假实与相应

四种不定心所中，寻和伺决定是假有，因为由思和慧合成，圣教如此说。

关于悔和眠，有两家主张。第一家认为：悔眠也是假有，因为《瑜伽师地论》说悔眠是世俗有。第二家认为：悔眠是实物有，因为论中只说后两种，即寻伺，是假有。“世俗有”的说法，是随着其他法的相而说，不是显示悔眠决定是假有。如同内种的体是实有，论中也说内种是世俗有。

四种之中，寻与伺决定不相应，因为寻与伺体类相同，只有粗细不同。

依寻伺的有无，以及对寻伺离染与否，立有寻有伺地、无寻唯伺地、无寻无伺地三地的区别；不依寻伺种子的现起与否，所以三地没有杂乱。

寻伺都可以与悔、眠两种互相相应，悔与眠之间也有互相相应的意义。

四种不定心所都不与第七、第八识俱起，理由如前所说。悔和眠只与第六识俱起，因为悔眠不是五识所有的法。

八、寻伺是否与五识俱起

关于寻伺是否与五识俱起，论中列出两家。

第一家认为：寻伺也与五识俱起。因为论中说五识有寻伺；又说寻伺就是七种分别，即有相分别等；《杂集论》又说任运分别就是五识。

第二家，即护法论师，认为：寻伺只与意识俱起。理由如下。

论中说寻求、伺察等法，都是意识不共的法。

论中又说寻伺与忧、喜相应，从未说与苦、乐俱起。舍受是普遍的，可以不必说。

外人质问：为什么不说寻伺与苦乐俱起？论主回答：初禅中有意地的乐，不离开喜，所以总说为喜；纯受苦之处有意地的苦，与忧相似，所以总说为忧。

论中又说寻伺以名身等所诠的义为所缘，五识不以名身等所诠的义为境。

论中说五识有寻伺，是显示五识多由寻伺引起，不是说五识与寻伺相应。

《杂集论》所说“任运分别就是五识”，与《瑜伽师地论》所说的“分别”意义各不相同：《杂集论》说的任运分别就是五识本身；《瑜伽师地论》说的是与五识俱起的分别意识所相应的寻伺。所以第一家的引证不能成立。

由此，五识决定没有寻伺。

九、不定心所与诸受、善、烦恼、随烦恼

关于诸受，有两家主张。

第一家认为：恶作与忧、舍相应，因为恶作只以忧戚的行相运转，也通于无记。睡眠与喜、忧、舍三受俱起，因为睡眠的行相通于欢喜、忧戚和中庸。寻伺与忧、喜、舍、乐相应，因为初禅中寻伺与意地的乐俱起。

第二家认为：四种不定心所也与苦受俱起，因为在纯受苦的恶趣中，与意地的苦俱起。

四种不定心所都可以与五种别境俱起，因为行相和所缘不相违背。

悔与眠只可以与十种善心所俱起，因为悔眠只在欲界，欲界没有轻安。寻伺可以与十一种善心所俱起，因为初禅中有轻安与寻伺俱起。

悔只可以与无明相应，因为悔的行相粗，贪等的行相细。睡眠和寻伺可以与十种根本烦恼俱起，因为睡眠寻伺与烦恼互不相违。

悔可以与中随烦恼和大随烦恼俱起，不与忿等十种小随烦恼俱起，因为忿等十种各自为主。睡眠和寻伺可以与二十种随烦恼俱起，因为在睡眠等阶位中，二十种随烦恼都会生起。

十、不定心所的三性、三界、所断

四种不定心所都通于善、不善、无记三性，因为对无记的事业也会追悔。

关于善性，有两家主张。第一家认为：悔和眠只是生得善，因为悔眠的行相粗鄙，又昏昧简略；寻伺也通于加行善，因为闻所成慧等阶位有寻伺。第二家认为：悔和眠也是加行善，因为闻、思的阶位中有悔和眠。

在无记中，后三种，即眠、寻、伺，都通于染污的有覆无记和清净的无覆无记。恶作不是有覆无记，因为恶作的理解粗猛，有覆无记的行相微细。

【译注】无覆无记有四类：异熟生、威仪、工巧、变化。下面依四类分别。

在四种无记中，悔只属于中间两种，即威仪和工巧，因为悔的行相粗猛，不是禅定的果。睡眠除去第四种变化，因为睡眠不是禅定所引生；异熟生的心也可以有睡眠。寻伺除去第一种异熟生，因为异熟生的心理解微弱，不能寻察名言等义。

恶作和睡眠只在欲界有；寻伺在欲界和初禅，因为其余的界地，法都微妙寂静。

生在上地，悔和眠必定不现起。寻伺在上下地之间，生在上地也可以起下地的寻伺，生在下地也可以起上地的寻伺。下地和上地的寻伺，都能缘取上地和下地。

关于悔眠能否缘取上地，有两家主张。第一家认为：悔眠不能缘取上地，因为行相粗近，又极其昏昧简略。第二家认为：悔眠也缘取上地的境，因为有邪见的人会后悔修习禅定，梦能普遍缘取所经历过的事。

悔不属于无学，因为无学已经离欲而舍弃了悔。睡眠和寻伺都通于有学、无学、非学非无学三种：寻求解脱的人，一切有为善法都称为有学；学已究竟的人，一切有为善法都称为无学。

悔与眠只通于见道所断和修道所断，因为悔眠也由邪见等的势力生起，不是无漏道直接引生，也不像忧那样深求解脱。如果因为已经断除而称为非所断，那么无学的睡眠就属于非所断。

寻伺不是真正的无漏道，能引生无漏道，又从无漏道引生，所以通于见道所断、修道所断和非所断。

关于寻伺属于非所断的情形，有两家主张。第一家认为：寻伺在五法中只属于分别，因为《瑜伽师地论》说寻伺是分别。第二家认为：寻伺也属于正智，因为经中说正思惟是无漏，正思惟能令心寻求等；又说寻伺是言说的因。未到究竟位时，对药与病等还不能普遍了知；后得智中为他人说法，必须借助寻伺，不像佛地那样无功用而说。所以寻伺也通于无漏。论中说寻伺必定是分别，没有决定说只属于五法中的第三种“分别”，因为后得的正智中也有分别。

【译注】五法是相、名、分别、正智、如如。第二家的意思是：菩萨后得智为人说法时，要寻思用什么名言、伺察对方根机，后得智中的寻伺属于正智，是无漏的。

其余诸门，依照上面所说，应依道理思考。

十一、心所与心王是一还是异

外人质问：以上六位的一切心所法，是离开心王的体另有自性，还是只是心王的分位差别？

论主反问：如果是其中一种，有什么过失？

外人回答：两种都有过失。

如果心所离开心王的体另有自性，圣教为什么说“唯有识”？又为什么说“心远行独行”“染净由心”“士夫由六界组成”？《大乘庄严经论》的说法又如何会通？如该论偈颂说：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">许心似二现　如是似贪等<br>或似于信等　无别染善法</div>

大意：承认心显现为能取所取二相；同样，心显现为似贪等，或显现为似信等，并没有另外的染法和善法。

【译注】“士夫六界”：经说一个人由地、水、火、风、空、识六界组成，只说识，不说心所，所以似乎心所就是心。

如果心所就是心王的分位差别，圣教为什么说心所与心相应？因为相应是不同体性之间的事，不是同一自性的事。又为什么说心王与心所同时生起，如同太阳与阳光？《瑜伽师地论》的说法又如何会通？该论说心所不就是心，如该论偈颂说：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">五种性不成　分位差过失<br>因缘无别故　与圣教相违</div>

大意：如果心所就是心，五蕴各别的体性就不能成立；心的分位有差别，就有过失；心王与心所的因缘就没有分别；也与圣教相违。

论主回答：应当说心所离开心王另有自性。因为心最殊胜，所以说“唯识”等。心所依于心，由心的势力而生，所以说心所显现得似心，并不是说心所就是心。“识”和“心”的名称也包括心所，因为心所恒常与心相应。所以说“唯识”等，以及说“显现似心”，都没有过失。

以上是依世俗谛而说。

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">若依胜义，心所与心非离非即。<br>诸识相望，应知亦然。<br>是谓大乘真俗妙理。</div>

大意：如果依胜义谛，心所与心既不相离，也不相即。诸识之间相互的关系，也应知是如此。就是大乘真谛与俗谛的妙理。

【译注】世俗谛中，心所与心王各有自体，才能谈相应、谈分工；胜义谛中，一切都是真如，心所与心王也就无所谓离与即。两层分开说，才不会落入“心所实有”或“只有一心”任何一边。

以上卷第七之上译毕。
