〔译注：本篇译《四食章》后三门：显相、废立、诸门。窥基依《瑜伽师地论》第五十七、六十六、九十四卷，说明四食怎样长养诸根和大种，为什么食只立四种，以及四食与三界、五趣、三性、因果的关系，最后会通《佛地经》一食、《法华经》二食、《阿含经》九食。〕

第三门　显相

一、四食怎样长养诸根大种

问：这四种食，怎样长养诸根和大种，成就食的相状？

答：所长养的，《瑜伽师地论》第五十七卷说，就是五色根以及意根，以及诸根所依的所有大种。

1. 段食：各种段食能摄益识，令识强盛，由此长养诸根大种，也令诸根大种强盛。
2. 触食：触能摄受喜、乐，或舍受的一部分，由此资益识，识又长养诸根、大种。
3. 意思食：意思为了证得殊胜的境界，依止方便，生起染污或不染污的希望，与喜根同时，缘未来的境界，摄益识，由此长养诸根、大种。

有人认为这段文就显示与喜同时的思称为思食，与乐、舍同时的思不是。这个意义不对。这是依据殊胜的缘境，暂且说与喜同时；与乐、舍同时的思也都是思食。不然的话，上界第三禅、第四禅以上就应当没有思食，便违背圣教。

这样三种食摄益识，是由于体性增盛，以及缘现在、未来而生。也缘过去，这个意义暂且依随顺的触和思来说，所以略而不论。

4. 识食：识由三种食所资持，能作为后后增盛的因，令后后得以生起，所以说识作为意根的食。

二、《瑜伽》第九十四卷：四种法

《瑜伽师地论》第九十四卷说：有四种法，在现法中最能长养诸根大种：

1. 气力。
2. 喜乐。
3. 对可爱的事物专注希望。
4. 前三种所依止的诸根、大种，以及寿命和暖气，安住不坏。

段食能给予气力作为食，由于气力，便能长养诸根、大种。"气"就是风大，"力"就是触处中的力触。由于段食，长养气力，长养诸根、大种等。

《瑜伽师地论》第五十七卷说，段食长养识，令识强盛，才长养诸根、大种，这是依据共通的所资来说；第九十四卷说资益气力，是依据各别的所资来说。下面三种食，第九十四卷说各别的资益也是这样；第五十七卷是说共通的资益，所以也不相违。《成唯识论》中，段食、识食两种依据共通和各别的资益来说，文义不相违；触食、思食只依据各别的所资来说，因为作用殊胜而显著，所以也不相违。

第九十四卷说："能随顺乐受的各种有漏触，能给予喜、乐作为食。"略去了顺益的舍受。由此便能长养诸根、大种。"如果能会合境界的思，能给予一切对可爱境的专注希望作为食。"这就是与定同时的欲，依据殊胜的来说；即使不是与定同时的希望，也是由于希望，便长养诸根、大种。

由于识能执受诸根、大种，令那些诸根、大种、寿命、暖气，以及识，不离开身体，作为住的因，所以说识是那些法安住的因。由于那些法安住，气力、喜乐、专注、希望才依之而运转。

第九十四卷第二个"复次"又说：由于段食，所以有气力；有气力，所以诸根大种增长。由此，各种顾恋身命的一切愚夫，为了这个意义而有所追求；追求的时候，造作种种新的善恶业，以及各种烦恼也令增长。触食、思食也是这样。由这三门，能积集后有的业、烦恼、识。这在现法中，由于业和烦恼所随逐，成为有取，又能摄受未来后有的诸根、大种等，令其再得增长。

由此，四种食各有共通、各别、现在、未来所长养的法。

三、段食何时称为食

这段食，能长养诸识，或者长养气力。《瑜伽师地论》第六十六卷说："如果正确消化变坏，便能长养；不正确消化变坏，就成为损减。"

1. 如果各种段物在吞咽的时候，令心欢悦，诸根愉悦，在那个时候不称为段食，只称为触食，因为是触的境界，触对殊胜的境界。不是以香、味、触三处就作为触食的体性，是以三处所生的欢悦之触作为触食。
2. 如果受用以后，安稳地消化变坏，增长喜乐，在消化变坏的时候，才称为段食。
3. 如果已经消化变坏，仍不能长养诸根的安乐，不称为段食。
4. 如果吞咽的时候不生欢喜，也不能令诸根愉悦，在那个时候，完全不称为食；要等后来安稳地消化变坏，增长喜乐，才称为食。

《瑜伽师地论》第五十七卷说："或者有段物，在受用的时候暂时成为损害，在变坏的时候才能摄益，如苦、辛等。或者有段物，在受用的时候暂时成为摄益，在变坏的时候才成为损害，如有甘美的食物不适宜。"所以在变坏的时候才立为食。论中只有两句，所以应当再加上最初和后来都损害的，如毒药等；最初和后来都利益的，如适宜的甘美饭食。四句中，第一句和第四句称为食，其余两句不是。

四、四食各作四句分别

由此应当作四句分别。《瑜伽师地论》第六十六卷说：

1. 或者有段物而不是食：就是各种段物不能长养诸根、大种。
2. 或者有是食而不是段物：就是触、思、识，能令诸根、大种长养。
3. 或者有是食也是段物：就是有段物能令诸根、大种长养。
4. 或者不是段物也不是食：就是触、思、识不能长养诸根、大种。

其余的触、思、识三种，随其所应，四句也是这样。为了令本义得以明白清净，都应当分别：

一、触：

1. 是触而不是食：就是随顺苦、忧以及一部分舍受的触。
2. 是食而不是触：就是段、思、识三种能长养诸根、大种的。
3. 是触也是食：就是触摄益喜、乐两种受以及一部分舍受，资益诸根、大种等。
4. 不是触也不是食：就是段、思、识三种不是食的。

二、思：

1. 是思而不是食：就是缘过去以及现在、未来世，不能摄益诸根、大种的。
2. 是食而不是思：就是其余三种食。
3. 是思也是食：就是与欲同时缘未来世、资益诸根大种的思。
4. 第四句：就是其余三种不是食的。

三、识：

1. 是识而不是食：就是不被三种食所资养、不能长养诸根大种的识。
2. 是食而不是识：就是其余三种食。
3. 第三句：被前三种食所资养、能资益诸根大种的识。
4. 第四句：就是前三种不是食的。

由此，四种食各有四句。所以《杂集论》第五卷说："由于变坏，所以有变坏的；由于有境界，所以有境界的；由于有希望，所以有希望的；由于有取，所以有取的。""取"是取境界，或者是有取，是有漏的异名。因为每一种中都有是与不是，所以得以成就这个意义。这样总的称为成就食的相状。

第四门　废立

一、为什么只立四食

有四种法，在现法中最能长养诸根、大种：

1. 气力。
2. 喜乐。
3. 对可爱境界的专注希望。
4. 就是前三种所依止的诸根、大种，以及寿命和暖气，安住不坏。

依次应当知道，各别以四种法作为食：一段食，二触食，三思食，四识食。由于各别所资养、长养诸根大种的法只有四种，所以食只立四种，不减也不增，其余的法对这四种没有殊胜的能力。

又由于追求三种食等，生起业和烦恼，生起后有的识，所以只立四种，其余的法不是这样。

又《瑜伽师地论》第五十七卷说："为什么建立这四种作为食？因为是多数。"第六十六卷说："四种是诸行安住的多数因缘，有情大多以这四种为资养。"所以不增不减。

又因为容易觉知。这四种的相状明显，容易了知。第六十六卷说，婴儿等类也能知道。

又因为每日每日容易资养。这四种每日都容易资养身体，其余的法不能数数资养。

又因为在念住中容易趣入。第六十六卷说，令人容易入道，能修习身等四种念住，因为一切有情都依食而住：

1. 由于段食，能修习身念住。
2. 由于触食，能修习受念住。
3. 由于识食，能修习心念住。
4. 由于思食，能修习法念住，因为思是诸行法之主。

食作为这四念住的因，所以容易入道。食只有四种。

二、七种因缘与四食

又《瑜伽师地论》第六十六卷说："有七种因缘，住持诸行，令其安住不坏。为什么世尊只说四食？"哪七种？

1. 生：因为没有不生而能安住的。
2. 命根。
3. 食。
4. 心自在通。
5. 因缘和合：由于因缘还没有穷尽，善等法得以安住。
6. 作意：由于发起先前的业，能牵引诸行，令其不断绝。
7. 无障碍：就是远离了违逆败坏的法。

该论自己回答说：这有五种原因：

1. 容易了知。
2. 能令羸瘦的诸根大种得到增益。
3. 又令疾病得以除愈。
4. 又能长寿。各种有情类如果得不到食，会非时中夭。
5. 令容易入道，修习四念住等。

所以只说四种，不增不减。

问：为什么又说依止命根，诸行得以安住？

答：在某些地方，从来不曾有饮食的缺乏，也不是求取饮食有所艰难，在那些地方，只由命根的势力而安住，如其所感的寿量而安住。佛依那些地方，说由命根而住。

问：如果这样，为什么不说命根为食？

答：《瑜伽师地论》第五十七卷说："如果离开食，命根终究不能长养身体。"识也是这样，要三种食资养，才能安住。

问：这也不对。生在无色界、进入灭尽定等，识自己执持身体，难道是由于三种食的力量？

答：说由三种食，是通于一切来论，不是每一种情况都这样。或者识由三种食执持命根等的作用殊胜，寿命的体性不是这样，所以不能作为比例。

三、睡眠、梵行、等至为什么不立为食

《瑜伽师地论》第五十七卷又说："为什么睡眠、梦、梵行、等至，都能长养诸根、大种，而不立为食？"答：有两种长养：一是摄受别义的长养，二是令无损害的长养。睡眠、梦等三种，对于后一种长养能作长养，对于前一种就不是，所以不立为食。

摄受别义，就是第九十四卷所说的长养的现缘，就是气力等。四种食对气力等能各别摄受，总的能资益识；其余的法不是这样，不应当作为食。

问：如果这样，为什么触、思、识三种不是长养？如果只有不损害称为长养，怎么会有处所宽遍的长养？

〔存疑：此问原文「若尔何故触思识三非长养耶。若唯不损名为长养，如何得有处宽遍耶」，未见答语，文意或有脱落。〕

以上总的是总废立。

四、诸根与色、声为什么不是食

问：为什么五根以及色、声两种，不属于食所摄？五根也能资益五识身，令其成为明或暗；观色、听声，也能长养。

答：如果能资益四种法，可以立为食；五根没有这种作用。五根由识所资养长养，识能资养殊胜，不是根资养识，所以不说五根为食。因为段食的作用在变坏的时候增长，对色、声不是这样。

《瑜伽师地论》第五十七卷以及《成唯识论》说："色在变坏的时候没有损益。"对自己的根既然没有损益，对其他的根也没有，所以不立为食。又，色粗而显著，声的体性虚疏，离开根而有作用，也不能资益气力令其强胜，所以不立为食。

五、胜定果色是否为食

胜定果色具足五处，本身完全不是食。只是由于圣者的力量，香、味、触三处可以成为食，就像香积佛国的饭可以作为食。

有一种说法认为不是这样：那是实在的三处，不是法处。有圣者以禅定神通力变现，令其资益的，是三识所得，不是法处。

这也不对。难道要三识所得才称为食？只要后来变坏的时候能资益气力，令识明盛，不一定要识所得。所以胜定果色中的三处称为食，因为本识所得，能资养。假立的法处色不是食的意义也成立，因为没有体性和作用，就像不相应行法。

六、受、想及其余心所为什么不是食

问：为什么受、想不称为食？

答：受由触资养，才资益识，就像气力一样，所以不立为食。想的作用微弱暗昧，对四种法没有能力，不如触、思，所以也不立为食。众生也由于爱而追求四食，爱不是亲近资长的，业等也是这样，所以不说为食。

其余的心所法都不及触、思：触遍于诸心，随顺生起三受；思能希望，是造作之主。所以其余的都不是食。

无漏法和无为法都破坏三有，所以只有有漏的四种才立为食的名称。

第五门　诸门

分五部分：一是三界，二是五趣，三是三性所摄，四是因果的差别，五是问答。

一、三界

《显扬圣教论》第一卷、《瑜伽师地论》第五卷、《成唯识论》等都说：由于触、思、识三种食，一切三界的有情得以安住；段食一种，只令欲界的有情安住。因为欲界有睡眠以及淫欲，必定需要段食资养；其余的界不是这样。这是依散位的境界来说；定位的境界通于三界，到下面应当了知。

二、五趣

《瑜伽师地论》第六十六卷说："粗的段食，在欲界五趣中都现前可得。这是指一部分孤独地狱，不是大地狱。其余的食，在三界中都现前可得。"

《瑜伽师地论》第五卷说："在地狱受生的有情，有微细的段食，就是腑脏之间的风，由于这个因缘，地狱众生得以久住。鬼、傍生、人、天有粗的段食。"就是作成分段而食啖，说为粗；地狱的风不是这样，所以称为细。"又有微细的食，就是住在羯逻蓝等阶位的有情，以及欲界诸天。这些有情食用以后，所有的段食流入一切身体的部分和肢节，随即消化，没有大小便秽。"

《瑜伽师地论》第五十七卷说："地狱中没有段食，定地诸天也是这样。诸地狱有广大的损害诸根大种的因缘，地狱众生仍不能死去。"该卷后文自己会通说："那里也有各种微细的风，随着进入身体各部分，以之为食，难以了知，所以不说。"所以不相违，就显示四食遍于五趣。

三、三性所摄

1. 段食只是无记，因为散位的香、味、触三境体性决定，能造、所造的本性决定。法处中的三境如果作为食，因为是自己的识所变现，也是第八识的境界，所以也是无记。如果依意识的境界，远远资长，色界、无色界所系的有漏法，属于善性所摄。如果是无漏的，亲近来说不资益三有，究竟来说是损害，因为破裂三有；近来说可以作为食。这个意义稍难了知，应当思惟审察。
2. 触、思、识，通于三性都有。如果取殊胜的识食，只是无记性，因为就是第八识。触、思、识通于定位、散位，定位中的思、触、识都能摄益。

四、因果的差别

《杂集论》第五卷说，有四种差别：

1. 不净依止住食：就是欲界的异生，因为具足系缚。世亲《摄大乘论释》第十卷只说"具缚"，《杂集论》较殊胜，因为依有现行和种子称为具缚。
2. 净不净依止住食：就是有学，以及色界、无色界的异生，因为有余下的系缚。《摄大乘论》说"有学"，与《杂集论》相同；在异生中说"如果生在色界、无色界"，这个意义就狭窄了，因为只说明三种食，没有说段食；在下地已经离欲的人，摄不尽。
3. 清净依止住食：就是阿罗汉，因为解脱一切系缚。《摄大乘论》的文字相同。
4. 示现依止住食：就是诸佛以及已经证得大威德的菩萨，因为只是示现以食力而住。所以《摄大乘论》说："就是佛世尊示现受用段食等四种食。如来进食的时候，实际上不接受食物，也不借助食物、因食物而生存，只是随顺世间，示现受食，示现借助食物，身体安住。"

《杂集论》不约第四识食来说明示现，所以取菩萨。《摄大乘论》依四种食都是示现，所以只说佛。《成唯识论》也依《摄大乘论》所说。各自所望不同，不相违。

五、问答

问一：如果三种食通于三界的散位，段食只在欲界，也有上界资益下界的段食以及其余三种食吗？

答：有。二禅以上生起初禅的四识，难道不是资益下界的三种食？又，段食的示现可以这样，就是大威德菩萨等，实际上不资益下界。

问二：下界资益上界吗？

答：有。由于依上地的定，生起触，触对境界，思惟妙理。又有一种解释说：这不是下界的食，只是长养，不然的话，定心也应当称为食，因为不是各别的摄益。这个意义不对，定不损害，触等摄受别义，所望的不同。

问三：这四种食只是种子，还是也通于现行？

答：前三种只是现行，识食通于种子。《瑜伽师地论》第九十四卷说："由于段食等的力量，所以有气力等，诸根大种都得到增益。由于这个因缘，各种顾恋身命的愚夫为了这个意义而有所追求，追求的时候造作新业，以及增长烦恼。由这段、触、思三门，能积集后有的业、烦恼、识。这在现法中，由于业和烦恼所随逐，成为有取，便能摄受未来的后有。"这个意思就显示：由前三种食积集种子识，后有增长。所以可知前三种都只是现行，那些种子就是后有的因，作为种子识。这通于现在、未来二世；未来的只在凡夫，不在圣者，因为依总报的果业，不是圣者。

问四：一切有情在每一念的时候，随所在之处，都决定有四种食吗？

答：不决定。识食决定有，其余的或有或无。

问五：如果承认五趣都有段食、触食等，那些食必定生乐。极苦的地狱趣中，《摄大乘论》说有乐，那必定是乐吗？

答：生起的是顺益的舍受，不是喜受、乐受。又《成唯识论》说："其余地方所说地狱有乐的，是随转理门，不是大乘的义理。"这个意义是正说，只生起顺益的舍受，必定不是喜受、乐受。

问六：如果三种食通于三性，不善怎么能长养？

答：就像行恶行，触对五妙欲，也能资长。后世受损，现在仍能资养。

问七：因果差别中，随所应有四种、三种食的地方，都能得四种不净食等吗？

答：欲界具足四种；色界有三种，除去不净食，没有第四种示现依止的少分，因为没有佛。无色界完全没有第四种以及第一种。

问八：三界中哪一界的食粗？

答：

1. 段食：《瑜伽师地论》第九十四卷说："欲界天、中有、母胎、卵壳中的都细，其余阶位称为粗。"第五十七卷只说天是细，其余的称为粗，是依据多数来说；或者是五趣相互比较为粗细，第九十四卷是在自趣中相互比较。又，完全消化、不消化为粗细，其余的不是这样。

〔译注：原文"卵?"缺一字，依义当作"卵壳"。〕

2. 其余三种食：第五十七卷说："在欲界，三种食为粗；在色界、无色界，三种食为细。"第九十四卷说："三种食在无色界称为细，其余地方称为粗。"因为以有色为所依，容易分别；以无色为所依，难以分别。这个意思就显示以有色的所依为粗，无色的所依为细。第五十七卷以定地法的行相难知称为细，散地的行相易知称为粗。各依一种意义，也不相违。

3. 第九十四卷说："还有另外的意义：一切四种食，能令已生的有情安住，称为粗；能令求生的有情安住，称为细。"因为本有、中有有粗细的差别。

这一切都应当依此推知，不是要紧的胜义，所以不具述。

六、食者只是假立

《瑜伽师地论》第九十四卷说："没有少许法生起以后安住，也没有我能食所食。只是约给未生诸法作生缘的道理，只是法引生法，说为食的意义。只是由于法，假立在识上，假想施设补特伽罗，对望这四种食说为食者，是随顺世间、约世俗谛有能食者，不是约胜义。如果说有识生起以后安住，体性是真实的补特伽罗称为食者，就不应当立识作为食的体性，因为从来没有见过补特伽罗还自己能食补特伽罗……"乃至广说。所以可知食者只是假立施设。

七、四食的观法

又，三种食作为因，能生起三种苦：

1. 界不平等苦
2. 欲希求苦
3. 求不充苦

因为由段、触、思三种作为因。所以：

1. 观段食如子肉想，不应当贪着。
2. 观顺乐的触，如无皮的牛，被各种虫啃食，多生众苦。
3. 观意会思，如一团大火。

作这样的观想以后，不要被三种苦所苦恼，坦然而住。

三种食作为缘，生起识的内苦，所以观识食如被三百支矛所攒刺……乃至广说。如果不审慎观察这些，便被喜、贪所染污。如果被这两种染污，就生起两种过失：一是未来的，二是现法的……乃至广如第九十四卷所说。

八、会通无漏法食与诸经的食数

问：如果无漏法破裂三有，所以说不是食，为什么《佛地经》说"由广大的法味喜乐所任持"，称为食？

答：《佛地经论》第一卷说："食能长养三有众生，这种无漏法断除三有，应当不称为食；只是因为是住持的因，所以也称为食。"就像有漏法障碍无漏，同时执持有漏，得称为食；无漏也是这样，断除有漏，同时执持无漏，怎么不是食？就是佛菩萨后得的无漏智，能说、能受大乘的法味，生起大喜乐；又根本正智受用真如之味，生起大喜乐，能任持身体令不断坏，长养善法，所以称为食。不是作为有情的食。只有大悲心、神通变现的境界资养有情，近来说也称为食，所以不相违。

问：为什么有漏法中以触为食的体性，无漏法中以喜、乐为食？

答：由于有漏的触引生喜、乐殊胜；无漏的喜、乐对治忧、苦殊胜，各自立为食，因为对治不同。又，无漏的受领受法味增长，说为食；也像有漏的触生起喜乐增长，立为食的名称，所以不违背道理，各自随其增上。

问：《佛地经》说一种食，就是"广大法味喜乐所持"；《法华经》说两种食，一是法喜，二是禅悦；处处说四种，就是段、触、思、识；《摄大乘论》说四种，就是不净依止等；《阿含经》说九种，四种是世间食，五种是出世间食。世间食就是段、触等；出世间食是：一禅食，二愿食，三念食，四八解脱食，五喜食。这些怎样会通？

答：

1. 《佛地经》《法华经》只说无漏资养无漏的食，不说有漏。
2. 《佛地经》中只说因为听闻正法而有的食，不说禅悦。
3. 《法华经》通说依定、慧所资养，所以说两种食，因为在福德、智慧两品中，这两种殊胜。念、愿、解脱不是增上殊胜，所以略而不说。
4. 处处说四种，是世间食。
5. 不净依止等四种，是依人的差别。
6. 说九种食，是有漏、无漏合起来说。无漏法资养、破除有漏的食，具足五种。所以《阿含经》说："常共专念，除舍四种世间之食，求取五种出世间食。"

有漏法中，段食等殊胜；无漏法中，禅定等殊胜。各依殊胜而立，也不相违。

（《四食章》终）
