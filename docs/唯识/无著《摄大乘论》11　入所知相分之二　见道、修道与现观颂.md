<div class="dt-subtitle">摄大乘论白话译注　第十一篇　入所知相分之二<br>无著菩萨造　唐　玄奘译　附世亲释、无性释</div>

一、为什么入唯识性

又，为什么要入唯识性？由于缘总法的出世止观智，由于从出世止观智之后所得的、了知种种相识的智慧，为了断除阿赖耶识中诸相的种子及其因，为了增长能触证法身的种子，为了转变所依，为了证得一切佛法，为了证得一切智智，所以入唯识性。

又，后得智对阿赖耶识所生的一切了别之相，见其如幻等，无颠倒而转。所以菩萨如同幻师，对所幻之事，对一切相，以及宣说因果时，常无颠倒。

【世亲释】阿赖耶识中诸杂染法的种子，称为阿赖耶识诸相的种子；“及相”的“相”是因的意思，表示种子与种子所缘之相，因果都断。无分别智能断一切障、证得佛法，还需要后得智做什么？无分别智没有分别，不能宣说种种因果法，所以需要后得智，宣说一切因果法常无颠倒，如同幻师对所幻之事。

二、四种三摩地与四种顺抉择分

在悟入唯识性的时候，有四种三摩地，是四种顺抉择分的依止。应当如何了知？应当了知：由四种寻思，在下品的无义忍中，有明得三摩地，是暖顺抉择分的依止。在上品的无义忍中，有明增三摩地，是顶顺抉择分的依止。又由四种如实遍智，已经入唯识，对无义已经得到决定，有入真义一分三摩地，是谛顺忍的依止。从此无间，伏除唯识之想，有无间三摩地，是世第一法的依止。应当了知，上面诸三摩地是现观的边际。

【世亲释】“明得”的“明”，指下品的无义智；“三摩地”，指无义智所依止的定。“明增”的“明”，指上品的无义智。“谛顺忍”：法无我的道理称为谛，随顺法无我之理的忍，称为谛顺忍；对外境之无已经决定的人，对能取之无也深生爱乐。“现观边”，是临近现观的意思。

【译注】顺抉择分，就是暖、顶、忍、世第一法四善根，随顺见道的抉择智，所以称为顺抉择分。

三、修道中如何修行

像上面所说，菩萨已经入地，已经得见道，已经入唯识，在修道中如何修行？在如前所说安立的十地中，摄一切经的教法都现前，由缘总法的出世后得止观智，经过无量百千俱胝那庾多劫，反复修习，因而得到转依。为了证得三种佛身，精勤修行。

【世亲释】“缘总法”，是缘一切法的总相，不是分别地缘。“出世”，是无分别智；“后得”，是能成立的智。后得智不能说只是世间，因为在世间中没有串习过；也不能说只是出世间，因为随世间而现前，所以不可决定而说。

四、菩萨现观与声闻现观的十一种差别

声闻的现观与菩萨的现观有什么差别？菩萨的现观不同于声闻，应当了知有十一种差别。第一，由所缘的差别，因为以大乘法为所缘。第二，由资持的差别，因为以广大的福德、智慧两种资粮为资持。第三，由通达的差别，因为能通达补特伽罗无我与法无我。第四，由涅槃的差别，因为摄受无住的大涅槃。第五，由地的差别，因为依十地而出离。第六、第七，由清净的差别，因为断除烦恼的习气，清净佛土。第八，由对自他得平等心的差别，因为成熟有情的加行没有休息。第九，由生的差别，因为生在如来家。第十，由受生的差别，因为常在诸佛的大集会中摄受生。第十一，由果的差别，因为十力、四无畏、不共佛法等无量功德果都成满。

五、入真观的二颂

关于上面的悟入，有二颂：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">名事互为客<br>其性应寻思<br>于二亦当推<br>唯量及唯假<br>实智观无义<br>唯有分别三<br>彼无故此无<br>是即入三性</div>

大意：名对于事是客，事对于名是客，名与事的自性应当寻思。对名与事两者的自性和差别，也应当推求，唯是识量，唯是假立。以如实智观察，没有义，唯有三种分别。所分别的义无，所以能分别的分别也无。如此就是悟入三性。

【世亲释】“名事互为客”，因为名与事不与对方的体相称，所以互相为客。以定心观察，称为寻思。“于二亦当推”，应当推求义的自性与差别都没有，唯有识量，唯有自性与差别的假立。“实智”，就是如实遍智，由四种寻思为因，生起四种如实遍智。“唯有分别三”，是唯有名分别、自性分别、差别分别三种虚妄分别。“彼无故此无”：所分别的义无，所以能分别的分别也无；有所分别的义，才能有能缘的分别。见名与事互为客，就是悟入遍计所执性；见名与事本来没有义，唯有分别的量，唯有名、自性、差别的假立，就是悟入依他起性；连分别也不见，就是悟入圆成实性。

六、教授二颂

又有教授二颂，如《分别瑜伽论》所说：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">菩萨于定位<br>观影唯是心<br>义相既灭除<br>审观唯自想<br>如是住内心<br>知所取非有<br>次能取亦无<br>后触无所得</div>

大意：菩萨在定位中，观察所现的影像唯是心。义相灭除以后，审细观察唯是自心的想。如此安住于内心，了知所取不是有；其次了知能取也没有；最后触证无所得。

【世亲释】“观影唯是心”，是观察似法似义的影像唯是自心。“义相既灭除，审观唯自想”，是在定位中遣除义想之后，审观似法似义之想唯是自心。“如是住内心”，是摄心安住于无义。“次能取亦无”，所取义既然没有，能取心的能取之性也不能成立。“后触无所得”，是从此之后触证真如，真如无所得，所以称为无所得。

七、五现观颂

又有另外五首现观伽陀，如《大乘经庄严论》所说：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">福德智慧二资粮<br>菩萨善备无边际<br>于法思量善决已<br>故了义趣唯言类<br>若知诸义唯是言<br>即住似彼唯心理<br>便能现证真法界<br>是故二相悉蠲除<br>体知离心无别物<br>由此即会心非有<br>智者了达二皆无<br>等住二无真法界<br>慧者无分别智力<br>周遍平等常顺行<br>灭依榛梗过失聚<br>如大良药消众毒<br>佛说妙法善成立<br>安慧并根法界中<br>了知念趣唯分别<br>勇猛疾归德海岸</div>

大意：菩萨善于具备福德与智慧二种资粮，没有边际；在定后思量诸法，善得决定，所以了知诸义都以意言为因。了知诸义唯是意言，就安住于似义唯心的正理，便能现证真实法界，所取与能取二相都得蠲除。体知离心没有别的所缘物，由此就领会心也非有；智者了达所取与能取都无，平等安住于远离二者的真实法界。有智慧的菩萨以无分别智的力量，周遍平等地常常随顺而行，灭除所依中如丛林荆棘般难入的过失聚，如同大良药消除众毒。依佛所说善成立的妙法，菩萨将智慧安置在法界与根本心中，了知忆念的义趣唯是分别，勇猛疾速地归向功德大海的彼岸。

【世亲释】五颂的总义是：第一颂显示资粮道，第二颂的前半显示加行道，第二颂的后半与第三颂显示见道，第四颂显示修道，第五颂显示究竟道。

【世亲释】资粮有二种：布施、持戒、忍辱三种波罗蜜多是福德资粮，般若波罗蜜多是智慧资粮；精进为智慧而修属智慧资粮，为福德而修属福德资粮；静虑缘四无量而修属福德资粮，其余属智慧资粮。“无边际”，是长远难度，因为很多，所以称为无边，并不是真的没有边。“于法思量善决已”，要在定后思惟诸法，才能善得决定。“灭依榛梗过失聚”，“依”是所依，所依中的杂染法种子极难了知，如同溪谷丛林荆棘难以进入。“安慧并根法界中”，是依佛的教法，把智慧安置在真如中，以及缘真如的根本心中；根本心就是缘如来一切正教总为一相的无分别心。“了知念趣唯分别”，是安住根本心之后，以后得智忆念诸义趣，了知唯是分别。
