<div class="dt-subtitle">大乘法苑义林章白话译注（四十四）<br>唐　窥基　撰</div>

〔译注：《三慧义林》是全书第二十六章，讨论闻所成慧、思所成慧、修所成慧。原文约八千六百字，分三篇。本篇译前五门：出体、释名、所缘、废立、位地。重点在第三门：萨婆多部认为闻慧唯缘名、思慧缘名义、修慧唯缘义，窥基依《解深密经》认为三慧都缘名与义，区别在于"以文为先""以义为先""文义俱证"。〕

三慧的意义，简略用十门分别：

1. 出体
2. 释名
3. 所缘
4. 废立
5. 位地
6. 与诸智相摄
7. 法行的差别
8. 与陀罗尼对照说明同异
9. 地证的不同
10. 诸门分别

第一门　出体

这三种慧的自性，属于别境中的慧所摄，因为称为三慧。通于现行和种子。《显扬圣教论》第十七卷说十八种现观，就是闻所成智、思所成智、修所成智，因为说是智。

一、三慧与五识

有人说：这三种慧只是与意识，或者与第七、第八识相应的慧性，不与五识同时。理由是：

1. 五识不能缘教法和道理。
2. 《成唯识论》第六卷说："十一种善心所中，五识只有十种，因为五识的自性散动，没有轻安。"
3. 说佛身中没有五识。
4. 眼等不能听闻佛法。
5. 五识中的善只是生得善，因为不明了。

有人认为五识也有闻慧、修慧：

1. 《成唯识论》中有人说："五识有轻安，因为定所引生的善也有调畅。"成所作智同时必定有轻安，所以五识决定有修慧。
2. 为什么五识本身没有分别，由第六识的分别引生，就有分别的烦恼；由闻慧的意识引生，就没有闻慧？五识不另外缘名或义，与名同时的声，体性就是教法，耳识既然缘那声，怎么不是闻慧？
3. 思慧深入地缘名所诠的意义，五识可以没有；闻慧粗略地缘教法，五识应当有。由闻慧的意识引生五识的善，因为闻所成，是闻慧的伴类，也属于闻慧所摄。
4. 如果能引生的意识是闻慧的加行善，所引生的五识是生得善，也应当能引生的第六意识是分别的烦恼，所引生的五识只是俱生的烦恼。如果这样，五识的烦恼就不应当通于见道所断，便违背圣教。
5. 如果亲自听闻声音才称为闻，意识的慧就应当不是闻慧；如果因为听闻声音、由此而成，五识也应当有闻慧。

二、窥基的抉择

《瑜伽师地论》第十三卷闻所成地说："对于五明处的名、句、文身，以觉慧为先，听闻、领受、读诵、忆念，称为闻所成地。"

那部论的意思是说："以觉慧为先"，是生得慧，因为最初暗昧低劣；后来的听闻等，都是闻慧，因为能明了。所以与耳识同时的明了意识，也是闻慧；不明了的，属于生得慧所摄。

由此：

1. 闻慧只取与意识相应的慧性；所引生的伴类，也通于与五识相应的慧性。第七识不缘外境，第八识在佛果才生起，所以没有闻慧。
2. 思慧只取与意识同时的慧。五识不是思慧的助伴，因为五识的行相浅。也不与第七识同时，因为在无漏位行相深。佛没有思慧，也不与第八识同时。
3. 修慧决定通于与八识同时都有。

说"那所成的慧"，体性如前面所说。只说"所成"而不说"慧"，就通于四蕴或五蕴为体性。

第二门　释名

先列名，后解释。

一、列名

1. 闻所成慧
2. 思所成慧
3. 修所成慧

二、解释

（一）通名

"慧"是简择的意思。"三"是数目，是带数释。

（二）别名

1. 闻所成慧："闻"是能听，就是耳识能听闻声音。"成"是生长圆满的意思。慧的体性如前面所说。以闻为因，"因闻所成的慧"，称为闻所成慧，是依士释。
2. 思所成慧："思"是思心所，由思筹度，殊胜的慧才生起。"因相应的思所成的慧"，称为思所成慧，是邻近释；或者"因思所成的慧"，是依主释。
3. 修所成慧："修"是证的意思，因为明证境界，体性就是定心所。"因定相应所成的慧"，是邻近释；或者"因定所成的慧"，也是依士释。

如果只说闻慧、思慧、修慧，就混滥为持业释，没有邻近释等。说"那所成的"，就没有这个过失。

第三门　所缘

一、萨婆多部的说法

《俱舍论》第二十二卷，毗婆沙师说：

1. 闻所成慧只缘名的境界，因为还不能舍弃文字而观察意义。
2. 思所成慧缘名和义的境界，有时由文字引出意义，有时由意义引出文字，因为还没有完全舍弃文字而观察意义。
3. 修所成慧只缘义的境界，因为已经能舍弃文字，只观察意义。

《大毗婆沙论》第四十二卷说："闻所成慧在一切时依名了解意义，忆念三藏的教法以及师友的教导有什么意义，随其所念都能解了。"到了成就位，实际上只缘义，现在依据最初的阶位，说只缘名。

《大毗婆沙论》又说："修所成慧在一切时不依于名而了解意义。譬如有人浮渡深而急的水：从来没有学过的，不舍弃所依的浮具；曾经学而还没有学成的，或者舍弃，或者执持；已经善于学习的，不需要所依，凭自己的力量浮渡。应当知道三慧依次也是这样。"

有人说：如果这样，思慧就不能成立，因为这既然通于缘名缘义，依次应当是闻所成慧、修所成慧。

现在详细审察三种相，没有超过的分别：诸修行者，依听闻至教所生的殊胜智慧，称为闻所成；依思惟正理所生的殊胜智慧，称为思所成；依修习等持所生的殊胜智慧，称为修所成。说"所成"这个词，显示三种殊胜的智慧，是由闻、思等三种因所成就。就像世间对于命、牛等，依次说是食物、草所成。

现在观察那个意思，天亲菩萨正取闻慧只缘教法、思慧只缘意义，修慧也是这样。只是《大毗婆沙论》在诸门分别中只有一种说法：这三种慧都缘名和义，与此相违。

二、大乘的说法

现在依大乘：

（一）闻慧

闻慧通缘名和义。《瑜伽师地论》第十三卷说："什么是闻所成地？简略来说，对于五明处的名身、句身、文身无量的差别，以觉慧为先，听闻、领受、读诵、忆念；又对依止名身、句身、文身的意义，无颠倒地了解，这称为闻所成地。"这里前一段文说缘名，后一段文说缘义。

该论第十一卷说："缘法作意，就是与闻所成慧相应的作意。"不说缘义，是因为缘教法的多，还不能舍弃文字而观察意义，以教法为先，然后才取意义，所以只说缘法。依实际道理，通缘名和义。

（二）思慧：有一种说法认为只缘义

思所成慧，有一种说法认为只缘义。《瑜伽师地论》第十六卷说思慧的自性："凡所思惟，只依于义，不依于文。"那里也说思择诸法，思惟素怛缆以及伽他，思惟的是其中的意义，不是那些文字。

《瑜伽师地论》第十一卷又说："缘义作意，就是思所成慧。"该卷又说："与修所成慧相应的作意，也只缘义，不缘文字。"

十地等中的各种后得智，有缘教法的，那是闻慧，也不是修慧。《十地经论》说："八地以上，对一切法能堪受、能思惟、能受持。"依次就是闻慧、思慧、修慧。八地以后，定心相续，向外缘教法，既然说为闻慧，所以可知思慧、修慧只缘义，筹虑和证解两种意义有差别。

在佛身中说没有闻慧、思慧，只有修慧，通缘名和义。如果听闻他人的教法不是修慧，那体性是什么？所以可知修慧通缘名和义，都是证解。

（三）依如实的意义：三慧都缘名与义

依如实的意义，《瑜伽师地论》第七十七卷、《解深密经》第三卷中，慈氏菩萨对佛说："世尊，如果闻所成慧、思所成慧、修所成慧都缘义，有什么差别？"

佛说："善男子：

1. 闻所成慧，依止于文字，只是如其所说，还没有善于领会意趣，意趣还没有现在前，随顺解脱，还不能领受成就解脱的意义。
2. 思所成慧，也依止于文字，不只是如其所说，也善于领会意趣，意趣还没有现在前，随顺解脱，还不能领受成就解脱的意义。
3. 如果诸菩萨的修所成慧，也依于文字，也不依于文字；也如其所说，也不如其所说；能善于领会意趣，所知事的同分三摩地所行影像现前，极为随顺解脱，已经能领受成就解脱的意义。

这称为三种了知意义的差别。"

那段经文说三慧都缘名和义：

1. 最初依听闻，以文字为先而观察意义的，称为闻慧。
2. 其次依思虑，以意义为先而观察文字的，称为思慧。
3. 其次依修习，对文字和意义都证解明了的，称为修慧。

这在因位中，八地以上是一个体性而从意义上分开；七地以前各有各别的体性。在佛位中，没有未曾得到的，完全没有闻慧、思慧，只有修慧。

诸圣教随其所宜，依相的增上，分别说缘名、缘义的不同，依实际道理是这样。

第四门　废立

一、《十地经论》的四喻

《十地经论》第一卷说："如渴思冷水，如饥思美食，如病思良医，如众蜂依蜜。我等亦如是，愿闻甘露法。"

这比喻四种意义：一是受持，二是助力，三是远离，四是安乐行。这意义是怎样的？

1. 如水不需要咀嚼，随得随饮。闻慧也是这样，最初听闻就接受，随着听闻而受持。
2. 如食物需要咀嚼，身体的力量得以助成。思慧也是这样，咀嚼所听闻的法，智慧的力量得以助成。
3. 如服用良药，药力运行，除去疾病。具足闻慧、思慧以后，随顺正确的意义，如法修行，远离一切烦恼习气的病患。
4. 如蜜是众蜂所依，是乐行的住处。闻、思、修三慧的果，是圣者所依之处，因为现法中爱味受乐而行。

三慧既然是圣果的因本，所以说前三种比喻；蜂依于蜜，比喻圣果。由此三慧不减不增。

二、四胜行中的慧行

又，修习圣因有四种殊胜的行：亲近善士、听闻正法、如理思惟、如教修行。第一种是福行，后三种是慧行。现在说慧行，所以不减不增。

三、依教理、散定立三慧

又所轨范的，略有两门：一是善人，二是胜法。法有两种：一是教，二是理。通说三乘修习殊胜的法，略有两个阶位：一是散，二是定。依修习殊胜的法，先教后理：闻慧最初缘教殊胜，思慧后来缘理殊胜，所以分为两种。修慧有世间、出世间，证解没有差别，合为一种慧。

四、依对治生死之因立三慧

又，生死的因略有两种：一是惑，二是业。生起多而重的，只有痴和疑：由于痴，迷于境界，不了解真妄；由于疑，对因果不肯造作修习。以这两门便兴起恶业。为了除去痴，令最初听闻；为了断除疑，其次思惟妙理；为了止息恶业，最后说修慧。生死之因灭了，苦果随之而无，出世间道修成，便成就觉悟寂静。

五、依对治三种随烦恼立三慧

又有三种随烦恼数数现行：一是不正知，二是失念，三是散乱。各自的行相各有能除的，正能断除的，体性只是慧，所以说三慧依次伏断这三种。

六、依智的三品立三慧

又，出世间的因略有两种：一是福，二是智。慧是智的相，殊胜，所以唯独得名；其余的是福的相，低劣，所以合说。在智之中，略有三品，就是下、中、上，因为初修、次修、后修不同。由这三品，把慧分成三种。

七、依三种力立三慧

又，慧生起时由三种力：

1. 一是缘力，二是因力，三是俱力。
2. 又由三种力：一是他力，二是自力，三是俱力。
3. 又由三种力：一是资粮力，二是自性力，三是俱力。
4. 又由三种力：一是外力，二是内力，三是俱力。
5. 又由三种力：一是多由教的力量，二是多由义的力量，三是多由定的力量。

依次三慧各由这些力量而生起，所以说三慧不减不增。

这一门就是简别，不说其余的法作为所成，只说由三种因所生起的妙慧，称为"那所成"，也是废立的意义。

第五门　位地

有两种：一是三乘凡圣的位次，二是三界九地的位次。

一、三乘凡圣的位次

有三慧而发心还没有决定的，称为住于外凡；发起决定的心，才是内凡位。

（一）二乘

如果在二乘的顺解脱分中：闻慧在五停心位，思慧在别相念、总相念二念处位，修慧在暖位以后的诸位。这是依随增上而说三慧的阶位。实际上在凡圣因果的阶位中，都可以生起三慧。暖位等的体性不是闻慧，在那个阶位也通于生起闻慧。只有见道中没有闻慧、思慧，因为是理上决定的观察。

（二）大乘

《成唯识论》说："唯识的相和性，在资粮位中，听闻思惟，能深深信解；在加行位，能渐渐伏除所取、能取，引发真见。"那段文的意思是说：四十心位生起闻慧、思慧，修习唯识；四善根以后，才生起修慧。这是从多数增上的修习来说，不是实际道理就是这样。

《华严经》中说："十住位的初发心住，能八相成道，能现神通。"又《瑜伽师地论》第六十五卷说："毗钵舍那菩萨，无论在定中还是受生，能以无色界的心了知三界法以及无漏法。"这不是抉择分位，因为不生在无色界，那一地也没有抉择分。所以资粮位修慧的行，还不能观察真理；加行位中才能观察真理。所以《成唯识论》说资粮位"对识的性相，听闻思惟"，不说修慧。

抉择分的体性只是修慧，在那个阶位也生起闻慧、思慧，因为是欲界身。

在见道位，只有修慧，因为向内观察谛理，不是散心。那闻慧、思慧的种子得以修习。

在修道位，七地以前，定心、散心间杂，三慧都可以生起。八地以上，无漏相续，完全没有散心。《十地经》说："八地以上，对一切法能堪受、能思惟、能受持。"该论解释说："依次就是闻慧、思慧、修慧。"本是一个慧体，在一刹那中，能取外在的教法而寻求意义，称为闻慧；能深入筹度，先理后文，称为思慧；在这两者中能证得明显，就称为修慧。圣者的智慧迅速，在一念的慧中从意义上分为三种，实际上没有另外的体性。

有人说：只是修慧所摄，不是闻慧、思慧，闻慧、思慧是假说，实际上是修慧。大乘、小乘都不说色界也有思慧的体性，无色界中有闻慧的体性。如果八地以后生起实在的闻慧、思慧，应当承认色界地也有思慧，无色界有闻慧。经中说无色界天在佛身边侍立听法等事，只是依修慧缘教法和意义。就像目犍连在猕猴池边，进入无所有处定，听到狂象的声音，只是修慧的听闻，不是闻慧。

二、三界九地的位次

（一）各界有几种慧

1. 欲界地有两种，就是闻所成慧和思所成慧。欲界是不定界、不是离染地，即使想要修习时，也堕入思慧之中，因为欲界的心行相粗。
2. 色界地有两种，就是闻所成慧和修所成慧。如果想要思惟的时候，就堕入修慧之中，因为上界地的心行相细。由此无色界也没有思慧。上地也有与思同时的慧，只是不由思而成，相状不明了。各种善性的，或者是生得的，或者是闻慧、修慧，决定不是思慧。
3. 无色界有一种，就是修慧。要由耳根听闻佛法以后，才引生所成的慧，无色界没有耳根，所以没有闻慧。不同界相违，不相随顺。即使由其他界引生，粗细悬殊，就像目犍连，不属于闻慧所摄。

（二）各慧在几地

1. 闻所成慧，通于六地：欲界、四静虑以及静虑中间。未至定勤求根本地的相，在善位中没有容许生起散心闻慧的。或者在七地，加上初禅未至定；或者在五地，又除去静虑中间。为什么静虑中间说没有闻慧？不承认上三未至定没有闻慧。由此应当知道最初的说法较好。
2. 思所成慧，只在欲界一地。
3. 修所成慧：有漏的在十七地，就是八根本定、八近分定、静虑中间；无漏的在十地，就是色界六地，除去上三未至定；无色界中四根本地。说非想地有无漏心，因为能引生灭尽定。

（三）上下地相起

在下地可以生起上地有漏的闻慧。《杂集论》第五卷等说："乐欲力，就是已经得到第二静虑的人，进入初静虑以后，如果想要以第二静虑地的心出定等，就能现前而出于定。其余一切地，应当如理了知。"所进入的定是修慧的心；那第二禅所出的心，不是生得善，因为诸论都说，如果生在那一地，才生起那一地的生得善。所以所出的心决定是闻慧。

有一种说法认为，所出的心决定是修慧，有漏、无漏的不同之心称为出，因为要生在那一地中，才生起那一地的闻慧。八地以后，心恒常是一类，怎么称为出？既然这样，纯粹是无漏，怎么生起闻慧？所以不同行相、不同分位称为出。前一位论师也承认闻慧称为出。

无漏的三慧，上下都通于生起。上地不生起下地有漏的思慧、修慧，因为思慧没有从下地生起，只属于一地所系；上地也不生起下地的闻慧，因为有漏的三慧是业性，都被厌舍。
