归敬章

能敬的相状，用六门分别：

1. 诸教的不同
2. 释名的差别
3. 出体性
4. 说明敬礼的用意
5. 敬礼与归依两种的差别
6. 诸门辨析

第一门　诸教的不同

诸教所说的敬礼，有七种情况：

1. 只有身敬，不是语敬、意敬。《俱舍论》说："稽首接足，所以说敬礼。"以自己的头首到地上，迎接对方的足，所以称为敬礼，因为虔诚仰慕深重。以身与语相比，身重语轻，举出重的来表示投诚，说明轻的也可以发起。身由意而起，不必说也自然成立。所以只有身敬。

2. 只有语敬，不是身敬、意敬。《说无垢称经》说，长者宝性以颂赞叹说：

「久积无边清净业，获得广大胜名闻，故我稽首大沙门，开导希夷寂路者。」（大意：长久积集无边的清净业，获得广大殊胜的名闻，所以我稽首礼敬大沙门，您开导众生走向深微寂静的道路。）

最初以身礼拜，后来只以言语，所以称为语敬，不属于身敬、意敬所摄。

没有只有意敬、不是身语敬的经文，因为只要标示让他人知道，必定要以形色、声音。也有解释说：《法华经》说"以深心念佛，修持净戒"，这就是意敬。

3. 只有身敬、语敬，不是意敬。《杂集论》序说：

「敬礼如是大觉尊，无等妙法真圣众。」（大意：敬礼这样的大觉世尊、无与伦比的妙法，以及真实的圣众。）

该论解释说："现在这首颂中，无颠倒地称赞最殊胜的功德，恭敬地申述顶礼。"意业就是能发起身语的思，不必说也自然成立，所以只举出身语。

4. 只有身敬、意敬，不是语敬。《杂阿毗昙心论》说："生起善心，转为可爱的果，全身敬礼。"举出重的身业，本来由意而转。语业的影子也是敬。

5. 只有语敬、意敬，不是身敬。《胜鬘经》说：

「咸以清净心，叹佛实功德：如来妙色身……敬礼难思议。」（大意：大家都以清净心，赞叹佛真实的功德：如来微妙的色身……敬礼不可思议。）

前面已经身礼，现在赞叹的时候只有语和意。

6. 三业都敬。天亲菩萨《摄大乘论释》序说："所以我至诚以身、语、思，频频修习无颠倒的归命礼。"《显扬圣教论》也说："我现在至诚，先赞叹礼敬。"至诚是意业，语是赞叹，身是礼拜，所以通于三业。

第二门　释名的差别

一、稽首

依世俗的解释："稽"是至的意思，"首"是头的意思，以头至地，所以称为稽首。这就是跪拜，头至地。就是《俱舍论》所说的"稽首接足，所以说敬礼"：屈下自己所尊贵的头，迎接对方所卑下的足，所以说稽首。《俱舍论》的意思是以身业的稽首，作为礼的别名，也就是三业敬礼的通称。《杂阿毗昙心论》也是这样，全身敬礼，也是稽首。

二、叩头

说"叩头"，是以手至头，所以说叩头。

三、敬礼

说"敬礼"，虔诚恭敬称为"敬"，轨则仪式称为"礼"。真诚地发起殷重诚恳的心，屈身行仪，褒扬赞叹，申述虔诚恭敬之道，标立敬礼的名称。又生起殷重清净的心，策发殊胜的业，申述诚意，归投仰慕，所以称为敬礼，就通于三业。

诸教中有时说"稽首"，是借身业的稽首，申述三业的敬礼，本体只是一物，不可以依照世俗的解释。

四、南无与和南

古来说的"南牟"，就是敬礼，应当说为"纳慕"或"纳莫"，所以不另外解释。"归依"是归敬依投的意思，不是这里所要说明的。如果说"伴谈"或"伴题"，汉语叫"稽首"，也叫"礼拜"，也不是敬礼，讹传为"和南"。

第三门　出体性

一、三思

敬礼的体性就是三业，合起来有三种思：

1. 审虑思
2. 决定思
3. 动发胜思

动发胜思正在发起身、语，是身语业的体性；前两种思是意业的体性。意业的体性通于三性，现在取善的思作为能敬的体性。大乘中，身、语除了佛果之外，体性只是无记，所以身语两种业的体性，只取能发起的思。

又有一种解释说：敬礼的体性只是惭和愧，崇重贤善称为惭，轻拒暴恶是愧。现在取前一种解释。

二、所摄

以色蕴、行蕴两蕴作为自性：身语是色蕴，意业是行蕴。发起身语之色的思，给予色的名称；造作驱动意，所以称为意业，属于两蕴所摄。随其所应，也通于种子，因为身语两业有无表色。从分位来说，也通于色处、声处。

第四门　说明敬礼的用意

瞿波论师解释《唯识二十论》说：

1. 想要显示大师有天眼，所以以身业礼拜；有天耳，所以以语业礼拜；有他心通，所以以意业礼拜。
2. 如律中所说：如果在明亮的地方，以身业礼拜，因为可以看见；在暗处而距离近，以语业礼拜，因为可以听到；在暗处而又远，以意业礼拜，因为不可见也不可闻。
3. 又显示敬礼是三轮的因：身业礼拜是神变轮的因，语业礼拜是记说轮的因，意业礼拜是教诫轮的因。也就是神境通、他心通、漏尽通的因。
4. 又显示发生三业圆满的善，三业的善总摄一切业道。
5. 又须凭借力量，借助大威神；如果敬礼不圆满，凭借的威神也不尽。

第五门　敬礼与归依的差别

略有七种解释：

1. 归依依据重的，只是身语；敬礼通于轻的，包括心和色，因为通于三业。
2. 归依的境界广，必须具足归依才成就业；敬礼或宽，即使只依一方，也可以成事。具足归依三宝才是归依，只敬一尊就是敬礼。
3. 归依有其期限，发言必定穷尽未来；敬礼只约投诚、措想。由于永久与暂时的差别，所以归依说"愿从今身尽未来际"；各种敬礼，起心虔仰，就是敬礼。
4. 归依的情意恳切，带有无表才作为归依；敬礼的心宽通，或只以表业作为体性。归依必定有表和无表，只要有善的表业，就成为敬礼。
5. 归依的意义重，必须合身语；敬礼通于轻，只要一种就是。
6. 归依带有相状，只在欲界、色界；敬礼的意义宽通，也遍于无色界。
7. 归依的意义殊胜，观察真理也可以成就；敬礼通于微细，崇重贤善也兼是。

澄净是信，归敬是业，体性迥然不同，不需要对比辨析。

第六门　诸门辨析

略有十二门。

一、观察五处，才可归依

《瑜伽师地论》第六十四卷说：由于观察五处，观察所归依的对象，才可以归依：

1. 身业清净。
2. 语业清净。
3. 意业清净。
4. 对有情生起大悲。
5. 成就无上的法。

二、所归依有几种

答：有三种，就是佛、法、僧。

三、为什么只有三种

有四种因缘，所以只有这么多，不减也不增：

1. 由于如来的本性极为调善。
2. 对于一切种类的所调伏、能调伏，有善巧方便。
3. 具足大悲。
4. 财物的供养，不以为喜；正行的供养，生起欢喜。

由于这样，佛所建立的法，佛的弟子众，都可以归依。

四、能归依的四缘与四种正行

具足四种因缘，所以说能归依：

1. 了知功德。
2. 了知差别。
3. 自己发誓愿。
4. 不再说有其余的大师。

五、归依所起的正行

应当知道归依生起四种正行：

1. 亲近善士。
2. 听闻正法。
3. 如理作意。
4. 法随法行。

如果成就这四种正行，才称为归依。

又有四种行：

1. 诸根不掉举。
2. 受持学处。
3. 悲愍有情。
4. 应当时时在三宝前勤修供养。

六、因果分别

归依在因位，不在佛果。佛没有所归依的，所以能归依也没有。《胜鬘经》说："声闻、辟支佛有恐怖，有归依，依止而不求依止。如来没有恐怖，没有归依。"

佛可以有敬礼。《梵网经》中，释迦佛也礼敬卢舍那佛。《法华经》也说："我闻圣师子深净微妙音，喜称南无佛。"（大意：我听闻圣狮子深远清净微妙的音声，欢喜地称念南无佛。）所以佛有敬礼。

七、有漏无漏分别

1. 身、语只是有漏；意业通于无漏，因为七地以前在因位。
2. 或者在因位，三业都通于无漏，因为后得智中有敬礼。
3. 或者在佛身中，三业都是无漏。

八、九地差别

1. 语业到初禅，因为有寻伺。
2. 身业到四禅，因为有身业。
3. 意业通于九地，因为有善思。

二禅以上，借用语言而起的，不是善性，所以不是语敬的体性。初地以前的菩萨、无色界的圣者，在佛边听法，所以有意表。归依就不是这样，因为不发起无表。

九、三性分别

敬礼只属于善性所摄，因为崇重贤善必定与惭愧同时，只是善性。生得善、加行善两种都可以；闻、思、修三慧，道理上也没有差错。

十、三科分别

1. 本体：只是色蕴、行蕴；连同眷属，是五蕴。
2. 本体只是一界、一处，就是法界、法处。如果有表业，就是三处：色处、声处、法处。
3. 连同眷属，属于四处、十界所摄。四处，是色处、声处、意处、法处；十界，是色界、声界、七心界以及法界。

十一、五种因缘，诸天不可归依

由于五种因缘，其余诸天等不可归依，只有三宝是真正的归依处。

一、由形相。那些诸天：

1. 不能现见，没有交接的仪轨。
2. 形相暴恶，令人怖畏。
3. 习于放逸，有贪爱。
4. 舍离他人，没有悲愍。
5. 不了知应作与不应作，对真实义不通达。

如来的形相：

1. 现前可见，有交接的仪轨。
2. 形相怡然淡泊，没有怖畏。
3. 没有放纵逸乐，远离贪爱。
4. 常不舍弃利益有情的事，有悲愍。
5. 善于了知应作与不应作，对真实义善于通达。

又有五种相，佛可以归依：

1. 为了利益有情，取证菩提。
2. 能善转正法眼。
3. 对恩人怨人，平等心利益有情。
4. 舍离对家属的贪着，恒常寂静。
5. 能善于解释一切疑惑。

二、由自性。诸天随顺于漏，本性不是调善，怎么能教化他人？如来远离诸漏，自性调善，所以能化度众生。

三、由作业。诸天受用欲乐、损害有情的恶业可以得见；佛安住静虑、能利益有情的善业可以得见。

四、由法尔。各种世间以及出世间的吉祥盛事，没有不是依靠自己的功力而得到的。如果没有功力，即使事奉诸天，也不能得到；所以即使不事奉天神，只要自己作功力，必定能得到。佛就不是这样，佛有大威神，能作为善友，方便劝导他人，令他人自己修习，便获得盛事。

五、由因果。那些天身由天业而得：是由供养诸天而得，还是无因而得？都有过失，如该论所说。

十二、受归依的功德

受归依的人获得四种功德：

1. 获得广大的福德。
2. 获得大欢喜。
3. 获得三摩地。
4. 获得大清净。

又获得四种功德：

1. 大护圆满：由于归依三宝，十方圣众都拥护这个人，令没有障难。
2. 对于一切种类的邪信解障，都得以轻微，或者永远灭尽。
3. 得以进入聪睿、正行、正至的善大众中，就是大师、同梵行者之中。
4. 对圣教有净信的诸天欢喜爱念，宣唱这样的话："我们由于成就三归依，从那里殁后来生到这里。这些人现在既然已经成就，多住于归依，也将会来到我们的众同分中。"

《显扬圣教论》第六卷所说也与此相同，有少许差别，大义没有不同。

这些义门，或者有确实的教证，或者以义理推准，没有见到前人的传述。诸位广学的人，请详细审察而加以订正。

（《归敬章》终）

四食章（上）

四食，合起来用五门分别：

1. 辨名
2. 出体
3. 显相
4. 废立
5. 诸门

第一门　辨名

分两部分：先列名，后解释。这些详细如《瑜伽师地论》第五十七、六十六、九十四卷，《显扬圣教论》第一卷，《杂集论》第五卷，两种译本的《摄大乘论》都在第三卷、第十卷，《成唯识论》第四卷所说。

一、列名

《瑜伽师地论》第五十七卷等说："如经中说，有四种食，都能长养诸根和大种。什么是四食？怎样长养诸根和大种？答：段食、触食、意思食、识食……"乃至广说。

二、释名

（一）总名

《瑜伽师地论》第六十六卷说："任持有情，令不坏灭。"《成唯识论》说："这四种能任持有情的身命，令不断坏，所以称为食。""四"是数目的名称，就是带数释。

（二）别名

1. 段食。"段"是分段，一分一分地受用，能任持身命。段就是食，是持业释。旧译称为"团"，认为可以抟、可以握，立为团食，这个意义完全不对。"团"字不是"抟"，水、饮料等不能抟成团圆，怎么称为团？所以应当称为段。

2. 触食。"触"是触对，令心心所同时触对境界，立为触的名称。触就是食，也是持业释。

3. 意思食。"意"是意处，是所依之心的名称；"思"是造作，是相应的心所。与意相应的思，称为意思，是邻近释；依意的思，就是依主释。意思就是食，也是持业释。

4. 识食。"识"是了别。识就是食，也是持业立名。

第二门　出体性

一、段食

《瑜伽师地论》第六十六卷说："段食应当说是香、味、触处所摄。"《成唯识论》说："就是欲界所系的香、味、触三种。"这句话的意思是显示：只有欲界所系的香、味、触三种，在变坏的时候有资养作用的，称为食；不是下面的一切，以及上界的触等。

二、触食

《瑜伽师地论》第九十四卷说："各种有漏的触，能给予喜乐，作为食。"《成唯识论》也说："就是有漏的触，总取境界的时候，摄受喜、乐以及顺益的舍受，能作为食事。"

这句话的意思是显示：三界有漏、与八识同时的触，摄益喜、乐以及顺益的舍受，摄益身体的，是触食的体性。如果引生苦、忧，不是顺益的舍受，触的体性就不是食，因为不能资益。所以《成唯识论》说："这种触与诸识都相应，属于六识的，食的意义偏胜。"这就彰显触食通于与八识同时的触，暗中会通天亲《摄大乘论释》第三卷所说："这里触食属于六识身，因为触对粗显的境界，资养的作用殊胜。"不取其余的触。

另一种说法：只取与六识同时的触，作为食的体性。论中说触通于与八识同时运转，作为食的体性的，只有与六识同时的。因为与第七、第八识同时的触，完全不能引生喜、乐两种受以及顺益的舍受；与第八识同时的舍受，在一切地中行相相同。

有人反驳这种说法：这个理由不成立。并不是一定要触能引生自己同时的喜、乐受等，才称为食。引生其余识同时的喜、乐等生起，摄益身体的，一切都是食。由于第八识等的触殊胜于自己的境界，引生与六识同时的喜等，所以也是食。

不过依照诸文，第二种解释较好，因为只说摄益喜等作为食，不是第七、第八识。

三、意思食

《成唯识论》说："思食，就是有漏的思，与欲同时运转。"又说："这种思与诸识都相应，属于意识的，食的意义偏胜。"

这个意思正是显示：三界有漏、与八识同时的思，希求可爱的境界、摄益身体的，都是思食的体性。暗中会通《瑜伽师地论》第五十七卷以及天亲《摄大乘论释》所说："缘未来的境界，摄益识，称为思食。"因为意思对境界的希望殊胜。由此第九十四卷说："如果在意地，能会合境界的思，称为意会思，能给予一切对可爱境专注希望，作为食。"

关于思食的范围，有三种说法：

1. 第一种：如上，通于与八识同时的思。
2. 第二种：与六识同时的有漏思，希求境界、资益身体的，都是思食的体性；第七、第八识不是，因为没有希求的行相。诸处只说与意同时的思，是因为与意同时的思通缘未来，最为殊胜；也有希望现前境界的思，所以承认通于五识。《成唯识论》说"与诸识相应"，是显示思的体性同时存在，食只是与六识同时的。
3. 第三种：思食只是与第六识同时的思，因为诸处只说缘未来。五识缘现前境界，是触的力量增长，不是思食。所以《成唯识论》说，思的体性通于诸识，成为食的意义只是与第六识同时的。所以世亲说："意思食，是能希望，由于希望，饶益所依身。就像远远看见水，口渴也不会死，这是以眼为门，意中希望的缘故。"五识没有希求未来的作用。

这三种解释中，第二种解释较好，因为五识对境界有微细的思，可以有希望；不然的话，五识应当没有与欲同时的心所。依此推知，第三种解释就同于《成唯识论》中不承认别境心所与五识同时的那一种说法。所以可知，正说是第二位论师较好。

四、识食

《成唯识论》说："识食，就是有漏的识。这种识通于诸识的自体，第八识的食的意义偏胜。"

这显示识食通取三界有漏的八识。正能执受的只有第八识，因为一类相续，执持殊胜。《摄大乘论》《成唯识论》都取第八识，实际上通于八识。《瑜伽师地论》等只总说"识"，没有另外说是第八识；只有《摄大乘论》以及《成唯识论》取第八识。

八识都可以称为食，只是并不是一切识都立为食的名称，取有漏位的第八识全部，因为恒常执持。《瑜伽师地论》第五十七卷说："由三种食长养识，识又长养诸根和大种，所以立为食。"所以可知，各种识不能资养的，都不属于食所摄。就像触、思等，在下面第三门显相中，作四句分别，才应当了知。

第七识的有漏部分，都由于作为本识的俱有依，能执持本识。就是第七、第八识的全部，以及六识的少分；或者除去第七识，因为第七识不能资养。

五、三科所摄

由此《集论》第三卷说："三蕴、五处、十一界的一分所摄。"

1. 三蕴：段食是色蕴，思食、触食是行蕴，八识是识蕴。
2. 五处：就是香、味、触三处，以及法处、意处。
3. 十一界：就是香、味、触、法界，以及七心界。

除去无漏的四种，因为无漏不能资益，所以说"一分"。也就是说，并不是一切香、味、触三种都是食的体性，因为有的不能资养。《瑜伽师地论》第五十七卷说："能长养的称为食，与此相违的不是食。"如段食一样，其余的食也是这样。
