一、诸教相摄（续）

（一）"无烧割等"属于第四重胜义的经证

问：凭什么知道"无烧割等"，就是一实真如，属于胜义胜义所摄？

答：《涅槃经》又说：

文殊师利菩萨对佛说："世尊所说的实谛，意义是什么？"

佛说："善男子，所说的实谛，称为真法。善男子，如果法不真，就不称为实谛。善男子，实谛没有颠倒，没有颠倒才称为实谛。善男子，实谛没有虚妄，有虚妄的不称为实谛。善男子，实谛称为大乘，不是大乘的不称为实谛。善男子，实谛是佛所说，不是魔所说，不是佛说的不称为实谛。善男子，实谛是一道清净，没有第二。善男子，有常、有乐、有我、有净，这就称为实谛的意义。"

这段经文的意思，就是说"无烧割等"的真如是谛，只是胜义，不属于俗谛所摄，因为最为殊胜。

文殊师利对佛说："世尊，如果以真实作为实谛，这个真实法就是如来、虚空、佛性。如果是这样，如来、虚空以及佛性就没有差别了。"

佛告诉文殊师利："有苦、有谛、有实；有集、有谛、有实；有灭、有谛、有实；有道、有谛、有实。善男子，如来不是苦，不是谛，是实；虚空不是苦，不是谛，是实；佛性不是苦，不是谛，是实。文殊师利，所说的苦，是无常相，是可断相，这是实谛。如来之性不是苦，不是无常，不是可断相，所以是实。虚空、佛性也是这样。"

这段经文的意思是：一实真如，在缠时称为佛性，在果位称为如来；法性空如，也因空而显，所以称为虚空。真如不是安立，所以不属于四谛所摄。这段经文所说的，就是废诠谈旨的一真法界。苦、集、灭、道是四谛的事，"谛"是四谛之理，"实"是四谛的真如。由此，真如不是苦，不是谛，只属于"实"所摄。

（二）《瑜伽》《显扬》说四俗一真

又如前面所引，《瑜伽师地论》《显扬圣教论》说有二谛：只说俗谛有四种，与这里的四重世俗相同；只说真谛有一种，就是非安立，只是第四重真谛。前三重真谛不离开后三重俗谛，所以不说。又，有差别的称为安立，所以说四种俗谛；没有差别的称为非安立，所以只有一种真谛。

《成唯识论》第九卷中，四重真谛都有，因为广泛具足地显示，表明胜义比世俗殊胜，也有差别。

（三）《胜鬘》一谛与《仁王》二谛

《胜鬘经》的一谛，属于第四重真谛所收。《仁王经》的二谛，各自以名称所摄。

（四）《辩中边》《显扬》《成唯识》的三种二谛

《辩中边论》《显扬圣教论》《成唯识论》第八卷，说二谛各有三种。

俗谛三种：

1. 假世俗
2. 行世俗
3. 显了世俗

依次就是遍计所执、依他起、圆成实三自性。

真谛三种：

1. 义胜义：就是真如。
2. 得胜义：就是涅槃。
3. 行胜义：就是圣道。

与四重二谛的对应：

1. 假世俗，属于第一重世俗所摄，因为只有假名，完全没有体性。
2. 行世俗，属于第二、第三重世俗所摄，因为是有为的事。心上变现似四谛的相和理，理不离事，所以属于依他起所摄，是第二、第三重世俗。
3. 显了世俗，属于第四重世俗所摄，因为依二空之门所显了。依照意义，应当也进入四重胜义之中，容易了知。
4. 义胜义，属于第四重真谛所摄。
5. 得胜义，属于第三重真谛所摄，因为是由证而显，就证得来辨明。
6. 行胜义，属于第二重真谛所摄，因为无漏的真智，在道理上稍为殊胜。如果随其事相，就属于第一重真谛所摄；随其所应，也进入四重世俗，容易了知。

如果说苦、集、灭、道四谛为得胜义，就是第三重世俗、第二重真谛所摄，因为论中自己这样说。

（五）《瑜伽师地论》第四十六卷的一谛至十谛

《瑜伽师地论》第四十六卷说："什么是谛的施设建立？有无量种。"

一、立一谛：就是不虚妄谛。属于第四重真谛所摄。

二、立二谛：一是世俗谛，二是胜义谛。《仁王般若经》中，波斯匿王对佛说："世尊，世谛中有没有第一义谛？如果有，谛就不应当是一；如果没有，智就不应当是二。"这与《瑜伽师地论》相同，随着名称，依次属于二谛所摄。

三、立三谛：一是相谛，二是语谛，三是用谛。因为所诠、能诠，体和用的离合有差别。相谛通于真和俗；语谛、用谛属于前三重世俗，不是真谛，属于中间、后面两种所摄。

〔存疑：原文「语用初三俗，唯非真中后二所摄」，句意简略，"中后二所摄"所指不明。此处依字面翻译。〕

四、立四谛：一是苦，二是集，三是灭，四是道。如前面已经说过。因为杂染、清净两类，各有因和果的差别。

五、立五谛：一是因谛，二是果谛，三是智谛，四是境谛，五是胜谛。前四种是安立，后一种是非安立。安立之中，有能有所，心和境不同。

1. 最初的因谛、果谛，属于第三重世俗、第二重真谛所摄。
2. 境谛通于真和俗。
3. 智谛只属于第二、第三重世俗，第一、第二重真谛所摄。
4. 第五胜谛，属于第四重世俗，以及第三、第四重真谛所摄。

或者前四种依次配集、苦、道、灭，后一种是真如。

六、立六谛：一是谛谛，二是妄谛，三是遍知谛，四是应永断谛，五是应作证谛，六是应修习谛。因为胜义和世俗两类有差别，染净因果两类各不相同。

1. 谛谛通于四重真谛，因为义理都殊胜；妄谛通于四重世俗，因为义理都低劣。
2. 或者说，谛谛是理，不是前两重世俗，是后三重真谛；妄谛如幻，是前两重世俗，属于第一重真谛所摄。后四种依次就是四谛，属于第三重世俗、第二重真谛所摄。

七、立七谛：一是爱味谛，二是过患谛，三是出离谛，四是法性谛，五是胜解谛，六是圣谛，七是非圣谛。前四种依次是集、苦、道、灭；意解思惟，以及圣者、凡夫所知的种类不同。

1. 最初的四谛，属于第三重世俗、第二重真谛所摄。
2. 意解思惟，属于第四重世俗、第三重真谛所摄，因为依言诠行相的二无我。
3. 四重真谛、四重世俗都是圣谛，因为圣者了知有无、事理的差别。
4. 凡夫对第一重世俗坚固执着，虚妄地说为真实，所以不是两种圣谛。圣者了知第一重世俗为无，可以属于第一重世俗所摄。

其他地方或者立七谛：爱味、过患、出离、应知、应断、应证、应修。以单观、重观两种观法观察四谛，第二重观中除去道谛，也属于第三重世俗、第二重真谛所摄。

八、立八谛：一是行苦性谛，二是坏苦性谛，三是苦苦性谛，四是流转谛，五是还灭谛，六是杂染谛，七是清净谛，八是正加行谛。依据三苦、生死、涅槃、有漏无漏品、圣因的差别而立。

1. 前四种以及第六种，属于第二、第三重世俗，第一、第二重真谛所摄。
2. 第五种以及第七种，属于第三重世俗、第二重真谛所摄，因为是清净的因果；或者属于第四重世俗，第三、第四重真谛所摄。
3. 第八正加行谛，属于第三、第四重世俗，第二、第三重真谛所收。

《胜鬘经》中也说八谛：有作四谛、无作四谛各有四种，因为对劣机、胜机宣说浅理、深理，种类不同。

1. 有作四谛，就是声闻的四谛，决定属于第三重世俗、第二重真谛所摄。
2. 无作四谛，就是菩萨的四谛，属于第三重世俗、第二重真谛所摄；或者属于第四重世俗、第三重真谛所摄，因为依言诠显示旨趣，不是非安立。

九、说九谛：一是无常谛，二是苦谛，三是空谛，四是无我谛，五是有爱谛，六是无有爱谛，七是彼断方便谛，八是有余依涅槃谛，九是无余依涅槃谛。依苦谛的四种境，以及后有爱、常断两种爱的集谛，一种道谛，两种灭谛，分成九谛。这仍是四谛，属于第三重世俗、第二重真谛所摄。

十、说十谛：一是逼切苦谛，二是财位匮乏苦谛，三是界不平等苦谛，四是所爱变坏苦谛，五是粗重苦谛，六是业谛，七是烦恼谛，八是听闻正法如理作意谛，九是正见谛，十是正见果谛。

1. 前五种是有漏的果，其次两种是异熟的因，再其次两种是出世间道，最后一种是无为的灭。
2. 苦谛的五种中：第一种摄四苦，就是生、老、死、怨憎会苦；第二种就是求不得苦；第三种是病苦；第四种是爱别离苦；第五种是简略摄持一切五取蕴苦。

八苦、两种集、两种道、一种灭有差别，属于第三重世俗、第二重真谛所摄。

这里暂且简略地配合诸谛的相摄，大小的义门都应当另外详说。颂说：

「不虚、真、相、苦，因、谛及爱、行，无常与逼切，增十谛各初。」（大意：不虚妄谛、真谛、相谛、苦谛、因谛、谛谛、爱味谛、行苦性谛、无常谛、逼切苦谛，依次是从一谛增到十谛各组的第一种。）

〔译注：这首颂是窥基为记忆一谛至十谛各组首项所作的口诀。"因谛"二字分属五谛的因谛和六谛的谛谛；二谛一组举"真"为代表。〕

二、问答分别

问一：哪些是安立，哪些是非安立

问：二谛有四种不同，其中哪些称为安立，哪些称为非安立？

答：《显扬圣教论》说，四种俗谛都是安立。《瑜伽师地论》说，第四重胜义是非安立，所以前三重真谛也是安立，因为前三重真谛的体性就是后三重俗谛。

问二：既有安立谛，为什么还要说非安立谛

问：如果是安立谛，已经立为谛，为什么又说非安立谛？

答：《瑜伽师地论》第六十四卷说：只说安立谛，离开非安立谛，在两种解脱上不合道理：一是从相缚解脱，二是从粗重缚解脱。如果修行安立谛，所行都有相状，对各种相缚不能解脱；相缚不能解脱，对粗重缚也不能解脱。如果修行非安立谛，不行于相状；不行于相状，相缚就解脱；相缚解脱，粗重缚也得以解脱。

问三：既有非安立谛，为什么还要说安立谛

问：如果非安立谛已经立为谛，何必又说安立谛？

答：《瑜伽师地论》第六十四卷说：为了让资粮道和方便道得以清净，有所厌舍，有所修习，有所进趣，有所了知，所以立安立谛。

问四：修行有相，为什么不能解脱二缚

问：如果修行有相，从二缚中解脱，有什么过失？

答：《瑜伽师地论》第六十四卷说：有极善的定心，依第四静虑，在顺决择分的善法中运转。缘诸谛的时候，本来应当从两种缚中得到解脱，究竟清净；因为是有相的心，相缚仍然存在。如果能对治的心也承认有相，与所对治的心究竟有什么差别？并且世间道与出世间道两种有差别，所以修行有相不能解脱。必须依无相的非安立谛。由此证明可知，无分别智决定没有相分，而能断惑。

问五：为什么立四重

问：只立一重俗谛、一重真谛就可以了，何必立四重？

答：

1. 这个谛如果只应摄行归真，就总立一谛。《胜鬘经》说一实谛："只有如来藏是一实，其余的有生起和穷尽。"或者是所取，不是一实。
2. 如果以事理、安立非安立来论，只应立二谛。《瑜伽师地论》第六十四卷说："一真法界称为胜义，其余称为世俗。"《仁王经》中说二谛，也是这样。
3. 如果随着人和法有胜有劣，应当各立二谛。《涅槃经》中随人、随法也说二谛；或者俗谛和真谛都有二谛。
4. 如果以空和事、理，以及义、得、行的不同，《显扬圣教论》等说二谛之中各有三种。
5. 如果以诸法的有无、事理、浅深、诠旨，意义各不相同，所以二谛之中各说四重。

又，《瑜伽师地论》解释说：世俗和胜义都有世间所成、道理所成、证得所成、真理所成。由此世俗谛和胜义谛各分四种。在劣法中，依世间所成等立四重世俗；在胜法中，依世间所成等立四重胜义。所以不增不减。

问六：二谛是同还是异

问：这二谛是相同还是相异？

答：也同也异。《仁王经》说："世谛之中没有第一义，智就不应当是二；如果说有，智就不应当是一。"《涅槃经》说："世谛就是第一义，佛有另外的方便，随顺众生说有二谛。"所以不可以说决定相同或决定相异。

1. 第一重世俗，有名无体，是世俗中最低劣的，再没有比第一重世俗更低的，只是假名安立，只是俗，不是真，这称为异。
2. 第四重胜义，体性微妙，离开言说，不可施设，是真谛中最殊胜的，超过一切，只是真，不是俗，这称为异。
3. 其余的可以称为同。

由此，二谛作四句分别：

1. 是俗不是真：就是第一重世俗。
2. 是真不是俗：就是第四重真谛。
3. 是真也是俗：就是前三重真谛、后三重俗谛。
4. 不是真也不是俗：就是除去以上的情况。

问七：真俗相待

第四重胜义不能自己成为胜，要对待四重世俗，所以称为胜义；所以前三重真谛也称为俗。第一重世俗不能自己成为俗，要对待四重真谛，才称为世俗；所以后三重俗谛也称为真。

1. 第一重胜义，对待第一重世俗而称为胜。
2. 第二重胜义，对待第二重世俗而称为胜。
3. 第三重胜义，对待第三重世俗而称为胜。
4. 第四重胜义，对待第四重世俗而称为胜。
5. 第一重世俗，对待第四重真谛而称为俗。
6. 第二重世俗，对待第三重真谛而称为俗。
7. 第三重世俗，对待第二重真谛而称为俗。
8. 第四重世俗，对待第一重真谛而称为俗。

所以如果有俗的时候，也必定有真；如果有真的时候，也必定有俗。

「俗是真家俗，真是俗家真。有俗亦有真，无真亦无俗。」（大意：俗是真的俗，真是俗的真。有俗，也就有真；没有真，也就没有俗。）

所以不是遣除依他起而证得圆成实，也不是没有俗谛而可以有真谛，因为真和俗相依而建立。

三、窥基的自述

这里所说的四种二谛，经论中已经有，诸位大德也有传述，只是后来的学人还没能疏通演说。窥基随着翻译的次第，简略地纂集所听闻的。其中委细的地方，以后再咨问审察。所以编集起来，作为一章，希望后来的学人能详细而容易地了解。

可以说义理高过千叶，道理光照万代。赞咏吟讽，又怎能畅尽心中的欢喜？所遗憾的只是徒然弹奏伯牙之琴，空自献尽卞和之璧罢了。

〔译注：末句用典。伯牙鼓琴，知音唯钟子期；卞和献璧，两次被刖足而不被识。窥基借此表示担心所阐的深义无人能识。〕

（《二谛章》终）
