彼果智分第十一

一、三种佛身

上面已经说了彼果断的殊胜，彼果智的殊胜应当如何看待？应当了知，由三种佛身显示彼果智的殊胜：第一，由自性身；第二，由受用身；第三，由变化身。

其中，自性身，就是诸如来的法身，因为法身是一切法自在转的所依止。受用身，就是依于法身，由种种诸佛的众会所显现，以清净佛土和大乘法乐为所受用。变化身，也依于法身，示现从睹史多天宫没，受生，受欲，逾城出家，往外道处修诸苦行，证大菩提，转大法轮，入大涅槃。

【世亲释】受用身，是受用清净佛土的所依止，又是受用大乘法乐的所依止。变化身，是示现与人、天同类之身的所依止。

关于三身，有一首嗢拖南颂：

```
相证得自在
依止及摄持
差别德甚深
念业明诸佛
```

大意：以相、证得、自在、依止、摄持、差别、功德、甚深、念、业，阐明诸佛之身。

二、法身的五相

诸佛的法身以什么为相？应当了知，法身简略有五相。

第一，以转依为相。因为转灭一切障的杂染分依他起性，转得解脱一切障、于法自在转的现前清净分依他起性。

第二，以白法所成为相。因为六波罗蜜多圆满，得到十种自在。其中，寿自在、心自在、众具自在，由布施波罗蜜多圆满而得。业自在、生自在，由持戒波罗蜜多圆满而得。胜解自在，由忍辱波罗蜜多圆满而得。愿自在，由精进波罗蜜多圆满而得。神力自在，五通所摄，由静虑波罗蜜多圆满而得。智自在、法自在，由般若波罗蜜多圆满而得。

【世亲释】寿自在，是随所欲住世多久，就能如意示现自身。心自在，是在生死中不被染污。众具自在，是对饮食等十种资具，随所欲都能如意得到。业自在，是身语业自在而转，随所欲而业现前。生自在，是随所欲在诸趣中受生。持戒能摄业因与生果，所以得此二自在。胜解自在，是令诸法随心而转，如所胜解一切事成，比如转地等成为金等；因为修忍时随顺有情的意乐而转，所以得到一切法随心而转。愿自在，是所愿皆成；因为修精进时所作之事都能究竟，中途不懈废。智自在，是普遍了知一切所知；法自在，是如所欲能正确安立契经等法。

第三，以无二为相。以有与无无二为相，因为一切法无所有，空所显的相是实有。以有为与无为无二为相，因为法身不是业与烦恼所为，又自在示现有为之相。以异性与一性无二为相，因为一切佛的所依没有差别，又因为无量相续各自现等觉。关于无二，有两颂：

```
我执不有故
于中无别依
随前能证别
故施设有异
种姓异非虚
圆满无初故
无垢依无别
故非一非多
```

大意：由于没有我执，法身中没有各别的所依；随前时能证者的不同，所以施设有差异。由于种姓有异，由于资粮不虚，由于佛事圆满，由于诸佛无有最初，所以不是一；由于无垢的所依没有差别，所以不是多。所以诸佛非一非多。

【世亲释】世间由于我执的力量，有各别的所依身；法身中我执都没有，所以没有各别的所依身。所依身没有差别，为什么承许有多佛？由众多依身各自所证，所以有差别。“种姓异”，诸菩萨的种姓有多种差别。“非虚”，种姓异，加行就异，资粮圆满也有多种；如果只有一佛，其余菩萨的资粮就空无果。“圆满”，诸佛要具作一切有情的利益等事，安立有情于三乘；如果如来不安立有情于佛乘，佛事就不圆满。“无初”，如同生死流转没有最初，诸佛也是如此；如果只有一佛，就应当有最初。“无垢依无别”，诸佛都以无垢法界为所依，没有差别，所以不是多。

第四，以常住为相。因为真如清净之相，因为本愿所引，因为所应作的事没有终尽之期。

【世亲释】清净真如体是常住，显现成佛，所以如来以常住为相。往昔发愿常作一切有情的利乐，所证的佛身由此愿所引，本愿不会空无结果。如果说如来所作的一切有情利乐已经究竟，并非如此，因为现在仍有无边应作之事，一切有情还没有涅槃。

第五，以不可思议为相。因为真如清净是自内所证，因为没有世间的譬喻能够比喻，因为不是诸寻思所行之处。

三、法身的最初证得

又，法身如何最初证得？以缘总相大乘法为境的无分别智和后得智，五相善修，在一切地中善集资粮，以金刚喻定破灭微细难破之障，从金刚喻定无间，离开一切障，所以得到转依。

【世亲释】“最初证得”，显示法身不是所生起的，因为法身的体是无为；如果是所生起，就应当是无常。金刚喻定，如同金刚，能破微细难破之障。由金刚喻定，能证转依，得到法身。

四、五种自在

又，法身由几种自在而得自在？简略由五种：

第一，由佛土、自身、相好、无边音声、无见顶相自在，由于转色蕴的所依。

第二，由无罪、无量、广大的乐住自在，由于转受蕴的所依。

第三，由辩说一切名身、句身、文身的自在，由于转想蕴的所依。

第四，由现化、变易、引摄大众、引摄白法的自在，由于转行蕴的所依。

第五，由大圆镜智、平等性智、妙观察智、成所作智的自在，由于转识蕴的所依。

【世亲释】转色蕴的所依，证得示现金银等宝净妙佛国的自在，以及在大集会中随有情胜解示现种种色身、相好、无边音声、无见顶相的自在。转受蕴的所依，得到无罪、无量、广大的乐住，“无量”因为众多，“广大”因为超过一切三界之乐。想以取相为性，名身等能取相，转染污的想蕴，得到清净的想蕴，所以得名身等辩说自在。转行蕴的所依：随所欲示现所作，称为现化；改转地等成为金等，称为变易；随意引来天、龙、药叉等众，称为引摄大众；随意引发诸白法现前，称为引摄白法。

【世亲释】转识蕴的所依，得到四智。大圆镜智，是对所知境界没有忘失，境界不现前时，也能记了，如同善于熟诵的书论分明。平等性智，是在先前通达真法界时，得到对诸有情的平等心等，到此究竟清净。妙观察智，如同掌管宝藏的人，随所欲对任何陀罗尼门、三摩地门作意思惟，就得到自在无碍的智慧。成所作智，是能示现从睹史多天宫没，乃至涅槃，种种佛事都得自在。

五、法身的三种依止

又，法身应当了知由几种处作为依止？简略由三种处。第一，由种种佛住的依止。关于佛住，有两颂：

```
诸佛证得五性喜
皆由等证自界故
离喜都由不证此
故求喜者应等证
由能无量及事成
法味义德俱圆满
得喜最胜无过失
诸佛见常无尽故
```

大意：诸佛证得五种喜，都是由于平等证得自己的法界；声闻等远离五种喜，都是由于不证法界，所以求喜的人应当平等证得法界。由于能力无量，由于事业成就，由于法味、义、功德都圆满，诸佛得到最殊胜而无过失的喜，因为诸佛见到五喜常而无尽。

第二，由种种受用身的依止，只为成熟诸菩萨。第三，由种种变化身的依止，大多为了成熟声闻等。

【世亲释】佛住，是佛安住的圣住、天住与梵住，法身是诸住的所依。五种喜：第一，依止法身有众多佛成等正觉，一切功能都平等，所以能力无量，见此而生欢喜。第二，一位如来所作利乐有情之事，就等同一切如来所作，由于佛多，事业也无量，见此而生欢喜。第三，见契经等法有殊胜滋味，生欢喜。第四，义圆满，随所思念诸事无不具足。第五，德圆满，十力、无畏、不共法等无不具足。此喜超过三界之喜，所以最胜；永断烦恼与习气，所以无过失；穷生死际常无有尽，入无余依涅槃界也无尽，所以生殊胜之喜。受用身依止法身，因为离开受用身，已入大地的诸菩萨就不能成熟。变化身依止法身，因为离开变化身，下劣信解的声闻等就不能成熟；“大多”二字，兼摄胜解行地的诸菩萨。

六、六种佛法摄持法身

应当了知，法身由几种佛法所摄持？简略由六种：第一，由清净，就是转阿赖耶识而得法身。第二，由异熟，就是转色根而得异熟智。第三，由安住，就是转欲行等住，而得无量智住。第四，由自在，就是转种种摄受业的自在，而得一切世界无碍神通智的自在。第五，由言说，就是转一切见闻觉知的言说戏论，而得令一切有情心生欢喜的辩说智自在。第六，由拔济，就是转拔济一切灾横过失，而得拔济一切有情一切灾横过失的智慧。应当了知，法身由上面所说的六种佛法所摄持。

【世亲释】转欲行等住，是转世间欲行等住，得到佛法之住，住种种住。转种种摄受业的自在，是转世间求利、务农等种种事业的自在。转拔济，比如世间有王难等逼恼之事发生时，以亲友之力、财宝之力等能够拔济，转此而证得拔济一切有情一切灾横过失的智慧。

七、诸佛法身的一与异

诸佛的法身，应当说有差异，还是没有差异？由于所依、意乐、事业没有差别，应当说没有差异。由于无量依身各自现等觉，应当说有差异。如同所说的佛法身，受用身也是如此：由于意乐和事业没有差别，应当说没有差异；不是由于所依没有差别，因为受用身有无量所依差别而转。应当了知，变化身如同受用身所说。

【世亲释】意乐没有差别，是都为利益安乐一切有情。事业没有差别，是同样示现成等正觉、般涅槃等种种作业。
