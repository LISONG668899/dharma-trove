增上慧学分第九

一、无分别智是增上慧

上面已经说了增上心的殊胜，增上慧的殊胜应当如何看待？就是无分别智，就其自性、所依、因缘、所缘、行相、任持、助伴、异熟、等流、出离、至究竟，加行、无分别、后得的胜利，差别，无分别与后得的譬喻，无功用作事，以及甚深而说。应当了知，无分别智称为增上慧的殊胜。

【世亲释】无分别智有三种：第一，加行无分别智，就是寻思的智慧；第二，根本无分别智，就是正证的智慧；第三，后得无分别智，就是起用的智慧。寻思智是根本智的因，后得智是根本智的果，所以成立根本无分别智，也就兼成立了其余二智。

二、无分别智的自性：离五种相

其中，无分别智以远离五种相为自性：第一，远离无作意；第二，远离超过有寻有伺地；第三，远离想受灭的寂静；第四，远离色的自性；第五，远离对真义的异计度。远离上面五种相，应当了知称为无分别智。

【世亲释】如果没有作意就是无分别智，睡眠、醉酒、闷绝等就应当成为无分别智。如果超过有寻有伺地就是无分别智，第二静虑以上诸地就应当成为无分别智，世间人也应当得到无分别智。如果想受灭等位中心心所不转就是无分别智，灭定等位没有心，智就不能成立。如果如同色的自性就是无分别智，智就应当如色一样顽钝无思。如果对真义起异计度，分别“这是真义”，无分别智就成了有分别。远离上面五种相，对真义转起，而对真义不起异计度，就是无分别智，如同眼识缘色时，不计度“这是色”。

三、无分别智诸门之颂

对上面所说无分别智的成立之相，又说多颂：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">诸菩萨自性<br>远离五种相<br>是无分别智<br>不异计于真</div>

大意：诸菩萨无分别智的自性，是远离五种相，对真义不起异计度。

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">诸菩萨所依<br>非心而是心<br>是无分别智<br>非思义种类</div>

大意：诸菩萨无分别智的所依，不是心，也不是非心，因为无分别智不思量义，又属于心的种类。

【世亲释】如果说依心而转，心能思量，就不是无分别；如果说依非心而转，就不成为智。为了避免两种过失，颂中说无分别智的所依不称为心，因为不思量义；也不是非心，因为由心所引，属于心的种类。

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">诸菩萨因缘<br>有言闻熏习<br>是无分别智<br>及如理作意</div>

大意：诸菩萨无分别智的因缘，是有言说的正闻熏习，以及如理作意。

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">诸菩萨所缘<br>不可言法性<br>是无分别智<br>无我性真如</div>

大意：诸菩萨无分别智的所缘，是不可言说的法性，就是无我性所显的真如。

【世亲释】由于是遍计所执的自性，一切法都不可言说。“无我性”，是遍计所执的补特伽罗和一切法都无自性；由无性所显的有性，称为真如。为了不让人执为断灭，所以如此说。

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">诸菩萨行相<br>复于所缘中<br>是无分别智<br>彼所知无相</div>

大意：诸菩萨无分别智的行相，在所缘之中，以所知的无相为行相。

【世亲释】无分别智在真如中平等平等生起，以无异、无相之相为行相。如同眼取色时见青等相，青等与色并无差异；无分别智与真如也没有相异的行相。

为了解释疑难，又说两颂：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">相应自性义<br>所分别非余<br>字展转相应<br>是谓相应义<br>非离彼能诠<br>智于所诠转<br>非诠不同故<br>一切不可言</div>

大意：所分别的，是以相应为自性的义，不是别的。字与字展转相续，就称为相应之义。离开能诠之名，智对所诠之义不能转起；能诠与所诠不相同，所以一切法都不可言说。

【世亲释】如果一切法都不可言说，以什么为所分别？以“相应”为自性的义是所分别：一个一个的字相续宣说，成为一个意义，就是相应之义，比如“斫刍”两字不断而说，就成为“眼”的意义。一切法不可言说，由什么成立？如果不了解能诠的名，对所诠的义就不起觉知；如果说一定要等待能诠的名才对所诠的义起觉知，名与义又互不相称，各有不同的相，所以能诠与所诠都不可说。

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">诸菩萨任持<br>是无分别智<br>后所得诸行<br>为进趣增长</div>

大意：诸菩萨由后得智所得的诸行，为了进趣增长，以无分别智为任持。

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">诸菩萨助伴<br>说为二种道<br>是无分别智<br>五到彼岸性</div>

大意：诸菩萨无分别智的助伴，说为两种道，就是前五种波罗蜜多。

【世亲释】两种道：第一，资粮道，就是布施、持戒、忍辱、精进波罗蜜多；第二，依止道，就是静虑波罗蜜多。

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">诸菩萨异熟<br>于佛二会中<br>是无分别智<br>由加行证得</div>

大意：诸菩萨无分别智的异熟，是在佛的两种法会中受生，分别由加行与证得而来。

【世亲释】两种法会，是受用身的法会和变化身的法会。无分别智在加行位时，在变化身的法会中受生；已经证得无分别智，在受用身的法会中受生。

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">诸菩萨等流<br>于后后生中<br>是无分别智<br>自体转增胜</div>

大意：诸菩萨无分别智的等流，是在后后生中，无分别智的自体展转增胜。

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">诸菩萨出离<br>得成办相应<br>是无分别智<br>应知于十地</div>

大意：诸菩萨无分别智的出离，在十地中，先得相应，后成办相应。

【世亲释】出离，是进趣究竟，就是进趣大涅槃。初地中最初得到无分别智，称为“得相应”；此后经无量百千大劫，称为“成办相应”。

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">诸菩萨究竟<br>得清净三身<br>是无分别智<br>得最上自在</div>

大意：诸菩萨无分别智的究竟，是得到清净的三身，得到最上的自在。

关于三种无分别智的胜利，有三颂：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">如虚空无染<br>是无分别智<br>种种极重恶<br>由唯信胜解<br>如虚空无染<br>是无分别智<br>解脱一切障<br>得成办相应<br>如虚空无染<br>是无分别智<br>常行于世间<br>非世法所染</div>

大意：加行无分别智如同虚空无染，种种极重的恶不能染污，仅仅由于信解。根本无分别智如同虚空无染，解脱一切障，得到成办相应。后得无分别智如同虚空无染，常行于世间，不被世间法所染。

【世亲释】加行无分别智：诸菩萨最初从他人听闻无分别之理，自己还不能亲见，生起胜解，以胜解为依止，方便推求无分别之理，称为加行无分别智，因为能生无分别智，所以也得无分别之名；仅由信乐无分别理而生胜解，就能对治种种恶趣。后得无分别智：由后得智的力量，观察有情的利乐之事，故意往世间受生，受生以后，利、衰、毁、誉、称、讥、苦、乐世间八法都不能染污；因为从无分别智所生，所以也得无分别之名。

关于三种智的差别，有四颂：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">如哑求受义<br>如哑正受义<br>如非哑受义<br>三智譬如是<br>如愚求受义<br>如愚正受义<br>如非愚受义<br>二智譬如是<br>如五求受义<br>如五正受义<br>如末那受义<br>三智譬如是<br>如未解于论<br>求论受法义<br>次第譬三智<br>应知加行等</div>

大意：如同哑人求取境义，如同哑人正受境义，如同不哑的人受义后能说，三种智的譬喻就是如此。如同愚人求取境义，如同愚人正受境义，如同不愚的人受义，智的譬喻如此。如同眼等五识求取境义，如同五识正受境义，如同意识受义，三种智的譬喻如此。如同未懂论的人求解论，如同温习论只受文字，如同懂论的人兼受文字与义理，依次比喻加行等三种智。

【世亲释】哑人求取境义，不能言说，如同加行无分别智；哑人正受境义，寂然无言，如同根本无分别智；不哑的人受义后能如所受而言说，如同后得无分别智。五识求受与正受都无分别，比喻加行与根本二智；意识受义也能分别，比喻后得智。未懂论的人求解论，比喻加行智；温习论的人只受文字，比喻根本智；懂论的人对文字和义理都能领受，比喻后得智。

【译注】第二颂末句，论本作“二智譬如是”，世亲释所引作“三智譬如是”。世亲释说愚喻“如前哑喻应正安立三智差别”，依世亲释，愚喻也比喻三智。

关于根本智与后得智的差别，有两颂：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">如人正闭目<br>是无分别智<br>即彼复开目<br>后得智亦尔<br>应知如虚空<br>是无分别智<br>于中现色像<br>后得智亦尔</div>

大意：根本无分别智如同人正在闭目，后得智如同同一人又睁开眼睛。根本无分别智如同虚空，后得智如同虚空中显现的色像。

【世亲释】虚空周遍无染，不能分别，也不被分别。根本无分别智也是如此：遍一切法一味空性，所以周遍；一切法不能染，所以无染；自无分别，所以不能分别；也不被他人分别行相，所以不被分别。虚空中所现的色像可被分别，后得智也是如此，既是所分别，也能分别。

如果以无分别智修成佛果，已经远离功用、作意与分别，如何能成办利益安乐诸有情的事？有一颂：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">如末尼天乐<br>无思成自事<br>种种佛事成<br>常离思亦尔</div>

大意：如同如意宝珠和天乐，没有思虑而成就各自的事；种种佛事得以成就，常离思虑也是如此。

【世亲释】如意宝珠没有分别，能成办有情所乐的事；天乐没有人演奏，随生在彼处有情的意乐而出种种声音。诸佛菩萨的无分别智离开分别，也能成办种种事业。

关于无分别智的甚深，有一颂：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">非于此非余<br>非智而是智<br>与境无有异<br>智成无分别</div>

大意：无分别智不缘分别，也不缘分别以外的余境；不是智，又是智；与所缘之境没有差异，智成为无分别。

【世亲释】无分别智如果缘分别，就不能成为无分别；如果缘分别以外的余境，余境决定没有，如何能缘？根本无分别智不缘分别，因为无分别；也不缘余境，就是缘依他起诸分别法的真如法性为境界，因为法与法性不可说一，也不可说异。根本无分别智不决定是智，因为不像加行分别智那样生起；也不是非智，因为从加行分别智之因而生。根本无分别智不像加行智那样有所取、能取而转，与所取之境无差别而转，平等平等，称为无分别。

如同薄伽梵在其余契经中说一切法都无分别，为了显示无分别的意义，又说一颂：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">应知一切法<br>本性无分别<br>所分别无故<br>无分别智无</div>

大意：应当了知，一切法本性无分别，因为所分别的事无所有；有情不得解脱，是因为没有无分别智。

【世亲释】一切法本来自性无分别，因为所分别的事无所有。有情为什么本来不得解脱？因为“无分别智无”：一切法本来自性无分别，没有现证无分别理的真智生起，就不能解脱；真证智生起，现见诸法无分别之性，就得解脱。

四、三种无分别智的差别

其中，加行无分别智有三种，就是由因缘、由引发、由数习而生的差别。

【世亲释】由种姓的力量而生，是因缘；由前生数习的力量而生，是引发；由现在生中士用之力而生，是数习。

根本无分别智也有三种，就是喜足、无颠倒、无戏论无分别的差别。

【世亲释】喜足无分别：菩萨在异生地，闻思觉慧到达究竟，便生喜足，认为所闻所思到此为止；世间也有喜足无分别，比如有情到第一有，以为是涅槃，便生喜足。无颠倒无分别，是声闻等通达真如，得到无常等四种无倒智，没有常等四种颠倒的分别。无戏论无分别，是诸菩萨对一切法乃至菩提都无戏论，所证的真如超过名言之路、超越世间智的境界。

后得无分别智有五种，就是通达、随念、安立、和合、如意思择的差别。

【世亲释】通达思择，是通达时觉察“我已通达”。随念思择，是出观后随忆念说“我已通达无分别性”。安立思择，是为他人宣说所通达之事。和合思择，是以总缘之智观一切法同一相，由此进趣转依，或转依后又起此智。如意思择，是随所思一切如意，能变地等成为金等。

五、成立无分别智之颂

又有多颂，成立无分别智：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">鬼傍生人天<br>各随其所应<br>等事心异故<br>许义非真实<br>于过去事等<br>梦像二影中<br>虽所缘非实<br>而境相成就<br>若义义性成<br>无无分别智<br>此若无佛果<br>证得不应理<br>得自在菩萨<br>由胜解力故<br>如欲地等成<br>得定者亦尔<br>成就简择者<br>有智得定者<br>思惟一切法<br>如义皆显现<br>无分别智行<br>诸义皆不现<br>当知无有义<br>由此亦无识</div>

大意：饿鬼、傍生、人、天各随所应，对同一事物，心所见不同，所以许可义不是真实。缘过去事等、梦境、镜像与定中影像时，所缘不是实有，境相仍能成就。如果义真有义的自性，就没有无分别智；没有无分别智，证得佛果就不合道理。得自在的菩萨，由胜解的力量，随所欲令地等成为金等；得定的人也是如此。成就简择、有智慧、得定的人，思惟一切法，诸义都如所思而显现。无分别智现行时，诸义都不显现。应当了知没有义，由此也没有识。

【世亲释】傍生见为有水的地方，饿鬼见为陆地高原；人见为有粪秽的地方，猪等傍生见为净妙可居的室宅；人见为净妙的饮食，诸天见为臭秽不净。众生对同一事物，心所见不同，所以应当了知境义不是真实存在。“由此亦无识”：所识的境义既然无所有，能识也就没有。

六、般若与无分别智

般若波罗蜜多与无分别智没有差别。如经中所说，菩萨安住于般若波罗蜜多，以“非处”相应，能对其余波罗蜜多修习圆满。什么称为以非处相应而修习圆满？就是由于远离五种处：第一，远离外道的我执处；第二，远离未见真如菩萨的分别处；第三，远离生死与涅槃二边之处；第四，远离只断烦恼障就生喜足之处；第五，远离不顾有情的利益安乐、住于无余依涅槃界之处。

【世亲释】外道住于般若时，执我、我所，想“我能住般若，般若是我所”。未见真如的菩萨，对无分别的般若分别“这是般若波罗蜜多”。菩萨远离上述诸处，称为以非处相应安住于般若波罗蜜多。

七、声闻智与菩萨智的差别

声闻等的智与菩萨的智有什么差别？由五种相应当了知差别：第一，由无分别差别，因为对蕴等法没有分别。第二，由非少分差别，因为通达真如、入一切种所知境界、普为度脱一切有情，都不是少分。第三，由无住差别，因为以无住涅槃为所住。第四，由毕竟差别，因为在无余依涅槃界中没有断尽。第五，由无上差别，因为在菩萨智之上，没有其余的乘胜过菩萨智。关于声闻智与菩萨智的差别，有一颂：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">诸大悲为体<br>由五相胜智<br>世出世满中<br>说此最高远</div>

大意：以大悲为体，由五种相而殊胜的菩萨智，在世间与出世间的圆满之中，说是最高最远的。

八、菩萨为什么不令一切有情富足

如果诸菩萨成就上面所说的增上尸罗、增上质多、增上般若，功德圆满，对财位得到大自在，为什么现见有些有情缺乏财位？因为菩萨见到那些有情对财位有重大的业障；因为菩萨见到那些有情如果得到财位，会障碍善法的生起；因为菩萨见到那些有情如果缺乏财位，厌离心会现前；因为菩萨见到那些有情如果得到财位，就成为积集不善法的因；因为菩萨见到那些有情如果得到财位，就会成为损恼其余无量有情的因。所以现见有些有情缺乏财位。关于财位，有一颂：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">见业障现前<br>积集损恼故<br>现有诸有情<br>不感菩萨施</div>

大意：由于菩萨见到业障、障善、厌离现前、积集不善、损恼他人，现在有些有情不能感得菩萨的财施。

【世亲释】此中应引饿鬼临江的譬喻：江中有水，并不障碍人饮用，诸饿鬼由于自身的业障，不能得饮。江比喻菩萨，水比喻财位，饿鬼比喻有情；如同饿鬼不能饮用江中的净水，有业障的有情也不能受用菩萨的财位。
