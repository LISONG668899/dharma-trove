# 窥基《大乘法苑义林章》（四十五）三慧义林（中）·诸智相摄与法行

〔译注：本篇译《三慧义林》第六门"诸智相摄"与第七门"法行差别"。第六门把诸经论所说的各种智，从一智、二智、三智、四智，到六现观、十现观、十智、十三智、十六行、十八现观、四十四智、七十七智，一一配入闻、思、修三慧。第七门以《辩中边论》的十种法行配三慧，并驳正《大毗婆沙论》"受持读诵三藏只是生得慧"之说。原计划《三慧义林》分两篇，因篇幅较大，改为三篇。〕

## 第六门　与诸智相摄

### 一、一智：心法智

《胜鬘经》中说一种智，就是心法智。经中说厌苦、求涅槃的智慧，究竟位只是修慧，因为观察如来藏、厌离众苦；方便位通于闻慧、思慧两种。

### 二、二智

#### （一）圣谛智与无二圣谛智

《胜鬘经》又说两种智：一是圣谛智，二是无二圣谛智。这两种只是修慧：前一种是安立谛的智，后一种是非安立谛的智。经中说二乘以前一种谛智断除各种烦恼，诸佛世尊以无二圣谛智断除各种住地烦恼，所以不属于闻慧、思慧所摄。

#### （二）两种如来藏空智

《胜鬘经》又说有两种如来藏空智：

1. 空如来藏智：就是缘若离、若脱、若断、若异的烦恼藏的智慧。
2. 不空如来藏智：就是缘过于恒河沙数、不离、不脱、不断、不异的不思议佛法的智慧。

前一种观察烦恼能覆藏的智慧，因为烦恼不是真实的，称为空；后一种观察法身被烦恼所藏的智慧，因为理是真实的，称为不空。究竟成满，也只是修慧；方便位通于闻慧、思慧两种。

#### （三）世俗智与胜义智

又有两种：世俗智、胜义智。三慧都通于这两种。有人说前一种智只是有漏，后一种智只是无漏，因为诸教中只说是无漏。

### 三、三智

#### （一）三种无分别智

《杂集论》说有三种无分别智：

1. 知足无分别：只是思慧、修慧。说各种异生随于一种无常等法，究竟思惟以后，生起喜足。
2. 无颠倒无分别：只是修慧。说各位声闻在诸蕴中，为了除去四种颠倒，如理观察，得到出世间的智慧，能通达无我，是中等的智慧。
3. 无戏论无分别：只是修慧。说各位菩萨了知法的戏论，除泯法相，得到极为寂静的出世间圣智，是上等的智慧。

#### （二）三种无生忍智

又有三种无生忍智：本性无生忍、自然无生忍、惑苦无生忍。依次就是缘三性境界的各种无漏智，也只是修慧。

### 四、四智

#### （一）四智：大圆镜智等

又有四种智，就是大圆镜智等：

1. 大圆镜智、平等性智：决定只是修慧。
2. 妙观察智：有一种说法认为只是修慧；有一种说法认为通于三慧。
3. 成所作智：有一种说法认为只是修慧；有一种说法认为通于闻慧，因为承认十地中生起这种智。意义依前面推知。

#### （二）四无学智

又有四种智，就是"我生已尽、梵行已立、所作已办、不受后有"，依次就是苦、灭、道、集四种无学智。真实成满在定中生起，只是修慧；前面的方便位，也通于闻慧、思慧。只是诸教中多说是修慧，因为是根本。

#### （三）四寻思、四如实智

又，四寻思、四如实智，都只是修慧，因为是成满位。寻思只是有漏，如实智通于无漏。

### 五、五种巧便观察

《胜鬘经》说：随顺法智，就是五种巧便观察成就：

1. 观察施设根、意解、境界。
2. 观察业报。
3. 观察阿罗汉的眠。
4. 观察心自在乐、禅乐。
5. 观察阿罗汉、辟支佛、大力菩萨的圣自在神通。

这五种观察，究竟成满只是修慧；最初的方便位，也通于闻慧、思慧。那部经自己说："在我灭度以后的未来世中，我的弟子们随顺信心，信心增上，依于明白的信心，随顺法智，自性清净心被烦恼所染污，而得以究竟。这种究竟，是进入大乘道的因。"

### 六、六现观智

又有六种现观智：

1. 思现观：只是思慧。
2. 信现观：不是慧。
3. 戒现观：不是慧。
4. 现观智谛现观：修慧。
5. 现观边智谛现观：修慧。
6. 究竟现观：修慧。

这是依据自性来说。如果取同时运行的，随其所应，以菩提分法作为自性。

### 七、十现观

《杂集论》第十三卷说，现观有十种：

1. 法现观：是闻慧，因为多缘教法。
2. 义现观：是思慧，因为多缘道理。
3. 真现观：只是修慧，就是智谛现观。
4. 后现观：只是修慧，就是智谛边现观。
5. 宝现观：就是信现观，如前面所说。
6. 不行现观：就是戒现观，如前面所说。
7. 究竟现观：只是修慧，就是究竟现观。
8. 声闻现观、独觉现观、菩萨现观：后三种依乘而有差异，随其所应说是慧。

### 八、十智

《瑜伽师地论》第六十九卷说十种智：世俗智、法智、类智、苦智、集智、灭智、道智、尽智、无生智、他心智。

1. 世俗智：通于有漏、无漏，属于三慧所摄。
2. 中间八智：只是无漏，只是修慧。
3. 他心智：通于有漏、无漏，也只是修慧。

又有十力智，就是处非处智乃至漏尽智，只在如来的相续中才有，只是无漏，只是修慧。

### 九、十三智

《杂集论》第三卷说十三种智：信解智、道理智、不散智、内证智、他性智、下智、上智、厌患智、不起智、无生智、生智、究竟智、大义智。

那部论自己解释：

1. 前三种，就是三慧。
2. 第四种，是胜义智。
3. 第五种，是他心智。
4. 第六种，是法智。
5. 第七种，是类智。
6. 其次四种，是四谛智。
7. 究竟智，就是尽智、无生智。

以上前面这九种，只是修慧。大义智就是大乘智，通于三慧所摄，究竟位只是修慧。

### 十、四谛十六行智

又，《显扬圣教论》第十六卷等说：观察四谛，生起十六种行相的智慧，前者作为后后的所依止，就是为了对治除去四种颠倒。

1. 苦谛四行：
   - 为了除去常颠倒，生起无常行。
   - 为了除去乐、净颠倒，生起苦行。
   - 为了除去我颠倒，生起空行。
   - 也为了除去我颠倒，生起无我行。

   空行观察诸行的我性是空，因为这观行之外，其余的我是空；无我行观察诸行没有我，因为这观行的体性不是我性。这是两者的差别。
2. 集谛四行：其次对常、乐、净、我四种爱所集的集谛，生起因、集、生、缘四种行相。
3. 灭谛四行：其次对这集谛断灭的灭谛，生起灭、静、妙、离四种行相。
4. 道谛四行：其次对能证这灭谛的道谛，生起道、如、行、出四种行相。

这些都只是修慧，通于有漏、无漏；成满位中只是无漏修慧。

### 十一、十八现观

《显扬圣教论》第十七卷说，现观有十八种：

1. 闻所生智
2. 思所生智
3. 修所生智
4. 顺决择分智
5. 见道
6. 修道
7. 究竟道
8. 不善清净世俗智
9. 善清净世俗智
10. 胜义智
11. 不善清净行有分别智
12. 善清净行有分别智
13. 善清净行无分别智
14. 成所作前行智
15. 成所作智
16. 成所作后智
17. 声闻等智
18. 菩萨等智

依据实际，现观的体性只是修慧；闻慧等助成修慧，属于五种现观所摄。这里有五类：

1. 依五位的道，有七种智：闻慧等三慧，因为在顺解脱分中施设。
2. 依观察二谛的智，有三种：观察世俗的智，因为有善、不善两种境界的差异。
3. 依能缘的行相，有三种：因为有分别中有有漏、无漏两类的差异。
4. 依二空、二真的智，有三种：因为加行智、根本智、后得智的差别。
5. 依乘，有两种：因为声闻、菩萨大小不同。

### 十二、四十四智

《瑜伽师地论》第十卷说四十四种智：就是观察老死支有四种：一是老死苦，二是老死集，三是老死趣灭，四是老死趣灭行。乃至行支，都作这样的观察。无明没有因，因为缺少智的种类，所以不说观察无明支。

菩萨往昔在菩提树下，对杂染法顺逆观察缘起支，在逆观中作这样的观察，依最初的方便，所以诸论说"到识支就退还"。这些都只是修慧，到成就时是修慧的观察；最初观察的加行，也通于闻慧、思慧。示现异生之相，只属于有漏所摄，实际上是无漏。

### 十三、七十七智

那部论又说七十七种智：

1. 缘现在老死，有两种智：一是缘现在的生而有老死，二是没有不缘现在的生而有老死。因为是现在自身自己所作的。
2. 缘过去老死，有两种智：一是缘过去的生而有老死，二是没有不缘过去的生而有老死。观察前际无始的老死，没有不是以生为缘的。
3. 缘未来老死，有两种智：一是缘未来的生而有老死，二是没有不缘未来的生而有老死。未来还没有生起，也可以有杂染、还灭的意义，现在观察杂染，所以成为两种智。

这三际中，前一种智观察果有因，显示其由来；后一种智观察果有因，并非不决定，破除外道妄计不平等之因、无因而生。这前六种智，称为真实智。

4. 第七种是法住智，观察缘起支所不摄的法，因为各种有漏的慧遍知其义。通知三世缘起的教法，称为缘起支所不摄。依此可知，圣者身中也有法住智，异生身中也有真实智，因为观察教法、观察缘起支，生起七种智。

乃至行支也有这七种智。因为缺少智的种类，除去无明支。究竟观成，只属于修慧所摄；最初的加行位，也通于闻慧、思慧。

### 十四、其余诸智

《瑜伽师地论》又说各种神通智、解脱门智、无碍解智、无诤智、愿智、力、无所畏、念住、一切种智、不共佛法等智。

1. 前五种神通，通于有漏、无漏，因为说异生身以及圣者都能生起；后面的漏尽通只是无漏，因为属于尽智、无生智二智所摄。六种神通都是修慧。
2. 解脱门智只是无漏，属于修慧所摄，因为是解脱门。空解脱门属于八种智所摄，无愿解脱门属于六种智所摄，无相解脱门属于五种智所摄。
3. 无碍解智乃至不共佛法智，只是修慧，随其所应，通于有漏、无漏，因为在阿罗汉等以及如来身中。

## 第七门　法行的差别

### 一、十种法行

法行有十种。《辩中边论》第三卷的颂说：

「谓书写、供养，施、他听、披读，受持、正开演，讽诵及思修。行十法行者，获福聚无量；胜故无尽故，由摄他不息。」（大意：就是书写、供养、施与他人、听他人读诵、披读、受持、正确地开示演说、讽诵，以及思惟、修习。修行这十种法行的人，获得无量的福德聚，因为殊胜，因为无尽，由于摄受他人而不止息。）

### 二、《大毗婆沙论》的两种说法

《大毗婆沙论》第四十二卷：

有人这样说：如果对三藏、十二分教，受持、转读、究竟流布，称为闻所成慧；依此发生思所成慧；依此发生修所成慧；修所成慧断除烦恼，证得涅槃。就像依金矿生出金，依金生出金刚，金刚能摧坏山石等物。

评定说：应当这样说：如果对三藏、十二分教，受持、转读、究竟流布，是生得慧；依此发生闻所成慧；依此发生思所成慧；依此发生修所成慧；修所成慧断除烦恼，证得涅槃。就像依种子生芽，依芽生茎，依茎转生枝、叶、花、果。

### 三、依《瑜伽》的抉择

依《瑜伽师地论》第十三卷说："什么是闻所成地？简略来说，对于五明处的名、句、文身无量的差别，以觉慧为先，听闻、领受、读诵、忆念；又对那意义无颠倒地了解，这称为闻所成地。"

这里的意思是说："对于五明处的名、句、文身无量的差别，以觉慧为先"，是生得慧；"听闻、领受、读诵、忆念，又对那意义无颠倒地了解"，才称为闻慧。这就显示总相：

1. 对于五明的教法，低劣暗昧的觉慧所有的善心，称为生得慧。
2. 听闻以后，有差别作意、明了的善心，称为闻慧。

并不是一定要先对三藏的教法听闻、领受，都是生得慧：

1. 对于三藏，不用功力所生的暗昧低劣的觉慧善心，称为生得慧。不随顺出世间，不是功力所起，体性不明了，读解文字意义任运而起，称为生得慧。所以即使受持三藏等教法，也有生得慧。
2. 如果对于三藏，要用功力所生的明了殊胜的觉慧善心，称为加行善。能随顺出世间，由功力而起，体性极为明了，读解文字意义加行而起，称为闻慧。所以可知受持三藏等教法，也有闻慧。

不然的话，怎么会对于五明的教法，以觉慧为先，称为生得慧；听闻领受，称为闻慧？

### 四、《辩中边论》的说明

《辩中边论》说：

1. 闻所成慧思惟大乘，能令善根之界得以增长。
2. 思所成慧思惟大乘，能正确悟入所求的真实意义。
3. 修所成慧思惟大乘，能令所求的事业成满，就是能趣入、修治诸地。

这三种妙慧，以十种法行作为助伴，由十种法行所摄受：

1. 前八种法行，称为闻慧。
2. 第九种法行，称为思慧。
3. 第十种法行，属于修慧所摄。

由这三慧，在这大乘中修习各种法行，获得最大的果：一是最殊胜，二是无尽。由于能摄受利益其他有情，所以大乘说为最殊胜；由于即使证得无余涅槃，利益他人的事业恒常不止息，所以大乘说为无尽。

### 五、《法华经》的证明

《法华经》说："受持这部经，或者读，或者诵，或者解说，或者书写，这个人应当得到八百种眼功德，乃至一千二百种意功德。"

如果对三藏受持读诵只是生得慧，怎么会有修行十种法行、获得很多福聚，五种法师成就六千种功德？因为这是加行善法用力才生起、明了理解的心所应得到的。由此应当如大乘所说。
