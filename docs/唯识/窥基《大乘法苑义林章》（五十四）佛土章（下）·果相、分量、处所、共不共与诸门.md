<p class="dt-title">佛土章（下）·果相、分量、处所、共不共与诸门</p>

<div class="dt-subtitle">大乘法苑义林章白话译注（五十四）<br>唐　窥基　撰</div>

〔译注：本篇译《佛土章》后五门，也是《大乘法苑义林章》全书的最后一篇。

1. 果相：佛土不离识，四土分别配八识。
2. 分量：讲他受用土随十地所见逐渐扩大，有卢舍那与千百亿释迦的结构。
3. 处所：窥基破斥古人"三界之外别有净土处所"的说法，理由是所化众生必有异熟识，异熟识必属三界，净土"超过三界"是说净土不被三界所系，不是另有处所。
4. 共不共。
5. 诸门：依《佛地经》十种圆满（土主、辅翼、眷属、任持、事业、摄益、无畏、游路、所乘、入门），逐一说明四土的相状。〕

第四门　彰果相

《佛地经》说："以最极自在的清净识为相状。"《佛地论》解释说："以佛的无漏心作为体相，因为只有识，不是离开识以外另有佛土。"

1. 法性土，就是法性心。法性土不离开与无分别智相应的清净识，因为法性土是识的真实体性。
2. 自受用土、他受用土以及变化土，都不离开与佛后得智相应的清净识。

识有不同：

1. 自受用土，就是第八识。
2. 他受用土，就是第七识。
3. 变化土，就是前五识。

因为随其所应，都是与那后得智相应的识。

十地菩萨见到法性土以及他受用土，地前三乘见到变化土，都随其所应，不离开能见者有漏、无漏的能观清净识。所以这部经（《无垢称经》）说："如果想要勤修严净佛土，先应当方便严净自心。随着诸菩萨的自心严净，就得到这样的严净佛土。"天亲菩萨《金刚般若论》说："以智慧熏习通达唯识，这样摄取净土。"所以修习智慧的因，果位的识就清净；内在的识清净以后，外在感得的众生以及器世间的国土都清净，详细如经中所说。也随着能见者所应的识，如前面所说，依此类推了知。

第五门　释分量

一、法性土

《佛地论》《成唯识论》都说："法性土不属于色法所摄，不能说形量的大小。"依事相来说，法性土的量没有边际，譬如虚空遍满一切处。

二、自受用土

自受用土，《十地经》说："第十地菩萨得以生在大自在宫，有十种果相显现，有大宝莲花座，周圆的大小如十阿僧祇百千三千大千世界微尘的数量，超出第十地菩萨，菩萨坐在上面成正觉。"成佛以后，穷尽未来际，相续变现为纯净的佛土，周圆没有边际，众宝庄严，因为随顺法性土，量没有边际。

三、他受用土

他受用土随顺十地菩萨的所宜而显现，或小或大，或劣或胜，前后改转。

《梵网经》说："我现在是卢舍那佛，正坐在莲花座上，一朵莲花有百亿国土，一国有一位释迦。"

《摄大乘论》等说：

1. 初地菩萨悟入十百法门，见到一百个佛国土。
2. 一个佛国土是一个三千世界，一个三千世界有百亿个四天下，每一个四天下各有一位化佛，所以一个三千世界中有百亿位化佛。
3. 初地菩萨见到一百个百亿化佛，以及一位受用身佛。受用身佛坐在一座大宝莲花台上，莲花有一百叶，每一叶就是一个三千大千世界。
4. 一位受用身佛名叫卢舍那，一百个百亿化佛名叫释迦，不离开一位卢舍那佛身，有众多释迦。
5. 二地菩萨见到一位受用身佛坐在千叶莲花上，乃至第十地菩萨所见的佛极大，莲花叶没有边际。
6. 并且二地菩萨见到十个初地菩萨所见的受用身卢舍那，以及一千个百亿化身释迦，乃至十地菩萨见到无量个九地菩萨所见的受用身卢舍那，以及无量的化身释迦。

大千世界中佛的数目众多，都不离开释迦的化现，所以称为一佛所化。又，小乘中只说一尊佛，没有多个化身，也是随顺小乘的根机说一尊佛。

或者资粮道见到一个四天下有一位主佛，加行道中见到一个三千世界有一位主佛，初地以上渐渐增加。所以他受用土的量不确定。

四、变化土

变化土，或者是净，或者是秽，或者小，或者大，前后改转，也没有一定的限度，因为随顺众生所宜，一时显现。

1. 《无垢称经》中，佛足趾按地，大千世界成为清净。无垢称菩萨将要到来时，佛预先把毗耶离一城变为清净。
2. 宣说《法华经》时，最初变化大千世界，其次变化十方各二百万亿佛国，令其清净，后来又再次变化。

所以可知变化土的大小随时不定。

《璎珞经》说："毗卢舍那佛是法身，卢舍那佛是受用身，释迦牟尼佛是化身。"所以这样说。

第六门　解处所

一、法性土与自受用土

法性土就是真如理，没有别的处所。自受用土也充满法界，没有别的处所。

二、他受用土

他受用土，《佛地经》说："超过三界所行之处。"《佛地论》解释说："因为不被三界的爱所执受，离开相应缚、所缘缚二缚的随增，所以说超过三界。"所以属于道谛的善性所摄。

《佛地论》有三种解释：

1. 有一种说法认为：他受用土与三界处所各别，因为有地方说在净居天上，有地方说在西方等。
2. 有一种说法认为：他受用土与三界同处，因为净土周圆没有边际，遍满法界。
3. 如实的意义是：自受用土周遍法界，没有一处不在，不能说离开三界处，也不能说就在三界处。他受用土，或者在色界净居天上，或者在西方等，处所不确定。

《法华经》也说："众生见到劫尽、大火所烧的时候，我的这个国土安稳，天人恒常充满。"十地菩萨所见的，就是报土；地前所见的，就是化土，随所宜而显现，哪能决定一个方位，特别指定一处？为了令众生生起殊胜的欣乐心，特别指出处所。随着心清净之处，就是净土之处。

三、化土

化土必定随顺三界的处所，因为随众生受化而生，就显现化土。

四、破斥古人的说法

古人对此作种种分别，认为三界之外另有处所作为净土，道理上必定不是这样。所化的众生必定有异熟识存在，有异熟识存在，必定属于三界所摄，怎么能出离三界？净土不被三界所系，所以说"超过三界"，不是处所有区别，因为随顺所化的众生。

第七门　共不共

《成唯识论》说：

1. 法性土：一切如来同样所证，体性没有差别。
2. 自受用土：一切佛各自变现不同，都没有边际，互不障碍。
3. 其余两种佛土：随诸如来所化的有情，有共有不共。

所化众生是共的：在同一处、同一时，随其所应，诸佛各自变现为国土，形状相似，互不障碍，辗转相杂，作为增上缘，令所化的众生由自己的识变现，认为在一个国土中有一尊佛身，为自己显现神通，说法饶益。比如这个国土的众生，适宜听闻释迦、弥勒、弥陀，这些诸佛就共同变现。

所化众生是不共的：只有一尊佛变现。各类有情从无始以来，种性法尔互相系属，或者多位众生系属一尊佛，或者一位众生系属多尊佛。比如底沙佛令释迦菩萨超越九劫等。

所以所化的众生有共、有不共。如果不是这样，多尊佛长久住世，各自辛劳，实际上就没有利益，因为一尊佛就能利益一切众生。由此，变化土、他受用土有共、有不共。

第八门　诸门辨

这一门中有十种：

1. 土主
2. 辅翼
3. 眷属
4. 任持
5. 事业
6. 摄益
7. 无畏
8. 游路
9. 所乘
10. 入门

一、土主

《佛地经》说："如来所都。"就是各种佛土以诸佛为主，因为殊胜，不是其余众生所都，只属于世尊；或者只有世尊住持摄受，不是其余众生所能做到。

就是三种佛身各自在自己的国土中为主，不是其余的：

1. 法性土的体性只有一个，以法身为主。
2. 自受用土遍满法界，每一尊佛自己变现，各自为主，互不障碍。
3. 他受用土以及变化土，由诸佛变现，合为一个相状，也是一个相状的佛身，各自随其所应摄受为主，互不障碍。

二、辅翼

（一）法性土、自受用土没有辅翼

法性土以及自受用土，只有佛居住，没有辅翼。十地菩萨能分分证得，不是法身的辅翼，因为法身无相，所以不说。

（二）他受用土的辅翼

他受用土，《佛地经》说："诸大菩萨众所云集。"就是这种净土恒常有无量的大菩萨僧常来辅翼，所以没有怨敌能为违害。

诸佛的慈悲，在佛自己的识上，随顺菩萨所宜，显现粗或妙的国土。菩萨随着自己的善根和愿力，在菩萨自己的识上，显现相似于佛所生的净土相状。菩萨与佛各由自心分别变现，同在一处，形相相似，所以认为是一个国土，共同聚集在其中。

（三）十地菩萨所变净土是有漏还是无漏

《佛地论》说："这样十地菩萨所变现的净土，是有漏，还是无漏？"略有三种意义：

1. 有一种说法认为是无漏：由自己的无漏种子，以愿力资助，变生净土，在其中受用大乘法乐，能证真如，得到真实的无漏，恒常见到诸佛，所以属于道谛所收。
2. 有一种说法认为是有漏：就是自心中加行有漏的净土种子，以愿力资助，变生净土，在其中受用大乘法乐。第七地以前烦恼还会现起；十地修道中，烦恼障和所知障的种子还在；第八识的体性能执持这些种子，现前接受熏习，所以仍然是有漏，属于无记性所摄，不是无漏。又，有情不会有两个真实的身，身既然是有漏，所依的净土怎么会是无漏？所以只是有漏，属于苦谛所摄。
3. 如实的意义是：十地菩萨自心所变现的净土有两种：
   - 第八识所变现的，只是有漏，因为属于有漏第八识的相分所摄，是有漏身的所依。受到无漏善力的资熏，相状净妙，仍然是有漏。随加行等所显现的也是这样。
   - 如果随后得无漏心变现净土的影像，属于无漏识的相分所摄，从无漏善的种子生起，所以体性是无漏，属于道谛所摄。

（四）变化土的辅翼

变化土中三乘大众聚集，因为是二乘圣人、菩萨、凡夫所聚集。佛所变现的，只是无漏。其余众生所变现的：

1. 有一种说法认为只是有漏，因为无漏后得智不能变现净土的相状。
2. 有一种说法认为也有无漏，因为无漏后得智随着佛所变现的增上缘力，也能变现事相，道理上不相违背。

前一种解释比较好。

三、眷属

《佛地经》说："无量的天、龙、人、非人等恒常随从。"

1. 法性土、自受用土两种没有辅翼，因为无相，如前面所说。
2. 他受用土只有天、人作为眷属，没有其余的种类。

〔存疑：原文「虽超三界天等仍是三界摄故。净识如是。摄受变现为严净土。故不相违」，大意似是：他受用土超过三界，经中所说天、龙等名称仍属三界所摄；佛的清净识这样摄受、变现，作为严净国土的庄严，所以与"超过三界"不相违。〕

或者为了成熟所化的有情，示现这样的变化种类。比如为了调伏劫比拏王，佛化现无量转轮王众眷属围绕。或者佛自己化现，或者诸菩萨化作这一类众生，任持净土，庄严供养，引导他方众生随从如来。《无量寿经》也说："命命鸟等，都是阿弥陀佛所化作。"化现为二乘，庄严净土，也是这样。

变化土中，也以真实的天龙八部作为辅翼。

1. 他受用土中，菩萨是真实的，二乘、八部都是权宜示现，因为二乘、八部不是真实得以生在其中。
2. 变化土中，二乘、八部都是真实的，十地菩萨都是权宜示现的形迹，因为十地菩萨不应生在变化土，权宜示现化形生在其中。

四、任持

1. 法性土的佛，不需要任持。
2. 自受用土，以自己的法乐任持。
3. 他受用土，《佛地经》说："以广大法味的喜乐所任持。"十地菩萨以大乘法味的喜乐所任持。

食能令身体安住，是任持的意义。

有人问：他受用土已经超过三界，体性是无漏，能断除有漏，不应当称为食。

回答：法味是任持的因，所以也称为食。比如有漏法障碍无漏，有漏法能任持有漏，也得称为食。无漏也是这样，无漏能断有漏，无漏能任持无漏，为什么不是食？诸佛菩萨的后得妙智，能说、能受大乘法味，生起大喜乐；或者正体智受用真如之味，生起大喜乐，能任持身体令不坏，长养善法，所以称为食。

第七地以前仍然是分段生，不是不依靠段食、触食等四食。第八地以上以及一切佛不依靠段食，可以说依靠其余的食。各种论中说佛、八地以上依靠段食，是示现依止住食所摄。

如果是变化土，实际上依靠四食，也可以说依靠法味为食，比如听闻《妙法莲华经》，六十劫安住。

《无垢称经》下卷《菩提分品》说："既已餐了不死之法，又饮解脱之味。"以涅槃不死作为食，因为所证的妙境生起喜乐，可以称为食。能任持无漏，也给予"食"的名称，不相违背。这种食的体性，各种教法说法不同，详细如另外的章节以及《法华经疏》所说。

五、事业

1. 佛的法身，或者只是自利，作为二身的所依；或者通于自利、利他二利。
2. 自受用身只有自利。
3. 他受用身以及变化身，只属于利他，因为为他人显现。

《佛地经》说："为一切众生作一切义利。"佛处在寂定中，由于先前所修的加行和愿力，任运能为一切有情作一切义利。

1. 他受用土中，多说妙法，少作神通，为十地菩萨作义利。
2. 变化土中，多作神通，少说妙法，为三乘作一切义利。

六、摄益

自性身土以及自受用身土，已经断尽、圆满，不说摄益。

（一）他受用土的摄益

他受用土的摄益意义，《佛地经》说："灭除各种烦恼、灾横、缠、垢。"就是各种烦恼称为缠、垢，这些就称为各种灾横的因。烦恼、缠、垢在他受用土中没有，烦恼等所作的灾横在他受用土中也没有。

或者：

1. 烦恼：就是十种根本烦恼，三界见道、修道所断，合共有一百二十八种。
2. 缠有八种：无惭、无愧、昏沉、睡眠、掉举、恶作、嫉、悭。
3. 垢有六种：害、恨、恼、谄、诳、憍。
4. 灾横：就是烦恼等所发的业以及所得的果。

所知障中，种子称为烦恼，现起称为缠、垢。离开这两种，称为摄益。如世间的封主，不一定摄受封户，只要不为封户造成灾害，封户也说"封主摄益我"。这里也是这样。又，现前证得解脱烦恼、灾横、缠、垢的殊胜福智，所以称为摄益。

（二）化身土的摄益

化身土中的二乘圣者，依此类推也是这样。凡夫菩萨还没有永远断除烦恼，制伏现行，也称为摄益。地前称为损力益能，因为能转向圣道。

这各种位次：

1. 分别起的二障：在四十心中渐渐能够制伏，在四善根的加行道中能顿然伏尽，初地顿然断除，称为摄益。
2. 俱生的二障：在加行道中能渐渐伏除，十地随其所应能渐渐断除，初地以上能顿然伏尽，所以称为摄益。

七、无畏

内在有摄益，外在没有怖畏。法性身土、自受用身土、他受用身土以及变化身，早已没有怖畏。

《佛地经》说："远离众魔。"魔就是四魔，是怖畏的因，因为由四魔能生起各种怖畏。佛都没有四魔，所以没有怖畏。

1. 他受用土：十地菩萨离开粗的四魔，没有五种怖畏。烦恼魔、蕴魔、死魔，随着逐渐断除的位次，随其所应说明，意义可以了知。
2. 变化土：三乘圣者也能分分远离四魔。
   - 十住菩萨示现八相成道，能降伏天魔。
   - 加行道中也能制伏分别起的烦恼，离开烦恼魔。
   - 十住第四生贵住中，舍离生死，出离三界，所以分分离开死魔。
   - 进入初地时，分分离开分段死，也称为分分离开五蕴魔。

所以没有怖畏。

八、游路

（一）佛的游路

《佛地经》说："以大念、慧、行作为游路。"《佛地论》解释说：

1. 诸如来的大念，就是无分别智，因为由念安住真如理。无分别智是法性土所游的路。
2. 大慧，就是后得智，因为分别诸法的真谛、俗谛相状。后得智是两种受用土以及变化土的路。

这两种智都有造作净土的增上业用，所以都称为"行"；都通于生起净土，所以都称为"路"。

或者：

1. 大念行是自利行，因为向内摄持记忆，是法性土以及自受用土的路。
2. 大慧行是利他行，因为向外分别，是他受用土以及变化土的路。

（二）菩萨与三乘的游路

上面说的是佛。十地菩萨：大念是闻慧，大慧是思慧，大行是修慧。以这三慧随其所应，亲疏相互资助，作为有漏、无漏国土的路，因为三慧都通于有漏、无漏。

如果是变化土，地前三乘也以三慧作为游路。二乘的修慧也通于无漏。凡夫菩萨只以有漏的三慧作为游路。

九、所乘

驾御所乘，行在这条路上。《佛地经》说："以大止、妙观作为所乘。"止，就是三摩地、等持；观，就是般若慧。止、观平等运行，所以称为所乘。路是总的位次，位次中的止、观各别，称为所乘。

1. 佛的三身恒常乘止观，进入三种佛土。
2. 十地菩萨乘止观，进入他受用土。
3. 地前二乘，随其所应，也乘这种止观品进入净土。
4. 如果是化现的秽土，通以散心、定心的慧作为所乘；如果不是这样，就没有办法生在佛土。

十、入门

从那个门进入，驾御所乘从这个门进入。《佛地经》说："以大空、无相、无愿解脱作为所入之门。"解脱就是涅槃，缘涅槃的妙智称为门。或者无漏智也称为解脱，因为离开系缚。因为这三种门，进入净土。

（一）三门各入一种佛土

暂且有一种说法：

1. 因无相门，进入法性土，因为观察诸法无相，证得真如。
2. 因无愿门，进入自受用土，因为对三界没有愿求。
3. 因大空门，进入他受用土以及变化土，因为通达二我空，进入这两种国土。

（二）三门都入三种佛土

或者说三门都能进入三种佛土。论中说三门或者各别观察三种自性，或者每一门都能观察三种自性。

（三）菩萨与三乘的入门

以上说的是佛的门。

1. 诸菩萨因这三种无漏之门，进入他受用土。
2. 地前二乘，也因三种无漏门，或者有漏门，进入化土。
3. 凡夫菩萨只因这三种有漏的等持进入化土，不称为解脱门，因为不属于无漏所摄。

（四）结说

从道理上说，他受用土以及变化土都有事相的所乘、游路、入门等。为了令有情欣乐真实的功德，所以就修行来说明。

法性土以及自受用土，量都没有边际，不说另有事相的门等相状。他受用土既然有分限，都依莲花才得以建立。《佛地经》说："大宝莲花所建立。"《观无量寿经》也说"作悬鼓想""有莲花座"。化土不确定，或者有莲花，或者没有莲花，依照这个娑婆佛土没有莲花的情形可以了知。

（《佛土章》终）
