<p class="dt-title">大乘蕴界处义</p>

<div class="dt-subtitle">大乘法苑义林章白话译注（三十七）<br>唐　窥基　撰</div>

〔译注：《大乘蕴界处义》是全书第十八章，讨论五蕴、十二处、十八界。重点在第五门：窥基综合诸论，立出"十种五蕴"，即无漏善、加行善、生得善、不善、有覆无记、异熟无记、威仪无记、工巧无记、变化无记、自性无记十种，逐一配上百法中的心法、心所、色法、不相应行，说明各自包含多少法。窥基在章末自述："诸师对此缺而不论，后学之徒于是没有凭据。"〕

蕴界处义，用五门分别：

1. 辨名
2. 出体
3. 废立
4. 与百法相摄
5. 十种蕴等分别

第一门　辨名

先解释新旧译名，后解释意义上的名称。

一、新旧译名

（一）蕴

梵语"塞建陀"（skandha），唐语称为"蕴"。旧译称为"阴"（读于禁反），这个"阴"是荫覆的意思。如果说"荫"，梵本应当称为"钵罗婆陀"。依此，"阴"的读音应当是于今反，就是阴阳的阴。

近代诸师竞相作不同的解释。有人说"淡聚"称为"淡阴"，这种解释不对，依医方的说法，称为"淡饮"，不称为"阴"。还有其他不同的解释，不能具述。如果说阴气是万物所藏，就是聚集的意思，借来作比喻立名，大致可以通，不是正当的名目。

现在称为"蕴"。有人译为"众"，所以《法华经》说"五众之生灭"，这也不对，如果说"众"，梵本应当称为"僧伽"。有人译为"聚"，这也不对，如果说"聚"，梵本应当称为"曷罗陀"。

（二）处

梵语"阿野怛那"（āyatana），称为"处"。旧译为"入"，这也不对，如果说"入"，梵语应当称为"钵罗吠舍"。旧经也有译为"处"的，如空无边处等、阿练若处，都与现在相同。

（三）界

梵语"驮都"（dhātu），唐语称为"界"。有人译为"持"，偏依一种意义，没有穷尽道理。

二、意义上的名称

《俱舍论》说："聚集、生门、种族，是蕴、处、界的意义。"

（一）蕴是聚集的意义

蕴是聚集的意义，可以聚集十一种意义。所以《辩中边论》说："非一，以及总略、分段的意义，称为蕴。"该论解释说：

1. 非一的意义：如契经说："所有的色，无论过去、未来、现在，内、外，粗、细，劣、胜，远、近，这一切简略为一聚，称为色蕴。"由于这种聚集的意义，蕴的意义得以成立。

   《俱舍论》解释说：在这段经中，无常已经灭去的，称为过去；如果还没有生起的，称为未来；已经生起还没有谢落的，称为现在；自身称为内，其余的称为外，或者依处来辨别；有对碍的称为粗，无对碍的称为细；苦谛、集谛所摄的染污称为劣，不染污的称为胜；过去、未来称为远，现在称为近。乃至识蕴，应当知道也是这样。

2. 总略的意义：如经中说"这一切简略为总聚"。
3. 分段的意义：如经中说"称为色蕴"等，因为各别安立色蕴等的相状。

由此聚集的意义，蕴的意义得以成立。

《俱舍论》说：

1. 和合聚集的意义是蕴的意义，这是依内明的解释。
2. 又说荷负重担的意义，如世间说肩为蕴，因为物品聚集在肩上，这是依世俗的解释。
3. 又说可以分段的意义是蕴的意义，所以世间有话说："你还我三蕴，我当给你。"这是依声论的解释。

考察《俱舍论》的三种解释，与《辩中边论》所说"非一以及总略、分段的意义称为蕴"，意思相同。

又解释蕴有两种意义：一是聚集的意义，二是灭的意义。所以《毗昙》说："阴是聚集的意义。"

（二）处是出生的意义

旧译"十二入"，"入"是杀的意义；现在称为"处"，是出生的意义，因为是出生六识之门的处所。

（三）界是种族、种子的意义

十八界，《俱舍论》说："种族的意义是界的意义。"大乘解释名称：种子的意义称为界。所以《辩中边论》说："非一，以及总略、分段的意义，称为蕴；能取、所取、能取所取的种子的意义，称为界；能受用、所了别的境界作用之门的意义，称为处。"

第二门　出体

五蕴的体性只是有为，因为是积聚的。《俱舍论》说："蕴不摄无为，因为意义不相应。"又《毗昙》说："阴是死法，只摄有为。"在三性之中是依他起性，因为谈的是有法，不是遍计所执；因为通于无漏，也是圆成实。在五法之内，体性就是前四种，只除去如如。

十二处、十八界，通以有为、无为作为体性，总摄五法以及依他起、圆成实二性，除去遍计所执性，因为遍计所执没有体性。

第三门　废立

有两门：一是总的废立三科，二是各别废立五蕴、十二处、十八界等。

一、总的废立三科

《俱舍论》说："因为愚、根、乐三种，所以说蕴、处、界三科。"该论自己解释说：

1. 愚：或者有人愚于心所，总执为我；或者只愚于色；或者愚于色和心。
2. 根：也有三种，就是利根、中根、钝根。
3. 乐：也有三种，就是乐于简略、中等以及广博的文句。

依次世尊说为蕴、处、界三科。

《瑜伽师地论》第九卷废立离合三科，颂说：

「随增说我事，为依、此所行，生、持、分广略，无别根、所缘。」（大意：随着增上，说五种我事立为五蕴；为了所依和所行的境界，立十二处；就生起、任持、分别的广略，立十八界；没有另外的根和所缘。）

以上总废立完毕。这首颂文下面自然会了知。

二、各别的废立

（一）五蕴

"随增说我事"，就是废立五蕴。《杂集论》说："为什么蕴只有五种？为了显示五种我事，就是身具我事、受用我事、言说我事、造作一切法与非法的我事、那些所依止的我自体事。"依次配合解释五蕴，不减也不增。

又《俱舍论》说："随着粗、染、器等、界的差别，依次而立。"这也是废立，也是先后的次第。论中说：

1. 随粗：色有对碍，所以在诸蕴中最粗。无色法中，受的行相粗，所以世间说"我的手痛"。比起受，想粗，因为男女等想容易了知。行比识粗，因为贪、嗔等的行相容易了知。识最为细微，因为总取境界的相状，难以分别。
2. 随染：或者从无始生死以来，男女对色互相爱乐，这是由于耽着乐受的滋味；耽爱又从颠倒的想而生；这颠倒的想由于烦恼而生；这样的烦恼依识而生。这识以及前三蕴，都是染污的识。由此随着染污，立五蕴的次第。
3. 随器等：或者色如器皿，受类似饮食，想如同助味的调料，行好像厨人，识比喻食者。所以随着器等立五蕴的次第。
4. 随界：或者随着界的差别立五蕴的次第。就是欲界中有各种妙欲，色的相状显了；色界的静虑有殊胜的喜等，受的相状显了；三无色界中取空等相，想的相状显了；第一有（有顶）中思最为殊胜，行的相状显了。这就是识住，识住在其中，显示好像世间田地和种子的次第。

所以诸蕴的次第是这样，由此五蕴没有增减的过失。

（二）十二处

处界的次第，颂说：

「前五境唯现，四境唯所造，余用远、速、明，或随处次第。」（大意：前五根的境界只是现在，前四根的境界只是所造色；其余依作用的远、速、明了来排列，或者随着处所的次第。）

〔译注：原文此处注云"恐繁不能别释"，窥基未展开解释。〕

（三）十八界

依《杂集论》第一卷废立十八界说："由于身、具等，能持过去、现在六种行受用性。"

该论解释说："身，就是内在的六根；具，就是外在的六境；过去、现在六种行受用性，就是六识。能持，就是六根、六境，因为能持六识的所依和所缘；过去、现在的六识，能持受用而不舍自己的相状。"应当知道，十八界以能持的意义，所以称为界。

问：为什么处只有十二种？

答：只由于身和具，能为未来六种行的受用作生长之门。所说的"只"，是简除六识。

第四门　与百法相摄

一、五蕴摄百法

1. 色蕴中摄十一种色。
2. 受蕴摄遍行中的受心所。
3. 想蕴摄遍行中的想心所。
4. 行蕴摄相应的心所四十九法，以及不相应行二十四法，合计七十三法。
5. 识蕴只摄八种心法。

总共摄九十四法，只除去六种无为。所以《俱舍论》说："蕴不摄无为，因为意义不相应。"

二、十二处摄百法

1. 内五处、外五处，摄十种色。
2. 意处摄八识。
3. 法处摄四类法：色法中法处所摄的色有五种，相应法有五十一种，不相应法有二十四种，无为法有六种，合计有八十六法。

三、十八界摄百法

只是开意处，立为六识界，其余的都与处相同。

第五门　十种五蕴的分别

没有一处经论具足说明，总的考究诸论，也可以具足立出十种五蕴：

1. 无漏善蕴
2. 加行善蕴
3. 生得善蕴
4. 不善蕴
5. 有覆无记蕴
6. 异熟无记蕴
7. 威仪无记蕴
8. 工巧无记蕴
9. 变化无记蕴
10. 自性无记蕴

一、无漏善五蕴

无漏的色蕴，有人说只有定所生的色，是色蕴的少分，没有五根等。正义是都具足。《涅槃经》说："舍弃无常的色，获得常住的色。"《胜鬘经》说："如来妙色身。"《佛地经》说："有五种法摄大觉地。"《成唯识论》第十卷、《佛地经论》说："如来的功德，属于蕴、处、界所摄。"这样的确实证文不止一处，不能繁引。下面都依此推知。所以五蕴法都通于无漏。

在百法中，总共有七十法通于无漏：

1. 心法：八识，是识蕴的体性。
2. 心所法：有二十三种通于无漏，就是五遍行、五别境、十一善、不定中的二种，就是寻、伺。
3. 色法：有十一种，就是五根、五境，以及法处所摄的圣所爱戒，以及定自在所生的色。
4. 不相应行：取二十二种，除去无想定、无想事。除去异生性，取非得；如果取异生性，就只是有漏。
5. 无为：有六种，都只是无漏，因为依真如假立。

《杂集论》说："虚空、非择灭是胜义无记"，也是随转门。

二、加行善五蕴

有五十二法：

1. 心法：有六种，除去第七、第八识，因为在因位中第七、第八识只是无记，到转依位就是无漏。
2. 心所法：有二十五种，就是遍行、别境各五种，善十一种，不定四种。
3. 色法：有三种，因为色、声两种表业由加行善心所发起；以及定共戒，以及一部分散心的无表，是加行善。
4. 不相应行法：有十八法，除去命根、众同分、无想天，以及名、句、文身。

《杂集论》说："五蕴的一分是善。"又说："加行善，就是依止善丈夫，听闻正法，修习清净的善法，法随法行。"《瑜伽师地论》第五十四卷说："威德定所生的色，也通于有漏。"这些总的是说，由闻慧等所发起的身语、定境的色等，作为色蕴的体性，所以通于五蕴。

三、生得善五蕴

总共以四十九法为体性：

1. 色蕴中有三种：就是色、声两种表业，以及法处中散心无表的一分。
2. 心所法：有二十四种，就是遍行、别境、善十种（除去轻安），以及四种不定。
3. 不相应行：十六种，除去命根、众同分、三种无心，以及名、句、文身。
4. 识蕴中取六识，除去第七、第八识。

所以《杂集论》说："生得善，就是前面所说发起善的身语等，由于先前串习，感得这样的果报……"乃至广说，与信等同时任运生起。这个意思是说：以宿世的串习为因，生得善心所发起的身语，作为色蕴的体性。

四、不善五蕴

以六十五法为体性：

1. 色蕴只有三种：就是色、声两种表业，以及法处的不律仪无表。
2. 心所法中有四十种：遍行、别境，以及六种根本烦恼、二十种随烦恼、四种不定。
3. 识蕴中取六识，除去第七、第八识。
4. 不相应行中取十六种：就是得、非得、四相，以及后面的十种。

五、有覆无记五蕴

有五十四法：

1. 色蕴只有两种：就是身表、语表，因为梵天在释子面前执手行诳。
2. 心法有七种，除去第八识，因为其余七识通于有覆。
3. 心所法有二十九种：就是遍行、别境，以及根本烦恼五种（除去嗔）；随烦恼有十一种，除去忿等七种以及无惭、无愧二种；不定中取三种，只除去恶作。
4. 不相应法取十六种：就是得、非得、四相，以及后面的十种。

《杂集论》第四卷说："如果欲界所系的分别烦恼、随烦恼，是不善；如果任运生起的一切烦恼，发起恶行的，也是不善；其余的都是有覆无记。"所以五蕴的一分是有覆性。不善五蕴依此推知。

六、异熟无记五蕴

1. 色蕴有十种：就是五根、五境，只除去法处色，因为法处色不是异熟。

   《杂集论》说八界、八处是无记，是依全分来说。现在取色、声，是依可能有的情况来说。声也通于异熟，依《菩萨地》，由于常行爱语、如语、谛语，感得大士的梵音声相，与其余的相好一样通于异熟。说声属于第三、第五转的，是随转小乘，因为小乘说声不是异熟。色蕴的十种都通于异熟。

2. 心法通于七识，只除去末那识。
3. 心所法取十一种：就是遍行、别境，以及不定中取睡眠，除去其余三种。
4. 不相应法取二十二种，只除去无想定、灭尽定二种定。

七、威仪无记五蕴

《杂集论》说："就是怀着非染非净的心所发起的威仪路。"有三十九法：

1. 色蕴中有四种：就是色、香、味、触。
2. 心法中有五种：就是意识缘威仪而发起，眼、鼻、舌、身四识缘威仪。因为声不是威仪，所以不说耳识。如果第八识缘四尘，也可以称为缘威仪。萨婆多部另外立似威仪心，就总共有六识，作为威仪路的识蕴。
3. 心所法有十四种：遍行五种、别境五种，以及不定四种。
4. 不相应法有十六种：就是得、非得、四相，以及后面的十种。

八、工巧无记五蕴

《杂集论》说："就是怀着非染非净的心所发起的工巧处。"是无记性的法，有四十二法：

1. 色蕴中有五种：身的工巧是四尘的体性，语的工巧就是声。
2. 心法取七识，只除去末那识：发起工巧的是第六意识，缘工巧的是五识以及第八识。
3. 心所法取十四种：遍行、别境，以及不定四种。
4. 不相应取十六种：得、非得、四相，以及后面的十种。

九、变化无记五蕴

《瑜伽师地论》第三卷说："变化有两种：一是善，二是无记。"说定境的色也通于无漏。第五十三卷说："如果依殊胜的禅定，对一切色都得到自在，诸定的加行令其现在前。"第九十八卷说："神通不能变化四种事，就是根等。"由此只有法处的色、声、香、味、触五种，作为色蕴的体性。如果为了利乐有情，就是善性，属于前两门所摄。《瑜伽师地论》说欲界也有各种变化，这些变化通于三性；生得的变化不是神通的果，假如是无记的，属于异熟生所摄。

这种变化蕴有三十五法：

1. 色蕴取五尘，兼取法处色。
2. 心法只取一种，就是第六意识。
3. 心所法有十二种：就是遍行、别境，以及不定中的寻、伺。
4. 不相应行有十六种：得、非得、四相，以及后面的十种。

十、自性无记五蕴

有四十七法：

1. 色蕴中有五尘，就是外在的器世界，以及长养的五种。既然不是前四种无记，所以称为自性无记。
2. 心法只取两种，就是第六、第七两识。
3. 心所法有十种，就是遍行、别境。二乘生起法执，不障碍二乘的果，所以不是染污，是自性无记。
4. 不相应行有十六种，依前面应当了知。

依《瑜伽师地论》第三卷，说无记有四种，没有这种自性无记。《成唯识论》也说："法执不障碍二乘，所以属于异熟生所摄。"依《瑜伽师地论》第六十六卷，说无记有五种：前四种如前面所说，再加上第五种自性无记，就是"各种色根中属于长养的、外在的各种色处、不属于异熟等所摄的，都称为自性无记，除去善、染污的色处、声处"。

考察这段文，只说色蕴是自性无记性，没有说其余四蕴通于自性无记。现在解释：其余四蕴也通于自性无记，如二乘等所生起的法执，是异熟生，也称为自性。异熟生有两种：一是业所感的，二是从业而生的。所以《本地分》第三卷说四种无记，已经摄尽了自性；第六十六卷中开出第五种，是因为从业而生的，体性不是异熟，立为自性。前后两处文字并不乖违，所以五蕴法都通于自性无记。

诸师对此缺而不论，后学之徒于是没有凭据。

（《大乘蕴界处义》终）
