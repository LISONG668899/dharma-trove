一、颂文与随烦恼的三类

前面已经说完六种根本烦恼的相状。外人质问：一切随烦恼的相状是怎样的？世亲菩萨用颂回答：

```
随烦恼谓忿　恨覆恼嫉悭
诳谄与害憍　无惭及无愧
掉举与惛沉　不信并懈怠
放逸及失念　散乱不正知
```

大意：随烦恼有忿、恨、覆、恼、嫉、悭、诳、谄、害、憍、无惭、无愧、掉举、惛沉、不信、懈怠、放逸、失念、散乱、不正知二十种。

论中解释：随烦恼只是根本烦恼的分位差别，或是根本烦恼的等流，所以称为随烦恼。

二十种随烦恼分为三类。忿等十种，各自单独生起，称为小随烦恼。无惭、无愧两种，遍于一切不善心，称为中随烦恼。掉举等八种，遍于一切染污心，称为大随烦恼。

【译注】三类的划分标准是“遍”的范围：小随烦恼互不同起，各自为主；中随烦恼遍于一切不善心；大随烦恼遍于一切染污心，连有覆无记的末那识也有。

二、十种小随烦恼

什么是忿？面对现前不利于自己的境界，愤然发作，是忿的自性；能障碍不忿，作为执持刀杖的所依，是忿的作用。心怀忿怒的人，多发起暴恶的身体行为。忿以瞋的一分为体，因为离开瞋，没有另外的忿的相状和作用。

什么是恨？由忿在先，怀着恶意不舍，结成怨仇，是恨的自性；能障碍不恨，令人热恼，是恨的作用。结恨的人不能含忍，恒常热恼。恨也以瞋的一分为体，因为离开瞋，没有另外的恨的相状和作用。

什么是覆？对自己所造的罪，恐怕失去利养和名誉，隐藏起来，是覆的自性；能障碍不覆，令人悔恼，是覆的作用。隐藏罪过的人，后来必定悔恼不安。

关于覆的体，有两家主张。第一家认为：覆是痴的一分，因为论中只说覆是痴的一分；不畏惧将来的苦果，所以隐藏自己的罪。第二家认为：覆是贪和痴的一分，因为也是恐怕失去利养名誉而隐藏自己的罪。论中依粗显的相状，只说是痴的一分，如同论中说掉举是贪的一分；论中又说掉举遍于一切染心，不可执着掉举只是贪的一分。

什么是恼？由忿和恨在先，追想过去的恶事，接触现前违逆的缘，暴躁炽热，乖戾，是恼的自性；能障碍不恼，如毒虫螫人，是恼的作用。追想往事的恶，接触现前违逆的缘，心就乖戾，多发出嚣张暴躁、凶狠鄙陋的粗言，如毒虫螫人。恼也以瞋的一分为体。

什么是嫉？追求自己的名利，不能容忍他人的荣耀，妒忌，是嫉的自性；能障碍不嫉，令人忧戚，是嫉的作用。嫉妒的人，听见或看见他人的荣耀，深怀忧戚，不得安稳。嫉也以瞋的一分为体。

什么是悭？耽着财物与佛法，不能惠施，隐秘吝惜，是悭的自性；能障碍不悭，鄙陋地积蓄，是悭的作用。悭吝的人心多鄙陋苦涩，积蓄财物和佛法，不能舍出。悭以贪的一分为体。

【译注】“财法”包括财物和佛法：不肯施舍财物是财悭，不肯传授佛法是法悭。

什么是诳？为了获得利养名誉，假装有德，诡诈，是诳的自性；能障碍不诳，作为邪命的所依，是诳的作用。矫饰欺诳的人，心怀别的图谋，多现出不实的邪命之事。诳以贪和痴的一分为体。

什么是谄？为了笼络他人，假装出种种仪态，阴险曲折，是谄的自性；能障碍不谄，令人不受教诲，是谄的作用。谄曲的人，为了笼络、蒙蔽他人，曲意顺从时宜，假设方便，或者为了讨取他人的心意，或者为了掩藏自己的过失，不能接受师友正确的教诲。谄也以贪和痴的一分为体。

【译注】诳与谄的区别：诳是假装自己有德，向人炫耀；谄是假意顺从他人，讨人欢心。一个是装高，一个是装低。

什么是害？对一切有情，心中没有悲悯，损恼他人，是害的自性；能障碍不害，逼迫恼害他人，是害的作用。有害心的人逼迫恼害他人。害也以瞋的一分为体。瞋与害的区别，可以依照善心所中无瞋与不害的区别来说明。

什么是憍？对自己兴盛的事，深生染着，陶醉傲慢，是憍的自性；能障碍不憍，作为染污法的所依，是憍的作用。憍醉的人生长一切杂染法。憍以贪的一分为体。

【译注】憍与慢的区别：慢是与他人比较而自高；憍是不与他人比较，只是对自己的盛事沉醉。

三、两种中随烦恼：无惭、无愧

什么是无惭？不顾及自身和正法，轻视拒斥贤人和善法，是无惭的自性；能障碍惭，生长恶行，是无惭的作用。对自身和正法无所顾及的人，轻视拒斥贤人和善法，不以过失和恶行为耻，障碍惭，生长一切恶行。

什么是无愧？不顾及世间，崇重暴恶，是无愧的自性；能障碍愧，生长恶行，是无愧的作用。对世间无所顾及的人，崇重暴恶，不以过失和罪行为耻，障碍愧，生长一切恶行。

不以过失和恶行为耻，是无惭和无愧共通的相，所以诸圣教假说为二者的体。如果执着不耻是二者各自的相，二者的体就应没有差别，二者就不应同时生起，因为受、想等心所之间没有体相同而相应的道理。如果依不顾自和不顾他立二者的差别，二者就应不是实有，就违背了圣教。如果承认二者实有而各别生起，就又违背了论中所说二者都遍于一切不善心。

不善心生起时，无论缘取什么境，都有轻拒善和崇重恶的含义，所以无惭和无愧都遍于不善心，所缘没有不同，没有各别生起的过失。

诸圣教说“不顾自他”，“自”指自身和正法，“他”指世间。或者，轻拒善、崇重恶，对自己损害，称为“自”；对他人损害，称为“他”。

论中说无惭和无愧是贪等的一分，是说无惭和无愧是贪等的等流，不就是贪等本身。

四、大随烦恼：掉举与惛沉

什么是掉举？令心对境不寂静，是掉举的自性；能障碍行舍和奢摩他，是掉举的作用。

关于掉举的体，论中列出三家。

第一家认为：掉举是贪的一分，因为论中只说掉举是贪的一分，掉举由回忆过去的乐事而生起。

第二家认为：掉举不只属于贪，因为论中说掉举遍于一切染心。掉举的相是不寂静，论中说不寂静属于烦恼的共相，离开不寂静，掉举没有另外的相。掉举依一切烦恼假立，在贪时最为增盛，所以说是贪的一分。

第三家，即护法论师，认为：掉举另有自性，遍于一切染心，如同不信等。论中说是其他烦恼的一分，体不因此就不是实有，否则不信等也应是假有。论中说掉举是世俗有，如同睡眠等，是随着其他法的相而说。掉举的别相就是嚣动，令同时俱起的心法不寂静。如果离开烦恼，掉举没有另外的相，论中就不应另外说掉举障碍奢摩他。所以“不寂静”不是掉举的别相。

什么是惛沉？令心对境没有堪任能力，是惛沉的自性；能障碍轻安和毗钵舍那，是惛沉的作用。

关于惛沉的体，论中也列出三家。

第一家认为：惛沉是痴的一分，因为论中只说惛沉是痴的一分，昏昧沉重是痴的相。

第二家认为：惛沉不只属于痴。没有堪任能力是惛沉的相，一切烦恼都没有堪任能力，离开无堪任，没有另外的惛沉之相。惛沉依一切烦恼假立，在痴的相增盛时，只说是痴的一分。

第三家，即护法论师，认为：惛沉另有自性，称为痴的一分，是指惛沉是痴的等流，如同不信等，不就是痴。论中随着其他法的相，说惛沉是世俗有，如同睡眠等，实际上是实有的。惛沉的别相就是瞢重，令同时俱起的心法没有堪任能力。如果离开烦恼，没有另外的惛沉之相，论中就不应另外说惛沉障碍毗钵舍那。所以“无堪任”不是惛沉的别相。

惛沉与痴的差别：痴对境界以迷暗为相，正障碍无痴，不是瞢重；惛沉对境界以瞢重为相，正障碍轻安，不是迷暗。

【译注】奢摩他是止，毗钵舍那是观。掉举是心浮动不定，障止；惛沉是心沉重昏昧，障观。修定时一浮一沉，正是止观的两大障碍。痴是“看不清”，惛沉是“提不起”，两者不同。

五、大随烦恼：不信、懈怠、放逸

什么是不信？对实有、有德、有能，不忍可、不喜乐、不希欲，令心污秽，是不信的自性；能障碍净信，作为懈怠的所依，是不信的作用。不信的人多懈怠。

不信的三种相，与信的三种相相反，可以了知。一切染法各有自己的别相，唯有不信的自相浑浊，又能令其余的心王与心所浑浊，如同极其污秽的东西，自己污秽，又污秽别的东西，所以说不信以心秽为自性。由于不信，对实有、有德、有能，不忍可、不喜乐、不希欲，“不忍乐欲”不是不信另外的体性。如果对其余的事邪误地忍可、喜乐、希欲，是不信的因或果，不是不信的自性。

什么是懈怠？对修善断恶的事懒惰，是懈怠的自性；能障碍精进，增长染污，是懈怠的作用。懈怠的人滋长染污。

对一切染污的事策励勤奋，也称为懈怠，因为退失了善法。对无记的事策励勤奋，对一切善品没有进退，是欲和胜解，不是另外的体性。如同对无记事的忍可和乐欲，既非清净也非染污，既不是信也不是不信。

【译注】勤于作恶，在唯识中算是懈怠，因为在善法上退步了。勤于学技艺等无记事，既不算精进也不算懈怠，只是欲和胜解在起作用。

什么是放逸？对染法与净法不能防恶修善，放纵荡逸，是放逸的自性；障碍不放逸，作为增恶损善的所依，是放逸的作用。

由于懈怠和贪、瞋、痴，不能防恶修善，总称为放逸，放逸没有另外的体。慢、疑等也有不防修的能力，比起懈怠和贪瞋痴四法，势用微弱；四法障碍三善根和普遍策励的精进。推究放逸的相，如同不放逸。

六、大随烦恼：失念、散乱、不正知

什么是失念？对一切所缘不能明白记忆，是失念的自性；能障碍正念，作为散乱的所依，是失念的作用。失念的人心散乱。

关于失念的体，论中列出三家。第一家认为：失念是念的一分，因为论中说失念是与烦恼相应的念。第二家认为：失念是痴的一分，因为《瑜伽师地论》说失念是痴的一分，痴令念丧失，所以称为失念。第三家，即护法论师，认为：失念是念和痴两者的一分，因为前面两处论文是互相省略的说法；论中又说失念遍于一切染心。

什么是散乱？对一切所缘，令心流荡，是散乱的自性；能障碍正定，作为恶慧的所依，是散乱的作用。散乱的人发起恶慧。

关于散乱的体，论中列出三家。

第一家认为：散乱是痴的一分，因为《瑜伽师地论》说散乱是痴的一分。

第二家认为：散乱属于贪、瞋、痴，因为《集论》等说散乱是三者的一分。论中说散乱是痴的一分，是因为痴遍于一切染心。贪、瞋、痴令心流荡，胜过其余的法，所以说为散乱。

第三家，即护法论师，认为：散乱另有自体。论中说散乱是三者的一分，是指散乱是三者的等流，如同无惭等，不就是三者本身。论中随着其他法的相，说散乱是世俗有。散乱的别相就是躁扰，令同时俱起的心法都流荡。如果离开贪瞋痴三者，散乱没有另外的自体，论中就不应另外说散乱障碍三摩地。

外人质问：掉举与散乱两者的作用有什么区别？

论主回答：

```
彼令易解，此令易缘。
```

大意：掉举令心的理解不断改变，散乱令心的所缘不断改变。

一刹那中，理解和所缘都不改变；在相续之中，就有改变的意义。染污心时，由掉举和散乱的力量，应当念念改变理解、改变所缘；或者由于念等的力量所制伏，如同系住的猿猴，有暂时安住的时候。所以掉举和散乱都遍于一切染心。

【译注】掉举是心在同一个对象上“想法”跳来跳去，散乱是心从一个对象跑到另一个对象。一个是对象不变而念头动，一个是对象本身在换。

什么是不正知？对所观察的境，错误理解，是不正知的自性；能障碍正知，令人毁犯，是不正知的作用。不正知的人多有毁犯。

关于不正知的体，论中列出三家。第一家认为：不正知是慧的一分，因为论中说不正知是与烦恼相应的慧。第二家认为：不正知是痴的一分，因为《瑜伽师地论》说不正知是痴的一分，令知不正，所以称为不正知。第三家，即护法论师，认为：不正知是慧和痴两者的一分，因为前面两处论文是互相省略的说法；论中又说不正知遍于一切染心。

七、二十之外的随烦恼

颂中的“与”“并”“及”等字，显示随烦恼不只二十种，因为《杂事》等经说有贪等多种随烦恼。

“随烦恼”的名称也包括根本烦恼，因为根本烦恼是前面烦恼的等流。与烦恼同类的其余染污法，只称为随烦恼，因为不属于根本烦恼。

只说二十种随烦恼，是因为二十种随烦恼不是根本烦恼，只是染污，又粗显。其余的染法，或者是二十种的分位，或者是二十种的等流，都包括在二十种之中，随其类别，应依道理了知。

八、随烦恼的假实与俱生分别

二十种随烦恼中，小随烦恼十种和大随烦恼中的放逸、失念、不正知三种，决定是假有。无惭、无愧、不信、懈怠，决定是实有，因为有教证和理证成立。掉举、惛沉、散乱三种，有一家认为是假，有一家认为是实，所引的理证和教证如前所说。

二十种随烦恼都通于俱生和分别起，因为随着两种根本烦恼的势力而生起。

九、随烦恼的互相相应与诸识

二十种随烦恼中，小随烦恼十种之间决定不同时俱起，因为互相违背，行相粗猛，各自为主。

中随烦恼两种，与一切不善心俱起，随其所应，都可以与小随烦恼和大随烦恼同时俱起。

论中说大随烦恼八种遍于一切染心，所以与小随烦恼和中随烦恼都可以同时俱起。

有些地方说六种遍于染心，是因为惛沉和掉举增盛时不同时俱起。有些地方只说五种遍于染心，是因为惛沉、掉举等违背唯善之法。

随烦恼只是染污，所以不与第八识俱起。第七识中只有八种大随烦恼，取舍的差别如上所说。与第六识俱起的，可以有一切随烦恼。小随烦恼十种粗猛，五识中没有。中随烦恼和大随烦恼通于粗细，五识中可以有。

十、随烦恼与诸受、别境、根本烦恼

由此，中随烦恼和大随烦恼与五受相应。

关于小随烦恼与诸受的关系，有两家主张。第一家认为：小随烦恼十种中，除去谄、诳、憍三种，忿等七种只与喜、忧、舍三受相应；谄、诳、憍三种，与苦受以外的四受俱起。第二家认为：忿等七种与乐受以外的四受俱起；谄、诳、憍三种与五受都俱起，因为意识有苦受，前面已经说过。随烦恼与诸受俱起的相状，如同根本烦恼所说。

以上是实义。依粗显的相状而说：忿、恨、恼、嫉、害，与忧、舍俱起；覆、悭，与喜、舍俱起；其余诳、谄、憍三种，再加上乐受。中随烦恼和大随烦恼依粗相而说，也如同实义。

二十种随烦恼与别境五种都可以同时俱起，因为互不违背。染污的念和染污的慧，即失念和不正知中以念、慧为体的部分，不与念、慧俱起；以痴为体的部分，也可以与念、慧相应。念也缘取现在曾经熟习的同类之境，忿也可以缘取刹那之前的过去，所以忿与念也可以相应。染污的定生起时，心也躁扰，所以散乱与定相应没有过失。

中随烦恼两种和大随烦恼八种，与十种根本烦恼都可以俱起。

小随烦恼十种决定不与见和疑俱起，因为小随烦恼行相粗动，见和疑行相审细。

忿等五种，即忿、恨、恼、嫉、害，可以与慢和痴俱起，不与贪和瞋同时俱起，因为忿等是瞋的一分。悭可以与痴和慢俱起，不与贪和瞋同时俱起，因为悭是贪的一分。憍只与痴俱起，与慢的理解不同，因为憍是贪的一分。覆、诳、谄，可以与贪、痴、慢俱起，因为行相不相违，覆等是贪和痴的一分。

十一、随烦恼的三性、三界与所缘

小随烦恼中的七种，即忿、恨、覆、恼、嫉、悭、害，以及中随烦恼两种，只属于不善。小随烦恼中的诳、谄、憍三种，以及大随烦恼八种，也通于有覆无记。

小随烦恼七种和中随烦恼两种，只属于欲界。诳和谄，在欲界和色界。其余的，即憍和大随烦恼八种，通于三界。

生在下地的有情，可以生起上地的十一种随烦恼，即诳、谄、憍和大随烦恼八种，因为耽着禅定，对他人生起憍、诳、谄。如果生在上地，可以生起下地的后十种，即中随烦恼两种和大随烦恼八种，因为与邪见和润生爱俱起时，可以生起后十种。小随烦恼十种，生在上地时，没有理由生起下地的，因为小随烦恼不是正润生的烦恼，也不是诽谤灭谛的烦恼。

中随烦恼两种和大随烦恼八种，在下地也缘取上地，因为与缘取上地的贪等相应生起。

关于小随烦恼是否缘取上地，有两家主张。第一家认为：小随烦恼十种在下地不缘取上地，因为行相粗近，不远取。第二家认为：嫉等也可以缘取上地，因为对上地殊胜的法也会生起嫉等。

大随烦恼八种和谄、诳，在上地也缘取下地，因为与缘取下地的慢等相应生起，例如梵天对释迦弟子生起谄诳。憍不缘取下地，因为下地不是所依恃的。

【译注】“梵于释子起谄诳”，指经中马胜比丘问大梵天王四大何处永灭，梵天王不知，当着众天之面不肯承认，用言辞搪塞，私下才引马胜比丘去问佛。

十二、随烦恼的所断

二十种随烦恼都不属于有学和无学，因为随烦恼只是染污，有学和无学只是清净。

后十种随烦恼，即中二大八，只通于见道所断和修道所断，因为与两种根本烦恼相应生起。属于见道所断的，随着所迷四谛的相状，或总或别地与根本烦恼俱生，所以随其所应都通于四谛。迷四谛的亲疏等，都如同根本烦恼所说。

关于前十种小随烦恼的所断，有两家主张。第一家认为：前十种只属于修道所断，因为缘取粗显的事境，任运生起。第二家认为：前十种也通于见道所断和修道所断，因为依两种根本烦恼的势力生起，缘取他人的见等也会生起忿等。属于见道所断的，随其所缘的总别烦恼的力量，都通于四谛。

在第二家中，又有两种看法。一种认为：忿等只缘取迷于四谛的烦恼而生起，不直接迷于四谛，因为行相粗浅，不深取。另一种认为：嫉等也直接迷于四谛，因为对灭谛和道谛等也会生起嫉等。

忿等十种只缘取有事，因为要依托本质才能生起。缘有漏、无漏等，可以依照前面所说了知。

以上卷第六之下译毕，成唯识论卷第六终。
