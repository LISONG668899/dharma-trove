# 遁伦与瑜伽论记

《瑜伽师地论》一百卷，是唯识学的根本大论。玄奘贞观二十一年（647）开译，二十二年译毕。此后唐人为它作注的不下二三十家，而完整传到今天的只有三部：窥基《瑜伽师地论略纂》十六卷，只注到第六十六卷；清素《瑜伽师地论义演》四十卷，今存二十二卷；再就是遁伦《瑜伽论记》，二十四卷、每卷分上下共四十八分卷，从头到尾注完一百卷，一卷不缺。

"完整"这两个字，看起来只是版本学上的运气，其实决定了这部书今天的研究方式——它不只是一部注疏，而是研究唐初唯识学不可绕开的一座资料库。以下几点，是近年学界在这部书里读出来的东西，也是本站逐篇译完全书之后，可以从文本内部加以印证的东西。

## 一、它保存了一批本身已经失传的注解者

唐代注《瑜伽师地论》的二三十家，绝大多数原书都不存在了：景师、泰师、备师、范师（玄范）、光师、灵雋师……这些名字，今天只能通过《瑜伽论记》的转引才看得到片段。

遁伦的做法是逐段列出各家说法，标"某师云""某师解云"，原样并列，很少合并。他偶尔也下判断，但用语极其克制，往往只是"今解""今勘第某卷云""后解为胜""今依多判"寥寥几字，绝不长篇驳斥某一家。正因为这样，他转引的每一段文字，都相当于替那些失传的书保留了一小块未经改写的残片。

这里边分量最重的一个案例是圆测（测师）。圆测是玄奘门下与窥基齐名的唯识学者，他注《成唯识论》的《成唯识论疏》原书早已亡佚，学界只能靠后人的转引去拼凑他的观点；他现存的完整著作，主要是《解深密经疏》（末卷已佚，靠藏译本补全）。而圆测对《瑜伽师地论》本身的逐段解释，除了《瑜伽论记》里的"测师云"，几乎再没有别的地方能看到。遁伦转引的"测师"这部分，因此成为认识圆测唯识学思想的一个独立窗口。

## 二、它记录了一场唐代唯识学内部的路线之争

窥基一系被后世称为"新译"唯识——完全依据玄奘从印度新译回来的护法一系论著建立体系；而在玄奘之前，中国已经有真谛译出的《摄大乘论》等"旧译"唯识流传了一百多年，形成了所谓"摄论学派"。按通常的叙述，玄奘新译一出，摄论旧说应当迅速让位。

日本学者水谷（林）香奈在2015年发表的专题论文《道倫(遁倫)集撰『瑜伽論記』について——基撰『瑜伽師地論略纂』との関係から》里，通过比对《瑜伽论记》与窥基《略纂》的对应段落，指出遁伦书中留有相当分量的摄论学派痕迹——即便是在"新译"阵营内部编成的注疏里，旧译摄论一系的解释思路仍然被认真地摆在台面上讨论，甚至被采用，并没有被新译体系彻底覆盖。

这个发现的意义在于：新旧唯识在中国的过渡，不是一次干净利落的换代，而是两套解释框架并行博弈了相当长的一段时间。《瑜伽论记》恰好是记录这段博弈过程的少数第一手材料之一。

## 三、他是新罗人，而这个身份牵连着一整片学术网络

遁伦的籍贯是新罗，这一点中日韩经录没有分歧。放在孤立的传记视角里，这只是一个国籍标签；但放进学界近年讨论的"新罗唯识学"这个框架里，分量就不一样了。

圆测是新罗人，圆测的弟子道证是新罗人，道证的弟子太贤——号"海东瑜伽之祖"——也是新罗人。圆测一生，新罗王数次请他归国，都未能成行；他留在长安讲学、注疏、带弟子，使得长安的唯识学脉中，长期有一条新罗僧侣的师承线在支撑。遁伦虽不属这一支的直系传承，但他的书里除了转引景、泰、备、基这几位大家，还大量引用顺憬、玄法师、灵雋师等新罗僧人的意见，在个别关键处，最后采信的是新罗元晓的说法，而不是窥基的。

这说明唐代长安的唯识学圈子，从来不是一个单纯的"汉地传统"，而是汉地与新罗僧侣共同参与、彼此激辩的共同体。杨白衣1984年的论文《新羅の學僧道(遁)倫の『瑜伽師地論記』の硏究》，正是把遁伦放在这整片新罗学僧的网络里去定位的。

这条跨海的线索还有后半段。这部书在中土后来几乎失传，是在日本的寺院里以抄本形式保存下来的。全书末尾附有一篇《跋瑜伽论记后》，作者是日本沙门性威，写于享保十八年（1733）。他说此书"存世仅仅可数，而秘名山古刹"，自己早年誊录一本，后来又得到"慈心藏本"再三校雠，才发愿刊印流布。一位新罗僧人在长安集成的书，靠日本僧人的抄校才流传到今天——《瑜伽论记》本身，就是七世纪到十八世纪东亚佛教跨海接力的一份实物证据。

## 四、它至今仍被学者当作"案发现场"来重新勘验

落到具体研究操作层面，《瑜伽论记》真正被使用的方式，是学者拿着一个具体的教理疑难，回到遁伦转引的诸师异说里，重新审一遍案。

一个典型的例子：菩萨"断烦恼"和"入地"（登上菩萨初地）这两件事，谁先谁后？这是唯识学修行位次理论里一个精细而聚讼已久的问题。日本学者吉田道興有一篇专题论文，专门梳理《瑜伽论记》里"远法师"与"融法师"两家对这个问题给出的、彼此不同的解答，并指出现代唯识学者胜又俊教也曾就同一段文字给出过自己的解读。这不是一段被读过一次就搁置的史料，而是不同时代的学者反复回来、各自重新解释的"未结案"的问题。

全书译完回头看，这样的"未结案"处处都是。随手举几个：定中是否还有细微的寻伺——景法师说此文分明证明定中有细寻伺，三藏法师（玄奘）常说寻伺只在近分方便定中，达法师则转述三藏的会通；种子识支是本有还是新熏——护法、护月、胜军三家并列；无有爱为何唯是上品——达法师据此证明无有爱一向是分别所起。遁伦把这些异说一一摆出，结论往往留给读者。

## 五、怎么读这部书

《瑜伽论记》是注疏，不含论本原文，脱离《瑜伽师地论》去读会完全悬空。所以第一条建议是备一部论本对照，读到哪一分卷，就翻开对应的论本卷次。本站每一篇的副标题都注明了对应关系，如"卷第一之上（论本第一卷）""卷第二十四之下（论本第一百卷）"。

第二条建议是与窥基《略纂》对读。《略纂》是基师一家之言，简明而有主张；《论记》是众家之说，繁富而少断语，两部互补。到第六十六卷之后《略纂》就没有了，那时只能靠《论记》。

第三条建议是不必从头顺读。全书篇幅极大，若为通读义理，可以先取本地分中五识身相应地、意地、有寻有伺等三地，以及菩萨地真实义品这几段；若为查考某个具体问题，直接按论本卷次定位即可。论本最后几卷（第八十五至一百卷，即《摄事分》）把阿含经中的蕴、处、缘起、食、谛、界、菩提分法逐一抉择，再转入毗奈耶与本母，篇幅不大而纲目极清，也是很好的入手处。

## 六、关于这个系列

本站以白话译释的方式，把《瑜伽论记》全书逐段译出。系列自2026年9月开篇，至2026年11月8日译完卷第二十四之下，连同书末性威跋文，全书告竣，共二百七十篇。

编号体例是"卷次＋上下＋序号"：如"卷07上-03"，即遁伦卷第七之上的第三篇；序号在每个半卷之内重新起算。每个半卷依篇幅切为若干篇，以科段自然分节而不按字数硬切——遇到义理紧密、须要仔细展开的段落，优先保证讲透，而不是控制篇幅。每篇开头有"本篇要目"与"编者按"，便于检索与把握重点。

译文力求逐句译出，不作删略。诸师异说一律各自成段，标明"景法师说""达法师说""三藏法师说"等，不合并、不裁断，保持遁伦并列诸家的原貌。梵语音译名词照录原名，必要时加注。

《大正藏》录文本身讹字与脱文不少，全书译下来，随文校出的疑字多达数百处。处理原则是：原文一律不改；有确据的（如依论本、依上下文可以确定的），随文括注"当作某"；无确据而文义可疑的，括注"疑当作某"或"文有脱误"，留待读者判断。读者若发现译文与原文有出入，欢迎指正。

## 七、译后记

二百七十篇译完，回头再看这部书，最深的感受是：它不是一个人在说话，而是一屋子人在说话。

一般的注疏，是一位作者站在论文前面替读者开路；《瑜伽论记》不一样。翻开任何一段，景法师、泰法师、基法师、测法师、备法师、达法师，还有屡屡被转述的三藏法师，你一言我一语，同一句论文常常有两三种读法，彼此并不客气。遁伦自己反而像是坐在角落里的记录者，偶尔插一句"今解"，偶尔说一句"后解为胜"，大部分时候一言不发。译久了才明白，这种克制本身就是一种立场：在玄奘新译刚刚出炉、各家说法尚未定型的年代，他选择把争论原样留下来，而不是替后人提前结案。一千三百年后，这些失传诸师的声音之所以还能被听见，全靠这份克制。

第二个感受是，这部看起来极其繁琐的书，处处透出实修的底色。讲灭尽定，诸师细究的是入定之前、出定之后两个时分怎样观受的生灭——因为定中已无能观之心；讲见道与修道的距离，用的是渴人望井、见水而无汲器的比喻；讲七觉支，要把二十一种观想一一配给十四种障碍；讲证净，要分辨预流、一来、不还、阿罗汉各自依哪几种随念为他人记别。这些不是书斋里的名相游戏，而是一代代修行人把自己的经验交给名相去保存。名相越细，往往说明当年用功的人越多。

第三个感受，来自书中反复出现的一对说法："随义说"与"据实论"。论文说遍知有六种，遁伦随即指出"此随义说，不据实论"——若据实而论，可以是两种，也可以是四种乃至九种。同一件事，从不同的角度去数，得出不同的数目，彼此并不矛盾。这对读一切经论都是一把钥匙：许多看似冲突的说法，只是"随义"的角度不同；而真正的"实"，往往不在任何一个数目里。

最后一个感受，是对这部书得以流传的感念。一位新罗僧人在长安汇集诸家之说，书在中土湮没，又在日本的名山古刹里被一代代抄写、珍藏；一千年后，有一位叫性威的日本僧人，嫌传本"文字讹舛"，四处求得别本，再三校雠，发愿刊印，还谦逊地在跋文末尾写道：书中鲁鱼豕亥、虫蛀残损之处，"后君子幸鉴定焉"。今天把它译成白话，校出数百处疑字，也只是接着做性威当年没有做完的事——而且同样不敢说已经做完。

这部书曾经靠着许多不知名的抄写者、校勘者活到今天。愿这二百七十篇白话译释，也能算作那条长长的接力中的一小段。
