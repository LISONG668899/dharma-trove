<p class="dt-title">十四种密意·三无自性</p>
<div class="dt-subtitle">瑜伽论记白话译释（二百三十一）　卷第十九之下（论本第七十三卷）<br>唐　遁伦　集撰</div>

本篇要目：菩萨地抉择·真实义品五事第二颂之八至十一：密意门（会释十四种密意经——第一经"一切法无性有性无二"；第二经三无自性性：相、生、胜义，唯遣遍计所执不遣依他，观骨聚比丘之喻，评梁《摄论》"遣真实性"为录文之误、驳"依他无众缘生"之说，引第七十五卷破恶取空——文中指为清辩学徒，并引《善戒经》不解空与解空；第三至第十四经：无生无灭、虚空、如幻、无常、苦、空、非有显现、虚伪不实、真如中眼等寂灭、遣一切想与"南无最胜士"颂、无谛无实与圣世间谛、不可思议）；次第门——五事抉择译毕

编者按：本篇译五事第二颂的第八"密意门"与第九"次第门"，五事的抉择至此全部完毕。密意门会释十四种佛经中的密意说法，核心是第二经的"三无自性性"：相无自性性、生无自性性、胜义无自性性。遁伦在这里提出一个贯穿全段的论点：三无自性"唯遣遍计所执，不遣依他"——相无自性遣除遍计，生无自性是说依他无"自然生"，胜义无自性是说依他无"胜义常住之性"，并不是连依他起的因缘法都遣除；入真观时虽然暂不缘俗，出观之后后得智仍缘因缘生法。他以修不净观的比丘观想骨聚遍满大地、后来推审本心而除遣骨相为喻，说明除遣的是执实之相，而非依他起本身。在此基础上，遁伦（及泰法师章）对两种说法提出批评：一是旧来摄大乘师说"遣依他因缘法得无生性"、梁译《摄论》说"遣真实性得无真实性"，认为是"录文人误""谬解本宗"；二是有人说"依他无性就是无众缘生"，引本论第七十五卷对"恶取空"的破斥，文中明言此是"清辩菩萨学徒恶取空宗，非慈氏、无著所学"（此段承泰法师章文而下，"解云"以下或是泰法师之语，或是遁伦之按，原文未明），并引《善戒经》区分"不解空"与"真解空"。这是唐代瑜伽行派与中观清辩一系"空有之争"的重要文献。原文讹字较多，随文注出。

一、第八密意门：第一经"一切法无性有性无二"

第八，解释密意门。其中会释十四种密意之经。

解释第一经，景法师解释道：若如名言而执有五事，就说无自性；离开那名言，任其五法各有别体，就说有自性。这就是没有言说所诠的法体，只有离言的法体，所以说"无二"。

景法师又说：问：世尊为什么说"一切法无性、有性，无二"？答：就依这样所说的五事：世俗道理是有，实际上没有，所以说无自性；真如没有世俗的自性，所以也说世俗无自性，如说胜义无自性；其余四法是世俗有，所以没有自然之性。然而五事由于各别之相，不觉自性之事，所以说这五事有自性。五事有自性，也有五事无自性，所以说一切法无二。

二、第二经：三无自性性（景法师释）

第二经中，景法师解释道：

一、"相无自性性，谓一切世俗言说自性"：就是遍计所执随言说之法，本来无相。

二、"生无自性性，谓一切行众缘所生，缘力故有，非自然有"：就是依他起性藉众缘而生，没有自然而生，名为生无性。

三、"胜义无自性性，谓真实义相所远离法，此由胜义说无自性"：这个胜义无性也是依他起，由于因缘，是无常的法体，不是那真实胜义之法，所以说"真实义相所远离法"。由于这依他起没有那胜义，所以说依他起名为胜义无自性性。

依照下文所解的《解深密经》，胜义无性有两种意义：一、就依他起来解释胜义无性，如上所说；二、就圆成实之体来说明胜义无自性性，又有两种意义：一是圆成实性离开名言，没有那取执的胜义之义相，名为胜义无性；二是这圆成实之体是胜义，这胜义由那无相、无生二门所显，所以名为胜义无自性性。现在这段文字只约依他起来辨胜义无性。

三、三无性唯遣遍计所执

问：相无自性，是没有遍计所执相的自性，名为相无性；依他起没有那横计的自然之生，名为生无性，这也是遣除遍计所执；就这依他起没有那胜义常住之性，名为胜义无性，这也是遣除遍计所执。那么三无性都是无遍计，总是一个"无"，只应说那相无自性就够了，何须再辨这依他起的无生、无胜义等？

解释说：依理实是如此，都是约无其遍计所执来说。然而现在的论宗，或约二性来辨三无，或约三性来辨三无，是总与别的分别，所以有三种。相无自性，就是总收那遍计所执，全部遣尽。又说依他起无生、无胜义等，是分别的分别：其次说明依他起的因缘法体，没有自然之生，没有那胜义，所以在总中开出这二种；并不是说在遣除遍计的相无性之外，另外遣除依他起、遣除胜义，来辨生无性、胜义无性。所以下文《解深密经》中说："唯遣遍计所执而辨三无性，未遣三性而辨三无性。"

四、会通《摄论》"先证根尘相无，后见识无生"

问：如果是这样，为什么《摄论》说"先证根尘相无自性，后时见识无生；识以根尘为因缘，因缘既无，识怎么生起"？依那论文，也遣除依他起，怎么能说只遣遍计所执性？

解释说：根尘以及识，有两种：

一是依他起的因缘生法。即使入初地，这也不遣除：心是俗谛，是后得智之境；无分别智自观真如，后得智自缘因缘生法，理与事并行，不相妨碍。若入真观，就遣除俗谛；根尘识等真俗并行（时），俗智缘什么境？所以知道因缘有法，入观时并不遣除。

二是遍计所执的根尘识等，颠倒之情执为有，毕竟没有体。论中约识，先遣根尘：若悟能生的根尘没有体，就悟所生之识怎么能生？这就是还遣遍计所执之识，不遣依他起。

依他起性中通有八识。入真观时，有漏的意识以及末那虽然暂时不起，出观之后还会生起；阿赖耶识恒常现行；五识遇缘，在观中也会生起。所以不能说入观时遣除那依他起之识。若同于遍计所执，入观时都遣除；遣遍计，所以悟本相无，后得智不缘；若遣依他，也应当后得智毕竟不缘了。

五、观骨聚比丘之喻

下面以譬喻显示。论中说"观行比丘……乃至恒无间转"：如观骨的时候，若还未广观，先观髑髅，乃至观足；亲身所依的绳床是骨，一房、一僧伽蓝、一村、一聚落、一国，乃至大地，骨都充满。后来想要除去所见之骨，因为久习观骨，骨境现前，不能除灭。于是作念："这样的骨聚虽然遍满大地，只是我心假想所安立。"推审本心，骨相便除灭。正如前面遍计执有定性之境时，只有自心，心外无法。

问：修行人入观观察骨聚，骨聚后来除遣，是由于定心执有实骨所以须要除遣，还是不执为实而须要除遣？若执为实，定心就有法执；有法执，就有无明；有无明，就不应名为定。若不执为实，所观的骨聚是依他起性，现在遣除骨聚就是遣除依他起，怎么又说不遣依他起？

解释说：定心观骨，没有执为实；为了调心，最初假作观骨；后来又寻究本心，舍骨而观心，以这转观舍弃骨聚。正如前面的三无性观，除遣遍计所执的实相、生以及胜义等。

论中说"此中五事……胜义无自性性故"：五事不是遍计所执，所以不是相无自性，只有其余二种无自性性，这句是总说。下面分别分别，所以说"随其所应……乃至说无自性"，意义如前。"是故"以下作结。"乃至我说一谛，更无第二"，是说那真如不是三无性，唯是不变的真实，说为一谛。

六、泰法师章：三无性与梁《摄论》之误

（泰法师）章中又解释说：相无自性性，唯是没有横计的人法二境的遍计所执性。生无自性性，是依他起从众缘生，没有自然之生，所以说依他起是生无性性，就是以无自然生之性为其体性。

胜义无自性有两种：一、依他起没有胜义，所以说依他起的俗法为胜义无性性，这是俗谛的胜义无自性性，如苦谛中没有真我，说为无我。二、真如胜义没有依他起，名为胜义无性性。现在这段文字是第一种意义："真实义相所远离"的俗法依他起性，由于没有胜义真如，所以说为胜义无性性。如观行比丘于大骨聚作假想观，其观既成，想舍也舍不掉……乃至解释说：于此假想观骨聚之作事，不是真实胜义；骨聚无性，总恒无间而转。像这样应当知道，真观依他起性，不是真实胜观，所以名为胜义无性观，然而是俗观，不是真观。

遍计所执性不属于五事所摄。五事不是由于无自性性而说无自性。五事中的相、名、分别、正智，都由二种无自性性：一、四种要依众缘而生，没有自然之生，说以无生自性为其性；二、四种是俗而非真，没有胜义之性，所以说胜义无性性。真如一种有其实体，由于胜义没有俗性，所以说胜义无性性，不是由于没有自己的真性而说无自性。所以世尊依此密意说："我说一真谛，更无第二真谛。"

旧译梁《摄论》等，名为"真实无性性"；现在名为"胜义无性性"，因为真实性属于胜义谛所摄，所以名为胜义。旧经名为"第一义谛"，现在的经论名为"胜义谛"。

现在依这部论来会通旧经论："真实无性"：一、依他起不是真实性，所以说依他起为（无）真实性性，以依他起无真实为其性；二、真实性不以依他起性为其性，所以说真实无性性。依梁《摄论》，竟说"遣除真实性而得无真实性，所以名为真实无性性"，这是录文之人的错误。

又依《佛性论》以及《瑜伽论》，以三性与五法相摄中，真实性与五法中的真如相摄。若遣除真实性而得无真实，名为真实无性性，那么真实无性性属于五法中的哪一法所摄？若说真如所摄，就与真实性无异；若说五法不摄，五法就摄法不尽。若说五法摄不尽，为什么《瑜伽论》说"问：如是五事为摄一切法、为不如是？答：如是"？又，若遣除真实性所以说真实无性性，为什么《瑜伽论》说"真如不由无自性性说无自性，是故世尊依此密意，于伽他中说如是言：我说一谛，更无第二"？

七、驳"依他无性即无众缘生"与恶取空

又，古时汉地论师说："依他无性，是没有众缘生的俗谛之性，所以名为依他无性。"这是不对的。《瑜伽论》说："云何生无自性性？谓一切行众缘所生，缘力故有，非自然有，是故说为生无自性性。"这意思是说：众缘所生之法没有自然之性，所以说生无自性为其性；不是说没有因缘生之性，所以说生无自性性。若说没有众缘生之性，所以说无自性性，那就是恶取空。

所以《瑜伽》第七十五卷说："复次，于大乘中，或有一类恶取空者，作如是言：由世俗故，一切皆有；由胜义故，一切皆无。应告彼言：长老，何者世俗？何者胜义？如是问已，彼若答云：若一切法皆无自性，是名胜义；若于诸法无自性中自性可得，是名世俗。何以故？无所有中建立世俗，假设名言而起言说。应告彼曰：汝何所欲？名言世俗，为从因有自性可得？为唯名言世俗说有？若名言世俗从因有者，名言世俗从因而生，而非是有，不应道理；若唯名言世俗说有，名言世俗无事而有，不应道理。又应告言：长老，何缘诸可得者此无自性？如是问已，彼若答言：颠倒事故。复应告言：汝何所欲？此颠倒事为有为无？若言有者，说一切法由胜义故彼无自性，不应道理。"（原文"应告彼言言"，衍一"言"字。）

八、"解云"：恶取空者是清辩学徒

（以下"解云"一段，承泰法师章文而来，当是泰法师或遁伦的解释。）解释说：在大乘部中，或有清辩菩萨等一类恶取空者，作如是言："由世俗故，一切依他起皆有；由第一义谛故，一切依他起皆无。"

慈氏菩萨说："应当问他：何者是世俗？何者是胜义？"如此问了之后，那清辩等回答说："一切依他起法皆无自性，是名胜义；若于无自性中因缘自性可得，是名世俗。为什么呢？在实无所有中建立世俗的有法，假设名言而起言说，所以名为世俗。"

慈氏菩萨应当告诉他说："你想怎样？名言所说的世俗法，是从因而有、自性可得？还是只是名言世俗说有、实际上没有因缘所生？若名言所说的世俗法是从因而有，名言世俗从因而生，因缘之道是不可破的，所以经中说'不坏世谛而入第一义谛'。你说从因而生的俗谛，依第一义谛而不是有，不合道理。若说只是名言世俗说有，实际上没有从因所生之法，那么名言世俗没有所诠的因缘生事，却说为有，不合道理。"

慈氏菩萨又应当问："为什么诸可得的因缘法，此中没有因缘的自性？"如此问了之后，那清辩等若回答说："因为是颠倒的因缘事；胜义谛理中没有颠倒之事。"慈氏菩萨又应当告诉他说："你想怎样？这颠倒的因缘事，是有这因缘法，还是没有因缘法？若说有这颠倒的因缘法，又说一切因缘法由胜义故都没有因缘的自性，就与邪见所说的无因缘法相同，不合道理。若说没有这颠倒的因缘法，因颠倒事故，没有事可得其因，而说你没有因缘自性，也不合道理。"

无著菩萨造《摄大乘论》，正是陈述此宗，所以论中说："若依他性、圆成实性亦无，即恒无二品，及染净法。"说清净与染污，染污就是颠倒之事，即依他起。自古以来的摄大乘论师误解本宗，所以说"遣依他因缘法而得无生性"，乃至于此，这是清辩菩萨学徒的恶取空宗，不是慈氏菩萨以及无著菩萨所学之宗。

九、引《善戒经》：不解空与真解空

《善戒经》第二卷说："有二种人，远离佛法，非佛弟子，永失佛法：一者说色乃至涅槃有真实性；二者不信世流布性。如是二人不信受持菩萨禁戒，谤一切法者，即是外道富兰那等的真实弟子。"富兰那，是说诸法之性无。而佛法中亦有亦无。

经中又说："设生我见，不至三恶；不解空义而为人广说，当知是人必到阿鼻（原文'阿毗'，当是'阿鼻'）。不解空者，谤一切法，不解实性，不解法性，妨于解脱，与多众生作恶知识，自不持戒，教人毁戒，常乐宣说无作无受，令多众生增长地狱。云何名为不解空义？说一切法本性自空、无因缘空，说一切法亦无处所；若无处所，何名为空？是不解空。云何名为真实解空义？说一切法中无有法故，是名为空；法亦不空，是名解空，无错谬。"

解释说：什么名为不解空义？说一切因缘法本性自空，因为没有因缘法所以空；说一切遍计所执法也没有依他起性的处所。若没有依他起性的处所，约什么说空？这名为不解空。什么名为真解空义？是说一切依他起法中，没有遍计所执之法，所以名为空；依依他起性之法也不空，这名为解空。

十、第三至第七经

第三经说"无生无灭等"，是依相无自性性：这是依五事之外的遍计所执之相来辨无生无灭等。依下面所解的《解深密经》，也就圆成实性来辨无生无灭等四种意义。

第四经说"于虚空"，是依遍计所执而说。

第五经说"诸法如幻"，是依那依他起，说无生以及胜义无性。

第六经说"等随观色乃至识有无常耶"等：定心平等，随境观察色乃至识是无常。"无常"之言是隐密之说，所以论主解释说：所计的常性，是色上的遍计等说，说无常，所以是依相无性来说。论主为什么要解释经语？经语颠倒，可以说"常无有"，因为在依他起的色等上遍计为常，所以说"常无"。然而那经就是想说等随观五蕴的常是无有的。

第七经说"五蕴皆有苦"，也是依依他起，说生无性以及胜义无性。

十一、第八至第十经

第八经说"等随观即彼皆空"，就是依生无自性性等，乃至说如是言。前面说明遍计所执性空，说等于虚空：虚空无体，比喻遍计所执性空。现在说"随观即彼皆空"，说明依他起诸法，空于自然之生，以及没有胜义；不同于前面所说的遍计所执空的相无自性，所以说"远离相无自性"。也不必一定对着前面来辨别而名为远离。

景法师解释经中"等随观即彼皆空"：说明依他起空、没有自然之生以及没有胜义，所以说为空；不辨相无自性，所以说"远离相无自性"（原文"慧。解经"，"慧"字当是"景"字之讹）。

论中说"如依远离性说彼为空……至亦尔"：前面说明依他起是因缘，因缘法之外，离开自然之生以及离开胜义，所以说为空；现在说明依他起即体无我，从异的方面说空义，所以说"依异相性为无我"。也可以说，说明这依他起法体无我，异于遍计所执的我无，所以说"依异相性说为无我"。

第九经说"如理观彼五蕴非有显现"，答"依相无性说"：因为那横计的五蕴，如理观察，实际上不是有，而随着妄情显现，所以依相无性说"非有显现"。

第十经说"说彼虚伪不实显现"，是依生无性以及胜义无性而说：因为依他起性虚妄无实，从缘显现，没有自然之生，所以名为生无自性；不只是没有自体，也不是真如胜义，所以说胜义无自性。

十二、第十一经：真如中眼等寂灭

第十一经中，景法师解释道：这说明真如法中远离十二处，总都不依那三无性来说。

问：假设依真如法中远离十二处之相，依三性来说，有什么过失？如那真如法中，遍计所执的眼永远寂灭，远离遍计所执的色想，乃至说永远寂灭、远离想，也是远离遍计所执。

解释说：三无性观在方便道；真如观诸法永寂，不作无相、无生等观。若就义理来说，真如法中离开遍计所执的十二处，总也可以说为相无自性；然而要依经中有"无性"之言，才能依经说为无性。经中只说眼等寂灭、远离诸想，竟不说有"无性性"之言，所以论主说"都不依三无性说"。由此可知三无性观在加行道，根本观中不作无性性的解。

泰法师说：在真如中眼等永远寂灭，远离色想乃至法想，真如实有体性，所以都不依无自性来说如是言。

备法师说：这是约圆成实性来说，不是约三无性来说。

十三、第十二经：遣一切想与"南无最胜士"颂

第十二经说"遣一切想"，也是依真如而说，所以不依三无性性而说。

详考这部论上下所说的无性性，唯依横计之性，不依依他起以及圆成实二性。所以《净名经》说："但除其病，而不除法。"法是依他起与圆成实、真俗二谛；病是遍计横执诸法。所以那部经的意思，还是同于这部论。

这人如是作真如观，（他人）都不能知道。所以上面论中说：诸天得他心智，寻求那比丘所入之定，竟然不能知道，所以说颂：

```
南無最勝士　南無士中尊
今我不知汝　依何修靜慮
```

（意谓：诸天礼赞这位比丘为最胜之士、士中之尊，却说自己不知道他依什么而修静虑。）

十四、第十三经：无谛无实与圣世间谛

第十三经中，景法师解释道：论中说"随顺喜、忧、舍处，眼所识色乃至意所识法中，无谛无实"，是依相无性而说。

"无无颠倒"：外道执法自然而生，名为无颠倒（他们自以为不颠倒）；现在说明依他起没有自然之生，所以"无无颠倒"。

"无不颠倒"：外道又执人天的报身是胜义涅槃、不颠倒之法；现在说明人天报身是生死，不是胜义，有烦恼，所以说"（无）不颠倒"。

论中说"复说有圣世间谛"，就是真如，即是出世的非安立谛，不依一切无性性而说。答文依此解释可知。

现在（遁伦）解释：前一卷说真如的差别，名为实性、谛性、无颠倒性、不颠倒性等，解释说：没有邪分别所取，所以名为无倒；唯是正智所证，所以名为不倒。现在这段文字的意思是：世间色等法中，没有谛、实等相，（众生）横计为实等，依三无性说无谛、实等；说有真如出世圣谛，为谛、为实、无倒、不倒，不依三无性而说。

十五、第十四经：不可思议

第十四经，有人解释：知道遍计所执是无，知道依他起是有，所以（说）依一切（无性）；若证得真如，就不依一切，因为真如不是无性。

现在（遁伦）解释：也可以说，定境非有非无，名为不可思议；诸佛的境界也是如此，非有非无，名为不可思议。只是在因位中，定境为了除去执著，依无性而说；诸佛的境界已经永远寂灭，不依无性而说。

十六、第九次第门

第九，解释次第门。其中约杂染品来辨前三事的次第，又约清净品来辨后二事的次第。依道理，五事都通于清净，论主是从多数来说，所以这样。

以上两颂辨析五事完毕。

下一篇将译释真实义品抉择的第二部分"解释三性"：以三颂分三段，第一颂列七门（总举、别分别、缘、差别、依止、微细执著、如名等执性）；景法师推崇玄奘法师《三性义章》的三门分别（情事理门、尘识理门、染净通门），并判定依《瑜伽》唯初门为正；又依五法、五相出三性之体；备法师更作九门分别三性诸说。其后依门解释圆成实之体、三性之缘、遍计所执的五种差别与依止等。
