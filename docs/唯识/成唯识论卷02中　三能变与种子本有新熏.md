<div class="dt-subtitle">成唯识论白话译注（五）　卷第二之中<br>护法等菩萨造　唐　玄奘译</div>

本篇要目：一、三类能变识　二、因能变与果能变　三、第二至第四颂：初能变阿赖耶识　四、阿赖耶识的自相、果相、因相　五、种子的定义与性质　六、种子来源三家之一：护月论师主本有　七、三家之二：难陀论师主新熏　八、三家之三：护法论师立本有与新熏二类　九、破分别说部“心性本净”　十、会通经论

一、三类能变识

识所变现的相有无量种类，能变现的识，类别只有三种。第一种称为异熟，即第八识，因为第八识具有最典型的异熟性质。第二种称为思量，即第七识，因为第七识恒常审察思量。第三种称为了境，即前六识，因为前六识了别境界的行相粗显。颂中“及”字表示前六识合为一种。

二、因能变与果能变

三种识都称为能变识。“能变”有两种含义。

第一种是因能变，指第八识中的等流习气和异熟习气两种因。等流习气，由前七识中的善、恶、无记三性熏习，使等流习气生起、增长。异熟习气，由前六识中有漏的善业、恶业熏习，使异熟习气生起、增长。

第二种是果能变，指由等流、异熟两种习气的力量，八识生起，显现种种相。

等流习气作为因缘，使八识的体和相各有差别地生起，称为等流果，因为果与因相似。

异熟习气作为增上缘，感生第八识。第八识酬报引业的力量，恒常相续，所以称为异熟。异熟习气又感生前六识，前六识酬报满业，从异熟识生起，所以称为异熟生，不称为异熟，因为前六识有间断。第八识的异熟与前六识的异熟生，合称异熟果，因为果与因性质不同。

【译注】引业决定投生哪一道，满业决定投生后的细节，如美丑、贫富、寿夭。第八识酬报引业，恒常不断，是“真异熟”；前六识中酬报满业的苦乐感受，时有时无，只是“异熟生”。等流果与因同类，如善心生善种；异熟果与因异类，如善恶业感生无记的果报身。

颂中所说的“异熟”，只是指有我爱执藏、能执持杂染种子的能变果识，即第八识，并不是指一切异熟。

前面已经略说了三种能变的名称，还没有广说三种能变的相状。外人质问：初能变的相状是怎样的？世亲菩萨用颂回答：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">初阿赖耶识　异熟一切种<br>不可知执受　处了常与触<br>作意受想思　相应唯舍受<br>是无覆无记　触等亦如是<br>恒转如瀑流　阿罗汉位舍</div>

大意：第一能变称为阿赖耶识，也称为异熟识、一切种子识。阿赖耶识执受种子与根身，变现器世间，了别作用极其微细，难以了知。阿赖耶识常与触、作意、受、想、思五个心所相应，只与舍受相应。阿赖耶识的性质是无覆无记，相应的触等五心所也是如此。阿赖耶识恒常相续，又刹那变转，如同瀑流。到阿罗汉位，阿赖耶识的名称才舍弃。

三、第二至第四颂：初能变阿赖耶识

论中解释：初能变识，大乘与小乘的经教都称为阿赖耶。阿赖耶识具有能藏、所藏、执藏三种含义。能藏和所藏，是因为阿赖耶识与杂染法互相为缘：阿赖耶识能摄藏杂染法的种子，阿赖耶识又被杂染法所熏习而藏。执藏，是因为有情把阿赖耶识执为自己内在的我。

【译注】“阿赖耶”梵语意为“藏”。三藏之中，执藏最为根本：阿赖耶识被第七末那识恒常执为自我，阿赖耶的名称正由此而立，到阿罗汉断尽我执，“阿赖耶”的名称就舍弃了。

四、阿赖耶识的自相、果相、因相

“阿赖耶”的名称，显示初能变识的自相，因为阿赖耶识以摄持因与果为自相。阿赖耶识的自相随分位不同有多种名称，“藏识”的名称所显的过失最重，所以颂中特别提出。

【译注】“过失最重”，指“阿赖耶”一名显示的是被执为我的杂染状态，修行者最先要舍的正是“阿赖耶”的名称。卷三会列出第八识的七种名称，各有所指。

阿赖耶识是能牵引三界、五趣、四生的善业与不善业所感的异熟果，所以称为异熟。离开阿赖耶识，命根、众同分等恒常相续的殊胜异熟果，就找不到。“异熟”的名称，显示初能变识的果相。阿赖耶识的果相随阶位与种类有多种，“异熟”的名称通用的阶位最宽，又不与其余诸识共有，所以颂中特别提出。

阿赖耶识能执持诸法的种子，令种子不失去，所以称为一切种。离开阿赖耶识，其余的法都不能普遍执持诸法种子。“一切种”的名称，显示初能变识的因相。阿赖耶识的因相有多种，执持种子是阿赖耶识独有的，所以颂中特别提出。

初能变识的体相有多种，大略只有自相、果相、因相三相。

五、种子的定义与性质

“一切种”的相状，应进一步分别说明。

外人质问：什么法称为种子？论主回答：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">谓本识中亲生自果功能差别。</div>

大意：种子就是阿赖耶识中，能够直接生起各自果法的种种功能。

种子与阿赖耶识、与所生的果法，不是一，也不是异，因为体与用、因与果的关系，在道理上本应如此。

种子与阿赖耶识、与果法不一不异，种子本身是实有的，因为假法如同无，不能作为因缘。

外人质问：种子与诸法既然不一不异，种子就应如同瓶子等，是假有，不是实有。论主回答：照你的道理，真如也与诸法不一不异，真如也应是假有；如果承认真如是假有，就没有真实的胜义谛了。种子只是依世俗谛说为实有，种子不同于真如。

种子依于第八识的体，种子是第八识的相分，不是其余的部分，因为第八识的见分恒常以种子为所缘境。

一切有漏种子与异熟识体性无别，所以属于无记性。有漏种子的因与果都有善等性质，所以有漏种子也依因果而称为善种子等。一切无漏种子不属于异熟识的体性，无漏种子的因与果都属于善性，所以只称为善。

外人质问：既然如此，为什么《瑜伽师地论·摄抉择分》说，二十二根一切都有异熟种子，都是异熟生？

论主回答：二十二根的种子称为异熟，并不是无记，只是依附于异熟识，所以称为异熟种子。性质不同的法互相依附，如同眼识依附眼根，眼根是无记，眼识通三性。另一种解释：无漏种子由熏习的力量转变成熟，所以立“异熟”之名，这里的“异熟”不是无记性所摄的异熟。

【译注】二十二根中包括未知当知根、已知根、具知根三种无漏根，所以论主要会通：说“异熟种子”，不等于说无漏种子是无记。

六、种子来源三家之一：护月论师主本有

种子从哪里来，论中列出三家。

第一家，依《述记》为护月论师的主张：一切种子都是本性就有的，不从熏习而生。熏习的力量，只能使种子增长。

护月论师的依据如下。

契经说：一切有情从无始以来，就有种种界，如同恶叉聚，法尔而有。“界”就是种子差别的名称。

【译注】恶叉是一种树，果实落地就自然聚成一堆。经中以恶叉聚比喻有情本来就具有多种种子，天然聚集。

契经又说：无始时来的界，是一切法平等的所依。“界”是因的意思。

《瑜伽师地论》也说：诸种子的体，从无始以来本性就有，由染净诸法新的熏习而被激发。一切有情从无始以来，如果是能般涅槃的种性，一切种子都具足；如果是不能般涅槃的种性，就缺少三乘菩提的种子。

诸如此类的论文，可以作证的不止一处。一切有情既然被说为本来就有五种种性的差别，就应决定有法尔本有的种子，不由熏习而生。

《瑜伽师地论》又说：地狱中的有情成就三种无漏根，是成就种子，不是成就现行。经论又说，有从无始以来展转传来、法尔所得的本性住种性。

由以上依据，护月论师证明：无漏种子是法尔本有，不从熏习生。有漏种子也应法尔本有，由熏习增长，不另由熏习新生。依本有建立因果，就不会紊乱。

【译注】五种种性：声闻种性、独觉种性、如来种性、不定种性、无种性。

七、三家之二：难陀论师主新熏

第二家，依《述记》为难陀论师、胜军论师等的主张：一切种子都由熏习而生。所熏的阿赖耶识与能熏的前七识，都是无始就有，所以一切种子从无始以来就已成就。

难陀论师的依据如下。

种子是习气的异名，习气必定由熏习而有，如同胡麻的香气，是由花熏习而生。

契经说：一切有情的心，由染净诸法所熏习，所以积集了无量的种子。

论中说：内种必定有熏习，外种的熏习或有或无。

名言、我执、有支三种熏习，总摄一切有漏法的种子。三种熏习既然都由熏习而有，有漏种子必定依靠熏习而生。

无漏种子的生起，也由熏习。《摄大乘论》说闻熏习：听闻从清净法界等流出来的正法而熏习生起，闻熏习就是出世心的种子。

有情本来种性的差别，不是由无漏种子的有无而定，只是依有无障碍而建立。《瑜伽师地论》说：对于真如境，如果有毕竟不可断的烦恼障和所知障两种种子，就立为不般涅槃的种性；如果只有毕竟不可断的所知障种子，没有毕竟不可断的烦恼障种子，就一部分立为声闻种性，一部分立为独觉种性；如果没有毕竟不可断的二障种子，就立为如来种性。由此可知，本来种性的差别，是依障碍建立的，不是依无漏种子。

经论所说“成就无漏种子”，是依将来可以生起而说，并不是已经有了种子的体。

八、三家之三：护法论师立本有与新熏二类

第三家，依《述记》为护法论师的正义：种子各有两类。

第一类是本有种子，指从无始以来，异熟识中法尔而有、能生蕴处界的功能差别。世尊依本有种子说：一切有情从无始以来就有种种界，如同恶叉聚，法尔而有。其余引证，详如第一家所说。本有种子称为本性住种。

第二类是始起种子，指从无始以来，由现行一次次熏习而有的种子。世尊依始起种子说：有情的心由染净诸法所熏习，所以积集了无量的种子。诸论也说：染净种子由染净诸法熏习而生。始起种子称为习所成种。

先破“唯有本有”。种子如果只是本有，前七转识就不应与阿赖耶识互为因缘。契经的偈颂说：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">诸法于识藏　识于法亦尔<br>更互为果性　亦常为因性</div>

大意：诸法藏于阿赖耶识中，阿赖耶识也藏于诸法中；诸法与阿赖耶识互相为果，也恒常互相为因。

偈颂的意思是：阿赖耶识与诸转识，在一切时中展转相生，互为因果。《摄大乘论》说：阿赖耶识与杂染法互为因缘，如同灯炷与火焰，展转相生而燃烧；又如同两束芦苇，互相依靠而竖立。只有依种子生现行、现行熏种子两种关系才建立因缘，其余的因缘找不到。

种子如果不由熏习而生，转识与阿赖耶识怎能有因缘的关系？只是熏习令种子增长，不能称为因缘，否则善恶业与异熟果也应是因缘关系。诸圣教都说有种子由熏习而生，“唯有本有”的主张都与圣教相违。所以“唯有本有”，与道理、与经教都相违背。

再破“唯有始起”。种子如果只是始起，最初的有为无漏法就没有因缘，就应不能生起。有漏种子不应作为无漏法的种子，否则无漏种子也应能生有漏法。如果承认有漏能生无漏，诸佛的有漏法就应再次生起，善等种子也应能作为不善等法的种子。

九、破分别说部“心性本净”

分别说部辩解：心性本来清净，被客尘烦恼所污染，所以称为杂染；离开烦恼时，心转成无漏，所以无漏法并不是无因而生。

论主破斥：你们所说的“心性”，是什么意思？

如果“心性”指空性之理，空理不是心的因，常住之法决定不是诸法的种子，因为常住之法的体前后没有转变。

如果“心性”就是指心，就应如同数论外道所说，相有转变，体常是一。恶心和无记心就也应是善。如果承认恶心和无记心是善，恶心和无记心就应与信等善心所相应；如果不承认，恶心和无记心就不是善心的体，尚且不能称为善，何况是无漏？

有漏的善心既然称为杂染，就如同恶心等，性质不是无漏，所以不应作为无漏法的因，否则善与恶等也可以互相为因。有漏心的性质如果是无漏，无漏心的性质就也应是有漏，因为找不到区别二者的因缘。

凡夫的心如果是无漏，凡夫位就有无漏法现行，凡夫就应称为圣者。

分别说部辩解：凡夫心的性质是无漏，凡夫心的相有染污，所以不称为无漏，没有以上的过失。论主回答：照此道理，心的种子也不是无漏，你们的论为什么说凡夫唯独能成就无漏种子？因为种子与现行的性相是相同的。

论主正面解释：契经说“心性本净”，是说心的空理所显示的真如，因为真如是心真实的体性。或者，是说心体不是烦恼，所以称为性本净。不是说有漏心的性质是无漏，才称为本净。

由此应当相信：有一些有情，从无始以来就有无漏种子，不由熏习，法尔成就；到后来殊胜进修的阶位，由熏习使无漏种子增长，无漏法生起时以本有的无漏种子为因；无漏法生起时，又熏成新的种子。有漏法的种子，也可以照此类推。

十、会通经论

诸圣教说内种必定有熏习，并没有决定说一切种子都由熏习而生，怎能完全否定本有种子？本有种子也需要由熏习使本有种子增盛，才能生果，所以说内种必定有熏习。

闻熏习不只是有漏的。听闻正法时，也熏习本有的无漏种子，使无漏种子渐渐增盛，展转乃至生起出世心，所以也称为闻熏习。闻熏习中有漏性的部分，属于修道所断，能感生殊胜的异熟果，是出世法殊胜的增上缘。闻熏习中无漏性的部分，不属于所断，是出世法真正的因缘。真正的因缘隐微难知，所以经论借粗显的殊胜增上缘，方便说为出世心的种子。

【译注】依护法论师的会通：听闻正法所熏成的有漏闻熏习，只是增上缘；真正生起出世心的因缘，是本有的无漏种子，闻熏习的作用是令本有无漏种子增盛。

依障碍建立种性差别，用意是显示无漏种子的有无。如果完全没有无漏种子，二障种子就永远不能断除，就立为不般涅槃的种性。如果只有二乘的无漏种子，所知障种子就永远不能断除，就一部分立为声闻种性，一部分立为独觉种性。如果也有佛的无漏种子，二障种子都可以永远断除，就立为如来种性。所以，由无漏种子的有无，才有障碍可断与不可断的分别。无漏种子隐微难知，所以经论依障碍来显示种性的差别。

不然的话，障碍有什么另外的原因，而有可断与不可断的分别？如果说障碍法尔就有可断与不可断的分别，为什么不承认无漏种子法尔本有？如果本来完全没有无漏种子，一切圣道就永远不能生起，谁能断除二障种子，而说依障碍立种性的差别？圣道既然必定没有生起的可能，说“将来可以生起”也决定不合道理。诸圣教处处说有本有种子，“唯有始起”的主张都与圣教相违。所以“唯有始起”，与道理、与经教都相违背。

由此应知：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">诸法种子各有本有、始起二类。</div>

大意：一切法的种子，都各有本来就有和新熏而起两类。

以上卷第二之中译毕。
