<div class="dt-subtitle">成唯识论白话译注（二十五）　卷第九之上<br>护法等菩萨造　唐　玄奘译</div>

本篇要目：一、第二十三至二十五颂　二、依三性立三无性　三、四种胜义与唯识实性　四、唯识五位总说　五、第二十六颂：资粮位　六、烦恼障与所知障　七、资粮位所修的胜行　八、三种退屈与三种练磨　九、第二十七颂：加行位　十、四寻思与四如实智　十一、暖、顶、忍、世第一法　十二、加行位的局限

一、第二十三至二十五颂

外人质问：如果有三性，为什么世尊说一切法都没有自性？世亲菩萨用颂回答：

```
即依此三性　立彼三无性
故佛密意说　一切法无性
初即相无性　次无自然性
后由远离前　所执我法性
此诸法胜义　亦即是真如
常如其性故　即唯识实性
```

大意：依三性立三种无性，所以佛以密意说一切法无自性。第一是相无性；第二是没有自然生起之性；第三是由于远离前面所执的我法之性。第三种无性是诸法的胜义，也就是真如，因为在一切阶位中常如其性，就是唯识的真实性。

二、依三性立三无性

论中解释：就是依前面所说的三性，立后面所说的三种无性，即相无性、生无性、胜义无性。所以佛以密意说一切法都没有自性，并不是说体性完全没有。说“密意”，显示不是了义。

依他起和圆成实二性，体不是没有，有愚夫对二性增益，虚妄执着为实有的我法自性，就称为遍计所执。为了除去遍计的执着，佛世尊对有与无，总说为无性。

外人质问：怎样依三性立三无性？

论主回答：依第一遍计所执，立相无性，因为遍计所执的体和相毕竟没有，如同空中的花。

依第二依他起，立生无性，因为依他起如同幻事，依托众缘而生，没有如同妄执的那种自然生起之性，所以假说为无性，并不是体性完全没有。

依第三圆成实，立胜义无性，就是说胜义，由于远离前面遍计所执的我法之性，所以假说为无性，并不是体性完全没有。如同太虚空，遍于一切色，是一切色的无性所显示的。

依他起不是胜义，也可以说为胜义无性；因为与第二生无性相混，所以论中不说。

【译注】三无性要读出层次：相无性是“根本没有”；生无性是“有，只是没有自己生起的本性，靠缘而有”；胜义无性是“有，就是远离一切执着的那个真实，因为离执，所以说无”。三个“无”字，意思完全不同。

三、四种胜义与唯识实性

胜义无性就是诸法的胜义，因为是一切法的胜义谛。

胜义谛大略有四种：第一是世间胜义，就是蕴、处、界等；第二是道理胜义，就是苦等四谛；第三是证得胜义，就是二空真如；第四是胜义胜义，就是一真法界。

颂中的胜义，是依最后一种而说，因为是最殊胜的道所行的境义。为了简别前三种，所以颂中如此说。

“此诸法胜义，亦即是真如”：

```
真谓真实，显非虚妄；
如谓如常，表无变易。
```

大意：“真”是真实，显示不是虚妄；“如”是如常，表示没有变易。

真如在一切阶位中常如其性，所以称为真如，就是湛然不虚妄的意思。“亦”字显示真如还有许多名称，如法界、实际等，如其余论中随义广释。

真如就是唯识的真实性。唯识性大略有两种：一是虚妄的，即遍计所执；二是真实的，即圆成实性。为了简别虚妄，所以说“实性”。又有两种：一是世俗的，即依他起；二是胜义的，即圆成实。为了简别世俗，所以说“实性”。

三首颂总显：诸契经中说“无性”的言语，不是究竟了义。一切有智慧的人，不应依此全盘否定诸法都没有自性。

【译注】“一切法无自性”是般若经的名句。唯识宗以三无性会通般若：般若说空，空的是遍计所执，不是依他起的缘起，更不是圆成实的真如。把“无自性”理解为“什么都没有”，就是恶取空。

四、唯识五位总说

外人质问：以上所成立的唯识相与唯识性，什么人，在几个阶位，怎样悟入？

论主回答：具足大乘两种种姓的人，大略在五个阶位中逐渐悟入。

外人质问：什么是大乘两种种姓？

论主回答：一是本性住种姓，就是从无始以来依附于本识、法尔所得的无漏法之因。二是习所成种姓，就是听闻从法界等流出的正法之后，由闻所成慧等熏习所成。要具足大乘两种种姓，才能逐渐悟入唯识。

外人质问：什么是悟入唯识的五个阶位？

论主回答：

一是资粮位，就是修习大乘的顺解脱分。

二是加行位，就是修习大乘的顺抉择分。

三是通达位，就是诸菩萨所住的见道。

四是修习位，就是诸菩萨所住的修道。

五是究竟位，就是安住于无上正等菩提。

外人质问：怎样逐渐悟入唯识？

论主回答：诸菩萨在资粮位中，对唯识的相与性能深深信解。在加行位，能逐渐伏除所取和能取，引发真实的见道。在通达位，如实通达唯识。在修习位中，依所见的道理一次次修习，伏除、断除其余的障碍。到究竟位，出离障碍，圆满明净，能穷尽未来际教化有情，又令有情悟入唯识的相与性。

【译注】五位与唯识的关系可以如此记：资粮位是“信”，加行位是“观”，通达位是“见”，修习位是“修”，究竟位是“成”。

五、第二十六颂：资粮位

外人质问：最初的资粮位，相状是怎样的？世亲菩萨用颂回答：

```
乃至未起识　求住唯识性
于二取随眠　犹未能伏灭
```

大意：直到还没有生起顺抉择的智慧、求住于唯识性之前，对二取的随眠，还不能伏除灭除。

论中解释：从发起深固的大菩提心，直到还没有生起顺抉择分的识、求住于唯识真实胜义性之前，都属于资粮位。为了趣向无上正等菩提，修习种种殊胜的资粮。为了有情而勤求解脱，由此也称为顺解脱分。

资粮位的菩萨，依靠因力、善友力、作意力、资粮力四种殊胜的力量，对唯识的意义深深信解，还不能了达能取所取都是空，多数安住于外门修菩萨行，所以对二取所引的随眠，还没有伏灭的功力，不能令随眠不生起二取的现行。

颂中的“二取”，显示的是二取之取，就是执取能取和所取的体性。二取的习气称为随眠：随逐有情，眠伏在藏识中；或者随着增长过失，所以称为随眠。随眠就是所知障和烦恼障的种子。

六、烦恼障与所知障

烦恼障，就是执着遍计所执的实我，以萨迦耶见为首，一百二十八种根本烦恼，以及根本烦恼等流的一切随烦恼。以上诸烦恼都扰恼有情的身心，能障碍涅槃，所以称为烦恼障。

【译注】一百二十八种根本烦恼：见道所断一百一十二种，即欲界四谛下各十种共四十种，色界和无色界四谛下各九种（除瞋）共七十二种；修道所断十六种，即欲界六种（贪、瞋、痴、慢、身见、边见），色界和无色界各五种（除瞋）。

所知障，就是执着遍计所执的实法，以萨迦耶见为首，见、疑、无明、爱、恚、慢等。以上诸法覆蔽所知境无颠倒的体性，能障碍菩提，所以称为所知障。

所知障决定不与异熟识俱起，因为异熟识微劣，不与无明和慧相应，又因为法空智品可以与异熟识同时生起。在前七转识中，随其所应，或少或多，如同烦恼障所说。眼等五识没有分别，所以法见、疑等决定不与五识相应；其余的由意识的力量，都可以引起。

所知障只与不善和无记两种心相应，因为论中说无明只通于不善和无记性，痴与无痴等不相应。

烦恼障中必定有所知障，因为烦恼障决定以所知障为所依。二障的体没有不同，作用有别，所以二障的随眠，随着圣道作用的胜劣，断除有先后。

【译注】二障的关系：同一个执着，执“我”的一面是烦恼障，执“法”的一面是所知障。法执是我执的根，所以烦恼障依所知障而起。二乘断了我执，法执还在；菩萨要连根拔除。

所知障在无覆无记性中，属于异熟生，不属于其余三种，因为威仪等势用薄弱，不能覆蔽所知、障碍菩提。所知障称为无覆，是对二乘而说；如果对菩萨而说，也是有覆。

外人质问：所知障如果有见、疑等，为什么契经说所知障的种子是无明住地？

论主回答：因为无明增上，所以总称为无明，并不是没有见等。如同烦恼障的种子，立见一处住地、欲爱住地、色爱住地、有爱住地四种住地的名称，难道其中就没有慢、无明等？

二障中分别起的，属于见道所断；任运起的，属于修道所断。二乘只能断烦恼障，菩萨两种都断。永远断除二障的种子，只有圣道能做到；伏除二障的现行，有漏道也可以。

菩萨在资粮位中，二障粗显的现行有的已被伏除；对微细的现行和二障的随眠，因为止观的力量微弱，还不能伏灭。资粮位还没有证得唯识真如，依胜解的力量修种种殊胜的行，应知也属于解行地。

七、资粮位所修的胜行

外人质问：资粮位所修的胜行，相状是怎样的？

论主回答：大略有两种，就是福和智。种种胜行中，以慧为体性的，都称为智；其余的称为福。

依六种波罗蜜多来说：依通相，六度都具福和智两种。依别相，前五度说为福德，第六度是智慧。或者，前三度只属于福德，后一度只属于智慧，其余两度通于两种。

又有两种，就是自利和利他。所修的胜行，随着意乐的力量，一切都通于自利和利他。依别相而说：六到彼岸、菩提分法等属于自利行；四种摄事、四无量心等一切都属于利他行。以上诸行，差别无边，都是资粮位所修的胜行。

八、三种退屈与三种练磨

资粮位中，二障还没有伏除，修胜行时，有三种退屈；能以三事练磨自心，对所证所修勇猛不退。

第一，听闻无上正等菩提广大深远，心就退屈。练磨的方法是：引他人已证大菩提为例，练磨自心，勇猛不退。

第二，听闻布施等波罗蜜多极难修习，心就退屈。练磨的方法是：省察自己的意乐，能修布施等，练磨自心，勇猛不退。

第三，听闻诸佛圆满的转依极难证得，心就退屈。练磨的方法是：引他人粗浅的善尚能得果，何况自己殊妙的因，练磨自心，勇猛不退。

由三事练磨自心，坚固炽热地修习种种胜行。

【译注】三种练磨用的都是论中自己的道理：别人能成佛，我也能；我已有修行的意愿，就能修；别人凭粗善都能得乐果，我以妙因必得妙果。论主不讲空泛的鼓励，只讲可以对照、可以推理的理由。

九、第二十七颂：加行位

外人质问：其次的加行位，相状是怎样的？世亲菩萨用颂回答：

```
现前立少物　谓是唯识性
以有所得故　非实住唯识
```

大意：在心前安立一个小小的东西，认为是唯识性；因为还有所得，所以还没有真正安住于唯识。

论中解释：菩萨先在第一个无数劫中，善加具备福德和智慧资粮，顺解脱分圆满之后，为了进入见道、安住于唯识性，又修加行，伏除二取，就是暖、顶、忍、世第一法。

四种总称为顺抉择分，因为随顺趣向真实的抉择分。因为接近见道，所以立“加行”的名称，并不是前面的资粮位没有加行的意义。

十、四寻思与四如实智

暖等四法，依四寻思和四如实智的初位与后位而立。

四寻思，就是寻思名、义、自性、差别四者，都是假有实无。如实遍知名、义、自性、差别四者离识而不存在，以及识也不存在，称为如实智。名与义的相状不同，所以分别寻求；名的自性差别与义的自性差别两两相同，所以合在一起思察。

【译注】“名”是名称，如“瓶”字；“义”是名称所指的事物，如瓶本身；“自性”是名与义各自的体；“差别”是名与义的种种属性，如瓶的大小、颜色。四寻思就是逐一检查：名称、事物、事物的本体、事物的属性，都只是心中假立，没有离心的实体。

十一、暖、顶、忍、世第一法

依明得定，发起下品寻思，观察没有所取，立为暖位。在暖位中，初次观察所取的名等四法，都是自心所变，假立施设而有，实际不可得。初次获得慧日的前相，所以立“明得”的名称；就是所获得的道火的前相，所以也称为“暖”。

【译注】暖如钻木取火，火未出而先有暖。暖位是见道之火将出的先兆。

依明增定，发起上品寻思，观察没有所取，立为顶位。在顶位中，再次观察所取的名等四法，都是自心所变，假立施设而有，实际不可得。明相转为增盛，所以称为“明增”；寻思到了极点，所以又称为“顶”。

依印顺定，发起下品如实智，对没有所取决定印可执持，对没有能取也随顺乐于忍可。既然没有离开能取之识的实境，怎能有离开所取之境的实识？因为所取与能取是相待而立的。印可和随顺忍可时，总立为忍位。印可前面的所取空，随顺后面的能取空，立“印顺”的名称。忍可境与识都空，所以也称为“忍”。

依无间定，发起上品如实智，印可能取所取二取都空，立为世第一法。前面的上品忍只印可能取空，现在世第一法对二空双双印可。从世第一法无间断地必定进入见道，所以立“无间”的名称。在凡夫的法中，世第一法最殊胜，所以称为世第一法。

以上暖位和顶位，依能取之识观察所取空。下品忍生起时，印可境空之相。中品忍转进时，对能取之识，如同境一样是空，随顺乐于忍可。上品忍生起时，印可能取空。世第一法，双印二空之相。

【译注】加行四位的进程，一步一步去掉执着：暖、顶先观所取空，即对象不实；忍先印所取空，再随顺、印可能取空，即主体也不实；世第一法把两者同时印定。下一刹那，就是见道。

十二、加行位的局限

暖等四位都带着相，所以还不能证实。所以说菩萨在加行四个阶位中，仍在心前安立一个小东西，认为是唯识真实胜义性，因为空和有两种相还没有除去，带着相的观心还有所得，并没有真正安住于真实的唯识之理。空有二相灭了之后，才真正安住。依此意义，有偈颂说：

```
菩萨于定位　观影唯是心
义相既灭除　审观唯自想
如是住内心　知所取非有
次能取亦无　后触无所得
```

大意：菩萨在定中，观察一切影像都只是心；外境之相既已灭除，审察观照只是自己的想。如此安住于内心，了知所取不存在；其次了知能取也不存在；最后触证无所得。

【译注】“现前立少物”是加行位最微细的障碍：心里还举着一个“唯识”的观念，还在“观空”。只要还有一个在观的心、一个被观的空，就仍是二取。见道时，连“唯识”的观念也放下，能所双泯，才真正住于唯识。

加行位还没有遣除相缚，对粗重缚也还不能断除，只能伏除分别起的二取，因为分别起的二取违背见道。对俱生的二取以及二取的随眠，因为有漏的观心还有所得、还有分别，所以还没有完全伏除，完全不能灭除。

加行位的菩萨，对安立谛和非安立谛都学习观察，为了引生将来的真见道和相见道，以及伏除分别起的两种障。非安立谛是加行位真正所观的，不像二乘只观安立谛。

【译注】安立谛是可以用名言安立的四谛差别相；非安立谛是离言的真如。二乘的加行只观四谛，菩萨的加行以观真如为主。

菩萨生起暖等善根，在方便阶段通于诸禅定，要依第四禅才能圆满成就，因为依托最殊胜的所依，才能进入见道。暖等善根只依欲界善趣的身体生起，因为其余诸趣的智慧和厌离心都不殊胜。加行位也属于解行地，因为还没有证得唯识真实胜义。

以上卷第九之上译毕。
