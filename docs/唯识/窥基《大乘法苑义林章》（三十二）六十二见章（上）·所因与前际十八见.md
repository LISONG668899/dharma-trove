<div class="dt-subtitle">大乘法苑义林章白话译注（三十二）<br>唐　窥基　撰</div>

〔译注：《六十二见章》是全书第十四章，讨论《长阿含·梵动经》所说外道的六十二种见解。窥基明确不依《智度论》《梵网六十二见经》《大毗婆沙论》等的配法，只依《瑜伽师地论》第六、七、八、五十八、八十七卷，《显扬》，《杂集》，《成唯识》来解释。原文约五千七百字，分两篇。本篇译第一门"所因"与第二门中"计前际"的五类十八见。〕

六十二见，简略用五门分别：

1. 说明所因
2. 辨明名相
3. 出体性
4. 迷谛的通与别
5. 问答分别

第一门　说明所因

略有两种因：一是佛宣说的因由，二是见解生起的因由。

一、佛宣说的因由

依《长阿含经》第十四卷《梵动品》：

佛游化摩竭陀国，在人间游行，来到竹林园，住在讲堂。当时有一位梵志，名叫善念，有一位弟子名叫梵摩达，师徒常常一起跟在佛后面行走。善念梵志以无数方便毁谤佛、法、僧；梵摩达以无量方便赞叹佛、法、僧。师徒二人各怀不同的心意，互相违背，因为所习的见解不同，所亲近的也不同。

当时诸比丘饭后一起来到讲堂中，这样议论："很奇特！世尊有大神力，威德具足，完全知道众生心意所趣向。善念梵志毁谤佛、法、僧，弟子梵摩达以无量方便称赞如来、正法以及比丘，师徒各怀不同的心意。"

佛在静室中，以清净的天耳，听到诸比丘这样的言论，来到讲堂，明知而故意问："你们刚才在说什么？"诸比丘说："刚才一起谈论，很奇特，世尊……"乃至广说师徒二人各怀不同见解，具体陈述那件事。

世尊告诉诸比丘："如果有人毁谤佛、法、僧，你们不得心怀忿恨、心生加害；如果怀有这种心意，就自己陷溺了。如果有人赞叹佛、法、僧，你们不必因此欢喜；如果生起欢喜心，也自己陷溺了。这是弱小的凡夫，寡闻，不通达深义，只是以自己所见，如实地赞叹佛法僧宝。另外还有其余的法，甚深微妙，是大法光明，只有贤圣弟子，能以这种法赞叹如来。

各种沙门、婆罗门等，对于本劫的本见、末劫的末见，种种无数，随其意所趣入的，全部进入六十二见之中，没有超出的。只有如来知道这些见处这样运转、这样执着，又超过这些，知道而不执着，因为不执着，就得到寂静、无余的解脱。所以称为如来甚深微妙的大法光明，贤圣弟子真实平等地赞叹如来。"

《瑜伽师地论》也说：由于依这六十二见，能显示见趣的不正法藏，师徒辗转传闻、相互传授作为方便，所以世尊宣说这些见解。

二、见解生起的因由

《瑜伽师地论》说：那一切见解，都以萨迦耶见作为因缘。因缘有亲有疏：

1. 亲近依我见，各种见解才生起；不然的话，就不属于边见所摄。由于亲近依止我见，所以说为边见。
2. 疏远相依的，说为邪见，因为缘梵王是常等，有邪见。

以上总的是第一门，说明所因。

第二门　辨明名相

一、不依的诸说

1. 《大智度论》说：以身见、边见二见作为根本，有二十句我、我所见，三世合计，加上根本的二见，成为六十二见。这不是本宗所依，因为该论依据的《阿含经》承认无色界有色身，是大众部的经，不可完全凭依。
2. 《梵网六十二见经》与《舍利弗阿毗昙》相同，属于正量部，也不是本宗所依。
3. 《大毗婆沙论》第一百九十九卷以及第二百卷，有广泛说明，只是属于萨婆多部，也不是所依凭的。

以上都不是大乘的义理，现在都不依。

二、本宗所依

现在依《瑜伽师地论》第八十七、六、七、八以及五十八卷，《显扬圣教论》第九、十卷，《杂集论》第一卷，《成唯识论》第六卷。这些上下诸文自己广泛解释，既然是本宗自己的义理，在道理上应当依凭。

先列出总的名相，后辨明别的名相。

三、总的名相

《瑜伽师地论》第八十七卷说：以萨迦耶见作为根本，有六十二种恶见趣。

（一）计前际的十八见

1. 四种遍常见论
2. 四种一分常见论
3. 两种无因论
4. 四种有边无边想论
5. 四种不死矫乱论

这十八种恶见趣，是计前际、说我的论。

（二）计后际的四十四见

1. 十六种有见想论
2. 八种无想论
3. 八种非有想非无想论
4. 七种断见论
5. 五种现法涅槃论

这四十四种恶见趣，是计后际、说我的论。

这样前际、后际各有五类，总共成为十类。

四、前际与后际的意义

"际"是边际、时分的意思，就是《阿含经》所说的本劫、本见、末劫、末见。

《瑜伽师地论》第八十七卷说："各种见依于世：依于过去以及现在世生起分别，所以称为计前际；依于未来世生起分别，所以称为计后际。"

这是约多数情况来说二际的道理。比如四种全常见中的第四种常见，见到死此生彼，现在称为前际。像这类都是依多数情况的意义，不是依实际的意义。比如五种现法涅槃论，说为后际，实际上只是现在。所以可知现在通于前际和后际：称为前际，因为在未来之前，是未来的因；或者称为后际，因为在过去之后，是过去的果。由此现在通于前后二际。

辨明了总的名相。

五、别的名相：计前际的五类十八见

《瑜伽师地论》第六卷、《显扬圣教论》第九卷说：应当知道，这里计前际的，就是：

1. 或者依下、中、上品的静虑，生起宿住随念，由于不善的缘起，对于过去的诸行，只是忆念，不能如实了知，计执过去世作为前际，发起常见。
2. 或者依天眼，计执现在世作为前际，对于诸行刹那生灭流转不能如实了知；又见到诸识流转相续，从这个世间到那个世间没有断绝，发起常见。

（一）四种遍常见论

《瑜伽师地论》第八十七卷说："与宿住随念同时运行的，就是计前际。三种常论中，由于下、中、上品清净的差别。"

现在观察论的意思：由于依静虑的宿住随念有下、中、上三品，分成前三种常见：

1. 忆念过去二十个成坏劫。
2. 忆念四十个成坏劫。
3. 忆念八十个成坏劫。

由于宿住随念有三品，所以所见有远有近。"伊师迦"是数论派所用的譬喻之名，说一切法都是常，世间只是隐与显，不是灭坏，所以计执为常。因为说三品静虑所见，六十劫的宿住不缘，所以只有三种。

《瑜伽师地论》第六卷等又说："或者依天眼，计执现在世作为前际，对于诸行刹那生灭流转不能如实了知；又见到诸识流转相续，从这个世间到那个世间没有断绝，发起常见。"这个意思就显示：以天眼见到有情的诸识流转，死于此处生于彼处，不能如实了知诸行刹那生灭流转，所以执为常。这是第四种常见。

总的审察这个意思：前三种见与《阿含经》相同，第四种就不是。《阿含经》中的第四种，是以捷疾智计执一切是常，不是由天眼。第八十七卷也说"与天眼同时运行"。这里的前三种，总合就是《大毗婆沙论》的第一种；这里的第四种，就是《大毗婆沙论》的第三种；《大毗婆沙论》其余两种常见，这里没有。

第八十七卷说，这四种常见都依静虑，不说依散心。《大毗婆沙论》说：第一种观劫，第二种观生，第三种观现在死此生彼，第四种依寻伺。

如果有人说：这前三种，就是《瑜伽师地论》所说依下、中、上三种静虑。即使这样，也有违背天眼的过失，因为《瑜伽师地论》第六卷说第四种就是依天眼所见，不是寻伺。

（二）四种一分常见论

1. 从梵天殁后来生此间，得到宿住通，观察先前所来之处，作这样的执着："我们都是梵王所化生。梵王是常，因为不见梵王的始终；我们是无常，因为见到我们现在来到这里。"常论中说"或者见梵王随意成立"，就是这种见。

2. 听说梵王有这样的见解：大种是常，心等是无常；或者相反。认同这种说法的人，或者住在梵世，乃至或者辗转听闻这样的道理："我以梵王为准则，相信梵王所说。"所以认为世间一部分是常住。常论中说"或者见四大种变异，或者见诸识变异"，变异就是无常，就是这种见。

3. 有人先前从戏忘天殁后来生此间，得到神通，生起执着："在那里的诸天不过度嬉戏等，在那里常住；我们是无常。"

4. 有人先前从意愤恚天殁后来生此间，得到神通，生起执着："在那里的诸天不过度愤恚，在那里常住；我们是无常。"

后面这两种天，依《瑜伽师地论》第五卷"自己能害而不是他人能害而死"这一句，就只是欲界中上面的四空居天，因为下面的两种天是被他人所害的。

这四种见，第八十七卷说都依静虑了知过去，所以称为前际。《大毗婆沙论》的四种与此相同，只是后两种天的说法不同，该论有两种说法：一说就住在妙高山的层级上，一说就是三十三天。

这四种见，由于执着大梵、大种，或心、戏忘、愤恚而生起。《阿含经》说没有这里的第二种，其余三种与此相同，另外加上捷疾世智对其余三者所计执的半常半无常。这些说法有言说，相状仍然难见，不只是宗派不同、义理有别，也很难领会其意。

（三）两种无因论

1. 从无想天殁后来生此间，得到宿住通，不能忆念那出心以前的所有阶位，便执着诸法本来没有而生起。"诸法如此，我也应当一切本来没有而生起。"便执着我以及世间无因而起。
2. 由于寻思，不能忆念前身，作这样的执着："无因而起……"乃至广说。

所以《瑜伽师地论》第七卷的无因论说："就是依静虑以及依寻思两种差别，见到各种因缘空无果报：大风突然生起，忽然又平静；暴河弥漫，忽然又成为空竭。所以作这样的执着。"《阿含经》等相同。

（四）四种有边无边论

《瑜伽师地论》第七卷、《显扬圣教论》第九卷说：

1. 如果依断的边际来求世间的边际：如果忆念坏劫，就对世间生起有边的想法，因为世界坏后临近空劫，有边限。
2. 如果忆念成劫，就对世间生起无边的想法，因为距离坏劫很远，不见边际。
3. 如果依方域周广来求世间的边际：如果向下过了无间地狱，再无所得；向上过了第四静虑，也无所得；向旁边一切处，都得不到边际。就对上下生起有边的想法，对旁边的处所生起无边的想法。
4. 如果为了对治这种执着，只依不同的文句，意义没有差别，就对世间生起非有边非无边的想法。

前两种见缘过去而生起，后两种缘现在而生起，相对于未来，所以称为前际。边无边论说四种都依静虑而生起。

第八十七卷又说："与宿住随念同时运行的，就是四种边无边论。由于忆念各种器世间成、坏，世间出现的方便。如果忆念成劫的分位，那时便生起四种妄想：

1. 如果有人一向忆念上下，下至无间地狱之下，上至第四静虑之上，忆念这样的分量边际，便对世间安住有边的想法。
2. 如果有人一向忆念旁边无际，便对世间安住无边的想法。
3. 如果有人忆念两种同时运行，便对世间安住两者都有的想法。
4. 如果忆念坏劫的分位，那时便生起非有边非无边的想法，因为各种器世间无所得。"

两处文字分别说了两种这样的见，由于有这样的行相，总的称为边无边论。

《阿含经》说，这第四种见依捷疾智；《瑜伽师地论》的四种都依静虑宿住智而生起。

《大毗婆沙论》说：

1. 以天眼见到下至地狱、上至初禅，执着我在其中全都遍满，便作这样的念头："超过这里如果有我，我应当可以看见。"所以知道有边。
2. 向旁边见到无边而作执着，同前面一样生起无边的想法。
3. 依天眼以及神境通，见下见上，如最初的近远；运身向旁边去，得不到边际。对上下生起有边的想法，对旁边生起无边的想法。
4. 与此相反。

四种都缘现在，相对于未来，所以称为前际。只有第四种见与第八十七卷不同，其余三种见相同。见到上面也有近远。

《阿含经》总相而说，得定以后生起执着有边、无边，不说缘什么分齐而生起执着。《阿含经》的第三种见与《大毗婆沙论》相同；第四种见依捷疾智而生起这种执着，也不说缘什么境界而生起，所以不可依。

（五）四种不死矫乱论

《瑜伽师地论》第八十七卷说："清净天有两种：一是不善清净，二是善清净。只进入世俗定的，称为不善清净，因为还没有了达谛理，心还没有解脱。如果证得内法的定，称为善清净，因为已经了达谛理，心善于解脱。

无乱也有两种：一是无相、无分别，二是有相、有分别。前一种是善清净天，后一种是不善清净天。

前一种清净天，对于自己的不死无乱而运转，所以称为不死无乱。后一种不清净天，如果有人依于不死无乱有所诘问，便假托其他的事，以矫乱的言辞避开，因为对谛理和无相心定不善巧。先生起心思这样思惟：'我们既然称为不死无乱，还有其他的不死无乱，对各种圣谛、无相定已经得到善巧，那些人所成就的功德比我们殊胜。那些人如果在其中诘问我，我如果作出记别，或者作出不同的记别，或者拨无实有，或者承认非有……'那些人对记别见到这样等等的各种过失以后，作这样的思惟：'我对一切诘问都不应当记别。'"

观察这段文的意思：就是所事奉的天称为不死，也称为无乱，应当说"不死无乱"。说"不死矫乱"，就是一个"不"字贯通两处，就是不死、不矫乱。或者那些人自称作这种无乱回答的人，生到不死天；现在毁责这些外道，称为矫乱。又以圣者真正是不死、清净无乱的天，这是能问的人；现在回答这种天的各种诘问，称为不死不矫乱天。

第八十七卷的意思，有四种情况：

1. 怖畏无知："不要让他人由此看出我无知，因而轻视讥笑我。"以此作为回答。
2. 行谄曲：行谄曲的人这样思惟："不是我们这些清净天对一切隐密的事都允许记别，就是自己所证的，以及清净道。"所以假设矫乱的言辞。
3. 怀恐怖、不得解脱：又怀着恐怖，不作记别："不要让我的低劣暗昧被他人知道。"由于这个因缘，不能解脱，以此为屋室而自己安处，就是把恐怖以及不解脱作为屋室，自己安处其中。
4. 愚戆：又有愚笨的人，专修止行，不能作矫乱的言辞，只是这样思惟："凡有来问的人，我应当反过来诘问，随着那人的回答，我一切都随顺那人，无所减少地印可随顺。"

《十六异论》中说：那些外道，如果有人来，依最胜生道（生天之道）问善与不善，依决定胜道问四圣谛，便自称说是不死无乱。随于处所，依不死净天不乱的诘问，就对所问的以言辞矫乱；或者假托其他的事方便避开；或者只随着问者的言辞而转。

1. 第一种，觉悟未开。该论第二个"复次"说："怖畏妄语，以及怖畏他人知道自己无智，所以不分明回答'我无知'。"这个意思是说：本性有识，只是觉悟未开。如果说"我懂"，就是妄语；如果说"不懂"，他人就知道我一无所知。所以以矫乱的言辞回答。
2. 第二种，对所证之法生起增上慢。第二个"复次"说："对自己所证还没有得到无畏，害怕他人诘问，怖畏妄语以及怖畏邪见，所以不分明说'我有所证'。"恐怕他人问其所证，因为还没有无畏，所以不能如实回答；回答就成为邪见，不回答就成为妄语。
3. 第三种，觉悟已开而还没有决定。第二个"复次"说："怖畏邪见以及妄语，害怕他人诘问，所以不分明说'我不决定'。"这个意思就显示：有少许所得，心还没有决定，回答就是邪见，不回答就是妄语；因为已经有所知，便以矫乱的言辞回答。

这样三种，假托其他的事，以言辞矫乱。

4. 第四种，羸劣愚钝。第二个"复次"说："只是害怕他人诘问，对于胜生道以及决定胜道都不了达，对于世间文字也不善知，又不分明说'我愚钝'，只随着他人的问话随言而转。"这个意思是：由于愚痴，完全没有了解，所以随着反问来回答前面的问题。

这与《阿含经》完全有差别。《阿含经》依四种问题成为四种差别：

1. 问世间有报还是无报？
2. 问有没有他世？
3. 问善还是非善？
4. 自己愚钝，他人问而不知。

《大毗婆沙论》说：一是怖畏妄语，二是怖畏邪见，三是怖畏无知，四是怖畏愚痴，所以以矫乱的言辞回答，成为四种差别。

以上五类是前际的见解。
