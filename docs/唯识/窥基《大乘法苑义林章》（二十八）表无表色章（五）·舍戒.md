<p class="dt-title">表无表色章（五）·舍戒</p>

<div class="dt-subtitle">大乘法苑义林章白话译注（二十八）<br>唐　窥基　撰</div>

〔译注：本篇译第五门"得舍分齐"中的"舍"。先说舍的相状：无表是功能不再新长，不是曾得的体性消失；再说各种戒的舍缘：比丘五众律仪五缘舍，其中"犯根本罪是否失戒"一节，窥基会通《十轮经》《涅槃经》《大方等陀罗尼经》与《瑜伽》的不同说法；其后依次说近事、近住、菩萨戒、静虑律仪、无漏律仪、不律仪、处中无表、十善业道的舍缘。文中两段陀罗尼照录原文，不作翻译。〕

上面辨明了得，下面辨明舍。舍分两部分：一是舍的相状，二是舍的因缘。

一、舍的相状

最初得到的功能念念增长；舍，是让功能不再新长，只是随顺旧有的而安住，不同于前面的阶位，不再新生，就称为舍。并不是舍弃往昔曾得到的体性，令其消失，称为舍。这与小乘所说的"得"属于自己不同。

身、语两种表，发起无表的，最初一念称为得，第二念中就称为舍。即使有相续，也不称为发起无表的表，只是随转，不是决定转，因为不是由于这个而发起身语，所以有这种情况，三性都不确定。

佛就不是这样。除了佛以外，都是未曾得到的，念念新生。佛是曾经得到的，只是随顺旧有的而安住，由于不萎缩、不歇止，所以不称为舍戒。所以《成唯识论》说："依于思和愿的善恶分限，假立无表。"佛的誓愿不萎缩，所以不称为舍，不同于因位。不然的话，诸佛的功德就不圆满了，因为念念新生，有未曾得到的。不然的话，前后诸佛就应当有胜劣，前佛的戒多，后佛的戒少。

发起无表的表业只在最初；其余的表业不是无表的因。

二、别解脱无表的舍缘

（一）比丘五众律仪：五缘舍

《瑜伽师地论》第五十三卷说，比丘等五众律仪，由五种因缘而舍：

1. 由舍弃所学的学处。
2. 由犯根本罪。
3. 由男女根隐没，或二形生起。
4. 由断善根。
5. 由弃舍众同分。

1. 舍所学处

就是律中所说的作法弃舍：对着比丘长跪作法，说出弃舍的语言，戒才成为舍。如果生起舍戒的心，即使说出语言，不对着比丘依法说舍，只称为戒羸，戒并没有舍。后来作罪的时候，称为污戒沙门所摄，不是白衣。由此比丘称为舍学处。近事、近住各自生起不同分的心，不必作法对他人，就成为舍。

2. 犯根本罪：是否失戒的两种说法

依《十轮经》第四卷，说犯重戒不舍戒。那部经说："善男子，如果有比丘对各种根本性重罪中，随犯一种，称为破戒、恶行的比丘，这样的比丘在亲教和合僧中所得的律仪，仍然没有断绝，乃至还没有弃舍所学的尸罗，仍然有白法的香气跟随。国王、大臣、各种在家人，没有律仪，不应当轻慢以及加以惩罚。这样的比丘不是法器，退失圣法，秽杂清净的僧众，破坏一切沙门的法事，不得受用四方僧物，在亲教和合僧中所得的律仪没有弃舍，所以仍然胜过一切在家白衣。犯性罪的尚且应当这样，何况犯其余各种小的遮罪。所以不允许国王、大臣、各种在家人轻慢以及加以惩罚。"

这里有两种解释。

第一种解释：犯重不一定失戒，要看心的品类。

《瑜伽师地论》第四十卷解释菩萨戒说："如果生起上品缠，犯根本罪，就舍戒，因为没有惭愧。上品缠尚且令焚灭一切善根，何况所受的戒。"上品缠，就是对四种根本罪数数现行，完全没有惭愧，深生爱乐，见为功德，称为上品缠；不是暂时现行就称为弃舍。不共住，是惩治处罚的方法，不是失戒的意思。以中品、下品缠犯，戒不舍。《瑜伽师地论》依据上品缠犯来说，《十轮经》只依据中品、下品缠犯来说。

所以《涅槃经》第三十四卷，迦叶菩萨问未来世二十一对诤论的意义，这是第十八对。到第三十五卷中，佛为他解释说："善男子，我在经中这样说：'如果有比丘犯四重戒，就不称为比丘，称为破比丘、亡失比丘，不再能生起善的芽种。譬如烧焦的种子不能生出果实，如多罗树头如果断坏，就不生果实。犯重的比丘也是这样。'我的弟子们听了这话，不理解我的意思，宣唱说：'如来说诸比丘犯重禁以后，就失去比丘戒。'

善男子，我在经中为纯陀说四种比丘：一是究竟到道（《俱舍论》称为胜道沙门），二是示道，三是受道（新译称为命道），四是污道。犯四重的，就是污道。我的弟子们听了这话，不理解我的意思，宣唱说：'如来说诸比丘犯四重以后，不失禁戒。'"

依照观察经文的意思：如果犯四重一向失戒，那么说"一向失戒"的就应当是理解佛意；如果一向不失，说"一向不失"的也应当是理解佛意。为什么都说"不理解"？所以可知，以上品、下品两种心犯戒，有失与不失的差别。

诸经中多说，如果有人犯四重禁，诵持这个咒语，罪都消灭，没有说戒体是否会重新生起。《大方等陀罗尼经》第四卷说：

文殊师利对佛说："如果有比丘在佛灭度以后毁犯四重戒，如果比丘尼毁犯八重戒，如果菩萨以及沙弥尼、优婆塞、优婆夷，毁犯这样的各种戒，应当怎样灭除这些过失？"

佛说："如果恶比丘毁犯四重禁，默然接受供养而不改悔，应当知道这个比丘必定受地狱之苦，没有疑问。我现在应当拿出良药，救度这些比丘。"

「离波离波帝　仇呵仇呵帝　陀罗离帝　尼呵罗帝　毗摩离帝　莎呵」

"这是三世七佛所宣说，救度末世恶律仪的比丘，令其坚固安住于清净之地。如果犯四重戒，至心忆念这个陀罗尼，诵一千四百遍，才作一次忏悔。请一位比丘作为证人，自己陈述罪过，在佛像前这样依次八十七日忏悔以后，各种戒根如果不还生，没有这种道理。那个人在八十七日以后，如果不坚固于无上菩提，也没有这种道理。

怎样知道得以安住清净戒？如果在梦中见到有师长用手摩他的头，或者父母、婆罗门、耆旧、有德之人，这样等人，或者给予饮食、衣服、卧具、汤药，应当知道这个人安住清净戒。

如果比丘尼犯八种罪，应当诵这个陀罗尼。"咒语说：

「阿疑离波　其罗帝　罗帝婆　摩罗帝呵　摩罗帝　莎呵」

"九十七日，诵四十九遍，才作一次忏悔。"经中广说菩萨以及沙弥等灭罪的方法。

那部经第一卷中，说陀罗尼也说："犯比丘戒、比丘尼戒等，应当作一次忏悔，如果戒根不还生，没有这种道理，除非不至心。"所以可知，犯重戒而不失戒，只称为污戒。如果不是这样，怎么能后来还得清净？《佛名经》中所说也大致相同。

依《四分律》，与萨婆多部一样，犯重不失戒。"不共住"是惩治处罚的方法，不是失戒的意思。

第二种解释：犯重，不问是什么心，决定失戒。

《瑜伽师地论》第五十三卷说"犯重所以舍"。《菩萨地》第四十卷解释菩萨戒说："如果以软品、中品缠，毁犯四种他胜处法，不舍菩萨的清净戒律仪；以上品缠犯，就称为舍。如果诸菩萨毁犯四种他胜处法，数数现行，完全没有惭愧，深生爱乐，见为功德，应当知道称为上品缠犯。并不是诸菩萨暂且一次现行他胜处法，便舍菩萨的清净戒律仪，像诸比丘犯他胜法，就弃舍别解脱戒那样。"

这里的意思是说：菩萨的清净戒，以上品缠犯才失戒；并不是诸菩萨以中品、下品缠犯也称为失戒，像诸比丘犯重就失戒那样。这就是反过来显示：比丘犯重，以中品、下品心也就失戒；菩萨就不是这样。所以说"并不是诸菩萨暂且一次现行，就称为犯"等。完整地读论文，义理和道路也很深远。

所以可知，菩萨犯重，有失戒有不失戒；破戒的比丘犯重，决定失戒。不可以用菩萨戒犯重有失有不失，来证明比丘也相同，原因是：

1. 比丘的意乐广大深远，是为了成为法器。
2. 菩萨种种都是引摄。

所以第四十卷说：由此菩萨犯重失戒，今生还可以再受；比丘今生不能再受，因为恶的意乐之思损坏了善器。如果因二形生起，以及断善根、作法弃舍而失戒，后来没有先前的事，今生还可以再受，因为不是污戒。

《十轮经》等是为了护持末法的僧众，止息诽谤，化导世俗，所以说不失戒，并不是实际上不失。《涅槃经》由此说：犯重实际上失戒，为了止息诽谤说不失。所以说"决定失"或"决定不失"的，都是不理解佛意。

《方等经》中只是说忏悔，犯重的罪消灭；说戒根"还生"，是引接的言语，也不相违。所以经中说："犯重的人，世尊不允许吃僧祇的饮食，下至一团；不允许踏上毗诃罗（寺院）一足跟的地方；摈出一切比丘的业事。"所以佛又说："应当迅速拔除稻禾中的稗草，应当迅速简择腐朽的栋梁，应当迅速簸扬种子中的糠秕，应当迅速摈除貌似比丘的人。"所以可知，犯重决定成为失戒。

律中自己说"不犯"的情况：最初还没有制戒的时候，痴狂、心乱、被病恼所缠的时候。由此可见，"犯重不失戒"这种解释，经文多，道理也正。又，犯戒的人实际上有上、中、下三品心，为什么一类心都令失戒？所以前一种解释较好。

〔存疑：此段原文「虽有此解言不失戒，文多理正。又犯戒者实有三心，何因一类是令失戒，故前解善」，紧接在第二解的论证之后，又回到第一解。此处理解为窥基最终取第一解，即依心的品类判定失与不失。〕

3. 形没、二形生

"形没"有两种解释。

第一种解释：一种形体隐没，没有形体的时候不失戒。就像证入圣位的人，即使失去形体，戒也不失。我们知道圣人不会成为无形，比如凡夫时得戒，后来被虫咬食，被虫咬食的时候就进入见谛，当时先前的戒都不失，因为进入见谛以后不失戒，可以失去形体。说"形没"，是因为二形生起的时候，先前只有一形，必定转而隐没，才成为二形，并不是没有形体就失戒。如果先前没有形体而受大戒，就不能得戒，因为意乐低劣，不是道器。受戒以后可以没有形体，因为意乐不低劣。

第二种解释：应当是六缘舍戒。一形隐没的时候，戒必定舍；二形后来生起，先前的一形还在，怎么称为隐没？只是因为二形、无形都失戒，论中在一处说，实际上是六缘。没有进入见谛而被虫咬食的说法，不可以用小乘来扰乱大乘的义理。

问：如果这样，各种渐渐命终的人，先从下身死去，难道过了形体就失戒？后来如果复苏，必须再受戒吗？

答：这又有什么错？先前没有形体的时候，戒已经舍了，何必要等到命终？

问：如果这样，这里最初生起，这里最后舍去，《瑜伽师地论》第一卷说最后的心才死，死的阶位一切先前都没有形体，怎么还会有命终舍戒？

答：二形先有，受戒不能得；后来二形生起，也决定舍戒。无形不是这样：先有，受戒不能得；后来生起，不舍戒。因为二形之器恶劣，男女的烦恼恒常同时现前，障碍法器。无形最初就有，道理也相同；后来才有，不失戒，因为不坏本性，不障碍圣道。二形就坏本性，障碍圣位。所以《俱舍论》说："成就未知当知根的，决定成就十三根，就是信等五根、身根、命根、意根、四受根（除去忧根），以及未知当知根。"没有说决定成就男根、女根其中之一，所以可知诸圣者也有无形。

4. 断善根

有两种心受戒，就是生得善心和加行善心。断善根，是断生得善，不是断加行善。

1. 以加行善心受戒的，在断善根之前的加行道中，戒已经失去。以断善作为因缘，也称为断善。
2. 以生得善心受戒的，要邪见生起现前，戒才失去。

戒通于以上、中、下三品心受，邪见到第九品才断尽善根，戒也是这样。只说断善时舍，不说最初就舍。

5. 弃舍众同分

就是命终时舍戒。最后一念正在命终的心，在现在世，戒也在现在，还不称为已舍，可以称为正在舍，就像世第一法舍异生性一样。如果命终以后，戒进入过去，现在住在中有等，已经舍戒，所以称为舍，因为隔着另一期生命。

这是说另外受持的比丘等戒，不是菩萨戒中的律仪戒。

6. 正法隐没时不舍

《瑜伽师地论》第五十三卷说："如果正法毁坏、正法隐没，即使没有新受的比丘律仪，先前已经受得的，应当知道不舍。为什么？因为那时坏劫正在生起，没有一个有情不损坏意乐而能受具足戒，何况会有证沙门果的人。"所以受戒不能得，先前的戒不失。

（二）近事律仪：三缘舍

近事律仪由三种因缘而舍：

1. 生起不同分的心。这里摄有期限的势力：期限多少年岁，受戒、舍戒，因为承认有少时、多时、尽形寿的近事。
2. 断善根。
3. 弃舍众同分。

正法隐没时，如比丘律仪，道理应当了知。没有犯重舍，也没有形没、二形生的舍。

《杂集论》第八卷说："问：如果只修学邬波索迦的一分学处，是说成就邬波索迦律仪，还是说不成就？答：应当说成就，只是称为犯戒。"所以可知犯重不失近事戒。

该卷又问："扇搋迦、半择迦等，是遮止这类人受近事戒，还是不遮止？"答："不遮止这类人受近事律仪，只是遮止这类人的身份，因为不堪承事比丘、比丘尼二出家众。"二形也是这样，男女的烦恼恒常同时现行，不堪亲近承事二众，所以不另外说。

《瑜伽师地论》第五十三卷说："为什么扇搋、半择，受了归依，也能随护诸近事男所有的学处，也不得称为近事男？答：近事男，各自能亲近承事比丘、比丘尼众。扇搋等能护持所受的律仪，不应当数数亲近承事出家二众；出家二众也不应当亲近摄受、抚摩、触碰这一类人；又也不应当像近事男那样相亲近。所以不得称为近事男。扇搋等受持护持所有的学处，应当知道福德等没有差别。"所以可知，形没、二形生的时候，也不失近事戒。

（三）近住律仪：三缘舍

近住律仪也由三种因缘而舍：

1. 由日出以后。这只是引接一类初机，没有另外的一法遮碍戒。如果心中期限满足，即使约期多日，有什么道理不能得戒？所以可知只是佛教的施设，化导初机。
2. 由发起不同分的心。
3. 舍众同分。

没有犯重舍以及形没、二形生舍，意义如前面所说。

关于没有断善舍，有两种说法：

1. 一种说：从道理上应当有四缘。这里"生起不同分心"摄有两种舍：一是生起弃舍的心，弃舍心就是生起不持戒的想法，不同于比丘一向要作法；二是断善根。因为近事戒没有日出舍，近住戒就有，所以合两种都称为生起不同分心，隐显互相彰示，也没有过失。比如先前已经生起邪见的方便，还没有断善根，今天受戒，就断了善根。所以相信应当有四缘，这里说为三缘。
2. 另一种说：只有三缘。因为一日一夜时间极为短促，不需要另外生起断善的方便，所以没有这种舍。先前生起断善的方便，不能受戒；以中品、下品心，即使受也不能得戒，必定要上品心才发戒；上品邪见才断善根。

（四）菩萨戒

《瑜伽师地论》第四十卷说，由两种因缘而舍：

1. 弃舍无上正等菩提的大愿。
2. 现行上品缠，犯他胜处法。

《瑜伽师地论·摄决择分》第七十五卷说，舍的因缘略有四种：

1. 决定发起不同分的心，作休止舍弃的意念。
2. 在有识别能力的丈夫面前，故意发起弃舍的语言，发言对他舍戒。
3. 总或别毁犯四种他胜处法，生起根本罪。
4. 以上品缠，总或别毁犯随顺四种他胜处法的罪，犯随顺罪。

该论又说："这三种戒，由律仪戒所摄持，令其和合。如果能对律仪戒精勤守护，也能护持其余的戒；如果对律仪戒不能，其余的也不能。所以如果有毁犯律仪戒的，称为毁犯一切菩萨律仪。"所以犯四重以及犯随顺罪就失戒的，都是犯了律仪，因为律仪戒是根本。"如果不舍，应当知道在其余的生中也得以随转。"

《菩萨地》的"退菩提心"，就摄《摄决择分》四缘中的前两缘；上品缠犯就摄后两缘。只有以上品缠犯四根本以及随顺四根本的罪，才都失戒。断善根摄在生起不同分心之中，所以不论。又因为退菩提心以前已经失戒，所以断善时不再说舍。

《摄决择分》说："这菩萨戒如果不舍，应当知道在其余的生中也得以随转。"第四十卷说："如果诸菩萨，即使转身遍于十方世界，在在处处受生，不舍菩萨的清净戒律仪。由于这位菩萨不舍菩提大愿，也不现行上品缠犯，即使转生到其余的生中，忘失本来的忆念，值遇善友，还得以觉悟菩萨戒的忆念。即使数数重受，也不是新受，也不是新得。"因为受戒的愿心尽未来际，心广大宽漫。其余的戒都不能这样，因为心愿狭小；即使作宽广的心，势力也不能达到。依此推知，比丘、近事、近住，今生还没有舍戒，重受也可以，只是不是新得。

第四十一卷说："如果以上品缠犯他胜处法，失去戒律仪，发露悔灭，应当再受。发露的方法如中品缠犯。如果以中品缠犯他胜处法，应当对三个人，或者超过这个数目，对于语言表达意义能觉能受的小乘、大乘补特伽罗，发露悔灭，除去恶作之法……"乃至广说。"如果以下品缠犯他胜处法以及其余的违犯，应当对一位如前面所说有德行的人，发露除悔。如果没有这样有德行的人可以对之发露，应当以清净的意乐生起自誓的心：'我应当决定防护未来，终究不再重犯。'这样对于所犯的，还能出罪，还能清净。"狂乱、苦痛逼迫而作重罪的，不称为犯。

依此推知，近事、近住两类犯戒不舍，应当对有德行、能开导受戒的人，或者自己发誓，发露自誓，还能出罪，还能清净戒体。

四他胜处以及随顺法，如新译的弥勒所造菩萨戒等中所说。无形、二形不遮止受菩萨戒，因为摄受广大，也不说舍。依这些道理，菩萨戒中的比丘等戒，在命终、二形、日出等时都不舍，因为心广大宽漫；另外受持的就不能这样。

（五）静虑律仪：四缘舍

1. 止息舍：出离那个定，生起不同分的心，因为是随心戒。
2. 不行舍：就是易地而舍，从下地生到上地，或从上地生到下地的时候。
3. 失用舍。
4. 永无舍：进入无余涅槃，一切都舍，永远不再成就。因为退失静虑等，就不再成就。

（六）无漏律仪：五缘舍

1. 止息舍：出离那个心，生起不同分的心，因为随心转。
2. 暂无舍：就是退失而舍。慧解脱以及身证的人，退失现法乐住、灭尽定等，或生到下地等的时候。不是退失圣果、生起诸烦恼。上面两种称为暂舍，因为今生还能引生现前。
3. 得果舍：《杂集论》第十四卷说："在各种现观位中，证得后来殊胜品的道时，舍弃先前所得的低劣品的道。如证得这个果所摄的道时，就舍弃这个向所摄的道，因为不再现前。"
4. 练根舍：《瑜伽师地论·摄决择分》第五十七卷说："几种补特伽罗有练根？答：一切有学，以及无学中的退法、思法、护法、住法、堪达种性，不是诸独觉，也不是菩萨，因为本性是利根。"

问：《杂集论》第十四卷说："如果诸菩萨本性是利根，为什么又令修练根？"

答：就是令依利根中的软根，引生利根中的中根；依利根中的中根，又引生上品利根。该论自己会通说："前面说菩萨本性是利根，后来又说时时之中应当修练根，是由于在自己的种类中又有软等三品，后后相引，称为练根。"不然的话，利根就应当只有一品。

第五十七卷说不动种性、独觉不练根，是不进修自乘；菩萨不练根，是不进修他乘。并不是不动法种性以及独觉不进修他乘，也不是菩萨不进修自乘。

第五十七卷又说："预流练根，也可以得一来果；一来练根，不能得不还果，因为对治难得，所得的果大。不还练根，只是进于离欲，不能得无学。"如前面应当了知。

有五种意义，所以需要练根：

1. 少分善根不具足。
2. 为了引生殊胜的定。
3. 为了种植多闻的力量。
4. 为了种植论议抉择的力量。
5. 为了种植观察甚深法忍的力量。

所以除了得果，也有练根而舍道共戒。

5. 进入无余涅槃，一切永远舍弃。

下面三种舍，种子不再成就。以四缘说静虑律仪的舍，以五缘说无漏律仪的舍，总的类别只有一种因缘，就是生起不同分的心，一切都舍，因为现行的思就是无表。所以在各种因缘的前方便中，已经说了舍。现在说种类在现行中相续而生，所以说四缘、五缘而舍。

（七）不律仪：四缘舍

不律仪没有正文，依道理由四种因缘而舍：

1. 誓愿舍：在佛等面前，自己约期发愿永远不再作，就像舍律仪一样舍弃那个思。
2. 受戒舍：如果受出家戒以及近事戒，一切永舍；如果受近住戒，作永舍的思，也永远舍弃。如果心中只是暂时舍，过了第二天早晨，舍近住戒以后，不律仪还会相续，因为那恶思没有永舍。
3. 得定舍：各种定共、道共戒，体性与恶相违。
4. 命终舍：因为约期止息。

有人说形没、二形生也舍，因为所依身改变了。有人说不是这样：承认这两种情况不舍律仪，也可以受得律仪，何况不律仪只是恶的意乐，那种器也是这样，所以没有这种舍。

《瑜伽师地论》第五十三卷说："应当知道这个人，乃至不律仪的思还没有舍弃以前，常常可以称为不律仪者，因为在每一日中，那不善之思广泛积集，那不善业多有现行，应当知道非福运运增长。"所以可知，如前面所说的四种舍比较好。

有人说没有誓愿舍，就像不服药，病终究难以痊愈，所以要受戒、得定、命终才舍。这也不对，因为那个思已经舍弃，就像舍律仪一样。所以前面的说法比较好。

（八）处中无表：六缘舍

处中的无表，如果立为有，这里没有正文。依《俱舍论》第十五卷，说由六种因缘而舍：

1. 受心断坏而舍：就是舍弃所受的，作这样的念头："我从今以后，舍弃先前所受的。"
2. 势力断坏：就是由净信、烦恼的势力，期限的势力断坏，就像射出的箭、陶家的轮等，势力尽了便断。
3. 作业断坏：就是如所受的，后来不再作。
4. 事物断坏：就是所舍施的四事什物、罗网等事物。
5. 寿命断坏：就是所依止的身有转易。
6. 善根断坏：就是生起加行断善根的时候，便舍弃善根所引的无表。

（九）十善业道

十善业道的表和无表，支类不同，大多说与近事戒相同。只是在舍的因缘中，加上期限满足：或一日一夜等，时间长短的期限满足了，就舍弃。
