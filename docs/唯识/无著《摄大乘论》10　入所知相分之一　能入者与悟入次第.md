入所知相分第四

一、入所知相的体

上面已经说了所知相，入所知相应当如何看待？入所知相，就是以多闻熏习为所依，不是阿赖耶识所摄，如同阿赖耶识一样成为种子，为如理作意所摄，似法、似义而生起，似所取事，有见的意言。

【世亲释】“多闻熏习所依”，是被大乘法所熏的自体。“不是阿赖耶识所摄”，因为能对治阿赖耶识。“如同阿赖耶识一样成为种子”，阿赖耶识是一切杂染法的因，多闻熏习也同样是一切清净法的因。“为如理作意所摄”，以如理作意为自性。“似法、似义而生起”，似法与义之相而生起。“似所取事”，似色等义。“有见”，似能见；由此成立有相有见的识。

【译注】意言，是意识的寻思。

二、谁能悟入

谁能悟入所应知的相？是大乘多闻熏习相续、已得逢事无量诸佛出现于世、已得一向决定胜解、已善积集诸善根，因而善备福德与智慧资粮的菩萨。

三、在何处悟入

在何处能悟入？就是在有见、似法、似义的意言上悟入，在大乘法相等所生起的胜解行地、见道、修道、究竟道中悟入：因为在胜解行地，对一切法唯有识性随闻而起胜解；因为在见道，如理通达；因为在修道，对治一切障；因为在究竟道，远离一切障。

【世亲释】在胜解行地，只是听闻一切法唯有识性而深生信解，所以称为能入。在见道，通达意言非法、非义，非所取、非能取。在修道，观意言非法非义、非所取非能取时，能对治一切障。在究竟道，善清净的妙智位中，最微细的障也没有了。

四、由何能入：三种练磨心与断四处

由何能入？由善根力所任持，就是由三种相练磨其心，由断除四处，以法与义为所缘境，止观恒常、殷重加行而无放逸。

【世亲释】“恒常”，是无间断地修；“殷重”，是恭敬地修。

无量世界中无量的人，刹那刹那都有人证得无上正等菩提，是第一种练磨其心。由某种意乐，能行布施等波罗蜜多，我已经获得此种意乐，我由此稍用功力，修习布施等波罗蜜多，就会圆满，是第二种练磨其心。如果有人成就有障碍的善法，命终时尚且能随其所爱，一切自体圆满而生，我有妙善、无障碍的善，到那时为什么不能获得一切圆满，是第三种练磨其心。关于三种练磨，有颂说：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">人趣诸有情<br>处数皆无量<br>念念证等觉<br>故不应退屈<br>诸净心意乐<br>能修行施等<br>此胜者已得<br>故能修施等<br>善者于死时<br>得随乐自满<br>胜善由永断<br>圆满云何无</div>

大意：人趣的有情，处所与数量都无量，念念都有人证得正等觉，所以不应退屈。以清净心的意乐，能修布施等行；最胜的菩萨已经得到此种意乐，所以能修布施等。行善的人临终时，尚且能随所乐而得圆满；殊胜的善由永断诸障而成，圆满怎么会没有？

【世亲释】三种练磨，是对治三种退屈心。菩萨听闻无上正等菩提最胜、甚深、广大、难以证得，心便退屈，所以修第一种练磨。菩萨听闻所修的波罗蜜多最胜、甚深、广大、难以修成，心便退屈，所以修第二种练磨；此中“意乐”就是信与欲，信解波罗蜜多真实有、有功德、能修成，是信，信解之后乐欲修行，是欲。菩萨思惟佛的言教，想到菩提要隔一念才能证得，难以证得，心便退屈，所以修第三种练磨；此中“无障碍善”，就是金刚喻定，能破极难破的微细之障，金刚喻定无间，就得到离一切障的转依。

由远离声闻、独觉的作意，断除作意。由对大乘的种种疑惑得以离疑，因为能永断异慧与疑。由远离所闻、所思之法中的我、我所执，断除法执。由对现前、现住、安立的一切相，无所作意，无所分别，断除分别。关于断四处，有颂说：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">现前自然住<br>安立一切相<br>智者不分别<br>得最上菩提</div>

大意：对现前自然安住的、定中所安立的一切相，智者不加分别，证得最上菩提。

【世亲释】“异慧”，是鄙劣的智慧，对道理动摇；“疑”是犹豫。“大乘的疑惑”，是对大乘所立三自性教法的疑惑：说诸法无自性、无生无灭、本来寂静、自性涅槃等，是依遍计所执说的；说诸法如幻、如阳焰、如梦等，是依依他起说的；说诸法真如、实际、无相、胜义、法界、空性等，是依圆成实说的。了知三类教法的所依，异慧与疑就不再生起。“现前现住”，是现前安住的色等；“安立”，是骨锁等定中所安立的相。对一切所缘境相都不作意、不分别，由无分别的方便才能悟入。

五、由四寻思与四如实遍智悟入

由什么、如何得以悟入？由闻熏习的种类、如理作意所摄、似法似义、有见的意言而悟入。

由四种寻思，就是由名、义、自性、差别都是假立的寻思；以及由四种如实遍智，就是由名、事、自性、差别都是假立的如实遍智，因为四者都同样不可得。

诸菩萨为了悟入唯识，如上所说如实地勤修加行：在似文、似义的意言上，推求文与名唯是意言；推求依文与名所诠的义也唯是意言；推求名与义的自性和差别唯是假立。在证得唯有意言的时候，同时证知：名与义的自性和差别都是假立，因为自性与差别的义相都没有，所以同样不可得。由四种寻思和四种如实遍智，在似文似义的意言上，就能悟入唯有识性。

【世亲释】先推求名、义、自性、差别唯是假立，称为寻思；后如实了知四者真实都不可得，称为如实遍智。推求的时候是寻思，如实了知不可得的时候是如实遍智。

六、悟入什么，如何悟入：绳蛇之喻

在悟入唯识性的过程中，悟入什么？如何悟入？悟入唯识性，悟入相与见二性，悟入种种性。因为名与义，以及名的自性与差别、义的自性与差别，都是假立，六种义都没有；因为所取与能取性现前；因为在同一时间，似种种相与义而生起。

【按】印顺法师《摄大乘论讲记》解说“六种义”：名与义各分三项，就是名、名的自性、名的差别，以及义、义的自性、义的差别，合为六种。六种都是以识为自性而假立，所以说六种义都无所有。

【按】印顺法师又依六种义解说四寻思：名，是能诠的名字；义，是名所诠的义理；自性，是诸法的自体，比如色、声；差别，是诸法上的种种差别，比如常与无常、可见与不可见。名寻思，推求名字唯是意言；义寻思，推求名所诠的义也唯是意言；自性假立寻思与差别假立寻思，推求名与义各自的自性与差别，都只是意识上的假立。推求的时候是四寻思；证得唯有意言，证知名、义、自性、差别都是假立、同不可得，就是四如实遍智。论中说“四寻思”与说“六相意言”，只是开合不同。

【译注】开合的方式是：四寻思中的自性与差别，分别落在名与义两边，就成为六相。

如同暗中的绳子显现似蛇。绳上的蛇不是真实的，因为根本没有蛇。如果已经了知蛇的义没有，蛇的觉知就灭去，绳的觉知还在。如果以微细的品类分析，绳的觉知也是虚妄的，因为绳以色、香、味、触为相；以色、香、味、触的觉知为依，绳的觉知也将灭去。同样，在似文似义的六相意言上，伏除非真实的六相义时，唯识性的觉知如同蛇的觉知，也应当除遣，因为有圆成实自性的觉知。

【无性释】识只是一个，由于所取与能取的差别，同一时间分为两种；又在一个识上似三相显现，就是所取、能取与自证分。一识上有多相显现，所以称为种种。绳蛇之喻成立通达三种自性：绳上的蛇不是真实的，依他起上名等六种遍计所执也不是真实的；依绳的觉知舍蛇的觉知，如同依唯识显现的依他起觉知，舍弃六种义的遍计执觉知；依色等细分的觉知除遣绳的觉知，如同依圆成实的觉知，除遣依他起的迷乱觉知。

七、悟入三性

如上所说，菩萨由于悟入意言似义之相，悟入遍计所执性；由于悟入唯识，悟入依他起性。如何悟入圆成实性？如果已经灭除意言、闻法熏习种类的唯识之想，那时菩萨已经遣除义想，一切似义没有生起的余地，所以似唯识也不能生起。由于此一因缘，菩萨安住于一切义无分别的名中，在法界中便得现见相应而住。那时菩萨平等平等、所缘与能缘的无分别智已经生起。由此，菩萨称为已经悟入圆成实性。

【世亲释】唯识之相也不生起，因为计有识的时候，就有义。此后现证真如，现证的境界不可言说，因为是内自所证。“所缘”是真如，“能缘”是真智，两者平等，如同虚空，不住于所取、能取二性；由于不分别所取与能取，称为无分别智。

八、名的十种差别

关于“安住于一切义无分别的名”，有一颂：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">法补特伽罗<br>法义略广性<br>不净净究竟<br>名所行差别</div>

大意：法名、补特伽罗名、法名、义名、略名、广名、字性名、不净名、净名、究竟名，是名所行的十种差别。

【世亲释】十种名是：第一，法名，如眼等。第二，补特伽罗名，如我等。第三，法名，如十二分教。第四，义名，如十二分教所诠的诸义。第五，略名，如一切法有为、无为等。第六，广名，如色、受等及虚空等。第七，字性名，就是从“阿”字到“诃”字的字母。第八，不净名，就是诸异生。第九，净名，就是诸见谛者。第十，究竟名，就是一切法的总相所缘，是出世智和后得智的所缘境界。此中意取总缘一切义的智所缘的境界。

九、见道

如上所说，菩萨由于悟入唯识性，悟入所知相；由于悟入所知相，入极喜地，善达法界，生在如来家，得一切有情平等心性，得一切菩萨平等心性，得一切佛平等心性。称为菩萨的见道。

【世亲释】“生在如来家”，因为能令诸佛种性不断绝。“一切有情平等心性”，是证得自他平等，如同自己想要灭尽众苦，对他人也是如此。“一切菩萨平等心性”，是与一切菩萨的意乐与加行都平等。“一切佛平等心性”，是见诸佛的法界与自己的法界没有差别，在见道位中得到佛的法身。
