<div class="dt-subtitle">卷第二十之上（论本第七十五卷）——菩萨地抉择初持瑜伽第九至第十一段：总释六品（五德通辨六度；戒、忍、精进、静虑各十种清净与本地分之对照，慧五清净）；菩提分品（四念住、四正断；三十七品配行位诸说；十四种缚；依空修观解脱六种想缚与十一后后想缚）；功德品（破初学大乘恶取空者——清辩之计与护法之宗；大乘教起五相因缘；十二处自共相十无颠倒；八殊胜诸地转胜；引《解深密经》七义之总科与经名四译）<br>唐　遁伦　集撰</div>

编者按：本篇译菩萨地抉择初持瑜伽的最后三段。"总释六品"一段，把本论此处的戒、忍、精进、静虑、慧的诸种清净，与本地分第四十二卷的十种清净逐一对照，名目异同一一列出。"菩提分品"一段，景法师把三十七道品配属于十信、十解、十行、十回向、暖顶忍世第一、初地见道、二地以上修道诸位，又与"有释"及《成唯识论》之说相比较；其后列出障碍解脱的"十四种缚"，以及修念住时层层生起的"想缚"——即使是顺合经教的无我想、无自性想，只要心中带有取执，也名为缚。"功德品"开篇再度破斥"初学大乘恶取空者"，景法师逐句疏解论主的两难问难，并针对"佛说因缘所生法，我说即是空"的引证，反问："是从因生空，还是从因生有？若生空，龟毛兔角也应从因而生。"备法师明言此是清辩之计，并说护法既宗承《瑜伽》，其所释《百论》中道之义必不违《瑜伽》。其后说明大乘经教起的五种因缘，以回应小乘"大乘非佛说"之难。最后总列引《解深密经》所辨的七义，并说明此经有四种译名。原文讹字较多，随文注出。

一、总释六品：五德通辨六度

（承前，以上分别辨析施、戒二品。）从此以下，总释六品。其中先牒前文广说、许诺现在略说，然后正式辨析。其中有二：初约五德通辨六度，后分别约清净施等即六度。

前段中说"无著"，是因为除去六种弊（悭、犯戒等六度的障碍）。"无恋"，是对于三有的因果没有系著。"无罪"，是远离六度九门的随惑。"无分别"，是不观三轮。"回向"，是回趣菩提。

论中说"如是菩萨由此五德……乃至名艰难慧"等。前面本地分中说明六度时，每一度中都有一颂，颂其九门：

```
自性一切難　一切門善士
一切種遂求　二世樂清淨
```

（原文所引作"自性一切门，一切门善士，一切种逐求，二世乐清净"，字有讹误，今依本地分通行颂文录出。意谓：六度各以自性、一切、难行、一切门、善士、一切种、遂求、二世乐、清净九门来分别。）

现在这段文字说"菩萨施等"，就是自性门；"一切施等"，就是第三门。论中说"广说一切嗢拖南颂皆随决了"，是辨明摄其余六门，广泛随应决了。

二、戒的十种清净与本地分对照

就第二部分散释六度清净中，初解释施，论中说"由增一次第"：如施门最初自性施中唯有一种，第二一切施中有二种，第三难行施有三种，乃至第九清净施中有十种。

（以下辨戒品。）"十净"，就是第九门中的清净戒有十种。其中第一是意乐清净，其余九种是加行清净。

本地分第四十二卷说："云何菩萨清净戒？当知此戒略有十种：一者初善受戒，唯为沙门三菩提故，非为活命故。二者不太沉（掉）戒：于违犯时，远离微薄生悔愧故；及不应举戒，远离非处生悔愧故。三者离懈怠心戒：于睡眠乐、倚乐、卧乐不耽著故，昼夜勤修诸善品故。四者离诸放逸所摄受戒：修习如前所说五支不放逸。五者正愿戒：远离利养恭敬贪故，不愿生天而自要期修梵行故。六者轨则具足所摄受戒。七者正命具足所摄受戒。八者离苦乐二边戒。九者永出离戒：远离一切外道见故。十者于先所受无损失戒：于先所受无缺减故。"

应当知道，"初善受，唯为沙门三菩提，非为活命"，是意乐清净；其余九种是加行清净。

加行有五种，与九种清净相摄：第二不沉掉、第三离懈怠，是第一无间缺加行；第四远离放逸所摄受，或是第二遍修治加行；第五正愿戒，是第三回向加行；第六轨则具足、第七正命、第八远离二边、第九永出离，总是第四助伴加行；第十于先所受无损无缺，是第五守护加行。

三、忍的十种清净

第三辨忍。忍有十种清净，其中前九种名为思择力清净，第十种名为修习力清净。

如第四十二卷说："菩萨清净忍略有十种：一、遇不饶益事，终不返报；二、不意愤；三、恒现前欲作饶益；四、先后无异，非一益已舍而不益；五、于有怨者自往悔谢；六、终不令他生疲厌，然后受谢；七、成就增上猛利惭愧；八、于大师成就上品爱敬；九、于有情增上哀愍；十、一切不忍及其助伴法皆得断故。"所以说前九种是思择力清净，第十种名为修习力清净。

论中说"思择力净复有四种"，如论文所说。"一种、二种"：第一种摄一种清净，所以说"一种"，就是初"远离罪生清净"，摄前面第一"遇不饶益终不返报"。第二"彼不现行清净"，摄二种清净，所以说"二种"，就是第二意不愤、第三恒作饶益。后二种各摄三种，所以说"三、三种"：第三"无罪生清净"，摄那第四先后无异、第五于有怨自往悔谢、第六终不令他生疲然后受谢；第四"远离彼因清净"，摄第七成上惭愧、第八于大师成上爱敬、第九于有情增上哀愍。

以前面九种清净名为思择力清净：思择力清净中，广说即有九种，略说只有四种，所以得以相摄。第十种清净名为修习力，与思择力中的四种清净性质不同，不相摄。

论中说"不忍因缘有三"，这就是所对治。

四、精进与静虑的十种清净

第四辨精进，有十种清净（括号中为本地分中的名称）：一、安处（相摄）；二、纯熟（串习）；三、策发（无缓）；四、方便（善摄）；五、不虚时住（应时修习）；六、艰辛住（通达众相）；七、出离（不退弱）；八、摄受助伴（不舍轭）；九、速疾神通（平等）；十、无尽性（回向大菩提）。

第五辨静虑，有十种清净：一、（世间清净，本地分名为世间清净）；二、无漏清净（出世清净）；三、根本方便（加行）；四、证得根本净（与本地分同名）；五、自在方便（由根本胜进清净）；六、住自在清净（入住出自在清净）；七、引发神通自在（舍静虑已复证入自在清净）；八、成就有情自在清净（神通变现自在清净）；九、降伏外道自在清净（远离一切见趣清净）；十、无上离系清净（离二障清净）。（原文第一项作"十清净"，当有讹脱。）

五、慧的五种清净

第六，慧有五种清净。依本地分第四十二卷说："云何菩萨清净慧？略有十种：于真实义，有二种，谓由尽所有性及如所有性取真实义故。"这二种与此处第一"通达诸相"相同。"于流转义有二种慧，谓取正因、果故"，这二种与第二"通达缘起"相同。"于执受义有二种慧，谓颠倒、不颠倒如实了知故"，与第三"通达教道"相同。"于方便义慧，谓一切所作、所不应作如实了知故"，与第四"通达士用"相同。"于究竟义有二种慧，谓杂染如实知杂染故，清净如实知清净故"，与第五"通达证得"相同。

有人解释：精进、静虑各有十种，慧的五种清净是在九门之外另外建立的。不及前一种解释。

六、第十菩提分品：四念住与四正断

从此以下，第十，抉择菩提分法品。其中分三：初辨三十七品的能治；次辨所治的十四种缚；后辨依定修观、解脱想缚。

初段中有二：一、随难分别解释；后辨次第。

前段中，先说明四念住：初以如量智分别观察身、受、心、法；次以如理智通观身等的真如。

其次说明四正断。论中说"云何菩萨为令未生恶不善法得不生故，生欲……乃至生思、生舍"，是说修习四正勤，每一种有八种断行，如前面广说。"谓于真如境系心令住"，是说四种正勤之行还观真如。"为令一切……乃至广说"，是为了令二缚不生，所以生起欲等八种断行。"如令"以下，类推后三种正勤之行。

七、三十七品配行位诸说

下面辨次第。景法师说：这里不再论其余的行相。

"于念住位，最初系心置所缘境"，在十信位。"次于所缘令心安住，勤修正断"，在十解位。"次得定"，是四如意足，在十行、十回向位。五根在暖、顶位，五力在忍位以及世第一位。七觉支在初地见道。八正道在二地以后的修道位中。

有人解释：四念住在顺解脱分善根位，四正断在暖法，四如意足在顶法，五根在忍位，五力在世第一法，七觉支在初地见道，八正道在二地以后的修道位。

现在依照《成唯识论》等：七觉支在初地入心，八正道在初地住心以后的诸地。

八、所治的十四种缚

其次辨所治的十四种缚。

景法师说：论中说"相缚、粗重缚"，有两处说法：一、《瑜伽》上文说末那为相缚，因为执取我相而不解脱；六识的烦恼名为粗重缚，因为六识粗心生起烦恼之缚，障碍解脱。二、《显扬论》说所执的相分名为相缚，因为对那相不厌舍；能执的见分名为粗重缚，因为能执取而系缚，过失粗重，名为粗重缚。又，粗重缚就是烦恼随眠的余势习气，如阿罗汉断尽惑种，仍有习气的不调柔性，令身语意对于缘境有失，名为粗重缚。这些意义，论中都有文字。

一、"根缚"：因六根而生起烦恼之缚，所以名为根缚；也可以说，执著诸根不能厌舍，名为根缚。像这样由根被系缚之时，就有烦恼粗重的不调柔性遍在身心，不得安稳，名为粗重缚。

二、"境缚"：对于违顺之境生起贪瞋，这有两种意义：一是被境所缚，心不能舍离；二是以贪瞋系缚前境。都名为境缚。

三、"有情展转相受缚"：就是经中所说，男被女色所缚、女被男色所缚，互相爱缚。

四、"建立缚……故名建立"：眼等五根从业而生时，必定取五尘；由五根生起增上势力，引起五尘，于其中取执，名为建立缚。

五、"于所知境无智缚"：不了解所知，就名为缚。

六、"于能知智无智缚"：不悟能知之智，也名为缚。

七、"后有爱缚"：被贪求后有之爱所缚。

八、"无有爱缚"：被执断之爱所系缚。

九、"执著不平等因及无因缚"：如执自在天为因，或执我等为因，违背正因之理，名为不平等；或执诸法自然而有、没有因缘。由于依邪教执著不平等因以及执无因而被缚，不悟正因。

十、"证得增上慢缚"：未证而说已证，是增上慢之缚。

十一、"执著遍计所执自性缚"：这个缚义是总说，因为一切执都是执遍计所执自性。

十二、"执著数取趣自性缚"：就是取执之心为缚。

十三、"补特伽罗遍知增上慢缚"：实际上未遍知诸数取趣，而说已遍知，是增上慢之缚。

十四、"法遍知增上慢缚"：实际上未遍知诸法，而说已遍知，是增上慢之缚。

有论师判定说：十四种中，前四种约相来辨缚，后十种约粗重来辨缚。

九、依空修观解脱六种想缚

下面辨依空修观、解脱想缚。其中有二：一、辨解脱想缚；二、辨解脱十一种后后想缚。

前段中，景法师说：唯观自身的身、受、心、法，取著于内想，名为第一想缚。唯观他身的身、受、心、法，取著外想，是第二缚。总观自他的身、受、心、法，生起内外想，是第三缚。见有众生可度，愿令其解脱，是第四缚。由于愿令他人得解脱，所以执身等修观而住，是第五想缚。见有修观而住之人，是第六想缚。

备法师说：这里是辨明远离道品之障所得的胜利。姑且约想的数目、随境而说六种。

十、十一种后后想缚

下面辨解脱十一种后后想缚。论中说"即于此中循环观故，复有十一后后想缚"，是说从开始得到念住之后，辗转修习时所生起的想缚，所以说"后后"。

论中说"谓于身等……是名初转"：

一、于那四谛染净之法中，生起第一义想，名为初缚。

二、即于苦集杂染的第一义中，生起造作想。

三、即于灭道清净的第一义中，生起无造作想。

四、于灭谛生起常想。

五、于苦集造作生起流转想。

六、于灭谛、道中生起无变异想。

七、于流转生起苦想。

八、于苦中，由生、灭、住、异的自相，生起有变异想。

九、于前面灭谛无变、苦集有变的第一义中，生起能摄染污清净一切法之想。

十、即于前面染净之中，生起无我、无染净之想。小乘就染净的非谛法来辨无我，无我之法不离染净；大乘辨二种无我，是第六法，所以不是染净。所以菩萨地说："有为无为名有，无我我所名非有。"若生起此想，便合于法想，为什么名为缚？解释说：虽然顺着经教生起这样的想，然而心中带有取执，所以名为缚。

十一、即于染净诸法生起无自性相之想。只是了知诸法没有决定之性，也由于情中带有取执，说名为缚。

论中说"由诸菩萨……乃至皆得解脱"，正是说明依空修习而脱离诸缚。

十一、第十一功德品：判段与破初学恶取空者

从此以下，第十一，抉择功德品。若依景法师的解释，从此以下乃至八殊胜，仍是抉择菩提分法品，其后《解深密经》的文字全是抉择功德品。虽然有此判法，现在还是依前面的判法，这是新罗玄法师亲承三藏法师所传。

其中分二：初随义难破，后引《解深密经》以辨七义。前段中有四：一、破初学大乘的恶取空者；二、成立大乘教起的因缘；三、说明自共相观能证佛法；四、说明由八种殊胜，于诸地中转胜。

初段中，先举邪执，二正征问而破斥。

景法师解释道：论中说"于大乘中……乃至一切皆无"，是那些初学者如此说："依他起与圆成实，依世俗门，一切皆有；依胜义谛，一切皆无。因为依他起无生、圆成实无性。"

其次论主重新征问而确定其说。论中说"应告彼言……乃至而起说故"，是外人回答说："依他起与圆成实都无自性，是胜义谛；于无性之法，假名建立，而起言说，互相教示，名为世俗。"

十二、论主两难：名言世俗为从因有、为唯名言

下面论主征问："名言世俗，为从因有、自性可得？为唯名言世俗说有？"姑且据依他起的色心等法，世俗说有，是从因而生、自性可得？还是无因而生、唯在名言中世俗说有？这是以两问来确定其说。

从此以下，正式破斥。论中说"若名言世俗从因有者……不应理"：要是有法，才从因而生；若立说世俗从因而生，那就是有法，而说"非有"，不合道理。

若说："佛说'因缘所生法，我说即是空'，虽从因生，何妨是空？"就应当反问：是从因生空，还是从因生有？若是生空，龟毛兔角也应当从因而生，因为二者同样是无。若是生有，那就是有法，怎么名为空？应当知道，经意是说：因缘所生之法，就是依他起；在依他起法上，没有决定、没有自然而生之性，所以说"我说即是空"。

论中说"若唯名言世俗有，名言世俗无事而有，不应道理"：若说世俗不从因生，就没有因果；没有因果之法，那么就什么来施设名言世俗？所以说"名言世俗无事而有，不应道理"。

论中说"又应告言：长老，何缘诸可得者此无自性"，这是重新征问：现在可得之法，为什么无自性？"彼若答言颠倒事故"，是外人回答说："虽然现在可得，因为是颠倒，所以都无自性。"

论中说"复应告言：此颠倒事，为有为无"，又以两问确定其说。"若言有者，说一切法由胜义故皆无自性，不应道理"：你若许可有那颠倒之事，就有苦集的因果法性，而说诸法由胜义故皆无自性，不合道理。"若言无者，颠倒事故诸可得者此无自性，不应道理"：若颠倒之事毕竟无，就应当不可得，犹如兔角；现在明明可得而说是无，不合道理。

十三、泰、备二师：清辩之计与护法之宗

泰法师说：这是清辩等的计执，被慈氏所破。牒文解释其义，如前面第七十三卷的论记所述。

备法师又说：清辩论师作如是计：依他起性因世俗故有，因胜义故无，于是违背中道（下文"解。放勒弁依他圆成有无即义"一句字有讹乱，不能确译）。又一种解释：《中论》《百论》等宗名为恶取空。前一种解释为胜，因为护法菩萨解释《百论》等所辨的中道之义；护法宗承《瑜伽》，那（《百论》）若违背《瑜伽》，（护法）何必为它造释（原文"护法宗承论伽，彼瑜若违瑜伽"，字有讹倒，今依文意译出）？

十四、成立大乘教起的五相因缘

其次成立大乘教起的因缘。

景法师说：由于那西方诸部小乘，都不相信有大乘的理与教，见到学大乘的人，称之为"空华"："你立真如本来是有、不生不灭，与那外道立我本来是有、不生不灭，有什么不同？又你所依的大乘教门，佛在何处所说？为何人所请？谁请佛说？有何略说、何广说？所以你所立的大乘教门不可依信，我宁可依那涂灰外道。"由于这样的事，所以要成立大乘教起的因缘。

论中说"由五相故思择大乘经起因缘"：

"谓为于说者生恭敬故，起第一说"：就是诸经中说"世尊住在某方某林"等说法之处的言辞。

"为摄众生故，起第二说"：就是诸经中引同闻众"与大比丘众千二百五十人俱，菩萨三万二千人"等言辞。

"为于正法生尊重故，起第三说"：就是经中说解脱月等请说经之人。若不请而说，听法之徒不生难遭之想；为了令其生起尊重，所以等待请问而说。

"为叙事故，起第四说"：就是诸经中佛为当时大众略标章门。

"为欲宣说真实义故，及多所作故，起第五说"：就是诸经中广说的言辞。

达法师说：一、"如是我闻"等是；二、列众；三、如梵王请等，是说发起序；四、是说在正宗分中略说所说之事；五、"为欲宣说真实故"，是广分别其义；"及多所作故"，是当时大众得益、依教奉行。

十五、十二处自共相观的十种无颠倒道

第三，说明十二处的自相、共相二种观，有十种无颠倒道，能证得所有不共佛法：六种是自相观，四种是共相观。

一者，了知随眠等名为遍计所构画，唯有名言，就显示眼等的自性不可言说。

二者，了知于处遍计所执、摄受虚妄，就显示外处的自相。

三者，了知依他起从因转生。

四者，了知依他起自然而灭，名为坏转之相。

五者，了知清净转相，乃至"当知此依二业"：一、生起清净，是道；二、寂灭清净，是灭。

六者，了知有为可以作为名言的安立之处。以上是自相，以下是共相。

七者，了知无常、空以及无我。

八者，了知所证无分别所起所行之理。

九者，了知所证只是出世智所行之法。

十者，了知圣道为涅槃之因。

第四，说明由八种殊胜，于诸住地后后转胜。这是通于诸地的功德。

十六、引《解深密经》七义总科与经名四译

从此以下，第二，引《解深密经》来辨七义，就分为七段：

一、如理请问菩萨等问胜义。

二、广慧菩萨问心意识之义。

三、德本菩萨问三性之义。

四、胜义生菩萨请问三无性之义。

五、慈氏菩萨请问奢摩他、毗钵舍那之义。

六、观自在菩萨问诸地之义。

七、曼殊室利菩萨请问三身之义。

就初问胜义谛相中，先开五门；第二依门解释，有四段。初解释二种离言门，其中先总牒、指经，后别引其文。

前段中说"解深密经"，此经有四种翻译：一、菩提流支译，名为《深密解脱经》；二、求那跋陀罗译，名为《相续解脱经》；三、真谛译，名为《解节经》；四、玄奘译，名为《解深密经》。梵本一个音，具含三种意义：一、两物相续之义；二、骨节相连之义；三、深密之义。历代三藏各取一义，所以译名不同。

就别引经文中，先长行广辨，后以颂叙述。长行中有三番问答。初番问答中说"最胜子"：佛是最胜，说明那菩萨是最胜者之子，名为最胜子，旧译作"佛子"。

以上，菩萨地抉择初持瑜伽的十一段，除功德品所引《解深密经》以外，全部译毕。

下一篇将译释功德品所引《解深密经·胜义谛相品》以下诸品的抉择：胜义谛离言、无二、超寻思境、离一异、遍一切一味诸相，以及心意识相品（阿陀那识）等。
