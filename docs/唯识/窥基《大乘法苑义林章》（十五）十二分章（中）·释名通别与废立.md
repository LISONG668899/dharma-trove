<div class="dt-subtitle">大乘法苑义林章白话译注（十五）<br>唐　窥基　撰</div>

〔译注：本篇译《十二分章》第三至第五门：解释总别名、通相与别相、废立。第四门以《法华经》《解深密经》的偈颂为例，逐一论证"应颂"中也含有其余各分，再推及其余各分，是全章最细密的一段。〕

第三门　解释总名和别名

先解释总名，后解释别名。

一、总名

先德翻译为"十二部经"。"部"字含有两种意义：一是部帙，二是部类。世人以为有十二部帙；"经"这个名称也有混滥，总名、别名难以分明。现在翻译为"十二分教"。"分"是类别、支条、段落、教法的意思。如前面所说，教法有十二种义类，支条、分段各不相同，所以称为十二分。这是带数释。

二、别名

一、依主释的六种：

1. 应颂：应当重述的颂。
2. 讽诵：可以讽诵的颂。
3. 自说：自己陈述的言说。
4. 缘起：待缘而起。
5. 希法：希有的法。
6. 方广：方正之理的广大。

二、持业释的一种：论议。论议的本体就是议，这一个名称只是持业释。

三、通于两种解释的五种：

1. 契经：如果说"契合真理的经"，是依主释；如果说"能契合的就是经"，是持业释。
2. 记别：记录因果的差别，是"差别的记"，是依主释；如果说"记识分别"称为记别，记就是别，是持业释。
3. 譬喻：如果说"譬"是比况，"喻"是晓谕，"晓谕的譬"，是依主释；如果说"譬"是类比，"喻"是比况，譬的本体就是喻，是持业释。
4. 本事：如果说"本世的事"，是依主释；如果说本的本体就是事，是持业释。
5. 本生：如果说"本世的生"，是依主释；如果说本的本体就是生，是持业释。

这十二种名称，都加上"教"字，称为契经教，乃至广说论议教，都是持业释。

第四门　通相与别相

这些教法，一往而论，依据实际，都有通相和别相。

一、契经的通相与别相

《涅槃经》说："从'如是'开始，到'奉行'结束。"那么十二分都称为契经，这是通相。《瑜伽师地论》等说："以长行连缀，简略宣说所应说的义理，称为契经。"这是别相。

别相的契经中，具足九分，只除去应颂、讽诵两种偈颂。

这一种行门，是以一分对照其余各分。已经对照说过的，下面不再另外说明。一切都应当这样了知。

二、应颂中含有其余各分

一、应颂中也有记别。论文中没有明文许可，经教中有证明。如《法华经》说：

「舍利弗来世，成佛普智尊，号名曰华光，当度无量众。」（大意：舍利弗在未来世，将成佛为普智尊，名号叫华光，将度化无量众生。）

像这样的经文处处都有，不止一处。所以应颂中也有记别，因为这是重颂前面长行的义理。

记别有三种：

1. 记别弟子死生的因果。
2. 记别深密的义理。
3. 记别成佛的事。

这首偈就是应颂中也有记别成佛之经。其余两种记别，随应或有或无。

二、应颂中决定没有讽诵。因为讽诵不是重说前面的长行，只是以两句等单独宣说所应说的法。

三、应颂中也有自说，如授记等，因为没有请问的人。

四、应颂中道理上有缘起。缘起有三种：

1. 因请问而说。
2. 因有人犯过而制戒。
3. 因事而说法。

如《法华经》第一卷中宣说一乘的地方，因为舍利弗殷勤三次请问，世尊以长行已经说完，又重新以偈颂宣说。其余两种缘起，随应或有或无。

五、应颂中道理上有譬喻。火宅喻、穷子喻、化城喻等，都以偈颂重说。

六、应颂中道理上有本事。

1. 《序品》中说，妙吉祥菩萨说：「彼佛灭度后，懈怠者汝是；妙光法师者，今则我身是。」（大意：那位佛灭度以后，那个懈怠的人就是你；妙光法师，就是现在的我。）既然说了弟子弥勒、文殊本世的事，所以应颂中也有本事。
2. 《化城喻品》中佛自己以偈颂说：「尔时闻法者，各在诸佛所，其有住声闻，渐教以佛道。我在十六数，曾亦为汝说。」（大意：那时听法的人，各自在诸佛的处所；其中住于声闻的，渐渐教以佛道。我是十六王子之一，曾经也为你们说法。）所以应颂中决定有本事，因为宣说了声闻等本生的事。

七、应颂中道理上有本生。《常不轻品》的重颂偈说：「彼时不轻，则我身是。时四部众，著法之者，闻不轻言，汝当作佛，以是因缘，值无数佛。」（大意：那时的常不轻菩萨就是我。那时执着于法的四部大众，听到常不轻菩萨说"你们将来都会作佛"，因为这个因缘，值遇了无数的佛。）既然说了常不轻佛的本生事，所以应颂中也有本生。十六王子的事，依此类推应当了知。

八、应颂中道理上有方广。

1. 《方便品》说："十方佛土中，唯有一乘法，无二亦无三，除佛方便说。"一乘既然是方广的甚深之经，所以应颂中也有方广。
2. 《解深密经》说："这时世尊想要重新宣说这个义理，而说偈：'阿陀那识甚深细，一切种子如暴流……'"这就是应颂中有方广。

九、应颂中道理上有希法。《化城喻品》说：「大通智胜佛，十劫坐道场，佛法不现前，不得成佛道。」（大意：大通智胜佛，在道场中坐了十劫，佛法没有现前，没有成就佛道。）又说：「东方诸世界，五百万亿国，梵宫殿光耀，昔所未曾有。」（大意：东方的诸世界，五百万亿个国土，梵天的宫殿光明照耀，是往昔从来没有过的。）这里说佛十劫坐在道场不得成佛，以及佛的神通令十方各五百万亿国土光明晃耀，这是佛世尊希奇的事，所以应颂中也有希法。

十、应颂中道理上有论议。如《解深密经》说完三无性以后，"这时世尊想要重新宣说这个义理，而说颂"：

「相、生、胜义无自性，如是我皆已显示。若不知佛此密意，失坏正道不能往。」（大意：相无自性、生无自性、胜义无自性，这些我都已经显示。如果不了知佛的这个密意，就会失坏正道，不能前往。）

又说："所以在其中立一乘，并非有情的种性没有差别。"这里既然研究审核三无性法，说为密意，又重颂前面所说的诸义，所以应颂中也有论议。

由此，没有正面的经文作确切证明，也应当承认应颂中有通相、有别相。以道理来证明，如前面所引，意义可以成立。所以应颂的通相，具足其余十一分，连自说也在内。这是就通相的修多罗来说；别相的修多罗没有。如果对照后面各分，只有九分，因为除去前面的契经和后面的讽诵。应颂的别相，如诸教所说。

上面广引一种法作为例子，其余的只简略指出，不能一一繁引，学人应当仔细研究。

三、记别中的通相与别相

记别中也有通相和别相。关于通相，有两种说法：

1. 有的说只有五分，就是自说、因缘、方广、希法、论议经。因为没有见到记别以讽诵来说的；也没有以譬喻来授记的；本事、本生都是说过去，记别是记未来受生的事，所以不说有本事、本生。这是依照授记死生、授记成佛称为授记来说的。
2. 有的说不是这样。如果分明记别诸了义经，称为记别，那么记别中也有讽诵、譬喻、本事、本生，具有后面九分。

四、其余各分的通相

1. 讽诵中，通相具有后面八分。
2. 自说的通相，具有后面七分。
3. 因缘的通相，具有后面六分，因为方广等教也有待请、因事而说的。
4. 譬喻的通相，只有后面五分。有一种说法认为只有后面三种，没有本事、本生，因为没有见到以譬喻宣说本事、本生的。
5. 本事的通相，有后面三分，唯独没有本生，因为师和弟子不同。
6. 本生也有后面三种。
7. 方广的通相，具有后面两分。
8. 希法的通相，具有后面一分。

记别以下各分的别相，随其所应，有多有少，因为经文不固定。

或者有一种解释说：其余各分所不摄的，称为别相。这也是随义解释，只是稍难了知。

五、总结通相的相摄

这样总的解释诸通相：

1. 契经、记别、自说、因缘、譬喻、方广、希法、论议这八部，都具足摄持其余十一分，可以在其中具有十二分。所以《涅槃经》中说，从十二部流出修多罗，从修多罗中流出方广，方广之中具足摄持十二部。其余一切依此应当了知。
2. 应颂、讽诵、本事、本生这四部，各有其余十分。因为应颂与讽诵决定互相不含；本事与本生互相不含也是这样。只可以在其中有十一分。

所以这里说"有"，是或者可以具有，不是决定具有。比如记别中不是记别的地方，就不摄记别；乃至论议中不是研究审核、追寻义理的地方，也不摄论议。随应或许有，意义上可以具足，不是决定具有。

第五门　废立

一、总的废立

问：为什么只立十二分教，不增也不减？

答：《涅槃经》说："因为能听法的人适合听闻。"三乘通说，以转法轮三周，总说有十二行相，能诠释的教法按类分为十二。又为了破除十二有支，悟入十二处，所以说法也分为十二。这是总的废立。

二、别的废立

这样的圣教，以种种相对为门：

1. 长行与偈颂相对为门，有直说和非直说。
2. 重颂与单颂相对为门，说有应颂和讽诵。
3. 无问与有问相对为门，说有无问自说和有问。因缘经中有另外请问的，称为因请而说，就是有问。
4. 佛事与非佛事相对为门，陈述宿世，说有本事和本生。

问：这样也应当有记与非记相对、法与喻相对、广与略相对、曾与未曾相对、论与不论相对为门。又也应当立本与末相对，就是对于所说的本事、本生，也应当对立末事、末生。

答：不应当这样。就像十力中，立处非处智力、上根下根智力，不再对立自业非业智力，乃至不立漏尽不尽智力。经中也是这样，暂且立直说和非直说等，不应当立有记和非记等，因为信乐的人适合听闻这些。

又另外解释：

1. 殊胜的事可以记别，让众生厌恶恶法、欣乐善法，所以立记别经。不可记别的，欣厌的意义微弱，所以没有"非记"经。
2. 诸有智慧的人以譬喻得到理解，举出譬喻成立法义，在道理上有大利益，所以有譬喻经。不是譬喻的经，没有另外殊胜的作用，只总的立为契经等，所以没有"非喻"经。
3. 乃至论与不论的经，道理和解释也是这样。广胜过略，曾有劣于未曾有，论议胜过非论议，并非齐等，所以略去不立。这是依照声闻有广教来说的。
4. 既然有本事、本生经，现在要立末事、末生：授记经中说的已经是末了。并且现在等法，其事可以看见；未来的果法微细难知，所以不再另立名为末事、末生。现在的果法彰明，只要陈述宿世生中的因和事，让众生了知现在的果，欣厌的意义就成立了，所以只立本事、本生，不另外立末事、末生。或者记别经也称为末事、末生等经，也没有过失。
