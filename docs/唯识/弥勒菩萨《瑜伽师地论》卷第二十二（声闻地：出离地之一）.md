# 弥勒菩萨《瑜伽师地论》卷第二十二（声闻地：出离地之一）

弥勒菩萨说　唐三藏法师玄奘奉诏译

## 本地分中声闻地第十三初瑜伽处出离地第三之一

### 一、出离地总说

已经说了趣入地。什么是出离地？嗢拕南说：

```
若世间离欲　如是出世间
及此二资粮　是名出离地
```

（大意：由世间道离欲，以及这样的出世间道离欲，还有这两种道的资粮，这名为出离地。）

就是由世间道而趣向离欲，由出世间道而趣向离欲，以及这两种道的一切资粮，总略为一，名为出离地。

#### 由世间道而趣离欲

什么名为由世间道而趣向离欲？就是如有一人，把下方的欲界观为粗相，把初静虑的离生喜乐，无论是定还是生，观为静相。他由于多住于这样的观察，便对欲界得以离欲，也能证入最初的静虑。这样又在初静虑以上，渐次如其所应，把一切下地观为粗相，把一切上地观为静相。他由于多住于这样的观察，便乃至对无所有处得以离欲，也能证入乃至非想非非想处。这名为由世间道而趣向离欲，除此之外再没有多出或增加的。

【按】遁伦《瑜伽论记》说：世间道离欲的道理通于异生，这里是就圣者以世俗道离欲来说明。

#### 由出世道而趣离欲

什么名为由出世间道而趣向离欲？就是如有一人，亲近善士，在圣法中已成聪慧，在圣法中已得调顺；对于苦圣谛如实知苦，对于集圣谛如实知集，对于灭圣谛如实知灭，对于道圣谛如实知道。既已成就有学的智见，从此以后渐次修习圣道，对于遍于三界的见所断、修所断的一切法，自己能离系，自己得解脱。这样便能超过三界。这名为由出世间道而趣向离欲。

【按】遁伦《瑜伽论记》引三藏说：《对法论》的论师依据真见道，以能所平等之智为见道之相；这部论的论主依据相见道，说四谛智名为见道。又说：自能离系，是无漏智等离于有漏的系缚，就是无间道；断除那烦恼、得到无为时，生起胜解，自得解脱，就是解脱道。

#### 二道资粮：十四门总标

什么名为两种道的资粮？嗢拕南说：

```
自他圆满善法欲
戒根律仪食知量
觉寤正知住善友
闻思无障舍庄严
```

（大意：自圆满、他圆满、善法欲，戒律仪、根律仪、于食知量，觉寤瑜伽、正知而住、善友，闻正法、思正法、无障碍、惠舍、沙门庄严。）

就是自圆满、他圆满、善法欲、戒律仪、根律仪、于食知量、初夜后夜常勤修习觉寤瑜伽、正知而住、善友性、闻正法、思正法、无障碍、修习惠舍、沙门庄严。这些等法，名为世间以及出世间诸离欲道所趣向的资粮。

应当知道这里的自圆满、他圆满、善法欲，这三种如前面修集种子的诸劣缘中已经辨析了它们的相。

【按】遁伦《瑜伽论记》说：前三门已在种姓地劣缘中说明，现在解释其余十一门；本卷只解释第四门戒律仪。

#### 二道资粮：戒律仪总标

什么是戒律仪？嗢拕南说：

```
戒律仪当知　辨三亏满十
六异门三净　胜功德十种
```

（大意：戒律仪，应当知道有辨析三相、亏损与圆满各十种、六种异门、三种清净、十种殊胜功德。）

戒律仪，就是如有一人，安住具戒，广说乃至受学学处。

#### 戒律仪：辨三（安住具戒等六句）

什么名为安住具戒？就是对于所受学的一切学处，不亏损身业，不亏损语业，无缺，无穿。这名为安住具戒。

什么名为善能守护别解脱律仪？就是能守护七众所受的别解脱律仪。这律仪由于众的差别，成为多种律仪；现在这义理中，只依苾刍律仪之处来说善能守护别解脱律仪。

【按】遁伦《瑜伽论记》说：为什么不说苾刍尼等？因为多分成就具戒之法的是苾刍，所以只就苾刍说。

什么名为轨则圆满？就是如有一人，或在威仪路中，或在所作事中，或在善品加行之处，成就轨则：随顺世间，不违越世间；随顺毗奈耶，不违越毗奈耶。

什么名为在威仪路中成就轨则，随顺世间，不违越世间；随顺毗奈耶，不违越毗奈耶？就是如有一人，对于所应行的，对于应如何行的，就在其中这样而行。由于这样行，不被世间所讥毁，不被贤良、正至、善士、诸同法者、诸持律者、诸学律者所呵责。如对于所行，对于所住、所坐、所卧，应当知道也是这样。这名为在威仪路中成就轨则，随顺世间，不违越世间；随顺毗奈耶，不违越毗奈耶。

什么名为在所作事中成就轨则，随顺世间，不违越世间；随顺毗奈耶，不违越毗奈耶？就是如有一人，对于他所作的，或衣服之事、或便利之事、或用水之事、或杨枝之事、或入聚落行乞食之事、或受用之事、或荡钵之事、或安置之事、或洗足之事、或为敷设卧具等事——这略说是衣事、钵事——又有其余这样等类诸所应作的，名为所作事。如其所应，对于所应作的，对于应如何作的，就在其中这样而作。由于这样作，不被世间所讥毁，不被贤良、正至、善士、诸同法者、诸持律者、诸学律者所呵责。这名为在所作事中成就轨则，随顺世间，不违越世间；随顺毗奈耶，不违越毗奈耶。

什么名为在诸善品加行之处成就轨则，随顺世间，不违越世间；随顺毗奈耶，不违越毗奈耶？就是在种种善品加行中：或对正法受持读诵；或对尊长修和敬之业，参觐承事；或对病人生起慈悲之心，殷重供养侍候；或对如法宣白的加行，住于慈悲之心，辗转给予同意；或对正法请问听受，勤勉而不懈惰；对诸有智慧的同梵行者，尽其身力而修敬事；对他人的善品常常勤加赞叹激励；常乐为他人宣说正法；进入静室，结跏趺坐，系念思惟。像这样等类其余无量所修的善法，都说名为善品加行。他对于这样随所宣说的善品加行，如其所应，对于所应作的，对于应如何作的，就在其中这样而作。由于这样作，不被世间所讥毁，不被贤良、正至、善士、诸同法者、诸持律者、诸学律者所呵责。这名为在诸善品加行之处成就轨则，随顺世间，不违越世间；随顺毗奈耶，不违越毗奈耶。

如果对于这样所说行相的轨则差别全都具足，应当知道说名为轨则圆满。

【按】遁伦《瑜伽论记》说：“于所应行、于如所行”有两种解释：一说所应行是简别那些恶人不应行之事，如所行是如其余善丈夫所行那样而行；一说所应行是佛所许可之处，如所行是佛所制定之处。“如法宣白加行……展转与欲”，是为法事之时，如理宣白大众，应住于慈心，受取那人的“欲”（委托同意）。

什么名为所行圆满？就是诸苾刍略有五种不应行之处。哪五种？一是唱令家，二是淫女家，三是酤酒家，四是国王家，五是旃荼罗、羯耻那家。如果对于如来所制定的这些不应行之处，能善远离；对于其余无罪的一切行处，知时而行。这名为所行圆满。

什么名为对于微小的罪见到大的怖畏？就是对于诸小学处、随小学处，如果有所违犯，可以使之还复清净的，名为微小罪。对于诸学处现行毁犯，说名为罪；既已毁犯之后，用少许功力就能还复清净，说名为微小。由于这个因缘，名为微小罪。怎样在其中见到大的怖畏？就是这样观察：“不要让我由于这毁犯的因缘，再没有堪能得到所未得、触到所未触、证到所未证；不要让我由此接近诸恶趣、前往诸恶趣；或者我会自责，或者被大师、诸天、有智慧的同梵行者依法呵责；不要让我由此在诸方各处，恶名、恶称、恶声、恶颂远近流布。”他对于这样现法、来世由毁犯之因所生的诸不可爱之果，见到大的怖畏。由于这个因缘，对于小学处、随小学处，即使有命难的因缘也不故意违犯；或在某时、某处由于失念而违犯，随即迅速如法发露，使之还复清净。这名为对于微小的罪见到大的怖畏。

【按】遁伦《瑜伽论记》说：除四重以外，其余都名为小戒；初受名为小，后来对缘而持名为随小；违犯这小戒与随小戒，名为微小罪。“得所未得、触所未触”等，是说初、中、后的修行。

什么名为受学学处？就是先受别解脱戒、以白四羯磨受具足戒时，从戒师那里得闻少分学处的体性；又从亲教师、轨范师那里，得闻其余的别解脱经，总略宣说超过二百五十条学处，都自己发誓说：“一切当学。”又从其余常相言议者、共同言议者、常相交往者、有亲爱者那里听闻所学之处，又在半月常所宣说的别解脱经中听闻所学之处，一切都自己发誓：“都当修学。”由于对一切所应学之处都受学，说名为获得别解脱律仪。

从此以后，对于诸学处，如果已经善巧，便能不犯；即使有所违犯，随即如法忏悔。如果对于诸学处尚未善巧、尚未晓悟，由于先前自己发誓愿受持，得以在现在求受善巧，想求晓悟；对于如前所说的诸所学处，从亲教师或轨范师那里，如先前那样请问。既已得到善巧以及晓悟之后，随其所教诲，不增不减，又能受学。又对于尊重者以及等同尊重者所说的学处，无论文还是义，都能无颠倒地领受。这名为受学学处。

【按】遁伦《瑜伽论记》说：从戒师那里得闻少分学处的体性，是听闻四波罗夷等过失。二百五十戒中，把众学法合为一条，其余有一百五十一条，所以说“过于”。

这样广为辨析了戒律仪。

应当怎样了知这里的略义？就是在这里，世尊显示戒蕴的略义有三种相：一是无失坏相，二是自性相，三是自性功德相。

这又是怎样的？就是如果说“安住具戒”，由此显示尸罗律仪的无失坏相。

如果又说“能善守护别解脱律仪”，由此显示尸罗律仪的自性相。

如果又说“轨则与所行都圆满”，由此显示别解脱律仪如其所受，以他人为增上的自性功德相。为什么？由于他人观见这样轨则与所行圆满，未信的人生信，已信的人增长；由此生起清净信心之处，心无厌恶，口不讥毁。如果不是这样具足尸罗、轨则与所行都圆满，以他人为增上的一切功德胜利就应当没有，与此相反的过失就应当有。

如果又说“对于微小的罪见到大的怖畏、受学学处”，由此显示别解脱律仪如其所受，以自己为增上的自性功德相。为什么？虽然由这样轨则与所行都圆满，获得如前以他人为增上的功德胜利，然而由于毁犯净戒的因缘，当生恶趣，或者没有堪能得到所未得，如前广说。如果能对那微小的罪见到大的怖畏，对先前所受的上品学处能正确修学，由于这个因缘，身坏之后当生善趣，也有堪能得到所未得，如前广说。由于这个因缘，说这名为别解脱律仪如其所受，以自己为增上的功德胜利。

又有另一异门：就是佛世尊在这里略显三种戒性：一是受持戒性，二是出离戒性，三是修习戒性。

就是如果说“安住具戒”，由此显示受持戒性。

如果又说“能善守护别解脱律仪”，由此显示出离戒性。为什么？别解脱律仪所摄的净戒，应当知道说名为增上戒学；就依这样的增上戒学，修习增上心学、增上慧学，由此能得一切苦尽，究竟出离。这样的出离，以增上戒作为前行与所依止之处，所以说这别解脱律仪名为出离戒性。

如果又说“轨则与所行都圆满，对于微小的罪见到大的怖畏，受学学处”，由此显示修习戒性。为什么？如果由这样所说的诸相、以别解脱律仪修习净戒，名为善修习、极善修习。

这样一种尸罗律仪，现前宣说，应当知道有六种。

【按】遁伦《瑜伽论记》说：“辨三”，是指下文略义中两番各以三义摄持，所以称为辨三；广说则有六句：安住具戒、善能守护别解律仪、轨则圆满、所行圆满、于少罪见大怖畏、受学学处。

#### 戒律仪：亏损十因缘

又这样的尸罗律仪，由十种因缘，应当知道是亏损；由与此相反的十种因缘，应当知道是圆满。

什么是十种亏损的因缘？一是最初恶受尸罗律仪，二是太过沉下，三是太过浮散，四是属于放逸懈怠，五是发起邪愿，六是属于轨则亏损，七是属于净命亏损，八是堕在二边，九是不能出离，十是所受失坏。

什么名为最初恶受尸罗律仪？就是如有一人，被国王所逼迫而求出家，或被狂贼所逼迫、或被债主所逼迫、或被怖畏所逼迫、或被不能活命的怖畏所逼迫而求出家；不是为了沙门性，不是为了婆罗门性，不是为了自我调伏，不是为了自我寂静，不是为了自我涅槃而求出家。这名为最初恶受尸罗律仪。

什么名为太过沉下？就是如有一人，本性无羞耻，对恶作羸弱，本性迟缓，对于诸学处所作迟缓。这名为太过沉下。

什么名为太过浮散？就是如有一人，坚执恶取，在不该恶作之处生起恶作，在不应作的诸恶作中妄作恶作；在不该之处对他人生起轻蔑之心、或恼害之心；在不该之处勉强生起晓悟。这名为太过浮散。

什么是属于放逸懈怠？就是如有一人，由于过去世违犯了所犯，对于这违犯，由于失念，有一类不能如法还复清净。如由过去，由未来世、由现在世，应当知道也是这样，就是违犯了所犯，对于这违犯，由于失念，有一类不能如法还复清净。又不是在事先对于所会毁犯的，发起猛利的不犯之欲，就是想：“我必定应当如如所行、如如所住，如是如是行于所行，如是如是住于所住，对于所会毁犯的终不毁犯。”由于这个因缘，随其所行所住，如是如是违犯所犯。由此成就前际俱行、后际俱行、中际俱行、先时所作以及俱随行的一切放逸。又自己执取以睡眠为乐、以仰卧为乐、以胁卧为乐；本性不勤勉，本性懒惰，不能具足振起；对于诸有智慧的同梵行者，不能时时觐问供事。这名为属于放逸懈怠。

什么名为发起邪愿？就是如有一人，依止邪愿修行梵行，说：“我所有的戒、禁，常精勤、修梵行，当得生天，或生其余天处。”或者爱乐利养恭敬而修梵行，就是因此从他人那里希求利养恭敬，就对这样的利养恭敬深生染著。这名为发起邪愿。

什么是属于轨则亏损？就是如有一人，在威仪路中、或所作事中、或诸善品加行之处的一切轨则，不随顺世间，违越世间；不随顺毗奈耶，违越毗奈耶，如前广说。这名为属于轨则亏损。

什么是属于净命亏损？就是如有一人，本性大欲，不知喜足，难养难满；常以非法追求衣服、饮食、卧具、病缘医药以及诸资具，不以正法。又为了贪求种种衣服、饮食、卧具、病缘医药、资具的因缘，方便显示自己有殊胜功德，矫诈造作不同寻常的威仪；为了诳骗他人，恒常诈现诸根不掉动、诸根不动摇、诸根寂静，由此使他人认为他有德行，会有所施与、有所作为，就是承事、供给衣服、饮食、卧具、病缘医药以及诸资具。

又多凶暴悖逆、强口、矫傲，修饰其名，执恃种姓；或求多闻，或住持佛法，为了利养，也为他人宣说正法，或是佛所说的，或是弟子所说的；或自己宣说自己确实有的德行，或稍加增益。或在他人面前方便现出某种相状，为了求取衣服，或求取任何一种沙门资具，或为求多，或求精妙；虽然没有匮乏，却现出穿著破旧的衣裳，为了使有净信的长者、居士、婆罗门等知道他的衣服有所匮乏，殷重承事，施给众多上妙的衣服。如为了衣服，为了其余任何一种沙门资生众具也是这样。

或者对于有净信的长者、居士、婆罗门那里，如其所欲而不能如愿，或者那人的财物有所缺乏，求而不得时，就强逼研磨，以粗语苦苦求索。或者那人的财物并不缺乏，得到下劣之物时，就当着施主的面毁弃所得的财物，这样告诉他说：“咄哉男子！某善男子、某善女人，比起你的族姓与财宝，极为下劣，又极贫乏，却能惠施这样多而美妙悦意的资产众具；你比起他们，族姓尊贵，财宝丰饶，为什么只施舍这样少劣、不悦意的东西？”

他由于这样或依矫诈、或邪妄语、或假现相状、或苦苦研逼、或以利求利等种种情状，从他人那里以非法希求一切衣服、饮食、卧具、病缘医药等诸资生之具，不是以正法而有所求。由于是非法，说名为邪命。这名为尸罗属于净命亏损。

【按】遁伦《瑜伽论记》说：希求未得的境界名为大欲，耽著已得的境界名为不知足；由于大欲所以难养，由于不知足所以难满。

什么名为堕在二边？就是如有一人，耽著受用极乐行这一边，从他人那里所得的，无论如法或非法的一切衣服、饮食、卧具、病缘医药以及诸资具，爱玩受用，不观察过患，不知道出离。这是一边。又有一类，喜好求受自苦行这一边，以无量门自我煎迫，受极大的苦楚：就是或依棘刺、或依灰土、或依木杵、或依木板、或如狐蹲而住、或如狐蹲而坐，修断瑜伽；或者事火，就是乃至一日三次承事于火；或者升水，就是乃至一日三次升上水中；或者一足站立，随日而转；或者其余诸如此类修自苦行，这是第二边。这名为堕在二边。

【按】遁伦《瑜伽论记》说：自苦行一边略有十种：一依棘刺修断瑜伽；二依灰土；三持木杵，夜里卧在上面；四著木板衣，夜里卧在板上；五如狐蹲而住，后夜不至于地；六如狐蹲而坐，后分至地，以上通名修断瑜伽，泰师以为是修涅槃断之行；七有外道相续事火，一日三次；八在水中立柱，一手执一柱、一脚踏一柱，一日三度升柱观日，随日而转；九一足立柱，随日而转；十是除此九种之外，九十六种外道等其余的邪行。

什么名为不能出离？就是如有一人，对于戒或禁，由于见而执取，就是认为：“我由于这戒或禁，当得清净、解脱、出离。”一切外道所有的禁戒，即使善于防护、善于清净，就其清净而言，也不名为出离。这名为不能出离。

什么名为所受失坏？就是如有一人，完全没有羞耻，不顾沙门之行，毁犯净戒，习于诸恶法，内怀腐败，外现贞实，犹如净水中所生的蜗牛，螺音狗行；实际不是沙门而自称沙门，实际不行梵行而自称梵行。这名为所受失坏。

略由这样十种因缘，名为戒的亏损。世尊有时说尸罗亏损，有时又说尸罗艰难。应当知道在那些因缘中，由两种因缘，就是不能出离以及所受失坏，说为尸罗艰难；由其余的因缘，应当知道只说为尸罗亏损。

#### 戒律仪：圆满十因缘

与这安立的黑品因缘相反的白品的一切因缘，应当知道说名为尸罗圆满、尸罗清净。


#### 戒律仪：六异门

有的地方世尊宣说尸罗名为根本，如伽他说：

```
若善住根本　其心便寂静
因圣见恶见　相应不相应
```

（大意：若善住于根本，其心便得寂静；由此与圣见相应，与恶见不相应。）

有的地方世尊宣说尸罗名为庄严具，如伽他说：

```
苾刍苾刍尼　戒庄严圆满
于不善能舍　于善能修习
```

（大意：苾刍、苾刍尼，以戒为庄严而圆满，对不善能舍，对善能修习。）

有的地方世尊宣说尸罗名为涂香，如伽他说：

```
苾刍苾刍尼　戒涂香圆满
于不善能舍　于善能修习
```

（大意：苾刍、苾刍尼，以戒为涂香而圆满，对不善能舍，对善能修习。）

有的地方世尊宣说尸罗名为薰香，如伽他说：

```
阿难有香类　顺风善能薰
逆风亦能薰　顺逆薰亦尔
```

（大意：阿难！有一类香，顺风时善能薰；逆风时也能薰，顺风逆风都能薰。）

有的地方世尊宣说尸罗名为妙行，如伽他说：

```
身妙行能感　可爱诸异熟
于现法当来　语妙行亦尔
```

（大意：身的妙行，能感得可爱的诸异熟，在现法与来世都是如此；语的妙行也是这样。）

有的地方世尊宣说尸罗名为律仪，如伽他说：

```
诸有惠施主　具戒住律仪
有阿笈摩见　及有果正见
```

（大意：诸有惠施的施主，具足戒、安住律仪，有阿笈摩之见，以及有果的正见。）

【按】遁伦《瑜伽论记》说：阿笈摩见，旧译“阿含见”，就是证见；阿笈摩此方翻为传，就是佛教传流、证理的正见，能得果，所以名为有见。

又有地方说：“安住具戒，善能守护别解脱律仪”，乃至广说。

问：由于什么缘故，世尊宣说尸罗名为根本？

答：能建立的意思、能任持的意思，是根本的意思。由这尸罗建立、任持一切世间以及出世间，能引生无罪、最胜、第一的快乐功德，使之生起、使之证得，所以尸罗说名为根本。譬如大地，建立、任持一切药草、卉木、丛林，使之生起、使之增长；这样的尸罗，如前广说。

【按】遁伦《瑜伽论记》说：建立，是最初能安立；任持，是后来能任持。令生，是对有为法说；令证，是对无为法说。

问：由于什么缘故，世尊宣说尸罗名为庄严具？

答：世间其余的耳环、指环、腕钏、臂钏，以及宝印、金银、花鬘等美妙的庄严具，如果是年幼黑发、少年盛壮、形色姝妙的人佩戴，稍增美好；如果是朽老、衰迈、齿落、发白、年过八十或九十的人佩戴，就不会美好，除非是为了俳戏，令众人欢笑。如果遭遇病苦、财货匮乏、亲戚丧亡，在那时佩戴，也不美好。戒这一庄严具，对一切类人、在一切时，若有佩戴的，都是美好的。所以尸罗名为庄严具。

问：由于什么缘故，世尊宣说尸罗名为涂香？

答：由这所受的清净、无罪、美妙良善的尸罗，能正确除遣由一切所受恶戒为因的身心热恼。譬如在最为炎热的时候，涂上栴檀、龙脑香等，一切郁蒸都得以除灭。所以尸罗说名为涂香。

问：由于什么缘故，世尊宣说尸罗名为薰香？

答：具戒的士夫补特伽罗，遍于诸方，美妙良善的称誉声颂普遍听闻。譬如种种根香、茎香等，随风飘扬，遍于诸方，悦意芬芳，周流弥远。所以尸罗名为薰香。

问：由于什么缘故，世尊宣说尸罗名为妙行？

答：由这尸罗清净的善行，能趣向美妙的安乐，前往美妙的天趣，趣向美妙的安隐，所以名为妙行。

问：由于什么缘故，世尊宣说尸罗名为律仪？

答：由这尸罗清净的善法，是防护之性，是息除之相，是远离之体，所以名为律仪。

#### 戒律仪：三种观察清净因

又戒律仪有三种观察的清净因相。哪三种？一是观察身业，二是观察语业，三是观察意业。

怎样观察这些业，使戒律仪都得清净？就是在希望将要造作以及想要正在造作身业时，这样观察：“我这身业，是能损害自己以及损害他人，属于不善性，能生起众苦，招感苦的异熟？还是不损害自己、也不损害他人，属于善性，能生起诸乐，招感乐的异熟？”这样观察之后，如果自己了知“我这身业损害自己、损害他人，属于不善性，能生起众苦，招感苦的异熟”，就对这业收敛而不作，也不给它机会。如果自己了知“我这身业不损害自己与他人，属于善性”，其余如前所说，就对这业不收敛，而去造作，给它机会。

又对过去已造的身业也数数观察：“我这身业，是能损害自己”，其余如前所说。这样观察之后，如果自己了知“我这身业损害自己、损害他人”，其余如前所说，便在有智慧的同梵行者那里如实发露，如法悔除。如果自己了知“我这身业不损害自己与他人”，其余如前所说，便生欢喜，昼夜安住，多多随之修学。这样，他对于过去、未来、现在世所造的身业，能善观察、能善清净。

如对于身业，对于语业，应当知道也是这样。

以过去的行为缘而生起意，以未来的行为缘而生起意，以现在的行为缘而生起意，就对这意数数观察：“我这意业，是能损害自己”，其余如前所说。这样观察之后，如果自己了知“我这意业属于黑品”，就对这业收敛而不生起，不给它机会；如果自己了知“我这意业属于白品”，就对这业不收敛，而去发起，给它机会。这样，他对于过去、未来、现在世所起的意业，能善观察、能善清净。

为什么？过去、未来、现在世所有的沙门或婆罗门，对于身语意三种业，或已观察、或当观察、或正观察，或已清净、或当清净、或正清净，或已多住、或当多住、或正多住，一切都是由这样的观察、这样的清净。如佛世尊曾经为长老罗怙罗所说：

```
汝今罗怙罗　于身语意业
应数正观察　念诸佛圣教
罗怙罗汝应　学是沙门业
若能于此学　唯胜善无恶
```

（大意：罗怙罗！你现在对于身、语、意三业，应当数数正确观察，忆念诸佛的圣教。罗怙罗！你应当学习这沙门之业；如果能在这上面修学，唯有殊胜的善，没有恶。）

如果对于这样的身语意业审正思择：“我这些业，是能损害自己”，广说如前，这名为观察。如果对其中一分收敛而不作，也不给它机会，广说乃至发露悔除；又对其中一分不收敛，而去造作、给它机会，广说乃至便生欢喜，昼夜安住，多多随之修学，这名为清净。

#### 戒律仪：戒德十种胜利

这样清净的尸罗律仪，应当知道有十种功德胜利。哪十种？

就是所有具戒的士夫补特伽罗，自己观察戒已清净，便得无悔；由于无悔所以欢悦；由于欢悦所以生喜；由于心喜，身得轻安；由于身轻安，便受殊胜的乐；由于乐，心得定；由于心得定，能如实知、能如实见；由于如实知见，便能生起厌离；由于能生起厌离，便得离染；由于离染，证得解脱；由于得解脱，便自知自见“我已解脱”，乃至“我能在无余依般涅槃界中当般涅槃”。这样，所有具戒的士夫补特伽罗，由于尸罗清净的增上力，获得无悔，渐次乃至能到涅槃。这名为第一种尸罗律仪的功德胜利。

又有其余具戒的士夫补特伽罗，在临终时生起这样的念头：“我已善作了身语意之行，没有恶作身语意之行”，乃至广说；“如果有那样的去处，是作福业者、作善业者、作能救济诸怖畏之事者所应前往的，我对那去处必定当会前往。”这样获得能往善趣的第二种无悔。由于没有悔恨，所有的士夫补特伽罗，名为贤善而死、贤善而逝、贤善而往。这名为第二种尸罗律仪的功德胜利。

【按】遁伦《瑜伽论记》说：人天善趣，是作福业等三种人在未来必定往生的，所以不怖畏恶趣，这是第二种无悔；如果有所违犯，就会怖畏恶趣，所以不名为贤善而死。

又有其余具戒的士夫补特伽罗，遍于诸方，美妙良善的称誉声颂普遍听闻。这名为第三种尸罗律仪的功德胜利。

又有其余具戒的士夫补特伽罗，睡得安稳、醒得安稳，远离一切身心热恼。这名为第四种尸罗律仪的功德胜利。

又有其余具戒的士夫补特伽罗，无论睡或醒，诸天都保护他。这名为第五种尸罗律仪的功德胜利。

又有其余具戒的士夫补特伽罗，对于他人的凶暴不忧虑其恶，没有种种怖畏，心离惊恐。这名为第六种尸罗律仪的功德胜利。

又有其余具戒的士夫补特伽罗，那些喜好杀害的人、怨雠、恶友，虽然得到可乘之隙，也常保护他，了知“这是具戒的士夫补特伽罗”，或作为善友，或保持中立。这名为第七种尸罗律仪的功德胜利。

又有其余具戒的士夫补特伽罗，一切魍魉、药叉、宅神、非人之类，虽然得到可乘之便、可乘之隙，却常保护他，这是由于具足尸罗的增上力。这名为第八种尸罗律仪的功德胜利。

又有其余具戒的士夫补特伽罗，如法而无艰难地从他人那里获得种种利养，就是衣服、饮食、卧具、病缘医药以及诸资具；由于依于尸罗增上的因力，国王、大臣以及诸平民、富有的长者以及商主等恭敬尊重。这名为第九种尸罗律仪的功德胜利。

又有其余具戒的士夫补特伽罗，一切所愿都得以如意。如果在欲界中，愿乐当生于或刹帝利大族姓之家、或婆罗门大族姓之家、或诸居士大族姓之家、或诸长者大族姓之家，或四大王众天、或三十三天、或夜摩天、或睹史多天、或化乐天、或他化自在天的众同分中，由于戒清净，就随所愿当得往生。如果愿乐入诸静虑现法乐住，或在有色天的众同分中或住或生，由于戒清净，便得离欲，所愿都得以如意。如果愿乐寂静的胜解，超过色界之定，入无色定具足安住，或在无色天的众同分中当得往生，其余如前所说。如果愿乐当证最极究竟的涅槃，由于戒清净，便证得一切究竟离欲。这名为第十种尸罗律仪的功德胜利。

这样已经说了戒蕴的广辨、戒蕴的亏损、戒蕴的圆满、戒蕴的异门、戒蕴的观察以及清净、戒蕴的一切功德胜利。在这里宣说、明了开示一切种相、最极圆满、资粮所摄的尸罗律仪。若有自己爱乐沙门性、婆罗门性的诸善男子，应当勤加修学。

瑜伽师地论卷第二十二

## 本卷要义

本卷开始出离地。出离地分为由世间道离欲、由出世间道离欲，以及这两种道的资粮。世间道是以下地为粗、上地为静，次第离欲，乃至无所有处；出世间道是如实知四谛，成就有学智见，渐修圣道，对三界见修所断一切法自能离系、自得解脱。

两种道的资粮共有十四门：自圆满、他圆满、善法欲、戒律仪、根律仪、于食知量、觉寤瑜伽、正知而住、善友、闻正法、思正法、无障碍、惠舍、沙门庄严。前三门已在种姓地说过，本卷专讲第四门戒律仪，以辨三、亏损十、圆满十、六异门、三种清净、十种胜功德六部分展开。

辨三部分逐句解释“安住具戒、善能守护别解律仪、轨则所行皆悉圆满、于微小罪见大怖畏、受学学处”，并以两番三义收摄：一番是无失坏相、自性相、自性功德相，后者又分观他增上（令未信者信）与观自增上（避恶趣、得所未得）；一番是受持戒性、出离戒性、修习戒性。别解脱律仪之所以名出离戒，是因为依增上戒修增上心、增上慧，才能一切苦尽、究竟出离。

亏损十因缘写得极为细致：从被逼出家的最初恶受，到太沉、太浮、放逸、邪愿、轨则亏损、净命亏损（诈现威仪、现相求衣、苦苦研逼、当面毁弃施物）、堕于欲乐与苦行二边、以戒禁取求出离，直到“内怀腐败，外现贞实”的所受失坏。其中后两种特称为“尸罗艰难”。

六异门以根本、庄严、涂香、薰香、妙行、律仪六喻说戒；三种清净是对身语意三业的过去现在未来反复观察，引佛告罗怙罗之偈为证；十种胜利从无悔、欢、喜、轻安、乐、定、如实知见、厌、离染、解脱的次第开始，一直说到临终无悔、诸天守护、随愿往生，乃至究竟涅槃。
