〔译注：本篇译《三身义林》第四门"因起果相"的前半。这一门原文近六千字，分两篇翻译。本篇讲成就三身的根本之因：

1. 以《摄大乘论》多闻熏习为一因，依《成唯识论》等辨析无漏种子的三种说法，窥基取"本有、新熏兼有"之说，并以"转灭""转齐"两义说明种子逐品增胜。
2. 依天亲《金刚般若论》立生因、了因，说明法身由了因成佛，自受用身、他受用身、变化身由生因成佛，各自成佛的相状。
3. 菩萨的三种类别，以及三身非定一、非定异。

下一篇译后半：生因与引因，以及二因、三因、四缘、六因、十因等诸门，再辨五果。〕

一、多闻熏习为一因

（一）《摄大乘论》的说法

《摄大乘论》等说一种因。那部论第六卷说："入所知相应当怎样了知？多闻熏习所依，不是阿赖耶识所摄……"又说："由什么能入？由善根力所任持……乃至广说。"因为多闻熏习是出世间心的种子体性。

这是说最初修习四种殊胜的修行：

1. 亲近善士，作为殊胜的助缘。
2. 听闻正法。
3. 如理思惟。
4. 如说修行。

后三种是内在的修行。内在的修行，要先有多闻熏习，少闻的人没有可能得到。

（二）无漏种子的三种解释

这多闻熏习的种子，《成唯识论》等略有三种解释。

第一种解释：只有新熏

只有新熏的种子，只以有漏种子作为因缘，直接生出无漏法。

《成唯识论》中已经广泛破斥这种说法。依《瑜伽师地论》第五十二卷问："如果各种习气摄一切种子，又称为遍行粗重，各种出世间法从什么种子生？如果说以粗重自性的种子为种子而生，不合道理。"所以可知有漏法不是无漏法直接生起的因缘。

第二种解释：只有本有

1. 各种无漏种子，在还没有发心以前，称为性种姓；发心以后，称为习种姓，因为熏习无漏种子的作用，令无漏种子渐渐增长。
2. 见道以前，有漏的闻熏习能生起现行，无漏种子还没有生起现行。同时取有漏闻熏和无漏种子这两者，称为顺解脱分善、顺抉择分善。所以《杂集论》说："顺抉择分善，属于修道所断，也可以建立为无漏性，属于道谛所摄。"
3. 见道以后，无漏种子才生起现行。
4. 第八地以前，有漏、无漏两种夹杂生起。
5. 成佛以后，各种有漏善法以及因位的无漏法，都转灭；各种果位的无漏法圆满生起。所以《涅槃经》说："舍弃无常的色，获得常住的色；受、想、行、识也是这样。"

窥基评论说：观察这种意义，只有旧的种子生起现行，完全没有现行再新熏种子的情形。《成唯识论》中也已经广泛破斥。

第三种解释：本有、新熏两种都有

种子都有两种：本有、新熏。见道以前，与第二种解释相同。见道以后，各种本有的无漏种子生起现行，新生起的各种现行又熏成新的种子。这里略有两种意义：一是转灭，二是转齐。

1. 转灭

比如大乘的修行位：

1. 无始以来，加行的殊胜善种和无漏善种，因为没有遇到助缘，都只是下品。
2. 见道以前，以有漏的闻熏习作为殊胜的助缘，资助下品的无漏种子，令下品的无漏种子渐渐增胜。
3. 到见道位，生起下品的现行，下品现行又熏成下品种子。
4. 以见道的修习作为助缘，到修道位，前一刹那中见道的下品种子灭去，修道中的中品种子生起中品现行，中品现行又熏成中品种子。
5. 以修道的修习作为助缘，到究竟位，前一刹那中，中品无漏种子灭去，后一刹那中，上品无漏种子生起。上品之后没有所依，道已经圆满，所以不再熏习。

本来只有一品，低劣的灭去、殊胜的生起，所以称为转灭。原因是：由于后来的修习，前面的同类种子不能作为同类因，引生后来的同类果。

这样，每一地的下、中、上品各种无漏种子，以及各位中加行殊胜善的下、中、上品各种有漏种子，都应当依此类推了知。到佛位中，只有无漏的上品圆满，无漏的中品、下品，以及一切有漏种子，都舍弃灭去。所以经中说"舍弃无常的色"等。

2. 转齐

1. 法尔本有的种子都有三品。最初修习下品，所以到见道位，下品无漏种子生起现行，现行又熏成下品种子。如果没有修习，下品种子任运生起。
2. 由于修习，到修道位，中品种子生起中品现行，现行又熏成中品种子，前面的下品种子也转成中品。如果不熏习，中品种子任运生起。
3. 由于修习，到佛位中，上品种子生起上品现行。道已经圆满，没有所熏，所以不再熏习。中品种子都转成上品。

前面的中品、下品种子不再相续，与后来殊胜的种子齐等，所以称为转齐。所以经中说"舍弃无常的色"等。

就自己同一品类来说，可以称为转灭；说"转齐"这个名称，是就其他不同品类来说。

（三）有漏、无漏种子的相互资助

这多闻熏习的种子：

1. 见道以前：
   - 有漏种子直接作为因缘，生起各种现行，现行作为因缘，又熏成种子。
   - 有漏种子对无漏种子以及其余的出世间法，作为增上缘。
   - 由于有漏种子受到无漏种子的资持，各种有漏种子感得殊胜的异熟，不造无间业，不堕恶趣等。
   - 由于有漏法资助无漏法，将来生起出世间的无漏现行。
2. 见道以后：
   - 无漏种子直接作为因缘，生起无漏现行。
   - 无漏种子对有漏法作为增上缘，令有漏善法感得十王果。
   - 各种有漏善法资助无漏法，辗转增明，证得离系法。
3. 乃至成佛：有漏法都灭去，纯粹的无漏法存在，各种受生都是依示现。

（四）闻熏习成为法身、受用身的因

这闻熏习，见道以前，听闻相似的法义、理与智之法以后，屡屡生起思惟，乃至在四善根中等引修习。到见道位，能证的智慧生起，熏发种子：

1. 所生的现前智慧和所显现的相好，作为受用身的因。
2. 所证之理的明显，作为法身的因。

所以《胜鬘经》说："对于无量烦恼藏所缠的如来藏不疑惑的人，对于出离无量烦恼藏所缠的如来法身，也没有疑惑。"由于修习两种因，所以得到两种身。

化身只由大悲熏煮，修习前面两种因，由愿力所生起。《金光明经》说："第一身依应身显现，第二身依法身显现。"法身没有所依，说法身是如如、如如智。

大菩提心以善根为自体，善根就是大菩提的体性。《大智度论》说："智慧和智慧所处，都称为般若。"《菩萨地》说："菩提和菩提断，都称为菩提。"各种善根就是多闻熏习的种子。

二、生因与了因

（一）经论的依据

《涅槃经》等经说有两种因：

1. 生因：如芽生出茎。
2. 了因：犹如灯照见物。

《般若经》说："一切诸佛法，都从这部经出；一切诸佛，从这部经生。"

天亲《金刚般若论》解释说：

「于实为了因，亦为余生因，唯独诸佛法，福成第一体。」（大意：受持、演说这部经，对真实的法身是了因，对其余的身是生因；唯有诸佛之法，以这种福德成为第一体。）

菩提称为法身，体性真实，是无为法。持经和说经两者是了因，因为真如法身是由证因而得，不是由生因所生。其余的，就是受报的相好庄严佛、化身相好佛，持经和说经对这两种身是生因，因为这两种身由生因所生。

十法行都能作为因。受持是自利，演说是利他，依据十法行中殊胜的两种，所以略而不说其余的。持经和演说只说为因，因为能持、能说两种善根正是因。

（二）生因的正与助

生因有两种：一正，二助。

1. 有漏的持经、说经，对受用身是疏远的助因，因为体性相违。
2. 无漏的持经、说经，是佛的正因，因为无漏与受用身相顺，直接生起。

这两种生因，通于现行和种子。

（三）了因的正与助

了因也是这样，有两种：一正，二助。

1. 无漏智中的无分别智，对自性身是正了因。
2. 各种有漏智以及后得智，是助了因。

各种种子不是了因，因为种子不能缘境。〔存疑：原文「非诸种子。不闻缘故」，"不闻缘"疑为"不能缘"之误，暂依此意翻译。〕

这是说：一种因能得两种果。对自己同类的果（有为的受用身、化身）作为生因，对其他异类的果（无为的法身）作为了因。化身也是由生因所生。

三、法身：了因成佛之相

这里所说的法身，见道以前处在烦恼缠缚的位置，称为如来藏。二乘得到生空真如，所知障还没有除去，生空真如不是功德的依止，所以不称为法身。

由于屡屡听闻、思惟、修习悲智之因，初地以上二障渐渐断除，真如成为功德的依止，就称为法身。如前面所引《大般若经》所说："初地中得平等身，乃至第十地得妙智身。"世尊亲自说这十身是法身。由于证得那真理的能证之智有十种功德的差别，显示所证的法身也有十种。

乃至成佛，二障都断尽，二智圆满成就，功德圆满，所证的理身明净显现，再没有差别，都称为法身，也称为自性身。犹如虚空除去翳障，明净豁然，不是新有的虚空。法身也是这样。这称为法身由了因成佛。

四、自受用身：生因成佛之相

（一）十地的生起

见道以前，由于屡屡听闻、思惟、修习大智之因，令无漏种子的势力增长。初地以上，能生起现行的各种无漏智，这各种智的分位差别，称为十地。所以《摄大乘论》说："法无我智的分位称为地。"

（二）菩萨受变易身的两类

此后菩萨略有两类：

1. 怖畏烦恼的菩萨：便折伏烦恼，令烦恼都不现行，从初地以后受变易身。《楞伽经》依这一类，把十地菩萨分为三种意生身。
2. 不怖畏烦恼的菩萨：从第七地将要圆满的心中，才受变易身。《胜鬘经》依这一类，说二乘无学和得自在的菩萨为三种意生身，因为这类菩萨在第七地以前不怖畏迷惑。

详细如《二种生死义林》中所说。

（三）十种受用身

所证的真理既然称为十种法身，能证的功德也称为十种受用身，因为受用法乐。

过去作为异生时，造十王业，初地以后受十王果。第八识、五识所变现的身形，是有漏异熟，相好、神通都渐渐具足。后得智依这有漏身更变现殊胜的相好身，是无漏所摄，生在各种净土，庄严道场。在一个身处，作两类变现，两者的相状相似，见到的人觉得冥合为一，合称为受用身。

1. 怖畏烦恼的菩萨：在见道以后生到广果天，资助现前身的因，转受变易身。
2. 不怖畏烦恼的菩萨：在第七地满心才生到广果天，资助现前身的业，转成变易身。

如《成唯识论》详细说明这种意义。

十地的受用身，依照十地所证，应当有十种名称。与法身的名称相同，道理上也没有差错，因为依能证的功德显示法身。或者十地的名称，就是十地受用身的名称，因为依十地菩萨立十地的名称。

（四）自受用身成佛

这样十地辗转殊胜，到第十地将要成佛时，在净居天上，有大宝莲花的相状显现，大小如十阿僧祇百千三千大千世界微尘的数量，菩萨坐在大宝莲花上成正觉。

金刚心位还有有漏的身和低劣的无漏身。解脱道生起时，有漏的身完全断尽，低劣的无漏身灭去，所以经中说"舍弃无常的色"等。四智圆满成就，功德具足，八识都成无漏，所变现的色身也都是无漏。智慧如其境界，充满遍布法界，功德色身也都是这样，相续湛然，穷尽未来际，因为利益众生的本愿穷尽法界。这称为自受用身由生因所生而成佛的相状。

五、他受用身：生因成佛之相

（一）随十地逐渐转大

见道以前，以大悲熏煮作为因，为十地中下类的菩萨显现他受用身。他受用身只是后得无漏智所变现，辗转殊胜广大，乃至成佛能遍满十方，随其所宜，为十地菩萨众，逐渐转大，显现他受用身。

初地菩萨见到佛坐在百叶莲花上，就是相称于百个大千世界。比如阿弥陀佛，眼如四大海水，眉间白毫相如五座须弥山，身高六十万亿那由他恒河沙由旬，应当是初地菩萨所见。二地菩萨见到佛坐在千叶莲花上，乃至十地菩萨所见辗转更大。

（二）他受用身也现受生

这他受用身，也有父母，也显现受生，不先住在天上，再下生成佛。

《鼓音王经》说：阿弥陀佛的父亲名叫月上，母亲名叫殊胜妙颜，儿子名叫月明，奉事的弟子名叫无垢称，魔王名叫无胜，提婆达多名叫寂。

《无量寿经论》说：「女人及根缺，二乘种不生。」（大意：女人和诸根残缺的人，以及二乘种性，不生在那个国土。）阿弥陀佛的国土既然是报土，没有真实的女人，所以母亲等是佛和菩萨所化现，因为化现分段身，所以显现这种相状。化现变易身，没有见到确实的说法。

《法华经》中说：大迦叶将来成佛时，没有魔事，魔和魔民都护持佛法。大迦叶成佛时的国土尚且有这样的相状，何况报土中有真实的魔事？只是大菩萨化为魔王，为了障碍他人的受用，有时显现魔事。

（三）观音、势至相继成佛

《观音授记经》说：阿弥陀佛寿命无量，百千万亿劫后当有终极。阿弥陀佛灭度以后，观世音菩萨在明相出现时，于七宝菩提树下成等正觉，名号是普光功德山王佛，国名众宝普集庄严，胜过阿弥陀佛国百千万亿倍，不可比拟。这位佛灭度以后，大势至菩萨成佛，名号是善住功德宝王佛。

十地菩萨的机宜事先已经淳熟，所以化导这类菩萨，即身成佛，不说先住在什么地方、什么天上，后来再补处，就以这个身就座成佛。这是他受用身由大悲所熏、生因所生而成佛的相状。

六、变化身：生因成佛之相

（一）初地以后能现化身

平等性智在初地以后，能随众生所乐示现。由于见道以前大悲熏煮，初地以后能随顺三乘，随其所宜见，显现种种身。

1. 《华严经》说：十住之中的初发心住，就能示现正觉，后来示现入涅槃。何况十地中不显现变化的相状？
2. 《法华经》等说：观音菩萨、妙音菩萨都以神力，"应以三乘身得度的，便显现那种身而为说法"。

所以在十地位中都能显现化身。

这变化身和他受用身，由后得智所变现，本来只是无漏；第五识、第八识的心品依这两种身所变现的，都只是有漏。两者同处、相似，见到的人觉得相似为一。

（二）成佛时示现下生

乃至成佛，能随顺十方三乘的所宜，显现种种变化，或者显现佛身，或者显现其余的身。在先前的菩萨位，要先住在睹史多天，然后才下生。

1. 劫初成劫的时候，生在婆罗门家，比如弥勒等，因为那时的人轻视富贵、重视净行。
2. 劫后减劫的时候，生在刹帝利家，比如释迦牟尼佛等，因为那时的人轻视净行、重视富贵。

佛为了化导这两种人，显现两种受生。

〔译注：原文「能寂」是释迦牟尼的意译。〕

（三）八相成道

《摄大乘论》第九卷说：佛的变化身能显现八相：

1. 天宫示现、隐没
2. 受生
3. 受欲
4. 逾城出家
5. 修各种苦行
6. 证大菩提
7. 转大法轮
8. 入大涅槃

《大般若经》第五百六十八卷也说八相：

1. 从天上隐没，就是入胎相
2. 婴儿，就是受生相
3. 童子，就是受欲相
4. 苦行
5. 成道
6. 降魔
7. 转法轮
8. 入涅槃

《大般若经》没有《摄大乘论》的出家相，加了降魔相。

1. 《摄大乘论》中，降魔属于成道相所摄。原因有二：成道离开三魔，降魔只降伏一魔；并且成道以后就降伏了魔。最初示现出家，后来才修苦行，所以把出家与苦行分开另立，因为那部论中，出家示现厌离世俗的相状，苦行示现修习邪行的相状。
2. 《大般若经》中，依出家是为了修苦行，所以把出家与苦行合起来建立；修道证果、降魔除怨，所以把降魔分开另立。

两者各依一种意义，也不相违。详细如那部经所说。

（四）显现成佛相的原因

显现八相的原因：《华严经》中说有十相，是在八相中加两相。三乘有情的根器还没有成熟，为了令三乘有情深深欣乐，才显现佛身，所以先住在天上，再下生成佛，因为是众生所应见的。这是变化身由大悲熏煮、生因所生而成佛的相状。

七、菩萨的三种类别

（一）三类的名称

教法中说菩萨种类有三种：

1. 一生所系：比如弥勒菩萨等。
2. 最后身。
3. 坐道场。

（二）一生所系的计算

弥勒菩萨等先住在人中，这个身称为一生所系。就将来的佛位来说，应当有四生：人中的本有、天上的本有，以及两个中有。比如预流果"七生"等的算法，这四生合称为一大生。如果住在天上，称为一生系，因为半生也称为一生，只有一个本有。

《大智度论》说弥勒菩萨有三生，是就人中说，除去成佛的身，所以说三生。

〔存疑：原文「望当佛位应有四生。人天本有及二中有。如七生等名一大生。若住天中称一生系。半生名一。一本有故」，大意如上，"半生名一"的具体算法未能完全确定。〕

（三）三类与三身

最后身和坐道场两种，只限于成佛的身位。化身既然显示这三类，两种受用身经中没有见到文字说明，依照化身的情形，应当全都可以了知：

1. 自受用身：第七地以前称为一生所系；第八地以后称为最后身，因为再没有受生；坐在莲花座上称为坐道场。
2. 他受用身：比如观音菩萨的前身，称为一生所系；观音菩萨的身称为最后身；坐在七宝座上称为坐道场。
3. 法身：没有生，便没有这三类的意义。

八、三身非定一、非定异

这三身不是决定为一，也不是决定为异：

1. 自受用身是佛自身的相状，法身就是这身的理性。理与智深妙，不是其余的人所能了知。
2. 三乘见到粗相，立名为变化身；十地菩萨见到细相，称为他受用身。

由于所见不同，体性和相状有差异，按功德义理的聚集，分成三身。不像有情各有不同的自体，立为三种。三身没有决定的差异，也不是没有差异，所以不是决定为一或为异。

比如释迦牟尼佛：

1. 十地菩萨所见的，称为他受用身。
2. 二乘所见的，称为变化身。
3. 无分别智观察佛的真理，就称为法身。
4. 真实智慧深微，长久修因圆满，自己受用法乐，不是其余的人所能了知，称为自受用身。

知见不同，所以不是决定为一或为异。以上是生因、了因所成的因起果相。
