# 窥基《大乘法苑义林章》（四十三）破魔罗义林

〔译注：《破魔罗义林》是全书第二十五章，讨论"魔"的种类、体性，以及菩萨在什么位次破除各种魔。窥基把魔分为分段品魔和变易品魔两大类，再展开为三魔、四魔、八魔、十魔。其中引《无垢称经》"作魔王者多是不思议解脱菩萨"、《鼓音王经》"唯有龙象能与龙象而为战诤"，说明十地菩萨所遇的天魔，多是大菩萨化现。〕

破魔罗的意义，用七门分别：

1. 列名的不同
2. 释名出体
3. 说明废立
4. 辨明所障
5. 能破的差别
6. 真实破魔的位次
7. 示现降魔的时间

## 第一门　列名的不同

### 一、二魔

魔有两种：一是分段品魔，二是变易品魔。

《法华经·安乐行品》说："如来也是这样，以禅定、智慧的力量，得到法的国土，在三界中称王，而诸魔王不肯顺伏。如来的贤圣诸将与魔王共同作战，有功的人，如来心中也欢喜，在四众中，为有功者宣说诸经，令有功者心中欢悦……乃至又赐与涅槃之城，说已得灭度，引导有功者的心，令有功者欢喜，而不为有功者宣说这部《法华经》。"

这是说二乘先前所破灭的，所以可知只是分段的魔。烦恼障一类既然障碍二乘，说为魔；所知障一类障碍菩萨，明显可知也是魔。

《胜鬘经》说："有作四圣谛、无作四圣谛，如来应正等觉最初觉知，然后为无明壳所覆藏的众生方便演说。"既然分出两种生死、两种五蕴、两种烦恼，明显可知天魔也有两类。

〔译注：原文"无明?藏"缺一字，依《胜鬘经》补作"无明壳藏"。〕

### 二、三魔

或者说三魔。《法华经》又说："如来也是这样，在三界中作为大法王，以法教化一切众生，见到贤圣的军队与五阴魔、烦恼魔、死魔共同作战，有大功勋，灭除三毒，出离三界，破除魔网，那时如来也大欢喜。"这里不说天魔。

### 三、四魔

或者说四魔。《瑜伽师地论》等说："坦然安坐于微妙的菩提座，降伏四魔，具足大势力，称为薄伽梵。"《佛地经论》说："所说的四魔：一是烦恼魔，二是蕴魔，三是死魔，四是自在天魔。"

### 四、八魔

或者说八魔，就是分段、变易各有四种魔。因为菩萨以分别以及所知障作为烦恼，所以道理上也决定有变易生死一类的烦恼魔。

又说八魔：《涅槃经》说，在四魔之上再加上四种颠倒。

### 五、十魔

或者说十魔。《杂藏》中说：

「欲、忧愁、饥渴，爱、睡眠、怖畏，疑、毒及名利，自高轻慢彼。汝等军如是，一切无能破；我智箭定刀，摧坏瓶投水。」（大意：欲、忧愁、饥渴、爱、睡眠、怖畏、疑、毒，以及名利、自高而轻慢他人，你们的魔军就是这些，一切人都不能破除；我以智慧之箭、禅定之刀，摧坏你们，如同打碎陶瓶投入水中。）

## 第二门　释名出体

先释名，后出体。

### 一、释名

#### （一）通名

梵语"魔罗"（māra），汉语称为扰乱、障碍、破坏：扰乱身心，障碍善法，破坏殊胜的事业，所以称为魔罗。这里简略称为"魔"，是诸魔的通称。"三"等是数目，是带数释。

又称为"波卑夜"（pāpīyas），汉语称为"恶者"，是天魔的别名，"波旬"是讹音，因为成就恶法、心怀恶意。"恶魔波旬"，是称号和名字同时举出。

#### （二）别名

1. 分段、变易：可以分、可以段，称为分段；"品"是类的意思。变改转易，称为变易；"品"的意义如前面所说。分段品、变易品就是魔，是持业释。
2. 四魔：烦杂众多，扰乱身心，称为烦恼；色等积聚，称为蕴；将尽、正尽、尽已，称为死；神用光明洁净、自在，称为天。这四种就是魔，都是持业释。
3. 涅槃八魔：前四种如前面所说；无常、无乐、无我、无净，颠倒的体性就是魔，也是持业释。
4. 十魔：
   - 可欣乐的，称为欲。
   - 内心悲戚，称为忧愁。
   - 希求饮食，称为饥渴。
   - 耽着欲望，称为爱。
   - 令心昏昧简略，称为睡眠。
   - 有所恐惧怯弱，称为怖畏。
   - 犹豫于两端，称为疑。
   - 损恼身心，称为毒。
   - 希求名誉、贪求财物，称为名利。
   - 自己高举、凌驾他人，称为高慢。

   欲等就是魔，也是持业释。

这里暂且解释各种名称的不同，在增减数目中，相同的依类解释。

### 二、出体

#### （一）二魔的体性

1. 分段魔：依有作的粗四谛一类，二乘、异生粗浅的境界之事，立分段魔的体性，通于障碍二乘。因为二乘求解脱，分段魔能作为解脱的障碍。
2. 变易魔：依无作的细四谛一类，大乘异生微妙的境界之事，立变易魔的体性，只障碍菩萨。因为菩萨求菩提，变易四魔细微，能作障碍。

#### （二）三魔的体性

1. 烦恼魔：一切见道、修道所断的烦恼障一类。
2. 蕴魔：因烦恼所感的五蕴诸法。
3. 死魔：依这五蕴无常死没，将死、已死，称为死魔。

   不取死触，因为死触只是色蕴，触处的范围狭窄；也不取死支，因为死支是将死、正死，不是已死。死就是灭相，属于不相应行蕴，依五蕴假立，舍弃众同分，进入过去，破坏寿命，所以称为魔。或者兼取死支，因为将死、正死逼迫身心，破坏寿命；或者兼取死触，因为触对末摩（死穴），令生苦恼，损害寿命。

#### （三）四魔的体性

1. 烦恼魔：烦恼障、所知障，无论现行、种子，以及随其所应的习气等法。
2. 蕴魔：分段、变易两种生死的五蕴。
3. 死魔：分段生死的没无、将死、正死、死已的灭相，称为死魔；变易生死的正死、将死两个阶位，称为死魔。如果那已经灭了，就不是魔的体性。
4. 自在天魔：欲界第六他化自在天的天子魔以及眷属，以及不思议解脱菩萨所化作的。

#### （四）八魔的体性

1. 分段烦恼魔：一百二十八种根本烦恼以及随烦恼的种子、现行、习气。
2. 分段蕴魔：就是这些烦恼所招感的各种粗的五蕴类。
3. 分段死魔：就是这五蕴终尽的已死、将死、正死。
4. 分段天魔：第六天的天子以及眷属，因为粗显下劣，是真实的凡夫一类，真实地破坏。
5. 变易烦恼魔：各种所知障的现行、种子、习气，因为菩萨以分别以及一切所知障作为烦恼。
6. 变易蕴魔：变易生死的五蕴果等。
7. 变易死魔：这在最初的阶位没有终尽舍弃，只有念念微细的堕落灭去，逼迫生灭，作为死魔。
8. 变易天魔：第十地菩萨所示现的作为，称为天魔。

《无垢称经》说："作魔王的，大多是不思议解脱菩萨。"《鼓音王经》说："阿弥陀佛的父亲名叫月上，母亲名叫殊胜妙颜，魔王名叫无胜，调达名叫寂。"只有龙象能与龙象作战诤斗。十地菩萨既然将要成佛，哪里是凡夫魔王所能抗敌的？所以必定是大菩萨化为魔王，与菩萨作战诤斗。

又，涅槃八魔的体性：前四种属于分段一类，后四种属于分别所知障所摄，因为是二乘的四种颠倒。

#### （五）十魔的体性

1. 欲魔：就是五尘境界，体性是所欲求的，能生起贪欲，从果立名，称为欲。欲的体性正是对欲境的贪。
2. 忧愁：就是忧受、苦受。
3. 饥渴：就是两种触所生的两种欲。
4. 睡眠：就是不定心所中的睡眠。
5. 怖畏：就是五种怖畏：
   - 不活畏：由于分别我以及对资生之物的爱而生起。
   - 恶名畏：行不饶益之事，有所希望而生起。
   - 死畏：由于有我见、失坏想而生起。
   - 恶趣畏：不遇诸佛、恶业所生起。
   - 怯众畏：见到自己所证低劣、他人殊胜而生起。

   前两种怖畏的体性，大多是贪欲，就是对财物、名誉的爱；第三、第五种大多是我爱；第四种的体性是与慧同时的无贪，或者体性是愧，因为拒斥恶法。
6. 疑：体性如名称所示。
7. 毒：就是三毒，贪、嗔、无明。
8. 名：就是声誉。
9. 利：就是资财产业。
10. 自高轻慢他人：体性就是慢。

这里随其所应，只说五蕴、烦恼作为魔军；或者说天魔以这些作为魔军。

## 第三门　说明废立

### 一、立二魔

所障碍的有两种：一是涅槃一类，二是菩提一类。依障碍前一类，立分段品魔；依障碍后一类，立变易品魔。

或者智慧有两种：一是中智，二是上智。依中智所知的，立前一种魔；依上智所知的，立后一种魔。

或者有漏法有两种：一是粗，二是细。依粗法立分段魔，依细法立变易品魔。有作、无作，安立、非安立，也是这样说。

### 二、立三魔

三魔只是就声闻来说，因为声闻毕竟恒时所能降伏的是这三种。天魔遮蔽阿难的心，使阿难没有听到佛问入涅槃的事；邬波毱多在坐禅观想，不知不觉魔王把花插在邬波毱多的头顶上。邬波毱多生起神通，也能制伏天魔，只是不是毕竟降伏，所以略去不说，实际上也能降伏。

### 三、立四魔，为什么不立业魔

又说四魔，不说业魔，是因为作为生死的因，惑是根本，最为殊胜；由惑所生起的，蕴殊胜，业不是。蕴是总，业是别，所以不另立为魔，因为在果和因两方面都不殊胜。生、老、病三种都劣于死，从殊胜的立为魔，不立这三种；只有死有增上的作用，单独立为魔。

从法来说，立三魔，就是惑、蕴、死；从有情来说，立一魔，就是自在天魔。

### 四、立八魔

《无上依经》说：三界之内有四种难，使人不能得到如来四德的法身：

1. 烦恼难
2. 业难
3. 生报难
4. 过失难

变易生死有四种：

1. 方便生死
2. 因缘生死
3. 有有生死
4. 无有生死

依次配合前面的四难。前面是分段，后面是变易。只有业一种不立为魔，因为扰乱、破坏、障碍的作用低劣。法既然有六种，有情分为假和实，所以成为八魔。

《涅槃经》的八魔：烦恼障一类，有因有异熟果，约法和有情分出前四种；所知障一类没有异熟果，不说有情，说二乘生起的障碍四德涅槃，所以说后四种。

### 五、立十魔

十魔随着增上而立。天魔大多生起烦恼以及五蕴，这十种相状增上，所以偏说，因为障碍定和智，略去不说其余的。

## 第四门　辨明所障

1. 二魔中：分段魔障碍三乘，变易魔障碍菩萨。前者障碍解脱、涅槃，后者障碍菩提、妙智。
2. 三魔中：烦恼魔障碍有余涅槃，蕴魔障碍无余涅槃，死魔障碍生命寿命。
3. 四魔中：前三种如前面所说；天魔能障碍一切善品，因为障碍出离欲界以及三界。
4. 前一种八魔中：分段、变易两种所障不同，各别的障碍相似。
5. 后一种八魔中：前四种如前面所说；后四种障碍具足四德的大涅槃。
6. 十魔：分别障碍智和定两门，因为说以智箭、定刀两种能破除。

或者下面所说能对治魔的体性，就是所障碍的，到下面应当了知。

## 第五门　能破的差别

有六门不同：

1. 真实能破的体性：破除前三魔，是正证真如的智慧，"我生已尽，梵行已立，所作已办，不受后有"，因为由智慧证得真如，那些魔才灭除。由于有神通，才降伏天魔，也以智慧为根本，以后得智为体性。
2. 《大集经》说：知苦、断集、证灭、修道，依次能坏蕴魔、烦恼魔、死魔、自在天魔。
3. 又，观察有漏皆苦、诸行无常、诸法无我、涅槃寂静，依次能坏蕴魔、烦恼魔、死魔、天魔。
4. 又，观察空、无相、无愿，具足这三种以后回向菩提，依次破坏四魔。
5. 又，观察身、受、心、法，依次破坏四魔。
6. 《大智度论》说："菩萨得道，所以破烦恼魔；得法性身，所以破蕴魔；得道以及法性身，所以破死魔；常一心进入不动三昧，破天魔。"

前面所说的意义，各随其相状的增上，随着前面所修四种不同的行相，相当的意义来配合，并不是正证真如的一念中有这些行相的差别，应当如理了知。应当各别解释相配的缘由，恐怕文字繁广，又容易了解，所以不述。

## 第六门　真实破魔的位次

### 一、分段四魔

1. 天魔：十住菩萨中的初发心住，分成十信。《华严经》说："初发心住能八相成道。"已经伏住分段一类的天魔，已经得到神通，天魔怎么能障碍？
2. 烦恼魔：第四生贵住中已经伏住分别的诸烦恼魔，在资粮道中渐伏，在加行道中能顿伏尽，在初地初心正断分别烦恼的体性尽。俱生的烦恼，在加行道中渐伏，初地以上能顿伏尽。只是以故意的力量，有时仍然生起，并不成为过失。八地以上一切不现行，种子在金刚喻定断除。
3. 蕴魔、死魔：如果依天亲的《法华论》所说，初地以上受变易生死，就伏住蕴魔、死魔。如果依《成唯识论》，有的到八地才受变易生死，七地满心才舍弃蕴魔、死魔二魔，因为加行所修的两类菩萨意乐不同。

《无垢称经》赞叹八地以上的功德说"降伏魔怨，制伏诸外道"，是说明具足功德，不是现在才开始破除。又，具足破除四魔，要到八地以上，所以赞叹八地以上的菩萨。《佛地经论》说："初地以上离开粗的四魔，八地以上能离开细的四魔。"又，分段魔称为粗，初地就离开；变易四魔还在，细的称为还没有离开。

### 二、变易品魔

1. 烦恼魔（分别所知障）：第四住中离开不共无明的伴类；所知障在资粮道中渐伏，在加行道中能顿伏尽，初地永断。六识中的俱生所知障，十地中分分断除，八地以上一切不现行。第七识中的，乃至金刚喻定的加行道中才断而不生起。这以及六识中的种子，在金刚无间道一时才断除。

2. 变易蕴魔、死魔：《成唯识论》有两种说法：
   - 一说：金刚道生起时，都已经弃舍，因为与两种障的种子同时舍弃。
   - 正义不是这样：解脱道生起时才弃舍，因为与无间道不相违。

3. 天魔：阿弥陀佛既然有魔王，以上各位依此推知，有什么差错？要大菩萨才能作魔事，障碍大位。如果是住地菩萨，才降伏天魔；如果已经成佛，十地菩萨也不能作障碍，已经出离三界，还需要降伏什么？

4. 涅槃八魔：四倒四魔就是所知障；前面四魔与前面所说没有差异，所以不另外说。

## 第七门　示现降魔的时间

释迦佛的化身，以化相示现降魔的阶位：

1. 烦恼魔：金刚心生起，破除烦恼魔。
2. 蕴魔：舍弃第五分寿命，进入无余涅槃，破除蕴魔。
3. 死魔：魔王请佛入灭以后，佛再住世三个月，为了显示对死得到自在，破除死魔。
4. 天魔：破天魔的时间，两种经文说法不定：
   - 《涅槃经》说：在菩提树下还没有成就菩提的时候，魔王恼乱，恐怕菩萨出离三界，菩萨进入慈定，生起雷吼三摩地，就破除天魔。这与《法华经》相同，大通智胜佛破魔军以后，将要得到阿耨多罗三藐三菩提，而诸佛法不现在前。
   - 《大般若经》说八相成道，得到菩提以后才破天魔。

随着根机和部派的执持，各有不同，不需要会通。

（《破魔罗义林》终）
