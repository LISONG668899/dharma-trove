<p class="dt-title">极微章与胜定果色章</p>

<div class="dt-subtitle">大乘法苑义林章白话译注（三十八）<br>唐　窥基　撰</div>

〔译注：本篇译两章。《极微章》是全书第十九章，篇幅很短，阐明大乘不承认实有极微，极微只是以慧分析色法所假立的，并说明分析极微的五种利益。《胜定果色章》是全书第二十章，讨论由殊胜禅定所变现的色法：凡夫能否生起，能变现哪些境界，由哪种大种所造。〕

极微章

简略用三门解释：

1. 辨明能见极微的眼
2. 解释违难
3. 说明利益

第一门　辨明能见极微的眼

眼有五种：

1. 肉眼：由业等所生。
2. 天眼：由修习方便而生起。

这两种都是色蕴中的眼根。

3. 慧眼
4. 法眼

这两种都是无漏的慧根。

5. 佛眼：就是前四种眼。

下面六通中会详细分别。

《瑜伽师地论》第五十四卷说：除去肉眼、天眼，其余眼的作用，以一切极微作为所行的境界。因为天眼只取聚色中的表面，上下、前后、两边，或明或暗，必定不能取极微的处所。因为极微的体性，是以思惟分析而建立的。天眼尚且不能，何况肉眼。

第二门　解释违难

问：《华严经》说："菩萨能知无色界宫殿由若干微尘所成。"《瑜伽师地论》第五十四卷说："略说极微有十五种：五根、五尘、四大，以及法处的实色。"像这样的教文处处都有，不止一处。如果没有极微，这些要怎样会通？

答：没有真实的极微体性，如智慧所分析的，那个量也可以成立，说知道那些极微，是如所分析的量。

《瑜伽师地论》第五十四卷说："不是积集极微而成粗色。"《成唯识论》说："诸识变现的时候，随着量的大小，一下子显现一个相，不是另外变作众多的极微，合成一个物。"

《瑜伽师地论》也说："由于各种聚色，最初生起的时候，全分而生；最后灭去的时候，不到极微，中间全部灭尽，犹如水滴。"这就是显示：就像热锅中的水被煎熬，微少地灭去的时候，不到边际，各种色一下子尽灭。仔细读上面的文，又反过来解释这个意思：各种色一下子灭去，不到极微就灭尽了，不像水滴那样微少地到达边际。各种色最终灭去，仍然不到边际，何况有真实的极微可以看见？所以只是知道智慧所分析的。

又，在有体有用的法中，最极微小的，就是阿拏，说这个称为极微，这又有什么过失？

第三门　说明利益

问：既然没有极微，说极微有什么意义？

答：《瑜伽师地论》第五十四卷说有五种利益：由于分析一个和合聚集的色，安立方便，

1. 对所缘的境界，便能清净、广大地修习。
2. 又能渐渐断除萨迦耶见。
3. 断除各种憍慢。
4. 伏住各种烦恼缠。
5. 以及能迅速除去各种相执。

这里的意思是说：修习法空观，要分析各种色，先到达极微，断除各种烦恼，然后进入空观。由于这个大的意义，所以说极微。

能分析极微的心，是什么人所作，属于哪一谛所摄，都应当另外思惟。

（《极微章》终）

胜定果色章

简略用三门分别：

1. 凡夫、圣者是否能生起
2. 境界的多少
3. 由哪种大种所造

第一门　凡夫、圣者是否能生起

一、第一种说法：通于凡夫和圣者

有一种说法认为，这种色通于凡夫和圣者都能生起。

1. 《瑜伽师地论》第五十四卷说："心自在转的微细性，就是色界、无色界二界的各种色。"如契经说："有平等心天，曾经在人中熏习莹治内心，随着这种修行的力量，住在一根毛端那样的空间里，辗转更互，不相妨碍。"
2. 又《阿含经》说："无色界诸天，眼泪落下如雨，在佛身边侍立。"

这样的证明处处都有。那些地方既然说上二界的天人现身住在这里，又说这种色也通于有漏，引证的教文如前面所说，所以可知凡夫、圣者都能现起。

《显扬圣教论》只说诸佛菩萨，是依大威德的殊胜之人来说的，难道二乘等也不能变现？因为承认无色界天能落泪。

《瑜伽师地论》又说："即使不是出世间定所行的，由于那个定的增上力，有能现起的。"这是说圣者具有世间、出世间的智慧，显示不是出世间智所行的，不是简除异生不能现起。所以可知这种色决定通于凡夫和圣者。

二、第二种说法：不是异生所能生起

有一种说法认为，这种色不是异生所能生起。

1. 《显扬圣教论》第十八卷说法处色的十二种相中，只说诸佛菩萨等所变现。
2. 《瑜伽师地论》又说："离开非出世定所行的，由于那个定的增上力，有一种能现起。"尚且不是一切圣者都能生起，何况各种异生。
3. 《瑜伽师地论》第六十五卷说："要具足威德、极为寂静的定心，才能作为缘，生起这种定所生的色。也不是不具足大威德的心，以及不定的心所缘的境界。"难道异生之类能获得威德、极为寂静的定心，现起各种色？
4. 又说："这件事不可思议。"如果异生能生起，就应当属于可思议所摄。

由此，只有圣者能生起，不是凡夫所能生起。

三、抉择

《瑜伽师地论》第三十三卷说："诸圣者的神通，随所变现的事，随所作的事，随所胜解的，一切都能如实成办，没有改变差异，堪任而有作用。不是圣者的神通，不能这样，犹如幻化，只可以观看，不堪受用。"

所以前一种解释是正确的。

第二门　境界的多少

一、胜定果色具足五境

《瑜伽师地论》第五十三卷说："胜定果色，对一切色都得到自在。"又《显扬圣教论》第四卷解释最初的胜处说："或胜或劣，就是清净、不清净的色、声、香、味、触所摄的色。"由这样等等的教文确实证明，所以可知这种色，无论是假是实，是有漏是无漏，都具足五境。

《瑜伽师地论》第八十九卷说："变化不能作四种事，就是业果、心、心所，以及根。"所以其余一切都能变化。

二、会通"唯有显色等相"

《瑜伽师地论》第六十四卷说："胜定果色，应当知道只有显色等相，因为对那香等，生起的因缺乏，以及没有作用。"

这句话的意思是显示：

1. 异生的定，前面加行的因低劣，所以不能变化香、味等色；即使变化，也没有那种实在的作用。不是指诸圣者。
2. 又，有漏定的势力微弱低劣，只能变起色、声、触三种；香、味因为没有前面的加行因，所以不能变起，即使变化也没有作用。不是指无漏心。
3. 又，二乘不能变起香、味两种，不是指诸菩萨。
4. 又，以欲界为本质的，具有五境；以上界的色为本质的，没有香、味两种，因为上界地没有种子、所依托两种因。
5. 又，变化欲界，具有五种；变化色界的境界，只有三种，随着有无的缘故。即使依托变化那里，也没有实在的作用，因为没有本质。

三、定果色通于香味的经证

如果定果色不变化香、味：

1. 《华严经》说："菩萨的鼻根能闻到无色界宫殿的香。"
2. 《法华经》说："由于受持这部经，光音天、遍净天，乃至有顶天，初生、退没，闻到香气都能了知。"

那些界的异熟本来没有香、味，如果不是定果色，这是什么香？并不是只变化香而不变化味。所以可知定果色通于香、味等。

《法华论》说："这是智慧的境界，鼻根能了知，因为诸根互用。"

四、会通"威德定色似彼自性"

不可以说：《瑜伽师地论》第六十五卷说"威德定所生的色，不与那十种有色处的自相相应，能似那些的自性而显现"，眼等五根既然没有实相的作用，香、味两种法的作用也没有，色、声、触三种有实在的作用。

因为根作为识的所依，所变现的根，识不依止，可以没有实在的作用；香、味不是这样，怎么会没有作用？香、味与色、触是同类的。似根只是色等五境所摄。如前面的道理，既然已经广泛成立，所以定果色决定具足五境，因为香积佛国决定具足五种境界。

第三门　由哪种大种所造

一、诸文的不同说法

1. 《瑜伽师地论》第五十四卷说："胜定果色，如果依此地所系的定，就由此地所系的大种所造。"
2. 又说："这种色由于殊胜禅定的力量，先生起大种，然后造色变异而生。"
3. 又说："这种色不依大种，只是从缘那个种类的影像三摩地所发起，所以也说为那种大种所造，不是依那种大种而生称为造。"
4. 《瑜伽师地论》第六十六卷说："问：世尊说有无见无对的色，应当说是哪种大种所造？答：如果那定心思惟欲界有色的诸法，影像生起，应当说是欲界的大种所造；思惟色界的，大种所造也是这样。"
5. 《显扬圣教论》第十八卷说法处色有十二种相，第五种色相不是实在的大种所生。

二、窥基的会通：两类大种

这五处文字作出种种不同的说法，现在详细审察"造"的意义，不超过两类，因为所缘的亲疏大种只有两类：

〔存疑：原文作「今详造义莫过三种，由彼所缘亲疏大种唯二类故」，前说"三种"，后说"二类"，下文也只列两类，"三"或为"二"之误。〕

1. 触处中业等所生的本质四大种。这通于身根、身识、同时的意识、第八识的境界；通于异熟、长养、等流；只属于欲界、色界二界所系，或者也通于不系。
2. 法处中定果的大种。这只是定中意识、第八识的境界，或者也通于五识的境界；不是异熟；通于色界、无色界所系以及不系。

（一）配释五处文字

1. 第一处文字，依后一类大种所造，随着能缘的定所在之处所系。这里说的"系"，是摄属的意思，不是系缚的意思；不然的话，无漏就不应当是大种所造。随着所摄属的等至中的大种所造。
2. 第二处文字，意义也与此相同。就是由于殊胜的禅定，先变现大种，然后造色生起，就是随着能缘之定所在之地的大种所造。随着定前面的因，以及从意义上说那大种先生起，实际上是同时的。这种大种通于造三识的境界。也承认定的力量先生起定果和本识等境界的大种，然后造色生起。或者这段文是依第一类大种所造来说的：定先击发触处的大种，然后造色生起。
3. 第三处文字，依第一类大种所造。定也变现大种，亲自生起造色；不过最初变现色境，要依托触处，法处的色才能生起，所以说是本质的大种所造。定所生的大种低劣，不说依定所生的大种而生起。其实本质的大种并不亲自实在能生，亲自能生的是定所生的大种。
4. 第四处文字，意义也与此相同，因为随着所思惟的本质大种所造。
5. 《显扬圣教论》的意思是说：不是实在的触处大种亲自生起，所以说不是大种所造，不是定中的大种。

（二）亲造与疏造

1. 如果第一类大种通于三识的境界，大种都能造后来的定果色，因为相依而有，成就造的意义，这是疏远的造，不是亲近的造。
2. 如果第二类大种所造通于三识的境界，都能作为所依，生起造色，这是亲近的造，不是疏远的造。

如果依第一类大种所造：或者以下地的大种能造上地的色，或者以有漏能造无漏，或者以自处能造他处。

如果依第二类大种所造：只是自类所造，不是他类能造；只以有漏能造有漏，只以无漏能造无漏，只以自处还造自处，都只是自类，一切都不是他类。

即使有诸处说互造的不同，依道理寻求文义，没有超出这两类。

三、另一种说法：应立三类

有一种说法认为，大种所造总共应当立三类，因为也有不依本质、定果而能成就造的。

前面第一处文字说"随着所系的定，大种所造"，这是依所依处的大种所造。比如依这个地方进入那个定的时候，不依杖本质，先前定中的期心不变现大种，那所造的色难道没有大种所造？就是随着所依的床座等物，或者所依身的大种所造。所以应当另外立第三类：依处。没有加行，以道理来摄，就是触处的大种，属于两类大种中第一类大种所摄。

神通的势力，如《瑜伽师地论》第六十二卷所说。修习的方便，最初在什么身中生起，异界相缘，像这样的意义，如《成唯识论疏》别章等所说。

（《胜定果色章》终）
