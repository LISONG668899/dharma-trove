<div class="dt-subtitle">大乘法苑义林章白话译注（十二）<br>唐　窥基　撰</div>

〔译注：本篇译《诸藏章》第二至第五门：名数增减、辨废立、出体性、释名义。重点是二藏、三藏乃至八藏的各家说法，世亲菩萨说三藏不增不减的十种理由，以及菩萨、声闻、独觉、素呾缆、毗奈耶、阿毗达磨诸名的解释。〕

第二门　名数增减

一、二藏

经量部的论师只立两藏：

1. 素呾缆藏（经藏）
2. 毗奈耶藏（律藏）

经量部的论师说：经、律两藏有各自的部类，佛和弟子都没有另外的部类宣说对法藏，只是诸经中诠释智慧的地方，称为对法；弟子们所造的论，只是解释经的注疏，不属于藏所摄。如《顺正理论》第一卷所说。

大乘中也依照根机和修行来说教门，分为两藏：

1. 菩萨藏
2. 声闻藏

《瑜伽师地论》第二十五、三十八、八十一、八十五卷，《大乘阿毗达磨杂集论》第十一卷，《显扬圣教论》第六卷和第二十卷，世亲菩萨《摄大乘论释》第一卷中，都广泛地自行建立两藏。因为独觉的教、理、行、果少于声闻的教，所以从多数立藏，只称为声闻藏。这就是依照半字教、满字教分为两藏。所以独觉只证生空，只断人执，摄入声闻。并且独觉最初发心，也依靠佛的声教，因为从声教而入，所以也称为声闻，如《法华经》《涅槃经》等所说。

二、三藏

大乘以及萨婆多等诸部，同说有三藏：

1. 素呾缆藏
2. 毗奈耶藏
3. 阿毗达磨藏

萨婆多部的义理，如《大毗婆沙论》所说；大乘的教证，如前面所引。

《普曜经》以及《阿阇世王经》，也说有另一种三藏：

1. 菩萨藏
2. 独觉藏
3. 声闻藏

因为根机不同，教法也有差异。前面因为独觉与声闻的修行等大多没有差异，所以摄入声闻藏；现在依据根机、果位、修行有少许差别，所以另外开出独觉藏。

三、四藏

有的说四藏，如《僧祇律》《分别功德经》，与大众部相同，在素呾缆等三藏之外，另立杂藏：

1. 只诠释定的，称为素呾缆。
2. 只诠释戒的，称为毗奈耶。
3. 只诠释慧的，称为对法。
4. 合诠两种或合诠三种的，称为杂藏。

《分别功德经》中广泛解释四藏的差别。

《结集三藏传》说四藏：一是经，二是律，三是大法，四是杂藏。

1. 大法：迦旃延造论完毕，拿去呈给佛。佛说："这是上法。"所以名为大法。大法中破除愚痴，有益于世间，这部论使众经明了，所以名为大法。传中另外还有两种"复次"的解释，不能一一繁引。
2. 杂藏：佛说宿世因缘，阿罗汉也说，天、魔、外道也说，所以名为杂藏。杂藏中多有偈颂，问十二因缘，这些各不相同的内容汇入一处，称为杂藏。

现在观察这部传，有两种解释：

1. 第一种解释的用意：只有佛世尊自己说宿世因缘的，称为素呾缆；阿罗汉也说的，称为杂藏。
2. 第二种解释的用意：只诠释定的，称为素呾缆；兼诠释慧等的，称为杂藏。因为"问十二缘""各不相同的内容汇入"，诠释的是慧。

前面《分别功德经》的那种解释，相当于这部传的第二种解释。

犊子部中也说四藏：一是经，二是律，三是对法，四是明咒。明咒藏中汇集各种咒语。犊子部所说的三世、无为、不可说等五种法藏，是所诠的法，不是这里能诠的教藏。

四、五藏

1. 法藏部中说有五藏：在上面的经、律、对法、明咒四藏之外，加上菩萨藏，阐明诸菩萨本来所行的事迹。
2. 《成实论》中说有五藏：说了三藏以后，又说杂藏和菩萨藏。

五、六藏

大乘中也说六藏。《瑜伽师地论》《显扬圣教论》《大乘阿毗达磨杂集论》，以及天亲菩萨的《摄大乘论释》说：菩萨、声闻各有三藏。《法华经》说："不得亲近小乘三藏。"所以可知大乘也有三藏，因此分为六藏。

独觉的教法少，又没有另外的戒律等，所以没有三藏，不能分成九藏。

六、七藏、八藏、九藏

1. 七藏：义理上可以有七藏，小乘说四藏，大乘说三藏，所以义理上成为七藏。不过没有另外的经文。
2. 八藏：《胎藏经》以及大众部又说八藏，因为菩萨、声闻各有四藏。
3. 九藏：或者可以说九藏。《普曜经》等既然说有菩萨、独觉、声闻三藏，每一藏各成三藏，所以义理上可以立九藏。

七、八万四千法藏

或者说为八万四千法藏。

像这样的增减，简略地有七种不同，就是二藏、三藏、四藏、五藏、六藏、七藏、八藏。如果另外说，有八万四千法藏；依此广说，有八俱胝四十洛叉，如《宗轮论疏》中详细分别。

以上总的是第二门，名数增减。

第三门　辨明废立

小乘的不同说法，不是本宗所要阐明的。大乘中只立二藏、两种三藏、六藏以及八万四千法藏等。

一、为什么只立二藏

天亲菩萨《摄大乘论释》说："这样的三藏，因为下乘、上乘有差别，所以分成两藏。"

这段话的意思是：只因为独觉的教、理、行、果少于声闻，摄入下乘之中，合称为声闻藏。又如佛十力中的根上下智力：根器本来也有中等，上下相比较，只分两品，或上或下，不说中等。现在以上下一往相比较，独觉的教摄入声闻藏。独觉的根器低劣，业力浅薄，所断、所修、所证、所利益的，都不能遍及穷尽，不广大，所以只说两藏。

二、为什么立菩萨、独觉、声闻三藏

《普曜经》等立菩萨、独觉、声闻三藏，是因为随着根机不同，乘和修行有差别，所以立三藏，不增也不减。

三、为什么立经、律、论三藏，不增不减

立素呾缆等三藏，不增也不减，天亲菩萨有四种解释，前三个"复次"与《大乘阿毗达磨杂集论》相同。下面依次列出十条理由：

第一条，一切过失简略有三种：

1. 疑惑
2. 二边行
3. 自见取

第一种是不肯修行；第二种是修行颠倒；第三种是理解不真实。为了对治这三种过失，依次说有三藏：

1. 经中为众生决定宣说义理，让众生趣入。
2. 律中开许一百零一种资具，让众生行于中道。
3. 论中显照诸法的体相，让众生生起真实智慧。

这就是未入、已入、作证三个阶段的依据。

第二条，又就最初所断的诸惑业来说。疑惑、二边行、自见取这三种都是见道所断，二边行的因就是戒禁取。

第三条，又依照障碍入道的诸惑业来说。一切烦恼只有两类：

1. 犹豫一类，以疑为首。
2. 决定一类，以见取为首。

举出这两种，摄尽一切烦恼。众生求入道，修行种种妙行，由于执着苦、乐二边，不能正确证得：在家人一类，执着受用欲乐一边；诸外道一类，执着自苦苦行一边。为了除去现在的这些惑业，所以只说三藏。

第四条，诸学的品类不超过三种，就是戒、定、慧。每一学增上，宗旨所说的三学各不相同，所以只有三藏，不增不减。

第五条，为恶律仪的人、多散乱的人、多烦恼的人，依次立毗奈耶、素呾缆、阿毗达磨三藏。

第六条，为恶业多的人、贪爱多的人、邪见多的人，依次立三藏。

第七条，为嗔多的人、贪多的人、痴多的人，依次立三藏。

第八条，为怖畏恶趣的人、怖畏欲界的人、怖畏三界的人，依次立三藏。

第九条，为了得到三事圆满的大般涅槃：由论藏得般若，由律藏得解脱，由经藏得法身。

〔译注：原文作「由律得解说」，"说"当作"脱"，据大般涅槃三德"法身、般若、解脱"译为"解脱"。〕

第十条，为了得到佛身，所以立三藏：

1. 由律藏得法身，因为法身的体性是解脱。
2. 由论藏得报身，因为报身以智慧为自体。
3. 由经藏得化身，因为依禅定发起神通。

〔存疑：原文作「为得二身故立三藏」，下文实际列出法身、报身、化身三身，"二身"或当作"三身"。〕

由于这样的差别，三藏不增不减。依照这个道理，分为上乘、下乘，成为六藏，没有另外的意义。八万四千法藏，随着所对治的八万四千烦恼，不增不减；依此再展开，成为八百万亿诸法藏，如《大乘阿毗达磨杂集论》第十一卷所说。

四、佛随宜所说，不可执定

佛随顺根机所说的藏数并不固定：

1. 依照舍邪归正的法门，只说一藏，就是正法教藏。
2. 对所诠的义藏法门，只说一藏，就是字藏。
3. 或者说二藏，乃至八万四千藏。

如《涅槃经》中，佛只说一种因缘，就是一切有为法；或者乃至说十二因缘，因为众生适合听闻。藏的说法也是这样，所立的数目随顺时宜，不可以用来互相诘难。

以上是第三门，辨明废立。

第四门　出体性

三藏的体性，意义类别没有不同，在《总料简章》中已经显示四重出体。暂且依照护法论师的四种出体中"相用别论"一重来说：总的以能说法者心上所显现的声、名、句、文作为体性，其中有假有实，途径不同。随其所应，属于三性、五法、蕴、处、界所摄，所引的教理，详如前面所说。

第五门　解释名义

分为两部分：先解释总名，后解释别名。

一、解释总名"藏"

天亲菩萨的论中说：「何缘名藏？由能摄故。谓摄一切所应知义。」（大意：凭什么称为"藏"？因为能摄持，摄持一切所应知的义理。）这段话的意思是：能诠的教法，能摄持一切所应知的义理，使义理不失，所以立"藏"这个名称。

又有一种解释说：摄持义就是藏义。所应知的法都由藏所摄；藏持守所摄的法，使法不失，称为藏。

藏的分别不同，有二藏、三藏等。二、三、六等是数目，在六合释中属于带数释。

古德解释说："藏"是记录的意思，圣者的言教能刊记诸法，称为藏。

二、解释别名

（一）二藏的别名

二藏中，一是菩萨藏，二是声闻藏。

一、菩萨。梵语应当称为"菩提萨埵"，这个词省略了，只称为"菩萨"。

1. 无性菩萨解释说："以菩提和萨埵作为所缘境，所以称为菩萨。依弘誓的语言，立'菩萨'这个称呼。"这段话的意思是：有些修行人发起大誓愿，求大菩提，度化有情，以菩提和有情这两者作为所缘境，立"菩萨"这个名称。这是有财释，因为以菩提、有情两者作为所缘境，所以称为菩萨。或者是相违释：既是菩，也是萨，因为智慧和悲心各不相同。
2. 无性菩萨又说："或者菩萨的心为了求菩提，有志向、有能力，所以称为菩萨。"这段话的意思是：菩提是所求的果；萨埵是勇健的意思。修行者的心为了求无上正等觉，有大志向，有所堪能，具足这种殊胜功德，称为菩萨。这是依主释，因为是"求大菩提的萨埵"。
3. 或者"萨埵"汉语叫"有情"，菩萨就是"求大菩提的有情"。依士释，如前面所说。

《瑜伽师地论》的解释，文字稍有差别，意义也与此相同。《十一面经》说："菩提就是般若，萨埵是指方便。这两种法利益安乐一切有情。"菩萨是"菩提的萨埵"，也是依主释。

二、声闻。"声"是音声，就是佛说法的所有音声；"闻"是听闻。如果修行者听闻佛说法，信受精进而出离三界，称为声闻。

1. 所以《法华经》第二卷开头说：「若有众生，内有智性，从佛世尊闻法信受，殷勤精进，欲速出三界，自求涅槃，是名声闻乘。」（大意：如果有众生内心有智慧的本性，从佛世尊听闻佛法，信受奉行，殷勤精进，想要迅速出离三界，自己求取涅槃，这称为声闻乘。）这是依照最初进入声闻乘的阶段说的，因为声闻大多依靠声教入道；后来证果的时候，不一定都要依靠声教。
2. 《瑜伽师地论》解释说：诸佛的圣教以声为上首，声闻从师友那里听闻这个教声，辗转修证，永远出离世间，所以称为声闻。以声为所闻，也是有财释。
3. 这只是依照住于自乘的理解，只以自利行来立名。如果是不定种性的声闻，道理就不是这样。所以《法华经》第二卷末尾说："以佛道声，令一切闻，故名声闻。"这是依照回心住于佛乘的利他行来说的。以佛道之声让他人听闻，所以称为声闻，就是有财释。如果是"声的闻"，所以称为声闻，就是依主释。

独觉最初进入自乘的阶段，大多也依靠佛的音声；并且独觉的教法少，从多数立藏；独觉所修证、所断、所得的，都不广大，所以合称为声闻。

随其所应，引导菩萨、声闻这两种根机；这两种根机所知的所有法义，都由藏所摄，就称为菩萨藏、声闻藏。两藏都是依士释。

（二）三藏的别名

一、《普曜经》中所说三藏，菩萨、声闻两个名称如前面所说。

二、独觉藏。

1. 《法华经》说：「若有众生，从佛世尊闻法信受，殷勤精进，求自然慧，乐独善寂，深知诸法因缘，是名辟支佛乘。」（大意：如果有众生从佛世尊听闻佛法，信受奉行，殷勤精进，求取自然的智慧，喜好独处、善于寂静，深知诸法的因缘，这称为辟支佛乘。）
2. 《瑜伽师地论》说：常乐寂静，不想与人杂居，修加行圆满，没有师友的教导，自然独自觉悟，永远出离世间，所以称为独觉。"独自证悟的觉者"，称为独觉，是依主释。
3. 或者观待因缘而悟入圣果，也称为缘觉。"待缘而觉"，也是依主释。

"独觉的藏"，是依主释，如前面所说。

（三）素呾缆等三藏的别名

一、素呾缆。

1. 《成实论》说："修多罗，就是直接说出的语言。"
2. 《杂阿毗昙心论》说：经有五种意义，就是出生、涌泉、显示、绳墨、结鬘。
3. 现在依大乘解释。梵语"素呾缆"，汉语称为"契经"。所以《瑜伽师地论》第二十五卷以及《显扬圣教论》第六卷说："什么是素呾缆？以二十四事简略地摄尽一切契经。""契"是契当、至合的意思。

"经"的意思，天亲菩萨的论中解释说：「谓能贯穿依故、相故、法故、义故，名素呾缆。」（大意：能贯穿所依、体相、诸法、义理，所以称为素呾缆。）

1. 依：在某处、由某人、为某人而有所说，称为"依"。
2. 相：真谛和俗谛的体相，称为"相"。
3. 法：十种善巧法等，称为"法"。
4. 义：随着密意等宣说诸法，称为"义"。

这是以四种意义解释素呾缆。

《瑜伽师地论》第二十五卷、《显扬圣教论》第二十卷说：佛世尊在某处，为某些有情，依照所化众生诸行的差别，宣说无量与蕴相应的言语，乃至广说。结集法藏的人，摄聚圣者的言语，为了让佛法久住，以美妙的言辞依次结集，贯穿缝缀，能引生义理和利益，能行梵行，具有真实、善良、美妙的义理，称为契经。

前面以贯穿的意义解释契经，进一步说：以教法贯穿义理，以教法摄持众生，称为"经"。就像用线串花，又像经线持住纬线。西域把汲水的绳索、缝衣的线、席子的经线、圣教等，都称为素呾缆。众生由教法所摄，不会散流堕入恶趣；义理由教法所贯，不会散失隐没。所以圣教称为契经。

《四分律》说：比如种种花散放在案上，风一吹就零落，因为没有线串起来。十二年以前，堪受略教的众生根性，就像那张桌案；种种出家、在家人的异见，使正法迅速灭亡，就像风；一切经义，称为花。如果有经教贯穿正理，人们就没有异见，佛法就不会灭亡。

所以《佛地经论》第一卷说："能贯穿、能摄持，所以称为经。"以佛的圣教贯穿摄持所应说的义理和所化的众生，称之为经。"契合真理的经"，称为契经，是依主释。如果只称"经"，就不是这种解释。素呾缆的体性就是藏，称为素呾缆藏，是持业释，因为经和藏都属于教法。

二、毗奈耶。汉语称为"调伏"。

1. 《瑜伽师地论》第八十五卷说：有四种有情，数数串习邪解、邪见所集成的界性。佛以种种胜解智力以及种种界智力，寻求这些有情先前所有的胜解以及后来的界性，随其所应，为了调伏这些有情，大多为这些有情转四种法教，称为毗奈耶。所以毗奈耶称为调伏。
2. 天亲菩萨解释说：因为犯罪、等起、还净、出离，所以称为毗奈耶。详细的解说如《摄大乘论释》第一卷。

"调"是调和驾御，"伏"是制伏灭除。调和控御身、语等业，制伏灭除各种恶行，所以既是调，也是伏，是持业释。这是修行的名称。"调伏的藏"，称为毗奈耶藏，因为藏是教法，也是依主释。

三、阿毗达磨。"达磨"是法，"阿毗"有四种意义，汉语称为"对法"，也称为数法、伏法、通法。

1. 对法。天亲菩萨解释说："对"的意思是：这个法对向无住涅槃，因为能宣说诸谛、菩提分法等各种妙行。依照这种解释，"能对向"称为"对"，体性就是教法，能宣说妙行，趣向涅槃。"对"就是法，称为"对法"；对法就是藏，称为"对法藏"，都是持业释。
2. 数法。对每一种法，反复宣说，训释言词、自相等。这是以理为法，以教为数，"法的数"，所以称为数法，是依主释。数法就是藏，称为数法藏，是持业释。
3. 伏法。由于对法具足论处所等，能降伏殊胜的他人邪异之论。"伏"的本体是理，诠释降伏的法，称为伏法，是依主释。或者教法就是伏，因为这个教法具足论处所等，能降伏他人的邪异之论，就是持业释。伏法就是藏，也是持业释。
4. 通法。对法能解释疏通契经的义理。经义称为法，对法能疏通经义，称为通法。"法的通"，是依主释。通法就是藏，也是持业释。

另外还有其他解释，如《对法疏》所说：

1. 《分别功德经》有两种解释：一是称为"无比法"，二是称为"大法"。《结集三藏传》中也称为"大法"。
2. 无性菩萨解释说：因为是择法的因，或者因为是共同了知。
3. 《杂阿毗昙心论》有两种解释。
4. 《大毗婆沙论》第一卷，十二位大论师有二十四种"复次"的解释。
5. 《顺正理论》说：或者诸契经称为达磨，论能决断了知契经，称为对法，这是以教对教。
6. 《俱舍论》有两种解释。
7. 或者教、理、行、果都称为对法，随其所应解释名义。

合起来有四十一种解释，如《对法疏》中的解释，不能一一繁述。

四、邬波题铄与摩怛理迦。论藏也称为"邬波题铄"，就是古译的"优婆提舍"，汉语称为"论议"；也称为"摩怛理迦"，就是旧译所说的"摩德勒伽藏"，汉语称为"本母"。

《瑜伽师地论》第八十一卷等说：这个邬波题铄，也称为摩怛理迦，也称为阿毗达磨。

《瑜伽师地论》第八十五卷说：为了抉择如来所说、所称、所赞、所美的先圣契经。比如没有字母，字义就不明了；同样，不被本母所摄的契经，义理隐晦，不明了；与此相反，义理就明了。所以称为摩怛理迦。

摩怛理迦属于义理，藏是教法，"本母的藏"，也是依主释。如果这个论教作为契经义理的母，称为本母，本母就是藏，就是持业释。

（四）六藏

六藏的名义，与二藏、三藏没有不同，所以不另外解释。

以上所解释的，暂且随顺一种意义。诸位有智慧的人，可以随意取舍。

以上合起来是第五门，解释名义。
