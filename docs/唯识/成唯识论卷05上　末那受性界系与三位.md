<p class="dt-title">末那受性界系与三位</p>

<div class="dt-subtitle">成唯识论白话译注（十三）　卷第五之上<br>护法等菩萨造　唐　玄奘译</div>

本篇要目：一、末那识与哪种受相应　二、末那识的性质：有覆无记　三、末那识系属哪一地　四、三位无有：永断与暂伏　五、有无清净的末那识　六、末那识的三种差别　七、我执必依法执而起　八、教证：心、意、识三义

一、末那识与哪种受相应

外人质问：染污的末那识与哪种受相应？论中列出三家。

第一家认为：末那识只与喜受相应，因为末那识恒常在内执着自我，生起喜爱。

第二家破斥：第一家的说法不对。照此说法，就应承认喜受一直存在到有顶天，喜受到有顶，违背了圣教。

【译注】有顶天即无色界最高的非想非非想处天。圣教说喜受只到色界第二禅，第三禅以上没有喜受。末那识遍于三界九地，如果只与喜受相应，就与圣教相违。

第二家立义：末那识与四种受相应。生在恶趣，与忧受相应，因为末那识缘取不善业所引的果报。生在人间、欲界天、初禅和二禅，与喜受相应，因为末那识缘取有喜之地的善业果报。生在第三禅，与乐受相应，因为末那识缘取有乐之地的善业果报。生在第四禅乃至有顶，与舍受相应，因为末那识缘取只有舍受之地的善业果报。

第三家，即护法论师，认为：第二家的说法也不合道理。

末那识从无始以来，任运地、同一类别地缘取内境，执着自我，恒常没有转易，所以不与变化不定的苦、乐、忧、喜相应。

颂中凡是末那识与前面藏识意义不同的地方，都另外说明。如果末那识与四种受相应，颂中也应另外说明。颂中既然没有另外说明，末那识的受决定与藏识相同。

所以末那识相应的只有舍受。

在未转依的阶位，末那识与前面所说的心所相应。在已转依的阶位，末那识只与二十一种心所俱起，即遍行五、别境五、善十一，如同第八识已转依的阶位，只与舍受俱起，因为任运而转，恒常对所缘平等运转。

二、末那识的性质：有覆无记

外人质问：末那识的心所属于什么性质？论主回答：属于有覆无记，不属于其余三性。

末那识相应的四种烦恼等是染污法，障碍圣道，隐蔽自心，所以称为“有覆”；不是善也不是不善，所以称为“无记”。

如同色界、无色界的一切烦恼等，被禅定的力量摄持，属于无记；末那识相应的染污法，所依的末那识微细，又任运而转，所以也属于无记。

【译注】一般烦恼会推动身语造作恶业，所以是不善。末那识的我执只在内心深处默默运转，从不发动身语去造善恶业，所以末那识是染污，又只算无记。

如果已经转依，末那识只是善性。

三、末那识系属哪一地

外人质问：末那识的心所系属哪一地？论主回答：生在哪一地，就系属哪一地。

生在欲界，现行的末那识及相应的心所就系属欲界；乃至生在有顶天，也同样如此。因为末那识任运地恒常缘取自己所在之地的藏识，执为内在的我，不缘取其他地的藏识。

如果某一地的异熟藏识现前，就称为生在该地。染污的末那识缘取该地的藏识，执为自我，就系属该地，称为“该地所系”。或者，末那识被该地的诸烦恼等所系缚，所以称为“该地所系”。

如果已经转依，末那识就不再被系缚。

四、三位无有：永断与暂伏

外人质问：染污的末那识从无始以来相续不断，到什么阶位永远断除，或者暂时断除？论主回答：颂中说“阿罗汉、灭定、出世道无有”。

“阿罗汉”总括三乘无学果位。在无学果位，染污末那的种子和现行都永远断灭，所以说“无有”。

在有学位，于灭尽定和出世道中，染污末那都暂时被伏灭，所以说“无有”。

染污的末那识从无始以来，微细地、同一类别地任运而转，一切有漏道都不能伏灭。三乘的圣道有伏灭末那的作用，因为真实的无我智慧与我执相违。后得的无漏智现前时，是真无我智的等流，也与染污末那相违。真无我智与后得智都是无漏，所以称为出世道。灭尽定是圣道的等流，极其寂静，所以灭尽定中染污末那也不存在。

由于还没有永远断除染污末那的种子，从灭尽定或圣道出来之后，染污末那又再现行，直到种子灭尽为止。

染污末那相应的烦恼是俱生的，所以不属于见道所断；是染污的，所以不属于“非所断”。染污末那相应烦恼的种子极其微细，与有顶地最下下品的烦恼同时一下子断除，因为两者势力相等。金刚喻定现前时，一下子断除染污末那的种子，成为阿罗汉，所以在无学位，染污末那永不再生起。

二乘无学回心趣向大乘，从初发心直到成佛之前，实际上是菩萨，也称为阿罗汉，因为在断除染污末那的意义上相同，所以颂中不另外说明。

五、有无清净的末那识

关于染污末那之外，是否还有清净的末那，论中列出两家。

第一家认为：末那识只与烦恼障俱起。理由有三：圣教都说三位没有末那；圣教又说末那与四种烦恼恒常相应；圣教又说末那是诸识杂染的所依。

第二家，即护法论师，破斥：第一家的说法与圣教和道理都相违。

契经说有出世的末那。没有染污的意识，如同有染污时，决定有俱生的、不共的所依。

论中说：藏识决定恒常与一个识同时运转，就是末那。意识生起时，藏识就与两个识同时运转，就是意识和末那。五识中任何一识生起，藏识就与三个识同时运转。乃至有时五识同时生起，藏识就与七个识同时运转。如果住灭尽定时没有第七识，那时藏识就应没有任何识同时运转，就不是“恒常决定与一识同时运转”。住圣道时如果没有第七识，那时藏识就应只与一个识同时运转，怎能说“意识生起时，藏识决定与两个识同时运转”？

《显扬圣教论》说：末那恒常与四种烦恼相应；或者转而与相反的心所相应，以自恃高举为行相；或者以平等为行相。由此可知，末那识通于染污和不染污。

如果因为论中说阿罗汉位没有染污的末那，就说没有第七识，那么也应因为论中说阿罗汉位舍弃阿赖耶，就说没有第八识。第八识既然仍在，第七识又怎能没有？

诸论都说：转第七识得平等性智。平等性智如同其余诸智，决定有所依的相应清净识。如果没有清净的第七识，平等性智就应不存在，因为离开所依，就没有能依。不能说平等性智依于前六转识，因为承认佛的平等性智如同大圆镜智，恒常运转。

无学位如果没有第七识，第八识就应没有俱有依。第八识必定有俱有依，如同其余诸识。

如同尚未证得人无我的人，我执恒常运转；尚未证得法无我的人，法执也应恒常运转。如果没有第七识，恒常运转的法执依于什么识？不能依于第八识，因为第八识没有慧心所。

由此应当相信：在二乘圣道、灭尽定和无学位中，第七识恒常运转，因为二乘还没有证得法无我。

诸论中以五种同法，证明有第七识作为第六识的所依。圣道生起时和无学位中，如果没有第七识作为第六识的所依，所立的宗和因就都有过失；或者五识也应有没有所依的时候。五识恒常有所依，第六识也应如此。

【译注】“五种同法”是把第六识与前五识相比的论证：前五识各有不共的、同时的根作为所依，第六识同属六识，也应有不共的、同时的所依，第六识的所依就是第七识。所以第七识不能有中断的时候。

所以决定有不染污的末那识，在阿罗汉、灭定、出世道三位中，恒常现起。颂中说三位“无有”，是依染污的末那而说，如同说四位没有阿赖耶，并不是没有第八识。三位没有末那，也是同样的道理。

六、末那识的三种差别

末那识的差别，大略有三种：第一种与补特伽罗我见相应，第二种与法我见相应，第三种与平等性智相应。

第一种，通于一切凡夫的相续、二乘有学、七地以前一类菩萨的有漏心位。在第一种阶位，末那识缘取阿赖耶识，生起补特伽罗我见，即人我见。

第二种，通于一切凡夫、声闻、独觉的相续，以及一切菩萨法空智和法空智之果不现前的阶位。在第二种阶位，末那识缘取异熟识，生起法我见。

第三种，通于一切如来的相续，以及菩萨在见道和修道中法空智和法空智之果现前的阶位。在第三种阶位，末那识缘取无垢识、异熟识等，生起平等性智。

【译注】三种末那，对应三个层次：执人为我，执法为实，证一切平等。凡夫两种执着都有；二乘断了人我执，法我执还在；菩萨证法空时，末那识转为平等性智。

七、我执必依法执而起

补特伽罗我见生起时，法我见也必定现前，因为我执必定依法执而生起。

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">如夜迷杌等，方谓人等。</div>

大意：如同夜里先把树桩看错，才会把树桩认作人。

【译注】先把树桩当作一个实在的东西，是法执；再把实在的东西认作人，是我执。没有法执作底，我执无从立足。所以法执比我执更深，断得也更晚。

我见与法见作用有别，并不互相违背，同依于一个慧心所。如同眼识等，体只有一个，具有了别青、黄等多种作用，并不互相违背。我见与法见也是如此。

二乘有学在圣道或灭尽定现前时，顿悟菩萨在修道位，有学的渐悟菩萨在生空智和生空智之果现前时，都只生起法执，因为我执已被伏住。

二乘无学，以及渐悟菩萨在法空智和法空智之果不现前时，也只生起法执，因为我执已经断除。

八地以上一切菩萨，所有我执都永不现行，或者已经永断，或者已经永伏。在法空智和法空智之果不现前时，仍生起法执，因为法执与我执不现行并不相违。如契经说：八地以上一切烦恼不再现行，只有所依的所知障还在。经中所说的所知障是现行，不是种子；否则烦恼的种子也应还在，经中就不应说烦恼不在。

与法执俱起的末那识，对二乘等称为不染污，对诸菩萨也称为染污，因为法执障碍菩萨的智慧。由此，与法执俱起的末那识也称为有覆无记；对二乘等称为无覆，因为法执不障碍二乘的智慧。

与法执俱起的末那识属于异熟生，因为从异熟识恒时生起，所以称为异熟生，不是异熟果。“异熟生”的名称通用较宽，如同增上缘，其余各类所不摄的，都归入异熟生。

【译注】无覆无记分为四类：异熟生、威仪、工巧、变化。法执末那不属于后三类，所以归入范围最宽的异熟生。

八、教证：心、意、识三义

外人质问：怎么知道第七识离开眼等识另有自体？论主回答：以圣教和正理作为决定的标准。

先说圣教。世尊在许多经中，说心、意、识三种不同的含义：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">集起名心，思量名意，了别名识。</div>

大意：积集种子、生起诸法，称为心；恒审思量，称为意；了别境界，称为识。

心、意、识三种含义通于八识，依最殊胜的作用来显示：第八识称为心，因为第八识积集诸法的种子，生起诸法；第七识称为意，因为第七识缘取藏识等，恒常审察思量，执为自我等；其余六识称为识，因为六识对六种各别的境界，粗动地、有间断地了别运转。如《入楞伽经》的偈颂说：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">藏识说名心　思量性名意<br>能了诸境相　是说名为识</div>

大意：藏识称为心，以思量为性的称为意，能了别诸境之相的称为识。

大乘经中处处另外说有第七识，所以第七识另有自体。诸大乘经是至教量，前面已经广说，所以不再重复论证。

《解脱经》中也另外说有第七识，如经中偈颂说：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">染污意恒时　诸惑俱生灭<br>若解脱诸惑　非曾非当有</div>

大意：染污的意恒时与诸烦恼同生同灭；如果解脱了诸烦恼，染污的意既不曾有，也不会再有。

《解脱经》自己解释偈颂的意思：有染污的意，从无始以来，与四种烦恼恒常同生同灭，即我见、我爱、我慢、我痴。对治道生起，断除烦恼之后，意就从烦恼中得到解脱。那时，意相应的烦恼不只是现在没有，过去和未来也没有，因为过去和未来没有自性。

【译注】“非曾非当有”说破了唯识的断惑观：烦恼断了，不是从现在被推到过去去，因为过去本无自性。断惑就是断得干干净净，过去未来一并空了。

诸如此类的圣教，各部派都有，恐怕读者厌烦繁文，所以不详述。

以上卷第五之上译毕。
