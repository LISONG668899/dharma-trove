一、声闻乘中的异门密意

声闻乘中，也以异门密意说过阿赖耶识。如《增壹阿笈摩》说：世间众生爱阿赖耶，乐阿赖耶，欣阿赖耶，喜阿赖耶；为了断除阿赖耶，佛宣说正法时，众生恭敬摄耳而听，安住于求解之心，依法与随法而行；如来出世，如此奇特希有的正法出现于世间。在声闻乘的《如来出现四德经》中，以上面所说的异门密意，已经显示了阿赖耶识。

大众部的阿笈摩中，也以异门密意，称阿赖耶识为根本识，如同树依于根。化地部中，也以异门密意，称阿赖耶识为穷生死蕴：有些处所、有些时候，可以见到色与心中断，阿赖耶识中色与心的种子并没有中断。

【世亲释】“有些处所”，是无色界，无色界中没有色。“有些时候”，是无想定等定位，定位中没有心。阿赖耶识中有色与心的熏习，以此为因，色与心又再生起。

【无性释】化地部立三种蕴：一念顷蕴，是一刹那中有生灭的法；一期生蕴，是直到死亡都恒常随转的法；穷生死蕴，是直到证得金刚喻定都恒常随转的法。穷生死蕴除了阿赖耶识，不能是别的法。

所以，所知依以阿赖耶识为性，以阿陀那识为性，以心为性，以阿赖耶为性，以根本识为性，以穷生死蕴为性等等。由上面所说的种种异门，阿赖耶识成为大王路。

【世亲释】“成为大王路”，是极其广阔的意思。

【译注】大王路，是国王所行的大道。各部圣教都以异门说到阿赖耶识，所以阿赖耶识如同人人共行的大道，宽广通达。

二、破斥异说，安立阿赖耶名最为殊胜

有一类人主张：心、意、识三者意义相同，只是文字不同。心意识义一文异的主张不能成立。意和识两者的意义差别可以得知，应当了知心的意义也有差别。

又有一类人，对薄伽梵所说的“众生爱阿赖耶”等语，主张五取蕴称为阿赖耶。另有人主张与贪俱起的乐受称为阿赖耶。另有人主张萨迦耶见称为阿赖耶。上述论师由于教的缘故和证的缘故，对阿赖耶识愚昧，所以作此执着。以五取蕴等安立阿赖耶的名称，即使依照声闻乘自己安立的道理，也不相应。不愚昧的人，取阿赖耶识来安立声闻乘所说的阿赖耶名称，才最为殊胜。

为什么最殊胜？如果五取蕴称为阿赖耶，生在恶趣中一向受苦的处所，五取蕴最为可厌，众生一向不起爱乐，说众生在五取蕴中执藏，不合道理，因为众生常求赶快舍离苦蕴。如果与贪俱起的乐受称为阿赖耶，第四静虑以上没有与贪俱起的乐受，具有第四静虑以上身的有情，对与贪俱起的乐受常有厌离，说有情在乐受中执藏，也不合道理。如果萨迦耶见称为阿赖耶，在正法中信解无我的人，对萨迦耶见恒常厌离，说信解无我的人在萨迦耶见中执藏，也不合道理。

阿赖耶识摄为内在的自我。生在恶趣一向受苦的处所，众生求离苦蕴，对阿赖耶识的我爱仍然恒常系缚，从来不求舍离。生在第四静虑以上，有情对与贪俱起的乐受常有厌离，对阿赖耶识的我爱仍然恒常系缚。在正法中信解无我的人，厌离我见，对藏识的我爱仍然恒常系缚。所以，把阿赖耶识安立为阿赖耶，最为殊胜。

三、阿赖耶识的三相

上面已经说明了阿赖耶识的种种异门。阿赖耶识的相应当如何看待？阿赖耶识的相，简略说有三种：第一，安立自相；第二，安立因相；第三，安立果相。

安立阿赖耶识的自相：依于一切杂染品法所有的熏习，阿赖耶识能作为杂染品法生起的因，因为阿赖耶识能摄持种子。

安立阿赖耶识的因相：上面所说的一切种子阿赖耶识，在一切时中，对杂染品类诸法现前作为因。

安立阿赖耶识的果相：依于杂染品法从无始时来所有的熏习，阿赖耶识相续而生。

【世亲释】三相的差别是：自相，是依一切杂染品法无始以来的熏习，摄持种子作为杂染法生因的识自体，兼由因性和果性两方面建立。因相，是杂染品类诸法熏习所成的功能差别作为生因，只由因性建立。果相，是依杂染品类诸法无始以来的熏习，阿赖耶识相续而生，只由果性建立。

四、熏习

又，什么称为熏习？“熏习”一词是能诠，所诠是什么？依于能熏之法俱生俱灭，所熏之中有能生起能熏之法的因性，就是“熏习”一词的所诠。比如胡麻中有花的熏习：胡麻与花同生同灭，诸胡麻就带着能生花香的因而生起。又如所说的贪等行者，贪等的熏习依于贪等俱生俱灭，行者的心就带着贪等的生因而生起。又如多闻的人，多闻的熏习依于闻法时的作意俱生俱灭，多闻者的心就带着能忆记的因而生起。由于熏习能够摄持，所以多闻者称为持法者。阿赖耶识中熏习的道理，应当了知也同样如此。

【译注】胡麻，原文作“苣蕂”。

五、种子与阿赖耶识非一非异

又，阿赖耶识中诸杂染品法的种子，是别异而住，还是没有别异？种子并不是另有一种实物住在阿赖耶识中，种子与阿赖耶识也不是不异。阿赖耶识如此而生，具有能生杂染诸法的功能差别，称为一切种子识。

【世亲释】如果种子与阿赖耶识别异，诸种子应当可以一一分开，阿赖耶识刹那生灭的意义也不能成立；又由于善、不善的熏习，种子应当成为善、不善性，阿赖耶识就不是无记。如果种子与阿赖耶识不异，一个阿赖耶识如何能有众多种子？两种说法都有过失，所以说种子与阿赖耶识非一非异。比如大麦种子有生芽的功能，所以有种子性；如果放得太久，或者被火烧过，大麦的样子依旧，功能已坏，就不再是种子。阿赖耶识也是如此，具有能生杂染诸法的功能，所以称为一切种子识。

六、更互为因

又，阿赖耶识与杂染诸法同时更互为因，应当如何理解？比如明灯的焰与炷，焰的生起与炷的燃烧，同时互为因。又如芦束互相依持，同时不倒。应当了知，阿赖耶识与杂染诸法更互为因的道理也同样如此。阿赖耶识是杂染诸法的因，杂染诸法也是阿赖耶识的因。只就上面所说的情况安立因缘，其余的因缘不可得。

又，熏习本身没有差异、没有混杂，如何能作为有差异、有混杂的诸法的因？比如用种种扎染的工具扎结好的布，扎结的时候，布上还没有种种不同的花样；放入染缸以后，布上就显现出种种不同、扎结染色的花纹图像。阿赖耶识也是如此，被种种不同的能熏之法所熏习，熏习的时候，还没有种种不同的差别可得；“果生”的染缸现前以后，就有种种不同、无量品类的诸法显现。

【世亲释】阿赖耶识如同被扎染的布。“果生染器”，就是使果法生起的众缘，如同染缸；“放入染缸”，就是被众缘所摄的意思。熏习的时候没有差异，到果成熟时，就显现非一品类的诸法。

七、二种缘起

上面所说的缘起，在大乘中极其微细，极其甚深。简略来说，有两种缘起：第一是分别自性缘起，第二是分别爱非爱缘起。依止阿赖耶识而诸法生起，称为分别自性缘起，因为阿赖耶识是能分别种种自性的缘。又有十二支缘起，称为分别爱非爱缘起，因为十二支在善趣、恶趣中，是能分别可爱、不可爱的种种自体的缘。

在阿赖耶识上，如果对第一种缘起愚昧，有人就分别执着自性（数论的冥性）是诸法的因，有人分别执着宿作是因，有人分别执着自在天的变化是因，有人分别执着实我是因，有人分别执着无因无缘。如果对第二种缘起愚昧，又有人分别执着“我是作者，我是受者”。

比如众多天生失明的人从未见过大象，有人牵来大象给众盲人看。众盲人有的摸到象鼻，有的摸到象牙，有的摸到象耳，有的摸到象足，有的摸到象尾，有的摸到象脊。有人问：“大象是什么样子？”有的说像犁柄，有的说像杵，有的说像簸箕，有的说像臼，有的说像扫帚，有的说像石山。不了解两种缘起的人，被无明所盲，也是如此：有人执着自性是因，有人执着宿作是因，有人执着自在天是因，有人执着实我是因，有人执着无因无缘，有人执着“我是作者，我是受者”。阿赖耶识的自性、因性、果性等，就如同众盲人所不了知的大象本身。

又，简略来说，阿赖耶识以异熟识和一切种子作为自性，能摄三界的一切自体、一切趣等。

八、种子的六义与熏习的四相

关于种子，有五首颂：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">外内不明了<br>于二唯世俗<br>胜义诸种子<br>当知有六种<br>刹那灭俱有<br>恒随转应知<br>决定待众缘<br>唯能引自果<br>坚无记可熏<br>与能熏相应<br>所熏非异此<br>是为熏习相<br>六识无相应<br>三差别相违<br>二念不俱有<br>类例余成失<br>此外内种子<br>能生引应知<br>枯丧由能引<br>任运后灭故</div>

大意：外种子不明了，内种子对善与不善明了；外种子只是世俗所说的种子，阿赖耶识中的内种子才是胜义的种子。种子有六种条件：刹那灭，俱有，恒随转，决定，待众缘，唯能引自果。所熏要具备四种条件：坚住，无记，可熏，与能熏相应。只有阿赖耶识是所熏，没有别的，就是熏习的相。六识不能与能熏相应，因为六识的所依、所缘、作意三者各不相同，前后两念又不能同时存在，若说同类识可以互熏，类推到其余同类法就成过失。外种子与内种子都有能生和能引两种作用；稻谷枯后仍能延续，尸骸在人死后仍能存在，是由于能引的作用，引的力量自然而然到后来才灭尽。

【世亲释】五颂的要义如下。

外种子是稻谷等，是无记，所以说不明了。内种子是阿赖耶识中的种子，通于善、不善，所以说明了。外种子只依世俗说为种子，因为外种子也是阿赖耶识所变现；阿赖耶识才是一切法真实的种子。

六义：刹那灭，种子生起之后无间即灭，常住之法不能作种子，因为常法一切时都没有变化。俱有，种子不是过去，不是未来，也不与果相离，种子在时，果即在时生起。恒随转，阿赖耶识中的种子一直随转到对治生起；外种子一直随转到根住或果熟。决定，各种种子各自决定，此物的种子还生此物，不是一切生一切。待众缘，种子要等待各自的众缘具足，才能生果。唯能引自果，各种种子只引生各自的果，如阿赖耶识种子引生阿赖耶识，稻谷种子引生稻谷。

熏习四相：坚，所熏要坚住才能受熏，风性流动，不能任持香气；占博迦油能持香气远达百由旬。无记，极臭的蒜不受熏，极香之物也不受熏，不极香、不极臭的才能受熏。可熏，金石之类不能受熏。与能熏相应，所熏与能熏要同时，无间而生。具备四德的只有阿赖耶识，所以所熏就是阿赖耶识，不是转识。

六识不能是所熏：六识有动转；六识的所依、所缘、作意各自不同。譬喻论师主张前念熏于后念，前后两个刹那不能同时存在，不能俱生俱灭。如果说同属识类就可以互熏，类推到其余同类法就成过失：眼根与耳根同属净色，也应当互相熏习，譬喻论师并不承认。

能生与能引：外种子到果熟为止是生因，枯后仍然相续是由于引因；内种子到寿命终了为止是生因，人死后尸骸仍存是由于引因。如果种子只有生因，生因一坏，果就应当立即灭尽，不会有片刻的延续。比如射箭，放弦是生因，弯弓是引因，所以箭离弦后不会立即坠落，能远远射到目标。

【无性释】颂末“任运后灭”，如同灯油和灯炷都烧尽之后，灯焰不待外缘，自然而然渐渐才灭，不是一下子熄灭。由此可知，必定有能引的功力。

九、内种不同于外种

为了显示内种子不同于外种子，又说两首颂：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">外或无熏习<br>非内种应知<br>闻等熏习无<br>果生非道理<br>作不作失得<br>过故成相违<br>外种内为缘<br>由依彼熏习</div>

大意：外种子有的没有熏习，内种子必定由熏习而有。如果没有闻法等熏习，多闻等果生起，不合道理。外种子有种了而失坏、不种而得生的情况，内种子没有已作而失、未作而得的过失，所以内外种子相违。外种子也以内种子为缘，因为外种子依于阿赖耶识中的熏习。

【无性释】外种子不一定由熏习而生，比如炭、牛粪、毛等，能生出与炭、牛粪、毛并未同生同灭的植物；有的外种子则由熏习而成，比如胡麻与花同生同灭而有香气。所以外种子有熏习与否不定。内种子是阿赖耶识中一切法的熏习，决定由熏习而有，因为没有闻法等熏习，就见不到多闻等果。外种子如稻谷，有时种了也会失坏；如稗草，有时没有种也会生出来。内种子不会如此，已作的不会失，未作的不会得，所以内外种子相违。外种子也以内种子为缘，因为稻谷等外种子都是众生共同受用之业的熏习，依阿赖耶识的力量变现出来，离开内种子没有别的外种子。

十、转识是能受用者

又，其余的转识，在一切自体、一切趣中，应当了知称为能受用者。如《中边分别论》中的伽陀所说：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">一则名缘识<br>第二名受者<br>此中能受用<br>分别推心法</div>

大意：第一种识称为缘识，第二种识称为受者。在受者之中，能受用、能分别、能推动的，是心所法。

【无性释】“缘识”是阿赖耶识，“受者”是六转识。“能受用”是受蕴，“分别”是想蕴，“推”是行蕴中的思，思最能推动心转起。受、想、思三者都辅助心受用境界，所以称为心法。

上面所说的阿赖耶识与转识两种识更互为缘。如《阿毗达磨大乘经》中的伽陀所说：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">诸法于识藏<br>识于法亦尔<br>更互为果性<br>亦常为因性</div>

大意：诸法藏在识中，识也藏在诸法中，两者互相为果，也恒常互相为因。

十一、四缘

在第一种缘起中，阿赖耶识与转识两种识互为因缘。在第二种缘起中，是什么缘？是增上缘。六识由几种缘所生？由增上缘、所缘缘、等无间缘所生。上面三种缘起，就是穷生死的缘起、爱非爱趣的缘起、能受用的缘起，共具四缘。

【世亲释】第一种缘起，是阿赖耶识中的习气与诸法互为因缘。第二种缘起，是无明等作为增上缘，由于无明等增上的势力，行等得以生起。六转识称为受用缘起，由三缘所生：比如眼识，以眼根为增上缘，以色为所缘缘，以无间灭去的前识为等无间缘，因为前识如果不让出处所，后识就不能生起。其余诸识也是如此。

【无性释】“共具四缘”，是随各自所应而说，不是每一种缘起都各具四缘。只有心和心所法才具足四缘。
