<div class="dt-subtitle">大乘法苑义林章白话译注（十九）<br>唐　窥基　撰</div>

〔译注：《二谛章》是全书第八章，也是卷二的开篇。窥基在这里提出唯识宗著名的"四重二谛"：世俗谛、胜义谛各有四重，世间、道理、证得、胜义。原文约九千三百字，分三篇。本篇译第一门"显名辨体"和第二门"三乘浅深"。〕

二谛深妙，不是简略的言语所能说尽，这里姑且叙述纲要，用三门来分别：

1. 显示名称，辨明体性
2. 三乘的浅深
3. 相摄与问答

第一门　显示名称，辨明体性

分两部分：一是显示名称，二是辨明体性。

一、显示名称

显示名称中又分两部分：先列名，后解释。

（一）列名

列名中又分两部分：先列总名，后列别名。

一、总名。诸经论立谛的数目不同：

1. 《胜鬘经》中只立一谛，因为究竟真实，不可破坏。
2. 《仁王经》中总说二谛，因为人和法各有胜劣的不同。
3. 《涅槃经》中说二谛，真谛、俗谛各有中智、上智所知。
4. 《显扬圣教论》《辩中边论》中，二谛各有三种，因为假、行、显等有差别。
5. 《瑜伽师地论》《成唯识论》中，二谛各有四种，下面会详细辨明。

在这些总名中：

1. 世俗谛，也称为"隐显谛"。
2. 胜义谛，旧译为"第一义谛"，也称为"真谛"。

二、别名。现在说明二谛，有无的体性不同，事和理的意义不同，浅和深不同，能诠和所诠的旨趣不同，所以二谛各有四重。也称为名事二谛、事理二谛、浅深二谛、诠旨二谛。

世俗谛的四种名称：

1. 世间世俗谛，也称为"有名无实谛"。
2. 道理世俗谛，也称为"随事差别谛"。
3. 证得世俗谛，也称为"方便安立谛"。
4. 胜义世俗谛，也称为"假名非安立谛"。

问：《显扬圣教论》说四种俗谛都是安立。前三种可以理解，为什么第四种也称为安立？

答：胜义谛的体性是自己内心所证。为了随顺引生证胜义的智慧，依世俗安立，称为胜义世俗。前三种世俗，有相状可以比拟；第四种是胜义的假名施设。

胜义谛的四种名称：

1. 世间胜义谛，也称为"体用显现谛"。
2. 道理胜义谛，也称为"因果差别谛"。
3. 证得胜义谛，也称为"依门显实谛"。
4. 胜义胜义谛，也称为"废诠谈旨谛"。

前三种称为安立胜义，第四种是非安立胜义。

（二）解释

先解释总名，后解释别名。

一、解释总名"世俗谛"。

护法论师解释说："世"是隐覆、可以毁坏的意思；"俗"是显现、随顺世间流转的意思。这个谛从道理上应当称为"隐显谛"：隐覆了空理，有相状显现。就像把手巾结成兔子等形状，隐去了本来的手巾，显现出兔子的相状；世俗也是这样。现在随顺古来的译名，称为世俗谛。梵语"三佛栗底"（saṃvṛti），所以从意义上解释为隐显谛。

又，体性堕落于生起和穷尽，称为"世"；体相显现，称为"俗"。世就是俗，称为世俗，是持业释。或者解释为"世间的俗"，意义也不相违。

"谛"是真实的意思。有，如实是有；无，如实是无。有和无都不虚妄，称为谛。世俗就是谛，是持业释；"世俗的谛"，是依士释。

二、解释总名"胜义谛"。

"胜"是殊胜。"义"有两种：一是以境界称为义，二是以道理称为义。

1. 第四重胜义，诸论大多说"胜就是义"，是持业释立名。或者四重胜义都是"胜的义"，是依士释。
2. 论中说，依他起、圆成实二性，随其所应，是根本智、后得智两种智慧的境界，所以诸教大多以真如的体性殊胜，作持业释立名，实际上也通于依士释。
3. 无漏的真智，无论在哪一谛，也以"胜"为义，因为以真如为境界，所以通于有财释。
4. 第四重胜义，大多依照"以道理称为义"，因为废诠谈旨，不是境界。前三重胜义，以境界称为义。

"谛"是真实的意思。事如实是事，理如实是理，理和事都不谬误，称为谛。胜义就是谛，或"胜义的谛"，两种解释如前面所说。

没有教文明说，从道理上，两种谛也可以称为圣谛，就像四圣谛一样。因为圣者能知有、无、事、理都不虚谬，称之为谛。

三、解释世俗谛的四种别名。

1. 世间世俗。隐覆真理，在世间情识中是有，堕在虚伪之中，称为"世间"。凡夫都认为是有，依情识、依名言假说，称为"世俗"。
2. 道理世俗。随着种种意义，建立蕴等诸法，称为"道理"。事相显现，差别容易了知，称为"世俗"。
3. 证得世俗。施设染净因果的差别，令众生趣入，称为"证得"。有相状可以了知，称为"世俗"。
4. 胜义世俗。妙出众法，是圣者所知，称为"胜义"。假相安立，不是离言的本体，称为"世俗"。

这里世间就是世俗谛，乃至胜义就是世俗谛，都是持业释。

四、解释胜义谛的四种别名。

1. 世间胜义。事相粗显，还可以破坏，称为"世间"。也是圣者所知，超过第一重世俗，称为"胜义"。
2. 道理胜义。知苦、断集、证灭、修道，因果的差别，称为"道理"。是无漏智的境界，超过前两重世俗，称为"胜义"。
3. 证得胜义。圣智依言诠的空门显示真理，称为"证得"。凡夫愚人不能测度，超过前三重世俗，称为"胜义"。
4. 胜义胜义。体性微妙，离开言说，远远超过众法，称为"胜义"。圣智内证，超过前四重世俗，又称为"胜义"。

这里世间就是胜义谛，乃至胜义就是胜义谛，都是持业释；或者"胜义的谛"，作依士释也没有过失。

二、辨明体性

（一）四重世俗的体性

1. 第一重世俗的体性。《显扬圣教论》说：就是所安立的瓶、军、林等，以及我、有情等。有的没有实体，有的体性实际上是无，只有情执和名言，完全没有体性。通于有作用和无作用两种法：瓶等有作用，我等没有作用。《涅槃经》第十三卷说："有名无实，如我、众生，乃至旋火之轮，以及名句等五种世法，称为世谛。"众生等没有作用，旋火轮等没有体性。

2. 第二重世俗的体性。《瑜伽师地论》说：就是所安立的蕴、处、界等。《涅槃经》也说："诸阴、界、入，称为世谛。"这就是有为、无为诸法的体和事，有各别的体性和作用，不同于第一重世俗。

3. 第三重世俗的体性。《显扬圣教论》说：就是所安立的预流果等以及所依之处，也就是诸圣果、四谛理等。《涅槃经》也说："有八苦相，称为世谛。"

4. 第四重世俗的体性。《瑜伽师地论》说：就是所安立的胜义谛性。《涅槃经》说："若烧、若割、若死、若坏，称为世谛。"因为可以烧、割等，没有常一的我、法等相状，所以二无我称为世俗。

第一重世俗的体性是假名安立；后三重世俗的体性是有相安立。

（二）四重胜义的体性

1. 第一重胜义的体性。《成唯识论》说：就是蕴、处等事。《涅槃经》也说："有名有实，称为第一义。"蕴、处、界等也是胜义。

2. 第二重胜义的体性。《成唯识论》说：就是四谛等因果的体和事。《涅槃经》也说："苦、集、灭、道，称为第一义谛。"

3. 第三重胜义的体性。《成唯识论》说：就是依言诠之门显示的二空真如。《涅槃经》也说："没有八苦相，称为第一义。"因为总观诸法为二无我，所以没有苦等，称为胜义。

4. 第四重胜义的体性。《瑜伽师地论》说：就是非安立的一真法界。《涅槃经》也说："实体就是如来、虚空、佛性。"又说："没有烧割等，称为第一义。"因为不依无我而显示真如。

前三重胜义有相状，所以是安立；第四重胜义没有相状，是非安立。

（三）与三性的对应

1. 最初一重世俗，心外之境是无，依情执立名，称为世俗。
2. 第二重俗谛，是心所变现的事。
3. 后两重俗谛，是心所变现的理。施设差别，就是前三重真谛。
4. 第四重真谛，只是内智所证，不是心所变现的理。

随其所应，就是三性。

以上是第一门，显示名称，辨明体性。

第二门　三乘的浅深

分两部分：先辨明三乘的二谛，后显示浅深。

一、三乘都有二谛

二乘自己的教法中，不说作二谛的观行而入真；现在说二乘也证生空，在加行观的时候，承认观真谛和俗谛。

《涅槃经》说：世谛和第一义谛，都有中智和上智。

1. 世谛方面：知道世谛的，称为中智；分别世俗无量无边，不是声闻、缘觉所能知的，称为上智。这是俗谛中的中智和上智。
2. 第一义谛方面："一切行无常，诸法无我，涅槃寂灭"，这是第一义，称为中智；知道第一义无量无边，不可称计，不是声闻、缘觉所能知的，称为上智。这是胜义中以各别种类的智为上智，以一切总相的智为中智，如下面详细说明。

如《仁王经》诘问："世谛中有没有第一义谛？如果有，谛就不应当是一；如果没有，智就不应当是二。"这就显示人和法都有二谛。以人来相比较：凡夫为下，二乘为中，如来为上。由此人和法各分两重，所以三乘都有二谛。

二、声闻乘的二谛

（一）四重世俗

1. 世间世俗谛：就是所安立的瓶、军、林等，以及我、有情等。这里只取所执的实我，不取实法；即使执着实法，因为不障碍声闻果，也不取。
2. 道理世俗谛：就是所安立的蕴、处、界等三科的体和事，因为声闻大多以三科作观。
3. 证得世俗谛：就是所安立的四圣谛理，因为依四谛理加行修习而证得。
4. 胜义世俗谛：就是所安立的生空真如，因为依生空之门证得真如。

（二）四重胜义

1. 世间胜义谛：就是所安立的三科等法。
2. 道理胜义谛：就是所安立的四圣谛理。
3. 证得胜义谛：就是所安立的生空真如。
4. 胜义胜义谛：就是非安立的生空无我，废诠谈旨的一真法界。

这里安立和非安立的相状，依照前面应当了知。所以诸论中所说的第二、第三重世俗谛等，大多依声闻的境界来说。

三、独觉乘的二谛

独觉与声闻所执、所证的体性没有差异，只是因为根器有上下，修行有浅深，所以成为差别。

（一）四重世俗

1. 世间世俗谛：就是所安立的瓶、军、林等，以及我、有情等。既然与声闻所执没有差别，也只取所执的实我等，不取所执的法等，因为执法不障碍独觉果。
2. 道理世俗谛：就是所安立的十二有支流转等法，因为独觉大多以十二有支为所缘境。
3. 证得世俗谛：就是所安立的十二有支杂染的顺逆观察，以及对清净品顺逆的因果等，七十七智、四十四智等法，因为依这些加行修习而证得。
4. 胜义世俗谛：就是所安立的生空真如。

（二）四重胜义

1. 世间胜义谛：就是所安立的流转有支。
2. 道理胜义谛：就是所安立的十二有支杂染顺逆、观察清净品顺逆等，七十七智、四十四智等。
3. 证得胜义谛：就是所安立的生空真如。
4. 胜义胜义谛：就是非安立的生空无我，废诠谈旨的一真法界。

既然与声闻所悟、所证相同，后两重胜义与声闻没有差异。

（三）独觉与声闻的兼摄

独觉所悟、所执与声闻相同，根器则不同，行相所缘也不同。上乘兼摄下乘：声闻的行相所缘，必定也是独觉的法，所以蕴等法、四圣谛理，也是独觉的境界。下乘不兼摄上乘：十二有支的流转、还灭，七十七智等，除了大利根的声闻，不是其余声闻的境界。

四、菩萨乘的二谛

菩萨与二乘根性不同，行相所缘有差别，所悟、所执也不同。

（一）四重世俗

1. 世间世俗谛：就是所安立的瓶、军、林等，以及我、有情等。这里通取所执的实人、实法，因为执着实法障碍菩萨果。
2. 道理世俗谛：就是所安立的十种善巧。《辩中边论》第二卷、《菩萨藏经》第十七卷说：一蕴，二界，三处，四缘起，五处非处，六根，七世，八谛，九乘，十有为无为善巧。菩萨以这十种为所缘境，除去我执、法执。《瑜伽师地论》说六种善巧，就是十种中的前六种；或者说七种，再加上谛善巧。
3. 证得世俗谛：就是所安立的三性、三无性、唯识妙理，因为缘这些为境而证得。
4. 胜义世俗谛：就是所安立的二空真如，因为菩萨双证二空真如。

〔译注：原文「十六善巧」，下文列出的只有十种，"六"当是衍字，译文作"十种善巧"。〕

（二）四重胜义

1. 世间胜义谛：就是所安立的十种善巧等。
2. 道理胜义谛：就是所安立的三性等理。
3. 证得胜义谛：就是二空真如，因为依二空之门而证得。
4. 胜义胜义谛：就是非安立的二空无我、一真法界。

（三）菩萨与二乘的兼摄

菩萨所悟、所执既然与二乘不同，所证、所断的宽狭也有差别。上乘必定兼取下乘：二乘的境界和修行，必定也是菩萨的境界和修行。所以十种善巧摄持蕴等法；诸论大多说第二、第三重世俗，以三科、四谛为体性。下乘不能及于上乘：菩萨的境界和修行不是二乘所知，所以法空真如、三性、三无性不是二乘的境界。

（四）安立与非安立

两组四重谛中：

1. 最初一重俗谛，是假名安立。
2. 后三重世俗、前三重胜义，是有相安立。
3. 第四重胜义，废诠谈旨，没有差别相，只是非安立，因为是自内所证。

五、浅深

所说的浅深，是就人和法的浅深来推究。无论依人还是依法，都通于两组四重谛。

（一）依人的浅深

《涅槃经》说："出世间的人所知的，称为第一义谛；世间的人所知的，称为世谛。世谛就是第一义谛，佛有善巧方便，随顺众生，说有二谛。比如五阴和合，称为某甲，凡夫众生随着这个称呼，这称为世俗谛。了解五阴中没有某甲这个名字，离开五阴也没有某甲这个名字，出世间的人如其性相而能了知，称为第一义谛。"

（二）依法的浅深

依法的浅深，《涅槃经》中自己具足解释，下面诸教相摄中会详细显示。

以五蕴法为例：

1. 如果是所执的五蕴，随着执着的情识，就是第一重世俗。
2. 五蕴的事，就是第二重世俗。
3. 五蕴之上的因果等道理，就是第三重世俗。
4. 观察五蕴没有两种实我，依二无我所显示的真理，就是第四重世俗，因为说的是依言诠显示真如。
5. 五蕴的事，就是第一重真谛。
6. 因果等理，就是第二重真谛。
7. 观察五蕴上两种我都没有的时候，依门显示真实，就是第三重真谛。
8. 观察五蕴的真如，自内所证，废诠谈旨的一真法界，就是第四重真谛。

前前粗，后后细。

（三）《成唯识论》中的例证

1. 《成唯识论》第七卷说："如果依世俗说，离开心另外有心所。"这就是第二重世俗，因为是事的差别。"如果依胜义说，心所与心非离非即。"这就是第二重真谛，因为因果道理非即非离。第三重世俗的情况依此类推，也是这样，现在是对望真谛来说。
2. 《成唯识论》第七卷又说："如前面所说的识的差别相，是依道理世俗。"这就是第二重世俗，"不是真胜义，因为在真胜义中，心行和言说都断绝"。这就是第四重真谛。
3. 《成唯识论》同卷又解释：八识的自体不是决定的一或异，这就是第三重世俗；对心行言说断绝，就是第四重真谛。
4. 虚妄的识性，是第一重世俗；真实的识性，是第四重真谛。这就是以第一重俗谛对望第四重真谛。

第二重俗谛对望第三重真谛，第三重俗谛对望第二重真谛，第四重俗谛对望第一重真谛，道理都是这样。依照这个道理一一推寻，从粗入细，相对来说，都通于两组四重谛。
