# 窥基《大乘法苑义林章》（三）总料简章·诠宗各异

## 第三门　所诠表的宗旨各不相同

"宗"，就是所崇尚、所尊重、所主张的意思。圣教所崇尚、所尊重、所主张的道理，称为宗。外道与内道、小乘与大乘，所崇尚、尊重、主张的法各不相同，所以说宗旨有别。

古来的大德总立四宗：

一、立性宗，如《杂阿毗昙心论》等。
二、破性宗，如《成实论》等。
三、破相宗，如《中论》《百论》等。
四、显实宗，如《涅槃经》等。

窥基现在不采用古德的四宗分法，而是分两部分来讲：先陈述其他各家的宗旨，后列出自宗的宗主。陈述其他各家的宗旨，又分两部分：先陈述外道，后陈述小乘。

### 一、外道的十六种宗

外道虽然有九十五种，大意不出十六种异论，详见《瑜伽师地论》第六、七卷和《显扬圣教论》第九、十卷。论中有一首颂概括十六种异论：

「执因中有果，显了、有去来，我、常、宿作因，自在等、害法，边无边、矫乱，见无因、断、空，计胜、净、吉祥。」

（大意：执著因中有果，从缘显了，去来实有；计我，计常，计宿作为因；计自在天等为因，以害生为正法；计边无边，不死矫乱；见无因，见断灭，见一切空；计最胜，计清净，计吉祥。这就是十六种异论。）

一、因中有果宗。雨众外道认为，诸法在因中常有果的体性。比如禾苗以谷子为因，想要禾苗时只要种谷子，禾苗一定从谷子生，不从麦子生。所以雨众外道认为谷子这个因中早已有禾苗的体性；不然的话，就应当一切法从一切法生。

二、从缘显了宗。僧佉（数论）和声论者主张这一宗。数论师认为，一切法的体性本来自有，从众缘显现，不是众缘所生；若不是从缘显现，果本来就有，再从因生，就不合道理。声论者说：声音的体是常住的，相也是本来就有的，无生无灭，只是由于一次次发声吐语才显了出来。

三、去来实有宗。胜论外道和计时外道等也这样主张：过去世和未来世，像现在世一样真实存在，不是假立的。这个观点也通于小乘，这里取的是外道的说法。

四、计我实有宗。兽主等一切外道都这样主张：有我，有萨埵（有情），有命者、生者等。这些外道由生起五种觉知而知道有我，比如见色时，生起"萨埵见色"的觉知等。

五、诸法皆常宗。伊师迦认为，我和世间都是常住的，包括计一切常、计一分常等。计极微是常，也属于这一宗。

六、诸因宿作宗。离系亲子（尼乾子），也叫无惭外道，认为现在所受的苦，都以宿世所作的业为因；若现在精进苦行，就能吐出旧业；不再造新业作因，旧业又被苦行所害，以后就不再有漏。

七、自在等因宗。主张不平等因的外道，随所侍奉的神，就以那位神为名，比如莫醯伊湿伐罗（大自在天）派等。这些外道或认为诸法是大自在天变化出来的，或认为是丈夫变化出来的，或认为是大梵天变化出来的，或认为时、方、空、我等是诸法之因。

八、害为正法宗。在斗诤劫中，一些婆罗门为了吃肉，妄起这种主张：若为祭祀，先念咒术，再杀害生命，那么主祭的人、被杀的生命以及帮助杀生的人，都能生天。

九、边无边等宗。证得世间静虑的边无边外道，住于有边、无边等想，认为世间有边、无边、亦有边亦无边、非有边非无边。

十、不死矫乱宗。就是不死矫乱外道。

十一、诸法无因宗。无因外道认为，我和世间都是无因而起的。

十二、七事断灭宗。断灭外道认为七事断灭。

十三、因果皆空宗。各种邪见外道认为没有布施、爱养等果报。这些外道看见行善的人反而生到恶趣，看见作恶的人反而生到善趣，就认为因果是空的；或者总体上拨无一切，认为一切皆空。

十四、妄计最胜宗。斗诤劫中的婆罗门认为：婆罗门是最殊胜的种姓，是梵王的儿子，从梵王的腹部和口中生出；其余种姓低劣，不是梵王的儿子。

十五、妄计清净宗。现法涅槃外道和以水等为清净的外道认为：坚固地执著享用诸天的微妙五欲，就叫证得现法涅槃，乃至广说。持牛戒、狗戒的外道也是这样认为。

十六、妄计吉祥宗。历算外道认为：若日月亏蚀、星宿失度等，或者随顺日月的意愿，事情都能成办，所以应当勤加供养日、月、星等。详细内容见论中所说。

以上第一部分，陈述外道的宗旨。

### 二、小乘的十一类宗

小乘虽然有二十部的主张，总结为宗旨，不超过十一类。

古来相传"十八部"的说法，是很大的错误。依照古代真谛法师所翻译的，部派成为十九部：大众部分出七部，加上本部共八部，应当是九部，漏掉了西山住部；上座部分出十一部，本部上座部也在其中。

《文殊师利问经》下卷说成二十部，与《宗轮论》略有不同。《文殊问经》的偈说：

「摩诃僧祇部，分别出有七，体毗履十一，是谓二十部。十八及本二，皆从大乘出，无是亦无非，我说未来起。」

（大意：大众部分出七部，上座部分出十一部，共二十部。十八部加上两个根本部，都从大乘中出，没有对，也没有错，我说这是未来将要出现的事。）

〔存疑："体毗履"即上座部的音译；"十八及本二"的计数与前文二十部的关系，原文简略，大意依字面理解。〕

《文殊问经》也说二十部，与《宗轮论》大体相同，只是所分出的部派增减有所不同。《宗轮论》说：

大众部中分出八部，加上本部共九部：一大众部、二一说部、三说出世部、四鸡胤部、五多闻部、六说假部、七制多山部、八西山住部、九北山住部。

上座部中分出十部，加上本部共十一部：一说一切有部、二雪山部（也叫上座部）、三犊子部、四法上部、五贤胄部、六正量部、七密林山部、八化地部、九法藏部、十饮光部、十一经量部。

两派合起来成二十部。《文殊问经》中大众部连本部有八部，上座部连本部有十二部，所以可知都是翻译者的错误。现在依照新译的《宗轮论》，把二十部总结为十一类：

第一类，大众部、一说部、说出世部、鸡胤部，四部的宗旨是：一切如来没有有漏法；佛身和寿量都无边际；眼等五识身有染污，也有离染；色界、无色界都具有六识身；五种色根以肉团为体；无为法有九种；过去世和未来世不存在；一刹那的心能了知一切法；道与烦恼可以同时现前。大义如此。

第二类，多闻部的宗旨是：佛陀的五种音声是出世间的教法，就是一无常、二苦、三空、四无我、五涅槃寂静；其余的音声是世间教。其余主张大多与说一切有部相同。

第三类，说假部的宗旨是：苦不是蕴；十二处不是真实的；由福德而得圣道；圣道不可修。其余主张大多与大众部相同。

第四类，制多山部、西山住部、北山住部，三部的宗旨是：一切菩萨还没有脱离恶趣；供养塔庙得不到大果报。其余主张大多与大众部相同。

第五类，说一切有部的宗旨是：一切有，有两种，一是法有，二是时有。心、心所、色、不相应行以及三种无为，是"法一切"；过去、未来、现在三世，是"时一切"。一切存在的法，都摄在名和色这两类之中。

第六类，雪山部的宗旨是：菩萨还是凡夫；菩萨入胎时不起贪爱；外道不能得五通；天中没有修梵行的人。

第七类，犊子部、法上部、贤胄部、正量部、密林山部，合为五部，宗旨是：补特伽罗与蕴不即不离；五识没有染污，也不是离染；入正性离生（见道）的十二心之间称为行向，第十三心称为住果。

第八类，化地部的宗旨是：过去世和未来世不存在，现在世和无为法存在；四圣谛一时现观；决定没有中有；有齐首补特伽罗；有世间正见，没有世间信根；没有出世的静虑；没有无漏的寻；善法不是有的因；预流果有退；无为法有九种。

第九类，法藏部的宗旨是：佛陀摄在僧团之中；佛陀与二乘的解脱相同，圣道不同；外道不能得五通；阿罗汉的身体都是无漏的。其余主张大多与大众部相同。

第十类，饮光部的宗旨是：若法已经断除、已经遍知，就不存在；还没有断除、还没有遍知，就存在；业的果报已经成熟，就不存在；还没有成熟，就存在；有学之法有异熟果。其余主张大多与法藏部相同。

第十一类，经量部的宗旨是：有胜义的补特伽罗；凡夫位中也有圣法；有根边蕴，有一味蕴，一味蕴就是细意识等。其余主张大多与说一切有部相同。

这里所陈述的只是略标宗要，详细陈述各宗，见《宗轮论》。

以上总体陈述其他各家的宗旨。

### 三、大乘的宗主

列出自宗的宗主，分两部分：先列偏于一边的宗主，后列中道的宗主。

#### （一）偏于一边的宗主：清辨等

清辨等论师辅助龙猛（龙树），依据《般若经》的意思，说诸法皆空。清辨等论师认为：一切法都不可言说，因为自性空无，所以不可说为空或有。有为法与无为法，依胜义谛来说，体性都是空的；依世俗谛来说，可以说有。所以清辨说一首颂：

「真性有为空，如幻缘生故；无为无有实，不起，似空花。」

（大意：依真实性来说，有为法是空的，因为有为法如幻，是缘生的；无为法没有实体，因为无为法不生起，好比空中的花。）

清辨等论师乃至不建立三性和唯识。因为清辨所说的胜义谛中一切都是空，所以称为偏于一边的宗主。

#### （二）中道的宗主：天亲等

天亲（世亲）等论师辅助慈氏（弥勒），依据《解深密经》等经，依真谛和俗谛来说一切法有空、有不空。

依世俗谛的道理：遍计所执，在情上有，在理上无；有为法和无为法，在理上有，在情上无。依胜义谛：一切法的体性有的存在、有的不存在，只因为言语达不到，所以说非空非有，并不是因为体性是空才说不可言说。

《成唯识论》说：胜义谛中，心念和言语都断绝了，所以非空非有。若要借言语来诠表，就引慈氏所说的颂：

「虚妄分别有，于此二都无。此中唯有空，于彼亦有此。故说一切法，非空非不空，有无及有故，是即契中道。」

（大意：虚妄分别是有的；在虚妄分别中，能取和所取二者都没有。虚妄分别中只有空性，空性中也有虚妄分别。所以说一切法不是空，也不是不空：有虚妄分别，没有能取所取，空性中有虚妄分别，空性也有，所以这就契合中道。）

天亲等论师依此建立三性和唯识：我与法、外境是空的，真谛、俗谛和识是有的，于是成立非空非有的中道义。天亲等以所阐明的"一切法非空非有"的中道义作为宗旨。详细内容见其他章节。

这里只是简略叙述两派所诤论的宗旨。至于各种教法以本部所阐明的各别法相为宗旨的情况，随其所应，详见其他地方的解释。
