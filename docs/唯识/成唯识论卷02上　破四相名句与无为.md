<p class="dt-title">破四相名句与无为</p>

<div class="dt-subtitle">成唯识论白话译注（四）　卷第二之上<br>护法等菩萨造　唐　玄奘译</div>

本篇要目：一、破生住异灭四相　二、四相的正确安立　三、破名句文身与随眠　四、破实有无为　五、六种无为都依真如假立　六、法执的两种与所缘缘　七、答“假说必依真事”之难

一、破生住异灭四相

外人质问：你们怎么知道诸有为相离开色心等而有实在的自性？论主代为回答：说一切有部依据契经。契经说：有三种有为法的有为相，乃至广说。

【译注】有为相指生、住、异、灭四相，是有为法之所以为有为法的标志。经中说生、异、灭三相，有部立为生、住、异、灭四相，并认为四相是离开色心而实有的不相应行。

论主破斥：契经并没有说有为相离开色心等而有实在的自性，引经作证不能成立。

“有为之有为相”中的“之”，是梵语的第六格，即属格。属格并不一定表示两个不同的东西。例如说“色之体”“心之体”，色的体就是色，心的体就是心。

能作为标志的相，体不一定异于被标志的法。有部自己承认坚是地的体相，坚相并不异于地；能相若定异所相，坚相等就应异于地等。有为相如果异于所标志的有为法之体，无为相的体也应异于所标志的无为法。

再从四相同时存在来破。生等四相的体如果同时存在，就应在一切时同时发挥作用。有部辩解：四相互相违背，所以作用不同时发起。论主回答：四相的体也互相违背，四相的体又怎能同时存在？住、异、灭三相的作用，也不应同时发起。能标志的四相与所标志的法，体都是本来就有的，四相的作用也应本来就有，因为体与作用没有不同的性质。

有部辩解：四相的作用还要等待因缘。论主回答：所等待的因缘就不应本来就有。执着有生等四相，生等四相便成了无用，因为所标志的法本来就有。所标志的法恒常存在，又与生等四相结合，无为法也应有生等四相，因为有为与无为在恒常存在上，找不到不同的原因。

再从三世实有来破。过去世与未来世，既不是现在，也不是常住，就应如同空中的花，不是实有。

【译注】有部主张三世实有，并说生相在未来位发挥作用，灭相在现在位发挥作用。论主下面针对三世实有破斥。

“生”的意思是有，怎能在未来世？“灭”的意思是无，就不应在现在世。灭如果不是无，生就不应是有。灭与住互相违背，怎能执着灭与住同时存在？住与生并不互相违背，怎能说住与生在不同的时世？所以有部的主张，进退都不合道理。

二、四相的正确安立

论主正面说明：有为法由因缘的力量，本来没有，现在有了；暂时存在，又归于无。为了显示有为法不同于无为法，假立四相。

本来没有、现在有的阶段，称为生。生起之后暂时停留，称为住。住时前后有别，称为异。暂时存在、又归于无，无的阶段称为灭。前三相是有，所以都在现在；后一相是无，所以在过去。

外人质问：灭是无，无怎能作为有为法的相？论主回答：灭相显示有为法后来归于无，作为有为法的相，有什么过失？

生相显示有为法以前没有，灭相显示有为法以后归于无，异相显示有为法不是凝然不变，住相显示有为法暂时有作用。所以四相对有为法都称为显示，所显示的内容各不相同。

以上是依刹那假立四相。依一期生命的分位，也可以假立四相：最初有，称为生；最后无，称为灭；生后相似相续，称为住；相续中转变，称为异。所以四相都是假立的。

三、破名句文身与随眠

外人质问：你们怎么知道名身、句身、文身离开色心等而实有，能作诠表？论主代为回答：有部依据契经。契经说：佛得到稀有的名身、句身、文身。

论主破斥：契经并没有说名、句、文离开色心等而实有，引经作证不能成立。

名、句、文如果离开声音而实有，就应如同色等，不是真正能诠表的东西。

有部辩解：声音能生起名、句、文。论主回答：能生名、句、文的声音，必定有音韵的高低曲折，音韵曲折已足以诠表，又何必要名、句、文？

有部辩解：声音上的音韵曲折，就是名、句、文，名、句、文离开声音而实有。论主回答：眼所见的色上有形状长短的曲折，色上的曲折就也应离开色处另有实体。

有部辩解：声音上的音韵曲折，如同琴弦、管乐的声音，不能诠表。论主回答：语声的曲折如果如同弦管之声，语声就应如同弦管之声，不另生名、句、文。又是谁说弦管之声决定不能诠表？

有部反问：声音如果能诠表，风声、铃声等也应有诠表作用。论主回答：语声应如同风声、铃声，不另生实在的名、句、文。

有部反问：如果只有语声能生名、句、文，为什么不承认只有语声能诠表？论主反问：凭什么道理决定知道能诠表的就是语声？又怎么知道离开语声另有能诠表的东西？

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">语不异能诠，人天共了；<br>执能诠异语，天爱非余。</div>

大意：能诠表的不外乎语声，人和天都明白。执着能诠表的东西异于语声的，只有“天爱”，没有别人。

【译注】“天爱”是梵语中讥讽愚人的说法，字面是“天所怜爱的人”，意思是只能靠天怜爱的笨人。

论主正面说明：依语声的分位差别，假立名身、句身、文身。名诠表事物的自体，句诠表事物的差别义理，文就是字，是名和句的所依。名、句、文三者离开语声没有另外的体，假有与实有有别，所以名、句、文也不就是声音。

【译注】名如“眼”，指出一个事物；句如“眼是无常”，说出事物的差别；文是组成名和句的字母音节。

由于名、句、文与声音有别，法无碍解与词无碍解的境界有所不同：法无碍解通达名、句、文，词无碍解通达语声。声音与名、句、文，在蕴、处、界的归属上也各不相同：声音属色蕴、声处、声界，名、句、文属行蕴、法处、法界。

以上只是依娑婆世界而说名、句、文依声音假立，并非一切世界都如此。其余佛土也有依光明、妙香、妙味等假立名、句、文的。

有人主张：随眠异于心王与心所，属于不相应行蕴。论主破斥：随眠的主张也不合道理。随眠称为贪等，如同现行的贪等，不是不相应行。执着另有其余的不相应行，照前面的道理，都应遮止。

【译注】随眠是烦恼的潜伏状态。唯识宗以随眠为烦恼的种子，存于阿赖耶识中，不另立为不相应行。

四、破实有无为

诸无为法离开色心等而决定实有，在道理上找不到依据。

可以确定存在的法，大略有三种。第一种是现前可知的法，如色法、心法等。第二种是现前受用的法，如瓶子、衣服等。第一、第二两种法，世间共知存在，不需要用道理证成。第三种是有作用的法，如眼根、耳根等，由眼根、耳根等各自的作用，证知眼根、耳根等存在。

无为法不是世间共知确定存在的，也没有作用，不像眼根、耳根等可以由作用证知。即使承认无为法有作用，无为法就应是无常。所以不能执着无为法确定实有。

主张是：诸无为法不应执着为离开色心等而实有的无为体性。理由是：诸无为法是所知的；或者，诸无为法是由色心等所显示的。例证是：如同色法、心法等。

再问：虚空等无为法，是一个还是多个？

如果虚空的体是一个，周遍一切处，虚空能容受色等法，虚空的体就应随着所容受的法而成为多个，因为虚空某一处与某法结合时，其余各处并不与该法结合。不然的话，诸法就应互相遍满。

有部辩解：虚空不与诸法结合。论主回答：虚空就不应能容受诸法，如同其余的无为法。

再问：色等法之中，有没有虚空？如果有，虚空与色就应混杂在一起；如果没有，虚空就不周遍。

择灭的体如果是一个，断除某一部、某一品烦恼时，就应同时得到其余各部、各品的择灭。某一法因缘缺少而得到不生时，就应同时得到一切法的非择灭。执着择灭、非择灭的体是一个，按道理就应如此。

【译注】“部”指见苦所断、见集所断等烦恼的五部分类，“品”指烦恼由粗到细的九品。

如果无为法的体是多个，无为法就有种类差别，就应如同色等，不是实在的无为法。虚空也就不应周遍、容受一切法。

其余部派所执离开心王与心所而实有的无为法，照前面的道理都应破斥。

主张是：诸无为法不是异于心等而存在的。理由是：有部承认无为法没有因果关系。例证是：如同兔角。

五、六种无为都依真如假立

论主正面说明：契经说有虚空等诸无为法，大略有两种安立方式。

第一种，依识所变而假立施设。有人曾听说虚空等名称，随着分别，心中就有虚空等的相。由于反复熏习的力量，心王与心所生起时，显现出似虚空等无为法的相。所显现的相前后相似，没有变易，所以假说为常。

第二种，依法性而假立施设。法性就是我空与法空所显的真如。真如既不是有，也不是无，心思与言语的道路都断绝了，与一切法既不是一，也不是异。真如是诸法真实的道理，所以称为法性。

真如远离一切障碍，所以称为虚空。由智慧简择的力量，灭除一切杂染，究竟证会，所以称为择灭。不由智慧简择，本性清净，或因缘缺少而显现，所以称为非择灭。苦受与乐受都灭了，所以称为不动。想与受不起作用，所以称为想受灭。以上五种无为，都依真如而假立。

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">真如亦是假施设名。<br>遮拨为无，故说为有；<br>遮执为有，故说为空；<br>勿谓虚幻，故说为实；<br>理非妄倒，故名真如。</div>

大意：“真如”的名称，也是假立施设的。为了遮止否定真如的人，所以说真如是有。为了遮止执着真如实有的人，所以说真如是空。为了不让人认为真如是虚幻的，所以说真如是实。真如的道理不虚妄、不颠倒，所以称为真如。

【译注】真如四句，一句一遮。说“有”，不是说真如像事物一样存在；说“空”，不是说真如什么都没有。每一种说法都是为了拔除一种执着，拔除之后，连“真如”的名字也要放下。

唯识宗的真如，不同于其余部派所说离开色心等另有实在常住之法而称为真如。所以诸无为法并非决定实有。

六、法执的两种与所缘缘

论主立两个论式。

第一个论式：主张是，外道和小乘所执的异于心王、心所的诸法，不是实有。理由是，所执的诸法是所取。例证是，如同心王与心所，心王与心所作为所取时，也不是离识的实有。

第二个论式：主张是，能取外法的觉知，也不缘取外法。理由是，觉知是能取。例证是，如同缘取心王、心所的觉知。

诸心王与心所，依他起，所以也如同幻事，不是真实存在。为了遣除执着心王、心所之外实有外境的妄执，所以说唯有识。

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">若执唯识真实有者，如执外境，亦是法执。</div>

大意：如果执着“唯识”本身是真实存在的，就和执着外境一样，也是法执。

【译注】“唯识”是用来遣除外境执着的药，药也不能执为实有。“亦是法执”一句关乎全论的用意，读者要时时记住。

法执大略有两种：第一种是俱生法执，第二种是分别法执。

俱生法执，是无始以来虚妄熏习的内在力量，使法执恒常与身俱在，不需要邪教和邪分别，自然而然地运转，所以称为俱生。俱生法执又有两种。第一种恒常相续，在第七识中：第七识以第八识为所缘，生起自心中的影像，执为实法。第二种有时间断，在第六识中：第六识以识所变现的蕴、处、界相为所缘，或者总缘，或者别缘，生起自心中的影像，执为实法。两种俱生法执都很微细，所以难断，要到十地之中，反复修习殊胜的法空观，才能除灭。

分别法执，是由现世的外缘力量引起的，并不与身俱在，要依靠邪教和邪分别才会生起，所以称为分别。分别法执只在第六意识中存在。分别法执也有两种。第一种以邪教所说的蕴、处、界相为所缘，生起自心中的影像，分别计度，执为实法。第二种以邪教所说的自性等相为所缘，生起自心中的影像，分别计度，执为实法。两种分别法执都很粗显，所以易断，初入初地时，观一切法的法空真如，就能除灭。

【译注】与上卷的两种我执对照：分别我执在见道时断，俱生我执在修道中断；分别法执在初地断，俱生法执在十地中断。菩萨的见道就是入初地。

一切法执所缘的法，自心之外的法有时有、有时无，自心之内的法一切法执都有。所以一切法执都以自心所显现的似法为所缘，执为实有。似法之相从因缘生起，所以是如幻的存在；所执的实法是虚妄计度的，所以决定没有。所以世尊说：弥勒，你应当知道，诸识所缘的对象，都只是识所显现的，是依他起性，如同幻事等。

由此可见，外道和小乘所执离识的我和法，都不是实有。所以心王与心所，决定不以外在的色等法为所缘缘，因为所缘缘的作用必须依于实有的体。

现在他人心聚中的心王与心所，不是自己心聚中的识的亲所缘缘，因为他人的心属于另一心聚，如同不是所缘的法。同一心聚中的心所，也不是心王的亲所缘缘，因为心所与心王自体各异，如同其余不被取的法。

【译注】“心聚”指同一刹那生起的一个心王及其相应的心所。他人的心，自己只能缘取自心中所变现的影像，所以他人的心最多只能作疏所缘缘。

由此应知，实际上没有外境，只有内识显现为似外境而生起。所以契经的偈颂说：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">如愚所分别　外境实皆无<br>习气扰浊心　故似彼而转</div>

大意：愚人所分别的外境，实际上都不存在。习气扰乱了心，所以心显现得好像外境。

七、答“假说必依真事”之难

有人提出问难：如果没有离识的实我、实法，假说的我法也应不存在。假说必须依据三样东西才能成立：真事、似事、共同的属性。例如，有真正的火，有像火一样的人，有勇猛、赤红的共同属性，才能假说某人是火。假说某人是牛等，也是同样的道理。实我实法如果没有，依据什么来假说我法？没有假说，“似”也不能成立，怎能说心显现得似外境？

【译注】依《述记》，问难者站在胜论的立场：“类”指同异句的火类，“实”指实句的火体。下文分别从“依类”“依实”两方面破斥。

论主回答：问难不合道理。离识的我和法，前面已经破了。依类、依实而假说火等，都不能成立。

先看依类假说。依类假说在道理上不能成立，因为勇猛、赤红等属性不是火类所有的。如果没有共同的属性而假说，就也应能对水等假说为火。

问难者辩解：勇猛等虽然不是火类的属性，勇猛等与火类不相离，所以可以假说。论主回答：不相离的辩解也不对。人类与勇猛等，现见也有互相分离的，有的人并不勇猛赤红。火类既没有勇猛等属性，人类与勇猛等又互相分离，世间依然对人假说为火，可知假说不依类而成立。

再看依实假说。依实假说在道理上也不能成立，因为勇猛、赤红等属性不是火与人共有的。勇猛、赤红在火上和在人上，体各不相同，因为所依不同。没有共同的属性而假说，过失和前面相同。

问难者辩解：人与火的属性相似，所以可以假说。论主回答：属性相似的辩解也不合道理。说“火”在人身上，并不是在属性上，所以说人是火，并不是依属性而说。由此可知，假说不依实而成立。

“假说必依真事”的主张也不合道理。“真事”指事物的自相，假智与言诠都不能以自相为境。假智与言诠得不到事物的自相，只在诸法的共相上运转。离开假智与言诠，也没有其他方法施设自相，作为假说的所依。

【译注】自相是事物独一无二、当下呈现的真实面貌，只有现量能够亲证；共相是概念和语言所涉及的普遍特征。说一个“火”字，“火”字只能指向一切火的共相，永远碰不到眼前的火本身。自相与共相之分是陈那论师量论的根本主张，论主用来说破：语言和概念从来摸不到事物本身。

假智与言诠必定依声音而生起，声音达不到的地方，假智与言诠就不运转。能诠的名言与所诠的意义，都不是自相。所以可知，假说不依真事。由此，假说只依似事而运转。“似”指增益出来、并非实有的相，声音依增益出来的似相而运转。所以不能说假说必依真事。问难者的问难不合正理。

论主依识所变现的相，为了对治妄执的真实我法，才说“假”，才说“似”。所以契经的偈颂说：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">为对遣愚夫　所执实我法<br>故于识所变　假说我法名</div>

大意：为了对治、遣除愚夫所执的实我实法，所以在识所变现的相上，假说我和法的名称。
