<p class="dt-title">清净不成与阿赖耶识差别</p>

<div class="dt-subtitle">摄大乘论白话译注　第五篇　所知依分之四<br>无著菩萨造　唐　玄奘译　附世亲释、无性释</div>

本篇要目：一、世间清净不成　二、出世清净不成　三、正闻熏习　四、灭尽定中识不离身　五、破色心无间为种子　六、转依三颂　七、阿赖耶识的差别　八、异熟识唯是无覆无记

一、世间清净不成

为什么世间清净不能成立？还没有离开欲界之贪、还没有得到色界之心的人，以欲界的善心，为了离开欲界之贪而勤修加行。欲界的加行心与色界心不俱生俱灭，所以欲界的加行心不被色界心所熏，说欲界的加行心是色界心的种子，不合道理。又，过去的色界心，经过许多生，被其余的心隔断，不应当作为现在定心的种子，因为过去的色界心已经没有了。所以成立：色界定心以一切种子异熟果识展转传来作为因缘，以加行善心作为增上缘。一切离欲之地，都应当如此了知。所以，世间清净离开一切种子异熟识，在道理上不能成立。

二、出世清净不成

为什么出世清净不能成立？世尊说，依于他人的言音和内心各别的如理作意，以此为因，正见得以生起。他人的言音和如理作意，是熏耳识，是熏意识，还是两者都熏？如理思惟正法的时候，耳识暂且不起；意识也被种种散动的其余诸识所隔断。与如理作意相应的心生起时，被闻法所熏的意识和熏习，早已灭去，成为过去，决定没有体，如何还能作为种子，生起后来与如理作意相应的心？又，与如理作意相应的心是世间心，与正见相应的心是出世心，两者从来没有俱生俱灭过，所以世间心不被出世心所熏；既然不被熏，说世间心是出世心的种子，不合道理。所以出世清净离开一切种子异熟果识，也不能成立。闻熏习摄受出世心种子的说法，在离开阿赖耶识的情况下不能相应。

又，一切种子异熟果识既是杂染之因，如何又能成为出世的、能对治杂染的清净心的种子？又，出世心从来没有生起过，出世心的熏习决定没有。没有熏习，出世心从什么种子而生？应当回答：从最清净法界等流的正闻熏习种子所生。

【世亲释】“最清净法界”，是佛世尊所证的法界，永断烦恼障和所知障，有别于声闻等所证。从最清净法界流出的契经等教法，称为“最清净法界等流”。无颠倒地听闻契经等教法，称为“正闻”。由正闻所起的熏习，称为“正闻熏习”。正闻熏习相续住在阿赖耶识中，作为生起出世间心的因。

三、正闻熏习

闻熏习是阿赖耶识的自性，还是不是阿赖耶识的自性？如果是阿赖耶识的自性，如何能成为阿赖耶识的对治种子？如果不是阿赖耶识的自性，闻熏习种子的所依应当如何看待？直到证得诸佛菩提，闻熏习随着在一个所依身中转起之处，寄存在异熟识中，与异熟识和合俱转，如同水与乳。闻熏习不是阿赖耶识，因为闻熏习是阿赖耶识的对治种子。

依下品熏习成中品熏习，依中品熏习成上品熏习，因为依闻、思、修反复修作而得相应。

【世亲释】下、中、上品，是依闻、思、修三慧而说，闻、思、修各有下、中、上三品；也可以说闻所成慧是下品，思所成慧是中品，修所成慧是上品。下品为因成中品，中品为因成上品。

又，正闻熏习种子的下、中、上品，应当了知也是法身种子，与阿赖耶识相违，不是阿赖耶识所摄，因为正闻熏习是出世间最清净法界的等流。正闻熏习属于世间法，同时是出世心的种子。又，出世心还没有生起时，正闻熏习已能对治诸烦恼的缠缚，已能对治诸险恶趣，已能使一切所造的恶业朽坏，又能随顺逢事一切诸佛菩萨。正闻熏习属于世间法，应当了知，初修业菩萨所得的正闻熏习也属于法身所摄；声闻、独觉所得的正闻熏习，只属于解脱身所摄。正闻熏习不是阿赖耶识，属于法身、解脱身所摄。正闻熏习的下、中、上品依次渐渐增长，异熟果识就依次渐渐减少，于是转变所依。一切种子的所依转变以后，异熟果识和一切种子就没有种子而转，一切种子永远断灭。

【世亲释】初修业菩萨，就是尚未见道的异生菩萨，所得的正闻熏习是法身的种子。声闻等的正闻熏习只是解脱之因，只得解脱身，不得法身。

又，为什么说如同水与乳？不是阿赖耶识的闻熏习，与阿赖耶识同处俱转，阿赖耶识的一切种子渐渐灭尽，不是阿赖耶识的闻熏习的一切种子渐渐增长，如同鹅在水中饮乳，乳尽而水在。又如世间人得离欲的时候，非等引地的熏习渐渐减少，等引地的熏习渐渐增长，因而得到转依。

四、灭尽定中识不离身

又，圣教说，入灭尽定时，识不离身。应当是异熟识不离身，因为灭尽定的生起不是为了对治异熟识。

又，出定以后，不是异熟识重新生起，因为异熟识一旦中断，除非重新结生相续，不会再生。

又，如果有人主张以意识的缘故，灭尽定中有心，此一主张不能成立：定不应成立的缘故；所缘和行相不可得的缘故；应当有善根相应的过失的缘故；不善与无记都不合道理的缘故；应当有想、受现行的过失的缘故；触可得的缘故；对三摩地有功能的缘故；应当有只灭想的过失的缘故；应当有思与信等善根现行的过失的缘故；拔出能依、使之离开所依，不合道理的缘故；有譬喻的缘故；如同非遍行，灭尽定中的心所不是非遍行的缘故。

又，如果有人以意识的缘故，执着灭尽定中有心，所说的心是善、是不善、是无记，都不能成立，所以不合道理。

【世亲释】上面的种种理由，要义如下。

心不能离开心所而存在。如果灭尽定中有意识，想和受等心所也应当不灭，灭尽定就不能成立。立阿赖耶识就没有过失，因为灭尽定所对治的是其余的心与心所，不是不明了的阿赖耶识。

心与心所相续不断，必定不离所缘与行相；灭尽定中所缘与行相都不可得，所以灭尽定中没有意识。阿赖耶识执受所依，没有此一妨难。

灭尽定中如果有意识，意识必定是善、不善、无记中的一种。不能是善，因为善心必定与无贪等善根相应，那样善根就现行，想、受也应当随之现行，没有别的原因使想、受单独不起。不能是不善，因为离欲时诸不善根都已永断。不能是无记，因为灭尽定是善。

又，灭尽定中如果有意识，根、境、识三事和合，必定有触；有触就生受，那样灭尽定中只灭了想，不灭受，与圣教“想受俱灭”相违。有触又必有与触俱生的思，思现行，信等善根也应当现行。

如果有人说：灭尽定中只有心，没有心所，也不对。心是所依，心所是能依，从无始以来互不相离，拔出能依、使之离开所依，不合道理。

又有譬喻：世尊说，身行、语行、意行都灭。身行是出入息，语行是寻和伺，意行是思、想等。如同寻、伺灭了，语必定不起；意行灭了，意也应当不起。如果有人说：身行灭了，身仍在，所以意行灭了，意也仍在。也不对，因为身行不是身住的唯一因，身还有饮食、命根、识等住因；离开意行，没有别的因能持心令住。

又，想与受是遍行心所，遍行心所灭了，心也随之灭了；非遍行的心所才可以单独灭去。所以，灭尽定中所说的有心，是异熟识，决定不是意识。

五、破色心无间为种子

又，如果有人主张色与心无间生起，就是诸法的种子，也不能成立，如前已说。又，从无色界、无想天死后，从灭尽定等出定，不合道理。又，阿罗汉的最后心不能成立，前后刹那之间只能容许有等无间缘。

【世亲释】有人主张，前刹那的色是种子，后刹那的色由前刹那的色而生；前识与后识的关系也是如此。依此主张，从无色界死后色再生起时，色早已断灭，哪里有种子？从无想天死后，或从灭尽定等出定，心再生起时，心早已断灭，哪里有心的因？依此主张，诸阿罗汉终究不能证得无余涅槃，因为色与心的因永无尽时。前刹那的色对后刹那的色，前刹那的识对后刹那的识，只能有等无间缘，不能有因缘。

所以，如果离开一切种子异熟果识，杂染和清净都不能成立。所以成立：如前所说之相的阿赖耶识，决定是有。

六、转依三颂

关于转依，有三首颂：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">菩萨于净心<br>远离于五识<br>无余心转依<br>云何汝当作<br>若对治转依<br>非断故不成<br>果因无差别<br>于永断成过<br>无种或无体<br>若许为转依<br>无彼二无故<br>转依不应理</div>

大意：菩萨在出世清净的意识中，已经远离眼等五识，又没有其余有漏的心。在转识上，你如何安立转依？如果说对治生起就是转依，对治不是断，所以不能成立；如果对治就是断，果与因就没有差别，在永断上成为过失。如果说转识没有种子或没有体就是转依，转识的种子与体本来都已不在，无可使之无，所以转依不合道理。

【世亲释】“净心”，是与出世对治相应的善意识。“远离于五识”，是出定位中没有眼等五识。“无余”，是没有其余有漏的杂染意识。如果承认阿赖耶识，使一切杂染种子成为无种子，就称为心的转依；不承认阿赖耶识，转依如何安立？对治只是永断的因，不是永断本身；果是永断，称为涅槃，因是对治，称为圣道；如果对治就是永断，才生起对治，就应当证入涅槃。杂染转识在定位中本来不起，转识的种子也没有可住之处，无可使之无，说转识无种无体就是转依，不合道理。如果有阿赖耶识，杂染转识在定位中不起，转识的种子都住在阿赖耶识中，才能使种子无、使体无而成转依。

七、阿赖耶识的差别

又，阿赖耶识的差别是什么？简略来说，应当了知有三种或四种。

三种，是三种熏习的差别：第一，名言熏习的差别；第二，我见熏习的差别；第三，有支熏习的差别。

【世亲释】名言熏习的差别：比如“眼”的名言熏习，在异熟识中作为眼生起的因，异熟所生的眼以名言熏习为因而生，也称为眼；耳等一切名言的差别也是如此。我见熏习的差别：由于染污意中萨迦耶见的力量，阿赖耶识中有我执熏习生起，以此为因，执自己为我，执别人为他，各有差别。有支熏习的差别：由于善、不善、不动行的力量，在诸趣中流转，有种种差别。

四种：第一，引发的差别；第二，异熟的差别；第三，缘相的差别；第四，相貌的差别。

引发的差别，就是新起的熏习。如果没有引发的差别，“行缘识”“取缘有”就不能成立。

异熟的差别，就是以行、有为缘，在诸趣中的异熟差别。如果没有异熟的差别，就没有种子，后有诸法的生起就不能成立。

缘相的差别，就是作为意中我执所缘之相。如果没有缘相的差别，染污意中我执的所缘就不能成立。

【世亲释】异熟的差别是异熟果，缘相的差别是等流果。

相貌的差别，就是阿赖耶识有共相，有不共相，有无受生种子相，有有受生种子相等。

共相，是器世间的种子。不共相，是各别内处的种子。共相就是无受生种子，不共相就是有受生种子。对治生起时，只有不共相所对治而灭。共相被他人的分别所持，修行者只见到清净，如同瑜伽师对同一物，有种种不同的胜解，种种所见都能成立。关于共相，有两颂：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">难断难遍知<br>应知名共结<br>瑜伽者心异<br>由外相大故<br>净者虽不灭<br>而于中见净<br>又清净佛土<br>由佛见清净</div>

大意：共相难断，难以遍知，应当称为共同的系缚。瑜伽师的心各有不同的胜解，因为外在的器世间广大。已转依的清净者，对器世间不能灭除，能在其中见到清净。又如清净佛土，由于佛的所见，所以清净。

又有一颂，对应前面所引的“种种胜解，种种所见，都能成立”：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">诸瑜伽师于一物<br>种种胜解各不同<br>种种所见皆得成<br>故知所取唯有识</div>

大意：诸瑜伽师对同一物，胜解各不相同，种种所见都能成立，所以可知所取只是识。

如果没有共相与不共相，诸器世间和有情世间生起的差别，就不能成立。

【无性释】共相是器世间的种子，由相似的自业异熟的增上力量，一切能受用者都有相似的器世间影像显现。不共相是各别内处的种子，是我执的所缘，就是各人身中眼等诸处的因。共相是无受生种子，是生起无苦乐、无损益的所依之因，因为器世间本身没有苦乐损益；不共相是有受生种子，是生起苦乐受等所依之因。道谛生起时，只有各别内处的种子灭去。器世间的共相被其余有情的分别所持，不能全灭，修行者在器世间中只见到清净。异生对同一处所，见到淤泥、沙石、瓦砾、高下不平、荆棘与种种污秽；断除了色等分别的如来，见到金银等众宝所成的清净佛土。

又有粗重相和轻安相。粗重相，是烦恼和随烦恼的种子。轻安相，是有漏善法的种子。如果没有粗重相和轻安相，所感异熟“无所堪能”与“有所堪能”的所依差别，就不能成立。

又有有受尽相和无受尽相。有受尽相，是已经成熟异熟果的善、不善种子。无受尽相，是名言熏习的种子，因为名言熏习是无始时来种种戏论流转的种子。如果没有有受尽相和无受尽相，已作的善业、恶业给果之后受用穷尽，就不能成立；新的名言熏习的生起，也不能成立。

【世亲释】如果没有旧的名言熏习，现在的名言也不会有。世间本来没有的，本无而今有，不合道理。

又有譬喻相，就是阿赖耶识以幻、阳焰、梦、眼翳为譬喻。如果没有譬喻相，由于不实遍计的种子，颠倒的所缘相就不能成立。

又有具足相和不具足相。具足一切系缚的人，称为具足相。世间离欲的人，称为损减相。有学的声闻和诸菩萨，称为一分永拔相。阿罗汉、独觉和诸如来，依次称为烦恼障全永拔相，以及烦恼障与所知障全永拔相。如果没有具足相和不具足相，上述次第的杂染与还灭，就不能成立。

八、异熟识唯是无覆无记

为什么善法和不善法能感异熟，异熟果是无覆无记？因为异熟果是无覆无记，与善和不善都互不相违；善与不善则互相违背。如果异熟果是善性或不善性，杂染与还灭就不能成立。所以异熟识只是无覆无记。

【世亲释】无覆，是没有染污。如果异熟果是善或不善，从善又生善，从不善又生不善，生死流转就没有边际。
