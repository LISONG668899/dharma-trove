所知相分第三

一、三相的定义

已经说了所知依，所知相又应当如何看待？所知相简略说有三种：第一，依他起相；第二，遍计所执相；第三，圆成实相。

什么是依他起相？就是以阿赖耶识为种子、虚妄分别所摄的诸识。依他起的诸识是什么？就是身识、身者识、受者识、彼所受识、彼能受识、世识、数识、处识、言说识、自他差别识、善趣恶趣死生识。

其中，身识、身者识、受者识、彼所受识、彼能受识、世识、数识、处识、言说识，由名言熏习的种子而生。自他差别识，由我见熏习的种子而生。善趣恶趣死生识，由有支熏习的种子而生。由于上面诸识，一切界、一切趣中杂染所摄的依他起相，虚妄分别都得以显现。上面诸识都是虚妄分别所摄，以唯识为性，是无所有、非真实之义显现的所依。上述诸识称为依他起相。

【世亲释】十一识的所指如下。身识，是眼等五界。身者识，是染污意。受者识，是意界。彼所受识，是色等六外界。彼能受识，是六识界。世识，是生死相续不断的时间。数识，是算计。处识，是器世间。言说识，是见、闻、觉、知四种言说。自他差别识，是依止身的差别。善趣恶趣死生识，是生死诸趣的种种差别。

【世亲释】“非真实之义”，就是所取。比如所执的“我”，实际上没有，似我显现；“无所有”，所以说“非真实”。依他起是似义显现的所依，就是似义显现的因。

什么是遍计所执相？就是在没有义、唯有识之中，似义显现。

什么是圆成实相？就是在依他起相上，所似现的义相永远没有自性。

【世亲释】遍计所执，比如实际上无我，在识中似我显现。圆成实，比如似我之相永远是无，无我是有。

【译注】“义”，指识外的所取境。

二、诸识皆唯有识，以梦等为喻

身识、身者识、受者识，应当了知就是眼等六内界。彼所受识，应当了知就是色等六外界。彼能受识，应当了知就是眼等六识界。其余的识，应当了知是上述诸识的差别。

又，上述诸识都唯有识，因为都没有义。用什么作譬喻来显示？应当了知以梦等为譬喻。比如在梦中，都没有外在的义，只有识；梦中有种种色、声、香、味、触、房舍、树林、土地、山岳似义的影像显现，梦中都没有义。由梦的譬喻显示，应当随之了知：一切时、一切处都唯有识。“等”字，应当了知还有幻事、诳惑、鹿爱（阳焰）、眼翳等譬喻。

如果醒觉的时候，一切时、一切处也都像梦等一样唯有识，那么从梦中醒来，就觉知梦中都唯有识；醒觉的时候，为什么不能觉知唯有识？真智觉醒的时候，就能觉知唯有识。如同在梦中时，“唯有识”的觉知不生起，从梦中醒来时，“唯有识”的觉知才生起；同样，还没有得到真智觉醒时，“唯有识”的觉知不生起，得到真智觉醒，“唯有识”的觉知才生起。

三、以教与理比知唯识

还没有得到真智觉醒的人，对唯识如何比知？应当由教和理来比知。

教，比如《十地经》中薄伽梵说：“如是三界皆唯有心。”又如薄伽梵在《解深密经》中也如此说。《解深密经》中，慈氏菩萨问世尊：“诸三摩地所行的影像，与能观的心，应当说有差异，还是没有差异？”佛告诉慈氏：“应当说没有差异。为什么？因为影像唯是识。我说识的所缘，唯是识所显现。”慈氏又问：“世尊，如果三摩地所行的影像与能观的心没有差异，为什么心还能取心？”佛说：“慈氏，没有少许法能取少许法。只是心如此生起的时候，就有如此的影像显现。如同以本质为缘，还是见到本质，而说‘我现在见到影像’，又认为离开本质另有所见的影像显现。心也是如此，如此生起的时候，似乎有差异的所见影像显现。”

由上面的教，理也就显现出来。为什么？在定心中，随所观见的青瘀等所知影像，都没有另外的青瘀等事物，只见到自心。由此道理，菩萨对一切识都应当比知：都唯有识，没有境界。又，在观青瘀等的时候，并不是忆持之识，而是见到所缘境现前安住。闻所成、思所成两种忆持之识，也以过去为所缘，所显现的影像得以成立唯识。由上面的比量，菩萨即使还没有得到真智觉醒，对唯识也应当可以比知。

【世亲释】定中所见的青瘀等影像，不是忆持之识，因为忆持之识所见暗昧，定中影像分明现前。如果有人说，如同闻慧、思慧，由于串习，境界已经过去，一作意就如昔而生，定中影像也是如此；那么闻慧、思慧的境界已经过去，现在没有体，在没有体的境上生起，只是识的影像似境而生，所以唯识更加彰显。

四、有色诸识为什么似色显现

上面已经以梦等为喻说明了种种诸识。在诸识之中，眼识等识可以成立唯识；眼等诸识既然是有色的，也唯有识，应当如何理解？也如前面一样，由教和理来理解。

如果眼等诸识的体也是识，为什么似色性显现，以同一类相、坚住相续而转？因为有色诸识是颠倒等诸杂染法的依处。如果诸识不似色显现，在非义之中执为义的颠倒就不应有；没有颠倒，烦恼障、所知障两种杂染就不应有；没有两种杂染，诸清净法也应当没有。所以诸识应当如此而转。关于有色诸识，有一颂：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">乱相及乱体<br>应许为色识<br>及与非色识<br>若无余亦无</div>

大意：迷乱的相，应当承认是色识；迷乱的体，应当承认是非色识。如果没有色识，其余的非色识也就没有。

【世亲释】“乱相”就是迷乱的因，以色识为体；“乱体”就是诸非色识。作为迷乱之因的色识如果没有，作为果的非色识也就没有。

五、诸识差别而转的原因

为什么身识、身者识、受者识、所受识、能受识，在一切身中都俱有和合而转？因为能圆满地显示受生与受用。

为什么如上所说，世识等诸识差别而转？因为从无始时来生死流转没有断绝；诸有情界没有数量；诸器世界没有数量；诸所作事展转言说没有数量；各别摄取受用的差别没有数量；诸可爱、不可爱业果异熟的受用差别没有数量；所受的死生种种差别没有数量。

六、三相成立唯识

又，如何安立上述诸识成为唯识性？简略由三相：第一，由唯识，因为没有义；第二，由二性，因为有相识、见识两种差别；第三，由种种，因为种种行相而生起。

所以如此的理由是：一切识都没有义，所以成立唯识。有相与见，所以成立二种：比如眼等识，以色等识为相，以眼识识为见，乃至以身识识为见；意识以从眼到法的一切诸识为相，以意识识为见。因为意识有分别，似一切识而生起。关于唯识，有一颂：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">唯识二种种<br>观者意能入<br>由悟入唯心<br>彼亦能伏离</div>

大意：唯识、二性、种种，修观者的意能够悟入。由于悟入唯心，对外境也就能够伏除远离。

【世亲释】意识的所取境界不决定，其余诸识的境界各有决定，又没有分别；意识有分别，所以只在意识上安立第三“种种”的相与见，意识具足安立唯识的三相。悟入唯有心、都没有义，就能伏离外境；所取义既然没有，又哪里有能取心？

七、一意识师的主张

又，在唯识之中，有一类论师说：只有一个意识，依于不同的根而转，得到不同的名称，如同意思业称为身业、语业。

又，意识依一切所依转起的时候，似种种相，有两种影像转起：就是唯义的影像和分别的影像。又在一切处，也似所触的影像而转，因为在有色界中，意识依止身体，如同其余的色根依止身体。

【世亲释】一个识的一分显现为义的影像，另一分是分别义的影像，所以意识依眼等转起也能有分别。在定中没有五识的时候，意识在身中似所触而生起。意识依止身体，所以能对身体作损益，如同身根依止身体，有外触现前时，能对所依身作损益。

关于一意识，有一颂：

<div class="dt-verse" style="margin:0.8em 0 0.8em 2em;line-height:1.9;white-space:normal;overflow-wrap:anywhere;">若远行独行<br>无身寐于窟<br>调此难调心<br>我说真梵志</div>

大意：心能远行，独行无伴，没有形体，寄寐于身窟之中。能调伏难调之心的人，我说是真正的梵志。

【世亲释】“远行”，因为心能缘一切所缘境。“独行”，因为心没有第二个。“无身”，因为心远离形体。“寐于窟”，因为心居住在身窟之中。“调此”，是使心得自在。“难调心”，因为心性暴恶。

又如经中所说：上述五根所行的境界，意都能领受，意是五根的所依。

又如所说的十二处中，六识身都称为意处。

八、阿赖耶识上安立相识与见识

如果安立阿赖耶识识为义识，应当了知其余的一切识都是阿赖耶识的相识，意识识及其所依止是阿赖耶识的见识。因为相识是见识生起的所缘相，在似义显现时，能作为见识生起的依止事。以上称为安立诸识成为唯识性。

【世亲释】在阿赖耶识上也能安立相与见两种识：意识及其所依止的染污意是见识，眼等诸识是相识，因为一切法都是识。相识作为所缘，是见识生起之因，使见识得以相续不断地安住。

九、四法悟入一切唯识

诸义现前分明显现，并不是实有，应当如何了知？如世尊所说：诸菩萨成就四法，就能随之悟入一切唯识、都没有义。

第一，成就相违识相智。比如饿鬼、傍生、诸天、人类，对同一事物，所见所识各不相同。

第二，成就无所缘识现可得智。比如对过去、未来、梦境、影像的缘虑中，识有所得。

第三，成就应离功用无颠倒智。比如在有义的情况下，能缘义的识应当无颠倒，不由功用，因为所知真实。

第四，成就三种胜智随转妙智。三种胜智是什么？其一，得心自在的一切菩萨与得静虑的人，随胜解的力量，诸义就随之显现。其二，得奢摩他、修法观的人，一作意时诸义就显现。其三，已得无分别智的人，无分别智现在前时，一切诸义都不显现。

由上面所说的三种胜智随转妙智，以及前面所说的三种因缘，诸义无义的道理得以成就。

【世亲释】“应离功用无颠倒智”的意思是：如果义如所显现的那样真实存在，不需要修起对治，无颠倒智就应当自然而成。“无分别智现前时一切诸义都不显现”的意思是：如果义如所显现的那样真实存在，就不应当有无分别智；无分别智既然真实存在，就决定应当承认诸义都无。
