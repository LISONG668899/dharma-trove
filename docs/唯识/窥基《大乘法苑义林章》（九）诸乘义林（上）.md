<div class="dt-subtitle">大乘法苑义林章白话译注（九）<br>唐　窥基　撰</div>

〔译注：《诸乘义林》是全书第四章，讨论一乘、二乘、三乘、四乘、五乘的开合，以及《法华经》一乘与《胜鬘经》一乘的异同。这是唯识宗"五性各别""一乘方便"立场的代表性论述。原文约五千字，分两篇。本篇译前三门：明增减、辨体性、释名字。〕

乘的意义，简略地用五门来分别：

1. 说明乘数的增减
2. 辨明乘的体性
3. 解释名字
4. 彰显废立的理由
5. 问答抉择

第一门　说明乘数的增减

一、说一乘

《法华经》说：「十方佛土中，唯有一乘法。」（大意：十方的佛国土中，只有一乘法。）

《胜鬘经》说：「摩诃衍者，出生一切声闻、缘觉世间、出世间善法。」（大意：大乘出生一切声闻、缘觉的世间善法和出世间善法。）乃至又说：「声闻、缘觉乘皆入大乘，大乘者即是佛乘，是故三乘即是一乘。」（大意：声闻乘、缘觉乘都归入大乘，大乘就是佛乘，所以三乘就是一乘。）又说：「若如来随彼所欲而方便说，即是大乘，无有二乘。二乘者入于一乘，一乘者即第一义乘。」（大意：如来随着众生的意欲方便宣说，那就是大乘，没有二乘；二乘归入一乘，一乘就是第一义乘。）

《辩中边论》第三卷《无上乘品》，广说一乘的差别有三种：

1. 正行无上
2. 所缘无上
3. 修证无上

详如该论所说。

《显扬圣教论》第二十卷，说佛以六种原因宣说一乘，不超出《摄大乘论》所说的十种原因。《摄大乘论》第十卷，说佛以十种原因的意义宣说一乘，下面再解释。

二、说二乘

世亲菩萨的《摄大乘论释》开头说："上乘和下乘有差别。"

《涅槃经》又说：「为声闻乘而说半字，为菩萨乘而说满字。」（大意：为声闻乘宣说半字教，为菩萨乘宣说满字教。）又说："一是大乘，二是声闻乘。"

《成唯识论》《摄大乘论》中成立"大乘是真佛语"的地方，都有这样的文句。二乘也称为大乘、小乘。

三、说三乘

《涅槃经》说，比如病人有三种：

1. 遇到良医也好，遇不到也好，决定能够痊愈。
2. 遇到良医就痊愈，遇不到就不能痊愈。
3. 遇到良医也好，遇不到也好，决定不能痊愈。

经中以大乘为第一种，二乘为第二种，无种性者为第三种。

又有一种三乘：菩萨乘、独觉乘、声闻乘。所以契经说：「为求菩萨者，说应六波罗蜜法；乃至为求声闻者，说应四谛法。」（大意：为求菩萨道的人，宣说相应的六波罗蜜法；乃至为求声闻道的人，宣说相应的四谛法。）三乘的经文处处都有，不止一处。

四、说四乘

《胜鬘经》说：摄受正法的善男子、善女人，荷负四种重担：

1. 对于离开善知识、没有听闻正法、行非法的众生，以人天善根来成熟这些众生。
2. 对于求声闻的人，授予声闻乘。
3. 对于求缘觉的人，授予缘觉乘。
4. 对于求大乘的人，授予大乘。

《大般若经》第十六会中，善勇猛菩萨请求说：「唯愿世尊哀愍我等，为具宣说如来镜智。」（大意：唯愿世尊哀愍我们，为我们完整宣说如来的镜智。）请求的理由是：

1. 如果有情对声闻乘性决定，听闻此法以后，能迅速证得自乘的无漏地。
2. 对独觉乘性决定的，听闻此法以后，能迅速依自乘而得出离。
3. 对无上乘性决定的，听闻此法以后，能迅速证得无上正等菩提。
4. 如果有情还没有证入正性离生，对三乘的种性不决定，听闻此法以后，都发起无上正等觉心。

"唯愿世尊为答所问。"

五、说五乘

前三乘如前面所说，第四是人乘，第五是天乘。《善戒经》等说：「无种姓人，无种姓故，唯以人天善根而成就之。」（大意：没有种性的人，因为没有三乘种性，只以人天善根来成就这类人。）

另外，《称赞大乘功德经》和十卷本《楞伽经》第八卷也说五乘：三乘如前，第四是种种姓乘，也就是不定种性；第五才是人天乘。

第二门　辨明乘的体性

一、大乘的体性

总的来说，教、理、行、果，总名为乘。

（一）教大乘

教大乘，是诠释、随顺大乘的三藏教法。

1. 根本教大乘。《摄大乘论》说"阿毗达磨大乘经"等，这是正本的教大乘。
2. 方便教大乘。《法华经》说：「我此九部法，入大乘为本。」（大意：我所说的九部法，是进入大乘的根本。）又，《胜鬘经》说：正法住、正法灭、波罗提木叉、毗尼、出家、受具足戒，是为大乘而说这六处。这是方便教大乘。

所以可知，诠释、随顺大乘的所有言教，无论方便还是根本，都是教大乘。

（二）理大乘

理大乘，是真如之理。六度等行，乘这个真如之理，能有所趣往，称为大乘。所以无性菩萨说："或者乘大性，所以名为大乘。"这只举出根本的理大乘。

其次是方便的理大乘：

1. 《胜鬘经》说：「圣谛者，非声闻、独觉谛，亦非声闻、独觉功德。」（大意：圣谛不是声闻、独觉的谛理，也不是声闻、独觉的功德。）
2. 《法华论》说：所谓念观，声闻观人无我，菩萨观真如二无我等。
3. 《涅槃经》也说：「声闻有苦有谛，而无有实；菩萨具有。」（大意：声闻有苦，有谛，没有真实；菩萨三者都具有。）

所以大乘的方便四谛理等，都是理大乘。

（三）行大乘

行大乘，是六度等。所以无性菩萨说："也是乘，也是大，所以名为大乘。"

1. 《胜鬘经》说正法住等六处，既然是行法，就称为大乘。
2. 《法华论》说：所谓方便，声闻观察蕴、界、处，厌苦离苦；菩萨修六度、四摄、自他二利，这就是随顺大乘。

无论根本行还是方便行，都称为行大乘。

（四）果大乘

果大乘，是佛的菩提和涅槃果法。

1. 《法华经》说：「说佛智慧故，诸佛出于世。唯此一事实，余二则非真。」（大意：为了宣说佛的智慧，诸佛出现于世间。只有这一件事是真实的，其余的二乘不是真实的。）
2. 《法华经》又说：「是法住法位，世间相常住。于道场知已，导师方便说。」（大意：这个法安住于法位，世间相常住不变。导师在道场中了知以后，以方便宣说。）
3. 《胜鬘经》说："二乘就是一乘。"
4. 《法华经》又说："为了让众生休息，所以说二乘。"
5. 《法华经·寿量品》说佛成道已经很久，这是报身佛。
6. 经中说"不如三界见于三界"，这是法身。

所以菩提、涅槃都是果大乘。《胜鬘经》又说：二乘的涅槃，称为趣向涅槃界；说二乘的四智究竟，得到休息之处，这是佛的有余说、不了义说。所以无论是根本果，还是随顺的果，都称为大乘。

〔存疑：「安乐行品说不如三界见于三界是法身」，"不如三界见于三界"一语出自《法华经·如来寿量品》，原文标为《安乐行品》，或为传写之误；此处依义翻译，不标品名。〕

（五）大乘体性的范围

在有为法中，通于现行和种子，以及各种随顺的有漏善法，也就是从善法欲以后的闻、思等行，连同无为法，都是大乘的乘体。

二、二乘的体性

大乘的体性如前面所说。

声闻乘的体性，是合声闻、独觉二乘所有的、从三归依以后随顺出世的有漏五蕴，以及随其所应的教、理、行、果，作为体性。

所以《瑜伽师地论》第六十四卷说：声闻乘的证得，以先受归依等作为原因，有五种证得：

1. 地证得：见地、修地、究竟地三地。
2. 智证得：九智，就是法智、类智，四谛智，以及之后所得的世俗智、尽智、无生智。
3. 净证得：四证净。
4. 果证得：四沙门果。
5. 功德证得：四无量、八胜处，乃至神通等。

所以可知，教、理、行、果，都是乘的体性。这部论说的证得，简略了见道以前的阶段；依照实际来说，归依以后都是乘的体性。

声闻乘只有根本，没有方便乘，因为声闻乘是最下的乘。即使有不定种性的声闻，对声闻乘来说是退出，所以不作为声闻乘的因。

《瑜伽师地论》又说独觉的证得，略有三种：

1. 先前已经得到顺决择分善根，而证得独觉果。
2. 先前已经得到证得，而证得独觉果。
3. 先前没有得到证得，而证得独觉果。

前两种证得称为"独胜"，最后一种称为"麟角喻"。所以独觉的根本法和方便法，教、理、行、果都是乘的体性。

因为把独觉和声闻合起来总称为声闻乘，所以这里列出两种乘的体性。

《法华经》中，以果来说三乘。一乘之因称为"门"，因为只有一扇门，并且门又狭小。二乘之因称为"衣裓、机案"，因为从宅舍中出来，随便怎么出来都可以，并不依靠门。

三、三乘的体性

如果分别来说：

1. 四谛的教、理、行、果，都是声闻乘。
2. 十二缘起的教、理、行、果，都是独觉乘。
3. 大乘如前面所说。

这样就有差别。有的经论把大乘说为菩萨乘，因为菩萨能自运，又能运他。《法华经》只说为佛乘，因为三乘相互比较，佛自己乘这个乘，只是广泛运载他人。如果称为大乘，就包括因和果。

四、四乘、五乘的体性

1. 《胜鬘经》的四乘。第四乘以人天善根、福分的有漏闻思修的现行和种子，三归、五戒、八戒、十善等的教、理、行、果，作为体性，因为果是因的眷属。如果从运载的意义说，人天的果就不是乘。其余三乘如前面所说。
2. 《大般若经》的四乘。种性具足的多少有差别，教等没有差别。只以根本法为三乘，连同方便法作为第四乘。
3. 《楞伽经》等的五乘。合人、天为一乘；开出不定种性，在三乘之外另立一乘。因为通与别不同，种性不同，乘的体性没有差别。合人、天为一，是因为人、天同是有漏法，根和种子相齐。
4. 另一种五乘。以通从别，把不定种性合入三乘，因为不定种性所趣向的不同；开人、天为两乘。乘的体性没有差别。

第三门　解释名字

〔译注：本门用"六合释"分析各乘的名称。持业释，前后两词指同一事物，如"乘即无上"；依主释（依士释），前词限定后词，如"声闻的乘"；带数释，带有数字；有财释，整个复合词指拥有这种性质的另一事物。〕

一、一乘，是带数释。

二、大乘，下面解释。

三、无上乘，乘就是无上，是持业释。

四、二乘中的下乘、上乘，依主释、持业释两种解释都可以，因为根机和教法都有上下。

五、二乘又称为大乘和声闻乘。声闻乘是"声闻的乘"，是依主释。

六、《法华经》说："终不以小乘法济度于众生。"这是翻译家译为"小乘"，梵本作"声闻"。或者也可以依照梵本说为"小"，这是把其余两乘摄在一起，相互比较而立名，也通于两种解释。

七、大乘之名，兼含佛和菩萨。

1. 也是大，也是乘，都是持业释。
2. 或者"乘于大性"，是有财释。
3. 或者是依主释。

次第可知。

八、三乘的名称中，有的说为佛乘，有的说为菩萨乘。

1. 菩萨乘：自运、运他，能前往所要到达之处，称为菩萨乘。
2. 佛乘：只运他，不自运，因为已经到达所要到达之处，体性和作用弘大广博，所以称为佛乘。想要让二乘趣向究竟的佛果，所以用"佛乘"作为名称。

这两种都是依主释。如果称为大乘，就兼含因和果。《法华经》中多就佛果称为大乘，因为要化导二乘趣向佛位这个究竟果。《胜鬘经》等都称为大乘。

九、三乘中的声闻乘、独觉乘，都是依主释，因为是"声闻的乘""独觉的乘"。

十、大乘通于持业释和依士释：

1. 持业释：也是乘，也是大。
2. 依士释：乘于大性，是"大的乘"，这是无性菩萨的说法。
3. 或者不可以作有财释，因为"大"不是能运载的。
4. 或者以"大"作为所乘，也可以作有财释。不过前一种解释比较好，因为"大"不是能运载的。

十一、《胜鬘经》中所说的四乘，第一称为人天乘，是"人天的乘"，也是依士释。

十二、《大般若经》中，第四种是种种姓乘，是"种种姓的乘"，也是依士释。

两经中其余三乘的名称，与前面相同。

十三、大乘如果称为无上乘，乘就是无上，是持业释。
