<p class="dt-title">十一善心所</p>

<div class="dt-subtitle">成唯识论白话译注（十六）　卷第六之上<br>护法等菩萨造　唐　玄奘译</div>

本篇要目：一、第十一颂　二、信　三、惭与愧　四、无贪、无瞋、无痴　五、精进　六、轻安　七、不放逸　八、行舍　九、不害　十、颂中“及”字所含的其余善心所　十一、善心所的假实　十二、善心所遍与不遍　十三、善心所与诸识、诸受

一、第十一颂

前面已经说完遍行和别境两位。外人质问：善位心所的相状是怎样的？世亲菩萨用颂回答：

```
善谓信惭愧　无贪等三根
勤安不放逸　行舍及不害
```

大意：善心所有信、惭、愧、无贪、无瞋、无痴三善根、精进、轻安、不放逸、行舍、不害。

论中解释：只与善心俱起的，称为善心所，就是信、惭等，决定有十一种。

二、信

什么是信？对于实有、有德、有能，深深地忍可、喜乐、希欲，令心清净，是信的自性；对治不信，喜乐善法，是信的作用。

信的差别，大略有三种。第一是信实有：对诸法真实的事和理，深信忍可。第二是信有德：对三宝真实清净的功德，深信喜乐。第三是信有能：对一切世间和出世间的善法，深信有力量能够得到、能够成就，生起希望。由此对治不信之心，爱乐证得和修习世间、出世间的善法。

“忍”是胜解，是信的因。“乐欲”是欲，是信的果。

【译注】信的三个对象，各配一种心态：对实有的事理是“忍可”，即认定为真；对三宝的功德是“喜乐”，即心生欢喜；对善法的力量是“希欲”，即想要得到。忍可在前，是信的因；希欲在后，是信的果；信本身，是中间那一份清净。

外人质问：请确切说明信的自相是什么。论主回答：刚才不是已经说了，心净为自性吗？

外人质问：“心净”的意思还不明了。如果“净”就是心，信就不应是心所。如果“净”是令心清净，信与惭等有什么区别？以“与心同时的清净之法”来解释，同样有与惭等无别的难题。

论主回答：信的体性澄清，能令心等清净。因为心最为殊胜，所以立“心净”的名称。

```
如水清珠，能清浊水。
```

大意：如同澄水的宝珠，放入浊水，能令浊水变清。

惭等心所是善，并不以清净为相；信以清净为相，所以没有与惭等混淆的过失。

一切染法各有自己的相，唯有不信的自相浑浊，又能令其余的心王与心所浑浊，如同极其污秽的东西，自己污秽，又污秽别的东西。信正好与不信相反，所以以清净为相。

有人说：信以爱乐为相。论主破斥：照此说法，信就应通于三性，信的体就应是欲；苦谛和集谛就不应是信的所缘。

有人执着：信以随顺为相。论主破斥：照此说法，信也应通于三性，就是胜解或欲。如果是印可随顺，就是胜解；如果是喜乐随顺，就是欲。离开胜解和欲，没有随顺的相。

由此应知，心净才是信。

三、惭与愧

什么是惭？依自身和正法的力量，崇重贤人和善法，是惭的自性；对治无惭，止息恶行，是惭的作用。依自身和正法的尊贵增上，崇重贤人和善法，羞耻过失和恶行，对治无惭，止息一切恶行。

什么是愧？依世间的力量，轻视拒斥暴恶，是愧的自性；对治无愧，止息恶行，是愧的作用。依世间诃斥厌弃的增上，轻视拒斥暴恶，羞耻过失和罪行，对治无愧，止息一切恶业。

【译注】惭是向内看：想到自己的人格和所学的正法，不屑作恶，所以“崇重贤善”。愧是向外看：想到世人的诃责，不敢作恶，所以“轻拒暴恶”。两者方向相反，所缘相同。

羞耻过失和恶行，是惭与愧共通的相，所以诸圣教假说羞耻为惭愧的体。

如果执着羞耻是惭与愧各自的相，惭与愧的体就应没有差别，惭与愧就决定不能相应，因为受、想等心所之间没有体相同而相应的道理。

如果说依顾自己和顾他人而立惭愧二者的差别，惭愧就应不是实有，就违背了圣教所说惭愧实有。如果承认惭愧是实有，又各别生起，就又违背了论中所说“十种善心所遍于一切善心”。

对方反问：崇重和轻拒如果是惭愧各自的相，惭愧的所缘不同，就不应同时俱起。两种过失既然相同，为什么只责难我们？

论主回答：谁说惭愧的所缘不同？

对方反问：不然又是怎样？

论主回答：善心生起时，无论缘取什么境，都有崇重善和轻拒恶的含义，所以惭与愧都遍于一切善心，所缘没有区别。

对方反问：难道我们的说法不也有遍缘善恶的含义？

论主回答：你们执着惭与愧的自相相同，凭什么道理能遮除前面所设的责难？

圣教说惭愧是“顾自他”，“自”指自身和正法，“他”指世间。或者，崇重善、轻拒恶，对自己有益，称为“自”；对他人有益与损害，称为“他”。

四、无贪、无瞋、无痴

颂中“无贪等”的“等”，等取无瞋和无痴。无贪、无瞋、无痴称为善根，因为生起善法最为殊胜，又是贪、瞋、痴三不善根的正对治。

什么是无贪？对三有和三有之因，不染着，是无贪的自性；对治贪着，造作善行，是无贪的作用。

什么是无瞋？对苦和苦之因，不恚恨，是无瞋的自性；对治瞋恚，造作善行，是无瞋的作用。

【译注】依《述记》：“有”指三界的果报，“有具”指感生三界的业和烦恼。“苦”指苦果，“苦具”指令人受苦的种种事物。

善心生起时，无论缘取什么境，对三有等都不染着、不恚恨。无贪和无瞋是依对三有等的态度而立，不一定以三有等为所缘，如同前面惭和愧依对善恶的态度而立。所以无贪和无瞋都遍于一切善心。

什么是无痴？对一切道理和事相明了通达，是无痴的自性；对治愚痴，造作善行，是无痴的作用。

关于无痴的体，论中列出两家。

第一家认为：无痴以慧为体。《集论》说，无痴以报得、教得、证得的智慧和抉择为体，生得慧、闻所生慧、思所生慧、修所生慧，依次都是抉择的性质。无痴就是慧，为了显示无痴在善法中有殊胜的功能，如同烦恼中的见，所以另外说明。

第二家，即护法论师，认为：无痴不就是慧，另有自性，正对治无明，如同无贪和无瞋，属于善根。

护法论师的理由如下。论中说大悲属于无瞋和无痴，不属于善根。如果无痴以慧为体，大悲就如同十力等，应属于慧根，而不属于无痴。如果无痴没有另外的自性，就应如同不害等，不是实物，就违背了论中所说“十一种善心所中三种是世俗有，其余都是实有”。

《集论》说无痴以慧为体，是举出无痴的因和果，显示无痴的自性，如同以忍可和乐欲表示信的自体。在道理上必定如此。贪、瞋、痴与六识相应，属于真正的烦恼，生起恶行最为殊胜，所以立为不善根。断除不善根，必定依靠通对治和别对治。通对治只是善慧，别对治就是三善根。由此，无痴必定另有自性。

五、精进

勤就是精进。对修善与断恶的事，勇敢精纯，是精进的自性；对治懈怠，圆满善法，是精进的作用。

“勇”表示殊胜前进，用以简别一切染法；“悍”表示精纯，用以简别清净的无记。由此显示精进只属于善性。

【译注】为恶事努力，不称为精进，所以用“勇”字简别；为无记事努力，如学技艺，也不称为精进，所以用“悍”字简别。精进只指向善法的努力。

精进的差别，大略有五种：被甲精进、加行精进、无下精进、无退精进、无足精进。就是经中所说的：有势、有勤、有勇、坚猛、不舍善轭，依次对应。

【译注】被甲：如披上铠甲，先发大誓愿。加行：誓愿之后，真正动手修行。无下：不自轻自贱。无退：遇苦不退。无足：不满足于少分成就。

五种精进的区别，有几种解释。第一种：依初发心、自分行、胜进行而分，自分行中又有上中下三品的差别。第二种：依初发心、长时修、无间修、殷重修、无余修的差别而分。第三种：依资粮、加行、见、修、究竟五道的差别而分；二乘的究竟道欣求大菩提，诸佛的究竟道乐于利乐他人。第四种：依两种加行、无间道、解脱道、胜进道的差别而分。

六、轻安

安就是轻安。远离粗重，调和舒畅身心，堪能任事，是轻安的自性；对治惛沉，转换所依，是轻安的作用。轻安伏除障碍禅定的法，令所依的身心转为安适。

七、不放逸

不放逸，就是精进和三善根，对所应断的恶、所应修的善，防恶修善，是不放逸的自性；对治放逸，成就圆满一切世间与出世间的善事，是不放逸的作用。精进和三善根四法，对断恶修善的事，都能防恶修善，称为不放逸。不放逸没有另外的体，因为没有不同的相。在防恶修善中，离开四法的功能，没有另外的作用。

外人质问：信、惭等也有防恶修善的功能。论主回答：信等比起精进和三善根，势用微弱；信等不是善根，也不普遍策励，所以不是不放逸的所依。

外人质问：防恶修善难道不就是不放逸的相和作用？防恶修善与精进和三善根有什么不同？

外人辩解：精进和三善根要依靠不放逸，才有防恶修善的作用。论主回答：不放逸就也应再依靠别的心所，便有无穷的过失。

外人辩解：精进只是普遍策励，三善根只是所依，怎能说精进和三善根有防恶修善的作用？

论主反问：你们所说不放逸的防恶修善作用，相状是怎样的？

如果是普遍依持，就是无贪等三善根。如果是普遍策励，就与精进没有区别。如果是止恶进善，就是精进与三善根四法的总和。如果是令心不散乱，就应是等持。如果是令心等同取一境，与触有什么区别？如果是令心不忘失，就应是念。如此推寻，不放逸的作用，离开无贪等终究找不到。所以不放逸决定没有另外的体。

【译注】说一切有部立不放逸为实有的大善地法，论主在此逐一排除，证明不放逸只是四法合力的假名。

八、行舍

什么是行舍？精进和三善根，令心平等、正直、无功用而住，是行舍的自性；对治掉举，令心静住，是行舍的作用。

精进和三善根四法，令心远离掉举等障碍，静住，称为舍。平等、正直、无功用而住，是依初、中、后三个阶位分辨舍的差别。

【译注】初位令心平等，离开沉掉；中位令心正直，离开偏曲；后位令心无功用而住，不需刻意用力。三个阶位层层深入。

由不放逸先除去杂染，舍再令心寂静而住。行舍如同不放逸，没有另外的体，因为离开四法，行舍没有自己的相和作用。能令心寂静的，就是四法；被令寂静的，就是心等。

【译注】“行舍”的“行”指行蕴，以区别于受蕴中的舍受。行舍是一种平衡的心态，舍受是一种不苦不乐的感受。

九、不害

什么是不害？对一切有情不加损恼，以无瞋为自性；能对治害，以悲悯为作用。

不害就是无瞋，对有情不加损恼，假名为不害。

无瞋，正对治断除众生性命的瞋；不害，正对治损恼众生的害。无瞋给予快乐，不害拔除痛苦。以上是无瞋与不害粗显相状的差别。

实际上，无瞋有实在的自体，不害依无瞋的一分假立，是为了显示慈与悲两种相状的区别，因为利乐有情，慈与悲最为殊胜。

有人说：不害不就是无瞋，另有自体，就是贤善之性。论主反问：贤善之性的相状是怎样的？对方回答：就是不损恼。论主回答：无瞋也是如此，怎能另有自性？对有情不加损恼、慈悲贤善，就是无瞋。

十、颂中“及”字所含的其余善心所

颂中的“及”字，显示十一种善心所之外，还有意义不同的心所，就是欣、厌等善心所。欣、厌等善心所意义有区别，说了种种名称，体并无不同，所以不另外立。

欣，与欲俱起，是无瞋的一分，对所欣求的境不憎恚。不忿、不恨、不恼、不嫉等也是如此，各随其所应，正对治瞋的一分。

厌，与慧俱起，是无贪的一分，对所厌离的境不染着。不悭、不憍等也是如此，各随其所应，正对治贪的一分。

不覆、不诳、不谄，是无贪和无痴的一分，各随其所应，正对治贪和痴的一分。有一家认为：不覆只是无痴的一分，因为没有地方说覆也是贪的一分。

不慢，有三家主张：第一家认为属于信的一分，因为相信对方，就不会轻慢对方；第二家认为属于舍的一分，因为心平等的人不会高慢；第三家认为属于惭的一分，因为崇重对方，就不会轻慢对方。

不疑，有三家主张：第一家认为属于信，因为相信对方就没有犹豫；第二家认为就是正胜解，因为决定的人没有犹豫；第三家认为属于正慧，因为有正见的人没有犹豫。

不散乱，体就是正定。正见和正知，都属于善慧。不忘念，就是正念。悔、眠、寻、伺通于染和不染，如同触、欲等，没有相对的善心所。

外人质问：为什么染法所对治的善法中，有的另外建立，有的不另外建立？

论主回答：相状和作用不同的，就另外建立；其余的善法相状作用并无不同，所以不应责难。另外，遍于六识的染法，力量殊胜，所以对治染法而另立善法。慢等和忿等只与意识俱起，所以不另立。害也只与意识俱起，害常常现起，损恼他人，又障碍无上乘的殊胜之因，即大悲。为了让人了知害的严重过失，对治害而立不害。失念、散乱、不正知，对治的善法归入别境，善法中不说。

外人质问：染法与净法相对，净法为什么比染法少？

```
净胜染劣，少敌多故。
```

大意：清净法殊胜，染污法低劣，以少数就能对敌多数。

另外，悟解真理的心通达，所以说多种善法同一体；迷情执事的心局限，所以随相状分为多种染法。所以对染法与净法，不应要求数目相等。

十一、善心所的假实

十一种善心所中，三种是假有，就是不放逸、行舍、不害，意义如前所说。其余八种是实有，因为相状和作用各不相同。

十二、善心所遍与不遍

关于十一种善心所是否遍于一切善心，论中列出四家。

第一家认为：十一种善心所中，四种遍于善心，就是精进和三善根，因为四法遍于一切善品。其余七种不一定。推寻事理还没有决定时，不生起信。惭与愧同类，所依之处各别，生起一种时就没有第二种。要在以世间道断除烦恼时才有轻安。不放逸和行舍，要在无漏道时才生起。悲悯有情时，才有不害。论中说十一种善心所在六个阶位中生起：在决定位，有信相应；在止息染污时，有惭愧生起，因为顾及自他；在善品位，有精进和三善根；在世间道时，有轻安生起；在出世道中，有行舍和不放逸；在摄受众生时，有不害。

第二家认为：第一家的说法不合道理。推寻事理还没有决定的心，如果不生起信，就不应是善，如同染心等没有清净的信。惭与愧种类不同，所依不同，所缘相同，都遍于一切善心，前面已经说过。如果出世道中不生起轻安，轻安觉支就不应是无漏。如果世间道中没有行舍和不放逸，世间道就不应寂静、防恶修善，也不应能伏除掉举和放逸。有漏的善心既然具足四法，如同出世道，也应有不放逸和行舍。善心生起时都不损害众生，因为违背能损害的法，所以有不害。论中说十一种善心所在六个阶位中生起，是依各阶位中某些心所增盛而说。

第二家立义：信等十一法中，十种遍于一切善心，轻安不遍，要在定位才有轻安，因为调和舒畅身心，其余阶位没有。《瑜伽师地论·摄抉择分》说，十种善心所在定地和不定地都遍于善心，定地的心中增加轻安。

第三家认为：定的加行也可以称为定地，加行中也稍有调和舒畅的意义，由此欲界也有轻安。不然的话，就违背了《本地分》所说“信等十一种善心所通于一切地”。

第四家认为：轻安只在定中才有，因为由定的滋养才有调和舒畅。论中说，欲界的一切心王与心所，由于缺少轻安，称为不定地。说“一切地都有十一种”，是指有寻有伺等三地都有。

【译注】“三地”指有寻有伺地、无寻唯伺地、无寻无伺地，是以寻伺的有无划分的三界九地。

十三、善心所与诸识、诸受

十一种善心所在第七、第八识中随阶位有无，前面已经详说。在第六识中，在定位十一种都具足；不在定位，只缺轻安。

关于五识，有两家主张。第一家认为：五识只有十种善心所，因为五识自性散动，没有轻安。第二家认为：五识也有轻安，因为由定所引生的善五识也有调和舒畅，与成所作智俱起的五识必定有轻安。

外人质问：十一种善心所与哪些受相应？论主回答：十种与五受都相应，只有轻安除去忧和苦，因为有逼迫的受就没有调和舒畅。

善心所与别境心所都可以相应，因为信等与欲等不相违背。十一种都只是善性。轻安不在欲界，其余十种通于三界。十一种都通于有学、无学、非学非无学三种。十一种都不属于见道所断。《瑜伽师地论》说信等六根只属于修道所断，不属于见道所断。其余诸门的分别，应依道理思考。
