<p class="dt-title">三身义林（一）·辨名与出体</p>

<div class="dt-subtitle">大乘法苑义林章白话译注（四十八）<br>唐　窥基　撰</div>

〔译注：从这一篇进入卷七。《三身义林》是全书第二十八章，篇幅很长，分四篇翻译：本篇译第一门"辨名"、第二门"出体"；第二篇译第三门"开合废立"；第三篇译第四门"因起果相"；第四篇译第五门"诸门分别"。出体一门列举关于三身体性的六种说法，窥基最后判定：前三种说法义理相违，后三种说法都没有谬误。〕

三身的意义，略用五门分别：

1. 辨名
2. 出体
3. 开合废立
4. 因起果相
5. 诸门分别

第一门　辨名

一、经中的三身名称

《佛地经》说："自性、法受用、变化，差别而转。"

《金光明经》第二卷《三身品》说："一切如来有三种身：一是化身，二是应身，三是法身。这样的三身，摄受无上正等正觉。"

二、自性身

《佛地论》说："自性，就是第一种自性身。"体性常住不变，称为自性身。《成唯识论》说："自性身是一切法平等的真实体性。"无性《摄大乘论释》第九卷说："自性身不是假立的，所以称为自性。自性身不像其余的身由合集而成。自性身是所依止，所以称为身。"自性就是身，是持业释。

自性身也称为法身，"法性"有两种解释：

1. "法"指差别的各种功德义，"性"指本体，是义的体，所以称为法性。无性《摄大乘论释》解释说："法性就是身，所以称为法身。"
2. "法"就是各种有为功德，法身是这些功德的体，是法的性，所以称为法性。无性《摄大乘论释》解释说："或者法身是诸法所依止之处。"《成唯识论》说："法身是大功德法的所依止。"《佛地论》说："法身是十力、四无畏等各种功德法的所依止，所以称为法性。"这是依主释。

"身"有三种意义，《成唯识论》说："体性、所依、积聚，总说称为身。"法性就是身，是持业释。

三、受用身

《佛地论》说："受用，就是第二种受用身，能令自己和他人受用种种大法乐。"这个意义总的显示：自受用身、他受用身都称为受用身。自受用身自己受用法乐，他受用身令他人受用法乐。

《成唯识论》说："自受用身恒常自己受用广大法乐。他受用身为十地菩萨众示现神通、宣说正法，决断众人的疑网，令他人受用法乐。"合这两种称为受用身。

1. 自受用身是持业释，因为受用就是身。
2. 他受用身是依主释，因为是受用的身。

《金光明经》也称为应身，只说他受用身，不说自受用身称为应身，因为应合机宜而示现的身称为应身。如那部经说："善男子，这些如来为了诸菩萨得以通达，宣说真谛……乃至广说。这种身能显现三十二相、八十种好、项背圆光，称为应身。"自受用身的定慧功德，那部经说是法身所摄。

四、变化身

《佛地论》说："变化，就是第三种变化身，为了利益安乐众生，示现种种变化的事。"转换旧的形相称为"变"，没有而忽然出现称为"化"。变与化不同，是相违释。变化就是身，是持业释。这是举出神境通殊胜的作用，称为变化身，因为变化身多作变化的事。

《金光明经》单称为化身，有三种理由：

1. 化身能导引众生。
2. 化身受用法乐低劣，殊胜的一方独得"变化"的名称。
3. 或者是省略，只称为"化"。

变化就是身，是持业释。总称为三身，是带数释。

第二门　出体

关于三身的体性，略有六种说法。

第一说：胜义中无身，世俗中说三身

有一种说法认为：《成唯识论》《佛地论》都说："如来功德身土，甚深微妙，非有非无，离开各种分别，断绝各种戏论，不是蕴、处、界等法门所摄。"所以在胜义谛中，佛非身也非不身，哪里有三种？依世俗谛随顺根机所显现，说有三身：法身是空理，报身是空智，为利益众生所显现的称为变化身。清辨等论师都持这种意义。

第二说：法身是真如，佛只有后三界

有一种说法认为：法身只以真如为体性。十八界中，佛只有后三界（意界、法界、意识界），通于无漏所摄。

由于佛身的大定、大智、大悲三法增上：

1. 第六、第七、第八识以及相应的心品，是自受用身。
2. 平等性智随顺十地菩萨的所宜，显现他受用身和净土的相状。
3. 成所作智随顺三乘的所宜，能生起变化身和净土的相状。

这两种身土由妙定所生，属于法界色所摄。佛以外众生的五识依这两种身土变现自己的影像，粗细不同，所以这两种身土不是五境所摄。

成所作智，或者与第六识相应，或者与第七识相应：

1. 与第六识相应：观察自相、共相等的称为妙观察智，生起变化作用的称为成所作智。两种作用前后分别生起，在道理上没有违背；或者同一体性分出作用，同时生起也没有过失。
2. 与第七识相应：变现他受用身的称为平等性智，生起变化身的称为成所作智。

佛恒常在定中，五识的体性是散乱的，所以前十五界在佛身上没有。经论说"转五识得成所作智"，成所作智的体性并不是五识。这就像说"转生死得涅槃"，涅槃不是五蕴所摄。

第三说：如来功德身土摄在蕴处界中

有一种说法认为：如来的功德身土，随其所应，摄在蕴、处、界中，蕴、处、界三者都通于有漏、无漏……乃至广说。

这种说法当中，又略有四种意义，合前两说共成六说。

（一）四智分别成三身

有一种说法认为：《成唯识论》《佛地论》都这样说：

1. 自性身：清净法界是自性身。《佛地经》说"清净真如是自性身"。《摄大乘论》智殊胜中说"转去阿赖耶识得自性身"。《大乘庄严经论》说"转第八识得大圆镜智"。所以合清净法界和大圆镜智二法为自性身。
2. 受用身：平等性智、妙观察智是受用身。《大乘庄严经论》等说平等性智在纯净土中为诸菩萨示现佛身，说妙观察智在大集会中说法断疑、显现自在，这显示二智是他受用身。《大乘庄严经论》又说"转各种转识得受用身"，这显示二智是自受用身。
3. 变化身：成所作智是变化身。《佛地经》说："成所作智在十方国土，显现无量种难思的变化。"

又，智殊胜中具足摄三身，所以可知三身都有实智。

窥基破斥说：这种意义不合理。

1. 《佛地经》说清净法界是自性身，是诸佛共有，体性常住，十地菩萨分分都能证得。如果大圆镜智是自性身，便没有这种意义。
2. 《金光明经》说如如、如如智都称为法身。如果把有为功德的根本即大圆镜智说成法身，就应当像那部经一样，四种实智品都是法身。
3. 经论又说"转各种转识得受用身"。如果成所作智不是受用身，成所作智就应当不是转识所得。
4. 如果成所作智是变化身，《解深密经》问"变化身有心还是无心"，经中就应当决定回答"化身有心"，因为这一说法以佛的五识为变化身。为什么经中说"化身不能说有心，因为没有自己所依的心；不能说无心，因为有依他的心"？由此可知化身的体性不是实智。

观察佛身，理和事有区别，粗细的功德有差别，体性是一，作用不同，所以分别说为三身。哪能分出四智，各自成就一身？

（二）《成唯识论》的说法

有一种说法认为，依《成唯识论》所说：

1. 自性身：清净法界是自性身。
   - 《大乘庄严经论》等说自性身本性常住。
   - 《赞佛论》说佛的自性身没有生灭。
   - 无著《金刚般若论》说：受持、演说《金刚经》的功德，对佛的法身是证得因，对其余二身是生起因。所以《金刚经》说："一切诸佛法，都从这部经出；一切如来，从这部经生。"
   - 各种经论说究竟转依是法身，转依就是清净真如。

   所以可知法身以法界为体性。经论说"转去藏识得法身"，意思是由转灭第八识中二障的粗重，证得真如，显现法身。智殊胜中说法身，是因为法身是智的依止，是智的真实体性，法身实际上不属于智所摄。

2. 受用身有两种：一是自受用身，二是他受用身。
   - 四智品中的真实功德，大圆镜智所生起的常住遍满的色身，是自受用身。《大乘庄严经论》说"大圆镜智是受用佛"，《摄大乘论》说"转各种转识得受用身"。转藏识实际上也得受用身，《摄大乘论》中因为说转藏识显现法身，所以对得受用身略而不说。
   - 法身既然说无生无灭，只由证得因而得，不是色、心等法；大圆镜智品与这种意义相违。大圆镜智品如果不是受用身，又属于哪一身所摄？受用身摄佛不共的有为真实功德，所以四智品中真实的色、心，都属于自受用身。
   - 平等性智品所显现的佛身，是他受用身。

3. 变化身：成所作智品所显现、随顺众生种类的种种身相，是变化身。经论说化身属于智殊胜所摄，是因为化身似智显现，或者由智所生起。经论说的"智"这个名称，化身的体性实际上不是智。

经论只说平等性智能显现受用身，成所作智显现三业化身，不说二身就是二智。所以平等性智、成所作智这两种实智属于自受用身所摄，二智所显现的相状说为他受用身、变化身。这两种身都是四智的相状，由四智所显现。为十地圣者所显现，和为地前三乘所显现，身相有粗有细，所以分别为两种身。

平等性智所显现的身，相似于无我平等，显示法乐增上，令他人受用，所以只说平等性智所显现的佛身是他受用身。成所作智显现三业变化增上，所以只说成所作智所显现的身相是变化身。所以不违道理。

（三）《金光明经》的说法

有一种说法依《金光明经》第一卷所说：

1. 化身："怎样是菩萨了别化身？善男子，如来过去在修行地中，为了众生修习种种法，直到修行圆满……乃至广说。随顺众生的意乐、行为、界别，不等待过时……乃至能显现种种身相，称为化身。"
2. 应身："善男子，这些如来为了诸菩萨得以通达，宣说真谛……乃至广说。为无边佛法作根本，由于如来相应的如如、如如智的愿力，这种身得以显现，具足三十二相、八十种好、项背圆光，称为应身。"
3. 法身："善男子，为了灭除一切烦恼等障，为了具足一切善法，只有如如、如如智，称为法身。"

经中又说："前两种身是假名有，第三种身称为真有，是前两种身的根本。由于离开法如如、离开无分别智，一切诸佛没有其他的法。为什么？因为一切诸佛智慧具足，一切烦恼究竟灭尽，得到清净佛地。所以法如如、如如智，摄一切佛法。"

那部经的意思是说：

1. 法身：清净法界以及四智品、常住遍满的色身，这些真实的有为、无为功德，称为法身，因为是有为、无为功德的根本。
2. 应身：由于如来相应的如如、如如智的愿力所显现的相好、项背圆光，为地前、三乘以及十地菩萨所显现的身，称为应身。为化导三乘所显现的佛身，以及为化导十地菩萨所显现的他受用身，都称为应身，因为应合他人的机宜而显现佛身。
3. 化身：修愿行圆满，不等待时间、处所，随顺众生种类显现五趣的身，称为化身，因为不显现佛的形相而显示变化。《佛地经》中，五趣的化身也属于化身所摄，因为多显现神通变化的事。

他受用身也称为应身。自受用身自己受用法乐，不是应合机宜而显现。他受用身能令菩萨受用法乐。自受用、他受用有区别，受用法乐没有差别，所以合称为受用身。

自受用身是有为功德法的根本，不是诸佛共有，是各别的体性，不是法的真性，所以不是自性身；也不是无为功德的根本，所以不称为法身。《成唯识论》与《金光明经》各依一种意义，也不相违。

（四）《佛地论》的说法

有一种说法依《佛地论》所说：

1. 自性身：清净法界是自性身。
2. 自受用身：四智的自性、相应心所，共同具有的常住遍满色身的真实功德，是自受用身，因为是三大阿僧祇劫所修成。天亲《金刚般若论》上卷也称为报佛。
3. 他受用身：为十地菩萨所显现的一分细相，是他受用身，因为令诸菩萨受用法乐。
4. 变化身：为三乘有情所显现的一分粗相，是变化身，因为地前三乘所应见的是粗相。变化身不是修成的真实功德，只是变化的作用。

他受用身、变化身都是四智的相状，所化的有情宜见粗相、细相，所以分成两类。地前三乘只依变化的作用发心修行，还不能证得广大法乐，所以这种化身不称为受用身。

六说的判定

这六种说法中：

1. 最初三种说法（胜义无身说、法身真如而佛只有后三界说、四智分别成三身说），义理相违，如论中自己所显示。
2. 第四种说法（《成唯识论》说）与第六种说法（《佛地论》说），文字稍有不同，两者的道理没有违背。第四种说法中，随二智增上，说二身所摄，不是说二身只由二智显现。乍看文字有别，意义实际上没有不同。
3. 第五种说法（《金光明经》说），经文和义理都没有差错。

由此，经过褒贬，共成六种说法，其中三种说法的道理没有谬误。

〔译注：末句原文「由是褒贬虽成六说。三理无谬」，"三理"指第四、第五、第六三种说法。〕
