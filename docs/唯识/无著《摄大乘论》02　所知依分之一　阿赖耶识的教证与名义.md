所知依分第二

一、阿赖耶识的教证

在十种殊胜之中，最先说所知依。所知依就是阿赖耶识。世尊在什么地方说过阿赖耶识，并称之为阿赖耶识？薄伽梵在《阿毗达磨大乘经》的伽陀中说：

```
无始时来界　　一切法等依
由此有诸趣　　及涅槃证得
```

大意：从无始时来就有的“界”，是一切法共同的所依。由于有“界”，才有生死中的诸趣，也才有涅槃的证得。

【世亲释】“界”是因的意思，世间把金矿等称为“界”，就是取因的意思。界是一切法共同所依止的因。不只生死诸趣由界而有，涅槃的证得也由界而有，因为要先有杂染，才能证得涅槃。

在《阿毗达磨大乘经》中，又说一颂：

```
由摄藏诸法　　一切种子识
故名阿赖耶　　胜者我开示
```

大意：一切种子识能摄藏诸法，所以称为阿赖耶。我为殊胜的菩萨开示阿赖耶识。

二、阿赖耶识的名义

上面先引圣教作为证明。又为什么阿赖耶识称为阿赖耶识？一切有生的杂染品法，作为果，摄藏在阿赖耶识中；阿赖耶识作为因，又摄藏在一切杂染品法中。所以称为阿赖耶识。或者，诸有情把阿赖耶识摄藏为自我，所以称为阿赖耶识。

三、阿陀那识

阿赖耶识又称为阿陀那识。圣教依据如《解深密经》所说：

```
阿陀那识甚深细　　一切种子如瀑流
我于凡愚不开演　　恐彼分别执为我
```

大意：阿陀那识极其深奥微细，一切种子如瀑流一般刹那相续。我不为凡夫愚人开示阿陀那识，恐怕凡夫愚人分别执着阿陀那识为自我。

【无性释】阿陀那识直到生死的尽头，行相都是同一类，没有改易，所以凡夫容易把阿陀那识执为自我。世亲释同。

又为什么阿赖耶识也称为阿陀那识？因为阿赖耶识执受一切有色根，又是一切自体受取的所依。所以如此的理由是：有色诸根由阿赖耶识执受，不会失坏，直到寿命终了都随之而转。又在相续正结生的时候，阿赖耶识受取新的生命，所以执受自体。因此，阿赖耶识也称为阿陀那识。

【世亲释】眼等有色诸根被阿赖耶识所摄受，所以不像死尸那样出现青瘀等相状。到了死的时候，阿赖耶识舍离身体，身体就出现青瘀等相状。所以决定可知，由阿赖耶识执受，直到寿命终了，有色诸根都不失坏。

四、心、意、识

阿赖耶识也称为心，如世尊所说的心、意、识三者。其中，意有两种。第一种意，是作为等无间缘的所依止：无间灭去的识，能为意识作生起的依止。第二种意是染污意，恒常与四种烦恼相应：第一萨迦耶见，第二我慢，第三我爱，第四无明。染污意是识的杂染所依。识由第一种意而生起，由第二种意而杂染。因为了别境界，所以称为识。因为是等无间的依止，又因为思量，所以意成为两种。

【世亲释】萨迦耶见，就是执着有我。由萨迦耶见的势力，生起我慢，倚恃我与我所而自我高举。在实际无我之中生起有我的贪爱，称为我爱。三者都以无明为因，无明就是无智。染污意是杂染的所依，因为即使在善心之中，染污意也执着有我。

五、六条理由证成染污意

又如何得知有染污意？

如果没有染污意，就不会有不共无明，有此过失。

又不会有五同法，有此过失，因为五识身必定有眼等作为俱有依。

又不会有“意”的训释词，有此过失。

又无想定与灭尽定没有差别，有此过失：无想定是染污意所显，灭尽定则不是；如果不承认染污意，两种定就没有差别。

又在无想天一期生中应当没有染污，有此过失，因为生在无想天中，就没有我执、我慢。

又一切时中我执现行，现前可以得知，就是在善、不善、无记心中都有我执现行。如果不承认染污意，只有不善心与我执相应，所以只有不善心有我、我所的烦恼现行，善心与无记心就没有。所以，如果建立染污意与善等心俱有而现行，而不是与善等心相应而现行，就没有上面的过失。

【世亲释】六条理由的意思如下。

不共无明，是对治还没有生起时，能障碍真智的愚痴。不共无明不在五识中，因为五识中没有能对治，有能对治的地方才有所对治。不共无明也不在意识中，因为如果在意识中，意识就毕竟成为染污，布施等心就不能成为善。如果有染污意与善心俱转，善心引生能对治，能治生起，所治灭除，就没有过失。

五同法：眼等五识，必定有眼等五根作为俱有依；意识也应当同样有俱有依，就是染污意。

训释词：能思量，所以称为意。六识已经谢灭，过去已灭的识没有任何思量，不能成为“意”的所依。

二定差别：无想定中有染污意，灭尽定中没有染污意，所以两种定有差别。如果不承认染污意，两种定中第六意识都不现行，两种定就没有差别。

无想天我执：生在无想天的有情如果没有我执，就不应当被圣者呵责厌离。无想天既被圣者呵责厌离，决定可知生在无想天中仍有我执。

我执恒随：在布施等善位中，也决定有我执随逐，自谓“我能修行布施”。我执不能离开无明，无明不能离开所依，无明的所依离开染污意，没有别的体。

【无性释】“不共无明”的“不共”，不是说不与其余烦恼相应，而是说不共无明只在染污意中有，其余处所没有，如同佛的“十八不共法”只在佛有。

关于染污意，有颂说：

```
若不共无明　　及与五同法
训词二定别　　无皆成过失
无想生应无　　我执转成过
我执恒随逐　　一切种无有
离染意无有　　二三成相违
无此一切处　　我执不应有
真义心当生　　常能为障碍
俱行一切分　　谓不共无明
```

大意：如果没有染污意，不共无明、五同法、意的训释词、两种定的差别，都不能成立，都成过失。生在无想天应当没有我执，成为过失。我执恒常随逐，没有染污意，一切情况下都不能有我执。离开染污意，“二”不能有，“三”成相违。离开染污意，一切处所的我执都不应有。真实义的心将要生起的时候，常能作为障碍，在一切位中俱行的，称为不共无明。

【世亲释】颂中的“二”，是不共无明和五同法。“三”，是训释词、二定差别、无想天中我执恒随。

染污意是染污的，所以是有覆无记性，与四种烦恼常共相应，如同色界、无色界二界的烦恼属于有覆无记性。色界、无色界的烦恼被奢摩他所摄藏，所以是有覆无记。染污意在一切时中微细随逐。

【译注】有覆无记，是不属于善、不善，而能覆障圣道、染污心的一类法。

六、心的体是阿赖耶识

心、意、识中，第三项心的体，离开阿赖耶识就没有别的可得。所以成立阿赖耶识作为心的体。以阿赖耶识为种子，意和识得以转起。又为什么阿赖耶识也称为心？因为阿赖耶识是种种法熏习的种子所积集之处。

七、声闻乘为什么不说阿赖耶识

又为什么声闻乘中不说心称为阿赖耶识、称为阿陀那识？因为阿赖耶识属于深细的境界。所以如此的理由是：诸声闻不在一切境界上转起智慧。对诸声闻，即使不说阿赖耶识，诸声闻的智慧也能成就解脱，佛因此不为诸声闻宣说。诸菩萨决定要在一切境界上转起智慧，所以佛为诸菩萨宣说。如果离开阿赖耶识的智慧，诸菩萨就不容易证得一切智智。

【世亲释】诸声闻只希求自身的利益，依粗浅的苦谛等正智，就能永断烦恼障。诸菩萨为了利益自他，求断烦恼障和所知障，所以佛为诸菩萨宣说阿赖耶识。

【无性释】离开阿赖耶识的智慧，为什么不容易证得一切智智？一切法的差别无边，分别智无法一一证知。菩萨了知所取的义、有情、我，都只是阿赖耶识中习气转变的力量所显现，就了知没有所取，也就了知没有能取，由此证得无分别智；再由后得智通达一切法共相所显的一味真如，一切境界的智慧就容易证得。
