# 《月灯三昧经》卷第四

高齐天竺三藏那连提耶舍汉译　白话今译

## 一、世尊出城还灵鹫山

这时，世尊在大众中开示、教导、令其得益、令其欢喜之后，就从座起身，走出王舍城，前往灵鹫山，敷座而坐。诸比丘众以及诸天、龙、夜叉、乾闼婆、阿修罗、迦楼罗、紧那罗、摩睺罗伽前后围绕。

这时，月光童子与八百亿人，以及天龙八部、诸鬼神等，还有其他世界的十那由他菩萨大众，手持种种宝鬘、涂香、末香、衣服、幡花、种种音乐，竖立幢盖，悬挂缯幡，走出王舍城，向灵鹫山来到如来所在之处，头面礼足，绕佛无量匝，以自己所持的花、香、衣服、宝盖、幢幡，演奏种种音乐，设大供养。设供养之后，他们躬身恭敬，为了请法，退坐一旁。

这时，月光童子这样说：“我想向如来、应供、正遍知有所请问，唯愿允许。”

这时，世尊告诉童子说：“如来、应供、正遍知随你所欲，任你发问。你所问的能利益无量众生，我当为你分别解说，使你心生欢喜。”

## 二、成就四法得此三昧

这时，月光童子蒙佛允许，就禀白佛说：“菩萨摩诃萨成就几种法，才能得到这一切诸法体性平等无戏论三昧？”

这时，佛告诉月光童子说：“菩萨摩诃萨成就四种法，就能得到这一切诸法体性平等无戏论三昧。

“是哪四种呢？第一，善于修学柔和，与人同住而使彼此安稳，到达调伏之地，能忍受毁谤侮辱，见到法而除去慢心，这是第一种法。菩萨如果能成就这样的法，就能得到这一切诸法体性平等无戏论三昧。

“其次，童子！菩萨摩诃萨成就善戒、清净戒、第一善清净戒、不浊戒、不缺戒、不穿戒（无漏洞的戒）、不杂戒、不定于色相的戒、自在戒、不可诃责的戒、不退落的戒、无所依的戒、无所取的戒、无所得的戒、圣者所赞叹的戒、智者所赞叹的戒。童子！这是第二种法。菩萨具足这种法，就能得到一切诸法体性平等无戏论三昧。

【按】这里列出的戒，从“清净、不缺、不穿”一路说到“无所依、无所取、无所得”。可见本经所说的持戒，最终也要与无所得的见地相合：持戒而不执有一个持戒的我、所持的戒，这才是“智所赞戒”。

“其次，童子！菩萨摩诃萨深深怖畏三界而生起惊畏之心，厌离三界而生起不染之心，不执著三界而生起视三界为逼恼的心，为了使三界中受苦的众生得到解脱而生起大悲心，趣向无上正等正觉而发起大精进心。童子！这是第三种法。菩萨成就这样的法，就能得到一切诸法体性平等无戏论三昧。

“其次，童子！菩萨摩诃萨求取多闻而没有厌足；因为看重法而不求财利，因为看重智慧而不求名闻；随所听闻而受持，为他人广为宣说，显示其中的义理，这是出于悲悯，而不是为了亲属；菩萨又这样想：‘怎样才能使前来听法的众生，对于无上菩提迅速得到不退转？’这是第四种法。菩萨成就这样的法，就能得到一切诸法平等无戏论三昧。

“童子！你应当知道：这个三昧法门，是无量诸佛所演说的，无量诸佛所赞叹的，无量诸佛所称美的，无量诸佛所显示的，无量诸佛所修习的。”

【按】四法可以概括为：调柔忍辱、清净持戒、厌离三界而起大悲、多闻而为利他说法。这四者都是此三昧的入门资粮。冈波巴大师的道次第，先以出离、戒律、悲心打底，再入见地，与此四法的排列颇为相合。

## 三、往昔诸佛名号

这时，世尊说偈道：

我忆念在不可思议那由他劫以前，有佛名号叫音声身；那位音声身如来世尊，住世寿命六千岁。

在那位佛之前，又有一尊佛，名号叫智自在，为世间所爱；那位智自在正遍知，寿命一万二千岁。

在那位佛之前，有一尊佛，名号叫威德自在大势力；那位威德佛、人中至尊，寿命七万六千岁。

在那位佛之前，又有一尊佛，名号叫大自在自然智；那位大自在天人师，寿命满一千万岁。

在那位佛之前，又有一尊佛，那位佛名号叫梵声师；那位梵声佛两足尊，寿命满一亿岁。

在那位佛之前，又有一尊佛，名号叫众自在最胜离；那位众自在无比尊，寿命满六亿岁。

在那位佛之前，又有一尊佛，那位佛名号叫声自在；那位音自在世尊，寿命满一千万岁。

在那位佛之前，又有一尊佛，名号叫声上，为世间的明灯；那位声上佛世间导师，寿命一万四千岁。

在那位佛之前，又有一尊佛，名号叫满月面普名称；那位满月面普名称佛，住世寿命只有一日一夜。

在那位佛之前，又有一尊佛，那位佛名号叫日面满；那位日面佛无比尊，寿命一万八千岁。

在那位佛之前，又有一尊佛，那位佛名号叫梵面亲；那位梵面亲两足尊，寿命二万三千岁。

在那位佛之前，又有一尊佛，那位佛名号叫梵婆薮；那位梵婆薮天人师，寿命一万八千岁。

这些佛出现在同一劫中，其数共有二百位世间导师。你们听我现在宣说这些佛的名号，他们都是三界世间的亲人：

无毁身佛、普音佛、遍威德佛、遍声佛、声供养佛、名声佛、声身勇佛、声身净佛、智起佛、智知佛、善聪佛、智光映蔽佛、智等起佛、智焰聚佛、智勇佛、梵上佛、梵命佛、梵善佛、善梵天佛、胜梵声佛、梵音佛、梵天佛、梵施佛、威力佛、威主佛、善威佛、威德自在佛、起威佛、威德眼佛、善胜佛、怖上佛、怖慧佛、善可怖佛、可怖面佛、怖起佛、可怖怖上佛、见实佛、善眼佛、月上佛、胜导师佛、深远音佛、无边音佛、净音自在佛、净音佛、无量音佛、善现声佛、魔力音坏佛、善眼佛、善眼净面佛、净眼佛、无量眼佛、普眼佛、善普眼佛、胜眼佛、眼映蔽佛、不毁眼佛、调伏上佛、调伏佛、善调心佛、善调佛、寂根佛、寂意佛、寂上佛、寂德佛、极寂佛、到定岸佛、寂心无上如来、住边寂佛、善调心佛、善调寂根佛、定意佛、寂上佛、寂德炽盛佛、度寂彼岸佛、定勇佛、众因陀罗王佛、众佛、众自在佛、映蔽众佛、众胜净智佛、大众主佛、众主勇健佛、大众佛、胜众解脱正遍知、见法佛、法幢佛、法起佛、法体性起佛、法力佛、法佛、妙法佛、勇健佛、自性法起决定佛。

【按】偈中佛名多连写，原文分合不易确定，以上依文意逐一分列，个别名号的断句存疑。

这样的自性法起佛，共有八亿尊，都是同一名号；这些佛出现在第二劫中，这些如来我都曾经供养过。

对于自性法起决定佛，如果有人听到他的名号，听了之后受持，作清净之业，这个人就能迅速获得这个三昧。

## 四、善胜音王佛与功德力王

我现在所说的牟尼王，在那位佛之后又有其他的佛；经过不可思议无数劫，有佛名号叫善胜音王佛。

那位善胜音王如来世尊，寿命七万六千岁。

这位如来世尊第一次法会时，有阿罗汉众三十亿，具足六通、三明，诸根调伏，具大威德与四神足，住于最后身，诸漏已尽，不被世间八法所染。

那时又有菩萨大众，其数共有万万亿，得六神通，具足辩才，对于诸法空性的修学已经究竟；

他们以神通力游历亿数佛刹，辗转教化超过恒河沙数的众生，向诸如来请问所行之道，然后又回到本来的世界。

他们博通一切修多罗，游行于世间作为明灯；佛子啊！这就叫做大神力，为了利益众生而游历诸国。

他们远离丑秽，修行梵行，不因贪欲而造作种种恶业，常为诸天所喜乐，在诸有之中无所依恃。

他们在空闲之处常行乞食，住在空寂之地行头陀行，多闻、善巧言说，具大福德，能在三界中无所执著。

他们乐于禅定，无所畏惧，对于义理决定而获得辩才；对于言辞文句和义理已经善学，佛子们一问之下就能究竟通达。

他们摄护一切善业，在无量劫中修行圆满，常为诸佛所赞叹，演说解脱之道的句义。

他们持戒清净，没有秽污，如同莲花处在水中而不被沾著；在三界中常生厌离，不被世间法所染。

他们的心清净，所作之业善良清净，少欲知足，具足威德；安住于未来的圣德之中，也安住于三明的殊胜之道。

```
要在修行非口言　自安于法为他说
为诸如来善摄受　委付一切佛法藏
```

大意是：关键在于实际修行，而不在口头言说；自己先安住于法中，再为他人宣说；这样的人为诸如来善加摄受，诸佛把一切佛法宝藏都托付给他们。

他们在三界中生起怖畏，以寂静之心常常修定，常为诸佛所加持护念，宣说千亿种修多罗。

即使宣说亿种修多罗，也远离一切世间的教说；他们信解空寂，宣说甚深的义理，具有无量的名称，功德如大海。

童子！我在无量劫中，一直赞叹他们，从无间断；我现在所说的只是其中少分，犹如大海中的一滴水。

那时善胜音王佛宣说这寂灭最胜之定，当时三千大千世界中，诸天和人全都充满。

那位佛宣说这寂定的时候，当时大地六种震动，天、人大众多如恒河沙，安住于不退转的菩提道。

那时有一位国王，是人中最上的尊者，名号叫功德力，具大威神；他具有五百个儿子，容貌端正，非常美丽。

他有美妙的夫人八亿位，都是王宫内的眷属；那位功德力王所生的女儿，共有一千四百亿。

这位国王在八月十五日，正要好好受持八关斋戒，与八亿那由他人一起，同时前往如来所在之处。

他稽首礼敬无上两足尊，随即在佛前坐在一旁；如来了知他心中所乐，就为他宣说这殊胜的三昧。

这位国王听了这个三昧之后，舍弃王位如同吐掉鼻涕唾沫，并舍弃一切所亲爱的人，在那位佛的座下出家。

夫人、后宫、调顺的儿子们以及诸女儿等，都出了家；后宫眷属以及亲族大众，共有七十六万那由他。

那位国王与妻子儿女出家之后，安住于勇猛，常常精进，经行不止，满八年之久，就在经行的时候命终了。

这位大圣王命终之后，又生回本来所在的王宫之中，忽然化生，没有胞胎的染污；那时如来仍然住世。

他的父亲名号叫坚固力，母亲名号叫大智慧；这位王子出生之后，就禀白父母说：“善胜音王佛还住世吗？

## 五、化生王子的偈问

“那时那位胜音王如来，曾经为我宣说殊胜的三昧：

```
非是因缘非无缘　于诸有中唯说一
一切诸法体性印　出千万亿修多罗
是诸菩萨无上财　今佛犹说三昧不
```

大意是：这个三昧说的不是因缘有，也不是无因缘；在诸有之中，只宣说同一个体性。它是一切诸法体性之印，从中出生千万亿部修多罗；它是诸菩萨无上的财宝。现在佛还在宣说这个三昧吗？

【按】“非是因缘、非无缘”：不落于“由因缘而有”的有边，也不落于“无因无缘”的断边。“于诸有中唯说一”，就是前卷所说“以一知一切”。“一切诸法体性印”这个名称，与大手印“法印”之义极其相契：一切法都被同一体性所印定，无有例外。

“他说法不破坏因果，能使人修习最殊胜的八圣道；如来以智慧观见世间，了知诸法而入于真谛；

“身业、口业都清净，意业清净，知见清净，超出一切攀缘，这位佛还在宣说这个三昧吗？

“能了知诸蕴、诸界平等，远离一切诸处之相，证得无生寂灭之忍，这位佛还在宣说这个三昧吗？

“具有无碍辩才，入于寂静的智慧，通达理解文字差别的智慧，能超越一切执取之事，这位佛还在宣说这个三昧吗？

“了知一切音声而得到欣喜，见到诸佛之后生起深深的爱乐，得到圣者之趣，柔和正直，佛还在宣说这个三昧吗？

“不起嗔怒，恒常调顺善良，说话美好，常含笑容，见到众生先开口慰问，佛还在宣说这个三昧吗？

“恭敬尊长而不懈倦，礼拜供养，恒常瞻仰，身体清净，具足白净之法，法王还在宣说这个三昧吗？

“对于一切白净之法常无厌足，住在空闲之处，远离邪命，忆念诸地而不忘失，法王还在宣说这个三昧吗？

“对于五蕴具有善巧的智慧与神通，远离烦恼，到达调伏之地，能断除凡夫的语言之道，法王还在宣说这个三昧吗？

“常能修习增进种种殊胜之行，远离犯戒，了知持戒与犯戒，并远离一切亲爱的牵缠，法王还在宣说这个三昧吗？

“超出一切三有之生，自识宿命，远离一切疑惑，心中敬法，闻持总持，佛现在还在宣说这个三昧吗？

“出生深刻锐利的殊胜智慧，信乐坚定如同山王不动，得到总持之门而不退转，世间的亲人还在宣说这个三昧吗？

“常求一切白净之法，对于恶法恒常远离，心不进入烦恼的伴党，如来还在宣说这法吗？

“一切修学都已究竟，得大自在，对于一切禅定已经穷尽，智慧能使人生信欣喜，说法的牟尼还住世吗？

“殊胜的智慧增长，了知受生的智慧、无量的智慧、平等的智慧，了知众生随业生于诸趣的智慧，这是牟尼王所宣说的殊胜之法；

“以信心出家，舍弃世俗之地，不执著三界，无所依恃，制伏自心使之欣喜，这是佛所说的殊胜菩提；

“对于一切法没有执著，又常能摄受一切法，对于业果的信心坚定不动，这是最胜世尊所说的法；

“了知戒律持犯的果报之智，灭除一切诤论，能宣说不相违、不相诤之地，这是两足尊牟尼所说的法；

“受持忍辱，没有嗔怒，对于问答能够善巧，了知诸法文句差别的智慧，这是大悲世尊所说的法；

“了知过去、未来之际，能了知三世诸佛的法性，了知三世分段的智慧，这是自然觉悟的世尊所说的法；

“常能系心于一处，常能安身于圣者之地，对于一切威仪恒常不改，这是人中牛王所说的法；

“以有惭有愧庄严自身，了知世间应时之语，对一切人常常伸出布施之手，这是无上世间亲人所说的法；

“常能摄心，具有惭愧，也常厌离恶与不善，随顺头陀行，常行乞食，这是牟尼王尊所说的殊胜之法；

“常怀惭愧，恒常欣喜，对尊长供养，恒常恭敬，远离憍慢，修行礼拜，这是如来所说的殊胜妙法；

“策励下劣之心，使它得到安稳，自己能测量智慧的分齐，远离无知的种种障碍，这样的殊胜之人宣说这法；

“能入于知心之智与语言之智，决定能了知一切言辞，远离一切无利益之事，这是法王如来所说的法；

“常得亲近善知识，远离一切不善之人，常得信佛而不放逸，这是牟尼所说的无上之法；

“了知世间的假名只是言说，常常厌离一切世间之苦，对于利益的得失没有忧喜，这是牟尼所说的最殊胜之法；

“如果得到恭敬，心不高举；得不到恭敬，心中放下；得到如实的称叹，心中也不欢喜，这是世间之师所说的法；

“常舍弃一切恶道，不与世俗之流交往，对于出家大众也不掺杂其中，这是自然智者所说的法；

“勇者远离不应行之处，对于佛所行之处常常安住，威仪具足，心善调柔，这样的法母是佛所说的；

“常远离一切凡愚之法，也远离一切玷污俗家之法，常护持一切诸佛之法，这法是大智者所说的；

“少说话而言语美妙，善于相应，对他人能说柔软之语，如法降伏一切怨敌，这是大智慧之日的教法；

“了知时节，知量饮食，慎勿轻信凡夫之法，如果遇到苦缘，心中也不忧戚，这是如来善妙殊胜的教导；

“如果见到贫穷的人，使他得到财物；如果见到破戒的人，生起悲心去救护，以悲悯之心为他开导晓喻，这样的殊胜之法是如来的教导；

“常以法摄受众生，以及施舍一切财物，对于世间八法所涉之物不作贮蓄，这是如来大圣所说的教导；

“赞叹持戒，诃责破戒，坚持清净戒律而不诈伪，不积聚资财，能够施舍，这是如来最殊胜的教导；

“以深心启请诸位师长，随其所说都能奉行，常能亲近诸位法师，这是如来最殊胜的教导；

“心中常常爱乐，恒常恭敬，也恒常安住于正见，对于一切善业能够决定，这是如来最殊胜的教导；

```
造诸善行为上首　善巧方便弃舍相
远离于想及事相　是为如来无上教
```

大意是：造作一切善行，以此为首要；同时以善巧方便舍弃对相的执著，远离想念以及对事物之相的执取，这是如来无上的教导。

【按】这首偈把行持与见地合在一处：一方面“造诸善行为上首”，另一方面“弃舍相、远离于想及事相”。行善而不著相，正是此三昧在日常中的落实，也就是大手印行者所说的“见行不分”。

“对于修多罗能够理解了知，对于真实谛理的句义善加修学，证得解脱智而常常善巧，这是如来最殊胜的教导；

“说话发言出于端正之语，心与境相称，言辞决定，有所宣说而没有疑惑，这是如来最殊胜的教导；

“应当常常修习诸法空性，安住于戒力而无所畏惧，游行于一切寂定之处，这是如来最殊胜的教导；

“不求亲爱和利养，心中没有种种谄曲，远离一切恶见，这是如来最殊胜的教导；

“对于陀罗尼得到殊胜的辩才，智慧照明广大无边，说法不断，辩才清净，这是如来最殊胜的教导；

“对于（前面所说的）四种法门久已修习，能入于最贤善之行，对于这佛教奉行修持，这是如来最殊胜的教导；

“对于佛所说的法得到随顺忍，安住于这种忍而远离一切过失，远离非智而安住于智慧，这是如来最殊胜的教导；

“以智慧安住于方便之地，修习菩萨的善巧之行，这是善丈夫所修的行，是诸佛最殊胜的教导；

“常远离不相应的方便，如来说这就是佛地；如果与智慧相合，佛就随喜，这称为如来最殊胜的教导；

“佛地广大，不是二乘的境界，凡愚无智的人对此生起毁谤；有智慧的人为诸佛所摄受，这称为如来最殊胜的教导。

“如来善知这一法门，为诸天所恭敬供养，千亿梵天大众恒常随喜，如来还在宣说这个三昧吗？

“无量千龙恒常礼拜，紧那罗、金翅鸟常常赞叹，这是在菩提树下所证得的，如来还在宣说这个三昧吗？

“这是有智之人常常求取的，是善妙殊胜之法的资财，不是财物的布施，而是无上的妙药，如来还在宣说这个三昧吗？

“它是智慧的宝藏，辩才无尽，能出生亿部微妙的修多罗，是善知三界的如实智慧，如来还在宣说这个三昧吗？

“它宣说以船筏渡到彼岸，不被四暴流所漂没，能使名闻之鬘得到增长，所以佛宣说这个三昧之定。

“赞叹十种最殊胜之力，以及赞叹人中的大牛王，菩萨的功德殊胜无尽，正是由于得到这个三昧的缘故；

“宣说以慈心除去嗔恚，行大悲的人具足大喜与大舍，使修大乘的人得到苏息，正是由于宣说这殊胜的三昧；

“为了作狮子吼而宣说殊胜之行，这是佛智慧的殊胜圣教，是一切诸法体性之印，这样的三昧是佛所说的；

“它能招致一切种智之智，是求菩提者的园苑，能破坏魔的军众，这就是佛所说的殊胜寂定；

“它能出生正觉的功德，是一切法的自性之印，是无生寂灭的妙法之印，这是导师所说的殊胜三昧；

“它为安住于法的人作光明之术，在怨仇之中不显现，如法降伏一切魔的官属，这是导师所说的殊胜三昧；

“它显示无碍的辩才之地、诸力、解脱以及诸根，以及最殊胜的十八不共法，都是由这个三昧而得到这些法。

“它是求取十力者的真实之法，是诸佛殊胜智慧的根本之因，是佛大丈夫所说之法，为了怜悯救护世间的缘故。

“它为最殊胜的佛子所摄受，是求解脱者所欲乐的；听闻这寂静难见之定，为诸佛子所爱乐。

“这是诸佛圆满智慧之处，有智慧的菩萨生起求取之心，他的心清净而没有烦恼，应当修习这样的寂灭之定；

“身业清净，口业也清净，如来为他显示解脱之门，没有杂秽，没有爱欲的束缚，应当勤修这个三昧；

“不生贪爱与嗔恚之地，能迅速获得大智慧，能生起明而灭除无明，所以应当修习这寂灭之定；

“它能使求解脱的人得到圆满，求三昧的人必定获得，远离讥毁与赞誉，是如来之眼，应当修习这个三昧；

“以神通之力游行于许多佛刹，以神足能见到诸佛的功德，得到陀罗尼门也不难，应当修习这殊胜的寂定；

“它能加持念根而得到菩提，也能加持而见到多佛，以微细的智慧宣说无生，修习这个三昧而得到它并不难。

```
不应法者难觉悟　远离一切文字故
不以音声能了解　曾不闻定故不知
智慧菩萨已解了　如法王说而能知
```

大意是：不与法相应的人难以觉悟这个三昧，因为它远离一切文字的缘故；它不是凭借音声就能了解的，那些人从来没有听闻过此定，所以不能了知。有智慧的菩萨已经解了，如法王所说的那样能够了知。

“这寂灭而不可毁坏之法，菩萨能够测量，只是为了救度世间的缘故。

“勇猛精进，能善加受持，坚固护念，恒常不失，具有尽苦的智慧以及灭的智慧，佛还在宣说这个三昧吗？

“演说一切法无生，也宣说一切诸有之生，这是诸佛如来最微妙的智慧，佛还在宣说这个三昧吗？”

【按】末句“演说一切法无生，亦说一切诸有生”，正是二谛并说：胜义中一切无生，世俗中随缘示现诸有之生。能这样同时宣说而不相违，才是诸佛最妙的智慧。

## 六、王子自述往昔修行

这位王子所显示的这些法，使八十亿千那由他的众生得到殊胜的随顺音声忍，对于殊胜的菩提不再退转。

坚固力王回答儿子说：“这位佛世尊现在仍然住世。”

国王问王子这样的话：“你是在哪里听到这些法的？”

王子说：“请听我说，刹帝利王！我曾经见过十亿尊佛，在一劫之中全都供养过，具足地请问过这个寂定。

“在过去九十四劫中，我常常得到了知宿命的智慧，从此不再生于胞胎之中，正是由于修习这个三昧之力。

“我在那些佛那里恒常听法，听了之后深信而修习；我常常坚固地生起这样的信心：必定证得菩提，没有怀疑。

“在受持读诵这个三昧的时候，如果有人来问我，乃至在梦中都没有疑网，一定会成就无上之道。

“我自从得到无贪爱之后，自知决定必定成佛；我也常常这样生起希求：不知什么时候能得到菩提？

“为了修学受持这殊胜的三昧，如果有比丘教导我，我对这个人生起恭敬，也像恭敬诸佛一样。

“对于教我一首偈颂的人，在修行菩萨随顺忍的时候，我以好心瞻仰他如同良师，以谦卑的身形恭敬供养他。

“对于年老、年少、中年的比丘，我都以惭愧谦下之心生起恭敬；恭敬他们能得到现世的称誉，福德与后世的名声也都增长。

“对于互相违逆诤论之事，我不欣乐；那时我安住于少事之中，能了知恶业趣向恶道，能了知善业趣向善道。

“那些不如法而放逸的人，我从他们那里听到不可爱的话，也自己思念这是自己往昔的恶业所致，凡是所造之业都不会失坏。

“那时我不嗔恨，也不傲慢，依照佛所说的忍力勤加修行；诸佛恒常赞叹忍辱，修习忍辱容易得到菩提之道。

“我本来持戒恒常清净，也使众生安住于清净戒律；恒常赞叹持戒最为上等，由于自己安住于清净戒律，人们才信受；

“恒常赞叹阿兰若寂静之处，自己也安住于此，清净持戒；劝人修行八关斋戒，也教导他们修学菩提；

“劝人修习清净梵行，也教导他们安住于法义；为他人显示菩提之道，在命终之后见到多佛。

“我忆念过去世的劫中，有佛名号叫妙声身，我在那位佛前发下弘誓：恒常安住于忍力而不倾动。

“我当初作这样的誓愿之后，经过八亿四千万年，那时魔来讥毁辱骂，我的心从来没有变动。

“那时魔的官属被降伏之后，知道我慈忍的坚固之力，以清净之心接足礼拜，有五百人发起了菩提心。

“我在往昔没有悭吝，恒常赞叹并行持布施；我大富，财物丰足，有好的名声，在饥荒之时作施主。

“如果有比丘受持这个三昧，或者能修习并为他人宣说，我就亲自恒常供养他，以这样的心愿使他得以成佛。

“那时我有这样无上的善业，见到佛世尊、人中最上者，生生世世恒常受具足戒，成为比丘，听受法师的教导。

“我常乐于头陀之行，也住在空寂的阿兰若林中，不为饮食而谄曲，少分所得都知足。

“我在一切时中没有嫉妒，也常常不贪著在家生活；既然不贪著居家，也不憎嫉，就欣乐于阿兰若而没有退失。

“那时我恒常安住于慈行，即使有人毁骂也不嗔恚；以慈悲之心善加调柔，名闻之花鬘遍满十方。

“我常常修习少欲知足，乐于苦行，修习阿兰若行，也恒常乞食而不厌倦，誓愿坚固而不动摇。

“我修习信心，常常清净，对于如来的信心更加增上；正是由于信佛有殊胜的利益，我诸根不缺，恒常端正。

“如佛所说就能实行，成就这样的坚固之行；这坚固之行有什么利益呢？诸天来供养，欢喜劝请说法。

“我所演说的这些功德，包括世间的上妙功德和其余的功德，有智慧的人都应当修学，这是为了求取菩提道的修行者。

“我现在忆念往昔所行的难行之行，是我过去常常修行的；如果现在要演说，需要很长时间，我与您一同前往佛所吧。”

## 七、父王闻法出家，世尊结说本生

那位具大利智的殊胜菩萨，获得了具足的五神通，以神足之力也前往佛所，与之同行的有梵天王多达千万。

坚固力王心中欣喜，与诸眷属亿万大众，一同前往如来世尊之处，顶礼接足，住立佛前。

佛那时了知国王心中所乐，就为国王宣说这个三昧；这位国王听闻这个三昧之后，舍弃王位而出家。

他出家之后，对于这个三昧受持、读诵，为他人宣说；后来经过六千劫，成佛，名号叫莲花上。

国王有眷属六百亿，同时随从国王前往佛所；他们听闻这样殊胜的三昧，欣喜踊跃，也都出了家。

那些出家的人对于这个三昧受持、读诵，为他人宣说；经过六十那由他劫，在同一劫中全都成佛，

名号都叫善调伏智上佛，无量人天兴起供养；每一尊佛都具有大名称，度脱恒河沙数的众生。

```
坚固力王我身是　修行胜妙菩提行
昔时我子五百人　是彼最后护法者
```

大意是：那位坚固力王就是我（释迦牟尼佛）的前身，当时正在修行殊胜微妙的菩提之行；往昔我的五百个儿子，就是将来最后护持此法的人。

【按】此处原文所指稍有曲折：偈中先说化生王子（功德力王转生）劝父王坚固力出家，世尊在这里点明坚固力王是自己的前身，又说往昔的五百子是“最后护法者”，即末世护持此三昧的人。这与第一卷月光童子与五百人共同发愿护持此定的情节前后呼应。

我在这样的千亿劫中，勇猛精进，远离懈怠，专心求取这殊胜的三昧，正是为了无上菩提的缘故。

童子！如果有诸菩萨想要得到这殊胜之定，应当精进勇猛，不顾惜身命，应当学我这样勤奋精进。

《月灯三昧经》卷第四终
