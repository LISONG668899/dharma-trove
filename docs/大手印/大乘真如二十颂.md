# 大乘真如二十颂

梅纪巴（阿瓦都帝巴·无二金刚）造　据藏文译出

## 题解

《大乘真如二十颂》（梵 Tattvamahāyānaviṃśaka，藏 de kho na nyid theg pa chen po nyi shu pa，直译"真如大乘二十［颂］"）收于德格版丹珠尔续部释 ཝི 函第 140a 至 141a 页（东北目录 D2250），紧接在《不作意论证》（D2249）之后，同属梅纪巴的"无念法类"。由至尊陀利室利智［传授］，译师僧伽罗·释迦光译出。

本篇与前面的《大乘二十颂》（D2248）题名相近，但内容与译者完全不同，是另一部作品。D2248 主要讲心性之见，本篇则主要讲密咒乘：以"智慧"（般若）为一切本尊、一切显现的真如；把密咒行者分为下、中、上三品，下品修业手印、三昧耶手印与完整的坛城，中品修智慧手印与自加持，上品则直接趣入大手印；最后以"大手印即是三身"作结。

全篇大致可分为十节：

一、智慧遍一切众生，诸本尊都是智慧的显现；二、般若的体相；三、密咒行者的三品：下品与中品的修法；四、生起本尊与习气；五、上品：趣入大手印；六、如梦中之女，一切唯心，觉知依于上师；七、如米成饭，无明转为明；八、刻意思维不是不可思议；九、轮之瑜伽：大手印即是三身；十、造者与回向。

本篇是密乘的论著，所说的业手印、三昧耶手印、智慧手印、坛城、自加持、本尊生起等，都属于密法的修持，有其严格的条件与次第，须依具德上师的灌顶、口授与亲自引导，不可凭文字理解，更不可自行揣度而行。

其中第八节"凡是刻意思维的，就不是不可思议"，与《真如宝鬘》第十五节"有意地不去思维，不能称为不可思议"、《不作意论证》所说的"不作意"意思相通。

体例：按意义单元分为十节，节题是译者所加；每节先列藏文原颂于代码块中，再译出；为了便于理解而补的字，都放在方括号中。原文含混或可有两解之处，以"【按】"说明，不妄补内容。原文异文依校勘惯例取后一读。文末附通篇连读。

## 一、智慧遍一切，诸本尊即智慧的显现

```
ཤེས་རབ་སྣ་ཚོགས་རྣམ་པར་སྨིན། །
རྣམ་མེད་དང་ནི་རྣམ་ཉིད་བྲལ། །
འདི་ཡི་དེ་ཉིད་ཤེས་རབ་འདོད། །
གང་ཕྱིར་འགྲོ་བ་ཁྱབ་པའི་བདག །
ཤེས་རབ་སྲིད་དང་མཉམ་བདག་ཉིད། །
སྐུ་གསུམ་ཐེག་པའི་གསུམ་པ་འདིས། །
དེ་ཉིད་འཁོར་ལོ་བདེ་བའི་ཐབས། །
དེ་ནི་རྣལ་འབྱོར་བདག་དང་གཞན། །
འཇམ་དཔལ་རྡོ་རྗེ་སྒྱུ་མ་ཆེ། །
རྡོ་རྗེ་མཁའ་འགྲོ་དེ་བཞིན་གཞན། །
སྣང་བའི་བྱེ་བྲག་ཤེས་རབ་ཉིད། །
དེ་ཉིད་རྒྱལ་བའི་བདག་ཉིད་གྲོལ། །
```

智慧成熟为种种［显现］，远离"无相"与"有相"本身；这［一切］的真如，被承许为智慧，因为它是遍于众生的体性。智慧以等同于三有为体性；以这三身之乘中的第三［乘］，真如、轮、安乐之方便——那就是瑜伽，自与他；文殊金刚、大幻化、金刚空行，以及其他［本尊］也是如此——种种显现的差别，都是智慧本身；那本身就是胜者的体性，就是解脱。

【按】第一句"shes rab sna tshogs rnam par smin"，直译是"智慧种种成熟"，意思较难确定；这里理解为智慧成熟、显现为种种相，存疑。"远离无相与有相"，即远离唯识的无相派与有相派（见《真如宝鬘》）。

第六至十句较难确定。"三身之乘中的第三［乘］"（sku gsum theg pa'i gsum pa），可能是指声闻、缘觉、大乘三乘中的第三乘——大乘，或大乘中的密咒乘；"真如、轮、安乐之方便"（de nyid 'khor lo bde ba'i thabs），可能是在列举密续或本尊之名：如"真如"可能指《真实摄经》，"轮"与"安乐"可能指胜乐（'khor lo bde mchog）；"自与他"（bdag dang gzhan），可能是"自加持"等修法，也可能是"自身瑜伽与他身瑜伽"。随后的"文殊金刚"（《密集》一系的本尊）、"大幻化"（Mahāmāyā）、"金刚空行"（Vajraḍāka），都是无上瑜伽续的本尊或续名。全段的大意是：各种续部、各种本尊，都只是智慧的种种显现差别。以上是依上下文的推测，存疑。

## 二、般若的体相

```
བསམ་གྱིས་མི་ཁྱབ་སེམས་པ་ཉིད། །
གཉིས་དང་གཉིས་མེད་དེ་བཞིན་ནོ། །
རྣམ་པ་ཀུན་གྱི་མཆོག་ལྡན་པ། །
དངོས་དང་དངོས་མེད་གཟུང་དང་འཛིན། །
རྣམ་པར་ཤེས་པས་བོར་བའི་སེམས། །
དམིགས་པ་མེད་ཅིང་བླ་ན་མེད། །
དག་ཅིང་ཞི་བ་སྣང་བ་མེད། །
རིག་པ་ཤེས་རབ་ཅེས་སུ་གྲགས། །
```

不可思议的心本身，二与无二也都是如此；具足一切殊胜相；那以识舍弃了有实与无实、所取与能取的心，无所缘、无上、清净、寂静、无显现——这样的觉知，被称为"般若"。

【按】"以识舍弃了"（rnam par shes pas bor ba），意思不很清楚，可能是说"舍弃了［以］识［为主的］有实无实、能取所取之分别"；这里照字面译出，存疑。"具足一切殊胜相"，见《大乐义明示》结颂按语。

## 三、密咒行者的三品：下品与中品

```
འདི་ལ་ཞུགས་པར་གྱུར་པ་ནི། །
གསང་སྔགས་ཆོས་ཀྱིས་རྣམ་པར་གསལ། །
གང་ཕྱིར་སྣ་ཚོགས་པ་ཡི་ཐབས། །
འདི་ལ་ཆུང་འབྲིང་ཆེན་པོ་ཡིས། །
ལས་དང་དམ་ཚིག་ཕྱག་རྒྱ་དག །
འཁོར་ལོ་རྫོགས་པར་སྒོམ་པ་ཉིད། །
མཐའ་མའི་བྱང་ཆུབ་བསམ་གཏན་དེ། །
དག་པའི་དེ་ཉིད་ཁ་ཕྱིར་བལྟས། །
ཡེ་ཤེས་ཕྱག་རྒྱ་སྙོམས་འཇུག་པས། །
འཇམ་པའི་རྡོ་རྗེ་ལ་སོགས་གཙོ། །
བདེན་མིན་རྫུན་གྱི་རྣམ་པ་མིན། །
འབྲིང་པོའི་རྣལ་འབྱོར་བདག་ཉིད་ཡིན། །
བདག་བྱིན་བརླབ་པའི་གོ་འཕང་ཤེས། །
གང་ཕྱིར་དེ་ཉིད་ནུས་པ་མེད། །
དེ་རྣམས་ལ་ནི་ཡང་དག་བསྟན། །
རིམ་གྱིས་བྱང་ཆུབ་གྲུབ་པའོ། །
```

趣入这［般若］的道路，由密咒之法而得以明示，因为［密咒］有种种方便。在这里，［行者有］下品、中品与上品。

［下品行者］修业手印与三昧耶手印，以及完整的坛城；那［所谓］最终的菩提禅定，［却］背向了清净的真如。

［中品行者］以与智慧手印的双入，［观想］文殊金刚等为主尊；［所观］不是真实，也不是虚妄的相——这是中品的瑜伽体性。［他们］了知自加持的果位；因为［他们］没有［直接证悟］真如本身的能力，所以为他们如实开示［这种方便］，［使其］逐渐成就菩提。

【按】这一节把密咒行者分为三品：下品以业手印（las kyi phyag rgya）、三昧耶手印（dam tshig gi phyag rgya）与完整的坛城观修为主；中品以智慧手印（ye shes kyi phyag rgya）与自加持为主；上品见下文第五节，直接趣入大手印。"手印"在这里是密续的专门用语，其中的业手印、智慧手印等，在无上瑜伽续中有特定的内涵与极严格的条件，只能在具德上师座前依灌顶与口授来理解与修持，这里只照原文译出名目，不作任何引申。

"背向了清净的真如"（dag pa'i de nyid kha phyir bltas），kha phyir bltas 字面是"面向外"，可能是说下品行者的修法着重于外在的仪轨，还没有直接面对真如；也可能是说这种禅定"背离"了真如。这里依前一种语气较轻的理解，存疑。"不是真实，也不是虚妄的相"，指中品行者所观的本尊如幻，非真非妄。

## 四、生起本尊与习气

```
ལྷ་རྣམས་མངོན་པར་དགོད་ཅེ་ན། །
འདི་ལ་བག་ཆགས་ཅི་སྟེ་མེད། །
བག་ཆགས་ཉིད་ནི་རྣམ་དག་ན། །
ཐམས་ཅད་དུ་ཡང་དེ་བཞིན་ནོ། །
```

如果［有人问：］"［既然］要明显地安立诸本尊，那么在这里为什么没有习气呢？"［回答是：］如果习气本身已经清净了，那么在一切处也都是如此。

【按】这一颂回应一个疑问：生起次第中观想本尊，岂不是又在造作新的习气？作者回答：当习气本身被认出是清净的，在一切显现中也都是清净的，所以观想本尊并不增长习气。这里依上下文的理解，存疑。

## 五、上品：趣入大手印

```
སླར་ཡང་རྣལ་འབྱོར་དེ་ཉིད་མཐོང་། །
ཕྱག་རྒྱ་ཆེ་ལ་མཆོག་ཏུ་གཞོལ། །
དངོས་པོ་ཀུན་གྱི་རང་བཞིན་གྱི། །
དབང་པོ་མཆོག་གིས་གནས་པར་བྱ། །
ངོ་བོ་ཉིད་ཀྱི་བདེ་ཐོབ་པས། །
རྣམ་པར་རྟོག་པ་ཐམས་ཅད་སྤངས། །
གང་ཕྱིར་འགྲོ་བ་དེ་ཉིད་ཡིན། །
དེ་ཕྱིར་ཐམས་ཅད་རྟོག་པ་མེད། །
```

再者，［上品的］瑜伽士见到真如，最殊胜地趣入大手印；应当以最上的根器，安住于一切事物的本性之中。由于获得了自性之乐，一切分别都已舍弃；因为众生就是真如，所以一切都没有分别。

【按】这一节说明上品行者：不依赖业手印、智慧手印等方便，而直接见到真如、趣入大手印（phyag rgya chen po），安住于一切事物的本性。这正是梅纪巴所说的大手印之道。

## 六、如梦中之女：一切唯心，觉知依于上师

```
ཕྱི་རོལ་དངོས་ཡིད་ཀྱིས་གཟུང་ལ། །
གང་ལ་འཁྲུལ་པ་སྣང་མི་འགྱུར། །
རྨི་ལམ་བུད་མེད་གསལ་བ་ཉིད། །
སེམས་ཅན་དོན་ནི་བྱེད་པ་སྟེ། །
ཐམས་ཅད་དངོས་པོའི་རང་བཞིན་འདི། །
སེམས་ཙམ་དུ་འགྱུར་བྱང་ཆུབ་བོ། །
སེམས་ཀྱི་འདོད་པ་སེམས་མ་ཡིན། །
རང་གིས་རིག་པ་སེམས་མིན་ཏེ། །
རིག་པ་བླ་མ་ལ་ལྟོས་འགྱུར། །
```

外在的事物，被心所执取；［但对证悟者而言，］在其中不再显现迷乱；［就像］梦中的女子清楚显现，［却也能］作利益众生之事。这一切事物的本性，都成为唯心——［这就是］菩提。

心所欲求的，并不是心；自证也不是心；觉知要依靠上师。

【按】"梦中的女子清楚显现，作利益众生之事"（rmi lam bud med gsal ba nyid / sems can don ni byed pa），意思较难确定，可能是说：如梦中的女子虽然不实，却清楚显现并能起作用；同样，如梦的显现虽无自性，证悟者仍能以之利益众生。这里依此理解，存疑。

"心所欲求的不是心，自证也不是心"，意思可能是：心所缘取的对象不是心本身，而能自证的觉知也不能被执为一个"心"；所以真正的觉知不能靠心去寻求，而要依靠上师的指示。这与《大乘二十颂》第十二颂"由上师才成为超越分析的"意思一致。

## 七、如米成饭，无明转为明

```
དངོས་མེད་ཀུན་གྱི་ངོ་བོ་ཉིད། །
མིང་འདི་མི་འདོད་པ་ནི་གང་། །
དངོས་པོ་ཀུན་གྱི་རང་བཞིན་འདི། །
སོ་སོར་རྟོགས་པར་དཀའ་བ་ཡིན། །
དེ་ལ་སོགས་པ་འདུས་པ་ན། །
ཇི་ལྟར་འདི་ནི་འབྲས་ལས་ཟན། །
དེ་ལྟར་དེ་བཞིན་ཉིད་དག་ལ། །
མ་རིག་པ་ནི་རིག་པར་འགྱུར། །
```

一切无实之法的本体——谁会不承许这个名称呢？［然而］一切事物的这一本性，是难以一一证悟的。当那些［因缘］聚合时，就像从米成为饭一样，同样，在真如之中，无明就转成为明。

【按】"谁会不承许这个名称呢"（ming 'di mi 'dod pa ni gang），意思是：说一切法以"无实"为本体，没有人会反对这个说法；但真正一一证悟它，却很困难。"如米成饭"的比喻是说：米本身就是饭的因，因缘具足时，米就成为饭，不需另外的东西；同样，无明本身在真如中就转为明（rig pa），不是另外得到一个明。这与《大乘二十颂》第八颂"菩提与烦恼不异"、《真如十颂》第三颂"从迷乱中成为无贪著"的意思相通。

## 八、刻意思维不是不可思议

```
གང་ལ་བསམ་པ་བསམ་གཏན་ཡིན། །
དེ་ལ་བསམ་མི་ཁྱབ་ཀྱིས་མིན། །
བསམ་གྱིས་མི་ཁྱབ་རྣལ་འབྱོར་པ། །
སངས་རྒྱས་ཀྱིས་ནི་གྲོལ་བར་བསྟན། །
```

凡是［有所］思维的禅定，那就不是［依］不可思议［而修的］；不可思议的瑜伽士，佛陀开示［他］是已经解脱的。

【按】这一颂与《真如宝鬘》第十五节"有意地不去思维，不能称为不可思议"、《不作意论证》所说的"不作意"相呼应：有所思维、有所造作的禅定，不是不可思议的境界；真正的不可思议，是离开造作的觉知。第一句"gang la bsam pa bsam gtan yin"，也可以理解为"凡是有所思的，就［只是］禅定［而已］"，意思相近。

## 九、轮之瑜伽：大手印即是三身

```
འདི་ནི་འཁོར་ལོའི་རྣལ་འབྱོར་ཡིན། །
གང་ཕྱིར་ཕྱག་རྒྱ་ཆེ་དེ་ཉིད། །
ཆོས་དང་ལོངས་སྤྱོད་སྤྲུལ་པ་སྟེ། །
གང་ཕྱིར་དེ་ནི་རྣམ་ཀུན་ཡིན། །
བྱ་བ་བྱས་པས་བསམ་དང་བྲལ། །
དོགས་པ་ཀུན་ལ་ཁ་ཕྱིར་བལྟས། །
སྤྱོད་ལམ་རྣམ་པ་བཞི་ལྡན་པ། །
སངས་རྒྱས་འདི་ནི་སངས་རྒྱས་བཞེད། །
```

这就是轮之瑜伽，因为那大手印本身，就是法身、报身与化身；因为它就是一切相。［证悟者］所作已办，所以远离思维；对一切疑惧都已背向；具足［行、住、坐、卧］四种威仪——这样的佛，被诸佛所承许。

【按】"轮之瑜伽"（'khor lo'i rnal 'byor），可能是指坛城之轮的瑜伽，即把一切显现都观为坛城；也可能是"胜乐［轮］的瑜伽"，存疑。"大手印就是三身"，与《五部自性》《大乘二十颂》以三身作结的说法一致。

"对一切疑惧都已背向"（dogs pa kun la kha phyir bltas），即《俱生六颂》所说的"无疑惧"，见该篇第四颂按语。"具足四种威仪"，与《大乘二十颂》第九颂"身的作为是如法的威仪"相应：证悟者并不舍弃如法的日常行止。

## 十、造者与回向

```
གཉིས་མེད་གཉིས་སུ་མེད་པས་བྱས། །
བདག་གིས་ཐོབ་པའི་བསོད་ནམས་ཀྱིས། །
དེ་ནི་འགྲོ་བ་གཉིས་མེད་ཉིད། །
དེ་ཡིས་བདེ་བ་ཆེན་པོར་ཤོག །
```

［本论］由无二者——无二［金刚］所造。以我所获得的福德，愿众生——［他们本来］就是无二——以此获得大乐！

【按】第一句"gnyis med gnyis su med pas byas"，字面是"由无二、无二者所作"，这里理解为作者以自己的名字"无二金刚"（gnyis su med pa'i rdo rje）作双关：既署名，又说本论是由"无二"［之智］所作。这一理解是推测，存疑。末两句说众生"本来就是无二"，愿他们由此获得大乐。

## 跋

［《大乘真如二十颂》，］阿瓦都帝巴·无二金刚所造，圆满。

由至尊陀利室利智［传授］，译师僧伽罗·释迦光译出。

【按】"僧伽罗·释迦光"（seng kar shākya 'od），"僧伽罗"（seng kar）可能是地名或族名，指他来自或曾到过僧伽罗（今斯里兰卡）；也可能是别的称号，存疑。陀利室利智，见《真如口诀·道歌宝藏》跋语按语。

## 通篇连读

敬礼至尊佛陀！

智慧成熟为种种显现，远离无相与有相本身；这一切的真如被承许为智慧，因为它是遍于众生的体性。智慧以等同于三有为体性；以这三身之乘中的第三乘，真如、轮、安乐之方便，那就是瑜伽，自与他；文殊金刚、大幻化、金刚空行，以及其他本尊也是如此——种种显现的差别都是智慧本身，那本身就是胜者的体性，就是解脱。

不可思议的心本身，二与无二也都是如此；具足一切殊胜相；那舍弃了有实与无实、所取与能取的心，无所缘、无上、清净、寂静、无显现——这样的觉知，被称为般若。

趣入这般若的道路，由密咒之法而得以明示，因为密咒有种种方便。在这里，行者有下品、中品与上品。下品行者修业手印与三昧耶手印，以及完整的坛城；那所谓最终的菩提禅定，却背向了清净的真如。中品行者以与智慧手印的双入，观想文殊金刚等为主尊；所观不是真实，也不是虚妄的相，这是中品的瑜伽体性。他们了知自加持的果位；因为他们没有直接证悟真如本身的能力，所以为他们如实开示这种方便，使其逐渐成就菩提。

如果有人问："既然要明显地安立诸本尊，那么在这里为什么没有习气呢？"回答是：如果习气本身已经清净了，那么在一切处也都是如此。

再者，上品的瑜伽士见到真如，最殊胜地趣入大手印；应当以最上的根器，安住于一切事物的本性之中。由于获得了自性之乐，一切分别都已舍弃；因为众生就是真如，所以一切都没有分别。

外在的事物被心所执取，但对证悟者而言，在其中不再显现迷乱；就像梦中的女子清楚显现，却也能作利益众生之事。这一切事物的本性都成为唯心，这就是菩提。心所欲求的并不是心，自证也不是心，觉知要依靠上师。

一切无实之法的本体，谁会不承许这个名称呢？然而一切事物的这一本性，是难以一一证悟的。当那些因缘聚合时，就像从米成为饭一样，同样，在真如之中，无明就转成为明。

凡是有所思维的禅定，那就不是依不可思议而修的；不可思议的瑜伽士，佛陀开示他是已经解脱的。

这就是轮之瑜伽，因为那大手印本身就是法身、报身与化身，因为它就是一切相。证悟者所作已办，所以远离思维；对一切疑惧都已背向；具足行住坐卧四种威仪——这样的佛，被诸佛所承许。

本论由无二者——无二金刚所造。以我所获得的福德，愿本来就是无二的众生，以此获得大乐！

《大乘真如二十颂》，阿瓦都帝巴·无二金刚造，圆满。由至尊陀利室利智传授，译师僧伽罗·释迦光译出。
