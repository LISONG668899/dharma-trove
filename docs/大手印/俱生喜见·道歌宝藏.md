# 俱生喜见·道歌宝藏

阿阇黎巴德造　据藏文译出

## 题解

本篇梵名 Sahajānandagītikādṛṣṭi，藏名 lhan cig skyes dga'i do ha mdzod kyi glu'i lta ba，直译为《俱生喜道歌宝藏之歌的见》，本站依通行题名称为《俱生喜见·道歌宝藏》。收于德格版丹珠尔续部释 ཟི 函第 4b 页（东北目录 D2348）。跋语说是"阿阇黎巴德所造"，没有记载译者。

巴德（Bhadepa），一般认为即八十四成就者中的巴德巴（Bhadrapa），已译的《行歌藏释》（D2293）中也收有以"巴德"为名的行歌。依成就者传记，巴德巴原是一位重视洁净的婆罗门，后来在上师引导下放下净与不净的分别而成就。

全篇只有十几句，以"得到了合缝的时候，贪、嗔、痴就在本处清净"为叠句，分三节：先说二取之毒紧贴胸前；再说"合缝"无价、等同虚空；最后说向一切处寻找，找到最后连自己也无可执取，能所双泯，就是得到了"合缝"。全篇的关键词"ཚེམ་བུ"字面是"缝合处、针脚"，用法特别，本译依字面译为"合缝"，在第一节按语中说明了几种可能的读法。

全篇没有涉及具体的密法修持。题名中的"俱生喜"，是密乘四喜之一，这里指俱生智本身。

体例：藏文原文全部保留在代码框中，按意义分节，每节后附汉译；凡标"存疑"的按语，表示本译对原文意思没有把握。藏文依 Esukhia 德格丹珠尔电子版。

## 一、二取之毒，巴德入睡

```
གཉིས་སྦྱོར་དུག་པོ་བྲང་ལ་བསྟབས། །
བྷ་དྷེ་པ་ནི་གཉིད་དུ་ལོག། །
ཇི་ལྟར་ཀུན་ལ་མཁས་པ་ཡིས། །
དུག་པོ་དེ་ནི་ཇི་ལྟར་ཁྱེར། །
ཚེམ་བུ་ཐོབ་པར་གྱུར་པ་ན། །
ཆགས་སྡང་གཏི་མུག་གནས་སུ་དག། །
```

二取结合的毒，放在胸前；巴德却睡着了。那精通一切的人，是怎样把那毒拿走的呢？——得到了合缝的时候，贪、嗔、痴就在本处清净。

【按】存疑。这四句文义隐晦。"二取结合的毒"（གཉིས་སྦྱོར་དུག་པོ），本译理解为能取与所取二元对立的毒，即轮回的根本；"放在胸前"，比喻它紧贴自身、无时不在。"巴德睡着了"，可能比喻放下了一切造作，安住于本然；"精通一切者如何拿走毒"，可能指上师以口诀除去二取之毒，也可能是反问：心性本来没有毒可拿。所指都不能确定。

【按】"ཚེམ་བུ"一词是全篇的关键，字面意思是"缝合处、针脚"，本译译为"合缝"。依上下文推测，它比喻把两片布缝成一片，即能所二取合而为一、双运无缝的俱生智，与首句"二取结合的毒"恰好相对：二取分立是毒，合而无缝就是俱生。也可能是某个形近词（如"宝珠"）的讹写。今依字面译出，存疑。

【按】"贪、嗔、痴就在本处清净"（གནས་སུ་དག），是说三毒不必另外去断除，在认出俱生的当下，就在它们本来的位置上自然清净。这两句是全篇的叠句。

## 二、合缝无价，等同虚空

```
ཚེམ་བུ་འདི་ལ་དབྱེ་བའམ། །
རིན་གྱི་གྲངས་ཀྱིས་ཆོད་པ་མེད། །
ད་ནི་བདག་གི་ཚེམ་བུ་འདི། །
ནམ་མཁའ་དང་ནི་མཉམ་པར་འགྱུར། །
ཚེམ་བུ་ཐོབ་པར་འགྱུར་བ་ན། །
ཆགས་སྡང་གཏི་མུག་གནས་སུ་དག། །
```

这合缝，没有分别，也不能以价值的数目来衡量；如今，我的这合缝，已与虚空平等——得到了合缝的时候，贪、嗔、痴就在本处清净。

【按】"不能以价值衡量"，与萨惹哈等道歌中"无价之宝"同义；"与虚空平等"，是说俱生智无边无际，周遍一切。

## 三、遍寻不得，自身亦无

```
བྷ་དྷེ་ཚེམ་བུ་ཚོལ་དུ་ཕྱིན། །
ཐམས་ཅད་དུ་ནི་བཙལ་བས་ན། །
བདག་ཉིད་ཀྱང་ནི་དམིགས་མེད་འགྱུར། །
ཚེམ་བུ་ཐོབ་པར་འགྱུར་བ་ན། །
ཆགས་སྡང་གཏི་མུག་གནས་སུ་དག། །
```

巴德出去寻找合缝；在一切处寻找之后，连自己也变得无可执取了——得到了合缝的时候，贪、嗔、痴就在本处清净。

【按】这是全篇的转折：向外到处寻找，找不到所寻的对象；而在寻找的尽头，连能寻找的"我"也找不到了。能所双泯，就是"得到合缝"。这与帝洛巴《恒河大手印》"以心观心，分别止息"、萨惹哈"以自心看自心"同一意趣。
