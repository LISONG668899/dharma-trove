# 那连提耶舍译《月灯三昧经》卷第二

高齐天竺三藏那连提耶舍汉译　白话今译

## 一、声德如来与大力王的往昔因缘

这时，世尊告诉月光童子说：“在过去久远、无量无边、不可思议、超过阿僧祇劫之前，那时有一尊佛出现于世，名号是声德如来、应供、正遍知、明行足、善逝、世间解、无上士、调御丈夫、天人师、佛、世尊。

“童子！那时声德如来、应供、正遍知在第一次法会上，聚集了八亿声闻弟子，都是阿罗汉：诸漏已尽，已经获得自利，灭尽了一切三有的结缚，依止正教，心善解脱，能到达一切心得自在的彼岸。第二次法会聚集了七亿大众，第三次法会聚集了六亿大众，也全都是大阿罗汉：诸漏已尽，已经获得自利，灭尽了一切三有的结缚，依止正教，心善解脱，能到达一切心得自在的彼岸。

“童子！那时这位佛的寿命是四万岁。当时阎浮提安稳丰乐，人民繁盛，遍满各地。

“童子！那时阎浮提有两位大国王：一位名叫坚固力，一位名叫大力。这两位大王各自统领半个阎浮提，两王的国土都安稳丰乐，人民繁盛，遍满各地。当时声德如来出现在大力王的国中。

“童子！那时大力王迎请声德如来和比丘僧，满一千年，以一切随顺、清净、无过失的衣服、饮食、卧具、汤药来供养。

“童子！那位声德如来和声闻僧得到了非常丰厚的利养、恭敬与赞叹。

“那时有一些具有净信的长者和婆罗门，在声德如来及声闻僧那里也发起了勇猛的心意，效法大力王而设供养，也就是以世间财物作为最殊胜的供养。但是这些人并不懂得什么是‘行’的供养。什么是‘行’的供养呢？就是受持五戒、八关斋戒，出家前往佛所，亲近佛、请问佛，而见到甚深的法忍。

“童子！那时声德如来这样想：‘这些众生志向意乐低劣，不能受持五戒、八戒，不能出家前往佛所、亲近请问而见到甚深法忍，不能修习梵行、寂静远离，不能受具足戒而得比丘的身分，也不能受持奉行究竟的善根。这样的寂灭之乐、无上的妙乐，他们全都远离了，只是用世间财物来供养我。这些众生只希求小小的快乐，却以为是最高的快乐；这些众生只看重现世法和后世法，不能爱重究竟的善根。什么叫看重现世法呢？就是贪乐五欲。什么叫看重后世的善根呢？就是乐于生天。什么叫做究竟的善根呢？就是究竟清净、究竟吉祥、究竟梵行、究竟穷尽、究竟最后、究竟涅槃。我现在要宣说这样的法，让这些众生明白，布施之行并不是究竟最殊胜的供养，而应当以无上的修行来供养我。’

“童子！那时声德如来为了觉悟那位大力王以及诸长者、婆罗门等，而说偈道：

“‘如果有人只行财物、饮食的布施，这样彼此之间并不能称为真正的互相尊敬；这样的行为不值得赞叹，诸佛和智者早已远离。

“‘如果有人宣说无我的智慧，这样的殊胜之人应当奉事；他对于圣谛的信心坚定不动，恭敬奉事这样的人，是佛所赞叹的。

“‘如果有人以财物饮食来奉施，只能获得眼前少许的利益；如果能远离这样的布施（而修出离），这个人就成就了出家之行。

“‘如果有人能生起不贪财物之心，又能显示不依财物之法，也能以净信对待那些不蓄财物的修行者，这个人就能迅速成就无上道。

“‘从来没有这样的事：处在五欲之中，对妻子儿女等生起爱著，愚痴的凡夫恒常住在家中，这样的人能够证得漏尽。

“‘厌离五欲如同厌离火坑，能对妻子儿女远离爱染，怖畏在家生活而求出离，这样的人获得殊胜的菩提就不难。

“‘过去、现在、未来的一切如来，从没有一位是常常住在家中、处于贪欲之地，而能获得殊胜妙道的。

“‘舍弃王位如同吐掉鼻涕唾沫，住在远离尘嚣的空闲之处，断除烦恼、降伏诸魔，才能悟解离垢的无为之道。

“‘如果有人在千万亿年中，供养恒河沙数的佛（世雄），不如有人能厌患在家生活，这样的功德才是最上。

“‘以饮食、衣服、种种妙花妙香以及涂香等事来供养佛，比不上出家奉行佛法。

“‘如果有人乐于求取菩提，能利益众生而厌离世间，向空闲寂静处走出七步，这样的福报最为殊胜。’

【按】此处所说“财食施不名相尊敬”，并不是否定布施，而是说布施若只停在世间财物，不是“究竟供养”。真正的供养，是以修行供养，以趣向出离与证悟供养。

“童子！那时大力王听到声德如来、应供、正遍知宣说出家修行的这些义理、利益与名称之后，便这样想：‘照我对佛所说义理的理解，如来并不是说布施波罗蜜就是究竟清净、究竟吉祥、究竟梵行、究竟穷尽、究竟最后、究竟涅槃。’大力王又想：‘住在家中，是不能获得无上果位、修得无上修行的义利的，而我现在正远离这样的修行。我现在一定要剃除须发，披上袈裟，舍家而入于非家，出家修道。’

“童子！那时大力王和他的眷属八万人一起，前后围绕，前往声德佛所，顶礼佛足，右绕三匝，退坐一旁。

“童子！那时声德如来知道大力王及其眷属心中所乐，就为他们宣说‘一切诸法体性平等无戏论三昧’，分别加以显示。

“童子！那时大力王听闻这个三昧，欢喜踊跃，深心爱乐，就在声德佛所舍弃王位，以正信出家，剃除须发，穿上三法衣。出家之后，对这个三昧广泛地听受、读诵、忆持、分别其义理，并如法修行相应。以这一善根，他在二亿劫中不堕恶道。此后又依次值遇二亿尊佛，在这些佛的教法中常常得以出家，在每一尊佛那里都对这个三昧听受、读诵、分别义理、修行相应。以这一善根，经过一百亿劫之后，他成就了佛道，名号为智勇如来、应供、正遍知、明行足、善逝、世间解、无上士、调御丈夫、天人师、佛、世尊，利益了无量无边的众生，然后才入般涅槃。童子！你应当看到，这个三昧有这样的神力，能使菩萨感得佛的智慧。

“童子！大力王所带领的八万眷属，听闻这个三昧，也都欢喜踊跃，心中非常爱乐，也都随着国王以正信出家，剃除须发，披上法衣。这些出家人听闻这个三昧，读诵、受持、分别解说、修行相应。以这一善根，他们在二亿劫中不堕恶道，每一劫中都值遇千万尊佛，在那些佛的座下常常得以出家。出家之后，听闻这个三昧，读诵、受持，如应修行而安住其中。以这一善根，在此后满百千劫时，他们在各个不同的世界成就佛道，名号都叫坚固勇健堪能如来、应供、正遍知、明行足、善逝、世间解、无上士、调御丈夫、天人师、佛、世尊。他们利益了无量众生之后，才入无余涅槃。

“童子！这个三昧有大威力，能使菩萨招致无上正等正觉。”

## 二、以偈重宣往昔因缘

这时，世尊想重新宣说这一意义，而说偈道：

我忆念过去久远之世，不可思议劫以前有佛出世，能为众生作种种利益，名号叫声德大仙尊。

第一次法会聚集满八亿众，全都是声闻弟子；第二次法会聚集七亿，第三次法会有六亿阿罗汉。

他们一切漏尽，没有烦恼，种种神通之力都已到达彼岸。那位佛的寿命是四万岁，国土世界非常庄严清净。

那时阎浮提有两位国王，名号叫大力和坚固力；这两位国王所住的国土，各自统领半个阎浮提。

佛出现在大力王的国中，诸殊胜的人天都来供养；这位国王对佛生起净信，恭敬供养满一千年。

国中无量人民效法这位国王，以种种供养来供养如来，但都只是用世间财物，不是以法供养；佛和声闻众因此都非常丰足。

那时世尊这样想：“我要宣说这样的法，使他们舍弃贪欲，一定要让这位国王生起厌离，在我的法中出家。”

那时人中至尊说偈道：“舍弃恶法，就是佛的教导；在家有许多过失，具足种种痛苦；如法修行，才是真正供养佛。”

当时国王听到这样的偈颂，独自走到空闲之处，这样思维：“我现在不能再处在家庭的缠缚中，而要作最殊胜的法供养。”

于是他舍弃王位，如同吐掉鼻涕唾沫，和八万眷属一同前往佛所，头面礼佛，住立在世尊面前。

佛知道他们心中所乐，为他们宣说难得一见的寂灭之定；他们听了心生爱敬，欢喜悦乐，全都欢喜出家。

出家之后，对这个三昧读诵、受持、广为分别；在此后的二亿劫中，从未堕入三恶道。

这些人以这些善业，得以见到百亿尊如来，在那些佛的教法中恒常出家，宣说这个殊胜的三昧。

这些人后来都成了佛，同名坚固大精进，利益了无量亿众生，后来入于涅槃，犹如火灭。

那时往昔的大力王，早已成就佛道，名号智勇，利益了无量百亿众生，把他们安置在菩提之中，然后入于涅槃。

既然听到这样殊胜的利益，就要知道：在末世受持此经，是佛所赞叹的；如果能奉持佛的法藏，这些人就能迅速成为人中至尊。

## 三、此三昧的最初所行：三轮清净的供养

“童子！所以，菩萨摩诃萨若爱乐这个三昧，就应当修习最初所行。

“童子！什么是菩萨对这个三昧的最初所行呢？童子！如果菩萨摩诃萨以大悲心为首，无论佛在世时还是佛灭度后，常常精勤地供养，也就是以花鬘、末香、涂香、宝幢、幡盖、音声、歌舞、种种伎乐、衣服、饮食、病瘦医药来供养，并把这些善根全部回向于这个三昧，不再志求其他任何法来供养佛；不求美妙的容色，不求资财，不为生天，不求眷属，心中唯念此法。

“这样的菩萨，尚且在法中都不见有佛，更何况在法之外见到有佛呢？所以，童子！这才是真正的供养佛，而且也不见有佛可得，不执取我想，不求果报。这位菩萨三轮清净，以花鬘、末香、涂香、宝幢、幡盖、音声、歌舞、种种伎乐、饮食、衣服、病瘦医药供养如来，回向无上正等正觉。以这样的善根，得到不可思议的功德、不可思议的果报，得到这个三昧，迅速成就无上正等正觉。”

【按】“尚于法中不见有佛，况复法外而见佛也”，这一句极为关要。上面刚说完以法供养胜于财供养，这里又把“法”与“佛”的执著也一并放下：供养时不见能供、所供、供物，这就是三轮清净。修供养而不落入有相，正是此三昧在行持上的“最初所行”。

这时，世尊说偈道：

如果有人以香奉献无边智慧的佛，能得到无量的香之果报；在千万劫中远离恶趣，永远没有一切臭秽。

在千万劫中修行殊胜之行，供养百万亿如来，成佛时获得殊胜的戒香。如果又能了知并无众生，布施香的人与受香的人二者都不可得，如果能以这样的心来布施，

就能得到柔软殊胜的随顺忍。如果有人增上修习这种忍，为了他人割截自身，如同割取钱币一般毫不吝惜，在千万亿恒河沙劫中，其心坚固而不退转。

怎样才称为“忍”？怎样又称为“随顺”？怎样称为“不退转”？怎样又称为“菩萨”？

欣乐于自性无我之法，因为没有我想，所以没有烦恼，能了知诸法全都尽灭，由于这个因缘，称为“忍”。

诸佛所学的，就随顺着去学；智者如法常常修行，了知诸佛之法而没有疑惑，所以称为“随顺”。

如果修行时有世间的魔，现作佛身，说这样的话：“佛道难以证得，你去作声闻吧。”菩萨不肯信受，这称为“不退”。

觉悟那些具有恶见的众生，让他们知道恶见不能证得甘露之道，劝他们舍弃恶道、安住善趣，所以称为“菩萨”。

得忍的人安住在随顺之道中，以无我之法使众生开悟，乃至在梦中都不起念、不存有众生、寿命之想。

如果有像恒河沙那样无量的魔，化作佛身来到他那里，都说：“身内有一个神我。”菩萨就对他们说：“没有我，你不是佛。”

他以智慧了达诸法皆空，了知之后不再与烦恼共处；因为戏论的缘故，才在言说上说“有”；见到这一点之后，以寂灭之心行于世间。

```
譬如世人所生子　随即为其立名字
诸方推名不可得　当知此字无所来
为立菩萨如是名　菩萨诸方不可求
乃至实际求不得　如是知者名菩萨
```

大意是：譬如世人生了孩子，随即为他起个名字；可是在十方去推求这个名字，都找不到它在哪里，应当知道这个名字是无所从来的。“菩萨”这个名字也是这样安立的，在十方去寻求菩萨都不可得，乃至在实际之中去寻求也不可得。能这样了知的人，才叫做菩萨。

【按】这首偈是以名言观空的典型：名字是假立的，名所指的“菩萨”也是假立的，十方推求、乃至实际中推求都不可得。藏传教授中“寻心不得”的观修，与此推求方式是一致的：不是推理出一个“空”的结论，而是在真实寻求中亲见“不可得”。

即使大海中燃起熊熊大火，菩萨也终究不会生起身见；菩萨住于初发心时，就已断尽一切恶见与烦恼。

他不见有任何生灭之法，也就是所谓的众生与寿命；诸法的体性是空的，犹如幻化，这不是外道所能了知的。

如果对饮食生起贪著，对衣钵生起爱惜悭吝，以及掉举嬉戏、轻浮躁动，这样的人就不懂得佛的菩提。

如果多喜睡眠和懈怠，奸诈虚伪、凶暴、不收敛身心，对诸佛没有清净的信心，这样的人就不懂得佛的菩提。

如果毁破禁戒而没有惭愧，对佛法没有归依与信心，不恭敬同修梵行的人，这样的人就不懂得佛的菩提。

不毁犯清净的戒律，具足惭愧，对佛法深深爱乐，能恭敬同修梵行的人，这样的人就能懂得殊胜的菩提。

以四念处作为圣者的境界，以喜悦作为床座卧具，以禅为饮食，以定为浆水，这样的人就能懂得佛的菩提。

以无我之忍作为经行之处，在空寂的林中修行正念；七觉支的香花非常可爱，嗅闻之后就能成就无上道。

菩萨体悟大道所修的行，不是其他人所能行的境地，也就是不是声闻和缘觉所能行的；有智慧的人谁不贪乐于此呢？

假设我的寿命极其长远，如恒河沙那样无量的劫数，宣说佛的一根毛发的功德也说不尽，因为如来的智慧没有边际。

如果听到这样的大利益，是无畏的世尊所宣说的，就应当迅速自己受持、并教他人受持此定，得到无上菩提就不难。

## 四、入三法忍的法门

“童子！所以，菩萨摩诃萨应当善巧了知入三法忍的法门，也就是了知第一忍、第二忍、第三忍；对于这些忍应当善巧了知，对于其中的智慧也要善巧了知。为什么呢？如果菩萨摩诃萨对于忍和智都能善巧了知，这位菩萨摩诃萨就能迅速证得无上正等正觉。所以，童子！菩萨摩诃萨如果想要迅速求得无上正等正觉，对这三忍法门应当受持；受持之后，为他人广为分别解说，利益安乐无量众生，救济世间，利益安乐诸天与人。”

这时，世尊为月光童子，以偈颂来宣说这入三忍的法门：

对一切众生没有违逆和诤论，口中不说无益的话，常常安住于饶益他人的法，这就称为第一忍。

```
知一切法犹如幻　即于此相不取着
能于智中增无减　是故名为初胜忍
```

大意是：了知一切法都如幻化，对于这如幻之相也不去执取；能使智慧只有增长而没有减损，所以称为第一殊胜忍。

【按】注意“即于此相不取着”：不仅不执著诸法为实有，连“如幻”这一相也不执著。这是防止把“空”“如幻”又变成新的执取对象，与大手印“不执空”的教诫相通。

对诸修多罗已经修学，智慧与善巧的言说恒常相应，对佛的无量智慧毫不怀疑，这就称为第一殊胜忍。

如果听到一切善说之法，就像听佛亲说一样毫无怀疑，能信受一切诸佛之法，这就称为第一殊胜忍。

常常宣扬了义经，如佛所说的那样来演说；如果经中说到我、人和众生，就知道这是引导接引众生的方便。

对于种种外道的各种异见，菩萨心中不受扰乱，反而对那些人生起深切的悲悯，这就称为第二殊胜忍之相。

种种陀罗尼现前，对总持之门没有疑惑，所说的言语都真实不虚，这就称为第二殊胜忍之相。

即使四大，也就是地、水、火、风等，互相转变，对佛的菩提也永不退转，这就称为第二殊胜忍之相。

世间所有的种种工巧技艺，菩萨都能善加修学，见不到还有超过自己的人，这就称为第三殊胜忍之相。

```
奢摩他力得调伏　毗婆舍那山不动
一切众生莫能欺　是名第三胜忍相
```

大意是：以奢摩他（止）的力量调伏了自心，毗婆舍那（观）如山一般不可动摇，一切众生都不能欺惑他，这就称为第三殊胜忍之相。

【按】止使心调柔，观使见不动，二者具足，才能不被任何境界和言说所迷惑。冈波巴大师的大手印教授极重止观双运，于此可见经证。

所有言说都恒常在定中，行、住、坐、卧都恒在三昧，三摩地坚固而到达彼岸，这就称为第三殊胜忍之相。

安住于正定而获得神通，前往许多佛刹说法，智者的神足之力毫无减损，这就称为第三殊胜忍之相。

如果修习这样的寂定时，其他一切众生都不能了知他心的境界和分齐，这就称为第三殊胜忍之相。

即使世界中的一切众生，一时都成了佛、演说佛法，这个人也都能完全领受，这就称为第三殊胜忍之相。

东、西、南、北以及四维、上、下二方也是如此，在一切方中都能见到佛，这就称为第三殊胜忍之相。

能变现无量的身体，每一个身体都作真金之色，前往无量佛刹去说法，这就称为第三殊胜忍之相。

在这佛世界中的所有阎浮提，一切众生都能看见菩萨的形相，诸天和人都认识他，这就称为第三殊胜忍之相。

对于诸佛之法、佛所行之处，以及导师所有的种种威仪，智者都能善加修学，这就称为第三殊胜忍之相。

世界中所有的众生都来赞叹这位菩萨，菩萨若对此心生欣悦，就说明他对佛的智慧还没有修学好；

世界中所有的众生都来骂詈、毁谤这位菩萨，菩萨若对此生起嗔恨之心，应当知道他对佛的智慧还没有修学好；

如果得到利养时心中不欢喜，遭遇损失时没有忧戚，其心安住犹如大山，这就称为第三殊胜忍之相。

第一叫做随顺音声忍，第二叫做思惟随顺忍，第三叫做修习无生忍；修学这三种忍，就能证得菩提。

【按】三忍的次第是：先依言教音声而随顺信解，再经思惟而随顺通达，最后在修习中证无生。这与闻、思、修三慧的次第相应，也就是从听闻教法到亲证法性的完整进路。

对于这三种殊胜之忍，如果有菩萨能够得到，善逝见到这位菩萨时，就会为他授无上菩提之记。

如果有不可思议数亿的众生听到这样的授记，都会发起无上菩提心：“我也要成为人中至尊。”

听到宣说授记的声音，大地即时六种震动，光明普照十方世界，天上降下无量种殊胜美妙的花。

对于这三种殊胜之忍，如果有菩萨能够得到，就再也不见有生与死，对于起与灭也是如此；

对于这三种忍，如果有菩萨能够得到，已经衰老的和正在衰老的都不见，安住于法中而得到这样的境界。

菩萨了知种种法，体性空寂犹如幻化；这空也不是有生有灭的，因为诸法的体性本来空寂的缘故。

如果有众生来恭敬、礼拜、尊重、供养，菩萨对他们没有偏爱，因为深深通达了世间的体性；

如果有众生来打骂，菩萨对他们没有嫌恨与轻慢，反而对此人生起悲心，为的是让他得到解脱；

如果用刀杖和瓦石加害，他的心对此毫无忿怒，安住于无我之忍法中，菩萨不担心生起嗔恚的覆蔽。

菩萨了知种种法，体性空寂犹如幻化；如果能安住在这样的法中，就为一切人天所供养。

有人手持锋利的刚刀，割截他身上的每一个肢节，他的心能够忍受而没有恚恨，悲悯与怜爱反而增广，从来没有坏失。

当别人用刀屠割他的肢节时，菩萨就生起这样的念头：“你如果还没有得到菩提，愿我不证涅槃。”

这样的忍力最为无上，因为安住于无我之忍的缘故。

这些具有大名称的菩萨，在无量那由他劫中修习，又超过这个数目如恒河沙，仍然还没有证得菩提；在这么长的时间里修行佛行，更何况觉悟的智慧，又怎么说得尽呢？

在不可思议亿劫中宣说，那些菩萨的功德名号也没有穷尽，他们善于安住在无我之忍中，就是这些具有大名称的菩萨。

如果想要了知菩提，一定要安住在微妙的智慧聚中；如果修习诸佛所说的忍，得到殊胜的菩提就不难。

## 五、无所有起如来与思惟大悲王子

这时，佛告诉月光童子说：“在过去广大、久远、无量、无数、不可思议、超过阿僧祇劫之前，那时有一尊佛出现于世，名号是无所有起如来、应供、正遍知、明行足、善逝、世间解、无上士、调御丈夫、天人师、佛、世尊。为什么叫做无所有起如来、应供、正遍知呢？童子！这位佛出生时，上升到虚空中，高七多罗树，行走七步，这样说道：‘一切诸法都无所有，一切诸法都无所有。’他的声音遍满三千大千世界。这时地神一层一层地互相转告，一直传到梵天世界，这样说道：‘这个世界中有佛出世，名号叫无所有起如来、应供、正遍知，他初生时在虚空中行走七步，说道：“一切诸法都无所有。”’童子！因为这个因缘，那位佛名号叫无所有起。

“那位佛成正觉的时候，所有的树木、丛林、药草都发出声音说：‘一切诸法都无所有。’童子！那时那个世界中所发出的一切声音，也都在说：‘一切诸法都无所有。’

“童子！那时无所有起如来说法时，有一位王子，名叫思惟大悲，形貌端正，为人所爱乐，心行调柔。童子！那时，王子前往无所有起如来那里，顶礼佛足，右绕三匝，退坐一旁。

“那时，无所有起如来知道思惟大悲王子深心所乐，就为他宣说这一切诸法体性平等无戏论三昧。王子听了之后，生起清净的信心，舍家而入于非家，出家修道，剃除须发，披上袈裟。出家之后，他对这个三昧读诵、受持，广为他人分别显示。以这一善根，他在二十劫中不堕恶道，每一劫中都值遇二亿尊佛。过了二十劫之后，他成就了佛道，名号为善思义如来、应供、正遍知、明行足、善逝、世间解、无上士、调御丈夫、天人师、佛、世尊，出现于世间。

“童子！你应当看到，这个三昧有这样的威力，能使菩萨招致无上正等正觉。

## 六、安住深忍：观一切法如幻

“童子！菩萨摩诃萨应当安住在甚深的忍法之中。菩萨摩诃萨怎样才能安住于深忍呢？童子！菩萨摩诃萨应当如实观察一切法犹如幻化、如梦、如阳焰（野马）、如回响、如光影、如水中月、如虚空的体性，应当这样了知。童子！菩萨摩诃萨如果如实观察一切法如幻化、如梦、如阳焰、如回响、如光影、如水中月、如虚空的体性，这就叫做菩萨摩诃萨安住于深忍。

“如果成就了深忍，菩萨面对贪染之法而不贪染，面对嗔恚之法而不嗔恚，面对愚痴之法而不愚痴。为什么呢？因为这位菩萨不见有法，也无所得：不见能贪染的人，不见所贪染的事，不见贪染的业；不见能嗔恚的人，不见所嗔恚的事，不见嗔恚的业；不见能愚痴的人，不见所愚痴的事，不见愚痴的业。

“菩萨摩诃萨对于这样的法全都无所见，也无所得，也就是对于贪染、嗔恚、愚痴都无所见；这位菩萨因为无所见的缘故，就无所贪染、无所嗔恚、无所愚痴。

【按】这里讲的是以见地断烦恼的道理：并不是用力压制贪嗔痴，而是照见能起烦恼者、所起之事、烦恼之业三者都不可得，烦恼便无从立足。大手印所说“烦恼自解脱”，在经中就是“以无所见故，即无所染、无瞋、无痴”。

“这位菩萨因为如实地无贪染、无嗔恚、无愚痴、没有颠倒之心，所以得名为定，名为无戏论，名为到达彼岸，名为陆地（出离水难），名为到达安稳，名为到达无畏，名为清凉，名为持戒，名为智者，名为慧者，名为福德，名为神足，名为忆念，名为受持者，名为聪慧者，名为善去者，名为有惭愧者，名为信解义理者，名为具头陀功德者，名为不贪著女色者，名为无染著者，名为应供者，名为漏尽者，名为无烦恼而自在者，名为心解脱者，名为慧解脱者，名为调伏者，名为大龙，名为所作已办，名为更无所作，名为放下重担，名为已得自利，名为灭尽一切三有之结，名为依止正教而心善解脱，名为到达一切心自在的彼岸，名为沙门，名为婆罗门，名为已沐浴者（洗净烦恼），名为已渡者，名为明了者，名为多闻者，名为佛子，名为释子，名为拔除棘刺者，名为越过坑堑者，名为拔出毒箭者，名为无热恼者，名为无尘埃者，名为没有覆盖缠缚的比丘，

“名为丈夫，名为善丈夫，名为胜丈夫，名为大丈夫，名为狮子丈夫，名为大龙丈夫，名为牛王丈夫，名为善调丈夫，名为勇健丈夫，名为荷负重担的丈夫，名为精进丈夫，名为勇猛（凶）丈夫，名为如花丈夫，名为莲花丈夫，名为白莲花（分陀利）丈夫，名为调御丈夫，名为如月丈夫，名为如日丈夫，名为作业丈夫，名为两足之中最上者，名为穷尽智慧边际者，名为多闻之中最胜者，名为已修梵行者，名为所作究竟者，名为一切恶都不能染者。”

## 七、诸法如幻的种种譬喻

这时，世尊说偈颂道：

劫末灾难毁坏世界时，世界荡然成空；如同前面成劫前是空，后面坏劫后也是空，以此比喻诸法也是这样。

观察世间的生起造作，全都住在水轮之上；如同下方如此，上方也是如此，诸法也是这样。

如同虚空中本来没有云，忽然生起阴霾，谁能知道它从哪里出来？诸法也是这样。

如来涅槃之后，人以思想忆念而见到佛的形象；最初是这样，后来也是这样，诸法也是这样。

犹如水上聚集的泡沫，被暴流所漂荡，观察它毫无坚实，诸法也是这样。

如同天上下雨落在水面，各处都有水泡生起，随生随即散灭，诸法也是这样。

譬如春天的日中，被阳光焚烤炙晒，阳焰的形状像水一样，诸法也是这样。

如同湿润的芭蕉树，有人把它折开求其坚实之心，内外都找不到实在之物，诸法也是这样。

如同幻术变化出许多形体，所谓男人、女人、大象、马匹，这些形相并不真实，诸法也是这样。

譬如有一个少女，夜里睡觉梦见生了孩子，孩子出生时欢喜，死去时忧伤，诸法也是这样。

如同有人梦中行淫欲之事，醒来之后什么也看不见；愚痴的贪爱终究一无所得，诸法也是这样。

```
如净虚空月　影现于清池
非月形入水　诸法亦复然
```

大意是：如同清净虚空中的月亮，月影显现在清澈的池水中，但并不是月亮本身进入了水中，诸法也是这样。

【按】水月之喻最能说明“显而无自性”：月影历历分明，不能说无；而水中实无月体，不能说有。诸法显现亦复如是，大手印所说“显空不二”，以此喻最为亲切。

如同有人自己喜好容貌，拿着镜子照自己的脸，镜中之像不可得，诸法也是这样。

看见阳焰以为是水，愚痴的人想要跑过去饮用，其中并没有真实的水可以解渴，诸法也是这样。

如同有人在山谷中，歌唱、哭泣、说话、欢笑而产生回响，听到的声音实不可得，诸法也是这样。

如同用告示（牓）教令诸国，善与恶的行为都依此施行，但并不是言教本身走到了那里，诸法也是这样。

如同有人饮酒大醉，看见大地都在旋转，其实大地从来没有动过，诸法也是这样。

## 八、远离有无二边，住于中道

```
缘起法无有　无有更不有
分别有无者　是则苦不灭
于有无分别　净不净诤论
远离是二边　智者住中道
```

大意是：缘起之法本无自性之有；既已无有，也不会再成为有。如果分别执著有或无，苦就不能灭尽。分别有与无，争论净与不净，智者远离这两边，安住于中道。

【按】这是全卷最根本的见地之偈。藏译本相应的颂文为冈波巴大师等噶举祖师常引：有与无是二边，净与不净也是二边，智者远离二边。汉译此处说“住中道”，读者须知这“中道”并不是两边之外另有一个可以执取的中间，否则又成了新的边执。

观察那过去的身体，对于身体不生身体之想；如果能这样了知，就是无为的体性。

眼、耳、鼻没有限量，舌、身、意也是如此；如果在诸根上起分别执著，圣道就没有用处了。

如果以为诸根无限，执取顽空、无记的状态，而想要希求涅槃之乐，那就应当修习圣道之业（不可落入顽空）。

【按】这一首要特别留意：经中既破执根为实的分别，又破落入顽空、无记的偏差。认识心性绝不是把心弄成一片空白，这一点在大手印的修持中也被反复叮咛。

宣说四念处时，愚人以为自己身已证得而生起慢心；真正身证了就没有慢心，因为身证能远离一切慢的缘故。

宣说四禅时，愚人以为自己已得禅行；真正灭除了迷惑的人没有慢心，因为以智慧观照断除了慢的缘故。

宣说四真谛时，愚人以为自己已经见谛；真正见到真实的人没有慢心，世尊是这样说的。

虽然广读众经，却依恃多闻而毁犯禁戒；多闻并不能救护他，破戒必受地狱之苦。

自恃持戒而生慢心，却不学习多闻；持戒的福报享尽之后，还要再受种种苦。

对于多闻和持戒，二者都不自恃；依恃而生慢心的薄福之人，正是由此引生种种苦。

慢是一切苦的根本，这是诸位导师所说的；有慢则苦增长，远离慢心苦就灭除。

虽然修习世间的三昧，却不能远离我想，他的过患还会再生起，就好像优垤迦（外道仙人郁头蓝弗）一样。

如果修习那无我之法，并于其中生起欣乐，这才是涅槃之乐的因，不会感招世间法。

【按】“修世三昧而不离我想”，是对禅修者的严重警告：定力再深，若有一个“我在修定”的执著，终究还要退堕。认识无我，才是从定到解脱的关键。

如同被众多盗贼包围，为了活命想要逃走，但没有脚不能跑，于是便被盗贼所杀；

同样，愚痴的人毁犯禁戒，却想出离世间，没有戒律就不能离去，终被老、病、死所杀害。

如同强壮而手持利刃的盗贼，在各处劫掠杀害；烦恼也是这样，损害众生的善根。

许多人口说五蕴是空，却不知道五蕴无我；如果有人问他五蕴是有还是无，他就皱起眉头，带着嗔恨来回答。

如果真正了知五蕴无我，听到别人辱骂，心中也不会嗔恨；有的人或许被魔所系缚，真正悟入空性的人是没有忿怒的。

如同有人身上患病疼痛，多年被苦痛逼恼；这病经历的时间很久了，于是寻求医生想要治疗。

这个人多次寻访，终于遇到一位良医；医生怜悯他，给他好药，说：“你服了它，病就会好。”

这个人得到了妙药，却不服用，病就好不了；这不是医生和药的过错，应当知道是病人自己的过失。

在这个法中出家，读诵道品的教法，修行却不相应，又怎能得到解脱呢？

```
诸法体性空　佛子观是事
一切有悉空　外道空少分
```

大意是：一切诸法的体性都是空的，佛子观察这件事，见到一切有法全都是空；外道所说的空，只是空的少分而已。

智者不与愚人争竞，勇猛的人应当舍离愚人；如果愚人辱骂，不要想着报复，对于愚人的作为，你不必嫌恨。

智者不与愚人往来，因为善知他们的习性；即使暂时互相亲近，以后必定成为怨嫉。

智者不与愚人亲密，知道他们的志向不坚定；他们的体性本身就会自我破坏，所以凡愚之人没有真正的朋友。

如果询问如法的话语，毁戒的人不会欢喜；无缘无故生起嗔恚的覆蔽，应当知道这是愚人。

愚人与愚人相合，如同粪与粪相和；智者与智者同处一处，犹如两份醍醐相合。

不观察世间的过患，不信入因果，对佛语没有信心，这样的人在世间就会被离间破坏。

有的人贫穷而没有财物，因为无法生活才求出家；在我的法中出家之后，对衣钵极其悭吝执著。

他亲近恶知识，毁破我的禁戒，不观察自己的行为，他的心没有安住之处。

他昼夜住于不适宜之处，作恶从不厌足；身心恒常放逸，口中常说粗鄙之语；

总是窥伺别人的过失，找机会向人宣说，却遮掩自己的瑕疵，这是深重的愚痴之相。

愚人贪嗜饮食，不知道节制分量；因为佛的缘故得到饮食，却毫无报恩之心。

得到上妙的美食，却不与其法相应，反而被饮食所害，就像大象吃了带泥的莲藕一样。

种种上等美味的饭食，智者虽然也吃，但诸根寂静而没有贪著，如法简择而食用。

即使是聪明有智的人，以温言慰问愚人从何处来，对愚人也没有亲近眷恋，只是生起悲悯之心。

智者总是利益愚人，愚人却反而给智者带来衰损；我见到这种过患之后，就像野鹿一样独处于空闲之地。

智者见到这种过患，就不与愚人共处；如果与愚人来往，连生天都会失去，更何况菩提呢？

智者恒常安住于悲心，安住于慈心并与喜心相合，常常舍弃一切三有，修习禅定而证得菩提。

悟道之后除去了忧愁和怖畏，看见世人被老与死所逼迫，就对他们生起悲悯，所说的话都合于真实的义理。

如果有人了知佛法，了知离于言说的圣谛，若听闻这样的法，就能远离对饮食的执著与贪爱，获得圣者的喜乐。

【按】末句原文为“得离食圣爱”，文义较简，大意是听闻离言圣谛之法，能离开对饮食等世间受用的贪爱，此为存疑之处的一种理解。

## 九、月光童子发愿安住坚固行，请佛应供

“童子！因为这个缘故，想要成就坚固行的菩萨，应当这样修学。为什么呢？童子！坚固行的菩萨要证得无上正等正觉尚且不难，更何况得到这个三昧呢？”

这时，月光童子禀白佛说：“稀有啊，世尊！如来、应供、正遍知善于宣说这坚固之行，为了趣入这个三昧之法，善加宣说、善加建立一切菩萨所应修学的内容。这是一切如来所行之处，尚且不是声闻、辟支佛的境地，更何况外道呢？

“世尊！我现在就要安住于这坚固之行。为什么呢？因为如佛所学的，我现在也想要学；因为我想要了知那无上正等正觉；因为我想要破坏魔王波旬及其眷属；因为我想要使一切众生脱离痛苦。唯愿如来以及比丘僧和诸位眷属，明天接受我的供养邀请，以悲悯我的缘故。”

那时如来和比丘僧默然许可，接受月光童子明日的供食之请，这是为了护念他的缘故。

月光童子蒙如来许可接受供养之后，欢喜踊跃，深自庆幸，随即从座起身，偏袒右臂，顶礼佛足，右绕三匝，告辞而去。

## 十、严城设供

这时，月光童子向王舍城回到家中，到家之后，就在当夜准备了种种无量无数殊胜美味的饮食。在王舍大城的一切地方，都悬挂缯彩，散布种种鲜花，竖立幢幡宝盖，焚烧各种名香，张设帷帐，清扫街巷，除去瓦砾，在四通八达的大道上洒水，使之清净，散布栴檀香末，遍铺各种珍宝，又散上种种鲜花、种种宝花，交错点缀地面，犹如彩画一般。又以无量种种庄严之物雕饰城中街巷，整座城都周遍装点了：有优钵罗花（青莲）、拘物陀花（黄莲）、钵头摩花（红莲）、分陀利花（白莲）。在他家中，纯用牛头栴檀涂饰屋宅，以种种庄严之物张设宝帐，为佛世尊准备上味的饮食。

这时，月光童子这样庄严城郭、街巷、房舍，准备种种供具，一夜之中全部准备完毕。到了第二天清晨，他与八十那由他菩萨一起，以阿逸多菩萨为上首，其中有：观世音菩萨、大势至菩萨、香象菩萨、宝幢菩萨、难胜菩萨、文殊师利童子菩萨、勇健军菩萨、妙臂菩萨、宝花菩萨、不虚现菩萨，这些菩萨摩诃萨在其余菩萨之中作为上首。月光童子与这样的大菩萨众前后围绕，走出王舍大城，来到如来所在之处，重新整理衣服，头面礼佛，右绕三匝，禀白佛说：“世尊！用斋的时间已到，所设的供养已经准备好了，愿世尊垂慈光临，进入王舍城，到我家中，哀悯接受我的供养。”

## 十一、佛入王城的种种神变

这时，世尊在午前时分，穿好衣服，手持钵盂，与大比丘满十万人，以及无量百千亿那由他菩萨摩诃萨一同前往。天、龙、夜叉、乾闼婆、阿修罗、迦楼罗、紧那罗、摩睺罗伽等无量百千众设供养，恭敬赞叹佛的大威力、大神足、大变现、大威仪；放出百千万亿那由他道光明，演奏百千种伎乐，降下种种天花。佛为了接受月光童子的供养，进入王舍城。

佛以长久积集的无量善根，用右足千辐轮相踏上城门的门槛，当时显现种种前所未有的神变。经中说：“诸佛如来进入城中时，法尔都是这样显现神变的。你们现在好好听，我当为你们宣说佛入城时所有的神妙功德。”于是说偈颂道：

大仙进入王城，千辐轮足踏上门槛，威力震动大地，众生全都欢喜。

一切缺乏饮食的人，都远离饥渴的苦患，身体都饱满了，这是由于佛踏上门槛的缘故；

聋、盲、喑哑之人，贫穷、薄福之人等等，诸根全都完具，这是由于佛踏上门槛的缘故；

阎罗界中的饿鬼，平时以脓、唾、屎、尿为食，都得到了天上美味的饮食，这是由于佛踏上门槛的缘故；

诸山和宝山，种种树林、花朵、果实，都弯曲躬身，转向佛的方向，这是由于佛踏上门槛的缘故；

大海、城市、村落，大地都六种震动，却不逼恼众生，这是由于佛踏上门槛的缘故。

人、天、鸠槃荼等，欢喜地住在空中，为佛擎持宝盖，发起大菩提心；

一切乐器不须敲击，自然发出美妙的声音，众人全都欢喜，这是由于佛踏上门槛的缘故。

百千万亿棵树，都向着佛垂下花果；无量天人住在空中，所设的供养都不是人间所有；

百千头牛王、兽中之王狮子发出吼声，大象和马匹都来归依礼敬，这是由于佛踏上门槛的缘故。

国中的诸位大王，见到具足十力的世尊，见到导师殊胜美妙的色身，欢喜地顶礼。

其余的人心生欢喜而赞叹，有的散布种种妙花，合十指掌，称佛为大悲者。

有的散布璎珞、金锁、臂钏，有的散布狮子形的饰带，发起大菩提心。

妇女们奉上金鬘，有的妇女散布面饰的花朵，有的解下金璎珞以及胸前、面部、手上的庄严饰物，有的散布金花和种种庄严身体的饰物；她们虽然舍弃这些，却没有一人不是一心希求诸佛之道。

城中人民铺上美妙的衣服，有的散布头顶的宝珠，以及散布种种宝网，因为佛来到城门的缘故。

如果有人被病苦逼迫，被种种忧愁之箭所射，这时也全都得到安乐，这是由于导师威德的缘故。

拘翅罗鸟、鹦鹉、孔雀、迦陵频伽等种种鸟类，住在空中，发出和雅美妙的声音。

众鸟心中欢喜，发出这些妙音的时候，能够灭除修行人的贪、嗔、痴烦恼。

无量亿的众生，听到这声音就得到随顺忍；圣者为他们授记，未来都将成佛。

众生见到佛的十力之身，都乐求佛的智慧，心想：“我怎样才能得到这样的身？佛知道了，就会为我授记。”

佛的每一个毛孔，都放出百千种光明，遍照一切佛刹，因为普眼的佛入城的缘故。

太阳的光明、摩尼宝珠、天火，都被遮蔽，其余的光都不显现，因为佛进入城门的缘故。

百千朵莲花开敷，从地涌出，千叶清净；十力之尊踏在上面，与大众游行于城中街巷。

道路上没有秽污，全部用香泥涂饰；全城都焚烧妙香，香气流布，非常可爱；

街巷非常庄严华丽，已经除去种种瓦砾，由于十力的功德，具足种种花香。

百千个凶恶的夜叉，见到佛的金色之身，生起大悲悯之意，以清净之心归依牟尼。

诸天的宫殿都空了，大家都一起来观看佛，在空中降下众花，就在佛进入这殊胜之城的时候。

如果有人在人天导师那里散花，这些花就在佛的上方化成花盖，庄严佛身，使之更加端好。

人、天、阿修罗等，看到具足十力的佛，心中欢喜踊跃，从来没有满足。

佛的右边有百千位梵天，左边的帝释天也是如此，无数的天人住在空中，恭敬三界至尊。

这时佛显现神变之后，开示殊胜微妙之法，百千听法的大众，都发起大菩提心。

佛以相好之花为身，犹如布满虚空的星辰；佛在国王的御道上行走，犹如清净虚空中的圆月。

犹如清净的摩尼宝珠，远离垢秽，没有瑕疵，向十方放出光明；佛照耀佛刹也是这样。

诸天大众围绕，人中至尊进入王城，足踏大地如画一般，来到月光童子的住宅。

城郭全部庄严，有百千亿幢幡，用栴檀涂饰地面，散布鲜花而作庄严。

佛在道路上行走时，发起广大的悲悯之心，口中放出无量光明，吐出妙香而宣说佛法。

众人看到佛身，心生安乐，得到不可思议的欢喜，心想：“我们什么时候能够作法王的殊胜供养呢？”

无量的人发心：“我明天也要迎请佛。这位怜悯救济众生的世尊，经过久远的时间都难以值遇。”

有的在街巷、城楼和城墙上，以殊胜美妙之物自作庄严，准备种种花鬘璎珞，散在佛身上，为求菩提；

有的散布殊胜的瞻波花鬘、婆师花、目多伽花；有的散布缯彩，发起殊胜淳厚至诚的心；

有的在家人心中清净，以殊胜的衣服庄严自身，用缯彩和种种鲜花，散在大比丘众身上，有优钵罗花等，又散布美妙的金花、种种摩尼宝，有的散布栴檀香末。

当时显现种种稀有之事，不可计数；佛进入城门时，许多人发起了道心。

无烦天、无热天、见谛的善现天、善见天、色究竟天（阿迦尼吒）这些离欲的天人，一切都来观看佛；

福生天（密身）及广果天，百那由他天众，如摩尼宝的光耀，都来瞻仰世尊；

无数的净天子，以及诸少净天、无量净天子，都来观看大仙；

少光天子、无量光天，以及光音天子等，都一起来观看佛；

梵辅天子、梵众天，以及住于禅定之藏的大梵天等，都来观看世尊；

他化自在天欢喜，化乐天怀着善心，兜率天、夜摩天众、三十三天之王，四方的四大天王：财主（多闻天王）、毗楼勒（增长天王）、恶眼（广目天王）、提赖吒（持国天王），都特来礼敬佛。

【按】原文“财主毘楼勒，恶眼提赖吒”，译者以四王名号分列，此处依通行四天王之名略作对应，供参考。

大力夜叉王和他的眷属以清净之心，与亲族一同在空中，降下诸天的妙花；

恒常醉乐的持鬘天，手持种种花鬘，与眷属一起心生欢喜，供养最胜的丈夫；

百器足夜叉，与妻子和眷属一起，亲自演奏美妙的音乐，供养如来；

喜悦而耽乐美妙歌声的，就是紧那罗王，他住在香山顶上，踊跃地全都来集会；

婆稚、睒婆利、罗睺、毗摩质多罗等阿修罗王，以及其他具大威德者，都降下种种宝物；

超过无量数的罗刹，被众多的眷属围绕，各自手持种种妙花，恭敬地散在佛身上；

阿耨达大龙王的女儿，善于学习音乐，演奏百种美妙的声音，以诚心供养佛；

阿耨达龙王的五百个儿子，求取广大的菩提智慧，与亲属围绕，一同来到无上尊前；

阿波罗龙王向佛合掌，手持龙宫殊胜的真珠，在空中供养佛；

目真陀龙王踊跃欢喜，散布种种美妙的宝果，以清净之心供养。

他们生起殊胜的恭敬之心，忆念佛的种种功德，被诸亲属围绕，都来赞叹佛。

难陀、跋难陀、德叉迦、黑瞿昙等龙王，与眷属来到佛所，屈膝礼敬善逝。

伊罗钵龙王与百名眷属号哭流泪，忆念迦叶佛，厌恶自己这样的受生，说：“我往昔心怀疑惑，毁坏了一片小小的伊兰叶，因此生在八难之处，不能了知佛法。我深深厌恶这蛇身，愿迅速舍离龙趣，能了知清凉之法，也就是佛在道场所证得的法。”

其他众多千位龙王，以及海龙王摩那斯，手持上妙的龙衣，来奉献给人中至尊。

提婆达多向佛投掷石头时，有一位夜叉住在空中接住了石头，他的名字叫金毗罗，恭敬地站在佛前。

阿吒夜叉城中，大夜叉们都空了城，他们相互告诫约束，全部集合，来供养大仙世尊。

灰毛夜叉、针毛夜叉、可怖的阿吒婆夜叉、雪山夜叉、婆多山夜叉、驴形夜叉，都来归依佛。

种种不同类别的身形，穿着非常可怕的衣服；无数那由他的鬼众，手持吉祥之物来奉献给佛；

以海中龙为食的金翅鸟，变化成婆罗门的形象，以宝冠庄严自身，住在空中礼敬佛。

阎浮提所有的城市，一切大林中的天神，与城神一同前来，供养世间解。

无量的林中天神来到，以及诸位树神等，还有一切河神，都聚集到法王之处。

山峰、岩岭之神，丘阜之神也来了，泉水、池塘、沼泽之神等，与海神一同欢喜地到来。

天、人、阿修罗、鬼神、迦楼罗、鸠槃荼等，饿鬼、富单那，都来供养佛。

诸天和阿修罗大众，远离了慢心，都来供养；见到佛进入王城，观看而没有满足。

这是因为佛在过去修菩萨行时，曾经供养过诸世尊；佛作了这样清净的善业，所以众生观看佛而没有厌足。

须弥山、铁围山等，以及阎浮提的诸山，都不能遮蔽诸佛照耀佛刹的光明。

这娑婆世界的诸海和土地全都平正，遍及整个佛刹，散布的众花全都充满。

百千种光明从法王足下放出，地狱完全变得清凉，除去痛苦，获得安乐。

具足十力的佛为众生说法，天人得到法眼清净，无量百千大众对于佛道得到决定。

无等等的佛进入城中，显现这样的神变；在无量百千劫中，佛来宣说尚且难以说尽。

这样殊胜的功德聚集，牛王（佛）度到彼岸，一切功德究竟圆满，我顶礼佛这一福田。

## 十二、月光童子供佛

这时，世尊与诸比丘前后围绕，前往月光童子的住处，坐在所敷设的座位上，诸比丘僧依次而坐。

这时，月光童子知道佛、菩萨和比丘都已坐好，就亲手拿着多种美食，也就是佉阇尼（硬食）、蒲阇尼（软食）、梨呵那（舐食）以及沙尼等种种食物，又拿着浆饮，以百味饮食供养如来和大众，使他们饱足。供养饱足之后，他欢喜踊跃，深深庆幸自己能有这样的际遇。佛和大众用完斋饭，收起钵盂，洗净双手，月光童子以价值万亿的宝衣奉献给如来；对比丘众，依上座、中座、下座的次第，分别以上等、中等、下等的三衣依次布施。

## 十三、月光童子再以偈请问

这时，月光童子对佛和僧众布施衣物之后，偏袒右肩，右膝着地，合掌作礼，住立在佛前，默念说偈，请问世尊：

有智慧的菩萨修持什么样的行，才能恒常了知诸法的体性？怎样才能趣入所应作的事业？唯愿导师为我宣说。

怎样才能得到宿命智？怎样才能不再处于胞胎？怎样才能得到不可破坏的眷众？因为什么而得到无量的辩才？

具有无上定慧的两足尊啊，愿您按照我所问的为我记别解说；您了知一切众生心中所行，对一切法都没有疑惑。

佛了知一切法的体性，以言说来宣说离于言语的法；如同狮子吼摧伏野干，佛降伏外道也是这样。

佛了知一切众生之所行，通达诸法而到达彼岸，具有无碍智慧的清净境界，唯愿法王为我宣说。

佛了知过去、未来之世，对于现在也全都明了，具有三世无碍的智慧与堪能，所以我请问释迦狮子；

一切三世诸佛之法，法王世尊都能了知，对于法的体性善能觉悟，所以我请问大智之海。

佛能远离一切法的过失，因为已经断除了心中的垢秽，剪除了一切愚痴垢秽的结缚，愿佛为我宣说菩提之行。

佛所证得的诸法之相，愿按照所证得之相为我宣说；我听闻这样的法相之后，就依照所听闻之相修行菩提。

众生的行相有种种差别，我修持什么样的行才能理解趣入？愿为我宣说趣入之行法，我听闻之后就能了知。

```
一切诸法各差别　其体空寂性远离
菩萨云何能现证　愿为我说是法母
```

大意是：一切诸法各有差别，它们的体性却都空寂，本性远离一切；菩萨要怎样才能现前证得这一点？愿佛为我宣说这能出生一切的法母。

【按】这一问是全经主体的开端：诸法显现各各差别，体性却同一空寂，菩萨如何“现证”？下一卷世尊的回答，正是本经所说三昧的正体。月光童子所问的不是如何理解空性，而是如何现证，这与大手印重在直下认识的意趣完全一致。

您已经对一切法到达彼岸，对于言说法句也已修学圆满，自己已没有疑惑，也能除去他人的疑惑，愿为我显示诸佛和菩萨之道。

《月灯三昧经》卷第二终
