# 苦乐无二见

阿阇黎香底巴 造

## 题解

本篇出自德格版丹珠尔续部（རྒྱུད་འགྲེལ།）ཟི 函第40b叶第1行至第41a叶第1行，东北目录编号 D2427。全篇四十三句，每句七个音节，另有礼敬和跋语。篇幅很短，所以把藏文原文全部保留在代码块中，按段落分开，每段后附汉译，疑难之处另以【按】说明。

梵文题名：Sukha-duḥkha-advaya-parivarga-dṛṣṭi-nāma（སུ་ཁ་དུཿཁ་ཨདྷྱ་པ་རིརྱ་གྷ་དྲྀཥྚི་ནཱ་མ），拼写似有讹变，照录不改。

藏文题名：བདེ་སྡུག་གཉིས་བྲལ་གྱི་ལྟ་བ（离苦乐二者之见）。

【按】藏文题名直译是“离苦乐二者之见”，本篇标题依通行译名作“苦乐无二见”。“离二”与“无二”意思相近，但字面不同，特此注明。

【按】作者“ཤཱནྟི་པ”（Śāntipa），这里音译为“香底巴”。藏传传统一般认为他就是超戒寺的大班智达宝生寂（Ratnākaraśānti），八十四大成就者之一。宝生寂兼通唯识、中观与密续，本篇中“破先修方便之说”“离正念的无念是迷误”等句，或许反映了他对当时某些大手印修法的看法，但这只是推测。跋语没有记载译者。

【按】本篇的结构大致是：先立超越修习、离有无二边的见地；然后指出两种偏差——一是离开正念的“无念”，二是把般若与方便分为先后；接着讲具足口诀的方便修法与喻光明，并提醒不可执著法身的相状；最后归到自明自觉、不住二与无二，即是般若波罗蜜多与大手印。

## 礼敬

```
ཡུམ་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་མ་ལ་ཕྱག་འཚལ་ལོ། །
```

敬礼佛母般若波罗蜜多！

## 正文

### 第一段：礼敬与立誓

```
སྒོམ་ལས་འདས་པ་སྒྲུབ་རྒྱུ་མེད། །མགོན་པོ་རྣམས་ཀྱི་བདག་ཉིད་ཅན། །གྲུབ་ཐོབ་རྣམས་ཀྱི་བླ་མ་ལ། །ཕྱག་འཚལ་གཉིས་བྲལ་ལྟ་བ་བཤད། །
```

（那位）超越了修习、没有什么需要成办，具有一切怙主的自性，是一切成就者的上师——我向他顶礼之后，来宣说离于二边的见地。

【按】这四句是作者的礼敬偈。所礼敬的“上师”没有说出名字，依“一切怙主的自性”“一切成就者的上师”这些赞辞，可能指作者的根本上师，也可能指诸佛总集的本尊。

【按】“སྒོམ་ལས་འདས་པ་སྒྲུབ་རྒྱུ་མེད”，“超越修习、无可成办”，是形容上师（或证悟者）已经到了无修无证的境界。“无修”在大手印中特指证悟圆满、不再有能修所修的分别，不是说初学者不用修。

### 第二段：瑜伽超越修习

```
རང་བཞིན་བསྒོམ་རྒྱུ་མེད་པའི་ཕྱིར། །རྣལ་འབྱོར་སྒོམ་ལས་འདས་པ་ཡིན། །དངོས་དང་དངོས་མིན་གཉིས་དང་བྲལ། །དེ་ཕྱིར་ཀུན་རྫོབ་གྲུབ་པ་མེད། །
```

因为自性没有什么可修的，所以（真正的）瑜伽是超越修习的。（它）远离有实与无实二者，所以世俗（在胜义中）也不成立。

【按】“ཀུན་རྫོབ་གྲུབ་པ་མེད”，“世俗不成立”，这一句必须小心理解：这里是说，在离有无二边的见地中，世俗法没有自性成立，并不是说世俗的显现与因果都不存在。所以在括号中补出“在胜义中”，以免误解。

【按】“རང་བཞིན་བསྒོམ་རྒྱུ་མེད”，“自性无可修”，意思是心的自性本来圆满，不是通过修习新造出来的。

### 第三段：自性智慧，双运无二

```
དངོས་པོ་སྒོམ་མེད་དངོས་མེད་མིན། །རང་བཞིན་དབྱེར་མེད་རྒྱུ་ལས་འདས། །ནམ་ཡང་རང་བཞིན་ཡེ་ཤེས་ཏེ། །ཟུང་འཇུག་དགའ་བ་གཉིས་སུ་མེད། །
```

（这里）既不修习有实的事物，也不是（落入）无实；自性无有分别，超越了因（缘）；无论何时，都是自性的智慧，双运的喜乐无二无别。

【按】“དངོས་པོ་སྒོམ་མེད་དངོས་མེད་མིན”，直译是“不修有实，非无实”，意思是：不把所修执为实有，但也不落入什么都没有的断见。

【按】“རྒྱུ་ལས་འདས”，“超越因”，即不是由因缘所生的有为法。

【按】“ཟུང་འཇུག་དགའ་བ”，“双运之喜”，在密乘中指智慧与方便、乐与空双运时的大乐。

### 第四段：无念并非离正念

```
དྲན་པ་དང་བྲལ་དྲན་མེད་དེ། །རྣལ་འབྱོར་པ་ཡི་འཁྲུལ་པ་ཡིན། །
```

离开了正念的那种“无念”，是瑜伽士的迷误。

【按】这两句非常重要。“དྲན་པ་དང་བྲལ་དྲན་མེད”，直译是“离开忆念的无忆念”。“དྲན་མེད”（无念）本是大手印中常用的词，指离于分别执著的境界；但作者在这里指出：如果把“无念”理解为连正念、明觉都没有，一片昏昧空白，那就是瑜伽士的迷误。真正的无念，是明觉不失而不起执著。这一解释与上下文“自性的智慧”相应。

【按】另一种可能的读法是：“离忆念、无忆念”两者都是要遮破的边，即“执著有念”与“执著无念”都是瑜伽士的迷误。原文过于简略，这里两种读法都保留，正文取前一种。

### 第五段：破“先修方便”之说

```
ཤེས་རབ་ཐབས་ཀྱི་ཟུང་འཇུག་ལ། །རྣལ་འབྱོར་གཞན་གྱི་དགོངས་པ་ནི། །དང་པོ་ཐབས་ནི་བསྒོམ་པའི་ཕྱིར། །མི་རྟོག་ཤེས་རབ་སྐད་ཅིག་ལ། །
མ་གྲུབ་ཐབས་ཀྱང་གྲུབ་མི་འགྱུར། །མཐོང་མིན་དེ་ནི་བསྒོམ་པ་མིན། །
```

关于般若与方便的双运，其他瑜伽士的意趣是：“首先要修习方便。”（但是，）在无分别般若的刹那中，（般若）如果没有成就，方便也不会成就；没有见到（真性），那就不是修习。

【按】这一段的语气，似乎是先引述“其他瑜伽士”的主张（先修方便，再修般若），然后加以评破：般若与方便是双运的，如果没有在刹那间生起无分别的般若，方便也不能成就；没有见到真性，那种修习就不是真正的修习。但原文没有引号，哪几句是他人的主张、哪几句是作者的评破，只能依文意判断。

【按】“མཐོང་མིན”，“没有见到”，这里补“真性”二字。也可以理解为“（这）不是见（道）”。

【按】本段并不是否定方便。下一段紧接着就讲具足上师口诀的方便修法，可见作者的意思是：方便必须与般若同时，不能分为先后两截。

### 第六段：具足口诀的方便修法

```
གང་ཞིག་ཐབས་ནི་སྒོམ་བྱེད་ན། །བླ་མའི་གདམས་ངག་ལྡན་པ་ཡིས། །ཡང་དག་ཕྱག་རྒྱ་ཐབས་ཉིད་ཀྱིས། །ཕྲ་ཞིང་རང་བཞིན་རབ་རྒྱུ་བ། །
ཡེ་ཤེས་ཀུན་གྱི་བདུད་རྩི་འབབ། །མཚོན་པའི་འོད་གསལ་སྐད་ཅིག་ལ། །བློ་ལྡན་བརྟན་པའི་སེམས་ཀྱིས་བསྒོམ། །
```

如果有人修习方便，那么具足上师口诀的人，以真实的手印方便本身，（使）细微而本性（的风息）畅然运行，一切智慧的甘露便会降下；在表示性的光明刹那之中，有智慧的人要以坚稳的心来修习。

【按】“ཡང་དག་ཕྱག་རྒྱ”，“真实的手印”，在密乘中，“手印”（ཕྱག་རྒྱ）有业手印、法手印、大手印、三昧耶手印等不同的意思，这里所指为何，原文没有说明。依“智慧甘露降下”等语看，可能是指圆满次第的方便道修法。这类修法依传统必须得灌顶、依上师口授，这里只照字面译出。

【按】“ཕྲ་ཞིང་རང་བཞིན་རབ་རྒྱུ་བ”，“细微而本性畅然运行”，主语没有明说，大概是指细微的风息或明点，这里补“风息”二字放在括号中。

【按】“མཚོན་པའི་འོད་གསལ”，“表示性的光明”，在密乘圆满次第中，有“喻光明”（表示的光明）与“义光明”（真实的光明）之分：喻光明是修道中通过方便所生的、近似于真实光明的体验，义光明则是真实证悟的光明。这里说“表示性的光明”，应当就是指喻光明。这一对应是译者依术语推定的。

### 第七段：执著法身之相，如旅人渐至

```
བརྟགས་པས་མ་གྲུབ་རྟོག་བྲལ་ཡིན། །དཔེར་ན་འགྲོན་པོ་ཡུལ་འགྲོ་བཞིན། །ཆོས་སྐུའི་མཚན་མར་སེམས་གཏད་པས། །རིམ་གྱིས་སླེབ་པས་དེ་ཉིད་མིན། །
སྔར་བཞིན་མཚན་མ་མེད་གྱུར་པས། །རྣམ་རྟོག་དང་བྲལ་བདེ་ཆེན་འགྲུབ། །
```

经过观察而不成立，就是离于分别。譬如旅人前往某地一样，把心专注于法身的相状，逐渐到达（某处），（但那）并不是（法身）本身。（法身）本来就像先前一样是无相的，（所以）远离分别念，大乐就能成就。

【按】“བརྟགས་པས་མ་གྲུབ་རྟོག་བྲལ་ཡིན”，“经观察而不成立，就是离分别”，是承上启下的一句：上一段说喻光明，这一句提醒，即使是光明，也是经观察而不成立的，应当离于分别执著。

【按】“དཔེར་ན་འགྲོན་པོ་ཡུལ་འགྲོ་བཞིན”，“譬如旅人前往某地”，这个比喻的意思是：如果把法身当作一个有相状的目标，专注于它，一步步去“到达”，那就像旅人走向远方一样，所到达的只是一个地方，而不是法身本身。因为法身本来无相，不是由“去”而“到”的。

【按】“སྔར་བཞིན་མཚན་མ་མེད”，“像先前一样无相”，这里理解为“本来就无相”。也可以理解为“像前面所说的一样无相”。

### 第八段：自明自觉，日夜大乐

```
སྣ་ཚོགས་པ་ཡི་རིག་པ་རྣམས། །རང་རིག་གཞན་གྱིས་རིག་མི་འགྱུར། །དེ་རྟོགས་ཉིན་མཚན་བདེ་ཆེན་མཉམ། །
```

种种的觉知，都是自己觉知自己，不是由他者来觉知的。证悟了这一点，日日夜夜都与大乐平等。

【按】“རང་རིག”，“自觉”“自证”，在这里指心的自明自知，不需要另一个能知来知它。这与唯识的“自证分”用词相同，但在大手印中多指心性本具的明觉。

### 第九段：不住二与无二，即般若波罗蜜多

```
གཉིས་དང་གཉིས་མེད་སྤངས་གྱུར་པའི། །གང་ལ་མི་གནས་རྣལ་འབྱོར་དེ། །ཤེས་རབ་ཕ་རོལ་ཕྱིན་པ་རྟོགས། །དེ་རྟོགས་བདག་མེད་ལྟ་བ་ཡིན། །
```

舍弃了“二”与“无二”、不住于任何处所的瑜伽士，就证悟了般若波罗蜜多；证悟了这一点，就是无我的见地。

【按】“གཉིས་དང་གཉིས་མེད་སྤངས”，“舍弃二与无二”，意思是不但舍弃二元的执著，连“无二”这一概念也不执著，这与前几篇“远离边与中”的意思一致。

### 第十段：结颂——离苦乐二边，得大手印

```
རྣལ་འབྱོར་བདེ་སྡུག་གཉིས་དང་བྲལ། །གཉིས་བྲལ་རྣལ་འབྱོར་ཤཱནྟི་པ། །རྟོགས་པས་ཕྱག་རྒྱ་ཆེན་པོ་ཐོབ། །
```

瑜伽，是远离苦与乐二者的；远离二边的瑜伽士香底巴，由于证悟而获得了大手印。

【按】“ཤཱནྟི་པ”（香底巴，Śāntipa），即作者自署其名。

## 跋语

```
བདེ་སྡུག་གཉིས་བྲལ་གྱི་ལྟ་བ་ཞེས་བྱ་བ་སློབ་དཔོན་ཤཱནྟི་པས་མཛད་པ་རྫོགས་སོ།། །
```

名为《离苦乐二者之见》，阿阇黎香底巴所造，圆满。

## 通篇连读

（那位）超越了修习、没有什么需要成办，具有一切怙主的自性，是一切成就者的上师——我向他顶礼之后，来宣说离于二边的见地。

因为自性没有什么可修的，所以（真正的）瑜伽是超越修习的。（它）远离有实与无实二者，所以世俗（在胜义中）也不成立。

（这里）既不修习有实的事物，也不是（落入）无实；自性无有分别，超越了因（缘）；无论何时，都是自性的智慧，双运的喜乐无二无别。

离开了正念的那种“无念”，是瑜伽士的迷误。

关于般若与方便的双运，其他瑜伽士的意趣是：“首先要修习方便。”（但是，）在无分别般若的刹那中，（般若）如果没有成就，方便也不会成就；没有见到（真性），那就不是修习。

如果有人修习方便，那么具足上师口诀的人，以真实的手印方便本身，（使）细微而本性（的风息）畅然运行，一切智慧的甘露便会降下；在表示性的光明刹那之中，有智慧的人要以坚稳的心来修习。

经过观察而不成立，就是离于分别。譬如旅人前往某地一样，把心专注于法身的相状，逐渐到达（某处），（但那）并不是（法身）本身。（法身）本来就像先前一样是无相的，（所以）远离分别念，大乐就能成就。

种种的觉知，都是自己觉知自己，不是由他者来觉知的。证悟了这一点，日日夜夜都与大乐平等。

舍弃了“二”与“无二”、不住于任何处所的瑜伽士，就证悟了般若波罗蜜多；证悟了这一点，就是无我的见地。

瑜伽，是远离苦与乐二者的；远离二边的瑜伽士香底巴，由于证悟而获得了大手印。
