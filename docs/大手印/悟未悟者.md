# 悟未悟者

阿阇黎吉祥无二金刚（梅纪巴）造　金刚手、玛班却巴 译

## 题解

本篇出自德格版丹珠尔续部（རྒྱུད་འགྲེལ།）ཞི 函第226b叶第3行至第227b叶第5行，东北目录编号 D2297。全篇是散文夹偈颂的论体，篇幅不长，所以把藏文原文全部保留在代码块中（偈颂按句排列，散文按句分行），按意义段落分开，每段后附汉译，疑难之处另以【按】说明。

梵文题名：Abodha-bodhaka（ཨ་བོ་དྷ་བོ་དྷ་ཀཿ），意为“使未悟者得悟”。

藏文题名：མ་རྟོགས་པ་རྟོགས་པར་བྱེད་པ（使未悟者得悟）。

【按】跋语说本篇是“大阿阇黎吉祥无二金刚（དཔལ་གཉིས་མེད་རྡོ་རྗེ）所造”，由印度堪布金刚手（ཕྱག་ན་རྡོ་རྗེ）与藏地译师玛班却巴翻译。“无二金刚”（Advayavajra）就是梅纪巴的别名，前面所译的《无尽宝藏圆满之歌广释》《除恶见》都是他的著作。译者金刚手与玛班却巴，也就是前面所译龙树《所缘修习》的译者。

【按】本篇的结构非常清楚，是一部简明的中观论：先立宗（了悟他人所遍计者本无，即是诸法实相）；然后以多种正理破外道所立的“我”（补特伽罗无我），并以绳蛇之喻答“无我则业果无关”的问难；再以绳、线、微尘的分析破法我（法无我），并答“一切成无”的问难；接着破有为法的生、住、灭，破唯识宗实有之“识”；最后说一切显现如幻，引“无可除亦无可立”的名偈，以“依止六度速得菩提”作结。

【按】本篇的最后八句偈，与前面所译龙树《所缘修习》的第九、第十偈几乎相同，两篇的译者也相同，可以互相参看。

```
མ་རྟོགས་རྟོགས་བྱེད་དེ་ཉིད་ནི། །བརྩེ་བས་བདག་གིས་བྲི་བར་བྱ། །
```

### 二、所破：他人所遍计之“我”

```
འདི་ན་གཞན་གྱིས་བརྟགས་པ་དེ་རྟོགས་པ་ནི་ཆོས་ཀྱི་དེ་ཁོ་ན་ཉིད་དོ།
གཞན་གྱིས་བརྟགས་པ་དེ་གང་ཡིན་ཞེ་ན།
བདག་བརྟག་པ་ཁྱབ་པ་ཀུན་དུ་འགྲོ་ཞིང་གཟུགས་ཅན་མ་ཡིན་པའི་གཅིག་པུ་ཡོད་པའོ།
```

在这里，了悟“他人所遍计的（并不存在）”，就是诸法的真实性。他人所遍计的是什么呢？就是所遍计的“我”：它是周遍的、遍行一切的、不是色法的、唯一而存在的（东西）。

【按】“他人所遍计的我”，指外道（如胜论、正理派）所主张的常我：周遍一切、遍行一切处、非物质、独一无二。本篇先破此“我”（补特伽罗无我），再破诸法（法无我），最后破唯识的“识”。

【按】第5句直译是“了悟他人所遍计者，即是法的真实性”，意思是：了悟他人所遍计的“我”本不存在，就是通达诸法的实相。括号中的字是译者所补。

### 三、以多种正理破“我”

```
བདག་བརྟག་པ་ཇི་ལྟ་བུ་ཞེ་ན།
རེ་ཞིག་ཕུང་པོ་ནི་བདག་མ་ཡིན་ཏེ།
སྐྱེ་བ་དང་འཇིག་པའི་ཆོས་ཅན་ཡིན་པའི་ཕྱིར་རོ།
ཕུང་པོ་ལས་གཞན་པ་ཡང་མ་ཡིན་ཏེ།
བུམ་པ་བཞིན་ཐ་དད་པར་མི་དམིགས་པའི་ཕྱིར་རོ།
དེ་བཞིན་དུ་ཡང་ཇི་ལྟར་བུམ་པ་དང་ཆུ་བཞིན་རྟེན་དང་བརྟེན་པའི་དངོས་པོར་ཡང་མེད་དེ།
འབྲས་དང་ཕོལ་མིག་ལྟར་ཕུང་པོ་དང་ཉེ་བར་གྱུར་པ་ཡང་ཡོད་པ་མ་ཡིན་ནོ།
ཕུང་པོ་དང་འདུལ་བ་ཡང་མ་ཡིན་ཏེ།
ཕུང་པོ་ལས་ཕྱི་རོལ་པ་མ་ཡིན་པའི་ཕྱིར་རོ།
དེ་བཞིན་དུ་ཇི་ལྟར་ལྷ་སྦྱིན་བ་ལང་ཅན་བཞིན་ཕུང་པོ་དང་ལྡན་པ་ཡང་མ་ཡིན་ནོ།
```

所遍计的“我”是怎样的呢？首先，蕴不是我，因为蕴具有生与灭的性质。也不是离开蕴之外另有我，因为不能像瓶子那样，离开蕴而被单独地缘取。同样，也不像瓶与水那样，（我与蕴之间）有能依与所依的关系；也不像谷粒与（其上的）疱一样，（我）与蕴相邻而存在。（我）也不是与蕴混合的，因为它并不在蕴之外。同样，也不像天授拥有牛那样，（我）拥有蕴。

【按】这是中观破“我”的典型论式，与月称《入中论》中的“七相观察”（如观车）相近：我不是蕴，不是离蕴而有，不在蕴中，蕴不在我中，我不拥有蕴，等等。本篇列举的是：一、蕴非我；二、离蕴无我；三、我与蕴非能依所依；四、我与蕴非相邻；五、我与蕴非混合；六、我不拥有蕴。

【按】第14句“འབྲས་དང་ཕོལ་མིག”，直译是“谷粒与疱”，所指不完全确定，这里读作比喻两物相邻而有。第15句“ཕུང་པོ་དང་འདུལ་བ”，“འདུལ་བ”（调伏）在这里不通，依上下文应是“འདུས་པ”（混合、聚合）的讹误，这里依此译出。“天授”是印度论典中的常用假名。

### 四、答难：无我则业果无关？——绳蛇之喻

```
འདིར་ཕ་རོལ་རྒོལ་བ་ན་རེ་བདག་མེད་ན་ནི་དེའི་ཚེ་ལས་དང་འབྲས་བུ་འབྲེལ་བ་དོན་མེད་པར་འགྱུར་བ་སྟེ།
བ་ལང་ཤི་ན་རྭ་དང་རྨིག་པ་དང་།
རྔ་མ་ལ་སོགས་པ་ཡང་ལྡོག་པར་འགྱུར་བ་བཞིན་ནོ་ཞེ་ན།
སྨྲས་པ་འདིར་ཁྱད་པར་ཅན་གྱི་དཔེ་ཉོན་ཅིག།
ནམ་མཁའོ་ཟེར་གྱུར་པ་ན་ཐག་པ་ལ་སྦྲུལ་དུ་ཤེས་པས་སྐྲག་པ་ཉིད་དུ་གྱུར་ནས་དེ་ལྟར་མར་མེ་ཁྱེར་ཏེ་བལྟས་པའི་ཚེ་འདི་ཐག་པ་ཡིན་གྱི་སྦྲུལ་ནི་མ་ཡིན་ནོ།
འོན་ཀྱང་མི་བདེན་པར་སྒྲོ་བཏགས་པ་དང་བྲལ་ལོ་སྙམ་པ་དེ་བཞིན་དུ་མདོར་བསྡུས་ན་གང་ཟག་གི་བདག་མེད་པའོ།
```

这里，对方辩驳说：“如果没有我，那么业与果的联系就失去了意义，就像牛死了，牛角、牛蹄与牛尾等也都随之消失一样。”回答：在这里，请听一个特殊的譬喻。天色昏暗的时候，把绳子认作蛇，因此而惊恐；后来拿着灯去看，（才知道）这是绳子，并不是蛇。然而（绳子本身并未消失），只是离开了不真实的增益而已。同样，简要地说，这就是补特伽罗无我。

【按】这一段非常重要。对方的问难是：如果没有“我”，造业者与受果者之间的联系就断了，业果就没有意义。论主的回答是：无我，只是去除了对“我”的错误增益，就像认出绳子不是蛇，只是去掉了“蛇”的错觉，绳子并没有因此消失；同样，破除“我”的执著，并不会使世俗的业果相续消失。这正说明，无我并不是断灭，业果在世俗中依然不虚。这一点必须特别注意。

【按】第22句开头“ནམ་མཁའོ་ཟེར་གྱུར་པ་ན”，字面不通顺，依文意（以下说“拿灯去看”）读作“天色昏暗的时候”，是推定的读法。第23句括号中的字是译者所补。

### 五、破法我：绳、线、微尘皆不成立

```
འདིར་བརྗོད་པ།
དེ་ལྟ་མོད་ཀྱི་ཐག་པའི་དངོས་པོ་ཡོད་དོ་ཞེ་ན།
སྨྲས་པ།
འདི་ཐག་པ་མ་ཡིན་ཏེ།
གཉིས་བསྒྲིལ་བའོ།
གཉིས་བསྒྲིལ་བ་ཡང་ཡོད་པ་མ་ཡིན་ཏེ།
སྣལ་མའི་ཚོགས་ཡིན་པའི་ཕྱིར་རོ།
དེ་ཡང་ཡོད་པ་མ་ཡིན་ཏེ་རྡུལ་ཕྲ་རབ་འདུས་པའི་ཕྱིར་རོ།
རྡུལ་ཕྲ་རབ་ཀྱང་ཡོད་པ་མ་ཡིན་ཏེ་ཕྱོགས་ཆ་ཐ་དད་པས་ཕྱེ་ན་རྡུལ་ཕྲ་རབ་ཀྱང་ཐ་དད་པར་མཐོང་བའི་ཕྱིར་རོ།
གང་ལ་ཆ་ཤས་ཆ་ཅན་དུ་གཏོགས་པ་དེ་ཇི་ལྟར་རྡུལ་ཕྲ་མོར་འགྱུར།
དེ་ལྟ་བས་ན་ཐམས་ཅད་མེད་པར་འགྱུར་རོ་ཞེ་ན།
```
```
དངོས་པོ་ཡོད་པ་མ་ཡིན་པས། །གང་ཞིག་མེད་པར་འགྱུར་བ་ཡིན། །
ཡོད་དང་མེད་པའི་ཆོས་བྲལ་བས། །ཡོད་དང་མེད་པར་བསམ་དུ་མེད། །
```
```
འདི་དག་ནི་ཆོས་བདག་མེད་པའོ།
```

这里有人说：“虽然如此，但绳子这件东西是存在的。”回答：这并不是绳子，而是两股（线）绞在一起的。两股绞在一起的也并不存在，因为它是一堆线的聚合。那（线）也并不存在，因为它是极微尘的聚合。极微尘也并不存在，因为如果按方位来分割，就会看见极微尘也有不同的部分。凡是可以分为部分与具部分者的，怎么能是极微呢？（对方说：）“这样一来，一切都成为不存在了。”（回答：）事物本来就不存在，又有什么东西会变成不存在呢？（真实）远离了有与无之法，所以不能思议为有，也不能思议为无。这就是法无我。

【按】这一段是以“绳子”为例，层层分析：绳是二股所绞，二股是众线所聚，线是微尘所聚，微尘又可按方位分割，所以没有不可分的极微。这是中观与经部、有部辩论中常用的“破极微”论证。

【按】“事物本不存在，又有什么会变成不存在”，是破“空性即断灭”的误解：并不是本来有的东西被破成没有，而是本来就没有实有之物。“离有无二法，不可思为有无”，就是中观离二边的见地。

### 六、破生、住、灭

```
གལ་ཏེ་སྐྱེ་བ་དང་གནས་པ་དང་བྲལ་བའི་འཇིག་པ་ཡོད་པ་དེའི་ཚེ་མོ་གཤམ་གྱི་བུ་ལ་ཡང་ཇི་ལྟར་ཟློག་པར་བྱེད།
འོན་ཏེ་ཅིག་ཅར་དུ་འཇུག་གོ་ཞེ་ན།
མ་ཡིན་ཏེ།

```

（对方问：）“如果是这样，那么生、住、灭是怎样的呢？”（对方自答：）“最初出现的，称为生。”回答：离开了住与灭，是什么在生呢？如果有一个没有住与灭的生，那么连龟毛也会生起了。（对方）说：“虽然如此，但（事物）是住的。”离开了生与灭，是什么在住呢？如果没有生与灭而能住，那么连未曾生出的两个头、三只手，也会被看见了。（对方）又说：“那么，（事物）是灭的。”如果离开了生与住而有灭，那么连石女之子，又怎么去遮止（他的灭）呢？（对方）又说：“（生、住、灭）是同时运作的。”不是这样，因为它们彼此相违，就像黑暗与光明一样。

【按】这一段破有为法的三相（生、住、灭），与龙树《中论·观三相品》的论证相近：三相若各别，则无生而生、无住而住、无灭而灭，都有过失；若同时，则彼此相违，如明暗不能并存。

【按】这一段中，“说”（སྨྲས་པ）与“若言”（ཞེ་ན）交替出现，哪几句是对方的话、哪几句是论主的回答，原文标记不完全清楚，以上依文意分配。

### 七、破唯识：识亦非一非多

```
འོན་ཏེ་རྣམ་པར་རིག་པར་སྨྲ་བ་ན་རེ་འདི་ལྟར་རྣམ་པར་ཤེས་པ་ནི་ཡོད་དོ་ཞེ་ན།
སྨྲས་པ།
གལ་ཏེ་ཡོད་པ་དེའི་ཚེ་ངོ་བོ་ཉིད་དཔྱད་པར་བྱ་སྟེ།
གཅིག་ཅིག་གི་རང་བཞིན་ཡིན་ནམ་དུ་མའི་རང་བཞིན་ཡིན།
རེ་ཞིག་གཅིག་གི་རང་བཞིན་ནི་མ་ཡིན་ཏེ།
ཕྱོགས་ཆ་དུ་མས་ཐ་དད་པའི་ཕྱིར་རོ།
གཅིག་གི་རང་བཞིན་མེད་ན་དུ་མའི་རང་བཞིན་ཡོད་པ་མ་ཡིན་ནོ།
ཁ་དོག་གམ་དབྱིབས་དམིགས་པ་མ་ཡིན་གྱི་འོན་ཀྱང་སྐྱེ་བའོ་ཞེ་ན།
དེ་ཡང་མི་འཐད་དེ་རང་ངམ་གཞན་ནམ་གཉི་ག་ལས་སམ་རྒྱུ་མེད་པར་མི་རུང་བའི་ཕྱིར་རོ།
```

（又有）主张唯识的人说：“这样，识是存在的。”回答：如果识存在，那就要观察它的体性：它是单一的自性，还是多的自性？首先，它不是单一的自性，因为它由众多的方分所区别。没有单一的自性，就不会有多的自性。（对方说：）“虽然看不到它的颜色或形状，但它是生起的。”这也不合理，因为（它）不能从自生、从他生、从二者共生，也不能无因而生。

【按】这一段破唯识宗所主张的实有之“识”，用的是“离一多因”（一与多都不成立）与“破四生”（不自生、不他生、不共生、不无因生）两种中观的根本论式。“识有众多方分”，是指识显现为种种行相，所以不是单一的。

【按】本篇作者梅纪巴在大手印传承中极为重要，他的见地属于中观，主张“无住”（不住于任何宗见）。这一段对唯识的破斥，正体现了他的立场。

### 八、显现如幻

```
དེ་ལྟ་ན་ནི་གལ་ཏེ་ཐམས་ཅད་མེད་པ་དེའི་ཚེ་ན་ཕྱི་རོལ་དང་ནང་དུ་སྣང་བ་འདི་དག་ཅི་ཞིག་ཡིན་ཞེ་ན།
སྨྲས་པ།
```
```
མགལ་མེའི་འཁོར་ལོ་སྤྲུལ་པ་དང་། །རྨི་ལམ་སྒྱུ་མ་ཆུ་ཟླ་དང་། །
སྒྲ་བརྙན་དང་ནི་སྨིག་རྒྱུ་དང་། །དུ་བའི་མཚན་མ་ལ་སོགས་བཞིན། །
```

（对方问：）“如果是这样，一切都不存在，那么外在与内在所显现的这些，又是什么呢？”回答：（它们）就像旋火轮、幻化、梦境、幻术、水中月、回声、阳焰、烟相等等一样。

【按】这里列举的都是佛经中常用的如幻之喻：旋火轮（挥动火把成轮）、化人、梦、幻术、水中月、回声、阳焰、烟等。意思是：显现虽然历历可见，却没有自性，如幻如化。这正是大手印“现空无二”的见地。

【按】“དུ་བའི་མཚན་མ”，“烟相”，在密乘中也指修行中出现的烟、阳焰等相，这里与其他如幻之喻并列，应是一般的譬喻。

### 九、引经：无可除亦无可立

```
དེ་སྐད་དུ་ཡང་།
```
```
འདི་ལ་བསལ་བྱ་ཅི་ཡང་མེད། །གཞག་པར་བྱ་བ་ཅུང་ཟད་མེད། །
ཡང་དག་ཉིད་ལ་ཡང་དག་ལྟ། །ཡང་དག་མཐོང་ན་རྣམ་པར་གྲོལ། །
```

```
ཞེས་གསུངས་སོ།
```

（经中）也这样说：“此中无一法可遣除，也无少法可安立；于真实中观真实，见到真实就得解脱。”

【按】这一偈非常著名，见于《宝性论》与《现观庄严论》等论典，是大乘见地的纲要：心性本来清净，没有烦恼需要遣除；本来具足，也没有功德需要新立；只要如实观照真实，见到真实就能解脱。大手印、大圆满都常引用这一偈来说明本来圆满、无修无整的见地。

### 十、结颂：无所缘与六度

```
དམིགས་པ་མེད་པའི་ཆོས་འདི་ཀུན། །དམིགས་པ་མེད་པར་རབ་ཏུ་བཤད། །
དམིགས་པ་མེད་པའི་བློར་བྱས་ནས། །དམིགས་པ་མེད་པར་འགྱུར་བ་ཡིན། །
སྦྱིན་དང་ཚུལ་ཁྲིམས་བཟོད་བརྩོན་འགྲུས། །བསམ་གཏན་ལ་སོགས་རྟག་ཏུ་བརྟེན། །
དུས་མི་རིང་བ་ཉིད་དུ་ནི། །བླ་མེད་བྱང་ཆུབ་ཐོབ་པར་འགྱུར། །
```

这一切无所缘之法，都以无所缘的方式宣说；以无所缘的心来修，就成为无所缘。常常依止布施、持戒、忍辱、精进与禅定等，不久就会获得无上菩提。

【按】这八句与前面所译龙树《所缘修习》中的第九、第十偈（第33至40句）几乎完全相同，只有个别字词不同。可见这两篇在流传中有密切的关系，或者梅纪巴在这里引用了龙树的偈子作为结尾。

【按】在层层破斥我、法、生住灭、识之后，以“依止六度速得菩提”作结，说明空性的见地与菩萨的行持不可分离，不能执空废行。

## 跋语

```
མ་རྟོགས་པ་རྟོགས་པར་བྱེད་པ་སློབ་དཔོན་ཆེན་པོ་དཔལ་གཉིས་མེད་རྡོ་རྗེས་མཛད་པ་རྫོགས་སོ།། །།རྒྱ་གར་གྱི་མཁན་པོ་ཕྱག་ན་རྡོ་རྗེ་དང་། བོད་ཀྱི་ལོ་ཙཱ་བ་རྨ་བན་ཆོས་འབར་གྱིས་བསྒྱུར་བའོ།།
```

名为《使未悟者得悟》，大阿阇黎吉祥无二金刚所造，圆满。印度堪布金刚手与藏地译师玛班却巴翻译。

## 通篇连读

向无有过失、功德如海的怙主妙吉祥顶礼之后，我以悲悯之心，来写这部“使未悟者得悟”的论。

在这里，了悟“他人所遍计的（并不存在）”，就是诸法的真实性。他人所遍计的是什么呢？就是所遍计的“我”：它是周遍的、遍行一切的、不是色法的、唯一而存在的（东西）。

所遍计的“我”是怎样的呢？首先，蕴不是我，因为蕴具有生与灭的性质。也不是离开蕴之外另有我，因为不能像瓶子那样，离开蕴而被单独地缘取。同样，也不像瓶与水那样，（我与蕴之间）有能依与所依的关系；也不像谷粒与（其上的）疱一样，（我）与蕴相邻而存在。（我）也不是与蕴混合的，因为它并不在蕴之外。同样，也不像天授拥有牛那样，（我）拥有蕴。

这里，对方辩驳说：“如果没有我，那么业与果的联系就失去了意义，就像牛死了，牛角、牛蹄与牛尾等也都随之消失一样。”回答：在这里，请听一个特殊的譬喻。天色昏暗的时候，把绳子认作蛇，因此而惊恐；后来拿着灯去看，（才知道）这是绳子，并不是蛇。然而（绳子本身并未消失），只是离开了不真实的增益而已。同样，简要地说，这就是补特伽罗无我。

这里有人说：“虽然如此，但绳子这件东西是存在的。”回答：这并不是绳子，而是两股（线）绞在一起的。两股绞在一起的也并不存在，因为它是一堆线的聚合。那（线）也并不存在，因为它是极微尘的聚合。极微尘也并不存在，因为如果按方位来分割，就会看见极微尘也有不同的部分。凡是可以分为部分与具部分者的，怎么能是极微呢？（对方说：）“这样一来，一切都成为不存在了。”（回答：）事物本来就不存在，又有什么东西会变成不存在呢？（真实）远离了有与无之法，所以不能思议为有，也不能思议为无。这就是法无我。

（对方问：）“如果是这样，那么生、住、灭是怎样的呢？”（对方自答：）“最初出现的，称为生。”回答：离开了住与灭，是什么在生呢？如果有一个没有住与灭的生，那么连龟毛也会生起了。（对方）说：“虽然如此，但（事物）是住的。”离开了生与灭，是什么在住呢？如果没有生与灭而能住，那么连未曾生出的两个头、三只手，也会被看见了。（对方）又说：“那么，（事物）是灭的。”如果离开了生与住而有灭，那么连石女之子，又怎么去遮止（他的灭）呢？（对方）又说：“（生、住、灭）是同时运作的。”不是这样，因为它们彼此相违，就像黑暗与光明一样。

（又有）主张唯识的人说：“这样，识是存在的。”回答：如果识存在，那就要观察它的体性：它是单一的自性，还是多的自性？首先，它不是单一的自性，因为它由众多的方分所区别。没有单一的自性，就不会有多的自性。（对方说：）“虽然看不到它的颜色或形状，但它是生起的。”这也不合理，因为（它）不能从自生、从他生、从二者共生，也不能无因而生。

（对方问：）“如果是这样，一切都不存在，那么外在与内在所显现的这些，又是什么呢？”回答：（它们）就像旋火轮、幻化、梦境、幻术、水中月、回声、阳焰、烟相等等一样。

（经中）也这样说：“此中无一法可遣除，也无少法可安立；于真实中观真实，见到真实就得解脱。”

这一切无所缘之法，都以无所缘的方式宣说；以无所缘的心来修，就成为无所缘。常常依止布施、持戒、忍辱、精进与禅定等，不久就会获得无上菩提。
