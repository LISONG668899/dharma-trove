# 唯心之见

阿阇黎萨惹哈 传　阿阇黎梅纪巴 说

## 题解

本篇出自德格版丹珠尔续部（རྒྱུད་འགྲེལ།）ཟི 函第48b叶第4行至第49a叶第3行，东北目录编号 D2435。全篇三十五句，每句七个音节，以“瑜伽士啊，除此之外再没有别的方法”为叠句。篇幅很短，所以把藏文原文全部保留在代码块中，按段落分开，每段后附汉译，疑难之处另以【按】说明。

梵文题名：Citta-mātra-dṛṣṭi-nāma（ཙིཏྟ་མ་ཏྲ་དྲྀཥྚི་ནཱ་མ）。

藏文题名：སེམས་ཙམ་གྱི་ལྟ་བ（唯心之见）。

【按】题名“唯心”（སེམས་ཙམ），字面上与“唯识宗”（སེམས་ཙམ་པ）的名称相同，但本篇的内容并不是宣讲唯识宗的宗义，而是以“心之船”为喻，说一切修持、一切宗见都归于此心，心融入空性而渡到彼岸。所以这里的“唯心”，应理解为“一切唯是此心”的意思，读者不要与唯识宗的宗义混同。

【按】跋语说本篇“由阿阇黎萨惹哈传下，阿阇黎梅纪巴所说”。萨惹哈是印度大手印传承的初祖之一；梅纪巴（མཻ་ཏྲི་པ，Maitrīpa）是夏瓦日巴的弟子、玛尔巴的上师，在大手印传承中极为重要。前面所译的萨惹哈道歌与梅纪巴的著作，与本篇可以互相参看。跋语没有记载译者。

## 正文

### 第一段：虚空之船

```
ནམ་མཁའ་ཞེས་བྱའི་གྲུ་ལ་ནི། །ལུས་ངག་ཡིད་གསུམ་དཀྲུགས་ཤིང་བྱས། །བླ་མའི་མན་ངག་གཞུང་ཤིང་བཙུགས། །སེམས་ཀྱི་བརྟན་པ་གྲུམ་ནན་ཞིང་། །
ཕ་རོལ་སྒྲོལ་བར་བྱས་པ་ལས། །འདི་ལས་ཐབས་གཞན་རྣལ་འབྱོར་པ། །ཡོད་པ་དག་ནི་མ་ཡིན་ནོ། །
```

在名为“虚空”的船上，以身、语、意三者为船桨，竖起上师的口诀作为桅杆，以心的坚稳紧紧（把舵），渡向彼岸。瑜伽士啊，除此之外，再没有别的方法了。

【按】本篇通篇以“渡船”为喻：船是心（或虚空般的心性），桨是身语意，桅杆是上师口诀，彼岸是解脱。以船喻修行，在印度道歌中很常见，古孟加拉语《恰雅歌集》中也有署名萨惹哈的渡船之歌。以下的配释，都是依这一譬喻推定的。

【按】“དཀྲུགས་ཤིང”，字面是“搅动之木”，这里读作船桨。“གཞུང་ཤིང”，字面是“主干之木”，这里读作桅杆或撑船的长篙。

【按】第4句“སེམས་ཀྱི་བརྟན་པ་གྲུམ་ནན་ཞིང”，其中“གྲུམ་ནན”意思不明，可能指船舵、缆绳之类，也可能是“紧紧地”的意思。这里依文意译作“以心的坚稳紧紧（把舵）”，括号中的字是译者所补，请读者留意。

### 第二段：无分别、无桨，双风推动

```
འདི་ལས་རྣམ་རྟོག་ཡོད་མིན་ལ། །དཀྲུགས་ཤིང་དག་ཀྱང་ཡོད་མ་ཡིན། །རླུང་གཉིས་ཀྱིས་ནི་དེད་ནས་འགྲོ། །ཐབས་ཀྱིས་དེ་རུ་བརྟོལ་ཏེ་གནས། །
```

在这里，没有分别，也没有船桨；以两股风推动而前行，以方便在那里穿透而安住。

【按】这几句与上一段看似矛盾：上一段说“以身语意为桨”，这里又说“没有船桨”。意思可能是：在究竟上，连能渡的工具也没有，没有分别造作；只是依两股风的推动而自然前行。

【按】“རླུང་གཉིས”，“两股风”，在圆满次第中常指左右二脉的气息；“ཐབས་ཀྱིས་དེ་རུ་བརྟོལ་ཏེ་གནས”，“以方便在那里穿透而安住”，可能指以方便令气息穿入中脉而安住。这是依圆满次第通义的推解，原文没有明说。

### 第三段：不速行则有盗贼与深渊

```
གྲུ་འདི་མྱུར་བར་མ་བསྐྱོད་ན། །བར་ནས་ཆོམ་པོའི་འཇིགས་པ་ཆེ། །རྒྱ་མཚོའི་ཆུ་རླབས་གཡོས་པ་ཡིས། །སྲིད་གསུམ་གཡང་སར་རྣལ་འབྱོར་ལྷུང་། །
སེམས་ཀྱི་གྲུ་འདི་བརྟན་བཟུང་བ། །ཕ་རོལ་དག་ཏུ་སྒྲོལ་བར་བྱ། །འདི་ལས་ཐབས་གཞན་རྣལ་འབྱོར་པ། །ཡོད་པ་དག་ནི་མ་ཡིན་ནོ། །
```

这只船如果不迅速驶行，途中就有强盗的大怖畏；因为大海的波浪翻动，瑜伽士就会坠入三有的深渊。要牢牢把住这心之船，渡到彼岸去。瑜伽士啊，除此之外，再没有别的方法了。

【按】“ཆོམ་པོ”，“强盗”，可能比喻烦恼、魔障或分别念，劫夺修行人的功德。“རྒྱ་མཚོའི་ཆུ་རླབས”，“大海的波浪”，比喻轮回中种种念头与境界的起伏。“སྲིད་གསུམ་གཡང་ས”，“三有的深渊”，即轮回三界。这些都是推解。

### 第四段：六见皆归此一船

```
མ་རྟོགས་པ་ནི་ཐམས་ཅད་ཀྱིས། །བྱེ་བྲག་ཏུ་ནི་སྨྲ་བར་བྱེད། །བརྟགས་ཤིང་ལྟ་དྲུག་ཐམས་ཅད་ཀྱང་། །གྲུ་འདི་གཅིག་ཏུ་འདུས་པར་འགྱུར། །
སེམས་ཀྱི་གྲུ་འདི་བརྟན་བཟུང་ལ། །ཕ་རོལ་དག་ཏུ་སྒྲོལ་བར་བྱ། །འདི་ལས་ཐབས་གཞན་རྣལ་འབྱོར་པ། །ཡོད་པ་དག་ནི་མ་ཡིན་ནོ། །
```

没有证悟的人，都在各别地分说；（但）仔细观察起来，一切六种见，也都汇集在这一只船中。要牢牢把住这心之船，渡到彼岸去。瑜伽士啊，除此之外，再没有别的方法了。

【按】“ལྟ་དྲུག”，“六见”，与前面所译甘巴拉《不相属之见》《不取著之见》中的“六见”应是同一说法，大概指当时印度内外六种主要的宗见。“一切六见都汇集在这一只船中”，意思可能是：一切宗派所说，归根到底都不离此心；不同宗派的分歧，只是未证悟者的分别。这是推解。

### 第五段：逆流而上，心融空性

```
མཐའ་གཅིག་ནས་ནི་དྲངས་བྱས་ནས། །གྲུ་འདི་གྱེན་ལ་བགྲོད་པར་བྱ། །ས་ར་ཧ་ནི་སྨྲ་བར་བྱེད། །སེམས་ནི་སྟོང་ཉིད་གནས་སུ་ཐིམ། །
སེམས་ཀྱི་གྲུ་འདི་བརྟན་བཟུང་ལ། །ཕ་རོལ་དག་ཏུ་བགྲོད་པར་བྱ། །འདི་ལས་ཐབས་གཞན་རྣལ་འབྱོར་པ། །ཡོད་པ་དག་ནི་མ་ཡིན་ནོ། །
```

从一端牵引着，让这只船逆流而上。萨惹哈这样说：心融入了空性之处。要牢牢把住这心之船，驶向彼岸。瑜伽士啊，除此之外，再没有别的方法了。

【按】“གྱེན་ལ་བགྲོད”，“向上行”“逆流而上”，在圆满次第中，可能比喻令气息、明点沿中脉向上运行；也可以照字面理解为逆着轮回之流而上。“མཐའ་གཅིག་ནས་དྲངས”，“从一端牵引”，意思不完全清楚。

【按】“ས་ར་ཧ”，即大成就者萨惹哈（Saraha），依跋语是本篇的传承上师，在诗中引他的话：“心融入空性之处。”这是全篇的点睛之句。

【按】本段叠句第二句作“驶向彼岸”（བགྲོད་པར་བྱ），前几段作“渡到彼岸”（སྒྲོལ་བར་བྱ），意思相近。
