# 无别五颂

梅纪巴造　据藏文译出

## 题解

本篇收于德格版丹珠尔续部释 ཝི 函第 114a 至 114b 页（东北目录 D2238），紧接在《慈五颂》（D2237a）之后，同属梅纪巴的"无念法类"。译者是印度堪布金刚手与玛班译师。

关于题名：藏本所录梵题作 Nirbheda-pañcaka，藏题作 mi phyed pa lnga pa，直译是"不可分五［颂］"。梵文 nirbheda 一词本身有两种意思：一是"穿透、洞彻"（与"洞见、胜观"之义相近），二是加上否定前缀理解为"不可分、无别"。藏译者取的是后一种，译作"不可分"；而本篇每颂之后的短释，也反复以"无别"（dbyer med）来点明各颂的要旨，如"自性无别""极为无别的俱生"。所以这里依藏译与短释，题作《无别五颂》。若依梵文另一义，也可以题作《洞见五颂》，两者都有根据，并存于此。

本篇体例特别：五颂各附一句散文短释，说明该颂所开示的是什么。这些短释是作者自注，还是后人所加，原文没有交代。全篇的线索，是"无别"——佛与众生无别、空性与悲心无别、空性与世俗清净无别：

第一颂说众生本来清净，破除对对治、真如与果的分别；第二颂说空性的智慧本身就是任运的悲心，这是证悟无别的体性；第三颂赞叹空性、悲心、轮之约束的力量与世俗清净，这是无别俱生的威力；第四颂说这境界不可言说，能信解者难得；第五颂说菩萨以此证悟，对伤害自己的众生不加报复而能安忍，并以悲心摄持被业所缚的一切众生。

体例：每颂先列藏文原颂于代码块中，再按完整的意义单元译出；短释照原文译出，标为"【短释】"；为了便于理解而补的字，都放在方括号中。原文含混或可有两解之处，以"【按】"说明，不妄补内容。文末附通篇连读。

## 题名与礼敬

梵语题名：Nirbheda-pañcaka。藏语题名：《无别五颂》（mi phyed pa lnga pa）。

敬礼佛陀！

## 第一颂　众生本来清净

```
སངས་རྒྱས་རྟོགས་ན་འགྲོ་བ་དག །
སངས་རྒྱས་རྟོགས་པ་ཅན་རྩ་ལག །
ཨེ་མའོ་སངས་རྒྱས་གཟོད་ནས་དག །
སངས་རྒྱས་བསྟན་པ་ཇི་ལྟར་རྟོགས། །
```

若证悟了佛，众生［便见其］清净；证悟佛的人，就是［众生的］亲眷。奇哉！佛本来就是清净的，［那么，］佛所开示的教法，又要怎样去证悟呢？

【短释】这一颂遮止对于对治、真如与果的分别——［这三者］在自性上是无别的——开示的是［诸法的］本体。

【按】这一颂很难确定，以下是依短释的理解。前两句说：若证悟了佛性，就会见到众生本来清净；证悟者与众生如同亲眷，没有隔阂。"亲眷"（rtsa lag），原意是亲属、同伴，也可以理解为"证悟佛者，［以众生为］亲眷"。后两句以惊叹的语气说：佛本来就是清净的，那么还有什么"教法"要去证悟呢？这是用反问来破除"另有一个佛果要去修得"的分别。

短释所说的"对治、真如与果"，指修行中常被分开来看的三者：用来对治烦恼的修法（对治）、所要证悟的实相（真如）、最终得到的佛果（果）。作者认为三者在自性上无别，这一颂就是要遮止把它们分开的分别心。

## 第二颂　空性即任运悲心

```
ཡེ་ཤེས་རྙོག་མེད་སྟོང་པ་སྟེ། །
ལྷུན་གྲུབ་སྙིང་རྗེའི་བདག་ཉིད་ཅན། །
དེ་ཡང་རྐྱེན་ལས་སྐྱེས་པ་སྟེ། །
དངོས་དང་དངོས་མེད་རྣམ་པར་སྤངས། །
```

智慧是无浊的、空的，［同时又］以任运的悲心为其体性；而它也是从因缘所生的，［所以］远离了有实与无实［二边］。

【短释】这里开示的，是证悟无别的体性。

【按】"无浊"（rnyog med），指没有烦恼与分别的浑浊，如清水一般。"任运"（lhun grub），即自然成就、不需造作。这一颂说：证悟空性的智慧，与悲心并不是两回事；空性的智慧本身就自然流露为悲心。"从因缘所生"一句，是说这智慧与悲心的显现也是缘起，所以既不是实有，也不是断无。这与《双运义明示》第八颂"空悲合一，不是由分别造作"的意思一致。

## 第三颂　四种稀有

```
ཆོས་རྣམས་སྟོང་པ་ཡ་མཚན་ཆེ། །
སྙིང་རྗེ་ཤིན་ཏུ་ངོ་མཚར་ཆེ། །
འཁོར་ལོ་སྡོམ་པའི་ནུས་པ་མཚར། །
ཀུན་རྫོབ་དག་པ་ཤིན་ཏུ་མཚར།
```

诸法是空的，真是大为稀奇！悲心，真是极为稀有！轮之约束的力量，真是奇妙！世俗是清净的，真是极为奇妙！

【短释】这一颂讲的，是那极为无别的俱生的威力。

【按】"轮之约束"（'khor lo sdom pa，梵 cakrasaṃvara），字面是"约束诸轮"，也是本尊胜乐金刚的名号。这里可以理解为本尊胜乐金刚，也可以理解为以脉轮、气息修持而约束诸轮的密法之力；原文没有交代，存疑。短释说四句都在讲"无别俱生的威力"，所以四者——空性、悲心、密法的力量、世俗清净——并非分开的四件事，而是同一俱生本性的四个方面。"轮之约束"属于密法的修持，须依具德上师的灌顶与口授来理解，不可照字面揣度。

## 第四颂　不可言说，信解者难得

```
ཧ་ཅི་བརྗོད་པ་ཇི་ལྟར་བཤད། །
བཤད་ན་སྐྱེ་བོ་སུ་ཡིས་གོ། །
རྟོགས་པར་གྱུར་ན་མི་འགྱུར་ཉིད། །
ལྷུན་གྱིས་གྲུབ་པ་ཉིད་དུ་སྣང་། །
```

哈！要说什么呢？又怎么解说呢？就算解说了，又有什么人能懂呢？若是证悟了，［它］就是不变的，显现为任运成就的。

【短释】这一颂开示的是：对于以悲心而全然无住的甚深法理，能起信解的人难以找到。

【按】"哈"（ha），是道歌中表示惊叹或自嘲的语气词。"以悲心而全然无住"（snying rjes rab tu mi gnas pa），是大乘"无住涅槃"的意思：以智慧不住生死，以悲心不住涅槃。短释把这一颂的"不可言说"，归结到这一甚深的法理难以被信解，与《幻教示》"实修者难得"的感叹相呼应。

## 第五颂　安忍与摄持众生

```
རང་གི་ལས་ཀྱི་ས་བོན་སྐུ། །
གནད་གཅོད་པ་ཡི་འབྲས་བུ་གང་། །
བདག་གིས་གཞན་ལ་མི་གཙེ་སྟེ། །
ཨེ་མའོ་དེ་ཉིད་ཀྱིས་ནི་བཟོད། །
```

［所受的］身，是自己的业种［所生］；［别人加诸我身、］伤及要害的［种种伤害］，也是［自己业种的］果报。［所以］我不去伤害他人；奇哉！就以这［了知］本身，［我］能够安忍。

【短释】这一颂所说的，是菩萨摄持一切众生——他们的心被自己的业线之结所缠缚——并且将他们放在心上。

【按】这一颂的藏文极为简略，以下是依短释的理解。前两句可以理解为：我这个身体是自己的业种所生，别人对我造成的伤害，触及要害，也是我自己业种的果报。后两句说：明白了这一点，我就不去报复、伤害他人，而能以这种了知安忍。"伤及要害"（gnad gcod pa），字面是"截断要害"，指致命的伤害或剧烈的痛苦。

另一种可能的理解是：第一句的"身"（sku）是敬语，指佛身，意思是"佛身是自己业种［成熟］的果"；但这样与后两句"不伤害他人、安忍"的文意不容易衔接，这里不取，存疑。

短释则从另一面来说：伤害他人的众生，其实是被自己的业力像绳结一样缠缚着，不由自主；菩萨了知这一点，就不报复，反而以悲心摄持他们、把他们放在心上。这样，全篇以菩萨的安忍与悲心作结，把前面所说的"空悲无别"落实到对待众生的行持上。

## 通篇连读

敬礼佛陀！

若证悟了佛，众生便见其清净；证悟佛的人，就是众生的亲眷。奇哉！佛本来就是清净的，那么佛所开示的教法，又要怎样去证悟呢？——这一颂遮止对于对治、真如与果的分别，这三者在自性上无别，开示的是诸法的本体。

智慧是无浊的、空的，同时又以任运的悲心为体性；而它也是从因缘所生，所以远离了有实与无实二边。——这里开示的，是证悟无别的体性。

诸法是空的，真是大为稀奇！悲心，真是极为稀有！轮之约束的力量，真是奇妙！世俗是清净的，真是极为奇妙！——这一颂讲的，是那极为无别的俱生的威力。

哈！要说什么呢？又怎么解说呢？就算解说了，又有什么人能懂呢？若是证悟了，它就是不变的，显现为任运成就。——这一颂开示的是：对于以悲心而全然无住的甚深法理，能起信解的人难以找到。

所受的身，是自己的业种所生；伤及要害的种种伤害，也是自己业种的果报。所以我不去伤害他人；奇哉！就以这了知本身，我能够安忍。——这一颂所说的，是菩萨摄持一切被自己的业线之结所缠缚的众生，并且将他们放在心上。
