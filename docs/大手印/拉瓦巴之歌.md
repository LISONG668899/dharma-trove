# 拉瓦巴之歌

阿阇黎拉瓦巴（甘巴拉）造　据藏文译出

## 题解

本篇收于德格版丹珠尔续部释 ཟི 函第 9b 页（东北目录 D2370）。开头没有梵藏题名，只有"敬礼佛陀"；跋语作"拉瓦巴之歌，圆满"，没有记载译者。拉瓦巴即甘巴拉（Kambalapāda），以披一条毛毯而得名，八十四成就者之一；本站已译他的《不相属之见》（D2428），《行·道歌宝藏》（D2347）的作者也自称承他的传承。

全篇约十五句，共四段，叠句是一个反问："若彻底了悟了那真如的自性，就请说说：与它相违的是什么？"四段依次说：无待无生时，与俱生无别；三界就是五方善逝，何者能缚；根本不可得，虚空岂会死；不要以虚妄把空拳绑住。全篇是纯粹的心性开示，没有涉及具体的密法修持。

体例：藏文原文全部保留在代码框中，按段落分节，每节后附汉译；叠句照原文每次重复。凡标"存疑"的按语，表示本译对原文意思没有把握。藏文依 Esukhia 德格丹珠尔电子版。

## 礼敬

```
སངས་རྒྱས་ལ་ཕྱག་འཚལ་ལོ། །
```

敬礼佛陀！

## 一、无待无生，即同俱生

```
ལྟོས་དང་སྐྱེ་བ་གནས་པ་མེད་པ་ན། །
དེ་ཚེ་ལྷན་ཅིག་སྐྱེས་དང་ཁྱད་པར་མེད། །
དེ་ཉིད་མི་མཐུན་པ་དེ་རྣམ་པར་སྨྲོས། །
```

当没有观待、没有生、没有住的时候，那时与俱生就没有差别。请说说：与它相违的是什么？

【按】"若彻底了悟了那真如的自性，就请说说：与它相违的是什么？"是全篇的叠句（首段只出现后一句）。这是一个反问：真如遍于一切，证悟之后，找不到任何与它相违的东西。

## 二、三界是五善逝，何者能缚

```
འདི་ལྟར་ཁམས་གསུམ་བདེ་བར་གཤེགས་པ་ལྔ། །
དེ་ཡི་ཚེ་ན་གང་གིས་བཅིངས་པར་སེམས། །
དེ་ཉིད་རང་བཞིན་ཤིན་ཏུ་གོ་གྱུར་ནས། །
ཇི་ལྟར་མི་མཐུན་པ་དེ་རྣམ་པར་སྨྲོས། །
```

这样，三界就是五方善逝；那时，你以为是被什么束缚着呢？若彻底了悟了那真如的自性，就请说说：与它相违的是什么？

【按】"三界就是五方善逝"，是密乘以五蕴、五毒本来清净为五方佛的见地。

## 三、根本不可得，虚空岂会死

```
འདི་ཀུན་རྩ་བའི་རང་བཞིན་མ་རྙེད་སྟོར། །
དེའི་ཚེ་ནམ་མཁའི་རང་བཞིན་མི་འཆིའམ། །
དེ་ཉིད་རང་བཞིན་ཤིན་ཏུ་གོ་གྱུར་ནས། །
དེ་ཉིད་མི་མཐུན་པ་དེ་རྣམ་པར་སྨྲོས། །
```

这一切根本的自性，找不到而失去了；那时，虚空的自性难道会死吗？若彻底了悟了那真如的自性，就请说说：与它相违的是什么？

【按】存疑。"找不到而失去"（མ་རྙེད་སྟོར），本译依字面译出，意思可能是：寻找一切的根本，找不到，于是执著也失去了；但心性如虚空，本来不生，也不会因此而"死"。

## 四、莫以空拳自缚

```
རྨོངས་པར་མ་བྱེད་གཉིས་མེད་མདུད་པ་ཡིས། །
ཅིས་ཏེ་སྟོང་པའི་ཁུ་ཚུར་རྫུན་གྱིས་བཅིངས། །
དེ་ཉིད་རང་བཞིན་ཤིན་ཏུ་གོ་གྱུར་ནས། །
ཇི་ལྟར་མི་མཐུན་པ་དེ་རྣམ་པར་སྨྲོས། །
```

不要愚昧！为什么要以无二的绳结，用虚妄把空拳绑住呢？若彻底了悟了那真如的自性，就请说说：与它相违的是什么？

【按】"空拳"，是佛典常用的譬喻：以空拳哄骗小儿，拳中其实无物。这里说：以为有一个"无二"可以执持，就像用绳子去绑一个空拳头，本来无物可绑。

【按】存疑。"以无二的绳结"，本译依字面译出，意思可能是：连"无二"也执为一个对象，就成了新的束缚。

```
ལྭ་བ་པའི་གླུ་རྫོགས་སོ། །
```
