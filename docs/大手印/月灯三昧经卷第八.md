# 《月灯三昧经》卷第八

高齐天竺三藏那连提耶舍汉译　白话今译

## 一、四种回向

“童子！所以菩萨摩诃萨为了乐求这个三昧，应当修习善根，行持法施或者行持财施，以这布施度用四种回向来回向。是哪四种呢？

“第一，过去诸佛以善巧方便证得无上正等正觉，愿我也得到这样善巧的方便；以此善根回向菩提，这称为第一回向。

“第二，在善知识那里听闻宣说这样的善巧方便，受持、读诵而修学，以这方便使我得成无上菩提，愿我长夜之中恒常得以值遇善知识；以这善根而回向，这称为第二回向。

“第三，愿我所得的资财与一切众生共同受用；以这善根而回向，这称为第三回向。

“第四，愿我自身在一切受生之处，得到财物、得到佛法，以此摄护利益一切众生，愿我常得这样的身；以这善根而回向，这称为第四回向。

“童子！以这四种回向，应当把一切善根都这样回向。

## 二、奉事持此三昧者

“其次，童子！菩萨摩诃萨为了求取这个三昧，无论在家还是出家，应当以不谄曲之心奉事持戒之人。如果有能受持这个三昧的人，无论出家还是在家，这个人如果遭遇病苦，危重困顿，若能以自己身体的血肉除去他的病患，菩萨若已成就增上的信心，就应当以不动摇之心以及清净之心给予布施。

## 三、实意法师的本生

“童子！在过去超过阿僧祇阿僧祇、无量无边、不可称、不可量、广大不可思议的劫数以前，那时有一尊佛，名号叫不可思议愿胜起王佛、如来、应供、正遍知、明行足、善逝、世间解、无上士、调御丈夫、天人师、佛、世尊。

“那位佛如来、应供、正遍知就在当天证成无上正等正觉，变化出无量无边的应化诸佛来说法，善能调伏无量众生，把他们安置在无漏的阿罗汉道上；也建立无量众生于无上正等正觉，得到不退转。这位不可思议愿胜起王如来就在当天寿尽，入于无余涅槃，正法住世八万四千亿那由他百千年。

“童子！在这位不可思议愿胜起王佛的正法灭尽之后，到了末世，就有无量执著邪见的比丘。那些比丘对于这样的修多罗不爱、不乐、不生信心，诽谤毁訾。如果有能受持这些经典的人，就被那些恶伴逼恼其身，以口呵斥毁辱，乃至夺去性命。那些恶比丘为了贪求利养与恭敬的缘故，杀害了二万位受持此经的比丘。

“童子！那时在这阎浮提中有一位国王，名叫智力，受持正法，护持正法，本愿已经成就，曾经在先前的佛那里种下种种善根。

“童子！往昔在这阎浮提内有一位法师，名叫实意，受持这样的三昧经典，进入王宫作国王的善知识；因为有大悲心，能够救济、利益、怜悯众生。那位国王喜乐见到这位比丘而没有厌足，听他说法论议，前往奉事，亲近供养，请问问难；听了说法能够受持，也善能酬答。

“那时那位比丘善解广说与略说互相摄收的义理，威仪与诸行都具足，善能通达五蕴、十八界、十二处；善知一切众生的聚合与分离、分离之后又复聚合，也了知众生的威仪、诸行、乐欲与性习，善知众生的根、力与精进，善知差别的智慧与性习，善知与谛理相应及不相应；酬答语言时对义理决定，辩才深妙，也能善知调伏众生；他含笑而先开口，见到的人都爱乐他，远离皱眉蹙额，他的心广大，安住于这样的四无量心，与大悲相应，一切异论都不能破坏他。

“童子！那时智力王有一个女儿，名叫智意，年方十六，容貌端正，形色美妙，姿容丰满，无不具备；她以那位实意比丘作为自己的老师与导师。

“那时那位比丘四大不调，在右大腿上生了恶性的黑疮，难以医治，一切医师都放弃他而离去。那时那位智力王见到这位比丘病重困苦，恐怕他死去，号哭流泪；还有诸妃后、八万宫女，以及国土城邑的人民、太子、诸官员、军众、将帅、守门巡逻的人，以及奴婢、亲近随从、左右侍者和其余大众，见到这位比丘都哭泣起来。

“童子！那时智力王先前有一位亲属命终生天，在国王的梦中现身劝导，这样说：‘这位比丘的病，必须用尚未婚配的少女的新鲜血液来洗疮，也用来涂敷疮口；再取她的肉煮成羹汤，以种种滋味调和，与饭一同食用，才能痊愈；如果得不到这种药，必定难以起身。’

“那时，智力王做了这样的梦，醒来到了天明，就从卧处起身，进入后宫，召集诸宫人，详细述说了这个梦：‘我梦见了这样的事。谁能施给这位病中比丘这种药，使我的善知识、宣说善道的人得以痊愈？’

“童子！那时一切内外宫人、宫女，都没有能承担此事的。童子！那时智意在父王那里听到这话之后，知道病中的比丘需要这样的药，听了之后心生欢喜，身心踊跃，这样思惟：‘正如父王所说，我现在这身体从未婚配，可以施给尊者新鲜的血肉。我在宫中年纪最小，对这位法师阿阇梨深生敬重，身、口、意清净，求取无染的智慧，我要以身上的血肉施给这位无所执著的法师，拿自己身上的肉以种种滋味调和。我应当作这位病中比丘的药，使我的大师病苦消除，能够起身康复。’

“那时，智意就拿起利刀，深心安住于法，割下自己大腿上的肉，伤口血流出来；她拿这新鲜的肉调以种种滋味，作成羹汤，用金碗盛取身上流出的血，随即奉国王的命令，唤病中的比丘进入宫中，在父王面前设座请他坐下，用血洗了疮口，又用血涂敷；又拿这肉调以种种其余的上妙滋味，作成美食，为了获得福德的缘故，奉施给法师。

“那时那位比丘并不知道，也没有察觉，不疑有什么不妥，就吃了下去。这位病中的比丘吃这食物的时候，病苦随即消除。

“那时，法师病苦消除之后，身体安稳快乐，就为智力王宣说殊胜微妙之法，为了求取这个三昧的缘故，使这宫内的一万三千位宫女等都发起无上正等正觉之心。

【按】王女割肉供师，与前卷安隐德比丘燃臂同属大乘经中舍身供养的本生，所显示的是为法忘躯、于身命无所顾惜的菩萨愿力。这类示现是诸圣者的境界，后学当学其敬法重师之心，而不可照字面仿效其行。

“那时，智力王就说偈问他的女儿说：

“‘你在哪里得到这新鲜美好的人肉以及人血，能为病人做成美食，使这位比丘得到安乐？

“‘你派谁、到哪里、杀了什么人，才得到这殊胜美好的肉，用种种不同的滋味调和，又得到洁净的血来洗涂疮口？

“‘法师吃了这食物，又用新鲜的血洗涂疮口，能除去这样严重的恶病，使那位尊者获得喜乐。

“‘我从本来的亲属天神那里，在梦中听到这样的话：“如果能得到这样的药，才可以除去那位比丘的病。

“‘“必须用人身新出的血，涂洗法师的毒恶之疮，调和人肉使它香美之后，作为他的食物而奉献。

“‘“比丘只要用这个药方，病患就会立即消除；只有这种药堪能救治，不必借助其他方法，大王请赶快备办。”

“‘我醒来之后从卧处起身，就进入后宫说了这些话；一切宫人听到这话，都默然而住，没有能承担的。

“‘我那时又告诉宫人说：“有没有人能做这样的事，舍弃自己身上的新鲜血肉，调和以种种其余的美味，

“‘“用这药食奉施给他，又以洁净的血洗涂法师比丘的黑色恶疮，这个药方才能使他痊愈；

“‘“如果不用这样的药来疗治比丘的恶疮，法师必定会死去，正是因为缺少这个药方的缘故。”

“‘那时宫人听到这些话，都默然不再言语，没有人能作这样的惠施，施出这样血肉的方药；

“‘乃至一切三界中的人，都没有能舍弃自身之肉的；我在宫中一一普遍告知，寂然无声，没有一句话表示能承担的。

“‘我心中敬重这位比丘，众人却都各自爱惜自身；因为恋著自己身体的缘故，不能割舍自己的血肉。

“‘善哉！告诉我你是在哪里得到的？’

“（智意答道：）‘我那时听了之后心中欢喜，听到父亲尊重殊胜美妙的话，我的心勇猛而不怯弱。’

“智意少女回答父亲说：‘愿父王以清净之心垂听。我对于自己的身体不爱恋，也不计著于我想，能以勇猛之心舍弃自身，为了求取无上菩提的缘故。

“‘唯愿父王再听我说：寻访人肉，始终得不到，所以便割下自己大腿上的肉，调以种种滋味奉献给法师。

“‘我没有杀害他人，也不是死人之肉，割自己的身体是为了作广大的利益；比丘既然得以免除病苦，我也将获得无量的福德。’

“国王随即问道：‘你割身的时候，是否被剧烈的痛苦所逼恼？你赶快准备药物自己涂敷伤口，不要让身体承受大苦。’

“听到父王怜念的话，她说：‘唯愿大王再听我说，听了之后深思正法之行：业果就是这样不可思议。

“‘我从父亲那里听到天神所说的话，对于自己的身命不顾恋，以信敬之心而奉施，所以自己舍弃了新鲜的血肉。

“‘以自己的身体作利益，得以除去比丘的毒恶之病；我现在既然作了无量的福德，就是以不坚固之身换取了坚固之身。’

“她的女儿又这样说：‘唯愿父王再稍听我说，听闻真实之法，愿您受持，观察那业果的不可思议。

“‘众生往昔造作不善之业，由于愚痴而堕入恶道，身肉销尽之后又重新复合，所以说业报难以思议。

“‘起初只剩下骨架锁连，一念之间身肉又重新复合；更何况造作善业的人，随心所欲又怎能得不到呢？

“‘我虽然割了身肉，起初并不痛，伤口流血也没有痛苦；如果割身体的一切部分时，因为思念法的缘故，也没有伤口之处。

“‘我对正法深深爱乐，所以割肉奉施；一切有为法犹如幻化，身上的伤口也会复合如初。

“‘譬如优昙钵罗花，经过无量劫或许才出现一次；比丘法师也是如此，在阎浮提中难得一见。

“‘犹如阎浮金聚的光明，观看的人没有厌足；法师实意也是如此，天人瞻仰而没有厌足。

“‘譬如饮用清凉的水，在炎热时能除去焦渴的苦患；比丘法师也是如此，能除去众生的种种渴爱。

“‘我舍弃大腿上的肉奉献给法师，并施舍自己身上新鲜洁净的血，除去那位法师四大不调之苦，佛所赞叹的事我已经做了。

“‘圣者成就相应的功德，以及受持这殊胜真实之定，我已经供养了那位比丘，愿以这福善得以成佛。

“‘如同香气芬芳非常可爱，随顺时节的香胜过栴檀，美妙的香气普遍熏染，无处不遍；持戒得定的人也是如此；

“‘犹如须弥山最为端严，遍照十方，特别可爱，光耀照彻地上以及虚空；持戒的法师也是如此。

“‘如果有人以清净深切的信乐，建立最殊胜美妙的宝塔，又有其他人来恭敬供养，就使造塔者的殊胜福德更加增长；

“‘说法的法师也是如此，我以清净之心使他得以安稳，割舍自身新鲜的血肉，我现在已经建造了正法之塔。

“‘如果有塔庙将要倒塌，智者扶持它使它不倾动，又有人来供养这塔，就能使扶持者获得殊胜的福德；

“‘比丘这位知法者，也如同塔一样，我以良药除去他的病患；他能演说殊胜微妙之法，把众生安置在无上之道上。

“‘法师比丘如果死去，这法又怎能得以听闻呢？父王应当知道，比丘如果丧亡，就会失去这个三摩地。

“‘法师也如同清净美妙的明灯，疗治众生烦恼的黑暗，安住于广大的三摩地，救济恶道中的一切众生。

“‘比丘所行不可测度，恒常安住于广大之心，对于决定的句义已经善学，一切邪恶的异论都不能破坏。

“‘我在无量亿劫之中，永远不再承受女人之身；如佛所说的至上敬法，我对法师已经作了恭敬。’

“（世尊说：）如果有人以恒河沙数的佛世界，满中宝物奉献如来；另有人以清净之心施舍一足、一指，这福德比前者最为殊胜。

“这样的女人死后，便得以见到千亿尊佛，在那些佛那里都得以出家，受持这殊胜的三昧。

“在诸位两足尊佛那里，以及他们般涅槃的最后时刻，她一切时常常出家，作清净无染的佛子。

“她也在燃灯如来那里，在那位佛的法中修行梵行；我那时得以转变女身，作为大法师宣说殊胜之法。

```
智力王者弥勒是　恒常勇猛护持法
法师即是然灯佛　昔王女者我身是
能舍身肉无顾吝　供养功德自在者
恒常远离谄曲心　为求如是三昧故
```

“大意是：那位智力王就是弥勒菩萨，恒常勇猛地护持佛法；实意法师就是然灯佛；往昔的王女就是我（释迦牟尼佛）的前身。我能舍弃身肉而毫无顾惜，供养具足功德的自在者，恒常远离谄曲之心，都是为了求得这个三昧的缘故。

“见到那位比丘被病苦逼迫时，当时所有为他啼泣的人，一切都获得不退转之地，究竟永远离开一切恶趣。

“那些人不再被种种苦恼逼迫，也远离了谤法以及病苦，五根具足而不残缺，心中也没有种种忧愁之刺，

“一切都端严殊妙，功德与威神常常炽盛，以百福庄严的三十二相，都是由于护念供养病人的缘故。

“他们在我的法中都出了家；在以后的末世之时，如果能受持我的正法藏，他们将得以见到千亿尊佛。

“受持恭敬我的法的人，就是摄持了菩提的种子，能广泛利益一切众生，将得以见到阿閦佛。

“听闻我所行的殊胜菩提之行，便能获得圣者所爱，以一切本生的庄严之事，奉献殊胜的供养给诸如来。

“见到多闻、持守禁戒的比丘，以清净之心奉事他，又能远离一切嗔恚与傲慢，这恒常是最殊胜的大福德；

“迅速远离一切嗔慢之后，供养护持佛法的我的儿子，在无量亿劫中远离黑暗，终究不会坠入恶道之苦。

“怀有诤斗之心的人，必定堕入恶趣；即使他持守禁戒以及多闻，供养诸佛，广行布施，住阿兰若修禅定等，都不能救护他。”

【按】这一本生的核心，是“不顾身命护持持三昧的法师”与“恒离谄曲心”。末句尤为警策：诤心一起，持戒、多闻、布施、禅修都救不了。对修心者而言，这是最实际的提醒。

## 四、阿难问：菩萨为何遭截手足之苦

这时，长老阿难从座起身，偏袒右肩，右膝着地，合掌向佛这样说：“世尊！我想向如来、应供、正遍知稍作请问，愿佛允许，随我所问而为宣说。”

这时，佛告诉阿难：“你回到本座，如来、应供、正遍知任你发问，我为你宣说，使你心生欢喜。”

这时，长老阿难禀白佛说：“世尊！唯然受教，善逝！唯然受教，世尊！”已经蒙佛允许，阿难便轻咳一声，这样说：“世尊！是什么因缘，其他的一些菩萨修行菩萨行时，遭遇被截断手足以及耳鼻，或被挖去双目，割截身体，对于种种苦都能忍受，而不从无上正等正觉退转？”

问了之后，佛说：“阿难！你如果知道我为了无上正等正觉而备受的种种苦，你尚且不堪起意想说，更何况能发问？阿难！假使有一个人从脚到头熊熊燃烧着火焰，又有另外一个人走到他那里，这样说：‘丈夫，过来吧！就以这燃烧不灭之身，与五欲相合，随意享受歌舞嬉戏之乐。’”

佛说：“阿难！你认为如何？这个人身上的火还没有熄灭，能随意享受歌舞嬉笑的五欲之乐吗？”

阿难禀白佛说：“不能，世尊！”

佛说：“阿难！这个人身上的火没有熄灭，或许还可能享受五欲之乐、歌舞喜戏；如来却不是这样，往昔修行菩萨行时，见到三恶道中受苦的众生以及种种贫苦之人，始终没有喜悦快乐。

【按】这个比喻极其深切：菩萨见众生受苦，犹如自身着火，怎能安享五欲？这就是大悲心的真实样子，也是认识空性之后，悲心不减反增的原因。

“阿难！过去的菩萨修行菩萨行时，如果成就不缺之戒、不穿之戒、无过尤之戒、不杂之戒、不执取之戒、不动摇之戒、不浑浊之戒、不毁坏之戒、不浅薄之戒、不显现异相之戒、不相违之戒、正直之戒、如所誓愿之戒、摄受众生之戒。阿难！这样成就诸戒的菩萨摩诃萨修行菩萨行，终究不会遭遇截手、断足、割耳、劓鼻、斩首、挖眼，其余身体部分也不会遭受种种苦，能迅速证得无上正等正觉。

【按】世尊的回答点出：菩萨受截手足之苦，与往昔戒行有缺相关；若具足清净戒，修菩萨行时就不会遭遇这些苦难。这再次显示本经对戒律的极度重视。

## 五、善花月法师的本生

“阿难！在过去阿僧祇阿僧祇劫，广大无量、不可思议、不可称、不可量、没有分齐的时候，那时有一尊佛，名号叫宝莲花月净起王佛、如来、应供、正遍知、明行足、善逝、世间解、无上士、调御丈夫、天人师、佛、世尊。阿难！那时宝莲花月净起王佛的寿命是九十九亿那由他百千劫，他在一切日月时中，使九十亿百千众生安住于佛法而不退转。

“阿难！那时宝莲花月净起王如来、应供、正遍知般涅槃之后，正法灭尽，在末法之中，对于这部修多罗，无量众生厌恶它，无量众生远离它，无量众生违背它，无量众生舍弃它。在大可怖畏之时、大厄难之时、不下雨之时、或雨水过多之时、非时降雨之时、饥荒之时、邪见炽盛之时、追求外道言论之时、恶兽夜叉横行之时、雷电霹雳之时、破坏佛菩提之时，有七千位菩萨从城邑、王都、村落人民之中走出，来到普贤林中，依止那里而住，与善花月法师在一起。那时那位比丘为那些大众宣说陀罗尼法门。

“阿难！这位善花月法师有一次独处静坐，以清净超过常人的天眼，看见多亿菩萨，他们已种下种种善根，从其他佛世界没去而来生此地。他想：‘他们如果得以听闻这陀罗尼法门，便能得到无上正等正觉的不退转；如果不得听闻这陀罗尼法门，就会退失无上正等正觉。’于是，善花月法师这样想过之后，就从三昧中起身，前往那些大菩萨众所在之处。到了那里之后，这样说道：‘善男子！我现在想要前往城邑村落，为众生演说法要。’

“那时，大菩萨众禀白善花月法师说：‘我们一切菩萨大众，都不愿仁者您离开这片林子，前往那些王都、城邑和村落。为什么呢？因为有无量我慢的比丘、比丘尼、优婆塞、优婆夷，在像法之时喜欢夺人性命。’

“那时，善花月法师对菩萨大众说：‘如果我护惜自己的身命，就不能护持过去、未来、现在诸佛的法了。’那时，法师就说偈道：

```
恒常不住于我想　乃能护持如来法
诸佛广大胜菩提　于恶世中能显示
若离一切取我想　亦离众生及寿命
于诸色声香味触　能速离者护佛法
```

“大意是：恒常不住于我想的人，才能护持如来之法；诸佛广大殊胜的菩提，他能在恶世之中显示出来。如果远离一切执取我想，也远离众生想与寿命想，对于色、声、香、味、触能够迅速远离执著，这样的人才能护持佛法。

【按】护法的资格不在于力量或地位，而在于“不住我想”。一个仍执著我的人，在恶世中必定护惜身命，也就护不了法。这与月光童子“舍身命护持此定”的誓愿是同一精神。

“‘如果有人供养百亿那由他的佛，以清净的信心施与美食，也施与灯、花鬘以及幡盖，经过恒河沙数多亿劫；

“‘如果有人在正法衰微的末世，佛法将要灭尽之时，在一日一夜中能护持佛法，这样的功德胜过前者。

“‘我作为人中的圣狮子，如果在正法灭时放置不护，就不能称为供养佛，也不能称为恭敬导师。

“‘你们安乐地自求利益，好好地守护自身，在正法与戒律中不要放逸，应当常常安住于修习慈心之行。

“‘护持正戒而不夹杂，清净皎洁而没有垢秽，这就是供养了一切佛，所有过去、现在的诸如来。

“‘施与殊胜的法宝，恒常修习忍辱，在寂静处修习禅定，善加调柔，远离一切斗诤，修行美妙之因，我要前往城邑去救度众生。’

“具大智慧的殊胜仙人将要下山的时候，大众有的悲泣，有的顶礼，说：‘愿您看看这些林树，香气可爱；智者啊，不要离去，救护我们吧。

“‘往昔的导师具足十力，诸根寂静，善加调柔，前往那山林闲寂之处，趣向无上殊胜的菩提；

“‘又能善行菩提之因，修集福德与智慧；您住在林中随顺而学习他吧，具大威德的圣者，愿您不要下山。

“‘您身上的相好特别微妙，头发绀青，非常可爱，皮肤光丽如同金色，光辉照耀大地，

“‘您眉间的白毫相特别可爱，犹如珂贝那样鲜白光亮；不要让别人生起妒嫉，国主、大臣或许会夺去您的性命。’

“阿难！那时，善花月法师就对那些菩萨大众说偈道：

“‘所有过去的诸如来，具足一切种智、诸漏已尽的人，都利益三有众生，而证得无上殊胜的菩提。

“‘他们为求菩提而修习殊胜之因，积集福德与智慧；我学习他们，所以常常修行，为的是救济众生的缘故。’

“大众都右绕这位具智慧的神仙，以头顶接足而恭敬礼拜，依恋瞻仰，叹息呼嗟，高声悲叫，都号哭哀切；有的从高处坠落，昏厥过去，犹如大树倒下一般。

“具福德的仙人并不因为大众的话而退转，为了利益一切众生，他手持衣钵准备辞去，犹如雄猛的狮子王，对得失毫不顾盼，因为他安住于法性的缘故。

“他说：‘不要让我停留在山林之中，损减众生的种种善根。’于是他就前往殊胜的城邑，为了利益众生的缘故。

## 六、善花月法师入城说法七日

“阿难！那时，善花月法师就前往城邑村落，为众生应机说法。

“这位比丘在清晨时，使九亿众生对于无上正等正觉住于不退转；然后依次游行到那珍宝王城，坐在毕钵罗树下。那时那位比丘坐了一夜到天明，进入城内，使三十六亿众生在佛法中得以住于不退转。

“那时，比丘一天没有进食；没有进食之后，就出了王城，前往佛爪塔所，一日一夜伫立恭敬。那位比丘到了第二天早晨，仍然没有进食，又进入珍宝王城，使二十三亿众生安住于佛法而得不退转。

“第二天没有进食之后，他又出王城，前往佛爪塔所，日夜伫立；夜尽之后到了清晨。到第三天仍然没有进食，又进入王城，安置九亿百千众生于佛法中住于不退转。

“第三天没有进食之后，又出王城到佛爪塔所，日夜伫立，夜尽天明。到第四天仍然没有进食，又进入那珍宝王城，安置九十百千众生住于佛法而不退转。

“第四天断食之后出城，前往佛爪塔所，日夜伫立，夜尽到天亮。到第五天仍然没有进食，又进入王城，安置一切大王宫内以及那城邑村落的人民于佛法中，使他们不退转。

“第五天没有进食之后，又出王城前往佛爪塔所，日夜伫立，夜尽天明。到第六天仍然没有进食，使国王的一千个儿子对于无上正等正觉住于不退转。

“第六天没有进食之后，又出那珍宝王城，前往佛爪塔所，在那一日一夜中伫立恭敬，夜尽天明。到第七天仍然没有进食，来到王城的城门。

## 七、勇健得王的嫉妒

“那时，有一位国王名叫勇健得。那时国王从后宫出来，登上金车：白银的栏楯，以殊胜美妙的栴檀作为车辕，以毗琉璃作为车轮，上面张设幡盖，以宝幢装饰，宝树庄严排列，种种缯彩罗网遍覆车上，垂挂着种种绢帛；有八百名童女手执宝绳牵引宝车，那些童女端正，具足种种美妙的容色，愚人对此爱乐，有智慧的人则不然。有八万四千刹帝利豪族侍卫在后，又有八万四千婆罗门豪族以及八万四千长者豪族都侍从着，也有五百名宫女登上种种宝饰的车舆走在国王之前。

“那些童女同时见到这位比丘，就对于无上正等正觉获得不退转；六百八十万宫人都见到这位比丘，也都对于无上正等正觉得到不退转。那时，众人都脱下璎珞以及宝饰的鞋子，偏袒右肩，右膝着地，都合掌向那位比丘作礼恭敬，站在他的面前。

“那时，那些女人由于宿世所种善根的熏习资助，就走下宝舆，偏袒右肩，整理衣服，右膝着地，合掌敬礼那位比丘之后，说偈道：

“‘今天威光遍照这珍宝王都城，由于这位比丘入城的缘故，众人都各自住立瞻仰。

“‘他断除了一切爱欲的过失，也远离了嗔恚以及愚痴、嫉妒、妄想、种种结缚，一切都能灭尽。’

“这时勇健得大王，正当出游的时候却无人观看他，他的儿子们以及其余眷属，都没有跟随国王的。

“比丘处在那大王的大众之中，端严殊特，无与伦比，犹如十五日的圆满之月，被一切众星所围绕。

“他的身体如同庄严的真金像，又加上工匠的磨莹装饰；犹如树王上妙花开敷，比丘的端严也是这样；

“又如具大威德的帝释、千眼天主游行升空，须弥山顶的忉利天王，比丘入城的美妙也是如此；

“譬如梵王处在梵众之中，又似化乐天之主，欲界夜摩天王非常端严，比丘入城的美妙也是如此；

“如同太阳照耀于虚空，千种光焰除去幽暗，遍照一切十方，比丘入城的美妙也是如此。

“他无量劫以来广行布施，恒常护持戒律而没有秽杂，修习忍辱世间无与伦比，所以以相好庄严身体，如此美妙；

“能生起圣者所赞叹的精进，以勇猛殊胜之心修习四禅，生起智慧而断除烦恼之网，所以比丘照耀世间。

“佛雄无比，是人中最上者，过去已经降下殊胜的法雨，未来、现在也是如此，他是那位法王真正的儿子。

“（女人们说：）‘愿这位比丘常常没有变异，他的容色光照一切世间；见到您的威德、听到您的声音，就映蔽了国王的威势，再也看不见了。

“‘您自己亲身证得佛法，受持奉行佛的教导而游行世间；我们愿意舍弃这女身，也将会像那位比丘一样。’

“那些女人都合掌说偈，散布庄严身体的饰物：殊胜美妙的金鬘、珠宝璎珞、耳环以及颈上的金锁。

“‘他的威势如同转轮王观察大地，游行四天下而生起视众生如子之想；对于国王、刹帝利、四姓等，他平等用心而没有憎爱。

“‘比丘已经修学了陀罗尼，分别了根、力、觉支与正道；犹如那满月处在众星之中，也如日轮的光明照耀。

“‘归命具足十力的调伏者，即使有人在百劫中赞叹也赞不尽，在无量千亿多劫中宣说，也不能说尽他一根毛发的功德。

“‘他转动法轮的智慧之句，是微细无垢、难以得见之法；沙门、魔、梵、婆罗门，都敬礼这位医王（佛）无比的儿子。’

“女人们说完偈颂都欢喜，在地上散布珠宝黄金，铺上美妙的衣服，把价值百亿的髻珠和璎珞施给那位比丘，为求菩提。

“那时，勇健得王这样想：‘这些宫人的心都变了，背叛了我。怎么知道呢？她们都脱下了臂钏与珠宝璎珞，偏袒右肩，右膝着地，向这位比丘合掌作礼。’那时勇健王见善花月容貌端正，自己看看自己的形貌比不上比丘，随即惊恐，怕他夺取王位，生起极大的嗔怒。

“那时那位比丘站在王道上，风吹尘土进了眼睛，他眨动眼睑。那时勇健王这样想：‘这比丘以染污之心贪著我的宫人，在眨眼约会。谁能杀了这比丘？’那时，勇健得王有一千个儿子侍从在后面，他便诏令儿子们说：‘你们现在去断了这比丘的命。’

“国王的一千个儿子因为敬重比丘的缘故，不接受国王的命令。国王这样想：‘儿子们尚且不接受我的命令，我现在孤单一人而没有帮手，谁还能杀这比丘呢？’那时勇健王有一个旃陀罗（刽子手），名叫难提，常常让他去杀戮，他狠毒凶暴，毫无顾惜。国王见到难提，欢喜踊跃：‘他必定能为我杀这比丘。’随即下令召唤。那时难提就来到国王那里。国王对他说：‘你现在能杀这比丘吗？如果能杀，必当重重封赏。’难提说：‘是的，大王！我遵奉命令。随大王所派遣，我能杀他，就在今天断他的命。’国王告诉难提：‘你应当知道现在正是时候，应当拿着利刀截断那比丘的手、足、耳、鼻；因为他以染心看我的宫人，应当用铁钩挖出他的眼睛。’那时，难提就接受国王的命令，手执利刀，割截了比丘的手、足、耳、鼻，并挖出了双眼。

【按】善花月法师的本生，是《三摩地王经》中最为人知的故事之一，藏传诸师常引以说明忍辱与护法者不惜身命。法师一身清净，只因一个揉眼的动作，便被嫉妒的国王处以极刑。这正说明：嫉妒与嗔心一起，无辜者也被看成罪人，这是嗔心颠倒的可怕。

## 八、国王的悔恨

“国王杀了比丘之后，随即前往园林；那时众人悲号懊恼，又回到珍宝王城。

“那时，勇健王在园苑中七日，心中没有喜悦快乐，完全不喜嬉戏，也不娱乐。七日过后，从园林出来，回到城中，在王道上看见这位比丘死后已经过了七天，尸体被弃置在路上，七日之中形色毫无变化。那时，勇健王便这样想：‘比丘死后已经过了七天，身色没有改变，他对于无上正等正觉必定已得不退转，这毫无疑问；我造了恶业，必定堕入地狱，不久就要受苦。’

“正这样想的时候，有八万四千诸天在空中一时同声说：‘是这样的，大王！正如你所想、如你所说，这位比丘确实是于无上正等正觉不退转的人。’国王听到这话，惊怖战栗，身毛都竖立起来，心中生起悔恨。

“那时，勇健得王忧愁苦恼，心中悔恨之后，说偈道：

“‘我要舍弃王位以及城邑、金、银、真珠、摩尼宝；我这愚痴无智、造作恶业的人，要拿利刀自杀。

“‘往昔的善花月法师，以三十二相庄严，进入王城，光明普照，犹如满月这星中之王。

“‘我被爱欲所迷惑扰乱，宫女围绕着出城游玩，登上宝车，有刹帝利随从，那位端正妙眼的人来到这里。

“‘宫女们见到比丘都欣喜，都以欢喜之心散布金鬘，一切女人都合掌，说偈歌颂赞叹那位比丘。

“‘我那时娱乐出游，刹帝利围绕，乘坐宝车，遇到了那位端正妙眼的人，他是具大威德的如来之子。

“‘我那时见到他生起恶意，嫉妒、嗔恚，生起加害之心，因为见到比丘进入王城，众女见到他都欣喜的缘故。

“‘他的光明遍照四方，如同月亮从阿修罗口中脱出；众人都发出大声，宫女见到他都欢喜。

“‘我往昔说出粗恶的话，普遍命令我的一千个儿子：“快杀了这比丘，把他截成数段，这是我的大怨家。”

“‘一切王子都持守戒律，怜悯爱念这位法师，都不接受我的命令，我那时心中怀着极大的忧恼。

“‘我见到这位比丘持守清净的戒律，与智慧相应，如同慈父，我那时以嗔心派人去杀他，没有考虑阿鼻地狱以及日后的悔恨。

“‘那时见到难提站在王道上，他狠毒地加害于人，使人受苦，我以恶言命令他：“把这比丘截断，像截断花鬘一样。”

“‘普贤林那地方非常端妙，众多仙人聚集，香气芬芳；那里的大众失去了法师，犹如独子失去了母亲。

“‘比丘啊，请您起来回到普贤林去，以广泛利益众人；您如今既然进入了这王城，那里的大众将会大为悲泣。

“‘美妙的花与幢幡排列在右边，左边也同样端严，以种种美妙的衣服铺在道路上，比丘请快快起来宣说妙法。

“‘您进入王城已经很久了，那里的大众必定大为悲哀；在那佛法尚未灭尽之时，愿不让您的命根断绝。

“‘假使有人具大威神，广大的名声流布于各方，具足能转动大地的势力，全都映蔽三千大千世界，解脱苦箭，远离忧患，得到与圣者欢喜相应之法，他如果见闻这件事尚且会生起苦恼，何况一般世间之人不会惊惶迷乱呢？

“‘花月法师犹如山王，以三十二相庄严，就像众女争抢花鬘一样，顷刻之间被截成数段。

“‘我造作了极重的不善业，将堕入那阿鼻地狱而没有谁能救我，与诸佛极其遥远，因为割截了比丘的缘故。

“‘不是儿子和亲属能救我，辅相、诸贵人以及僮仆也不能；我既然造作了深重的恶业，这些人都不能救我。

“‘过去、未来的一切佛，以及现在十方的诸佛，具足十力、远离烦恼的导师，心如金刚，我归依他们。’

## 九、普贤林大众的哀悼

“诸天见到那位比丘被截成数段，都悲泣号叫，前往告诉那些菩萨大众：‘花月比丘被国王杀了。

“‘那位聪明利智的法师，具大威德，名声遍闻，安住于陀罗尼的菩萨，现在在王城中被杀了；

“‘那位经过无量劫广行布施、护持戒律不动而没有秽杂、能修忍辱无与伦比的人，现在在王城中被杀了；

“‘那位无量劫来常常精进、以增上殊胜之心修习四禅、生起智慧能断烦恼的人，现在在王城中被杀了；

“‘那位舍弃了一切对身体的贪爱、也不顾恋自己寿命、从普贤林中出来的人，现在在王城中被杀了。’

“那林中的大众进入王城，高声悲叫，都号哭哭泣，见到这位比丘的身体成为数段，一切人都昏厥倒地。这些比丘启白国王说：‘大王！法师有什么过失呢？

“‘他持戒无缺，具有大名称，能了知宿世无边的事；他对于总持得到究竟，善解世间全都空寂，为众生显示无相，舍弃一切愿求之想；

“‘他演说微妙可爱的声音，诸根寂静，善加调柔，了达过去宿世之事，超出一切世间；

“‘他将会成佛，得到自然智，在那世间最为稀有；他清净的眼睛明见而无暗障，这就是慈心所照耀的。

“‘贪爱淫欲非常鄙秽，能生苦恼，丧失生天之趣；习惯贪欲的人远离多闻，被称为损减智慧的人；

“‘耽著爱欲的人如同盲人，便能伤害父母，也能伤害持戒的人，所以应当舍弃贪欲。

“‘大王如果习于爱欲，便会失去威德与殊胜的自在，趣向极恶的地狱之中，生在大怖畏、极苦之处。

“‘杀害聪慧殊胜的法师，造作这样深重的恶业；如果想要立志求取菩提，就应当远离这样的恶行。’

## 十、法师的功德与菩萨总持

“（大众又赞叹法师说：）他对于殊胜美妙的色、声、香、味、触，心中勇猛，能够舍弃；了知身与意都空如幻化，眼、耳、鼻、舌也是如此。

“他修习布施、持戒无与伦比，忍辱、精进也是如此，已经到达禅定与智慧的彼岸，堪能利益众生。

“一切世间的诸天与人，能以慈心观察如来，他们的眼睛能除去大黑暗，悟解最殊胜的无上菩提。

“他以欢喜信心施舍楼阁、象、马、车乘以及床褥、一切辇舆、牛、羊等、国界、城邑、诸村落，舍弃王位以及金、银、真珠、颇梨和珊瑚，头、目、妻子都能施舍，为了求取无上菩提的缘故。

“他欢喜地作无与伦比的供养，美妙的花、涂香以及末香、种种幡、殊胜的幢盖、美妙的歌声与种种伎乐。

“他在诸有之中远离愿求之想，因为了知三界都是空的缘故，所以以十力的相好庄严，光明遍照于十方。

“对于色界、欲界都不执著，对于无色界也是如此；如果安住于菩萨总持的人，就能脱离三界，如同蛇蜕去旧皮；

“没有我想、众生想，也没有男想与女想，他修行梵行而没有秽杂，因为菩萨安住于总持的缘故；

“有事、无事之想都没有，安与不安之想也是如此，非非数想与非数想都没有，因为安住于菩萨总持的缘故；

```
非有有想悉皆无　非有命想众生想
非有村想及城想　菩萨安住总持故
非非贪想非贪想　非非瞋想无瞋想
非非痴想非痴想　以住菩萨总持故
```

“大意是：非有之想与有之想全都没有，没有寿命之想、众生之想，没有村庄之想以及城市之想，因为菩萨安住于总持的缘故。既没有‘非非贪’之想，也没有‘非贪’之想；既没有‘非非嗔’之想，也没有‘无嗔’之想；既没有‘非非痴’之想，也没有‘非痴’之想，因为安住于菩萨总持的缘故。

【按】这里的“总持”已不是记诵的能力，而是安住于离一切想的心性。值得注意的是：不但没有贪想，连“非贪”之想、乃至“非非贪”之想也没有。离贪而不执“离贪”，这正是离戏的精细处。修心者常在断烦恼之后又执著“我已无烦恼”，此偈正破此执。

“对于诸根以及诸力、禅定、道品都不执著，都能舍弃三有，因为菩萨安住于总持的缘故。

“不被贪、嗔所染，也没有愚痴散乱、谄曲之心，见到具足十力的佛就设置供养，智者并不希求生在天上。

“从他人那里听闻甚深微妙之法，不生起一切疑惑，譬如器皿盛装清净的油（满而不溢），尽与无尽之相的道理也是如此。

```
正以贪恋故生爱　此则名为大烦恼
亦以瞋嫌故起憎　斯则名为恶怨怖
智者远离此二边　是谓能趣胜菩提
```

“大意是：正是因为贪恋而生起爱著，这称为大烦恼；也因为嗔嫌而生起憎恶，这称为可怕的怨敌。智者远离爱与憎这两边，这就是能趣向殊胜菩提的人。

“他得以成为具足十力的人中牛王，超出一切世间。

“他舍弃一切内外之事，安住于实际法性之中，护持禁戒，善加清净，无穿漏、无缺损、无秽浊。

“他对于清净的戒律毫无间杂，也没有（需要忏悔的）羯磨之法；智者舍弃了二边，能悟入无上的大菩提。”

《月灯三昧经》卷第八终
