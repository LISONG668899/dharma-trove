# 境之实相修习

宝洲阿阇黎乐金刚造　据藏文译出

## 题解

《境之实相修习》（藏 dngos po'i gnas lugs bsgom pa，直译"事物之实相的修习"）收于德格版丹珠尔续部释 ཞི 函第 206b 至 211b 页（东北目录 D2294），紧接在牟尼施的《行歌藏释》（D2293）之后。跋文说是"宝洲（ནོར་བུ་གླིང་པ）的阿阇黎乐金刚（བདེ་བའི་རྡོ་རྗེ，梵 Sukhavajra）所作"；作者生平与"宝洲"所指都不详，本篇也没有译者跋语。

**结构：**全篇分两大部分。前一部分是散文，依"四手印"次第讲修法：业手印、法手印、三昧耶手印（本篇以四种拙火修法来说明）、大手印（以"九印"印持一切器世间与有情）。后一部分是长篇偈颂，反复阐明以大乐空性"印持"一切显现的大手印见修：心如光明大海中的波浪、无修而修、现量是对治之王、以见摄七支供、囚徒之喻、"印持"的定义、四喜与止观的分别、乐如浪起于光明大海等。接着有一大段讲空性与悲心、念众生恩、二乘终归大乘的偈颂（第二十五至三十节），内容与龙树《菩提心释》非常相近，很可能是引文。最后以点金药之喻、"室利嘿汝嘎"四字的解释和结颂收尾。

**本篇的要点：**本篇最核心的概念是"印持"（རྒྱས་གདབ）。作者特别说明：仅仅体验到乐或无分别，若不以大乐空性来"印持"，就没有菩提；所谓"印持"，是不仅了知所缘之境如幻，而且现量了知自己的体验也如幻。以推理成立"乐是空"，仍属比量，不是真正的大乐。

**关于"不修对治""不思善恶"等说法：**本篇有多处说"不必修对治""对善与恶都不思维""虽无因果""做了一切也能解脱"，这些都是就已现证心性光明者的境界而说的。本篇第二十七节自己明说："了知诸法是空，却仍然依止业果，这比稀奇更稀奇。"读者应以此为准，不可把这些句子理解为可以舍弃业果、放纵烦恼。

**关于密乘内容的告诫：**本篇第二、四、十六、十九节等涉及业手印、拙火、脉、风、明点的修法。这些都属于无上瑜伽续圆满次第的隐秘修持，只能在具德上师座前，依具足的灌顶与口授，在严格的誓言戒律中修习；绝不可依文字自行理解或练习。原文第 10–12 句列举业手印的年岁，其中有未满十八岁者，依本译体例略去不译，另附的藏文底本相应各句也只标"［略］"。

**与已译各篇的关系：**本篇与已译的《所缘修习》（D2277）等篇不重复。第三十四节"室利嘿汝嘎"四字的解释，是《喜金刚》系统续释中通行的说法。

**体例说明：**各节标题后括号中的句号，对应另附的《境之实相修习_藏文底本.txt》中的编号。偈颂原文放在代码框中，其后按完整的意义单元译出；按语中凡标"存疑"的，表示本译对原文意思没有把握。

## 四、三昧耶手印：四种拙火（第 49–58 句）

```

```


其中第一种是：观想从阴毛际到脐间有一盏八指［长］的灯，并对下行之道作开合。

```
གཉིས་པ་མར་མེ་གསོ་བ་ནི་སྤུ་མཚམས་ནས་ལྟེ་བར་ཕྱིན་པས་ལྟེ་བའི་བྱང་ཆུབ་ཀྱི་སེམས་འཛག་པས་གསོ་བའོ། །
```

第二种"添灯"是：［火］从阴毛际上到脐间，脐间的菩提心滴落，以此来添［灯］。

```
གསུམ་པ་ནི་ཨ་ཝ་དྷཱུ་ཏཱི་སྲུབ་ཤིང་ལ་ལ་ནཱ་དང་ར་ས་ནཱ་ལྟེ་བ་ཁྲག་གི་ཐིག་ལེ་ལས་མེ་འབར་བས་སྙིང་གའི་བྱང་ཆུབ་ཀྱི་སེམས་ཞུ་ནས་བདེ་བ་ཆེན་པོ་བསྒོམ་མོ། །
```

第三种是：以中脉为钻木，［以］左脉与右脉［为钻木的绳］；从脐间血之明点燃起火，使心间的菩提心融化，修习大乐。

```
བཞི་པ་བ་སྤུའི་བུ་ག་ནི་ལྟེ་བའི་དབུས་སུ་བུ་ག་ཕྲ་མོ་འཁྱིལ་བ་བསྒོམས་ལ་སྟེང་གི་རླུང་མནན་པར་བྱའོ། །
```

第四种"毛孔之孔"是：在脐的中央，观想一个细小盘绕的孔，并压住上方之风。

【按】"三昧耶手印"在其他论典中多指本尊身的观修，本篇则以四种拙火修法来说明，这里依原文译出。"下行之道"，原文 བཤང་བའི་ལམ，指下身的排泄之道。"左脉与右脉"，原文作 ལ་ལ་ནཱ（腊腊那）与 ར་ས་ནཱ（惹萨那）。第三种中左右二脉如何配合"钻木"，原文语句简略，这里依钻木取火的譬喻补译，存疑。这四种都是涉及风息、脉道与明点的实修方法，必须在具德上师亲自指导下依口授修习，不可依文字自行练习，否则有损身心。

```
རྣམ་པར་ཤེས་པ་རྟོག་པ་ཡིན་ཏེ།
ནམ་མཁའ་མི་རྟོག་པ་ལ་ཐིམ་པས་ན།
ནམ་མཁའ་སྟོང་པ་ལྟ་བུའི་རྟགས་འབྱུང་ངོ་། །
```

这样具足修习时，地融入水，就看见如烟［的相］；水融入火，就看见如阳焰［的相］；火融入风，就出现看见如萤火虫［的相］；风融入识，就出现如虚空［的相］；识就是分别，由于它融入无分别的虚空，所以出现如同虚空般空无的征相。

【按】这是圆满次第中诸大种次第融入、依次出现烟、阳焰、萤火等征相的说法，与临终次第融入的说法相通。

## 六、大手印的修习：九印（第 66–79 句）

```
དེ་ལ་ཕྱག་རྒྱ་ཆེན་པོ་བསྒོམ་པ་ནི།
རྒྱ་དགུས་གདབ་པར་བྱའོ། །
```

```
གཟུང་བ་མེད་དེ་རང་གི་སྣང་བ་ཡིན་པས་རྣམ་པར་སྣང་མཛད་ཀྱི་རྒྱས་བཏབ་བའི་བདེ་བ་ཆེན་པོ་དང་།
```

```
འཛིན་པ་བདེ་བ་ཆེན་པོའི་རང་བཞིན་ཡིན་པས་མི་བསྐྱོད་པའི་རྒྱས་བཏབ་པ་དང་།
```

```
སེམས་རང་རིག་གཉིས་སུ་མེད་པར་ཡང་མི་བསམ་སྟེ།
བདེ་བ་ཆེན་པོ་ལྷུན་གྱིས་གྲུབ་པ་བསམ་གྱིས་མི་ཁྱབ་པ་ཡིན་པས།
རྡོ་རྗེ་སེམས་དཔའི་རྒྱས་བཏབ་པ་དང་།
```

对于心的自证，也不思维为"无二"，因为大乐任运成就、不可思议——以金刚萨埵来印持；

```
བསྒོམ་པར་བྱ་བ་དང་།
སྒོམ་པར་བྱེད་པ་དང་།
སྒོམ་པ་པོ་རོ་གཅིག་པ་གཉིས་སུ་མེད་པའི་རྒྱས་གདབ་པ་དང་།
```

所修、能修与修者，一味无二——以此来印持；

```
སྦྱོར་བ་དང་དངོས་གཞི་དང་རྗེས་རོ་གཅིག་པར་རོ་མཉམ་པའི་བདེ་བ་ཆེན་པོས་རྒྱས་གདབ་པ་དང་།
```

加行、正行与后行，成为一味——以平等一味的大乐来印持；

```
འཁོར་བ་དང་མྱ་ངན་ལས་འདས་པ་གཉིས་འོད་གསལ་བའི་ངང་དུ་རྒྱས་གདབ་པ་དང་།
```

轮回与涅槃二者，在光明的境界中印持；

```
སྣོད་ཀྱི་འཇིག་རྟེན་དང་བཅུད་ཀྱི་སེམས་ཅན་བརྟན་པ་དང་གཡོ་བ་རྣམས་ཧེ་རུ་ཀ་ལ་རོལ་པས་རྒྱས་གདབ་པའོ། །
```

器世间与其中有情众生、稳固的与动摇的，以嘿汝嘎的游戏来印持。

```
དེ་ལྟར་རྒྱས་དགུས་སྣོད་བཅུད་ཀུན་བདེ་སྟོང་གཉིས་ཀྱིས་རྒྱས་གདབ།
```

这样，以九印把一切器世间与有情，都以乐与空二者来印持。

【按】"印持"（རྒྱས་གདབ），是密续中以某一佛部或某一法义"盖印"，表示一切法都摄入其中、不出其外。原文说"九印"，但这里实际列出的只有七种，可能有脱文，或者计数的方法不同，存疑。

## 七、偈颂：心如大海起波，修无可修（第 80–101 句）

```
སེམས་ནི་འོད་གསལ་རྒྱ་མཚོ་ལས། །
གློ་བུར་དབའ་རླབས་ཚུལ་དུ་བརྟག །
སེམས་ནི་ནམ་མཁའ་སྟོང་པ་ལས། །
གློ་བུར་སྤྲིན་གྱི་ཚུལ་དུ་བརྟག །
```

要观察：心，［就像］从光明的大海中，突然出现波浪那样；要观察：心，［就像］从空的虚空中，突然出现云那样。

```
བསྒོམ་དུ་མེད་པ་ལྷུན་གྲུབ་བསྒོམ། །
རྟོག་པའི་དྲ་བ་ངང་གིས་སྟོང་། །
མངོན་སུམ་ཚད་མས་མཐོང་བ་ཉིད། །
ཤེས་བྱ་རྣལ་མ་ཡིན་པར་གསལ། །
```

修那无可修的任运成就，分别之网自然就空了；以现量所见到的，所知就明现为不是［本来］真实的。

```
རྟོག་པ་ཐམས་ཅད་འགོག་པ་དང་། །
མི་རྟོག་ཡེ་ཤེས་ངང་ལ་གཞག །
```

灭除一切分别，安住于无分别智慧的境界中。

```
བསྒོམ་དུ་མེད་པ་བསྒོམ་པ་ཡིན། །
ལྷུན་གྱིས་གྲུབ་པ་བསྒོམ་པ་ཡིན། །
```

修那无可修的，就是修；修那任运成就的，就是修。

```
རྣམ་པར་རྟོག་པ་མེད་པ་ལ། །
རྣམ་རྟོག་མེད་པའི་སྒྲོ་མི་གདགས། །
```

对于无分别，不要增益"［这是］无分别"；

```
དངོས་པོ་གདོད་ནས་གཉིས་མེད་ལ། །
གཉིས་མེད་ཅེས་བྱ་བསམ་མི་བྱ། །
```

对于本来无二的事物，不要想"［这是］无二"；

```
བདེ་ཆེན་སྒྲོ་སྐུར་བྲལ་བ་ལ། །
བྲལ་ལོ་སྙམ་དུ་བསམས་ན་སྐྱོན། །
```

对于离开增益与损减的大乐，若想"［我已］离开了"，就是过失；

```
ཉམས་མྱོང་འོད་གསལ་དག་པ་ལ། །
དག་གོ་ཞེས་ཀྱང་རློམ་མི་བྱ། །
```

对于清净的觉受光明，也不要自许"［已］清净了"。

```
རློམ་སེམས་མེད་པ་གནས་པའི་ཚེ། །
རྟོག་པ་རང་གི་ངང་གིས་འགག །
```

当没有自许之心而安住时，分别就自然止息。

【按】"所知就明现为不是［本来］真实的"，原文 ཤེས་བྱ་རྣལ་མ་ཡིན་པར་གསལ，"རྣལ་མ"有"本然、真实"等义，这一句意思不很确定，存疑。

## 八、分别的自性即光明，现量是对治之王（第 102–127 句）

```
ཆོས་དང་གང་ཟག་བདག་མེད་ཅེས། །
རྟོག་པའི་ངོ་བོ་ཉིད་ཡིན་ཏེ། །
རྟོག་པའི་རང་བཞིན་འོད་གསལ་བར། །
ཤེས་ན་དེ་ཚེ་ཉིད་ན་འགགས། །
```

"法无我与人无我"，［这样的想法］也是分别的体性；若了知分别的自性是光明，在那时它就止息了。

```
གཉེན་པོའི་རྒྱལ་པོ་མངོན་སུམ་ཡིན། །
གཅིག་དང་དུ་བྲལ་གཏན་ཚིགས་རྣམས། །
འོད་གསལ་ཤེས་ན་དགོས་པ་མེད། །
```

对治之王，就是现量；［离］一与多等理由，若了知光明，就不需要了。

```
གླང་པོ་དངོས་སུ་རྙེད་གྱུར་ནས། །
གླང་པོའི་རྗེས་ནི་ཚོལ་བྱེད་དམ། །
```

已经真正找到了大象，还要去寻找大象的足迹吗？

```
བདེ་ཆེན་དེར་སྣང་མངོན་སུམ་ལ། །
ལུས་དང་རྗེས་དཔག་བཙལ་མི་དགོས། །
```

对于大乐如此显现的现量，不必再寻求经教与比量。

```
མྱོང་བ་དངོས་པོའི་གཤིས་ཡིན་པས། །
ཆད་པར་ལྟ་བའི་དོགས་པ་མེད། །
```

因为体验就是事物的本性，所以没有落入断见的担忧；

```
གང་ལ་དེའོ་མི་སེམས་པས། །
སྒྲོ་འདོགས་པ་ཡི་དོགས་པ་མེད། །
```

因为对任何［境］都不想"就是它"，所以没有增益的担忧；

```
སྣོད་བཅུད་བདེ་ཆེན་རྒྱས་གདབ་པས། །
ཉོན་མོངས་དགྲ་ལས་ལྡང་དོགས་མེད། །
```

因为以大乐印持器世间与有情，所以没有被烦恼之敌再度扰乱的担忧；

```
ལས་ལ་བྱེད་དོ་བྱའོ་ཞེས། །
དགེ་སྡིག་གང་ལའང་མི་སེམས་ཤིང་། །
རྨི་ལམ་ལས་ལ་ཁྱད་མེད་པས། །
ངན་སོང་གསུམ་གྱི་དོགས་པ་མེད། །
```

对于业，不想"在作""该作"，对善与恶都不思维，因为与梦中之业无别，所以没有［堕］三恶道的担忧。

```
གང་དང་གང་ལ་སེམས་པ་ན། །
བདེ་ཆེན་དེར་སྣང་ངོ་ཤེས་ན། །
གཉེན་པོ་གཞན་ཞིག་བཙལ་མི་དགོས། །
```

无论想到什么，若认识到那就是大乐的显现，就不必寻求别的对治。

```
བྱ་བ་བཏང་བའི་སེམས་ཉིད་ནི། །
ལྷུན་གྱིས་གྲུབ་པར་རྣམ་པར་གནས། །
```

舍弃了造作的心性，就安住于任运成就之中。

【按】"一与多等理由"，指中观以"离一多"等正理成立空性。"大象与象迹"的比喻，是大手印传统中常用的譬喻：见到本体，就不必再依推理去寻找。"经教与比量"，原文作 ལུས་དང་རྗེས་དཔག（身与比量），"身"字疑是 ལུང（经教）之误，这里依文意译作"经教"，存疑。"对善与恶都不思维……没有［堕］三恶道的担忧"，是就已现证大乐空性者的境界而说的，不是说初学者可以不顾善恶业果；本篇后文（第 404–407 句一段）也特别说到，了知诸法空性之后仍要依止业果。

## 九、真正的礼拜、供养、忏悔与随喜（第 128–142 句）

```
ཇི་ལྟར་ཆུ་ལ་ཆུ་གཞག་དང་། །
ཇི་ལྟར་མར་ལ་མར་བཞིན་དུ། །
རང་གིས་རང་གི་ཡེ་ཤེས་ནི། །
ལེགས་མཐོང་གང་ཡིན་འདི་ཕྱག་ཡིན། །
```

如同在水中注入水，如同在酥油中加入酥油，自己好好地见到自己的智慧——这就是礼拜；

```
དེ་ཉིད་གཉིས་མེད་མཆོད་པ་ཡིན། །
```

这就是无二的供养；

```
གཉེན་པོ་སྟོང་ཉིད་ལྟ་བ་འདི། །
སྡིག་པ་བཤགས་པའི་མཆོག་ཡིན་ཏེ། །
མེ་དང་གྲང་བའི་རེག་པ་བཞིན། །
བདེ་སྟོང་མངོན་སུམ་འདི་དང་འགལ། །
```

这对治——空性之见，是忏悔罪业中最殊胜的，就像火与冷的触感［不能并存］一样，［罪业］与这乐空现量相违。

```
རྗེས་སུ་ཡི་རང་ལ་སོགས་དང་། །
ཆོས་སྤྱོད་སྡོམ་པའི་ནང་ནས་ཀྱང་། །
དོན་དམ་བྱང་ཆུབ་སེམས་འདི་མཆོག །
སྟོང་ཉིད་མངོན་སུམ་མཐོང་སྟེ་མཆོག །
```

在随喜等［诸支］以及法行、律仪之中，这胜义菩提心是最殊胜的，因为现见空性，所以最殊胜。

```
དཀྱིལ་འཁོར་སྦྱིན་སྲེག་བཟླས་བརྗོད་ཀྱི། །
ནང་ན་བདེ་ཆེན་དཀྱིལ་འཁོར་མཆོག །
```

在坛城、火供、念诵之中，大乐坛城是最殊胜的。

【按】这一段把七支供（礼拜、供养、忏悔、随喜等）都摄入对心性的现见之中，是大手印传统中常见的"以见摄行"的说法。

## 十、一切显现都是大乐坛城（第 143–165 句）

```
གང་དང་གང་ལ་བློ་གཞག་པ། །
དེ་དང་དེ་ནི་བདེ་ཆེན་དུ། །
ཤེས་ན་མལ་ཆ་སྟན་དག་དང་། །
གཡོག་འཁོར་གཉེན་བཤེས་སྣང་བ་ཀུན། །
བདེ་ཆེན་ཤེས་པ་བསྒོམས་པས་ཆོག །
```

无论把心安放在何处，若了知那就是大乐，那么床铺、坐垫，以及仆从、眷属、亲友等一切显现，［只要］修习大乐之知就足够了。

```
སྣོད་ནི་གཞལ་ཡས་ཁང་ཡིན་ལ། །
བཅུད་ནི་ལྷ་དང་ལྷ་མོ་ཡིན། །
འགྲོ་བ་རིགས་དྲུག་བདེ་གཤེགས་དྲུག །
དམྱལ་བའི་འཇིག་རྟེན་བདེ་བ་ཅན། །
ཡི་དྭགས་དུད་འགྲོ་བདེ་ཆེན་གྱི། །
ངང་དུ་ཤེས་པ་ལྷ་ཡི་སྐུ། །
```

器世间就是无量宫，有情就是男女本尊；六道众生就是六位善逝，地狱世间就是极乐，饿鬼与畜生，在大乐的境界中被了知为本尊之身。

```
སེམས་ལ་བཀག་པ་མེད་པ་ཉིད། །
གཉེན་པོ་མཆོག་ཏུ་ཁོ་ཡིས་མཐོང་། །
```

对于心不加遮止，他见此为最殊胜的对治。

```
དཔེར་ན་རྨི་ལམ་གནས་སྐབས་ན། །
བདེ་དང་སྡུག་བསྔལ་སྣང་བ་ཀུན། །
སད་པར་གྱུར་པ་རོ་གཅིག་ལྟར། །
དེ་བཞིན་འཁོར་བའི་བདེ་སྡུག་ཀུན། །
སྐྱེ་མེད་ངང་དུ་མཉམ་པས་ན། །
རྣལ་འབྱོར་སེམས་ལ་བླང་དོར་མེད། །
```

譬如在梦中，苦与乐一切显现，醒来时都成为一味；同样，轮回中的一切苦乐，在无生的境界中都是平等的，所以瑜伽士的心中没有取舍。

```
དགྲ་སྡང་རྨི་ལམ་འདྲར་ཤེས་ནས། །
ཆགས་སྡང་གཉེན་པོ་བསྒོམ་མི་དགོས། །
```

了知仇敌与嗔恨都如梦一般，就不必修贪与嗔的对治；

```
སེམས་ཀྱི་རང་བཞིན་ཡོངས་ཤེས་ན། །
ཆོས་ཉིད་གཞན་དུ་བསྒོམ་མི་དགོས། །
```

若完全了知心的自性，就不必另外去修法性。

【按】"六道众生就是六位善逝"，是密续中把六道众生观为六部佛的清净观。"地狱世间就是极乐"（བདེ་བ་ཅན），这里"极乐"是"具乐"之意，也是阿弥陀佛净土的名称。

## 十一、不改造心性，大舍是最胜之修（第 166–176 句）

```
དུས་གསུམ་ཁམས་གསུམ་ཐ་སྙད་དུ། །
བེམས་པོ་གློ་བུར་ཡིན་ཤེས་ན། །
སེམས་ཀྱི་རང་བཞིན་བཅོས་མི་དགོས། །
```

若知三时与三界，在名言中都只是无情之物、都是突然出现的，就不必去改造心的自性。

```
སྐྱེ་འགག་ནམ་མཁའི་སྐྲ་ཤད་བཞིན། །
སྔ་ཕྱི་སྐྱེ་བས་སྟོང་པས་ན། །
མ་སྐྱེས་ཞེས་སུ་བསྒོམ་པ་མེད། །
```

生与灭，就像空中的毛发；前与后都空于生，所以没有［去］修"未生"这回事。

```
རྒྱལ་བའི་ཐུགས་གཞི་རྟོག་མེད་ལ། །
སྐྱེ་བ་མེད་པ་ཞེས་སུ་བསྒྲགས། །
```

胜者之意的基础——无分别，被宣说为"无生"。

```
གཉེན་པོ་སྤང་བྱ་དབྱེར་མེད་ཀྱི། །
དོན་ལ་བྱ་བཙལ་མེད་པ་ཉིད། །
བཏང་སྙོམས་ཆེན་པོ་བསྒོམ་པའི་མཆོག །
```

对于对治与所断无别的义理，无所作、无所求，就是修习大舍中最殊胜的。

【按】"无情之物"，原文 བེམས་པོ，指无心识的物质；这里说三时三界在名言中都是"无情之物、突然的"，意思是都不是心的本性，存疑。"大舍"（བཏང་སྙོམས་ཆེན་པོ），指不取不舍的平等安住，不是四无量心中一般的"舍"。

## 十二、囚徒之喻：放任而自然无分别（第 177–187 句）

```
དཔེར་ན་མི་འགའ་བཙོན་བྱས་ན། །
དེ་ལ་འབད་རྩོལ་གྱིས་འབྲོས་ལ། །
དེ་ཉིད་བཙོན་པར་གཏད་ནས་ནི། །
འབད་རྩོལ་མེད་པར་གནས་པ་བཞིན། །
```

譬如有人被囚禁，他便努力想要逃走；而一旦把他交付给牢狱，他就不再勉力而安住下来。

```
ཉོན་མོངས་འབད་པས་བཀག་ཀྱང་ནི། །
ཆེད་ཀར་འབྱུང་བར་འགྱུར་བ་ལ། །
དེ་ཉིད་བདག་ཉིད་ལྕགས་བཀྲོལ་ནས། །
ཡུལ་ལ་རང་དགའ་བཏང་ན་ནི། །
རང་གི་ངང་གིས་རྟོག་མེད་སྐྱེ། །
```

烦恼虽然用努力去遮止，却反而会特别生起；若把它自己的锁链解开，任它在境上自在而行，就会自然生起无分别。

```
དེས་ན་ཐབས་ལ་མཁས་པ་ཡིན། །
འབྲས་བུ་ལམ་དུ་བྱེད་པར་གསུངས། །
```

所以，这就是善巧方便，［经中］说为"以果为道"。

【按】这个比喻的意思是：越用力压制念头，念头越多；若不加遮止，任其自在，反而自然平息。这是大手印"松坦安住"的教授，需要在已认识心性的基础上修持，不是放纵烦恼。

## 十三、不必刻意修对治（第 188–213 句）

```
བླུན་པོ་ཡོད་མེད་སྡུག་བསྔལ་ཀྱང་། །
གདོད་ནས་སྐྱེ་བ་མ་མྱོང་ལ། །
མཁས་པ་འགག་པ་སེམས་ལ་མེད། །
ཆེད་ཀར་གཉེན་པོ་བསྒོམ་མི་དགོས། །
```

愚人［所执］的有、无与苦，也本来未曾生起；智者的心中没有［可］灭的，所以不必刻意去修对治。

```
རྣལ་འབྱོར་ནང་དུ་ཁ་བལྟས་ལ། །
སེམས་ལས་མ་གཏོགས་མྱོང་མེད་པས། །
སྣང་སྲིད་རྟག་དང་མི་རྟག་ལ། །
བཀག་པ་དང་ནི་སྒྲུབ་པ་མེད། །
```

瑜伽士向内观看，除了心之外，没有别的［可］体验，所以对于显有、常与无常，没有遮止，也没有成立。

```
སེམས་ཀྱང་ཡེ་ཤེས་ཡིན་ཤེས་ན། །
མྱ་ངན་འདས་པ་བསྟན་མི་དགོས། །
```

若了知心就是智慧，就不必再去显示涅槃。

```
གལ་ཏེ་ཆགས་སྡང་སྐྱེས་གྱུར་ཀྱང་། །
གཉེན་པོ་མི་སྡུག་བྱམས་སོགས་ནི། །
འགྲོ་བའི་སེམས་རྒྱུད་གཉིས་མི་འཆང་། །
```

即使生起了贪与嗔，不净观、慈心等对治，众生的心续也不能同时持有二者。

```
ཇི་ལྟར་སྤྲིན་ནི་སྣ་ཚོགས་དག །
ནམ་མཁའི་དབྱིངས་སུ་ཐིམ་པ་ལྟར། །
དངོས་པོ་འོད་གསལ་གློ་བུར་བཅས། །
ཕྱིས་ནི་རང་གི་ངང་འགགས་ན། །
གཉེན་པོ་དག་ནི་སུ་ལ་བསྒོམ། །
```

如同种种云朵融入虚空，事物是光明中突然出现的，之后又自然止息，那么对治又是对谁修呢？

```
མ་རིག་འཁྲུལ་པའི་བག་ཆགས་ཀྱིས། །
སེམས་ལ་སྨིག་རྒྱུ་བཞིན་སྣང་ན། །
མི་མཁས་སྨིག་རྒྱུ་འཆོས་པ་བཞིན། །
གཉེན་པོ་བསྒོམ་པ་ཀྱེ་རེ་མཚར། །
```

由于无明迷乱的习气，心中显现［种种］，如同阳焰；不明智的人像修整阳焰一样去修对治，真是稀奇！

```
སེམས་ཀྱི་རང་བཞིན་འོད་གསལ་བ། །
སྐྱེ་བ་ཉིད་ཀྱང་མི་བརྟན་ན། །
གློ་བུར་རྟག་པར་ག་ལ་འགྱུར། །
དེ་བས་གཉེན་པོ་མི་བསྒོམ་སྟེ། །
```

心的自性是光明，连生起本身都不稳固，突然出现的［烦恼］怎么会成为恒常？所以不修对治。

【按】"众生的心续也不能同时持有二者"，大意似是：一刹那心中不能同时有烦恼与对治，所以对治只是用一个念头去代替另一个念头，并非根本解脱，存疑。本段说"不修对治"，是就证悟心性光明者而说，不是说初学者可以舍弃对治的修法。

## 十四、不执相，不造作（第 214–222 句）

```
གཉེན་པོ་མེད་ཅིང་བསྒོམ་པའང་མེད། །
མཚན་མར་མི་འཛིན་རྣལ་འབྱོར་པ། །
འདི་དང་འདི་འགའ་སེམས་པ་མེད། །
```

没有对治，也没有修；不执著相的瑜伽士，不去想"这个""那个"。

```
འགྲིབ་པ་མེད་ཅིང་འགག་པ་མེད། །
འདུ་མི་བྱེད་པ་ནམ་མཁའ་འདྲ། །
```

无减、无灭，不造作，如同虚空。

```
འདུ་ཤེས་ལས་བྱུང་ཏིང་འཛིན་སྐྱོན། །
འདུ་མི་བྱེད་ཅེས་སེམས་པ་མེད། །
```

从想所生的三摩地是过失；［连］"不造作"［这个念头］也不去想。

```
མངོན་སུམ་རྟོག་བྲལ་རྒྱུན་བསྲིངས་ནས། །
བསྒོམས་སོ་ཞེས་སུ་ཐ་སྙད་འདོགས། །
```

使离开分别的现量之流延续下去，［只是］施设名言，说"修了"。

## 十五、勉强不分别反成障碍（第 223–237 句）

```
རྟོག་མེད་ཡེ་ནས་སྐྱེ་ན་ཡང་། །
སྒྲོ་འདོགས་སེལ་བ་བསྒོམ་པ་ཡིན། །
```

即使无分别本来就生起，断除增益，［才］是修。

```
བཅོས་མེད་རང་གསལ་མ་བྱས་ན། །
ནན་གྱིས་མི་རྟོག་བསྒོམས་གྱུར་ཀྱང་། །
མི་རྟོག་པ་ཉིད་སྒྲིབ་པའི་རྒྱུ། །
```

若不［安住于］无造作的自明，即使勉强修无分别，这无分别本身就是障碍之因；

```
དཔེར་ན་སྨན་ཉིད་མ་ཞུ་ན། །
ནད་ཀྱི་ནང་ན་དེ་ཉིད་ལྕི། །
```

譬如药物若不消化，在病中它反而更加沉重。

```
འབད་མེད་བསྒོམས་ལ་སྒྲོ་འདོགས་བཅད་ཅེས་བྱ། །
```

不勉力而修，就称为"断除增益"。

```
སྒྱུ་མ་ཆུ་ཟླ་བཞིན་དུ་ཤེས་མེད་ན། །
སྟོང་ཞེས་བརྗོད་པས་སེམས་ལ་ཡོངས་མི་འགྲོ། །
```

若不了知［一切］如幻、如水中月，即使口说"空"，也不能完全入心。

```
སེམས་ཀྱི་རང་བཞིན་སྣང་སྟོང་རྟོགས་ན་ནི། །
འགྲོ་བ་རྣམས་ལ་སྙིང་རྗེ་ངང་གིས་སྐྱེ། །
```

若证悟心的自性是显空［无二］，对众生的悲心就自然生起。

```
བདག་དང་གཞན་དག་དབྱེ་བ་མེད་པར་ཡང་། །
ཆུ་ཟླ་ལྟ་བུར་བློ་ནི་སྐྱེ་འགྱུར་ན། །
བདེ་བ་ཆེན་པོ་སྒོམ་ཞེས་དེ་ལ་བྱ། །
```

若对于自与他无别，也生起如水中月的觉知，那就称为"修大乐"。

【按】"药物若不消化，反而加重病情"，是比喻执著"无分别"本身成为新的执著。

## 十六、四类乐都须以大乐印持；"印持"的定义（第 238–255 句）

```
གང་ཞིག་བྷ་གར་བདེ་བ་རྟོག་མེད་མྱོང་། །
གང་ཞིག་མེ་ལོང་གཟུགས་བརྙན་སྣང་བ་དང་། །
གང་ཞིག་གཏུམ་མོ་དྲོད་ལས་བདེ་མྱོང་དང་། །
གང་ཞིག་དགོད་དང་ལྟ་དང་ལག་བཅངས་དང་། །
འོ་བྱས་འཁྱུད་པ་བདེ་བ་དམ་པ་མྱོང་། །
```

有人在密处体验无分别之乐；有人［体验］镜中影像般的显现；有人从拙火之暖体验乐；有人在笑、看、执手、亲吻拥抱中，体验殊胜之乐。

```
རྟོག་མེད་མྱོང་བར་གྱུར་ཀྱང་བདེ་ཆེན་གྱིས། །
རྒྱས་མ་བཏབ་ན་བྱང་ཆུབ་མེད་དོ་ཞེས། །
རྡོ་རྗེ་འཆང་བ་གསུང་ཞིང་ཚད་མས་གྲུབ། །
བདེ་བ་སྟོང་པ་ཉིད་ཀྱི་རྒྱས་གདབ་བྱ། །
```

虽然体验到无分别，若不以大乐来印持，就没有菩提——金刚持这样说，并以量成立；［所以］要以乐与空来印持。

```
རྒྱས་གདབ་ཅེས་བྱའི་དོན་ནི་ངོ་བོ་ཡང་། །
དམིགས་པའི་ཡུལ་ནི་སྒྱུ་མར་མ་ཟད་ཀྱི། །
རང་གི་མྱོང་བ་སྒྱུ་མར་མངོན་སུམ་དུ། །
རིག་པ་དེ་ལ་རྒྱས་གདབ་རྗེས་སུ་བརྗོད། །
```

所说"印持"的意义与体性是：不仅所缘之境是幻，对于自己的体验也现量了知为幻——对于这种觉知，才称为"印持"。

```
རྟོག་པ་རེ་རེས་བཅད་པ་རྒྱས་གདབ་མིན། །
དེ་བཞིན་རྗེས་དཔག་བསྒོམ་པ་རྒྱས་གདབ་མེད། །
ཤེས་བྱའི་དཀྱིལ་འཁོར་སྤྲོས་དང་བྲལ་བ་ཡི། །
མངོན་སུམ་དེར་སྣང་རྒྱ་ཡི་རྣམ་པར་བྱུང་། །
དེས་ན་རྒྱས་གདབ་ཅེས་ནི་བྱ་བར་བཤད། །
```

以一个一个的分别去截断，不是印持；同样，比量的修习，也没有印持。在离开戏论的所知坛城中，现量如是显现，生起为印的相状——所以说为"印持"。

【按】"密处"，原文 བྷ་ག（梵 bhaga），是密续术语，这里与"笑、看、执手、拥抱"并列，都是业手印修法的象征说法；"笑、看、执手、拥抱"，在密续中常用来对应事部、行部、瑜伽部与无上瑜伽部四续。这些内容须依灌顶与口授，不可照字面理解或模仿。本段的重点是：任何乐或无分别的体验，若没有以大乐空性来"印持"，都不是菩提之道。

## 十七、不必另求口诀与果位（第 256–264 句）

```
འཇིག་རྟེན་འདི་དང་འཇིག་རྟེན་ཕ་རོལ་དག །
བདེ་ཆེན་མཉམ་པར་ཤེས་ཏེ་བསྒོམས་པས་ན། །
འདའ་བའི་མན་ངག་གཞན་ནས་བཙལ་མི་དགོས། །
```

此世与来世，以了知大乐平等而修，就不必再从别处寻找迁转的口诀。

```
སེམས་ཀྱི་རང་བཞིན་ཆོས་ཀྱི་སྐུར་ཤེས་ན། །
འབྲས་བུ་ཐོབ་བྱས་སར་དུ་བཙལ་བ་མེད། །
```

若了知心的自性是法身，就不必在地［道］之中去寻求要得的果。

```
སེམས་ཀྱི་ངང་ལས་འཕེལ་འགྲིབ་མེད་ཤེས་ན། །
བསྒོམ་པ་ཤོར་ཡང་སྤོགས་པ་བཙལ་མི་དགོས། །
```

若了知心的境界中没有增减，即使修习有所失落，也不必去寻求补救。

```
ལེགས་བྱས་ཉེས་བྱས་གློ་བུར་ཡིན་ཤེས་ན། །
དམ་ཚིག་ཉམས་ཆགས་བཤགས་པ་དེ་ཉིད་ཡིན། །
```

若了知善行与恶行都是突然的，那［了知］本身就是对誓言违犯的忏悔。

【按】"迁转的口诀"（འདའ་བའི་མན་ངག），可能指临终时迁转神识（颇瓦）一类的口诀，存疑。

## 十八、如何显现，如何施设（第 265–276 句）

```
ཇི་ལྟར་སྣང་བ་དེ་ལྟར་བདེན། །
ཇི་ལྟར་བཏགས་པ་དེ་ལྟར་མེད། །
ཇི་ལྟར་བཙལ་བ་དེ་ལྟར་སྐྱོན། །
ཇི་ལྟར་བསམས་པ་དེ་ལྟར་བྲལ། །
```

如何显现，就如此是真实；如何施设，就如此是没有；如何寻求，就如此是过失；如何思维，就如此是远离。

```
ཡུལ་ནི་གང་དང་གང་དག་ལ། །
རྟོག་བྲལ་གསལ་བ་སྐྱེས་གྱུར་ན། །
དེའི་ཚེ་དེ་འོང་མིའི་སེམས་ལ། །
དེ་ནི་སྟོང་ཉིད་བསྒོམ་པ་ཡིན། །
```

对于任何境，若生起离开分别的明，那时，对于那人的心而言，那就是修空性。

```
རང་རིག་གཉིས་མེད་བསྒོམ་བྱ་ཞེས། །
གང་ལ་གདམས་ངག་ཕོག་གྱུར་ཀྱང་། །
གཉིས་མེད་ཉིད་དུ་མ་མྱོང་ན། །
གང་ཞིག་བསྟན་ཀྱང་མིང་དུ་ཟད། །
```

即使对某人传授了"要修自证无二"的口诀，若不体验为无二本身，那么所指示的，也只是名言而已。

【按】"如何显现，就如此是真实"四句，文句极简，大意是：显现上是世俗真实；施设的名相本无实有；去寻求反成过失；思维所及都远离真实，存疑。第 271 句"那时，对于那人的心而言"，原文 དེའི་ཚེ་དེ་འོང་མིའི་སེམས་ལ，文句不很通顺，存疑。

## 十九、六根各住，知心离分别（第 277–292 句）

```
ཡུལ་ནི་གང་དང་གང་དག་ལ། །
ཐམས་ཅད་ལས་ནི་སེམས་བསྡུས་ན། །
ནང་གི་བདག་ཉིད་གཡོ་མེད་པར། །
གནས་པས་མིག་གིས་གཟུགས་དག་གམ། །
གནས་པས་རྣ་བས་སྒྲ་དག་གམ། །
གནས་པས་སྣ་ཡིས་དྲི་དག་གམ། །
གནས་པས་ལྕེ་ཡིས་རོ་དག་གམ། །
གནས་པས་ལུས་ཀྱིས་རེག་དག་གམ། །
གནས་པས་ཡིད་ཀྱིས་ཆོས་དག་གམ། །
ཤེས་པའི་བློ་དེ་རྟོག་བྲལ་ཡིན། །
```

对于任何境，若从一切［境］中收摄心，内在的自体不动而安住，［这样］安住着以眼［见］色、安住着以耳［听］声、安住着以鼻［嗅］香、安住着以舌［尝］味、安住着以身［觉］触、安住着以意［知］法——那能知之心，就是离分别的。

```
རྟོག་པའི་སྐྱེ་དང་འགག་པ་དང་། །
རང་རིག་གཉིས་ཀྱིས་མྱོང་བས་ན། །
རྟོག་དང་བྲལ་བས་མངོན་དུ་གྲུབ། །
```

分别的生与灭，因为由自证这二者来体验，所以离开分别而现前成立。

```
གང་ཞིག་རྟོག་བྲལ་དོན་དེ་ལ། །
ཚོར་བ་བདེ་བ་ལ་བརྟེན་ནས། །
བསྒོམས་པས་ཕོ་ཉའི་ལམ་དུ་གྱུར། །
```

对于那离分别之义，依于乐受而修习，就成为使者之道。

【按】"使者之道"（ཕོ་ཉའི་ལམ），"使者"（梵 dūtī）在密续中指修方便道的伴侣，"使者之道"即依手印之方便道，须依灌顶与口授，存疑。

## 二十、四喜的次第（第 293–310 句）

```
གང་ལ་དང་པོ་རྟོག་མེད་ལ། །
དགའ་བ་ཞེས་སུ་བཤད་པ་ཡིན། །
```

最初的无分别，说为"喜"；

```
རྟོག་བྲལ་བདེ་ཆེན་གཉིས་པ་ལ། །
མཆོག་དགའ་ཞེས་སུ་བཤད་པ་ཡིན། །
དེ་ནི་ལུས་ཀྱི་བདེ་བ་སྟེ། །
ཡིད་འོང་ཡུལ་ལས་བྱུང་བའོ། །
```

离分别的第二种大乐，说为"胜喜"，那是身体之乐，从悦意之境而生；

```
རྟོག་དང་བྲལ་བ་གསུམ་པ་ནི། །
ལྷན་ཅིག་སྐྱེས་དགའ་ཞེས་བཤད་དེ། །
ཡིད་ཀྱི་མངོན་སུམ་བདེ་བ་ཡིན། །
```

离分别的第三种，说为"俱生喜"，是意的现量之乐。

```
གཟུང་འཛིན་དྲི་མ་དང་བྲལ་བས། །
མྱོང་བས་གསལ་བ་སྐྱེ་བ་ནི། །
རང་རིག་བདེ་ཆེན་ཞེས་སུ་བཤད། །
```

由于离开能取所取的垢染，从体验中生起明，说为"自证大乐"。

```
གང་ཞིག་རྟོག་པས་བར་བཅད་ན། །
དགའ་བདེའི་ཏིང་འཛིན་ཉམས་འགྱུར་བས། །
```

若被分别所间断，喜乐的三摩地就会衰损。

```
ཕྱག་རྒྱ་བཞི་ཡི་ཡུལ་རྣམས་ལས། །
ཚོར་བ་བདེ་བ་སྐྱེས་གྱུར་པས། །
རྒྱུ་རྐྱེན་ཚོགས་པའི་སྟོབས་ལྡན་པས། །
རྟོག་དང་བཅས་པས་སྐྱེ་མི་འགྱུར། །
```

从四手印之境生起乐受，因为具有因缘聚合之力，所以不会以有分别［的方式］生起。

【按】本篇这里以"喜、胜喜、俱生喜、自证大乐"为次第，与通常"喜、胜喜、离喜、俱生喜"的四喜次第不同，依原文译出。第 307–310 句的意思不很确定，存疑。

## 二十一、止与观的分别（第 311–327 句）

```
དེ་བས་བདེ་བའི་ཏིང་འཛིན་ལས། །
རྣལ་འབྱོར་པ་ཡི་ཡིད་གཞག་ནས། །
གཉིས་མེད་བདེ་ཆེན་བསྒོམ་པར་བྱ། །
```

所以，瑜伽士的意，从乐之三摩地中安置下来，修习无二的大乐。

```
གང་ཞིག་བདེ་བའི་ཏིང་འཛིན་ལས། །
སེམས་འཇོག་པ་ནི་ཞི་གནས་ཡིན། །
```

从乐之三摩地中安住心，就是"止"。

```
དེས་ན་དགའ་དང་མཆོག་དགའ་དང་། །
ལྷན་སྐྱེས་དགའ་བ་ཕུལ་བྱུང་ཡང་། །
ཞི་གནས་སེམས་ལས་མི་འདའ་སྟེ། །
ལུས་དང་ཡིད་ཀྱི་བདེ་བར་ཟད། །
```

所以，喜、胜喜与俱生喜，虽然殊胜，也不超出"止"的心，只是身与意之乐而已。

```
བདེ་ཆེན་དོན་གྱིས་རྒྱས་གདབ་ན། །
ལྷག་མཐོང་ཕུལ་དུ་བྱུང་བར་འགྱུར། །
```

若以大乐之义来印持，就成为殊胜的"观"。

```
གང་ཞིག་བདེ་བའི་ཆོས་ཅན་ལ། །
སྟོང་ཉིད་སྒྲུབ་པ་གང་ཡིན་པ། །
ལྷན་ཅིག་སྐྱེས་དགའ་ཡིན་སྙམ་སྟེ། །
དེ་ནི་རྗེས་དཔག་བསྒོམ་པའི་ལམ། །
སོ་སོར་རྟོག་པའི་རྣལ་འབྱོར་ཏེ། །
བདེ་བ་ཆེན་པོ་མྱོང་བའང་མེད། །
```

有人在乐这一有法之上，［以推理］成立空性，想"这就是俱生喜"——那是比量修习之道，是各别观察的瑜伽，并没有体验到大乐。

【按】"止"（ཞི་གནས，奢摩他）、"观"（ལྷག་མཐོང，毗钵舍那）。本段说：单有乐的三摩地只是"止"；以大乐空性印持，才是"观"；以推理成立乐是空，则仍是比量，不是现量体验。

## 二十二、乐如波浪起于光明大海（第 328–349 句）

```
འོད་གསལ་བདེ་བའི་རྒྱ་མཚོ་ལས། །
དགའ་བདེ་དབའ་རླབས་ཚུལ་དུ་ཤེས། །
དེ་ཉིད་སྟོང་པ་བསྒོམ་པ་ཡིན། །
```

了知喜与乐，就像从光明之乐的大海中［起的］波浪——这就是修空。

```
བདེ་དང་ཡིད་བདེ་གང་ཡིན་ལས། །
དེ་ཡི་རང་བཞིན་སྟོང་ཤེས་ན། །
གཏན་ཚིགས་ལ་སོགས་དོན་མེད་ཡིན། །
```

对于乐与意乐，若了知它们的自性是空，［成立空性的］理由等就没有意义了。

```
ཆུ་ནི་དང་བར་གྱུར་པ་ལས། །
ཉ་དག་མྱུར་དུ་འཕར་བ་ལྟར། །
དེ་བཞིན་སྟོང་གསལ་རང་བཞིན་ལས། །
སྣ་ཚོགས་ཤེས་པ་ལྡང་ཞིང་འགག །
```

如同水变得澄清之后，鱼儿迅速跃起；同样，从空明的自性中，种种识生起而又止息。

```
སྣོད་བཅུད་བདེ་ཆེན་རྒྱས་བཏབ་པས། །
སེམས་ཀྱི་གླང་པོ་ཡན་བཏང་ཡང་། །
གནས་མ་རྙེད་ནས་ལྡོག་པར་འགྱུར། །
```

以大乐印持器世间与有情，心之大象即使放开，找不到住处也就回来了。

```
དངོས་པོ་གསལ་བ་མཐོང་ན་ཡང་། །
དེ་དེ་བདེ་བས་རྒྱས་བཏབ་ནས། །
གཡེང་བ་ཉིད་ཀྱང་གཡེང་བ་མིན། །
```

即使见到事物明显，以乐来印持它们，散乱本身也就不是散乱。

```
སྤྱོད་ལམ་རོ་མཉམ་ཡིན་ཤེས་ནས། །
འགྲོ་བ་ཉིད་ནི་འགྲོ་འོང་མེད། །
```

了知一切行止都是平等一味，行走本身也就没有来去；

```
རྒྱུ་འབྲས་མེད་ཀྱང་རྒྱས་བཏབ་པས། །
སྐྱེ་བ་ཉིད་ནའང་སྐྱེ་བ་མེད། །
```

虽然没有因果，但因为印持，生起本身也就没有生；

```
འགག་པ་ཐིམ་པའི་རྒྱས་བཏབ་པས། །
བཀག་ཙམ་ཉིད་ནའང་འགག་པ་མེད། །
```

以止灭融入的印持，仅仅是遮止本身，也就没有灭。

【按】"心之大象即使放开，找不到住处也就回来了"，与萨惹哈道歌中"放开心之象"的比喻相近。"虽然没有因果"，是就胜义而说，不是否定世俗的业果。

## 二十三、善逝与诸法平等；法身与报身（第 350–365 句）

```
བདེ་གཤེགས་རྣམས་ནི་བདེ་ཆེན་ཉིད་ཀྱི་སྐུ། །
ཆོས་རྣམས་ཐམས་ཅད་བདེ་གཤེགས་ཉིད་དང་མཉམ། །
```

诸善逝就是大乐之身；一切法都与善逝本身平等。

```
བྱིས་པའི་བློ་ཅན་དངོས་ལ་ཞེན་པ་རྣམས། །
རྣམ་པར་རྟོག་པས་བརྟགས་པ་ཉིད་ལ་སྤྱོད། །
```

具有孩童之慧、执著事物的人们，行于分别所遍计的［境］中。

```
དངོས་རྣམས་ཐམས་ཅད་བཅོས་སུ་མེད་ན་ཡང་། །
གྲུབ་མཐའ་ངན་པས་བསླད་པས་འཆོས་པར་བྱེད། །
```

一切事物虽然无可造作，［他们］却被恶劣的宗见所染污，而去造作。

```
གདོད་ནས་རྣམ་དག་འོད་གསལ་ཆོས་ཀྱི་དབྱིངས། །
བདེ་གཤེགས་ཆོས་ཀྱི་སྐུ་ཡིས་མཁྱེན་པར་མཉམ། །
```

本来清净的光明法界，与善逝的法身在智慧上平等。

```
འཁོར་བའི་ཕུང་པོ་སྒྱུ་མར་རྣམ་དག་ཤེས། །
ལོངས་སྤྱོད་རྫོགས་སྐུ་སྒྱུ་མར་ཡང་དག་མཉམ། །
```

了知轮回的诸蕴如幻而清净，就与圆满报身如幻真正平等。

```
གལ་ཏེ་སྒྱུ་མའི་རྒྱུན་ལ་བདེ་སྡུག་དང་། །
དགའ་དང་གདུང་བའི་བྱེ་བྲག་ཡོད་མིན་ཡང་། །
དེར་སྣང་སྐད་ཅིག་རེ་རེར་གནས་པ་ལས། །
བདེ་ཆེན་བདེ་བ་ཆེན་པོ་ཉིད་དུ་གཅིག །
```

即使在幻的相续之中，没有苦与乐、喜与焦灼的差别，在那显现的每一刹那安住之中，大乐就是大乐本身，同为一体。

```
རྣམ་པར་རྟོག་པ་ཐ་དད་མེད་ན་ཡང་། །
མི་རྟོག་ངང་ལས་རོ་གཅིག་གྱུར་པར་སྣང་། །
```

即使分别没有差别，［也］从无分别的境界中，显现为成为一味。

【按】第 360–365 句文意较为曲折，大意是：一切显现虽如幻、本无苦乐差别，但每一刹那都是大乐的显现；一切分别都从无分别中显现为一味，存疑。

## 二十四、依上师教授，苦乐都成大乐（第 366–369 句）

```
དང་པོའི་ལས་ཅན་སོ་སོའི་སྐྱེ་བོ་ལ། །
བདེ་བ་ལམ་དུ་བྱེད་པར་གསུངས་ན་ཡང་། །
གང་ཞིག་བླ་མའི་ཕན་པའི་ལུང་ཐོབ་ནས། །
བདེ་སྡུག་ཐམས་ཅད་བདེ་བ་ཆེན་པོར་འགྱུར། །
```

对于初业的凡夫，虽然说以乐为道；但若有人得到上师利益的教授，一切苦乐都会成为大乐。

## 二十五、不知空性则无解脱（第 370–377 句）

```
གང་ཞིག་སྟོང་ཉིད་མི་ཤེས་པ། །
དེ་ལ་ཐར་པའི་སྐལ་བ་མེད། །
འགྲོ་དྲུག་སྲིད་པའི་བཙོན་ར་རུ། །
རྨོངས་པ་དེ་ནི་འཁྱམ་པར་འགྱུར། །
```

谁不知道空性，他就没有解脱之分；那愚者会在六道三有的牢狱中流浪。

```
དེ་ལྟར་རྣལ་འབྱོར་པ་རྣམས་ཀྱིས། །
སྟོང་པ་ཉིད་ནི་བསྒོམ་བྱས་ན། །
བློ་ནི་གཞན་དོན་ལ་དགའ་བར། །
འགྱུར་བ་ཉིད་དུ་ཐེ་ཚོམ་མེད། །
```

这样，瑜伽士们若修习空性，心就会乐于利他，这是毫无疑问的。

【按】从这里（第 370 句）起，到第 448 句"这样说了"为止，是一大段引文。这段偈颂的内容与龙树《菩提心释》（Bodhicittavivaraṇa）中的偈颂非常相近，很可能就是引自该论，但本篇没有标明出处，存疑。

## 二十六、念众生恩，护众生如护自身（第 378–399 句）

```
སེམས་ཅན་གང་ཡིན་ཐམས་ཅད་སྔོན། །
ཕ་མ་མཛའ་བཤེས་རྩ་ལག་ཏུ། །
གྱུར་ཅིང་ཕན་ཆེན་བཏགས་པས་ན། །
བྱས་པ་གཟོ་བ་ཉིད་དུ་བྱ། །
```

一切众生，往昔都曾是［我的］父母、亲友与眷属，曾经给予［我］大利益，所以要报恩。

```
སེམས་ཅན་ལ་བརྟེན་བླ་མེད་པའི། །
སངས་རྒྱས་གོ་འཕང་ཉིད་ཐོབ་ན། །
ཚངས་དབང་དྲག་པོ་འཇིག་རྟེན་སྐྱོང་། །
སོགས་པ་འཐོབ་པ་མཚར་ཅི་ཆེ། །
```

依于众生，能得到无上的佛位，那么得到梵天、帝释、大自在天、护世天王等［果位］，又有什么稀奇呢？

```
སེམས་ཅན་ཕན་པ་བྱས་ཙམ་གྱིས། །
འགྲོ་བ་གསུམ་པ་དམ་པར་སྐྱེ། །
```

仅仅因为利益众生，就能生于殊胜的三善趣。

```
སེམས་ཅན་གནོད་པས་སྡུག་བསྔལ་ནི། །
རྣམ་པ་དུ་མའི་ཚུལ་དག་གིས། །
དམྱལ་བ་ཡི་དྭགས་དུད་འགྲོ་རུ། །
སེམས་ཅན་རྣམས་ནི་ཉེ་བར་སྤྱོད། །
```

因为损害众生，众生就会在地狱、饿鬼、畜生之中，以种种方式受苦。

```
དངོས་པོ་ཀུན་གྱིས་མགུ་བྱ་བ། །
རང་ལུས་བཞིན་དུ་བསྲུང་བར་བྱ། །
འབད་པས་སེམས་ཅན་མི་དགའ་བ། །
དུག་དང་འདྲ་བ་སྤང་བར་བྱ། །
```

要以一切事物使［众生］欢喜，像守护自己的身体一样守护［他们］；要努力把令众生不悦的事，像毒药一样舍弃。

```
སེམས་ཅན་ཡོངས་སུ་མ་བཏང་བས། །
སངས་རྒྱས་བྱང་ཆུབ་ཀུན་དུ་འཐོབ། །
གཞན་གྱི་གནོད་པ་མ་བཟོད་པས། །
མནར་མེད་དུ་ཡང་སྐྱེ་བར་བྱེད། །
```

因为不舍弃众生，就能得到一切佛的菩提；因为不能忍受他人的损害，也会生于无间地狱。

【按】"大自在天"，原文 དྲག་པོ（猛厉者），是大自在天（Rudra）的异名。"不能忍受他人的损害"，意思是对他人的伤害生起嗔恨，存疑。

## 二十七、知空而依业果，最为稀奇（第 400–411 句）

```
རང་གི་ལུས་དང་ནོར་སྦྱིན་པ། །
འདི་ནི་མཚར་ཞིང་འདི་ནི་བསྔགས། །
འདི་ནི་འཇུག་པ་མཆོག་ཡིན་ནོ། །
```

布施自己的身体与财物，这是稀奇的，这是值得赞叹的，这是殊胜的趣入；

```
མཚར་ཞེས་བྱ་བ་འདི་མིན་ཏེ། །
ཆོས་འདི་སྟོང་པར་ཤེས་ནས་སུ། །
ལས་ཀྱི་འབྲས་བུ་བསྟེན་བྱེད་པ། །
མཚར་བ་བས་ཀྱང་འདི་མཚར་ཞིང་། །
ངོ་མཚར་བས་ཀྱང་ངོ་མཚར་རོ། །
```

但所谓的"稀奇"，不是这个：了知此法是空，却仍然依止业果——这比稀奇更稀奇，比奇妙更奇妙。

```
སེམས་ཅན་བསྐྱབ་པའི་བསམ་པ་འདིས། །
སྲིད་པའི་འདམ་དུ་སྐྱེས་མོད་ཀྱི། །
པདྨ་ལ་ནི་ཆུ་བཞིན་དུ། །
སྲིད་པའི་སྐྱོན་གྱིས་དེ་མ་གོས། །
```

以救护众生的心，虽然生在三有的污泥之中，就像莲花不沾水一样，不被三有的过失所染污。

【按】这一段是全篇的关键：前面说"不思善恶""没有因果"，都是就胜义与证悟境界而说；这里明说，真正稀有的，是了知一切空性之后仍然谨慎依止业果。

## 二十八、菩萨与佛以悲心示现（第 412–427 句）

```
བཟང་པོ་ལ་སོགས་རྒྱལ་བའི་སྲས། །
འདི་ན་ཡེ་ཤེས་མེ་ཡིས་ནི། །
ཉོན་མོངས་བུད་ཤིང་བསྲེགས་བཞིན་དུ། །
འོན་ཀྱང་ཐུགས་རྗེས་བསླབ་པ་མཛད། །
```

普贤等诸胜者之子，在这里以智慧之火焚烧了烦恼之柴，然而以悲心示现修学。

```
བྱང་ཆུབ་ཆེ་དང་འཆི་དང་སྐྱེ། །
དུར་ཁྲོད་གཤེགས་དང་དཀའ་སྤྱོད་མཛད། །
བདུད་སྡེ་རབ་ཏུ་འཇོམས་པ་དང་། །
ཆོས་ཀྱི་འཁོར་ལོ་བསྐོར་བ་དང་། །
ལྷ་ཡུལ་གཤེགས་དང་མྱ་ངན་འདས། །
```

［示现］大菩提、死与生、前往尸林、修苦行、摧伏魔军、转法轮、前往天界与涅槃。

```
དེ་བཞིན་ཁྱིམ་ནས་བྱུང་བ་རྣམས། །
སྙིང་རྗེའི་དབང་གིས་འཇུག་པ་ཡིས། །
འགྲོ་བའི་མགོན་པོ་སྟོན་པར་མཛད། །
```

同样，那些出家者，以悲心的力量而趣入［世间］，示现为众生的怙主。

```
ཚངས་དབང་ཉེ་དབང་དྲག་སོགས་ཀྱི། །
གཟུགས་ཀྱིས་རབ་ཏུ་འཇུག་མཛད་ཅིང་། །
འགྲོ་བ་འདུལ་བའི་སྦྱོར་བ་ཡིས། །
ཐུགས་རྗེས་ཐུགས་ཀྱིས་རོལ་པ་མཛད། །
```

以梵天、帝释、遍入天、大自在天等的形相而趣入，以调伏众生的方便，以悲心之意而游戏。

## 二十九、二乘终归大乘（第 428–439 句）

```
ཐེག་པ་གཉིས་པོ་དག་ཀྱང་ནི། །
ཐེག་པ་ཆེན་པོར་འབྱུང་བས་ན། །
སྲིད་པའི་ལམ་གྱིས་དུབ་པ་རྣམས། །
ངལ་བསོ་དོན་དེ་དེ་ཉིད་མིན། །
```

二乘也终将从大乘而出，所以［二乘］只是为疲于三有之道的人们所设的休息，并不是真实之义。

```
ཉན་ཐོས་དེ་དག་དེ་སྲིད་དུ། །
སངས་རྒྱས་རྣམས་ཀྱིས་མ་བསྐུལ་བར། །
དེ་སྲིད་ཡེ་ཤེས་ལུས་གཅིག་གིས། །
ཏིང་འཛིན་དྲེགས་པས་མྱོས་ཏེ་གནས། །
```

那些声闻，只要没有被诸佛劝请，就一直以一个智慧之身，沉醉于三摩地的骄慢之中而安住。

```
བསྐུལ་ནས་སྣ་ཚོགས་གཟུགས་ཀྱིས་ནི། །
སེམས་ཅན་དོན་ལ་དགའ་བྱེད་ཅིང་། །
བསོད་ནམས་ཡེ་ཤེས་ཉེར་འཕེལ་ནས། །
སངས་རྒྱས་བྱང་ཆུབ་འཐོབ་པར་འགྱུར། །
```

被劝请之后，就以种种形相乐于利益众生，福德与智慧增长，而得到佛的菩提。

【按】"二乘只是休息处"，与《法华经》"化城喻"的意思相通。"一个智慧之身"，原文 ཡེ་ཤེས་ལུས་གཅིག，指声闻入灭尽定后的状态，存疑。

## 三十、习气是种子；说空者不是断见（第 440–448 句）

```
བག་ཆགས་ལས་ནི་བྱུང་བས་ན། །
བག་ཆགས་ས་བོན་དག་ཏུ་བཤད། །
བག་ཆགས་རྗེས་མཐོང་ཚོགས་པ་ན། །
སྲིད་པའི་མྱུ་གུ་དེ་བསྐྱེད་དོ། །
```

因为［三有］从习气而生，所以说习气是种子；习气与［诸缘］聚合时，就生出三有之芽。

```
སྟོང་ཉིད་སྨྲ་བས་སྨྲ་བྱེད་ཅིང་། །
རྟག་ཏུ་ལུས་ངག་ཡིད་གསུམ་གྱིས། །
འདི་ལྟར་སེམས་ཅན་དོན་བྱེད་པ། །
ཆད་པར་སྨྲ་བ་ཡོད་མ་ཡིན། །
ཞེས་གསུངས་སོ། །
```

说空性的人，宣说［空性］，而且恒常以身、语、意三者这样利益众生，［所以］不是说断灭的人。——这样说了。

【按】"习气与［诸缘］聚合时"，原文 བག་ཆགས་རྗེས་མཐོང་ཚོགས་པ་ན，"རྗེས་མཐོང"意思不明，这里依文意补译，存疑。

## 三十一、点金药之喻：心在大乐中成一味（第 449–458 句）

```
དཔེར་ན་གསེར་འགྱུར་ཟངས་ལྕགས་ཐམས་ཅད་ལ། །
གསེར་འགྱུར་རྩི་ཡི་ནུས་པའི་ཐབས་རྙེད་ན། །
ཐམས་ཅད་ཁ་དོག་གསེར་དུ་འགྱུར་བ་ལྟར། །
སེམས་ཀྱང་བདེ་ཆེན་ངང་དུ་རོ་གཅིག་འགྱུར། །
```

譬如对于一切铜与铁，若得到点金药的力用之法，一切的颜色都会变成金色；心也同样，在大乐的境界中成为一味。

```
སྒྱུ་མ་སྨིག་རྒྱུ་དྲི་ཟའི་གྲོང་ཁྱེར་རྣམས། །
རྟོག་དང་བྲལ་བའི་སྟོང་པའི་རྣམ་པ་སྐྱེས། །
དེ་བཞིན་སྒྱུ་འདྲར་སེམས་ཀྱི་སྒྱུ་འདྲར་ཤེས། །
བདེ་ཆེན་རྒྱས་བཏབ་བདག་བྱིན་བརླབ་པ་ལ། །
སྒྱུ་མའི་དཔེ་ཡིས་དོན་རྣམས་བཙལ་མི་དགོས། །
ཐམས་ཅད་སྒྱུ་འདྲ་མི་འདྲར་དགག་སྒྲུབ་བྱེད། །
```

幻、阳焰、乾闼婆城，生起离分别的空之相；同样，了知心如幻、如［所现之］幻，在以大乐印持、自加持之中，就不必以幻的譬喻去寻求诸义，［也不必］对一切"如幻""不如幻"作遮止与成立。

【按】第 455 句"了知心如幻、如［所现之］幻"，原文 སྒྱུ་འདྲར་སེམས་ཀྱི་སྒྱུ་འདྲར་ཤེས，文句重复，意思不很确定，存疑。

## 三十二、无遮无立，不需推理（第 459–463 句）

```
ཕྱག་རྒྱའི་ལམ་ལ་བདེ་བ་སྟོང་པར་ཤེས། །
ཆོས་ཀྱི་མདོ་དོན་སེམས་ཀྱིས་སྟོང་པར་ཤེས། །
ཆོས་རྣམས་ཀུན་ལ་ཡོད་མེད་དགག་སྒྲུབ་མེད། །
རྟོག་མེད་མངོན་སུམ་ལམ་ལ་བློ་གཞག་པས། །
རྟགས་ཀྱིས་རྗེས་འབྲངས་གཞན་སེལ་དགོས་པ་མེད། །
```

在手印之道上，了知乐是空；以心了知法与经的义理是空；对于一切法，没有有与无的遮止与成立；把心安住于无分别的现量之道，就不需要依随因相［推理］来遣除他者。

【按】"依随因相来遣除他者"（རྟགས་ཀྱིས་རྗེས་འབྲངས་གཞན་སེལ），指因明中以因相推理、以"遣他"（apoha）来成立的方法。

## 三十三、知心之秘密即是成佛（第 464–476 句）

```
དུས་གསུམ་བདེ་གཤེགས་ཇི་ལྟར་སངས་རྒྱས་ལྟར། །
གང་དུ་ཁ་བལྟས་སེམས་ཀྱི་གསང་ཤེས་པས། །
སྒྲིབ་པ་ཀུན་ཟད་ཡེ་ཤེས་ཕུན་ཚོགས་ཤིང་། །
སངས་རྒྱས་ཞིང་གྲོལ་སེམས་ཅན་ཐམས་ཅད་སྒྲོལ། །
ཐམས་ཅད་བཟང་རྒྱུ་ཉིད་དུ་གྱུར་པར་ངེས། །
```

就像三时的善逝怎样成佛一样，无论向何处看，因为了知心的秘密，一切障碍都已穷尽，智慧圆满，成佛并且自己解脱，救度一切众生，决定一切都成为善的因。

```
ཇི་ལྟར་སྦྲུལ་གྱི་རང་བཞིན་ཤེས་པ་ན། །
དེ་ཡི་དུག་ནི་གནོད་པར་མི་འགྱུར་ཏེ། །
གང་ཞིག་ཉོན་མོངས་འཁོར་བའི་རང་བཞིན་ཤེས། །
དེས་ནི་དེ་མ་ཐག་ཏུ་ངེས་གྲོལ་འགྱུར། །
```

就像了知了蛇的自性，它的毒就不能伤害；谁了知烦恼与轮回的自性，他就当下决定解脱。

```
དེ་ཉིད་ཀྱིས་ནི་སངས་རྒྱས་ཤིང་། །
དེ་ཉིད་ཀྱིས་ནི་ཉོན་མོངས་འཇོམས། །
བདེ་ཆེན་ལམ་ལ་བརྟེན་ནས་ནི། །
ཐམས་ཅད་བྱས་ཀྱང་རྣམ་པར་གྲོལ། །
```

以此成佛，以此摧伏烦恼；依于大乐之道，即使做了一切，也能解脱。

【按】"依于大乐之道，即使做了一切，也能解脱"，是就已证悟心性者的境界而说的，前文（第二十七节）已明说要了知空性而依止业果，不可理解为可以随意造作恶业。

## 三十四、智慧无为；"嘿汝嘎"四字的解释（第 477–486 句）

```
རྣམ་པར་རྟོག་པ་རྣམ་སྤངས་ཤིང་། །
གཟུང་དང་འཛིན་པ་དང་བྲལ་བས། །
ཡེ་ཤེས་འདུས་མ་བྱས་པ་སྟེ། །
རྒྱུ་དང་རྐྱེན་གྱིས་མ་བསྐྱེད་པའོ། །
```

远离分别，离开能取与所取，智慧是无为的，不是由因与缘所生的。

```
ཤྲཱི་ནི་གཉིས་མེད་ཡེ་ཤེས་ཏེ། །
ཧེ་ནི་རྒྱུ་སོགས་སྤངས་པ་ཡིན། །
རུ་ནི་བཀོད་པ་དང་བྲལ་བ། །
ཀ་ནི་གང་དུའང་མི་གནས་པ། །
```

"室利"（Śrī），是无二的智慧；"嘿"（He），是舍弃因等；"汝"（Ru），是离开安立；"嘎"（Ka），是不住于任何处。

```
སེམས་ཀྱི་ངང་ལ་རྣམ་གནས་ན། །
མྱ་ངན་འདས་པ་བསྟན་དུ་མེད། །
```

若安住于心的境界之中，涅槃就没有［另外］可显示的。

【按】"室利嘿汝嘎"（Śrī Heruka）四字的解释，是《喜金刚》等续释中常见的说法：He 取 hetu（因）之义，表示离开因等；Ru 表示离开聚合安立；Ka 表示无所住；Śrī 表示无二智慧。

## 三十五、结颂与跋文（第 487–492 句）

```
བདེ་ཆེན་རྟོགས་པའི་མན་ངག་འདི། །
སྡེབ་སྦྱོར་གོ་རིམ་བསྒྲིགས་པ་མིན། །
ཉམས་མྱོང་རྟོགས་པའི་ཕན་པའི་ལུང་། །
དམ་པའི་སྤྱི་བོས་བླང་བར་མཛོད། །
```

这证悟大乐的口诀，不是依诗律次第编排的；是体验与证悟之利益的教授，请诸位圣者以头顶戴受。

```
དངོས་པོའི་གནས་ལུགས་བསྒོམ་པ་ཞེས་བྱ་བ།
ནོར་བུ་གླིང་པའི་སློབ་དཔོན་བདེ་བའི་རྡོ་རྗེས་མཛད་པ་རྫོགས་སོ།།
```

名为《境之实相修习》，宝洲的阿阇黎乐金刚所作，圆满。

【按】"乐金刚"（བདེ་བའི་རྡོ་རྗེ，梵 Sukhavajra），作者生平不详。"宝洲"（ནོར་བུ་གླིང་པ），可能是地名（如梵 Ratnadvīpa 或 Maṇidvīpa），所指不明，存疑。本篇没有译者跋语。
