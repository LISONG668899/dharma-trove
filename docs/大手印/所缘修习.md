# 所缘修习

圣者龙树 造　金刚手、玛班却巴 译

## 题解

本篇出自德格版丹珠尔续部（རྒྱུད་འགྲེལ།）ཞི 函第127b叶第1行至第128a叶第6行，东北目录编号 D2277。全篇七十二句，每句七个音节，共十八偈（四句一偈），另有礼敬与跋语。篇幅很短，所以把藏文原文全部保留在代码块中，按偈分开，每偈后附汉译，疑难之处另以【按】说明。

梵文题名：Bhāva-saṃcāra-nāma（བྷ་བ་སཉྩར་ནཱ་མ）。

藏文题名：དངོས་པོ་སྦྱོང་བ（事物修治）。

【按】藏文题名“དངོས་པོ་སྦྱོང་བ”，直译是“对事物的修治”或“观修事物”，本篇标题依通行译名作“所缘修习”。

【按】跋语说本篇是“大阿阇黎圣者龙树亲造”，由印度堪布金刚手（བཛྲ་པཱ་ཎི）与藏地译师玛班却巴（རྨ་བན་ཆོས་འབར）翻译、校订定稿。

【按】本篇的梵文题名，与龙树的《三有迁转论》（Bhavasaṃkrānti）相近；汉译藏经中有施护所译的《大乘破有论》，一般认为是这部论的汉译。本篇末偈“眼不见色，意不知法”，正是月称《明句论》所引用的龙树偈子。所以本篇很可能就是《三有迁转论》（或其某一传本）的另一个藏译本。据译者所知，德格丹珠尔中观部另收有这部论的藏译本，但未及核对。本篇与中观部的藏译本、与汉译《大乘破有论》的关系，译者没有逐句对勘，这里只作提示，以待考证。

【按】本篇虽然收在续部释论中，内容却是纯粹的中观见地：诸法无生、如虚空、如幻城，五蕴皆空，一切唯是名言假立，连空性也是假立；同时强调依六度、智悲双运而速得菩提。书中“无因无果”“业无自性”等语，都是就胜义的观察而说的，并不是否定世俗的因果，读者须善加理解。

## 正文

### 第一偈：执无实为实有，如空中花

```
དངོས་པོ་མེད་ལ་དངོས་པོར་ཤེས། །དངོས་མེད་སྐྱེ་བ་ཡོད་མ་ཡིན། །རྟག་ཏུ་སྐྱེ་བ་དངོས་པོ་ཉིད། །དངོས་འཁྲུལ་ནམ་མཁའི་མེ་ཏོག་བཞིན། །
```

（凡夫）把无实之物认作实有；然而无实之物，并没有生起。（认为事物）常常在生起，这正是执为实有；执为实有的迷乱，就像虚空中的花一样。

【按】第3句“རྟག་ཏུ་སྐྱེ་བ་དངོས་པོ་ཉིད”，直译是“常生即是实有”，语法简略。这里读作：凡夫总认为事物在生起，这本身就是实有的执著。括号中的字是译者所补。“虚空之花”是佛经中比喻本不存在之物的名喻。

### 第二偈：诸法如虚空

```
མཁའ་དང་མཉམ་པའི་ཆོས་རྣམས་ནི། །སྐྱེ་བ་མཁའ་དང་མཉམ་ཉིད་མཆོག། །ཐམས་ཅད་རང་བཞིན་གྱིས་མཁའ་མཉམ། །དེས་ན་སྲིད་པ་དམ་པའི་དངོས། །
```

与虚空相等的诸法，它们的生起，也与虚空相等，这是最殊胜的（见解）。一切法在自性上都与虚空相等，所以，三有（的本性）就是殊胜的实义。

【按】第8句“དེས་ན་སྲིད་པ་དམ་པའི་དངོས”，直译是“故三有是殊胜之实”，意思可能是：既然一切法本性如虚空，三有轮回的本性也就是胜义，并没有离开轮回另外的胜义。这一读法是推定的，括号中的字是译者所补。

### 第三偈：无因无果，无业自性

```
རྒྱུ་མེད་འབྲས་བུ་མེད་པ་སྟེ། །ལས་ཀྱི་རང་བཞིན་ཡོད་མ་ཡིན། །འཇིག་རྟེན་པ་མེད་འཇིག་རྟེན་མེད། །འདི་དག་ཐམས་ཅད་བདེན་མ་ཡིན། །
```

没有因，也没有果，业的自性并不存在；没有世间人，也没有世间，这一切都不是真实的。

【按】“无因无果，业无自性”，是就胜义的观察而说的：因、果、业都没有自性。这绝不是否定世俗的因果业报。在世俗中，因果丝毫不爽，必须谨慎取舍。这一点必须特别注意，以免落入断见。

### 第四偈：不生之物，如石女之子

```
མ་སྐྱེས་པས་ནི་དངོས་པོ་གང་། །ཇི་ལྟར་གཞན་ལས་ཤེས་པར་འགྱུར། །མོ་གཤམ་གྱི་ནི་བུ་ཉིད་ཀྱང་། །དེ་ཚེ་སྐྱེ་བར་འགྱུར་མ་ཡིན། །
```

既然不生，什么事物能从他者被了知呢？石女的儿子，那时也不会生起。

【按】“石女之子”是佛经中比喻本不存在之物的名喻。“不生”是中观的核心见地，诸法本来无生。

### 第五偈：世间本不生，如幻城

```
འཇིག་རྟེན་གཟོད་ནས་མ་སྐྱེས་ཏེ། །གང་གིས་ཀྱང་ནི་སྤྲུལ་མ་ཡིན། །དོན་མེད་འཁྲུལ་པའི་འཇིག་རྟེན་འདི། །ཟླ་བ་བཟང་པོའི་གྲོང་ཁྱེར་བཞིན། །
```

世间本来就没有生起，也不是任何人所化现的。这毫无实义的迷乱世间，就像“月贤城”一样。

【按】“ཟླ་བ་བཟང་པོའི་གྲོང་ཁྱེར”，直译是“月贤之城”，所指不明，依上下文应是乾闼婆城一类如幻之城的名称。“不是任何人所化现”，是破斥大自在天等造物主之说。

### 第六偈：世间生于分别，分别生于心

```
འཇིག་རྟེན་རྣམ་པར་རྟོག་ལས་འབྱུང་། །རྣམ་རྟོག་སེམས་ལས་བྱུང་བ་སྟེ། །གང་ཕྱིར་ལུས་ལས་སེམས་བྱུང་བས། །དེ་ཕྱིར་ལུས་ལ་རྣམ་པར་བརྟག། །
```

世间是从分别中生起的，分别是从心中生起的；因为心是依于身而生起的，所以要对身体仔细观察。

【按】“心从身生，所以要观察身”，这里应当理解为观修的次第：先从观察身体入手，了知身体无实，再进而了知心无实。这并不是主张心由物质所生的唯物之见。这一读法是依下文“色空、受无自性”的次第推定的。

### 第七偈：五蕴皆空，无分别自性

```
གཟུགས་སྟོང་ཚོར་བ་རང་བཞིན་མེད། །འདུ་ཤེས་མེད་ཅིང་འདུ་བྱེད་མེད། །སེམས་བྱུང་མེད་ཅིང་དངོས་པོ་མེད། །དེ་ཕྱིར་མི་རྟོག་རང་བཞིན་ནོ། །
```

色是空的，受没有自性；没有想，也没有行；没有心所，也没有实有之物。所以（一切）是无分别的自性。

【按】这几句依次观察五蕴（色、受、想、行、识），与《心经》“五蕴皆空”的意思相同。“心所”（སེམས་བྱུང）这里代表识蕴及其相应的心理作用。

### 第八偈：无二之道

```
དེས་ན་སེམས་མིན་ཆོས་ཀྱང་མིན། །ལུས་མིན་ཁམས་ལ་སོགས་པ་མིན། །གཉིས་སུ་མེད་པའི་ལམ་འདི་ནི། །དེ་ཉིད་རིག་པ་རྣམས་ཀྱིས་གསུངས། །
```

所以，（它）不是心，也不是法；不是身，也不是界等等。这无二之道，是通达真如的人所宣说的。

【按】“不是心、不是法、不是身、不是界”，意思是：真实的本性，不能用心、法、身、界等任何概念来界定。

### 第九偈：无所缘

```
དམིགས་པ་མེད་པའི་ཆོས་འདི་ཀུན། །དམིགས་པ་མེད་པར་རབ་ཏུ་བསྟན། །དམིགས་པ་མེད་པའི་བློ་བྱས་ན། །དམིགས་པ་མེད་པར་འགྱུར་བ་ཡིན། །
```

这一切无所缘的法，以无所缘的方式来宣说；如果生起了无所缘的心，就会成为无所缘。

【按】“无所缘”（དམིགས་པ་མེད་པ），是本篇题名的关键词。依藏文题名，本篇是“事物修治”，修持的要点，就是了知一切法本来无所缘，心也不执取任何所缘。

### 第十偈：依六度速得菩提

```
སྦྱིན་དང་ཚུལ་ཁྲིམས་བཟོད་བརྩོན་འགྲུས། །བསམ་གཏན་ལས་བྱུང་བསྟེན་པར་བྱ། །དུས་མི་རིང་བ་ཉིད་ན་ནི། །བླ་མེད་བྱང་ཆུབ་ཐོབ་པར་འགྱུར། །
```

要依止布施、持戒、忍辱、精进，以及从禅定所生（的智慧）；不久就会获得无上菩提。

【按】这里列举了布施、持戒、忍辱、精进、禅定，“从禅定所生”的应当就是般若，合为六度。在讲完空性之后，紧接着就讲六度，说明空性的见地与菩萨的行持不相分离。

### 第十一偈：智悲双运，速得一切智位

```
ཤེས་རབ་ཐབས་ལ་གནས་གྱུར་པས། །སེམས་ཅན་ཀུན་ལ་བརྩེ་བར་བྱ། །ཐམས་ཅད་མཁྱེན་པའི་གོ་འཕང་མཆོག། །ལྷ་ཉིད་དུས་མི་རིང་བར་འཐོབ། །
```

由于安住于智慧与方便，要慈爱一切众生；殊胜的一切智果位，天尊（您）不久就会获得。

【按】第44句的“ལྷ”（天、天尊），在这里大概是对受教者的尊称，相当于“陛下”“尊者”。龙树的一些论著是写给国王的，本篇或许也是对某位国王所说。这一读法是推定的。

### 第十二偈：一切唯是名言

```
འདི་དག་ཐམས་ཅད་མིང་ཙམ་སྟེ། །ཐ་སྙད་ཙམ་དུ་རབ་ཏུ་འཇུག། །དངོས་པོ་མེད་ལ་ཐ་དད་པའི། །བརྗོད་བྱ་ཡོད་པ་མ་ཡིན་ཏེ། །
```

这一切都只是名称，只是以名言而运作；对于无实之物，并没有（可以）分别的所诠。

### 第十三偈：名中无名

```
བདག་ཉིད་གང་དང་གང་གིས་ནི། །ཆོས་རྣམས་གང་དང་གང་བརྟགས་པ། །དེ་ནི་དེ་ལ་ཡོད་མིན་ཏེ། །ཆོས་རྣམས་ཀྱི་ནི་ཆོས་ཉིད་དེ། །
མིང་གིས་མིང་ཉིད་སྟོང་པས་ན། །མིང་ལ་མིང་ནི་ཡོད་མ་ཡིན། །ཆོས་རྣམས་ཐམས་ཅད་མིང་མེད་པས། །མིང་ནི་བཏགས་པ་ཙམ་ཉིད་དོ། །
```

以任何名称、对任何法所假立的，那（名称所指的）在那（法）上并不存在，这就是诸法的法性。名称本身空于名称，名称之中没有名称；一切法都没有名称，名称只不过是假立而已。

【按】“名称空于名称”，意思是：名称本身也没有自性，并不是在名称之中有一个真实的“名称”存在。这与《金刚经》“所言某某，即非某某，是名某某”的意思相近。

### 第十四偈：连空性也是假立

```
མི་བདེན་པར་གྱུར་ཆོས་འདི་དག། །བརྟགས་པ་ཉིད་དུ་རབ་ཏུ་འཇུག། །གང་ལ་བརྟགས་པ་དེ་མེད་ན། །སྟོང་པ་ཉིད་དུ་བརྟགས་པ་གང་། །
```

这些不真实的法，只以假立而运作；所假立的（基础）如果不存在，那么被假立为“空性”的，又是什么呢？

【按】这几句的意思是：连“空性”本身也只是假立，并没有一个实有的空性可以执取。这是中观“空亦复空”的意思，防止把空性执为实有。

### 第十五偈：二谛

```
མིག་གིས་མཐོང་བའི་གཟུགས་རྣམས་ནི། །དེ་ཉིད་རིག་པ་ཞེས་དེ་བཤད། །འཇིག་རྟེན་ལོག་པའི་ང་རྒྱལ་ཅན། །ཀུན་རྫོབ་བདེན་པ་ཞེས་འདིར་འཇོག། །
གང་དུ་ཚོགས་པའི་རྐྱེན་མཐོང་བ། །འདྲེན་པ་གསལ་བར་གྱུར་པ་ཡིན། །བློ་དང་ལྡན་པས་དོན་དམ་ལ། །བརྟགས་ཏེ་གྲགས་པ་ངེས་པར་མཐོང་། །
```

眼睛所见的种种色，（有人）说那就是“通达真实”；世间颠倒而傲慢的人，在这里（把它）安立为世俗谛。在哪里见到聚合的众缘，导师（的教义）就在那里明白显现；具有智慧的人，对胜义加以观察，就必定看见（这只是）世间的共许。

【按】这八句的语法比较简略，意思不完全确定。大意可能是：世间人把眼见的色当作真实，这在中观中安立为世俗谛；了知诸法只是众缘聚合，就明白了佛陀的教义；以智慧观察胜义，就知道一切显现只是世间的共许，没有自性。这是依文意的推解。

### 第十六偈：眼不见色，意不知法

```
གཟུགས་ནི་མིག་གིས་མི་མཐོང་ཞིང་། །ཡིད་ཀྱིས་ཆོས་རྣམས་མི་རིག་པ། །འདི་ནི་མཆོག་ཏུ་བདེན་པ་སྟེ། །འཇིག་རྟེན་གང་གིས་ཀྱང་མི་ཤེས། །
```

色不被眼所见，法不被意所知，这才是最殊胜的真实，任何世间人都不能了知。

【按】这一偈非常著名。依译者所知，月称的《明句论》曾引用龙树论中意思相同的偈子，大意是：眼不见色，意不知法，这是最胜的真实，世间所不能入。说明胜义谛超越根识与分别的境界。此处出处是凭记忆所述，未及核对原文。

## 跋语

```
དངོས་པོ་སྦྱོང་བ་ཞེས་བྱ་བ་སློབ་དཔོན་ཆེན་པོ་འཕགས་པ་ཀླུ་སྒྲུབ་ཀྱི་ཞལ་སྔ་ནས་མཛད་པ་རྫོགས་སོ།། །།རྒྱ་གར་གྱི་མཁན་པོ་བཛྲ་པཱ་ཎི་དང་། བོད་ཀྱི་ལོ་ཙཱ་བ་རྨ་བན་ཆོས་འབར་གྱིས་བསྒྱུར་ཅིང་ཞུས་ཏེ་གཏན་ལ་ཕབ་པའོ།།
```

名为《事物修治》，大阿阇黎圣者龙树亲造，圆满。印度堪布金刚手与藏地译师玛班却巴翻译、校订并定稿。

## 通篇连读

（凡夫）把无实之物认作实有；然而无实之物，并没有生起。（认为事物）常常在生起，这正是执为实有；执为实有的迷乱，就像虚空中的花一样。

与虚空相等的诸法，它们的生起，也与虚空相等，这是最殊胜的（见解）。一切法在自性上都与虚空相等，所以，三有（的本性）就是殊胜的实义。

没有因，也没有果，业的自性并不存在；没有世间人，也没有世间，这一切都不是真实的。

既然不生，什么事物能从他者被了知呢？石女的儿子，那时也不会生起。

世间本来就没有生起，也不是任何人所化现的。这毫无实义的迷乱世间，就像“月贤城”一样。

世间是从分别中生起的，分别是从心中生起的；因为心是依于身而生起的，所以要对身体仔细观察。

色是空的，受没有自性；没有想，也没有行；没有心所，也没有实有之物。所以（一切）是无分别的自性。

所以，（它）不是心，也不是法；不是身，也不是界等等。这无二之道，是通达真如的人所宣说的。

这一切无所缘的法，以无所缘的方式来宣说；如果生起了无所缘的心，就会成为无所缘。

要依止布施、持戒、忍辱、精进，以及从禅定所生（的智慧）；不久就会获得无上菩提。

由于安住于智慧与方便，要慈爱一切众生；殊胜的一切智果位，天尊（您）不久就会获得。

这一切都只是名称，只是以名言而运作；对于无实之物，并没有（可以）分别的所诠。

以任何名称、对任何法所假立的，那（名称所指的）在那（法）上并不存在，这就是诸法的法性。名称本身空于名称，名称之中没有名称；一切法都没有名称，名称只不过是假立而已。

这些不真实的法，只以假立而运作；所假立的（基础）如果不存在，那么被假立为“空性”的，又是什么呢？

眼睛所见的种种色，（有人）说那就是“通达真实”；世间颠倒而傲慢的人，在这里（把它）安立为世俗谛。在哪里见到聚合的众缘，导师（的教义）就在那里明白显现；具有智慧的人，对胜义加以观察，就必定看见（这只是）世间的共许。

色不被眼所见，法不被意所知，这才是最殊胜的真实，任何世间人都不能了知。
