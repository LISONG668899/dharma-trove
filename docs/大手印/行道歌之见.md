# 行道歌之见

阿阇黎卢伊巴 传　阿阇黎吉拉巴 造

## 题解

本篇出自德格版丹珠尔续部（རྒྱུད་འགྲེལ།）ཟི 函第39b叶第6行至第40a叶第3行，东北目录编号 D2425。全篇二十五句，每句七个音节，以“对傲慢者没有胜者之道，卢伊巴这样说，守护身体的知足便能成就”三句为叠句，四次重复。篇幅很短，所以把藏文原文全部保留在代码块中，按段落分开，每段后附汉译，疑难之处另以【按】说明。

梵文题名：Caryā-dṛṣṭi-dohā-gītikā-nāma（ཙརྱ་དྲྀཥྚི་དོ་ཧ་གཱི་ཏི་ཀ་ནཱ་མ）。

藏文题名：དོ་ཧ་སྤྱོད་པའི་གླུའི་ལྟ་བ（道哈行歌之见）。

【按】跋语说本篇“由阿阇黎卢伊巴（ལཱུ་ཡི་པ）传下，阿阇黎吉拉巴（ཀི་ར་པ）所造”。卢伊巴是印度八十四大成就者中最著名的一位，常被列为第一。“吉拉巴”是音译，八十四大成就者中有一位名为 Kirapalapa（或作 Kilapa）的成就者，名字相近，但是否同一人无法确定。跋语没有记载译者。

【按】全篇的主旨，是批评只重外在形式的修行人：只重装束、只求灌顶、借瑜伽之名沉溺于睡眠饮酒争论，而心怀傲慢。作者以卢伊巴的话为证：对傲慢的人，没有成佛之道。这些批评针对的是“不证悟内义、只执外相”，并不是否定装束、灌顶等本身，读者须善加理解。

## 正文

### 第一段：外相装束如疯人

```
རྨ་བྱའི་གདུགས་བསྒྲེང་འཛིན་བྱེད་ཅིང་། །ཆ་བྱད་སྣ་ཚོགས་འཛིན་བྱེད་པའི། །རྣལ་འབྱོར་པ་ནི་སྨྱོན་པ་འདྲ། །
ང་རྒྱལ་ཅན་ལ་རྒྱལ་བའི་ལམ། །མེད་ཅེས་ལཱུ་ཡི་སྨྲ་བར་བྱེད། །ལུས་ཀྱི་ཚིམ་བུ་བསྲུངས་པས་གྲུབ། །
```

高举着孔雀翎的伞盖，佩戴着种种装束的瑜伽士，就像疯子一样。“对于心怀傲慢的人，并没有通往胜者的道路。”——卢伊巴这样说。守护身体的知足，便能成就。

【按】“རྨ་བྱའི་གདུགས”，“孔雀（翎）伞盖”，在印度，有些外道或瑜伽行者以孔雀翎作为伞盖、拂尘等装饰，表示身份。作者讥讽那些只重外表装束、标榜自己是瑜伽士的人，说他们就像疯子一样。

【按】“ང་རྒྱལ་ཅན་ལ་རྒྱལ་བའི་ལམ་མེད”，“对傲慢者没有胜者之道”，“རྒྱལ་བ”（胜者）指佛。“胜者之道”就是成佛之道。这一句与“傲慢”（ང་རྒྱལ）在藏文中有字音上的呼应（ང་རྒྱལ与རྒྱལ་བ），可能译自原文的双关，这里无法在汉文中保留。

【按】“ལཱུ་ཡི”，即卢伊巴（Lūipa），印度八十四大成就者之首，以食鱼肠而证悟著称。依跋语，本篇是由卢伊巴传下的道歌，作者在叠句中引卢伊巴的话为证。

【按】“ལུས་ཀྱི་ཚིམ་བུ་བསྲུངས་པས་གྲུབ”，是全篇叠句中最难解的一句。“ཚིམ”是“满足”“饱足”，“ཚིམ་བུ”字面大概是“知足”“满足”。这里译作“守护身体的知足，便能成就”，意思可能是：不追求外在的装束、仪式、享乐，只要对身体所需知足，安然守护此身，用它来修行，便能成就。另一种可能的理解是：守护身体（作为修行的所依），令其安适，便能成就，这与萨惹哈《民众道歌》中“未见有圣地像自身这样安乐”一类的说法相近。“ཚིམ་བུ”一词的确切意义，译者未能确定，也不能排除是其他词的传抄讹误，请读者留意。

### 第二段：多受灌顶而不证悟

```
དབང་བསྐུར་མང་པོ་བླང་བྱ་སྟེ། །དོན་མེད་པར་ནི་སླུ་བར་བྱེད། །དབང་བསྐུར་རྟོགས་པར་མ་གྱུར་ན། །
དུས་ཀྱི་དབང་དུ་འགྲོ་བ་ཡིན། །ང་རྒྱལ་ཅན་ལ་རྒྱལ་བའི་ལམ། །མེད་ཅེས་ལཱུ་ཡི་སྨྲ་བར་བྱེད། །
ལུས་ཀྱི་ཚིམ་བུ་བསྲུངས་པས་གྲུབ། །
```

要接受许多灌顶，（结果却只是）毫无意义地欺骗（自己和他人）。如果没有证悟灌顶（的真义），终究要落入死亡的掌控之中。“对于心怀傲慢的人，并没有通往胜者的道路。”——卢伊巴这样说。守护身体的知足，便能成就。

【按】这一段批评的是：只是一味地多求灌顶，而不去证悟灌顶所指示的真义。这并不是否定灌顶，相反，第三句明确说“如果没有证悟灌顶（的真义）”，可见作者重视的是灌顶的证悟。这一点必须特别说明，以免读者误以为灌顶可以不要。

【按】“དབང་བསྐུར་མང་པོ་བླང་བྱ་སྟེ”，“要接受许多灌顶”，语气可能带有讥讽，描写那些热衷于到处求灌顶的人；也可能是“虽然接受了许多灌顶”的意思。这里照字面译出，括号中的字是译者所补。

【按】“དུས་ཀྱི་དབང”，“时间的掌控”，“དུས”（时）在这里指死亡、无常（梵文 kāla 兼有“时间”与“死亡”二义），所以译作“死亡的掌控”。

### 第三段：沉溺睡酒争论，瑜伽难成

```
གཉིད་དང་ཆང་དང་རྩོད་པ་དང་། །སྦྱོར་བས་རྣལ་འབྱོར་ཇི་ལྟར་གྲུབ། །བཟློག་ན་སྲིད་པའི་ཞགས་པས་བཅིངས། །
ང་རྒྱལ་ཅན་ལ་རྒྱལ་བའི་ལམ། །མེད་ཅེས་ལཱུ་ཡི་སྨྲ་བར་བྱེད། །ལུས་ཀྱི་ཚིམ་བུ་བསྲུངས་པས་གྲུབ། །
```

沉溺于睡眠、饮酒和争论之中，瑜伽怎么可能成就呢？反而会被三有的绳索所束缚。“对于心怀傲慢的人，并没有通往胜者的道路。”——卢伊巴这样说。守护身体的知足，便能成就。

【按】“སྦྱོར་བས”，“以结合”“以从事”，这里读作“沉溺于（睡眠、饮酒、争论）”。“སྦྱོར་བ”在密乘中也可以指“合修”，那么这一句也可以读作“以睡眠、饮酒、争论以及合修（来修），瑜伽怎能成就”，是批评借密乘之名放纵欲乐的人。两种读法这里都保留，正文取前一种。

【按】“བཟློག་ན”，字面是“如果反转”，这里依文意读作“反而”。

### 第四段：等视陶碗与金勺，得遇诸佛

```
ཚང་དུས་ཁམ་ཕོར་གསེར་སྐྱོགས་ལྟར། །གལ་ཏེ་དེ་ལྟར་བྱས་པ་ན། །སངས་རྒྱས་རྣམས་དང་ཕྲད་པར་འགྱུར། །
ང་རྒྱལ་ཅན་ལ་རྒྱལ་བའི་ལམ། །མེད་ཅེས་ལཱུ་ཡི་སྨྲ་བར་བྱེད། །ལུས་ཀྱི་ཚིམ་བུ་བསྲུངས་པས་གྲུབ། །
```

在（一切）圆满的时候，（看待）陶碗就像金勺一样；如果能够这样做，就会与诸佛相会。“对于心怀傲慢的人，并没有通往胜者的道路。”——卢伊巴这样说。守护身体的知足，便能成就。

【按】“ཚང་དུས་ཁམ་ཕོར་གསེར་སྐྱོགས་ལྟར”，这一句非常简略，意思难以确定。“ཚང”是“圆满”“齐备”，“ཁམ་ཕོར”是陶土或粗糙的碗，“གསེར་སྐྱོགས”是黄金的勺子。最可能的意思是：对粗陋的陶碗与贵重的金勺平等看待，没有好坏取舍，也就是“一味”“平等”的境界；“圆满之时”可能是指证悟圆满之时，也可能只是“吃饭（饮食齐备）的时候”。这里依前一种意思译出，括号中的字是译者所补。

【按】与第一段对照来看：第一段讥讽重视孔雀伞盖等外在装饰的人，这一段则说视陶碗如金勺，两者正好相对，强调瑜伽士不应执著外在的贵贱好坏。
