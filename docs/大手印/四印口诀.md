# 四印口诀

阿阇黎无二金刚（梅纪巴）造　印度堪布金刚手、藏地译师比丘戒胜译　据藏文译出

## 题解

《四印口诀》（梵 Caturmudropadeśa，藏 phyag rgya bzhi'i man ngag）收于德格版丹珠尔续部释 ཞི 函第 211b 至 214b 页（东北目录 D2295）。跋文说是"阿阇黎无二金刚所作"，即梅纪巴（Maitrīpa，Advayavajra）；由印度堪布金刚手（梅纪巴的弟子）与藏地译师比丘戒胜（一般认为即那措译师）译出。

**结构：**全篇由显入密，次第分明。先说入口诀前须了知宗派：三乘、四种"住"（毗婆沙、经部、唯识、中观）、九类修行者，以及每类各自的观察、禅定、禅定之垢与见，其中还附有上师为弟子引入"无相"安住的方法（第一至六节）。次说密咒乘在诸宗中的位置——见地与"极无所住"中观相同，而方便殊胜（第七节）。再说五次第、两种"安慰"、以三性与金刚萨埵、大乐层层"印持"，并以四印配次第（第八、九节）。全篇的重心是业手印即灌顶，尤其是智慧智灌顶中四喜次第的三派之说（第十至十四节）。最后依次说明四印各自的四喜与所生之果：业手印生等流果，法手印生异熟果，大手印生离垢果，三昧耶手印生士用果，合为十六喜（第十五至十九节）。

**核心论题：俱生喜居第三。**作者批评"猛厉派"把俱生喜放在第四，次第与义理都不善巧；"劣派"虽把俱生放在第三，却把体验执为真实，与外道无别；只有"善派"次第与义理都正确。作者并说，续中虽有把俱生列在最后的说法，但"在数目上排第四，在义理上要配为第三"。这与梅纪巴在已译的《灌顶教示》（D2252）中的立场一致，罗摩波罗的《灌顶教示难释》（D2253）对此也有讨论，可以互相参看。本篇又说，大手印本身是"一刹那现证菩提"，并没有四刹那与四喜的区分，只是观待四印而安立四喜。

**与其他四印论著的关系：**本篇第十五节明说四印配四果之说出自"阿阇黎龙树"，指归于龙树名下的《四印决定》。本篇与已译的《境之实相修习》（D2294）都依四印次第讲修法，但两篇对"法手印""三昧耶手印"的界定不同，读者不可混同。

**关于密乘内容的告诫：**第十一至十四节讨论智慧智灌顶的三派之说，大量使用业手印修法的隐语（亲吻拥抱、搅动、宝珠、莲花、明点的位置等）；第五节有上师为弟子引入无相安住的方法与咒语。这些都属于无上瑜伽续的隐秘内容，只能在具德上师座前，依具足的灌顶与口授领受和修持，绝不可依文字自行理解或模仿。原文第 159–162 句是所引续文，其中说到智慧母的年岁，依本译体例略去不译，另附的藏文底本相应各句也只标"［略］"。咒语依体例保留藏文原文。

**体例说明：**各节标题后括号中的句号，对应另附的《四印口诀_藏文底本.txt》中的编号。按语中凡标"存疑"的，表示本译对原文意思没有把握。

## 三、观察、禅定、禅定之垢、见的定义（第 31–35 句）

```

རང་གི་འབྲས་བུ་ལ་བློས་ཡུལ་དུ་བྱེད་པའོ། །
```

"观察"，是依于闻、思的自己的各别观察之慧；"禅定"，是自己的修所成慧；"禅定之垢"，是它的直接违品；"见"，是被自己的慧所摄持的殊胜之处，以及心以自己的果为对境。

## 五、九类的禅定（第 50–66 句）

```
བསམ་གཏན་ནི་མི་སྡུག་པ་བསྒོམ་པ་དང་།
སྲོག་དང་རྩོལ་བ་བགྲང་བ་ལ་གནས་པ་དང་།
སྟོང་པ་ཉིད་ཀྱི་བདེན་པ་མར་མེ་བསད་པ་ལྟ་བུ་ཅི་ཡང་མི་སྣང་བ་ལ་སེམས་གནས་པ་དང་།
སྣའི་རྩེ་མོར་གནས་པ་དང་།
དཀྱིལ་འཁོར་བསྡུས་ནས་སེམས་གནས་པ་དང་།
སེམས་ཀྱི་རྣམ་པ་ལ་སེམས་གནས་པ་དང་།
རྣམ་པ་མེད་པ་ལ་གནས་པ་དང་གཟུགས་བརྙན་ལ་གནས་པ་དང་།
ཅིར་ཡང་མ་གྲུབ་པའི་ངོ་བོ་ཉིད་ལ་གནས་པའོ། །
```

禅定是：修习不净观；安住于数息与勤［息］；心安住于如灯熄灭一般、什么都不显现的空性之谛；安住于鼻尖；收摄坛城而使心安住；心安住于心的行相；安住于无相；安住于影像；安住于无论如何都不成立的体性。

【按】这九种禅定，依次对应前面所说的九类：不净观（下等声闻）、数息（中等声闻）、空如灯灭（上等声闻）、鼻尖（缘觉）、收摄坛城（经部）、心之行相（有相唯识）、无相（无相唯识）、影像（如幻中观）、无所成立（极无住中观），这是依次序推定的，存疑。"数息与勤［息］"，原文 སྲོག་དང་རྩོལ་བ（命与勤，即 prāṇa 与 āyāma），指调息、数息的修法。

```
དེ་ལ་སེམས་ཀྱི་རྣམ་པ་ལ་གནས་པར་བྱ་བ་ནི་དང་པོར་ཅི་ཡང་རུང་བ་ལ་ཤེས་པ་གཏད།
དེ་ཉིད་སེམས་ཙམ་དུ་ཤེས་པར་བྱས་ཏེ་གནས་པའོ། །
```

其中，安住于心的行相的方法是：先把识投注在任何［一个对象］上，再了知它只是心，而安住。

```
རྣམ་པ་མེད་པ་ལ་གནས་པ་ནི་ཐོག་མར་མཆོད་པ་ལ་སོགས་པ་བྱས་ཏེ།
སློབ་མ་སྟན་ལ་བཞག་ལ་དབུགས་སོར་བཅུག་སྟེ།
ཐོག་མར་མེ་ཏོག་ལྟ་བུ་ལ་ཤེས་པ་གཏོང་དུ་བཅུག་ནས་ལག་པ་སྤྱི་བོར་བཞག་ལ་སྔགས་འདི་བརྗོད་དོ། །
```

安住于无相的方法是：先作供养等，让弟子坐在座上，使呼吸调匀；先让［他］把识投注在像花一类的［对象］上，［上师］把手放在［他的］头顶，诵这个咒：

```
ཨོཾ་ཨ་ར་ར་ཧཱུཾ་ཧཱུཾ།
ཨོཾ་བཛྲ་ཡོ་གི་ནཱི་ཨ་དྷི་ཏིཥྛ་ཧཱུཾ་ཕཊ།
ཅེས་པའི་མགོར་རང་གི་ཡི་དམ་གྱི་སྔགས་བརྗོད་དོ། །
དེ་ནས་མེ་ཏོག་ཀྱང་མེད་པར་བྱས་ན་མྱུར་དུ་སྐྱེའོ། །
```

在这［咒］的前面，诵自己本尊的咒。之后，连花也撤去，［无相的禅定］就会迅速生起。

【按】这段说的是上师为弟子直接引入"无相"安住的方法，咒语依体例保留藏文原文，不作音译与意译。这一修法须依具德上师亲自传授，不可依文字自行模仿。

## 六、禅定之垢、见与悲心（第 67–73 句）

```
བསམ་གཏན་གྱི་དྲི་མ་རྣམས་དང་།
ལྟ་བ་རྣམས་ནི་གཞན་ནས་གསལ་བས་འདིར་མ་བརྗོད་དོ། །
```

禅定之垢与见，在别处已经明说，这里就不说了。

```
དེ་ལྟར་ན་མི་མཁས་པ་རབ་རིབ་ཅན་དང་།
མཁས་པ་རབ་རིབ་མེད་པའོ། །
```

这样，不智者是有眼翳的，智者是没有眼翳的。

```
དེ་དག་གི་སྙིང་རྗེ་ཡང་སེམས་ཅན་ལ་དམིགས་པ་དང་།
ཆོས་ལ་དམིགས་པ་དང་།
དམིགས་པ་མེད་པའོ། །
```

他们的悲心，也有缘众生的、缘法的与无所缘的［三种］。

【按】"不智者有眼翳"，大概是说较低的宗派见地仍有所执，如同眼有翳障，存疑。"缘众生、缘法、无所缘"，是大乘所说的三种悲心。

## 七、密咒乘在诸宗中的位置与殊胜（第 74–84 句）

```
དེ་ལ་གསང་སྔགས་ཀྱི་ཐེག་པ་ནི་ཐེག་པ་གསུམ་ལས་ནི་ཐེག་པ་ཆེན་པོའོ། །
གནས་པ་ནི་ཕྱི་མ་གཉིས་སོ། །
སྦྱོར་བ་ནི་ཐ་མ་བཞི་ལའོ། །
དེ་ལ་སློབ་དཔོན་ཉིད་ཀྱི་གཞུང་གིས་ནི་རབ་ཏུ་མི་གནས་པར་སྦྱོར་བའོ། །
```

密咒乘，在三乘之中属于大乘；在［四种］"住"中，属于后两种；在［九种］"类"中，属于最后四种。依阿阇黎自己的论典，是与"极无所住"相配合的。

```
དེ་ལྟ་ན་ཡང་དེ་དང་ཐམས་ཅད་དུ་ཁྱད་མེད་པ་ནི་མ་ཡིན་ཏེ།
ཇི་སྐད་དུ།
དོན་གཅིག་ན་ཡང་མ་རྨོངས་དང་། །
ཐབས་མང་དཀའ་བ་མེད་པ་དང་། །
དབང་པོ་རྣོན་པོས་དབང་བྱས་ཕྱིར། །
སྔགས་ཀྱི་ཐེག་པ་ཁྱད་པར་འཕགས། །
ཞེས་གསུངས་པས་དེ་བརྗོད་པར་བྱ་སྟེ།
```

虽然如此，也不是与它们在一切方面都没有差别，如经中所说："虽然义理相同，但不愚昧，方便众多，没有难行，由利根者所驾驭，所以咒乘殊胜。"既然这样说，就要宣说那［殊胜之处］：

【按】"阿阇黎自己的论典"，可能指作者自己（无二金刚）的其他论著，也可能指龙树等，存疑。"虽然义理相同"一偈，是印度晚期论著（如三藏宝鬘的《三理灯论》）中常被引用的名偈，说明密咒乘与波罗蜜多乘见地相同而方便殊胜。

## 八、五次第、两种安慰与四重印持（第 85–95 句）

```
ཕྱི་བསྐྱེད་པའི་རིམ་པ་དང་།
ཟབ་མོ་བསྐྱེད་པའི་རིམ་པ་དང་།
རྫོགས་པའི་རིམ་པ་དང་།
ཡོངས་སུ་རྫོགས་པའི་རིམ་པ་དང་།
ངོ་བོ་ཉིད་ཀྱི་རིམ་པའོ། །
```

［这就是：］外生起次第、甚深生起次第、圆满次第、究竟圆满次第、自性次第。

```
ཡང་དེ་བཞིན་གཤེགས་པའི་དབུགས་དབྱུང་བ་དང་།
རྡོ་རྗེ་འཆང་གི་དབུགས་དབྱུང་བའོ། །
```

又有：如来的安慰，金刚持的安慰。

```
ཡང་ཀུན་བརྟགས་ལ་གཞན་དབང་གི་རྒྱ་དང་།
གཞན་དབང་ལ་ཡོངས་སུ་གྲུབ་པ་དང་།
ཡོངས་སུ་གྲུབ་པ་ལ་རྡོ་རྗེ་སེམས་དཔའ་དང་།
དེ་ཉིད་ལ་བདེ་བ་ཆེན་པོས་རྒྱས་གདབ་པའོ། །
```

又有：以依他起来印持遍计所执，以圆成实来印持依他起，以金刚萨埵来印持圆成实，以大乐来印持那［金刚萨埵］。

【按】"安慰"，原文 དབུགས་དབྱུང་བ（梵 āśvāsa，"使松一口气、使安心"），这里似指修道中两个层次的安住或证得，确切所指待考，存疑。"遍计所执、依他起、圆成实"，是唯识三性；这里以层层"印持"的方式，由三性上升到金刚萨埵与大乐。

## 九、以四印配次第与印持（第 96–105 句）

```
ཡང་ཕྱག་རྒྱ་བཞི་ལས་རྟོགས་པར་བྱ་སྟེ།
ལས་ཀྱི་ཕྱག་རྒྱ་ནི་ཟབ་མོ་བསྐྱེད་པའི་རིམ་པ་དང་།
རྫོགས་པའི་རིམ་པའོ། །
ཆོས་ཀྱི་ཕྱག་རྒྱ་ནི་ཡོངས་སུ་རྫོགས་པའི་རིམ་པའོ། །
ཕྱག་རྒྱ་ཆེན་པོ་ནི་ངོ་བོ་ཉིད་ཀྱི་རིམ་པའོ། །
དམ་ཚིག་གི་ཕྱག་རྒྱ་ནི་ཕྱི་བསྐྱེད་པའི་རིམ་པའོ། །
```

又要从四印来了解：业手印，是甚深生起次第与圆满次第；法手印，是究竟圆满次第；大手印，是自性次第；三昧耶手印，是外生起次第。

```
ཀུན་བརྟགས་ལ་གཞན་དབང་གི་རྒྱ་ནི་ཕྱི་བསྐྱེད་པའི་རིམ་པའོ། །
ཡོངས་སུ་གྲུབ་པའི་རྒྱ་ནི་ལྷ་ཐམས་ཅད་ཀྱང་རྣམ་པར་རིག་པ་ཙམ་མོ། །
རྡོ་རྗེ་སེམས་དཔའི་རྒྱ་ནི་རྣམ་རིག་སྟོང་པ་ཉིད་དུ་ཤེས་པའོ། །
བདེ་བ་ཆེན་པོའི་རྒྱ་ནི་དེ་ཉིད་མན་ངག་ཉམས་སུ་མྱང་བར་བྱས་པའོ། །
```

以依他起印持遍计所执，就是外生起次第；圆成实之印，是［了知］一切本尊也只是识；金刚萨埵之印，是了知识就是空性；大乐之印，是亲身体验那口诀。

## 十、业手印即灌顶：瓶灌顶与秘密灌顶（第 106–114 句）

```
ལས་ཀྱི་ཕྱག་རྒྱ་ནི་དབང་གི་ངོ་བོ་སྟེ།
དེ་ཡང་བུམ་པ་དང་།
གསང་བ་དང་།
ཤེས་རབ་ཡེ་ཤེས་དང་།
བཞི་པའོ། །
```

业手印，是灌顶的体性，即：瓶灌顶、秘密灌顶、智慧智灌顶与第四灌顶。

```
བུམ་པ་ནི་སློབ་དཔོན་གྱི་དབང་མན་ཆད་དེ།
ལུས་དག་པར་བྱེད་པའོ། །
གསང་བ་ནི་ཐབས་ཤེས་རབ་གཉིས་ལས་བྱུང་བའི་བྱང་ཆུབ་ཀྱི་སེམས་སྟེར་བ་སྟེ།
ངག་དག་པར་བྱེད་པའོ། །
```

瓶灌顶，是阿阇黎灌顶以下［诸灌顶］，能清净身。秘密灌顶，是授予由方便与智慧二者所生的菩提心，能清净语。

## 十一、智慧智灌顶的三种说法之一：猛厉派（第 115–139 句）

```
ཤེས་རབ་ཡེ་ཤེས་ནི་གསུམ་སྟེ།
དྲག་པོ་དང་།
ངན་པ་དང་།
བཟང་པོའོ། །
```

智慧智灌顶［的解说］有三种：猛厉派、劣派、善派。

```
དེ་ལ་དྲག་པོ་ནི་འོ་དང་འཁྱུད་པ་ནས་བརྩམས་ཏེ་ཕྱི་རོལ་གྱི་བྱ་བ་ནི་དགའ་བ་སྟེ།
རྣམ་པ་སྣ་ཚོགས་སོ། །
བསྲུབ་པ་དང་སྲུབས་པའི་སྦྱོར་བ་ནི་རྣམ་པར་སྨིན་པ་སྟེ་མཆོག་དགའོ། །
རིན་པོ་ཆེར་ཉམས་སུ་མྱོང་བ་ནི་མཚན་ཉིད་དང་བྲལ་བ་སྟེ་དགའ་བྲལ་ལོ། །
པདྨར་ལྷུང་བ་ནི་རྣམ་པར་ཉེད་པ་སྟེ།
ལྷན་ཅིག་སྐྱེས་པའོ་ཞེས་འདོད་པ་སྟེ་ལུང་དང་འགལ་བའོ། །
```

其中，猛厉派的主张是：从亲吻拥抱开始的外在行为是"种种"，即"喜"；搅动与被搅动的结合是"异熟"，即"胜喜"；在宝［珠］中体验，是"离相"，即"离喜"；落入莲花，是"揉灭"，即"俱生"——这与经教相违。

```
ལུང་ལས་མཆོག་དགའ་བྲལ་དགའ་དབུས་དག་ཏུ། །
མཚོན་བྱ་ཤེས་ནས་བརྟགས་པར་གྱིས། །

```

所以，这里猛厉派的结合，对于次第与义理二者都不善巧。

【按】"种种、异熟、揉灭、离相"，是《喜金刚》系统所说的四刹那（梵 vicitra、vipāka、vimarda、vilakṣaṇa）。本段及以下讨论的核心问题是：俱生喜应排在四喜的第三还是第四。作者主张"俱生在胜喜与离喜之间"，即第三，与梅纪巴在《灌顶教示》（D2252）中的立场相合；罗摩波罗的《灌顶教示难释》（D2253）对此也有讨论，可以参看。所引"在胜喜与离喜的中间"等经句，应出自《喜金刚续》，存疑。"宝［珠］"（རིན་པོ་ཆེ）、"莲花"、"搅动"等，都是密续中业手印修法的隐语，须依灌顶与口授，不可照字面理解或模仿。

## 十二、智慧智灌顶的三种说法之二：劣派（第 140–148 句）

```
ད་ནི་དབང་བསྐུར་ངན་པ་བརྗོད་པར་བྱ་སྟེ།
འོ་དང་འཁྱུད་པ་ལ་སོགས་པ་ཕྱི་རོལ་གྱི་བྱ་བ་ནི་རྣམ་པ་སྣ་ཚོགས་ཏེ་དགའ་བའོ། །
བསྲུབ་པ་དང་སྲུབས་པའི་སྦྱོར་བ་ནི་རྣམ་པར་སྨིན་པ་སྟེ་མཆོག་དགའོ། །
རིན་པོ་ཆེར་ཉམས་སུ་མྱོང་བ་ནི་མཚན་ཉིད་བྲལ་བ་སྟེ་ལྷན་ཅིག་སྐྱེས་པའོ། །
པདྨར་ལྷུང་བ་ནི་རྣམ་པར་ཉེད་པ་སྟེ་དགའ་བྲལ་ལོ་ཞེས་འདོད་པ་སྟེ།
```

现在说劣派的灌顶［解说］：亲吻、拥抱等外在行为是"种种"，即"喜"；搅动与被搅动的结合是"异熟"，即"胜喜"；在宝［珠］中体验，是"离相"，即"俱生"；落入莲花，是"揉灭"，即"离喜"——这样主张，

```
མུ་སྟེགས་པ་དང་ཁྱད་མེད་པའོ། །
ཅིའི་ཕྱིར་ཞེ་ན།
ཉམས་སུ་མྱོང་བ་ལ་ཡང་དག་པར་འཛིན་པའི་ཕྱིར་རོ། །
དེ་ནི་གོ་རིམ་ལ་མཁས་ཀྱང་དོན་ལ་མི་མཁས་པའོ། །
```

与外道没有差别。为什么呢？因为把体验执为真实。这一派虽然善巧次第，却不善巧义理。

【按】劣派在名目次第上已把"俱生"放在第三，与作者的主张相同；作者批评它的，是把业手印中的体验执为真实，所以说"与外道无别""善巧次第而不善巧义理"。

## 十三、智慧智灌顶的三种说法之三：善派（第 149–172 句）

```
ད་ནི་དབང་བསྐུར་བཟང་པོ་བརྗོད་པར་བྱ་སྟེ།
འདིའི་ལུགས་ཀྱིས་དགའ་བ་བཞི་ནི་འདི་ལྟར་ཤེས་པར་བྱ་སྟེ།
ཕྱི་རོལ་གྱི་བྱ་བ་ནས་བསྐྱོད་པའི་མཐར་ཐུག་པ་ནི་རྣམ་པ་སྣ་ཚོགས་པའི་དགའ་བའོ། །
རིན་པོ་ཆེའི་མཐར་ཐུག་པ་ཉམས་སུ་མྱོང་བ་ནི་རྣམ་པར་སྨིན་པ་སྟེ་མཆོག་དགའོ། །
```

现在说善派的灌顶［解说］：依这一宗，四喜要这样了知：从外在行为直到动摇的究竟，是"种种"之喜；体验到宝［珠］的究竟，是"异熟"，即"胜喜"。

```
བཅོམ་ལྡན་འདས་ཀྱིས།
བཅུ་དྲུག་ཕྱེད་ཕྱེད་ཐིག་ལེ་ཅན། །
ཞེས་བྱ་བའི་ཐིག་ལེ་བཞིའི་གཟུགས་ཀྱིས་བཞུགས་པ་ལས་གཉིས་ནི་རྡོ་རྗེ་རྩེ་མོའི་ཆ་ལ་གནས།
གཉིས་ནི་པདྨའི་ཟེའུ་འབྲུའི་ཆ་ལ་གནས་པའི་མཚན་ཉིད་དང་བྲལ་བ་སྟེ་ལྷན་སྐྱེས་པའོ། །
```

薄伽梵［在续中］说"具有十六的半之半的明点"——［明点］以四个明点的形相而住，其中两个住于金刚尖端的部分，两个住于莲花蕊的部分，这是"离相"，即"俱生"。

```
ཐིག་ལེ་བཞི་ཆར་ཡང་པདྨའི་ཆ་ལ་གནས་པ་ནི་རྣམ་པ་མེད་པ་སྟེ་དགའ་བྲལ་ལོ། །
```

四个明点全都住于莲花部分，是"无相"，即"离喜"。

```
དེ་ཡང་།
```

又［续中说］：

［第 159–162 句，所引续文四句说的是阿阇黎灌顶，其中说到智慧母的年岁，依本译体例略去不译。］

```
ཞེས་པ་དང་།
དབང་ནི་བཞི་ཡི་གྲངས་ཀྱིས་ཀྱང་། །
དགའ་བ་ལ་སོགས་རིམ་ཤེས་བྱ། །
ཞེས་པ་དང་།
```

以及［续中说］："就灌顶的四数而言，也要依次了知喜等。"

```
ཐམས་ཅད་གསང་བའི་རྒྱུད་ལས་ཀྱང་། །
གཉིས་ཤོར་གཉིས་ནི་མཉམ་པའི་དབུས། །
རྡོ་རྗེ་ནས་ནི་པདྨར་རེག །
རྒྱུ་ལ་འབྲས་བུས་རྒྱས་གདབ་ཅིང་། །
འདི་ནི་བདེ་ཆེན་རྒྱལ་པོའོ། །
ཞེས་གསུངས་སོ། །
```

《一切秘密续》中也说："二者［明点］失去，二者在平等的中央，从金刚触及莲花，以果印持因，这是大乐之王。"

【按】"具有十六的半之半的明点"（བཅུ་དྲུག་ཕྱེད་ཕྱེད་ཐིག་ལེ་ཅན），是《喜金刚续》中的名句，注家多解为以十六分之四分（即四个明点）来表示四喜，这里依本篇的解释译出。善派的要点是：以明点在金刚与莲花之间的位置来区分四喜，并以"俱生"居于第三。"《一切秘密续》"（ཐམས་ཅད་གསང་བའི་རྒྱུད），所引偈颂第一句"二者失去，二者在平等的中央"文意难解，存疑。本段全是圆满次第中明点修持的隐语，须依灌顶与口授，不可照字面理解或模仿。

## 十四、三派的总评；第四灌顶（第 173–180 句）

```
དེ་ལྟར་ན་དྲག་པོའི་སྦྱོར་བ་ནི་མི་བསྐྱོད་པའི་རྒྱ་དང་བྲལ་ལ་དབང་བསྐུར་ངན་པ་ནི་རྡོ་རྗེ་སེམས་དཔའི་རྒྱ་དང་བྲལ་ཞིང་རྡོ་རྗེ་འཆང་གི་དབུགས་དབྱུང་བ་དང་བྲལ་བའོ། །
འདིར་རྡོ་རྗེ་སེམས་དཔས་མི་བསྐྱོད་པ་ལ་རྒྱས་བཏབ་པ་ནི་དབུ་མའི་ལམ་མོ། །
```

这样，猛厉派的结合，离开了不动［佛］之印；劣派的灌顶［解说］，离开了金刚萨埵之印，也离开了金刚持的安慰。在这里［善派］，以金刚萨埵来印持不动［佛］，就是中道。

```
དེ་ཡང་ལུང་ལས་མདོར་བསྟན་པ་དང་།
རྒྱས་པར་བསྟན་པ་དང་།
ཤིན་ཏུ་རྒྱས་པར་བསྟན་པ་སྟེ།
དེ་དག་ནི་དབང་གི་འགྲེལ་པ་ཉིད་ན་གསལ་བས་འདིར་མ་བྲིས་སོ། །
```

这在经中有略说、广说与极广说，这些在灌顶的注释中已经明说，这里就不写了。

```
དེ་ནི་ཤེས་རབ་ཡེ་ཤེས་ཀྱི་དབང་སྟེ་ཡིད་དགའ་བར་བྱེད་པའོ། །
བཞི་པ་ནི་ཤེས་རབ་ཡེ་ཤེས་ཀྱི་རང་བཞིན་དགའ་བ་གསུམ་དང་ཐ་མི་དད་པ་རྟེན་འབྲེལ་གྱི་ངོ་བོར་ཟུང་དུ་འཇུག་པ་ནི་བཞི་པའོ། །
```

这就是智慧智灌顶，能令意欢喜。第四［灌顶］，是智慧智的自性，与三喜无异，以缘起的体性而双运——这就是第四［灌顶］。

【按】"以金刚萨埵来印持不动"，与前面第八节"以金刚萨埵印持圆成实"等四重印持相呼应。"灌顶的注释"，可能指作者另作的灌顶释论，或指梅纪巴系统的《灌顶教示》及其释论，存疑。

## 十五、业手印生等流果（第 181–182 句）

```
དེ་དག་ནི་ལས་ཀྱི་ཕྱག་རྒྱ་སྟེ།
རྒྱུ་མཐུན་པའི་འབྲས་བུ་སྐྱེད་པར་བྱེད་དོ་ཞེས་སློབ་དཔོན་ཀླུ་སྒྲུབ་ཀྱིས་བཤད་དོ། །
```

这些就是业手印，生起等流果——阿阇黎龙树这样说。

【按】以四印配四果——业手印配等流果、法手印配异熟果、大手印配离垢果、三昧耶手印配士用果——是归于龙树名下的《四印决定》（Caturmudrāniścaya）中的说法，本篇下文依次说明。

## 十六、法手印及其四喜；异熟果（第 183–191 句）

```
ཆོས་ཀྱི་ཕྱག་རྒྱ་ནི་སྣང་གྲགས་ཀྱི་ཆོས་སྣ་ཚོགས་སུ་སྣང་བ་ཉིད་དེ།
```

法手印，就是显现与声音之法以种种的形相显现。

```
དེ་ཡང་ལས་ཀྱི་ཕྱག་རྒྱའི་ལྷན་ཅིག་སྐྱེས་པ་ཉིད་ལས་གྲོལ་བ་སྣ་ཚོགས་ཀྱི་རྟོག་པ་འབྱུང་བ་དང་།
སྣ་ཚོགས་ཀྱི་རྟོག་པ་འགགས་ཤིང་ལྷན་ཅིག་སྐྱེས་པའི་གཟུགས་སུ་གནས་པ་དང་།
སྣ་ཚོགས་དང་ལྷན་ཅིག་སྐྱེས་པ་ཉིད་དུ་མེད་པ་དང་།
སྣ་ཚོགས་དང་ལྷན་ཅིག་སྐྱེས་པ་གཉིས་ཀའི་རྟོག་པ་མི་དམིགས་པ་དང་བཞི་ནི་ཆོས་ཀྱི་ཕྱག་རྒྱའི་དགའ་བ་དང་།
མཆོག་དགའ་དང་།
ལྷན་ཅིག་སྐྱེས་དགའ་དང་།
དགའ་བྲལ་ལོ། །
```

也就是：从业手印的俱生本身中解脱出来，生起种种的分别；种种的分别止息，而安住于俱生之形；种种与俱生本身都没有；种种与俱生二者的分别都不可得——这四者，就是法手印的喜、胜喜、俱生喜与离喜。

```
དེས་ན་ཆོས་ཀྱི་ཕྱག་རྒྱ་ནི་དངོས་པོ་མ་བཅོས་པའི་རང་བཞིན་ལས་མ་བཅོས་པའི་ཕྱག་རྒྱ་ཆེན་པོ་སྐྱེ་བའི་ཕྱིར་རྣམ་པར་སྨིན་པའི་འབྲས་བུ་ཞེས་བརྗོད་དོ། །
```

所以，法手印由于从事物未经造作的自性中，生起未经造作的大手印，所以称为"异熟果"。

## 十七、大手印：离垢果，一刹那现证菩提（第 192–207 句）

```
ཕྱག་རྒྱ་ཆེན་པོ་ནི་ཆོས་ཐམས་ཅད་སྐྱེ་བ་མེད་པའི་ངོ་བོ་ཟུང་དུ་འཇུག་པ།
གཟུང་བ་དང་འཛིན་པའི་རྟོག་པ་དང་བྲལ་བ་དང་།
ཉོན་མོངས་པ་དང་ཤེས་བྱ་ལ་སོགས་པའི་སྒྲིབ་པ་སྤངས་པ།
ཇི་ལྟ་བ་བཞིན་དུ་རང་གི་མཚན་ཉིད་ཉམས་སུ་མྱོང་བ་སྟེ།
དྲི་མ་མེད་པའི་འབྲས་བུར་བརྗོད་དོ། །
```

大手印，是一切法无生之体性的双运，离开能取与所取的分别，舍弃了烦恼障与所知障等，如实地体验自相——称为"离垢果"。

```
དེའི་ངོ་བོ་ནི་མཐའ་དབུས་ཀྱི་ཆོས་ཐམས་ཅད་གཟུགས་ཅན་མ་ཡིན་པ་དང་།
ཐམས་ཅད་དུ་ཁྱབ་པ་དང་མི་འགྱུར་བ་དང་།
དུས་ཐམས་ཅད་པའོ། །
```

它的体性是：边与中的一切法都不是有色的，遍于一切，不变，贯通一切时。

```
དེས་ན་ཕྱག་རྒྱ་ཆེན་པོ་ནི་སྐད་ཅིག་མ་གཅིག་ལ་མངོན་པར་སངས་རྒྱས་པ་སྟེ།
སྐད་ཅིག་མ་བཞི་དང་།
དགའ་བ་བཞི་དབྱེ་བ་ནི་མེད་དོ། །
```

所以，大手印是在一刹那中现证菩提，没有四刹那与四喜的区分。

```
འོན་ཀྱང་ཕྱག་རྒྱ་བཞི་ལ་ལྟོས་ནས་དགའ་བ་བཞི་བཞག་སྟེ་ལས་ཀྱི་ཕྱག་རྒྱ་ནི་དགའ་བའོ། །
ཆོས་ཀྱི་ཕྱག་རྒྱ་ནི་མཆོག་ཏུ་དགའ་བའོ། །
ཕྱག་རྒྱ་ཆེན་པོ་ནི་ལྷན་ཅིག་སྐྱེས་པའི་དགའ་བའོ། །
དམ་ཚིག་གི་ཕྱག་རྒྱ་ནི་དགའ་བྲལ་ལོ། །
```

然而，观待于四印而安立四喜：业手印是喜，法手印是胜喜，大手印是俱生喜，三昧耶手印是离喜。

```
དེ་ཉིད་ཇི་ལྟ་བ་བཞིན་ཆོས་ཀྱི་འཁོར་ལོའི་དུས་སུ་བླ་མའི་ཞལ་ལ་ལྟོས་པར་བྱའོ། །
```

这一义理究竟如何，要在转法轮之时，观待上师亲口［的教授］。

【按】这里四印配四喜的次第是"业手印、法手印、大手印、三昧耶手印"，与四印通常的排列次第不同，与本篇"俱生居第三"的主张一致：大手印配俱生喜，排在第三。

## 十八、三昧耶手印及其四喜；士用果（第 208–217 句）

```
དམ་ཚིག་གི་ཕྱག་རྒྱ་ནི་དེ་ཁོ་ན་ཉིད་མཚོན་པར་བྱེད་པ་འབྲས་བུ་ལྷའི་དཀྱིལ་འཁོར་ཏེ།
དེ་ཡང་རྗེ་བཙུན་གྱིས་ཐབས་མཚོན་པ་དང་།
རྗེ་བཙུན་མས་ཤེས་རབ་མཚོན་པ་དང་།
འཁྱུད་པས་གཉིས་སུ་མེད་པ་མཚོན་པའི་ཕྱིར་དམ་ཚིག་གོ། །
```

三昧耶手印，是表示真如的果——本尊坛城。也就是：［男］尊表示方便，［女］尊表示智慧，拥抱表示无二，所以称为"三昧耶"。

```
དེ་ཡང་བསྐྱེད་པའི་རིམ་པ་བདུན་པོ་དག་པར་བྱས་ནས་རྒྱུའི་ཧེ་རུ་ཀ་བསྐྱེད་པ་དང་།
ལྷ་མོའི་འཁོར་ལོ་སྤྲོ་བ་དང་།
ཉི་མ་དང་ཟླ་བར་ཐིག་ལེའི་གཟུགས་སུ་ཞུ་བ་དང་།
ལྷ་མོའི་དབྱངས་ཀྱིས་བསྐུལ་བ་དང་།
འབྲས་བུ་རྡོ་རྗེ་འཛིན་པར་གྱུར་པ་ནི་དམ་ཚིག་གི་ཕྱག་རྒྱའི་དགའ་བ་བཞི་སྟེ་གོ་རིམ་བཞིན་ནོ། །
```

也就是：清净了七种生起次第之后，生起因嘿汝嘎，放出天女之轮，［本尊］在日月中融化为明点之形，以天女之歌劝请，成为果金刚持——这就是三昧耶手印的四喜，依次第［而配］。

```
འབྲས་བུ་ལྷའི་འཁོར་ལོ་འདི་ནི་འགྲོ་བའི་དོན་འཛིན་པར་བྱེད་པས་སྐྱེས་བུ་བྱེད་པའི་འབྲས་བུ་བརྗོད་དོ། །
```

这果本尊之轮执持众生的利益，所以称为"士用果"。

【按】"男尊、女尊、拥抱"，是本尊双运像的象征，表示方便与智慧无二。"七种生起次第"，所指待考。第 212–216 句列出的步骤有五项（生起因嘿汝嘎、放出天女轮、融化、劝请、成为果金刚持），如何配四喜原文没有说明，存疑。

## 十九、结语与跋文（第 218–221 句）

```
དེ་ལྟར་ན་ཕྱག་རྒྱ་བཞི་ལ་དགའ་བ་བཞི་བཞི་སྟེ་བཅུ་དྲུག་ཏུ་ཤེས་པར་བྱའོ། །
```

这样，四印各有四喜，要了知为十六［喜］。

```
ཕྱག་རྒྱ་བཞིའི་མན་ངག་སློབ་དཔོན་གཉིས་མེད་རྡོ་རྗེས་མཛད་པ་རྫོགས་སོ།། །།
རྒྱ་གར་གྱི་མཁན་པོ་བཛྲ་པཱ་ཎི་དང་།
བོད་ཀྱི་ལོ་ཙཱ་བ་དགེ་སློང་ཚུལ་ཁྲིམས་རྒྱལ་བས་བསྒྱུར་བའོ།།
```

《四印口诀》，阿阇黎无二金刚所作，圆满。印度堪布金刚手与藏地译师比丘戒胜译出。

【按】"无二金刚"（Advayavajra），即梅纪巴。"金刚手"（Vajrapāṇi），是梅纪巴的弟子，曾到西藏传授大手印。"比丘戒胜"（ཚུལ་ཁྲིམས་རྒྱལ་བ），一般认为即那措译师。
