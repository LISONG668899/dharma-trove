# 无二根本修习次第

阿阇黎那波 传　阿阇黎尼拉康达 造

## 题解

本篇出自德格版丹珠尔续部（རྒྱུད་འགྲེལ།）ཟི 函第38a叶第4行至第38b叶第2行，东北目录编号 D2422。全篇是一首恰雅歌（行歌）体的密乘道歌，每句七个音节，有反复出现的叠句。篇幅很短，所以把藏文原文保留在代码块中，按段落分开，每段后附汉译，疑难之处另以【按】说明。

梵文题名：Advaya-nirika-bhāvanā-krama（ཨ་དྭ་ཡ་ནི་རི་ཀ་བྷ་བ་ན་ཀྲ་མ），拼写似有讹变，照录不改。

藏文题名：གཉིས་མེད་ཀྱི་རྩ་བསྒོམ་པའི་རིམ་པ（修习无二之根本的次第）。

【按】藏文题名中的“རྩ”有两种意思：一是“根本”，二是“脉”（如“脉、气、明点”的脉）。本篇的标题依通行译名作“无二根本修习次第”；但若读作“修习无二之脉的次第”，在密乘的语境中也说得通。正文中并没有讲到脉的修法，所以这里取“根本”之义。

【按】跋语说本篇“由阿阇黎那波（ནག་པོ）传下，阿阇黎尼拉康达（ནི་ལ་ཁན་དྷ）所造”。“那波”意为“黑者”，即著名的成就者黑行者（Kṛṣṇa、Kāṇha），恰雅歌集中有许多署名于他的道歌。“尼拉康达”是音译，梵文可能是 Nīlakaṇṭha（青颈），其生平不详。跋语没有记载译者。

【按】本篇是以密乘隐语写成的道歌，表面上的“沉醉”“失去种姓”“毁灭亲眷”“拥抱”等语，都是比喻证悟的境界与智慧方便的无二，不能照字面去理解。

【按】本篇有四句（第38a叶第6至7行），描写涉及未成年人，本译依原则略去不录，藏文也不录，在相应位置另作说明。其余诸句全部照录照译。

## 礼敬

```
གཉིས་མེད་བདེ་ཆེན་ལ་ཕྱག་འཚལ་ལོ། །
```

## 正文

### 第一段：平等性中失落珍宝

```
མཉམ་པ་ཉིད་ཀྱི་ཀློང་དཀྱིལ་དུ། །མྱོས་པས་དབྱིངས་སུ་རིན་ཆེན་སྟོར། །ཀྱེ་མ་རིགས་ཉམས་ངོ་མཚར་ཆེ། །མཉམ་ཉིད་གནས་སུ་གཉིས་མེད་འགྱུར། །
```

在平等性的广界中央，因为沉醉，在法界中失落了珍宝。唉！种姓衰失了，真是稀奇！在平等性的处所，成为了无二。

【按】本篇是印度密乘道歌（恰雅歌）的体裁，用的是密乘的“隐语”：表面上说沉醉、失宝、失去种姓、拥抱、毁灭亲眷，实际上指的是证悟的境界。以下按语中的解释，都是依这一体裁的通常读法推定的，原文没有自释，请读者留意。

【按】“མྱོས་པས”，“因为沉醉”，在道歌中常用来比喻大乐或证悟的“醉”，不是世俗的醉酒。“རིན་ཆེན་སྟོར”，“失落珍宝”，可能是说在法界中，原本执为珍宝的一切（包括对证悟的执著）都失落了；也可能是说珍宝（菩提心、明点）融入法界。两种读法这里都保留。

【按】“རིགས་ཉམས”，“种姓衰失”。在印度社会中，失去种姓是极大的耻辱；而在道歌里，“失去种姓”常比喻超越了一切世俗分别与身份，所以作者反而说“真是稀奇”。

### 第二段：叠句

```
བདག་གིས་དེ་ནི་མ་རྟོགས་པས། །ནི་ལ་ཁན་དྷས་མཚམས་སུ་འཇོམས། །བདག་གིས་དེ་ནི་མ་རྟོགས་པས། །དགེ་སྦྱོང་གིས་ནི་མཚམས་སུ་འཇོམས། །
```

因为我不曾领会它，尼拉康达便在界限处把它摧破；因为我不曾领会它，沙门便在界限处把它摧破。

【按】这四句是全篇的叠句。“བདག་གིས་དེ་ནི་མ་རྟོགས་པས”，“因为我不曾领会它”，语气可能带有反讽：作者并不是以概念去领会，而是在不领会（不作分别）中，界限自然被摧破。也可以照字面理解为：因为“我”不懂得这无二之理，所以需要尼拉康达（上师或作者自己）来摧破界限。原文的语气难以确定，这里照字面译出。

【按】“མཚམས་སུ་འཇོམས”，“在界限处摧破”，是本篇最难的一句。“མཚམས”有“界限”“边际”“闭关”“间隙”等多种意思，“འཇོམས”是“摧破”“降伏”。依道歌的主题，最可能的意思是摧破二取的界限、自他的边际。由于主语之后没有明确的宾语，这里补“它”字。

【按】“ནི་ལ་ཁན་དྷ”，依跋语是本篇的作者，这里在叠句中自署其名。“དགེ་སྦྱོང”，“沙门”，可能是作者的自称（作者是出家沙门），也可能另有所指。

### 第三段：拥抱虚空，毁灭亲眷

```
གཉིས་མེད་སེམས་ནི་གཉིས་མེད་འགྱུར། །མཁའ་ཡི་བདག་ཉིད་མགུལ་ནས་མཁྱུད། །བདག་གཞན་བརྗེ་བའི་ཁྱད་པར་བྱས། །གཉེན་འདུན་ཐམས་ཅད་རླག་པར་བྱས། །
```

无二的心成为无二，从颈项处拥抱着虚空的自性；作了自他相换的殊胜之事，把一切亲眷都毁灭了。

【按】“མཁའ་ཡི་བདག་ཉིད་མགུལ་ནས་མཁྱུད”，“从颈项处拥抱虚空的自性”，道歌中常以“拥抱”比喻与空性（智慧）无二无别。这里拥抱的是“虚空的自性”，即空性本身。

【按】“བདག་གཞན་བརྗེ་བ”，“自他相换”，在显宗是修菩提心的方法；在这里，可能也带有“自他界限消融”的意思。

【按】“གཉེན་འདུན་ཐམས་ཅད་རླག”，“毁灭一切亲眷”，在恰雅歌中，常以“杀死婆婆”“毁灭亲族”之类的隐语，比喻断除烦恼、断除分别念或断除对世俗关系的执著，绝不是字面上的伤害亲人。这一点必须特别说明。

### 第四段：叠句

```
དེ་ནི་བདག་གིས་མ་རྟོགས་པས། །ནི་ལ་ཁན་དྷས་མཚམས་སུ་འཇོམས། །དེ་ནི་བདག་གིས་མ་རྟོགས་པས། །དགེ་སྦྱོང་གིས་ནི་མཚམས་སུ་འཇོམས། །
```

因为我不曾领会它，尼拉康达便在界限处把它摧破；因为我不曾领会它，沙门便在界限处把它摧破。

### 第五段：叠句

```
དེ་ནི་བདག་གིས་མ་རྟོགས་པས། །ནི་ལ་ཁན་དྷས་མཚམས་སུ་འཇོམས། །
```

因为我不曾领会它，尼拉康达便在界限处把它摧破。

【按】本段之前，德格版原文还有四句（第38a叶第6至7行）。这四句的描写涉及未成年人，本译略去不录，藏文也不录。本段叠句只有前两句，没有“沙门”两句，原文如此。

### 第六段：不需财宝，与合意的伴侣同行

```
དུང་དང་གསེར་དང་དངུལ་དག་ཀྱང་། །གཅིག་ཀྱང་བདག་ལ་དགོས་པ་མེད། །བདག་ཉིད་འཐད་པའི་གྲོགས་དང་འགྲོགས། །
```

海螺、黄金和白银，没有一样是我需要的；我与合意的伴侣相伴同行。

【按】“བདག་ཉིད་འཐད་པའི་གྲོགས”，“合意的伴侣”，在密乘道歌中，“伴侣”常指智慧（般若）或智慧手印，也可以理解为与自己相应的道友。原文没有说明，这里照字面译出。

### 第七段：拥抱黑鲁嘎，我的王国

```
ཧེ་རུ་ཀ་ལ་འཁྱུད་པ་ཡིས། །བདག་གི་རྒྱལ་སྲིད་ངོ་མཚར་ཆེ། །ནམ་མཁའ་དེང་རྩེར་ཆགས་པ་ལ། །སུས་ཀྱང་མ་མཐོང་ངོ་མཚར་ཆེ། །
```

由于拥抱着黑鲁嘎，我的王国真是稀奇！安住在虚空的顶端，却没有任何人看见，真是稀奇！

【按】“ཧེ་རུ་ཀ་ལ་འཁྱུད”，“拥抱黑鲁嘎”，从这里的语气看，说话的“我”似乎是以瑜伽母（智慧）的身份，与黑鲁嘎（方便）合而为一，表示智慧与方便无二。这是恰雅歌中常见的写法。

【按】“བདག་གི་རྒྱལ་སྲིད”，“我的王国”，比喻证悟的境界，一切自在。

【按】“ནམ་མཁའ་དེང་རྩེར་ཆགས་པ”，“安住在虚空的顶端”，其中“དེང་རྩེ”一词的意思不能确定：可能是“ལྡིང”（盘旋、悬空）的异写，那么就是“悬于虚空之巅”；也可能有别的意思。这里依文意译作“虚空的顶端”，请读者留意。“ཆགས”在这里是“安住”“形成”的意思，不是“贪著”。

### 第八段：八瑜伽母欢喜相拥

```
རྣལ་འབྱོར་མ་བརྒྱད་དགའ་ཞིང་འཁྱུད། །ཧེ་རུ་ཀ་དང་འཁྱུད་ནས་གནས། །
```

八位瑜伽母欢喜地拥抱，（我）与黑鲁嘎相拥而安住。

【按】“རྣལ་འབྱོར་མ་བརྒྱད”，“八瑜伽母”，在喜金刚坛城中，主尊周围有八位瑜伽母（八天女），这里可能指她们。在圆满次第中，八瑜伽母也常与脉、气相配。原文没有说明，这里照字面译出。

## 通篇连读

在平等性的广界中央，因为沉醉，在法界中失落了珍宝。唉！种姓衰失了，真是稀奇！在平等性的处所，成为了无二。

因为我不曾领会它，尼拉康达便在界限处把它摧破；因为我不曾领会它，沙门便在界限处把它摧破。

无二的心成为无二，从颈项处拥抱着虚空的自性；作了自他相换的殊胜之事，把一切亲眷都毁灭了。

因为我不曾领会它，尼拉康达便在界限处把它摧破；因为我不曾领会它，沙门便在界限处把它摧破。

因为我不曾领会它，尼拉康达便在界限处把它摧破。

海螺、黄金和白银，没有一样是我需要的；我与合意的伴侣相伴同行。

由于拥抱着黑鲁嘎，我的王国真是稀奇！安住在虚空的顶端，却没有任何人看见，真是稀奇！

八位瑜伽母欢喜地拥抱，（我）与黑鲁嘎相拥而安住。
