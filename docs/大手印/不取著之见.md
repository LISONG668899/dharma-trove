# 不取著之见

阿阇黎甘巴拉 造

## 题解

本篇出自德格版丹珠尔续部（རྒྱུད་འགྲེལ།）ཟི 函第46a叶第5行至第46b叶第2行，东北目录编号 D2429。全篇二十六句，每句七个音节，以“像我这样骑马的勇士世间没有，奔驰之中降伏三毒野马”为叠句。篇幅很短，所以把藏文原文全部保留在代码块中，按段落分开，每段后附汉译，疑难之处另以【按】说明。

梵文题名：Asambandha-sarga-dṛṣṭi-nāma（ཨ་སམྦནྡྷ་སརྒ་དྲྀཥྚི་ནཱ་མ）。

藏文题名：ཞེན་མེད་ཀྱི་ལྟ་བ（不取著之见、无贪著之见）。

【按】藏文题名是“ཞེན་མེད”（不取著、无贪著），梵文题名却以“asambandha”（不相属）开头，与上一篇《不相属之见》的梵文题名相近，二者不能对应。可能是梵文题名在传抄中与上一篇混淆了，也可能另有原因。这里依藏文题名。

【按】作者甘巴拉（ཀཾ་པ་ལ），即上一篇《不相属之见》的作者，八十四大成就者中的“披毛毯者”拉瓦巴。上一篇是论辩体，这一篇则是道歌体，以骑手驯服野马为喻，讲在不离烦恼活动之中调伏三毒、不留痕迹的修持。跋语没有记载译者。

## 正文

### 第一段：骑上五善逝之马

```
སྲིད་པ་གསུམ་གྱི་རྒྱུ་ལས་འདི། །དཔའ་བོ་བདག་གི་དཀྱུས་སར་ཐུངས། །བདེ་གཤེགས་ལྔ་ཡི་རྟ་ལ་ཞོན། །
རྟ་པ་བདག་འདྲའི་དཔའ་བོ་ནི། །འཇིག་རྟེན་ན་ནི་ཡོད་མ་ཡིན། །བརྒྱུགས་པས་དུག་གསུམ་རྟ་རྒོད་བཏུལ། །
```

从这三有的因中，我这勇士来到了赛马场上，骑上了五方善逝的骏马。像我这样骑马的勇士，世间是没有的；在奔驰之中，降伏了三毒的野马。

【按】本篇通篇以“骑马驯马”为喻。依道歌的通常读法，野马比喻难以调伏的心与三毒，骑手勇士比喻瑜伽士，驯马比喻调伏自心。以下的解释都是依这一譬喻推定的，原文没有自释。

【按】第2句“དཔའ་བོ་བདག་གི་དཀྱུས་སར་ཐུངས”，“དཀྱུས་ས”是赛马场、跑道，“ཐུངས”可以是“饮”（འཐུང的过去式），也可以是“短”（ཐུང）。若读作“饮”，就是“在赛马场上饮（马）”；若读作“短”，就是“缩短了赛程”。两种读法都不很顺，这里依文意译作“来到了赛马场上”，请读者留意。第1句“从三有之因中”的意思，大概是说这匹马（心）本来出自三有轮回之因。

【按】“བདེ་གཤེགས་ལྔ་ཡི་རྟ”，“五善逝之马”，可能是说所骑的马本身就是五方佛的体性，比喻五毒转为五智；也可能是说以五方佛为坐骑。这是推解。

【按】叠句末句“བརྒྱུགས་པས་དུག་གསུམ་རྟ་རྒོད་བཏུལ”，“奔驰之中降伏了三毒野马”，意思是：不是把野马拴住不动，而是在奔驰之中把它驯服，比喻不离烦恼的活动而调伏烦恼。这是依文意的推解。

### 第二段：鞍与嚼子

```
ལྷ་ཆེན་བཞི་ཡི་སྒ་ཡིས་བསྟད། །ཤེས་རབ་ཐབས་ཀྱིས་སྲབ་ཏུ་བཅུག། །རྟ་པ་བདག་འདྲའི་དཔའ་བོ་ནི། །
འཇིག་རྟེན་ན་ནི་ཡོད་མ་ཡིན། །བརྒྱུགས་པས་དུག་གསུམ་རྟ་རྒོད་བཏུལ། །
```

以四位大天为马鞍来装饰，以智慧与方便作为嚼子。像我这样骑马的勇士，世间是没有的；在奔驰之中，降伏了三毒的野马。

【按】“ལྷ་ཆེན་བཞི”，“四大天”，所指不明：可能指四大天王，也可能指四大种（地水火风）的神祇，也可能是密续中的四位大天（如四魔被降伏后作为座垫）。原文没有说明，这里照字面译作“四位大天”。“བསྟད”，这里读作“装饰、安放”。

【按】“སྲབ”是马的嚼子、衔铁，用来控制马的方向。“以智慧与方便为嚼子”，比喻以智慧方便双运来驾驭心。

### 第三段：以烦恼为饲料，拴在六见之中

```
ཉོན་མོངས་བཅུ་ཡི་གསོས་ཅིག་བྱིན། །ལྟ་དྲུག་དབུས་ཀྱི་བྲེས་སུ་བཅུག། །བརྒྱུགས་པས་དུག་གསུམ་རྟ་རྒོད་བཏུལ། །
རྟ་པ་བདག་འདྲའི་དཔའ་བོ་ནི། །འཇིག་རྟེན་ན་ནི་ཡོད་མ་ཡིན། །
```

以十种烦恼作为饲料喂给它，把它拴在六见中央的缰索上。像我这样骑马的勇士，世间是没有的；在奔驰之中，降伏了三毒的野马。

【按】“ཉོན་མོངས་བཅུ”，“十种烦恼”，一般指贪、嗔、痴、慢、疑五种钝使，与身见、边见、邪见、见取见、戒禁取见五种利使，合为十种根本烦恼。“以烦恼为饲料”，比喻把烦恼转为道用。

【按】“ལྟ་དྲུག”，“六见”，与同一作者的《不相属之见》第55句所说的“六种见”可能相同，那里列举的是外道与内道的六种宗见。“拴在六见中央的缰索上”，大概是说不落入任何一种见，安住于其中央，即离边的中道。这是推解。

【按】“བྲེས”是拴马的长索、马桩绳。

【按】本段叠句的次序与其他段落不同，“降伏三毒野马”一句放在前面，原文如此。

### 第四段：持上师教言之剑

```
བླ་མ་ལུང་གི་རལ་གྲི་ཐོགས། །ཚངས་པའི་གནས་དྲུག་སྟེང་དུ་འགྲོ། །རྟ་པ་བདག་འདྲའི་དཔའ་བོ་ནི། །
འཇིག་རྟེན་ན་ནི་ཡོད་མ་ཡིན། །བརྒྱུགས་པས་དུག་གསུམ་རྟ་རྒོད་བཏུལ། །
```

手持上师教言的宝剑，驰往六梵天处之上。像我这样骑马的勇士，世间是没有的；在奔驰之中，降伏了三毒的野马。

【按】“བླ་མ་ལུང་གི་རལ་གྲི”，“上师教言之剑”，比喻以上师的口诀斩断分别执著。

【按】“ཚངས་པའི་གནས་དྲུག”，“六梵天处”，所指不明。“梵天处”一般指色界诸天；“六”也许是概数，或指某种分法。“驰往其上”，意思是超越三界中最高的天界。这是推解。

### 第五段：十方奔驰，马迹不现

```
ཕྱོགས་བཅུ་དག་ཏུ་བརྒྱུགས་པས་ཀྱང་། །དེ་ཡི་རྟ་རྗེས་མངོན་པ་མེད། །རྟ་པ་བདག་འདྲའི་དཔའ་བོ་ནི། །
འཇིག་རྟེན་ན་ནི་ཡོད་མ་ཡིན། །བརྒྱུགས་པས་དུག་གསུམ་རྟ་རྒོད་ཐུལ། །
```

即使向十方奔驰，它的马蹄印迹也显现不出来。像我这样骑马的勇士，世间是没有的；在奔驰之中，降伏了三毒的野马。

【按】“དེ་ཡི་རྟ་རྗེས་མངོན་པ་མེད”，“马迹不现”，比喻心念生起运行时，不留任何痕迹，与前面所译《调伏心与识之法》中“鹿跑去后找不到足迹”的意思相同。

【按】本段叠句末句作“ཐུལ”，与前面各段的“བཏུལ”只是时态写法不同，意思相同。
