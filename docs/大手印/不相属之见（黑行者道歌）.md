# 不相属之见（黑行者道歌）

阿阇黎那波巴 造

## 题解

本篇出自德格版丹珠尔续部（རྒྱུད་འགྲེལ།）ཟི 函第49a叶第6行至第49b叶第4行，东北目录编号 D2437。全篇二十九句，每句七个音节，以“所谓你和我，哪里会再相逢；大海中破碎的船，还会再聚合吗”为叠句。篇幅很短，所以把藏文原文全部保留在代码块中，按段落分开，每段后附汉译，疑难之处另以【按】说明。

梵文题名：Asambandha-dṛṣṭi-nāma（ཨ་སམྦནྡྷ་དྲྀཥྚི་ནཱ་མ）。

藏文题名：འབྲེལ་མེད་ཀྱི་ལྟ་བ（不相属之见、无关联之见）。

【按】本篇与前面所译的 D2428《不相属之见》，梵文、藏文题名完全相同，但是两部完全不同的作品，内容没有重复：

D2428 是甘巴拉（拉瓦巴）所造，喇嘛惹那帕拉自译，共五百八十八句，是论辩体，用因明的方法破斥能遍所遍、因果、父子、佛法、心境、我蕴等一切“关联”，归于胜义菩提心。

本篇 D2437 是那波巴（黑行者）所造，只有二十九句，是道歌体，以“你我不能再相逢”“破船不能再聚合”为叠句，说财富青春、父母子孙、身体寿命，到死亡时一切关联都会断绝，劝人觉悟无常。

两篇同名，大概都是取“无关联”之义，一篇从胜义的正理上说，一篇从无常的体验上说。为了区分，本篇标题加注“黑行者道歌”；D2428 仍保持原来的标题与文件名，不作改动。

【按】跋语说本篇是“阿阇黎那波巴（ནག་པོ་པ）所造”。那波巴即黑行者（Kṛṣṇācārya、卡纳巴），正文第23句自称“卡纳”（ཀན་པ）。前面所译的《无二根本修习次第》《心宝之见》，都是由他传下的道歌；《离忧之见》所哀悼的上师，大概也是他。跋语没有记载译者。

## 正文

### 第一段：财富青春种姓，临终皆不现

```
ནོར་དང་ལང་ཚོ་རིགས་ཀྱིས་དྲེགས། །བདག་ཉིད་འཇིག་པར་འགྱུར་བའི་དུས། །དེ་དག་གཅིག་ཀྱང་སྣང་བ་མེད། །ཁྱོད་དང་ང་ཞེས་བྱ་བ་ནི། །
ཕྲད་པར་འགྱུར་བ་ག་ལ་ཡོད། །རྒྱ་མཚོའི་ནང་དུ་གྲུ་ཞིག་པ། །སླར་ཡང་འདུ་བར་འགྱུར་རམ་ཅི། །
```

因为财富、青春与种姓而骄慢的人，到了自身坏灭的时候，这些没有一样会再显现。所谓“你”和“我”，哪里还会有再相逢的时候？大海中破碎了的船，难道还会重新聚合吗？

【按】叠句“ཁྱོད་དང་ང་ཞེས་བྱ་བ་ནི། ཕྲད་པར་འགྱུར་བ་ག་ལ་ཡོད”，“所谓你和我，哪里会再相逢”，是全篇的主旨：死亡来临时，一切人与人之间的关联都将断绝，就像大海中破碎的船，木板四散，再也不能聚合。本篇题名“不相属之见”（无关联之见），在这里就是指人与人之间的种种关联，终究都是无常、不能常相聚的。

【按】“རྒྱ་མཚོའི་ནང་དུ་གྲུ་ཞིག་པ”，“大海中破碎的船”，比喻死亡时身心离散、亲友离散。

### 第二段：亲人如看戏者

```
ཕ་དང་མ་དང་བུ་ཚ་རྣམས། །གར་ལ་ལྟ་ཕྱིར་འདུས་པ་འདྲ། །གར་མཁན་སོང་ནས་ལྟད་མོ་གྱེས། །ཁྱོད་དང་ང་ཞེས་བྱ་བ་ནི། །
ཕྲད་པར་འགྱུར་བ་ག་ལ་ཡོད། །རྒྱ་མཚོའི་ནང་དུ་གྲུ་ཞིག་པ། །སླར་ཡང་འདུ་བར་འགྱུར་རམ་ཅི། །
```

父亲、母亲与子孙们，就像为了看舞蹈而聚在一起一样；舞者一走，看戏的人也就各自散去了。所谓“你”和“我”，哪里还会有再相逢的时候？大海中破碎了的船，难道还会重新聚合吗？

【按】“གར་ལ་ལྟ་ཕྱིར་འདུས་པ”，“为看舞而聚集”，比喻亲人眷属只是因缘暂时聚合，如同观众聚在一起看戏；“舞者”可能比喻此生的身命，身命一尽，亲人也就各自离散。这是推解。

### 第三段：不知身死何处

```
ཚོང་དུས་དག་གམ་སྲང་དག་གམ། །རིའམ་ཐང་ངམ་ཆུ་འགྲམ་དུ། །ལུས་དག་གང་གི་སར་འཇིག་པ། །བདག་གིས་དེ་ནི་མ་ཤེས་སོ། །
ཁྱོད་དང་ང་ཞེས་བྱ་བ་ནི། །ཕྲད་པར་འགྱུར་བ་ག་ལ་ཡོད། །རྒྱ་མཚོའི་ནང་དུ་གྲུ་ཞིག་པ། །སླར་ཡང་འདུ་བར་འགྱུར་རམ་ཅི། །
```

是在集市上，还是在街巷里，是在山上、平原，还是在河边——这身体会在什么地方坏灭，我也不知道。所谓“你”和“我”，哪里还会有再相逢的时候？大海中破碎了的船，难道还会重新聚合吗？

【按】这几句是说死处不定：人不知道自己会死在哪里。这与佛法中常说的“死期不定、死处不定、死缘不定”相应。

### 第四段：卡纳之言

```
ཀན་པ་ནི་སྨྲ་བར་བྱེད། །བདག་གིས་འདི་ལས་རྟོགས་པ་མེད། །འགྲོ་འོང་བྱས་པས་བདག་ཉིད་བཅོམ། །ཁྱོད་དང་ང་ཞེས་བྱ་བ་ནི། །
ཕྲད་པར་འགྱུར་བ་ག་ལ་ཡོད། །རྒྱ་མཚོའི་ནང་དུ་གྲུ་ཞིག་པ། །སླར་ཡང་འདུ་བར་འགྱུར་རམ་ཅི། །
```

卡纳这样说：除此之外，我再没有别的证悟；（众生）因为来来去去，毁坏了自己。所谓“你”和“我”，哪里还会有再相逢的时候？大海中破碎了的船，难道还会重新聚合吗？

【按】“ཀན་པ”，卡纳，即作者黑行者（卡纳巴、那波巴）在诗中自署其名。

【按】“བདག་གིས་འདི་ལས་རྟོགས་པ་མེད”，可以读作“除此之外，我再没有别的证悟”，意思是：我所证悟的，就是这无常、无关联的道理；也可以读作“我从这里一无所证”，作自谦之辞。这里取前一种读法。

【按】“འགྲོ་འོང་བྱས་པས་བདག་ཉིད་བཅོམ”，“因为来来去去而毁坏了自己”，“来去”可能指轮回中的生死往来，意思是众生在生死往来中不断毁坏自己。也可以读作“在来去之中，我执被摧毁了”，意思是看透生死往来，就破除了我执。原文简略，两种读法都说得通，这里正文取前一种，括号中补“众生”二字。
