# 大手印_香巴道歌集（十八）蒋扬钦哲旺波

## 题解

蒋扬钦哲旺波的三首金刚即兴歌：以六度赞颂唐东杰布的《持明之花》、尼古六法圆满次第纲要《了义阶梯》、融香巴与大圆满于一体的《幻化供云》。

本篇出自《吉祥香巴噶举道歌金刚句与证道歌汇编·闻即有义加持海》，由蒋贡康楚·罗卓泰耶（1813–1899）在匝扎仁钦扎汇编。全书汇集香巴噶举历代祖师的金刚句与证道歌，核心见修是“嘎乌玛大手印”，故归入大手印类目，按祖师分篇发布。叙述译为白话散文，道歌分行译为诗；疑难处加【按】，存疑处附藏文原文。凡涉及拙火、迁识、方便道等密法观修之处，须得灌顶并依具德上师口授方可修持，此译仅作文献阅读。

## 赞颂尊珠桑波内在解脱的金刚即兴歌·持明之花
在极其浑浊的争斗时代，像优昙花一样稀有而意义重大的稀奇化身圣者，七种教敕的主人，以无与伦比、令人惊叹的解脱事迹，名闻雪域四方的蒋扬钦哲旺波，从他密意广界的本智宝藏中自然迸发出许多甚深广大的金刚歌。这里收录与本书相应的一首：赞颂成就自在者尊珠桑波内在解脱的金刚即兴歌，名为《持明之花》：

阿吙！
您把“杭”字的甘露，分施给
一口吞下三有的旃陀利，
燃与滴融入中脉而成本智之身——
我敬礼乐空拙火的波罗蜜多。

您惯于追逐白红明点的奔流与回返，
以不泄之喜心满意足为戒律，
沉睡的迷乱在自处清净，成为那达之语——
我敬礼明空梦境的波罗蜜多。

您饮下极寂无生的甘露波浪，
于甚深意义生起安忍，如莲花开放，
无与伦比、美妙圆满的金刚之心——
我敬礼觉空光明的波罗蜜多。

您以惯于诸法无实的智慧，
与一心专爱的精进，
超越亲与怨，成为任运功德的法界——
我敬礼显空幻身的波罗蜜多。

胜义上虽没有来去与贪取，
世俗上却以运用命勤之风的禅定，
您有着无误成就游空刹土的事业——
我敬礼受空迁识的波罗蜜多。

中有的一切迷乱显现，
您以证悟本尊、咒语皆为法身的智慧，
能从中现起为双运的圆满报身——
我敬礼觉受与空性的中阴波罗蜜多。

总之，因您熟习了了义的六波罗蜜多
与无别的金刚六法，
身、语、意、功德、事业无有穷尽——
我敬礼常住殊胜的波罗蜜多。

这样，以恭敬的朝阳催动了精华，
令持明欢喜的词句青莲
含笑绽放；愿以此戏乐，
我能持有与怙主您无别的成就解脱！

——这首歌，以本智空行尼古玛所阐明的金刚六法，赞颂清凉雪域成就种姓大海中的牛王、莲花生的化现唐东巴的内在解脱。它是在这位至尊亲自加持过的圣地，靠近吉祥扎拉萨尔巴达铁索桥的地方，乘坐一只以树木的青春为饰的木船，横渡缓缓流淌的洛希塔大河时，就在渡河途中写下作为祈请的。

【按】
1. 尊珠桑波，是唐东杰布的法名。“七种教敕”，指蒋扬钦哲旺波所得的七种传承：远传教言、地伏藏、甚深伏藏、意伏藏、再伏藏、随念伏藏、净相。
2. 本歌把尼古六法一一配上六度：拙火配布施、梦境配持戒、光明配安忍、幻身配精进、迁识配禅定、中阴配智慧，最后归于“常住殊胜的波罗蜜多”，即佛果常、乐、我、净四德中的“常”。
3. “旃陀利”（caṇḍālī），即拙火的梵名，字面义为“猛厉女”，此处把拙火拟人化为吞食三有的女子。“杭”字甘露、燃与滴、白红明点、命勤之风，都是圆满次第的术语，须依灌顶与上师口授。
4. “扎拉萨尔巴达”，原文 ཤྲཱི་ཛ་ལ་སརྦ་ཏ，应是梵化的地名，所指未能确考；“铁索桥”即唐东杰布所建的铁索桥之一。“洛希塔”（Lohita）是雅鲁藏布江的梵名。“以树木的青春为饰的木船”，原文 རྐང་འཐུང་གི་ལང་ཚོས་བཀྲ་བའི་གཟིངས，རྐང་འཐུང（以足饮者）是树的雅称，此处意译，存疑。

## 总摄甚深意义的金刚即兴歌·了义阶梯
这是总摄甚深意义的金刚即兴歌，名为《了义阶梯》：

唉玛吙！
超越能取与所取的本初真如，
离一切戏论、光明本然的体性，
被不变的大乐紧紧拥抱，
具一切相之最胜者，在心间游戏。
开示隐义秘密真如的
诸位成就持明的密意精华，
我虽没有完全见到，却以随兴生起的金刚之歌，
在今天降下甚深欢喜的水流。

金刚身的实相，决定的意义，
完全通达之后再击中要点，
见到乐空本智将会生起，
于是开示方便道甚深的圆满次第。

其中，安布的是脉，动摇的是风，
明点是最胜菩提心——共三种；
它们是成、住、坏三种作用圆满的舞蹈，
安住为自性大本智的所依。
三脉与具足四种轮
所有的结中，有方便、智慧与中性的
三个字，以及命与勤平衡的风，
还有乐空交缠的明点——
这三组依次成就乐、明、无念的
法性生起与三身的缘起。

具有金刚之法，是脉的道；
调伏并做幻轮动作，是脉的要点。
把命勤之风收入宝瓶，是风的道；
具足四种加行，是风的最胜要点。
“阿”与“杭”的融乐奔流与回返，是明点的道；
把它系缚在四轮之中，是明点的要点。
把显空视为本尊身，是幻身的道；
无所贪执地现起为化身，是幻身的要点。
临睡时以意愿约束，是梦境的道；
睡前与醒时都投入无生，是梦境的要点。
把器世间与有情收摄为精华，是光明的道；
把风与心平等系缚，是光明的要点。
忆念三种法性，是中阴的道；
常常把一切看作迷乱，是中阴的要点。
从梵穴迁出精华，是迁识的道；
收摄并阻断风与心，是迁识的要点。
这样，以根本与支分的次第，
总摄了甚深圆满次第的意义。
另外，以击中风的要点，
获得明的觉受与明点的乐，
分别开示了各自的方法。

无念、无相的圆满次第，
就是本初无生、如虚空般的光明之义，
不被法我与人我所束缚，
安住于最胜的空性。
所以，大手印超越心智的对境，
是“不作意”的心要之义。
上上根器的人，一经直指，
赤裸见到便生起，在本性的境界中解脱。
其他人，随着所生起的体验，
以风、心、明点的要点加以调伏，
于是依此，光明不可思议地现起。

至尊谛洛巴也这样说过：
“劣慧之人若不能安住于义，
就持风的要点，把觉性逼出精华；
以种种观视与持心之法，
在觉性安住于本然之前，加以调伏。
譬如观察虚空的中央，
执取边与中的念头便会止息；
同样，以心观察心，
分别念的聚合止息，无始的所依转化，
便见到无上菩提心的本性。”
因此，依靠甚深秘密道的
方便，以要点加以调伏，
按照精进与根器的分际，
在三时中得到解脱，这就是心要的最胜义。

持明与空行亲口所说的决定之义，
在我自己的心续里并没有生起体验，
我只落在凭信解而修行者的行列末端，
本不应这样说话；尽管如此，
对随兴生起而成为金刚乐音的这首歌，
一切过失，我在三根本的坛城前
不加隐瞒地忏悔；若有任何善根，
愿一切众生都安住于大手印！

【按】
1. 本歌是尼古六法圆满次第的纲要：先说金刚身的脉、风、明点三者，再以“道”与“要点”成对，列出脉、风、明点、幻身、梦境、光明、中阴、迁识的修持纲领，最后归于“不作意”的大手印，并引谛洛巴（《恒河大手印》）的说法，说明上根者一经直指即解脱，余者须以气脉方便调伏。
2. “具一切相之最胜者”，即“具一切相最胜空性”，是时轮等续中对空性的称呼。
3. “方便、智慧与中性的三个字”“四种加行”“三种法性”等，原文只列名目，具体内容须依引导文与上师口授。本歌所列一切气脉明点修法，都不可依文字自行试修。
4. 末段“只落在凭信解而修行者的行列末端”，“信解行地”是尚未登地者的修行阶位，这是作者的谦辞。

## 声空金刚即兴歌·幻化供云
这是声空金刚即兴歌，名为《幻化供云》：

阿吙！
八识的迷乱已尽，
本基解脱的本净吉祥山上，
光明舞成幻化的游戏——
我敬礼持明与空行的聚会。
我以声空之歌的供养，
为令勇士与空行欢喜而唱：

从脉清净、遍满广大的喉间，
唱出显空生起次第的歌，
遍计迷乱的蕴、界、处之聚，
都融入三座本尊之身。

从风在中脉游戏的喉间，
唱出明空念诵的歌，
对声音词句自相的一切贪执，
都融入教与证的境界。

从明点大乐的喉间，
唱出乐空四喜的歌，
凡庸烦恼的一切束缚，
都融入双运光明的境界。

从自明觉、不可言说的喉间，
唱出安住本然、任运广大的歌，
种种能取所取的一切分别，
都融入生起与解脱同时的境界。

从“嘎底”水晶管的喉间，
唱出虹光明点的歌，
蕴、界与有质碍的一切相状，
都融入法尽、超越心智的境界。

从三门平衡的喉间，
唱出生起、圆满与大圆满的歌，
执轮回涅槃为二的一切分别，
都融入无作之果的广界。

从我这法油子、福薄者的喉间，
唱出种种声空的歌，
想做、想修的一切正法，
都融入懒惰拖延的境界。

这是了义之歌的供养，
是厌倦自己心续的哀歌。
愿以此善，尚未证悟的众生界，
都在自明觉的本体中任运成就！

——以上是他所说的。

【按】
1. 本歌以七种“喉间”与七首歌为纲：脉、风、明点、自明觉、“嘎底”水晶管、三门平衡，以及作者自嘲的“法油子”之喉，每一首歌都把一类执著融入相应的境界。前六节由生起次第、念诵、乐空、大手印本然安住、大圆满顿超（虹光明点、法尽）到生圆与大圆满的总摄，层层递进；第七节突转为自嘲，是道歌常见的谦辞。
2. “嘎底水晶管”，是大圆满顿超法中连接心与眼的光脉。“法尽、超越心智”是顿超四相中的最后一相。这些都是大圆满的术语，可见钦哲旺波以利美（不分宗派）的立场，把香巴、大手印与大圆满融为一体。
3. “法油子”，指听法很多却被法“熏油”、心不再被法打动的人，与皮革用久变硬的比喻同义。
