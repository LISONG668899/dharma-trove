# 梦教示

梅纪巴（阿阇黎无二金刚）造　据藏文译出

## 题解

《梦教示》（梵 Svapnanirdeśa，藏 rmi lam nges par bstan pa，直译"梦之决定开示"）收于德格版丹珠尔续部释 ཝི 函第 111b 页（东北目录 D2233），紧接在《俱生六颂》（D2232）之后，同属梅纪巴的"无念法类"。译者是印度上师金刚手与比丘戒胜（即那措译师）。

全篇共九颂三十六句。佛陀在律、论、经中都说"诸法如梦"，本篇就借"梦"这一个比喻，把佛教内部对诸法的六种理解排列出来：梦是真的、梦是假的、梦是种种心、梦是无相之心、梦如幻化、梦无所住。作者先指出前两种分别落入常、断二边，再依次叙述"种种心"与"无相心"两种唯识的说法，以及"如幻"与"无住"两种中观的说法，最后归结到"无住"之说，并指出要依自证、上师的教言与经教的差别来通达。

这与《中观六颂》判摄宗义的思路一致，可以对照着读。由于全篇极为简略，有几处句子须依上下文才能读通，下面都在按语中说明。

体例：按意义单元分段，每段先列藏文原颂于代码块中，再译出；为了便于理解而补的字，都放在方括号中。原文含混或可有两解之处，以"【按】"说明，不妄补内容。原文异文 brdzun、rdzun 依校勘惯例取后者，意义相同，下文不再一一注出。文末附通篇连读。

## 题名与礼敬

梵语题名：Svapnanirdeśa。藏语题名：《梦教示》。

敬礼佛陀！

## 一、造论缘起

```
འདུལ་བ་དང་ནི་ཆོས་མངོན་དང་། །
མདོ་ལས་རྒྱལ་བ་སྐྱེས་མཆོག་གིས། །
རྨི་ལམ་ལྟ་བུར་ཆོས་གསུངས་པ། །
གསལ་བར་འདི་ནི་བསྟན་པ་ཡིན། །
```

胜者、最胜之士［佛陀］，在律藏、论藏和经藏中，都宣说诸法如梦；这里要把［这一教义］清楚地开示出来。

## 二、六种理解

```
རྨི་ལམ་བདེན་ནམ་རྫུན་པའམ། །
སྣ་ཚོགས་སེམས་སམ་རྣམ་མེད་སེམས། །
སྒྱུ་མའམ་ཡང་ན་མི་གནས་ལས། །
དམ་པ་ལྟར་ནི་གང་ཞིག་འདོད། །
```

梦是真实的，还是虚假的？是种种［相］的心，还是无相的心？是如幻化，还是无所住？在这［六种理解］当中，承许哪一种为最胜呢？

【按】这里列出的六种，就是下文逐一讨论的六种立场：一、梦是真实的；二、梦是虚假的；三、梦是"种种心"，即心带着种种行相，相当于唯识的有相论；四、梦是"无相心"，即心本身无行相，相当于唯识的无相论；五、梦如幻化，相当于中观的如幻无二论；六、梦无所住，相当于中观的一切法无住论。第三至第六的对应，是依梅纪巴在《真性宝鬘》等论中的四宗判摄来理解的，原文本身没有标出宗名。

## 三、真与假：常、断二边

```
མ་རྟོགས་པ་ནི་རྨི་ལམ་བདེན། །
རྟོགས་ན་དེ་ནི་རྫུན་འགྱུར་ཏེ། །
དང་པོར་རྟག་པར་ཤེས་བྱ་སྟེ། །
གཉིས་པ་ཆད་པར་གྱུར་པ་ཡིན། །
```

没有认出［是梦］的时候，梦是真实的；一旦认出，它就变成虚假的了。应当知道，第一种［说梦是真实的］是常见；第二种［说梦是虚假的］则成了断见。

【按】梦中的人不知是梦，便以梦境为真；醒来或认出是梦，便说梦是假的。作者指出，把梦执为真实，落入常边；把梦断定为纯然虚假、什么都没有，又落入断边。所以前两种理解都不是最胜的。

## 四、醒觉所除与不除

```
རབ་ཏུ་སད་པས་རྟོག་པ་སེལ། །
ཉམས་སུ་མྱོང་བ་སེལ་མ་ཡིན། །
```

真正醒觉了，所除去的是分别念；所领受的体验，并不被除去。

【按】这两句是全篇的枢纽：觉醒（无论是从梦中醒来，还是从无明中觉悟）所去除的，只是把梦执为实有或断无的分别；至于梦中种种的显现与领受，作为体验本身，并不因此而被否定掉。这就避开了断见，也引出下文对"种种心"等几种理解的讨论。

## 五、种种心之说

```
སེམས་བཅས་སྣ་ཚོགས་སེལ་བདག་ཉིད། །
གང་ཞིག་ཉམས་སུ་ཆེར་མྱོང་བ། །
སྐད་ཅིག་འཇུག་པ་ཀུན་གཞིག་རྩ། །
སྣ་ཚོགས་སྣང་བ་འཇུག་པ་རྣམས། །
དེ་དང་དེར་ནི་རྣམ་པར་གནས། །
སེམས་འདི་ཉིད་ནི་དེ་ལྟར་འདོད། །
```

［主张"种种心"的人说：］那被深切领受的，是带着心的种种［行相］，体性明了；刹那刹那的转起，以阿赖耶为根本；种种显现的转起，各自安住于各自的位置——他们这样承许这个心。

【按】这一段的藏文多处难解，以下几点都是依上下文的推测：

第一句"sel bdag nyid"，字面是"遣除的体性"，在这里很难讲通；疑 sel 是 gsal（明了）的讹写，那么意思就是"体性明了"。这里暂依此读，存疑。

第三句"kun gzhig rtsa"，gzhig 是"摧毁"，讲不通，疑为 kun gzhi'i rtsa（阿赖耶的根本、以阿赖耶为根）之讹，这里依此读。阿赖耶识是唯识宗所立的根本识，种种转识都由它而转起，与"刹那转起"文义相合。

整段的意思是：有相唯识认为，梦中以及一切的种种显现，都是心本身带着的种种行相，是真实被领受的；它们刹那转起、以阿赖耶为根，各自显现。这就是"种种心"的主张。

## 六、无相心之说

```
གལ་ཏེ་རྨི་ལམ་རྨི་ལམ་ཉིད། །
སེམས་དངོས་སྣ་ཚོགས་དེ་ཚེ་རྫུན། །
ཡོད་དང་མེད་པ་འཇུག་མེད་པ། །
གསལ་བ་ལ་ནི་ཆད་པ་མེད། །
```

如果梦只是梦而已，那么，心的种种事相，那时便都是虚假的；［心］不落入有与无，而明性则没有断灭。

【按】这是"无相心"的主张：种种行相都是虚假的，唯有离开行相的明性是不断的。"不落入有与无"（yod dang med pa 'jug med pa），也可以读作"有与无都不转起"，意思相近。与上一段的有相论相比，这一派把行相判为虚妄，只承许无相的明性。

## 七、如幻与无住之说

```
ཅི་སྟེ་མིང་མེད་ལ་མིང་བཏགས། །
མིང་ནི་སྒྱུ་མ་ཉིད་དུ་དོགས། །
མིང་ལ་མིང་ནི་རིགས་མ་ཡིན། །
མིང་ནི་མི་གནས་པ་ཡིན་ནོ། །
```

如果是在本无名称之处安立名称，那么这名称便被认为是如幻化一般；［但若再进一步看，］在名称上安立名称是不合理的，名称［本身也］是无所住的。

【按】前两句是"如幻"的主张：诸法本无名称，名称只是假立，所以一切如幻。后两句是"无住"的主张：连"如幻"这个名称、这个安立本身，也不能再执持，不可在名称上再加名称，所以名称也无所住。第二句的 dogs，一般是"怀疑、疑惧"，这里依上下文解作"被认为、被看作"，存疑。

## 八、结示

```
འདིར་ནི་དྲུག་ལས་གཉིས་དེར་བྱོས། །
གཞི་ནི་རྟོགས་པར་བྱ་བའོ། །
སྣ་ཚོགས་འདི་དག་རྨི་ལམ་མཚུངས། །
དེ་ལྟར་རྒྱལ་བ་མཆོག་གིས་གསུངས། །
```

在这里，于六种［理解］之中，你要把两种安立在那［最胜］处；要证悟的，是［这一］根本。这些种种［显现］都和梦一样——最胜的胜者就是这样宣说的。

【按】第一句很难确定。"gnyis der byos"字面是"把二作在那里"。一种理解是：六种之中，应取后两种，也就是如幻与无住的中观见；另一种理解是：应把前两种，也就是常见与断见，放在一边。从下一颂专说"无住"来看，作者最终所取的是无住之说，如幻之说则是通往无住的阶梯。这里依第一种理解，存疑。"根本"（gzhi），指诸法的本来实相，也可以理解为"基"。

## 九、无住宗与三种依据

```
མི་གནས་གཞུང་ནི་རྟོགས་བྱ་སྟེ། །
སངས་རྒྱས་པ་ཀུན་ནོར་ཡིན་པས། །
རང་རིག་དང་ནི་བླ་མའི་བཀའ། །
ལུང་གི་ཁྱད་པར་གྱིས་ཤེས་སོ། །
```

应当通达的，是无住的宗义；因为［其余的］佛教宗派都有所错失。这要依靠自证、上师的教言，以及经教的殊胜［抉择］来了知。

【按】第二句"sangs rgyas pa kun nor yin pas"有两种完全不同的读法：nor 可以是"错失、错误"，也可以是"财宝"。按前一种，意思是"因为［前面那些］佛教徒的［理解］都有错失"；按后一种，意思是"因为［无住之宗］是一切佛教徒的珍宝"。梅纪巴在别处以无住论为中观的究竟，两种读法都与此相合；这里取前一种，因为与上文逐一检讨各宗的语气相合，后一种也可以成立，存疑。

"自证、上师的教言、经教"三者，是大手印传统中常说的三种依据：自己的亲身证悟、上师的口诀，以及佛经与论典。三者互相印证，才能确定无误地通达无住的实相。

## 跋

《梦教示》，阿阇黎无二金刚所造，圆满。

上师金刚手与比丘戒胜译出。

【按】"无二金刚"（gnyis med rdo rje，梵 Advayavajra），即梅纪巴。"比丘戒胜"（dge slong tshul khrims rgyal ba），即那措译师·戒胜，也就是《中观六颂》跋语中的"那措"。

## 通篇连读

敬礼佛陀！

胜者、最胜之士在律、论、经中，都宣说诸法如梦，这里要把这一教义清楚地开示出来。

梦是真实的，还是虚假的？是种种相的心，还是无相的心？是如幻化，还是无所住？这六种之中，以哪一种为最胜呢？

没有认出是梦时，梦是真实的；一旦认出，它就变成虚假的。说梦真实是常见，说梦虚假则成了断见。

真正醒觉所除去的，是分别念，而所领受的体验并不被除去。

主张"种种心"的人说：那被深切领受的，是带着心的种种行相，体性明了；刹那转起，以阿赖耶为根本，种种显现各自转起，各安其位——他们这样承许心。

如果梦只是梦，那么心的种种事相都是虚假的；心不落入有与无，而明性没有断灭。

如果在本无名称之处安立名称，名称便被看作如幻；但在名称上再安立名称是不合理的，名称本身也无所住。

六种理解之中，你要把两种安立在最胜处；要证悟的是这一根本。这一切种种显现都如梦一样，最胜的胜者就是这样宣说的。

应当通达的是无住的宗义，因为其余的理解都有所错失；这要依自证、上师的教言与经教的殊胜抉择来了知。

《梦教示》，阿阇黎无二金刚造，圆满。上师金刚手与比丘戒胜译出。
