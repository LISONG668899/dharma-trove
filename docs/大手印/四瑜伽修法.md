# 四瑜伽修法

谭帝巴阿阇黎 造

## 题解

本篇出自德格版丹珠尔续部（རྒྱུད་འགྲེལ།）ཟི 函第12b叶第4行至第13a叶第3行，东北目录编号 D2380。全篇四十二句，每句七个音节，另有礼敬和跋语。篇幅很短，所以把藏文原文全部保留在代码块中，按段落分开，每段后附汉译，疑难之处另以【按】说明。

梵文题名：Caturyoga-bhāvanā-nāma（ཙ་ཏུར་ཡོ་ག་བྷཱ་བ་ན་ནཱ་མ），意为“名为四瑜伽修习”。

藏文题名：རྣལ་འབྱོར་བཞིའི་ཉམས་ལེན་གྱི་ཐབས（四瑜伽修持之方法）。

【按】作者“ཏན་ཏི་པ”（Tantipa），这里音译为“谭帝巴”。八十四大成就者中有一位织工出身的成就者，名为 Tantipa，意思是“织师”，本篇末句作者自称“ཏན་ཏི”，很可能就是这一位，但跋语只称“阿阇黎谭帝巴”，没有更多信息。跋语也没有记载译者。

【按】本篇所说的“四瑜伽”，是阿离迦离瑜伽、明咒瑜伽、平等性瑜伽、方便瑜伽这四种，属于无上瑜伽续部圆满次第一类的修法，涉及脉、明点、种子字、五甘露等。它与噶举派大手印通常所说的“四瑜伽”（专一、离戏、一味、无修）名称相同，内容却完全不同，读者千万不要混淆。本篇收入大手印类目，是因为它出自印度大成就者的道歌口诀集，且以“心与心性无因”的见地统摄全篇。

【按】本篇讲的都是密乘圆满次第的修法，依传统，必须先得到相应的灌顶，并依具格上师的口授才能修持，不能仅凭文字自行实修。这里翻译出来，只是供学习、了解之用。文中许多关键之处（例如“勇父之道”“它止息时”“不动佛之水”）原文都极简略，必须依上师口诀才能确定，按语中所作的解释只是译者依通常说法所作的推测，并不代表传承的口诀。

## 礼敬

```
དཔལ་རྡོ་རྗེ་སེམས་དཔའ་ལ་ཕྱག་འཚལ་ལོ། །
```

敬礼吉祥金刚萨埵！

## 正文

### 第一段：总标见地

```
སེམས་དང་སེམས་ཉིད་རྒྱུ་མེད་དེ། །བསྒྲུབ་བྱ་སྒྲུབ་བྱེད་ཐིག་ལེའི་ངོ་། །འབྲས་བུ་མ་གྲུབ་མྱ་ངན་འདས། །དཔལ་ལྡན་དཔའ་བོ་ཡི་གེ་མེད། །
```

心与心性，都是无因的；所修与能修，都是明点的本面；果并不（另外）成立，那就是涅槃；吉祥勇父，没有文字。

【按】“སེམས་དང་སེམས་ཉིད་རྒྱུ་མེད”，“心与心性无因”。“心”（སེམས）指能分别的心识，“心性”（སེམས་ཉིད）指心的本性。说二者都“无因”，意思应是：从究竟上看，心与心性都不是由因缘造作而成立的。这四句先立见地，下面讲的种种观想、气脉、明点修法，都要在这一见地的摄持下来理解，不能把它们执为实有。

【按】“བསྒྲུབ་བྱ་སྒྲུབ་བྱེད་ཐིག་ལེའི་ངོ”，“所修与能修是明点之本面”。“ཐིག་ལེ”（明点）有两层意思：一是圆满次第中身内脉道里的明点（菩提心精华）；二是大手印、大圆满中所说的“唯一明点”，指本来圆满、无有分割的心性。这里两层意思可能都有：既指下文所修的明点，也指所修、能修无二的本性。“ངོ”是“面”“本面”，这里译作“本面”，取“本来面目”之意。

【按】“འབྲས་བུ་མ་གྲུབ”，“果不成立”，意思应是：果并不是在心性之外另外成立的一个东西，心性本身离一切造作，就是涅槃。括号中的“另外”二字是译者所补。

【按】“དཔལ་ལྡན་དཔའ་བོ་ཡི་གེ་མེད”，“吉祥勇父无文字”。“吉祥勇父”大概指黑鲁嘎（胜乐）一类的本尊，也可以理解为证悟本身。说他“无文字”，是指究竟的本尊、究竟的实相超越一切文字、种子字。下文虽然要依“阿离迦离”（元音、辅音字母）来修，但这一句先点明：字母只是方便，究竟上无有文字。这一解释是依上下文推定的。

### 第二段：标宗

```
ལྟེ་བར་གསང་བའི་གེ་སར་ལ། །ཨཱ་ལི་ཀཱ་ལི་ལ་བརྟེན་ནས། །རྣལ་འབྱོར་བཞི་ཡི་ཉམས་ལེན་བཤད། །
```

在脐间秘密（莲花）的花蕊上，依靠阿离、迦离，宣说四种瑜伽的修持。

【按】“གེ་སར”是梵文 kesara 的音译，指莲花的花蕊（雄蕊、花须）。“ལྟེ་བར་གསང་བའི་གེ་སར”，“脐间秘密花蕊”，大概指脐轮莲花的中心。“莲花”二字原文没有，是译者所补。

【按】“ཨཱ་ལི་ཀཱ་ལི”（阿离迦离），指梵文的元音字母（阿离）与辅音字母（迦离）。在无上瑜伽续部中，阿离、迦离常与左右二脉、月与日、方便与智慧相配，是圆满次第修持的重要所依。

### 第三段：第一瑜伽——阿离迦离瑜伽

```
ལྟེ་བ་ཡེ་ཤེས་འཁོར་ལོ་རུ། །རྩ་ནི་བརྒྱད་ཀྱི་ཐིག་བཏབ་ནས། །ཨཱ་ཕྲེང་ཀཱ་ཕྲེང་མཉམ་བསམས་ནས། །མཁའ་འགྲོ་བརྒྱད་ཀྱི་མེ་ལྕེ་སྦར། །
བྱང་ཆུབ་སེམས་ཀྱི་རང་བཞིན་ནི། །ནམ་མཁའི་དབྱིངས་ཀྱི་འོད་ལས་ནི། །གཉིས་མེད་ཟུང་འཇུག་འཛག་བྱས་པས། །དཔའ་བོ་རྣམས་ཀྱི་ལམ་ནས་རྒྱུ། །
དེ་འགག་རྣལ་འབྱོར་མཚན་མ་མེད། །བརྟན་པའི་རྣལ་འབྱོར་གྲུབ་འགྱུར་བ། །སངས་རྒྱས་རྣམས་ཀྱི་ས་ལམ་ཐོབ། །ཨཱ་ལི་ཀཱ་ལིའི་རྣལ་འབྱོར་རོ། །
```

在脐间的智慧轮中，画定八条脉的线，然后同时观想阿（元音）字鬘与迦（辅音）字鬘，点燃八位空行母的火焰。菩提心的自性，从虚空界的光明中，以无二双运的方式滴降下来，从诸勇父的道路中运行。当它止息时，便是无相瑜伽；稳固的瑜伽便会成就，从而获得诸佛的地与道。这就是阿离迦离瑜伽。

【按】“ཡེ་ཤེས་འཁོར་ལོ”，“智慧轮”。脐轮一般称为“化身轮”或“幻化轮”，这里称为“智慧轮”，可能是本篇所依传承的特殊说法，也可能是泛称。原文如此，照译。

【按】“རྩ་ནི་བརྒྱད་ཀྱི་ཐིག་བཏབ”，“画定八脉之线”，大概是观想脐轮有八条辐脉，如画坛城时先弹定界线一样。“ཐིག་བཏབ”本是画坛城、建筑时“弹线”“画定线”的术语。脐轮的脉瓣数，诸续说法不一（常见六十四瓣），这里说“八”，可能指主要的八条辐脉，与下句“八位空行母”相配。

【按】“ཨཱ་ཕྲེང་ཀཱ་ཕྲེང་མཉམ་བསམས”，“同时观想阿鬘、迦鬘”。“མཉམ”可以理解为“同时”“一起”，也可以理解为“平等地”。这里取“同时”。

【按】“མཁའ་འགྲོ་བརྒྱད་ཀྱི་མེ་ལྕེ་སྦར”，“点燃八空行之火焰”，从下文菩提心滴降的次第看，这应当就是圆满次第中“拙火”（猛厉火）一类的修法：脐间燃起火焰，上至顶门，令菩提心融化滴降。但本篇并没有用“拙火”（གཏུམ་མོ）这个词，所以这里只照字面译出，不加“拙火”之名。

【按】“བྱང་ཆུབ་སེམས”（菩提心），在这里指圆满次第中的明点菩提心（白菩提），而不是显宗所说的发愿利他的菩提心。“ནམ་མཁའི་དབྱིངས”（虚空界），从脉络上看可能指顶轮，也可能指法界本身。两层意思这里都保留，译作“虚空界”。

【按】“དཔའ་བོ་རྣམས་ཀྱི་ལམ”，“诸勇父之道”，可能指菩提心滴降所经过的脉道（例如中脉），也可能指勇父、空行所表示的脉与气。前面翻译的《自性不成立口诀》中也有“从勇士之门发出声音”一句，两处的“勇父”（དཔའ་བོ）或许都是指身内的脉道与门户。这一联系只是推测，录在这里以备参考。

【按】“དེ་འགག”，“它止息时”，“它”指什么，原文没有明说。可能是上句运行的菩提心（或气），也可能是分别念。依圆满次第的通义，气入、住、融于中脉时，分别念自然止息，显现无相的空乐智慧，所以译作“当它止息时，便是无相瑜伽”。“它”所指，请读者依师长口授决定。

### 第四段：第二瑜伽——明咒瑜伽

```
ཨ་ཧོ་བཟླས་པའི་རྣལ་འབྱོར་པ། །དངོས་དང་དངོས་མེད་བྲལ་འགྱུར་བས། །ཕྱི་ནང་དུག་གི་རྣམ་པ་སེལ། །རྣལ་འབྱོར་འདི་ནི་བརྟན་གྲུབ་ན། །
ཟླ་བ་དྲུག་ནས་འགྲུབ་འགྱུར་བའི། །རྡོ་རྗེ་སེམས་དཔའ་དང་མཉམ་མོ། །དེ་ནི་རིག་པའི་རྣལ་འབྱོར་རོ། །
```

念诵“阿吙”的瑜伽士，由于远离了有与无，便能遣除外内一切毒的相状。这一瑜伽如果稳固成就，六个月便能成就，与金刚萨埵等同。这就是明咒瑜伽。

【按】“ཨ་ཧོ་བཟླས་པ”，“念诵阿吙”。“ཨ་ཧོ”在藏文中常作感叹词（“啊吙”“奇哉”），但这里与“念诵”连用，应是作为咒语或种子字来念。具体是哪一种念诵（例如配合呼吸的金刚念诵），原文没有说明。

【按】“དངོས་དང་དངོས་མེད་བྲལ”，“远离有与无”，即远离实有与断无二边，也就是中观所说的离边。这一句是说，念诵时不执念诵为实有，也不落于空无，所以能遣除毒。

【按】“ཕྱི་ནང་དུག”，“外内之毒”，“外毒”可能指世间的毒物、毒害，“内毒”指贪嗔痴等烦恼。这一读法是依常见的说法推定的。

【按】“ཟླ་བ་དྲུག་ནས་འགྲུབ”，“六个月成就”，原文的语法稍有含混，也可以读成“稳固成就以后，从第六个月起（便与金刚萨埵等同）”。两种读法意思相近，这里取较顺的一种。

【按】“རིག་པའི་རྣལ་འབྱོར”，“རིག་པ”可以译作“明觉”，也可以译作“明咒”（梵文 vidyā）。因为本段讲的是念诵，所以这里译作“明咒瑜伽”。若依大手印、大圆满的用语，“རིག་པ”指心性的明觉，那么也可以译作“明觉瑜伽”，意思是以念诵为方便而契入明觉。两种理解都有道理，特此并存。

### 第五段：第三瑜伽——平等性瑜伽

```
སེམས་ཉིད་གནས་སུ་པདྨ་ནི། །མཉམ་པ་ཉིད་ནི་དམར་པོར་བསམ། །པད་འདབ་བཞི་ལ་ཐིག་ལེ་ནི། །དབུས་སུ་རྒྱུ་མེད་ཐིག་ལེ་ཡིན། །
དེ་དག་རྣམས་ཀྱི་ཁ་དོག་ནི། །ཤར་དུ་དམར་དང་བྱང་དུ་སེར། །ནུབ་ཏུ་དཀར་དང་ལྷོ་རུ་གནག། །སྣ་ཚོགས་འོད་གསལ་དབུས་སུ་འཕྲོ། །
སྔར་བཤད་སྔགས་དང་བཅས་པ་ནི། །སྒོམ་ན་རྣལ་འབྱོར་དབང་ཕྱུག་དེ། །སྐད་ཅིག་གཅིག་ལ་རྫོགས་སངས་རྒྱས། །དེ་ནི་མཉམ་ཉིད་རྣལ་འབྱོར་རོ། །
```

在心性之处观想莲花；要观想平等性为红色。在四片莲瓣上有明点，中央则是无因的明点。它们的颜色是：东方红色、北方黄色、西方白色、南方黑色；种种光明从中央放射出来。连同前面所说的咒语一起修持的话，那位瑜伽自在者，在一刹那之间便能圆满成佛。这就是平等性瑜伽。

【按】“སེམས་ཉིད་གནས་སུ”，“在心性之处”，从圆满次第的脉络看，可能指心间（心轮），因为心间常被视为心性所住之处；也可能是说“安住于心性的状态中”。这里照字面译作“在心性之处”。

【按】“མཉམ་པ་ཉིད་ནི་དམར་པོར་བསམ”，“观想平等性为红色”，语法上有些特别：可能是说那朵莲花即是平等性，观为红色；也可能是说莲花的颜色是红色，而它的体性是平等性。这里照字面译出。

【按】四方明点的颜色（东红、北黄、西白、南黑），与常见的五方佛坛城方位颜色不同（例如常见的有东白、南黄、西红、北绿，或东蓝、南黄、西红、北绿等配法），可能是本篇所依传承的特殊配法，也可能有传抄讹误。原文如此，照录不改。“གནག”是“黑”，在密续中也常指深蓝色。

【按】“དབུས་སུ་རྒྱུ་མེད་ཐིག་ལེ”，“中央无因明点”，与开头“心与心性无因”相呼应，表示中央的明点象征无造作的心性本身。

【按】“སྔར་བཤད་སྔགས”，“前面所说的咒语”，可能指上一段的“阿吙”，也可能指第一段的阿离迦离。原文没有明说。

【按】“སྐད་ཅིག་གཅིག་ལ་རྫོགས་སངས་རྒྱས”，“一刹那间圆满成佛”，这是密续中常见的赞叹之辞，意思是在根器、因缘具足、证悟心性的当下即可成佛；不应理解为不需要任何积累与修持便可成佛。

### 第六段：第四瑜伽——密咒方便瑜伽及结语

```
མི་བསྐྱོད་ཆུ་དང་རྣམ་སྣང་དང་། །ཕྱི་ནང་བདུད་རྩི་ལྔ་ཡིས་ནི། །སྔགས་པའི་ཐབས་ཀྱི་རྣལ་འབྱོར་གྱི། །ཏན་ཏི་བདག་གིས་གྲུབ་པ་ཐོབ། །
```

以不动佛之水、毗卢遮那等外内五甘露（来修持）——这密咒士的方便瑜伽，我谭帝已经获得了它的成就。

【按】“མི་བསྐྱོད་ཆུ་དང་རྣམ་སྣང”，“不动佛之水与毗卢遮那”，这是续部中的隐语（密语）。在无上瑜伽续部中，五甘露常以五方佛之名作为隐语来称呼，“不动佛之水”“毗卢遮那”等，都是五甘露中某几种的代称。至于每一佛名具体对应哪一种甘露，诸续说法不完全一致，本篇也没有说明，所以这里照字面译出，不作对应。

【按】“ཕྱི་ནང་བདུད་རྩི་ལྔ”，“外内五甘露”，“外”可能指以实物（甘露丸等）为所依，“内”可能指身内的五种精华或五蕴、五大的清净。原文没有解释。

【按】本段四句的语法比较简略：第一、二句说以五甘露（修持），第三句以属格“གྱི”结尾，接第四句“我谭帝获得成就”，所以整段的意思是“这一以五甘露为所依的密咒方便瑜伽，我谭帝已得其成就”。第四瑜伽的名称原文没有像前三段那样以“这就是……瑜伽”明确标出，这里依第三句称为“方便瑜伽”。

【按】作者以第一人称说“我谭帝已获得成就”，是印度成就者道歌中常见的自述方式，用来表示所说的是自己亲证的口诀，不是空谈。

## 跋语

```
རྣལ་འབྱོར་བཞིའི་ཉམས་ལེན་ཅེས་བྱ་བ་སློབ་དཔོན་ཏན་ཏི་པས་མཛད་པ་རྫོགས་སོ།། །།
```

名为《四瑜伽修持》，阿阇黎谭帝巴所造，圆满。

## 通篇连读

心与心性，都是无因的；所修与能修，都是明点的本面；果并不（另外）成立，那就是涅槃；吉祥勇父，没有文字。

在脐间秘密（莲花）的花蕊上，依靠阿离、迦离，宣说四种瑜伽的修持。

在脐间的智慧轮中，画定八条脉的线，然后同时观想阿（元音）字鬘与迦（辅音）字鬘，点燃八位空行母的火焰。菩提心的自性，从虚空界的光明中，以无二双运的方式滴降下来，从诸勇父的道路中运行。当它止息时，便是无相瑜伽；稳固的瑜伽便会成就，从而获得诸佛的地与道。这就是阿离迦离瑜伽。

念诵“阿吙”的瑜伽士，由于远离了有与无，便能遣除外内一切毒的相状。这一瑜伽如果稳固成就，六个月便能成就，与金刚萨埵等同。这就是明咒瑜伽。

在心性之处观想莲花；要观想平等性为红色。在四片莲瓣上有明点，中央则是无因的明点。它们的颜色是：东方红色、北方黄色、西方白色、南方黑色；种种光明从中央放射出来。连同前面所说的咒语一起修持的话，那位瑜伽自在者，在一刹那之间便能圆满成佛。这就是平等性瑜伽。

以不动佛之水、毗卢遮那等外内五甘露（来修持）——这密咒士的方便瑜伽，我谭帝已经获得了它的成就。
