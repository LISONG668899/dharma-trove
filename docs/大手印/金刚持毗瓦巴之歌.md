# 金刚持毗瓦巴之歌

大成就者毗瓦巴造　据藏文译出

## 题解

本篇收于德格版丹珠尔续部释 ཟི 函第 6b 页（东北目录 D2356）。开头没有梵藏题名，只有"敬礼佛陀"；跋语作"毗瓦巴所作的金刚歌，圆满"（བི་རཱུ་བྱེད་པའི་རྡོ་རྗེའི་གླུ），没有记载译者。本站依通行题名称为《金刚持毗瓦巴之歌》。毗瓦巴（Virūpa）名下本站已译的还有《道歌宝藏（毗瓦巴）》（D2280）、《道果经教》（D2284）、《甘露成就基础》（D2285）与《拙火业印·道歌宝藏》（D2344）。

全篇很短，共四段，以射箭为喻，叠句是"我射出了俱生之箭：没有靶子，一处也没有射中"。俱生之箭没有靶子，象征俱生智无所缘；世人射的是执一切为实有的箭；在俱生智中没有能受所受，能所化为无二；最后，毗瓦巴自称是一个连二十个贝币工钱都拿不到的仆人，象征不求任何所得。全篇没有涉及具体的密法修持。

体例：藏文原文全部保留在代码框中，按段落分节，每节后附汉译；叠句照原文每次重复。凡标"存疑"的按语，表示本译对原文意思没有把握。藏文依 Esukhia 德格丹珠尔电子版。

## 礼敬

```
སངས་རྒྱས་ལ་ཕྱག་འཚལ་ལོ། །
```

敬礼佛陀！

## 一、金刚瑜伽士持弓

```
རྡོ་རྗེ་རྣལ་འབྱོར་མདའ་འཛིན་ཏེ། །
ཆོས་རྣམས་མཚོན་པར་རབ་ཤེས་ནས། །
ང་ཡིས་ལྷན་སྐྱེས་མདའ་འཕངས་རྒྱབ། །
འབེན་མེད་གཅིག་ཀྱང་ཕོག་པ་མེད། །
```

金刚瑜伽士手持弓箭，善知诸法的表示之后——我射出了俱生之箭：没有靶子，一处也没有射中。

【按】射箭是萨惹哈以来印度成就者常用的意象（萨惹哈本人传说就是一位箭匠）。"俱生之箭"象征俱生智；"没有靶子，一处也没有射中"，是说俱生智没有任何所缘的对象，它不射向任何东西，也不落在任何东西上。这正是大手印"无所缘"的意思。这两句是全篇的叠句，以下各节照原文重复。

【按】存疑。"འབེན་མེད་གཅིག་ཀྱང་ཕོག་པ་མེད"，字面是"没有靶子，一个也没有射中"，本译依字面译出；也可以理解为反语："没有靶子，［却］无一落空"。依全篇无所缘的宗旨，本译取前者。

## 二、执实之箭

```
ལྷན་ཅིག་སྐྱེས་པའི་གཏམ་གསོན་ཅིག། །
ཐམས་ཅད་དངོས་བོར་སྦྱོར་བའི་མདའ། །
ང་ཡིས་ལྷན་སྐྱེས་མདའ་འཕངས་རྒྱབ། །
འབེན་མེད་གཅིག་ཀྱང་ཕོག་པ་མེད། །
```

请听这俱生的话语：［世人射的］是把一切都执为实有的箭——我射出了俱生之箭：没有靶子，一处也没有射中。

【按】这一节以对比的方式说：世人射出的，是执一切为实有的箭，总要有一个靶子；而瑜伽士射出的俱生之箭，没有靶子。

【按】存疑。第七句"ཐམས་ཅད་དངོས་བོར་སྦྱོར་བའི་མདའ"，主语不明，本译补为"世人射的"，也可能是说俱生之箭能把一切执实一并射破，意思不完全确定。

## 三、无受，无二

```
དེ་རྣམས་ནས་ནི་ཚོར་བ་མེད། །
དེ་ཡི་འདི་ཡིན་གཉིས་མེད་སོང། །
ང་ཡིས་ལྷན་སྐྱེས་མདའ་འཕངས་རྒྱབ། །
འབེན་མེད་གཅིག་ཀྱང་ཕོག་པ་མེད། །
```

从那些之中，没有感受；"它的这个"，已成无二——我射出了俱生之箭：没有靶子，一处也没有射中。

【按】存疑。"དེ་རྣམས་ནས་ནི་ཚོར་བ་མེད"与"དེ་ཡི་འདི་ཡིན་གཉིས་མེད་སོང"两句，文义极简，本译依字面直译。大意可能是：在俱生智中，没有能受与所受；"它的""这个"等能所的分别，都已化为无二。

## 四、不取工钱的仆人毗瓦巴

```
གླ་སྟེར་འགྲོན་བུ་ཉི་ཤུ་མེད། །
དེ་འདྲའི་ཁོལ་པོ་བི་རཱུ་བྱེད། །
ང་ཡིས་ལྷན་སྐྱེས་མདའ་འཕངས་རྒྱབ། །
འབེན་མེད་གཅིག་ཀྱང་ཕོག་པ་མེད། །
```

连二十个贝币的工钱也不给，那样的仆人，毗瓦巴来做——我射出了俱生之箭：没有靶子，一处也没有射中。

【按】存疑。"གླ་སྟེར་འགྲོན་བུ་ཉི་ཤུ་མེད"，"འགྲོན་བུ"指贝币（古印度的小钱）。本译理解为：毗瓦巴甘愿做一个连二十个贝币工钱都拿不到的仆人，象征他不求任何回报、不取任何所得，与"没有靶子"同一意趣。依毗瓦巴的传记，他曾在酒馆赊酒、以神通令太阳停驻，也做过种种不合常规的事；这一句是否与传记中某一事迹相关，不能确定。

## 跋语

```
བི་རཱུ་བྱེད་པའི་རྡོ་རྗེའི་གླུ་རྫོགས་སོ། །
```

毗瓦巴所作的金刚歌，圆满。
