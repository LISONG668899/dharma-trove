# 双运义明示

梅纪巴（阿阇黎阿瓦都帝）造　据藏文译出

## 题解

《双运义明示》（梵 Yuganaddhaprakāśa，藏 zung du 'jug pa rab tu gsal ba bstan pa，直译"极明显示双运"）收于德格版丹珠尔续部释 ཝི 函第 113a 至 113b 页（东北目录 D2237），紧接在《真如十颂》（D2236）之后，同属梅纪巴的"无念法类"。作者署名"阿阇黎阿瓦都帝"，即梅纪巴；译者是金刚手与那措译师。

"双运"（zung du 'jug pa，梵 yuganaddha），是大手印与密续中的核心概念，意思是两种看似相对的方面——显现与空性、空性与悲心、空性与光明——本来合一、不可分离。全篇十颂四十句：

第一至四颂以缘起破实有：显现若认出其清净便是不变的；依缘而生的，其实也并非从缘而生；色不在色中、眼中、识中，就像火不在钻木中却依钻木而生；对儿子的贪恋也不是实有的。第五至七颂由此说明：诸法唯是缘起，所以无自性；安住于此的瑜伽士不失大乐，不取不舍而随顺世俗名言；不生故无自性，缘起故不灭，有无二边都坏灭时，双运便显现。第八、九颂正说双运：空性与悲心合一，空性与光明本然双运，具足一切殊胜相，是甚深本然的心要。第十颂说行持：身语意常安住于善妙的觉慧，无论作或不作，都可称为"行"。

体例：每颂先列藏文原颂于代码块中，再按完整的意义单元译出；为了便于理解而补的字，都放在方括号中。原文含混或可有两解之处，以"【按】"说明，不妄补内容。文末附通篇连读。

## 题名与礼敬

梵语题名：Yuganaddhaprakāśa-nāma。藏语题名：名为《双运义明示》。

敬礼文殊童子！

## 第一颂　清净即不变

```
གང་དང་གང་སྣང་དེ་དག་པར། །
རྟོགས་པར་གྱུར་ན་མི་འགྱུར་ཉིད། །
རྐྱེན་ལས་སྐྱེས་པ་དེ་འགྱུར་བ། །
དེ་ཡང་རྐྱེན་ལས་དེ་མ་སྐྱེས། །
```

凡是显现的一切，如果证悟它是清净的，［它］就是不变的。从因缘所生的，是变异的；然而，就连这［变异者］，其实也不是从因缘所生的。

【按】这一颂先立两层：从凡夫的角度，依缘而生的事物是变异的；但若证悟显现本身是清净的，它就是不变的。第四句"就连这也不是从因缘所生"，是中观的无生之义：缘起的事物，在胜义中并没有真实的"生"，这与龙树《中论》"诸法不自生，亦不从他生"的意思一致。"清净"（dag pa），在大手印中指显现本来离垢、无自性，而不是经过修治之后才变得干净。

## 第二、三颂　钻木取火之喻

```
གཟུགས་ལས་གཟུགས་ནི་ཡོད་མ་ཡིན། །
མིག་ལ་ཡང་ནི་ཡོད་མ་ཡིན། །
དེ་སྐྱེས་རྣམ་ཤེས་ལ་ཡང་མིན། །
ཇི་ལྟར་གཙུབ་ཤིང་མི་བསྟེན་བཞིན། །
གཙུབ་ཤིང་དང་ནི་གཙུབ་གཏན་དང་། །
སྐྱེས་བུའི་ལག་པ་མ་བསྟེན་པར། །
མངོན་དུ་མེ་ནི་གྲུབ་པ་མེད། །
དེ་ནི་འདི་དག་བསྟེན་ནས་འབྱུང་། །
```

［所见的］色，并不存在于色［境］之中，也不存在于眼［根］之中，也不在由它们所生的［眼］识之中。这就好比：不依靠上面的钻木、下面的木座和人的双手，火就不会显现成立；火是依靠这些而生起的。

【按】这两颂以钻木取火为喻，说明缘起无自性。"钻木"（gtsub shing），是钻火时上面旋转的木棒；"木座"（gtsub gtan），是下面承受的木块。火不在钻木中，也不在木座中，也不在手中，分开来找都找不到；但三者和合，火就生起。同样，所见之色，在境中、根中、识中分别去找都不可得，但根、境、识和合，色的显现就生起。所以显现是缘起，缘起即无自性。第二颂末句"就像不依靠钻木那样"，在藏文中属于第二颂，但意思要连到第三颂才完整，所以这里合为一段译出。

## 第四颂　对儿子的贪恋

```
བདག་གིས་བུ་བས་སྔར་རྨོངས་སམ། །
འོན་ཏེ་བུ་ལས་རྨོངས་པར་འགྱུར། །
བུ་ཉིད་ལ་ནི་སྔར་ཞེན་པ། །
དེ་ནི་རྫས་སུ་ཡོད་མ་ཡིན། །
```

是我在［有］儿子之前就已经愚痴［于他］了呢，还是由于儿子［出生］才生起愚痴的？对儿子本身先前所有的贪恋，［其实］并不是实体存在的。

【按】这一颂很难确定，以下是依上下文的推测。它似乎是以父母对儿子的贪恋为例，说明烦恼也是缘起无自性的：如果说在儿子出生之前就已经有对他的贪恋，那时儿子还不存在，贪恋缘什么而生？如果说是儿子出生之后才有，那么贪恋就是依儿子这个缘而生，并非自己本有的实体。所以，贪恋不是实体存在的。这样理解，与前面钻木取火之喻同属一个论证：境（色、儿子）与心（识、贪恋）都是缘起而无自性。

另外，经中有"梦中生子、子死而悲"的譬喻，梦中的儿子本来不存在，对他的贪恋与悲伤却真实生起；本颂也可能暗用这一譬喻。第一句"bdag gis bu bas sngar rmongs sam"的语法较特别，也可以理解为"是我比儿子先愚痴呢"，那么意思就是在问愚痴的先后次第。由于几种读法都可能成立，这一颂存疑。

## 第五颂　安住无自性，不失大乐

```
དེ་ལྟར་རྐྱེན་ཉིད་འབའ་ཞིག་ཕྱིར། །
ཆོས་རྣམས་རང་བཞིན་མེད་པ་ཉིད། །
དེ་ལ་གནས་པའི་རྣལ་འབྱོར་པས། །
བདེ་མཆོག་ལས་ནི་ཉམས་མི་འགྱུར། །
```

这样，因为［一切］唯是因缘而已，所以诸法都是没有自性的。安住于这［无自性］之中的瑜伽士，不会从最胜的大乐中退失。

【按】"最胜的大乐"（bde mchog），在密续中也是本尊胜乐金刚（Cakrasaṃvara）的名号，但这里应是一般意义的"最胜之乐"，即证悟空性而有的大乐。在密乘的语境中，"大乐"有其特定的修持内涵，须依具德上师的灌顶与口授来理解，不可凭文字揣度。

## 第六颂　不取不舍而随顺名言

```
ཐམས་ཅད་བླང་དང་དོར་མེད་ཀྱང་། །
ཐ་སྙད་དུ་ནི་འཇུག་པར་འགྱུར། །
འདི་དག་སྒྱུ་མ་བཞིན་དངོས་མེད། །
རྐྱེན་ལས་བྱུང་བར་རྟོགས་པའི་ཕྱིར། །
```

虽然对一切都没有取舍，但［瑜伽士］仍会在世俗名言中行事；因为［他］证悟了这一切都是从因缘所生，如幻化一般，没有实体。

【按】"世俗名言"（tha snyad），指世俗的言说、约定与行事。这一颂说：证悟无自性的瑜伽士，在胜义中无取无舍，但并不因此废弃世俗的行事；正因为知道一切如幻，所以能随顺名言而不被它束缚。这与《除恶见》《幻教示》中反对"以空废行"的意思一致。

## 第七颂　有无坏灭，双运显现

```
མ་སྐྱེས་ཕྱིར་ན་རང་བཞིན་མེད། །
རྐྱེན་ལས་བྱུང་བ་མི་འགག་ཉིད། །
དངོས་དང་དངོས་མེད་ཉམས་པས་ན། །
ཟུང་དུ་འཇུག་པ་སྣང་བར་འགྱུར། །
```

因为不生，所以没有自性；［而］从因缘所生的［显现］，又是不灭的。由于"有实"与"无实"［这两种执著］都已坏灭，双运便显现出来了。

【按】这一颂是全篇的枢纽：一方面诸法不生，所以无自性，这破除了"有实"之执；另一方面缘起显现不灭，这破除了"无实"之执。两种执著都坏灭了，显现与空性的双运就自然显露。"显现"（snang bar 'gyur），也可以理解为"被照见、被证悟"。

## 第八颂　空悲合一，空明双运

```
སྟོང་པ་སྙིང་རྗེ་གཅིག་གྱུར་པ། །
རང་གི་རྟོག་པས་བྱས་པ་མིན། །
སྟོང་པ་ཉིད་དང་རབ་གསལ་བ། །
རང་བཞིན་ཟུང་དུ་འཇུག་པ་ཉིད། །
```

空性与悲心合而为一，并不是由自己的分别念造作出来的；空性与极明之光，其自性本来就是双运的。

【按】"空性与悲心合一"（stong pa snying rje gcig gyur pa），是大乘与密乘共许的要点：证悟空性的智慧与利他的悲心并非两物。这里特别指出，这种合一"不是由自己的分别念造作出来的"，也就是说，不是先修空、再修悲，然后用意念把两者拼合起来，而是本然如此。"极明"（rab gsal ba），指心性的光明。"空性与光明双运"，是大手印直指心性时的根本要点：心的本性是空的，同时是明的，空与明不可分。

## 第九颂　具一切殊胜相的心要

```
རྣམ་པ་ཀུན་མཆོག་རྒྱས་ལྡན་པའི། །
ཟབ་མོ་གཉུག་མའི་སྙིང་པོ་ཉིད། །
མངོན་སུམ་རིག་པ་སངས་རྒྱས་ཀྱིས། །
མཆོད་པ་ལེགས་སྦྱོར་བྱེད་པ་ཡིན། །
```

那具足一切殊胜相、广大圆满的，正是甚深本然的心要；对这现量亲证的觉知，诸佛也以殊妙的供养来恭敬［它］。

【按】"具足一切殊胜相"（rnam pa kun mchog ldan pa），对应梵文 sarvākāravaropetā（具一切殊胜相），是《时轮》等密续中形容空性的用语，意思是空性并非一片空白，而是具足一切显现的妙相。原文多一"rgyas"字，可以理解为"广大、圆满"，这里照译。"本然"（gnyug ma），即本来如此、非造作的。

后两句较难确定。一种理解是：这现量的觉知，受到诸佛的供养恭敬；另一种理解是：以现量觉知，诸佛［自身］就是在作殊妙的供养，也就是说，安住于这觉知本身就是最上的供养。"现量亲证的觉知"（mngon sum rig pa）也可以理解为"现量了知［它的人］"。这里取第一种理解，存疑。

## 第十颂　作与不作都是行

```
ལུས་དང་ངག་དང་སེམས་ཀྱི་ནི། །
རྟག་ཏུ་བློ་བཟང་རབ་གནས་ན། །
སྤྱོད་པ་བྱེད་དང་མི་བྱེད་ཀྱང་། །
དེ་ལ་སྤྱོད་པ་བྱེད་ཅེས་བརྗོད། །
```

如果身、语、意都恒常安住于善妙的觉慧之中，那么，无论他［外表上］是在行持，还是不在行持，都可以说他是在行持。

【按】"善妙的觉慧"（blo bzang），指证悟双运的智慧。这一颂的意思是：对于证悟者来说，"行"不再以外在的作为来衡量；只要身语意恒常安住于证悟之中，即使外表上没有任何修行的动作，他也时时都在修行。这是证悟者的境界，以"恒常安住"为前提；尚未证悟的人，不能以此为由放弃实际的修持，梅纪巴在《除恶见》中对此已有明确的说明。

## 跋

《双运义明示》，阿阇黎阿瓦都帝所造，圆满。

金刚手与那措译出。

【按】"阿瓦都帝"（a ba dhū tī，梵 Avadhūti），是梅纪巴的称号之一，意思是"离弃者"，指舍离一切世俗分别的修行人。

## 通篇连读

敬礼文殊童子！

凡是显现的一切，如果证悟它是清净的，它就是不变的；从因缘所生的，是变异的，然而就连这变异者，其实也不是从因缘所生的。

所见的色，并不存在于色境之中，也不在眼根之中，也不在由它们所生的眼识之中；这就好比：不依靠上面的钻木、下面的木座和人的双手，火就不会显现，火是依靠这些而生起的。

是我在有儿子之前就已经愚痴于他了呢，还是由于儿子出生才生起愚痴的？对儿子本身先前所有的贪恋，其实并不是实体存在的。

这样，因为一切唯是因缘而已，所以诸法都没有自性；安住于这无自性之中的瑜伽士，不会从最胜的大乐中退失。

虽然对一切都没有取舍，但他仍会在世俗名言中行事，因为他证悟了这一切都是从因缘所生，如幻化一般，没有实体。

因为不生，所以没有自性；而从因缘所生的显现，又是不灭的。由于有实与无实两种执著都已坏灭，双运便显现出来了。

空性与悲心合而为一，并不是由自己的分别念造作出来的；空性与极明之光，其自性本来就是双运的。

那具足一切殊胜相、广大圆满的，正是甚深本然的心要；对这现量亲证的觉知，诸佛也以殊妙的供养来恭敬它。

如果身、语、意都恒常安住于善妙的觉慧之中，那么无论他外表上是在行持还是不在行持，都可以说他是在行持。

《双运义明示》，阿阇黎阿瓦都帝造，圆满。金刚手与那措译出。
