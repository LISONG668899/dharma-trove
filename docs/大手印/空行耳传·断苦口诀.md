# 空行耳传·断苦口诀

化身瑜伽士编集　据藏文译出

## 题解

《空行耳传·断苦口诀》（藏 mkha' 'gro ma'i gdams ngag snyan nas snyan du brgyud pa'i gdung ba gcad pa'i gdams pa，直译"空行母口诀·由耳到耳传承·断除焦灼之教授"）收于德格版丹珠尔续部释 ཞི 函第 145a 至 150a 页（东北目录 D2286），紧接在《甘露成就基础》（D2285）之后。跋语说是"化身瑜伽士"（sprul pa'i rnal 'byor pa）编排成文，没有译者跋语。

**题名中的"断苦"：**"苦"，藏文作 gdung ba，兼有"焦灼、苦恼"与"渴慕、思念"两义。本篇开头与结颂都说明，这里要断除的，不是一般的痛苦，而是这样一种修行人的焦灼：他有福分、积集了资粮，长久依止上师，受了无量的口诀，相续也被熏染了，却还没有以口诀串习纯熟、生起证悟，因而心中焦灼渴求。本篇就是为这样的人，汇集诸空行母与成就者以"表征"（brda）传授的口诀。

**结构：**礼敬与缘起之后，共有十五段口诀，每段以"断除［对］……之实相之焦灼的教授，第几"作结：

- 第一至第五：见地、修习、行持、觉受、果，由罗摩、森哈达拉、拉玛、甘嘎罗摩诃、玛哲五位空行母，以表征向阿阇黎东比嘿噜嘎（Ḍombi Heruka）宣说；
- 第六：无二瑜伽（空行母摩诃拉宣说）；
- 第七：双运瑜伽（空行母贝多向上师赞岭巴·迦布惹宣说）；
- 第八：开启莲花（空行母坎达罗哈宣说），全篇最隐晦的一段，以"盗取王库"的故事为表征；
- 第九、第十：帝洛巴向那洛巴宣说上师的十六法与弟子的十二法；
- 第十一：认识迷乱之识；
- 第十二：真性的二十种瑜伽；
- 第十三：三摩地的助伴、力量与支分；
- 第十四：不向未经观察的法器传授甘露般的口诀；
- 第十五：认识智慧宝珠；

最后是结颂与回向，归结于"在大手印的无垢地上全部圆满"。

**关于"表征"之语：**本篇几乎全是一句一喻的表征语言（芝麻与灯、水中月、空中鸟迹、贫家宝藏等），不作解释，深义要依上师口授来领会。其中有不少是大手印传统中常见的比喻，能依通行教义看出大意的，在按语中简要说明；看不出的，一律存疑，不妄补内容。许多空行母之名是音写，无法确定其梵文原形，也都存疑。

**关于密乘内容的告诫：**第五、第八等段落涉及密乘法器、脉道、风息、明点的隐语；第八段中"杀死守门人""斩下王后的头"等，都是象征语言，比喻以智慧斩断念头、我执与烦恼，或比喻圆满次第中风息与明点的运行，绝不是字面上的暴力行为。第三段所说的种种"禁行"，是以证悟为前提的成就者行持，不可照字面模仿。这些内容只能在具德上师座前依灌顶与口授领受，本译只照原文译出，不作修法上的解说。

**时代：**本篇汇集了东比嘿噜嘎、帝洛巴、那洛巴、夏瓦日巴等多位成就者传承的口诀，编成的时代应在那洛巴之后，约十一世纪前后。

**与前译的关系：**本篇以前没有译过，与已译篇目没有整段的重复。其中一些比喻（如"空中鸟迹""水中月""盐融于水""贫家宝藏""如河流般的瑜伽"），在此前所译的《道歌宝藏》《真如十颂》等篇中也多次出现，可以互相参看。

体例：本篇的口诀多为偈颂体，依本译的体例，按意义单元把藏文原文列于代码块中，再以完整的意义单元译出；为了便于理解而补的字，都放在方括号中。全篇共 381 句，各节标题后注明所含句号，标题为译者所加。原文含混或可有两解之处，以"【按】"说明。


## 一、题名、礼敬与缘起（第 1–17 句）

```
༄༅༅། །
རྒྱ་གར་སྐད་དུ།
ཌཱ་ཀི་ནི་ཨུ་པ་ཡ་ཤྲཱི་དྷ་ར་མི་ས་ར་བྷི་ར་ནཱ་མ།
བོད་སྐད་དུ།
མཁའ་འགྲོ་མའི་མན་ངག་སྙན་ནས་སྙན་དུ་བརྒྱུད་པ་གདུང་བ་བཅད་པའི་གདམས་པ་ཞེས་བྱ་བ།
བླ་མ་རྗེ་བཙུན་རྣམས་ལ་ཕྱག་འཚལ་ལོ། །
རྡོ་རྗེ་མཁའ་འགྲོ་མ་རྣམས་ལ་ཕྱག་འཚལ་ལོ། །
```

梵语题名：Ḍākinyupadeśa……-nāma。藏语题名：名为《空行母口诀·耳传·断苦之教授》。

敬礼诸上师尊者！敬礼诸金刚空行母！

【按】梵语题名藏文音写作"ཌཱ་ཀི་ནི་ཨུ་པ་ཡ་ཤྲཱི་དྷ་ར་མི་ས་ར་བྷི་ར"，除前面的"Ḍākinī-upa[deśa]"之外，后半音节散乱，无法还原，存疑。"断苦"，藏文作"གདུང་བ་བཅད་པ"（gdung ba bcad pa），"gdung ba"兼有"焦灼、苦恼"与"渴慕、思念"两义，这里的"断苦"，是断除修行人虽受了口诀、却仍未证悟而生起的焦灼与渴求，见第 13–17 句。

```
བླ་མ་རྗེ་བཙུན་མཆོག་དང་བྱིན་རླབས་འབྱུང་བའི་གནས། །
རྣལ་འབྱོར་མ་དང་མཁའ་འགྲོའི་ཚོགས་རྣམས་ལ། །
གུས་པ་མཆོག་གིས་རབ་ཏུ་རྩེ་གཅིག་འདུད་པར་བྱས་ནས་ཀྱང་། །
སྐལ་ལྡན་གདུང་བ་གང་ཟག་གདུང་བ་གཅད་པའི་ཕྱིར། །
བླ་མ་རྣམས་ཀྱི་བརྒྱུད་པའི་མན་ངག་བྲི། །
```

我以最上的恭敬，一心专注地顶礼殊胜的上师尊者、加持的来源，以及瑜伽母与空行的聚会；然后，为了断除有缘而焦灼之人的焦灼，写下诸上师传承的口诀。

```
དེ་ལ་རྟེན་གྱི་གང་ཟག་སྐལ་བ་དང་ལྡན་ཞིང་ཚོགས་ཆེན་པོ་བསགས་པ་དེས།
བླ་མ་དམ་པ་རྣམས་ཡུན་རིང་བར་བསྟེན་ཅིང་གདམས་པས་རྒྱུད་ཡོངས་སུ་བསྒོས་པར་གྱུར་ཀྱང་།
གདམས་ངག་གིས་གོམས་པར་མ་གྱུར་ཅིང་།
ཡིད་གདུང་བ་མ་ཆད་པ་དག་ལ་རྡོ་རྗེ་མཁའ་འགྲོ་མ་རྣམས་ཀྱིས།
སློབ་དཔོན་ཆེན་པོ་ཌོམྦི་ཧེ་རུ་ཀ་ལ་སོགས་པ་རྣམས་ལ་བརྡར་གསུངས་པ་དེ་དག་བདག་གིས་བསྟན་པར་བྱའོ། །
```

这里所说的根器之人，是具有福分、积集了广大资粮的人。他虽然长久依止了殊胜的上师们，相续也被口诀完全熏染了，却还没有以口诀串习纯熟，心中的焦灼还没有断除。对于这样的人，我要开示诸金刚空行母以表征（brda）向大阿阇黎东比嘿噜嘎等所说的［口诀］。

【按】这一段说明本篇的缘起：受了很多口诀、却还没有真正串习、心中仍然焦灼不安的修行人，就是本篇的对象。所以"断苦"的"苦"，不是一般的痛苦，而是求道者"未得而求"的焦灼。

"表征"（brda），是空行母传法的特殊方式：以种种比喻、象征、隐语来直接指示，不作解释。本篇的十五段口诀，几乎全是这样的表征之语，一句一喻，其深义要依上师的口授来领会。本译只照字面译出，能依通行的大手印教义看出大意的，在按语中简要说明；看不出的，一律存疑，不妄补内容。

## 二、第一口诀：见地的实相（第 18–36 句）

```
དེའང་མཁའ་འགྲོ་མ་རོ་མས།
སློབ་དཔོན་ཌོམྦི་ཧེ་རུ་ཀ་ལ་ལྟ་བའི་གནས་ལུགས་བརྡར་གསུངས་པ། །
```

空行母罗摩，以表征向阿阇黎东比嘿噜嘎宣说见地的实相：

```
ཏིལ་འབྲུ་དང་ནི་སྒྲོན་མས་ཕྱོགས་ཀུན་གསལ་བར་བྱེད། །
སྔགས་ཀྱིས་བཏབ་པའི་དུག་ནི་སྨན་གྱི་མཆོག་ཏུ་གྱུར་པ་སྟེ། །
རྨ་བྱའི་ཟས་ནི་གཞན་དུ་གྱུར་པ་ཡོད་མ་ཡིན། །
ཙནྡན་དྲི་དང་རི་དྭགས་གླ་རྩིའི་དྲི་བཞིན་ནོ། །
ཆུ་ཟླ་དང་ནི་རྒྱ་མཚོའི་རླབས་ནི་ཐ་དད་ཅུང་ཟད་མེད། །
སོལ་བའི་རང་བཞིན་གང་གི་ཁ་དོག་ནག་པོ་དག་དང་མཚུངས། །
རི་བོ་ཆེན་པོ་གང་གིས་བསྐྱོད་པར་མི་ནུས་པས། །
གངས་རིའི་ཆུ་ནི་གཞན་དུ་གྱུར་པ་ཡོད་མིན་ནོ། །
དཔེར་ན་དྲི་དང་སྒོག་སྐྱ་ཐ་དད་གྱུར་པ་མེད། །
ཉི་མ་ཟླ་བའི་ཡོན་ཏན་གསལ་བ་ཡིན། །
མཁའ་ལ་བྱ་འཕུར་རྗེས་ནི་ཚོལ་བས་རྙེད་མི་འགྱུར། །
ནམ་མཁའི་ཁམས་ནི་རྟོག་གེའི་སྤྱོད་ཡུལ་མ་ཡིན་ནོ། །
མཎྜལ་དག་ནི་ཕྱོགས་ལས་ཐམས་ཅད་རབ་ཏུ་སྙོམས། །
དཔེར་ན་རོ་ལངས་དང་ནི་ས་པྲ་ཀོ་ནེ་བཞིན། །
དཔའ་བོ་ངོ་མཚར་ནོར་བུ་ཤེལ་བཞིན་ནོ། །
```

芝麻与灯，照亮一切方向；以密咒加持的毒，成为最上的药；孔雀的食物，不会变成别的；就像旃檀的香与麝鹿的香；水中月与海浪，没有丝毫差别；就像黑色的炭，［它的］本性就是那黑色；大山，没有人能动摇；雪山的水，不会变成别的；譬如气味与大蒜，没有差别；日月的功德是明显的；在虚空中寻找飞鸟的踪迹，是找不到的；虚空界不是思辨的行境；诸曼荼罗，从各个方向都平等；就像起尸与"萨布拉果内"一样；勇士，像稀有的宝珠水晶一样。

```
ཞེས་གསུངས་ཏེ།
དེ་དག་ནི་གནས་ལུགས་ཀྱི་གདུང་བ་བཅད་པའི་གདམས་པ་ཞེས་བྱ་སྟེ་དང་པོའོ།། །།
```

［空行母］这样说了。这些叫作"断除［对］实相［之］焦灼的教授"，第一。

【按】这些表征多是大手印传统中常见的比喻，可大致这样理解：
- "芝麻与灯"：芝麻中本有油、灯本自明亮，比喻心性本具、本自光明，遍照一切；
- "以密咒加持的毒成为最上的药""孔雀的食物"：孔雀能食毒而更显光彩，比喻烦恼以方便转为道用；
- "旃檀之香、麝香"：香与香木不可分，比喻显现与心性不二；
- "水中月与海浪"：月影与波浪都是水，比喻显现与空性无别；
- "炭的黑色"：本性不可改变；
- "大山不动""雪山之水不变"：见地坚固不动；
- "气味与大蒜"：两者不可分；
- "空中鸟迹"：念头生灭不留痕迹，心性不可寻得；
- "虚空不是思辨的行境"：心性超越思辨。

"诸曼荼罗，从各个方向都平等"（maN+Dal dag ni phyogs las thams cad rab tu snyoms），可能指平坦的坛场，比喻平等性，存疑。"萨布拉果内"（sa pra ko ne），意思不明，可能是某种植物或隐语，存疑。"起尸"（ro langs），见《道歌宝藏（毗瓦巴）》第十节按语，比喻无取无舍。"勇士，像稀有的宝珠水晶一样"，可能是说证悟者如水晶般透明，随缘显现而本身不变，存疑。

"罗摩"（ro ma），音译兼意译（ro ma 又是右脉之名），存疑。

## 三、第二口诀：修习的实相（第 37–55 句）

```
དེ་ནས་མཁའ་འགྲོ་མ་སིངྷ་དྷ་རས།
སློབ་དཔོན་ཌོམྦི་ཧེ་རུ་ཀ་ལ་བསྒོམ་པའི་དོན་བརྡར་གསུངས་པ་ནི།
```

然后，空行母森哈达拉，以表征向阿阇黎东比嘿噜嘎宣说修习之义：

```
གནས་ནི་ཚང་ཚིང་དག་གམ་དུར་ཁྲོད་དུ། །
བདག་མེད་པ་ཡི་མཛའ་མོ་དག་དང་ཕྲད་བྱས་ལ། །
ཡིད་ནི་རབ་དགའི་བསམ་པ་ཡིས། །
དཔེར་ན་ལས་ཟིན་པ་ཡི་སྐྱེས་བུ་བཞིན། །
དམན་པའི་དོན་སྟོར་ནམ་མཁར་ཁྱེར་བར་བྱ། །
ཆུ་བོ་ཆེན་པོ་རྒྱུན་དུ་བབ་པ་བཞིན། །
དྲང་སྲོང་ཀུ་ཤ་གཙང་མའི་སྟེང་དུ་གཞག །
མར་མེའི་རྩེ་མོ་རླུང་གིས་མི་བསྐྱོད་དང་། །
མེ་ལོང་གཡའ་མེད་བཞིན་དུ་གསལ་བར་ཕྱི། །
བུ་ནི་ཡིད་འོང་བྲལ་བའི་མ་བཞིན་དུ། །
རུས་སྦལ་དང་ནི་མཁར་གཞོང་ཉི་མ་ལ། །
རྩལ་དང་ལྡན་པའི་འཕོང་སློབ་བརྩོན་པ་སྟེ། །
བསྡམས་པའི་བརྩོན་ནི་ངེས་པར་གྲོལ་བར་འགྱུར། །
ས་ལེ་སྦྲམ་ལས་བྱས་པའི་རྒྱན་བཞིན་དུ། །
བུ་རམ་དག་གི་རོ་ལ་མྱང་བར་བྱ། །
```

处所，在丛林或尸陀林中；与无我的女友相会；以心中极为欢喜的意乐，就像被业所牵的人一样，舍弃下劣的目的，带到虚空中去；就像大河恒常流动；安坐在仙人的清净吉祥草上；就像灯焰不被风所动，又像无锈的镜子一样明亮地擦拭；就像与爱子分离的母亲；像龟与铜盘［向着］太阳；像有技能而精进的学射者；收束的精进，一定能得到解脱；就像以黄金所作的饰物；要品尝砂糖的滋味。

```
ཞེས་གསུངས་པ་སྟེ།
དེ་དག་ནི་བསྒོམ་པའི་གནས་ལུགས་ཀྱི་གདུང་བ་གཅད་པའི་གདམས་པ་ཞེས་བྱ་སྟེ་གཉིས་པའོ།། །།
```

［空行母］这样说了。这些叫作"断除［对］修习之实相［之］焦灼的教授"，第二。

【按】这些表征可大致这样理解：
- "处所在丛林或尸陀林"：修行的环境要寂静；
- "与无我的女友相会"：无我母（Nairātmyā）是喜金刚的佛母，这里比喻与无我的智慧相应，是象征用语，存疑；
- "像被业所牵的人"：一心专注、不由自主地投入，存疑；
- "像大河恒常流动"：修习要相续不断，这是大手印"如河流般的瑜伽"；
- "灯焰不被风所动""无锈的镜子"：心安住不动而明了；
- "与爱子分离的母亲"：对修习念念不忘，如母亲思念失散的孩子；
- "有技能而精进的学射者"：专注而精进；
- "以黄金所作的饰物"：饰物虽有种种形状，本质都是黄金，比喻种种念头都是心性；
- "品尝砂糖的滋味"：觉受要亲自品尝，不可言说。

"龟与铜盘［向着］太阳"（rus sbal dang ni mkhar gzhong nyi ma la），意思不很清楚：龟可比喻收摄诸根（如龟收缩四肢），铜盘向日可比喻心的明照，存疑。"舍弃下劣的目的，带到虚空中去"（dman pa'i don stor nam mkhar khyer bar bya），意思不很清楚，存疑。"安坐在仙人的清净吉祥草上"，是印度传统修禅的坐垫。

"森哈达拉"（singha dha ra），音译，存疑。

## 四、第三口诀：行持的实相（第 56–73 句）

```
དེ་ནས་མཁའ་འགྲོ་མ་ལཱ་མས་སློབ་དཔོན་ཧེ་རུ་ཀ་ལ་སྤྱོད་པའི་དོན་བརྡར་གསུངས་པ་ནི།
```

然后，空行母拉玛，以表征向阿阇黎嘿噜嘎宣说行持之义：

```
བག་མ་དང་ནི་སྨྱོན་མའི་ཚུལ་བཞིན་ཏེ། །
གླང་པོ་བཙོངས་ལ་ཕག་རྒོད་གསད་པར་བྱ། །
ཉ་ནི་རྒྱ་མཚོ་ཆེན་པོར་ཡངས་པ་ཆེ། །
ནགས་རྣམས་མེ་ཡི་ཕུང་པོར་རབ་ཏུ་བསྲེག །
སྤྱན་གཟིགས་ཟས་ལ་རྟག་ཏུ་ལོངས་སྤྱོད་བྱ། །
རེས་འགའ་མགྱོགས་པའི་རྟ་ལ་བཞོན་པ་བྱ། །
གྲི་གུག་རྣོན་པོའི་མཚོན་ཆ་དག་གིས་ནི། །
ཅེ་སྤྱང་དུར་ཁྲོད་དག་ཏུ་རྣམ་པར་རོལ། །
འདབ་ཆགས་ཁྲ་ཡི་རྩལ་ནི་ཤིན་དུ་དྲག །
ཝ་ནི་དུར་ཁྲོད་ཉིད་དུ་ཤིན་དུ་གཞོལ། །
ཆང་འཐུངས་པ་དང་ཡུལ་རྣམས་གཞོལ་བ་འདྲ། །
མེ་ཏོག་དག་ལ་བུང་བ་རྒྱུ་བ་བཞིན། །
བུ་ཆུང་དང་ནི་སེང་གེ་མེ་ལོང་མཚུངས། །
སྟག་ནི་འཇིགས་པ་མེད་པར་ཀུན་དུ་རྒྱུ། །
ལྐུགས་པ་དག་ནི་ཁ་ལས་ཁྱོད་མ་འདའ། །
```

就像新娘与疯女的样子；卖掉大象，杀死野猪；鱼在大海中非常宽广；把森林在火堆中烧尽；恒常享用供奉的食物；有时骑上快马；豺狼以锋利的弯刀等兵器，在尸陀林中游戏；鹰隼的技能非常勇猛；狐狸非常专注于尸陀林；就像饮了酒而趋向诸境；就像蜜蜂在花间游行；小孩与狮子，同于镜子；老虎无所畏惧地到处游行；哑巴们，不要超出口中［所说］。

```
ཞེས་གསུངས་པ་སྟེ།
དེ་དག་ནི་སྤྱོད་པའི་གནས་ལུགས་གདུང་བ་གཅད་པའི་གདམས་པ་སྟེ་གསུམ་པའོ།། །།
```

［空行母］这样说了。这些是断除［对］行持之实相［之］焦灼的教授，第三。

【按】这些表征多与印度成就者的"禁行"（brtul zhugs）有关，可大致这样理解：
- "新娘与疯女"：外表谦和如新娘，内心无拘如疯女，这是成就者行持的两面；
- "卖掉大象，杀死野猪"：可能是比喻舍弃我慢（大象）与愚痴（野猪），存疑；
- "鱼在大海中非常宽广"：行持自在无碍；
- "把森林在火堆中烧尽"：以智慧之火焚烧烦恼；
- "有时骑上快马"：可能比喻驾驭风息或迅速前进，存疑；
- "豺狼在尸陀林中游戏""狐狸专注于尸陀林"：在尸陀林等可怖之处行持而无畏；
- "像蜜蜂在花间游行"：受用诸境而不贪著，如蜂采蜜而不损花；
- "老虎无所畏惧地到处游行"：行持无畏。

"恒常享用供奉的食物"（spyan gzigs zas），"spyan gzigs"是"呈献、供奉"之意，存疑。"就像饮了酒而趋向诸境"，意思不很清楚，存疑。"小孩与狮子，同于镜子"，可能是说小孩与狮子都像镜子一样，见什么就映现什么而不加分别，存疑。"哑巴们，不要超出口中［所说］"（lkugs pa dag ni kha las khyod ma 'da'），意思不明，可能是要求守密、不随意言说，存疑。

这些行持都是以证悟为前提的成就者禁行，须依具德上师的灌顶与口授来理解，不可照字面模仿。"拉玛"（lA ma），音译，存疑。

## 五、第四口诀：觉受的实相（第 74–92 句）

```
དེ་ནས་མཁའ་འགྲོ་མ་ཀཾ་ཀ་རོ་མ་ཧས།
སློབ་དཔོན་ཌོམྦི་ཧེ་རུ་ཀ་ལ་ཉམས་སུ་མྱོང་བའི་དོན་བརྡར་གསུངས་པ་ནི།
```

然后，空行母甘嘎罗摩诃，以表征向阿阇黎东比嘿噜嘎宣说觉受之义：

```
དཀར་པོ་ཚེས་ནི་ཟླ་བའི་རིམ་པ་སྟེ། །
གཞའ་ཚོན་དག་ནི་ནམ་མཁའ་དག་ལ་མཛེས། །
གཞོན་ནུ་མ་ཡིས་མ་སྨྲས་ཅི་སྟེ་གོ། །
འཁུར་བ་ཆུས་བཀང་པ་ནི་སྨྲ་མི་བྱེད། །
ཁུག་རྣ་ལྟ་བུ་སྣི་བའི་རྣམ་པ་ཡིན། །
དབུལ་པོའི་རང་བཞིན་གཏེར་ལྡན་ཤིན་ཏུ་ངོ་མཚར་ཆེ། །
ལན་ཚྭ་ཆུ་ཉིད་ལ་ནི་རབ་ཏུ་ཐིམ། །
ནམ་མཁའི་ཉམས་ལས་འདའ་བར་མི་བྱེད་དོ། །
བསླུས་པའི་ཆོས་རྣམས་ལ་ནི་རེ་བར་མི་བྱེད་ཅིང་། །
རལ་གྲིའི་ངར་ནི་སྣུམ་གྱིས་ཉམས་པར་འགྱུར། །
རྒྱལ་པོ་དག་ནི་རྐུན་པོས་འཇིགས་མི་བྱེད། །
ཝ་ཡིས་སེང་གེ་སྐྲག་པར་འགྱུར་མ་ཡིན། །
མཁའ་ལྡིང་རྣམས་ནི་མཁའ་ལས་དཔངས་མི་དམའ། །
འདི་ཉིད་ཡིན་དང་མ་ཡིན་གང་ཡང་མིན། །
སུས་བྱས་གང་ཡིན་གོ་བ་སུ་ཞིག་ཡིན། །
```

白分的日子，是月亮［渐增］的次第；彩虹在虚空中很美丽；少女不说话，又怎么会明白呢？盛满水的水罐，不会发出声音；像弯曲的耳朵，是弯垂的形相；贫穷者的本性中具有宝藏，非常稀有；盐完全融化于水中；不超出虚空的觉受；对欺诳的诸法不抱希望；剑刃被油所损坏；国王们不怕盗贼；豺狼不会使狮子恐惧；金翅鸟们的高度，不低于虚空；"这就是"与"不是"，什么都不是；是谁所作？是什么？谁能明白？

```
ཞེས་གསུངས་པ་སྟེ།
དེ་དག་ནི་ཉམས་སུ་མྱོང་བའི་གནས་ལུགས་ཀྱི་གདུང་བ་གཅད་པའི་གདམས་པ་སྟེ་བཞི་པའོ།། །།
```

［空行母］这样说了。这些是断除［对］觉受之实相［之］焦灼的教授，第四。

【按】这些表征可大致这样理解：
- "白分的日子是月亮渐增的次第"：觉受与证悟像上弦月一样逐渐增长；
- "彩虹在虚空中很美丽"：觉受显现而无实，如彩虹；
- "少女不说话"：觉受不可言说，如少女的心事；
- "盛满水的水罐不会发出声音"：真正有证悟的人不炫耀，如满罐无声；
- "贫穷者的本性中具有宝藏"：众生本具佛性而不自知，这是《宝性论》著名的"贫家宝藏"之喻；
- "盐完全融化于水中"：心与心性、觉受与空性融为一味；
- "国王们不怕盗贼""豺狼不会使狮子恐惧""金翅鸟不低于虚空"：证悟者对念头与障碍无所畏惧。

"像弯曲的耳朵，是弯垂的形相"（khug rna lta bu snyi ba'i rnam pa），意思不明，存疑。"剑刃被油所损坏"（ral gri'i ngar ni snum gyis nyams par 'gyur），字面是"剑刃会被油所损"，意思不很清楚，可能是比喻觉受的锋芒被贪著所钝化，存疑。"甘嘎罗摩诃"（kaM ka ro ma ha），音译，存疑。

## 六、第五口诀：果的实相（第 93–110 句）

```
དེ་ནས་མཁའ་འགྲོ་མ་མ་ཏྲེ་ཡིས་སློབ་དཔོན་ཌོམྦི་ཧེ་རུ་ཀ་ལ་འབྲས་བུའི་གནས་ལུགས་ཀྱི་གདུང་བ་གཅད་པའི་བརྡར་གསུངས་པ་ནི།
```

然后，空行母玛哲，以表征向阿阇黎东比嘿噜嘎宣说断除［对］果之实相［之］焦灼［的口诀］：

```
ཡི་གེ་བཞི་པ་དག་གིས་ཟླ་བ་རྒྱས། །
ཧེ་རུ་ཀ་ཡི་ནམ་མཁའི་ངང་ཉིད་དེ། །
རྡོ་རྗེ་དང་ནི་པདྨ་ཡི་གེ་བྲལ། །
ཁ་ཊྭཱཾ་ག་ནི་ཉི་མའི་འོད་ཟེར་བཞིན། །
རྡོ་རྗེ་དང་ནི་ལྗོན་ཤིང་འབྲས་བུ་སྟེ། །
བྱ་ནི་ངང་པ་ཆུ་ན་རྟག་ཏུ་གནས། །
པདྨའི་སྡོང་བུ་འདབ་མ་རབ་ཏུ་རྒྱས། །
ཌ་མ་རུ་ནི་བུང་བའི་རྩི་དང་མཚུངས། །
བདུད་རྩི་སྐལ་ལྡན་རྣམས་ལ་ཆུ་ཤེལ་ཏེ། །
རིན་ཆེན་བདུན་ལ་རྒྱལ་པོས་མངའ་ཡང་མཛད། །
རྣམ་གྲངས་རྣམས་ནི་རས་ཀྱིས་ཤེས་ལ་བཀབ། །
ཀུན་འདར་མ་ལ་བྱེ་བྲག་གང་ཡང་མེད། །
རྩལ་ཆེན་རྫོགས་པའི་སེང་གེ་གངས་ལ་གནས། །
ཤེལ་ནི་ཕྱི་ནང་མེད་པར་ཤིན་དུ་དག །
བཙོ་མའི་གསེར་ནི་དྲི་མའི་གཡའ་དང་བྲལ། །
```

以第四个字，月亮圆满；［这］就是嘿噜嘎的虚空状态；金刚与莲花，远离文字；天杖，像太阳的光芒；金刚与树的果实；鸟——天鹅，恒常住在水中；莲花的茎与叶，非常繁茂；手鼓，同于蜜蜂之蜜；甘露对于有缘者，就是水晶；国王也统治着七宝；诸种异名，以布遮盖而认知；在"衮达玛"中，没有任何差别；威力圆满的狮子，住在雪山上；水晶内外都没有，极为清净；炼过的黄金，离开了垢染之锈。

```
ཞེས་གསུངས་པ་སྟེ།
དེ་དག་འབྲས་བུའི་གནས་ལུགས་ཀྱི་གདུང་བ་གཅད་པའི་གདམས་པ་སྟེ་ལྔ་པའོ།། །།
```

［空行母］这样说了。这些是断除［对］果之实相［之］焦灼的教授，第五。

【按】这一段的表征大多涉及密乘的法器与象征（金刚、莲花、天杖、手鼓、甘露等），是圆满次第与果位的隐语，须依具德上师的灌顶与口授来领受，这里只照原文译出，不作解说。可以大致看出的是：
- "以第四个字，月亮圆满"："第四"可能指第四灌顶或第四喜，月亮圆满比喻果位的圆满，存疑；
- "天鹅恒常住在水中"：天鹅能从水乳中只取乳，比喻证悟者处于世间而不染，存疑；
- "威力圆满的狮子住在雪山上"：果位稳固无畏；
- "水晶内外都没有，极为清净""炼过的黄金离开了垢染之锈"：果位就是本来清净的心性离开了客尘。

"衮达玛"（kun 'dar ma，梵 avadhūtī），即中脉，"在中脉中没有任何差别"，存疑。"诸种异名，以布遮盖而认知"（rnam grangs rnams ni ras kyis shes la bkab），意思不明，存疑。"玛哲"（ma tre），音译，存疑。

## 七、第六口诀：无二瑜伽（第 111–138 句）

```
མཁའ་འགྲོ་མ་མ་ཧ་ལས།
སློབ་དཔོན་ཌོམྦི་ཧེ་རུ་ཀ་ལ།
གང་དུ་གསུངས་པ་དེ་དག་ཀྱང་།
གཉིས་མེད་ཀྱི་རྣལ་འབྱོར་དུ་བྱ་བའི་བརྡར་གསུངས་པ་ནི།
```

空行母摩诃拉，以表征向阿阇黎东比嘿噜嘎宣说：凡是在任何地方所说的那些［口诀］，也都要作为无二的瑜伽：

```
རྒྱལ་པོ་རྣམས་ནི་རིན་ཆེན་སྐལ་བར་ལྡན། །
སྨན་པ་བཟང་དང་ཕྲད་པར་གྱུར་པ་ལས། །
ཉི་མའི་དཀྱིལ་འཁོར་མུན་པ་སེལ་བ་ལྟར། །
རུས་སྦལ་རྒྱ་མཚོ་དག་ཏུ་འགྲོ་མི་འགྱུར། །
སྟོབས་ལྡན་གྱད་ཀྱིས་ཕ་རོལ་འཇོམས་པར་བྱེད། །
རི་བོ་འགྱེལ་ན་ཆུ་རྣམས་འབྲུབ་པར་བྱེད། །
ནགས་ཁྲོད་དག་ན་རྔོན་པ་གླུ་རྣམས་ལེན། །
མེ་ཤེལ་རས་བལ་འདུས་པས་མེ་འབྱུང་འགྱུར། །
གསེར་འགྱུར་རྩི་ནི་ཤིན་ཏུ་ངོ་མཚར་ཆེ། །
ཆུ་དང་བཅས་པའི་སྐྱེ་ཤིང་ལོ་འདབ་རྒྱས། །
སྦུར་ལེན་ནོར་བུ་དག་ནི་སྦུར་རྣམས་སྡུད། །
ཤེས་པ་རྣམས་ནི་གཞན་གྱི་ལུས་ལ་འཇུག །
སྤྲེའུ་རྣམས་ནི་དྲན་པར་ལྡན་པ་སྟེ། །
མཉན་པས་འགྲོ་བ་དག་ནི་སྒྲོལ་བར་བྱེད། །
ག་བུར་སྦྱོར་བས་ཚད་པའི་ནད་རྣམས་སེལ། །
དགེ་སློང་བག་དང་ལྡན་པ་གསོ་སྦྱོང་བྱེད། །
རིགས་ངན་རྒྱལ་པོའི་ཁབ་ཏུ་མི་གནས་ཏེ། །
བཅད་པར་གྱུར་ན་ཏཱ་ལའི་ལོ་འདབ་མེད། །
སྒྱུ་མ་མཁན་པོ་སྒྱུ་མའི་ལོངས་སྤྱོད་མཁས། །
རྒྱལ་པོའི་བུ་མོ་རྒྱན་དང་རབ་ཏུ་ལྡན། །
གར་མཁན་རྣམས་ནི་གར་གྱི་རྣམ་པ་བྱེད། །
སྦྲང་མ་རྣམས་ནི་ངན་སྐྱུགས་ནང་དུ་རྒྱུག །
```

国王们具有珍宝的福分；由于遇到了良医；就像日轮驱除黑暗；龟不会走进大海；有力的力士摧毁对手；山若倒塌，诸水就奔流；猎人们在森林中唱歌；火晶与棉花会合，就生出火来；点金药非常稀有；有水的树木，枝叶繁茂；吸草的宝珠，吸聚草屑；神识进入他人的身体；猴子们具有记性；船夫渡送众生；以樟脑调配，消除热病；具足谨慎的比丘作布萨；下劣种姓的人不住在王宫中；多罗树一旦砍断，就不再生叶；幻师善于幻化的受用；国王的女儿具足装饰；舞者们作种种舞姿；苍蝇们奔向呕吐物中。

```
ཅེས་གསུངས་པ་སྟེ།
དེ་དག་ནི་གཉིས་སུ་མེད་པའི་རྣལ་འབྱོར་གྱི་གནས་ལུགས་ཀྱི་གདུང་བ་གཅད་པའི་གདམས་པ་སྟེ་དྲུག་པའོ།། །།
```

［空行母］这样说了。这些是断除对无二瑜伽之实相之焦灼的教授，第六。

【按】这一段的表征数量很多，彼此之间没有明显的次第，大致都是说明"无二"——方便与智慧、显现与空性、能与所不二，以及修行中的种种要点。可大致看出的是：
- "遇到良医""日轮驱除黑暗"：遇到上师而无明消除；
- "火晶与棉花会合，就生出火来"：方便与智慧（或上师与弟子、因与缘）和合而生证悟；
- "点金药非常稀有"：口诀能把烦恼转为智慧，如点金药化铁为金；
- "吸草的宝珠"（琥珀），比喻心性能摄受一切显现；
- "神识进入他人的身体"：指"夺舍"（grong 'jug）之法，那洛六法之一，存疑；
- "船夫渡送众生"：上师或证悟者救度众生；
- "多罗树一旦砍断，就不再生叶"：断除轮回之根，不再受生（这是佛经中常见的比喻）；
- "幻师善于幻化的受用""舞者作种种舞姿"：了知一切如幻而游戏其中；
- "苍蝇奔向呕吐物"：可能是反面的比喻，指凡夫贪著不净之境，存疑。

"龟不会走进大海"、"山若倒塌，诸水就奔流"、"猴子们具有记性"、"下劣种姓的人不住在王宫中"、"国王的女儿具足装饰"等，意思不很清楚，存疑。"摩诃拉"（ma ha la），音译，存疑。

## 八、第七口诀：双运瑜伽（第 139–165 句）

```

བླ་མ་ཟངས་གླིང་པ་ལ་ཀཔྤུ་ར་ལ་ཟུང་འཇུག་གི་རྣལ་འབྱོར་གྱི་བརྡ་གསུངས་པ་ནི།

མ་ནི་བུ་ལ་རབ་ཏུ་ཆགས་པའོ། །
བུ་རམ་ཤིང་ལས་བུ་རམ་འབྱུང་བ་ལྟར། །
རྒྱ་མཚོར་ཕྱིན་པས་ནོར་བུ་རྙེད་པར་འགྱུར། །
ཆུ་ཡི་ནང་གི་ཟླ་བ་སེལ་མི་བྱེད། །
ནོར་བུ་མེ་ཤེལ་རྩོལ་སྒྲུབ་དག་དང་བྲལ། །
རྒྱལ་པོའི་བཙུན་མོ་རྒྱལ་པོ་ཉིད་ཀྱང་ཡིན། །
ཚོང་པ་ཚོང་འདུས་དག་ཏུ་གནས་པར་བྱེད། །
རྫ་མཁན་དག་ནི་སོ་བཏང་རྫ་ལ་སྤྱོད། །
སྤྲིན་དང་བྲལ་བའི་ནམ་མཁའ་རབ་ཏུ་དངས། །
དམུ་རྒོད་མི་སྲུན་བརྟུལ་བས་ཞོན་པར་བྱེད། །
མཛའ་བོ་དག་གིས་གསུངས་པས་རེ་བ་མེད། །
རྨི་ལམ་སད་པས་དགྲ་དང་ཡོངས་སུ་བྲལ། །
ཁྱིམ་བདག་མཚོན་ཆའི་འཁོར་ལོ་རབ་ཏུ་རྣོ། །
ཆོམ་རྐུན་རབ་ཏུ་མང་བས་མེལ་ཚེ་མཁས། །
ཆུ་རྣམས་མ་ལུས་རྒྱ་མཚོ་རོ་གཅིག་འགྱུར། །
ཕ་ལམ་རྡོ་རྗེས་དངོས་པོ་ཐམས་ཅད་འབིགས། །
སྨིག་རྒྱུའི་ཆུ་ཡིས་གདུང་བར་མི་བྱེད་དོ། །
གཞའ་ཚོན་ཡལ་བ་དག་ལ་སྡུག་བསྔལ་མེད། །
རྨི་ལམ་རྨིས་པའི་ནོར་ལ་སྟེར་མི་བྱེད། །
བྲག་ཅའི་སྒྲ་ལ་རང་ཉིད་དགའ་བ་སྟེ། །
བྲམ་ཟེ་ཆང་འཐུང་བ་ནི་ཤིན་ཏུ་གསང་། །
རྣལ་འབྱོར་རྣལ་འབྱོར་རྣལ་འབྱོར་ཤིན་ཏུ་ཆེ། །
```

"赤年萨勒"具有悲心；母亲非常爱恋孩子；就像从甘蔗中生出砂糖；到了大海就能找到宝珠；不去除水中的月亮；宝珠与火晶，远离勤作；国王的王后，也就是国王本身；商人们住在市集中；陶工们使用烧好的陶器；离云的虚空极为清澈；野性未驯的马，以调伏而骑乘；由于朋友们说了，［就］没有希望；从梦中醒来，就与敌人分离了；居士的兵器之轮非常锋利；盗贼很多，所以看守者很善巧；一切河水，在大海中都成为一味；金刚石穿透一切事物；不被阳焰之水所苦；彩虹消散，并没有痛苦；对梦中所得的财物，不去布施；对着回声，自己欢喜；婆罗门饮酒，非常秘密；瑜伽、瑜伽、瑜伽，极为广大。

```
ཞེས་གསུངས་པ་སྟེ།
དེ་དག་ནི་ཟུང་འཇུག་གི་རྣལ་འབྱོར་གྱི་གནས་ལུགས་ཀྱི་གདུང་བ་གཅད་པའི་གདམས་པ་སྟེ་བདུན་པའོ།། །།
```

［空行母］这样说了。这些是断除对双运瑜伽之实相之焦灼的教授，第七。

【按】这一段的表征，大致都在说明"双运"：显现与空性、方便与智慧不二，以及证悟后对显现的态度。可大致看出的是：
- "从甘蔗中生出砂糖""到了大海就能找到宝珠"：依修持而得证悟；
- "不去除水中的月亮"：不需要去除显现，显现本身就是空性；
- "宝珠与火晶，远离勤作"：如意宝与火晶自然起作用，比喻任运成就；
- "国王的王后，也就是国王本身"：方便与智慧（父与母）不二；
- "离云的虚空极为清澈"：心性离开了念头之云；
- "野马以调伏而骑乘"：调伏心与风息；
- "从梦中醒来，就与敌人分离了"：了知一切如梦，烦恼之敌自然消失；
- "一切河水在大海中成为一味"：一切显现在心性中一味；
- "不被阳焰之水所苦""彩虹消散并没有痛苦""对梦中所得的财物不去布施""对着回声自己欢喜"：了知一切如幻、如梦、如虹、如回声，所以不为显现所苦，也不执为实有；
- "婆罗门饮酒，非常秘密"：密乘的行持要隐秘，存疑。

"赤年萨勒"（khri snyan sa le），意思不明，可能是人名或某种事物，存疑。"由于朋友们说了，就没有希望"（mdza' bo dag gis gsungs pas re ba med），意思不很清楚，存疑。"盗贼很多，所以看守者很善巧"，可能是说念头越多，正念越要警觉，存疑。

"贝多"（be to），音译，存疑。"上师赞岭巴·迦布惹"（bla ma zangs gling pa kap+pu ra），"zangs gling pa"字面是"铜洲人"，可能指来自某个岛国的上师；"迦布惹"（kappura，梵 karpūra，意为樟脑），可能是他的名字，存疑。

## 九、第八口诀：开启莲花（第 166–193 句）

```
དེ་ནས་མཁའ་འགྲོ་མ་ཁཎྜ་རོ་ཧས།
སློབ་དཔོན་ཌོམྦི་ཧེ་རུ་ཀ་ལ།
པདྨོ་ཁ་འབྱེད་པའི་གདམས་པ་བརྡར་གསུངས་པ་ནི།
```

然后，空行母坎达罗哈，以表征向阿阇黎东比嘿噜嘎宣说开启莲花的教授：

```
དབུལ་པོ་རྣམས་ནི་ནོར་མེད་སྡུག་བསྔལ་དེ། །
ནང་ཕྱེད་མཚན་མོ་དག་གི་དུས་སུ་ནི། །
རྒྱལ་པོའི་བང་མཛོད་བདག་ཉིད་བརྐུ་བར་བྱ། །
མ་སྐྱེས་དཔེ་མེད་མཛེས་པའི་གྲོགས་བརྐུས་ལ། །
ཤིན་ཏུ་མགར་བ་མཁས་པའི་ལྡེ་མིག་གིས། །
གཟེ་མ་བཞི་བསྟེན་སྒོ་ལྕགས་དབྱེ་བར་བྱ། །
སླར་ཡང་སྒོ་དེ་དམ་དུ་གཅད་པར་བྱ། །
རྐེད་གཏན་གཞུག་ཅིང་རྐེད་གཟེར་བསྡམ་པར་བྱ། །
སྒོ་བ་པོ་དེ་ཡོངས་སུ་གསད་བྱ་ཞིང་། །
འབྲུ་མར་འབབ་པ་སྟེགས་བྱས་ལ། །
བཙའ་མེད་ལྕགས་ལས་བྱས་པ་དག་གི་གྲིས། །
རྒྱལ་པོའི་བཙུན་མོ་དམ་པ་མགོ་བཅད་དེ། །
དམག་དཔོན་ཆེན་པོ་དུག་གིས་གསད་པར་བྱ། །
མེལ་ཙེ་བ་དང་བློན་པོ་རྣམས་ཀྱང་བསད། །
དེ་ནས་རྒྱལ་པོའི་བང་མཛོད་ཁ་ཕྱེ་ལ། །
གོས་བཟང་དག་གིས་ཡོངས་སུ་དྲིལ་བ་ཡི། །
གསེར་དང་དངུལ་གྱི་གའུ་ཁ་ཕྱེ་ལ། །
ཕྱོགས་མེད་པ་ཡི་ནོར་བུ་རིན་ཆེན་བལྟ། །
མར་མེ་དང་ནི་ནམ་མཁའི་བུ་མོའི་ཚུལ། །
ཉི་མ་དང་ནི་ཟླ་བས་བདུད་རྩི་འཐིགས། །
ཆེ་བས་ཆེ་བའི་རབ་ཏུ་ཆེ་བ་ཉིད། །
རྨ་བྱ་ཁྱི་དང་ཕག་དང་སྨྱོན་པ་ཉིད། །
ཤ་ཟ་བུང་བ་ཤིན་དུ་རོལ་བར་བྱེད། །
```

穷人们没有财富而痛苦，要在半夜的时候，亲自去盗取国王的库藏。盗取了那不生、无比、美丽的伴侣之后，以极为善巧的铁匠所作的钥匙，依靠四根销子，打开门闩；然后再把那门紧紧关上；插上腰杠，钉牢腰钉；把那守门人完全杀死；以流淌的芝麻油作台；以无锈之铁所作的刀，斩下国王殊胜王后的头；以毒杀死大将军；也杀死守望者与大臣们。

然后，打开国王的库藏，打开以上好的衣物层层包裹的金银护身盒，观看那无方所的珍宝。灯与天女的样子；日月滴下甘露；大中之大，极为广大；孔雀、狗、猪与疯人；食肉的蜂，极为游戏。

```
ཅེས་གསུངས་པ་སྟེ།
དེ་དག་ནི་པདྨོ་ཁ་དབྱེ་བའི་མན་ངག་གི་གནས་ལུགས་བརྡར་གསུངས་པའི་གདམས་པ་སྟེ་བརྒྱད་པའོ།། །།
```

［空行母］这样说了。这些是以表征宣说开启莲花口诀之实相的教授，第八。

【按】这一段是本篇中最为隐晦的一段，以"盗取王库"的故事，作为圆满次第中"开启莲花"（padmo kha dbye ba）这一口诀的表征。其中"杀死守门人""斩下王后的头""以毒杀死大将军""杀死守望者与大臣"等，都是象征的语言，比喻以智慧斩断种种念头、我执与烦恼，或比喻风息、明点在身体脉道中的运行，绝不是字面上的暴力行为。"国王的库藏""无方所的珍宝"，比喻本具的心性与俱生智慧。

"开启莲花"可能是指打开心间（或其他脉轮）的脉结，"四根销子""门闩""腰杠""腰钉"等，都是身体脉道与修法的隐语；"灯与天女""日月滴下甘露"，是圆满次第中明点与风息的象征用语；"孔雀、狗、猪与疯人""食肉的蜂"，可能是比喻证悟者的种种行持或觉受。这些都是无上瑜伽续圆满次第中有特定内涵的象征用语，只能在具德上师座前依灌顶与口授领受，这里只照原文译出，不作解说，存疑。

"坎达罗哈"（khaN+Da ro ha，梵 Khaṇḍarohā），是胜乐坛城中的空行母之名。

## 十、第九口诀：上师的十六种功德（第 194–217 句）

```
དེ་ནས་རྣལ་འབྱོར་པ་ཏེ་ལོ་པས་དཔལ་ནཱ་རོ་པ་ལ།
བླ་མའི་ཆོས་བཅུ་དྲུག་པ་ཞེས་བྱ་བའི་གདམས་པ་བརྡར་གསུངས་པ་ནི།
```

然后，瑜伽士帝洛巴以表征向吉祥那洛巴宣说名为"上师的十六法"的教授：

```
ས་གཞི་བཟང་པོ་དག་གི་ཐུན་མོང་ལ། །
བློ་དམན་རྣམས་ཀྱིས་ལས་ལ་མ་ཞུགས་ཤིང་། །
སྡུག་བསྔལ་ནད་ཀྱིས་གཟིར་བ་བསལ་བའི་ཕྱིར། །
དེད་དཔོན་ལྟ་བུ་དག་གིས་སེམས་བསྐྱེད་ལ། །
མུ་ཏིག་འཕྱང་བ་ཆེན་པོ་གཟུང་བྱས་ལ། །
འབྱུང་བ་ས་ཆུ་མེ་རླུང་དབང་དུ་བསྡུས། །
རྒྱ་མཚོ་ཆེན་པོ་བཞི་ནས་རིན་ཆེན་བཙལ། །
སྦྲང་རྩིའི་བཅུད་ནི་མར་གྱི་སྙིང་པོར་ལྡན། །
གོམས་པར་བྱ་ཞིང་བཟོ་ལ་བྱང་བར་བྱ། །
ཕྱེ་མ་ལེབ་དང་རི་དྭགས་བུང་བ་དང་། །
ཉ་དང་གླང་ཆེན་དག་ལས་རབ་ཏུ་གྲོལ། །
དུག་མདས་མ་ཕོག་ཕོག་ཀྱང་སླར་ལ་གསོ། །
ཐ་རྒོད་ཆུ་ཡིས་རབ་ཏུ་བངས་པར་བྱ། །
རབ་ཏུ་ནོར་མང་ཕྱུག་ཅིང་ཤིན་དུ་ཕྱུག །
ཞིང་པའི་ལས་ལ་རབ་ཏུ་གུས་པར་འགྱུར། །
མ་ཡིས་བུ་ནི་རབ་ཏུ་སྨིན་པར་བྱེད། །
འཇོམས་བྱེད་སེང་གེའི་བླ་མ་དེ་དག་ལ། །
ལུས་ངག་ཡིད་གུས་ཡོ་བྱད་ཅི་དགོས་དབུལ། །
གུས་པར་ལྡན་པས་དེ་འདྲ་ཡང་དང་ཡང་། །
རྩལ་མེད་རྟེན་ཅིང་བསྙེན་བཀུར་རབ་ཏུ་འབད། །
```

在善妙大地的共同［处］，［他］不从事劣慧者的事业；为了消除被痛苦与疾病所逼迫［的众生］，像船长一样发起菩提心；持有长垂的大珍珠［串］；把地、水、火、风诸大收归自在；从四大海中寻找珍宝；蜂蜜的精华，具有酥油的心要；串习［纯熟］，善于工巧；从飞蛾、鹿、蜜蜂、鱼与大象中完全解脱；不被毒箭所射中，即使被射中也能重新治愈；野马被水充分浸湿；非常富有，财富众多；对农夫的工作非常恭敬；［像］母亲使孩子成熟。

对于那些能摧伏［烦恼］、如狮子般的上师，要以身语意的恭敬，供养一切所需的资具；具足恭敬，一再这样［承事］，不倦地依止，极力承事供养。

```
ཅེས་གསུངས་པ་སྟེ།
དེ་དག་ནི་བླ་མ་ཆོས་དེ་རྣམས་དང་ལྡན་པའི་སྡིག་པའི་གྲོགས་པོ་སྤང་བ་སྟེ་དགུ་པའོ།། །།
```

［帝洛巴］这样说了。这些是［依止］具足那些法的上师，舍弃恶友，第九。

【按】这一段是帝洛巴向那洛巴说明"具格上师"的十六种功德，也以表征的方式说出。可大致看出的是：
- "像船长一样发起菩提心"：上师以菩提心带领众生渡过轮回；
- "把地、水、火、风诸大收归自在"：上师对身体的风息、诸大有自在；
- "从四大海中寻找珍宝"：上师精通四部续（或四灌顶）；
- "从飞蛾、鹿、蜜蜂、鱼与大象中完全解脱"：这是印度的著名比喻，飞蛾死于色（扑火）、鹿死于声（被歌声诱捕）、蜜蜂死于香（困于花中）、鱼死于味（吞饵）、大象死于触（被母象诱入陷阱），比喻五根贪著五境；上师已经从这五种贪著中解脱；
- "不被毒箭所射中，即使被射中也能重新治愈"：上师不被烦恼所伤，即使有烦恼也能立刻对治；
- "母亲使孩子成熟"：上师以慈悲成熟弟子。

"持有长垂的大珍珠［串］"、"蜂蜜的精华具有酥油的心要"、"野马被水充分浸湿"等，意思不很清楚，存疑。按题目说是"十六法"，但原文的条目难以确定地分出十六条，存疑。

最后的标题"这些是［依止］具足那些法的上师，舍弃恶友"，藏文作"བླ་མ་ཆོས་དེ་རྣམས་དང་ལྡན་པའི་སྡིག་པའི་གྲོགས་པོ་སྤང་བ"，字面是"上师具足那些法的、舍弃恶友"，中间似有脱字，这里依意补出"依止"，存疑。

## 十一、第十口诀：弟子的十二种功德（第 218–238 句）

```
དེ་ནས་རྣལ་འབྱོར་པ་ཏེ་ལོ་པས།
དཔལ་ན་རོ་པ་ལ་སློབ་མའི་ཆོས་བཅུ་གཉིས་པ་ཞེས་བྱ་བའི་བརྡར་གསུངས་པ་ནི།
```

然后，瑜伽士帝洛巴以表征向吉祥那洛巴宣说名为"弟子的十二法"的［教授］：

```
གཅན་གཟན་མཆེ་བ་དག་གིས་མ་རུངས་རྨ་མེད་པ། །
སྡུག་བསྔལ་བཙོན་ར་འདི་ན་ཡུན་རིང་ནད་ཀྱིས་ཐེབས། །
ཁང་བཟང་དམ་པ་ནད་མེད་བདེ་བ་ཡོན་ཏན་ལྡན། །
ཀླུ་ཡི་རྒྱལ་པོ་འགྲོ་ལ་ཆར་རྒྱུན་རྟག་ཏུ་འབེབས། །
དུག་སྡོང་ལོ་འདབ་རྒྱས་པའི་ལོ་འདབ་འབྲས་བུ་ཆགས་པ་མེད། །
སྤུ་གྲིའི་སོར་ཆགས་སྦྲང་རྩིའི་རོ་རྣམས་རྟག་ཏུ་སྤོང་བར་བྱེད། །
བདེ་བའི་ཆོས་ཀུན་གསོད་པར་ལྡན་པའི་སྐྱེས་བུ་སེམས་སྟོབས་ལྡན། །
རྨ་ཡོད་བག་ཡོད་གནས་མི་བྱེད། །
མི་བཟད་ནད་ཀྱིས་གཟིར་བ་སྨན་པ་དག་ལ་རབ་ཏུ་གུས། །
སྐོམ་པས་རབ་གདུངས་ངེས་པར་བཏུང་བ་འབའ་ཞིག་སྒྲུབ་པར་བྱེད། །
རླན་བྲལ་རུས་སྦལ་རྒྱ་མཚོ་ཆེན་པོ་མཐོང་ན་རབ་ཏུ་དགའ། །
མགོ་ལ་མེ་ལྕེས་ཟིན་པ་མྱུར་དུ་སེལ་བར་བྱེད། །
རིན་ཆེན་སྣོད་མཆོག་དེ་དག་ཏུ། །
རོ་མཆོག་བཅུད་ཀྱིས་ངེས་པར་འགེངས། །
མུན་པ་དག་ལ་སྒྲོན་མེ་བཞིན། །
སྐལ་ལྡན་བྱ་བ་གསལ་བར་བྱེད། །
```

［他］未被猛兽的毒牙所伤；在这痛苦的牢狱中，长久被疾病所缠；［向往］无病、安乐、具足功德的殊胜宫殿；龙王恒常对众生降下雨水；有毒的树枝叶繁茂，却不贪著它的果实；恒常舍弃剃刀刃上的蜂蜜之味；心力坚强的人，［愿意］斩断一切安乐之法；有伤的人谨慎，不住［于危险之处］；被难忍的疾病所逼迫，对医生非常恭敬；被口渴所逼，一心只求饮水；干涸的龟见到大海，非常欢喜；头被火焰燃着，就迅速扑灭；在那些殊胜的珍宝器皿中，一定以最上的美味精华充满；就像黑暗中的灯，使有缘者的事业明显。

```
སློབ་མ་ཆོས་དེ་རྣམས་དང་ལྡན་པ་བསྟེན། །
དེ་ལས་བཟློག་པ་སྤང་བར་བྱའོ། །
སློབ་མ་བསྟེན་པའི་གདུང་བ་གཅད་པའི་གདམས་པ་སྟེ་བཅུ་པའོ།། །།
```

要依止具足那些法的弟子，舍弃与此相反的［弟子］。这是断除［对］依止弟子之焦灼的教授，第十。

【按】这一段是帝洛巴向那洛巴说明"具格弟子"的十二种功德，可大致看出的是：
- "在这痛苦的牢狱中，长久被疾病所缠"：弟子深刻认识到轮回之苦；
- "有毒的树枝叶繁茂，却不贪著它的果实""舍弃剃刀刃上的蜂蜜之味"：弟子了知世间欲乐的过患而不贪著（剃刀上的蜜，舔之则伤舌，是佛经中常见的比喻）；
- "被难忍的疾病所逼迫，对医生非常恭敬"：弟子视上师如医生，恭敬依止；
- "被口渴所逼，一心只求饮水""头被火焰燃着，就迅速扑灭"：弟子求法心切，如渴求水、如救头燃；
- "干涸的龟见到大海，非常欢喜"：弟子得遇正法时极为欢喜；
- "殊胜的珍宝器皿"：弟子是堪受法的法器，能以口诀的美味充满。

"未被猛兽的毒牙所伤""龙王恒常对众生降下雨水""心力坚强的人，愿意斩断一切安乐之法""有伤的人谨慎，不住［于危险之处］"等，意思不很清楚，存疑。按题目说是"十二法"，原文的条目也难以确定地分出十二条，存疑。

第九、第十两段口诀，与此前各段由空行母宣说不同，是帝洛巴向那洛巴所说，内容是上师与弟子的条件，与马鸣《事师五十颂》等关于师徒相互观察的教导意思相通。

## 十二、第十一口诀：认识迷乱之识（第 239–263 句）

```
དེ་ནས་མཁའ་འགྲོ་མ་ཀཾ་ཀ་རོ་མ་ཧས།
བླ་མ་ཟངས་གླིང་པ་ན་ཀཔྤུ་ར་ལ་འཁྲུལ་པའི་ཤེས་པ་གཅད་པའི་བརྡ་བརྒྱད་གསུངས་པ་ནི།
```

然后，空行母甘嘎罗摩诃，向上师赞岭巴·迦布惹宣说断除迷乱之识的八种表征：

```
བྱིས་པ་ཆུང་ངུར་གྱུར་པ་རྣམས་ཀྱིས་ནི། །
མེ་ལོང་བཞིན་ལ་ཐ་དད་དག་ཏུ་རྟོགས། །
ཤིན་དུ་བློ་གྲོས་དམན་པའི་རི་མོ་མཁན། །
རང་གིས་བྲིས་པའི་རི་མོ་དག་ལ་སྐྲག །
མཁྲིས་པའི་ནད་ཀྱིས་བཏབ་པའི་མིག་ཅན་དག །
མཐོང་བའི་ཡུལ་རྣམས་དག་ལ་ཆགས་སྡང་སྐྱེ། །
ཇི་ལྟར་དར་གྱི་སྲིན་བུ་དག་གིས་ནི། །
རང་གི་ཁ་ཆུའི་རྣམ་པས་འཆིང་བར་བྱེད། །
མི་མཁས་དམན་པའི་གང་ཟག་ལ་དེ་ནི། །
སྒྱུ་མའི་འཕྲུལ་གྱི་རྣམ་པས་བསླུས་པ་ཡིན། །
རྒྱ་དང་རྙི་ལ་སོགས་པས་རི་དྭགས་ནི། །
རང་དབང་མེད་པར་རབ་ཏུ་བསྡམས་པར་འགྱུར། །
མི་མཐུན་དགྲ་ཡིས་ཟིན་པར་གྱུར་པའི་བཙོན། །
ལྕགས་སྒྲོག་དམ་པ་དག་གིས་བཅིངས་གྱུར་ལ། །
རྨི་ལམ་ན་ནི་ཁྲི་མོན་དོང་བཅུག་པ། །
དེ་ཚེ་སྡུག་བསྔལ་མི་བཟོད་སྐྱེ་བ་ཡིན། །
```

成了小孩子的人们，把镜中的面容认作［与自己］不同的；智慧极为低劣的画师，对自己所画的图画感到害怕；眼睛被胆病所染的人们，对所见的境界生起贪与嗔；就像蚕以自己口水的形相，把自己缠缚起来。

对于不善巧的下劣之人，那是被幻术的变化之相所欺骗；野兽被网与套索等，不由自主地完全困住；被敌对之敌所捉住的囚犯，被坚固的铁链所捆缚；在梦中落入深坑，那时就生起难忍的痛苦。

```
བླ་མ་བསྟེན་ཅིང་ངེས་ཤེས་བསྐྱེད། །
གཉུག་མ་གོམས་པར་བསྟེན་པར་བྱ། །
འཁྲུལ་པ་ཡི་ནི་ཤེས་པ་ཉིད། །
རིག་པ་ཉིད་དེ་ཡེ་ཤེས་ཉིད། །
འཁྲུལ་པའི་ཤེས་པ་སྤངས་བྱས་ལ། །
གཉུག་མའི་ཡེ་ཤེས་གོམས་པར་བྱའོ། །
```

要依止上师，生起定解，要依止对本然的串习。迷乱之识本身，就是觉性，就是智慧。舍弃了迷乱之识，要串习本然的智慧。

```
འཁྲུལ་པའི་ཤེས་པ་ངོ་ཤེས་པར་བྱ་བའི་གདུང་བ་གཅད་པའི་གདམས་པ་སྟེ་བཅུ་གཅིག་པའོ།། །།
```

这是令人认识迷乱之识的、断除焦灼的教授，第十一。

【按】这一段以八个比喻说明"迷乱之识"：小孩把镜中的自己当作别人、画师被自己画的图吓到、患黄疸病的人把白看成黄、蚕作茧自缚、被幻术所骗、野兽落网、囚犯被锁、梦中堕坑——都是说明轮回的痛苦都是自己的心所造、自己被自己的显现所缚。这些比喻在大手印、大圆满的教言中都很常见。

后面的六句是本段的正说，非常重要："迷乱之识本身，就是觉性，就是智慧"——这是大手印"念头即法身""迷乱即智慧"的要点。但紧接着又说"舍弃了迷乱之识，要串习本然的智慧"，意思是：认识到迷乱之识的本性就是智慧，就是"舍弃"了迷乱之识；不是另外去消灭什么，而是认识它的本来面目，然后安住串习。这与《真如十颂》第三颂"迷乱也是无所住的"、《真如十颂广释》"不是像拔刺那样拔除迷乱，而是遍知它的自性不生"的意思一致。

"在梦中落入深坑"，藏文作"ཁྲི་མོན་དོང་བཅུག་པ"，"khri mon"意思不明，这里依上下文译出，存疑。

## 十三、第十二口诀：真性的二十种瑜伽（第 264–289 句）

```
ལྷོ་ཕྱོགས་ཀྱི་གྲོང་ཁྱེར་དུ་མཁའ་འགྲོ་མ་བི་ལ་དེ་ཝིས།
རྣལ་འབྱོར་པའི་སྨྱོན་པའི་བརྟུལ་ཞུགས་ལ་རི་ཏ་པ་ལ་ལ།
དེ་ཁོ་ན་ཉིད་ཀྱི་རྣལ་འབྱོར་ཉི་ཤུ་བརྡར་གསུངས་པ་ནི།
```

在南方的城市中，空行母毗拉德维，以表征向行持瑜伽士疯行禁行的日达巴拉，宣说真性的二十种瑜伽：

```
ཞིང་པ་རྣམས་ནི་རིམ་གྱིས་ལས་ལ་འཇུག །
ཤིང་རྟ་དག་ནི་འཁོར་ལོ་གཉིས་དང་ལྡན། །
དཔེ་མེད་ནམ་མཁའ་ཉིད་དུ་གནས། །
རིག་པའི་མདངས་ནི་ཐམས་ཅད་འབིགས་པར་བྱེད། །
ཆུ་ཡི་ནང་དུ་ཨུཏྤལ་ཤིན་ཏུ་མཛེས། །

- "美人恒常照镜子"：恒常观照自心；

## 十四、第十三口诀：三摩地的助伴、力量与支分（第 290–314 句）

མུན་པའི་ཚོགས་རྣམས་ངེས་པར་སེལ་བྱེད་ན། །
ཚ་སྒོ་མེད་པའི་ཞིང་པ་དག་གིས་ནི། །
འབྲས་བུའི་ནུས་པ་ཡོངས་སུ་སྐྱེད་པར་བྱེད། །

རྟེན་ཐབས་མཁས་པ་རྣམས་ཀྱི་ཆུ་ལུད་ཀྱིས། །

```

```

［瑜伽母］这样说了。这些是以表征宣说的三摩地的助伴、力量与支分，第十三。

【按】"使有漏的安乐堪能［转为道用］"（zag bcas kyi bde ba las su rung bar bya ba），是指把世间有漏的安乐（如业手印所生的安乐）转为修道之用的方便，属于无上瑜伽续圆满次第的内容，须依具德上师的灌顶与口授来理解，这里不作解说。

- "缘起的种种作为，能成就一切圆满"：修道的成就依于种种因缘的和合；
- "只要鸟的羽毛还没有长全，就要依靠柔软的巢"：修行人在功力未成熟之前，要依靠上师、助伴与适当的环境，不可过早独行，这是很重要的告诫；

- "水车与渠道的工匠能如所欲地延长诸水"：以善巧的方便引导风息或安乐，存疑。

"昆达［花］"（kunda），是一种白色的花，在密续中常象征菩提心，见《灌顶教示难释》第四十七节按语。"没有过失的农夫"，藏文作"ཚ་སྒོ་མེད་པ"，意思不很清楚，存疑。"支多"（ci to），音译，存疑。

བརྐུས་པར་གྱུར་ཀྱང་སྡུག་བསྔལ་རྟག་ཏུ་སྐྱེས། །
གཙུབ་ཤིང་ཡན་ལག་རྫོགས་པར་མ་གྱུར་པ། །
མེ་ནི་འབྱུང་བར་རུང་བ་ནམ་ཡང་མེད། །
བག་ཡོད་བློ་ལྡན་མཁས་པ་གང་ཞིག་གིས། །
ཞབས་མེད་སྣོད་དུ་བཅུད་རྣམས་བླུགས་མི་བྱེད། །
འབྲུ་མར་འབར་བར་མི་འདོད་སྐྱེས་བུ་ནི། །
རྟག་ཏུ་རླུང་རྣམས་གཡོ་བར་བྱེད་ཅིང་གནས། །
དུག་ཅན་སྦྲུལ་ནི་མཁས་པ་དག་རྣམས་ཀྱིས། །
མཐོང་བར་མི་འདོད་ཐག་རིང་ཡོངས་སུ་སྤོང་། །
```

对于像奴仆一样不能自主的人们来说，［口诀］不会像主人一样有安乐的时候；在没有擦去锈垢的镜面上，面容的影像不会清楚地显现；离开了弦的弓与射手，即使有技能，也不能射；在没有洗过、极为肮脏的器皿中，不会盛满上好的美味佳肴。

有分寸的善巧农夫们，会完全避免在不适当的时节播种；盗贼把心思托付给别人，所以即使偷到了，也恒常生起痛苦；钻木的部件不完整，就永远不能生出火来。

谨慎、有智、善巧的人，不会把精华倒进没有底的器皿；不希望芝麻油灯燃烧的人，才会恒常使风吹动；智者们不想看见毒蛇，远远地避开。

```
ཞེས་གསུངས་པ་སྟེ།
དེ་དག་ནི་སློབ་དཔོན་ཌོམྦི་ཧེ་རུ་ཀས་རྡོ་རྗེ་སློབ་དཔོན་དུ་གྱུར་པ་རྣམས་ལ་བདུད་རྩི་ལྟ་བུའི་མན་ངག་སྣོད་མ་བརྟགས་པ་རྣམས་ལ་མི་བསྟན་པ་སྟེ་བཅུ་བཞི་པའོ།། །།
```

［东比嘿噜嘎］这样说了。这些是阿阇黎东比嘿噜嘎［告诫］已成为金刚阿阇黎的人们，不要向未经观察的法器开示甘露般的口诀，第十四。

【按】这一段是对传法上师的告诫：口诀如甘露，必须先观察弟子是否堪为法器，不可轻率传授。所用的比喻都很清楚：
- "没有擦去锈垢的镜面"：弟子的相续未经净化，口诀无法显现；
- "离开了弦的弓"：弟子缺乏必要的条件；
- "肮脏的器皿不会盛满佳肴"：不清净的法器盛不了口诀；
- "不在不适当的时节播种"：传法要待时机；
- "钻木的部件不完整就不能生火"：弟子的因缘不具足，就不能生起证悟；
- "不把精华倒进没有底的器皿"：对不能持守的人传法，口诀会流失；
- "远远避开毒蛇"：避开会损害正法的人。

"盗贼把心思托付给别人，所以即使偷到了，也恒常生起痛苦"，意思不很清楚，可能是说口诀被不堪的人得到，反而成为痛苦之因，存疑。"不希望芝麻油灯燃烧的人，才会恒常使风吹动"，意思是：向不堪的人传法，就像在灯旁扇风，会使口诀之灯熄灭，存疑。

"哈哈宣响"（ha har sgrogs pa，梵 Aṭṭahāsa），是密续中所说的八大尸陀林之一。这一段与第十段"弟子的十二法"首尾呼应：上师要观察弟子，弟子也要具足条件。

## 十六、第十五口诀：认识智慧宝珠（第 341–371 句）

```
རྗེ་བཙུན་ནཱ་རོ་པས་བླ་མ་གངས་གསེང་པ་ལ།
ནོར་བུ་རིན་པོ་ཆེ་ངོས་གཟུང་བའི་གདམས་ངག་བསྟན་པ་ནི།
```

尊者那洛巴向上师岗森巴开示认识如意宝珠的口诀：

```
ནང་གི་མུན་པའི་རྒྱ་མཚོ་ཆེན་པོ་རུ། །
རིན་ཐང་མེད་པའི་ནོར་བུ་རབ་སྟོར་བས། །
ཟེ་མ་ལྔ་དང་རབ་ཏུ་ལྡན་པ་ཡིས། །
མཆེ་བ་གཉིས་གཙིགས་ཕག་པ་ཟོས་པར་འགྱུར། །
ལྕགས་སྣ་གསུམ་ལས་བརྡུངས་པའི་རལ་གྲི་ཡིས། །
ཕག་པའི་ཤ་དང་རུས་པ་སོ་སོར་དབྱེ། །
དེ་ནས་ནོར་བུ་རིན་ཆེན་བཙལ་བར་བྱ། །
རྙེད་པར་གྱུར་ན་ཆུ་ཡིས་བཀྲུ། །
དེ་ནས་རྒྱལ་མཚན་རྩེ་ལ་ཕྱར་བར་བྱ། །
འདོད་པའི་དོན་ལ་གསོལ་བ་གདབ་པས་འབྱུང་། །
```

在内在黑暗的大海中，遗失了无价的宝珠。以具足五冠者，露出两颗獠牙，那猪就会被吃掉；以三种铁所锻造的剑，把猪的肉与骨分开。然后寻找珍贵的宝珠；若找到了，就用水洗净；然后挂在胜幢的顶端；向它祈求所愿之事，就会出现。

```
དྲི་མ་མེད་པའི་ནོར་བུ་རིན་ཆེན་དེ། །
ངེས་པར་ནམ་མཁའི་དཀྱིལ་དུ་སྦ་བར་བྱ། །
ནོར་བུ་ལྷུན་པོ་རི་ཡི་རྩེ་ལ་གཞག །
ནོར་བུ་མེ་དང་ཆུ་ཡིས་རབ་ཏུ་བཏུལ། །
ནོར་བུ་བྱ་ཡི་འདབ་མ་གདགས་པར་བྱ། །
ནོར་བུ་ཆུ་བོ་ཆེན་པོའི་གཞུང་ལ་བསྐུར། །
ནོར་བུ་མར་མེའི་ངོས་ལ་བསྟན་པར་བྱ། །
ནོར་བུ་སྨྱོན་པའི་ལག་ཏུ་གཏད་ལ་གཞག །
ནོར་བུ་མེ་ལོང་ངོས་ལ་བསྟན་ལ་གཞག །
ནོར་བུ་རས་བལ་ཕུང་པོའི་སྟེང་དུ་གཞག །
ནོར་བུ་རིན་ཆེན་དྲི་ཟའི་གྲོང་དུ་བཅོལ། །
ནོར་བུ་རིན་ཆེན་རྒྱལ་པོའི་གཏེར་དུ་སྦ་བར་བྱ། །
ནོར་བུ་རིན་ཆེན་མེ་དཔུང་དཀྱིལ་དུ་སྦ། །
ནོར་བུ་རིན་ཆེན་རྐུན་པོའི་ནོར་ཉིད་ཡིན། །
ནོར་བུ་རིན་ཆེན་ཤེལ་གྱི་སྟེང་དུ་གཞག །
ནོར་བུ་ནོར་ཅན་བསྟན་པའི་ནོར། །
ནོར་བུའི་ནོར་ནི་བཙལ་ཞེས་གསུངས་པ་སྟེ། །
```

那无垢的珍贵宝珠，一定要藏在虚空的中央；把宝珠放在须弥山顶；以火与水把宝珠完全调炼；把宝珠系在鸟的羽毛上；把宝珠送入大河的水流中；把宝珠显示在灯的面上；把宝珠交托在疯人的手中；把宝珠显示在镜面上；把宝珠放在棉花堆上；把珍贵的宝珠寄托在乾闼婆城中；把珍贵的宝珠藏在国王的宝藏中；把珍贵的宝珠藏在火堆的中央；珍贵的宝珠，就是盗贼的财物；把珍贵的宝珠放在水晶上；宝珠是有财者所显示的财宝；要寻找宝珠的财富。［那洛巴］这样说了。

```
དེ་དག་ནི་ཡེ་ཤེས་ཀྱི་ནོར་བུ་ངོས་གཟུང་བའི་ཐབས་བརྡར་གསུངས་པའོ། །
རང་གི་གཉུག་མའི་དེ་ཁོ་ན་ཉིད་ཀྱི་ཡེ་ཤེས་ངོས་གཟུང་བའི་གདུང་བ་གཅད་པའི་གདམས་པ་སྟེ་བཅོ་ལྔ་པའོ།། །།
```

这些是以表征宣说的认识智慧宝珠的方法。这是令人认识自己本然的真性智慧的、断除焦灼的教授，第十五。

【按】这是全篇最后一段口诀，以"如意宝珠"比喻本然的真性智慧。前半说寻找宝珠：
- "在内在黑暗的大海中遗失了无价的宝珠"：心性被无明所遮蔽；
- "猪""猪的肉与骨"：猪在藏传佛教中常象征愚痴，以智慧之剑把愚痴剖开，才能找到宝珠，存疑；
- "用水洗净""挂在胜幢的顶端""向它祈求所愿"：认识了心性之后，要净化、珍重它，它就能成就一切所愿。

"具足五冠者，露出两颗獠牙"（ze ma lnga dang rab tu ldan pa ... mche ba gnyis gtsigs），可能是指具五骷髅冠、露出獠牙的忿怒本尊，存疑。"以三种铁所锻造的剑"，存疑。

后半一连串"把宝珠藏在虚空中、放在须弥山顶、系在鸟羽上、送入河流、显示在灯面镜面上、交给疯人、放在棉花堆上、寄托在乾闼婆城、藏在火堆中……"，都是说明认识心性之后在种种境界中护持、运用它的方法，大致可以理解为：心性如虚空般无处可藏、如须弥山般稳固、如鸟羽般轻灵、如河流般相续、如灯与镜般明照、如疯人般无执、如棉花般柔软、如乾闼婆城般如幻、如王藏般珍贵、如火中之宝不被焚毁、如水晶般透明。但每一句的确切含义，都要依上师的口授来领会，存疑。

"宝珠就是盗贼的财物"，可能是说心性本来就是自己的，却像被盗贼偷去一样不认识，存疑。"上师岗森巴"（bla ma gangs gseng pa），可能是那洛巴的某位藏族或印度弟子，存疑。

## 十七、结颂与回向（第 372–379 句）

```
སློབ་མ་སྐལ་ལྡན་ཚོགས་བསགས་རིན་ཆེན་ལྟ་བུའི་གང་ཟག་འདི། །
དཔག་ཏུ་མེད་པའི་གདམས་ངག་རྣམས་ཀྱིས་རྒྱུད་དག་ཡོངས་སུ་སྦྱངས་གྱུར་ཀྱང་། །
གདུང་བ་ཆད་པར་མ་གྱུར་བླ་མ་རྣམས་ཀྱིས་ཡོངས་སུ་གདུངས་གྱུར་པ། །
གདམས་ངག་རྣམས་དང་བླ་མའི་གདུང་བ་གཅད་ཕྱིར་བརྒྱུད་པའི་མན་ངག་བཀོད། །
རྗེ་བཙུན་མཆོག་དང་རྡོ་རྗེ་མཁའ་འགྲོའི་ཚོགས་རྣམས་བཟོད་མཛོད་ལ། །
དེ་ལས་བྱུང་བའི་དགེ་བ་ཟླ་བ་ལྟ་བུའི་དྲི་མ་མེད་པ་དེས། །
འགྲོ་བ་མ་ལུས་ཡིད་ཀྱི་གདུང་བ་ཡོངས་སུ་གཅད་པར་གྱུར་ནས་ཀྱང་། །
ཕྱག་རྒྱ་ཆེན་པོའི་དྲི་མེད་ས་ལ་མ་ལུས་ཡོངས་སུ་རྫོགས་གྱུར་ཅིག །
```

这如珍宝般的人——有福分、积集了资粮的弟子，虽然以无量的口诀完全净治了相续，焦灼却还没有断除，被诸上师所［牵动而］焦灼；为了断除［对］口诀与上师的焦灼，我编排了传承的口诀。

祈请殊胜的尊者与金刚空行母众宽恕！以由此所生的、如月亮般无垢的善根，愿一切众生心中的焦灼都完全断除，并在大手印的无垢地上，全部完全圆满！

【按】"被诸上师所［牵动而］焦灼"（bla ma rnams kyis yongs su gdungs gyur pa），意思是对上师的渴慕之情，即"求道的焦灼"，与开头第 13–17 句相应。"在大手印的无垢地上全部完全圆满"，说明本篇的归宿是大手印。

## 跋（第 380–381 句）

མཁའ་འགྲོ་མའི་གདམས་ངག་སྙན་ནས་སྙན་དུ་བརྒྱུད་པའི་གདུང་བ་གཅད་པའི་གདམས་པ་ཞེས་བྱའོ། །

名为《空行母口诀·耳传·断苦之教授》。

由化身瑜伽士编排成文，圆满。

【按】"化身瑜伽士"（sprul pa'i rnal 'byor pa），没有具体的名字，可能是编者的谦称，也可能是指某位被视为化身的瑜伽士，存疑。本篇没有译者跋语。从内容看，本篇汇集了东比嘿噜嘎、帝洛巴、那洛巴、夏瓦日巴等多位成就者传承的空行母表征口诀，编成的时代应在那洛巴之后，即十一世纪前后。
