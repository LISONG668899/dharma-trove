# 嘎内日巴之歌

阿阇黎嘎内日巴造　据藏文译出

## 题解

本篇收于德格版丹珠尔续部释 ཟི 函第 7b 页（东北目录 D2361）。开头没有梵藏题名与礼敬，跋语作"甘达日之歌，圆满"（གཎྜ་རིའི་གླུ），没有记载译者。作者一般还原为 Kāṇeripā（嘎内日巴），即以甘达日为名的成就者；本站依此题为《嘎内日巴之歌》。他的生平不详，篇中叠句提到"嘎纳巴"（黑行者），可能与黑行者一系有关。

全篇约十五句，共四段，以"在虚空中挤牛奶"为主喻，叠句是"嘎纳巴在虚空中相续不断地挤奶，向持守瑜伽律仪的会众献上供养"。四段依次说：挤奶人是上师，饮乳的小牛是自心；请玛玛基取来奶桶，奶桶就是无垢的俱生；挤满了桶，五象难持；挤奶人在此不可见。

关于密乘内容的告诫：篇中的"玛玛基""持守瑜伽律仪的会众"等，属于密乘的象征语言与会供，须依灌顶与上师口授理解，不可照字面揣测。

体例：藏文原文全部保留在代码框中，按段落分节，每节后附汉译；叠句照原文每次重复。凡标"存疑"的按语，表示本译对原文意思没有把握。藏文依 Esukhia 德格丹珠尔电子版。

## 一、上师挤奶，自心饮乳

```
མཁའ་ལ་བ་འཇོ་འཇོ་བྱེད་བླ་མ་སྟེ། །
འཐུང་བའི་བེའུ་ནི་རང་གི་སེམས་ཉིད་ཡིན། །
མཁའ་ལ་རྒྱུན་མི་འཆད་འཇོ་ཀ་ན་པ། །
རྣལ་འབྱོར་སྡོམ་པའི་ཚོགས་ལ་མཆོད་པ་འབུལ། །
```

在虚空中挤牛奶的挤奶人，是上师；那吮吸乳汁的小牛，就是自己的心。嘎纳巴在虚空中相续不断地挤奶，向持守瑜伽律仪的会众献上供养。

【按】全篇以"在虚空中挤牛奶"为主喻，与已译的《萨惹哈之歌（挤虚空之乳）》（D2355）意象相同。这里把挤奶人比作上师，小牛比作自心：上师从空性中挤出法乳，自心如小牛般吮饮。"嘎纳巴在虚空中相续不断地挤奶，向持守瑜伽律仪的会众献上供养"，是全篇的叠句。

【按】"嘎纳巴"（ཀ་ན་པ），即黑行者，这里大概是作者以黑行者为挤奶人，或作者自称承黑行者之传，所指不完全确定。

## 二、请玛玛基取来奶桶

```
བ་འཇོ་སྣོད་གསོལ་ག་རེ་མཱ་མ་ཀཱི། །
བ་འཇོ་སྣོད་ནི་དྲི་མེད་ལྷན་ཅིག་སྐྱེས། །
མཁའ་ལ་རྒྱུན་མི་འཆད་འཇོ་ཀ་ན་པ། །
རྣལ་འབྱོར་སྡོམ་པའི་ཚོགས་ལ་མཆོད་པ་འབུལ། །
```

玛玛基啊，请把挤奶的桶拿来！挤奶的桶，就是无垢的俱生。嘎纳巴在虚空中相续不断地挤奶，向持守瑜伽律仪的会众献上供养。

【按】"玛玛基"（མཱ་མ་ཀཱི），是密乘四佛母之一，常象征智慧母或明妃。"挤奶的桶是无垢的俱生"，意思是盛受法乳的器皿就是俱生智。这是象征语言，须依上师口授理解。

【按】存疑。"ག་རེ"，本译读作呼唤语，所指不完全确定。

## 三、挤满了桶，五象难持

```
མཁའ་ལ་བཞོས་ཤིང་བཞོས་ཤིང་སྣོད་བཀང་བཞག། །
བཟུང་བར་མི་ནུས་འདི་ལྟར་གླང་པོ་ལྔ། །
མཁའ་ལ་རྒྱུན་མི་འཆད་འཇོ་ཀ་ན་པ། །
རྣལ་འབྱོར་སྡོམ་པའི་ཚོགས་ལ་མཆོད་པ་འབུལ། །
```

在虚空中挤了又挤，把桶装满放着；这样的五头大象，却是无法捉住的。嘎纳巴在虚空中相续不断地挤奶，向持守瑜伽律仪的会众献上供养。

【按】存疑。"这样的五头大象，无法捉住"，所指不明：可能比喻五根或五毒，如狂象般难以驯服；也可能是说法乳满溢，连五头大象也无法承载。今照字面译出。

## 四、挤奶人在此不可见

```
མཁའ་ལ་བ་འཇོ་འཇོ་བྱེད་འདིར་མ་མཐོང། །
ཇི་ལྟར་ནང་དུ་ཆུས་གང་ཀ་ལི་པ། །
མཁའ་ལ་རྒྱུན་མི་འཆད་འཇོ་ཀ་ན་པ། །
རྣལ་འབྱོར་སྡོམ་པའི་ཚོགས་ལ་མཆོད་པ་འབུལ། །
```

在虚空中挤牛奶的人，在这里是看不见的；就像嘎里巴，内里被水充满一样。嘎纳巴在虚空中相续不断地挤奶，向持守瑜伽律仪的会众献上供养。

【按】存疑。"嘎里巴"（ཀ་ལི་པ），所指不明，可能是一种容器、一个人名，或某种隐语；"内里被水充满"的比喻也不清楚。全句的大意可能是：挤奶的上师与所挤的虚空，都不是可见的对象。
