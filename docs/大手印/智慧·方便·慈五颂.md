# 智慧·方便·慈五颂

梅纪巴（阿阇黎阿瓦都帝巴·无二金刚）造　据藏文译出

## 题解

本篇（藏 thabs dang shes rab rtse ba lnga pa，直译"方便与智慧之嬉戏五颂"；藏本所录梵题作 Prajñopāya...pañca）收于德格版丹珠尔续部释 ཝི 函第 136b 至 137a 页（东北目录 D2246），紧接在《五部自性》（D2245）之后，同属梅纪巴的"无念法类"。译者是印度堪布金刚手与藏地译师粗敦·智慧源，跋语说是"译出并校订而定稿"。

需要特别说明的是：本篇与前面所译的《慈五颂》（D2237a），是同一部作品的两个不同藏译本。两本都是五颂二十句，结构、比喻与句序完全一致：显现与空性如同一对夫妻，因执著而失和，于是一同来到上师面前，上师使二者重归和合；最后两颂赞叹上师的善巧与双运的境界。两本的差别在于译者与用词：

《慈五颂》由金刚手与玛班·法炬译出，题名用"欢喜和睦"（dga' gcugs），把两方称为"最亲爱的伴侣"与"爱人"；

本篇由金刚手与粗敦·智慧源译出，题名用"嬉戏"（rtse ba），把两方称为"嬉戏的伴侣"，并明说这是"方便与智慧"的嬉戏。

两个译本可以互相印证：《慈五颂》中几处难解的句子，在本篇中意思更为清楚，下面在各颂的按语中逐一对照。读者可以把两篇并读。

这样的夫妻、嬉戏之喻，是大手印道歌中常见的象征语言，所说的都是显现与空性、方便与智慧的双运，不是在讲世俗的男女之事。

体例：每颂先列藏文原颂于代码块中，再按完整的意义单元译出；为了便于理解而补的字，都放在方括号中。原文含混或可有两解之处，以"【按】"说明，不妄补内容。文末附通篇连读。

## 题名与礼敬

梵语题名：Prajñopāya...pañca。藏语题名：《方便与智慧嬉戏五颂》。

敬礼吉祥金刚萨埵！

【按】藏本梵题作 pra jño pā ya be ya pañca，其中 prajñopāya 是"智慧方便"，pañca 是"五"，中间的 be ya 难以还原，可能是讹文，这里不强作还原，存疑。题名中的"嬉戏"（rtse ba），梵文可能对应 krīḍā（游戏、嬉戏）一类的词，在密续中常指方便与智慧的和合之戏。本篇题名依来稿作《智慧·方便·慈五颂》，"慈"取恩爱之义，与《慈五颂》的题名一致。

## 第一颂　显现：最胜的嬉戏伴侣

```
རབ་ཏུ་སྣང་བའི་མཆོག་རྩེ་བ། །
རྟེན་ཅིང་འབྲེལ་པར་འབྱུང་བ་ཙམ། །
གལ་ཏེ་མེད་གྱུར་འཆིང་འགྱུར་ཉིད། །
སྟོང་ཉིད་ཡོད་པའི་འདོད་ཙམ་མ། །
```

那最胜的嬉戏伴侣——明现［的显现］，只是缘起而已。如果［把她］当作不存在，那本身就成了束缚，［因为那样的话，］空性也就只是被执为"有"的［东西］罢了。

【按】这一颂对应《慈五颂》第一颂，前两句意思相同，后两句两本差异较大：

《慈五颂》作"如果当作不存在，便是空性；把它当作实在的女子而贪求，便成束缚"，是把"否定显现"与"执显现为实有"作为两种过失对举。

本篇作"如果当作不存在，那就成了束缚；空性也只是被执为有的"，意思似乎是：否定显现、只取空性，这本身就是束缚，因为这样的"空性"已经被当成一种实有的东西了。

末句"stong nyid yod pa'i 'dod tsam ma"最难确定：'dod tsam 可以是"仅仅被承许、被执为"，句末的 ma 可以是否定词，也可以是阴性的词尾（"……之女"）。若读为否定，意思是"空性并不只是被执为有的"；若读为阴性词尾，可能是把显现称为"［执］空性为有之女"。这里依上下文取第一种理解，存疑。

## 第二颂　空性：身无可比的嬉戏者

```
སྟོང་ཉིད་ཤིན་ཏུ་མཆོག་རྩེ་བའི། །
གང་གི་ལུས་ནི་དཔེ་མེད་པ། །
གལ་ཏེ་བརྒྱ་ལ་ཐ་དད་གྱུར། །
རྩེ་བའི་གཙོ་བོ་ཐ་དད་འགྱུར། །
```

空性，是那最为殊胜的嬉戏者，他的身体无可比拟；如果万一［二者］分离了，那嬉戏之主也就分离了。

【按】这一颂对应《慈五颂》第二颂。《慈五颂》第三句作"de dang brgya la byed na"（万一与他作［某事］），句意不明，当时依上下文推测为"万一把显现与空性分开"；本篇此句明确作"gal te brgya la tha dad gyur"（如果万一分离了），正好证实了那一推测。第四句《慈五颂》作"喜乐之主就会失去"，本篇作"嬉戏之主也就分离了"，意思相近。

"嬉戏之主"（rtse ba'i gtso bo），指双运的主体，即方便与智慧和合的大乐；也可以理解为作为"夫君"的空性本身。"身体无可比拟"，与《慈五颂》的"具有色相"相应，都是说这空性不是一片空白。

## 第三颂　上师使之和合

```
དེ་ཕྱིར་དོགས་པ་ཁྱོ་ཤུག་གཉིས། །
བླ་མ་དམ་པའི་སྤྱན་སྔར་གནས། །
གཉུག་མའི་རྩེ་བ་དེ་དང་དེའི། །
ལྷན་ཅིག་སྐྱེས་པའི་རྩེ་བར་མཛོད། །
```

因此，那心怀忧虑的夫妻二人，［一同］来到殊胜上师的面前；［上师］使他们各自本然的嬉戏，成为俱生的嬉戏。

【按】这一颂对应《慈五颂》第三颂。前两句相同。后两句《慈五颂》作"使他们像从前一样，欢喜地和合在一起"，强调"恢复本来"；本篇作"使他们各自本然的嬉戏，成为俱生的嬉戏"，用了"本然"（gnyug ma）与"俱生"（lhan cig skyes pa）两个大手印的核心用语，意思更为明确：显现与空性各自本来就是本然的，上师所做的，是让人认出二者本来同时俱生、不可分离。两本说法不同，意思一致。

## 第四颂　赞叹上师

```
ཨེ་མའོ་བླ་མ་དམ་པ་མཁས། །
ངོ་མཚར་འདི་འདྲའི་ཐབས་མཁས་པ། །
གཉུག་མ་དབྱེར་མེད་དམིགས་པ་མེད། །
བླ་ན་མེད་པ་གཉི་ག་སྟེ། །
```

奇哉！殊胜的上师真是善巧，在这样稀有的方便上如此善巧！［如今二者是］本然、无别、无所缘的，二者都是无上的。

【按】这一颂对应《慈五颂》第四颂。《慈五颂》第三句作"本性无二"，本篇作"本然、无别"；第四句《慈五颂》作"二者都在无上之中生起"，本篇作"二者都是无上的"，意思更为简明，可以印证《慈五颂》该句的理解。

## 第五颂　双运的境界

```
མཚན་ཉིད་ཐམས་ཅད་ཡང་དག་རྫོགས། །
མཐའ་གཉིས་དག་ནི་རྣམ་པར་སྤངས། །
དངོས་པོ་ཀུན་གྱི་རང་བཞིན་ནི། །
རང་བཞིན་མེད་པ་རྟག་ཏུ་ཤར། །
```

一切体相都真实圆满，［常、断］二边都完全远离；一切事物的本性，就是无自性，恒常地显现着。

【按】这一颂与《慈五颂》第五颂几乎相同，只是第三句《慈五颂》作"本体"（ngo bo nyid），本篇作"本性"（rang bzhin）。末两句"一切事物的本性，就是无自性，恒常显现"，把显现与空性收在一句之中。
