# 大乘二十颂

梅纪巴（阿阇黎无二金刚）造　据藏文译出

## 题解

《大乘二十颂》（梵 Mahāyānaviṃśikā，藏 theg pa chen po nyi shu pa）收于德格版丹珠尔续部释 ཝི 函第 137b 至 138b 页（东北目录 D2248），紧接在《真如口诀·道歌宝藏》（D2247）之后，同属梅纪巴的"无念法类"。译者是印度堪布天作月（Devākaracandra）与藏地译师比丘释迦精进，跋语说是"译出并校订而定稿"。

全篇二十颂八十句。作者在第三颂说，这是"随顺密咒乘"来讲说的，但全篇所讲的主要是见地与心性，很少涉及仪轨。大致可以分为五部分：

第一至三颂：礼敬本然之身，说三身都是心要的本性，见此便能成就菩提。

第四至七颂：说真如远离四边，如虚空般寂静，无始无中无终；不可思议的心性即是一切事物的本性；证悟众生一味，便无浊而光明。

第八至十五颂：说菩提与烦恼不异，迷乱的本性无垢；证悟者身语意的行持；众生如幻；真如不是思辨所能得，要依上师；最后连"空性""大乐""无二"等名言也都超越。

第十六至十九颂：特别指出，经中所说的初业行持，是一切瑜伽士都应当做的；空性与悲心无别，就是佛智；以三身作结。

第二十颂：回向。

其中第十六颂"初业行持是一切瑜伽士的事"，与《除恶见》的主旨完全一致，说明梅纪巴即使在讲最高的心性之见时，也不舍弃初业的善行。第七颂"随你安乐而住"、第十四颂"无论怎样行持都是安乐"一类的话，是就证悟者的境界而说的，不能作为未证者放逸的借口；作者以第十六颂作了明确的平衡。

另外，同函还有一部《真如大乘二十颂》（D2250），题名相近，但内容与译者都不同，是另一部作品，读者不要混淆。

体例：每颂先列藏文原颂于代码块中，再按完整的意义单元译出；为了便于理解而补的字，都放在方括号中。原文含混或可有两解之处，以"【按】"说明，不妄补内容。文末附通篇连读。

## 题名与礼敬

梵语题名：Mahāyānaviṃśikā。藏语题名：《大乘二十颂》。

敬礼心要之身！

## 第一颂　礼敬本然之身

```
ཟུང་འཇུག་གོ་འཕང་ཡང་དག་སོན། །
རྣམ་པ་ཀུན་གྱི་མཆོག་ལྡན་པ། །
མཚན་ཉིད་མེད་ཅིང་འདུས་མ་བྱས། །
གཉུག་མའི་སྐུ་ལ་ཕྱག་འཚལ་ལོ། །
```

那真正达到双运果位的、具足一切殊胜相的、无相而无为的本然之身，我向它顶礼。

【按】"心要之身"（snying po'i sku）与"本然之身"（gnyug ma'i sku），都是指三身的共同本性，即自性身。"具足一切殊胜相"，见《大乐义明示》结颂按语。"无相"（mtshan nyid med），这里指没有可以执取的体相，与"具足一切殊胜相"并不相违：本然之身无可执之相，却能显现一切妙相。

## 第二颂　三身即心要的本性

```
འདི་ནི་ཆོས་དང་ལོངས་སྤྱོད་སྤྲུལ། །
སྙིང་པོ་དེ་ཡི་རང་བཞིན་པས། །
དེ་ལ་འདི་མཐོང་ལྡན་པ་ཡིས། །
ཡང་དག་རྫོགས་པའི་བྱང་ཆུབ་འགྲུབ། །
```

这［本然之身］就是法身、报身与化身，因为［三身］是那心要的本性；在那［心要］中见到这［本然之身］的人，就能成就圆满正等菩提。

【按】"报身"，原文作 longs spyod（受用），是 longs spyod rdzogs pa'i sku（圆满报身）的略称。"化身"，原文 sprul，异文作 sbrul（蛇），显然是讹文，依校勘惯例取 sprul。

## 第三颂　随顺密咒乘而说

```
འདི་ལ་མཐོང་བར་གྱུར་པ་ཡིས། །
སྒྲོ་མ་བཏགས་པས་ལྷག་པར་མཐོང་། །
གསང་སྔགས་ཐེག་པའི་རྗེས་འབྲངས་ནས། །
དེ་འདིར་ད་ལྟར་བཤད་པར་བྱ། །
```

已经见到这［本然之身］的人，因为不起增益，所以能殊胜地照见；［我］随顺密咒乘，现在在这里来讲说它。

【按】"殊胜地照见"（lhag par mthong），也就是"胜观"（毗钵舍那），这里指以不增益的方式照见心性。

## 第四颂　远离常断二边

```
སྣ་ཚོགས་རྟོག་པའི་གཞུང་ནི་མེད། །
ཆད་པར་སེམས་པའང་མེད་པ་སྟེ། །
རྟག་དང་ཆད་པའང་གཉིས་ཀ་མེད། །
གཉིས་པོ་མེད་པས་གཉིས་མིན་ཏེ། །
```

［这里］没有分别种种［显现］的教轨，也没有认为［一切］断灭的想法；常与断二者都没有，［而且］因为［常、断］二者都没有，所以也不是"非二者"。

【按】这一颂与《真如宝鬘》第十五节无住派的偈颂"不分别种种，也不承许断灭；不是常，不是断，不是二者，也不是非二者"几乎相同，说的是远离四边的无住之见。第四句"因为二者都没有，所以也不是非二者"，意思是："非常非断"这一说法，也是相对于"常、断"而立的；既然常、断本来不成立，"非常非断"也就不能执为一个立场。

## 第五颂　离四边的真如

```
མཐའ་བཞི་རྣམ་གྲོལ་དེ་ཉིད་ནི། །
དེ་ཉིད་རིག་པ་མཁས་པས་ཤེས། །
མཐའ་བཞི་རྣམ་པར་དག་པ་ཉིད། །
མཐའ་བཞི་ལ་ནི་རྣམ་པར་བརྟེན། །
```

那远离四边的真如，是通达真如的智者所了知的。［所谓］"四边的清净"本身，［其实也是］依于四边［而说的］。

【按】后两句较难确定。这里的理解是：说"远离四边""四边清净"，也只是相对于四边而施设的名言，并不是另有一个"离四边"的东西可以执取；这与上一颂"也不是非二者"的意思一致。也可以理解为"四边的清净，就在四边本身之中"，即不离四边而见其清净。两种读法都可以成立，存疑。

## 第六颂　心性即一切事物的本性

```
ནམ་མཁའ་དང་མཉམ་ཞི་བ་དང་། །
ཐོག་མ་དབུས་དང་ཐ་མ་སྤངས། །
བསམ་གྱིས་མི་ཁྱབ་སེམས་ཉིད་ནི། །
དངོས་པོ་ཀུན་གྱི་རང་བཞིན་ནོ། །
```

如同虚空，寂静，远离开始、中间与终结——那不可思议的心性，就是一切事物的本性。

## 第七颂　证悟一味，安乐而住

```
འགྲོ་བ་རོ་གཅིག་པར་རྟོགས་ན། །
རྙོག་པ་མེད་ཅིང་འོད་གསལ་བའོ། །
ཀུན་དུ་རྟོག་པས་འཇིགས་མེད་ན། །
ཇི་ལྟར་བདེ་བ་ཁྱོད་གནས་བྱོས། །
```

如果证悟了众生［与诸法］同为一味，那就是无浊而光明的。如果［你］不再被种种分别念所怖畏，那就随你怎样安乐而住吧！

【按】"一味"（ro gcig），见《真如十颂》第五颂按语。"随你怎样安乐而住"（ji ltar bde ba khyod gnas byos），是道歌中常见的说法，意思是证悟一味的人，已不再被分别念所动，所以无论行住坐卧都能安住；这是就已经证悟者而说的，前提是"不再被分别念所怖畏"。未证悟的人，不能以此为由而放逸，第十六颂对此有明确的说明。

## 第八颂　菩提与烦恼不异

```
བྱང་ཆུབ་ཉོན་མོངས་ཐ་དད་མེད། །
ཉོན་མོངས་བྱང་ཆུབ་ལས་མི་འབྱུང་། །
འཁྲུལ་པས་ཉོན་མོངས་རྟོགས་པ་སྟེ། །
འཁྲུལ་པའི་ངོ་བོ་དྲི་མ་མེད། །
```

菩提与烦恼并非不同；［然而］烦恼并不是从菩提中生起的。烦恼是由迷乱所分别出来的，而迷乱的本体是无垢的。

【按】这一颂很重要："菩提与烦恼不异"，是就本性而说：烦恼的本性就是菩提；"烦恼不从菩提生起"，是说烦恼并不是菩提本身的产物，而是由迷乱的分别而有。迷乱本身没有自性，所以说它的本体无垢。这与《真如十颂》第三颂"从迷乱中成为无贪著，迷乱本身也无所住"的意思相通。

## 第九颂　证悟者的身语意

```
ལུས་ཀྱི་ལས་སུ་སྤྱོད་ལམ་སྟེ། །
ངག་གི་ལས་ནི་ཆོས་སྟོན་ཏེ། །
ཡིད་ཀྱི་ལས་སུ་ཡང་དག་འཛིན། །
རྣམ་པར་མི་རྟོག་བློ་ལྡན་པའོ། །
```

身的作为，是［如法的］威仪；语的作为，是宣说正法；意的作为，是正确地受持［正法］——［这就是］具有无分别智慧的人。

【按】"威仪"（spyod lam），指行、住、坐、卧四种威仪。"正确地受持"（yang dag 'dzin），也可以理解为"正念、正持"。这一颂说明：具有无分别智慧的人，并不是什么都不做，而是身语意都如法而行。

## 第十颂　众生如幻

```
འགྲོ་བ་སྒྱུ་མ་སྒྱུ་མ་འདི། །
སྒྱུ་མས་སྒྱུ་མ་མི་བྱ་སྟེ། །
སྒྱུ་མ་རྨོངས་པས་འཁྲུལ་པ་ཆེ། །
འཁྲུལ་འགྱུར་འཁྲུལ་པ་དམ་པའི་ལུགས། །
```

众生如幻，这如幻［的众生］——不要以幻去造作幻；［因为］对幻的愚昧，是大迷乱；［了知］迷乱就是迷乱，这是圣者的道轨。

【按】这一颂的藏文很难确定，以上只是依上下文的理解。"不要以幻去造作幻"（sgyu mas sgyu ma mi bya），可能是说：不要在如幻的显现上再加上执著的造作。末句"'khrul 'gyur 'khrul pa dam pa'i lugs"，直译是"迷乱成为迷乱，圣者之道"，这里理解为"认出迷乱就是迷乱，这是圣者之道"；也可以理解为"把迷乱转为［清净的］迷乱"，即如幻地利生。两种读法都存疑。

## 第十一颂　了知自性，诸佛摄于其中

```
ཇི་ལྟར་རང་བཞིན་རྣམ་ཤེས་ན། །
སངས་རྒྱས་ལ་སོགས་བསྡུས་པ་སྟེ། །
ཀུན་ནས་ཀུན་དུ་ལོངས་སྤྱོད་ན། །
དེ་ཉིད་རིག་པར་རབ་ཏུ་འགྲུབ། །
```

如果如实地了知了自性，那么诸佛等都摄于其中；若在一切处都［如此］受用，就能完全成就对真如的了知。

【按】第一句"ji ltar rang bzhin rnam shes na"，也可以读作"如果［了知］识的自性如其所是"，rnam shes 可以是动词"了知"，也可以是名词"识"。这里依前者，存疑。"受用"（longs spyod），指在日常的一切显现中安住于对自性的了知。

## 第十二颂　真如非思辨可得，依上师

```
ཆོས་ཀྱི་ཕུང་པོ་སྟོང་ཕྲག་གིས། །
རྟོག་པ་ཞེས་བྱ་སྟོང་པ་ཉིད། །
རྟག་པ་འདི་ནི་དཔྱད་པས་མིན། །
བླ་མས་དཔྱད་པ་མིན་པར་འགྱུར། །
```

以数千的法蕴［所开示的］，所谓"分别"，就是空性；这一观察，并不是靠［理智的］分析［所能达到的］；由上师［的指引］，才成为超越分析的。

【按】第三句原文作"rtag pa"（常），讲不通，应是 brtag pa（观察）之讹，与《真如宝鬘》第十五节同一讹误，这里依此译出。这一颂说明：分别的本性即空性，这是佛陀以无数法门所开示的；但要真正契入，不是靠思辨分析，而要依上师的指引，才能超越分析。

## 第十三颂　超越一切名言

```
སྐྱེས་བུ་རྣམ་རྟོག་བྲལ་བ་ནི། །
རྣམ་ཀུན་བདེ་བའི་དེ་ཉིད་དོ། །
སྟོང་ཉིད་བདེ་བའི་དེ་ཉིད་མིན། །
བསམ་མི་ཁྱབ་མིན་བདེ་བ་མིན། །
```

远离分别的人，就是一切相安乐的真如。［它］不是空性，不是安乐的真如；不是不可思议，也不是安乐。

【按】这一颂先说远离分别者即是"一切相安乐的真如"，随即又说它"不是空性，不是安乐的真如，不是不可思议，也不是安乐"。这是在破除对一切名言的执著：即使是"空性""大乐""不可思议"这样的说法，一旦被执为一个对象，也就不是真如了。第三句也可以读作"空性不是安乐的真如"，即空性与安乐不能分别执取；这里依上下文取否定一切名言的理解，存疑。

## 第十四颂　佛不被增益

```
དེས་ན་སངས་རྒྱས་སྒྲོ་མ་བཏགས། །
དེ་ནི་དོན་དམ་མཐོང་བ་མེད། །
གང་ལ་སྤྱོད་པ་ཇི་ལྟར་བདེ། །
དེ་ལྟ་རིག་པ་མཐོང་བ་མེད། །
```

所以，佛［是］不被增益的；那就是胜义，［其中］没有［能见与所见的］看见。无论在什么上行持，都是安乐；这样的觉知，［也］没有［能见与所见的］看见。

【按】"没有看见"（mthong ba med），意思是没有能见、所见的二取；胜义不是作为一个对象被"看见"的。第三句"gang la spyod pa ji ltar bde"，也可以理解为"无论行于何处，都如其所乐"，与第七颂"随你怎样安乐而住"相呼应；这同样是就证悟者的境界而说的。

## 第十五颂　无所希求的大瑜伽

```
གཉིས་སུ་མེད་པ་གཉིས་མེད་མིན། །
བྱང་ཆུབ་དག་པའི་མཚན་ཉིད་མེད། །
རེ་བ་མེད་འདི་རྣལ་འབྱོར་ཆེ། །
རྣམ་པ་ཐམས་ཅད་རྟོགས་པའོ། །
```

无二，［也］不是"无二"；菩提，没有"清净"的体相。这无所希求的，就是大瑜伽，［也就是］证悟一切相。

【按】"无二也不是无二"，与第四颂"也不是非二者"同一思路：连"无二"也不能执为一个立场。"无所希求"（re ba med），指不希求果位，因为本然之身本来具足；这也是大手印"无希无惧"的要义。

## 第十六颂　初业行持是一切瑜伽士的事

```
ཇི་ལྟར་གསུངས་པ་དང་པོའི་ལས། །
རྣལ་འབྱོར་ཀུན་གྱི་བྱ་བ་ཡིན། །
སྟོང་དང་སྙིང་རྗེ་དབྱེར་མེད་པ། །
དེ་ནི་སངས་རྒྱས་ཡེ་ཤེས་འདོད། །
```

如［经论中］所说的初业行持，是一切瑜伽士都应当做的事。空性与悲心无别，那就被承许为佛的智慧。

【按】这一颂极为重要。"初业行持"（dang po'i las，梵 ādikarma），即梅纪巴在《除恶见》中详细说明的初业仪轨：受斋戒、供养、施食、诵经、作擦擦、回向等日常善行。作者在这里明确说：这是"一切瑜伽士"都应当做的，也包括已经修学甚深见地的人。前面第七、十四颂所说"随意安乐而住""无论怎样行持都是安乐"，必须与这一颂合起来理解：证悟心性，并不是舍弃初业善行的理由。这正是《除恶见》所要破除的"恶见"。

## 第十七颂　空悲双运

```
སྟོང་ལས་སྙིང་རྗེ་གཞན་མིན་ཏེ། །
སྙིང་རྗེ་ཡི་ནི་མིང་གཞན་ཡིན། །
བདག་གིས་འདུས་བྱས་སུ་མི་བརྗོད། །
བརྗོད་པ་ཟུང་དུ་འཇུག་པར་རོ། །
```

悲心不在空性之外，［空性］只是悲心的另一个名字。我不说［它］是有为的，我说［它］是双运的。

【按】第二句"snying rje yi ni ming gzhan yin"，直译是"是悲心的另一个名字"，主语没有明说，这里依上下文补为"空性"；也可以理解为"［悲心］是［空性］的另一个名字"，意思相同。"不说是有为的，说是双运的"，意思是空悲无别的佛智，不是由因缘造作而成的有为法，而是空与悲本来双运。

## 第十八颂　一切执取皆可为禅定

```
བུམ་པ་ལ་སོགས་འཛིན་གང་ལ། །
རྣལ་འབྱོར་ཀུན་གྱི་བསམ་གཏན་བྱ། །
འདིས་ནི་སངས་རྒྱས་ཆེན་པོར་འགྱུར། །
རྣམ་པ་ཀུན་གྱི་ལུས་གཅིག་པའོ། །
```

无论［心中生起］对瓶等的什么执取，瑜伽士都［就在其上］修一切禅定；由此就成为大佛，［也就是］一切相同一的身。

【按】这一颂的意思是：瑜伽士不必离开日常对瓶等事物的认知另求禅定，而是就在每一个念头、每一种执取之上，认出它的本性，这本身就是禅定。这与大手印"念头即法身"、"于一切显现上修持"的要义一致。第二句"rnal 'byor kun gyi bsam gtan bya"，也可以理解为"一切瑜伽士都要［在其上］修禅定"，意思相近。

## 第十九颂　三身

```
འདུས་མ་བྱས་སེམས་ཆོས་ཡིན་ཏེ། །
རྟོགས་པའི་ལོངས་སྤྱོད་རྫོགས་མཚན་ཉིད། །
སྣ་ཚོགས་སེམས་ནི་སྤྲུལ་པའོ། །
གཉུག་མ་ཀུན་གྱི་རང་བཞིན་ནོ། །
```

无为之心是法身；证悟［的受用］是圆满报身的体相；种种［显现］的心是化身；本然是一切［身］的自性［身］。

【按】这一颂与《五部自性》第四节所引的偈颂几乎相同，那里第二句作"常住是圆满报身之相"，这里作"证悟是圆满报身之相"。"本然是一切的自性"，指自性身，即三身一味的本性，呼应第一颂所礼敬的"本然之身"。

## 第二十颂　回向

```
དེ་ལྟར་འདི་ཡིས་ཐོབ་པ་ནི། །
བསོད་ནམས་ལྡན་པའི་བསོད་ནམས་ཀྱིས། །
དེ་ནི་འཇིག་རྟེན་མ་ལུས་པ། །
སངས་རྒྱས་བྱང་ཆུབ་ཐོབ་པར་ཤོག །
```

这样，以由此所获得的、具足福德的福德，愿一切世间［众生］都获得佛的菩提！

## 通篇连读

敬礼心要之身！

那真正达到双运果位的、具足一切殊胜相的、无相而无为的本然之身，我向它顶礼。

这本然之身就是法身、报身与化身，因为三身是那心要的本性；在那心要中见到这本然之身的人，就能成就圆满正等菩提。

已经见到它的人，因为不起增益，所以能殊胜地照见；我随顺密咒乘，现在在这里来讲说它。

这里没有分别种种显现的教轨，也没有认为一切断灭的想法；常与断二者都没有，而因为常、断二者都没有，所以也不是非二者。

那远离四边的真如，是通达真如的智者所了知的；所谓四边的清净，其实也是依于四边而说的。

如同虚空，寂静，远离开始、中间与终结——那不可思议的心性，就是一切事物的本性。

如果证悟了众生与诸法同为一味，那就是无浊而光明的；如果你不再被种种分别念所怖畏，那就随你怎样安乐而住吧！

菩提与烦恼并非不同，然而烦恼并不是从菩提中生起的；烦恼是由迷乱所分别出来的，而迷乱的本体是无垢的。

身的作为是如法的威仪，语的作为是宣说正法，意的作为是正确地受持正法——这就是具有无分别智慧的人。

众生如幻，对这如幻的众生，不要以幻去造作幻；因为对幻的愚昧是大迷乱，了知迷乱就是迷乱，这是圣者的道轨。

如果如实地了知了自性，那么诸佛等都摄于其中；若在一切处都如此受用，就能完全成就对真如的了知。

以数千的法蕴所开示的，所谓分别就是空性；这一观察，并不是靠理智的分析所能达到的，由上师的指引，才成为超越分析的。

远离分别的人，就是一切相安乐的真如；它不是空性，不是安乐的真如，不是不可思议，也不是安乐。

所以，佛是不被增益的，那就是胜义，其中没有能见与所见的看见；无论在什么上行持，都是安乐，这样的觉知，也没有能见与所见的看见。

无二，也不是无二；菩提，没有清净的体相；这无所希求的，就是大瑜伽，也就是证悟一切相。

如经论中所说的初业行持，是一切瑜伽士都应当做的事；空性与悲心无别，那就被承许为佛的智慧。

悲心不在空性之外，空性只是悲心的另一个名字；我不说它是有为的，我说它是双运的。

无论心中生起对瓶等的什么执取，瑜伽士都就在其上修一切禅定；由此就成为大佛，也就是一切相同一的身。

无为之心是法身，证悟的受用是圆满报身的体相，种种显现的心是化身，本然是一切身的自性身。

这样，以由此所获得的、具足福德的福德，愿一切世间众生都获得佛的菩提！

《大乘二十颂》，阿阇黎无二金刚造，圆满。印度堪布天作月与藏地译师比丘释迦精进译出，并校订而定稿。
