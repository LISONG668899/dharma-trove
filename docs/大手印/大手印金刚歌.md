# 大手印金刚歌

吉祥夏瓦日自在等尊前所出　据藏文译出

## 题解

《大手印金刚歌》（梵 Mahāmudrā-vajragīti，藏 phyag rgya chen po rdo rje'i glu）收于德格版丹珠尔续部释 ཞི 函第 150a 至 152b 页（东北目录 D2287），紧接在《空行耳传·断苦口诀》（D2286）之后。跋语说，这是"由吉祥夏瓦日自在、空行母智慧眼母与莲花眼的尊前，将心要之义作成道歌"的《大手印金刚歌·表征传承秘密之灯》；没有译者跋语。

**作者与受者：**开头一句"嘿吙！无二金刚，请这样谛听"，"无二金刚"（gnyis med rdo rje，梵 Advayavajra）既可以理解为对听者的称呼，也正是梅纪巴（Maitrīpa）的法名。按照噶举派的传承，梅纪巴正是在吉祥山从夏瓦日巴得到大手印的传授，所以本篇很可能被视为夏瓦日巴向梅纪巴所唱的道歌。不过跋语同时列出"空行母智慧眼母"（ye shes kyi spyan ma）与"莲花眼"（pad+ma'i spyan）两位，三者的关系，以及谁是唱者、谁是传者，原文没有说明，存疑。

**结构：**全篇是一句一喻的"表征"（brda）道歌，以"嗡阿吽，唉玛吙"之类的感叹语分成几大段。依内容大致可分为：依止上师；见地——以虚空、大海、冰、大地、黄金、火与水"六喻"显示心性；迷乱之喻与对治之喻；修习的要点；修习中对昏沉、掉举等的调整；行持；上师的功德与修行的得失；果；最后以"基、道、果"配"三解脱门"与"三身"作总结。各节标题为译者所加。

**关于表征语言：**本篇几乎全是比喻，不作解释，而且比喻的排列往往正反交错——前一句是迷乱之喻，后一句可能是证悟之喻。许多比喻是大手印与如来藏传统中常见的（如"地下黄金""贫家宝藏""瓶中灯""绳与蛇""蛇结自解""冰与水""船上飞鸟"），能依通行的教义看出大意的，在按语中简要说明；看不出的，一律存疑，不妄补内容。少数涉及风息的修法（如"宝瓶合口之风"），须依具德上师的口授来修习，不可照字面自行修练。"在那里杀死野兽""斩断敌人""把心中所珍爱的送到尸陀林"等，都是比喻断除念头与贪执的象征语言，不是字面上的行为。

**与前译的关系：**本篇以前没有译过，与已译篇目没有整段的重复。它的体裁与《空行耳传·断苦口诀》（D2286）、《大手印口诀秘密金刚歌》（D2440）相近，都是一句一喻的表征之歌；其中"天鹅取乳""狮子之乳""疯人、狗、猪"等比喻，在《空行耳传·断苦口诀》中也出现过，可以互相参看。

体例：本篇是偈颂体，依本译的体例，按意义单元把藏文原文列于代码块中，再以完整的意义单元译出；为了便于理解而补的字，都放在方括号中。全篇共 244 句，各节标题后注明所含句号（与另附的《藏文底本》编号一致）。原文含混或可有两解之处，以"【按】"说明。

## 一、题名与礼敬（第 1–8 句）

```
༄༅༅། །
རྒྱ་གར་སྐད་དུ།
མ་ཧཱ་མུ་དྲཱ་བཛྲ་གཱི་ཏི་ནཱ་མ།
བོད་སྐད་དུ།
ཕྱག་རྒྱ་ཆེན་པོ་རྡོ་རྗེའི་གླུ་ཞེས་བྱ་བ།
དཔལ་ཤ་བ་རི་དབང་ཕྱུག་ལ་ཕྱག་འཚལ་ལོ། །
ན་མོ་དྷརྨ་ཀཱ་ཡ།
མ་ཧཱ་སུ་ཁ་ཡེ།
```

梵语题名：Mahāmudrā-vajragīti-nāma。藏语题名：名为《大手印金刚歌》。

敬礼吉祥夏瓦日自在！敬礼法身——大乐！

【按】"南无达磨迦耶，摩诃苏卡耶"（namo dharmakāya mahāsukhāya），是梵文"敬礼法身、大乐"。

## 二、依止上师（第 9–27 句）

```
ཀྱེ་ཧོ་གཉིས་མེད་རྡོ་རྗེ་འདི་ལྟར་ཉོན། །
གང་ཞིག་མིག་མེད་པ་ཡིས་ལམ་མཁན་བསྟེན། །
བུ་ཆུང་དཔའ་བོ་མ་ལ་རག་ལུས་ཏེ། །
མེ་ལོང་བསྟན་པས་བཞིན་གྱི་དཀྱིལ་འཁོར་གསལ། །
ངང་པའི་མཆུ་ཡིས་ཆུ་དང་འོ་མ་འབྱེད། །
```

嘿吙！无二金刚，请这样谛听：盲人要依止向导；幼小的孩子，［将来虽是］勇士，［现在］仍要依靠母亲；拿出镜子来，面容的轮廓才看得清楚；天鹅的嘴能把水与乳分开。

```
བསྐལ་པའི་མུན་པ་སེལ་བྱེད་སྒྲོན་མེ་སྟེ། །
གཏེར་གྱི་བང་མཛོད་འབྱེད་པའི་ལྡེ་མིག་མཆོག །
མི་ཟད་གཏེར་ཆེན་འབྱིན་པའི་རྒྱལ་པོ་བསྟེན། །
དབུལ་པོ་བསྟེན་པས་བདག་ཉིད་དབུལ་པོར་འགྱུར། །
```

［上师］是驱除劫中黑暗的灯，是打开宝藏库藏的最上钥匙。要依止能出生无尽大宝藏的国王；依止穷人，自己也会变成穷人。

```
ནམ་མཁའ་རྒྱ་མཚོ་ཉི་ཟླ་གསུམ་ལྡན་བསྟེན། །
ནེ་ཙོའི་ཁ་ཐོན་སྙན་པས་ཅི་ཞིག་ཕན། །
འདབ་ཆགས་བུ་ནི་མཁའ་ལ་འཕུར་ན་བདེ། །
དུད་འགྲོ་གཡང་ལ་བསྐྱུར་ན་གསོན་མི་རུང་། །
```

要依止具足虚空、大海、日月三者的［上师］。鹦鹉背诵得再动听，又有什么用呢？雏鸟在空中飞翔，就安乐；畜生被丢到悬崖上，就活不成。

```
ཉི་ཟླ་གཟའ་བྲལ་སྤྲིན་རླུང་བཏབ་ན་གསལ། །
སྤྲིན་སངས་གྱུར་ཀྱང་གཟས་ཟིན་སྣང་བ་མེད། །
ཆུ་སྐྱེས་པདྨའི་བཅུད་ནི་བུང་བས་ལེན། །
ཤ་སྦྲང་དྲུང་ན་གནས་ཀྱང་དེ་ལྟར་མིན། །
ཆུ་ཤེལ་ཆུ་ནི་རྐྱེན་དང་འཛོམ་པ་གཅེས། །
སེང་གེའི་འོ་མ་སྣོད་ངན་ཕལ་པར་མིན། །
```

日月离开了罗睺，云被风吹散，就明亮；云虽然散开了，若被罗睺所吞，也没有光明。水中所生的莲花，它的精华由蜜蜂采取；肉蝇虽然住在旁边，却不是这样。月精石出水，贵在与［月光之］缘会合。狮子的乳，不是劣器、凡器［所能盛装的］。

【按】这一段说依止具格上师的必要。"盲人依止向导""孩子依靠母亲""镜子照见面容""天鹅分开水乳"，比喻弟子要依上师才能认识心性、分辨真伪。"依止穷人，自己也会变成穷人""鹦鹉背诵得动听"，是说不可依止只会口说而没有证悟的人。

"具足虚空、大海、日月三者"，意思不很确定：可能是指证悟如虚空、功德如大海、智慧与悲心如日月，存疑。"畜生被丢到悬崖上，就活不成"，与上句"雏鸟在空中飞翔就安乐"对比，可能是说根器未熟的人，若没有上师的引导而骤然被推入甚深之法，反而有害，存疑。

"日月离开罗睺""被罗睺所吞"：罗睺（gza'）是印度传说中吞食日月、造成日月食的星曜。这两句可能是说：外障（云）虽然除去，若内心仍被我执（罗睺）所吞，心性的光明仍然不能显现，存疑。"蜜蜂采莲花精华，肉蝇却不能"，比喻有缘的弟子能从上师那里得到法的精华，无缘的人虽然近在身边，也得不到。"月精石"（chu shel），是传说中遇到月光就会流出水来的宝石，比喻弟子的根器要与上师的加持之缘相遇。"狮子之乳不是劣器所能盛"，是常见的比喻，说甚深的口诀只能传给堪受的法器。

## 三、见地：显有如虚空——六喻（第 28–43 句）

```
ཨོཾ་ཨཱཿཧཱུཾ་ཨེ་མ་ཧོ། །
སྣང་སྲིད་ཐམས་ཅད་ནམ་མཁའ་ཉིད་ལས་བྱུང་། །
ནམ་མཁའ་ཡོད་མེད་ཕྱོགས་རྒྱུ་ཁ་དོག་བྲལ། །
ཐོག་མ་བར་དང་ཐ་མ་འགྲོ་འོང་མེད། །
འབྱུང་བཞི་རབ་ཏུ་འཁྲུགས་ཀྱང་འགྱུར་མི་སྲིད། །
རྐྱེན་གྱིས་དཀར་ནག་སྣང་ཡང་དཀར་ནག་མེད། །
```

嗡阿吽，唉玛吙！一切显有都从虚空本身出生；虚空离开了有与无、方所、因与颜色；没有初、中、后，没有来与去。四大即使剧烈扰动，［虚空］也不可能改变；因缘虽然使［虚空］显现出黑白，［虚空中］却没有黑白。

```
རྒྱ་མཚོ་གཏིང་ཟབ་རྒྱ་ཆེ་སྣ་ཚོགས་འཆར། །
དབའ་རླབས་རི་བོ་འདྲ་ཡང་རྒྱ་མཚོའི་ངང་། །
ཆབ་རོམ་བྲག་འདྲ་ཆུ་ལས་ཡོང་མ་འདས། །
ས་ལ་སྣ་ཚོགས་འཁྲུངས་ཀྱང་ཟད་པ་མེད། །
བསྲེགས་བཅད་བདར་ཡང་གསེར་གྱི་ངོ་མི་འགྱུར། །
མེ་ནི་ཚ་ཞིང་ཆུ་ནི་རླན་མི་འབྲལ། །
```

大海深而广，种种［影像］都在其中显现；波浪虽然像山一样，仍是大海的本性；冰块虽然像岩石，从来不离开水。大地上虽然生出种种，却不会穷尽；黄金虽然经过烧、切、磨，金的本色也不会改变；火是热，水是湿，［彼此］不可分离。

```
སྤྲུལ་པ་དྲུག་ནི་རབ་ཏུ་རྟོགས་པར་གྱིས། །
ནམ་མཁའ་སྟོང་ལས་སྟོང་པ་འབྱུང་བ་སྟེ། །
རྐྱེན་གྱིས་མེ་ཆུ་འབྱུང་ཡང་ཤེལ་གྱི་ངོ་མི་འགྱུར། །
བཀའ་རྟགས་ཕྱག་རྒྱ་གཉུག་མ་ཞེས་བརྗོད་དོ། །
```

要彻底了悟这六种化现！从虚空的空性中出生空性；因缘虽然使水晶生出火与水，水晶的本色却不会改变。这就称为"王敕的印信，本然的手印"。

【按】这一段是本篇的见地。"一切显有都从虚空本身出生"，是以虚空比喻心性：一切显现都从心性中生起，而心性本身离开有无、方所、颜色、初中后与来去，四大的扰动、黑白的显现都不能改变它。

"六种化现"（sprul pa drug），依上下文，可能就是上面所说的六个比喻：虚空、大海（与波浪）、冰（与水）、大地、黄金、火（之热）与水（之湿）。它们共同说明：种种显现（化现）与心性不二，显现虽然变化，本性不变。这样配数是译者的推测，存疑。

"从虚空的空性中出生空性"，是说从空性中生起的一切，本身也是空性。"水晶生出火与水"：印度传说中，日精石（sūryakānta）遇到日光就生火，月精石遇到月光就出水，比喻心性随缘显现种种，而本性不变。

"王敕的印信，本然的手印"（bka' rtags phyag rgya gnyug ma），"bka' rtags"是国王诏令上的印信，见到它就确定是王命，不可更改；"phyag rgya gnyug ma"，即本然的大手印。这是说：上面所示的心性，就是一切法无可更改的"印"——大手印。

## 四、迷乱之喻（第 44–60 句）

```
ས་འོག་གསེར་དང་གྱད་ཀྱི་ནོར་བུ་དང་། །
དབུལ་པོའི་གཏེར་དང་བུམ་པའི་མར་མེ་ལྟོས། །
```

看那地下的黄金、力士的宝珠、穷人的宝藏、瓶中的灯！

```
ནོར་བུ་རིན་ཆེན་མི་གཙང་འདམ་དུ་བྱིང་། །
སྒྱུ་མར་མ་ཤེས་རྒྱལ་པོ་ཨ་ཐང་ཆད། །
ཐག་པ་སྦྲུལ་དུ་མཐོང་བས་བརྒྱལ་ནས་ཤི། །
མར་མེ་ཉི་མ་དམུས་ལོང་མུན་པར་སྣང་། །
མི་གཙང་དྲི་ཟ་ཙནྡན་དྲི་ལ་འབྲོས། །
མིག་སྐྱོན་ཅན་གྱིས་ཟླ་བ་གཉིས་སུ་མཐོང་། །
```

珍宝沉没在不净的泥中；不知道是幻术，国王就沮丧绝望；把绳子看成蛇，昏厥而死；灯与太阳，在盲人看来是黑暗；以不净为食的［虫子］，逃避旃檀的香气；眼睛有病的人，看见两个月亮。

```
གླང་པོ་བཞག་ནས་གླང་པོའི་རྗེས་ཚོལ་བ། །
བུ་ཆུང་མེ་ལོང་གཟུགས་བརྙན་མཐོང་བས་དགའ། །
རི་དྭགས་འཁྲུལ་པ་སྨིག་རྒྱུ་ཆུ་ལ་སྙེག །
གསེར་མ་ཤེས་པ་ར་གན་ཕྱེ་མ་འཆང་། །
ཀོ་ཆུ་གླང་རྗེས་ཆུ་ནི་མྱུར་དུ་སྐམ། །
```

把大象留在［家里］，却去寻找大象的足迹；小孩见到镜中的影像而欢喜；迷乱的野兽追逐阳焰之水；不识黄金的人，却拿着黄铜粉；牛蹄印中的水，很快就会干涸。

```
རྐྱལ་མེད་པ་དག་རྒྱ་མཚོར་ཞུགས་ན་འབྱིང་། །
ལམ་མཁན་མེད་པར་དམུན་ལོང་ལམ་འགྲོ་དང་། །
འདབ་གཤོག་མེད་པའི་བྱ་དག་འཕུར་ན་ལྟུང་། །
དུག་ལོ་བྲེགས་ནས་བསྒྱུར་ཀྱང་ཅི་ཞིག་ཕན། །
```

不会游泳的人进入大海，就会沉没；没有向导的盲人行路，以及没有翅膀的鸟去飞，就会坠落；把毒树的叶子剪掉再移植，又有什么用呢？

【按】第 44–45 句，是如来藏教法中最著名的几个比喻：地下的黄金、力士额上的宝珠（出自《大般涅槃经》，力士额上的宝珠陷入皮肉之中，自己不知道，以为丢了）、穷人家中地下的宝藏（出自《如来藏经》《宝性论》）、瓶中的灯（出自龙树《法界赞》，灯在瓶中，光照不出来，瓶破则光明显现）。都是比喻心性本具，只是被客尘遮蔽而不自知。

第 46–60 句，多是比喻众生因不认识心性而迷乱：

- "珍宝沉在泥中"：心性被烦恼所覆；
- "把绳子看成蛇，昏厥而死"：把本无自性的显现执为实有而受苦，这是佛典中常见的比喻；
- "灯与太阳在盲人看来是黑暗""眼病者看见两个月亮"：无明使人看不见本有的光明，或把一执为二；
- "留下大象，去寻象迹"：心性就在自身，却向外寻求，这是萨惹哈道歌中常见的比喻；
- "小孩见镜中影像而欢喜""野兽追逐阳焰"：把幻现执为实有而追逐；
- "不识黄金，拿着黄铜粉"：不识真宝而执持假货；
- "牛蹄印中的水很快干涸"：有为的、浅小的成就不能持久；
- "不会游泳而入海""盲人无向导""无翅之鸟"：没有口诀与上师而修行，必定失败；
- "剪毒树的叶子再移植"：只对治枝末的念头，而不断我执的根本，毫无用处。

"不知道是幻术，国王就沮丧绝望"（sgyu mar ma shes rgyal po a thang chad），可能是说国王把幻师变出的景象当真而惊惧绝望，比喻把显现执为实有，存疑。"以不净为食的［虫子］逃避旃檀的香气"（mi gtsang dri za），"dri za"字面是"食香者"，这里"以不净为食者"可能指粪虫之类，比喻习惯了轮回的人反而逃避正法，存疑。"牛蹄印中的水"，藏文作"ཀོ་ཆུ་གླང་རྗེས"，"ཀོ་ཆུ"意思不很确定，这里依"牛蹄印中积存的少许水"理解，存疑。

## 五、对治与了悟之喻（第 61–93 句）

```
མུན་ཁུང་དག་ཏུ་སྒྲོན་མེ་བཏེག་པས་གསལ། །
ཐག་པ་གཅིག་ཆོད་མདུད་པ་བརྒྱ་གྲོལ་ཏེ། །
ཐག་པ་མེས་ཚིག་དག་གིས་འཆིང་མི་ནུས། །
གསེར་འགྱུར་རྩི་ཡིས་ཟངས་ལྕགས་གསེར་དུ་འགྱུར། །
```

在黑暗的洞穴中举起灯，就明亮；斩断一根绳子，百个结都解开；被火烧过的绳子，不能再捆缚；点金药能把铜铁变成黄金。

```
རྨ་བྱས་བཙན་དུག་ཟོས་པས་སྤུ་ཐོག་རྒྱས། །
མིག་དང་ལྡན་པས་རྐང་པ་གར་གཞག་ཕྱིན། །
དབང་གི་རྒྱལ་པོ་གཅིག་ལ་འདོད་དགུ་རྫོགས། །
ཁྱུང་ཕྲུག་གཤོག་རྫོགས་མཁའ་ལ་འཕུར་ན་བདེ། །
མར་མེ་བཏེག་པས་མུན་པའི་ལམ་གསལ་ཞིང་། །
ཅང་ཤེས་སྒྲོག་ཏུ་བཅུག་པ་ཕྱེ་བས་གྲོལ། །
```

孔雀吃了猛毒，羽毛反而更加丰茂；有眼睛的人，想把脚放在哪里，就能走到哪里；一位自在的国王，一切所愿都圆满；大鹏的雏鸟羽翼长满，在空中飞翔就安乐；举起灯，黑暗的道路就明亮；被套上锁链的良驹，打开［锁链］就解脱。

```
ངང་པ་ཆུ་ལ་འོ་མ་ལེན་པ་ལྟོས། །
དགྲ་སྐུགས་བཙལ་བས་འཇིགས་པ་སངས་ནས་འགྲོ། །
ནམ་མཁའ་མ་མཐོང་ནམ་མཁའ་མཐོང་བ་སྟེ། །
རྒྱ་དང་རྒྱ་ཡི་འབུར་ནི་ལོག་པར་འབྱུང་། །
```

看那天鹅在水中取乳！找到了埋伏的敌人，恐惧就消除而前行。不见虚空，就是见到虚空；印章与印章的凸纹，是颠倒而现的。

```
མར་མེ་བསད་པས་ལུས་དང་གྲིབ་མ་མེད། །
སྒྱུ་མ་བཤིག་པས་འདུ་ཤེས་རྣམ་ལྔ་སྤངས། །
ཆུ་ལ་ཆུ་བཞག་དེ་ཉིད་དབྱེར་མེད་འགྱུར། །
ནམ་མཁའི་མེ་ཏོག་རི་བོང་རྭ་ཞེས་བྱ། །
གཟིངས་ལ་འཕུར་བའི་བྱ་ནི་སླར་ལ་ལྡོག །
```

灯熄灭了，身与影都没有了；幻术被破除，就舍弃了五种想；把水放进水中，就成为无别。［那些］被称为"空中花、兔角"［的东西，本来就没有］。从船上飞出的鸟，又会回来。

```
གང་ཞིག་ཆབ་རོམ་སྤངས་ནས་ཆུ་ཚོལ་བ། །
རྒྱུ་རྐྱེན་རྩོལ་བས་བྱས་པ་རང་འབྱུང་མིན། །
དབུལ་པོ་མི་ནོར་རྒྱ་ཡིས་འདེབས་པ་དང་། །
ས་བོན་འབྲས་བུ་ཐ་དད་འཛིན་པ་འཁྲུལ། །
རྐུན་མ་ངོས་མ་ཟིན་པར་རབ་མདའ་སྦྲེན། །
```

有人舍弃了冰块，却去寻找水；由因缘与勤作所造的，不是自生的；穷人把别人的财物盖上［自己的］封印；执持种子与果实为相异，是迷乱；没有认出盗贼，就乱射好箭。

```
ཀྱེ་མ་འདི་ནི་སྦྲུལ་དང་རིག་སྔགས་མཚོན་ཆ་འདྲ། །
རྟ་རྔས་སྦྲུལ་ལ་མདུད་པ་བརྒྱབ་པ་གྲོལ། །
མཁའ་ལ་མདུང་བསྐོར་ལས་ཟིན་སྐྱེས་བུ་བདེ། །
ཁྱུང་ཆེན་མཁའ་ལྡིང་ཉམ་ང་འཇིགས་པ་མེད། །
རི་མཐོའི་ཁ་ན་ཡུལ་ཁམས་སྣ་ཚོགས་གསལ། །
```

唉！这就像蛇、明咒与兵器：用马尾在蛇身上打的结，［自己就］解开；在空中舞矛，事情做完，人就安乐；大鹏金翅鸟翱翔空中，无惧无畏；在高山的顶上，种种地域都看得清楚。

```
བུ་ཡི་སྡུག་བསྔལ་མ་ཡིས་མཐོང་མི་བཟོད། །
རལ་གྲི་ངར་མས་དངོས་པོ་མ་ལུས་གཅོད། །
སྨྱོན་པར་གྱུར་ཀྱང་དུག་ལ་རེག་མི་བྱེད། །
བུ་ཆུང་ཡིན་ཡང་གཙུག་གི་ནོར་མི་འབྲལ། །
```

母亲不忍看见孩子的痛苦；锋利的剑斩断一切事物；即使变疯了，也不去碰毒；即使是小孩子，也不离开顶上的宝珠。

【按】这一段的比喻，大多是说认识心性之后的解脱，也间杂着几个迷乱之喻：

- "黑洞举灯"：一旦认识心性，无始的无明当下消除；
- "斩断一根绳，百结都解开"：认识了心性这一根本，一切束缚同时解脱；
- "被火烧过的绳子不能捆缚"：烦恼的形相虽然还在，已经失去了束缚的力量，这是大手印传统中常用的比喻；
- "点金药把铜铁变成金""孔雀吃毒而羽毛丰茂"：以口诀把烦恼转为道用；
- "有眼的人随意而行"：有了正见，行持就自在；
- "大鹏雏鸟羽翼长满"：见修圆满就能自在翱翔；
- "良驹的锁链打开就解脱"："ཅང་ཤེས"（cang shes）一般指良马、骏马，也有"聪慧者"的意思，这里依良驹理解，存疑；
- "不见虚空，就是见到虚空"：心性不可作为对象来见，不见任何对象，才是真见，这是大手印的要义；
- "灯熄灭了，身与影都没有了"：能取与所取一同消失；
- "把水放进水中，就成为无别"：心与心性、觉受与空性融为一味；
- "从船上飞出的鸟又会回来"：这是萨惹哈道歌中著名的比喻，念头无论飞到哪里，都离不开心性，最后自然回归；
- "舍冰寻水""执种子与果实为相异"：离开烦恼去另找心性，或执道与果为二，都是迷乱；
- "蛇结自解"：用马尾在蛇身上打的结，蛇自己就能解开，比喻念头自生自解，不须另加对治；
- "金翅鸟翱翔""高山之顶"：证悟者无畏，而且遍知一切；
- "母亲不忍孩子痛苦"：证悟之后自然生起大悲；
- "锋利的剑斩断一切事物"：智慧斩断一切执著；
- "疯了也不碰毒""小孩也不离顶上宝珠"：即使行持如疯人、如小孩般无拘，也不失去正见与守护。

"找到了埋伏的敌人"（dgra skugs btsal bas），"skugs"意思不很确定，这里依"埋伏、隐藏"理解，可能是比喻：念头被认出就不再可怕，存疑。"印章与印章的凸纹，是颠倒而现的"（rgya dang rgya yi 'bur ni log par 'byung），可能是说印章上的文字与印出来的文字左右相反，比喻迷与悟、轮回与涅槃本是一印的两面，存疑。"舍弃了五种想"（'du shes rnam lnga），可能指对五蕴（或五境）的执想，存疑。"由因缘与勤作所造的，不是自生的"，是说有为造作的境界不是本然的心性，与"俱生"相对。"穷人把别人的财物盖上［自己的］封印"（dbul po mi nor rgya yis 'debs pa），意思不很清楚，可能是比喻把本不属于自己的东西执为己有，存疑。"没有认出盗贼，就乱射好箭"，比喻不认识念头的本性，只是盲目对治，存疑。

"这就像蛇、明咒与兵器"，可能是总说下文：如蛇结自解（第 86 句）、如明咒能解毒（参看第 139 句）、如兵器能斩断（第 91 句），存疑。"在空中舞矛，事情做完，人就安乐"（mkha' la mdung bskor las zin skyes bu bde），可能是说向虚空挥矛，没有所击的对象，比喻对治念头而知其本无，事情就了结了，存疑。

## 六、修习的要点（第 94–117 句）

```
ཨཱཿཨོཾ་ཧཱུཾ།
ཨེ་མ་ཧོ། །
མེ་དོན་གཉེར་བས་དུ་བ་ཤུགས་ཀྱིས་འབྱུང་། །
ནོར་བུ་རྙེད་ན་སོ་ནམ་འབད་མི་དགོས། །
མི་གཅིག་སྐྱེས་པས་ཤིང་ལ་འདོད་ལྔ་འབྱུང་། །
སྐྱུར་པོ་ཟོས་ན་མཐོང་བས་ཉམས་སུ་མྱོང་། །
```

阿嗡吽，唉玛吙！求火的人，烟会自然先出现；得到宝珠，就不需要辛苦耕作；一人出生，树上就生出五种欲乐；吃过酸的东西，一看见就［口中］体会到［那滋味］。

```
སྔར་འདྲིས་མི་དང་ཕྲད་ན་ཐེ་ཚོམ་མེད། །
སྐྱེས་བུ་ནམ་མཁས་བཟུང་བ་ཐར་མི་སྲིད། །
རྨི་ལམ་སྒྱུ་མའི་མཚོན་གྱིས་གནོད་པ་མེད། །
དངུལ་རྡོ་འོ་མ་བུར་ཤིང་ཏིལ་མར་ལྟོས། །
ཆུ་ནི་མཐོང་དང་ཐོས་པས་སྐོམ་མི་སེལ། །
```

遇到先前熟识的人，就没有怀疑；被虚空所抓住的人，不可能逃脱；梦与幻中的兵器，不会造成伤害。看那银矿石、乳、甘蔗与芝麻油！水，单是看见与听到，并不能解渴。

```
སྨན་པའི་ངག་མི་ཉན་པའི་ནད་པ་དེ། །
ཟས་ནོར་བྱིན་པས་རང་ཉིད་བཀྲེས་ནས་ཤི། །
གཏེར་མཛོད་བགྲངས་པས་རང་གིས་ཐོབ་པ་མེད། །
འོན་པ་སིལ་སྙན་ལོང་བ་རི་མོ་མཁན། །
བྱིས་པ་མནའ་གཏམ་དམུས་ལོང་ཡུལ་ཁམས་སྟོན། །
```

那不听医生之言的病人；把食物与财物给了别人，自己却饿死；数别人的宝藏，自己什么也得不到；聋子［打］铙钹，盲人［作］画师；小孩发誓，盲人指示地方。

```
སྒོ་ང་མ་ཡིས་གབ་ན་བྱེའུ་ཕྲུག་སྨིན། །
རྡོ་ལ་བཞུ་བཏུལ་བྱས་ན་རིན་ཆེན་ནོར། །
སྦང་མ་མནན་ནས་བསིངས་པས་གར་ཆང་འབྱུང་། །
བུ་ཆུང་གསོས་པས་དཔའ་བོའི་ལས་རྣམས་ནུས། །
རྒྱལ་བུ་ཚར་ནས་ཡུལ་ཁམས་དབང་ཐོབ་སྟེ། །
```

鸟蛋若被母鸟覆盖，雏鸟就会成熟；把矿石熔炼锤打，就成为珍宝财物；把酒糟压紧再榨，就会流出酒来；把小孩养育长大，就能做勇士的事业；王子长成之后，就得到国土的权力。

```
མཁའ་ལ་སྤྲིན་དེངས་འཁྱགས་པ་ཆུར་ཐིམ་འགྱུར། །
མཁའ་ལྡིང་རྒྱལ་པོ་སྤྲོ་བསྡུ་མེད་པར་གནས། །
ཆུ་ནི་མ་རྙོགས་རང་དངས་ཉིད་དུ་ཞོག །
```

空中云散了，冰就融化为水；金翅鸟王，不展不收［翅膀］而安住；水不去搅浑，就让它自然澄清。

【按】这一段是修习的要点，也是正反交错：

- "求火的人，烟会先出现"：修习时会先出现种种觉受的征相，就像钻木求火先见到烟；
- "得到宝珠就不需耕作"：得到心性的口诀，就不需要其他辛苦的造作；
- "吃过酸的，一看见就体会到"：亲身体验过的觉受，一再生起就能认出，存疑；
- "遇到先前熟识的人，就没有怀疑"：这是大手印与大圆满传统中常说的"母子光明相会"之类的比喻，认识了心性之后再遇到它，就不再怀疑，存疑；
- "梦与幻中的兵器不会造成伤害"：知道念头如梦如幻，它就伤不了人；
- "银矿石、乳、甘蔗、芝麻"：银在矿石中，酥在乳中，糖在甘蔗中，油在芝麻中，比喻心性本具于身心之中，要经过修习才能提炼出来；
- "水，单是看见与听到并不能解渴""不听医生之言的病人""把饮食给了别人，自己却饿死""数别人的宝藏"：只听闻而不实修，毫无用处，这是佛经中常见的比喻；
- "聋子打铙钹，盲人作画师，小孩发誓，盲人指示地方"：没有亲证的人去教别人，都是不可靠的；
- "母鸟覆蛋""熔炼矿石""压榨酒糟""养育孩子""王子长成"：修习要经过一段时间的串习，证悟才会成熟；
- "云散冰融"：念头的执著消散，心就恢复本来的流动；
- "金翅鸟王不展不收而安住"：大鹏在高空中不用振翅而自然滑翔，比喻心不放逸也不收摄，自然安住，这是大手印"不作意"的修法；
- "水不搅浑，自然澄清"：心不加造作，念头自然平息，这是大手印中最著名的比喻之一。

"一人出生，树上就生出五种欲乐"（mi gcig skyes pas shing la 'dod lnga 'byung），意思不很清楚，可能与如意树的传说有关——有福德的人出生，如意树就出生种种受用，存疑。"被虚空所抓住的人，不可能逃脱"，可能是说一旦被心性（虚空）所"抓住"，就不会再退转，存疑。

## 七、修中的调整（第 118–153 句）

```
ཇི་ལྟར་མཁས་པས་བ་ལང་སྐྱོང་བ་བཞིན། །
བརྟན་གསལ་རྣོ་བ་མར་མེའི་སྙིང་པོ་ལྟོས། །
སྒྱུ་མའི་སྐྱེས་བུ་ཆགས་ཞེན་རྩིས་གདབ་མེད། །
བྱ་ནི་ནམ་མཁར་རྟེན་མེད་གནས་པར་བྱེད། །
```

就像善巧的人放牛一样；看那灯的心要：稳固、明亮、锐利！对幻化之人，不起贪著与计较；鸟在虚空中，无所依而住。

```
ཚོས་མ་རྣམས་ཀྱིས་རས་གོས་དག་པར་བཀྲུ། །
མཁར་སྤེ་རྩིག་ན་འགྲམ་གཞི་ལེགས་པར་ཐིང་། །
མ་ཡི་སྡུག་བསྔལ་བུ་ཡིས་མཐོང་བར་གྱིས། །
ཡིད་བཞིན་ནོར་བུ་སྤྱི་བོའི་གཙུག་ཏུ་བཞག །
ནམ་མཁའ་ལྟ་ན་འཇའ་ཚོན་ལུས་སུ་བསྒྱུར། །
```

染匠们把棉布洗干净；筑城墙，要把墙基打好；要让孩子看见母亲的痛苦；把如意宝放在头顶上；观看虚空时，就把身体转化为彩虹。

```
དམུ་རྒོད་རྟ་ནི་ཐབས་ཀྱིས་ཟུང་ལ་འཚོས། །
རི་གཟར་འབབ་ཆུ་ཡང་ཡང་བརྡབས་ན་དྲུངས། །
སྤྲེའུ་ཟིན་ན་ཀུན་ལ་ཡང་རྩལ་སྦྱང་། །
བསགས་པའི་ཡོ་བྱད་ཆགས་མེད་ཀུན་ལ་སྦྱིན། །
```

野马要以方法捉住来喂养；山崖上的流水，一再拍击就会澄清；抓住了猴子，对一切［技艺］再加以训练；积聚的资具，要无贪地布施给一切人。

```
བྱིང་ཞིང་རྨུགས་ན་འདབ་ཆགས་མཁའ་ལ་སྤུར། །
ཡང་ན་བུམ་པ་ཁ་སྦྱོར་རླུང་གིས་ཁོང་། །
རྒོད་ན་ཁོང་སྟོང་རྐུན་མ་སྤྲིན་ལ་ལྟོས། །
རྒྱ་མཚོའི་དབའ་རླབས་ཆུ་ཟླར་ཤེས་པར་བྱ། །
རྐུན་མ་མཐོང་ཞིང་ཚོར་ན་ལྡོག་པར་ངེས། །
```

若昏沉、昏昧，就［观想］鸟飞向空中；或者以宝瓶合口之风充满［身］内。若掉举，就观［身］内空虚，观［念头这］盗贼［如］云。要了知大海的波浪［就是水］，［如］水中之月。认出了盗贼，察觉了，［它］一定会退去。

```
རྩ་བ་སྨན་ན་ཐམས་ཅད་སྨན་ཞེས་བྱ། །
ནོར་བུ་རིན་ཆེན་ས་ཡི་གཏེར་དུ་སྦ། །
ཡང་ན་རི་དྭགས་གར་སོང་དེང་ལ་གསོད། །
ལྟོགས་ན་དུག་ལ་སྔགས་ཀྱིས་བཏབ་ལ་བཟའ། །
སྙོམས་ལས་བྱིས་པའི་ཉམ་ང་གཡང་ས་ལྟོས། །
```

根若是药，一切都称为药；把珍宝藏在地下的宝藏中；或者，野兽到哪里，当下就在那里杀死它；饥饿时，以咒加持了毒再吃；看那懒惰小孩［面临］的可怖悬崖！

```
སྙིང་ལ་གཅེས་པ་དུར་ཁྲོད་གནས་སུ་སྐྱོལ། །
ན་ཚ་བྱུང་ན་རྐྱལ་པ་སྟོང་པར་གྱིས། །
དེ་ལ་བུ་ག་ཐོད་ལ་མེས་ཚིག་མེ་ལ་གདུངས། །
སྨན་མ་ཞུ་ན་སླར་ཡང་ནད་དུ་འགྱུར། །
རྩ་དང་གསེར་གཉིས་འཆིང་བྱེད་ཁྱད་པར་མེད། །
```

把心中所珍爱的，送到尸陀林去；若发了热病，就把皮囊掏空；对那［病］，在孔窍与头骨上用火烧灼，以火熏热；药若不消化，又会变成病；草绳与金［链］两者，在束缚上没有差别。

```
ཤེས་པ་འཐུམས་ན་ཡུལ་ཁམས་སྐོར་ཞིང་བལྟ། །
རྐང་འགྲོས་བུལ་ན་འོག་རྟ་རོལ་ལ་སྤོས། །
དཔའ་རྩལ་ཞེན་ན་དཔའ་རྩལ་ཀུན་ལ་སྦྱང་། །
མེ་དོན་གཉེར་བས་གཙུབ་ཤིང་དྲག་ཏུ་གཙུབས། །
```

心识郁闷时，就周游各地去观看；步伐若迟缓，就换乘坐骑；若贪著勇武的技能，就对一切勇武的技能都加以修练；求火的人，要猛力钻燧木。

```
རི་བོ་མི་བསྐྱོད་ཆུ་བོ་རྒྱུན་ཆད་མེད། །
གསེར་གླིང་ཕྱིན་ནས་ས་རྡོ་བཙལ་མི་རྙེད། །
ཤིང་བྲལ་འདབ་མ་ཤིན་དུ་ཡང་ལ་སོགས། །
ཡིད་བཞིན་ནོར་བུ་ཡོད་ན་དགོས་འདོད་འབྱུང་། །
```

山不动摇，河流不断；到了金洲，寻找土石也找不到；离开树［枝］的叶子极轻……等等；有了如意宝，所需所欲就会出生。

【按】这一段说修习中的种种调整与防护：

- "像善巧的人放牛"：牧人不紧拉着牛，也不让它走失，只是远远看着，比喻心要松紧适度，保持正念而不强制；
- "灯的心要：稳固、明亮、锐利"：心的安住要有这三种品质，存疑；
- "鸟在虚空中无所依而住"：心不依任何所缘而安住；
- "染匠洗布""筑墙打基"：先要净除障碍、打好基础（如加行）；
- "让孩子看见母亲的痛苦"：观一切众生如母而受苦，以生起悲心，存疑；
- "把如意宝放在头顶上"：观上师在头顶，即上师相应法；
- "观看虚空时，把身体转化为彩虹"：观身如虹，无实，存疑；
- "野马以方法捉住喂养""抓住猴子再加训练"：心如野马、如猴子，要以方便调伏；
- "若昏沉，就观鸟飞向空中"：心沉没时，要提起；"宝瓶合口之风"（bum pa kha sbyor），即"宝瓶气"，是风息修法，须依具德上师亲自指导才能修习，不可照字面自行修练；
- "若掉举，就观内空"：心散乱时，要放松向内；
- "认出了盗贼，它一定退去"：念头一被认出，就自然消散，这是大手印"认出即解脱"的要点；
- "根若是药，一切都是药"：认识了心性这一根本，一切显现都成为道；
- "把珍宝藏在地下"：证悟要隐秘守护，不可炫耀；
- "野兽到哪里，当下就在那里杀死它"：念头生起在哪里，当下就在那里断除（认出它的本性），是象征的语言，不是字面上的杀生；
- "以咒加持了毒再吃"：以口诀把烦恼转为道用；
- "把心中所珍爱的送到尸陀林"：断除最深的贪执，存疑；
- "药若不消化，又会变成病"：对治法若执著不放，反而成为新的障碍；
- "草绳与金链，在束缚上没有差别"：执著恶念与执著善念、觉受，同样是束缚；
- "心识郁闷时，周游各地""步伐迟缓，就换坐骑"：修习中心若沉闷，要以方便调整，不可死守一法；
- "猛力钻燧木"：修习要精进不断，如钻木取火不可中途停止；
- "山不动摇，河流不断"：心安住不动如山，正念相续如河；
- "到了金洲，找不到土石"：证悟之后，一切显现都是心性，找不到心性以外的任何东西。

"山崖上的流水，一再拍击就会澄清"（ri gzar 'bab chu yang yang brdabs na drungs），"drungs"可能是"dwangs"（澄清）之误，存疑。"若掉举，就观［身］内空虚，观［念头这］盗贼［如］云"（rgod na khong stong rkun ma sprin la ltos），原文很简略，补字是译者的理解，存疑。"要了知大海的波浪［就是水］，［如］水中之月"（rgya mtsho'i dba' rlabs chu zlar shes par bya），"chu zlar"可读作"水中月"，也可读作"水与月"，存疑。"看那懒惰小孩［面临］的可怖悬崖"（snyoms las byis pa'i nyam nga g.yang sa ltos），可能是警策懈怠：懒惰的人就像在悬崖边玩耍的小孩，存疑。"若发了热病，就把皮囊掏空""在孔窍与头骨上用火烧灼"（第 142–143 句），可能是古代印度或藏地治疗热病的方法，用来比喻修习中的某种调整，具体所指不明，存疑。"离开树［枝］的叶子极轻……等等"（shing bral 'dab ma shin du yang la sogs），意思不很清楚，可能是比喻离开执著的心轻安自在，存疑。

## 八、行持（第 154–181 句）

```
ཨཱཿཨོཾ་ཧཱུཾ།
ཨེ་མ་ཧོ། །
བྱ་འཕུར་ནམ་མཁའ་དག་ལས་མི་འདའ་སྟེ། །
སྣ་ཚོགས་ནོར་བུ་ཚོན་གྱི་ཁ་དོག་སྣང་། །
གསེར་དང་གསེར་གྱི་རྒྱན་ལ་འགྱུར་བ་མེད། །
འདམ་སྐྱེས་པདྨ་འདམ་གྱིས་མི་གོས་སོ། །
```

阿嗡吽，唉玛吙！鸟虽然飞翔，却不离开虚空；种种宝珠，显现出彩色；黄金与黄金的饰物，［在金的本质上］没有改变；泥中所生的莲花，不被泥所染。

```
གང་དག་འཇིགས་སར་སྐྱེལ་མ་སངས་ནས་འགྲོ། །
རྒྱལ་པོ་གང་ཞིག་རྒྱལ་སྲིད་བོར་ནས་འཁྱམ། །
སུམ་ཅུ་རྩ་གསུམ་ཐོས་པ་ནེ་ཚོའི་ཆོས། །
ཆུ་ལ་མར་ཁུ་བླུགས་པས་འདྲེས་པ་མིན། །
```

那些在可怖之处有护送者的人，［恐惧］消除而前行；有某位国王舍弃了王位而流浪；听闻了"三十三"，［只是］鹦鹉之法；把酥油倒进水里，并不相混。

```
བྱ་རྒོད་རྙིས་ཟིན་གླང་ཆེན་འདམ་དུ་བྱིང་། །
ནོར་བུ་རིན་ཆེན་ལུང་ཁུང་དག་ཏུ་བོར། །
རྒྱལ་བློན་འཛོམ་ན་རྒྱལ་སྲིད་མངའ་ཐང་འཕེལ། །
མིག་དང་རྐང་པར་ལྡན་པས་དོན་སར་ཕྱིན། །
དཔའ་བོའི་གོ་མཚོན་བློན་པོ་བཀའ་རྟགས་ཁྱེར། །
```

鹫被网所捉，大象陷入泥中；把珍宝丢在山谷洞穴中。君臣和合，国家的威势就增长；具足眼与足，就能到达目的地；勇士［有］铠甲与兵器，大臣带着［国王的］印信。

```
རྩིས་མེད་སྨྱོན་པ་ཞེན་མེད་བུ་ཆུང་དང་། །
རྟོག་མེད་ཕྲག་དང་གླང་ཆེན་ཆུར་འཇུག་ལྟོས། །
ཕྲག་རྒོད་རྣམས་ནི་དུག་སྦྲུལ་མི་གཏོང་ཟ། །
དབུལ་པོ་རིན་ཆེན་རྒྱལ་པོའི་མཁར་དུ་སྦ། །
གསོ་སྦྱོང་སྤྱད་རྣམས་རིག་པ་མདའ་ཡིས་བསྣུན། །
```

看那无所计较的疯人、无所贪著的小孩、无分别的"扎"（phrag），以及大象入水！凶猛的"扎"们，吞食毒蛇而不放；穷人把珍宝藏在王城里；修持布萨的人们，以觉性之箭射击。

```
ཡུལ་ཁམས་ཀུན་གྱི་དགྲ་རྣམས་སྲིད་དུ་གཅད། །
དཔའ་བོ་གང་ཡིན་དེ་ཡིས་དགྲ་རྣམས་འདུལ། །
མཁའ་ལྡིང་རྒྱལ་པོ་ཕྱེ་ལེབ་སྤྱོད་ཡུལ་མིན། །
རིགས་ངན་རྒྱལ་པོ་ཝ་ཡིས་སེང་ལྤགས་གྱོན། །
ནགས་ལ་མེ་མཆེད་གདོང་དུ་གར་བབ་སྲེག །
```

一切地区的敌人，都要在［它们］还存在时斩断；谁是勇士，他就能调伏敌人；金翅鸟王，不是飞蛾的行境；下劣种姓的国王，［如］狐狸披上狮子的皮；森林中火势蔓延，所到之处都焚烧。

```
མེ་འབར་བ་ལ་རླུང་གིས་བསྐྱོད་ན་འབར། །
རིན་ཆེན་སྣོད་སྦྱར་མི་གཙང་ཕྱིས་པ་སངས། །
སྨྱོན་པ་བུ་ཆུང་ཁྱི་ཕག་སེང་གེ་བཞིན། །
```

燃烧的火被风吹动，就更加炽燃；珍宝的器皿被不净所污，擦拭就干净了；［行持］如疯人、小孩、狗、猪与狮子。

【按】这一段说证悟者的行持：

- "鸟虽飞翔，却不离开虚空"：一切行持都不离开心性；
- "种种宝珠显现彩色""黄金与金饰"：显现虽然种种不同，本质不变；
- "泥中莲花不被泥染"：处于世间而不被烦恼所染；
- "有护送者，恐惧消除"：依上师的护持，行于险处而无畏；
- "国王舍弃王位而流浪"：如帝洛巴、那洛巴等成就者舍弃世间的地位，行于无住；
- "酥油倒进水里不相混"：证悟者处于凡俗中而不与凡俗相混；
- "鹫被网所捉，大象陷入泥中""把珍宝丢在山谷洞穴中"：反面的警告，行持若失去正见，就会被贪执所困，丢失证悟；
- "君臣和合""具足眼与足""勇士的铠甲兵器、大臣的印信"：见地（眼）与行持（足）、智慧与方便要相辅相成；
- "无所计较的疯人、无所贪著的小孩"：成就者的行持无造作、无贪著；
- "大象入水"：大象入水，悠然自在，比喻证悟者入于诸境而无碍，存疑；
- "穷人把珍宝藏在王城里"：把证悟安放在最安全之处，即守护于心性之中，存疑；
- "勇士调伏敌人""森林中火势蔓延""火被风吹更炽"：证悟的智慧焚烧一切烦恼，遇到的境越多，智慧之火越旺；
- "珍宝器皿被污，擦拭就干净"：心性本净，染污只是客尘；
- "金翅鸟王不是飞蛾的行境""狐狸披狮皮"：证悟者的境界不是凡夫所能测度；而没有证悟的人模仿成就者的行持，就像狐狸披上狮皮，终究会露出原形；
- "疯人、小孩、狗、猪与狮子"：成就者的"禁行"，无取舍（如疯人、小孩）、无净秽分别（如狗、猪）、无畏（如狮子），这与《空行耳传·断苦口诀》第八口诀中"孔雀、狗、猪与疯人"的说法相应。

这些行持都是以证悟为前提的成就者行持，须依具德上师的口授来理解，不可照字面模仿。

"听闻了'三十三'，［只是］鹦鹉之法"（sum cu rtsa gsum thos pa ne tso'i chos），意思不很清楚，"三十三"可能指三十三天，或某种口诀的数目；整句可能是说只会复述听来的法而无体验，就像鹦鹉学舌，存疑。"扎"（phrag），藏文原词意思不明，从"吞食毒蛇而不放"来看，可能是某种能食蛇的动物（如獴），存疑。"修持布萨的人们，以觉性之箭射击"（gso sbyong spyad rnams rig pa mda' yis bsnun），可能是说守持戒律的人以觉性之箭射中要害，存疑。"一切地区的敌人，都要在［它们］还存在时斩断"（yul khams kun gyi dgra rnams srid du gcad），"srid du"也可以理解为"在［轮回之］有中"，存疑。

## 九、上师的功德与修行的得失（第 182–208 句）

```
ཨཱཿཨོཾ་ཧཱུཾ།
ཨེ་མ་ཧོ། །
ཆུ་རྣམས་ཐམས་ཅད་རྒྱ་མཚོ་ཆེན་པོར་གཅིག །
གང་ཞིག་ལྟོགས་པའི་དུས་སུ་ཟས་སྟེར་བ། །
ནད་རྣམས་གསོ་བ་སྨན་པའི་རྒྱལ་པོ་སྟེ། །
ཆུ་བོ་ཆེན་པོ་སྒྲོལ་བའི་མཉེན་པ་མཆོག །
གནོད་པའི་དགྲ་རྣམས་འདུལ་བའི་དཔའ་བོ་སྟེ། །
དགེ་བཤེས་རྒྱལ་པོ་ཕྱོགས་མེད་ཀུན་ལ་སྙོམས། །
```

阿嗡吽，唉玛吙！一切河水在大海中都成为一味。在饥饿时布施食物的［人］，是医治诸病的医王，是渡过大河的最上船夫，是调伏伤害之敌的勇士——善知识之王，没有偏私，对一切平等。

```
མཁས་པ་དག་གིས་འཇའ་ཚོན་བལྟ་བར་བྱ། །
གནད་དུ་བསྣུན་པའི་ཚོར་བ་སྤངས་པ་མེད། །
བུང་བ་མེ་ཏོག་དག་ལ་ཆགས་ཞེན་བྲལ། །
ཉ་ནི་རྟག་ཏུ་ཆུ་ལས་ཡོང་མི་འདའ། །
རྩི་སྨན་ཡོད་ཀྱང་དུག་ལ་རེག་མི་བྱེད། །
ཇི་ལྟར་ཕྱུག་པོ་སོ་ནམ་བྱེད་པ་ལྟོས། །
སེང་གེའི་འོ་མ་ལྐུགས་པའི་ཁ་བཞིན་བསྡམ། །
```

智者应当观看彩虹；被击中要害的感受，并没有舍弃；蜜蜂对诸花没有贪著；鱼恒常不离开水；虽然有药，也不去碰毒；看那富人怎样耕作！要像狮子之乳、像哑巴的口那样，严加守护。

```
སྨྱོན་པས་རང་གི་སྙིང་ལ་མཚོན་བསྣུན་དང་། །
གཤེད་མས་ཟིན་པའི་ཆད་པས་བཅད་པའི་མི། །
ས་བོན་རུལ་པ་མྱུ་གུ་ཡོང་མི་སྐྱེ། །
ཚེ་ལོ་སུམ་ཅུ་ཉི་ཤུ་བཅུ་པ་བཞིན། །
```

疯人用兵器刺自己的心，以及被刽子手捉住、被判刑处斩的人；腐烂的种子，绝不会生出苗芽；就像寿命三十、二十、十岁［那样递减］。

```
གང་ཞིག་ཡེ་ཤེས་ཉི་མ་ཤར་ནས་ནུབ། །
དབུལ་པོས་ནོར་བུ་རིན་ཆེན་རྙེད་ནས་བོར། །
གང་དག་ཅང་ཤེས་རྟ་ལ་ཞོན་ནས་འབབ། །
ཇི་ལྟར་དབུལ་པོའི་ནོར་བུ་རྒྱལ་པོས་ཕྲོགས། །
```

有人智慧的太阳升起之后又落下；穷人得到了珍宝之后又丢弃；那些骑上了良马之后又下来的人；就像穷人的宝珠被国王夺走。

```
ཡིད་བཞིན་ནོར་བུ་མཆོད་ན་དགོས་འདོད་འབྱུང་། །
དངུལ་དཀར་མེ་ལོང་ཡང་ཡང་ཕྱིས་ན་གསལ། །
བརྒྱ་བྱིན་ལྷ་ཡི་ལོངས་སྤྱོད་འབད་པ་མེད། །
མེ་ཏོག་པདྨ་བུང་བའི་ཚོགས་རྣམས་འདུ། །
```

供养如意宝，所需所欲就会出生；白银的镜子一再擦拭，就会明亮；帝释天人的受用，不需勤作；莲花的花朵上，群蜂都来聚集。

【按】第 184–189 句，是赞叹上师（善知识）的功德：如大海容纳一切河水，如布施饥者的施主，如医王、如船夫、如勇士，对一切众生平等无偏。

第 190–196 句，说修行人的守护："观看彩虹"，了知显现无实；"蜜蜂对诸花没有贪著"，受用诸境而不贪；"鱼不离水"，不离开心性；"有药也不碰毒"，即使有对治的能力，也不故意放逸；"富人仍然耕作"，即使已有证悟，仍要精进；"像狮子之乳、像哑巴的口"，要严守秘密。"被击中要害的感受，并没有舍弃"（gnad du bsnun pa'i tshor ba spangs pa med），可能是说被口诀击中要害而生起的觉受，不要舍弃，要一直保持，存疑。

第 197–204 句，多是反面的警告：如疯人自伤、如死刑犯、如腐烂的种子不能发芽，比喻违背口诀或失去信心的人，断绝了证悟的可能；"智慧的太阳升起又落下""穷人得宝又丢弃""骑上良马又下来""穷人的宝珠被国王夺走"，比喻得到了证悟或口诀，却因放逸、散乱或违缘而失去。"就像寿命三十、二十、十岁［那样递减］"（tshe lo sum cu nyi shu bcu pa bzhin），意思不很清楚，可能是比喻修行若退失，功德就像寿命一样渐渐减少，也可能是说人寿无常，存疑。

第 205–208 句，又转为正面：恭敬供养上师（如意宝），一切所需自然具足；心性之镜一再擦拭（修习），就会明亮；证悟的受用任运而有，不需勤作；如莲花开放，群蜂自然聚集，比喻证悟者自然利益众生。

## 十、果（第 209–228 句）

```
ཨཱཿཨོཾ་ཧཱུཾ།
ཨེ་མ་ཧོ། །
པོ་ཏ་ལ་ལ་ནམ་ལངས་ཉི་ཤར་མཉམ། །
འཇིམ་པའི་ལོགས་ལ་བཏབ་པའི་བདེ་གཤེགས་སྐུ། །
མྱུ་གུ་མེ་ཏོག་འབྲས་བུ་རིམ་གྱིས་སྨིན། །
དབང་པོ་སྐྱོན་དང་བྲལ་ན་གཟུགས་རྣམས་མཐོང་། །
```

阿嗡吽，唉玛吙！在普陀洛迦，天亮与日出同时；印在泥上的善逝身像；苗芽、花朵、果实，依次成熟；诸根离开了过患，就看见诸色。

```
ཤེལ་གོང་དྲི་མ་མེད་པའི་ཕྱི་ནང་གསལ། །
སྒྱུ་མ་མཁན་གྱིས་མཁས་པ་སྣ་ཚོགས་སྟོན། །
རྡོ་རྗེ་ཕ་ལམ་གང་གིས་གཞོམ་པར་མིན། །
ཡིད་བཞིན་ནོར་བུས་མི་མཐུན་གནོད་པ་སེལ། །
```

无垢的水晶块，内外明澈；幻师显现出种种巧妙；金刚石不被任何东西摧毁；如意宝消除不顺与伤害。

```
སེང་གེ་མངལ་རྒྱ་ཁྱུང་ཕྲུག་གོང་རྒྱ་བྲལ། །
མཁའ་ལ་ཉི་ཤར་འོད་ཟེར་ཕྱོགས་བཅུར་ཁྱབ། །
སྲིན་བུ་བུང་བ་གནས་གྱུར་མཁའ་ལ་འཕྱོ། །
ཡིད་བཞིན་ནོར་བུ་རྟོག་མེད་དགོས་འདོད་འབྱུང་། །
```

狮子离开胎藏之封，大鹏的雏鸟离开卵壳之封；空中太阳升起，光芒遍满十方；虫子转变为蜜蜂，在空中飞翔；如意宝无分别而出生所需所欲。

```
རང་གིས་གྲིབ་མ་མཐོང་བས་འབྲོས་པ་དང་། །
རི་དྭགས་སྨིག་རྒྱུ་རྙེག་པ་ནོར་བ་སྟེ། །
དགྲ་ལ་ཟིན་དུ་མཐོང་ན་ངེས་པར་གསོད། །
འཁྱག་པའི་རང་བཞིན་ཆུ་རུ་ཤེས་པར་བྱོས། །
ཉི་ཟླའི་ངོས་ལ་འཆར་ནུབ་གསལ་འགྲིབ་མེད། །
རིན་ཆེན་བྱི་དོར་བྱས་ན་དགོས་འདོད་འབྱུང་། །
```

见到自己的影子就逃跑，以及野兽追逐阳焰，都是错误；见到敌人被擒，就一定杀掉；要了知冰的本性就是水！在日月的表面上，没有升落，也没有明暗增减；珍宝经过擦拭，就会出生所需所欲。

【按】这一段说证悟的果：

- "印在泥上的善逝身像"：如同以模子在泥上印出佛像（即"擦擦"），比喻佛身本具于心性中，一经修习就显现，存疑；
- "苗、花、果实依次成熟"：证悟依次第圆满；
- "诸根离过患就看见诸色""无垢水晶内外明澈"：障碍清除之后，心性的光明内外通彻；
- "幻师显现种种巧妙"：证悟者的化身如幻，随缘利益众生；
- "金刚石不被摧毁"：法身不坏；
- "如意宝消除不顺""无分别而出生所需所欲"：佛的事业任运成就，没有分别而能满足众生的愿求；
- "狮子离开胎藏、大鹏雏鸟离开卵壳"：传说狮子出胎就能跳跃，大鹏出卵就能飞翔，比喻证悟者一离开身体的束缚（或一旦破除最后的障碍），功德就当下圆满显现，这是大手印与大圆满传统中常见的比喻；
- "太阳升起光芒遍满十方"：智慧遍照一切；
- "虫子转变为蜜蜂"：凡夫转变为圣者，存疑；
- "冰的本性就是水"：烦恼的本性就是智慧；
- "日月的表面没有升落与明暗增减"：心性的光明本身没有生灭增减，升落只是从地上看的显现。

"在普陀洛迦，天亮与日出同时"（po ta la la nam langs nyi shar mnyam），"普陀洛迦"是观世音菩萨的住处，意思不很清楚，可能是比喻证悟的时候，无明之夜结束与智慧之日升起同时，没有间隔，存疑。"见到自己的影子就逃跑""野兽追逐阳焰"，是重提迷乱之喻，与下文的"冰即是水"对照。"见到敌人被擒，就一定杀掉"（dgra la zin du mthong na nges par gsod），可能是说念头一被认出（擒住），就一定当下解脱（杀掉），是象征的语言，存疑。

## 十一、总结：基、道、果与三解脱门（第 229–241 句）

```
ཨེ་མ་ཧོ། །
དེ་ལྟར་བསྟན་པའི་དོན་དེ་ཐམས་ཅད་ཀྱང་། །
རང་བཞིན་ལས་དང་འབྲས་བུ་གསུམ་དུ་གནས། །
གཞི་ལ་ཆོས་སྐུ་ལྷུན་གྱིས་གྲུབ་པ་ན། །
དེ་ཕྱིར་སྐུ་གསུམ་ལྷུན་གྱིས་གྲུབ་པར་གནས། །
```

唉玛吙！这样所显示的一切义理，都安住于自性、业与果三者之中。在基上，法身任运成就，因此三身任运成就而安住。

```
རང་བཞིན་སྟོང་པ་རྣམ་པར་ཐར་པའི་སྒོ། །
ལམ་ནི་མཚན་མེད་རྣམ་པར་ཐར་པའི་སྒོ། །
འབྲས་བུ་སྨོན་མེད་རྣམ་པར་ཐར་པའི་སྒོ། །
སྒོ་གསུམ་ཕྱེད་པས་སྐུ་གསུམ་ཞལ་མཐོང་འགྱུར། །
```

自性是空——解脱门；道是无相——解脱门；果是无愿——解脱门。打开三门，就得见三身之面。

```
འོན་ཀྱང་ཐམས་ཅད་རྫུན་པའི་རང་བཞིན་ལ། །
དོན་ལ་ཆེད་དུ་བྱ་བ་ཅི་ཡང་མེད། །
ཤིན་ཏུ་གསང་བ་རྡོ་རྗེའི་ཚིག་འདི་དག །
ཁྱོད་ཀྱིས་ཡེ་ཤེས་རིག་པས་རྟོགས་པར་གྱིས། །
```

然而，在一切都是虚妄的自性上，于实义中，没有任何要刻意去做的。这些极其秘密的金刚语，你要以智慧觉性来了悟！

【按】这一段是全篇的总结：上面所说的种种比喻，可以归纳为"自性（基）、业（道）、果"三者，与下文的"基""道""果"相应。

"在基上，法身任运成就，因此三身任运成就而安住"：心性本来就是法身，而法、报、化三身都本具于其中，不是修出来的。

"三解脱门"——空、无相、无愿，是般若经中所说的；本篇把它们配在基、道、果上：基的自性是空，道上不执任何相，果上不希求任何果。"打开三门，就得见三身之面"，是说通达三解脱门，就现见本具的三身。

"然而，在一切都是虚妄的自性上，于实义中，没有任何要刻意去做的"：上面所说的一切修法、一切次第，都是在虚妄的显现上安立的方便；在实义中，没有任何可修、可做的。这正是大手印"无作""不作意"的究竟意趣。

"你要以智慧觉性来了悟"中的"你"，与开头的"无二金刚，请这样谛听"相呼应。

## 十二、跋（第 242–244 句）

```
དཔལ་ཤ་བ་རི་དབང་ཕྱུག་དང་།
མཁའ་འགྲོ་མ་ཡེ་ཤེས་ཀྱི་སྤྱན་མ་དང་།
པདྨའི་སྤྱན་གྱི་ཞལ་སྔ་ནས་སྙིང་པོའི་དོན་མགུར་དུ་བཞེངས་པ་ཕྱག་རྒྱ་ཆེན་པོ་རྡོ་རྗེའི་གླུ་བརྡ་བརྒྱུད་གསང་བའི་སྒྲོན་མ་རྫོགས་སོ།།
```

由吉祥夏瓦日自在、空行母智慧眼母与莲花眼的尊前，将心要之义作成道歌的《大手印金刚歌·表征传承秘密之灯》，圆满。

【按】"智慧眼母"（ye shes kyi spyan ma）与"莲花眼"（pad+ma'i spyan），都是意译，无法确定其梵文原名与身份。"莲花眼"可能是某位上师的名字，也可能是对某位空行母或本尊的称号，存疑。"尊前"（zhal snga nas），是藏文对上师的尊称，这里的意思可能是这首道歌是由这三位共同唱出的，也可能是说由他们传出、后人作成道歌，存疑。

"表征传承秘密之灯"（brda brgyud gsang ba'i sgron ma），是本篇的副题，说明本篇属于以表征传授的"表示传承"，与《大手印表示传承》（D2439）等可以互相参看。

本篇没有译者跋语。从用语来看（如"本然手印""不搅自澄"等），本篇与藏地噶举派的道歌风格非常接近，它是否从梵文译出，还是在藏地依印度传承编成，尚待考订。
