# 俱生之歌

瑜伽自在寂天造　上师迪日室利迦那、玛班·却巴译　据藏文译出

## 题解

本篇梵名 Sahajagīti，藏名 lhan cig skyes pa'i glu，即《俱生之歌》，收于德格版丹珠尔续部释 ཟི 函第 1b 至 2a 页（东北目录 D2341），是 ཟི 函的第一篇。跋语说是"瑜伽自在寂天（Śāntideva）所造"，由上师迪日室利迦那（Dhīriśrījñāna）与译师玛班·却巴（rma ban chos 'bar）译出。玛班·却巴也是已译的《摄要开示》（D2298）的译者。

这里的寂天，称为"瑜伽自在"，一般认为不是《入菩萨行论》的作者，而是八十四成就者中的布苏固（Bhusuku），即以寂天为名的大成就者；已译的《行歌藏释》（D2293）中也收有布苏固的行歌。不过两者在藏地传统中常被视为同一人，这里不作断定。

全篇很短，是一首带叠句的道歌：四段，每段先以两句开示，再接两句叠句"无与伦比的花一旦生起，便胜过十方；去取那无价的花吧！"全篇以一朵花比喻俱生智：它从空性的森林中开放，一朵而有种种颜色，无根无枝；取得它的花蕊，就是幻化之师；最后说到观察胜喜与离喜，并以供养上师作结。

关于密乘内容的告诫：第三、四段的"花蕊""胜喜""离喜"，属于无上瑜伽续圆满次第的象征语言与四喜之说，只能在具德上师座前，依具足的灌顶与口授领受，不可依文字自行揣测或效仿。

体例：藏文原文全部保留在代码框中，每段后附汉译；叠句在第一段完整列出，其后各段照原文重复。凡标"存疑"的按语，表示本译对原文意思没有把握。藏文依 Esukhia 德格丹珠尔电子版。

## 题名与礼敬

```
རྒྱ་གར་སྐད་དུ། ས་ཧཱ་ཛ་གཱི་ཏི།
བོད་སྐད་དུ། ལྷན་ཅིག་སྐྱེས་པའི་གླུ།
བླ་མ་དམ་པ་ལ་ཕྱག་འཚལ་ལོ། །
```

梵语：萨哈札·吉提。藏语：《俱生之歌》。

敬礼殊胜上师！

## 一、空性林中，一花多色

```
སྟོང་པའི་ནགས་ལས་མེ་ཏོག་རབ་རྒྱས་པ། །
མེ་ཏོག་གཅིག་ལ་ཁ་དོག་སྣ་ཚོགས་ཏེ། །
དཔེ་མེད་མེ་ཏོག་སྐྱེས་ན་ཕྱོགས་ལས་རྒྱལ། །
རིན་ཐང་མེད་པའི་མེ་ཏོག་ལོངས་ཤིག་དང་། །
```

从空性的森林中，花朵盛开；一朵花上，有种种的颜色。无与伦比的花一旦生起，便胜过十方；去取那无价的花吧！

【按】"空性的森林"与"一朵花有种种颜色"，是全篇的主喻：花象征心性（俱生智），它从空性中开放，一体而显现种种，即空性与显现不二。

## 二、无根无枝，看那金黄之花

```
དེ་ལ་རྩ་བ་མེད་ཅིང་ཡལ་འདབ་མེད། །
གྲོགས་དག་སེར་ཁ་བཟང་པོའི་ཕྱོགས་རྒྱལ་ལྟོས། །
དཔེ་མེད་མེ་ཏོག་སྐྱེས་ན་ཕྱོགས་ལས་རྒྱལ། །
རིན་ཐང་མེད་པའི་མེ་ཏོག་ལོངས་ཤིག་དང་། །
```

它没有根，也没有枝叶。朋友们，看那金黄美好、胜过诸方［的花］吧！无与伦比的花一旦生起，便胜过十方；去取那无价的花吧！

【按】"没有根，也没有枝叶"，是说心性不从任何因缘生起，也没有可以执取的部分。

【按】存疑。"སེར་ཁ་བཟང་པོ"，本译读作"金黄美好［的花］"；"སེར་ཁ"也可解为"缝隙""开口"，所指不完全确定。"ཕྱོགས་རྒྱལ"一词与叠句"胜过十方"相应，故译为"胜过诸方"。

## 三、取蕊者是幻化之师

```
གེ་སར་བླངས་པས་སྒྱུ་འཕྲུལ་མཁན་པོ་ཡིན། །
རྡོ་རྗེ་དབང་ཕྱུག་ཆོས་ཀྱི་དབྱིངས་ལ་མཆོད། །
དཔེ་མེད་མེ་ཏོག་སྐྱེས་ན་ཕྱོགས་ལས་རྒྱལ། །
རིན་ཐང་མེད་པའི་མེ་ཏོག་ལོངས་ཤིག་དང་། །
```

取得了花蕊的人，就是幻化之师；［以这花］在法界中供养金刚自在。无与伦比的花一旦生起，便胜过十方；去取那无价的花吧！

【按】存疑。"花蕊"（གེ་སར），在密乘象征语中常与圆满次第的明点、大乐相关；"取得花蕊者是幻化之师"，大概是说得到俱生之乐精华的人，了知一切如幻，能自在变化。"金刚自在"指金刚持，或心性本身。这些都是象征语言，须依上师口授理解，不可照字面揣测。

## 四、观察胜喜与离喜，供养上师

```
མཆོག་དང་དགའ་བྲལ་རྣམ་པར་བརྟགས་ཏེ་ཟུང་། །
བླ་མ་དམ་པའི་ཞབས་ལ་གུས་པས་མཆོད། །
དཔེ་མེད་མེ་ཏོག་སྐྱེས་ན་ཕྱོགས་ལས་རྒྱལ། །
རིན་ཐང་མེད་པའི་མེ་ཏོག་ལོངས་ཤིག་དང་། །
```

对胜喜与离喜，善加观察而把握；以恭敬心供养殊胜上师的双足。无与伦比的花一旦生起，便胜过十方；去取那无价的花吧！

【按】"胜喜"（མཆོག་དགའ）与"离喜"（དགའ་བྲལ），是密乘四喜中的两种，四喜即喜、胜喜、离喜、俱生喜。俱生喜在第几位，印度诸师说法不一，已译的梅纪巴《四印口诀》《灌顶教示》对此有专门讨论。本篇题名为"俱生之歌"，所以这里"观察胜喜与离喜"，大概是要人在二者之间认出俱生，意思不完全确定。四喜属于无上瑜伽续圆满次第，须在具德上师座前依灌顶与口授领受。末句以供养上师作结，表明认出俱生全靠上师之恩。
