# 断分别之歌

阿阇黎里拉巴造　据藏文译出

## 题解

本篇梵名 Vikalpaparihāragīti（底本作 bi ka lpa pa ri ha ra sti ka nā ma），藏名 rnam rtog spang ba'i glu，即《断分别之歌》，收于德格版丹珠尔续部释 ཟི 函第 2b 页（东北目录 D2343）。跋语说是"阿阇黎里拉巴所造"，没有记载译者。

里拉巴（Līlāpa）是八十四成就者之一。依成就者传记，他本是一位南印度的国王，在宫中坐狮子座上修行，从上师得到教授后，就在王位上修成。他的名字"里拉"意为"游戏"，篇末"里拉无我之狮"一句，就同时暗含他的名字与狮子座。

全篇约三十句，通篇用无上瑜伽续的"隐语"写成。这类隐语，如"博拉""嘎郭拉""樟脑""四等香""大肉"等，《喜金刚续》第二品中列有一部分，是用来在会供与修法中秘密表达方便与智慧双运、明点、拙火、尸林禁行等内容的，外人听来不知所云。全篇的主旨，从题名与第五、六节可以看出：舍弃净与不净、贵与贱的一切分别，安住于身中，最终以把自明之觉指向虚空的方式，证悟无二。

关于密乘内容的特别告诫：本篇第一至五节，几乎每一句都是隐语，涉及事业手印、明点、拙火、会供与尸林禁行。本译只依字面直译，按语只说明一般公认的含义；凡不能确定的，都标为存疑，不作强解。这些修法在藏传佛教各派中，都只对具足灌顶、严守三昧耶、已有生起与圆满次第基础的修行人，在具德上师亲自指导下才开示。读者绝不可照字面理解、揣测或效仿；不具缘者不应随意传阅。

体例：藏文原文全部保留在代码框中，按意义分节，每节后附汉译；隐语一律音译或直译，不以意译替代。凡标"存疑"的按语，表示本译对原文意思没有把握。藏文依 Esukhia 德格丹珠尔电子版。

## 一、博拉与嘎郭拉

```
བོ་ལ་གསང་བའི་རྡོ་རྗེ་ལ། །
འདུས་པ་སེམས་ཀྱི་རང་བཞིན་ནི། །
ཐིག་ལེ་གསང་བའི་རྩ་ལ་བྲེང། །
ཀཀྐོ་ལ་ཡི་ཁ་སྦྱོར་ལ། །
```

在博拉的秘密金刚中，汇聚着心的自性；明点系于秘密之脉，与嘎郭拉相结合。

【按】"博拉"（བོ་ལ，梵 bola）与"嘎郭拉"（ཀཀྐོ་ལ，梵 kakkola），是《喜金刚续》所列隐语中的两个，传统上分别指方便（金刚）与智慧（莲花），即事业手印修法中的男女双方，同时象征方便与智慧双运。这一节以下全部是圆满次第的隐语，须依灌顶与口授理解。

【按】存疑。"བྲེང"，本译依上下文译为"系于"，也可能是"流布""舒展"之义，所指不完全确定。

## 二、燃起、系缚、证悟三身

```
ཀྱེ་ཧོ་རེ་ནི་འབར་བར་བྱེད། །
ཀྲྀ་པི་ཏ་ཡི་སྒྲ་སྒྲོགས་པས། །
རྩ་དྲུག་འཁོར་ལོ་ཧཱུཾ་གིས་བཅིང། །
སྐུ་གསུམ་དྷཱུ་ཏཱིར་བདག་མེད་རྟོགས། །
```

嗟吙！令它燃起；发出克里比达之声，以"吽"系缚六脉之轮，在都帝之中证悟三身与无我。

【按】"都帝"（དྷཱུ་ཏཱི，梵 avadhūtī），即中脉。"令它燃起"，一般理解为拙火的燃起。"以吽系缚六脉之轮"，是以种子字摄持诸脉轮的修法。

【按】存疑。"རེ་ནི་འབར་བར་བྱེད"，"རེ"所指不明，可能是某一种子字或隐语，本译只译为"令它燃起"。"克里比达"（ཀྲྀ་པི་ཏ），可能是某种乐器（如手鼓）的隐语，所指不能确定，今音译。

## 三、饮甘露，择会众

```
རང་བྱུང་མེ་ཏོག་ལྡན་པ་ཡི། །
ག་པུར་བོ་ལ་བསྲེས་བྱས་ནས། །
ཀ་རུ་ཀའི་བདུད་རྩི་འཐུང་བར་གྱིས། །
ཀ་ལི་ཛེ་ར་སྐལ་བར་ལྡན། །
རྣལ་འབྱོར་ཚོགས་སུ་བསྲེ་བར་བྱ། །
འདུ་དྷུ་ར་སྐལ་བར་མི་ལྡན་ཏེ། །
སྤོངས་ཤིག་རྣལ་འབྱོར་དམ་ཚིག་གོ། །
```

把具有自生之花的樟脑，与博拉相混合，饮下嘎茹嘎的甘露吧！具缘的嘎里杰惹，应当融入瑜伽士的会众；不具缘的阿杜都惹，应当舍弃——这是瑜伽的三昧耶。

【按】"樟脑"（ག་པུར，梵 karpūra），在《喜金刚续》的隐语中一般指菩提心明点；"自生之花"一般指智慧母的红分。这一节是事业手印与会供的隐语，只能在具德上师座前依灌顶与口授了知，绝不可照字面揣测或效仿。

【按】存疑。"嘎茹嘎"（ཀ་རུ་ཀ）、"嘎里杰惹"（ཀ་ལི་ཛེ་ར）、"阿杜都惹"（འདུ་དྷུ་ར）三词，所指都不能确定；依上下文，后二者大概指可以与不可以进入会供的两类人，今一律音译。"应当舍弃不具缘者"，是密乘会供不得让未入门者参与的三昧耶。

## 四、涂香，具本尊慢

```
བཞི་མཉམ་གླ་རྩི་ལུས་བྱུགས་ནས། །
རྟོག་པ་རྣམས་ནི་སྤང་བར་བྱ། །
དཔའ་བོ་དཔའ་མོའི་ཚོགས་དག་ཏུ། །
ཧེ་རུ་ཀ་ཡི་ང་རྒྱལ་ལྡན། །
```

以四种等分的麝香涂抹身体，舍弃种种分别；在勇士与勇母的会众之中，具足嘿噜嘎的佛慢。

【按】"四种等分的香"（བཞི་མཉམ），是密乘会供与修法中所用的一种和合香，也常作为隐语使用。"具足嘿噜嘎的佛慢"，即生起次第中观想自己就是本尊、坚固本尊慢。

## 五、尸林大肉与相会

```
ཤ་ཝ་ཞིང་ཆེན་ཁུར་བྱས་ནས། །
མ་ལ་རིགས་སྐྱེས་བྲམ་ཟེ་ལ། །
ཀུན་ཏུ་ཕྲད་པའི་རྣལ་འབྱོར་པ། །
རྟོག་པ་མི་བྱ་ལུས་ལ་གནས། །
ཀྱེ་ཧོ་སྐལ་ལྡན་མཆོད་པར་གྱིས། །
```

担负着夏瓦大肉，与玛拉种姓所生的婆罗门［女］处处相会的瑜伽士，不要作分别，就安住于身中。嗟吙！具缘者啊，应当供养！

【按】存疑。"ཤ་ཝ"（梵 śava），意为尸体；"ཞིང་ཆེན"，字面是"大田"，在密乘中常作为人肉的隐语，指尸林修法所用的物品。"མ་ལ་རིགས་སྐྱེས་བྲམ་ཟེ"，本译直译为"玛拉种姓所生的婆罗门［女］"，所指不明，可能是事业手印的隐语。这一节全部是印度大成就者尸林禁行的隐语，读者只可了解其为象征，不可照字面理解或效仿。

【按】这一节的落脚点是"不要作分别，就安住于身中"：无论净与不净、贵与贱，一切分别都要舍弃，这正是本篇题名"断分别之歌"的意思。

## 六、仰卧观空，里拉巴证悟

```
ལི་ལ་བདག་མེད་སེང་གེ་ཡིས། །
སྟོང་ཉིད་དོན་ནི་རྟོགས་པར་འགྱུར། །
རྣམ་རྟོག་སྤང་ཕྱིར་རྣལ་འབྱོར་ཀྱེ། །
བདག་ནི་གན་རྐྱལ་ཉལ་བྱས་ནས། །
ལག་པ་བསྣོལ་ནས་བྲང་ལ་སྦྱར། །
རང་རིག་ནམ་མཁའི་ཕྱོགས་སུ་གཏད། །
ལི་ལ་སྐྱེས་ཏེ་གཉིས་མེད་རྟོགས། །
རྟོག་མེད་རྣལ་འབྱོར་གྲུབ་པ་ཐོབ། །
ལི་ལ་པ་ཡིས་རྟོགས་ནས་གྲོལ། །
```

以里拉无我之狮，就能证悟空性之义。为了断除分别，瑜伽士啊！我仰面躺下，双手交叉，贴于胸前，把自明之觉指向虚空的方向；游戏生起，证悟了无二，获得了无分别瑜伽的成就——里拉巴就这样证悟而解脱。

【按】"里拉"（ལི་ལ，梵 līlā），意为"游戏"，同时是作者的名字。依八十四成就者传记，里拉巴本是一位国王，坐在狮子座上修行而成就；所以"里拉无我之狮"，一方面说游戏、无我如狮子般无畏，一方面暗指他的狮子座。

【按】"仰卧、双手交叉贴于胸前、把自明指向虚空"，是作者自述的修法姿势，属于把心安住于虚空般觉性的修法。具体的身要与心要，须依上师口授，不可只依文字照做。
