# 摄要开示

阿阇黎吉祥阿难陀金刚造　印度堪布金刚手、藏地译师玛班·却巴译　据藏文译出

## 题解

本篇梵名 Sarvasārasamuccaya-prakaraṇa，藏名 snying po kun las btus pa'i rab tu byed pa，直译为《一切精华集要论》，本站依通行题名称为《摄要开示》。收于德格版丹珠尔续部释 ཞི 函第 227b 至 228a 页（东北目录 D2298）。跋文说是"大阿阇黎吉祥阿难陀金刚（Śrī Ānandavajra）亲口所造"，由印度堪布金刚手（Vajrapāṇi）与藏地译师玛班·却巴（rma ban chos 'bar）译出。阿难陀金刚的生平不详。金刚手是梅纪巴的弟子，前一篇《悟未悟者》（D2297）也是由这两位译出，所以本篇大概也出自梅纪巴一系的传承，这只是推测。

全篇共十一颂，每颂四句。内容可分三层。

第一层（第一至四颂）：从"喜乐"破起。令心中生起安乐的喜悦觉受，仍然只是分别；把"离贪"执为一个实在的境界，反而成为轮回之因。分别念本身就是真如的自性，离开显现与流动，另外没有涅槃；"不分别的心""舍离分别"也只是假立为涅槃之名。无二的实相，既不是涅槃，也不是轮回。

第二层（第五至七颂）：破"遮灭"实有。所谓"各别遮灭"，能遮、所遮、遮的作用三者都没有实体，那么靠什么、成就什么、如何成就？诸法本来无生，只是像空花一样显现为实有，凡愚却想凭分别的力量把它们除掉，以为这样就得到了涅槃之果。

第三层（第八至十一颂）：以譬喻收结。饥饿的婴儿吸吮自己的手指，把口水当作乳汁，于是不哭了；凡夫把自己分别造作出来的东西当作涅槃，也是这样。最后一颂是全篇的归宿：把"贪"与"离贪"两边都舍离而入于等持，无苦无乐，必见真如。

本篇所说的"喜悦""安乐"，很可能是针对修行中出现的乐受，尤其是执着乐受的倾向，提醒修行人不可把乐受当作证悟。篇中没有具体的密法修持，但读者也不可据此认为可以不依上师而自行修习等持。

体例：凡标"存疑"的按语，表示本译对原文意思没有把握。藏文依 Esukhia 德格丹珠尔电子版，异文取第二读。

## 二、喜乐亦是分别（第一颂至第二颂首句）

```
གང་དེ་དགའ་བའི་རང་བཞིན་གྱིས། །
སྙིང་ལ་བདེ་བྱེད་ཉམས་མྱོང་བ། །
དེ་ཡང་ཀུན་དུ་རྟོག་པ་ཙམ། །
འདོད་ཆགས་བྲལ་བའི་དངོས་པོ་གང་། །
དེ་ནི་གཅིག་ཏུ་སྲིད་རྒྱུའི་མཆོག །
```

那以喜悦为自性、令心中生起安乐的觉受，也只不过是遍计分别而已。而所谓离贪的"实事"，［若执为实有，］那唯独是三有之因中最强的一种。

【按】存疑。"dngos po"是"实事、实在之物"；"gcig tu srid rgyu'i mchog"字面是"唯是有（轮回）之因的最胜者"。如果照字面直读为"离贪之境是三有的最胜之因"，文义难通。本译理解为：把"离贪"当作一个可以获得的实在境界去执取，反而成为最强的轮回之因。这样与末颂"把贪与离贪都完全舍离"相呼应。方括号内是补足的意思。

## 三、离显现与流动别无涅槃（第二颂次句至第四颂次句）

```
གང་ཞིག་ཡིད་ཀྱིས་སྐྱེས་པ་ཡི། །
རྣམ་པར་རྟོག་པ་གང་དག་ཀྱང་། །
དེ་ཉིད་རང་བཞིན་ཡིན་ཕྱིར་ཏེ། །
སྣང་ཞིང་རྒྱུ་བ་འདི་དག་ལས། །
མྱ་ངན་འདས་པ་གཞན་དུ་ནི། །
ཡོད་མིན་ཡུལ་ནི་ཅི་ལ་ཡང་། །
རྣམ་པར་མི་རྟོག་བདག་ཉིད་སེམས། །
རྣམ་རྟོག་སྤངས་པ་དེ་བཞིན་ཏེ། །
མྱ་ངན་འདས་པ་ཞེས་བརྟག་གོ། །
```

凡是由意所生的一切分别念，因为本身就是真如的自性，所以在这些显现与流动之外，另外并没有涅槃。

以对任何境都不分别为体性的心，以及同样地，舍离分别，［这些也只是］假立为"涅槃"而已。

【按】"de nyid rang bzhin"可读为"真如（de nyid，梵 tattva）的自性"，也可读为"就是它自己的自性"。本译取前者，因为下文紧接着说离开显现与流动别无涅槃。"显现"（snang ba）与"流动"（rgyu ba），是大手印口诀中常用的一对词：显现指境界的现起，流动指念头的生起与游走。

【按】"brtag"是观待而安立、假立之意。作者的意思是：说"不分别的心"是涅槃，说"舍离分别"是涅槃，也都只是名言上的安立，为下一句"无二既非涅槃亦非轮回"作铺垫。

## 四、无二非涅槃亦非轮回（第四颂后二句）

```
གཉིས་མེད་མྱ་ངན་འདས་པ་མིན། །
འཁོར་བའང་མ་ཡིན་པ་ཁོ་ན། །
```

无二［的实相］，既不是涅槃，也决然不是轮回。

## 五、破遮灭实有（第五颂至第六颂次句）

```
སོ་སོར་འགེགས་ཚིག་གང་ཡིན་དང་། །
སོ་སོར་འགག་བྱར་འགེགས་པ་ཡི། །
གསུམ་གྱི་དངོས་པོའང་མེད་པས་ན། །
གང་གིས་གང་ཞིག་ཇི་ལྟར་འགྲུབ། །
ཡུལ་ནི་དངོས་མེད་གཉིས་ཡིན་ནོ། །
སོ་སོར་འགེགས་པའི་བྱེ་བྲག་ཅི། །
```

所谓"各别遮灭"的名言，［所要］各别灭除的［对象］，以及［能］遮灭［的作用］，这三者的实体既然都不存在，那么，以什么、成就什么、又怎样成就呢？

境本是两种无实之法；那么，各别遮灭又有什么差别可言呢？

【按】存疑。这两颂文字简古，本译把"三者"理解为能遮、所遮与遮的作用，正与下句"以什么（能）、成就什么（所）、怎样成就（作用）"三问相应。另有一种可能：作者针对的是有部所说的择灭（so sor brtags 'gog）、非择灭等无为法，把"各别遮灭"当作实有的涅槃，"三者"则指三种无为。"境本是两种无实之法"一句，可能指择灭与非择灭两种"灭"本身都没有实体，也可能指能遮与所遮二者都无实。两种解释的大意相同：涅槃不是靠遮灭某个实在的东西而得到的。

## 六、诸法无生而现似实有（第六颂后二句至第七颂）

```
ནམ་མཁའི་མེ་ཏོག་ལ་སོགས་པས། །
ཅིར་ཡང་མཐོང་ཞིང་རྒྱས་པ་བཞིན། །
སྐྱེ་བ་མེད་པའི་རང་བཞིན་གྱིས། །
བདེན་པའི་དངོས་པོ་སྦྱིན་སྣང་བ། །
རྣམ་རྟོག་སྟོབས་ལས་བསལ་བ་ལ། །
བུས་པའི་འབྲས་བུ་ངོ་མཚར་ཆེ། །
```

就像虚空中的花等，［本无所有，却］被看成种种形相，而且越看越繁茂一样；［诸法］以无生为自性，却显现得好像真实的实事。凭着分别的力量去把它们除掉，这样得到的愚童之果，真是稀奇啊！

【按】"sbyin snang ba"，sbyin（施予）文义不通，疑是 bzhin（如、似）之讹，今依"似真实的实事而显现"译出。"bus pa"疑即 byis pa（愚童、凡夫）的异写，第八颂同。"真是稀奇"是反讽语：本来无生的东西，用分别去除掉它，所得的"果"，只是孩童式的自我满足，下颂以婴儿吮指为喻说明这一点。

## 七、婴儿吮指之喻（第八颂至第九颂）

```
ཇི་ལྟར་བུས་པ་བཀྲེས་པ་དག །
སོར་མོ་རང་གི་ཁར་བཅུག་ནས། །
ནུ་ཞོ་འབབ་པ་ལྟ་བུ་ནི། །
མཆིལ་མ་འཐུངས་པས་ངུ་བ་མེད། །
```

就像饥饿的婴儿，把自己的手指放进嘴里，好像有乳汁流出来一样，吸着自己的口水，于是就不哭了。

```
དེ་ལྟ་བས་ན་འབྲས་རྨོངས་པས། །
མྱ་ངན་འདས་ལ་སོགས་པར་བྱེད། །
བདེ་བ་ཐོབ་པར་འདོད་པ་ཡི། །
སོ་སོའི་སྐྱེ་བོ་དེ་ཉིད་དམན། །
```

同样地，对果愚昧的人，［把自己分别造作出来的东西］当作涅槃等等。想要获得安乐的凡夫，正因为这样而低劣。

【按】"'bras rmongs"，字面是"对果愚昧"；也可能是 byis rmongs（愚童、愚蒙）之讹，与上颂"婴儿"相应。两种读法大意相同。

## 八、钻木生火之喻（第十颂）

```
འགྲོ་རྣམས་དེ་ལྟར་སྡུག་བསྔལ་བས། །
ཐོབ་པར་གྱུར་པ་མི་མཉམ་སྟེ། །
དྲུད་པ་ལས་བྱུང་མེ་ཡིས་ནི། །
འོད་མ་ཚིག་གྱུར་ཇི་བཞིན་ནོ། །
```

众生像这样因为苦［而追求乐］，所得到的并不是平等［的实相］，就像摩擦竹子所生的火，反把竹子本身烧掉一样。

【按】存疑。"mi mnyam"可解为"不平等"，也可解为"无与伦比、无等"。本译取前者，理解为承接上颂对凡夫求乐的批评：以求乐之心造作出来的境界，并不是离苦乐二边的平等性，反而像钻竹所生的火回头烧毁竹子，造作本身成为损害自己的因。若取后者，此颂则是正面之喻，与《大宝积经·普明菩萨会》（迦叶品）中"两木相磨生火，火还烧木"之喻相同，意思是：由苦而发起的观察，所生的智慧之火，最终连观察本身也烧尽，所得的是无与伦比的果。依上下文，前一解较顺，但不能确定，两解并存，请读者斟酌。

## 九、贪与离贪俱舍而入等持（第十一颂）

```
ཆགས་དང་ཆགས་བྲལ་ཞེས་བྱ་བ། །
རྣམ་པར་སྤངས་ནས་མཉམ་གཞག་ན། །
སྡུག་བསྔལ་མེད་ཅིང་བདེ་བ་མེད། །
དེ་ཉིད་མཐོང་བར་སོམ་ཉི་མེད། །
```

若把所谓"贪"与"离贪"［两边］都完全舍离，而安住于等持，［那时］既无苦，也无乐，必定得见真如，这是毫无疑问的。

【按】此颂与第一颂首尾相应：第一颂说喜乐的觉受只是分别、执取离贪反成轮回之因；此颂说贪与离贪两边都舍，苦乐俱泯，才见真如。全篇的意思就落在这里。

## 通篇连读

敬礼上师与诸佛。

那以喜悦为自性、令心中生起安乐的觉受，也只不过是遍计分别而已。而所谓离贪的"实事"，若执为实有，那唯独是三有之因中最强的一种。

凡是由意所生的一切分别念，因为本身就是真如的自性，所以在这些显现与流动之外，另外并没有涅槃。以对任何境都不分别为体性的心，以及同样地，舍离分别，这些也只是假立为"涅槃"而已。无二的实相，既不是涅槃，也决然不是轮回。

所谓"各别遮灭"的名言，所要各别灭除的对象，以及能遮灭的作用，这三者的实体既然都不存在，那么，以什么、成就什么、又怎样成就呢？境本是两种无实之法；那么，各别遮灭又有什么差别可言呢？

就像虚空中的花等，本无所有，却被看成种种形相，而且越看越繁茂一样；诸法以无生为自性，却显现得好像真实的实事。凭着分别的力量去把它们除掉，这样得到的愚童之果，真是稀奇啊！

就像饥饿的婴儿，把自己的手指放进嘴里，好像有乳汁流出来一样，吸着自己的口水，于是就不哭了。同样地，对果愚昧的人，把自己分别造作出来的东西当作涅槃等等。想要获得安乐的凡夫，正因为这样而低劣。

众生像这样因为苦而追求乐，所得到的并不是平等的实相，就像摩擦竹子所生的火，反把竹子本身烧掉一样。

若把所谓"贪"与"离贪"两边都完全舍离，而安住于等持，那时既无苦，也无乐，必定得见真如，这是毫无疑问的。
