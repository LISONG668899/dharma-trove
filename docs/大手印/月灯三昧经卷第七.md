# 《月灯三昧经》卷第七

高齐天竺三藏那连提耶舍汉译　白话今译

## 一、大神通的根本之业

“童子！菩萨摩诃萨应当常乐修习神通的根本之业。什么是菩萨摩诃萨大神通的根本之业呢？就是摄持一切善法，却不执取戒聚，不贪著定聚，对于智慧聚也不作戏论，对于解脱聚与解脱知见聚也不执取贪著。童子！这就是菩萨摩诃萨大神通的根本之业。如果成就了神通的根本之业而得到大神通，菩萨摩诃萨对一切变现都得自在，便能为一切众生说法。为了摄受大乘的缘故，这位菩萨对于这大神通的根本之业应当常常修学。”

【按】世尊所说“大神通的根本”，不是修炼某种特殊能力，而是“摄一切善法而不取著”。戒、定、慧、解脱、解脱知见五分法身照常具足，心中却不执取其中任何一分。这与前卷般若十利的意趣一贯。

这时，世尊说偈道：

神通的根本殊胜之业，显示的是不求果报；如果希求果报而修种种行，执取我想就不能除去。

所谓神通，就是佛不可思议的智慧；如果安住于执取，这个人就没有智慧。

不可思议的诸法，借音声来显示；如果执著于音声，就不能通达方便之说。

不晓得方便之教，也不知道方便之说，把非法说成是法，对于法又怎能觉了呢？

在三千世界之中，我那时宣说种种经典；义理是一，滋味却有种种，那些全都不可言说。

所有十方诸佛，显示宣说无量之法；仔细思惟一句的义理，就能理解一切。

一切法无我，如果有人修学这一义理，那时修习这一句，悟入佛法就不难。

一切法都是佛法，如果有人修学此法，如法地解了，就随顺于空性之法。

```
诸语是佛语　一切声事无
遍于十方求　佛语不可得
```

大意是：一切言语都是佛语，而一切音声之事本无所有；遍于十方去寻求，佛语也了不可得。

佛语最为第一，佛语无有超过其上的；微细之事也全无所有，这才是最上之语。

那法最为无上，显现而不断绝；却无一微尘许可得，这是诸佛所宣说的。

诸法不可得，也没有法可以证得；这样了知法，就能理解佛的菩提。

他如果悟入此法，就能转动法轮；转动法轮的时候，就宣畅殊胜的甘露。

菩萨能够解了无上的佛菩提，得以成为无与伦比的世尊，使他人悟入佛的智慧。

无作（无修）以及无愿、无相与空，这样四种法门，佛说是解脱之门。

眼、耳以及鼻、舌、身、意等诸根，这些体性都是空的，憍陈如最初见到这一点。

如果能对这一法如实了知其体性，诤论在他那里就不存在了，因为通达了法相的缘故。

这是勇猛者的境界，是救护众生的菩萨，对此完全没有疑惑，因为了知诸法体性空的缘故。

能通达诸法的体性，所以得名为佛；以难以测量的法界，觉悟应当得度的人。

得到诸佛的事业，都是由戒身所造作的；佛的言教与戒的音声，都同一平等之相。

已经宣说的种种音声，也就是下等、中等、上等之音，都平等同为一相，佛能以此显示法教。

佛法无所住，也不在任何方所；不生也不灭，所以称为无漏。

不是新的也不是旧的，不是离散也不是和合，不是青也不是黄，不是白也不是黑。

难以言说，不可执取，借助言语才得以昭显宣畅；这不是音声的境地，是诸佛善巧智慧的通达。

那是无漏之法，这是说它无所依止；不在十方任何处所，这是佛所说的法。

在佛灭度之后，思念佛的身相，就能见到佛身，这是由于佛的神力的缘故。

终究没有一个众生是证得寂灭的；然而宣说此法的时候，有无量大众得以灭度。

## 二、见法身即是见佛

```
譬如彼日月　影现于百川
皆睹其像貌　诸法相如是
若知诸法性　犹若诸影像
终不以色身　得睹于真佛
诸法无形相　求状不可得
如是无形法　即是佛法身
若人见法身　是名见导师
法身即正觉　如是名见佛
```

大意是：譬如那太阳和月亮，影子显现在百川之中，人人都看见它的形貌，诸法之相就是这样。如果了知诸法的体性犹如影像，就终究不会以色身来见真佛。诸法没有形相，寻求其形状不可得，这样无形之法，就是佛的法身。如果有人见到法身，这就称为见到导师；法身就是正觉，这样才称为见佛。

【按】这是本卷乃至全经关于“见佛”最明白的经文：见法身即是见佛，而法身就是“诸法无形相、求状不可得”。这与大手印“认识心性即见法身”完全同一意趣。日月映现百川之喻，又说明一切显现都如影像，无须断除，只须认识其性。

不得而示现得，不得而说为得；如果想要求作沙门，应当了知这一道理。

我已经宣说了真实之行，了知众生的乐欲；如果入于秘密之教，他就没有执著。

如果说有所证得，他就无所成就；这样得不到道果，所以称为非沙门。

这法甚深奥妙，未能通达的人才这样说（有所证得）；那教法极其渊深玄妙，难以宣说显示。

五蕴（五众）之事都无所有，全从虚妄而起；没有能生起者，也没有五蕴之法。

五蕴的体性与相状，就是一切法的相；佛说这样的相，其相不可得。

如同虚空中没有任何物，诸法也是如此；前际、后际以及现在，三际都应如实观察。

言说如同虚空，因为空中无所执取；这样的法之体性，无所执取如同虚空。

演说这样的法，从来没有任何所说；对于法无所见，这才是不可思议。

这法没有自性，法的体性不可得；领会佛菩提的人，是定中寂灭的境界；

如果能这样了知，对于法就没有执著；如果能不执著于法，这个人就了知了法的想念。

菩萨在一切时中，舍弃一切想；如果有人舍弃了想，对于佛法就没有执著。

那边际没有可以执取之处，这就称为实际；对于实际了达的人，在亿劫中都能不执著。

对本际妄加分别，愚痴的人就在生死中轮转；在十方遍处推求，本际都不可得。

因为一切法空的缘故，菩萨无所执著；为了菩提而兴起修行，那行也不可得。

```
如鸟飞虚空　足迹不可得
正觉性如是　菩萨能解了
```

大意是：如同鸟儿飞过虚空，足迹了不可得；正觉的体性就是这样，菩萨能够解了。

【按】鸟迹之喻在大手印传承中常被引用：念头生起又消失，如鸟飞空中，不留痕迹。经中用它来说明正觉的体性，也就是说，觉性本身无迹可寻，却明明了知。

如同有人善于学习幻术，幻化出种种事物，示现种种色像，而实际上不可得。

如果执取得与失，他就一无所得；他的智慧犹如幻化，但并不就等同于那幻化。

在这空性之法处，愚痴的人妄加分别；行于分别之中，这样的人就趣向恶道。

## 三、凡夫因妄分别而流转

众生生、老变迁，流转无穷无尽，沉没在生死之中，苦恼没有限量。

世间所生的苦恼，是由于愚痴的妄想分别；没有断除那分别，就长久在生死中漂流。

最初贪乐，然后相应，习惯于执著欲望的果报，执取而不能舍弃，因为住于业与烦恼的缘故。

众生的业没有穷尽，被欲望的暴流所漂荡，屡屡受生，屡屡又死灭。

没有智慧，被魔所扰乱，造作种种恶业，处处受生，便感召种种死亡的果报。

凡夫愚痴黑暗，而获得生死之身，贫穷又加上痛苦楚切，又趣向不善之趣。

以刀、鞭、杖等，彼此互相伤害，造作这样的恶事，增长种种苦恼。

“我的儿子”“我的财物”，凡夫这样妄加分别；这样的妄想分别，又增长种种有漏。

他们增长种种生死，这就是凡夫；流转于种种不同的趣，所以称为凡夫。

他们舍弃佛法，增长种种恶法，于是不能得到解脱，因为被系缚在魔网之中的缘故。

愚人因为爱欲的缘故，随事染污于女色，又趣向不净之处，堕入种种恶道。

贪欲染著是佛所不赞叹的，以及亲近女色；这是令人怖畏的种种罗网，女色的罗网最为可怕；菩萨恒常远离，犹如远离恶毒的蛇，常常不亲近女色，知道这不是佛道。

修学菩提之道，如佛本来所修习的那样；修学佛道之后，迅速成就无上之道。

他得到最无上的果位，成为世间的庙塔，智慧没有能超过他的，成为天中之天，使他人安住于八戒，戒身没有垢染。

他劝教无量亿的大众修习菩提，为大众作利益，对一切众生都生起悲心。

那位勇健的智者，擂击法鼓，震动魔王的宫殿以及魔的眷属，劝令无量亿的魔修习菩提；

他降伏一切异论，胜出一切外道，震动大地、大海以及群山。

他变现为许多身形，种种不同的类别；大智者能显示百千种神变。

他震动无量佛刹，多如恒河沙，降伏那些魔众，便悟入无上之道。

又化作美妙的树木，以种种珍宝庄严装饰，花果奇特茂盛，芬芳非常可爱；

或者化作台榭、楼观以及宫阁，勇健者所作的变化，花池非常精妙明净，

充满八功德水，清凉而没有秽浊；如果有众生饮用，就能灭除三种渴爱。

如果有人饮用此水，都能得到不退转，能得到无上的智慧，堪为世间的导师。

无上的寂灭之道，修行人应当了知；不通达这一道的，就是所谓的外道。

如果有人亲近他们，受持奉行他们的言教，就会坠入大恶之处，在阿鼻地狱中难以救拔，承受大而极度的苦恼，无法全部详说。

只有我能了知，以及殊胜的大菩萨；这法甚深，难以看见，不是愚痴凡夫的境地，那些住于执取的人，对此法会生起疑惑。

菩萨变现殊胜的庄严，有无量种可爱之相，一切都能前往无上的诸佛刹土。

在一切诸佛国土中，都显现种种不同的色相，菩萨的大神力，一切都能显现。

具有大力、大勇猛，披着坚固殊胜的铠甲，手执大金刚杵，摧灭“空法”（见下按）。

【按】原文“摧灭于空法”，字面似说摧灭空法，与全经宗旨不合。依上下文，或指摧灭对空法的执著与误解，或“空”字有讹，此处存疑。

从自身放出无数的大光明，其数如恒河沙，消灭世间的黑暗。

他不染著女色，也不随顺女色；应当远离这种想念，女色之想非常可怖。

佛土常常不空，有勇猛者住在其中，恶魔波旬等，不能扰乱。

住于恶见的人，不能值遇诸佛，被忿怒所控制，安住于悭贪之中。

他们被魔波旬所控制，对于生天与解脱，魔都为他们制造障碍，所以他们堕入恶道。

## 四、想与智：离想之道

观察一切想，而安住于远离想，这个人就能了知诸佛无上的智慧。

能见到前际、后际，以及现在；演说这样的义理，其中却无所说。

假名和合而有言语，菩萨这样了知，利益众生，无量而难以思议。

想，是测度了知义理的，因为它显示能取的作用；而那所想之相并无可取，这就显示了寂灭之义。

```
不寂者是想　寂灭者是智
若知想自性　便离于诸想
若有想可遣　是则还有想
彼行想戏论　是人不离想
```

大意是：不寂静的是想，寂灭的是智。如果了知想的自性，就远离了一切想。如果认为有一个想可以遣除，那么这本身还是有想；这样的人行于想的戏论之中，他并没有离开想。

【按】这首偈对修心者极为切要。初学者常想“把念头赶走”，经中明说：若有想可遣，还是有想。离想的关键不是遣除，而是“知想自性”。认识了念头的本性，念头当下就是离想；这与冈波巴所传“念头不须断除，认识其体性即自解脱”的教授完全一致。

如果有人生起这样的心：“这想是谁造作的？这想是谁能证知的？谁能灭除这想？”

```
起想之法者　诸佛莫能得
即于此处有　无我离取着
若其心不生　何由得起想
若心得解脱　彼则无由起
```

大意是：那生起想的法，诸佛也不能得到；就在这里，有的只是无我、远离执取。如果心本来不生，又从哪里生起想呢？如果心得到解脱，想也就无从生起。

【按】这里经中引导行者去追问想念的来源：谁造作、谁证知、谁灭除？追寻的结果是“诸佛莫能得”，也就是寻而不得。大手印观修中“寻觅心与念之来处、住处、去处”，与此完全相应。寻而不得之处，就是无我、离取，就是心本不生。

如果证得了解脱，心就不可思议；因为心不可思议，所以成就不可思议。

我本来作这样的念头：“安住于心地之后，舍弃一切心，愿成就不可思议。”

由白净之法的果报，见到了无为；在一念之中，能了知一切众生的念头。

```
众生即是心　心即是如来
诸佛不思议　显了于此心
```

大意是：众生就是心，心就是如来；诸佛的不可思议，就显现明了于这一颗心。

【按】这四句可以说是全经最直接的“心即是佛”之语，也是经教大手印最根本的依据之一。众生、心、如来三者无别；诸佛不可思议的功德，不在心外，就是此心的显现。冈波巴大师所说“心之本性即是法身”，在这里有直接的经证。读者若只记住本卷一句，就记住这一句。

如果有人生起这样的念头：“怎样才能舍弃心呢？”思惟于无心，就能远离一切心。

如果在临死灭度时，心随着想念而转，这个人生起思虑之心，就使心不能解脱。

愚人心存女色之想，就生起爱欲；如果能灭除想，就能没有爱欲。

如果思惟无上之法，这种思惟是最大的思惟；因为思惟诸法的缘故，获得真实之心。

忆念无穷无尽，长夜恒常攀缘；种种邪曲怪异的忆想，思虑之心不可穷尽。

名为心尽之法，在尽之中本来没有智；智慧不是尽灭之地，因为法无有穷尽的缘故。

【按】“智慧非尽地”：认识心性并不是让心灭尽成为空无，智慧本身无尽。这句话再次防止把离想误解为断灭。

借假名言语之道，离于言语而演说；这法没有差异，智慧没有穷尽。

不生也不灭，无相，无状貌；常在亿劫之中，显现无相之法。

观察一切有，安住于非有之中；从未见到有的差异，也不见到无的差异。

借假名而有言说，显示非有也非无；然而那一切诸佛，对于有与无都无所见。

一切有为法，都显示为非有；如果能了知此法，就能见到非有。

常常无所证得，因为毕竟无所有的缘故；如果有可以证得的，就称为世间。

如果生起这样的心：“我要在世间成佛。”生起这种存有之想，终究不能悟入菩提。

无所畏惧的菩萨，对于法无所求取，自然没有烦恼，这就称为菩提。

众人这样说：“我在趣向菩提。”因为不知道这一道理，他们远离了佛的菩提。

以音声来说法：“一切诸行都是空的，音声的体性与自性，精微而不可见。”

## 五、报得神通与持经功德

显示大神通的人，宣说这部修多罗，利益诸菩萨，这是诸佛所明示的。

他断除那些所对治的，也就是种种烦恼等；他安住于大神通，善修四神足。

获得尸罗（戒），对于空性究竟通达，安住于神通，神足不可思议；

安住于无愿之智，修习智慧，善加清净，求取智慧没有厌足，无量而不可思议。

在神通三昧中，任运而无须功用；这果报恒常空无，一切常常寂灭；

以这果报的神足之力，前往游历亿数世界，见到佛这世间的明灯，犹如恒河沙数。

这个人对于生与灭，随心而得自在；因为心得自在之后，他的身体就得到清净。

在佛的诸弟子中，如果修习神通之力，与这报得的神通相比，十六分之一也不及；

一切诸天大众都不能见到他的身体，唯有佛世尊，以及同样得到此通的人能见。

他的身体没有种种疾病，也没有白发皱纹，以及羸弱虚老，临终时没有苦痛；

他没有疑惑滞碍，以及种种迷惑，昼夜恒常演说百亿部修多罗。

一切种种烦恼，连习气都已断除；对一切众生，常常生起平等之心。

在百千种三昧中，无垢而得自在，修习大智慧，为他人演说。

对于男、女二根等，一切都远离其想，安住于非有之想，能宣说真实决定之义。

以清净的智慧，演说如实之法，称合于随顺之法，这是定与慧的境界。

那些修习禅定的人，不被有所滞碍，常以真实之言说法，无不利益众生；

他善得人身，远离一切八难，能报答诸佛之恩；因为常乐此经的缘故，他在无量劫中舍弃世间。

如果对这部微妙的经典，乃至受持一首偈，这个人就曾经见过诸佛，屡屡作过供养。

因为爱乐此经的缘故，迅速悟入佛的菩提；他就能见到诸佛恒常住在灵鹫山，诸佛都为这个人授记：“你将见到弥勒佛。”

他见到弥勒佛；如果在末代之时，受持此经的人，会得到上妙的爱乐之心。

转读此经的人，就是受持法藏的人；在一切供养之中，法供养最为上等。

如果能受持此经，那难以思议的佛菩提，也就是“佛的无上智慧”，他得到那智慧并不难。

前往诸佛刹土时，他便能震吼，作大狮子吼，这佛吼不可思议。

在那亿数佛所，他做释迦狮子所作的事，能以无量辩才演说而无所畏惧。

甘蔗种族的功德之种（释迦佛）为这个人授记：在以后的末代，他能护持佛的菩提。

如果对这部殊胜的经典，显示它的功德，就能获得这些妙果，迅速证得菩提，常在一切生中成就无所畏惧。

如果有人对于此经，这菩萨的境界、无尽的殊胜三昧、一切菩萨之母，想要迅速证得菩提，就应当受持此经。

他得以亲近佛，也接近佛的菩提；不久就能从此经中获得殊胜微妙的寂灭。

这是勇健者的境地，是菩萨所安住的；他见到世间明灯（佛）的照耀，犹如恒河沙数。

## 六、持此离垢寂定的种种功德

他能作具大力的转轮王，见到佛具足十力的寂定之心，以无量百首偈颂赞叹，得到离垢地的殊胜三昧。

他设置无与伦比的供养来供养佛，具有大名号，是人中最上者；舍弃王位如同吐掉鼻涕唾沫，修行最上殊胜的梵行，在殊胜的佛法中出家，得到这寂灭离垢之定。

他得到殊胜善妙美好的言语，演说多亿部经而不断绝：空、无相、无愿的微细之法，寂静殊胜，离垢而没有诸漏，自性空寂，言语道断；出定之后能为许多人宣说，甚深的智慧常常无量，广大的智慧具有无边的义理。

得到这甚深三昧之后，能为世间作照明，常修梵行，恒常皎洁，没有种种腥臊与鄙秽，使无量众生得以安住，使他们得到寂定而远离种种垢染。

他常得聪明锐利、敏捷迅速的辩才，多闻如海，智慧无量，言语善妙，通达诸法，因为受持这寂定殊胜之经的缘故；

了知种种事业以及工巧，通晓因明论议以及医方，到达一切勇健的彼岸，因为受持这离垢寂定的缘故；

对于种种偈论以及戏笑，善于歌舞，都能究竟，常为世间作师范，因为受持这离垢寂定的缘故；

常有上妙的种种眷属，恒常得到一切上等的供养，能修殊胜微妙的菩提之行，因为受持这离垢寂定的缘故；

忧恼的毒箭逼切内心，那位智者没有这种患难，恒常没有病疾，常常安稳，因为受持这离垢寂定的缘故；

世间所有的种种病患，一切身体的病患以及心的病患，这个人常常没有这样的病患，因为受持这离垢寂定的缘故；

所有的身痛以及心痛，或是牙痛以及头痛，智者常常没有这些痛恼，因为受持这离垢寂定的缘故；

心中有无量其他的痛恼，从意念中生起而焚烧其身，他没有一切由此生起的烦恼，因为受持这离垢寂定的缘故；

```
犹如虚空无所染　自性无垢常清净
彼人心净亦如是　持此离垢寂定故
亦如日月之光明　其光颇执常清净
彼心清虚亦如是　持此离垢寂定故
如人执持诸彩色　欲画虚空不可得
彼人心净亦如空　持此离垢寂定故
```

大意是：犹如虚空无所染污，自性无垢，恒常清净，这个人的心清净也是如此，因为受持这离垢寂定的缘故。也如太阳和月亮的光明，那光明恒常清净（无可执持），他的心清虚也是如此，因为受持这离垢寂定的缘故。如同有人手持种种彩色，想在虚空中作画，是不可能的，这个人的心清净也如虚空，因为受持这离垢寂定的缘故。

【按】“欲画虚空不可得”，是对心性的绝妙比喻：种种念头烦恼如彩色，心的本性如虚空，彩色终究画不上虚空。所以心性本来无垢，不是修成清净，而是本来就不可能被染。大手印“心性如虚空，本来清净”的教授，以此喻最为亲切。原文“其光颇执”，“颇”字费解，或为“叵”（不可）之意，译文取“不可执持”，存疑。

譬如风行于十方，遍游诸方而无所执著；他的心流注也犹如风，不染世间而得解脱；风行迅疾而不可见，不能用罗网来系缚，这个人的志意深沉难以了知，因为受持这离垢寂定的缘故。

墙壁上的光影不可取，指着水中的影像也难以执持；得到这三昧在身的时候，没有人能了知这个人的心；

十方世界一切众生的所有语言尚且可以计算，得到这三昧在身的时候，没有人能了知这个人的心；

得到这样的寂灭之定，他的心无垢、无染著，三界众生没有能与他相等的，唯有诸佛三界之尊除外。

远离贪爱欲望，不染著于色，不以愚痴之心执著于女人，得到这样的殊胜之定时，就获得殊胜的寂灭而无所染著；

对于男女没有恋情，不染著于妻妾以及眷属，得到寂灭殊胜之定时，善妙寂静之行无所染著。

对于财货不视为珍宝，不希求生天之果，不执著财物，他的心清净而没有妄想，由于得到此定而获得殊胜的利益；

不为生天而修梵行，智者行布施而不求回报，为了菩提之因而修梵行，因为得到离垢寂定的缘故；

不为求取王位而修持戒行，许多人为此而修梵行，他却是为了利益众生而求菩提，专心想要成就此定的缘故。

一切贪欲都已舍弃，身体不受恼害，永远不希求淫欲之事，断除淫欲以及高慢，由于得到这寂定的缘故；

他常常不被嗔恚所恼，嗔恼的秽心永不生起，常以慈心除去嗔怒，由于获得这殊胜的寂定；

他常常不被愚痴蒙蔽心智，这是由于以智慧断除了无明，获得无量无碍的智慧，由于得到此定而获得这些利益。

以不净观除去爱欲，以慈心除去嗔恚而无余，以智慧断除无明之网，获得这微妙之定而照耀世间。

没有睡眠与懈怠，远离烦恼的生起以及烦恼之地，永远得到解脱而没有杂秽，得到这三昧就获得这些利益。

不被悭贪所逼迫，心中常乐于惠施他人，一切都能施舍，全都给予安乐，这是因为这个人能受持此三昧的缘故。

具足威势，无与伦比，一切时常有大身力，一切世间没有能匹敌的，菩萨由于受持这殊胜之定的缘故。

他也能作转轮王，具足七宝，乘空而行，那时一切都归依奉事，这位智者获得这样的果报。

生于最殊胜、贤善、豪贵之家，资生之物与眷属都丰富完备，象、马、车乘以及辇舆，富饶的金银，具足众宝；

恒常生在贵族豪富之家，这样辗转生于殊胜之处，对佛、法、僧深深信乐，生在那里为众人所恭敬。

阎浮提内不信佛法的家庭，他都能使他们生起正信，能使他们建立菩提心，也使他们得到道果。

他得到无上菩提之后，转动无上的妙法轮；如果有人了知他所说之法，都能获得无生法忍。

菩萨常乐于慈爱养育，都能长养一切众生，恒常作无量殊胜的利益，开启众生的眼目，除去黑暗。

如果佛教导一位菩萨，无量百千亿的众生，都会在其中种下善根，听闻之后就发起菩提心。

那时的刹土不会空虚，因为有智者奉持佛法的缘故；佛子啊！菩萨随其所住之处，广泛利益无量的众生。

护持戒律无与伦比，受持梵行，在无量劫中清净三昧，对于禅定与解脱常常决定，这样的菩萨称为佛子。

他常常修习殊胜的神足，能前往无量的诸佛刹，在如来那里听闻正法，随所听闻的都能忆念。

如果是安住于总持的菩萨，能宣说无量的修多罗，又了知过去的一切众生，未来、现在也是如此。

## 七、业不至彼，因缘生灭

他晓悟众生的种种生死，也了达未来的情形；没有从此处去到彼处的人，推求其少分也不可得。

业既然不到彼处，寻求它也难以得到；具有大名称的菩萨，才能理解这一点。

【按】这里与前面一再强调的“业不失坏”看似相反，其实是同一件事的两面：业果丝毫不爽，但并没有一个实有的业从此世搬运到彼世，也没有一个实有的人从此处走到彼处。因缘相续而现，这就是“无有从此向彼者”。

最殊胜清净之心的人，安住于空寂，以无上的大乘运载一切众生。

他不思惟忆念、心存有众生之想；那具有大名誉的人，能悟入无生之法。

他虽然有所宣说，却不执取众生之想，悟入那境界的空性，安住于坚固的智慧。

显说这个三昧，是佛法所安住之处；不生起种种思想，也就是对男、女等的分别之想。

观察诸女人（了知其体性），而安坐于道场；安坐于道场之后，摧坏一切魔军。

对魔无所见，却降伏了一切魔众；不见魔女前来，到达我的所在之处。

安坐于道场时，遣除一切想；因为断除一切想的缘故，一切大地都震动；须弥山以及大海，十方也是如此。

在那十方世界，全都了知那些众生；菩萨的神通之力震动大地，六种震动的时候，就证得了菩提之道。

一切有为法，以及无为法，对这些法全都了达。只有说法的音声，而没有能了知者，这就是诸法之道；如果了知这一道，就称为世间解。

```
因缘故法生　因缘故法灭
因缘之体性　如实悉了达
```

大意是：诸法因为因缘而生起，也因为因缘而灭去；对于因缘的体性，全都如实了达。

如果修学一切法，对于空性之法能够究竟，便能了知诸法之道，穷尽一切法。

他所行的法道，菩萨寻求而不可得；凡是了知这一道的，就是不可思议的正觉。

如果了知一切道，就能获得究竟，远离恶道，能了知诸法之相。

## 八、成道说法与真大乘

安坐于道场之后，作大狮子吼，无边亿数世界中，言音全都充满。

又能震动那些佛刹，这位具有大名称的世雄，善于度化众生的人，就是圣者调御士。

已经证得无上菩提，从菩提树下起身，无量亿的大众中应当度化的都已度化，然后能作变化，化作无边的佛，前往游历诸世界，利益一切众生。

诸佛能安立无量亿的大众，诸应化如来为他们宣说最殊胜之法。

这就是真正的大乘，称为如来的智慧，能生起众生的信心，而作为成佛之因；

这是真正的大乘，是如来最妙之乘；恭敬于如来，也加倍恭敬于菩萨。

对佛深加恭敬，对法、僧也是如此，想要证得殊胜的菩提，他的心不下劣。

敬奉菩萨，尊重勇猛者，都能迅速登上正觉，不久成就如来。

在千个世界之中，菩萨都前往造访，见到牟尼世尊，菩萨无所畏惧。

以种种殊胜的宝末，遍散于大雄世尊身上，又糅杂以曼陀罗花，为了乐求菩提的缘故。

庄严这个世界，为了求取佛的功德；以宝网罗覆其上，遍及十方，悬挂种种殊胜美妙的幡，建立亿数宝幢宝盖，以无量种庄严，光饰这个世界。

变化出殊胜的台阁，以及美妙的宫殿，廊庑都端正美丽，众宝互相交错；楼窗以及宫室，都作半月形，并有各种香瓶等，都用美妙的珍宝装饰。

难以思议的诸菩萨，安住于这样的境际，演说美妙的言语，犹如恒河沙数。

你们不要心怀疑惑，那位佛具有自在之力，能生起增上的信心，迅速得以往生彼刹。

女人听到赞叹那个国土，如果能生起增上的信心，就能得到男子之身，能前往亿数佛刹。

那由他亿数佛刹中所有的种种供具，全部用来供养一切佛，也不及慈心的一分；常常修习戒、定、无量的禅定与解脱，修习三解脱门，就能迅速成为人中最上者。

在末法恶世之中，菩萨如果持戒，以常怀悲心之身供养佛，这种供养最为殊胜。

这个人就是供养了诸佛，过去以及现在、未来的最胜世尊。在恶世中持戒的人，十方诸佛都看见他。菩萨在末法之中护持佛的禁戒，这样的善男子能护持佛法。

（以下世尊以七言偈重宣上义：）

女人听闻赞叹那宝国，如果生起增上的信乐之意，便能获得男子聪慧之身，能前往游历亿数佛刹。

那由他亿数佛刹中，所有种种供养佛的器具，全部用来供养诸佛，也不及慈心的一少分；

修持禁戒以及三昧，并修习诸禅与四无量心，也修习三种解脱门，就能迅速成就世间无上的佛果。

以常怀悲心之身供养诸佛，这样的供佛在世间无与伦比。

如果有菩萨在那末代恶世之时不舍弃戒律，这个人就能供养一切佛，过去的诸佛以及现在、未来的最胜世尊。

如果有人在恶世中持守禁戒，十方诸佛都看见这个人。菩萨如果在以后的恶世中持守清净的禁戒，这是佛所赞叹的，这就是我的儿子，能护持佛法。

## 九、安隐德比丘燃臂供佛的本生

这时，佛告诉月光童子：“在过去无量无数、不可思议、旷远广大的阿僧祇劫以前，那时有一尊佛，名号叫声德如来、应供、正遍知、明行足、善逝、世间解、无上士、调御丈夫、天人师、佛、世尊。童子！那位声德如来把无量不可思议数的众生安置于无上正等正觉，使诸人天修习佛的事业之后，才入于无余涅槃。

“童子！那时有一位国王，名叫德音。那位国王在佛如来、应供、正遍知涅槃之后，为了供养声德如来，建造了八十四千万亿座塔，在每一座塔前点燃百千万那由他盏灯，以一切伎乐、香花、宝鬘、涂香、末香，又以一切衣服、宝盖、幢幡，都是为了供养诸佛如来，安置在塔所。

“那时德音王在如来舍利塔所献上供养之后，聚集了满八十百千万亿那由他的大菩萨众，供给他们一切乐具。这些菩萨都是大法师，善能说法，得到无量辩才，善能显示无量诸法的真实功德。童子！那时大众中有一位比丘，名叫安隐德，也在那法会中坐着；他年方二十左右，容颜光艳，头发乌黑，住于童真贤妙之行，从未受用过色欲之乐，刚刚受具足戒，正是第一个夏安居的时候。

“童子！那时德音王迎请大菩萨众，为了圆满六波罗蜜的菩萨藏、大陀罗尼、善巧方便与自在无碍，所以在那天夜里迎请大菩萨众在佛塔前举行法会。当时百千万那由他盏灯都炽盛明亮，打扫洒净殿堂屋宇，散布种种花朵，铺设种种美妙的衣服。

“那时德音王与后宫的妃后、宫女，以及辅相、城邑人民与诸眷属，以种种伎乐，手持涂香、末香、花鬘、衣服、宝盖、幢幡，全都出来供养佛塔；供养完毕之后，与八万宫人一起，为了听法的缘故，都登上高殿。那时，无量天人为了听法的缘故，也都来集会。

“那时，安隐德比丘见到百千亿那由他盏灯炽盛燃烧，遍照四方，观察大众法会，就这样想：‘我也修行大乘，乐求一切诸法体性平等无戏论三昧。如果我现在想要获得这个三昧，应当供养这位佛的庙塔。我现在要作这样的供养：使诸天、人、阿修罗等生起奇特之想，欢喜踊跃而得到法的光明，使我的供具映蔽那位国王所有的供具，使德音王以及宫人眷属见到我的供养都欢喜。’

“那时，安隐德菩萨见到大众在塔前为了听法而聚集，就在那天夜里，在佛塔前用布缠住右臂，用油涂上，为了供养佛的缘故而点燃它。当时安隐德菩萨安住于增上的信心，求取无上正等正觉，燃烧右臂之后，他的心没有异样，脸色也不改变。

【按】燃臂供佛的故事，与《法华经·药王菩萨本事品》同类，是大乘经中表现菩萨舍身、于身命无所吝惜的本生示现。这类记载意在显示证空者对色身毫无执著，以及以法为重的愿力，属于圣者的特殊示现，绝非一般修行人可以仿效之事。经中下文安隐德自己也说：“不以无身手，故名阙身分；若不持戒者，是名身分缺。”真正要学的，是持戒与知空。

“童子！那时安隐德比丘燃臂的时候，大地震动，臂上的光明映蔽了无量百千排灯烛，使它们都失去光照，以这手臂的光明遍照十方。那时，安隐德菩萨欢喜充满，就一切诸法体性平等无戏论三昧，以和雅美妙、辩才端正的言音辞句作成歌颂，使所有大众都普遍听到。那时，大众中有一万二千位忉利天子心生欢喜，设种种供养，都是为了法的缘故而来到这个法会。

“那时，德音王在高楼上，与后宫眷属、妃后、宫女一起，看见安隐德比丘燃烧右臂，熊熊的红色火焰遍照四方。见了之后，心中这样想：‘这位比丘必定获得了神足，才能作出这样稀有的变现，对于自己的身命毫不吝惜。’

“那时，德音王见到安隐德比丘稀有的神变，心生爱乐，以清净的信心以及自己善根之力的熏习资助，与诸后妃、八万宫女一起，从千肘高的殿上纵身投下，为的是想去见这位菩萨比丘。由于恭敬心与善根之力立即显现了果报，他们当即被天、龙、夜叉、乾闼婆、阿修罗、迦楼罗、摩睺罗伽所护持，没有让他们坠落受伤。由于天、龙、夜叉、乾闼婆、阿修罗、迦楼罗、摩睺罗伽护持之力的缘故，这位德音王以及后妃、宫女，虽然从高殿上落下，身心都没有受到损伤，也不疲倦，不恐怖。

“那时，德音王用两手抱住比丘的手臂而大声号哭，一切大众也都是这样，因为他们见到安隐德比丘燃烧他那如同瞻波花鬘般的臂膊，那手臂原本纤长如象王的鼻子；所有见到的人都惊奇赞叹，没有一个不呼喊叹息、悲泣流泪的。

“那时，安隐德比丘见到大王以及众人都悲泣懊恼，就问国王说：‘大王！为什么悲号流泪，以及大众都这样悲啼呢？’

“那时德音王以偈颂回答说：

“‘具大智慧的安隐德！聪慧殊胜的法师！见到你燃烧身体的一部分，因此我哀伤哭泣。

“‘你的容颜非常端妙，犹如炽盛的火聚；见到你毁坏身体，所以增加了我的忧恼。

“‘你燃烧右臂的时候，光耀遍照十方世界，映蔽了一切灯烛，星辰月亮也都不再显现。

“‘大地全都震动，你的心却毫不倾摇；我的心生起恭敬，知道你不是凡夫。

“‘从那千肘高的殿上，我与八万宫人一起，亲自投身而下，身体竟然没有任何伤患。

“‘善哉！你清净的智慧！善哉！你无上的心意！善哉！精进的大士！善哉！你成就了大信心！

“‘你燃烧身臂的时候，心中没有动摇异样，反而发起欢喜之心，并且宣说妙法。

“‘你犹如圆满的月亮，又如清净天空中的太阳，如同须弥山王一样端严美妙。

“‘我作这样的愿：愿我也圆满大精进，所以能捐弃所爱的身体，利益一切众生。

“‘我因为爱法而悲啼，我的喜乐广大无垢；但你已毁坏了身体，所以我极其忧恼。’

“受天人供养、具有无边殊胜辩才的安隐德，回答国王，就说了这样的偈言：

“‘不是因为没有身体或手臂，就称为身体残缺；如果不持戒，这才称为身体残缺。

“‘我已经用这臭秽之身供养了如来，那难以思议的福田，一切世间的宝塔。

“‘如果有人以充满三千大千世界的七宝之沙，在佛世尊那里为了菩提而布施；虽然有这样的布施供养，还有其他的供养胜过这个：如果能了知法空，便能舍弃身命。

“‘我现在说真实之语，大王！愿您仔细听，以及这里的大众，一切人都听我说：如果我确实决定能成就无上佛果，这话真实不虚，就让大地六种震动。’

“说这话的时候，大地便震动起来；见到这稀有之事，诸天都大为欢喜。人天欢喜之后，都发起了菩提心，无量难以思议的大众，都趣向无上的智慧。

“安隐德比丘利益一切大众，安置亿数众生于无上的智慧之中。

“（安隐德又说：）

```
以此实法言　推体皆无实
此语审不虚　令臂还如故
若此法审实　安隐名亦无
十方悉推求　空故不可得
诸法犹如响　声出于其中
求声不可得　如是知诸法
```

“大意是：以这真实之法而说：推求诸法的体性，都没有实在；如果这话确实不虚，就让我的手臂恢复如初。如果此法确实真实，连‘安隐’这个名字也是无有，在十方遍处推求，因为空的缘故而不可得。诸法犹如回响，声音从其中发出，寻求那声音却不可得，应当这样了知诸法。

【按】安隐德的“真实语”不是祈求神力，而是以空性之理为誓：若诸法推求皆无实，臂即复原。手臂复原，正是以此真实之理为根据。这与第二卷“诸方推名不可得”一偈呼应：连“安隐”之名也是推求不得的。

“‘彻底了达的人，对于空性无所畏惧；这个人的话真实，相火（执相之火）不能焚烧他。

“‘所有世间的众生，天、人、夜叉、龙，以一切智的威力，都使他们悟入寂定。

“‘人以及天所有的世间苦难，不退转者的威德，一切都能迅速摧坏。’

“说这话的时候，他的身臂恢复如本来一样，安隐德比丘的身相具足庄严。

“诸天千亿之数，住在清净的虚空中，以信心将曼陀罗花散在那位比丘身上，这些都是超过人间的花，遍满整个阎浮提。

“天女亿那由他之数，演奏伎乐，唱着歌咏，安隐德比丘作大狮子吼。

“牟尼如来世尊，使其余亿数佛土，各在自己的佛刹中，传说那位清净大士安隐德比丘的名号。

“比丘、比丘尼、清信士、清信女，天、龙以及夜叉、乾闼婆、紧那罗等，听到他决定之业，安隐而得以离垢，以信心求道的人，其数如恒河沙。

“安隐德比丘聪慧而得自在，为了佛的智慧而燃臂，却不为此忧愁。

“那人在千个佛刹中，变化身形多如恒河沙数，手臂的光明遍照，犹如劫末之火。

“降下种种香末，遍满一切国土；下至大地，上至诸天，都来聚集。

“以一切供养之具，庄严这个佛刹，地上充满真珠，供养安隐德；以一切众宝花朵，庄严这个佛刹，龙王降下美妙的真珠，供养安隐德；又以一切珍宝，装饰这个佛刹，龙王降下珍宝庄严，为了供养安隐德。

## 十、世尊结说本生

“最殊胜的释迦狮子，住在灵鹫山，在诸比丘面前作狮子吼：

“那时的安隐德就是我，德音王就是弥勒；在那千亿劫中，我们共同修行菩提之行。

“那时见到持戒者安隐德的智慧，无量的女人都变成了男子。

“诸佛都为他们授记，终究没有疑惑，他们迅速得以成就，证得世间的自然智慧。

“听闻此经之后，宣说决定的功德，对于自己（的功德）不生执著，应当修学这样的法。”

《月灯三昧经》卷第七终
