# 香巴道歌集（十二）唐东杰布

## 题解

由尼古玛直接摄受、持“近传”的大成就者唐东杰布：五部空行母为他取名之歌、给德列巴的自解脱大手印，以及心不死自解脱金刚歌。

本篇出自《吉祥香巴噶举道歌金刚句与证道歌汇编·闻即有义加持海》，由蒋贡康楚·罗卓泰耶（1813–1899）在匝扎仁钦扎汇编。全书汇集香巴噶举历代祖师的金刚句与证道歌，核心见修是“嘎乌玛大手印”，故归入大手印类目，按祖师分篇发布。叙述译为白话散文，道歌分行译为诗；疑难处加【按】，存疑处附藏文原文。凡涉及拙火、迁识、方便道等密法观修之处，须得灌顶并依具德上师口授方可修持，此译仅作文献阅读。

## 五部空行母为他取名
大成就者唐东杰布，由本智空行尼古玛亲自摄受，无人能与他相比，是香巴法“近传”的教敕持有者。他在后藏杰德塘修秘密行时，本智空行五部母答应为他成办一切所愿的事业，并为他取了与实义相符的名字：

住在杰德塘的
这位非常稀奇的人，
我们聚在这里的五位女子，
各给他起一个合乎实义的名字。

在周遍广大的大平原上，
证悟空性的瑜伽士，
像无畏的国王一样安住，
所以叫他“唐东杰布”——空原之王。

在平等离戏的山谷中，
具有显空无别之见、
离于取舍的疯人，
叫他“隆东疯人”——空谷疯人。

无论百味的饮食，
还是不净的秽物与呕吐物，
遇到什么都无利无害、能取其精华的人，
叫他“诸食取精者”。

无论遇到种种什么境缘，
都证悟为梦与回声，
压倒八法、平等一味的人，
叫他“诸缘一味者”。

轮回涅槃一切诸法，
虽然显现，却如水中之月，
深知它们无所凭依的人，
叫他“诸法无依者”。

这位无与伦比的瑜伽士，
为了增广无量的事业，
把众生引向安乐平原的
时候，如今已经到了。

——五部空行母如是赞叹。

【按】
1. “唐东杰布”，字面意为“空原之王”；“隆东疯人”，意为“空谷疯人”。五部空行母所取的名字，都是对他证悟的描述。
2. “近传”，指唐东杰布直接从尼古玛得法，绕过了中间的历代传承，所以比七宝传承“近”得多。
3. “诸法无依者”，原文 རྐྱགས་གཏད་མེད་པ，རྐྱགས་གཏད 字义为“依托、执着的凭据”，存疑。

## 给德列巴的自解脱大手印
这位至尊为智者持戒者德列巴，以金刚歌的形式宣说了自解脱大手印的教言：

孩子，听着，智者持戒者德列贝！
从前你被愚痴的黑暗遮蔽，
想修法时，心里却夹杂着八法。
要成办来世的大事，
就要照下面这样去做：

把今生的打算，一把甩掉；
对八法的贪执，彻底放下；
执着与顾情面，干净解开；
亲疏的关系绳索，一刀斩断。

拔出我执这根钉住三有的橛；
希惧的念头，松松地放开；
斩断对衣食二者的牵缠；
不要求大，要守住卑下之处。

出离的苦，欣然接受；
贪嗔与争胜之心，远远丢掉；
虚伪狡诈的恶念，赶出境外；
贪吃与装模作样，放回原处。

正直地守护三律仪与誓言；
傲慢自负与嗔怒，赶出去；
即使人人轻视你，也要修忍辱；
凡庸这个强敌，放它走吧。

在自心内调伏嗔恨；
舍弃积攒吝啬的念头；
让慈心与悲心依于心续；
对出世法与世间法的一切，
要以自己的心为证人。

如今若不成办这件大事，
以后再指望，也已无可指望。

在本然的境界中，松松地放开；
把迷乱的根基，从根拔断；
不散乱地看自己的心；
以不忘失的正念，紧紧抓住。
若自己不认识自己的面目，
即使苦苦挣扎，也只是白受折磨。

睡眠时若抓不住光明，
即使认识了心性，意义也不大；
中阴时若抓不住光明，
断要害的痛苦，会让你皮肉发抖；
自心若得不到自在，
即使修上一劫，也只是筋疲力尽。

前一个分别念已灭，
后一个尚未生起，豁然之间，
明而无分别的境界，
没有依托、离于根基的
当下鲜活的觉知——
这就是自心离戏的法身。
所显现的一切，都是自心；
自心离戏，就是法身。

所以，分别念是法身的妙力；
显现不必遮止，本已空。
无论生起什么、显现什么，都以正念守住，
松松地放开，彻底地放下。

若认出了自己的面目，就一再接续它；
不造作、不散乱，安住于本处。
离于来、去、生、灭、住，
这就是大手印。

把不散乱转为道用，最珍贵；
不费力地松坦护持，最珍贵；
就这样去修持吧。

我在无偏的国土中游历；
离于贪执的瑜伽士，
和绕着四大洲转的日月二者，
都没有闲坐休息的工夫啊！昂！

——如是宣说。

【按】
1. 本歌的语言非常口语化，大量使用藏语表示动作方式的状语，如“一把甩掉”“彻底放下”“一刀斩断”“松松地”“紧紧地”，译文尽量保留这种干脆利落的口吻。
2. “断要害的痛苦，会让你皮肉发抖”，字面为“肉发颤”，形容临死四大分离时的恐怖。
3. 末尾的“昂”，是语气词，有“就是这样”的意味。

## 心不死自解脱金刚歌
我以身、语、意三门恭敬，
向至尊上师佛陀祈请。

看似死亡的这个分别念，
自性本不成立，是本然的运行。
被称为会死的身与心，
是不死自解脱的大手印。

异熟的物质之身，没有死；
习气的梦境，又怎么会死？
心性自身的光彩，就是本尊身，
明空无执，如同水中月。

在本性空寂离戏之中，
没有病，也没有死，
没有涅槃，也没有轮回，
一切都是自心迷乱的妙力。

妙力的显现明然而无碍，
无碍融入无生的法界。
离于生、灭、住三者的
不死本智，真是稀有！

把体验安放在无执的境界中，
与一切行住坐卧融合而修。

谁这样长久熟习，
死亡便融入法身的法界，
中阴时成就胜者报身，
以化身引导众生。
具缘者们，修持吧。

——大成就者至尊的《不死自解脱》金刚语，完。
