# 见要摄

至尊那若巴 造　玛尔巴译师 译

## 题解

本篇出自德格版丹珠尔续部（རྒྱུད་འགྲེལ།）ཞི 函第244a叶第5行至第245b叶第3行，东北目录编号 D2304。全篇一百四十句，每句七个音节，另有礼敬与跋语。篇幅不长，所以把藏文原文全部保留在代码块中，按意义段落分开，每段后附汉译，疑难之处另以【按】说明。

梵文题名：Dṛṣṭi-saṃkṣipta-nāma（དྲྀཥྚི་སཾ་ཀྵིཔྟ་ནཱ་མ）。

藏文题名：ལྟ་བ་མདོར་བསྡུས་པ（见地略摄）。

【按】跋语说本篇是“至尊那若巴的《见要摄》”，由译师玛尔巴却吉罗卓翻译、校订。那若巴是帝洛巴的弟子、玛尔巴的上师，是噶举派大手印传承中最重要的印度祖师之一；玛尔巴是把那若巴的教法传入藏地的大译师。所以本篇是噶举派传承中极为直接的一份根本文献。

【按】本篇是一部简明扼要的大手印见地论，结构非常清楚：先依“一切法住于心”抉择世俗，再依“心住于虚空”抉择胜义（离四边戏论），再依“虚空无所住”抉择无二（现空无别）；然后说明心性是明而无分别的光明智慧，有客尘而本性清净；接着列举经续中如来藏、大乐、普贤父母、本来成佛、第四灌顶、俱生喜等种种名称，说明它们都指同一心性，轮回与涅槃、基道果都是它的不同分位；最后破斥外道与内道诸宗的偏执，说明见地正确则修行不误。

## 礼敬

```
རྡོ་རྗེ་མཁའ་འགྲོ་ལ་ཕྱག་འཚལ་ལོ། །
```

敬礼金刚空行！

## 正文

### 一、礼敬立宗

```
ཐམས་ཅད་མཁྱེན་ཉིད་སྐྱོབ་པའི་གཙོ། །འགྲོ་བའི་མགོན་ལ་ཕྱག་འཚལ་ལོ། །
ལུང་དང་རིགས་པའི་རྗེས་འབྲངས་ནས། །དངོས་དོན་བསྡུས་ཏེ་གཏན་ལ་དབབ། །
```

敬礼一切智者、救护者之主、众生的怙主！我随顺经教与正理，归纳实义而加以抉择。

【按】本篇的结构，依“抉择世俗—抉择胜义—抉择无二”的次第展开，每一步都以经中的一句话作结：“一切法住于心”“心住于虚空”“虚空无所住”。这三句话在大手印典籍中常被引用，出处这里不作考证。

### 二、抉择世俗：一切法不离心

```
སྣང་ཞིང་སྲིད་པའི་ཆོས་རྣམས་ཀུན། །རང་རིག་སེམས་ནི་གུད་ན་མེད། །
སྣང་ཞིང་གསལ་བ་ཡིན་པའི་ཕྱིར། །དཔེར་ན་རང་རིག་ཉམས་མྱོང་བཞིན། །
གལ་ཏེ་སེམས་དེ་མ་ཡིན་ན། །འབྲེལ་པ་མེད་ཕྱིར་མི་སྣང་ཐལ། །
དེ་ལྟར་ཀུན་རྫོབ་གཏན་ལ་དབབ། །ཆོས་ཀུན་སེམས་ལ་གནས་ཞེས་གསུངས། །
```

显现与存在的一切法，都不离自明之心而另有；因为它们是显现而明了的，譬如自明的体验一样。如果它们不是心，由于（与心）没有关联，就会有“不显现”的过失。像这样来抉择世俗。（经中）说：“一切法住于心。”

【按】这一段的论证是：凡是显现出来、被明了的，都不离能明了的心；如果显现之物与心毫无关系，就不可能被心所显现。所以在世俗层面，一切显现都可以抉择为不离自心。这是借用唯识的论证来抉择世俗，并不是主张心为实有，下一段随即抉择心本身离戏。

【按】“རང་རིག”（自明、自证），在这里指心自己明了自己的特性，也就是心的明分。

### 三、抉择胜义：心离一切戏论

```
ཆོས་ཀྱི་དངོས་གཞི་སེམས་ཉིད་དེ། །རིག་པ་བཞི་སོགས་ཀྱིས་དཔྱད་ཀྱང་། །
དངོས་པོ་སྒྲ་ཡི་ཆ་ཙམ་མེད། །དཔེར་ན་ནམ་མཁའི་པདྨ་བཞིན། །
དེ་ལྟར་ཡོད་པ་མ་གྲུབ་ཕྱིར། །མེད་པ་ཅུང་ཟད་གྲུབ་མི་འགྱུར། །
ཕན་ཚུན་ལྟོས་པ་ཉིད་ཀྱི་ཕྱིར། །ཚུ་རོལ་མ་གྲུབ་ཕ་རོལ་བཞིན། །
ཡོད་མེད་གཉིས་ཀ་མ་ཡིན་ཏེ། །སོ་སོ་ཉིད་དུ་བཀག་ཕྱིར་རོ། །
གཉིས་ཀ་མེད་པ་མ་ཡིན་ཏེ། །ཡོད་མེད་དངོས་སུ་འགལ་བའི་ཕྱིར། །
ལུས་ཅན་ཡང་ནི་མ་ཡིན་ལ། །ལུས་ཅན་མིན་པ་མི་སྲིད་ཕྱིར། །
དེས་ན་སྤྲོས་པ་ཐམས་ཅད་བྲལ། །དེ་ལྟར་དོན་དམ་གཏན་ལ་དབབ། །
སེམས་ནི་ནམ་མཁའ་ལ་གནས་གསུངས། །
```

诸法的根本就是心性。以四种正理等去观察，（心）作为实有之物，连一点点名言上的成分也没有，就像虚空中的莲花一样。这样，“有”既然不成立，“无”也就一点都不能成立，因为（有与无）彼此观待，就像此岸不成立，彼岸也就不成立一样。也不是“有无二者俱是”，因为（有与无）已经各别遮破了；也不是“二者俱非”，因为有与无是直接相违的。（它）不是有形质的，因为（与之相对的）无形质也不可能（成立）。所以，它远离一切戏论。像这样来抉择胜义。（经中）说：“心住于虚空。”

【按】“四种正理”（རིག་པ་བཞི），一般指观待理、作用理、证成理、法尔理。

【按】这一段是中观的“离四边”：心不是有、不是无、不是亦有亦无、不是非有非无，所以离一切戏论。“此岸不成立，彼岸也不成立”，比喻有与无相互观待而立，一方不成立，另一方也就不成立。

【按】第25、26句“ལུས་ཅན་ཡང་ནི་མ་ཡིན་ལ། ལུས་ཅན་མིན་པ་མི་སྲིད་ཕྱིར”，直译是“也不是有身者，因为非有身者不可能”，意思不很清楚，这里依离边的脉络读作：心不是有形质的，而与之相对的“无形质”也同样不能成立。这一读法是推定的。

### 四、抉择无二：现空无别

```
རང་རིག་སྤྲོས་བྲལ་དེ་ཉིད་ཀྱང་། །སྣང་ཞིང་སྟོང་ལ་སྟོང་ཞིང་སྣང་། །
དེ་ཕྱིར་སྣང་སྟོང་དབྱེར་མེད་དེ། །དཔེར་ན་ཆུ་ཡི་ཟླ་བ་བཞིན། །
དེ་ལྟར་གཉིས་མེད་གཏན་ལ་དབབ། །ནམ་མཁའ་ཅི་ལའང་མི་གནས་གསུངས། །
```

那自明而离戏的（心），显现而空，空而显现；所以显现与空性无二无别，就像水中的月亮一样。像这样来抉择无二。（经中）说：“虚空不住于任何处。”

【按】“显现而空，空而显现”，是大手印与大圆满中“现空双运”的核心表述。“水中月”比喻：月影清楚显现，却没有实体；虽然没有实体，却清楚显现。

### 五、心性光明，即是智慧

```
རང་བཞིན་སྤྲོས་བྲལ་དེ་ཉིད་ནི། །རིག་པ་ཡིན་ཕྱིར་གསལ་བའོ། །
རང་རིག་མིན་ཕྱིར་མི་རྟོག་སྟེ། །རང་རིག་རང་ལ་རྟོག་མི་སྲིད། །
རྣམ་པར་རྟོག་བྱ་མིན་པའི་ཕྱིར། །སེམས་དེའི་རང་བཞིན་མི་རྟོག་ཉིད། །
གསལ་བ་མི་རྟོག་ཡེ་ཤེས་ཏེ། །དཔེར་ན་བདེ་གཤེགས་ཡེ་ཤེས་བཞིན། །
དེས་ན་སེམས་ཉིད་འོད་གསལ་ལ། །སེམས་ནི་ཡེ་ཤེས་ཡིན་རྟོགས་ན། །
སངས་རྒྱས་གཞན་དུ་མི་བཙལ་གསུངས། །
```

那离戏的自性，因为是明觉，所以是明了的；因为是自明的，所以是无分别的——自明不可能对自己起分别，因为它不是分别的对象。所以，那心的自性就是无分别。明了而无分别的，就是智慧，就像善逝的智慧一样。所以，心性是光明的。（经中）说：如果了悟心就是智慧，就不必到别处去寻找佛。

【按】第38句德格版作“རང་རིག་མིན་ཕྱིར”（因为不是自明），与下一句“自明不可能对自己起分别”的论证不合，依文意疑是“ཡིན”（是）的讹误，这里读作“因为是自明的”。

【按】“明了而无分别”（གསལ་བ་མི་རྟོག），是大手印对心性的经典描述：心性既有明分（不是昏昧空白），又没有分别执著。这与前面《苦乐无二见》中“离正念的无念是迷误”的意思相通。

### 六、客尘与心性：一异甚深

```
འོན་ཀྱང་སེམས་དེ་གློ་བུར་གྱི། །རྣམ་རྟོག་དྲི་མས་ཉོན་མོངས་ཏེ། །
ཆུ་དང་གསེར་དང་ནམ་མཁའ་ལྟར། །གནས་སྐབས་དག་དང་མ་དག་གཉིས། །
རང་བཞིན་འོད་གསལ་སེམས་དེ་དང་། །གློ་བུར་རྣམ་རྟོག་དྲི་མ་གཉིས། །
གཅིག་གམ་ཐ་དད་གང་ཡིན་པ། །ཤིན་ཏུ་ཟབ་པ་ཆེན་པོ་ཉིད། །
ཤིན་ཏུ་ཟབ་ཕྱིར་མཁས་པས་དཔྱོད། །བཤད་པ་ཡོད་ཀྱང་མ་བྲིས་སོ། །
```

然而，那心被突然生起的分别之垢所染污，就像水、黄金与虚空一样，有清净与不清净两种分位。本性光明的心，与突然生起的分别之垢，二者是一还是异，这是极其甚深的问题。因为极其甚深，所以由智者去观察；虽然有（这方面的）解说，这里就不写了。

【按】“水、黄金、虚空”，是《宝性论》等论典中比喻心性本净而有客尘的常用譬喻：水本清而有泥浊，金本纯而有矿杂，虚空本净而有云翳。

【按】“心性与客尘是一是异，极为甚深，这里不写”，作者有意略而不谈，表示这一问题须依上师口授与亲证来了解。

### 七、心性的种种异名（一）

```
སྟོང་པ་དེ་ཉིད་རིག་པ་སེམས། །བྱང་ཆུབ་སེམས་ཀྱང་དེ་ཉིད་དོ། །
སངས་རྒྱས་རིགས་ཀྱང་དེ་ཉིད་ཡིན། །བདེ་གཤེགས་སྙིང་པོ་དེ་ཉིད་དེ། །
ཇི་བཞིན་པ་ཡི་རོ་མྱང་བས། །བདེ་བ་ཆེན་པོའང་དེ་ཉིད་ཡིན། །
གསང་སྔགས་ཞེས་པ་འདི་ཉིད་དོ། །ཐབས་དང་ཤེས་རབ་དེ་ཉིད་ལ། །
ཟབ་དང་རྒྱ་ཆེ་དེ་ཉིད་ཡིན། །ཀུན་བཟང་ཡབ་ཡུམ་དེ་ཉིད་དོ། །
ནང་སྟོང་དབྱིངས་དང་ཡེ་ཤེས་ལས། །ཡེ་སངས་རྒྱ་ཞེས་དེ་ལ་བྱ། །
```

那空性，就是明觉之心；菩提心也就是它；佛的种姓也就是它；善逝藏也就是它；由于尝到了如实的滋味，大乐也就是它；所谓“密咒”，就是这个；方便与智慧也在它上面；甚深与广大也就是它；普贤父母也就是它；由于内在的空性法界与智慧，称它为“本来成佛”。

【按】从这里开始，作者列举经续中对心性的种种称呼，说明它们都指同一个心性：菩提心、佛种姓、如来藏、大乐、密咒、方便智慧、深广、普贤父母、本来成佛等等。

【按】“ཀུན་བཟང་ཡབ་ཡུམ”（普贤父母）、“ཡེ་སངས་རྒྱ”（本来成佛）等，是宁玛派大圆满中常用的名词，出现在那若巴的著作中，值得注意；这或许反映这些名词在印度晚期密乘中已经通用，也可能与本篇在藏地的传译有关。这只是附记，不作推断。

### 八、心性的种种异名（二）：轮回涅槃皆依于它

```
དྲི་མ་དང་བཅས་རང་རིག་དེ། །དེ་ཡང་གཞན་ལ་མི་ལྟོས་ཕྱིར། །
རང་བྱུང་ཡེ་ཤེས་དེ་ཉིད་དོ། །འཁོར་བའི་དངོས་གཞི་དེ་ཉིད་དེ། །
མྱ་ངན་འདས་པའང་དེ་ཉིད་ཡིན། །དབུ་མ་ཆེན་མོའང་དེ་ཉིད་དོ། །
མཐོང་བར་བྱ་བ་དེ་ཉིད་དོ། །བསྒོམ་པར་བྱ་བའང་དེ་ཉིད་དོ། །
ཐོབ་པར་བྱ་བའང་དེ་ཉིད་དོ། །ཚད་མའི་བདེན་པའང་དེ་ཉིད་ཡིན། །
རྒྱུ་དང་ཐབས་དང་འབྲས་བུ་ཡི། །རྒྱུད་ནི་རྣམ་གསུམ་གྲགས་པ་དང་། །
གཞི་ལམ་འབྲས་བུར་གྲགས་པ་དང་། །དེ་ཉིད་ཀྱི་ནི་གནས་སྐབས་སོ། །
རྒྱུ་རྐྱེན་རྩ་བ་ཀུན་གཞི་དང་། །འཁོར་བ་ཇི་སྲིད་ཕུང་པོ་དང་། །
གཞན་དབང་ཤེས་པ་ལ་སོགས་གྲགས། །
```

那有垢的自明之心，也因为不依于他，所以就是自生智慧；轮回的根本是它，涅槃也是它；大中观也是它；所应见的是它，所应修的是它，所应得的也是它；量的真谛也是它。所说的因、方便、果三种续，以及所说的基、道、果，都是它的不同分位。因缘、根本、阿赖耶，乃至轮回期间的诸蕴、依他起的识等等，也都是对它的称呼。

【按】“因、方便、果三续”，是密续中常说的“三续”（因续、方便续、果续）；“基道果”是大手印、大圆满抉择的纲领。作者说这些都只是同一心性在不同分位上的名称。

【按】“有垢的自明心也是自生智慧”，意思是：即使在有垢的凡夫位，心性本身仍然不依他而自显，与佛的智慧本质无别。

### 九、有垢心性幻现轮回

```
ཨེ་མ་ཧོ། །སེམས་ཉིད་དྲི་མ་དང་བཅས་དེ། །
རྣམ་འཕྲུལ་འགྲོ་བ་དྲུག་ལ་སོགས། །ནམ་མཁའི་ཁམས་ཀྱི་མཐའ་ཀླས་པར། །
སྡུག་བསྔལ་འཁྲུལ་འཁོར་བསམ་ལས་འདས། །
```

奇哉！那有垢的心性，幻化为六道众生等等，遍满无边无际的虚空界，痛苦与迷乱的轮回，超出了思议。

### 十、无垢心性即是诸佛

```
རྣམ་རྟོག་དྲི་མ་དང་བྲལ་བའི། །རང་རིག་སྤྲོས་བྲལ་དེ་ཉིད་ནི། །
མི་གནས་མྱ་ངན་འདས་པ་ཡིན། །རྡོ་རྗེ་སེམས་དཔའ་འང་དེ་ཉིད་ཡིན། །
སངས་རྒྱས་དྲུག་པའང་དེ་ཉིད་དོ། །རིགས་དྲུག་པའང་དེ་ཉིད་དོ། །
འཇམ་དཔལ་གཞོན་ནུའང་དེ་ཉིད་ཡིན། །རྣམ་པར་སྣང་མཛད་དེ་ཡིན་ཏེ། །
ཆོས་ཀྱི་སྐུ་དང་བདེ་ཆེན་དང་། །ཟུང་འཇུག་ཅེས་པ་དེ་ཉིད་དོ། །
བཞི་པའི་དབང་ཡང་དེ་ཡིན་ཏེ། །ལྷན་ཅིག་སྐྱེས་དགའ་དེ་ཉིད་དོ། །
རང་བཞིན་དག་པའང་དེ་ཉིད་ལ། །དེ་ལ་སོགས་པ་མདོ་རྒྱུད་ལས། །
རྣམ་གྲངས་ཐ་སྙད་གྲགས་པ་རྣམས། །ཕལ་ཆེར་དེ་ལ་བརྟེན་པ་ཡིན། །
ཇི་ལྟར་རིགས་པར་སྦྱར་བར་བྱ། །
```

远离分别之垢的自明离戏之心，就是无住涅槃；金刚萨埵也是它，第六佛也是它，第六部也是它，文殊童子也是它，也是毗卢遮那；所谓法身、大乐与双运，就是它；第四灌顶也是它，俱生喜也是它，自性清净也是它。诸如此类，经续中所说的种种异名与名言，大多依于它而安立，应当如理地加以配合理解。

【按】“第六佛”“第六部”，指在五方佛（五部）之上的第六尊佛（第六部），一般指金刚持或金刚萨埵，代表五部的总集。

【按】“第四灌顶”（句义灌）与“俱生喜”，是无上瑜伽续中直指心性的灌顶与智慧。作者说它们都指同一心性。

### 十一、无垢心性幻现净土

```
ཨེ་མ་ཧོ། །སེམས་ཉིད་དྲི་མ་མེད་པ་དེའི། །
རྣམ་འཕྲུལ་གཟུགས་སྐུར་བསྡུས་པ་ཡི། །ཞིང་ཁམས་རྣམ་པར་དག་པ་དང་། །
དཀྱིལ་འཁོར་རྣམ་འཕྲུལ་ལ་སོགས་པ། །ངོ་མཚར་དངོས་གཞི་དེ་ཉིད་དེ། །
ནམ་མཁའི་མཐའ་ཀླས་ཁྱབ་པར་སྣང་། །
```

奇哉！那无垢心性的幻化，摄为色身的清净刹土与坛城幻化等等，稀奇的实事就是它，遍满无边的虚空而显现。

### 十二、破诸宗的偏执

```
རང་སེམས་དེ་ལ་རྨོངས་པ་ཡི། །ཕྱི་རོལ་མུ་སྟེགས་པ་དག་གིས། །
བདག་དང་གཙོ་བོ་ལ་སོགས་ཞེས། །གྲུབ་མཐའ་ལོག་པའི་རྒྱ་མཚོར་ཞུགས། །
རང་གི་སྡེ་པ་ཉན་ཐོས་དང་། །རང་རྒྱལ་སེམས་ཙམ་པ་དག་གིས། །
གཟུང་འཛིན་གཉིས་སུ་འཛིན་པ་དང་། །གཉིས་མེད་ཡང་དག་ཉིད་དུ་རྟོགས། །
གཞན་ཡང་རྣམ་བདེན་རྣམ་རྫུན་སོགས། །རྣམ་རྟོག་དྲ་བར་ཚུད་པར་འགྱུར། །
```

对自心愚昧的外道们，说“我”“主”等等，陷入了邪宗的大海。自宗中的声闻、缘觉与唯识派，执著能取与所取为二，或者把“无二（之识）”理解为真实（有）。此外，还有实相派、假相派等，都落入了分别的罗网。

【按】“བདག་དང་གཙོ་བོ”（我与主），指外道所立的神我与数论派的“自性”（主，pradhāna）。

【按】“把无二理解为真实”，是指唯识宗主张无二取的识是真实有，中观认为这仍是一种执著。“实相派、假相派”（རྣམ་བདེན་པ、རྣམ་རྫུན་པ），是唯识宗内部的两派。作者的立场是：一切宗见，只要执为实有，都落入分别之网。

### 十三、见地不错，修行乃正

```
དེ་ལྟར་ལྟ་བ་མ་ནོར་ན། །བསྒོམ་པ་དང་ནི་སྤྱོད་པ་དག། །
དངོས་དང་མཐུན་པས་བྱང་ཆུབ་ཐོབ། །དཀྱུས་བསྟན་པ་ཡི་རྟ་བཞིན་ནོ། །
ལྟ་བ་དངོས་དང་མ་མཐུན་ན། །བསྒོམ་དང་སྤྱོད་པ་འཁྲུལ་འགྱུར་བས། །
འབྲས་བུ་ཇི་བཞིན་མི་འཐོབ་སྟེ། །དམུས་ལོང་དམིགས་བུ་མེད་པ་བཞིན། །
```

像这样，如果见地没有错误，修与行就会与实相相符而获得菩提，就像被指示了跑道的马一样。如果见地与实相不相符，修与行就会迷乱，不能如实获得果位，就像没有靶子的盲人一样。

【按】这一段说明见地的重要：见地是修行的方向，见地正确，修与行才不会偏离。“被指示跑道的马”与“没有靶子的盲人”，是一正一反两个譬喻。

### 十四、谦辞与回向

```
དོན་དངོས་རྒྱ་མཚོ་ལྟར་ཟབ་པས། །ཁྲོན་པའི་སྦལ་འདྲ་བདག་གི་བློས། །
དཔྱོད་པས་གཏིང་རྙེད་ག་ལ་འགྱུར། །ནོངས་གྱུར་མཁས་ལ་བཟོད་པར་གསོལ། །
འདི་བྱས་དགེ་བ་གང་ཡིན་པས། །སྐལ་ལྡན་སྐྱེ་བོ་དམ་པ་ཡི། །
འཁྲུལ་པའི་དྲི་མ་རབ་སྤངས་ནས། །རྟོགས་པའི་ཤེས་རབ་སྐྱེ་བར་ཤོག། །
```

实义像大海一样深，以我这如井底之蛙的心智去观察，怎能探得其底？若有错误之处，请诸位智者宽恕。以作此论所生的一切善根，愿具缘的殊胜众生，彻底舍弃迷乱之垢，生起证悟的智慧。

## 跋语

```
རྗེ་ན་རོ་པའི་ལྟ་བ་མདོར་བསྡུས་པ་ཞེས་བྱ་བ་རྫོགས་སོ།། །།ལོ་ཙཱ་བ་མར་པ་ཆོས་ཀྱི་བློ་གྲོས་ཀྱིས་བསྒྱུར་ཅིང་ཞུས་པའོ།།
```

至尊那若巴的《见要摄》圆满。译师玛尔巴却吉罗卓翻译并校订。

## 通篇连读

敬礼一切智者、救护者之主、众生的怙主！我随顺经教与正理，归纳实义而加以抉择。

显现与存在的一切法，都不离自明之心而另有；因为它们是显现而明了的，譬如自明的体验一样。如果它们不是心，由于（与心）没有关联，就会有“不显现”的过失。像这样来抉择世俗。（经中）说：“一切法住于心。”

诸法的根本就是心性。以四种正理等去观察，（心）作为实有之物，连一点点名言上的成分也没有，就像虚空中的莲花一样。这样，“有”既然不成立，“无”也就一点都不能成立，因为（有与无）彼此观待，就像此岸不成立，彼岸也就不成立一样。也不是“有无二者俱是”，因为（有与无）已经各别遮破了；也不是“二者俱非”，因为有与无是直接相违的。（它）不是有形质的，因为（与之相对的）无形质也不可能（成立）。所以，它远离一切戏论。像这样来抉择胜义。（经中）说：“心住于虚空。”

那自明而离戏的（心），显现而空，空而显现；所以显现与空性无二无别，就像水中的月亮一样。像这样来抉择无二。（经中）说：“虚空不住于任何处。”

那离戏的自性，因为是明觉，所以是明了的；因为是自明的，所以是无分别的——自明不可能对自己起分别，因为它不是分别的对象。所以，那心的自性就是无分别。明了而无分别的，就是智慧，就像善逝的智慧一样。所以，心性是光明的。（经中）说：如果了悟心就是智慧，就不必到别处去寻找佛。

然而，那心被突然生起的分别之垢所染污，就像水、黄金与虚空一样，有清净与不清净两种分位。本性光明的心，与突然生起的分别之垢，二者是一还是异，这是极其甚深的问题。因为极其甚深，所以由智者去观察；虽然有（这方面的）解说，这里就不写了。

那空性，就是明觉之心；菩提心也就是它；佛的种姓也就是它；善逝藏也就是它；由于尝到了如实的滋味，大乐也就是它；所谓“密咒”，就是这个；方便与智慧也在它上面；甚深与广大也就是它；普贤父母也就是它；由于内在的空性法界与智慧，称它为“本来成佛”。

那有垢的自明之心，也因为不依于他，所以就是自生智慧；轮回的根本是它，涅槃也是它；大中观也是它；所应见的是它，所应修的是它，所应得的也是它；量的真谛也是它。所说的因、方便、果三种续，以及所说的基、道、果，都是它的不同分位。因缘、根本、阿赖耶，乃至轮回期间的诸蕴、依他起的识等等，也都是对它的称呼。

奇哉！那有垢的心性，幻化为六道众生等等，遍满无边无际的虚空界，痛苦与迷乱的轮回，超出了思议。

远离分别之垢的自明离戏之心，就是无住涅槃；金刚萨埵也是它，第六佛也是它，第六部也是它，文殊童子也是它，也是毗卢遮那；所谓法身、大乐与双运，就是它；第四灌顶也是它，俱生喜也是它，自性清净也是它。诸如此类，经续中所说的种种异名与名言，大多依于它而安立，应当如理地加以配合理解。

奇哉！那无垢心性的幻化，摄为色身的清净刹土与坛城幻化等等，稀奇的实事就是它，遍满无边的虚空而显现。

对自心愚昧的外道们，说“我”“主”等等，陷入了邪宗的大海。自宗中的声闻、缘觉与唯识派，执著能取与所取为二，或者把“无二（之识）”理解为真实（有）。此外，还有实相派、假相派等，都落入了分别的罗网。

像这样，如果见地没有错误，修与行就会与实相相符而获得菩提，就像被指示了跑道的马一样。如果见地与实相不相符，修与行就会迷乱，不能如实获得果位，就像没有靶子的盲人一样。

实义像大海一样深，以我这如井底之蛙的心智去观察，怎能探得其底？若有错误之处，请诸位智者宽恕。以作此论所生的一切善根，愿具缘的殊胜众生，彻底舍弃迷乱之垢，生起证悟的智慧。
