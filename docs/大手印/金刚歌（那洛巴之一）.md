# 金刚歌（那洛巴之一）

大阿阇黎那洛巴（Nāropa）造　据藏文译出

## 题解

《金刚歌》（梵 Vajragīti，藏 rdo rje'i glu）收于德格版丹珠尔续部释 ཞི 函第 152b 至 153a 页（东北目录 D2288）。紧接其后的 D2289、D2290、D2291 三篇，题名都是《金刚歌》，内容各自独立，所以本译分为四个文件，并在题名后注明作者以示区别。本篇的跋语说是"大阿阇黎那洛巴"所作，没有译者跋语。

全篇只有八句偈，以"疯人把石头、木头看成黄金"为喻，说分别念如同魔祟，使人刹那刹那被束缚，并劝人以具足慈悲的智慧来摧毁分别念。

**与前译的关系：**本篇以前没有译过，与已译篇目没有重复。紧接着的 D2289 也是那洛巴所作，主题相同（分别念的束缚与智慧的对治），可以连读。

体例：本篇很短，依本译的体例，保留藏文原文于代码块中，按意义单元译出，最后附通篇连读；补的字放在方括号中，存疑之处以"【按】"说明。

## 正文

```
རྣམ་པར་རྟོག་པའི་གདོན་ཆེན་པོས། །
ཟིན་པར་གྱུར་པའི་སྨྱོན་པ་དག །
རྡོ་ཤིང་སོགས་ལ་གསེར་དུ་མཐོང་། །
དེ་ལ་རིན་ཆེན་གསེར་ཡོད་མིན། །
```

被分别念这个大魔所附身的疯人们，会把石头、木头等等看成黄金；但那里面并没有珍贵的黄金。

【按】"大魔"（gdon chen po），"gdon"指使人发狂的魔祟、邪魅。这是说：被分别念所控制的人，就像被魔附身而发疯的人一样，把本来没有价值、没有实体的东西执为珍宝，即把虚妄的显现执为实有、可贪求。

```
རྣམ་རྟོག་གདོན་གྱི་རྗེས་འབྲངས་ནས། །
སྐད་ཅིག་སྐད་ཅིག་བཅིངས་པར་འགྱུར། །
ཤེས་རབ་སྙིང་བརྩེར་བཅས་པ་ཡི། །
དེ་གཞོམ་པ་ལ་འབད་པར་གྱིས། །
```

跟随着分别念之魔，就会刹那刹那被束缚。［所以，］要以具足慈悲的智慧，努力摧毁它！

【按】"具足慈悲的智慧"（shes rab snying brtser bcas pa），即智慧与慈悲（空性与大悲）双运；摧毁分别念，不是单以空性的智慧，而要与悲心相合。"慈悲"，藏文作"snying brtse"，是慈爱、悲悯之意。
