# 杀之结合不思议（帝洛巴不思议之五）

瑜伽自在帝洛巴说　据藏文译出

## 题解

本篇是帝洛巴"不思议"八篇口诀的第五篇（东北目录 D2309），跋语说是帝洛巴在恶种旃陀罗之城（རིགས་ངན་གཏུམ་མོའི་གྲོང་ཁྱེར），对一位屠夫所说，名为"杀之结合不思议"（གསོད་པའི་སྦྱོར་བ）。全篇约八十句。帝洛巴借屠夫每天所做的"杀"，开示密乘"度脱"的本义：以金刚智慧斩断我执，以悲心把众生的心识送往净土，使他们从痛苦之处解脱。第八节是全篇的见地核心："命"只对执著于相的人显现，对离相、具悲心的人则不然。

特别告诫：本篇是八篇中最容易被误解的一篇。篇中所说的"杀"，全部是象征语言，指的是以智慧斩断我执、轮回与烦恼，以及大成就者把心识迁往净土的度脱事业，绝不是世间的杀生。佛教一切乘的根本戒律都禁止杀生，本篇丝毫没有改变这一点。正如第八节所说，凡是还有相执的人，"命"对他就是真实的，杀生就是真实的恶业。帝洛巴对屠夫说法，用意是借他熟悉的事把他引向空性与悲心；传统上，屠夫听法之后，应当舍弃屠业。读者绝不可照字面理解、引用或效仿。

帝洛巴名下有八篇以"不思议"（bsam gyis mi khyab pa）为名的短篇口诀，在德格版丹珠尔续部释 ཞི 函中连续排列（第 246a 至 253a 页前后，东北目录 D2305 至 D2312）。第一篇之前有梵藏总题"大手印不思议"（梵 Acintyamahāmudrā，藏 phyag rgya chen po bsam gyis mi khyab pa），东北目录据此把第一篇编为 D2305。八篇各有独立的开头、礼敬与跋语，跋语都说是瑜伽自在帝洛巴在某地对某一种人所说，都没有译者的记载。八篇依次是：对瑜伽士说"自性不思议"，对威力者说"事业不思议"，对歌者说"音乐不思议"，对外道说"法性不思议"，对屠夫说"杀之结合不思议"，对吠陀师说"种种不思议"，对幻师说"事物不思议"，对娼女说"不思议大乐"。

这一组口诀的特点是"随类说法"：帝洛巴就每一种人所熟悉的行业与生活，把它转为认识心性的大手印之道。歌者的音声、屠夫的屠宰、幻师的幻术、娼女的欲乐，都被用作象征，指向同一个不可思议的心性。所以篇中凡是说到杀、欲、酒肉等，都是象征语言，绝不可照字面理解或效仿；涉及圆满次第风脉明点与事业手印的部分，只能在具德上师座前，依具足的灌顶与口授领受。

关于编号：所据的 Esukhia 电子版只在第一篇前标有 {D2305}，第二至第八篇没有单独的编号标记。本译依篇次顺序，把八篇依次配为 D2305 至 D2312，这一配属与东北目录通行的次序一致，但未能逐篇核对目录原书，读者须知。

体例：藏文原文全部保留在代码框中，按意义分节，每节后附汉译；凡标"存疑"的按语，表示本译对原文意思没有把握。藏文依 Esukhia 德格丹珠尔电子版，异文取第二读。

## 篇题

```
ཤན་པ་ལ་གདམས་པ་བཞུགས། །
```

对屠夫的教言。

## 一、赞叹与呼告

```
ཨེ་མ་སངས་རྒྱས་ཨེ་མ་ཆོས། །
ཨེ་མ་གཏུམ་པོ་མཛད་པ་ལེགས། །
ཨེ་མ་གསོད་པ་ཤིན་ཏུ་ཟབ། །
ཨ་ཨ་སྡུག་བསྔལ་གནས་ནས་བསྒྲལ། །
```

唉玛！佛！唉玛！法！唉玛！忿怒者的作为真是善妙！唉玛！"杀"是极为甚深的！啊啊，从痛苦之处度脱！

【按】"忿怒者"（གཏུམ་པོ），也是旃陀罗（屠宰、贱业种姓）一词的藏译，这里双关：既指忿怒本尊，也指本篇的听者屠夫。帝洛巴以屠夫熟悉的"杀"为象征，开示的是以智慧斩断我执与轮回，使众生"从痛苦之处度脱"。

## 二、金刚部的三昧耶

```
རྡོ་རྗེ་རིགས་ཀྱི་དམ་ཚིག་སྟེ། །
གསལ་ཞིང་དངས་པ་ཐུགས་ཀྱི་རིགས། །
རྣོ་ཞིང་རྩུབ་པས་འབིགས་པ་ཡང། །
གང་ལ་བསྣུན་པས་འཇོམས་པར་བྱེད། །
མ་སྐྱེས་རྡོ་རྗེ་ཡེ་ཤེས་ཀྱང། །
རྣོ་ཞིང་འབིགས་པའི་རང་བཞིན་ཏེ། །
བསད་ཅིང་ཕྲིན་ལས་དྲག་པོ་ཡིས། །
གདུག་པ་མ་ལུས་ཞི་བར་མཛོད། །
```

这是金刚部的三昧耶，明澈清净，是意的部类。锐利而粗糙，能够穿刺，击在哪里，就能摧毁哪里。不生的金刚智慧，也是锐利、能穿刺的自性；以"杀"与猛厉的事业，使一切恶毒者息灭。

【按】金刚部是密乘五部之一，以金刚为标志，象征能断一切烦恼的智慧，传统上与"意"相配。屠夫手中的刀锐利能穿刺，帝洛巴以此比喻不生的金刚智慧能斩断一切迷乱。

## 三、"杀"的对象

```
བརྩེ་ཞིང་མཁས་པའི་རྣལ་འབྱོར་པས། །
ཅི་ནུས་བསད་པའི་སྦྱོར་བ་བརྩམ། །
ངན་སོང་གསུམ་དུ་བཀའ་སྩལ་དང། །
བསྒྲལ་བའི་གནས་ལྔར་གྲགས་པ་དང། །
སྙིང་རྗེའི་ཡུལ་ནི་རྣམ་པ་གཉིས། །
ལས་དང་དགེ་བས་བསྡུས་པའོ། །
```

慈悲而善巧的瑜伽士，要尽力着手于"杀"的结合。［它的对象，］经中说是三恶趣，即著名的五种度脱之境，以及两种悲心之境，为业与善所摄。

【按】存疑。"五种度脱之境"（བསྒྲལ་བའི་གནས་ལྔ），密乘一般说"十种应度之境"，这里说五种，具体所指不明。"两种悲心之境，为业与善所摄"，所指也不确定，可能指因恶业而受苦者与具有善根者两类。本译只照字面译出。

## 四、度脱的目的：送往净土

```
རང་བཞིན་ཡེ་ནས་རྣམ་དག་ཀྱང། །
མ་རྟོགས་ཉོན་མོངས་དབང་གིས་ནི། །
ཁམས་གསུམ་སྡུག་བསྔལ་མྱོང་འགྱུར་ལ། །
བསད་པས་ཐར་བར་བྱ་ཕྱིར་རོ། །
དེ་ཡི་རིག་པ་འོག་མིན་ནམ། །
སངས་རྒྱས་ཞིང་ལས་མི་ལྡོག་པའི། །
གནས་སུ་ངེས་པར་བྱས་པས་ནི། །
ཡོན་ཏན་ལྡན་པའི་གནས་སུའོ། །
```

［众生的］自性本来清净，但因为没有证悟，被烦恼所控制，在三界中经受痛苦；为了以"杀"使他们解脱，把他们的明觉决定送往色究竟天，或者佛刹中不退转之处，也就是具足功德之处。

【按】这一节说明密乘"度脱"的本义：不是夺取生命，而是把心识迁往净土，使之不再退转。传统上说，能如此做的，只有已经证悟空性、具足大悲与能力的大成就者。

## 五、以悲心与智慧而"杀"

```
ཆོས་རྣམས་ཅི་ཡང་མིན་པ་ལས། །
སྙིང་རྗེས་བསད་པར་དམ་བཅས་ནས། །
ཆོས་ཀུན་འཛིན་པའི་ཤེས་རབ་ཀྱིས། །
ཇི་ལྟར་རྟོགས་ཤིང་གོམས་པ་ལས། །
ཡིག་འབྲུ་འོད་ཟེར་སྣ་ཚོགས་ཀྱིས། །
སྒྲིབ་པ་སྦྱང་ཞིང་གོ་འཕང་བསྒྲོད། །
སྔགས་དང་ཕྱག་རྒྱ་ལྡན་པ་ཡིས། །
རྒྱལ་བའི་ཐུགས་རྗེས་གསད་པར་བྱ། །
```

诸法什么都不是，从这里以悲心发誓去"杀"；以持一切法的般若，依照所证悟、所熟习的，以种子字的种种光芒，净除障碍，登上果位；具足真言与手印，以诸佛的悲心而"杀"。

【按】"诸法什么都不是"，是说"杀"的前提是证悟一切法空，没有能杀、所杀与杀的行为；在这种证悟中，以悲心为动机，以真言、手印、种子字光明为方法。全部是密乘观修的象征，须依灌顶与口授。

## 六、自利与利他圆满

```
དེ་ཡིས་ཆོས་ཀུན་དོན་གཅིག་ཅིང། །
དེ་རྩལ་སྒྲིབ་པའི་བག་ཆགས་ཆོམས། །
ཤེས་རབ་ཏིང་འཛིན་དམ་ཚིག་ཉེ། །
སྐྱེ་འགྱུར་དོགས་པ་མེད་པས་བསད། །
དེ་བསད་མཆོད་པའི་ཁྱད་པར་གྱིས། །
རྡོ་རྗེ་མཁའ་འགྲོ་ལ་སོགས་མཉེས། །
དེ་འོང་སེམས་ཅན་དོན་བྱ་སྟེ། །
སྡུག་བསྔལ་གནས་བསྒྲལ་བསོད་ནམས་ཚོགས། །
རང་སེམས་ཁྱད་པར་དམ་ཚིག་ཉེ། །
བདག་དོན་ཕུན་སུམ་ཚོགས་པའོ། །
ངན་འགྲོ་རྣམས་ཀྱི་སྒྲིབ་པ་སྦྱངས། །
བསད་པས་བྱང་ཆུབ་ལམ་ལ་བཀོད། །
གཞན་དོན་ལྷུན་གྱིས་གྲུབ་པའོ། །
```

由此，一切法同一义，它的力用摧毁障碍的习气。般若、等持与三昧耶相近，因为没有再投生的忧虑而"杀"。以"杀"的殊胜供养，使金刚空行等欢喜；那［众生］将会来利益众生。从痛苦之处度脱，是福德资粮；自心殊胜，三昧耶相近，是自利圆满。净除恶趣众生的障碍，以"杀"安置于菩提道上，是利他任运成就。

【按】存疑。"三昧耶相近"（དམ་ཚིག་ཉེ），"ཉེ"字面是"近"，意思不完全确定，可能是说与三昧耶相应。"因为没有再投生的忧虑"，大概是说被度脱者不会再堕恶趣。

## 七、无一不是方便

```
དེ་ལྟར་ཤེས་རབ་ཆེན་པོ་ཡིས། །
དངོས་འཛིན་རྡུལ་ཙམ་མ་དམིགས་ལ། །
ཐབས་སུ་མ་གྱུར་གང་ཡང་མེད། །
མཉམ་པར་ཤེས་ནས་ཅི་དགའ་གྱིས། །
ངང་ལས་མ་གཡོས་སྙིང་རྗེ་ཡིས། །
སྣ་ཚོགས་མཛད་པ་སྟོན་པར་བྱེད། །
```

这样，以大般若，对实有的执取连微尘许也不缘；没有任何东西不成为方便。了知了平等性，就随意而行；不离本然的状态，以悲心示现种种事业。

【按】"随意而行"，是对已经证悟平等性、"实执连微尘也不缘"的人而说的，前提非常高。下一节明说，"命"只对执相者显现；反过来说，凡是还执著于相、有实执的人，这里的一切都不适用。

## 八、命只对执相者显现

```
གསོད་པའི་སྦྱོར་བ་གོམས་པ་ཡིས། །
སྒྱུ་མ་ལྟ་བུའི་ཚུལ་ཤེས་ནས། །
ཡོད་མེད་དམིགས་པ་ལས་འདས་པས། །
ལོག་རྟོག་ཙམ་ལ་སྲོག་ཏུ་སྣང། །
སྲོག་ཀྱང་མེད་ལ་གཅད་བྱ་མེད། །
སྲོག་ནི་དངོས་པོར་ལྟ་བ་དང། །
མཚན་མར་ཞེན་པ་རྣམས་ལ་སྣང། །
དེ་ལྟར་མཚན་མ་བྲལ་བ་དང། །
སྙིང་རྗེའི་བློ་ཅན་རྣམས་ལ་མིན། །
```

熟习了"杀"的结合，了知如幻之理，超越了有与无的所缘，［那时就知道：］只是对颠倒分别，才显现为"命"；命也没有，也没有可断的。"命"只对那些把它看作实物、执著于相的人显现；对于这样离开了相、具有悲心之心的人，就不是这样。

【按】这一节是全篇的见地核心，也是最容易被误解的地方。帝洛巴说"命"只对执相者显现，是就胜义与证悟者的境界而说：对已经彻底离开一切相执的人，不存在一个实有的"命"被断除。但这句话的反面同样清楚：凡是还有相执、还有"我"与"他"的分别的人，"命"对他就是真实显现的，杀生对他就是真实的恶业。

【按】所以，这一节绝不是为杀生开脱。佛教的根本戒律禁止杀生，这一点在任何乘中都没有改变。帝洛巴对一位以屠宰为生的人说这些，用意是借他熟悉的事，把他引向证悟空性与生起悲心；传统上，屠夫听法之后，应当舍弃屠业。读者绝不可照字面理解。

## 九、以如幻之行度化众生

```
དེ་ལྟར་ཤེས་ལ་སྤོང་ལེན་ནམ། །
འཇུག་དང་རྩོལ་བས་ལེན་མི་འགྱུར། །
སྒྱུ་མ་ལྟ་བུའི་སྤྱོད་པ་ཡིས། །
དེ་མ་རྟོགས་པའི་འགྲོ་བ་རྣམས། །
མ་ལུས་རྒྱལ་བའི་ས་ལ་འགོད། །
```

这样了知之后，就不会以取舍、进入或勤作去执取；以如幻的行持，把一切没有证悟这一点的众生，都安置在佛地之上。

## 十、种种譬喻与大誓愿

```
གཏུམ་པོ་རང་གི་གནས་ན་འགྱིང། །
དཔའ་བོས་གཡུལ་ལས་རྒྱལ་བར་བྱེད། །
ནགས་ཀྱི་མུན་པ་མེ་ཡིས་བསྲེག། །
དུག་མཚོའི་སླེ་ལ་བདུད་རྩིས་མྱོས། །
སྔོན་གྱི་ཐུགས་དམ་ཆེན་པོ་ཡིས། །
འཇིག་རྟེན་འགྲོ་བ་མ་ལུས་པ། །
རྒྱལ་བའི་ཞིང་དུ་སྦྱོར་བས་ན། །
བསད་པའི་སྦྱོར་བ་ཤེས་པར་བྱོས། །
```

忿怒者在自己的处所昂然而立；勇士在战场上得胜；火焚烧森林中的黑暗；在毒海的岸边，以甘露而沉醉。以往昔的大誓愿，把世间一切众生都结合到佛刹之中，所以，要了知"杀"的结合。

【按】存疑。"忿怒者在自己的处所昂然而立"，可能是比喻智慧安住于本位，也可能指圆满次第中拙火安住于脐轮，所指不确定。第八篇也有类似的句子。"在毒海岸边以甘露沉醉"，是说在轮回烦恼之中，以智慧甘露而得安乐。

## 十一、自他一味

```
གཞི་རྩ་བྲལ་བའི་སྐད་ཅིག་ལ། །
ཡང་དག་སྒྱུ་མའི་ཚུལ་དུ་སྣང། །
བདག་དང་གཞན་གྱི་རང་བཞིན་རྣམས། །
རྣམ་དག་དབྱིངས་སུ་ཚུལ་གཅིག་གོ། །
```

在离开根基与根本的刹那，真实如幻地显现；自与他的自性，在清净的法界中，同为一味。

【按】最后两句收归全篇：所谓能杀与所杀、自与他，在清净法界中本来一味。真正被"杀"的，是把自他执为实有的执著。

## 跋语

```
རྣལ་འབྱོར་གྱི་དབང་ཕྱུག་ཏིལླི་པས། །
རིགས་ངན་གཏུམ་མོའི་གྲོང་ཁྱེར་དུ་ཤན་པ་ལ་གདམས་པ་གསོད་པའི་སྦྱོར་བ་བསམ་གྱིས་མི་ཁྱབ་པ་ཞེས་བྱ་བ་ཨི་ཐི། །
```

瑜伽自在帝洛巴在恶种旃陀罗之城中，为一位屠夫所说的教言，名为《杀之结合不思议》。如是。

## 通篇连读

唉玛！佛！唉玛！法！唉玛！忿怒者的作为真是善妙！唉玛！"杀"是极为甚深的！啊啊，从痛苦之处度脱！

这是金刚部的三昧耶，明澈清净，是意的部类。锐利而粗糙，能够穿刺，击在哪里，就能摧毁哪里。不生的金刚智慧，也是锐利、能穿刺的自性；以"杀"与猛厉的事业，使一切恶毒者息灭。

慈悲而善巧的瑜伽士，要尽力着手于"杀"的结合。［它的对象，］经中说是三恶趣，即著名的五种度脱之境，以及两种悲心之境，为业与善所摄。

［众生的］自性本来清净，但因为没有证悟，被烦恼所控制，在三界中经受痛苦；为了以"杀"使他们解脱，把他们的明觉决定送往色究竟天，或者佛刹中不退转之处，也就是具足功德之处。

诸法什么都不是，从这里以悲心发誓去"杀"；以持一切法的般若，依照所证悟、所熟习的，以种子字的种种光芒，净除障碍，登上果位；具足真言与手印，以诸佛的悲心而"杀"。

由此，一切法同一义，它的力用摧毁障碍的习气。般若、等持与三昧耶相近，因为没有再投生的忧虑而"杀"。以"杀"的殊胜供养，使金刚空行等欢喜；那［众生］将会来利益众生。从痛苦之处度脱，是福德资粮；自心殊胜，三昧耶相近，是自利圆满。净除恶趣众生的障碍，以"杀"安置于菩提道上，是利他任运成就。

这样，以大般若，对实有的执取连微尘许也不缘；没有任何东西不成为方便。了知了平等性，就随意而行；不离本然的状态，以悲心示现种种事业。

熟习了"杀"的结合，了知如幻之理，超越了有与无的所缘，［那时就知道：］只是对颠倒分别，才显现为"命"；命也没有，也没有可断的。"命"只对那些把它看作实物、执著于相的人显现；对于这样离开了相、具有悲心之心的人，就不是这样。

这样了知之后，就不会以取舍、进入或勤作去执取；以如幻的行持，把一切没有证悟这一点的众生，都安置在佛地之上。

忿怒者在自己的处所昂然而立；勇士在战场上得胜；火焚烧森林中的黑暗；在毒海的岸边，以甘露而沉醉。以往昔的大誓愿，把世间一切众生都结合到佛刹之中，所以，要了知"杀"的结合。

在离开根基与根本的刹那，真实如幻地显现；自与他的自性，在清净的法界中，同为一味。
