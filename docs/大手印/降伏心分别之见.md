# 降伏心分别之见

阿阇黎甘噶拉、美卡拉 传　阿阇黎拉克什米 说

## 题解

本篇出自德格版丹珠尔续部（རྒྱུད་འགྲེལ།）ཟི 函第47b叶第4行至第48a叶第4行，东北目录编号 D2433。全篇四十六句，每句七个音节，以“唉稀奇啊美果，心中不要怀疑；稀奇啊阿瓦都底巴，心中的怀疑有什么用”为叠句。篇幅很短，所以把藏文原文全部保留在代码块中，按段落分开，每段后附汉译，疑难之处另以【按】说明。

梵文题名：Citta-kalpa-parihāra-dṛṣṭi-nāma（ཙིཏྟ་ཀལྤ་པ་རི་ཧ་ར་དྲྀཥྚི་ནཱ་མ）。

藏文题名：སེམས་ཉིད་ཀྱི་རྟོག་པ་འཇོམས་པའི་ལྟ་བ（摧破心之分别之见）。

【按】跋语说本篇是“由甘噶拉（ཀཾ་ཀ་ལ）与美卡拉（མེ་ཁ་ལ）传下，阿阇黎拉克什米（ལཀྵ་མཱི）所说”。依藏传成就者传记，甘噶拉（Kanakhalā）与美卡拉（Mekhalā）是一对姊妹成就者，是黑行者（卡纳巴）的弟子，列于八十四大成就者中；拉克什米大概是女成就者拉克什明伽拉（Lakṣmīṅkarā）。这些对应只是依名字推定，跋语没有更多说明，也没有记载译者。

【按】本篇的特点是通篇用“颠倒语”：断首者折斧、青蛙吞象、石女生子、盲人指路、哑巴说话、老鼠追猫等等。这是印度密乘道歌中常见的隐语写法，用违反常识的意象来打破分别心，显示心性的体验不可思议、不可言说。全篇的点题之句是最后的“心的体验，谁也不能说出”。

## 正文

### 第一段：断首者折斧，蛙吞象，柴发笑

```
མར་སར་མགོ་བོ་བཅད་བ་ཡིས། །སྟ་རེའི་སོ་ནི་འཆག་པར་བྱེད། །སྦལ་པས་གླང་པོ་མིད་པར་འགྱུར། །ཀྱེ་མ་ཤིང་ཐུན་དགོད་པར་བྱེད། །
ཀྱེ་མ་ངོ་མཚར་མེ་གོ་ཀྱེ། །སེམས་ལ་ཐེ་ཚོམ་མ་བྱེད་ཅིག། །མཚར་ན་ཨ་བ་དྷཱུ་ཏཱི་པ། །སེམས་ལ་རྟོག་པ་མ་བྱེད་ཅིག། །
```

在酥油地上被砍去头颅的人，反倒使斧刃崩折；青蛙把大象吞了下去；唉！木柴在哈哈大笑。唉，稀奇啊，美果！心中不要怀疑；稀奇啊，阿瓦都底巴！心中不要分别。

【按】本篇通篇用“颠倒语”写成：断首者折斧、青蛙吞象、木柴发笑、虚空生花、石女生子、蜜蜂抬象、盲人指路、哑巴说话、老鼠追猫、醉驴吓跑大象、猴子吃石头——全是世间不可能的事。这是印度密乘道歌中所谓“隐语”（sandhyā-bhāṣā）的一种写法，用种种违反常识的意象，来打破分别心的惯性，表示证悟的境界超出常情、不可思议。每一个意象背后是否另有确定的密意，原文没有解释，这里只照字面译出，不作逐一配释。

【按】“མར་ས”，字面是“酥油之地”，也可能是“下方之地”（མར）的意思。所指不明，照字面译出。“断首”的意象，或许与跋语中所说的传承上师甘噶拉、美卡拉两位成就者有关：依藏传成就者传记，这两位姊妹成就者曾自断头颅以供养上师。这一联系只是推测。

【按】叠句中的“མེ་གོ”，这里音译为“美果”，可能是对人的称呼，或许就是跋语中的“美卡拉”（མེ་ཁ་ལ）的异写或简称；也可能另有意思。“ཨ་བ་དྷཱུ་ཏཱི་པ”（阿瓦都底巴），字面是“修阿瓦都底（中脉）的人”，也可以理解为“离一切的瑜伽士”（avadhūta），是对修行人的称呼。两个称呼都是呼格。

【按】本段叠句末句作“心中不要分别”（རྟོག་པ），其余各段多作“心中不要怀疑”（ཐེ་ཚོམ）或“心中的怀疑有什么用”，原文如此。

### 第二段：虚空生花

```
ཁོ་ཡིས་མ་བཤད་འདི་མ་གོ། །ནམ་མཁའ་ལས་ནི་མེ་ཏོག་འབྱུང་། །ཀྱེ་མ་ངོ་མཚར་མེ་གོ་ཀྱེ། །སེམས་ལ་ཐེ་ཚོམ་མ་བྱེད་ཅིག། །
མཚར་ན་ཨ་བ་དྷཱུ་ཏཱི་པ། །སེམས་ཀྱི་ཐེ་ཚོམ་ཅི་ཞིག་བྱ། །
```

他没有说，这个人也没有听懂；从虚空中生出了花朵。唉，稀奇啊，美果！心中不要怀疑；稀奇啊，阿瓦都底巴！心中的怀疑又有什么用呢？

【按】第9句“ཁོ་ཡིས་མ་བཤད་འདི་མ་གོ”，直译是“他未说、此未懂”，意思难以确定。可能也是一句颠倒语：说者无所说，听者无所闻，却有所领会；与下句“虚空生花”同样表示不可思议。这里照字面译出。

### 第三段：石女生子，天衣者哭

```
ཀྱེ་མ་མོ་གཤམ་བུ་སྐྱེས་ན། །ཁྲི་ཡང་གར་ནི་བྱེད་པར་འགྱུར། །རས་བལ་དཀོན་པར་ཐོབ་འགྱུར་བས། །ནམ་མཁའི་གོས་ཅན་ངུ་བར་བྱེད། །
ཀྱེ་མ་ངོ་མཚར་མེ་གོ་ཀྱེ། །སེམས་ཀྱི་ཐེ་ཚོམ་ཅི་ཞིག་བྱ། །མཚར་ན་ཨ་བ་དྷཱུ་ཏཱི་པ། །སེམས་ལ་ཐེ་ཚོམ་མ་བྱེད་ཅིག། །
```

唉！石女如果生了孩子，连床榻也会跳起舞来；因为难以得到棉布，身披虚空之衣的人在哭泣。唉，稀奇啊，美果！心中的怀疑又有什么用呢？稀奇啊，阿瓦都底巴！心中不要怀疑。

【按】“ནམ་མཁའི་གོས་ཅན”，“以虚空为衣者”，即裸形者，也是耆那教天衣派（Digambara）的称号。“因为难得棉布而哭泣”，可能是一句双关的讽刺：本以虚空为衣的人，却为没有布而哭。这是推解。

### 第四段：蜂抬大象，盲人指路

```
ཀྱེ་མ་གླང་ཆེན་ཁྲི་ལ་འདུག། །སྦྲང་བུ་གཉིས་ཀྱིས་འདེགས་པར་བྱེད། །དམུས་ལོང་ལམ་སྟོན་ངོ་མཚར་ཆེ། །ལྐུགས་པས་གཏམ་ནི་སྨྲ་བར་བྱེད། །
ཀྱེ་མ་ངོ་མཚར་མེ་གོ་ཀྱེ། །སེམས་ལ་ཐེ་ཚོམ་མ་བྱེད་ཅིག། །མཚར་ན་ཨ་བ་དྷཱུ་ཏཱི་པ། །སེམས་ཀྱི་ཐེ་ཚོམ་ཅི་ཞིག་བྱ། །
```

唉！大象坐在床上，两只蜜蜂把它抬了起来；盲人在指路，真是稀奇！哑巴在开口说话。唉，稀奇啊，美果！心中不要怀疑；稀奇啊，阿瓦都底巴！心中的怀疑又有什么用呢？

### 第五段：鼠追猫，醉驴吓象

```
བྱི་བས་བྱི་ལ་འདེད་པ་མཚར། །དེ་མཐོང་ངོ་མཚར་སྐྱེ་བར་འགྱུར། །བོང་བུ་མྱོས་པ་མཐོང་འགྱུར་བས། །གླང་པོ་རྣམས་ཀྱང་བྲོས་པར་བྱེད། །
ཀྱེ་མ་ངོ་མཚར་མེ་གོ་ཀྱེ། །སེམས་ལ་ཐེ་ཚོམ་མ་བྱེད་ཅིག། །མཚར་ན་ཨ་ཝ་དྷཱུ་ཏཱི་པ། །སེམས་ཀྱི་ཐེ་ཚོམ་ཅི་ཞིག་བྱ། །
```

老鼠追赶着猫，真是稀奇！看到这情景，就生起了惊奇。因为看见了喝醉的驴子，连大象们也都逃跑了。唉，稀奇啊，美果！心中不要怀疑；稀奇啊，阿瓦都底巴！心中的怀疑又有什么用呢？

【按】本段叠句中“阿瓦都底巴”写作“ཨ་ཝ་དྷཱུ་ཏཱི་པ”，“བ”与“ཝ”只是转写的不同，意思相同。

### 第六段：猴吃石头，心之体验不可说

```
ཀྱེ་མ་སྤྲེའུ་ལྟོགས་པ་ནི། །རྡོ་བ་ཁམ་གྱིས་ཟ་བར་བྱེད། །ཀྱེ་མ་སེམས་ཀྱི་ཉམས་མྱོང་ནི། །སུས་ཀྱང་བརྗོད་པར་ནུས་མ་ཡིན། །
ཀྱེ་མ་ངོ་མཚར་མེ་གོ་ཀྱེ། །སེམས་ལ་ཐེ་ཚོམ་མ་བྱེད་ཅིག། །མཚར་ན་ཨ་ཝ་དྷཱུ་ཏཱི་པ། །སེམས་ཀྱི་ཐེ་ཚོམ་ཅི་ཞིག་བྱ། །
```

唉！饥饿的猴子，一口一口地吃着石头。唉！心的体验，谁也不能说出来。唉，稀奇啊，美果！心中不要怀疑；稀奇啊，阿瓦都底巴！心中的怀疑又有什么用呢？

【按】“སེམས་ཀྱི་ཉམས་མྱོང་སུས་ཀྱང་བརྗོད་པར་ནུས་མ་ཡིན”，“心的体验，谁也不能说出”，是全篇的点题之句：前面种种颠倒语，都是在说明证悟心性的体验，超出语言与常识，不可言说，所以“心中不要怀疑、不要分别”。

## 跋语

```
སེམས་ཉིད་ཀྱི་རྟོག་པ་འཇོམས་པར་བྱེད་པ་ཞེས་བྱ་བ་ཀཾ་ཀ་ལ་དང་མེ་ཁ་ལ་ནས་བརྒྱུད་པ་སློབ་དཔོན་ལཀྵ་མཱི་ཡིས་གསུངས་པ་རྫོགས་སོ།། །
```

名为《摧破心之分别》，由甘噶拉与美卡拉传下，阿阇黎拉克什米所说，圆满。
