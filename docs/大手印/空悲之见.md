# 空悲之见

阿阇黎圣天 传　阿阇黎匝达巴 造

## 题解

本篇出自德格版丹珠尔续部（རྒྱུད་འགྲེལ།）ཟི 函第46b叶第2行至第7行，东北目录编号 D2430。全篇三十句，每句七个音节，以“悲心达玛鲁鼓声响稀奇，圣天于无所缘的王国中永无餍足”四句为叠句。篇幅很短，所以把藏文原文全部保留在代码块中，按段落分开，每段后附汉译，疑难之处另以【按】说明。

梵文题名：Śūnyatā-karuṇā-dṛṣṭi-nāma（ཤཱུ་ནྱ་ཏཱ་ཀཱ་རུ་ཎ་དྲྀཥྚི་ནཱ་མ）。

藏文题名：སྟོང་ཉིད་སྙིང་རྗེའི་ལྟ་བ（空性悲心之见）。

【按】跋语说本篇“由大阿阇黎圣天传下，阿阇黎匝达巴所造”。圣天（Āryadeva）是龙树菩萨的弟子，在藏传成就者的传说中也被列为成就者之一。“匝达巴”（ཙ་ཏ་བ）是音译，八十四大成就者中有一位名为 Catrapa（ཙ་ཏྲ་པ）的成就者，名字相近，但是否同一人无法确定。跋语没有记载译者。

【按】本篇的主旨是空性与悲心无二：观察三有显现为空，悲心的鼓声自然响起；意、气、根止息，无我无住；如月放月光，俱生智趣入心性；行持一切而无所缘。古孟加拉语《恰雅歌集》中有一首署名圣天的道歌，内容与本篇相近，本篇很可能是其藏译传本或同源的传本，但译者未作逐句对勘。

## 正文

### 第一段：观察三有，显现为空

```
མི་གཙང་བ་ཡི་སྲིད་པ་དང་། །འཇིག་རྟེན་པ་ཡི་སྤྱོད་པ་དང་། །རྣམ་པས་དཔྱད་ཅིང་བལྟས་པས་ན། །དངོས་པོ་སྟོང་པ་ཉིད་དུ་སྣང་། །
ཀྱེ་མ་སྙིང་རྗེ་ཌ་མ་རུ། །སྒྲ་སྒྲོགས་པ་ནི་ངོ་མཚར་ཆེ། །ཨཱརྱ་དེ་བ་དམིགས་མེད་པའི། །རྒྱལ་པོའི་སྲིད་ལ་ངོམས་པ་མེད། །
```

对于不净的三有，以及世间人的种种行为，以种种方式去考察、观看，一切事物便都显现为空性。奇哉！悲心的达玛鲁鼓，咚咚作响，真是稀奇！圣天在无所缘的王国之中，永无餍足。

【按】“མི་གཙང་བ་ཡི་སྲིད་པ”，“不净的三有”，指充满烦恼与痛苦的轮回。“རྣམ་པས་དཔྱད”，“以种种方式考察”，这里的“རྣམ་པ”可以理解为“种种方面”，也可以理解为“完全地”。

【按】“སྙིང་རྗེ་ཌ་མ་རུ”，“悲心的达玛鲁鼓”。达玛鲁（ḍamaru）是一种双面小手鼓，常为密乘瑜伽士所持。以悲心比作鼓声，意思是：在证悟空性的同时，悲心自然响起，遍及一切。这正是题名“空悲之见”的意思：空性与悲心无二。

【按】“ཨཱརྱ་དེ་བ”，即圣天（Āryadeva），是本篇所依托的传承上师，在叠句中出现，大概是以圣天的口吻来唱。跋语说本篇是“由大阿阇黎圣天传下”。

【按】“དམིགས་མེད་པའི་རྒྱལ་པོའི་སྲིད”，“无所缘的王国”，比喻离一切所缘、无所执著的证悟境界。“ངོམས་པ་མེད”，一般意思是“不满足”“无餍足”，这里译作“永无餍足”，意思可能是在这境界中受用无尽、永不厌倦。但“ངོམས”也有“炫示”之义，也可以读作“无所炫示”。另外，古孟加拉语《恰雅歌集》中署名圣天的道歌，相应之处的意思接近“无所希求而为王”。这里取较常见的读法，并列出另外的可能。

### 第二段：意、气、根皆不住

```
གང་དུ་ཡིད་དང་རླུང་དག་དང་། །དབང་པོ་གནས་པ་ཡོད་མིན་ན། །བདག་ནི་གང་དུ་འགྲོ་བ་དང་། །གང་དུ་གནས་པ་མ་ཤེས་སོ། །
ཀྱེ་མ་སྙིང་རྗེ་ཌ་མ་རུ། །སྒྲ་སྒྲོགས་པ་ནི་ངོ་མཚར་ཆེ། །ཨཱརྱ་དེ་བ་དམིགས་མེད་པའི། །རྒྱལ་པོའི་སྲིད་ལ་ངོམས་པ་མེད། །
```

在意、风息与诸根都不住的地方，我不知道自己到哪里去了，也不知道住在哪里。奇哉！悲心的达玛鲁鼓，咚咚作响，真是稀奇！圣天在无所缘的王国之中，永无餍足。

【按】“ཡིད་དང་རླུང་དག་དང་དབང་པོ”，“意、风息与诸根”，在圆满次第中，心与气是相互依存的，气息止息、诸根收摄时，分别心也随之止息。这几句描写的就是这种境界：意、气、根都不再运作，连“我”去了哪里、住在哪里都无从得知，即无我、无住的境界。

【按】前面已经提到，《恰雅歌集》中署名圣天的道歌，有与这几句意思相近的句子。本篇很可能就是那一首或其同源的传本，但两者的字句没有逐句对勘，这里只是附记，以备参考。

### 第三段：月光与俱生

```
ཟླ་བ་ལས་ནི་ཟླ་བ་ཡི། །འོད་ཟེར་ཡོངས་སུ་གསལ་བར་འབྱུང་། །ལྷན་ཅིག་སྐྱེས་པའི་རང་བཞིན་ནི། །དེ་ཉིད་དུ་ནི་འཇུག་པར་འགྱུར། །
ཀྱེ་མ་སྙིང་རྗེ་ཌ་མ་རུ། །སྒྲ་སྒྲོགས་པ་ནི་ངོ་མཚར་ཆེ། །ཨཱརྱ་དེ་བ་དམིགས་མེད་པའི། །རྒྱལ་པོའི་སྲིད་ལ་ངོམས་པ་མེད། །
```

从月亮之中，月亮的光芒完全明亮地放出；俱生的自性，也就趣入那（真性）之中。奇哉！悲心的达玛鲁鼓，咚咚作响，真是稀奇！圣天在无所缘的王国之中，永无餍足。

【按】“ཟླ་བ་ལས་ནི་ཟླ་བ་ཡི་འོད་ཟེར”，“从月亮中生出月亮的光芒”，比喻光明与心性本是一体，从心性中自然放出光明，并不是从外面来的；“俱生的自性趣入其中”，意思是俱生智与心性本来无二。这是依道歌通常的读法推定的。

【按】“ལྷན་ཅིག་སྐྱེས་པ”，“俱生”，是大手印的核心术语，指心的本性与生俱来、本自具足。

### 第四段：行持一切，自性无缘

```
ཨཱརྱ་དེ་བ་ཐམས་ཅད་སྤྱད། །སྤྱད་པས་རང་བཞིན་དམིགས་མེད་འགྱུར། །ཀྱེ་མ་སྙིང་རྗེ་ཌ་མ་རུ། །སྒྲ་སྒྲོགས་བ་ནི་ངོ་མཚར་ཆེ། །
ཨཱརྱ་དེ་བ་དམིགས་མེད་པའི། །རྒྱལ་པོའི་སྲིད་ལ་ངོམས་པ་མེད། །
```

圣天行持一切；由于行持，自性便成为无所缘。奇哉！悲心的达玛鲁鼓，咚咚作响，真是稀奇！圣天在无所缘的王国之中，永无餍足。

【按】“ཐམས་ཅད་སྤྱད”，“行持一切”，意思是瑜伽士不舍弃任何行为，在一切活动中修持；“由于行持，自性成为无所缘”，意思是在一切行持之中，不起执著，自然契入无所缘的自性。这是推解。

【按】最后一段的叠句中，“སྒྲ་སྒྲོགས་བ”的“བ”应是“པ”的异写，意思不变。
