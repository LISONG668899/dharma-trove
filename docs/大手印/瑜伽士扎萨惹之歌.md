# 瑜伽士扎萨惹之歌

瑜伽士扎萨惹造　据藏文译出

## 题解

本篇收于德格版丹珠尔续部释 ཟི 函第 10a 页（东北目录 D2372）。开头只有"敬礼吉祥佛陀"；跋语作"瑜伽士扎萨惹之歌，圆满"，没有记载译者。作者扎萨惹（梵 Prasara），生平不详；篇中提到"梅纪"，可能与梅纪巴一系有关。

全篇约十五句，共三段，主喻是"卖掉了大象，就安然睡去"：有财宝的人要守夜，放下一切执取的瑜伽士却自在无忧。三段依次说：卖象而眠；不问法与非法，自生自性不动；以梅纪之辨，远离无始以来的一切过失。全篇没有涉及具体的密法修持。

体例：藏文原文全部保留在代码框中，按段落分节，每节后附汉译；叠句照原文每次重复。凡标"存疑"的按语，表示本译对原文意思没有把握。藏文依 Esukhia 德格丹珠尔电子版。

## 礼敬

```
དཔལ་སངས་རྒྱས་ལ་ཕྱག་འཚལ་ལོ། །
```

敬礼吉祥佛陀！

## 一、卖象而眠

```
ཤིན་ཏུ་ངོ་མཚར་བདག་གིས་གཏམ། །
གླང་ཆེན་བཙོངས་ནས་གཉིད་ལོག་ལྟར། །
གང་ཞིག་ནོར་ཡོད་མེལ་ཚེ་བྱེད། །
ཀུན་ཁྱབ་དཔའ་བོ་པྲ་ས་ར། །
```

我的话真是稀奇：就像卖掉了大象之后，就安然睡去。凡是有财宝的人，都在守夜；周遍一切的勇士扎萨惹［却安然无忧］。

【按】全篇的主喻是"卖掉大象，安然入睡"：有财宝的人要守夜防贼，放下了财宝的人就可以安睡。比喻放下了一切执取的瑜伽士，没有什么需要守护，自在无忧。"凡是有财宝的人都在守夜——周遍一切的勇士扎萨惹却安然无忧"，是全篇的叠句。

【按】存疑。叠句中"却安然无忧"一语，原文没有，是本译依"卖象而眠"之喻补出的；原文只说"凡是有财宝的人都在守夜，周遍一切的勇士扎萨惹"，两句的关系也可以理解为对照以外的其他关系。

## 二、不问法与非法

```
ཆོས་དང་ཆོས་མིན་གཏམ་མི་འདྲི། །
རང་བྱུང་རང་བཞིན་གཡོ་བ་མེད། །
གླང་ཆེན་བཙོངས་ནས་གཉིད་ལོག་ལྟར། །
གང་ཞིག་ནོར་ཡོད་མེལ་ཚེ་བྱེད། །
ཀུན་ཁྱབ་དཔའ་བོ་པྲ་ས་ར། །
```

不去问法与非法的话语，自生的自性不动摇。就像卖掉了大象之后，就安然睡去。凡是有财宝的人，都在守夜——周遍一切的勇士扎萨惹［却安然无忧］。

【按】"不去问法与非法"，是说已经安住于自性的瑜伽士，不再纠缠于法与非法的分别。这是就证悟者的境界而说的，不是说可以不辨是非。

## 三、以梅纪之辨离一切过

```
རྣལ་འབྱོར་མཻ་ཏྲིའི་དབྱེ་ཤེས་པས། །
ཐོག་མེད་དུས་བསགས་སྐྱོན་ཀུན་བྲལ། །
གང་ཞིག་ནོར་ཡོད་མེལ་ཚེ་བྱེད། །
ཀུན་ཁྱབ་དཔའ་བོ་པྲ་ས་ར། །
```

瑜伽士以了知梅纪的分辨，远离了无始以来所积的一切过失。凡是有财宝的人，都在守夜——周遍一切的勇士扎萨惹［却安然无忧］。

【按】存疑。"མཻ་ཏྲིའི་དབྱེ་ཤེས"，本译直译为"梅纪的分辨"，"梅纪"可能指梅纪巴（Maitrīpa），即作者的上师或所依的传承；也可能指"慈"（梵 maitrī）。所指不能确定。
