# 大手印_香巴道歌集（十六）久美德千

## 题解

唐东杰布的后裔、大译师久美德千依尼古六法次第所作的祈请文《降大乐雨》。

本篇出自《吉祥香巴噶举道歌金刚句与证道歌汇编·闻即有义加持海》，由蒋贡康楚·罗卓泰耶（1813–1899）在匝扎仁钦扎汇编。全书汇集香巴噶举历代祖师的金刚句与证道歌，核心见修是“嘎乌玛大手印”，故归入大手印类目，按祖师分篇发布。叙述译为白话散文，道歌分行译为诗；疑难处加【按】，存疑处附藏文原文。凡涉及拙火、迁识、方便道等密法观修之处，须得灌顶并依具德上师口授方可修持，此译仅作文献阅读。

## 六法祈请文·降大乐雨
这是大成就者唐东杰布的侄孙、大译师久美德千所作的道歌，名为《六法祈请文·降大乐雨》：

那摩 希日 嘉纳 达基尼 古巴耶！

游空的主母、悲心者，
本智的主母尼古玛，
孩子以渴仰向您祈请，
请从离戏的法界中垂念。

善于开示大秘密坛城的母亲，
现在就授予我四喜的灌顶吧；

善于打开无生之门的母亲，
现在就以净除之法洗净我的罪障吧；

善于燃起“阿”字短音拙火的母亲，
现在就焚尽我浊垢的蕴与界吧；

善于从“杭”字挤出大乐的母亲，
现在就赐予我俱生的本智吧；

善于显示幻化自身觉受的母亲，
现在就拆毁我对贪嗔的执实吧；

在梦境中变化转现的母亲，
现在就斩断我沉睡迷乱的束缚吧；

令任运光明现起的母亲，
现在就驱散我愚痴的黑暗吧；

在临终时引领的母亲，
现在就带我去往游空的刹土吧；

摧毁中阴迷乱显现的母亲，
现在就赐予我不坏的报身吧！

——这是说法者久美德千所作的祈请。

【按】
1. 久美德千（འགྱུར་མེད་བདེ་ཆེན），唐东杰布的后裔，以译师著称，曾撰唐东杰布传。原文 དབོན，可指侄子或孙辈，此处译为“侄孙”，存疑。
2. 开头梵语 namaḥ śrī jñāna ḍākinī guptayai，意为“顶礼吉祥本智空行秘密母”，即尼古玛。
3. 底本英文小标题附注说，本篇又见于《尼古六法传承祈请文·降加持雨》。
4. 全篇依尼古六法次第：灌顶、前行净除、拙火（阿字与杭字的燃与滴）、幻身、梦境、光明、迁识、中阴，每偈都以“现在就……吧”作结，语气恳切急迫。所涉拙火等修法，须依灌顶与上师口授。
