# 毗瓦巴之歌（水中优钵罗）

大成就者毗瓦巴造　据藏文译出

## 题解

本篇收于德格版丹珠尔续部释 ཟི 函第 9a 至 9b 页（东北目录 D2369）。开头没有梵藏题名，只有"敬礼佛陀"；跋语作"毗瓦巴之歌，圆满"，没有记载译者。

关于题名：本站已有《金刚持毗瓦巴之歌》（D2356）与《道歌宝藏（毗瓦巴）》（D2280），为了区分，本篇依叠句加括号，题为《毗瓦巴之歌（水中优钵罗）》。

全篇约十五句，共四段，叠句是"优钵罗花在水中采摘，水也沾不上它——这样的大幻师，就是毗瓦巴"。这首歌以第三人称赞叹毗瓦巴，大概出自他的弟子或后人之手：世人说他是恶人，其实他有甚深的功德；他醉卧市集河边；他令恒河倒流；他以太阳为抵押喝酒，令外道神像崩裂。这些都是毗瓦巴传记中的著名事迹。

关于禁行的告诫：毗瓦巴饮酒、醉卧等行为，是大成就者已有稳固证悟之后的禁行，有特定的前提，读者只可了解，不可模仿。

体例：藏文原文全部保留在代码框中，按段落分节，每节后附汉译；叠句照原文每次重复。凡标"存疑"的按语，表示本译对原文意思没有把握。藏文依 Esukhia 德格丹珠尔电子版。

## 礼敬

```
སངས་རྒྱས་ལ་ཕྱག་འཚལ་ལོ། །
```

敬礼佛陀！

## 一、世人说恶，实有深德

```
ངན་པ་ངན་པ་འཇིག་རྟེན་ཀུན་སྨྲ་ཡང། །
གཅེས་པའི་ཡོན་ཏན་དྲི་མེད་ཟབ་མོ་ཡོད། །
ཨུཏྤལ་ཆུ་ནང་བཏུས་ན་ཆུས་མི་རེག། །
དེ་འདྲའི་མང་པོའི་སྒྱུ་མཁན་བི་རཱུ་པ། །
```

世间的人都说"恶人，恶人"，［其实他］有珍贵的功德，无垢而甚深。优钵罗花在水中采摘，水也沾不上它——这样的大幻师，就是毗瓦巴。

【按】"优钵罗花在水中采摘，水也沾不上它——这样的大幻师，就是毗瓦巴"，是全篇的叠句。优钵罗（ཨུཏྤལ）即青莲花，生于水中而不沾水，比喻毗瓦巴虽然行种种违背世俗的事，却不被染污。

【按】存疑。"མང་པོའི་སྒྱུ་མཁན"，本译译为"大幻师"，字面是"众多之幻师"，可能是说能现种种幻化的人。

## 二、市集河边，醉卧不知

```
ཚོང་དུས་དང་ནི་གྲོང་དང་ཆུ་འགྲམ་ནི། །
གང་དུ་ཕྱིན་ནས་ལུས་འགྱེལ་དེ་མི་ཤེས། །
ཨུཏྤལ་ཆུ་ནང་བཏུས་ན་ཆུས་མི་རེག། །
དེ་འདྲའི་མང་པོའི་སྒྱུ་མཁན་བི་རཱུ་པ། །
```

无论在市集、村落还是河边，到哪里，他身体倒下，自己也不知道。优钵罗花在水中采摘，水也沾不上它——这样的大幻师，就是毗瓦巴。

【按】这一段描写毗瓦巴醉卧街头的形象。依成就者传记，毗瓦巴原是那烂陀寺的住持，后来行种种违背戒律的禁行，饮酒食肉，被逐出寺院。这些都是大成就者的禁行，有特定的前提，不是一般修行人可以模仿的。

## 三、怒令恒河倒流

```
འཇིག་རྟེན་ངན་པར་སྨྲ་བ་དེ་རྫུན་ཡིན། །
ཁྲོས་པས་གངྒཱ་བབ་པ་རྒྱུན་ལས་བཟློག། །
ཨུཏྤལ་ཆུ་ནང་བཏུས་ན་ཆུས་མི་རེག། །
དེ་འདྲའི་མང་པོའི་སྒྱུ་མཁན་བི་རཱུ་པ། །
```

世人说他坏，那是谎言；他发怒时，能令恒河的流水倒流。优钵罗花在水中采摘，水也沾不上它——这样的大幻师，就是毗瓦巴。

【按】"令恒河倒流"，是毗瓦巴传记中的著名神迹之一：他要渡恒河，船夫索要渡资，他便令河水倒流而过。

## 四、以日为押，饮酒毁像

```
ཉི་མ་གཏའ་མར་བཅུག་ནས་ཆང་ནི་འཐུངས། །
ཨནྡ་འཇིགས་བྱས་བྷེ་མེའི་ས་ར་བཤིག། །
ཨུཏྤལ་ཆུ་ནང་བཏུས་ན་ཆུས་མི་རེག། །
དེ་འདྲའི་མང་པོའི་སྒྱུ་མཁན་བི་རཱུ་པ། །
```

他以太阳为抵押来喝酒；令安达恐惧，摧毁了比梅的萨惹。优钵罗花在水中采摘，水也沾不上它——这样的大幻师，就是毗瓦巴。

【按】"以太阳为抵押来喝酒"，是毗瓦巴最著名的传说：他在酒馆饮酒，以太阳为抵押，令太阳停驻天空不落，直到国王代他付了酒钱。

【按】存疑。"令安达恐惧，摧毁了比梅的萨惹"（ཨནྡ་འཇིགས་བྱས་བྷེ་མེའི་ས་ར་བཤིག），所指不明。毗瓦巴传记中有他令外道神像（如比玛湿婆之像）崩裂的故事，"比梅"可能即指此；"安达""萨惹"所指不确定，今一律音译。
