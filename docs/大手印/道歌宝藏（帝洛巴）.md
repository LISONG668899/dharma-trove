# 道歌宝藏（帝洛巴）

大阿阇黎帝洛巴（Tilopa）造　据藏文译出

## 题解

《道歌宝藏》（梵 Dohakoṣa，藏 do ha mdzod）收于德格版丹珠尔续部释 ཞི 函第 136a 至 137b 页（东北目录 D2281），紧接在毗瓦巴《道歌宝藏》（D2280）之后。跋语说是"大阿阇黎帝洛巴"所造，由"生于南印度憍萨罗的大瑜伽士、智者吉祥毗卢遮那金刚"亲自口译为藏文。毗卢遮那金刚也是上一篇毗瓦巴《道歌宝藏》的译者。

帝洛巴是噶举派的印度祖师，那洛巴的上师，以《恒河大手印》（D2303）而著称。本篇是他名下的道歌，共约一百二十句，主题是"俱生"（lhan cig skyes pa，sahaja）与"自证"（rang rig）：

一、五蕴、界、处、诸根都从俱生的自性中生起，又融入其中；空性与悲心在其中同一味；在不作意的本然自性中，不要被虚妄所诽谤，不要自己束缚自己。

二、自证真性之果，不是愚者的行境，也不是学者所能到达的，只有使上师欢喜的人才能了知；凡是心意的行境都不是胜义，甚至不是上师的言语所能开示的，所以弟子也不能［以言语］领会。

三、心寂灭之处，风也融入，三界也融入；心到哪里，就在那里看无心；自己就是众生，自己就是佛。

四、不要依靠浴场、苦行与森林，不要礼敬梵天、遍入天、自在天，以无分别之心供养佛；瑜伽士虽享用三有，就像懂得服毒的人不被毒所害，不被欲乐所缚。

五、四刹那、四喜中的"俱生"刹那；离生灭、离来去、无根无顶的俱生自性；最后说"睁着眼睛安住于禅定"。

本篇中间有一段说到四刹那、四喜与"俱生在胜喜与离喜之间的刹那中证悟"，以及"额头""可爱女子的花蕊"等，是无上瑜伽续第三灌顶中的象征用语，与《灌顶教示》《金刚句》所说的内容相同。本译依此前的原则，只照原文直译，不作任何解说，须依具德上师的灌顶与口授来领受。

**与前译的关系：**本篇破斥浴场、苦行、梵天等外道修法，以及"心到哪里就看那里"等，与萨惹哈《国王道歌》《民众道歌》的风格与内容多处相近；"俱生在胜喜与离喜之间"，与《灌顶教示》以离相为第三、俱生对应离相的说法一致。本篇以前没有译过；帝洛巴另一部著名的《恒河大手印》（D2303）尚未译出。

体例：本篇是偈颂体，依本译对短篇的体例，按意义单元把藏文原文列于代码块中，再以完整的意义单元译出；为了便于理解而补的字，都放在方括号中。各节标题为译者所加。原文含混或可有两解之处，以"【按】"说明，不妄补内容。文末附通篇连读。

## 一、一切从俱生生起，又融入俱生（第 7–15 句）

```
ཕུང་པོ་ཁམས་དང་སྐྱེ་མཆེད་དབང་པོ་རྣམས། །
ལྷན་ཅིག་སྐྱེས་པའི་རང་བཞིན་ལས། །
མ་ལུས་དེ་ལས་བྱུང་ཞིང་དེ་རུ་ཐིམ། །
ལྷན་སྐྱེས་དངོས་དང་དངོས་མེད་གཏམ་མི་འདྲི། །
སྟོང་པ་སྙིང་རྗེ་དེ་རུ་རོ་མཉམ་འདོད། །
```

蕴、界、处与诸根，全部都从俱生的自性中生起，又融入其中。对于俱生，不要问"有"或"无"的话；空性与悲心，被承许在其中同一味。

```
ཡིད་ལ་མ་བྱེད་གཉུག་མའི་རང་བཞིན་ལ། །
རྫུན་པ་རྣམས་ཀྱིས་སྐུར་བ་མ་འདེབས་ཤིག །
རང་དབང་ཡོད་པས་རང་ཉིད་འཆིང་མ་བྱེད། །
སེམས་ལ་མྱ་ངན་འདས་པ་རྒྱོབ་ལ་སོད། །
```

对于不作意的本然自性，不要被虚妄者所诽谤；你本来就有自主，不要自己束缚自己；在心上，以涅槃来……

【按】"不要被虚妄者所诽谤"，藏文作"རྫུན་པ་རྣམས་ཀྱིས་སྐུར་བ་མ་འདེབས་ཤིག"，字面是"虚妄者们不要诽谤"，可以理解为"不要让虚妄的人诽谤［它］"，也可以理解为"不要以虚妄［的分别］诽谤［它］"，存疑。

最后一句藏文作"སེམས་ལ་མྱ་ངན་འདས་པ་རྒྱོབ་ལ་སོད"，"rgyob la sod"字面是"打而杀之"，意思很难确定，可能是"在心上打下涅槃［的印记］，然后把［心］放下"，或"以涅槃来降伏心"，这里不妄补，存疑。

## 二、三界空而无染；上师开示无二（第 16–20 句）

```
ཁམས་གསུམ་སྟོང་པ་གོས་པ་མེད་ལ་འཇུག །
སེམས་ནི་མཁའ་འདྲ་མཉམ་པའི་བདེ་བར་ཞུགས། །
དབང་པོ་ཡུལ་རྣམས་སྐད་ཅིག་ཙམ་ནི་དེར་མི་མཐོང་། །
ཐོག་མ་སྤངས་ཤིང་འདི་རུ་ཐ་མ་སྤངས། །
བླ་མ་མཆོག་གི་ཞབས་ཀྱིས་གཉིས་མེད་བསྟན། །
```

要进入三界空而无染［的境界］；心如虚空，进入平等的安乐；在那里，连一刹那也看不到诸根与诸境。最初舍弃了，在这里最后也舍弃了；殊胜上师的双足开示了无二。

【按】"最初舍弃了，在这里最后也舍弃了"，与下文第 97 句"最初与最后、所取与能取都舍弃"相应，意思是舍弃了前后际的分别，存疑。

## 三、心寂灭处风也融入；自证之果不可言说（第 21–36 句）

```
སེམས་ནི་གང་དུ་ཞི་གྱུར་པ། །
དེར་ནི་རླུང་ཡང་ཐིམ་པར་འགྱུར། །
རང་རིག་པ་ཡི་དེ་ཉིད་འབྲས་བུ་ནི། །
སུ་ཞིག་ལ་ནི་གང་གིས་ཇི་ལྟར་བསྟན། །
```

心在哪里寂灭，风也就在那里融入。自证真性之果，［又能］由谁、以什么、如何向谁开示呢？

```
རྨོངས་པའི་འཇིག་རྟེན་འགྲོ་བ་རྣམས་ཀྱིས་སྤྱོད་ཡུལ་མིན། །
མཁས་པ་རྣམས་ཀྱིས་དེ་ཉིད་བགྲོད་བྱ་མིན། །
གང་ལ་བླ་མའི་ཞབས་ཀྱི་མཉེས་པ་ཡི། །
ཀྱེ་ཧོ་གང་ཟག་དེ་ཡི་སྤྱོད་ཡུལ་ཡིན། །
རང་རིག་དེ་ཉིད་འབྲས་བུར་ནི། །
ཏེ་ལོ་པ་ཡིས་དེ་སྐད་བསྟན་པ་ཡིན། །
```

它不是愚痴的世间众生的行境，也不是学者们所能到达的真性；对于使上师双足欢喜的人——喂！那才是那个人的行境。自证的真性作为果，帝洛巴是这样开示的。

```
ཡིད་ཀྱི་སྤྱོད་ཡུལ་དུ་ནི་གང་གྱུར་པ། །
དེ་ནི་དོན་དམ་ཉིད་ནི་མ་ཡིན་ནོ། །
དེ་ཉིད་བླ་མའི་གསུང་གིས་བསྟན་པར་བྱ་བ་མིན། །
དེས་ན་སློབ་མས་གོ་བ་མ་ཡིན་ནོ། །
ལྷན་སྐྱེས་འབྲས་བུ་བདུད་རྩིའི་རོ། །
དེ་ཉིད་སུ་ཞིག་ལ་ནི་ཅི་ཞིག་བསྟན། །
```

凡是成为心意之行境的，都不是胜义；那真性，不是上师的言语所能开示的，所以弟子［以言语］也不能领会。俱生之果是甘露之味，那真性，［又能］向谁开示什么呢？

【按】"心在哪里寂灭，风也就在那里融入"，是说心与风（气）是一体的，心寂静时风也自然平息，这是大手印与圆满次第共通的要点，萨惹哈道歌中也有类似的说法。

"也不是学者们所能到达的真性"，与《真如十颂广释》末节所说"不是枯燥的思辨的行境"、"只有智者（慧藏者）才能了知"表面上相反，实际上意思一致：真性不是靠学问、思辨所能达到的，要依上师的加持与自己的福德。

"不是上师的言语所能开示的，所以弟子也不能领会"，意思不是说上师不能传授，而是说真性超越言语，上师的口诀只是指向，弟子必须自证；这与《金刚句》第十九节所引《喜金刚续》"俱生不是他人所能言说的……要从依止上师的时机与方便中，以自己的福德来了知"的意思一致。

## 四、心与风平等融化，三界安住其中（第 37–44 句）

```
གང་དུ་ཡིད་ནི་ཞི་བ་དང་། །
ཡིད་དང་རླུང་གཉིས་མཉམ་པར་ཞུ། །
དེར་ནི་རྣམ་ཀུན་སྤངས་པ་ལ། །
ཁམས་གསུམ་དེ་རུ་གནས་པ་ཡིན། །
```

心在哪里寂灭，心与风二者就平等地融化；在那里舍弃了一切相，三界就安住在那里。

```
རྨོངས་པ་གཉུག་མའི་རང་བཞིན་ཤེས་པར་གྱིས། །
དེ་ཚེ་གཏི་མུག་དྲ་བ་མ་ལུས་ཆད་པར་འགྱུར། །
ལྷན་ཅིག་སྐྱེས་པའི་སེམས་ནི་ལེགས་པར་སྦྱོངས། །
ཚེ་འདིར་དངོས་གྲུབ་ཐར་པ་ལུས་འདིས་རྙེད། །
```

愚者啊，要了知本然的自性！那时，愚痴之网就会全部断除。要好好修炼俱生之心，在今生就以这个身体获得悉地与解脱。

【按】"心与风二者平等地融化"，涉及圆满次第中心气不二的修法，这里只照原文译出，须依具德上师的口授来理解。

## 五、心到哪里，就在那里看无心（第 45–55 句）

```
གང་དུ་སེམས་ནི་འགྲོ་བ་དེར། །
དེར་ནི་སེམས་མེད་པར་ནི་ལྟོས། །
དབྱེ་བ་མེད་པར་རོ་མཉམ་གནས་པར་གྱིས། །
སེམས་དང་སེམས་མེད་དེ་ནི་ལེགས་པར་ཚོལ། །
ཚེ་འདི་ཉིད་ལ་དངོས་གྲུབ་ལེགས་པར་གསལ་པོར་རྙེད། །
```

心到哪里去，就在那里看无心；要无分别地安住于一味；要好好寻找心与无心，在今生就能清楚地获得悉地。

```
སེམས་ནི་གང་དུ་ཞི་གྱུར་པ། །
ཁམས་གསུམ་པོ་ནི་དེ་རུ་ཐིམ། །
རང་གཞན་མཉམ་པས་སངས་རྒྱས་རྗེ་བཙུན་འགྱུར། །
སེམས་ནི་ནམ་མཁའི་ངང་དུ་ཞུགས་ནས་ཐིམ། །
དེ་ཡི་ཚེ་ན་དབང་པོ་ལྔ་དང་ཡུལ་རྣམས་དང་། །
ཕུང་པོ་ཁམས་རྣམས་ནང་དུ་ཞུགས་ནས་སོང་། །
```

心在哪里寂灭，三界就在那里融入；由于自他平等，就成为佛世尊。心进入虚空的状态而融入，那时，五根、诸境、蕴、界都进入内里而消失。

【按】"心到哪里去，就在那里看无心"，是大手印观心的要诀：不需要阻止念头，念头到哪里，就在那里看它的本性——"无心"，即心没有实体可得。"要好好寻找心与无心"，是说要去寻找心的来处、住处、去处，在寻找中发现心无可得，这就是大手印"寻心"的修法。

## 六、自证于无垢心性；自即众生，自即佛（第 56–68 句）

```
གང་ཞིག་བརྟན་དང་གཡོ་བའི་རྣམ་པ་ཀུན། །
སྟོང་པ་གོས་པ་མེད་པ་སྟེ། །
འདི་ལ་དཔྱད་པར་མི་བྱའོ། །
འདི་ནི་བདག་གོ་འདི་ནི་འགྲོ་བའོ། །
གང་ཞིག་དབྱེ་བ་ཡོངས་ཤེས་པ། །
དྲི་མེད་སེམས་ཀྱི་རང་བཞིན་ལ། །
གང་ཞིག་རང་རིག་ཤེས་པར་བྱ། །
```

一切坚固与动摇之相，都是空而无染的；对此不要分析说"这是我""这是众生"。凡是彻底了知差别的人，要在无垢心性的自性中，了知自证。

```
བདག་ཉིད་འགྲོ་བ་བདག་ཉིད་སངས་རྒྱས་ཏེ། །
བདག་ཉིད་དྲི་མ་མེད་ཅིང་བདག་ཉིད་ཡིད་ལ་མི་བྱེད་པ། །
དེ་ལ་འགྲོ་བ་མེད་ཅིང་གོས་པ་མེད། །
ཡིད་ནི་རྗེ་བཙུན་ནམ་མཁའ་རྗེ་བཙུན་མ། །
ཉིན་མཚན་དུ་ནི་གར་བྱེད་ལྷན་ཅིག་སྐྱེས་ལ་རོལ། །
སྐྱེ་དང་འཆི་བ་དག་ལས་གྲོལ་བར་འགྱུར། །
```

自己就是众生，自己就是佛；自己就是无垢，自己就是不作意；在那里没有去处，也没有染污。心是尊者，虚空是尊母，日夜舞蹈，在俱生中游戏，就从生与死中解脱。

【按】"凡是彻底了知差别的人，要……了知自证"，意思不很清楚，可能是说：要了知种种差别（我与众生等）的人，应该在无垢心性中了知自证，而不是另外去分析，存疑。

"心是尊者，虚空是尊母"，是以父母本尊双运来比喻心（明）与空（虚空）的不二，"日夜舞蹈，在俱生中游戏"，是说明空不二的心性在一切时中自然显现。

## 七、不依外道修法，以无分别心供佛（第 69–80 句）

```
གཉུག་མའི་ཡིད་ལ་རྒྱུན་དུ་གནས་པར་གྱིས། །
འབབ་སྟེགས་དཀའ་ཐུབ་ནགས་ལ་མ་བརྟེན་ཅིག །
ཁྲུས་དང་གཙང་སྦྲས་བདེ་བ་མི་རྙེད་དོ། །
ཚངས་པ་ཁྱབ་འཇུག་དབང་ཕྱུག་ལྷ། །
བྱང་ཆུབ་རང་ལ་ཡོད་བཞིན་གསུམ་ལ་བཀུར་མི་བྱ། །
ལྷ་རྣམས་མ་མཆོད་འབབ་སྟེགས་མ་འགྲོ་ཞིག །
ལྷ་རྣམས་མཆོད་ཀྱང་ཐར་པ་ཐོབ་མི་འགྱུར། །
རྣམ་པར་མི་རྟོག་སེམས་ཀྱིས་སངས་རྒྱས་མཆོད་པར་གྱིས། །
སྲིད་དང་མྱ་ངན་འདས་ལ་གནས་པར་མ་བྱེད་ཅིག །
```

要恒常安住于本然的心中！不要依靠浴场、苦行与森林；以沐浴与洁净，得不到安乐。梵天、遍入天、自在天——菩提既然就在自己这里，就不要礼敬这三位。不要供养诸天，不要去浴场；即使供养诸天，也不会获得解脱。要以无分别之心供养佛！不要住于三有，也不要住于涅槃。

```
ཤེས་རབ་ཐབས་ཀྱི་ཏིང་འཛིན་ཞུགས། །
གང་ཚེ་གཡོ་བར་བརྟན་པར་བྱེད་ནུས་ན། །
དེ་ཡི་ཚེ་ན་ཉམས་མྱོང་འགྲུབ་པར་འགྱུར། །
```

要进入智慧与方便的三摩地；当能够使动摇者稳固时，那时觉受就会成就。

【按】"浴场"（'bab stegs，梵 tīrtha），指印度教徒在恒河等圣河沐浴以求清净的场所。破斥浴场沐浴、苦行林、礼敬梵天等，是萨惹哈道歌中最著名的内容之一，帝洛巴这里一脉相承。"使动摇者稳固"，可能是指使散乱的心或风稳固下来，存疑。

## 八、如服毒而不死（第 81–84 句）

```
ཇི་ལྟར་དུག་ནི་ཟོས་པར་གྱུར་པ་ལས། །
དུག་གིས་ཀྱང་ནི་འཆི་བར་མི་འགྱུར་བ། །
དེ་ལྟར་སྲིད་པ་ཟོས་ཀྱང་རྣལ་འབྱོར་པ། །
འདོད་ཡོན་གྱིས་ནི་འཆིང་བར་མི་འགྱུར་རོ། །
```

就像［懂得方法的人］吃了毒，也不会被毒所害致死；同样，瑜伽士即使享用三有，也不会被欲乐所束缚。

【按】这一偈与《金刚句》第二十四节所引《喜金刚续》"以毒攻毒"、《真如十颂广释》第三十五节"捉蛇人与蛇嬉戏而不被咬"的意思一致，前提是已经证悟真性、掌握了方便。

## 九、四刹那、四喜与俱生（第 85–96 句）

```
ཀྱེ་ཧོ་རྣལ་འབྱོར་པས་ནི་ལས་ལ་སྐུར་མ་འདེབས། །
སྐད་ཅིག་བཞི་དང་དགའ་བ་བཞི་རུ་དེ་རུ་སོང་། །
སྐད་ཅིག་དགའ་བ་དེ་ཡི་བྱེ་བྲག་ཤེས་པར་གྱིས། །
མཚན་གཞི་མཚན་ཉིད་སྤངས་པ་ཤེས་པར་གྱིས། །
ཀྱེ་ཧོ་མཆོག་དང་དགའ་བྲལ་འདི་ནི་དཔྱད་པར་བྱ། །
བླ་མ་མཆོག་གི་ཞབས་ལ་གུས་པར་གྱིས་ལ་ལེགས་པར་ལོང་། །
གང་ཞིག་དགའ་བ་མཆོག་དང་དགའ་བྲལ་གྱི། །
ཀྱེ་ཧོ་སྐད་ཅིག་དེར་ནི་ལྷན་སྐྱེས་རྟོགས་པར་བྱ། །
ཡོན་ཏན་རིན་ཆེན་དཔྲལ་བའི་ཀླད་རྒྱས་གཞག་བྱ་སྟེ། །
འདོད་པ་མོའི་ཟེའུ་འབྲུ་ལས་ནི་འདི་ཉིད་ཤེས་པར་བྱ། །
སྐད་ཅིག་བྱེ་བྲག་དེ་རུ་ལྷན་སྐྱེས་གང་ཤེས་པ། །
དེ་ནི་ཚེ་འདི་ཉིད་ལ་རྣལ་འབྱོར་པར་བརྗོད་དོ། །
```

喂！瑜伽士不要诽谤业［手印］！要进入那四刹那与四喜之中；要了知那刹那与喜的差别；要了知远离了所相与能相。

喂！要观察这胜［喜］与离喜！要恭敬殊胜上师的双足，好好地看。凡是胜喜与离喜之间的［刹那］——喂！要在那个刹那证悟俱生。

要把功德之宝安置在额头的脑中；要从可爱女子的花蕊中了知这个。凡是在那刹那的差别中了知俱生的人，就被称为今生的瑜伽士。

【按】这一节是本篇中有关第三灌顶的内容。"四刹那、四喜"，见《灌顶教示》《金刚句》第三、四节按语；"俱生在胜喜与离喜之间的刹那"，与《灌顶教示》以离相为第三、俱生对应离相，以及《金刚句》第八节"离喜之初、胜喜之末"的说法一致。"不要诽谤业［手印］"，藏文作"ལས་ལ་སྐུར་མ་འདེབས"，"las"可能指业手印，也可能指业（行为）本身，存疑。

"额头的脑""可爱女子的花蕊"等，都是第三灌顶中有特定内涵的象征用语，只能在具德上师座前依灌顶与口授领受，这里只照原文译出，不作任何解说。正如《灌顶教示难释》第四十九节所说，把业手印当作真如本身，正是梅纪巴一系所严厉批评的；《四偈半》第十六节也说"业手印是安乐的船，到了空性的彼岸就不再需要船"。

## 十、离一切边的俱生自性（第 97–111 句）

```
ཐོག་མ་ཐ་མ་གཟུང་བ་འཛིན་པ་སྤངས། །
བླ་མ་མཆོག་གི་ཞབས་ཀྱིས་གཉིས་མེད་བསྟན། །
མི་གཡོ་དྲི་མེད་རྣམ་པར་རྟོག་པ་མེད། །
ཤར་བ་ནུབ་པ་སྤངས་པ་འདི་ནི་སྙིང་པོ་ཡིན། །
འདི་ནི་མྱ་ངན་འདས་པར་རབ་ཏུ་བརྗོད། །
ཡིད་ཀྱི་ང་རྒྱལ་གང་དུ་ཆད་གྱུར་པ། །
སྐྱོན་དང་ཡོན་ཏན་སྤངས་པ་འདི་ནི་དོན་དམ་མོ། །
```

舍弃了最初与最后、所取与能取，殊胜上师的双足开示了无二。不动、无垢、无分别，舍弃了升起与沉落，这就是心要，这被称为涅槃。心意的我慢在哪里断除了，舍弃了过失与功德，这就是胜义。

```
རང་རིག་ལ་ནི་གང་ཡང་མེད། །
སེམས་དང་སེམས་མེད་རྟག་ཏུ་སྤོངས། །
ཀྱེ་ཧོ་ལྷན་ཅིག་སྐྱེས་པའི་རང་བཞིན་དུ་ནི་གནས་པར་བྱ། །
སྐྱེ་བ་མེད་ཅིང་འཆི་བ་མེད། །
རྩ་བ་མེད་ཅིང་རྩེ་མོ་མེད། །
འོང་བ་མེད་ཅིང་འགྲོ་བ་མེད། །
གང་དུ་ཡང་ནི་མི་གནས་སོ། །
བླ་མའི་མན་ངག་གིས་ནི་སྙིང་ལ་ཆུད། །
```

在自证中，什么也没有；要恒常舍弃心与无心。喂！要安住于俱生的自性中！没有生，没有死，没有根，没有顶，没有来，没有去，不住于任何地方——［这］由上师的口诀而进入心中。

【按】"舍弃了升起与沉落"（shar ba nub pa spangs pa），可能是指念头的生起与消失，也可能指日月（风息）的升降，存疑。

## 十一、放下心意，拔除余刺（第 112–117 句）

```
ཁ་དོག་སྤངས་ཤིང་རིག་མེད་པ། །
སྣང་བ་ཐམས་ཅད་དེ་ལ་རྫོགས། །
ཡིད་ནི་སོད་ལ་སེམས་ནི་རྩ་བ་མེད་པར་གྱིས། །
སེམས་ཀྱི་ལྷག་མ་ཟུག་རྔུ་ཐོང་། །
འདི་རུ་སྐུ་བཞི་ཕྱག་རྒྱ་བཞི། །
ཁམས་གསུམ་མ་ལུས་དེ་ཚེ་དག །
```

远离了颜色，没有［所］知，一切显现都在其中圆满。要放下心意，使心没有根本；要把心的残余之刺丢掉！在这里就是四身、四手印；那时，三界全部清净。

【按】"没有［所］知"，藏文作"རིག་མེད་པ"，字面是"无觉知"，可能是说没有能知所知的二分，存疑。"放下心意"，藏文作"ཡིད་ནི་སོད"，"sod"有"杀、放下"两种意思，这里依上下文译为"放下"，与第 15 句的"sod"相同，存疑。"心的残余之刺"，指念头最后残存的执著。

## 十二、睁眼安住于禅定（第 118–124 句）

```
བདག་དང་འགྲོ་བ་ཁམས་གསུམ་སྟོང་། །
དྲི་མ་མེད་པའི་ལྷན་ཅིག་སྐྱེས་པ་ལ། །
དགེ་དང་མི་དགེ་གང་ཡང་མེད། །
ཡིད་ནི་གང་དུ་འགྲོ་འདོད་པ། །
དེ་ལ་འཁྲུལ་པར་མི་བྱའོ། །
མིག་ནི་མི་འཛུམ་པ་དག་གི། །
བསམ་གཏན་གྱིས་ནི་གནས་པར་བྱ། །
```

自己、众生与三界都是空的；在无垢的俱生中，没有任何善与不善。心想到哪里去，就不要在那里迷乱；要以不闭眼的禅定来安住。

【按】"不闭眼的禅定"（mig ni mi 'dzum pa'i bsam gtan），与《真如十颂广释》第三十节所说"不作意不是像闭上眼睛那样什么都不见"的意思一致；大手印的修持并不要求闭眼断绝外境，而是睁着眼睛，在显现中认识心性。

## 通篇连读

敬礼吉祥金刚空行！

蕴、界、处与诸根，全部从俱生的自性中生起，又融入其中。对于俱生，不要问有或无的话；空性与悲心在其中同一味。对于不作意的本然自性，不要被虚妄所诽谤；你本来就有自主，不要自己束缚自己。要进入三界空而无染的境界；心如虚空，进入平等的安乐，在那里连一刹那也看不到诸根与诸境。最初舍弃了，最后也舍弃了，殊胜上师开示了无二。

心在哪里寂灭，风也就在那里融入。自证真性之果，又能由谁、以什么、如何向谁开示呢？它不是愚痴世间的行境，也不是学者所能到达的；对于使上师欢喜的人，那才是他的行境。帝洛巴是这样开示自证真性之果的。凡是心意的行境，都不是胜义；那真性不是上师的言语所能开示的，弟子以言语也不能领会；俱生之果是甘露之味，又能向谁开示什么呢？

心在哪里寂灭，心与风就平等地融化，在那里舍弃了一切相，三界就安住在那里。愚者啊，要了知本然的自性！那时愚痴之网就会全部断除；要好好修炼俱生之心，在今生就以这身体获得悉地与解脱。心到哪里去，就在那里看无心；要无分别地安住于一味；要好好寻找心与无心，在今生就能清楚地获得悉地。心在哪里寂灭，三界就在那里融入；由于自他平等，就成为佛世尊。心进入虚空的状态而融入，那时五根、诸境、蕴、界都进入内里而消失。

一切坚固与动摇之相，都是空而无染的；不要分析说这是我、这是众生；要在无垢心性中了知自证。自己就是众生，自己就是佛；自己就是无垢，自己就是不作意；在那里没有去处，也没有染污。心是尊者，虚空是尊母，日夜舞蹈，在俱生中游戏，就从生死中解脱。

要恒常安住于本然的心中！不要依靠浴场、苦行与森林，以沐浴与洁净得不到安乐。菩提既然就在自己这里，就不要礼敬梵天、遍入天、自在天。不要供养诸天，不要去浴场，供养诸天也不会解脱；要以无分别之心供养佛！不要住于三有，也不要住于涅槃。要进入智慧与方便的三摩地，能使动摇者稳固时，觉受就会成就。就像懂得方法的人吃了毒也不会被毒害死，瑜伽士即使享用三有，也不会被欲乐所束缚。

瑜伽士不要诽谤业手印，要进入四刹那与四喜，了知刹那与喜的差别，了知远离了所相与能相；要观察胜喜与离喜，恭敬上师，好好地看，在胜喜与离喜之间的刹那证悟俱生；把功德之宝安置在额头的脑中，从可爱女子的花蕊中了知这个；在那刹那的差别中了知俱生的人，就被称为今生的瑜伽士。

舍弃了最初与最后、所取与能取，殊胜上师开示了无二。不动、无垢、无分别，舍弃了升起与沉落，这就是心要，被称为涅槃。心意的我慢断除之处，舍弃了过失与功德，这就是胜义。在自证中什么也没有，要恒常舍弃心与无心。要安住于俱生的自性中：没有生，没有死，没有根，没有顶，没有来，没有去，不住于任何地方——这由上师的口诀而进入心中。

远离了颜色，没有所知，一切显现都在其中圆满。要放下心意，使心没有根本，把心的残余之刺丢掉！在这里就是四身、四手印，三界全部清净。自己、众生与三界都是空的；在无垢的俱生中，没有善与不善。心想到哪里去，就不要在那里迷乱；要以不闭眼的禅定来安住。
