# 见修行果道歌

大婆罗门萨惹哈造　据藏文译出

## 题解

本篇梵名 Bhāvanādṛṣṭicaryāphaladohagītikā，藏名 lta sgom spyod pa 'bras bu'i do ha'i glu，即《见修行果道歌》，收于德格版丹珠尔续部释 ཟི 函第 3a 至 4a 页（东北目录 D2345）。跋语说是"阿阇黎萨惹哈巴所造"，没有记载译者。本站已译萨惹哈的《国王道歌》（D2263）、《王后道歌》（D2264），以及梅纪巴的《无尽宝藏圆满之歌广释》（D2257），可以互参。

全篇约六十句，以见、修、行、果四者为纲：

见（第一至三节）：种种事物就是自心，佛与众生如水与波；双运大手印乐明无念、如虚空、如水月、如哑巴做梦；本然不造作的心就是法身，以造作的心得不到瑜伽。

修（第四、五节）：以自身为山，收束诸根；散乱不必刻意舍弃，所遇即心即是本尊；分别生起时像棉絮一样放松；以自心看自心，忆念而无所忆念，没有想要修的欲念。

行（第六节）：像小孩、像蜜蜂、像狮子、像风；内具谨慎，外如疯人；以有利益的行持去行持。

果（第七、八节）：显现当下不成立就是大手印；不作意是大手印之道；不希求果而证悟；见、行、果无别而俱生。

本篇基本上是纯粹的大手印见修开示，没有具体的密法修持。唯第六节"像疯人一样行持"，属于印度成就者的禁行，须知其前提，不可模仿。

体例：藏文原文全部保留在代码框中，按意义分节，每节后附汉译；凡标"存疑"的按语，表示本译对原文意思没有把握。藏文依 Esukhia 德格丹珠尔电子版。

## 一、见：万法即自心，佛与众生不二

```
དངོས་པོ་སྣ་ཚོགས་རང་གི་སེམས་ཉིད་ཡིན། །
འཁོར་འདས་ཐམས་ཅད་རྣལ་འབྱོར་དབྱེར་མེད་པ། །
སངས་རྒྱས་སེམས་ཅན་གཉིས་སུ་མེད་པ་སྟེ། །
དཔེར་ན་ཆུ་དང་དེ་ཡི་རླབས་བཞིན་ནོ། །
དངོས་དང་དངོས་མིན་སྤངས་པའི་སེམས་ཉིད་འདི། །
རྟོགས་པའི་རྣལ་འབྱོར་སྐད་ཅིག་གཅིག་ལ་ནི། །
སྒྲོན་མེ་ཆུང་ངུ་ཞིག་གིས་མུན་པ་ལྟར། །
འཁོར་བའི་དུག་ལྔ་རང་བཞིན་རབ་རིབ་སེལ། །
```

种种事物，就是自己的心性；轮回与涅槃的一切，在瑜伽中无二无别。佛与众生不是两个，譬如水与它的波浪。这远离有与无的心性，证悟了它的瑜伽士，在一刹那间，就像一盏小灯照破黑暗一样，除去轮回五毒自性的翳障。

【按】"水与波浪"，是萨惹哈道歌中常用的譬喻：波浪从水中起，又落回水中，始终不离水；众生的迷乱从心性中起，也始终不离心性。

【按】"一盏小灯照破黑暗"，与帝洛巴《恒河大手印》中"一盏灯能除去千劫黑暗"同义。

## 二、双运大手印的体相

```
ཟུང་འཇུག་ཕྱག་རྒྱ་བློ་འདས་ཆེན་པོ་ནི། །
བདེ་གསལ་མི་རྟོག་ནམ་མཁའ་ལྟ་བུ་སྟེ། །
ཁྱབ་ཅིང་རྒྱ་ཆེན་སྙིང་རྗེ་ཆེན་པོའི་ངོ། །
སྣང་ཡང་རང་བཞིན་མེད་པ་ཆུ་ཟླ་བཞིན། །
གསལ་ཡང་ཐ་སྙད་མཐའ་དབུས་ཀུན་དང་བྲལ། །
གང་གིས་མ་གོས་དྲི་མེད་རེ་དོགས་བྲལ། །
ལྐུགས་པའི་རྨི་ལམ་བཞིན་དུ་སྨྲ་མི་ཤེས། །
ཚད་མེད་བདེ་ཆེན་རང་བཞིན་ཡེ་ཤེས་ནི། །
ཉི་ཟླའི་འོད་བཞིན་ཕྱོགས་དང་བྲལ་བ་མེད། །
```

双运的大手印，超越了心智，是乐、明、无念，犹如虚空；它周遍而广大，是大悲的面貌。它虽显现，却没有自性，如同水中之月；它虽明朗，却远离一切名言与边、中。它不被任何东西所染，无垢，远离希望与疑惧；就像哑巴做梦，说不出来。无量大乐自性的智慧，就像日月之光，没有任何方向不被照到。

【按】"乐、明、无念"，是大手印修持中常说的三种觉受，这里用来描述双运大手印本身的体相。"哑巴做梦"，比喻证悟者自己清楚明白，却无法以言语说出。

【按】存疑。"ཉི་ཟླའི་འོད་བཞིན་ཕྱོགས་དང་བྲལ་བ་མེད"，字面是"如日月之光，没有离开任何方向"，本译依义译为"没有任何方向不被照到"。

## 三、本然之心即法身

```
ཀྱེ་ཧོ་རྣལ་འབྱོར་རང་འབྱུང་ངོ་མཚར་ཆེ། །
གཉུག་མ་མ་བཅོས་སེམས་ནི་ཆོས་སྐུ་སྟེ། །
བཅོས་པའི་སེམས་ཀྱིས་རྣལ་འབྱོར་ཐོབ་མི་འགྱུར། །
དེ་ཕྱིར་བདེ་བའི་ཕྱོགས་སུ་ཡན་པར་མཐོང། །
རང་བཞིན་གྲུབ་པའི་ལམ་ཐོབ་རྣལ་འབྱོར་བདེ། །
རྣམ་རྟོག་བྲལ་བས་ཞེ་འདོད་འབྱུང་མི་སྲིད། །
རྟ་མགྲིན་གྲུབ་ཐོབ་བདག་ཉིད་སར་ཧས་སྨྲས། །
```

嗟吙！瑜伽是自然生起的，真是稀奇！本然、不加造作的心就是法身；以造作的心，是得不到瑜伽的。所以，要看到它在安乐之中自在无拘；获得了自性成就之道，瑜伽士就安乐；因为远离分别，所以不可能生起企求。——马头明王的成就者，我萨惹哈这样说。

【按】"本然不造作的心就是法身，以造作的心得不到"，是全篇见地的核心，也是萨惹哈一系大手印的根本。

【按】存疑。"ཡན་པར་མཐོང"，本译译为"看到它自在无拘"，"ཡན་པ"有松散、自由之义。"马头明王的成就者"（རྟ་མགྲིན་གྲུབ་ཐོབ），萨惹哈与马头明王的关系，在一般传记中不常见，所指不明，今照原文直译。

## 四、修：以身为山，摄根观心

```
ཀྱེ་ཧོ་རྣལ་འབྱོར་ལྟ་བའི་ཉམས་ལེན་གྱིས། །
དེ་ཡི་རང་བཞིན་གང་ཞིག་སྒོམ་འདོད་ན། །
རང་ལུས་རི་བོ་འདི་ནི་གནས་ཀྱི་མཆོག། །
སེམས་ཉིད་དུས་ཀྱི་རྣལ་འབྱོར་སྒྲུབ་པ་པོ། །
དབང་པོ་རྣམས་བཅིངས་མཚམས་བཅད་བདེ་བར་འགྱུར། །
གཡེང་བ་རྣམས་ཀྱང་ཆེད་དུ་སྤང་མི་བྱ། །
ཏུག་ཕྲད་སེམས་སུ་ཤེས་ན་ཡི་དམ་ལྷ། །
ཤེས་པ་མ་བཀུག་རྟོག་པ་རིམ་གྱིས་སྤངས། །
སེམས་ལ་རྣམ་རྟོག་བྱུང་ན་རྣལ་འབྱོར་པས། །
རས་བལ་འདབ་མ་བཞིན་དུ་གློད་ལ་ཞོག། །
```

嗟吙！瑜伽士以见地来修持；如果想要修持它的自性：自己的身体这座山，就是最殊胜的处所；心性就是时之瑜伽的修行者。把诸根收束，划定界限，就会安乐。种种散乱也不必刻意去舍弃；如果了知所遇到的一切都是心，那就是本尊。不要把心识勾回来，分别要渐次舍离；心中生起分别时，瑜伽士要像棉絮一样，把它放松、放下。

【按】"自己的身体这座山就是最殊胜的处所"，意思是不必到外面去寻找闭关的山，自身就是道场，这与帝洛巴《自性不思议》中"自身寂静的道场"相同。

【按】"散乱不必刻意舍弃，知所遇即心即是本尊"，是大手印修持的特点：不是以对治去压制散乱，而是认出散乱本身就是心。"像棉絮一样放松"，是常用的譬喻：棉絮轻柔，不紧不松。

【按】存疑。"时之瑜伽的修行者"（དུས་ཀྱི་རྣལ་འབྱོར་སྒྲུབ་པ་པོ），所指不明，可能指"恒时的瑜伽"，也可能与时轮有关。"划定界限"（མཚམས་བཅད），一般指闭关时划定界限，这里与"收束诸根"连说，可能指不让心随根外驰。

## 五、修：自看自心，无修之修

```
བྱ་བ་སྤོངས་ལ་རང་སེམས་རང་གིས་ལྟོས། །
ཞེ་འདོད་བྱུང་ན་བདུད་དུ་ཤེས་པར་གྱིས། །
རྣམ་རྟོག་རྣམས་ཀྱི་རྩ་བ་སེམས་ཡིན་ཏེ། །
དེ་མེད་ཕྱིར་ན་རྣམ་རྟོག་ཡོད་མིན་ནོ། །
དྲན་པ་དྲན་མེད་བསྒོམ་པའི་རྣལ་འབྱོར་ཏེ། །
སེམས་འདི་རྟག་པར་མ་གྲུབ་རང་ལ་ཐིམ། །
བསྒོམ་འདོད་མེད་པས་སངས་རྒྱས་འབྲས་བུ་ཐོབ། །
```

放下种种作为，以自心看自心；如果生起企求，要知道那是魔。一切分别的根本是心，心既然不存在，分别也就不存在了。忆念而无所忆念，就是修持的瑜伽；这心从不恒常成立，融入自身；因为没有想要修的欲念，所以得到佛果。

【按】"忆念而无所忆念"（དྲན་པ་དྲན་མེད），是大手印中有名的说法：保持明了的觉知，却不以任何对象为所忆念。"没有想要修的欲念，所以得到佛果"，与第三节"以造作的心得不到瑜伽"前后相应。

## 六、行：如童子、蜂、狮、风

```
རྣལ་འབྱོར་བུ་ཆུང་ལྟ་བུར་རྟོག་པ་མེད། །
ལྡུམ་རའི་བུང་བས་མེ་ཏོག་རོ་མྱང་ལྟར། །
ནགས་ནས་ནགས་སུ་འཁྱམ་པ་སེང་གེ་བཞིན། །
ཀུན་དུ་རྒྱུ་བ་སྣ་ཚོགས་རླུང་ལྟར་ནི། །
སེམས་ཉིད་བག་དང་ལྡན་པ་སྤྱོད་པའི་མཆོག། །
རང་བཞིན་མི་དགག་སྨྱོན་པ་ལྟ་བུར་སྤྱོད། །
རྒྱབ་ཏུ་མི་ཆགས་མདུན་དུ་ཞེན་པ་མེད། །
མདོར་ན་ལྟ་སྒོམ་སྤྱོད་པ་ཉམས་ལེན་ལ། །
ཇི་ལྟར་ཕན་པའི་སྤྱོད་པས་རྣལ་འབྱོར་སྤྱོད། །
```

瑜伽士像小孩一样，没有分别；像园中的蜜蜂品尝花的滋味；像狮子从一片森林游荡到另一片森林；像风一样到处流动。心性具足谨慎，是最殊胜的行持；不遮止自性，像疯人一样行持；对过去不贪恋，对前面不执取。总之，对于见、修、行的实践，瑜伽士以怎样有利益的行持，就怎样去行持。

【按】"像小孩""像蜜蜂""像狮子""像风"四喻，分别比喻无分别、受用而不执著、无畏、无所阻碍。

【按】"具足谨慎"（བག་དང་ལྡན་པ）与"像疯人一样行持"同时提出，并不矛盾：前者是内心不离正念，后者是外在不被世俗规范所束缚。"像疯人一样行持"，是印度成就者已有稳固证悟后的禁行，有一定的前提，不是一般修行人可以模仿的；末句"以有利益的行持去行持"，正是对此的约束。

## 七、果：所遇即大手印

```
སྣ་ཚོགས་སྣང་བ་སེམས་ཀྱི་ངོ་བོ་འདི། །
ཏུག་ཕྲད་ཙམ་གྱིས་མ་གྲུབ་ཕྱག་རྒྱ་ཆེ། །
སྣང་ལ་མི་སྣང་འབྲས་བུ་སངས་རྒྱས་འབྱུང། །
དེ་ལ་སེམས་ན་དངོས་གྲུབ་དམ་པ་ཡིན། །
ཕྱི་ནང་ཐམས་ཅད་ལྷན་ཅིག་སྐྱེས་པ་འདི། །
རྣམ་རྟོག་ཆུ་བོའི་རྒྱུན་གྱི་རྣལ་འབྱོར་འདྲ། །
དེ་ཡང་སེམས་ལས་གཞན་ན་བཙལ་དུ་མེད། །
ཡིད་ལ་མི་གཞག་ཕྱག་རྒྱ་ཆེན་པོའི་ལམ། །
```

种种显现，就是心的体性；仅仅在相遇之时就不成立，这就是大手印。显现而又不显现，佛果就生起；心若安住于此，就是殊胜的成就。外与内的一切都是俱生的，就像分别之河流不断的瑜伽；而它也不能在心之外去寻找；不放在意中，就是大手印之道。

【按】存疑。"ཏུག་ཕྲད་ཙམ་གྱིས་མ་གྲུབ"，本译译为"仅仅在相遇之时就不成立"，意思大概是：显现在与心相遇的当下，就没有实体。"དེ་ལ་སེམས་ན"，本译读作"心若安住于此"，也可解为"若对此作思维"，所指不完全确定。"像分别之河流不断的瑜伽"，比喻不详，可能是说俱生之境如河水恒流，念念不断而不离心性。

【按】"不放在意中"（ཡིད་ལ་མི་གཞག），即不作意，与梅纪巴不作意法类、帝洛巴《恒河大手印》的"不作意"同义。

## 八、果：不希果而证悟

```
འབྲས་བུ་མ་རེ་རྟོགས་ན་ཕྱག་རྒྱ་ཆེ། །
མ་རྟོགས་རྟོག་པ་ནམ་མཁའི་སྤྲིན་དང་འདྲ། །
རྟོགས་ན་དེ་ཉིད་རང་བཞིན་སྟོང་པ་ཡིན། །
ལྟ་སྤྱོད་འབྲས་བུ་དབྱེར་མེད་ལྷན་ཅིག་སྐྱེས། །
རང་བཞིན་དབྱེར་མེད་རྟོགས་ན་འབྲས་བུའི་མཆོག། །
```

不希求果而证悟，就是大手印。没有证悟时，分别就像虚空中的云；证悟了，它就是空的自性。见、行与果无别而俱生；证悟了自性无别，就是最殊胜的果。

【按】全篇以"见、行、果无别"作结，与题名"见修行果"相应：四者分开讲，实际上同是俱生的心性。

## 跋语

```
ལྟ་སྒོམ་སྤྱོད་པ་འབྲས་བུ་དོ་ཧའི་གླུ་ཞེས་བྱ་བ་སློབ་དཔོན་ས་ར་ཧ་པས་མཛད་པ་རྫོགས་སོ། །
```

## 通篇连读

敬礼圣者文殊！

种种事物，就是自己的心性；轮回与涅槃的一切，在瑜伽中无二无别。佛与众生不是两个，譬如水与它的波浪。这远离有与无的心性，证悟了它的瑜伽士，在一刹那间，就像一盏小灯照破黑暗一样，除去轮回五毒自性的翳障。

双运的大手印，超越了心智，是乐、明、无念，犹如虚空；它周遍而广大，是大悲的面貌。它虽显现，却没有自性，如同水中之月；它虽明朗，却远离一切名言与边、中。它不被任何东西所染，无垢，远离希望与疑惧；就像哑巴做梦，说不出来。无量大乐自性的智慧，就像日月之光，没有任何方向不被照到。

嗟吙！瑜伽是自然生起的，真是稀奇！本然、不加造作的心就是法身；以造作的心，是得不到瑜伽的。所以，要看到它在安乐之中自在无拘；获得了自性成就之道，瑜伽士就安乐；因为远离分别，所以不可能生起企求。——马头明王的成就者，我萨惹哈这样说。

嗟吙！瑜伽士以见地来修持；如果想要修持它的自性：自己的身体这座山，就是最殊胜的处所；心性就是时之瑜伽的修行者。把诸根收束，划定界限，就会安乐。种种散乱也不必刻意去舍弃；如果了知所遇到的一切都是心，那就是本尊。不要把心识勾回来，分别要渐次舍离；心中生起分别时，瑜伽士要像棉絮一样，把它放松、放下。

放下种种作为，以自心看自心；如果生起企求，要知道那是魔。一切分别的根本是心，心既然不存在，分别也就不存在了。忆念而无所忆念，就是修持的瑜伽；这心从不恒常成立，融入自身；因为没有想要修的欲念，所以得到佛果。

瑜伽士像小孩一样，没有分别；像园中的蜜蜂品尝花的滋味；像狮子从一片森林游荡到另一片森林；像风一样到处流动。心性具足谨慎，是最殊胜的行持；不遮止自性，像疯人一样行持；对过去不贪恋，对前面不执取。总之，对于见、修、行的实践，瑜伽士以怎样有利益的行持，就怎样去行持。

种种显现，就是心的体性；仅仅在相遇之时就不成立，这就是大手印。显现而又不显现，佛果就生起；心若安住于此，就是殊胜的成就。外与内的一切都是俱生的，就像分别之河流不断的瑜伽；而它也不能在心之外去寻找；不放在意中，就是大手印之道。

不希求果而证悟，就是大手印。没有证悟时，分别就像虚空中的云；证悟了，它就是空的自性。见、行与果无别而俱生；证悟了自性无别，就是最殊胜的果。
