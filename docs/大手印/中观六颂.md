# 中观六颂

梅纪巴（阿瓦都帝·无二金刚）造　据藏文译出

## 题解

《中观六颂》（梵 Madhyamaṣaṭka，藏 dbu ma drug pa）收于德格版丹珠尔续部释 ཝི 函第 110a 页（东北目录 D2230），正好夹在《除恶见》（D2229）与《除恶见难释》（D2231）之间，同属梅纪巴的"无念法类"。译者是印度上师金刚手与藏地的那措译师。

全篇只有六颂，每颂四句。前五颂依次列出几种对"离四边之心性"的理解：有相论者的主张、以自证为中观的主张、如幻无二的宗派、证空之觉与后得清净世俗、一切相不生的主张；第六颂则以"本尊体性、无二大乐、唯是缘起"作结，归到密乘的见地。梅纪巴在《真性宝鬘》等论中有类似的宗义判摄，读本篇时可以互相参照；不过本篇极为简略，各颂与哪一宗派确切对应，原文并没有一一标明，下面在按语中说明。

体例：每颂先列藏文原颂于代码块中，再按完整的意义单元译出；为了便于理解而补的字，都放在方括号中。原文含混或可有两解之处，以"【按】"说明，不妄补内容。文末附通篇连读。

## 题名与礼敬

梵语题名：Madhyamaṣaṭka。藏语题名：《中观六颂》。

敬礼佛陀！

【按】藏本梵题音写作 ma dhya ma sha ta，与"六"（ṣaṭka）对不上，应是传写之讹，这里依藏题 dbu ma drug pa（中观六［颂］）还原为 Madhyamaṣaṭka。

## 第一颂

```
མཐའ་བཞི་ལས་ནི་རྣམ་གྲོལ་བའི། །
ཤེས་པ་སྐད་ཅིག་མ་ཡོད་དེ། །
རྟོག་པས་སྟོང་ཞིང་དམིགས་པ་མེད། །
རྣམ་བཅས་སྨྲ་བར་ཤེས་པར་བྱ། །
```

有一种远离四边的、刹那刹那的识，它是实有的；这识空于分别念，没有所缘——应当知道，这是有相论者［的主张］。

【按】"四边"，指有、无、亦有亦无、非有非无四种边执。"有相论者"（rnam bcas smra ba，梵 sākāravādin），是唯识宗中承许识带有行相、行相与识同样真实的一派。本颂的要点在"刹那的识是实有的"（ཡོད་དེ）：心性虽然离开分别、离开外境，但仍被承许为实有的刹那之识，这正是有相唯识的立场，与后面几颂的中观见有别。"没有所缘"（dmigs pa med），可以理解为没有心外的所缘境，也可以理解为不可执取为对象；两种理解在这里意思相通，都是说离开能取所取。

## 第二颂

```
ཆད་པ་མ་ཡིན་རང་རིག་ནི། །
སྔོན་པོ་ལ་སོགས་པར་སྣང་བ། །
དེ་ནི་མཚན་ཉིད་ཀྱིས་མ་སྐྱེས། །
དབུ་མ་པ་ཡི་ལམ་དུ་འདོད། །
```

［心］不是断灭；自证［之识］显现为青等［种种相］，而这［显现］就其体相而言是不生的——［有人］认为这是中观者之道。

【按】"不是断灭"，是说这一派不像断见那样否定一切心识，承许自证的明知是有的。"就其体相而言不生"（mtshan nyid kyis ma skyes），是说显现为青黄等的自证，并没有以自相成立的生起。这一颂所说，似乎是把唯识的"自证"纳入中观、承许显现而又说其无自相生的一派，后世有称之为"瑜伽行中观"的；但原文只说"认为是中观者之道"，没有标出宗名，也没有说出是谁所承许，以上只是推测，存疑。

## 第三颂

```
མཐའ་བཞི་ལས་ནི་རྣམ་གྲོལ་བའི། །
གསལ་བ་རྫུན་པའི་མཚན་ཉིད་དེ། །
དེ་ནི་སྒྱུ་མ་ལྟར་གཉིས་མེད། །
ཚད་མར་ལྡན་པའི་གྲུབ་མཐའོ། །
```

远离四边的明［性］，它的体相是虚妄的；这［明性］就像幻化一样，是无二的——这是具足正量的宗派。

【按】"虚妄"一词，德格本作 brdzun pa，另一读法作 rdzun pa，依校勘惯例取后者，二者意思相同，都是"虚假、不实"。这一颂与梅纪巴在别处所说的"如幻无二论"（māyopamādvayavāda）相合：显现的明性本身虚妄不实，如幻而无能取所取之二。又，"体相虚妄"也让人联想到唯识中的"假相论"（行相虚妄），但本颂明说"如幻""无二"，并称之为宗派，应以如幻无二的中观宗来理解为妥。"具足正量"（tshad mar ldan pa），意思是这一宗派的主张合乎正量、可由正理成立；也可理解为"以正量为依据"。

## 第四颂

```
དངོས་པོ་སྟོང་པར་རིག་པ་གང་། །
སྣང་བ་མེད་ཅིང་སྒྲིབ་གཡོགས་མེད། །
དེ་ཉིད་དབུ་མ་པ་ཡི་ལམ། །
རྗེས་ཐོབ་དག་པའི་ཀུན་རྫོབ་ཡིན། །
```

那证知诸法［本来］是空的觉知，［在其中］没有显现，也没有遮障覆蔽——这就是中观者之道；［出定之后的］后得［位］，则是清净的世俗。

【按】"觉知"，原文 rig pa，这里是一般意义的觉知、了知，不是大圆满专用的"明觉"。"后得"（rjes thob），指从根本定出定之后的阶段。本颂的意思是：在根本定中，证知诸法空性的觉知，既没有任何显现，也没有障蔽；出定之后，种种显现仍然生起，但已是清净的世俗，如幻而现。这一颂是承接第三颂、说明如幻无二宗的入定与出定，还是另立一种中观的主张，原文没有交代，两种读法都可以成立，存疑。

## 第五颂

```
གསལ་བ་འམ་ནི་མི་གསལ་བ། །
དེ་ཉིད་ལ་ནི་དམིགས་སུ་མེད། །
རྣམ་ཀུན་མ་སྐྱེས་པ་རང་བཞིན། །
གཞན་དག་དབུ་མ་པ་རུ་འདོད། །
```

无论是明，还是不明，在那真性本身之中，都不可得；一切方面都不生，就是［诸法的］自性——另一些人认为，这才是中观者［的主张］。

【按】这一颂进一步连"明性"也不承许：明与不明，在真性中都不可得，所以不像第三颂那样以"如幻的明性"为究竟。这与梅纪巴所说的"一切法无住论"（sarvadharmāpratiṣṭhānavāda）相合，而梅纪巴本人在《真性宝鬘》等论中，是以无住论为中观的究竟。"一切方面"（rnam kun），也可以读作"一切行相"，那么意思就是"一切行相都不生"；两种读法义理一致，这里取通常的副词义。"另一些人"（gzhan dag），只是指出这是另一派的主张，并不含贬义。

## 第六颂

```
མཐའ་བཞི་ལས་ནི་རྣམ་གྲོལ་བའི། །
གསལ་བ་ལྷ་ཡི་བདག་ཉིད་ཅན། །
གཉིས་མེད་མཆོག་ཏུ་བདེ་བའི་དངོས། །
རྟེན་ཅིང་འབྲེལ་འབྱུང་ཙམ་བདག་ཉིད། །
```

远离四边的明［性］，以本尊为它的体性；它是无二的、最胜大乐的实性，而它的本质，只是缘起而已。

【按】前五颂都标出了"是某某的主张"，这一颂却没有，而是直接以本尊、大乐、缘起作结，应当是梅纪巴归结到密乘的见地：同样是远离四边的明性，在密乘中显现为本尊之身，体验为无二大乐；而它之所以能如此显现，恰恰因为它只是缘起，没有自性。"只是缘起"一句，把密乘的本尊与大乐收归中观的缘起性空，避免把本尊或大乐执为实有。这里所说的本尊、大乐，属于密法的修持，须依具德上师的灌顶与口授来理解，不可凭文字自行揣度修习。

## 跋

《中观六颂》，智者阿阇黎梅纪巴所造，圆满。

上师金刚手与那措译出。

【按】"梅纪巴"，原文作 mai tri，即梅纪巴（Maitrīpa）。"那措"，原文作 nags tsho，一般认为就是那措译师·戒胜（nag tsho tshul khrims rgyal ba），他曾与金刚手合作译出梅纪巴的多部著作。

## 通篇连读

敬礼佛陀！

有一种远离四边、刹那刹那的识，它是实有的，空于分别念，没有所缘——应当知道，这是有相论者的主张。

心不是断灭，自证之识显现为青黄等种种相，而这显现就其体相而言并不生起——有人认为，这就是中观者之道。

远离四边的明性，体相是虚妄的，像幻化一样无二——这是具足正量的宗派。

那证知诸法本来是空的觉知，没有显现，也没有遮障覆蔽，这就是中观者之道；出定之后的后得位，则是清净的世俗。

无论是明还是不明，在真性本身中都不可得；一切方面都不生，就是诸法的自性——另一些人认为，这才是中观者的主张。

远离四边的明性，以本尊为体性，是无二、最胜大乐的实性，而它的本质，只是缘起而已。

《中观六颂》，智者阿阇黎梅纪巴造，圆满。上师金刚手与那措译出。
