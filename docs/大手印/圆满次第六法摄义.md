# 圆满次第六法摄义

*华智仁波切 造*

六法之中，作为道之根本的拙火（脐火定），分为三种：加行拙火、觉受拙火、殊胜拙火。

第一种加行拙火，又有三个要点：身之要点，即坐式姿势；气之要点，即柔缓与猛烈两种呼吸法；心之要点，即观想。

其中觉受拙火：当四大汇聚生起暖相时，会经历三个阶段——第一是暖热、或说带有苦受之时；第二是乐受之时；第三是离于分别之时。此中又有五种征相：如烟、如阳焰、如萤火（或如灯焰、又或如黎明晨曦）、如无云晴空；再有另外五种征相：炽燃之相、月轮之相、日轮之相、罗睺之相、闪电之相，即所谓"光"，分别有黄、白、蓝、红等光色相继生起。如此，觉受的十种征相便会圆满显现。

殊胜拙火，则是当中脉的脉结得以解开之后，便证得大手印这一殊胜悉地。

作为道之基础的幻身，分为三种：不净幻身、清净幻身、密义风心幻身。其中，清净幻身又分两种瑜伽：本然形态瑜伽、幻化形态瑜伽。

作为衡量道上进展标尺的梦境瑜伽，分为四个次第：认取梦境、净治梦境、修炼梦境为幻化、令心安住于真如实相。

作为道之心要的光明，分为三种：基位光明、道位光明、果位光明。其中，基位光明，有三个出现的时机：入睡之时、等至（禅定）之时、临终死亡之时。道位光明，包括：微细光明、粗显光明、觉受光明。果位光明，则唯一是不再迁变、究竟殊胜的光明。

作为道上验证成果的中阴，分为三种带入道用之法：其一，将初期中阴的光明带入道用，成就法身；其二，将（明空）双运带入道用，成就报身；其三，将受生带入道用，成就化身。

作为道上令人生起坚定信念的颇瓦法（迁识法），分为三种：串习修炼而迁的颇瓦、猛力强行而迁的颇瓦、依身体要点而迁的颇瓦。

善哉！善哉！以上是华智仁波切所说。
