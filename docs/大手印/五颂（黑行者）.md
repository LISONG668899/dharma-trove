# 五颂（黑行者）

具禁行大阿阇黎黑行者（Kṛṣṇa）造　据藏文译出

## 题解

《五颂》（梵 Pañcagāthā，藏 tshigs su bcad pa lnga pa）收于德格版丹珠尔续部释 ཞི 函第 137b 至 138a 页（东北目录 D2282），紧接在帝洛巴《道歌宝藏》（D2281）之后。跋语说是"具禁行的大阿阇黎黑行者"（brtul zhugs spyod pa'i slob dpon chen po nag po）所造，由瑜伽自在吉祥毗卢遮那金刚译出。

**作者的提示：**本篇的题名在德格目录中虽只作《五颂》，跋语明确说作者是"黑行者"（nag po pa，Kṛṣṇācārya / Kāṇha），偈中也多次自称"黑者"（nag po）。所以这是黑行者的道歌，与此前已译出的黑行者《道歌宝藏》（D2301）及其广释（D2302）、《不相属之见（黑行者道歌）》（D2437）同属一位作者，但内容不同，没有重复。为了与《慈五颂》《无别五颂》等区别，文件名加了"（黑行者）"。

全篇五偈，每偈四句，是典型的"行歌"（caryāgīti）风格：以干涸的池塘、枯萎的莲花、飞走的蜜、被火烧尽的根叶、海水枯竭、十门冒烟等意象，描写瑜伽士的"死"——世人说"黑行者不在了"，黑行者却说自己住在大乘甚深的森林中，心性空而在本然中圆满，即使身体像莲花一样枯干，又怎么能说他死了呢？

这些意象在印度行歌中通常有双重含义：表面上是一首描写死亡的歌，内里是圆满次第中风息、明点融入、心融入空性的象征。例如"拙火"（gtum mo）一词，既是"旃陀罗女"，又是圆满次第中的"拙火"；"莲花""蜜""十门"等，也都是密续中有特定内涵的象征用语。本译依此前的原则，只照原文直译，不作解说，须依具德上师的灌顶与口授来领受。

体例：本篇是短篇偈颂，依本译对短篇的体例，每偈先列藏文原文于代码块中，再以完整的意义单元译出；为了便于理解而补的字，都放在方括号中。原文含混或可有两解之处，以"【按】"说明，不妄补内容。文末附通篇连读。

## 第一颂　莲花干枯，蜜已飞走

```
ཆུ་ཟད་པས་ནི་འདམ་གྱི་པདྨ་སྐམས། །
སྦྲང་རྩི་བྲོས་པས་གར་སོང་ཆ་ཡང་མེད། །
རྩ་བ་ལོ་མ་སྡོང་པོ་མེ་ཡི་སྦྱོར་བས་ཟད། །
ནག་པོ་ན་རེ་དབང་པོའི་བཞད་གད་ལ་ནི་ལྟོས། །
```

水已干涸，泥中的莲花也枯萎了；蜜已逃走，去了哪里一点踪影也没有；根、叶、茎，都因火的作用而烧尽了。黑者说：看那诸根的嬉笑吧！

【按】"诸根的嬉笑"（dbang po'i bzhad gad），意思不很清楚：可能是说诸根（感官）已经失去作用，像一场笑话；也可能是说黑者以嬉笑的态度看待诸根的消散，存疑。"莲花""蜜""火"等，都是行歌中有双重含义的象征用语，这里只照原文译出。

## 第二颂　如拙火女

```
ཟ་ཞིང་འཐུང་དང་གནས་ནས་ཡལ་ག་བཅག་ནས་སོང་། །
ཀྱེ་ཧོ་འདི་ནི་བདག་གི་ལས་ནི་གཏུམ་མོ་ལྟ་བུ་ཡིན། །
རྒྱུན་གྱི་(བ་,བུ་)མོ་ལྟ་བུས་པདྨ་བསྲེགས། །
ཡོན་ཏན་བརྒྱ་ནི་སྐྱོན་གཅིག་གིས་ནི་ཟད་པར་བྱས། །
```

吃了，喝了，从住处折断了树枝就走了。喂！我的这番作为，就像拙火（旃陀罗女）一样；像相续的少女一样，把莲花烧掉了；一百种功德，被一个过失耗尽了。

【按】"拙火"（gtum mo，梵 caṇḍālī），既是"旃陀罗女"（最低种姓的女子），又是圆满次第中从脐间生起的"拙火"，黑行者的道歌中常以此双关。"相续的少女"，藏文作"རྒྱུན་གྱི་བུ་མོ"（异文作"བ་མོ"），意思不明，存疑。"一百种功德，被一个过失耗尽了"，意思不很清楚，可能是说一切世间的功德（或身体的作用）都因一个缘故而消尽，存疑。

## 第三颂　世人说黑者不在了

```
རྒྱ་མཚོ་ཟད་པས་པདྨ་རྣམས་ཀྱང་སྐམས། །
དེ་ཚེ་སྒོ་བཅུ་ལས་ནི་དུ་བ་བྱུང་། །
འཇིག་རྟེན་པ་ནི་ནག་པོ་མེད་ཅེས་ཟེར། །
ནག་པོ་ཐེག་ཆེན་ཟབ་མོའི་ནགས་ན་གནས། །
```

大海已经枯竭，诸莲花也都干枯了；那时，从十门中冒出了烟。世间的人说："黑者不在了！"黑者却住在大乘甚深的森林中。

【按】"十门"（sgo bcu），一般指身体的九窍再加顶门，即十个出入口；"从十门中冒出了烟"，表面上是描写火化或死亡，内里也是圆满次第的象征用语，存疑。"大乘甚深的森林"，比喻证悟的境界，世人看不见，以为他已经死了。

## 第四颂　心空而在本然中圆满

```
སེམས་ནི་སྟོང་ཞིང་གཉུག་མའི་ངང་དུ་རྫོགས། །
ཕུང་པོ་བཞད་གད་གྱུར་ཀྱང་འགྱོད་པ་མེད། །
འོ་མའི་ནང་ན་མར་ཡོད་པ་ནི་མི་མཐོང་བཞིན། །
འདོད་པ་ཡོད་དེ་འཇིག་རྟེན་པས་ནི་མ་མཐོང་ངོ་། །
```

心是空的，在本然的状态中圆满；即使诸蕴成了笑话，也没有懊悔。就像看不见牛奶中有酥油一样，［那所］欲求的［安乐］是有的，世间的人却看不见。

【按】"诸蕴成了笑话"，藏文作"ཕུང་པོ་བཞད་གད་གྱུར"，意思是身体（五蕴）已经崩坏，像一场笑话，存疑。"牛奶中有酥油"，是佛典中常用的比喻：酥油本来就在牛奶中，只是要经过搅拌才能显现，比喻佛性、大乐本来具足，世人却看不见。"欲求的［安乐］"，藏文作"འདོད་པ"，可以是"欲求"，也可以是"所欲的［对象］"，存疑。

## 第五颂　黑者怎么会死

```
འཇིག་རྟེན་འཚོ་བ་འམ་ནི་འཆི་བ་གང་ཡང་མེད། །
འདི་ལྟའི་ལོངས་སྤྱོད་ནག་པོ་རྣལ་འབྱོར་པ། །
པདྨ་བཞིན་དུ་ལུས་ཆ་སྐམས་གྱུར་ཀྱང་། །
ནག་པོ་ཅི་ཡི་ཕྱིར་ན་ཤི་ཞེས་བྱ། །
```

对于世间，既没有活，也没有死；这样的受用，就是黑者瑜伽士［的受用］。即使身体的各部分像莲花一样枯干了，又为什么要说黑者死了呢？

【按】这一偈是全篇的结论：证悟者超越了生与死，世人看到他的身体枯干、以为他死了，而他实际上安住于本然的心性中，无所谓生死。"对于世间，既没有活，也没有死"，可以理解为"在［他看来］世间本来没有生与死"，也可以理解为"他对世间来说已经无所谓生死"，两说意思相通。

## 跋

```
བརྟུལ་ཞུགས་སྤྱོད་པའི་སློབ་དཔོན་ཆེན་པོ་ནག་པོས་མཛད་པའི་ཚིགས་སུ་བཅད་པ་ལྔ་པ་རྫོགས་སོ།། །།
རྣལ་འབྱོར་གྱི་དབང་ཕྱུག་ཤྲཱི་བཻ་རོ་ཙ་ན་བཛྲས་བསྒྱུར་བའོ།།
```

《五颂》，具禁行的大阿阇黎黑者所造，圆满。

瑜伽自在吉祥毗卢遮那金刚译出。

【按】"具禁行"（brtul zhugs spyod pa），指黑行者以行持密乘禁行（如住尸陀林、游行等）而著称。"毗卢遮那金刚"，见《道歌宝藏（毗瓦巴）》跋语按语。
