# 八真如之见

阿阇黎因札菩提 造

## 题解

本篇出自德格版丹珠尔续部（རྒྱུད་འགྲེལ།）ཟི 函第47a叶第6行至第47b叶第4行，东北目录编号 D2432。全篇三十四句，每句七个音节，另有礼敬和跋语。篇幅很短，所以把藏文原文全部保留在代码块中，按段落分开，每段后附汉译，疑难之处另以【按】说明。

梵文题名：Tattva-aṣṭaka-dṛṣṭi-nāma（ཏཏྟྭཱ་ཨཥྚ་ཀ་དྲྀཥྚི་ནཱ་མ）。

藏文题名：དེ་ཉིད་བརྒྱད་ཀྱི་ལྟ་བ（八真如之见）。

【按】作者“ཨིནྡྲ་བྷཱུ་ཏི”（Indrabhūti），这里音译为“因札菩提”，即因陀罗菩提。藏传传统中有几位名叫因札菩提的人物，最著名的是邬金国王因札菩提，八十四大成就者中也有一位。本篇的作者是哪一位，无法确定。本篇在诗中三次自署其名。跋语没有记载译者。

【按】题名中的“八真如”，正文没有明确列出八项，如何数成“八”，原文没有交代，这里不作强配。本篇的大意是：轮回涅槃诸法都是分别所立，如水中月、乾闼婆城，都是迷乱显现；有垢之心即是轮回，离于名言即是涅槃；如无云虚空、不住一切，即是大手印；所以连微细的分别也要防护，在无二的意义上修持。

```
འཇམ་དཔལ་གཞོན་ནུར་གྱུར་པ་ལ་ཕྱག་འཚལ་ལོ། །
```

## 正文

### 第一段：立宗

```
འཁོར་འདས་དངོས་པོའི་རྟོག་པ་འདི། །གྲུབ་པ་མེད་དེ་ཆུ་ཟླ་བཞིན། །ཀུན་རྫོབ་ཐ་སྙད་རྟེན་བྱས་ནས། །དེ་ཉིད་བརྒྱད་ཀྱི་ལྟ་བ་འཆད། །
```

这些对于轮回、涅槃诸事物的分别，都不成立，就像水中的月亮一样。依于世俗的名言，我来宣说八真如之见。

【按】“ཀུན་རྫོབ་ཐ་སྙད་རྟེན་བྱས་ནས”，“依于世俗名言”，意思是：真如本身离言，但为了宣说，只能依世俗名言而说。

【按】题名中的“八真如”（དེ་ཉིད་བརྒྱད），正文中并没有明确列出八项。正文中“真如”（དེ་ཉིད）一词出现多次（中观的真如、初终自性的真如、善逝之见的真如等），但如何数成“八”，原文没有交代，这里不作强配。

### 第二段：无云虚空即大手印

```
དྲི་བཅས་སེམས་ནི་འཁོར་བ་སྟེ། །ཐ་སྙད་དང་བྲལ་མྱ་ངན་འདས། །དཔེར་ན་སྤྲིན་མེད་ནམ་མཁའ་ནི། །གང་ལ་མི་གནས་ཕྱག་རྒྱ་ཆེ། །
ཨིནྡྲ་བྷཱུ་ཏི་སྨྲ་བར་བྱེད། །
```

有垢的心就是轮回，离于名言就是涅槃；譬如没有云的虚空，不住于任何处，那就是大手印——因札菩提这样说。

【按】“དྲི་བཅས་སེམས”，“有垢的心”，指被客尘烦恼与分别所染的心；离开名言分别，就是涅槃。这与“心垢即轮回，心净即涅槃”的通义一致。

【按】“སྤྲིན་མེད་ནམ་མཁའ”，“无云的虚空”，是大手印中形容心性最常用的譬喻：本来清净，无所依住。

【按】“ཨིནྡྲ་བྷཱུ་ཏི”，因札菩提（Indrabhūti，因陀罗菩提），即本篇作者，在诗中自署其名。

### 第三段：分别如火，细念亦须防护

```
འཁོར་བ་མྱ་ངན་འདས་པ་དང་། །བདེ་དང་སྡུག་བསྔལ་གང་ཞིག་ཀྱང་། །སེམས་ཀྱི་རྟོག་པས་སྲེག་པར་བྱེད། །དཔེར་ན་ག་པུར་མེ་བཞིན་ནོ། །
དེ་ཕྱིར་རྣལ་འབྱོར་རྟོག་པ་ནི། །ཆུང་ཡང་ཀུན་དུ་སྦ་བར་བྱ། །
```

轮回与涅槃，乐与苦，无论哪一个，都被心的分别所焚烧，就像樟脑遇到火一样。所以瑜伽士对于分别，即使是很微小的，也要处处防护。

【按】“ག་པུར་མེ”，“樟脑遇火”，樟脑极易燃烧，一点火星就会燃尽。比喻分别念一起，就能焚毁一切，所以连微细的分别也要防护。这是依文意的推解。也可能是说：轮回涅槃、苦乐等，都只是心的分别所燃起的火，并无实体。

【按】“སྦ་བར་བྱ”，字面是“隐藏”“遮护”，这里依文意译作“防护”；也可能是“སྤང་བར་བྱ”（舍弃）的异写或讹误，那么就是“要处处舍弃”。两种读法意思相近。

### 第四段：心与诸法如乾闼婆城

```
སེམས་དང་སེམས་ཉིད་དངོས་པོའོ། །དངོས་པོ་ཐམས་ཅད་མི་གནས་པ། །དཔེར་ན་དྲི་ཟའི་གྲོང་ཁྱེར་བཞིན། །མི་གནས་མི་འདས་འཁྲུལ་སྣང་ཡིན། །
ཨིནྡྲ་བྷཱུ་ཏིས་གཉིས་མེད་སྨྲས། །
```

心与心性，（若执为）事物——（而）一切事物都不住，就像乾闼婆城一样；不住也不去，只是迷乱的显现。因札菩提宣说无二。

【按】第16句“སེམས་དང་སེམས་ཉིད་དངོས་པོའོ”，直译是“心与心性是事物”，若照字面理解，就与佛法“心性非事物”的通义相违。依下句“一切事物都不住”，这里理解为：即使把心与心性当作事物来看，事物也都是无住、如幻的。所以在括号中补出“若执为”。这一读法是译者推定的，请读者留意。

【按】“མི་གནས་མི་འདས”，“不住、不去”，意思是诸法既不真实安住，也不真实灭去。

### 第五段：中观真如与善逝之见

```
དེ་ནི་དབུས་མའི་དེ་ཉིད་དེ། །བདག་མེད་ཆོས་ཀྱང་རང་བཞིན་ལ། །ཐོག་མཐའི་རང་བཞིན་དེ་ཉིད་དོ། །བདེ་གཤེགས་ལྟ་བ་དེ་ཉིད་དེ། །
སྟོང་ཉིད་དོན་ཡང་ཤེས་པར་བྱ། །དངོས་མེད་དྲན་མེད་བློ་འདས་སྨྲ། །
```

这就是中观的真如；无我之法也在自性中，起初与终了的自性就是那真如。善逝之见就是那真如，也应当了知空性的意义。（这）被说为无实、无念、超越心识的。

【按】第22句“བདག་མེད་ཆོས་ཀྱང་རང་བཞིན་ལ”，“无我之法也在自性中”，语法不完整，意思可能是：法无我也就是诸法的自性。这里照字面译出。

【按】“དྲན་མེད”，“无念”，与前面所译《苦乐无二见》中“离正念的无念是迷误”所说的“无念”用的是同一个词。这里的“无念”是指离于分别执著的境界，与那里所破的“昏昧无念”不同，读者须注意区分。

### 第六段：日月山河皆迷乱显现

```
དཔེར་ན་ཉི་མ་ཟླ་བ་དང་། །ནམ་མཁའ་སྐར་མའི་འཁོར་ལོ་དང་། །ས་དང་ཆུ་དང་རྒྱ་མཚོ་དང་། །ཕྱོགས་དང་མཚམས་དང་དེ་ཡིན་ལ། །
རི་རབ་ལ་སོགས་འཁྲུལ་སྣང་ཡིན། །ཨིནྡྲ་བྷཱུ་ཏི་སྨྲ་བར་བྱེད། །དེ་རྣམས་གང་ཡང་གྲུབ་པ་མེད། །གཉིས་མེད་དོན་ལ་ཉམས་ལེན་གྱིས། །
```

譬如日月、虚空中的星轮，大地、水与大海，方位与隅界，以及须弥山等等，这些都是迷乱的显现。因札菩提说：这些无论哪一个都不成立，要在无二的意义上修持。

【按】“ཕྱོགས་དང་མཚམས”，“方位与隅界”，指四方与四隅。“དེ་ཡིན་ལ”一句语法不很清楚，这里依文意并入上文。

## 通篇连读

这些对于轮回、涅槃诸事物的分别，都不成立，就像水中的月亮一样。依于世俗的名言，我来宣说八真如之见。

有垢的心就是轮回，离于名言就是涅槃；譬如没有云的虚空，不住于任何处，那就是大手印——因札菩提这样说。

轮回与涅槃，乐与苦，无论哪一个，都被心的分别所焚烧，就像樟脑遇到火一样。所以瑜伽士对于分别，即使是很微小的，也要处处防护。

心与心性，（若执为）事物——（而）一切事物都不住，就像乾闼婆城一样；不住也不去，只是迷乱的显现。因札菩提宣说无二。

这就是中观的真如；无我之法也在自性中，起初与终了的自性就是那真如。善逝之见就是那真如，也应当了知空性的意义。（这）被说为无实、无念、超越心识的。

譬如日月、虚空中的星轮，大地、水与大海，方位与隅界，以及须弥山等等，这些都是迷乱的显现。因札菩提说：这些无论哪一个都不成立，要在无二的意义上修持。
