# 《月灯三昧经》卷第三

高齐天竺三藏那连提耶舍汉译　白话今译

## 一、一法：如实了知一切法体性

这时，世尊知道月光童子心中默念、以偈发问，便告诉月光童子说：“如果菩萨与一法相应，就能获得一切最殊胜的功德，迅速成就无上正等正觉。是哪一法呢？童子！就是菩萨对一切法的体性如实了知。童子！怎样才是对一切法的体性如实了知呢？就是了知一切法远离名称，远离音声，远离语言，远离文字，远离生灭的因相、缘相与攀缘之相；也就是以无相远离于相，以非心远离于心，而了知诸法。”

【按】第一卷世尊答“一法”是于众生起平等心，这里再答“一法”，是如实了知一切法体性。前者是行，后者是见，同一三昧的两面。“非心远离于心”一句尤须细读：不是用一个心去远离另一个心，而是了知心本非心，于是对心的执取自然脱落。

这时，世尊就说偈道：

诸法只说一件事，就是法无有相；这是智者所说的，应当如实地了知。

如果宣说这样的法，菩萨能够了知，他就能得到无碍的辩才，宣说亿部修多罗。

他为导师（佛）所加持护念，显示诸法的实际；不分别假名，实际上从来没有说过什么。

```
以一知一切　以一切知一
虽有种种说　而不起于慢
```

大意是：由一法的体性了知一切法，又由一切法了知那同一的体性；虽然有种种言说，却不因此生起慢心。

【按】“以一知一切”，因为一切法同一体性；“以一切知一”，因为种种显现都只是这一体性。大手印中“一即一切”的觉受，此偈即其经教根据。

他的心能够了知一切法都没有名，却随顺修学种种名言，用来演说真实之义。

对于所听到的种种音声，了知声音的本源；了知声音的本源之后，就不被声音所染。

了知音声的本际，诸法之相也是如此；如果能解了这一法，就不再处于胞胎之中。

一切法无生，能够了知这无生，又了知随俗说生的道理，就能知道宿命。

如果得到宿命智，就能了知所作之业；如果常常了知所作之业，就能得到坚固的眷属。

如果菩萨能够解了这空性之法，就没有什么不了知的；这不是烦恼的境界。

对于这不是烦恼的境界，凡夫愚人妄加分别，所以在亿劫之中屡屡流转生死，不能了知自己的妄想。

犹如大导师，他不作恶业，也不堕恶道；那些凡夫等人，不能了知这一义理，便生起诽谤之心。这样的灭苦之法：

```
诸法不可得　非无诸法想
若能如是知　彼想亦不见
```

大意是：诸法虽然不可得，却不是没有对诸法的想念显现；如果能这样了知，那些想念也就不再被见为实有。

【按】这一偈最贴近观心实修：并不要求把念头灭掉才算证空。想念照样起现（“非无诸法想”），而认知它不可得，想念自身便不再被执为实物（“彼想亦不见”）。冈波巴所传“分别念即法身”的教授，与此意趣相通。

我了知这样的想念，是凡夫的妄想分别；对于远离分别之法，了知的人就不会迷惑。

这是智者的境地，不是愚人的境界；这是菩萨所行的，就是空性无分别。

这是菩萨之地，是佛子所行的；佛法微妙的庄严，就是宣说寂灭空性。

这些菩萨等，断除了一切三有的习气，不被色法所破坏，安住于佛性之中。

一切法都无所住，因为没有所住之处；如果能这样了知，得到菩提就不难。

修习布施、持戒、多闻与忍辱，亲近善知识；如果能了知这样的业，就能迅速证得菩提之道。

这样的人常为诸天所恭敬，乾闼婆、夜叉、摩睺罗伽等，龙、鬼、罗刹、紧那罗，这些都常来供养菩萨。

```
恒为诸佛所称叹　与诸世间兴利益
智慧相续乐寂灭　胜妙菩萨悲愍身
若有菩萨能知空　利益无量亿众生
柔和处众演说法　闻者欣乐而爱敬
```

大意是：这样的菩萨恒常为诸佛所称叹，为一切世间兴起利益；他的智慧相续不断，乐于寂灭，而这位殊胜微妙的菩萨又以悲悯为身。如果有菩萨能够了知空性，就能利益无量亿的众生；他以柔和之心处于大众之中演说佛法，听闻的人都欣乐而爱敬他。

【按】这就是前言所引的两句经文。“乐寂灭”与“悲愍身”并举，“能知空”与“利益无量亿众生”相续，说明知空并不使人冷漠，反而是广大利他的根源。大手印行者若认识心性后对众生漠然，便是偏离了这里的教诲。

广大的智慧更加增长明亮，以这样的智慧能够见到佛，也能看到庄严清净的妙刹，听受诸佛所说的法。

了知一切法如幻化，犹如虚空自性空；能够了知体性是空无的，能这样修行就无所染著。

修行菩提行的人，对于一切事都不生执著；了知一切法如变化，而在诸佛刹中示现变化。

他能作诸佛所作的事，了知幻法的体性无来无去；随着众生先前所求而使之得到利益，这就是能安住于菩提的人。

他恒常忆念一切如来的恩德，愿绍隆佛种不使断绝；能得到光耀精妙之身，成就三十二种相好。

其余无量种利益，修行殊胜的菩提行就能得到；成就大力而不可动摇，具威德的诸王也无法抗衡。

他具足福德，非常端严，福德与功德的威光照耀；诸天见到他的威光都不敢正面相对，这就是修行佛法的智者。

他安住于坚固的菩提心，作一切众生的善友；这个人不再有种种黑暗，能显示殊胜微妙的菩提之道。

远离言语之道而无所欲求，了知诸法寂灭如同虚空；能够了知这样的业的人，就能成就无量殊胜的辩才。

他演说百千部修多罗，能显示那些法的微细义理；智者恒常成就无碍的智慧，能了知微细的法之体性。

他常常善知众生的信解，学习一切语言音声，为人显示因果的道理，能获得上面所说的殊胜妙事。

他具足受持之力而毫无减少，进入大众中无所畏惧，修持梵行；恒常忆念受持而不忘失，因为善能悟解法性的缘故。

他的耳朵从来听不到不可爱的话，总是听到可乐的声音；口中常说令人悦意的话，因为这个人善知法性的缘故。

正念、智慧、法智全都成就，其心清净而没有浊秽；宣说百千部经而没有滞碍，所有演说都不会虚设。

对文字语句的差别已经修学，善解千亿种语言；对名言意味、义理旨趣都善能理解，这是由于悟入法性才有这样的功德。

夜叉、罗刹、天、阿修罗、迦楼罗、紧那罗、摩睺罗伽、鸠槃荼，这八部众常常爱敬他，这是由于他悟解法性的缘故。

心怀恶意的神众、毗舍阇，饮血食肉、极其毒害；而对于受持这寂定的人，这些都常常为他作守卫护持。

听到智者广大的言说，心中欢喜踊跃，身毛竖立，对那菩提深深爱乐，就能获得广大难思的福德。

这样的福报难以了知，在百千劫中也说不尽；因为他护持善逝的法宝藏，这宝藏无量无边，没有限数。

这就等于已经供养了一切佛，过去、未来的诸世尊，以及现在住于十方的诸佛，因为他能宣说这寂定的缘故。

如果有人为了乐求福德，供养具足十力的大悲者，供养无量无数亿佛，时间经过大海沙数那么多的劫；

又有另外一个乐求福德的人，对这胜义之法受持一首偈；在那劫末恶世之时，这样的福德最为殊胜。

如果有人能听闻一首偈，这个人就等于供养了一切佛；在这末代恶世之时，这是最殊胜的上等供养。

这个人就得到了最大的利益，堪受世间的奉敬；他是诸具足十力者所生的最上之子，在漫长的时间里已经作了供养。

他见到我在灵鹫山，我就为他授菩提之记；我已经付嘱弥勒世尊，那位佛也会为他授记。

这个人又会被阿弥陀佛宣说无量殊胜的利益；或者往生安乐国，又愿乐见到阿閦佛。

在无量无边百千劫中，这个人不堕任何恶道；在这菩提道上修行殊胜之行，成就无量种种快乐。

无量功德与殊胜利益，我现在已经这样宣说了；如果想要得到像我这样的功德，应当在末世中正确受持此经。

## 二、心的体性即是佛功德体性，即是一切法体性

“童子！因为这个缘故，菩萨摩诃萨能够这样了知不可思议的诸法体性，就能得到这样的功德利益，能赞叹宣说如来的真实功德，不会诽谤如来说如来不真实。为什么呢？因为如来已经证得诸法，为世间所知；这个人如实了知那些法，也就了知如来的无量功德，能如实了知不可思议的佛法。为什么呢？童子！因为佛有无量无边的功德，不可思议，远离于心。因为这个缘故，其他人不能思议、不能称量。为什么呢？童子！因为心没有自性，又没有形状颜色，不可观见。

“童子！这样的心的体性，就是佛功德的体性；这样的佛功德的体性，就是一切诸法的体性。因为这个缘故，童子！如果菩萨对于一切法的体性同一义如实了知，就称为菩萨寂灭于心、善解出离三界的善根。他如实了知，如实知见，如实宣说而没有不同的说法，随所说而行持，没有任何执著；他超出一切烦恼之地，超过欲界、色界，解脱于无色界，超过名言之地，超过音声之地。他善解离于文字之法，善解分别文字的智慧，善解离于语言之法；他了知文字，善于文字，善于文字差别的智慧，广知文字的智慧，善解一切法差别的智慧，善于一切法广大差别的智慧，善于分别一切处之法的智慧，与不可思议的佛法相应，魔王波旬及其魔民都不能破坏他。”

【按】这一段是全经极为关要的经文，可以说是经教大手印的直接依据。经中层层推进：佛的功德不可思议，是因为“远离于心”；而心本身“无性、无形色、不可睹见”；所以“心体性即是佛功德体性，即是一切诸法体性”。认识自心无形无色、不可见的体性，就是认识佛的功德与一切法的实相。冈波巴大师所传“认识自心即见法身”，正以此为根本经证。又须留意下文：证此者“善解离文字法”，同时又“善于文字差别智”，离言与善说并不相妨。

在宣说这一法门的时候，有八亿那由他的诸天人等证得修习无障碍之法忍，全都被诸佛授以无上正等正觉之记：经过四百八十万阿僧祇劫之后，他们将证得无上正等正觉，名号种种不同，国土各有差别，寿命则都相等。

这时，世尊说偈道：

如果有具足智慧的菩萨，趣向殊胜微妙的菩提之道，善于法与义的种种言说，能够行持一切法的体性；

口中常说真实之语，称扬佛的真实功德而为人演说，能了知一切诸佛之法，对三界至尊没有怀疑。

一切诸法同一义理，因为修习空性而如实了知；它们没有种种别异之相，对于这同一义理已经修学。

无分别之想与分别之想，众生、寿命、我、人之想，尽与无尽这样的想，都把这些想断除无余。

```
不见如来有其色　以知诸法自性无
亦非诸想随形好　以断一切颠倒故
一切诸佛不思议　远离于心体寂灭
若人能得如是知　真见无上两足尊
```

大意是：不见如来有色身之相，因为了知诸法本无自性；如来也不是种种想念中的相好随形好，因为已经断除一切颠倒。一切诸佛不可思议，远离于心，体性寂灭；如果有人能够这样了知，才是真正见到无上的两足尊。

【按】第一卷末说“然后观佛非色身”，这里进一步说明怎样才算“真见佛”：不在色相上见，不在想念的相好上见，而是在“远离于心、体寂灭”上见。结合上面“心体性即是佛功德体性”一段来读，真见佛与认识心的体性实为一事。

如果有人能了知神我之想，于其中发起殊胜的智慧，这样了知诸法之后，他就得名为清净之眼。

这个人没有种种障碍，以大智慧悟解出离之道，充满具足福慧二种因，没有一切对三有的愿求贪乐。

在真实之处如实而见，没有一切不真实的言语；这个人所有的言论，都随顺一切如法的仪则。

智者超出欲界，超越色界、无色界的烦恼之地；能在三界中远离染著，行于世间利益众生。

他超过一切名字之地，又超过音声，了知其体性是空；虽然经过很长时间演说佛法，对于那些言说却无所依著。

远离种种想与戏论，断除颠倒的种种恶见，对于智慧善能决定，这个人勇健，修行如同虚空。

如果有多亿那由他的魔，为了扰乱他的心意而说种种话，他都能映蔽这些魔众，不被魔力所自在摄持。

他舍弃一切魔业，戒行清净而没有热恼；如果能深深乐于禅定之乐，他就能了知世间是空。

如果说五蕴就是世间，他已经了知那些法的体性空寂；既没有灭，也没有生，一切诸法都如虚空。

他宁可舍弃自己的身体性命，终究不毁犯如来的教诫；对于持戒护持到达彼岸，随其所愿都能往生。

他游行于无量的佛刹，见到多那由他亿尊佛；终究不希求生在天上，远离一切对三有的愿求贪乐。

这个人不舍弃勤奋精进，在短暂的时间中也修行法行；在十方诸佛那里，善能赞咏称叹。

这时，月光童子听闻了这样的寂灭之定，舍弃了一切利养之事，修行诸佛所赞叹之法，说道：

“如果有人想要得到自然智，成为一切世间的最上者，就应当修学这殊胜的三昧；如果这样修学，就会成为人天之中的最上者。”

## 三、如何显说此三昧

这时，世尊告诉月光童子说：“童子！菩萨摩诃萨对于这里所显说的三昧之智，应当善加修习，并为他人显示。童子！怎样显示呢？就是对一切法生起平等之心，没有此彼，没有分别，也没有‘无分别’，无造、无起，无生、无灭；一切妄想、分别忆想、生起之想全都断除；心所攀缘的、意所思维造作的，以及种种假名，也都断除；也断除一切恶的觉观，了知五蕴、十八界、十二处都没有自性；断除贪、嗔、痴，也就是念、慧、解脱、惭愧都坚固；修行仪则中所应行的处所，也就是空闲之地、智慧之地，断绝来去；这是一切菩萨所学，一切如来所行之处，一切功德的成就。童子！这就叫做显说这样的三昧。如果能这样显说这个三昧，就不离一切禅定，心中不失去一切三昧，没有迷惑，能生起大悲心，利益无量无边的众生。”

【按】“无有分别、无无分别”：不但不落于分别，也不落于“刻意不分别”。初修者常以为认识心性就是压住念头、保持无念，经中这一句恰好破除了这一误解。

这时，世尊当下说偈道：

```
平等非崄地　微寂难可见
断除一切想　故名为三昧
非妄想分别　离见不可取
其心不可得　是名为三昧
```

大意是：这是平等之地，不是险峻崎岖之地，微细寂静，难以得见；断除一切想，所以称为三昧。它不是妄想分别，远离一切见解，不可执取；其心了不可得，这就叫做三昧。

【按】“其心不可得，是名为三昧”：不是另有一个三昧的状态可得，心不可得本身就是三昧。这与大手印“于心寻觅了不可得，即是见心”的教授如出一辙。

正住于如实之定，不执取一切法；因为如实地不执取，所以说为寂灭之定。

法没有一丝一毫的微尘那么多，也没有一点点可得；因为没有一点点可得，所以称为三昧。

认为有得或无得，这就叫做妄想；对于法远离分别，所以称为三昧。

借着声音来说明义理，但这声音之事本非实有，犹如呼唤时的回响，又如同虚空。

众生没有所住，住处不可得；“得”与“不得”的音声，自性都不可得；

无论是上去还是堕落，所去之道都不可得；“去”与“不去”的音声，对于道应当这样了知。

```
存有定是取　存无定亦然
无着行菩提　证圣道亦尔
```

大意是：心中存一个“有”，必定是执取；心中存一个“无”，同样也是执取。不执著有、也不执著无而修行菩提，证得圣道也是如此。

远离险峻的平等之地，这定与慧是无相的；佛子啊！修习这一法，就是善修与定相应。

不是文字所能做到的，要趣入这甚深的义趣，须舍弃一切语言之事，得定而无所执取。

得到此定的菩萨，如所说而相应安住；即使大火焚烧世界，他在其中也不被焚烧。

无量劫火生起时，就像虚空本来不会燃烧一样；如果了知法如虚空，这个人就不会被火焚烧。

如果在焚烧佛刹的时候，他在定中这样发愿，就能把那火熄灭无余，人和大地都不被毁坏。

他的神足没有边际，游行虚空毫无挂碍；随着所学之定而安住，菩萨就获得这样的功德。

无论是出生还是退没，都没有生起，也没有灭去；如果能这样了知，得到此定就不难。

世间有生有灭，这是如来随俗所说；如果能了知此定，应当知道这人就是世间的亲人。

他对世间不染著，世间法不能障碍他；如果身无障碍，就能前往诸佛刹土。

他常见清净国土，也见到世间导师；他得以听闻正法，在诸佛刹中演说。

他不生起无知，在宣说法性的时候，能通达诸法，如同随顺法性一般。

他在亿劫中演说，辩才从不间断；能变化出许多身体，化作其余的诸位菩萨。

这些变化出来的菩萨，前往游历诸佛刹，在千叶莲花上结跏趺而安坐。

他们显示诸佛菩萨之道，总持修多罗以及其余亿部经典，这都是由于修习寂定的缘故。

除了不退转的菩萨之外，其余的人纵然不可思议，也不能穷尽他的辩才，以及他所显示的佛菩提。

他乘着重阁而去，以种种珍宝庄严装饰；散布种种妙花，香气馥郁，非常可爱。

散布种种末香，并焚烧殊胜的妙香，或者散布无量的珍宝，都是为了菩提的缘故。

救济众生的菩萨，具有这样无量的功德；他断除了一切烦恼，获得了殊胜的神足。

不生起烦恼，清净而极其光耀，无为而不可破坏，这就是菩萨的境界。

```
寂静深寂静　离恼无烦恼
超过于戏论　乐无戏论法
文字无能入　诸法无相故
智知唯音声　是故名定者
```

大意是：寂静而又深深寂静，远离热恼，没有烦恼；超越一切戏论，乐于无戏论之法。文字不能进入其中，因为诸法本无相的缘故；智者了知文字言说只是音声，所以称为得定的人。

无尽而殊胜的寂灭，无须功用造作，不能以见而见；一切佛的境界，在实际之中没有可以安住的家宅。

【按】“实际无家宅”，是说证入实际时，心不再有一个可以落脚、可以依靠的处所。这与大手印所说“无所依、无所住”之心相通。

随着诸佛修学一切法的自性，修学这佛的功德，到达功德的彼岸；

非此也非彼，本际没有分别，所以一切诸佛到达功德的彼岸；

对于未来不去执取，因为已经了知法性；无须功用，没有戏论，到达功德的彼岸。

## 四、月光童子赞佛

这时，月光童子禀白佛说：“稀有啊，世尊！如来、应供、正遍知能迅速而善巧地宣说一切诸法体性平等。所说的这一切诸法体性平等，是菩萨所应修学的；如果菩萨对所说的三昧能够修学，就能迅速证得无上正等正觉。世尊！我又乐于宣说。如来！我又乐于宣说。善逝！我想要稍作一些宣说。”

佛说：“童子！你乐于宣说，就说吧。”

这时，月光童子在佛前合十指掌，向佛站立，称扬佛的真实功德，说偈赞叹道：

佛见到众生被生、老、病、死所逼迫，常被贪、嗔、痴等所迷惑，所以佛本来就是为此而发菩提心，愿成正觉，解开众生的一切束缚。

善哉！您在无量劫中修行，安住于布施，调柔身心，防护种种过失；持戒、忍辱、精勤精进，善修禅定和智慧。

您毫无希求地舍弃王位，妻子、宝货都能施舍；头、目、手、足以及寿命都能施舍，心中从来没有疲倦厌烦。

您的禁戒皎洁清净，没有垢染，宁可捐弃身体性命，也常常护持戒律；您善能禁制身口意，我归命调伏自心的善逝。

您安住在智慧矿藏般的忍辱之力中，即使被剜割身体也没有忿怒，以慈悲之力使流出的鲜血变成乳汁；我归命这无比奇特的如来。

您成就了大力，安住于十力，以无量智慧抉择诸法；佛以悲悯世间之心，救济利益六道诸趣的众生。

您已经了知一切法体性是空，见到一切世间都是虚妄；悟道契合无我之性，了知那解脱其实并无所脱。

【按】“知彼解脱无所脱”：既然本无实缚，解脱也就无实可脱。这正是了义的解脱观，不把解脱看成从一个实有的牢笼中逃出。

您远离烦恼和放逸，降伏魔的力量及其军众；了知圣道，具有无垢无碍的智慧，宣说寂静、无碍、清净之法。

即使虚空中的星宿坠落，大地、大海、城邑都坏灭，即使虚空那无为之性发生变异，如来也终究不会说不真实的话。

您见到苦恼的众生，安住在执取和分别之中，就为他们显示远离执取之道，也就是甚深的寂灭空性。

在不可思议无数劫中，大雄世尊早已勇猛修学；修学一切无执著之后，所以佛没有任何过失。

佛所修学的一切法，按照所证得的法为他人宣说；这不是愚痴凡夫的境地，也不是一切外道的境地。

心中常常安住于我想，这就叫做凡夫的过失；如果能善知无我之法，就没有一切过失。

大雄所说的真实之语，是恒常安住于真实之法的；安住于这样的真实之法以后，又能演说真实之语。

过去曾修真实之行，才能称述自己的本愿；获得真实的妙果报，所以能说真实之语。

具足所行的真实之行，善能觉悟真实之际；对这样所修的真实之行，我归命具有大智慧的人中至尊。

您的智慧最为殊胜，无与伦比；智慧具足，极为光明；究竟到达殊胜的智慧，我归命以智慧而言说的世尊。

您能与众生作亲友，久远以来修习慈悲之心；善能安住而不动摇，不动犹如须弥山。

您是天人之师，具备广大的功德，教诫大众与一切众生；善逝具有甚深殊胜的智慧，处在大众中无所畏惧而发出震吼。

这样无畏的狮子吼，如同狮子王的威猛雄健，降伏一切外道，犹如狮子摧伏野干。

大雄善能降伏不调顺的人，已调伏的人又能善加调御，能使他们成就为善友，安住坚固而不坏。

您见到那些苦恼的众生，最极依止于我见，就为他们演说无我之法，其中没有贪爱，也没有不爱。

您不学愚痴的凡夫人，依止险难的不善之路，而为他们显示真实之道，也就是趣向涅槃的道路。

如果有人执取我想，他就住于极大的苦恼之中，因为他不了解无我之法，而无我之法正是能灭除苦恼的所在。

在不可思议的劫数之中，大智世尊早已修学；修学远离执取之后，所以没有任何过恶。

您演说远离过失的种种法句，世尊自身远离一切过失；善说真实微妙的言语，口中所说能使人解脱百种怖畏。

无量那由他百千亿的天、龙、夜叉住在虚空中，爱乐无上最圣之法，听闻的人没有不契合真实义理的。

如来善美而令人欢喜的言语，温润、合时、称意、悦心，和合了无量的微妙音声，以怜悯之心解脱无数的人。

百千种伎乐音声，一时同奏，互相和合，全都是天界中的悦乐之声，如来的一个音声就能映蔽它们；

迦陵频伽等众鸟，同时一起发出微妙的声音，能使他人心生欣乐，但比起佛的音声，连少分都不及；

敲击发出欢喜的音乐，善于配合一切管弦，吹螺、击鼓、吹笛、弹琴、奏箜篌，在佛的音声面前都不能显现；

紧那罗王的歌舞之音，他已经善学百千种音乐，听到的人都欢喜，但在佛的音声面前都不能显现；

拘翅罗、鹦鹉、舍利鸟的声音，孔雀、哀鸾、鸳鸯等，所有一切有美妙音声的鸟，在佛的音声面前都不能显现；

可爱、悦乐、美妙的声音，世间所有善于歌咏的人，都来聚集，同时发声，佛的声音最为殊胜，远远超过他们。

诸天、夜叉、阿修罗王，三界所有的众生，其中最殊胜上妙的身体，佛放出一道光明就全部映蔽了。

如来的色身如同盛开的花朵，以一切相好作为庄严；出生的福果非常清净，光明显照于十方。

各种大鼓小鼓、箜篌的声音，铜钹、笙、箫的美妙声音，这样种种音声互相和合，百分之一也不及佛的一音；

乾闼婆、阿修罗、摩睺罗伽等，以及夜叉所有美妙的声音，连同三界中一切美妙的音声，比起佛来，百分之一也不及。

梵天所有的光明，以及有顶天身上的光明，世尊若放出一道光明，其余的光明百分之一也不及。

您的身、口、意业都清净，因为布施清净，所以不被世间所染；您是功德宝聚、人中之王，自然的功德无与伦比（无等等）。

## 五、世尊微笑，弥勒请问笑因

月光童子赞叹十力世尊的真实功德之后，欢喜地这样说道：“愿我供养佛法王的这一福德，使我成为释迦文佛那样的佛。”

佛了知他殊胜而最清净的修行，善逝当时就露出微笑。弥勒菩萨看见佛的微笑，便请问说：“唯愿人中至尊宣说微笑的因缘。”

那时大地六种震动，天与龙欢喜地住在虚空中，欣悦地瞻仰两足尊，请求说：“请为我们宣说微笑的因缘。

“这是诸佛的智慧所了知的，不是佛弟子声闻的境地；现在您要把谁安置在最殊胜的佛道上呢？唯愿怜悯，为我们宣说。

“除了慈悲的牟尼世尊之外，一切世间没有谁堪能授予法王之位；愿您为他授予菩提之记。

“我现在善为请问世间导师，具大威德的释迦牛王；您已经度到智慧光明的彼岸，除断了贪、嗔、痴的垢秽过失。

“在不可思议的恒河沙亿劫中，导师在这么多劫里修行，为求殊胜微妙的菩提之行；现在因为什么因缘而显现微笑呢？

“您能施舍自身的手、足等，妻子、眷属以及其余亲爱之人，常能修行这殊胜之行，所以我请问牟尼世尊。

“象、马、车乘以及牛、羊、奴婢、摩尼、真珠、黄金，没有见到任何一样珍宝，是您在修菩提行时不能施舍的。

“您最殊胜的智慧全都显现，了知一切众生之所行，对他们的心、信、性、欲都已善知，愿您宣说因为什么因缘而显现微笑？

“是谁曾经供养人中至尊？是谁如今成就广大的利益？是谁能受持奉行佛之所行？您为了谁而显现这微笑？

“那时大地六种震动，亿朵妙莲从地中涌出，花的光耀具足亿叶，金色炽盛，非常可爱。

“佛子们坐在那些莲花上，那是神足第一的菩萨们，无量的法师如云聚集，所以我作这样的请问。

“击鼓、鸣铙、吹螺的声音，伎乐有亿数之多，如恒河沙；在这些种种音乐之中，佛的声音最为殊妙。

“拘翅罗、频伽、鹅、鹤等众鸟一时如云聚集，同时各自发出美妙的声音，也不能和佛的音声相比。

“是谁往昔行布施、持禁戒，在无量亿劫中修习？是谁又供养人中至尊？牟尼为了谁而显现微笑？

“是谁往昔生起大恭敬心，曾经请问两足尊？因为什么因缘而得菩提，而现在便显现这微笑呢？

“过去所有的十力世尊，以及现在、未来世的诸佛，天人导师全都了知，所以我请问您这人中的宝塔；

“您能了知众生心念的次第，神足之力毫无减损，又知道众生心中所乐，所以我请问牟尼导师；

“修行无上最殊胜的行，对于因与相应之法已经善学，佛菩提之道要怎样才能得到？所以我请问两足尊；

“诸法微细，难以得见，空寂难以称量，不可思议，要修行十力世尊之所行，所以我请问世间大师；

“如果能善修慈悲之心，在不可思议的众生之中，却常常不起众生之想，所以我请问两足尊；

“您所行的境界难以思议，它的边际底蕴不可得，您已经超越了心的境界，所以我请问两足尊。

“您的布施、持戒都已究竟，智者明净，了知三世，远离一切过恶，是为了什么义理而显现这微笑？

“舍利弗、目犍连、拘律陀，以及如来的其余弟子，这都不是他们所行的境地，唯有佛的境界最为无上。

“您对一切法都到达彼岸，所有应学的都已究竟；导师生起大悲悯心，宣扬微妙的第一音声。

“过去无量阿僧祇劫，您也曾请问这样的义理，因而成为救度世间的亲尊；如今您已证果，请为我们宣说。

“夜叉、罗刹、龙、鸠槃荼，都在瞻仰两足最胜尊；一切都恭敬合掌而住，都在疑惑世尊为什么因缘微笑。

“众多菩萨大众如云聚集，具足神通，来自多亿佛刹，他们是从如来心中所生的长子，一切都恭敬合掌。

“世尊导师不会无缘无故，最殊胜的丈夫显现微笑；您那微妙的言语、如鼓的音声，是因为什么因缘而显现微笑？

“香象菩萨从东方而来，从阿閦佛的世界，被那由他菩萨大众围绕，为了请问释迦佛而来到这里。

“又从安乐妙世界，观音菩萨、大势至菩萨，被那由他菩萨大众围绕，前来请问两足尊释迦狮子。

“他们在过去无量亿佛那里，供养了无边的如来，犹如大海中的沙数，为的是修行无上殊胜的菩提。

“为一切诸佛所赞叹，对于菩萨的功德已经究竟，十方世界都闻名知晓的文殊师利，也合掌而住。

“游历那由他佛刹，这样殊胜的弟子难以得见；佛子们对功德已经善学，一切都合掌恭敬而住。

“他们的根器最为殊胜，再没有超过的，这样调伏柔软的人，能受持一切佛法之藏；愿您为他们宣说和润的言语。

“世尊导师不会无缘无故，最殊胜的丈夫显现微笑；愿您以微妙如鼓的音声演说，是因为什么因缘而显现微笑？

“您的声音如拘翅罗、鸲鹆、鹅、孔雀，如雷霆、牛王的声音震吼；愿您发出天乐般美妙的声音，唯愿您演说增长喜乐的言语。

“您善集慈悲，远离种种过失，智慧现前，断除愚痴；显示离于文字的真实义理，在百千劫中已经修持；

“您决定了知诸有空寂，显示苦灭的种种句义；能摧坏一切外道的智慧，宣说空无众生与寿命；诸佛修行百千种行，以百千种福德而庄严。

“百千诸天都来赞叹，百千梵天也是如此；夜叉、罗刹等心中清净，摩睺罗伽、金翅鸟、龙都欣喜。

“您口中常常宣说而无滞碍，这是清净微妙的业果所生起的；所有已经灭度的诸佛，以及现在、未来世的诸佛，您都了知而无障碍，这是从种种功德所生的。

“大海、大地以及诸山，一切都六种震动；诸天、阿修罗、龙、摩睺罗伽，都散布种种上妙殊胜的香花。

“您断除了贪、嗔以及昏沉与慢心，戒行与心意全都清净；以寂静的音声宣称无想之法，大圣就这样作狮子吼。

“您具足辩才，名称广大，对于眼（见）与法都善能平等；世间没有能与您相等的，也没有能超过您的；唯愿大悲世尊宣说微笑的义理。

“拘翅罗、频伽以及孔雀、命命鸟等众鸟的美妙声音，一时同发，非常可爱，但与佛的少许音声都不能相比；

“大鼓、金钲以及各种小鼓、螺贝、箫、筑、琴、箜篌，千种音乐同时演奏，与佛的少许音声都不能相比；

“诸天千种美妙的音乐，以及天女美妙的歌声，聚集相和，令人爱乐，与佛的少许音声都不能相比。

“救世导师以一种音声说法，众生随着各自的信解而生起种种不同的理解，一切人都以为佛是在专为自己说；愿大沙门宣说微笑的因缘。

“诸天与龙的美妙声音，迦楼罗、乾闼婆、毗舍阇的声音，这些都不能灭除烦恼，唯有佛的音声能够断除。

“佛的音声能使人虽然生起爱心而不染著，修行慈心便能远离嗔恚的过失，能生起智慧而远离愚痴；能这样做的人，就远离了一切垢染。

“佛的音声不会传出大众之外，却能断除百种疑惑；佛的音声没有高下，牟尼的妙音寂静而平等。

“即使三千大千世界散坏，大海在一念之间完全干涸，日月可以坠落在地上，世雄也终究不会说不真实的话。

“您的言语清净，具足六十种功德，吼声深沉美妙，无所畏惧；愿如来以梵音为我们宣说，寂静的世尊因为什么因缘而显现微笑？

“一切三有中的众生，您都能了知他们所行；过去、现在以及未来，愿人中至尊为我们宣说微笑的因缘。

“所有具足大悲的如来，在诸力中都已得到究竟；如来那清净如满月的面容，终究不会无缘无故而显现微笑。”

## 六、世尊为月光童子授记

这时，世尊当下以偈颂回答弥勒菩萨摩诃萨说：

这位月光童子，赞叹如来，爱敬无比；这样赞叹如来之后，将来还会为世间所称美。

往昔在这王舍城中，他已经见过多亿尊佛，在那些佛的座下常常请问这殊胜微妙的寂灭之定。

在修行菩提道的时候，他在一切世中都是我的儿子；他常能具足无碍的辩才，恒常安住于梵行。

```
彼人末代可怖时　惟是弥勒所证知
一切时中住梵行　能广分别是三昧
```

大意是：这个人在末代可怖之时，唯有弥勒能够证知；他在一切时中安住于梵行，能广为分别宣说这个三昧。

【按】这是世尊亲口为月光童子所作的授记：于末代可怖之时，住梵行而广说此三昧。噶举传承将冈波巴大师视为此授记的应验，冈波巴出家持戒、广传经教大手印，与“一切时中住梵行，能广分别是三昧”两句恰相符契。

如果想求得这殊胜的三昧，依照所称说的修行就能得到；他为无量亿佛所摄受，供养最殊胜的大导师。

我安住于智慧之中，所以作此记说：这位月光具有殊胜微妙之行，在末代之世没有障碍，对于他的梵行和寿命都无障碍；

他了知千亿尊如来，就像观看掌中的庵摩罗果一样分明。又超过那恒河沙数，他能在未来修行供养；

诸天与龙有八亿，夜叉众有七千亿，在未来供养两足尊的时候，这些都能互相辅助。

月光童子听到这样的授记之后，心中充满了欢喜与爱乐，便踊身跃上七多罗树那么高，住在空中，发出稀有之言：

“啊！佛所说的最为无上，安住于解脱、智慧与神通；因为安住于决定的殊胜智慧，一切异论都不能破坏。

“佛远离二边而证得解脱，观察事物而不执著事物；在三界中智慧无碍，完全没有一切戏论。

“对一切戏论都不染著，种种见解与觉观全部断除；善修圣道而无所依，不被他人破坏，也不违逆他人。

“又对三界无所依恃，断除一切结缚，所行清净；贪爱的束缚与枝蔓全都舍离，一切三有的相续都已灭尽。

“悟解诸法并无自体性，对离于言说之法全都了知；对于那些颠倒无智的人，佛如狮子吼摧伏野干。

“佛现在为我显现微妙的法藏，我现在获得了微妙的宝聚，断除了一切恶趣，我现在必定成佛，再无疑惑。

“愿您以具足百福、金色庄严的手，以此宝掌摩我的头顶；在天人大众面前，唯愿人中至尊为我灌顶。”

## 七、世尊往昔以此三昧愈病的因缘

世尊说：

“我忆念过去修行之时，在师子幢佛的教法中，当时有一位比丘，非常聪慧，名叫贤施，是一位法师。

“我那时作王子，名叫黠慧，身患病苦，极其困重；当时贤施作我的老师，他柔和、淳厚、正直，具备儒雅的德行。

“五百位良医一个不少，全都来为我医治，却都不能除去我的病，亲戚眷属心怀忧恼。

“这时大师听说我患病，便来到我这里慰问；贤施随即生起悲悯之心，为我宣说这个三昧。

```
我得闻此三昧已　不顾财宝心爱乐
了知诸法体性故　其时病苦即除愈
```

大意是：我听闻这个三昧之后，不再顾惜财宝，心中只爱乐此法；因为了知诸法体性的缘故，当时的病苦随即痊愈。

【按】此处病愈，经文明说是“了知诸法体性故”，不是靠咒力或药力。认识诸法体性能令身心苦恼当下解脱，这一点在噶举传承中屡见于祖师们以病为道的教授。

“那位比丘修行菩提行，后来成就佛道，名号然灯；我往昔作黠慧王子时，就是以这个三昧除去了苦恼。

“因为这个因缘，童子！我忆念这件事，现在付嘱给你：你要能忍受辱骂、毁辱等，受持、读诵这个三昧。

## 八、末世恶比丘的种种过失

“末世的比丘会有无量之多，他们放逸、毁犯禁戒，多有悭吝，坚固执著衣钵，乐于作恶，对这个三昧生起诽谤；

“他们嫉妒、轻浮躁动，放纵诸根，为了贪求利养而住在俗家，常常依靠放债收息来谋生，这些人将会诽谤这个三昧。

“他们伸手展脚，放纵狂妄，走路说笑时顾影自怜，结成伴党，扬臂随路而行，如果进入村落，就显现种种异常的举止。

“这样不合仪则的人，日夜把心系在女色上，对于色与声常常爱著，游行村邑时就显现这样的仪态；

“心中常常贪嗜美食，喜好嬉笑、歌舞和音乐，经营贩卖贸易，总是谋求利益，喜乐饮宴和乘骑；

“广为贮存积聚饮食之后，命终就堕入三恶道。

“他们专门从事开垦种植与耕田，守护玩赏自己所住之处，接受别人的差遣，传递书信，舍弃禁戒和威仪；

“亲近白衣（在家人）而违背佛教，毁破禁戒，住于恶道，常作佛所不赞叹的事业，也就是用斗秤欺诳他人；造作这样的种种恶行，以这些恶行堕入恶道。

“有的人原本拥有很多财宝、珠玉、黄金、贝币，舍弃亲爱之人而出家，却不能安住于清净的戒聚，反而又去开店贩卖，作鄙陋的营生。

“他们畜养公母牛马，使之交配生育，只把依恃财物粮谷作为最殊胜的想法；那又何必出家、剃除须发，却不护持戒律和仪则呢？

“我在过去修行菩提时，在千劫中修习苦行，为的是求得这样的寂灭之定，愚人听了反而嗤笑。

“他们行非梵行，喜说妄语，常常贪求利养，趣向恶道；披着梵行者的法服作为标帜，毁犯戒律，诽谤此定，说这不是佛法。

“他们彼此互相破坏，不能如法地求取利养，各自想要寻求对方的短处过失，命终堕于三恶趣。

“百千人中难得有一个能安住于忍辱的人；结党斗诤的人无量无数，舍弃忍辱，总是忿恨争竞。

“他们都自称是菩萨，希望名声流布于诸国；如果得到虚名，就自己欣喜庆幸，连善行都没有，更何况道呢？

“我从来没有听说过，也没有见到过：没有清净的行持，没有乐法之心，诽谤此法而不欣慕，却能获得菩提之道。

“许多人是因为无法生活才出家，并不求一切佛菩提；愚人安住在我见之中，听到说无我便惊恐怖畏。

“他们彼此之间总是互相诤论，以我慢抬高自己，互相凌辱轻蔑；自称自己对，说别人错，常行不善之事，却妄自欢喜。

“那些成就清净戒律种种功德、安住慈心修行忍辱、调伏柔和、淳朴善良的人，这些善人反被他们欺凌。

“如果将来有人生起恶心，极其抵触冲撞，作不善之事，喜乐斗诤，行非法之事，这些人在那时反而得到供养。

“我现在好好地劝告你，你应当对我生起清净的信心；对于如来所说的这一教法，那些恶人之辈，你不要亲近。

“对于极度贪爱、嗔恚深重、愚痴深厚、昏沉傲慢的人，无惭、无愧、心不调伏的人，你对他们要迅速生起忍辱之力。

```
我今所说无量德　比丘于此不安住
非但口言得菩提　要须坚固行者得
```

大意是：我现在所说的无量功德，比丘若不安住其中，是得不到的；菩提不是只靠口说就能得到的，必须要坚固修行的人才能证得。”

【按】卷末一偈与第一卷“说香而得活”遥相呼应：此三昧再殊胜，非口说可得。读到这里，正是检点自己的时候。

《月灯三昧经》卷第三终
