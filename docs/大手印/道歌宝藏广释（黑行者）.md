# 道歌宝藏广释（黑行者）

无量光（无量金刚） 造　（译者不详）

## 题解

本篇出自德格版丹珠尔续部（རྒྱུད་འགྲེལ།）ཞི 函第230a叶至第242b叶，东北目录编号 D2302，是对前面所译黑行者《道歌宝藏》（D2301）的逐句广释。全篇约一千零七十个短句，篇幅很长，所以这里只录汉译，不录藏文原文；各节标题后所注的段号，对应藏文底本按“།”切分后的逐段编号，以便查对。疑难之处另以【按】说明。

梵文题名：Śrī-Kṛṣṇavajrapāda-dohākoṣa-ṭīkā（ཤྲཱི་ཀྲྀཥྞ་བཛྲ་པཱ་ད་དོ་ཧ་ཀོ་ཥ་ཊཱི་ཀཱ）。

藏文题名：དཔལ་ནག་པོ་རྡོ་རྗེ་ཞབས་ཀྱི་དོ་ཧ་མཛོད་ཀྱི་རྒྱ་ཆེར་འགྲེལ་པ（吉祥黑金刚足道歌宝藏广释）。

【按】释者在礼敬偈中自称“智者无量金刚”，跋语称“班智达无量光”，应是同一人，生平不详。本篇没有译者跋语，译者不详。

【按】本释论的特点，是把黑行者道歌的每一句，都配到无上瑜伽续圆满次第的风、脉、明点修法上来解释，尤其大量引用《时轮》（《本初佛续》、具种的开示）、《密集》、《胜乐》、《喜金刚》、《合和明点续》等续部，以六支瑜伽、四喜、身语意三种系缚、红白菩提心等来解说道歌中的隐语。所以，读本篇时要知道：这是一位印度班智达依时轮等续部所作的一种解释，与噶举派等传承中把这些道歌当作直指心性的大手印口诀来讲，侧重点有所不同，两者可以互相参看。

【按】释论所引的根本颂，与德格版 D2301 的文句有不少出入，有些地方释论的读法更通顺，可以纠正 D2301 中的讹误或难解之处（如“ཟ་མ་ཏོག”“山居女”“于此没有心与心所”等），译文按语中都一一注明，读者可以对照前面所译的《道歌宝藏（黑行者）》阅读。

【按】本篇大量涉及无上瑜伽续圆满次第的修法，包括拙火、宝瓶气、闭门、明点升降、事业手印等方便道的内容。这些修法，必须具足灌顶、严守三昧耶、依止具德上师亲自指导才能修持，历代祖师都一再告诫不得依书私修。文中“主妇”“年轻女子”“莲花”“金刚”“精”“血”等，都是象征智慧与方便、空与乐、脉与明点的修道语言，绝不能照字面理解。本译文只是如实翻译论文，按语中的解释也只是依通常的说法所作的推解，不代表传承口诀。正文各节的小标题是译者为方便阅读而加的，原文没有分节。

## 正文

### 一、礼敬与立誓（第1–8段）

在充满无垢之水的轮回大海中，从密咒之道的湖里，生出了莲花——行者黑行者，以利益众生之蜜所成的芳香之花，愿它恒常胜利！由于自己弟子的劝请，智者无量金刚，要详细地分析行者（黑行者）《道哈宝藏》的词句与意义。

【按】释者在礼敬偈中自称“智者无量金刚”（མཁས་པ་དཔག་མེད་རྡོ་རྗེ），跋语则称“班智达无量光”（པཎྜི་ཏ་འོད་དཔག་མེད），应是同一人的不同称呼，梵文或为 Amitavajra 或 Amitābha，生平不详。本篇没有译者跋语。

### 二、释“世间人起骄慢”（第9–23段）

在这里，（作者）看到世间那些以颠倒的知见，自以为精通胜义、骄慢地自称“我通达真实”的人，便以被悲悯的重担所润湿的心，想要摧毁他们的一切骄慢；为了开示如实的密咒道的真实，为了一切众生的共同利益，阿阇黎行者金刚以俗语的词句，说了“世间人起骄慢”等等。世间人所起的骄慢是什么呢？就是说：“我精通胜义。”

这是总说，不是别说。为了开示别说，（作者）说“千万中只可能有一个”等等。“千万中若有（一个）”：“无尘”，就是在此离开了贪欲等烦恼，所以称为“离尘”，那就是俱生之身。“进入它”，就是心决定地进入它，即进入无尘。（作者的）意思是：那样的瑜伽自在者，就像我一样。

【按】“འཕྲལ་སྐད”，这里读作“俗语”，指黑行者用以写作道歌的地方语言（阿波布朗夏语，apabhraṃśa），而不是梵文。

【按】释论所引的根本颂，与前面所译 D2301 的字句略有不同：D2301 第2句作“现在我已进入胜义”，释论则作“我精通胜义”。以下凡有类似的出入，都在按语中注明，以便对照。

### 三、释“学者如蜂绕木橘”（第24–44段）

驳斥了那些怀着颠倒知见而骄慢的人之后，（作者）又就那些具有世间安乐之慧、显出“我了知胜义”之傲慢的学者们，说了“以经教与古老的正理”等等。了解经教等的学者们起骄慢，就是显出自己了知胜义谛的傲慢。

（他们）会怎样做呢？（作者）说“如蜂绕熟木橘”等，“它们绕行游走”。“蜂”就是采蜜的蜂。其余的意思如文：在外面绕行游走。同样，（这些学者）与外在的咒语和手印等相联系，因为他们执著于那种见解。甚深真实的意义，就是“不合甘露”的意思。如《四天女请问》这部大瑜伽续中说：“大能仁的法蕴，有八万四千种；若不了知其中的真实，那一切都没有果。”

【按】D2301 根本颂第5句作“经教与古老的吠陀”（རིག་བྱེད），释论引作“经教与古老的正理”（རིགས་པ）。

【按】第38段“བདུད་རྩི་མི་རིགས”，直译是“甘露不合理”，意思不明，可能有讹误，这里照字面译出。《四天女请问续》是无上瑜伽续之一。

### 四、戏论从无戏论的俱生智中生起（第45–50段）

（有人问：）如果是这样，那么戏论之相又怎样实际地运作呢？应当回答：戏论之相，如蕴、界、处等，也是从无戏论的俱生智本身生起的；从它生出了戏论之相。为了开示这一点，（经中）也说：“以戏论令成无戏论。”

### 五、释“菩提心与尘”：种种三法（第51–84段）

所以，为了开示众生如何从“ཨེ་ཝཾ”字、从俱生之身中生起，（作者）说了“菩提心与”等等：“以菩提心与尘，为不动之身所拥抱。”

（这三者所表示的是：）空、极空、大空；显现、增长、近得；心、心所与无明；女、男与中性；昼、夜与黄昏；化身、受用身与法身；身、语、意；（气的）出、入、住；迎请、请回与安住；ཨོཾ་ཨཱཿཧཱུཾ三字；下、上与平的门；本尊的真实、咒的真实与坛城的真实；萨埵、罗阇与答摩；月、日与罗睺；生、住与灭等等——这些都是以“菩提心”“尘”与“不动”这三个词来表述的。

【按】这一段列举了一系列“三法”，说明根本颂中“菩提心、尘、不动”三词，分别对应各种三分法：如空的三阶段、三显现（显、增、得）、三身、三门、三字、三德等。这是无上瑜伽续中常见的配对方式。

【按】第70至72段“རླངས་པ”“ཕྱུར་བ”“རྣམ་པར་བཅིངས་པ”，这里依上下文读作气息的出、入、住，不能完全确定。D2301 根本颂第10句作“不动因此被染”，释论引作“为不动之身所拥抱”，字句不同。

### 六、释“于本然之身中见到”（第85–105段）

在哪里见到它呢？（作者）说“以莲花种子的自性，清净的俱生于身中见到”等等。莲花之身就是莲花，它的种子就是自性；“清净”，是因为它无垢而本性光明，所以它就是俱生之身。如果想：在哪里见到、在哪里了悟它呢？就是在自己的身中见到。这的意思是：（它就是）从身、语、意所生的薄伽梵；进入一切空界的众生，就是“ཨེ་ཝཾ”字的体性。

如《本初佛续》中说：“身的明点是月，是菩提心；语与重点，是尘与日；罗睺与时火是心；ཨེ与ཝཾ，是一切众生唯一的种子。”正因为这样，（续中）也说到空行母之轮的生起、安住、融入与极寂静。

【按】“本初佛续”（དང་པོའི་སངས་རྒྱས་ཀྱི་རྒྱུད），一般指《时轮续》的根本续。本篇释论大量引用《时轮续》，以时轮的身体观（明点、脉、气）来解释黑行者的道歌，这是本篇的一大特点。

### 七、从一种子何以生出种种众生（第106–121段）

所以，从“ཨེ”与“ཝཾ”二字中，生出种种的众生。（有人问：）就像从一团泥中，只能生出一种瓶子的果；那么从一（种子）中，怎么会生出种种形色、种种方所、相续不断、无边无际的众生呢？对此应当回答：“如同从师傅那里学得知识，如同从灯点燃灯，如同从印模印出印纹，如同从镜子中现出面容，如同从声音生出回声，如同从火晶生出火；对着日光，日轮生火，（没有日光就没有火）；吃了酸物就流涎，没有酸物就没有。不从自生，不从他生，不从二者共生，也不是无因而生；任何事物，从任何东西，永远都没有真实的生起。”

【按】这一偈所举的一系列譬喻（师传、灯、印、镜、声、火晶、酸），是佛教说明“缘起而无实生”的经典譬喻，见于《稻秆经》与龙树《缘起心论》等：众生的相续，并不是有一个实体从前世迁移到后世，而是如这些譬喻一样，依缘而现、无有实生。第116、117句意思不完全清楚，这里依文意补出括号中的字。

### 八、引《时轮续》说身体的生成（第122–157段）

（续中说：）“父母的精与血，以及命气与下行气，再与心金刚相合，就是身体生成的因。无量光、宝生、命气与下行气，依次是身、语、意与贪，以及心金刚之面。从精生出月，从血生出日，从命气生出罗睺，从下行气的力量生出时火。从精生出诸脉，从精生出骨；从尘生出血，从肉生出皮，从骨生出髓。从月生出水，从血生出火，从罗睺生出命气，从时火生出下行气，从力生出意。一切有身者的小舌与舌，都由精所生；左右两眼由尘所生；同样，两鼻孔由血所生；同样，两耳孔由空所生；同样，下面的三门由下行气所生；同样，两乳孔由罗睺所生；同样，两睾丸由下行气所生。”

【按】这一大段是《时轮续》对人身生成的说明：以父精、母血、命气、下行气四者，配合月、日、罗睺、时火，说明身体各部分的生成。原文多处传抄似有讹误（如“从精生骨”与“从精生脉”重复、“从肉生皮”与上下文不连贯），这里依字面照译，不作改动。这些是时轮金刚的专门教法，须依传承口授才能确切理解。

### 九、释“虚空之水与无量光之泥”（第158–187段）

这样，身体的莲花依次生成；为了开示生起之聚合的世俗与胜义的次第，（作者）说了“以虚空之水”等等。“虚空”就是不动（佛），它被表示为“水”，因为它极为清净。如（经中）说：“虚空的甘露之滴。”所谓“无量光之泥”，无量光就是菩提心，应当理解为“以尘为庄严”。从那里，“舍弃了泥的根”，是表示中间（的阶段）。

这的意思，在别处也是这样：如同种子、水与泥聚合的时候，苗、茎等就生起；同样，以法界为种子、以虚空为水、以菩提心为因而生起的薄伽梵不坏之身，以莲花的体性，依茎、枝、叶的次第而圆满。

（作者）说“它舍弃了罪恶，具有根与茎”等等：“罪恶”就是过失，“舍弃”就是摧毁，因为它是光明；以此摧毁（罪恶），所以称为“舍弃罪恶”，它是第一个元音（ཨ）的自性。如《本初佛续》中说：“第一个元音的自性，诸佛称之为‘慧’。”

【按】D2301 根本颂第14句作“它彻底舍弃根而作”（རབ་ཏུ་སྤངས），释论引作“它舍弃了罪恶”（སྡིག་སྤངས），并据此解释为光明摧毁罪恶。两者字形相近，可能是传抄之异，也可能是两个不同的传本。

【按】第171段“དེ་ཉིད་བར་པ་མཚོན་པའོ”，“བར་པ”（中间）所指不明，可能指中有，或指生起过程的中间阶段。

### 十、释“生起ཧཾ字之相”（第188–223段）

舍弃了罪恶，而把主要的根作为茎干。（有人问：）是什么舍弃了罪恶，而作成主要的根与茎干呢？（作者）说“生起了ཧཾ字”，别人的说法中称之为“清净的种子”。它就是以不坏的彼岸（？）与口的方式所成的“ཧཾ”，是无支分的金刚字，有短音与长音；（它是）极长音收摄的体性、一切安乐收摄为一的体性，称为安住于圆满的月轮之中。

如《吉祥合和明点续》中说：“从元音与辅音字中，（生出）三十二种菩提心；了悟莲花坛城的咒，被称为‘续’与‘坛城’。（它）被说为住在众生头脑的中央，在它的中央有ཧཾ字，是明点的自性，不可摧坏。它是一切众生以及动与不动（世界）生起的因；以明显与不明显的形相，安住为它的种子体性。一切有身者的身形，最初都从它生起。它以甘露下滴的方式，安住于昼与夜；以向下进入的方式，火就燃烧而住。它将成为圆满的坛城，对此毫无疑问。因为它是诸事物的最上心髓，所以称它为坛城；由于摄取与执持它，身体就被认为是坛城本身。”

“生起之相”这句话中，“相”（རྣམ་པ）在这里只是俗语的修饰词；“生起”，就是从如上所说的ཧཾ字所生。

【按】“ཧཾ”字在无上瑜伽续中常观于顶轮，是白菩提（明点）的种子字；与脐轮的拙火相对，拙火向上燃，ཧཾ字的甘露向下滴，这正是引文中“甘露下滴”“火向下进入而燃烧”所说的。第192段“གཞོམ་དུ་མེད་པའི་ཕ་རོལ་དང་ནི་ཁའི་ཚུལ”意思不明，这里只能照字面试译。

【按】《吉祥合和明点续》（དཔལ་ཁ་སྦྱོར་ཐིག་ལེ，Sampuṭa-tilaka）是无上瑜伽续之一。

### 十一、释“若玛、江玛与四瓣莲花”（第224–254段）

（有人问：）如果是这样舍弃了罪恶、作成了主要的茎干，那么根的支分、枝与叶的形相是什么呢？（作者）说：“以若玛与江玛二者，安住为右与左两边的茎干；四瓣莲花与四根，大乐住在巢中。”

在这里，“江玛”这个词，表示元音、智慧与月；它的自性是：在左边的鼻孔中，命气运行，安住为江玛。“若玛”这个词，表示辅音之形、方便与日；它的自性是右边鼻孔的自性，自性中命气运行，安住为若玛。从这里所生的，依次聚合为识、行、想、受与色——这些坛城，依三有生起的次第，就是江玛；地、水、火、风与空的自性，依三有坏灭的次第，就是若玛。这样，依十二迁转的次第，舍弃了不平等与平等地运行的所取与能取。

“四瓣莲花”，就是四空的自性，是四片花瓣；“四根”，就是四界的自性，四条脉向上安住。（它们）住在哪里呢？（作者）说“大乐住在巢中”：四喜的自性、空性本身，就是大乐之巢；“住”，在这里就是大乐之处，即顶轮的莲花。在那里，一切四空，就是勇父与空行母网的聚集，称为“札兰达惹”，意思就是“在须弥山顶上”。

【按】“江玛”（རྐྱང་མ，lalanā）与“若玛”（རོ་མ，rasanā）是左右二脉，分别配以月与日、智慧与方便、元音与辅音。“十二迁转”，是时轮等续所说气息在一昼夜中依十二宫迁转的次第。“四空”“四喜”，是圆满次第中依次生起的四种空与四种喜的体验。

【按】“札兰达惹”（Jālandhara）是印度二十四圣地之一，在圆满次第中常与顶轮相配。“须弥山顶”也是顶轮的象征。

### 十二、释“取诶旺种子，如莲开放”与“蜂饮花蜜”（第255–270段）

“取来ཨེ་ཝཾ的种子”等：“ཨེ་ཝཾ”，就是具有上面所说性相的ཨེ་ཝཾ字；取来它的种子，它的种子成为心髓；“花”，就是盛开的不坏莲花。意思是这样：就像种子生出茎干等，那空的花也会以种子的心髓为因；在这里也是一样，从ཨེ་ཝཾ字所生的身体之莲，也是以ཨེ་ཝཾ为心髓的花。

“以蜂之形”：蜂就是心金刚，它的形就是自性。“大乐勇士”，就是由方便与智慧二者相合的结合；因为它明显地以不间断的大贪的体性而安住，所以那不坏的薄伽梵就称为“勇士”。“蜜”就是花的精华；意思是：因为是大乐的勇士，所以菩提心体验大种（的精华）。

【按】“方便与智慧二者相合”“大贪”，是无上瑜伽续的专门术语，指方便与智慧双运所生的大乐，在胜义上就是空乐无二的智慧。这些都须依灌顶与上师口授来理解，不能照字面理解为世俗的欲乐。

### 十三、释“取五大种子而圆满”（第271–299段）

（有人想：）以这样的体性，ཨེ་ཝཾ字自性的薄伽梵，怎样成为有漏五大的自性呢？（作者）说：“五大的种子，取来之后，从聚合中生起。”“大种”，就是地等五大；“种子”，就是ཨེ་ཝཾ字；“取来之后聚合”，就是从金刚与莲花的结合中所生的大种。

为了阐明这一点，（作者）说“坚硬的是地”：地界就是坚硬，坚硬就是地界；因为能融化，所以是水；因为热，所以是火；因为动，所以是风；因为是安乐，所以是虚空界。“五者圆满”，就是由这样形成的五大而圆满，摄而言之，就是菩提心。

如《吉祥喜金刚续》中，（问：）由大种所成的、具有补特伽罗的蕴，是什么缘故呢？薄伽梵说：“从金刚与莲花的结合中，由接触而生坚硬的地，由湿润而生水，由摩擦而生火，由动摇而称为风，安乐是虚空界；以五种形相而周遍环绕，诸元音是生起之因。”

【按】这一段以“金刚与莲花的结合”（方便与智慧双运）说明五大的生起，引自《喜金刚续》。这是无上瑜伽续中以内在的方便智慧双运来说明一切显现生起的象征说法，须依传承口授理解。

### 十四、释“愚痴的这些都是空”：生起与融入的次第（第300–335段）

“那”（དེ་ནི），就是“它本身”；“它本身就是这个”，是这一句的意思。“地等四种真实，以及四种空性，作为生起与坏灭之因，应当了知这八种义。从光明生出大空，在其中生出方便，从方便中又生出识，风也从那里生出，从风生出火，从水中又生出地，依此次第，众生生起。地融入水，水融入火，火融入微细之界，风融入心，心成为心所，心所融入无明，它又成为光明，三有就灭尽了。”

为了开示这一点，（作者）说：“愚痴的这些，都是空。”因为（那些人）在这样的乘之外，所以称他们为“愚痴者”。唉，愚痴的人们，要以密咒的方式来了知这一点！“这些”，就是这空性的光明；意思是：离开了它，在别处并没有空性的真实。

它这样开示：三有寂灭、唯一的大乐金刚薄伽梵本身，在这里显现于自己身体的莲花中；那不坏之花的精华，被心以蜂之形常常摄取而安住。如《吉祥喜金刚续》中说：“自己作，自己摄取；自己是国王，自己是主尊。”

【按】这一段引文说明了生起与融入的两种次第：从光明生出空、识、风、火、水、地，众生生起；临终（或在圆满次第中）则依地融水、水融火、火融风、风融心、心融心所、心所融无明、无明融入光明的次第消融。这与藏传佛教所说的“死亡融入次第”相应。引文中“从风生火，从水生地”中间似有脱文（缺“从火生水”），这里照原文译出。

【按】根本颂第32句“这些愚痴的（显现）都是空”，释论把“愚痴者”解释为对乘外之人的呼唤，并把“这些”解释为空性的光明。

### 十五、能成办者：既不舍境，亦不贪境（第336–340段）

这样确定了所应成办的之后，现在来观察能成办的。在这里，首先，舍弃对一切境的受用，并不是能成办者；贪著一切境，也不是能成办者。因为（前者）是声闻与波罗蜜多乘等所安住的方式。

【按】这一段开始讲修道（能成办者）：既不像声闻、显宗那样舍弃一切境界，也不贪著一切境界。这是下文“受用三有而得解脱”的前提。

### 十六、以具方便的受用成办大贪之觉悟（第341–386段）

为了开示：以受用一切过失已经清净的境界，而现证大贪的菩提——（所以说）境界的这一真实，正是能成办者。如萨惹哈说：“有些人舍弃诸境，有些人被诸境所缚；有些人就取这境界本身，而现证殊胜的解脱。”薄伽梵也说：“世间被什么所缚，就以那个使世间解脱；愚痴的世间不知道这真实，舍弃了它，就得不到成就。世间被贪欲所缚，就以贪欲本身得解脱；这种逆转的修习，佛教之外的外道不能了知。”

（有人问：）如果是这样，一切爱乐、贪著（欲乐）的众生，岂不都成了现证大贪的菩提？（答：）不是这样。我们并不是说，仅仅受用境界，就是相续不断的大乐；而是说它须与方便相结合。因为离开了方便的境界，不了知三显现，就不能现证大贪的安乐。如《一切大智等入续》中说：“执著于男女根的交合、一心沉溺的人，不能获得大贪的菩提。什么时候只是取了安乐，而仅以殊胜的信解，安住于初学者的地位，那时就是有学。若有人以金刚与莲花结合的安乐，表示自性显现的真实功德，那就是进入了大贪的安乐。”如《吉祥喜金刚续》中说：“使凶暴众生被缚的种种业，若具足方便，就以那业本身，从三有的束缚中解脱。”

（有人问：）然而，（这种安乐）是有贪著的；而大乐是无相的。怎么能与它相同呢？对此应当回答：有相的安乐本身，以殊胜上师的口诀，就成为无相。如萨惹哈说：“这有相的安乐，大士们说它就是无相；它是自生智慧的体性，是遍计（而现）的大乐。”所以，具有方便地受用境界，就是现证大贪菩提的能成办者。

【按】这一段是本篇释论在见地上的关键：所谓“受用三有而得解脱”“以贪欲解脱贪欲”，并不是说任何人放纵欲乐都能成佛。释者明确说：仅仅受用境界、执著于欲乐的人，不能得菩提；必须“具足方便”，即在上师口诀的引导下，以了知三显现、认识空乐无二的智慧来转化，才能使“有相的安乐成为无相”。这是无上瑜伽续中极为特殊的方便道，传统中只对具有相应根器、得到灌顶与口授的修行人开示，绝不能照字面去理解或效仿。

【按】释论所引萨惹哈“有些人舍弃诸境……”一偈，与前面所译《王后道歌》等萨惹哈道歌的思想相同。“三显现”指显现、增长、近得三种心的显现阶段。第384段“ཀུན་རྟོག”（遍计），这里依字面译出，意思不完全确定。

### 十七、五大坛城与气息（第387–426段）

（作者）说“地、水、火之界”等等：地，是地的坛城；水，是水的坛城；火，是火的坛城；风，是风的坛城；虚空，是虚空的坛城。这五者，依生起与坏灭的次第，称为月与日的次第。如《吉祥本初佛续》中说：“虚空等常从左（脉）运行，坏灭者等常从右（脉）运行。”

《吉祥密集续》的后续中也说：“五智自性的气息，是五大的体性；以团块之形呼出，在鼻尖上仔细观察；具有五种宝色，称为命与勤（气）；在心间观想自己的咒语，把心安置于明点之中。”对此的详细解说，在名为《金刚鬘》的大续中说：“在鼻尖上观想芥子，称为命与勤；在命与勤中有五种光芒，是五佛的体性。”金刚藏也说：“从左、右两个鼻孔，最初或最后，无论哪一个，当（气息）从中间运行时，就是虚空之风在运行；当风的坛城运行时，就依靠鼻孔的上部运行；当火的坛城运行时，就依靠右鼻孔运行；当地的坛城运行时，就接触下部运行；当水的坛城运行时，就从左边运行。”

“以心取这些坛城为境”：境，就是金刚与莲花的结合；从中，心体验安乐的智慧手印，它的境就是“心”。取来它之后，就了悟坛城之轮；“圆满”，就是进入一切相的六智等等，意思是要这样去体验。

【按】这一段引用《时轮续》《密集续》后续、《金刚鬘续》以及金刚藏的论著，说明五大与气息在左右中脉、鼻孔中运行的规律。这是圆满次第中“命勤”（气息修持）的专门教法。“金刚藏”（རྡོ་རྗེ་སྙིང་པོ），可能是《喜金刚续》释论的作者，也可能指时轮传承中的金刚藏菩萨，这里不能确定。

【按】D2301 根本颂作“把地水火风空，取为心识之境而了知”，释论把“心之境”解释为方便智慧双运中所体验的智慧手印。这是释论的密乘化解释。

### 十八、释“无波浪的平等”与“善恶皆无”（第427–450段）

为什么呢？（作者）说“无波浪的（境界）完全受用”。“波浪”，就是迎请与送回；因为没有这些，所以“无波浪”。因为它是如实的ཨེ་ཝཾ字的体性，所以是俱生的体性；因为它远远超越了如瓶般（被摄持）的风，所以是“平等”。

“过失，就是一切垢都舍弃了”：一切罪恶就是一切过失，是离贪的体性；舍弃，就是解脱。如《本初佛续》中说：“没有像离贪一样的罪恶，没有像安乐一样的殊胜善；所以，国王啊，要常常把心安住在不变的安乐中。”

因为对这样的安乐也会起显现的傲慢，所以（作者）说“在那里善与恶也都没有”等等：“恶”，就是离贪的痛苦；“善”，就是菩提心不再外泄的安乐；在那里一个也没有。如《吉祥合和明点续》中说：“贪与离贪二者，若吃了，就成为三有。”

【按】“没有像离贪一样的罪恶，没有像安乐一样的殊胜善”，是《时轮续》中著名的一偈，在无上瑜伽续的语境中，“离贪”指菩提心的外泄与安乐的丧失，“安乐”指不变的大乐。这是密续的特殊术语，与显宗所说的“离贪是善”在语境上完全不同，读者须特别注意，不可混淆。

【按】“如瓶般的风”，指圆满次第中的“瓶气”修法；“超越瓶气”，意思是俱生的境界超越了一切有为的气息修持。

### 十九、释“空与非空之间”（第451–477段）

“黑行者清楚地开示”，意思是：这是行者黑金刚清楚地开示的，别人没有清楚地开示过。为了开示：那些背离这种瑜伽的人，即使修了本尊瑜伽，也不能达到无分别，（作者）说“受用如外在的诸大之后”：以自己的心决定地受用，“空性”就是了悟诸相之轮为空性；“非空”就是观想自己本尊的瑜伽士等等，因为心进入并缘取它。

“空性与非空二者”，就是在空性与非空的中间。“唉，愚人们，你们连那一个真实也没有看见”，意思是没有了悟。（有人想：）如果是这样，怎样才只有那个真实呢？（作者）说：“唯一的俱生，就是那个。”如果只有俱生存在，那只有黑金刚知道。

“即使读了许多经论”：论，就是量论等等；经教，就是事续与行续等等。即使以种种方式阅读、听闻、思惟与串习它们，也一点都不了知，因为它们没有它的体性。“无波浪的密咒之道的口诀”，意思是：别人要像我一样才能了知。

【按】释论把根本颂第38句解释为“黑行者清楚地开示”，正好补足了前面所译 D2301 中意思不明的那一句。

【按】“空”指了悟诸相为空，“非空”指执著本尊相的生起次第瑜伽；俱生就在二者的中间，既不落空，也不落有。

### 二十、释“不往上行，不往下走”：止息上下二气（第478–500段）

为了以种种方式详细开示这样的口诀，（作者）说了“不往上行，也不往下走”等等。“不往上走”，就是以这种方式遮止命气；“不往下走”，就是遮止下行气。由身、语、意的差别，遮止月、日与罗睺，水、火与空性——自己种姓的三条道路。“不往下行”，就是以这种方式遮止向下运行的气：由身、语、意三者的差别，遮止大便、小便与菩提心运行的地、水、火（与）智慧界的三种姓。

这样，由于遮止了上下命气与下行气的道路，见到了前面所说的智慧影像，在此之后，以金刚念诵的仪轨，使命气与勤（气）常常生起。如《吉祥时轮续》中说：“见到影像之后所生的，是命与勤；常常从上、下与三脉中，为了遮止身、语、意三者，月、日、罗睺，以及大便、小便与精的运行；月、日与黑暗，以及身、语、意的脉，大便、小便与时的运行，它们依次是命与勤。”

【按】“遮止上下二气”，是圆满次第中令气入中脉的修法：上行的命气与下行的下行气都被遮止，聚于中脉，由此见到“智慧的影像”（光明的征相），然后以“金刚念诵”（配合呼吸的ཨོཾ་ཨཱཿཧཱུཾ念诵）来修持命勤。这是时轮金刚六支瑜伽中的专门修法，须依传承口授。D2301 根本颂只说“不往上行，不往下走，舍弃二而稳固安住”，释论以时轮的气脉修法作了详细解释。

（续前引《时轮续》）“月是身的方便，智慧是日；智慧是大便之脉，主（方便）是精（菩提心）的运行；水、火、空、地与风，智慧界在于自证；以方便，心是黑暗天女，智慧是菩提心的运行；上与下的六种姓，以身、语、意而作；以智慧与方便结合的差别，安住于一切有身者。”

【按】这一段《时轮续》的引文非常简略，是时轮金刚以身、语、意配左右中三脉与种种界、种姓的专门说法，意思多不能确定，这里只照字面译出。

### 二十一、释“于二者不行而安住”：中间之息（第513–529段）

（有人问：）这样，命与勤是怎样安住的呢？（作者）说：“于二者中不运行而安住。”“二者”，就是上与下的命与勤；“不运行”，就是完全舍弃；以这样的体性不动而安住，称为“中间之息最为殊胜”。如具明者所说：“俱生的黑鲁嘎，中间之息最为殊胜，具足大便、小便与精的三条脉。”在《随入明显事物之真实》中也说：“俱生虽然住在自己的基中，却完全从分别之网中解脱；自己也生起不可言说的喜乐，那就是空性的自性。”

【按】“中间之息”（བར་མའི་དབུགས），指气息既不外出也不内入、止息于中脉的状态，在圆满次第中被视为最殊胜的境界。“具明者”（རིག་ལྡན་པ）所指不明。“随入明显事物之真实”可能是一部论典的名称，这里依字面译出。

### 二十二、释“心不迁移”与“主妇住家”（第530–566段）

这样，为了开示（如何）遮止大乐的菩提心（外泄），（作者）说：“黑行者说：心不迁移到任何地方。”阿阇黎黑行者说：心，就是菩提心；“不动”，就是不向任何地方外泄；因为舍弃了向上与向下的外出，使时之脉成为三界。这的意思是：我所要成办的，并不只是使有兔之月（的明点）不下落，而是（遮止）向上与向下二者运行的体性。

（有人问：）这种没有外出的体性住在哪里呢？（作者）说：“不动之风的主妇，住在家中。”“不动之风”，就是燃烧之风；“主妇”，因为它就是智慧手印的体性；“家”，就是它的安乐、虚空界、前面所说的ཨ与ཧཾ的自性，即阿瓦都底（中脉）；“住在其中”，就是住在那个家里。

这的意思是：风具有运行的性质，依于虚空界；被带到离开来去的虚空界中，心的坐骑（风）连同显现，就融入具足三智之中。所以说：它的自性，进入了大乐的薄伽梵。如《无上密意续》中说：“显现、增长与种种聚合，这些被说为心的三种相。风以微细之形，与智慧相混合；从根门出来，进入诸境。不具显现的，成为风之坐骑的因；在其中，这一切自性，次第次第进入黑暗。风住在哪里，它就在那里运行；只要风不停止运行，显现就不会稳固。”

【按】释论把“主妇”解释为“智慧手印”，把“家”解释为中脉（阿瓦都底），把“心不迁移”解释为菩提心（明点）不向上下外泄。这是圆满次第的专门解释。“有兔之月的明点”，指顶轮的白菩提。

【按】“风是心的坐骑”，是密乘的重要观念：心依于风（气）而运动；风止息、融入中脉，心的种种显现（显、增、得三相）也就依次融入光明。引文说“只要风不停止运行，显现就不会稳固”，意思是风动则心动。

### 二十三、释“殊胜之山的深洞”：脊柱与中脉（第567–588段）

（有人问：）它怎样成为一切众生所共有的呢？（作者）说“在最殊胜之山的深洞中”：“殊胜”就是卓越体性的山，“最”就是脊柱的体性。如《吉祥合和明点续》中说：“风住在脚底，风呈弓形；住在会阴三角处的，同样是红色的三角形；以圆形为体性，水住在腹部；在心间，地也遍呈四方而住；脊柱如杖的体性，同样是山王须弥。”它的洞就是山洞，因为不是身、语、意的行境，所以是“深”。

（问：）因此会怎样？（作者说：）“一切众生都会被束缚”：一切众生都被束缚，就是衰损；因为向上直到顶门之间，以二根结合所生安乐的、显现的傲慢之菩提心不存在。

【按】释论把“殊胜之山”解释为脊柱（须弥山），“深洞”解释为脊柱中的中脉；并引《合和明点续》说明五大在身中的位置（风在脚底、火在会阴、水在腹部、地在心间）。D2301 根本颂作“一切众生都会贪著”，释论作“都会被束缚”，并解释为菩提心外泄而衰损。第588段语法复杂，以上依文意试译。

### 二十四、释“水干涸、劫火炽燃”：菩提心外泄而死（第589–620段）

（问：）怎么知道一切众生都被它所缚呢？（作者）说：“无垢的水干涸了。”“无垢”，就是胜义的自性；“融化”，就是世俗的、如军荼花（白色）一样的（菩提心）；称为“无垢之水二谛”的菩提心，就会干涸，即向下堕落。因为菩提心会成为外出的体性；当它向下堕落时，就成为衰损。如《吉祥本初佛续》中说：“一切有身者在死亡时，月的甘露向下滴落；识的自性与性相，以及日、血、罗睺，向上而行。”

（问：）因此会怎样？（作者）说：“劫火炽燃。”“劫火”，就是菩提心外泄的阶段，是黑分的性相，称为死亡之时。如《吉祥本初佛续》中说：“堕落就成为离贪，从离贪生出痛苦；由于痛苦，界就耗尽；由于界耗尽，就会死亡；由死亡又生出后有。这样，（一切）是由离贪而生的；除此之外，众生没有别的（来源）。所以，要尽一切努力，舍弃（这种）心所的离贪；以不外泄的真实安乐，从轮回的束缚中解脱。”

【按】这一段是时轮金刚的特殊观点：众生的死亡与轮回，是由于菩提心（明点）的外泄（称为“离贪”）而来；所以修行要守护菩提心不外泄，以“不变的安乐”解脱轮回。这里的“离贪”是密续的特殊术语，指明点外泄、大乐丧失，与显宗的“离贪”意思完全不同。读者务必注意。

【按】“军荼花”（ཀུནྡ）是一种白色的花，在密续中常用来比喻白菩提。

### 二十五、释“持地难持”：以六支瑜伽持风与菩提心（第621–641段）

（问：）怎样使菩提心生起呢？（作者）说：“这持地极难执持。”“难执持”，就是须以六支瑜伽来执持风、执持菩提心，所以在这里是难以执持的。“持地”，就像须弥山一样，是不动的。正因为如此，（作者）说“平等与不平等”：就是收摄与外出。其中，以平等迁转的次第运行的，是日的运行，即右鼻孔；不平等的迁转，因为不依次第运行，所以是不平等，即月风运行，是左鼻孔。以具足平等与不平等二者的心去观察心界，就是完全度脱，这就是这样了知的意思。如果以这样的心不了知（这一点），那么月与日不平等、平等地运行，众生的识界就不能解脱，不能到达顶门，这就是意思。

正因为如此，（作者）说“黑行者说”：黑金刚以舍弃了离贪阶段的安乐、以智慧之眼来表示，所以“难以表示”，因为一切都是空性，因为一切相都平等。因为是亲证、体验安乐，所以“难以了悟”。

【按】“六支瑜伽”（སྦྱོར་བའི་ཡན་ལག་དྲུག），是时轮金刚圆满次第的修法：收摄、禅定、命勤、执持、随念、三摩地。D2301 根本颂作“越不过平等与不平等”，释论以左右鼻孔的气息运行来解释“平等与不平等”。

### 二十六、释“能稳住心宝的人”（第642–660段）

（问：）这样的（境界）以什么来了悟呢？（作者）说：“能了悟心宝的人。”从金刚与莲花平等结合中，心所缘、如实而成的自性之喜，因为能增长无上的安乐，所以称为“宝”，就是心之宝，就是佛的影像。如《吉祥密集续》中说：“男女根结合之后，不应舍弃菩提心；要把三界一切，观为佛的影像。因为空性是影像之因，果就是不变的安乐。”

正因为如此，（作者）说“放出俱生”：“每一个太阳所生”，就是一切空；“迁转”，就是与虚空一同迁转而显现。如《文殊真实名经》中说：“从虚空所生，自生……”

【按】D2301 根本颂第59句意思不明（“གང་གི་ཡི་ནི་རིན་ཆེན་རིས་ནུས་པ”），释论引作“能了悟心宝的人”（གང་གིས་ཡིད་ཀྱི་རིན་ཆེན་རྟོགས），可以印证前面在 D2301 中的推读（读作“能稳住心宝的人”）大体不误。

【按】《密集续》的引文，是无上瑜伽续方便道的专门教法，须依灌顶与上师口授理解，不能照字面理解或效仿。“观三界一切为佛的影像”“空性是影像之因，果是不变的安乐”，说明这一修法的核心是空乐无二的智慧，而不是世俗的欲乐。

### 二十七、《密集后续》的亲近等四时（第661–672段）

（接前引《文殊真实名经》）“……从虚空所生、自然而生，般若智慧之大火。”

如是，《吉祥密集后续》中说：

```
于亲近之时，当精勤观修大顶髻（尊）之影像；
于近亲近之时，（观修）影像甘露漩（尊）；
于修之时，观修本尊之身相，并令其成为无所缘；
于大修之时，影像即是佛主之心。
```

【按】“亲近、近亲近、修、大修”是《密集》系统所说的四支修法（sevā、upasevā、sādhana、mahāsādhana），各派配释不一。“大顶髻”（གཙུག་ཏོར་ཆེ）可能指顶髻转轮王（Uṣṇīṣacakravartin），“甘露漩”（བདུད་རྩི་འཁྱིལ་པ）可能指甘露漩明王（Amṛtakuṇḍalin），两者都是忿怒尊名；但也可以把“甘露漩”读作“影像中甘露回旋”。这里的“影像”（གཟུགས་བརྙན），在时轮与密集的圆满次第中，指修习时于虚空中现起的空色佛像，不是用意识造作出来的观想像。本论把这一引文配到下文的六支瑜伽，所以作者的意思应当是：四个阶段所见的影像，由粗到细，最后影像与佛心无二。

### 二十八、具种的开示与世尊的誓言（第673–683段）

为了开示这一点，具种（Kalkī）也开示了密意，这样说：“其他的顶髻影像”，就是三界无余的诸佛影像，在虚空的法生处，安立心金刚。在亲近之时，应当观修“各别收摄”，以“禅定”使它稳固。

对此，世尊的誓言是：

```
完全舍弃一切思虑，在一天之中周遍观察；
如果（那时）还没有生起信心，那就是我说了妄语。
```

这里所说的“信心”，就是使人生起信心的烟等征相。

【按】“具种”（རིགས་ལྡན），是香巴拉的具种法王，这里应当指造《时轮无垢光释》的具种白莲（Kalkī Puṇḍarīka），或泛指时轮系统的诸具种王。“各别收摄”（pratyāhāra）与“禅定”（dhyāna），是时轮六支瑜伽的第一、二支。“烟等征相”，就是六支瑜伽在各别收摄阶段所现的十种征相（烟、阳焰、萤火、灯、炽燃、月、日、罗睺、电、明点）的前几种。世尊“一日观察，若不生信则我说妄语”的誓言，是在说这一修法见效迅速、真实可验，但这必须是在具足灌顶、依止上师口授、如法闭关的前提下说的，不能理解为任何人随便修一天就会出现征相，也不能自行依书效仿。

### 二十九、释“唯彼了知法性，说与他人亦不懂”（第684–691段）

像这样，悦意之宝——佛的影像——的证悟生起时，就是（根本颂）所说的“他了知诸法的自性”。“唯有他了知自性”，就是唯有他一人现证了法的自性。

（根本颂说）“即使给别人开示，别人又怎么能懂得”：“别人”，就是耽著于根（境）之乐的人；“怎么能懂得”，意思是：即使给他讲了，他也不会懂。

### 三十、释“系住行道之心”与“三界放出又收摄”（第692–710段）

再以另一种方式开示这一点：风是（心的）坐骑之因，因此，三显现的体性、一百六十种自性的体性，就从诸根之门出生，而缘取各种外境。

（根本颂）说：“能系住那行于道路的自身的人。”“行于道路”，就是识界行于轮回之道；“意”（心），就是俱生之相；“所应系缚”，就是以（六支）令（风之）命力坚固，这就叫作“系缚”。

瑜伽自在者这样做时，（根本颂）说：“三界一切都从那里放出，又收摄回那里。”

“三界”，就是身、语、意三轮。“一切（无余）”，就是在醒觉之位，以喜等差别的菩提心，遍散到各个毛孔之间，然后又收摄回原处；（菩提心）上行之后，第四（喜）穷尽，以等流等差别，收摄入阿瓦都帝（中脉）；超越了分与微细明点，进入一切空性之界——意思是说：由此现证大金刚持。

【按】“三显现”就是显、增、得三种心；“一百六十种自性”，一般指与三显现相应的八十（或一百六十）种自性分别心。“风是心的坐骑”是无上瑜伽续的通说：心乘风而动，风从根门流出，心就随之缘取外境；所以系住风，就能系住心。

“第四（喜）穷尽”（བཞི་པ་ཟད）一句意思不太确定：可能指菩提心上行至顶，四喜的次第圆满；也可能指“第四”位（时轮所说醒、梦、熟眠之外的第四位）的习气穷尽。“等流”（རྒྱུ་མཐུན་པ）在此是说菩提心收摄时与先前融降的次第相应。“分与明点”（ཆ་དང་ཐིག་ལེ），是时轮圆满次第的专门术语。这一段完全属于圆满次第的内在修法，必须依灌顶与上师口授理解，不能自行依文字修习。

### 三十一、释“善逝、天女、忿怒尊众何用”（第711–729段）

正因为这样，（根本颂）说：“善逝、天女、忿怒尊众，为什么要（贪著）三有？”这是说：对如来、天女、忿怒尊众，为什么要贪著呢？意思是：舍弃坛城之轮，安住于俱生之时。

其中的密意是这样的：蕴、处等，身、语、意，以及坛城诸尊，以口诀而成为大乐一味——如果是这样，那么它本身就成了大坛城，在此之外，并没有别的坛城。

正如《密续》中说：

```
超越一切支分的观修，远离分别与能分别者，
真实超越了分与明点，这就是最殊胜的坛城。
```

【按】根本颂这一句藏文作“སྲིད་པ”（三有），释论随即解作“སྲེད་པ”（贪著），二字只差一个元音符号，释论的读法更通顺，所以 D2301 所译“三有的天女”，依释论应当改读为“何必贪著善逝、天女、忿怒尊众”。

这里说“舍弃坛城之轮”，不是说生起次第的本尊、坛城是错误的，可以不修；释论自己解释得很清楚：是以口诀使蕴、处、身语意、诸尊都成为大乐一味，这时一切本身就是大坛城，所以不必再向外执著另一个造作的坛城。这是对已经通达圆满次第的修行人而言的。对初学者来说，生起次第正是趣入这一境界的阶梯，不可舍弃。

### 三十二、释“能稳住俱生者，彼时即成就”（第730–747段）

再从另一门，把它开示为坛城：（根本颂说）“能使俱生稳固的人。”“俱生”，就是俱同生起的般若（智慧）；“稳固”，就是使它不外泄。

“平等一味”：由于四喜成为一体，自己的意之王，就是无有支分的金刚。

（根本颂）说：“就在那一刹那间成就。”“成就”，就是大手印的成就，也就是获得大金刚持。“就在那时”，就是（不待）时间的“非时”，在相续中名为“一（刹那）”。

正如《吉祥胜乐续》中也说：

```
天界、人间与地下（三处），在一刹那之间成为一身；
以自与他的分别，在刹那之间也不能为害。
```

正因为这样，（根本颂）说：“没有衰老与死亡的怖畏。”

【按】“意之王”（ཡིད་ཀྱི་རྒྱལ་པོ），就是根本颂的“与国王成为一味”中的“国王”，释论把它解释为自己的心——心是一切心所之王。“非时”（དུས་མ་ཡིན་པ）一句，字面是“就在那时、非时，于相续中名为一”，意思不完全确定，大概是说：大手印的成就不依赖于时间的长短次第，而是在证悟的那一刹那、在自相续中顿然圆满。“无老死怖畏”，是就证得大金刚持而言的，不是说修行人的色身会长生不死。

### 三十三、大手印的体性：不动、无分别、不变、离生灭（第748–769段）

开示大手印的体性：（根本颂）说“不动”等等。

“不动”，就是菩提心不外泄。

“无分别”，因为体验是一味的，所以远离了“彼”与“此”的分别。

“不变”——如果有人问：贪欲与离贪又有什么用呢？因为（大手印）已经从这两者中解脱了。

“离生灭”，因为已经遮止了月与日。

“美”，就是极其美妙，因为它是大乐。

“心髓”（精华），因为它就是光明。

“今于此”等等，就是因为这个缘故而称之为涅槃：言语上所说的“涅槃”，这是真实的涅槃，因为它就是无住涅槃。

如果有人问：那么它具有什么样的特点呢？（根本颂）说：“于此没有心与心所。”就是说：在此处，凡是心，都是（显、增、得）三种；心所，就是心的一百六十种自性；连明点也不起任何作用——意思是说：像这样的分别，丝毫也不生起。

【按】根本颂与释论在这一段有不少异文：

一、D2301 根本颂作“没有过失的”，释论作“不变”（འགྱུར་བ་མེད་པ）；D2301 作“离开了东方与西方”，释论作“离生灭”，并解释为“遮止了月与日”。东方是日出之处、西方是日落之处，所以两种说法意思可以相通：日月代表左右二脉之风，日月的出没就是风的生灭；遮止了左右二脉，风入中脉，就超越了生灭。

二、D2301 末句译作“心中毫无骄慢”，释论引作“于此没有心与心所”（གང་ལ་སེམས་དང་སེམས་ལས་བྱུང་བ་མེད），依释论应当改读。

三、“不变”下面的“贪欲与离贪又有什么用”，在时轮系统中，“离贪”常指明点的流失，“贪”指对欲乐的执著；大手印超越这两者，所以叫作“不变”——这里的“不变”，正是时轮所说的“不变之乐”。

四、“连明点也不起任何作用”（ཐིག་ལེས་ཀྱང་ཅིའང་མི་བྱེད），字面如此，意思不完全确定，大概是说在大手印境界中，明点的流动、增减等作用也都止息了。

“无住涅槃”，就是既不住于生死、也不住于寂灭的大乘究竟涅槃。

### 三十四、释“了知 ཨེ་ཝཾ”（第770–800段）

为了开示这一点，（根本颂）说：“以任何方式了知了 ཨེ་ཝཾ 的人。”它的意思是这样的：正如《天主请问续》中所说：

```
ཨེ 是空性的自性，ཝཾ 说为大悲；
明点是无二的结合，应当忆念它的双运。

ཨེ 说为母，ཝཾ 应当知道是父；
明点成为无二的结合，它的结合真是稀有。

ཨེ 说为莲花，ཝཾ 是金刚的自性；
由此成为明点的种子，由此真实生起三有。

ཨེ 成为般若，ཝཾ 真实说为方便；
明点即是不坏者，由此生起一切文字。

谁能了知法之印——这两个字的真实义，
他就能对一切有情，转动法轮。

众生如果对这两个字，不知道它的真实义而常常念诵，
他就会被排除在佛法之外，就像富人舍弃了自己的财富一样。
```

【按】“ཨེ་ཝཾ”（evaṃ），在梵文中是“如是”的意思，一切佛经开头的“如是我闻”（evaṃ mayā śrutam）的第一个词就是它。密续把这两个字解释为空性与大悲、母与父、莲花与金刚、般若与方便，而两者无二的结合就是“明点”。所以偈中说“不知真实义而常常念诵”，就是讥讽那些天天诵经，开口就是“如是我闻”，却不知道“如是”二字含有甚深密义的人，犹如守着宝藏而不知受用的富人。

“母、父、莲花、金刚”等，是密续的象征语言，指智慧与方便、空与悲的双运，修持上属于无上瑜伽续圆满次第，必须依灌顶与上师口授，绝不能照字面理解为世俗的男女之事。

“《天主请问续》”（ལྷའི་དབང་པོས་ཡོངས་སུ་ཞུས་པ），梵文大概是 Devendraparipṛcchā，是常被引用来解释 evaṃ 二字的一部续，原文在德格版甘珠尔中是否有完整译本，我不能确定。偈中“被排除在佛法之外”（ཕྱིར་འབྱུང），也可以理解为“从佛法中退失”。

### 三十五、释“无余”与“法之匣、本然之主的装束”（第801–813段）

这里，了知这样的 ཨེ་ཝཾ 二字，就是证悟；谁能了知，谁就证悟了佛。

“无余”，就是 ཨེ་ཝཾ 二字的种种（含义）没有遗漏，因为它就是种种一体的体性。

如果有人问：它成为什么样子了呢？（根本颂）说：“那就是法之匣（ཟ་མ་ཏོག）。”诸法的蕴、界、处，也就是喜等等；它们的“匣”，就是（它们的）安住处所。

（“唉”这个词，）是呼唤之词。

（根本颂）说：“那就是本然之主的装束。”“本然之主”，就是心金刚；“装束”，就是庄严，因为它是从（心金刚的）拥抱中生起的。

【按】这一段正好解决了 D2301 中第78句“ཟ་མ་ཏོག”不明的问题：释论解释为“诸法的安住处所”，“ཟ་མ་ཏོག”就是匣子、箱子（梵文 samudgaka 一类的词），所以 D2301 那一句可以读作：“唉！这被称为法之匣。”意思是说：蕴、界、处、四喜等一切法，都安住、含藏于 ཨེ་ཝཾ 的双运之中，就像宝物收在匣中。

“呼唤之词”（བོད་པའི་ཚིག），指根本颂中的“ཀྱེ་ཧོ”（唉、咦），是道歌中表示惊叹或呼唤的词。

“从心金刚的拥抱中生起”，是说般若与方便、空与乐双运时，种种显现都成为心金刚的庄严——这也是象征语言，须依上师口授理解。

### 三十六、释“风门插上门闩”与“黑暗中点燃心灯”（第814–833段）

再者，以此简略开示修行的方便：（根本颂）说：“在风行走的门上……”

“风行走的门”，就是上（门）与下（门）。

“紧紧地”，就是在那里稳固而不开启。

“门闩”，就是使六门之风和合，遮止月与日之道，使时火（kālāgni）完全圆满——这就是此身的系缚。

（根本颂）说：“如果在内部的黑暗之中……”就是说：如果那里有不尽者，那就是“黑暗”——它就是不动的三摩地，如同宝瓶气一般的体性，无能摧坏之音（无击之声）；以法自在者——意之菩提心——在那个时候使大乐显明，所以叫作“灯”；“如果点燃”，就是以烟等征相使它显明。

正如《吉祥密集续》中也说：

```
从心金刚的止灭中，就会见到烟等征相。
```

这就是语的系缚。

【按】D2301 根本颂作“在风与虚空这两道门上”，释论则解释为“上门与下门”：在圆满次第中，通常指上方的鼻孔、口等风的出入之门，与下方的二便之门；“六门”大概指眼、耳、鼻等身上的诸门，或指六脉轮之门，不能确定。关闭这些门，就是令风不从左右二脉及诸根门散出，而收入中脉。

“遮止月与日之道”，就是遮止左（月）右（日）二脉的风；“时火”（དུས་ཀྱི་མེ），在时轮中指脐下的拙火（或称劫火），风入中脉，拙火就炽燃圆满。

“如同宝瓶气”，就是宝瓶气（瓶风）的修法；“无能摧坏之音”（གཞོམ་དུ་མེད་པའི་སྒྲ），就是“无击之声”（anāhata），即不依两物相击而自然现起的内在之声。“不尽者”（མི་ཟད་པ）一句，意思不完全确定，可能指不外泄的菩提心。

释论在这里把修法分为身、语、意三种“系缚”：插上门闩、遮止日月之道，是身的系缚；见到烟等征相，是语的系缚；下文“胜者之宝升到上方”，接着讲心（意）的系缚。这些都是圆满次第风脉明点的修法，具有很大的危险性，绝不能离开具德上师的指导而依书自修，否则不但无益，还会导致风病等严重的身心障碍。

### 三十七、释“胜者之宝住于上方虚空”：心的系缚（第834–855段）

（根本颂）说：“胜者之宝，住于上方的虚空。”“胜者之宝”，就是前面所说的那无能摧坏之音。“住于上方的虚空”，就是当（菩提心）触及作为所依的第六——智慧坛城的明点时，这就叫作“拥抱”。

正如（经中）也说：

```
空行金刚宝珠，诸佛安住于顶门。
```

这就是心的系缚。

《吉祥合和明点续》中也说：

```
从风与火的坛城中，激发金刚与莲花的种子；
以明点之声真实地压住它，忆念它如同雨流降注。
```

又说：

```
与明点之声真实相应，当一切相都转变之时，
那时就称之为“果”——这是最胜的瑜伽士所宣说的。
```

【按】D2301 根本颂这一句，译作“胜者之宝就升到了身体的上方”，释论引文作“住于上方的虚空”，释为菩提心上达顶轮。“第六智慧坛城”，时轮系统以地、水、火、风、空五坛城之上的第六为智慧坛城，位于顶门。至此，释论所说的身、语、意三种系缚已经讲完：门闩遮止日月之道是身的系缚，见烟等征相是语的系缚，菩提心上达顶门的明点是心的系缚。

“《合和明点续》”（ཁ་སྦྱོར་ཐིག་ལེ），即《吉祥合和明点续》（Sampuṭatilaka），是《合和续》系统的一部续。“明点之声压住”“如雨流降注”，是圆满次第中拙火上燃、顶门明点融降的过程，必须依灌顶与上师口授理解。

### 三十八、释“在受用三有之中成就解脱”（第856–865段）

如果有人问：由此会成为什么呢？（根本颂说：）“黑行者说：乃至在受用（三有）之中，就能成就解脱。”这是说：黑行者金刚受用三有。“般若”，就是体验安乐，因为已经从一切“离贪”（流失）中退转回来了；“解脱”，就是获得、现证大手印的果位。

正如《吉祥本初佛续》中说：

```
将命风纳入中央，系缚左右日月之运行；
与菩提心之手印相伴，在胜喜中相伴，令金刚坚起；
以水生（莲花）、金刚之声、自手、莲花的游戏，或者令安乐恢复；
能够舍弃种子的泄漏、具乐的坏灭——这就是吉祥上师的口诀。
```

【按】这里的“受用三有”，释论配合时轮的方便道来解释：所谓“般若”，是在体验安乐的同时不令菩提心流失（“从离贪中退转”）。在时轮系统中，“离贪”专指明点的流失，所以“不离贪”即“不泄”。

所引《本初佛续》（即时轮根本续）这一偈，讲的是无上瑜伽续中事业手印的方便道修法，核心在于“将风纳入中脉”与“不令种子泄漏”，藏文第三句意思不完全确定，这里只照字面译出。这一类修法，在藏传佛教各派中，都要求修行人具足灌顶、严守三昧耶、已经在生起与圆满次第上有很深的修证，并且依止具德上师的亲自指导，历代祖师都一再告诫不得私修、不得以此为名放纵欲乐，否则只会成为堕落的因。这里只是如实翻译论文，读者绝不可照字面理解或效仿。

### 三十九、释“以稳固之意结合，于法之字中”（第866–884段）

（作者）想到唯以心的系缚就能成就一切，所以明白地开示心的稳固：（根本颂）说“如果以稳固之意（与它）结合”，就是以金刚与莲花结合之门，作菩提心稳固的结合。

在哪里（结合）呢？（根本颂）说“在法之字之中”：“法之字”，就是无能摧坏者，也就是无我的种子；“在其中”，就是“于它”的意思。

由此会成为什么呢？（根本颂）说“刹那之间风就止息了”：“风”，就是命风，在那一刹那间止息。

还有什么呢？（根本颂）说“对于诸境，也就无所贪著而行”：“诸境”，就是色等诸境；意思是说：虽然受用它们，却没有耽著，所以从轮回的系缚中解脱。

【按】“无我的种子”，大概指无我母（Nairātmyā）的种子字，或者泛指空性；“无能摧坏者”就是前面所说的“无击之声”。D2301 中“住在法之字的跟前”，依释论应当读作“以稳固之意，结合于法之字之中”。

“受用诸境而不耽著”，是这一段的要点：解脱不在于离开诸境，而在于对诸境没有耽著。

### 四十、释“于胜喜与离喜之间”（第885–890段）

那么，法之字应当在哪里认识呢？（根本颂）说“在得到胜（喜）与离喜的地方”。“胜（喜）与离喜”，就是月与日；在这两者的中央所见到的，就是法之字。它具有前面所说的特相，应当在中央标示出来。

【按】D2301 按语依通常的四喜次第，把“胜喜与离喜之间”解释为俱生喜；释论在这里却解释为“月与日”，即左右二脉，“二者的中央”就是中脉。两种解释并不矛盾：风入中脉，俱生喜就生起。依释论，“法之字”就是在中脉中所认识的无能摧坏之音、ཨེ་ཝཾ 之双运。

### 四十一、释“主妇系风令不动”（第891–895段）

（根本颂）说：“如果在谁那里，这样的口诀明显成就了……”这是说：这样的密咒，依理以口诀明显成就；当它圆满成就的时候，（根本颂）说“主妇就把风系住，使它不动”：就是说，主妇（系住）风，令它具有前面所说的特相，而成为“不动”。

【按】这一句藏文是“ཁྱིམ་བདག་མོ་རླུང་གི་སྔོན་དུ་བསྟན་པའི་མཚན་ཉིད་དང་ལྡན་པའི་མི་གཡོ”，语法不太清楚，也可以读作“主妇，就是具有前面所说之风的特相的‘不动’”。“主妇”在黑行者道歌中象征心性中的智慧一面，下文释论又解释为大手印、智慧手印。

### 四十二、释“殊胜之山顶上的平原”（第896–907段）

如果有人问：在这里，系缚了勤作之风以后，法之字成为大乐的体性、如金刚一般的体性，它安住在哪里呢？（根本颂）说：“在殊胜之山的顶上，舍弃了平原……”

“殊胜之山”，就是宝山，也就是前面所说的那座山（脊柱）。“顶上”，因为它是一切动者与不动者的大乐的住处。“平原”，就是最胜之支（头部）的平原，也就是头顶。

（根本颂）说“山居女在那里安住”：这样的山居女，就是自性已经成就的法之字；世尊在哪里安住，那里就是她的安住之处。

【按】这一句藏文作“རི་བོ་མཆོག་གི་རྩེ་ཐང་སྤངས་པ་ལ”，字面是“舍弃了殊胜之山顶上的平原”，与释论的解释不太相合。“སྤངས”（舍弃）可能是“སྤང”（草甸、高原牧场）的讹写，那就成了“殊胜之山顶上的高山草甸”。释论只解释了“平原就是头顶”，这里存疑。

D2301 中把“རི་ཁྲོད”译作“山居的瑜伽士”，释论引文作“རི་ཁྲོད་མ”（山居女），即夏瓦日女（Śabarī），是印度道歌中著名的象征，代表无我母、智慧。依释论，D2301 那一句应当改读为“山居女就住在那里”。

### 四十三、释“狮子跳不过，大象何须说”（第908–926段）

它有什么样的特点呢？（根本颂）说“连狮子也不能跳越过去”：“不能跳越”，就是不能摧坏。被谁（不能摧坏）呢？“狮子”，就是五面者，也就是以五坛城为自性的命风——狮子不能压制它，因为它是第六智慧坛城的体性。

（根本颂）说“大象就更不必说了”：“大象”，就是畜生，也就是日与月。意思是说：它们怎么能远行到那里、怎么能把它照明呢？

（根本颂）说“像这样，月与日（是）大畜”：这里所要说的是：骑在运行于月与日坛城之风上的识界本身，虽然以一切的体性，在一切处、于一切中安住，世尊大乐金刚也安住（于此），（它）却不能证悟。

那么，在生于身体者的身体中，它究竟安住在哪里呢？（根本颂说：）“在它的殊胜种姓中，开示它的种子……”等一偈半，容易理解，所以这里不再解说。

【按】“狮子”在这里不是比喻法之字的威力，而是比喻五坛城（地、水、火、风、空）的风；智慧坛城是第六，五大之风不能到达，左右二脉（日月）之风更不能到达。所以“狮子跳不过，大象何须说”，是说一般的风息都不能到达顶门的大乐之处。D2301 中的“大象的希望也就落空了”，与这里释论所引的“月与日是大畜”，文句有出入，所以 D2301 那一段的推解，依释论应当修正。

“一偈半容易理解”所指的根本颂，在 D2301 中大概对应“这是我在殊胜之山上所开示的，这就是大乐之处”一带，但释论所引“在它的殊胜种姓中开示它的种子”一句，D2301 中没有完全相同的句子，两本的根本颂可能有不少出入。

### 四十四、释“咒与续一样也不作”（第927–956段）

如前面所说，在事业手印中所见到的智慧手印，由于不变的大乐已经圆满，为了开示这一点，（根本颂）说：“咒与续，一样也不作。”就是一样也不作。不作什么呢？“咒”，就是密咒的念诵；“续”，就是读诵续典。

为什么是这样呢？（根本颂）说“自家的主妇”：“自家的主妇”，就是俱生、自显的智慧手印；“取来”，就是以殊胜上师的口诀（取来）；“会得解脱”，意思是说：（解脱）是由与心相应的手印以及俱生（智慧）所成办的。

正如《吉祥时轮》中也说：

```
唯是心之显现、从意所生，如同镜中的影像；
瑜伽自在者应当依止（她），她是五佛及诸佛子无余一切的所依，生起智慧的光芒；
焚烧自身连同诸魔、一切障碍无余；
焚烧贪欲等，以一年的修持，于身赐予同味之乐。
```

对那位薄伽梵母耽著的瑜伽士，不应当执著、耽著咒与续。

这里的意思是这样的：“它”是什么呢？它被赞叹为菩提心之意（这就是“咒”）；因为它是会聚于此的因，摄持语界之王的近眷属，所以是“续”。对它生起欢喜，就是做了一切。

正如《喜金刚续》中也说：

```
没有诵咒、没有苦行，没有坛城、没有火供；
它就是诵咒、苦行、火供，它就是坛城的主尊与坛城本身。
```

【按】“智慧手印”（ཡེ་ཤེས་ཀྱི་ཕྱག་རྒྱ），是观想所现的本尊明妃；“事业手印”，是实际的方便道修法；此外还有“大手印”，即空性智慧本身。释论在这里的意思是：一切外在的诵咒、读续，最终都归于俱生智慧，所以证悟俱生智慧时，“一样也不作”而一切已经圆满。

所引《时轮》偈说智慧手印“唯是心之显现，如镜中影像”，正说明这是心的显现，不是外在的女人。

“菩提心之意是咒，摄持语界之王的近眷属是续”一段，大概是对“咒”（mantra，意+救护）与“续”（tantra，相续、摄持）的词源解释，藏文文句很难读，这里只依字面试译，意思不能确定。

“一样也不作”，是对已证俱生智慧的行者而言；对未证悟的修行人来说，诵咒、读续、坛城、火供都是积资净障、成熟相续不可缺少的方便，不能以此为借口而舍弃。

### 四十五、释“主妇未住自家之前，只是五欲”（第957–976段）

为了明白地开示这一点，（根本颂）说：“只要主妇还没有安住于自己的家……”

“自己的家”，就是一切空性；远离罪恶之处，就是自己的家。“大手印”，就是主妇。“乃至没有安住”，就是还没有融入（自家）。“那时就是五欲”：暂时以五种现证菩提，随着众多有情意乐的差别，以面容、手印、颜色、形状等种种（相）那样安住，（但实际上）并不安住。

正如《吉祥本初佛续》中也说：

```
与事业手印平等结合，缘取智慧手印等；
以大手印唯一结合，不泄之乐、安乐增长；
处处都有面与手等，处处都有头、眼与面；
处处都具足世间的听闻，遍满一切而安住。
```

【按】这一段释论文句很简略，“暂时以五种现证菩提……那样安住，并不安住”的意思不完全确定。大概是说：在主妇（大手印）还没有融入空性之家以前，五欲（或五佛）以种种面目、手印、颜色、形状等相显现，虽似安住，实则不是究竟的安住处。“五种现证菩提”（མངོན་པར་བྱང་ཆུབ་པ་ལྔ），是瑜伽续生起本尊的五个步骤。

所引《本初佛》偈的后半，“处处有手足、处处有头眼与面、处处有耳”，与般若经、《薄伽梵歌》等形容遍满者的著名句式相似，这里用来说明大手印遍满一切。偈中三种手印的次第是：事业手印、智慧手印、大手印。

### 四十六、释“诵咒、火供、坛城事业有什么用”（第977–987段）

这一段开示以“天物手印”成就其果——大手印——的口诀，又再一次开示：（根本颂）说“诵咒、火供、坛城的事业，这些……”就是说：这些外在的念诵、坛城、火供的事业，为什么每天（都要做）呢？面朝上方，为什么（做这些）嬉戏的体性？没有果报。

这些为什么是无意义的呢？（根本颂）说：“如果不常常与这样的年轻女子相会……”它（智慧）恒常是对年轻女子之爱的自性，它就是“天物手印”；对她，以无有波动的恒常之喜等次第，生起随爱——那就是以无有波动的亲密（而相会）。

【按】“天物手印”（ལྷ་རྫས་ཀྱི་ཕྱག་རྒྱ），这个词在别处很少见，下文第999段以下也用来称“自家的主妇”，意思大概是“天界的、非凡的手印”，指智慧手印或大手印。也有可能是“ལྷན་སྐྱེས”（俱生）的讹写，即“俱生手印”，不能确定。

“年轻女子”（གཞོན་ནུ་མ），与 D2301 中所说相同，是密乘道歌中智慧（般若）的象征，释论自己也明确说她就是“天物手印”，与“主妇”同指心性中的智慧一面。“相会”“亲密”，比喻方便与智慧恒常双运、无有间断。这些都是象征语言，绝不能照字面理解。“无有波动”（དབའ་རླབས་མེད་པ），字面是“没有波浪”，指心不散动、乐不间断。

### 四十七、释“以此身如何成就菩提”与“稳住心宝”（第988–1007段）

（根本颂说）“以这个身体，怎么能成就菩提呢？”“菩提”，就是大手印；怎么能成就呢？意思是说：如果没有前面所说的 ཨེ་ཝཾ 字之身，就不能成就。

（根本颂）说“如果谁常常证悟俱生之乐”，这容易理解。

（根本颂）说“能够稳住心宝的人”：以极为猛烈的拙火之火使它融化以后，因为（它）不可动摇，所以谁使它稳固了的那个心宝，就是菩提心。

做了什么呢？（根本颂）说“取来自家的主妇……”：“自家的主妇”，就是那天物手印。在她那里，在那 ཨེ་ཝཾ 字上，执持大乐之身相，那就是怙主金刚萨埵，身、语、意之主。（“此”）是呼唤之词。

（根本颂）说“这一殊胜的义理，我已经宣说了”：意思是说，我黑行者金刚，宣说了这不造作的殊胜义理，除了这一义理，再没有别的了。

【按】这里明确说“以这个身体成就菩提”，指的是以 ཨེ་ཝཾ（智慧与方便双运）为体的“身”，不是指凡俗的血肉之身本身。“拙火”（གཏུམ་མོ），是圆满次第脐轮之火；“拙火融化（顶门明点）”，是四喜生起的基础。

### 四十八、释“如盐入水”与“常与她安住”（第1008–1054段）

为了以譬喻开示这一点，（根本颂）说：“就像盐溶入水中一样……”就像盐溶入水中，取来主妇——智慧手印——的自性也是这样；“心”，就是菩提心，成为一味。

正如《吉祥喜金刚续》中说：

```
精之相即是薄伽梵，其乐说为（佛）母。
```

精与乐，也就是所依与能依的体性，它们一切都说为空性的自性；乐平等而一味，从那一刹那而成。

正如《吉祥本初佛续》中也说：

```
乃至以所依与能依的结合，乃至（达到）不泄之际；
当心成为止灭时，所依与能依之相就不存在了。
```

正如《合和明点续》中也说：

```
从两个鼻孔，入（息）说为乐之时，
出（息）也是乐之时，这两者即称为一；
无伴者、独一者，行于不可思议之时；
命风与下行风平等安住，舍弃出与入，
去与来都得解脱，这就说为“一时”。
非贪亦非离贪，不缘于中央；
非贪非离贪之道，二者混合，不可摧坏；
如同酥油融入酥油，混合而无浑浊；
同样，如同离贪一样，在一刹那间成为一味。
```

（根本颂）说：“那常常与她平等安住的人……”就是说：如果这两者互相（结合）；“常常安住”，就是不间断，那时也就会这样。

这里的意思是：如前所示，界之精与（乐之）体性，要使它们互相不间断。如果成为另一种（情况）：精的体性是月的自性，即圆满报身；血的自性显现为日，化身的能力（于此）安住；与安住于乐之体性的主妇一同，这两种菩提心结合而成为一团，超越了生与灭的轮回之道，成为一味相续不断的吉祥嘿汝嘎。

正如《吉祥合和明点续》中也说：

```
当大贪安住于宾客之处，以月之形相而安住时，
那就是诸佛最殊胜的身；
当安住于金刚之尖端时，那时圆满报身，也就成为能力；
欲安住于莲花之中，那被称为“白芥子”，
真实称为日之形相，应说为化身；
诸佛、菩萨，在那里放出、生起，
莲花舞自在王，就成为莲花之主。
```

【按】“如盐入水”，是大手印的著名譬喻，D2301 按语已经说明。释论在这里以圆满次第的“红白菩提心”来解释：白（精，月）与红（血，日）二种菩提心，在中脉中融合为一，成为一味，配以法身、报身、化身，最后成就“吉祥嘿汝嘎”（Heruka）。

所引诸续的偈颂，都是无上瑜伽续圆满次第关于风、脉、明点的专门教法：“入息出息皆为乐时、二者为一”，是说命风（上行）与下行风平等住于中脉，出入息止息；“酥油融入酥油”，比喻二种菩提心融合无别；“白芥子”，比喻极微细的明点。偈中“宾客之处”（མགྲོན་གནས）、“欲安住于莲花之中”等句，意思不完全确定，这里只照字面译出。

这些都是象征性的修道语言，“精、血、莲花、金刚”等，在修道上指脉、风、明点与智慧方便的双运，必须依灌顶与上师口授才能理解，绝不能照字面理解或依书效仿。释论最后归结于“超越生灭的轮回之道，成为一味相续不断的嘿汝嘎”，说明一切方便的目的，都是证悟空乐无二的大手印。
