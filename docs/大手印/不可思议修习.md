# 不可思议修习

阿阇黎罗睺罗 造

## 题解

本篇出自德格版丹珠尔续部（རྒྱུད་འགྲེལ།）ཟི 函第25b叶第3行至第26a叶第5行，东北目录编号 D2399。全篇五十四句，每句七个音节，另有两句礼敬和跋语。篇幅很短，所以把藏文原文全部保留在代码块中，按段落分开，每段后附汉译，疑难之处另以【按】说明。

梵文题名：Acinta-bhavati-paribhāvanā-nāma（ཨ་ཙིནྟ་བྷ་བ་ཏི་པ་རི་བྷཱ་བ་ན་ནཱ་མ），拼写似有讹变，照录不改。

藏文题名：བསམ་གྱིས་མི་ཁྱབ་པ་བསྒོམ་པ（修习不可思议）。

【按】跋语中的题名作“ཚད་མེད་བཞི་བསམ་གྱིས་མི་ཁྱབ་པ་བསྒོམ་པ”，即“四无量不可思议修习”，比开头的题名多出“四无量”三字，正好点明本篇的内容：本篇讲的是与空性无二、无所缘的四无量修法，并结合在心间观修种子字、莲花的瑜伽。

【按】作者“རཱ་ཧུ་ལ”（Rāhula），即罗睺罗。这不是佛陀之子罗睺罗尊者，而是一位印度的密乘阿阇黎。八十四大成就者中有一位名为 Rāhula 的成就者，可能就是本篇的作者，但无法确证。跋语没有记载译者。

【按】本篇中的四无量，次序与通常的“慈、悲、喜、舍”不同，而且原文没有一一标出名称。正文各段标题中的“悲无量”“舍无量”“慈无量”“喜无量”，都是译者依内容推定而加的，只为方便阅读，读者须知。

【按】本篇也涉及在心间观想种子字、莲花、明点等密乘修法，依传统须得灌顶、依上师口授才能修持，这里只供学习了解之用。

## 正文

### 第一段：标宗

```
དགོངས་པ་མདོར་བསྡུས་རྣལ་འབྱོར་གྱི། །ཚད་མེད་བཞི་ཡི་ཉམས་ལེན་ནི། །བསམ་གྱིས་མི་ཁྱབ་བཤད་པར་བྱ། །
```

这是把瑜伽的密意简要归纳起来的四无量修持，它不可思议，我现在来宣说。

【按】“དགོངས་པ་མདོར་བསྡུས་རྣལ་འབྱོར་གྱི”，“瑜伽密意简要归纳的”，也可以读作“简要归纳密意的瑜伽之（四无量修持）”。两种读法意思相近。

【按】“བསམ་གྱིས་མི་ཁྱབ”，“不可思议”，既是本篇的题名，也是这里对四无量修持的形容：本篇所讲的四无量，不是一般有所缘的四无量，而是与空性无二、超越思维的四无量。

### 第二段：见地——因果空性

```
རྒྱུ་འབྲས་སྟོང་པའི་རང་བཞིན་ལ། །དངོས་མེད་གཟུགས་དང་གཉིས་མེད་སྨྲ། །དམིགས་མེད་འབྲས་བུ་འབད་མེད་འགྱུར། །དཔེར་ན་འབྲུག་མེད་ཆར་བཞིན་ནོ། །
```

对于因与果都是空性的这一自性，（经论）宣说为无实体的色相与无二；（因此）无所缘的果，不需勤作便能成就，就像没有雷声而降下的雨一样。

【按】“དངོས་མེད་གཟུགས་དང་གཉིས་མེད་སྨྲ”，“说无实之色与无二”，主语没有明说，这里依文意补“经论”二字放在括号中；也可以理解为瑜伽士如是宣说。“无实之色”，意思是显现为色相，却没有实体，也就是现空不二。

【按】“དམིགས་མེད”，“无所缘”，在四无量的修持中特别重要：一般的四无量是缘众生而修，本篇所说的是在了知因果、自他皆空的基础上修四无量，所以称为“无所缘”。这并不是说不缘众生，而是说缘众生的同时不执著众生为实有。

【按】“འབྲུག་མེད་ཆར”，“没有雷声的雨”，比喻果自然成就，不需要声势与造作。这一解释是依上句“不需勤作”推定的。

### 第三段：一切显现本来清净

```
དེ་ཕྱིར་རང་བཞིན་བདག་མེད་ཀྱི། །བརྟུལ་ཞུགས་སྐལ་ལྡན་རྣལ་འབྱོར་པས། །སྣང་ཞིང་སྲིད་པ་སྣ་ཚོགས་འདི། །དངོས་པོ་སྟོང་པ་བདག་མེད་དེ། །
ངོ་བོ་ཉིད་ཀྱིས་རྣམ་པར་དག། །
```

所以，具足自性无我之禁行的、有缘分的瑜伽士（了知）：这种种显现与三有，一切事物都是空性、无我的，在本体上本来就是完全清净的。

【按】“རང་བཞིན་བདག་མེད་ཀྱི་བརྟུལ་ཞུགས”，“自性无我之禁行”，意思大概是：以自性无我的见地作为修行的禁行（威仪）。“བརྟུལ་ཞུགས”（禁行）在密乘中常指瑜伽士特殊的行持。

【按】本段四、五句的主语是“瑜伽士”，但谓语原文没有明说，这里依文意补“了知”二字放在括号中。

### 第四段：无缘大悲与中观之义

```
དེ་ལྟ་བུ་ཡི་སྙིང་རྗེ་ལ། །སངས་རྒྱས་སེམས་ཅན་གཉིས་སུ་མེད། །མི་བསྒོམ་མི་རྟོག་རང་བཞིན་གསལ། །མཐའ་དབུས་བྲལ་བ་དབུ་མའི་དོན། །
དེ་ལྟའི་སེམས་ཀྱི་རང་བཞིན་བསྒོམ། །
```

在这样的悲心中，佛与众生无二无别；（这悲心）不修、不分别，自性明了；远离边与中，就是中观的真义——要修习这样的心的自性。

【按】“དེ་ལྟ་བུ་ཡི་སྙིང་རྗེ”，“这样的悲心”，指与上文空性见地不相分离的悲心，也就是通常所说的“无缘大悲”或“空悲双运”。

【按】“མི་བསྒོམ་མི་རྟོག”，“不修、不分别”，这里的“不修”，是指不以有所缘、有造作的方式来修，而不是说什么都不用修；所以下句紧接着又说“要修习这样的心的自性”，两者并不矛盾。

【按】“མཐའ་དབུས་བྲལ”，“远离边与中”，意思是不但远离有、无等二边，也不执著有一个“中”可得，这是中观离一切戏论的见地。

### 第五段：悲无量——拔除众生病苦

```
མ་རྟོགས་པ་ཡི་སེམས་ཅན་ལ། །ནད་འདོན་སྙིང་རྗེ་བསྒོམ་པར་བྱ། །
```

对那些没有证悟（这一自性）的众生，要修拔除病苦的悲心。

【按】“ནད་འདོན་སྙིང་རྗེ”，“拔除病苦之悲心”，“ནད”本义是“病”，这里应泛指一切痛苦。悲无量的定义正是“愿众生离苦及苦因”，所以这一段可以看作四无量中的“悲无量”。原文没有标出“悲无量”之名，这里是译者依内容标出的。

### 第六段：舍无量——平等安住

```
བདག་གི་མདུན་དུ་གང་ཞིག་ཀྱང་། །མཉམ་པར་བཞག་སྟེ་མཉམ་པར་བསྒོམ། །དེ་ལ་རྣམ་པ་ཐམས་ཅད་ཀྱི། །གཉིས་མེད་དོན་ནི་འགྲུབ་འགྱུར་རོ། །
```

无论在我面前的是谁，都要平等地安住、平等地修习；对此，一切相的无二之义便能成就。

【按】“མཉམ་པར་བཞག”，“平等安住”，在一般用法中是“入定”“等持”的意思。这里与“平等修习”连用，可能是说：对于面前的一切众生，不分亲疏，都以平等心安住、修持。这一段与“舍无量”（平等心）的意思最为接近，所以这里标为舍无量。但原文没有标出，这只是译者的推定。

### 第七段：寂静处耳传口诀——心间白吽

```
དགོན་པའི་སྙན་རྒྱུད་གདམས་ངག་ནི། །སངས་རྒྱས་ཐམས་ཅད་འདུས་པའི་སྐུ། །ཀུན་གྱི་སེམས་ཉིད་ཧཱུཾ་ཡིག་ཡིག་དཀར། །བདག་དང་གཞན་གྱི་སྙིང་གར་བསྒོམ། །
ཉི་མའི་གདན་སྟེང་ཐིག་ལེར་བསྒོམ། །དེ་ཉིད་ཀྱི་ནི་འཕྲོ་འདུ་ལས། །ཉོན་མོངས་ཐམས་ཅད་སྦྱང་བར་བསམ། །དེ་ནི་གཉིས་མེད་དོན་ཡིན་ཏེ། །
ལྷ་ཡི་དེ་ཉིད་རང་བཞིན་མེད། །
```

寂静处的耳传口诀是：（观想）一切佛总集之身，以及一切众生的心性，为白色的吽字，在自己和他人的心间观修；在日轮座垫上，观修为明点；从它的放光与收摄中，观想一切烦恼都被净化。这就是无二之义，本尊的真性是没有自性的。

【按】“དགོན་པའི་སྙན་རྒྱུད”，“寂静处的耳传”，可能指在寂静处（山林、静处）修行的瑜伽士之间口耳相传的口诀，也可能是某一传承的专名。原文没有说明。

【按】“ཧཱུཾ་ཡིག་ཡིག་དཀར”，“吽字字白”，“ཡིག”一字重复，应是传抄中的衍文，这里依文意读作“白色的吽字”。吽字通常观为蓝色，本篇观为白色，原文如此，照录不改。

【按】“སངས་རྒྱས་ཐམས་ཅད་འདུས་པའི་སྐུ”与“ཀུན་གྱི་སེམས་ཉིད”，“一切佛总集之身”和“一切众生的心性”，两者同时观为一个白吽字，正表示佛与众生的心性无二，与第四段“佛与众生无二”相呼应。“众生”二字原文只作“ཀུན”（一切），这里依文意补出。

【按】“ཉི་མའི་གདན་སྟེང་ཐིག་ལེར་བསྒོམ”，“在日轮座垫上观修为明点”，意思可能是吽字在日轮上，进而收摄为明点；也可能是另外在日轮上观一个明点。原文简略，这里照字面译出。

【按】“ལྷ་ཡི་དེ་ཉིད་རང་བཞིན་མེད”，“本尊的真性没有自性”，意思是：所观的本尊与种子字，虽然清楚显现，其真实本性却是空性，没有自性，这正是“无二”的意思。

### 第八段：慈无量——愿得安乐

```
དེ་ལྟར་སྙིང་རྗེ་བསྒོམ་བྱས་ནས། །བསམ་མི་ཁྱབ་པའི་བསམ་པ་ནི། །ཕན་ཕྱིར་བདེ་ལྟར་བསམ་པར་བྱ། །
```

这样修习悲心以后，（再生起）不可思议的意乐，为了利益（众生），要观想（愿他们）得到安乐。

【按】“ཕན་ཕྱིར་བདེ་ལྟར་བསམ་པར་བྱ”，直译是“为了利益，要如安乐那样思维”，语法比较简略。依四无量的通义，“愿众生得乐及乐因”是“慈无量”，所以这里读作“愿他们得到安乐”，并标为慈无量。这一读法是译者依文意推定的，括号中的字都是译者所补。

### 第九段：心间八瓣莲花与昂字

```
རྣལ་འབྱོར་བདག་ཉིད་སྙིང་ག་རུ། །པདྨ་འདབ་བརྒྱད་སྲན་མའི་ཚད། །དེ་ནས་འོད་གསལ་དཀར་དམར་ཏེ། །བར་དུ་མེ་ལྷའི་ཨཾ་ཡིག་ནི། །
དངོས་པོའི་རྣལ་འབྱོར་གང་ཡང་མེད། །དེ་ལས་ཅི་ཡང་བསམ་མི་ཁྱབ། །གང་ཞིག་སྒོམ་པའི་རྣལ་འབྱོར་དེ། །གཉིས་མེད་ཡེ་ཤེས་འགྲུབ་འགྱུར་རོ། །
```

在瑜伽士自己的心间，有一朵八瓣莲花，大小如豆；然后（放出）白色、红色的光明，中间是火神的“昂”（ཨཾ）字。（这）不是任何实有事物的瑜伽，从那里（所生的）一切，都不可思议。凡是修习这一瑜伽的瑜伽士，都将成就无二的智慧。

【按】“སྲན་མའི་ཚད”，“豆子的大小”，“སྲན་མ”是豆类，指莲花非常细小。

【按】“མེ་ལྷའི་ཨཾ་ཡིག”，“火神的ཨཾ字”。一般所说的火神（阿耆尼）种子字是“རཾ”（让），而不是“ཨཾ”（昂）；这里写作“ཨཾ”，可能是传承的特殊说法，也可能是“རཾ”的传抄讹误。原文如此，照录不改，并在译文中保留藏文字形。

【按】“དཀར་དམར”，“白、红”，在圆满次第中常对应白菩提与红菩提，或方便与智慧，本篇没有说明，这里只照字面译出。

【按】“དངོས་པོའི་རྣལ་འབྱོར་གང་ཡང་མེད”，“没有任何实有事物的瑜伽”，意思应是：这里所观的莲花、光明、种子字，都不执为实有，并不是一种以实有事物为所缘的瑜伽。

### 第十段：喜无量与舍无量之果

```
གསལ་རིག་མེད་པ་ཆོས་སྐུ་དེ། །དེ་ལྟར་ཕྲ་བའི་རྣལ་འབྱོར་པས། །མངོན་ཤེས་ཤར་ཏེ་གཉིས་མེད་རྟོགས། །དགའ་བའི་རང་བཞིན་འབྱུང་འགྱུར་ལ། །
བཏང་སྙོམས་འབྲས་བུ་ཐོབ་པའོ། །
```

明了觉知而不实有，这就是法身。像这样（修习）细微瑜伽的瑜伽士，神通便会生起，证悟无二；欢喜的自性将会生起，并获得舍的果。

【按】“གསལ་རིག་མེད་པ་ཆོས་སྐུ”一句最需要小心。字面上可以读作“没有明觉的法身”，但这样读就与大手印、大圆满“法身即明空无二”的通义相违，扭曲了法义。所以这里把“གསལ་རིག”（明觉）与“མེད་པ”（无、不实有）分开读，理解为“明了觉知，而又无有实体”，也就是明空不二，这才是法身。若有其他传本作“གསལ་རིག་སྟོང་པ”之类，可以作为佐证，但译者尚未对勘。

【按】“ཕྲ་བའི་རྣལ་འབྱོར”，“细微瑜伽”，大概指上一段在心间观修细小如豆的莲花与种子字的瑜伽。“细微瑜伽”在圆满次第中也常指专注于细微明点的修法。

【按】“དགའ་བའི་རང་བཞིན”，“欢喜的自性”，与四无量中的“喜无量”相应；“བཏང་སྙོམས་འབྲས་བུ”，“舍的果”，与“舍无量”相应。本篇的四无量，大致可以这样配：第五段为悲，第六段为舍（平等），第八段为慈，本段为喜与舍的果。这一配法是译者依内容推定的，原文并没有一一标出，次序也与通常的“慈、悲、喜、舍”不同。

### 第十一段：破偏执，结归口诀

```
ཁ་ཅིག་ལྷ་མོ་བཞི་བསྒོམས་ནས། །ཁ་ཅིག་དག་གི་དོན་ལ་བརྟེན། །གཉིས་མེད་བསྒོམ་པ་མི་ཤེས་སོ། །ཞལ་ནས་ཞལ་དུ་བརྒྱུད་པ་ཡི། །
ཞལ་གདམས་གཞན་ལ་ཕན་ཕྱིར་ནི། །རཱ་ཧུ་ལས་ནི་བཤད་པར་བྱས། །
```

有些人观修四位天女，有些人依靠（四无量的）义理，但都不懂得修习无二。（这是）面对面传承下来的口诀，为了利益他人，由罗睺罗宣说出来。

【按】“ཁ་ཅིག་ལྷ་མོ་བཞི་བསྒོམས”，“有些人观修四天女”，在某些密续中，四无量被观为四位天女（例如以四天女代表慈、悲、喜、舍）。作者的意思大概是：有些人把四无量只当作观修四天女的生起次第，有些人只在义理上思维四无量，但两者都没有契入“无二”。具体是哪一部续的四天女，原文没有说明。

【按】“ཁ་ཅིག་དག་གི་དོན་ལ་བརྟེན”，“有些人依于义理”，“དག”是复数词，“དོན”是“义”。这里补“四无量的”放在括号中。也可能“དག”是“清净”之义，那么就是“依于清净之义”。两种读法都可以，正文取前一种。

【按】“ཞལ་ནས་ཞལ་དུ་བརྒྱུད་པ”，“面对面传承”，即上师亲口传给弟子、不立文字的口诀。作者以第三人称“罗睺罗”自署，是道歌常见的体例。

## 跋语

```
ཚད་མེད་བཞི་བསམ་གྱིས་མི་ཁྱབ་པ་བསྒོམ་པ་ཞེས་བྱ་བ་སློབ་དཔོན་རཱ་ཧུ་ལས་མཛད་པ་རྫོགས་སོ།། །
```

名为《四无量不可思议修习》，阿阇黎罗睺罗所造，圆满。

## 通篇连读

这是把瑜伽的密意简要归纳起来的四无量修持，它不可思议，我现在来宣说。

对于因与果都是空性的这一自性，（经论）宣说为无实体的色相与无二；（因此）无所缘的果，不需勤作便能成就，就像没有雷声而降下的雨一样。

所以，具足自性无我之禁行的、有缘分的瑜伽士（了知）：这种种显现与三有，一切事物都是空性、无我的，在本体上本来就是完全清净的。

在这样的悲心中，佛与众生无二无别；（这悲心）不修、不分别，自性明了；远离边与中，就是中观的真义——要修习这样的心的自性。

对那些没有证悟（这一自性）的众生，要修拔除病苦的悲心。

无论在我面前的是谁，都要平等地安住、平等地修习；对此，一切相的无二之义便能成就。

寂静处的耳传口诀是：（观想）一切佛总集之身，以及一切众生的心性，为白色的吽字，在自己和他人的心间观修；在日轮座垫上，观修为明点；从它的放光与收摄中，观想一切烦恼都被净化。这就是无二之义，本尊的真性是没有自性的。

这样修习悲心以后，（再生起）不可思议的意乐，为了利益（众生），要观想（愿他们）得到安乐。

在瑜伽士自己的心间，有一朵八瓣莲花，大小如豆；然后（放出）白色、红色的光明，中间是火神的“昂”（ཨཾ）字。（这）不是任何实有事物的瑜伽，从那里（所生的）一切，都不可思议。凡是修习这一瑜伽的瑜伽士，都将成就无二的智慧。

明了觉知而不实有，这就是法身。像这样（修习）细微瑜伽的瑜伽士，神通便会生起，证悟无二；欢喜的自性将会生起，并获得舍的果。

有些人观修四位天女，有些人依靠（四无量的）义理，但都不懂得修习无二。（这是）面对面传承下来的口诀，为了利益他人，由罗睺罗宣说出来。
