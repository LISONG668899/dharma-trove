# 大手印_香巴道歌集（十七）夏鲁·洛色丹炯

## 题解

夏鲁·洛色丹炯的《嘎乌玛大手印备忘觉受之歌·如意宝》，备忘式地列出嘎乌玛大手印止观引导的纲目。

本篇出自《吉祥香巴噶举道歌金刚句与证道歌汇编·闻即有义加持海》，由蒋贡康楚·罗卓泰耶（1813–1899）在匝扎仁钦扎汇编。全书汇集香巴噶举历代祖师的金刚句与证道歌，核心见修是“嘎乌玛大手印”，故归入大手印类目，按祖师分篇发布。叙述译为白话散文，道歌分行译为诗；疑难处加【按】，存疑处附藏文原文。凡涉及拙火、迁识、方便道等密法观修之处，须得灌顶并依具德上师口授方可修持，此译仅作文献阅读。

## 嘎乌玛大手印备忘觉受之歌·如意宝
这是受金刚佛母摄受、打开了觉受、证悟与智慧之脉的夏鲁巴·仁钦洛色丹炯所作的道歌，名为《嘎乌玛大手印备忘觉受之歌·如意宝》：

母亲、空行主母尼古玛
心中甘露的精华，
写成文字在多罗树叶上，
装进护身盒里，
据说曾庄严在至尊琼波的颈间。
与那位怙主无二无别的法主，
父亲图多夏的恩德，
让我依次得到嘎乌玛大手印的
引导与观修，我把它作为备忘说出来：

道的前行，是三种自然安住；
正行的实义，是从四种过失中解脱；
最后，四身的本面任运成就——
这就是这条妙道的特点。

阿吙！
不造作，截断念流，从心底截断，收紧又放松，
视线的高低远近，法行、咒语与声音，
行住坐卧不拘一定——这些是止的持心法。
本体：寻找生与灭；
又寻找外境的显现与分别念；
再寻找这两者有无的差别，每项各二，合为六；
自性：把心决断于法界，是第七。
直指观之后，就安放在心的中央。
在三种自然安住上，有十八种修法。

噫嘻！
因为太近，所以认不出它；
因为太深，所以抓不住它；
因为太容易，所以不相信它；
因为太好，所以心里装不下它。

现在，法身、报身、化身三身，
从心明空双运的匣子里出来了；
它们的无别，就是自性身，
圆满于自明觉、空性之心的妙力中。
光彩，是虔信、悲心与方便三者；
方便，是把风与生起次第在双运中融合；
增上，是靠放开而显出来的工具；
若有障碍出现，就用这两种去除的方法。

父亲上师的口诀如意宝，
我怕被健忘这个贼从心里偷走，
于是在吉祥夏鲁日普的极静处，
由比丘洛色丹炯说出。

——这是嘎乌玛大手印的备忘觉受之歌。

【按】
1. 夏鲁巴·仁钦洛色丹炯，夏鲁寺的大师，“金刚佛母”指尼古玛。夏鲁日普是夏鲁寺附近的闭关处。
2. “图多夏”（མཐུ་སྟོབས་ཞབས），是洛色丹炯的上师，所指具体为谁未能确考，暂音译，存疑。
3. 本歌开头所述，与本书第一篇金刚持“实相金刚句”末尾的故事相应：琼波南交把尼古玛的金刚句装进护身盒佩戴，所以称“嘎乌玛”。“前行三种自然安住、正行四种过失自解脱、究竟四身任运”，也与金刚句一致。
4. “阿吙”以下一节极为简略，是备忘式的条目罗列，列出止的种种持心方法（不造作、截断念流、松紧调节、视线的高低远近、借法行与咒声持心、不拘威仪等）以及观的七种寻察（三对寻察合为六，加上决断于法界为七）。条目的确切分法与“十八种修法”的内容，原文没有展开，须依嘎乌玛大手印的引导文与上师口授。原文 འཕྲོ་བཅད་དང་ཞེ་བཅད，译为“截断念流，从心底截断”，存疑。
5. “太近、太深、太容易、太好”四句，是噶举大手印常说的“四种过失”的一种表述：心性因为太近而认不出，因为太深而抓不住，因为太容易而不信，因为太好而容纳不下。
6. “增上是靠放开而显出来的工具”“这两种去除的方法”，原文 བོགས་རྒྱངས་ཀྱིས་ཐོན་པའི་ལག་ཆ་ཡིན、གེགས་བྱུང་ན་སེལ་ཐབས་གཉིས་པོ་ཤོག，句意简省，暂依字面意译，存疑。
