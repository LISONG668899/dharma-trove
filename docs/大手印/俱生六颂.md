# 俱生六颂

梅纪巴（阿瓦都帝·无二金刚）造　据藏文译出

## 题解

《俱生六颂》（梵 Sahajaṣaṭka，藏 lhan cig skyes pa drug pa）收于德格版丹珠尔续部释 ཝི 函第 111a 页（东北目录 D2232），紧接在《除恶见难释》（D2231）之后，与前面的《中观六颂》（D2230）是一对同样体裁的短篇，同属梅纪巴的"无念法类"。译者是印度上师金刚手与藏地的粗敦译师。

《中观六颂》是从宗义的角度，判摄各家对"离四边"的理解，最后归到密乘；这一篇则直接从密乘与大手印的角度来讲"俱生"：先说真性远离常断二边，再说破有破无都是对治增益的方便，然后讲俱生不造作、俱生即是大乐、以"无疑惧"为大乐的体相，最后讲证悟种种显现都是自证，便没入俱生之海，而通达密咒真性的瑜伽士安住于无疑惧的意义之中。

本篇反复出现的"无疑惧"（dogs pa med pa，梵 niḥśaṅka），是理解全篇的关键，也是本篇最需要谨慎理解的地方，下面在按语中详细说明。

体例：每颂先列藏文原颂于代码块中，再按完整的意义单元译出；为了便于理解而补的字，都放在方括号中。原文含混或可有两解之处，以"【按】"说明，不妄补内容。文末附通篇连读。

## 题名与礼敬

梵语题名：Sahajaṣaṭka。藏语题名：《俱生六颂》。

敬礼持金刚！

## 第一颂

```
རྟག་དང་ཆད་ལས་ངེས་གྲོལ་བ། །
དེ་ཉིད་བདེ་གཤེགས་རྣམས་ཀྱིས་བཞེད། །
རང་བཞིན་ལས་སྐྱེས་ཆོས་རྣམས་ལ། །
སྒྲུབ་དང་སེལ་བར་ཕྱག་ནི་བརྗོད། །
```

决定远离常边与断边的，正是诸善逝所承许的真性。对于从自性［本然］而生的诸法，［我］就［其离于］成立与遣除，而作礼赞。

【按】前两句意思明确："真性"（de nyid）远离常、断二边，这是诸佛所许的。后两句的藏文很费解，直译是"对于从自性所生的诸法，于成立与遣除，说礼敬"。"成立"（sgrub）指肯定、安立为有，"遣除"（sel）指否定、破为无。这两句可以有两种理解：一是作者对俱生诸法敬礼，而这些法本身既不可成立，也不可遣除，也就是离开肯定与否定；二是说对于自性所生的诸法，一般人或成立、或遣除，下一颂就分别回应这两种人。从下文"对说有者说无、对说无者说有"来看，第二种理解与上下文衔接较好，但"作礼"一词在这种理解下不太顺，藏译或有讹误，存疑。"从自性而生"（rang bzhin las skyes），可能对应梵文 sahaja（俱生）一系的说法，意思是本然而有、不由造作，而不是"由某种自性实体所生"。

## 第二颂

```
ཡོད་པར་སྨྲ་བ་ལ་བརྗོད་པ། །
ཐམས་ཅད་རྣམ་པར་དཔྱད་ན་མེད། །
མེད་པར་སྨྲ་བ་ལ་བརྗོད་པ། །
རྣམ་པར་དཔྱད་ན་ཐམས་ཅད་ཡོད། །
```

对主张"有"的人，要这样说：一切法，若仔细观察，都是没有的。对主张"无"的人，要这样说：若仔细观察，一切法都是有的。

【按】这一颂的意思是：说"有"、说"无"都只是对治的方便，随对方的执著而施设。对执著实有的人，以观察显示一切无自性；对执著断无的人，则显示一切仍如幻地显现、缘起不虚。"若仔细观察，一切都是有的"一句，不能理解为胜义中实有，否则与第一颂"远离常断"相违；应理解为：观察到底，并不能得出断灭的"无"，显现与缘起依然不灭。这是依上下文的理解，原文本身没有这样展开。

## 第三颂

```
ཇི་ལྟ་ཇི་ལྟར་སྒྲོ་བཏགས་པ། །
དེ་ཉིད་རྣལ་འབྱོར་པ་རྣམས་སྐྱེ། །
དེ་ལྟ་དེ་ལྟར་སྒྲོ་བཏགས་པ། །
རྣལ་འབྱོར་དེ་ཉིད་ཀྱིས་ནི་འཇོམས། །
```

增益是以什么样的方式生起的，瑜伽士们［的瑜伽］就正以那样的方式生起；增益是以那样的方式安立的，就以那同样的瑜伽来摧破它。

【按】"增益"（sgro btags pa），指对本来没有的东西妄加安立，如把无自性的执为有自性。第二句"de nyid rnal 'byor pa rnams skye"最难解：de nyid 可以是"那同样的"，也可以是专门术语"真性"。按前一种读法，意思是瑜伽随增益的样子而生起，有什么增益就起什么对治；按后一种读法，意思是"真性在瑜伽士们之中生起"，也就是增益怎样生起，真性就在瑜伽士那里怎样显露。两种读法都能与第四句"以那瑜伽本身摧破"相配，这里依对仗的句式取前一种，并存后一种，存疑。全颂的要旨是一致的：瑜伽不是另外造作一个东西，而是针对增益本身、随增益之处而破除它。

## 第四颂

```
གང་ཕྱིར་ལྷན་ཅིག་སྐྱེས་མ་བཅོས། །
དེ་ཕྱིར་དོགས་མེད་ལྷན་ཅིག་སྐྱེས། །
བདེ་བས་ལྷན་ཅིག་སྐྱེས་གཞན་མིན། །
བདེ་བ་དོགས་པ་མེད་མཚན་ཉིད། །
```

因为俱生是不造作的，所以俱生是无疑惧的。俱生并不是在大乐之外的另一种东西；大乐，以无疑惧为它的体相。

【按】"俱生"（lhan cig skyes pa，梵 sahaja），指与心同时本有、不由修造而生的本性，在大手印中即指心的本来面目。"无疑惧"（dogs pa med pa，梵 niḥśaṅka），在密续中是一个特定的用语，意思是没有疑虑、没有顾忌与畏惧，不再以分别心计较净与不净、该与不该。这个词极易被误解为"可以毫无顾忌地随意而行"，那是严重的歪曲：在本篇中，"无疑惧"是从"俱生不造作"推出来的，也就是因为证悟了本来不造作的俱生，分别计较自然消失，而不是凭意志放下戒律、去作违规之行。没有证悟的人，以为自己"无疑惧"，只是放逸而已。"大乐"在密乘中有特定的修持内涵，须依具德上师的灌顶与口授来理解，不可照字面揣度。

## 第五颂

```
ཤེས་ཕྱིར་དོགས་པ་མེད་པའི་བདག །
དབྱེར་མེད་རྟོགས་པ་དམ་པ་བདེ། །
སྣ་ཚོགས་རང་རིག་རྟོགས་བྱས་པས། །
ལྷན་ཅིག་སྐྱེས་པའི་རྒྱ་མཚོར་ནུབ།
```

因为［如实］了知，［所以］是无疑惧的体性；证悟无二无别，就是殊胜的大乐。由于证悟了种种［显现］都是自证，［一切］便没入俱生的大海之中。

【按】第一句也可以读作"因为了知那无疑惧的体性"，即"了知"的对象就是无疑惧的本性；两种读法意思相近，这里取较简单的读法。"体性"，原文 bdag，不是指"我"，而是指本性、体性。"无二无别"（dbyer med），这里指乐与空、显现与心性、能取与所取不可分离。"自证"（rang rig），指心自明自知；"证悟种种显现都是自证"，是说种种显现并不是心外的境，而是心的自明，由此不再有能取所取的对立，所以说"没入俱生之海"，就像江河流入大海、不再分别。

## 第六颂

```
སྔགས་ཀྱི་དེ་ཉིད་རྣལ་འབྱོར་པས། །
དོགས་མེད་དོན་ལ་རབ་ཏུ་གནས། །
སྲིད་པ་ཡང་འདི་བླ་མར་བྱས། །
དོགས་པ་མེད་པའི་ཡུལ་གྱིས་སྟོན། །
```

通达密咒真性的瑜伽士，安住于无疑惧的意义之中。就连三有，也被他奉为上师，以无疑惧的境界来开示［他］。

【按】"密咒真性的瑜伽士"（sngags kyi de nyid rnal 'byor pa），也可以理解为"修密咒真性之瑜伽的人"。后两句很难确定："bla mar byas" 字面是"作为上师"，也可以理解为"使之成为殊胜、至上"。按前一种读法，意思是对这样的瑜伽士来说，连轮回三有本身都成了上师，种种境界都在向他开示无疑惧的意义；按后一种读法，意思是三有也因此而成为殊胜的，以无疑惧的境界来显示［真性］。两种读法都表达了同一个大手印的要点：轮回的显现不必舍弃，对证悟者而言反而成了显示俱生的助缘。这里取前一种读法，存疑。这样的境界是证悟者的境界，修行人不可在未证之时，借口"三有即上师""无疑惧"而放逸，前面第四颂的按语已经说明。

## 跋

《俱生六颂》，上师梅纪巴所造，圆满。

上师金刚手与粗敦译出。

【按】"梅纪巴"，原文作 mai tri pa。"粗敦"，原文作 mtshur，一般认为就是与金刚手合译梅纪巴多部著作的粗敦·智慧源（mtshur ston ye shes 'byung gnas）。

## 通篇连读

敬礼持金刚！

决定远离常边与断边的，正是诸善逝所承许的真性；对于本然而生的诸法，我就其离于成立与遣除而作礼赞。

对主张"有"的人，就说：一切法仔细观察，都是没有的；对主张"无"的人，就说：仔细观察，一切法都是有的。

增益以什么方式生起，瑜伽士的瑜伽就以那样的方式生起；增益以那样的方式安立，就以那同样的瑜伽摧破它。

因为俱生不造作，所以俱生无疑惧；俱生不在大乐之外，大乐以无疑惧为体相。

因为如实了知，所以是无疑惧的体性；证悟无二无别，就是殊胜的大乐；证悟种种显现都是自证，一切便没入俱生的大海。

通达密咒真性的瑜伽士，安住于无疑惧的意义；就连三有，也被他奉为上师，以无疑惧的境界开示他。

《俱生六颂》，上师梅纪巴造，圆满。上师金刚手与粗敦译出。
