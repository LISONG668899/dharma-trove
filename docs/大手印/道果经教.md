# 道果经教

据藏文译出

## 题解

《道果经教》（藏 lam 'bras gsung mdo，跋语作"深道上师三昧耶身各别观察之灭——道及其果的教授与口诀"）收于德格版丹珠尔续部释 ཞི 函第 139a 至 142b 页（东北目录 D2284），紧接在毗瓦巴《八十四句》（D2283）之后。本篇没有梵语题名，没有作者署名，也没有译者跋语。

**这是什么文献：**从内容与结构看，本篇就是萨迦派"道果"（lam 'bras）教法的根本文——传为大成就者毗瓦巴所口授的《金刚句》（rdo rje tshig rkang），萨迦派通称为《道果根本颂》或《宝贵口诀·道果金刚句》。按照萨迦派的传统说法，毗瓦巴把这部口诀传给黑行者等弟子，后由印度班智达迦耶达罗（Gayadhara）传入西藏，传给卓弥译师（'brog mi lo tsā ba），再传到萨迦初祖萨钦·贡噶宁波（sa chen kun dga' snying po），由萨钦首次写成文字。所以本篇虽收在丹珠尔中，却没有梵语题名与译者，正与这一传承说法相合。本篇开头"写下道果经教"（lam 'bras gsung mdo bri bar bya）一句，也说明它是从口传而"写下"的。

**本篇的性质与翻译的限度：**《金刚句》是萨迦派最根本、也最隐秘的教法之一，文字极为简略，几乎每一个词组都是一整段修法或一整套教义的代号，例如"四量""以三除修毒""四种聚界""十三地"等，若没有萨迦派历代的注释（如萨钦的十一部注释、"黄卷"等）与上师的口传，几乎无法如实理解。传统上，这部《金刚句》只传授给已受喜金刚灌顶、正式进入道果传承的弟子。

本译依本书一贯的原则，只照藏文字面译出，凡是能依通行的道果教义确定其大意的，在按语中简要说明其所指的名目；凡是无法确定的，一律存疑，不妄补内容。读者务必明白：这里的译文只是字面的线索，绝不能代替萨迦派上师依灌顶与口传所作的讲解，更不能凭文字自行修习。本篇中有大量关于脉、风、明点、业手印、"婆伽"等的内容，都是无上瑜伽续圆满次第中有特定内涵的象征用语与修法，这里只照原文直译，不作任何解说。

**全篇的结构**大致依道果教法的次第：
- 三现（不净现、觉受现、清净现）；
- 四续（根本因续、身方便续、道之释续、大手印果续）与四灌顶；
- 以四量决定果，以三法除禅修之毒；
- 方便道与智慧道的障碍及其守护；
- 以三十七菩提分法配合修道的种种觉受与征相：四神足（四种聚界与元素融入的征相）、四念处、四正断、忍、世第一法；
- 出世间道：依化身、报身、法身、自性身四个层次，各以四灌顶修持，配合七觉支、五力、八正道，从初地依次到第十三地（金刚持地），每一地都有"内相"（风息止息若干指）与"外相"（明点稳固于某处）；
- 最后成佛，以及结颂。

**与前译的关系：**本篇以前没有译过。毗瓦巴的《道歌宝藏》（D2280）、《八十四句》（D2283）、《甘露成就基础》（D2285）与本篇同属毗瓦巴名下，可以参看。

## 一、礼敬与立誓（第 1 段）

```
༄༅༅། ། བླ་མ་དམ་པའི་ཞབས་པད་ལ་བཏུད་དེ། ། ལམ་འབྲས་གསུང་མདོ་བྲི་བར་བྱ། །
```

顶礼殊胜上师的莲足之后，我要写下道果的经教。

## 二、三现（第 2–3 段）

```
སེམས་ཅན་ལ་ཉོན་མོངས་པའི་སྣང་བ་ལ་མ་དག་པའི་སྣང་བ། རྣལ་འབྱོར་པ་ཏིང་ངེ་འཛིན་ལ་ཉམས་ཀྱི་སྣང་བ།
བདེ་བར་གཤེགས་པའི་སྐུ་གསུང་ཐུགས་མི་ཟད་པ་རྒྱན་གྱི་འཁོར་ལོ་ལ་དག་པའི་སྣང་བའོ། །
```

对具有烦恼的众生来说，是不清净的显现；对住于三摩地的瑜伽士来说，是觉受的显现；对善逝身语意无尽庄严之轮来说，是清净的显现。

【按】这就是道果教法开头著名的"三现"（snang ba gsum）：不净现、觉受现、清净现，分别对应凡夫、修道的瑜伽士与佛三种层次的显现，是道果"共同道"的总纲。

## 三、四续与四灌顶（第 4–8 段）

```
ཀུན་གཞི་རྒྱུ་རྒྱུད་ལ་འཁོར་འདས་(ཆང་,ཚང་)བས་རྩ་རྒྱུད། ལུས་ཐབས་རྒྱུད་སོགས་ལ་གདན་སོགས་གསུམ་པ་བཞི་ཡིས་རྒྱུའི་དབང་།
ལམ་དུ་བསྐྱེད་རིམ་ལ་སོགས་ལྔ་པ་བཞིས་བསྟན། མཉམ་གཞག་གི་དམ་ཚིག་སོགས་བསྲུང་།
རྡོ་རྗེ་མཁའ་འགྲོ་ལ་སོགས་ཀྱི་ཉམས་ཆགས་བསྐང་། འདོད་ཡོན་སོགས་ལྔ་ཡིས་མཉེས་པ་སོགས་བྱ།
ལམ་གྱི་ཐུན་བཞི་ལ་དབང་བཞི་བསྒོམས་པས་ལུས་ལ་བརྟེན་ནས་བདེ་ཆེན་གྱི་སྒྲིབ་པ་འདག་ཅིང་འཚང་རྒྱ་བར་གསལ་བས་བཤད་རྒྱུད།
ཕྱག་རྒྱ་ཆེན་པོ་འབྲས་བུའི་རྒྱུད་ནི། འབྲས་བུའི་དབང་བཞིས་ཐམས་ཅད་མཁྱེན་ཏོ། །
```

阿赖耶是因续，因为它含摄轮回与涅槃，所以是根本续。在身方便续等上，以"座"等三，以四［灌顶］为因位的灌顶。在道上，以生起次第等五［法］的四［组］来开示；守护等持的三昧耶等；补救金刚空行等的毁损；以五种欲妙等使［本尊］欢喜等。在道的四座中修习四灌顶，依靠身体，大乐的障碍得以清净而成佛，［这一切］明白开示，所以是释续。大手印是果续：以四种果位的灌顶，成为一切智。

【按】这一节是道果的"四续"（rgyud bzhi）：一、"阿赖耶因续"——阿赖耶含摄轮回与涅槃，是根本；二、"身方便续"——以身体为修道的方便，配合"座"（gdan）等因位的四灌顶；三、"道之释续"——在四座修习中修四灌顶的道，以生起次第等为内容；四、"大手印果续"——以四果灌顶成佛。

"以'座'等三，以四［灌顶］为因位的灌顶"（gdan sogs gsum pa bzhi yis rgyu'i dbang），在道果注释中指"座、本尊、种子"等三法配合四灌顶，具体所指须依注释，存疑。"以生起次第等五［法］的四［组］"（bskyed rim la sogs lnga pa bzhis），指四灌顶各有五法（见、修、行、果等），合为"四组五法"，存疑。"补救金刚空行等的毁损"（nyams chags bskang），是对三昧耶的毁损加以忏补。这些都是灌顶与圆满次第的内容，须依具德上师的灌顶与口授来理解。

## 四、四量与除修毒（第 9–17 段）

```
ཚད་མ་བཞིས་འབྲས་བུ་གཏན་ལ་ཕབ་ནས། འགལ་འདུས་སྐྱོན་མེད་སོགས་གསུམ་གྱིས་བསམ་གཏན་གྱི་དུག་དབྱུང་།
ཟས་སྤྱོད་ལམ། རླུང་ཐིག་ལེ། ཕྱག་རྒྱ་མ་བསྟེན། དངས་མ་ལྔའི་བདེ་བ་དང་།
དབང་པོ་ལྔ་ཉམས་དང་མ་བྲལ་བས་བདུད་རྩི་བསྟེན། འཁོར་བའི་རྩ་བཞི་དང་།
འཁོར་ལོ་རྣམས་དང་། གཞན་རྣམས་དང་། ས་ཐོག་མཐའ་ལ་རེ་རེ། གསུམ་པ་བཅུས་བར་གྱི་རྩ་མདུད་དྲལ་བས་ལ་དོར།
འཇུག་པ་སེལ་བའི་ལམ་ཡིད་འདག་པའི་རྣམ་རྟོག་བསྒོམས་པས་ལྟ་བའི་དུག་དབྱུང་།
རྣམ་ཤེས་ལྔས་ཡུལ་ལྔ་མ་སྤངས་པས། བདུད་རྩི་བསྟན། དག་པའི་ཆོས་རྣམས་གདོད་ནས་སྟོང་པར་ཤར་བས་ལ་དོར།
```

以四量决定了果之后，以"违与合无过"等三［法］，除去禅修之毒：饮食、行为、道；风、明点；依止手印母；五种精华的安乐，以及不离五根的觉受，所以依止甘露。轮回的四根本、诸轮、其他，以及地、始、终各一；以第三的十［法］解开中间的脉结，所以［在关口］抛下。以消除趣入之道，修习清净意的分别，除去见之毒。因为五识不舍弃五境，所以开示甘露；清净之法从本以来显现为空，所以［在关口］抛下。

```
གསང་སྔགས་སྙན་བརྒྱུད་ལ་སོགས་བཞི་མ་ཆད་པས། ལུས་ཁྱད་པར་ཅན་ལ་བརྟེན་ནས་དངོས་པོའི་མཐའ་རྟེན་ཅིང་འབྲེལ་པར་འབྱུང་བ།
གཞན་དབང་རྟེན་འབྲེལ་བྱང་ཆུབ་ཆེན་པོའི་ལམ། ཆོས་ཐམས་ཅད་རྟེན་ཅིང་འབྲེལ་བར་འབྱུང་བ་ལོ་རྒྱུས་ཀྱིས་ཚད་མའོ། །
ཀུན་གཞི་རྣམ་ཤེས་དག་པའི་བྱང་ཆུབ་ཆེན་པོ། ། རྟེན་ཅིང་འབྲེལ་པར་འབྱུང་བ་ལྔ་ཡིས་ལམ་ཡོངས་སུ་རྫོགས་པའོ། །
```

因为密咒耳传等四者没有中断，依靠殊胜之身，事物的边际就是缘起；依他起的缘起，就是大菩提之道；一切法都是缘起的——［这是］以历史［传承］为量。阿赖耶识清净，就是大菩提；以五种缘起，道得以圆满。

【按】"四量"（tshad ma bzhi），道果中指决定道与果的四种依据：圣教量、历史［传承］量、上师口诀量、觉受量。本篇第 16 段明确说到"以历史为量"。

"以'违与合无过'等三［法］，除去禅修之毒"，在道果中指"除修毒"（bsam gtan gyi dug dbyung）的内容：当修行中出现偏差或障碍时，以饮食、行为、风、明点、依止手印母等方法来调整。第 12、14 段末的"la dor"（字面是"在山口抛下"），在道果术语中意思是"彻底决断、放下"，存疑。"第三的十［法］"、"轮回的四根本"等，都是道果注释中有专门解释的名目，这里无法确定其所指，存疑。"依止手印母""五种精华的安乐"等，是圆满次第中的象征用语与修法，这里不作解说。

"五种缘起"（rten 'brel lnga），道果中有"外缘起、内缘起、秘密缘起"等多种缘起的说法，具体所指须依注释，存疑。

## 五、方便道与智慧道的障碍及守护（第 18–22 段前半）

```
ཐབས་ཀྱི་ཕྱོགས་སུ་ལྷུང་བའི་རྣལ་འབྱོར་པའི་ལམ་གྱི་བར་ཆད་ནི། དད་པ་བརྟན་པོས་སྲུང་བའི་འཁོར་ལོ།
སྔགས་ཟློས། སྔགས་མདུད། ཆོས་རྣམས་སེམས་ཉིད་སྣང་བ། གཞན་དབང་རྟེན་འབྲེལ།
གཟུགས་བརྙན་ཡིན་ཕྱིར། དེ་ཁོ་ན་ཉིད་རྒྱ་མཚོའི་དོན་དང་མ་བྲལ་བས་བསྲུང་།
ཤེས་རབ་ལ་ཕྱིའི་བདུད་ལམ་གཉིས། ལྟ་གྲུབ་བརྒྱད་རྒྱུར་བའོ། ། ནང་གི་བདུད་ལམ་ལ་སོགས་བཅུ་དང་བརྡ་མ་ཤེས་ན་འོད་བརྡ་ཤེས་པས་བསྲུང་།
གྲིབ་དང་སྒྲིབ་པ་ཐིག་ལེ་འཛག་པ་བསྲུང་། ། ཚོགས་ལམ་ནས་ཐ་མལ་པའི་ལུས་ངག་ཡིད་དང་བྲལ་བས་བྲལ་བའི་འབྲས་བུ་བཞི་ཐབས་ནས།
```

偏于方便一方的瑜伽士的道障：以坚固的信心作守护之轮；念诵密咒；结咒结；［了知］诸法是心的显现、依他起的缘起，因为如影像一样；以不离真性大海之义来守护。

对于智慧［一方］：外在的魔道有两种，即［以］八种见与宗义而流转；内在的魔道等有十种。若不认识表征，以认识光明的表征来守护。守护影、障与明点的漏失。

【按】道果中把修行者分为"偏于方便"与"偏于智慧"两种，各有不同的障碍与守护方法。"咒结"（sngags mdud），是以密咒加持的线结等护身的方法。"明点的漏失"（thig le 'dzag pa），是圆满次第中要守护的要点。这些都须依具德上师的口授来理解。第 21 段"ལྟ་གྲུབ་བརྒྱད་རྒྱུར་བའོ"，意思不很清楚，存疑。

## 六、修道：三十七菩提分与四神足（第 22 段后半–31 段）

```
ཁམས་འདུ་ལུགས་གསུམ་གྱིས་ཕྱོགས་མེད་རྣམས་དང་། རླུང་སེམས་བདག་བྱིན་གྱིས་བརླབས་ནས།
བྱང་ཆུབ་ཀྱི་ཕྱོགས་དང་མཐུན་པའི་ཆོས་སུམ་ཅུ་རྩ་བདུན་ལྟར་ལམ་བགྲོད་ན།
སྒོམ་པ་མི་འཆོར་བའི་རྫུ་འཕྲུལ་གྱི་རྐང་པ་བཞི་ནི། ལས་ཀྱི་རླུང་ཕོ་མོ།
མ་ནིང་གི་རླུང་། ཐོད་རྒལ་གྱི་ཡེ་ཤེས་ཀྱི་མེ་འབར་བས། ཁམས་འདུས་པ་དང་པོ།
རྒྱུན་གྱི་རླུང་པོ་ལག་ཅ་ཅན་གྱིས་རྩ་དྲལ། སེམས་གནས། རྟ་རྨི། རྩ་རླུང་གི་ཟུག་འབྱུང་།
སྣ་ཚོགས་འདུད་ལ་སོགས་བཞི་རྩ་བའི་རླུང་ལ་སོགས་ཟིན་པའི་བྱེ་བྲག་བདུན་གྱིས་ཡན་ལག་གི་རླུང་རིམ་གྱིས་ནང་དུ་འགག །
དེ་ཙ་ན་ཐིག་ལེ་མང་དུ་ཁ་འབུ། རྟེན་མཉམ་དུ་འདྲེ་དེ་ལ་བརྟེན་ནས་སེམས་ནང་དུ་གནས།

བསྒོམ་པ་མི་འཆོར་བའི་མཐོང་སྣང་རྨི་ལམ་ཉམས་གསུམ་གསུམ་ནི་རྣམ་རྟོག་སྔོན་དུ་སོང་བ་ལྟར་ཁམས་གསུམ་ཀུན་དུ་སྣང་ངོ་། །
```

从资粮道开始，由于远离凡庸的身语意，［有］离系的四果。以三种聚界的方式……，以及加持风心之后，若依三十七菩提分法来行道：

修习不失坏的四神足是：业风的男与女、中性之风，以超越的智慧之火燃烧，这是第一次的聚界。以带钳的持续之风撕开脉；心住；马梦；脉风的刺痛生起；以"种种结"等四种根本风等被持住的七种差别，支分之风依次在内里止息。那时，许多明点萌芽；所依平等地混合，依靠它，心安住于内；五识聚于内；五蕴调伏；作智慧的往来。修习不失坏的见相、梦境与觉受，各有三种，就像分别在前那样，在一切三界中显现。

【按】这一节开始，道果把修道中种种身心的觉受与征相，配合三十七菩提分法来说明。"四神足"（rdzu 'phrul gyi rkang pa bzhi），在这里配合"第一次的聚界"（khams 'dus pa dang po）：风息、明点等在身体中聚集所产生的种种觉受。"业风的男、女、中性之风"，是圆满次第中对风息的分类；"超越的智慧之火"（thod rgal gyi ye shes kyi me），"thod rgal"是"超越"之意，与大圆满的"顿超"同字，这里指拙火，存疑。"带钳的持续之风"（rgyun gyi rlung po lag ca can），"lag ca"（钳子）比喻风如钳子般撕开脉结，存疑。"马梦"（rta rmi），是修行中出现的一种梦相，存疑。

这些都是圆满次第中极为隐秘的身心觉受，只能在道果传承中依上师的口授来理解，这里只照原文译出，不作解说。

## 七、四大融入与种种显现（第 32–42 段）

```
ས་ཆུ་ལ་ཐིམ་ན་སྨིག་རྒྱུ། ཆུ་མེ་ལ་ཐིམ་ན་དུ་བ། མེ་རླུང་ལ་ཐིམ་ན་སྲིན་བུ་མེ་ཁྱེར།
རླུང་རྣམ་པར་ཤེས་པ་ལ་ཐིམ་ན་མར་མེ་འབར་བ། རྣམ་པར་ཤེས་པ་འོད་གསལ་ལ་ཐིམ་ན་ནམ་མཁའ་སྤྲིན་མེད་ལྟ་བུ།
ས་ཆུ་མེ་རླུང་དང་རླུང་སེམས་མཉམ་པར་འདུས་ན་ཁམས་གསུམ་ཀུན་དུ་མེ་འབར་བ་ལྟ་བུར་སྣང་།
```

地融入水，［显现］如阳焰；水融入火，如烟；火融入风，如萤火；风融入识，如燃烧的酥油灯；识融入光明，如无云的虚空。地、水、火、风与风心平等地聚集，三界都显现如燃烧的火。

```
ཆུ་རླུང་དང་སྤུ་ལུས་གྲང་། རླུང་གི་རླུང་འདུ་འཕྲོ་དང་རང་འཕུར་བྱ་འབྱུང་།
འབྱུང་བ་བཞིའི་རླུང་མཉམ་རྒྱུ་དང་ལྷ་མོ་སྣ་ཚོགས་ཀྱིས་གར་མཆོད་དང་དྲི་རོ།
འབྱུང་བ་བཞིའི་རླུང་མཉམ་རྒྱུ་དང་ལྷ་མོ་སྣ་ཚོགས་ནམ་མཁའ་དང་མཉམ་པ་དང་སྤུ་ལུས་བདེ།
བདུད་རྩི་ལྔ་དང་བཞིན་གཤེགས་སྐུ་སོགས། སིཧླ་དང་ཉི་མ། ག་པུར་དང་ཟླ་བ།
རྩ་བྲན་རྣམས་སུ་ཐིག་ཕྲན་དང་སྐར་མ། རྩ་འཛིན་ལ་སོགས་སུ་ཤིང་སྡོང་ལ་སོགས།
ཆགས་སྡང་རྣམ་པ་ལྔ་དང་། ཉམ་ང་མྱ་ངན་འདྲེའི་རྩ། མཆི་མའི་རྩར་གཡལ་དང་མཆི་མ།
ལྟེ་བར་དང་པོ་ཆགས་པའི་རིགས་དྲུག་གི་ཡི་གེར་རླུང་སེམས་མཉམ་པར་འདུས་ན།
རིགས་དྲུག་གི་གར་སྔགས་དེར་ཁྲིད་པ། རྨི་ལམ་ཉམས་ལྟ་བུ་ཁམས་གསུམ་ཀུན་དུ་སྣང་ངོ་། །
```

水风与［显现］，身毛寒冷；风之风的聚散，与自己飞翔的鸟出现；四大之风平等运行，与种种天女以舞蹈供养，以及香与味；四大之风平等运行，与种种天女等同虚空，以及身毛安乐；五甘露与如来身等；悉诃罗香与太阳；樟脑与月亮；在支脉中，小明点与星辰；在持脉等中，树木等；五种贪嗔；恐惧、忧伤、鬼的脉；在泪脉中，羞愧与眼泪。在脐间，最初形成的六道的文字上，若风心平等地聚集，就被引到六道的舞蹈与咒语那里；三界都显现如梦与觉受一般。

【按】第 32–34 段的"四大融入"及其征相（阳焰、烟、萤火、灯焰、无云虚空），与临终时四大分解的次第、圆满次第中风息融入中脉的征相相同，是藏传密法中广为人知的说法。

第 35–42 段列举风心聚集于身体不同的脉与轮时，修行者所见的种种显现与身体感受。其中的"悉诃罗香"（si hla，一种香料）与太阳、"樟脑"与月亮，是以香料比喻脉中的明点；"六道的文字"，是脐轮中代表六道众生的种子字。这些都是道果中有特定内涵的修道征相，这里只照原文译出，不作解说。

## 八、三字与中间的聚界（第 43–47 段）

```
ཨོཾ་ལས་བསམ་གཏན་སོགས་ཀྱི་ཏིང་ངེ་འཛིན་ཡུམ་གྱི་མཁའ། ཨ་ལས་ཡང་དག་པར་ཐིམ་ན་ཁམས་གསུམ་ནམ་མཁའ་ཡུམ་ཆེན་མོ་ཤེས་རབ་ཀྱི་ཕ་རོལ་ཏུ་ཕྱིན་མ་ལ་སོགས་ཀྱི་ཕོ་བྲང་དུ་ཐིམ་ན་ཆོས་སྐུ་ཉམས་སུ་མྱོང་ཞིང་གཟུང་འཛིན་གྲོལ།
ཧཱུཾ་ལས་གསལ་ཞིང་ཡང་ལ་རང་འབྱུང་གི་ཡེ་ཤེས་ནམ་མཁའ་ཤིན་དུ་དྲི་མ་མེད།
ཁམས་འདུས་པ་བར་པ་རླུང་པོ་ལག་ཅ་བྲི་བས་རྩ་དྲལ། ཐིག་ལེའི་གཟུགས་དང་མཐོང་སྣང་བརྟེན་ནོ། །
མདོར་ན་རཀྵ་ལ་སོགས་སུ་སྲིན་པོ་སོགས་དྲི་ཅན་གྱི་སྒྲ་ལྷའི་མིག་རྣམ་པར་དག་པ་བཞིན།
སྲིད་པའི་རྩེ་མོ་མན་ཅད་ཏིང་ངེ་འཛིན་གྱི་ཉམས་སུ་འབྱུང་བ་སྙམ་བྱེད་པ།
```

从"嗡"［字］，［生起］禅定等的三摩地，［是］佛母的虚空；从"阿"［字］真实地融入，融入三界的虚空、大佛母般若波罗蜜多等的宫殿时，就体验到法身，能取所取得到解脱；从"吽"［字］，明亮而轻盈，自生的智慧，如虚空般极为无垢。第二次的聚界：风以钳子撕开脉，明点之形与见相就稳固了。总之，在"罗刹"等［脉］中，听到罗刹等乾闼婆的声音，就像天眼得到清净一样；［觉得］有顶以下的［一切］都显现为三摩地的觉受。

【按】"嗡、阿、吽"三字，在这里与三摩地、法身、自生智慧相配，存疑。"第二次的聚界"（khams 'dus pa bar pa），与上文"第一次的聚界"相对。"罗刹等［脉］"（rak+Sha），是脉的名称，存疑。

ནང་གི་མཁའ་འགྲོ་མ་ལྔ་དེ་བཞིན་གཤེགས་པའི་སྐུ་ལྔ། བྱང་ཆུབ་ཆེན་པོའི་རྟེན་འབྲེལ་མཛད་པས།
དངོས་གྲུབ་རྣམས་རང་ལ་འབྱུང་བར་ཤེས་ཤིང་རེ་ཞིང་སྩོལ་བའི་བློ་སེལ་ཏོ། །
བདུད་དང་གོལ་ས་རྣམས་རང་གི་ལམ་དང་རྟེན་འབྲེལ་དུ་ཤེས་པས་སྐྱོན་ཡོན་ཏན་དུ་བསླང་ཞིང་རིམ་པ་ཡིན་མིན་དུ་སྐྱེ་བའི་དོད་བྱུང་རྒྱལ་དུ་གཏང་།
```

［这些］说不尽的［征相］，只是标示一下，［其余］五十［种］秘而不宣。修习不失坏的外缘起，即风的逆转等，各有三种；内在的五空行母、五如来身，作为大菩提的缘起，所以了知诸悉地都在自身中生起，而消除了希求［他人］赐予的心。了知诸魔与歧途都是自己的道与缘起，所以把过失转为功德，对于次第是否［如此］而生起的［疑虑］，就让它得胜地过去。

【按】"五十［种］秘而不宣"（lnga bcu la gsang），意思是还有五十种征相没有写出，存疑。"了知诸悉地都在自身中生起，而消除了希求赐予的心"，是道果的要点：成就不是外来的赐予，而是自身缘起的显现。"把过失转为功德"，与毗瓦巴《道歌宝藏》"逆缘即悉地"的意思一致。最后一句"རིམ་པ་ཡིན་མིན་དུ་སྐྱེ་བའི་དོད་བྱུང་རྒྱལ་དུ་གཏང"，意思不很清楚，存疑。

## 十、智慧道的障碍；四念处（第 52–55 段）

```
ཤེས་རབ་ཀྱི་ཕྱོགས་སུ་ལྷུང་བའི་ལམ་ལ། ལྷའི་བུའི་བདུད་འོང་བས་སད་པ་བཞིས་བསྲུང་།
སྒོམ་པ་མི་འཚེར་བའི་དྲན་པ་ཉེ་བར་གཞག་པ་བཞི་ནི། ཡུལ་འགགས་པས་རང་ཡི་དམ་གྱི་ལྷ་དང་།
གུག་སྐྱེས་ཀྱི་དགོས་པ་བསམ་ཞིང་ཏིང་ངེ་འཛིན་ཆ་བསྙམས་པས། ཁམས་འདུས་པ་ཐ་མ་རླུང་པོ་ལག་ཅ་དྲལ་བས་རྩ་བྲལ།
སྐྱེ་མཆེད་དྲུག་གི་ནང་དུ་ཐིག་ལེ་འདུས་པས་རྗེས་སུ་དྲན་པ་དྲུག་ཡང་དག་པར་ཤེས།
```

在偏于智慧一方的道上，若天子魔到来，以四种觉醒来守护。修习不……的四念处是：由于对境止息，［观］自己是本尊；思惟驼背者的必要，使三摩地平衡；第三次［即最后］的聚界，风以钳子撕开脉，而离开脉。明点聚集于六处之中，所以真实了知六随念；见到一些化身。

【按】"四种觉醒"（sad pa bzhi），是对治天子魔的方法，具体所指须依注释，存疑。"修习不……"，藏文作"སྒོམ་པ་མི་འཚེར་བའི"，"'tsher"可能是"'chor"（失坏）之误，与上文"修习不失坏"相同，存疑。"驼背者"（gug skyes），可能是女本尊俱毗迦（Kubjikā）等的名称，存疑。"六随念"，即念佛、法、僧、戒、施、天。

## 十一、四正断；忍（第 56–60 段）

```
སྤྲུལ་སྐུ་འགའ་མཐོང་། སྒོམ་པ་མི་འཆོར་བའི་ཡང་དག་པར་སྤོང་བ་བཞི་ནི།
སྤྲུལ་སྐུ་ལས་དབང་གསུམ་གྱི་རྗེས་ལས་བྱུང་བའི་ཤེས་པ་བསམ་ཞིང་། དགྱེས་སོགས་པང་ཅན་བཅུ་གཉིས་མའི་རྩ་བཙལ་ཞིང་།
སྙིང་པོའི་ཨ་ཀུན་འདར་གྱི་སྣ་རྩེར་དལ་རྒྱུ་ལ་སོགས་རིག་པ་ཡིད་འཇུག་པས།
ལུས་ངག་ཡིད་གསུམ་རྡོ་རྗེ་སྐྱིལ་ཀྲུང་བཅས། ཐིག་ལེ་རླུང་ནོན་པས་རྔ་སྒྲ་ལ་སོགས་མི་ཐོས་པས།
ཆོག་ཤེས་པ་སོགས་ཀྱི་བདུད་ཆོམས་པའོ། ། ནང་གི་སངས་རྒྱས་རྣམས་ཀྱི་ལམ་སྲིད་པའི་རྩེ་མོར་ཕྱིན་ཅིང་མ་སྐྱེས་པའི་ཆོས་ལ་བཟོད་དཀའ་བ་སྟོང་པ་ཉིད་ཀྱི་བཟོད་པའོ། །
```

修习不失坏的四正断是：从化身思惟三灌顶之后所生的智慧，寻找喜［金刚］等具膝者十二女的脉；心要的"阿衮达"在鼻尖缓缓运行等，觉性进入心意，所以身语意三者都结金刚跏趺；明点压住风，所以听不到鼓声等，因此摧毁了"知足"等魔。

内在诸佛之道到达了有顶，对于不生之法，［生起］难忍的［忍］，就是空性之忍。

【按】这一节极为隐秘。"具膝者十二女"（pang can bcu gnyis ma），可能是喜金刚坛城中的某些女尊或脉的名称，存疑。"阿衮达"（a kun 'dar），可能是中脉（avadhūtī）的某种异名，存疑。"明点压住风，所以听不到鼓声等"，是说风息入中脉后，内在的种种声音（如鼓声）止息，存疑。"知足等魔"，是说满足于初步觉受而不再精进，也是一种魔障。"空性之忍"，对应四加行道中的"忍位"。

## 十二、世第一法；自相（第 61–63 段）

```
དབུ་མར་སེམས་རྟོག་མེད་ལོག་སེམས་འཕོས་ན་བཟོད་པ། འཁོར་བའི་ཆོས་ལས་འདས་ཤིང་།
མྱ་ངན་ལས་འདས་པའི་ལམ་ཆོས་རྣམས་རྫོགས་པས་ཆོས་རྣམས་ཀྱི་ནང་ན་མཆོག་གོ། །
དེ་ལྟར་ཉམས་སྐྱོན་ཅན་སྐྱོན་མེད་དང་། ཕྱི་དབྱིབས་ཀྱི་ཨ་ནས་ཡར་རླུང་སེམས་མཉམ་པར་འདུས་ནས་ལམ་དུ་འབྱུང་བ་རྣམས་ངོ་བོ་རང་མཚན་ཉིད་དོ། །
```

若无分别的心转入中脉，就是忍；超越了轮回之法，涅槃之道的诸法圆满了，所以是诸法中最上的［世第一法］。这样，有过失与无过失的觉受，以及从外形的"阿"字向上、风心平等聚集而生起为道的一切，就是本体的自相。

【按】这里依次说到四加行道的"忍"与"世第一法"。"外形的'阿'字"，是脐轮中的种子字，风心从那里向上聚集，存疑。

## 十三、出世间道：化身、瓶灌顶——初地（第 64–75 段前半）

```
འཇིག་རྟེན་ལས་འདས་པའི་ལམ་ལ། ཕྱི་ནང་རྟེན་ཅིང་འབྲེལ་པར་འབྱུང་བའི་ལམ་གྱིས་སྤྲུལ་སྐུ་རང་བཞིན་གྱིས་ལྷུན་གྲུབ་ཐོབ་པར་བྱེད་པ།
སྤྱོད་པའི་རིམ་པའི་ལམ་ནས་ལུས་དག་པར་བྱེད་པ་བུམ་པའི་དབང་མཐར་ཕྱིན།
དེ་ཁོ་ན་ཉིད་ཀྱི་རྟགས། བྱང་ཆུབ་ཀྱི་ཡན་ལག་བདུན་ནི། རྩ་རིན་པོ་ཆེའི་ཕོ་བྲང་བཞི།
གཙོ་བོ་གསུམ་སྟེ་ལུས་ཀྱི་དཀྱིལ་འཁོར་མཐོང་བས་རྟོག་པའི་འགྲོ་ལྡོག་བྱེད།
སྤྲུལ་སྐུའི་ཞིང་ཁམས་བརྒྱ་བསྒུལ་ཞིང་ཉན། སྦྱིན་བརྒྱ། འོད་བརྒྱ་འགྱེད།
མར་བརྒྱ་འཆད། ཏིང་ངེ་འཛིན་མི་འདྲ་བ་བརྒྱ་ལ་སྙོམས་པར་འཇུག་ནུས། རིགས་དྲུག་གི་རྩར་ཁྱད་པར་དུ་མིའི་རྟེན་མཐོང་ནས་དགའ་ལ་གཡང་ཟ།
ངོ་ཚ་ལ་སྐྱུག་བྲོ། ། སྔོན་བླ་མས་རྒྱུ་དུས་ན་བསྟན་པའི་འཁོར་འདས་དབྱེར་མེད་དེ་ཙ་ན་རྟོག སྙིང་རྗེ་སྐྱེ།
མཆི་མ་ལྟུང་། གཞན་གྱི་སེམས་སྣ་ཚོགས་ཤེས། འདོད་ཡོན་སྣ་ཚོགས་མཐོང་བས་དགོད་བྲོ། །
རྫུ་འཕྲུལ་སྣ་ཚོགས་སྐད་ཅིག་མས་འབྱུང་བ་རྣམས་ནང་གི་ཞིང་ཁམས་མཐོང་བས་སོ། །
ནང་མ་མཐོང་པར་ཕྱི་མི་མཐོང་། དེ་ཙ་ན་ལིང་ག་བརྟན། རྡོ་རྗེ་རྩེར་ལྷན་ཅིག་སྐྱེས་པའི་སར་ཐིག་ལེ་གནས་པ་ལྟར།
ལུས་བདེ་བས་མྱོས་ཤིང་བརྒྱལ། རང་གཞན་ངོ་མི་ཤེས། ནང་རྟགས་རླུང་སོར་གཅིག་འགགས།
ཕྱི་རྟགས་གསང་གནས་ཕྱེད་ཐིག་ལེས་བརྟན་ས་དང་པོའོ། ། ཡང་སྤྲུལ་སྐུ་ལས་དབང་བཞི་སྒོམ་ལམ་ས་གཉིས་པ་ནས་སྤྲུལ་པའི་སྐུའི་ཞིང་ཁམས་སྟོང་ལ་སོགས་པ་བསྒུལ་བ་ལ་སོགས་པ་ནུས།
```

在出世间道上：以外内缘起之道，使化身自然任运成就；以行持次第之道清净身体，瓶灌顶达到究竟。真性的征相——七觉支是：脉的四座珍宝宫殿、三条主脉，即见到身体的坛城，所以能作分别的往来；能震动并聆听百个化身刹土；［能作］百次布施，放出百道光，讲说百［种法］；能入百种不同的三摩地。在六道的脉中，特别见到人身，就欢喜而发痒；对羞愧则想呕吐。

先前上师在因位时所开示的轮回涅槃无别，那时就证悟了；生起悲心，流下眼泪；了知他人种种的心；见到种种欲妙而想笑；种种神变刹那间出现——这是因为见到了内在的刹土。不见内在，就不见外在。那时，林伽稳固；就像明点安住于金刚尖端、俱生之处那样，身体被安乐所醉而昏厥，不认识自己与他人。内相：风止息一指；外相：明点稳固于秘处的一半——［这是］初地。

【按】从这一节开始，道果把出世间道的十三地，配合化身、报身、法身、自性身四个层次与四灌顶来说明，每一地都有"内相"（风息止息的指数）与"外相"（明点稳固的身体部位）。

"七觉支"在这里配合初地（见道）的种种征相。"能震动并聆听百个化身刹土……能入百种不同的三摩地"，是经论中说初地菩萨的"百种功德"（如一刹那能见百佛、动百世界等）。"林伽稳固""明点安住于金刚尖端、俱生之处""秘处"等，都是第三灌顶中有特定内涵的象征用语，只能依具德上师的灌顶与口授领受，这里不作任何解说。"对羞愧则想呕吐"，意思不很清楚，存疑。

## 十四、二地至六地（第 75 段后半–77 段）

```
ཡོན་ཏན་ལ་སོགས་འཕེལ། འགྲོ་ལྡོག་ལ་སོགས་འགགས། ནང་རྟགས་རླུང་སོར་དྲུག་འགགས།
ཕྱི་རྟགས་གསང་གནས་ཏེ། སྙིང་ཐིག་ལེས་བརྟན། ལོངས་སྐུ་འགའ་མཐོང་། སྒོམ་ལམ་ས་དྲུག་གོ།
```

又从化身修四灌顶，从修道的第二地起，能震动千个化身的刹土等；功德等增长；往来等止息。内相：风止息六指；外相：从秘处到心间，明点稳固；见到一些报身——［这是］修道的第六地。

【按】这里的"内相""外相"，随着地位的提升，风息止息的指数与明点稳固的部位也依次上升。"从秘处到心间"，藏文作"གསང་གནས་ཏེ། སྙིང་ཐིག་ལེས་བརྟན"，文字可能有脱漏，存疑。

## 十五、报身、秘密灌顶——七地至十地（第 78–86 段）

```
ཡང་ལོངས་སྐུ་ལས་དབང་བཞི་བཞི་བདག་བྱིན་གྱིས་བརླབ་པའི་རིམ་པའི་ལམ་ནས།
ལོངས་སྐུ་རང་བཞིན་གྱིས་ལྷུན་གྲུབ་ཐོབ་པར་བྱེད་པ། ངག་དག་པ་གསང་བའི་དབང་མཐར་ཕྱིན།
དེ་ཁོ་ན་ཉིད་ཀྱི་རྟགས་དབང་པོ་ལྔ་དང་དངས་མའི་རླུང་ལྔ་ལ་མངའ་བརྙེས།
ནུས་པ་ལྔ་དང་ལྟ་སྟངས་རྣམས་ལ་ཐོགས་པ་མེད། བྷ་གའི་དཀྱིལ་འཁོར་དུ་རིགས་དྲུག་གི་ས་བོན་མཐོང་།
ས་བོན་དྲུག་ལ་མངའ་བརྙེས། སེམས་ཅན་རྣམས་ཀྱི་སྐད་དུ་ཆོས་སྟོན་ཅིང་ཆོས་སྤྱི་དང་རང་གི་མཚན་ཉིད་ལ་ཐོགས་པ་མེད།
ལྟེ་བར་ཡི་གེའི་ཕྱི་མོ་བརྒྱད། ཨཱ་ལི་ཀཱ་ལི་མཐོང་ནས། མདོ་སྡེའི་ཆོས་གསུང་རབ་ཡན་ལག་བཅུ་གཉིས་ལ་ཐོགས་པ་མེད།
བདུད་རྩི་ལྔ་དང་རོ་དྲུག་ལ་ལོངས་སྤྱོད་ནུས། ཚངས་པའི་དབྱངས་སུ་གྱུར་པ་རྣམས་ཨ་ནི་ཡིག་འབྲུ་ཅེས་པ་དྲུག་གིས་གསལ་ལོ། །
ས་བདུན་ཡན་ཆད་ལོངས་སྐུའི་ཞིང་ཁམས་འཁོར་བཞིའི་བརྒྱ་དུང་ཕྱུར་ལ་སོགས་བསྒུལ་བ་ལ་སོགས་པ་ནུས།
ནང་རྟགས་རླུང་སོར་བཅུ་འགགས། ཕྱི་རྟགས་མགྲིན་སྨིན་ཐིག་ལེས་བརྟན། སྒོམ་ལམ་ས་བཅུའོ། །
```

又从报身［修］四灌顶各四次，从自加持次第之道，使报身自然任运成就；清净语，秘密灌顶达到究竟。真性的征相：对五根与五种精华之风得到自在；对五种力用与诸种观视，没有障碍；在婆伽坛城中见到六道的种子，对六种子得到自在；以众生的语言说法，对法的共相与自相没有障碍。在脐间见到八个字母之母、元音与辅音，所以对经部之法、十二分教没有障碍；能受用五甘露与六味；成为梵音的［功德］，以名为"阿"字等的六［字］而明显。从第七地以上，能震动四眷属的百亿等报身刹土。内相：风止息十指；外相：明点稳固于喉间与眉间——［这是］修道的第十地。

【按】"自加持次第"（bdag byin gyis brlab pa'i rim pa），是《密集》圣者流五次第中的"幻身"次第，在这里配合报身与秘密灌顶。"婆伽坛城"（bhaga'i dkyil 'khor）等，是第三灌顶中的象征用语，这里不作解说。"八个字母之母"（yi ge'i phyi mo brgyad），即梵文字母的八组。"四眷属的百亿"，藏文作"འཁོར་བཞིའི་བརྒྱ་དུང་ཕྱུར"，存疑。

## 十六、法身、智慧灌顶——十二地（第 87–95 段前半）

```
ཡང་དབང་བཞི་བཞི། སེམས་དག་ལ་དཀྱིལ་འཁོར་འཁོར་ལོ་ཐབས་ཀྱི་ལམ་ནས་ཆོས་སྐུ་རང་བཞིན་གྱི་ལྷུན་གྲུབ་ཐོབ་པར་བྱེད་པ།
ཤེས་རབ་དང་ཡེ་ཤེས་ཀྱི་དབང་མཐར་ཕྱིན། དེ་ཁོ་ན་ཉིད་ཀྱི་རྟགས། སྟོབས་ལྔ་ནི།
བྱང་ཆུབ་ཀྱི་སེམས་ཀྱི་རླུང་ལྔ་བསྐྱོད་པའི་དངས་མའི་དངས་མ། རྩ་བ་བྱང་ཆུབ་སེམས་ཀྱི་དཀྱིལ་འཁོར་མཐོང་ནས་རྟགས་བསྟན་པ།
སྐུ་གསུམ་ཡེ་ཤེས་ལྔ་ལ་སོགས་དབང་ཐོབ་ནས། བདུད་རྩི་ལྔ་གར་འདུ་མཐོང་ནས་སངས་རྒྱས་རྣམས་གཞན་དོན་མཛད་པ་མཐོང་།
སྤྲུལ་པ་བདེ་ཆེན་ཐིག་ལེ་འདུ་བ་མཐོང་ན། སངས་རྒྱས་རྣམས་འོག་མིན་གྱི་གནས་ན་ཟབ་མོ་ལ་བཞུགས་པ་མཐོང་།
ལྟེ་བ་སྤྲུལ་པར་བདུད་རྩི་ལྔ་དང་རླུང་ལྔ་འདུས་པ་མཐོང་ན། ལོངས་སྐུའི་རིགས་ལྔ་ཡུམ་གྱི་བྷ་ག་ན་བཞུགས་ནས་སྐལ་ལྡན་བྱང་ཆུབ་སེམས་དཔའ་ལ་གསང་བ་སྒྲོགས་པ་མཐོང་།
ཕྱག་རྒྱ་མའི་དངས་མའི་དངས་མ་མཐོང་ན་མངོན་ཤེས་ལ་ཐོགས་པ་མེད། རྩ་ཡིག་རྣམས་སུ་དངས་མ་འདྲོངས་ན་རྫུ་འཕྲུལ་ལ་ཐོགས་པ་མེད།
དེ་ཉིད་སླར་སྤོས་ན་སྔོན་གྱི་གནས་རྗེས་སུ་དྲན། ནང་རྟགས་རླུང་སོར་བཅུ་གཉིས་འགགས།
ཕྱི་རྟགས་སྤྱི་གཙུག་ཧྲི་ལ་ཐིག་ལེས་བརྟན། ས་བཅུ་གཉིས་སོ། ། ཡང་དབང་བཞི་བཞི་མཐར་ཕྱིན་གྱི་ལམ་ནས་མཐར་ཐུག་རྟེན་འབྲེལ་མཐར་ཐུག་འདའ་བ།
```

又［修］四灌顶各四次，清净心，从坛城轮的方便之道，使法身自然任运成就；智慧智灌顶达到究竟。真性的征相——五力是：使菩提心的五风运动的精华之精华，见到根本菩提心的坛城而显示征相；得到三身、五智等的灌顶之后，见到五甘露聚于何处，就见到诸佛利益他人；见到化现的大乐明点聚集，就见到诸佛住于色究竟天的甚深［境界］中；见到在脐间化现中五甘露与五风聚集，就见到报身五部住于佛母的婆伽中，对有缘的菩萨宣说秘密；见到手印母的精华之精华，神通就没有障碍；使精华进入诸脉字中，神变就没有障碍；把它再转移，就能随念前世。内相：风止息十二指；外相：明点稳固于顶上"诃罗"［处］——［这是］第十二地。

【按】"坛城轮的方便之道"（dkyil 'khor 'khor lo thabs kyi lam），是道果中第三灌顶的道，以业手印为方便，这里只照原文译出，不作解说。"手印母的精华之精华""佛母的婆伽"等，都是第三灌顶中有特定内涵的象征用语，只能依具德上师的灌顶与口授领受。"诃罗"（hri la），是顶上某一部位的名称，存疑。

## 十七、自性身、第四灌顶——十二地半（第 95 段后半–103 段前半）

```
རྡོ་རྗེའི་དབའ་རླབས་ཀྱི་ལམ་གྱིས་ཕྱག་རྒྱ་ཆེན་པོ་མཆོག་གི་དངོས་གྲུབ་རིག་མའི་སྐྱེས་བུ།
སྲིད་པ་རྣམ་པར་དག་པའི་ལམ། ། ངོ་བོ་ཉིད་ཀྱི་སྐུ་རང་བཞིན་གྱི་ལྷུན་གྲུབ་ཐོབ་པར་བྱེད་པ།
བཞི་པ་ལུས་ངག་ཡིད་ཀྱི་དབང་མཐར་ཕྱིན། དེ་ཁོ་ན་ཉིད་ཀྱི་རྟགས་འཕགས་པའི་ལམ་ཡན་ལག་བརྒྱད་ནི།
རྣམ་ཤེས་བརྒྱད་འདག་ཀར་འབྲས་བུ་གཉིས་ཐོབ་སྟེ། ས་ཆེན་དགའ་ཞིང་རངས་ལ་མགུ། །
དེ་རྣམ་པ་དྲུག་ཏུ་གཡོ། ། བདུད་གནས་སུ་སྒྲ་གྲག ། ཕྱག་རྒྱ་མའི་གནས་སུ་ཁམས་གསུམ་མཐོང་།
མཁའ་འགྲོ་མ་རྣམས་རིང་ནས་འདུ། ། ཧ་རི་མ་ལ་སོགས་པ་དབང་ཕྱུག་གི་དོན་བརྒྱད་འཆར།
ནང་རྟགས་སྲོག་རྩོལ་ཨ་ཝ་དྷཱུ་ཏཱིར་འཇུག ། ཕྱི་རྟགས་གཙུག་ཏོར་ཕྱེད་ཐིག་ལེས་བརྟན།
```

又从究竟之道［修］四灌顶各四次，超越究竟的缘起，以金刚波浪之道，［成为］大手印殊胜悉地的持明者，［这是］清净三有之道，使自性身自然任运成就；第四身语意灌顶达到究竟。真性的征相——八支圣道是：八识一清净，就得到二果。大地欢喜、愉悦、满足，它以六种方式震动；在魔的处所发出声音；在手印母的处所见到三界；诸空行母从远方聚集；"诃利摩"等八种自在之义显现。内相：命勤（命气）进入中脉；外相：明点稳固于顶髻的一半——［这是］第十二地半。

【按】"金刚波浪之道"（rdo rje'i dba' rlabs kyi lam），是道果中第四灌顶的道，存疑。"持明者"（rig ma'i skyes bu），字面是"明妃之士"，存疑。"八种自在之义"（dbang phyug gi don brgyad），指八种自在功德（如微细、轻盈等），"诃利摩"（ha ri ma）可能是其中一种的名称，存疑。"命勤"（srog rtsol，梵 prāṇāyāma），这里指命气。"中脉"，藏文作"ཨ་ཝ་དྷཱུ་ཏཱི"（avadhūtī）。

## 十八、第十三地：金刚持地（第 103 段后半–111 段）

```
ས་ཕྱེད་དང་བཅུ་གསུམ་མོ། ། བཞི་པ་ཡིད་ཀྱི་དབང་མཐར་ཕྱིན། དེ་ཁོ་ན་ཉིད་ཀྱི་རྟགས་འབྲས་བུའི་ཕྱོགས་གཅིག་འཐོབ་སྟེ།
འབིགས་བྱེད་གཞོན་ནུའི་གྲོང་ཁྱེར་ཆོས་ཀྱི་དབྱིངས། ། བྱང་ཆུབ་སེམས་ཀྱིས་ནི་འབིགས།
འབྲས་བུ་ལོངས་སྐུའི་ཞིང་ཁམས་རབ་བཀྲམ་ལ་སོགས་པ་བསྒུལ་བ་ལ་སོགས་པ་ནུས།
ས་བཅུ་གསུམ་ཐོབ་ཀར་ས་བཅུ་མ་ལ་སོགས་པ་ཡིད་ཀྱིས་བཀུག་སྟེ། སློབ་དཔོན་དུས་གསུམ་བདེ་གཤེགས་བཅུད་འདུས་ཡིན།
ཡི་དམ་ལྷ་དང་བླ་མ་དབྱེར་མེད་ལ། ། བྷ་གར་དངོས་གྲུབ་ལེན་པའི་རྟེན་འབྲེལ་གྱིས། །
སྲིད་པ་རྣམ་པར་དག་པའི་ལམ། ། ངོ་བོ་ཉིད་ཀྱི་སྐུ་ཤིན་ཏུ་རྣམ་པར་དག་པ་རང་བཞིན་གྱི་ལྷུན་གྲུབ་ཐོབ་པར་བྱེད་པ།
འབྲས་བུ་མཐར་ཕྱིན་དེ་ཁོ་ན་ཉིད་ཀྱི་རྟགས་ལོངས་སྐུའི་ཞིང་ཁམས་མ་ལུས་པ་ལ་སོགས་པ་བསྒུལ་བ་ལ་སོགས་པ་ནུས།
ནང་རྟགས་སྲོག་རྩོལ་ཨ་ཝ་དྷཱུ་ཏཱིའི་འགགས། ཕྱི་རྟགས་གཙུག་ཏོར་ཧྲི་ལ་ཐིག་ལེས་བརྟན།
ཕྱི་ནང་གི་རྟེན་འབྲེལ་འགྲོས་བཞི་ཐིམ་པ་རྣམས་ཀྱིས་སྒོམ་ཉམས་ཀྱིས་སྐྱོན་ཡོད་མེད་ཕྱེད་པས་བཅུ་གསུམ་པའོ། །

第四意灌顶达到究竟。真性的征相：得到果的一分，即［以］菩提心穿透能穿透的少年之城——法界。果：能震动"遍布"等报身刹土等。一得到第十三地，就以意召来十地女等；阿阇黎就是三世善逝的精华所集；本尊与上师无别；以在婆伽中取悉地的缘起，［是］清净三有之道，使极为清净的自性身自然任运成就；果达到究竟。真性的征相：能震动所有的报身刹土等。内相：命勤在中脉中止息；外相：明点稳固于顶髻"诃罗"［处］。以外内缘起四种运行的融入，分辨禅修觉受中有无过失，所以是第十三地。

【按】"少年之城"（gzhon nu'i grong khyer），比喻法界，存疑。"以意召来十地女"（sa bcu ma），是第十三地的象征说法，存疑。"阿阇黎就是三世善逝的精华所集，本尊与上师无别"，是道果"上师瑜伽"的要点。"以在婆伽中取悉地的缘起"等，都是第三、第四灌顶中有特定内涵的象征用语，只能依具德上师的灌顶与口授领受，这里不作任何解说。

## 十九、成佛（第 112–113 段前半）

```
ཐམས་ཅད་མཁྱེན་ཏེ། བཅུ་གསུམ་རྡོ་རྗེ་འཛིན་སར་རྟེན་འབྲེལ་འགྲིག་པ་ལྟར་སྣང་།
```

［成为］一切智；在第十三地金刚持地，如缘起的协调一致那样显现；一成佛，就与一群眷属一起成佛。

【按】"与一群眷属一起成佛"（'khor tshom bu cig dang bcas te 'tshang rgya），是道果的一个特别说法：上师成佛时，其眷属弟子也一同成佛，存疑。

## 二十、结颂与跋（第 113 段后半–115 段）

```
འཚང་རྒྱ་ཀར་འཁོར་ཚོམ་བུ་ཅིག་དང་བཅས་ཏེ་འཚང་རྒྱའོ། ། གསང་སྔགས་རྡོ་རྗེའི་ཐེག་པ་ནི། །
རྒྱུ་དང་ལམ་དང་འབྲས་བུའི་དབང་། ། རྟོགས་པས་བརྟགས་པས་རྟོག་མེད་རྟོགས། །
ཡེ་ཤེས་སྣང་བ་དེ་བཞིན་ནོ། ། ལམ་ཟབ་བླ་མ་དམ་ཚིག་ལུས་སོ་སོར་བརྟགས་པའི་འགོག་པ་ལམ་འབྲས་བུ་དང་བཅས་པའི་གདམས་ངག་དང་མན་ངག་དུ་བཅས་པ་རྫོགས་སོ།།
```

密咒金刚乘，是因、道、果的灌顶；以证悟、以观察，证悟无分别；智慧的显现也是如此。

《深道上师三昧耶身各别观察之灭——道及其果的教授与口诀》，圆满。

【按】跋语中的题名"深道上师三昧耶身各别观察之灭"（lam zab bla ma dam tshig lus so sor brtags pa'i 'gog pa），文字很难理解，可能是几个名目的并列，存疑；后半"道及其果的教授与口诀"（lam 'bras bu dang bcas pa'i gdams ngag dang man ngag），就是萨迦派对《道果金刚句》的通称"道及其果"（lam 'bras bu dang bcas pa）。本篇没有作者与译者的署名，见题解。
