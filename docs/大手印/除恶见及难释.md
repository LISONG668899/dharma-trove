# 《除恶见》及《难释》

<p lang="bo">ལྟ་བ་ངན་པ་སེལ་བ། ལྟ་བ་ངན་པ་སེལ་བའི་དཀའ་འགྲེལ།</p>

阿瓦都帝·无二金刚（梅纪巴）造　据藏文译出

## 题解

《除恶见》（Kudṛṣṭinirghātana）收于德格版丹珠尔续部释 ཝི 函第 104b 至 110a 页（东北目录 D2229），《除恶见难释》（Kudṛṣṭinirghāta-ṭīkā）紧接其后，在第 110a 至 111a 页（D2231）。两部都署名阿瓦都帝·无二金刚，也就是梅纪巴；《除恶见》由印度上师金刚手与藏地译师粗敦·智慧源译出，《难释》也是金刚手与粗敦所译。两部都属于梅纪巴的"无念法类"。

《除恶见》书名叫"除恶见"，内容却主要是一部"初业仪轨"（ādikarma-vidhi），也就是在家菩萨一日之中的修持：清晨受八关斋戒，供养财神，为饿鬼施食，以牛粪作五佛曼扎而供养，诵经，作擦擦与泥塔，回向，饭前施食，饭后与善知识共处，傍晚持诵，以瑜伽睡眠入睡。它所要破除的"恶见"，是认为修无分别、行疯人禁行的瑜伽士便不需要这些初业善行的看法。梅纪巴的回答是：初业的种种善行就是六波罗蜜多，不离般若，所以不会成为束缚；诸佛在果位上也是无勤作地显现初业之行。这对理解梅纪巴的大手印并不离开显教善行，很有意义。

《难释》篇幅很短，主要解释《除恶见》开头的"有学""无学"、因位的三种分位与五种自在等名目。

## 题名与造论偈

梵语题名：Kudṛṣṭinirghātana-nāma。藏语题名：名为《除恶见》。

敬礼文殊童子！敬礼佛陀！

谁若安住于此，便能获得胜者的果位——那初业者的仪轨本身，我要宣说《除恶见》。

## 一、有学与无学：初业仪轨的地位

这里，众生有两种：有学与无学。

其中，从以增上意乐而胜解的加行、入地的加行，直到究竟获得五种自在为止，安住于因位的有学者们，以极为清净的初业仪轨积集二资粮，便能真实获得圆满正等菩提。

无学者，对真如与果的分别，已由对治品所清除；他们如同释迦牟尼那样，以往昔愿力之势的能力，在双运之中无勤作地利益众生，［这一事业的］体相相续不断——这也安立为"趣入初业"。

这就像所说的：

"怙主，您没有心意，也没有分别的动摇，然而您自然而然地在世间行诸佛事业。圆满利他，是佛的主要之果，没有别的；所以说佛是果。一切妄分别的狂风，都不能动摇［您］，就像如意树；这样圆满一切众生的一切意愿。那果本身，远离对违品的取与舍；具智者证悟圆满菩提，难道是凭初业者的勤作吗？"

【按】"有学""无学"，原文 slob pa、mi slob pa，这里指尚在修学的菩萨与已成佛者。"五种自在"，下文《难释》列为对烦恼、受生、业、方便、成熟众生的自在。末句原文 dang po las pa 'bad pas sam，是反问句式，意思是佛果的无勤作利他，并不是初业者那样勤作而来的，但句意不很确定，存疑。

## 二、诘难：修无学者何须初业

如果有人说："初业者固然适合有学的仪轨，可是对于修习无学、无自性的人来说，怎么还会有初业的造作呢？譬如这也就像被金链束缚一样。"

［答：］说得是；［但它并不束缚，］因为它不离证悟般若波罗蜜多。［初业仪轨］是五波罗蜜多的自性。所以，所开示的，是具一切殊胜相的空性。

这就像世尊所说："离开了般若波罗蜜多的五波罗蜜多，得不到'波罗蜜多'之名。"《圣维摩诘所说大乘经》中也说："离开智慧的方便是束缚，离开方便的智慧也是束缚；具有智慧的方便是解脱，具有方便的智慧也是解脱。"

这些要从它的本身——殊胜上师的口诀中去证悟，就像灯与光那样，是俱生成立的。

所以说：

"空性与悲心无别，这就是所许的佛智；一切瑜伽士所应作的，就是所开示的初业者［之行］。五波罗蜜多中所开示的，称为初业者；［它］不应离开般若波罗蜜多的体性去观察。"

同样，又说：

"对布施、持戒、安忍、精进、禅定、般若恭敬，具智者常常依止，智慧便会安乐地生起。报身与化身，［是］布施、持戒、安忍三者［所成］；禅定、般若，［是］法［身］的；精进，则许为二者共有。"

因为这样开示，所以初业的菩萨，应当以极为清净［的行持］安住。否则，便会落入说"无"［的断见］。

又说：

"善与不善，虽然都没有实体，但仍应当行善，而不是不善；世间世俗虽然如水中之月，从那里［仍会生起］可意、痛苦与不悦。"

【按】"金链"之喻，是说即使是善业的仪轨，执著它也仍是束缚，就像金链与铁链同样能束缚人。"不应离开般若波罗蜜多的体性去观察"，原文 shes rab pha rol phyin pa yi ngo bo nyid ni dpyad mi bya，句意不很确定，今依上下文翻译。

## 三、疯人禁行与初业

如果有人问："既然这样，有学者安住于疯人的禁行，想要体验无分别，又怎么会趣入初业呢？"

［答：］那是具有舍身布施的行持，也就是"把身体施舍出去之后，再开始行持"的意思：舍身的布施；以身、语、意利益一切众生的持戒；忍受寒、热、锯割的安忍；面对世间八法的伤害而平等的精进；随顺一切事物、无勤作、自然而生的禅定；对一切法无所缘、随观察之相的般若——这是以无勤作的同一味，在一切处都许为同一味，是一切波罗蜜多之最上。

所以，安住于疯人的禁行，也就是趣入初业。并不像有人所说的那样：［这种禁行］在现世毁坏名声，在来世欺误［自己］，在一切方面都不合理。

【按】"疯人的禁行"，原文 smyon pa'i brtul zhugs，是密乘瑜伽士在证悟后所行、不顾世俗规范的禁行。作者的意思是：真正的疯人禁行，本身就是六波罗蜜多的圆满，所以与初业仪轨并不相违。

## 四、授布萨与学处

对此，对持禁行的弟子菩萨，《喜金刚》中说："首先授予布萨，然后授予学处。"

首先授予布萨，就是：

"尊者或阿阇黎请垂念！我名叫某某的优婆塞，从现在起，直到菩提心要，皈依佛、法、僧。"

这样说两遍、三遍。

"请尊者摄受我为皈依三宝者。阿阇黎请垂念！我名叫某某的优婆塞，从此时起，直到明日太阳未升起之前，远离杀生、偷盗他人财物、非梵行、妄语，同样远离饮令人醉的饮料、非时食、花鬘、涂饰、歌舞、嬉戏、床座与高广大床。我要以八支功德，如阿罗汉那样安住。"

这是授予布萨的词句。

在家菩萨皈依三宝，［终身］远离杀生、不与取、欲邪行、妄语，以及本身有过失、令人醉的饮料——酒，这五种。具有胜解与行持的在家菩萨，应当完全了知十不善，完全约束而不再作，并且要作诸善业。

【按】"布萨"，原文 gso sbyong（upoṣadha），这里指在家人一日一夜受持的八关斋戒。"阿罗汉那样安住"，是八关斋戒传统的说法：受戒者一日一夜效法阿罗汉而住。

## 五、晨起的修持与施食

在黎明时分起身，洗脸等之后，随念三宝，以"嗡 阿 吽"守护自己、处所与瑜伽，然后依照仪轨，作禅定、持诵、赞颂等。《文殊真实名经》也要诵三遍。

之后，诵

```
ཨོཾ་ཛམྦྷ་ལ་ཛ་ལེནྡྲ་ཡེ་སྭཱ་ཧཱ།
```

一百零八遍，以一百零八掬水供养吉祥财神。

然后，诵

```
ན་མཿས་མནྟ་བུདྡྷཱ་ནཱཾ་སརྦ་ཏ་ཐཱ་ག་ཏ་ཨ་བ་ལོ་ཀི་ཏེ། ཨོཾ་སམྦྷ་ར་སམྦྷ་ར་ཧཱུཾ་ཕཊ་སྭཱ་ཧཱ།
```

这一施食咒七遍。伸直右手五指，观想以五甘露［加持］放在门边的施食连同水，即使一粒饭，也变成摩揭陀国的一大斗；弹指三次，施予一切饿鬼众。

【按】"吉祥财神"，原文 dpal gnod gnas，依咒文是黄财神赞巴拉（Jambhala）。"《文殊真实名经》"，原文 mtshan yang dag par brjod pa（Mañjuśrī-nāma-saṃgīti）。"弹指"，原文 se gol。咒语照录藏文原文，不作翻译，下同。

## 六、四无量心与五佛曼扎

现在，修习四无量心：把一切众生看作独子一样的慈；想把他们从痛苦及痛苦之因——轮回大海中救出来的悲；因皈依三宝而生起欢欣的意乐之喜；舍弃对不真实之物的贪著的舍。

然后，以乐于利益一切众生的心，取干净的牛粪，与净水混合，以

```
ཨོཾ་བཛྲ་རེ་ཁེ་ཧཱུཾ
```

加持坛场，作方形等任何所欲的曼扎。

在它上面，观想八瓣杂色莲花的中央，月轮与日轮之上，从蓝色吽字圆满生起的不动佛，结触地印，身蓝色。

然后，在东方的花瓣上，观想从白色嗡字圆满生起的毗卢遮那，结最上菩提印。然后，在南方的花瓣上，观想从黄色 traṃ 字生起的宝生，身黄色，结施愿印。然后，在西方的花瓣上，观想从红色 hrīḥ 字生起的阿弥陀，结禅定印，身红色。然后，在北方的花瓣上，观想从绿色 khaṃ 字生起的不空成就，身绿色，结无畏印。

以

```
ཨོཾ་བཛྲ་པུཥྤེ་ཧཱུཾ
```

等现前执持的咒语，供养一切所欲之中最上的［供品］。

这五如来，都身披袈裟，具有顶髻，有日轮［为座］；唯有毗卢遮那在月轮上。其中四尊面向不动佛，不动佛面向修行者。

在他们面前，使所证悟的义理如实现前，诵皈依三宝的偈颂。皈依三宝的偈颂是：

"敬礼佛之主，敬礼救护之法，敬礼大僧伽，常敬礼三宝。皈依三宝，一一忏悔一切罪，随喜众生之善，以意受持佛菩提。直至菩提，我皈依佛、法与众中尊；为成办自他之利，我发殊胜菩提心；把这一切众生请为宾客，我要行殊胜悦意的菩提行；为利众生，愿成佛道！忏悔一切罪，随喜一切福德；圣八支布萨，应当持斋行持。"

然后说：

"以戒律旃檀涂身，以禅定之衣覆盖，以菩提分之花庄严，如其所乐而安住。"

说完之后，以

```
ཨོཾ་བཛྲ་མཎྜལ་ཧཱུཾ་མུཿ
```

请［诸佛］回去。同样，文殊等也要依照口诀供养。

——以上是曼扎的仪轨。

【按】"曼扎"，原文 dkyil 'khor（maṇḍala），这里指以牛粪与水涂成的供坛。印度习俗以牛粪为清净之物，涂地为坛。

## 七、曼扎的利益

"［以］牛粪与水，是布施；好好涂抹，是持戒；安忍，是除去细小的生物；精进，是投入作为；禅定，是那时一心专注之心；般若，是把资粮等好好庄严。愿以作能仁们的曼扎，由此获得六波罗蜜多！从一切病中解脱，成为金色；在天与人中，像月亮一样光彩；生于富有财宝黄金的王族；以身作善逝的殊胜处所。"

这是曼扎利益的偈颂。

"以牛粪、水与花，常作曼扎之后，献上少许，在三时恭敬礼拜上师；使他人心中欢喜，也使自己的心增长；安乐而具有无量财富，生于极乐；六波罗蜜多圆满，被佛等所加持；作曼扎的人，圆满无量功德。"

诸如此类，广说利益。

## 八、诵经与供养经像

"以曼扎等仪轨，常常供养、诵读真实般若波罗蜜多，也要证悟它的义理。一偈、四偈、二偈［的般若］，以及六门陀罗尼、《贤行［愿］》，以及《三聚经》，在三时，从一字［般若］起，到三［者］为止，入定［诵读］；不失坏本尊［誓言］，具智者随所得而诵读。"

佛与菩萨的画像、经卷、铸像等，都要供养。

——以上是供养画像、经卷、佛像等的仪轨。

【按】"一偈、四偈、二偈"，大概是指几种极简的般若经（如《一偈般若》等），原文没有具名。"《贤行［愿］》"，原文 bzang po spyod pa，即《普贤行愿品》。"《三聚经》"，原文 phung po gsum pa（Triskandhaka），即忏悔、随喜、回向三聚的忏悔经。"从一字［般若］起，到三［者］为止"，原文 yi ge gcig nas nyer bzung nas gsum gyi bar du，句意不很确定，存疑。

## 九、作擦擦的仪轨

现在，随顺大曼扎的安布，宣说作擦擦的仪轨：

```
ན་མ་སྶ་མནྟ་བུདྡྷཱ་ནཱཾ། ཨོཾ་བཛྲ་ཨཱ་ཡུ་ཥེ་སྭཱ་ཧཱ།
```

这是取泥的咒。

```
ཨོཾ་བཛྲོད་བྷ་བཱ་ཡ་སྭཱ་ཧཱ།
```

这是揉泥的咒。

```
ཨོཾ་ཨ་ར་ཛེ་བི་ར་ཛེ་སྭཱ་ཧཱ།
```

这是涂油的咒。

```
ཨོཾ་དྷརྨ་དྷཱ་ཏུ་གརྦེ་སྭཱ་ཧཱ།
```

这是放入模中的咒。

```
ཨོཾ་བཛྲ་མུངྒ་ར་ཨཱ་ཀོ་ཊ་ཡ་སྭཱ་ཧཱ།
```

这是压印的咒。

```
ཨོཾ་དྷརྨ་ཨཱ་ཡུ་ཥེ་སྭཱ་ཧཱ།
```

这是迎请的咒。

```
ཨོཾ་སུ་པྲ་ཏིཥྛ་བཛྲཱ་ཡ་སྭཱ་ཧཱ།
```

这是请安住的咒。

```
ཨོཾ་སརྦ་ཏ་ཐཱ་ག་ཏ་མ་ཎི་ཤ་ཏ་དཱི་པ་ཏེ་ཛྭ་ལ་ཛྭ་ལ་དྷརྨ་དྷཱ་ཏུ་གརྦྷེ་སྭཱ་ཧཱ།
```

这是开光的咒。

```
ཨོཾ་སྭ་བྷཱ་བ་བི་ཤུདྡྷེ་ཨ་ཧ་ར་ཨ་ཧ་ར་ཨཱ་གཙྪ་ཨཱ་གཙྪ་དྷརྨ་དྷཱ་ཏུ་གརྦྷེ་སྭཱ་ཧཱ།
```

这是请回的咒。

```
ཨོཾ་ཨཱ་ཀཱ་ཤ་དྷརྨ་དྷཱ་ཏུ་གརྦྷེ་སྭཱ་ཧཱ།
```

这是请恕的咒。

这样，就是作擦擦的仪轨。

【按】"擦擦"，原文 tsha tsha，是用模子压制的小泥塔或泥佛像。"开光"，原文 rab tu gnas pa（pratiṣṭhā），即安住加持。

## 十、以泥沙作塔的仪轨

```
ན་མོ་བྷ་ག་བ་ཏེ་བཻ་རོ་ཙ་ན། པྲ་བྷ་རཱ་ཛཱ་ཡ། ཏ་ཐཱ་ག་ཏཱ་ཡ། ཨཪྷ་ཏེ་སམྱཀྶཾ་བུདྡྷཱ་ཡ། ཏདྱ་ཐཱ། ཨོཾ་སུ་ཀྵྨེ་སུ་ཀྵྨེ། ས་མ་ཡེ་པྲ་ས་མ་ཡེ། ཤཱནྟེ་དཱནྟེ། ས་མ་རོ་པེ། ཨ་ན་ལམྦྷེ། ཏ་རམྦྷེ་ཡ་ཤོ་བ་ཏི་མ་ཧཱ་ཏེ་ཛ་ནི་རྐུ་ལེ། ནིརྦཱ་ན། སརྦ་བུདྡྷཱ་དྷིཥྛཱ་ན་ཨ་དྷིཥྛི་ཏེ་སྭཱ་ཧཱ།
```

对着泥或沙，把这一陀罗尼诵二十一遍，然后作塔；那么，塔中有多少极微尘，便得到那么多恒河沙数倍的造塔福德；会成为十地的自在者；会迅速成就无上正等圆满菩提——这是世尊毗卢遮那所说的。这一陀罗尼的利益不可计量。

以

```
ཡེ་དྷརྨཱ་ཧེ་ཏུ་པྲ་བྷ་བཱ་ཧེ་ཏུནྟེ་ཥཱནྟ་ཐཱ་ག་ཏོ་ཧྱ་བ་དཏ། ཏེ་ཥཱཉྩ་ཡོ་ནི་རོ་དྷ་ཨེ་བཾ་བཱ་དཱི་མ་ཧཱ་ཤྲ་མ་ཎཿ
```

这一偈颂开光。然后，诵

```
ན་མོ་བྷ་ག་བ་ཏེ་རཏྣ་ཀེ་ཏུ་རཱ་ཛཱ་ཡ། ཏ་ཐཱ་ག་ཏ་ཡཱཪྷ་ཏེ་སམྱཀྶཾ་བུདྡྷཱ་ཡ། ཏདྱ་ཐཱ། ཨོཾ་རཏྣེ་རཏྣེ་མ་ཧཱ་རཏྣེ་རཏྣ་བོ་དྷི་སྭཱ་ཧཱ།
```

等陀罗尼，并礼拜佛塔等；礼拜一座塔，便等于礼拜了一千万座塔等。

——以上是以泥等作塔的仪轨。

【按】"恒河沙数倍"，原文作 bye ma snyed kyi 'gyur，字面是"沙数之倍"，今依通行说法译作"恒河沙数倍"，存疑。"ye dharmā"一偈，即缘起偈："诸法从缘起，如来说其因；彼法因缘尽，是大沙门说。"

## 十一、随喜与回向

这一切，由殊胜的回向，便能生起殊胜之果。所以，要以《般若波罗蜜多经》中所说的大回向来回向。也就是这样说：

"就像如来、应供、正等觉们，以佛的智慧与佛眼所了知、所见到的这一善根——它是什么种类、什么部类、什么体相、什么自性、以什么法性而真实安住——他们怎样了知，我也同样随喜。就像他们把善根回向无上正等菩提那样，我也同样回向。"

又说：

"以我所作的这一善业，愿不久在世间成佛，为利众生而说法，解脱被众多痛苦所逼的众生！"

——以上是随喜福德与回向的仪轨。

## 十二、饮食的仪轨

"无论以什么、靠什么维生，清净的生活就是胜者；为了平息饥渴等，要把［食物］想作药。"

说了这些之后，对所得到的食物，以

```
ཨོཾ་ཨ་ཀཱ་རོ་མུ་ཁཾ་སརྦ་དྷརྨཱ་ཎཱཾ་ཨཱདྱ་ནུཏྤན་ན་ཏྭཱ་ཏ། ཨོཾ་ཨཱཿཧཱུཾ་ཕཊ་སྭཱ་ཧཱ།
```

施予食子。然后，以

```
ཨོཾ་ཨཱཿསརྦ་བུདྡྷ་བོ་དྷི་སཏྭ་བྷྱོ་བཛྲ་ནཻ་བི་དྱཻ་ཧཱུཾ
```

供养净食。诵

```
ཨོཾ་ཧ་རི་ཏི་མ་ཧཱ་ཡཀྵི་ནི་ཧ་ར་ཧ་ར་སརྦ་པཱ་པཾ་ན་ཀྵ་ན་སྭཱ་ཧཱ།
```

施予两团食。以

```
ཨོཾ་ཨ་གྲ་པ་ཎི་ཊཱ་སི་བྷྱཿསྭཱ་ཧཱ།
```

施予第三团食。

然后，以"嗡 阿 吽"加持自己碗中的食物；直到毒等都平息为止，首先用拇指与无名指取食。

然后，对安乐地吃完后剩下的食物，以

```
ཨོཾ་ཨུཙྪི་ཊ་བནྡི་ཨ་སི་བྷྱཿསྭཱ་ཧཱ།
```

施予剩余之团。其余没有加持的剩食，全部丢弃。

这就像所说的："施予食子，供养净食，诃利帝与初份之团，以及第五——施予剩余，果报便成为大受用。"

【按】"诃利帝"，原文 'phrog ma，即鬼子母（Hārītī），咒中的 ha ri ti ma hā yak+Shi ṇi 即"大药叉女诃利帝"。"初份之团"，咒中的 agra piṇḍa 即"最初的一团食"。"团"，原文 chang bu，即用手捏成的食团。

## 十三、饭后与日间的行持

然后，作漱口等；心意安乐、完全清净，具有殊胜之乐，为了利益、安乐一切众生，把这一偈诵三遍：

"愿国王、施主，以及其他众生，寿命与无病都圆满，常得安乐！"

然后，以完全清净的身、语、意之业，随意安住。

然后，依止善知识，一同行持；以本生、譬喻、因缘，或证悟传记的谈话，日夜以极安适的心而住。

## 十四、傍晚与睡眠

然后，在下午的时候，也以无生之意，如前那样作持诵、赞颂等；以 a 字等施予食子，以瑜伽的睡眠而卧。

## 十五、"优婆塞"四字之义

"u：恒常趣入佛法，是近于寂静的优婆塞，近于利益众生；因为近于利益一切，所以恒常断除罪恶。［pā］：舍离与罪人相交，大丈夫断除罪恶，处处忏悔罪恶。［sa］：一切增益都解脱，在三摩地中好好平等安住，以处处最上的欢喜，智者成就圆满菩提。［ka］：在一切时中无勤作，以悲心完全守护，即使成为痛苦，也不是不愿意，而是作最上的利益。"

这是以具有［优婆塞］四个字之义的词句来亲近［善法］。

"善业已经完全作了，福德资粮已经积集；由于串习的力量，就像醒着一样，在梦中也行善。如果把一切众生看作无垢的影像，就像说一切［法空］的人那样，虽不追随、不缘取，仍照样去作；所以，［他］是不退转的。"

这样说。

这样，日夜不断地积集福德资粮，直到菩提心要为止，以利益与安乐众生而真实安住。

【按】这一段是以"优婆塞"（upāsaka，藏文 dge bsnyen）的四个音节 u、pā、sa、ka 来解释其义的字母偈：u 取 upa（近），pā 取 pāpa（罪），sa 取 samādhi（三摩地），ka 取 karuṇā（悲）。藏译只保留了开头的 u 字，其余三字在藏文中已不显，今依偈义在方括号中补出 pā、sa、ka 三字，以便读者理解。"就像说一切［法空］的人那样"，原文 thams cad smra ba'i skyes bu ltar，所指不很确定，也可能指说一切有部，存疑。

## 结尾偈

"名为'虚空藏'的人，最倾心于中观之义，安住于初业，把它作为本尊之行；他从金刚座而来，是婆罗门种姓，心意寂静。应虚空藏的请求，我开示了初业仪轨的少许词句；愿以此，串习菩提，迅速除去烦恼罪恶心智之垢的翳障！愿以这初业仪轨，我所得到的福德，使那些初业者与众生获得无二！"

## 跋

大学者阿阇黎、阿瓦都帝·无二金刚所造的《除恶见》，圆满。

印度堪布上师金刚手，与藏地译师粗敦·智慧源译。

【按】"阿瓦都帝"，原文 nges par sbyangs pa，是梵语 avadhūta（善修、头陀）的藏译，梅纪巴又称阿瓦都帝巴（Avadhūtipa）。"金刚手"，即梅纪巴的弟子、曾参与译出王后道歌的印度上师。"粗敦·智慧源"，原文 mtshur ston ye shes 'byung gnas（Jñānākara）。结尾偈说本论是应"虚空藏"（nam mkha'i snying po）的请求而作，他从金刚座而来，是婆罗门出身。

## 附：《除恶见难释》

梵语题名：Kudṛṣṭinirghāta-ṭīkā。藏语题名：《除恶见难释》。

敬礼持金刚！

### 一、三种位

这里，位有三种：因位、果位，以及利益众生位。其中，有学是因位；果位与利益众生位，是如来。

其中，所谓"因位"，是从发殊胜菩提心起，直到安住菩提心要为止。所谓"果位"，是生起真实圆满菩提的智慧、断除一切烦恼、获得功德之位。所谓"利益众生位"，是从最初转法轮起，直到教法未灭为止。

### 二、因位的三种分位

因位又有三种：意乐位、加行位、自在位。

其中，意乐位，是令一切众生决定解脱的愿。它的四种近难是：观察除去他人的痛苦、观察所需、观察助伴、观察受用。

其中，作为方便而发愿菩提，随之寻求的四种是：种姓、殊胜善知识、悲心，以及不顾痛苦的安忍。"从四种四缘中，生起菩提心"——以这十句来开示。这就是增上意乐位。

以增上胜解的加行，［有］加行道的十波罗蜜多，以及得地的七波罗蜜多。

其中，增上胜解的十波罗蜜多是：布施、持戒、安忍、精进、禅定、般若、方便、愿、力、智。这些就是十波罗蜜多。

得地的四种圆满是：意乐、加行、摄受、布施圆满；［得地的七波罗蜜多是：］布施、持戒、安忍、精进、禅定、般若、方便。这些就是七波罗蜜多。

以增上胜解的加行，诸波罗蜜多便有差别。这两种就是加行位。

五种自在是：对烦恼、受生、业、方便、成熟众生的自在。

【按】"四种近难"，原文 nye ba'i dka' ba bzhi，所指不很明确，今照字面翻译。"以这十句来开示"，原文 tshig bcu po，依上文似指"四种观察""四种寻求"等句，但数目不完全相合，存疑。

### 三、初业的意义

住于因位的初业者，要作一切［初业仪轨］。住于果位与利益众生位的［诸佛］，则如同释迦牟尼那样，无勤作地真正趣入初业。

由这些，应当广知《除恶见》。

### 跋

《除恶见难释》，吉祥阿瓦都帝·无二［金刚］所造，圆满。

金刚手与粗［敦］译。

【按】《难释》篇幅很短，主要解释《除恶见》开头所说的"有学""无学"、"因位"与"五种自在"等名目，并结论说：初业仪轨是因位菩萨所应作，诸佛则无勤作地显现初业之行。
