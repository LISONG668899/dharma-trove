# 空性见

阿阇黎夏瓦日巴 造

## 题解

本篇出自德格版丹珠尔续部（རྒྱུད་འགྲེལ།）ཟི 函第40a叶第3行至第40b叶第1行，东北目录编号 D2426。全篇三十句，每句七或八个音节，以“舍弃吧！丢开吧！我是愚痴的啊”为叠句。篇幅很短，所以把藏文原文全部保留在代码块中，按段落分开，每段后附汉译，疑难之处另以【按】说明。

梵文题名：Śūnyatā-dṛṣṭi-nāma（ཤཱུ་ནྱ་ཏཱ་དྲྀཥྚི་ནཱ་མ）。

藏文题名：སྟོང་པ་ཉིད་ཀྱི་ལྟ་བ（空性之见）。

【按】作者夏瓦日巴（ཤ་བ་རི་པ，Śavaripa），意为“猎人”，是印度八十四大成就者之一。依藏传噶举派的传承，他是龙树、萨惹哈一系的传人，又是梅纪巴的上师，在大手印的传承中地位非常重要。本篇在诗中多次自署其名。跋语没有记载译者。

【按】本篇也是以密乘隐语写成的道歌，“拥抱无我母”“拥抱空性妃”“沉醉”“睡去”“杀象”等语，都是比喻证悟的境界与断除我执，不能照字面理解。

## 礼敬

```
སྤྱན་རས་གཟིགས་དབང་ཕྱུག་ལ་ཕྱག་འཚལ་ལོ། །
```

敬礼观世音自在！

## 正文

### 第一段：分别之端即是法性

```
སེམས་ཀྱི་རྟོག་རྩེ་ཆོས་ཉིད་ནི། །ས་བོན་ནམ་མཁའི་དབྱིངས་སུ་སྨོས། །བདག་མེད་གཞོན་ནུས་མགུལ་ནས་འཁྱུད། །
གཉིད་སད་བྱེད་པ་ཉིད་དུ་གནས། །སྤོངས་ཤིག་དོར་ཤིག་བདག་རྨོངས་སོ། །
```

心的分别念的尖端，就是法性；它的种子，说是在虚空界之中。年轻的无我母从颈项处拥抱着（我），（我）就安住在醒觉本身之中。舍弃吧！丢开吧！我是愚痴的啊。

【按】“སེམས་ཀྱི་རྟོག་རྩེ”，“心之分别的尖端”，是全篇第一个难点。“རྩེ”是“尖端”“顶点”“端头”。这一句可能的意思是：念头生起的当处、当下，就是法性，不需离开念头另找法性，这与大手印“念头当体即法身”的说法相应。另一种读法是“观察心的究竟处（顶点），就是法性”。两种读法这里都保留，正文照字面译作“尖端”。

【按】“ས་བོན་ནམ་མཁའི་དབྱིངས་སུ་སྨོས”，“种子说为在虚空界中”，“种子”可能指心或分别念的种子，意思是：追溯念头的种子，它就在（或就是）虚空般的法界中，并没有实在的根源。“སྨོས”是“说”“称说”，主语没有明说。

【按】“བདག་མེད་གཞོན་ནུ”，“年轻的无我母”，即无我母（Nairātmyā），喜金刚的明妃，是“无我”（空性）的人格化。她被称为“年轻的”，是表示空性常新、不老，并非指凡俗的人。“从颈项处拥抱”，是道歌中常见的比喻，表示行者与空性无二无别。

【按】“གཉིད་སད་བྱེད་པ་ཉིད”，“醒觉本身”，与下文“睡入虚空界中”相对：一方面是从无明之睡中醒来，另一方面是让分别念睡入（消融于）法界。

【按】叠句“སྤོངས་ཤིག་དོར་ཤིག་བདག་རྨོངས་སོ”，直译是“舍弃吧！丢开吧！我是愚痴的”，语气可以有两种理解：一是作者自谦地说“我是个愚人”（道歌中常见这种自嘲），同时劝人舍弃一切；二是把“我是愚痴的”看作要舍弃的对象，即“把‘我是愚痴的’这一念也舍弃、丢开吧”。原文没有标点可以区分，这里照字面译出。

### 第二段：拥抱空性妃，游戏大乐

```
ཀྱེ་ཧོ་བཅིངས་པ་མ་ལུས་པ། །ཤ་བ་རི་བདེ་ཆེན་པོར་རོལ། །སྟོང་པའི་བཙུན་མོ་འཁྱུད་བྱས་ཏེ། །
```

奇哉！一切束缚，毫无剩余（都已解开）；夏瓦日巴在大乐中游戏，拥抱着空性的妃子。

【按】“ཀྱེ་ཧོ་བཅིངས་པ་མ་ལུས་པ”，“奇哉！一切束缚无余”，句子没有谓语，这里依文意补“都已解开”放在括号中。

【按】“ཤ་བ་རི”，即作者夏瓦日巴（Śavaripa），意为“猎人”，在诗中自署其名。

【按】“སྟོང་པའི་བཙུན་མོ”，“空性的妃子”，与上段“无我母”同义，都是空性的人格化。

### 第三段：身语意成熟，沉醉

```
ཀྱེ་ཧོ་ལུས་ངག་སེམས་སྨིན་ཏེ། །ཐམས་ཅད་དུས་སུ་བརྟགས་པ་ཡིས། །ཤ་བ་རི་ནི་མྱོས་པར་འགྱུར། །
```

奇哉！身、语、意都成熟了；在一切时中都这样观察，夏瓦日巴便沉醉了。

【按】“བརྟགས་པ”，“观察”，也可以理解为“这样确认”“这样了知”。“མྱོས་པ”，“沉醉”，与前面几篇一样，比喻大乐或证悟的“醉”。

### 第四段：睡入虚空界

```
དགའ་བའི་རྣམ་པ་ཐམས་ཅད་དུ། །ཤ་བ་རི་ནི་གཉིད་ལོག་ནས། །གཉིད་ནི་ནམ་མཁའི་དབྱིངས་སུ་ལོག། །
```

在一切欢喜的相状中，夏瓦日巴睡着了；那睡眠，就睡入了虚空界之中。

【按】这里的“睡”与第一段的“醒觉”看似矛盾，其实是道歌常用的反语：对分别念而言是“睡去”（止息、消融），对心性而言是“醒觉”。“睡眠睡入虚空界中”，意思是连“睡”本身也消融于法界之中。这一解释是依道歌通常的读法推定的。

### 第五段：种子与虚空平等，果如大星升起

```
ཀྱེ་ཧོ་བདག་གི་དེ་ཉིད་ནི། །ས་བོན་ནམ་མཁར་མཉམ་པར་སྨོས། །འབྲས་བུ་ནམ་མཁར་སྐར་ཆེན་ཤར། །
སྤོངས་ཤིག་དོར་ཤིག་བདག་རྨོངས་སོ། །
```

奇哉！我的真性，说是种子与虚空平等；果，就像在虚空中升起的大星。舍弃吧！丢开吧！我是愚痴的啊。

【按】“ས་བོན་ནམ་མཁར་མཉམ་པར་སྨོས”，“说种子与虚空平等”，与第一段“种子说为在虚空界中”相呼应。

【按】“འབྲས་བུ་ནམ་མཁར་སྐར་ཆེན་ཤར”，“果是在虚空中升起的大星”，“སྐར་ཆེན”（大星）可能指晨星（金星），比喻证悟的果位如晨星在晴空中升起，明亮而无所依。这一解释是推定的。

### 第六段：杀三有之象，作五根朵玛

```
སྲིད་པས་བཅིངས་པའི་གླང་ཆེན་བསད། །དབང་པོ་ལྔ་ཡི་གཏོར་མ་བྱས། །བདག་གི་སྡུག་བསྔལ་ཐམས་ཅད་སྤངས། །
སྤོངས་ཤིག་དོར་ཤིག་བདག་རྨོངས་སོ། །
```

杀了被三有所束缚的大象，把五根作成朵玛（供施），舍弃了我的一切痛苦。舍弃吧！丢开吧！我是愚痴的啊。

【按】“སྲིད་པས་བཅིངས་པའི་གླང་ཆེན”，“被三有所缚的大象”，道歌中常以狂象比喻难以调伏的心或我执。“杀象”比喻断除我执，不是字面上的杀生。

【按】“དབང་པོ་ལྔ་ཡི་གཏོར་མ”，“五根的朵玛”，意思可能是：把眼、耳、鼻、舌、身五根（及其所取的境）都作为供施，不再执为己有；也可能是说以五根所受用的一切作为供养。原文简略，这里照字面译出。

### 第七段：日夜守心，独处寂静

```
ཉིན་མཚན་རྟག་ཏུ་གཉིད་མེད་པར། །རང་གི་སེམས་ལ་བྱ་ར་བྱས། །དེ་ནས་སྐྱེས་པ་བུད་མེད་ནི། །
གཅིག་ཏུ་དབེན་པར་སོང་སྟེ་གནས། །གཙོ་བོ་འཇིག་རྟེན་མགོན་ལ་སྨྲ། །སྤོངས་ཤིག་དོར་ཤིག་བདག་རྨོངས་སོ། །
```

日日夜夜，常常不睡，看守着自己的心。然后，男子与女子一同前往独一寂静之处安住。主尊对世间怙主说道：“舍弃吧！丢开吧！我是愚痴的啊。”

【按】“བྱ་ར་བྱས”，“看守”“守护”，“守心”是大手印修持中保持正念的要诀。这里说“常常不睡”，与第四段“睡入虚空界”看似相反：前者是说正念不间断，后者是说分别念消融，两者并不矛盾。

【按】“སྐྱེས་པ་བུད་མེད”，“男子与女子”，依道歌的通例，可能比喻方便与智慧，二者合一而入于独一的寂静（法界）。“གཅིག་ཏུ་དབེན་པ”，“独一寂静处”，也可以理解为“一味的寂静”。这些都是推解。

【按】“གཙོ་བོ་འཇིག་རྟེན་མགོན་ལ་སྨྲ”，德格版此处有异文：作“མགོན་པ”则是“主尊世间怙主说”，作“མགོན་ལ”则是“主尊对世间怙主说”。这里依校正后的“ལ”译出。“世间怙主”通常指观世音菩萨，本篇开头正是礼敬观世音自在，所以这一句可能是夏瓦日巴（或主尊）向观世音陈述，也可能是观世音亲口所说。“主尊”是谁，原文没有说明。两种读法这里都保留。

### 第八段：结归大乐

```
སྟོང་པའི་བཙུན་མོ་འཁྱུད་བྱས་ཏེ། །ཤ་བ་རི་བདེ་ཆེན་པོར་གནས། །
```

拥抱着空性的妃子，夏瓦日巴安住于大乐之中。

【按】本段与第二段几乎相同，只是把“在大乐中游戏”换成“安住于大乐”，首尾呼应。

## 通篇连读

心的分别念的尖端，就是法性；它的种子，说是在虚空界之中。年轻的无我母从颈项处拥抱着（我），（我）就安住在醒觉本身之中。舍弃吧！丢开吧！我是愚痴的啊。

奇哉！一切束缚，毫无剩余（都已解开）；夏瓦日巴在大乐中游戏，拥抱着空性的妃子。

奇哉！身、语、意都成熟了；在一切时中都这样观察，夏瓦日巴便沉醉了。

在一切欢喜的相状中，夏瓦日巴睡着了；那睡眠，就睡入了虚空界之中。

奇哉！我的真性，说是种子与虚空平等；果，就像在虚空中升起的大星。舍弃吧！丢开吧！我是愚痴的啊。

杀了被三有所束缚的大象，把五根作成朵玛（供施），舍弃了我的一切痛苦。舍弃吧！丢开吧！我是愚痴的啊。

日日夜夜，常常不睡，看守着自己的心。然后，男子与女子一同前往独一寂静之处安住。主尊对世间怙主说道：“舍弃吧！丢开吧！我是愚痴的啊。”

拥抱着空性的妃子，夏瓦日巴安住于大乐之中。
