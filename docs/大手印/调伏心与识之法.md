# 调伏心与识之法

阿阇黎寂天 传　阿阇黎美果 说

## 题解

本篇出自德格版丹珠尔续部（རྒྱུད་འགྲེལ།）ཟི 函第23b叶第6行至第24a叶第5行，东北目录编号 D2395。全篇三十七句，每句七个音节，另有礼敬和跋语。篇幅很短，所以把藏文原文全部保留在代码块中，按段落分开，每段后附汉译，疑难之处另以【按】说明。

梵文题名：Citta-citila-śapanopāyaṃ（ཙིཏྟ་ཙི་ཏི་ལ་ཤ་པ་ནོ་པཱ་ཡཾ），德格版拼写看来已经讹变，照录不改。

藏文题名：སེམས་དང་སེམས་ཉིད་འདུལ་བའི་ཐབས（调伏心与心性之方法）。

【按】本篇题名一般译作“调伏心与识之法”，但藏文的“སེམས་དང་སེམས་ཉིད”直译是“心与心性”，而不是“心与识”。本篇标题仍用通行译名，在此注明原文的字面意思。至于“调伏心性”的说法：心性本来清净，无须调伏，所以“调伏”的对象主要是“心”（妄心）；所谓“调伏心性”，大概是说认识心性、安住心性。梵文题名中的“citta-citila”或许原是“citta-caitasika”（心与心所），那么题名也可能原本是“心与心所”，但这只是推测。

【按】跋语说本篇是“由阿阇黎寂天传下，阿阇黎美果所说”。正文中的猎人“布苏古”，依藏传说法正是寂天的别名，所以本篇可以说是借寂天（布苏古）之口所说的道歌，由美果传出。“美果”（མེ་ཀོ）这里是音译，八十四大成就者中有一位名为 Mekopa（མེ་ཀོ་པ）的成就者，可能就是这一位，但无法确证。跋语没有记载译者。

## 正文

### 第一段：斑斓之鹿

```
སྤུ་མདོག་སྣ་ཚོགས་རི་དྭགས་ཏེ། །རྐང་པས་རྡེག་ཅིང་ཕྱོགས་བཞིར་འགྲོ། །བརྡས་ནས་ནམ་མཁར་བསད་པར་བྱས། །རང་གི་ཤ་ཡིས་རང་ལུས་ལ། །
རྣམ་པ་ཀུན་དུ་དགྲ་རུ་སོང་། །བྷུ་སུ་ཀུ་ཡི་རྔོན་པ་ཡིས། །སྐད་ཅིག་གཅིག་ཀྱང་གཏོང་བ་མེད། །
```

那只毛色斑斓的野鹿，用蹄子踏着地面，奔向四方；（猎人）惊吓追逐它，在虚空中把它杀了。它因为自己的肉，在一切方面都成了自己身体的仇敌；猎人布苏古，连一刹那也不放过它。

【按】本篇通篇以“猎人追鹿”为喻。依大手印道歌的通常读法，野鹿比喻心（妄心），猎人比喻修行人或上师的口诀，杀鹿比喻妄心在虚空般的心性中消融。这一读法是依题名“调伏心与心性”和全篇脉络推定的，原文本身没有点破。

【按】“སྤུ་མདོག་སྣ་ཚོགས”，“毛色种种”，可以理解为心显现为种种念头、种种习气；“ཕྱོགས་བཞིར་འགྲོ”，“奔向四方”，可以理解为心向外驰散，追逐外境。这些都是推解。

【按】“བརྡས་ནས”是全篇的一个难词。一种读法是“惊吓、驱赶”（追逐猎物），这里正文取这一读法；另一种读法是“以表示（符号）”，“བརྡ”是“表示”“标志”，在大手印传承中，上师以“表示”（象征）直指心性，是非常重要的说法。若取后一读法，这一句便是“以表示（直指）之后，在虚空中把它杀了”，意思是通过上师的表示，妄心当下消融于虚空般的心性中。两种读法法义上都说得通，第十一段同一词也是如此，特此并存。

【按】“ནམ་མཁར་བསད”，“在虚空中杀了”，依上面的读法，指妄心在虚空般的心性中消融、止息，不是真有一个东西被杀死。

【按】“རང་གི་ཤ་ཡིས་རང་ལུས་ལ་དགྲ་རུ་སོང”，“因为自己的肉，成了自己身体的仇敌”，意思是：鹿之所以被猎杀，正是因为它有一身肥美的肉，所以它的肉反而成了它自己的仇敌。用在心上，大概是说：心之所以被困、受苦，正是因为它自己的执著，这执著就是它自己的仇敌。这一句是全篇的叠句，下面各段反复出现。

【按】“བྷུ་སུ་ཀུ”（布苏古，Bhusuku），依藏传说法是寂天菩萨的别名。传说寂天在那烂陀寺时，表面上只做吃饭、睡觉、行走（或解手）三件事，所以人们取这三件事梵文名称的首音节，称他为“布苏古”。本篇跋语说此法“由阿阇黎寂天传下”，正与此相应。至于“布苏古”三字所指的确切三件事，各种传记说法稍有不同，这里不作细述。

【按】另外，印度的古孟加拉语《恰雅歌集》（Caryāgīti）中，有一首署名布苏古的道歌，也是以猎人与鹿为喻，有“鹿因自己的肉而成为仇敌”一类的句子，本篇很可能就是那一首或其同源的传本。但两者的字句并不完全相同，译者未作逐句对勘，这里只是附记，以备参考。

### 第二段：母鹿告诫公鹿

```
རི་དྭགས་མོ་ནི་ཕོ་ལ་སྨྲ། །ནགས་སུ་གནས་ན་བདེ་བར་འདུག། །དེ་ནས་བྱུང་ནས་གསོད་པར་བྱེད། །རང་གི་ཤ་ཡིས་རང་ལུས་ལ། །
རྣམ་པ་ཀུན་དུ་དགྲ་རུ་སོང་། །བྷུ་སུ་ཀུ་ཡི་རྔོན་པ་ཡིས། །སྐད་ཅིག་གཅིག་ཀྱང་གཏོང་བ་མེད། །
```

母鹿对公鹿说：“住在森林里，就能安乐地生活；（一旦）从那里出来，就会被杀。”它因为自己的肉，在一切方面都成了自己身体的仇敌；猎人布苏古，连一刹那也不放过它。

【按】“དེ་ནས་བྱུང་ནས་གསོད་པར་བྱེད”，“从那里出来，就杀”，语法上主语不明：可以读作“（鹿）从森林里出来，就会被（猎人）杀死”；也可以读作“（猎人）从那里出来，就杀（鹿）”。这里取前一种读法，并作为母鹿的话来译。母鹿的话到哪一句为止，原文没有引号，这里依文意，把第二、三句都看作母鹿的话。

【按】母鹿与公鹿，若依题名，可能分别比喻“心性”与“心”，或者“智慧”与“方便”，但原文没有说明。“住在森林里就安乐”，或许是说心安住于本位就安乐，向外驰散就被杀。这些都是推解。

### 第三段：公鹿的辩白

```
ཕོ་ནི་མོ་ལ་འདི་སྐད་སྨྲ། །སུ་ལ་བདག་གིས་གནོད་མ་བྱས། །ཅི་ཡང་བདག་གིས་ཟོས་པ་མེད། །སུ་ལའང་གནོད་པ་མ་བྱས་ན། །
ཅི་ཡི་ཕྱིར་ན་སོད་ཅིག་སྨྲ། །རང་གི་ཤ་ཡིས་རང་ལུས་ལ། །རྣམ་པ་ཀུན་ཏུ་དགྲ་རུ་སོང་། །བྷུ་སུ་ཀུ་ཡི་རྔོན་པ་ཡིས། །
སྐད་ཅིག་གཅིག་ཀྱང་གཏོང་བ་མེད། །
```

公鹿对母鹿这样说：“我没有伤害过任何人，我什么也没有吃。既然我没有伤害过任何人，为什么（他们）还要说‘杀了它’？”它因为自己的肉，在一切方面都成了自己身体的仇敌；猎人布苏古，连一刹那也不放过它。

【按】“སོད་ཅིག”是命令语气，“杀吧”“杀了它”，是猎人或旁人的呼喊。这里译作“杀了它”，并在前面补“他们”二字。

【按】“ཅི་ཡང་བདག་གིས་ཟོས་པ་མེད”，“我什么也没有吃”，可能与下一段“不伤草与水”相呼应：这只鹿不吃草也不喝水，也就是说，它根本不是一个有实体、需要饮食的东西。依此看，公鹿的辩白似乎在暗示：心本来无害、无所取，却仍然被追杀（被执著、被造作）。这是推解。

### 第四段：遍寻不得

```
རྩྭ་དང་ཆུ་ལ་མི་གནོད་པའི། །གང་དུ་གནས་ཀྱང་ལྟོགས་པ་མེད། །རྟག་ཏུ་བཙལ་ཀྱང་མ་རྙེད་པའི། །རི་དྭགས་ཕོ་མོ་འདི་གཉིས་ནི། །
བདག་གིས་རྙེད་པར་མ་གྱུར་ཏོ། །རང་གི་ཤ་ཡིས་རང་ལུས་ལ། །རྣམ་པ་ཀུན་དུ་དགྲ་རུ་སོང་། །བྷུ་སུ་ཀུ་ཡི་རྔོན་པ་ཡིས། །
སྐད་ཅིག་གཅིག་ཀྱང་གཏོང་བ་མེད། །
```

它不伤害草和水，无论住在哪里都没有饥饿；（这）一直寻找却找不到的公母二鹿，我终究没有找到。它因为自己的肉，在一切方面都成了自己身体的仇敌；猎人布苏古，连一刹那也不放过它。

【按】“རྩྭ་དང་ཆུ་ལ་མི་གནོད”，“不伤草与水”，意思是不吃草、不喝水。与上一段“我什么也没有吃”相呼应。

【按】“རྟག་ཏུ་བཙལ་ཀྱང་མ་རྙེད”，“一直寻找却找不到”，这是大手印、大圆满中“寻心不得”的修法：寻找心的来处、住处、去处，以及形状颜色，终究不可得。这里说的“我”，从上下文看应当是猎人布苏古，也就是修行人自己。

### 第五段：踪迹消失于虚空

```
རྒྱུག་ཅིང་འགྲོ་བའི་རི་དྭགས་ནི། །དེ་ཡི་རྗེས་ནི་རྙེད་པ་མེད། །བརྡས་པས་ནམ་མཁའི་དབྱིངས་སུ་སྟོར། །བྷུ་སུ་ཀུ་ཡི་རྔོན་པ་ཡིས། །
སྐད་ཅིག་གཅིག་ཀྱང་གཏོང་བ་མེད། །
```

那奔跑而去的鹿，找不到它的足迹；被惊吓追逐之后，（它）消失在虚空界中。猎人布苏古，连一刹那也不放过它。

【按】“དེ་ཡི་རྗེས་ནི་རྙེད་པ་མེད”，“找不到它的足迹”，比喻念头生起、消失，都没有可寻的踪迹。

【按】“བརྡས་པས”与第一段的“བརྡས་ནས”同一词，也可以读作“以表示（直指）之故”，那么这一句就是“由于（上师的）表示，（心）消融于虚空界中”。见第一段按语。

【按】本段最后只有“猎人布苏古连一刹那也不放过”，没有“因自己的肉成为仇敌”一句，叠句在这里发生了变化，表示鹿已经消失于虚空，不再有“自身之肉”可以成为仇敌了。这一理解是译者依结构推定的。

【按】“一刹那也不放过”，若依大手印的修法来理解，可以看作修行人对心念时时刻刻保持正念觉照，不让它一刹那散逸。

## 跋语

```
སེམས་དང་སེམས་ཉིད་འདུལ་བའི་མན་ངག་ཅེས་བྱ་བ་སློབ་དཔོན་ཤཱནྟ་དེ་བ་ནས་བརྒྱུད་པ་སློབ་དཔོན་མེ་ཀོ་ལས་གསུངས་པ་རྫོགས་སོ།། །
```

名为《调伏心与心性的口诀》，由阿阇黎寂天传承下来，阿阇黎美果所说，圆满。

【按】跋语中的题名作“口诀”（མན་ངག），开头的题名作“方法”（ཐབས），意思相近。“ཤཱནྟ་དེ་བ”即 Śāntideva，寂天。

## 通篇连读

那只毛色斑斓的野鹿，用蹄子踏着地面，奔向四方；（猎人）惊吓追逐它，在虚空中把它杀了。它因为自己的肉，在一切方面都成了自己身体的仇敌；猎人布苏古，连一刹那也不放过它。

母鹿对公鹿说：“住在森林里，就能安乐地生活；（一旦）从那里出来，就会被杀。”它因为自己的肉，在一切方面都成了自己身体的仇敌；猎人布苏古，连一刹那也不放过它。

公鹿对母鹿这样说：“我没有伤害过任何人，我什么也没有吃。既然我没有伤害过任何人，为什么（他们）还要说‘杀了它’？”它因为自己的肉，在一切方面都成了自己身体的仇敌；猎人布苏古，连一刹那也不放过它。

它不伤害草和水，无论住在哪里都没有饥饿；（这）一直寻找却找不到的公母二鹿，我终究没有找到。它因为自己的肉，在一切方面都成了自己身体的仇敌；猎人布苏古，连一刹那也不放过它。

那奔跑而去的鹿，找不到它的足迹；被惊吓追逐之后，（它）消失在虚空界中。猎人布苏古，连一刹那也不放过它。
