# 道歌宝藏（黑行者）

黑行者 造　毗卢遮那金刚 译

## 题解

本篇出自德格版丹珠尔续部（རྒྱུད་འགྲེལ།）ཞི 函第229a叶第1行至第230a叶第6行，东北目录编号 D2301。全篇一百二十二句，句长不一，另有礼敬与跋语。篇幅不长，所以把藏文原文全部保留在代码块中（逐句排列），按意义段落分开，每段后附汉译，疑难之处另以【按】说明。

梵文题名：Dohā-koṣa（དོ་ཧ་ཀོ་ཥཱ）。

藏文题名：དོ་ཧ་མཛོད（道哈宝藏）。

【按】跋语说本篇是“大瑜伽自在阿阇黎那波多杰（黑金刚）所造”，即黑行者（Kṛṣṇācārya、Kāṇha，卡纳巴），由“生于南方憍萨罗的瑜伽自在吉祥毗卢遮那金刚”亲自翻译。黑行者是印度大成就者，恰雅歌集中署名最多的作者，前面所译的《无二根本修习次第》《心宝之见》《不相属之见（黑行者道歌）》都与他有关。毗卢遮那金刚（Vairocanavajra）是十一世纪来藏的印度译师，曾翻译多部道歌。

【按】黑行者的《道哈宝藏》与萨惹哈的《道哈宝藏》并称，是印度大手印道歌的代表作。本篇的核心是“俱生”（ལྷན་ཅིག་སྐྱེས་པ）：批评只凭经论而骄慢的学者如蜂绕木橘、只执外在仪轨的修行人如嬉戏，强调在空与非空之间认识唯一的俱生，心不迁移、风不动摇，刹那成就，如盐入水而成一味。

【按】本篇大量使用无上瑜伽续圆满次第的隐语：中脉与左右二脉、脉轮、“ཨེ་ཝཾ”、四喜、闭二门、主妇、年轻女子等等。其中“主妇”（ཁྱིམ་བདག་མོ）与“年轻女子”（གཞོན་ནུ་མ）是黑行者道歌的著名象征，喻指心性与智慧，绝不能照字面理解。这些修法须得灌顶、依上师口授才能修持；按语中的解释只是依通常的说法所作的推解，不代表传承口诀。

## 礼敬

```
དཔལ་རྡོ་རྗེ་སེམས་དཔའ་ལ་ཕྱག་འཚལ་ལོ། །
```

敬礼吉祥金刚萨埵！

## 正文

### 一、真入无染者千万中一

```
འཇིག་རྟེན་པ་ནི་ང་རྒྱལ་བྱེད། །
ད་ནི་དོན་དམ་འཇུག་པའོ་ཞེས། །
གོས་པ་མེད་ལ་ཞུགས་པ་ནི། །
བྱེ་བའི་ནང་ནས་གཅིག་ཙམ་སྲིད། །
```

世间人生起骄慢，说：“现在我已进入胜义了。”（其实）真正进入无染境界的，千万人中也只可能有一个。

### 二、学者如蜂绕木橘

```
ལུང་དང་རིག་བྱེད་རྙིང་པ་ཡིས། །
མཁས་པ་ང་རྒྱལ་བྱེད་པ་དག། །
དཔལ་འབྲས་སྨིན་པ་ལ་ནི་བུང་བ་བཞིན། །
དེས་ནི་ཕྱི་རོལ་དག་ཏུ་འཁོར་བར་བྱེད། །
```

凭着经教与古老的吠陀而骄慢的学者们，就像蜜蜂围着成熟的木橘果打转一样，他们因此只在外面绕圈子。

【按】“དཔལ་འབྲས”，木橘果（bilva），外壳坚硬。蜜蜂绕着它飞，却进不去，只在外面打转。比喻只凭经论与学问而骄慢的学者，始终在实义之外徘徊，进不到内在的证悟。这是道歌中批评学者的著名譬喻。

### 三、本然之身中的莲花

```
བྱང་ཆུབ་སེམས་དང་རྡུལ་གྱིས་བརྒྱན། །
མི་བསྐྱོད་པ་ནི་གོས་འགྱུར་བས། །
པདྨའི་ས་བོན་རང་བཞིན་ལ། །
དག་པ་གཉུག་མའི་ལུས་ལ་མཐོང་། །
```

菩提心以尘为庄严，不动（佛）因此被染；在莲花种子的自性上，于清净的本然之身中见到（它）。

【按】这几句用的是无上瑜伽续圆满次第的隐语：“菩提心”（白分）与“尘”（红分）、“不动佛”“莲花”等，都是指身内的脉、明点与智慧。具体所指须依传承口授。这里只照字面译出，不作具体配释。

【按】“གཉུག་མའི་ལུས”，“本然之身”，是本篇反复出现的词，“གཉུག་མ”是本来、本然，相当于“俱生”。

### 四、身中之莲：中脉与左右二脉

```
ནམ་མཁའི་ཆུ་དང་འོད་དཔག་མེད་ཀྱི་འདམ། །
དེས་ནི་རྩ་བ་རབ་ཏུ་སྤངས་ནས་བྱས། །
ཨ་ཝ་དྷཱུ་ཏཱིས་རྩ་བ་སྡོང་པོ་བྱས། །
ཧཾ་གི་ཡི་གེའི་རྣམ་པར་སྐྱེས་གྱུར་པ། །
རོ་མ་དང་ནི་རྐྱང་མ་གཉིས་ཀྱིས་ནི། །
གཡས་དང་གཡོན་ཕྱོགས་གཉིས་ཀྱི་སྡོང་བུར་བྱས། །
པདྨ་འདབ་མ་བཞི་དང་རྩ་བ་བཞི། །
བདེ་བ་ཆེན་པོ་དག་ནི་ཚང་ན་གནས། །
ཨེ་ཝཾ་ས་བོན་དག་ནི་བླངས་ནས་ནི། །
མེ་ཏོག་པདྨ་བཞིན་དུ་རྒྱས་པར་བྱེད། །
བུང་བའི་གཟུགས་ཀྱིས་བདེ་ཆེན་དཔའ་བོ་ནི། །
སྦྲང་རྩི་དག་ནི་རབ་ཏུ་འཐུང་བར་བྱེད། །
```

以虚空之水与无量光之泥，它舍离了（凡俗的）根而生长。以阿瓦都底（中脉）作为根与茎，生起了“ཧཾ”字之相；以若玛与江玛二脉，作为右边与左边两侧的枝干。莲花有四片花瓣与四条根，大乐就住在其中，如在巢中。取来“ཨེ་ཝཾ”的种子，使它如莲花一样开放；以蜜蜂之形的大乐勇士，畅饮着花蜜。

【按】这一段把身体比喻为一株莲花：中脉（阿瓦都底）是根茎，左右二脉（若玛、江玛）是两侧的枝干，脉轮是莲花，大乐住于其中。“ཨེ་ཝཾ”（诶旺）在密续中象征智慧与方便、空与乐的双运。“蜜蜂饮花蜜”比喻大乐的受用。这些都是圆满次第的象征语言，修持须得灌顶、依上师口授。

【按】第14句“དེས་ནི་རྩ་བ་རབ་ཏུ་སྤངས་ནས་བྱས”，直译是“它彻底舍弃根而作”，意思不完全清楚，这里依文意试译。

### 五、五大皆空

```
འབྱུང་བ་ཆེན་པོ་ལྔ་ཡི་ས་བོན་ནི། །
བླངས་ནས་རྫོགས་པ་དག་ཏུ་བྱེད་པར་འགྱུར། །
སྲ་བར་འགྱུར་བ་དག་ནི་ས་ཡིན་ནོ། །
ཆུ་ནི་རླན་པ་ཚ་བ་མེ་ལས་སྐྱེས། །
ཡང་ཞིང་གཡོ་བ་དག་ནི་རླུང་ཡིན་ནོ། །
ནམ་མཁའ་བདེ་བ་དག་ནི་གང་བའོ། །
མ་ལུས་ལྷ་དང་ལྷ་མིན་དེ་ལས་སྐྱེས། །
རྨོངས་པ་འདི་དག་རྣམས་ནི་སྟོང་པའོ། །
ས་དང་ཆུ་དང་མེ་རླུང་ནམ་མཁའ་རྣམས། །
བློ་ཡི་ཡུལ་དུ་བླངས་ནས་ཤེས་པར་གྱིས། །
དབའ་རླབས་མེད་ཅིང་མཉམ་པ་གཉུག་མའི་ལུས། །
སྒྲིབ་པ་མ་ལུས་སྤངས་པ་སྟེ། །
དགེ་དང་སྡིག་པ་གཅིག་ཀྱང་མེད། །
```

取来五大的种子，使它圆满：坚硬的是地，水是湿润，热是从火所生，轻而动的是风，虚空则是大乐所充满。一切天与非天，都从那里生起；这些愚痴的（显现），都是空的。把地、水、火、风、空，都取作心识的对境来了知；没有波浪、平等的本然之身，舍弃了一切障碍，善与恶一个也没有。

【按】“取五大为心识之境而了知”，意思是：把构成身体与外界的五大，都认识为心的显现，了知其空性。“没有波浪的本然之身”，比喻心性如无波的水面，平等安住。

【按】“善与恶一个也没有”，是就本然的心性而说的：心性本身超越善恶的分别。这并不是说世俗中可以不分善恶。

### 六、空与非空之间：唯一俱生

```
གསལ་པོར་ནག་པོ་དག་གིས་གསུམ། །
ཕྱི་རོལ་འབྱུང་བ་དག་ནི་སྤྱད་བྱས་ནས། །
སྟོང་དང་སྟོང་མིན་དག་ལ་འཇུག་པར་གྱིས། །
སྟོང་དང་སྟོང་མིན་གཉིས་ཀྱི་དབུས་སུ་ནི། །
ཀྱེ་ཧོ་རྨོངས་པ་ཅི་ཡང་མ་མཐོང་ངམ། །
ལྷན་ཅིག་སྐྱེས་པ་གཅིག་པུ་ཡོད། །
ནག་པོ་བདག་གིས་ཡོངས་སུ་ཤེས། །
ལུང་དང་བསྟན་བཅོས་མང་པོ་བཀླགས་པ་དང་། །
ཉན་ཀྱང་རྨོངས་པ་ཅི་ཡང་མི་ཤེས་སོ། །
```

黑行者清楚地（宣说）……受用了外在的诸大之后，要进入空与非空之中。在空与非空二者的中间，唉，愚人们，你们什么也没有看见吗？（那里）只有唯一的俱生，我黑行者完全了知。读了许多经论，也听过，愚人们却什么都不知道。

【按】第38句“གསལ་པོར་ནག་པོ་དག་གིས་གསུམ”，意思不明，这里只译出前半。

【按】“空与非空的中间，只有唯一的俱生”，是本篇的核心：既不执空，也不执有，于二者之中认识俱生的心性。“ནག་པོ”（黑行者）是作者在诗中自署其名。

### 七、心不迁移，风不动摇

```
སྟེང་དུ་མི་རྒྱུ་འོག་ཏུ་མི་འགྲོ་ཞིང་། །
གཉིས་པ་སྤངས་པས་དེ་ནི་བརྟན་པར་གནས། །
ནག་པོ་ན་རེ་ཡིད་ནི་གང་དུ་མི་འཕོ་ཟེར། །
མི་གཡོ་རླུང་ནི་ཁྱིམ་བདག་མོ་ནི་ཁྱིམ་དུ་གནས། །
```

（心）不向上行，也不向下走，舍弃了二（取），它就稳固地安住。黑行者说：心不迁移到任何地方，风不动摇，主妇就住在家中。

【按】“ཁྱིམ་བདག་མོ”，“主妇”，是黑行者道歌中的著名隐语，喻指心（或智慧、或中脉中的气）。“主妇住在家中”，比喻心安住于本位，不向外驰散；“风不动摇”，指气息止息于中脉。心与气相依，气不动则心不动。

### 八、难以表示，难以了悟

```
མཆོག་གི་རི་བོ་དག་ནི་ཕུག་ཟབ་མོར། །
འགྲོ་བ་མ་ལུས་པ་ནི་ཆགས་པར་འགྱུར། །
དྲི་མ་མེད་པར་ཆུ་ནི་སྐམས་འགྱུར་ཏེ། །
དུས་ཀྱི་མེ་ནི་རབ་ཏུ་ཞུགས་གྱུར་པ། །
ས་འཛིན་འདི་ནི་ཤིན་ཏུ་བཟུང་དཀའ་སྟེ། །
མཉམ་དང་མི་མཉམ་དག་ལ་རྒལ་མི་ནུས། །
ནག་པོ་ན་རེ་མཚོན་དཀའ་རྟོགས་དཀའ་བ། །
འདི་ནི་གང་གི་སེམས་ཀྱིས་བསམ་མི་ནུས། །
གང་གི་ཡི་ནི་རིན་ཆེན་རིས་ནུས་པ། །
ཉི་མ་རེ་རེ་ལྷན་ཅིག་སྐྱེས་པ་འཕྲོ། །
དེ་ཡིས་ཆོས་ཀྱི་རང་བཞིན་དག་ནི་ཤེས། །
གཞན་ལ་བསྟན་དུ་ཟིན་ཀྱང་མི་ཤེས་སོ། །
```

在殊胜之山的深洞里，一切众生都会贪著。在无垢之中，水干涸了，劫末之火炽燃。这持地（之山）极其难以把握，越不过平等与不平等。黑行者说：（这）难以表示，难以了悟，这是任何人的心都无法思议的。能够稳住心宝的人，在每一个刹那都放射出俱生；他了知诸法的自性，即使给别人开示，别人也不能懂得。

【按】第51至56句的“殊胜之山”“深洞”“水干涸”“劫火炽燃”，都是圆满次第的隐语，可能指中脉、气入中脉、拙火燃起等，原文没有解释。

【按】第59句“གང་གི་ཡི་ནི་རིན་ཆེན་རིས་ནུས་པ”，字面不通，与第115句“གང་གིས་ཡིད་ནི་རིན་ཆེན་བརྟན་ནུས”（能稳住心宝的人）对照，这里依后者读作“能够稳住心宝的人”。第60句“ཉི་མ་རེ་རེ”，直译是“每一个太阳”，这里读作“每一刹那”，不能确定。

### 九、舍弃坛城，安住俱生刹那

```
ལམ་འགྲོ་གཉུག་མའི་ཡིད་ནི་བཅིངས་ནུས་པ། །
ཁམས་གསུམ་མ་ལུས་སྤྲོ་ཞིང་ཡང་དེར་སྡུད། །
བདེ་གཤེགས་སྲིད་པའི་ལྷ་མོ་ཁྲོ་བོའི་ཚོགས། །
དཀྱིལ་འཁོར་འཁོར་ལོ་དག་ནི་སྤངས་ནས་སུ། །
ལྷན་སྐྱེས་སྐད་ཅིག་ལ་ནི་བདག་གནས་བྱ། །
གང་གིས་ལྷན་སྐྱེས་མི་གཡོ་བརྟན་ནུས་པ། །
གཉུག་མའི་ཡིད་ཀྱིས་རྒྱལ་པོ་རོ་མཉམ་འགྱུར། །
དེ་ཡི་སྐད་ཅིག་ལ་ནི་འགྲུབ་འགྱུར་ཏེ། །
རྒས་དང་འཆི་བའི་འཇིགས་པ་གང་ཡང་མེད། །
མི་གཡོ་མི་རྟོག་སྐྱོན་རྣམས་མེད་པ་ནི། །
ཤར་ནུབ་སྤངས་པ་དེ་ནི་སྙིང་པོ་སྟེ། །
འདི་ནི་འདི་རུ་མྱ་ངན་འདས་པར་གསུངས། །
དེས་ནི་ཡིད་ཀྱིས་ང་རྒྱལ་ཅི་ཡང་མི་བྱེད་དོ། །
```

能系住那行于道路的本然之心的人，三界一切都从那里放出，又收摄回那里。舍弃了善逝、三有的天女、忿怒尊众，以及坛城与轮，在俱生的刹那中安住自身。能使俱生不动、稳固的人，以本然之心，与国王成为一味；在那一刹那间就能成就，没有任何衰老与死亡的怖畏。不动、无分别、没有过失的，离开了东方与西方的，那就是心髓；（经中）说，这就是在此处的涅槃。（证得这一境界的人，）心中毫无骄慢。

【按】“舍弃善逝、天女、忿怒尊众、坛城与轮”，是说不执著生起次第的本尊、坛城等造作，直接安住于俱生的刹那。这是大手印道歌的典型说法，强调心性的直接认识，并不是否定生起次第的修持在修道中的作用。

【按】“离开东方与西方”，可能比喻离开左右二脉，即气入中脉，也可能比喻离开一切方所。“与国王成为一味”，“国王”可能指心性本身。

### 十、了知诶旺

```
ཨེ་ཝཾ་རྣམ་པ་གང་གིས་ཤེས་གྱུར་པ། །
དེས་ནི་མ་ལུས་ལུས་པ་མེད་པར་ཤེས། །
ཀྱེ་ཧོ་ཆོས་ཀྱི་ཟ་མ་ཏོག་ཅེས་དེ་ལ་བྱ། །
གཉུག་མའི་བདག་པོ་ཆ་ལུགས་དེ་ཡིན་ནོ། །
```

以任何方式了知了“ཨེ་ཝཾ”的人，就了知了一切而无所遗漏。唉！这被称为“法的……”，那就是本然之主的装束。

【按】“ཨེ་ཝཾ”象征智慧与方便的双运。第78句“ཟ་མ་ཏོག”意思不明，可能是“匣子、容器”之类，这里不强译。

### 十一、闭二门，燃心灯

```
གལ་ཏེ་རླུང་དང་ནམ་མཁའ་སྒོ་གཉིས་ལ། །
སྒོ་ལྕགས་དམ་པོར་གང་གིས་འཇུག་ནུས་ན། །
དེས་ནི་དེ་རུ་མུན་པ་ནག་པོ་ཡིས། །
ནང་དུ་ཡིད་ཀྱི་མར་མེ་དག་ནི་བྱ། །
རྒྱལ་བ་རིན་ཆེན་ལུས་ཀྱི་སྟེང་དུ་སོང་། །
ནག་པོ་ན་རེ་སྲིད་ལོངས་སྤྱད་པས་ཐར་པ་འགྲུབ། །
```

如果有人能在风与虚空这两道门上，紧紧地插上门闩，那么在那里，在黑暗之中，就在内部点燃心的明灯；胜者之宝，就升到了身体的上方。黑行者说：在受用三有之中，就能成就解脱。

【按】“闭风与虚空二门”，可能指收摄左右二脉的气息，或闭止向外散失之门。“在黑暗中点燃心灯”，比喻在收摄一切外散之后，内在心性的光明自然显现。“胜者之宝升至身体上方”，可能指明点上升至顶轮。这些都是圆满次第的隐语，须依传承口授。

【按】“在受用三有之中成就解脱”，是道歌中“不离烦恼而得解脱”的思想：不必离开世间的一切受用，在受用中认识心性，就能解脱。这须以证悟为前提，不能理解为放纵欲乐。

### 十二、胜喜与离喜之间

```
གང་གི་ཡིད་ནི་བརྟན་པར་བྱས་གྱུར་ན། །
དེ་ནི་ཆོས་ཀྱི་ཡི་གེའི་དྲུང་ན་གནས། །
སྐད་ཅིག་གིས་ནི་རླུང་གིས་འཆིང་བར་འགྱུར། །
དེའི་ཚེ་ཡུལ་རྣམས་ལ་ཡང་རེ་བ་མེད། །
མཆོག་དང་དགའ་བྲལ་དབུས་སུ་གང་སྐྱེས་པ། །
ཆོས་ཀྱི་ཡི་གེའི་དབུས་སུ་ཤེས་པར་གྱིས། །
```

如果心被稳固住了，它就住在法之字的跟前；刹那之间，就被风所系住，那时对于诸境，也不再有所希求。在“胜喜”与“离喜”的中间所生起的，要在法之字的中央去认识它。

【按】“胜喜”与“离喜”，是无上瑜伽续所说“四喜”中的两种（喜、胜喜、离喜、俱生喜）。在胜喜与离喜之间所生起的，一般指俱生喜，也就是俱生智慧。“法之字”，大概指上文的“ཨེ་ཝཾ”。这些须依上师口授来理解。

### 十三、殊胜之山，大乐之处

```
འདི་ལྟའི་གདམས་ངག་གསལ་པོར་འགྲུབ་འགྱུར་ནི། །
དེ་ཡི་ཁྱིམ་བདག་མོ་རླུང་མི་གཡོ་བཅིངས། །
མཆོག་གི་རི་བོའི་རྩེ་ལ་རྒྱས་པའི་ཐང་། །
རི་ཁྲོད་པ་ནི་དེ་རུ་གནས་བྱས་པས། །
གདོང་ལྔ་པས་ཀྱང་རྒལ་བར་མི་ནུས་ན། །
གླང་པོ་ཆེ་ཡི་རེ་བ་རིང་དུ་འགྱུར། །
འདི་ནི་མཆོག་གི་རི་བོར་བདག་གིས་བསྟན། །
འདི་ནི་བདེ་བ་ཆེན་པོའི་གནས་ཡིན་ནོ། །
```

这样的口诀一旦明显成就，他的主妇就把风系住，使它不动。在殊胜之山的顶上，有开阔的平原，山居的瑜伽士就住在那里；连五面者（狮子）都越不过去，大象的希望也就落空了。这是我在殊胜之山上所开示的，这就是大乐之处。

【按】“五面者”（གདོང་ལྔ་པ）是狮子的别称。“殊胜之山的顶上”，可能指顶轮，或指证悟的境界。“连狮子都越不过，大象的希望落空”，可能比喻这一境界超越一切，种种分别（大象）都无法到达。这是推解。

### 十四、俱生刹那，何须续咒

```
ལྷན་ཅིག་སྐྱེས་པའི་སྐད་ཅིག་འདི་རུ་ལྟོས། །
བདེ་བ་ཆེན་པོ་མ་རྙེད་བར་དུའོ། །
འགྲོ་བ་ཀུན་གྱིས་ལུས་ངག་ཡིད་འདྲེན་སྤྱོད། །
ཀྱེ་ཧོ་དེ་ཉིད་བདེ་ཆེན་རྒྱལ་པོ་གཅིག་ཏུ་ཉིད། །
རྒྱུད་དང་སྔགས་རྣམས་ཀྱིས་ནི་ཅི་ཞིག་བྱ། །
```

看看这俱生的刹那吧！在还没有找到大乐之前，一切众生都被身、语、意牵引着行事。唉！那（俱生）就是唯一的大乐之王，续与咒又有什么用呢？

【按】“续与咒有什么用”，是道歌中常见的说法，强调直接认识俱生心性的重要，并不是说续与咒在修道中没有作用。

### 十五、本然主妇，不在外求

```
གཉུག་མའི་ཁྱིམ་བདག་མོ་ནི་བླངས་ནས་རོལ་པར་བྱ། །
གཉུག་མའི་ཁྱིམ་དུ་ཁྱིམ་བདག་མོ་ནི་མ་ཆུད་པའི། །
བར་དུ་དེ་སྲིད་འདོད་ཡོན་ལྔ་ལ་སྤྱོད། །
བཟླས་པ་སྦྱིན་སྲེག་དཀྱིལ་འཁོར་ལས་འདི་ཡིས། །
རྟག་ཏུ་ཀུ་རེ་རྩེད་མོས་ཅི་ཞིག་བྱ། །
གཞོན་ནུ་མ་དང་རྟག་ཏུ་མཛའ་བ་དེ་མེད་ན། །
ལུས་འདི་ཡིས་ནི་བྱང་ཆུབ་ཇི་ལྟར་འགྲུབ། །
```

把本然的主妇取来，与她游戏吧！在主妇还没有回到本然之家以前，那时只是（在外）受用五欲。诵咒、火供与坛城事业，这些常常的嬉戏有什么用呢？如果不与年轻的女子（智慧）常常亲密，以这个身体怎么能成就菩提呢？

【按】“主妇回到本然之家”，比喻心回到心性的本位；在此之前，心只在外受用五欲而散乱。“诵咒、火供、坛城事业是嬉戏”，是批评只执著外在仪轨而不认识心性的修行人。

【按】第110句的“གཞོན་ནུ་མ”（年轻的女子），在密乘道歌中是智慧（般若）的象征，与“主妇”同指心性中的智慧一面。“与之常相亲密”，比喻方便与智慧常相双运。这是象征语言，绝不能照字面理解。

### 十六、了悟俱生，何须吠陀

```
གང་གི་རྒྱུན་དུ་ལྷན་ཅིག་སྐྱེས་རྟོགས་ན། །
རིག་བྱེད་རྙིང་པ་དེ་ཡིས་ཅི་ཞིག་བྱ། །
དེས་ནི་འགྲོ་བ་མ་ལུས་རྣམ་རྟོག་བཅད། །
གང་གིས་ཡིད་ནི་རིན་ཆེན་བརྟན་ནུས་ན། །
གཉུག་མའི་ཁྱིམ་བདག་མོ་ནི་བླངས་ནས་འདིར། །
དེ་ནི་རྡོ་རྗེ་སེམས་དཔའ་མགོན་པོ་སྟེ། །
མཆོག་གི་དོན་འདི་བདག་གིས་རབ་ཏུ་བརྗོད། །
```

如果常常了悟俱生，那古老的吠陀又有什么用？他斩断了一切众生的分别。能够稳住心宝的人，在这里取来本然的主妇，那就是怙主金刚萨埵——这一殊胜的义理，我已经宣说了。

### 十七、如盐入水，刹那一味

```
ཇི་ལྟར་ལན་ཚྭ་ཆུ་ལ་ཞུ་བ་བཞིན། །
དེ་ལྟར་ཁྱིམ་ཐབ་མོས་ནི་གཟུང་བའི་སེམས། །
ཀྱེ་ཧོ་སྐད་ཅིག་གིས་ནི་རོ་མཉམ་འགྱུར། །
གང་གིས་དེ་དང་རྟག་ཏུ་མཉམ་པར་གནས། །
```

就像盐溶入水中一样，被主妇所摄持的心也是这样，唉！刹那之间就成为一味——那常常与她平等安住的人。

【按】“如盐入水”，是大手印著名的譬喻：盐溶于水，再也分不出盐与水；比喻心融入心性，成为一味。与前面《大手印表示传承》“盐溶于水，形失而味存”相呼应。

## 跋语

```
རྣལ་འབྱོར་གྱི་དབང་ཕྱུག་ཆེན་པོ་སློབ་དཔོན་ནག་པོ་རྡོ་རྗེས་མཛད་པའི་དོ་ཧ་མཛོད་ཅེས་བྱ་བ་རྫོགས་སོ།། །།ལྷོ་ཕྱོགས་ཀོ་ས་ལར་སྐུ་འཁྲུངས་པའི་རྣལ་འབྱོར་གྱི་དབང་ཕྱུག་ཤྲཱི་བཻ་རོ་ཙ་ན་བཛྲའི་ཞལ་སྔ་ནས་རང་འགྱུར་དུ་མཛད་པའོ།།
```

名为《道哈宝藏》，大瑜伽自在阿阇黎那波多杰（黑金刚）所造，圆满。由生于南方憍萨罗的瑜伽自在吉祥毗卢遮那金刚亲自翻译。

## 通篇连读

世间人生起骄慢，说：“现在我已进入胜义了。”（其实）真正进入无染境界的，千万人中也只可能有一个。

凭着经教与古老的吠陀而骄慢的学者们，就像蜜蜂围着成熟的木橘果打转一样，他们因此只在外面绕圈子。

菩提心以尘为庄严，不动（佛）因此被染；在莲花种子的自性上，于清净的本然之身中见到（它）。

以虚空之水与无量光之泥，它舍离了（凡俗的）根而生长。以阿瓦都底（中脉）作为根与茎，生起了“ཧཾ”字之相；以若玛与江玛二脉，作为右边与左边两侧的枝干。莲花有四片花瓣与四条根，大乐就住在其中，如在巢中。取来“ཨེ་ཝཾ”的种子，使它如莲花一样开放；以蜜蜂之形的大乐勇士，畅饮着花蜜。

取来五大的种子，使它圆满：坚硬的是地，水是湿润，热是从火所生，轻而动的是风，虚空则是大乐所充满。一切天与非天，都从那里生起；这些愚痴的（显现），都是空的。把地、水、火、风、空，都取作心识的对境来了知；没有波浪、平等的本然之身，舍弃了一切障碍，善与恶一个也没有。

黑行者清楚地（宣说）……受用了外在的诸大之后，要进入空与非空之中。在空与非空二者的中间，唉，愚人们，你们什么也没有看见吗？（那里）只有唯一的俱生，我黑行者完全了知。读了许多经论，也听过，愚人们却什么都不知道。

（心）不向上行，也不向下走，舍弃了二（取），它就稳固地安住。黑行者说：心不迁移到任何地方，风不动摇，主妇就住在家中。

在殊胜之山的深洞里，一切众生都会贪著。在无垢之中，水干涸了，劫末之火炽燃。这持地（之山）极其难以把握，越不过平等与不平等。黑行者说：（这）难以表示，难以了悟，这是任何人的心都无法思议的。能够稳住心宝的人，在每一个刹那都放射出俱生；他了知诸法的自性，即使给别人开示，别人也不能懂得。

能系住那行于道路的本然之心的人，三界一切都从那里放出，又收摄回那里。舍弃了善逝、三有的天女、忿怒尊众，以及坛城与轮，在俱生的刹那中安住自身。能使俱生不动、稳固的人，以本然之心，与国王成为一味；在那一刹那间就能成就，没有任何衰老与死亡的怖畏。不动、无分别、没有过失的，离开了东方与西方的，那就是心髓；（经中）说，这就是在此处的涅槃。（证得这一境界的人，）心中毫无骄慢。

以任何方式了知了“ཨེ་ཝཾ”的人，就了知了一切而无所遗漏。唉！这被称为“法的……”，那就是本然之主的装束。

如果有人能在风与虚空这两道门上，紧紧地插上门闩，那么在那里，在黑暗之中，就在内部点燃心的明灯；胜者之宝，就升到了身体的上方。黑行者说：在受用三有之中，就能成就解脱。

如果心被稳固住了，它就住在法之字的跟前；刹那之间，就被风所系住，那时对于诸境，也不再有所希求。在“胜喜”与“离喜”的中间所生起的，要在法之字的中央去认识它。

这样的口诀一旦明显成就，他的主妇就把风系住，使它不动。在殊胜之山的顶上，有开阔的平原，山居的瑜伽士就住在那里；连五面者（狮子）都越不过去，大象的希望也就落空了。这是我在殊胜之山上所开示的，这就是大乐之处。

看看这俱生的刹那吧！在还没有找到大乐之前，一切众生都被身、语、意牵引着行事。唉！那（俱生）就是唯一的大乐之王，续与咒又有什么用呢？

把本然的主妇取来，与她游戏吧！在主妇还没有回到本然之家以前，那时只是（在外）受用五欲。诵咒、火供与坛城事业，这些常常的嬉戏有什么用呢？如果不与年轻的女子（智慧）常常亲密，以这个身体怎么能成就菩提呢？

如果常常了悟俱生，那古老的吠陀又有什么用？他斩断了一切众生的分别。能够稳住心宝的人，在这里取来本然的主妇，那就是怙主金刚萨埵——这一殊胜的义理，我已经宣说了。

就像盐溶入水中一样，被主妇所摄持的心也是这样，唉！刹那之间就成为一味——那常常与她平等安住的人。
