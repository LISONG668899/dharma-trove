# 四偈半

阿阇黎龙树藏（Nāgārjunagarbha）造　据藏文译出

## 题解

《四偈半》（藏 tshigs su bcad pa phyed dang lnga pa，直译"第五［偈］为半的［四偈］"，即四偈半）收于德格版丹珠尔续部释 ཞི 函第 128a 至 133a 页（东北目录 D2278），紧接在已译出的《所缘修习》（D2277，藏文题名 dngos po sbyong ba，亦题为龙树所造）之后。题名中的作者是"阿阇黎龙树藏"（klu sgrub snying po，Nāgārjunagarbha）。本篇没有梵语题名，也没有译者跋语，篇末只附有一段传承记录：从吉祥山的"大主宰"［龙树］、经夏瓦日巴、迦罗巴而传到那洛巴。

全篇的结构很特别：开头是四偈半（十八句）的根本颂，以十六个比喻列举修行人的十六种过患——希望、恐惧、向外寻求、我执、二取显现、取舍、见的我慢、修的执著、行的我慢、苦行的自负、以灌顶为足、以证悟为足、不依上师、诽谤佛语、贪著安乐、执著空性，最后说"远离这些的认知，就像获得如意宝珠"。然后逐一讲述十六个故事来解释每个比喻，每个故事的末尾都有一位人物以偈颂说出教诫，并标明"这是令远离某某的口诀，第几"。

篇末说：前十个是"过去的例子"，与经续相合；后六个是"未来的例子"，与成就者的成就相合。后六个故事的人物——吉祥狮子与东比嘿噜嘎、恒伽女、那洛巴、甘巴拉、古古日巴等——都是晚于龙树的印度大成就者，篇中以"未来"称之，正是因为本篇托名于龙树。这样的托名与传承记录，反映出本篇是在夏瓦日巴、那洛巴一系大手印传承中流传的口诀，大约编成于十一世纪前后。

本篇的十六种过患，涵盖了见、修、行、果的各种偏差，尤其是后六种，直接针对密乘与大手印行者常见的错误：以为得了灌顶就够了、以为有了证悟就不必再修、不依上师、偏执中观而诽谤其余佛语、贪著业手印的安乐、执著空性而落入断见。这与梅纪巴《真如十颂》及其《广释》、《灌顶教示难释》中的告诫完全一致，可以互相参看。

**关于内容的说明：**这些故事多是民间譬喻与成就者传说，情节有时离奇，有的带有寓言性质（如染色的豺、双头鹦鹉），有的写到婚外私情（第六个故事），第十二个故事说空行母们杀死了以证悟为足的瑜伽士并作为会供。这些都是以故事来警示修行人的过患，不能照字面理解为可以效仿或认可的行为。第十五个故事涉及业手印，第十六个故事末尾提到"第三灌顶"，都是无上瑜伽续的内容，须依具德上师的灌顶与口授来理解。

**文字的问题：**本篇藏文颇多难解之处，有些人名、地名的拼写不规范，有些句子明显有脱漏或误写，根本颂中的比喻与后面故事末尾的"第几口诀"标题也有几处对不上，例如第三个故事的标题是"舍弃所修的口诀"，根本颂却说"向别处执取"；第五、六两个故事的标题都是"远离取舍"。这些都在各节按语中说明，不妄改原文。人名能对出梵文的，注出梵文；对不出的，依藏文意译或音译，并在按语中注明。

体例：根本颂与各故事中的偈颂，先列藏文原文于代码块中，再以完整的意义单元译出；故事的散文部分只译中文。为了便于理解而补的字，都放在方括号中。各节标题为译者所加。原文含混或可有两解之处，以"【按】"说明，不妄补内容。

## 一、根本颂：四偈半

```
སློབ་དཔོན་ཀླུ་སྒྲུབ་སྙིང་པོའི་ཞལ་སྔ་ནས། །
རེ་བའི་དཔེ་ནི་སེར་སྐྱ་འདྲ། །
དོག་པ་རྒྱལ་བུ་གཞོན་ནུ་སྟེ། །
གཞན་དུ་འཛིན་པ་སྨིག་རྒྱུ་ཆུ། །
བདག་འཛིན་ཕུང་བྱེད་ཉི་ཟེར་གཟུགས། །
སྣང་བ་གཉིས་ལྡན་ནེ་ཙོའི་བྱ། །
དོར་བ་ཐུར་མ་འཁྲུལ་པའི་གཟུགས། །
ལྟ་བས་ང་རྒྱལ་ཆོས་ཀྱི་ཝ། །
སྒོམ་ལ་དེར་འཛིན་ཨ་ནུ་ལྟ། །
སྤྱོད་པས་ང་རྒྱལ་འཛིན་ན་པ། །
དཀའ་བས་རློམ་སེམས་བཟང་སྐྱོང་བུ། །
དབང་གི་བུ་གྲོལ་འདོད་ཀོས་ལ། །
རྟོགས་པས་ཆོག་ཟེར་དཔལ་གྱི་བུ། །
བླ་མ་བླ་བྲལ་བླ་མེད་གངྒཱ་མོ། །
བཀའ་ལ་སྐུར་འདེབས་ཀྲྀཥྞ་པ། །
བདེ་བས་གྲུབ་འདོད་ཐངས་བཟང་གླུ། །
སྟོང་པས་དེ་བཞིན་གདོལ་པ་ཛ། །
དེ་རྣམས་བྲལ་བའི་ཤེས་པ་ནི། །
ནོར་བུ་རིན་ཆེན་ཐོབ་པ་འདྲ། །
```

阿阇黎龙树藏说：

希望的比喻，像迦毗罗女；恐惧，像少年王子；向别处执取，像阳焰之水；毁灭自己的我执，像日光中的形相；

具二种显现，像［双头的］鹦鹉；舍弃，像［金］簪——迷乱之相；以见解起我慢，像染色的豺；在修习中执著于它，像阿努；

以行持起我慢，像持那巴；以苦行而自负，像贤护［王］之女；以灌顶求解脱，像憍萨罗［王］；以证悟为满足，像吉祥之子；

不依上师、离开上师，像恒伽女；诽谤佛语，像黑者；以安乐求成就，像唐桑鲁［王］；以空性［为执］也是如此，像旃陀罗杂。

远离这些的认知，就像获得了如意宝珠。

【按】这十八句就是题名所说的"四偈半"：每四句一偈，共四偈，最后两句是半偈。前十六句列举十六种过患及其比喻，最后两句说远离这些过患的认知如同如意宝珠。各比喻的意义，要看下面对应的故事才能明白。

几处文字的问题：
- "染色的豺"，藏文作"ཆོས་ཀྱི་ཝ"（法之豺），从第七个故事看，应是"ཚོས་ཀྱི་ཝ"（染料之豺），即掉进染缸而被染色的豺，"chos"（法）是"tshos"（染料）的误写。
- "像阿努"（ཨ་ནུ་ལྟ），第八个故事的主人公是比丘"雅舒哈"（ya shu ha），"阿努"与之对不上，可能是另一个名字或误写，存疑。
- "以灌顶求解脱"，藏文作"དབང་གི་བུ་གྲོལ་འདོད"，其中"bu"（子）字意思不通，可能是衍文或误写，这里依第十一个故事的内容译出，存疑。
- "吉祥之子"（dpal gyi bu），第十二个故事的主人公是"吉祥狮子"（śrī siṃha），"子"字可能是"狮子"（seng ge）的省略或误写，存疑。
- "不依上师、离开上师"，藏文作"བླ་མ་བླ་བྲལ་བླ་མེད"，字面是"上师、离上、无上"，意思是离开上师、不以上师为上，这里依第十三个故事的标题"不依上师"译出。
- "黑者"（ཀྲྀཥྞ་པ），即第十四个故事中的迦尔纳王之子黑者（Kṛṣṇa），不是大成就者黑行者（Kāṇha）。
- "唐桑鲁"（ཐངས་བཟང་གླུ），第十五个故事中作"唐桑鲁王"（rgyal po thang bzang glu），意思大约是"美原之歌"，这里音译。

## 二、希望：迦毗罗女（第一）

很久以前，在婆罗痆斯国，有一位名叫普拉莫哈的居士，与迦毗罗女、舟眼女两人，［相约］在尼连禅河岸边、草地上一处芳香之地定了时间［相会］。可是［迦毗罗］女在那里等了五天五夜，他都没有来。

于是她垂头丧气地回到母亲身边。母亲说："女儿啊，你的容色为什么这样憔悴呢？"女儿说：

```
ཀྱེ་མཚན་མོ་གཉིས་དང་གཉིས་གསུམ་བར། །
ཁྱིམ་བདག་གཞོན་ནུ་ལ་བསྡད་པས། །
ཡིད་གདུངས་པས་ནི་ཡི་ཆད་གྱུར། །
ཟས་དང་བྲལ་བ་ལྟོ་བ་ལྟོགས། །
```

"唉！我在那里等那年轻的居士，等了两夜，又等了两三夜；心中焦急，已经绝望了；没有饭吃，肚子饿了。"

母亲就给了她满满一碗米饭。她吃得太快，饭进到了肺腔里，头也昏乱了。于是去看一位大医师，医师问："这些是怎么回事？"她就把上面的事讲了。医师说：

```
གང་གིས་གང་ལ་རེ་བ་ནི། །
ཞི་བར་མི་འགྱུར་བདེར་མི་འགྱུར། །
སྡུག་བསྔལ་སྣ་ཚོགས་འཕེལ་བ་སྟེ། །
རེ་བ་མེད་པས་བདེ་བའི་མཆོག །
```

"无论谁对什么抱有希望，都不会平静，也不会安乐，只会增长种种痛苦；没有希望，才是最上的安乐。"

这些是开示因希望而毁灭，是令人无所希望的口诀，第一。

【按】"普拉莫哈"（pra mo ha），梵文可能是 Pramoha，意为"迷惑"，这个名字本身可能就有寓意，存疑。"舟眼女"（gru spyan mo），意思不明，这里依字面意译；从下文只说"［迦毗罗］女"等待来看，两位女子中主要人物是迦毗罗女。"草地上一处芳香之地"，藏文作"ནེའུ་སིང་པོས་ངད་ཅན"，"ne'u sing"是草地，"ngad can"是有香气之处，这里依字面译出，存疑。"饭进到了肺腔里"（glo ba'i sul du song），意思是噎住呛入，存疑。

这个故事的寓意是：迦毗罗女因为对居士的希望而等待、焦急、饥饿，乃至因急食而病倒；希望本身就是痛苦的根源。这正是大手印"离希惧"中的"离希望"。

## 三、恐惧：少年王子（第二）

很久以前，有一位名叫"贤客"的王子。他的父亲，出身力量强大的刹帝利种姓，在他头顶上为他灌顶［即位］，并说："王子啊，你要认真看守城门，努力不要让王位落到别人手里！"说完就去世了。

后来，在行法施的时候，有一位名叫"前行"的婆罗门来到王宫。［王子］因为担心王位被夺，就起身去做守门的事。弟弟趁他离开，就夺走了王位。

后来迦毗罗女问："那么，你为什么要那样费力呢？"那失去王位的［王子］说：

```
བདག་ལ་ཡབ་ཀྱིས་གདམས་པ་བཞིན། །
ཁྲི་སྟན་ཤོར་གྱིས་དོགས་པ་ན། །
སྒོ་ཡི་བྱ་བ་ལ་ཕྱིན་པས། །
ནུ་བོས་བདག་གིས་བདེ་བ་ཕྲོགས། །
```

"照着父亲对我的嘱咐，我因为担心失去王座，就去做守门的事；［结果］弟弟把我的安乐夺走了。"

婆罗门说：

```
དོགས་པ་དང་བཅས་སེམས་ཀྱིས་བདེ་མི་རྙེད། །
ཉམ་ང་དང་བཅས་རྟག་ཏུ་བདེ་མི་འགྱུར། །
གང་ལ་དོགས་ཡོད་དེ་འཇིག་ཡོད་པའི་ཕྱིར། །
མཁས་པ་རྣམས་ཀྱིས་དོགས་པ་སྤང་བར་བྱ། །
```

"心中怀着疑惧，就得不到安乐；带着畏怯，就永远不会安乐。因为哪里有疑惧，哪里就有毁灭，所以智者们应当舍弃疑惧。"

这是令人远离恐惧的口诀，第二。

【按】"恐惧"，根本颂作"དོག་པ"，故事标题作"དོག་པ"，偈中作"དོགས་པ"（疑惧、担心），意思相同。"贤客"（mgron bzang）、"前行"（mdun na 'gro），都是依藏文意译的人名。"弟弟趁他离开"，藏文作"ནུ་བོ་འགྲོ་བས་རྟེན་པས"，意思是弟弟利用他离开［王座］的机会，存疑。"迦毗罗女"在这里又出现，与第一个故事中的迦毗罗女是否同一人，原文没有说明，存疑。

这个故事的寓意是：王子越是害怕失去王位，越是去做本不该做的守门之事，结果反而失去了王位；恐惧本身就招致所恐惧的事。

## 四、向别处寻求：阳焰之水（第三）

很久以前，有一位名叫"无草"的比丘去灵鹫山。他口渴得厉害，把阳焰误认为水，就跑去喝；结果疲惫不堪，只好坐下来吃青草灌木。仙人足目说：

```
བགྲོད་དཀའ་འཁོར་བའི་ཐང་ཆེན་ལ། །
གཞན་དུ་བཙལ་འདོད་མི་དག་ནི། །
ཉོན་མོངས་ཐོ་བས་གདུངས་འགྱུར་ཏེ། །
སྐོམ་པ་སྨིག་རྒྱུའི་ཆུ་འཚོལ་འདྲ། །
```

"在难以穿越的轮回大荒原上，想要到别处去寻找［解脱］的人们，被烦恼的炎热所煎熬，就像口渴的人寻找阳焰之水一样。"

这些是［令人］舍弃所修之［对象］的口诀，第三。

【按】"无草"（sog ma med），依藏文意译。"足目"（rkang mig，梵 Akṣapāda），是印度正理派的创始者，这里作为仙人出现。"青草灌木"，藏文作"སྔོའི་ལྡུམ་བུ"，存疑。"烦恼的炎热"，藏文"ཐོ་བ"（锤子）意思不通，可能是"tsha ba"（炎热）或"gdung ba"之误，这里依上下文译出，存疑。

这个故事的标题是"舍弃所修的口诀"，而根本颂的比喻是"向别处执取，像阳焰之水"，两者不完全对应。从偈意看，所说的是：不要离开自心而向别处寻求真理，就像不要把阳焰当成水去追逐；标题中的"所修"，可能是指把真理当作心外的所修对象去寻求，存疑。

## 五、我执：日光中的形相（第四）

很久以前，股生王有五百位王后、一千个儿子。他向仙人吉祥喜女祈求而得到一位王子，因为［对这位王子来说，像他这样的人］再也没有第二个，所以［国王］对他非常珍爱。王子也［认为］：没有人比自己更珍贵；连一点点痛苦的刺都舍不得让自己受；如果自己死了，整个眷属都会毁灭。

有一天早上，他沐浴之后，在宫殿的顶上面向东方，对着阳光微微闭眼坐着。在阳光的闪烁中，他看见出现了一片尸陀林，心想："我会被污秽所染！"就逃跑，结果从宫殿顶上摔下来死了。

于是，近事男"善慧"说：

```
བདག་ཏུ་འཛིན་པ་ཆེས་པས་སྡུག་བསྔལ་འབྱུང་བ་སྟེ། །
བདག་བདེ་འདོད་པས་གཞན་གྱིས་གནོད་པ་བྱུང་། །
བདག་ཏུ་འཛིན་པ་ཡོངས་སུ་དོར་བྱས་ནས། །
སེམས་ཅན་ཀུན་ཀྱང་སྨན་པ་བཞིན་དུ་བྱ། །
```

"由于我执太重，就会产生痛苦；想要自己的安乐，［反而］受到他人［或他物］的伤害。完全舍弃了我执之后，要像医生那样［对待］一切众生。"

这是令人远离我执的口诀，第四。

【按】"股生王"（rgyal po brla skyes），依藏文意译，梵文可能是 Ūrujāta 一类的名字。"他向仙人吉祥喜女祈求而得到一位王子"，藏文作"སྲས་ནམ་ག་རུ་དྲང་སྲོང་དཔལ་དགའ་མོ་བསླངས་ཏེ"，其中"nam ga ru"意思不明，可能是人名或"nam zhig"（某时）之误，存疑。"因为再也没有第二个"（de gcig bu med pas），意思不很清楚，存疑。"受到他人的伤害"，藏文作"གཞན་གྱིས་གནོད་པ་བྱུང"，故事中王子是被自己的恐惧所害，"他人"可能泛指外境，存疑。

这个故事的寓意是：王子因为过于珍爱自己，看到阳光中幻现的尸陀林就惊恐逃跑，反而摔死；我执就像把日光中的幻影当真，越要保护自己，越是自取灭亡。

## 六、二取显现：双头鹦鹉（第五）

很久以前，在祇陀林中，王子一切义成与黑魔天授两人，转生为同一个鹦鹉身体上的两个头。

有一次，在天授那个头睡着的时候，义成找到了一种树根做的药，还有［一种叫作］"诃罗"的毒，［他想：］"［药的］精华［对身体来说］是一样的，［但］利益的滋味，就由我自己来品尝吧！"于是吃了药。魔天授［醒来］打了一个药味的嗝，非常愤怒，天授就吃了毒药，结果两者都毁灭了。

于是天王帝释说：

```
དེ་ཉིད་མཐོང་བའི་མཁས་པ་ཡིས། །
སྨན་ལྷའི་བསོད་ནམས་མི་བསླང་ཞིང་། །
དུག་ལྟ་མི་མཐུན་དོར་མི་བྱ། །
བླང་དང་དོར་བས་ཕུང་བར་འགྱུར། །
```

"见到真性的智者，不会去求取药的福德，也不会把毒视为不顺而舍弃；因为取舍会导致毁灭。"

这是令人远离取舍的口诀，第五。

【按】"一切义成"（don thams cad grub pa，Sarvārthasiddha），即释迦牟尼佛出家前的名字；"天授"（lha sbyin，Devadatta），是佛的堂弟，经中常作为与佛对立的人物；这里说他是"黑魔"。两人转生为一身双头的鹦鹉，是本生故事一类的寓言。"树根做的药"（shing gi rtsa ba srog pa? sman yang smra），藏文作"ཤིང་གི་རྩ་བ་སྲོག་པ་དང་། སྨན་ཡང་སྨྲ་དང་། དུག་ཧ་ལ་གཉིས"，文字有误，这里依大意译出，存疑。"药的福德"，藏文作"སྨན་ལྷའི་བསོད་ནམས"（药神的福德），存疑。

根本颂中这个比喻对应的是"具二种显现，像鹦鹉"，故事的标题则是"远离取舍的口诀"。寓意是：一身二头，本是同一个身体，却分成"我的"与"他的"，一个独占药，一个因怒服毒，结果同归于尽；这就是二取（能取所取、自他）显现与取舍的过患。

## 七、取舍：金簪——迷乱之相（第六）

很久以前，在迦毗罗城，有一位名叫"日施"的婆罗门，他有一颗能消除瘟疫、名叫"车渠"的大宝珠。这位居士［婆罗门］有两位妻子，两人都没有生儿子。

［他］与安乐城中一位名叫萨曼达的女居士约好了幽会的时间，就去了。先前的两位妻子也随后跟来了。于是［他们］躲进一棵腐朽的树干里。后来那两位妻子回去了，［婆罗门］就与萨曼达相会同寝。

这位居士头上的冠饰上，有两根金簪向上竖立着。［萨曼达］因为眼花，把它们误认成两个人，就对婆罗门说："美男子啊，我们被两个人紧紧盯住了！"婆罗门对她说："那是我的两位妻子。她们如果把我们的行为告诉国王，一定会受到惩处，所以我们逃到别的地方去吧！"

他们逃到一处林苑之后，［萨曼达］认出那原来是金簪，对自己极度的迷乱感到懊悔，于是女居士萨曼达唱了一首歌：

```
འོ་སྐོལ་མི་ཡིས་སྐྲག་ནས་བྲོས་པ་དང་། །
འཁོར་བ་དོར་བར་འདོད་ན་སྒྲུབ་པ་འདིས། །
དང་པོ་གཞི་སྟོང་པ་ཉིད་ནས་སྡུག་བསྔལ་བྱུང་སྟེ།
གཉིས་མེད་ལ་གཉིས་སུ་བརྟགས་པས་གདུངས་པར་འགྱུར།
```

"我们被人吓得逃走；若想舍弃轮回，［也是］以这样的修行：最初从本来空性的基中生起了痛苦，在无二之上妄执为二，所以受煎熬。"

这是令人远离取舍的口诀，第六。

【按】这个故事讲的是成年人之间的婚外私情，原文较为简略，这里照原文译出，不加渲染。故事的情节有几处不很连贯：先说两位妻子跟来，他们躲进树干里，接着说两位妻子回去了，然后萨曼达把金簪误认为两个人，婆罗门却说"那是我的两位妻子"，似乎婆罗门也误以为妻子在附近。原文可能有脱漏，这里依字面译出，存疑。"车渠"（mu sa ra ga la ba，梵 musāragalva），是佛经中七宝之一。"一处林苑"，藏文作"ན་དཔེའི་ཚལ"，意思不明，存疑。

萨曼达的歌，藏文前两句是偈颂，后两句是散文，文句也不完整，这里依字面译出，存疑。寓意是：本来什么都没有（只是两根金簪），却因眼花而见为两个人，因而恐惧、逃跑、受苦；轮回的痛苦也是这样，在本来空性、无二之上妄执为二，才生起取舍与痛苦。

这个故事的标题与上一个故事相同，都是"远离取舍"，根本颂的比喻是"舍弃，像金簪——迷乱之相"，意思是：要舍弃的东西，就像被误认为人的金簪，本来只是迷乱之相，没有可舍的实体。

## 八、见解的我慢：染色的豺（第七）

很久以前，在摩揭陀国，有一位名叫"高丽玛"的染工女，在城边的一间茅屋里，有一个盛着赭红色染料的大缸，缸口用木条盖着。她去采花的时候，一只尸陀林的豺掉进了染料里，全身都被染成了染料的颜色。

［这只豺］到了尸陀林，遇见一只狼，狼问："喂，威严无比的你是谁？"她说："我是天上的鹿，名叫舍罗那，具有香气与美色。"于是狼专门向熊、虎、猴子、狮子等宣扬，大家都成了她的眷属。

到了月圆的时候，她到母亲那里说："我是最殊胜的、无上的、卓越的，成了百兽的女王！"母亲说："女儿啊，在适当的水中沐浴之后，住在低下的地方才安乐；出身低劣而以皮毛自傲，长久结交下去一定会毁灭。"可是她不肯放下对皮毛的骄慢。

后来她回到猛兽群中，自己发出了［豺的］叫声，就被识破是豺；狮子一吼，她就昏倒了。于是所有的野兽和猛兽，各拔下她一撮毛，和粪混在一起。

于是天子们说了偈颂：

```
སེམས་ཀྱིས་སྟོབས་ཀྱིས་མི་འགྲོ་ཞིང་། །
པགས་པས་ང་རྒྱལ་འགྲོ་བྱེད་པ། །
རྒྱུན་དུ་བདེ་བར་མ་གྱུར་ཏེ། །
སྤུ་དང་བྲལ་བས་ཝ་ཉིད་ཕུང་། །
བདེ་བས་འབྲས་བུ་བསྒྲུབས་པ་ལ། །
ཞེ་འདོད་མེད་པས་མི་འགྲོ་ཞིང་། །
གྲུབ་མཐའ་ང་རྒྱལ་འགྲོ་བྱེད་པ། །
ཝ་བཞིན་ཐལ་བར་བརླག་པར་འགྱུར། །
```

"不凭心的力量而行，却以皮毛骄慢而行，就不会恒常安乐；毛被拔光，豺就毁灭了。

以安乐来成就果，却没有真心而不行，以宗派的骄慢而行，就会像豺一样被毁成灰烬。"

这是令人远离对自己见解之骄慢的口诀，第七。

【按】这个故事是印度著名的"染色豺"寓言（见《五卷书》等），佛典中也有类似的故事。"高丽玛"（kau'u ri ma，可能是 Gaurī），"舍罗那"（sha ra na），都是音译。"在适当的水中沐浴"，藏文作"ཚད་མའི་ཆུ"（量之水），意思不很清楚，存疑。

寓意是：豺因为偶然染上了美丽的颜色，就以为自己是天鹿、百兽之王，最后一开口就露出本相而被毁；修行人若只是学到一些宗派的见解，就以此自傲，以为自己超越了一切，这种"见解的我慢"终究会使自己毁灭。偈中"以安乐来成就果，却没有真心而不行"两句，意思不很清楚，存疑。

## 九、修习的执著：雅舒哈比丘（第八）

很久以前，在憍萨罗国，有一位名叫雅舒哈的比丘，修习遮止六识聚的禅定，因而远离了风息的出入与移动，能够［入定］五百年。

当时，转轮圣王"喜净光"对他说：

```
དགེ་སློང་ཁྱོད་ཀྱིས་སེམས་ལ་ལྟོས། །
ཤེས་རབ་ཕ་རོལ་ཕྱིན་དྲུག་མ། །
ཙམ་དུ་མི་གནས་འདི་སྒོམས་ལ། །
འགོག་པའི་སྙོམས་པར་འཇུག་པ་ཐོང་། །
```

"比丘啊，你要看自己的心！［修习］般若波罗蜜多等六度，不要只停留在［无想的禅定中］；要修习这个，放下灭尽定吧！"

可是他反而诽谤这个意义，仍然执著于先前的无想［定］，因而转生为长寿天；后来又转生为边地的国王；后来又因为能忆念前世，就诽谤佛法，又因为执著于先前的无想［定］，而转生为长寿天；后来又因为忆念前世而诽谤佛法，大地当下裂开，他就堕入了无间地狱。

这些是令人在修习中远离所缘［之执著］的口诀，第八。

【按】"雅舒哈"（ya shu ha），音译；根本颂中这个比喻作"像阿努"，对不上，存疑。"喜净光"（dga' sbyangs mdangs），依藏文意译。"遮止六识聚的禅定"，就是使六识都不起作用的无想定一类禅定。

"般若波罗蜜多等六度，不要只停留在"一句，藏文作"ཤེས་རབ་ཕ་རོལ་ཕྱིན་དྲུག་མ། ཙམ་དུ་མི་གནས"，语法不很清楚，可能是"不要只停留在［禅定］那样的程度，要修习般若等六度"，这里依大意译出，存疑。

这个故事是佛教中常见的警示：无想定、灭尽定一类的禅定，若执著为究竟，只会转生长寿天，福尽之后仍堕恶趣；而且因为执著自己的定境，往往会诽谤佛法。长寿天是佛教所说的"八无暇"之一。这与梅纪巴一系所批评的"闭眼什么都不见就是不作意"（《真如十颂广释》第三十节）的错误相同。

## 十、行持的我慢：持那巴婆罗门（第九）

很久以前，有一位名叫"持那巴"的婆罗门，在凉亭中睡觉时梦见［有人对他说］："善男子，看一看清净的行持！从业中生起了殊胜的菩提心之后，离开了般若的五度，并不是最上的，连'波罗蜜多'的名字都得不到。为什么呢？因为一切法都是不可言说的。"

虽然这样告诉了他，他还是没有远离对［行持的］显现执著。他被魔王他化自在天所加持，获得了有顶天的安乐，后来又堕入了恶趣。

这是令人远离对行持之执著的口诀，第九。

【按】"持那巴"（'dzin na pa），音译兼意译，存疑。"看一看清净的行持"，藏文作"གཙང་མའི་སྤྱོད་པ་ལོང་ཅིག"，"long cig"意思不很清楚，存疑。"从业中生起了殊胜的菩提心"，藏文"ལས་བྱང་ཆུབ་མཆོག་ཏུ་བསྐྱེད་ནས"，"las"可能是"从"，也可能是"业"，存疑。"离开了般若的五度"，就是《入菩萨行论》等论所说："布施等五度若离开般若，就不得称为波罗蜜多"。"他化自在天"（dga' rab dbang phyug），欲界第六天之主，常作为魔王出现。"有顶"（srid pa'i rtse mo），即三界最高的非想非非想处天。

这个故事没有偈颂，寓意是：执著于布施、持戒等外在的善行，而不配合般若，即使能得到很高的福报，终究还会堕落。

## 十一、苦行的自负：贤护王之女（第十）

很久以前，贤护王的女儿，以身、语、意与受用，承事一位名叫"生主母"的比丘尼，达六年之久；她修了二十种具足资粮道十三种征相的行持，听到多少就修学多少。

于是，比丘尼"吉祥女"说："喂，我要把一切轮回的心要——涅槃的真性给你，你就能从对轮回的恐惧中彻底解脱。"女儿说："比丘尼，从前那些喜乐的果就是最殊胜的了，因为不会再有比它更殊胜的果，所以我不要。"

吉祥女说：

```
ཆོས་ཀྱི་གསུང་ཉིད་མི་ཤེས་པར། །
འབྲས་བུ་འདོད་པའི་དཀའ་ཐུབ་དག །
རྒྱལ་པོ་དག་གི་ཕོ་ཉ་བཞིན། །
དཀའ་བས་མང་ཡང་དོན་ཆུང་འགྱུར། །
```

"不懂得法的言教，而希求果报的苦行，就像国王们的使者，辛苦很多，意义却很小。"

这是［令人远离］以为作了很多苦行就已足够的口诀，第十。

【按】"贤护王"（rgyal po bzang skyong，梵 Bhadrapāla），"生主母"（skye dgu'i bdag mo，梵 Prajāpatī，即佛的姨母摩诃波阇波提），"吉祥女"（dpal mo，梵 Śrīmatī），依藏文意译或对出的梵文译出。"二十种具足资粮道十三种征相的行持"，藏文作"ཚོགས་ཀྱི་ལམ་རྟགས་བཅུ་གསུམ་དང་ལྡན་པའི་སྤྱོད་པ་བཅུ་ཕྲག་གཉིས"，具体所指不明，存疑。"国王们的使者"，比喻奔波劳苦却只是为别人传话，自己得不到真正的利益。

最后的标题，藏文作"དཀའ་བས་མང་པོ་བྱས་པས་ཆོག་པར་འཛིན་པར་བྱ་བ"，字面是"［令人］执持以为作了很多苦行就已足够"，显然脱漏了"远离"（dang bral bar）一词，这里依根本颂"以苦行而自负"补出。

## 十二、以灌顶为足：憍萨罗王（第十一）

《吉祥最胜本初续》中说：

```
དཔལ་མཆོག་དང་པོ་དབང་ལས་འབྱུང་། །
ལུས་ངག་ཡིད་ཀྱི་ཐ་བ་དག །
དབང་གིས་རབ་ཏུ་སྨིན་བྱས་ན། །
དཔལ་མཆོག་དང་པོ་ཐོབ་པར་འགྱུར། །
```

"吉祥最胜本初，从灌顶而生；身、语、意的污垢，若以灌顶使之成熟，就能获得吉祥最胜本初。"

憍萨罗王看到这段话之后，就从因陀罗菩提王那里接受了十七次灌顶。

于是因陀罗菩提王说："大王啊，殊胜的［灌顶］就像种子；恒常的串习，就像以水和肥料使苗生长；行持，就像使庄稼成熟。所以，大王应当串习修持。"虽然这样说了，他还是因为先前的经文［所说］，坚决不肯改变。

于是空行母说了偈颂：

```
དབང་གིས་ཡེ་ཤེས་མཚོན་བྱས་ཤིང་། །
འོས་སུ་རུང་བར་བྱར་འདོད་ཀྱང་། །
གོམས་བྲལ་ཆུ་ཤིང་འབྲས་བུ་ལྟར། །
ལན་ཅིག་སྐྱེད་ན་ཟད་འགྱུར་ཉིད། །
```

"即使以灌顶指示了智慧，想要使它成熟，［若］没有串习，就像芭蕉的果实那样，只结一次就枯尽了。"

所以要串习。这是令人远离以为只要有灌顶就已足够的口诀，第十一。

【按】"《吉祥最胜本初续》"（dpal mchog dang po，梵 Śrīparamādya），是瑜伽续部的重要续典。"因陀罗菩提"（Indrabhūti），是印度著名的成就者国王，传说是乌仗那国王。"芭蕉"（chu shing），芭蕉一生只结一次果，结果后就枯死，比喻只有灌顶而不串习，即使有一点体验，也会很快消失。

这个故事的寓意是：灌顶只是播下种子，若不串习修持，就像只结一次果的芭蕉，不会有真正的成就。这正是《真如十颂广释》所批评的"以为只要有灌顶就已足够"。

## 十三、以证悟为足：吉祥狮子（第十二）

吉祥东比嘿噜嘎的一位弟子，名叫吉祥狮子，在空行母与男女瑜伽士举行会供轮的时候说：

```
ཆོས་རྣམས་སྟོང་པར་རྟོགས་པ་ཡིས། །
དེ་ཡི་མཐའ་ལ་སྒོམ་དུ་མེད། །
གལ་ཏེ་སྒོམ་ན་དམན་འགྱུར་ཏེ། །
དཔེར་ན་རྒྱལ་པོ་རྒྱལ་པོར་ནི། །
སླར་ཡང་འདོད་པ་མེད་པ་བཞིན། །
བུདྡྷ་ཐམས་ཅད་སྟོང་པ་ཉིད་དུ་གཅིག་པར་རྟོགས་ནས་སྒོམ་མི་དགོས།
སྒོམ་སོགས་སྦྱིན་སྲེག་ཐལ་བ་འདྲ། །
```

"由于证悟了诸法是空，［所以］在它的究竟上没有什么要修的；如果还去修，就成了低劣的，就像国王不会再想要当国王一样。证悟一切佛都在空性中同一，［就］不需要修；修等就像火供之后的灰烬。"

所有的金刚空行母都说："喂，你这个窃取佛陀秘密、有邪恶贪求的人，听着！看见初一的月亮，那就是满月吗？婴儿刚出生，就力量圆满了吗？种子刚种下，果实就丰收了吗？看见大海中的宝珠，就到手了吗？仅仅发了菩提心，就能利益众生了吗？看见食物，就解除饥饿了吗？［你这样说］是因为无明。如果以串习的眷属来使证悟这位主人欢喜，就会获得双运的智慧。以证悟为满足的，是断见者，是外道，是魔当下所加持的，是自己毁灭自己。"

说完，［空行母们］就把他杀了，作为空行母的受用。

这是令人远离以证悟为满足的口诀，第十二。

【按】"东比嘿噜嘎"（ḍombi heruka），是印度大成就者之一，以与一位低种姓女子共修而著称。"吉祥狮子"（śrī siṃha），是他的弟子，与大圆满传承中的吉祥狮子同名，是否同一人原文没有说明，从时代与故事看应是另一人，存疑。

"修等就像火供之后的灰烬"一句前，藏文有"བུདྡྷ་ཐམས་ཅད་སྟོང་པ་ཉིད་དུ་གཅིག་པར་རྟོགས་ནས་སྒོམ་མི་དགོས"一段散文，混在偈颂中间，这里一并译出。"以串习的眷属来使证悟这位主人欢喜"，藏文作"རྟོགས་པའི་གཙོ་བོ་ལ་གགས་གོམས་པའི་འཁོར་གྱིས་མཉེས་པར་བྱ"，其中"gags"意思不明，可能是衍字或误写，这里依大意译出，存疑。"断见者"，藏文作"སྲུན་པ"，意思不明，可能是"chad pa"（断见）一类词的误写，存疑。

空行母们"把他杀了，作为空行母的受用"，是成就者传说中常见的象征性情节，意在极言以证悟为足的过患之重——这种人是"自己毁灭自己"。这不能照字面理解为对暴力的认可。

这个故事的核心，是空行母们的六个比喻：初一的月亮不是满月，初生的婴儿不是力量圆满，刚播的种子不是丰收，看见的宝珠不是到手，仅发心不能利生，看见食物不能解饿。初步的证悟（见道）必须以串习（修道）来圆满，才能获得双运的智慧。这与梅纪巴一系"见、修、行、果"次第的教导一致，也是大手印传承中对"一悟即了、不必再修"之说最有力的破斥。

## 十四、不依上师：恒伽女（第十三）

法护王的女儿，名叫恒伽女，阅读了如来所有的经与续，生起了［自以为］如实的证悟，就去修习。

后来，在罗刹们供养大菩提［寺］的那一夜，恒伽女来到所有瑜伽士举行会供轮的地方。所有的瑜伽士都被空行母所加持，身体腾空而起，口中发出欢喜的声音，心中却［对她］充满敌意。于是恒伽女先前的证悟就消失了。

她对瑜伽士们说："唉，我做了什么不应该做的事？请你们告诉我！"所有的瑜伽士异口同声地说：

```
བླ་མ་ལས་ནི་དངོས་གྲུབ་རྙེད། །
རིག་མ་ལས་ནི་བདེ་བ་འབྱུང་། །
བླ་མ་བྲལ་བའི་དངོས་གྲུབ་ནི། །
ཁྲི་ཕྲག་འབད་ཀྱང་ཐོབ་མི་འགྱུར། །
གཞན་གྱིས་དངོས་གྲུབ་འབྱུང་བྱེད་པ། །
དུག་དང་བཅས་པའི་ཟས་བཞིན་ནོ། །
མཁའ་འགྲོ་ཀུན་གྱིས་འཚེ་བ་དང་། །
བར་ཆད་སྣ་ཚོགས་འབྱུང་བར་འགྱུར། །
```

"从上师那里得到悉地，从明妃那里生起安乐；离开上师的悉地，即使努力千万次也得不到。从别处产生的悉地，就像有毒的食物；一切空行母都会加害，种种障碍都会出现。"

这样使她生起了信心。这是令人舍弃不依上师［之过］的口诀，第十三。

【按】"法护王"（Dharmapāla），可能是指印度波罗王朝的达摩波罗王（约八至九世纪），存疑。"大菩提"（byang chub chen po），可能指菩提伽耶的大菩提寺，存疑。"心中却对她充满敌意"，藏文作"ཡིད་ཀྱིས་ཀུན་དུ་ཞེ་སྡང་བར་བྱས"，意思不很清楚，可能是指对她不依上师而生起的忿怒，存疑。"从明妃那里生起安乐"（rig ma las ni bde ba 'byung），是密续中的象征用语，须依具德上师的灌顶与口授来理解。

这个故事的寓意是：即使阅读了所有的经续，自以为有了证悟，若不依止上师，这种证悟也不稳固，遇到外缘就会消失；而且从别处得来的悉地像有毒的食物，会招致障碍。这与梅纪巴《真如十颂》"没有上师口诀庄严的中观只是中等"的意思一致。

## 十五、诽谤佛语：黑者（第十四）

迦尔纳王的儿子，名叫黑者，把中观视为最上，而诽谤其余一切佛语与论典。［结果他］被北方的夜叉所执持而发疯了。

他的父王就去请求密咒师们，作了驱除魔障的修法。吉祥那洛巴说：

```
སངས་རྒྱས་དགོངས་པ་དཔག་བསམ་ཤིང་ལྟ་བུའི་གསུང་དག་ལ། །
སེམས་ཅན་བློའི་ཐེག་པ་སྣ་ཚོགས་བྱས། །
ཕྱོགས་མེད་ཕྱོགས་སུ་འཛིན་པའི་བདུད་ཆེན་གྱིས། །
འདི་དང་མ་འོངས་གཉིས་ཀར་སླུ་བར་འགྱུར། །
འགྲོ་བའི་བློ་ལ་ཐམས་ཅད་བདེན་པ་ཉིད། །
དོན་དམ་ཡུལ་དུ་གང་ཡང་ཡོད་མ་ཡིན། །
དེ་ཉིད་རྣལ་འབྱོར་སེམས་སུ་དབྱེར་མི་ཕྱེད། །
བཀའ་ལ་སྐུར་པ་འདེབས་པ་དམྱལ་བའི་གནས་སུ་འགྲོ། །
```

"佛陀的密意，就像如意宝树一样的言教，［随着］众生的心，成为种种的乘；执著于无偏为有偏的大魔，会使今生与来世两者都被欺骗。

对于众生的心来说，一切都是真实的；在胜义的境界中，什么也不存在；那真性，在瑜伽士的心中是不可分割的。诽谤佛语，就会堕入地狱。"

所以，不要诽谤一切佛语，第十四。

【按】"迦尔纳王"（karṇa），可能是指印度东部的迦尔纳苏伐剌那国一类的国王，存疑。"黑者"（kṛṣṇa），不是大成就者黑行者（Kāṇha）。"那洛巴"（Nāropa），是帝洛巴的弟子、马尔巴的上师，噶举派的重要祖师。

那洛巴的偈颂说明：佛陀的言教像如意宝树，随众生根器而开出种种乘，各有其用；执著某一宗派为唯一真理而诽谤其余，正是"执著无偏为有偏"的大魔。在世俗中，对众生的心来说，种种乘都是真实的；在胜义中，一切都不存在；而这两者在瑜伽士的心中是不可分的。这与《真如十颂广释》第三十六节所说"波罗蜜多乘并不低劣"，以及译师粗敦对"喜欢广博论典而反对心要"者的批评，可以互相参看：真正的中观或大手印行者，不会偏执一宗而诽谤其余。

## 十六、贪著安乐：唐桑鲁王（第十五）

有一位名叫唐桑鲁的国王，从吉祥甘巴拉处接受了灌顶，在乌仗那的尸陀林中修习安乐。尸陀林中所有的饿鬼都来障碍他，他的心非常散乱。

他去请问瑜伽母"善熟迦罗罗"，她说：

```
ལས་ཀྱི་ཕྱག་རྒྱ་བདེ་བའི་གྲུ། །
སྟོང་པའི་སྐམ་ས་རྙེད་ནས་ཅི་བྱར་ཡོད། །
བཅོས་མའི་བདེ་ལ་བཅོས་མའི་ཡིད་ཞེན་ན། །
འཁོར་བའི་མཚོ་ཆེན་རྒལ་བར་ནུས་མ་ཡིན། །
```

"业手印，是安乐的船；［若］已到达空性的陆地，还要［船］做什么呢？若以造作的心贪著造作的安乐，就不能渡过轮回的大海。"

所有的瑜伽士都专门对王后宣说了［这首偈］。这是令人舍弃对安乐之贪著的口诀，第十五。

【按】"甘巴拉"（Kambala，la ba pa，"披毛毡者"），见《真如十颂广释》第十二节按语，是印度大成就者。"乌仗那"（uḍḍiyāna），是密续传说中空行母聚集的圣地。"善熟迦罗罗"（legs smin kā ra la），音译兼意译，存疑。"所有的瑜伽士都专门对王后宣说"，藏文作"ལྷ་ལྕམ་ལ་རྣལ་འབྱོར་པ་ཐམས་ཅད་ཀྱིས་ཆེད་དུ་བརྗོད་པ་བྱས"，"王后"在故事中没有出现过，与上下文的关系不清楚，存疑。

这首偈是本篇最重要的偈颂之一："业手印是安乐的船，到了空性的彼岸，就不再需要船；若以造作的心贪著造作的安乐，就不能渡过轮回之海。"这与《灌顶教示难释》第四十九节、《金刚句》第十三节所说"由二根所生的安乐不是真如""被五大所围绕的安乐并不是真性"意思完全一致。业手印是无上瑜伽续中有极严格条件的修法，只能在具德上师座前依灌顶与口授来理解，这里不作任何解说。

## 十七、执著空性：旃陀罗杂（第十六）

有一位名叫"杂"的旃陀罗，依止大阿阇黎古古日巴，缘于胜义之心，修习片面的圆满次第，结果执著一切法都是无所依的［空无］。

后来，在阇烂达罗国，瘟疫使大多数人都死了，所有的庄稼都被冰雹摧毁，五年没有下雨。人们去问一位通晓秘语的婆罗门，他说："这个地方住着一个佛教徒，却倾向于秘密宣说外道的宗义而住，所以出现了种种不祥：在这一世毁灭别人，在来世毁灭自己。"

吉祥古古日巴听说了，就来到旃陀罗杂那里说：

```
དང་པོ་དངོས་པོའི་ཆོས་རྣམས་ནི། །
སྟོང་པ་ཉིད་ཀྱིས་བཟློག་པར་བྱ། །
སྟོང་པ་ཉིད་ལ་ཞེན་ཆེས་ནས། །
དངོས་འཛིན་པས་ཀྱང་ཕུང་བར་གྱུར། །
དུག་སྦྲུལ་ཤི་ན་དར་ཡ་ཀན། །
དུག་ལ་སྔགས་བཏབ་སྨན་གྱི་མཆོག །
གང་ལ་རྒྱས་བཏབ་བདེ་འགྱུར་ཕྱིར། །
ཞེན་པ་ཐོང་ལ་གཉིས་མེད་སྒོམས། །
```

"最初，要以空性来遮止对诸实有法［的执著］；［可是］若过于执著空性，也会像执著实有一样毁灭。

毒蛇死了，［还要］……；在毒上念诵密咒，［毒就成为］最上的药；因为对任何事物加以印定，都能成为安乐，所以要放下执著，修习无二！"

然后［古古日巴］为他授了第三灌顶。

【按】"杂"（dza），音译，是一位旃陀罗（最低种姓）的修行人。"古古日巴"（kukkuripa），是印度大成就者之一，传说与一只母狗同住，是马尔巴的上师之一。"阇烂达罗"（jālandhara），是印度西北的圣地，密续二十四圣地之一。

"片面的圆满次第"（rdzogs pa'i rim pa phyogs gcig pa），意思是只偏重空性一面的圆满次第修法。"执著一切法都是无所依的"，藏文作"བརྟེན་མེད་དུ་ཞེན་པ"，意思是执著空无而落入断见。"秘密宣说外道的宗义"，藏文作"ཕྱི་རོལ་གྱི་གྲུབ་མཐའ་གསང་པར་སྨྲ་བ་ལ་ཕྱོགས"，意思是这位佛教徒表面上是佛教徒，实际上所持的是外道（断见）的宗义，存疑。

古古日巴偈中"毒蛇死了，［还要］……"一句，藏文作"དུག་སྦྲུལ་ཤི་ན་དར་ཡ་ཀན"，"dar ya kan"意思不明，可能是某种解毒药或梵文词的音译，存疑。"然后为他授了第三灌顶"，藏文作"ཞེན་ནས་དབང་གསུམ་པ་མཛད་དོ"，"zhen nas"（执著之后）意思不通，应是"de nas"（然后）的误写；"第三灌顶"即智慧智灌顶，是无上瑜伽续的内容，须依具德上师的灌顶与口授来理解。

这个故事没有标明"第十六"，也没有"令人远离……的口诀"的标题，应是传写时脱漏，或者因为是最后一个故事而省去了。寓意是：空性本是用来对治实有执著的药，若执著空性，就像吃了药又被药所害；所以连对空性的执著也要放下，修习空有无二。这正是《真如十颂广释》第五节所说"凡是开示唯空的地方，那里所开示的只是以智慧一分为主"、"生与不生的双运才是应当证悟的真性"。

## 十八、结说与跋

这样，阿阇黎龙树讲了十个过去的例子，因为与经和续相合，所以要了知佛就是佛；讲了六个未来的例子，因为与获得成就［的事迹］相合，所以要了知［他是］一切智者。

远离这十六种［过患之］缘的认知，因为就是佛陀的密意，所以像如意宝珠。

《四偈半》，阿阇黎龙树藏所说，圆满。

在吉祥山，由大主宰［所传］；由尊者山居者［夏瓦日巴］所授与；他传给尊者迦罗巴；他传给尊者那洛巴。

【按】"十个过去的例子"，指前十个故事，人物多是佛陀时代或更早的人（佛、天授、帝释、比丘、国王等），所以说"与经和续相合"；"六个未来的例子"，指后六个故事，人物是龙树之后的印度大成就者（因陀罗菩提、东比嘿噜嘎、恒伽女、那洛巴、甘巴拉、古古日巴等），从托名龙树的立场看，这些都是"未来"的事，所以说"与获得成就相合"，并以此证明龙树是"一切智者"（能预知未来）。

"要了知佛就是佛"（sangs rgyas sangs rgyas su rig par bya），意思不很清楚，可能是说"要了知［龙树］是佛"，存疑。

篇末的传承记录："在吉祥山，由大主宰"，"吉祥山"（dpal gyi ri，Śrīparvata）是传说中龙树晚年所住之山，"大主宰"（mnga' bdag chen po）应是指龙树；"由尊者山居者所授与"，即夏瓦日巴，他是梅纪巴的上师，传说他在吉祥山从龙树得法；"迦罗巴"（ka ro pa），不清楚是哪一位，可能是 Kāropa 或 Karṇaripa 一类的名字，存疑；最后传到那洛巴。这条传承说明本篇在夏瓦日巴、那洛巴一系的大手印传承中流传，与梅纪巴一系的"龙树—夏瓦日巴—梅纪巴"传承可以互相对照。

## 根本颂通篇连读

阿阇黎龙树藏说：

希望的比喻，像迦毗罗女：因希望而苦等、焦急、病倒，没有希望才是最上的安乐。

恐惧，像少年王子：越怕失去王位，越失去王位，智者应舍弃疑惧。

向别处执取，像阳焰之水：在轮回荒原上向心外寻求，就像口渴的人追逐阳焰。

毁灭自己的我执，像日光中的形相：过于珍爱自己，反被幻影吓死，要舍弃我执，像医生一样对待众生。

具二种显现，像双头鹦鹉：一身而分自他，以取舍而同归于尽。

舍弃，像金簪——迷乱之相：在无二之上妄见为二，因而恐惧逃避。

以见解起我慢，像染色的豺：以宗派之见自傲，终被识破而毁灭。

在修习中执著于它，像阿努（雅舒哈比丘）：执著无想之定，生长寿天而终堕地狱。

以行持起我慢，像持那巴：执著善行而离般若，得有顶之乐而终堕恶趣。

以苦行而自负，像贤护王之女：不懂法的言教而只求果报的苦行，辛苦多而意义少。

以灌顶求解脱，像憍萨罗王：只受灌顶而不串习，如芭蕉结果一次就枯。

以证悟为满足，像吉祥狮子：初一之月不是满月，证悟必须以串习圆满。

不依上师，像恒伽女：离开上师的悉地，努力千万次也得不到。

诽谤佛语，像黑者：执无偏为有偏，诽谤佛语堕入地狱。

以安乐求成就，像唐桑鲁王：到了空性的彼岸，不再需要安乐之船。

以空性为执也是如此，像旃陀罗杂：过于执著空性，也像执著实有一样毁灭，要放下执著，修习无二。

远离这些的认知，就像获得了如意宝珠。
