# 《大宝积经》卷第四十二（菩萨藏会·尸波罗蜜品）

唐·三藏法师玄奘 奉诏译

## 菩萨藏会第十二之八

【按】本品《尸波罗蜜品》相当于《佛说大乘菩萨藏正法经》（T0316）的《持戒波罗蜜多品》（卷十八至卷二十三）。

### 尸波罗蜜品第七之一

#### 三种妙行

那时，佛告诉舍利子：“什么是菩萨摩诃萨的尸罗波罗蜜多？菩萨摩诃萨为了阿耨多罗三藐三菩提，依此勤修而行菩萨行。舍利子！菩萨摩诃萨行尸罗波罗蜜多，有三种妙行。是哪三种？一是身妙行，二是语妙行，三是意妙行。舍利子！什么名为身妙行、语妙行、意妙行呢？舍利子！就是菩萨摩诃萨远离杀生，远离不与取，远离欲邪行，这名为身妙行。舍利子！菩萨摩诃萨远离妄语，远离离间语，远离粗恶语，远离绮语，这名为语妙行。舍利子！菩萨摩诃萨对于种种贪著、瞋恚、邪见都无所有，这名为意妙行。菩萨摩诃萨具足这样的三种妙行，这名为尸罗波罗蜜多。

“再者，舍利子！菩萨摩诃萨行尸罗波罗蜜多时，这样思惟：‘什么是身妙行、语妙行、意妙行呢？’舍利子！菩萨摩诃萨这样思惟：‘若身不造杀生、不与取、欲邪行之业，这名为身妙行。’菩萨摩诃萨这样思惟：‘若语不造妄语、离间、粗恶、绮语之业，这名为语妙行。’菩萨摩诃萨这样思惟：‘若意不造贪著、瞋恚、邪见之业，这名为意妙行。’由于具足这样的正思惟，这名为菩萨摩诃萨行尸罗波罗蜜多。

#### 尸罗不可建立，不执尸罗

“再者，舍利子！这样的菩萨摩诃萨行尸罗波罗蜜多时，这样想：‘若业不由身、语、意造作，此业可以建立吗？’菩萨摩诃萨这样如理观察：若业不由身、语、意造作，此业便不可建立，无论是青、是黄，是赤、是白，是红、是颇胝之色。此业又不是眼所识，不是耳所识，不是鼻、舌、身、意所识。为什么？舍利子！因为此业不是能生，不是所生，不是己生，不可执受，都没有能了别此业的。菩萨摩诃萨这样了知：这尸罗之性不可造作；若不可造作，便不可建立；若不可建立，我们于其中便不应执著。这样，菩萨摩诃萨由于观解之力，不见妙行以及尸罗，也不见有具足尸罗的人，不见尸罗所回向之处。菩萨摩诃萨这样观察之后，毕竟不起虚妄的有身见。为什么？舍利子！因为有身见，才可能有这样的观察：这是持戒，这是犯戒。

“这样观察之后，对于那守护以及仪则，无论行或境，都具足正知而行；因为以正知而行，所以名为持戒者。菩萨摩诃萨不取著自己、不取著他人而行于行，不毁尸罗、不取尸罗而行于行。若取著于我，就是取著尸罗；若不著于我，便不取著尸罗。若知尸罗不可得，便不毁犯所有律仪；若对律仪无所毁犯，便不名为毁犯尸罗，也不名为执取尸罗。舍利子！以什么因缘对于这尸罗而不执取？因为知道一切法都是他相。若由于他相，便没有我；若我是无，有什么可执取呢？”那时世尊想重宣此义，而说颂道：

【按】“远离离间语”之“离”，宋、元、明、宫本无；“远离粗恶语”之“离”，宋、元、明、宫、圣本无。“即不名为毁犯尸罗”之“即”，宋、元、明、宫本作“则”。“又亦不名”之“亦”，元、明本无。

原文：“谓一切法知他相故。若由他相则无有我”（大意：因为知道一切法都是他相。若由于他相，便没有我。“他相”所指未详，存疑。）

```
若有身语意清净，
行时恒修一切净，
常住清净诸禁戒，
是名菩萨具尸罗。
贤圣聪慧诸菩萨，
能善护持十业道，
不由身语及意作，
如是智者说尸罗。
若非造作非所生，
非执无形亦无显，
由无有形有显故，
未曾可得而建立。
尸罗无为亦无作，
非眼能见非耳闻，
非鼻非舌亦非身，
又非心意所能识。
若非六根之所识，
则无有能施设者，
如是观察尸罗净，
曾未依执住尸罗。
不恃持戒生憍慢，
不计我想护尸罗，
善护尸罗无戒想，
具足尸罗行觉行。
妄有身见已除遣，
见与见者曾无有，
无有能见无彼处，
不观持戒犯戒者。
善入无护法理趣，
威仪具足不思议，
妙善正知能守护，
除斯更无具戒者。
```
（大意：若有人身、语、意清净，行时恒常修习一切清净，常住于清净的诸禁戒，这名为菩萨具足尸罗。贤圣聪慧的诸菩萨，能善护持十业道，不由身、语以及意造作，这样，智者名之为尸罗。若不是造作，不是所生，不可执取，无形也无显色，由于没有有形、有显的缘故，从未可得而建立。尸罗是无为，也无造作，不是眼所能见，不是耳所能闻，不是鼻、不是舌、也不是身，又不是心意所能识知。若不是六根所能识知，便没有能施设它的人；这样观察尸罗的清净，从未依执而住于尸罗。不倚恃持戒而生憍慢，不计执我想而护持尸罗，善护尸罗而无戒想，具足尸罗而行觉悟之行。虚妄的有身见已经除遣，见与见者从未存在，没有能见，也没有那所见之处，不观察持戒者与犯戒者。善入于无护法的理趣，威仪具足，不可思议，以妙善的正知能够守护，除此之外，再没有具足戒的人。）

```
无我想者无尸罗，
无所依我能依戒，
我说究竟常无畏，
不执身我与尸罗。
说无我者不取戒，
说无我者戒无依，
说无我者不希戒，
说无我者戒无心。
不毁尸罗不执戒，
亦不计我起尸罗，
无所依我及戒想，
甚深慧行菩提行。
如是尸罗无所畏，
此人常不犯尸罗，
若能不执有诸法，
如是尸罗圣所赞。
若住我见诸愚夫，
计我具戒能持戒，
彼受护戒果终已，
于三恶趣常缠缚。
若有断尽诸我见，
彼无有我及我所，
是真持戒无见故，
无复怖畏堕诸恶。
若能如是知戒行，
无有能见犯尸罗，
尚不观我及三有，
况见持戒及犯戒。
```
（大意：没有我想的人便没有尸罗，没有所依之我能够依于戒，我说这是究竟恒常的无畏，不执著身、我与尸罗。说无我的人不取著戒，说无我的人，戒无所依；说无我的人不希求戒，说无我的人，于戒无心。不毁尸罗，不执著戒，也不计执有我而生起尸罗，没有所依之我以及戒想，这是甚深的智慧之行、菩提之行。这样的尸罗无所畏惧，此人恒常不犯尸罗；若能不执著有诸法，这样的尸罗为圣者所称赞。若住于我见的诸愚夫，计执有我具戒、能持戒，他们受用护戒的果报终了之后，常被缠缚于三恶趣中。若有人断尽一切我见，他便没有我以及我所，这是真正的持戒，因为没有见，便不再怖畏堕入诸恶趣。若能这样了知戒行，便没有能见的人犯尸罗；尚且不观察我以及三有，何况见到持戒与犯戒！）

#### 十种极重深心

“再者，舍利子！这样行尸罗波罗蜜多的菩萨摩诃萨行菩萨行、持清净戒时，具有十种极重的深心。是哪十种？一是发起深心信奉诸行，二是发起深心勤加精进，三是猛利地乐欲诸佛正法，四是广泛具足崇重一切诸业，五是深怀信奉一切果报，六是对诸贤圣深深发起敬心，七是对诸尊重的邬波柁耶、阿遮利耶清净侍奉，八是对贤圣兴起供养，九是对诸正法励意请求，十是求菩提时不顾身命。舍利子！这样行尸罗的菩萨摩诃萨有这样的十种深心之法。菩萨摩诃萨安住于深心，修种种善法。什么名为种种善法呢？就是三种妙行：身妙行、语妙行、意妙行。若诸菩萨摩诃萨安住于这样的三种妙行，是为了勤求大菩萨藏微妙法门。为什么？因为诸菩萨摩诃萨依此法门，能趣向阿耨多罗三藐三菩提。”那时世尊想重宣此义，而说颂道：

【按】“邬波柁耶”即亲教师（和尚），“阿遮利耶”即轨范师（阿阇梨）。

```
由身而发起，佛所赞善业，
为得闻法故，供养诸贤圣。
于法及圣人，猛励起恭敬，
为利诸众生，慈心不嫉妬。
当演智人言，无谈不爱语，
所说欣乐相，发语无麁鄙。
意业常居善，曾无乐诸恶，
恒观察法性，恭敬住慈心。
于如来圣教，敬心而听法，
于法恭敬已，速悟大菩提。
```
（大意：由身而发起佛所称赞的善业，为了得闻正法，供养诸贤圣。对于正法以及圣人，猛利地生起恭敬，为了利益众生，以慈心而不嫉妒。应当演说智者之言，不谈不可爱的话，所说的都是欣乐之相，发语无有粗鄙。意业常居于善，从不乐于诸恶，恒常观察法性，恭敬而住于慈心。对于如来的圣教，以敬心听法；对于正法恭敬之后，便迅速觉悟大菩提。）

“舍利子！诸菩萨摩诃萨行尸罗波罗蜜多时，安住于这样的十种最胜之法，为了勤求菩萨藏法门，对诸贤圣以及一切师长勤加恭敬，奉事供养，乃至施予贮水之器。

#### 第一发心：观病身

“再者，舍利子！菩萨摩诃萨行尸罗波罗蜜多时，应当具足这样十种发心。是哪十种？舍利子！菩萨摩诃萨观察这病身：诸界如同毒蛇，恒常互相违害，多诸苦恼，多诸过患，是癫狂、痈疖、疽癣、恶疠、风热、痰饮等众病所聚集之处。又，这身如病、如疮、如被箭刺、如暴水急流、如刽子手，摇动不息，迅速生起，迅速灭去。又观察这身虚伪羸弱，衰老朽坏，迅速败坏，只是暂时停住，难以爱乐，形状如同坟冢之间。那时菩萨又这样想：‘我这病身虽然经受这样的苦，却从未遇到这样的福田；我现在得以遇到，又善感得这样的身体，我应当依诸福田长养慧命，舍弃不坚之身，获得坚固之身。为了勤求大菩萨藏微妙法门，对那贤圣、邬波柁耶、阿遮利耶等诸尊师奉事供养，乃至施予贮水之器。’舍利子！这名为菩萨摩诃萨的第一发心。”那时世尊想重宣此义，而说颂道：

```
诸界暴毒蛇，展转相依附，
随一兴增动，生则致大患。
所谓眼耳鼻，舌齿内腹藏，
如是诸患恼，皆悉依身生。
痈疖与癫狂、疽癣大疾疠，
诸余种种病，无不依身生。
是身犹如病，如痈如中箭，
如是毒害身，速坏暂时住，
如趣彼冢间，悉是无常相，
摇鼓烂坏身，众病速生灭。
我当修佛身，所因贤善业，
```
（大意：诸界如暴烈的毒蛇，展转互相依附，随其中一种兴起增动，一生起便招致大患。就是眼、耳、鼻、舌、齿、内腹脏腑，这样的种种患恼，都依身而生。痈疖与癫狂、疽癣、大疾疠，以及其余种种疾病，无不依身而生。这身犹如疾病，如痈、如中箭，这样有毒害的身体，迅速败坏，只暂时停住，如同趋向那坟冢之间，都是无常之相；摇动、腐烂、败坏的身体，众病迅速生灭。）

```
以彼朽烂坏，衰老无常身，
转成于佛身，及难思法身。
以如是朽坏，遍常流秽身，
当证得如是，无流无秽身。
若人怖寒热，遮障坚防护，
毕为老病死，诸苦同煎害。
若人于寒热，身遍能堪忍，
庄严丈夫业，速成无上身。
我当勤供养，世所同尊重，
以不坚实身，当贸彼坚实。
```
（大意：我应当修习佛身所因的贤善之业，以那朽烂败坏、衰老无常之身，转成佛身以及难思的法身。以这样朽坏、遍常流出秽物的身体，当证得那样无漏、无秽的身体。若人怖畏寒热，遮障坚密地防护，终究被老病死等诸苦共同煎害；若人对于寒热，身体都能遍加堪忍，以丈夫之业庄严，迅速成就无上之身。我应当勤加供养世间所共同尊重的人，以不坚实的身，换取那坚实之身。）

【按】“难思法身”之“思”，宋本作“忘”。

“舍利子！诸菩萨摩诃萨行尸罗波罗蜜多时，发起这样的第一心之后，为了勤求大菩萨藏微妙法门，对说法师倍加奉事，勤加供养，乃至施予贮水之器。

#### 第二发心：观身不坚

“再者，舍利子！菩萨摩诃萨行尸罗波罗蜜多时，生起这样的念头：‘身是不坚的，其性不牢固，要借助覆盖、洗濯、按摩，而终究归于破坏、离散、磨灭之法。’舍利子！譬如陶师揉泥制作瓦器，无论大小，终究归于破坏；这样，舍利子！身是不坚的，终究归于破坏，如那瓦器。又，舍利子！譬如树枝所依附的花叶果实，终究堕落；这样，舍利子！身是不坚的，是必定堕落之法，势必不能久住，如成熟的果实等。又，舍利子！譬如草端凝结的霜露，被日光照射，必定不能停住；这样，舍利子！身是不坚的，如霜露之滴，也不能久住。又，舍利子！譬如大海以及众多河流中有泡沫之聚，一切都不坚固，其性虚弱，不可敲触；这样，舍利子！这身不坚，犹如泡沫之聚，其本性虚弱也是这样。又，舍利子！如天降大雨，流泡纷乱浮动，慢慢生起，慢慢灭去；这样，舍利子！身是不坚的，如水上之泡，其性轻薄也是这样。舍利子！菩萨摩诃萨深自观身，见到这些事之后，又这样想：‘我在长夜中感得这样不坚固的身体，从未遇到这样的福田；我现在得以遇到，又善感得这样的身体，我应当依诸福田长养慧命，以不坚之身换取坚固之身，为了勤求大菩萨藏微妙法门，对说法师奉事供养，乃至施予贮水之器。’舍利子！这名为菩萨摩诃萨的第二发心。”那时世尊想重宣此义，而说颂道：

【按】“𢾊”字（敲之“高”易为“亭”）先前电子文本未能显示，今据《大正藏》补出，宋、宫本作“敦”，此依文意译作“敲触”。“徐起徐灭”，元、明、圣本作“速起速灭”。

```
如世诸陶师，埏埴坏成器，
皆当归破坏，众生命如是。
譬如依树枝，所有叶花果，
皆归堕落法，人命亦如是。
如草端垂露，日光之所照，
须臾不暂停，人命亦如是。
如河海聚沫，其性本虚弱，
如是不坚身，虚浮亦如是。
譬如天大雨，生起水浮泡，
刹那速消灭，不坚身亦尔。
不坚起坚想，于坚想不坚，
邪分别所行，不能证坚实。
于坚起坚智，不坚知不坚，
正分别所行，能证于坚实。
为修坚实想，微施于水器，
故以不坚身，贸易彼坚实。
```
（大意：如世间的陶师揉泥制成瓦器，都将归于破坏，众生的性命也是这样。譬如依附于树枝的所有叶、花、果，都归于堕落之法，人的性命也是这样。如草端垂挂的露水，被日光所照，须臾之间片刻不停，人的性命也是这样。如河海中聚集的泡沫，其性本来虚弱，这样不坚的身体，虚浮也是这样。譬如天降大雨，生起水上浮泡，刹那间迅速消灭，不坚之身也是这样。于不坚生起坚想，于坚却想为不坚，这是邪分别所行，不能证得坚实。于坚生起坚智，于不坚知其不坚，这是正分别所行，能证得坚实。为了修习坚实之想，略施水器，所以以不坚之身，换取那坚实之身。）

【按】“为修坚实想”之“想”，明本作“慧”。

“舍利子！诸菩萨摩诃萨行尸罗波罗蜜多时，发起这样的第二心之后，为了勤求大菩萨藏微妙法门，对说法师倍加奉事，勤加供养，乃至施予贮水之器。

#### 第三发心：忆饿鬼之苦

#### 第九发心：著无义行与专修义利

“再者，舍利子！菩萨摩诃萨行尸罗波罗蜜多时，生起这样的心：‘一切众生被无义之行所拘执，顾恋身命，执著于无义之行，不能励意专修义利。’舍利子！什么名为执著于无义之行？就是对于身命有所顾恋，对于觉分之法情无希望，以计执我与我所为前导，恒常对其身体防卫覆护，沐浴调治，装饰珍护，这便名为执著于无义之行。舍利子！又有执著于无义之行，就是对于身命有所顾恋，对于觉分之法情无希望，以计执我与我所为前导，而对于妻妾、男女、兄弟、朋友、眷属、亲戚防卫覆护，乃至对一切受用之具珍玩执著，这便名为执著于无义之行。舍利子！又有执著于无义之行，就是对于身命有所顾恋，对于觉分之法情无希望，以计执我与我所为前导，而对于奴婢僮仆防卫、驱役、桎梏、守护，这便名为执著于无义之行。

（大意：诸愚痴凡夫常顾恋身命，不愿求菩提，生起杂染的三业。常为了利益自身以及妻子眷属，珍玩于无义之事，这名为愚痴凡夫。驱役奴仆等，多畜养四足之畜，珍著于无义之事，这名为无智之人。贮积众多财谷，不布施也不食用，珍著于无义之事，名为守藏的愚夫。诸愚痴凡夫专门珍著于无义之事；具足妙慧的菩萨，精勤求取种种义利，不顾身命，欣乐于资助菩提，生起种种善业，这名为专修义利。）

【按】“宝著”之“宝”，三处，宋、宫等本作“实”。“助菩提”之“提”，宋、元、明、宫、圣本作“萨”。

```
方便善修习，施戒忍正勤，
静虑与妙慧，是名专义利。
供养于父母，给侍诸师长，
深敬奉三宝，是名专义利。
于摄一切法，诸菩萨妙藏，
诵持及开阐，是名专义利。
如是专义利，诸佛之所赞，
精进善相应，是胜无畏子。
发如是念已，以清净信心，
敬养尊重师，乃至奉水器。
```
（大意：以方便善加修习布施、持戒、忍辱、正勤、静虑与妙慧，这名为专修义利。供养父母，给侍诸师长，深深敬奉三宝，这名为专修义利。对于摄一切法的诸菩萨妙藏，诵持以及开阐，这名为专修义利。这样的专修义利，为诸佛所称赞，与精进善妙相应，这是殊胜的无畏之子。生起这样的念头之后，以清净的信心，敬养尊重之师，乃至奉上水器。）

“舍利子！诸菩萨摩诃萨行尸罗波罗蜜多时，发起这样的第九心之后，为了勤求大菩萨藏，对说法师倍加承事，勤加供养，乃至施予贮水之器。

#### 第十发心：随顺师教，获七圣财

“再者，舍利子！菩萨摩诃萨行尸罗波罗蜜多时，生起这样的心：‘世间众生邪僻自在，反而执拗于师长的教诲，无所获得。不获得什么？就是圣财。什么是圣财？就是信、戒、闻、惭、愧、舍、慧，这样的法，名为圣财。那些众生因为不获得这些，所以名为极度贫穷。’菩萨摩诃萨又这样想：‘我现在应当修习妙善的自在，对于师长的教诲随顺敬受。为什么？菩萨摩诃萨由于妙善的自在，对于师长的教诲随顺敬受，便有所证得。证得什么？就是圣财。什么名为菩萨的圣财？就是菩萨藏法门的差别。了知菩萨的妙善自在，就是说法师的妙善自在：对于菩萨藏法门的差别，广为众生宣畅敷演，辨了建立，开阐分别，显示流布。菩萨摩诃萨安住于这样的菩萨藏之后，获得圣法之财，永断贫穷，迅速证得阿耨多罗三藐三菩提。’舍利子！菩萨摩诃萨依尸罗波罗蜜多行菩萨行，生起这样的心之后，妙善自在，对于师长的教诲随顺敬受，又这样想：‘我应当以不坚之身换取坚固之身，为了勤求菩萨藏，承事供养说法师，乃至施予贮水之器。’舍利子！这名为菩萨摩诃萨的第十发心。”那时世尊想重宣此义，而说颂道：

【按】“宣畅”之“畅”，元、明本作“扬”。

原文：“了知菩萨妙善自在，即说法师妙善自在”（大意：了知菩萨的妙善自在，就是说法师的妙善自在。所指未详，存疑。）

```
世间下劣诸众生，
谀谄幻惑多奸伪，
颠倒僻执不如理，
专恶自在违师教。
深知是已顺师诲，
便能分别广敷演，
由斯获得仙圣财，
信戒舍闻惭愧慧。
如是七财无尽藏，
知非器者勿开显，
世间多有善众生，
堪为诸佛净法器。
无谄美言来请问，
妙善自在而闲雅，
常发勇猛勤精进，
恭敬正法乐常闻。
为证诸佛妙菩提，
不顾所爱之身命，
知彼堪任正法器，
复能受持深妙理。
导师发起大慈悲，
为说无杂真法界，
诸大菩萨妙法藏，
依彼建立胜菩提。
```
（大意：世间下劣的众生，谀谄、幻惑，多有奸伪，颠倒僻执，不如道理，专恶自在，违背师教。深知这些之后，随顺师长的教诲，便能分别广为敷演，由此获得仙圣之财：信、戒、舍、闻、惭、愧、慧。这样的七财无尽之藏，知道不是法器的人，不要为他开显；世间多有善良的众生，堪为诸佛的清净法器：无谄地以美言前来请问，妙善自在而闲雅，常发勇猛，勤加精进，恭敬正法，乐于常闻；为了证得诸佛的妙菩提，不顾所爱的身命；知道他堪任正法之器，又能受持深妙之理。）

【按】“勇猛”，明本作“猛勇”。

```
又于其中广开示，
诸佛坚固圣财宝，
一切诸法为空相，
亦无相相无我相。
无有寿命无变异，
无诸戏论无受藏，
一切诸法之自性，
不从缘生亦无相。
曾无初起无终灭，
无相真如之所显，
若善自在柔和者，
于师教诲无倒执。
自然最胜为开示，
本境所学解脱门，
净信尸罗与惭愧，
正闻舍施般罗若。
为彼分别广敷显，
无尽七财之法藏，
佛子和柔妙自在，
随顺善友所诲言，
我当承事说法师，
为证无上菩提故。
菩萨适发是心已，
于渴乏者生悲爱，
乃至经营净瓦器，
盛满清水随时施。
```
（大意：导师发起大慈悲，为他宣说无杂的真实法界、诸大菩萨的妙法之藏，依此建立殊胜的菩提。又在其中广为开示诸佛坚固的圣财之宝：一切诸法是空相，也是无相之相、无我之相；没有寿命，没有变异，没有种种戏论，没有受藏；一切诸法的自性，不从缘生，也无相；从无初起，无终灭，是无相真如所显现。若是善妙自在、柔和的人，对于师长的教诲没有颠倒执著。自然的最胜者为他开示本来所学的境界、解脱之门：净信、尸罗与惭愧、正闻、舍施、般罗若，为他分别广为敷显无尽的七财之法藏。佛子柔和、妙善自在，随顺善友所教诲的话：“我应当承事说法师，为了证得无上菩提。”菩萨刚发起这样的心，便对干渴困乏的人生起悲爱，乃至经营干净的瓦器，盛满清水，随时布施。）

【按】“承事说法师”之“说”，《大正藏》作“语”，CBETA依高丽藏作“说”，今从之。“般罗若”即般若（智慧）。

“舍利子！诸菩萨摩诃萨行尸罗波罗蜜多时，发起这样的第十心之后，为了勤求大菩萨藏，对说法师倍增承事，勤加供养，乃至施予贮水之器。”
