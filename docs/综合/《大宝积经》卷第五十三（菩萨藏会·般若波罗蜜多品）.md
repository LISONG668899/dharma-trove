# 《大宝积经》卷第五十三（菩萨藏会·般若波罗蜜多品）

唐·三藏法师玄奘 奉诏译

## 菩萨藏会第十二之十九

【按】译者题署“法师”二字，宋、宫本无。

### 般若波罗蜜多品第十一之四

#### 四正胜道善巧

“再者，舍利子！什么是菩萨摩诃萨的四正胜道善巧？舍利子！菩萨摩诃萨因为修习般若波罗蜜多，其道有四种。是哪四种？一是为了令未生的恶不善法不生，便生起欲乐，勇猛策励，发勤精进，摄持其心，平等安住；二是为了永断已生的恶不善法，便生起欲乐，勇猛策励，发勤精进，摄持其心，平等安住；三是为了令未生的善法生起，便生起欲乐，勇猛策励，发勤精进，摄持其心，平等安住；四是为了令已生的善法安住不忘、修习圆满，便生起欲乐，勇猛策励，发勤精进，摄持其心，平等安住。舍利子！这样的四种，也名为四种正胜。

“再者，舍利子！什么名为为了令未生的恶不善法不生，乃至摄持其心，平等安住？舍利子！所说的为了令未生的恶不善法不生，便生起欲乐、勇猛策励，就是如理作意；发勤精进，就是不舍如理作意；摄持其心、平等安住，便名为如理观察。为什么？由于如理方便，恶不善法不再现行。舍利子！什么名为恶不善法？又以什么义说恶不善法不再现行？舍利子！恶不善法，就是尸罗戒所对治的、定所对治的、慧所对治的。什么名为戒所对治？舍利子！所说的对治，就是犯戒，以及其余一切发起毁犯尸罗之法，为种种妙戒之聚所对治，这样名为戒所对治。舍利子！什么名为定所对治？就是违犯轨则，以及其余一切引起心乱之法，为种种妙定之聚所对治之法，这样名为定所对治。舍利子！什么名为慧所对治？就是毁犯于见，以及其余一切能引起种种见、缠、障、盖之法，为种种妙慧之聚所对治，这样名为慧所对治。舍利子！这样等等都得名为恶不善法。若所有的如理作意，不令这样的恶不善法得以生起，便名为恶不善法不再现行。舍利子！这名为菩萨摩诃萨的第一正胜。

【按】“发起毁犯”之“起”，元、明本作“趣”。

“再者，舍利子！什么名为为了永断已生的恶不善法，乃至摄持其心，平等安住？舍利子！种种恶不善法积集于心，无方无处；以及种种恶不善法现行于觉心，依止于因、缘、所缘之境而得生起。什么名为缘境生起？就是因净妙之相而起贪心，因损坏之相而起瞋心，因无明之相而起痴心。那时菩萨便安住于这样的如理思惟：‘以不净之相，贪欲寂静；以慈愍之相，瞋恚寂静；以缘起之相，愚痴寂静。’这些烦恼虽然由于作意而永远息灭，假立言说名为寂静，而实际上的寂静并无别的可得，只是为了断灭平等之性而现观诸法，就以这法名为正胜。舍利子！这名为菩萨摩诃萨的第二正胜。

“再者，舍利子！什么名为为了令未生的善法生起，乃至摄持其心，平等安住？舍利子！这样的义，文句无量。为什么？菩萨摩诃萨无量的善法都应当积集，由于这样，文句也有无量。舍利子！应当知道，菩萨的一切善根以乐欲为根本，由于精进，便能积集一切善根。为什么？由于以这样的法摄持安住，一切善根都得以究竟。舍利子！这名为菩萨摩诃萨的第三正胜。

【按】“而有无量”，明本作“而无有量”。

“再者，舍利子！什么名为为了令已生的善法安住不忘、修习圆满，便生起欲乐，乃至摄持其心，平等安住？舍利子！这样的义，应当知道就是回向菩提。为什么？由于回向菩提，所有的善根不再失坏。为什么这样说？因为那菩萨不依三界而发心。舍利子！若诸菩萨不依三界修习善根，又回向一切智者，应当知道所有的一切善法便是究竟，没有能令其穷尽的。舍利子！这名为菩萨摩诃萨的第四正胜。舍利子！菩萨摩诃萨为了修行般若波罗蜜多，精勤修习这样四种道分善巧。

#### 五根道分善巧

“再者，舍利子！什么是菩萨摩诃萨的五分道善巧？舍利子！是哪五种？就是信根、精进根、念根、定根、慧根，这名为五种。舍利子！什么名为菩萨摩诃萨修行般若波罗蜜多的信根？舍利子！这样的信，是信四种法。是哪四种？一是信受处于生死之中的世间正见。由于这信，菩萨摩诃萨依趣业报，乃至遭遇丧命的因缘，终究不起意造作种种恶业。二是信受这样的诸菩萨行。由于这信，修行正行，终究不起意乐于证取其余诸乘。三是信受这样胜义了义的甚深缘起：一切诸法无我、无有情，只是言说所假立，唯是空、无相、无愿之相。由于这信，有情见趣以及种种随眠不再增长。四是信受这样的力、无畏等一切佛法；信受之后，离疑离惑，修集一切所有的佛法。舍利子！这样等等的相，名为菩萨摩诃萨的信根。舍利子！什么名为菩萨摩诃萨修行般若波罗蜜多的精进根？就是信根所信之法，由精进根而得以生起，就以此法名为精进根。舍利子！什么名为菩萨摩诃萨修行般若波罗蜜多的念根？就是由精进所积集的诸法，以念根之力而不失坏，就以此法作为念根。舍利子！什么名为菩萨摩诃萨修行般若波罗蜜多的定根？就是由念根之力而不失坏的诸法，那诸法以定根摄住于一缘，所以名为定根。舍利子！什么名为菩萨摩诃萨修行般若波罗蜜多的慧根？就是由定根摄住于一缘的诸法，那诸法以慧根之力观察通达明了，所以名为慧根。舍利子！菩萨摩诃萨若具足这样五种增上之根，无间相续修行正行，能迅速圆满一切佛法，也迅速趣入授记之地。舍利子！譬如具五神通的外道仙人，若胎藏中男女二形尚未生起，终究不会为之妄加授记；如来也是这样，若诸菩萨尚未具足成就这样无间相续的五根，终究不会为他们授记。舍利子！这样等等的相，名为菩萨的五分道法。菩萨摩诃萨为了修行般若波罗蜜多，便能修习这样的五分道善巧。

【按】“修集一切”之“集”，明本作“习”。“授记别地”之“别”，元、明本作“莂”。

#### 五力道分善巧

“再者，舍利子！菩萨摩诃萨因为依般若波罗蜜多，道善巧又有五分。是哪五种？就是信力、精进力、念力、定力、慧力，这名为五种。舍利子！什么名为菩萨摩诃萨的信力？舍利子！这些菩萨清净的胜解，忍受决定，坚固难坏，不可制伏。假设有恶魔化作佛像来到菩萨处作障碍，想令这菩萨对正法之智以及殊胜解脱远离，心不欣乐，又这样说：‘这样的法不是佛的正教。’舍利子！即使四大之性互相转变，也终究不能使成就信力胜解的菩萨因为魔的迷惑而令信力倾动。舍利子！这样名为菩萨摩诃萨的信力。

【按】“忍受决定”之“忍”，宋、元、明本作“信”。“情不欣乐”之“欣”，明本作“欲”。

“再者，舍利子！什么是菩萨摩诃萨的精进力？舍利子！就是菩萨发勤精进，方便修习一切善法，在那些处获得坚固的住持之力。由于这力，乃至那处所作之事尚未终了究竟，在这期间，没有任何天以及世间能令这菩萨的住持之力移动，不住于本处。舍利子！这样名为菩萨摩诃萨的精进力。

“再者，舍利子！什么是菩萨摩诃萨的念力？舍利子！诸菩萨等对那些法由于安住于念，令心安住，没有能令其移动散乱的。这菩萨摩诃萨由于念的持力，善能摧灭一切烦恼，而没有能制伏这念的。舍利子！这样名为菩萨摩诃萨的念力。

“再者，舍利子！什么是菩萨摩诃萨的三摩地力？舍利子！诸菩萨等安住于远离的诸静虑支，虽然观察一切音声、种种语业之道以及音声之刺，却不能障碍初静虑；这些菩萨虽然以这样的一切善法寻伺推求无量诸法，却不能障碍第二静虑；这些菩萨虽然安住于所生的欢喜，却不能障碍第三静虑；这些菩萨虽然为了成熟一切众生，摄受正法而不住于舍，却不能障碍第四静虑。舍利子！菩萨摩诃萨安住于这样的四种静虑，一切静虑所对治之法都不能制伏。又，这菩萨虽然安住于三摩地而不舍，却不随那定力受生。舍利子！这样名为菩萨摩诃萨的三摩地力。

“再者，舍利子！什么是菩萨摩诃萨的慧力？舍利子！这智慧之力坚固难伏，就是一切世间与出世间之法所不能制伏的。这样的智力，又是这菩萨生生之处，乃至世间已经流行的正行、工巧业处，难作难解的，诸菩萨对那一切都不由师教而现前了知。舍利子！这些菩萨又对一切出世间法，就是能救度诸世间的法，菩萨摩诃萨以智慧之力都能摄受，不被一切世间天人所制伏。舍利子！这名为菩萨摩诃萨的慧力。这样等等的相，便名为菩萨摩诃萨的五分道善巧。舍利子！这些菩萨摩诃萨为了修行般若波罗蜜多，精勤修习这样的五分道善巧。

【按】“坚固难伏”之“伏”，元、明、宫本作“拔”。“工巧业处”之“工”，元、明本作“善”。

#### 七觉分善巧

“再者，舍利子！什么是菩萨摩诃萨修行般若波罗蜜多的觉分善巧？舍利子！菩萨摩诃萨有七种觉分。是哪七种？就是念觉分、择法觉分、精进觉分、喜觉分、安觉分、等持觉分、舍觉分，这名为菩萨摩诃萨的七种觉分。舍利子！什么名为菩萨摩诃萨的念觉分？就是诸菩萨由于依这样的正念之力，随觉诸法，观察诸法，寻思诸法，了达诸法，拣择诸法，鉴照诸法。这菩萨摩诃萨由于念力，随觉一切诸法的体相。舍利子！什么名为了达诸法自体相之智？就是由于念力觉知一切法的自体相是空。若诸菩萨通达这一点，便名为念觉分法。

【按】“简择”之“简”，元、明本作“拣”。

“再者，舍利子！什么名为菩萨摩诃萨的择法觉分？就是诸菩萨具足拣择八万四千法藏之智，随那些法应当拣择。这样的拣择就是了义；这样的了义由于不了义，不了义由于世俗义，世俗义由于胜义义，胜义义由于假施设，假施设由于殊胜的决择，这殊胜的决择名为拣择。舍利子！若诸菩萨成就这一点，这样名为择法觉分。

原文：“如是简择所谓了义，如是了义由不了义，不了义者由世俗义，世俗义者由胜义义，胜义义者由假施设，假施设者由胜决择”（大意：这样的拣择就是了义；这样的了义由于不了义，不了义由于世俗义，世俗义由于胜义义，胜义义由于假施设，假施设由于殊胜的决择。诸“由”字所表关系未详，存疑。）

“再者，舍利子！什么名为菩萨摩诃萨的精进觉分？就是菩萨对于这样的念、择法、喜、安、定、舍之智，摄受欣乐，勇猛的势力与意欲不退不减，正勤策励，不舍善轭，为了道的现观而发起正勤。舍利子！若诸菩萨成就这一点，这样名为精进觉分。

【按】“择法”之“法”，元、明本作“进”。“善扼”之“扼”，宋、元、明、宫本作“枙”，即“轭”。

“再者，舍利子！什么名为菩萨摩诃萨的喜觉分？就是菩萨对法生喜，便喜悦于法；由于喜悦于法，心不沉没；由于不沉没，生起清净的喜；由于喜清净，身心安隐，远离种种烦恼。舍利子！若诸菩萨成就这一点，这样名为喜觉分法。

“再者，舍利子！什么名为菩萨摩诃萨的安觉分？就是菩萨由于身安而获得心安，由于心安而息灭种种烦恼，远离一切所有的盖障，对所缘之境其心安住，这样便入于三摩地。舍利子！若诸菩萨成就这一点，便名为安觉分法。

“再者，舍利子！什么名为菩萨摩诃萨的三摩地觉分？就是菩萨以这定心觉知于法，而不是以不定之心。为什么？若心得定而觉了诸法，终究不会发起种种爱、见等缠、障、邪觉，唯有对法的平等实性，心定而趣入，觉知一切法的平等之性。舍利子！若诸菩萨成就这一点，这样名为三摩地觉分法。

“再者，舍利子！什么名为菩萨摩诃萨的舍觉分法？就是菩萨对能随顺忧、喜之分的法，心无执著；对种种世间法，心不摄受，不高不下，安住不动，无欣无厌，无爱无恚，唯能随顺修习圣道。若诸菩萨成就这一点，便名为舍觉分法。像这样，舍利子！菩萨摩诃萨为了对这些七觉分法通达善巧，便乐于修行般若波罗蜜多，精勤修习觉分善巧。

#### 八圣道分善巧

“再者，舍利子！什么是菩萨摩诃萨修行般若波罗蜜多的道分善巧？舍利子！菩萨摩诃萨具足这样的八圣道分。是哪八种？就是正见、正思惟、正语、正业、正命、正精进、正念、正三摩地，这样名为诸菩萨等的八圣道分。舍利子！什么名为菩萨摩诃萨的正见？舍利子！就是众贤圣的出世间之见。这样的见，不是由我见生起，不是由有情见生起，不是由命者见生起，不是由数取者见生起，不是由断见生起，不是由常见生起，不是由有见生起，不是由无有见生起，不是由善见生起，不是由不善见生起，乃至不是由涅槃见生起。舍利子！若诸菩萨远离这些见，便名为菩萨的正见。

“再者，舍利子！什么是菩萨摩诃萨的正思惟？舍利子！若诸菩萨由某种思惟便能发起贪、瞋、痴等一切烦恼，这样的思惟终究不发起；若诸菩萨由某种思惟便能生长戒聚、定聚、慧聚、解脱聚、解脱智见聚等种种功德，这样的思惟诸菩萨等恒常发起。舍利子！若有菩萨成就这法，便名为正思惟分。

【按】“解脱”，元、明本作“解脱聚”。“解脱智见”之“智”，元、明本作“知”。

“再者，舍利子！什么名为菩萨摩诃萨的正语？舍利子！就是诸菩萨这样的言语：不自我损恼，不损恼他人，不与众生互相争诤。由于这菩萨成就这样的语言，能入圣道，所以说名为菩萨的正语。

“再者，舍利子！什么名为菩萨摩诃萨的正业？舍利子！就是诸菩萨终究不造作感黑报的黑业；若业能感白净的果报，若业能尽一切诸业，这样的业便方便发起。舍利子！这些菩萨就以这业作为白业，以业为依趣，精勤方便修习平等之业，这样名为菩萨的正业。

【按】“而为白业”之“白”，元、明、宫本作“自”。

“再者，舍利子！什么名为菩萨摩诃萨的正命？舍利子！就是诸菩萨所有的圣种、杜多功德，不谄不诳，不怀浮诈；对于种种乞求，其性远离逼迫，易满易养；对那些轨则，奉而修行，不生怠慢松缓；对他人的利养不起嫉妒，对自己的利养生起知足；对圣者所开许的不深深染著，而常清净地自守其命行。舍利子！若诸菩萨成就这一点，便名为菩萨的正命。

【按】“无怀浮诈”之“无”，《大正藏》作“不”，今依CBETA所录高丽藏作“无”。“慢缓”之“慢”，元、明本作“缦”。

“再者，舍利子！什么是菩萨摩诃萨的正精进？舍利子！这些菩萨对于圣者所不开许的贪、瞋、痴等烦恼随眠以及种种邪行，若有在这些法中发勤精进的，菩萨不乐于行这样的精进；若种种正勤为圣谛所摄，趣入圣道，能到达涅槃，引发正行，这样的精进为诸菩萨所乐于修学，就以此法名为正精进。

“再者，舍利子！什么名为菩萨摩诃萨的正念？舍利子！就是有种种念极善安住，其性不下劣，心善正直，没有邪曲，能观察生死所有的过患，作为趣向大涅槃的道路。若诸菩萨对这样的念恒常正确忆持，为了令圣道不忘失，就以此法名为正念。

“再者，舍利子！什么名为菩萨摩诃萨的正三摩地？舍利子！所谓三摩地，若对正性平等，便对一切法平等。诸菩萨等安住于这样的三摩地之后，为了解脱一切众生而趣入正性。这样的正定是无尽之道，过去、未来、现在诸佛为了令诸菩萨证得现观而宣说开示，这便名为菩萨的正定。舍利子！这名为菩萨摩诃萨的八圣道分。若诸菩萨摩诃萨想要修行般若波罗蜜多，应当勤修这八圣道分善巧。

#### 止观道善巧

“再者，舍利子！菩萨摩诃萨因为修行般若波罗蜜多，修习道善巧。道善巧又有两种。是哪两种？就是奢摩他以及毘钵舍那，这名为两种。舍利子！什么名为奢摩他道？舍利子！就是诸菩萨其心寂静、深极寂静、最胜寂静，没有散乱，诸根淡泊，不掉不举，远离种种躁扰以及昏沉，安静而严密守护，远离种种谄曲，调顺堪能，乐于常常独处，远离那喧闹，乐于远离之行，身无尘染，心无惑乱，在寂静之门思惟作意，远离种种恶欲，无所希望，远离种种大欲，欢悦知足，正命清净，正行圆满，严密守护威仪，知时知分，易养易满，善知其量，常乐思择，无高无下，对弊鄙粗恶的言语其性能够堪忍。在相应之门发心安住，乐处闲静之室，在静虑之分作意缘念，生起大慈，引发大悲，安住大喜，修习大舍，从初静虑乃至八定，次第证入。若诸菩萨成就这一点，这样名为奢摩他道。舍利子！菩萨摩诃萨又有无量种奢摩他资粮正行，诸菩萨等对这资粮方便趣入，这样也名为奢摩他道。

【按】“次第”之“第”，《大正藏》作“等”，今依CBETA所录高丽藏作“第”。

“再者，舍利子！什么名为毘钵舍那道？就是诸菩萨在妙慧之分修习圣道，对诸法中发起这样的无作观智，又发起无我、无有情、无命者、无数取的观智；对诸蕴中起法的观智，对诸界中起法界的观智，对诸处中起空聚落的观智，对诸眼中起照了的观智，对缘起中起不相违的观智，对种种见趣起远离的观智，对种种因果起业报的观智，对所应得的果起作证的观智，对所入的正性起趣入的观智。舍利子！所谓毘钵舍那，就是对诸法起如理之见，对诸法起真实之见，对诸法起不变异之见，对诸法起空见，对诸法起无相见，对诸法起无愿见。又，舍利子！所谓毘钵舍那，不是以有因而观，不是以无因而观，不是以生、灭、住之因而观，不是以有所得之因而观。为什么？菩萨对此都无所观而又观察，不见而见，见而不见。舍利子！若诸菩萨作这样的观察，名为如实观，名为真实见，也名为证得毘钵舍那的善巧方便。舍利子！菩萨摩诃萨在这观中虽然发起这样的观解，却不堕于那无所作为，也不远离善根加行。若诸菩萨成就这一点，这名为菩萨摩诃萨的毘钵舍那。舍利子！菩萨摩诃萨为了修行般若波罗蜜多，精勤修习奢摩他、毘钵舍那的道法善巧。

#### 趣一道善巧

“再者，舍利子！菩萨摩诃萨的道相是这样的。我若略说菩萨之道，则唯有一种趣道善巧。舍利子！是什么呢？就是菩萨独一，为众人之表率，无有与之相等者，不借伴侣助力，为了证得阿耨多罗三藐三菩提，由自己摄受的精进势力、清净的欲解，披上坚固的铠甲。为什么？由于这菩萨不由他人而悟，不缘于他人，自己所建立，自力所生起，严备这样坚固的甲铠。舍利子！这些菩萨发起这样的念头：‘这样的甲铠是一切众生所不能披的，我现在独自披上这样的甲铠；一切贤圣、诸新发意、尚未安住正位的诸菩萨等所未曾披的，我现在独自披上。’那时菩萨又这样想：‘我现在这样严备，岂能让布施自在地度我？我当自在地度那布施。同样，持戒、忍辱、精进、静虑以及般若等，岂能让它们自在地度我？我当先自在地度它们。’又这样想：‘我现在岂能让波罗蜜多发起我？我当发起波罗蜜多。这样广说，一切善根都当因我而得以发起，不让善根来发起我。’舍利子！若诸菩萨摩诃萨对这样的法不借伴侣助力，自己能够建立，认为‘我独一而无有等同者’，当坐于坚固殊胜的金刚座，自以势力摧伏魔军，用一刹那相应的妙慧，当证无上正等菩提。舍利子！若诸菩萨生起这样等等的欲解、方便、决定观察，这名为菩萨摩诃萨的趣一道善巧。舍利子！菩萨摩诃萨为了修行般若波罗蜜多，修习这样的趣一道善巧。舍利子！这样等等的道善巧之相，诸菩萨摩诃萨为了修行般若波罗蜜多，修习这样的道法善巧。

【按】“独一”之“一”，宋、元、明、宫本作“拔”。“贤圣”，《大正藏》作“圣贤”，今依CBETA所录高丽藏、碛砂藏作“贤圣”。

#### 缘起善巧

“再者，舍利子！什么是菩萨摩诃萨的缘起善巧？舍利子！就是诸菩萨依般若波罗蜜多修习缘起，在隐密寂静的室中这样思惟：‘这样的世间纯大苦聚，是从哪里集起的？’思惟之后便自己了知：这样的苦聚，由于不如理作意集起，所以无明集起；无明集起，所以诸行集起；诸行集起，所以诸识集起；诸识集起，所以名色集起；名色集起，所以六处集起；六处集起，所以诸触集起；诸触集起，所以诸受集起；诸受集起，所以诸爱集起；诸爱集起，所以诸取集起；诸取集起，所以诸有集起；诸有集起，所以生集起；生集起，所以老死、愁、叹、忧、苦、逼恼都全部集起。舍利子！菩萨摩诃萨又这样想：‘那些法虽然集起，却无作、无用、无有主宰。这样的诸法，以诸善为因，以不动为因，以涅槃为因，那一切法从缘生起，没有主宰，也是这样。若众生以下根为因、以中根为因、以上根为因、以诸业为因，因果流转也是这样。’舍利子！这样一切有所取之法，因缘和合而得以集起，菩萨一切都能了知，这样名为缘起善巧。舍利子！菩萨摩诃萨又这样想：‘由于什么灭，那些法便灭？’思惟之后便自己了知：由于不如理作意灭，所以无明灭；无明灭，所以诸行便灭；诸行灭，乃至纯大苦聚灭。舍利子！若能了知这样的法智，便名为缘起善巧。舍利子！这些菩萨又这样想：‘因依正法，依止诸缘，依止和合，得以修习诸善。这法若由诸因和合、依止诸缘，那么这些法便不依止于我，不依止于有情，不依止于命者，不依止于数取，那么这法便不可称量。’舍利子！诸菩萨等若能这样如理观察，便名为缘起善巧。又观察一切佛法都是菩提之相、缘所生起之相，观察诸缘起都是尽灭之相，因为能观待众生，所以不趣入毕竟寂灭，这又名为缘起善巧。舍利子！这些菩萨摩诃萨为了修行般若波罗蜜多，修习这样的缘起善巧。

【按】“有所取法”，明本作“所有取法”；“取”，元、明本作“因”。

#### 一切法善巧：有为与无为

“再者，舍利子！什么是菩萨摩诃萨的一切法善巧？舍利子！菩萨摩诃萨因为修行般若波罗蜜多，于一切法普遍摄持一切有为与无为。菩萨摩诃萨对这样等等的有为与无为一切诸法应当修习善巧。舍利子！什么是菩萨摩诃萨的有为善巧？就是妙善的身行、妙善的语行、妙善的意行，这便名为有为善巧。什么名为无为善巧？就是以这样妙善的身、语以及意行，回向毕竟无为的菩提，回向无为菩提的妙观，又回向于萨伐若，这便名为无为善巧。再者，舍利子！菩萨摩诃萨的有为善巧，就是积集五种到彼岸。是哪五种？就是布施、持戒、忍辱、精进、静虑波罗蜜多，这名为有为。若由般若波罗蜜多的无为之智，那么五种到彼岸便不可厌毁；这样的妙智又能积集诸到彼岸的资粮善法，信解无漏的无上菩提，以及回向一切智智，这便名为无为善巧。

【按】萨伐若，即一切智。

“再者，舍利子！菩萨摩诃萨的有为善巧，就是以无碍之光照耀众生，以四摄法摄受众生，这名为有为。若观察诸法无我、无有情、无取、无执，对四摄法方便善巧，爱乐信受无为的等觉，以及回向一切智智，这便名为无为善巧。

“再者，舍利子！菩萨摩诃萨的有为善巧，就是不断能令生死相续的结缚，而又永断能令生死相续的烦恼，任持菩提的结缚相续，一分结缚不再现行，这名为有为善巧。若又修习空、无相、无愿诸法的正智，现观善巧，无上菩提不由他缘，对无为法而又作证，这便名为无为善巧。

【按】“结缚相续”之“续”，元、明本作“缚”。

原文：“任持菩提结缚相续一分结缚不复现行”（大意：任持菩提的结缚相续，一分结缚不再现行。所指未详，存疑。）

“再者，舍利子！菩萨摩诃萨的有为善巧，就是诸菩萨虽然行于三界，却不被那三界的烦恼所染污，这样名为有为善巧；虽然具足通达一切三界的出离之法，却不坠堕于出离之界中，这便名为无为善巧。舍利子！菩萨摩诃萨的一切法善巧，便名为一切智智。若诸菩萨圆满证入一切智智，便是一切时的智慧善巧，这就名为诸法善巧。舍利子！菩萨摩诃萨为了修行般若波罗蜜多，修习这样的一切法善巧。像这样，舍利子！若有依菩萨藏修行般若波罗蜜多的菩萨摩诃萨，为了修行般若波罗蜜多，依慧分别，善巧通达，修习这样的十种善巧。

#### 妙慧之相

“再者，舍利子！什么名为菩萨摩诃萨的妙慧？什么名为到彼岸之义？舍利子！所说的慧，就是能解了一切善法。这是现见之慧，因为随顺通达一切法；这是真量之慧，因为如实通达一切法；这是通达之慧，因为一切见趣、诸缠缚之法不能障碍；这是离愿之慧，因为永离一切欲求之愿；这是安悦之慧，因为永息一切热恼；这是欢喜之慧，因为缘法的喜乐不断绝；这是依趣之慧，因为对种种义智都能现见；这是建立之慧，因为建立一切觉品之法；这是证相之慧，因为随其所乘证得其果；这是了相之慧，因为善能照了这智性；这是济度之慧，因为救度一切瀑流；这是趣入之慧，因为能趣入正性无生之法；这是策励之慧，因为振发一切善法；这是清净之慧，因为远离先前随眠烦恼之浊；这是最胜之慧，因为升登一切诸法之顶；这是微妙之慧，因为以自然智随觉于法；这是离行之慧，因为不再有杂染的三界法；这是摄受之慧，因为为一切贤圣所摄受；这是断愿之慧，因为除遣一切相的分别；这是舍逸之慧，因为远离一切愚痴黑暗；这是方便之慧，因为是一切瑜伽师地者所成就的；这是发趣之慧，因为当安住于一切圣智之道；这是照明之慧，因为除灭一切无明瀑流的翳暗之膜；这是施明之慧，因为开导一切，犹如眼目；这是无漏之慧，因为慧眼超过邪僻之路；这是胜义之慧，因为照了这样的大圣谛；这是无别之慧，因为善能调顺；这是光明之慧，因为是种种智慧之门；这是无尽之慧，因为遍于一切，随行照耀；这是无灭之慧，因为常常广见；这是解脱道之慧，因为永断一切取执的系缚；这是不离处之慧，因为不与一切烦恼障法共同安止。舍利子！这样的慧相，我现在略说。应当知道菩萨摩诃萨更有无量无边的诸慧。为什么？舍利子！乃至一切众生有多少心行，应当知道菩萨摩诃萨也有那么多慧业智行；乃至一切众生有多少欲解，应当知道菩萨摩诃萨也有那么多慧的观察之智；乃至一切众生有多少烦恼之门，应当知道菩萨摩诃萨也有那么多广大的慧门；乃至一切声闻、独觉以及正等觉有多少遍知，应当知道菩萨摩诃萨也有那么多慧所行之处。舍利子！这样等等的一切慧处，诸菩萨摩诃萨都于其中精勤修学，这便名为菩萨的妙慧。

【按】“瀑流”之“瀑”，宋、元、明、宫本作“暴”。“清净慧”之“净”，元、明、宫本作“澄”。“翳暗膜”之“膜”，明本作“瞙”。“施明慧”之“明”，元、明、宫本作“眼”。

#### 到彼岸之义

“再者，舍利子！什么名为菩萨摩诃萨的到彼岸之义？舍利子！乃至一切所知的种种妙善之法能到达彼岸的，应当知道都是到彼岸之义。又，舍利子！如上广说的一切慧句，应当知道都是到彼岸之义。又，诸菩萨修行差别圆满之义，应当知道都是到彼岸之义；这样的一切智智圆满之义，应当知道都是到彼岸之义；对一切有为无为法无执著之义，应当知道都是到彼岸之义；能善觉悟无量生死大过失之义，应当知道都是到彼岸之义；对一切诸法能开悟不觉者之义，应当知道都是到彼岸之义；能开示无穷尽的法宝藏之义，应当知道是到彼岸之义；无障碍解脱圆满之义，应当知道是到彼岸之义；觉悟布施、持戒、忍辱、精进、静虑、慧平等之义，应当知道是到彼岸之义；最胜决择善巧之义，应当知道是到彼岸之义；遍行一切众生界之义，便名为到彼岸之义；无生法忍圆满之义，便名为到彼岸之义；不退转地究竟圆满之义，便名为到彼岸之义；清净修治诸佛国土之义，便名为到彼岸之义；成熟一切众生之义，便名为到彼岸之义；前往道场、升菩提座之义，便名为到彼岸之义；毕竟摧伏诸魔军之义，便名为到彼岸之义；一切佛法都圆满之义，便名为到彼岸之义；在菩萨藏差别法门中正确安住之义，便名为到彼岸之义。舍利子！若对这样的大菩萨藏微妙法门正确修学之后，我说他们便对一切波罗蜜多都得以究竟。

【按】“正修学已”之“学”，元、明本作“觉”。

#### 受持菩萨藏经的五组十种功德

“再者，舍利子！若有安住于大乘的诸善男子以及善女人，都应当对这大菩萨藏微妙法门殷勤请求，受持读诵，通达义理，广为他人分别显示。为什么？舍利子！若有人对这菩萨藏经殷重听闻、受持读诵，乃至为他人分别解说，应当知道这人必定获得十种功德称赞利益。是哪十种？一是在所生之处，对一切微妙的工巧业处究竟通达；二是在所生之处常居于高贵种族，荣望当世；三是在所生之处有大威严，势力自在；四是凡所发的言令，一切人都听从，无不信服；五是在所生之处具大豪富；六是在所生之处恒常被天人所爱敬；七是生于人中常为轮王，得大自在；八是所生常得作天帝释；九是若生于色界，作大梵王；十是在所生之处常不远离大菩提心。舍利子！受持此经的人便获得十种功德称赞利益。

“再者，舍利子！这些善男子、善女人等受持此经，殷重听闻，读诵解义，乃至为他人广说开示，应当知道这人又获得这样的十种功德称赞利益。是哪十种？一是不与尼伽兰陀的邪论相杂；二是不起我见；三是没有有情见；四是没有命者见；五是没有数取见；六是不起断见；七是不起常见；八是对一切世务心无顾及；九是恒常发起殊胜之心，乐欲出家；十是若听闻经典，能迅速受持，悟解深义。舍利子！这名为获得十种功德称赞利益。

【按】“尼伽兰陀”，即离系外道。“邪论”之“邪”，元、明本作“耶”。“悟解深义”，元、明本作“恒悟解深义”。

“再者，舍利子！这些善男子、善女人等受持此经，殷重听闻，读诵解义，乃至为他人广为分别解说，应当知道这人又获得这样的十种功德称赞利益。是哪十种？一是成就正念；二是成就正觉；三是成就正趣；四是成就志勇；五是成就正慧；六是得以具足无难；七是忆念本生之事；八是其性贪欲淡薄，没有猛利之贪，不被重贪所焚烧恼乱；九是其性瞋恚淡薄，没有猛利之瞋，不被重瞋所焚烧恼乱；十是其性愚痴淡薄，没有猛利之痴，不被重痴所焚烧恼乱。舍利子！这名为获得十种功德称赞利益。

【按】“性薄瞋恚”之“瞋恚”，元、明本作“贪瞋”。

“再者，舍利子！这些善男子、善女人等受持此经，殷重听闻，读诵解义，乃至为他人广为分别解说，应当知道这人又获得这样的十种功德称赞利益。是哪十种？一是成就机速之慧；二是成就捷辩之慧；三是成就猛利之慧；四是成就迅疾之慧；五是成就广博之慧；六是成就甚深之慧；七是成就通达之慧；八是成就无著之慧；九是常常现前见到一切如来，见了之后以清美的颂文加以赞叹；十是善能如理请问如来，又能如理开释疑难。舍利子！这名为获得十种功德称赞利益。

“再者，舍利子！这些善男子、善女人等受持此经，读诵解义，乃至为他人广为分别解说，应当知道这人又获得这样的十种功德称赞利益。是哪十种？一是常乐远离种种不善之友；二是常乐亲近种种善知识；三是能松解诸魔所有的系缚；四是摧毁诸魔所有的军阵；五是善能诃责厌离一切烦恼；六是对一切行心中恒常捐舍；七是违背一切趣向恶趣之道；八是归向一切趣向涅槃之道；九是善能宣说一切越度生死的清净之地；十是巧能随学一切菩萨所行的轨则，又能奉行诸佛的教敕。这样名为十种功德称赞利益。舍利子！若有善男子、善女人，能对这样的大菩萨藏微妙法门殷重听闻，受持读诵，研寻义趣，明了通达，又能为他人广说开示，应当知道这人便获得如上的功德称赞利益。”那时世尊想重宣此义，而说颂道：

【按】“清净之地”之“地”，元、明、宫本作“施”。

```
诸聪叡者慧无边，
妙能通达法及义，
尊胜文词善圆具，
由持如是大经王。
常获丰饶法宝藏，
恒欣悦意行法施，
发生最上胜欢喜，
由持如是大经王。
多众生闻说法者，
证斯广大胜功德，
我当云何说是法，
如持经者之所获。
证获如斯最胜慧，
于正法所终无坏，
由念发生微妙智，
能说无上智依处。
勤求善说正法句，
最胜众圣所称赞，
常闻发起超胜行，
由持如是大经王。
慧者闻已持深义，
于诸文句无妄执，
常随理趣而观照，
增长妙智量无边。
```
（大意：诸聪睿者智慧无边，妙能通达法以及义，尊贵殊胜的文词善能圆满具备，都是由于受持这样的大经王。常常获得丰饶的法宝之藏，恒常欣悦地行法布施，发生最上殊胜的欢喜，都是由于受持这样的大经王。许多众生听闻说法者，证得这样广大殊胜的功德，我当怎样宣说这法，如受持经者之所获？证得这样最胜的智慧，对于正法终究无所毁坏，由念发生微妙之智，能宣说无上智慧的依处。勤求善说的正法文句，为最胜的众圣所称赞，常常听闻，发起超胜之行，都是由于受持这样的大经王。智者听闻之后受持深义，对种种文句没有妄执，常随理趣而观照，增长妙智，其量无边。）

【按】“证获”之“证”，宋、元、明、宫本作“诸”。

```
无边妙智无边义，
第一义解谅难思，
遍游十方广称赞，
闻经胜利无穷尽。
极善微薄贪瞋痴，
获得第一心清净，
由闻如是大经王，
功德胜利无边际。
虽获胜财无放逸，
称量财义谁坚固，
深达世财非有实，
于财无恋趣非家。
出诣闲静住中林，
于彼惛沈常远离，
听闻净法曾无厌，
静虑正教无悭悋。
请问疑难世导师，
闻已为他广开释，
由斯增长微妙智，
于白净法终无退。
```
（大意：无边的妙智、无边的义，第一义的理解实在难以思议，遍游十方广为称赞，闻经的殊胜利益无有穷尽。极善地令贪、瞋、痴微薄，获得第一的心清净，由于听闻这样的大经王，功德殊胜利益无有边际。虽然获得殊胜的财富而不放逸，称量财物之义，有谁是坚固的？深达世间财物并非实有，对财物无所恋著而趣向非家。出家前往闲静之处，住于林中，对那昏沉常常远离，听闻清净之法从无厌足，静虑与正教都无悭吝。请问世间导师种种疑难，听闻之后为他人广为开释，由此增长微妙之智，对白净之法终无退转。）

“像这样，舍利子！诸菩萨摩诃萨为了修行般若波罗蜜多，对这部经典精勤修学，行菩萨行，这名为菩萨摩诃萨在般若波罗蜜多中方便修学的正法要义。”

【按】“精勤修学”之“勤”，明本作“进”。
