# 《大宝积经》卷第八（密迹金刚力士会）

西晋·三藏竺法护 奉诏译

## 密迹金刚力士会第三之一

### 序分：灵鹫山大会

#### 菩萨众的功德

我是这样听说的。一时，佛游化于王舍城灵鹫山，与大比丘众四万二千人在一起，还有菩萨八万四千人。他们都是大圣，神通已经通达，各自在十方其他佛国的法会中，因此特地前来集会于此。他们都已得法忍，至于不退转地，是一生补处；已得总持，辩才无碍；周游十方无数佛土，以神通自在游戏；舍弃一切外道之学，降伏众魔，消除怨敌；平等对待众生，彻见一切的根源，晓了三界众生的根本，普遍契入一切波罗蜜（度无极）。他们常处闲静之中，善巧方便，无所不通。诸佛都赞叹宣扬他们的功德。他们在无数劫中奉行菩萨（开士）之行，积功累德，历经亿、载、兆、姟之久；从无限的久远以来，心平如地；他们所游的诸佛国土境界，不可限量。

他们所行清净，舍弃一切罣碍，除去种种阴盖；身体坚强，犹如钩锁相连之骨，得金刚之志，成就圣道之性；作大狮子吼，独步于大众之中，体解所入之法，得无所畏；光明遮蔽日月，阐扬照耀真实之法。他们平等通达过去、现在、未来三世，能觉悟迷惑，决断疑惑；深入微妙之理，下及缘起，开化刚强难化的众生，舍弃断灭与常住之想；一切禅思、三昧、正受，都能护持通达，处处随意契入；听闻十方的音声，都能领受，无需再问；不断三宝，训诲言教，积德无量，兴隆道宝，超过一切声闻、缘觉之地。

【按】“兆姟”之“姟”，宫本作“垓”，皆数名。慧琳《一切经音义》卷第十一说（解释）：“兆”“垓”都是数法之名，在一、十、百、千、万、亿、兆、京、垓等十五等数中，是第七及第九位的数名。“钩锁”，慧琳说：连环之义。

他们行无尽的慈，遵循无极的悲，摄持四梵行（慈、悲、喜、舍），以四恩（四摄）普遍济度，随时开化度脱；越过三解脱门，至于三达之智（三明）。他们周旋于三界，犹如日月；往来于四方，如同转轮圣王；以勇猛的智慧度脱生老死；出入五趣，如同火炬照破黑暗；心无所著，犹如莲花生于污泥；所行无增无损，犹如虚空，无所增减爱憎；他们宣说三藏，如同国中明君赏赐印绶、授予官号；超越世俗的八法，不因之忧戚欢喜；游入八难之处，化度危厄的众生；以智慧成就，转不退之法轮；解除众生的迷乱，显示真正的本无（真如）之法；发起教化，超越诸分，至于一切智，令三界为之震动；以佛的十八不共法教诲愚冥的众生；远离三毒，如同吹散浮云；以道法之舟往度众生，劝导众生出离十二种生死之海，脱离生死之轮；往来于三处，济度十二因缘中的众生。法会中的诸菩萨都具足功勋。

【按】“无所增爱”之“增”，元、明、宫本作“憎”，今依“憎”义译出。

#### 菩萨众的名号

他们的名号是：月施菩萨、月英菩萨、寂英菩萨、首英菩萨、光英菩萨、光首菩萨，以及首积、首寂、钩锁、龙忻、龙施、执像蜜天、缘胜、缘手、常举手、常下手、宝印手、宝掌、普世、宿王、金刚意、金刚步、不动行迹、过三世度、无量迹、无量意、海意、坚意、上意、持意、增意、常惨、常笑、喜根、善照威、离垢、弃恶趣、去众盖、极精进、智积、常观、光世音、大势至、山顶、虚空藏、不眴、不慕乐、宝上、宝心、善思、善思义、珠结总、豪王、净王、严土、宝事、恩施、帝天、水天、帝罔、明罔、喻天、积快、臂善、白象、香手、众香手、师子、英普、利意、妙御、大御、寂意、慈氏、普首、童真等菩萨。那八万四千菩萨的名号，各如这样。

【按】“不眴”，慧琳《一切经音义》卷第十一说（解释）：眴，动目，即目不瞬动之义。

#### 天龙八部与人众来会

这时，在这三千大千佛土中，大尊威严的帝释、梵天、四天王，以及诸天、龙、神、阿须轮（阿修罗）、迦留罗（金翅鸟）、真陀罗（紧那罗）、摩休勒（摩睺罗伽）、揵沓惒（乾闼婆），各王及其官属都来集会。阿耨达龙王、和轮龙王、摩那斯龙王、多朱龙王、雪色龙王、无量色龙王、须深龙王，以及其余无数百千龙王，连同他们的官属，都来到法会中。闲居阿须轮、须摩质阿须轮、决河阿须轮、顺树阿须轮、璎珞阿须轮、狂惑阿须轮、断绝阿须轮、执鬼阿须轮，各与无数眷属围绕，都来到法会中。摩竭国王萍沙（频婆娑罗）以及宫人眷属，都来到法会中。诸比丘、比丘尼、清信士（优婆塞）、清信女（优婆夷），主天地神、欲界天、色界天、净居天，都来到法会中。

【按】慧琳《一切经音义》卷第十一说（解释）：“阿须轮”即阿修罗，“迦留罗”即金翅鸟，“真陀罗”古云紧那罗，“摩休勒”即摩睺罗伽，“揵沓惒”（健沓和）即乾闼婆。“须深龙王”之“深”，《大正藏》作“修”，CBETA 据高丽藏作“须”。“摩竭国王萍沙”之“萍”，宫本作“英”。异译《如来不思议秘密大乘经》（宋·法护等译）此处作“摩伽陀国主阿阇世王”。

### 菩萨净济之业

那时，世尊与无数百千大众眷属围绕，而为他们说经，宣说菩萨大士的种种事业，这个法名为《净济广布道义》。什么是菩萨的事业呢？

行布施之业，开化众生，救济危厄；修禁戒之业，圆满所愿的十善之事；行忍辱之业，具足一切三十二相、八十种好，庄严自身；行精进之业，所造的德本一切具足，没有缺漏；行禅思之业，志性和安，成就不可思议；行智慧之业，断除种种尘劳（烦恼），成就圣明，化度不明达的人；行博闻之业，得到无碍辩才，所说如流，听的人随即领受；行功德之业，劝导利益众生无限之福；行圣明之业，缘此而得无量至真的辩才；行寂然（止）之业，所发起的事都不可思议；行正观之业，舍弃邪行与无益之事；行慈心之业，常修仁和，从未怀害心；行悲之业，想要济度众生，不厌生死的始终；行喜之业，以法乐自娱，也教化众生令他们仰慕道法；行护（舍）之业，断除无量的罪衅，向人显示罪福，以法兼利他人；行听法会之业，去除种种阴盖，令自己不骄慢自大；行出家之业，捐弃恩爱、眷恋、怨恨之心以及世俗的习气；行闲居之业，所立的要义不失一心；行有志之业，得到总持，念法不忘，以此化度众人；行思念之业，心意晓了，无不通达；行游步之业，理解义理的归趣，有益而无损；行意止（念处）之业，观察身、痛痒（受）、心意（心）、诸法；行意断（正断）之业，断除一切罪恶之法，普修道义与一切妙行；行神足之业，身心轻安，往来趣向危厄之处，救度下劣的众生；行诸根之业，具足寂静，眼、耳、鼻、口、身、心安定不乱；行诸力之业，消除种种尘劳瑕秽的过失，常能自制，也教化众人；行觉意（觉支）之业，畅达自然之法，以通达而端正自己；行于道之业，超越九十六种外道邪径；行真正之业，成就仁义之事，没有瞋喜；行解辩之业，见到众生的心而为他们开示阐明；行自归之业，自身自能通达，不须仰赖他人；行善友之业，通达功勋之门，以智慧德行济度众生；行纯性之业，普遍和顺于三世，没有欺惑；行应时之业，都能具足，超越一切苦难；行圣贤之业，所往之处殊胜特异，超越大众；行宴坐之业，如所听闻之法，常常奉行；行四恩（四摄）之业，聚合大众，为他们演说经法；行正法之业，随顺三宝的教法，令其不断绝；通晓劝助之业，勤加化度众生，庄严清净佛土；善权方便之业，普遍运用，具足一切悲愍与智慧。

世尊这样广为一切大众宣说菩萨之业，名为“清净”。

### 密迹金刚力士赞叹，寂意菩萨劝请

这时，有一位金刚力士，名叫密迹，住在世尊右边，手执金刚，上前对佛说：“真是前所未有！如来至真畅快地宣说了名为《净济》的菩萨事业经典的要义。正如刚才大圣所宣说的这个法，我观察思惟，这一切事业，都入于菩萨的功德业与智慧业之中。为什么呢？那微妙的功德，都是诸菩萨所娱乐、所化现示现的，以此所乐来摄导众生。那智慧之业，菩萨以雅正的言辞，多令众生欢悦。如果有菩萨晓了，扼要地说，功德之业以及修习智慧光明之业，这样的修行就是第一真实至诚。为什么呢？那功德之业，就是菩萨的善权方便，所度无极（方便波罗蜜），具足福庆；那智慧之业，就是菩萨的智度无极（般若波罗蜜），众行完备。以这二种事业普遍具备一切菩萨之道，而恩德广济，一切魔及其官属都不能抵挡，因而度脱魔界。菩萨这样至于不退转，将成就无上正真之道，契合于法的本源。一切不退转的菩萨接近佛世尊，都能得到如来的秘密要藏，随意宣说，从不覆藏隐匿。”

【按】“雅词”，宫本作“杂乱”。

这时，寂意菩萨对密迹金刚力士说：“密迹！你所说的二种事业，接近于如来的智慧。仁者能乐于安住、宣说如来的秘密之业，那不是一切声闻、缘觉之地所能企及的，何况其余凡夫所能企及的呢？”这时，密迹金刚力士默然不答。

这时，寂意菩萨上前对佛说：“密迹力士能否俯允，为这众会适时敷演诸菩萨的秘密与如来的秘要？一切众会都普遍渴仰，想要听闻。如果听闻他所说的，心中坦然，欢喜大悦，奉行菩萨之行，具足成就这秘要之事，心性调和，入于无极的大慈。”

佛告诉密迹金刚力士：“仁者能承担重任，为这众会宣说菩萨的秘密与如来的秘要，千佛都会劝勉赞叹。你宣说诸菩萨的道品诸行，众会都乐于听闻。”

密迹金刚力士上前对佛说：“我少能堪任为众会宣说菩萨的秘密与如来的秘要。如果如来以威神劝勉辅助，加以扶持，我乘着大智慧光明，承受佛的圣旨，才敢宣布诸菩萨的秘密与如来的秘要。世尊！譬如在黑夜昏暗之时，依靠灯火的光明，才能见到形色，往来好丑，东西南北，应当进退之处。正是这样，世尊！如果蒙佛建立、承受佛的圣旨，我就把所知少许，粗略地赞叹宣说。”

佛说：“善哉！就请及时宣说吧。”

### 四不可思议

这时，密迹力士对寂意菩萨说：“仁者请听，以及诸位来会大众，听闻诸菩萨的秘密与如来的秘要，不要恐惧，不要惊怖，不要心怀畏惧。”

这时，寂意菩萨告诉诸会大众说：“如来宣说有四种不可思议，依此得以成就无上正真之道，证得最正觉。哪四种呢？所造立的业不可思议；如龙王般的心志与所行不可计量；禅思一心不可称限；诸佛所行无有边际——这就是四件事。仁者应当知道，这四种不可思议，佛道所行不可思议，最为至尊，以此成就正觉，所以名为四不可思议。诸位仁者集会于此，如果听闻菩萨与诸佛世尊的不可思议，不应当恐怖、心怀畏惧，而应更加踊跃，倍加恭敬，这才能通达大道。”

【按】此四不可思议，异译《如来不思议秘密大乘经》作：“一者、业不可思议，二者、龙不可思议，三者、定不可思议，四者、佛不可思议。”

这时，寂意菩萨随即入于相应的三昧正受，令一切众会听闻如来之法，没有诽谤的人，各各心生欢喜。在一切来集的众会场地上，天上降下种种花，以及随心所念的种种花，散在佛的身上以及众会之上，作为供养。

### 菩萨身密

#### 身的威仪随众生而现

这时，密迹力士对寂意说：“仔细听，仔细听，好好地思惟忆念。我现在将宣布诸菩萨的秘密与如来的秘要：日夜寂然，修习恬淡宁静。

原文：“如来菩萨所言至诚，无分别决乃授道别，从是以往顺从菩萨。五行菩萨，无有谀谄、不为匿訑、不自贡高。”（大意：如来与菩萨所说都是至诚的。自从得授道记以来，我便随从这位菩萨。这位菩萨所行，没有谀谄，不隐匿欺诳，不自贡高。存疑。）

【按】异译《如来不思议秘密大乘经》此处作：“今我世尊昔于然灯如来法中居菩萨位，从彼佛所得授阿耨多罗三藐三菩提记。从是以来，我常随逐释迦菩萨，而是菩萨所有身业曾无异作，亦不见有邪曲之相；语无异作，亦不曾闻虚妄之言；心无异作，亦不曾知爱著之失。”可参看。“匿訑”，慧琳《一切经音义》卷第十一说（解释）：匿，隐藏；訑，欺诳。

“他应时显现相应的形相，自在变化；以自在之心，不计较邪佞非法之业；谨慎身行、威仪礼节，开化众生；口中无所说，不妄发言辞。菩萨的威仪不可限量。

【按】“邪侫”之“侫”，CBETA 据高丽藏录作“侫”，《大正藏》作组字异体。

“再者，寂意！菩萨随顺众生的行为，依其可开化之处，示现一切威仪礼节之事：所行的学问、禅思、礼节，使他们学习种种音响言辞，各令明了；男女所行的举动进止、威仪礼节，各依大小，乃至乳下的婴孩，凡应被教化的，都谨慎示现相应的威仪；长老、中年、少小之类，所应教化的威仪礼节；尊卑、豪贱、明愚的所行，开通或闭塞、通达或愚騃；所行的多少、威仪礼节，都依照教诲，对应当得度的人而开化他们。

【按】“达騃”，慧琳《一切经音义》卷第十一说（解释）：达是智，騃是愚，以相比对。

“对于地狱、饿鬼、畜生之类，诸天、龙、神、阿须轮、迦楼罗、真陀罗、摩休勒，以及人与非人，凡所应开化的，都加以诱导；对于比丘、比丘尼、清信士、清信女，以及帝释、梵天、四天王、大神妙天，凡所应开化的，都加以训诲。菩萨都知道众生的深浅厚薄、难度易化，应病与药而为他们说法，使贪淫的人不贪著财业，建立威仪，随顺礼节。

“菩萨在那里无为寂然，以身修行，不舍静默，显现身的威仪。如果有贪嫉的人，各为他们示现，不惜身命，随时救济。身行清净，身体放出光明，对那些在地狱、饿鬼、畜生中受苦的众生，救济他们的危厄，令他们立于安处，没有种种苦难。

#### 舍身施与与示现化度

“如果有众生多有悭吝之业，就随其所好，示现种种珍宝财物，令他们各得其所。头、目、肌肉、骨节、肢体、髓脑，妻子、群从、车马、奴仆、衣裘，随其心意所乐，都施予他们；如果求甘美的饮食、上好的衣被，都令他们满意，各得其所。他受取众生无数之身，法界无量，安置于无处，饱满一切。道智无穷，各现其身，在十方不可限极，因缘方便也不可穷尽。以无数之身随时现形，开化众生，各令得其所宜。

原文：“法界无量举安无处饱满一切”（大意：法界无量，安置于无处，饱满一切。存疑。）

【按】“法界无量举安无处饱满一切”一句，异译《如来不思议秘密大乘经》作：“由彼菩萨知身无量，即能随知法界无量。无量即无尽身、无尽门，即是缘生无尽法门。”

“如果有众生多贪欲，淫想情色，就化现女像，端正殊妙，那人见了，喜悦敬向，与她共相娱乐，看了不厌，如同宝贵的明珠；忽然间，她变得臭秽，颜色极为丑恶。那人见了这样的变化，心生厌患；菩萨便示现死亡，使他更觉丑恶，接着为他说法：无常、苦、空，一切三界犹如幻化，没有一个是真实的。那人听了就通达，便发起无上正真道意，得不退转。

“又那位菩萨以一顶宝盖覆盖这三千大千世界，无不周遍，又能把它纳入一粒芥子之中。如果劫火燃烧时，他把一切都举放在一只手掌上，他的身体并不增大，也没有增减。他以身供养十方诸佛世尊，又变化出如须弥山那样大的花，怀在衣襟之上，成为花盖，贡献给如来；化作一个如千佛国土那样大的香炉，作一个如须弥山那样大的灯炬，供养如来，照耀恒河沙数诸佛国土，以此贡献给佛。他用细帛与白㲲裹覆自身，灌上麻油，作为灯火，自身自然放出光明，照遍三千大千佛土。如果有众生见了而觉得奇怪，探问其中的缘由，或者得以想念菩萨的境界。见到这样的变化，无数的众生都发起道心，得到悦意，充实饱满。

【按】“㲲”字先前电子文本未能显示，今据《大正藏》补出。慧琳《一切经音义》卷第十一说（解释）：“裓”是衣襟；“緤”（㲲）是西国的布名。

#### 示现大力士与冢间舍身

原文：“被弘誓铠现和罗势，执于无极，手持金刚力士侍佛而自显燿，众人恐怖，自归作礼菩萨大士。”（大意：菩萨披着弘誓之铠，现出威德的形势，手持金刚，以金刚力士之身侍立佛旁而显现威光；众人恐怖，都归依礼敬这位菩萨大士。）

【按】“和罗”，慧琳《一切经音义》卷第十一说（解释）：是梵语，唐言“威德”。异译《如来不思议秘密大乘经》此处作：“其中所有憍慢贡高诸有情类，菩萨即现大力那罗延身、或金刚手菩萨可畏之相。彼等有情见已惊怖，即向菩萨折伏其心，归命顶礼求哀听法。”

“众人听受经法。菩萨又示现大力士身于冢间：在大群人众聚集之处，自己示现身死，形体广大修长，弃置在大冢之间；种种禽兽来吃他的肉，四足、两足的众生都吃他的身体，命终之后都得以生天。以此为根本，乃至最后灭度，这都是菩萨本愿殊特所致。为什么呢？那位菩萨最初发心时，心中自己立誓说：‘假使有人、禽兽、飞鸟，见到我身死后来吃我的肌肉，命终就生天，度脱世间，证得道果，奉持禁戒，所愿都得成就。’正是这样，寂意！应当这样观察：菩萨所行，随时以相应的仪轨来开化众生。”

#### 本生：仁良虫

密迹金刚力士对寂意菩萨说：“在久远的过去世，这阎浮利（阎浮提）天下广大，统合为一个区域，有八万四千个国家，其余郡县丘聚有无数百千个，人民炽盛，不可计数。那时，财宝衣食自然周遍充满，种种奇异的宝树交错缠络在屋宅之间。这些众生有种种疾病，不安，多受病患，多有羸瘦的人：有金疮、疮疡、疽痛等恶疾，又有无数百千良医都不能治疗。众人得病积有年岁，不能自安，求哀投归。这些人遭遇这样的苦厄，没有救护，各自呼天抢地，呼求天、龙、神、揵陀罗（乾闼婆）、真陀罗、摩休勒、人与非人：‘谁能治疗、消除我们的病厄？’

“菩萨那时作为一切人之首，示现为良医，治疗众人的疾病，常以慈心专精奔走，侍从在病人之后，犹如奴仆一样，供给他们所需，以报答恩慈，济度他人的危厄。所以，寂意！在往古之世，现在这位世尊，当时作天帝释，名叫善自。他在天上远远看见众人得了种种疾病，困厄难言；以天耳听到众人困厄中的呻吟悲叹。他见闻这些之后，兴起大悲哀，心中自念：‘现在这些人遭受困厄，极为困苦，无所归依。现在我应当救济众人的困厄：对没有救护的人，为他们建立善妙的救护；对无所依止的人，为他们设立种种依止；对无所归投的人，为他们造作可受的归处。’

“那时，天下阎浮利中有一个大国城，名叫具留。那时，天帝菩萨在离国城不远之处，化作一只虫兽，名叫仁良，自然化生在那个国界之内。这时，天帝释前往虚空中，以偈颂告诉天下阎浮利的人们说：

```
去此国土不大远，
而有一虫名仁良，
其有服食此虫肉，
则得免济一切厄。
汝等勿恐莫怀惧，
睹其虫身恣取肉，
终不抱瞋无厌秽，
斯是神妙好良药。
```

（大意：离这个国土不远之处，有一只虫名叫仁良，凡是服食这只虫的肉的人，就能免除一切病厄。你们不要恐惧，不要心怀畏惧，见到这只虫的身体，就随意取它的肉；它终究不会怀瞋，也不会厌恶，这是神妙的良药。）”

密迹金刚力士又对寂意菩萨说：“那时，那大国城、郡县、村落、丘聚中所有患病的人，听到这个声音，都聚集前往具留大国。到了那只虫的所在，各自取它的肌肉，带回去救治疾病，都得以痊愈；而那只虫的身肉如故，没有减少。这时，那国界旷野中的虫说偈颂道：

```
以斯之言要，令众成佛道，
使吾妙智慧，究竟无穷尽。
周习学禁戒，取肌肉施与，
以是至诚辞，速逮正真道。
```

（大意：以这样的誓言为要约：愿令众生都成佛道，使我的妙智慧究竟无穷无尽；我周遍修习禁戒，割取肌肉施与众生，以这至诚之言，愿迅速证得正真之道。）”

密迹金刚力士说：“正是这样，寂意！那天下阎浮利所有患病的人，都前往割取那仁良虫的肉，全都服食，治疗身体的疾病，无不痊愈。那时，那只虫慈愍众生，它的身体如故，也不增也不减；人们各自截取，又生长如故，身体完整，也没有缺漏。郡国、县邑、州城、大邦，所有受苦患的人，敢来吃这仁良虫的肉的，都得到安隐。七日之中，使天下人不再有疾病众患之难，只是除去了身病，还未消除心病——淫、怒、痴之疾。

“那时，天下男女大小都得安隐，不再有身体的病患，各自心中念道：‘现在我们的身体，以什么方式报答仁良养育的慈恩呢？它能承担众人的病苦，使我们病愈，身得安隐，永无众患。’病愈的人们共同集会，前往具留国，到了仁良虫的所在，都一起合掌，为仁良虫说这首偈颂：

```
仁为是救护，仁身良医药，
咸令我除患，以何报仁养？
```

（大意：您是我们的救护者，您的身体是良医妙药，使我们都除去病患，我们以什么来报答您的养育之恩呢？）

“这时，仁良虫隐没了自己的身体，现出天帝的形相，为大众说偈颂道：

```
如吾今日身，不用众居业，
不以饮食供，金银及珍宝，
不以好象车，不快马细车。
男女诸大小，咸共心和同，
皆改往修来，身奉行十善。
各相向慈心，展转相愍伤，
相见如骨肉，犹如父母子，
心不怀害念，乃报其慈养。
```

（大意：像我今天这样的身体，不需要你们种种居家的产业，不要以饮食供养，也不要金银与珍宝，不要好的象车，也不要快马细车。只愿男女大小都同心和合，都改正过往、修持未来，以身奉行十善；彼此以慈心相待，辗转相互怜愍，相见如同骨肉，犹如父母与子女，心中不怀害人之念——这才是报答我的慈养。）”

【按】“男女诸大小咸共心和同”之“共”，《大正藏》作“供”，CBETA 据高丽藏作“共”。

密迹金刚力士对寂意菩萨说：“那时，那些人听了他的训诲，由于宿世福德的感化，都一起奉行这十善业，具足清净，不令缺漏。正是这样，寂意！那时天下男女大小奉行十善，终身之后，都不堕入恶趣三涂之难，命终之后自然得以生到忉利天上。天帝释又为他们讲说佛法，开示大业，他们都发起无上正真道意，当下都安立于不退转地。寂意应当了知：这就是菩萨所修的秘密之行，护持身行清净，不惜身命，以自身布施，开化救济无数众生，使他们至于大道。”

#### 菩萨身坚固，三世本无不相违

佛告诉寂意：“菩萨身所行的种种秘密，坚固牢强，不可破坏，犹如金刚。他的身体随着众人所学、随顺其志与律而散布，即使有人想毁坏它，也不能破坏。众生以此而学，依所学之法而住，一切都不毁坏。他所宣说的言教，火不能烧，刀不能伤；他的身体坚强，终究不可毁坏。寂意！就像那菩萨之身，身随顺法律，调化众生。那菩萨的心，不住于寂然，也不怀妄想。

“一切众生之身，本来都是本无（真如），自己也是这样，本来也是空。由于了知本无：自身本无，一切诸法也本无；诸法本无，又理解自身归于本无，一切诸法也本无；诸法本无，自身自然也归于本无。自身既是本无，过去、未来、现在之法也是本无；了知过去、未来、现在之法本无，又自身也是本无：过去本无、未来本无，彼此不相错乱。未来的本无，不与过去的本无相违；过去的本无，不与现在的本无相违；现在的本无，不与过去的本无相违；现在的本无，不与过去、未来相违；过去、未来的本无，不与现在的本无相违；那未来的本无，不与现在的本无相违；过去、未来、现在的本无，不与现在的本无相违。行于那过去、未来、现在本无的人，于诸阴（蕴）、诸种（界）、诸入（处）、众衰、四大，从来不相违背。

【按】“本无”，竺法护译语，即真如。异译《如来不思议秘密大乘经》此段皆作“真如”，如：“自身真如即入一切有情身真如……亦非过去真如与彼未来现在真如有所违背。”

“假使生死与无为自然都是本无：生死本无，以无所行为本无自然；无行本无，不违于本无；诸行本无，自然如此。又，族姓子！所说的本无，那本无平等无异，不离于欲，无所成立。本无是没有诤讼的；那诤讼者与种种诤讼也无所诤；由于无所诤，那本无也无所诤，这就名为如来的本无。

#### 如来形像与法身

“如来没有形像，归于这本无，这就名为如来的形像。普遍示现一切所有的色像，所以形像就是如来的形像，一切本来都是空的，这就名为如来之像。所以菩萨示现一切形像，而如来从未造作、显现形像。无像、无诤，才能普遍示现一切众像，而不是以本无有所成立。

“以本无之业观察自身：诸身本无；自己观察法身与一切诸身，都没有身。观察如来之身，了知一切身都是从因缘而生；由于了知法身本来所从而行，因与法身而成就法身。没有阴、种、诸入，就名为法身，行于平等之业，消除众生所见之缘，无论所闻、所经历的粗细之事。

#### 耆域医王药童子之喻

“寂意！譬如耆域医王合集种种药物，用药草作成童子之形，端正美好，世所稀有；所作安稳详审，所有的一切究竟殊异，无与伦比；往来周旋，住立、安坐、卧寐、经行，没有缺漏，所显现的种种变化事业都具足。有大豪族、国王、太子、大臣、百官、贵姓、长者，来到耆域医王那里，看见药童子，与他一起歌戏，看着他的容颜，疾病都得以消除，便得安隐、寂静、无欲。寂意你看：那耆域医王治疗世间的疾病，其余的医师都比不上他。

“正是这样，寂意！如果菩萨奉行法身，假使众生淫、怒、痴炽盛，男女大小彼此爱慕而共相娱乐，贪欲尘劳都得以止息；由于得以止息，内心止息了欲想，远离了热恼之欲，因此受到教化——这都是菩萨的愿行具足所致。

【按】“耆域医王”，异译《如来不思议秘密大乘经》作“耆婆医王”，并作“精妙和合成女人相”，与此作“童子形”不同。

“正是这样，寂意！如果菩萨善修法身之行，这些菩萨就是法身。他们示现以饮食充实身体，其实不吃抟食来安养身体，已经断除一切饮膳；只是由于怜愍众生，才示现再饮食；饭食并不进入体内，也不附著于身中，而那法身之力也不增不损。菩萨的法身，不知所生，也没有死，无终无始，而随顺习俗，示现有生有死。虽然示现命终，却了解一切法都无所行；示现受生，却畅达一切法无为、无会。一切诸法虽然有所生，其实都无所生；完全了知诸行，自己示现其身；即使示现诸根缺减而游行，也不毁坏法身，以法身、法食、法力，以法为归依，了达如来之身。

【按】“抟食”之“抟”，宫本作“搏”。

#### 如来身即虚空身

“寂意！想要了知如来之身吗？那就是虚空之身，无与伦比；处于三界最为至尊；施予众生，身无所归；不可譬喻，没有比类。他的身体清净，舍离垢秽，没有尘埃；他的身体本来清净，没有沾污，自然鲜明，永无尘暗；本性仁和，都无所生。他的身体寂然，不为心、意、识所见所拘系。他的身体自然，犹如幻化、阳焰、水中之月。他的身体已度过空、无相、无愿。他的身体普遍周遍十方虚空，心都平等，了知三界的本源，一切众生无有吾我。他的身体无底，不可限量，无作无想。这个身体无著，无所思念，所住的真谛达到不可退还之地。

“他的身体无像，却自然现像；无痛（受）却现痛；自然无想，却现有想；没有生死之识，却自然示现种种生死之识；没有地、水、火、风，却因此示现地、水、火、风四大之身。了解种种世间一切现法都是虚假不实的：眼无所见，耳无所闻，鼻不嗅香，舌不在味，身不倚于所行，永远消除众识；意无所受，心无转移，没有心、意、识，了解真谛，从来不进不退。

【按】“其身本净而无沾污”之“沾”，先前电子文本作“玷”，今据《大正藏》作“沾”。

#### 菩萨身密的普现与无量

“那时，寂意！这就是如来的法身。如果有菩萨能证得这样与如来相等之身，就无不周遍地奉行菩萨之行：在这三千大千世界的四方区域、郡国、县邑、州城、大邦，都化现其身，普遍示现；一切众魔都不能见知菩萨所作的事；现与不现，都能明了微妙的事业。虽然无所示现，却普现一切，从未在念行、见闻知识上有所修行，而开化众生；不因为身行而失去四意止（四念处）。为了众生之类，因而示现其身无常、苦、空、非身之义，了达诸身的本法都是寂灭的。为众生示现身归于坏败：那些依果报而求身的人，因此退转；以此求报，就随顺四颠倒。那些能够解了、睹见无作无见的人，晓知其身犹如草木、墙壁、瓦石，菩萨就为这些众生示现清净之身。

“正是这样，寂意！自从菩萨在锭光佛（燃灯佛）那里得授决（授记）以来，就证得了这秘密之身、清净之体。即使菩萨口有所宣说，其实都无言说。又，寂意！如来所说，是随时之宜，依其想念，宣说菩萨秘密之身的寂静，从此转进，而得拔济，所至无边。所说的菩萨身之秘密，是由于得到自在的缘故。菩萨宣说自身的寂密，我只是粗略地举出其要点；假使想要具足宣说，就是经过恒河沙劫，也不能说尽。”

【按】“宣己身寂密”之“寂”，《大正藏》作“秘”，CBETA 据高丽藏作“寂”。“锭光”，慧琳《一切经音义》卷第十一说（解释）：前劫中的佛名。“江河沙劫”之“江”，元本作“洹”，明本作“恒”。

### 菩萨语密

密迹金刚力士对寂意菩萨说：“什么是语密呢？那言语清净：随着众生的种类，乃至堕在畜生中的多少数目，菩萨也示现种种音响言语；观察他们的音响，示现种种言辞，随顺那些众生的章句言语而演说言教，随时宣说而与他们交谈，说他们苦乐善恶之处。那菩萨的音声，普入一切，无所不达。有时以歌戏、幻化、瞋喜来演说他的音句，随顺众生的言辞音响而入于教诲。依照他们一切身意所信、心所好乐，菩萨都了解而分别，各使他们听闻明了。”

寂意菩萨问密迹力士：“菩萨所化现的音响是怎样的呢？”

密迹回答说：“随从众生的一切音响。又菩萨的音声所随顺的无有限量，犹如众生所生之处，心念各不相同，五趣的音辞各各不同，不可称计。菩萨这样各各随从其音辞，而其实也没有言辞，这就名为随众生之音而无不通达，晓了其无所有。应当这样观察：一切众响所宣的言辞，终究一切不可思议，言语没有穷尽，这就是菩萨所化，随时而不可譬喻穷尽。他随意宣说不可计数的音响：或演说帝释、梵天、四天王的声音，或又随意宣说诸天、龙、神、阿须轮、迦楼罗、真陀罗、揵沓和、摩休勒、人与非人的声音，随顺众生上、中、下的声音，粗细好丑，而演说音响，令一切欢喜。”

于是说偈颂道：

```
以如言辞，多所解决，敷演无数，所说言教。
疗以慈心，达入愍哀，宣布广说，喜悦护意。
天帝合集，柔软和调，若有闻斯，蔽众音响。
因从伎乐，所演悲声，颁宣斯出，经典训诲。
诸真陀罗，思好雅颂，其音喻此，普悉具足，
闻令欲止，淫心不兴。一切山神，皆好音乐，
计于欲界，众诸妙音。诸伎乐出，诸天声响，
皆悉起此，诚可爱悦。其法音声，随时方便，
所宣歌颂，消瞋恚欲，除去痴慢，自大之行，
分别畅了，行所归趣。以闻道术，宣传之故，
其在色界，一切诸天，皆能悦可，斯诸天意。
因得听闻，殊异言教，在世发意，当成佛道。
```

（大意：以如是的言辞，多所解答决疑，敷演无数所说的言教；以慈心疗治，深入悲愍，宣布广说，令人喜悦，护持其意。天帝集合众音，柔软和调，如果有人听闻，能盖过一切音响。随顺伎乐所演奏的悲声，宣说出经典的训诲；诸真陀罗喜好雅颂，那音声譬喻于此，普遍具足，听了令欲望止息，淫心不起。一切山神都喜好音乐，乃至欲界一切美妙的音声、种种伎乐所出、诸天的声响，都从这里生起，实在可爱可悦。那法的音声随时方便，所宣说的歌颂，消除瞋恚与欲望，除去愚痴、我慢、自大之行，分别畅了所行的归趣。由于听闻道术、宣传其法的缘故，在色界中的一切诸天，都能令他们心意欢悦；因得听闻殊异的言教，在世间发心，将成就佛道。）

【按】“德海若宣”等句为四言偈，原文作一句四字，今每行两句录出。

```
龙揵陀罗、摩休勒等，一切妓乐，若干种品。
德海若宣，微妙音教，众生皆悦，心豫踊跃。
入无央数，若干音响，阎浮天下，所居人民。
其音普遍，入斯众生，若得闻者，悉得度脱。
虚空天神，及此地祇，其声通达，咸至彼间，
皆得闻教，莫不悦豫，佥然决疑，悉心欢欣。
哀鸾鹄雁、赤嘴鸦音、山鸟孔雀、鹦鹉鹍鸡、
雁殊异鸟、耆域鸳鸯、若闻此声、皆可意悦。
师子虎狼、熊罴猿猴、麑鹿骡驴、野狐诸兔、
象马狗犬、牛羊猪类，闻其音声，可意喜悦。
四足二足，诸有形貌，其多诸足，诸无足者，
皆乐闻是，解知音声，宣布受诲，舍众邪业。
```

（大意：龙、揵陀罗、摩休勒等的一切伎乐，种种品类；德海若宣说微妙的音教，众生都欢悦，心中欢喜踊跃。它入于无数种种音响，阎浮天下所居的人民，那音声普遍入于这些众生，如果有人听到，都得度脱。虚空中的天神与这地上的地祇，那声音通达，都传到他们那里，都得听闻教法，无不欢悦，都决除疑惑，满心欢喜。哀鸾、鸿鹄、大雁、赤嘴鸦音鸟、山鸟、孔雀、鹦鹉、鹍鸡、大雁等殊异之鸟、耆域鸟、鸳鸯，如果听到这声音，都心意欢悦。狮子、虎狼、熊罴、猿猴、麑鹿、骡驴、野狐、诸兔、象马、狗犬、牛羊、猪类，听到它的音声，都心意喜悦。四足、二足、一切有形貌的，多足的、无足的，都乐于听闻，了解其音声，宣布受教，舍弃种种邪业。）

【按】慧琳《一切经音义》卷第十一说（解释）：“鵾鸡”似鹤而大；“鵶音”是乌鸦之类，形小而嘴足皆赤。“麑”，慧琳以为当作“麋”，今照原文录出。

```
于斯三千，诸国有音，最上中间，及豪下贱，
地狱饿鬼，至畜生类，诸天人民，众诸音响，
行无妄见，唯念至真。亦无想求，未曾诤讼，
奉行所业，志存道心。颁宣令现，当应时节，
己以专一，忍众生诤。以音教告，百亿国土，
从是通达，江河沙数，不倚财业，心无所行。
诸佛国土，所有众魔，此等得闻，斯大和声，
悲哀将护，所救如是，出入行步，悉为兴礼。
正使众生，有百千亿，其心各抱，若干志念；
闻是言辞，不以蔽碍，叉其十指，稽首作礼。
```

（大意：在这三千世界中，诸国所有的音声，最上、中间以及豪贵下贱的，地狱、饿鬼乃至畜生之类，诸天人民的种种音响，所行没有妄见，唯念至真；也没有想求，从不诤讼，奉行所业，志存道心。宣说显现，适应时节，自己专一，忍受众生的诤论。以音声教告百亿国土，从此通达恒河沙数的世界，不倚恃财业，心无所行。诸佛国土所有的众魔，这些都得以听闻这广大和雅之声，悲哀将护，所救就是这样；出入行步，都为他们兴起礼敬。即使众生有百千亿，他们的心各抱种种志念，听了这样的言辞，没有障碍，都合起十指，稽首作礼。）

```
卧寐聋哑、口不能言、跛蹇无足，诸大疾病；
彼若闻此，微妙善语，宣畅柔和，至好音教，
心常怀念。尘劳危厄，口所宣说，亿载尘劳，
其得闻是，清净法音，开化乌鸟，致于清凉。
口所宣布，众生悉闻，诸佛经法，及诸圣众，
布施禁戒，行忍辱事，精进一心，智慧之法。
说意所存，功勋众行，亿百千劫，不能畅尽。
本际无底，其意无量，演于佛音，所往无极。
```

（大意：卧床不起的、聋哑口不能言的、跛蹇无足的、患种种大疾病的，他们如果听到这微妙善语，宣畅柔和、最好的音教，心中常常怀念。尘劳危厄，口所宣说的亿载尘劳，他们听到这清净的法音，开化乌鸟之类，都得到清凉。口所宣布的，众生都听到：诸佛经法以及诸圣众、布施、禁戒、行忍辱之事、精进、一心、智慧之法。所说的心意所存、功勋众行，即使亿百千劫也不能说尽；本际无底，其意无量，演说佛音，所往无极。）

【按】“卧寐聋瘂”之“聋”，明本作“龙”。本卷相当于异译《如来不思议秘密大乘经》卷第一至卷第三前分（菩萨身密品、菩萨语密品之初）。
