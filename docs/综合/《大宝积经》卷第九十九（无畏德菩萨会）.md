# 《大宝积经》卷第九十九（无畏德菩萨会）

元魏·三藏法师佛陀扇多 译

## 无畏德菩萨会第三十二

【按】译者题名“魏”，元、明本作“魏北天竺”；“法师”二字，元、明本无；“译”，元本作“第五译”。本会异译有西晋竺法护译《佛说阿阇贳王女阿术达菩萨经》（T0337），“阿术达”即无畏德。

#### 序分

如是我闻：一时，婆伽婆住在王舍大城耆阇崛山中，与五百比丘众在一起。菩萨摩诃萨无量无边，又有八千位菩萨摩诃萨为上首，都得三昧以及陀罗尼，善入空、无相、无愿三解脱门，善巧于诸神通，得无生法忍，他们是：弥楼菩萨、大弥楼菩萨、常入定菩萨、常精进菩萨、宝手菩萨、常喜根菩萨、跋陀波罗菩萨、宝相菩萨、罗睺菩萨、释天菩萨、水天菩萨、上意菩萨、胜意菩萨、增上意菩萨摩诃萨，这八千人等为上首。那时婆伽婆依王舍城而住，无论国王、王子、诸婆罗门、长者、居士，都尊重赞叹，供养佛。那时世尊被无量百千万大众恭敬围绕，为他们说法。

【按】“而为上首”之“而”，宫本作“如”。

#### 无畏德女见声闻不起

那时尊者舍利弗、尊者大目犍连、尊者大迦叶、尊者须菩提、尊者富楼那弥多罗尼子、尊者离波多、尊者阿湿卑、尊者优波离、尊者罗睺罗、尊者阿难，这样等无量声闻，在早晨整衣持钵，进入王舍城，挨家挨户如法乞食，没有别的事缘。当时诸声闻这样乞食，渐渐来到阿阇世王所住的宫殿。到了王那里，退立一面，默然而住，不说乞食，也不说不乞食。

【按】“大目犍连”之“犍”，宫本作“揵”，下同。

那时阿阇世王有一个女儿，名为无畏德，端正无比，无匹无双，无与并列、无与同类，成就最胜殊妙的功德，年方十二，在她父王的堂阁之上，穿着金宝鞋，坐在那里。当时无畏德见到诸声闻，不起身，不迎接，默然而住，不与他们问答，不迎、不礼、不让床座。阿阇世王见无畏德默然而住，便告诉她说：“你难道不知道，这些都是释迦如来的上足弟子，成就大法，是世间的福田吗？他们是为了愍念众生而乞食的。你现在既然见到了，为什么不起身、不迎接、不礼敬、不与他们相问，又不让座？你现在看见了什么事，竟不起身迎接？”

【按】“复不让坐”之“复”，《大正藏》作“彼”，今依CBETA（所录高丽藏）作“复”；“让”，宫本作“请”。

#### 女以诸喻答父王

那时无畏德对父王说：“请问大王，可曾见过或听说过转轮圣王见到诸小王而起身迎接吗？”王说：“没有。”又说：“大王！可曾见过或听说过狮子兽王见到野干时为它起身迎接吗？”王说：“没有。”又说：“大王！可曾见过或听说过帝释天王迎接其余天人吗？大梵天王可曾礼敬其余天众吗？”王说：“没有。”又说：“大王！可曾见过或听说过大海之神礼敬江河池沼等神吗？”王说：“没有。”又说：“大王！可曾见过或听说过须弥山王礼敬其余小山王吗？”王说：“没有。”又说：“大王！可曾见过或听说过日月光神礼敬萤火虫吗？”王说：“没有。”

【按】“无畏德白父王言”之“德”，宫本无。“师子兽王”之“兽”，宋、宫本作“狩”。

女儿说：“大王！像这样，菩萨发心趣向阿耨多罗三藐三菩提，如转轮圣王，以大慈悲初发心之后，怎么会礼敬离开大慈悲的小乘声闻？大王！可曾有已求无上正真正觉之道的狮子兽王，而去礼敬小乘的野干之人？

【按】“颇见已求”之“见”，宋、元、明、宫本作“有”，与下文“颇有”诸句相次，今依此译。

“大王！可曾有已求大梵之道处而精进的人，反去亲近善根微少的声闻人吗？

“大王！可曾有想到达大智之海、想求善知大法之聚的人，反去求如牛蹄迹般的声闻人吗？因为他们是从他人听闻音声而得解的。

“大王！可曾有想到达佛这须弥山、为了求如来无边色身的人，反去求那小如芥子中空的三昧之力的声闻人而礼敬他们吗？

“大王！可曾有人听闻诸佛如来的功德智慧如日月之光，听闻之后才去礼敬如萤火虫的声闻人吗？因为诸声闻只能自润自照，是从他人听闻音声而得解的。

“大王！佛入涅槃之后，尚且不礼敬诸声闻人，何况现在世尊在世。为什么呢？大王！若有人亲近声闻人，这人便发声闻之心。若有人亲近缘觉人，这人便发缘觉之心。若有人亲近正真正觉，便发阿耨多罗三藐三菩提心。”

【按】“尚不礼敬”之“尚”，宫本无。

无畏德女这样说了之后，以偈回答父亲阿阇世说：

```
譬如人至海，而取一文钱，
我见诸声闻，所行亦如是。
至大法海已，舍大乘宝聚，
而起狭劣心，修行小乘道。
如人亲近王，出入无障碍，
从王乞一钱，彼人徒亲王。
敬心近轮王，从乞百千财，
润无量贫穷，是名善亲王。
如人求一钱，声闻亦如是，
不求真解脱，而取小涅槃。
若起狭劣心，自度不度他，
犹如小医师，唯自治己身。
譬如大医王，疗治众多人，
善起慈悲心，得恭敬名称。
彼医得世利，以达医方故，
自度不度他，智者不恭敬。
如善巧医王，通达众方已，
救无量千亿，病苦诸众生。
彼医得世间，恭敬及名称，
发菩提心者，普治烦恼病。
```
（大意：譬如有人到了大海，却只取一文钱；我见诸声闻的所行也是这样。到了大法之海，舍弃大乘的宝聚，而生起狭劣之心，修行小乘之道。如人亲近国王，出入没有障碍，却向王乞一文钱，那人白白亲近了国王。以恭敬心亲近转轮王，向他乞得百千财物，润泽无量贫穷之人，这名为善于亲近国王。如人求一文钱，声闻也是这样，不求真正的解脱，而取小涅槃。若生起狭劣之心，自度而不度他，犹如小医师，只医治自己的身体。譬如大医王，疗治众多的人，善于生起慈悲之心，得到恭敬与名称。那医师得到世间之利，因为通达医方，若只自度而不度他，智者便不恭敬他。如善巧的医王，通达众多药方之后，救治无量千亿病苦的众生；那医师得到世间的恭敬与名称，发菩提心的人，普遍医治烦恼之病。）

```
大王蓖麻林，花香影不妙，
声闻如蓖麻，不救世发心。
如至树王所，多众得利益，
诸菩萨亦尔，能益一切众。
不以秋阳焰，能竭诸小水，
至于大海已，能润无量众。
声闻道狭劣，犹如牛蹄迹，
不能灭众生，所有诸烦恼。
非上诸小山，而现金色身，
唯升须弥山，悉见金色身。
大王诸菩萨，亦如须弥山，
以彼住世故，世间得解脱。
皆是一色身，一切智具足，
声闻智不尔，其犹如朝露。
不能润于世，以不证法故，
如地多增长，润益无量众。
声闻如花露，菩萨如大雨，
亲近得大法，如海之润势。
犹如踯躅花，无彼微妙香，
男女所不乐，唯喜薝卜花。
如求青莲花，花香甚奇妙，
踯躅如声闻，彼智不润众。
犹如薝卜花，诸菩萨亦尔，
愍念众生故，能化众生众。
```
（大意：大王，蓖麻林的花、香、树影都不美妙，声闻如同蓖麻，原文“不救世发心”一句，存疑。如到了树王之处，众多的人得到利益，诸菩萨也是这样，能利益一切众生。秋天的阳焰，只能晒干小水，到了大海，能润泽无量众生。声闻之道狭劣，犹如牛蹄印中的水，不能灭除众生所有的烦恼。登上小山，不能现出金色之身；只有登上须弥山，才都现出金色之身。大王，诸菩萨也如须弥山，因为他们住世，世间得到解脱。都是同一色身，一切智具足；声闻的智慧不是这样，犹如朝露，不能润泽世间，因为不证得法；如大地增长万物，润益无量众生。声闻如花上的露水，菩萨如大雨；亲近菩萨得到大法，如大海般润泽之势。犹如踯躅花，没有那微妙的香气，男女都不喜爱，只喜爱薝卜花。如求青莲花，花香甚为奇妙；踯躅如同声闻，他们的智慧不能润泽众生。犹如薝卜花，诸菩萨也是这样，因为愍念众生，能教化众生。）

【按】“而现金色身”之“而”，宋、宫本作“如”。“无彼微妙香”之“彼”，元、明本作“比”；“香”，宫本作“音”。“薝卜”之“薝”，《大正藏》作“檐”，今依CBETA（所录高丽藏）作“薝”。

```
大王颇曾知，何者大奇特？
一人在旷野，如利多人是。
若欲善安隐，度无量众生，
应发菩提心，勿取二乘道。
世间旷野中，能济失道众，
如彼善导师，诸菩萨亦尔。
大王颇曾见，小栰度大海，
唯乘彼大舶，能度无量众。
大王声闻栰，菩萨如大舶，
修道法薰已，令渡饥渴海。
大王颇曾见，乘驴堪入阵？
唯见乘象马，鬪战便得胜。
声闻如驴乘，菩萨如龙象，
降魔坐道树，度无量众生。
犹如夜虚空，见诸星不现，
满月显现故，能照阎浮提。
声闻如星宿，菩萨如满月，
愍念众生故，示现涅槃道。
不以萤火光，能令有所作，
日光照阎浮，令作种种事。
声闻如萤火，不能多利益，
佛具解脱光，愍念一切众。
不以野干声，能令兽王恐，
唯有师子王，一吼飞鸟落。
```
（大意：大王可曾知道，什么是大奇特之事？原文“一人在旷野，如利多人是”，大意为一人在旷野中，却如能利益众多之人，存疑。若想善得安隐，度化无量众生，应当发菩提心，不要取二乘之道。在世间的旷野中，能救济迷失道路的众人，如那善于引导的导师，诸菩萨也是这样。大王可曾见过，用小筏渡过大海？只有乘那大船，才能渡无量的众人。大王，声闻如小筏，菩萨如大船，以修道之法熏习之后，令众生渡过饥渴之海。大王可曾见过，骑驴能上阵作战？只见乘象马作战才能得胜。声闻如驴乘，菩萨如龙象，降伏魔军，坐于道树之下，度化无量众生。犹如夜晚的虚空，不见诸星显现时，满月显现，能照亮阎浮提。声闻如星宿，菩萨如满月，因为愍念众生，示现涅槃之道。萤火之光，不能令人有所作为；日光照耀阎浮提，令人作种种事。声闻如萤火，不能有多大利益；佛具有解脱之光，愍念一切众生。野干的叫声，不能令兽王恐惧；只有狮子王一吼，飞鸟便落下。）

【按】“大舶”之“舶”，宫本作“船”。“令渡”之“渡”，宋、元、明、宫本作“度”。“师子王”之“师”，《大正藏》作“狮”，今依CBETA（所录高丽藏）作“师”。

```
大王诸声闻，不发菩提心，
不为益众生，除一切烦恼。
大王见此故，不发声闻心，
既发大心已，云何得发小？
大王善得身，能发无上心，
救拔一切众，弃舍小乘道。
善得世间身，复得世间利，
善来在世间，而发无上心。
悕求无上道，救拔诸众生，
若能自他利，彼人善可叹。
亦得世名称，及得究竟道，
以是故我今，不礼敬声闻。
```
（大意：大王，诸声闻不发菩提心，不为利益众生、除去一切烦恼。大王，我见到这些，所以不发声闻之心；既已发起大心，怎么能再发小心？大王，善得此身，能发无上之心，救拔一切众生，弃舍小乘之道。善得世间之身，又得世间之利，善来到世间，而发无上之心。希求无上之道，救拔众生；若能自利利他，那人值得赞叹。也得到世间的名称，以及得到究竟之道，所以我现在不礼敬声闻。）

#### 父王责女我慢

那时阿阇世王对无畏德女说：“你大有我慢，为什么见到诸大声闻而不起身迎接？”女儿说：“大王！不要说这样的话。大王也有我慢，为什么不迎接王舍城内的贫穷之人？”王对女儿说：“他们不是我的同类，我为什么要迎接？”女儿说：“大王！初发心的菩萨也是这样，一切声闻、缘觉都不是同类。”王对女儿说：“你难道没见到诸菩萨等都礼敬一切众生吗？”女儿说：“大王！菩萨为了度化憍慢瞋恼的众生等，令他们得以生起回向之心，所以礼敬一切众生。为了增长众生的种种善根，所以菩萨礼敬众生。而诸声闻没有瞋恨之心，又不能增长善根。大王！假使百千诸佛如来为他们宣说妙法，他们所得的戒、定、三昧也没有增益。大王！声闻如琉璃，菩萨如宝器。大王！譬如瓶子已满，天降雨时连一滴也不能接受。像这样，大王！诸声闻等，假使百千诸佛如来为他们宣说妙法，也不能接受润泽，不能增益戒、定、慧等，也不能令众生发心趣向一切智。大王！譬如大海能接受诸河以及云雨等。为什么呢？因为大海是无量之器。大王！诸大菩萨摩诃萨等演说法时，随所听闻的人都得大福利，增长一切种种善根。为什么呢？因为诸菩萨都是无边的言说之器。”

【按】“汝大我慢”之“汝”，元、明本作“女”。“勿作此语”之“语”，元、明本作“说”。

那时阿阇世王听了女儿的话，默然而住。

#### 舍利弗问住何乘

那时尊者舍利弗这样想：“这无畏德女得大辩才，能这样无尽地言说。我现在上前到她那里，稍稍问她。我且问她：‘你得忍了吗？’”这样想之后，上前问女孩说：“你现在是住于声闻乘吗？”答：“不是。”“你现在是住于缘觉乘吗？”答：“不是。”“你现在是住于大乘之心吗？”答：“不是。”舍利弗说：“若是这样，你住于什么乘而能这样作狮子吼？”女孩回答尊者舍利弗说：“若我现在有所住，便不能作狮子吼。我无所住，所以我能作狮子吼。而舍利弗这样说‘住于什么乘’。如舍利弗所证得的法，那法难道有乘的分别吗？那是声闻、缘觉之乘，还是大乘？”舍利弗说：“你听我说。我所证的法，没有乘与非乘的差别之相，因为是一相，就是无相。”

【按】“汝得忍不”“汝今为住”之“汝”，诸本或作“女”。“大乘心耶”之“耶”，宋、元、明、宫本作“也”。

无畏女说：“尊者舍利弗！若法无相，怎么可以求？”舍利弗说：“无畏德女！诸佛之法与凡夫之法，有什么胜负差别之相？”女孩对尊者舍利弗说：“空与寂静有什么差别？”舍利弗说：“没有差别。”无畏德说：“舍利弗！如空与寂静没有差别胜负之相，诸佛之法与凡夫之法也没有胜负差别之相。又，舍利弗！也如虚空能容受诸色而没有差别，诸佛之法与凡夫之法没有差别，也没有不同之相。”

#### 目连问佛法与声闻法差别

那时尊者大目犍连对无畏德女说：“你见佛法与声闻法有什么差别，而见到这样的诸大声闻不起身迎接、不与酬对、不让床座？”无畏德女回答目连说：“假使星宿遍满三千世界，也不能照明；声闻也是这样，以入定之智才能照知，若不入定便不能觉知。”大目连说：“若不入定，便不能知众生之心。”女孩对目连说：“佛不入定，而在恒河沙等世界如其所应说法，度化众生，因为善知众生之心。何况如微少星宿光明的诸声闻呢？这是诸佛如来的殊胜之事。

【按】“不与詶对”之“詶”，宋、元、明本作“酬”。

“又，大目连！一切声闻可能知道有几个世界成、几个世界坏吗？”大目连说：“不能知道。”女孩对目连说：“声闻可知道有多少诸佛已入涅槃、多少诸佛未来当入、多少诸佛现在正入？”目连回答：“不能知道。”女孩对目连说：“声闻可知道有多少众生多贪欲？多少众生多瞋恚？多少众生多愚痴？多少众生是等分行？”目连回答：“不能知道。”女孩对目连说：“声闻可知道有多少众生受声闻乘？多少众生受缘觉乘？多少众生受佛乘？”目连回答：“不能知道。”女孩对目连说：“声闻可知道有多少众生由声闻度化？多少众生由缘觉度化？多少众生由佛度化？”目连回答：“不能知道。”女孩对目连说：“声闻可知道有多少众生在正定聚、是正见者？多少众生住于邪定聚？”目连回答：“不能知道。”女孩对目连说：“只有如来正真正觉如实善知众生界而为他们说法，这样的事不是声闻、缘觉的境界，何况其余众生。目连！应当知道这是如来的殊胜之事，因为如来具得一切智，是一切声闻、缘觉所没有的。”

#### 誓现香象世界

当时无畏女又对尊者大目连说：“世尊常授记大目犍连在神通中最为第一。目连的神通能知道、能到达香象世界，知道那世界的一切树木都散发上妙的栴檀香吗？”目连回答：“现在才刚听说那世界的名字，怎么能前往那世界？”目连问女孩：“那里的佛名叫什么，在那世界说法？”女孩便回答：“那位佛号为放香光明如来、应、正遍知，在那里说法。”目连对女孩说：“现在怎样才能见到那位佛？”当时无畏女不起于座，不动威仪，而发誓愿：“若菩萨初发心时便能超过一切声闻、缘觉，以这誓愿，愿那放香光明如来在此现身，令诸声闻、缘觉见到那香象世界，以及闻到上妙的栴檀香树。”

当时无畏女发了这誓之后，于是放香光明如来从身上放出光明。因为放光，当时诸声闻都见到那香象世界，以及佛被菩萨众围绕，罗网隐身，为大众说法，他们所说的法在这里都能听到。由于佛的神力，又闻到那些树微妙的栴檀之香。那世界的佛这样说：“是这样，是这样，正如无畏女所说。菩萨这样初发心时，已经超过声闻、缘觉的境界。”

宣说此法时，弥勒菩萨摩诃萨对佛说：“世尊！那妙树之香是什么因缘来的？”佛说：“弥勒！这是无畏女与诸声闻如法论议以及发誓愿，那位佛知道之后，所以以神力现出这样的香以及那世界。而那上妙的栴檀之香遍满这三千大千世界。”

当时无畏女对目连说：“若见到这样不可思议的种种殊胜功德，而还能生起狭劣的小乘声闻之心、只求自度，应当知道他的善根甚为微少。谁见到菩萨成就无量功德之事而不发起菩提之心？目连！可知道那佛世界离这里有多远？”回答说：“不知道。”女孩说：“目连！乘种种神通经过百千劫，能知能见那佛世界，是不可能的。譬如一切竹苇丛林不可计算；超过这样数量的诸佛世界，才有那香象世界。”那时那位佛收摄光明。收摄光明之后，香象世界以及那位如来忽然不现。

【按】“语目连曰”之“曰”，宋、元、明、宫本作“言”。

#### 迦叶问见佛

那时尊者摩诃迦叶对无畏说：“你曾见到那香象世界以及那位如来、应、正遍知吗？”女孩便回答：“大迦叶！如来可见吗？如佛所说：若以色见我，以及以音声求我，他全是行于邪道，不能见如来。因为诸如来的体就是法身，佛法不是可以见闻的，怎么可以知见？随众生以何种方便为乐，佛便示现无障碍之身，因为住于方便。然而大迦叶对我说：‘见到那世界以及见到那佛等正觉了吗？’我见到那佛，不是以肉眼见，因为不是肉眼所见之色。不是以天眼见，因为无所受。不是以慧眼见，因为远离想。不是以法眼见，因为远离诸行。不是以佛眼见，因为远离识的观见。大迦叶！我见如来，也如尊者迦叶所见，因为灭除了无明、爱、见之心。原文：‘大迦叶！我见彼佛，亦如尊者迦叶所见，又复亦见我我所等。’（大意：大迦叶！我见那佛，也如尊者迦叶所见，又也见到我与我所等。存疑。）”

【按】“以离想故”之“想”，宋、元、明、宫本作“相”。

迦叶对女孩说：“若法永无，怎么会生起无明、爱以及我、我所之相？因为所有众生都不可见。”女孩说：“大迦叶！像这样一切诸法永无，他怎么能见？”大迦叶说：“若一切佛法毕竟是无，怎么可以见？”女孩说：“大迦叶！你见到诸佛法有增长之义吗？”大迦叶说：“我尚且不知诸凡夫之法，何况佛法。”无畏女说：原文：“是故尊者大迦叶！彼法不成就，云何有断续而不证者见？”（大意：所以尊者大迦叶！那法不成就，怎么会有断与续，而有不证者的见？存疑。）“大迦叶！诸法永无，不可示现。所以大迦叶！一切法都无。若法本无，怎么能见那清净的法界？大迦叶！若想见清净的如来，那善男子、善女人应当清净自心。”

当时大迦叶对无畏说：“怎样善于清净自心？”女孩说：“大迦叶！如自身的真如以及一切法的真如，若信那真如，不作也不失，这样见，便自心清净。”迦叶问：“自心以什么为体？”女孩说：“以空为体。若证得那空，信自身，便信真如是空，因为一切法性寂静。”

#### 迦叶问正见与内观

那时尊者大迦叶对无畏女说：“你从哪位佛那里听闻这样的法而得正见？如佛所说，发起正见有两种因缘：从他人听闻佛法，以及内心思惟。”女孩说：“大迦叶！借那外在的声音，听闻外声之后再内心思惟。大迦叶！菩萨大士不借他人宣说，不借音声，怎么说是住于寂灭？”迦叶对女孩说：“随所听闻的法而观察，名为观行。”

【按】“汝从何佛”之“汝”，宫本作“女”。“迦叶言女”之“女”，元、明本作“汝”。

当时大迦叶又问女孩说：“菩萨怎样内心思惟？”女孩说：“大迦叶！若与诸菩萨说法、同事，而不生起众生之相，菩萨这样内观，所以名为成就内观。大迦叶！一切诸法具足本际以及中际、后际，因为一切法是真如之体，一切法现在是真如之体。若这样观察，应当知道这菩萨名为成就内观。”迦叶对女孩说：“怎样安立这些法？”女孩说：“大迦叶！应当这样作：如那真如，见无缚无解。”大迦叶说：“怎样见名为正见？”女孩说：“大迦叶！若离开二边之见，不作也非不作，这样见而不见，这名为正见。大迦叶！法只有名字，而离开名字，因为永不证得。”当时大迦叶又问女孩说：“怎样得见自己？”无畏女说：“如尊者大迦叶所见。”大迦叶说：“我不见自身，也不见我所。”女孩对尊者大迦叶说：“应当这样见一切法，因为没有我与我所。”

#### 须菩提问辩才

宣说此法时，尊者须菩提心中大为欢喜，对无畏女说：“你善得大利，能成就这样的辩才。”当时无畏女便对尊者须菩提说：原文：“须菩提！法有可得有不可得，而可求耶？而语我言善得辩才。我有此辩，若我说无有所觉知若内若外，则有辩才。”（大意：须菩提！法有可得有不可得，可以求吗？你却对我说善得辩才。我有这辩才，是因为若我说没有所觉知的内或外，便有辩才。存疑。）

当时须菩提便对女孩说：“你证得什么？得到什么法而有这样快妙的辩才？”女孩便回答：“因为不自己知，也不从他人知所得的善法以及不善法的差别之相。这样知法，不见染净、有漏无漏、有为无为、世间出世间以及凡夫法，因为不见。因为那法体就是佛与佛法，得到佛法而不见佛。须菩提！若是这样，无所觉见，便有这辩才。”

【按】“汝何所证”之“汝”，《大正藏》作“女”，今依CBETA（所录碛砂藏）作“汝”。

须菩提说：“怎样是辩才？”女孩说：“须菩提！如仁者所得的，便这样除灭。”女孩对尊者舍利弗说：“如那法体，无闻无得而有所说。”女孩对尊者须菩提说：“法体可以住吗？又可以增减吗，而能有这辩才？”当时须菩提便对女孩说：“若证得无漏，以及法没有差别，以及没有辩说，因为那法体不可说。”女孩对尊者须菩提说：“对一切法，怎么会生起这样的念头说‘善得其利，得这样的辩才’？”须菩提对女孩说：“是因为得到辩才而说？还是因为没有得到而说？”女孩对尊者须菩提说：“你信佛所说‘一切诸法如回响’吗？”须菩提说：“我信这事。”女孩说：“回响是有辩才，还是没有辩才？”须菩提说：“因为有内在的声音，所以有外在的回响。”女孩对须菩提说：“因为有缘而有声，而有那回响，那回响有什么性相？然而那回响之声没有性相。为什么呢？若是缘生，它便没有生之义。”须菩提说：“一切法是缘生。”无畏女说：“一切诸法的体性不生。”须菩提说：“若一切法的体性是这样毕竟无，为什么如来这样说‘恒河沙等诸佛当成正觉’？”女孩说：“法界可以生吗？”须菩提说：“不可以生。”无畏女说：“诸佛如来一切都是法界的性相。”须菩提说：“不见一切诸法界。”无畏女说：“所有所说的言语是无漏的，而说恒河沙等诸佛当得正觉。原文：‘此言何趣？何以故？法界不生不灭故。一切说非说，以毕竟净故。以彼非事，不可言说，离于实际。’（大意：这话的旨趣是什么？为什么呢？因为法界不生不灭。一切说都是非说，因为毕竟清净。因为那不是事，不可言说，远离实际。存疑。）”

#### 菩萨八法，不论在家出家

须菩提说：“你甚为奇特，既是在家人，而能这样善巧说法，又有这样无尽的辩才。”无畏女说：“须菩提！菩萨无论有取或不取、有闻或不闻、在家或出家，而有辩才。为什么呢？因为心清净便令智慧显现，因为智慧显现便显现辩才。”女孩对尊者须菩提说：“现在可以善说菩萨之行。”须菩提说：“你说，我听。”

【按】“汝甚奇哉”“汝说我听”之“汝”，诸本或作“女”。“言语无漏”之“语”，宫本作“证”。

无畏女说：“须菩提！菩萨因为成就八种法行，所以不能说是在家或出家。哪八法？须菩提！一是菩萨得身清净，决定信解菩提；二是成就大慈大悲而不舍众生；三是因为成就大慈悲，善巧于世间一切诸事；四是能舍身命，以及成就善巧方便；五是善巧于无量的发愿；六是成就般若波罗蜜行，因为远离一切见；七是大勇猛精进，因为修种种善业而无厌足；八是得无障碍之智，因为得无生法忍。须菩提！菩萨成就这样的八法，所以不能说是在家或出家，无论以何种威仪，住于菩提之中没有障碍。”

【按】“无障智”之“障”，明本作“碍”。“不得言在家”之“在”，明本作“拄”。

#### 罗睺罗责高座说法

那时尊者罗睺罗对无畏女说：“这话是不清净的言说。你穿着宝鞋，又坐在高床上，而能这样与诸声闻往复论义。你难道没听说，为不病的人不得说法，以及不得为坐在高床座上的人说法吗？”

【按】“为不病者”之“病”，明本作“净”。

当时无畏女便对尊者罗睺罗说：“你如实知道净与不净吗？尊者罗睺罗！这世间是净吗？”罗睺罗说：“没有净与不净。”无畏女说：“如来制戒，随之受行。而违犯那戒，是净还是不净？若又有人不违犯那戒，是不是净与不净？”无畏女说：“且止且止，不要这样说。若如所说之法、若如所制之戒而修行的人，那人说不净。罗睺罗！因为他证得无漏法，他便没有违犯。因为不违犯，他也没有净与不净。原文：‘何以故？以诸声闻过诸说法、过诸制戒，如来为诸声闻学者来于三界为彼故说。而彼声闻已过三界，以是义故说过不过。诸界如是，以彼不能觉知戒故说净不净。而虚空者唯有言说、唯智力见，是故得说净不净也。’（大意：为什么呢？因为诸声闻超过了诸说法、超过了诸制戒，如来是为了来于三界的声闻学人而说的。而那些声闻已经超过三界，因此说超过与不超过。诸界也是这样，因为他们不能觉知戒，所以说净与不净。而虚空只有言说，只有智力能见，所以可以说净与不净。存疑。）”

【按】“声闻学者”之“学”，明本作“觉”。

罗睺罗说：“净与不净有什么差别？”无畏女说：“譬如真金远离诸垢，作成庄严之具或不作，颜色有什么差别？”罗睺罗说：“没有差别。”无畏女说：“净与不净只是以名字作为差别，没有其余的差别。为什么呢？一切法性远离一切垢，无染无著。”

女孩对尊者罗睺罗说：“你说坐在高广床上不应说法。一切菩萨坐于草敷，胜过坐在高床上，胜过声闻在于梵天。”罗睺罗说：“是什么道理？”女孩说：“罗云！你可见过菩萨坐于什么座而得菩提？”罗睺罗说：“坐于草座。”女孩说：“菩萨坐于草座，所有三千大千世界的帝释、梵天、护世四天王等，以及其余天子，乃至阿迦尼吒天等，都来礼拜，合十指掌，到菩萨那里礼菩萨之足。”罗睺罗说：“是这样，是这样。”当时无畏女问罗云说：“成就这样的法，菩萨坐于草座，胜过坐在那高广大床上，也胜过声闻在于梵天。”

#### 何者是如来真子

那时阿阇世王对无畏女说：“你难道不知这是释迦如来的儿子，在学戒中最为第一吗？”当时无畏女对父王说：“且止大王！不要这样说，说罗睺罗是如来之子。大王！可曾见过或听说过狮子之王生出野干吗？”王说：“没见过。”女儿说：“大王！可曾见过或听说过转轮圣王礼敬其余小王吗？”回答说：“没见过。”女儿说：“大王！像这样，如来是狮子之王，转大法轮，被声闻围绕。大王！若依正法而说，谁是如来的真子？便应回答说：是诸菩萨。所以大王！不能说如来有子、如来无子。若说如来有真子，应当说：若发阿耨多罗三藐三菩提心的人，是如来之子。”

【按】“若依王法”之“王”，宋、元、明、宫本作“正”，今依此译作“正法”。“是如来子”，明本作“是如来真子”。

宣说此法门时，阿阇世王宫内二万诸女发菩提心。原文：“二万天子满足彼法，闻此女师子吼已发菩提心。王复语言：『此是过去未来现在诸佛之子，离诸烦恼学声闻戒，云何真子？』”（大意：二万天子满足那法，听了这女孩的狮子吼后发菩提心。王又说：“这是过去、未来、现在诸佛之子，远离诸烦恼，学声闻之戒，怎么是真子？”存疑。）那时那些天子以花散于佛，遍满王舍城，是为了供养无畏女。

【按】“说此法门时”之“门”，宫本无。“师子吼已”之“已”，宫本作“言”。

#### 女供声闻，同诣佛所

当时无畏女下了那床之后，才礼敬诸大声闻，施以种种微妙饮食，无论可舐的、可嗅的、可咂的，如法供养。那些声闻受供养完毕，她这样说：“请问尊者诸大声闻，为什么早晨离开如来之所而来到这里？应当听法之后再乞食。尊者们先去，我片刻之间也会到那里。”无畏德女在早晨，与阿阇世王以及女孩的母亲，还有王舍城无量人众前导后从围绕，来到如来之所，礼如来足，退坐一面。那些声闻也到了佛所，礼佛足后退坐一面。

【按】“正尔间”之“间”，宫本作“闻”。

#### 现丈夫身，授记离垢如来

那时尊者舍利弗对佛说：“世尊！这无畏德女，这样奇特，得大福利。”佛对尊者舍利弗说：“这无畏女已在过去九十亿佛所发菩提心，在那些佛所种诸善根，是为了求无上的佛菩提。”舍利弗说：“世尊！这女孩能转女身吗？”佛说：“舍利弗！你见她，难道她是女人吗？你现在不应作这样的见解。为什么呢？因为这位菩萨的发愿之力，示现女身是为了度化众生。”

【按】“发愿力故”之“愿”，《大正藏》作“顾”，今依CBETA（所录高丽藏）作“愿”。

于是无畏德女发这样的誓言：“若一切法非男非女，令我现在现出丈夫之身，令一切大众都能看见。”说了这话，便灭去女身，现出丈夫之身，升于虚空，高七多罗树，住而不下。那时世尊便对尊者舍利弗说：“舍利弗！你看见那位无畏德菩萨了吗？在虚空中住而不下。”舍利弗说：“已经看见，世尊！”佛说：“舍利弗！这位无畏德菩萨再过七千阿僧祇劫得成正觉，号为离垢如来、应、正遍知。那佛世界名为光明。佛寿一百劫，正法住世十劫。纯是菩萨僧，有三万不退转菩萨。那佛世界以清净琉璃为地，八道庄严，被莲花所覆盖，没有一切恶道之名，天人充满。舍利弗！如兜率天受微妙之乐以及殊胜的法味，那里的天子们受这样的快乐。”

【按】“皆悉覩见”，《大正藏》作“悉皆覩见”，今依CBETA（所录高丽藏、碛砂藏）作“皆悉”。

#### 母日月光授记

那时无畏德菩萨的母亲名为日月光，与阿阇世王一起，合十指掌，前往佛所，说：“世尊！我得大利，我怀胎九月生了这孩子，而这善男子现在作这样的大狮子吼。我现在把这善根回向阿耨多罗三藐三菩提，此后在那离垢光世界成就无上正真正觉。”于是佛告诉尊者舍利弗说：“舍利弗！你现在看见了吗？”回答说：“已经看见。”佛说：“舍利弗！这月光女舍此身后，生于忉利天，号为光明增上天子。若弥勒菩萨得菩提时，他是那位见王的上足之子，在那里供养弥勒佛之后便出家。那位见王之子对弥勒佛所说之法，初、中、后所说都能忆持。依次都见到贤劫诸佛，都得以供养。这样渐次供养诸佛之后，在那离垢如来得菩提时，得作大王，具足七宝，号为持地。那位见王之子供养这样的诸如来之后，也得成就阿耨多罗三藐三菩提，号为遍光如来、应、正遍知，具足成就，那佛的世界如上所说。”

【按】“号日月光”之“日”，明本作“曰”。“阿阇世王俱”之“王”，宫本作“王妇”。“往至佛所”之“往”，《大正藏》作“住”，今依CBETA（所录高丽藏）作“往”，宫本同。“能忆持”之“忆”，《大正藏》作“亿”，今依CBETA作“忆”。

那时月光夫人欢喜踊跃，便脱下价值百千两金的妙宝璎珞供养佛。告诉大王之后，受五百正戒，具修梵行。

#### 现比丘身，又现女身

那时无畏德菩萨在如来面前这样说：“以这誓愿因缘之力，令我未来得菩提时，诸菩萨也都身披法服。原文：‘一切化生，以此誓愿因缘故，愿令如来犹如年少八腊比丘。’（大意：一切都是化生，以这誓愿因缘，愿令如来犹如年少的八腊比丘。存疑。）”无畏德菩萨这样现身说了这话之后，身披正法之服，便成为比丘，威仪具足。

那时无畏德菩萨对自己的父王阿阇世说：“大王！一切诸法都是这样。”当即忽然现出化生之相，远离种种分别所起之相，没有种种颠倒。“大王！当即此时又现出女身。王看见了吗？”王说：“已经看见。而我不是以色身之相见。我现在见到比丘身之后，又见到女身。”

【按】“忽化生相”之“化”，宋本作“现”。“还即此时”之“还”，宋本作“以”。

原文：“佛问王言：『何者是实？大王！应当作如是学，住一切法中，正见一切。亦生烦恼所烧故，以不达法力故。以不达故，于非疑处而生疑悔。当应数数亲近如来及文殊师利童子菩萨，以彼菩萨威德力故，而令大王得受悔过。』”（大意：佛问王说：“哪个是真实的？大王！应当这样学：住于一切法中，正见一切。又因为被烦恼所烧，因为不通达法的力量；因为不通达，在不该怀疑之处而生疑悔。应当数数亲近如来以及文殊师利童子菩萨，以那菩萨的威德之力，令大王得以受持悔过。”其中“亦生烦恼所烧故”一句，文意未详，存疑。）

【按】“亦生烦恼”之“亦”，元、明本作“众”。

#### 流通

那时世尊告诉阿难说：“你受持这无畏德菩萨授记法门，读诵不要忘失。阿难！若有善男子、善女人等，以充满三千大千世界的七宝布施诸佛如来。若又有人能受持这无畏德菩萨授记法门，一句一偈，听闻之后受持，所得的福德超过前者，何况具足读诵、广为人说、如法修行。”

【按】“受记”之“受”，宋、元、明、宫本作“授”。

如来宣说这无畏德菩萨授记法门时，月光夫人、无畏德的母亲，以及诸天、龙、阿修罗等，听佛说了之后，都大欢喜，信受奉行。

【按】“月光夫人”下，宋、元、宫本有“及”字。
