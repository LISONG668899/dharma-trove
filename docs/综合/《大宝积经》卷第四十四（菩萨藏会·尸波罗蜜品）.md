唐·三藏法师玄奘 奉诏译

## 菩萨藏会第十二之十

### 尸波罗蜜品第七之三

#### 五种想与贪尽之义

“再者，舍利子！菩萨摩诃萨行尸罗波罗蜜多时，具足这样的清净尸罗：对于诸行恒常生起不可乐之想，对于众生生起父母之想，对于那些有情生起难以保持之想，对于美妙五欲生起非妙之想，对于受与了别生起无识之想。舍利子！这位菩萨摩诃萨这样观察之后，不生起平等或不平等之心。为什么？这位菩萨摩诃萨这样观察：若发起心的平等，应当超出于心而入于寂灭；若发起心的不平等，应当令染污之心转为不平等。这样，以眼与色为缘而生眼识，染污之心的生起与灭去由于随眠，那心体生起，对于所缘之境，妄心计执为净。若能了知那是不如理的，而其体不净，这样了知之后，便得解脱；若那解脱，便在那里穷尽。穷尽了什么？就是贪尽、瞋尽、痴尽。这样的尽，就不是贪尽、瞋尽、痴尽。为什么？若刹那之贪有灭尽，那么贪应是一回事，尽又是另一回事；若是这样，贪应是实有，尽也是实有；若贪是实有，便不应灭尽。

【按】“应超出心”之“超”，宋、元、明、宫本作“起”。

原文：“若当发起心平等者，应超出心入于寂灭。若当发起心不平等，应令染心转不平等”（大意：若发起心的平等，应当超出于心而入于寂灭；若发起心的不平等，应当令染污之心转为不平等。所指未详，存疑。）

“然而，舍利子！一切有情都由于不正思惟、不如理作意而生起贪欲。所谓贪欲，是分别所起的；若没有分别，计执便断；若计执已断，便没有实有；因为没有实有，其中便无所贪；因为无贪，这就是真实。若是真实，其中便没有苦；因为没有苦，便没有烧恼；没有烧恼，这就是真实。若是真实，其中便没有热；因为没有热，这就是清凉，这就是涅槃。在涅槃中没有贪爱。为什么？舍利子！所谓涅槃，没有这样的思虑：‘我应当除灭这样的贪爱，由于贪爱已尽，名为得到涅槃。’若是这样，那么能贪是一回事，所贪又是一回事，涅槃又是另一回事。这些若是相异，便是在彼之中又有彼；若在彼之中又有彼，智者应当寻思那真实。这样寻求之后，不得坚实；若没有坚实，便是虚；若是虚，便是寂静；若是寂静，便是空。空无什么法？就是我与我所。若是常、若是恒、若是住、若是变异之法，便没有有情，便没有命者。由于这样，对于贪、瞋、痴便无所生起。

原文：“此若异者，则于彼为彼”（大意：这些若是相异，便是在彼之中又有彼。所指未详，存疑。）

“舍利子！因为什么而有我与我所？计执这是我，这是我所有，便生起我与我所；颠倒地计执有我，所以执著于我所；执著于我所，便有所作；在所作之中生起四种行。哪四种？就是身之所作、语与心之所作；由意思惟而发出粗恶之语，从此便生起运用身体加以伤害。舍利子！一切愚痴凡夫由于生起自与他的分别之想，被想所执持，被想所系缚。菩萨摩诃萨因行尸罗波罗蜜多，对于这样的事知其颠倒之后，不与诸行相亲近。为什么？因为亲近便生怖畏。菩萨摩诃萨这样想：‘我现在为了求取无怖畏而度化众生，不宜对他们生起怖畏，我应当与他们共为亲爱。’

【按】“我当与之”之“与”，《大正藏》作“兴”，今依CBETA作“与”。

#### 于众生起父母想：得念菩萨本生

“再者，舍利子！菩萨摩诃萨怎样依尸罗波罗蜜多，对一切众生生起父母之想？舍利子！菩萨摩诃萨行尸罗波罗蜜多时，这样思惟：‘没有任何众生，是从过去久远世以来不曾作过我父母、容易找到的。为什么？一切众生必定曾作我的父亲或母亲。然而由于对她生起贪心，便舍弃了母亲之想；由于对他生起瞋心，便舍弃了父亲之想，流转生死，不能断绝。’所以，舍利子！菩萨摩诃萨由于这事深深思惟之后，对众生生起眷属之想。

“舍利子！如那过去超过阿僧企耶、广大无量、不可思议的劫，那时有佛名为最胜众，出现于世，如来、应、正等觉、明行圆满、善逝、世间解、无上丈夫、调御士、天人师、佛、薄伽梵。那尊佛住寿九拘胝岁，与九拘胝那庾多大声闻众共同集会。那时有一位菩萨名为得念，生在王宫，形貌端严，为众人所乐见，成就第一圆满清净的色相。这位菩萨初生之时，父母各以八万四千童少婇女赐给他，亲友眷属又以八万四千诸妙彩女献给他，父母的知友又以彩女八万四千奉给菩萨，为了令她们常随左右侍从，伴他长大。舍利子！那时菩萨的父亲为这位菩萨建造三时宫殿，即热时、雨时以及寒时，令那位菩萨居住在重叠的宫殿上，随时而住，又令无量百千伎乐围绕菩萨，令他娱乐。那时菩萨听到种种乐音，每当乐声将起，便生起生灭之想，现在面前；乐音暂停时，便思惟：这声音依什么而起？从何处而生？依什么而止息？在何处而灭？那时菩萨这样观察时，不生起昼夜差别之想，只恒常生起无常之想、一切世间不可乐之想。舍利子！那时得念菩萨四万岁中从未对快乐生起耽著，又四万岁中对诸欲从未贪染。这时菩萨住在深宫之中，入于四静虑，发起五神通，即从内宫以神足之力身升虚空，前往最胜众如来、应、正等觉薄伽梵所；到了那里之后，请问那尊佛，得到少许善法，又回到本宫。

【按】“婇女”之“婇”，圣本作“彩”；“彩女”之“彩”，宋、元、明、宫本作“婇”。“耽著”，宋、元、明、宫、圣本作“味著”。

“舍利子！这位得念菩萨在那位如来入涅槃之日，又前往如来所住之处，问诸苾刍：‘最胜众佛现在在哪里？我现在想见佛，亲觐供养。’那时诸苾刍告诉得念说：‘善男子！你不知道吗？如来现在已般涅槃。’那时菩萨知道如来已般涅槃之后，就在那里全身扑倒在地，涕泣闷绝，过了许久才苏醒，便说颂道：

```
如是照世间，到诸法彼岸，
我住放逸地，如何自欺诳？
百千劫拘胝，如来乃一现，
而我不奉事，谁当作依救？
如我自惟忖，我母非亲善，
何不赞如来，令我初生见。
父亦非亲善，陷我于诸欲，
既被所拘执，乖事世间依。
不闻佛所说，六十妙音声，
生为失大利，谓不事佛故。
到诸法彼岸，利世大悲者，
我憍逸所执，不事两足尊。
```
（大意：“这样照耀世间、到达诸法彼岸的如来，我却住于放逸之地，怎能这样自我欺诳！百千拘胝劫，如来才出现一次，而我却不奉事，谁来作我的依靠救护？如我自己思忖，我的母亲并非真正亲善，为什么不赞叹如来，令我初生时便能见到？父亲也非亲善，令我陷于诸欲之中；既被诸欲所拘执，便违背了奉事世间所依。没有听到佛所说的六十种美妙音声，生而失去大利，就是因为没有奉事佛。到达诸法彼岸、利益世间的大悲者，我被憍逸所执持，没有奉事两足尊。”）

【按】“既被所拘执”之“被”，元、明本作“彼”。

```
千亿那庾劫，见诸佛甚难，
我不修供养，灭后方来至。
今我重思忖，父母俱非善，
当我初生时，何不为赞佛，
令见最胜尊，常住如来所，
广修诸供养，及听闻正法？
如来所宣畅，六十妙音声，
而我未曾闻，灭后方来至。
我今失大利，涅槃后方来，
无为演妙法，如先佛所说。
```
（大意：“千亿那庾多劫中，见到诸佛甚为困难，我却没有修习供养，佛灭度之后才来到。我现在重新思忖，父母都不是善的：在我初生之时，为什么不为我赞叹佛，令我见到最胜尊，常住在如来身边，广修种种供养，以及听闻正法？如来所宣说的六十种美妙音声，我却从未听闻，佛灭度之后才来到。我现在失去大利，佛涅槃之后才来，没有人为我演说妙法，如先佛所说的那样。”）

“舍利子！那时得念菩萨就在那里悲啼着起身，前往最胜众如来般涅槃的床前；到了那里之后，哀恸悲咽，右绕如来满百千匝，退住一面，而说颂道：

```
佛为群生真实尊，
显扬无上微妙法，
我今发起至诚心，
为获最胜菩提故。
我今敬礼如来足，
世界真言大慧者，
愿我当获如斯智，
等最胜尊之所得。
我昔羸劣无智慧，
堕在魔罗品类中，
安处居家多迫迮，
不得奉事人中上。
我已曾修胜妙福，
由此暂得觐如来，
然佛不垂开正法，
故我于今受极苦。
我今天龙等众前，
兴发至诚真谛语，
若我本期如实者，
当依所言无不遂。
愿我当于未来世，
诸佛出现人中尊，
见甚深义广大用，
宣说无上真实法。
```
（大意：“佛是众生真实的尊者，显扬无上微妙之法，我现在发起至诚之心，为了获得最胜菩提。我现在敬礼如来之足，世界上说真实语的大慧者，愿我将获得这样的智慧，等同最胜尊之所得。我往昔羸劣，没有智慧，堕在魔罗的品类之中，安处于居家，多有逼迫窘迫，不得奉事人中最上者。我已曾修殊胜美妙的福德，由此暂得觐见如来，然而佛不为我开示正法，所以我现在受极大的痛苦。我现在在天龙等大众面前，发起至诚的真谛之语：若我本来的期愿如实，应当依我所言，无不如愿。愿我在未来世，诸佛人中尊出现时，见到甚深之义、广大之用，宣说无上真实之法。”）

```
尔时诸难我不生，
既生诸欲不亲近，
女色自在无随转，
摧坏魔罗之囹圄。
生生常得见诸佛，
无上正法现前闻，
由覩诸佛净信生，
生净信已修诸行。
若我所发至诚言，
必当谛实非虚者，
由此如来还起坐，
如从重睡欻然觉。
菩萨适发诚言已，
如来应时便起坐，
百千拘胝诸天众，
以上妙衣而奉散。
菩萨是时心喜悦，
举身上踊住虚空，
既在虚空安住已，
以妙伽他赞最胜。
慈心利世大明照，
第一说者大神通，
觉悟愍念世间依，
演宣无上正法者。
```
（大意：“那时我不生于诸难，既生之后不亲近诸欲，不随女色的自在而转，摧坏魔罗的牢狱。生生常得见到诸佛，无上正法现前得闻，由于见到诸佛而生起净信，生起净信之后修习诸行。若我所发的至诚之言，必定真实不虚，由此令如来还起而坐，如从沉睡中忽然醒觉。”菩萨刚发出至诚之言，如来应时便起身而坐，百千拘胝诸天众以上妙之衣奉献散布。菩萨这时心生喜悦，全身向上踊起，住于虚空，在虚空中安住之后，以美妙的伽他赞叹最胜者：慈心利益世间的大光明照耀者，第一的说法者，具大神通，觉悟而怜悯世间的依怙，演说无上正法的人。）

“舍利子！那时得念菩萨说完这些赞颂之后，为了令大众倍加欢悦，又在佛前说颂道：

```
我于未来当作佛，
示现授记人中尊，
汝等大众应随学，

世间依怙不思议，
谁有于斯不生信？
哀愍我等及众生，

```
（大意：“我在未来将作佛，示现为授记的人中尊，你们大众应当随学，在如来所兴起供养。世间依怙不可思议，谁对此不生信心？他怜悯我们以及众生，已入涅槃又重新起身。”）

“舍利子！这位得念菩萨在最胜众如来的法中大设供养，种植种种善本，就以这样的善根之力，在此命终，生于善趣诸天世界，经过二十大劫拘胝不堕恶趣，又经过二十大劫拘胝不受欲乐。舍利子！这位得念菩萨在这样的时期中亲觐奉事七千诸佛，在诸佛所广设供养，为了求阿耨多罗三藐三菩提，常修梵行。在最后一劫的来世之时，得到殊胜上妙之身，由自己的善根之力所发起，成等正觉，号为娑罗王如来、应、正等觉、明行圆满、善逝、世间解、无上丈夫、调御士、天人师、佛、薄伽梵，出现于世。舍利子！这位娑罗王佛寿命二十拘胝岁，与诸弟子两次集会说法：第一次大会，声闻弟子有二十拘胝；第二次大会有四十千，都是大阿罗汉，诸漏已尽，不再有烦恼，获得大势力，乃至到达诸心自在的第一彼岸。舍利子！那位佛世尊般涅槃之后，流布舍利，广建灵庙，正法住世满一万年。”那时薄伽梵想重宣此义，而说颂道：

#### 了知诸欲与诸欲违厌

“再者，舍利子！这样的菩萨摩诃萨因行尸罗波罗蜜多，以清净的戒众，对众生生起父母之想。为什么？‘我在往昔生起贪心，所以舍弃了母亲之想；生起瞋心，所以舍弃了父亲之想。我现在行尸罗波罗蜜多，安住于净戒，对于那诸欲恒常兴起厌离违背之心。’这位菩萨摩诃萨为了除去贪欲，以正确的作意，对于诸欲生起真实的违厌之想。舍利子！这位菩萨摩诃萨由于生起这样的正思惟，能自己了知诸欲之相，又能了知对诸欲的违厌。

【按】“清净戒众”之“众”，宋、元、明、宫本作“聚”。“违背之心”之“心”，明本作“想”。

“舍利子！什么名为了知诸欲，以及能了知对诸欲的违厌？舍利子！所说的诸欲，名为贪爱，就是贪著眼识所识的诸色，这名为欲；贪爱耳识所识的诸声，这名为欲；这样，贪爱鼻识所识的诸香、舌识所识的诸味、身识所识的诸触，这名为欲。舍利子！若有贪爱，便有执著；所谓执著，名之为结；结名为发起，发起名为缚，也名为不实的戏论。这样，舍利子！一切众生都被不实戏论的种种缚所缚，被缠缚、遍缚、增上遍缚，不得解脱。舍利子！一切众生被什么所缚，名之为缚？就是被色缚所缚，所以名之为缚，乃至被声、香、味、触之缚所缚，所以名之为缚。又因为什么名为色缚？就是对于自身所得的诸色，妄起我想、命者之想、数取趣之想、常想、恒想、不变异之想、实想、全想、一合之想，这样的种种想名为色缚。舍利子！什么名为被色缚所缚？就是对于所生起的我自体之相深深亲近、珍重，广兴我爱，对于诸妻妾、一切女色恋著不已，这样名为被色缚所缚。

#### 诸欲的过患

【按】以下一段呵欲之文，系就出家菩萨对治淫欲之法而说，依原文照译。

“舍利子！这些众生得到并受用诸欲之法后，造作不善之业，不如实了知诸欲的过失。什么名为诸欲的过失？舍利子！一切诸欲无一不是过失，所以智者对于诸过失不应生欲。然而能趣向恶道，是欲的重大过失，我当为你开示其相。舍利子！什么名为能趣向恶道的诸欲重过？舍利子！我说一切习近诸欲之时，没有少许恶是不造作的；那恶若果报成熟，没有少许苦是不摄受的。所以，舍利子！我观察一切千世界中，众生的大怨敌没有超过妻妾女色诸欲的。为什么？舍利子！所谓有智者，就是如来；所说的无智者，就是众生。凡是智者所呵毁的，这名为真实；凡是无智者所摄受的，便不是真实。舍利子！诸无智者摄受什么？就是摄受诸有为法，摄受妻妾女色诸欲以及男女等；那无智者又被妻子、诸女色等所摄受；这样展转互相摄受，便不摄受那圣道。

“舍利子！那无智者因为被男女、妻妾、诸女色等所缠缚，对于诸善法多生障碍。障碍什么？就是障碍出家，障碍尸罗，障碍静虑，障碍生天之道，障碍涅槃，又能障碍种种美妙善法。又，舍利子！那无智者若摄受男女、妻妾、诸女色等，简略地说，就是摄受怨仇，就是摄受地狱、傍生、焰魔鬼趣等。舍利子！这样的摄受，简要地说，就是摄受一切恶不善法，障碍一切贤圣之法。又，若摄受男女、妻妾、诸女色等，乃至对于一切美食也能障碍，何况其余殊胜之事。舍利子！这样的障碍，简略地说，就是障碍见佛，障碍闻法，障碍奉事僧众，障碍因见佛而得的净信，障碍因闻法而得的净信，障碍因奉事僧众而得的净信。又简略地说，障碍获得具足无难，障碍信财、戒财、闻财、舍财、慧财、惭财、愧财。舍利子！若有人摄受男女、妻妾、诸色欲等，就是摄受不信、恶戒、邪闻、悭吝、恶邪之慧、无惭、无愧，又摄受病痈、毒箭、火聚、毒蛇。

“为什么？舍利子！应当知道，妇人是众苦之本，是障碍之本，是杀害之本，是系缚之本，是忧愁之本，是怨对之本，是生盲之本；应当知道，妇人灭除圣慧之眼；应当知道，妇人如热铁花散布于地，以足踏在上面；应当知道，妇人令种种邪性流布增长。舍利子！以什么因缘名为妇人？所说的‘妇’，名为加于重担。为什么？因为能使众生负起重担，能使众生困于重担，能使众生承受重担，能使众生持着重担有所行走，能使众生荷着重担遍处周行，能令众生对这重担心生疲苦，能令众生被这重担所煎迫，能令众生被这重担所伤害。舍利子！又以什么因缘名之为妇？所说的妇，是众生所输委之处，是贪爱之奴所流没之处，是顺从妇人者所输税之处，是被妇人所媚者所迷惑之处，是胜过妇人者所归投之处，是屈从妇人者所凭仗之处，是妇人自在者所放逸之处，是作妇人之奴者所疲苦之处，是随妇人而转者所欣仰之处。舍利子！以这样等等的因缘，以这些处名之为妇。又，舍利子！世间众生由于妇人的因缘，不舍重担。不舍什么重担呢？就是五蕴。哪五蕴？色蕴、受蕴、想蕴、行蕴、识蕴。舍利子！世间的妇人能令众生不舍这样的五蕴重担，所以把五蕴名之为妇。

“舍利子！又因什么因缘，世人称妇人为‘故第二’？舍利子！这样的女人，是犯尸罗的第二个伴侣，是犯威仪的第二个伴侣，是犯正见的第二个伴侣，是饮食时的第二个伴侣，是往地狱、傍生、鬼趣的第二个伴侣，是能障碍圣慧、障碍涅槃之乐、摄受一切苦的第二个伴侣，所以名为‘故第二’。舍利子！又因什么缘故，世人称妇人为‘母众’？舍利子！一切女人生多过失，有无边的幻诳，所以名为母众。若有人随逐母众的自在，应当知道便堕入魔罗手中，自在地作恶。这样，舍利子！应当知道世界上一切女人生多过失，有无边的幻诳，心多轻躁，心多掉动，其心流荡，倾覆不住，心似山中猿狖，心似猿猴，善能示现幻诳之术，以这样的种种相，所以称女人为母众。又，舍利子！所说的母众，就是母幻村，又名为幻之城邑、幻王所都、幻客之亭、幻人之馆、幻国、幻村、幻处、幻方，是幻世间、幻世界，是无边之幻、广大之幻、无量之幻、不可思议之幻。舍利子！由于这样等等诸欲的重过能趣向恶道，所以称女人为母幻村。舍利子！譬如幻师善学幻术，在大众中示现种种幻诳之事；舍利子！母村也是这样，善学女人的幻诳之术，能令丈夫无论看见、听闻、抚摩、接触，都被系缚。又，诸女人巧知惑媚，由于知道媚术，势力自在，凡有所作，歌舞、戏笑、啼泣、往来，或住、坐、卧，在一切时都能令丈夫不得自在，随那女人系缚驱使。舍利子！譬如世间成熟的稻田，被大冰雹之雨伤残极甚；这样，舍利子！这母幻村犹如大冰雹落在丈夫的田中，摧坏一切白法的苗稼，消灭殆尽。舍利子！这样等等能趣向恶道的贪欲重过，一切世间愚痴凡夫被它幻惑，不能觉了，反而摄受所爱的妻妾、诸女色欲，为之迷醉。

#### 二种想与无依静虑

“再者，舍利子！聪慧的菩萨摩诃萨因行尸罗波罗蜜多，对于这些诸欲深知其过失之后，便依正法生起二种想，就是对诸愚夫生起恶人之想，对佛菩萨生起善人之想。菩萨摩诃萨这样观察之后，便自己思惟：‘我现在应当前往善丈夫的趣向，不宜前往那恶丈夫的趣向。我不应前往地狱、傍生、焰魔鬼趣，我不应前往毁坏尸罗的趣向，我不应前往犯戒的住处；我现在应当前往最胜无上、远离前面诸法的无障碍之趣，我现在应当前往诸佛如来的大智慧之趣。’又这样想：‘我应当逆流而行，不是顺流者；我应当作狮子吼，不作野干鸣；我应当示现金翅鸟王的大势力，不应示现微细虫类所有的力量；我现在应当作贤良之人，不作险恶、愦杂之人；我现在应当吃贤良胜士的清净之食，不应吃那无良下士的不净之食；我应当修行微妙的静虑、最胜的静虑、殊特的静虑、由第一三摩地所得的那一类静虑，不应修行非那一类的静虑、下劣微少的静虑。’

【按】“非下少静虑”之“少”，宋、元、明、宫本作“劣”。

“舍利子！菩萨摩诃萨又这样想：‘我应当游戏于诸佛的静虑，不应游戏于声闻、独觉、一切愚夫异生的静虑。我应当修行无所依的静虑，不应修行依于色的静虑，也不依于受、想、行、识的静虑；不应修行依于地界的静虑，也不依于水界、火界、风界的静虑；也不修行依于欲界的静虑，也不依于色界、无色界的静虑；也不修行依于此世、他世的静虑；也不依于已见、已闻、已念、已识、已得、已触、已证的这样的静虑。’舍利子！这位菩萨摩诃萨又这样说：‘我应当修习无所依的静虑；由于修习，将不自损，也不损他，也不俱损。我应当追求圆满成就的佛智，岂还应当追求世间诸欲？’

#### 四种厌离与见色诸想

“再者，舍利子！这样聪慧的菩萨摩诃萨行尸罗波罗蜜多时，作了这样等等的正观之后，又应当发起四种厌离。哪四种？就是能对诸欲生起厌离，对诸有能生起厌离，对不知恩的众生生起厌离，对一切行的种种苦恼生起厌离。舍利子！这名为菩萨摩诃萨因行尸罗波罗蜜多而发起的四种厌离之想，应当这样修学。

“再者，舍利子！菩萨摩诃萨行尸罗波罗蜜多时，观察处在恶道中的有情见到美妙女色而生起贪心，便应生起四种厌离之想。哪四种？就是退失之想、颠坠之想、厕所之想、脓溃粪秽不净之想。这样，舍利子！处在诸恶道中有识的有情见到美妙女色，尚且应当发起这样的四种想，何况人呢！舍利子！安住大乘、厌离一切有为之行的诸族姓子，见到美妙女色，生起退失、颠坠、厕所、脓溃粪秽这样的四种想；若生起这些想后，仍然生起贪心，又应当再生起三种亲属之想，就是对于母亲一类的人生起母亲之想，对于姊妹一类的人生起姊妹之想，对于女儿一类的人生起女儿之想。”

【按】“有情识者”之“识”，宋本作“议”。

佛告诉舍利子：“菩萨摩诃萨听了我所说而能善解的，应当随顺这样的经典、尸罗波罗蜜多。为什么？没有任何众生，是从久远世来不曾作我父母、容易找到的。为什么？这些众生都曾作过我的父母。若有人习近妻妾、女人，便是习近过去的母亲。舍利子！菩萨摩诃萨听我说了之后，为了清净，应当这样励力勤加修学。

#### 观眼见眼，无差别而起贪

“再者，舍利子！一切世间愚痴凡夫对于那正法违逆不信；菩萨不是这样，随顺正法，无有违逆。若有人修行这样的种种观察，仍被贪心所随逐，菩萨又应如理观察：所生的贪心，是见到什么而生起的？若是对眼生起贪心，菩萨再应如理观察：我是对于眼生起染爱，谁能见到眼？是眼见眼吗？那便是自体见自体吗？为什么？那也是眼，这也是眼，都是四大所造，又是大种所生；不是由自体对此自体生起染爱，又不是对我的自体生起染爱。为什么？因为那就是这。若有人对那生起染爱，应当就是对这生起染爱，因为没有差别。一切世间愚痴凡夫住于无差别之中，我现在应当求取有差别之法。为什么？因为种种欲觉都没有功德。”那时世尊想重宣此义，而说颂道：

【按】“都无有德”之“德”，宋、元、明、宫本作“得”。

原文：“一切世间愚痴凡夫无差别住，我今应求差别之法”（大意：一切世间愚痴凡夫住于无差别之中，我现在应当求取有差别之法。所指未详，存疑。）

```
展转同一义，都无差别性，
由乖理邪执，起是贪爱心。
云何四大生，还能染大造？
诸法犹如幻，无由起贪爱。
我等邪分别，妄起贪爱心，
不肖者生贪，贤善人无爱。
遍于十方界，无实贪可求，
但虚妄分别，故起斯贪爱。
```
（大意：展转同是一义，都没有差别之性，由于违背道理的邪执，生起这贪爱之心。怎么由四大所生的，还能对大种所造之物生起染著？诸法犹如幻化，没有由来生起贪爱。我们以邪分别，妄起贪爱之心；不肖的人生起贪欲，贤善的人没有爱著。遍于十方世界，没有真实的贪可求，只是由于虚妄分别，所以生起这贪爱。）

#### 观眼如聚沫等，无谁染爱

“再者，舍利子！菩萨摩诃萨行尸罗波罗蜜多时，作了这样的观察之后，仍被贪心所随逐，若因听闻佛所说诸法的善根之力，又应随顺这样的经典，就是：眼如聚沫，不可撮摩。为什么？那聚沫等一切诸法，本来没有我，也没有有情，没有命者，没有数取趣，没有摩纳婆，没有丈夫，没有意生，没有作者，没有受者。在这样无作无受的一切法中，谁能染爱？又在什么地方生起染爱？舍利子！眼如浮泡，其性不坚实。为什么？那浮泡等一切诸法，本来没有我，也没有有情，没有命者，没有数取趣，没有摩纳婆，没有丈夫，没有意生，没有作者，没有受者。在这样无作无用的诸法之中，谁能染爱？又在什么地方生起染爱？舍利子！眼如阳焰，由业、惑、爱而生。为什么？那阳焰等一切诸法，本来没有我，也没有有情，乃至谁能染爱？对什么染爱？

“舍利子！眼如芭蕉，其体不坚固。为什么？那芭蕉等一切诸法，本来没有我，也没有有情，乃至谁能染爱？对什么染爱？舍利子！眼如梦，不是如实之见。为什么？那虚梦等一切诸法，本来没有我，也没有有情，乃至谁能染爱？对什么染爱？舍利子！眼如回响，系属于众缘。为什么？那回响等一切诸法，本来没有我，也没有有情，乃至谁能染爱？对什么染爱？舍利子！眼如光影，依业影而显现。为什么？那光影等一切诸法，本来没有我，也没有有情，乃至谁能染爱？对什么染爱？舍利子！眼如浮云，是飘乱散去之相。为什么？那云等法，本来没有我，也没有有情，乃至谁能染爱？对什么染爱？舍利子！眼如闪电，与念念坏灭相应。为什么？那电等法，本来没有我，也没有有情，乃至谁能染爱？对什么染爱？舍利子！眼如虚空，离于我与我所。为什么？那空等法，本来没有我，也没有有情，乃至谁能染爱？对什么染爱？舍利子！眼是无知的，如草木土石。为什么？无知等法本来没有我，也没有有情，乃至谁能染爱？对什么染爱？舍利子！眼无作用，随风力机关而转。为什么？无作等法本来没有我，也没有有情，乃至谁能染爱？对什么染爱？舍利子！眼是虚诳、不净、朽烂之物所积聚。为什么？虚诳等法本来没有我，也没有有情，乃至谁能染爱？对什么染爱？舍利子！眼是虚伪、摧破、坏散、灭尽之法。为什么？虚伪等法本来没有我，也没有有情，乃至谁能染爱？对什么染爱？舍利子！眼如丘井，常被衰老所逼。为什么？丘井等法本来没有我，也没有有情，乃至谁能染爱？对什么染爱？舍利子！眼不能久停，终于死亡之际。为什么？那非久停的一切诸法，本来没有我，也没有有情，没有命者，没有数取趣，没有摩纳婆，没有丈夫，没有意生，没有作者，没有受者。在这样无作无用、因缘和合所生的诸法之中，谁能染爱？又在什么地方行于染爱？这样广说，一切内外诸根、诸尘之法也是这样。舍利子！菩萨摩诃萨这样正确观察时，被诸贪爱所牵引，无有是处。若有菩萨摩诃萨作这样的观察，应当知道他便在诸法中永离贪爱。舍利子！这名为菩萨摩诃萨行尸罗波罗蜜多时毕竟清净，灭除诸贪爱。”

#### 乃至命难不犯十善

那时，佛告诉舍利子：“这样清净地行尸罗波罗蜜多的菩萨摩诃萨，不行一切伤害众生之业，乃至遇到命难，对众生也终不加害。不行一切不与取之业，乃至遇到命难，对他人的资具也终不劫盗。不习近一切淫荒邪行，乃至遇到命难，对诸女色也终不染著趋近。不说一切欺诳妄语，乃至遇到命难，对众生也不行虚诳。不说一切粗犷之言，乃至遇到命难，对众生也终不毁骂。不说一切离间之言，乃至遇到命难，对众生也不说破坏之语，因为对自己的眷属生起知足。不传说一切浮绮的谈说，言必如量，乃至遇到命难，也终不绮饰异词、矫饰文句。对他人的财物不起贪著，乃至遇到命难，对一切所受用之物也终无爱染。对种种恼辱具足忍辱成就，听到粗恶之言善能堪忍，乃至遇到命难，也不生忿恚。在诸法中不生邪见，乃至遇到命难，也终不信奉其余天神，只对佛以净心归趣。舍利子！这样名为菩萨摩诃萨的尸罗清净。”

#### 具足成就种种尸罗

佛告诉舍利子：“这位菩萨摩诃萨因行尸罗波罗蜜多，具足成就无量无边的诸佛正法。舍利子！菩萨摩诃萨由于行尸罗波罗蜜多，具足成就不缺的尸罗，因为不与无智者相亲近；具足成就不穿的尸罗，因为能远离不平等之生；具足成就不斑杂的尸罗，因为不亲近恶人的种种烦恼；具足成就不杂的尸罗，因为只被白法所增长；具足成就应供的尸罗，因为如其所欲而自在行；具足成就受称赞的尸罗，因为不被智者所呵毁；具足成就善守的尸罗，因为圆满具备正念以及正知；具足成就不受诃呰的尸罗，因为不生种种过失；具足成就善护的尸罗，因为善于防卫诸根之门；具足成就高广的尸罗，因为为一切佛所忆念；具足成就少欲的尸罗，因为知清净之量；具足成就知足的尸罗，因为欣乐于断除；具足成就正行的尸罗，因为身心远离；具足成就处于寂静的尸罗，因为厌离烦闹；具足成就圣种善喜的尸罗，因为不看他人颜色，无所希望；具足成就杜多功德少事的尸罗，因为自在生长种种善根；具足成就如说而行的尸罗，因为不欺诳世间诸天与人；具足成就大慈的尸罗，因为不伤害一切有命者；具足成就大悲的尸罗，因为堪忍一切苦恼；具足成就大喜的尸罗，因为对那法乐无有退减；具足成就大舍的尸罗，因为一切爱恚毕竟断除；具足成就常省己过的尸罗，因为恒常在内心善加省察观照；具足成就不讥他人过失的尸罗，因为善于随顺护持众生之心；具足成就成熟众生的尸罗，因为究竟能到布施的彼岸；具足成就善守护的尸罗，因为究竟能到持戒的彼岸；具足成就无憎害心的尸罗，因为究竟能到忍辱的彼岸；具足成就不退转的尸罗，因为究竟能到正勤的彼岸；具足成就定分圆满的尸罗，因为究竟能到静虑的彼岸；具足成就正闻无厌的尸罗，因为究竟能到大慧的彼岸；具足成就亲近善友的尸罗，因为善于修集觉分的资粮；具足成就远离恶友的尸罗，因为弃舍不平等之道；具足成就不顾恋身体的尸罗，因为以无常之想恒常观察；具足成就不顾恋性命的尸罗，因为其所珍重的不能常保；具足成就不起追悔的尸罗，因为心善清净；具足成就不诈现的尸罗，因为方便善加清净；具足成就不恼热的尸罗，因为增上意善加清净；具足成就不轻掉的尸罗，因为永离种种贪爱；具足成就不高慢的尸罗，因为柔和质直；具足成就不强戾的尸罗，因为其性贤善；具足成就善调伏的尸罗，因为没有愤恚；具足成就寂静的尸罗，因为其性安然收摄；具足成就善语的尸罗，因为如其所说，无有违逆；具足成就成熟有情的尸罗，因为常不舍离诸摄法；具足成就守护正法的尸罗，因为对于圣法之财自己不毁坏。舍利子！聪慧的菩萨摩诃萨这样以清净的戒聚具足成就尸罗波罗蜜多，为了阿耨多罗三藐三菩提，善能修行菩萨妙行。舍利子！这名为菩萨摩诃萨的尸罗波罗蜜多。若诸菩萨摩诃萨精勤修行这菩萨行，一切众魔、魔民、天子都不能娆乱这位菩萨，也不会被那些异道他论所摧屈。”

【按】“不斑”之“斑”，宋、元、明、宫本作“班”。“大悲尸罗”之“悲”，《大正藏》作“慈”，CBETA依高丽藏作“悲”，今从之。“不轻掉尸罗”至“不高慢尸罗”之间，宫本重出“永离诸贪爱故具足成就不高慢”一段。《尸波罗蜜品》至此圆满。
