# 《大宝积经》卷第三十二（出现光明会）

唐·三藏菩提流志 译

## 出现光明会第十一之三

【按】本卷开头承上卷，仍是弥勒菩萨请问微笑因缘的偈颂；其后世尊摩月光童子顶，说偈付嘱《出现光经》，并呵斥末世愚痴比丘；月光童子请佛应供，世尊入王舍城，空中出声说偈。至卷末偈颂未完，接下卷。

### 弥勒菩萨续说偈请问

#### 谁于往昔修此善法

```
如来已尽于生际，
大悲普覆诸世间，
法王最胜人中尊，
愿说何缘现微笑？
无量无边大菩萨，
并余威德诸天众，
悉于空中持妙盖，
而此大地皆振动，
谁于往昔如来所，
长夜修行诸善法，
平等悦意大悲尊，
愿说何缘现微笑？
谁于往昔供诸佛，
得闻此法生欢喜，
导师最胜人中尊，
愿说何缘现微笑？
```
（大意：如来已尽生际，大悲普覆世间，法王、最胜人中尊，愿说因何缘故显现微笑？无量无边的大菩萨，以及其余具威德的诸天众，都在空中执持妙盖，而这大地全都振动。是谁在往昔于如来所，长夜修行诸善法？平等悦意的大悲尊，愿说因何缘故显现微笑？是谁往昔供养诸佛，得闻此法而生欢喜？导师、最胜人中尊，愿说因何缘故显现微笑？）

#### 赞佛音声与知眼空寂

```
世尊音声悦众意，
犹如鴈王声美妙，
自然无量音和雅，
愿说何故放斯光？
无量俱胝讽颂言，
劝赞悦可相应语，
拘抧罗声殊胜类，
愿说何故放斯光？
雷鼓深远说法声，
普闻无边千亿界，
慈心麁言或软语，
何故现斯金色光？
了生无生尽无尽，
知眼性离无来去，
为世照明甘露灭，
何故现斯金色光？
知眼起作常空寂，
无去无来无住处，
犹如阳炎水泡沫，
示现微笑何因缘？
如是耳鼻舌身意，
色声香味并触法，
乃至音声及名等，
当知一切亦复然。
```
（大意：世尊的音声悦可众意，犹如雁王之声美妙，自然流出无量音声，和雅动听，愿说因何缘故放此光明？无量俱胝的讽颂之言，劝勉、赞叹、悦可人心的相应之语，殊胜如拘抧罗鸟之声，愿说因何缘故放此光明？如雷如鼓、深远的说法之声，普闻于无边千亿世界，以慈心说粗言或软语，因何缘故显现此金色光？了知生与无生、尽与无尽，知眼性远离，无来无去，为世间作照明，宣说甘露寂灭，因何缘故显现此金色光？知眼的生起造作常空寂，无去无来，无住处，犹如阳焰、水泡、泡沫，显现微笑是何因缘？像这样，耳鼻舌身意，色声香味触法，乃至音声及名等，应当知道一切也是如此。）

【按】“讽颂”之“颂”，明本作“诵”。“甘露灭”之“灭”，宋、元、明、宫本作“法”。“示现微笑”之“示”，圣本作“亦”。

#### 赞佛相好

```
金刚常身不坏身，
具足百千殊胜相，
体无机关而运动，
愿说微笑何因缘？
髀膊𦟛满足跟长，
腹相不现如师子，
脐深妙好腰圆满，
愿说微笑何因缘？
金色净身离尘垢，
一一众毛绀青色，
右旋上靡香芬馥，
愿说微笑何因缘？
妙身圆满常安住，
犹如尼拘陀树王，
一切功德以庄严，
音声悦众令欣乐。
```
（大意：金刚常住之身、不坏之身，具足百千殊胜之相，身体没有机关而能运动，愿说微笑是何因缘？髀与膊均直圆满，足跟修长，腹相不现如狮子，脐深而妙好，腰身圆满，愿说微笑是何因缘？金色清净之身远离尘垢，每一根毛都是绀青色，右旋向上而靡，香气芬馥，愿说微笑是何因缘？妙身圆满常安住，犹如尼拘陀树王，以一切功德庄严，音声悦众，令人欣乐。）

【按】“𦟛”字（月旁庸）为罕用字，先前电子文本未能显示，今据《大正藏》补出，通“傭”，意为均直圆满。下文“修臂𦟛圆”“膊𦟛平正”同。“膊𦟛平正”之“膊”，元、明本作“𬧅”。

```
修臂𦟛圆肩妙好，
项约圆满螺文现，
游步无边百千刹，
示诸众生邪正道。
齿白无垢如珂雪，
舌相广长周覆面，
师子颊辅鼻修直，
皆从方便净心生。
优钵罗香从口出，
栴檀香气遍于身，
已于往昔广修慈，
清净意乐常相续。
如来足下善安平，
随所履地无窊曲，
犹如师子象王步，
超过一切诸世间。
千辐轮相妙端严，
殊胜光文常炳著，
所行善利诸群品，
见者皆生净信心。
一指能出百千光，
普照无边诸佛刹，
往昔勤修众善行，
获此种种相庄严。
```
（大意：修长的手臂均直圆满，肩膀妙好，颈项圆满，现出螺文；游步于无边百千刹土，为众生指示邪道与正道。牙齿洁白无垢如珂雪，舌相广长，遍覆面部，狮子颊辅，鼻修长端直，这些都从方便与清净心所生。优钵罗花香从口中出，栴檀香气遍于全身，这是因往昔广修慈心，清净意乐常相续不断。如来足下平稳安住，凡所踏之地无有凹凸，犹如狮子、象王之步，超过一切世间。千辐轮相妙好端严，殊胜光纹常显明，所行之处善利众生，见者都生起清净信心。一指能出百千光明，普照无边诸佛刹土；往昔勤修众善行，获得这种种相好庄严。）

【按】“窊曲”之“窊”，圣本作“𥦠”。

```
成就色身无等伦，
面相端严最殊胜，
神变利益诸世间，
愿说何缘现微笑？
膊𦟛平正如鹿王，
身不低屈犹师子，
出兴为世作灯明，
愿说何缘现微笑？
马王隐相无尘染，
掌中平满手过膝，
希有最胜人师子，
愿说微笑何因缘？
从身出现无边光，
妙色寂静而恒照，
其心清净常相续，
演说无边诸契经。
非彼安住断常人，
所能净修如是法，
若能舍离诸边见，
速成如来清净身。
```
（大意：成就色身无与伦比，面相端严最为殊胜，以神变利益世间，愿说因何缘故显现微笑？膊均直平正如鹿王，身体不低屈犹如狮子，出兴于世，为世间作灯明，愿说因何缘故显现微笑？马王阴藏之相，无有尘染，掌中平满，手长过膝，希有最胜的人中狮子，愿说微笑是何因缘？从身出现无边光明，妙色寂静而恒常照耀，其心清净常相续，演说无边契经。这不是那些安住于断见、常见的人所能清净修习的法；若能舍离诸边见，便能速成如来清净之身。）

【按】“出兴”，《大正藏》作“出与”，CBETA依高丽藏作“出兴”，今从之。

```
天鼓云雷声远震，
迦兰陀鸿响清彻，
天乐音声千万种，
愿说何故现斯光？
导师一音演说法，
令诸毁戒断相续，
如来所说妙言音，
皆是甚深希有法。
牛王眉间白毫相，
遍至百千诸佛刹，
妙眼犹如绀青色，
顶相空天无能见，
齿白齐密具四十，
犹如清净颇胝宝，
皆从无量善业生，
愿说何缘现微笑？
如来圆满功德身，
成就无边微妙色，
出现希有净光明，
愿说何缘现微笑？
```
（大意：如天鼓、云雷，声音远震；如迦兰陀鸿鸟，鸣响清彻；如千万种天乐之音，愿说因何缘故显现此光？导师以一音演说法，令诸毁戒者断其相续；如来所说的美妙言音，都是甚深希有之法。如牛王般的眉间白毫相，光遍至百千诸佛刹土；妙眼犹如绀青色；顶相，空中诸天也无能见；牙齿洁白、整齐、细密，具足四十，犹如清净的颇胝宝——这些都从无量善业所生，愿说因何缘故显现微笑？如来圆满的功德之身，成就无边微妙之色，出现希有的清净光明，愿说因何缘故显现微笑？）

【按】“如来所说”之“来”，明本作“是”。

#### 赞佛智德

```
大悲最胜两足尊，
了达众生心志乐，
已得无碍妙辩才，
愿说何缘现微笑？
如来已到于彼岸，
具足三明及六通，
示现无边清净光，
愿说何缘现微笑？
佛于往昔无量劫，
供养百千诸世尊，
如是因果不败亡，
愿说何缘现微笑？
佛于往昔无量劫，
安住微妙诸等持，
知眼生边及尽边，
愿说何缘现微笑？
过去未来现在世，
导师于彼悉能了，
净智无碍不思议，
愿说何缘现微笑？
```
（大意：大悲最胜两足尊，了达众生的心志与喜乐，已得无碍的妙辩才，愿说因何缘故显现微笑？如来已到彼岸，具足三明与六通，示现无边清净光明，愿说因何缘故显现微笑？佛在往昔无量劫中，供养百千诸世尊，这样的因果不会败亡，愿说因何缘故显现微笑？佛在往昔无量劫中，安住于微妙的诸等持，知眼的生边与尽边，愿说因何缘故显现微笑？过去、未来、现在世，导师对这一切都能了知，清净之智无碍，不可思议，愿说因何缘故显现微笑？）

### 世尊摩顶付嘱此经

那时，世尊在大众中，以金色手摩月光童子之顶，而说偈道：

#### 付嘱与乐不乐此经之人

```
童子谛听，吾今付汝，此菩提法，出现光经。
于后恶世，法欲灭时，当为众生，开示演说。
我以佛眼，见未来世，于是微妙，甚深经典，
若乐不乐，皆悉了知。
```
（大意：童子！仔细听：我现在将这部菩提之法《出现光经》付嘱给你。在以后的恶世、正法将灭之时，你应当为众生开示演说。我以佛眼见未来世，对于这部微妙甚深的经典，谁乐、谁不乐，我都完全了知。）

```
若有众生，志求佛道，常念诸佛，当授此经。
若坏净信，乐于愦閙，长夜惛睡，不乐斯经。
于我法中，虽得出家，于涅槃法，不生欣乐，
如是痴人，虚食信施。闻有为法，多诸过患，
犹著世间，不生惊怖，如是痴人，智者呵责，
虽服法衣，而无智慧。
```
（大意：若有众生志求佛道，常念诸佛，应当传授此经给他。若有人破坏净信，喜好喧闹，长夜昏睡，便不喜乐这部经。在我的法中虽得出家，却对涅槃之法不生欣乐，这样的痴人，是白白受食信施。听闻有为法多诸过患，仍然执著世间，不生惊怖，这样的痴人为智者所呵责，虽然身穿法衣，却没有智慧。）

```
牟尼所说，真实之言，无智若闻，不能信受，
如是愚人，勿与同止。若有得闻，此殊胜法，
不生欢喜，爱乐之心，如是等人，我所呵责，
虽得人身，则为空过。若有得闻，此甚深法，
能生欢喜，爱乐之心，是人已曾，值遇诸佛，
决定当得，无上菩提。
```
（大意：牟尼所说的真实之言，无智之人若听到，不能信受，这样的愚人，不要与他同住。若有人得闻这殊胜之法，不生欢喜爱乐之心，这样的人是我所呵责的，虽得人身，却是空过。若有人得闻这甚深之法，能生欢喜爱乐之心，此人已曾值遇诸佛，决定当得无上菩提。）

【按】“牟尼所说”之“所”，《大正藏》作“诸”，宋、元、明、宫本及高丽藏作“所”，今从之。

#### 舍离恶知识与愚小之人

```
若人愚痴，恶见所害，断于慧命，远离菩提，
是故应当，舍恶知识，亲近恭敬，明慧之人。
一切世间，无量过患，众生常没，三恶趣中，
皆从痴惑，因缘所起，随惑流转，不得自在。
弃舍正法，行于非法，是故当离，愚小之人。
犹如御者，自折其轴，既作恶业，生地狱中。
口出恶言，恒自伤害，如持利斧，自伐其身。
不知诸法，因缘所造，随业受报，无能救者。
```
（大意：若人愚痴，为恶见所害，便断了慧命，远离菩提；所以应当舍弃恶知识，亲近恭敬明慧之人。一切世间有无量过患，众生常沉没在三恶趣中，这都是从痴惑因缘所起，随惑流转，不得自在。他们弃舍正法，行于非法，所以应当远离愚小之人。犹如驾车的人自己折断车轴，既作了恶业，便生于地狱之中。口出恶言，常常自我伤害，如同拿着利斧砍伐自身。不知诸法是因缘所造，随业受报，没有谁能救护。）

【按】“痴惑”之“惑”，《大正藏》作“恶”，宋、元、明、宫、圣本及高丽藏作“惑”，今从之。

```
亲近世仙，以为善友，而便自谓，修习于空。
已证无为，生断灭见，如身器破，心亦随灭。
多所乐说，绮饰言辞，于此味著，终无义利。
虽为毒蛇，之所螫害，终不令人，堕于恶趣。
愚者说法，坏人善根，令无量众，堕于地狱。
```
（大意：亲近世间的仙人，把他当作善友，就自称修习空法；自以为已证无为，便生起断灭见，认为如同身体这个器皿破了，心也随之而灭。多喜说绮丽修饰的言辞，于此贪著其味，终究没有义利。即使被毒蛇所螫害，终究不会令人堕于恶趣；而愚者说法，破坏他人善根，令无量众生堕于地狱。）

```
汝等大众，应当观察，如是童子，今在我前，
往昔已曾，供养无量，恒河沙数，诸佛世尊。
坚固修行，求无上智，心不依止，一切诸有。
知眼生边，毕竟清净，离诸戏论，无所染著。
为欲利益，无量众生，演说无上，现光经典。
愚人不能，修学是法，于修行者，见其过失。
是故应舍，愚痴之人，不应亲近，修学是法。
```
（大意：你们大众应当观察：这位童子如今在我面前，他往昔已曾供养无量恒河沙数的诸佛世尊；坚固修行，求无上智，心不依止一切诸有；知眼的生边毕竟清净，远离诸戏论，无所染著；为了利益无量众生，演说无上的《现光经》。愚人不能修学这部法，反而对修行者挑剔其过失。所以应当舍弃愚痴之人，不应与他们亲近而修学此法。）

【按】“恒河沙数”之“数”，南藏作“等”。“修学是法”之“是”，圣本作“其”。

#### 愚痴比丘的种种过失

```
愚痴之人，乐于诤论，不能勤修，无诤论行。
彼诸人等，无如理心，是故不应，恭敬称赞。
愚痴之人，懈怠嬾惰，常行不善，身语意业，
无有净戒、智慧多闻，常思欲境，乐于愦閙。
汝等应观，如是愚人，种族及身，皆悉鄙恶，
瞋恚佷戾，形貌丑陋。设生善处，身常下劣，
执著我相，迷于真理，无有智慧，分别语言，
闻性空法，不生爱乐。
```
（大意：愚痴之人喜好诤论，不能勤修无诤之行。这些人没有如理之心，所以不应恭敬称赞他们。愚痴之人懈怠懒惰，常行不善的身语意业，没有清净戒律、智慧与多闻，常思欲境，喜好喧闹。你们应当观察这样的愚人：种族与身体都卑鄙丑恶，瞋恚乖戾，形貌丑陋；即使生于善处，身份也常下劣；执著我相，迷于真理，没有智慧，只会分别言语，听闻性空之法，不生爱乐。）

```
如来世尊，久已远离，一切世间，语言戏论。
凡夫于此，深生染著，尽其寿命，不能了知。
虽赞持戒，不修梵行，口说于法，身行非法，
自说是律，常行非律，佛教弟子。著坏色衣，
破戒之人，而披此服，增长憍慢，放逸之心，
所食信施，如吞猛火。既舍居家，无五欲乐，
又于佛法，无胜妙乐，乐于杂行，不离二边，
所有意乐，皆不清净。
```
（大意：如来世尊早已远离一切世间的语言戏论，凡夫却对此深生染著，尽其一生也不能了知。他们虽赞叹持戒，却不修梵行；口中说法，身行非法；自说这是律，却常行非律——这样的佛教弟子，身著坏色衣，是破戒之人，披着这件法服，增长憍慢放逸之心，所食的信施，如同吞下猛火。既已舍弃居家，没有五欲之乐，在佛法中又没有殊胜妙乐，喜好杂行，不离二边，所有的意乐都不清净。）

```
如是愚人，处在大众，犹如野干，入师子群。
虽说如是，寂静之法，不能了知，真实空义。
为众称赞，生贡高心，不念大师，惭愧谦下。
受不净物，如得摩尼，欢喜执持，心无暂舍。
是辈下劣，虽复出家，守护威仪，执持衣钵，
但有形像，无实智慧，虽复剃发，不舍恶心，
堕于倒见，非沙门法。退失寂静，涅槃之道，
亦无沙门，所证之果，无明烦恼，不灭微尘，
游行聚落，自称寂静。
```
（大意：这样的愚人处在大众之中，犹如野干闯入狮子群。虽说这样寂静的法，却不能了知真实的空义。被大众称赞，便生贡高之心，不念大师，不知惭愧谦下。接受不净之物，如得摩尼宝，欢喜执持，心中片刻不舍。这类下劣之人虽然出家，守护威仪，执持衣钵，却只有形相，没有真实智慧；虽然剃发，不舍恶心，堕于颠倒之见，不是沙门之法。他们退失寂静涅槃之道，也没有沙门所证之果，无明烦恼一点微尘也没有灭除，却游行聚落，自称寂静。）

【按】“不灭微尘”之“灭”，宫本作“减”。

```
愚人无智，不知正趣，心所乐欲，皆为不善。
因利养故，住阿兰若，不为修习，涅槃之因。
惛沈憙睡，但念安身，常乐修行，如是等事。
虽住兰若，经历多年，以倒见故，失涅槃道，
终不能得，沙门道果。毁破正见，违犯禁戒，
爱好衣服，庄严其身。于诸欲乐，常生爱染，
若入城邑，现憍慢相，放纵身业，不住威仪。
```
（大意：愚人无智，不知正确的趣向，心中所乐欲的都是不善。他们因为利养的缘故住阿兰若，不是为了修习涅槃之因；昏沉嗜睡，只想安养身体，常喜做这类事情。虽然住在阿兰若经历多年，因颠倒见的缘故，失去涅槃之道，终究不能得到沙门道果。他们毁破正见，违犯禁戒，爱好衣服，庄严其身；对诸欲乐常生爱染；若进入城邑，便显现憍慢之相，放纵身业，不住于威仪。）

```
或入城邑，游行自说，彼阿兰若，山窟之中。
汝等当知，是我所住，徐行低视，进止安庠。
发言诡异，现罗汉相，令白衣众，咸相谓言，
兰若比丘，是真圣者。或复在彼，阿兰若处，
见有人来，即便指示，我于是处，昼夜经行，
或施软草，宴坐之所。或入聚落，诣白衣家，
诈现慇懃，问讯安隐。说于世俗，王贼之事，
或以染心，于女人前，种种方便，自赞其德，
我能为世，作大福田，我舍王位，出家修道，
宫人婇女，皆悉生天。彼人闻已，益加恭敬，
衣服饮食，种种供养。大德哀愍，数来我所。
```
（大意：或者进入城邑，游行时自己说：“那阿兰若的山窟之中，你们应当知道，是我所住之处。”慢步低视，进止安详，言语诡异，显现阿罗汉之相，令在家众都互相说：“这位兰若比丘是真正的圣者。”或者在那阿兰若处，见有人来，便指给他看：“我在这里昼夜经行。”或者指示铺施软草宴坐的地方。或者进入聚落，到在家人家中，假装殷勤，问讯安好；谈说世俗中国王、盗贼之事；或以染污之心在女人面前，用种种方便自赞其德：“我能为世间作大福田；我舍弃王位出家修道，宫人婇女都已生天。”那人听了，更加恭敬，以衣服、饮食种种供养，说：“大德哀悯，请常来我这里。”）

```

于兰若众，矜高利养，轻毁诽谤，精进比丘。
心迷名利，转生贪著，为活命故，常行欺诳，
增长身语，不善之业，若有施主，净心供养，
由懈怠故，损减其福。如是愚人，常生恶欲，
于此空法，无顺忍心。
```
（大意：他贪著美味，不知过患，被魔得其便，如龟落入网中。在兰若众中，矜夸于利养，轻毁诽谤精进的比丘。心迷于名利，转生贪著，为了活命，常行欺诳，增长身语的不善之业。若有施主以净心供养，因他懈怠的缘故，损减了施主的福德。这样的愚人常生恶欲，对这空法没有随顺忍可之心。）

#### 得此法非难

```
若于我法中，能离如是过，
勤修不放逸，得此法非难。
于利与非利，称讥苦乐等，
世法不能动，得此法非难。
观身不净想，诸蕴疮疣想，
受食涂疮想，得此法非难。
虽受好衣服，亦不生憍慢，
为遮惭耻故，得此法非难。
不矜持色力，于食无贪著，
为存寿命故，得此法非难。
了知诸有空，于欲无取舍，
常修空寂行，得此法非难。
去一由旬山，独坐修禅定，
观有为无我，得此法非难。
观眼尽生边，及眼流转相，
勤修眼净道，得此法非难。
耳鼻舌身心，色声香味触，
乃至音声名，一切皆如是。
```
（大意：若在我的法中能离开这样的过失，勤修不放逸，得此法并不难。对于利与衰、称与讥、苦与乐等，这些世间法不能动摇他，得此法不难。观身作不净想，观诸蕴作疮疣想，受食时作涂疮之想，得此法不难。虽然接受好衣服，也不生憍慢，只是为了遮蔽羞耻，得此法不难。不矜恃色身与气力，对饮食无贪著，只为维持寿命，得此法不难。了知诸有皆空，对欲无取无舍，常修空寂之行，得此法不难。到距离一由旬远的山中，独坐修禅定，观有为法无我，得此法不难。观眼的尽边与生边，以及眼的流转之相，勤修眼清净之道，得此法不难。耳鼻舌身心，色声香味触，乃至音声、名，一切都是这样。）

【按】“不矜持色力”之“持”，宋、元、明、宫本作“恃”。

#### 应了知未来比丘的种种情形

```
如是未来世，无量诸比丘，
精勤懈怠者，一切皆应了。
彼遇善恶友，修习不修习，
生信及不信，一切皆应了。
彼遇善恶友，于诸根尽道，
修习不修习，一切皆应了。
若爱乐菩提，或一二三月，
后时还退失，一切皆应了。
若人闻此法，能生爱乐心，
设令时退失，还得于净信。
若人闻此法，不能离放逸，
便生是念言，此经非佛说。
若人闻此法，为魔所摄持，
初虽起信心，后则还弃舍。
```
（大意：像这样，未来世的无量比丘，精勤的与懈怠的，一切都应了知。他们遇善友或恶友，修习或不修习，生信或不生信，一切都应了知。他们遇善友或恶友，对于诸根灭尽之道修习或不修习，一切都应了知。若爱乐菩提，过了一、二、三个月，后来又退失，一切都应了知。若人听闻此法，能生爱乐之心，即使一时退失，还能重得净信。若人听闻此法，不能离放逸，便生这样的念头：“此经不是佛说。”若人听闻此法，被魔所摄持，最初虽起信心，后来又弃舍。）

```
于法无欣乐，虚空求名利，
游行于聚落，赞说陀罗尼，
三昧总持光，彼实不能了。
缠缚于五欲，贪求诸世业，
以分别言说，诽谤修空者。
无有念慧心，尽寿为空过，
愚人舍空法，是则为破戒，
当堕阿鼻狱，终不得生天。
```
（大意：对法没有欣乐，徒然求取名利，游行于聚落，赞说陀罗尼、三昧、总持之光，其实他们并不能了解。缠缚于五欲，贪求世间诸业，以分别言说诽谤修空的人。没有正念与智慧之心，一生都是空过；愚人舍弃空法，这就是破戒，当堕阿鼻地狱，终不得生天。）

#### 闻思此经的功德

```
若于一刹那，造立于千塔，
不如闻是经，受持四句偈。
以百千华鬘，供养于佛塔，
不如闻是经，思惟四句偈。
若人造宝塔，其数如恒沙，
不如刹那顷，思惟于此经。
于百亿佛刹，散华以供养，
不如刹那顷，思惟于此经。
袈裟百万亿，奉施于诸佛，
不如刹那顷，思惟于此经。
佛眼胜清净，无所不知见，
若爱乐此经，当得如来眼。
```
（大意：若在一刹那间造立一千座塔，不如听闻此经，受持四句偈。以百千花鬘供养佛塔，不如听闻此经，思惟四句偈。若人造宝塔，其数如恒河沙，不如在一刹那顷思惟这部经。在百亿佛刹散花供养，不如在一刹那顷思惟这部经。以百万亿件袈裟奉施诸佛，不如在一刹那顷思惟这部经。佛眼殊胜清净，无所不知不见；若爱乐此经，当得如来之眼。）

#### 然灯佛时的宿缘

```

我为摩纳仙，持华来供养，
便记我成佛，号释迦牟尼，
当坐于道场，演说此经典。

欢喜生净心，合掌而发愿，
若摩纳成佛，我当助宣化，
乃至灭度后，护持于法藏。
如彼然灯佛，所说现光经，
摩纳与童子，尔时俱听受。
```
（大意：过去无数劫前，有佛名为然灯，我当时是摩纳仙人，持花前来供养，佛便授记我成佛，号释迦牟尼，将坐于道场，演说这部经典。你当时是一个童子，听到我得授记，欢喜而生净心，合掌发愿：“若摩纳成佛，我当助他宣扬教化，乃至他灭度之后，护持其法藏。”如那然灯佛所说的《现光经》，摩纳与童子当时一同听受。）

愚人不勤修，于此生诽谤，
我虽闻此言，亦不生瞋恚。
```
（大意：我曾在往昔以优钵罗花供养那尊佛，你当时在此会中，即发这样的愿：“在我的末法之中，受持此经典，广为宣说流布。”若有人听闻此法，心不生瞋恚，能受持读诵，这就名为善丈夫。你应当在后世受持这部难闻之法，广为众生分别其义趣。我也在过去正法将灭时，受持这部《现光经》，广为众生宣说。愚人不勤修，对此生起诽谤，我虽听到这样的话，也不生瞋恚。）

#### 皆由胜忍力

```
我常修忍力，饶益诸世间，
由忍力成就，相好庄严身。
童子汝当观，佛身妙圆满，
金色最清净，皆从忍力生。
我足指按地，震动无边刹，
众生不颠坠，皆从忍力生。
我从一毛孔，出百千光明，
清净照一切，皆由胜忍力。
罗刹甚可畏，吸人精气者，
常慈心敬我，皆由胜忍力。
我所有眷属，善能调伏心，
尊重于如来，皆由胜忍力。
百千诸音乐，遍于大众中，
称赞佛功德，皆由胜忍力。
百千诸龙王，瞋毒甚可畏，
见佛生欢喜，皆由胜忍力。
罗叉夜叉等，持百千华鬘，
悉来供养我，皆由胜忍力。
无量百千刹，现在诸如来，
称赞我功德，皆由胜忍力。
```
（大意：我常修忍力，饶益世间，由忍力成就相好庄严之身。童子！你应当观察：佛身妙好圆满，金色最为清净，都从忍力所生。我的足指按地，震动无边刹土，众生却不颠倒坠落，都从忍力所生。我从一个毛孔放出百千光明，清净照耀一切，都由殊胜忍力。罗刹极为可怕，吸人精气，却常以慈心敬我，都由殊胜忍力。我所有的眷属善能调伏其心，尊重如来，都由殊胜忍力。百千种音乐遍于大众之中，称赞佛的功德，都由殊胜忍力。百千龙王瞋毒极为可怕，见佛却生欢喜，都由殊胜忍力。罗叉、夜叉等持百千花鬘都来供养我，都由殊胜忍力。无量百千刹土中现在的诸如来称赞我的功德，都由殊胜忍力。）

若乐著世间，无世尽边智，
不知世尽故，常行于世漏。
若住有漏心，无心尽边智，
不知心尽故，常行于心漏。
若住有漏法，无法尽边智，
不知法尽故，常行于法漏。
```
（大意：若执著于想，没有想的尽边智，因不知想的尽，常行于想之漏。若乐著世间，没有世的尽边智，因不知世的尽，常行于世之漏。若住于有漏心，没有心的尽边智，因不知心的尽，常行于心之漏。若住于有漏法，没有法的尽边智，因不知法的尽，常行于法之漏。）

```
若具头陀法，无眼尽边智，
不知眼尽故，非实头陀者。
虽著坏色衣，无眼尽边智，
不知眼尽故，非实应法服。
虽生贵族家，无眼尽边智，
不知眼尽故，彼非家清净。
虽多畜眷属，无眼尽边智，
速堕恶趣中，眷属无能救。
虽善声明论，无眼尽边智，
不知眼尽边，非达声明者。
虽善诸工巧，无眼尽边智，
不知眼尽故，彼非工巧者。
虽于多问难，一字广分别，
无眼尽边智，彼非随义说。
虽学智者说，不知密非密，
无眼尽边智，于法无所得。
虽了种种言，世论及诸法，
无眼尽边智，如坠险攀藤。
```
（大意：若具足头陀法，而没有眼的尽边智，因不知眼的尽，并非真正的头陀行者。虽著坏色衣，没有眼的尽边智，因不知眼的尽，并非真正合于法服。虽生于贵族之家，没有眼的尽边智，因不知眼的尽，他并非家族清净。虽多蓄眷属，没有眼的尽边智，便迅速堕入恶趣，眷属无能救护。虽善于声明论，没有眼的尽边智，因不知眼的尽边，并非通达声明的人。虽善于种种工巧，没有眼的尽边智，因不知眼的尽，他并非真正的工巧者。虽对众多问难，一字也能广为分别，没有眼的尽边智，他并非随顺义理而说。虽学智者之说，却不知秘密与非秘密，没有眼的尽边智，于法无所得。虽了解种种言语、世间论说以及诸法，没有眼的尽边智，就如坠落险处而攀附藤蔓。）

【按】“不知眼尽边，非达声明者”之“边”，宋、元、明、宫本作“故”。

```
虽善于声明，推步吉凶相，
及文字音韵，读诵皆穷了，
不知眼尽边，彼等终无智。
虽明女人相，邪语令迷惑，
按摩蠲劳法，秘密之幻术，
不知眼尽边，彼等终无智。
虽演说百宗，一字无遗失，
不知眼尽边，所说终无义。
如是眼生边，边际与流转，
乃至于寂灭，当知亦复然。
耳鼻舌身心，色声香味触，
乃至音声名，一切皆如是。
```
（大意：虽善于声明，推算吉凶之相，以及文字音韵，读诵都已穷尽通达，若不知眼的尽边，他们终究无智。虽明了女人之相，以邪语令人迷惑，懂得按摩消除疲劳之法与秘密幻术，若不知眼的尽边，他们终究无智。虽演说百家宗义，一字无遗失，若不知眼的尽边，所说终究无义。像这样，眼的生边、边际与流转，乃至寂灭，应当知道也是如此；耳鼻舌身心，色声香味触，乃至音声、名，一切都是这样。）

```
虽读诵声论，而悉了其义，
不知眼尽边，彼终为下劣。
虽诵四围陀，及呪皆通利，
不知眼尽边，彼终为下劣。
如是眼生边，边际与流转，
乃至于寂静，当知亦复然。
耳鼻舌身心，色声香味触，
乃至音声名，一切皆如是。
```
（大意：虽读诵声论而完全了解其义，若不知眼的尽边，终究是下劣的。虽诵四围陀以及咒术，都通达流利，若不知眼的尽边，终究是下劣的。像这样，眼的生边、边际与流转，乃至寂静，应当知道也是如此；耳鼻舌身心，色声香味触，乃至音声、名，一切都是这样。）

【按】“四围陀”之“围”，宋、元、明、宫本作“韦”。本卷偈颂至此未完，接下卷。
