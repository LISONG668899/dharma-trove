# 《大宝积经》卷第八十（护国菩萨会之一）

隋·三藏法师阇那崛多 译

## 护国菩萨会第十八之一

【按】本会异译有宋施护译《佛说护国尊者所问大乘经》四卷（T0321）。译者题名，元本作“隋北天竺三藏阇那崛多译”。会题“第一十八”，明本无“一”字。

#### 序分：法会大众

如是我闻：一时，婆伽婆在王舍城耆阇崛山中，与大比丘众一千二百五十人在一起；又有菩萨摩诃萨五千人，都得无碍辩才，成就大忍，降伏魔怨，接近佛智，是一生补处，都得陀罗尼、无边辩才、力、无所畏、自在神通，乃至一切功德都具足，他们的名字是普贤菩萨、普眼菩萨、普明菩萨、普光菩萨、圆光菩萨、上意菩萨、无边意菩萨、广意菩萨、无尽意菩萨、持地菩萨、持世菩萨、益意菩萨、咒手菩萨、文殊师利等六十位不思议菩萨，贤护等十六位菩萨，像这样等菩萨摩诃萨五千人在一起。又有娑婆世界主梵天王，以及释提桓因、护世四王、功德天子、正意天子，一切天王、一切龙王、一切紧那罗王、一切乾闼婆王、一切夜叉王、一切阿修罗王、一切迦楼罗王，像这样等王，各各都与百千眷属一起前来集会。

那时世尊坐在功德藏师子宝座上，在大众中色相显现如须弥山，普照世间如日天子，显现世界如月天子，其德寂静如梵天王，威德难以仰视如天帝释，七菩提分都具足如转轮王，宣说无相、空、无愿之法，心无所畏如师子王，身光照耀如大火聚，又放光明犹如诸天最胜无上的摩尼宝珠，普照三千大千世界，以大梵音令众生都得欢喜。对一切法解其深义，在大众中为众说法，初、中、后都善，其义微妙，具足无杂，是清净梵行。

【按】“色象”之“象”，宋、元、明本作“像”。“照耀”之“耀”，宋、元、宫本作“曜”。

#### 喜王菩萨偈赞

那时众中有一位菩萨摩诃萨，名为喜王，坐在众中，看见如来坐在师子座上放大光明，如百千个太阳普照一切，令天人的光明隐蔽不现。见到这事之后踊跃欢喜，遍满身心，不能自胜，便从座而起，合掌向佛，以偈赞叹说：

```
世尊覆蔽此大众，
天龙修罗乾闼婆，
菩萨声闻无威德，
普照一切如金山。
犹如须弥诸天俱，
处于大海佛亦然，
世尊住于慈悲海，
放大光明百千种。
住于梵行犹梵王，
光明威德过诸天，
安住禅定解脱中，
照耀世间胜众生。
犹如帝释在天众，
色象光明最为胜，
佛过世间亦复然，
诸相庄严功德具。
犹如轮王典四域，
照耀世间说法时，
令诸众生入圣道，
世尊显现慈悲意。
光明障蔽火摩尼，
犹如秋日行虚空，
佛比千日最为胜，
佛日普照于世间。
```
（大意：世尊覆蔽这大众：天、龙、阿修罗、乾闼婆、菩萨、声闻都失去威德，佛普照一切如金山。犹如须弥山与诸天一起处于大海，佛也是这样，世尊住于慈悲之海，放出百千种大光明。住于梵行如同梵王，光明威德超过诸天，安住于禅定解脱之中，照耀世间，胜过众生。犹如帝释在天众之中，色相光明最为殊胜，佛超过世间也是这样，诸相庄严，功德具足。犹如轮王统领四方，照耀世间而说法时，令众生入于圣道，世尊显现慈悲之意。光明障蔽火与摩尼，犹如秋日行于虚空，佛比千个太阳更为殊胜，佛日普照于世间。）

【按】“照耀世间”之“耀”，宋、元、明、宫本作“曜”。

```
如夜暗时秋满月，
佛光清净亦复然，
面部圆满犹如月，
覆翳一切天人光。
犹如山顶夜火聚，
清净显现无边界，
能灭一切无明暗，
世尊智慧光普照。
佛音遍满山谷中，
能伏外道犹师子，
宣说无我空无愿，
令诸外道皆恐怖。
威光犹如摩尼王，
映夺一切摩尼光，
如来躯体真金色，
普照世间胜诸光。
如来世间无与等，
况复有胜世尊者，
福智精进方便等，
一切功德无能过。
救护世间大丈夫，
我今覩见功德海，
令我欢喜生尊重，
是故顶礼世尊足。
我已赞叹胜调御，
功德圆满世间灯，
我今所有诸功德，
令诸众生证菩提。
```
（大意：如夜暗时的秋季满月，佛光清净也是这样，面部圆满犹如月亮，覆蔽一切天人的光明。犹如山顶夜里的火聚，清净显现，没有边际，能灭一切无明之暗，世尊的智慧之光普照。佛音遍满山谷之中，能降伏外道犹如狮子，宣说无我、空、无愿，令诸外道都恐怖。威光犹如摩尼宝王，映夺一切摩尼的光明，如来的躯体是真金之色，普照世间，胜过诸光。如来在世间无与相等，何况有胜过世尊的，福德、智慧、精进、方便等，一切功德无人能超过。救护世间的大丈夫，我现在看见这功德之海，令我欢喜，生起尊重，所以顶礼世尊之足。我已赞叹殊胜的调御者、功德圆满的世间明灯，我现在所有的一切功德，愿令众生证得菩提。）

【按】“覆翳”之“翳”，宫本作“蔽”。

那时喜王菩萨摩诃萨以偈赞佛之后，合起十指，谛观佛身，目不暂舍，观察法界甚深，难解、难行、难入，不可思惟，难知，寂静微细之法，不可思量的诸佛境界。在内心观察，周遍法界，观察如来之智、世尊的境界无有等等。作这样观察之后，进入如来之智、不思议境界的方便行中，诸佛世尊同一法性而没有差异。思惟观察诸佛世尊无所染著，犹如虚空。作这样观察时，入于实证的真如体性，一切诸法之性都是这样。生起这样的信心，爱乐诸佛如来无碍解脱之门，了知常、乐、我、净，了知佛之身，这样思惟：“如来之身遍一切刹，显现在众生面前，诸佛的功德在无量劫中说之不尽。”喜王菩萨作此念后，默然而住，观察法界。

#### 护国比丘偈赞

那时有一位慧命菩萨比丘，名为护国，在舍婆提城受夏安居，三个月过后，执持衣钵，与诸年少初学比丘游行诸国，来到王舍城耆阇崛山。那时慧命护国菩萨来到世尊面前，顶礼佛足，右绕三匝，退住一面，合掌向佛，以偈赞叹说：

```
敬礼最胜放光者，
敬礼意如虚空者，
敬礼能决他疑网，
敬礼超过三界尊。
十方无数刹土中，
闻赞如来功德事，
彼国所有诸菩萨，
欢喜皆来供养佛。
菩萨如法供养已，
一心听佛所说法，
闻法欢喜还本土，
赞叹如来诸功德。
如来积行为众生，
经于无量无边劫，
为他求于菩提时，
其心初无有疲惓。
世尊行檀持戒坚，
羼提精进游诸禅，
智慧方便皆具足，
是故稽首大圣尊。
如来具足四如意，
诸根诸力诸解脱，
又知众生心意识，
是故顶礼大智海。
```
（大意：敬礼放出最胜光明的人，敬礼心意如虚空的人，敬礼能决断他人疑网的人，敬礼超过三界的尊者。十方无数刹土之中，听闻赞叹如来功德之事，那些国土所有的菩萨都欢喜前来供养佛。菩萨如法供养之后，一心听佛所说之法，听法欢喜回到本土，赞叹如来的种种功德。如来为众生积集修行，经过无量无边劫，为他人求菩提时，其心从来没有疲倦。世尊行布施、持戒坚固，忍辱、精进、游于诸禅，智慧与方便都具足，所以稽首大圣尊。如来具足四如意足、诸根、诸力、诸解脱，又了知众生的心、意、识，所以顶礼大智之海。）

【按】“其心初无”之“其”，明本作“一”。

```
知诸众生心所念，
身口所作善恶业，
亦知解脱方便等，
世尊知已为说法。
贪欲恚痴迷众生，
能令入于三恶道，
如来知已教断除，
令彼众生生善趣。
过去一切诸世尊，
天人魔梵所恭敬，
未来功德具足者，
世尊皆悉了了知。
诸佛净土所生处，
菩萨声闻及缘觉，
天人眷属与种姓，
寿命长短皆悉知。
灭度已后正法住，
供养舍利起庙塔，
受法藏人若干种，
调御丈夫皆悉知。
十力智慧无障碍，
悉能了达三世事，
入于一切法智中，
故我稽首大智海。
```
（大意：了知众生心中所念，身、口所作的善恶之业，也了知解脱的方便等，世尊了知之后为他们说法。贪欲、瞋恚、愚痴迷惑众生，能令他们入于三恶道，如来了知后教他们断除，令那些众生生于善趣。过去一切诸世尊，为天、人、魔、梵所恭敬，未来功德具足的诸佛，世尊都清清楚楚地了知。诸佛净土所生之处，菩萨、声闻以及缘觉，天人眷属与种姓，寿命长短，都了知。灭度之后正法住世，供养舍利，建起庙塔，受持法藏之人有若干种，调御丈夫都了知。十力智慧无有障碍，都能了达三世之事，入于一切法的智慧之中，所以我稽首大智之海。）

```
佛无等等况有过，
诸相庄严如来身，
譬如星宿在虚空，
是故我礼胜丈夫。
如来妙色无与等，
映蔽大会天人光，
释梵威德在佛边，
一切隐没皆不现。
身如金山无垢秽，
绀发柔软而右旋，
佛顶显现如须弥，
无量功德光明聚。
眉间毫相放大光，
无量无边无有数，
佛眼修广如青莲，
以大慈悲视众生。
如秋满月行虚空，
如来面部亦复尔，
众生观者无厌足，
是故我礼面中王。
犹如师子鹅孔雀，
安行徐步如象王，
游止震动于大地，
敬礼十力大苦行。
手指𦟛纤无不爱，
网缦珊瑚赤铜色，
臂肘修长立过膝，
敬礼如来金色身。
```
（大意：佛无与等等，何况有超过的，诸相庄严如来之身，譬如星宿在虚空中，所以我礼敬殊胜丈夫。如来妙色无与伦比，映蔽大会中天人的光明，释、梵的威德在佛身边，一切都隐没不现。身如金山，没有垢秽，绀青的头发柔软而右旋，佛顶显现如须弥山，是无量功德的光明之聚。眉间毫相放大光明，无量无边，无有数量，佛眼修长宽广如青莲花，以大慈悲看视众生。如秋季满月行于虚空，如来的面容也是这样，众生观看都无厌足，所以我礼敬面容之王。犹如狮子、鹅、孔雀，安然徐步如同象王，游行止住震动大地，敬礼行大苦行的十力者。手指匀称纤长，无不可爱，指间网缦如珊瑚赤铜之色，臂肘修长，站立时过膝，敬礼如来的金色之身。）

【按】“𦟛”字先前电子文本未能显示，今据《大正藏》补出，即“傭”，匀称之义。

```
足下轮相罗网具，
行时足迹犹采画，
若有顶礼世尊者，
佛光照耀得生天。
法王具足七财宝，
常以法施调伏心，
教照众生以法行，
我今顶礼于法王。
慈悲为铠念为刀，
持戒为弓智慧箭，
以此能破烦恼怨，
生死有爱增长种。
自度度他亿众生，
解脱一切诸系缚，
能示无畏安隐路，
令其得至常乐道。
行此乘者断生死，
无有恩爱别离苦，
得至微妙无为处，
慈心说法为众生。
赞叹最胜世尊已，
一切法中自在者，
以此赞叹胜善根，
令诸众生证菩提。
```
（大意：足下轮相，罗网具足，行走时足迹犹如彩画，若有人顶礼世尊，佛光照耀，便得生天。法王具足七种财宝，常以法施调伏人心，教导照示众生以法而行，我现在顶礼法王。以慈悲为铠甲，以正念为刀，以持戒为弓，以智慧为箭，以此能破烦恼之怨，破生死中有爱增长的种子。自度又度他亿数众生，解脱一切系缚，能指示无畏安隐之路，令他们得以到达常乐之道。行此乘的人断除生死，没有恩爱别离之苦，得以到达微妙无为之处，以慈心为众生说法。赞叹最胜的世尊、于一切法中自在的人之后，以这赞叹的殊胜善根，愿令众生证得菩提。）

【按】“采画”之“采”，宋、元、明、宫本作“彩”。“教照”之“照”，元、明本作“诏”。

#### 护国请问清净菩萨行

那时护国菩萨以偈赞佛之后，合起十指，对佛说：“世尊！我心中有疑，想请问如来，唯愿听许。”那时佛告诉护国菩萨比丘：“任你所问，我当为你分别解说，断除你的疑惑，令你欢喜。”那时护国既蒙听许，便对佛说：“菩萨摩诃萨修行什么，能在一切法中增长功德，到达究竟之处而得自在，证得敏捷之智，得到决定之智，对法明了，入于一切智，教化众生，能决断疑网，理解一切智，以善巧方便济度众生，如所说而行，常宣说真实，得念佛三昧，善能咨问一切深义，听后能受持，迅速证得一切种智？”那时护国菩萨想再次宣说此义，说偈道：

【按】“恣汝所问”之“恣”，明本作“姿”。

```
菩萨行行常决定，
真实决定从何生？
智慧大海分别处，
愿胜丈夫为我说。
佛身微妙犹真金，
人天中胜大福聚，
慈愍我等大归依，
清净之行为我说。
云何而得无尽利，
觉道总持甘露生？
云何清净智慧海，
而断众生诸疑惑？
无量亿劫在生死，
而无疲倦悔厌心，
观诸众生逼切苦，
常为众生作利益。
清净刹土佛眷属，
最胜国土及寿命，
一切众事微妙处，
愿说清净菩提行。
```
（大意：菩萨所行之行常常决定，这真实的决定从何而生？在智慧大海分别之处，愿殊胜丈夫为我宣说。佛身微妙犹如真金，是人天中殊胜的大福聚，慈愍我们的大归依，请为我宣说清净之行。怎样得到无尽之利，生起觉道、总持与甘露？怎样以清净智慧之海断除众生的疑惑？在无量亿劫中处于生死，而没有疲倦、悔恨、厌离之心，观察众生被苦逼切，常为众生作利益。清净刹土、佛的眷属、最胜的国土以及寿命，一切众事微妙之处，愿宣说清净的菩提之行。）

```
降伏众魔破邪见，
枯竭爱海得解脱，
法行相续无绝断，
无上最胜为我说。
色力财宝及四辩，
哀愍软言令众喜，
慈悲云雨润一切，
愿为我说佛境界。
愿出迦陵频伽声，
大梵雷音破邪见，
众会渴仰为法来，
愿施解脱甘露浆。
我今欲成微妙道，
若不乐法则不请，
闻法时至恭敬待，
唯愿为说大法宝。
世尊我愿成菩提，
如来深知我志乐，
非为恼乱故问佛，
善哉愿说最胜行。
```
（大意：降伏众魔，破除邪见，枯竭爱海而得解脱，法行相续，没有断绝，请无上最胜者为我宣说。色身之力、财宝以及四无碍辩，哀愍以柔软之言令众人欢喜，以慈悲云雨滋润一切，愿为我宣说佛的境界。愿发出迦陵频伽之声、大梵雷音，破除邪见，众会渴仰为法而来，愿施予解脱的甘露之浆。我现在想成就微妙之道，若不乐于法便不会请问，闻法的时机到来，恭敬等待，唯愿宣说大法之宝。世尊，我愿成就菩提，如来深知我的志向与意乐，不是为了恼乱而问佛，善哉，愿宣说最胜之行。）

#### 四法成清净

那时世尊告诉护国菩萨说：“善哉护国！你现在竟能问这样的义理，利益众多人，安乐天人，也大大饶益未来世，摄受诸菩萨。谛听谛受，当为你宣说。”护国说：“善哉世尊！愿为我宣说。”佛说：“护国！菩萨有四法，能成就如上所说的清净之事。哪四种？一是真实心，没有谄曲；二是对众生行于平等；三是心念行于空；四是如所说而行。护国应当知道，这四种能得菩萨的清净之法。”那时世尊想再次宣说此义，说偈道：

【按】“说偈曰”之“曰”，宋、元、明、宫本作“言”。

```
若有菩萨心无谄，
而常不退菩提道，
亦无佷戾贡高意，
彼则名为无边智。
见诸众生无救护，
生老病死所逼切，
发心欲度于有海，
能为一切作法船。
调伏平等于众生，
观诸众生如一子，
皆当救度令解脱，
最胜丈夫发此心。
行住坐卧念空门，
寿者我想皆悉无，
一切世间都如幻，
众生愚痴所迷惑。
大智菩萨所言说，
依之行行无违失，
调伏寂静离诸过，
能求菩提名佛子。
```
（大意：若有菩萨心无谄曲，常不退于菩提道，也没有刚愎乖戾与贡高之意，他便名为无边智者。见到众生没有救护，被生、老、病、死所逼切，发心想度脱有海，能为一切作法船。调伏平等对待众生，看待众生如同独子，都当救度令其解脱，最胜丈夫发起这样的心。行、住、坐、卧都念空门，寿者与我之想都没有，一切世间都如幻化，众生被愚痴所迷惑。大智菩萨所说的话，依之修行，没有违失，调伏寂静，离开种种过失，能求菩提，名为佛子。）

【按】“佷戾”之“佷”，明本作“狠”。

#### 四无畏法

佛说偈之后，告诉护国菩萨说：“善男子！菩萨摩诃萨又有四种无畏之法。哪四种？一是得到陀罗尼，二是值遇善知识，三是得深法忍，四是戒行清净。这名为菩萨的四无畏法。”那时世尊想再次宣说此义，说偈道：

```
菩萨大名称，由得总持故，
受持最妙法，如来所宣说，
恒常无忘失，增长于智慧，
彼等智无碍，超过一切法。
常遇善知识，增于助道法，
常说于菩提，诸佛所行处，
恶知识如火，畏烧故远离，
若闻空相法，勇猛坚其心。
菩萨离我人，一切诸见等，
持戒无缺漏，其心调寂静，
教化诸众生，安住于佛戒。
```
（大意：具大名称的菩萨，由于得到总持，受持如来所宣说的最妙之法，恒常不忘失，增长智慧，他们的智慧无碍，超过一切法。常遇善知识，增长助道之法，常说菩提——诸佛所行之处；恶知识如火，因怕被烧而远离，若听闻空相之法，勇猛坚固其心。菩萨远离我、人等一切见，持戒没有缺漏，其心调伏寂静，教化众生，令其安住于佛戒。）

【按】“智无碍”之“碍”，明本作“疑”。“持戒无缺漏”之“持”，宫本作“于”。

#### 四种欢喜

佛说偈之后，又告诉护国：“诸菩萨众行圆满、到达究竟之处，有四种功德令心欢喜。哪四种？一是菩萨见佛而生欢喜，二是听闻正法而生欢喜，三是舍弃一切而生欢喜，四是随顺法忍而生欢喜。这是四法生起欢喜。”那时世尊再次说偈道：

```
菩萨所生处，常见最胜人，
威光遍一切，照曜于世间。
见已心恭敬，如天奉帝释，
为度众生故，求于菩提时。
从佛闻正法，不怖而欢喜，
一心信敬已，随顺于佛教。
闻于随顺法，得忍心无疑，
诸法无众生，我想亦复尔。
常观如是已，舍相生欢喜，
既不取我相，见乞心踊跃。
城邑与大地，妻子及寿命，
一切布施时，其心初无悔。
```
（大意：菩萨所生之处，常见最胜之人，威光遍满一切，照耀世间。见后心生恭敬，如同天人奉事帝释，为了度化众生而求菩提时，从佛听闻正法，不怖畏而欢喜，一心信敬之后，随顺于佛教。听闻随顺之法，得忍而心无疑惑：诸法没有众生，我想也是这样。常这样观察之后，舍弃相而生欢喜，既不取我相，见到乞求者便心中踊跃。城邑与大地、妻子以及寿命，一切布施之时，其心从来没有悔恨。）

#### 四法应当弃舍

佛说偈之后，又告诉护国：“菩萨这样说：有四种法应当弃舍。哪四种？一是菩萨弃舍居家，二是出家之后不贪利养，三是远离诸檀越，四是不惜身命。这是四法应当弃舍。”那时世尊再次说偈道：

```
菩萨见家过，舍之而出家，
游止于山林，无人寂静处。
远离男与女，眷属及大众，
单己无等侣，譬如犀一角。
专意求净道，得失心无忧，
少欲及知足，离谄除憍慢。
精进为众生，布施调伏心，
苦行修禅定，一心求佛智。
不惜身与命，远离爱眷属，
坚心求菩提，其志犹金刚。
若人来割截，无有恚恨想，
勇猛心增长，求于一切智。
```
（大意：菩萨见到居家的过患，舍弃居家而出家，游止于山林无人寂静之处。远离男女、眷属以及大众，独自一人没有伴侣，譬如犀牛的独角。专心求清净之道，对得失心无忧虑，少欲而知足，离开谄曲，除去憍慢。为众生而精进，布施并调伏其心，修苦行、修禅定，一心求佛的智慧。不惜身体与性命，远离所爱的眷属，以坚固之心求菩提，其志犹如金刚。若有人来割截其身，没有恚恨之想，勇猛之心增长，求于一切智。）

#### 四种无悔之法

佛说偈之后，又告诉护国：“菩萨有四种无悔之法。哪四种？一是不破禁戒的无悔之法，二是住阿兰若处的无悔之法，三是行四圣种的无悔之法，四是多闻的无悔之法。这是四种无悔之法。”那时世尊再次说偈道：

```
持戒净无垢，犹如摩尼珠，
不生贡高心，言我能持戒。
复以此戒善，转教于多人，
常怀如是望，成就于佛戒。
彼等住空闲，清净兰若处，
亦不生我想，及以寿者想。
观察男女色，犹如于草木，
不生男女想，及以吾我想。
彼住四圣种，无懈怠谄曲，
至心恒修行，远离于放逸。
```
（大意：持戒清净无垢，犹如摩尼宝珠，不生贡高之心，说“我能持戒”。又以这持戒之善转教多人，常怀这样的希望：成就佛戒。他们住于空闲、清净的阿兰若处，也不生起我想以及寿者之想。观察男女之色，犹如草木，不生男女之想以及吾我之想。他们安住于四圣种，没有懈怠谄曲，至心恒常修行，远离放逸。）

```
求多闻功德，精勤常修习，
愿成一切智，最上功德处。
众生处牢狱，无有救护者，
轮转于生死，求财以自给。
我当求法船，济度彼生死，
烦恼海众生，令其至彼岸。
众生无归依，亦无救护者，
众生在有为，无能令其出。
我当作导师，救之令解脱，
是故我发心，求于菩提道。
```
（大意：求多闻的功德，精勤常常修习，愿成就一切智，这是最上功德之处。“众生处于牢狱，没有救护的人，轮转于生死，求财以自给。我当求取法船，济度他们出离生死，令烦恼海中的众生到达彼岸。众生没有归依，也没有救护者，众生处在有为之中，没有人能令他们出离。我当作导师，救护他们令其解脱，所以我发心求菩提道。”）

#### 四种调伏之行

佛说偈之后，又告诉护国：“菩萨有四种调伏之行，应当修行。哪四种？一是愿生善处，常值诸佛；二是供养师长而不求回报；三是常乐空闲，弃舍利养；四是得无碍辩与头陀忍法。这是四种调伏之法。”那时世尊再次说偈道：

```
菩萨勇猛乐山林，
常不从人求利养，
恒得深智无碍辩，
善能通达诸法相。
常当供养诸师长，
随顺师教无违背，
随所生处值诸佛，
供养恭敬求菩提。
常生胜处名高远，
若生天上天中尊，
又得成就菩提道，
教诸众生行十善。
念佛功德常欢喜，
我亦不久成佛道，
既成正觉功德满，
度脱众生生死苦。
```
（大意：菩萨勇猛，乐于山林，常不从人求取利养，恒常得到深智与无碍辩才，善能通达诸法之相。常当供养诸师长，随顺师教，没有违背，随所生之处值遇诸佛，供养恭敬，求取菩提。常生于殊胜之处，名声高远，若生在天上，便是天中之尊，又得以成就菩提道，教导众生行十善。念佛功德常常欢喜：“我也不久将成佛道，既成正觉，功德圆满，度脱众生的生死之苦。”）

#### 四法净菩萨行

佛说偈之后，又告诉护国：“菩萨有四种法，清净菩萨之行。哪四种？一是修行菩提时心无瞋恨；二是弃舍眷属、宫殿、财宝，乐处山林，也不称说自己的功德；三是虽然行布施，不求果报；四是精勤乐法，不见师长的过失。这是四法清净菩提之行。”那时世尊再次说偈道：

【按】“净菩萨行”之“菩萨”，明本作“菩提”。

```
其心清净无怨恨，
亦不求人之过罪，
自不谄曲无染著，
行于大道求菩提。
深观居家是苦本，
亲近恶友无正念，
是故弃舍行出家，
处于山林求解脱。
游行空闲寂静乐，
永断眷属恩爱念，
不惜于身及寿命，
独步无畏犹师子。
乞食支身常知足，
犹如飞禽无储积，
不乐生天及人中，
唯求无上菩提道。
独行无侣唯一己，
恒不恐怖如师子，
畏诸烦恼如野兽，
若得利养心不喜。
```
（大意：其心清净，没有怨恨，也不寻求他人的过罪，自己不谄曲，没有染著，行于大道，求取菩提。深观居家是苦的根本，亲近恶友便没有正念，所以弃舍居家而出家，处于山林，求取解脱。游行于空闲寂静之乐，永远断除眷属恩爱之念，不惜身体以及寿命，独自行走无所畏惧，犹如狮子。乞食维持身体，常常知足，犹如飞禽没有储积，不乐生于天上以及人中，唯求无上菩提道。独行没有伴侣，只有一己，恒常不恐怖，如同狮子，畏惧诸烦恼如同畏惧野兽，若得利养，心不欢喜。）

```
观诸众生恒放逸，
慈悲誓愿为破之，
我为救护诸众生，
常当炽然勤精进。
凡所出言恒哀愍，
于憎爱人常含笑，
不著一切亦如风，
唯当求于丈夫行。
常乐行于空无相，
观有为法如幻化，
调伏诸根意广大，
行住常乐甘露法。
常依佛教行大道，
恒当清净于内心，
求陀罗尼及辩才，
荷负诸苦求菩提。
菩萨常观如是行，
见前利益生欢喜，
若不爱乐于菩提，
是人无恶而不造。
```
（大意：观察众生恒常放逸，以慈悲誓愿为他们破除：“我为了救护众生，常当炽然勤行精进。”凡所出言恒常哀愍，对憎与爱的人常含笑容，不执著一切，也如风一样，唯当求取大丈夫之行。常乐行于空与无相，观察有为法如同幻化，调伏诸根，心意广大，行住常乐甘露之法。常依佛教行于大道，恒常清净内心，求取陀罗尼以及辩才，荷负种种苦而求菩提。菩萨常观察这样的修行，见到眼前的利益便生欢喜，若不爱乐菩提，此人便没有什么恶不造。）

【按】“恒当”之“当”，明本作“常”。“见前利益”之“见”，宋、元、明本作“现”。

#### 四种堕落之法

佛说偈之后，又告诉护国：“菩萨有四种堕落之法。哪四种？一是不恭敬他人，二是背恩谄曲，三是多求利养名闻，四是伪装善行，宣扬自德。这是四种堕落之法。”那时世尊再次说偈道：

```
彼于父母及师长，
常怀憍慢不恭敬，
违背恩养心谄曲，
诸根散乱多愚痴。
常念利养不休息，
谄曲诈现精进相，
自谓持戒及苦行，
一切无有如己者。
恶口麁言喜鬪诤，
常求人过不休息。
彼恒违离沙门行，
营理田作及贩卖。
未来世中诸比丘，
弃舍功德及戒行，
以怀嫉妬鬪诤故，
覆灭损坏我正法。
彼去菩提甚悬远，
亦复远离七圣财，
违背解脱八正路，
流转五道生死中。
```
（大意：他们对父母以及师长，常怀憍慢而不恭敬，违背恩养，心中谄曲，诸根散乱，多有愚痴。常念利养不休止，谄曲地伪装出精进之相，自认为持戒以及苦行，一切人都不如自己。恶口粗言，喜好斗诤，常求他人过失不休止。他们恒常违离沙门之行，经营田作以及贩卖。未来世中的诸比丘，弃舍功德以及戒行，因为怀着嫉妒、斗诤，覆灭损坏我的正法。他们距离菩提甚为遥远，也远离七圣财，违背解脱的八正道，流转于五道生死之中。）

#### 四种障道之法

那时世尊说此偈后，又告诉护国：“菩萨有四种障道之法。哪四种？一是懈怠，二是不信，三是我慢，四是瞋恚。这是四种障道之法。”那时世尊再次说偈道：

```
懈怠不信暗钝心，
常为我慢及瞋恚，
见有忍辱诸比丘，
驱逐傧出于塔寺。
若得利养心欢喜，
各言我是常住者，
恒作方便求人短，
何人有过我治罚。
如是等人去法远，
憎嫉功德坠三涂，
厌恶诸佛微妙法，
是人当入猛火中。
彼人造恶不休息，
必当具受苦中苦，
是故汝等求菩提，
无令后悔堕恶道。
无量亿劫佛乃出，
为诸众生作利益，
汝等既得善趣身，
应舍放逸求解脱。
```
（大意：懈怠、不信、暗钝之心，常因我慢以及瞋恚，见到有忍辱的诸比丘，便驱逐摈出塔寺。若得利养心中欢喜，各自说“我是常住者”，恒常设法寻求他人短处：“哪个人有过失，我来治罚。”这样的人远离正法，憎嫉功德，坠入三途，厌恶诸佛的微妙之法，此人当入于猛火之中。那人造恶不休止，必当具受苦中之苦，所以你们求菩提，不要令自己后悔而堕入恶道。无量亿劫佛才出世，为众生作利益，你们既已得到善趣之身，应当舍弃放逸，求取解脱。）

【按】“傧出”之“傧”，宋、元、明、宫本作“摈”。

#### 四种人不得亲近

那时世尊说此偈后，又告诉护国：“菩萨须舍弃四种补特伽罗，不得亲近。哪四种？一是不得亲近恶知识，二是不得亲近执著邪见的人，三是不得亲近诽谤正法的人，四是不得亲近贪求利养的人。这是四种人不得亲近。”那时世尊再次说偈道：

```
能舍恶知识，亲近善知识，
菩提道增长，犹月渐圆满。
远离执见人，及舍我寿等，
为求佛道故，弃之如毒器。
诽谤于佛法，寂静甘露味，
若欲求菩提，应避如粪秽。
远离贪利养，亦舍恶行人，
是等不应近，犹如避火坑。
若欲降众魔，转无上法轮，
欲求第一利，速远恶知识。
舍爱及憎恶，利誉亦嫉妬，
若求无上道，常修于佛智。
```
（大意：能舍弃恶知识，亲近善知识，菩提道便增长，犹如月亮渐渐圆满。远离执著邪见的人，以及舍弃我、寿者等见，为求佛道，弃舍他们如同毒器。对诽谤佛法、寂静甘露之味的人，若想求菩提，应当避开如同粪秽。远离贪求利养的人，也舍弃恶行之人，这些人不应亲近，犹如避开火坑。若想降伏众魔，转无上法轮，想求第一利益，就迅速远离恶知识。舍弃爱以及憎恶、利养、名誉以及嫉妒，若求无上道，常当修习佛的智慧。）

#### 四法受未来苦

那时世尊说此偈后，又告诉护国：“菩萨有四种法会受未来之苦。哪四种？一是轻慢有智之人，二是常怀嫉妒之心，三是对一切法没有信心，四是对清净智慧之法常怀疑惑、无有忍可，而求利养。这是四法受未来之苦。”那时世尊再次说偈道：

```
侍佛之人有智者，
一切天人应供养，
而反贡高怀憍慢，
是故彼受无边苦。
于净法中心无忍，
所求利养皆非法，
常怀憍慢而贡高，
见有智者不恭敬。
于佛法中无信解，
于贤圣众亦复然，
此人常游三恶道，
若在人中多愚痴。
彼舍人间寿命已，
在大地狱受剧苦，
若此劫尽生余方，
畜生饿鬼亦复然。
若欲求作世间灯，
能尽诸苦胜丈夫，
常当远离三涂业，
修诸功德成菩提。
```
（大意：侍奉佛的有智之人，一切天人都应当供养，却反而贡高怀憍慢，所以他们受无边之苦。在清净法中心无忍可，所求的利养都是非法，常怀憍慢而贡高，见到有智之人不恭敬。在佛法中没有信解，对贤圣之众也是这样，此人常游于三恶道，若在人中多有愚痴。他们舍弃人间寿命之后，在大地狱受剧烈之苦，若这劫尽了，便生于其他地方，作畜生、饿鬼也是这样。若想求作世间的明灯、能尽诸苦的殊胜丈夫，常当远离三途之业，修种种功德成就菩提。）

#### 四种系缚

那时世尊说此偈后，又告诉护国：“菩萨有四种系缚。哪四种？一是轻慢他人，这是菩萨的系缚。二是对世俗禅定心生乐著，不求究竟，这是菩萨的系缚。三是不守护自心，智慧未成就而行放逸，这是菩萨的系缚。四是为求利养而进入他人之家，这是菩萨的系缚。护国！应当知道，这名为菩萨的四种系缚。”那时世尊再次说偈道：

```
恒常轻慢他，乐住世间善，
贪著诸见缠，如象没深泥。
乐入白衣家，常怀于放逸，
暗钝无智慧，此行名系缚。
欲断诸有苦，远离老病死，
当舍于憍慢，常行菩萨道。
受于无边苦，弃舍诸乐事，
亦离于憎爱，成佛无染著。
```
（大意：恒常轻慢他人，乐住于世间之善，贪著种种见的缠缚，如大象陷没于深泥。乐于进入白衣之家，常怀放逸，暗钝没有智慧，这样的行为名为系缚。想断除诸有之苦，远离老、病、死，应当舍弃憍慢，常行菩萨道。承受无边之苦，弃舍种种乐事，也离开憎与爱，成佛而无所染著。）

【按】“诸见缠”之“缠”，宋、元、明、宫本作“缚”。

```
为求菩提佛智故。
```
（大意：你们常应行六度，以及诸地、诸智、诸力等，一切功德若得成就，常得解脱死亡的罗网。我在往昔无量劫中，为众生求菩提，常行布施以调伏其心，舍离恩爱，安住正道。恒常不舍离阿兰若，修苦行至羸瘦，以求菩提，炽然精进，没有懈怠，求取最胜丈夫之智。见到众生在诸有的牢狱之中，轮转于五道生死，以慈心念一切，生起大悲，所以求菩提道。舍弃爱子以及妻妾，也舍弃资财、七宝等，寿命、国土以及大地，都是为求菩提与佛智。）

#### 八法障碍菩提

那时佛又告诉护国菩萨说：“善男子！在未来世，行大乘的菩萨补特伽罗等有这样等过患，应当自己远离。他们自己不勤求，却与这样的人共相亲近；不勤修正行，自己行谄曲，亲近行谄曲的人；自己没有智慧，随顺没有智慧的人；贪求世间利益，恒常没有厌足；悭惜他人之家，嫉妒胜过自己的人；谄曲诈伪，无羞无惭；伪装圣相，自尊自重；徒众眷属各自相互赞誉以求名利；为求利养常入聚落。既不怜愍一切众生，也不是为了教化众生，常自己说‘我有平等’。恒常这样想：‘怎样让别人知道我是众生真正的善知识，知道我多闻。’实际上对佛法没有恭敬心，没有求法心，犹如破器，不再有用，如懈怠的人，没有成就。相互寻求过失，以方便行之，无智懈怠，只有恶的觉观。各各谈论破法等事，固执恶心，至死不悔。多聚集悭贪之人，所畜的眷属也学这老师，以此围绕自己，在我的法中。

【按】“徒众眷属”之“徒”，明本作“彼”。

“这样修行的人，凡所作之事，不问明哲之人，不求佛法，因为没有精进之行，所以生在贫穷之家。从贫穷之家出家，在我的教法中得到少许利养，心生欢喜而没有惭愧。他们尚且没有忏悔之心，怎能自己觉悟殊胜的智慧？他们弃舍诸佛的功德而取现在的名利，因为得到现在的利益，自己说‘我是沙门’。护国！对于这样的补特伽罗、这样的人等，我不说他们有随顺世俗之忍，何况能有诸佛的大智？他们远离人天之道，何况成就佛道？

“护国！这样的人，我说有八种法障碍菩提。哪八种？一是当生于三恶道，二是当生于边地下贱之处，三是当生于贫穷，四是颜色不正，五是愚痴无智，六是常与恶知识相会，七是多有病患，八是得大恶病而命终。护国！这八法障碍菩提。为什么呢？护国！我也不说只凭言说便能得菩提，我也不说伪装圣者的人有清净之行，我也不说有谄曲的人有菩提之行，我也不说多贪利养的人有供养佛之行，我也不说有我慢的人有清净的般若之行，我也不说没有智慧的人有能决断他人疑惑之行，我也不说有嫉妒的人有清净心之行，我也不说不精进的人有能得诸陀罗尼之行，我也不说不乐功德的人有得善道之行，我也不说悭惜他人之家的人有身心清净之行，我也不说伪装威仪的人能值遇佛会，我也不说乐在俗家的人有清净口业之行，我也不说不恭敬的人有心清净之行，我也不说有不知足的人有乐法之行，我也不说爱惜身命的人有求法之行。

【按】“贫穷”之“穷”，宋、元、明、宫本作“家”。

“护国！我虽然呵骂毁訾六师外道，然而这些人在我的法外进入我的法中作种种恶业，我若毁辱他们，其过患比六师外道多一倍。为什么呢？因为他们只是自己口说‘我是比丘’，而以无行欺诳一切天人世间。”那时世尊想再次宣说此义，说偈道：

```
威仪浊乱无恭敬，
唯增我慢贪名誉，
烦恼覆蔽心迷醉，
此等远离妙菩提。
耽著名利及懈怠，
懈怠增长失正念，
若无正念失持戒，
若无持戒失善道。
彼人生在贫穷家，
得出家已著利养，
如人弃舍于真金，
担负草秽以为宝。
为求名利住山林，
至彼更求诸等侣，
弃舍神通辩才智，
求现名利及眷属。
若彼命终堕恶道，
或生贫穷下贱中，
懈怠恶色无威德，
斯等皆由我慢受。
彼既远离诸善行，
亦由放逸失正念，
在于长远大恶道，
亿千劫中未能脱。
```
（大意：威仪浊乱，没有恭敬，只增长我慢，贪求名誉，被烦恼覆蔽，心中迷醉，这些人远离妙菩提。耽著名利以及懈怠，懈怠增长便失去正念，若没有正念便失去持戒，若没有持戒便失去善道。那人生在贫穷之家，出家之后执著利养，如人弃舍真金，背负草秽当作宝物。为求名利住在山林，到了那里又寻求同伴，弃舍神通、辩才与智慧，求取现世的名利以及眷属。若他命终便堕入恶道，或生于贫穷下贱之中，懈怠、面色丑恶、没有威德，这些都是由于我慢而受报。他既远离诸善行，也由于放逸失去正念，在长远的大恶道中，亿千劫中不能解脱。）

【按】宫本无“烦恼覆蔽心迷醉，此等远离妙菩提”二句。

```
若求名利得菩提，
提婆达多应是佛，
毘岚猛风吹坏物，
懈怠无戒亦复然。
自无善行贪女色，
戒行不净失功德，
于我法中无所用，
无智犹如朽烂木。
若为菩提求佛法，
何得不依解脱行？
犹如黐胶缚猕猴，
我慢求道亦复然。
我昔为求一句法，
弃舍身命为菩提，
彼人懈怠舍我教，
如是无利于我法。
我昔为求善教故，
投身高崖及火聚，
我得闻已如法行，
弃舍一切爱憎等。
彼人闻我功德法，
曾不爱乐于一句，
无法云何得菩提，
犹如盲前说道路。
```
（大意：若求名利能得菩提，提婆达多应当是佛，如毗岚猛风吹坏万物，懈怠无戒也是这样。自己没有善行，贪恋女色，戒行不净，失去功德，在我的法中毫无用处，无智犹如朽烂之木。若为菩提而求佛法，怎能不依解脱之行？犹如以黐胶粘缚猕猴，以我慢求道也是这样。我往昔为求一句法，为菩提弃舍身命，那人懈怠，舍弃我的教法，这样对我的法毫无利益。我往昔为求善教，投身于高崖以及火聚，我听闻之后如法修行，弃舍一切爱憎等。那人听闻我的功德之法，竟不爱乐其中一句，没有法怎能得菩提，犹如在盲人面前说道路。）
