# 《大宝积经》卷第八十九（摩诃迦叶会之二）

元魏·优禅国王子月婆首那 译

## 摩诃迦叶会第二十三之二

【按】“优禅国”，元、明本作“优禅尼国”，与上卷题名同。

#### 末世菩萨唯作供养舍利之业

那时摩诃迦叶对佛说：“世尊！在未来末世后五百岁，什么样的菩萨会行于谄曲？”那时世尊告诉迦叶说：“迦叶！很多人行于谄曲，亲近恶友，少读诵经典，为求衣食。”那时摩诃迦叶对佛说：“善哉，世尊！唯愿世尊利益多人，宣说那些谄曲、不勤修行的菩萨的过失。令那些菩萨听了这些过失之后，自己收摄心行，令其清净。”

那时世尊告诉摩诃迦叶说：“迦叶！在未来末世后五百岁，会有些菩萨亲近恶友，少读诵经典，只作供养舍利的事业，以香花、璎珞、幡盖、灯明供养如来的舍利塔庙。迦叶！我是为了在家无智的众生，令他们种植善根，才说供养舍利。那些愚痴之人不理解我的意思，只作这一事业。迦叶！我在一切天人之中常说这样的法：修奢摩他、毗婆舍那以调伏自己，世间自会有信乐的婆罗门、居士来供养舍利。迦叶！那些愚痴之人舍弃读诵、修禅与智慧，借供养舍利来活命。

“迦叶！若有菩萨以充满三千大千世界、上至梵天的香花灯明，每一根灯炷都如须弥山，以这样等供养如来。若有菩萨以清净心持戒，在师尊之处受持读诵一首四句偈，以清净心修行乃至走七步，功德胜过前者无量无边。迦叶！若有菩萨以充满三千大千世界的花香、末香，在百千年中昼夜六时供养如来。若有菩萨舍弃喧闹，深畏三界，为了利益众生，发心趣向阿兰若处，举足走七步，胜过前面的功德无量无边。迦叶！你认为怎样？如来是为了教化众生才这样说的吗？迦叶！不要作这样的见解，如来说的是实话。为什么呢？因为如来亲见、明了而知。”

#### 往昔妙花如来与尼弥大王

佛告诉迦叶：“过去无量无边不可思议无数阿僧祇劫，那时有佛，号为妙华如来、应供、正遍知、明行足、善逝、世间解、无上士、调御丈夫、天人师、佛、婆伽婆，那劫也名为妙花。迦叶！妙花如来有九十六亿百千声闻大众。那时有一位转轮圣王，名为尼弥，如法治世，统领四天下。迦叶！当时尼弥大王一千个儿子具足，勇健威猛。迦叶！那时大王已具足一千个儿子之后，又有两个儿子结跏趺坐，忽然化生：一名达摩，二名善法。

【按】“结加趺坐”之“加”，宋、明本作“跏”。

“迦叶！那时大王邀请妙花如来以及比丘僧，满八万四千年供养衣服、卧具、饮食、汤药，舍弃种种家事，只修供养。七日之后，为一切比丘各施新衣与种种饮食，随其心意所乐；广造精舍，随其心意乐住。每一位比丘配给七个侍使之人，施予百味饮食。迦叶！那时大王造立一座精舍，方圆八十由旬，彩画微妙，超出世间。妙花如来以及比丘僧坐在那精舍中，从地下涌出众多妙花，令那精舍中的花深至膝盖。迦叶！那时大王在这不可思议功德的精舍中供养妙花如来，满八万四千年，恭敬供养，尊重赞叹。

#### 二童子礼佛，那罗延扶之不起

“迦叶！那时大王供养如来满八万四千年之后，最后一天，妙花如来饭食之后，达摩、善法二位王子与眷属以及四众，来到妙花如来、正遍知之所，头面作礼，对佛说：‘世尊！有没有布施的功德善根，胜过这尼弥大王的功德善根？’迦叶！二位王子礼如来时，大千世界都震动。迦叶！那时妙花如来的侍者弟子，名为通达法，从座而起，顶礼佛足，对佛说：‘世尊！是什么因缘大地震动？因为什么因缘这二位王子礼佛之后便这样住着不起？’

“那时妙花如来告诉通达法：‘善男子！何必问这些。若佛如来说出这二位王子以清净心、深忍、大悲之心礼如来之足，一切天人都会迷闷没溺。’迦叶！那时妙花如来告诉一位神足第一的声闻弟子那罗延说：‘善男子！你显示神力，扶起这两个童子。’迦叶！那时那罗延比丘从座而起，便以右手捉住一个童子，又以左手捉住另一个童子，想扶他们起来，却不能动。当时那罗延用尽大神通，扶两个童子想令他们起来，也不能动他们。如把一根毛分为千万分，连一分也不能动。迦叶！那时三千大千世界大地都震动，山河石壁也都大动，却不能动那两个童子。迦叶！那时那罗延以妙花如来威神之力，令下方恒河沙等诸佛世界都震动，也不能动那两个童子一根毛的一分。迦叶！那时那罗延比丘礼妙花佛，说：‘世尊！我莫非失去了神通力吗？为什么呢？世尊！这两个童子出生不久，在佛前头面著地，我用尽神力也不能令他们起来。’

“那时妙花如来告诉那罗延比丘说：‘善男子！你没有失去神通。善男子！菩萨的境界不可思议，一切声闻、缘觉都不能动，不能思量。善男子！若充满三千大千世界的一切众生，都具有与你一样的大神力，经过亿劫也不能扶起这两个童子。’迦叶！那时妙花如来说这话时，众中四百二十万众生发阿耨多罗三藐三菩提心。那些众生这样想：‘菩萨的神力甚为希有。未得一切智，神力已是如此，大声闻的神力都不能令其动摇，何况成就佛道。所以我们应当行菩萨道，愿证如来无上的智慧。’

“迦叶！那时四百二十万众生这样想之后，对无上菩提心得以坚固安住。迦叶！那时那众中有一位菩萨，名为善慧，在大众中从座而起，偏袒右肩，顶礼佛足，对妙花如来说：‘世尊！唯愿世尊令二童子起来，并如他们所问，愿佛解说。’”

佛告诉迦叶：“那时妙花如来从虚空中发出大音声，那声音遍满乃至十方恒河沙等诸佛世界。声音所到之处，世界大地都六种震动，放大光明遍照十方。迦叶！那两个童子听到这声音之后，从地上起来。迦叶！童子起来时，这三千大千世界的人天伎乐不鼓自鸣，虚空中雨下众多妙花。迦叶！那两个童子从地上起来之后，来到如来之所，右绕三匝，顶礼佛足，合掌恭敬，瞻仰如来。迦叶！那时妙花如来告诉善慧菩萨说：‘善男子！这两个童子礼我足之后，这样问：“世尊！有没有布施的福德善根，胜过这尼弥大王的功德善根？”这两个童子礼我足、发问之后，便住着不起。’迦叶！那时善慧菩萨对妙花如来说：‘世尊！愿佛解说二童子之问，令诸天人得到安乐。’

#### 妙花如来答：少忍与净心礼佛，胜王功德

“那时妙花如来告诉善慧菩萨：‘善男子！你现在谛听，当为你说。善男子！对尼弥国王所作的功德，若有菩萨住于阿兰若行、远离行，少许了知诸法，得无生忍，功德胜过前者无量无边。善男子！若三千大千世界的一切众生，每一个众生所作的功德都如尼弥王。这样三千大千世界一切众生所有的福德，不如菩萨修行远离，住于清净心，与正念相应，了解诸法空、无来无去，这样少许的忍，其功德胜过前面的功德，前面的功德百分不及一，千分不及一，亿分不及一，百亿分不及一，千亿分不及一，百千亿分不及一，百千那由他亿分不及一，乃至算数也不及其一。善男子！如恒河沙等一切世界的所有众生，每一个众生都作如尼弥王那样的福德。那些众生所作的福德，经过恒河沙劫常修福德。善男子！你认为怎样？那些善男子得福多吗？’迦叶！那时善慧菩萨对妙花如来说：‘希有，世尊！如来所说的譬喻不可思议，这样的善根不可思议。’

“迦叶！那时妙花如来告诉善慧菩萨：‘善男子！我现在告诉你，有智慧的人成就深忍，能相信这话。那一切众生所积集的善根，不如这两个童子以清净心礼如来之足；童子的善根胜过前面一切众生的善根，前者百分不及一，千分不及一，百千分不及一，亿分不及一，百亿分不及一，千亿分不及一，百千亿分不及一，百千亿那由他分不及一，乃至算数譬喻所不能及。’迦叶！那时妙花如来的大众之中，八万四千比丘同声说：‘世尊！我们随喜那些人的功德：成就深法忍，相信诸法空，心乐远离，趣向阿兰若举足七步，发阿耨多罗三藐三菩提心，成就智慧。我们随喜。’迦叶！那时妙花如来赞叹比丘们：‘善哉善哉。诸善男子！你们以这随喜之业的不可思议善根，当作恒河沙等的转轮圣王，然后得成阿耨多罗三藐三菩提。’”

那时摩诃迦叶以及大众，一时同声对佛说：“世尊！我们随喜那些人发心，成就深忍，相信诸法空，远离寂灭，自性清净。”

#### 二童子问施不望报，佛说三组四法

那时世尊告诉摩诃迦叶说：“迦叶！那时达摩、善法二童子对妙花如来说：‘世尊！菩萨具足什么法，能布施而不望回报，不生嫉妒，心不悭吝，不生贪著，见他人行施心不希望，成就如来无上之行，得深法忍，成就无上智慧？’迦叶！那时妙花如来告诉善法二童子说：‘善男子！菩萨具足四法，能布施而不望回报，不嫉妒，不悭吝，不生贪，见他人布施不希望，成就如来无上之行，得甚深忍，见无上智。哪四法？一是相信诸法空，二是远离，三是深忍，四是正念。善男子！菩萨具足这四法，能布施而不望回报，心不嫉妒，不悭吝，不生贪，见他人布施不希望，成就如来无上之行，成就深忍，具足无上智。

【按】“告善法二童子”，宋、元、明本作“告达摩善法二童子”。

“‘善男子！又有四法，若菩萨具足这四法，能布施而不望回报，心不嫉妒，不悭吝，不生贪，见他人布施不希望，成就如来无上之行，成就深忍，圆满无上智。哪四法？善男子！菩萨求多闻，得多闻之后游历城邑聚落，说法无所希望，乃至不受一句善言赞叹，心无所贪。诸佛所说的一切布施中，法施第一；住于第一的布施，其心欢喜，不求世间财物的布施。为什么呢？善男子！十方无数阿僧祇诸佛世界的诸佛如来以及比丘僧，不求世间资生之具。若有菩萨住于清净戒，修习正法，具大悲心，不求利养，为一切诸佛所忆念。若有人能宣说一首四句偈，了知所说偈的文字都是自性空，一切诸法也是这样都是自性空。这位善男子的善根功德，胜过前面的善根，前者百分不及一，千分不及一，百千分不及一，亿分不及一，百亿分不及一，千亿分不及一，百千亿分不及一，百千那由他亿分不及一，乃至阿僧祇分也不及一。’

【按】“不求世间资生之具”之“求”，宋、元、明、宫本作“少”。

“迦叶！那时妙花如来告诉二童子：‘善男子！菩萨具足四法，得成如来无上之行。哪四法？一是行于无上之处，二是宣说无上之法，三是布施无上之物，四是相信无上之法。善男子！这名为四法。菩萨成就这四法，得成如来无上之行。’迦叶！当时妙花如来为二童子宣说这些法时，那两个童子听了这些法之后，跃到空中，高七多罗树，同声赞佛：

#### 二童子空中赞佛

```
如来知诸行，教众生行施，
而不著于施，此施无上施。
能成无上忍，此中无有我，
众生命及人，希有大精进。
演说如是法，成就甚深忍，
及得无上行，得无上菩提。
永灭诸欲恼，大智慧清净，
更不受后有，说于远离行。
令住阿兰若，修于空解脱，
亦不生分别，常勤行布施。
不生于分别，此是无垢际，
远离诸名字，说清净尸罗。
令行寂灭处，此是第一戒，
觉知寂灭处，常修行于忍。
```
（大意：如来了知诸行，教众生行布施，而不执著于布施，这布施是无上的布施。能成就无上之忍，这其中没有我、众生、命者以及人，真是希有的大精进！演说这样的法，令人成就甚深之忍，以及得无上之行，得无上菩提。永灭种种欲望苦恼，大智慧清净，不再受后有，宣说远离之行，令人住于阿兰若，修习空解脱，也不生分别，常勤行布施。不生分别，这是无垢之际；远离一切名字，宣说清净的尸罗，令人行于寂灭之处，这是第一戒。觉知寂灭之处，常修行忍辱。）

```
不分别众生，此是清净忍，
离一切分别，修坚固精进。
离一切有为，佛说此精进，
能成远离法，焚烧一切事。
断于诸有无，此无分别禅，
不起诸烦恼，非此亦非彼。
中间亦不住，此第一智慧，
```
（大意：不分别众生，这是清净之忍。远离一切分别，修坚固的精进；远离一切有为，佛说这是精进。能成就远离之法，焚烧一切事，断除诸有与无，这是无分别之禅。不起种种烦恼，不在此也不在彼，中间也不住，这是第一智慧。）

```
远离于三世，修习寂灭想。
复观于此想，此想何处生？
是故知无想，赞叹佛功德。
演说第一法，其心不异念，
听受于正法，说名字无尽。
自性体不成，观境界无实，
其心则解脱。若起如是想，
我为说法者，彼则被魔缚，
不知于法相。若欲得菩提，
及求声闻者，求缘觉菩提，
当修学此法。说于一解脱，
智慧无边量，勿作下劣愿，
当愿上菩提。若求如是身，
相好自庄严，如佛金色身，
当求上菩提。作生一切法，
作者不可得，诸法从缘生，
无自性自性。
```
（大意：远离三世，修习寂灭之想；又观察这想：这想从何处生？因此知道无想。赞叹佛的功德，演说第一义之法，心中不起别的念头，听受正法。说名字无穷尽，而其自性之体不成立；观察境界无实，其心便得解脱。若生起这样的念头：“我是说法者”，他便被魔所缚，不知道法的真相。若想得菩提，以及求声闻、求缘觉菩提的人，都应当修学此法。宣说唯一的解脱，智慧无边无量；不要作下劣之愿，应当愿求无上菩提。若求这样的身：以相好自我庄严，如佛的金色之身，应当求无上菩提。造作生出一切法，而作者不可得；诸法从因缘生，以无自性为自性。）

#### 二童子说发心无生

“迦叶！二童子在虚空中说这偈时，尼弥大王从城中出来，诸地神、虚空诸神都来集会。那时众中八万四千众生发阿耨多罗三藐三菩提心，阿僧祇众生种下善根。迦叶！那时达摩、善法二童子等从空中下来，来到妙花如来之所，说：‘世尊！我们归依佛，归依法，归依僧，发阿耨多罗三藐三菩提心，以比丘之形行菩萨道。世尊！真正发心的人，相信一切法无生。世尊！真正发心的人，不执著诸法。为什么呢？世尊！若有执著，法便不生。所以世尊说，远离执著之心便得那无生。世尊！这无生也不应说是无生。为什么呢？有言说便有生灭。若具足清净之智，便无生灭，无生灭之处是毕竟尽。所以世尊！以平等之际发阿耨多罗三藐三菩提心，不念于法，也没有法可得，也没有不得，这样得到平等——无得的平等。为什么呢？因为一切诸法本性清净。’迦叶！那时妙花如来为二童子宣说此法时，众中一万众生得无生法忍。尼弥大王以及一千个儿子、五千大臣，都发阿耨多罗三藐三菩提心。”

【按】“若有著则法不生”之“法”，宫本作“善法”。

#### 二童子说出家颂

佛告诉迦叶：“那时妙花如来饭食完毕，洗了钵之后，在大众中告诉大王说：‘尼弥大王！我现在要说法。’王与大众听到佛将说法，踊跃欢喜。迦叶！那时达摩、善法二童子听闻佛说法，以清净信心远离欲火，想求出家，从城中出来到佛之所。到了佛所之后说颂道：

```
一切诸如来，赞叹出家法，
在家多垢秽，坏灭白净法。
增长不善法，毁灭于善法，
在家多过失，出家离染污。
设使百亿劫，受欲无厌足，
受欲无厌足，在家而死灭。
如海受众流，而无有厌足，
凡夫亦如是，受欲无厌足。
如火烧干草，而无厌足时，
凡夫亦如是，受欲无厌足。
贪欲网所缚，灭坏于世间，
是故应离缚，为发出家故。
```
（大意：一切诸如来都赞叹出家之法；在家多有垢秽，坏灭白净之法，增长不善之法，毁灭善法；在家多有过失，出家远离染污。假使经过百亿劫，受欲而无厌足，受欲而无厌足，在家中死去。如大海接受众多河流，而没有厌足；凡夫也是这样，受欲而无厌足。如火烧干草，没有厌足之时；凡夫也是这样，受欲而无厌足。被贪欲之网所缚，灭坏世间，所以应当离开这系缚，为此而发心出家。）

【按】“受欲无厌足”重出一句，元、明本无；“在家而死灭”之“在”，明本作“抂”，“而”，元、明本作“如”，“灭”下，元、明本有“受欲无厌足”五字。“干草”，宫本作“草木”。

```
在家具众过，不得无上道，
出家修远离，尔乃得菩提。
过去诸如来，已入于涅槃，
住阿兰若法，获得大菩提。
是故学诸佛，趣向阿兰若，
舍爱离居家，然后得安隐。
一切三千界，珍宝满其中，
以此珍宝聚，在家施诸佛。
若以无恼心，知于在家过，
学诸佛如来，出家求智慧。
既求出家已，远离诸欲火，
举足行七步，胜以三千施。
```
（大意：在家具有众多过失，不能得无上道；出家修远离，才能得菩提。过去诸如来已入于涅槃，都是住于阿兰若法而获得大菩提。所以学习诸佛，趣向阿兰若，舍弃爱欲、离开居家，然后得安隐。以充满一切三千世界的珍宝，在家中拿这珍宝之聚布施诸佛；若以无恼之心，知道在家的过失，学习诸佛如来，出家求智慧。既已求得出家，远离种种欲火，举足走七步，便胜过以三千世界的珍宝布施。）

```
三千之功德，不如此一分，
是故出家者，如来之所赞。
成就大智慧，远离诸系缚，
离一切诸著，乃证无上道。
速住寂静处，断除诸欲爱，
一切毒炽心，悉灭无有余。
学诸佛如来，如实知诸法，
速远离在家，住阿兰若法。
若欲求佛道，修于远离行，
应学阿兰若，不应乐在家。
此是诸佛境，圣人所住处，
能住此道者，则能得菩提。
欲等恼众生，若求远离者，
应离在家法，修习阿兰若。
欲证甘露法，转无上法轮，
摧伏诸魔怨，当习阿兰若。
```
（大意：三千世界布施的功德，不如这一分；所以出家，为如来所赞叹。成就大智慧，远离种种系缚，离开一切执著，才证无上道。迅速住于寂静之处，断除种种欲爱，一切毒害炽盛之心都灭尽无余。学习诸佛如来，如实了知诸法，迅速远离在家，住于阿兰若法。若想求佛道，修远离之行，应当学阿兰若，不应乐于在家。这是诸佛的境界，圣人所住之处，能住于此道的人，便能得菩提。欲望等苦恼众生，若求远离，应当离开在家之法，修习阿兰若。想证得甘露之法，转无上法轮，摧伏诸魔怨，应当修习阿兰若。）

#### 举国出家

“迦叶！那时达摩、善法二童子说了这颂之后，从城中出来，前往妙花如来所住之处。到了之后头面礼足，右绕三匝，说：‘世尊！我们现在想在如来之所求出家。唯愿世尊哀愍听许，令我们得以出家。’迦叶！那时妙花如来知道二童子信心清净，求出家之法，当时如来便听许他们出家，住于比丘之法。迦叶！那时大王听到二童子已得出家，便令太子继承王位，王与九百九十九个儿子、八万四千夫人、五千大臣以及人民，以清净信心远离欲火，舍家出家，一起前往妙花佛所。到了之后顶礼佛足，对妙花佛说：‘世尊！我们想求出家，愿佛听许，令我们得以出家。’迦叶！当时妙花佛知道大众信心清净，全都听许出家，住于比丘之法。

【按】“信心清净”之“信心”，宋、元、明、宫本作“心信”。

“迦叶！那时大王的第一太子登位七日之内，自己思惟：‘我终究不舍萨婆若心。何必要这样的王位宝财，被欲望所缚。我终究不舍无上菩提。’这样想之后，发心出家，在十五日游历四天下，说这偈道：

```
我父及亲属，皆悉已出家，
无量亿众生，为法亦出家。
我今乐出家，不乐住五欲，
一心求出道，欲诣导师所。
若发心出家，离诸欲火者，
应速随我法，离难甚难得。
不发出家心，不远离欲火，
安心在居家，安住于实法。
```
（大意：我的父亲以及亲属都已出家，无量亿众生为了法也已出家。我现在乐于出家，不乐住于五欲，一心求出离之道，想前往导师之所。若发心出家、远离欲火的人，应当迅速随我之法，这是离难而甚难得的。若不发出家之心，不远离欲火，便安心在居家，安住于真实之法。）

【按】“一心求出道”之“道”，元、明本作“家”。“应速随我法”之“法”，宋、元、明、宫本作“去”。

“迦叶！当时那童子说这偈时，四天下中没有一个众生乐于在家，都发心愿求出家。迦叶！当时妙花如来知道众生心信清净、求出家之后，妙花如来在四天下的一切城邑村落都化作化佛以及比丘僧。迦叶！当时四天下的一切众生，没有一人住在家中，都以清净信心远离欲火，全部得以出家。那些众生出家之后，不需要种植，那地自然生出粳米，诸树自然生出衣服，一切诸天供侍给使。

【按】“时彼童子说此偈时”之“童”，元、明本作“太”。“种殖”之“殖”，明本作“植”。

“迦叶！那时达摩、善法二比丘勇猛精进，在六十三亿年中不坐不卧，只勤加精进，求萨婆若，念萨婆若。在六十三亿年中勤加精进之后，得遍至三昧，所坐之地名为金刚处，那地全是金刚所成。十方一切诸佛所说之法，他们都能听闻受持，听闻之后又能为他人解说。迦叶！当时四天下的一切众生，若有修学声闻乘的，没有一个众生以凡夫之身命终，最懈怠的也得阿那含果，从此命终生于净居天。与他们同行求缘觉的人，从此命终，当生在他方无佛之处，生于大种姓，诸根具足。由于过去世的善根之力，远离欲火而行出家，七日之后成就缘觉之道，利益无量无边众生，入般涅槃。菩萨乘的人成就五神通，具足四无量、无碍辩才，得陀罗尼。

“迦叶！不要作别的念头。那时的尼弥大王难道是别人吗？就是我。那时的太子，就是现在的弥勒菩萨。迦叶！不要作别的见解。为什么呢？达摩童子，就是现在的文殊师利。善法童子，就是虚空藏菩萨。迦叶！你看那佛的国土这样清净，是具善根的众生所住之处。”

#### 二比丘说真供养如来

那时摩诃迦叶对佛说：“世尊！妙花如来寿命多久？”佛告诉迦叶：“妙花如来寿命八劫。迦叶！妙花如来般涅槃之后，正法住世满足一劫。一切诸天供养舍利，没有在家之人。迦叶！当时那两位比丘少欲知足，不供养舍利，不礼佛塔。迦叶！那时诸天、新学比丘百千大众互相说：‘这两位比丘是邪见，不信佛的舍利，不兴供养，不礼佛塔。’迦叶！那时诸天以及比丘百千大众说这话时，达摩、善法二比丘问众人说：‘你们认为怎样？怎样的供养是真正供养如来？因为什么事，如来的舍利才得到供养？’比丘们说：‘因为修戒、定、智慧、解脱、解脱知见，舍利才得到供养。’二比丘说：‘修戒、定、慧、解脱、解脱知见，才是真正的供养；不是供养舍利。’比丘们说：‘是这样，是这样，如你们所说。什么是戒相？禅定、智慧、解脱、解脱知见又是什么相？’达摩、善法二比丘说：‘无作之相是戒相，乃至解脱知见的无作之相是知见相。’迦叶！当时二比丘对众人说：‘你们认为怎样？无作能供养无作吗？’比丘们说：‘不能。’

“达摩、善法二比丘说：‘真正的供养，没有佛想，没有见佛，何况供养。若要供养佛，应当供养自身。’比丘们说：‘怎样供养自身？’二比丘说：‘应当如如来、应、正遍知那样供养自身，为一切众生所供养。如佛所学，应当这样学。护持禁戒，积集种种善法，思惟诸法而不取法相。若能这样自我供养，当得天人的供养。若想供养佛的舍利，应当自我供养。如佛如来具足种种功德，舍利才得到供养。若能成就这样的功德，名为供养佛。不起想相，名为供养佛。无论多少都不生分别，名为供养佛。不是向后世去，不是从今世来，不是彼岸，不是常也不是断，不是取也不是舍，这便名为供养如来。不增不减，不生不灭，不尽也不是不尽，这便名为供养如来。不是心，也不是心数法，不是忆想，不是我，不是取，不是受，不是诤论也不是不诤论，不是毁也不是赞，不是二也不是入，这便名为供养如来。也不是有为，也不是无为，这便名为供养如来。身无所作，口无所作，意无所作，在身口意中求之不可得，这便名为供养如来。没有过去之想，未来、现在之想也不可得，无依无著，没有所求之想，也不分别，这便名为供养如来。没有佛想，没有法想，没有僧想，没有人想、自想、他想，这便名为供养如来。

【按】“非今世来”下，元、明本有“非此岸”三字。

“‘真如来身无生无相，不可以生而修供养。真如来身名为无作之相，不以作相而修供养。真如来身名为无二之相，不应以二相而修供养。真如来身名为无漏之相，不以有漏而修供养。真如来身名为空相，不以身见、命见、断见、常见、我见、我所见、有见、无见供养如来。真如来身名为无相之相，不可以相而修供养。真如来身名为无愿之相，不可以愿而修供养。真如来身名为无有之相，不可以有而修供养。真如来身名为不动之相，不可以动相而修供养。真如来身名为无行之相，不可以行而修供养。真如来身名为离贪之相，不可以贪而修供养。真如来身名为离瞋之相，不可以瞋而修供养。真如来身名为离痴之相，不可以痴而修供养。真如来身具足戒、定、慧、解脱、解脱知见，不可以破戒、乱心、愚痴而修供养。真如来身具慈、悲、喜、舍，不可以瞋心、恼心、嫉妒心、散乱心而修供养。真如来身具足布施、持戒、忍辱、精进、禅定、智慧，不可以悭吝、破戒、瞋恚、懈怠、散乱、愚痴而修供养。’迦叶！达摩、善法在大众中宣说此法时，四百二十万众生得无生法忍，八万四千众生得清净智阿那含果，二百三十万众生发阿耨多罗三藐三菩提心。

【按】“真如来身无生无相”，元、明本作“真如来身名无生相”。“具施”，明本作“具布施”。

“迦叶！你看达摩、善法二比丘等这样的清净心。迦叶！你应当学那两位正士甚深的忍以及善巧方便。迦叶！那两位比丘在大众中宣说此法时，比丘们听了此法之后，都安住于深忍，都行少欲知足之行，不供养舍利以及佛塔庙。为什么呢？因为那些比丘都乐于深法。迦叶！那七日之后，一切佛塔都隐没，以及舍利所在的器中，舍利也都隐没。迦叶！你应当这样学那正士甚深的忍。”

#### 末世为活命供养塔庙，非沙门业

佛告诉迦叶：“应当知道，末世后五百岁，会有些菩萨以及比丘，不修身，不修心，不修戒，不修慧，为了活命，供养佛塔以及佛的舍利，不是为了涅槃，不是为了离欲而修供养，自己违犯禁戒，愚痴无智。如来的舍利是戒、定、慧、解脱、解脱知见所熏修的，他们却为了活命而供养尊重。自己具有贪、瞋、痴，对佛如来、应、正遍知那离贪、瞋、痴的舍利，为了活命而兴起供养；自身具足悭贪、嫉妒、瞋恚、懈怠、乱心、愚痴，若有大施主正住于一心，他们为了活命，劝化施主供养如来的舍利。迦叶！我为了教化初发心的诸善男子、善女人等，以神通力留下这些舍利，令供养者受人天之乐，作为未来之因，乃至得涅槃。那些愚痴之人在我的法中虽然得以出家，不理解我的法，舍弃出家之行，而只供养塔庙舍利，为了自己活命，为了得到衣钵，为了利养，为了名闻，为了这些事而供养舍利。

【按】“勋修”之“勋”，元、明本作“熏”，义即熏修。

“什么名为比丘之业？迦叶！如上面所说，沙门之业有两种：一是修禅，二是习诵。这样说，是为了入道，不是究竟之说。迦叶！若有作业能尽一切业，名为沙门之业。无作、无诵、无禅，无作也无无作，无念也无不念，无尽无生，证三解脱门，不住三界，无来无去，这是沙门之业。那些众生离开这正业，而另习其余之业。那福业是为了教化在家之人，这样在家人随顺如来的教导，当得阿那含果。那些愚人在我的法中出家，尚且不修行随顺之法，何况能得到果证。若说他们能得果，那是不可能的。

#### 咒袈裟之喻

“迦叶！在未来世后五百岁，会有相似的沙门，衣服形貌像沙门，戒不相似，定不相似，慧不相似。迦叶！譬如有人善知医方以及种种咒术，便以咒术咒一件袈裟，给人令他穿上，那人见了生贪，便穿上它。到了第七日或第八日，他的身体炽燃，犹如火聚。如那咒过之后拿给人的袈裟，那人见了便生贪著；比丘也是这样，见到好衣服便受取而穿，到了第七日或第八日，无论在屋内、在巷中、在林中，他所穿的衣服炽燃如火，烧毁人的善根。迦叶！你认为怎样？那人穿这袈裟有利益吗？”迦叶对佛说：“世尊！没有利益。”佛告诉迦叶：“是这样，是这样。我的袈裟，是戒、定、智慧、解脱、解脱知见，是无量阿僧祇善根所集成的。迦叶！在未来世会有愚痴之人，穿著圣人之衣，像沙门的样子，进入村邑之中。有信心的婆罗门、长者、居士，见他穿著法服，以为是沙门，都共同尊重、供养、赞叹。那愚痴之人因为袈裟而得到供养，便生欢喜，身坏命终堕于地狱。生在地狱之后，以炽热的铁片作为衣服，吞食铁丸，饮熔化沸腾的铁汁，坐在热铁床上。迦叶！你看袈裟的威德是这样。那愚痴之人穿著袈裟，受乐放逸，自作恶业，身坏命终堕于地狱。迦叶！我常说：宁可以烧热的铁片为衣，也不以破戒之身穿著袈裟；宁可吞热铁，也不以破戒之身吃人的信施。迦叶！你看破戒之人吃他人的信施有这样的过患，所以你们应当修学清净的戒法。

#### 末世画像卖像以自活

“迦叶！你认为怎样？无论天、龙、夜叉、乾闼婆、阿修罗、迦楼罗、紧那罗、摩睺罗伽，无论人、非人，能作出如来的色身之像吗？”迦叶对佛说：“不能，世尊！如来的色像不可思议，因为没有色像。所以这些都不能作。”佛告诉迦叶：“在未来世后五百岁，会有些比丘，不修身，不修心，不修戒，不修慧，或在布上、墙壁之下造如来像，借此来活命，因为这一事业而自高轻慢他人。”

【按】“叠”，元、宋本作“㲲”，即细布。

那时摩诃迦叶对佛说：“世尊！波斯匿王造如来像，得福多吗？”佛说：“迦叶！得福甚多。波斯匿王造如来像，布施无价之衣，不求衣服饭食的回报。迦叶！那些愚痴之人为了活命而造立形像。迦叶！卖畜生尚且不善，何况那些愚痴之人作如来像，在白衣面前炫卖以自己活命。迦叶！譬如有人年幼无知，舍弃甘露而饮毒药。迦叶！那些愚痴之人也是这样，造如来像为了资生而卖掉，这名为毒。迦叶！所说的毒，就是在正法中贪是那毒。迦叶！那些愚痴之人因为贪心而生起瞋恚，互相斗诤，互相诽谤，各说‘我在行供养’，因那诤论而堕于地狱。迦叶！譬如有人没有善巧方便，进入敌阵作战时，所持的刀剑反而伤了自己。迦叶！愚痴之人也是这样，因为没有方便，因为法的缘故而堕于地狱。

【按】“而起瞋恚”之“起”，《大正藏》作“记”，今依CBETA（所录高丽藏）作“起”，宫本同。

“迦叶！若有善男子、善女人以七宝造如来塔，庄严成就，每一座宝塔都高广严好如须弥山，遍满恒河沙数诸佛世界，如甘蔗、竹、苇那样密集。迦叶！你认为怎样？那善男子、善女人得福多吗？”迦叶对佛说：“世尊！造四指高的如来像，得福尚且无量，何况造如须弥山那样的像，所得功德不可思议。”佛告诉迦叶：“若有菩萨内观佛身，得深法忍，功德胜过前者无量无边。迦叶！若又有人住于净戒，以四句偈为他人宣说，解释其义趣，所得的福德无量无边。

【按】“不可思议”之“议”，宋、元、明、宫本作“量”。

#### 往昔大精进菩萨观画像

“迦叶！怎样观如来之身？迦叶！若菩萨想观如来，应当学大精进菩萨。迦叶！在往昔无数阿僧祇劫，有一位佛世尊，号为光明如来、应供、正遍知、明行足、善逝、世间解、无上士、可化丈夫调御师、天人师、佛、婆伽婆。迦叶！光明如来般涅槃之后，有一位菩萨，名为大精进，是婆罗门种，端正无比。迦叶！光明如来的正法之中，有些比丘少欲知足，住于如法之行。迦叶！那些比丘都造立如来的形像。那时有一位比丘在白布上画了如来像，以种种彩色庄严，全都具足，拿到大精进菩萨那里。那时大精进菩萨见到这画像，心中大为欢喜，这样说：‘如来的形像尚且如此妙好，何况如来正遍知之身。愿我来世得成就这样妙色之身。’那时大精进菩萨这样想：‘我现在不能住在家中。若在家中，不能成就这样的身。’

【按】“众彩”之“彩”，宫本作“缘”。

“迦叶！那时大精进菩萨年方十六，诸根具足，到父母那里头面敬礼，对父母说：‘我现在想在如来的正法中出家学道，愿父母随喜。’父母回答：‘不要这样说。为什么呢？我们现在年老，只有你一个儿子，你若出家，我们就会死。’大精进说：‘我当设法令父母存活，我也得以出家。’父母问：‘你想做什么？’儿子对父母说：‘我从今日起，不吃种种美味，不上床座，不吃酥油，不喝浆水，无论善言恶言，口都不说，直到得以出家。’迦叶！大精进菩萨这样立誓之后，默然而住，这样默然一日不食。那时父母念诵种种咒术，拿着百味饮食给他，他也不肯吃，也不说话。

【按】“苏油”之“苏”，元、明本作“酥”。

“迦叶！大精进菩萨这样默然过了第二日。那时父母与母亲的相识五百人等，拿着百味饮食来到他那里，念诵种种咒术，希望他进食；他连看都不看，何况吃。迦叶！大精进在第三日，父亲的亲属五百人，拿着种种饮食劝他进食，他也是这样默然不语，不饮不食，也不看一眼。在第四日，五百位同伴朋友拿着百味饮食，念诵种种咒术，要令他顺从他们的意思。大精进仍默然而住。在第五日，那时父母把宝藏中的金、银、琉璃种种宝物全部拿出，以及八万四千个以上妙之物庄严的婇女，带到他那里。父亲的亲属、母亲的亲属以及他的同伴朋友各五百人，劝大精进这样说：‘你应当住在家中，以这些财宝随意布施作福，与诸婇女共相娱乐。’大精进在大众中默然而住，连看一眼也没有。在第六日，他断除种种忆想，不起进食之念，只念如来、应、正遍知。迦叶！那时父母以及他的相识、八万四千位妙婇女，同时悲泣，礼拜大精进。大精进仍然不看一眼。

【按】“望其飡设”之“设”，宫本作“食”。“汝当在家”之“当”，宋本作“常”。“不起食念，但念如来”，《大正藏》脱“但念”二字，作“不起食念如来”，今依CBETA补，宋、元、明、宫本同。

“迦叶！那时大精进菩萨所住之处有一位宅神，在虚空中显现大神力，说颂道：

```
精进心坚固，难动如须弥，
不舍出家心，为得菩提故。
大地可倾动，火可在水居，
如是等可转，菩萨不可动。
汝等莫勤苦，而作不善业，
众生无慧眼，久远处生死。
为利诸群生，是故求菩提，
其心乐出离，必成无上道。
不为世间报，而行菩萨道，
愿成大觉智，救济苦众生。
三千大千界，珍宝满其中，
及诸上妙土，其心不贪著。
汝等愚痴心，所作不善业，
汝当自悔过，菩萨不处俗。
```
（大意：大精进的心坚固，难以动摇如须弥山，不舍出家之心，是为了得菩提。大地可以倾动，火可以居于水中，这样等事都可转变，菩萨却不可动摇。你们不要勤苦地作不善之业，众生没有慧眼，久远地处在生死之中。他为了利益群生，所以求菩提，其心乐于出离，必定成就无上道。他不为世间的果报而行菩萨道，愿成就大觉之智，救济受苦的众生。三千大千世界充满珍宝，以及种种上妙的国土，他的心都不贪著。你们以愚痴之心所作的不善之业，你们应当自己悔过，菩萨不会处于俗世。）

“迦叶！当时大精进菩萨的父母、眷属、相识以及诸婇女，听了天神的话都悔过，告诉菩萨说：‘随你的意思出家。你应当饮食，不要令性命断绝。’迦叶！当时大精进七日不食，光明焕发，颜色不变，只是心中忆念正遍知之身，一切诸天散花供养。当时大精进过了七日之后，舍弃种种家业，如丢弃涕唾。那时父母、同伴朋友、相识以及八万四千婇女，都悲泣着随行相送。

【按】“汝当饮食”之“饮”，宫本作“饭”。

“那时大精进菩萨拿着画在布上的佛像，进入深山中寂静无人、只有禽兽的地方，展开画像，取草作座，在画像前结跏趺坐，正身正念观察如来。仔细观察之后，这样想：‘如来是这样希有微妙，画像尚且如此端严微妙，何况如来正遍知之身。’又这样想：‘怎样观佛？’那时林神知道那菩萨心中所想，对菩萨说：‘善男子！你这样想“怎样观佛”。若想观佛，应当观画像，观这画像与如来无异，这名为观佛。这样观，名为善观。’

【按】“结加趺坐”之“加”，明本作“跏”。

“当时大精进这样想：‘我现在怎样观这画像与如来相等？’又这样想：‘如来像不觉不知，一切诸法也是这样不觉不知。这样的像只有名字，一切诸法也是这样只有名字，这样的名字自性空寂，无所有。如来之身，其相就是这样。如这画像，不是证，不是得，不是果，不是证者，不是得者，不是得果者。不是住者，不去不来，不生不灭，不垢不净，非色非非色，不是贪尽，不是瞋尽，不是痴尽，不是阴、界、入，不是初、不是中、不是后。一切诸法也是这样，如来的身相也是这样。如这画像不觉不作，一切诸法也是这样，如来的身相也是这样。如这画像，不见、不闻、不嗅、不尝、不触、不知，没有出息，没有入息，一切诸法也是这样，没有知者。如这画像不属于欲界所摄，不属于色界、无色界所摄，一切诸法也是这样。如这画像，不是初、不是中、不是后，不是此、不是彼，不是行也不是非行，不是取也不是舍，不是作也不是诵，不是实也不是虚，不是生死也不是涅槃，一切诸法也是这样，如来的身相也是这样。’

“菩萨这样观如来之身，结跏趺坐，经过一日一夜，成就五神通，具足四无量，得无碍辩，得普光三昧，具大光明。成就超过人眼的天眼，以这天眼见到东方阿僧祇佛。得清净天耳，诸佛世尊所说之法都能听受。因为天耳清净，每一位佛所说之法，都能听闻受持而互不障碍。迦叶！当时大精进勤行精进满足七日，以智慧为食，不食世间供养，一切诸天散花供养。迦叶！当时大精进不披袈裟，也不见佛，不受禁戒，心中只是忆念、学习萨婆若。迦叶！菩萨应当这样观如来之身，非观也非非观。迦叶！菩萨应当这样观如来的画像，如大精进菩萨摩诃萨观如来像，这样观之后成就大智慧，以此智慧都见到十方阿僧祇佛，听闻佛说法。

【按】“具足无量”之“足”，元、明、宫本作“四”，今依此译作“具足四无量”。

“迦叶！那时大精进菩萨从山中出来，来到村落为人说法，一次法会说法，令二万众生安住于阿耨多罗三藐三菩提，无量阿僧祇众生安住于声闻、缘觉的功德，父母亲属都安住于不退转的阿耨多罗三藐三菩提。迦叶！不要作别的念头。那时的大精进菩萨摩诃萨难道是别人吗？就是我。迦叶！所以菩萨摩诃萨应当学大精进菩萨摩诃萨，也应当学其余诸大菩萨。

“迦叶！在未来末世后五百岁，会有些求菩萨道的善男子，没有方便之心，多有贪著，在墙壁下画如来像而求利养。他们这样说：‘只有我在供养，别人都没有供养。’以修少许善事而自高轻慢他人，借这供养来活命。迦叶！那时的众生不修三昧，不诵正典，只作这一事业。因为这一事业，从施主那里获得衣服、饮食、卧具、汤药来活命。迦叶！你看那些破戒的菩萨，住于不清净的戒，自称多闻。迦叶！那些破戒之人不诵经典，供养形像而借此活命。”

#### 流通

那时摩诃迦叶对佛说：“世尊！希有，世尊！希有，善逝！世尊广说愚痴凡夫谄曲的过失。世尊！若有善男子、善女人听到这样的说法，哪有不住于清净戒的？世尊！愿此法在未来久住，令那些善男子、善女人听了之后生惭愧心，想：‘如来知道我，如来觉察我。’令他们所作的邪法永远止息。”那时世尊告诉摩诃迦叶：“如来所说，是为了善男子；为那些听闻我这法而修行离恶的人，我为此人说这样的法。”

那时世尊说此经之后，摩诃迦叶、弥帝隶菩萨、文殊师利童子，一切世间的天、人、阿修罗、乾闼婆等，听闻佛所说，都大欢喜。

【按】“弥帝隶”，即弥勒菩萨的另一种音译。
