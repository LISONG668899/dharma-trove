# 法界平等性之义

麦彭仁波切 造

顶礼文殊师利！

```
མདོ་སྔགས་ཐེག་པའི་རྟོགས་བྱའི་གནད། །
ཆོས་དབྱིངས་མཉམ་པ་ཉིད་ལ་ཐུག །
མཉམ་པ་ཉིད་དུ་རྟོགས་པ་ལ། །
དངོས་པོར་ལྟ་བ་རྟོགས་པ་གནད། །
```

经、咒二乘所应证悟之要害，最终皆归结于法界之平等性；而欲证悟此平等性，其中关键，即在于证悟对诸法之见地。

```
ལྟ་བ་སྤྲོས་བྲལ་དབུ་མ་དང་། །
སྔགས་ལམ་ལྷན་སྐྱེས་བདེ་ཆེན་གྱི། །
གནད་ལ་གོམས་པས་སྤྲོས་བྲལ་ཤེས། །
བློ་འདས་རང་བྱུང་ཡེ་ཤེས་འཆར། །
```

通过串习离戏中观之见地，以及密咒道俱生大乐之要害，便能了知离戏之义；超越分别心识、自然而生之智慧，由此显现。

```
དེ་ལ་གོམས་པ་བརྟན་གྱུར་ན། །
འཁོར་འདས་ཆོས་ཀུན་མཉམ་པ་ཉིད། །
ཆོས་སྐུ་ཐིག་ལེ་ཉག་གཅིག་དོན། །
རང་གི་རྒྱུད་ལ་སྒྲིབ་མེད་འཆར། །
```

若于此串习得以稳固坚定，则轮回与涅槃之一切诸法皆平等一味；法身唯一明点之义，便能于自相续中无所障蔽地显现出来。

```
ཆོས་རྣམས་ཐམས་ཅད་མཉམ་པ་ཉིད། །
མཉམ་པ་ཉིད་ལ་བླང་དོར་མེད། །
མཉམ་ཉིད་གདེང་དུ་གྱུར་པ་ན། །
རྟོགས་པ་ཚད་དུ་འཁྱོལ་ཞེས་བྱ། །
```

一切诸法悉皆平等，于平等性之中，本无取舍可言；当对此平等性生起真实定解之时，便称之为证悟已达究竟。

```
རྟོགས་པ་ཚད་དུ་འཁྱོལ་བའི་ཚེ། །
འཁོར་དང་མྱ་ངན་འདས་པ་དང་། །
བདེ་དང་སྡུག་བསྔལ་བདག་དང་གཞན། །
ཐམས་ཅད་མཉམ་ཉིད་གྲོལ་བ་ན། །
འཇིགས་མེད་ཕྱོགས་ལས་རྣམ་རྒྱལ་ཡིན། །
```

当证悟达至究竟之际，轮回与涅槃、安乐与痛苦、自与他，一切悉皆于平等性中得以解脱之时，即是所谓的"无畏"、亦即"于一切方遍皆得胜"。

```
ཕྱོགས་ལས་རྣམ་པར་རྒྱལ་བ་གང་། །
རིག་འཛིན་དཔའ་བོ་རྒྱལ་བའི་སྲས། །
ས་རྣམས་སྦྱོང་ཞིང་འགྲོ་བ་འདུལ། །
འབྲེལ་ཚད་དོན་དང་ལྡན་པར་འགྱུར། །
```

凡获得如是遍方胜利之人，便成为持明者、勇士、诸佛之子；他们净治诸地、调伏众生，凡与之结缘者，皆能因此而具足意义。

```
དེ་ཕྱིར་བརྒྱུད་པའི་མན་ངག་གིས། །
ཡང་དག་ལྟ་བ་རྟོགས་བྱས་ལ། །
མཆོག་ཏུ་གོམས་པ་བརྟན་པ་ཡིས། །
རྒྱལ་བ་རིག་འཛིན་གྲུབ་མཐར་སྙོགས། །
```

是故，依凭传承之窍诀教授，证悟真实无谬之见地，再以殊胜稳固之串习，终将证得胜者持明之究竟果位。

```
དེ་སྐད་གདམས་པ་སྐལ་བཟང་གི། །
འགྲོ་བའི་རྒྱུད་ལ་སྨིན་གྱུར་ནས། །
ཡང་དག་ལམ་མཐོང་རིག་འཛིན་གྱི། །
དགོངས་པའི་བཙན་ས་ཟིན་གྱུར་ཅིག །
```

愿如是教言，于具善缘之众生相续中得以成熟；愿彼等得见真实无谬之道，攻克持明者密意之坚固要塞！

于铁鼠年十二月二十六日，在协宗扎西曲林，麦彭迅疾书就。吉祥圆满！

---

## 译者说明

本篇依藏文原颂重新译出。"ཆོས་དབྱིངས་མཉམ་པ་ཉིད"（法界平等性）指轮涅一切诸法于胜义中本自平等、无有高下取舍之实相；"རྟོགས་པ་ཚད་དུ་འཁྱོལ"（证悟达至究竟/极限）为格鲁、宁玛等宗派论及修证次第时常用之表述，意谓证悟功德臻于圆满、再无可进之境地，故译为"证悟已达究竟"。末段"དགོངས་པའི་བཙན་ས"（密意之堡垒/要塞）为藏文诗颂中常见之譬喻，喻证悟之境地犹如攻取之城塞，故依其譬喻原貌译出，未作平淡化处理。
