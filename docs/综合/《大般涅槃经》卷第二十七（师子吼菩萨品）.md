# 《大般涅槃经》卷第二十七（师子吼菩萨品）

北凉·天竺三藏昙无谶 译　刘宋·沙门慧严等 依《泥洹经》再治

## 师子吼菩萨品之三

### 五阴念念生灭，谁缚谁解

师子吼说："世尊，如佛所说，一切诸法有两种因：一是正因，二是缘因。依这两种因，应当没有系缚与解脱。这五阴念念生灭，若是生灭的，谁被系缚？谁得解脱？世尊，因这五阴生出后来的五阴，这五阴自己灭了，并不到达那后来的五阴；虽然不到达那里，却能生出那后来的五阴。如因种子生芽，种子不到芽中，虽不到芽中，却能生芽。众生也是这样，怎样有系缚与解脱？"

"善男子，仔细听，仔细听，我当为你分别解说。

#### 临终与中阴

"善男子，如人舍命、受大苦时，宗亲围绕，号哭懊恼，此人惶怖，不知依靠谁来救护；虽有五根，却无所觉知；肢节颤动，不能自持；身体虚冷，暖气将尽；见到先前所修善恶的报相。

"善男子，如太阳将落，山陵土堆的影子向东移去，理上没有向西移的；众生的业果也是这样，这五阴灭时，那五阴相续而生。如灯生起，黑暗就灭；灯灭了，黑暗就生起。

"善男子，如用蜡印印在泥上，印与泥相合，印离开而纹样成就；而这蜡印并不变到泥中，纹样不是从泥中出，也不是从别处来，因为印的因缘而生出这纹样。现在的五阴灭了，中阴的五阴生起，这现在的五阴终不变为中阴的五阴；中阴的五阴也不是自己生起，也不是从别处来，因为现在的五阴，所以生出中阴的五阴。如印印泥，印离开而纹样成就，名称虽无差别，而时节各异。所以我说，中阴的五阴不是肉眼所见，是天眼所见。

"这中阴中有三种食：一是思食，二是触食，三是意食。

"中阴有两种：一是善业之果，二是恶业之果。因为善业，得善的觉观；因为恶业，得恶的觉观。

"父母交会和合之时，随业的因缘，一向趋向受生之处，对母亲生起爱，对父亲生起瞋；父精出时，以为是自己所有，见了心中喜悦，生起欢喜。以这三种烦恼因缘，中阴的五阴坏了，生出后来的五阴，如印印泥，印离开而纹样成就。

#### 系缚

"出生时诸根有具足有不具足。具足的，见色就生贪；因为生贪，就名为爱；因为迷狂而生贪，这名为无明。以贪爱与无明两种因缘，所见的境界都是颠倒：以无常见为常，以无我见为我，以无乐见为乐，以无净见为净。因为四种颠倒，作善恶之行；烦恼造作业，业又造作烦恼，这名为系缚。因为这个道理，名为五阴生起。

#### 解脱

"此人若得亲近佛以及佛弟子、诸善知识，就能听受十二部经；因为听法，观察善的境界；因为观察善的境界，得大智慧；大智慧名为正知见；得了知见，就对生死生起悔厌之心；生起悔厌之心，就不生欢乐；不生欢乐，就能破除贪心；破除贪心，就修八圣道；修八圣道，就得无生死；没有生死，名为得解脱。如火不遇到柴薪，名之为灭；灭了生死，所以名为灭度。因为这个道理，名为五阴灭。"

### 烦恼锁缚五阴

师子吼说："空中没有刺，怎么说拔刺？五阴没有系缚，怎么说系缚？"

佛说："善男子，以烦恼之锁系缚五阴。离开五阴，就没有别的烦恼；离开烦恼，也没有别的五阴。善男子，如柱子支撑房屋，离开房屋就没有柱子，离开柱子就没有房屋。众生的五阴也是这样，因为有烦恼，名为系缚；因为没有烦恼，名为解脱。

"善男子，如拳头、合掌、系缚这三者，合散生灭，更没有别的法。众生的五阴也是这样，因为有烦恼，名为系缚；因为没有烦恼，名为解脱。

"善男子，如说名色系缚众生，名色若灭，就没有众生；离开名色，就没有别的众生；离开众生，也没有别的名色。也名为名色系缚众生，也名为众生系缚名色。"

师子吼说："世尊，如眼睛不能看见自己，手指不能触碰自己，刀不能割自己，受不能领受自己，如来为什么说名色系缚名色？为什么呢？说名色就是众生，说众生就是名色；若说名色系缚众生，就是名色系缚名色。"

佛说："善男子，如两手相合时，更没有别的法来合；名与色也是这样。因为这个道理，我说名色系缚众生；若离开名色，就得解脱，所以我说众生解脱。"

### 阿罗汉的子断与果系

师子吼说："世尊，若有名色就是系缚，诸阿罗汉还未离开名色，也应当是系缚。"

"善男子，解脱有两种：一是子断，二是果断。所说的子断，名为断烦恼；阿罗汉等已断烦恼，众结烂坏，所以种子之结不能系缚。因为还未断果，名为果系缚。诸阿罗汉不见佛性，因为不见，所以不得无上正等正觉。因为这个道理，可以说是果系，不得说是名色系缚。

【按】"子"指烦恼之种因，"果"指烦恼所感的果报之身。阿罗汉已断烦恼之子，尚有余报之果。

"善男子，譬如点灯，油未尽时，光明就不灭；油若尽了，灭就无疑。善男子，所说的油，比喻诸烦恼；灯比喻众生。一切众生因为有烦恼之油，所以不入涅槃；若得断除，就入涅槃。"

### 八种譬喻

师子吼说："世尊，灯与油二者之性各异，众生与烦恼不是这样，众生就是烦恼，烦恼就是众生；众生名为五阴，五阴名为众生；五阴名为烦恼，烦恼名为五阴。如来为什么以灯来比喻？"

佛说："善男子，譬喻有八种：一是顺喻，二是逆喻，三是现喻，四是非喻，五是先喻，六是后喻，七是先后喻，八是遍喻。

#### 顺喻

"什么是顺喻？如经中说：天降大雨，沟渠都满；沟渠满了，小坑就满；小坑满了，大坑就满；大坑满了，小泉就满；小泉满了，大泉就满；大泉满了，小池就满；小池满了，大池就满；大池满了，小河就满；小河满了，大河就满；大河满了，大海就满。如来的法雨也是这样：众生的戒满了；戒满足了，不悔之心就满；不悔之心满了，欢喜就满；欢喜满了，远离就满；远离满了，安稳就满；安稳满了，三昧就满；三昧满了，正知见就满；正知见满了，厌离就满；厌离满了，呵责就满；呵责满了，解脱就满；解脱满了，涅槃就满。这名为顺喻。

#### 逆喻

"什么是逆喻？大海有其本，就是大河；大河有其本，就是小河；小河有其本，就是大池；大池有其本，就是小池；小池有其本，就是大泉；大泉有其本，就是小泉；小泉有其本，就是大坑；大坑有其本，就是小坑；小坑有其本，就是沟渠；沟渠有其本，就是大雨。涅槃有其本，就是解脱；解脱有其本，就是呵责；呵责有其本，就是厌离；厌离有其本，就是正知见；正知见有其本，就是三昧；三昧有其本，就是安稳；安稳有其本，就是远离；远离有其本，就是喜心；喜心有其本，就是不悔；不悔有其本，就是持戒；持戒有其本，就是法雨。这名为逆喻。

#### 现喻

"什么是现喻？如经中说：众生的心性犹如猕猴，猕猴的习性是舍一取一；众生的心性也是这样，取著色、声、香、味、触、法，没有片刻停住。这名为现喻。

#### 非喻

"什么是非喻？如我过去告诉波斯匿王：'大王，有亲信的人从四方来，各自这样说：大王，有四座大山从四方来，要伤害人民。大王若听到了，当设什么计策？'

"王说：'世尊，假设有这样的山来，没有逃避之处，只应当专心持戒、布施。'

"我就赞叹说：'善哉，大王！我说四山，就是众生的生、老、病、死。生、老、病、死常来逼迫人，大王为什么不修持戒、布施？'

"王说：'世尊，持戒布施得到什么果报？'

"我说：'大王，在人天之中多受快乐。'

"王说：'世尊，尼拘陀树若持戒布施，也在人天中受安乐吗？'

"我说：'大王，尼拘陀树不能持戒、修行布施，若能，所受的果报就没有不同。'这名为非喻。

【按】"非喻"，指以实际不存在之事（四山来逼、树能持戒）为喻。

#### 先喻、后喻、先后喻

"什么是先喻？我在经中说：譬如有人贪著美妙的花，采取时被水漂走；众生也是这样，贪著五欲，被生老死所漂没。这名为先喻。

"什么是后喻？如《法句经》说：

```
莫轻小恶
以为无殃
水渧虽微
渐盈大器
```

（大意：不要轻视小恶，以为不会招来祸殃；水滴虽然微小，渐渐也能盈满大器。）

"这名为后喻。

"什么是先后喻？譬如芭蕉，结果就死；愚人得到供养也是这样，如骡子怀孕，性命不久。

#### 遍喻：波利质多树

"什么是遍喻？如经中说：三十三天有波利质多树，其根入地深五由旬，高一百由旬，枝叶四面伸展五十由旬。叶子成熟就变黄，诸天见了，心生欢喜：'这叶子不久必当落下。'叶子落下之后，又生欢喜：'这枝条不久必当变色。'枝条变色之后，又生欢喜：'这颜色不久必当生出花苞。'见了又欢喜：'这花苞不久必当生出花嘴。'见了又欢喜：'这花嘴不久必当开放。'开放之时，香气周遍五十由旬，光明远照八十由旬。那时诸天在夏季三个月中，在树下受乐。

"善男子，我的诸弟子也是这样：叶子变黄，比喻我的弟子想要出家；叶子落下，比喻我的弟子剃除须发；颜色改变，比喻我的弟子以白四羯磨受具足戒；初生花苞，比喻我的弟子发无上正等正觉之心；花嘴，比喻十住菩萨得见佛性；开放，比喻菩萨得无上正等正觉；香气，比喻十方无量众生受持禁戒；光明，比喻如来的名号无碍，周遍十方；夏季三个月，比喻三三昧；三十三天受快乐，比喻诸佛在大涅槃中得常乐我净。这名为遍喻。

#### 取喻少分

"善男子，凡所引用的譬喻，不必全取，或取少分，或取多分，或全部取用。如说如来面如满月，这名为少分。

"善男子，譬如有人从未见过乳，转问他人：'乳是什么样的？'那人回答：'如水、蜜、贝。'水是湿相，蜜是甜相，贝是色相，虽然引了三种比喻，也还不是乳的实体。善男子，我说灯喻比喻众生，也是这样。

"善男子，离开水就没有河；众生也是这样，离开五阴，没有别的众生。善男子，如离开车厢、车舆、轮、辐、轴、辋，更没有别的车；众生也是这样。

#### 灯喻的合法

"善男子，若想合上那灯喻，仔细听，仔细听，我现在当说：灯炷比喻二十五有，油比喻爱，光明比喻智慧，除破黑暗比喻破除无明，温暖比喻圣道。如灯油尽了，明焰就灭；众生的爱尽了，就见佛性。虽有名色，不能系缚；虽然处在二十五有，不被诸有所污染。"

### 五阴空无，谁修道

师子吼说："世尊，众生的五阴空无所有，有谁受教修习道法？"

佛说："善男子，一切众生都有念心、慧心、发心、勤精进心、信心、定心。这样的诸法虽然念念生灭，仍然相似相续不断，所以名为修道。"

师子吼说："世尊，这样的诸法都念念灭，这念念灭也是相似相续，怎样修习？"

佛说："善男子，如灯虽然念念灭，而有光明除破黑暗；念等诸法也是这样。善男子，如众生的食物，虽然念念灭，也能令饥饿的人得以饱满。譬如上等药物，虽然念念灭，也能治愈疾病。日月的光明，虽然念念灭，也能增长树林草木。

"善男子，你说念念灭，怎能增长？因为心不断，所以名为增长。善男子，如人诵书，所诵的字句不能同时，前面的不到中间，中间的不到后面，人与文字以及心想都念念灭，因为长久修习，所以得以通利。善男子，譬如金匠，从初学手艺直到白头，虽然念念灭，前面的不到后面，因为积累熟习，所作的就越来越精妙，所以得称为好金匠。读诵经书也是这样。

"善男子，譬如种子，地也不教它'你应当生芽'，因为法性如此，芽就自然生出；乃至花也不教它'你应当结果'，因为法性如此，果就自然生出。众生修道也是这样。

"善男子，譬如计数，一不到二，二不到三，虽然念念灭，而能数到千万。众生修道也是这样。

"善男子，譬如灯念念灭，最初灭去的火焰并不教后来的火焰：'我灭了，你生起，应当破除黑暗。'

"善男子，譬如小牛，一出生就求乳，求乳的智慧，实在没有人教。虽然念念灭，而先饥后饱。所以应当知道不应是相似的；若是相似，就不应有不同的生起。众生修道也是这样，起初虽然未增长，因为长久修习，就能破坏一切烦恼。"

【按】"是故当知不应相似，若相似者不应异生"，意谓前后念并非全同；若全同，就不会有由饥至饱的变化。

### 须陀洹生于恶国

师子吼说："世尊，如佛所说，须陀洹人得果证之后，虽然生在恶国，仍然持戒，不杀、盗、淫、两舌、饮酒。须陀洹的五阴就在此处灭了，并不到恶国去；修道也是这样，不到恶国去。若是相似的，为什么不生在清净美妙的国土？若恶国中的五阴不是须陀洹的五阴，怎能不作恶业？"

佛说："善男子，须陀洹虽然生在恶国，终不失去须陀洹之名；五阴不是相似的，所以我引小牛为喻。须陀洹人虽然生在恶国，因为道力，不作恶业。

"善男子，譬如香山有狮子王，所以一切飞鸟走兽都绝迹于这山，没有敢接近的；有时这狮子王到雪山中去了，一切鸟兽仍然不敢住在那里。须陀洹人也是这样，虽然不修道，因为道力，不作诸恶。

"善男子，譬如有人服食甘露，甘露虽然消失了，以其力势，能令此人不生不死。

"善男子，如须弥山有上妙的药，名叫楞伽利，有人服用，虽然念念灭，因为药力，不遇病苦。

"善男子，如转轮王所坐之处，国王虽然不在，也没有人敢接近。为什么呢？因为国王的威力。须陀洹人也是这样，虽然生在恶国，不修习道，因为道力，不作恶业。

"善男子，须陀洹的五阴在此处灭了，虽然生出别的五阴，仍然不失须陀洹的五阴。

"善男子，譬如众生为了果实，对种子多加劳作，施肥灌溉，还未得到果实，种子就已灭了，也得名为因种子而得果实。须陀洹的五阴也是这样。

"善男子，譬如有人资产巨富，只有一个儿子，先已去世；他的儿子有一个儿子，又在他乡。这人忽然去世，孙子听说了，就回来收取产业；虽然知道这些财物不是自己所作，然而收取时没有人阻拦。为什么呢？因为同一姓氏。须陀洹的五阴也是这样。"

### 修戒、修定、修慧

师子吼说："如佛说偈：

```
比丘若修习
戒定及智慧
当知是不退
亲近大涅槃
```

（大意：比丘若能修习戒、定、智慧，应当知道此人不退转，接近大涅槃。）

"世尊，怎样修戒？怎样修定？怎样修慧？"

#### 第一说

佛说："善男子，若有人受持禁戒，只为自利，为人天受乐，不为度脱一切众生，不为护持无上正法，只为利养，畏惧三恶道，为了寿命、容色、气力、安乐、无碍辩才，畏惧王法、恶名、丑声，为了世间事业，这样护戒，就不得名为修习戒。

"善男子，什么名为真正修习戒？受持戒时，若是为了度脱一切众生，为了护持正法，为了度未度的人，为了令未解的人得解，为了令无归依的人得归依，为了令未入涅槃的人得入。这样修时，不见戒，不见戒相，不见持戒者，不见果报，不观毁犯。善男子，若能这样，就名为修习戒。

"又什么名为修习三昧？修三昧时，若为了自己度脱，为了利养，不为众生，不为护法；为了见到贪欲、秽食等过患，男女等根、九孔不净，斗讼打刺，互相杀害；若为了这些事修三昧，就不名为修习三昧。

"善男子，又什么名为真正修三昧？若为了众生修习三昧，在众生中得平等心；为了令众生得不退之法，为了令众生得圣心，为了令众生得大乘，为了护持无上之法，为了令众生不退菩提，为了令众生得首楞严，为了令众生得金刚三昧，为了令众生得陀罗尼，为了令众生得四无碍，为了令众生见佛性。作这样的修行时，不见三昧，不见三昧之相，不见修者，不见果报。善男子，若能这样，就名为修习三昧。

"又什么名为修习智慧？若修习的人这样思惟：'我若修习这样的智慧，就能得解脱，度过三恶道，谁能利益一切众生？谁能度人出离生死之道？佛出世难，如优昙花；我现在能断诸烦恼结，必得解脱。所以我应当勤修智慧，迅速断除烦恼，早得度脱。'这样修习的，不得名为修习智慧。

"什么名为修习智慧？若观察生老死之苦，一切众生被无明所覆，不知修习无上正道，就发愿：'愿我这身代一切众生受大苦恼；众生所有的贫穷、下贱、破戒之心、贪瞋痴业，愿都来集于我身。愿众生不生贪取，不被名色所系缚。愿众生早日度脱生死，令我一身处在其中而不厌倦。愿令一切众生都得无上正等正觉。'这样修时，不见智慧，不见智慧之相，不见修者，不见果报，这就名为修习智慧。

"善男子，修习这样的戒、定、智慧，名为菩萨；不能这样修戒、定、慧，名为声闻。

#### 第二说：断十六恶律仪、世间三昧、诸恶见

"再者，善男子，又什么名为修习戒？若能破除一切众生的十六种恶律仪。哪十六种？一是为了利益饲养羔羊，养肥之后转卖；二是为了利益买来屠杀；三是为了利益饲养猪豚，养肥之后转卖；四是为了利益买来屠杀；五是为了利益饲养牛犊，养肥之后转卖；六是为了利益买来屠杀；七是为了利益养鸡令肥，养肥之后转卖；八是为了利益买来屠杀；九是钓鱼；十是猎人；十一是劫夺；十二是刽子手；十三是张网捕捉飞鸟；十四是两舌；十五是狱卒；十六是咒龙。能为众生永断这样的十六种恶业，这名为修戒。

"怎样修定？能断一切世间的三昧，即无身三昧，能令众生生起颠倒之心，以为这是涅槃；又如无边心三昧、净聚三昧、世边三昧、世断三昧、世性三昧、世丈夫三昧、非想非非想三昧，这样的定能令众生生起颠倒之心，以为这是涅槃。若能永断这样的三昧，这就名为修习三昧。

【按】以上诸三昧，是外道以为涅槃的种种禅定，名称多与外道诸说（如世性即数论自性、世丈夫即神我）相关。

"又什么名为修习智慧？能破除世间所有的恶见。一切众生都有恶见，即：色就是我，也是我所；色中有我，我中有色，乃至识也是这样；常就是我，色灭而我存在；色就是我，色灭我就灭。又有人说：作者名为我，受者名为色。又有人说：作者名为色，受者名为我。又有人说：无作无受，自生自灭，都不是因缘。又有人说：无作无受，都是自在天所造作。又有人说：没有作者，没有受者，一切都是时节所作。又有人说：作者、受者都无所有，地等五大名为众生。善男子，若能破除一切众生这样的恶见，这就名为修习智慧。

#### 戒定慧的次第

"善男子，修习戒是为了身寂静，修习三昧是为了心寂静，修习智慧是为了破除疑心。破除疑心是为了修道，修道是为了见佛性，见佛性是为了得无上正等正觉，得无上正等正觉是为了得无上大涅槃，得大涅槃是为了断除众生的一切生死、一切烦恼、一切诸有、一切诸界、一切诸谛；断除生死乃至断除诸谛，是为了得常乐我净之法。"

【按】"断……一切诸谛"，原文如此，存疑。

### 生死亦不生不灭，何不名涅槃

师子吼说："世尊，如佛所说，若不生不灭，名为大涅槃。生也是这样，不生不灭，为什么不得名为涅槃？"

"善男子，是这样，是这样，如你所说，这生虽然不生不灭，却有始终。"

"世尊，这生死之法也没有始终；若没有始终，就名为常；常就是涅槃，为什么不称生死为涅槃？"

"善男子，这生死之法都有因果；因为有因果，所以不得名之为涅槃。为什么呢？涅槃之体没有因果。"

师子吼说："世尊，涅槃也有因果。如佛所说：

```
从因故生天
从因堕恶道
从因故涅槃
是故皆有因
```

（大意：因为有因，所以生天；因为有因，堕入恶道；因为有因，所以涅槃；所以都有其因。）

"如佛往昔告诉诸比丘：'我现在当说沙门、道、果。所谓沙门，是能具足修习戒、定、智慧；道，是八圣道；沙门果，就是涅槃。'世尊，涅槃这样，岂不是果吗？为什么说涅槃之体无因无果？"

佛说："善男子，我所宣说的涅槃之因，就是佛性；佛性之性不生涅槃，所以我说涅槃无因。能破烦恼，所以名为大果；不从道而生，所以名为无果。所以涅槃无因无果。"

### 佛性共有还是各有

师子吼说："世尊，众生的佛性，是共同所有，还是各自所有？若是共有，一人得无上正等正觉时，一切众生也应当同时得到。世尊，如二十人同有一个怨敌，若一人能除掉他，其余十九人也同时除掉了。佛性若是这样，一人得到时，其余的人也应当得到。若是各自所有，就是无常。为什么呢？因为可以计数。然而佛说众生的佛性不一不二；若是各自所有，就不应说诸佛平等，也不应说佛性如虚空。"

佛说："善男子，众生的佛性不一不二，诸佛平等，犹如虚空，一切众生共同有之。若有能修八圣道的人，应当知道此人就能明见。善男子，雪山有草，名叫忍辱，牛若吃了，就成醍醐；众生的佛性也是这样。"

师子吼说："如佛所说，忍辱草是一株还是多株？若是一株，牛吃了就尽了；若是多株，怎么说众生的佛性也是这样？如佛所说，若有修习八圣道的，就见佛性，这意义是不对的。为什么呢？道若是一，如忍辱草就应当有尽；若有尽，一人修了，其余的人就没有份了。道若是多，怎能说具足修习？也不得名为一切智。"

#### 道路树荫诸喻

佛说："善男子，如平坦的道路，一切众生都在其中行走，没有障碍；路中有一棵树，树荫清凉，行人在树下停车休息，然而那树荫常住不移，也不消坏，没有人能拿走。道路比喻圣道，树荫比喻佛性。

"善男子，譬如一座大城只有一个门，虽有很多人经由出入，都没有人能作障碍，也没有人能破坏毁落而拿走。

"善男子，譬如桥梁，行人所经，也没有人遮止障碍、毁坏拿走。

"善男子，譬如良医遍治众病，也没有人能阻止这医生只治这人而舍弃那人。圣道与佛性也是这样。"

师子吼说："世尊，所引的诸喻，意义不是这样。为什么呢？先走在路上的，对后来的就有妨碍，怎能说没有障碍？其余的比喻也都是这样。圣道与佛性若是这样，一人修习时应当妨碍其余的人。"

佛说："善男子，你所说的意义不相应。我所比喻的道，是少分之喻，不是全部。善男子，世间之道就有障碍，有此彼的差异，没有平等；无漏之道不是这样，能令众生没有障碍，平等无二，没有方所此彼的差异。这样的正道能为一切众生的佛性作了因，不作生因，犹如明灯照了事物。

"善男子，一切众生都同样以无明为因缘而有行，不可说一人以无明为因缘有了行之后，其余的人就应当没有。一切众生都有无明为因缘而有行，所以说十二因缘一切平等。众生所修的无漏正道也是这样，平等地断除众生的烦恼、四生、诸界、诸有之道。因为这个道理，名为平等。证得的人，彼此知见，没有障碍，所以得名为一切智。"

#### 毒乳之喻

师子吼说："一切众生的身体不是一种，或有天身，或有人身、畜生、饿鬼、地狱之身，这样多种身体差别不一，怎能说佛性是一？"

佛说："善男子，譬如有人把毒药放在乳中，乃至醍醐都有毒。乳不名为酪，酪不名为乳，乃至醍醐也是这样；名字虽然改变，毒性不失，遍于五味中都是这样。若服醍醐，也能杀人，其实并没有把毒药放在醍醐中。众生的佛性也是这样，虽然处在五道，受不同的身体，而这佛性常一不变。"

### 何故于拘尸那城入涅槃

师子吼说："世尊，十六大国中有六大城，即舍婆提城、婆枳多城、瞻婆城、毗舍离城、波罗奈城、王舍城，这六城是世间最大的。如来为什么舍弃它们，在这偏远之地、简陋狭小的拘尸那城入般涅槃？"

【按】原文"波罗?城"缺一字，即波罗奈城。

"善男子，你不应说拘尸那城是偏远之地、简陋狭小，应当说这城是由微妙功德所庄严的。为什么呢？因为是诸佛菩萨所行之处。

"善男子，如贫贱之人的房舍，国王若经过，就应当赞叹：这房舍庄严华丽，福德成就，才令大王掉转车驾前来光顾。善男子，如人患重病，服用粗劣的药，服后病愈，就应当欢喜赞叹：这药最上最妙，能治愈我的病。善男子，如人乘船在大海中，船忽然破了，无所依靠，因为抱着一具死尸，得以到达彼岸；到了彼岸之后，应当大为欢喜，赞叹这死尸：我幸亏遇到它，才得安稳。拘尸那城也是这样，是诸佛菩萨所行之处，怎能说是偏远之地、简陋狭小的城？

#### 善觉劫憍尸迦王

"善男子，我回忆往昔，经过恒河沙劫，劫名善觉。那时有一位圣王，姓憍尸迦，七宝成就，千子具足。那王最初建立这城，周围纵广十二由旬，以七宝庄严。那国土多有河流，其水清净、柔软、甘美，即尼连禅河、伊罗跋提河、熙连禅河、伊搜末堆河、毗婆舍那河，这样的河流有五百条。河的彼岸树木繁茂，花果鲜洁。那时人民寿命无量。

"那时转轮圣王过了一百年之后，这样宣告：'如佛所说，一切诸法都是无常，若能修习十善之法，就能断除这样的无常大苦。'人民听了，都共同奉修十善之法。我那时听到佛的名号，受持十善，思惟修习，初发无上正等正觉之心。发了这心之后，又以这法转教无量无边众生说：一切法无常变坏。所以我现在继续在这里，也说诸法无常变坏，唯说佛身是常住之法。我回忆往昔所行的因缘，所以现在来到这里涅槃，也想报答这地方往昔的恩德。因为这个道理，我在经中说：我的眷属受恩能报。

#### 善见王修四无量

"再者，善男子，往昔众生寿命无量时，那时这城名叫拘舍跋提，周围纵广五十由旬。那时阎浮提居民邻接，鸡飞可及。有一位转轮王名叫善见，七宝成就，千子具足，统领四天下。他的第一太子思惟正法，得辟支佛。当时转轮王见他的太子成为辟支佛，威仪安详，神通稀有，见了这件事，就舍弃王位，如弃涕唾，出家在这娑罗树间，八万年中修习慈心，悲、喜、舍心也各八万年。善男子，要知道那时的善见圣王，就是我身。所以我现在常乐游止于这四法。这四法名为三昧。因为这个道理，如来之身常乐我净。善男子，因为这个因缘，现在来到这拘尸那城娑罗树间，入三昧正受。

#### 过去迦毗罗卫悉达多佛

"善男子，我回忆往昔，经过无量劫，这城那时名叫迦毗罗卫，城中有国王名叫白净，王的夫人名叫摩耶，王有一个儿子名叫悉达多。那时王子不由老师教导，自然思惟，得无上正等正觉，有两位弟子，一名舍利弗，二名大目犍连，给侍弟子名叫阿难。那时世尊在双树间演说这样的《大涅槃经》，我当时在会中，得以参与这件事，听到众生都有佛性，听了这件事，就对菩提得不退转，随即自己发愿：'愿未来世成佛之时，父母、国土、名字、弟子、侍者、说法教化，都如今天的世尊一样，没有不同。'因为这个因缘，现在来到这里敷扬演说《大涅槃经》。

### 初成道后的教化

"善男子，我初出家、还未得无上正等正觉时，频婆娑罗王派使者来说：'悉达太子，若作圣王，我当作你的臣属；若不乐在家，得无上正等正觉，愿先来到这王舍城，说法度人，接受我的供养。'我当时默然，已接受了他的邀请。

#### 度三迦叶

"善男子，我初得无上正等正觉之后，前往竭阇国。那时伊连禅河边有一位婆罗门，姓迦叶，与五百弟子在那河边求无上道。我为了此人，前往为他说法。

"迦叶说：'瞿昙，我现在年迈，已经一百二十岁，摩伽陀国所有的人民以及他们的大王频婆娑罗，都以为我已证得阿罗汉果。我现在若在你面前听受法教，一切人民或许会生起颠倒之心：大德迦叶不是阿罗汉吗？希望瞿昙速往别处。若这里的人民确知瞿昙的功德胜过我，我们就无从再得到供养了。'

"我当时回答：'迦叶，你若对我不生深重的大瞋恨，请容我住一宿，明天一早就走。'

"迦叶说：'瞿昙，我心中没有别的，对你深相爱重，只是我的住处有一条毒龙，其性暴急，恐怕会伤害你。'

"我说：'迦叶，毒中之毒，不过三毒，我现在已经断了，世间之毒，我不畏惧。'

"迦叶又说：'若真能不畏惧，善哉，请住下。'

"善男子，我那时特意为迦叶示现十八种变化，如经中所说。那时迦叶及其眷属五百人，见闻这些之后，证得阿罗汉果。这时迦叶又有两个弟弟，一名伽耶迦叶，二名那提迦叶，师徒眷属又有五百人，也都证得阿罗汉果。

#### 应频婆娑罗王请

"那时王舍城的六师之徒听到这件事，就对我生起大恶心。我当时如约应那国王之请，前往王舍城，还未到半路，国王与无量百千之众都来奉迎。我为他们说法，当时听了法，欲界诸天八万六千人发无上正等正觉之心，频婆娑罗王所带领的随从十二万人得须陀洹果，无量众生成就忍心。进城之后，度化舍利弗、大目犍连及其眷属二百五十人，令他们舍弃本来的见解，出家学道。我就住在那里，接受国王的供养。外道六师互相聚集，前往舍卫城。

### 须达长者与祇园精舍

"那时那城中有一位长者，名叫须达多，为了给儿子娶媳妇，来到王舍城，到了那城之后，寄住在长者珊檀那家。当时这长者半夜起来，告诉诸眷属：'你们可以起来，赶快一起庄严、洒扫宅舍，备办饮食佳肴。'

"须达听了，随即自己思惟：'莫非是要请摩伽陀王？还是有婚姻欢乐的聚会？'思惟之后，就上前问：'大士，是要请摩伽陀王频婆娑罗吗？还是有婚姻欢乐的聚会？为什么匆忙不安到这样？'

"长者回答：'不是的，居士。我明天请佛，无上的法王。'

"须达长者初次听到佛的名字，全身汗毛都竖了起来，随即又问：'什么名为佛？'

"长者回答：'你没听说吗？迦毗罗城有一位释种之子，名叫悉达多，姓瞿昙，父亲名叫白净。他出生不久，相师为他占相，说他必定当作转轮圣王，如庵罗果已在手中。他心中不愿乐，舍弃王位出家，无师自觉，得无上正等正觉，贪、恚、痴已尽，常住不变，不生不灭，没有忧畏；对一切众生其心平等，犹如父母平等看待独子；所有的身心在众中最为殊胜，虽然胜过一切，却没有憍慢；涂香与割截二事，其心无二；智慧通达，对诸法无碍；具足十力、四无所畏、五智三昧、大慈大悲以及三念处，所以号为佛。明天接受我的邀请，所以匆忙，没有空闲招呼你。'

"须达多说：'善哉，大士！你所说的佛，功德无上，现在在什么地方？'

"长者回答：'现在就在这王舍大城，住在迦兰陀竹林精舍。'

"那时须达多一心念佛所有的功德，即十力、无畏、五智三昧、大慈大悲以及三念处。作这样的念时，忽然大放光明，其光明猛盛犹如白日。他就随着光明出来，到了城门下，因为佛的神力，城门自然打开了。出了城门，路上有一座天祠，须达经过时礼拜致敬，随即又变得黑暗，心中惶怖，又想返回所住之处。

"那时那城门有一位天神，告诉须达：'仁者，若前往如来所，能获得很多善利。'

"须达多说：'什么善利？'

"天神说：'长者，假使有人以真宝交结的璎珞、骏马一百匹、香象一百头、宝车一百乘、用金子铸成的人像也是一百个，端正女人身佩璎珞、以众宝装饰，上妙的宫宅殿堂屋宇，雕文刻镂，金盘盛银粟、银盘盛金粟，数目各一百，用来布施一人，这样辗转布施遍阎浮提所得的功德，不如有人发意走一步前往如来所。'

"须达多说：'善男子，你是谁？'

"天神说：'长者，我是胜相婆罗门之子，是你往昔的善知识。我因为往日见到舍利弗、大目犍连，心生欢喜，舍身之后得作北方天王毗沙门之子，专门守护这王舍城。我因为礼拜舍利弗等生欢喜心，尚且得到这样美妙的身体，何况能见到如来大师，礼拜供养？'

"须达长者听了这件事，就重新上路，来到我这里，到了之后，头面敬礼我的双足。我当时就为他应机说法，长者听了，得须陀洹果。获得果证之后，又请我说：'如来大慈，唯愿光临舍卫城，接受我微薄的供养。'

"我就问：'你在舍卫城可有精舍能够容纳吗？'

"须达多说：'若佛哀悯，必定垂顾，我就当竭尽所能营办建立。'

"善男子，我那时默然接受了邀请。须达长者已蒙听许，就对我说：'我从来没有做过这样的事，唯愿如来派舍利弗来指授仪则。'我就嘱咐舍利弗前去协助经营。

"当时舍利弗与须达多同乘一车前往舍卫城，因为我的神力，经过一日一夜就到了住处。

"那时须达多对舍利弗说：'大德，这大城外，什么地方有不近不远、多有泉池、有好树林、花果茂盛、清净闲旷的土地？我当在其中为佛世尊以及比丘僧建立精舍。'

"舍利弗说：'祇陀的园林，不近不远，清净寂静，多有泉流，树木花果随时而有，这里最好，可以建立精舍。'

"那时须达多听了这话，就前往祇陀大长者那里，告诉祇陀：'我现在想为无上法王建立僧坊，唯有你的园地可以建立，我现在想买，能卖给我吗？'

"祇陀回答：'即使用真金遍铺这块地，也不卖给你。'

"须达多说：'善哉，祇陀！林地归我了，你就收金子吧。'

"祇陀回答：'我的园子不卖，怎么收金子？'

"须达多说：'你若不明白，我们一起到断事的人那里去。'

"当时两位长者就一同前往，断事的人说：'园子归须达，祇陀收金子。'

"须达长者当即派人用车马运载金子，随时聚集铺地，一天之中只铺了五百步，金子还未铺遍。祇陀说：'长者若后悔，随你停止。'

"须达多说：'我不后悔。'自己想着该从哪个库藏取出金子来补足。

"祇陀心想：'如来法王真实无上，所说的妙法清净无染，所以令这人这样轻视宝物。'就对须达说：'其余未铺遍的，不再需要金子，请送给我，我自己为佛建造门楼，常让如来经由出入。'

"祇陀长者自己建造门坊，须达长者七日之中建成大房三百间，禅坊静处六十三所，冬屋夏堂各自不同，厨房、浴室、洗脚之处、大小厕所，无不齐备。所设已经完毕，就拿着香炉，向王舍城遥遥说道：'所设已经办好，唯愿如来慈哀怜悯，为了众生，接受这住处。'

"我当时远远知道这长者的心意，就与大众从王舍城出发，譬如壮士屈伸手臂的一瞬间，就到了舍卫城祇陀园林须达精舍。到了之后，须达长者把他所建造的奉施给我，我当时接受了，就住在其中。

大般涅槃经卷第二十七

【按】本卷相当于北本卷第二十九（师子吼菩萨品第十一之三）全卷。
