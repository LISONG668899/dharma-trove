# 《大宝积经》卷第九十六（勤授长者会）

唐·三藏法师菩提流志 奉诏译

## 勤授长者会第二十八

【按】卷题“第”字，圣本无；译者题名“法师”二字，圣本无；“诏”，圣本作“诰”。本会异译有西晋白法祖译《佛说菩萨修行经》（T0330），一名《威施长者问观身行经》。

#### 序分

如是我闻：一时，佛在舍卫国祇树给孤独园，与大比丘众一千二百五十人在一起，都是阿罗汉，诸漏已尽，不再有烦恼，得上等调伏，犹如大龙，所作已办，弃舍重担，获得自利，尽除诸有的结缚。以正智解脱，心得自在，是最上的应供者，为众人所知识。只有阿难还在学地。他们的名字是：阿若憍陈如、摩诃迦叶、摩诃迦旃延、摩诃阿湿波、舍利弗、大目乾连、摩诃劫宾那、摩诃拘絺罗、摩诃梵颇、罗睺罗、难陀，像这样等为上首。又有菩萨摩诃萨五百人在一起，都得三昧以及陀罗尼。

#### 勇猛授长者与五百长者议发心

那时舍卫大城有一位长者，名为勇猛授，富有财宝，仓库满溢，金、银、琉璃、砗磲、玛瑙、珊瑚、琥珀、摩尼、真珠、象、马、牛、羊、奴婢仆使、商贾之类，一切众多。当时勇猛授与五百位长者游宴聚会，这样商议说：“诸仁者！佛出世难，人身难得，时机也难遇，在佛法中以信心出家这件事也难，成就比丘之性也甚难，如法修行也难，知恩报恩、受少恩而不忘的人难得，能对佛法生起信乐之心的人难得，信乐得以成就这件事又难，庄严佛法这件事也难，解脱生死更加难。我们是以声闻、辟支佛乘而求灭度，还是发趣最上的佛乘？”大家都说：“我们宁可于无上佛道而趣向涅槃。”

【按】“车𤦲”之“𤦲”字先前电子文本未能显示，今据CBETA补出，即砗磲。

这样商议之后，大家前后围绕，出舍卫城，前往祇陀林，来到如来之所，顶礼佛足，右绕三匝，退坐一面。那时世尊明知而故问，告诉长者们说：“你们因为什么缘故现在来我这里？”当时勇猛授与五百位长者从座而起，偏袒右肩，右膝著地，合掌向佛说：“世尊！我们诸人同时集会，这样商议说：‘佛世难遇，人身难得，乃至解脱生死更加难。我们是以声闻、辟支佛乘而求灭度，还是发趣最上的佛乘？’大家都这样说：‘我们宁可于无上佛道而趣向涅槃。’由于这一商议，现在来到如来、应、正等觉之所。世尊！菩萨摩诃萨志求阿耨多罗三藐三菩提，应当怎样学？应当怎样住？怎样修行？”

#### 佛说起大悲而不著身命财

佛说：“善哉善哉！你们发趣阿耨多罗三藐三菩提，来到我这里。应当谛听，好好思念。诸菩萨应当怎样学、应当怎样住、应当怎样修行，当为你们宣说。”当时诸长者受教而听。佛告诉长者们：“菩萨摩诃萨对阿耨多罗三藐三菩提有殊胜志乐的，应当对一切众生生起大悲之心，应当广为修行，应当勤加熏习。所以菩萨对身、命、财以及妻子、仓库、舍宅、饮食、衣服、车乘、卧具、花鬘、涂香、一切乐具，应当无所执著。为什么呢？因为众生执著于身而生恶业，由于恶业而堕入地狱之中。若对众生生起大悲之心，对身、命、财便不执著，便生于善趣。

“所以菩萨摩诃萨对阿耨多罗三藐三菩提有殊胜志乐的，对众生生起慈悲之后，应当修大舍而不求回报；不求回报的人应当住于戒律；三戒清净之后应当具足忍辱；能忍受诸恶之后应当发起精进，不惜身命；应当修习一心，安住于禅定；应当修习智慧与善巧方便；应当对我、人、众生、寿命都舍离。为了众生，应当行布施、护持净戒。为了众生，应当修忍辱、发起精进。为了众生，应当入于禅定，修习智慧与善巧方便。”

#### 观身过患

当时诸长者又对佛说：“世尊！我们对自身以及妻子、一切财宝资生之具，心中常常爱惜。世尊！菩萨摩诃萨怎样观察，才能对身、命、财没有贪吝？”

【按】“身命财”之“财”，明本作“不”。

那时世尊告诉长者们说：“善男子！菩萨摩诃萨对阿耨多罗三藐三菩提有殊胜志乐的，应当观察这身体有无量的过患：由微尘积集而成，有生、住、异、灭，念念迁流，有九个漏出不净的疮门，犹如毒蛇所住的窟穴；其中没有主宰，如空无一人的聚落；毕竟破坏，如坏了的瓦瓶；恶露满溢，犹如污秽之器；容受种种不净，犹如厕所；不可触动，犹如恶疮；贪著美味而成祸患，如掺了毒的食物；不识恩德，如未生怨；欺误于人，如恶知识；以痴爱为害，如以猕猴为友；断绝智慧之命，犹如杀人者；夺取种种善法，犹如劫贼；常伺求人的便利，犹如怨仇；没有慈心，犹如刽子手；难以承事，如暴恶之人；如箭射在身上，一触便痛；如朽腐的房舍，常须修治；如老弱的车乘，难以驱策；如装毒蛇的箱子，不可靠近；如旅舍，是疲苦所集之处；如孤独的屋舍，无所摄属；如狱卒伺机加害；如国王忧虑国事；如边城警戒畏惧；如恶国多有灾难；如破器难以持守；如祭祀之火没有厌足；如阳焰虚诳不实；如幻化迷惑于人；如剖开的芭蕉，其中没有坚实；如水上的聚沫，不可执持；如水上的泡，迅速生起迅速消灭；如河岸边的树，临于危险而动摇；如湍急的河流，终归于死亡之海。”

【按】“逆旅馆”之“逆”，宋本作“𨒫”。“如狱卒伺害”之“伺”，宋、元、明、宫本、圣本作“司”。“驶河流”之“驶”，宋、元、宫本作“駚”。

#### 观身前后因缘与身之结构

又告诉长者们：“再观察这身体的前后因缘：最初从欲爱和合而生，为了长养而吞咽段食，到了生藏，被痰阴消化。接着到了黄藏，将要成熟时，便变为酸。接着到了风藏，风把汁与滓分开，各自分别流行，成为大小便，汁变为血，血变为肉，肉处生脂，脂处成骨，骨中生髓，这样身体的因缘前后都不清净。

【按】“抟食”之“抟”，《大正藏》作“搏”，今依CBETA作“抟”；抟食即段食。“痰阴”之“阴”，元、明本作“荫”。“脂、脂”，宫本作“指指”。

“若诸菩萨作这样的观察时，又应当思惟：这身体由三百六十块骨头聚集而成，如朽坏的房舍。诸关节互相支持，以四条细脉周匝弥布，五百分肉犹如泥涂，六脉相系，五百条筋缠缚，七百条细脉作为编络，十六条粗脉钩带相连，有两条肉绳，长三寻半，在内缠结，十六条肠胃环绕生藏与熟藏，二十五条气脉犹如窗隙，一百零七处关穴如破碎之器，八万个毛孔如乱草覆盖，五根七窍充满不净，七重皮包裹，以六味长养，犹如祭祀之火，吞受而没有厌足。这样的身体，一切都臭秽，自性溃烂，谁会对它爱重憍慢？只应当观察它如借来的器物，犹如车子运载，只是为了养育它，以达到菩提。”

【按】“四细脉”之“细”，宋、元、明、宫本作“网”。“溃烂”之“溃”，宋、元、明、宫本作“殨”。

那时世尊说偈道：

```
是身众秽器，犹如贮粪瓶，
凡夫无智慧，恃色生憍慢。
鼻中洟恒流，口气常臭秽，
眼眵虫遍身，谁当生净想？
如人执持炭，磨莹欲令白，
假使至尽时，体色终无变。
设欲净其身，倾河以自洗，
身尽莫能净，其事亦如是。
```
（大意：这身体是众多污秽之器，犹如装粪的瓶子，凡夫没有智慧，依恃色身而生憍慢。鼻中涕常流，口气常臭秽，眼有眵，虫遍满身体，谁会对它生起清净之想？如人拿着木炭，磨擦想令它变白，即使磨到穷尽之时，体色终究不变。假设想令身体清净，倾倒河水来洗自己，身体洗尽也不能清净，这事也是这样。）

【按】“磨莹”之“莹”，宋、元、明、宫本作“鎣”。

#### 观身四十四种

那时世尊说了这偈之后，又告诉五百位长者说：“若诸菩萨发起殊胜志乐，趣向阿耨多罗三藐三菩提，应当以四十四种观察这身体。哪四十四种？一是这身体可厌，因为其性无和合；二是这身体臭秽，因为脓血常流；三是这身体不坚，因为毕竟败坏；四是这身体羸弱，因为靠肢节互相支持；五是这身体不净，因为秽恶流溢；六是这身体如幻，因为诳惑凡愚；七是这身体是疮门，因为九处常流；八是这身体火燃，因为欲火炽盛；九是这身体为火，因为瞋火猛烈；十是这身体遍燃，因为痴火遍布；十一是这身体盲冥，因为有贪、瞋、痴；十二是这身体堕于网中，因为被爱网覆盖；十三是这身体是疮聚，因为疮遍满；十四是这身体不安，因为有四百四种病；十五是这身体是诸虫的住处，因为有八万户虫；十六是这身体无常，因为毕竟归于死；十七是这身体顽痴，因为对法无知；十八是这身体犹如瓦器，因为有生、住、坏；十九是这身体受逼迫，因为多有忧恼；二十是这身体没有救护，因为必定坏灭；二十一是这身体险恶，因为谄诳难知；二十二是这身体如无底之坑，因为诸欲难满；二十三是这身体如火受薪，因为贪色无厌；二十四是这身体无厌足，因为贪受五欲；二十五是这身体如被捶打，因为随时受损害；二十六是这身体不定，因为有盛衰增减；二十七是这身体随心流转，因为不正思惟；二十八是这身体不知恩，因为必被弃于冢间；二十九是这身体为他物所食，因为被狐狼所噉；三十是这身体如机关，因为筋骨互相支持；三十一是这身体不可观，因为有脓血粪秽；三十二是这身体不自由，因为依饮食而生；三十三是这身体被虚妄缠裹，因为终将败坏；三十四是这身体是恶友，因为多所违逆损害；三十五是这身体是杀者，因为自我残害；三十六是这身体是苦器，因为被苦所逼；三十七是这身体是苦聚，因为由五蕴而生；三十八是这身体无主，因为由众缘而生；三十九是这身体无命者，因为远离男女之相；四十是这身体是空，因为应当观察蕴、界、处；四十一是这身体虚妄，因为如在梦中；四十二是这身体不实，因为如幻化；四十三是这身体是幻惑，因为如阳焰；四十四是这身体是欺诳，因为如影像。这就是四十四种。

“菩萨作这样的观察时，对所有的身命爱欲执著，妻子、舍宅、饮食、衣服、车乘、香鬘、一切乐具，都厌离而无所顾恋，迅速能成就六波罗蜜，迅速得阿耨多罗三藐三菩提。”那时世尊说偈道：

```
善得人身甚为难，
莫为此身造众恶，
毕竟冢间餧狐狼，
勿为恶见生贪爱。
凡愚迷惑痴狂故，
由爱此身造诸业，
此身亦复不知恩，
昼夜唯增众苦缘。
机关动转常疲困，
洟唾便利恒充满，
饥渴寒热相煎迫，
何有智者爱此身？
此身无厌如大坑，
徒能长养众怨害，
由此身故常作恶，
于无量劫受诸苦。
```
（大意：能得人身甚为难得，不要为这身体造种种恶；它毕竟会在冢间喂养狐狼，不要因恶见而对它生起贪爱。凡愚因为迷惑痴狂，由于爱这身体而造种种业；这身体也不知恩，昼夜只增长种种苦缘。如机关般动转，常常疲困，涕唾大小便恒常充满，饥渴寒热交相煎迫，哪有智者会爱这身体？这身体无有厌足，如同大坑，只能长养种种怨害；由于这身体常常作恶，在无量劫中受种种苦。）

【按】“洟唾”之“洟”，宫本、圣本作“涕”。

```
应念定死修胜福，
正信生于佛法中，
饮食衣服及涂香，
长养此身来已久。
谁能执持令不坏，
应知无益勿耽迷，
牟尼世尊难可遇，
无量劫中时出现。
当于佛法生净信。
恶道可畏勿随行，
设令寿命千亿岁，
犹惧无常生厌离，
何况须臾不可保，
为彼沈沦恶趣中？
```
（大意：应当念死必定到来而修殊胜之福，以正信生于佛法之中；饮食、衣服以及涂香，长养这身体已经很久了。谁能执持它令其不坏？应当知道无益，不要耽迷；牟尼世尊难以值遇，在无量劫中才时而出现。应当对佛法生起净信，恶道可畏，不要随行；假使寿命千亿年，尚且畏惧无常而生厌离，何况须臾之命不可保，怎能为这身体沉沦于恶趣之中？）

```
或有恶友来相劝，
人身难得今已得，
多求财宝受娱乐，
及此盛年恣嬉游。
何有求财而乐者？
设得守护犹勤苦。
如此愚人徒妄言，
是故智者应观察。
财物如幻亦如梦，
愚痴众生被诳惑，
刹那时得刹那失，
何有智者生爱心？
譬如幻师幻化事，
乾闼婆城种种色，
财宝如是诳凡愚，
于虚妄中何有实？
```
（大意：或有恶友来相劝说：“人身难得，现在已经得到，应多求财宝，享受娱乐，趁这盛年恣意嬉游。”哪有求财而得快乐的？即使得到了，守护它也还勤苦。这样的愚人只是妄言，所以智者应当观察。财物如幻也如梦，愚痴的众生被它诳惑，刹那之间得到，刹那之间失去，哪有智者会生爱心？譬如幻师所幻化之事，乾闼婆城的种种颜色，财宝就是这样诳惑凡愚，在虚妄之中哪有真实？）

```
种种苦恼求财利，
水火王贼常侵夺，
由此能为众苦因，
何有智者生爱乐？
有诸常怀贪爱者，
驰逐财利无厌时，
能于父母无慈心，
乃至亲属生怨害。
言语善顺心乖违，
造作种种欺诳缘，
或学邪论邪呪等，
夸衒伎艺如婬女。
或复谄诳现柔和，
或复刚强示威猛，
如是无量众恶业，
莫不皆由财利生。
珊瑚金玉摩尼珠，
是物本来如泡沫，
不能了知如幻化，
为此虚诳坠三涂。
```
（大意：以种种苦恼求取财利，水、火、王、贼常来侵夺，由此能成为众苦之因，哪有智者会生爱乐？有些常怀贪爱的人，追逐财利没有厌足之时，能对父母没有慈心，乃至对亲属生起怨害。言语善顺而内心乖违，造作种种欺诳之缘，或学邪论、邪咒等，夸耀技艺如同淫女。或者谄诳而示现柔和，或者刚强而显示威猛，这样无量的众恶之业，没有不是由财利而生的。珊瑚、金玉、摩尼珠，这些东西本来如泡沫，不能了知它们如幻化，为这虚诳之物而坠入三途。）

【按】“伎艺”之“伎”，宋、元、明、宫本作“技”。

```
弥勒世尊出现时，
一生次当补我处，
国界黄金而布地，
是等为从何所来？
劫尽世间悉烧坏，
须弥河海尽燋枯，
毕竟磨灭归虚空，
而此宝物何从去？
种种恶业求财物，
养育妻子谓欢娱，
临命终时苦逼身，
妻子无能相救者。
于彼三涂怖畏中，
不见妻子及亲识，
车马财宝属他人，
受苦谁能共分者？
父母兄弟及妻子，
朋友僮仆并珍财，
死去无一来相亲，
唯有黑业常随逐。
```
（大意：弥勒世尊出现之时，他是一生补处，次当补我之处，国土以黄金铺地，这些黄金从何处来？劫尽时世间都被烧坏，须弥山、河海都焦枯，毕竟磨灭，归于虚空，而这些宝物又到哪里去？以种种恶业求取财物，养育妻子，以为欢娱；临命终时苦逼其身，妻子没有能救他的。在那三途的怖畏之中，见不到妻子以及亲友，车马财宝都属于他人，受苦时谁能与他分担？父母、兄弟以及妻子，朋友、僮仆以及珍宝财物，死去时没有一样来相亲随，只有黑业常常随逐。）

```
智人终不为亲爱，
作诸恶业入阿鼻，
唯除业尽方得出，
亲属无有能代者。
阎罗使者唯考业，
不问亲缘及友朋，
汝得人身不舍恶，
极苦今应甘忍受。
阎罗常告彼罪人，
无有少罪我能加，
汝自作罪今自来，
业报自招无代者。
父母妻子无能救，
唯当勤修出离因，
是故应舍枷鏁业，
善知远离求安乐，
于家妻子应生怖，
恒依佛教正修行，
在家炽然为苦本，
犹如炎炉甚可畏。
身心燋热镇烧燃，
谁有智者生贪著？
爱乐修行诸佛教，
无所营求为快乐。
愚暗凡夫不觉知，
家为苦本横贪爱，
于彼皮筋骨肉中，
迷惑妄生夫妇想，
不能了知如幻化，
凡夫于此生贪著。
智者能知此过患，
世间欲乐皆捐弃，
乐法当如求药想，
应速舍离居家缚。
```
（大意：智者终究不会为了亲爱而作种种恶业，入于阿鼻地狱；只有业尽才能出来，亲属没有能代替的。阎罗的使者只考察业，不问亲缘以及朋友：“你得到人身而不舍弃恶，现在应当甘心忍受极苦。”阎罗常告诉那些罪人：“没有少许罪是我能加给你的，你自己作罪，现在自己来，业报自招，没有代替的人。”父母妻子不能救，只应当勤修出离之因；所以应当舍弃如枷锁的业，善于知道远离而求安乐。对家与妻子应当生起怖畏，恒常依佛的教导正确修行；在家炽燃，是苦的根本，犹如火炉甚为可畏。身心焦热，常常燃烧，哪有智者会生贪著？爱乐修行诸佛的教导，无所营求才是快乐。愚暗的凡夫不能觉知，家是苦的根本，却横生贪爱，在那皮、筋、骨、肉之中，迷惑而妄生夫妇之想，不能了知它们如幻化，凡夫因此而生贪著。智者能知这过患，把世间欲乐都捐弃，乐法应当如求药之想，应当迅速舍离居家的系缚。）

#### 五百长者得无生忍说偈

那时五百位长者听了这法，得无生忍，欢喜踊跃，说偈道：

```
庆哉获大利，诸利中最上，
我等于佛法，皆生欣乐心。
发趣于菩提，利乐众生类，
以善而养命，觉慧自安心。
怜愍诸众生，愿当成佛道，
我等皆已发，无上菩提心。
金色相庄严，照明于世界，
乐菩提心者，当得如来身。
大心菩提心，诸心中最上，
解脱一切缚，具足诸功德。
少福诸众生，于此无欣乐，
不观生死过，不乐菩提心。
```
（大意：庆幸啊，我们获得大利，是诸利中最上的；我们对佛法都生起欣乐之心。发趣于菩提，利乐众生之类，以善法养命，以觉慧安住自心。怜愍众生，愿当成就佛道，我们都已发起无上菩提心。以金色之相庄严，照明世界，乐于菩提心的人，当得如来之身。广大之心、菩提之心，在诸心中最为上胜，能解脱一切系缚，具足种种功德。福德微少的众生，对此不能欣乐，不观察生死的过患，不乐于菩提心。）

```
菩提心功德，若有色方分，
周遍虚空界，无能容受者？
恒河沙数等，诸佛刹土中，
假使布珍宝，供养于诸佛。
有能一合掌，回向菩提心，
其福过于彼，边际不可得。
非唯供养福，余福亦复然，
如是菩提心，最胜仙所说。
菩提心最胜，如阿伽陀药，
能除一切病，与一切安乐。
我见诸众生，三火所热恼，
智者无量劫，勤苦常修习。
如医王勇猛，具足菩提行，
救拔众生苦，永离诸忧恼。
于一切生处，终不舍是心，
勤修诸行愿，勇猛求佛法。
我等得善利，我等心欣乐，
今遇释师子，当得如来身。
```
（大意：菩提心的功德，若有形色与方位分量，周遍虚空界，也无处能容受。在恒河沙数等诸佛刹土中，假使遍布珍宝，供养诸佛；若有人能一合掌，回向菩提心，他的福德超过前者，边际不可得。不只是供养的福德，其余的福德也是这样，这样的菩提心是最胜仙人所说的。菩提心最为殊胜，如阿伽陀药，能除一切病，给予一切安乐。我们见到众生被三火所热恼，智者在无量劫中勤苦常修习。如勇猛的医王，具足菩提之行，救拔众生之苦，令他们永离种种忧恼。在一切受生之处，终不舍弃这心，勤修种种行愿，勇猛求取佛法。我们得到善利，我们心中欣乐，现在遇到释迦狮子，当得如来之身。）

【按】“救拔众生苦”，圣本作“救拔苦众生”。

#### 世尊微笑，授记五百长者

那时世尊便微笑，从面门放出种种光明，青、黄、赤、白、红、紫、颇黎色，照于无量无边世界，乃至梵世，日月的威光都被隐蔽，光绕佛三匝，又从佛顶入。那时尊者阿难便从座起，偏袒右肩，右膝著地，合掌向佛说：“世尊！是什么因缘现出这微笑？如佛所现，不是没有因缘的。”便在佛前说偈道：

【按】“颇黎”，明本作“玻𭹳”，宫本作“颇梨”。“合掌向佛白言”之“白”，宋本作“曰”。

```
诸佛最上之导师，
不以无因现微笑，
哀愍世间利益者，
愿说所为之因缘。
贫乏众生无法财，
应说最上大乘施，
能作世间盲冥眼，
愿说微笑之因缘。
```
（大意：诸佛是最上的导师，不会无因现出微笑，哀愍世间、作利益的世尊，愿说您这样做的因缘。贫乏的众生没有法财，应当宣说最上的大乘之施，能作世间盲冥者的眼目，愿说微笑的因缘。）

【按】“哀愍”之“愍”，宋、元、宫本作“慜”。

那时世尊告诉阿难说：“你看见这五百位长者现在在我这里发阿耨多罗三藐三菩提心了吗？”阿难说：“是的，已经看见。”佛告诉阿难：“这五百位长者已在往昔百千亿那由他诸佛之所承事供养，种诸善根，现在听闻此法，得无生忍。这些长者从此以后不生于恶趣，在人天中常受快乐。又在来世弥勒佛所供养、恭敬、尊重、赞叹。以及贤劫中的一切诸佛，都承事恭敬供养，在诸佛所听闻正法，受持读诵，为他人广说。过了二十五劫，各在诸佛刹中成就无上菩提，都同一名号，号为胜莲花藏如来、应、正等觉。”

#### 流通

那时尊者阿难对佛说：“世尊！希有，世尊！希有，善逝！应当怎样称呼这广大的法门？怎样奉持？”佛告诉阿难：“这法门名为‘菩萨瑜伽师地’，也名为‘勇猛授长者所问’，你应当以这样的名号受持。”

佛说此经之后，尊者阿难以及比丘们、五百位长者、诸菩萨众，天、人、阿修罗等，听闻佛所说，都大欢喜，信受奉行。
