# 《大宝积经》卷第四十七（菩萨藏会·毘利耶波罗蜜多品）

唐·三藏法师玄奘 奉诏译

## 菩萨藏会第十二之十三

【按】品名本卷作“毘梨耶”，与前卷“毘利耶”同。

### 毘利耶波罗蜜多品第九之三

#### 五种增进之法与五种损减之法

“再者，舍利子！这样勇猛无倦正勤的菩萨摩诃萨，成就五种增进之法，便能迅速觉悟阿耨多罗三藐三菩提。舍利子！什么名为成就五种增进之法？就是：值遇佛出世，是增进之法；得以亲近善友，是增进之法；得以具足无难，是增进之法；随其所修集的一切善法永不失坏，是增进之法；在那安住律仪的菩萨摩诃萨处随从修学，是增进之法。舍利子！这是菩萨摩诃萨因修行毘利耶波罗蜜多，成就五种法，增进不退，迅速觉悟无上正等菩提。”

【按】“随所修集”之“集”，宋、元、明、宫、圣本作“进”。

那时，长老舍利子对佛说：“世尊！是否有菩萨对这五种法有所损减？”佛说：“有。”舍利子说：“是什么呢？大德薄伽梵！是哪些呢？大德苏揭多！”佛告诉舍利子：“有五种法，菩萨若成就，便能损减。是哪五种？就是对于佛世而不值遇，对于那善友不怀亲近，具足无难之法而不获得，所修习的善法多有失坏，对于诸安住律仪的菩萨心中不随之修学。由于具足这样的损减之法，也不能迅速觉悟无上菩提。

#### 在家菩萨的五种损减

“舍利子！菩萨成就哪五种法？舍利子！在家菩萨作国王的师傅，以威势之力恐吓众生，致使有事务的人来请求他施加威福，若为人办成这样的事，便重重地接受酬谢。这位菩萨贪图世间之利，心无正直，便替人去办，凡所出言，无非为了利益。舍利子！由于这样的法，损减善道；由于这样的法，损减无难。这样的在家菩萨为了养身而行种种恶行，不值遇佛世，乃至不能迅速证得阿耨多罗三藐三菩提。舍利子！这名为菩萨成就的第一损减之法。

“再者，舍利子！在家菩萨住于毁城之法。什么名为住于毁城之法？舍利子！若诸如来、应、正等觉出现于世间，为诸天、人、魔、梵说法，开示宣畅初善、中善、后善，文义巧妙，纯一圆满，清白梵行；那时将有四众出现，就是苾刍、苾刍尼、邬波索迦、邬波斯迦。那时苾刍尼依附于村落、城市、郊野、馆舍、国邑、王都，为了护持戒律而在其中居住。那些在家菩萨来到这住处，污染她们的戒众；因为毁坏戒律，所以名为住于毁城。犯了这事之后，不值遇佛世，乃至不能迅速觉悟无上菩提。舍利子！这名为菩萨成就的第二损减之法。

“再者，舍利子！在家菩萨见到那些有所依止、善说法律、演说正法之时，便对父母、兄弟、姊妹、妻妾、男女、眷属以及众生作为法障。舍利子！在家菩萨障碍正法之后，在长夜中自己对于法律常常多有障碍，不值遇佛世，乃至不能迅速觉悟无上菩提。舍利子！这名为菩萨成就的第三损减之法。

“再者，舍利子！在家菩萨听闻佛经中如来赞说少欲知足、与出离要道相应、独处山林静修、离苦之法，心生不信，轻毁诽谤，也教他人生起这样的见解。这些在家的不善菩萨毁呰如来的清净之教之后，又沉溺于可毁呰之趣。什么名为可毁呰之趣？就是堕入地狱、畜生、焰魔世界，或生于边地以及蔑戾车的恶邪见之中。在家菩萨由于行这事，不值遇佛世，乃至不能觉悟无上菩提。舍利子！这名为菩萨成就的第四损减之法。

“再者，舍利子！在家菩萨依止国王以及诸大臣，乃至富贵有权势的人，行弊恶之行，倚恃为势力，讥呵、毁骂、轻蔑、戏弄无量众生。舍利子！在家菩萨由于成就这语恶行，迅速招集诸恶趣之报，不值遇佛世，不遇善友，不得无难，失坏善根，不随安住律仪的菩萨修学正法，不能迅速觉悟无上菩提。舍利子！这名为菩萨成就的第五损减之法。”那时世尊想重宣此义，而说颂道：

```
菩萨成就五种法，
如是智慧无增长，
既不速疾见如来，
亦不逢事人中上。
或为王者大师傅，
欺诈诳惑诸众生，
由具如斯不善业，
不遇世间依怙者。
令多有情生怖畏，
若纳赃财若损害，
兴造如斯恶业已，
终不奉值人中尊。
或令诸尼净戒聚，
破坏摧灭生悲苦，
当离无量亿如来，
叵得成就诸无难。
于其父母妻子等，
障碍不令修法行，
又障听闻于正法，
速感愚痴覆蔽果。
若人厌世乐出家，
便致拘执缘留碍，
当离无量最胜尊，
叵得成就诸无难。
```
（大意：菩萨成就这五种法，这样的智慧便不增长，既不能迅速见到如来，也不能遇到并奉事人中最上者。或作国王的大师傅，欺诈诳惑众生，由于具足这样的不善之业，不能遇到世间依怙者。令许多有情生起怖畏，或收纳赃财，或加以损害，造作这样的恶业之后，终究不能奉值人中之尊。或令诸尼的净戒之聚破坏摧灭，令她们生起悲苦，便将远离无量亿如来，难以成就种种无难。对于父母、妻子等，障碍他们，不令修习法行，又障碍他们听闻正法，迅速感得愚痴覆蔽之果。若有人厌世乐于出家，便加以拘执，以种种缘留难障碍，便将远离无量最胜尊，难以成就种种无难。）

【按】“赃财”之“财”，元、明本作“赇”。

```
若有听闻如是法，
所谓赞说住空闲，
便生不忍忿恚心，
谤毁谓为非法说。
谤毁如是正法已，
常住生盲大剧苦，
一切重障罪业中，
方斯十六不及一。
彼难奉见诸如来，
设见不能怀信敬，
受女黄门生盲身，
又受驼驴猪狗等。
若有于佛及菩萨，
深生殷重爱敬心，
远离一切障碍已，
相续修行贤圣道。
父母妻子眷属等，
恒乐安勤正法中，
众生厌世求出家，
赞美劝助令其果。
若处眷属正法中，
当速往登贤善趣，
有能赞劝出家者，
速悟无上佛菩提。
```
（大意：若有人听闻这样的法——就是赞说安住空闲之处——便生起不忍、忿恚之心，谤毁说这是非法之说。谤毁这样的正法之后，常住于生盲的大剧苦之中，在一切重障罪业中，比起这罪，十六分也不及其一。他们难以奉见诸如来，即使见到，也不能心怀信敬，受女人、黄门、生盲之身，又受骆驼、驴、猪、狗等身。若有人对佛以及菩萨深生殷重爱敬之心，远离一切障碍之后，相续修行贤圣之道；对父母、妻子、眷属等，恒常乐于令他们安勤于正法之中；有众生厌世求出家，便赞美劝助，令其成就。若处在眷属之中而安于正法，将迅速往登贤善之趣；能赞叹劝助他人出家的，迅速觉悟无上佛菩提。）

#### 出家菩萨的五种损减与饿狗之喻

“再者，舍利子！出家菩萨又有五种法，若成就了，便不值遇佛世，不亲近善友，不具无难，失坏善根，不随安住律仪的菩萨修学正法，也不能迅速觉悟无上菩提。舍利子！什么名为出家菩萨成就的五种法？一是毁犯尸罗，二是诽谤正法，三是贪著名利，四是坚执我见，五是对他人之家多生悭嫉。舍利子！这样名为出家菩萨成就的五种法，不值遇佛世，乃至不能获得无上正等菩提。

【按】“不具无难”之“无”，宋、圣、宫本作“友”。

“舍利子！譬如饿狗惶惶地沿路寻觅，遇到一具早已没有肉腻的锁骨，只看到骨上的红色便以为是厚味，便衔起它；来到人多之处的四通大道中，因为贪图其味，口涎流在骨上，误以为甜美，或咬、或舔、或啮、或吮，欢爱缠附，从不舍离。那时有刹帝利、婆罗门以及诸长者，都是大富贵之人，来到这路上。那时这饿狗远远看见他们来，心生热恼，这样想：‘那来的人莫非要夺我所珍重的美味？’便对那些人发大瞋恚，发出深沉凶恶的声音，恶眼斜视，露出牙齿，便要去咬他们。舍利子！你认为怎样？那来的人是为了别的事，难道还会求这没有肉、只有红色的锁骨吗？”

【按】“䶧”字（齿旁尧）先前电子文本未能显示，今据《大正藏》补出，即“咬”；宋、元、明、宫本作“齩”。“慞惶”之“慞”，圣本作“章”。“琐骨”之“琐”，宋、元、明、宫本作“锁”。“衔之”之“衔”，元、明本作“啣”。

舍利子对佛说：“世尊！不会的。世尊！不会的。善逝！”佛告诉舍利子：“若是这样，那悭吝的饿狗为什么发出深沉凶恶的声音，露牙而吠？”舍利子说：“依我理解，它恐怕那来的人贪著美膳，必定会夺走它的甘露良味，由于这样的心意，所以露牙而吠。”佛告诉舍利子：“是这样，是这样，如你所说。未来末世有诸苾刍，对于他人的施主勤习于家悭，耽著于屎尿，妄加缠裹；虽然遇到这样具足的无难，却弃之不顾，不修正当的检束。这样的苾刍，我说他的行为如同前面那愚痴的狗。舍利子！我现在出世怜悯众生，为了令其止息，专门思惟这事，为这样等等的恶苾刍说这个譬喻。

【按】“家悭”，指对施主之家起悭吝独占之心。

#### 悭他家者的三重过与三恶言

“再者，舍利子！这些菩萨摩诃萨为了利益安乐无量众生而求佛智，行毘利耶波罗蜜多。那些菩萨摩诃萨对自己的身肉尚且行布施，何况谋求妄想中的恶肉，而对他人之家生起种种悭嫉？舍利子！那些苾刍因为悭吝他人之家，我说此人是痴丈夫，是只为活命的人，是守护财谷的奴仆贱役，是珍重世间财宝玩物而被系缚的人，是只钦尚衣食的人，是为了求取妄想中贪嗜的恶肉而生起悭嫉的人。

【按】“规求”之“规”，南藏作“现”。

“舍利子！我现在再说这样的正法。那些苾刍先到了他人之家，不应见到其余苾刍便生嫉妒。若有苾刍违背我的法教，见到其余苾刍，或者这样说：‘这施主之家先与我相识，你从哪里来，竟在这里？我在这家极为亲密，调笑往来，你从哪里来，随便侵夺？’舍利子！因为什么缘故，那悭吝的苾刍对后来的人偏生嫉妒？舍利子！由于诸施主之家许给他衣钵、饮食、卧具、病缘医药以及供身等资生什物，他这样想：‘恐怕那施主会把先前许给我的东西施给后来的人。’由于这样，这苾刍便在施主之家生起三重过失：一是生起住处的过失，见到其余苾刍，或者生起怨恨之言：‘我现在要离开这里。’二是凡所习近之处，便说不知道应与不应。三是对于并非固定的人家妄起种种过失。舍利子！那悭吝的苾刍对后来的人说三种恶言：一是说住处的过失，以种种恶事增益那家，令后来的苾刍心不乐住；二是对后来苾刍所有真实之言反说是虚妄；三是诈现善相，谄附此人，伺察到微小的过隙，便当众治罪举发。舍利子！这样的苾刍对他人施主之家生起悭嫉，迅速灭尽一切所有的白法，永尽无遗。

【按】“乃在此耶”之“在”，明本作“至”。

原文：“二者凡所习近当言未知应与不应。三者于不定家妄起诸过”（大意：二是凡所习近之处，便说不知道应与不应。三是对于并非固定的人家妄起种种过失。所指未详，存疑。）

#### 胜现王佛时律仪、住律仪二童子

“再者，舍利子！若有苾刍住于家悭，我说此人是不善者，便是弃舍了菩提资粮，又是不能随逐安住律仪的菩萨修习正法的人。又，舍利子！这样的情形，我再说一说。往昔超过无数广大、无量、不可思议的阿僧企耶劫，有佛出世，名为胜现王如来、应、正等觉、明行圆满、善逝、世间解、无上丈夫、调御士、天人师、佛、薄伽梵。那尊佛住寿九十拘胝岁，声闻众会有九十拘胝那庾多，都是大阿罗汉，诸漏已尽，乃至一切得心自在，到达第一究竟。

“舍利子！在那时，有一位大长者名叫善择，其家巨富，多有财宝，资产僮仆无不充足。他有两个儿子：一名律仪，二名住律仪，年纪幼小，容貌端正，清净之色圆满，众人喜见。舍利子！那时胜现王如来、应、正等觉在早晨穿衣持钵，大苾刍僧左右随从，那位佛世尊居于僧众之首，为了福利众生而示现乞食之法，进入那长者所住的大城。威仪安详有序，诸根寂定，心意恬淡，得到调顺的奢摩他，以及获得第一调顺的奢摩他，修摄诸根如大龙象，澄静无浊如深泉池，盛德巍巍如黄金楼观，色相超挺如紫金山，又如大海众宝充盈，如帝释天主被诸天围绕，如大梵王心虑寂静。舍利子！那位薄伽梵有这样的种种威相庄严。长者的两个儿子那时在重阁上，远远看见胜现王佛从远处走来，容貌威严，色像第一，生起欢喜之心，赞叹从未有过。舍利子！那住律仪童子因为先看见佛，心中喜悦踊跃，对他的哥哥说：‘从出生以来，哥哥可曾见过这样端严的含灵之王？’哥哥回答弟弟说：‘我从出生以来实在不曾见过这样端严的含灵中王。’弟弟对哥哥说：‘依我思忖，在未来世我必定要作这样的含灵中王。’舍利子！那时住律仪童子便为他的哥哥说颂道：

```
『如律仪兄今所见，
我于当来定如是，
大苾刍众所围遶，
当复倍胜于今日。
求菩提道因缘故，
当誓不噉诸饮食，
兄既乐居牢狱中，
我意决定当超胜。
如是一切众生尊，
譬等众星之满月，
谁有见斯不生信，
而乐居家不出离？』
```
（大意：“如律仪哥哥现在所见的，我在将来必定也会这样，被大苾刍众所围绕，并将比今天更加殊胜。为了求菩提道的因缘，我当发誓不吃饮食；哥哥既然乐于住在牢狱之中，我的心意决定要超胜于此。这样一切众生的尊者，譬如群星中的满月，谁见了不生信心，而还乐于居家不出离？”）

“舍利子！那时律仪童子便以伽他回答他的弟弟说：

```
『弟当且止勿高声，
非但语言便遂事。
我岂当发世语言，
试谁在先成正觉？』
```
（大意：“弟弟暂且停止，不要高声，不是单凭言语就能成事的。我岂会发出世俗的言语，比试谁先成就正觉？”）

“舍利子！那时住律仪童子又以伽他对他的哥哥说：

```
『如是无上菩提道，
非但弊鄙悭心证，
我当发大贤善声，
决定成佛人中上。
夫怀悭者相如是，
资产不欲令他知，
今我岂复守沉默，
尚舍身命况财宝。
我以家资咸布施，
为求菩提道因缘，
及以兄分家财宝，
尽施佛田深敬故。
谁见如是最胜尊，
具三十二妙相者，
而不发愿趣菩提，
唯除具诸下劣见。
所有家宅及财宝，
父母并诸眷属等，
我当一切皆舍离，
速往善逝如来所。
为世依怙作光明，
照世慈尊极难遇，
百千拘胝那庾劫，
如是胜相甚难闻。
```
（大意：“这样的无上菩提之道，不是弊鄙悭吝之心所能证得的，我应当发出大贤善之声：我决定成佛，作人中最上者。所谓怀有悭吝的人，其相就是这样：自己的资产不想让他人知道；我现在岂能再守沉默？连身命都要舍弃，何况财宝。我把家中的资财全部布施，为了求菩提道的因缘；以及哥哥所分得的家财珍宝，也全部施给佛这福田，因为深深敬重。谁见到这样的最胜尊，具足三十二种妙相，而不发愿趣向菩提？唯除那些具有下劣之见的人。所有的家宅以及财宝、父母以及诸眷属等，我应当一切都舍离，迅速前往善逝如来之所。为世间的依怙，作为光明，照耀世间的慈悲之尊极难遇到，在百千拘胝那庾多劫中，这样的殊胜之相都极难听闻。”）

【按】“今我”，明本作“我今”。

```
我见世尊入王都，
大苾刍僧所围遶，
如盛满月在清天，
流光洞照诸依地。
我见世尊游四衢，
周遍庄严于一切，
犹彼具足千光日，
独满虚空常遍照。
我见世尊居众首，
庄严显发苾刍僧，
如彼苏迷卢山王，
映诸宝山悉严丽。
如来威光极炽盛，
通照此土诸群生，
圆成妙相两足尊，
荣光蓥饰诸大众。
如来住大神通力，
善御天龙非人等，
复兴无量种变现，
为众生故入王都。
谁见如斯正法主，
三十二相大庄严，
而复希趣下劣乘？
唯除不肖愚暗者。
我今欣覩人中尊，
发生难得清净信，
为利含识趣菩提，
要当往觐如来所。』
```
（大意：“我看见世尊进入王都，被大苾刍僧所围绕，如同盛满的月亮在晴朗的天空，流光洞照一切依地。我看见世尊游于四通大道，周遍庄严一切，犹如那具足千光的太阳，独自充满虚空，常常遍照。我看见世尊居于大众之首，庄严显发苾刍僧众，如那苏迷卢山王映照诸宝山，都庄严美丽。如来的威光极为炽盛，通照这片土地上的众生，圆满成就妙相的两足尊，以荣光装饰诸大众。如来住于大神通力，善于调御天、龙、非人等，又兴起无量种变现，为了众生而进入王都。谁见到这样的正法之主，具足三十二相的大庄严，而又希求趣向下劣之乘？唯除那些不肖愚暗的人。我现在欣喜地见到人中之尊，生起难得的清净信心，为了利益含识而趣向菩提，一定要前往觐见如来。”）

“舍利子！那时律仪童子又以伽他回答他的弟弟说：

```
『我于途路非懈怠，
而不速往如来所，
待我下斯重阁已，
当出外宇谛思惟。
宜应捐舍于我想，
又不顾惜吾身命，
及求最上丈夫智，
尔乃往诣如来所。
父母家宅及财宝，
于如是等生重爱，
我今一时皆弃舍，
尔乃往诣如来所。
若有欲愿当成佛，
又深爱乐如来者，
宜速捐诸珍宝聚，
舍离家法趣非家。』
```
（大意：“我在路途中并非懈怠，而不迅速前往如来之所，等我下了这重阁之后，出到外宇当仔细思惟：应当捐舍我想，又不顾惜我的身命，以及求取最上丈夫之智，然后才前往如来之所。父母、家宅以及财宝，对于这些生起深重的爱著，我现在一时全部弃舍，然后才前往如来之所。若有人想愿当成佛，又深深爱乐如来，应当迅速捐弃种种珍宝之聚，舍离在家之法，趣向非家。”）

#### 二童子供佛发愿

“舍利子！那时住律仪童子听了这话之后，便从阁上下了阶道，将要前往胜现王如来、应、正等觉之所；还没有到达的时候，他的哥哥律仪又从重阁迅速下来，奔往佛所，礼敬完毕，那时住律仪才到达。那时哥哥律仪童子便以十亿无价的宝衣奉献如来，又在佛前说颂道：

```
『我今不求于妙相，
奉施如来无价衣，
唯愿当来所获报，
如今世尊等无异。
一切含灵中最胜，
一切妙法善安住，
唯愿当来所获报，
如今世尊等无异。
具足无上智慧藏，
诸力正勤善安住，
三十二相身所持，
愿速当成人中上。
成就诸佛十种力，
四无所畏善安住，
唯愿当来所获报，
如今世尊等无异。
如佛所知真净法，
唯佛善住皆明照，
愿赐演通如是法，
令我速悟上菩提。
我今不求妙色相，
奉佛无价胜上衣，
唯希寂静妙菩提，
为利诸天世间故。
```
（大意：“我现在不求妙相，奉施如来无价之衣，唯愿将来所获的果报，如今天的世尊一样，没有差异：一切含灵中最殊胜，一切妙法善安住，唯愿将来所获的果报，如今天的世尊一样，没有差异。具足无上的智慧宝藏，诸力与正勤善安住，三十二相为身所持，愿迅速成为人中最上者。成就诸佛的十种力，四无所畏善安住，唯愿将来所获的果报，如今天的世尊一样，没有差异。如佛所知的真实清净之法，唯佛善住而都能明照，愿赐我演说通达这样的法，令我迅速觉悟无上菩提。我现在不求妙色相，奉佛无价的殊胜上衣，唯求寂静美妙的菩提，为了利益诸天世间。”）

```
如来所住微妙法，
一切异论无倾动，
我今为求如是法，
敢施无价胜上衣。
诸法无生无老病，
亦无忧愁悲叹等，
愿为开斯寂静法，
导利诸天世间故。
若法无有贪瞋痴，
亦无诸慢及渴爱，
愿说菩提与佛性，
无为清凉甘露法。
若法如来所安住，
为天龙等深敬礼，
或有思虑或无思，
愿为开斯寂静法。
佛住是处能通照，
无量四方诸佛土，
如发大焰深暗中，
愿证如斯等甘露。
若诸一切爱无爱，
性常不依于欲界，
色无色界亦无依，
愿说如斯胜妙法。』
```
（大意：“如来所安住的微妙之法，一切异论都不能倾动，我现在为了求这样的法，敢施无价的殊胜上衣。诸法无生、无老、无病，也没有忧愁、悲叹等，愿为我开示这寂静之法，为了导引利益诸天世间。若有法没有贪、瞋、痴，也没有诸慢以及渴爱，愿说菩提与佛性这无为清凉的甘露之法。若有法为如来所安住，为天龙等深深敬礼，或有思虑或无思虑，愿为我开示这寂静之法。佛住于此处能通照无量四方的诸佛国土，如在深暗中发出大火焰，愿我证得这样的甘露。若一切爱与无爱，其性常不依于欲界，于色界、无色界也无所依，愿说这样的殊胜妙法。”）

“舍利子！那时住律仪童子听了哥哥律仪说这颂之后，便以一双新的美妙宝屐奉施胜现王如来，就在佛前说伽他道：

```
『愿我当为诸群生，
为救为趣为依舍，
更不履践于邪径，
恒导群迷说正路。
愿常不习诸贪欲，
此乃愚夫之所行，
永离一切有为法，
恒值如来出兴世。
既逢明照世间者，
便应供养两足尊，
勤求无上佛菩提，
为利一切群生故。
当以无量香花鬘，
高妙幢幡诸宝盖，
奉献龙中之大龙，
为利一切群生故。
复以种种上衣服，
卧具饮食诸医药，
俱持奉献佛世尊，
为利一切群生故。
击大小鼓吹螺贝，
及奏箫管清歌等，
俱持奉献照世尊，
为利一切群生故。
厚味种种极淳浓，
世间微妙所珍尚，
俱持奉献救世尊，
为利一切群生故。
```
（大意：“愿我当为一切众生作救护、作归趣、作依靠、作舍宅，不再履践邪径，恒常引导迷途众生，宣说正路。愿我常不习近诸贪欲，这是愚夫所行的；永离一切有为之法，恒常值遇如来出兴于世。既然遇到明照世间者，便应供养两足尊，勤求无上佛菩提，为了利益一切众生。当以无量的香、花鬘、高妙的幢幡、种种宝盖，奉献给龙中的大龙，为了利益一切众生。又以种种上妙衣服、卧具、饮食、种种医药，全部奉献给佛世尊，为了利益一切众生。击大鼓小鼓，吹螺贝，以及奏箫管、清歌等，全部奉献给照世尊，为了利益一切众生。种种极为淳浓的厚味，世间所珍尚的微妙之物，全部奉献给救世尊，为了利益一切众生。”）

```
广行如是供养已，
利益无量诸群生，
我于尔时便出家，
精励勤修于梵行。
当安住斯八妙道，
复安无量亿众生，
愿我为诸有识依，
常不履于邪曲径。
众圣诃毁极下劣，
所谓婬欲我能捐，
又当弃捐诸放逸，
于不放逸恒修学。
愿我永不生众难，
常得生诸净信家，
生生常见人中尊，
见已于佛生深信。
既生信已修恭敬，
以妙花鬘及涂香，
种种音乐供养已，
为求诸佛深智慧。
如是广修诸供养，
乃经无量拘胝劫，
永断欲法舍居家，
精勤奉修清净行。』
```
（大意：“广行这样的供养之后，利益无量众生，我在那时便出家，精励勤修梵行。当安住于这八支妙道，又安置无量亿众生；愿我作一切有识之依，常不履践邪曲之径。众圣所呵毁的极下劣之事，就是淫欲，我能捐弃；又当弃捐种种放逸，恒常修学不放逸。愿我永不生于众难，常得生于具净信的人家，生生常见人中之尊，见后对佛生起深信。既生信心之后修习恭敬，以美妙花鬘以及涂香、种种音乐供养之后，为了求诸佛的深智慧。这样广修种种供养，经过无量拘胝劫，永断欲法，舍弃居家，精勤奉修清净之行。”）

“舍利子！那时住律仪童子说了这颂之后，就在他所赞叹的胜现王如来之处，为那位如来以赤栴檀建立道场，高广华丽，装饰四逾缮那，纵广庄严，具备种种雕饰之美。那时童子建立道场、庄严成就之后，便奉施那位佛世尊，又在佛前说颂道：

```
『佛所安住四种住，
往昔最胜所称誉，
我今欣求如是住，
唯愿善逝慈哀许。
若有安住是所住，
心常了知无量众，
及知过去未来生，
我今欣求如是住。
若住是住至究竟，
四种正胜四神足，
及四最胜无碍辩，
我今欣求如是住。』
```
（大意：“佛所安住的四种住，往昔最胜者所称誉的，我现在欣求这样的住，唯愿善逝慈悲哀悯允许。若有人安住于这所住，其心常了知无量大众，以及知道过去与未来的生，我现在欣求这样的住。若住于这住而至究竟，四种正胜、四神足，以及四种最胜无碍辩，我现在欣求这样的住。”）

原文：“佛所安住四种住”（大意：佛所安住的四种住。“四种住”所指未详，存疑。）

“舍利子！那时薄伽梵胜现王如来怜悯这童子，接受他所献的上胜道场，与苾刍僧入内居住。那时那童子看到如来以及苾刍僧接受他的布施，心中大为欢喜，踊跃无量，又以种种上妙供具供养，倍加恭敬尊重赞叹，在半个月之间从不间断。过了这以后，便在佛前除去须发，披上袈裟衣，以清净信心舍弃家法，趣向非家，专志精勤求取种种善法。舍利子！那时两位童子求取善法之后，心中正确了知，对于佛菩提共同发起弘誓。他的哥哥律仪发这样的誓言：‘愿我最先成就等正觉，其佛名为世间依怙放大光明。’他的弟弟住律仪又发誓言：‘愿我最先成就等正觉，其佛名为大导商主天人中尊。’舍利子！那时律仪童子菩萨摩诃萨发了这愿之后，就在胜现王如来面前合掌而立，以大誓庄严，说伽他道：

```
『我当不复更安坐，
亦无放倚身眠卧，
专精勤求菩提道，
为利一切群生故。

常舍嬾惰勤精进，
志求上妙菩提道，
为利一切群生故。

皮骨筋脉皆枯燥，
```

```
修行无上菩提行，
与发最胜勤精进，
为利一切群生故。
```

#### 二菩萨千年精进

那时，佛告诉舍利子：“那过去世胜现王如来法中的律仪童子菩萨摩诃萨与住律仪童子菩萨摩诃萨，在那位佛所发起大弘誓，因行毘利耶波罗蜜多，精勤不懈，修行正道。舍利子！那两位菩萨行精进时，在千年之中，乃至从未有一弹指之顷被睡眠所逼夺；千年之中，从未生起想要躺卧休息的心；千年之中，从未生起乐于坐下的心；千年之中，从未有一次屈身蹲踞，唯除大小便利或饮食之时，便就站着；千年之中，从未吃第二餐，每日只一食，一食只一团，饮水一器；千年之中，从未生起欣乐饮食之心，如‘我现在极为饥渴，愿迅速得到’这样的念头从未生起；千年之中，从未有一次过量饮食；千年之中，从未生起称量饮食的念头，这咸、这淡，这甜、这苦，辛酸美恶，从无思虑；千年之中，每次乞食时一心正念，从未观看授食之人的面孔，不生这样的念头：‘谁给我食物？是男人吗？是女人吗？’乃至童男童女都不瞻视；千年之中，居住在树下，从未仰面观看树的形相；千年之中，所穿的衣服从未更换；千年之中，从未有一念生起欲觉、恚觉、害觉；千年之中，从未生起缘念亲里的觉想，无论父母、兄弟、姊妹以及其余眷属，都不缘念；千年之中，从未生起思念所居之家的心；千年之中，从未生起仰观虚空中日月星宿、云霞等色的念头；千年之中，从未生起以身体倚靠墙壁或树木的念头；千年之中，从未生起以种种酥油涂抹肢体的念头；千年之中，从未生起身心惊怖的念头；千年之中，从未生起身心疲倦的念头；千年之中，从未生起懈怠懒惰放逸之心，只生起这样的念头：‘我现在修行阿耨多罗三藐三菩提，何时当证？何时当得？’千年之中，从未有一次身心痛恼；千年之中，从未生起‘我想剃发’的念头，唯有四天大王时常前来，以其神力用手摩取他们头上的头发带走，在他们的天宫中建起窣堵波，以众宝庄严而供养；千年之中，虽然有天王或来或去，而心中都没有来去之想；千年之中，从未生起从阴影处到阳光处、从炎热处到清凉处的念头；千年之中，在严寒之时，从未生起盖上厚暖衣服以取温暖舒适的念头；千年之中，从未生起谈论世间无益之语的念头。

“舍利子！这两位菩萨在千年之中行这样等等坚固的精进，那时有一个恶魔名叫愚痴念，如同我现在出现于世间时，也有恶魔罗名叫愚痴念的。舍利子！那时恶魔为了兴起破坏扰乱，在律仪菩萨所经行的道路上，仰面铺满利刀，遍布其行走之处。那时律仪菩萨对于那刀道稍微失去本心，生起利刃之想；刚生起这想，便即追悔，发出大音声，再三唱言：‘咄！奇事！我现在怎么住于放逸？’舍利子！那时那位菩萨所发出的音声遍告三千大千世界，在上方空中有百千拘胝天魔徒党，听到这位菩萨忆念自省的音声，便同时对菩萨说：‘如你现在普告之声，说得极好，说得极好。’舍利子！这样的天声唯有律仪听到，那住律仪对于诸天之声以及这位菩萨普告的大声，都没有听到。那时律仪菩萨听了诸天的话之后，奋发坚固的大精进，想要再向前经行，再次转心，不缘念于刀刃。舍利子！那时那位菩萨摩诃萨降伏魔怨之后，住于这样的威仪，行于这样的妙行，修习这样的道迹，生起这样的大悲，兴发这样的勇猛精进，从未休废。

#### 二大士往生梵世、转轮王家

“再者，舍利子！那两位大士在那法中因行毘利耶波罗蜜多，都成就这样的威仪行迹与大悲勇猛，又在千年之中住于空闲林中修习念佛。过了这以后，胜现王如来才入涅槃。那时诸天便前来告诉他们说：‘善男子！难道不知道吗？如来现在已般涅槃。’那时两位大士听到诸天的告知，便前往胜现王如来涅槃的林中；到了那里之后，合掌而立，瞻仰如来，目不暂舍，极怀恋慕，深生敬重，这样想：‘如来出世，是大慈悲者，覆护众生如同舍宅，为什么一下子就迅速般涅槃，令我们这些人无依无怙？’舍利子！这两位大士站在如来面前，深怀恋仰，七日七夜脚不移动，不胜哀感，便站着命终，往生梵世。受了梵天之身后，得到宿命智力，以大神通从上方下来，到达涅槃会上，为胜现王如来、应、正等觉所有的舍利建起窣堵波，以珍宝妙物极尽世间的庄严，经四万年才得以成就，在上面安置种种轮盖。舍利子！那时两位菩萨为那位如来建起窣堵波之后，心中大为欢喜，合掌而立，观察其福相，倍加欣庆；这样又经过七万年，才开始礼拜，因此命终，都生于赡部洲中大转轮王之家，处于王后的胎中。舍利子！他们初生之后，便忆念起过去所经历的种种事，这样说：‘我现在应当安住于最上第一的不放逸之法。’又以伽他自我告诫说：

“舍利子！那时那位菩萨身相端正，如十六岁的少年，不乐于世俗之网，常思其过患，便剃除须发，穿上袈裟衣，以清净信心弃舍家法，趣向非家，二万年中勤修梵行。后来命终之后，又生于梵世；在那里寿尽，又生于赡部洲。舍利子！在那时，赡部洲有佛出世，名为妙香如来、应、正等觉、明行圆满、善逝、世间解、无上丈夫、善调御士、天人师、佛、薄伽梵。那时那位菩萨遇到佛之后，便在其法中剃除须发，穿上袈裟衣，以清净信心弃舍家法，趣向非家，满一拘胝岁修行梵行。这样次第有一万位如来出现于世，律仪菩萨都得以值遇，在诸佛所种植众多德本，常勤精进修行梵行。那住律仪菩萨常与他的哥哥同生一处修习种种圣道，唯有在一尊佛那里没有修梵行，因为这个缘故，律仪菩萨先得成佛，出现于世，名为炽然精进如来、应、正等觉、明行圆满、善逝、世间解、无上丈夫、调御士、天人师、佛、薄伽梵，住世教化经过九十拘胝岁，声闻大众有九十那庾多共同集会说法。

#### 炽然精进如来觉悟轮王

“舍利子！炽然精进如来兴世之时，那住律仪菩萨作转轮王，威加四方，福德所覆，对炽然精进如来生起极深的信心，以种种上妙衣服、肴膳饮食、病缘医药、什物众具，供养、恭敬、尊重、赞叹，在三个月中奉献那尊佛以及苾刍僧。舍利子！那时炽然精进如来、应、正等觉虽然接受供养，为了令那位轮王觉悟，令他忆念起来，说伽他道：

#### 起家悭时观三种怖畏

那时，佛告诉舍利子：“诸菩萨摩诃萨因行毘利耶波罗蜜多，安住于正勤而行菩萨道，应当依随律仪菩萨摩诃萨修学勇猛无倦的精进波罗蜜多，不应依附那啃着枯骨锁、住于悭吝的众生而修学。舍利子！若有菩萨乐求菩提，不应对他人之家生起悭吝；若一时失念生起悭吝时，应当乐于观察三种怖畏。哪三种？就是：对他人之家屡屡往来，或因乞食，或因谈话，缠绵不已，于是成为亲好；见到那第二位贤善的苾刍，因为贪著，便生起悭嫉，或者稍微生起一念恚心，不相随顺；由于这缘故，应当知道是摄受了地狱的种种苦业之道，应当知道是把生盲的种子种在心田中，应当知道是具足摄受了生于边地之业。舍利子！我现在再为你说其相。就是那位菩萨见到诸贤善清净的苾刍来到他那里，便生起嫉妒瞋恚之心，内心虽然忿结，外表却装作清白，与人交谈言论，心中却悭吝；而身体恒常将迎，随事供给；或在私下隐蔽之处怒目而视，或以不实之事加以诬谤。舍利子！以这因缘，这样的菩萨应当知道是摄受了地狱业道，生盲的种子种在心中，即使生于人道，也在边地，遭受种种苦楚，受生盲之报，多被诽谤，被他人役使，昼夜辛勤，从无停息。舍利子！若诸菩萨对他人之家生起悭嫉时，应当思惟这三种怖畏。”

【按】“植其中心”之“植”，圣本作“殖”。“设于他家”之“设”，宋、元、明、宫本作“说”。

#### 舍利子请说离家悭法

那时，如来说了这话之后，长老舍利子对佛说：“甚为奇特，世尊！从未有过。这些菩萨摩诃萨极为希有，竟能好好地遇到如来宣说这家悭出离之法。善哉，世尊！愿为我们这些声闻众宣说正法要义、远离家悭之相。为什么？我们在佛法之中，并非不愿脱离地狱、生盲、边地、诽谤的果报，常愿生于中国的人趣。我们声闻深深想要乐闻离家悭之法，唯愿世尊舍弃无缘之怨，不舍弃我们，务必为我们宣说。”

那时，佛告诉舍利子：“善哉！善哉！舍利子！甚为希有，你们竟能住于无浮华谄曲之心，请问如来这样的义理。谛听，谛听，当为你们说。舍利子！若有众生想要随如来修学佛法，我当为他如其所应而显说。为什么？因为众生能随佛修学，如来不违背他们的心意，必定现在其前为他们宣说。又，舍利子！若有众生不乐于随佛修学正法，若为他们宣说，此人听了，便会成为斗诤的根本。舍利子！这样成就净信的菩萨摩诃萨因行毘利耶波罗蜜多，对诸佛之法广生净信，在长久的大夜中常乐观察，为了救济沉溺的众生，前往如来之所，殷勤郑重地咨询疑问，对于所敷演的都乐欲听闻；听闻正法之后，又获得广大清净的深信，欢喜踊跃，倍加精进，受持正法，如说修行。

【按】“殷勤”之“殷”，宋、宫本作“慇”。

原文：“唯愿世尊舍无缘怨，不舍我等”（大意：唯愿世尊舍弃无缘之怨，不舍弃我们。“无缘怨”所指未详，存疑。）

#### 末世恶苾刍依三事

“又，舍利子！未来之世我的诸弟子中，少有苾刍深心希乐趣向般涅槃寂静之法，多依三件事作为常业。哪三件？一是常喜欢追求世间的名利；二是贪乐朋党，追求施食之家，往还不绝；三是喜乐追求华饰的房宇，贮积财富、什物、资具。这名为依止追求三事。舍利子！这些苾刍因为依止这样三种事，终究不能解脱三种恶趣。舍利子！这样的苾刍不乐于解脱地狱、傍生、焰魔鬼趣，反而喜乐勤修灭尽生天之道的法，又常勤修互相言语斗讼、讥刺、离间、诤论之事，又乐于摄受心不净信的诸恶友等，舍弃空静的林间，依泊于村落，以白衣俗人为朋党。

【按】“离间诤论”之“诤”，《大正藏》无，今依CBETA补。“村落”之“落”，圣本作“聚”。“朋翼”之“翼”，元、明本作“党”。

原文：“而返喜乐勤修灭尽趣天道法”（大意：反而喜乐勤修灭尽生天之道的法。所指未详，存疑。）

“舍利子！诸在家人这样说：‘这样的长老屡屡来我家，与我交好，我当供给他，布施他衣服、饮食、卧具、病缘医药以及其余资具。那些住在空闲之处的长老们，与俗人一向没有交往，我们怎能与他们交谈问候？’因此缘故，这些苾刍与在家人转相亲狎，互相谈说，只叙说世俗之事、繁杂的戏论。舍利子！这恶苾刍乐于与无良之人同住同行，长久住在一处，从不迁移，多觅朋党，多找施食之家，屡屡探视，亲自往来庆吊，由于这事，暗中怀有亲爱。假设有客苾刍前来，都不供给，先行毁呰非法之言；而那客苾刍实是贤圣，这恶苾刍也不称说：‘你是多闻、具戒清净的人，你是预流、一来、不还、阿罗汉果。’这样等等的话全不称说。舍利子！这恶苾刍在我的法中不修我的法，没有其余事，只乐于毁呰呵骂不止。舍利子！那些作为朋党的俗人又这样说：‘诸客苾刍从未与我们共同久住，周旋往来；旧住的苾刍与我们久住，情事相知，替我们传递使命，经理事务。因为这个缘故，我当与诸旧住苾刍互相护持偏袒，假借威势。’舍利子！由于这样等等，诸恶苾刍对这部经典无论理解与否，在一切时都诽谤、毁呰、不信。

“又，舍利子！若有人听闻如来所说的经典，对这样的文句差别法门常乐听闻，听了便信解，无有疑惑，必定能舍离这样的众生，以及舍弃应往恶趣的业。这样，舍利子！修行无倦精进的菩萨摩诃萨，听闻这样的悭嫉等往恶趣之业的种种相，听了之后便不自己去行家悭等事，何况还为他人开示这法。舍利子！这样名为菩萨摩诃萨精勤无倦修行毘利耶波罗蜜多，应当这样修学。
