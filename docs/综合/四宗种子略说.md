# 四宗种子略说

**（藏文：གྲུབ་མཐའ་བཞིའི་ས་བོན་བཤད་པ）**

**堪布阿旺巴桑（阿琼堪布）造**
汉译：据藏文原文，参英译本（Adam Pearcey 译，2018年）

---

顶礼具无缘大悲之吉祥圣上师！

于此，略说四宗之种子（要义）如下：

## 一、声闻毗婆沙宗（有部）

首先，声闻毗婆沙宗之二谛，《俱舍论》云："若彼以物摧碎、或以慧析离余分之后，缘彼之心即不复趣入者，如瓶、如水，是名世俗〔谛〕；此外〔即析之而心仍趣入者〕即是胜义〔谛〕。"（译注：此颂出自《俱舍论》第六品第四偏。）

如是所说：凡任何粗大之物，可以铁锤等击碎，或于心中析离其部分，令执彼粗大显现之心不复认取为彼者，此类皆是世俗谛。至于胜义，则是：任何粗大之色法或心法之物，以微尘与刹那加以各别分析之后，至色法之边际，即无分微尘；至心法之边际，即无分刹那——此等自性，凡执取彼之心不能再舍弃、不能再析离者，即许为胜义谛。

## 二、经部宗

其二，依经部宗之理，《释量论》云："凡具有作用能力（能生果效）者，此处即许为胜义有；凡不具作用能力者，则许为世俗有；此二者，即自相与共相之定义。"（译注：此颂出自《释量论》第三品第三偏。）

如是所说：具自相、具作用能力之物，即胜义谛；此处于观察名言中有无自相之际，凡具自相、具作用能力之物，即安立名为"胜义"；具共相、非实法、不具作用能力者，则安立名为"世俗谛"。然而此种二谛安立方式，唯于观察名言中自相有无之场合中方是如此，并非说此宗别无其他安立二谛之方式。

## 三、唯识（心识唯）宗

其三，依唯识宗之理，一切法皆判定为遍计、依他、圆成三性之自性。《大乘经庄严论》云："三性各具三种显现。"（大意：遍计、依他、圆成三自性，各各皆有其显现方式。）

如是所说：凡摄于境、义、心（译注：藏文原文作"ཡུལ་དོན་སེམས"，英译者按语疑此处或有笔误，通常此语多作"处、境、身"〔即器世间、根之对境、有情自身〕三者）三者之一切法，皆判定为唯心所摄。遍计所执之能取所取二法，以及依他起之心与心所诸法——凡具迷乱、虚妄性质之法，皆是世俗谛；而依他起之本体，即自明自现之能知（心识），以及此依他起空却遍计能取所取二法之圆成实——此摄属法性与本智者，即许为胜义谛之定义。

## 四、中观宗

其四，中观宗虽有众多支分派别，然此处唯就应成、自续二派而说。

### （一）自续派

首先，自续派之主张：彼宗乃就座后（后得位）中、具有承许（主张）之"名言胜义"这一异门之义而加以阐说；此系主要为渐修根器之人所设之入道方式。

依此宗之理，首先，世俗谛内部又分为正世俗与倒世俗二种。《二谛论》云："世俗复分为正与非正〔二种〕。"（译注：此颂出自寂护论师弟子智藏〔Jñānagarbha〕所著《二谛分别论》第十二偏。）即许具自相、具作用能力之物为正世俗，许具共相、不具作用能力之物为倒世俗；故如是，未经观察胜义之正理加以析辨、未经观察抉择之世间共许可悦之自性，即许为世俗谛。

至于胜义，《中观庄严论》云："自宗与他宗所说此等诸事物，真实中因离一多之自性故，其自性不成，犹如影像。"（译注：此颂出自《中观庄严论》第一偏。）如是，以离一多之正理，外内诸法于胜义中亦不成自体；然虽不成，却仍以缘起不灭之自性而显现。空性遣除无有之边，显现遣除实有之边（译注：一般多谓"显现遣除无有〔断灭〕之边，空性遣除实有〔常存〕之边"；然此处堪布阿旺巴桑依循宗喀巴大师《三主要道论》之说，更进一步而言：正因诸法之显现即已遣除执为实有之边——因为诸法要能显现，必须本自无有自性；复因诸法之空性即已遣除执为无有之边——因为正唯诸法是空，方能如是显现）——空性与缘起不可分割之双运自性，此即判定为离边、无有承许之自性，是为胜义谛。

然当某时进入与等持（入定）相顺之阶位时，先前以心识次第判定"有""无""双运""离边"此四者，因彼等仍未超出心识分别之范畴，故仍未证得离心之中观密意；唯有当一切法趋入离于"是""非"诸戏论之法界之时，此离于四边承许之境，方与中观应成派密意要害相同一致。

### （二）应成派

应成派者，彼宗以等持（入定）中离一切承许为宗，以顿悟根器之人为主要所化对象。此宗所应破之细微所破，即是自续派"于世俗中执为有、于胜义中执为无"这一细微执着之部分。月称论师云："犹如欲求水者不能没有容器，〔于名言中〕亦须毫无疑虑地承许世俗谛。"（译注：此语出自月称论师《明句论》。）

如是所说：对此仅属缘起、如是而已之世俗，不加观察，先将其作为基础而承许，再以中观四大论式，判定一切法为离四边或八边戏论之自性。故本无需再承许诸法本性无生之理，因"有无理由"等一切承许，皆属心识之法；此处所指，乃是以超越心识之各别自证智慧所照见之理，以此戏论方能真实寂灭之故。

如是，即是离一切承许之中观应成宗。然于后得位中，摄受自己之弟子，安立道地次第之时，则相对于此仅属缘起、如幻之诸法，以及彼等对方持二取显现者而言，则一切名言中因果之安立，悉皆合理成立。因有显现，故安立为世俗谛；而彼显现自显现之当下，即已安住于离边之自性中——此即许为胜义谛。

对此，此处有一类论师主张："此处并非要破除显现本身，唯是须遣除执彼为实有。"依此教证之言，而将中观密意依己方主张而解说者，依彼而言：以观察名言之量所寻获之义，即是世俗谛；以观察胜义之量所寻获之义，则许为胜义谛。所谓世俗，即唯是名言假立、唯由施设而有：以"唯名"一语，遣除自续派所许具自相之实物；以"施设而有"一语，说明一切法皆由心识向外施设安立，凡所摄之境，非由其自身安住之方式而成立、唯是施设而已之法——许为世俗谛。至于胜义，则显现本身并非所破之对境，所应破除者，乃是执彼显现为实有之执着；譬如：柱子一类之事物，其本身之体不被遮破，而须破除者是其"实有"——既遮破柱子实有之"有"，虽由此而成立"无"，然此"无"亦并非再被遮破；假若此"无"亦被遮破，则将转而成立"有"，故此"无"本身不被遮破。如是遮破"实有"所显之空性——即以柱子等无实之有法与其相俱之空性，即是胜义谛。诸师如是主张。
