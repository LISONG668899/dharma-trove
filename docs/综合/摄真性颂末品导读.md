# 谁能看见吠陀说的那件事——《摄真性颂》末品「超越根识境者观察品」导读与串讲

八世纪的那烂陀，静命论师用三千六百余颂的《摄真实论》（Tattvasaṃgraha），逐一清算了印度诸家哲学的根本主张。这部书至今没有汉译全本，窥基、法藏、澄观都未曾听闻这场辩论。末品「超越根识境者观察品」是全书收官之作，处理的问题极其根本：一个宗教传统凭什么可信？

以下的译讲，是一路逐字勘定丹珠尔原文得出的——哪些偈颂已经字斟句酌地译出，哪些段落还只是靠结构标记定位，文中会随处标明。

## 一、破题：柱子倒了，才有这一品的问题

弥曼差派（Mīmāṃsā）的立场极端而自洽：吠陀无始以来自在，没有作者，因而不可能有错。静命在前一品已经拆掉这根柱子——语言必有生灭，"无作者"立不住。柱子一倒，问题翻转到这一品的开篇：

```
དེ་ལྟར་ཚད་མ་ཐམས་ཅད་ནི། །རང་ལས་ཚད་མ་ཉིད་མི་གནས། །
དབང་པོ་ལས་འདས་དོན་རིག་པའི། །སྐྱེས་བུ་གྲུབ་ཕྱིར་འབད་མི་དགོས། །
```

如是一切能量法，量性不住于自身；超越根境知义士，成立彼者无须劳。

——量若不能自证，权威就必须外求。这句"无须劳"是反语：接下来五百余颂，恰恰要为"成立此士"而劬劳。

## 二、对手的四重防线

弥曼差师的应对极见手腕，可拆成四层，每一层都逐句译出过。

**缩小靶心**——他不去正面守"无人遍知"这个大命题，而是釜底抽薪：

```
འདིར་ནི་ཆོས་ཤེས་ཉིད་དགག་པ། །འབའ་ཞིག་ཉེ་བར་མཁོ་བ་ཡིན། །
གཞན་ནི་ཐམས་ཅད་ཤེས་ན་ཡང་། །སྐྱེས་བུ་གང་གིས་གནོད་པར་འགྱུར། །
```

于此，我等所需者唯是遮遣「知法者」而已；除此之外，纵许有人遍知一切，于我复有何损？

真正能威胁吠陀权威的，从来不是"知道一切"，而是"知道该不该做这件事"。"遍知"两个字，他索性大方让出去。

**能力有边界**——这是最有常识感染力的一击，一连串对仗类比：

```
རྣ་བས་རྟོགས་བྱའི་སྒྲ་རྣམས་ལ། །རིང་དང་ཕྲ་སོགས་དམིགས་པ་ཡིས། །
སྐྱེས་བུ་ཕུལ་བྱུང་མཐོང་བ་ཡིན། །གཟུགས་སོགས་དམིགས་པ་མ་ཡིན་ནོ། །
```

以耳所能了达之声，若能缘及遥远、细微等，此人于闻声一事上乃为殊胜，然非谓其能缘及色等。

听觉再敏锐也换不来视觉，通语法的不懂天文，跳得再远终归有限——能力可以精进，但精进只能在同一种类里加深，绝不会因为熟练就跨界成为另一种能力，更不可能跨到"超感官"这个量级。

**远隔无由得见**——空间与时间上的封堵：

```
ཁང་དམིག་གཅིག་ལ་གནས་པ་ཡི། །མངོན་སུམ་གང་ཞིག་འཇུག་པར་འགྱུར། །
དེ་ཉིད་དུ་ནི་དེ་མཐོང་ནུས། །ཁང་དམིག་གཞན་ལ་མ་ཡིན་ནོ། །
```

安处一室之现量，唯能运行、照见此室本身，而不能及于其余诸室。

**结论**——直接照见超根之境者，实无一人：

```
དེ་ཕྱིར་དབང་འདས་དོན་རྣམས་ལ། །དངོས་སུ་ལྟ་བ་པོ་ཡོད་མིན། །
```

是故，于超越根识之境，实无有能直接照见之者。

（约第53至194颂，弥曼差师的立场继续展开——渐次知与顿时知的两难，对"吠陀永恒之言能否被见"的攻击，用因果逻辑质疑"凭部分推知全体"的可能性。骨架清楚，逐颂细译尚未铺开。）

## 三、翻盘：不比感官的上限，比"看见"的对象是什么

真正的转折出现在第199颂前后。静命不跟对手争"谁的感官更厉害"——那场比赛他必输。他换了个层面：

```
ལྟ་བ་ངན་པ་འཇིག་བྱེད་པ། །གདུལ་བྱ་རྣམས་ལ་ཕན་པའི་ཕྱིར། །
བདག་མེད་དེ་ཡིས་གསལ་བར་གསུངས། །
```

为摧毁恶见，为利所化，故以此明说无我。

佛所知的，从来不是"数清一身有多少根毛"那种穷举式的遍知，而是照见贯穿一切法的共通体性。第211颂把正面主张说得极直白：

```
དངོས་པོ་ཀུན་ལ་གནས་པ་ནི། །དེ་ཉིད་དངོས་སུ་མཁྱེན་པས་ན། །
བདེ་བར་གཤེགས་རྣམས་ཀུན་མཁྱེན་ཡིན། །
```

由现见诸法所共具之真实性故，诸善逝即是遍知。

抓住共相，实质上就懂了殊相——这是把"遍知"的定义从"信息总量"换成了"洞见深度"。

## 四、洞见从哪里来：无限精进的论证

对手完全可以追问：这份洞见怎么长出来的？答案落在第283颂前后，是全品最见巧思的一段。

先承认能力确有强弱——鹫鸟天生望极远，各人根性不同（此处已抽样核对，未逐颂细译）。真正的反击紧接其后：他把一切精进的过程分成两类。有一类确有内在极限——弥曼差师自己举过的例子，十肘之内跳跃，练一百遍也跳不出一由旬；但慧与悲不是这样：

```
འོན་ཀྱང་ཤེས་རབ་བརྩེ་སོགས་ནི། །གོམས་པས་འཕེལ་བར་མཐོང་བའི་ཕྱིར། །
དེ་ནི་འཕེལ་བར་འགྱུར་བས་ན། །ཕུལ་བྱུང་གཞན་ཡང་རྟོགས་པར་འགྱུར། །
```

然智慧、悲心等法，以串习故现见增长；以能增长故，亦能通达更殊胜之余义。

```
ཡིད་ཀྱི་ཡོན་ཏན་ཉིད་ཀྱིས་ནི། །དེ་དག་རབ་ཀྱི་མཐར་ཐུག་ཡིན། །
```

以是心之功德故，彼等有究竟圆满之点。

慧、悲随观修反复增长，从未观察到一个天然封顶之处；找不到极限，理论上便存在一个"圆满至极"的点——这便是遍知。跳跃有极限，是跳跃本身的物理结构决定的；心之功德没有观测到极限，这足以推翻"一切能力皆有边界"这条命题的必然性。第289颂给出这套理论的判准：

```
ཆོས་ཀུན་རྟོགས་པའི་ངོ་བོ་ནི། །ཤེས་རབ་མཚན་ཉིད་ཀྱིས་ནི་གནས། །
གཅིག་ནི་ཡོངས་སུ་མ་ཤེས་ན། །དེ་ཉིད་རྫོགས་པར་མི་འགྱུར་རོ། །
```

通达一切法之体性，即安立为慧之相；若于一法未能遍知，则此慧即不得圆满。

紧接着，他换了个模型说明"圆满"是怎么回事——不是往上堆积信息，而是向下去除遮障：

```
གསེར་གྱི་དྲི་མ་ལ་སོགས་བཞིན། །དེ་ལྟར་ཉོན་མོངས་པ་དང་ནི། །
ཤེས་བྱའི་སྒྲིབ་སོགས་འདི་དག་ནི། །ཇི་སྐད་བཤད་པའི་ཆོས་ལྡན་ཡིན། །
དེ་མེད་དྲི་མེད་བློ་འབྱུང་འགྱུར། །
```

犹如金中所具之垢秽等，如是烦恼与所知障等，亦具前说之法性；彼若无，则无垢之智生起。

```
འོད་གསལ་ཀུན་མཁྱེན་ཉིད་འབྱུང་འགྱུར། །
```

彼等既至究竟圆满，光明遍知即得生起。

金子的光洁不是外加的，是砂石磨去之后自然显现的——遍知不是知道得更多，而是遮蔽清除之后，心本有的照见自然朗现。这也回应了第一段"一室之现量出不了那一室"的譬喻：局部性本身是遮障造成的假象，不是心的本质。

（第300至440颂这一大段，目前只做过结构抽样，铺陈的是这套论证的细节，逐颂细译尚未展开。）

## 五、为什么教主说法前后不一？——悲心的解释，以及一次对种姓特权的反击

对手换角度：教主对不同人开不同的药方，前后说法不一，这不正说明他有局限？静命把答案安在悲心上：

```
དེ་དག་དེ་ལྟར་ཉེར་བསྟན་པ། །དེ་འདྲ་རང་དོན་བསྒྲུབ་ཕྱིར་མིན། །
དེ་དག་གི་རྩོམ་མ་ལུས་པ། །དེ་འདྲ་གཞན་གྱི་དོན་དུ་ཡིན། །
```

彼等如是近为教示，非为成办自利故；彼等所造无余，皆是为利他而作。

```
ཐུགས་རྗེ་གཞན་དབང་གྱུར་པ་ནི། །དེ་ཉིད་གསལ་བར་གཟིགས་པ་ཅན། །
དམིགས་བསལ་ཀུན་ལ་དོགས་མེད་པས། །ཐམས་ཅད་དུ་ནི་སྟོན་པར་མཛད། །
```

以他者为所缘之悲心，即是明见真实者；于一切所缘皆无拣择，故于一切处皆施教导。

说法因人而异，是病人各异，不是医生的知见有局限——悲心无差别地对一切众生开放，差异出现在受教者一方。

紧接这一段，静命顺手拆了对方另一条防线——把权威系在婆罗门血统上的主张：

```
རིགས་དང་དུལ་དང་ཕུན་ཚོགས་པའི། །བྲམ་ཟེ་བ་ལང་གླང་པོ་ཆེ། །
ཁྱི་དང་ཁྱི་འཚེད་པ་དག་ནི། །མཁས་པ་རྣམས་ནི་མཉམ་པར་བལྟ། །
```

种姓与调伏、圆满具足之婆罗门，牛、象，犬与食犬肉者——智者皆平等而观。

（这一譬喻的用语，与印度思想史上"智者视婆罗门、牛、象、犬乃至食犬者皆平等"这一著名意象遥相呼应，是跨宗派共享的一个论辩母题。）

```
ལན་བརྒྱར་རིགས་ནི་བཀག་བྱས་པས། །རིགས་ཀྱིས་རྒྱགས་པ་ཅི་ཕྱིར་བྱེད། །
```

种姓百番已被遮遣，何故犹以种姓自负？

```
གང་དག་སྡིག་པ་སྤངས་བྱས་པས། །དོན་དམ་པ་ཡི་བྲམ་ཟེ་ནི། །
དྲི་མེད་བདག་མེད་གོམས་བྱེད་པའི། །དེ་དག་ཐུབ་པའི་བསྟན་པ་ཡོད། །
```

以断恶故，究竟胜义之婆罗门——即彼修习无垢无我者，方为具足能仁之教法。

真正能作依止的，是断恶修净的实质，不是出身。一场认识论辩论，在这里延伸成了一次对种姓特权本身的批评。

## 六、狮子吼与试金石

论辩收束为一句"狮子吼"，摧折骄慢外道之后，是那句后来被反复引用了一千三百年的话：

```
དགེ་སློང་དག་གམ་མཁས་རྣམས་ཀྱིས། །བསྲེགས་བཅད་བརྡར་བའི་གསེར་བཞིན་དུ། །
ཡོངས་སུ་བརྟགས་ལ་ང་ཡི་བཀའ། །བླང་བར་བྱ་ཡི་གུས་ཕྱིར་མིན། །
```

如烧、截、磨炼之金，比丘与智者当善观察而后取我语，非因恭敬故。

弥曼差主张吠陀因"无人可以为它负责"而绝对可信——一种不容检验的权威。静命一路论证下来，可信的基础恰恰相反：正因经得起检验，才可信。

## 七、品末的定义

```
ཉོན་མོངས་མ་ལུས་དགྲ་བོ་ཡི། །ཚོགས་ནི་འཇིག་པར་བྱེད་པ་ཅན། །
མངོན་པར་མཐོ་བ་སྣ་ཚོགས་ཀྱི། །རྫོགས་རྒྱུ་མྱ་ངན་འདས་ཐོབ་རྒྱུ། །
ཐུན་མོང་མིན་པའི་ཐབས་རྙེད་པ། །སྐྱེས་བུ་མ་ལུས་དང་མི་མཐུན། །
གཅིག་པུ་དེ་ཉིད་ཀུན་མཁྱེན་མགོན། །དེ་ནི་ཚད་མ་དང་ལྡན་ཡིན། །
```

摧毁无余烦恼怨敌之聚者，是种种增上生圆满之因、涅槃可得之因，得不共方便者，与一切士夫皆不同——唯彼一人，即是遍知怙主，彼即具足量者。

与全论开篇"一切能量法不住于自身"遥相呼应：论证的起点是追问"量从哪里来"，五百余颂之后，立起来的不是一部无作者的永恒经典，而是一个通过无边际的修行清除遮障、以悲心回向利他的人格。

---

一千三百年前，这场辩论在那烂陀发生，梵本传入藏地，被认真译出、疏解、传习，却始终没有渡过喜马拉雅进入汉语。这些偈颂，是第一次被这样逐字勘定、译出、连成一篇——不敢说这就是"接续绝学"，只是想让这场迟到的对话，第一次真正被汉语听见。
