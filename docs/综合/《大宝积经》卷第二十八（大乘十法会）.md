# 《大宝积经》卷第二十八（大乘十法会）

元魏·三藏法师佛陀扇多 译

【按】本会同本异译有《佛说大乘十法经》（梁·僧伽婆罗译）一卷，以下异本对照即指此经。

## 大乘十法会第九

### 净无垢宝月王光菩萨请问

如是我闻：一时，婆伽婆（世尊）住在王舍大城耆阇崛山中，与大比丘众五百位大阿罗汉在一起，菩萨摩诃萨无量无边。

那时会中有一位菩萨摩诃萨，名叫净无垢宝月王光，即从座起，整理衣服，偏袒右肩，右膝胡跪在莲花台上，来到如来所，合掌向佛，说道：“世尊！修行大乘、安住大乘的比丘，怎样修行大乘？怎样安住大乘？世尊！以什么意义，这大乘名为大乘？又以什么意义名为安住大乘？”

【按】“䠒跪”之“䠒”，先前电子文本未能显示，今据《大正藏》补出；元、明、宫本作“互”。“䠒跪”即胡跪。菩萨名，异译作“净无垢妙净宝月王光”。

那时，世尊告诉净无垢宝月王光菩萨摩诃萨说：“善哉，善哉！净无垢宝月王光！善男子！你善能问这甚深的义理。仔细听，仔细听，好好思念，我现在为你分别解说。”

那时，净无垢宝月王光菩萨摩诃萨听到佛允许，就对佛说：“是的，世尊！我顶受圣教。”

### 十法总标

佛说：“善男子！菩萨摩诃萨成就十种法，就是修行大乘，就是安住大乘。哪十种？第一，信成就；第二，行成就；第三，性成就；第四，乐菩提心；第五，乐法；第六，观正法行；第七，行法顺法；第八，舍离慢与大慢；第九，善解如来秘密之教；第十，心不希求声闻、缘觉乘。”

【按】第七“行法慎法”，下文释作“观法顺法”，异译作“行于正法及顺法”，“慎”当作“顺”，今从之。

### 第一，信成就

那时，净无垢宝月王光菩萨摩诃萨对佛说：“世尊！怎样是菩萨摩诃萨的信成就？”

佛说：“善男子！菩萨摩诃萨行不谄曲之行，得柔软之行。那菩萨相信诸如来正真正觉的无上菩提；相信诸如来在一念之中宣说三世之事；相信如来藏不老不死，无量无边，不生不灭，不常不断；相信诸佛的实际、法界、一切智、一切智人所知的力、无所畏与不共佛法；相信诸如来的无见顶相；相信诸如来以三十二相、八十种好庄严其身，身有圆光；相信声闻所说、缘觉所说、菩萨所说，以及相信所有善妙的言说；相信此世与他世；相信行正行、住正行的人，无论是沙门还是婆罗门；相信善业的果报甚可爱乐，微妙最胜，就是或为天中的天主，或为人中的人主；相信不善的果报不可爱乐，苦恼无量，或在地狱，或在饿鬼，或在畜生。

“那菩萨这样相信之后，就远离三种法：一是疑，二是惑，三是不决定。善男子！菩萨摩诃萨成就这样的信，名为信成就。”

那时，世尊为了显明这个意义，以偈重说道：

```
信为增上乘，信者是佛子，
是故有智者，应常亲近信。
信是世间最，信者无穷乏，
是故有智者，应常亲近信。
若不信之人，不生诸白法，
犹如烧种子，不生根牙等。
```

（大意：信是增上之乘，有信的人是佛子，所以有智慧的人应当常常亲近信。信是世间最殊胜的，有信的人不会穷乏，所以有智慧的人应当常常亲近信。不信的人，生不出诸白净之法，犹如被烧过的种子，生不出根与芽等。）

【按】“根牙”之“牙”，宋、元、明、宫本作“芽”。

### 第二，行成就

#### 出家修学，灭三恶业

“善男子！怎样是菩萨摩诃萨的行成就？善男子！菩萨摩诃萨因为行成就，剃除须发，披上正法之服，舍家出家。出家之后，修学菩萨的戒行等事，修学声闻的戒行等事，修学缘觉的戒行等事。菩萨这样修学之后，身口意等恶业全都灭除。

【按】“行成就故”之“行”，宋、元、宫本作“信”。“修菩萨如是学已”之“修”，宋、元、明、宫本作“彼”。

“什么名为身不善业？就是杀生、偷盗、邪淫，用瓦石刀杖欺掷他人，伤人手足等，或来或去行欺凌之事。善男子！这些名为身不善业。

“善男子！什么名为口不善业？就是妄言、绮语、两舌、恶口，不善的言说，诽谤正法甚深经典，宣说诸和上、阿阇梨等住于正法之人所有的过失短处，这些名为口不善业。

“善男子！什么名为意不善业？就是嫉妒、悭吝、邪见，增上的嫉妒悭吝，乐于利养、乐于称誉、乐于亲爱等；家族之慢、容色之慢，恃少壮之慢、恃无病之慢、恃寿命之慢、恃多闻之慢、恃修行之慢；欲觉、害觉、瞋恼觉等，以及国土之觉、衣服等觉；执著住处、执著车乘、执著敷具等，执著饮料、执著食物以及执著儿女、犁牛耕种诸所作之事等；忧虑奴仆、忧虑婢女、忧虑诸作者、谷帛库藏诸财物等。那菩萨这样执著之后，在前面所说的种种事中若失去一件事，他的心就生起忧悲苦恼。那菩萨以爱润泽其心，所以生起后有的萌芽之心。善男子！略说意业犹如轮转，这名为意不善业。

【按】“姤悋”之“姤”，宋、元、明、宫本作“妒”。

#### 惭

“那菩萨远离身等不善业，对和上生起尊重之想，对阿阇梨生起和上之想，对其余或老或少的人生起恭敬。那菩萨在独处时这样思惟：‘我不应这样——我已发起度一切众生、救一切众生之心，要令一切众生住于正定之行中。’那菩萨这样思惟：‘我现在自身不调伏诸根，不勤修行，不守护诸根，不调伏诸根。’那菩萨这样思惟：‘现在我若已作这样的修行，这些众生见到我后，心就调伏，随顺我的教导，诸佛欢喜，以及诸天、龙、乾闼婆等都欢喜。’善男子！这样的修行名为菩萨的惭。

【按】“如是等行”之“行”，宋、元、明、宫本无。

#### 愧

“那菩萨这样思惟：‘不要让出家人或在家人，在我的身口意等业诸威仪中诃责我，就是（诃责我）毁坏戒行，或作邪见之行，或作恶行之行，或行邪命。’那修行的菩萨这样惭之后，日夜系心观察戒行；观察戒行之后，没有忧悔，远离诸障碍。菩萨这样正确修行之后，在诸如来的正法之中修习诸行。善男子！这样的修行名为菩萨的愧。善男子！菩萨摩诃萨成就这样的行，名为行成就。”

【按】“观戒行已”之“已”，《大正藏》作“己”，CBETA 校改作“已”。

那时，世尊为了显明这个意义，以偈重说道：

```
行为增上乘，诸佛缘觉等，
是故智者修，彼等微妙事。
菩萨大名称，无畏行成就，
是故证菩提，诸佛本所说。
```

（大意：行是增上之乘，诸佛、缘觉等都由行而成，所以智者修习他们那些微妙之事。菩萨具大名称，无畏而行成就，所以证得菩提，这是诸佛本来所说的。）

【按】“彼等微妙事”，明本“彼”作“行”，宫本“等”作“业”。

### 第三，性成就

“善男子！怎样是菩萨摩诃萨的性成就？善男子！菩萨摩诃萨禀性自然少欲、少瞋、少痴，不悭吝，不涩滞，不粗犷，不我慢，不急暴，调和柔软，善言软语，容易共住。那菩萨对一切上等殊胜的供养，都如心意而行布施；所有诸物，衣服饮食，都分舍给他人；这样布施之后，就生起欢喜，遍满身心；像这样乃至舍弃身体的上等部分。善男子！那菩萨行这样的行，若见到如来，若见到声闻，见了就生起欢喜之心。善男子！菩萨摩诃萨成就这样的法，名为性成就。”

那时，世尊为了显明这个意义，以偈重说道：

```
相烟即知火，见鸳鸯知水，
异相知菩萨，菩萨大智慧。
不涩不恼众，舍诸谄曲行，
善信众生故，是名菩萨性。
```

（大意：看到烟的相，就知道有火；见到鸳鸯，就知道有水；由殊异之相，就知道是菩萨，菩萨有大智慧。不涩滞、不恼害大众，舍弃诸谄曲之行，善能使众生信服，这名为菩萨之性。）

### 第四，乐菩提心

#### 四种发菩提心相

“善男子！怎样是菩萨摩诃萨的乐菩提心？善男子！菩萨摩诃萨因为有菩提之相，所以发菩提心；尚未发菩提心时，或有诸如来，或有诸声闻劝他发菩提心。善男子！这是菩萨初发菩提心之相。

“善男子！那菩萨听闻有菩提，听闻菩提心有大功德，听闻发阿耨多罗三藐三菩提心，这是菩萨第二种发菩提心之相。

“善男子！那菩萨见到诸众生无主、无亲、无救、无护，无人能度他们到达彼岸；菩萨就为那些众生生起慈悲心，而这样说：‘我当对那些无主、无亲、无救、无护的诸众生等作救护。’为了那个因缘，发阿耨多罗三藐三菩提心，这是菩萨第三种发菩提心之相。

【按】“无能度之令至彼岸”之“令”，宫本作“今”。

“善男子！那菩萨因为见到如来相好具足之身，生起欢喜心，生起勇悦心，心生欢喜，以这个因缘发阿耨多罗三藐三菩提心，这是菩萨第四种发菩提心之相。

#### 修行六度

“善男子！那菩萨为了令那些众生得到利益安稳快乐，修行布施、持戒、忍辱、精进、禅定、般若。

“善男子！怎样是菩萨修行布施？善男子！菩萨这样思惟：‘我应当怎样行布施？’就生起念头说：‘需要食物的施给食物，需要饮料的施给饮料，需要床敷的施给床敷，需要衣服的施给衣服，指环、臂钏以及宝冠等所需之物，都施给他们。’善男子！菩萨乃至割下自身之肉施给众生；这样行施，愿取阿耨多罗三藐三菩提，而不取著受者与财物，不住于施事等，这名为菩萨修行布施。

【按】“须衣服者”之“须”，明本作“施”。

“善男子！菩萨怎样修持戒？善男子！那菩萨先自己调顺身业，调顺口业，调顺意业；菩萨自身所有的恶业一切舍离，所有口的恶业一切舍离，所有意的恶业一切舍离，持戒不缺、不漏、不杂。菩萨这样持禁戒之后，回向阿耨多罗三藐三菩提，而心终不取著于戒，这名为菩萨修持戒。

“善男子！怎样是菩萨修行忍辱？善男子！菩萨若听到出家人或在家人，乃至毁骂他，听到他们说自己的恶，或者被打、被系缚、被囚禁，或被截断手足，都能忍受，对那人生起忍辱之心。菩萨这样修行忍辱之后，回向阿耨多罗三藐三菩提，不因那忍辱而生起慢心，这名为菩萨修行忍辱。

“善男子！菩萨怎样修行精进？善男子！菩萨这样思惟：‘如虚空界无量无边，众生界也无量无边，唯有我一人独自没有同伴，要令（众生）入于无余涅槃界中。’这样，菩萨为了那个因缘，发起精进之行，先持守自身；持身之行完成后，观察受、心、法；这样正确观察受、心、法之后，行持心之行；菩萨行持心之行后，其次又修行见法等行。菩萨这样持守心意之后，为了令未生的恶不善法断而不生，发起欲心，勤加精进；为了令未生的善法生起，发起欲心，勤加精进。菩萨这样其次又修行初如意足，这样修行第二、第三乃至第四如意足。修这样的行而不生起慢心，这名为菩萨修行精进。

“善男子！菩萨怎样修行禅定？善男子！菩萨不执著欲，不执著灭，不执著离欲，不执著自身，不执著他身，不执著色、受、想、行、识，不执著欲界，不执著色界，不执著空，不执著无相、无愿，不执著此世界，不执著未来世界，而行布施；不依止布施，不依止持戒，不依止忍辱，不依止精进，不依止禅定；这样修行禅定，回向阿耨多罗三藐三菩提而不分别，这名为菩萨修行禅定。

“善男子！菩萨怎样修行般若？善男子！菩萨常这样思惟而教化众生，教化众生之后又这样想：‘我教化无量无边的众生界，令入于无余涅槃界中，而没有一个众生入于涅槃界。为什么？如佛所说，一切诸法无我、无众生、无命、无养育者、无补特伽罗。’这样修慧，而以那智慧回向阿耨多罗三藐三菩提，作这样的愿，而对智慧不生分别，这名为菩萨修行般若。善男子！菩萨摩诃萨这样发菩提心，名为菩萨乐菩提心。”

那时，世尊为了显明这个意义，以偈重说道：

```
犹如真宝珠，光明不舍离，
又如矿中金，治已转增明。
如是菩提性，转明菩提心，
二边清净已，魔所不得便。
```

（大意：犹如真正的宝珠，光明不会舍离；又如矿中的金子，冶炼之后更加明亮。这样的菩提之性，使菩提心更加明亮，二边都清净之后，魔就不能得便。）

【按】“如是菩提性”之“菩提”，明本作“菩萨”。

### 第五，乐法

#### 于法师起种种想

“善男子！怎样是菩萨摩诃萨的乐法？善男子！菩萨摩诃萨禀性自然乐法、喜法、以法润心。若见到沙门或婆罗门如法之人，随其所有之物都奉献给他，饮食等一切都施与，乃至合掌，生起恭敬之心；生起恭敬之后，从他那里听闻未曾听过的法。菩萨这样求得正法之后，如实修行。

【按】“如法人”之“如”，宋、元、明本作“知”。

“菩萨对那持法的法器，生起尊重之想，生起和上之想、阿阇梨之想，生起这样的念头：‘我从过去以来，久已失去导师，现在忽然遇到了。’生起导师之想。

“又这样想：‘我常被系缚在世间的牢狱中，无人解救，无人寻访，现在忽然遇到了。’生起寻访之想。

“又这样想：‘我从久远以来，在世间昏睡，愚痴盲目，忽然在现在令我的眼睛睁开。’就生起觉醒之想、开示之想。

“又这样想：‘我从久远以来沉没在深泥之中，无人拔济，现在忽然遇到了。’生起拔济之想。

“又这样想：‘我从久远以来失去引导众生的导师，现在忽然遇到了。’生起导师之想。

“又这样想：‘我从久远以来被关在世间，处于贫苦艰难之处，无人救接，现在忽然遇到了。’所以就生起救接者之想。

“又这样想：‘我从久远以来患上难愈之病，没有良医能够治疗，现在忽然遇到了。’生起良医之想。

“又这样想：‘我从久远以来被贪欲之火所焚烧，未曾蒙受云雨，现在忽然遇到了。’所以就生起大云雨之想。

【按】“又作是念”之“又”，宫本作“久”。

#### 为一句法不惜受苦

“菩萨这样，为了那个因缘，忍受寒热等诸苦恼之事，以及诸众生中能恼人的，如蚊虻等，都能忍受，也能忍受饥渴等事。见到享乐的众生，不生执著之心。那菩萨这样想：‘我虽然能享受世间的快乐，（不如）若我听闻一句法后能成就闻慧。’生起闻慧之想。

“菩萨以这乐法的因缘，所以行布施而不生忧愁，乃至没有忧苦等事。菩萨这样远离一切忧苦等事，生起这样的心：‘我为了得闻如来所说的一句法，乃至入于阿鼻地狱，寿命一劫，或百千劫，也不疲倦。不疲倦之后，修行一切种智；若有尚未得到佛正法的人，能令他们得到。’善男子！菩萨摩诃萨这样乐法，名为菩萨乐法。”

那时，世尊为了显明这个意义，以偈重说道：

```
大智求法者，所谓诸菩萨，
求法无厌足，以恭敬心故。
当求于正法，是名菩萨相，
闻已常忆持，复如法修行。
```

（大意：有大智慧而求法的人，就是诸菩萨；他们求法没有厌足，因为有恭敬之心。应当求于正法，这名为菩萨之相；听闻之后常常忆持，又如法修行。）

【按】“当求于正法”之“当”，宋、元、明、宫本作“常”。

### 第六，观正法行

“善男子！怎样是菩萨摩诃萨的观正法行？善男子！菩萨摩诃萨作这样的观察：

“一切法如幻，因为诳惑凡夫；（凡夫）愚痴覆心，因为没有正慧；一切法虚妄如梦，因为只是心念；一切法如水中之月，因为不是实有之事；一切法如镜中之像，因为没有众生；一切法如回响，因为是空声所生；一切法有生灭，因为由因缘而成；一切法不生，因为是真如之性；一切法不灭，因为本来无生；一切法无作，因为没有作者；一切法如虚空，因为没有染污；一切法寂静，因为体性无染；一切法离垢，因为远离一切垢；一切法永灭，因为本来灭除烦恼；一切法无色，因为不可见；一切法远离心、意、意识，因为没有身；一切法无住，因为灭除一切阿梨耶；一切法无求，因为远离此与彼的亲爱；一切法无著，因为远离一切烦恼境界；一切法如蛇，因为（若）没有方便咒术之力（就会受害）；一切法如芭蕉，因为不坚实；一切法如水沫，因为其性无力。

【按】“阿梨耶”，即阿赖耶。

“善男子！菩萨摩诃萨这样观正法行，名为菩萨观正法行。”

那时，世尊为了显明这个意义，以偈重说道：

```
一切法如幻，覆众生心故，
虚妄犹如梦，应如是受持。
诸法如水月，以影像起故，
诸法如镜像，智何不觉知？
```

（大意：一切法如幻，因为覆蔽众生之心；虚妄犹如梦境，应当这样受持。诸法如水中之月，因为由影像而起；诸法如镜中之像，有智慧的人怎会不觉知？）

### 第七，观法顺法

#### 不灭色而证法界

“善男子！怎样是菩萨摩诃萨的观法顺法？善男子！菩萨摩诃萨观察色是无常，而不因灭除色而证入法界；以如实之智，对法界中所有诸法如实觉知诸法之相后，善能记持、善能修习那法界中所有诸相；（对其中）有所说者、修者、记者，自然这样入于法界之行。

“像这样乃至受、想、行、识，以如实观察；正确观察之后，而不灭除识，不厌离识，证入法界。所有法界中的一切诸法，以真实智慧如实证知；那些法中有诸名字，善说、善知、善修、善记；因为善知、善修、善记，自然这样入于法界之行。如知无常，这样知苦、无我、不净也是这样。

【按】“受想行识”，宋、元、明、宫本作“想受行识”。“知苦”之“苦”，宋、宫本作“若”。

#### 幻化四兵之喻

“观察色是无常，如实善知，对那色中不再生起恐怖之想。为什么？因为如实知道色是虚妄而生的；这样，菩萨如实善知。受、想、行、识都是无常，都是苦、无我以及不净等，对那识中不再生起恐怖之想。为什么？因为如实知道识是虚妄的。菩萨这样如实善知。

“善男子！譬如善巧的幻师与幻师的弟子，幻作种种四兵等事，就是象兵、马兵、车兵、步兵，智者见了不生恐怖。为什么？因为善知这是虚妄、是幻师所作，诳惑众生而示现的。

【按】“幻所作”，宋、元、明、宫本作“幻师所作”，今从之。

“善男子！菩萨这样观察色是无常，观察无常之后，其中不生恐怖之想。为什么？因为如实知道色是虚妄而生的，菩萨这样如实善知。受、想、行、识都是无常，观察无常之后，对于识中不生恐怖。为什么？因为如实知道识是虚妄而生的，菩萨这样如实善知。善男子！菩萨这样观法顺法。”

#### 毒药与事火之喻：向涅槃而不证

那时，净无垢宝月王光菩萨摩诃萨对佛说：“世尊！菩萨怎样观察色是无常，而不离开色而说法界、证法界、习学法界，对一切诸法以智慧之力如实证知？”

那时，世尊告诉净无垢宝月王光菩萨摩诃萨说：“善男子！因为你问，我现在说个比喻。善男子！譬如世间有智慧的人持有诸毒药；持有毒药后，或煎或熬，或与其他药相合；与其他药相合之后，为了财利而叫卖，却不自己吃。为什么？那人这样思惟：‘不要让我自身由于这个因缘而致丧命。’

“善男子！菩萨摩诃萨心随顺趣向涅槃，心润泽趣向涅槃，心润泽流向涅槃，心正确趣取涅槃，而菩萨摩诃萨不证涅槃。为什么？菩萨这样思惟：‘不要让我自身由于这个因缘而退转菩提。’

“又，善男子！我再说个比喻。善男子！譬如有人奉事于火，他奉事火之后，尊重敬顺，善加护持，却不生起这样的心：‘我供养火，尊重赞叹，善加护持，所以要用两手去捉它。’为什么？那人这样想：‘不要让我自身由于这个因缘而身苦心恼。’

“善男子！菩萨摩诃萨虽然心随顺趣向涅槃，心润泽趣向涅槃，心润泽趣向涅槃之流，心正确趣取涅槃，随顺趣向涅槃之岸，而那菩萨不证涅槃。为什么？菩萨这样思惟：‘不要让我自身以这个因缘而退失菩提之智。’”

#### 弄蛇之喻：住世间而不染

那时，净无垢宝月王光菩萨摩诃萨对佛说：“世尊！依我对佛所说法义的理解，菩萨应当常住于世间。”

佛说：“善男子！是这样，是这样！菩萨应常住于世间。”

这时，净无垢宝月王光菩萨摩诃萨对佛说：“世尊！菩萨怎样住于世间，而不被世间法所染？”

佛说：“善男子！我现在为你以譬喻宣说。善男子！譬如有人善解捉诸禽兽的方便，以咒力与毒蛇嬉戏，捉住诸毒蛇，或含在口中，或在手中摩弄，种种玩弄它们，而终究不因为弄蛇的因缘而被害命终。为什么？因为有善巧的咒术之力。善男子！菩萨摩诃萨住于世间，行世间法，因为有善巧的大智方便咒术之力，与诸烦恼恶毒药嬉戏，玩弄烦恼之蛇，而不因那烦恼的因缘退失菩提。为什么？因为菩萨成就善巧方便与智慧之力。”

#### 比丘得无漏心

那时，净无垢宝月王光菩萨摩诃萨对佛说：“世尊！甚为奇特，世尊！奇哉，善逝！最为难有，世尊！最为难有，善逝！世尊！这些菩萨摩诃萨虽然心向涅槃而不证涅槃，虽在世间而不被世法所染污。世尊！我现在归依诸菩萨。世尊！若有善男子、善女人得闻这样的菩萨之行而生欢喜心，那人过去已种诸善根。为什么？若听闻这法门，乃至一弹指顷生起希有之心，世尊！那些善男子、善女人已为如来所授记。为什么？因为听闻这法门而至心谛听的缘故。”

佛说：“善男子！是这样，是这样！”

说这法门时，五百比丘得到无漏之心。得到无漏之心后，从座而起，整理衣服，偏袒右肩，右膝着地，合掌向佛，说道：“世尊！对诸菩萨，可以如正恭敬善逝那样恭敬，可以礼敬诸菩萨。”

佛说：“诸比丘！是这样，是这样。善男子！菩萨摩诃萨这样观法顺法，名为菩萨观法顺法。”

那时，世尊为了显明这个意义，以偈重说道：

```
应敬大智慧，应敬大无畏，
应敬正服者，应敬佛所生，
以方便力故，智慧善巧故，
超过声闻地，菩萨大智慧。
善知诸阴虚，生灭不定故，
见世间火然，是故不证灭。
```

（大意：应当恭敬具大智慧者，应当恭敬具大无畏者，应当恭敬披着正法之服者，应当恭敬从佛所生者。因为有方便之力，因为智慧善巧，菩萨以大智慧超过声闻之地。他善知诸阴虚妄，因为生灭不定；见到世间如火燃烧，所以不证灭度。）

### 第八，离慢与大慢

“善男子！这样名为菩萨摩诃萨观法顺法。

“善男子！怎样是菩萨摩诃萨离慢与大慢？善男子！所说的慢，是生起这样的心：‘我现在所有的家族、种姓、容色，以及种种金银珍宝诸宝藏等，象兵、马兵、车兵、步兵，都不比别人差。’若人这样生起憍慢之心，这名为慢，因为他不生恭敬之心。

“善男子！什么是大慢？善男子！若有菩萨这样想：‘唯有我的家族、种姓、容色、金银宝藏、象兵、马兵、车兵、步兵胜过别人。’所以不生恭敬之心，这名为大慢。善男子！这样的憍慢以及大慢，菩萨摩诃萨都已舍离。善男子！菩萨摩诃萨就是这样离慢、离大慢。”

【按】此处“慢”与“大慢”，异译作“慢”与“增上慢”。

那时，世尊为了显明这个意义，以偈重说道：

```
离慢离大慢，常行慈悲心，
以彼润心故，于世不放逸。
虽行乞食事，诸菩萨大事，
说义利益事，若诸天及人。
```

（大意：远离慢与大慢，常行慈悲之心，因为以慈悲润泽其心，所以在世间不放逸。虽然行乞食之事，却是诸菩萨的大事，宣说义理，利益诸天与人。）

### 第九，善解如来秘密之教

#### 列举诸密教

“善男子！怎样是菩萨摩诃萨善解如来秘密之教？善男子！菩萨摩诃萨对于诸经中所有隐覆的甚深密义，对那些说法如实善知。

“善男子！什么是如来的密教？善男子！我为声闻授记，说他们得阿耨多罗三藐三菩提，这不应（照字面）这样理解。如我说：‘阿难！我患背痛。’这不应这样理解。对诸比丘说：‘我现在衰老，你们可以为我寻觅侍者。’这不应这样理解。对目连说：‘你可以去问耆婆医王——我所患的病，应当服什么药。’这不应这样理解。

“善男子！如来处处追随诸外道论义争胜，这不应这样理解。善男子！佉陀罗刺刺伤如来的脚，这不应这样理解。善男子！如来又说：‘提婆达多是我的宿怨，常常跟随我寻求我的过失。’这不应这样理解。善男子！如来往昔进入舍卫城，在奢犁耶婆罗门村周遍乞食，空钵而出，这不应这样理解。善男子！旃遮摩那毘孙陀梨以木器合在腹上来诽谤如来，也不应这样理解。善男子！如来往昔在毘兰多国，受毘兰若婆罗门之请，三月安居而吃马麦，这不应这样理解。”

【按】“此不应尔”，异译作“不应如说取”“不随说取”，即不应照字面理解之意，今依此译出。“佉陀罗”，梵语，即佉陀罗木（一种硬木）。

#### 记声闻成佛

那时，净无垢宝月王光菩萨摩诃萨对佛说：“世尊！前面所说的，应当怎样理解？世尊！为什么为诸声闻授记，说他们得阿耨多罗三藐三菩提？”

佛说：“善男子！我为声闻授记，说他们得阿耨多罗三藐三菩提，是因为见到声闻有佛性的缘故。”

这时，净无垢宝月王光菩萨摩诃萨对佛说：“世尊！这些声闻断除诸有漏，远离三有，生分已断，而因为有佛性的缘故，为如来所授阿耨多罗三藐三菩提记，这事怎样理解？”

佛说：“善男子！我现在为你说个比喻。善男子！譬如灌顶转轮圣王具足千子，按最大的儿子授予王位。然而那转轮王因为儿子根钝，应当先教的，延到中期才教；应当中期教的，延到后期才教，一切工巧、咒术等事都是这样。而这王子因为根钝，应当先学的，延到中期才学；应当中期学的，延到后期才学。善男子！你认为怎样？那转轮王的儿子这样学习之后，难道就不是国王的真正儿子吗？”

这时，净无垢宝月王光菩萨摩诃萨说：“不是的，世尊！不是这样，善逝！他是真正的王子。”

佛说：“善男子！菩萨摩诃萨也是这样：因为根钝，应当先学的，延到中期才学；应当中期学的，延到后期才学；这样依观察众生五阴而灭除诸烦恼，烦恼灭除之后，然后得成阿耨多罗三藐三菩提。善男子！你认为怎样？那些声闻以这个因缘得成正觉，难道可以说声闻不得成正觉吗？”

原文：“菩萨摩诃萨亦复如是”（大意：菩萨摩诃萨也是这样。此处以根钝王子比喻声闻，而经文作“菩萨”，照原文译出，存疑。）

这时，净无垢宝月王光菩萨摩诃萨说：“是这样，世尊！我从未见到在人、天、魔、梵这些大众中，有能说声闻不得成正觉的；若有人能这样说，是不可能的，唯除一阐提。”

那时，如来告诉净无垢宝月王光菩萨摩诃萨说：“善男子！我现在为你再说个比喻。善男子！利根的菩萨住于第十地，除去二种无我（之障）而坐于道场，是已除去才坐呢，还是未除去就坐呢？”

这时，净无垢宝月王光菩萨摩诃萨说：“世尊！已除去才坐。世尊！已除去才坐，善逝！”

佛说：“善男子！那利根者以这个因缘，难道可以不得成正觉吗？”

这时，净无垢宝月王光菩萨摩诃萨说：“得成，世尊！得成，善逝！”

那时，如来告诉净无垢宝月王光菩萨摩诃萨说：“善男子！这里（声闻之事）也是这样。”

原文：“除二无我坐道场者”（大意：除去对二种无我（人无我、法无我）的障碍而坐道场。依上下文译出，存疑。）

#### 背痛与寻侍者

那时，净无垢宝月王光菩萨摩诃萨说：“世尊！如来为什么往昔告诉阿难‘我患背痛’？”

佛说：“善男子！我观察后世，怜愍众生，所以这样说：说我背痛，令诸病人这样知道：佛的金刚之身尚且有背痛，何况我们以及其余的人。因为这件事，我说这话。而那些愚人照字面理解，说佛有病，有背痛等，就自己毁坏，也令他人毁坏。”

如来又告诉净无垢宝月王光菩萨摩诃萨说：“善男子！我往昔告诉比丘说：‘我现在衰老，你们可以为我寻觅侍者。’善男子！我说这话，也是为了怜愍、顾念后世而这样说：为了令后世的声闻弟子，年老衰弊时应当有人给侍，所以说这话：‘我现在衰老，需要寻觅侍者。’令未来世的人这样知道后不生退转。因为这个意义，我说这话：‘我现在衰老，你们可以为我寻觅侍者。’而那些愚人照字面理解，（说）如来衰老，所以需要侍者。

#### 遣目连问药

“善男子！应当怎样理解佛告诉目连，令他到耆婆大医王处询问服药之法？善男子！这也是我怜愍后世而这样说：有些声闻借药物来调养身体，他们当忆念我：佛的金刚之身尚且服药，何况我们以及其余的人。因为这件事，我说这话：‘你到耆婆大医王处询问服药之法。’而那些愚人照字面理解，说如来之身是有病患之身。

【按】“假药将身”之“将”，明本作“持”，即借药调养身体。

“善男子！如来往昔告诉目连比丘，令那目连向耆婆问药。耆婆不便正面回答，只说：‘只应当服酥，只应当服酥。’然而这是如来示现业的果报，令诸弟子听了应当忆知而不退还。

【按】“服苏”之“苏”，宋、元、明、宫本作“酥”。“耆婆无容故不正答”之“无容”，依上下文译作“不便”，存疑。

#### 逐外道论义

“善男子！如来处处追随外道尼乾子等争胜论义，这事怎样理解？善男子！我观察后世，愍念众生，所以作这件事，令那些众生这样知道：诸佛如来正真正觉尚且有怨家，何况我们以及其余的人。而那些愚人照字面理解，说佛如来确实有怨家。善男子！转轮圣王凭着少许福德尚且没有怨家，何况如来成就无量无边的功德。

【按】“何故如来”之“故”，元、明本作“况”，今从之。

#### 木刺刺足

“善男子！佉陀罗木刺刺伤如来的脚，这事怎样理解？善男子！如来是示现业的果报，令未来世的人这样知道：如来成就无量功德，尚且有业报，何况我们以及其余的人。以这个因缘，令他们止息恶行；又为了这个因缘，我这样说有这样的业报。而那些愚人照字面理解，（说）佉陀罗木刺真的刺伤了如来的脚。”

#### 提婆达多是善知识

这时，净无垢宝月王光菩萨摩诃萨说：“世尊！提婆达多是佛的宿怨，寻求如来的过失。”

佛说：“善男子！若没有提婆达多这位善知识，终究不能得知如来具有无量功德。善男子！提婆达多是善知识，与我争胜，示现作怨家，使如来的无量功德得以显现。善男子！提婆达多这位善友知识，在宫内对阿阇世王说，令他加害如来；那时国王故意放出护财象王，想要灭除如来。善男子！如来见到大象就调伏了它。那时无量无边的众生见到大象被调伏，生起奇特之心，就生起正信，归依三宝，就是佛宝、法宝、僧宝，这是为了显扬三宝。

“善男子！这样的事应当这样理解：提婆达多是善知识，长久以来跟随，示现为怨家。而那些愚人照字面理解，这样说：‘提婆达多是加害佛的人，是怨家。’善男子！乃至过去五百世中所生之处，提婆达多都是善知识，示现怨家之事，都是示现，用来显扬诸菩萨，以及显扬如来的无量功德。而那些愚人照字面理解：‘提婆达多是加害佛的人，是怨家。’因为这不善于理解义理的因缘，堕入三途之中，就是地狱、饿鬼、畜生诸苦恼之处。

“为什么？善男子！提婆达多这位善知识，善修无量诸殊胜功德，善修善根，亲近诸佛，宿世种植德本，心向大乘，顺向大乘，趣向大乘的彼岸，接近阿耨多罗三藐三菩提。善男子！那些人（对他）坏心的缘故，于未来世生于地狱、饿鬼、畜生诸恶道中。”

#### 空钵而出

那时，净无垢宝月王光菩萨摩诃萨说：“世尊！如来往昔进入舍卫城，在奢犁耶婆罗门村周遍乞食，空钵而出，这事怎样理解？”

佛说：“善男子！我这样做，也是为了愍念后世众生而示现这件事，令未来世的人这样知道：如来具足无量功德，尚且空钵而出，何况我们以及其余的人。

“善男子！又有人说：‘是魔波旬劝那些婆罗门、长者、居士，令他们不肯供养如来。’这也不是这样。为什么？善男子！魔王没有力量能劝长者令他们不供养如来饮食。善男子！这事不应这样理解。为什么？魔王没有力量能遮障对如来的供养；乃是如来劝持魔王，令他对长者、婆罗门等说，使他们不供养。善男子！如来已经灭除一切障碍，成就无量诸殊胜功德，而有人能障碍对如来的供养，那是不可能的。如来没有真实的业果报应，是为了令那些众生得道，如来示现这样方便善巧的种种事。

“善男子！如来若断了一餐饮食，令诸声闻以及魔波旬、天龙八部及诸天子这样想：‘不要令（如来的）眷属为了那些事生起忧苦之心。’所以如来日夜示现这样等事，（使人反思）若生起一念不善之心（会有何过），乃是如来已断诸有，如前示现，后来也是这样。令未来世的人这样知道：如来已断诸有，尚且有这样的事，何况我们以及其余的人。示现这件事时，七万天众在如来所生起清净心；如来那时知道他们的心之后，为他们种种说法，他们听法后得法眼净。善男子！我是为了观察后世而示现这件事，如来没有这样的业报。”

原文：“如来若断一飡食已，令诸声闻及魔波旬、天龙八部及诸天子作如是念：『无令眷属生忧苦心为彼诸事。』是故如来日夜示现如是等事，令发一念不善之心，乃是如来断于诸有”（大意：此段文句曲折，依字面译出，存疑。）

#### 被木盂谤

那时，净无垢宝月王光菩萨摩诃萨说：“世尊！旃遮摩那毘孙陀梨以木器合在腹上来诽谤世尊，这事怎样理解？”

佛说：“善男子！这也不是这样。如来成就无量功德，没有业报之患。善男子！以如来的威神之力，能把旃遮摩那毘孙陀梨等放到超过无量恒河沙数世界之外；而（如来）被诽谤，乃是如来以方便之力示现业的果报。我的诸弟子因为福薄，既得出家在我的法中，若因被诽谤，就会退出我的法，不思量如来的言教，而这样说：‘我们现在已被诽谤，不应再在佛的正法之中。’（如来示现被谤，）令那些人听到教言后忆念：诸佛如来具足成就一切白法，灭除诸恶法，尚且有这样的恶缘被谤，何况我们以及其余的人。这样知道之后，就不再退还，修习清净梵行。

【按】“佛正法”之“正”，宋本作“王”。

“善男子！旃遮摩那毘孙陀梨等生起恶心，以佛的威力，令她在梦中开悟：‘我实在诽谤了佛，我若舍身，必定堕入三恶道。’善男子！如来若知道可以防护的，必定防护，所以示现这样的事。善男子！没有一个众生是如来所舍弃的，所以示现这件事。”

【按】“旃遮摩那毘孙陀梨”，诸经或作旃遮摩那、孙陀利等，是以木盂系腹伪称怀孕而谤佛的女子。

#### 食马麦

那时，净无垢宝月王光菩萨摩诃萨说：“世尊！如来往昔在毘兰多国，受毘兰若婆罗门之请而吃马麦，这事怎样理解？”

佛说：“善男子！我也是愍念后世众生，所以示现这件事。如来确实知道诸婆罗门、居士等邀请而不供养，却接受他们的邀请，在那里安居。为什么？善男子！那安居之处有五百匹马，把它们所有的饲麦施给众僧，直到三个月。

“善男子！那些马都是大菩萨，宿世种植德本，而遇到恶友，造诸恶业，生在畜生之中。善男子！那五百匹马中有一个调马的人，是日藏菩萨，以愿力的缘故生在那里。善男子！这日藏菩萨劝五百匹马发菩提心，为了令它们得到解脱，所以生在那里。善男子！以那善于调马的马主之力，那五百匹马都忆起宿命，得到菩提心，恢复本心。

“善男子！如来愍念那五百匹马，所以接受那邀请，在那里安居；调马人的麦给如来吃，五百匹马的麦给诸弟子吃。善男子！那调马者以马的声音调教五百匹马，都令它们忏悔，劝它们发心，又令那些马对佛法、对三宝生起敬重之心。善男子！过了三个月，那五百匹马舍身，生于三十三天。它们在畜生中尚且得到这样的利益，如来那时为它们说法，令它们得到阿耨多罗三藐三菩提记。善男子！那里所有调教五百匹马、防护马的人，如来为他们授记，当得成就自调伏心的缘觉之道。

“善男子！世间没有这样的食物——如来吃了而不变为微妙之味的。善男子！假使如来吃土块、瓦石等物，也无不变为微妙之味的饮食。善男子！如来所吃的都成为上味，三千大千世界之中世间所吃的东西都无可比拟。为什么？因为如来得到味中的上味，得到食中的上味，得到大丈夫的诸相好等。善男子！你现在应当这样正确理解：如来所吃的，都是微妙之味，无可比拟。

【按】“而无不退微妙味食”之“退”，明本作“作”，今从之。

“善男子！阿难比丘怜愍我，所以这样说：‘为什么如来生于转轮圣王之家，舍弃王位出家，竟能吃马麦？’如来善知阿难的心后，就给他一粒麦，告诉他说：‘阿难！你应当知道这是什么味道？’阿难吃了之后，生起奇特之心，就对我说：‘世尊！我生在王家，长在王家，而从未得到这样的上味。’善男子！阿难比丘以那食物的味道，身心得到安乐，七日不吃饭。善男子！因为这件事，应当知道如来没有业报。然而那居士、婆罗门邀请诸有德清净的比丘而不供养，诸比丘等受请前往那里而不得供养，这是示现业报。

【按】“此是何味”之“味”，《大正藏》作“昧”，CBETA 校改作“味”。

“善男子！你应当看如来的神力：那婆罗门邀请佛与僧众而不供养，如来为他授记，不堕恶道。善男子！与佛一同受请、在那里安居的五百比丘中，有四十位比丘多有贪心，不能观察不净之行，若得到称意的微妙饮食，都会退转；因为吃马麦的缘故，不生欲心，过了七日，得到阿罗汉果。善男子！如来善巧了知众生之心，所以接受那邀请，是为了度他们的缘故。

“善男子！菩萨摩诃萨善巧成就这样甚深秘密的法教与示现之事，若这样了知，名为善解如来密教。”

那时，世尊为了显明这个意义，以偈重说道：

```
善知渐法门，及以顿所说，
内心善巧知，诸菩萨示现。
善巧知秘密，远离诸疑惑，
善知诸佛说，所有秘密教。
```

（大意：善知渐次的法门以及顿说之法，内心善巧了知诸菩萨的示现。善巧了知秘密，远离诸疑惑，善知诸佛所说的一切秘密之教。）

### 第十，不求声闻缘觉乘

那时，净无垢宝月王光菩萨摩诃萨对佛说：“世尊！怎样是菩萨摩诃萨不求声闻、缘觉乘？”

佛说：“善男子！菩萨摩诃萨在地狱、饿鬼、畜生诸恶道中，虽然在那里受极重之苦，不可具说，而心不求声闻、缘觉乘，也无心求自己得解脱，不念少欲，不念少作，不行少欲，不行少作之事。善男子！菩萨对那些（有）善业的众生而与之同事，然而这菩萨对那些众生善加劝化，令他们修行，发阿耨多罗三藐三菩提心。善男子！菩萨摩诃萨成就这样的法，所以不求声闻、缘觉菩提。”

那时，世尊为了显明这个意义，以偈重说道：

```
常化诸众生，心不生疲惓，
于无上菩提，坚固不退转。
其心不可动，犹如妙山王，
修行慈悲心，不求二乘道。
```

（大意：常常教化诸众生，心不生疲倦；对于无上菩提，坚固而不退转。其心不可动摇，犹如妙高山王；修行慈悲之心，不求二乘之道。）

### 大乘之义

那时，净无垢宝月王光菩萨摩诃萨对佛说：“世尊！如来已经宣说菩萨成就这样等法，所以名为修行大乘、安住大乘；而如来没有说以什么意义，这大乘名为大乘？”

那时，世尊告诉净无垢宝月王光菩萨摩诃萨说：“我现在问你，随你的意思回答。善男子！你认为怎样？转轮圣王所行之道，具足四兵大众所行的道路，称作什么？”

这时，净无垢宝月王光菩萨摩诃萨说：“世尊！这名为王道，名为大道，是无畏之道，是无碍之道，是胜过一切诸国王的道。”

佛告诉净无垢宝月王光菩萨摩诃萨说：“善男子！诸佛如来正真正觉所行之道，那乘名为大乘，名为上乘，名为妙乘，名为胜乘，名为无上乘，名为无上上乘，名为无等乘，名为不恶乘，名为无等等乘。善男子！因为这个意义，名为大乘。”

这时，净无垢宝月王光菩萨摩诃萨对佛说：“善哉，世尊！善哉，善逝！善哉，世尊！畅快地宣说了这样的大乘名义。”

### 魔波旬来扰与悔过

#### 菩萨以神通令魔劝众

如来宣说这十法法门时，魔波旬这样想：“今天沙门瞿昙超过了我的境界。我若具备四种兵众去扰乱那瞿昙，令他不能宣说这法门。”那时魔波旬这样想后，就带领四兵来到王舍城耆阇崛山。

这时，净无垢宝月王光菩萨摩诃萨远远看见波旬带领四兵大众，为了扰乱如来、令他不能宣说这法门，想要来到这里。那时，净无垢宝月王光菩萨摩诃萨就显现神通；显现神通后，令魔波旬到王舍城的四衢道口这样唱言：“你们王舍城的诸人民等，应当知道，今天沙门瞿昙在王舍城耆阇崛山，为诸四众具说正法，初善、中善、后善，文义都深，淳备具足清净梵行。你们诸人可以前往那沙门瞿昙处听他说法，令你们长夜成就大安乐等诸利益事。”

那时，王舍大城之中，诸婆罗门、刹利、长者以及居士等被魔劝说后，手执香花、涂香、末香、烧香、宝幢、宝盖，出王舍城，到耆阇崛山，来到如来所，顶礼佛足，尊重赞叹，退坐一边。

【按】“末香”之“末”，宋、元、宫本作“粖”。

这时，魔波旬也带领四兵从王舍城出来，到耆阇崛山，来到如来所，化作曼陀罗花散在如来身上后，与四兵大众退坐一边。

#### 波旬悔过

这时，净无垢宝月王光菩萨摩诃萨知道魔波旬坐在一边后，就对魔说：“你魔波旬！以什么因缘带领四兵大众扰乱如来，并障碍如来宣说这法门？你现在应当在如来所生起惭愧之心、生起忏悔之心，不要令你在长夜中得不到利益，成就大苦报。”

这时，魔波旬听到净无垢宝月王光菩萨的话后，就合十指爪，以掌拄地，礼如来足，在如来所生起惭愧之心、生起忏悔之心，而这样说：“我现在非常畏惧如来。甚为奇特，善逝！唯愿大慈受我忏悔。我非常愚痴，没有智慧，没有善巧之智，不爱惜自身，而对如来生起恶心，又想令这法门断绝。善哉，世尊！再次接受我的忏悔。”

佛说：“波卑椽！善哉，善哉！你在长养善根。若我的法中有善男子、善女人生起忏悔之心以求清净（，也是这样）。善哉，波卑椽！”

【按】“波卑椽”之“椽”，宋、元、明、宫本作“掾”。“波卑掾”，即波旬（意为恶者）的异译。“起心忏悔”，明本作“能起心忏悔”。

#### 如来以恶言度众

这时，魔波旬到佛前站立，说道：“世尊！如来诸经中都断除恶语、不善之语吗？”

如来回答说：“是这样，是这样。”

魔波旬说：“为什么如来是法王、法主，得法自在，却称我为‘波卑椽’，这样叫我？”

佛说：“波卑椽！我现在为你说个比喻。善男子！譬如有一位长者居士，财富无穷，只有一个儿子，非常爱念，片刻不离眼前，把性命系在儿子身上。然而那独子诸根不调，非常恶劣谄曲；长者居士因为爱念之心，用杖打他，或用瓦或用石（打他），想令这儿子止息那些恶事。善男子！你认为怎样？这长者居士打他的儿子，有恶心吗？”

魔波旬说：“没有，世尊！是想令所爱念的儿子成就，所以作这样的事。”

佛说：“波旬应当知道，如来正真正觉善知众生的心性、根器、欲乐，所以观察：应以恶言而得度的，就说恶言；应以默然无所言说而得度的，就为之默然；应以驱遣而得度的，就驱遣他；应以说法而得度的，就为他说法；应以摄受而得度的，就摄受他；应见色身而得度的，就现色身令他见到；应闻声、闻香，或得味、得触而得度的，就为他现声而为他说法，乃至现香、味、触，令他得度。”

#### 波旬发愿护法

这时，魔波旬欢喜踊跃，又合十指爪，顶礼佛足，说道：“世尊！随在什么地方，无论村落、城邑，或在王都，宣说这法门，我为了听受这法门，当前往那里，护持这法门，也护持那持法的法器。世尊！我到那里时，必定有种种瑞相：大众寂定，离开睡眠之盖；又令各方上等胜妙的法器前来问法；无论读、诵、受持的人，身心都安乐，不生慢心，随顺宣说此法；无论广说者、略说者，都在如来所生起欢喜心。又，如来对诸众生生起欢喜心；那些众生心生欢喜之后，善根增长，恶法消灭。”

### 外道得无生忍之因缘

这时，大众中有诸外道尼乾子等，听到魔波旬这样忏悔，心大欢喜，踊跃无量，得无生忍。

那时，尊者阿难对佛说：“世尊！以什么因缘，宣说这法时，这些外道得无生忍？”

佛说：“阿难！在过去，超过无量劫，在这王舍城耆阇崛山，那时有佛，名为上力足正真正觉，在这里说法。佛说法之后，有诸外道来到佛所，想要扰乱如来，又想障碍宣说这法门，所以来到佛所。听闻法后，心生欢喜，就说：‘世尊！畅快地宣说了这法。’在如来所生起奇特之心。以这个因缘，在六十劫中，不堕地狱、饿鬼、畜生，只生于人、天，所生之处都忆念那佛；虽然忆念佛，却没有善友。阿难！你认为怎样？那些外道尼乾子等，难道是别人吗？就是现在这大众中的诸外道。为什么？这些善男子在那时具足恶见，所以想扰乱如来并障碍这法；他们听闻法后生起大欢喜，以这个因缘，现在蒙佛授记，这些外道当得阿耨多罗三藐三菩提，何况现在得无生忍。”

宣说这法门时，一万二千众生远尘离垢，得法眼净；二万众生发阿耨多罗三藐三菩提心。

### 信谤此法门的福罪

那时，尊者阿难对佛说：“世尊！若有善男子、善女人对这法门生起一念信心，功德无量，何况读诵、受持、拥护，广为人说。”

佛说：“阿难！若有善男子、善女人劝无余众生界都发阿耨多罗三藐三菩提心；若又有善男子、善女人对这法门生起一念信心，或读或诵，广为他人宣说，这人所得的福德超过前面所说的人。为什么？阿难！因为这法门是一切智智之道所在之处。阿难！若有男子、女人听闻这法门，以及见到受持这法门的法师，若生起恶心，所得之罪也超过前者。”

那时，净无垢宝月王光菩萨摩诃萨说：“若有男子、女人诽谤这部经，如来已说所得之罪超过前者。”

佛告诉净无垢宝月王光菩萨摩诃萨说：“若有男子、女人一时挖去一切众生所有的眼目；若又有男子、女人对这法门以及持法者生起一念恶心，所得之罪超过那人。为什么？阿难！因为这法门名为光明，能施予一切众生智慧之眼。”

尊者阿难对佛说：“世尊！这法门不应在不信的男子、女人面前宣说。为什么？因为需要保护众生。世尊！我见到这样谤法的业缘，会生于地狱、饿鬼、畜生恶道之中。”

佛对阿难说：“应当宣说这法门，不应不说。为什么？因为这（听闻）名为他们（将来得度）的因，令他们修行之后得到阿耨多罗三藐三菩提。”

### 经名与流通

阿难对佛说：“世尊！应当以什么名字称这法门？怎样奉持？”

佛说：“阿难！阿难应当知道，因为宣说十法，所以名为‘十法法门’，这样受持；也名为‘净无垢宝月王光菩萨所问’，这样受持。”

佛宣说这法门时，尊者阿难、净无垢宝月王光菩萨摩诃萨，以及众会中的诸大菩萨，以及声闻众、天龙八部，听闻佛所说，都大欢喜，顶受奉行。

【按】大乘十法会凡一卷，即本卷；相当于异译《佛说大乘十法经》全经。译者“元魏”，元、明本作“元魏北天竺”；“三藏法师”之“法师”，宋、元、明、宫本无。
