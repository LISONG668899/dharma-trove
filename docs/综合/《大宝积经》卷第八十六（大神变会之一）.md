# 《大宝积经》卷第八十六（大神变会之一）

唐·三藏法师菩提流志 奉诏译

## 大神变会第二十二之一

【按】译者题名“法师”二字，宋、元、宫本无。本会未见汉译异本。

#### 序分

如是我闻：一时，佛在舍卫国祇树给孤独园，与大比丘众一千二百五十人在一起，又有菩萨摩诃萨八千人，文殊师利与商主天子也在会中。

#### 三种神变：说法、教诫、神通

那时商主天子对佛说：“世尊！如来常以几种神变调伏众生？”佛告诉天子：“我以三种神变调伏众生：一是说法，二是教诫，三是神通。

“什么名为说法神变？就是如来以无碍的大智，见到未来世一切众生心行的差别，对三宝有信或不信，以及业与果报，都全部了知。如佛所说，若现在世所行的恶因，将堕入恶趣，随业受报，决定没有差错。若那些众生由于善业因缘与誓愿之力，从恶趣出来，生于人天之中，或以声闻、辟支佛乘以及大乘而得解脱，经过若干劫受苦受乐，当得涅槃，当得值遇若干诸佛，这样等业决定没有差错。若那些众生由于善业因缘与誓愿之力，将生于欲界、色界、无色界，经过若干劫，以这样的乘而得解脱，以这样的修行当得见佛，承事供养。像这样一切上、中、下品的善业、不善业，乃至一念，如来全都了知而为之说法，这名为说法神变。

【按】“所行恶因”，宫本作“行是恶因”。

“什么名为教诫神变？就是像这样教导诸持戒者：这是应当作的，这是不应当作的；这是应当信的，这是不应当信的；这是应当亲近的，这是不应当亲近的；这法是杂染的，这法是清净的；乃至摄受一切功德、善道的资粮；行这样的道得声闻乘、辟支佛乘，行这样的道成就大乘；非法应当远离，如法应当安住；如佛所教，决定没有差错。这是地狱之业，这是傍生之业，这是饿鬼之业，这是人天之业；不善应当舍弃，善法应当修习；这是圣道，应当这样学。这些众生在人天中往返，渐渐入于涅槃，这样的示现教导终究不会空过，这名为教诫神变。

“什么名为神通神变？就是为了调伏憍慢的众生，或现一身而作多身，或现多身而作一身，山崖墙壁出入无碍，身上出火、身下出水，身下出火、身上出水，入地如入水，履水如履地，有大威德的日月用手抚摸，或现大身直至梵世，乃至广大遍覆三千大千世界。随所应现而调伏众生，这名为神通神变。”

#### 文殊师利说诸佛最大神变

那时商主天子对佛说：“世尊！有超过这些的神变吗？”佛告诉天子：“如来还有殊胜的神变。”便对文殊师利说：“你可以演说，令诸菩萨得深法忍，摧伏众魔，也令如来的菩提之法久住于世。”

文殊师利对佛说：“世尊！如来若把三千世界的四大海水放在掌中，水性众生没有受到扰动，这样的神变还不算殊胜。若如来对一切法，那不可言说、无名无相、无色无声、无行无作、无文字、无戏论、无表示、远离心意识、一切语言道断、寂静照明之法，而以文字语言分别显示，这是一切世间所不能理解的，沙门、婆罗门听了都惊怖，这名为诸佛最大的神变。

“再者，如来若把三千大千世界纳入口中，四天下没有障碍，日月光明也不隐蔽，如本来那样住，其中众生也不觉知自己往来的方所。世尊！这样的神变还不算殊胜。若如来对一切法那不可说、无文字、无名相，乃至远离心意识、一切语言道断、寂静照明之法，而以文字语言宣说显示，这名为诸佛最大的神变。

“再者，如来以不共之身的神通力，随众生种种示现，令他们都欢喜。这样的神变还不算殊胜。所谓如来的大神变，就是：无我而说我，无众生而说众生，无人而说人，无养育者而说养育者，无名而说名，无色而说色，无受想行识而说受想行识，无处而说处，无界而说界；虽然说眼空，眼却不说自己空；虽然说色空，色却不说自己空；说眼识空，识却不说自己空；乃至意空以及法空、意识空等，也是这样。说这样等无名无相、无动无知、无言之法，摧灭一切生灭之相，这就是如来最大的神变。

【按】“说如是等”之“说”，宫本作“识”。

“这样的神变，不与眼相应，不与色相应，不与眼识相应，不与耳、声、耳识，鼻、香、鼻识，舌、味、舌识，身、触、身识，意、法、意识相应。这样的神变，不与身合，不与心合，无行无作，远离一切境界，是一切世间所不能信的。为什么呢？所说的世间，名为五蕴。凡夫对此妄生执著，或说蕴常，或说无常。由于这个缘故，一切世间妄见蕴是常，听到说无常便不能生信；妄见蕴是乐，听到说蕴是苦便不能生信；妄见蕴是我，听到说无我便不能生信；妄见蕴是净，听到说不净便不能生信；计执蕴是我所，说无我所便不能生信；计执五蕴是实，听到说不实便不能生信。由于这个缘故，如来的神变超出心相，听闻的人不欣喜，是一切世间所不能信的。

“再者，超越眼的境界，因为不是色法，这名为神变。超越耳的境界，因为不是声法，乃至超越意的境界，因为不是意法，不可显示，不是智所能知，这名为神变。再者，空、无相、无愿不可言说，而说空、无相、无愿，这名为神变。无起无作、无性无相、无生无灭、本来涅槃不可言说，而说涅槃，这名为神变。

“再者，布施清净，因为三轮清净，这名为神变。哪三轮？就是远离我相以及众生相，不念菩提。持戒清净，这名为神变，因为身口意业无所造作。忍辱清净，这名为神变，因为刹那坏灭而无所执著。精进清净，这名为神变，因为无去无来、身心不动。禅定清净，这名为神变，因为心无所依、内外寂静。智慧清净，这名为神变，因为照明诸法、灭一切见。

【按】“净三轮”之“净”，宋、元、明、宫本无。

“再者，法没有出离之相，而说出离之法，这名为神变。法没有差别，而以文字分别，这名为神变。法无所行，而说有修行，这名为神变。法无来去，而说有来去，这名为神变。在唯一道的证得上建立诸果，这名为神变。在一味之法中分别三乘，这名为神变。一切诸佛只是一佛，而说无量佛，这名为神变。一切佛土只是一佛土，而说无量佛土，这名为神变。无量众生即是一众生，而说无量众生，这名为神变。一切佛法只是一佛法，而说无量法，这名为神变。法不可显示，而显示诸法，这名为神变。法无所得，而修习作证，这名为神变。”

那时商主天子对文殊师利说：“依我对仁者所说之义的理解，对一切法的所有言说都名为神变。”文殊师利说：“是这样，是这样。一切言说实际上无所说，名为大神变。”宣说此法时，一万二千天子发阿耨多罗三藐三菩提心，五百菩萨得无生法忍。

#### 舍利弗与商主天子问答

那时长老舍利弗对商主天子说：“你听到这神变，不惊怖吗？”天子回答：“我就是神变，怎么会惊怖？”舍利弗说：“天子以什么密意而说这话？”天子说：“一切诸法，无论善与不善，无动而动，名为大神变。所以舍利弗！作善业的人生于天上，有大威德，这样的善业不可思议。一切众生往来生死也不可思议，不可思议者名为大神变。如佛所说，四种境界不可思议：一是业的境界不可思议，二是龙的境界不可思议，三是禅的境界不可思议，四是佛的境界不可思议。由于这个缘故，说一切法名为大神变，不应惊怖。

“再者，舍利弗！若如来宣说这神变，虚空界难道会惊怖吗？”舍利弗回答：“不会。”天子说：“若虚空不惊怖，为什么问我‘你不惊怖吗’？”舍利弗说：“你难道等同于虚空吗？”天子说：“如佛所说，内空、外空，是虚空吗？”舍利弗回答：“是的。”天子说：“所以一切众生都是虚空之性。”舍利弗说：“天子！如你所说，不久你也将示现这神变。为什么呢？因为超过一切境界就是大神变。”

#### 往昔因缘：等须弥如来与净庄严王

那时舍利弗对佛说：“世尊！这位商主天子往昔供养诸佛世尊以及文殊师利，才能成就这样的辩才。”佛告诉舍利弗：“是这样，是这样，如你所说，他是文殊师利所成熟的。

“舍利弗！在往昔古世，过了无量劫，有佛名为等须弥如来、应供、正遍知、明行足、善逝、世间解、无上士、调御丈夫、天人师、佛、世尊，出现于世。国名安乐，劫名欢喜。舍利弗！那佛世界的一切众生具足安乐，乃至没有少许苦恼之声。那佛国土由四宝所成，就是金、银、琉璃以及颇梨，大地平坦如掌，清净柔软如天上的妙衣，没有种种难处。天人充满，安隐繁盛，快乐无量，所以名为安乐世界。

“那佛法中纯是菩萨，精进勇猛，智慧光明，得修多罗王陀罗尼，辩才无尽，善巧方便，分别说法，有神通智慧，摧破恶魔，解脱无碍，成就定与忍，善知根性，应病与药，具足大福德与智慧资粮，为众生作不请之友。以神通力遍游诸佛刹，入于智慧与修行之海，安住于布施、持戒、智慧、多闻，以无边善根方便回向，住于十力、四无所畏、一切佛法，游戏于三昧、诸禅、解脱。那位佛世尊以这样等大菩萨为眷属。

【按】“神通智慧”之“通”，《大正藏》作“道”，今依CBETA（所录高丽藏）作“通”。“恶魔”，宋、元、明本作“魔怨”。

“那世界中有一位转轮王，名为净庄严，以正法化世，统治四天下，七宝具足。王有一千个儿子，都发阿耨多罗三藐三菩提心。净庄严王以及他的后宫，也都已发阿耨多罗三藐三菩提心。那位等须弥如来寿命七十俱胝岁，那时净庄严王在百千年中承事供养那位佛如来以及菩萨众，以衣服、饮食等一切乐具。王与一千个儿子以及他的后宫得清净信，爱法欢喜，再无异心，常在佛前亲手供养，亲近听法，过了百千年之后，当时王的一千个儿子以及内宫获得四种念。哪四种？一是念佛与菩萨，二是念施，三是念戒，四是不忘菩提之心。因为得到这四念，无论白天黑夜常得见佛以及诸菩萨。

#### 等须弥如来说殊胜神变

“后来有一次，净庄严王以及他的眷属为了听法前往佛所。当时那位如来为了教化诸菩萨，在大众中示现种种神变。那时净庄严王上前对佛说：‘世尊！有超过这些的神变吗？’佛告诉大王：‘如来还有殊胜的神变，就是：了知过去已灭、现在不住、未来未生，没有心与心所，而说三世的心与心所法；在一味之中说三解脱；在唯一的灭的证得中说四圣谛；开示诸法空、无相、无愿，成熟颠倒苦恼的众生；说无相无为而成就菩提。在不取不舍中说檀波罗蜜，在无住无作中说尸波罗蜜，在无我之法中说羼提波罗蜜，在身心寂静中说毗离耶波罗蜜，在不乱不摄中说禅波罗蜜，在远离此岸与彼岸中说般若波罗蜜；无所动念而行方便。远离依怙之相而修习慈，以无作之法修习悲，以远离欣悦而修喜，以不住之法而修舍。以无所见而起天眼，因为无所闻而起天耳，无所攀缘而起他心智，远离前际而起宿命智，身心不动而起神足。不住于法而修念处，以无生灭而修四正勤，非根而说根，非力而说力，诸法寂静而说菩提分法，无差别而修八圣道，不住于寂静而修奢摩他，远离法相而修毗钵舍那，本来寂灭而说涅槃。’

【按】“成熟颠倒苦恼众生”之“熟”，明本作“就”。

“那位佛世尊为净庄严王与一千个儿子及眷属宣说这神变之法时，八万四千众生发阿耨多罗三藐三菩提心。净庄严王以及一千个儿子证得法忍，以佛的神力，当即在佛前以偈赞叹道：

#### 净庄严王偈赞

```
如须弥山，映于大海，如来威光，蔽诸大众。
如日初出，破一切暗，世尊毫相，遍照佛刹。
如月圆满，光明炽盛，佛德圆满，慧光普照。
譬如莲花，不著于水，佛处于世，无所染著。
如师子王，吼于林野，人中师子，吼于性空。
说一切法，非有非无，令离边见，名师子吼。
于一切相，若生若灭，说无生灭，名师子吼。
分别此岸，或示彼岸，不住诸法，名师子吼。
分别二相，是染是净，诸法性净，名师子吼。
贪瞋痴行，从分别生，不起分别，名师子吼。
说生死法，无常无我，从颠倒起，名师子吼。
生死涅槃，本来寂静，是大菩提，名师子吼。
诸见所缚，流转世间，开示性空，名师子吼。
如来导师，所现神变，悉能开示，名师子吼。
```
（大意：如须弥山映照于大海，如来的威光蔽盖大众。如太阳初出，破除一切黑暗，世尊的白毫之相遍照佛刹。如满月光明炽盛，佛的功德圆满，智慧之光普照。譬如莲花不著于水，佛处于世间无所染著。如狮子王在林野中吼叫，人中狮子吼说性空。说一切法非有非无，令人离开边见，名为狮子吼。对一切相，无论生或灭，说其无生无灭，名为狮子吼。分别此岸，或指示彼岸，而不住于诸法，名为狮子吼。分别染与净二相，而说诸法本性清净，名为狮子吼。贪、瞋、痴之行从分别而生，不起分别，名为狮子吼。说生死之法无常、无我，从颠倒而起，名为狮子吼。生死与涅槃本来寂静，这就是大菩提，名为狮子吼。被诸见所系缚而流转世间，为之开示性空，名为狮子吼。如来导师所现的神变，都能开示，名为狮子吼。）

```
于一切违顺，其心不倾动，
常住于平等，名随顺法忍。
随顺佛所说，甚深寂静法，
亦不于中证，名随顺法忍。
远离诸过恶，增长于善法，
于中无所著，名随顺法忍。
说诸法空声，及一切见声，
二俱无所著，名随顺法忍。
无边佛法声，种种烦恼声，
不起声分别，名随顺法忍。
于施戒多闻，精进及定慧，
如法而修行，名随顺法忍。
不舍菩提心，平等观一切，
清净菩提道，名随顺法忍。
如来自意语，开示诸佛法，
于此无疑惑，名随顺法忍。
```
（大意：对一切违逆与顺从，其心不倾动，常住于平等，名为随顺法忍。随顺佛所说甚深寂静之法，也不在其中取证，名为随顺法忍。远离种种过恶，增长善法，而对其中无所执著，名为随顺法忍。说诸法空的声音以及一切见的声音，对二者都无所执著，名为随顺法忍。无边佛法的声音与种种烦恼的声音，不起声音的分别，名为随顺法忍。对布施、持戒、多闻、精进以及禅定与智慧，如法而修行，名为随顺法忍。不舍菩提心，平等观一切，清净菩提之道，名为随顺法忍。如来随自意所说之语，开示诸佛之法，对此没有疑惑，名为随顺法忍。）

```
若我证菩提，当大师子吼，
演说此神变，如今佛所说。
我于不思议，无上大福田，
已植于种子，终无有退转。
假令大地坏，大海悉枯竭，
我所种善根，永无有退失。
了知众生心，其性如虚空，
深植菩提种，得无边福德。
如我今志乐，唯佛能证知，
天人乾闼婆，无有能知者。
```
（大意：若我证得菩提，当作大狮子吼，演说这神变，如现在佛所说。我在不可思议的无上大福田中已种下种子，终究不会退转。假使大地毁坏，大海全都枯竭，我所种的善根永远不会退失。了知众生之心，其本性如虚空，深植菩提之种，得无边的福德。像我现在的志乐，只有佛能证知，天、人、乾闼婆，没有能知道的。）

```
我今终不求，诸天胜妙报，
我当得智慧，如佛人中尊。
我于百千岁，亲近供养佛，
发趣菩提故，修此无边业。
我今与千子，及后宫眷属，
愿常供养佛，为成熟菩提。
我今得善利，善见于诸佛，
善得闻此法，爱乐于菩提。
若爱乐菩提，则为爱乐法，
怜愍众生故，不舍于佛乘。
```
（大意：我现在终究不求诸天殊胜美妙的果报，我当得到如佛那样的智慧，成为人中之尊。我在百千年中亲近供养佛，为了发趣菩提，修这无边的善业。我现在与一千个儿子以及后宫眷属，愿常常供养佛，为了成熟菩提。我现在得到善利：好好地见到诸佛，好好地得闻此法，爱乐于菩提。若爱乐菩提，便是爱乐于法，因为怜愍众生，不舍弃佛乘。）

#### 法速疾菩萨说菩提之相

“那时众中有一位菩萨，名为法速疾，对净庄严王说：‘大王！你并没有随顺如来的神变，也不是发趣无上菩提。为什么呢？大王！菩提住于法界，不来不去，无知无行，非色非相，不取不舍，如在虚空中作画，无所触碍，本性清净。大王！菩提入于一切处，因为诸法平等。菩提无分别，因为远离诸相。菩提寂静，因为止息诸相。菩提本性清净，因为远离计执。菩提不动，因为没有杂乱。大王！菩提名为心平等，因为无所生起。菩提名为众生平等，因为本来无生。菩提名为不生之生，因为因缘无自性。菩提不可显示，因为远离心意识。大王！菩提无所行，因为超过诸境界。菩提无戏论，因为远离寻思之相。菩提是空，因为性与相都空。菩提无相，因为远离一切相。菩提无愿，因为无所住。菩提无作，因为没有业报。菩提无为，因为远离三相。大王！菩提的性相就是这样。若对此法有所愿求，只是徒自疲劳。为什么呢？菩萨应当如菩提之性而行，能这样行，名为正行。’

#### 法速疾菩萨说菩萨正行

“那时净庄严王对法速疾菩萨说：‘愿为我宣说菩萨的正行。’法速疾说：‘大王！舍弃一切所有是菩萨行，因为众生平等无分别。头陀与学戒是菩萨行，因为戒性平等无所行。远离瞋恚热恼是菩萨行，因为忍性平等无心相。坚固勇猛是菩萨行，因为精进平等远离心行。三昧与解脱是菩萨行，因为禅定平等无所缘。闻慧与资粮是菩萨行，因为慧性平等无所念。生于梵住是菩萨行，因为染与净平等，二者都远离。起诸神通是菩萨行，因为神通平等不生念。具足辩才是菩萨行，因为法与义平等，远离心相。成就胜解是菩萨行，因为法界平等无所动。修七觉分是菩萨行，因为观照平等而不懈怠。起四摄法是菩萨行，因为诸法平等，同其事业。以平等心对待众生是菩萨行，因为心性平等无分别。庄严佛土是菩萨行，因为清净平等如虚空。三十二相是菩萨行，因为观法无相而入于平等。清净身口意是菩萨行，因为远离三业，其性平等。随喜众生是菩萨行，因为一切众生平等无我。不厌生死是菩萨行，因为了知如梦，其性平等。常修善业是菩萨行，因为知业平等，没有业报。坚固修行是菩萨行，因为观一切法如幻化。安忍众苦是菩萨行，因为了知平等，苦不生起。亲近善友是菩萨行，因为对朋友与非朋友心平等。勤修深心是菩萨行，因为果报平等，无所求。多闻无厌是菩萨行，因为说法与听法都平等。对法不悭吝是菩萨行，因为平等说法而不希求。摄受正法是菩萨行，因为平等成熟诸佛之法。常求真实之智是菩萨行，因为第一义谛之性平等。谦下其心是菩萨行，因为以平等心谦下于众生。普遍摄取一切善功德是菩萨行，因为功德平等无所念。’

【按】“头陀学戒”之“戒”，宫本作“成”。“染净平等”之“染”，宫本作“深”；“平等”，宋本作“三等”。

#### 法速疾菩萨劝出家

“那时净庄严王听到宣说这样的诸菩萨行，欢喜踊跃，生起爱乐之心，便脱下衣服与庄严身体之具，送给法速疾菩萨。当时王的一千个儿子也各自脱下身上的庄严之具，奉上菩萨，这样说：‘愿令一切众生成就菩萨行，得到这样的辩才。我们现在畅快地得到善利，得见这样真正的善知识，恭敬供养。’那时法速疾菩萨告诉净庄严王：‘你所作的供养甚为下劣，应当知道还有殊胜的供养。’当时法速疾菩萨以偈颂道：

【按】“尔时速疾菩萨”，宋、元、明、宫本作“尔时法速疾菩萨”。“净庄严王”之“净”，宫本作“妙”。

```
大千界众生，皆发趣菩提，
假令尽一劫，男女以奉施；
若人发道意，以信而出家，
随佛而修学，其福胜于彼。
过去未来世，一切诸如来，
无有不舍家，得成无上道。
三世一切佛，称赞出家法，
若乐供养佛，当依佛出家。
```
（大意：大千世界的众生都发趣菩提，假使穷尽一劫，以男女奉施；若有人发起道心，以信心出家，随佛修学，他的福德胜过前者。过去、未来世的一切诸如来，没有不舍弃家而成就无上道的。三世一切佛都称赞出家之法，若乐于供养佛，应当依佛出家。）

```
设满恒沙界，珍宝供养佛，
不如一日中，出家修寂静。
彼则近菩提，摧破魔军众，
出家不放逸，白法恒增长。
不坏众善根，远离诸烦恼，
舍于家业累，顺道圣所赞。
舍家离恼缚，除恼离魔缚，
心解行无染，不久证菩提。
```
（大意：假使以充满恒河沙数世界的珍宝供养佛，不如一日之中出家修习寂静。他便接近菩提，摧破魔军，出家而不放逸，白净之法恒常增长。不坏种种善根，远离诸烦恼，舍弃家业的拖累，随顺圣者所赞叹的道。舍家便离开苦恼的系缚，除去苦恼便离开魔的系缚，心得解脱，行无染著，不久证得菩提。）

#### 净庄严王与千子出家，念大悲王子继位

“那时净庄严王听了这偈之后，对自在的王位以及一切爱欲全都舍离，便对佛说：‘世尊！我愿在佛的善法律中出家受戒。’当时等须弥如来告诉他：‘大王！出家没有过患，我常劝赞；乐著于居家，不是我所许可的。你对王位若还有爱著，我当教你如法而住。’

【按】“犹有爱者”之“者”，宋、元、明本作“著”。

“那时净庄严王告诉一千个儿子说：‘你们谁能继承王业？’诸子都说：‘我们也乐于出家，愿父王听许。’父王告诉他们：‘你们若全都出家，这四天下的国土人民由谁来养育？若你们的大悲心坚固，应当为众生作王，普遍令众生安住于善法。’当时一千个儿子中有一位王子，名为念大悲，便以偈颂回答父王说：

```
父王于佛法，所得诸功德，
我悲受王位，亦当如是学。
我常修梵行，尽形持八戒，
我当不饮酒，不涂饰香花，
身去庄严具，不卧金床座，
足不蹑金屣，首不饰宝冠，
不著天妙衣，不观诸妓乐，
不玩奇鸟兽，不从宫女人。
```
（大意：父王在佛法中所得的种种功德，我以悲心接受王位，也当这样学。我常修梵行，尽形寿持八戒：我当不饮酒，不以香花涂饰，身上去除庄严之具，不卧金床宝座，脚不穿金鞋，头不戴宝冠，不穿天上的妙衣，不观看种种伎乐，不玩赏奇鸟异兽，不亲近宫中女人。）

```
周巡四天下，宣行十善道，
呵责家过患，赞叹出家法。
舍自在憍慢，亲近佛法僧，
不退菩提心，常厌于三界。
以施爱利益，同事摄众生，
普令于大乘，悉当得成熟。
昼夜六时分，当往于佛所，
为听闻法故，供养彼如来。
```
（大意：我将周巡四天下，宣行十善之道，呵责居家的过患，赞叹出家之法。舍弃自在的憍慢，亲近佛、法、僧，不退菩提心，常厌离三界。以布施、爱语、利行、同事摄受众生，普遍令他们在大乘中都得成熟。昼夜六时，当前往佛所，为了听闻佛法，供养那位如来。）

“那时等须弥如来赞叹念大悲王子说：‘善哉善哉。善男子！你因为见到平等之法，安住于大悲，以出家的正信，在在家菩萨中最为殊胜，与出家的功德平等，没有差异。’那时净庄严王便立念大悲继承王位，自己与九百九十九个王子随佛出家。出家之后，等须弥如来为他们宣说这样的神变之法，此后不久他们获得五神通，得到念总持、多闻与智慧。当时念大悲在十五日受灌顶之位，也以此法为四天下一切众生宣示教化。九十二俱胝众生发阿耨多罗三藐三菩提心，都在等须弥如来的法中出家修道，安住于大乘，得不退转。

“舍利弗！你观察此法无量的功德，成熟一切具善根的众生。舍利弗！那时的净庄严王难道是别人吗？就是现在的商主天子。法速疾菩萨，就是现在的文殊师利。那一千个儿子，就是这贤劫中的千佛。念大悲王子，就是我。舍利弗！这些菩萨因为深心正行、不放逸，得阿耨多罗三藐三菩提。”宣说这往昔修行之法时，三万二千天人发阿耨多罗三藐三菩提心。

#### 文殊师利说三种决定义

那时舍利弗对文殊师利说：“仁者与商主天子久修梵行，多供养佛，种诸善根。”

文殊师利说：“大德！梵行名为八圣道，是有为法，我即是无为，所以我不是久修梵行。梵行名为有所行，我无所行，所以我不是久修梵行。又，梵行名为二相，我没有二相，所以我不是久修梵行。又，梵行名为灭烦恼，我没有烦恼，也无所灭，所以我不是久修梵行。对驰骋五欲而说梵行，我对五欲本来无所行，所以我不是久修梵行。超过魔道名为梵行，我常安住在诸魔道中，所以我不是久修梵行。成就善法名为梵行，我对善恶都无所得，所以我不是久修梵行。声闻、缘觉所住的正位名为梵行，我无所证，所以我不是久修梵行。修涅槃之道名为梵行，我对涅槃无所愿求，所以我不是久修梵行。

【按】“我常安住”之“常”，宋、元、明本作“当”。

“再者，舍利子！你说我多供养佛。你以为如来可以供养吗？为什么这样说呢？如来不是色，也不可见，怎么能供养如来？如来不是受，止息一切受；如来不是想，远离一切结；如来不是行，毕竟无作；如来不是识，超出心意；怎么能供养如来？再者，如来行于性空，不是眼与色界；住于无相之际，不是耳与声界；远离二相，不是鼻与香界；没有可知之相，不是舌与味界；没有障碍之相，不是身与触界；入于平等，不是意与法界；怎么能供养如来？又，如来名为法界，名为如如，入于实际，住于大空，不动本性，断诸戏论，无所攀缘，不住于识，不依三界，也不住于今世后世，常寂、极寂，远离身口意，无形无相，无毁无誉，无漏无失，犹如虚空遍一切处，怎么能供养如来？

【按】“名为法界”之“名”，《大正藏》作“各”，今依CBETA（所录高丽藏）作“名”。

“再者，舍利弗！如你所说种诸善根，这善根不是身见之根，不是贪瞋之根，不是颠倒之根，不是五蕴、六入、七识住之根，不是八邪、九恼、十不善之根。那善根不是戒学之根，不是心学之根，不是慧学之根，不是正趣之道之根，不是明与解脱之根，不是四谛、六通之根，不是九次第定、十无学之根，不是五根、五力、七菩提分、八圣道之根。又，善根不是结使之根，不是障碍之根，不是恶作之根，不是生灭见之根，不是断常见之根，不是我见、人见、众生见、寿者见之根，不是蕴魔、烦恼魔、死魔、天魔之根。那善根不是妄念之根，不是无明之根，不是行、识、名色、六入、触、受、爱、取、有、生、老死忧恼之根。那善根不是欲界、色界、无色界之根，不是布施、持戒、忍辱、精进、禅定、智慧之根，不是慈、悲、喜、舍之根，不是声闻、缘觉所证之根。

“菩萨的善根，就是：心无所住的一切智之根、无自作他作之根、忍辱调伏之根、庄严身口意之根、大慈大悲之根、成熟一切众生之根、摄受一切法之根、成就一切佛法之根、不断三宝种之根、舍一切所有而不求果报之根、积集众善而不求释梵果报之根、发大精进而不乐小乘之根、修习禅定而不味著之根、以无所舍而行智慧之根、遍入诸行而修方便之根、具足十力四无畏之根、得陀罗尼无碍辩之根、获神通力清净佛土之根、趣向菩提树转法轮之根。”

【按】“成就一切佛法根”之“就”，明本作“熟”。

文殊师利说这三种决定之义后，一切大众都称善哉，以种种花散在世尊以及文殊师利身上，这样说：“若佛刹中没有文殊师利，佛便不出世。不是文殊师利，便不能成熟一切众生广大的善根。若有人得闻文殊师利所说的法门，不惊不怪，便远离一切魔业障碍，在这大乘中得清净光明。”

【按】“不惊不怪”之“怪”，宋、元、明、宫本作“怖”。
