# 《大宝积经》卷第九十八（妙慧童女会、恒河上优婆夷会）

唐·三藏法师菩提流志 奉诏译

## 妙慧童女会第三十

【按】译者题名“诏”，宫本作“诰”。本会异译有西晋竺法护译《须摩提菩萨经》（T0334）、后秦鸠摩罗什译《须摩提菩萨经》（T0335）等，“须摩提”即妙慧。

#### 妙慧童女偈问

如是我闻：一时，佛在王舍城耆阇崛山中，与大比丘众一千二百五十人、菩萨摩诃萨一万人在一起。当时王舍城有一位长者的女儿，名为妙慧，年方八岁，面貌端正，容色姝好，诸相具足，见者欢喜，曾在过去无量诸佛之所亲近供养，种诸善根。当时那女孩来到如来之所，顶礼佛足，右绕三匝，长跪合掌，说偈道：

```
无上等正觉，为世大明灯；
菩萨之所行，唯愿听我问。
```
（大意：无上等正觉，是世间的大明灯；菩萨的所行，唯愿听许我请问。）

佛告诉妙慧：“现在任你问。当为你解说，令你断除疑网。”那时妙慧便在佛前以偈问道：

```
云何得端正，大富尊贵身？
复以何因缘，眷属难沮坏？
云何见己身，而受于化生，
千叶莲花上，面奉诸世尊？
云何能证得，自在胜神通，
遍往无量刹，礼敬于诸佛？
云何得无怨，所言人信受，
净除于法障，永离诸魔业？
云何命终时，得见于诸佛，
闻说清净法，不受于苦恼？
大悲无上尊，唯愿为我说。
```
（大意：怎样得到端正、大富、尊贵之身？又以什么因缘，眷属难以被沮坏？怎样见到自身在千叶莲花上受化生，当面奉事诸世尊？怎样能证得自在殊胜的神通，遍往无量佛刹，礼敬诸佛？怎样能没有怨敌，所说的话人们信受，净除法障，永离种种魔业？怎样在命终时得见诸佛，听闻宣说清净之法，不受苦恼？大悲无上的世尊，唯愿为我宣说。）

#### 佛说十组四法

那时佛告诉妙慧童女说：“善哉善哉！善能问这深妙之义。谛听谛听，好好思念，当为你说。”妙慧说：“是的，世尊！愿乐欲闻。”

佛告诉妙慧：“菩萨成就四法，得受端正之身。哪四法？一是对恶友不起瞋心，二是住于大慈，三是深乐正法，四是造佛形像。”那时世尊说偈道：

```
瞋坏善根勿增长，
慈心乐法造佛形，
当获具相庄严身，
一切众生常乐见。
```
（大意：瞋能毁坏善根，不要令它增长；以慈心乐法，造佛形像，当获得具足相好庄严之身，一切众生常乐于见到。）

“再者，妙慧！菩萨成就四法，得富贵之身。哪四法？一是应时布施，二是没有轻慢之心，三是欢喜而给予，四是不希求果报。”那时世尊说偈道：

```
应时行施无轻慢，
欢喜授与不希求，
能于此业常勤修，
所生当获大财位。
```
（大意：应时布施而无轻慢，欢喜给予而不希求回报，能对这业常常勤修，所生之处当获得大财富与地位。）

“再者，妙慧！菩萨成就四法，得眷属不坏。哪四法？一是善能舍弃离间之语，二是令邪见的众生安住于正见，三是正法将灭时护持令其久住，四是教导众生趣向佛的菩提。”那时世尊说偈道：

```
舍离间言及邪见，
正法将灭能护持，
安住众生大菩提，
当成不坏诸眷属。
```
（大意：舍离离间之言以及邪见，正法将灭时能够护持，令众生安住于大菩提，当成就不坏的眷属。）

“再者，妙慧！菩萨成就四法，当在佛前得受化生，处于莲花座上。哪四法？一是捧着种种花果以及细末香散于如来以及诸塔庙，二是终不对他人妄加损害，三是造如来像，安置在莲花上，四是对佛的菩提深生净信。”那时世尊说偈道：

【按】“捧诸花果”，元、明本作“捧诸妙花果”。

```
花香散佛及支提，
不害于他并造像，
于大菩提深信解，
得处莲花生佛前。
```
（大意：以花香散于佛以及支提（佛塔），不害他人，并且造佛像，对大菩提深深信解，便得以处于莲花中，生在佛前。）

“再者，妙慧！菩萨成就四法，能从一佛土到另一佛土。哪四法？一是见他人修善不加障碍恼乱，二是他人说法时从不留难阻碍，三是燃灯供养如来之塔，四是对种种禅定常勤修习。”那时世尊说偈道：

```
见人修善说正法，
不生谤毁加留难，
如来塔庙施灯明，
修习诸禅游佛刹。
```
（大意：见人修善、说正法，不生谤毁、不加留难，对如来塔庙施以灯明，修习种种禅定，便能游历佛刹。）

“再者，妙慧！菩萨成就四法，处世没有怨敌。哪四法？一是以无谄曲之心亲近善友，二是对他人的殊胜之法没有嫉妒之心，三是他人获得名誉，心常欢喜，四是对菩萨行没有轻毁之心。”那时世尊说偈道：

```
不以谀谄亲善友，
于人胜法无妬心，
他获名誉常欢喜，
不谤菩萨得无怨。
```
（大意：不以阿谀谄媚亲近善友，对他人的殊胜之法没有嫉妒之心，他人获得名誉常生欢喜，不诽谤菩萨，便得以没有怨敌。）

“再者，妙慧！菩萨成就四法，所说的话人们相信。哪四法？一是所说与所行常常相应，二是对善友不覆藏种种恶，三是对所听闻的法不求其过失，四是对说法者不生恶心。”那时世尊说偈道：

```
发言修行常相应，
己罪不藏于善友，
闻经不求人法过，
所言一切皆信受。
```
（大意：所说与所行常常相应，对善友不隐藏自己的罪，听经时不求人与法的过失，所说的一切人们都信受。）

“再者，妙慧！菩萨成就四法，能远离法障，迅速得到清净。哪四法？一是以深切的意乐摄持三种律仪，二是听闻甚深的经典不生诽谤，三是见到新发意的菩萨，生起对一切智的心，四是对一切众生大慈平等。”那时世尊说偈道：

```
以深意乐摄律仪，
闻甚深经能信解，
敬初发心如佛想，
慈心普洽障消除。
```
（大意：以深切的意乐摄持律仪，听闻甚深的经典能够信解，恭敬初发心者如同佛想，以慈心普遍润泽众生，障碍便得消除。）

“再者，妙慧！菩萨成就四法，能远离诸魔。哪四法？一是了知法性平等，二是发起精进，三是常勤念佛，四是一切善根都回向。”那时世尊说偈道：

```
能知诸法平等性，
常起精进念如来，
回向一切诸善根，
众魔不能得其便。
```
（大意：能知诸法的平等之性，常起精进，忆念如来，回向一切善根，众魔便不能得其便。）

“再者，妙慧！菩萨成就四法，临命终时诸佛现前。哪四法？一是他人有所求，布施令其满足，二是对种种善法深生信解，三是对诸菩萨施以庄严之具，四是对三宝勤修供养。”那时世尊说偈道：

```
他有所求令满足，
信解深法舍严具，
三宝福田勤供养，
临命终时佛现前。
```
（大意：他人有所求便令其满足，信解深法，施舍庄严之具，对三宝福田勤加供养，临命终时诸佛便现前。）

#### 妙慧发愿，大地震动

那时妙慧童女听佛说了之后，说：“世尊！如佛所说的菩萨诸行，我当奉行。世尊！若我在这四十种行中缺少一种而不修，便是违背佛教、欺诳如来。”那时尊者大目犍连告诉妙慧说：“菩萨之行甚难修行。你现在发这殊胜的大愿，难道对这愿能得自在吗？”那时妙慧说：“尊者！若我的弘愿真实不虚，能令诸行得到圆满，愿这三千大千世界六种震动，天上雨下妙花，天鼓自鸣。”说这话时，虚空中花散如雨，天鼓自鸣，三千大千世界六种震动。

【按】“大目犍连”之“犍”，宫本作“揵”。“妙慧白言”之“白”，《大正藏》作“曰”，今依CBETA作“白”。

当时妙慧又对目连说：“以我这样的真实之言，在未来世当得成佛，也如今日的释迦如来。在我的国土中没有魔事以及恶趣，也没有女人之名。若我这话不是虚妄的，令这大众身体都成金色。”说了这话之后，大众都成金色。那时尊者大目犍连便从座起，偏袒右肩，顶礼佛足，说：“世尊！我现在先礼敬这位初发心菩萨以及诸菩萨摩诃萨众。”

#### 文殊与妙慧问答

那时文殊师利法王子告诉妙慧说：“你住于什么法而发这诚实之愿？”妙慧回答：“文殊师利！这不是该问的。为什么呢？因为在法界中无所住。”又问：“什么名为菩提？”答：“无分别之法，这名为菩提。”又问：“什么名为菩萨？”答：“一切诸法如同虚空之相，这名为菩萨。”又问：“什么名为菩提之行？”答：“犹如阳焰、谷响之行，是菩提之行。”又问：“依什么密意而这样说？”答：“我在这里不见有少许法是密或非密的。”又问：“若是这样，一切凡夫应当就是菩提。”答：“你以为菩提异于凡夫吗？不要作这样的见解。为什么呢？这些都同一法界之相，非取非舍，没有成坏。”又问：“对这义理中能够理解的人，其数有多少？”答：“如若干幻化之心与心所的数量，若干幻化的众生能了解这义理。”文殊师利说：“幻化本来没有，哪有这样的心与心所法？”答：“法界也是这样，非有非无，乃至如来也是这样。”

那时文殊师利对佛说：“世尊！现在这妙慧甚为希有，竟能成就这样的法忍。”佛说：“是这样，是这样，确实如你所说。然而这童女已在过去发菩提心，经过三十劫，我才发趣无上菩提；她也曾令你安住于无生忍。”那时文殊师利便从座起，为她作礼，对妙慧说：“我在往昔无量劫前曾供养过您，没想到现在还能亲近。”妙慧告诉他说：“文殊师利！你现在不要生起这样的分别。为什么呢？因为以无分别而得无生忍。”

#### 转女成男，授记

文殊又问妙慧：“你现在还不转女身吗？”妙慧回答：“女人之相了不可得，现在转什么？文殊师利！我当为你除断疑惑。由于我这样的真实之语，在未来世得阿耨多罗三藐三菩提时，在我的法中，诸比丘闻佛唤‘善来’便出家入道。我国土中的所有众生身都是金色，服用资具如同第六天，饮食丰饶，随念而至。没有魔事以及种种恶趣，也没有女人之名。有七宝林，上面罗列宝网，七宝莲花上覆盖着宝帐。如文殊师利所成就的清净佛刹那样装饰庄严，没有差异。若我这话不是虚妄的，令这大众身体都成金色，我的女身变成男子，如三十岁知法的比丘。”说这话时，大众都成金色，妙慧菩萨转女成男，如三十岁知法的比丘。当时地居天众辗转赞叹说：“大哉大哉！妙慧菩萨摩诃萨能在来世得菩提时，严净佛刹的功德就是这样。”

【按】“七宝林”之“林”，元、明本作“座”。“覆以宝帐”之“覆”，宋本作“复”。“装校”之“装”，明本作“庄”。“令此大众”之“令”，明本作“今”。

那时佛告诉文殊师利：“这位妙慧菩萨在未来世成就等正觉，号为殊胜功德宝藏如来，出现于世。”佛说此经时，三十俱胝众生对阿耨多罗三藐三菩提住于不退转，八十俱胝众生远尘离垢，得法眼净，八千众生都获得智证。

【按】“远尘离垢”，明本作“远离尘垢”。

#### 五千比丘回心与授记

五千位修行菩萨乘而心想退转的比丘，因为见到妙慧菩萨意乐善根的威德殊胜，各自脱下身上所穿的上衣施给如来。这样布施之后，发弘誓说：“我们以这善根，决定愿成就阿耨多罗三藐三菩提。”那些善男子等因为以这善根回向无上菩提，超越了九十劫的生死之苦，对阿耨多罗三藐三菩提不退转。那时世尊便为他们授记说：“你们在未来世过一千劫之后，在无垢光明劫中，阳焰世界难忍佛刹，在一劫中相继成佛，都同一名号，号为辩才庄严如来，出现于世。

【按】“过千劫后”之“千”，宫本作“十”。

#### 付嘱流通

“文殊师利！这样的法门有大威德，能令菩萨摩诃萨以及声闻乘人获得大利益。文殊师利！或有善男子、善女人为求菩提，而没有善巧方便，修行六波罗蜜满一千劫。若又有人经过半月，时时书写、读诵此经，所获的福聚与前面的功德相比，前者百分不及一，千分、百千俱胝分，乃至算数譬喻所不能及。所以文殊师利！这样微妙的法门就是诸菩萨契经的根本。我现在付嘱给你，你在未来世受持、读诵、为人解说。譬如转轮圣王出现于世，所有七宝都在他面前，王灭之后，宝物随之隐没。像这样，这微妙法门流行于世，诸如来的七菩提分等法眼便不灭；若不流行，正法便当灭。所以文殊师利！若善男子、善女人等为求菩提，应当发起精进，书写此经，受持、读诵、为人演说。这是我的教导，不要在后世生起悔恨之心。”

【按】“皆悉在前”之“在”，明本作“拄”。“宝随隐没”之“随”，宋、元本作“隐”，宫本作“皆”。

佛说此经之后，妙慧菩萨、文殊师利菩萨以及大众，天、人、阿修罗、乾闼婆等，听闻佛所说，都大欢喜，信受奉行。

## 恒河上优婆夷会第三十一

唐·三藏菩提流志 奉诏译

【按】会题前，宋、元、宫本有“大宝积经”四字。译者题名“三藏”，宋、元、宫本作“三藏法师”；“诏”，宫本作“诰”；此行明本无。本会未见汉译异本。

#### 化人无所从来

如是我闻：一时，佛在舍卫国祇树给孤独园。当时舍卫城有一位优婆夷，名为恒河上，从她的住处来到佛所，顶礼佛足，退坐一面。那时世尊问恒河上：“你从哪里来？”那优婆夷便对佛说：“世尊！若问化人‘你从哪里来’，这样问，他应当怎样回答？”世尊告诉她说：“化人没有往来，也没有生灭，怎么能说有所从来？”她又问：“诸法难道不都如化吗？”佛说：“是这样，是这样，如你所说。”恒河上说：“若一切法都如化，为什么问我‘你从哪里来’？”

#### 不往善恶趣，不证涅槃

世尊告诉她说：“这幻化之人不往恶趣，不生天上，不证涅槃。恒河上！你也是这样吗？”她说：“我若见到自身异于幻化，才可以说往善恶趣、证于涅槃。我不见自身异于幻化，怎么能说往诸恶趣乃至涅槃？再者，世尊！如涅槃之性毕竟不再生于善恶趣以及般涅槃，我观察自身也是这样。”

佛说：“你难道不趣向涅槃界吗？”恒河上说：“若以这问题问无生者，他应当怎样回答？”佛说：“无生就是涅槃。”恒河上说：“诸法难道不都同于涅槃吗？”佛说：“是这样，是这样。”“世尊！若一切法都同于涅槃，为什么问我‘你难道不趣向涅槃界吗’？再者，世尊！譬如化人对化人说：‘你难道不趣向涅槃界吗？’他对这问题应当怎样回答？”世尊告诉她说：“这所问的没有攀缘。”恒河上说：“如来难道是以有所攀缘而这样问吗？”世尊告诉她说：“我所问的也没有攀缘。只是因为这会中有善男子以及善女人应当可以成熟，所以发这样的问。为什么呢？如来对那些诸法，连名字尚且不可得，哪里有诸法以及能趣向般涅槃的人？”

#### 无心积集与不思议处

恒河上说：“若是这样，为什么为了菩提而积集善根？”佛说：“若诸菩萨以及那善根都不可得，积集之时即是无心，不积集之时也是这样。”恒河上说：“所说的无心，是想说明什么义理？”世尊告诉她说：“这法不是思惟所能知，也不是思惟所能得。为什么呢？这其中心尚且不可得，何况心所生的法。因为心不可得，这便说名为不思议处。这不思议处，无得无证，非染非净。为什么呢？如来常说一切诸法犹如虚空，没有挂碍。”

#### 说有诸法如说我、如阳焰

恒河上说：“若一切法如虚空，为什么世尊说有色、受、想、行、识，以及界、处、十二因缘、有漏无漏、是染是净、生死涅槃？”佛告诉恒河上：“譬如说‘我’，虽有言说，而实际上没有我相可得。我说诸色，实际上也没有色相可得，乃至涅槃也是这样。又如阳焰，没有水可得，我说诸色乃至涅槃也是这样。恒河上！在我的法中修梵行的人，见一切法都无所得，才可以说名为真修梵行。有增上慢的人说有所得，这便不名为住于真梵行。我说这样有增上慢的人，听闻这甚深之法便生大惊疑，不能解脱生老病死、忧悲苦恼。恒河上！我灭度之后，若有人能宣说这样甚深的断流转之法，会有愚痴之辈由于恶见，对这法师生起瞋害之心，由于这因缘堕于诸地狱。”

#### 断流转法

恒河上说：“如佛所说的断流转之法，以什么义理名为断流转？”世尊告诉她说：“断流转，就是实际、不思议界，此法不可穿凿沮坏，所以说名为断流转之法。”

【按】“名为断流转”之“为”，宋、元、明、宫本无。

#### 世尊微笑，说往昔千佛

那时世尊和悦微笑，从面门放出种种光明，青、黄、赤、白、红、颇梨色，那光普照无量国土，上至梵世，又从如来顶上而入。那时尊者阿难见到这事，心中想：“如来、应、正等觉不是无因缘而现微笑的。”这样想之后，便从座起，偏袒右肩，右膝著地，合掌向佛这样说：“是什么因缘现出这微笑？”佛说：“我忆念往昔，有一千位如来也在此处宣说这样的法。那些法会中也各有恒河上优婆夷为上首，那优婆夷以及大众听了此法之后都出家，在无余涅槃中得到灭度。”

【按】“红”，元、明本作“红紫”；“颇梨”，明本作“玻瓈”。

#### 流通

阿难对佛说：“应当怎样称呼此经？我们应当怎样受持？”佛说：“此经名为‘离垢清净’，你应当以这名字受持。”宣说此经时，七百比丘众、四百比丘尼众诸漏永尽，心得解脱。那时欲界诸天子化作种种天上的妙花散在佛上，这样说：“这位优婆夷甚为希有，能与如来互相酬对，得无所畏。这人已在无量佛所亲近供养，种诸善根。”

佛说此经之后，恒河上优婆夷以及诸天、人、阿修罗、乾闼婆等，听闻佛所说，都大欢喜，信受奉行。
