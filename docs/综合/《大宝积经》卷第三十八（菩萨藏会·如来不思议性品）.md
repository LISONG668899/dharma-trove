# 《大宝积经》卷第三十八（菩萨藏会·如来不思议性品）

唐·三藏法师玄奘 奉诏译

## 菩萨藏会第十二之四

【按】本卷续《如来不思议性品》，专说如来十力，相当于《佛说大乘菩萨藏正法经》（T0316）《如来不思议品》中说十力的部分。

### 如来不思议性品第四之二

#### 七、如来不思议力：总说十力

那时，佛告诉舍利子：“菩萨摩诃萨怎样对如来不思议力信受谛奉，清净无疑，倍加踊跃，深生欢喜，生起希奇之想？舍利子！诸佛如来具足成就这样的十力，由于成就的缘故，如来、应、正等觉在大众中作正狮子吼，自称我处于大仙尊位，转大梵轮，一切世间所有沙门、婆罗门，或天、或魔、或梵等，都不能如法而转。舍利子！什么名为如来十力？就是处非处智力、业报智力、种种界智力、种种解智力、种种根智力、一切遍行行智力、静虑解脱三摩地三摩钵底杂染清净智力、随念前世宿住作证智力、死生作证智力、漏尽作证智力。舍利子！如来成就这样的十力，乃至在大众中能转梵轮，是一切世间所不能转的。

【按】“具足成就”之“具”，《大正藏》作“俱”，CBETA依高丽藏作“具”，今从之。

#### 第一力：处非处智力

“再者，舍利子！什么是如来的处非处智力？舍利子！如来无上智力的处非处，是说对于是处如实知道是处，对于非处如实知道非处。舍利子！什么是是处？什么是非处？舍利子！所说的非处，是无所摄受的：说身恶行、语恶行、意恶行能感得可喜、可乐、可爱、可意之报，无有是处。所说的是处，是有所摄受的：说身恶行、语恶行、意恶行能感得不可喜、不可乐、不可爱、不可意之报，斯有是处。又，舍利子！所说的非处，是无所摄受的：说身妙行、语妙行、意妙行能感得不可喜、不可乐、不可爱、不可意之报，无有是处。所说的是处，是有所摄受的：说身妙行、语妙行、意妙行能感得可喜、可乐、可爱、可意之报，斯有是处。

“再者，舍利子！所说的非处，是无所摄受的：说由悭吝而能感得大富，由犯戒而得生人天，由瞋恚而感得端正，由懈怠而能得到对观，心散乱的人能入正决定，由恶慧而能永断一切相续习气，这样说的，无有是处。所说的是处，是有所摄受的：说由悭吝而能感得贫穷，由毁犯戒律便感得地狱、畜生、鬼趣，由瞋恚而感得丑陋之报，由懈怠而不得对观，由心散乱而不入正定，由恶慧而不断一切相续习气，这样说的，斯有是处。又，舍利子！所说的非处，是无所摄受的：说由布施而能感得贫穷，由持戒而堕于地狱、畜生、鬼趣，由含忍而感得丑陋，由正勤而不得对观，由心一缘而不入正定，由圣慧而不断一切相续习气，这样说的，无有是处。所说的是处，是有所摄受的：说由布施而能感得大富，由持戒而得生人天，由怀忍而感得端正，由正勤而能得对观，由心一缘而入正决定，由圣慧而永断一切相续习气，这样说的，斯有是处。

“再者，舍利子！所说的非处，是无所摄受的：说因杀生而感得长寿，不与取者能得大富，行邪欲者感得贞良之妻，这样说的，无有是处。所说的是处，是有所摄受的：说杀生者能感得短寿，不与取者能感得贫穷，行邪欲者妻子不贞良，这样说的，斯有是处。又，非处是无所摄受的：说离杀者能感得短寿，离不与取能感得贫穷，离于邪欲而妻子不贞良，这样说的，无有是处。所说的是处，是有所摄受的：说离杀者能感得长寿，离不与取能感得大富，离邪欲者感得贞良之妻，这样说的，斯有是处。

“再者，舍利子！这样一切善与不善业道的是处非处，现在当略说，显示其要。说妄语者不感得诽谤，无有是处；若能感得，斯有是处。离妄语者能感得诽谤，无有是处；不感得诽谤，斯有是处。离间语者若能感得不坏的眷属，无有是处；不能感得，斯有是处。远离离间语而感得眷属破坏，无有是处；感得不坏的眷属，斯有是处。粗恶语者若能常闻可意之声，无有是处；闻不可意之声，斯有是处。离粗恶语而闻不可意之声，无有是处；若不闻，斯有是处。若怀绮语，感得所说言教令他人信受，无有是处；若不信受，斯有是处。若离绮语，所说言教令他人不受，无有是处；若信受，斯有是处。又，舍利子！若贪著者感得财物不散，无有是处；若感得散失，斯有是处。若离贪著而感得财物散失，无有是处；若不能感得，斯有是处。若心瞋恚而不趣地狱，无有是处；若有趣向，斯有是处。若离瞋恚而不生善趣，无有是处；若往生善趣，斯有是处。若兴邪见，受邪见之因而能得道，无有是处；不能得道，斯有是处。说正见者受正见之因而不得圣道，无有是处；能得圣道，斯有是处。

“再者，舍利子！造无间业者心得安住，无有是处；若不安住，斯有是处。又，舍利子！若戒清净者心不安住，无有是处；若得安住，斯有是处。又，舍利子！若住于有所得见而能得顺忍，无有是处；若不得，斯有是处。若信解空而不得顺忍，无有是处；若有所得，斯有是处。又，舍利子！若住于恶作而得心安息，无有是处；若不能得，斯有是处。若系心者不得心安，无有是处；若能得，斯有是处。又，舍利子！若有女人作转轮王、作帝释天主、作梵天自在，无有是处；若丈夫作，斯有是处。若有女人出世作佛，无有是处；转女身之后出世作佛，斯有是处。又，舍利子！若第八人未证果而出受，无有是处；证果之后出，斯有是处。若至圣流而受第八有，无有是处；即以此诸蕴而般涅槃，斯有是处。若一来之人受第三有，无有是处；即以此诸蕴而般涅槃，斯有是处。若不还之人又还于此，无有是处；即在彼处而般涅槃，斯有是处。若阿罗汉更续生有，无有是处；若不更续，斯有是处。又，舍利子！若诸圣人更求邪师、受邪标帜，无有是处；不求邪师及邪标帜，斯有是处。又，舍利子！若得无生法忍的菩萨有退转，无有是处；决定得菩提而无有退转，斯有是处。

【按】“而出受者”之“受”，宋、元、明、宫本作“定”。“第八人”即须陀洹向；“至圣流”即预流。

原文：“若第八人未证于果而出受者无有是处”（大意：若第八人未证果而出受，无有是处。“出受”所指未详，存疑。）

“再者，舍利子！所说的非处，是无所摄受的：若诸菩萨安坐道场，不证菩提而中途起座，无有是处。所说的是处，是有所摄受的：若诸菩萨坐于道场，证得佛道之后便起座，斯有是处。又，舍利子！所说的非处：若说如来有习气相续，无有是处。所说的是处：一切如来习气永断，斯有是处。又，舍利子！若说如来之智有障碍，无有是处；佛智无碍，斯有是处。又，舍利子！若有人能观见如来之顶，无有是处；无人能观，斯有是处。又，舍利子！若有人能知如来心之所住，无有是处；若不能知，斯有是处。又，舍利子！若说如来有不定之心可得，无有是处；诸佛世尊心恒在定，斯有是处。又，舍利子！若诸如来说不实之语，无有是处；若诸如来是真语者、实语者、谛语者、不异语者，斯有是处。又，舍利子！诸佛如来有误失可得，无有是处；由于无误失，所以名为佛及薄伽梵，斯有是处。舍利子！像这样，四无所畏、十八不共佛法，也应这样广为分别解说。

“再者，舍利子！所说的非处，是无所摄受的：乃至说如来在现在世有障有碍的智见运转，无有是处。所说的是处，是有所摄受的：佛薄伽梵在现在世有无障无碍的智见运转，斯有是处。舍利子！这名为如来的处非处智力，不可思议，无量无边。譬如虚空无边无际，如来的处非处智力无边无际也是这样。若有人想求如来、应、正等觉处非处智力的边际，无异于有人求虚空的边际。舍利子！菩萨摩诃萨听闻诸如来不可思议的是处非处智力如同虚空之后，信受谛奉，清净无疑，倍加踊跃，深生欢喜，生起希奇之想。”那时世尊想重宣此义，而说颂道：

```
十方虚空无边量，
处非处智亦无边，
如实知处非处已，
为众广宣微妙法。
解脱道器成就人，
佛知其行方为说，
若非解脱道器者，
知非处已便舍离。
假使虚空可移动，
十方大地同时裂，
世出世间大圣尊，
处非处智皆如实。
```
（大意：十方虚空无边无量，处非处智也无有边际；如实知道处与非处之后，为大众广宣微妙之法。对于成就了解脱道器的人，佛知其所行，才为他说法；若不是解脱道之器，知道是非处之后便舍离。假使虚空可以移动，十方大地同时破裂，世出世间的大圣尊，其处非处智都如实不虚。）

“舍利子！这名为如来第一处非处智力。由于成就的缘故，如来、应、正等觉在大众中作正狮子吼，自称我处于大仙尊位，转大梵轮，诸世间所有沙门、婆罗门，或天、魔、梵等，一切都不能如法而转。

#### 第二力：业异报智力

“再者，舍利子！什么是如来的业报智力？舍利子！如来、应、正等觉以无上智力，如实能知过去、未来、现在的业以及业受，或因、或处、或诸异报，都能了知。舍利子！如来怎样如实了知呢？就是如来、应、正等觉如实能知：过去的业受，得到善因，远离不善，在未来世将为善根之因；若过去的业受，得到不善因，远离善，在未来世将为不善根之因；这样的种种相，如来于此如实了知。若诸业受在未来世将随顺下劣分，若诸业受在未来世将随顺殊胜分，这样的种种相，如来于此如实了知。

“又，舍利子！若诸业受在现在世随顺下劣分，在未来世将随顺殊胜分；若诸业受在现在世随顺殊胜分，在未来世随顺下劣分；若诸业受在现在世随顺下劣分，在未来世也随顺下劣分；若诸业受在现在世随顺殊胜分，在未来世也随顺殊胜分；这样的种种相，如来于此如实了知。又，舍利子！若诸业受在过去世是狭劣的方便，在未来世是广大的方便；若诸业受少有所作而获大胜进，若诸业受广有所作而得少胜进；这样的种种相，如实了知。又，舍利子！若诸业受将为得声闻性之因，将为得独觉性之因，将为得佛性之因，这样的种种相，如来于此如实了知。又，舍利子！若诸业受在现在世是苦，能在未来感得乐的异报；若诸业受在现在世是乐，能在未来感得苦的异报；若诸业受在现在世是苦，能在未来感得苦的异报；若诸业受在现在世是乐，能在未来感得乐的异报；这样的种种相，如来于此如实了知。

“再者，舍利子！如来如实能知过去、未来、现在一切有情的业、因、诸异报，或即或离，或有随顺不异之分，这样的种种相，如来知道之后，为诸有情如实宣说。舍利子！如来、应、正遍知对于去来今的业以及业受、因、处所、异报之智，无量无边，不可思议。譬如虚空无边无际，如来的业异报智力无边无际也是这样。若有人想求如来、应、正等觉业异报智力的边际，无异于有人求虚空的边际。舍利子！菩萨摩诃萨听闻诸如来的业异报智力如同虚空、不可思议之后，信受谛奉，清净无疑，倍加踊跃，深生欢喜，生起希奇之想。”那时世尊想重宣此义，而说颂道：

```
如来善知因异报，
明眼如实了诸业，
最胜三世无有碍，
有情诸行如实知。
一切含灵于五趣，
当得成诸苦乐因，
若能转因所转苦，
明照善逝如实知。
黑白异报一切业，
随其所应因异报，
犹若掌中如意宝，
善逝了观如实知。
诸异报业因虽少，
当来获果无有量，
或无量因感少果，
善逝遍能如实知。
```
（大意：如来善知因与异报，以明眼如实了知诸业；最胜者对于三世无有障碍，对有情的种种行如实了知。一切含灵在五趣之中，将成就种种苦乐之因；若能转变其因、转变其所转之苦，明照的善逝都如实了知。黑白异报的一切业，随其所应的因与异报，犹如掌中的如意宝，善逝明了观察而如实了知。种种异报之业，其因虽少，将来所获之果却无有量；或无量之因感得少果，善逝都能遍知而如实了知。）

【按】“因异报”之“异”，宫本作“果”。

```
若因当证声闻果，
及当证于独觉果，
能感无上妙智力，
善逝无余如实知。
若业成熟因时苦，
此业当获于乐果，
若业成熟因时乐，
当获苦果如实知。
若业因果皆住苦，
若业因果皆住乐，
若业自体因自体，
善逝相应如实知。
苦果循环于三世，
有情流转五趣中，
最胜圆满菩提智，
皆能不异如实知。
```
（大意：若有因将证声闻果，以及将证独觉果，或能感得无上妙智之力，善逝都无余而如实了知。若业成熟、其因之时是苦，此业将获得乐果；若业成熟、其因之时是乐，将获得苦果，都如实了知。若业的因与果都住于苦，若业的因与果都住于乐，若业的自体与因的自体，善逝都相应而如实了知。苦果在三世中循环，有情在五趣中流转，最胜圆满的菩提之智，都能无误而如实了知。）

【按】“独觉果”之“果”，宫、圣本作“乘”。

“舍利子！这名为如来第二业异报智力。由于成就的缘故，如来、应、正等觉在大众中作正狮子吼，自称我处于大仙尊位，转大梵轮，诸世间所有沙门、婆罗门，或天、魔、梵等，一切都不能如法而转。

#### 第三力：种种解智力

“再者，舍利子！什么是如来的种种解智力？舍利子！如来、应、正等觉以无上智力，能如实了知那些有情类、那些数取趣，非一的欲解、种种的欲解，如来对此都能了知。舍利子！我再为你广为分别解说。那些数取者，或住于贪欲而起瞋恚之解，或住于瞋恚而起贪欲之解，乃至住于愚痴而起贪瞋之解，这样的种种相，如来都能如实了知。又，舍利子！若数取者住于不善而起不善之解，或住于善法而起善解，这也是如来如实了知的。若数取者住于下劣的方便而起广大之解，或住于广大的方便而起下劣之解，或由此解而在下劣的方便中将住于胜进，或由此解而在胜进的方便中将住于下劣，这也是如来如实了知的。又，舍利子！若由此解将种下邪定之种，若由此解将种下正定之种，若由此解将种下正定解脱之种，这也是如来如实了知的。又，舍利子！若由此解将趣向欲界，或趣向色界，或趣向无色界，若由此解遍趣三界，这也是如来如实了知的。又，舍利子！若由此解随顺下劣分而将获得胜进，或得到胜进而将住于下劣，这也是如来如实了知的。又，舍利子！若由此解将在来世受种种生、受种种类、种种受用，这也是如来如实了知的。又，舍利子！若由此解将从顶位退堕，或由此解种下解脱之种，这也是如来如实了知的。了知之后，如其所应，广为有情如法演说。这样，舍利子！如来非一解、种种解的智力，不可思议，无边无际，与虚空相等。这些菩萨摩诃萨听闻如来的种种解智力如同虚空、不可思议之后，信受谛奉，清净无疑，倍加踊跃，深生欢喜，生起希奇之想。”那时世尊想重宣此义，而说颂道：

```
世间种种解，过现无有量，
彼种种解心，导师皆能了。
若有贪解者，复当住瞋恚，
或现住瞋恚，痴解如实知。
住痴起贪解，心注不思议，
间杂流转起，导师悉能知。
诸下劣方便，而起广大解，
或增上方便，导师悉能知。
随入于邪性，复入所不趣，
解脱三界解，如来悉能知。
种种生及类，诸受用差别，
若退堕于顶，两足尊能知。
知种种解已，导师如法说，
是第三佛力，最胜子能信。
```
（大意：世间的种种胜解，过去与现在无有限量，那些种种胜解之心，导师都能了知。若有贪欲之解的人，又将住于瞋恚；或现在住于瞋恚，其痴解也如实了知。住于痴而起贪解，其心之所注不可思议，间杂流转而起，导师全都能知。诸下劣的方便而起广大之解，或增上的方便，导师全都能知。随入于邪性，又入于所不趣之处，以及解脱三界之解，如来全都能知。种种的生与类，种种受用的差别，或从顶位退堕，两足尊都能知。知道种种胜解之后，导师如法宣说，这是第三种佛力，最胜佛子能够信受。）

【按】“心注不思议”之“注”，宫本作“生”。“复入所不趣”之“趣”，宋、宫本作“起”。“退堕顶”，“顶”即四加行位中的顶位。

“舍利子！这名为如来第三种种解智力。由于成就的缘故，如来、应、正遍知在大众中作正狮子吼，自称我处于大仙尊位，能转梵轮，一切世间沙门、婆罗门以及天、魔、梵，都不能如法而转。

#### 第四力：种种界智力

“再者，舍利子！什么是如来的种种界智力？舍利子！如来、应、正等觉以无上智力，如实了知一切世间的种种诸界：由于此界，世间含生集起福行、集起非福行、集起不动行，或由此界种下出离之种，这样的种种界，如来于此如实了知。又，舍利子！如来如实了知眼界、色界以及眼识界。这样的种种界怎样了知呢？就是如实了知，由于内空、外空、内外空的缘故；乃至如实了知意界、法界以及意识界。这样的种种界怎样了知呢？就是如实了知，由于内空、外空、内外空的缘故。又如实了知地界、水界、火界、风界。这样的种种界怎样了知呢？就是如实了知，它们如同空界。这样，欲界、色界以及无色界都如实了知，因为是遍计分别所起的。又如实了知：有为界，是造作之相；无为界，是无造作之相；杂染界，是烦恼所引之相；清净界，是自体光净之相。又如实了知：诸行界，是不顺理的无明之相；涅槃界，是顺理的明之相。这样的种种界都能明了。所以，舍利子！若有界能安立世间，此界便是世间所依住的；这样，若有界能发起牵引，若有界能兴起建立，若有界能生起方便，若有界能生起意欲，若有界能生起炽然，若有界能作为依止，舍利子！这样的种种界无量无边，也是如来如实明了的。明了之后，如其所应，广为有情如法演说。舍利子！如来非一界、种种界的智力，不可思议，无有边际，与虚空相等。若有人想求如来种种界智力的边际，无异于有人求虚空的边际。这样，舍利子！这些菩萨摩诃萨听闻如来的种种界智力如同虚空、不可思议之后，信受谛奉，清净无疑，倍加踊跃，深生欢喜，生起希奇之想。”那时世尊想重宣此义，而说颂道：

```
世间诸含生，依止种种界，
随其所流转，最胜悉能知。
福非福不动，及顺于出离，
住如是界已，证寂静涅槃。
若眼界色界，及以眼识界，
耳鼻舌身意，诸界悉能知。
又知于法界，及以意识界，
内外界悉空，佛能如实知。
地界及水界、火界与风界，
四界同空相，如是悉能知。
```
（大意：世间的种种含生，依止于种种界，随其所流转，最胜者全都能知：福行、非福行、不动行，以及随顺出离之界，住于这样的界之后，证得寂静涅槃。若眼界、色界以及眼识界，耳、鼻、舌、身、意诸界，全都能知。又知道法界以及意识界，内外诸界都是空，佛能如实了知。地界以及水界、火界与风界，四界同是空相，这样全都能知。）

【按】“火界与风界”之“火”，《大正藏》作“水”，CBETA依高丽藏作“火”，今从之。

```
若欲界色界，及以无色界，
遍分别所起，佛能如实知。
如虚空无边，界无边亦尔，
佛皆能照了，不谓我能知。
诸界本无生，亦无有灭者，
是谓涅槃界，胜丈夫能知。
如空量无边，诸佛智如是，
由智能了知，变异于诸界。
已知种种界，调伏诸含生，
是佛第四力，最胜子能信。
```
（大意：若欲界、色界以及无色界，是遍计分别所起，佛能如实了知。如虚空无有边际，界的无边也是这样，佛都能照了，却不说“我能了知”。诸界本来无生，也没有灭者，这名为涅槃界，殊胜丈夫能够了知。如虚空的量无有边际，诸佛之智也是这样，由于智慧能了知诸界的变异。了知种种界之后，调伏一切含生，这是佛的第四种力，最胜佛子能够信受。）

“舍利子！这名为如来第四非一界、种种界智力。由于成就此力，如来、应、正等觉在大众中作正狮子吼，自称我处于大仙尊位，能转梵轮，是一切世间沙门、婆罗门以及天、魔、梵所不能转的。

#### 第五力：种种根智力

“再者，舍利子！什么是如来非一根、种种根的智力？舍利子！如来、应、正等觉以无上智力，如实能知其他有情、诸数取者种种诸根的差别之相，如来都能分别了知。舍利子！这样的种种相怎样了知呢？就是了知钝根、中根、利根、胜根、劣根，因为随遍分别诸根的缘故；能知众生生起极重的贪、生起极重的瞋、生起极重的痴，这样的诸根也是如来如实了知的。又，舍利子！由于随遍分别诸根的缘故，如来能知：或生起假立的贪瞋痴，或生起微薄的贪瞋痴，或生起颠倒的贪瞋痴，或生起被摧伏的贪瞋痴，这样的种种相，也是如来如实了知的。又，舍利子！若由不善之因所生的诸根，若由善因所生的诸根，若由不动之因所生的诸根，若由出离之因所生的诸根，也是如来如实了知的。

【按】“如是诸根”之“根”，明本作“相”。“不动因”之“动”，《大正藏》作“勤”，CBETA依高丽藏作“动”，今从之。

“又，舍利子！如来如实了知眼根、耳根、鼻根、舌根、身根、意根，女根、男根、命根，乐根、苦根、忧根、喜根、舍根，信根、正勤根、念根、慧根、三摩地根，未知当知根、知根、知已根，这样的诸根差别之相，也是如来如实了知的。又，舍利子！如来如实了知那些诸根：因于眼根，将住于耳根，而不住于那鼻、舌、身根；或因于耳根，将住于鼻根；或因于鼻根，将住于舌根；或因于舌根，将住于身根；或因于身根，将住于眼根；这样的种种根，如来于此如实了知。

“再者，舍利子！若诸有情住于布施之根而修持戒的方便，那时如来以胜劣根智为他宣说布施；若住于持戒之根而修布施的方便，为他宣说持戒；若住于忍辱之根而修正勤的方便，为他宣说忍辱之法；住于正勤之根而修忍辱的方便，为他宣说正勤；住于静虑之根而修智慧的方便，为他宣说静虑；若住于智慧之根而修禅定的方便，为他宣说正慧；这样，一切菩提分法的诸根差别如实了知，都应广说。又，舍利子！若诸有情住于声闻之根而反修独觉的方便，如来以诸根智为他宣说下乘；住于独觉之根而修声闻智的方便，以诸根智为他宣说中乘；住于大乘之根而修二乘智的方便，以诸根智为他宣说大乘；住于下劣之根而修大乘之行，以诸根智为他宣说二乘。若诸有情没有堪任之根、没有堪任之相，如来如实了知他无堪任、非法器之后，便舍置不说；若诸有情有堪任之根、有堪任之相，如来如实了知他有堪任、是法器，便殷勤郑重地为他说法，令他悟入。这样，舍利子！如来了知一切有情诸根的纯熟与不纯熟，诸根的出离与不出离。舍利子！诸有情的根，如来如实一切了知：住于这样的相、这样的方便、这样的信解、这样的本因、这样的所缘、这样的等流、这样的究竟。舍利子！如来的种种根智不可思议，无边无际，与虚空相等。若有人想求如来诸根智力的边际，无异于有人求虚空的边际。诸菩萨摩诃萨听闻这根力如同虚空之后，信受谛奉，清净无疑，倍加踊跃，深生欢喜，生起希奇之想。”

【按】“而便舍置”之“便”，明本作“复”。

那时世尊想重宣此义，而说颂道：

```
到根彼岸含灵尊，
善达有情意性行，
随诸众生根所堪，
人中师子为说法。
下中上根所堪任，
善逝胜智根中起，
观彼解脱器心已，
知行慧者为说法。
若人诸根能发起，
至极相续微烦恼，
善达彼人所有根，
知行随顺为说法。
若诸丈夫有善根，
随勤信欲广开示，
又随根行相差别，
说诸胜义定慧等。
若人发起于信欲，
慧者随根说净道，
知彼所行众行已，
为说胜法超诸苦。
有定住佛菩提根，
迷倒误转声闻智，
为说大乘成正觉，
此佛难伏第五力。
```
（大意：到达诸根彼岸的含灵之尊，善达有情的意、性与行，随众生根之所堪受，人中狮子为之说法。下、中、上根所堪任的，善逝的殊胜之智从诸根中生起，观察他们是否为解脱之器之后，知其所行的智者为之说法。若人的诸根能够发起，至极相续的微细烦恼，善达那人所有的根，知其所行而随顺说法。若诸丈夫有善根，随其勤、信、欲而广为开示，又随根与行相的差别，宣说种种胜义、禅定、智慧等。若人发起信欲，智者随其根而宣说清净之道，知道他所行的种种行之后，为他宣说超越诸苦的殊胜之法。有人安住于佛菩提之根，却迷倒误转为声闻之智，为他宣说大乘，令成正觉，这是佛难以被摧伏的第五种力。）

“舍利子！这名为如来第五种种根智力。由于成就此力，如来在大众中作正狮子吼，自称我处于大仙尊位，能转梵轮，一切世间沙门、婆罗门以及天、魔、梵，都不能如法而转。

#### 第六力：遍趣行智力

“再者，舍利子！什么是如来的遍趣诸行智力？舍利子！如来、应、正等觉以无上智力，如实了知遍行的诸行。舍利子！这样的种种相怎样了知呢？就是能了知有情之性等：正定之性、不正定之性以及邪定之性。舍利子！什么名为正定之性？就是由于因力和先世的方便，开智利根所生的缘故。诸如来无论为他说法或不说法，如来都如实了知那有情前世的因果堪为法器，随其所应而说法，令其迅速解脱。舍利子！什么名为不定之性？是由外缘之力而成熟的相：若得到如法的教授教诫，便可得解脱；若得不到如法的教授教诫，便不得解脱。如来为他们宣说随顺缘因相应之法，那些有情听闻正法之后，如理修行，证得解脱之果。为了令这样的众生得到义利，诸佛世尊出现于世。舍利子！什么名为邪定之性？就是有情之性被烦恼所蔽，不修净业，识性薄弱，愚痴深厚，住于邪见之网，不是正法之器；即使如来为他说法或不说法，终究不能堪任证得解脱。如来如实了知那有情不是法器之后，便舍置不说。所以，舍利子！诸菩萨摩诃萨怜悯这些有情，为了利益他们，披上弘誓铠甲，进入邪见之军，教化摧伏。

“又，舍利子！如来如实了知三种贪行：或由净美之相而起贪行，或由爱恋之相而起贪行，或由先世之因而起贪行。又能了知三种瞋行：或由损害之相而起瞋行，或由委练观察而起瞋行，或由先世随眠而起瞋行。又能观察了知三种痴行：或有痴行因无明而生，或有痴行因妄有身见而生，或有痴行因疑而生。这样一切，如来都能如实了知。

【按】“先世因”，宫、圣本无“世”字。“又观了知”之“观”，宋、元、明、宫本作“能”。

“再者，舍利子！如来如实了知诸行：苦行与乐行都能迅速通达，因为诸根锐利；苦行与乐行都是迟缓通达，因为诸根迟钝。又如实了知：迟行而迟通，因为舍弃所缘；迟行而速通，因为修道不止息；速行而迟通，因为勇决精进；速行而速通，因为不是那种性。又如实了知：或有诸行，简择之力圆满而修习之力不满；或有诸行，修习之力圆满而简择之力不满；或有诸行，简择与修习二力都圆满；或有诸行，简择与修习之力都不满；这样的种种相，如来都能如实了知。又如实了知：或有诸行，信欲具足而方便不具足；或有诸行，方便具足而信欲不具足；或有诸行，信欲与方便都不具足；或有诸行，信欲与方便二者都具足；这样一切都能了知。又如实了知：或有诸行，身业清净而不由语与心；或有诸行，语业清净而不由身与心；或有诸行，心业清净而不由身与语；或有诸行，非由身、语、心；或有诸行，由身、语、心而得清净。舍利子！这样乃至一切有情所有的诸行，或因于流转，或因于不流转，或因于流转与不流转，如来以无碍智见的缘故，在这样的一切处中运转。这样，舍利子！如来遍趣行智力不可思议，无边无际，与虚空相等，诸菩萨摩诃萨听闻这智力不可思议、如同虚空之后，信受谛奉，清净无疑，倍加踊跃，深生欢喜，生起希奇之想。”

原文：“速行速通，非彼性故”（大意：速行而速通，因为不是那种性。所指未详，存疑。）

【按】“简择”之“简”，宋、元、明、宫本作“拣”。“遍教行智力”之“教”，宋、元、明、宫、圣本作“趣”，与前文“遍趣诸行智力”相合，今依之译作“遍趣行”。

那时世尊想重宣此义，而说颂道：

```
善逝如实了诸行，
能知定因有情性，
又知不定成熟相，
及诸根因相应法。
诸行三种贪相应，
及与三种瞋痴合，
无边广惑相应行，
缘因大师如实知。
诸有苦行而根利，
及有此行而钝根，
诸有乐行根利钝，
世大依怙如实知。
诸有钝行及钝修，
或复行钝而修利，
或复行速而修迟，
或有俱速非彼性。
或有诸行简择生，
不由修习道力起，
```
（大意：善逝如实了知诸行，能知正定之因的有情之性，又知不定之性的成熟之相，以及诸根与因相应之法。诸行中与三种贪相应的，以及与三种瞋、三种痴相合的，与无边广大的烦恼相应的行，大师都依其缘与因而如实了知。诸有苦行而根利的，以及有此苦行而根钝的，诸有乐行而根利或根钝的，世间的大依怙都如实了知。诸有行迟钝而修习也迟钝的，或行迟钝而修习锐利的，或行迅速而修习迟缓的，或有二者都迅速而不是那种性的。或有诸行从简择而生，不由修习道力而起；或从修习而生而非简择；或俱生，或别异，或共同相应。）

```
或修习生非简择，
俱生别异共相应。
或有诸行信欲转，
清净而非方便净，
或有返此俱不俱，
佛遍智者皆明了。
复有净修于身业，
非语非心业清净，
或复语净及身净，
而彼心体非清净。
或有内心常清净，
身语二业非清净，
或复语净及心净，
而彼身业未甞净。
或身语心净不净，
诸行流转及寂灭，
遍智见者如实知，
是为如来第六力。
```
（大意：或有诸行随信欲而转，清净而不是方便清净；或有与此相反，或俱或不俱，佛遍智者都能明了。又有清净地修习身业，而不是语业、心业清净；或者语业清净以及身业清净，而那心体并不清净。或有内心常清净，而身语二业不清净；或者语业清净以及心业清净，而那身业从未清净。或身语心清净或不清净，诸行的流转以及寂灭，遍智见者都如实了知，这是如来的第六种力。）

【按】“佛遍智者皆明了”，宋、元、明本“皆”作“能”，宫、圣本“明”作“开”。

“舍利子！这名为如来第六遍趣行智力。由于此力，如来自称处于大仙尊位，转大梵轮，乃至没有能如法而转的。

#### 第七力：静虑解脱等持等至杂染清净智力

“再者，舍利子！什么是如来的静虑、解脱、三摩地、三摩钵底发起杂染清净智力？舍利子！如来、应、正等觉以无上智力，如实了知自己与他人一切静虑、解脱、三摩地以及三摩钵底发起杂染与清净之法。舍利子！这样的种种相怎样了知呢？就是如实了知：由于因、由于缘，一切有情能被杂染；又如实了知：由于因缘，一切有情能得清净。

“舍利子！什么因、什么缘能令杂染？舍利子！以不称理作意为因、无明为缘，令诸有情发起杂染。这样，以无明为因、诸行为缘，以诸行为因、识为其缘，以识为因、名色为缘，以名色为因、六处为缘，以六处为因、诸触为缘，以诸触为因、受为其缘，以受为因、爱为其缘，以爱为因、取为其缘，以取为因、有为其缘，以有为因、生为其缘，以生为因、老死为缘，以烦恼为因、诸业为缘，以诸见为因、爱为其缘，以随眠为因、诸缠为缘。舍利子！由于这样的种种因缘，令诸有情发起杂染，这样的种种相，也是如来如实了知的。

“舍利子！什么因、什么缘能令清净？舍利子！有二因二缘能令一切有情清净，就是由于他人的随顺之音以及由于内心自己的如理作意，又有奢摩他缘于一境以及毘钵舍那的善巧方便。又有二因二缘能令清净，就是不来之智以及不去之智。又有二因二缘能令清净，就是无生之观以及证入正定。又有二因二缘能令清净，就是行具足以及明与无明的解脱作证。又有二因二缘能令清净，就是修习解脱门以及性解脱之智。又有二因二缘能令清净，就是随觉谛以及随得谛。舍利子！这样的种种因、种种缘能令一切有情清净，也是如来如实了知的。

【按】“由内自如理作意”之“由”，宫本作“曰”。

原文：“谓行具足及明无明解脱作证”（大意：就是行具足以及明与无明的解脱作证。“明无明解脱”所指未详，存疑。）

“再者，舍利子！如来如实了知诸有情的杂染境界，了知诸有情的清净境界：或有杂染境界入于清净境界，或有清净境界入于杂染境界，这都是由于如实观察的缘故；或有杂染境界入于杂染境界，或有清净境界入于清净境界，这都是由于增上慢执著的缘故。如来在其中以如实之智运转。又，舍利子！如来以如实之知，在诸静虑中超越、间杂、差别而运转，就是离欲、恶不善法，有寻有伺，离生喜乐，具足安住于最初静虑；如来安住于初静虑后，从灭尽定出；这样乃至入灭尽定后，从初静虑出。又，舍利子！如来以如实之知，对于八解脱，或顺次而入，或逆次而入，或顺逆而入，或间杂而入。舍利子！这样的解脱是哪八种？就是有色观诸色，是初解脱；内无色想、外观诸色，是第二解脱；于净解脱，或对于净性生起净解，是第三解脱；虚空想处定，是第四解脱；识想处定，是第五解脱；无所有处定，是第六解脱；非有想非无想处定，是第七解脱；若想受灭，是第八解脱。

【按】“以如实知”之“知”，宋、元、明、宫本作“智”。“内无色想”之“想”，元、明本作“相”。

“又，舍利子！如来以如实之智，或安住于一种三摩地中，而又示现其余的三摩地以及三摩钵底，又示现种种观解，而诸如来对于诸等持从未混乱。又，舍利子！诸佛如来不缘于三摩地而入于三摩地，或依一种三摩地而成就其余一切三摩地，或不起于一种三摩地而能遍入诸三摩地。又，诸如来之心常住于定，无有展转攀缘；又，诸如来没有不定之心可得。诸佛如来住定深妙，没有谁能观察如来所得的三摩地。舍利子！声闻所得的三摩地被独觉的三摩地所映夺，独觉所得的三摩地被诸菩萨的三摩地所映夺，菩萨所得的三摩地被诸佛的三摩地所映夺，如来所得的三摩地无有能映夺的。为什么？因为诸如来无可映夺之智常现在前运转。舍利子！如来如实了知：以这样的教授、这样的教诫，能发起声闻、独觉的诸三摩地；又以这样的教授教诫，能发起诸菩萨等的美妙三摩地。诸佛如来如实了知之后，便作这样的教授教诫。舍利子！如来静虑、解脱、三摩地、三摩钵底杂染清净发起智力，不可思议，无边无际，与虚空相等，若有人想求如来定力的边际，无异于有人求虚空的边际。舍利子！诸菩萨摩诃萨听闻这诸定智力不可思议、如同虚空之后，信受谛奉，清净无疑，倍加踊跃，深生欢喜，生起希奇之想。”那时世尊想重宣此义，而说颂道：

```
由此有情兴杂染，
由此有情得清净，
大雄如是了知已，
广为宣扬微妙法。
由彼违理作意因，
无明为缘生杂染，
复因无明诸行缘，
乃至展转生诸苦。
违理作意及无明，
为彼有支生根本，
诸佛如实了知已，
随其所应宣妙法。
一切杂染之根本，
所谓业行及无明，
复从此缘生诸识，
如是展转兴诸苦。
由彼所说随顺音，
及由内怀如理观，
如斯二因二缘故，
一切含灵证清净。
```
（大意：由此有情兴起杂染，由此有情得到清净，大雄这样了知之后，广为宣扬微妙之法。由于那违理作意之因、无明为缘而生起杂染，又因无明、以诸行为缘，乃至展转生起诸苦。违理作意以及无明，是那有支生起的根本，诸佛如实了知之后，随其所应宣说妙法。一切杂染的根本，就是业行以及无明，又从此缘生起诸识，这样展转兴起诸苦。由于那所说的随顺之音，以及由于内心怀有如理之观，以这样的二因二缘，一切含灵证得清净。）

```
由奢摩他如理因，
及由毘钵舍那缘，
如是含灵证解脱，
大师如实皆能了。
行者安住净尸罗，
观察诸法皆空寂，
已善修习解脱门，
远离诸有迫迮苦。
此皆诸佛如实知，
一切有情清净行，
空无相愿解脱门，
善逝随根而显示。
独觉最胜及声闻，
顺逆履游诸静虑，
如来宣示彼所证，
如有毒刺及怨雠。
诸佛所证定解脱，
究竟无怨无毒刺，
当知第七如来力，
不为异证所摧伏。
```
（大意：由于奢摩他如理之因，以及由于毘钵舍那之缘，这样含灵证得解脱，大师都能如实了知。行者安住于清净尸罗，观察诸法都是空寂，已善修习解脱门，远离诸有逼迫狭窄之苦。这都是诸佛如实了知的一切有情的清净之行，空、无相、无愿的解脱门，善逝随其根性而显示。独觉中最胜者以及声闻，顺逆游履于诸静虑，如来宣示他们所证的，如同有毒刺以及怨雠。诸佛所证的禅定解脱，究竟无怨无毒刺，应当知道这第七种如来之力，不被其他的证悟所摧伏。）

“舍利子！这名为如来第七诸定智力。由于得到此力，如来自称处于大仙尊位，转大梵轮，乃至没有能如法而转的。

#### 第八力：宿住随念作证智力

“再者，舍利子！什么是如来的宿住随念作证智力？舍利子！如来、应、正等觉以无上智力，随所忆念而如实了知。舍利子！如来这样如实了知自己与他人一切有情的无量宿住：或念一生、十生、百生、千生，乃至无量拘胝那庾多百千生，都能随念而知。又随念知道劫坏、劫成，或劫成坏，或无量劫坏、无量劫成、无量劫成坏，或者随念百拘胝劫乃至无量百千拘胝那庾多劫，都能了知。又能随念：我在先世曾在某某处，是这样的名，这样的姓，这样的种类，这样的饮食，这样的色，这样的相，这样的形貌，这样的寿量，这样的久住，这样的苦乐；我在某某处命终，生到某某处，又在某某处命终，来生此处。这样，无论自己或他人，以及种种形相、处所、流类的无量宿住，都能随念而一并了知。

“又，舍利子！如来如实了知一切有情随其往昔之因，因为这因的缘故，这样的有情来生于此，知道这因之后，随其所应而说法。又能了知一切有情在过去世中诸心的相续：此心无间缘于这样的境，这样的心生起；由于所缘不具足，这样的心灭去；这样一切，如来都如实随念了知。又，舍利子！若一个有情的心生起展转，从这样的心无间次第这样相续，在殑伽沙劫中以种种言说也不能说尽。如一个有情的心相是这样，一切有情的心也是这样，如来随着他们所有一切心相，都能随念如实了知。又，舍利子！如来依诸有情诸心的展转，即使尽于后际的拘胝劫数也说不尽，而如来之智也无有穷尽。

“再者，舍利子！如来的宿住随念作证智力，不可思议，无有等者，无等等者，无量无数，不可宣说，又不可说它有边际穷尽。舍利子！如来以佛神力加持诸有情，令他们忆念宿住，而告诉他们说：‘你们现在应当忆念在过去世已种下这样的善法之根，或在佛所，或在声闻所，或在独觉所，或在正法中种下种种善根，这样的善根都应当忆念。’那些有情以如来之力，随念都能知道。舍利子！这样，如来以佛神力加持那些有情，令他们知道宿住中无量善根的所缘之境后，如其所应而为说法。舍利子！若诸有情对于阿耨多罗三藐三菩提得不退转，随其欲解而求出离，或依声闻乘，或依独觉乘，或发阿耨多罗三藐三菩提心，这样，如来以随念智力如实了知。这样，舍利子！如来宿住随念作证智力，不可思议，无量无数，无有边际，与虚空相等，若有人想求如来宿住随念的边际，无异于有人求虚空的边际。舍利子！诸菩萨摩诃萨听闻这宿住智力不可思议、如同虚空之后，信受谛奉，无惑无疑，乃至踊跃欢喜，生起希奇之想。”那时世尊想重宣此义，而说颂道：

```
不思那庾拘胝劫，
照世明灯悉随念，
亦念过往自他生，
如观掌内五庵果。
随念名姓色分别，
住寿命尽诸生趣，
含灵具足如是因，
知时如应为说法。
诸过去世无边际，
众生所有心心法，
是心无间是心生，
最胜大智皆能了。
善逝了知一有情，
过往无间心相续，
如殑伽沙拘胝劫，
不能说尽其边际。
```
（大意：不可思议的那庾多拘胝劫，照世的明灯都能随念；也忆念过去自己与他人的生世，如观掌中的五个庵摩罗果。随念其名、姓、色等分别，其住、寿命尽以及诸生趣，含灵具足这样的因，知道时机而如应说法。诸过去世无有边际，众生所有的心与心法，此心无间、此心生起，最胜大智都能了知。善逝了知一个有情过去无间的心相续，即使如殑伽沙拘胝劫，也不能说尽其边际。）

```
乃至后际拘胝劫，
演诸含灵往所行，
而不与等智无尽，
是名诸佛智海量。
一切有情善信欲，
已曾供养诸世尊，
佛威神力所加被，
令缘过去修净行。
大师随念彼所受，
过去曾修诸福行，
念彼所住三乘智，
不退解脱所依处。
善逝称往无边智，
诸有情界难思议，
无边名称第八力，
最胜长子能信受。
```
（大意：乃至后际的拘胝劫中，演说诸含灵往昔所行，而无有能等同的，其智无尽，这名为诸佛智海之量。一切有情的善信欲，已曾供养诸世尊，以佛威神力所加被，令他们缘念过去所修的清净之行。大师随念他们所受的、过去曾修的种种福行，忆念他们所住的三乘之智，是不退解脱所依之处。善逝称说往昔无边之智，诸有情界难以思议，无边名称的第八种力，最胜长子能够信受。）

【按】“而不与等智无尽”之“不”，宋、元、明、宫、圣本作“无”。

“舍利子！这名为如来第八宿住智力。由于得到此力，如来自称处于大仙尊位，转大梵轮，乃至没有能如法而转的。

#### 第九力：天眼死生作证智力

“再者，舍利子！什么是如来的天眼通作证智力？舍利子！如来、应、正等觉以无上智力，以清净天眼超过于人，观察诸有情死于此而生于彼，或劣或胜，好色恶色，随其所习之业，或往善趣，或往恶趣，这样的种种相，如来明见而如实了知。又能如实了知诸含灵所造的业行：这样的有情成就身恶行、成就语恶行、成就意恶行，诽谤贤圣，生起种种邪见，他们乘着这样的邪见业受之因，身坏命终，堕于诸恶趣，或生地狱，或生畜生，或生鬼趣。如来又知道：这样的有情成就身妙行、成就语妙行、成就意妙行，不谤贤圣，修行正见，他们乘着这样的正见业受之因，身坏命终，往诸善趣，或生到天上的安乐世界中。

“又，如来以清净天眼观察十方，不可宣说、超过殑伽沙数、穷尽虚空际、穷极法界量的诸佛世界种种相状：或者现见诸佛刹土有正在燃烧的，或见刹土有正在毁坏的，或见刹土有正在形成的；又现见一切含识死时、生时；或者现见诸大菩萨从覩史多天降神入母胎，或者现见出母胎，或见向诸方各行七步，或者现见入处内宫，或见出家示现修苦行，或见诸佛觉悟大菩提，或者现见转大法轮，或者现见舍弃诸寿行而入大涅槃；或者现见诸声闻众一切毕竟入般涅槃，或者现见一切独觉示现种种神通、报答净施之福而入涅槃。又，有些有情不是可以现见的，却为如来天眼所见，也不是那外道五通仙人之眼所能见，也不是声闻、独觉、菩萨等之眼所能见，那一切如来天眼都能现见。这样不可现见的微细众生，在车轮大小的范围内，如来以天眼观察，多于三千大千世界所有的人与天。这样一切无量无边，不可思议，如来都能如实明见。舍利子！如来以清净天眼观察一切无量佛土诸含灵之性：什么样的众生是如来所化度的？什么样的众生见到如来之后才得调伏？如来那时随其所应利益而显现，就在他面前令他悟解，不是其余众生所能知道的。这样，舍利子！如来天眼随念作证智力，不可思议，无有边际，与虚空相等，若有人想求如来天眼智力的边际，无异于有人求虚空的边际。舍利子！诸菩萨摩诃萨听闻这样的力不可思议、如同虚空之后，信受谛奉，乃至生起希奇之想。”那时世尊想重宣此义，而说颂道：

【按】“随应利见”之“见”，宋、元、明、宫本作“现”。

```
善逝天眼净无垢，
净业修治无量劫，
最胜由是观十方，
无垢难思诸佛土。
或坏或成或成坏，
乃至起住火洞然，
或有佛住或无佛，
自然尊眼悉能见。
有情性广难思议，
乃至有色及无色，
若堕恶趣善趣生，
自然尊眼悉能见。
或多拘胝佛现在，
或现如来入涅槃，
并及缘觉若声闻，
自然尊眼悉能见。
或为利生诸菩萨，
或行近妙菩提行，
住诸如来无障处，
自然导师皆能见。
善逝如是眼无垢，
能见极细诸众生，
第九眼力不思议，
最胜聪慧了能信。
```
（大意：善逝的天眼清净无垢，是在无量劫中以净业修治而成；最胜者由此观察十方无垢而难思的诸佛国土：或坏，或成，或成坏，乃至生起、安住、大火洞燃；或有佛住，或无佛住，自然尊的眼都能看见。有情之性广大难以思议，乃至有色以及无色，或堕恶趣，或生善趣，自然尊的眼都能看见。或有众多拘胝佛现在，或显现如来入涅槃，以及缘觉或声闻，自然尊的眼都能看见。或为利益众生的诸菩萨，或修行接近妙菩提之行，住于诸如来无障碍之处，自然导师都能看见。善逝这样的眼无有垢染，能见极微细的诸众生，第九眼力不可思议，最胜聪慧者能了知信受。）

【按】“佛现在”之“在”，宫、圣本作“住”。“聪慧了能信”之“了”，元、明、宫本作“子”。

“舍利子！这名为如来第九天眼智力。由于此力，自称我处于大仙尊位，转大梵轮，乃至一切世间都不能如法而转。

#### 第十力：流尽作证智力

“再者，舍利子！什么是如来的流尽作证智力？舍利子！如来、应、正等觉以无上智力，如实了知：为了尽诸流而成无流，心解脱、慧解脱，以自然通慧作证具足而住；如实了知：我生已尽，梵行已立，所作已办，不受后有。舍利子！如来的流尽智力清净无垢，光洁圆照，永断一切相续习气。诸声闻乘虽然也流尽，只能断除少分习气；诸独觉乘虽然也流尽，也能断除少分习气，却远离大悲以及种种才辩。唯有如来诸流永尽，具足一切种微妙佛法，断除一切相续习气，以大悲所摄、无畏才辩所观察，一切世间诸有含识都不能映夺，一刹那心中常具足相应而无差异。为什么？因为如来无业、无烦恼，没有忘失、威仪的种种习气。舍利子！譬如清净的虚空不与一切烟尘云雾共同住止，如来的流尽智力也是这样，不与一切烦恼习气共同住止。

“舍利子！诸佛如来住于这样的流尽之智后，又能为那些有流有取的一切众生宣说流尽之法，以及宣说永断一切取之法。一切众生的诸流、诸取都从虚妄的遍计分别而起，如来如实观察这一点之后，想令一切不再生起，便如其所应，以种种譬喻为之说法，令他们如实了知诸流是虚妄的；由于知道这一点，便不取著诸法；由于不取著，便能毕竟入般涅槃。又，舍利子！如来如实了知一切有情诸流的起与灭、诸流的趣向之行，这样了知之后，为诸有情如应说法。这样，舍利子！如来流尽作证智力，不可思议，无有边际，与虚空相等，若有人想求如来流尽智力的边际，无异于有人求虚空的边际。舍利子！诸菩萨摩诃萨听闻如来流尽作证智力不可思议、如同虚空之后，信受谛奉，心虑清净，无惑无疑，倍加踊跃，深生欢喜，生起希奇之想。”

【按】本经“漏尽”多作“流尽”，“诸流”即诸漏。“如是知已”之“是”，明本作“实”。

那时世尊想重宣此义，而说颂道：

```
导师流尽智无垢，
无量广大净无障，
由成如是第十力，
故说寂静妙菩提。
诸声闻乘流尽智，
有量习气随系缚，
人中最胜大导师，
无量结习同灰烬。
有证缘觉菩提者，
远离大悲才与辩，
唯薄伽梵诸流尽，
大悲才辩无有量。
诸佛安住流尽智，
了知众生流取相，
皆从虚妄诸法生，
彼未解斯真理趣。
```
（大意：导师的流尽之智无有垢染，无量广大，清净无障，由于成就这样的第十种力，所以宣说寂静美妙的菩提。诸声闻乘的流尽之智，仍有有限的习气随之系缚；人中最胜的大导师，无量的结使习气都同于灰烬。有证得缘觉菩提的，却远离大悲、才能与辩说；唯有薄伽梵诸流已尽，大悲与才辩无有限量。诸佛安住于流尽之智，了知众生流与取之相，都从虚妄的诸法而生，他们不理解这真实的理趣。）

【按】“流取相”之“取”，宋、元、明本作“尽”。“皆从虚妄”之“妄”，宋、元、明、宫本作“空”。

```
如来起悲为敷演，
无常不净无我法，
彼观诸法空无性，
当证如来寂静地。
无我无寿无数取，
无人摩纳作受者，
虚妄遍入诸法中，
起大悲心说令脱。
善逝慈悲无厌倦，
真智常流无忘失，
由是最胜恒方便，
为利众生开妙法。
能伏他论第十力，
无有边际等虚空，
世尊常住十力故，
无等法轮恒转世。
```
（大意：如来生起悲心为他们敷演无常、不净、无我之法，他们观察诸法空无自性，将证得如来寂静之地。无我、无寿、无数取，无人、摩纳、作者、受者，虚妄遍入于诸法之中，生起大悲心宣说令其解脱。善逝的慈悲无有厌倦，真实之智常流而无忘失，由此最胜者恒以方便，为利益众生开示妙法。能伏他论的第十种力，无有边际，等同虚空，世尊常住于十力，所以无等的法轮恒转于世间。）

【按】“无有边际”之“无”，明本作“为”。

“舍利子！这名为如来第十流尽智力。由于成就此力，如来、应、正等觉自称我处于大仙尊位，在大众中作正狮子吼，转大梵轮，一切世间沙门、婆罗门、诸天、魔、梵，都不能如法而转。这样，舍利子！诸菩萨摩诃萨由于听闻如来功德不可思议，对于如来十力信受谛奉，心虑清净，无惑无疑，倍加踊跃，深生欢喜，生起希奇之想。”
