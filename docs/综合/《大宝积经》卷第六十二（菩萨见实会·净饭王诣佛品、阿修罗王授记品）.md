### 净饭王诣佛品第二

#### 四天王与诸天来集

那时世尊吃完饭，洗手洗钵之后，现出瑞相。随即毘沙门天王被无量那由他百千亿夜叉众围绕，譬如壮士屈伸手臂的工夫，在一念之间从天宫隐没，出现在佛前，头面礼足，站立在北方，在虚空中，夜叉大众前后围绕，合掌恭敬佛及众僧。提头赖吒天王被无量百千那由他乾闼婆众前后围绕，也如壮士屈伸手臂的工夫，从天宫隐没，在如来面前头面礼足，住在东方，在虚空中恭敬世尊以及比丘众。那时毘楼勒叉天王被无量百千那由他鸠槃荼众所围绕，也如壮士屈伸手臂的工夫，从天宫隐没，在佛前头面礼足，住在南方，在虚空中合掌恭敬如来以及比丘众。那时西方毘楼博叉天王被无量百千那由他诸龙前后围绕，也如壮士屈伸手臂的工夫，从天宫隐没，在如来面前头面礼足，住在西方，在虚空中合掌恭敬如来以及比丘众。释提桓因天王也是这样，被无量那由他百千天众围绕，从三十三天隐没，住在佛前，头面礼足，在虚空中恭敬如来以及比丘众。夜摩天王、兜率陀天王、化乐天王、他化自在天王、娑婆世界主大梵天王、光音天王、遍净天王、广果天王、净居天王，各被无量百千那由他天众所围绕，从那天上隐没，住在佛前，头面礼足，在虚空中恭敬如来以及比丘众，也是这样。那时毘摩质多阿修罗王与六十那由他眷属前后围绕，犹如壮士屈伸手臂的工夫，从自己的宫中隐没，住在佛前，头面礼足，现出恭敬之相，退住一旁。金翅鸟王也与八万六千迦楼罗众眷属围绕，从自己的宫中隐没，住在佛前，头面礼足。以及诸外道有八亿人，从各方而来，说偈道：

【按】“毘楼勒叉”之“叉”，圣、圣乙本无（下同）。“鸠槃茶”之“茶”，宫本作“荼”。

```
于净虚空中，十五夜满月，
超过诸星众，光明独显耀。
佛如净月轮，灭暗除三垢，
能超诸外道，犹如空中月。
秋日千光明，能除诸暗冥，
超出明月光，开布莲花池。
佛光过于日，普照大千界，
如来能开现，声闻莲花林。
天主憍尸迦，住在善法堂，
出过诸大众，金刚杵光耀。
十力功德山，两足尊胜王，
超过诸外道，犹如释天王。
```
（大意：在清净的虚空中，十五日夜里的满月，超过诸星众，光明独自显耀。佛如清净的月轮，灭除黑暗，除去三垢，能超过诸外道，犹如空中之月。秋日放出千道光明，能除去种种黑暗，超出明月之光，开敷莲花之池。佛光超过太阳，普照大千世界，如来能开显声闻的莲花之林。天主憍尸迦住在善法堂中，超出诸大众，金刚杵光明照耀。十力的功德之山、两足尊的殊胜之王，超过诸外道，犹如帝释天王。）

【按】“显耀”之“耀”，圣、圣乙本作“曜”。“出过诸大众”之“大”，明本作“天”。

```
须夜摩天王，天众所供养，
住在天众中，光赫坐宝座。
十力无边威，超过恶道趣，
无畏光明德，显说八正道。
如兜率天王，在宫众围遶，
超过诸天众，宿善而光耀。
调御天人师，八部所供养，
超过诸世间，无畏显说法。
如化乐天王，在于天宫中，
超过诸天众，功德独光显。
佛超诸世间，离浊出三界，
能调未调王，具十力光照。
```
（大意：须夜摩天王为天众所供养，住在天众之中，光明赫然，坐于宝座。十力无边的威德，超过恶道诸趣，以无畏光明之德，显说八正道。如兜率天王在宫中被大众围绕，超过诸天众，由于宿世善业而光明照耀。调御天人之师，为八部所供养，超过诸世间，无畏地显说正法。如化乐天王在天宫之中，超过诸天众，功德独自光显。佛超越诸世间，远离浊垢，出离三界，能调伏未调伏之王，具足十力的光明照耀。）

【按】“而光耀”之“光”，元、明本作“晃”。“天人师”，宋、元、明、宫、圣、圣乙本作“人天师”。“功德独光显”之“独”，宫本作“福”。

```
如自在天王，住居天宫中，
超过诸天众，宿善而晃耀。
如是佛光明，具足十力行，
超过天人众，本善功德故。
如大梵天王，超过诸梵众，
光耀说甜美，显于八正路。
如来胜梵天，沙门众中王，
光明照三界，转于四谛法。
知见众集已，天人龙听法，
人中最胜王，吐宣八正语。
虚空可度量，海可瓶量尽，
须弥山可称，佛德难可知。
```
（大意：如自在天王住在天宫之中，超过诸天众，由于宿世善业而晃耀。这样的佛之光明，具足十力之行，超过天人众，由于本来的善业功德。如大梵天王超过诸梵众，光明照耀，说话甜美，显示八正之路。如来胜过梵天，是沙门众中之王，光明照耀三界，转四谛之法。知道大众已经集会，天、人、龙都来听法，人中最殊胜的王，吐出宣说八正之语。虚空可以度量，大海可以用瓶量尽，须弥山可以称重，佛的功德却难以知晓。）

#### 净饭王出城诣佛

那时净饭王对释种们说：“诸位仁者！如太阳将要出来，先现瑞相，就是明星出来的时候，应当知道太阳不久就会出来。迦卢陀夷也是这样，对佛如来的一切种智先现瑞相；比丘所说的如来功德，便是一切智之相。诸位仁者！赶快备好车乘，我当前往如来之所。”那时释种大臣说：“善哉大王！现在正是时候，所需之具，现在都已备办。”那时大王敕令诸臣说：“从迦毘罗城乃至尼俱陀林，在这期间精心修治道路，用好的软沙遍布地面，散种种花，悬挂种种缯彩，奏起伎乐，作种种歌舞。”

【按】“诸人者”之“人”，宋、元、明、宫本作“仁”，今从之。“先现瑞相”之“现”，宋、元、明、宫、圣本作“见”。“唱伎”，宋本作“倡伎”，元、明本作“倡妓”。

那时大王乘好的车乘出迦毘罗城，前往尼俱园。在那车乘之后，有八万头白象，以种种宝间错庄严，在那象上各立有七宝殿堂，甚为奇特微妙。在那象之后，各有八万匹装饰好的宝马，那马上各有金幢，那马与幢各以七宝庄严，微妙第一。那时城中有无量的人装饰车乘，所有的服饰：青马、青车、青盖装饰，手持青刀，衣服都是青色，鞍鞯鞦辔也都是青色，各持青幢，每一辆车后有百位穿青衣的人围绕。又有释种等各自装饰种种好车，以青、黄、白、赤杂色庄严，杂色的车马，杂色的装饰，每一辆车马都有百人以杂色庄严，也是这样。

【按】“𩋋”字（革旁戋）先前电子文本未能显示，今据《大正藏》补出，即“鞯”；圣、圣乙本作“韀”。

那时世尊远远看见国王来了，告诉诸比丘：“你们若想见三十三天游戏之众，应当观看释种出迦毘罗城。为什么？释种游行与天人无异。”那时世尊说偈道：

```
其迦毘罗妙城中，
净饭大王及眷属，
最胜人王今方至，
谛听谛听我当说。
象马车乘过百千，
种种庄严甚殊妙，
从迦毘罗而引出，
人王宝藏及诸乘。
青马青车青庄严，
将从衣服悉青色，
靴帽刀拂咸亦青，
青鞭青辔青铃网，
青衣人持青幢盖，
人马皆青甚殊妙。
黄马黄车黄庄饰，
将从衣服悉黄色，
靴帽刀拂皆亦黄，
黄鞭黄辔黄铃网，
黄衣人持黄幢盖，
人马皆黄甚殊妙。
```
（大意：在那迦毘罗美妙的城中，净饭大王以及眷属，最殊胜的人中之王现在正要到来，谛听谛听，我当宣说。象、马、车乘超过百千，种种庄严甚为殊妙，从迦毘罗城引出，是人王的宝藏以及种种车乘。青马、青车、青色庄严，随从的衣服都是青色，靴帽刀拂也都是青色，青鞭、青辔、青色铃网，穿青衣的人持着青色幢盖，人马都是青色，甚为殊妙。黄马、黄车、黄色装饰，随从的衣服都是黄色，靴帽刀拂也都是黄色，黄鞭、黄辔、黄色铃网，穿黄衣的人持着黄色幢盖，人马都是黄色，甚为殊妙。）

【按】“青庄严”之“严”，圣、圣乙本作“饰”。“靴”，圣、圣乙本作“鞾”。

```
赤马赤车赤庄饰，
将从衣服悉赤色，
靴帽刀拂皆亦赤，
赤鞭赤辔赤铃网，
赤衣人持赤幢盖，
人马皆赤甚殊妙。
白马白车白庄严，
将从衣服悉白色，
靴帽刀拂皆亦白，
白鞭白辔白铃网，
白衣人持白幢盖，
人马皆白甚微妙。
杂色车马杂庄严，
将从衣服悉杂色，
靴帽刀拂皆亦杂，
杂色鞭辔杂铃网，
杂色衣人持幢盖，
人马皆杂甚微妙。
```
（大意：赤马、赤车、赤色装饰，随从的衣服都是赤色，靴帽刀拂也都是赤色，赤鞭、赤辔、赤色铃网，穿赤衣的人持着赤色幢盖，人马都是赤色，甚为殊妙。白马、白车、白色庄严，随从的衣服都是白色，靴帽刀拂也都是白色，白鞭、白辔、白色铃网，穿白衣的人持着白色幢盖，人马都是白色，甚为微妙。杂色的车马、杂色的庄严，随从的衣服都是杂色，靴帽刀拂也都是杂色，杂色的鞭辔、杂色的铃网，穿杂色衣的人持着幢盖，人马都是杂色，甚为微妙。）

【按】“赤庄饰”之“饰”，明本作“严”。“白马白车”，圣、圣乙本作“白车白马”。“杂庄严”之“严”，宋、元、宫本作“饰”。

```
彼诸车后庄严象，
其数足满八十千，
金鞍金𩋋金庄饰，
象背皆有七宝殿。
种种庄饰妙龙马，
其数亦满八十千，
七宝庄严甚奇丽，
众妙服饰从车后。
以诸妙花散御路，
用五种香熏其地，
悬诸瓶香并缯彩，
壮士戏人歌舞辈，
种种庄严遍其路，
作诸音乐从王后。
```
（大意：那些车后的庄严之象，其数满足八万，金鞍、金鞯、金色装饰，象背上都有七宝殿堂。种种装饰的美妙龙马，其数也满八万，以七宝庄严，甚为奇丽，众多美妙的服饰跟随在车后。以种种妙花散在御路上，用五种香熏其地面，悬挂种种香瓶以及缯彩，壮士、戏人、歌舞之辈，种种庄严遍满道路，奏起种种音乐，跟随在国王之后。）

#### 世尊空中游行与净饭王三礼

那时净饭王以及诸侍从到了尼俱树园，下车而入，步行的大众引导随从，前后围绕。那时世尊知道父王心中深生怨恨，为了度化国王，超过人的高度，在虚空中自在游行。如来行走时，娑婆世界主大梵天王在如来的右边，释提桓因在如来的左边，须夜摩天王、兜率陀天王、化乐天王、他化自在天王各自执持种种天盖供养如来。那时毘沙门王、提头赖吒天王在佛的东面，偏袒右肩，右膝着地，合掌向佛，现出恭敬之相；毘楼勒叉王、毘楼博叉王在佛的西面，也偏袒右肩，右膝着地，合掌向佛，现出恭敬之相。那时四天王天、三十三天、夜摩天、兜率陀天、化乐天、他化自在天诸天子等，在虚空中降下天优钵罗花、栴檀末香、曼陀罗花，奏天伎乐以及歌舞；又在虚空中降下种种香水，以及自古以来未曾见闻的优钵罗花、旃檀香末，供养如来。那时世尊示现神通，以神通之力，令人看见天人的差别之相。那时净饭王看见诸天子供养如来，生起稀有之心；又看见装饰的七宝重阁充满虚空，见了之后这样说：“如来往昔作童子时，对四天下转轮圣王之位不生顾恋。为什么？如今在三千大千世界中作大法王，统领天人，富贵自在。现在这位世尊是正法之王；我现在在这里被人围绕，世尊却有天人侍卫。”

【按】“提头赖吒天王”之“天”，圣乙本无。“毘楼”之“楼”，圣本作“娄”。“示现神通”之“示”，宋、元、明、宫本作“亦”。“乃有天人”之“乃”，圣、圣乙本作“及”；“侍卫”之“侍”，明本作“待”。

那时净饭王偏袒右肩，右膝着地，头面礼足，合掌向佛这样说：“世尊初生之时，无人扶持而行走七步，观察十方，这样说：‘我在世间最尊最胜，当得度脱老病死的边际。’我在那时头面礼拜世尊之足。又在后来到了田村，在阎浮树下坐于清凉之处，太阳虽然西移，树影却始终不动，又有六位天童子在如来面前合掌作礼，我在那时头面礼拜大牟尼之足。我现在是第三次又头面礼拜世尊之足。”那时净饭王说偈道：

【按】“扶持”之“持”，圣、圣乙本作“侍”（下偈中宋、圣、圣乙本亦作“侍”）。

```
两足世尊初生时，
无人扶持行七步，
自说我于世最胜，
尔时我礼明智者。
牟尼逾城至田村，
阎浮树影荫不移，
六天童子修供养，
我时复礼世应供。
今是第三稽首礼，
恭敬怜愍世间尊，
堪受人天微妙供，
世无如佛何有胜。
世尊本号悉达多，
字为父母所喜乐，
始知如来名称实，
得愿满足获甘露。
```
（大意：两足世尊初生之时，无人扶持而行走七步，自己说我在世间最殊胜，那时我礼拜这位明智者。牟尼越城来到田村，阎浮树的影子荫蔽而不移，六位天童子修习供养，我那时又礼拜这位世间应供。现在是第三次稽首礼拜，恭敬怜愍世间的尊者，堪受人天微妙的供养，世间没有如佛者，哪有超胜的？世尊本来名号为悉达多，此字为父母所喜乐，如今才知如来的名称真实，所愿满足，获得甘露。）

#### 世尊为父王说海龟井鳖喻

那时欲界诸天为世尊敷设师子座，以天妙衣铺在座上以及尼俱园中，又以天劫波树衣遍覆虚空。那时世尊从空中下来，在师子座上跏趺而坐。那时净饭王以及诸眷属头面礼足，退坐一旁；欲界、色界二界诸天子等也头面礼足，在虚空中退坐一旁。那时世尊说偈道：

【按】“加趺”之“加”，宋、明、宫、圣、圣乙本作“跏”。

```
净饭大王及眷属，
来诣世尊设供养，
从迦毘罗妙城出，
趣尼俱陀可乐园。
佛与无量众围遶，
阿修罗王及龙王，
鸠槃荼王金翅王，
乾闼婆王并眷属，
夜叉大王鬼神众，
紧那罗王悉皆集，
欲界天王并天子，
一切皆生欣喜心。
六欲诸天既如是，
梵辅梵身梵天众，
遍净诸天并眷属，
乃至广果净居天，
沙门大众婆罗门，
僧佉卫世尼乾子，
及余一切诸外道，
修行种种异术士，
斯等诸方皆来集。
如来示现自神力，
令净饭王及释种，
```

#### 世尊微笑与马胜请问

那时毘摩质多阿修罗王等六十那由他阿修罗设供养之后，都各自合掌作礼而住，欣欣踊跃，情意充满，喜乐称心，菩提之心流注不绝。那时世尊知道那些阿修罗以信心供养之后，如诸佛之法，示现微笑之相，从其面门放出无量颜色的光——青、黄、赤、白、红、紫、颇梨色，也如金、银以及杂色——从口中放出之后，绕佛三匝，又从顶上而入。那时慧命马胜比丘从座而起，偏袒右肩，右膝着地，合掌向佛，为佛作礼，以偈问道：

```
雄猛牟尼现瑞相，
愍世间者非无因，
人中最胜愿为说，
大仙所现之因缘。
怜愍世间现瑞应，
见诸修罗胜供养，
欲授修罗决定记，
令我等辈得欣欣。
朝有胜心无有疑，
此众中有发心者，
世尊知其信根已，
人中师子现此瑞。
```
（大意：雄猛的牟尼现出瑞相，怜愍世间者并非没有原因，人中最胜者愿为宣说大仙所现瑞相的因缘。怜愍世间而现出瑞应，见到诸阿修罗殊胜的供养，想为阿修罗授决定之记，令我们这些人得以欣喜。今朝有殊胜之心，没有怀疑，这大众中有发心的人，世尊知道他们的信根之后，人中师子现出这瑞相。）

【按】“之因缘”之“因”，圣乙本作“由”。

```
朝日谁发清净心？
谁于人中生胜信？
世尊知其信根已，
现此最妙之瑞相。
今此大众皆有疑，
皆见如来现微笑，
谁复朝日降魔怨？
现此瑞相为此人。
善哉降怨大仙尊，
愿断大众心犹豫，
愿尊速说勿踟蹰，
断此大众之疑网。
```
（大意：今朝谁发起清净之心？谁在人中生起殊胜的信心？世尊知道他们的信根之后，现出这最妙的瑞相。现在这大众都有疑惑，都见到如来现出微笑，今朝谁又降伏了魔怨？现这瑞相是为了这样的人。善哉降伏怨敌的大仙尊，愿断除大众心中的犹豫，愿尊者迅速宣说，不要踟蹰，断除这大众的疑网。）

【按】“犹豫”之“豫”，圣、圣乙本作“预”。

#### 世尊为诸阿修罗授记

那时世尊以偈回答马胜比丘说：

```
善哉比丘所问义，
我所现瑞利世间，
我说果报无有余，
汝今一心善谛听。
诸阿修罗供养佛，
为求无上胜菩提，
修罗心意无所依，
如手在空不障碍。
此等供养世尊已，
阿修罗众心清净，
大智皆舍修罗道，
于人天中久受乐。
此等于其未来世，
值遇恒沙人师子，
于善名劫得成佛，
如来皆号为善名。
数满六十那由他，
名振十方照世间，
演说无依无著法，
广能度胜天人众。
彼诸佛土甚严净，
佛知世间离五浊，
净佛国土三千界，
满足六十那由他。
```
（大意：善哉比丘所问之义，我所现的瑞相利益世间，我宣说果报，毫无遗余，你现在一心善加谛听。诸阿修罗供养佛，为求无上殊胜的菩提，阿修罗的心意无所依，如手在虚空中没有障碍。这些人供养世尊之后，阿修罗众心意清净，以大智慧都舍弃阿修罗道，在人天中长久受乐。这些人在未来世值遇恒河沙数的人中师子，在善名劫中得以成佛，如来都号为善名。数满六十那由他，名声振动十方，照耀世间，演说无依无著之法，能广为度化殊胜的天人大众。那些佛土甚为庄严清净，佛使世间远离五浊，清净的佛国土是三千大千世界，满足六十那由他。）

【按】“度胜”之“胜”，宋、元、明、宫本作“脱”。

```
彼国无诸三恶趣，
以欣喜心土田净，
彼佛雄猛除诸难，
演说无上大乘法。
彼等诸佛得寿命，
住世六十那由劫，
演说无所依止法，
一一导师皆亦然。
彼诸如来灭度后，
世间智者尽皆灭，
满足六十那由劫，
彼佛正法住在世。
是诸如来各各度，
如恒河沙众生聚，
彼诸如来等无量，
土寿法住亦如是。
彼诸善逝能成熟，
六十那由众生数，
皆令安住大乘中，
各各绍继三宝种。
今此授记为修罗，
利世间者大仙说。
天人闻斯授记已，
身心踊跃得净信。
```
（大意：那些国土没有三恶趣，以欣喜之心令国土清净，那些佛雄猛，除去种种难处，演说无上的大乘之法。那些佛所得的寿命，住世六十那由他劫，演说无所依止之法，每一位导师都是这样。那些如来灭度之后，世间的智者都全部灭度，满足六十那由他劫，那些佛的正法住在世间。这些如来各自度化如恒河沙数的众生之聚，那些如来同等无量，国土、寿命、正法住世也是这样。那些善逝能成熟六十那由他数的众生，都令其安住于大乘之中，各自绍继三宝之种。现在这授记是为阿修罗而授，是利益世间的大仙所说。天人听闻这授记之后，身心踊跃，得到清净信心。）

【按】“天人闻斯授记已，身心踊跃得净信”二句，CBETA标点置于引号之外，今依句式并入偈中。
