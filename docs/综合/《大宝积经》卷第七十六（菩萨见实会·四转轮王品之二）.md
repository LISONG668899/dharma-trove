# 《大宝积经》卷第七十六（菩萨见实会·四转轮王品之二）

北齐·三藏那连提耶舍 译

## 菩萨见实会第十六之十六

### 四转轮王品第二十六之二

#### 地天王得金轮宝

“大王！过去有一位王，名为地天，如法为王，名为法王。七宝具足，就是轮宝、象宝、马宝、明珠宝、玉女宝、长者宝、主兵宝，这名为七宝。大王！那地天王的父亲名为地生。那地生王临命终时，地天是最年长的儿子。地生命终之后，辅相大臣为地天灌顶，立为大王，便是刹利灌顶大王。

“那时地天王成为刹利灌顶王之后，在十五日月亮圆满、受斋之日，沐浴洗头，剪除须发以及指甲之后，穿上新净之衣，以种种花鬘、种种璎珞、天冠、臂印、环钏、耳璩庄严其身，在高楼上，婇女围绕。便在东方出现金轮宝，千辐不缺，毂辋具足，光明照耀，纵广七肘，纯是真金。

【按】“璎珞”之“璎”，圣本作“缨”。“耳𤦲”之“耳”，圣本作“铒”。“𤦲”字先前电子文本未能显示，今据《大正藏》补出，即“璩”，耳饰。“婇女”之“婇”，圣本作“采”。“照耀”之“耀”，宋、元、明、宫本作“曜”。

“大王！那时地天王见到这事之后，便这样想：‘我往昔曾听先前的老人说，若刹利灌顶王在十五日月圆满、受斋之日，沐浴洗头，剪除须发以及指甲，穿上不染污之衣，以种种花鬘、种种璎珞、天冠、臂印、环钏、耳璩庄严其身，在高楼上，婇女围绕。若在东方有金轮宝，毂辋具足，千辐不缺，前来应现，当知此王必定得作转轮圣王。’又这样想：‘我现在难道可以作轮王吗？我现在应当试一试。’

【按】“不污衣”之“污”，《大正藏》作“汅”，宋、元、明、宫、圣本作“打”，今依CBETA作“污”。“铒𤦲”之“铒”，宋、元、明、宫本作“金”。

“大王！那时地天王便从座而起，偏袒右肩，整理衣服，右膝著地，对着轮宝合掌，向那天轮这样说：‘宝轮可以下来，在地上停住。’说了这话之后，那天宝轮从空中降下到地上，停在王前。那时地天王便用妙香涂手，用殊胜的好衣擦拭轮宝，用右手接取轮宝，放在左手中。又用右手摩拭那轮，这样说：‘你现在应当降伏东方。’说了这话之后，那时金轮宝飞升虚空，左右旋转，便前往东方，到往昔转轮王所行之道。那道路平正，散布诸花，甚可爱乐。轮宝所经过之处都平正，没有高低。由于王的福力，河、池、井、泉枯竭之处，八功德水都充满。一切所有树林花果枯萎的，都开放繁荣；已开放繁荣的，更加茂盛。

【按】“摩拭”之“拭”，元、明、宫、圣本作“𢪛”。“所经”之“经”，圣本作“逕”。

#### 地天王以十善降伏四天下

“大王！那时地天转轮圣王便与四兵随轮而去。轮宝若停住，王也随着停住。王所到之处所有国土，大小诸王与其臣民，各以金盘盛满银粟，或以银盘盛满金粟，奉迎大王，各自这样说：‘善哉大王！善来大王！这些国土安隐丰乐，人民炽盛。唯愿大王接受这些国土，摄化人民，我们都将奉侍左右，唯愿留住。’

【按】“金盘”之“盘”，宋、元、明、宫、圣本作“槃”。

“那时地天转轮圣王告诉那些国王以及臣民等，这样说：‘我现在不需要国土宝物，你们自己受用。你们现在若想随顺我，应当远离杀生，也不要偷盗，也不要邪淫，也不要妄语，也不要两舌，也不要恶口，也不要绮语，也不要贪欲，也不要瞋恚，也不要邪见。你们应当自己安住十善，也教他人令住十善，我便知道你们归从于我，接受我的教敕，我看你们就如我的儿子。你们常应供养父母、师长以及诸沙门、婆罗门等，不要作非法不善的恶行，也劝他人令行善法。若能这样，我便知道你们一切国土所有人民都归从、降伏于我。’又告诉他们说：‘你们常应孝养父母，恭敬师长以及诸沙门、诸婆罗门，不要作非法不善的恶行，也劝他人令行善法。若能这样，我便知道你们一切国土所有人民都归从、降属于我。’

“那时圣王以及四兵，这样渐渐渡过大海，降伏弗婆提，直到人境的尽头，轮宝才停住。这样乃至南方、西方、北方以及郁单越，都降伏之后，渡过那北海，到人境尽头之后，王与轮宝回到阎浮提本宫门上，在虚空中停住不动。那时地天转轮圣王这样降伏四天下之后，回到阎浮提便即安住。地天大王与轮宝回到这阎浮提时，那四天下变成七宝，端严殊特。什么是七宝？就是金、银、琉璃、颇梨、砗磲、赤珠、玛瑙。

【按】“姝特”之“姝”，宋、元、明、宫本作“殊”。“车𤦲”即“砗磲”。“赤珠”之“赤”，《大正藏》作“亦”，今依CBETA（所录高丽藏）作“赤”。“马瑙”，宋、元、明、宫本作“码碯”。

“那时轮宝在四天下周回旋转之后，一切地狱、畜生、饿鬼等八难都消灭，在四天下所有一切不善的恶声都除灭，何况有造作恶业的人。为什么呢？这都是地天圣王本愿之力。又轮宝周回旋转时，四天下中不须种植，处处都生出自然的秔米，干净而没有糠秕。又轮宝周回旋转时，四天下中自然生出天树宝衣。又轮宝周回旋转时，四天下中一切病患都除愈，唯除三种病患。哪三种？一是求欲，二是段食，三是衰老。又轮宝旋转时，四天下中所有人民寿命千万岁。又轮宝周回旋转时，四天下中一切人民所有苦恼自然消灭。像这样等无量无边希有不可思议之事出现于世。

【按】“又复轮宝周旋转时，四天下中自然而生天树宝衣”句首“周旋转时，四”，《大正藏》无，今依CBETA（所录高丽藏）补；同句“周旋”之“旋”，《大正藏》作“施”，今依CBETA作“旋”。

#### 地天王升天退堕而说偈

“那时地天大王又过了很久，作这样的念头：‘我现在在这里受种种快乐，五欲众具，可还有比这更胜的地方吗？’又自己思念：‘我往昔曾听说须弥山顶上有三十三天，那里的五欲资具是怎样的？’那时地天大王未除爱欲，厌恶人间所有的五欲资财之具，欣羡那天上上妙之乐。‘我现在宁可前往那天上。’那时地天大王作此念后，王以及四兵忽然之间到了忉利天。那时帝释远远望见地天大王，这样说：‘善来大王！善哉大王！’便分出半座，请王坐下。王便就座。那时地天在那天上经过无量百千岁，分位而治。

“那时地天大王又过了很久，生起大贪心，作这样的念头：‘我现在应当让那天主退位，独自作天王。’作此念后，便从帝释的半座堕下，以及四兵，到了阎浮提的安隐城中。那时地天大王长久在天上享受殊胜美妙之乐，心生耽著，忽然到了人间，不能堪受人间的资具，身心沉没，犹如醍醐放在热沙之中，随即消融，不知所在。地天大王身心沉没，不能堪忍人间所有饮食的精气，也是这样。那时地天大王身心疲顿，说偈道：

【按】“生大贪心”之“生”，《大正藏》作“至”，今依CBETA（所录高丽藏）作“生”。

```
诸王大自在，不能除渴爱，
如干草遇火，是故应舍欲。
常行于婬欲，未曾满足时，
如渴饮咸水，终不能除渴。
如众流归海，终无有满足，
爱欲亦如是，曾无满足时。
如火焚草木，无有厌足时，
爱欲亦如是，终无有满足。
犹如深谷响，随声无休息，
闻声亦如是，亦无休息时。
亦如盛香箧，受香无简择，
嗅香亦如是，亦无有厌足。
```
（大意：诸王虽有大自在，却不能除去渴爱，如干草遇到火，所以应当舍弃欲望。常行淫欲，未曾有满足之时，如口渴而饮咸水，终究不能解渴。如众流归入大海，终究没有满足，爱欲也是这样，从来没有满足之时。如火焚烧草木，没有厌足之时，爱欲也是这样，终究没有满足。犹如深谷的回响，随声而没有休止，耳听声音也是这样，也没有休止之时。也如盛香的箱子，受香而不加简择，鼻嗅香气也是这样，也没有厌足。）

```
如杓挠美食，终无知止足，
舌贪嗜美味，亦无于止足。
如镜现面像，亦无有厌足，
如是行欲人，于欲无厌足。
如虚空受风，未曾有厌足，
身常受诸触，终无厌足时。
如梦中饮水，终不能除渴，
意所受诸法，亦无有厌足。
贪求爱欲人，复增长爱欲，
观于诸境界，爱无厌足时。
见欲增苦恼，犹如火焚薪，
灭除诸爱欲，亦如水灭火。
```
（大意：如用杓搅拌美食，终究不知止足，舌贪嗜美味，也没有止足。如镜中显现面像，也没有厌足，像这样行欲的人，对欲没有厌足。如虚空容受风，从来没有厌足，身体常受诸触，终究没有厌足之时。如梦中饮水，终究不能解渴，意所领受的诸法，也没有厌足。贪求爱欲的人，又增长爱欲，观察种种境界，爱没有厌足之时。见到欲望增长苦恼，犹如火焚烧柴薪，灭除种种爱欲，也如以水灭火。）

【按】“杓挠”之“挠”，元、明本作“搅”。

#### 佛示地天王本生

佛说：“大王！你知道那时的地天大王是别人吗？大王应当知道，不要作别的看法，地天王就是我自身。大王应当知道，那地天大王往昔之时豪富自在，贪求无厌，于是命终。为什么呢？诸根无厌，境界不能令其满足；诸根如镜，境界如光影；诸根如幻，境界如梦。大王！应当安心于此法，深自观察，不要随顺他人之教。大王！此法是过去、未来、现在诸佛世尊的无上菩提。

“大王！应当远离一切豪贵，应当竭尽一切渴爱之海，推倒憍慢之山，远离一切衰祸。于一切法平等，不是一切凡夫之地，也不是声闻所能行，又不是一切缘觉的境界，而是一切菩萨所行，一切诸佛正觉所证。大王应当安心，不令散乱，应当这样想：‘我应当怎样在未来世，在一切世间天人之中，得以成为灯明、成为火炬、成为光、成为船、成为导者、成为老师，得以成为商主、成为首领、成为无上者，自度又度他，自己解脱又令他解脱，自己安隐又令他安隐，自得涅槃又令他得涅槃。’大王！不要观望先前所经历的豪富自在，大王应当知道，诸根如幻，没有厌足，没有能令其满足的；境界如梦，不能令其满足。”

【按】“消竭”之“竭”，圣本作“端”。“商主”之“商”，宋、元本作“啇”。

#### 顶生王七宝具足

佛说：“大王！过去有一位王，名为顶生，有大威德，有大神足，有大威势，从父亲乌哺沙王的头顶上出生。他久积善根，曾见无量无数诸佛，修种种善根。在诸世尊所恭敬供养，积集善本，在四天下豪贵自在。大王！那时顶生王灌顶受位七日之后，得到七宝具足，成为转轮王。哪七种？

“一是金轮宝，千辐不缺，毂辋具足，自然而有，纵广七肘，前来应现。二是白象宝，六牙具足，七支拄地，白如雪山，自然而来。三是马宝，其色绀青艳丽，前来应现。上述象与马，从清晨到用餐之时，在四天下周遍八方，直到大海边际，又回到本处。四是珠宝，大如人的大腿，纯是青琉璃，其光照耀，周围八方各一由旬。五是长者宝，财宝丰饶，巨富无量，随王所念都能办到，自然应现。六是玉女宝，形容端正，微妙第一，不高不矮，不白不黑，身上诸毛孔散发栴檀香，口气洁净如青莲花，舌头广大，伸出能覆盖面部，形色细薄如赤铜叶，身体柔软犹如无骨，冬温夏凉，其心慈悲，常出柔软之语，用手触王，便知王心所念之处。七是主兵宝，自然出现，勇猛而有策谋，武略第一，预知王心七日所念，善知四兵战斗之法，未集合的令其集合，已集合的令其解散。又有千子具足，勇健端正，能降伏怨敌。

【按】“七肢拄地”之“肢拄”，宋、宫本作“枝拄”，元、明本作“支拄”，圣本作“枝柱”。“从旦至食”之“旦”，《大正藏》作“且”，宫本作“旦”，今依CBETA（所录高丽藏）作“旦”。“人髀”之“髀”，圣本作“体”。

#### 阿逾阇城与三种殿

“大王！那时顶生转轮圣王七宝具足，统领四天下，如法教化世间，令四天下丰乐安隐，人民炽盛，城邑聚落一个挨一个，近到鸡能飞过去。那时大地全无沙砾荆棘，多有众宝，具足无量园林泉池，端严殊妙，甚可爱乐。为什么呢？这都是顶生圣王安住于法的力量。在那时，无论天或人，所受的欲乐中，他最为第一。

【按】“姝妙”之“姝”，宋、元、明、宫本作“殊”。“受欲乐”之“受”，圣本作“爱”。

“大王！那时顶生大王所住之城，名为阿逾阇，那城东西十二由旬，南北长七由旬。那城由七宝所成，众宝罗网覆盖其上，悬挂众宝铃。那城内外种种庄严，都如上述无量称王的宝庄严城等，没有差异，也如忉利天的得胜之堂。

【按】“悬”，圣本作“县”。

“大王！顶生大王建造三种宫殿：第一名为月出殿，在盛夏炎热时王住在其中；第二殿名为毗琉璃藏，在春季时王住在其中；第三殿名为日威德起，在冬季寒冷时王住在其中。那时顶生与玉女宝以及众婇女前后围绕，进入月出殿。这时身体清凉，犹如以牛头栴檀涂抹其身。王与眷属前后围绕，若进入那毗琉璃殿时，身心调适，犹如以多摩罗叶香涂抹其身。大王！那顶生大王又与眷属婇女围绕，进入那日威德殿时，身体和暖，犹如以沉水香涂抹其身，进入那殿时身体和暖，也是这样。大王！这顶生王随欲自在，令诸宫殿等随其时节而生乐触，随意出风，随意降雨，种种音乐随意而至，生活所需也随意出现。

【按】“和煖”之“煖”，宫、圣本作“软”。

“大王！那时顶生在其宫内，七日之中天降金银。过了七日之后，作这样的念头：‘甚为奇特希有，不可思议，这样清净之业所获的果报，随意出现，充满我意，是福德所致，毫无差违。谁见到这样的果报，还会对修福德生起知足之心？’

【按】“不可思议”之“不可”，宋、元、宫、圣本无。

#### 顶生王巡三洲

“大王！顶生圣王在阎浮提经过百千岁后，作这样的念头：‘我现在在这里，阎浮大洲安隐丰乐，人民炽盛，都已归属；在我宫内七日降宝。我现在应当前往西瞿陀尼。’作此念后，顶生大王便与四兵上升虚空，从阎浮提渐次到达那西瞿陀尼。王到那里之后，在那里统领了无量百千岁。顶生大王的依报超过人间，但还未得天报。大王！顶生圣王在瞿陀尼随意降宝，充满其宫内，与阎浮提相同，没有差异。

【按】“依报”之“依”，圣本作“衣”。

“大王！那时顶生又在后来作这样的念头：‘我统领阎浮提，丰乐安隐，人民炽盛，又在宫内随意降宝。这瞿陀尼也都安隐丰乐，人民炽盛，又在宫内随意降宝。我现在也知道东方有大洲，名为弗婆提，我现在应当前往。’作此念后，便与四兵一起升入虚空，从瞿陀尼渐次前往东弗婆提。王到那里之后，在弗婆提住下统领，无量千岁享受五欲之乐，依报超过人间，但还未得天报。大王！顶生圣王在弗婆提随意降宝，充满其宫内，与阎浮提相同，没有差异。

“大王！那时顶生又在后来作这样的念头：‘我的阎浮提丰乐安隐，人民炽盛，又在宫内随意降宝。以及瞿陀尼也都安隐丰乐，人民炽盛，也在宫内随意降宝。这弗婆提都安隐丰乐，人民炽盛，也在宫内随意降宝。我现在也知道北方有大洲，名为郁单越，其中人民没有我、我所。虽然如此，我应当前往那里，亲自试一试眷属。’顶生大王作此念后，与其四兵一起升入虚空，从弗婆提渐次前往北郁单越。王到那里之后，在郁单越无量千岁教诫眷属。

【按】“北有大洲”之“北”，圣本作“比”。“自试眷属”之“试”，宋、元、明本作“诫”。

#### 顶生王与帝释分座

“又过了很久，作这样的念头：‘我的阎浮提丰乐安隐，已降七宝，以及瞿陀尼人民炽盛，安隐降宝，东弗婆提也都这样随意降宝，这郁单越也都安隐。我曾听说有三十三天住在须弥山顶，我现在应当前往亲自观看。’那时顶生作此念后，便与四兵一起升入虚空，停在须弥山顶。在那时，释提桓因与三十三天集会在善法堂，讨论人天之事。那时帝释远远望见顶生从远处而来，便出来迎接他，这样说：‘善来大王！善来至此。’便分出半座，请王坐下。王便就座。

【按】“此郁单越”之“此”，元、明本作“北”。“四兵”之“兵”，宫、圣本作“众”。“住须弥山顶”之“住”，宋、元、明、宫本作“往”。

“那时顶生王坐在半座时，便有十种胜事映蔽诸天。哪十种？一是寿命胜过诸天，二是容色胜过诸天，三是名称胜过诸天，四是受乐胜过诸天，五是统领自在胜过诸天，六是形貌胜过诸天，七是音声胜过诸天，八是香气胜过诸天，九是食味胜过诸天，十是细触胜过诸天。大王！那时顶生与那帝释，形容相貌、行动威仪都相同，没有差别，饮食、衣服、资生之具都没有不同，唯有眨眼与否是不同之处。诸天等便由此分别识知天王与人王两者的区别。”

【按】“威仪”之“威”，圣本作“盛”。

佛说：“大王！甚为奇特希有。帝释与顶生，人与天既然有别，形容相貌却相同，没有差异。大王应当知道，福德之力就是这样。谁会对福德生起满足之心呢？大王！那时顶生在忉利天，无量千岁增上自在。

【按】“在忉利天”之“在”，宋、元、明、宫本作“于”。

#### 顶生王退堕与说偈

“大王！那时顶生在四天下豪富自在，又在忉利天上豪富自在，与帝释分治，仍不满足，又作这样的念头：‘我现在宁可独自作天主，何必要帝释？应当让他退位。’大王！那时顶生作此念后，从天上退下，回到阎浮提，在阿逾阇城的最上园中。王降下时，威光照耀，遍满阎浮提，一切方向都映蔽了日光。也如日出时月亮没有光明，日光在空中也不再有光明。王的光明映蔽也是这样。如日轮出来映蔽月轮，顶生的威光映蔽那日轮也是这样。

“大王！那时阿逾城的人出城游观，见到那顶生以及四兵从天上退落，堕在那园中。那人见后惊怪为前所未有，便进入城中，普遍告诉城中人说：‘现在有天子以及四兵从空中而下，堕在王的最上园中。’大王！那时城中的王以及臣民，备办种种歌舞伎乐、涂香、末香、宝幢幡盖、花鬘璎珞，身体衣服都清净，迅速出城前往那园中。大王，那时顶生从天上堕落时，一切大地六种震动。在那时，一切人间所有的庄严，以最殊胜的妙香涂抹其身，都来到园中顶生王之所。那时顶生耽著天上上妙的资财，不能堪忍人间资具所有的香气，昏沉倒地。犹如生酥、醍醐投入极热的沙中，不能停住，那时顶生昏沉不能支持，也是这样。

【按】“璎珞”，明本作“缨珞”，圣本作“缨络”。“速疾”之“速”，圣本作“远”。“生苏”之“苏”，明本作“酥”。

“那时城中的王以及臣民、内外人众，见到顶生王在那园中昏沉倒地，便问道：‘天人，你是谁？’那时顶生便告诉那王以及诸人民说：‘你们往昔可曾听说有顶生大王吗？’那时国王以及诸人民都回答说：‘我们往昔曾从老人那里听说，有一位大王名为顶生，不舍人身，带领诸眷属以及四兵升上天上。’那时顶生告诉众人说：‘往昔的顶生，就是我。我以及四兵从天上堕落。’那时国王以及城内外所有人众，便以偈颂问顶生道：

```

```

```
受五欲亦尔，终无有厌足。

```

#### 佛示顶生王本生

佛告诉大王：“你知道那时的顶生王是别人吗？不要作别的看法，不要生疑惑，就是我自身。我往昔作顶生王时，统领人天，豪贵自在，贪欲无厌而命终。所以大王！应当舍弃豪富、憍慢与自在，安住于不放逸。若能安住于不放逸之行，此人便能修种种善根。大王！若不放逸，又能入于法界平等。大王！若人能远离放逸，便成就利益。大王！有为界、无为界，非男非女，非过去、非未来、非现在。大王！应当于此法安住自心，不要随顺他人之教。大王！此法是过去、未来、现在诸佛世尊的无上菩提。

【按】“憍慢”之“慢”，《大正藏》作“漫”，宋、元、明、宫、圣本作“慢”，今依CBETA（所录高丽藏）作“慢”。

“大王！应当远离一切豪贵，竭尽一切渴爱之海，推倒憍慢之山，远离一切衰祸。于一切平等，不是一切凡夫之地，也不是声闻所能行，又不是一切缘觉的境界，而是一切菩萨所行，一切诸佛正觉所证。大王应当安心，不令散乱，应当这样想：‘我应当怎样在未来世，在一切世间天人之中，得以成为灯明、成为火炬、成为光、成为船、成为导者、成为老师，得以成为商主、成为首领、成为无上者，自度又度他，自己解脱又令他解脱，自己安隐又令他安隐，自得涅槃又令他得涅槃？’大王！观察先前所经历的豪富自在，大王应当知道，诸根如幻，没有厌足，没有能令其满足的；境界如梦，不能令其满足。

#### 尼弥王观三世平等

“大王！过去有一位王，名为尼弥，了达诸法，如法为王，重视不放逸，凡所作事都远离放逸。大王！这尼弥王常观三世平等，又观一切诸法犹如三世平等，观过去一切诸法远离自性，观未来一切诸法远离自性，观现在之法也同样远离自性。大王！那尼弥王观一切三世法平等之后，对诸法不生取著。那尼弥王观察一切世间被四颠倒所颠倒：在不净之法中生起净想，在苦法中生起乐想，在无常法中生起常想，在无我法中生起我想。见到世间这样，便作这样的念头：‘世间就要毁坏，甚为大大败坏。这些众生，一切诸法自性空寂，却不觉知。’

【按】“世间则坏”之“则”，宋、元、明、宫本作“败”。

“大王！那时尼弥王又作这样的念头：‘我应当以四摄法摄受众生。若我以四法摄受众生，这些众生便会随顺于我，接受我的言教。’那时尼弥大王先作了这方便之后，便以四摄摄受众生。摄受众生之后，尼弥大王便教导人民一切诸法平等，这样说：‘你们众生，一切诸法离于自性。若一切法离于自性，那法也非过去、非未来、非现在。为什么呢？因为那法的自性不真实。若法离于自性，那法也不可说是过去、未来、现在。’大王！那时那尼弥王对那些众生教导这三世平等之法后，那些众生中，八十千万那由他无量百千众生得无生法忍。

#### 诸天称叹与帝释遣车迎王

“大王！那时三十三天在善法堂聚集而坐，这样议论：‘善哉善哉！鞞提呵国的人大获善利。这尼弥王了解诸法，如法为王，具足方便，对颠倒的众生，以善巧方便显示不颠倒之法。’那时释提桓因在离善法堂很远的别处，便以天耳听到那些天人所说，听后随即来到善法堂，就座而坐。就座之后，问那些天人说：‘你们诸天在善法堂谈论什么？’这样问了之后，那时诸天等回报帝释说：‘是的，天主！请听我们所说，我们刚才集会在善法堂所谈论的事，是说那鞞提呵国的人善得利益。这尼弥王了解诸法，如法为王，具足方便，对颠倒的众生，以善巧方便显示不颠倒之法，就是显示诸法的自性。’

【按】“去善法堂远”之“远”，圣本作“不远”。“解了诸法”之“诸”，宋、元、明、宫本作“说”。

“那些天人这样说了之后，那时帝释回报诸天子，这样说：‘这尼弥王具足成就不可思议的善巧方便。你们在这忉利天上，想见那尼弥王吗？’那时诸天都同声这样说：‘是的，天主！我们在这里想见那尼弥大王。’那时帝释天主便告诉名为摩多梨的驾驭之臣说：‘你上前来，可迅速备好诸天的千马宝车，前往阎浮提鞞提呵国的尼弥王所。这样说：“这是诸天的千匹调马之车，派来迎接大王。唯愿大王登上这宝车，不要生起怖畏，三十三天都愿乐见到大王。”若他上车之后，这样说：“大王！我现在带王从哪条道路前往那天上？是从住于颠倒地的众生之道而去？还是从住于不颠倒地的众生之道而去呢？”’那时摩多梨回答帝释说：‘是的，我接受教令。’

【按】“唯然天主”之“唯”，圣本作“惟”。“可疾严备”之“疾”，宋、元、明、宫、圣本作“庄”。

#### 尼弥王中道而行令众住三昧

“听了这话之后，便备好千匹调马之车，自己登上，从那忉利天下到阎浮提，到鞞提呵国的尼弥王所。对尼弥王这样说：‘忉利诸天现在送来千匹调马之车，王可以登车，不要生起怖畏，忉利诸天愿乐见王。’那时尼弥大王以无畏之心便即登车。登车之后，摩多梨这样说：‘我现在带王从哪条道路前往？是从住于颠倒地的众生之道而去？还是从住于不颠倒地的众生之道而去？’王便回答说：‘你可以带我从那两条道路的中间而去。’那时摩多梨便带尼弥王，从颠倒地众生之所与不颠倒地众生之所两处之间而去。

“大王！那时尼弥王对摩多梨说：‘你可以暂时停车，我要观察那颠倒众生所住之处。’那时摩多梨便接受王的教令，暂时停下马车。那时尼弥王在片刻之间，令八十千万众生安住于见实三昧之中。为什么这位王能在片刻之间令这么多众生住于见实三昧之中？因为这位王善于修习不放逸之行。令这些众生住于三昧，后来都得无生法忍。这时摩多梨全然不觉知王所作的事。

“那时摩多梨又带王到了须弥山顶。那时尼弥王远远望见青翠茂盛的丛林，告诉摩多梨说：‘那林子必定是不颠倒众生所居之处。’摩多梨说：‘大王！这是忉利诸天的善法之堂，那些忉利天众集会在堂上，想见大王。唯愿大王不要生起怖畏，当登上此堂。’那时尼弥王心不恐惧，便登上堂上。那时帝释远远望见尼弥王到来，便这样说：‘善来大王！’便分出半座，请王坐下。那时尼弥王便就帝释的半座而坐。

“那时帝释便以美言相互慰问，说：‘大王！你快速获得善利，能令佛法炽然增长。’那时帝释向忉利天众这样说：‘这尼弥王成就具足不可思议的善巧方便。这位王在片刻之间，能令八十千万众生安住于佛法中，然而摩多梨全然不觉知。’那时尼弥王便为忉利诸天广说种种殊胜微妙之法。利益天众之后，对帝释说：‘我现在想要回阎浮提。为什么呢？是为了在阎浮提护持佛的正法。’帝释回报说：‘现在正是时候。’又命令驾驭之臣摩多梨说：‘你可以再驾千匹调马之车，送尼弥王回阎浮提。’那尼弥王回到阎浮提之后，成就大悲与善巧方便，令无量众生安住于佛法之中。

【按】“白帝释言”之“白”，明本作“即白”。“大悲”之“悲”，宋、元、明、宫本作“慈”。

#### 一切法皆是佛法

“大王！不要作别的疑惑，不要生起别的看法。往昔的尼弥王，就是我自身。大王！应当观察不放逸之力难以思议。尼弥大王登上帝释之座，尚且没有贪著！所以大王！在佛法中应当勤加精进，修习不放逸。大王！什么是佛法？大王！一切诸法都是佛法。”

那时净饭王听了这话之后，便对佛说：“若一切法都是佛法，一切众生也应当是佛。”佛说：“若以不颠倒之心见众生，那就是佛。大王！所说的佛，就是如实见众生。如实见众生，就是见实际。实际，就是法界。大王！法界不可显示，只是名称，只是世俗，只是世俗的名数，只是有言说，只是假施设，应当这样观察。

#### 陀罗尼门与六十七法门

“大王！一切法无生，这是陀罗尼门。为什么这名为陀罗尼门？因为在此一切法无动无摇，无取无舍，这名为陀罗尼门。大王！一切诸法不灭，是陀罗尼门。为什么不灭是陀罗尼门？在其中一切法无动无摇，无取无舍；那陀罗尼门没有相貌，没有自性，不可施设，无作无造，无来无去，无众生，无命，无人，无养育，非对治，无形无状，无缠无离，无秽无净，无爱无憎，无缚无解，无命者，无出无退，无得无住，无定无乱，无知也非无知，非见非不见，非戒非犯，非悔非不悔，非喜非不喜，非猗非不猗，非苦非乐，非定非不定，非实非倒，非涅槃非不涅槃，非爱非离爱，非见非不见，非解脱非不解脱，非智非不智，非视非不视，非业非不业，非道非不道。大王！应当以这六十七法门入于一切法。

【按】“无来无去”之“去”，圣本作“生”。

#### 五阴非曾有非当有非今有

“大王！这色的自体，非曾有，非当有，非今有，同样，受、想、行、识的体性也是这样，非曾有，非当有，非今有。大王！如镜中之像，非有非无，这色的体性也是这样，非曾有，非当有，非今有。受、想、行、识也是这样，非曾有，非当有，非今有。大王！譬如回响之声，非曾有，非当有，非今有。大王！同样，色的体性也是这样，非曾有，非当有，非今有，受、想、行、识也是这样，非曾有，非当有，非今有。大王！譬如阳焰，非曾有，非当有，非今有。这色的体性也是这样，非曾有，非当有，非今有。大王！譬如聚沫没有坚实，非曾有，非当有，非今有。这色的体性也是这样，非曾有，非当有，非今有，大王！同样，受、想、行、识的体性也是这样，非曾有，非当有，非今有。大王！譬如在梦中梦见国中最殊胜的女人，这梦中所见，也非曾有，非当有，非今有。这色的体性也是这样，非曾有，非当有，非今有，同样，受、想、行、识的体性也是这样，非曾有，非当有，非今有。大王！譬如石女梦见生子，这梦中所见，也非曾有，非当有，非今有。这色的体性也是这样，非曾有，非当有，非今有，同样，受、想、行、识也是这样，非曾有，非当有，非今有。

【按】“譬如聚沫”前之“大王”，宫本作“大王如是受想行识亦复如是非曾有非当有非今有大王”。

“大王！色无所依，乃至识也无所依。大王！譬如虚空无所依，同样，大王！色无所依，乃至识也无所依。大王！色无有生，乃至识也无有生。大王！色无有灭，乃至识也无有灭。大王！如涅槃界，无有生，也无有灭。大王！同样，色也无生无灭，乃至识也无生无灭。大王！譬如法界，也无生无灭。大王！同样，色也无生无灭，乃至识也无生无灭。

“像这样，大王！一切法是如来的境界。不可思议也是如来的境界，不共法也是如来的境界，因为不与一切凡夫境界相共。所以一切声闻、缘觉，不毁不赞，不得不失，非觉非不觉，非知非不知，非识非不识，非舍非不舍，非修非不修，非说非不说，非证非不证，非显示非不显示，非可闻非不可闻。为什么呢？大王！那法没有这样的法可以扶举，可以摧倒。为什么呢？因为一切诸法离于自性。大王！现在可以在此法中安住其心，深观此法，不要相信他人。”

#### 释种得忍与授记

那时净饭王这样想：“在诸法中无法可得，没有这样一种法，证得此法而号为佛。诸法实不可得，佛只是为众生假借言说。”那时世尊说此法时，净饭王等七万释种得无生法忍。那时世尊知道诸释种已得深信，便现出微笑。那时慧命马胜比丘以偈颂问道：

```
大雄尊导师，为世现微笑，
惟愿世明炬，演说微笑事。
十力一切智，何因现微笑？
愿说彼笑因，断世诸疑网。
佛为释众故，而现微笑瑞，
为诸人天众，速除诸疑网。
得闻大雄说，世间离诸疑，
其心皆欣喜，安住佛法中。
世尊诸子等，得知微笑事，
坚固住誓愿，智慧必通达。
唯愿尊导师，断除大众疑，
众等除疑已，必得广大乐。
```
（大意：大雄尊导师为世间现出微笑，唯愿世间的明炬演说微笑之事。十力一切智者，因何现出微笑？愿说那笑的因缘，断除世间的疑网。佛为释种大众而现出微笑之瑞，为了诸人天大众，迅速除去疑网。听闻大雄宣说，世间远离疑惑，其心都欢喜，安住于佛法之中。世尊的诸弟子，得知微笑之事，坚固安住于誓愿，智慧必定通达。唯愿尊导师断除大众之疑，大众除疑之后，必得广大之乐。）

【按】“惟愿”之“惟”，宋、元、宫、圣本作“唯”。“除疑已”之“已”，宫本作“心”。

那时世尊以偈颂回答马胜说：

```
我现寂灭笑，马胜当谛听，
我今如实说，释种决定智。
诸法不可得，释种皆得知，
是故于佛法，决定心安住。
名称大释种，依于无所得，
当得上菩提，晓知一切法。
人中命终已，此释种决定，
得生安乐国，面奉无量寿。
住安乐国已，无畏成菩提，
能趣十方界，供养无量佛。
安住一佛土，能供十方佛，
愍诸众生故，而求无上道。
游历诸佛国，供养彼佛等，
皆已神力到，随佛所出处。
```
（大意：我现寂灭之笑，马胜应当谛听，我现在如实宣说释种的决定之智。诸法不可得，释种都已了知，所以对于佛法，以决定之心安住。具名称的大释种，依于无所得，当得无上菩提，晓知一切法。在人中命终之后，这些释种决定得生安乐国，面奉无量寿佛。安住安乐国之后，无畏而成就菩提，能趣向十方世界，供养无量佛。安住于一佛土，能供养十方佛，因怜愍众生，而求无上道。游历诸佛国，供养那些佛等，都以神力到达，随佛所出现之处。）

```
无量僧祇劫，供养诸导师，
以种种妙供，后当成佛道。
一一成佛已，能度无量众，
令得成佛道，复化诸众生。
彼国众生辈，皆当成佛道，
彼诸世尊等，不度声闻众。
一一诸佛等，俱寿一劫岁，
彼佛正法住，无量阿僧祇。
彼佛灭度后，大智菩萨众，
持法化于世，亿岁阿僧祇。
彼诸佛子等，教化无量众，
置于无上道，说法悉空寂。
令住不放逸，修集空寂法，
能得一切智，乐不放逸事。
```
（大意：在无量阿僧祇劫中，供养诸导师，以种种美妙的供养，以后当成佛道。各个成佛之后，能度无量众生，令他们成就佛道，又教化众生。那国的众生们，都当成就佛道，那些世尊等，不度声闻之众。每一位佛，都同寿一劫，那些佛的正法住世，无量阿僧祇劫。那些佛灭度之后，大智菩萨众，持法教化世间，经亿数阿僧祇岁。那些佛子等，教化无量众生，安置于无上道，说法都是空寂。令他们安住不放逸，修集空寂之法，能得一切智，乐于不放逸之事。）

【按】“乐不放逸事”之“事”，宋、元、明、宫、圣本作“辈”。

```
闻是释种趣，世尊所说者，
天人咸欣喜，志求于佛道。
```
（大意：听闻世尊所说释种的趣向，天人都欢喜，志求于佛道。）

#### 付嘱舍利弗流通见实三昧

那时世尊告诉慧命舍利弗：“舍利弗！这是菩萨见真实三昧，你应当为阿毗跋致诸菩萨宣说。为什么呢？舍利弗！此三昧不可言说。而如来在那三昧中不得一法，若不可得，它便不可觉；若不可觉，它便不可说；若不可说，它便不可知；那不可知的，就是过去、未来、现在诸佛之法。舍利弗！我现在付嘱于你，这是菩萨见实三昧，应当受持读诵，广为显说。

【按】“菩萨见实三昧”之“实”，明本作“真实”。

“舍利弗！若有善男子、善女人安住大乘，经过十劫修行五波罗蜜，离开般若波罗蜜；若又有人得闻这菩萨见实三昧，所得福德又超过前者。若又有善男子、善女人暂时得闻菩萨见真实三昧；若又有人得闻这菩萨见真实三昧后，为一人宣说，此人所得福德又胜过前者。若又有善男子、善女人，经过十劫，听闻后为他人解说；若又有人，乃至一刹那间修习这菩萨见真实三昧，所得福德又超过前者。所以舍利弗！你应当以这菩萨见真实三昧经，为诸菩萨宣说，教示修行。舍利弗！若修习这菩萨见实三昧，当获得无生法忍。舍利弗！在此会中，我所授记于无上道的诸菩萨，都得以安住于这菩萨见真实三昧之中。”

【按】“暂得闻”之“得”，宋、元、明、宫本无。

这时一切诸菩萨、声闻、天人，一切大众，阿修罗、乾闼婆、人非人等，听闻佛所说，欢喜奉行。
