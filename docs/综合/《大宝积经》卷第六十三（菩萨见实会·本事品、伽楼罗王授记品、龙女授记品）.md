# 《大宝积经》卷第六十三（菩萨见实会·本事品、伽楼罗王授记品、龙女授记品）

北齐·三藏那连提耶舍 译

## 菩萨见实会第十六之三

### 本事品第四

#### 迦叶忆念如来善根

那时慧命摩诃迦叶见到诸阿修罗王供养佛之后，生起稀有之心，这样思惟：“世尊本来修菩萨行时，作了什么善根，得到这样的果报？”那时迦叶便入如实三昧，以那三昧庄严其心之力，忆念过去阿僧祇阿僧祇劫中如来所修的一切功德，在那一道又一道、那一生又一生中所修的善根，都是为了满足无上菩提，以这善根得以安住不退转地，那些善根都得以忆念了知。那时迦叶忆念如来的大善根时，生起这样的心：“如佛所修习的善根广大。如来每一次发心的善根，即使十方世界恒河沙数国土中的众生都得人身，得人身之后，众生如恒河沙劫供养善逝，又如阿修罗一样，每一个众生如恒河沙劫供养如来之后，也不能报答如来一次发心的善根。”那时慧命摩诃迦叶从三昧起，以偈赞叹说：

```
一一如来牟尼尊，
发心广大向菩提，
此修罗等所供养，
佛迦罗分不及一。
世尊应供人中上，
如须弥山真檀聚，
人天中胜所供养，
由度功德彼岸故。
人中师子应受供，
过诸恒河沙数等，
譬如大海满中水，
香水和合而供养。
具足功德应受供，
多于恒河沙数等，
积满花聚而供养，
犹如斫迦婆罗山。
自然大士应受供，
如须弥山灯明炷，
大海以为香油器，
以灯供养诸胜者。
应受供养大威势，
多于恒河沙数等，
造立塔庙而供养，
由度功德彼岸故。
```
（大意：每一尊如来牟尼尊，发心广大，趣向菩提，这些阿修罗等所作的供养，不及佛的一迦罗分。世尊是应供，是人中之上，如须弥山般的栴檀之聚，为人天中的殊胜者所供养，因为已度到功德的彼岸。人中师子应受供养，超过恒河沙数，譬如大海中满满的水，以香水和合而供养。具足功德者应受供养，多于恒河沙数，积满如斫迦婆罗山般的花聚而供养。自然的大士应受供养，以如须弥山般的灯炷，以大海作为香油之器，以灯供养诸殊胜者。应受供养的具大威势者，以多于恒河沙数，建造塔庙来供养，因为已度到功德的彼岸。）

【按】“真檀”之“真”，宋、元、明、宫、圣、圣乙本作“栴”。迦罗分，极微小的分量。斫迦婆罗山，即铁围山。

```
人中坚固应受供，
以诸广大胜宝盖，
其盖遍覆三千界，
经于那由他劫数。
怜愍世间人中尊，
无边功德应受供，
以诸宝幢所供养，
遍满十方诸世界。
于不思议亿劫数，
以广大幡而供养，
满恒河沙诸世界，
经于无量亿劫数。
```
（大意：人中坚固者应受供养，以种种广大殊胜的宝盖，其盖遍覆三千世界，经过那由他劫数。怜愍世间的人中之尊，具无边功德，应受供养，以种种宝幢来供养，遍满十方诸世界。在不可思议亿劫之中，以广大的幡来供养，充满恒河沙数诸世界，经过无量亿劫。）

```
供养如来人师子，
起于分别作譬喻，
大论师中师子子，
谛听谛听诸天人。
我及诸来在此众，
若如恒河沙数等，
诸有十方世界众，
一切皆当得作佛。
具足十力人师子，
彼佛头数如恒沙，
一一皆有恒沙头，
于一一头如恒沙。
各各皆有恒沙口，
彼于一一无量口，
有于无量沙数舌，
以舌赞叹于如来。
彼诸如来说不尽，
功德彼岸不可到，
一切智智不可量，
由度功德彼岸故。
```
（大意：为了供养如来人中师子，我起分别心作譬喻，大论师中的师子之子，谛听谛听，诸天人。我以及诸来到这会中的大众，若如恒河沙数，以及十方世界所有的大众，一切都当得作佛。具足十力的人中师子，那些佛的头数如恒河沙，每一位佛都有恒河沙数的头，在每一个头上又如恒河沙数，各各都有恒河沙数的口，在那每一个无量之口中，有无量沙数之舌，以舌赞叹如来，那些如来也说不尽，功德的彼岸不可到达，一切智智不可度量，因为已度到功德的彼岸。）

#### 如来发心功德无边

那时世尊告诉诸比丘说：“善哉善哉！诸比丘！我的诸声闻端直而住，有智有法，也如梵天，竟能入于我的功德海中。为什么？如来具足无量功德，具足不可思议的功德。诸比丘！如来的功德聚不可思议。诸比丘！如来的功德聚若是有形之色，每一次发心所得的功德，在如恒河沙数的世界中也容纳不下。为什么？诸比丘！如来每一次发心的功德，是一切智所攀缘之处，如恒河沙数的诸佛在如恒河沙数的劫中也不能思量，说不能尽。为什么？如来本来修菩萨行时，没有一次发心不是为了利益一切众生、为众生所摄的，没有一次发心不是为了一切众生。众生界无边际，其中的众生也无边际；所有的众生界无边际，如来每一次发心的功德也无边际。为什么？如众生界无边际，如众生界不可度量，如来每一次发心的功德聚不可穷尽，都是为了怜愍、利益、安乐一切众生，所以发心。假使一切众生都来供养，也不能报答如来一次发心的功德。为什么？那些众生供养如来，都是为了希望得到杂食的世间果报；菩萨本来发心，远离杂食、求世间果报之心，为了利益安乐众生，想令众生背离生死，趣向涅槃。如来本来修菩萨行时，为了利益安乐众生，远离杂食，不求世间果报。”

【按】“恒沙”之“恒”，《大正藏》作“洹”，今依CBETA作“恒”。

原文：“彼诸众生供养如来，皆为悕望杂食世报故”（大意：那些众生供养如来，都是为了希望得到杂食的世间果报。“杂食”所指未详，存疑。）

#### 因陀幢如来佛土

佛告诉诸比丘：“在过去世无量无边流转生死、阿僧祇不可思议、无始世界的不可说劫中，有佛号为因陀幢王出现于世，如来、应供、正遍知、明行足、善逝、世间解、无上士、调御丈夫、天人师、佛、婆伽婆。那佛如来以每一次发心，曾为如恒河沙数世界中的众生思量发心，作利益安乐。比丘！那因陀幢如来作佛时，恒河沙数的世界同为一个佛刹。那因陀幢如来、应供、正遍知的国土庄严清净，远离恶趣以及八难。在那因陀幢如来、应供、正遍知的国土中，所有众生都住于正定聚；邪定的众生、增上慢的众生一向都没有；不净的身业、不净的口业、不净的意业一切都没有；也没有恶趣的烦恼，造作恶趣之业。为什么？因陀幢如来教导这些众生，令他们发心止息一切恶，以善法传授令他们修学。在这因陀幢如来的国土中，曾得五种乐，就是一得欲乐，二得出家乐，三得禅乐，四得三摩跋提乐，五得无上菩提乐。那些众生虽然受这些乐，却不贪著。譬如蜜蜂只取花的滋味，不取花的颜色；那些众生也是这样，虽然受这些乐，却不执取。譬如飞鸟在空中飞行，不执著于空；像这样，众生虽然受这些乐，却不执取，也是这样。

【按】“恒河沙世界”之“河”，圣乙本无。“正遍知其佛土中”之“知”，圣乙本作“知明”。

“在这因陀幢如来、应供、正遍知的佛土中，所有众生没有忧苦，唯有喜乐，也没有不苦不乐受；由于没有愚痴，唯有称心之乐。为什么？因为那些众生本来修善。由于那因陀幢如来本来修菩萨行时示现种种相好，令那些众生不作一切恶，安置众生修习善法，他们次第远离诸恶道，安住于善处，他们对一切种类的不善业一向都没有。其所作之业得果报时，心不欣乐；生起苦受，绝无此理，因为不作恶业，所以不受苦果；由于没有愚痴，不苦不乐受也没有。那因陀幢如来的佛土中，一切时恒常没有恶风暴雨，也没有毒热；那些众生由时节变易而生的苦，一切都没有。

原文：“其所作业得果报时，心不欣乐”（大意：其所作之业得果报时，心不欣乐。句意与上下文如何相承，未详，存疑。）

“那因陀幢如来本来修菩萨行时，那佛土中众生的一切身业，以智为首，随智而转，演说开示，正确显明；同样一切口业，以智为首，随智而转，演说开示，正确显明；同样一切意业，以智为首，随智而转，演说开示，正确显明。像这样，那些众生从那菩萨听闻之后，那些众生的一切身业、一切口业、一切意业，以智为首，随智而转，回向，以善业的缘故，愚痴之报不生。由于愚痴，才受不苦不乐受；那些众生在那佛土中，苦受、不苦不乐受一向都没有，因为远离了愚痴。那些众生生于那国土时，那因陀幢如来教化之后，他们对法敬重；若游行时，思量于法，爱欲于法，染著于法；他们心生爱欲，染著于法，游行时没有苦受，行住坐卧、睡眠醒觉乃至没有威仪之苦。那些众生在那国土中没有可随顺的恶，由于没有恶，所以没有苦可生；对善不执著，以这因缘，那些众生由于随顺善而没有执著，所以变易之苦没有；对诸法中不生贪著，所以坏苦不生；也没有怨憎会苦。为什么？由于那些众生对一切众生得以安住平等心现前，所以没有怨憎会苦。也没有爱别离苦。为什么？由于那些众生对一切法不执著，而爱别离苦从爱而生，所以没有爱别离苦。苦苦也没有。为什么？因为对乐受不生执著。唯有行苦，就是无常之苦。为什么？因为那佛唯说第一义。那佛住世经过恒河沙劫，在那佛刹中，没有一个与佛争论的众生来生于其国。为什么？由于那如来本来行菩萨道时成熟了众生。”

【按】“染著”之“染”，圣本作“深”。“染著于法”之“法”，圣本作“法若”。

#### 少善根不能成熟众生净佛国土

佛告诉诸比丘：“你们认为怎样？能以下劣的善根、少量的善根、不善修习的善根、与不善相应的善根、非大精进的善根、非善趣的善根、非善发的善根、非善回向的善根，利益这样等等的众生，能给予安乐、除去痛苦吗？能清净这样广大的国土，成熟这样多的众生吗？”诸比丘说：“不能，世尊！”

佛又告诉诸比丘说：“你们认为怎样？可以用下劣之心、怯弱而与不善根相应之心、非精进之心、非善集善根之心、非善趣之心、非善发善根之心、非善回向之心，利益这样等等的众生，思惟给予安乐、能除去痛苦吗？能庄严清净这样广大的佛刹，成熟这样多的众生吗？”诸比丘说：“不能，世尊！”

【按】“不善根相应心”之“根”，宫本无。“非善集根心”之“集根”，元本作“习根”，明本作“习善根”，圣乙本作“善根”。

佛又告诉诸比丘说：“你们认为怎样？可以用下劣之信、少量之信、羸弱之信、怯弱之信、与不善相应之信、非精进之信、非善集善根之信、非善趣之信、非善发善根之信、非善回向之信，利益这样等等的众生，除去痛苦、给予安乐吗？能庄严清净这样广大的佛刹，成熟这样多的众生吗？”诸比丘说：“不能，世尊！”

佛又告诉诸比丘：“你们认为怎样？可以用下劣之戒、少量之戒、羸弱之戒、非精进之戒、非善集善根之戒、非善趣之戒、非善发善根之戒、非善回向之戒，利益这样等等的众生，除去痛苦、给予安乐吗？能庄严清净这样广大的佛刹，成熟这样多的众生吗？”诸比丘说：“不能，世尊！”

佛又告诉诸比丘说：“你们认为怎样？可以用下劣的精进、少量的精进、羸弱的精进、怯弱的精进、非相应的精进、非精进的精进、非善集善根的精进、非善趣的精进、非善发善根的精进、非善回向的精进，利益这样等等的众生，除去痛苦、给予安乐吗？以及能庄严清净这样广大的佛刹，成熟这样多的众生吗？”诸比丘说：“不能，婆伽婆！”

佛又告诉诸比丘：“你们认为怎样？可以用下劣之念、少量之念、羸弱之念、怯弱之念、非与善根相应之念、非精进之念、非善集善根之念、非善趣之念、非善发善根之念、非善回向之念，利益众生以及思惟给予安乐吗？以及能庄严清净这样广大的佛刹，成熟众多众生吗？”诸比丘说：“不能，世尊！”

佛又告诉诸比丘说：“你们认为怎样？可以用下劣之定、少量之定、羸弱之定、怯弱之定、非与善根相应之定、非精进之定、非善集善根之定、非善趣之定、非善发善根之定、非善回向之定，利益众生，思惟给予安乐吗？能庄严清净这样广大的佛刹，以及能成熟这样多的众生吗？”诸比丘说：“不能，世尊！”

佛又告诉诸比丘说：“你们认为怎样？可以用下劣之慧、少量之慧、羸弱之慧、怯弱之慧、非与善根相应之慧、非精进之慧、非善集善根之慧、非善趣之慧、非善发善根之慧、非善回向之慧，利益众生，思惟给予安乐吗？能庄严清净这样广大的佛刹，以及能成熟这样多的众生吗？”诸比丘说：“不能，世尊！”

佛告诉诸比丘说：“诸比丘！实在是这样，不能以少量的善根、少量的戒、少量的信、少量的精进、少量的念、少量的定、少量的慧，利益众生以及思惟给予安乐、离苦，不能庄严清净广大的佛刹，成熟这样多的众生。”

【按】“成熟”之“熟”，圣、圣乙本作“就”。

#### 文殊师利来证因陀幢即是世尊

佛告诉诸比丘：“你们认为怎样？那时的因陀幢如来，你们知道是谁吗？”如来问了之后，诸比丘默然不答。就在那时，东方超过如恒河沙数诸佛世界，有一个世界名为月光庄严，那国土有佛，号为高威德王如来、应供、正遍知，现在住世。文殊师利在那大众中，便知道释迦牟尼的心念，便对高威德王佛说：“现在释迦如来在娑婆世界说法。世尊！我现在想前往那里，拜见释迦如来，礼拜听法，供养恭敬。”这样请求之后，那时高威德王如来告诉文殊师利：“随意而去，现在正是时候。”那时文殊师利童子从座而起，偏袒右肩，右膝着地，头面礼拜高威德王如来，右绕三匝。譬如壮士屈伸手臂的工夫，那时文殊师利在那月光庄严世界中隐没，在释迦牟尼佛前出现，头面接足，敬礼如来，退坐一旁，对佛说：“世尊！往昔的因陀幢如来，就是现在的世尊。为什么？由于这位世尊具足不可思议的种种善巧方便，能成熟众生，清净佛国土，恒常不疲倦，也无厌足；世尊安置众生住于菩萨乘，也无厌足。若有说实语的人作正确的话，说胜中之胜、胜中之妙、胜中的上首、最胜中的最胜，说佛是这样的，应当知道释迦牟尼佛真实无异。”那时文殊师利说偈道：

【按】“如来问已”之“问”，明本作“闻”。“任意而去”之“任”，宫本作“住”。

```
雄猛巧方便，怜愍诸世间，
现大威神力，成熟众生故。
已于过去世，曾作八亿佛，
犹自有神力，无心取正觉。
六十一三千，清净佛国土，
浅识不知佛，牟尼巧方便。
不舍初发心，彼彼处处现，
更于未来世，示现无量佛。
```
（大意：雄猛而具巧方便，怜愍诸世间，示现大威神力，为了成熟众生。已在过去世曾作八亿佛，仍自有神力，无心取正觉。六十一个三千世界的清净佛国土，浅识的人不知佛，不知牟尼的巧方便。不舍最初的发心，在那一处又一处示现，更在未来世示现无量佛。）

【按】“六十一三千”之“一”，圣、圣乙本作“二”。

原文：“六十一三千，清净佛国土”（大意：六十一个三千世界的清净佛国土。所指未详，存疑。）

### 伽楼罗王授记品第五

#### 金翅鸟王化现供具

（大意：“如佛没有过失，善见诸法，虚伪的妄相欺诳愚者，如幻的庄严没有实体，唯能惑乱诸凡夫。众生对法迷惑而无智，不知诸法如实之性，导师已见那一一之法，又能令其他众生理解。虚空兴起云，遍覆大地，见那空中之云犹如影子，它没有实体，无所依止，也如影子，没有实在。”）

【按】“彼彼法”之“彼”，元、明、圣、圣乙本作“岸”。

```
世间尊重以此业，
于智慧人作利益，
如来示现无体性，
一切众生真实故。

```
（大意：“像这样，众生没有体性，唯能诳惑诸根之门，佛以智慧这样见诸有趣，只能诳惑无智之人。世间所尊重的以此业，为有智慧的人作利益，如来示现无体性，是为了令一切众生得到真实。唯以真实之法令佛子喜悦，在生死泥中作桥梁，真实之法不是愚痴者的境界，因为他们执著于声而不求其义。我归依无边的佛，具足示现真实的人，能为愚夫作亲人与救护、归趣、舍宅与善知识。像这样，为了求大菩提，我们供养尊贵的导师，愿得作佛，觉悟他人，我们利益世间犹如佛一样。”）

#### 马胜请问龙女果报

那时世尊知道诸龙女已得深信，现出微笑之相。那时慧命马胜比丘以偈问道：

```
于世智中胜智者，
最胜导师现微笑，
尊重坚固德如山，
今现微笑非无因。
人中最上胜尊主，
愿为说此笑因缘，
天人龙鬼若得闻，
于佛皆生大欣喜。
世间导师于世闻，
常知一切因缘法，
无有一法佛不解，
因缘种类佛悉知。
唯愿善逝见为说，
如佛所知笑因缘，
一切大众若得闻，
皆生欣喜除疑网。
如来妙法有大利，
此等大众必当获，
大众若得寂定心，
由味妙法利益故。
佛力令断分别已，
唯乐菩提听佛说，
若得闻于笑因缘，
当必成就于佛道。
```
（大意：在世间智慧中最殊胜的智者，最殊胜的导师现出微笑，尊重坚固，功德如山，现在现出微笑，并非没有原因。人中最上的殊胜尊主，愿为宣说这微笑的因缘，天、人、龙、鬼若得听闻，都会对佛生起大欢喜。世间的导师在世间中，常知一切因缘之法，没有一法是佛不了解的，因缘的种类佛都知道。唯愿善逝为我们宣说如佛所知的微笑因缘，一切大众若得听闻，都生欢喜，除去疑网。如来的妙法有大利益，这些大众必当获得，大众若得寂定之心，是由于品味妙法的利益。佛力令我们断除分别之后，唯乐菩提，听佛宣说，若得听闻微笑的因缘，必当成就佛道。）

【按】“于世闻”之“闻”，宋、元、明、宫、圣、圣乙本作“间”，今从之。

```
若人于法情有疑，
其心掉动生苦恼，
现今此会大众是，
不知微笑因缘故。
大众堪能断疑网，
唯愿导师令除灭，
速为众说度我等，
以何因缘现微笑？
谁于今日心清净？
谁于今日降魔怨？
谁于佛所生敬信？
谁于今日供养佛？
唯愿导师大众前，
演说谁有如是力，
我等闻已生喜心，
生喜心已得安乐。
此诸大众咸敬礼，
一切皆有疑网心，
愿说笑因生喜故，
唯愿世尊断众疑。
此诸天人得闻已，
大众当得无疑网，
若得闻于如来说，
一切当得欣喜心。
```
（大意：若人对法心有疑惑，其心掉动，生起苦恼，现在这会中的大众就是这样，因为不知道微笑的因缘。大众堪能断除疑网，唯愿导师令其除灭，迅速为大众宣说，度脱我们，以什么因缘现出微笑？谁在今天心意清净？谁在今天降伏魔怨？谁在佛所生起敬信？谁在今天供养佛？唯愿导师在大众面前，宣说谁有这样的力量，我们听了之后生起欢喜心，生起欢喜心之后得到安乐。这些大众都恭敬礼拜，一切都有疑网之心，愿宣说微笑的原因，令大众生喜，唯愿世尊断除大众的疑惑。这些天人得以听闻之后，大众当得没有疑网，若得听闻如来所说，一切都当得到欢喜之心。）

#### 世尊授龙女记

那时世尊以偈回答慧命马胜说：

```
善哉善哉慧马胜，
能问如来笑因缘，
见诸龙女供养已，
我愍世间故微笑。
我今为汝说彼果，
离诸过恶至心听，
我今所为现微笑，
汝马胜等听我语。
此诸龙女心无著，
求大菩提修进行，
以智慧修世间空，
决定安住菩提道。
于此无作无受者，
亦无生者养育者，
但有诸法无余事，
其法亦妄如焰像。
以知恩故供养我，
能以智慧知真实，
善哉佛解诸世间，
所谓能见空无主。
彼乐此空善修习，
虽设供养犹如幻，
于胜菩提所发愿，
观彼菩提亦无著。
此以无等供养佛，
亦观众生空寂已，
永离龙道恶趣身，
与彼帝释天中住。
```
（大意：善哉善哉，智慧的马胜，能问如来微笑的因缘，见到诸龙女供养之后，我怜愍世间而微笑。我现在为你宣说那果报，远离种种过恶，至心而听，我现在所以现出微笑，你们马胜等听我说。这些龙女心无所著，求大菩提，修习精进之行，以智慧修习世间空，决定安住于菩提道。在此中没有作者、没有受者，也没有生者、养育者，只有诸法，没有其余之事，那法也是虚妄，如阳焰之像。由于知恩而供养我，能以智慧了知真实，善哉！佛了解诸世间，就是能见到空而无主。她们乐于这空而善加修习，虽然设置供养，也如幻化，对殊胜菩提所发的愿，观察那菩提也无所执著。她们以无等的供养供佛，也观察众生空寂之后，永离龙道的恶趣之身，与那帝释在天中同住。）

【按】“听我语”之“语”，元、明本作“说”。“空无主”之“主”，圣乙本作“生”。

```
在忉利天极受乐，
尽彼天子寿命已，
无能毁訾彼名称，
复得生彼夜摩天。

具受彼中胜妙乐，
于彼善道尽寿已，

彼得善名无能毁，
为诸天女胜供养，

乃至尽彼天寿限。
于彼化乐天宫中，
具受彼天胜乐报，

```
（大意：在忉利天极受快乐，尽了那天子的寿命之后，没有人能毁訾她们的名称，又得生于那夜摩天。居住在夜摩天宫时，具受那天上的胜妙之乐，诸佛子等住在那里，乃至尽了那天的寿量。这些佛子具受快乐，尽了那夜摩天的寿命之后，又得往生兜率天，与那处的天人同类。被诸天女常常围绕，具受那天上的胜妙之乐，心无所著，安住于善道，譬如莲花不被水所污。那些天人能以大智慧观察一切世间是空，犹如画在石上的字不会灭去，她们的正念不失也是这样。那些天子住在那天上，具受其中的胜妙之乐，在那善道中尽了寿命之后，当更往生化乐天。她们得到善名，无人能毁，被诸天女殊胜地供养，虽然住在天宫，心无所著，乃至尽了那天的寿限。）
