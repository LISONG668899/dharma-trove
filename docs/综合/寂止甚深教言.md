# 寂止甚深教言

全知麦彭仁波切 造

顶礼妙吉祥！

```
སེམས་ལ་དམིགས་ན་ཞི་གནས་འགྲུབ། །
རིམ་གྱིས་གནས་ལུགས་ལྷག་མཐོང་སྐྱེ། །
```

若能专注于自心，即能成办寂止之定；渐次，实相之胜观由此而得生起。

```
དེ་ལ་རང་སྙིང་སྟོང་པའི་ངང་། །
གསལ་ལེ་སང་ངེ་བ་ལེ་ནི། །
ཤེས་པ་ནང་དུ་བཀུག་ནས་བཞག །
སེམས་ཀྱིས་སེམས་ལ་དམིགས་ཞེས་བྱ། །
```

于此当中，在自己心间空性之境界中，明然清澈、朗然赤裸，将觉知向内收摄而安住，此即所谓"以心观心"。

```
སེམས་ལ་དམིགས་ན་སེམས་ནི་འདི། །
ཞེས་པའི་གཏད་སོ་མི་དམིགས་ཀྱང་། །
སེམས་ཞིག་ཡོད་ན་ལུས་ཀྱི་ནང་། །
སྙིང་དབུས་མིན་པ་གར་ཡང་མེད། །
```

虽说以心观心，然而并无一个可指认为"此即是心"的实有对境可得；但若确实有心，则于身体之内，除心间之外，再无他处可寻。

```
མི་དྲན་དགུ་དྲན་འགྱུ་རྟོག་གི། །
བྱུང་ཁུང་དེ་རུ་བལྟ་བཞིན་གནས། །
སེམས་བཙལ་མི་བྱ་ལྷན་ནེར་བཞག །
བཞག་ས་ཡོད་མེད་བྱ་མི་དགོས། །
བཞག་རྒྱུའི་སེམས་ཡོད་དེ་གས་ཆོག །
```

无论生起何种忆念不忆念、纷纭杂乱之动念，皆应观照其生起的根源而安住；不必刻意寻觅此心，只须任其坦然而住。至于有无一个安住之处，也不必深究，只要有一颗能够安住的心，便已足够。

```
ཁོང་ནང་སེམས་དེ་ཉལ་མལ་དུ། །
ན་ནོར་ཞོག་དང་དེ་ག་རང་། །
བཞག་ཐབས་ཡིན་གྱི་གཞན་མི་དགོས། །
```

如同将此心安置于内在的卧榻之上一般，任其自然而息、不加造作，这便是安住之法，此外别无他法可需。

```
ཆུ་ལ་ཉི་འོད་ཕོག་པ་ཡི། །
ཟེར་མ་ལྷམ་ལྷམ་གཡོ་བ་ལྟར། །
སེམས་རྟོག་འགྱུ་བ་མྱུར་མྱུར་པོ། །
ཐད་ཀར་བཀག་པས་མི་ཁེགས་ཏེ། །
ཆུ་དེ་མ་བསྒུལ་རང་བཞག་ན། །
ཟེར་སྣང་དེ་ཡང་ལྷན་ནེར་ལྷོད། །
```

譬如阳光照在水面之上，波光粼粼、闪烁摇曳，分别念迅疾的动摇也是如此——若以强力直接加以遮止，反而无法止息；然而，若任水面不加搅动、自然安住，那波光的显现也会随之自然趋于平静。

```
དེ་བཞིན་འགྱུ་བ་ཀྱང་མེད་པོའི། །
འབྱུང་ཁུངས་ཤེས་པ་ལྷན་ནེར་ཞོག །
```

同样，纵然这动念本自无有实体，也只需识知其生起的根源，坦然安住即可。

```
དེ་ངང་མ་བརྗེད་དྲན་པའི་རྒྱུན། །
བར་མེད་ལུ་གུ་རྒྱུད་དུ་བརྟེན། །
```

于此境界中不忘失，当依止无有间断、犹如链环相扣一般相续的正念。

```
སྟོང་སང་འདྲ་ཡང་དེ་གར་ཞོག །
གསལ་གསལ་འདྲ་ཡང་དེ་གར་ཞོག །
འགྱུ་འགྱུ་འདྲ་ཡང་དེ་གར་སྡོད། །
ཙེན་ནེ་ཀ་རེ་རྗེན་ནེ་བ། །
ཅི་འདྲ་བྱུང་ཡང་དེ་གར་ཞོག །
```

无论显现为空豁豁然，皆安住于当下；无论显现为明朗朗然，皆安住于当下；无论显现为动摇摇然，亦安住于当下；无论显现为鲜明锐利，或是裸然赤露，不管出现何种情形，皆一概安住于当下。

```
སྟོང་ངོ་གསལ་ལོ་འགྱུའོ་ཞེས། །
ཤེས་ཀྱང་དེ་གའི་རྗེས་དེད་སྤོང་། །
ཤེས་པ་རང་མལ་རང་སོར་ཞོག །
```

纵然了知"这是空的""这是明的""这是动的"，也应舍弃追逐此类分别的念头，让觉知安住于它本自的位置、本然的居所。

```
དེ་ལ་གོམས་འདྲིས་ཡུན་རིང་བྱ། །
འདྲ་དཔྱད་རྟོག་ཆེན་རང་སར་བསྐྱུར། །
```

于此应当长久串习，把一切比较、审察的粗大分别念，皆舍置于其本位之中。

```
རེས་འགའ་མི་འགྱུ་རྨུགས་པ་ན། །
བྱིང་བ་གསེང་ལ་རང་གར་ཞོག །
```

有时若不生动念而陷入昏沉暗昧，应当消除此种沉没昏钝，任其自然而安住。

```
རེས་འགའ་འགྱུ་དྲན་དྲག་སྐྱེ་ན། །
འགྱུ་འགྱུ་པོ་དེ་སེམས་ཡིན་པས། །
དེ་ཡི་སྟེང་དུ་ལྟོས་ལ་ཞོག །
འགྱུ་རྗེས་མ་མཐུད་རང་ས་ཟུང་། །
དེ་ནས་འགྱུ་བ་རང་འགག་འགྱུར། །
```

有时若猛然生起强烈的动念，由于这纷纭动摇之念本身即是心，故应直视于彼而安住；不追随动念之后，坚守自己的本位，如此一来，动念便会自然止息。

```
འགྱུས་དང་མ་འགྱུས་ཐམས་ཅད་ཀུན། །
ཚོར་ཙམ་བྱུང་ཡང་སེམས་ཀྱི་སྟོང་། །
སེམས་ནི་རང་བཞག་ཅེས་བྱའོ། །
```

无论是动摇还是不动摇，一切之中，纵然仅仅生起些许觉受，也无非是心之空性，这便称为"心之自然安住"。

```
སེམས་དེ་སྙིང་དབུས་མལ་བཞག་གམ། །
རང་སེམས་རང་བབ་ལྷོད་དེ་ནི། །
འགྱུ་དྲན་འཇུར་མདུད་རང་ཁྲོལ་བཞག །
```

将此心安置于心间的卧榻之上，或让自心任其本然、松坦而住，如此，动念纷纭所结之扭结，便会自然解开。

```
རྣམ་རྟོག་འགྱུ་བ་ཟད་མེད་པོ། །
རང་གར་ཡར་བའི་དུས་མེད་ལ། །
ཇི་ཙམ་འགྱུས་ཀྱང་འབྲས་བུ་མེད། །
ངན་རྟོག་སྡུག་བསྔལ་ཟད་མི་ཤེས། །
```

分别妄念之动摇本无穷尽，绝无自行止息、自然平息之时；无论如何动摇，都不会有任何结果；恶念与痛苦，无穷无尽，难以了知其边际。

```
དེ་བས་འདི་ཡི་མཚངས་རིག་ནས། །
ཐོག་མེད་དུས་ནས་འདི་དབང་སོང་། །
དེ་ཕྱིར་ཡོན་ཏན་ཅང་མ་ཐོབ། །
```

是故，应当认清此中之过患：从无始以来，我们始终受此所转、任其摆布，正因如此，才从未获得任何功德。

```
ད་ནི་འདི་ལ་ཞེན་ལོག་ནས། །
ཅི་ནས་སེམས་གནས་བསྒྲུབ་བྱས་ན། །
ཏིང་འཛིན་མངོན་ཤེས་ལ་སོགས་པའི། །
ཡོན་ཏན་རྣམ་མང་ཐོབ་འགྱུར་ཞིང་། །
རྣལ་གནས་རང་དབང་བདེ་མཆོག་རྙེད། །
```

如今，若能对此生起厌离，设法令心得以安住，便将获得禅定、神通等诸多功德，并证得任运自在之殊胜安乐。

```
དེ་ལྟར་སྐྱོན་ཡོན་ཤེས་པའི་བློའི། །
ཅི་ནས་སེམས་ལ་དབང་བསྒྱུར་ནས། །
ཇི་སྲིད་ཞི་གནས་མ་ཐོབ་བར། །
བརྩོན་པ་ལྷོད་པ་མེད་པར་བྱ། །
```

如是，凭借了知过患与功德之智慧，设法令心得以驾驭；乃至尚未证得寂止之前，皆应精进不懈，不容丝毫松懈。

```
དེ་ལྟར་ཡང་ཡང་གོམས་པ་ལས། །
སྙིང་དབུས་རླུང་འདུ་དབུ་མར་འཇུག །
རྣམ་རྟོག་མགོ་རྒོད་ཇེ་ཞི་དང་། །
རང་སེམས་ལས་རུང་ཇེ་བཟང་འགྱུར། །
```

如此反复串习之后，心间之气便汇聚而融入中脉，狂野纷飞的分别念渐趋平息，自心也愈发调柔而堪能。

```
བླ་མའི་ངོ་སྤྲོད་གཞན་མེད་ཀྱང་། །
མན་ངག་གནད་ཀྱི་བཞག་ཐབས་འདི། །
སེམས་གནས་སླ་ལ་རླུང་གེགས་མེད། །
```

纵然并未得到其他上师之直指教授，此窍诀心要的安住之法，也能使心易于安住，且不致有气脉方面的障碍。

```
སེམས་ལ་དམིགས་པ་འདི་ལྟ་བུས། །
ནང་དུ་ཡང་དག་བཞག་པ་ན། །
ཏིང་འཛིན་ལས་སུ་རུང་བ་ནི། །
དཀའ་ཚེགས་མེད་པར་མྱུར་དུ་རྙེད། །
```

以这样专注于心之法，若能于内在真实安住，那么堪能之禅定，便会迅速而毫无艰难地获得。

```
སྙིང་གའི་ཕྲ་ཐིག་འདིར་མི་དགོས། །
ཁ་དོག་ཡི་གེ་རླུང་འཛིན་མེད། །
རང་སེམས་ཡོད་པ་དེ་ཉིད་ལ། །
ལྟ་བཞིན་དྲན་རྒྱུན་བསྐྱང་བ་ཡིན། །
```

此中不需要心间的细微明点，也不需要彩色种子字与持风之法；只需于自心本有之上，一边观照、一边护持正念之相续不断，如此而已。

```
འདི་བས་ཟབ་པའི་ཞི་གནས་ཀྱི། །
གདམས་པ་བྱ་སླ་དོན་ཆེ་མེད། །
```

再没有比这更为深奥、更易修持、且义理更为重大的寂止教授了。

```
དང་བོར་སེམས་གནས་གྱུར་ནས་ནི། །
སེམས་ཀྱིས་སེམས་ལ་བལྟས་པ་ན། །
ནམ་མཁར་བལྟས་ཤིང་བལྟས་པ་ན། །
མཐོང་བའི་དངོས་པོར་མི་དམིགས་ལྟར། །
```

最初，待心得以安住之后，以心观心之时，就如同仰望虚空、一再地观看，却始终见不到任何可以指认的实有之物一般。

```
ལྟ་ངན་ཀུན་ལས་རང་གྲོལ་ནས། །
སྟོང་གསལ་ཟུང་འཇུག་སེམས་ཀྱི་གསང་། །
ཆོས་ཉིད་གནད་ལ་འཆར་བ་ཡིན། །
```

由此，便从一切邪见之中自然解脱，空明双运这一心之隐秘，即于法性之要害处显现出来。

```
དེ་ནས་རིག་སྟོང་གཉུག་མ་ཆེ། །
ལྷན་སྐྱེས་ཡེ་ཤེས་རང་བྱུང་བ། །
འོད་གསལ་རྫོགས་པ་ཆེན་པོའི་དོན། །
བརྒྱུད་པའི་བྱིན་རླབས་ལས་མཐོང་འགྱུར། །
```

此后，觉空无别之广大本然、俱生自生之智慧，光明大圆满之义，将由传承之加持力而得以现见。

于火马年二月初六日午间座间，麦彭巴所写。善哉！
