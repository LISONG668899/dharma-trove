# 《大宝积经》卷第七十四（菩萨见实会·六界差别品之二）

北齐·三藏那连提耶舍 译

## 菩萨见实会第十六之十四

### 六界差别品第二十五之二

#### 梦闻美女音乐喻

“大王！如人在梦中见到国中第一端正最殊胜的女人，在那女人身边听到微妙可爱的音乐，那人听后，以那乐音自我娱乐，享受五欲之乐。此人醒后，忆念梦中可爱的音乐。你认为怎样？梦中所见是真实存在的吗？”王说：“不是的。”“大王！你认为怎样？此人把所梦执以为真实，这是智慧吗？”王说：“不是的，世尊！为什么呢？梦中所见的最殊胜女人、可爱音乐，毕竟是无，何况五欲之乐。此人只是自己疲劳，全无真实。”

佛说：“大王！同样，愚痴无闻的凡夫，见到最殊胜的女人以及音乐，称合其意，心生执著，生执著后生起爱乐，既爱乐后生起染著之心，生染著后作染著之业，就是身三种、口四种、意三种业。造了那业之后便即谢灭，这业灭了之后，不依于东方而住，也不依于南、西、北方、四维、上下而住。这样的业，乃至临死之时最后识灭，见到先前所作，在心想中显现。大王！此人见后心生慌乱怖惧，自身这一分的业已尽，另一业现前。大王！犹如梦醒后忆念梦中之事。像这样，大王！以最后识为主，以那业为因缘，以这两种缘，在受生的一分之中，识心初起，或生于地狱，或生于畜生，或生于阎魔罗界，或生于阿修罗，或生于天人之中。前识既已灭去，受生之识生起，受生相续，心的种类不断绝。

【按】“前识既灭生分识生”之“生分”，圣本作“受生分”。

“大王！没有一法从此世到他世而有生灭，见到所作之业以及所受果报，都不失坏，没有作业者，也没有受报者。大王！那最后识灭时，名为属于死之类；若初识生起，名为属于生之类。大王！那最后识生起时无所从来，到它灭时也无所至。其缘生起时也无所从来，灭时也无所至。其业生起时也无所从来，灭时也无所至。死时也无所从来，灭时也无所至。初识生起时也无所从来，灭时也无所至。其生也无所从来，灭时也无所至。为什么呢？因为自性远离。那最后识、最后识的体性空，缘、缘的体性空，业、业的体性空，死、死的体性空，初识、初识的体性空，受、受的体性空，世间、世间的体性空，涅槃、涅槃的体性空，起、起的体性空，坏、坏的体性空。

“大王！像这样，作业与果报都不失坏，没有作业者，没有受报者，只是随顺世俗而有，不是第一义。大王应当知道，一切诸法都是空寂，一切诸法空，这是空解脱门；空无空之相，名为无相解脱门；若无相，便无愿求，名为无愿解脱门。像这样，大王！一切法都具足三解脱门，与空同行，是涅槃的先导之道，远离相，远离愿求。究竟于涅槃界，决定如同法界，周遍虚空边际。大王应当知道，诸根如幻，境界如梦。一切譬喻都应当这样了知。

#### 耳闻恶声：梦亲爱别离喻

“大王！耳闻恶声，便生恶心。大王！如人在梦中与亲爱之人别离，生大苦恼，悲号啼哭，或离开父母、妻子等所爱眷属。此人醒后，忆念梦中亲爱别离、悲哭等事。你认为怎样？梦中所见是真实存在的吗？”王说：“不是的。”佛说：“大王！你认为怎样？此人把所梦执以为真实，这是智慧吗？”王说：“不是的，世尊！为什么呢？梦中所见的亲爱别离毕竟是无，何况悲泣。此人只是白白疲劳，全无真实。”

佛说：“大王！同样，愚痴无闻的凡夫，见闻恶声而生执著，生执著后生起不爱之心，因为不爱而生瞋心，因为生瞋心而造作瞋业，就是身三种、口四种、意三种业。造了那业之后便即谢灭，这业灭了之后，不依于东方而住，也不依于南、西、北方、四维、上下而住。这样的业，乃至临死之时最后识灭，见到先前所作，在心想中显现。大王！此人见后心生忧愁怖惧，自身这一分的业已尽，另一业现前。大王！犹如梦醒后忆念梦中之事。像这样，大王！以最后识为主，以那业为因缘，以这两种缘，在受生的一分之中，识心初起，或生于地狱，或生于畜生，或生于阎魔罗界，或生于阿修罗，或生于天人之中。前识既已灭去，受生之识生起，受生相续，心的种类不断绝。

#### 耳闻舍声：梦闻不了句义声喻

“大王！耳闻舍声，便起舍相。大王！如人在梦中听到不明了句义的声音，此人醒后忆念梦中所听到的声音。你认为怎样？梦中所闻之声是真实存在的吗？”王说：“不是的。”“大王！你认为怎样？此人把所梦执以为真实，这是智慧吗？”王说：“不是的，世尊！为什么呢？梦中毕竟没有声音可得，何况会有了义以及不了义之句。此人只是空自疲劳，全无真实。”

#### 舌尝美味：梦食百味喻

“大王！如人在梦中自身饥渴，得到百味的馔食，随意而食。此人醒后，忆念梦中的百味饮食。你认为怎样？此人所梦的是真的食物吗？”王说：“不是的。”佛说：“大王！你认为怎样？此人把所梦执以为真实，这是智慧吗？”王说：“不是的，世尊！为什么呢？梦中毕竟没有饮食，何况吃它。此人只是白白疲劳，全无真实。”

【按】“是真食不”之“食”，明本作“实”。“无闻凡夫”之“闻”，圣本作“间”。

佛说：“大王！同样，愚痴无闻的凡夫，见到百种食物后心生执著，生执著后起贪乐之心，既贪乐后心生染著，生染著后作染著之业，就是身三种、口四种、意三种业。造了那业之后便即谢灭，这业灭了之后，不依于东方而住，也不依于南、西、北方、四维、上下而住。这样的业，乃至临死之时最后识灭，见到先前所作，在心想中显现。大王！此人见后心生贪乐，自身这一分的业已尽，另一业现前。大王！犹如梦醒后忆念梦中之事。像这样，大王！以最后识为主，以那业为因缘，以这两种缘，在受生的一分之中，识心初起，或生于地狱，或生于畜生，或生于阎魔罗界，或生于阿修罗，或生于天人之中。前识既已灭去，受生之识生起，受生相续，心的种类不断绝。

“大王！没有一法从今世到后世而有生灭，见到所作之业以及所受果报，都不失坏，没有作业者，也没有受报者。大王！那最后识灭时，名为入于死之类；若初识生起，名为入于生之类。大王！那最后识生起时无所从来，到它灭时也无所至。其缘生起时也无所从来，灭时也无所至。其业生起时也无所从来，灭时也无所至。死时也无所从来，灭时也无所至。初识生起时也无所从来，灭时也无所至。其生也无所从来，灭时也无所至。为什么呢？因为自性远离。那最后识、最后识的体性空，缘、缘的体性空，业、业的体性空，死、死的体性空，初识、初识的体性空，受生、受生的体性空，世间、世间的体性空，涅槃、涅槃的体性空，起、起的体性空，坏、坏的体性空。

【按】“后识体性空”之“空”，圣本作“家”。

“大王！像这样，作业与果报都不失坏，没有作业者，没有受报者，只是随顺世俗而有，不是第一义。大王应当知道，一切诸法都是空寂，一切诸法空，这是空解脱门；空无空之相，名为无相解脱门；若无相，便无愿求，名为无愿解脱门。像这样，大王！一切法都具足三解脱门，与空同行，是涅槃的先导之道，远离相，远离愿求。究竟于涅槃界，决定如同法界，周遍虚空边际。大王应当知道，诸根如幻，境界如梦。一切譬喻都应当这样了知。

【按】“虚空际”之“际”，宫本作“界”。

#### 舌根坏喻

“大王！如人在梦中梦见舌根毁坏。此人醒后，忆念梦中舌根毁败。你认为怎样？此人所梦的是真的毁坏吗？”王说：“不是的。”“大王！你认为怎样？此人把所梦执以为真的毁坏，这是智慧吗？”王说：“不是的，世尊！为什么呢？梦中毕竟没有舌根，何况毁坏。此人只是白白疲劳，全无真实。”

佛说：“大王！同样，愚痴无闻的凡夫，见到舌根毁坏心生执著，生执著后生起不爱之心，生不爱后作染著之业，就是身三种、口四种、意三种业。造了那业之后便即谢灭，这业灭了之后，不依于东方而住，也不依于南、西、北方、四维、上下而住。这样的业，乃至临死之时最后识灭，见到先前所作，在心想中显现。大王！此人见后心生怖惧，自身这一分的业已尽，另一业现前。大王！犹如梦醒后忆念梦中之事。像这样，大王！以最后识为主，以那业为因缘，以这两种缘，在受生的一分之中，识心初起，或生于地狱，或生于畜生，或生于阎魔罗界，或生于阿修罗，或生于天人之中。前识既已灭去，受生之识生起，受生相续，心的种类不断绝。
