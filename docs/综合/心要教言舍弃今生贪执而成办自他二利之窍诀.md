# 心要教言：舍弃今生贪执而成办自他二利之窍诀

*华智仁波切 造*

【译注：此篇标题为后世编者所加，早期版本原无标题，今人依内容拟题为"舍弃今生之贪执、成办自他二利之方法教言"（'di snang gi zhen pa spangs nas don gnyis sgrub tshul gdams pa）。】

顶礼上师！

```
གང་ལ་བརྟེན་ན་ཉེས་ཚོགས་ཀུན་འཇོམས་ཤིང་། །
དགེ་ལེགས་ཡོན་ཏན་རྒྱ་མཚོ་འབྱུང་བའི་གཞི། །
སྐྱབས་གསུམ་ཀུན་འདུས་ངོ་བོ་ཆོས་ཀྱི་རྗེ། །
ཡོངས་འཛིན་དགེ་བའི་བཤེས་གཉེན་ལ་བཏུད་ནས། །
```
依止之则能摧灭一切罪恶，是善妙功德大海得以涌现的根本，三皈依处之总集、法之至尊——顶礼这样一位摄受、教养我的善知识！

```
ཐུབ་དབང་ཆོས་ཀྱི་ཉི་མ་སྐྱེ་དགུའི་མིག །
སྐྱོབས་པ་དེ་ཡི་བཀའ་དང་རྗེས་འབྲེལ་བའི། །
ཕན་པའི་ངག་འདི་ཁྱོད་ལ་གསོལ་བགྱིད་ན། །
རང་ལ་བརྩེ་བས་ཡིད་ལ་བཅག་པར་ཞུ། །
```
如今我要向你说这样一番有益的话——它与能仁佛陀、法之日轮、众生眼目——那位怙主的教诲一脉相承。若你真正爱惜自己，就请务必将它牢记于心。

```
སྲིད་པའི་བདེ་འབྱོར་གཡོ་བའི་ཟློས་གར་མཁན། །
འདི་གཅིག་ཁོ་ནས་སྔར་ཡང་འགྲོ་རྣམས་བསླུས། །
ཚེ་གང་འགྲོགས་ཀྱང་འཆི་བའི་ཤུལ་ལམ་དུ། །
ཞུགས་པའི་ཚེ་ན་བདག་ཉིད་གཅིག་པུར་འདོད། །
```
轮回中变幻无常的安乐富贵，如同一场戏耍表演——单单是这一场戏，从古至今就已经欺骗了无数众生。无论此生与什么相伴相依，一旦踏上死亡之路，终究是自己孤身一人独自前行。

```
གཏམ་སྙན་གྲགས་པ་བྱེ་མའི་ཁང་བུ་འདྲ། །
སྒྲུབ་དཀའ་འཇིག་སླ་བྱིས་པ་བསླུ་བའི་ཆོས། །
ཤ་ཐང་ཆད་པར་འབད་པས་བསྒྲུབ་གྱུར་ཀྱང་། །
ནམ་ཞིག་ཙ་ན་སྒྱུ་མའི་རང་མཚང་ངོམ། །
```
美名与声誉，就如同沙筑的城堡一般，建造艰难，却又极易坍塌，是专门用来欺骗愚童的把戏。纵然精疲力竭、费尽千辛万苦去成就它，终有一天，它如幻的本来面目，也必将自行败露无遗。

```
དུས་ངན་མཛའ་བཤེས་ཇི་ལྟར་བཀུར་ན་ཡང་། །
རང་གི་བསམ་བཞིན་ཁོང་རྣམས་མགུ་བར་དཀའ། །
བཟང་བྱས་མི་ཚོར་ཅུང་ཟད་ཙམ་གྱིས་ཀྱང་། །
ངན་རྐྱེན་མི་ཤོང་ཁྲོ་བའི་རྣམ་འགྱུར་སྟོན། །
```
在这样恶劣的时代，无论你如何尊敬、款待你的亲友，也很难真正如你所愿地让他们心生欢喜。你待他们的种种好处，他们往往浑然不觉；反倒是稍有一点点不顺心的逆缘，便立刻显露出难以忍受的、愤怒不悦的神情。

```
བྱམས་པའི་འཛུམ་དང་སྙན་པའི་གཏམ་གྱིས་ཀྱང་། །
མཁོ་བའི་ཡོ་བྱད་དག་གིས་བསྙེན་བཀུར་ཡང་། །
རང་ཉིད་དབུལ་ཚེ་རུལ་བའི་རོ་བཞིན་དུ། །
འདོར་བའི་གྲོགས་ལ་སུ་ཞིག་ཡིད་རྟོན་བྱེད། །
```
纵然你以慈爱的笑容、悦耳的言辞相待，供给他们一切所需的用度，加以款待承事——可一旦自己落魄贫穷之时，他们便会像抛弃一具腐烂的尸体一般，将你彻底抛弃。像这样的朋友，又有谁能真正信赖依靠呢？

```
སྡིག་ལ་འཛེམ་མེད་སྡུག་བསྔལ་ཁྱད་དུ་བསད། །
རྒྱ་དབུས་ས་མཐའ་སྲོག་དང་བརྡོས་ནས་ཀྱང་། །
འབད་དེ་བསྐོར་ཞིང་བསོགས་པའི་ནོར་ཅན་འགའ། །
ཕལ་ཆེར་ལྟོག་གྲིར་ཤི་བ་མཐོང་ལགས་སམ། །
```
你可曾见过：那些丝毫不畏惧造罪、把千辛万苦全都不放在眼里、不惜以性命为赌注，往返于汉地与卫藏边远之地，历经种种艰难辛苦、四处奔波敛聚财富的富人，最终，其中大多数，不是死于饥饿，便是死于刀兵之下？

```
ཡར་ལ་དཀོན་མཆོག་མཆོད་པ་འབུལ་མ་བྲ། །
མར་ལ་ངན་སློང་རྣམས་ལ་སྦྱིན་མ་སྤོབས། །
བར་དུ་རང་གིའང་སྤྱོད་པར་མ་ནུས་པའི། །
སེར་སྣས་བཅིང་བའི་ཟས་ནོར་ཕལ་ཆེར་ཞིག །
```
向上，舍不得将其供养三宝；向下，也没有胆量施舍给贫苦的乞丐；居中，就连自己也不曾真正受用享有——这些被吝啬悭贪牢牢捆缚住的绝大多数衣食财物，

```
ཤི་བའི་ཚེ་ན་དོན་མེད་མི་རྣམས་ཀྱིས། །
འཐབ་རྩོད་གཡོ་རྒྱུ་སྣ་ཚོགས་ཐབས་མང་པོས། །
རང་གར་ཁྱེར་ན་སྡིག་དང་རྣམ་སྨིན་དག །
ཁོ་ལ་བཞག་ནས་སོང་བ་གཟིགས་ལགས་སམ། །
```
一旦你死去，这些与你毫无关系的人，便会争斗不休、施展种种狡诈的手段，将它们各自据为己有、掳掠一空——而所造下的罪业及其异熟果报，却全都留给了你自己一人承担、独自带走。这样的情形，你难道不曾亲眼见过吗？

```
སྤྱིར་ན་འདུས་བྱས་ཆོས་ལ་ཡིད་མི་རྟོན། །
ཁྱད་པར་དེང་སང་སྙིགས་མའི་སྐབས་འདིར་ནི། །
ཕས་ཀྱང་བུ་ལ་ཡིད་ཆེས་མི་ནུས་ཤིང་། །
གྲོགས་ཀྱི་དངས་མ་དགྲ་ཡི་རྩེ་མོར་འགྲོ། །
```
总而言之，一切有为之法，都不值得信赖依靠；尤其是在如今这五浊恶世之中，就连父亲也无法完全信任自己的儿子，最要好的挚友，转眼也会变成最凶恶的仇敌之首。

```
ཁར་སང་བཤད་པ་དེ་རིང་བརྫུན་དུ་འགྱུར། །
གསང་ཚིག་བཅོལ་ན་རྒྱལ་ཁམས་ཡོངས་ལ་འཆད། །
ངོས་ལ་བསྟོད་ཅིང་ལྐོག་ཏུ་མི་སྙན་སྨྲ། །
ཕན་པའི་སྙིང་གཏམ་སྨྲས་ན་རྣ་བ་གཟེན། །
```
昨天说过的话，今天就变成了谎言；把秘密托付给他，他转眼就传遍了举国上下；当面对你极尽赞美，背地里却尽说你的是非坏话；纵使你出于好意、诚心诚意地劝说忠告，他也会掩耳不听，心生反感。

```
ཀྱེ་མ་དུས་ངན་སྐྱེ་བོ་ཆོ་རིགས་ངན། །
འདི་འདྲའི་ངོ་འཛིན་བྱེད་པ་ཤིན་ཏུ་འཁྲུལ། །
མི་སེམས་བཟུང་བས་མི་ཟིན་ཞོག་ལ་ཐོང་། །
བློ་སྙིང་བླ་མར་གཏོད་དང་དེ་ཀ་རང་། །
```
唉，在这样的恶劣时代，与这般行止低劣、种性败坏之人还想着要建立、维系情谊，实在是大错特错、极其愚痴的想法。人心是无法真正把握、拿捏得住的，索性放下它、随它去吧！唯有将自己的身心，全然交托给上师——除此之外，别无他法。

```
དེང་སང་དུས་ཀྱི་བཤེས་གཉེན་ཕལ་པ་འགའ། །
བཙན་ཕྱུག་གོལ་ས་མཐོན་པོའི་མི་ལ་དགའ། །
གདམས་ངག་ཞུ་འདོད་མེད་ཀྱང་ངས་སྦྱིན་ཟེར། །
ཆོས་ཀྱི་ཕྱག་རྟེན་ཐོགས་ནས་རྗེས་ལ་སྙོགས། །
```
然而，如今这个时代里，有一些寻常的所谓"善知识"，却只喜欢趋附权贵富豪、地位显赫之人。人家根本没有请求传授窍诀，他却主动说"我来传给你"，甚至捧着法本，反过来追着别人、巴巴地跟随在后面。

```
དད་གསུམ་ལྡན་ཀྱང་འབྱོར་པས་མ་ཆོག་ན། །
ཆོས་སྦྱིན་ལྟ་ཅི་ཞལ་འཛུམ་དཀར་ཙམ་ཡང་། །
སྟོན་པའི་གོ་སྐབས་སྤྲིན་བར་ཉི་ཞུར་འདྲ། །
འདི་འདྲར་སེམས་དང་སྐྱོ་བ་མི་འཕེལ་ལམ། །
```
而对于虽具足三种信心【译注：即明净信、欲乐信、胜解信】，却财力不足的求法者，别说赐予正法了，就连露出一丝笑容的机会，也如同乌云密布中偶现的一线阳光那般难得一见。见到这般情形，难道不会令人心生悲哀、生起厌离之情吗？

```
ཆོས་འདོད་ཡིན་ཟེར་གཡོན་པོའི་བསམ་སྦྱོར་ཅན། །
དད་པ་མེད་པའི་ཕྱག་གིས་ཐལ་ཚུབས་སློང་། །
མོས་གུས་མེད་པའི་ཁམས་འདྲི་སྙུན་ཞུ་གསོལ། །
ངན་སྤྱོད་རྟོག་པའི་མིག་གིས་བྱ་ར་བྱེད། །
```
而另有一些人，口口声声说自己渴求正法，居心却早已扭曲不正——他们毫无信心地顶礼叩拜，不过是徒然扬起满地尘土；毫无恭敬之心地嘘寒问暖、探病问安，双眼却时刻紧盯着上师，暗中窥探、伺机搜寻他行止上可能存在的过失。

```
ཆོས་མཐོང་སྤུ་ཙམ་མེད་བཞིན་བླ་མ་བསྐུར། །
གཡོ་སྒྱུའི་སྤྱོད་པའི་དགྱེ་རྒུ་ཀྱང་ཀྱོག་བྱེད། །
མདོ་སྔགས་སྤྱི་བཤད་ཙམ་གྱིས་མི་ཆོག་པར། །
བསྐྱེད་རྫོགས་བསྒོམ་ཁྲིད་རྫོགས་ཆེན་ཞུ་དོ་སྐད། །
```
明明连一根毫毛尖那么微小的功德也未曾在这位上师身上见到，却依人依止，还大加吹捧奉承；即便面对这般虚伪狡诈的行径，也曲意逢迎、加以美化。他们不满足于只听闻显密教法的泛泛概说，反而一再要求传授生起次第、圆满次第的实修引导，乃至大圆满的窍诀。
