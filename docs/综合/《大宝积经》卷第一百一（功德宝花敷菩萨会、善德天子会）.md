# 《大宝积经》卷第一百一（功德宝花敷菩萨会、善德天子会）

唐·三藏菩提流志 奉诏译

## 功德宝花敷菩萨会第三十四

【按】译者题名，明本无“大”字，“三藏”作“三藏法师”。本会未见汉译异本。

#### 功德花菩萨请问

如是我闻：一时，佛在王舍城耆阇崛山，与大比丘众一千二百五十人在一起，又有无量诸菩萨众。那时会中有一位菩萨，名为开敷功德宝花，便从座起，偏袒右肩，右膝著地，合掌向佛这样说：“世尊！我想向如来请问，唯愿哀愍，垂允听许。”佛告诉功德花菩萨说：“善男子！任你所问，当为你说。”那时功德花菩萨对佛说：“世尊！十方世界中，有没有现在的诸佛如来，若善男子、善女人等受持其名号，便能迅速证得阿耨多罗三藐三菩提？”佛说：“善哉善哉。功德花！你现在为了利益安乐天人世间以及未来世的诸菩萨等，向如来问这样的义理。谛听谛听，好好思念，当为你说。”功德花说：“是的，世尊！愿乐欲闻。”

#### 东方

那时佛告诉功德花菩萨说：“善男子！东方有一个世界，名为一切法功德庄严，劫名普集一切利益。那里现有佛，号为无量功德宝庄严威德王如来，寿命无数。那佛的众会无量无边，都是清净的大菩萨。若有具清净信心的善男子、善女人受持那佛的名号，便能灭除六十千劫的生死之罪，转身之后得陀罗尼，名为乐说无碍。凡所说法，常有十俱胝佛刹的诸佛世尊授予辩才，令其无畏。”那时世尊说偈道：

```
若人受持彼佛名，
当获如是诸功德，
亦能成就余胜法，
速证无上佛菩提。
```
（大意：若人受持那佛的名号，当获得这样的种种功德，也能成就其余殊胜之法，迅速证得无上的佛菩提。）

#### 南方

“再者，功德花！南方有一个世界，名为功德宝庄严，劫名广大功德。那里现有佛，号为功德宝胜庄严威德王如来。若有具清净信心的善男子、善女人受持那佛的名号，转身之后当得日轮光明遍照三昧，在诸佛刹中随愿往生，也当摄受无量功德庄严的佛土。生到那佛刹之后，具足三十二相，获得无断的辩才，转身之后当得阿耨多罗三藐三菩提。”那时世尊说偈道：

【按】“无断辩才”之“断”，元、明本作“碍”。

```
若人受持彼佛名，
转身当得难思定，
三十二相以庄严，
一生当证菩提果。
```
（大意：若人受持那佛的名号，转身之后当得难以思议的定，以三十二相来庄严，一生之中当证菩提之果。）

#### 西方

“再者，功德花！西方有一个世界，名为离一切忧暗，劫名能胜王。那里现有佛，号为一切法殊胜辩才庄严如来。若有具清净信心的善男子、善女人受持那佛的名号，毒不能害，刀不能伤，火不能烧，水不能溺。舍弃此身之后，当受化生，获得陀罗尼，名为百旋。”那时世尊说偈道：

```
若人受持彼佛名，
水火刀毒无能害，
转身当受化生报，
成就百旋陀罗尼。
```
（大意：若人受持那佛的名号，水、火、刀、毒都不能加害，转身之后当受化生的果报，成就百旋陀罗尼。）

#### 北方

“再者，功德花！北方有一个世界，名为离尘暗，劫名持大名称。那里现有佛，号为积集无量辩才智慧如来。若有具清净信心的善男子、善女人受持那佛的名号，便是奉事了六十俱胝那由他佛，得遍一切处陀罗尼、无尽藏陀罗尼。乃至未成无上菩提之前，终不再入三恶趣中，常得往生诸佛刹土，修菩萨行，度脱无量恶趣众生，当对阿耨多罗三藐三菩提得不退转。”那时世尊说偈道：

【按】“积集无量辩才智慧如来”之“积”，宫本作“称”。

```
若人受持彼佛名，
所获功德无有边，
决定当得陀罗尼，
成就无上菩提果。
```
（大意：若人受持那佛的名号，所获得的功德无有边际，决定当得陀罗尼，成就无上菩提之果。）

#### 东南方

“再者，功德花！东南方有一个世界，名为胜妙庄严，劫名出生功德。那里现有佛，号为千云雷吼声王如来。若有具清净信心的善男子、善女人受持那佛的名号，转身之后得佛的四无所畏、四种神足、大慈大悲、十八不共法。所得国土的功德庄严，也如西方极乐世界，没有不同。若有女人能受持，都转为男子之身。”那时世尊说偈道：

【按】“千云雷吼声王如来”之“雷”，宫本作“电”。

```
若人受持彼佛名，
获不思议胜功德，
彼常见于无量佛，
女人当得丈夫身。
```
（大意：若人受持那佛的名号，获得不可思议的殊胜功德，他常见到无量的佛，女人当得男子之身。）

#### 西南方

“再者，功德花！西南方有一个世界，名为无量庄严，劫名能生妙法。那里现有佛，号为最上妙色殊胜光明如来。若有具清净信心的善男子、善女人受持那佛的名号，便是奉事了九十俱胝诸佛如来，得度脱一切众生三昧。为什么名为度脱一切众生三昧？若善男子、善女人依这三昧演说法时，能令三千大千世界中的恶趣众生都得解脱，得生人天，普获安乐，决定当得阿耨多罗三藐三菩提。犹如悦意如来佛刹中的所有众生，常受安乐。”那时世尊说偈道：

```
若人受持彼佛名，
所生常具大威德，
诸根色力皆殊胜，
智慧无边无所著。
```
（大意：若人受持那佛的名号，所生之处常具大威德，诸根、色身、力量都殊胜，智慧无边而无所执著。）

#### 西北方

“再者，功德花！西北方有一个世界，名为离垢，劫名广族。那里现有佛，号为种种胜光明威德王如来。若有具清净信心的善男子、善女人受持那佛的名号，转身之后得无量辩才庄严陀罗尼，都能受持八十俱胝如来所说之法。所得国土的功德庄严，也如西方极乐世界，没有不同。”那时世尊说偈道：

```
若人受持彼佛名，
国土犹如无量寿，
成就甚深诸法智，
一生当证佛菩提。
```
（大意：若人受持那佛的名号，国土犹如无量寿佛的国土，成就甚深诸法之智，一生之中当证佛菩提。）

#### 东北方

“再者，功德花！东北方有一个世界，名为无忧，劫名辩才庄严。那里现有佛，号为无数劫积集菩提如来。若有具清净信心的善男子、善女人受持那佛的名号，便是供养了八十俱胝诸佛世尊，转身之后具足六十种言音辩才。”那时世尊说偈道：

```
若人受持彼佛名，
智慧无边到彼岸，
如供八十俱胝佛，
转生当证妙辩才。
```
（大意：若人受持那佛的名号，智慧无边，到达彼岸，如同供养八十俱胝佛，转生之后当证得美妙的辩才。）

#### 上方

“再者，功德花！上方有一个世界，名为无量功德庄严威德，劫名无量吼声。那里现有佛，号为虚空吼声净妙庄严光明照如来。若有具清净信心的善男子、善女人受持那佛的名号，所生之处种族尊豪，识性聪慧，善能通达世俗文词，凡所发言人们都信受。在诸地之中，具足清净的戒、定、智慧以及解脱知见，获得宿命智，得五神通，也当得佛的十八不共法，迅速成就阿耨多罗三藐三菩提。”那时世尊说偈道：

【按】“及于解脱知见”之“及于”，宋、元、明本作“解脱”。

```
若人受持彼佛名，
所生未曾离诸佛，
具足八种梵音声，
速证无上菩提果。
```
（大意：若人受持那佛的名号，所生之处未曾离开诸佛，具足八种梵音声，迅速证得无上菩提之果。）

#### 下方

“再者，功德花！下方有一个世界，名为种种音声，劫名积集智慧。那里现有佛，号为一切法门神变威德光明照耀如来。若有具清净信心的善男子、善女人受持那佛的名号，转身之后得陀罗尼，名为成就正觉，当能受持九十俱胝诸佛如来所说之法，一生之中当得阿耨多罗三藐三菩提。”那时世尊说偈道：

```
若人受持彼佛名，
得成正觉陀罗尼，
受持无量诸佛法，
一生当证大菩提。
```
（大意：若人受持那佛的名号，得成正觉陀罗尼，受持无量诸佛之法，一生之中当证大菩提。）

#### 流通

那时开敷功德宝花菩萨以及一切功德辩才音菩萨得陀罗尼门。八万俱胝菩萨都趣向无上菩提，得不退转。三那由他诸天以及人发阿耨多罗三藐三菩提心。佛说此经之后，功德花菩萨以及一切世间的天、人、阿修罗、乾闼婆等，听闻佛所说，都大欢喜，信受奉行。

## 善德天子会第三十五

唐·三藏菩提流志 奉诏译

【按】会题前“大宝积经”四字，以及译者题名一行，明本无。本会异译有菩提流志译《佛说文殊师利所说不思议佛境界经》（T0340）。

#### 佛境界即非境界

如是我闻：一时，佛在舍卫国祇树给孤独园，与大比丘众一千人、菩萨摩诃萨一万人以及欲界、色界诸天子等在一起。当时文殊师利菩萨摩诃萨与善德天子都在会中。那时世尊告诉文殊师利：“你应当为这诸天大众以及诸菩萨演说诸佛甚深的境界。”文殊师利对佛说：“是的，世尊！若善男子、善女人想知道佛的境界，应当知道它不是眼、耳、鼻、舌、身、意的境界，不是色、声、香、味、触、法的境界。世尊！非境界就是佛的境界。由于这个道理，如佛所得的阿耨多罗三藐三菩提，是什么境界呢？”佛说：“是空的境界，因为诸见平等。是无相的境界，因为一切相平等。是无愿的境界，因为三界平等。是无作的境界，因为有作平等。是无为的境界，因为有为平等。”

文殊师利说：“世尊！什么是无为的境界？”佛说：“无念是无为的境界。”文殊师利说：“世尊！若无为等是佛的境界，无念的人依什么而说？因为无所依，便无所说；因为无所说，便不可说。世尊！诸佛的境界是不可说的。”

#### 于烦恼中求佛境界

佛说：“文殊师利！佛的境界应当在哪里求？”答：“在一切众生的烦恼中求。为什么呢？众生烦恼之性不可得，不是声闻、缘觉所能知，这便名为诸佛的境界。”佛说：“文殊师利！佛的境界有增减吗？”答：“没有增减。”佛说：“怎样了知一切众生烦恼的本性？”答：“如佛的境界没有增减，烦恼的本性也没有增减。”佛说：“什么名为烦恼的本性？”答：“烦恼的本性就是佛界的本性。世尊！若烦恼之性异于佛的境界，便不能说佛住于一切法的平等性中。因为烦恼之性就是佛界之性，所以说如来住于平等性。”

又问：“你见如来住于什么平等？”答：“依我的理解，众生现行贪、瞋、痴时所住的平等，就是如来所住的。”佛说：“众生现行三毒烦恼，住于什么平等？”答：“住于空、无相、无愿的平等性中。”佛说：“文殊！在那性空之中，怎么又有贪、瞋、痴？”文殊师利说：“在那有之中，有性空之处，有贪、瞋、痴。”佛说：“在什么有之中说有性空？”答：“在文字语言之中说有性空。因为有性空，所以有贪、瞋、痴。如佛所说：诸比丘，有无生、无为、无作、无起。若无生、无为、无作、无起不存在，也不可说有生、有为、有作、有起。所以比丘，因为有无生以及无所起，由此才得说有生、有起。像这样，世尊！若没有性空、无相、无愿，便不可说贪、瞋、痴等一切诸见。”

【按】“无相无愿”之“无”，宋、元、明、宫本无。

佛说：“文殊师利！由于这个道理，如你所说，住于烦恼的人就是住于性空。”文殊师利说：“世尊！若观行的人离开烦恼而求性空，便不相应。怎么会另有一个性空异于烦恼？若观察烦恼即是性空，才是正修行。”

#### 不离烦恼，不住烦恼

佛说：“文殊师利！你是住于烦恼，还是离开烦恼？”文殊师利说：“所有的烦恼都平等。这样的平等，我正修行而入于这平等，便不离烦恼，也不住烦恼。若沙门、婆罗门自以为离欲，见他人有烦恼，他便随于二见。哪二见？认为有烦恼，名为常见；认为无烦恼，名为断见。世尊！正修行的人不见自他有无之相。为什么呢？因为明了一切法。”

佛说：“文殊师利！依什么正修行？”答：“正修行的人无所依。”佛说：“不依于道而修行吗？”答：“若有所依而修行，便是有为；若行有为，便不是平等。为什么呢？因为不离生、住、坏。”佛说：“文殊师利！无为之中可有数量吗？”文殊师利说：“世尊！若无为有数量，便是有为，不是无为。”佛说：“若圣者证得无为，便有此法，怎么会没有数量？”答：“因为法无数量，圣者远离数量，所以是无数量。”

#### 化人无证与不证

佛说：“文殊！你证得圣法了吗？还是没有证得？”文殊师利说：“世尊！若问化人：‘你证得圣法了吗？还是没有证得？’他会怎样回答？”佛说：“文殊！化人不可说有证或非证。”文殊师利说：“佛难道没说一切诸法都如化吗？”佛说：“是这样，是这样。”答：“若一切法都如化，为什么问‘你证得圣法了吗，还是没有证得’？”佛说：“文殊！你在三乘中证得什么平等？”答：“佛界平等，我这样证得。”佛说：“你得到佛的境界了吗？”答：“若世尊得到，我也当得到。”

#### 须菩提问难：说法、三乘、住地

那时尊者须菩提对文殊师利说：“如来没有得到佛的境界吗？”文殊师利说：“你对声闻的境界有所得吗？”须菩提说：“圣者的解脱，非得也非不得。”答：“是这样，是这样。如来的解脱，也非有境界、非无境界。”

须菩提说：“文殊师利！你说法时不护念新发意的菩萨。”文殊师利说：“须菩提！你认为怎样？若有医生护念病人，不给他辛、酸、苦、涩等药。那医生对那病人，是令他痊愈，还是令他死去？”须菩提说：“是给他死苦，不是施予安乐。”文殊师利说：“说法的人也是这样。若护念他人，恐怕他生起惊怖，隐覆这样甚深的义理，只以杂乱的语句、绮丽的文辞而为之演说，便是授予众生老、病、死之苦，不给予无病安乐的涅槃。”宣说此法时，五百比丘不受诸法，漏尽意解。八千天人远尘离垢，在诸法中得法眼净。七百天子发阿耨多罗三藐三菩提心，这样发愿说：“我们在未来世当如文殊师利，得这样的辩才。”

【按】“远尘离垢”，元、明本作“远离尘垢”。

那时长老须菩提对文殊师利说：“你难道不以声闻乘之法为声闻说吗？”答：“一切乘之法都是我所乘的。”须菩提说：“你是声闻，还是辟支佛，还是应正等觉？”答：“我是声闻，因为不是由他人的声音而生起理解。我是辟支佛，因为不舍大悲，无所畏惧。我是应正等觉，因为不舍本愿。”须菩提说：“你怎样作声闻？”答：“那些众生未曾闻法，令他们得以听闻，所以我是声闻。”又问：“你怎样作辟支佛？”答：“令众生对法界信解觉悟，所以说我是辟支佛。”又问：“你怎样作应正等觉？”答：“对一切诸法法界平等这样了知，所以我是应正等觉。”

须菩提说：“文殊师利！你决定住于哪一地？”答：“住于一切地。”须菩提说：“你难道也住于凡夫地吗？”文殊师利说：“我也决定住于凡夫地。”须菩提说：“你以什么密意这样说？”答：“因为一切诸法自性平等，所以这样说。”须菩提说：“若一切法都平等，应当在哪里建立诸法——这是声闻地、辟支佛地、菩萨地、佛地呢？”文殊师利说：“譬如在十方虚空界中，说这是东方的虚空，南、西、北方、四维、上下也这样说。这样的言说有种种差别，并不是虚空本身有差异。所以仁者！依于一切法毕竟空之中，建立种种诸地之相，也不是空性有差别。”

#### 入正性离生而复出：射师之喻

须菩提说：“文殊师利！你已证入正性离生了吗？”答：“我已证入，而又出来了。”须菩提说：“怎么证入而又出来？”文殊师利说：“仁者应当知道，这是菩萨的智慧方便。对正性离生如实证入，以方便而出。须菩提！譬如有人善于射术，有一个怨敌，他想杀害他。射师有一个儿子，怜爱甚重。当时那爱子在旷野中，他的父亲误以为是所怨恨的仇人，放箭射他。儿子便大声呼喊：‘我没有过错，为什么要害我？’当时那射师有迅疾之力，急速赶到儿子那里，夺回那支箭。菩萨也是这样，为了调伏声闻、辟支佛，所以入于正位，又从那里出来，不堕于声闻、辟支佛地。由于这个道理，名为佛地。”

【按】“我无咎”之“咎”，宫本作“过咎”。

须菩提说：“菩萨怎样得到此地？”文殊师利说：“若诸菩萨住于一切地而无所住，便得此地。若对一切地都能演说，而不住于下劣之地，便得此地。若有修行是为了尽除一切众生的烦恼，而法界无尽，虽住于无为而行于有为，在生死中作园林观赏之想而不求涅槃，便得此地。所有的志愿都令圆满，得无我之忍，成熟众生，便得此地。得到佛的智慧，而对无智之人不生瞋恨之心，便得此地。为求法的人转法轮，而对法界也没有差别，这样修行便得此地。再者，若诸菩萨摧伏魔怨，而示现作四魔，便得此地。”

【按】“而现作四魔”之“现”，宫本作“见”。

#### 超过世间

须菩提说：“文殊师利！这菩萨行，一切世间甚难相信。”文殊师利说：“是这样，是这样，如你所说。这些菩萨行于世间而超过世间之法。”须菩提说：“文殊师利！请为我们宣说这超过世间。”

文殊师利说：“所说的世间，名为五蕴。在这五蕴中，色是聚沫之性，受是水泡之性，想是阳焰之性，行是芭蕉之性，识是幻化之性，这样应当知道世间的本性是聚沫、阳焰、水泡、幻化、芭蕉，其中没有蕴，也没有蕴的名字，没有众生，也没有众生的名字，没有世间，也没有超过世间。若对五蕴这样正知，名为胜解；若正确胜解，便本来解脱；若本来解脱，便不执著世间法；若不执著世间法，便超过世间。

【按】“夫世间者”之“夫”，宫本作“未”。“泡”，宫本作“抱”。“无蕴无蕴名字”，宋、元、宫本作“无蕴无蕴无蕴名字”。

“再者，须菩提！五蕴本性是空，若本性是空，便没有我与我所；若没有我与我所，便是无二；若本来无二，便没有取舍；因为没有取舍，便无所执著；因为无所执著，便超过世间。再者，须菩提！这五蕴属于因缘，若属于因缘，便不属于我，不属于众生；若不属于我、不属于众生，便是无主；无主便无所取，无所取便无诤，无诤论是沙门之法，如以手画虚空，没有触碍。这样修行空的平等性，便超过世间。再者，须菩提！五蕴法界同入于法界，便是无界；若是无界，便没有地界、水火风界，没有我、没有众生、没有寿命，没有欲界以及色界、无色界，没有有为、无为、生死、涅槃之界。入于这界之后，便与世间同在而无所住；若无所住，便超过世间。”

#### 二百比丘解说圣谛义

宣说这超过世间之法时，二百比丘不受诸法，漏尽意解，各自脱下郁多罗僧衣覆在文殊师利身上，这样说：“若不对这法门生起信解，他便无所得，也无所证。”那时须菩提告诉那些比丘说：“长老！你们稍有所得、有所证吗？”比丘们说：“若是增上慢的人，便可以说有得有证；没有增上慢的沙门之法，无得无证。他在什么地方生起这动念，而自己说：‘我这样得，我这样证。’若在其中有动念，便是魔业。”

须菩提说：“长老！依你们的理解，得了什么、证了什么而这样说？”比丘们说：“只有佛世尊以及文殊师利知道我们所得、知道我们所证。大德！依我们的理解，若不了知苦相，而这样说‘苦是我应当知的’，是增上慢。像这样，说‘集应当断、灭应当证、道应当修’，是增上慢。因为他们不了知苦、集、灭、道之相。这样说，乃至说‘道我已修’，是增上慢。什么是苦相？就是无生之相。像这样，集、灭、道之相若是无生之相，便是无相、无所得。其中没有少许苦可知、集可断、灭可证、道可修。若对这所说的圣谛之义不惊、不怖、不畏，便不是增上慢；若生惊怖，便是增上慢。”

那时世尊赞叹那些比丘说：“善哉善哉。”告诉须菩提：“这些比丘在迦叶佛的法中曾听闻文殊师利演说这样甚深之法。这些比丘往昔修行这深法，现在听闻便随顺而迅速了知。这样次第，在我的法中听闻这深法而生信解的人，将来都当在弥勒的法中入于圣众之数。”

#### 文殊现神变：众会自见入兜率天

那时善德天子对文殊师利说：“仁者在这阎浮提中屡屡说法，我们愿请仁者前往兜率陀天。那些天子也有久种的广大善根，他们若听闻法，便应能理解。因为执著于快乐，不能来到佛所听法，而自我损减。”那时文殊师利便现神变，令善德天子以及一切众会都自以为进入兜率陀天宫，见到那里的园林、宫殿、楼观、栏楯、窗牖，交错庄严。那些宝台层级高广，达到二十重，众宝网幔，天花遍布，种种异类之鸟翔集和鸣。虚空中有诸天女散曼陀罗花，歌咏赞叹，游戏快乐。善德天子见到这些之后，对文殊师利说：“希有，文殊！为什么我们这样迅速已到了兜率陀天宫，见到这园林以及诸天众？愿文殊师利为我们说法。”

那时长老须菩提告诉善德说：“天子！你并没有离开会中而前往别处，这是文殊师利的神通变化，令你自己见到进入兜率天宫。”那时善德天子对佛说：“希有，世尊！文殊师利的游戏三昧与神通变化，在一刹那间示现这会众都进入兜率天宫。”佛说：“天子！你对文殊师利的神通变化难道见到了吗？依我所知，文殊师利若想把恒河沙等诸佛刹土的功德庄严聚集在一佛国中，都能示现。或者以指端举起恒河沙诸佛刹土，越过上方如恒河沙的诸佛土之后，放在虚空之中；又把诸佛刹所有的四大海水纳入一个毛孔，水性众生也不觉得逼迫狭窄，都自见没有离开海中。把所有世界的诸须弥山王都放在芥子之内，依须弥山而住的诸天子等都自以为在自己本来的宫殿。又把诸佛刹所有五道众生都安置在他的掌中，以种种美妙的资具，犹如一切乐庄严国土，都令其得见。又把诸世界所有的火聚都放在一兜罗绵中。再者，诸佛世界所有的日月，在一个毛孔中都能遮蔽。随其所应作的，都能作到。”

#### 恶魔请见神变，誓护法门，说咒

#### 文殊往兜率天说法

那时文殊师利告诉善德天子说：“善男子！你前往兜率陀天，普遍告诉天众，我当到那里去。”当时善德天子听了这话，礼世尊足以及诸菩萨、大德声闻，与他的眷属恭敬围绕，在众会面前忽然不现，片刻之间已到了兜率陀天。那时善德普遍告诉诸天子说：“你们应当知道，文殊师利怜愍你们，想到这里来。你们应当舍弃种种欲乐，远离憍慢，恭敬尊重，随顺听法。”那时善德天子如所应当办的庄严道场，便合掌这样说：“文殊师利！现在正是时候。”

【按】“遍告天众”之“众”，宋、元、明、宫本作“众言”。

于是文殊师利与一万菩萨、五百声闻，以及天、龙、夜叉、乾闼婆等前后围绕，礼佛足之后，从会中隐没，出现在兜率陀天，与诸菩萨、声闻大众在那道场中随所敷设而坐。当时大众都听到四天王宫、三十三天、夜摩、兜率以及化乐、他化自在诸天子等，魔众、梵众，乃至有顶天，互相唱说：“文殊师利现在在兜率陀天，正要说法。”诸天听了，无数百千都来集会，整个欲界天宫都容纳不下。当时文殊师利便以神力，令那些诸天自见宽广，互不妨碍。那时善德天子对文殊师利说：“大众已经集会，愿为我们说法。”

#### 四法与八法

文殊师利告诉善德天子说：“有四种法，菩萨住于不放逸，便能摄取一切佛法。哪四种？一是住于戒律而具足多闻，二是住于禅定而行智慧，三是住于神通而起大智，四是住于寂静而常观察。

“天子！有八种法入于戒律。哪八种？一是身清净，二是语清净，三是意清净，四是见清净，五是头陀功德清净，六是命清净，七是舍离一切诈现异相、以利求利的清净，八是不舍一切智心的清净。这名为入于戒律的八法。

“天子！又有八法入于多闻。哪八种？一是尊重，二是谦下其心，三是发起精进，四是不失正念，五是随所闻而受持，六是心善于观察，七是如所闻而转教他人，八是不自赞毁他。这名为入于多闻的八法。

“天子！又有八法入于禅定。哪八种？一是寂静地住在阿兰若，二是舍离喧闹，三是不染著境界，四是身心轻安，五是心缘于定境，六是断绝种种声相，七是减少饮食以维持身体，八是不取著圣者之乐。这名为入于禅定的八法。

“天子！又有八法入于智慧。哪八种？一是对蕴善巧，二是对界善巧，三是对处善巧，四是对缘起善巧，五是对谛善巧，六是对三世善巧，七是对一切乘善巧，八是对一切佛法善巧。这名为入于智慧的八法。

“天子！又有八法入于神通。哪八种？一是天眼通，因为见无障碍；二是天耳通，因为闻无障碍；三是他心通，因为观察一切众生之心；四是宿命通，因为忆念前际；五是神足通，因为示现一切神变；六是漏尽通，因为尽除一切众生的漏；七是不住于烦恼、不取于解脱，因为有方便之力；八是不依声闻的解脱而入涅槃。这名为入于神通的八法。

“又有八法能入于智。哪八种？一是苦智，二是集智，三是灭智，四是道智，五是因智，六是缘智，七是三世智，八是一切智。这名为八种。

“又有八法入于寂静。哪八种？一是内寂静，二是外寂静，三是爱寂静，四是取寂静，五是有寂静，六是生寂静，七是一切烦恼寂静，八是三界寂静。这名为八法。

“又有八法入于观察。哪八种？一是戒，二是闻，三是禅定，四是智慧，五是神通，六是智，七是寂灭，八是不放逸。天子！这名为八法，菩萨因为安住于不放逸，诸佛的菩提以及菩提分法一切都当得到。所以天子！应当依这不放逸而住。

#### 不放逸的功德

“你们天子依不放逸，便三种乐常不减损。哪三种？一是天乐，二是禅乐，三是涅槃乐。再者，诸天子！依不放逸而住的人，得以远离三苦。哪三种？就是行苦、苦苦、坏苦。又，不放逸的人超越三种怖畏。哪三种？就是地狱、饿鬼、畜生。又，不放逸的人得以超越三有。哪三种？就是欲有、色有、无色有。再者，诸天子！依不放逸而住的人，得以远离三垢。哪三种？就是贪垢、瞋垢、痴垢。又，不放逸的人对三学处当得圆满。哪三种？就是增上戒、增上心、增上慧。不放逸的人常得亲近供养三宝。哪三种？就是佛宝、法宝、僧宝。

【按】“三者涅槃乐”之“者”，宫本无。

“再者，依不放逸而住的人，得以远离三种波罗蜜的障碍。哪三种？一是自己悭吝，二是对行布施的人心生憎嫉，三是随顺悭吝之人。自己破戒，憎嫉持戒的人，随顺破戒之人；自己瞋恚，憎嫉忍辱的人，随顺瞋恚之人；自己懈怠，憎嫉精进的人，随顺懈怠之人；自己散乱，憎嫉禅定的人，随顺散乱之人；自己没有智慧，憎嫉有智慧的人，随顺无智之人。你们诸天子！这名为依不放逸而住的人当得远离三种波罗蜜的障碍。

“再者，诸天子！依不放逸而住的人，当得三种波罗蜜的伴助。哪三种？就是：布施增长，不求果报，回向菩提；持戒增长，不求生天，回向菩提；忍辱增长，对一切众生不生害心，回向菩提；精进增长，对种种善根没有厌足，回向菩提；禅定增长，心不散乱，回向菩提；智慧增长，常修善业，回向菩提。这名为依不放逸而住所得的波罗蜜三种伴助。所以诸天子！住于不放逸，增长一切善法，为佛所印可。

#### 三十七品菩提分法

“再者，一切法如虚空，这四正勤应当观察。哪四种？就是：诸法无作，为了令未生的不善法不生而发起精进；法性清净，为了除灭已生的不善法而发起精进；诸法寂静，为了令未生的善法得以生起而发起精进；一切法无处无行，为了令已生的善法安住不失而发起精进。天子！这是诸菩萨的四正勤，为佛所印可。

“再者，诸天子！法性平等，无生无灭。依这法性，因为无所得，所以不作诸恶；因为随顺法性，所以勤修众善；这样修的人是无所修。再者，对一切法不取不舍，这名为正勤。再者，诸天子！应当观察四念处，就是：无身的住处、无受的住处、无心的住处、无法的住处。无住处、无建立处，这名为念处。

“再者，应当观察四如意足：一是身心不懈，因为乐修善法；二是为了成就一切众生而发起精进，因为要断除贪欲；三是一切法不可得，而证得诸佛之法；四是心如幻化，法无所依，因为超过一切取著。

【按】“为成就”之“就”，宋、元、明本作“熟”。

“再者，应当观察五根：一是信根，因为决定安住于诸法中，为上首；二是精进根，因为遍修诸行，成就佛身；三是念根，因为具足诸法，心善调柔，无所忘失；四是定根，因为远离攀缘，不随顺昏睡；五是慧根，因为决断诸法，正观现前，不随顺他人。什么是诸力？就是安住于这样的诸法性中，一切烦恼不能沮坏，这名为力。因为住于这力，便得殊胜之法，如实了知非异非如，说名为觉分。若对诸法随顺觉了，由这道次第修行，通达秘密，对法不动，说名为圣道。

“所以诸天子！应当这样修三十七品菩提分法，超出诸行，不再有障碍，智慧炽然，究竟寂静。什么名为究竟寂静？就是诸法无起，也无所尽；因为无所尽，便无所作；因为无所作，也非无作，无受，无受者，无施设，这名为究竟寂静。”宣说此法时，一万二千天子在诸法中得法眼净。

#### 菩萨修道与去来之道

那时善德天子对文殊师利说：“菩萨怎样修习于道？”文殊师利说：“天子！若诸菩萨不舍生死而令众生入于涅槃，不舍爱取而拔出众生、令其立于圣道，这名为菩萨修习于道。再者，天子！修习道的人，善巧安住于清净性空。为什么呢？菩萨以寂静之心见一切法自性清净，为那些乐著诸见、安住于随眠、没有方便的众生演说诸法自性空之义。为什么呢？因为这些众生在自性空中而生起种种见。这位菩萨以无相、无愿、无所作、一切法自性不生，为那些久习烦恼、有生灭之见的凡夫，令他们对这无生得以信乐，而对生灭也无所动摇。天子！这名为菩萨修习于道。再者，天子！应当见菩萨去来之道。”

诸天子说：“文殊师利！什么是菩萨去来之道？”文殊师利说：“天子！菩萨证得菩提而去，如其所应说法而来。得诸禅定与解脱而去，现生于欲界之中而来。因为入于圣道而去，因为以大悲成熟众生而来。得无生法忍而去，因为忍受众生而来。因为对一切法出离而去，因为拔出众生而来。誓愿坚固而去，誓愿无自性而来。以三解脱门而去，故意受生而来。因为趣向菩提道场而去，因为要令众生安立于菩提而来。天子！这名为诸菩萨去来之道。”宣说这菩萨道时，五百菩萨得无生法忍。

【按】“得诸禅解脱”之“禅”，元、明本作“禅定”。

#### 一切功德光明世界，持法炬菩萨来

那时善德天子对文殊师利说：“我们曾听说有一个世界，名为一切功德光明，在什么地方？哪位如来在其中说法？”文殊师利说：“天子！那一切功德光明世界在上方，过十二恒河沙佛刹，普贤如来在其中说法。”诸天子说：“我们愿见那世界以及那位如来。”那时文殊师利便入于光明庄严三昧，以三昧之力放大光明，越过十二恒河沙佛刹，遍照一切功德光明世界。当时那里的菩萨问：“这光明从哪里来？”那佛告诉他们说：“善男子！下方过十二恒河沙佛刹，有一个世界名为娑婆，那国土有佛名为释迦牟尼如来、应、正等觉，在世说法。那里有一位菩萨名为文殊师利，入于光明庄严三昧，放大光明遍照十方无量佛刹，这是他的光明来照这会。”那些菩萨便对普贤如来说：“我们愿见释迦牟尼世尊以及文殊师利菩萨。”当时普贤如来放大光明，照十二恒河沙佛刹，直到娑婆世界，令那些菩萨分明见到这里的菩萨众会。当时那位世尊告诉诸菩萨：“谁能前往那娑婆世界？”那时持法炬菩萨摩诃萨对佛说：“世尊！我能前往那娑婆世界。”佛说：“现在正是时候。”

那时持法炬菩萨与十亿菩萨一起，从那国土隐没，出现在兜率陀天，放大光明遍照世界。当时诸天、龙、夜叉、乾闼婆、阿修罗、迦楼罗、紧那罗、摩睺罗伽，帝释、梵天、护世诸天子等，以及诸声闻、菩萨大众，得未曾有，这样说：“这些菩萨的游戏神通甚为希有。”那时众会因这光明，见到一切功德光明世界，以及见到普贤如来国土的庄严，在一劫中也说不尽。在这文殊师利现神变时，七那由他诸天子等发阿耨多罗三藐三菩提心。

【按】“释梵护世”之“护”，宫本作“诸”。“菩萨大众”之“众”，南藏作“士”。

#### 还诣佛所，付嘱流通

那时持法炬菩萨对文殊师利说：“我们可以一同去礼觐释迦如来。”当时文殊师利把那些天子中应可度化的都度化之后，与持法炬诸菩萨众，以及大声闻，天、龙、夜叉、乾闼婆等，前往佛所。到了之后顶礼佛足，退住一面。那时持法炬菩萨对佛说：“世尊！普贤如来问讯世尊：少病少恼，起居轻利，安乐而行吗？”

那时世尊告诉那些菩萨说：“善男子！这位文殊师利以及持法炬正士的神通变化、智慧光明、成熟众生、奉事诸佛，一切菩萨都不能知其智慧方便深入的边际。你们善男子！应当学习这位文殊师利以及持法炬正士，以及诸菩萨所有的神通、辩才、智慧，奉事诸佛，成熟众生。这些正士在无数劫以来，从一佛刹到另一佛刹，常作佛事。若众生入于这些正士的境界，将来不再堕于魔界。”那时世尊告诉长老阿难：“你好好受持这法门，为了不断三宝之种。”那时持法炬菩萨摩诃萨从这会中起身，与他的眷属回到本来的佛刹。

佛说此经之后，善德天子、长老阿难，一切世间的天、龙、乾闼婆、阿修罗等，听闻佛所说，都大欢喜。
