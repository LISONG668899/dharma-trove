# 《大宝积经》卷第四十六（菩萨藏会·毘利耶波罗蜜多品）

唐·三藏法师玄奘 奉诏译

## 菩萨藏会第十二之十二

【按】品名“毘利耶”，明本作“毘梨耶”。

### 毘利耶波罗蜜多品第九之二

#### 末世护法四想

“再者，舍利子！在未来世正法将灭之时，又有菩萨摩诃萨安住于大乘，行毘利耶波罗蜜多，见到这样等等的恶众生诽谤、毁灭这正法之后，倍加振发勇猛正勤的大精进力，对这部经典、大菩萨藏微妙法门，殷勤听受，书写受持，读诵，广为他人开示演说。舍利子！这样的菩萨摩诃萨在那时应当生起四种想。是哪四种？舍利子！就是：我父的宝藏不久将要灭尽，为了这个缘故，佛薄伽梵释迦牟尼如来、应、正等觉在百千那庾多拘胝无数大劫中，精勤修习难行苦行，才获得这正法宝藏。所以我应当发勤精进，奉持此藏，遍持此藏，极力遍持，广为流通此藏，想令法宝久住不灭。舍利子！譬如有人只有一个儿子，怜念爱重，具大福相，观之无厌。此人后来要去某处，带着这个儿子将要经过危险之地，恐怕他颠坠，便用手执持，又平等遍持，极力平等遍持：‘不要让我的儿子堕入险难之处。’这样，舍利子！那善男子也是这样，深怀奉信，敬重于我，不舍这样无上的法宝，其志恒常希求清净寂灭，虽经恶世，而能摄受最胜正法。舍利子！我现在以这菩提因缘的无上正法付嘱此人。

“又，舍利子！譬如世间大军交战之时，很少有众生为了护卫大众而处在前阵，只有果敢雄猛的丈夫，率领骁勇之士抵抗强敌，为了护卫自己的大众，处在大军之前，振奋威势而住。这样，舍利子！在未来世正法灭时，破坏正法的人现前之时，有众生发起深心，欣乐寂灭，而能对这无上法宝，乃至受持少分要义，应当知道此人也是这样，披上正勤坚固的甲胄，奋发勇猛的大精进力，摧碎诸魔所有的军阵。为什么？舍利子！若有众生对这部经典乃至受持一首四句颂，不生诽谤，随喜赞叹，说这部经典真是佛说，在许多人面前广为宣扬显示，应当知道此人便是随喜赞说过去、未来、现在诸佛所说的经法。舍利子！如来不说此人只得少分的功德果报，我说此人能成就如虚空之量的大功德聚。为什么？舍利子！我说这些人名为善人。这样的善人甚为难得，就是知恩者以及报恩者。舍利子！这样的知恩与报恩之人，应当知道是人中的珍宝。

【按】“坏正法者”之“坏”，《大正藏》作“怀”，CBETA依高丽藏作“坏”，今从之。

“又，舍利子！在未来世正法灭时，诸恶魔等的威势显现之时，若有众生对如来信重不舍，受持这经，无有远离，我说此人是第一丈夫，是善丈夫，是胜丈夫，是健丈夫，是大丈夫。应当知道此人便是如来殊胜之法的朋侣，不是诈现亲近的恶党，应当知道此人是行真实之行的人。这样，舍利子！菩萨摩诃萨应当修习坚固的正行，乃至命终，中间无有片刻废止；对于诸佛应当勤加卫护，乃至命终，中间无有片刻废止；对于正法应当勤加摄受，乃至命终，中间无有片刻废止；对于甚深的空法应当勤加信解，乃至命终，中间无有片刻废止。舍利子！这是菩萨摩诃萨在后来恶世所生起的四种法。

【按】“朋侣”，宋本作“明后”。

“若有成就这样四种法的菩萨摩诃萨，在未来世法将要尽时、诽谤正法时、毁灭正法时、犯戒徒党大为强盛时、炽然追求顺世外道恶咒术时、劫浊乱时、有情浊时、寿命浊时、烦恼浊时、诸见浊时，菩萨摩诃萨在那时应当住于三处作为依止。是哪三处？就是应当住于阿兰若处，应当住于诤论息灭之处，应当住于佛菩提之处。舍利子！这是菩萨摩诃萨在未来恶世所住的三处，应当这样受持，这便是具足毘利耶波罗蜜多。”那时世尊想重宣此义，而说颂道：

```
于最胜法不远离，
为尽生老病死苦，
常勤精进无妄念，
当速成就自他利。
若有于是善说法，
闻已安住正思惟，
当知我为彼大师，
彼则是我真弟子。
若不听闻如是法，
设闻不住正思惟，
是人当趣诸恶道，
犹彼众流归大海。
百千拘胝那庾劫，
诸佛出现甚为难，
虽复暂遇不亲奉，
当随恶魔自在转。
```
（大意：对于最胜之法不远离，为了穷尽生老病死之苦，常勤精进，没有妄念，将迅速成就自利与利他。若有人对这善说之法，听闻之后安住于正思惟，应当知道我是他的大师，他便是我真正的弟子。若不听闻这样的法，或者听闻了不住于正思惟，此人将趣向诸恶道，犹如众多河流归于大海。在百千拘胝那庾多劫中，诸佛出现甚为难得，虽然暂时遇到而不亲近奉事，将随恶魔自在而转。）

#### 胜观佛时六恶苾刍说有我

“再者，舍利子！往昔过去九十一劫，那时有佛出世，名为胜观如来、应、正等觉、明行圆满、善逝、世间解、无上丈夫、善调御士、天人师、佛、薄伽梵。舍利子！那尊佛的法中有六位苾刍，行种种恶行，恒常互相追随：一名善见，二名善乐，三名欢喜，四名调善，五名苏逾遮，六名火天授。舍利子！这六位苾刍恒常宣说非法，说有我、有人、有常、有断，结成坚固的团伙，互相信任，到深隐之处共同谋议：‘我们应当各自去诱化，每人以一百家作为徒党，又令这一百家转告其眷属，这样展转向亲戚姻亲传告，或可达到五十倍、一百倍等。’这样议定之后，便前往教化，无论村落、城市、郊野、店肆，或到王都以及其余国家，每一家都前往。到了那里之后，不说正法，先对佛世尊加以毁谤。

“舍利子！那些恶苾刍怎样毁谤？舍利子！诸恶苾刍告诉众人说：‘世间决定有我、有众生、有寿命者、有数取者。若世间决定没有我以及诸法，那么谁去谁来？谁坐谁卧？谁语谁默？谁能行布施？谁是所受者？谁能受用？谁受苦乐？谁能受不苦不乐？若有人来对你们说：“世间决定无我、无众生、无寿命者、无数取者。”应当知道此人是你们的怨家，不是你们的善友。’舍利子！那时诸恶苾刍又诱化妇人、丈夫以及男女，这样说：‘若有人说无我等法，应当知道此人是不善者，是暴恶者，是你们的恶友，不是你们的善友。’又教化说：‘你们这些人都是聪慧的，深能领解我所说的义理。从今以后，若有恶友、非善友前来，会对你们说世间决定无我等法，你们不应随便与他们亲昵交往，往来承事供养。’舍利子！诸恶苾刍这样教化，在半个月之间，每人各诱得满五百家归从他们的见解。

【按】“亲昵”之“昵”，明本作“眤”。

“舍利子！那时有诸苾刍是阿罗汉，永离一切烦恼垢秽，是胜观如来、应、正等觉的真实弟子，为了乞食等种种因缘，前往那些恶苾刍所教化的人家。刚到门口，便被妇人、丈夫以及诸男女共同毁骂，非理呵责，以粗恶之言当面挫辱，对诸苾刍说颂道：

【按】“便为妇人”之“便”，北藏作“更”。

```
汝等不能知正法，
汝等迷失于圣道，
汝等退舍于净教，
汝等皆当堕地狱。
```
（大意：“你们不能知道正法，你们迷失了圣道，你们退舍了清净之教，你们都将堕入地狱。”）

“舍利子！那些人说了这话之后，对阿罗汉更加呵骂；呵骂之后，又以种种言词骂佛，就在佛前说伽陀道：

```
如来所说非虚妄，
所谓诸行悉无常，
又说诸法皆无我，
及以无恒无不变。
诸行都无有坚实，
皆为虚伪妄失法，
所说空华无所有，
但能诳惑彼愚夫。
```
（大意：“如来所说之法是虚妄的：说诸行都是无常，又说诸法都是无我，以及无恒、无不变；诸行都没有坚实，都是虚伪、妄失之法，所说的如空中之花，无所有，只能诳惑那些愚夫。”）

【按】“非虚妄”之“非”，宋、元、明、宫本作“法”，即“如来所说法虚妄”，与下文“诳惑彼愚夫”相应，今依之译出。“妄失法”之“妄”，宋、元、明、宫本作“忘”。

“舍利子！那些人说了这样的话轻毁佛之后，更加愤恚，又在佛前说伽他道：

```
如来所说一切法，
决定无我无众生、
无有寿命无数取，
亦无作者及受者。
而今现见诸世间，
有能行施及所受，
并余种种受用人，
及觉广大诸受等。
当知宣说定无我，
一切皆应堕恶道。
```
（大意：“如来所说的一切法，决定无我、无众生，没有寿命，没有数取，也没有作者以及受者。而现在明明见到世间有能行布施的人以及所受者，以及其余种种受用的人，以及觉受广大的种种受等。应当知道，宣说决定无我的，一切都应堕入恶道。”）

“舍利子！在那时，诸不善人同声说这非法之语的，大小男女有六十八拘胝千众生，都是由于恶苾刍的化导而行这恶业。他们命终之后同生于无间大地狱中，所受之身粗大，鱼形人首，其舌长广，弥布于地，周遍被钉下，如种姜的田地；又在舌上有众多铁犁常常耕它。他们每一个身体又被一百只极恶的商佉所啃食。又在空中，大热铁丸猛焰赫然，光色炽盛，从空中坠落，常常雨落在他们身上。这些罪人以恶业的缘故，受这样等等的种种楚毒。”那时世尊想重宣此义，而说颂道：

```
铁丸猛焰如飞电，
可畏无量百千种，
常于其身而堕坠，
炽然恒受种种苦。
又于身内遍流转，
炎炽猛盛难逢近，
腾焰高踊百由旬，
流火遍出身毛孔。
又彼众生一一舌，
尽为无量铁犁耕，
一切舌分皆分裂，
如是苦受恒缠绕。
斯由亲近恶友已，
能感如斯大苦聚，
又由远离具戒者，
致令速堕于恶道。
```
（大意：铁丸的猛焰如飞电，可怖畏的有无量百千种，常常在他们身上坠落，炽然燃烧，恒受种种痛苦。又在身内遍处流转，炎炽猛盛，难以接近，腾起的火焰高踊百由旬，流火遍从身上毛孔冒出。又那些众生的每一条舌，都被无量铁犁所耕，一切舌分都破裂，这样的苦受恒常缠绕。这是由于亲近恶友之后，能感得这样的大苦聚，又由于远离具戒之人，致使迅速堕入恶道。）

【按】“常于其身”之“常”，元、明本作“当”。“猛盛”之“盛”，明本作“威”。“腾焰”之“腾”，宫本作“胜”。

“舍利子！那时那非法的六位恶苾刍，由于恶教的缘故，命终之后都生于阿毘大地狱中，每一个所受之身纵横等量三十逾缮那，每一个身上都生出一千张口，每一张口中各生出两条舌，每一条舌长宽之量等于四逾缮那，每一条舌上有五百把铁犁，铁牛拉着来耕他们的舌。这些罪人虽然受苦痛，因为大苦逼迫，连号叫都来不及。又在头上各有万亿狱卒，手执刀、锯、矛、矟等害具，斫刺破裂，毁坏其身首。在这狱中寿命万亿岁，这样展转又往其余诸大地狱中，备受辛酸的种种苦楚。为什么？因为他们瞋恨毁谤佛的圣教。

【按】“恶苾刍”之“苾”，《大正藏》作“芯”，今依高丽藏作“苾”。

#### 安隐长者之子初生说法

“舍利子！在那时，有一位大长者名叫安隐，财富无量，资产具足，多有珍宝，金银、琉璃、珊瑚、末尼、真珠、贝玉，无不具备；又多有仆使奴婢，财谷库藏都盈满。这时长者被恶苾刍所教化，接受其说法之后，生起断见。长者有妻子名叫焰慧，容色美盛，为人所重。她生了一个男孩，形貌端严，众人观之无厌，成就第一圆满清净之色，曾在过去无量百千那庾多拘胝佛所种植种种善本。刚出生时三次微笑，又说这话：‘奇哉！奇哉！为什么现在生在持断见的家中？’他的母亲听到后惊恐惶惧，身毛竖立，与诸女人丢下他逃避。舍利子！那时诸女人想要仔细弄清楚，又回来靠近，观察这孩子是什么种类：是天吗？是龙吗？是药叉吗？是健达缚吗？是阿素洛吗？是揭路荼吗？是紧捺洛吗？是牟呼洛伽吗？是究槃荼吗？是毕舍遮、人非人吗？舍利子！那时这婴儿再次说话，告诉诸女人说：‘你们虽然恐怖逃走，我却很安乐。’那时这婴儿为诸女人说颂道：

【按】“是时长者”之“是”，明本作“尔”。

```
汝当乐义利，于义利勿怖，
我当度汝等，令脱于邪道。
汝安隐勿怖，应怖前恶友，
我当度汝等，令脱于邪见。
```
（大意：“你们应当乐于义利，对义利不要恐怖，我当度你们，令你们脱离邪道。你们安稳，不要恐怖，应当恐怖的是先前的恶友，我当度你们，令你们脱离邪见。”）

“舍利子！那时那孩子的父母以及其余大众，听到这婴儿说伽他之后，便来到孩子那里。这时婴儿为他的父母说颂道：

```
家中凡所有，广大诸财谷，
速持来见与，供佛及声闻。
彼大声闻众，照世胜观尊，
三界围轮中，都无与等者。
彼大声闻众，照世胜观尊，
广阐扬妙法，利益诸群品。
彼大声闻众，照世胜观尊，
身具三十二，大丈夫威相。
彼佛声闻众，犹如乌昙花，
名称甚难闻，过亿拘胝劫。
```
（大意：“家中所有的广大财谷，快拿来给我，用来供养佛以及声闻。那大声闻众与照耀世间的胜观尊，在三界轮围之中，无有与之相等的。那大声闻众与照耀世间的胜观尊，广为阐扬妙法，利益众生。那大声闻众与照耀世间的胜观尊，身具三十二种大丈夫威相。那佛与声闻众犹如优昙花，其名称甚难听到，要经过亿拘胝劫。”）

“舍利子！那时孩子的父母听了这法之后，便取家中二十拘胝上妙财宝，拿到孩子那里，对他说：‘这些财宝是你父母所有之物，你应当取去，随你的志意，随你所生信心的对象，奉施出去。’那时父母便为这孩子说颂道：

```
此是汝父母，所致诸财宝，
随心所敬信，汝当持布施。
若金若珍宝，家中甚丰积，
随心所敬信，汝当持速施。
衣服坐卧具，花鬘及涂香，
随心所敬信，汝持欢喜施。
于佛及法僧，无上福田所，
为利诸群生，当应行布施。
```
（大意：“这是你父母所积聚的种种财宝，随你心中所敬信的，你应当拿去布施。无论金银还是珍宝，家中甚为丰积，随你心中所敬信的，你应当拿去迅速布施。衣服、坐卧之具、花鬘以及涂香，随你心中所敬信的，你拿去欢喜布施。对于佛以及法、僧这无上福田，为了利益众生，应当行布施。”）

“舍利子！那时婴儿听了父母所说的颂之后，又为父母说颂道：

```
我今往胜观，世间依怙所，
当广设供养，为利群生故。
诸有欲希求，天上人中乐，
应随我所诣，胜观如来所。
```
（大意：“我现在前往胜观——世间依怙者之所，当广设供养，为了利益众生。凡是想要希求天上、人中之乐的，应当随我前往胜观如来之所。”）

“舍利子！那时婴儿以正念正知观视四方，对父母说：‘父母当知，我现在应当前往薄伽梵胜观如来、应、正等觉之所。’于是众人听了这话，都大为惊愕：‘为什么婴儿在初生之日，就能与人往返言谈议论，又能徒步有所前往？’那时有八万四千众生，听说这奇异之事，都来聚集，这样说：‘我们应当看看这婴儿是什么种类：是天？是龙？是药叉吗？乃至是毕舍遮、人非人吗？’

【按】“徒步”之“徒”，《大正藏》作“徙”，CBETA依高丽藏作“徒”，今从之。

#### 婴儿即大自在天子，当来成大悲如来

“舍利子！你现在应当观察，那过去世胜观如来法中的婴儿，难道是别人吗？不要生其余的疑惑，就是现在的大自在天子。从此以后，又经过拘胝那庾多劫不再退堕；过了这些劫后，生于转轮圣王的种族中，他将来的父亲号为名称，如我现在的父亲净饭大王；他将来的母亲号为离暗，如我现在的母亲摩诃摩耶；他将来的儿子号为无忧，如我现在的儿子罗睺罗。舍利子！他出家觉悟菩提之后，得以成佛，名为大悲如来、应、正等觉，十号具足。那尊佛寿量满百千拘胝岁，佛身的常光遍照所及十逾缮那，佛说法之处的大会充满一百逾缮那。大悲如来处世教化，为了度化声闻，三次集会说法：第一次大会度化弟子有一百拘胝，第二次大会度化弟子有那庾多拘胝，第三次大会度化弟子有百千那庾多拘胝。舍利子！他的弟子中满一拘胝都是大阿罗汉，诸漏已尽，不再有烦恼，得自在之慧，具足八解脱，成就静虑以及六神通。舍利子！大悲如来所度的声闻阿罗汉众，如上所说的三会数量，他的菩萨众数量也相等，都是往世所生的父母。那位佛世尊宣说妙法，利益无数众生之后，然后涅槃。佛灭度后，正法住世满一拘胝岁，分布舍利，饶益众生，也如我现在般涅槃之后流布供养一样，没有差异。

#### 不倦精进与勇猛精进

“舍利子！安住于正勤的菩萨摩诃萨也是这样，修行毘利耶波罗蜜多时，为了求阿耨多罗三藐三菩提，能对这经修行正行，倍加振发勇猛正勤的大精进力，度脱无量众生等。我说此人是善丈夫，思觉观察，不倦不退，勇猛精进，明了系念在心。舍利子！什么是菩萨摩诃萨的不倦精进？

【按】“修行正行”之“行”，元、明本作“法”。

“舍利子！菩萨摩诃萨为了众生而求菩提时，不应限定数量而有所求。为什么？菩萨摩诃萨不作这样的念头：‘在多少劫中我当流转，在多少劫中我不流转。’因为这样，菩萨那时披上不可思议的铠甲，处于生死之中，作这样的念：‘假使如我前际所经历的生死这样多，再经受勤苦，经历生死倍于前际，为了求菩提，中间也无懈怠止息。’舍利子！菩萨摩诃萨具足这样坚固的弘誓，便名为成就不倦精进。

“再者，舍利子！菩萨摩诃萨怎样修行勇猛精进？舍利子！假使三千大千世界中满是炽火，发起勇猛正勤的菩萨摩诃萨为了前往觐见那位如来，以精进之力从这炽火中穿过，不怯不退。又，舍利子！勇猛正勤的菩萨摩诃萨为了求得听闻大菩萨藏微妙法门，以精进之力，虽然遇到这火，也从中直过而无怯退。又，舍利子！假使三千大千世界中满是炽火，勇猛正勤的菩萨摩诃萨为了宣说大菩萨藏深妙之法，以精进之力从这炽火中直过而无怯退。又，舍利子！假使三千大千世界中满是炽火，勇猛正勤的菩萨摩诃萨为了生起善根因缘，以精进之力从这炽火中直过而无怯退。又，舍利子！假使三千大千世界中满是炽火，勇猛正勤的菩萨摩诃萨为了利益众生，以精进之力能从中穿过；这样，为了令他人得寂静，为了令他人得调伏，虽然遇到这火，都从中穿过而无怯退。又，舍利子！发起勇猛不倦正勤的菩萨摩诃萨，为了令他人般涅槃，以精进之力，虽然遇到这火，能从中穿过而无怯退。舍利子！这名为菩萨摩诃萨修行毘利耶波罗蜜多的勇猛之相。

【按】“皆由中过”之“由”，圣本作“犹”。

“再者，舍利子！发起勇猛不倦正勤的菩萨摩诃萨行毘利耶波罗蜜多时，由于不懈倦、坚固不退的善根所发起的无上大悲所熏习，恒常发起勇猛的大精进力，对众生常行化导。又，舍利子！这样发起勇猛不倦正勤的菩萨摩诃萨，在一切时举足下足，常不舍离大菩提心，对佛、法、僧恒常生起珍重敬意，系念在前，对众生恒常遍加观察，为了利益他们，不想令他们被烦恼的势力所逼夺。又，舍利子！发起勇猛不倦正勤的菩萨摩诃萨，所有已生的种种妙善根，一切都回向无上菩提，令这善根毕竟无尽，譬如少量的水投入大海，乃至劫火焚烧，中间也无有穷尽。舍利子！菩萨摩诃萨也是这样，以种种善根回向菩提，也无有穷尽，这名为菩萨摩诃萨勇猛不倦的大精进力。又，舍利子！勇猛不倦精进的菩萨摩诃萨，以平等之行积集善根，对众生生起平等之行而积集善根，为了引生一切智智而积集善根，为了利益众生而积集善根。舍利子！这样无量的种种大善根，都是菩萨摩诃萨勇猛无倦的大精进力所集起的。

#### 相好的福聚与法螺之相

“再者，舍利子！这样勇猛不倦正勤的菩萨摩诃萨，常应精进修学这法，所得的福聚无量无边，现在当广说福聚之相。舍利子！我观察世间一切众生所有的福聚无量无边，这样乃至一切有学、无学所有的福聚，一切独觉所有的福聚，转加无量，不可思议。如上所有的种种福聚等，假使全部放入一个众生的一个毛孔中，这样，众生的每一个毛孔都有如上的福德之聚，无量无边，不可思议。这样，假使一切众生一切毛孔所有的福聚合集起来，放在一场无遮的大法祠中；舍利子！这样法祠的功德福聚，倍增一百倍，感得如来大丈夫身色相中的一相。这样，每一种大丈夫相，都是以这样的功德所成就。这样，一切如来身中大丈夫相所有的福聚，都合成一个眉间毫相。这样，入于一个眉间毫相的福聚，又超过此百千倍的大功德聚，合成如来顶上无人能见的乌瑟腻沙大丈夫相。这样，入于一个肉髻的大功德聚，又超过此拘胝百千倍的大功德聚，合成如来的大法商佉之相。舍利子！由于这如来的大法螺之相是由无量种功德所集成的，因为这样，如来随其意欲，发出大音声，遍告无量无边一切世界，为诸有情广说妙法，如其根性，随其所闻信解，都令欢喜。为什么？都是由于精进修学的缘故。舍利子！菩萨摩诃萨应当这样想：‘这样的无上正等菩提虽然极难得到，我当不舍精进的铠甲，发大勇猛，必定迅速觉悟无上菩提，不足为难；成佛之后，随我的意欲，从法螺之相发出大音声，遍告无量无边一切世界，为众生说微妙之法，随其根性信解，都令欢喜。’舍利子！这名为菩萨摩诃萨勇猛无倦的正勤之相。

【按】“无关键”即无遮，不设限制。“商佉”即法螺。“眉间毫相”之“毫”，圣本作“豪”。“随根信解”之“信”，元、明本作“性”。

#### 诸智比较与处非处智力

“再者，舍利子！勇猛无倦精进的菩萨摩诃萨依毘利耶波罗蜜多，常应这样精进修学；由于修学，具足成就一切智慧。舍利子！假使三千大千世界所有众生，一切都成就随信行之智，用此智来比一位成就随法行之智的人，百分不及一，千分不及一，百千万分不及一，僧佉分不及一，迦罗分不及一，伽拏那分不及一，乌波摩分不及一，乌波尼沙陀分不及一。再者，舍利子！假使三千大千世界所有众生，一切都成就随法行之智，想用来比一位第八人之智，百分不及一，乃至乌波尼沙陀分不及一。再者，舍利子！假使三千大千世界所有众生，一切都成就第八人之智，想用来比一位预流果之智，百分不及一，乃至乌波尼沙陀分不及一。再者，舍利子！假使三千大千世界所有众生，一切都成就预流果之智，想用来比一位乃至一来向之智；这样，一来果之智，乃至想用来比不还果之智；这样乃至想用来比阿罗汉之智、独觉之智、经过百劫的菩萨之智、成就不退转的菩萨之智；这样乃至想用来比一生补处菩萨之智，都应广说，无量无边，算数譬喻所不能及。这样，舍利子！假使十方无量无边一切世界所有众生，都成就一生补处菩萨之智，想用来比如来十力中的一种——处非处智，百分、千分、百千万分不及一，僧佉分不及一，迦罗分不及一，伽拏那分不及一，乌波摩分不及一，乌波尼沙陀分不及一，乃至算数譬喻所不能及。

【按】“随信行”“随法行”“第八人”，即见道前后的诸圣位。“系属一生”即一生补处。

“舍利子！这位菩萨摩诃萨因行毘利耶波罗蜜多，听闻如来这样甚深的智解之时，其心不惊，无有怖畏，对这智慧生起乐欲之心，发起正勤，中间无有废舍，这样想：‘我现在修行勇猛精进，假使我身的皮、肉、骨、血、筋、脉、髓、脑都枯燥烂坏无遗，在还未得到如来这样的处非处智力之前，在这中间发大勇猛、坚固精进，终无懈怠废止。’舍利子！这名为菩萨摩诃萨勇猛无倦正勤波罗蜜多的坚固之相，应当这样修学。

【按】“于是智人”之“人”，宋、元、明、宫本作“入”。

#### 灭众生烦恼火

“再者，舍利子！菩萨摩诃萨因行毘利耶波罗蜜多，发大勇猛无倦的正勤，常应这样精进修学；由于修学，能灭除众生的种种烦恼之火。舍利子！假使一切众生在过去世所有的种种心，都进入一个众生的一心中运转；这样，众生的每一种心，乃至一切众生每一个都各有那么多的心，无量繁杂，难以了知；这样，一切众生的每一种心中，各具有无量的贪、瞋、痴等种种烦恼的繁杂；把这一切众生所有的烦恼，都放入一个众生的一心中运转。舍利子！假使展转一切众生都具有这样无量的烦恼，难以了知。菩萨摩诃萨这样想：‘我当策励勇猛，发勤精进，寻求这样的智慧资粮，随我所发正勤之力，对众生的贪、瞋、痴之火以及其余热恼，我一定要令其息灭无遗，斩除毒害，摧破散坏，如同灰烬，迅速令众生住于涅槃之道。’舍利子！这名为菩萨摩诃萨勇猛无倦的正勤波罗蜜多，应当这样修学。

【按】“摧破”之“破”，宋、元、明、宫本作“碎”。

#### 心精进的进止之相

“再者，舍利子！菩萨摩诃萨依毘利耶波罗蜜多，安住于勇猛无倦的精进，常应这样正勤修学。由于修学，种种善的身业无有休废，种种善的语业无有休废，种种善的心业无有休废，乃至所有一切正勤，都作为策进菩萨身、语、心业的方便。舍利子！然而诸世间只说菩萨身、语二业的精进第一，不说菩萨心的精进之相。舍利子！菩萨摩诃萨心的精进之相无量无边，我现在略说。什么名为心的精进之相？就是菩萨的心修行正勤，或进或止，这样为相。

“舍利子！什么名为正勤的进与止？舍利子！菩萨修行大精进，是为了菩提而勤行精进。所说的进，是对众生发起大悲；所说的止，是无我之忍。所说的进，是摄受众生；所说的止，是于法不取。所说的进，是于生死无倦；所说的止，是不得三界。所说的进，是一切尽舍；所说的止，是不厌布施。所说的进，是摄取净戒；所说的止，是不厌尸罗。所说的进，是堪忍众苦；所说的止，是心无毁坏。所说的进，是生起种种善法；所说的止，是心常远离。所说的进，是摄受静虑；所说的止，是心常寂灭。所说的进，是闻法无厌；所说的止，是如理善巧。所说的进，是听说无倦；所说的止，是无戏论之法。所说的进，是求取智慧资粮；所说的止，是断除种种戏论。所说的进，是增长梵信；所说的止，是真知而行舍。所说的进，是具足五神通；所说的止，是遍知漏尽。所说的进，是修习诸念处；所说的止，是念无功用。所说的进，是正断的方便；所说的止，是善恶俱舍。所说的进，是引发神足；所说的止，是任运作用。所说的进，是诸根的善巧；所说的止，是观察非根之性。所说的进，是摄受诸力；所说的止，是智无所制伏。所说的进，是生起菩提分；所说的止，是以智简择诸法。所说的进，是求取道的资粮；所说的止，是无来往之性。所说的进，是求奢摩他；所说的止，是心住于寂止。所说的进，是资助胜观；所说的止，是伺察法性。所说的进，是随觉种种因；所说的止，是遍知种种因。所说的进，是从他人听闻音声；所说的止，是如法修行。所说的进，是身的庄严；所说的止，是法性之身。所说的进，是语的庄严；所说的止，是圣默然之性。所说的进，是信解解脱之门；所说的止，是无有发起。所说的进，是远离四魔；所说的止，是舍弃烦恼习气。所说的进，是方便善巧；所说的止，是观察深慧。所说的进，是观察所缘之境；所说的止，是无功用之观。所说的进，是观察假名；所说的止，是了达实义。舍利子！这样等等的进止之相，名为菩萨摩诃萨的唯心精进。若诸菩萨摩诃萨听闻这样等等心的精进之相，应当发起勇猛无倦、具足的正勤。舍利子！这样名为菩萨摩诃萨修行正勤波罗蜜多、无有厌倦、勇猛精进的修习之相。

【按】“真知行舍”之“知”，元、明本作“智”。“智简择法”之“简”，元、明本作“拣”。
