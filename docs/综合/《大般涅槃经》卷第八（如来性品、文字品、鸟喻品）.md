# 《大般涅槃经》卷第八（如来性品、文字品、鸟喻品）

北凉·天竺三藏昙无谶 译　刘宋·沙门慧严等 依《泥洹经》再治

## 如来性品第十二

【按】本品在北本中属《如来性品第四之五》，其中开头“二十五有有我不耶”至雪山乐味药一段，北本在上一卷之末。

### 贫女宝藏喻

迦叶对佛说：“世尊，二十五有中有我吗？”

佛说：“善男子，我，就是如来藏的意思。一切众生悉有佛性，这就是我的意思。这样的我，从本以来常被无量烦恼所覆盖，所以众生不能见到。

“善男子，如一个贫穷的女人，家中有许多真金宝藏，家里老少没有一个人知道。这时有一个外人，善知方便，对贫女说：‘我现在雇你，你可以为我耘除杂草。’女人答道：‘我现在不能。你若能把金藏指示给我的孩子，然后我就赶快为你去做。’那人又说：‘我知道方法，能指示给你的孩子。’女人答道：‘我家老少尚且不知道，何况你能知道？’那人又说：‘我现在确实能。’女人答道：‘我也想见，请一并指示给我。’那人就在她家中掘出了金藏。女人见了，心生欢喜，生起奇特之想，敬仰这个人。

“善男子，众生的佛性也是这样，一切众生不能见到，如那宝藏，贫人不知道。善男子，我现在普遍指示一切众生所有的佛性，被诸烦恼所覆蔽，如那贫人有真金宝藏而不能见到。如来今天普遍向众生开示诸觉悟的宝藏，就是佛性。一切众生见到这件事之后，心生欢喜，归仰如来。善于方便的人，就是如来；贫女人，就是一切无量众生；真金宝藏，就是佛性。

### 涂乳之喻

“再者，善男子，譬如一个女人生了一个孩子，婴儿生了病。这女人愁恼，寻求良医。良医来了，调配了酥、乳、石蜜三种药给孩子服用，并告诉女人：‘孩子服药之后，暂且不要给他喂奶，必须等药消化了，才可以喂。’这时女人就把苦味的东西涂在乳上，对孩子说：‘我的乳上涂了毒，不能再碰。’小孩口渴，想吃母乳，闻到乳上的毒气，就远远躲开了。等到药消化了，母亲才洗净乳房，唤孩子来吃奶。这时小孩虽然饥渴，因为先前闻到了毒气，所以不来。母亲又说：‘为了你服药，所以才涂毒；你的药已经消化了，我已经洗干净了，你就可以来吃奶，没有苦味了。’孩子听了，才渐渐回来吃奶。

“善男子，如来也是这样。为了度化一切众生，教众生修习无我之法；这样修习之后，永断我执之心，入于涅槃。为了除去世间的种种妄见，为了示现超出世间之法，又为了显示世间所计执的我是虚妄而非真实，为了修习无我之法而得清净之身，就像那女人为了孩子而以苦味涂乳；如来也是这样，为了修空的缘故，说诸法都无有我。如那女人洗净乳房之后，唤孩子回来再吃；我现在也是这样，宣说如来藏。所以比丘不应生起恐怖，如那小孩听到母亲呼唤，渐渐回来吃奶；比丘也是这样，应当自己分别如来秘藏，不能说没有。”

### 迦叶以种种理由难有我

迦叶菩萨对佛说：“世尊，实在没有我。为什么呢？婴儿出生时无所知晓，若有我，出生之日就应当有所知，因为这个道理，确定知道没有我。若确实有我，受生以后就应当没有终殁；若一切众生都有佛性，是常住的，就应当没有坏灭之相；若没有坏灭之相，为什么会有刹帝利、婆罗门、毗舍、首陀罗以及旃陀罗、畜生的差别？现在见到业缘种种不同，诸趣各异。若确实有我，一切众生应当没有胜负之分，因为这个道理，确定知道佛性不是常法。

“若说佛性一定是常，为什么又说有杀、盗、淫、两舌、恶口、妄语、绮语、贪、恚、邪见？若我性是常，为什么酒后荒醉迷乱？若我性是常，盲人应当能见色，聋人应当能闻声，哑人应当能说话，跛足的人应当能行走。若我性是常，就不应当躲避火坑、大水、毒药、刀剑、恶人、禽兽。若我是常，过去经历的事不应当忘失；若不忘失，为什么又说：‘我曾在哪里见过这个人？’若我是常，就不应当有老少、盛衰、忆念往事。若我是常，住在哪里？是在涕唾之中，还是在青黄赤白诸色之中？若我是常，就应当遍满身中，如胡麻中的油，没有空隙；若截断身体时，我也应当被截断。”

### 力士额珠喻

佛告诉迦叶：“善男子，譬如王家有一位大力士，他的眉间有一颗金刚珠。他与其他力士角力相扑，对方力士用头撞他，他额上的珠子随即陷入皮肤中，他自己全然不知道珠子在哪里。那里生了疮，就叫良医来给自己治疗。这时有一位明医，善知方药，随即知道这疮是因为珠子进入身体所致，这珠子进入皮下就停住了。

“这时良医就问力士：‘你额上的珠子在哪里？’力士惊讶地答道：‘大师医王，我额上的珠子竟然丢失了吗？这珠子现在在哪里？莫非是幻化？’忧愁啼哭。这时良医安慰力士说：‘你现在不应生大愁苦。你因为争斗时，宝珠进入了身体，现在就在皮里，影子显现在外面。你们争斗时，瞋恚之毒炽盛，珠子陷入体内，所以自己不知道。’

“这时力士不信医生的话：‘若在皮里，脓血不净为什么不流出来？若在筋里，就不应能看见。你现在怎么欺骗我？’这时医生拿镜子照他的脸，珠子在镜中清楚地显现。力士见了，心中惊怪，生起奇特之想。

“善男子，一切众生也是这样，因为不能亲近善知识，虽有佛性，都不能见到，而被贪淫、瞋恚、愚痴所覆蔽，所以堕入地狱、畜生、饿鬼、阿修罗，或生在旃陀罗、刹帝利、婆罗门、毗舍、首陀罗等种种家中。由心所起的种种业缘，虽然受了人身，却聋盲喑哑、跛躄驼背，在二十五有中受诸果报。贪淫、瞋恚、愚痴覆盖其心，不知有佛性，如那力士宝珠在体内，却说已经丢失。

“众生也是这样，因为不知亲近善知识，不认识如来微密的宝藏，修学无我，譬如非圣之人虽然说有我，也不知道我的真性。我的诸弟子也是这样，因为不知亲近善知识，修学无我，却也不知道无我之处；尚且不知道无我的真性，何况能知道有我的真性？

“善男子，如来这样宣说一切众生都有佛性，譬如良医指示那力士的金刚宝珠。这些众生被无量亿诸烦恼等所覆蔽，不认识佛性；若烦恼除尽，那时才能证知明了，如那力士在明镜中见到他的宝珠。善男子，如来秘藏就是这样无量不可思议。

### 雪山乐味药喻

“再者，善男子，譬如雪山有一种一味药，名叫乐味，味道极甜，生在深密的草丛下，人们无法见到。有人闻到香气，就知道那地方应当有这种药。过去世中有一位转轮王，在那雪山中为了这种药，到处制作木筒来承接这药。这药成熟时，从地中流出，汇集到木筒中，味道真正。国王死后，这药或酸、或咸、或甜、或苦、或辣、或淡，本是一味，却随着流经之处而有种种不同。这药的真味停留在山中，犹如满月。凡人福薄，虽然用锄头挖掘，费尽辛苦，也不能得到。后来又有圣王出现于世，以福德因缘，就得到这药的真正之味。

“善男子，如来秘藏的滋味也是这样，被诸烦恼的丛林所覆盖，无明的众生不能见到。药的一味，比喻佛性；因为烦恼的缘故，出现种种味道，即地狱、畜生、饿鬼、天、人、男、女、非男非女、刹帝利、婆罗门、毗舍、首陀罗。佛性雄猛，难以毁坏，所以没有能杀害它的。若能杀害，就是断了佛性；而佛性终究不可断，若说佛性可断，没有这样的道理。如我之性，就是如来秘密之藏，这秘藏一切都不能毁坏烧灭；虽然不可破坏，却也不可见到，若成就了无上正等正觉，才能证知。因为这个缘故，没有能杀害的。”

### 佛性不可坏，坏五阴名杀生

迦叶菩萨又对佛说：“世尊，若没有能杀害的，就应当没有不善之业了。”

佛告诉迦叶：“确实有杀生。为什么呢？善男子，众生的佛性住在五阴之中，若破坏五阴，就名为杀生；若有杀生，就堕入恶趣。因为业的因缘，而有刹帝利、婆罗门等、毗舍、首陀罗以及旃陀罗，若男若女、非男非女，二十五有的差别之相，流转生死。非圣之人横计有我，说我有大小种种相，如稗子，或如米豆，乃至如拇指，这样种种妄生忆想，妄想之相没有真实。出世间的我相，名为佛性，这样计我，名为最善。

“再者，善男子，譬如有人善知地下伏藏，就拿锋利的锄头直向下挖掘，磐石沙砾都能直接通过，毫无困难，只有到了金刚，不能穿透。金刚是一切刀斧都不能破坏的。善男子，众生的佛性也是这样，一切论师、天魔波旬以及诸人天都不能破坏。五阴之相就是起作，起作之相如石沙，可以穿透，可以破坏；佛性真我，譬如金刚，不可毁坏。因为这个道理，破坏五阴，名为杀生。善男子，必定应当知道，佛法就是这样不可思议。

### 方等经如甘露亦如毒药

“善男子，方等经犹如甘露，也如毒药。”

迦叶菩萨又对佛说：“如来为什么说方等经譬如甘露，也如毒药？”

佛说：“善男子，你现在想知道如来秘藏的真实之义吗？”

迦叶说：“我现在确实想知道如来秘藏的意义。”

那时世尊说偈：

```
或有服甘露　伤命而早夭
或复服甘露　寿命得长存
或有服毒生　有缘服毒死
无碍智甘露　所谓大乘典
如是大乘典　亦名杂毒药
如酥醍醐等　及以诸石蜜
服消则为药　不消则为毒
方等亦如是　智者为甘露
愚不知佛性　服之则成毒
声闻及缘觉　大乘为甘露
犹如诸味中　乳最为第一
如是勤进者　依因于大乘
得至于涅槃　成人中象王
众生知佛性　犹如迦叶等
无上甘露味　不生亦不死
迦叶汝今当　善分别三归
如是三归性　则是我之性
若能谛观察　我性有佛性
当知如是人　得入秘密藏
知我及我所　是人已出世
佛法三宝性　无上第一尊
如我所说偈　其性义如是
```

（大意：有人服了甘露，反而伤命早夭；有人服了甘露，寿命得以长存；有人服毒而活，有人因缘不同而服毒致死。无碍智慧的甘露，就是大乘经典；这样的大乘经典，也名为杂毒之药。如酥、醍醐以及石蜜，服后能消化就是药，不能消化就成毒。方等经也是这样，对智者是甘露，愚人不知佛性，服了就成毒。对声闻、缘觉来说，大乘是甘露，犹如诸味之中乳最为第一。这样勤勉精进的人，依靠大乘而到达涅槃，成为人中象王。众生知道佛性，如迦叶等人，得无上甘露之味，不生也不死。迦叶，你现在应当善于分别三归依，这三归依之性就是我之性。若能谛观我性中有佛性，应当知道这人已得入秘密之藏；了知我与我所，这人已经出世。佛法三宝之性，是无上第一尊贵的。我所说的偈，其义理就是如此。）

那时迦叶又说偈：

```
我今都不知　归依三宝处
云何当归趣　无上无所畏
不知三宝处　云何作无我
云何归佛者　而得于安慰
云何归依法　唯愿为我说
云何得自在　云何不自在
云何归依僧　转得无上利
云何真实说　未来成佛道
未来若不成　云何归三宝
我今无预知　当行次第依
云何未怀妊　而作生子想
若必在胎中　则名为有子
子若在胎中　定当生不久
是名为子义　众生业亦然
如佛之所说　愚者不能知
以其不知故　轮回生死狱
假名优婆塞　不知真实义
唯愿广分别　除断我疑网
如来大智慧　唯垂哀分别
愿说于如来　秘密之宝藏
```

（大意：我现在全然不知归依三宝之处，怎样才能归趣无上无所畏的境地？不知三宝之处，怎样修无我？怎样归依佛而得到安慰？怎样归依法？唯愿为我宣说。怎样得自在，怎样不自在？怎样归依僧而辗转得到无上利益？怎样真实地说未来成就佛道？未来若不能成佛，怎能归依三宝？我现在没有预知，应当依次第而行。怎能还未怀孕就作生子之想？若胎儿确实在胎中，才名为有子；孩子若在胎中，必定不久将出生，这才是“子”的意思，众生的业也是如此。如佛所说，愚者不能了知，因为不知，轮回于生死牢狱。我只是假名的优婆塞，不知真实之义，唯愿广为分别，断除我的疑网。如来大智慧者，唯愿垂哀分别，宣说如来秘密的宝藏。）

佛以偈回答：

```
迦叶汝当知　我今当为汝
善开微密藏　令汝疑得断
今当至心听　汝于诸菩萨
则与第七佛　同其一名号
归依于佛者　真名优婆塞
终不更归依　其余诸天神
归依于法者　则离于杀害
归依圣僧者　不求于外道
如是归三宝　则得无所畏
```

（大意：迦叶，你应当知道，我现在为你善加开示微密之藏，令你的疑惑得以断除，现在应当至心听。你在诸菩萨之中，与第七佛同一名号。归依佛的人，才真名为优婆塞，终究不再归依其余诸天神；归依法的人，就远离杀害；归依圣僧的人，不求于外道。这样归依三宝，就能得到无所畏。）

迦叶又说偈：

```
迦叶白佛言　我亦归三宝
是名为正路　诸佛之境界
三宝平等相　常有大智性
我性及佛性　无二无差别
是道佛所赞　正进安止处
亦名正遍见　故为佛所称
我亦趣善逝　所赞无上道
是最为甘露　诸有所无有
```

（大意：迦叶对佛说：我也归依三宝。这名为正路，是诸佛的境界。三宝平等之相，常有大智之性；我性与佛性，无二无差别。这是佛所赞叹之道，是正确精进的安止之处，也名为正遍见，所以为佛所称扬。我也趣向善逝所赞的无上之道，这是最上的甘露，是诸有之中所没有的。）

【按】“汝于诸菩萨，则与第七佛，同其一名号”，第七佛指过去七佛中的迦叶佛，与迦叶菩萨同名。又，迦叶问偈与佛答偈在原文中连写，“迦叶汝当知”以下是佛的回答，“迦叶白佛言”以下又是迦叶的话，这里分开列出，便于阅读。

### 大乘之中三归一体

那时佛告诉迦叶菩萨：“善男子，你现在不应像诸声闻、凡夫之人那样分别三宝。在这大乘之中，没有三归依的分别之相。为什么呢？因为在佛性之中，就有法与僧。为了化度声闻与凡夫，所以分别宣说三宝的不同之相。善男子，若想随顺世间之法，就应分别说有三归依。

“善男子，菩萨应当这样思惟：‘我现在这个身体归依于佛。若就在这身中成就佛道，成佛之后，就不应再恭敬、礼拜、供养诸世尊。为什么呢？诸佛平等，同为众生作归依的缘故。若想尊重法身舍利，就应当礼敬诸佛塔庙。为什么呢？为了化度众生的缘故，也令众生在我身中生起塔庙之想，礼拜供养。这样，众生就以我的法身作为归依之处。一切众生都依止非真的邪伪之法，我当次第为他们宣说真法；又有归依非真僧的人，我当为他们作依止真僧之处；若有分别三归依的人，我当为他们作一归依之处，没有三种差别；对天生盲人，为他们作眼目；又当为诸声闻、缘觉作真实的归依之处。’善男子，这样的菩萨为无量恶的众生以及诸智者作佛事。

“善男子，譬如有人临阵作战时，就生起这样的心念：‘我在这当中最为第一，一切兵众都依恃我。’也如太子这样思惟：‘我将调伏其余的王子，继承大王的帝王之业而得自在，令诸王子都来归依我。’所以不应生起下劣之心。如国王、王子、大臣也是这样。善男子，菩萨摩诃萨也是这样思惟：‘怎样令三事与我一体？’

“善男子，我显示三事就是涅槃。如来名为无上士，譬如人身，头最为上，不是其余的肢节手足等。佛也是这样，最为尊上，不是法与僧。为了化度诸世间，种种示现差别之相，如那阶梯一般。所以你现在不应受持如凡愚人所知的三归差别之相。你对于大乘，应当猛利决断，如锋利的刀。”

迦叶菩萨对佛说：“世尊，我是知道而故问，不是不知道。我是为了大勇猛的菩萨，请问无垢清净的行处，想令如来为诸菩萨广宣分别奇特之事，称扬大乘方等经典。如来大悲，现在已经善说了。我也是这样安住其中。所说的菩萨清净行处，就是宣说《大涅槃经》。世尊，我现在也当广为众生显扬这样的如来秘藏，也当证知真正的三归依处。若有众生能信这部《大涅槃经》，这人自然能了达三归依处。为什么呢？因为如来秘藏中有佛性。凡宣说这部经典的人，都说身中尽有佛性，这样的人就不会远求三归依处。为什么呢？因为在未来世，我身就将成就三宝，所以声闻、缘觉之人以及其余众生，都会依止我，恭敬礼拜。”

佛说：“善男子，因为这个道理，应当正确修学大乘经典。”

【按】此段末句“善男子，以是义故，应当正学大乘经典”，慧远《大般涅槃经义记》判为“如来述劝”，即迦叶说完之后，佛接着劝勉的话，所以有“善男子”的称呼，并非错简。

迦叶又说：“佛性这样不可思议，三十二相、八十种好也不可思议。”

### 我与无我性相无二

那时佛赞叹迦叶菩萨：“善哉，善哉！善男子，你已成就深利的智慧。我现在当再为你善说如何入于如来藏。

“若说我是住著的，就是常法，不离于苦；若说无我，修行净行就无所利益。若说诸法都无有我，这就是断见；若说我是住著的，就是常见。若说一切行无常，就是断见；说诸行是常，又是常见。若说苦，就是断见；若说乐，又是常见。修一切法常的，堕于断见；修一切法断的，堕于常见。如尺蠖虫，必须靠前脚才能移动后足；修常与断的也是这样，必须依靠断与常。

【按】这几句文意较曲折，“修一切法常者堕于断见，修一切法断者堕于常见”，大意是常见与断见互相依待，执其一端必引出另一端，如尺蠖前后相依而行。

“因为这个道理，修其余法为苦的，都名为不善；修其余法为乐的，就名为善；修其余法为无我的，是诸烦恼的部分；修其余法为常的，这就名为如来秘藏，即所谓涅槃，没有窟宅；修其余无常之法的，就是财物；修其余常法的，是说佛、法、僧以及正解脱。应当知道，这样的佛法中道，远离二边而宣说真法，凡夫愚人对此不生疑惑，如羸弱的病人服食了酥之后，气力轻健。

“有无之法，体性不定。譬如四大，其性不同，各自相违，良医善知，随其偏盛而加以调理。善男子，如来也是这样，对于众生犹如良医，知道诸烦恼体相的差别而为他们除断，开示如来秘密之藏，清净佛性常住不变。

“若说有，智者不应染著；若说无，就是妄语。若说有，不应默然，也不应戏论诤讼，只求了知诸法的真性。凡夫之人戏论诤讼，是因为不理解如来微密之藏。

“若说苦，愚人便以为身体是无常；说一切苦，又不能知道身中有乐性。说无常，凡夫之人以为一切身都是无常，譬如瓦器破坏；有智慧的人应当分别，不应全说一切都是无常。为什么呢？我身中就有佛性的种子。若说无我，凡夫会以为一切佛法都没有我；智者应当分别：所说的无我，是说假名不实。这样知道了，就不应生疑。若说如来秘藏空寂，凡夫听了，就生断灭之见；有智慧的人应当分别如来是常，没有变易。若说解脱譬如幻化，凡夫会以为得到真解脱就是磨灭；有智慧的人应当分别，人中狮子虽有去来，却常住不变。

“若说‘无明因缘生诸行’，凡夫之人听了，分别生起二法之想，即明与无明；智者了达其性无二，无二之性就是实性。若说‘诸行因缘生识’，凡夫以为是二，即行与识；智者了达其性无二，无二之性就是实性。若说十善、十恶，可作、不可作，善道、恶道，白法、黑法，凡夫以为是二；智者了达其性无二，无二之性就是实性。若说应当修一切法为苦，凡夫以为是二；智者了达其性无二，无二之性就是实性。若说一切行无常，如来秘藏也是无常，凡夫以为是二；智者了达其性无二，无二之性就是实性。若说一切法无我，如来秘藏也无有我，凡夫以为是二；智者了达其性无二，无二之性就是实性。我与无我，其性无二。如来秘藏的意义就是这样，是不可称计、无量无边的诸佛所赞叹的。我现在在这部成就一切功德的经中，都已宣说了。”

原文：“我与无我，性无有二。”（大意：我与无我，其本性并无二致。）

### 乳中有酪之喻

“善男子，我与无我，性相无二，你应当这样受持顶戴。善男子，你也应当坚持忆念这样的经典。如我先前在《摩诃般若波罗蜜经》中说，我与无我没有二相。

“如因乳生酪，因酪得生酥，因生酥得熟酥，因熟酥得醍醐。这样，酪性是从乳生，还是从自己生，从他物生？乃至醍醐也是如此。若是从他物生，就是他物所作，不是乳所生；若不是乳所生，乳就毫无作用。若是自己生，就不应相似相续而生；若是相续而生，就不是同时俱生；若不是同时俱生，五种味就不是同时存在；虽然不是同时，也一定不是从别处而来。应当知道，乳中先有酪的相，因为甜味多，所以不能自己变化，乃至醍醐也是如此。

“这牛吃了水草，以此因缘，血脉转变而成为乳。若吃了甜草，它的乳就甜；若吃了苦草，乳就有苦味。雪山有一种草，名叫肥腻，牛若吃了，所得的纯是醍醐，没有青、黄、赤、白、黑等颜色；因为吃谷草的因缘，它的乳就有颜色、滋味的不同。这些众生因为明与无明之业的因缘，所以生起二相；若无明转变，就变为明。一切诸法，善与不善等，也是这样，没有二相。”

迦叶菩萨对佛说：“世尊，如佛所说乳中有酪，这是什么意思？世尊，若说乳中确实有酪的相，因为微细所以不可见，为什么又说从乳的因缘而生酪？法若本来没有，才名为生；若已经有了，怎能说生？若说乳中确实有酪相，那么百草之中也应当有乳，乳中也应当有草。若说乳中确实没有酪，为什么因乳而能生出酪？若法本来没有而后生出，为什么乳中不生出草？”

“善男子，不可以确定地说乳中有酪，或乳中无酪，也不可以说是从他物而生。若说乳中确实有酪，为什么体与味各不相同？所以不可以说乳中确实有酪性。若说乳中确实没有酪，乳中为什么不生出兔角？把毒放在乳中，酪就能杀人。所以不可以说乳中确实没有酪性。若说这酪是从他物而生，为什么水中不生出酪？所以不可以说酪是从他物而生。

“善男子，这牛因吃草的因缘，血就变白，草与血灭了之后，以众生的福力，变而成乳。这乳虽然是从草与血而出，却不能说是二，只能名为从因缘而生。酪乃至醍醐也是如此，因为这个道理，得名为牛味。这乳灭了之后，以因缘成为酪。什么因缘？或是酸，或是暖，所以名为从因缘而有，乃至醍醐也是如此。所以不能确定地说乳中没有酪相；说从他物而生，离开乳而有，是不可能的。

“善男子，明与无明也是这样，若与烦恼诸结俱在，名为无明；若与一切善法俱在，名为明。所以我说没有二相。因为这个缘故，我先前说：‘雪山有一种草名叫肥腻，牛若吃了，就成醍醐。’佛性也是这样。善男子，众生福薄，见不到这种草；佛性也是这样，因为被烦恼覆盖，众生见不到。

“譬如大海，虽然同是一种咸味，其中也有上妙之水，味道如乳。譬如雪山，虽然成就种种功德，生出许多药草，也有毒草。众生之身也是这样，虽有四大毒蛇之种，其中也有妙药之王，就是佛性。佛性不是造作之法，只是被烦恼客尘所覆盖。若刹帝利、婆罗门、毗舍、首陀罗能断除烦恼，就能见到佛性，成就无上道。

### 雷声象牙花

“譬如虚空中雷声震动，云起，一切象牙上都生出花纹；若没有雷震，花纹就不生，也没有名字。众生的佛性也是这样，常被一切烦恼所覆盖，不可得见，所以我说众生无我。若得以听闻这大般涅槃微妙经典，就能见到佛性，如象牙上的花纹。虽然听闻契经与一切三昧，不听闻这部经，就不知道如来微妙之相，如没有雷时，象牙上的花纹不可得见。听闻这部经之后，就知道一切如来所说的秘藏佛性，譬如天雷时见到象牙上的花纹。听闻这部经之后，就知道一切无量众生都有佛性。

“因为这个道理，说大涅槃名为如来秘密之藏，能增长法身，犹如雷时象牙上的花纹，能被长养。因为有这样的大义，所以得名为大般涅槃。若有善男子、善女人能习学这大涅槃微妙经典，应当知道这人能报佛恩，是真正的佛弟子。”

【按】“象牙花”是古印度传说：雷声震动时，象牙上会生出花纹。经中以此比喻听闻本经而得见佛性。

### 十住菩萨少分见佛性

迦叶菩萨对佛说：“真是奇特啊，世尊！所说的佛性，甚深甚深，难见难入，是声闻、缘觉所不能理解的。”

佛说：“善男子，是这样，是这样，正如你所赞叹的，不违背我所说。”

迦叶菩萨对佛说：“世尊，佛性为什么甚深、难见、难入？”

佛说：“善男子，如有一百个盲人，为了治眼，来到良医那里。这时良医就用金篦刮去他们眼中的翳膜，伸出一根手指问：‘看见了吗？’盲人答道：‘我还没看见。’又伸出两根、三根手指给他们看，才说稍微看见了。善男子，这大涅槃微妙经典，在如来尚未宣说时也是这样，无量菩萨虽然具足修行诸波罗蜜，乃至到了十住，仍未能见到自己所有的佛性；如来宣说之后，就稍微见到了。这些菩萨摩诃萨见到之后，都这样说：‘真是奇特啊，世尊！我们流转无量生死，常被无我之说所迷惑扰乱。’善男子，这样的菩萨，位阶到了十地，尚且不能明了知见佛性，何况声闻、缘觉之人能见到呢？

“再者，善男子，譬如仰望虚空中的鹅雁，是虚空还是鹅雁？仔细观察不已，才仿佛见到。十住菩萨对如来之性的知见少分也是这样，何况声闻、缘觉之人能知见呢？

“善男子，譬如喝醉的人要走远路，朦胧地看见道路。十住菩萨对如来之性的知见少分也是这样。

“善男子，譬如口渴的人走在旷野之中，被干渴所逼，到处寻找水源，见到一片丛林，树上有白鹤，这人迷乱昏闷，不能分别是树还是水；仔细观察不已，才见到是白鹤和丛林。善男子，十住菩萨对如来之性的知见少分也是这样。

“善男子，譬如有人在大海中，在无量百千由旬之外，远望大船上的楼橹堂阁，心想：‘那是楼橹，还是虚空？’看了很久，才确定知道是楼橹。十住菩萨在自身中见如来之性也是这样。

“善男子，譬如王子身体极为柔弱，通宵游戏，到了清晨，眼睛看一切都不清楚。十住菩萨虽然在自身中见到如来之性，也是这样，不大明了。

“再者，善男子，譬如官吏被王事所拘，夜里才回家，闪电暂时一亮，见到一群牛，心想：‘是牛群，是云，还是房舍？’这人看了很久，虽然生起牛群之想，仍不能确定。十住菩萨虽然在自身中见到如来之性，也是这样，未能确定。

“再者，善男子，如持戒比丘观察无虫的水，却见到似虫之相，心想：‘这里面动的，是虫还是尘土？’看了很久，虽然知道是尘土，也不明了。十住菩萨在自身中见如来之性，也是这样，不大明了。

“再者，善男子，譬如有人在阴暗中远远看见一个小孩，心想：‘那是牛，是人，还是鸟？’看了很久，虽然看出是小孩，仍不明了。十住菩萨在自身中见如来之性，也是这样，不大明了。

“再者，善男子，譬如有人在黑夜中见到一幅菩萨画像，心想：‘这是菩萨像、自在天像、大梵天像，还是染色的衣服？’这人看了很久，虽然心想是菩萨像，也不明了。十住菩萨在自身中见如来之性，也是这样，不大明了。

“善男子，所有的佛性就是这样甚深，难得知见，唯有佛能知，不是声闻、缘觉所能达到的。善男子，智者应当这样分别了知如来之性。”

迦叶菩萨对佛说：“世尊，佛性这样微细难知，肉眼怎能见到？”

佛告诉迦叶：“善男子，如非想非非想天，也不是二乘所能了知，只能随顺契经，因信而知。善男子，声闻、缘觉信顺这样的《大涅槃经》，自知己身中有如来之性，也是这样。善男子，所以应当精勤修习《大涅槃经》。善男子，这样的佛性，唯有佛能知，不是声闻、缘觉所能达到的。”

### 贫人梦呓“刀刀”之喻

迦叶菩萨对佛说：“世尊，非圣的凡夫，有众生之性，都说有我。”

佛说：“譬如有两个人是亲密的朋友，一个是王子，一个是贫贱之人。这两人互相往来。这时贫人见到王子有一把好刀，洁净美妙第一，心中贪著。王子后来拿着这把刀逃到别国去了。贫人后来寄宿在别人家里，在睡梦中说梦话：‘刀！刀！’旁人听到，就把他抓到国王那里。

“当时国王问道：‘你说的刀，可以拿给我看。’这人把以上的事全都告诉国王：‘大王现在即使屠割臣的身体，分裂手足，想要得到那把刀，也实在得不到。臣与王子素来亲厚，以前同在一处，虽然亲眼见过，却连用手碰一下都不敢，何况故意去拿？’国王又问：‘你所见的刀，相貌像什么？’答道：‘大王，臣所见的，像公羊的角。’国王听了，欣然而笑，对他说：‘你现在随意去吧，不要害怕。我的库藏中都没有这样的刀，何况你在王子那里见到？’

“当时国王就问群臣：‘你们见过这样的刀吗？’说完就驾崩了。随即立了其他的儿子继承王位，又问群臣：‘你们曾在官府库藏中见过这把刀吗？’诸臣答道：‘臣等曾见过。’又问：‘它的形状像什么？’答道：‘大王，像公羊角。’国王说：‘我的库藏中怎么会有这样形状的刀？’接连四代国王都检查寻找，都没有找到。

“过了一段时间，先前逃走的王子从别国回到本土，又得为王。登上王位之后，又问诸臣：‘你们见过刀吗？’答道：‘大王，臣等都见过。’又问：‘它的形状像什么？’有的答道：‘大王，它的颜色清净，如优钵罗花。’又有的答道：‘形状像羊角。’又有的答道：‘颜色红赤，犹如火聚。’又有的答道：‘犹如黑蛇。’这时国王大笑：‘你们都没有见到我那把刀的真实之相。’

“善男子，菩萨摩诃萨也是这样，出现于世，宣说我的真相，说了之后就舍去，譬如王子拿着洁净美妙的刀逃到别国。凡夫愚人说一切有我、有我，如那贫人寄宿在别人家里，说梦话‘刀刀’。声闻、缘觉问众生：‘我有什么相？’众生答道：‘我见到我的相，大如拇指。’或说如米，或说如稗子；有的说我相住在心中，炽然如日。这样的众生不知道我相，譬如诸臣不知道刀相。菩萨这样宣说我法，凡夫不知，种种分别，妄作我相，如问刀相而答像羊角。这些凡夫次第相续而生起邪见，为了断除这样的诸邪见，如来示现宣说无我，譬如王子对诸臣说：‘我的库藏中没有这样的刀。’

“善男子，今天如来所说的真我，名为佛性。这样的佛性在我的佛法中，譬如那把洁净的刀。善男子，若有凡夫能善于宣说，就是随顺无上佛法；若有善能分别、随顺宣说这个道理的，应当知道这就是菩萨的相貌。”

## 文字品第十三

【按】本品逐一解说梵文字母（悉昙）的意义。经文以汉字音译梵字，又就每个字母的发音引出一层法义，大多是依梵语词首的谐音来说的。译文保留经中原有的音译字，只将其后的释义译为白话。

### 半字为根本

佛又告诉迦叶：“所有种种异论、咒术、言语、文字，都是佛所说，不是外道所说。”

迦叶菩萨对佛说：“世尊，如来怎样宣说文字的根本？”

佛说：“善男子，最初宣说半字作为根本，用以受持诸记论、咒术、文章以及诸阴实法。凡夫之人学习这字的根本，然后才能知道什么是法、什么是非法。”

迦叶菩萨又对佛说：“世尊，所说的‘字’，其义如何？”

“善男子，有十四个音，名为字义。所说的字，名为涅槃，因为是常，所以不流；若不流，就是无尽；无尽，就是如来金刚之身。这十四个音名为字本。

### 十四音

“短‘阿’，是不破坏的意思。不破坏，名为三宝，比喻如金刚。又，‘阿’是不流的意思，不流就是如来。如来九孔没有流漏，所以不流；又没有九孔，所以不流。不流就是常，常就是如来，如来无作，所以不流。又，‘阿’名为功德，功德就是三宝，所以名为‘阿’。

“其次长‘阿’，名为阿阇梨。阿阇梨是什么意思？在世间中得名为圣者。什么名为圣？圣名为无著，少欲知足，也名为清净，能度众生出三有之流、生死大海，这名为圣。又，‘阿’名为制度，修持净戒，随顺威仪。又，‘阿’名为依止圣人，应当学习威仪进止举动，供养恭敬礼拜三尊，孝养父母，以及学习大乘；善男子、善女人等具持禁戒，以及诸菩萨摩诃萨等，这名为圣人。又，‘阿’名为教诲，如说：‘你们应当这样做，不要这样做。’若有能遮止非威仪之法的，这名为圣人，所以名为‘阿’。

“短‘伊’，就是佛法，梵行广大，清净无垢，譬如满月；你们应当这样做、不应这样做，这是义、这不是义，这是佛说、这是魔说，所以名为‘伊’。

“长‘伊’，佛法微妙甚深难得，如自在天、大梵天王的法名为自在，若能受持，就名为护法。又，自在名为四护世天王，这四位自在者能摄护《大涅槃经》，也能自在地敷扬宣说。又，‘伊’是能为众生自在说法。再者，‘伊’是为了自在而说，说什么呢？就是修习方等经典。再者，‘伊’是为了断除嫉妒，如除去稗草秽物，都能令其转变成为吉祥，所以名为‘伊’。

“短‘忧’，是在诸经中最上最胜、增长上上的，就是大涅槃。再者，‘忧’是如来之性，是声闻、缘觉从未听闻过的，如在一切处中，北郁单越最为殊胜；菩萨若能听受这部经，在一切大众中最上最胜，所以名为‘忧’。

“长‘忧’，譬如牛乳是诸味中的上味，如来之性也是这样，在诸经中最尊最上；若有诽谤的，应当知道这人与牛没有分别。再者，‘忧’是说这人名为无慧正念，诽谤如来微密秘藏，应当知道这人甚可怜悯，远离如来秘密之藏而宣说无我之法，所以名为‘忧’。

“'□‘，就是诸佛的法性涅槃，所以名为’□‘。

【按】此字在《大正藏》中为罕用字，由“口”与“垔”组成，先前电子文本未能显示，这里以□存之。依十四音的次第，这是梵文的 e 音字母，诸经多译作“咽”“翳”。下一字“野”，宋、元、明本作“黳”。

“‘野’，是如来的意思。再者，‘野’是如来进止屈伸、举动，无不利益一切众生，所以名为‘野’。

“‘乌’，名为烦恼的意思，烦恼名为诸漏，如来永断一切烦恼，所以名为‘乌’。

“‘炮’，是大乘的意思，在十四音中是究竟之义；大乘经典也是这样，在诸经论中最为究竟，所以名为‘炮’。

“‘庵’，能遮止一切诸不净之物，在佛法中能舍弃一切金银宝物，所以名为‘庵’。

“‘痾’，名为胜乘的意思。为什么呢？这大乘经典《大涅槃经》在诸经中最为殊胜，所以名为‘痾’。

### 诸辅音

“‘迦’，是对诸众生生起大慈悲，生起子想，如罗睺罗，作妙善之义，所以名为‘迦’。

“‘呿’，名为非善友。非善友名为杂秽，不信如来秘密之藏，所以名为‘呿’。

“‘伽’，名为藏。藏就是如来秘藏，一切众生都有佛性，所以名为‘伽’。

“重音‘伽’，是如来常住之音。什么名为如来常住之音？就是如来常住不变，所以名为‘伽’。

“‘俄’，是一切诸行破坏之相，所以名为‘俄’。

“‘遮’，就是修习的意思，调伏一切众生，名为修习之义，所以名为‘遮’。

“‘车’，是如来荫庇一切众生，譬如大伞盖，所以名为‘车’。

“‘阇’，是正解脱，没有衰老之相，所以名为‘阇’。

“重音‘阇’，是烦恼繁茂，譬如稠密的森林，所以名为‘阇’。

“‘若’，是智慧的意思，了知真实法性，所以名为‘若’。

“‘吒’，是在阎浮提示现半身而演说法，譬如半月，所以名为‘吒’。

“‘侘’，是法身具足，譬如满月，所以名为‘侘’。

“‘茶’，是愚痴之僧，不知常与无常，譬如小孩，所以名为‘茶’。

“重音‘茶’，是不知师恩，譬如公羊，所以名为‘茶’。

“‘拏’，是非圣的意思，譬如外道，所以名为‘拏’。

“‘多’，是如来在那里告诉诸比丘：‘应当远离惊畏，我当为你们宣说微妙之法。’所以名为‘多’。

“‘他’，名为愚痴的意思，众生流转生死，自己缠缚如蚕作茧，所以名为‘他’。

“‘陀’，名为大施，就是大乘，所以名为‘陀’。

“重音‘陀’，是称赞功德，就是三宝，如须弥山，高峻广大，没有倾倒，所以名为‘陀’。

“‘那’，是三宝安住，没有倾动，譬如门槛，所以名为‘那’。

“‘波’，名为颠倒的意思。若说三宝全都灭尽，应当知道这人是自己疑惑，所以名为‘波’。

“‘颇’，是世间的灾难。若说世间灾难兴起之时，三宝也会灭尽，应当知道这人愚痴无智，违失圣意，所以名为‘颇’。

“‘婆’，名为佛的十力，所以名为‘婆’。

“重音‘婆’，名为重担，能堪任荷负无上正法，应当知道这人是大菩萨，所以名为‘婆’。

“‘摩’，是诸菩萨严峻的制度，就是大乘大般涅槃，所以名为‘摩’。

“‘邪’，是诸菩萨在一切处为众生宣说大乘法，所以名为‘邪’。

“‘啰’，能破坏贪欲、瞋恚、愚痴，宣说真实之法，所以说‘啰’。

“轻‘罗’，名为声闻乘动转不住，大乘安稳没有倾动；舍弃声闻乘，精勤修习无上大乘，所以名为‘罗’。

“‘和’，是如来世尊为众生降下大法雨，就是世间的咒术经书，所以名为‘和’。

“‘赊’，是远离三箭，所以名为‘赊’。

“‘沙’，名为具足的意思，若能听受这部《大涅槃经》，就已得以听闻受持一切大乘经典，所以名为‘沙’。

“‘娑’，是为众生演说正法，令其心生欢喜，所以名为‘娑’。

“‘呵’，名为心生欢喜：‘奇哉世尊，离一切行！怪哉如来，入般涅槃！’所以名为‘呵’。

“‘罗’，名为魔的意思，无量诸魔不能毁坏如来秘藏，所以名为‘罗’。再者，‘罗’是乃至示现随顺世间，有父母妻子，所以名为‘罗’。

“‘鲁、流、卢、楼’，这四字说有四种意义，就是佛、法、僧以及对法。所说的对法，是随顺世间，如提婆达多示现破坏僧团，化作种种形貌色像，是为了制戒的缘故；智者了达，不应对此生起畏怖，这名为随顺世间之行，所以名为‘鲁流卢楼’。

【按】“鲁流卢楼”四字即梵文的 ṛ、ṝ、ḷ、ḹ 四个流音字母，经中把它们放在辅音之后另说。“三箭”指贪、瞋、痴三毒，如箭伤人。

### 半字与满字

“吸气时舌根随鼻发出的声音，长短与超声，随着发音而理解意义，都是因为舌与齿而有差别。这样的字义，能令众生口业清净。众生的佛性则不是这样，不必假借文字然后才得清净。为什么呢？因为佛性本来清净，虽然处在阴、界、入之中，却不同于阴、入、界，所以众生都应当归依。诸菩萨等因为佛性的缘故，平等看待众生，没有差别。

“所以半字是诸经书、记论、文章的根本。又，半字的意义，都是烦恼言说的根本，所以名为半字。满字，是一切善法言说的根本。譬如世间作恶行的人，名为半人；修善行的人，名为满人。这样，一切经书记论，都以半字作为根本。

“若说如来以及正解脱入于半字，这事不对。为什么呢？因为离于文字。所以如来对一切法无碍无著，真得解脱。

“什么名为理解字义？若有人知道如来出现于世，能灭除半字，这名为理解字义。若有人追逐半字之义，这人不知道如来之性。

“什么名为无字义？亲近修习不善法的人，名为无字。又，无字是虽能亲近修习善法，却不知如来是常还是无常、是恒还是非恒，以及法、僧二宝，是律非律，是经非经，魔说佛说；若有不能这样分别的，这名为追逐无字之义。我现在已说了这样追逐无字的意义。善男子，所以你现在应当远离半字，善于理解满字。”

【按】“众生佛性则不如是假于文字然后清净”一句，依下文“性本净故”，意思是：佛性不像口业那样要借助文字才得清净，因为佛性本来清净。

迦叶菩萨对佛说：“世尊，我们应当善学字数。现在我值遇无上之师，已经领受如来殷勤的教诲。”

佛赞叹迦叶：“善哉，善哉！乐于正法的人应当这样学。”

## 鸟喻品第十四

### 鸳鸯与迦邻提鸟

那时佛告诉迦叶菩萨：“善男子，鸟有两种，一名迦邻提，一名鸳鸯，游止都在一起，互不舍离。苦、无常、无我等法也是这样，不得相离。”

迦叶菩萨对佛说：“世尊，苦、无常、无我，为什么如那鸳鸯与迦邻提鸟？”

佛说：“善男子，有不同的法是苦，有不同的法是乐；有不同的法是常，有不同的法是无常；有不同的法是我，有不同的法是无我。譬如稻米不同于麻麦，麻麦又不同于豆、粟、甘蔗。这些种子从萌芽乃至花叶，都是无常；果实成熟，人们受用的时候，才名为常。为什么呢？因为其性真实。”

迦叶对佛说：“世尊，这些东西若是常，与如来相同吗？”

佛说：“善男子，你现在不应这样说。为什么呢？若说如来如须弥山，劫坏之时须弥山崩倒，如来那时难道也一同毁坏吗？善男子，你现在不应受持这样的意义。善男子，一切诸法，除了涅槃，再没有一法是常的，只是以世俗谛说果实为常。”

迦叶菩萨对佛说：“世尊，善哉，善哉！正如佛所说。”

佛告诉迦叶：“是这样，是这样。善男子，虽然修习一切契经与诸禅定，乃至未曾听闻大般涅槃，都说一切都是无常。听闻这部经之后，虽有烦恼，却如同没有烦恼，就能利益一切人天。为什么呢？因为明了自身中有佛性，这名为常。

“再者，善男子，譬如庵罗树，花刚开时，名为无常之相；若结成果实，多所利益，才名为常。善男子，也是这样，虽然修习一切契经与诸禅定，未曾听闻这样的大涅槃时，都说一切都是无常；听闻这部经之后，虽有烦恼，却如同没有烦恼，就能利益一切人天。为什么呢？因为明了自身中有佛性，这名为常。

“再者，善男子，譬如金矿熔化之时，是无常之相；熔化后成为金子，多所利益，才名为常。善男子，也是这样，虽然修习一切契经与诸禅定，未曾听闻这样的大涅槃时，都说一切都是无常；听闻这部经之后，虽有烦恼，却如同没有烦恼，就能利益一切人天。为什么呢？因为明了自身中有佛性，这名为常。

“再者，善男子，譬如胡麻未被压榨时，名为无常；压榨成油之后，多有利益，才名为常。善男子，虽然修习一切契经与诸禅定，未曾听闻这样的大涅槃时，都说一切都是无常；听闻这部经之后，虽有烦恼，却如同没有烦恼，就能利益一切人天。为什么呢？因为明了自身中有佛性，这名为常。

“再者，善男子，譬如众流都归于大海，一切契经、诸定、三昧，都归于大乘《大涅槃经》。为什么呢？因为它究竟善说有佛性。善男子，所以我说有不同的法是常，有不同的法是无常，乃至无我也是如此。”

### 如来有忧无忧

迦叶菩萨对佛说：“世尊，如来已经远离忧悲的毒箭。所谓忧悲，名为天，如来不是天；忧悲名为人，如来不是人；忧悲名为二十五有，如来不在二十五有之中。所以如来没有忧悲，为什么又说如来有忧悲？”

“善男子，无想天名为无想；若无想，就没有寿命；若没有寿命，怎么会有阴、界、诸入？因为这个道理，无想天的寿命不可说有所住之处。善男子，譬如树神依树而住，不能确定说依于枝、依于节、依于茎、依于叶，虽然没有确定的处所，却不能说没有。无想天的寿命也是这样。

“善男子，佛法也是这样，甚深难解。如来实在没有忧悲苦恼，而对众生生起大慈悲，示现有忧悲，看待众生如罗睺罗。

“再者，善男子，无想天中所有的寿命，唯有佛能知，不是其余的人所能达到的，乃至非想非非想处也是如此。迦叶，如来之性清净无染，犹如化身，怎会有忧悲苦恼？若说如来有忧悲，怎能利益一切众生、弘广佛法？若说没有，怎么说平等看待众生如罗睺罗？若不平等看待如罗睺罗，这样的话就是虚妄。因为这个道理，善男子，佛不可思议，法不可思议，众生佛性不可思议，无想天的寿命不可思议；如来有忧与无忧，是佛的境界，不是声闻、缘觉所能了知的。

“善男子，譬如空中，舍宅与微尘不能住立；若说舍宅不因虚空而住，没有这样的道理。因为这个道理，不可说舍宅住于虚空或不住于虚空。凡夫之人虽然说舍宅住于虚空，而这虚空实在无所住。为什么呢？因为其性无住。善男子，心也是这样，不可说住于阴、界、入，也不可说不住。无想天的寿命也是这样，如来的忧悲也是这样。若没有忧悲，怎么说平等看待众生如罗睺罗？若说有，又怎么说其性如同虚空？

“善男子，譬如幻术师，虽然化作种种宫殿、杀生、养育、系缚、放舍，以及化作金银琉璃宝物、丛林树木，都没有实性。如来也是这样，随顺世间，示现忧悲，并无真实。善男子，如来已入大般涅槃，怎会有忧悲苦恼？若说如来入于涅槃是无常，应当知道这人就有忧悲；若说如来不入涅槃，常住不变，应当知道这人没有忧悲。如来有忧与无忧，没有人能知道。

“再者，善男子，譬如下等的人能知下等之法，不知中等与上等；中等的人知中等，不知上等；上等的人知上等，也知中等与下等。声闻、缘觉也是这样，只知道自己的地位；如来不是这样，完全知道自己的地位以及其他的地位，所以如来名为无碍智。示现幻化，随顺世间，凡夫以肉眼以为是真实的，而想穷尽了知如来无碍无上的智慧，没有这样的事。有忧与无忧，唯有佛能知。因为这个缘故，有不同的法是有我，有不同的法是无我，这名为鸳鸯与迦邻提鸟之性。

“再者，善男子，佛法犹如鸳鸯共行。这迦邻提鸟与鸳鸯，盛夏水涨时，选择高原安置它们的雏鸟，为了长养的缘故；然后随其本性，安稳地游行。如来出世也是这样，化度无量众生，令他们安住正法，如那鸳鸯与迦邻提鸟选择高原安置雏鸟。如来也是这样，令众生所作已办之后，就入于大般涅槃。善男子，这名为有不同的法是苦，有不同的法是乐：诸行是苦，涅槃是乐，第一微妙，因为破坏了诸行。”

### 不放逸是甘露

迦叶菩萨对佛说：“世尊，为什么众生得到涅槃名为第一乐？”

佛说：“善男子，如我所说，诸行和合，名为老死。

```
谨慎无放逸　是处名甘露
放逸不谨慎　是名为死句
若不放逸者　则得不死处
如其放逸者　常趣于死路
```

（大意：谨慎而不放逸，这里名为甘露；放逸而不谨慎，这名为死亡之道。若不放逸，就能得到不死之处；若放逸，就常走向死路。）

“放逸，名为有为法，这有为法是第一苦；不放逸，就名为涅槃，那涅槃名为甘露，是第一最乐。若趣向诸行，这名为死处，受第一苦；若到达涅槃，就名为不死，受最妙之乐。若不放逸，虽然聚集诸行，这也名为常乐不死、不破坏之身。

“什么是放逸，什么是不放逸？非圣的凡夫，这名为放逸，是常死之法；出世的圣人，是不放逸，没有老死。为什么呢？因为入于第一常乐的涅槃。因为这个道理，有不同的法是苦，有不同的法是乐，有不同的法是我，有不同的法是无我。

“如人在地上仰观虚空，见不到鸟迹。善男子，众生也是这样，没有天眼，在烦恼之中，自己见不到自身中有如来之性，所以我说无我的秘密之教。为什么呢？没有天眼的人不知道真我，横计有我，因为诸烦恼所造作的有为法，就是无常，所以我说有不同的法是常，有不同的法是无常。

```
精进勇健者　若处于山顶
平地及旷野　常见诸凡夫
升大智慧殿　无上微妙台
既自除忧患　亦见众生忧
```

（大意：精进勇健的人，如处在山顶，常见平地与旷野中的诸凡夫；登上大智慧之殿、无上微妙之台，既已自己除去忧患，也见到众生的忧患。）

“如来完全断除无量烦恼，住在智慧之山，见到众生常在无量亿烦恼之中。”

迦叶菩萨又对佛说：“世尊，如偈中所说，这意义恐怕不对。为什么呢？入涅槃的人没有忧也没有喜，怎么能登上智慧台殿？又怎么会住在山顶而见到众生？”

佛说：“善男子，智慧殿就名为涅槃；没有忧患的，是说如来；有忧患的，名为凡夫人。因为有凡夫之忧，所以说如来无忧。须弥山顶，是说正解脱；勤精进，比喻须弥山没有动转；地，是说有为之行，这些凡夫安住在这地上，造作诸行。那有智慧的人，就名为正觉，离于诸有而常住，所以名为如来。如来怜悯无量众生常被诸有的毒箭所射中，所以名为如来有忧。”

迦叶菩萨又对佛说：“世尊，若如来有忧悲，就不能称为等正觉。”

佛说：“迦叶，都有因缘。凡有众生应受教化之处，如来就在其中示现受生；虽然示现受生，而实际上并无生，所以如来名为常住之法，如迦邻提、鸳鸯等鸟。”
