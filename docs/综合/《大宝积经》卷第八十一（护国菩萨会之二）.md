# 《大宝积经》卷第八十一（护国菩萨会之二）

隋·三藏法师阇那崛多 译

## 护国菩萨会第十八之二

【按】译者题名，元、明本作“隋北天竺三藏阇那崛多”（元本“译”作“初译”）；宋、宫本“阇那崛多”作“阇那耶舍”。

#### 焰意王与福焰王子

那时佛又告诉护国说：“护国！我忆念往昔，过去无量阿僧祇劫，又过阿僧祇劫，不可称量，不可思惟，没有譬喻，不可计算，不可得说。那时有佛出世，名为成利慧多陀阿伽度、阿罗诃、三藐三佛陀、明行足、善逝、世间解、无上士、调御丈夫、天人师、佛、世尊。那时有一位王名为焰意。护国！那焰意王治理教化之时，这阎浮提纵广一万六千由旬。护国！那时这阎浮提内有二万座城，每一座城有千俱致户人家。护国！那时焰意王自己所住的城名为宝光明，东西十二由旬，南北七由旬，由七宝所成。有七重宝墙围绕，每一重墙之间相距八步，牢固难坏。护国！那国的众生寿命十俱致那由他岁。

【按】“墙间”之“间”，宫本作“门”。

“护国！那时焰意王初生一个儿子，名为福焰，端正殊特，身色具足，世间无双，见者无厌。护国！那王子初生之日，在他出生之处有七宝藏自然出现，王宫内也有七宝藏自然出现，高达七人。护国！那王子出生时，阎浮提内一切众生都大欢喜，踊跃无量，若有众生被关押在牢狱、身带枷锁的，自然得到解脱。护国！那福焰王子对世间所有的工巧技艺，七日之内都学成了。

#### 净居天劝诫莫放逸

“护国！那福焰王子在清晨时分，有净居诸天来告诉王子说：‘童子！你不要放逸，应当善观无常。童子！生命不会久停，到达后世就是这样迅速，必须常常观察，生起大怖畏，所造之业必定受报，如影随形。’那时净居诸天又为童子说这偈道：

```
童子谨慎莫放逸，
亦莫随顺放逸者，
弃舍放逸佛所赞，
若受放逸诸佛诃。
常自调顺不放逸，
一切能施无妬嫉，
慈悲念于诸众生，
彼人不久当作佛。
```
（大意：童子谨慎，不要放逸，也不要随顺放逸的人，舍弃放逸为佛所称赞，若受于放逸则为诸佛所呵责。常自调顺而不放逸，能施一切而没有嫉妒，以慈悲心念众生，此人不久当作佛。）

```
过去无量佛，现在及未来，
一切从善起，住不放逸道。
饮食及衣服，金银璎珞等，
俱致劫布施，为求无上道。
手足耳鼻等，求者欢喜施，
真心求功德，不久得成佛。
王位威势力，妻子及眷属，
有为如幻化，速舍莫恋著。
寿命不久停，如坏器易坏，
假借世不久，此亦无常定。
父母及眷属，恶道无能救，
众生造善恶，如影恒逐形。
多求于欲海，相害不为利，
而无济拔者，虚受疲劳苦。
```
（大意：过去无量诸佛，以及现在与未来的佛，一切都从善而起，住于不放逸之道。以饮食与衣服、金银、璎珞等，经俱致劫布施，为求无上道。手足耳鼻等，乞求者来便欢喜布施，以真心求功德，不久便得成佛。王位、威势之力、妻子以及眷属，有为之法如同幻化，应迅速舍弃，不要恋著。寿命不会久停，如破器容易损坏，借来的世间之身不会长久，这也是无常的定则。父母以及眷属，在恶道中不能救护，众生所造的善恶，如影子常随形体。多求于欲海，相互残害而无利益，没有能救拔的人，白白承受疲劳之苦。）

【按】“无常定”之“定”，宋、元、明、宫本作“净”。

```
今欲作他利，求寂无上道，
干枯皮肉髓，汝莫以为苦。
诸佛出世难，寂灭法难闻，
勤事善知识，能破诸魔众。
舍离恶知识，能住于正道，
遮蔽恶邪径，善哉精进住。
汝莫惜身命，持心如金刚，
正问诸师道，莫舍正信意。
一切过去佛，常乐阿兰若，
汝应顺彼学，应乐在空闲。
弃舍于恩爱，妻子眷属等，
己身及寿命，以求广大智。
```
（大意：现在想作利益他人之事，求取寂灭的无上道，即使皮肉骨髓干枯，你也不要以为是苦。诸佛出世难值，寂灭之法难闻，勤于奉事善知识，能破诸魔众。舍离恶知识，能住于正道，遮断邪恶之路，善哉，精进安住。你不要爱惜身命，持心如金刚，正确地向诸师请问道法，不要舍弃正信之意。一切过去佛常乐于阿兰若，你应当随顺他们修学，应当乐在空闲之处。舍弃恩爱、妻子眷属等，以及自身与寿命，以求广大之智。）

#### 王子十年不乐与胜喜乐城

那时世尊又告诉护国菩萨说：“善男子！那福焰王子从诸天听闻此偈之后，十年之内未曾睡眠，未曾嬉笑，未曾歌舞，未曾喜乐，未曾踊跃，未曾放逸，不入园苑，不乐眷属，不贪王位，对资财城郭不生乐心，像这样一切内外诸物都弃舍，只入禅定，住于静室而自己思惟：‘一切法无常，无强无力，没有坚牢，暂时显现而又灭去。王位无味，没有自在，恩爱别离，怨憎相会，没有可贪著的，妄生爱乐都是由于愚痴，虚妄诳惑，没有一样是真实的，唯有解脱寂灭为乐。而众凡夫被愚痴所醉，常乐处于其中，横生优劣之相。我现在在这凡愚众中，应当安住默然，思惟不放逸。’

“护国！那时那焰意大王为这童子另外建立一座城，名为胜喜乐，有七重宝墙围绕。那城南北有七百条街巷，街巷的墙壁由七宝所成，以金铃罗网覆盖其上，又以真珠众宝罗网重复覆盖其上。每一条巷首都有八万四千根宝柱，在宝柱上系着六万条宝绳相互钩连，宝绳之间悬挂十四俱致棵宝多罗树，微风吹动，发出美妙的声音，犹如百千种音乐不鼓自鸣。每一条街巷首安置五百位童女与盛壮少年，善解歌舞，是为了令一切众生爱乐。那焰意王又再告令一切人：‘你们众人从今以后，昼夜不要作其他事，只作歌舞嬉戏，令众生欢喜受乐。四方来的人都令他们欢喜，乃至不许说出一句粗话。’想令王子心生爱乐。又在巷首安置种种布施之具，就是衣服、饮食、璎珞、床铺毡褥、车乘辇舆、象马牛羊、五行之具，金、银、琉璃、砗磲、玛瑙、珊瑚、琥珀、真珠等宝，涂香、末香、烧香、熏香、种种花鬘等。若需要衣服的给衣服，需要食物的给食物，需要饮料的给饮料，需要车乘的给车乘，随其所需而施与。又在各处安置珍宝等堆聚，准备给众人受用。又在城中造作宫殿，准备作为王子游戏之处。那地面都以众宝间错铺成，在城上建起大高楼，以众宝庄严。在城中央造一座大殿，殿内安置千万张床铺。在殿的四边造种种园苑，那园苑内有种种树木，一切花果与令人喜乐的树木具足充满。

【按】“车𤦲”之“𤦲”，宫本作“渠”。“虎魄”之“魄”，宫本作“珀”。

“护国！那园苑中造有七宝池，池的四面有四种宝阶道。哪四种？就是金、银、琉璃、颇梨。在一面有两只狮子，由百宝所成。那两只狮子各自吐出香水注入池内。那池的四边又各有两只宝狮子，各自引水流出池外，池中常有优钵罗花、波头摩花、俱物头花、奔陀利花。那池的四岸有宝树围绕，又有树木与种种花果周匝遍满。又有八百棵宝树，这些宝树以宝绳相互连系，每一棵宝树各悬缯幡。那池的四面又有亿数宝多罗树，在树间系着宝绳，悬挂金铃，微风吹动，发出微妙的声音，如百千种音乐不鼓自鸣。怕有尘埃，以大宝网覆盖地上。在那殿内安置千万张七宝床铺，每一张宝床上各铺五百种褥子。在殿中间设一个高座，那座由七宝所成，高于七人，又在座上铺八万俱致件微妙衣服。在那高座前放置宝香炉，焚烧沉水香，昼夜各三次散种种名花。以金罗网覆盖殿上，那罗网边悬挂金莲花，又以真珠罗网覆盖在金网上，又有八万颗明净珍宝作为光明。在那园内又放置九百万个宝聚，每一个宝聚高一由旬，放出大光明，照耀那世界。

【按】“颇梨”之“颇”，《大正藏》作“玻”，今依CBETA作“颇”。“覆地上”之“地”，宋、元、明、宫本作“池”。

“护国！在那园内又有种种鸟，就是鹦鹉、鸲鹆、鸿鹤、俱系罗鸟、孔雀、鹅、雁，以及鸳鸯、俱那罗鸟、迦陵频伽鸟、命命鸟。那些鸟若想鸣叫时，都发出人声，微妙和雅，犹如诸天欢喜园内诸鸟的声音，凡所发出的声音，都是为了令王子生起欢喜。又另外为王子建立厨房，每日备办五百种味供养王子。

【按】“迦陵频伽”之“伽”，《大正藏》作“迦”，宫本作“伽”，今依CBETA（所录高丽藏）作“伽”。

“那时大王又敕令国内各城邑的一切童子都来集会，童子之数共有八十俱致。那些童子，有的年方二十，有的超过二十，都能善解一切工巧技艺，装束鲜洁，都令他们进入胜喜乐城。那些童子各有父母，又送来千万俱致名婇女，准备给童子们驱使役用，童子的眷属也都奉献千万名童女作为给使，乃至国内的大富长者以及人民，也各送来千万俱致名婇女。这些婇女年方十六，不高不矮，不白不黑，不粗不细，都端正无比，世间无双，善解音乐以及歌舞，善于嬉笑，言语调柔，颜色和悦，无论老少都能安慰劝喻，一切技能都善于通达，身相具足，口中香气如优钵罗花，身上诸毛孔散发栴檀香，微妙清洁，犹如天女。福焰王子处在这宫内，婇女众等常作音乐，种种供养。那时王子听到这音乐之后，这样想：‘现在这些人是我的大怨仇，夺去我的善法。我应当弃舍。’

【按】“胜喜乐城”之“喜”，宫本作“善”（下同）。

“王子那时见到种种乐事，不喜不乐，譬如男子临被处死，虽然见到美色也不生欢喜。像这样，福焰王子在那些女众之中时心无欢喜，在那城内与诸眷属一同聚会也不欢喜。从此以来经过十年，不取色相，不取声、香、味、触等相，只这样想：‘我现在何时能脱离这些怨仇？我何时能行不放逸而得解脱？’那时众女对焰意王说：‘大天应当知道，现在这王子与我们相聚，不相喜乐，也不受乐。’”

【按】“从是已来”之“已”，宋、元、明、宫本作“以”。“大天”之“天”，元、明本作“王”。

#### 父王以偈劝乐

佛说：“护国！那时焰意王与八万小王前后围绕，前往福焰王子之所。到后泪流满面，遍身战抖，不能自持，忧愁苦恼，昏闷倒地。片刻又起来，起身向福焰王子说偈道：

【按】“躄地”之“躄”，宫本作“擗”。“复起，起向”之第二“起”，明、宫本作“趣”。

```
汝有最妙大果报，
有谁为汝作不善，
而不受于最胜乐，
汝不受乐我忧苦，
愿汝受乐施我喜，
若有触扰向我说，
我能与彼极重罪。
汝观此城妙莲花，
是我思惟为汝作，
世间所少速当说，
我能示现如帝释。
汝今面目如青莲，
云何颦眉不畅适？
今此婇女甚殊特，
微妙清净等诸天，
各各善解诸伎术，
歌舞音乐悉能通。
汝应与此相娱乐，
云何忧愁如毒箭？
汝今应当快受乐，
```
（大意：“你有最妙的大果报，有谁对你作了不善之事，使你不受最胜之乐？你不受乐，我便忧苦，愿你受乐，给我欢喜，若有人触扰你，告诉我，我能给他极重的罪罚。你看这城如美妙的莲花，是我思惟为你建造的，世间所缺少的东西，赶快说出来，我能示现如帝释一样。你现在面目如青莲，为什么皱眉不舒畅？现在这些婇女甚为殊特，微妙清净，等同诸天，各各善解种种技艺，歌舞音乐都能通达。你应当与她们相娱乐，为什么忧愁如中毒箭？你现在应当快乐受用，不是忧愁苦恼的时候。）

【按】“颦眉”之“颦”，宫本作“频”。

```
非是忧愁苦恼时。
园林池苑甚茂盛，
花果枝叶欝扶疎，
宽博如天妙果林。
汝今正是上年时，
颜色憔悴如枯花，
但应受乐莫忧苦。
流泉浴池犹如天，
微妙香水洗浴身，
诸花开敷群蜂遶，
汝今云何不爱乐？
鹅鴈鹦鹉及鸿鹤，
命命俱那微妙声，
香山雪山无有异，
谁有见闻不爱乐？
众宝胜殿真珠网，
琉璃严净如天宫，
宝座庄严妙衣覆，
金铃罗网出妙音，
种种音声甚殊特。
街衢道路及巷首，
千数婇女作音乐，
犹如喜园天玉女，
何故迷乱不受乐？
童子婇女如天身，
为汝受乐故聚集，
父母为汝泣堕泪，
我如丧失所爱子，
愁忧怅怏何可住。
```
（大意：园林池苑甚为茂盛，花果枝叶繁茂扶疏，宽广如天上的妙果林。你现在正是青年之时，颜色憔悴如枯萎的花，只应受乐，不要忧苦。流泉浴池犹如天上，以微妙的香水洗浴其身，诸花盛开，群蜂环绕，你现在为什么不爱乐？鹅、雁、鹦鹉以及鸿鹤，命命鸟、俱那罗鸟的微妙之声，与香山、雪山没有差异，谁见闻了会不爱乐？众宝殊胜的宫殿，真珠罗网，琉璃严净如天宫，宝座庄严，妙衣覆盖，金铃罗网发出妙音，种种音声甚为殊特。街衢道路以及巷首，千数婇女作音乐，犹如欢喜园中的天上玉女，为什么迷乱而不受乐？童子与婇女如同天身，为了让你受乐而聚集，父母为你哭泣落泪，我如同丧失了所爱的儿子，忧愁惆怅，怎么能安住？”）

【按】“妙果林”之“果”，宋、宫本作“车”。“上年时”之“上”，明本作“少”。“怅怏”之“怏”，《大正藏》作“快”，今依CBETA（所录高丽藏）作“怏”。“何可住”之“住”，宋、元、明、宫本作“任”。

#### 王子以偈答父

“那时福焰王子以偈回答父王说：

```
如彼具足功德者，
观诸有为生死苦，
厌离烦恼欲求脱，
弃舍一切世间欲。
见诸众生没死网，
常求解脱远欲乐，
思惟菩提最为胜，
唯愿父王听我说。
无人为我作恶事，
我自不乐诸欲乐，
一切恩爱如怨讐，
增长烦恼向恶趣。
此诸婇女愚人乐，
增长魔业系缚缠，
远离功德增不善，
又令未来堕恶趣。
诸圣呵责此五欲，
我今云何乐苦本？
如此婇女假外色，
唯有皮囊盛筋骨，
肉血𡱁尿内不净，
此真死尸云何乐？
歌舞音乐伎术等，
如幻如梦诳愚痴，
```
（大意：“如那些具足功德的人，观察诸有为法与生死之苦，厌离烦恼，想求解脱，弃舍一切世间之欲。见到众生沉没于死亡之网，常求解脱，远离欲乐，思惟菩提最为殊胜，唯愿父王听我说。没有人对我作恶事，是我自己不乐种种欲乐，一切恩爱如同怨仇，增长烦恼，趣向恶道。这些婇女是愚人之乐，增长魔业与系缚的缠绕，远离功德，增长不善，又令未来堕入恶趣。诸圣呵责这五欲，我现在怎能乐于苦的根本？如这些婇女，只是假借的外表之色，只有皮囊盛着筋骨，肉、血、屎、尿，内中不净，这真是死尸，怎能爱乐？歌舞音乐与技艺等，如幻如梦，诳惑愚痴之人，愚痴分别，失去正道，我怎会随顺而作爱欲之业？）

【按】“没死网”之“没”，元、明本作“投”。“𡱁”字先前电子文本未能显示，今据《大正藏》补出，即“屎”字；宋、元、明、宫本作“屎”。

```
愚痴分别失正道，

#### 王子思惟生死过患

那时世尊告诉护国菩萨说：“护国！那时福焰王子从诸天听闻赞叹佛的功德，乃至法、僧的功德之后，欢喜踊跃，不能自持。护国！那时福焰王子又这样想：‘这样的诸佛世尊有这样的大众，成就这样觉悟所证的最胜妙法，这样成就的圣众弟子，我却不得见。我现在值遇生死的种种恶苦恼，这样的生死没有义利。凡夫们执著我见，在家多有过患，贪欲无厌，为智者所呵毁，被放逸无明的黑暗所覆蔽。这样的诸行难以穿透，这样的识心甚难降伏，这样的名色甚深难以觉知，这样的六入不得自在，这样的恶触领受果报，这样的愚痴多有过患，这样的渴爱坚固系缚而不舍，这样的诸取甚难舍离，这样的诸有没有圣道，这样的生甚难解脱，这样的老能毁坏少年，这样的病损减壮盛之色，这样的死没有润泽，这样的生多有衰恼，这样的往来没有利益。这样微妙的如来正教甚为可爱。怎能因为爱好的缘故，被种种烦恼迷惑其心，被种种恶觉浊乱而不清净？心常放逸，常与愚痴之辈为友；不善思惟，心常染著烦恼生死；乐于恶知识，常与这样的恶人在一起。尚且不能成办世间的清净善事，何况能得阿耨多罗三藐三菩提。像我现在，便从这楼的东面投身而去，若从门出，恐怕诸眷属会作障碍。’”

（大意：我现在如贫人，愿尊者摄受；我现在被系缚，愿尊者能为我解开；我心中大有疑惑，愿决断我的痴网。请指示我修行之处，怎样得菩提？我现在沉没于大水中，愿指示济度我；我处在大黑暗中，愿燃起大法炬；我身上有大疮，愿治疗令其迅速痊愈；我身上有毒箭，愿尊者能为我拔出；常堕于恶道，愿以慈悲救济我。种种执著的人，令他们回邪住于正道，我沉没于忧戚之河，愿度我到彼岸，得住于八圣道。我的寿命短促，求善多有障碍，愿从今以后，得住于真如之命。我现在身得闲静，已离开种种难处，作福必定获报，愿为我决断疑惑。世尊请为我宣说，菩萨怎样不放逸而趣向无上道，未来证得菩提，能解开诸有的系缚。”）

#### 王子得陀罗尼以偈赞佛

那时佛告诉护国菩萨说：“护国！那时吉利意如来知道福焰王子的心之后，为他广说诸菩萨行。那福焰王子听闻此法之后，便得陀罗尼，名为解脱，也得五神通。当即上升虚空，化作众花散在佛上，这样反复散花。护国！那时福焰王子从空中下来之后，便以偈赞叹那吉利意如来说：

```
敬礼金色尊，面净如满月，
敬礼智无比，离垢三界尊。
发净光润泽，顶高如须弥，
观者无厌足，眉间白毫相。
清净妙光明，目如青莲花，
微妙甚殊特，慈悲心哀愍，
观示诸世间。如来广长舌，
软薄如赤铜，出能遍覆面，
说法教道众，敬礼微妙声。
齿白如珂雪，坚实如金刚，
齐密具四十。熈怡微笑时，
教化无量众，敬礼美实言，
尊色世无比。放光照诸刹，
梵天及护世，彼光悉不现。
鹿王纤𦟛膊，行步如象王，
亦复如师子，安祥游步时，
地动诸山震。世尊具身相，
皮肤软妙泽，身如紫金色，
威光无与比，观者无厌足。
```
（大意：“敬礼金色之尊，面容清净如满月，敬礼智慧无比、离垢的三界之尊。头发清净光润，头顶高如须弥，观者无厌足，眉间白毫之相，清净美妙的光明，眼睛如青莲花，微妙甚为殊特，以慈悲心哀愍，观示诸世间。如来的广长舌，软薄如赤铜，伸出能遍覆面部，说法教导大众，敬礼微妙之声。牙齿白如珂雪，坚实如金刚，整齐细密，具足四十颗。和悦微笑之时，教化无量大众，敬礼美善真实之言，尊者之色世间无比。放光照耀诸刹，梵天以及护世天王，他们的光明都隐没不现。小腿纤长匀称如鹿王，行步如象王，也如狮子，安详游步时，大地震动，诸山摇动。世尊具足身相，皮肤柔软美妙润泽，身如紫金之色，威光无与伦比，观者无厌足。）

【按】“说法教道众”之“道”，宋、元、明、宫本作“导”。“鹿王纤𦟛膊”之“𦟛”，即“傭”，匀称。“安祥”之“祥”，元、明本作“庠”。

```
苦行无数劫，乐施无疲倦，
慈心向众生，故礼大悲父。
尊常乐施戒，坚住忍精进，
禅定及般若，总持智无比，
是故我敬礼。世尊说法时，
降伏诸外道，处众如师子，
医王除三垢，闻者皆欢喜，
是故我今礼。身口意清净，
三界无染著，如莲花处水。
尊声如梵天，如迦陵伽音，
度过三界岸，是故我敬礼。
尊观诸世间，如幻亦如梦，
复如伎儿戏，说诸法无我。
众生及命者，亦如水中月，
空寂无生处。如是知世已，
为彼作方便，百千诸法门，
慈悲摄教众。众生多诸患，
诸毒常炽然，观察热恼已，
犹如大医王，常行于世间，
拔济无数众，生老病死苦，
爱离怨憎会，忧悲苦恼等。
观世苦恼已，慈悲能度脱，
常行于世间。
```
（大意：在无数劫中修苦行，乐于布施，没有疲倦，以慈心对待众生，所以礼敬大悲之父。尊者常乐于布施、持戒，坚住于忍辱、精进、禅定以及般若，总持与智慧无比，所以我敬礼。世尊说法时，降伏诸外道，处在大众中如狮子，是除去三垢的医王，听闻者都欢喜，所以我现在礼敬。身口意清净，对三界没有染著，如莲花处在水中。尊者之声如梵天，如迦陵频伽之音，已度过三界之岸，所以我敬礼。尊者观察诸世间，如幻也如梦，又如伎人演戏，宣说诸法无我。众生以及命者，也如水中之月，空寂而无生处。这样了知世间之后，为他们作方便，以百千种法门，以慈悲摄受教化大众。众生多有种种患难，诸毒常常炽燃，观察其热恼之后，犹如大医王，常行于世间，拔济无数众生的生、老、病、死之苦，爱别离、怨憎会、忧悲苦恼等。观察世间的苦恼之后，以慈悲能令其度脱，常行于世间。）

```
世界如车轮，天人或畜生，
地狱饿鬼中，迷惑无导师。
世尊为彼等，示现最胜导。
过去有诸佛，法王离世间，
亦说此圣道，如今世尊说。
清净无秽浊，胜于大梵天，
亦胜揵闼婆，及与诸天女。
如是等诸音，如来声最胜，
为世间解说，真实润益忍。
种种方便说，具足诸功德，
百千那由数，诸众生闻已，
证三乘寂灭。若有供养彼，
得胜上妙乐，无量天人等，
当得正真道。或得于人王，
大富长者等，或领一天下，
二三四天下，转轮圣帝王，
十善化众生，七宝具足乐，
皆由供养佛。或作释梵王，
四天大王处，兜率化乐天，
他化须夜摩，斯由供养佛，
来世作正觉。如是供养佛，
或见或闻声，无有空过者，
除多众生苦，得证甘露处，
最妙无老病。世尊知正道，
善说正道处，能断诸恶道，
令住无畏路。无垢大圣道，
能为众生依，若人求福德，
须于佛边种。
```
（大意：世界如车轮旋转，天人或畜生，地狱、饿鬼之中，迷惑而没有导师。世尊为他们示现最胜的引导。过去有诸佛法王离开世间，也宣说这圣道，如今世尊所说。清净而没有秽浊，胜过大梵天，也胜过乾闼婆以及诸天女。在这样的种种音声中，如来之声最为殊胜，为世间解说真实润益之忍。以种种方便宣说，具足种种功德，百千那由他众生听闻之后，证得三乘寂灭。若有人供养他，便得殊胜上妙之乐，无量天人等，当得正真之道。或得为人王、大富长者等，或统领一天下，或二、三、四天下，作转轮圣帝王，以十善教化众生，具足七宝之乐，都由于供养佛。或作帝释、梵王、四天大王，或在兜率天、化乐天、他化自在天、须夜摩天，这都由于供养佛，来世将作正觉。像这样供养佛，或见到，或听到其声，没有空过的，能除去众多众生之苦，得证甘露之处，最妙而无老病。世尊了知正道，善于宣说正道之处，能断除诸恶道，令众生住于无畏之路。）

【按】“揵闼婆”之“揵”，明本作“乾”。

```
以是因缘故，当得无尽藏，
多数俱致劫，彼福不可尽，
乃至未成佛，当得清净刹，
微妙如他化，得已大欢喜。
彼妙刹土中，所有众生辈，
身口意清净。如是等功德，
斯由供养佛。若彼众生辈，
求天及涅槃，及以人中乐，
福报等无量，斯皆不可尽。
大名胜供养，复于百刹中，
无量百千众，当说大名称。
斯由叹佛德，如来除热恼，
能令众解脱，慈悲见欢喜。
诸根寂清净，人中最胜王，
无量功德聚，是故我顶礼。
我已得五通，虚空能飞上，
听尊妙音声。未来若作佛，
为众宣微妙，度脱无量众。
我赞功德聚，无垢清净福，
天人诸龙等，夜叉乾闼婆，
杂类众生辈，来世愿成佛。
```
（大意：无垢的大圣道，能作众生的依止，若人求福德，必须在佛边种植。因为这个因缘，当得无尽之藏，经多数俱致劫，那福德不可穷尽，乃至未成佛之前，当得清净的刹土，美妙如他化自在天，得到之后大欢喜。那美妙刹土中所有的众生，身口意都清净。这样的功德，都是由于供养佛。若那些众生求天上、涅槃以及人中之乐，所得福报都无量，这些都不可穷尽。具大名称的殊胜供养，又在百个刹土中，无量百千大众，当宣说其大名称。这都是由于赞叹佛德，如来除去热恼，能令大众解脱，以慈悲见之而欢喜。诸根寂静清净，人中最胜之王，无量功德之聚，所以我顶礼。我已得到五神通，能飞上虚空，听尊者的美妙音声。未来若作佛，为大众宣说微妙之法，度脱无量众生。我赞叹这功德之聚，以这无垢清净之福，愿天、人、诸龙等，夜叉、乾闼婆、杂类众生们，来世都成佛。”）

#### 焰意王寻子诣佛

那时世尊说此偈后，又告诉护国菩萨说：“护国！那时焰意大王过了那一夜之后，听到童子宫内的哭声，听后急忙赶往胜喜乐城。到后问诸婇女说：‘你们现在为什么哭？’那时那些女子对大王说：‘大王应当知道，福焰王子在今夜中忽然不见了。’护国！那时焰意王听了这话之后，昏闷倒地，如大树倒下，片刻才起来。大声悲泣，啼哭懊恼，绕着那城走了百千圈。护国！那时那里守护城池的天神告诉焰意王说：‘大王应当知道，从这里往东方有佛世尊，名为成利慧。大王！王子现在在那里，顶礼承事供养那佛世尊。’那时焰意王听了天神的告知之后，当即与童子宫内的诸婇女等，以及王的部众八万四千俱致百千那由他人，向东方前往成利慧如来、阿罗呵、三藐三佛陀之所。到后顶礼佛足，退住一面，以偈赞叹佛：

人中丈夫无等等，

忍辱精进善方便，

胜于日月摩尼光。

佛身现处如虚空，

```

于诸法中无疑惑，
为众示现始学书，

舍于父母及妻子，
眷属宗亲恋慕啼，

#### 王子奉施城邑供养佛僧

那时世尊说此偈后，又告诉护国菩萨说：“护国！那时那成利慧如来知道焰意王深信之心后，如其所应为他说法，令他安住于阿耨多罗三藐三菩提的不退转地。护国！那时那福焰王子对成利慧如来说：‘世尊！我现在想请如来以及比丘僧进入我的城内，唯愿世尊慈愍听许。’那时成利慧如来因怜愍王子，默然接受邀请。护国！那时福焰王子知道佛已应许，告诉父母以及诸眷属与婇女等说：‘诸位应当知道，我现在以胜喜乐城以及庄严之具全部奉施给那如来以及比丘僧，终无悔恨。唯愿父母以及诸眷属生起随喜之心。’那时父母眷属同时同声唱言：‘善哉善哉！我们都随喜。’

“护国！那时福焰王子当即更好地庄严胜喜乐城，奉施给如来。那时王子为佛以及僧众每日备办五百种味的上妙饮食，供养佛及僧众。又为比丘建造僧伽蓝，都以七宝庄严其房舍，舍内铺设杂色种种缯褥数百千重。又每日为比丘僧作新净衣，随其所乐布施给众僧。又为他们建造经行之处，都以众宝庄严其地，上面覆盖宝网，经行处两边种植种种树木花果与种种花，就是优钵花、波头摩花、分陀利花等，一切众花无不具足。那时王子这样供养佛以及众僧，经过三亿俱致岁，在这期间未曾睡眠，不爱惜身命，只念供养佛以及众僧。这期间没有贪欲之心，没有瞋害之心，对王位不生乐心，在一切处弃舍身命，何况其他东西。又对如来所说之法，都受持而终不忘失，乃至一句也未曾重复请问如来。在那期间也不洗浴，也不以酥油涂摩其身，也不洗足，也不坐卧，唯除吃饭时以及大小便利，乃至始终没有疲倦之想。

【按】“辦具”之“辦”，宫本作“辨”。“忧钵花”之“忧”，宋、元、明、宫本作“优”。“分陀利”之“分”，明本作“芬”。“苏油”之“苏”，元、明本作“酥”。

“那如来涅槃时，王子亲自取赤旃檀堆积起来，阇维如来之身。在阇维如来之身的地方，以种种上妙供具供养舍利。又在阎浮提内各处，以种种花鬘、名香、种种音乐，乃至幡盖宝幢供养舍利。这样供养之后，又为舍利另外建造九十九俱致座宝塔。那些塔都由七宝所成，又以杂宝真珠罗网覆盖在塔上。又为诸塔造七宝伞盖，每一座塔奉施五百个宝盖，又在每一座塔所奉施数百千种音乐。在阎浮提内各处都令种植种种妙花树，在每一座塔前点燃百千盏灯，每一盏灯器盛千斛油。又以一切诸香，涂香、末香、烧香以及花鬘等，供养那些塔。

【按】“赤真檀”之“真檀”，宋、元、明本作“旃檀”，译文依此。

“那时福焰王子这样供养经过俱致岁之后，后来出家。出家之后，只畜三衣，常行乞食，乐于头陀，常坐不卧，在其余时间未曾睡眠，也不向人有所求索，施与一切而心不望回报，常为他人解说正法。这样经过四俱致岁，乃至若有人以一句善言赞叹他，心中尚且不接受，何况接受他人的利养之物。听法时没有疲倦之想，常有诸天承事供养。那时那国土内的国王与大臣、夫人、婇女，一切人民以及诸眷属，都随从仿学那王子出家修道。

#### 本生结示

“护国！那时净居诸天子等见到这事之后，这样想：‘现在这国内一切人民都仿学王子出家，现在这国内全是三宝，我们现在应当作檀越供养他们，这就是供养三宝，利益世间。’那如来涅槃后，正法住世经过六万四俱致岁，都是福焰比丘所住持的。那福焰比丘从此以来常这样供养，这样次第供养九十四俱致诸佛，对每一位佛都如上述那样供养。护国！你认为怎样？那焰意王是别人吗？不要作别的看法，就是现在的无量寿如来。护国！你认为怎样？那福焰王子是别人吗？不要作别的看法，就是我自身。那时守护城池的天神是别人吗？就是阿閦佛。”

【按】“即是供养”之“是”，明本作“时”。“六万四俱致岁”之“四”，宋、元、明、宫本作“四千”。“住持”之“住”，元、明本作“任”。

#### 呵责未来恶比丘

那时世尊又告诉护国菩萨说：“护国！所以若诸菩萨摩诃萨想得阿耨多罗三藐三菩提，应当学习那福焰王子以深心至诚所修的诸行，能舍弃一切憎爱之心。正因为我常勤修这样的苦行，所以得成阿耨多罗三藐三菩提。然而未来世有些比丘，爱重名利，贪著眷属，于种种善法自然损减，常被我慢这怨贼所损害，甚为可怜。因为贪利而远离正法，白白出家，玷污沙门之行。只有口说‘我是菩萨’，然而内心纯行谄曲，身心昏浊，沉没于烦恼之泥，才有出家的形相，便违背本道。舍弃自己的誓愿，贪著衣服、饮食、房舍、卧具、汤药等事，心无惭愧，不避耻辱，没有威仪。远离佛的境界，心常贪著。护国！若有人得闻这样的法，应当觉察知道那恶知识。恶知识求名贪利，不应亲近。”那时世尊想再次宣说此义，以偈颂说：

```
多行于放逸，远离十力处。
心常贪利养，及诸眷属等，
弃舍佛菩提，千种诸功德。
诈圣求名利，恶性无惭耻，
奸谄无羞愧。彼专为利事，
入于佛法中，随顺诸烦恼，
速疾堕恶趣。口言我大德，
胜在阿兰若，心恒念聚落。
彼等为贪故，心多诸觉观，
彼人远解脱，犹如天与地，
行者应远离，如畏恶毒蛇。
彼不乐佛法，并诸功德僧，
弃舍离善道，常行于邪径，
失于无量善，为诸有覆蔽。
```
（大意：多行于放逸，远离十力之处。心常贪著利养以及诸眷属等，弃舍佛的菩提与千种功德。伪装圣者以求名利，恶性没有惭耻，奸诈谄曲，没有羞愧。他们专为利益之事，进入佛法之中，随顺种种烦恼，迅速堕入恶趣。口说“我是大德，胜过他人，住在阿兰若”，心中却常念聚落。他们因为贪心，心中多有觉观，那人远离解脱，犹如天与地，修行的人应当远离他们，如畏惧恶毒之蛇。他们不乐佛法以及有功德的僧众，弃舍离开善道，常行于邪路，失去无量善法，被诸有所覆蔽。）

【按】“速疾堕恶趣”之“堕”，宫本作“随”。“邪径”之“邪”，明本作“都”。

```
闻我往昔行，真实诚心信，
应当学我行，多俱致劫数。
如是法难得，应发大忍心，
我有所说处，勤劬当奉行。
若当欲成佛，妙胜大乘中，
应念彼王行，诸功德无量。
思惟真实已，应住彼教中，
如是菩提道，当见如佛说。
深思诸功德，圣人种性处，
当应如教行。若舍如是教，
则失功德味，当生恶趣中，
愚痴无有别，生彼已当悔。
劝住山林者，慎莫自赞誉，
亦勿毁他行，宁常自呵责。
昔背亿数佛，斯由我慢心，
莫惜己身命，恩爱处悉舍。
如我说此经，法中生敬心，
若能如说行，菩提不为难。
此乘大仙说，闻已莫生疑，
是故佛法中，应住如圣教。
精勤舍身命，如我教莫违，
若不信此教，于后悔无益。
```
（大意：听闻我往昔的修行，以真实诚心信受，应当学习我的修行，经多俱致劫数。这样的法难得，应当发起大忍之心，我所说之处，应当勤劬奉行。若想成佛，在殊胜的大乘中，应当忆念那王子的修行与无量功德。思惟真实之后，应当安住于他的教导之中，这样的菩提道，当见到如佛所说的那样。深思种种功德与圣人种性之处，应当如教而行。若舍弃这样的教导，便失去功德之味，当生于恶趣之中，愚痴而无所分别，生到那里后当会后悔。劝住在山林的人，切莫自我赞誉，也不要毁谤他人的修行，宁可常常自我呵责。往昔背离亿数佛，都是由于我慢之心，不要爱惜自己的身命，恩爱之处都应舍弃。如我所说的此经，应当于法生起敬心，若能如所说而行，菩提并不困难。此乘为大仙所说，听闻之后不要生疑，所以在佛法中，应当安住如圣教。精勤舍弃身命，如我所教，不要违背，若不信这教导，以后后悔也无益。）

【按】“诚心信”之“诚”，宋、元、明、宫本作“成”。“生敬心”之“生”，《大正藏》作“行”，宫本作“生”，今依CBETA（所录高丽藏）作“生”。

#### 校量功德与经名

那时世尊说此偈后，又告诉护国菩萨说：“护国！若有菩萨常行五波罗蜜，没有休息；若有菩萨在此经中能如法而行，能如教安住，又自己唱言：‘我如教安住，我如教而行。’前面行五波罗蜜的功德，若与这功德相比，百分不及其一，百千分不及其一，百千俱致分不及其一，算数之外的算数分不及其一，哥罗分不及其一，譬喻分不及其一，优波尼沙陀分不及其一。”

佛说此经时，三十那由他天、人以及阿修罗等，未曾发阿耨多罗三藐三菩提心的都发了心，得以于阿耨多罗三藐三菩提不退转。又有七千比丘尽除诸有漏，心得解脱。那时长老护国菩萨对佛说：“世尊！此法本名为什么？我们怎样奉持？”这样请问之后，那时佛告诉护国菩萨：“善男子！此法本名为‘不空誓清净行’，这样受持。也名为‘善丈夫游戏菩萨行决定毗尼’，这样受持。也名为‘真实义具足’，这样受持。也名为‘福焰菩萨大士往昔本行’，这样受持。”佛说此法之后，长老护国菩萨以及诸天、人、阿修罗、乾闼婆等，听闻佛所说，欢喜奉行。

【按】“乾闼婆”之“乾”，宋、元、宫本作“揵”。
