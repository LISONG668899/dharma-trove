# 《大宝积经》卷第六十七（菩萨见实会·兜率陀天授记品、化乐天授记品、他化自在天授记品、诸梵天等授记品）

北齐·三藏那连提耶舍 译

## 菩萨见实会第十六之七

### 兜率陀天授记品第十六

#### 兜率陀天思惟授记之义

那时有八亿兜率陀天，见到阿修罗、伽楼罗乃至夜摩天等供养如来、听闻授记之后，欢喜踊跃，生起这样的念头：“世尊是在什么法上授予阿耨多罗三藐三菩提记的呢？是为色授记，还是为受、想、行、识授予阿耨多罗三藐三菩提记呢？”

【按】品题“授记品”，宋、元、明、宫本作“得授记品”。“伽楼罗”之“伽”，明本作“迦”（下同）。“闻授记”之“授”，宋、元、明、宫本作“受”。“为色受记”之“受”，宋、元、明、宫本作“授”。

那些天人又这样想：“既不是为色授记，也不是为受、想、行、识授阿耨多罗三藐三菩提记。为什么呢？色既不生，菩提也不生，不生的色怎能觉悟不生的菩提？像这样乃至识也不生，不生的识怎能觉悟不生的菩提？色既不灭，菩提也不灭，不灭的色怎能觉悟不灭的菩提？像这样乃至识也不灭，不灭的识怎能觉悟不灭的菩提？色无分别，菩提也无分别，无分别的色怎能觉悟无分别的菩提？像这样乃至识也无分别，无分别的识怎能觉悟无分别的菩提？色既无二，菩提也无二，无二的色怎能觉悟无二的菩提？像这样乃至识也无二，无二的识怎能觉悟无二的菩提？色既无作，菩提也无作，无作的色怎能觉知无作的菩提？像这样乃至识也无作，无作的识怎能觉知无作的菩提？色既不可得，菩提也不可得，不可得的色怎能觉知不可得的菩提？像这样乃至识阴不可得，菩提也不可得，不可得的识怎能觉知不可得的菩提？

【按】“非与色记”之“记”，宋、元、明本作“授记”。“云何不可得识”之“可”，《大正藏》作“何”，今依CBETA（所录高丽藏）作“可”。

“像这样，在那些不可得的诸法之中，什么是佛？什么是菩提？什么是菩萨？什么是授记？色阴空，受、想、行、识也都是空。为什么呢？因为本性自空。同样，佛空、菩提空、菩萨空、授记空。为什么呢？因为自体空。在这样本性空的一切法中，所说的佛只是名称、只是假用，只是世俗谛、只是言说，只是施设之说；色阴、受、想、行、识也只是名称与假用，是世俗的言说以及施设，智者对此不应取著。

【按】“但是世谛”之“但”，元、明本无。“世俗言说”之“俗”，明本作“谛”。

“譬如有人在梦中享受五欲之乐，那人醒后便不见那快乐，忆念着却得不到五欲之乐，便生苦恼。同样，安住于菩萨乘的人，如果有所取著，便不能契会菩提；不证菩提，所以得不到它的滋味；因为得不到滋味，心中便生苦恼。为什么呢？这些法如梦一样不真实。那些法义理各别，愚痴凡夫的取著理解各不相同，一切诸法都应当这样了知。什么法是佛？什么法是菩萨？什么法是菩提？那些佛法都不可得。凡夫不可得，凡夫法也不可得。声闻不可得，声闻法也不可得。辟支佛不可得，辟支佛法也不可得。菩萨不可得，菩萨法也不可得。佛不可得，佛法也不可得。菩提不可得，涅槃也不可得。我们对这些法解了无疑。”

#### 兜率陀天以偈赞佛

那时兜率陀天对这法既然没有疑虑，便乐于在世尊处修供养，所作的供养胜过夜摩天。他们顶礼佛足，右绕三匝，退住一面，便以偈颂赞叹世尊说：

```
所有住佛功德者，
如来为其说行法，
彼得三种解脱门，
无等境界中修行。
无色亦无受想行，
无其受者亦无心，
斯则无碍智境界，
乐离欲阴人师子。
彼诸智慧妙丈夫，
不取发于菩提想，
离阴已获胜善根，
于佛功德无疑虑。
志愿无上大菩提，
然于菩提离取著，
是故内心无忧喜，
名为佛子修圣行。
同佛见法悉平等，
是故于法无所畏，
智者于此世间处，
求佛功德起修行。
简择色相无所著，
弃舍一切有相心，
于彼三有不起愿，
观察诸有悉皆空。
```
（大意：凡是安住于佛功德的人，如来为他们宣说修行之法，他们得到三种解脱门，在无等的境界中修行。无色，也无受、想、行，无受者，也无心，这就是无碍智的境界，乐于远离欲与五阴的人中师子。那些具足智慧的妙丈夫，不取发菩提心之想，离五阴而已获得殊胜善根，对佛的功德没有疑虑。志愿无上大菩提，然而对菩提远离取著，所以内心无忧也无喜，名为佛子修行圣行。与佛一样见法都是平等，所以对法无所畏惧，智者在这世间，为求佛的功德而起修行。简择色相而无所著，舍弃一切有相之心，对三有不起愿求，观察诸有都是空。）

```
能知五阴各不生，
如来授记及菩提，
菩提心等亦无生，
作是说者非愚惑。
如来功德及生死，
此诸佛法悉无生，
如是知者人中胜，
是为真实如来子。
若能知是阴不灭，
界入及以如来法，
佛与菩提及授记，
斯等诸法皆不灭。
若为菩提修行者，
当知彼亦是不灭，
知诸世间不灭故，
彼求菩提不为难。
五阴界入与菩提，
佛及菩萨皆无作，
如是了知为佛子，
彼人能持佛正法。
阴界诸入皆无觉，
菩提与佛并菩萨，
及以授记悉无觉，
如是知者为佛子。
```
（大意：能知五阴各各不生，如来的授记以及菩提、菩提心等也都无生，这样说的人并非愚惑。如来的功德以及生死，这些佛法都是无生，这样了知的人是人中最胜，是真实的如来之子。若能知道这五阴不灭，界、入以及如来之法，佛与菩提以及授记，这些法都不灭。若是为菩提而修行的人，当知他也是不灭；因为了知诸世间不灭，他求菩提并不困难。五阴、界、入与菩提，佛以及菩萨都是无作，这样了知的是佛子，此人能受持佛的正法。阴、界、诸入都无觉，菩提与佛以及菩萨，还有授记也都无觉，这样了知的是佛子。）

【按】“非愚惑”之“惑”，宫本作“或”。

```
五阴界入性空寂，
佛与菩提及授记，
如来真子修行者，
斯等亦皆自性空。
阴界诸入悉虚妄，
两足世尊及菩提，
行者授记亦虚妄，
如是了知为佛子。
非是依止非不依，
亦非有法非无法，
非是有为非无为，
如是了知为佛子。
世尊如是见世间，
我等如是知佛心，
即为胜妙供养佛，
及以一切贤圣众。
我等赞佛所得福，
唯佛世尊能了知，
以斯功德施群生，
愿皆成佛具众相。
```
（大意：五阴、界、入本性空寂，佛与菩提以及授记，如来真子修行的人，这些也都自性空。阴、界、诸入都是虚妄，两足世尊以及菩提，修行者与授记也都是虚妄，这样了知的是佛子。非是依止，也非不依止，也非有法，非无法，非有为，非无为，这样了知的是佛子。世尊这样见世间，我们这样了知佛心，这就是以殊胜美妙之法供养佛以及一切贤圣众。我们赞叹佛所得的福德，唯有佛世尊能够了知，以此功德施与群生，愿都成佛，具足众相。）

#### 授兜率陀天记

那时世尊听了那些兜率天的赞叹，并且知道他们的深信，便为天众现出微笑。那时慧命马胜以偈颂问道：

```
得大势力无上士，
以其因力现笑光。
愿佛说是微笑因，
令众得闻皆欣喜。
以见如来微笑故，
此诸大众悉怀疑，
众会慇懃普瞻仰，
咸皆一心欲听闻。
犹如世间有病人，
唯思医师及良药，
如是大众于佛所，
愿乐欲闻说授记。
斯等皆有深智慧，
志求菩提无所著，
一切恭敬悉瞻仰，
唯希如来为记莂。
世尊于此起大悲，
以佛智力断疑网，
是故大众得欣喜，
咸皆愿求佛功德。
世尊今正授记时，
唯愿除灭诸疑惑，
如来久已离怨敌，
愿断众邪外道论。
```
（大意：得大势力的无上士，以某种因缘之力现出笑光。愿佛宣说这微笑之因，令大众听闻都欢喜。因为见到如来微笑，这些大众都怀疑惑，众会殷勤普遍瞻仰，都一心想要听闻。犹如世间有病人，只想着医师和良药，像这样大众在佛的处所，愿乐听闻宣说授记。这些人都有深智慧，志求菩提而无所著，一切人都恭敬瞻仰，只希望如来为他们记莂。世尊于此生起大悲，以佛的智力断除疑网，所以大众得以欢喜，都愿求佛的功德。世尊现在正是授记之时，唯愿除灭各种疑惑，如来早已远离怨敌，愿断除众多邪外道之论。）

那时世尊便以偈颂回答慧命马胜说：

```
汝今启请如来义，
问其微笑正是时，
为利世间故致问，
必当饶益诸众生。
知诸天众心乐欲，
故我现是微笑光，
以知佛法胜妙故，
于我便作上供养。
彼皆如实见世间，
随顺圣教得证法，
已到三种解脱门，
非诸世间所能知。
过去已供无量佛，
亦曾问是深义趣，
于彼佛所久修空，
今故于斯显空义。
是故今者于此处，
便得值遇佛世尊，
以空赞叹无上士，
利益一切诸世间。
如斯世间悉无生，
诸佛菩提及授记，
所有修行菩提者，
彼等一切亦无生。
```
（大意：你现在启请如来之义，问那微笑正是时候，为了利益世间而发问，必当饶益众生。知道诸天众心中的乐欲，所以我现出这微笑之光；他们因为知道佛法殊胜美妙，于是对我作了上等的供养。他们都如实见世间，随顺圣教而证得法，已到达三种解脱门，不是诸世间所能知晓。过去已供养无量佛，也曾问过这甚深义趣，在那些佛所久修空性，所以如今在此显发空义。所以现在于此处，便得以值遇佛世尊，以空赞叹无上士，利益一切诸世间。）

【按】“诸世间”之“间”，圣本作“尊”。

```
众生悉同有此法，
如是知已得菩提，
过去曾学菩提心，
彼于此义能解了。
如是世间亦不灭，
斯诸天众善通达，
明智照了悉无疑，
是故彼天皆作佛。
决定必得无依处，
于法不取离分别，
一切世间皆无作，
彼于斯义能了知。
一切法体离自性，
天众心净无疑惑，
菩提及与菩提心，
一切皆空无自性。
兜率诸天坚固慧，
皆悉安住无所依，
故得菩提不为难，
必当速成无上智。
于其未来星宿劫，
当得度脱无边众，
彼天一切皆成佛，
同号名曰择法王。
如来于此诸天众，
知其心乐为记说，
一切天人闻说已，
咸皆踊跃称心意。
```
（大意：像这样世间都是无生，诸佛、菩提以及授记，所有修行菩提的人，他们一切也都无生。众生都同样具有此法，这样了知之后便得菩提，过去曾学菩提心，他们对此义能够解了。像这样世间也是不灭，这些天众善于通达，明智照了，全无疑惑，所以那些天都将作佛。决定必得无依之处，对法不取，远离分别，一切世间都是无作，他们对此义能够了知。一切法体离于自性，天众心净，没有疑惑，菩提以及菩提心，一切皆空，没有自性。兜率诸天智慧坚固，都安住于无所依，所以得菩提并不困难，必当迅速成就无上智慧。在未来的星宿劫中，当度脱无边众生，那些天一切都成佛，同号名为择法王。如来对这些天众，知其心中所乐而为他们记说，一切天人听闻之后，都踊跃称心如意。）

【按】“择法王”之“择”，宫本作“释”。

### 化乐天授记品第十七

#### 化乐天说实际

那时以化乐天王为首，与其眷属七亿化乐天众等，见到阿修罗、伽楼罗，乃至见到兜率天等供养如来，听闻授记之后，欢喜踊跃，都称心如意，得以安住实际，在真如中没有疑惑。他们从座而起，偏袒右肩，右膝著地，头面作礼，向佛合掌，异口同音对佛说：“世尊！依我们所理解的佛所说之义，一切诸法就是真实际、无边际、无碍际、无住际、无尽际、不二际、非际实际。世尊！所说的实际，是因为不颠倒。无边际，是因为无有限量。无碍际，是因为远离对治。无住际，是因为远离自性。无尽际，是因为无有生。不二际，是说一味。所说的非际，是因为非有。世尊！那实际遍一切处，没有一法不是实际。世尊！所说的菩提也是实际。世尊！什么是菩提？一切法就是菩提，因为远离自性。乃至五无间业也是菩提。为什么呢？菩提无自性，五无间业也无自性，所以无间业也是菩提。世尊！所说的菩提，如同无余涅槃之性，也如同无间业之性。为什么呢？一切法就是无余涅槃之性，也是无间业之性，所以无余涅槃界就是菩提。世尊！如果有众生住于生死，可以说求涅槃；在实际之中，没有住于生死而求涅槃的人。为什么呢？因为实际无二。世尊！我们对此解了无疑。若对此法没有疑虑的人，当知此人过去已曾在诸佛所得授阿耨多罗三藐三菩提记。”

【按】“闻授记已”之“授”，圣本作“受”。“得授阿耨多罗三藐三菩提记”之“授”，宋、元、明、宫、圣本作“受”。

#### 授化乐天记

那时世尊听化乐天王以及七亿化乐天等说授记之后，为了令大众心生喜悦，而现出微笑。那时慧命马胜以偈颂问道：

```
怜愍世者现微笑，
而不说其笑因缘，
天人导师非无因，
现此奇特微笑相。
既见世尊笑光已，
今诸大众悉怀疑，
唯愿说其微笑因，
断除一切诸疑网。
斯等若蒙如来说，
闻已咸生希有心，
为彼众会净真路，
趣向菩提作因缘。
若有众生疑虑者，
是人难得妙菩提，
唯愿大智断疑惑，
精勤速证无上道。
世尊此诸大众等，
志求菩提离诸恶，
得闻诸天授记已，
决定当成大法王。
是故世尊愿怜愍，
除断一切疑惑心，
授此诸天菩提记，
令诸大众皆欣喜。
```
（大意：怜愍世间者现出微笑，却不说那笑的因缘，天人导师并非无因，现此奇特的微笑之相。既见世尊的笑光之后，现在大众都怀疑惑，唯愿宣说微笑之因，断除一切疑网。这些人若蒙如来宣说，听后都会生起希有之心，为那众会清净真实之路，作为趣向菩提的因缘。若有众生心存疑虑，此人难以得到妙菩提，唯愿大智者断除疑惑，精勤速证无上道。世尊，这些大众，志求菩提，远离诸恶，听闻诸天授记之后，决定当成大法王。所以世尊愿垂怜愍，除断一切疑惑之心，授予这些天菩提之记，令诸大众都欢喜。）

【按】“今诸大众”之“今”，明本作“令”。“得闻诸天授记已”之“授”，《大正藏》作“提”，今依CBETA（所录高丽藏）作“授”。

那时世尊以偈颂回答慧命马胜说：

```
哀愍世间故现笑，
马胜汝今问我义，
我悉与彼天授记，
汝等咸各净心听。
此诸化乐天众等，
自说授记得菩提，
众中既作师子吼，
能坏外道诸邪见。
譬如空中雨众石，
必堕大地无有疑，
如是佛子离疑惑，
自知定当成佛道。
犹如日没至夜时，
当知日出必不久，
如是佛子备众行，
定知必当具十力。
又如日在正中时，
观诸色像皆明了，
如是佛子具众行，
自知必得萨婆若。
喻若日光至没时，
众人咸知日不见，
如是佛子皆自知，
决定当得最胜智。
譬如众流趣其下，
智者当知归大海，
如是佛子具明慧，
定知必得上菩提。
如人以石掷虚空，
决定堕地无疑虑，
如是佛子悉自知，
不久当得世间解。
```
（大意：我为哀愍世间而现笑，马胜你现在问我其义，我都为那些天授记，你们各自净心谛听。这些化乐天众，自说得授记、得菩提，既在众中作师子吼，能破外道的种种邪见。譬如空中降下众石，必定堕落大地，无有疑问；像这样佛子远离疑惑，自知必定当成佛道。犹如日落到了夜晚，当知日出必定不久；像这样佛子具备众行，确知必当具足十力。又如日在正中之时，观看各种色像都很明了；像这样佛子具足众行，自知必得萨婆若（一切智）。又如日光到了落下之时，众人都知道太阳将不可见；像这样佛子都自知，决定当得最胜智。譬如众流趋向低处，智者当知终归大海；像这样佛子具足明慧，确知必得无上菩提。如人把石头掷向虚空，决定堕地，无可疑虑；像这样佛子都自知，不久当得世间解。）

【按】“自说授记”之“说”，元、明本作“能”。“日出必不久”之“日”，明本作“月”。“日不见”之“见”，宋、元、明、宫、圣本作“现”。

```
智者法尔有此见，
以知法故不致疑，
自知分有佛功德，
必定近于自然智。
假使诸魔那由众，
现佛言汝不作佛，
不能沮坏其心意，
已自善解真法故。
决定于彼佛功德，
咸各自说得授记，
于斯诸天授记事，
如来悉生随喜心。
此天所修菩萨行，
悉自了知不由他，
彼等自说成善逝，
世尊于此皆随喜。
是故马胜若有人，
欲得无上菩提者，
可于此法应勤求，
必获最胜安隐处。
自成正觉寤斯理，
随义如实能了知，
亲近供养善知识，
彼证菩提不为难。
若有千劫修苦行，
皮膏血肉无恋惜，
若能解了斯义趣，
此福广大胜于彼。
过去所有一切佛，
未来怜愍众生者，
及以现在诸世尊，
悉依此法成佛道。
```
（大意：智者法尔有此见解，因为知法所以不致疑惑，自知有份于佛的功德，必定接近自然智。假使那由他数的魔众，现作佛身说“你作不了佛”，也不能沮坏他们的心意，因为他们已自己善解真实之法。决定于那佛的功德，各自说得授记，对于这些天的授记之事，如来都生随喜之心。这些天所修的菩萨行，都是自己了知，不由他人，他们自说当成善逝，世尊对此都随喜。所以马胜，若有人想得无上菩提，可在此法中勤求，必获最胜安隐之处。自成正觉，觉悟此理，随其义理如实了知，亲近供养善知识，他证菩提并不困难。若有人千劫修苦行，对皮、膏、血、肉无所恋惜，若有人能解了这义趣，此人的福德广大，胜过前者。过去的一切佛，未来怜愍众生者，以及现在诸世尊，都依此法成就佛道。）

【按】“可于此法”之“可”，宫本作“彼”。

```
化天于我供养已，
咸皆善知第一义，
曾供过去诸如来，
寤斯义理当成佛。
诸佛所有胜三昧，
及以现在所住定，
彼天深得佛境界，
由本先世久修习。
马胜！化乐天子等，
于彼三昧无有疑，
清净佛法既善学，
今于佛道现修行。
是故于理生信解，
当正勤求离苦边，

闻佛所说妙法已，

```
（大意：化乐天对我供养之后，都善知第一义，曾供养过去诸如来，觉悟这义理，当得成佛。诸佛所有的殊胜三昧，以及现在所住之定，那些天深得佛的境界，是由于本来在先世久已修习。马胜！化乐天子等，对那三昧没有疑惑，清净佛法既已善学，现在正于佛道修行。所以对此理生起信解，应当以正勤求得离苦的边际，常应亲近多闻之人，必得无上大菩提。听闻佛所说的妙法之后，化乐诸天众会等，都欢喜除去疑网，流注趣向大涅槃。）

### 他化自在天授记品第十八

#### 他化自在天说诸法非可知证

那时以他化自在天王为首，与其眷属八十那由他天众等，见到阿修罗、伽楼罗、龙女、龙王、鸠槃茶、乾闼婆、夜叉、紧那罗、诃罗伽阇天、四天王、忉利天、夜摩天、兜率陀天、化乐天等供养如来，听闻授记之后，欢喜踊悦，都称心如意，异口同声对佛说：“世尊！化乐诸天所说的实际，我们尚且不见‘实’，何况见‘际’。为什么呢？世尊！若是见到实，才可以说见到际。为什么呢？此人是行于二处。安住于这样乘的人，若是善男子、善女人，应当为他们宣说这两种法。这两种法并非真实的境界。世尊！若有善男子、善女人对不二法不信不入，虽然如此，此人发心希望得菩提，当知此人是行于非路。为什么呢？因为这对菩提来说不是道行。世尊！若有众生求菩提，此人不见有一法可以觉悟。为什么呢？因为没有少许法可以觉悟阿耨多罗三藐三菩提。世尊！那法非过去、非未来、非现在，非有为、非无为，非有、非无，非可识、非可知、非可舍、非可修、非可证。所谓菩提，那法不与其余的法作对治，其余的法也不与那法作对治。为什么呢？那法非杂烦恼，也非离烦恼，法体不可得，因为本性自离。此法不与彼法作对治，彼法也不与此法作对治。为什么呢？因为一切诸法都远离诸相。所以那法非可知、非可识、非可舍、非可修、非可证。

【按】“鸠槃茶”之“茶”，宋、宫、圣本作“荼”。“非杂烦恼”之“杂”，圣本作“离”；“非离烦恼”之“离”，圣本作“杂”。

“世尊！色之生，因为远离生相，它也非可知乃至非可证，受、想、行、识也同样如此。世尊！色之灭，因为远离色相，它也非可知乃至非可证，受、想、行、识也同样如此。世尊！过去，因为远离过去相，它也非可知乃至非可证；未来，因为远离未来相，它也非可知乃至非可证；现在，因为远离现在相，它也非可知乃至非可证。世尊！有为，因为远离有为相，它也非可知乃至非可证；无为，因为远离无为相，它也非可知、非可识、非可舍、非可修、非可证。世尊！像这样乃至为五阴所摄，或为过去所摄、现在所摄、未来所摄，或为有为所摄、无为所摄，这些法都不可得。因为不可得，所以那法非可知、非可识、非可舍、非可修、非可证。世尊！若有这样为求菩提而发心修行的善男子、善女人，他们都名为安住菩萨乘。”

#### 他化自在天以偈赞佛

那时他化自在诸天各自说了自己所知之法后，以偈赞叹说：

```
世尊善说尽有边，
永不暂受六趣身，
世间无智畏生死，
发心欲度生死岸。
彼诸阴体不可得，
以阴性相本自空，
一切法空皆无相，
是故诸法离对治。
自体即空无有物，
无有可知及修舍，
亦复非是可证法，
如来说有即非有。
相求菩提不可得，
助道诸法亦如是，
取心求佛不可得，
菩萨相求亦不得。
坚著诸相愚痴辈，
彼等望得寤菩提，
颠倒境界取相行，
无智非行菩提道。
入佛境界离众相，
名为智者如法行，
远离诸相及无相，
亦离于空及不空。
```
（大意：世尊善说，穷尽有的边际，永不暂受六趣之身；世间人无智，畏惧生死，发心想要渡过生死之岸。那些五阴之体不可得，因为五阴的性相本来自空，一切法空，都无有相，所以诸法远离对治。自体即空，无有一物，没有可知以及可修、可舍的，也不是可证之法，如来说有即是非有。以相求菩提不可得，助道诸法也是如此；以取心求佛不可得，以相求菩萨也不可得。坚执诸相的愚痴之辈，他们希望觉悟菩提，在颠倒境界中取相而行，无智，并非行于菩提道。入佛境界远离众相，名为智者如法而行，远离诸相以及无相，也远离空与不空。）

```
彼能寤解无上道，
于诸外道非境界，
亦非声闻所能知，
又非缘觉之所趣。
心得解脱净无垢，
罗汉于法相应者，
及诸一切辟支佛，
非彼智慧之境界。
彼句非为相心知，
及修少空亦不解，
若有解空说空者，
亦说诸法无自性。
彼受佛教无毁訾，
是名善修空寂静，
能寤难寤菩提道，
世尊于彼真导师。
赞佛二足最尊已，
所获无量诸功德，
回施一切诸群生，
成佛觉寤未觉者。
```
（大意：他们能觉解无上道，这不是外道的境界，也不是声闻所能知，又不是缘觉所趣。心得解脱、清净无垢、与法相应的罗汉，以及一切辟支佛，都不是他们智慧的境界。这语句不是有相之心所能知，修习少分空也不能理解；若有人理解空、宣说空，也就宣说诸法无自性。他们领受佛教而无毁訾，这名为善修空寂静，能觉悟难以觉悟的菩提道，世尊是他们的真导师。赞叹二足最尊之后，所获得的无量功德，回施一切群生，以此成佛，觉悟未觉之人。）

#### 授他化自在天记

那时世尊知道那八十那由他他化自在天以及天王等已得深信，为了令大众增益善根，所以现出微笑。那时慧命马胜以偈颂问道：

```
二足世尊现微笑，
以知他化深信故，
未曾演说笑因缘，
唯愿如来为解释。
大圣今者非无因，
现是希有微笑相，
愿佛开显因缘义，
灭除大众诸疑惑。
由见世尊微笑故，
今此众会悉怀疑，
怜愍一切世间者，
唯愿敷演分别说。
此众咸皆背生死，
合掌恭敬求涅槃，
斯等靡不怀犹豫，
无碍说者愿断除。
悉皆正信善逝法，
心得开解离取著，
咸有净信尊重心，
善哉牟尼愿解说。
勇猛精进于佛法，
远离疑网登圣路，
一切诸佛游此道，
是故愿除大众疑。
```
（大意：二足世尊现出微笑，因为知道他化天的深信，却未曾演说笑的因缘，唯愿如来为我们解释。大圣如今并非无因，现出这希有的微笑之相，愿佛开显因缘之义，灭除大众的疑惑。由于见到世尊微笑，现在这众会都怀疑惑，怜愍一切世间者，唯愿敷演分别解说。这些大众都背弃生死，合掌恭敬求涅槃，他们无不怀有犹豫，无碍说法者愿为断除。他们都正信善逝之法，心得开解，远离取著，都有清净信心与尊重心，善哉牟尼，愿为解说。勇猛精进于佛法，远离疑网，登上圣路，一切诸佛都游于此道，所以愿除大众之疑。）

那时世尊以偈颂回答慧命马胜说：

```
汝为怜愍大众故，
以偈问我正是时，
具足辩才有巧便，
乃能问此微笑义。
以问如来现笑故，
必当利益无量众，
是故一切众会等，
皆得住于胜菩提。
知彼他化深信已，
故我现是微笑光，
一切随顺如来教，
为求菩提修妙行。
观察世法离诸相，
如见阳焰非真实，
愚者见焰谓是水，
欲求菩提勿同彼。
取相贪乐凡夫境，
无智常怖于无相，
愚痴执相舍正路，
离相能获妙菩提。
妄想思量虚伪法，
随所分别即被缚，
智者观相悉皆空，
得上寂灭陀罗尼。
执相凡愚住恶心，
彼皆无智归六趣，
轮回逼迫受众苦，
都由愚痴住相故。
```
（大意：你为怜愍大众，以偈问我正是时候，具足辩才，有善巧方便，才能问这微笑之义。因为问如来现笑之故，必当利益无量众生，所以一切众会等，都能安住于殊胜菩提。知道他化天深信之后，所以我现出这微笑之光，他们一切都随顺如来之教，为求菩提修习妙行。观察世法远离诸相，如见阳焰并非真实，愚人见阳焰以为是水，想求菩提，切勿如此。执取相而贪乐凡夫境界，无智之人常常怖畏无相，愚痴者执相而舍弃正路，离相才能获得妙菩提。妄想思量虚伪之法，随所分别即被系缚，智者观相都是空，得到最上的寂灭陀罗尼。执相的凡愚住于恶心，他们都无智而归于六趣，轮回逼迫，受众多苦，都是由于愚痴住相的缘故。）

```
著相众生见诸阴，
佛与菩提及菩萨，
智者离相见空已，
能得无上大菩提。
住相之类增烦恼，
能观无相得除结，
所谓结者即是相，
观结无相即断除。
若有分别求道者，
分别于道为障碍，
智者虽复行于欲，
彼欲即为无相行。
诸法无体不可得，
分别诸法说言空，
若离分别得无相，
彼即菩提更无余。
闻于善逝说是语，
大众除疑得无畏，
顶受牟尼所说法，
如智顶戴瞻卜花。
斯诸天众获无畏，
于我设供最无上，
亦知诸法佛境界，
当作世间大导师。
```
（大意：著相的众生见到诸阴、佛与菩提以及菩萨，智者离相而见空之后，能得无上大菩提。住相之辈增长烦恼，能观无相便得除去结缚，所谓结就是相，观结无相即能断除。若有人以分别求道，对道的分别便成为障碍，智者虽然行于欲，那欲即成为无相之行。诸法无体不可得，分别诸法而说为空，若离分别而得无相，那就是菩提，更无其余。听闻善逝说这些话，大众除去疑惑，得到无畏，顶受牟尼所说之法，如同智者顶戴瞻卜花。这些天众获得无畏，对我所设的供养最为无上，也了知诸法是佛的境界，当作世间的大导师。）

【按】“说言空”，南藏作“说空言”。“瞻卜花”之“瞻”，宋、元、明、宫本作“薝”。

### 诸梵天等授记品第十九

#### 诸梵天离诸分别

那时六千万梵众天，见到阿修罗、伽楼罗乃至他化自在天等供养如来、听闻授记之后，欢喜踊跃，都称心如意。他们在世俗谛中，于禅定以喜悦为食，也在佛法中得到智慧光明；由于宿植善根，已曾亲自承事供养诸佛，以及深信清净的缘故，对甚深之法获得法忍。

那些天了知诸法无作而非无作、非生非不生、非有非不有、非起非不起、非灭非不灭、非依非不依、非清非浊、非憎非爱、非贤非愚、非知非不知、非见非不见、非受非不受、非测非不测、非无非非无、非物非非物、非可得非不可得、非去非来、非趣非不趣、非空非不空、非相非不相、非愿非不愿。

【按】“非恻非不恻”之“恻”，圣本作“测”，今依文意从之。

那些梵天对一切法心无所著，也无所住；在非用之中不作非用之想，在非不用之中也不作非不用之想。在语言之中无语言之想，在非语言之中也无非语言之想。在有作之中无有作之想，在无作之中也无无作之想。对凡夫不作凡夫之想，对非凡夫也不作非凡夫之想。对凡夫法不作凡夫法之想，对非凡夫法也不作非凡夫法之想。对声闻不作声闻之想，对非声闻也不作非声闻之想。对声闻法不作声闻法之想，对非声闻法也不作非声闻法之想。对缘觉不作缘觉之想，对非缘觉也不作非缘觉之想。对缘觉法不作缘觉法之想，对非缘觉法也不作非缘觉法之想。对菩萨不作菩萨之想，对非菩萨也不作非菩萨之想。对菩萨法不作菩萨法之想，对非菩萨法也不作非菩萨法之想。对佛不作佛之想，对非佛也不作非佛之想。对佛法不作佛法之想，对非佛法也不作非佛法之想。对涅槃不作涅槃之想，对非涅槃也不作非涅槃之想。对生死不作生死之想，对非生死也不作非生死之想。像这样那些天全都远离各种分别，定心清净。他们既得清净之心，便以寂灭之法说偈赞佛：

【按】“无其作想”之“其”，宋、元、明本作“作”。

```
大圣甚深寂灭智，
修行寂灭到彼岸，
演说寂灭度众生，
亦自常行寂灭法。
菩提寂灭善清净，
斯法牟尼之境界，
速得寂灭胜甘露，
以是今得尽诸有。
恒说寂灭微妙道，
是彼智者所行处，
八正之路灭恼浊，
拔济一切诸群生。
善修寂灭证菩提，
乃是先佛之所行，
修彼能到安隐城，
过去诸佛所证知。
是诸如来修学法，
导师如是化世间，
若人能行有学法，
获得无学胜菩提。
```
（大意：大圣具足甚深的寂灭之智，修行寂灭，到达彼岸，演说寂灭，度化众生，自己也常行寂灭之法。菩提寂灭，善妙清净，此法是牟尼的境界，迅速得到寂灭的殊胜甘露，因此现今得以穷尽诸有。恒常宣说寂灭微妙之道，是那些智者所行之处，以八正道灭除恼浊，拔济一切群生。善修寂灭，证得菩提，乃是先佛之所行，修习它能到达安隐之城，是过去诸佛所证知的。这是诸如来所修学之法，导师这样化导世间，若有人能行有学之法，便获得无学的殊胜菩提。）

```
一心趣向寂灭道，
诸根寂静久修习，
当得为佛世间解，
那罗延力度群生。
若知寂灭甘露者，
能尽一切诸有相，
是为真实如来子，
寂灭能除世间畏。
彼等所设供养佛，
胜上希有最殊特，
所说寂灭尽烦恼，
于诸无相最第一。
世间寂灭离诸相，
所谓寂灭即涅槃，
众生轮转受诸苦，
远离寂灭取相故。
牟尼诸法不思议，
即是菩提一切智，
已度淤泥到彼岸，
故佛于此无疑虑。
```
（大意：一心趣向寂灭之道，诸根寂静，久久修习，当得成为世间解之佛，以那罗延之力度化群生。若知寂灭甘露的人，能尽一切诸有之相，这是真实的如来之子，寂灭能除世间的怖畏。他们对佛所设的供养，殊胜希有，最为殊特，所说的寂灭能尽烦恼，在诸无相中最为第一。世间寂灭，远离诸相，所谓寂灭即是涅槃，众生轮转，受种种苦，是因为远离寂灭而取相。牟尼的诸法不可思议，即是菩提、一切智，已度过淤泥，到达彼岸，所以佛对此没有疑虑。）

```
若有离阴得解脱，
于佛大乘不愿乐，
欲求菩提思灭度，
于其五阴生怖畏。
离欲净心求涅槃，
彼等如是简择智，
于法取相凡夫境，
是谓如来之所说。
若取寂灭即是缚，
以是不得一切智，
若有于其五阴相，
不生存执取著心。
彼能利益释迦法，
是名喜乐无相行，
能获无名安隐处，
逮得菩提佛境界，
降魔诤论灭烦恼，
速得成就一切智。
我等赞叹无上士，
所获寂灭诸功德，
唯佛大智能了知，
回施众生愿成佛。
```
（大意：若有人离开五阴而得解脱，对佛的大乘却不愿乐，想求菩提而思惟灭度，对五阴生起怖畏；离欲净心而求涅槃，他们这样的简择之智，对法取相，是凡夫的境界，这是如来所说的。若是执取寂灭，就是系缚，因此不能得到一切智；若有人对那五阴之相，不生存执取著之心，他能利益释迦之法，这名为喜乐无相之行，能获得无名的安隐之处，逮得菩提、佛的境界，降伏魔与诤论，灭除烦恼，迅速成就一切智。我们赞叹无上士所获得的寂灭诸功德，唯有佛的大智能够了知，回施众生，愿都成佛。）

【按】“能了知”之“知”，元、明本作“智”。

#### 大梵天王以偈赞佛

那时娑婆世界主大梵天王，知道诸梵天赞叹佛之后，对佛正立，以真实功德赞颂说：

```
法王已知一切法，
不实虚诳如空拳，
亦如秋云及电光，
是故大圣离取心。
犹如梦中饥饿人，
飡食百味甘美膳，
梦人饥食皆不实，
如来见法亦如是。
又如梦中焦渴人，
得饮清净凉冷水，
梦渴饮水皆虚妄，
佛见诸法亦如是。
无作无受无众生，
无其作业及得报，
亦无得受果报者，
世尊于此无疑虑。
譬如美言得人爱，
然彼语言无可取，
亦无言说及听者，
大圣了知皆不实。
如闻箜篌美妙音，
其声亦无真实性，
世尊如是见诸阴，
知阴无体不可得。
```
（大意：法王已经了知一切法，不实虚诳，如同空拳，也如秋云以及电光，所以大圣远离取心。犹如梦中饥饿之人，吃到百味甘美的膳食，梦中之人、饥饿与饮食都不真实，如来见法也是如此。又如梦中焦渴之人，得饮清净凉冷之水，梦中的渴与饮水都是虚妄，佛见诸法也是如此。无作、无受、无众生，没有作业以及得报，也没有领受果报的人，世尊对此没有疑虑。譬如美言得人喜爱，然而那语言无可执取，也没有言说者以及听者，大圣了知都不真实。如听箜篌美妙之音，那声音也没有真实之性，世尊这样见诸阴，知道五阴无体不可得。）

【按】“无可取”之“取”，《大正藏》作“最”，宫、圣本作“取”，今依CBETA（所录高丽藏）作“取”。

```
犹如摩尼性自净，
系之衣上随色变，
诸法自体本清净，
虚妄分别增倒染。
譬如无垢鲜白衣，
随受染色种种变，
诸法如是性自净，
随所分别而染污。
犹如有人闻贝声，
寻其贝声从何来，
其声非自非他性，
大仙见法亦如是。
如人思美肴饍食，
其食众缘所合成，
观食各各无自性，
如来见法皆如是。
譬如众缘号为城，
推其城体无自性，
如是众缘皆悉空，
法王见法亦如斯。
```
（大意：犹如摩尼宝本性自净，系在衣上便随颜色变化，诸法自体本来清净，虚妄分别增长颠倒染污。譬如无垢鲜白之衣，随所受的染色种种变化，诸法也是这样本性自净，随所分别而受染污。犹如有人听到贝声，寻找那贝声从何而来，那声音非自性也非他性，大仙见法也是如此。如人想着美味的肴膳之食，那食物由众缘合成，观察食物各各无自性，如来见法都是如此。譬如众缘称为城，推究那城的本体无有自性，像这样众缘都是空，法王见法也是如此。）

```
喻若有人击鼓声，
虽能令人心欣喜，
声及众缘皆悉空，
大圣见法亦如是。
譬如有人打鼓时，
其声不从十方来，
声灭亦不向诸方，
世尊见法皆如是。
如是彼人击鼓已，
其鼓不生憎爱心，
亦不分别众缘性，
佛见诸法皆若斯。
又如彼人打妙鼓，
声不作心生他喜，
及以众缘皆亦然，
导师见法皆如是。
如人击彼妙鼓时，
鼓亦不生苦乐想，
亦不观察众缘性，
如来见法皆如是。
犹如有人击妙鼓，
声不即缘亦不离，
及彼伎缘亦复然，
牟尼见法皆如是。
```
（大意：又如有人击鼓之声，虽能令人心生欢喜，声音以及众缘都是空，大圣见法也是如此。譬如有人打鼓之时，那声音不从十方而来，声灭时也不去向诸方，世尊见法都是如此。像这样那人击鼓之后，那鼓不生憎爱之心，也不分别众缘之性，佛见诸法都是这样。又如那人打美妙之鼓，声音不作意而令他人生喜，以及众缘也都如此，导师见法都是如此。如人击那妙鼓之时，鼓也不生苦乐之想，也不观察众缘之性，如来见法都是如此。犹如有人击妙鼓，声音不即是缘，也不离缘，以及那伎乐之缘也是如此，牟尼见法都是如此。）

【按】“伎缘”之“伎”，圣本作“支”。

#### 授诸梵天记

那时世尊知道诸梵天、大梵王等深心敬信，并以寂灭赞颂佛之后，又见大众想要生起善根，便即微笑。那时慧命马胜以偈颂问道：

```
既见如来口中出，
离垢清净微笑光，
世间天人大众等，
一切咸生希有心。
以见世尊微笑故，
诸来大众普怀疑，
皆悉瞻仰如来面，
慇懃愿乐欲听闻。
愿佛开示笑因缘，
荡除大众疑惑心，
最胜牟尼非无因，
而现希有微笑相。
诸佛所现微笑光，
必为利益诸世间，
今者为谁现此笑？
唯愿敷演分别说。
大众得闻必欣喜，
由知微笑因缘故，
斯诸大众皆合掌，
一心瞻仰乐欲闻。
是故愿佛为解释，
必当断灭诸疑惑，
导师为彼诸来众，
愿垂演说微笑因。
```
（大意：既见如来口中放出离垢清净的微笑之光，世间天人大众等，一切都生希有之心。因为见到世尊微笑，诸来大众普遍怀疑，都瞻仰如来之面，殷勤愿乐想要听闻。愿佛开示笑的因缘，荡除大众疑惑之心，最胜牟尼并非无因，而现希有的微笑之相。诸佛所现的微笑之光，必为利益诸世间，现在为谁现此微笑？唯愿敷演分别宣说。大众听闻必定欢喜，因为得知微笑的因缘，这些大众都合掌，一心瞻仰，乐欲听闻。所以愿佛为我们解释，必当断灭各种疑惑，导师为那诸来大众，愿垂演说微笑之因。）

```
众会若闻必喜悦，
以得洗除疑网故，
众心坚固皆清净，
专念希仰如来德。
大众瞻仰世尊颜，
犹如覩见初生月，
具八妙声如梵天，
一心渴仰愿速闻。
天人众等闻佛说，
必得除疑住正法，
梵音演说义相应，
得闻甚深出世法。
佛智善巧能悦豫，
故令大众增踊跃，
此众心净离疑结，
能乐如来一切智。
精进勇猛有力人，
乃能志求无上道，
是故导师愍世间，
唯愿解说令众喜。
善哉世尊平等心，
怜愍一切诸众生，
令诸大众增善根，
安心不动求佛智。
```
（大意：众会若得听闻必定喜悦，因为得以洗除疑网，众人之心坚固，都已清净，专念希仰如来之德。大众瞻仰世尊之颜，犹如看见初生之月，世尊具足八种妙音，如同梵天，大众一心渴仰，愿速听闻。天人众等听闻佛说，必得除疑，安住正法，以梵音演说，义理相应，得闻甚深的出世之法。佛智善巧，能令人悦豫，所以令大众增长踊跃，这些大众心净，远离疑结，能乐如来的一切智。精进勇猛有力之人，才能志求无上道，所以导师怜愍世间，唯愿解说，令大众欢喜。善哉世尊平等之心，怜愍一切众生，令诸大众增长善根，安心不动，求佛智慧。）

那时世尊便以偈颂回答慧命马胜说：

```
怜愍一切诸世间，
故我现是微笑光。
汝当谛听说彼因，
其义甚深微妙句。
此诸众会若得闻，
发勤精进修善业，
当得利益诸众生，
于佛妙法起胜行。
斯诸梵众皆欣喜，
如来法中悉无疑，
那由他劫久修行，
犹如恒河沙劫数。
于诸境界悉不著，
心如虚空无障碍，
虽乐常修菩萨行，
而不速取菩提证。
此等复于未来世，
无量亿劫恒沙数，
天众清净无垢秽，
得大势力住世间。
然后当成一切智，
为大法王有威力，
具足功德尽诸有，
观诸世间悉空寂。
```
（大意：为了怜愍一切世间，所以我现出这微笑之光。你当谛听我说其因，其义甚深，是微妙之句。这些众会若得听闻，发起勤精进修习善业，当能利益众生，于佛的妙法起殊胜之行。这些梵众都欢喜，对如来之法都无疑惑，在那由他劫中久久修行，犹如恒河沙劫之数。对诸境界都不执著，心如虚空，没有障碍，虽乐于常修菩萨行，而不急于取证菩提。这些人又于未来世，经无量亿劫、恒河沙数，天众清净，没有垢秽，得大势力，住于世间。然后当成就一切智，为大法王而有威力，具足功德，穷尽诸有，观察诸世间都是空寂。）

```
彼佛如本久修行，
寿命限量亦如是，
斯诸善逝住世时，
能于苦恼度众生。
彼佛国土无伦匹，
世界严净甚滋茂，
无量那由劫数中，
如来演说不可尽。
彼佛刹土严净事，
无量佛说亦不尽，
彼佛同号大智力，
国土皆悉名最胜。
为众演说不动法，
不可思议无所依，
彼佛世界众生等，
咸皆修治诸善根。
无一众生受后有，
生死之中重生者，
彼等当时有一苦，
于其世间便显现。
唯畏诸行皆无常，
令诸众生起厌离，
尔时彼国众生辈，
离老病死诸苦相。
```
（大意：那些佛如同本来久修之行，寿命限量也是如此，这些善逝住世之时，能于苦恼之中度化众生。那佛国土无可伦比，世界庄严清净，甚为繁盛，在无量那由他劫数中，如来演说也说不尽。那佛刹土庄严清净之事，无量的佛宣说也说不尽，那些佛同号大智力，国土都名为最胜。为大众演说不动之法，不可思议，无所依止，那佛世界的众生等，都修治种种善根。没有一个众生受后有、在生死之中再次受生的，那时他们有一种苦，在那世间便显现出来：只是怖畏诸行都是无常，令众生生起厌离，那时那国土的众生们，远离老、病、死等诸苦相。）

```
一切依于一教法，
同厌无常修胜行，
彼诸众生当尔时，
耳更不闻余音声，
唯闻不净无常苦，
无我寂灭空无相，
甘露涅槃及菩提，
安隐清凉无上乐。
斯等如是胜妙音，
恒常数数而得闻，
尔时更无余声响，
若树若壁及露地，
或复空中及寺庙，
但闻如是微妙句。
闻已一切皆得道，
便于生死得解脱，
皆是如来神力故，
具八功德妙音声。
尔时无有杂毒心，
所谓离欲及瞋恚，
亦无愚痴出恶声，
麁言逼恼来经耳。
一切厌背于生死，
趣向涅槃大正路，
```
（大意：一切众生都依于同一教法，同样厌离无常，修习胜行。那些众生在那时，耳中不再听到其余音声，只听到不净、无常、苦、无我、寂灭、空、无相、甘露、涅槃以及菩提、安隐清凉的无上之乐。这些殊胜美妙之音，恒常屡屡得以听闻，那时更没有其余声响，无论树木、墙壁以及露地，或者空中以及寺庙，只听到这样的微妙之句。听闻之后，一切都得道，便于生死中得到解脱，这都是如来的神力所致，具足八功德的妙音声。那时没有杂毒之心，即是离于欲以及瞋恚，也没有愚痴发出恶声，粗言逼恼来经耳中。）

```
彼土一切悉当空，
佛及众生皆灭度。
斯是彼佛大神力，
发弘志愿不思议，
曾于过去那由劫，
为求菩提修道行。
彼国所有诸众生，
一切悉皆当作佛，
此诸梵天发广愿，
皆由观察寂灭句。
悉得证知甚深义，
解了如来吉祥路，
其所修学皆通达，
于诸世间为导师。
彼能观察众生空，
不生疲倦懈怠心，
是故巧入诸法性，
修集菩萨胜妙行。
```
（大意：一切众生都厌背生死，趣向涅槃的大正路，那国土一切都将成空，佛与众生都入灭度。这是那佛的大神力，所发的弘大志愿不可思议，曾在过去那由他劫中，为求菩提修习道行。那国所有的众生，一切都当作佛，这些梵天发广大愿，都是由于观察寂灭之句。他们都得以证知甚深之义，解了如来的吉祥之路，所修学的都已通达，在诸世间成为导师。他们能观察众生空，不生疲倦懈怠之心，所以善巧地契入诸法之性，修集菩萨的殊胜妙行。）

【按】“巧入”之“巧”，元、明本作“乃”。
