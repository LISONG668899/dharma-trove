# 《大宝积经》卷第二十二（被甲庄严会）

唐·三藏菩提流志 奉诏译

## 被甲庄严会第七之二

### 世尊自述往昔被甲

“又，无边慧！我忆念往昔修菩萨行时，披这样的甲胄，乘这样的大乘，超过诸边际，能灭黑暗，能除怖畏，以大精进，在无量百千俱胝那由他佛所，听闻这菩萨摩诃萨的甲胄庄严、大乘庄严。我踊跃欢喜地观察此法时，对佛世尊恭敬尊重，不作这样的念头：‘我披这样的甲胄，我有这样的甲胄，我得这样的法，我有这样的法，我有这样种类的法。’

“我在那时没有我想，远离身见，远离我慢，心无高下，也无分别；为了摄受一切众生，护持诸佛如来的法藏，成熟无量百千俱胝那由他众生，从未有一念疲倦之心。

“我在那时不舍甲胄，乘无边之乘，世世生中能破魔军，魔的诸眷属退败消灭，魔的使者怖畏奔散。一切异道——诸遮罗迦、路伽耶陀、波利婆罗遮伽，以及与这些外道相应之辈——我都降伏，使他们得到安稳；一切异论都已摧灭，一切外道都已降伏；令行于邪趣的众生在此乘中安住于众善之轭。

【按】“波利婆罗遮伽”，梵语音译，即游行出家的外道。

“我为诸众生开示甲胄与甲胄的庄严，也为众生演说这样种类之法的安乐大乘。住于此乘的人便获得一切安乐资具，就是有为的安乐资具、转轮圣王的安乐资具、帝释与梵王的安乐资具，以及无为的安乐资具。为诸众生说此法时，令诸众生入于此法之中，生于圣种性，建立大法幢，作师子吼，而发心趣向阿耨多罗三藐三菩提。

### 如理知见平正之道

“无边慧！诸菩萨摩诃萨应当在披上这样的大甲胄之后，如理观察而加以抉择：应当以什么法而发心趣向？对于一切法都能知见，而无分别。为什么？诸菩萨摩诃萨安住于正道，是如理而知的缘故；以正道发心趣向，是如理而见的缘故。如理清净，就既不分别，也非不分别，而在分别与不分别之中平等知见。若见有法可求可觅，就不平等，不住于如理清净的知见。因为无分别、无不分别，对那分别与不分别都无所执取；因为无所执取，远离分别以及不分别。

“在这道中，没有怜愍，没有施为，也没有增益，也没有取舍。住于平正之道，也不分别过去、现在、未来，能遍知一切分别。（断除）所有的随眠，对于一切法得以安住于平等、无颠倒的意义，才得名为住于此道的人。

### 八支圣道及其清净

“无边慧！什么是道以及道的清净？就是所说的八支圣道：正见、正思惟、正语、正业、正命、正精进、正念、正定。

“正见能断萨迦耶见（身见），超过一切见所行的境界；一切诸见在一切处都得清净，而能了知一切分别——无论胜分别、遍分别——都是无分别，无胜分别，无遍分别。不住于邪思，断除邪思惟；能见正命，见正命之想，见命之清净，住于清净之命。如理能见清净的身业、清净的语业、清净的意业。住于正业；以正见观察语业，对于语言与说语言者都能见知；住于正语，能清净对治。以正精进，见到善摄的精进，住于正精进。以正见忆念，而无有念，也无作意，无所执取；以清净之念住于正念。以正见观三昧，在三昧中无所依止，而能清净三昧之见，住于正定。

【按】“于语语者”之“语”，明本作“业”。

“无边慧！诸菩萨摩诃萨这样见时，得到一切处的清净正见，住于清净之道。这清净之道，是善丈夫所修行，智者所尊重，众圣所悦可，如来所称赞；不是一切魔、魔民、魔使、魔天大众所行之处，也不是一切爱著外道、依止诤论、行于诸见稠林、趣向诸非道的路伽耶陀等所行之处，也不是一切爱乐涅槃的人所行之处。

### 不分别涅槃

“为什么？住于无为的人，对于涅槃就有所分别；分别涅槃，就会分别诸行。为什么？在涅槃界中超过一切动念分别，尚且没有无为，何况有有为？这道能清净一切分别，乃至没有少许无为的分别，岂会有一切有为的分别？若对圣道有分别，就不名为住于圣道。若断除一切动念分别，这才名为住于圣道、住于无畏之道、住于安稳之道、住于安乐之道。

“这道能到达无老、病、死、忧、苦之处；这道能到达无有自性、超过自性之处；这道能到达远离一切性与非性之处；这道能到达无示现之相、非色相之处；这道如虚空遍于一切处，能到达无上的大宫殿中。这样去的人不再退还，便获得种种安稳快乐。那大宫殿不可示现，没有诸事相，没有少许有为，也没有少许无为；已灭有为，已舍无为，不给与众生有为的安乐、无为的安乐。

### 涅槃大宫殿

“无边慧！那些欣乐有为涅槃的人，尚且不求有为的安乐，何况有人能到达那大宫殿？大宫殿中没有施设，清凉寂静，所以名为涅槃；灭除贪瞋痴，断诸随眠，撕裂爱见之网，竭尽无明之流，拔除众毒箭，尽除不善法，所以名为涅槃；远离一切憍慢、病疾与众苦的逼恼，所以名为涅槃；不是心、意、识、心所所行之处，所以名为涅槃；止息诸诤论、一切结使，乃至法想，所以名为涅槃；断绝诸意乐以及意乐所求，也没有分别与所分别之相，所以名为涅槃。

“无边慧！这就是大般涅槃的体性。涅槃无边，不可宣说；若有所趣向，就不是道；道也无言，不可宣说。诸菩萨摩诃萨若以这道趣向涅槃大宫殿时，也令无量百千众生住于此道。

“无边慧！诸菩萨摩诃萨在这道中发心趣向时，没有疲倦，也没有忧恼；随其所欲而求，随其所欲而庄严，随其所庄严之处一一庄严，随其所摄受的众生而为他们说法，令诸众生都得欢喜。为什么？这道无与等同，能清净对治，所作究竟。诸佛世尊、声闻、缘觉，都在这道中发心趣向，彼此不相违背；未到达那地，未如其所愿，终不相离。

“什么是地？就是涅槃之地、大宫殿之地。譬如虚空不可以比喻，唯有以虚空来比喻虚空。广大空寂名为虚空，涅槃宫殿也是这样，是大空寂，没有主宰，也没有我所；一切众生即使进入其中，也不能摄取一毛端那么多。广大空寂、广大无量，名为大涅槃，名为大宫殿。

### 菩萨道非二乘所有

“无边慧！诸菩萨摩诃萨的这殊胜之道，不是诸声闻、缘觉所有的。住于此道的人成就一切功德资粮，得不退转，为诸众生作大饶益，以殊胜之行作大庄严，以这道而发心趣向。像那样的庄严，也不是声闻、缘觉所有的。

“诸菩萨摩诃萨住于此道时，若作转轮王，无所顾惜，有大威德与神通变现，而能了知世间与出世间；若作帝释、大梵天王，无所耽著，远离憍慢，乐见诸佛，乐闻正法，成熟无量百千诸天，趣向阿耨多罗三藐三菩提。”

那时，世尊说偈道：

```
菩萨殊胜道，世间无有上，
众圣及二乘，皆趣于斯道。
一切诸菩萨，发趣大菩提，
为得道庄严，以斯道开示。
若于斯道中，已趣今趣者，
彼皆以正见，安住于斯道。
一切诸菩萨，若住平等见，
行于斯道中，安乐而发趣。
斯道最殊胜，斯道为无上，
如实能诱进，于中无所执。
若住于斯道，行于斯道中，
一切诸智人，其意不倾动。
不说于斯道，少有倾动者，
由是无所动，于动常远离。
我说于斯道，无动无施为，
亦无有增益，斯道故无上。
一切诸菩萨，善住于斯道，
斯道无有爱，亦复无有憎。
斯道非过去，斯道非未来，
彼际不分别，如是而修习。
斯道无烦恼，斯道无分别，
于义不乖违，如是而安住。
住于最胜道，无住为安住，
住于斯道者，能获清净性。
我说八支道，众圣之所行，
住于斯道者，菩提不难得。
菩萨依怙者，如是住斯道，
能得道清净，一一而进趣。
斯之最上道，善士所修行，
如来所称赞，此智为无上。
魔及魔军众，魔之所摄者，
外道余众生，非其所行处。
```

（大意：菩萨的殊胜之道，世间无有能超过的，众圣与二乘都趣向此道。一切诸菩萨发心趣向大菩提，为了得到道的庄严，以此道开示众生。若在此道中已趣、今趣的人，他们都以正见安住于此道。一切诸菩萨若住于平等之见，行于此道之中，就安乐而发趣。此道最殊胜，此道为无上，能如实引导前进，其中无所执著。若住于此道、行于此道中，一切诸智人的心意都不倾动。我不说此道有少许倾动，由此无所动摇，常远离动摇。我说此道无动、无施为，也无增益，所以此道无上。一切诸菩萨善住于此道，此道没有爱，也没有憎。此道非过去，此道非未来，对那边际不作分别，这样修习。此道没有烦恼，此道没有分别，于义理不相违背，这样安住。住于最胜之道，以无住为安住，住于此道的人能获得清净之性。我所说的八支道，是众圣所行，住于此道的人，菩提不难得。菩萨这依怙者，这样住于此道，能得道的清净，一一进趣。这最上之道，是善士所修行，如来所称赞，这智慧最为无上。魔与魔军之众、为魔所摄的人、外道与其余众生，都不是他们所能行的地方。）

```
分别涅槃者，不住斯胜道，
愚为分别害，不能趣涅槃。
超过分别者，无想无分别，
于斯大道中，以是而发趣。
众圣之胜道，愚夫皆远离，
若行此法者，斯道为无上。
斯之最胜道，能至无上处，
其中无衰恼，无畏无灾难。
斯之无上道，无色无形相，
不可以色相，而能示现者。
斯之安隐道，正直无所畏，
以斯道发趣，究竟大涅槃。
斯之最净道，犹若太虚空，
一切无罣碍，常趣于涅槃。
若至涅槃者，一往无复退，
斯之大涅槃，最上胜安乐。
涅槃大宫殿，空寂不可量，
故名大涅槃，亦名大宫殿。
斯大涅槃中，三毒烦恼灭，
若至其中者，无退无受生。
涅槃大空寂，犹若太虚空，
广大空寂故，于中无罣碍。
涅槃大宫殿，永离苦忧恼，
无边境界处，说名为涅槃。
涅槃无数量，数量不可得，
寂灭清凉性，说名为涅槃。
涅槃无施设，趣道亦无上，
无量无分别，分别不可得。
我为诸菩萨，开示于斯道，
若住斯道者，彼近于涅槃。
```

（大意：分别涅槃的人，不住于这殊胜之道；愚人被分别所害，不能趣向涅槃。超过分别的人，无想也无分别，在这大道中以此发趣。众圣的殊胜之道，愚夫都远离它；若有人行此法，此道为无上。这最胜之道能到达无上之处，其中没有衰恼，无畏也无灾难。这无上之道无色、无形相，不能以色相来示现。这安稳之道正直而无所畏，以此道发趣，究竟到达大涅槃。这最清净之道犹如太虚空，一切无罣碍，常趣向涅槃。若到达涅槃，一往不再退还，这大涅槃是最上殊胜的安乐。涅槃大宫殿空寂而不可量，所以名为大涅槃，也名为大宫殿。在这大涅槃中，三毒烦恼都已灭除，若到达其中，就不退也不受生。涅槃大空寂，犹如太虚空，因为广大空寂，其中没有罣碍。涅槃大宫殿永离苦与忧恼，是无边境界之处，名为涅槃。涅槃没有数量，数量不可得，是寂灭清凉之性，名为涅槃。涅槃没有施设，趣向它的道也无上，无量无分别，分别不可得。我为诸菩萨开示此道，若住于此道，他就接近涅槃。）

【按】“说名为涅槃”之“说”，《大正藏》作“设”，CBETA 据高丽藏作“说”。

```
若住于斯道，世间胜安乐，
一切皆当得，说名无畏者。
善住于斯道，其心无所染，
由是道清净，说名无畏者。
以见平正道，一切能随觉，
一切资具中，一切不贪著。
菩萨依怙者，殊胜真实道，
饶益诸众生，勇猛而发趣。
若得无上道，最上道庄严，
令世悉欢喜，斯道而发趣。
斯道最殊胜，能令意清净，
随其所乐求，一切当发趣。
若得圣王位，转轮大军旅，
能舍大王位，出家行学道。
若得天帝释，大梵天王位，
于彼无耽著，斯为善顺道。
世间诸学处，一切能明了，
住于斯道中，乃为实语者。
```

（大意：若住于此道，世间殊胜的安乐，一切都当获得，名为无畏者。善住于此道，其心无所染污，由此道得清净，名为无畏者。由于见到平正之道，一切都能随之觉悟，在一切资具之中，一切都不贪著。菩萨这依怙者以殊胜真实之道饶益诸众生，勇猛而发趣。若得到无上之道与最上的道庄严，就令世间都欢喜，以此道而发趣。此道最为殊胜，能令心意清净，随其所乐求，一切都当发趣。若得到圣王之位、转轮王的大军，能舍弃大王之位，出家修行学道。若得到天帝释、大梵天王之位，对它们没有耽著，这就是善顺此道。世间的诸学处，一切都能明了，住于此道中，才是说真实语的人。）

【按】“斯为善顺道”之“道”，宋、元、明、宫本作“者”。

### 摄取八正道的诸法行

“又，无边慧！诸菩萨摩诃萨在这道中发心趣向时，为了摄取八正道，修行一种法，就是不作诸不善法。

“又为了摄取八正道，修行两种法：一是对内，随所有的善法如理思惟；二是对外，随所有的善法如理请问。

“又为了摄取八正道，修行两种法：一是如实了知诸法之事；二是了知无事、无住、无所分别。

“又为了摄取八正道，修行两种法：一是对内随顺觉知；二是对外无所执著。

“又为了摄取八正道，修行两种法：一是自己的信心无所分别；二是众生若尚未有信，我令他们安住于此道之中。

“又为了摄取八正道，修行两种法：一是对所作之业能如实知见；二是对所作之业而无执著。

“又为了摄取八正道，修行三种法：一是对诸苦取蕴一一了知；二是对诸无苦取蕴勤求至乐；三是对诸和合之法专修远离。

“又为了摄取八正道，修行三种法：一是宣说最上之法，言语不相违背，随所说的法义，心无诤论；二是不执著一切文字；三是摄取一切诸法。

“又为了摄取八正道，修行四种法：一是对于义理的正方便之事；二是随顺义理而作相应的正方便之事；三是顺于法而作观察的正方便之事；四是不起一切执著的正方便之事。

“又为了摄取八正道，修行四种法：一是能以坚固的誓愿自守，如所说而行；二是能以六根的善巧在道中发趣；三是能令意乐清净；四是能住于不放逸之行。

### 得道清净与明修习

“无边慧！诸菩萨摩诃萨以这些法行摄取道的缘故，才可以名为随顺道的人。观察一切法，因为性空的缘故、无名的缘故、无相的缘故、无愿的缘故、无生的缘故、无作的缘故、厌的缘故、离的缘故、灭的缘故、出的缘故，得到法的光明。观察生灭尽时，不对无生而起生之想，便在那时超升而入离生（正性），出过非法，得道清净，获无生忍。

“由于道清净，超过一切想，不住于非想，灭除道想，远离法想，出离无明之网，以明的修习，所应得之法都能获得。以明的修习得到什么法？就是以明的修习得想受灭，得一切法决定的善巧，得随顺秘密、顺于法性。

“诸菩萨摩诃萨行此道时，不住于处所，不为相所覆蔽，知一切法同于虚空，生如虚空之生，性如虚空之性，没有少许相作为罣碍。这道清净，不畏灾患；披大甲胄而不为执著所缚；乘于大乘而无所迷惑；远离诸障难，犹如虚空。在这道中发心趣向，为诸众生作大光明。无边慧！这就是诸菩萨摩诃萨的殊胜之道，不是诸声闻、缘觉所行的。”

那时，世尊说偈道：

```
为摄八正道，演说诸法行，
若住此道中，斯为大精进。
善法修行者，能于一切时，
不作不善法，斯行摄于道。
菩萨修习者，于内如理思，
于外求请问，斯行摄于道。
菩萨观察者，如事正了知，
如理如法住，斯行摄于道。
菩萨依怙者，于内随觉知，
于外无所执，斯行摄于道。
菩萨无畏者，自信无分别，
令他住净信，斯行摄于道。
菩萨思惟者，净诸所作业，
于业无所执，斯行摄于道。
菩萨无系者，常知苦取蕴，
求无苦取蕴，斯行摄于道。
菩萨善智者，修离和合行，
能离于和合，斯行摄于道。
菩萨思义者，随义能了知，
演说无违诤，斯行摄于道。
菩萨具慧者，不著于文字，
摄持一切法，斯行摄于道。
菩萨行法者，能与法相应，
亦随义相应，斯行摄于道。
菩萨顺道者，正住于坚誓，
如说而修行，斯行摄于道。
菩萨道清净，善净于意乐，
住法不放逸，斯行摄于道。
菩萨一切时，勤修此诸行，
身心获安乐，斯行摄于道。
```

（大意：为了摄取八正道，演说诸种法行；若住于此道中，这就是大精进。修行善法的人，能在一切时不作不善法，这样的修行摄取于道。菩萨修习者对内如理思惟，对外求法请问，这样的修行摄取于道。菩萨观察者如实正确地了知诸事，如理如法而住，这样的修行摄取于道。菩萨依怙者对内随顺觉知，对外无所执著，这样的修行摄取于道。菩萨无畏者自己的信心无所分别，又令他人住于清净之信，这样的修行摄取于道。菩萨思惟者清净一切所作之业，对业无所执著，这样的修行摄取于道。菩萨无系者常知苦取蕴，求无苦取蕴，这样的修行摄取于道。菩萨善智者修习远离和合之行，能远离于和合，这样的修行摄取于道。菩萨思义者随顺义理而能了知，演说而无违诤，这样的修行摄取于道。菩萨具慧者不执著于文字，摄持一切法，这样的修行摄取于道。菩萨行法者能与法相应，也随顺义理而相应，这样的修行摄取于道。菩萨顺道者正住于坚固誓愿，如所说而修行，这样的修行摄取于道。菩萨道清净，善能清净意乐，住于法而不放逸，这样的修行摄取于道。菩萨在一切时勤修这些行，身心获得安乐，这样的修行摄取于道。）

【按】“菩萨思义者”之“义”，宋、元、明、宫本作“议”。

```
菩萨正念者，住于清净道，
了知一切法，皆空无有相。
菩萨观察者，能令愿清净，
亦不住无愿，远离于诸相。
菩萨如理观，理趣悉平等，
于诸法不生，无有少疑惑。
菩萨妙智者，能观一切法，
厌离寂灭故，明见而发趣。
菩萨观法者，如理见法生，
不于生见生，不于尽见尽。
菩萨精进者，如是观察时，
出离于非法，超升正位中。
菩萨妙智者，斯道为清净，
速至大安隐，成就无上忍。
菩萨妙智者，随顺观诸法，
超过一切想，常住于无想。
菩萨妙智者，斯道能净治，
远离于道想，亦不住法想。
菩萨妙智者，斯道净治故，
出于无明网，获大法光明。
菩萨妙智者，能以明修习，
教授诸众生，由是而发趣。
菩萨明修习，为得一切法，
决定甚深义，善巧大方便。
菩萨明修习，方便离诸想，
随顺秘密法，能知决定义。
菩萨妙智者，以大法光明，
能灭于想受，由是而发趣。
菩萨妙智者，不住于斯道，
不住斯道故，于道而发趣。
```

（大意：菩萨正念者住于清净之道，了知一切法都是空、无有相。菩萨观察者能令愿清净，也不住于无愿，远离诸相。菩萨如理观察，理趣全都平等，对诸法不生，没有少许疑惑。菩萨妙智者能观察一切法，由于厌离寂灭，明见而发趣。菩萨观法者如理见到法的生起，不在生中见生，不在尽中见尽。菩萨精进者这样观察时，出离于非法，超升到正位之中。菩萨妙智者此道已清净，迅速到达大安稳，成就无上之忍。菩萨妙智者随顺观察诸法，超过一切想，常住于无想。菩萨妙智者能清净此道，远离道想，也不住于法想。菩萨妙智者由于清净此道，出离无明之网，获得大法光明。菩萨妙智者能以明修习，教授诸众生，由此而发趣。菩萨以明修习，是为了得到一切法决定的甚深义理与善巧的大方便。菩萨以明修习，以方便远离诸想，随顺秘密之法，能知决定的义理。菩萨妙智者以大法光明，能灭除想受，由此而发趣。菩萨妙智者不住于此道，因为不住于此道，所以在道中发趣。）

```
菩萨无畏者，能知一切法，
犹若净虚空，诸相无所覆。
菩萨知诸法，其性同虚空，
诸法如空故，清净而无垢。
菩萨如是住，不为相所碍，
速为诸众生，演说而教授。
菩萨妙智者，一切道清净，
于道无灾患，无碍而发趣。
如是清净道，速往大菩提，
能于无为证，平等而发趣。
菩萨大甲胄，大乘及大道，
如空无罣碍，清净而发趣。
趣斯乘及道，如趣太虚空，
远离于众相，无相而发趣。
大乘平等乘，广大如虚空，
于斯清净道，此乘当发趣。
一切诸菩萨，尊重于斯法，
为诸众生故，勇猛而发趣。
若诣大菩提，住斯殊胜道，
非诸二乘等，于此能发趣。
菩萨正忆念，能令道清净，
以斯清净道，最上而发趣。
```

（大意：菩萨无畏者能知一切法犹如清净的虚空，诸相都不能覆蔽。菩萨知道诸法之性同于虚空，因为诸法如空，所以清净无垢。菩萨这样安住，不被相所障碍，迅速为诸众生演说教授。菩萨妙智者一切道都已清净，在道中没有灾患，无碍而发趣。这样清净的道，迅速趣往大菩提，能于无为而证，平等而发趣。菩萨的大甲胄、大乘以及大道，如虚空无罣碍，清净而发趣。趣向此乘与此道，如趣向太虚空，远离众相，无相而发趣。大乘是平等之乘，广大如虚空，在这清净之道上，此乘当发趣。一切诸菩萨尊重此法，为了诸众生勇猛而发趣。若趣往大菩提，就住于此殊胜之道，不是诸二乘等能在此发趣的。菩萨正忆念，能令道清净，以这清净之道最上而发趣。）

【按】“于此能发趣”之“此”，宋、元、明、宫本作“斯”。

### 以慈悲加持四大

“又，无边慧！诸菩萨摩诃萨这样发心趣向时，能以善巧正确了知无量的念处、正断、根、力、觉分、解脱、等持、等至、神足、止观，以无量功德作殊胜庄严；为了降伏诸世间而披大甲胄，为了出离三界而乘于大乘，为了摄受天、人、阿修罗而安住于此道，而发心趣向阿耨多罗三藐三菩提。

“无边慧！诸菩萨摩诃萨披大甲胄、乘于大乘、住于此道时，若不以慈、悲、喜、舍遍照众生，对诸众生不爱如自己，这样的甲胄、大乘、大道，大地就不能承受，一切众生也不愿亲近。若以哀愍利益众生而披大甲胄、乘于大乘、安住于此道，这样的甲胄、大乘、大道，是一切世间的天、人、阿修罗所不能行的，一切耽著世间、住于世间的愚夫也不能见。

原文：“不以慈悲喜舍遍照众生，于诸众生不爱如己。如是甲胄大乘大道，而于大地所不堪受”（大意：依下文偈颂“菩萨不修习，大慈及大悲，大喜大舍等，大地不堪受”，此句是假设之辞，意为“若不以慈悲喜舍遍照众生……大地不能承受”，今依此译出。）

“又，诸菩萨摩诃萨为了哀愍一切众生而披大甲胄，能以甲胄加持地界与水、火、风界，令这地界不倾覆，一切众生不生恐怖，能令水界、火界、风界随其所应作而作其所应作。

“又，诸菩萨摩诃萨从初发心发趣而披的甲胄，乃至现在所披的这大甲胄，乘这大乘，以清净之道发趣，直到一生补处，前往菩提树、坐于道场之时，这三千大千世界之中金刚所成的坚固道场之地，若不加以加持，就会涌没倾覆；虽然是坚固金刚所成，也不能荷负这大甲胄、大乘、大道。

【按】“踊没”之“踊”，宋、明、宫本作“涌”。

“又，诸菩萨摩诃萨由于往昔的誓愿，对诸众生趣向慈悲的缘故，为十方诸佛、诸大菩萨共同称赞的缘故，即使是金刚大轮围山、须弥卢山、一切宝山以及其余山王，若不加以加持，也不能荷负这大甲胄、大乘、大道。

“又，诸菩萨摩诃萨由于本愿之力，由于诸佛如来的本愿之力，对诸众生不作恼害，不作伤害，不作损害，不作怨敌，不作仇雠，不凌辱依恃，不逼迫，为了令众生获得安乐，而披大甲胄，乘于大乘，住于此道中，而发心趣向阿耨多罗三藐三菩提。

【按】“趣慈悲”之“趣”，明本作“起”。“凌恃”之“凌”，明本作“陵”。

### 以慧为先导

“无边慧！诸菩萨摩诃萨披甲胄时，披的是智慧的甲胄，持智慧的刀仗，以大智慧回向，乘回向之乘，生起智慧光明，住于光明之道，以智慧明眼观察诸法，而发起一切智智。为了摄取一切智智，为诸众生修行般若波罗蜜、檀那（布施）波罗蜜、尸罗（持戒）波罗蜜、羼提（忍辱）波罗蜜、毘梨耶（精进）波罗蜜、禅波罗蜜，一切都以智慧为先导，以智慧来修习，以智慧来摄持，回向阿耨多罗三藐三菩提。”

【按】“起慧光明”之“起”，明本作“趣”。“发起于一切智智”之“起”，元、明本作“趣”。

那时，无边慧菩萨摩诃萨对佛说：“希有，世尊！诸菩萨摩诃萨的种种智慧，遍于一切处都能摄持，成就无量的诸佛之法。”

那时，世尊告诉无边慧菩萨摩诃萨说：“无边慧！是这样，是这样，如你所说。诸菩萨摩诃萨的种种智慧，遍于一切处，摄持一切法；披大甲胄，乘于大乘，住于此大道，一一都以智慧为先导而发心趣向。无边慧！即使有智慧，若没有以智慧为先导，在这道中也不能发心趣向。若有智慧，又以智慧为先导，遍于一切处随之运转、随之而行，以智慧摄持，以智慧防护，那时才名为披大甲胄、乘于大乘、住于此大道，以安稳之法饶益世间，能开慧眼，以眼观察，慧身朗照，放大光明，而发心趣向阿耨多罗三藐三菩提。

“无边慧！这就是诸菩萨摩诃萨所披的甲胄与甲胄庄严、所乘的大乘与大乘庄严、所行的大道与大道庄严，而发心趣向阿耨多罗三藐三菩提。无边慧！诸善丈夫的甲胄庄严、大乘庄严、大道庄严以及一切功德的种种庄严，我若要具体宣说，在无量劫中也说不尽。为了令你们了知，也为了未来诸善丈夫的甲胄庄严、大乘庄严、大道庄严、无边功德资粮庄严，我现在在这里略说少分。那些善丈夫若听闻我的法，也当披大甲胄，乘于大乘，住于此大道，以功德庄严而发心趣向。”

那时，世尊说偈道：

```
我说一切断，亦说四念住，
一切善方便，斯由不放逸。
具足正忆念，法善巧相应，
勇进而出离，斯由不放逸。
根力菩提分，被甲乘大乘，
以此为侍卫，菩萨当发趣。
禅定胜解脱，等持及等至，
以此为侍卫，菩萨当发趣。
大慈悲喜舍，被甲乘大乘，
以此为侍卫，菩萨当发趣。
成就于止观，神足及神变，
以此为侍卫，菩萨当发趣。
无量诸功德，被甲乘大乘，
于道无疲倦，菩萨当发趣。
精进不放逸，被甲乘大乘，
了知彼念处，菩萨当发趣。
光明大甲胄，降伏诸世间，
被斯甲胄已，乃名为智者。
正趣一切智，出过三界中，
乘斯大乘已，乃名为智者。
大道清净道，映蔽诸世间，
天人阿修罗，乃名遍闻者。
如是诸菩萨，普为诸众生，
能于一切时，精进被甲胄。
```

（大意：我宣说一切正断，也宣说四念住，一切善巧方便，都由于不放逸。具足正确的忆念，与法的善巧相应，勇猛精进而出离，都由于不放逸。根、力、菩提分，披甲而乘大乘，以此作为侍卫，菩萨当发趣。禅定、殊胜的解脱、等持以及等至，以此作为侍卫，菩萨当发趣。大慈、悲、喜、舍，披甲而乘大乘，以此作为侍卫，菩萨当发趣。成就止观、神足以及神变，以此作为侍卫，菩萨当发趣。以无量诸功德，披甲而乘大乘，在道中没有疲倦，菩萨当发趣。精进不放逸，披甲而乘大乘，了知那些念处，菩萨当发趣。以光明的大甲胄降伏诸世间，披上这甲胄后，才名为智者。正确趣向一切智，出过三界之中，乘了这大乘后，才名为智者。以大道、清净之道映蔽诸世间的天、人、阿修罗，才名为遍闻者。像这样的诸菩萨，普遍为了诸众生，能在一切时精进地披甲胄。）

```
菩萨不修习，大慈及大悲，
大喜大舍等，大地不堪受。
菩萨不修习，于彼诸众生，
知时饶益事，大地不堪受。
菩萨不修习，于彼诸众生，
爱之如己者，大地不堪受。
菩萨不修习，以慈乘大乘，
诸山及大海，大地不堪受。
菩萨不修习，慈念诸众生，
乘于此大乘，众生不亲近。
若被斯甲胄，慈光不照明，
于彼大甲胄，众生不亲近。
若被斯甲胄，功德海无边，
加持四大界，彼乃堪荷负。
摄取众生故，普照以慈光，
加持四大界，彼乃堪荷负。
摄取众生故，成就大菩提，
加持四大界，彼乃堪荷负。
不讥恼众生，被斯大甲胄，
大乘而出离，斯名为智者。
善巧大方便，一切悉加持，
无上而出离，斯名为智者。
由是此大地，不没亦不倾，
水火风界等，能作所应作。
```

（大意：菩萨若不修习大慈、大悲、大喜、大舍等，大地就不能承受。菩萨若不修习对诸众生知时而作饶益之事，大地就不能承受。菩萨若不修习对诸众生爱之如己，大地就不能承受。菩萨若不修习以慈心乘于大乘，诸山与大海、大地都不能承受。菩萨若不修习慈念诸众生而乘此大乘，众生就不亲近。若披这甲胄而慈光不能照明，对那大甲胄，众生就不亲近。若披这甲胄，功德海无边，加持四大界，它们才能荷负。为了摄取众生，普照以慈光，加持四大界，它们才能荷负。为了摄取众生，成就大菩提，加持四大界，它们才能荷负。不讥刺恼害众生，披这大甲胄，以大乘而出离，这名为智者。以善巧的大方便，一切都加以加持，无上而出离，这名为智者。由此这大地不沉没也不倾覆，水、火、风界等都能作其所应作。）

```
然诸大菩萨，被甲乃无边，
乘于此大乘，以道而发趣。
成就一生处，至于最后身，
往诣树王下，坐于坚固地。
于此道场处，安住如金刚，
身心不疲倦，现证一切智。
菩萨无畏者，若不以加持，
彼地当倾覆，坏已无复成。
一切大地界，若不以加持，
假使金刚成，无不倾覆者。
菩萨于往昔，大誓愿庄严，
于诸众生所，已起大慈念。
现在十方界，诸佛刹土中，
遍知两足尊，一切皆护念。
设复余石山，须弥卢宝山，
金刚轮围山，坚固嶷然住。
菩萨智慧者，若不以加持，
于斯大甲胄，不堪为荷负。
诸佛诸菩萨，神力所加持，
众生及大地，堪近堪荷负。
```

（大意：然而诸大菩萨所披的甲胄无边，乘这大乘，以道而发趣。成就一生补处，到达最后身，前往菩提树王之下，坐于坚固之地。在这道场处，安住如金刚，身心不疲倦，现证一切智。菩萨无畏者若不加以加持，那地就会倾覆，毁坏之后不能再成。一切大地界若不加以加持，即使是金刚所成，也无不倾覆。菩萨在往昔以大誓愿庄严，对诸众生已生起大慈之念；现在十方世界诸佛刹土中的遍知两足尊，一切都护念他。即使其余石山、须弥卢宝山、金刚轮围山坚固巍然而住，菩萨智者若不加以加持，对这大甲胄也不能荷负。由于诸佛、诸菩萨神力所加持，众生与大地才能亲近、才能荷负。）

【按】“假使金刚成”之“成”，宫本作“刹”。

```
被斯大甲胄，不为恼众生，
甲胄无有上，以乘当发趣。
被斯大甲胄，不为害众生，
甲胄不思议，以乘当发趣。
被斯大甲胄，不为雠众生，
为除众生病，以乘当发趣。
具足殊胜道，无上最净治，
不恼不雠怨，不害正安住。
被慧大甲胄，乘慧回向乘，
甲胄不可坏，回向无过上。
菩萨依怙者，住道慧光明，
以慧观诸法，无上而发趣。
菩萨殊胜道，甲胄及大乘，
斯由慧光起，是故心清净。
乘诸波罗蜜，趣佛大菩提，
慧摄慧清净，以慧为先导。
一切波罗蜜，以此慧为先，
慧摄慧清净，能授无上智。
菩萨不思议，能起慧光明，
能然大慧灯，安乐而发趣。
起慧光明故，慧眼由是开，
于佛无上智，明见而发趣。
菩萨勇猛者，甲胄乃无边，
无边庄严故，名为大甲胄。
菩萨大智者，大乘大庄严，
于佛一切智，无染而发趣。
菩萨大智者，大道大庄严，
殊胜不思议，清净而发趣。
```

（大意：披这大甲胄，不为恼害众生，甲胄无上，以此乘当发趣。披这大甲胄，不为伤害众生，甲胄不可思议，以此乘当发趣。披这大甲胄，不与众生为仇，为了除去众生的病，以此乘当发趣。具足殊胜之道，无上而最清净，不恼、不仇怨、不害，正确安住。披智慧的大甲胄，乘智慧回向之乘，甲胄不可破坏，回向无可超过。菩萨这依怙者住于道的智慧光明，以智慧观察诸法，无上而发趣。菩萨的殊胜之道、甲胄与大乘，都由智慧之光而生起，所以心得清净。乘诸波罗蜜，趣向佛的大菩提，以智慧摄持，以智慧清净，以智慧为先导。一切波罗蜜都以这智慧为先，以智慧摄持，以智慧清净，能授予无上之智。菩萨不可思议，能生起智慧光明，能燃起大智慧之灯，安乐而发趣。由于生起智慧光明，慧眼因此开启，对佛的无上智慧，明见而发趣。菩萨勇猛者所披的甲胄无边，因为无边的庄严，所以名为大甲胄。菩萨大智者以大乘作大庄严，对佛的一切智，无染而发趣。菩萨大智者以大道作大庄严，殊胜不可思议，清净而发趣。）
