# 当依止正念正知之理

麦彭仁波切 造

顶礼上师文殊师利！

```
ནང་དུ་མཉམ་པར་བཞག་སྟེ་བལྟས་ཙ་ན། །
རང་སེམས་རྣམ་པར་རྟོག་པའི་འཕྲོ་རྒོད་འདི། །
མུ་མཐའ་མེད་པ་ཆུ་བོའི་གཉེར་མ་འདྲ། །
ངེས་པ་མེད་པ་བར་སྣང་སྤྲིན་དང་འདྲ། །
རྒྱུན་ཆད་མེད་པ་ཆུ་ཀླུང་ཆེན་པོ་འདྲ། །
དོན་མེད་སྟོང་འཁྱམས་བར་སྣང་རླུང་དང་འདྲ། །
```

当我们平等安住、向内观照之时，便会发现，自心分别妄念之狂野奔驰，浩瀚无边，犹如江河之涟漪；漂移不定，犹如虚空之浮云；相续不断，犹如浩荡之大川；虚耗无义、空自游荡，犹如空中之飘风。

```
འདི་རྗེས་དེད་ནས་ཐོག་མེད་ད་བར་སོང་། །
དེ་ཡིས་རང་དོན་ཅུང་ཟད་མ་འགྲུབ་པར། །
ཕྱི་མའི་རྣམ་སྨིན་ཁུར་ལེན་ད་ལྟར་ཡང་། །
གདོན་ཟིན་ནད་པ་བཞིན་དུ་མི་བདེས་མནར། །
```

自无始以来，我们一路追随此种妄念直至如今，此中不曾成办自身丝毫之利益；如今仍在为来世之异熟果报背负重担，恰如被鬼魅所附、被疾病所缠之人，为不安与痛苦所折磨。

```
ངན་གོམས་ལངས་ཤོར་བག་ཆགས་རྗེས་འགྲོ་བ། །
ཤོག་དྲིལ་བརྐྱང་པ་སླར་ཡང་རང་མལ་བཞིན། །
རང་དབང་མེད་པར་གཡེངས་བའི་རྦ་རླབས་འདི། །
རང་ལ་རང་གནོད་བྱེད་པའི་རྩ་བ་ཡིན། །
```

随恶习而起、逐旧有习气之后而奔走，正如展开之卷轴，一旦松手，便又弹回原来卷曲之状；这种身不由己、任意散乱之波浪，正是我们自己伤害自己的根本所在。

```
དེ་བས་དྲན་པས་བྱ་རས་ནམ་ཟིན་ཚེ། །
རྩ་བའི་དམིགས་པ་གཅིག་པུ་མ་གཏོགས་པ། །
ཅི་དྲན་གང་དྲན་ཐད་ཁར་རྦད་ཀྱིས་ཀྱིས་ཆོད། །
བཅད་ནས་དེ་དང་ཤེས་བཞིན་ལྷན་ནེར་སྡོད། །
```

因此，当正念执掌起哨兵之职时，除了根本所缘之唯一对境之外，无论浮现何种念头、忆起何种事相，都应当场立即斩断；斩断之后，便与彼所缘对境一同、伴以正知，坦然而安住。

```
ཡང་འབྱུང་ཡང་འཕྲོ་བྱུང་ན་མགོ་ནས་ནོན། །
ཤེས་བཞིན་ལུ་གུ་རྒྱུད་དུ་མ་སྦྲེལ་ན། །
ཞི་གནས་ཏིང་འཛིན་བསྐལ་པ་བརྒྱར་ཡང་དཀའ། །
```

若念头再度生起、再度蔓延，便当从其根源处即刻压伏；倘若不能将正知如链环般连续不断地贯穿，那么纵使历经百劫，寂止之禅定也难以成就。

```
ནམ་ཞིག་རྣམ་རྟོག་གདོན་འདྲ་ཤུགས་ཆུང་ལ། །
བཏང་འགྲོ་བཞག་སྡོད་རང་སེམས་ལས་རུང་ཚེ། །
ཏིང་ངེ་འཛིན་གྱི་ཡོན་ཏན་སྙིང་ལ་འཆར། །
```

待到有朝一日，那如鬼魅一般的分别妄念势力渐弱，无论任其散去、还是令其安住，自心皆已调柔堪能之时，禅定之种种功德，便会于心中自然显现。

```
དེ་བར་ཆད་མེད་གོམས་པ་སྲིངས་ཤིག་བུ། །
```

在此之前，孩子啊，切莫间断，唯当不断增进串习！

于水蛇年二月初四日，米滂南杰所写。吉祥圆满！

---

## 译者说明

本篇依藏文原颂重新译出。"དྲན་པ"（正念）与"ཤེས་བཞིན"（正知）为止观修持中一对相辅相成之心所：正念司职忆持所缘、不令散失，正知则司职随时觉察心是否已然偏离所缘，二者合而为修心之哨兵与巡察。颂中"依托""执掌哨兵之职"一句，藏文原意近于"正念担起守卫、值哨之责"，喻正念如镇守边界之哨兵，随时防范杂念之侵扰，故如此译出，以存原意之生动。末句"孩子"（བུ）为米滂仁波切训诫弟子之习惯语，故径译如原。
