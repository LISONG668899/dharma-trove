# 佛子菩萨十地五道摄义

*华智仁波切 造*

顶礼与怙主文殊师利无二无别之上师！

现在，我将佛子菩萨十地五道的各种名相，以简明易懂的方式加以解说。总的来说，共有五道、十地。五道分别是：资粮道、加行道、见道、修道、无学道。十地则将在下面讲说修道的时候一并解说。

## 一、资粮道

在资粮道上，佛子菩萨——也就是"胜者之子"——发起善妙的意乐，即愿菩提心与行菩提心。在如理如法地生起了这种世俗菩提心之后，便对胜义菩提心，也就是见道无分别智，生起希求胜解，并以此希求胜解作为道用来修持，所以称为"胜解行地"。

资粮道又分为下、中、上三品。处于下品资粮道时，何时能够进入加行道尚不确定；处于中品资粮道时，则确定下一世必定能够进入加行道；处于上品资粮道时，则确定此生此世便能进入加行道。

之所以称为"资粮道"，一方面是因为在这个阶段，我们要特别精进地积累福德资粮；另一方面，也因为这正是历经无数大劫积累资粮的开端。

### 下品资粮道

根本颂中说：

```
四念处等，愿趣入！
```

这句话的意思是，在下品资粮道阶段，我们主要修持四念处。

**第一，身念处（1）**【译注：华智仁波切在根本颂中，以粗体数字标出三十七菩提分法的次第，本译文亦依原文以括注数字标示，以便读者掌握脉络】。所谓"身"，外而言之是指外在的器世间，内而言之是指自己的身体，中间则是指其他有情众生的身体。我们以精细的智慧，对这三者一一加以观察、抉择，然后在等持中安住于"这一切在胜义中都不成立、其自性犹如虚空一般空性"的境界之中；在后得位中，则修习将一切观为如幻如梦。

这个修法，对于对治贪着身体尤其有用。我们可以观想：这个身体里充满了血液、脓液等种种不净之物，是四百零四种疾病、六万种鬼祟障碍，以及各类细菌微生物寄居繁衍的巢穴；也可以观想，有朝一日命终之后，这具身体终将腐烂、化为白骨。

**第二，受念处（2）**。我们以精细的智慧，对乐受、苦受、舍受三者一一观察抉择，然后在等持中安住于"一切受本来无生、离于生起"的境界；在后得位中，则修习将一切感受观为如芭蕉树般毫无实质，其本性即是苦。

**第三，心念处（3）**。我们以精细的智慧，观察分析广、中、狭三种意识活动，然后在等持中安住于其空性自性之中；在后得位中，须了知心的自性远离生灭、无所住著。

**第四，法念处（4）**。我们以善能分辨的精细智慧，抉择一切属于有为法范畴的诸法，然后安住于"诸法自性平等"的认知之中；在后得位中，则观一切诸法犹如八种譬喻：如梦、如幻、如阳焰、如眼翳所现之影、如镜中像、如谷响、如寻香城、如变化所现之幻事。

再者，就第一种而言，"身体"本是以精细智慧加以观察分析的所观对境；然而一旦对这个所谓的"身体"彻底观察分析、破除了它真实存在的一切妄执之后，随之显现的空性——犹如虚空一般——便成为身念处真正的所缘对境。其余三种念处也是同样的道理：四念处虽然各自有不同的所缘对境，但归根结底，无非都是等持位如虚空般的空性，与后得位如幻的显现这两者而已，此外别无其他，四者的一切内涵都摄在这两者之中。

### 中品资粮道

在中品资粮道阶段，我们主要修持四正断。

第一，对于尚未生起的不善法，努力使其不生（5）；第二，对于已经生起的不善法，迅速加以断除（6）；第三，对于尚未生起的善法，努力使其生起（7）；第四，对于已经生起的善法，努力使其进一步增长（8）。

之所以称为"四正断"，是因为要断除一切不善法的实质，以及一切障碍善法生起的因素，共有四种。这主要是就身、语、意三门的行持而言，其力用尤为强猛。

### 上品资粮道

在上品资粮道阶段，我们修持四神足。

第一，**欲神足（9）**：对等持怀有欢喜与希求，因而不为不信、邪见等所动摇，以此欢喜、希求之心趣入并修习等持。

第二，**勤神足（10）**：为了安住于等持之门中，勤勉精进地努力，从而遣除等持的过患与障碍，并成办应有的功德，纵遇违缘也不为其所转。

第三，**心神足（11）**：令心安住一处，不被分别念与随他自在等所分裂，从而现前禅定等持。

第四，**观神足（12）**：在一切威仪、日常行持中，都能护持等持的相续，以此作为获得神通等神变力用的方便。

这四种之所以称为"支"（足），是因为它们能够支撑、成办各种神变功德所依赖的等持。

在上品资粮道，通过现前种种神变，佛子菩萨能够以神变力亲赴诸佛真实安住的刹土，在那里听闻、受持成百上千无量的法门，并以智慧之力摄持这些法义，从而获得相续不断的等持，如江河之流般绵延不绝。

以上正如前面所说，此阶段以积累资粮为主，所以在五道之中，居于第一位，称为"资粮道"。

## 二、加行道

加行道之所以如此命名，是因为它是趣入、连接见道无分别智——亲见实相——的桥梁。

加行道分为四个阶段：

——前二者，暖位与顶位，此时何时能够进入见道尚不确定；

——后二者，忍位与世第一法位，此时则确定此生此世必定能够进入见道。

根本颂中说：

```
暖顶等，愿趣入！
```

这段话的含义是这样的：

见道的无分别智，犹如能够焚烧烦恼障的烈火。然而，就像钻木取火之时，火尚未真正燃起之前，木头相互摩擦已经会产生一定的热度一样，在见道无分别智真正生起之前的先兆，是相续中会生起前所未有的、有别于以往的"暖相"，同时较为粗重的烦恼也会暂时被压伏，这便是加行道的暖位。之所以称为"顶位"，是因为它是一切世间善根的巅峰。到达忍位时，能够对空性这一诸法实相的义理毫无怖畏地予以忍可、接受，所以称为"忍位"。世第一法位之所以如此命名，是因为它是一切属于世间修所生法当中最为殊胜的顶点。

暖、顶、忍、世第一法这四者，合称为"顺抉择分"。

在暖位与顶位这两个阶段，我们主要修持五根：

第一，**信根（13）**：对见道的智慧生起殊胜的希求胜解。

第二，**精进根（14）**：不懈怠、不松懈地精进努力，寻求令见道智慧在自相续中生起的方便方法。

第三，**念根（15）**：护持增上戒学，使其不致衰损、退失。

第四，**定根（16）**：与增上定学相应，能够如理安住于等持之中。

第五，**慧根（17）**：通过增上慧学，令实相正见在自相续中生起，并如理修持。

到了忍位与世第一法位这两个阶段，前面所说的这五种根，各自都远离了与其相对应的障碍——不信、懈怠、忘失、散乱、非正知——彻底不再被这些障碍所动摇，这时信（18）、精进（19）、念（20）、定（21）、慧（22）这五种功德，便称为"五力"。

## 三、见道

之所以称为"见道"，是因为这是首次亲见超越世间的圣者智慧的阶段。

根本颂中说：

```
念与择法等，愿得地！
```

这段话中间部分的含义是这样的：

**择法觉支（23）**，总的来说，是指能够精细辨别一切诸法各自体相的智慧；此处特指对四谛各自体相所生起的法智、法忍，以及随后生起的类智、类忍，也就是所谓的"十六刹那忍智"，即在这十六个刹那当中，如实显示出一切诸法各别体相的法性实相远离一切戏论，并对此毫无怖畏地予以忍可。

除此之外，还有**念觉支（24）、精进觉支（25）、喜觉支（26）、身心轻安觉支（27）、定觉支（28）、舍觉支（29）**，连同择法觉支，合称为七觉支。

这里所说的"舍"，是指心保持平等、不偏不倚。比如，具足这种舍心的菩萨，即便右边有人以旃檀香涂抹其身，左边有人正在割截其肉，也不会对前者生起贪爱、对后者生起嗔恚，二者一律平等对待。

如此认知、并最终圆满这种见道智慧的真实见地之后，菩萨便超越了凡夫异生，成为比一般人更为殊胜的"圣者"（阿黎耶）。

### 初地

这是圣者菩萨十地当中的第一地，即首次亲见诸法实相真谛的阶段，所以称为"见道"。到达此地时，还会生起前所未有的、极为丰盛的欢喜，因此这一地也称为"极喜地"。

在这一地，悭吝的障碍及其相关的习气得以清净，布施波罗蜜多得以圆满，菩萨由此获得十二种、每种各一百的功德：

——刹那之间，能够趣入、出定一百种等持；

——能够亲见一百位佛陀，并蒙受加持；

——能够前往一百个佛刹；

——能够震动一百个世界；

——能够以光明照耀一百个世界；

——能够成熟一百位有情；

——刹那之间，能够示现一百个大劫；

——能够以智慧照见过去一百个大劫；

——能够以智慧照见未来一百个大劫；

——能够开启一百种法门；

——能够示现一百种化身；

——每一化身，又能各自示现一百位眷属。

到达这一地时，菩萨能够转生为南瞻部洲之王。

## 四、修道

修道，就是对见道时已经现见的智慧，反复修习、逐渐串习熟悉。此时所修学的，是八圣道支。

根本颂中说：

```
正见、正思、正语等，愿修行！
```

这段话的含义是这样的：

由于见道时已经现见了无分别智，因此对实相如是本性的真实证悟，便是**正见（30）**。

依靠这种正见的力量，一切烦恼都不再于心中生起，一切分别念自然而然都趋于善妙，这便是**正思惟（31）**。

心既已趋于善妙，身语二门便不会生起不善，凡有所言，都利益众生，这便是**正语（32）**。

无论做任何事情，都是为了利益他人，这便是**正业（33）**。

时时知足，不被五种邪命所染污，这便是**正命（34）**。所谓五种邪命，即：诈现异相、旁敲侧击、以利求利（巧取）、强取豪夺、贪图厚利以少博多（诈现小惠）。以上五种邪命，都须彻底断除。

为利益他人而精勤不懈，遣除倦怠与疲厌，这便是**正精进（35）**。

时时护持正念的相续不断，这便是**正念（36）**。

安住于第四禅等禅定等持，趣入种种三摩地，这便是**正定（37）**。

修道所含的九地，是如下逐渐经历的：

### 二地

在修道下下品阶段，戒波罗蜜多得以圆满，与破戒相关的一切障碍得以清净。

与前面所说见道时相同的功德也一并获得，只是此处的十二种功德，其数量各为一千：刹那之间能够趣入、出定一千种等持，等等，均比前地增至千倍。

到达此地时，菩萨能够转生为四大部洲之主。

这第二地称为"离垢地"，因为它远离了破戒的一切垢染。

### 三地

在修道中下品阶段，忍辱波罗蜜多得以圆满，与嗔恚相关的一切障碍得以清净。

获得十二种、每种各十万的功德：刹那之间能够趣入、出定十万种等持，等等。

到达此地时，菩萨能够转生为三十三天之主，如帝释天一般。

这第三地称为"发光地"，因为到达此地的菩萨，能够以正法之光，照耀那些被深重恶习黑暗所笼罩的有情众生。

### 四地

在修道上下品阶段，精进波罗蜜多得以圆满，与懈怠相关的一切障碍得以清净。

获得十二种、每种各千万的功德：刹那之间能够趣入、出定千万种等持，等等。

到达此地时，菩萨能够转生为夜摩天（原文作"双子座"之主，指焰摩天王）之主。

这第四地称为"焰慧地"，因为到达此地的菩萨，能够焕发出焚烧烦恼障、所知障的智慧烈焰之光。

### 五地

在修道下中品阶段，禅定波罗蜜多得以圆满，与散乱相关的一切障碍得以清净。

获得十二种、每种各一亿的功德：刹那之间能够趣入、出定一亿种等持，等等。

到达此地时，菩萨能够转生为兜率天之主。

这第五地称为"极难胜地"，因为到达此地的菩萨，既能安住于等持之中成办自利，同时也能兼顾成办利他之事业，二者能够并行不悖，极难成就而能成就。

### 六地

在修道中中品阶段，般若波罗蜜多得以圆满，与无明愚痴相关的一切障碍得以清净。

获得十二种、每种各百亿的功德：刹那之间能够趣入、出定百亿种等持，等等。

到达此地时，菩萨能够转生为兜率天（原文如是，或指化乐天）之主。

这第六地称为"现前地"，因为到达此地的菩萨，轮回与涅槃的一切诸法都能现量了知、现前明见。

### 七地

在修道上中品阶段，方便波罗蜜多得以圆满，与不善巧方便相关的一切障碍得以清净。

获得十二种、每种各一万亿的功德：刹那之间能够趣入、出定一万亿种等持，等等。

到达此地时，菩萨能够转生为他化自在天之主。

这第七地称为"远行地"，因为到达此地，已经远远超越了轮回的境地。

以上初地至七地，合称为"七不净地"，因为处于这些阶段的菩萨，仍然能够直接现见不清净的显现。

### 八地

在修道下上品阶段，力波罗蜜多得以圆满，与力用羸弱相关的一切障碍得以清净。

获得十二种功德：刹那之间能够趣入、出定其数量等同于十万个大千世界微尘数的等持，等等。

到达此地时，菩萨能够转生为一个大千世界之主。

这第八地称为"不动地"，因为到达此地的菩萨，不再被有相与无相的分别念所动摇；此时，五根与染污意都发生转依，得以自在游历清净刹土，成所作智与妙观察智也得以现前。

### 九地

在修道中上品阶段，力波罗蜜多（愿波罗蜜多）得以圆满，与愿望不能如愿成就相关的一切障碍得以清净。

获得十二种功德：刹那之间能够趣入、出定其数量等同于百万个大千世界微尘数的等持，等等。

到达此地时，菩萨能够转生为大梵天，作二千大千世界之主。

这第九地称为"善慧地"，因为到达此地的菩萨，具足圆满的四无碍解等功德。

### 十地

在修道上上品阶段，智慧波罗蜜多（智波罗蜜多）得以圆满，到达此地的菩萨从此远离了一切所知障。

获得诸多功德，例如：刹那之间，能够趣入、出定其数量等同于不可思议诸佛刹土中不可思议微尘数目的等持；如同前面各地一样，仍是十二种功德，直到眷属圆满这一项，此时是指被数量等同于不可思议佛刹微尘数的眷属所环绕。

到达此地的菩萨，能够转生为净居天之主，作为一佛的补处，广大利益众生。

这第十地称为"法云地"，因为到达此地的菩萨，能够从总持与等持的云端，向所调伏有情的刹土之中，降下犹如雨水一般的正法甘霖。

## 五、无学道

在这一阶段，菩萨自身发出无量光明，供养过去、现在、未来三世一切诸佛，诸佛也回赐以广大加持之光。以此对治力，凭借犹如金刚一般的等持，摧毁了细微所知障——那些潜藏未现的习气，从而现前圆满正等正觉的果位。

在五道之中，这是第五道，之所以称为"无学道"，是因为从此以后，再也没有任何道需要继续修学。

现前无学道的果位时，菩萨便到达了第十一地，即"普光地"。

愿善妙吉祥！
