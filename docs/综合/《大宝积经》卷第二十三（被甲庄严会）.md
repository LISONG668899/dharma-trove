# 《大宝积经》卷第二十三（被甲庄严会）

唐·三藏菩提流志 奉诏译

## 被甲庄严会第七之三

### 随入一切法

“又，无边慧！诸菩萨摩诃萨在无边的甲胄境界、无边的大乘境界、无边的大道境界中发心趣向。为什么？因为在一切处都能随入。诸菩萨摩诃萨为了随入一切法而披大甲胄，为了随入一切法而乘于大乘，为了随入一切法而住于此大道，因为对一切法得平等而发心趣向。

“然而这甲胄，不得少许法——无论内外、粗细、远近，过去、现在、未来，有为、无为，住与不住。若这甲胄对一切法不能抉择、不能决了、不能遍知、不能随入、不能作证、不能超过，就不可以名为披大甲胄；对一切法若能抉择、能决了、能遍知、能随入、能作证、能超过，才可以名为披大甲胄。

“又这大乘，也没有少许法——无论内外，乃至回向一切智智——不遍知、不随入、不作证、不超过的，所以此乘名为大乘、法善巧乘、至涅槃乘、无上上乘、无等等乘。又这大道，也没有少许法——无论内外——乃至能对一切诸法以平正大道而发心趣向；这平正之道，没有少许法不遍知的，所以此道名为无上道、无数量道、无等等道。

### 无量甲胄

“无边慧！诸菩萨摩诃萨披大甲胄，能遍入一切众生的心与心所行，能遍清净一切众生的杂染烦恼；乘于大乘，增长众生的一切善根；住于此大道，劝化众生修一切善法。

“无边慧！诸菩萨摩诃萨为了每一个众生、每一种心行，穷尽生死之际，长时流转，求智慧之乐，不舍甲胄，而能坚固地披上大甲胄、无量甲胄、难思甲胄、清净甲胄、无边甲胄、无取甲胄、知众生想甲胄、知无众生甲胄、知无我甲胄、知众生自性甲胄、随觉众生自性甲胄、知我自性甲胄、随觉我自性甲胄、知内自性甲胄、随觉内自性甲胄、知外自性甲胄、随觉外自性甲胄、知内外自性甲胄、随觉内外自性甲胄、知一切法自性甲胄、随觉诸法自性甲胄、知一切法无所得甲胄、知一切法自性无所得甲胄、了知一切诸法甲胄、无边甲胄、无中甲胄、无中边甲胄、非过去甲胄、非未来甲胄、非现在甲胄、无作甲胄、无作者甲胄。

【按】“求智慧乐”之“乐”，元、明本作“药”。

### 无所被而被

“无边慧！诸菩萨摩诃萨对于这甲胄，也无所披，也不随觉，也不决了，也不出离，也不现证：因为无甲胄而披甲胄，因为不随觉而能随觉，因为不决了而能决了，因为不出离而能出离，因为不现证而能现证，因为无所乘而乘大乘。对大乘不作施设，以无所施设而为施设；然而对大乘没有少许施设，若有施设就不是施设，因为那施设不可得、不可见的缘故。

“也没有乘可以安住，以无所得而住于大乘，远离趣向，不至于究竟，不到达涅槃，因为不可得，以非道为道。在道中发心趣向，是因为平正的缘故；这平正之道无所施设：谁来施设？在何处施设？从何处施设？也没有造作，也没有作者，也非和合，也非不和合，对一切厌离，对一切不求。为什么？因为这平正之道与一切法不异不同，不相应的缘故。

“不起法想，远离一切法，无垢无净；法性也是如此，无垢无净，所以这道名为无染之道；以不可趣向而为进趣，以不可摄取而为摄取。这道甚深，无生、无起，无出、无作，无得、无行，无处、无住，无障、无事；对一切事能显了，对一切事无差别；不随事而转，因为无事的缘故，到达无上之处。

“无边慧！诸菩萨摩诃萨对这甲胄、这乘、这道，应当这样了知。然而这甲胄、这乘、这道，无所可见，无所可知，因为不可得。谁披甲？谁乘此乘？谁行此道？也不可见，也不可知，也不可得。

### 劝勤修习与末世难闻

“无边慧！若诸菩萨摩诃萨听闻这法后不惊不怖，读诵宣说，对法的理趣无所违背，随顺修行而生爱乐，入于胜解，为了这法应当勤加精进；若对这法的决定理趣与善巧方便有所堪能，就披这甲胄，乘这乘，行这道；对这深法无所得的缘故，而发心趣向，穷尽生死之岸，成为正觉者，能以无边功德庄严出现于世间。

“无边慧！诸菩萨摩诃萨对这法应当生起爱乐，发起大精进而不放逸。若有众生对这深法刚刚生起爱乐，我说那人就得大饶益，何况能精勤不放逸、戒行清净而发心趣向的人。

“无边慧！你看这法多么广大，多么殊胜，多么清净。我对这法殷勤称赞，是想令众生生起爱乐，当得长夜的利益安乐，为了厌离、寂灭、遍知的缘故。无边慧！你又当看这法能授予世间、出世间具足的安乐。种种匮乏的众生，由于对这深法退失的缘故，远离了世间以及出世间一切具足丰饶的安乐。

“无边慧！你又当看如来现前时，这深妙的法宝多么丰饶，多么容易得到，你现在对这甚深之法应当勤加修习。那些愚夫在我演说这法宝时尚且不想听，何况能受持如来现前的丰饶法宝？他们不乐于听闻，不想咨问。若到末世后五百岁正法灭尽之时，佛、法宝与持法者三者都不现前，又怎能想听闻、爱乐、咨问呢？

“无边慧！然而在后时，若为如来善加加持的人，这深妙的法宝也能令其得到。无边慧！在那怖畏之时，这深妙的法宝实在没有损减，也没有灭尽，只是对这法没有听闻的人，没有受持的人；唯有在我面前渴仰听闻、披甲胄的人，在那时才能爱乐听受这法。那时的众生听闻这法后能生起净信，我说那人当得成就这广大之法，何况在现今对这法能生净信、勤修行的人。

### 以法丰足匮乏众生

“无边慧！诸菩萨摩诃萨披无上甲胄、无量甲胄、大甲胄时，应当这样想：‘我为了一切匮乏的众生，就是缺乏戒的、缺乏闻的、缺乏慧的、缺乏解脱的、缺乏解脱知见的，以这大法使他们丰足。’由于这大法使之丰足的缘故，令一切匮乏都得舍离；戒财、闻财、慧财、解脱财、解脱知见财，都令其富饶；贪瞋痴之火都令其息灭；一切众病都令其除愈；无上的良药都令其服用。服了这药的缘故，众病消除，获得大安乐，永离有余，证得清凉之性的无上涅槃，不再有其余的思惟观察，不求一切有为、无为。为什么？因为这涅槃是最上的安乐，一切所求更无其余，所求已永远止息灭尽的缘故。

### 此乘三世诸佛所乘

“无边慧！诸菩萨摩诃萨披上这样的大甲胄之后，又为了哀愍摄取一切众生而乘这大乘。这大乘，过去诸佛已乘而出离，未来诸佛当乘而出离，现在诸佛今乘而出离。（其实）没有去者，也没有乘，也没有出离。为什么？因为空、无相、无愿、无生、无作者的缘故，非已出离，非今出离，非当出离。乘此乘的人这样出离，是为善出离而无执著。对于一切法，非有和合，非无和合，无来无去。这乘、这道出离时，也非和合，无来无去；这乘、这道在大甲胄中出离时，也非和合，非不和合，无来无去，因为不可得的缘故。

“无边慧！诸菩萨摩诃萨以这甲胄、这乘、这道而发心趣向。又以这甲胄、这乘、这道发心趣向时，不作这样的念头：‘无论凡夫法、声闻法、缘觉法、诸佛法，那些法离我或远或近。’也不作这样的念头：‘空、无相、无愿、无生、无作，那些法离我或远或近。’也不作这样的念头：‘厌、离、灭，乃至大般涅槃，那些法离我或远或近。’

### 诸法真实性相不可言说

“无边慧！这大甲胄、这乘、这道，是一切菩萨、一切声闻、一切缘觉、一切众生所不能动摇的，而发心趣向阿耨多罗三藐三菩提。无边慧！诸佛世尊对这甲胄、这乘、这道得不动之后，而般涅槃。为什么？因为一切诸法不可动摇的缘故；一切法性与法性之相，相已远离、相已清净、相已遍清净的缘故。不可以相来观察、作胜观察、作遍观察。一切法相与法相之性，不可以性来观察、作胜观察、作遍观察。一切诸法无性无相，不可显示，不可言说，这就是诸法的真实性相。

“无边慧！这甲胄、这乘、这道的真实之相不可显示，不可言说，也是这样。为了令众生了知，增长一切法的光明，对这甲胄、这乘、这道，假借施设而略说。

### 随义行而不随语言

“你现在若想对这甲胄、这乘、这道随义而行，不要依于施设，不要依于显示，不要依于言说，应当随义而行。随义而行的人，没有少许应行之事，没有少许随行之事。对于非义，不应随行；对于是义，则应随行。随义而行时，不随声音而行，不随文字而行，不随语言而行；不随（它们）而行的人，就不随它们而转。

“什么是义？就是秘密之说。对于秘密之说，应当随之觉了，应当以信而行。以信而行的人，在这义中无所分别；对于无分别，才应随行。应当随行的，乃是不行，也不随行。为什么？因为在这义中，没有少许行，没有少许随行，没有少许遍行，远离行的缘故。不应随行：不随顺与菩提相应而行，不随顺与流转相应而行；对那相应与不相应都不作意，都非正念，因为念已清净，所以不应行。

“无边慧！在这义中，你应当随行，不要另有所行；若另外随行，就会妄失。（那样就会）随逐音声，随逐文字，随逐语言，对那语言不能舍离。遍知音声，超过文字，随觉语言，就不随之而行，就不随之流转。在这义中这样随行、这样随入，就没有少许行，因为行已止息的缘故。

【按】“则为妄失”之“妄”，明本作“忘”。“无少有行”之“少”，宫本作“有”。

“无边慧！随义而行时，不要再以行去行于义。若不以行去行于义，就是不来、不再退还。若得不来、不再退还，就以这甲胄、这乘、这道随顺趣向阿耨多罗三藐三菩提，为诸众生作大饶益。

“无边慧！若对这法这样宣说、随义而行、能随入的人，心不颠倒，没有疑惑，成就胜解。对这甲胄、这乘、这道若尚未摄取，就能摄取而迅速发心趣向；若有尚未披这甲胄的，就能迅速披上；若有尚未乘这乘的，就能迅速乘上；若有尚未住于这道的，就能迅速安住。无边慧！那些众生当摄取广大的福德资粮，为佛世尊所护念，与法无违，与僧同行。无边慧！你已摄取无量善根，在后来的末世当以这法摄受诸众生，为诸众生荷负重担，所获的福德，其量难以言说。”

那时，世尊说偈道：

```
菩萨无畏者，如是被甲时，
为利诸众生，乃被无边甲。
众生若贫乏，弊苦无法财，
无戒无多闻，无慧无解脱；
被此无边甲，令法致丰饶，
以法丰饶故，一切获安乐。
为舍诸贫苦，演说无上法，
闻者皆离尘，住斯安乐道。
戒蕴备充足，多闻如大海，
便得最上慧，由斯能断缚。
解脱遍照明，解脱正知见，
若能现证者，一切获安乐。
贪瞋痴大火，恒烧遍炽然，
众生由是苦，彼火我令灭。
授诸众生药，一切病皆除，
若病消除已，得至涅槃界。
永舍一切余，趣于安乐处，
从彼安乐中，无有退还者。
一切有为乐，于彼不复求，
无上大安乐，于彼皆当证。
以无戏论法，成熟诸众生，
究竟大安乐，一切皆当得。
如是发趣者，一往不复还，
出过于发趣，常得胜安乐。
于大安乐中，乐欲不乐欲，
发趣无发趣，一切皆当断。
如是被甲已，当乘于此乘，
为愍诸众生，一切皆摄取。
```

（大意：菩萨无畏者这样披甲时，为了利益诸众生，才披无边之甲。众生若贫乏，困苦而无法财，无戒、无多闻，无慧、无解脱；披上这无边之甲，令他们的法财丰饶；因为法财丰饶，一切都获得安乐。为了舍除诸贫苦，演说无上之法，听闻的人都远离尘垢，住于这安乐之道。戒蕴充足完备，多闻如同大海，便得最上的智慧，由此能断除系缚。解脱普遍照明，具解脱正知见，若能现证，一切都获安乐。贪瞋痴的大火恒常燃烧，遍处炽然，众生因此受苦，我令那火熄灭。授予诸众生药物，一切病都除去；若病消除之后，就得到达涅槃界。永舍一切有余，趣向安乐之处，从那安乐中无有退还的人。一切有为之乐，对它们不再希求；无上的大安乐，对它们都当证得。以无戏论之法成熟诸众生，究竟的大安乐，一切都当获得。这样发趣的人，一往不再退还，超出于发趣，常得殊胜的安乐。在大安乐之中，乐欲与不乐欲、发趣与无发趣，一切都当断除。这样披甲之后，当乘此乘，为了哀愍诸众生，一切都加以摄取。）

【按】“为利诸众生”之“诸”，宋、元、明、宫本作“益”。

```
过去正遍知，此乘已出离，
未来正遍知，此乘当出离，
现在佛世尊，此乘今出离，
故于此大乘，无不皆乘者。
一切诸最胜，世间大依怙，
以此乘出离，不起于乘想，
非乘以为乘，非道以为道，
非出以为出，出离故无上。
此乘出离时，曾无少出离，
以空无有相，无愿无作故。
非乘非出离，乃名为大乘，
一切悉平等，由是而发趣。
此乘无和合，亦无不和合，
发趣无上道，现证大安乐。
此乘无相应，亦无不相应，
无处无所依，由是而发趣。
此道无有来，此道亦无去，
行斯正道者，寂静而发趣。
我说于此道，此乘此甲胄，
于法无所依，寂静最无上。
```

（大意：过去的正遍知已乘此乘而出离，未来的正遍知当乘此乘而出离，现在的佛世尊今乘此乘而出离，所以对于这大乘，没有不乘的。一切诸最胜者、世间的大依怙，以此乘出离，而不起乘之想；以非乘为乘，以非道为道，以非出为出，因为出离，所以无上。此乘出离时，从未有少许出离，因为空、无相、无愿、无作的缘故。非乘、非出离，才名为大乘，一切都平等，由此而发趣。此乘无和合，也无不和合，发趣无上之道，现证大安乐。此乘无相应，也无不相应，无处所也无所依，由此而发趣。此道无来，此道也无去，行这正道的人寂静而发趣。我所说的此道、此乘、此甲胄，对于法无所依，寂静而最为无上。）

```
一切凡夫法，一切声闻法，
一切缘觉法，一切不可得。
于佛一切法，离垢无上法，
不远亦不近，一切不可得。
于空无相法，无愿无作法，
不远亦不近，一切不可得。
于厌离灭法，涅槃寂静法，
不远亦不近，一切不可得。
此乘此甲胄，此道无所取，
无上不可动，毕竟不可得。
一切法自性，真实希有相，
不可以施设，诸法性空故。
此乘此甲胄，此道无显示，
如诸法自性，彼性亦如是。
一切诸法中，相性不可得，
于无相性法，我略为开示。
一切诸法中，一切自性相，
于我如是说，毕竟无所有。
此乘及此道，甲胄自性相，
于彼求言说，毕竟亦非有。
言说非有故，是为希有相，
于彼言说中，语相亦非有。
诸法不可量，无胜无边量，
一切不可测，是故法无上。
此乘此甲胄，此道亦如是，
于彼无相中，如是应随入。
为令诸众生，遍知勤修习，
速逮法光明，故我如是说。
```

（大意：一切凡夫法、一切声闻法、一切缘觉法，一切都不可得。对于佛的一切法、离垢的无上法，不远也不近，一切都不可得。对于空、无相之法，无愿、无作之法，不远也不近，一切都不可得。对于厌、离、灭之法，涅槃寂静之法，不远也不近，一切都不可得。此乘、此甲胄、此道无所取，无上而不可动摇，毕竟不可得。一切法的自性是真实希有之相，不可以施设，因为诸法性空的缘故。此乘、此甲胄、此道无可显示，如诸法的自性，它们的性也是如此。在一切诸法中，相与性都不可得；对于无相无性之法，我略为开示。在一切诸法中，一切自性之相，依我这样所说，毕竟无所有。此乘、此道与甲胄的自性之相，对它们求取言说，毕竟也不存在。因为言说不存在，这就是希有之相；在那言说之中，语言之相也不存在。诸法不可量，无胜无边量，一切不可测度，所以法为无上。此乘、此甲胄、此道也是这样，在那无相之中，应当这样随入。为了令诸众生遍知而勤修习，迅速获得法的光明，所以我这样宣说。）

【按】“毕竟不可得”之“竟”，宋、元、宫本作“究”。

```
诸法无语言，一切不可说，
于彼诸法中，一切应随入。
以法无言故，于彼应随行，
行无少有行，一切法无行。
无求而乐求，无行而随行，
如是随行者，于义不观察。
汝今于实义，一切应随行，
音声及语言，于彼勿随转。
音声语言中，若得不随转，
于义乃随行，是为求义者。
何者名为义，应知秘密说，
以信无分别，是义乃随行。
明了如是义，能于秘密说，
无执无所著，不行不随转。
若有随行者，彼则随执著，
若无随行者，一切不随转。
由是正忆念，远离于随转，
菩提及生死，二俱不相应。
于彼亦无念，无念为正念，
于念清净故，说为清净者。
若异此修行，远离无上法，
汝应于是义，如说而修习。
若随语言者，是则随音声，
于彼不超过，同于世间法。
音声及文字，不应随彼转，
应知真实义，无行以随行。
实义无音声，亦无有文字，
超过语言故，乃名为实义。
是义应随行，随行无所有，
以行止息故，乃名为实义。
于真实义中，不行以为行，
斯则不退转，不舍于甲胄。
```

（大意：诸法没有语言，一切都不可说，在那诸法之中，一切都应当随入。因为法无言说，对它应当随行；所行没有少许行，一切法无行。无求而乐求，无行而随行，这样随行的人，对于义不作观察。你现在对于真实义，一切都应当随行；对于音声与语言，不要随之而转。在音声语言之中，若能不随之而转，于义才是随行，这是求义的人。什么名为义？应知是秘密之说；以信而无分别，于这义才是随行。明了这样的义，对于秘密之说，无执无著，不行也不随转。若有随行的，他就随之执著；若无随行的，一切都不随转。由此正确忆念，远离随转，菩提与生死二者都不相应。对于它们也无念，以无念为正念；因为念已清净，所以说为清净者。若与此不同而修行，就远离无上之法；你应当对这义如所说而修习。若随顺语言，就是随顺音声，对它们不能超过，就同于世间之法。对于音声及文字，不应随之而转；应知真实义，以无行而随行。真实义没有音声，也没有文字，因为超过语言，才名为真实义。这义应当随行，而随行无所有；因为行已止息，才名为真实义。在真实义中，以不行为行，这就不退转，不舍甲胄。）

```
随顺大甲胄，大乘及大道，
趣于安乐处，利益诸众生。
此诸安隐法，我今为汝说，
汝当随义行，能断汝疑惑。
若乘此乘者，乘已当发趣，
速诣大菩提，现证无上觉。
于此最上乘，不乘为速乘，
于道于甲胄，其义亦如是。
于此无上法，精勤修习者，
彼诸众生等，为佛之护念。
于后怖畏时，汝当开此法，
广为诸众生，而作利益者。
于后怖畏时，若能开此法，
所生无上福，其数不可量。
```

（大意：随顺大甲胄、大乘与大道，趣向安乐之处，利益诸众生。这些安稳之法，我现在为你宣说，你应当随义而行，能断除你的疑惑。若乘此乘，乘了之后当发趣，迅速趣往大菩提，现证无上觉。对于这最上之乘，以不乘为速乘；对于道、对于甲胄，其义也是这样。对于这无上之法精勤修习的那些众生，为佛所护念。在后来怖畏之时，你应当开示这法，广为诸众生作利益。在后来怖畏之时，若能开示这法，所生的无上福德，其数不可计量。）

【按】“乘已当发趣”之“已”，《大正藏》作“己”，CBETA 校改作“已”。

### 甲胄、乘、道之名

“无边慧！诸菩萨摩诃萨所披的甲胄名为大胜，也名为无边胜，也名为大庄严；所乘之乘名为大商，也名为无边光，也名为妙庄严；所行之道名为无量庄严资粮，也名为无量方便资粮。以这道的缘故，诸善丈夫发心趣向阿耨多罗三藐三菩提。

### 一切义成王本生

#### 栴檀香光明如来与光明国

“又，无边慧！在过去久远，超过无量劫，又加倍那么多劫，有佛出世，号为栴檀香光明如来、应供、正遍知、明行足、善逝、世间解、无上士、调御丈夫、天人师、佛、世尊。劫名电光，国名光明。那时那刹土大地平坦如掌，没有诸杂秽、瓦砾、荆棘，以黄金、白银作为沙堆，成行排列于国界之中，见者欣悦。

“那时四天下，每一洲都广二亿由旬；每一洲中又有四万八千座大城，每一座城广十由旬，长二十由旬，城墙周围环绕，庄严华丽，极其高峻。每一座城有八俱胝人居住其中，有一万个聚落、一千座园苑围绕庄严。这国界中又有种种花树、果树、香树、衣树、上味之树以及金刚树交错庄饰。池沼泉流，岸边端直，八功德水充满其中，优钵罗花、波头摩花、拘物头花、芬陀利花，杂色辉映，无处不遍。

【按】“皆广二亿”之“二”，宫本作“三”。

“那栴檀香光明如来寿命六十八俱胝那由他年，又有六十俱胝那由他诸声闻众作为眷属。那时的人民容貌端正，安稳快乐，贪瞋痴薄，容易开示，以少许劝化就能遍知诸法的性相。

#### 一切义成王与香光池

“无边慧！又在那时，有一位转轮王名叫一切义成，七宝具足，四天下都归附受化。那阎浮洲有一座大城，那城纵横四十由旬，人民兴盛，安稳丰乐。宫城之内广五由旬，以七宝间隔装饰，美妙的多罗树垂挂着诸铃铎，真金罗网弥覆其上。

“国王的正殿纯是绀琉璃，广一由旬，四面有一千根柱子；那殿上又有一千座楼，高峻庄丽，以众宝装饰。在那殿前有一大香池，周围环绕，澄澈清净；其旁又有十六个香光小池，以七宝所成，排列围绕。每两池之间有渠道激流注水，发出美妙的声音，如同演奏众乐。每一个小池有八条阶道，香光大池有三十二条阶道，每一条阶道都是纯金所成，宝树成行，宝网弥覆，上妙香气遍满城中，所以称那池名为香光。

【按】“复有千楼”之“千”，宫本作“十”。

“无边慧！那转轮王有四位夫人：一名无边音，二名贤善音，三名众妙音，四名鹅王音。每一位夫人各有两个儿子：一名不空胜，二名贤胜，三名龙胜，四名胜音，五名妙音，六名梵音，七名胜云，八名云音。他有婇女六亿，诸子一万。

#### 空中如来劝发

“那时那国王在内宫中与他的眷属娱乐嬉戏，忽然在空中见到一位如来的妙色之身。那时那如来就告诉国王说：‘大王！应当披无上甲胄，乘无上之乘，而发心趣向阿耨多罗三藐三菩提，授予诸众生智慧之药，不要贪著人天的五欲。这大甲胄能摄受无上的安乐，这无上之乘能引入无上的园苑，进入其中的人不再退还。一切人天的种种诸欲，都是无常变坏之法，其势不能久住，须臾之间就会磨灭。’

“无边慧！那时一切义成大王听到这些话后，对那如来说道：‘谁能开示这大甲胄，使我如那甲胄而庄严披上？谁能开示这大乘，使我如那大乘而乘御？谁能开示这大道，使我如那大道而发趣？’

“那时那如来告诉一切义成大王说：‘大王应当知道，有栴檀香光明如来，大王应当前往他那里，他当为大王演说这法——披大甲胄，乘于大乘，趣于大道。’那如来这样说完，忽然不见了。

#### 出家修学

“无边慧！那时一切义成大王见到这事后，战栗毛竖，生起希有之心，便生怖畏，不再乐于人天的种种欲乐，厌舍一切诸行有为，求大甲胄、大乘、大道，就与八个儿子、四位夫人以及其余诸子、婇女、侍从，一同前往那栴檀香光明如来所。

“到了那里之后，与他的眷属恭敬作礼，稽首佛足，就以一百檀卢那的七宝杂花散在如来、应、正遍知身上，又以无量支婆罗奉献给如来及声闻众，又以一切安乐资具满一万年供养。从此以后，舍弃王位，与他的眷属在栴檀香光明如来的法中出家。

【按】“檀卢那”，梵语音译，是容量单位；“支婆罗”，梵语音译，即衣。

“无边慧！那时那栴檀香光明如来知道一切义成比丘及其眷属有至诚乐法之心，便为他们开示甲胄庄严、大乘庄严。他们听了之后，发起坚固之心，为了深法不惜身命，端坐思惟，精勤不退，常亲近如来，对世间的一切诸欲得以心念不动。

#### 无所见而得忍授记

“无边慧！那时那如来问一切义成比丘说：‘善男子！你现在是披大甲胄、乘于大乘、发趣于道吗？以这道的缘故，能成就一切智智、无等等智。你应当如理精勤修习。’

“那一切义成比丘对栴檀香光明如来说：‘世尊！我在现在，不见有名为甲胄的法，也不见有能披甲胄的人，也不见有披甲所从之处，也不见有披甲之处。世尊！我不见有名为乘的法，也不见有乘大乘的人，也不见有乘之所从，也不见有乘大乘之处。世尊！我不见有名为道的法，也不见有由此道而已发趣、今发趣的人，也不见有道之所从，也不见有道的处所。世尊！我对于阿耨多罗三藐三菩提，无论远近、过去未来现在，都无所得、无所见。如我现在这样观察时，实在没有少许法可以亲近、可以证得。若我无所证，世尊难道应当问我说：“你是披大甲胄、乘于大乘、发趣于道吗？”世尊是一切知者、一切见者，像我们这样对法的修行，唯有如来才能了知，不是诸声闻、缘觉的境界。’

“无边慧！那一切义成比丘在如来面前这样说时，与他的眷属便得到菩萨的无生法忍；由于得法忍的缘故，都不退转。那时栴檀香光明如来为他们全部授记：过五百阿僧祇劫，当证阿耨多罗三藐三菩提。他们听到授记，欢喜踊跃，上升虚空，高七多罗树，就以偈颂赞叹如来说：

```
无量大名称，挺特如山王，
世尊一切智，能演诸功德。
佛眼悉明见，犹如日照临，
尊严大会中，我礼如来足。
无量德资粮，佛智已圆满，
我等亦当得，世尊无上智。
无上大光明，普照于人天，
开示诸法藏，无边功德海。
智慧常无失，正觉离烦恼，
慧光大精进，我礼深功德。
大龙大庄严，众相以严身，
安住如须弥，御众无伦匹。
能为世导师，映蔽人天众，
演说无所畏，我礼胜丈夫。
世尊大牟尼，无边功德海，
能开我法眼，令我被甲胄。
然我一切时，为乘大乘者，
常于此胜道，发趣更无余。
牟尼勇猛尊，觉知一切法，
世无有过者，我等咸归命。
```

（大意：您有无量的大名称，挺拔特出如同山王；世尊具一切智，能演说诸功德。佛眼明见一切，犹如太阳照临；在尊严的大会之中，我礼敬如来之足。佛以无量功德资粮，智慧已经圆满；我们也当获得世尊的无上之智。您以无上的大光明普照人天，开示诸法宝藏，是无边的功德海。智慧常无失误，正觉而远离烦恼，具慧光与大精进，我礼敬您甚深的功德。您是大龙，有大庄严，以众相庄严其身，安住如须弥山，统御大众无与伦比。您能为世间导师，映蔽人天大众，演说无所畏惧，我礼敬殊胜的丈夫。世尊大牟尼是无边的功德海，能开启我的法眼，令我披上甲胄。然而我在一切时都为乘大乘的人，常在这殊胜之道上发趣，更无其他。牟尼勇猛之尊，觉知一切法，世间没有超过您的，我们都归命于您。）

#### 成佛与结说

“无边慧！那栴檀香光明如来、应、正遍知说这法时，成熟了无量无数的众生。一切义成比丘从此以后，与他的眷属供养承事无量无数诸佛世尊，过五百阿僧祇劫，证得阿耨多罗三藐三菩提，号为超无边境界王如来。那佛刹土所有功德广长之相，也如栴檀香光明如来、应、正遍知的光明世界一样，没有差异，诸声闻众其数无量。国王的夫人、诸子与眷属，也过五百阿僧祇劫，都证得阿耨多罗三藐三菩提。

“无边慧！诸菩萨摩诃萨披大甲胄，乘于大乘，在这道中执持大法炬，作大法明，放大法光，建大法幢，击大法鼓，乘大法船，以摄受大法而发心趣向。善丈夫游戏于其中，降下法雨，润泽众生，皆令欢喜，精勤勇进，而发心趣向阿耨多罗三藐三菩提。

### 得法光明观察缘起

“无边慧！诸菩萨摩诃萨住于此道时得到法的光明；由于光明的缘故，能见一切诸法的缘起，自性本空，自性无相，自性无起。不在色中见色，受、想、行、识也是这样；不在识中见识异于识的缘起，了知识的相自性本空、自性无相、自性无起，只属于众缘，见众缘和合，众缘也是空、无相、无起。

“作这样见时，不在眼中见眼，耳、鼻、舌、身、意也是这样；不在意中见意异于意的缘起，了知意的相自性本空、自性无相、自性无起。乃至地界、水界、火界、风界、空界，欲界、色界以及无色界，没有作者，没有受者。不在少许法中见有少许法离开因缘而生起，都属于众因缘，自性无相，自性无起，缘之性也是空、无相、无起。

“无边慧！这就是诸菩萨摩诃萨住于此道观察缘起。这样观察之后，能以智慧在缘起中证得真实际。以这一切法光明的缘故，如来的十力、四无所畏、十八不共法、大慈、大悲、大喜、大舍，乃至一切诸佛之法，都迅速得以圆满。”

【按】“住此道观察”之“道”，元、明本作“道时”。

那时，世尊说偈道：

```
菩萨无畏者，如是能安住，
作大法光明，妙智而发趣，
建于大法幢，此幢无有上，
一切佛法中，正念而发趣。
智慧善游戏，法施诸众生，
霔于大法雨，无畏而发趣，
以法润众生，皆令得欢喜，
以是诸菩萨，妙善而发趣。
如是诸菩萨，得大法光明，
能于正法中，勇猛善安住。
由是法光明，了知一切法，
以众缘故起，一切无坚实。
诸法自性空，自性无有相，
自性无有生，自性无有体。
诸法以众缘，和合而共起，
众缘和合故，自性无所有。
菩萨能观察，了众缘亦空，
众缘自性空，自性无有相。
亦无有生起，亦非有所作，
如是观察者，于法勤修习。
诸起无体故，众缘亦非缘，
如是如理观，能知一切法。
```

（大意：菩萨无畏者能这样安住，作大法光明，以妙智而发趣；建立大法幢，这幢无上，在一切佛法中正念而发趣。以智慧善能游戏，以法布施诸众生，降下大法雨，无畏而发趣；以法润泽众生，都令他们得到欢喜，因此诸菩萨妙善而发趣。这样的诸菩萨得到大法光明，能在正法中勇猛而善安住。由于这法的光明，了知一切法都以众缘而生起，一切都无坚实。诸法自性空，自性无有相，自性无有生，自性无有体。诸法以众缘和合而共同生起，因为是众缘和合，所以自性无所有。菩萨能观察，了知众缘也是空，众缘自性空，自性无有相，也没有生起，也不是有所造作；这样观察的人，对于法勤加修习。由于诸生起无体，众缘也非缘；这样如理观察，能知一切法。）

```
观诸色受想，行识亦如是，
皆以众因缘，由斯诸蕴起。
诸蕴无有实，自性本来空，
性空故无相，一切无所起。
诸蕴远离相，离相则无生，
无生则无灭，诸蕴如是相。
无相妄有相，彼相从何有？
诸法无体故，斯蕴亦无性。
界处亦如是，一切从缘起，
自性本来空，无相无有体。
一切诸法中，法体不可得，
了知一切法，名义思惟者。
欲色无色界，一切从缘起，
自性本来空，无相亦无体。
观此能观智，何能知彼境？
此智及彼境，自性常远离。
所起及众缘，此二俱无作，
能作如是知，斯为真实相。
无相以相说，菩萨由斯入，
而亦不分别，若相及无相。
如斯善智者，能见真实相，
于诸法界中，不作少法相。
```

（大意：观察色、受、想以及行、识也是这样，都以众因缘，由此诸蕴生起。诸蕴没有实体，自性本来空；因为性空，所以无相，一切无所生起。诸蕴远离相，离相就无生，无生就无灭，诸蕴就是这样的相。无相而妄有相，那相从哪里来？由于诸法无体，这些蕴也无自性。界与处也是这样，一切从缘而起，自性本来空，无相也无体。在一切诸法中，法体不可得；了知一切法的，是思惟名与义的人。欲界、色界、无色界，一切从缘而起，自性本来空，无相也无体。观察这能观之智，它怎能知道那所观之境？这智与那境，自性常相远离。所生起的与众缘，这二者都无造作；能作这样了知的，这就是真实之相。无相而以相来说，菩萨由此而入，也不分别有相与无相。这样的善智者，能见真实之相，在诸法界中，不作少许法相。）

```
若法及法界，此二俱无相，
诸法远离相，说名为法界。
说名法界者，无界无非界，
虽名为法界，然实不可得。
思惟此义时，不念不可得，
离诸分别故，获大法光明。
诸法无性故，光明亦无性，
由斯观察故，复得法光明。
不见能观智，斯见亦不见，
见法虚妄故，说此名为观。
光明不思议，无边无有量，
见诸法皆空，说名不分别。
若法有诸相，常无证入者，
闻斯净法音，应生大欢喜。
若法无有生，常无分别者，
闻斯净法音，寂然获安乐。
若后末世时，闻斯无上法，
应说彼众生，久集诸功德。
若后末世时，闻斯无上法，
当于此法中，以速而发趣。
```

（大意：法与法界，这二者都无相；诸法远离相，名为法界。名为法界的，无界也无非界；虽然名为法界，实则不可得。思惟这义时，也不念“不可得”；因为远离诸分别，获得大法光明。由于诸法无性，光明也无性；由于这样观察，又得到法的光明。不见能观之智，这“见”也不见；因为见法是虚妄的，所以说这名为观。这光明不可思议，无边无量，见诸法都是空，名为不分别。若认为法有诸相，就常无证入之人；听到这清净的法音，应当生起大欢喜。若法无有生，常无分别之人，听到这清净的法音，寂然而获安乐。若在后来的末世听闻这无上之法，应当说那些众生久已积集诸功德。若在后来的末世听闻这无上之法，当在这法中迅速发趣。）
