# 《大宝积经》卷第七十九（富楼那会·大悲品、答难品、富楼那品）

后秦·三藏鸠摩罗什 译

## 富楼那会第十七之三

【按】卷题，圣本作“佛说菩萨藏经卷下”（卷末同）；宫本作“卷第七十八”。译者题名，宋、宫本作“姚秦三藏鸠摩罗什译”，元本作“姚秦三藏法师鸠摩罗什奉诏译”，明本作“姚秦三藏法师鸠摩罗什译”。会题“之三”，宫本作“之二”。

### 大悲品第六

【按】品次“第六”，宫本作“第四”。

#### 目连请说本行大悲

那时大目揵连这样想：“希有，世尊！世尊成就这样的大悲，善能解说诸菩萨之事。为什么呢？菩萨具足修集佛法，为了无生灭而开示觉悟众生。”那时佛知道目连所想，便告诉他说：“是这样，是这样。目连！诸佛成就大悲之心。若我的弟子听闻宣说这大悲的完整义理，心便迷闷，再也没有所乐。目连！暂且放下如来的大悲。若我完整宣说作菩萨时所有的大悲，你也会迷闷，再也没有所乐。”那时目连对佛说：“善哉，世尊！愿宣说本来行菩萨道时大悲的少分。”佛告诉目连：“你现在谛听，好好忆念受持。当为你宣说本来行菩萨道时大悲的少分，当以譬喻解说其义。本来行菩萨道时所行的大悲说不能尽，而这大悲依于四事。哪四种？这是菩萨的大悲，菩萨随其所住之悲能修佛法，名为大悲。

#### 愿代众生受地狱苦

“目连！我本来对众生有这样的大悲，有这样的大愿：所有在阿鼻大地狱受种种苦恼的众生，以及黑绳大地狱、僧伽陀地狱、活地狱、叫唤地狱、大叫唤地狱、炙地狱、大炙地狱的众生，我常代这些众生承受种种大地狱中的苦，乃至罪业了结，承受种种苦时，心无忧悔。目连！若有这样的因缘能度众生，我能全部代受，令众生出离大地狱。我代受苦，一入地狱，便尽除众生所作的罪业，我那时心无忧悔。目连！我发这样的大愿，精进咨问有智之人，就是佛以及佛弟子：‘可有这样的道理因缘，能代受苦恼，令众生出离地狱吗？’目连！智者听了之后，只为我称赞宣说多闻、深发道心、布施、持戒、忍辱、精进，称赞宣说亲近善知识。目连！我听了之后大发精进，为求法而深生意欲，求得成就诸佛大法，勤行精进，具足诸波罗蜜，深行忍辱。

【按】“我常代”之“代”，圣乙本作“伐”。

#### 深行忍辱

“目连！我本来怎样深行忍辱？我本来作菩萨时，发这样的心：十方所有众生，有色的、无色的，有想的、无想的，非有想的、非无想的，假使这些众生都得到人身，来到我这里，这样说：‘仁者发阿耨多罗三藐三菩提心，我们多有匮乏五欲乐具与资生之物。你若不能全部给我们，便不得阿耨多罗三藐三菩提。’若这些众生那时都恶口，苦切地骂詈，妄说我的过恶，因为不称其意，便以刀杖瓦石加害我身。我在那时不应生恚，不应悔退，我应当这样调伏其心：‘这些众生愚痴，不知自己在造愚痴之业。若我对这些愚痴众生生起瞋恨，与他们有什么不同？他们不入于道，我入于善道，我现在对这些众生忍受种种苦，不起瞋业，心应当如大地，平等承受好与丑。’目连！我本来深行这样的忍辱。

【按】“乏短”之“乏”，圣乙本作“之”。

#### 视众生如一子：仙人然臂照道

“又，目连！我常在长夜中看待一切众生如同独子。如大长者财富丰饶，多有珍宝、奴婢、人使，行百种戒法，求得一子，深心爱念，情无厌足。目连！这长者对儿子常求好事，常给好事，常给利益，不给衰恼。像这样，目连！我常在长夜中看待众生如同独子，我常在长夜中为众生求种种好事，以此饶益，不给衰恼。目连！我在长夜中对失道的众生、行邪道的众生，指示正道，令其住于正道。目连！因为这因缘，应当知道如来在长夜中对众生深心爱念，看待如同独子。

“目连！在过去世，有一群商客夜间赶路迷失道路，进入邪径。因为夜里黑暗，不知往何处去，都这样说：‘我们迷失了道路，无救、无归、无所依止。哪些众生，无论天、龙、夜叉神、人或非人，能指引我们得到正道？谁能怜愍饶益我们，在这夜暗邪隘的道路中给我们光明？’目连！那时空林泽中有一位外道仙人住在草庵中，在夜暗中听到众商客悲唤的声音，便这样说：‘现在众商客在夜暗中于这空林中迷失道路，若我不救，便不合道理，这些商客或许会被虎、狼、狮子、大象、野牛等恶兽恼害夺命。’目连！仙人当即以大声告诉众商客：‘你们不要害怕，我现在来救你们，当作光明，为你们指示正道。’那时仙人安慰告诉众商客之后，便以叠布衣缠裹两臂，用油遍浇，以火点燃，为众商客照明指路。目连！那时众商客都这样想：‘现在这位仙人甚为希有，为了我们不惜身命。’

【按】“悲唤”之“唤”，宫本作“叹”。

“目连！那时这位仙人以手臂的光明照示商客道路之后，对众生的悲心更加增长，这样想：‘我得阿耨多罗三藐三菩提时，为行邪道的众生作法的光明，指示正道。’目连！我那时虽然燃烧两臂，身心并无异样。为什么呢？目连！深心的菩萨在求他人利益时不贪身命，因为以净心布施的因缘，手臂又平复如初，没有疮疤。众商客们便得到正道，到了天明，见到仙人两臂没有疮疤，生起希有之心：‘现在这位仙人有大神力，能整夜燃烧两臂为我们照明，使我们得到正道，而他的手臂都没有烧伤，必定成就大行，必定有大德。’目连！那时众商客对仙人说：‘善哉仙人！能作第一难行的苦行。现在以这行持想要愿求什么事？’仙人回答说：‘诸位商客！我以此事，愿得阿耨多罗三藐三菩提之后，当度你们脱离生死之苦，为行邪道的众生宣说正道。’那时众商客心中大欢喜，都这样说：‘我们应当以什么事报答这位仙人？’仙人说：‘你们应当一同专心修行善法，切莫放逸。’众商客说：‘恭敬遵从您的教诲。’众商客等恭敬欢喜，于是告别离去。目连！你认为那时为众商客燃臂照路的外道仙人，是别人吗？不要这样想，就是我自身。众商客，就是现在的一千二百五十位比丘。目连！如来在长夜中对怖畏的众生施予无畏，对行邪道的众生指示正道，令无眼的众生得到净眼，能治愈病重的众生。因为这因缘，应当知道如来在长夜中对众生深有大悲。

【按】“疮瘢”之“瘢”，圣本作“槃”。“岂异人乎”之“乎”，圣本作“于”。

#### 人药王子

“又，目连！在过去久远之时，这阎浮提中大病劫到来，众生普遍被大病所恼。那时阎浮提王名为摩醯斯那，有八万四千座大城，王在其中威势自在。那时王的第一夫人怀孕，若以身体或手触碰众生，他们的病便都除愈。月满生下一个男孩，生下后便说：‘我能医治病人。’又在出生时，阎浮提内的诸天鬼神都共同唱言：‘现在国王所生的，便是人药。’因为这声音普遍流传，便取名为人药。那时人们都带病人给这王子看，病人到来，王子以手触碰，或以身触碰，便都痊愈，安隐快乐。这样辗转，阎浮提内都带病人给王子看。王子以手触碰，病都除愈，安隐快乐。目连！人药王子在一千年中这样治病，后来命终。命终之后，病人们前来，听说他已经死了，忧愁涕泣：‘谁还能度脱我们的病痛苦恼？’病人们说：‘人药王子在何处火化？’问知所在之后，前往他火化之处，取出骨头捣成粉末涂在身上，便都痊愈，于是唱言：‘人药王子到现在还能医治病人。’目连！像这样的因缘医治病人，骨头渐渐用尽。骨头用尽之后，到燃烧其身之处取地上的灰炭，各自涂在身上，病都痊愈。目连！像这样，人药王子在大病劫中，以这样的方便医治病人。目连！你认为那时的人药王子是别人吗？不要这样想，就是我自身。我对多病苦恼、无救无依的众生，治疗其病。我现在得阿耨多罗三藐三菩提，也以大智慧之药医治众生，令其毕竟尽苦。目连！我为众生受身，随其可以饶益之处便加以饶益。目连！因为这因缘，应当知道我是特意为众生受身而作饶益。

【按】“怀妊”之“妊”，圣本作“任”。“消尽”之“消”，圣乙本作“销”。

#### 以身血肉施饥渴众生

“又，目连！在过去久远之时，我曾独自行走，那时有恶兽来夺我的性命，想吃我的肉。我临死时心中发愿：‘我现在死后，当生在这空林泽中，作一头大畜之身，若有恶兽来夺我的命，令它们都得到充足饱满。为什么呢？这些恶兽常常杀害小虫，吃它们的肉，多造杀罪而不能饱足。’我那时发愿，当生在这里作大畜之身，令一切吃肉饮血的众生都得饱足。当即死后，便在那里化生为大畜之身，令恶兽饮血吃肉，都得充足。这样辗转百千万亿那由他世，特意为此受身，饶益众生，乃至一劫。目连！若我自己宣说本来行道时，以身上血肉施予饥渴的众生令其饱满，以一劫或少于一劫说也说不尽。目连！我本来就是这样对苦恼众生深生悲心。

“又，目连！在过去久远之时，我忆念本身，见到苦恼众生，便这样想：‘我现在不应舍弃而不救。’便到他们那里问道：‘你们有什么苦？需要什么？’回答说：‘仁者！我们现在甚为饥渴。’我听了之后便对他们说：‘你们现在需要什么饮食？’回答说：‘我们只想饮血吃肉。若能以身上的血肉给我们，我们便快乐，不再有病痛。’我便答应他们，自己割肉出血给这些众生。目连！我那时心无悔惜，不愁不沮丧，只这样想：‘我现在割肉，也灭除了那么多生死之苦的分量。’我常在长夜中乐于这样布施，这样布施之后，深得欢乐。因为这因缘，应当知道如来对众生深有大悲。

【按】“即作是念”之“即”，元、明本作“而”。

#### 大力王割臂与帝释障施

“目连！我忆念过去时世，有一位王名为大力，有大德力，深种善根。那时大力王这样想：‘我现在何不设大施会，满足众生？’这样想之后，设大施会，任凭所求：需要食物的给食物，需要饮料的给饮料，有需要衣服、卧具、金银宝物、车乘、钱财的，有需要砗磲、玛瑙、颇梨、琉璃、珊瑚、琥珀等宝物的，都能给予。花香、璎珞、涂香、末香、缯彩幢盖，男女大小，奴婢人使，象马牛羊，田地产业，都给予。目连！这大力王这样大施。

【按】“车𤦲”即“砗磲”，明本作“硨磲”；“马瑙”，明本作“码碯”；“颇梨”，明本作“玻瓈”；“虎珀”之“虎”，宋、元、明、宫本作“琥”。“瓔珞”，圣、圣乙本作“缨络”。

“那时帝释这样想：‘我现在何不给这国王制造障碍，令他的布施不能成功。’当即自己化作婆罗门，到王那里问王说：‘现在大会中布施什么？’回答说：‘婆罗门！我所有的东西都拿来布施，无所爱惜。’婆罗门说：‘照你的志愿，我现在所乞求的，能给我吗？’大力王说：‘我既已发言，所有的都给。’婆罗门说：‘王若是这样，我现在需要王的身体部分。’王便想：‘这婆罗门不需要财物，现在来只是想破坏我的大施。我若不以身体部分给他，便是我自己破坏了大会布施之事。’这样想之后，对婆罗门说：‘给你身体部分，截取拿去。’婆罗门说：‘大王现在这样说，莫非会后悔吗？’大力王说：‘我心不悔。只是现在有许多乞求的人从四方前来集会，我都应当使他们得到满足。’婆罗门说：‘我现在一人尚且不能满足，何况其余的人。’目连！那时大力王便用利刀自割其臂给婆罗门：‘你可以拿去这一只臂。’目连！那大力王自割手臂时，心无变异，没有悔恨。因为这样一心布施，能舍一切，手臂又平复如初。那时大力王以刀割下身体部分给婆罗门，给了之后又长出来。目连！那时帝释因为这因缘，天福便尽，心中热恼，大声呼唤，以现身便堕入阿鼻大地狱中。

#### 调达世世为怨与骨髓辟支佛

“目连，你认为那时以身体布施的大力国王是别人吗？不要这样想，就是我自身。那时想障碍我大施会的帝释是别人吗？不要这样想，就是调达。目连！那时调达这愚痴之人生起嫉恚之心，想障碍我的布施而不能破坏，堕入大地狱。我现在得阿耨多罗三藐三菩提，设大法施，调达这愚痴之人仍生恚嫉，因为贪求利养，谋合人众想共同杀我。我那时在耆阇崛山下经行，他自己在山上设机关推下石头。他自己破坏善根，对我生恶，自己失去利养、豪尊与势力，以此身堕入阿鼻大地狱中。目连！我对调达这愚痴之人没有身、口、意的恶，而他在长夜中把我当作怨敌，世世障碍我修集善法，却也不能障碍我行善。我常在长夜中以慈悲覆护滋润他，却不能使他把我当作亲人。目连！调达世世不识我的恩德，我现在举手说，像调达这样的人，也不识天、人、世间、阿修罗的恩德，这样的人入于邪定之位。

“目连！调达后来临入阿鼻大地狱时，才对我生起深切真实的好心，这也是如来的威神之力。调达是第一不知恩义的人，临入阿鼻大地狱时，听到大声说：‘愚痴的调达！你瞋恚于佛，佛是不可杀的人，你却想横起杀害的因缘。因为这罪，现在堕入阿鼻大地狱中。’听了之后大为恐怖，心便摧伏，这样说：‘我现在唯以肉与骨，一心归命于佛。’心便得乐，对佛生信，发出大声，便入于阿鼻大地狱中。因为这因缘，后来出离地狱，得生人中，出家学道，得辟支佛，号为骨髓。目连！我现在为调达授记作辟支佛，他便已度脱生死之苦。目连！我度调达，如我本来的誓愿。为什么呢？我在先世曾立约要度调达：‘我当度你，没有其他人度你。’目连！调达只在我这里种下涅槃的因缘，不在其他地方种。调达从此以后，也不在其他地方种善根，只在我这里信心清净，说归命佛。以这善根因缘，后来得辟支佛道。

【按】“肉骨”，明本作“骨肉”。“骨髓”，宫本作“骨体”。“授调达记”之“授”，宋、元、宫本作“受”。

#### 如调伏大象忍受一切

“目连！我常在长夜中对众生作父母之想，怜愍他们孤穷，没有财物，往来于生死险难的恶道，愚痴无智，常如盲人没有眼睛，谁能指示引导？谁能救护？唯有我一人应当指示，应当救护。目连！我这样想之后，若有众生恶口骂我，我不还报。苦切地责备我，我也不还报。若瞋恨，若打我，我终不还报。为什么呢？我应当常给一切众生毕竟的安乐，应当除去一切苦恼衰患，我现在不应给他们种种苦恼。这些众生，谁能忍受？唯有我能忍受。我现在当学众生忍之法、善寂灭之法、柔和随顺之法，当如调伏的大象，不如不调伏的象。

【按】“示导”之“导”，圣本作“道”。“苦切责我”之“苦”，《大正藏》作“若”，宫本作“苦”，今依CBETA（所录高丽藏、碛砂藏）作“苦”。

“目连！譬如调伏的大象，进入战阵时心不退缩，能忍受鼓声、螺声、角声、大叫唤声，听到这样可畏的声音不惊不畏。能忍受寒热、蚊虻毒虫、风雨饥渴，能忍受种种锋剑所伤，弓、弩、箭、矟、刀、矛、戟、剑、铁轮、鞭打，都能忍受，不惊不畏，直冲战阵，不退不缩。目连！调伏的大象不这样想：‘我不能冲入贼阵。’只这样想：‘我当战胜这贼阵。’目连！我本来行菩萨道时，发大心愿也是这样，对众生调伏其心。若众生恶口骂我，我不加报复。与我诤论，我也不报复。若以刀杖瓦石加害我，以及夺我性命，我那时心不退转于阿耨多罗三藐三菩提，也不分别这可以接受、这不可以接受，这应当亲近、这不应亲近，在这事中无忧、无悔、无有恚恨，对菩萨道心无厌离。不这样想：‘我现在不能进入大贼阵。’只这样想：‘我能破这大恶贼阵，当得阿耨多罗三藐三菩提，度脱三界无量众生。’目连！我本来行菩萨道时所行的忍辱，对众生所有的慈悲，若以言说，说不能尽。

#### 忍力仙人八万四千岁受骂

#### 以身为奴仆随唤即去

“又，目连！我忆念过去世，自己以身体布施给众生，为世间人作奴仆。那时众人以种种事务使唤我，有人使唤我清除屎尿，有人使唤我作清除粪便的人，有人使唤我清除尘土，有人使唤我取草，有人使唤我取谷米、乳酪、酥油、蜜，有人使唤我取柴薪、炭火、水，这样等种种事务都使唤我去取。目连！我不记得那时生起这样的心：有人使唤我清除屎尿便不随去，有人使唤我取花香、璎珞、涂香、末香、饮食、果蓏便随去。目连！我不记得那时喜好的事务便随去，不喜好的事务便不随去。目连！我不记得那时随顺刹利而不随顺婆罗门，随顺婆罗门而不随顺刹利，随逐毗舍而不随顺首陀罗，随逐首陀罗而不随顺毗舍，随逐刹利、婆罗门而不随顺毗舍、首陀罗，随逐毗舍、首陀罗而不随顺刹利、婆罗门。也不记得有这样的差别：这人大，这人小，随逐这人，不随逐那人。目连！只是随顺先叫唤我的人，欢喜地随去。

【按】“苏油蜜”之“苏”，宋、元、明、宫本作“酥”。“蜜、有人”之“有”，圣乙本作“油”。“𦬔”字先前电子文本未能显示，今据《大正藏》补出，宋、元、明、宫本作“蓏”，即瓜果。

“目连！我忆念本来行菩萨道时，不记得有人以如法之事使唤我去作，我终究在力所能及时不去作。目连！我忆念本来行菩萨道时，没有所作之事不究竟的，没有所行之善不终结完成的。总而言之，我忆念本来行菩萨道时，未曾贪惜身体，何况财物。我行菩萨道时，对财物不生起我的东西之想，我只是以先业果报而有财物，对这财物生起这样的想法：‘这东西应当与众生共用，在这东西中我有一份，众生也有一份。’目连！随着我行菩萨道而接近佛法，便不这样想：‘在我的东西中说我有一份、众生有一份。’只想所有的东西都是众生的东西，我没有份。目连！随着我接近佛法，便在其中乐于不贪著、不摄取、不执取，乐于远离诸法，不乐领受诸法，乐于一切空法，不乐一切法有，乐于一切法寂，不乐诸法的事相，乐于本性无所有，不乐本性有所有。

“目连！我忆念本来行菩萨道时，无量百千万世，在夜暗中燃烧自身，为失道的众生照示道路。目连，我忆念本来行菩萨道时，无量百千万世，对吃肉的众生割肉施与。目连，我忆念本来行菩萨道时，无量百千万世，对饮血的众生刺血施与，令其饱满快乐。目连！总而言之，在世间中种种财物与资生所用之物，对众生终不贪惜，都是为了不恼不害众生，这是智者所认可、贤圣所称赞的。我常常这样在长夜中对众生深行悲心。

【按】“夜闇”之“闇”，宋本作“阇”。

#### 吉利商主救死囚

“又，目连！我忆念过去作商客之主，名为吉利，入于大海取得大珍宝，安隐出海，回到本国。此人入城到家门前，那时城中有许多乞丐围绕在前，这样说：‘善来，安隐的吉利大檀越！我们想有所乞求。若见许可，我们便乞求。’目连！那时吉利对众乞丐说：‘你们可以乞求我所有的东西，我能给予，无所贪惜。’那时众乞丐对吉利说：‘你从大海所得的宝物全部给我们，我们若得到便都吉利。’像这样，目连！吉利当即把珍宝全部给了乞丐，共有八十亿颗摩尼珠，每一颗都值百亿两金。目连！这吉利以这么多东西布施之后，心无异样，不生疑悔。那时吉利以许多宝物给了乞丐之后，不进家门，又回到海上采取珍宝。入海之后得到加倍的宝物，过了八十年回到本国。

【按】“贾客主”之“主”，宋本作“生”。“围绕”之“围”，圣本作“违”。“与乞人已”之“已”，《大正藏》作“己”，今依CBETA作“已”。

#### 象王以身为桥

“又，目连！在过去久远之时，雪山王边有五百头象成群，其中有一头大象王为首领，体貌可爱，力大有智。那时这群象夜宿在山中险隘难行之处，只有一条道路。那时猎人见到这群象，便在夜里于险道中挖了大坑，这样想：‘这群象会掉进这坑里，便归属于我，随我取用。’夜里挖好坑之后，驱赶群象走向险道的坑。群象想出去，见到有大坑，不能通过。目连！那时象群之主以身体横在坑上作桥，使五百头象从它的脊背上走过。群象过去之后，作势踊跃跳动。那时山神说这偈道：

```
「『恶人作深坑，中有智象王，
度彼亦自度，唐劳作深坑。』
```
（大意：“恶人挖了深坑，其中有智慧的象王，度彼群象，也度自己，挖深坑的人白白辛劳。”）

#### 象手问佛本愿度尽众生

那时会中有一位比丘名为象手，从座而起，偏袒右肩，右膝著地，合掌对佛说：“世尊！我从如来听闻这些难行之事，身上汗毛竖起，涕泪流下。我现在想问一件事。世尊自己说：‘我作菩萨时随所说而行，随所行而说。’世尊从最初愿度一切众生，若作这样的愿，现在所度的众生还未尽，就将入涅槃。如来灭度后，或有人来问难诸比丘：‘你们大师的本愿，是当度一切众生；众生还未度尽，自己便灭度了。’若有这样的问难，应当怎样回答？”

#### 以阴入界破众生见

佛告诉象手比丘：“若有这样问难的，应当反问他：‘你以什么法为众生？’那人若说：‘阴、入、界是众生。’应当反问他：‘是阴、入、界和合是众生，还是离散是众生？’那人若说：‘阴、入、界和合是众生。’应当回答他：‘你自己已经回答了。为什么呢？和合是众生，阴、入、界不是众生。佛所说的法是为了离散，不是为了和合。世尊乐于离散之行，不乐和合，和合之中没有众生。’那人若说：‘只是阴、入、界是众生。’应当反问说：‘若是这样，一切草木瓦石都是众生。为什么呢？你说阴、入、界是众生，这其中也有阴、入、界。’那人回答说：‘这其中没有心、没有心数法，所以不是众生。’应当反问他：‘若是这样，一切众生应当是同一个众生。为什么呢？如来不说阴、入、界有不同。’那人若说：‘如来在经中说有众生，所以有众生。’应当回答他：‘你自己已经回答了。为什么呢？如来经中说离有离无。’那人若说：‘若是这样，便没有道果。’应当反问他：‘你以什么为果？’那人若说：‘我说决定的第一义为果。’应当反问他：‘决定的第一义中没有音声语言，在没有音声语言之中，不能说决定有或无。你说决定的第一义为果，这决定的第一义中没有众生，也没有众生的名字。所以你说有众生，这话自相破坏。’

【按】“汝说阴入界”之“界”，圣乙本作“还”。“彼人答言”之“答”，圣本作“若”。“若尔者”之“者”，宫、圣、圣乙本作“时”。

#### 见法门即是见佛

“又，象手！如来经中说，在诸法中没有被灭的，只灭除苦恼。我这样通达诸法实相，随所得之法为众生宣说，是为了无贪取，为了远离，为了无戏论，为了无作起。象手！若人这样了知我的法义，此人便能不为有、无而起行业。若人不为有、无而起行业，此人怎会见有众生、见无众生？象手！这名为常住的诸法实相。其中没有忆想分别，无垢无净，无来无去，无道无道果，无长无短，无方无圆，无形无色，所以说诸法一门，就是定门。象手！这名为见法门。入于这见法门，名为能见佛。象手！对此你认为怎样？随以什么法见佛，这法是已灭、今灭、当灭的灭相吗？”“不是的，世尊！”“你认为怎样？随以什么法见佛，这法是已生、今生、当生的生相吗？”“不是的，世尊！”“象手！若是这样，如来不名为灭。”“是这样，世尊！”

#### 以身相破如来灭见

“象手！那人若说：‘就所有的身相而言，我因为这个说如来灭度入涅槃之后不再回转，只因见到身相不再回转，所以名为如来灭度。’应当反问他：‘你说身相成就就是如来吗？’那人若说：‘我说身相成就名为如来。’应当回答他：‘佛经中不说身相名为如来。若说身相是如来，一切瓦石山河草木都是如来。’那人若说：‘一切瓦石山河草木，没有三十二大人相，所以不名为如来。’应当回答他：‘你说有三十二相名为如来，转轮圣王便是如来。为什么呢？转轮圣王身有三十二相。’那人若说：‘相师入于相法，知相的婆罗门说他当作佛，这事是真实的。’应当回答他：‘若有三十二相，便应当是佛。而你自己说相师见他有三十二相，授记当得作佛。你现在说的是佛相。’那人若说：‘我说佛的十力、四无所畏、十八不共法、无漏的根、力、觉、道、禅定、解脱、三昧等是佛相。’应当回答他：‘你说十力等是佛相，现在应当说佛的体性。’那人若说：‘佛与这些相不同吗？’应当回答他：‘你自己说这是佛相，佛相不是佛。’那人若说：‘另有无形无色之法，以佛的十力等为相。’应当回答他：‘无形无色之法，怎能以有形有色为相？又你若说无形无色之法名为佛，其余的无形无色之法都可以是佛。若这些法也是佛，那么这十力、四无所畏、十八不共法、根、力、觉、道、禅定、解脱、三昧等，也应当与这些法相应。’象手！我的诸弟子应当这样降伏愚痴之人。

#### 道场所证十二因缘

“又，象手！我本来愿得阿耨多罗三藐三菩提，度脱一切众生。我坐道场得阿耨多罗三藐三菩提之后，不得众生，不得众生的名字。我坐道场只通达十二因缘法：这事有，所以那事有；这事无，所以那事无。什么事有，所以有什么事？什么事无，所以无什么事？就是因为无明的因缘，所以有诸行；因为诸行的因缘，所以有识；因为识的因缘，所以有名色；因为名色的因缘，所以有六入；因为六入的因缘，所以有触；因为触的因缘，所以有受；因为受的因缘，所以有爱；因为爱的因缘，所以有取；因为取的因缘，所以有有；因为有的因缘，所以有生；因为生的因缘，所以有老死；因为老死的因缘，所以有忧悲苦恼；这样辗转，只是大苦的聚集。因为无明灭，所以诸行灭；因为诸行灭，所以识灭；因为识灭，所以名色灭；因为名色灭，所以六入灭；因为六入灭，所以触灭；因为触灭，所以受灭；因为受灭，所以爱灭；因为爱灭，所以取灭；因为取灭，所以有灭；因为有灭，所以生灭；因为生灭，所以老死灭；因为老死灭，所以忧悲苦恼灭；这其中只是大苦聚的灭除。我在其中生起眼、智、明、觉，通达这样无中、无后、无坏的解脱。如来因为通达这解脱，不得其余之法，只得众因缘所生之法。象手！如来通达诸法，随即以这样为众生宣说。象手！无论诸佛出世或诸佛不出世，诸法的性相常住不异，就是名色不失，不相违背，不生不起。象手！我常这样说法，你们也应当随顺我的意思了知。我为你们宣说这样的法，你们只应当勤加修行。象手！大师应当为弟子作的事，我都已作完。你们如所说而行，在诸法中当得智慧光明。”

#### 正法灭即如来灭之难

那时象手对佛说：“世尊！若有人说：‘如来所说的正法灭亡了，谁来指示引导？因为没有宣说引导的人，所以名为正法灭亡；因为正法灭亡，所以名为如来灭度；这样也名为不度一切众生。’”佛告诉象手：“若人这样问难，应当这样回答：‘佛是一切智人，都知都见，常等待众生可度的时节，虽然入于涅槃，仍能有所利益。又佛现在为未来世的佛授记作佛，这便是佛种相续不断绝。一切佛法是同一佛法，所以说名为如来法，如来法就是佛法。’所以应当知道，如来本来行菩萨道时，随所说而行，随所行而说。”

【按】“示导”“说导”之“导”，圣、圣乙本作“道”。“常待”之“待”，宫本作“持”。

#### 佛自说实语与五百辟支佛

象手对佛说：“希有，世尊！如来善能通达推求一切诸法。因为善能通达一切法，身、口、意业以智慧为首，都随顺智慧。世尊本来行菩萨道时，随所说而行，随所行而说。”佛告诉象手：“是这样，是这样。象手！如你所说。我本来行菩萨道时，随所说而行，随所行而说。象手！若人说实话，谁不错谬，出现于世间饶益众生、安乐天人，是一切大师中宣说正道的人，正智解脱，没有戏论，到达彼岸，度未度的人？当说如来世尊就是我，这是实语。象手！若人说实话，谁是不欺诳的人？知恩报恩的人当说就是我，这是我的实语。若有众生为我作了小事，这事不会失去。

“象手！我从初发阿耨多罗三藐三菩提心以来，在这中间心无退转，也不忆念贪乐声闻、辟支佛乘，想‘我当得这法’。只有一次发心，想教导弟子求辟支佛。象手！在过去久远之时，我那时作外道仙人，智慧明利，多闻有辩才，得到深法忍。那时有五百位年少婆罗门，见到在家五欲的过患，见到出家的利益，出家学道，都来到我这里。我便为他们说法，他们得到辟支佛道，具足六神通，心得自在，具足如意足，常以神力飞入城邑聚落乞食，供养于我。我这样想：‘这样成就大净智的人，我不应接受他们的供养。这些仙人因为我的教化而得到这样的法，我却没有得到。’为了得到这法，未证的当证，所以勤行精进。象手！我勤行精进想证得这法时，净居天前来现身，告诉我说：‘不要贪求这种智慧。你应当得阿耨多罗三藐三菩提，应当度无量无边众生。’象手！我那时听了之后便不再修那道，心中得到第一欢喜快乐，半月静坐，快乐遍满全身。

#### 四法诸天开悟知当作佛

“象手！菩萨成就四法，诸天开悟，得欢喜心，自知当得阿耨多罗三藐三菩提。哪四种？一是菩萨自己深发阿耨多罗三藐三菩提心，也教他人令其深发心。二是见到发大乘心的人，心不生嫉妒，不这样想：‘阿耨多罗三藐三菩提唯有我当得到，其余的人不应得到。’三是对众生所行，随时教诲，以好意与之交谈，护持其善。四是常自勤心广求诸法，为他人宣说，无所悭吝。象手！菩萨摩诃萨成就这四法，诸天开悟，知道当作佛。”那时世尊想阐明此事，说偈道：

```
「菩萨以坚心，住于无上乘，
亦能化众生，令住于此乘。
本行菩萨时，常无嫉恚心，
勤行发精进，喜心转增益。
见诸众生恶，知时而化喻，
常以慈悲心，而无有瞋恚。
常勤行求法，流布与众生，
以法充一切，如雨普流润。
行是四法者，诸天所开悟，
汝当得作佛，勿生疑惑心。
菩萨闻是已，勇猛发精进，
是事必应实，我定当作佛。
如是诸菩萨，以精进及愿，
忆念智与慧，而自转高大。
```
（大意：菩萨以坚固之心安住于无上乘，也能教化众生，令他们安住于此乘。本来行菩萨道时，常无嫉恚之心，勤行发起精进，欢喜之心辗转增益。见到众生作恶，知时而加以教化开喻，常以慈悲之心而没有瞋恚。常勤行求法，流布给众生，以法充满一切，如雨普遍流润。修行这四法的人，为诸天所开悟：“你当得作佛，不要生起疑惑之心。”菩萨听了之后，勇猛发起精进：“这事必定真实，我决定当作佛。”像这样，诸菩萨以精进与誓愿、忆念、智与慧，而自我辗转高大。）

【按】“忆念智与慧”之“智”，宋、元、明、宫本作“知”。

```
若有诸如来，出现于世间，
是菩萨则有，如是诸功德。
大人所恭敬，诸王及臣民，
皆生欢喜心，知是有道者。
经书章句义，文颂算数事，
皆悉善通达，众生中最上。
聪达有智慧，造事不以力，
但以其策谋，而能有所成。
摧伏诸战阵，不以身手力，
但以智慧力，自然而降伏。
诸王及臣民，皆叹未曾有，
怜愍众生故，生在于世间。
诸人佥皆知，谓与天共语，
何故知如此？以知我心故。
```
（大意：若有诸如来出现于世间，这位菩萨便有这样的种种功德：为大人所恭敬，诸王以及臣民都生欢喜之心，知道这是有道之人。经书章句之义，文颂算数之事，都善于通达，在众生中最为上等。聪达而有智慧，作事不以蛮力，只以其策谋而能有所成就。摧伏种种战阵，不以身手之力，只以智慧之力，自然而降伏。诸王以及臣民都赞叹前所未有：“是为了怜愍众生，才生在世间。”众人都知道，说他与天人交谈：“为什么能知道这些？因为知道我的心。”这位菩萨常得值遇诸佛，前往咨请问法，能大大利益众生。）

【按】“大人所恭敬”之“大人”，宋、元、明、宫本作“天人”。

```
是菩萨常得，值遇见诸佛，
往诣咨请问，能大益众生。
诸佛答问已，断了所疑惑，
能利诸众生，皆使得欢喜。
佛示神通力，受记当作佛，
是故此菩萨，心得大欢喜。
所爱贵重物，内外无贪惜，
是故大欢喜，自知当作佛。
普慈覆一切，常无瞋恨心，
是故大欢喜，自知当作佛。
诸佛所称赞，已得深妙忍，
是故大欢喜，自知当作佛。
```
（大意：诸佛回答所问之后，断除了一切疑惑，能利益众生，都使他们得到欢喜。佛示现神通之力，授记当作佛，所以这位菩萨心得大欢喜。对所爱、贵重之物，内外都无贪惜，所以大欢喜，自知当作佛。以普遍的慈心覆护一切，常无瞋恨之心，所以大欢喜，自知当作佛。为诸佛所称赞，已得甚深微妙之忍，所以大欢喜，自知当作佛。）

【按】“断了”之“了”，宋本作“子”。

```
不依止诸法，知法不可依，
得如是智慧，身能飞虚空。
其心不在内，亦复不在外，
出过一切想，故得无上忍。
长夜以慈悲，普念诸众生，
以是福德故，得见无量佛。
一切身皆是，佛身无差别，
能得如是忍，以法自增长。
发心菩提者，谁不随而学，
坚住于正法，得如是功德。
是故求道者，常应勤求法，
以法求自利，增益于菩提。」
```
（大意：不依止诸法，知道法不可依止，得到这样的智慧，身体能飞行于虚空。其心不在内，也不在外，超出一切想，所以得到无上之忍。在长夜中以慈悲普念众生，以这福德的缘故，得见无量佛。一切身都是佛身，没有差别，能得到这样的忍，以法自我增长。发菩提心的人，谁不随之修学？坚住于正法，得到这样的功德。所以求道的人，常应勤求于法，以法求得自利，增益于菩提。）

【按】“普念诸众生”之“诸”，宫本作“若”。“以是福德故，得见无量佛”，宫本作“能得如是忍，以法自增长”。

### 富楼那品第八

【按】品次“第八”，宫本作“第六”。

#### 佛说坚住善法偈

那时富楼那弥多罗尼子对佛说：“希有，世尊！世尊过去世行菩萨道时，善能坚住种种善法。”佛说：“是这样，是这样。富楼那！我在长夜中行菩萨道时，坚住于善法。”那时世尊想阐明此事，说偈道：

```
「求法能得法，是为佛道本。
常勤修习法，远离于非法，
常行于正道，远离诸邪道，
常修习诸佛，所可亲近道，
是则离诸难，能得无难处。
得无难处已，精进必不虚，
在二最尊贵，诸形色中上，
眷属具成就，于诸一切胜。
坚心常安住，戒品忍辱品，
亦住精进品，增长于禅智，
于诸众生中，常能为上首，
功德中亦胜，了义无所畏。」
```
（大意：求法便能得法，这是佛道的根本。常勤修习于法，远离非法，常行于正道，远离种种邪道，常修习诸佛所亲近之道，这便能离开诸难，得到无难之处。得到无难之处后，精进必定不落空，“在二最尊贵”一句存疑，在种种形色中为上，眷属具足成就，在一切之中殊胜。以坚固之心常安住于戒品、忍辱品，也安住于精进品，增长禅定与智慧，在众生之中常能为上首，在功德中也殊胜，了达义理，无所畏惧。）

【按】“是为佛道本”之“为”，明本作“名”。

#### 富楼那发愿与流通

那时富楼那对佛说：“世尊！这样的妙法，谁会不学？只念我们本来往昔懈怠，不希望佛的智慧，不自信能得到这样的佛慧，以声闻乘自我出离得度。世尊！我从今日起，开示、教导、利益、喜悦诸菩萨众，令他们安住于佛法。为什么呢？诸佛世尊是行难行的人。世尊本来行菩萨道时，为了众生常行这样甚难的大事，这样的事，一切阿罗汉、辟支佛尚且没有，何况其余的众生。世尊！这样甚难的大事，唯有诸菩萨摩诃萨等为了怜愍饶益一切众生，行菩萨道时有这样等无量无边阿僧祇甚难的大事。世尊！诸菩萨行这样甚难的大事，得阿耨多罗三藐三菩提之后，能转法轮，度脱苦恼的众生。”佛说：“是这样，是这样。富楼那！如你所说。诸菩萨摩诃萨深发阿耨多罗三藐三菩提心，为一切众生求利益安乐，对一切众生有大慈悲。为一切众生而行菩萨道时，有这样等无量无边阿僧祇甚深极难的大愿大事。”

【按】“甚难大事”之“大”，圣乙本作“本”。

佛说此经完毕，慧命富楼那、当时会中的四众，天、人、龙神、乾闼婆、阿修罗等，都大欢喜，信受佛语。
