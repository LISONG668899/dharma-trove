# 《大宝积经》卷第三十四（出现光明会）

唐·三藏菩提流志 译

## 出现光明会第十一之五

【按】本卷开头承上卷，仍是世尊入城时空中所出四言偈，演说陀罗尼行，并说一段陀罗尼；其后世尊到月光童子家受供，宣说施资粮的八十种功德，又说为成就陀罗尼应远离的八十种人，以偈颂作结，出现光明会至此圆满。

### 空中声说陀罗尼行

#### 陀罗尼究竟清净

```
尔时世尊，当入城时，以不思议，神通之力，
于虚空中，出微妙声，演说种种，陀罗尼行，
令诸大众，闻如是言。是陀罗尼，于眼尽边，
生边边际，寂静流转，乃至寂灭，如是诸法，
皆能通达，究竟安住。
```
（大意：那时世尊正要入城时，以不可思议的神通之力，在虚空中发出微妙之声，演说种种陀罗尼之行，令大众听到这样的话：这陀罗尼对于眼的尽边、生边、边际、寂静、流转，乃至寂灭，这样的诸法，都能通达，究竟安住。）

```
以布施力，究竟摄取，以持戒力，究竟成就，
以忍辱力，究竟庄严，以精进力，究竟发起，
以智慧力，究竟宣说。离诸文字，语言音声，
乃至色心，究竟清净。有漏无漏，若义若利，
皆悉空寂，究竟清净。亦不依止，一切诸有，
究竟安住，总持三昧。无去无来，非善不善，
乃至无记，自利利他，如是诸相，究竟清净。
亦不安住，自在威德，声闻凡夫，诸佛之法，
亦不安住，于眼尽边，生边边际，乃至寂灭，
如是诸行，究竟寂静。
```
（大意：以布施之力究竟摄取，以持戒之力究竟成就，以忍辱之力究竟庄严，以精进之力究竟发起，以智慧之力究竟宣说。远离一切文字、语言、音声，乃至色与心，究竟清净。有漏与无漏，或义或利，都是空寂，究竟清净。也不依止一切诸有，究竟安住于总持三昧。无去无来，非善非不善，乃至无记，自利利他，这样的种种相，究竟清净。也不安住于自在威德，以及声闻、凡夫、诸佛之法；也不安住于眼的尽边、生边、边际，乃至寂灭，这样的诸行，究竟寂静。）

```
若生不生，是苦是乐，称赞毁谤，皆悉舍离。
究竟清净，究竟照明，空陀罗尼，之所解了，
此即住佛，所行之处，此即住佛，游戏之处，
此即安住，诸佛神通，此即安住，诸佛智慧。
安住如是，眼尽边力，安住如是，眼生边力，
安住如是，眼边际力，乃至安住，寂灭之力，
耳鼻舌身，乃至名等，二十五法，亦复如是。
```
（大意：若生若不生，是苦是乐，称赞与毁谤，全都舍离；究竟清净，究竟照明，为空陀罗尼所解了。这就是安住于佛所行之处，这就是安住于佛游戏之处，这就是安住于诸佛的神通，这就是安住于诸佛的智慧。安住于这样的眼尽边之力，安住于这样的眼生边之力，安住于这样的眼边际之力，乃至安住于寂灭之力；耳、鼻、舌、身，乃至名等二十五法，也都是如此。）

#### 陀罗尼的威力与不可得

```
是陀罗尼，成就如来，殊胜之力。是陀罗尼，
成就如是，威德之力。入诸如来，一切行处，
住诸如来，一切境界。令诸世间，于修罗众，
离坚固心，住梵天行，能令无量，百千夜叉，
及鸠槃荼，皆生欢喜。亦令无量，乾闼婆众，
并诸罗刹，爱乐调伏。假使梵众，以妙音声，
于其句义，不能宣说，非诸心法，之所计度，
亦非心法，之所受持。是陀罗尼，非眼所得，
是陀罗尼，亦不至身，是陀罗尼，非眼所得，
亦不至于，眼所行处。耳鼻舌身，乃至名等，
二十五法，亦复如是。
```
（大意：这陀罗尼成就如来殊胜之力；这陀罗尼成就这样的威德之力；进入诸如来的一切行处，安住于诸如来的一切境界。它令世间中的阿修罗众离开坚固之心，安住于梵天之行；能令无量百千夜叉以及鸠槃荼都生欢喜；也令无量乾闼婆众以及诸罗刹爱乐调伏。假使梵天众以美妙音声，对其句义也不能宣说；它不是诸心法所能计度的，也不是心法所能受持的。这陀罗尼不是眼所能得，这陀罗尼也不至于身；这陀罗尼不是眼所能得，也不至于眼所行之处。耳、鼻、舌、身，乃至名等二十五法，也都是如此。）

#### 说种种眼

```
又说于眼，尽边生边，边际流转，乃至寂灭，
无我无人、众生寿者，乃至无有，补特伽罗。
无相无为，不来不去，如是等相，皆悉了知。
又说了知，法性之眼。又说了知，法成就眼，
智眼慧眼、梵眼天眼。梵生得眼，天生得眼，
梵异熟眼，天异熟眼，梵因生眼，天因生眼，
天神变眼，天精进眼，下劣生眼，殊胜生眼，
舍离阎罗，世间之眼，龙夜叉眼，鸠槃荼眼，
热恼之眼，非热恼眼，清净之眼，非清净眼，
广狭之眼，声闻乘眼，禅定之眼，三摩地眼，
境界之眼，想出生眼，贪出生眼，贪舍离眼，
从因生眼，非因生眼，相应之眼，不相应眼，
依门生眼，非门生眼，因缘生眼，因门生眼，
非肉成眼，智清净眼，无所有眼，不可得眼。
耳鼻舌身，乃至名等，二十五法，亦复如是。
```
（大意：又说眼的尽边、生边、边际、流转，乃至寂灭，无我、无人、无众生、无寿者，乃至无有补特伽罗，无相、无为，不来不去，这样的种种相，都完全了知。又说了知法性之眼。又说了知法成就之眼，智眼、慧眼、梵眼、天眼，梵的生得眼、天的生得眼，梵的异熟眼、天的异熟眼，梵的因生眼、天的因生眼，天的神变眼、天的精进眼，下劣生眼、殊胜生眼，舍离阎罗世间之眼，龙与夜叉之眼、鸠槃荼之眼，热恼之眼、非热恼之眼，清净之眼、非清净之眼，广狭之眼、声闻乘之眼，禅定之眼、三摩地之眼，境界之眼、想出生之眼，贪出生之眼、贪舍离之眼，从因生之眼、非因生之眼，相应之眼、不相应之眼，依门生之眼、非门生之眼，因缘生之眼、因门生之眼，非肉所成之眼、智清净之眼，无所有之眼、不可得之眼。耳、鼻、舌、身，乃至名等二十五法，也都是如此。）

【按】“殊胜生眼”之“殊”，《大正藏》作“珠”，宫本及高丽藏作“殊”，今从之。

#### 赞陀罗尼功德

```
如是陀罗尼，诸佛之所得，
具足大威神，智慧无边量。
远离于执著，念处悉清净，
无色无去来，非方及方所。
无相离言说，超过诸戏论，
菩萨勤修习，究竟得清凉。
假使以百千，那由他偈颂，
演说于一句，不能得其边。
众圣之所赞，清净无染著，
一切诸众会，皆悉生尊重。
如是陀罗尼，善法威神力，
能摧灭烦恼，令得于胜利。
功德及智慧，广大犹如海，
成就忍辱力，其心安不动。
菩萨常修习，智者所称叹，
舍离于贫穷，当获大财宝。
```
（大意：这样的陀罗尼，是诸佛所证得的，具足大威神，智慧无边无量。它远离执著，念处都清净，无色，无去无来，非方也非方所；无相，离于言说，超过一切戏论；菩萨勤加修习，究竟得到清凉。假使以百千那由他的偈颂演说其中一句，也不能穷尽其边际。它为众圣所赞叹，清净无所染著，一切众会都生尊重。这样的陀罗尼，以善法的威神之力，能摧灭烦恼，令人得到殊胜之利。功德与智慧广大犹如大海，成就忍辱之力，其心安稳不动。菩萨常加修习，为智者所称叹，舍离贫穷，当获大财宝。）

【按】“究竟得清凉”之“凉”，明本作“净”。“成就忍辱力”，宫、圣本作“成就于忍辱”。

```
如是陀罗尼，增长诸功德，
常以空性等，真实句庄严，
以舍于文字，名之为空性，
以舍于心识，名之为法性。
如是陀罗尼，离垢常清净，
安住于实智，现种种饶益，
令诸众生等，欢喜发净心。
无量夜叉众，及于鸠槃荼，
如是众鬼王，亦生大欢喜。
如是陀罗尼，寂静无戏论，
爱乐于众生，普皆与安乐。
于多百千劫，常在于诸趣，
作无量利益，清净无所染。
或以百千偈，演说甘露法，
令无量众生，皆生大欢喜。
往昔无量佛，以清净意乐，
于是陀罗尼，常思惟法性。
释梵诸天众、龙王阿修罗，
闻此陀罗尼，心生大欢喜。
```
（大意：这样的陀罗尼增长种种功德，常以空性等真实之句庄严：因舍离文字，名之为空性；因舍离心识，名之为法性。这样的陀罗尼离垢而常清净，安住于真实之智，示现种种饶益，令众生都欢喜而发净心；无量夜叉众以及鸠槃荼，这样的众鬼王也生大欢喜。这样的陀罗尼寂静无戏论，爱乐众生，普遍给予安乐；在许多百千劫中常在诸趣，作无量利益，清净而无所染；或以百千偈颂演说甘露之法，令无量众生都生大欢喜。往昔无量诸佛以清净意乐，在这陀罗尼中常思惟法性。帝释、梵天、诸天众、龙王、阿修罗，听闻这陀罗尼，心生大欢喜。）

```
如是陀罗尼，所经诸国土，
常无有灾难，病苦及忧恼。
一切诸众生，各各皆欣乐，
愿此陀罗尼，常住于我心。
如是陀罗尼，随所在身心，
喉腭及唇舌，生无量功德。
若能常受持，获无量功德，
利益多众生，皆令得欢喜。
如是陀罗尼，舍离诸过恶，
演说微妙法，得无尽辩才。
令百千众生，皆断除疑惑，
摧破诸憍慢，获无量功德。
如是陀罗尼，甚深微密法，
智者常思惟，勇猛勤修习。
被于智慧甲，摧灭诸烦恼，
增长功德已，爱乐无厌足。
如是陀罗尼，具广大名称，
能了尽无尽，生边无生边。
以如是智慧，种种自庄严，
百千诸如来，尊重而供养。
```
（大意：这样的陀罗尼所经过的诸国土，常无灾难、病苦以及忧恼；一切众生各各欣乐，愿这陀罗尼常住于我心。这样的陀罗尼随其所在的身心、喉腭以及唇舌，生出无量功德；若能常加受持，获得无量功德，利益众多众生，都令他们欢喜。这样的陀罗尼舍离诸过恶，演说微妙之法，得无尽辩才；令百千众生都断除疑惑，摧破诸憍慢，获得无量功德。这样的陀罗尼是甚深微密之法，智者常加思惟，勇猛勤修；披上智慧之甲，摧灭诸烦恼，增长功德之后，爱乐而无厌足。）

【按】“唇舌”之“舌”，宫本作“口”。“增长功德已”之“已”，宋、元、明、宫、圣本作“心”。

```
如是陀罗尼，明行为两足，
依止于胜定，趣向菩提道，
随顺于止观，通达无漏慧。
以净信根力，成就于二手，
以精进忍辱，成就于两乳，
智慧波罗蜜，而为其顶相，
修多罗为线，贯穿四辩鬘。
往昔所修行，种种诸功德，
及无量譬喻，一切悉庄严。
如是陀罗尼，具无量功德，
于眼前后际，尽边无尽边。
若生若无生，边际非边际，
寂静不寂静，流转非流转。
无有及无起，寂灭并无我，
无人无寿者，乃至无众生。
如是无量门，一切皆解了。
耳鼻舌身心，六尘并四大，
乃至世生名，一切皆如是。
如上所称叹，微妙陀罗尼，
寂静胜功德，诸佛之境界。
陀罗尼实义，非文字诠表，
随顺于世间，但以假名说。
```
（大意：这样的陀罗尼具有广大名称，能了知尽与无尽、生边与无生边；以这样的智慧种种自我庄严，百千如来都尊重供养。这样的陀罗尼，以明与行为两足，依止于殊胜之定，趣向菩提之道，随顺于止观，通达无漏之慧；以清净的信根之力成就两手，以精进、忍辱成就两乳，以智慧波罗蜜作为其顶相，以修多罗为线，贯穿四无碍辩之鬘；往昔所修行的种种功德以及无量譬喻，一切都作为庄严。这样的陀罗尼具足无量功德：对于眼的前际后际，尽边与无尽边，生与无生，边际与非边际，寂静与不寂静，流转与非流转，无有以及无起，寂灭以及无我，无人、无寿者，乃至无众生，这样无量的法门，一切都能解了。耳鼻舌身心，六尘以及四大，乃至世、生、名，一切都是这样。以上所称叹的微妙陀罗尼，寂静而具殊胜功德，是诸佛的境界。陀罗尼的真实之义，不是文字所能诠表的，只是随顺世间，以假名而说。）

【按】“陀罗尼实义”之“实”，南藏作“真”。

### 世尊受供，宣说施资粮的八十种功德

那时，世尊与大众到了童子家中，敷座而坐。这时，月光童子知道佛已坐好，亲自捧持微妙供具，奉献如来以及大众；这些供物纯粹是以禅定、福德、殊胜善根的不可思议之力所成就的。他这样布施时，也不是为了自己，而是普令一切无量众生发心趣向菩提，获得大善利；他的供养周遍大众，全都充足。

那时，世尊用斋完毕，在众会中告诉月光童子说：“童子！若有善男子、善女人等安住于大乘，行布施资粮，有八十种殊胜功德。是哪八十种？就是：成熟众生；以善言摄受；妙相圆满；诸根无缺；舍离生死；证于涅槃；断尽诸结使；得殊胜自在；具足功德；庄严佛土；眷属清净；有大威德；具足智慧；成就最上殊胜之行；圆满无上、无等等之行；除灭习气；增长如来一切智之行；其身与舍利为世间的声闻、缘觉所供养；摧破恶人；能令人王、天、龙、夜叉、阿修罗王、迦楼罗王以及梵天王都生清净信心；有大威德；宣说契经、应颂、授记、自说、讽诵、譬喻、因缘、本事、本生、方广、希法，乃至论议，受持演说而心无懈倦；于法无吝；安住佛道；为世界最胜；名色清净；证得法身；得无所畏；成就福德；映蔽诸外道；具足善人之法；舍弃恶人之行；以信为福德与智慧之因；与佛法和合；降伏众魔；对佛所说的安乐之法无有疑惑；摧破恶欲；具大威德；修菩萨行；得殊胜神通；舍离生死；成就众生；赞叹无边之行；摄受功德；慰喻众生；受用法乐；修行惠施；入大智之门；住于煖法；种性决定；修行法忍；安住佛道。童子！若善男子、善女人等修布施资粮，便具足成就这八十种殊胜功德。”

【按】“受记”为原文，即十二部经中的“授记”。“皆生清信”之“清”，宋、元、明、宫本作“净”。原文所列与“八十”之数未必一一相合，今依原文照译。“信福智因”，依文意作“以信为福德与智慧之因”。

那时，世尊又说偈道：

#### 布施资粮的胜利

```
大智诸菩萨，具足施资粮，
胜利有八十，我今已略说。
复有诸功德，无量难思议，
皆从布施生，今当少宣说。
汝以平等施，普遍于大会，
如是施资粮，智者应修习。
此施能积集，福聚不思议，
相好庄严身，一切皆圆满。
生处及种族，国土若居家，
名称与色心，一切皆清净。
诸天神变事，及宫殿婇女，
清净无碍辩，皆从布施生。
布施胜资粮，诸佛咸称叹，
此即是菩提，最初安住本。
```
（大意：大智诸菩萨具足布施资粮，其胜利有八十种，我现在已略说了。还有其余无量难以思议的功德，都从布施而生，现在当少加宣说。你以平等之心布施，普遍于整个大会，这样的布施资粮，智者应当修习。这布施能积集不可思议的福聚，以相好庄严其身，一切都圆满。其生处以及种族，国土或者居家，名称与色心，一切都清净。诸天的神变之事以及宫殿、婇女，清净无碍的辩才，都从布施而生。布施这一殊胜资粮，诸佛都称叹，这就是菩提最初安住的根本。）

```
精进诸菩萨，于施无疑惑，
安住决定心，勤修于布施。
如是布施心，成就殊胜福，
菩萨勤修习，当证佛菩提。
由布施威力，成就胜神通，
振动俱胝刹，不损诸众生。
由布施能引，净戒及多闻，
正信与精进，三昧无漏慧。
由布施能引，根力菩提分，
正断及神足，远离诸习气。
由布施能引，清净妙音声，
于百俱胝刹，开示无边法。
由净信行施，速得诸神通，
为成就神通，应勤修布施。
```
（大意：精进的诸菩萨对布施无有疑惑，安住于决定之心，勤修布施。这样的布施之心成就殊胜之福，菩萨勤加修习，当证佛菩提。由布施的威力，成就殊胜神通，振动俱胝刹土而不损伤众生。由布施能引生净戒以及多闻、正信与精进、三昧与无漏慧。由布施能引生诸根、诸力、菩提分、正断以及神足，远离种种习气。由布施能引生清净美妙的音声，在百俱胝刹土开示无边之法。由清净信心而行布施，便迅速得到种种神通；为了成就神通，应当勤修布施。）

【按】“振动俱胝刹”之“振”，明本作“震”。

```
无量诸天众，百千阿修罗，
龙神及夜叉，眷属共围绕，
咸乘妙楼阁，自在而游戏。

```
（大意：无量天众、百千阿修罗、龙神以及夜叉，眷属共同围绕，都乘着美妙楼阁自在游戏；这样的诸王见到勤行布施的人，都当起身远迎，敷座供养。这样行布施的人具足大威德与自在神通之力，摄受诸天王；鸠槃荼、夜叉都来归伏，乾闼婆众也献上种种音乐。贼害之人对他生起慈心，恶人当会远离，珍财无有损减，库藏都充盈。因修布施的缘故，成就殊胜资粮，乃至获得佛智，不行外道之法。此人没有病恼，守护陀罗尼，得到种种殊胜之力，都从布施而生。这样行布施的人修习菩提之道，不遇恶知识，得到同类的善友。）

#### 施资粮者的智慧

```
复有诸菩萨，积集施资粮，
成就不思议，陀罗尼智慧。
以无量偈颂，演说于总持，
一切无罣碍，不失于本义。
广大菩提心，志愿常坚固，
具足于净戒，舍离诸魔业。
不著五欲乐，专精求正念，
心常无迷惑，亦不生贪爱。
瞋恚诸烦恼，如实皆了知，
于一切境界，不著不迷惑。
是人善了知，如是诸烦恼，
以因缘和合，能生诸过失。
乃至于佛法，若因若因因，
如是因作用，一切皆能了。
```
（大意：又有诸菩萨积集布施资粮，成就不可思议的陀罗尼智慧，以无量偈颂演说总持，一切无有罣碍，不失本义。他们广大的菩提心志愿常坚固，具足净戒，舍离诸魔业；不著五欲之乐，专精求取正念，心常无迷惑，也不生贪爱；对于瞋恚等诸烦恼都如实了知，对于一切境界不著也不迷惑。此人善能了知这样的诸烦恼，是以因缘和合而能生出种种过失；乃至对于佛法，或因、或因之因，这样的因的作用，一切都能了知。）

【按】“专精求正念”之“精”，宋、元、明、宫本作“勤”。

#### 贪瞋痴即佛道与供养痴

```
是人能了知，贪欲即佛道，
自性无差别，于贪无所染。
一切诸佛道，当于烦恼求，
知性无差别，是入总持门。
说贪是总持，总持即是贪，
知性无差别，是学总持门。
如是供养贪，即为供养佛，
以供养佛故，成就总持门。
是人能了知，瞋恚即佛道，
自性无差别，于瞋无所染。
瞋即是总持，总持即是瞋，
知性无差别，是学总持门。
如是供养瞋，亦为供养佛，
以供养佛故，成就总持门。
是人能了知，愚痴即佛道，
自性无差别，于痴无所染。
若如实了知，痴性之边际，
是则修佛道，成就总持门。
痴即是总持，总持即是痴，
知性无差别，是学总持门。
如是供养痴，即为供养佛，
以供养佛故，成就总持门。
```
（大意：此人能了知贪欲即是佛道，自性无有差别，于贪无所染著。一切诸佛之道，应当在烦恼中求取；知其性无差别，这便是进入总持之门。说贪是总持，总持即是贪，知其性无差别，这便是修学总持之门。这样供养贪，即是供养佛；因供养佛的缘故，成就总持之门。此人能了知瞋恚即是佛道，自性无有差别，于瞋无所染著。瞋即是总持，总持即是瞋，知其性无差别，这便是修学总持之门。这样供养瞋，也就是供养佛；因供养佛的缘故，成就总持之门。此人能了知愚痴即是佛道，自性无有差别，于痴无所染著。若如实了知痴性的边际，这便是修佛道，成就总持之门。痴即是总持，总持即是痴，知其性无差别，这便是修学总持之门。这样供养痴，即是供养佛；因供养佛的缘故，成就总持之门。）

### 为成就陀罗尼应远离的八十种人

那时，世尊告诉月光童子说：“善男子！若有众生安住于大乘，想要成就以上所说的陀罗尼，应当远离八十种人。是哪八十种？就是：杀父的人；害母的人；杀阿罗汉的人；以屠害之心出佛身血的人；破和合僧的人；贼住出家的人；无根与二根之人；邪见、邪思惟、邪语、邪业、邪命、邪精进、邪念、邪定的人；不知处、不知时、不知法、不知道、不知量、不知自他的人；对佛、法、僧以及诸学处不能尊重，对不放逸以及殊胜境界也不宗仰的人；不知法、不知律、不知学处、不知其罪是重是轻、不知其戒是毁是缺、又不知所行是细是粗、也不知业的未来与现在、对下劣之事也不了知的人；赞叹声闻乘、毁谤如来之法的人；劝导开示辟支佛乘，令人远离厌舍无上正道的人；破戒、破见、破诸威仪、行于非道的人；说有我、有人、有众生、有命者、有补特伽罗的人；志意下劣，生起贪瞋痴的人；持断见、常见、空无因见的人；不见有、不见无、不见业、不见精进的人；不知业、不知业因，不知异熟、不知异熟因，不知诸根、不知诸根之因，不知界、不知界因，不知解脱、不知解脱因，不知道、不知道因，不知烦恼、不知烦恼因，不知布施、不知布施之因，不知前际与后际、不知前际与后际之因，不知生死、不知生死之因，不知有漏、不知有漏之因，不知尽与非尽，不知有与非有，不知边际与非边际，不知寂静与非寂静，不知转与非转，不知性与非性，不知生与非生，不知灭与非灭的人。童子！若善男子、善女人等想要成就以上所说的陀罗尼，应当舍离这八十种非法之人。”

【按】“贼住出家”，指未受具足戒而私入僧中、窃听说戒羯磨者。“无根二根”，指无男女根者与兼具二根者。原文所列与“八十”之数未必一一相合，今依原文照译。

那时，世尊又说偈道：

#### 应远离与应亲近之人

```
若不了于眼，生尽之边际，
是人迷总持，智者应远离。
若能了于眼，无我无众生，
是人住总持，智者应亲近。
若能了于眼，生尽离文字，
是人住总持，智者应亲近。
若能了于眼，寂静无所住，
是人住总持，智者应亲近。
若能了于眼，自性无所住，
是人住总持，智者应亲近。
若能了于眼，无转无色相，
是人住总持，智者应亲近。
若能了于眼，无生性寂灭，
是人住总持，智者应亲近。
若能了于眼，自性离名相，
诸佛无能说，称叹及表示，
是人住总持，智者应亲近。
若能了于眼，自性离名相，
无有能思惟，受持及演说，
是人住总持，智者应亲近。
```
（大意：若不了知眼的生尽边际，此人迷于总持，智者应当远离他。若能了知眼无我、无众生，此人安住于总持，智者应当亲近他。若能了知眼的生与尽离于文字，此人安住于总持，智者应当亲近他。若能了知眼寂静无所住，此人安住于总持，智者应当亲近他。若能了知眼的自性无所住，此人安住于总持，智者应当亲近他。若能了知眼无转、无色相，此人安住于总持，智者应当亲近他。若能了知眼无生、其性寂灭，此人安住于总持，智者应当亲近他。若能了知眼的自性离于名相，诸佛也无法言说、称叹以及表示，此人安住于总持，智者应当亲近他。若能了知眼的自性离于名相，没有谁能思惟、受持以及演说，此人安住于总持，智者应当亲近他。）

#### 总持自性空

```
如是总持性，非文字诠辩，
无有诸方所，亦非心所到，
是法无欢喜，亦不住瞋恚，
不动如山王，虽说无所得。
总持实无有，乃至我亦无，
若我自性空，总持亦无有。
总持自性空，愚者计为有，
由是妄分别，不闻生忧恼。
若分别贪性，及以总持空，
如是二分别，毕竟不可得。
若了空性空，总持亦非有，
乃至菩提分，三摩地亦空。
若有能了知，总持及空性，
乃至三摩地，于眼亦了知。
```
（大意：这样的总持之性，不是文字所能诠辩的，没有种种方所，也不是心所能到达的；此法无有欢喜，也不住于瞋恚，如山王般不动，虽然宣说，却无所得。总持实际上并不存在，乃至我也没有；若我的自性是空，总持也就没有。总持自性空，愚者却计为实有；由于这样的妄分别，不闻正法而生忧恼。若分别贪性以及总持之空，这样的两种分别，毕竟都不可得。若了知空性亦空，总持也非实有，乃至菩提分、三摩地也都是空。若有人能了知总持以及空性，乃至三摩地，对于眼也就了知了。）

（大意：若对于眼的尽边如实善加了知，便对总持之门究竟能够成就。以下同样：若对于眼的生边、边际、寂静、流转、无有、无生、寂灭如实善加了知，便对总持之门究竟能够成就。若在眼的变异之中如实了知其尽边，便对总持之门究竟能够成就；同样，在眼的变异之中如实了知其生边、边际、寂静、流转、无有、无生、寂灭，便对总持之门究竟能够成就。耳鼻舌身心，六尘以及四大，乃至世、生、名，一切都是这样。）

#### 于地、于我无取无分别

```
于地不变异，无取无分别，
如是了知者，成就总持门。
于地无生相，无取无分别，
如是了知者，成就总持门。
于地无灭相，无取无分别，
如是了知者，成就总持门。
于地证入相，无取无分别，
如是了知者，成就总持门。
于地出离相，无取无分别，
如是了知者，成就总持门。
于地无愿相，无取无分别，
如是了知者，成就总持门。
于地无住相，不来亦不去，
无边与无尽，相应不相应。
离名字计度，观察与流转，
无有及修治，无言说表示。
寂静无所依，念住并正断，
神足及根力，觉支无畏道。
如是诸地法，无取无分别，
如是了知者，成就总持门。
```
（大意：对于地不变异之相，无取无分别，这样了知的人便成就总持之门。对于地的无生之相、无灭之相、证入之相、出离之相、无愿之相，无取无分别，这样了知的人都成就总持之门。对于地的无住之相，不来亦不去，无边与无尽，相应与不相应，远离名字计度，观察与流转，无有以及修治，无言说、无表示，寂静无所依，念住以及正断，神足以及根、力，觉支、无畏、道——这样的诸地之法，无取无分别，这样了知的人便成就总持之门。）

```
若于我无入，无取无分别，
如是了知者，成就总持门。
若于我无出，无取无分别，
如是了知者，成就总持门。
若于我无相，无取无分别，
如是了知者，成就总持门。
若于我无愿，无取无分别，
如是了知者，成就总持门。
若于我无住，无取无分别，
如是了知者，成就总持门。
若于我无生，无取无分别，
如是了知者，成就总持门。
若于我无灭，无取无分别，
如是了知者，成就总持门。
若于我文字，无取无分别，
如是了知者，成就总持门。
若我离文字，无取无分别，
如是了知者，成就总持门。
知眼前后际，远离于断常，
因缘自性空，导师方便说。
```
（大意：若对于我的无入，无取无分别，这样了知的人便成就总持之门。同样，对于我的无出、无相、无愿、无住、无生、无灭，对于我的文字，以及我离于文字，无取无分别，这样了知的人都成就总持之门。知眼的前际后际，远离断见与常见，因缘的自性是空，这是导师以方便而说。）

#### 分别眼相不名说法

```
若演说法时，分别于眼相，
是人妄分别，不名真说法。
若思惟法时，分别于眼相，
是人妄分别，不名思惟法。
若修习法时，分别于眼相，
是人妄分别，不名修习法。
若了眼空性，即不趣菩提，
诸佛于是人，常现前说法。
若不了知眼，亦不了知色，
若能了知眼，于色亦了知。
若能了于眼，于色亦了知，
若于色了知，于眼亦能了。
耳鼻舌身心，六尘并四大，
乃至世生名，一切皆如是。
```
（大意：若演说法时分别眼相，此人是妄分别，不名为真正说法。若思惟法时分别眼相，此人是妄分别，不名为思惟法。若修习法时分别眼相，此人是妄分别，不名为修习法。若了知眼的空性，便不趣向菩提，诸佛对于此人常现前说法。若不了知眼，也就不了知色；若能了知眼，对于色也就了知。若能了知眼，对于色也就了知；若对于色了知，对于眼也就能了知。耳鼻舌身心，六尘以及四大，乃至世、生、名，一切都是这样。）

原文：“若了眼空性，即不趣菩提”（大意：若了知眼的空性，便不趣向菩提。所言“不趣菩提”所指未详，存疑。）

```
若演说法时，分别于因相，
是人妄分别，不名为说法。
若演说法时，分别寂静相，
是人妄分别，不名为说法。
若演说法时，分别于道相，
是人妄分别，不名为说法。
若演说法时，分别于空相，
是人妄分别，不名为说法。
若演说法时，分别于积集，
是人妄分别，不名为说法。
若演说法时，分别于事物，
是人妄分别，不名为说法。
若演说法时，分别眼摄取，
是人妄分别，不名为说法。
于眼不了知，是则生贪欲，
若能了知眼，贪欲则不生。
耳鼻舌身心，六尘并四大，
乃至世生名，一切皆如是。
若演说法时，分别种种果，
是人妄分别，不名为说法。
不退于志愿，了达于性空，
得诸三昧门，彼能善说法。
不退于志愿，于眼离分别，
以无分别故，彼能善说法。
```
（大意：若演说法时分别因相，此人是妄分别，不名为说法。同样，若演说法时分别寂静之相、道相、空相，分别积集、事物，分别眼的摄取，此人都是妄分别，不名为说法。对眼不了知，便生起贪欲；若能了知眼，贪欲便不生。耳鼻舌身心，六尘以及四大，乃至世、生、名，一切都是这样。若演说法时分别种种果，此人是妄分别，不名为说法。不退失志愿，了达性空，得诸三昧之门，他便能善说法。不退失志愿，对眼远离分别，因无分别的缘故，他便能善说法。）

【按】“分别种种果”之“果”，宋、元、明、宫、圣本作“界”。“彼能善说法”之“善”，宫本作“宣”。

#### 应说法与不应说法者

```
不了眼性空，亦迷眼自性，
以不了知故，是不应说法。
若了眼性空，即知眼自性，
以能了知故，是人应说法。
不了眼性空，亦迷句自性，
以不了知故，是不应说法。
若了眼性空，即知句自性，
以能了知故，是人应说法。
不了眼性空，亦迷文自性，
以不了知故，是不应说法。
若了眼性空，即知文自性，
以能了知故，是人应说法。
不了眼性空，亦迷名自性，
以不了知故，是不应说法。
若了眼性空，即知名自性，
以能了知故，是人应说法。
不了眼性空，亦迷色自性，
以不了知故，是不应说法。
若了眼性空，即知色自性，
以能了知故，是人应说法。
不了眼性空，依世相分别，
不能善随顺，调伏诸众生。
若了眼性空，不依相分别，
即能善随顺，调伏诸众生。
```
（大意：不了知眼的性空，也迷于眼的自性，因不了知的缘故，此人不应说法；若了知眼的性空，便知眼的自性，因能了知的缘故，此人应当说法。不了知眼的性空，也迷于句的自性、文的自性、名的自性、色的自性，因不了知的缘故，此人不应说法；若了知眼的性空，便知句的自性、文的自性、名的自性、色的自性，因能了知的缘故，此人应当说法。不了知眼的性空，依世间之相而分别，便不能善加随顺、调伏众生；若了知眼的性空，不依相而分别，便能善加随顺、调伏众生。）

【按】“若了眼性空，不依相分别，即能善随顺，调伏诸众生”一颂，宋、元、明、宫、圣本无。

```
不了眼有无，处众而说法，
是人贪利养，一切无信受。
若了眼有无，处众而说法，
是人不贪著，一切皆信受。
不了眼性空，而处于法座，
虽说多譬喻，一切无信受。
若了眼性空，而处于法座，
所说诸譬喻，一切皆信受。
耳鼻舌身心，六尘并四大，
乃至世生名，一切皆如是。
```
（大意：不了知眼的有与无，处在大众中说法，此人贪求利养，一切人都不信受；若了知眼的有与无，处在大众中说法，此人不贪著，一切人都信受。不了知眼的性空而坐于法座，虽然说了许多譬喻，一切人都不信受；若了知眼的性空而坐于法座，所说的种种譬喻，一切人都信受。耳鼻舌身心，六尘以及四大，乃至世、生、名，一切都是这样。）

### 流通

那时，世尊说完这部经，月光童子以及大众，一切世间的天、人、阿修罗、乾闼婆等，听闻佛所说，都大欢喜，信受奉行。

【按】出现光明会至此圆满，凡五卷（卷第三十至卷第三十四）。
