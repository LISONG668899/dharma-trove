# 《大般涅槃经》卷第十四（梵行品）

北凉·天竺三藏昙无谶 译　刘宋·沙门慧严等 依《泥洹经》再治

## 梵行品第二十之一

### 七善法

"善男子，什么是菩萨摩诃萨的梵行？善男子，菩萨摩诃萨安住于大乘大般涅槃，住于七种善法，就得以具足梵行。哪七种？一是知法，二是知义，三是知时，四是知足，五是自知，六是知众，七是知尊卑。

#### 知法：十二部经

"善男子，什么是菩萨摩诃萨知法？善男子，这位菩萨摩诃萨了知十二部经，即修多罗、祇夜、授记、伽陀、优陀那、尼陀那、阿波陀那、伊帝目多伽、阇陀伽、毗佛略、阿浮陀达摩、优波提舍。

"善男子，什么名为修多罗经？从'如是我闻'乃至'欢喜奉行'，这一切名为修多罗。

"什么名为祇夜经？佛告诉诸比丘：'过去我与你们愚昧无智，不能如实见到四真谛，所以流转，久处生死，沉没在大苦海中。哪四种？苦、集、灭、道。'如佛过去为诸比丘说完契经之后，那时又有利根的众生为了听法，后来才到佛所，就问别人：'如来刚才说了什么事？'佛当时知道了，就依本经，以偈颂说：

```
我昔与汝等
不见四真谛
是故久流转
生死大苦海
若能见四谛
则得断生死
生有既已尽
更不受诸有
```

（大意：过去我与你们，没有见到四真谛，所以长久流转于生死大苦海中。若能见到四谛，就能断除生死；生与有既已穷尽，就不再受诸有。）

"这名为祇夜经。

"什么名为授记经？如有经律，如来宣说时，为诸天人授成佛的记别：'你阿逸多，未来有国王名叫蠰佉，你当在那时成就佛道，号为弥勒。'这名为授记经。

"什么名为伽陀经？除了修多罗以及诸戒律之外，其余所说的四句偈，如：

```
诸恶莫作
诸善奉行
自净其意
是诸佛教
```

（大意：一切恶不要做，一切善奉行，自己净化其心意，这就是诸佛的教法。）

"这名为伽陀经。

"什么名为优陀那经？如佛在傍晚入于禅定，为诸天众广说法要。当时诸比丘各自想：'如来现在在做什么？'如来第二天早晨从禅定起来，没有人问，以他心智就自己说道：'比丘们应当知道，一切诸天的寿命极长。你们诸比丘，善哉！为他人而不求自利；善哉，少欲；善哉，知足；善哉，寂静。'像这样无人发问而自说的诸经，名为优陀那经。

"什么名为尼陀那经？如诸经偈依其所由的根本因缘为他人演说。如舍卫国有一个男子，用罗网捕鸟，捕到之后关在笼中，随时给它水和谷物，后来又放了它。世尊知道这事的始末因缘，就说偈：

```
莫轻小恶
以为无殃
水渧虽微
渐盈大器
```

（大意：不要轻视小恶，以为不会招来祸殃；水滴虽然微小，渐渐也能盈满大器。）

"这名为尼陀那经。

"什么名为阿波陀那经？如戒律中所说的譬喻，这名为阿波陀那经。

"什么名为伊帝目多伽经？如佛所说：'比丘们应当知道，我出世时所说的名为契经；鸠留秦佛出世时，名为甘露鼓；拘那含牟尼佛时，名为法镜；迦叶佛时，名为分别空。'这名为伊帝目多伽经。

"什么名为阇陀伽经？如佛世尊本为菩萨时修诸苦行，所谓：'比丘们应当知道，我在过去作鹿、作罴、作獐、作兔，作粟散小王、转轮圣王、龙、金翅鸟。'诸如此类行菩萨道时所受的身，这名为阇陀伽。

"什么名为毗佛略经？就是大乘方等经典，其义广大犹如虚空，这名为毗佛略。

"什么名为未曾有经？如那位菩萨刚出生时，无人扶持，就行走七步，放大光明，遍观十方；也如猕猴手捧蜜器献给如来；如白颈狗在佛边听法；如魔波旬变作青牛，行走在瓦钵之间，令诸瓦钵互相碰撞，却毫无损伤；如佛初生时进入天庙，令那天神之像起身下来礼敬。这样的诸经，名为未曾有经。

"什么名为优波提舍经？如对佛世尊所说的诸经，作议论，分别广说，辨明其相状，这名为优波提舍经。

"菩萨若能这样了知十二部经，名为知法。

【按】十二部经中，阿浮陀达摩即"未曾有经"，前列其梵名，后释其汉义。

#### 知义、知时、知足、自知、知众

"什么是菩萨摩诃萨知义？菩萨摩诃萨若对一切文字语言广知其义，这名为知义。

"什么是菩萨摩诃萨知时？善男子，菩萨善知：在这样的时候，适合修寂静；在这样的时候，适合修精进；在这样的时候，适合修舍定；在这样的时候，适合供养佛；在这样的时候，适合供养师长；在这样的时候，适合修布施、持戒、忍辱、精进、禅定，具足般若波罗蜜。这名为知时。

"什么是菩萨摩诃萨知足？善男子，菩萨摩诃萨知足，即对饮食、衣服、医药，行住坐卧、睡眠醒觉、言语沉默，都知足。这名为知足。

"善男子，什么是菩萨摩诃萨自知？这位菩萨自知：我有这样的信，这样的戒，这样的多闻，这样的舍，这样的慧，这样的去来，这样的正念，这样的善行，这样的问，这样的答。这名为自知。

"什么是菩萨摩诃萨知众？善男子，这位菩萨知道：这是刹利众，婆罗门众，居士众，沙门众；在这样的众中，应当这样往来，这样坐起，这样说法，这样问答。这名为知众。

#### 知人尊卑

"善男子，什么是菩萨摩诃萨知人尊卑？善男子，人有两种：一是有信，二是无信。菩萨应当知道，有信的是善，无信的不名为善。

"再者，有信的又有两种：一是常往僧坊，二是不往。菩萨应当知道，往的是善，不往的不名为善。

"往僧坊的又有两种：一是礼拜，二是不礼拜。菩萨应当知道，礼拜的是善，不礼拜的不名为善。

"礼拜的又有两种：一是听法，二是不听。菩萨应当知道，听法的是善，不听法的不名为善。

"听法的又有两种：一是至心听，二是不至心。菩萨应当知道，至心听的名为善，不至心的不名为善。

"至心听法的又有两种：一是思惟其义，二是不思惟。菩萨应当知道，思惟的是善，不思惟的不名为善。

"思惟的又有两种：一是如所说而行，二是不如所说而行。如所说而行的是善，不如所说而行的不名为善。

"如所说而行的又有两种：一是求声闻，不能利益安乐饶益一切苦恼众生；二是回向无上大乘，利益多人，令得安乐。菩萨应当知道，能利益多人令得安乐的，最上最善。

"善男子，如诸宝之中，如意宝珠最为殊胜微妙；如诸味之中，甘露最上；这样的菩萨在人天之中，最胜最上，不可譬喻。

"善男子，这名为菩萨摩诃萨安住于大乘《大涅槃经》，住于七善法。菩萨住于这七善法之后，就得以具足梵行。

### 慈悲喜舍：为何是四

"再者，善男子，又有梵行，即慈、悲、喜、舍。"

迦叶菩萨对佛说："世尊，若多修慈，能断瞋恚；修悲心，也能断瞋恚，为什么说四无量心？推究其义，应当只有三种。

"世尊，慈有三种所缘：一是缘众生，二是缘法，三是无缘。悲、喜、舍心也是如此。若依这个道理，只应有三，不应有四。

"众生缘，是缘于五阴，愿给予其安乐，这名为众生缘。法缘，是缘众生所需的物品而施给他们，这名为法缘。无缘，是缘于如来，这名为无缘。慈多是缘贫穷众生，如来大师永离贫穷，受第一乐；若缘众生，就不缘佛，缘法也是如此。因为这个道理，缘如来的，名为无缘。

"世尊，慈所缘的一切众生，如同缘父母、妻子、亲属，因为这个道理，名为众生缘。法缘，是不见父母、妻子、亲属，见一切法都从因缘而生，这名为法缘。无缘，是不住于法相及众生相，这名为无缘。悲、喜、舍心也是如此。所以应当是三，不应有四。

【按】迦叶对"三缘"先后举了两种解释：前一种以"缘如来"为无缘，后一种以"不住法相及众生相"为无缘。

"世尊，人有两种：一是见行，二是爱行。见行之人多修慈悲，爱行之人多修喜舍。所以应当是二，不应有四。

"世尊，所谓无量，名为无边，边际不可得，所以名为无量。若是无量，就应当是一，不应说四；若说是四，怎能是无量？所以应当是一，不应是四。"

#### 佛答：如来说法，秘密难知

佛告诉迦叶："善男子，诸佛如来为众生所宣说的法要，其言秘密，难以了知。或者为众生说一种因缘。比如说：什么是一种因缘？就是一切有为之法。

"善男子，或者说两种，即因与果；或者说三种，即烦恼、业、苦；或者说四种，即无明、诸行、生、老死；或者说五种，即受、爱、取、有以及生；或者说六种，即三世的因果；或者说七种，即识、名色、六入、触、受以及爱、取；或者说八种，即除去无明、行以及生、老死之外，其余的八事；或者说九种，如《城经》中除去无明、行、识，其余的九事；或者说十一种，如为萨遮尼犍子所说，除去生这一法，其余的十一种；或者有时完整地说十二因缘，如在王舍城为迦叶等完整地说十二支，从无明乃至生、老、病、死。

"善男子，如一种因缘，为了众生而作种种分别，无量心法也是这样。善男子，因为这个道理，对于诸如来深密的行处，不应生疑。

"善男子，如来世尊有大方便：无常说为常，常说为无常；说乐为苦，说苦为乐；不净说为净，净说为不净；我说为无我，无我说为我；对于非众生说为众生，对于真实众生说为非众生；非物说为物，物说为非物；非实说为实，实说为非实；非境说为境，境说为非境；非生说为生，生说为非生；乃至无明说为明，明说为无明；色说为非色，非色说为色；非道说为道，道说为非道。善男子，如来以这样无量的方便来调伏众生，岂是虚妄？

"善男子，或者有众生贪著财货，我对这人，就化身作转轮王，在无量岁中随他所需，给予种种供给，然后教化他，令他安住于无上正等正觉。若有众生贪著五欲，我就在无量岁中以妙五欲满足他的心意，然后劝化他，令他安住于无上正等正觉。若有众生以荣华豪贵自尊自大，我就在无量岁中为他作仆役，奔走侍奉，得到他的心之后，就又劝化他，令他安住于无上正等正觉。若有众生性情乖戾，自以为是，须要有人呵责劝谏，我就在无量百千岁中教诲呵责，殷勤晓喻，令他的心调顺，然后又劝他，令他安住于无上正等正觉。

"善男子，如来就是这样在无量岁中以种种方便，令诸众生安住于无上正等正觉，岂是虚妄？诸佛如来虽然身处众恶之中，却无所染污，犹如莲花。善男子，应当这样了知四无量的意义。

"善男子，这无量心的体性有四种，若有人修行，就生于大梵天处。

#### 四无量各有所对治

"善男子，这样的无量心，伴侣有四种，所以名为四。修慈能断贪欲，修悲心能断瞋恚，修喜心能断不乐，修舍心能断贪欲、瞋恚与众生相。善男子，因为这个道理，得名为四，不是一、二、三。

【按】"修舍心者能断贪欲瞋恚众生"，后文复述作"修舍心者能断贪恚及众生相"，据此译。

"善男子，如你所说，慈能断瞋，悲也是这样，应当说三种。你现在不应作这样的问难。为什么呢？善男子，瞋恚有两种：一种能夺命，一种能鞭打。修慈就能断那夺命之瞋，修悲能除那鞭打之瞋。善男子，因为这个道理，岂不是四种吗？

"再者，瞋有两种：一是瞋众生，二是瞋非众生。修慈心的人断对众生的瞋，修悲心的人断对非众生的瞋。

"再者，瞋有两种：一是有因缘，二是无因缘。修慈心的人断有因缘的，修悲心的人断无因缘的。

"再者，瞋有两种：一是过去长久修习的，二是现在修习的。修慈心的人能断过去的，修悲心的人断现在的。

"再者，瞋有两种：一是瞋圣人，二是瞋凡夫。修慈心的人断瞋圣人，修悲心的人断瞋凡夫。

"再者，瞋有两种：一是上品，二是中品。修慈断上品，修悲断中品。

"善男子，因为这个道理，就名为四，怎能问难说应当是三而不是四？所以迦叶，这无量心以伴侣相对，分别为四。

"又因为心器的缘故，应名为四：心器之中若有慈，就不能同时有悲、喜、舍心。因为这个道理，应是四种，不能减少。

"善男子，以行相分别，所以应有四种：若行慈时，就没有悲、喜、舍，所以有四种。

"善男子，以无量的缘故，也得名为四。所谓无量，有四种：有的无量心有所缘而不自在；有的无量心自在而非所缘无量；有的无量心既所缘无量又自在；有的无量心既非所缘无量也不自在。

"什么无量是有所缘而不自在？缘于无量无边的众生，却不能得自在三昧，虽然得了也不稳定，或得或失。

"什么无量是自在而非所缘无量？如缘父母、兄弟、姊妹，想令他们安乐，所缘并非无量。

"什么无量是既所缘无量又自在？就是诸佛菩萨。

"什么无量是既非所缘无量也不自在？声闻、缘觉不能广缘无量众生，也不自在。

"善男子，因为这个道理，名为四无量，不是诸声闻、缘觉所能了知的，是诸佛如来的境界。善男子，这四事，声闻、缘觉虽然也名为无量，却少得不值一提；诸佛菩萨，才得名为无量无边。"

迦叶菩萨对佛说："世尊，是这样，是这样，实在如圣教所说，诸佛如来所有的境界，不是诸声闻、缘觉所能达到的。

### 慈与大慈

"世尊，是否有菩萨安住于大乘大般涅槃，得慈悲心，却不是大慈大悲心呢？"

佛说："有的，善男子。菩萨若对诸众生作三品分别：一是亲人，二是怨憎，三是中人。对亲人中又作三品，即上、中、下；怨憎也是如此。

"这位菩萨摩诃萨对上品亲人给予增上之乐，对中、下品亲人也平等给予增上之乐；对上品怨憎给予少分之乐，对中品怨憎给予中品之乐，对下品怨憎给予增上之乐。菩萨这样转进修习，对上品怨憎给予中品之乐，对中、下品怨憎平等给予增上之乐。再转进修习，对上、中、下品怨憎平等给予上乐。若对上品怨憎也给予上乐，那时就得名为慈心成就。菩萨那时对于父母和上品怨憎，得平等心，没有差别。善男子，这名为得慈，不是大慈。"

"世尊，什么缘故菩萨得这样的慈，仍然不能名为大慈？"

"善男子，因为难以成就，所以不名为大慈。为什么呢？长久以来在过去无量劫中，多积集烦恼，未修善法，所以不能在一日之中调伏其心。

"善男子，譬如干的豌豆，用锥子刺，终究刺不进去；烦恼的坚硬也是这样，虽然一日一夜系心不散，也难以调伏。又如家犬不怕人，山林中的野鹿见人就惊怖逃走；瞋恚难以去除，如同守家的狗；慈心容易失去，如同那野鹿。所以这心难以调伏。因为这个道理，不名为大慈。

"再者，善男子，譬如在石上画画，其纹常在；在水上画画，很快就消失，势必不能久住。瞋恚如同画在石上，诸善根本如同画在水上，所以这心难以调伏。如大火堆，其光明久住；电光之明，一刻也不能停留。瞋恚如同火堆，慈心如同电光，所以这心难以调伏。因为这个道理，不名为大慈。

"善男子，菩萨摩诃萨住于初地，名为大慈。为什么呢？善男子，最极恶的人名为一阐提。初住菩萨修大慈时，对一阐提心无差别，不见其过失，所以不生瞋恚。因为这个道理，得名为大慈。

"善男子，为众生除去无利益之事，这名为大慈；想给予众生无量利乐，这名为大悲；对众生心生欢喜，这名为大喜；无所拥护，名为大舍。若不见我、法之相与自身，见一切法平等无二，这名为大舍；自己舍弃自己的安乐，施与他人，这名为大舍。

【按】这里以"除无利益"为大慈、"与无量利乐"为大悲，与一般"慈与乐、悲拔苦"的说法次第相反，照原文译出。

"善男子，唯有四无量能令菩萨增长具足六波罗蜜，其余诸行不一定能这样。善男子，菩萨摩诃萨先得世间的四无量心，然后才发无上正等正觉之心，依次第才得出世间的四无量。善男子，因世间无量，得出世间无量，因为这个道理，名为大无量。"

### 慈是真实，不是虚观

迦叶菩萨对佛说："世尊，除去无利益、给予利乐，实际上并没有做什么；这样思惟，就是虚观，没有实际利益。

"世尊，譬如比丘修不净观时，见所穿的衣服都作皮相，其实不是皮；所吃的食物都作虫相，其实不是虫；观大豆羹作粪汁想，其实不是粪；观所吃的酪犹如脑髓，其实不是脑；观碎骨末犹如炒面，其实不是炒面。四无量心也是这样，不能真实利益众生，令他们得乐，虽然口中说给予众生快乐，实际上众生并没有得到。这样的观，岂不是虚妄吗？

"世尊，若不是虚妄，真实给予了快乐，那么众生为什么不因诸佛菩萨的威德之力而一切都受快乐？若真实不能得乐，那么如佛所说：'我回忆往昔，独自修习慈心，经过此劫世界七次成坏，都不来此世间受生。世界成时，生在梵天中；世界坏时，生在光音天。若生在梵天，力量势用自在，没有能摧伏的，在千梵之中最胜最上，名为大梵王，众生都对我生最上之想。三十六次作忉利天王释提桓因，无量百千次作转轮王。'独修慈心，就得到这样的人天果报。若不是真实的，怎能与这意义相应？"

佛说："善哉，善哉！善男子，你真是勇猛，无所畏惧。"就为迦叶说偈：

```
若于一众生
不生瞋恚心
而愿与彼乐
是名为慈善
一切众生中
若起于悲心
是名圣种性
得福报无量
设使五通仙
悉满此大地
有大自在主
奉施其所安
象马种种物
所得福报果
不及修一慈
十六分中一
```

（大意：若对一个众生不生瞋恚之心，而愿给予他快乐，这名为慈善。若对一切众生生起悲心，这名为圣者种性，所得福报无量。假使具五神通的仙人充满这大地，有大自在的君主奉施他们所需的安乐之物，象马等种种财物，所得的福报，不及修一念慈心的十六分之一。）

"善男子，修慈实在不是妄想，确是真实。若是声闻、缘觉的慈，这名为虚妄；诸佛菩萨的慈，真实不虚。怎么知道呢？善男子，修行这样大涅槃的菩萨摩诃萨，观土为金，观金为土；地作水相，水作地相；水作火相，火作水相；地作风相，风作地相，随意成就，没有虚妄。观真实众生为非众生，观非众生为真实众生，都随意成就，没有虚妄。善男子，应当知道菩萨的四无量心，是真实的思惟，不是不真实的。

"再者，善男子，什么名为真实思惟？就是因为能断除诸烦恼。善男子，修慈能断贪欲，修悲心能断瞋恚，修喜心能断不乐，修舍心能断贪、恚以及众生相。所以名为真实思惟。

### 慈为诸善根本：布施与誓愿

"再者，善男子，菩萨摩诃萨的四无量心，能作为一切善的根本。善男子，菩萨摩诃萨若见不到贫穷众生，就无缘生起慈心；若不生慈心，就不能生起布施之心。以布施的因缘，令诸众生得安稳快乐，即饮食、车乘、衣服、花香、床卧、房舍、灯明。

"这样布施时，心无系缚，不生贪著，必定回向无上正等正觉。那时其心无所依止，妄想永断；不是因为怖畏，不求名称利养，不求人天；对于所受的快乐不生憍慢，不期望回报，不为了欺诳他人而行布施，不求富贵。凡行布施时，不见受施者是持戒还是破戒，是福田还是非福田，这是善知识还是非善知识；布施时不见是法器还是非法器，不选择日子时辰，是处所还是非处所，也不计较饥馑还是丰乐，不见因果，这是众生还是非众生，是福还是非福。虽然不见施者、受者以及财物，乃至不见断绝以及果报，却常行布施，没有断绝。

"善男子，菩萨若见持戒、破戒乃至果报，终究不能布施；若不布施，就不能具足檀波罗蜜；若不具足檀波罗蜜，就不能成就无上正等正觉。

"善男子，譬如有人身中毒箭，他的眷属想令他安稳，为他除毒，就请良医来为他拔箭。那人却说：'且慢，不要碰！我现在应当先观察：这毒箭从什么方向来？是谁射的？是刹利、婆罗门、毗舍，还是首陀？'又想：'这箭杆是什么木？是竹，还是柳？那箭镞的铁是哪个冶炉出的？是刚，还是柔？那箭羽是什么鸟的翅膀？是鸱鹫的吗？所有的毒，是人造的，还是自然有的？是人毒，还是蛇毒？'这样的愚痴之人，最终还未弄清楚，随即就命终了。善男子，菩萨也是这样，若行布施时分别受者是持戒还是破戒，乃至果报，终究不能布施；若不能布施，就不能具足檀波罗蜜；若不具足檀波罗蜜，就不能成就无上正等正觉。

"善男子，菩萨摩诃萨行布施时，对诸众生慈心平等，犹如对儿子之想。又行布施时，对诸众生生起悲悯之心，譬如父母照看生病的孩子。行布施时，其心欢喜，犹如父母见孩子病愈。布施之后，其心放舍，犹如父母见孩子长大，能自己谋生。

#### 施食之愿

"这位菩萨摩诃萨在慈心中布施饮食时，常发这样的愿：'我现在所施的，都与一切众生共享。以这因缘，令诸众生得大智慧之食，勤奋精进，回向无上大乘。愿诸众生得善智之食，不求声闻、缘觉之食。愿诸众生得法喜之食，不求爱欲之食。愿诸众生都得般若波罗蜜之食，都令充满，摄取无碍增上的善根。愿诸众生悟解空相，得无碍之身，犹如虚空。愿诸众生常作受施者，怜悯一切，为众生的福田。'善男子，菩萨摩诃萨修慈心时，凡所布施饮食，都应当坚定发起这样的愿。

#### 施浆之愿

"再者，善男子，菩萨摩诃萨在慈心中布施饮浆时，应当发这样的愿：'我现在所施的，都与一切众生共享。以这因缘，令诸众生趣入大乘之河，饮八功德水，迅速走上无上菩提之道，离开声闻、缘觉的枯竭，渴仰志求无上佛乘，断除烦恼之渴，渴仰法味，离开生死之爱，爱乐大乘大般涅槃，具足法身，得诸三昧，入于甚深智慧大海。愿诸众生得甘露味、菩提味、出世味、离欲味、寂静味，这样种种滋味。愿诸众生具足无量百千法味，具足法味之后，得见佛性；见佛性之后，能降法雨；降法雨之后，佛性遍覆，犹如虚空。又令其余无量众生得一种法味，即大乘，不是声闻、辟支佛之味。愿诸众生得一种甜味，没有六种差别之味。愿诸众生唯求法味、无碍佛法所行之味，不求其余的滋味。'善男子，菩萨摩诃萨在慈心中布施饮浆时，应当坚定发起这样的愿。

#### 施车乘之愿

"再者，善男子，菩萨摩诃萨在慈心中布施车乘时，应当发这样的愿：'我现在所施的，都与一切众生共享。以这因缘，普令众生成就大乘，得住大乘，不退之乘，不动转之乘，金刚座之乘；不求声闻、辟支佛乘，趣向佛乘，无能降伏之乘，无羸乏之乘，不退没之乘，无上之乘，十力之乘，大功德之乘，未曾有之乘，稀有之乘，难得之乘，无边之乘，知一切之乘。'善男子，菩萨摩诃萨在慈心中布施车乘时，常应这样坚定发起誓愿。

#### 施衣之愿

"再者，善男子，菩萨摩诃萨在慈心中布施衣服时，应当发这样的愿：'我现在所施的，都与一切众生共享。以这因缘，令诸众生得惭愧之衣，以法界覆身，撕裂诸见之衣。衣服离身一尺六寸，得金色之身，所受诸触柔软无碍，光色润泽，皮肤细软，常有光明，无量无色，离于色相。愿诸众生都普遍得到无色之身，超过一切色，得入无色的大般涅槃。'善男子，菩萨摩诃萨布施衣服时，应当这样坚定发起誓愿。

#### 施花香之愿

"再者，善男子，菩萨摩诃萨在修慈之中，布施花、香、涂香、末香及各种杂香时，应当发这样的愿：'我现在所施的，都与一切众生共享。以这因缘，令诸众生一切都得佛花三昧，以七觉分的妙鬘系在头顶。愿诸众生形如满月，所见诸色微妙第一。愿诸众生都成就一相，百福庄严。愿诸众生随意得见可意之色。愿诸众生常遇善友，得无碍之香，离开诸臭秽。愿诸众生具足诸善根这无上珍宝。愿诸众生相视和悦，没有忧苦，众善各自具备，不互相忧念。愿诸众生戒香具足。愿诸众生持无碍之戒，香气芬馥，充满十方。愿诸众生得坚牢之戒、无悔之戒、一切智之戒，离开诸破戒，都得无戒之戒、未曾有之戒、无师之戒、无作之戒、无秽之戒、无污染之戒、究竟圆满之戒、究竟之戒，得平等之戒，对于以香涂身和以刀斫刺，平等而无憎爱。愿诸众生得无上之戒、大乘之戒，不是小乘之戒。愿诸众生都得具足尸波罗蜜，犹如诸佛所成就的戒。愿诸众生都被布施、持戒、忍辱、精进、禅定、智慧所熏修。愿诸众生都得成就大般涅槃微妙莲花，其花香气充满十方。愿诸众生纯食大乘大般涅槃无上的香馔，犹如蜜蜂采花，只取香味。愿诸众生都得成就无量功德所熏之身。'善男子，菩萨摩诃萨在慈心中布施花香时，常当坚定发起这样的誓愿。

【按】"无戒""竟已戒"：无戒，指超出有相持守、无所执持的戒；竟已戒，指已究竟圆满的戒。原文一连串戒名，照列译出。

#### 施床座之愿

"再者，善男子，菩萨摩诃萨在慈心中布施床座卧具时，应当发这样的愿：'我现在所施的，都与一切众生共享。以这因缘，令诸众生得天中天所卧之床，得大智慧，坐于四禅之处，卧于菩萨所卧之床，不卧声闻、辟支佛之床，离开卧于恶床。愿诸众生得安乐之卧，离开生死之床，成就大涅槃的师子卧床。愿诸众生坐此床之后，又为其余无量众生示现神通，作师子游戏。愿诸众生住在这大乘大宫殿中，为诸众生演说佛性。愿诸众生坐于无上之床，不被世间法所降伏。愿诸众生得忍辱之床，离开生死、饥馑、冻饿。愿诸众生得无畏之床，永离一切烦恼怨贼。愿诸众生得清净之床，专求无上正真之道。愿诸众生得善法之床，常被善友所拥护。愿诸众生得右胁而卧之床，依循诸佛所行之法。'善男子，菩萨摩诃萨在慈心中布施床座时，应当坚定发起这样的誓愿。

#### 施舍宅之愿

"再者，善男子，菩萨摩诃萨在慈心中布施房舍时，应当发这样的愿：'我现在所施的，都与一切众生共享。以这因缘，令诸众生安处于大乘之舍，修行善友所行之行，修大悲行、六波罗蜜行、大正觉行、一切菩萨所行的道行，无边广大如虚空之行。愿诸众生都得正念，远离恶念。愿诸众生都得安住于常乐我净，永离四种颠倒。愿诸众生都受持出世间的文字。愿诸众生必定成为无上一切智的法器。愿诸众生都得入于甘露的屋宅。愿诸众生在初心、中心、后心，常入大乘涅槃的屋宅。愿诸众生在未来世，常处于菩萨所居的宫殿。'善男子，菩萨摩诃萨在慈心中布施房舍时，常当坚定发起这样的誓愿。

#### 施灯明之愿

"再者，善男子，菩萨摩诃萨在慈心中布施灯明时，应当发这样的愿：'我现在所施的，都与一切众生共享。以这因缘，令诸众生光明无量，安住于佛法。愿诸众生常得照明。愿诸众生得微妙之色，光泽第一。愿诸众生其眼清净，没有翳障。愿诸众生得大智慧之炬，善解无我、无众生相、无人、无寿命。愿诸众生都得看见清净佛性，犹如虚空。愿诸众生肉眼清净，彻见十方恒河沙数世界。愿诸众生得佛的光明，普照十方。愿诸众生得无碍之眼，都得看见清净佛性。愿诸众生得大智慧之明，破除一切黑暗以及一阐提。愿诸众生得无量光明，普照无量诸佛世界。愿诸众生点燃大乘之灯，离开二乘之灯。愿诸众生所得的光明，灭除无明黑暗，超过千日并照之功。愿诸众生得大光明，灭尽三千大千世界所有的黑暗。愿诸众生具足五眼，悟解诸法实相，成就无师之觉。愿诸众生无所见、无无明。愿诸众生都得大乘大般涅槃的微妙光明，开示众生真实的佛性。'善男子，菩萨摩诃萨在慈心中布施灯明时，常应勤发这样的誓愿。

【按】"愿诸众生得大光明，悉灭三千大千世界所有黑暗"，北本作"得火珠明"。

### 慈即如来

"善男子，一切声闻、缘觉、菩萨、诸佛如来所有的善根，都以慈为根本。善男子，菩萨摩诃萨修习慈心，能生出这样无量的善根，即不净观、出息入息观、无常生灭观，四念处、七方便、三观处、十二因缘观、无我等观，暖法、顶法、忍法、世第一法，见道、修道，正勤、如意足、诸根、诸力、七菩提分、八圣道，四禅、四无量心，八解脱、八胜处、十一切入，空、无相、无愿，无诤三昧、知他心智以及诸神通、知本际智，声闻智、缘觉智、菩萨智、佛智。善男子，这样的诸法，都以慈为根本。善男子，因为这个道理，慈是真实的，不是虚妄的。若有人问：'什么是一切诸善的根本？'应当说：'是慈。'因为这个道理，慈是真实的，不是虚妄的。

"善男子，能行善的，名为真实思惟；真实思惟，就名为慈。慈就是如来。慈就是大乘，大乘就是慈，慈就是如来。善男子，慈就是菩提道，菩提道就是如来，如来就是慈。善男子，慈就是大梵，大梵就是慈，慈就是如来。善男子，慈能为一切众生作父母，父母就是慈，慈就是如来。

"善男子，慈是不可思议的诸佛境界，不可思议的诸佛境界就是慈，应当知道慈就是如来。善男子，慈就是众生的佛性。这样的佛性，长久被烦恼所覆蔽，所以令众生不能看见。佛性就是慈，慈就是如来。

"善男子，慈就是大空，大空就是慈，慈就是如来。善男子，慈就是虚空，虚空就是慈，慈就是如来。

"善男子，慈就是常，常就是法，法就是僧，僧就是慈，慈就是如来。善男子，慈就是乐，乐就是法，法就是僧，僧就是慈，慈就是如来。善男子，慈就是净，净就是法，法就是僧，僧就是慈，慈就是如来。善男子，慈就是我，我就是法，法就是僧，僧就是慈，慈就是如来。

"善男子，慈就是甘露，甘露就是慈，慈就是佛性，佛性就是法，法就是僧，僧就是慈，慈就是如来。善男子，慈就是一切菩萨的无上之道，道就是慈，慈就是如来。善男子，慈就是诸佛世尊的无量境界，无量境界就是慈，应当知道这慈就是如来。

### 声闻之慈

"善男子，慈若是无常，无常就是慈，应当知道这慈是声闻之慈。善男子，慈若是苦，苦就是慈，应当知道这慈是声闻之慈。善男子，慈若是不净，不净就是慈，应当知道这慈是声闻之慈。善男子，慈若是无我，无我就是慈，应当知道这慈是声闻之慈。善男子，慈若是妄想，妄想就是慈，应当知道这慈是声闻之慈。

"善男子，慈若不名为檀波罗蜜，是非檀之慈，应当知道这慈是声闻之慈，乃至般若波罗蜜也是如此。善男子，慈若不能利益众生，这样的慈是声闻之慈。善男子，慈若不入一相之道，应当知道这慈是声闻之慈。善男子，慈若不能觉了诸法，应当知道这慈是声闻之慈。善男子，慈若不能见如来性，应当知道这慈是声闻之慈。善男子，慈若见诸法都是有相，应当知道这慈是声闻之慈。

"善男子，慈若是有漏，有漏之慈是声闻之慈。善男子，慈若是有为，有为之慈是声闻之慈。善男子，慈若不能住于初住，是非初住之慈，应当知道这就是声闻之慈。善男子，慈若不能得佛的十力、四无所畏，应当知道这慈是声闻之慈。善男子，慈若能得四沙门果，应当知道这慈是声闻之慈。

"善男子，慈若是有、是无、是非有非无，这样的慈不是诸声闻、辟支佛等所能思议的。善男子，慈若不可思议，法就不可思议，佛性就不可思议，如来也不可思议。

### 修慈的功德

"善男子，菩萨摩诃萨安住于大乘大般涅槃，修这样的慈，虽然安于睡眠之中，却不睡眠，因为勤修精进；虽然常觉醒，也无所谓觉醒，因为没有睡眠。在睡眠中，诸天虽然守护，也无所谓守护者，因为不行恶事。睡眠时不作恶梦，没有不善，因为离开了睡眠。命终之后虽然生于梵天，也无所生，因为得自在。

"善男子，修慈的人能成就这样无量无边的功德。善男子，这部大涅槃微妙经典也能成就这样无量无边的功德，诸佛如来也得成就这样无量无边的功德。"

### 慈心真实利益众生

迦叶菩萨对佛说："世尊，菩萨摩诃萨所有的思惟都是真实的，声闻、缘觉的不是真实的。那么一切众生为什么不因菩萨的威力而平等地受快乐？若诸众生实在不能得乐，应当知道菩萨所修的慈心是没有利益的。"

佛说："善男子，菩萨的慈不是没有利益。善男子，有的众生必定受苦，有的不必定受苦。若有众生必定受苦，菩萨的慈对他就没有利益，即一阐提。若有众生受苦并非必定，菩萨的慈对他就有利益，令那些众生都受快乐。

"善男子，譬如有人远远看见狮子、虎豹、豺狼、罗刹鬼等，自然生起恐怖；夜行时看见树桩，也生起怖畏。善男子，这些人自然生起怖畏；众生也是这样，见到修慈的人，自然受到快乐。善男子，因为这个道理，菩萨修慈是真实的思惟，不是没有利益。

### 慈善根力的种种示现

"善男子，我说这慈有无量法门，即神通。

#### 降伏醉象

"善男子，如提婆达多教唆阿阇世王想谋害如来。那时我进入王舍大城，挨家次第乞食。阿阇世王就放出名叫护财的狂醉大象，想让它伤害我和诸弟子。那象当时踩死了无量百千众生，众生死后，血腥之气很重，那象闻了，狂醉比平常更甚；见到随从我的弟子们穿着赤色袈裟，以为那是血，就又冲向我的弟子之中。未离欲的弟子都惊怖四散奔逃，唯有阿难没有走。

"那时王舍大城中的一切人民同时放声啼哭号泣，说：'怪哉！如来今天要灭没了！为何正觉一下子就散坏了！'这时调达心生欢喜：'瞿昙沙门灭没了，太好了！从今以后，他真的不会再出现了。痛快啊，这计策，我的心愿得遂了！'

"善男子，我那时为了降伏护财象，就入于慈定，伸出手给它看，就从五指中现出五头狮子。那象见了，心中怖畏，随即失禁，全身伏地，敬礼我的双足。善男子，我那时手的五个指头实在没有狮子，乃是修慈的善根之力，令它调伏。

#### 力士移石

"再者，善男子，我将要涅槃，刚开始动身前往拘尸那城时，有五百力士在途中平整道路，洒扫清理。其中有一块大石，众人想抬起扔掉，用尽力气也不能。我当时怜悯他们，就起了慈心。那些力士随即看见我用脚的大拇趾举起这块大石，抛向虚空，又用手接住，放在右掌上，一吹令它粉碎成末，又再聚合，令那些力士贡高之心止息。我就为他们略说种种法要，令他们都发无上正等正觉之心。善男子，如来那时实在没有用脚趾举起这块大石到虚空中，又放在右掌上，吹令粉碎，再复合如初。善男子，应当知道这就是慈的善根之力，令诸力士见到这样的事。

#### 首波罗城卢至长者

"再者，善男子，这南天竺有一座大城，名叫首波罗。城中有一位长者，名叫卢至，是众人的导首，已在过去无量佛所种下诸善根本。善男子，那大城中一切人民都信奉邪道，侍奉尼犍外道。我那时为了度那位长者，从王舍城前往那城邑，中间相距六十五由旬，徒步而行，是为了化度那些人。

"那些尼犍听说我要到首波罗城来，就想：'沙门瞿昙若到这里，这些人民就会舍弃我们，不再供养，我们穷困憔悴，怎么活下去？'众尼犍就各自分散，告诉那城里的人：'沙门瞿昙现在要到这里来了。那沙门抛弃父母，东奔西走，所到之处，能令土地谷米歉收，人民饥馑，死亡的很多，疾病瘦弱相继，无法救解。瞿昙无赖，专门带着诸恶罗刹鬼神作为侍从；无父无母、孤苦穷困的人来请教他，作他的门徒。他所教导的，全说虚空。凡他所到之处，从来没有安乐。'

"那些人听了，就心怀怖畏，头面敬礼尼犍子的脚，说：'大师，我们现在该设什么计策？'尼犍回答说：'沙门瞿昙生性喜欢丛林、流泉、清水，城外若有这些，应当破坏。你们可以一起出城，凡有树林的地方，都砍伐干净，不要留下；流泉、井池，都放入粪便尸体；紧闭城门，各自备好兵器，在城墙上防守，勤加固守。他若来了，不要让他上前。若他不能上前，你们就安稳了。我们也当作种种法术，令那瞿昙原路返回。'那些人民听了这话，恭敬应诺，照着施行：砍伐树木，污染诸水，备好兵器，牢牢防守。

"善男子，我那时到了那城，不见一切树木丛林，只见众人备好兵器，在城墙上自守。见了这情景，随即生起怜悯，以慈心对待他们。所有的树木就恢复如初，又另外生长出不可计数的其余树木；河池泉井，其水清净盈满，如青琉璃，生出各种杂花，遍覆其上；城墙变成绀琉璃，城内人民都能透彻看见我和大众；城门自己打开，没有人能阻止；所备的兵器变成各种杂花。卢至长者为首，与那里的人民一同前来佛所。我就为他们说种种法要，令那些人都发无上正等正觉之心。

"善男子，我那时实在没有化作种种树木、清净流水盈满河池、把本城变为绀琉璃、令那些人民透彻看见我、打开城门、把兵器变为花。善男子，应当知道这都是慈的善根之力，能令那些人见到这样的事。

#### 婆私吒失子

"再者，善男子，舍卫城中有一位婆罗门女，姓婆私吒，只有一个儿子，爱之甚深，因病命终。那时这女人忧愁悲痛入心，狂乱失去本性，裸身而不知羞耻，游走在四通八达的街道上，啼哭失声，喊着：'儿啊，儿啊，你到哪里去了？'走遍城邑，不知疲倦。而这女人已在先佛那里种下众多德本。

"善男子，我对这女人生起慈悯之心。这时女人就见到了我，便生起是自己儿子之想，恢复了本心，上前抱住我的身体，如同爱抚儿子一样。我当时就告诉侍者阿难：'你拿衣服给这女人。'给了衣服之后，就为她说种种法要。这女人听法，欢喜踊跃，发无上正等正觉之心。善男子，我那时实在不是她的儿子，她也不是我的母亲，也没有抱持。善男子，应当知道这都是慈的善根之力，令那女人见到这样的事。

#### 摩诃斯那达多割肉

"再者，善男子，波罗奈城有一位优婆夷，名叫摩诃斯那达多，已在过去无量先佛那里种下诸善根。这位优婆夷在夏安居九十天中，请僧众，奉施医药。这时众中有一位比丘身患重病，良医诊断说须用肉作药，若得到肉，病就可以除去；若得不到肉，性命将难以保全。

"当时优婆夷听了医生这话，随即拿着黄金走遍市集，唱道：'谁有肉卖？我用金子买。若有肉的，我付同等重量的金子。'找遍城市，求而不得。这位优婆夷随即亲自拿刀割下自己大腿上的肉，切好作成肉羹，加入种种香料，送给生病的比丘。比丘服了，病就痊愈了。

"这位优婆夷却因伤口苦恼，不能忍受，就出声念道：'南无佛陀，南无佛陀。'我那时在舍卫城，听到她的声音，对这女人生起大慈之心。这女人随即见到我拿着良药涂在她的伤口上，伤口愈合如初。我就为她说种种法，她听法欢喜，发无上正等正觉之心。善男子，我那时实在没有前往波罗奈城，拿药涂这位优婆夷的伤口。善男子，应当知道这都是慈的善根之力，令那女人见到这样的事。

#### 调达头痛腹胀

"再者，善男子，调达这恶人贪而不知足，因为多服酥，头痛腹胀，受大苦恼，不能忍受，就说：'南无佛陀，南无佛陀。'我那时住在优禅尼城，听到他的声音，就生起慈心。那时调达随即见到我前往他那里，用手抚摩他的头和腹部，给他盐汤让他服下，服后就平复了。善男子，我实在没有前往调婆达那里，抚摩他的头腹，给他汤服。善男子，应当知道这都是慈的善根之力，令调婆达见到这样的事。

#### 五百群贼复明

"再者，善男子，憍萨罗国有一群盗贼，数目五百，成群结党抢劫，为害越来越严重。波斯匿王忧患他们的横暴，派兵伺机搜捕，捕到之后，挖去他们的眼睛，就扔在黑暗的丛林之下。这些盗贼已在先佛那里种下众多德本。失去眼睛之后，受大苦恼，各自说：'南无佛陀，南无佛陀，我们现在没有救护。'啼哭号啕。

"我那时住在祇洹精舍，听到他们的声音，就生起慈心。当时有凉风吹来香山中的种种香药，充满他们的眼眶，随即恢复了眼睛，与原来无异。众贼睁开眼睛，就见到如来站在他们面前，为他们说法。盗贼听法之后，发无上正等正觉之心。善男子，我那时实在没有作风吹来香山中的种种香药，也没有站在他们面前为他们说法。善男子，应当知道这都是慈的善根之力，令那群盗贼见到这样的事。

#### 释种诸女

"再者，善男子，琉璃太子因为愚痴，废黜他的父王，自立为君主，又记起旧日的嫌怨，大量杀害释迦族人，抓了一万二千名释种女子，割去耳朵鼻子，截断手足，推入坑沟之中。那时诸女身受苦恼，说：'南无佛陀，南无佛陀，我们现在没有救护。'又大声号啕。这些女子已在先佛那里种下诸善根。

"我那时在竹林中，听到她们的声音，就起了慈心。诸女那时见到我来到迦毗罗城，用水洗她们的伤口，敷上药，痛苦随即消除，耳鼻手足恢复如初。我当时就为她们略说法要，令她们都发无上正等正觉之心，随即在大爱道比丘尼那里出家，受具足戒。善男子，如来那时实在没有前往迦毗罗城，用水洗伤口，敷药止痛。善男子，应当知道这都是慈的善根之力，令那些女子得到这样的事。

"悲心、喜心也是这样。善男子，因为这个道理，菩萨摩诃萨修慈的思惟，就是真实的，不是虚妄的。

"善男子，所谓无量，不可思议；菩萨所行，不可思议；诸佛所行，也不可思议；这部大乘经典《大涅槃经》，也不可思议。"
