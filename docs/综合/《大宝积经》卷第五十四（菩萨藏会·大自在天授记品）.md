# 《大宝积经》卷第五十四（菩萨藏会·大自在天授记品）

唐·三藏法师玄奘 奉诏译

## 菩萨藏会第十二之二十

【按】译者题署“奉诏”二字，元本无。

### 大自在天授记品第十二

#### 大蕴如来为精进行童子说四摄法

那时，佛告诉舍利子：“往昔过去的大蕴如来、应、正等觉，为精进行童子广说这样的四无量法以及六波罗蜜多之后，那时那尊佛又告诉精进行童子：‘菩萨摩诃萨怎样随摄法而转？童子应当知道，菩萨摩诃萨具足如来的四摄之法，由于这法，菩萨摩诃萨恒常在长夜中摄受众生。是哪四种？就是布施、爱语、利行、同事，这样名为四种摄法。童子！什么名为这样的摄法？童子！所说的施有两种：一是财施，二是法施，这是布施。所说的爱语，就是对一切前来求乞或乐于闻法的人，菩萨都能以爱语慰喻。所说的利行，就是能满足自己或他人所有的意乐。所说的同事，就是随自己所有的智慧与功德，为他人演说，摄受建立一切众生，令他们安住于智或法。再者，童子！所说的布施，是对前来乞求的众生心意清净；所说的爱语，是对前来乞求的众生善言安慰；所说的利行，是随众生所有的义利都令其成熟；所说的同事，是对前来乞求的众生行平等之心，成就其义利。再者，童子！所说的布施，是诸菩萨发意行舍；所说的爱语，是方便不断；所说的利行，是深心无悔；所说的同事，是回向大乘。再者，童子！所说的布施，是随慈心而行舍；所说的爱语，是常不舍离欢喜之心；所说的利行，是成就大悲，心中恒常欣乐利益众生之事；所说的同事，是修舍平等，没有高下，心中恒常回向一切智智。再者，童子！所说的布施，是如法求财，常思行舍，拯济贫乏；所说的爱语，是施财之后，又加以安置，令其安住于法义；所说的利行，是自利利他平等摄取；所说的同事，是为了利益众生，究竟发起一切智之心。再者，童子！所说的布施，是一切所有内外诸法都全部舍离；所说的爱语，是对一切法的功德智慧无所秘惜；所说的利行，是弃舍自利，专务利他；所说的同事，是总摄财物如同置于掌中，随缘惠施，心无忧戚。

【按】“如来四摄”之“来”，元、明本作“是”。“欢喜之心”之“欢”，《大正藏》作“叹”，今依CBETA作“欢”。“拯济”之“拯”，宋、宫本作“振”。“平等摄取”之“取”，《大正藏》作“受”，今依CBETA所录高丽藏、碛砂藏作“取”。

“‘再者，童子！所说的法施，是如所听闻的法广为他人宣说；所说的爱语，是以无染之心分别开示；所说的利行，是为他人传授诵读经典，乃至说法而无厌倦；所说的同事，是以不舍离一切智之心，将众生安置于正法之中。再者，童子！所说的法施，是若为往返求听法的人，依佛的正教不乱地宣说；所说的爱语，是以微妙的音声开示正法；所说的利行，是以衣服、饮食、床座、医药以及其余随用的什物众具，对求法者以及说法者，只要有匮乏，便即给施；所说的同事，是常起深心，无间断地说法。再者，童子！所说的法施，是由于这菩萨了知法施是诸施中最上，所以常行法施；所说的爱语，是所演说的利益之事；所说的利行，是演畅其义而不依于文；所说的同事，是想令一切佛法圆满，常为众生如其所应敷演教化。再者，童子！所说的布施，就是柁那波罗蜜多；所说的爱语，就是尸罗波罗蜜多以及羼底波罗蜜多；所说的利行，就是毘利耶波罗蜜多；所说的同事，就是静虑波罗蜜多以及般若波罗蜜多。再者，童子！所说的布施，是指初发心的一切菩萨；所说的爱语，是指已发行的一切菩萨；所说的利行，是指不退转的一切菩萨；所说的同事，是指系属一生的诸大菩萨。再者，童子！所说的布施，是为了坚固菩提的根本；所说的爱语，是为了成就菩提的萌芽；所说的利行，是为了开发菩提的妙花；所说的同事，是为了成熟菩提的胜果。像这样，童子！这名为菩萨摩诃萨的四种摄法。菩萨摩诃萨为了修行大菩提，以这样等等的四摄之法，在长夜中摄受众生，这名为菩萨摩诃萨随摄法而转。童子！这样的摄法无量无边，都说名为菩提之道。’

【按】“柁那”之“柁”，明本作“檀”。“言布施者，为欲坚固”之“施”，《大正藏》作“于”，今依CBETA作“施”。

#### 精进行童子与善慧长者未蒙授记

“舍利子！那时薄伽梵大蕴如来、应、正等觉为这精进行童子开示这样的大菩提道，那时那童子在佛处听闻这法之后，又听到赞说过去、未来、现在诸佛，得大欢喜，便以上妙的衣服、肴膳饮食、床座、医药、什物众具，奉献给大蕴如来以及声闻众。这样经过九十六拘胝岁，供养、恭敬、尊重、赞叹，又兴起菩提大愿。虽然作了这样无量的功德，而大蕴如来并未给童子授阿耨多罗三藐三菩提之记。舍利子！你以为那时的精进行童子是别人吗？不要作别的怀疑，就是我自身。我在那尊佛处，以种种供养奉献佛及僧经过那么多年，又发起大菩提愿，然而那位如来不为我授记说：‘你在来世当得作佛，号为释迦牟尼如来、应、正等觉。’

【按】“肴饍”之“饍”，元、明本作“膳”。“兴菩提大愿”之“兴”，元、明本作“兴发”。“尔所岁，又”，宫本作“尔所广大”。“起发”，宋、元、明、宫本作“发起”。“正等觉”，元、明本作“等正觉”。

“舍利子！从大蕴如来灭度之后，经过阿僧企耶劫，那时有佛出兴于世，名为宝性如来、应、正等觉、明行圆满、善逝、世间解、无上丈夫、调御士、天人师、佛、薄伽梵。舍利子！宝性如来有八十那庾多声闻弟子共同集会说法，都是大阿罗汉，诸漏已尽，不再有烦恼，乃至其心自在，证得第一波罗蜜。那时世间有一位转轮圣王，名为善见，七宝应现，就是成就金轮乃至主将兵宝。这善见王以其轮宝威服四天下，以正法治世，名为法王，以仁德养育万物，为众人所欣慕敬重，国界人民居住宽广。所治理的大城名为圆满，东西长十二逾缮那，南北宽七逾缮那，安隐丰乐，人民炽盛，甚为可爱，多有财宝，资具充溢。那时城中有一位大长者名为善慧，其家巨富，财宝充积，曾供养过去诸佛，种下众多德本。舍利子！那时薄伽梵宝性如来观察这长者的深心欲解，这样思惟：‘这位大长者善根已熟，堪为这样的大菩萨藏法门之器，又是诸佛正法之器。’了知之后，便前往他那里，示现大神变，在上方虚空中结跏趺坐，为那长者开示菩提之道，又赞说过去、未来、现在诸佛。舍利子！那时善慧听闻佛开示大菩萨道，又听闻赞说三世诸佛之后，获得广大的欢喜净信，便以上妙的衣服、肴膳饮食以及其余资具，奉献给宝性如来以及弟子众，经过一千年，供养、恭敬、尊重、赞叹，又兴起阿耨多罗三藐三菩提的微妙大愿。虽然这样广发众行，然而那位如来并未为他授记。舍利子！你以为那时的善慧长者是别人吗？不要有别的怀疑，就是我自身。我那时虽然以种种供养奉献佛及僧，并发起广大的菩提胜愿，然而那位如来不为我授记，说我在来世当得作佛，号为释迦牟尼如来、应、正等觉。

#### 放光如来出世

“舍利子！自宝性如来灭度之后，经过阿僧企耶劫，有佛出世，名为放光如来、应、正等觉、明行圆满、善逝、世间解、无上丈夫、调御士、天人师、佛、薄伽梵。舍利子！因为什么缘故此佛名为放光？舍利子！在那时有一位国王出世，名为胜怨，所都的大城名为盛莲花，安隐丰乐，人民炽盛，财宝众具充积流溢。国王有一位婆罗门种姓的大臣，名为光主，其家巨富，财产仓库具足盈满。这位大臣为胜怨王所偏爱看重，欣慕其德，常受礼遇，王心无厌逆。舍利子！那时胜怨王割出所统治国土的四分之一，赐给这位大臣，封他为王。那时光主王治理小国，以法治世，不行邪枉。舍利子！这光主王后来诞生太子，形貌端正，众人乐于观看，成就第一圆满的净色，以三十二大丈夫相具足庄严。又王子的全身都放出光明，犹如日轮所照耀，因此为他立名为放光。舍利子！那时光主王召集国中善于占相的诸婆罗门，都集合之后，便把王子给他们看，令他们为王子看相。诸婆罗门看过相之后，便这样说：‘现在这位王子必定当作佛。’那时光主王便把王子交给诸位养母。其后不久，王子身相长大，聪睿明达。那时住在色究竟天宫的净居天，以通智之力知道这位王子将登正觉，便从那里隐没，来到放光王子菩萨的住处，到了之后，右绕菩萨，就在他面前说颂道：

【按】“邪抂”之“抂”，宋、元、明、宫本作“枉”。“照耀”之“耀”，元、明本作“曜”。

```
非谓安处大王宫，
能生清净胜功德；
要假仙幢袈裟相，
果证无上妙菩提。
盛壮须臾若流逝，
迅速过于大猛风，
不可憙乐弊衰老，
摧坏世间之所爱。
衰老能令薄势力，
难得欣乐趣非家，
大仙今者极盛年，
宜当及时发精进。
善哉善哉大慧者，
善哉善哉大超悟，
善哉善哉速出家，
定成坚固正等觉。
```
（大意：“并不是安处于大王宫中，就能生起清净殊胜的功德；一定要借助仙人之幢、袈裟之相，才能证得无上妙菩提。盛壮之年须臾之间就像流水逝去，迅速超过大猛风；不可喜乐的弊恶衰老，摧坏世间所爱之物。衰老能令势力衰薄，难以欣乐地趣向非家；大仙现在正当极盛之年，应当及时发起精进。善哉善哉，大智慧者！善哉善哉，大超悟者！善哉善哉，迅速出家，必定成就坚固的正等觉。”）

“舍利子！那时放光菩萨摩诃萨被净居天开悟之后，以清净信心趣向非家；在出家的当夜，便成就阿耨多罗三藐三菩提。那时那位世尊便以这样广大的名称出现于世间，号为放光如来，十号具足，为诸天人所赞颂。那时胜怨王听说光主王的王子出家修行，证得无上正等菩提，名为放光，便前去告诉光主王说：‘我听说你的儿子出家成佛，不知世尊以大慈悲能否降临？若不垂愍来到这里，我当严备四种兵力之军，前往如来之所，亲自奉事礼敬。’舍利子！那时光主王便召集大臣、守卫、军众，详细宣说这事。诸大臣说：‘大王现在应当亲自前往放光如来那里咨问这事：大悲世尊怜悯众生，是否要前往那胜怨王处？还是不前往？’那时光主王便严驾车乘，与诸大臣侍卫导从，前往如来之所。到了那里之后，顶礼佛足，便把上述之事详细禀告世尊。那时放光如来告诉父王说：‘大王应当知道，我现在要前往胜怨王处，因为怜悯众生。’舍利子！那时放光如来随其所乐，别住于胜怨王都一处，便与二十拘胝大阿罗汉出发前往那国。那时父王也备四种强力军众跟随在佛后面，备办种种上妙的衣服、肴膳饮食、床座、医药以及其余资具，供养佛及僧，乃至跟随如来到自己王国领土的边界，便礼佛足，绕无数匝，涕泣哽咽，告辞而回。

【按】“王于今者”之“王”，宋、宫本作“天”。“到己王领”之“己”，《大正藏》作“已”，今依CBETA作“己”。

原文：“时放光如来随所乐欲别住一处胜怨王都，即与二十拘胝大阿罗汉出诣彼国”（大意：那时放光如来随其所乐，别住于胜怨王都一处，便与二十拘胝大阿罗汉出发前往那国。“别住一处”句意未详，存疑。）

#### 胜怨王庄严王都供佛

“那时胜怨王听说放光如来与诸大众将要来到这盛莲花城，便庄严装饰所都的大城，除去一切沙砾瓦石，令街巷道路清净平坦，扫洒修治，极为华丽；又以香水再加洒地，散布名花，厚可及膝，以妙香瓶排列薰香于道路，铺设种种微妙宝衣，在上方虚空中张挂幡盖，奏起伎乐，繁盛充满。舍利子！那时胜怨王这样庄严装饰盛莲花城大王都之后，又下严令，击鼓宣告：在这王都城的内外，所有的花鬘以及涂香等，不得有人擅自受用或拿去出卖，一切都应当奉献供养放光如来；若违反此令，当加重罚。舍利子！那时胜怨王携带种种花鬘、涂香、末香、珍妙衣服、幢幡宝盖，击奏种种美妙音乐，又设仪仗，现出盛大的严备，以国王的威势出所都之城，为了瞻仰那位如来，并行礼拜，陈设种种供养，与四种军以及王城内所有的婆罗门、长者、居士、豪族之类等前往佛所。到了那里之后，胜怨王最先顶礼那位如来之足，又以种种花鬘、涂香、末香、上妙衣服、幢幡宝盖供养如来。自己供养之后，又令王子、大臣以及诸侍卫、婆罗门、长者、居士等也如大王一样广修供养。舍利子！那时胜怨王供养之后，具足欢喜之心、具足妙善之心、具足离盖之心、具足适悦之心，与群臣跟随在佛的后面。

【按】“华丽”，元、明、宫本作“庄严”。“霑洒”之“霑”，宋、宫本作“沾”。“列薰”之“薰”，宋、元、明、宫本作“重”。“四种军”之“种”，明本作“众”。

#### 迷伽儒童

“舍利子！那时有一位婆罗门名为珍宝，住在大雪山王旁边，以五百儒童为弟子，为众人所尊崇，名德远播，善持艺术，对三毘陀经已到达彼岸，又对尼揵荼书以及计罗婆论、分别字论、伊底诃婆论、五分记论、随顺世论、祠祀咒论、丈夫相论，这些论都善能通达，以及自宗师傅的三明大教，通晓其理趣，深知其开许与遮止。舍利子！这婆罗门有一位近住的儒童弟子，名为迷伽，受学于珍宝，完全通达其深旨，艺术经论都明了通达，智慧与老师相等，堪为导首。那时迷伽对老师说：‘大师应当知道，所学的经论都已通达，我现在应当返回自己的出生地。怎样奉酬大师的恩德？’那时老师告诉他说：‘伐瑳迷伽！作为弟子想报答师恩，应当以财宝表达深厚的心意。是什么呢？若能备办五百羯利沙钵那，就足以表达深心。’舍利子！那时迷伽儒童奉了老师的教示，致敬右绕，告辞而行，遍游村落、城市、亭馆、国邑、王都，处处寻觅酬谢老师的财宝。凑齐之后，将要陈献报答，渐渐来到盛莲花城，远远看见王都种种严饰，明丽华美，甚为可爱，便问旁人：‘现在这王都有什么盛事，荣饰周遍，庄严如此？’旁人回答说：‘你不知道吗？今天放光如来、应、正等觉与八十拘胝大阿罗汉、八万四千诸大菩萨将要进入此城，城中人民将行大布施，将兴大福德。由于这事，所以如此庄严。’那时迷伽儒童忽然听到这样的佛名之声，获得广大的欢喜净信，暗自思忖：‘诸佛如来出世甚难，极难值遇，超过优昙花，又像盲龟难遇浮木之孔，百千大劫中有时才遇到一次。我现在得以奉见，甚为稀有，必定应当用这五百羯利沙钵那买花散奉放光如来，再另外求财来酬谢老师的恩德。’

#### 放光如来授记

“舍利子！那时放光如来、应、正等觉具足遍照之眼以及遍照之智，对三世中没有一事不通达，知道那迷伽的意欲与胜解之后，便举起足趾踏在他的头发上，随即向右回顾，如龙象回身，告诉诸声闻一切大众：‘你们诸苾刍不要踩他的头发。为什么？这位儒童在此后经过阿僧企耶劫，当成如来、应、正等觉，号为释迦牟尼。’舍利子！那时迷伽听到佛的授记，欢喜踊跃，升上虚空，高七多罗树，证得百千那庾多拘胝种无动之定，又以神通智力看见东方超过殑伽沙数的无量诸佛都为他授记，这样说：‘儒童应当知道，你在来世经过阿僧企耶劫，当得作佛，号为释迦牟尼。’同样，南方、西方、北方、四维、上下，周遍十方，各有如殑伽沙数的无量如来，都如东方诸佛一样为他授记。舍利子！迷伽儒童蒙诸佛授记安慰之后，从虚空下来，前往佛所，以信心舍家，趣向非家，修习坚固清净的梵行。舍利子！你现在对此不要生起疑惑，以为往世的那位迷伽儒童是别人吗？不要这样看，就是我作那儒童菩萨。我那时以这五茎青色莲花奉散那尊佛，又解开金色头发铺在道上，兴起这样的行，便蒙授记。

#### 无相行方蒙授记与无生法忍

“所以，舍利子！若有菩萨摩诃萨想要迅速得到如来的授记，应当对这样的大菩萨藏微妙法门殷重听闻，受持读诵，通明义趣，广为他人分别开示，又应当修行无相的正行。为什么？我忆念往昔未得值遇放光佛之前，没有一种白净的行法不修行的，虽然作了这样无量的勤苦，然而不蒙佛为我授记。为什么？由于所修的诸行都是有相的。从此以后，我才对这大菩萨藏微妙法门，随所听闻便安住于正行。这样的行就是无相行、无功用行、无所得行，行了这样等等的无相行之后，放光如来才为我授记。舍利子！我忆念往昔最初见到放光佛时，便得以超过一切有相、有功用的行；又初见佛时便能随觉一切法性；又得以通达一切诸法自性无生。从此以后，放光如来才为我授记，这样说：‘迷伽儒童！你在来世超过阿僧企耶劫，当得作佛，号为释迦牟尼如来、应、正等觉。’舍利子！在授记之时，我便证得无生法忍。

【按】“何以故”之“何”，《大正藏》作“我”，今依CBETA所录高丽藏作“何”。

“舍利子！证得什么样的无生法忍？就是证得一切色法无所得之忍，证得受、想、行、识法无所得之忍，证得蕴、界、处法无所得之忍。舍利子！所说的得忍，就名为忍受诸法都无所得。为什么？并不是在证得这样的忍时世间之法又再现行，也不是异生之法、诸有学之法、无学之法、独觉之法、菩萨之法、诸佛之法又再现行。为什么这样说？由于一切法不现行，所以说名为得忍；由于一切法毕竟无得，也无所得，所以名为得忍。又，这忍在一刹那中尽除一切相以及种种所缘，所以得名为忍。又，这忍不忍于眼，不坏于眼以及种种所缘，所以名为得忍；不忍于耳、鼻、舌、身、意，不坏于意，这样的忍是无尽的境界，这样的忍不是所趣的境界，所以名为得忍。所以，舍利子！若有菩萨摩诃萨想要迅速为如来授记、证得这忍，应当对这样的大菩萨藏微妙法门殷重听闻，受持读诵，通达义趣，广为他人分别开示，安住于正行，就是无相行、无功用行、无所得行，这样等等的法名为正行。”

#### 那罗达多长者子发心

那时，大众中有一位长者子名为那罗达多，从薄伽梵处听闻宣说这样的大菩萨藏微妙法门，又听闻赞叹诸佛菩萨的殊胜功德之后，便从座起，披衣偏袒一肩，右膝着地，向佛合掌，顶礼恭敬，对佛说：“世尊先前为诸长者等广说诸法，相续不绝，这样开示，这样教导，令他们都证得阿罗汉果，就在此生尽老死的边际，而未曾听到宣说大菩萨藏微妙法门、赞叹诸佛菩萨的功德。我有幸得大利益，现在完全得以听闻，私下生起这样的念头：‘这样的大乘为尊、为胜、为上、为妙、为无有上，再也没有超过其上的，就是阿耨多罗三藐三菩提。’我现在当面亲闻佛说，受持领悟，开显诸法；这样的法分别诸法，无所依执，无我、我所，没有摄受。世尊！我这样想：‘这样的妙法为尊、为胜、为上、为妙、为无有上，再也没有超过其上的，这样的法我应当修集。’世尊！我现在思惟，一切乘中最为无上的，就是佛乘；诸佛如来也说此乘，立为第一，最为无上。我从今日起发起无上正等觉之心，为了利益安乐众多众生，为了悲愍诸世间，利益安乐无量天人；如佛为诸大菩萨所建立的一切学处，我现在都当全部依随修学。”

那时长者子说了这伽陀赞叹佛之后，便对佛说：“世尊！我现在与这些有情等来到如来之所，都已安住于阿耨多罗三藐三菩提，唯愿世尊哀愍他们，再为他们说法，令一切人对阿耨多罗三藐三菩提不再退转。又，我现在想在佛处种下种种善根，唯愿世尊现前为我作证，以这善根之力，令众生平等迅速证得阿耨多罗三藐三菩提，又获得无量广大的佛法，也如现在的世尊一样。”

那时长者子与诸眷属、五百乐工、一万人众，一心同声对佛说：“世尊！我们现在在如来面前，一同至诚归依于佛，归依于法，归依于僧，唯愿世尊忆持我们是邬波索迦，从今日起乃至寿终，宁可舍弃身命，也不舍弃归依的清净信心。又，世尊忆持我们：从今日起乃至菩提，为了阿耨多罗三藐三菩提而发起增上勇猛之心。又，世尊忆持我们：唯愿迅速证得阿耨多罗三藐三菩提，为众生宣说正法，也如现在的如来没有差异。又，世尊忆持我们：唯愿来世成佛之时，大众围绕，如现在没有差异。又，世尊忆持我们：唯愿来世度脱无量被苦所逼的众生，如现在没有差异。”

#### 世尊现神变与微笑

那时长者子以及诸来众并五百乐工发了这誓愿之后，又以种种微妙音乐供养如来，右绕三匝。那时世尊怜悯他们，升上虚空，结跏趺坐。那时五百乐工看见如来示现这样的神变，对世尊更加生起净信。以佛的威力，种种乐器不需拿持，自然向上涌起，住在空中，无所凭借，奏起众多伎乐，繁会充溢，右绕如来。那时长者子与一同前来的大众，都看见神变，叹为未曾有，心生庆悦，踊跃欢喜，都一同合掌致敬如来。那时空中周围正好一逾缮那，又有无量百千音乐，也无人执持，自然出现，犹如蜂房悬于虚空，奏起伎乐，发出微妙之音。那时长者子与他的眷属以及五百乐工、一万城中之人，以及先前来听法大众中的六万人、诸苾刍众一千二百五十人，以佛的威力都升到空中。又以佛的神力，在上方空中五百座乐台自然出现，这些台中都在宣说妙法。又有四座大乐台现于佛前，庄严雕饰，穷尽世间的瑰丽奇异。又有无量百千拘胝诸天子众排列住于空中，以天曼陀罗花散在佛上；以佛的神力，所散的花在虚空中变成八万座高妙的花台。那时大众看见上方台中有这样等等广大的庄严，对如来更加生起净信爱敬之心，叹为未曾有。那时世尊知道大众其心清净，又了知那罗达多以及一同前来的大众的增上意乐之后，便现出微笑，如前广说，乃至其光又从顶上隐没。

【按】“结加”，明本作“结跏”。“上踊”之“踊”，元、明本作“涌”。

#### 佛为阿难说诸人当来果报

那时长老阿难见到微笑，披衣偏袒一肩，向佛合掌，恭敬作礼，对佛说：“世尊！有什么因缘现出这微笑？我想如来所现的神相不会没有因缘。”

佛告诉阿难：“你现在应当知道，这长者子那罗达多与七位妻子、男女以及奴婢等三十六人，由于供养我的善根之力，在未来世经过一千拘胝劫不堕恶趣，在人天之中往返，受种种快乐。过了这些劫之后，值遇佛出世，名为商主如来、应、正等觉、明行圆满、善逝、世间解、无上丈夫、调御士、天人师、佛、薄伽梵，在这尊佛处供养、恭敬、尊重、赞叹，广修梵行。从此以后，又经过二十拘胝劫不堕恶道。阿难应当知道，这长者子的七位妻子、七个女儿以及七个婢女，从此命终便舍弃女身，得成男子，恒常与那罗达多不相舍离，行菩萨道，在未来世同处一劫，得成阿耨多罗三藐三菩提。阿难应当知道，长者子那罗达多菩萨摩诃萨成佛时，号为平等心如来、应、正等觉，出现于世，十号具足；这位大菩萨所有的眷属成佛时，都同一名号，为阿若末若如来、应、正等觉，具足十号。这五百乐工由于供养我的善根之力，在未来又经过阿僧企耶劫不堕恶趣，又在那期间满一千拘胝次作转轮圣王的侍从。阿难应当知道，这五百乐工，总而言之，在这劫中得以值遇一万尊佛，都得以亲自承事供养，没有空过的。从此以后，在同一劫中得成阿耨多罗三藐三菩提，都号为美音。这一万人由于供养我的善根之力，其中四百人当得值遇慈氏如来，在那尊佛处清净修持梵行，得尽诸漏，便般涅槃。其余的人，在未来又经过如殑伽沙数的大劫不堕恶道，渐次得以值遇一千拘胝尊佛，在那些佛处广修诸行，之后一切都得成阿耨多罗三藐三菩提，都同一名号，名为甚希有。阿难应当知道，这六万大众中有满一千人，在我灭度之后正法已尽，又过了那刀兵中劫，在慈氏如来尚未出现之前、众生寿命渐渐增长之时，那时赡部洲将有八万独觉出现于世，这一千人都得以值遇，供养修善；之后又值遇慈氏如来，又得以供养；从此以后经过二十五拘胝那庾多劫不堕恶趣，最后的人身由于种种善根之力所觉悟，以净信舍家，趣向非家，便得以证悟缘觉菩提。阿难应当知道，在这大众中有一万人具足生起圣见，其余一千人等一同发起阿耨多罗三藐三菩提心。又有六十那庾多诸天子等，远尘离垢，于诸法中生起清净法眼。像这样，阿难！谁见到这样特殊的胜利，而对佛不生起净信、爱乐、恭敬，发起稀有之心？唯有愚痴不肖之人除外。为什么？那些人在如来处只修了这样微细的善根，就能获得如来的大我，或者证入无上涅槃。”那时世尊想重宣此义，而说颂道：

【按】“那庾多”之“庾”，《大正藏》作“庚”，今依CBETA作“庾”。“如来大我”之“我”，元、明本作“利”。

```
于佛所修诸供养，
获得如斯胜功德，
若有希求高大果，
当于导师修供养。
若佛现在修供养，
或复于佛涅槃后，
供养驮都如芥子，
常得奉侍诸如来。
若复欲修诸供养，
如来住世或涅槃，
供养驮都如芥子，
行平等心果平等。
```
（大意：在佛处修种种供养，获得这样殊胜的功德，若有希求高大之果的，应当对导师修习供养。若对现在世的佛修习供养，或者在佛涅槃之后，供养如芥子大小的驮都，常得奉侍诸如来。若又想修种种供养，无论如来住世或涅槃，供养如芥子大小的驮都，行平等之心，所得之果也平等。）

【按】驮都，即佛舍利。

```
若有具修平等心，
供养平等人中上，
当成平等之胜报，
及证平等妙菩提。
若有欲摄诸善趣，
遮障绝除众恶道，
及欲趣向涅槃路，
如是获得不为难。
佛具最胜净尸罗，
佛具最胜三摩地，
若生最胜净信已，
当获最胜如来果。
```
（大意：若有人具足修习平等之心，供养平等的人中至上者，当成就平等的殊胜果报，以及证得平等的妙菩提。若有人想摄取种种善趣，遮障断绝众多恶道，以及想趣向涅槃之路，这样获得并不困难。佛具足最胜清净的尸罗，佛具足最胜的三摩地，若生起最胜的净信之后，当获得最胜的如来之果。）

```
若修最胜诸供养，
速登最胜之善道，
及证最胜尊正见，
能宣最胜微妙法。
若乐人中聪叡者，
亲持诸佛清净法，
当修猛利正欲乐，
多闻如理正思惟。
有得转轮之圣主，
或为帝释梵天王，
广修无量胜功德，
定趣无余大寂灭。
```
（大意：若修习最胜的种种供养，迅速登上最胜的善道，以及证得最胜尊贵的正见，能宣说最胜的微妙之法。若乐于成为人中的聪睿者，亲持诸佛的清净之法，应当修习猛利的正欲乐、多闻以及如理正思惟。有人得以成为转轮圣主，或作帝释、梵天王，广修无量殊胜功德，必定趣向无余的大寂灭。）

#### 结劝受持菩萨藏经

那时世尊说了这颂之后，告诉长老舍利子：“若有安住于大乘的诸善男子以及善女人，想要迅速证得阿耨多罗三藐三菩提，应当对这样的大菩萨藏微妙法门，发起猛利清净的欲乐，殷重听闻，受持读诵，通达义趣，广为他人分别开示。为什么？若对这部经受持读诵，乃至为他人分别解说，能令三宝永不断绝，常不远离四无量行，常勤修习六种到彼岸，恒常以正确方便用四摄法摄化众生。舍利子！这样的大乘大菩萨藏微妙法门，应当知道就是诸菩萨之道。为什么？因为这部经典善能摄持阿耨多罗三藐三菩提。舍利子！这部经是诸菩萨等的圣珍宝藏，我依这部经正确修学之后，毕竟证得生死永断，又证得一切波罗蜜多；由于证得这些，便号为无上正等觉者。舍利子！如来对一切波罗蜜多都已究竟，如来对一切所作都已静息，如来对无量诸地都已证得，又更证得无边之地。为什么？由于佛证得这些波罗蜜多，而能究竟安住于一切到彼岸之法。所以诸菩萨摩诃萨应当对这大菩萨藏微妙法门精进修行，如我所证。”那时世尊说颂道：

```
于业应知业，于报应知报，
无业亦无报，是安隐涅槃。
诸有为皆苦，于中无有智，
是故智生已，有为皆解脱。
```
（大意：对于业，应当知道是业；对于报，应当知道是报；无业也无报，这是安隐的涅槃。一切有为都是苦，其中没有智慧，所以智慧生起之后，对一切有为都得解脱。）

那时世尊说了这颂之后，长老舍利子以及大苾刍，并诸天、人、健达缚、阿素洛等一切众生，听闻佛所说，都大欢喜，信受奉行。
