# 《大宝积经》卷第三十七（菩萨藏会·如来不思议性品）

唐·三藏法师玄奘 奉诏译

## 菩萨藏会第十二之三

【按】本品《如来不思议性品》相当于宋·法护等译《佛说大乘菩萨藏正法经》（T0316）的《如来不思议品》（卷七至卷十五）。

### 如来不思议性品第四之一

#### 十种如来不思议法

那时，佛告诉舍利子：“这些菩萨摩诃萨善住于这样清净的信心之后，又能信受如来、应、正遍知的十种不可思议法，谛实奉持，清净无惑无疑，不生异分别，倍加踊跃，深生欢喜，生起希奇之想。舍利子！什么名为如来十种不思议法？舍利子！一是信受如来不思议身，二是信受如来不思议音声，三是信受如来不思议智，四是信受如来不思议光，五是信受如来不思议尸罗以及等观，六是信受如来不思议神通，七是信受如来不思议力，八是信受如来不思议无畏，九是信受如来不思议大悲，十是信受如来不思议不共佛法。舍利子！这名为十种不思议法。

“若有菩萨摩诃萨为了求法而兴起正勤，不怯不退，不生舍离，发这样的心：‘我现在还没有得到不思议法，宁可让风所转的身体皮肉筋骨受大苦恼，或者血肉干枯竭尽，也必定要勤行精进，中间无有片刻废止。’这样，舍利子！已得信解的诸菩萨摩诃萨，若听闻这样的如来十种不思议法，便信受谛奉，清净无疑，倍加踊跃，深生欢喜，生起希奇之想。”那时世尊想重宣此义，而说颂道：

```
佛身难思议，为真法身显，
无相不可观，唯佛子能信。
诸趣杂种类，音声不可思，
随音为说法，信诸佛境界。
一切种群生，三世诸根异，
佛皆能觉了，信是不思议。
诸佛无边光，光网不思议，
遍满十方界，无边佛土海。
佛戒超世间，不依止世法，
神足不思议，菩萨能信受。
众生不能知，如来之境界，
如来常在定，解脱不思议。
```
（大意：佛身难以思议，是真实法身所显现，无相而不可观见，唯有佛子能够信受。诸趣的种种类别，其音声不可思议，佛随其音声为之说法，信受这是诸佛的境界。一切种类的众生，三世诸根各异，佛都能觉了，信受这是不可思议。诸佛的无边光明，光网不可思议，遍满十方世界，无边的佛土之海。佛的戒超越世间，不依止世间法；神足不可思议，菩萨能够信受。众生不能知晓如来的境界：如来常在定中，其解脱不可思议。）

【按】“佛戒超世间”之“超”，圣本作“起”。

```
法界不相杂，唯佛力能知，
大仙诸智力，犹若空无际。
为利一众生，住无边劫海，
令其得调伏，大悲心如是。
一切诸群生，种种问难海，
一音令悦解，无畏不思议。
成一切种智，随觉于诸法，
及不共佛法，遍智皆能见。
一切难思议，诸佛法如是，
有能奉信者，是为善住信。
```
（大意：诸法界不相混杂，唯有佛力能知；大仙的种种智力，犹如虚空无有边际。为了利益一个众生，安住于无边的劫海，令他得到调伏，大悲心就是这样。一切众生种种问难如海，佛以一音令他们都悦意解了，无畏不可思议。成就一切种智，随觉一切诸法，以及不共佛法，遍知之智都能照见。一切难以思议的诸佛之法就是这样，能够奉信的人，这名为善住于信。）

【按】“种种问难海”之“海”，宋、元、明本作“法”。

#### 一、如来不思议身

那时，佛告诉舍利子：“菩萨摩诃萨怎样对如来不思议身信受谛奉，清净无疑，倍加踊跃，深生欢喜，生起希奇之想？舍利子！所谓如来身，是永断一切恶不善法的。为什么？因为能成就一切微妙善法。如来身，远离一切不净的涕唾、痰癊、脓血、大小便利。为什么？因为如来早已解脱一切骨肉筋脉。如来身，自性清彻。为什么？因为如来早已远离一切烦恼垢秽。如来身，出过世间。为什么？因为不被世间法所染污。如来身，具无量功德，早已积集福德与智慧资粮，是一切众生慧命的依止。如来身，是无量净戒所熏修，是无量等观以及无量慧、解脱、解脱智见所熏修。如来身，是诸功德之花所严饰。如来身，如明净镜中的微妙之像，如净水中明满之月，又如光影所照耀。如来身，不可思议，等同虚空界，穷极法界之性。如来身，清净无染，远离一切染秽浊乱。如来身，就是无为，远离一切有为之相。如来身，是虚空身，是无等身、无等等身、一切三界无与等同之身。如来身，是无譬喻之身，无相似之身。如来身，清净无垢，远离诸烦恼，自性清彻。

【按】“痰癊”之“痰”，宋、宫本作“淡”。“解脱智见”之“智”，宋、宫本作“知”。“照耀”之“耀”，宫本作“曜”。“清净无染”之“染”，圣本作“流”。

“又，舍利子！如来身，不可以前际求，不可以后际求，不可以现在求，不可以生处种姓求。如来身，不可以色求，不可以相求，不可以好求。如来身，不可以心求，不可以意求，不可以识求。如来身，不可以见求，不可以闻求，不可以念求，不可以了别求。如来身，不可以蕴求，不可以界求，不可以处求。如来身，不可以生求，不可以住求，不可以坏灭求。如来身，不可以取求，不可以舍求，不可以出离求，不可以行求。如来身，不可以显色求，不可以相貌求，不可以形色求，不可以来求，不可以去求。如来身，不可以净戒作意求，不可以等观作意求，不可以正慧作意求，不可以解脱作意求，不可以解脱智见作意求。如来身，不可以有相求，不可以无相求，不可以诸法相求。如来身，不可以力的增益求，不可以无畏的增益求，不可以无碍辩的增益求，不可以神通的增益求，不可以大悲的增益求，不可以不共佛法的增益求。舍利子！菩萨摩诃萨想要求如来身，应当如幻、如焰、如水中月，以这样的自性来求如来身。

“舍利子！如来身，就是空、无相、无愿的解脱之身，无变异之身，无动坏之身，无分别之身，无依止之身，无思虑之身。如来身，就是安住、善住、得不动之身。如来身，就是无色而为色之自性的身，就是无受而为受之自性的身，就是无想而为想之自性的身，就是无行而为行之自性的身，就是无识而为识之自性的身。舍利子！如来身，无有、无生，不是四大之身；如来身，就是希有的、希有之法的身。如来身，不由眼而起，不在色中，也不在色外；不依于耳，不在声内，也不在声外；不是鼻所能知，不在香中，也不在香外；不是舌所能显，不在味中，也不在味外；不与身相合，不在触中，也不在触外。如来身，不依心而转，不依意而转，不依识而转，安住不动，不是旋还，也不随转。舍利子！如来身，等量于虚空；如来身，穷极于法界；如来身，尽于虚空界。舍利子！这名为第一如来不思议身。诸菩萨摩诃萨听闻如来不思议身如同虚空之后，信受谛奉，清净无疑，倍加踊跃，深生欢喜，生起希奇之想。”

【按】“不在香中”之“中”，宋、元、明、宫、圣本作“内”。

那时世尊想重宣此义，而说颂道：

```
拘胝那庾劫，行无量大行，
善净身三业，获无等佛身。
慈心遍十方，起大悲行施，
常离邪婬行，得胜虚空身。
于世尊福田，佛子广行施，
舍净珍服等，如无量殑沙。
奉持于净戒，如牦牛护尾，
假使碎身苦，于怨大忍生。
正勤波罗蜜，修行极疲苦，
发弘大誓愿，求常住佛身。
乐观诸定境，乐广慧方便，
乐观于法界，愿等法界身。
```
（大意：在拘胝那庾多劫中，修行无量的大行，善净身语意三业，获得无等的佛身。以慈心遍及十方，发起大悲而行布施，常离邪淫之行，得到殊胜的虚空身。对于世尊这一福田，佛子广行布施，舍弃清净的珍宝衣服等，多如无量殑伽沙。奉持清净的戒律，如牦牛护惜其尾；假使粉身碎骨之苦，对于怨敌也生起大忍。修行正勤波罗蜜，极为疲苦，发起弘大誓愿，求取常住的佛身。）

【按】“犛牛”之“犛”，明本作“氂”。

```
于佛行善已，成无等妙觉，
获大虚空身，清白离尘染。
无我人性空，无相不可说，
证是牟尼身，过诸眼境界。
意净离色声，本空无起作，
见真如身者，则见十方佛。
如种种幻化，象马狂夫等，
诳惑愚倒者，如是观十方。
三世无量佛，同处法性身，
无等等虚空，极清净法界。
```
（大意：乐于观察诸定境，乐于广大的智慧方便，乐于观察法界，愿得等同法界之身。在佛所修行善法之后，成就无等的妙觉，获得广大的虚空之身，清白而远离尘染。无我、无人，其性空寂，无相而不可言说，证得这样的牟尼之身，超过一切眼所见的境界。意念清净，远离色声，本来空寂，无起无作，见到真如之身的人，便见到十方诸佛。如种种幻化的象、马、狂夫等，诳惑愚痴颠倒的人，应当这样观察十方。三世无量诸佛，同处于法性之身，无等等如虚空，是极清净的法界。）

“这样，舍利子！这名为如来不可思议身，菩萨摩诃萨信受谛奉，清净无疑，倍加踊跃，深生欢喜，生起希奇之想。”

#### 二、如来不思议音声

那时，佛告诉舍利子：“菩萨摩诃萨怎样对如来不思议音声信受谛奉，清净无疑，乃至生起希奇之想？舍利子！如来出世，怜悯一切含识，敷演法化，所发出的音声齐于整个众会；由于所调伏众生之力的缘故，如来的音声普遍十方无量世界，令众生心生欢喜。舍利子！然而诸如来所发出的音声，虽然遍满世界，却不作这样的念头：‘我为苾刍众说法，我为苾刍尼众说法，我为邬波索迦众、邬波斯迦众、婆罗门众、刹帝利众、长者众、天众、梵众，这样的种种大众说法。’也不作这样的念头：‘我现在演说契经、应颂、记莂、伽他、自说、缘起、本事、本生、方广、希法、譬喻、解释，这样的十二分教。’从来不曾起念而为之敷演。舍利子！如来随着种种集会的大众，就是苾刍乃至梵众，如其所听闻的种种正勤而为之说法。这些众生因为乐于闻法，各自认为听到如来的法声从面门发出；然而这法声对于其所说的种种言词互不障碍，各自悟解自己所了解的法，这便名为不可思议。

【按】“记莂”之“莂”，宋、元、明、宫本作“别”。

“舍利子！诸佛如来由先世福德所感得的果报音声，其相无量，就是慈润之声、可意之声、意乐之声、清净之声、离垢之声、美妙之声、喜闻之声、辩了之声、不坚硬之声、不涩滞之声、令身适悦之声、令心踊跃之声、令心欢悦愉快之声、发起喜乐之声、易解之声、易识之声、正直之声、可爱之声、可喜之声、庆悦之声、意悦之声、狮子王吼之声、大雷震动之声、大海震动之声、紧捺洛歌唱之声、羯罗频伽之声、梵天之声、天鼓之声、吉祥之声、柔软之声、显畅之声、大雷深远之声、令一切含识诸根欢喜之声、称可一切众会之声、成就一切微妙之相的声。舍利子！这样的如来音声，具足这样殊胜的功德，以及其余无量无边功德所庄严。舍利子！这名为第二如来不思议音声。这些菩萨摩诃萨听闻如来不思议音声具足无量殊胜功德，便信受谛奉，清净无疑，倍加踊跃，深生欢喜，生起希奇之想。”

【按】“䩕”字（革旁卬）先前电子文本未能显示，今据《大正藏》补出，宋、元、明、宫、圣本作“鞕”，即“硬”，“不䩕声”即不坚硬之声。“悦豫”之“豫”，宋本作“预”。“微妙相声”之“相”，宫本作“根”。

那时世尊想重宣此义，而说颂道：

```
导师演妙音，所谓梵音声，
由是法具足，令诸梵欢喜。
牟尼演妙音，从大悲流涌，
谓与慈相应，喜舍亦如是。
如是具足音，灭众生贪火，
息除瞋恚毒，坏裂诸痴暗。
假使赡部洲，无量种人声，
纵获遍闻已，终不悟解脱。
天地虚空声，不悟亦如是，
若闻圣主声，必能证寂灭。
```
（大意：导师演出的妙音，就是所谓梵音之声，由于此法具足，令诸梵天欢喜。牟尼演出的妙音，从大悲中流涌而出，是说与慈相应，与喜、舍相应也是这样。这样具足的音声，熄灭众生的贪火，止息瞋恚之毒，破裂种种愚痴之暗。假使赡部洲中无量种人的声音，纵然全都听遍了，终究不能悟入解脱；天、地、虚空的声音，不能令人觉悟也是这样；若听闻圣主之声，必定能证得寂灭。）

【按】“假使”之“使”，《大正藏》作“作”，CBETA依高丽藏作“使”，今从之。“无量种人声”之“种”，明本作“众”。

```
二足及四足，多足及无足，
悉同彼音声，悟之善恶法。
三千世界内，下中上音声，
随彼种类音，化令证解脱。
演无分别声，无缚无摄受，
处定开真谛，闻者息烦恼。
无边众生闻，佛法僧音声，
及施戒闻忍，如来声如是。
彼声非有量，声智俱无边，
信佛声无疑，唯聪慧菩萨。
```
（大意：二足以及四足、多足以及无足的众生，佛都同他们的音声，令他们悟知善恶之法。三千世界之内的下、中、上种种音声，佛随其种类之音，化导他们证得解脱。演说无分别之声，无缚而无所摄受，处在定中开示真谛，听闻者便止息烦恼。无边的众生听到佛、法、僧之声，以及布施、持戒、多闻、忍辱之声，如来之声就是这样。那声音不是有限量的，声与智都无边际，能信受佛声而无疑惑的，唯有聪慧的菩萨。）

【按】“悉同彼音声”之“声”，元、明、宫、圣本作“转”。“声智俱无边”之“俱”，《大正藏》作“但”，CBETA依高丽藏作“俱”，今从之。

#### 三、如来不思议大智

那时，佛告诉舍利子：“菩萨摩诃萨怎样对如来不思议大智信受谛奉，清净无疑，倍加踊跃，深生欢喜，生起希奇之想？舍利子！如来的无碍智见不可思议，在一切法中依之而起，诸菩萨摩诃萨便能信受谛奉，乃至生起希奇之想。舍利子！如来为了令人生信，依如来的智波罗蜜多广说譬喻，诸有智者便得开解。

“舍利子！假使有人把殑伽沙等世界中所有草木的茎干枝叶，下至截成四指长短，堆积成大聚，用火焚烧，变成墨，投到他方殑伽沙等世界的大海之中，经百千年研磨，全成墨汁。舍利子！如来成就这样的无碍智见，以这智从那样的大海之中取一滴墨，以智力分析了知：这是某世界某树所成，某根、某茎、某枝、某条、花、果、叶等，类别所作，全都了知。为什么？舍利子！由于如来善能通达法界，所以能这样了知此墨从某世界某树而来，这样次第乃至广说。舍利子！这名为如来、应、正遍知具足这样的大神通力，具足这样的大威德力，具足这样的大宗势力。所以，舍利子！若有善男子、善女人对如来的大智清净信受，又在佛所生起爱敬之心，那善男子、善女人所有的善根难以知其边际，迅速穷尽苦的边际。为什么？舍利子！因为如来善能通达法界。由于通达，若有众生在如来所生起微小的善，便能穷尽苦际，毕竟不坏。

“舍利子！我现在再为你说一个譬喻，令有智者因此譬喻对其义理得到了解。舍利子！如有一个男子，寿命百年，此人把一根毛端分散为一百五十分，取毛的一分沾一滴水，来到我所，这样说：‘冒昧把这滴水寄放在您这里，以后若需要，请还给我。’那时如来取那滴水放进殑伽河中，被那河的流浪漩涡所旋转，和合引注，流到大海。此人满了百年，来到我所，对我说：‘先前寄放的那滴水，现在请还给我。’舍利子！如来成就不思议智，由于这智，如来、应、正等觉知道那滴水在大海中的位置，便用一分毛端在大海里沾取原来的那滴水，还给此人。舍利子！这譬喻的意义是什么呢？就是说，众生曾以一滴微善之水寄放在如来福田的手中，久而不失。这样，舍利子！若有善男子、善女人对如来不思议智清净信受，生起爱敬之心，缘念如来而兴种种供养，又以名花散在空中奉献，此人所有的善根难以知其边际，迅速穷尽苦际。为什么？舍利子！因为如来善能通达法界。若有人在如来所生起一念善心，便能穷尽苦际，毕竟不坏。”

【按】“洄澓”之“洄”，宋、元、明、宫本作“回”。

#### 识与智的差别

那时，长老舍利子对佛说：“世尊！如来的不思议大智是离开识而转的吗？”佛说：“不是。”舍利子又对佛说：“世尊！若是这样，什么是智？什么是识？”

佛说：“舍利子！有四种识住，识依此而住，所以名为识住。是哪四种？就是色识住：识缘于色，识住在色中，由此而生喜乐住著，转加增长，坚固广大。受识住：识缘于受，识住在受中，由此而生喜乐住著，转加增长，坚固广大。想识住：识缘于想，识住在想中，由此而生喜乐住著，转加增长，坚固广大。行识住：识缘于行，识住在行中，由此而生喜乐住著，转加增长，坚固广大。舍利子！这样的种种相，名之为识。又以什么名之为智？就是不住于五取蕴中，了达识蕴，这名为智。

“又，舍利子！所说的识，是指能了别地界、水界、火界、风界，这名为识。所说的智，若不住于四大界中，能善通达与识之法界不相离的，这名为智。又，舍利子！所说的识，是指能了别眼所知的色、耳所知的声、鼻所知的香、舌所知的味、身所知的触、意所知的法，这名为识。所说的智，是在内寂静而不行于外，唯依于智，不对任何一法生起分别以及种种分别，这名为智。又，舍利子！从境界而生，这名为识；从作意而生，这名为识；从分别而生，这名为识。无取、无执，无有所缘，无所了别，无有分别，这名为智。又，舍利子！所说的识，住于有为法。为什么？因为在无为法中识不能运行。若能了达无为之法，这名为智。又，舍利子！住于生灭的，名之为识；不生不灭、无有所住的，这名为智。

原文：“若有不住四大界中，能善通达识之法界不相离者”（大意：若不住于四大界中，能善通达与识之法界不相离的。“不相离”所指未详，存疑。）

“舍利子！这样的种种相，或识或智，这名为如来第三不思议大智。若诸菩萨摩诃萨听闻这样的不思议大智无障无碍，在一切法中依之而起，便信受谛奉，清净无疑，倍加踊跃，深生欢喜，生起希奇之想。”那时世尊想重宣此义，而说颂道：

```
无量殑伽沙，十方界草木，
尽焚成墨灰，亿载磨于海。
十力智深妙，取滴示含生，
如实分别知，此某界树等。
如是十方界，尘水示如来，
佛智等虚空，遍晓无疑滞。
十方众生心，发贪瞋痴行，
如实悉能知，无增减解脱。
十力世尊智，照明于法界，
无分别离思，佛子能信受。
```
（大意：把无量殑伽沙数十方世界的草木，全部焚烧成墨灰，在大海中研磨亿年；十力的智慧深妙，取出一滴示给众生，如实分别了知这是某世界的某树等。像这样，十方世界的微尘与水滴，都呈现于如来面前；佛智等同虚空，遍晓一切而无疑滞。十方众生的心，发起贪、瞋、痴之行，佛都如实了知，无增无减而得解脱。十力世尊之智，照明于法界，无分别而离思虑，佛子能够信受。）

#### 四、如来不思议大光

那时，佛告诉舍利子：“菩萨摩诃萨怎样对如来不思议大光信受谛奉，清净无疑，倍加踊跃，深生欢喜，生起希奇之想？舍利子！诸佛如来因为善能通达法界，所以不可思议。由于通达，一切如来放大光明，遍照三千大千佛世界而无障碍。舍利子！譬如空中没有云雾，日轮炎盛，放大光明，遍照世间；这样，舍利子！如来、应、正等觉放大光明遍照一切也是如此。

“又，舍利子！如世间中，灯油之光比萤火之光更广更大，显照明净，超过最胜；烛炬的光耀又胜过灯光；庭燎的火聚又胜过烛炬；药草发出的光又超过火聚；星宿之光倍胜药草；满月流光又超过星耀；炽盛的日光又超过月光；四天王天身体所发之光、宫殿之光、墙壁之光、庄严具之光，又倍胜于前，不可为喻。这样展转，乃至他化自在天的身、宫殿、墙壁、身上的庄严具，都发出光明，又倍胜于上。梵身天之光、梵辅天之光、梵众天之光、大梵天之光，以及少光、无量光、光净、少净，乃至遍净、广果、有想、无想、无烦、无热、善现、善见、色究竟天，所有的身光、宫殿光、墙壁光、庄严具光，比起前面诸光是最为第一的。这样色究竟天所有的光明，比于如来正遍知之光，如来之光超过于它，微妙显照，最胜明净，广大第一，不可为喻。为什么？舍利子！因为如来之光不可思议，是从无量戒聚而生，从等持聚而生，从慧聚、解脱聚、解脱智见聚而生，从这样无量功德所由而生。

【按】“宫殿光”之“宫”，《大正藏》作“官”，今依CBETA作“宫”。

“又，舍利子！三千大千世界所有诸光，比起如来之光，百倍也不及其一，乃至优波尼商倍也不及其一，这样算数譬喻都不能及。再者，舍利子！如把赡部捺陀金放在普通的金中，令那普通的金犹如墨聚，失去明亮光泽；这样，舍利子！这三千大千世界中所有光明，在如来光前不能明照，也是如此。又，一切世间所有诸光，在如来光前，不可以说是有光、有净、有胜、有上、有无上。

【按】“优波尼商”之“商”，《大正藏》作“啇”，CBETA依碛砂藏作“商”，今从之。

“再者，舍利子！你现在应当知道，如来若不是为了怜悯众生而摄持此光令其只周遍一寻，仅以一分业力所生之光，便能遍照三千大千佛世界，令日月之光都不再显现；若是这样，便不能分别有昼有夜，不能分别有月、半月以及时节岁数的分齐。只是为了怜悯众生，才显现周遍一寻之光。舍利子！若如来、应、正遍知发意想以光明遍满无量无数无边世界，便能遍照。为什么？舍利子！因为如来已得第一般若波罗蜜多。

“舍利子！我现在为你再说一个譬喻，重明此义，诸有智者更加显了。舍利子！假使有人把这三千大千世界碎为微尘，放在衣襟中，往东方去，经过那样微尘数的世界才放下一粒微尘，这样展转，放尽这些微尘，而这东方所有世界还未穷尽其边际；南、西、北方、四维、上下也是这样。舍利子！你认为怎样？是否有人能得到这些世界的边际？”舍利子说：“不能，薄伽梵！不能，苏揭多！”

“舍利子！这些世界所有诸光无量无边、不可思议，而如来之光最为第一；那一切光比于如来之光，百倍也不及其一，乃至优波尼商分也不及其一，这样算数譬喻都不能及。舍利子！如来若发意想以光明遍照一切世界，便能遍照。为什么？因为如来已得第一般若波罗蜜多。舍利子！如来之光没有障碍，所有墙壁、树木、轮围山、大轮围山、乾陀摩达那山、目脂邻陀山、大目脂邻陀山、伊沙陀罗山、雪山、黑山以及苏迷卢山王，这些都不能障碍，佛的光明全都能洞彻，遍照三千大千世界。

“舍利子！少智的众生不能信解如来之光：有的众生见如来之光只照一寻；其次有智者，见如来之光照两寻；其次有智者，见如来之光照一拘卢舍；其次大智者，乃至能见如来光明遍照三千大千世界。舍利子！乃至统领百千世界的梵天王，能见如来光明遍照百千世界；这样展转，乃至已登上地的诸大菩萨摩诃萨，能见如来光明遍照无量无边世界。舍利子！如来为了怜悯众生，又放光明，遍照如同虚空的一切众生界。舍利子！这名为第四如来不思议光。诸菩萨摩诃萨听闻如来说这大光不可思议、如同虚空之后，无惑无疑，清净信受，倍加踊跃，深生欢喜，生起希奇之想。”那时世尊想重宣此义，而说颂道：

```
日月等光明，及诸释梵等，
乃至色究竟，无光等佛者。
色究竟天光，遍照三千界，
比佛一毛光，十六不及一。
如来所放光，遍满虚空界，
诸大慧众生，方能见如是。
佛光无有边，量等虚空性，
随所化众生，见光有差别。
如有生盲者，不见日光明，
彼不见光照，谓日光无有。
```
（大意：日月等的光明，以及帝释、梵天等，乃至色究竟天，没有光明能等同于佛的。色究竟天之光遍照三千世界，比起佛的一根毫毛之光，十六分也不及其一。如来所放的光，遍满虚空界，唯有诸大慧众生，才能见到这样的光。佛光没有边际，其量等同虚空之性，随所化的众生，所见的光有差别。如同生盲之人，不见日光，因为看不见光照，便说没有日光。）

```
下劣诸众生，不见佛光明，
彼不见光照，谓佛光无有。
或见光一寻，或见拘卢舍，
或及一由旬，或满三千界。
已住于大地，大慧光菩萨，
或住八九地，至于十地者。
如来超彼地，光轮无有边，
不思议佛土，施作诸佛事。
诸佛不思议，佛光不思议，
信者及获福，亦尔难思议。
```
（大意：下劣的众生，不见佛的光明，因为看不见光照，便说没有佛光。有的见光一寻，有的见一拘卢舍，有的及于一由旬，有的遍满三千世界。已住于大地的大慧光菩萨，或住于第八、九地，乃至十地的菩萨。如来超过那些地，光轮无有边际，在不可思议的佛土中施作种种佛事。诸佛不可思议，佛光不可思议，信受者以及所获的福德，也同样难以思议。）

#### 五、如来不思议尸罗与三摩地

那时，佛告诉舍利子：“菩萨摩诃萨怎样对如来不可思议的清净尸罗众以及三摩地众信受谛奉，清净无疑，倍加踊跃，深生欢喜，生起希奇之想？舍利子！你们应当知道这样的正说：若有含识在世间奉持尸罗，清净无染，由于清净，应当知道此人成就清净的身业，成就清净的语业，成就清净的意业。此人虽然常处在世间，却不被那世间法所染。应当知道此人是婆罗门，是远离诸恶的人，是沙门，是寂静者，这名为第一修静虑者，得第一三摩地波罗蜜多者。舍利子！这样的含识就是如来，这样说，名为正说。为什么？舍利子！我从未见到诸天世间，无论魔、梵、沙门、婆罗门，以及其余天、人、阿素洛等，有谁具有这样无量无边不可思议的清净尸罗与三摩地众而等同如来的。为什么？舍利子！因为如来已得第一尸罗与三摩地波罗蜜多。舍利子！你现在想听佛宣说如来尸罗波罗蜜多的譬喻吗？”

舍利子说：“现在正是时候，薄伽梵！现在正是时候，苏揭多！世尊！若诸苾刍听闻佛所说的如来尸罗波罗蜜多譬喻，如所听闻后，当共同受持。”

佛告诉舍利子：“善哉！善哉！我当为你分别解说。舍利子！你认为怎样？众生界与大地界，哪个最多？”舍利子说：“如我理解佛所说的义理，众生界多，不是地界。”佛说：“是这样，是这样。舍利子！众生界多，不像地界。舍利子！假使三千大千世界所有众生，卵生、胎生、湿生、化生，或有色、或无色，或有想、或无想、或非有想非无想，所有这一切众生在一刹那顷、或一牟呼罗多顷、或一罗婆顷，假使同时都得人身；舍利子！那一切众生得人身之后，在一刹那乃至一罗婆顷，假使同时都成就阿耨多罗三藐三菩提；每一位如来又化作那样多的如来，每一位所化的如来各有千头，每一头各有千口，每一口各有千舌；那时这一切化如来都成就如来十力、四无所畏、四无碍解，又成就佛的无障无碍无尽辩才。舍利子！这些如来以那样多的舌头，布演无碍无尽的辩才，依于一位如来的尸罗波罗蜜多众作无量称赞，即使经过拘胝那庾多百千大劫这样称赞，如来的戒众仍不能说尽。舍利子！如来的戒众无量无边，无有穷尽，不可思议；这些如来的无上智慧、无碍无障无尽的辩才也无有穷尽，不可思议。乃至这些化如来直到同时入大涅槃，赞说如来的戒众也不能说尽。为什么？因为如来的戒众以及诸世尊的无上智慧、无碍辩才，这二者都不可思议，无量无数，与虚空界平等平等。

【按】“依一如来”，宋、元、明、宫本作“依一切如来”。“戒众”之“众”，宋、明、宫本作“聚”。

“舍利子！且不说三千大千世界所有众生。假使东方殑伽沙等世界中所有众生，以及南、西、北方、四维、上下十方殑伽沙等世界中所有众生，那一切众生在一刹那顷乃至罗婆顷，同时都得人身，都成就阿耨多罗三藐三菩提，这样广说，乃至如来的戒众以及诸如来的无上智慧、无碍辩才，都不可思议，无量无数，与虚空界平等平等。为什么？舍利子！因为如来证得了第一尸罗波罗蜜多。”

那时，佛告诉舍利子：“你现在想听佛宣说如来三摩地波罗蜜多的譬喻吗？”舍利子说：“现在正是时候。若诸苾刍听闻佛所说的如来三摩地波罗蜜多譬喻，如所听闻后，当共同奉持。”

#### 劫火中如来所住处的十种希奇法

佛告诉舍利子：“假使有时这世间劫将要被火烧，由于第七个太阳出现，三千大千世界一时燃烧，这样极燃、遍极燃、大洞燃。舍利子！应当知道，如来在这样大洞燃的世界之中，随在一处，假使如来在其中或经行、或住、或坐、或卧，应当知道此处成就十种甚为希奇、不可思议之法。舍利子！哪十种名为希奇之法？就是如来游止之处，不加功力，坦然平正，犹如手掌之中。舍利子！这名为此处成就第一甚希奇法。

“再者，舍利子！假使如上所说的世界乃至大洞燃等，如来在其中或经行、或住、坐、卧，那地方自然高耸显敞，没有杂乱的瓦石。舍利子！这名为此处成就第二甚希奇法。

“再者，舍利子！假使如上所说的世界乃至大洞燃等，如来在其中或经行、或住、坐、卧，那地方自然平坦宽博，庄严清净，为如来所受用。舍利子！这名为此处成就第三甚希奇法。

“再者，舍利子！假使如上所说的世界乃至大洞燃等，如来在其中或经行、或住、坐、卧，那地方自然生出种种香草，光色青翠，卷曲柔软而右旋，具有细滑之触，如迦遮邻地。舍利子！这名为此处成就第四甚希奇法。

“再者，舍利子！假使如上所说的世界乃至大洞燃等，如来在其中或经行、或住、坐、卧，那地方自然有八功德水从地中涌出，就是一轻、二冷、三软、四澄静、五无秽、六清净、七乐饮、八多饮无患。舍利子！这名为此处成就第五甚希奇法。

“再者，舍利子！假使如上所说的世界乃至大洞燃等，如来在其中或经行、或住、坐、卧，那地方自然凉风和畅，轻柔吹拂，相续而发，这是如来先世之业所感得的。舍利子！譬如极为炎热的时候，在午后有一个男子，被热所逼，奔向殑伽河，投入水中沐浴身体，热乏止息，清凉悦乐，往返游戏，渡到对岸，经行往来；远远望见不远处有一大片树林，枝叶翠盛，阴影浓密，便走入林中；又见到那里设着美妙的床座，铺着上好的氍毹，上面加上绵褥，覆以迦遮邻地的帔，轻妙鲜明的细布重叠其上，柔软的倚枕放在床的两头。那大丈夫登上此床，或坐或卧，床的四面清风微动，轻轻扇动，相续不断。这样，舍利子！如来在这大洞燃等世界之中行住坐卧，自然有凉风微微扇动，相续不断，也是如此。舍利子！这名为此处成就第六甚希奇法。

【按】“氍毹”，《大正藏》作“𣰽毺”，CBETA依高丽藏作“氍毹”，今从之。“排软倚枕”之“排”，宋、元、明、宫本作“细”。

“再者，舍利子！假使如上所说的世界乃至大洞燃等，如来在其中或经行、或住、坐、卧，那地方自然有江河池沼，种种水生之花出现，就是殟钵罗花、钵特摩花、拘贸陀花、奔荼利花，那些花芬芳馥郁，光彩映发，见者悦乐。舍利子！这名为此处成就第七甚希奇法。

“再者，舍利子！假使如上所说的世界乃至大洞燃等，如来在其中行住坐卧，那地方自然在平原、陆地、丘陵上都生出种种妙花，就是阿底目多迦花、瞻博迦花、苏末那花、婆使迦花、阿输迦花、波吒罗花、迦腻罗花、怛罗尼花、瞿怛罗尼花，这样的种种花开敷鲜荣，色香具足，众生见了得未曾有。舍利子！这名为此处成就第八甚希奇法。

【按】“如来于中行住坐卧”之“于”，宋、元本作“在”，明本作“抂”。

“再者，舍利子！假使如上所说的世界乃至大洞燃等，如来在其中行住坐卧，那地方自然以金刚为体，坚固难坏。舍利子！这名为此处成就第九甚希奇法。

“再者，舍利子！假使如上所说的三千大千世界劫将要尽时，乃至烧、极烧、遍极烧，燃、极燃、遍极燃、大洞燃等，在这些世界中，如来在其中或经行、或住、坐、卧，应当知道那地方就是佛的灵庙，是诸天世间、魔、梵、沙门、婆罗门、天以及人民、阿素洛等恭敬供养尊重之处。舍利子！这名为此处成就第十甚希奇法。

#### 如来常在定

“再者，舍利子！你现在应当知道，这样十种甚希奇法，都是如来先世业力所成就的。为什么？舍利子！因为如来善能通达法界。由于通达，如来、应、正遍知入于这三摩地，依此定心受乐而不退失，即使经过殑伽沙等大劫而住，然而如来从未曾退起三摩地之心。舍利子！如来、应、正遍知依此定心，经一顿饭的时间，或住一劫、百劫、千劫，或住百千劫，或住一拘胝劫、百拘胝劫、千拘胝劫、百千拘胝劫，或者乃至超过上面的数目。为什么？因为如来、应、正遍知成就第一三摩地波罗蜜多。由于成就，如来具足这样的大神通力，具足这样的大威德力，具足这样的大宗势力。舍利子！如那非想非非想处的诸天子，生于彼处，识缘于一境，经八万四千劫而住，乃至三摩地的寿命未尽以来，此识不被其余境界之识所移转。舍利子！那些天子尚且以世间定的力量经过那样长的时间，何况如来的三摩地波罗蜜多，岂会不能久住！

“再者，舍利子！从如来、应、正遍知初证阿耨多罗三藐三菩提之夜，乃至入无余大般涅槃界之夜，在这中间，如来之心从未曾从三摩地中起来。所以名此定为无回转心、无所行心、无观察心、无动虑心、无流荡心、无摄众聚心、无散乱心、无高举心、无沉下心、无防护心、无覆藏心、无欣勇心、无违逆心、无萎悴心、无动摇心、无惊喜心、无昏沉心、无分别心、无异分别心、无遍分别心。又，此定不随识心，不依眼心，不依耳、鼻、舌、身、意心，不依色心，不依声、香、味、触、法心，不趣向诸法之心，不起智心，不观过去心，不观未来心，不观现在心。舍利子！如来、应、正遍知住于三摩地，这样离于心，没有一法可得，于一切法中生起无碍智见，因为无功用的缘故。又，舍利子！如来不从三摩地起，离于心意识而能作种种佛事，因为无功用的缘故。这样，舍利子！这些菩萨摩诃萨听闻如来不思议尸罗以及三摩地之后，信受谛奉，清净无疑，倍加踊跃，深生欢喜，生起希奇之想。”

【按】“无摄众聚心”，元、明本无“众”字。

那时世尊想重宣此义，而说颂道：

```
无量无等百千劫，
昔有趣中行觉行，
戒闻定忍不放逸，
导师能修妙觉因。
最胜业果净如是，
妙广净戒超诸有，
十力尊戒如空净，
难说无垢譬虚空。
从佛初得菩提夜，
至后入于寂灭夜，
佛心无行无异行，
大静虑定未曾起。
十力戒聚无退分，
解脱神力亦如是，
一心住经无量劫，
大圣无思无异思。
佛智如空非思境，
明达无缘照三世，
无心意思无改变，
唯有佛子能信受。
```
（大意：往昔在无量无等的百千劫中，处在诸趣之中修行觉悟之行，以戒、闻、定、忍、不放逸，导师能修习妙觉之因。最胜的业果就是这样清净，美妙广大的净戒超越诸有；十力尊的戒如虚空般清净，难以言说，无垢如同虚空。从佛初得菩提之夜，到最后入于寂灭之夜，佛心无行，无异行，大静虑定从未起出。十力的戒聚无有退分，解脱与神力也是这样；一心安住，经无量劫，大圣无思，无异思。佛智如虚空，不是思虑的境界，明达而无所缘，照见三世，无心、无意、无思，无有改变，唯有佛子能够信受。）

【按】“无改变”之“改”，宫本作“役”，圣本作“伇”。

#### 六、如来不思议神通

那时，佛告诉舍利子：“菩萨摩诃萨怎样对如来不思议神力信受谛奉，清净无疑，倍加踊跃，深生欢喜，生起希奇之想？舍利子！如来、应、正遍知所获得的神通，不可思议，不可宣说，现在当为你方便开显。舍利子！如来常说，我的声闻众中得神通的，就是长老大目犍连最为第一。舍利子！这样所得的神通，若以称量观察声闻的神通，不见有与菩萨神通相等的；若以称量观察声闻、菩萨所得的神通，不见有与诸佛如来神通相等的。舍利子！这名为如来不可思议神通。这些菩萨摩诃萨想要证得如来神通，应当加倍发起上品正勤，便能获证。舍利子！你们现在想在如来所听闻宣说不思议神通的譬喻吗？”

舍利子说：“现在正是时候。若诸苾刍听闻佛所说的神通譬喻，如所听闻后，当共同受持。”

【按】“如所闻已”，明本作“如是闻已”。

佛告诉舍利子：“谛听，谛听，当为你说。”舍利子说：“是的，世尊！愿乐欲闻。”佛告诉舍利子：“你认为怎样？尊者大目揵连有大神通吗？”舍利子说：“我从前从佛受持这样的话：尊者大目揵连在声闻僧中神通第一。”佛说：“是这样，是这样。舍利子！现在当为你广说譬喻。假使三千大千世界中满是声闻，都得到如大目揵连那样的神通，譬如甘蔗、竹、苇、稻、麻的丛林那样稠密；这些声闻以种种正勤迅速之势力显现神通变化之时，若比之于如来的神通变化，百分、千分、百千万分也不及其一，拘胝分、百拘胝分、千拘胝分、百千拘胝分也不及其一，这样，僧佉分、迦罗分、伽拏那分、沤波摩分、优波尼商分也不及其一。为什么？因为如来、应、正遍知已得第一神通变化波罗蜜多。

“再者，舍利子！假使如来把一粒芥子投在地上，那些声闻众以种种正勤迅速之势力大显神通变化之时，终究不能把所投的芥子移动一根毛端那么多。为什么？因为如来、应、正遍知已得第一神通变化。又，舍利子！且不说三千大千世界。假使东方乃至如殑伽沙等世界中所有众生，以及十方殑伽沙等世界的众生，或卵生、或胎生，乃至非想非非想处，一切众生都是声闻，都成就第一神通变化，都如尊者大目揵连；这样的声闻以种种正勤迅速之势力大显神通变化之时，终究不能把所投的芥子移动一根毛端那么多。为什么？因为如来已得第一波罗蜜神通波罗蜜多。舍利子！这名为如来具足这样的大神通力，具足这样的大威德力，具足这样的大宗势力。”

#### 风灾不能动如来衣

那时，薄伽梵又告诉长老舍利子说：“舍利子！你是否曾听说，风劫兴起时，世间有一种大风名叫僧伽多，那风所吹，把这三千大千世界的苏迷卢山王、轮围山、大轮围山，以及四大洲、八万小洲、大山、大海举离原处，高过一逾缮那，碎为粉末？”舍利子说：“我从前在佛前亲自听闻受持这样的事。”

【按】“八万小洲”之“小”，《大正藏》作“少”，CBETA依高丽藏作“小”，今从之。

佛说：“是这样，是这样。舍利子！又，风灾兴起时，更有大风名叫僧伽多，那风所吹，把这三千大千世界以及苏迷卢山、轮围山等，以及诸大海，举高一百逾缮那之后碎为微尘；或者举高二百逾缮那，或高四百、五百，乃至举高一千逾缮那，或高三千、四千逾缮那之后碎为微尘，乃至或高无量百千逾缮那之后碎为微尘；而这些微尘随风散灭，完全不可得，何况山石还会存在！此风又向上，击散坏灭焰摩天宫，乃至微尘都散灭，何况宫殿还会存在！这样展转次第向上，击散坏灭覩史多天、乐变化天、他化自在天、魔罗众天、婆摩天、净光天、遍净天所有的宫殿，乃至那些微尘也都散灭不可得，何况宫殿墙壁还会存在！舍利子！假使如上所说的大风突然兴起，摧坏世界，就以此风吹如来衣服的一根毛端，尚且不能吹动，何况衣角以及整件衣服！为什么？因为如来、应、正等觉成就不可思议的神通、不可思议的威仪、不可思议的妙行、不可思议的大悲。

“再者，舍利子！假使十方如殑伽河沙等世界中有这样的大风轮兴起，将要吹坏这些世界，那时如来以一根指端托持这世界移往他处，或令风轮无力吹动，飒然退返，而如来的神通变化以及一切力量都没有退减。舍利子！如来的神通不可思议，难闻难信，唯有诸大菩萨摩诃萨才能信受谛奉，清净无惑无疑，倍加踊跃，深生欢喜，生起希奇之想。”那时世尊想重宣此义，而说颂道：

```
假使三界诸含灵，
一切变成声闻众，
尽得神通波罗蜜，
譬如尊者目揵连。
获大神通力如来，
以一芥子投于地，
一切声闻现神通，
未能摇转毛端量。
假使十方世界中，
所有殑伽河沙等，
吠岚僧伽大猛风，
吹碎如斯诸世界。
如是诸风大猛盛，
将吹一切智衣服，
尽其势力不能动，
乃至如一毛端量。
大牟尼尊以一毛，
能障彼风令不起，
佛具如斯大神力，
等彼虚空无边际。
```
（大意：假使三界一切含灵，全都变成声闻众，都得到神通波罗蜜，譬如尊者目揵连；获得大神通力的如来，以一粒芥子投在地上，一切声闻显现神通，也不能摇动它一根毛端之量。假使十方世界中，所有如殑伽河沙数的吠岚僧伽大猛风，吹碎这样的种种世界；这样的诸风极为猛盛，将吹一切智者的衣服，用尽其势力也不能吹动，乃至一根毛端之量。大牟尼尊以一根毫毛，便能阻障那风令其不起；佛具有这样的大神力，等同虚空，无有边际。）

“这样，舍利子！这名为如来不可思议的大神通力，菩萨摩诃萨信受谛奉，清净无疑，倍加踊跃，深生欢喜，生起希奇之想。”
