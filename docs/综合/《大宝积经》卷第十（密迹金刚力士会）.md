# 《大宝积经》卷第十（密迹金刚力士会）

西晋·三藏竺法护 奉诏译

## 密迹金刚力士会第三之三

### 如来三密

这时，寂意又问密迹金刚力士：“如来有几种秘要，是一切声闻、诸缘觉之地所不能企及的，何况愚暗蒙蔽的凡夫之类？善哉，密迹！愿你乐于承担，宣说如来秘要的普入之义，一切众会都想听闻。”

密迹力士对寂意说：“仔细听，仔细听，好好地思惟忆念，我现在将敷演如来的秘要。有三件事。哪三件呢？一是身密，二是口密，三是意密。

### 如来身密

#### 随众生所乐示现威仪色相

“什么是身密呢？如来在这里无所思想，也不起念，却普遍示现一切威仪礼节。有些天人喜欢经行，就见到如来经行；那时诸天人民心中自念：‘世尊是至上的。’这些人得见如来的身密；佛对此并没有念想，也不期望，而一切众生都见到如来至真妙德的威仪。如果诸天人喜欢坐，就见到如来坐；如果诸天人喜欢卧，就见到如来卧；如果喜欢听经，就见到如来说经；如果喜欢寂静，就见到如来默然；如果喜欢禅思，就见到如来入三昧；如果天人目视而不瞬，就见到如来目未曾瞬；如果心意自在而喜欢光明的，就见到如来光明无所障碍；喜欢紫金色的，也见到紫磨金色。如果诸天人民喜欢银色、水精色、琉璃色、玛瑙色、砗磲色、黄色、真珠正白、正赤、黄白红紫色，或取明月珠色、暴乱色，炎光日月之色，四天王、帝释、梵天、阿须伦之色，或中分色、须弥华色，或思妙色，或药形色，或碧石色，或无忧华、旃匐华色，或思夷华色，或青莲、红、黄、白华色，或忉利天色，或毗沙门王的容颜，或四天王之形，以及首藏、青帝、黄帝、赤帝、白帝之色，或虚空清净之色，或天人民心志无量，所喜品色各不相同——也都见到如来种种品类的功勋德色。

【按】“旃匐”，元、明、宫本作“詹卜华”，即薝卜花。

“正是这样，寂意！假使恒河沙数诸佛世界中充满众生、一切含命之类，辗转相爱，辗转相生，都已罪报尽毕，得为人形，从思想而生；其中一个人，即使他所生的样子，也如同那一切众生一样，如来也见到种种品色、威仪礼节以及心所好乐，不可限量，全都想要察知他们本末的言行，也是这样。如来至真由于这样的因缘，各各对众生示现如来之像，威仪礼节、言行，都是这样使然。犹如一个人心得解脱，不与二人共同一样，想要宣说至实，心得解脱，乃至于道。如来至真才能令一切众生欢悦，为了令众生欢悦而显示色像，威仪礼节、言行也是这样。

#### 明镜之喻

“寂意！犹如清净的明镜，随着来照的色貌，就显现其像，不失其本类，平等显示，没有差异，从不变改；明镜照形，也没有想念。如来也是这样：虽然以法济度一切众生，却没有想念，没有利养之心，能令一切众生的心行欢悦，随着上中下、深浅之法，开化度脱三界的迷惑众生。这就是如来身行的秘要。”

#### 佛身即是法身

密迹金刚力士又对寂意菩萨说：“如来的秘要，也不分别阴（蕴）、种（界）、诸入（处），不归于罪福，不生尘劳，不由父母所成，没有四大胞胎，也没有骨肉。所闻的功勋，没有涂抹的花香，都无所有；不系于色，没有出入息，寿命灭尽。想要了知佛身，就是法身：身无有色，没有种种妄想；所示现的色相，是为了那些贪慕美好、追求豪尊之位的众生，而示现形相，让他们亲眼看见。法相静寂，为了敬重智慧的缘故，使一切众生趣向天眼。”

#### 见与不见

密迹又对寂意说：“如果有众生共在一会，各自见到佛身，是依其心意的因缘而见。

原文：“其远住观住本，不见其住本也。见住远不见者，无意缘也，见者以乱意缘不见也。若以意缘不得见者，若以己身而察见之，用见他人故不见之也。又见他人故复能见者，用见己心故不见之也。其在梦中有所见者，从梦觉已则无所见也。定意所见起无所见，起往所见定无所见，其空静所见不静不见，其在空静则无不见。其见无业，离于无业无所见之，其离无业乃有所见，一无所见。”（大意：有的在远处观看能见，在近处却不见；有的在远处见，近处不见，是因为没有专注之心的缘故；有的以散乱之心见到，以专注之心反而不见。有的以专注之心不能见到，以观察自身来见到，因为观看他人的缘故反而不见；又有的因为观看他人而能见到，因为观看自心反而不见。有的在梦中有所见，从梦中醒来就无所见；有的在定中有所见，出定就无所见；有的出定有所见，在定中无所见；有的在空静中有所见，不静时不见；有的在空静中则无不见。其中见与不见，与有无加行之心相应而各不相同。存疑。）

【按】异译《如来不思议秘密大乘经》此处作：“或有众生见佛身者、或不见者，或远处即见、近处不见，或近处即见、远处不见……或专注心见、散乱心不见，或散乱心见、专注心不见，或他观即见、自观不见，或自观即见、他观不见，或梦境中见、寤已不见，或觉寤已见、梦中不见，或定中见、出定不见，或出定见、定中不见……或加行心见、无加行心不见，或无加行心见、加行心不见。”今据以译出大意。

#### 如来身如虚空，不可见顶

密迹又对寂意说：“那如来之身，从无数事中各随其宜而显现。那色界诸天，身行寂然，威仪礼节，心先自定而后又乱。这如来之身没有边际，也没有限碍，也没有妄想，不可想象节量。如来之身不可限取，没有种种形像，如来之身也是这样，无所不遍。犹如虚空不起妄想，如来也是这样，永无思想。犹如虚空遍入一切形色，如来也是这样，普遍照耀一切众生。犹如虚空普入一切色的间隙之中，如来之身也是这样，普照众生，无所不遍。犹如虚空长养一切百谷草木，如来也是这样，至真之体长养一切德本。犹如虚空不计有常与无常，也没有昼夜，如来也是这样，身不是有常，也不能说是无常，不能见到他的顶相。

【按】“间关”，元本作“间开”，明、宫本作“周遍”。异译此段作“又如虚空遍入一切处、一切处通达，如来身相亦复如是”。

“又，寂意！诸佛世尊，佛普遍观见天上世间的魔王、梵天，没有谁敢见到佛的顶相的。诸天、龙、神、揵沓和、阿须伦、迦楼罗、真陀罗、摩休勒、人与非人、声闻、缘觉以及诸菩萨，都不能见到如来的顶相。为什么呢？

#### 应持菩萨测度佛身

“佛成道不久，在波罗奈转法轮时，东方离这世界极远之处，有思夷华佛的国土，世界名叫怀调。有一位菩萨，名叫应持，来到这忍界奉见世尊，稽首作礼，敬问供事。礼佛足之后，绕佛七匝，就到佛前。应持菩萨当时心中想：‘我想要度量知道如来身体的限量。’他自己变化其身，高三百三十六万里，观看如来之身，有五百四十三万兆姟又二万亿里。他就心中想：‘我获得神足，以神通自娱，我何不再测度佛身的边际究竟如何？’

“佛以威德、以神足之力，使他到上方离此百亿恒河沙诸佛国土之处，有一个世界名叫莲华严，那国土有佛，名叫莲华上如来、至真、等正觉，现在正在说法。应持菩萨到了那佛面前，仍不能见到（释迦佛的顶）；站在上方远远观看，始终见不到世尊大圣能仁佛的顶；想要见到顶相，始终见不到；不知道佛身的高长广远有几千亿载恒河沙佛土。

“这时，应持菩萨前往莲华上佛那里，稽首礼佛足，右绕三匝，站在佛前对佛说：‘我身从来处到此，是远是近？’佛说：‘离这里有百亿恒河沙佛土，你这族姓子从那里来到这里。’应持菩萨对佛说：‘我向上越过这么多佛土，仍不能见到释迦文佛的顶，不知道他高长有几百千亿恒河沙佛土。’那佛回答说：‘假使族姓子以这样的方便、圣明的智慧、这样的神足之力，从这里再往上经恒河沙劫，迅速越过无可比喻的佛土，尚且不能见到世尊释迦文的顶，也不能得知他身体的边限。又，族姓子应当知道：佛身无限，巍巍如此，不可譬喻，诸佛世尊不可称量。又，族姓子！因为没有伴侣的缘故，名为不可譬喻。如来的禁戒也没有譬喻，三昧定意、智慧、解脱、解脱知见品，身、口、心业，色相众好，都不可譬喻。一切众生以种种品类引譬举喻，赞叹如来的禁戒无极、定慧解脱、解脱知见品、身口心业、色相威好，犹如虚空，不可得其边际。如来之身无际，也是这样。’

“这时，应持菩萨听闻莲华上如来所说，欣然大悦，得未曾有，随即礼佛足，绕佛七匝，从那佛国隐没，承佛的圣旨，蒙佛加持自身的神力，一念发意之顷，就到达这佛土。他前往佛所，上前稽首礼释迦文佛足，右绕七匝，就站在佛前，以偈颂赞叹道：

```
欲解达佛身，犹如喻虚空，
乐得知边际，以舍所造作。
过此百千亿，无量江河沙，
上越若干土，欲见佛身顶。
过到无限土，至莲华佛界，
乐得身边限，不睹见佛顶。
其彼国土佛，名曰莲华上，
见我心所念，便以分别说。
假使引众喻，讲诸佛世尊，
便不顺佛教，则为诽谤圣。
若欲知譬喻，诸佛法平等，
颁宣虚空限，实无有边际。
```

（大意：想要了达佛身，就像想要比量虚空；想要知道它的边际，所作的就应当舍弃。我越过这里百千亿、无量恒河沙数，向上越过若干佛土，想要见到佛身的顶。越过无限的佛土，到了莲华佛的世界，想要知道佛身的边限，却见不到佛的顶。那国土的佛，名叫莲华上，见到我心中所念，就为我分别解说：“假使引用种种譬喻来讲说诸佛世尊，那就是不顺佛的教导，就是诽谤圣者。如果想要知道譬喻，诸佛之法是平等的，所宣说的虚空的限量，实在没有边际。”）

```
设犹如虚空，佛戒禁若斯，
定意智慧业，解脱度知见，
犹虚空无际，色身亦如是。
欲观世护顶，等譬如虚空，
如虚空所周，佛身遍如是。
如虚空所遍，光明照亦然，
其光照所至，有言辞若兹，
如言辞所至，心遍亦复如；
如心所遍至，慈心布如是，
如慈心所遍，慧周等无异；
如慧之所周，身所周若斯，
功德亦如是，道心无有二；
如道心功德，解色亦如是，
充满于虚空，所度复越是。
```

（大意：设若犹如虚空，佛的戒禁也是这样，定意、智慧之业、解脱、解脱知见，犹如虚空无际，色身也是这样。想要观看世间护者（佛）的顶，等同譬如虚空：虚空所周遍之处，佛身也这样周遍；虚空所遍之处，光明照耀也是这样；他的光明所照到之处，有言辞也是这样；言辞所到之处，心的周遍也是这样；心所遍到之处，慈心也这样布满；慈心所遍之处，智慧周遍也没有差异；智慧所周遍之处，身体所周遍也是这样，功德也是如此，与道心没有两样；如同道心的功德，了解色也是这样，充满于虚空，所度的又超过这一切。）

```
如一切众生，所受福德品，
其发道心福，一人德如是；
如其发道心，功德业名称，
若受正法者，功德过于彼。
一切诸佛兴，颁宣百亿劫，
叹持正法功，不得其边际。
其兴于道心，而护诸正法，
好乐解空无，十六不获一，
以乐解空无，则不失道心。
执持尊上法，是慧乃和同，
逮得斯法趣，菩萨则勇猛，
获致佛功勋，奉修佛道行。
```

（大意：如同一切众生所受的福德品类，那发道心的福德，一个人的功德就是这样；如同那发道心的功德事业与名称，如果有人受持正法，功德又超过那发心者。一切诸佛出世，在百亿劫中宣说，赞叹护持正法的功德，也不能得其边际。那发起道心而护持诸正法的人，若喜好理解空无，（发心而不解空者）十六分不及其一（“十六不获一”依上下文译出，存疑）；由于乐于理解空无，就不会失去道心。执持尊上之法，这智慧才和合相应；得到这个法的旨趣，菩萨就勇猛，获得佛的功勋，奉修佛道之行。）


```
说是颂偈时，震动亿佛土，
诸天亿百千，鼓亿千伎乐，
无数亿千人，悉发大道心，
因闻大法故，应持之所叹，
是处不可议，无上不可限，
诸佛普示现，自在之秘业。
```

（大意：宣说这偈颂时，震动亿数佛土，诸天亿百千众，鼓奏亿千种伎乐，无数亿千人都发起大道之心；由于听闻大法的缘故，以及应持菩萨的赞叹，这不可思议、无上、不可限量之处，诸佛普遍示现了自在的秘密事业。）”

#### 如来不食而示食

密迹力士对寂意说：“这就是如来身的秘要：如果那些众生都聚集在一会中，有的能见到如来之身，有的不能见到；那能见到的，欢喜观看；那不能见到的，默然而观。如来并不进食，众生却都见到如来饮食。又，寂意！譬如有一位天人名叫精力，最初被教化而受道，他取如来的饭食，用器皿盛受，去救济穷乏的众生。众人都见到如来进食，见到如来把食物送入口中，其实自然回到器中。那些天子取去，是因为往古宿世在如来所种植众多德本而还有余殃，所生之处遭受羸弱困乏的众生，就给他们服食；对那些饥乏困厄得不到食物的人，如来怜愍他们，把食物授给他们。这些众生吃了这饭之后，身体安隐，消除尘劳，种种妄想止息，心性仁和，志存无上，以平等觉发起不可思议之心。由于这个缘故，应当这样观察：如来并不进食，如来至真以法为食。

“为什么呢？如来之身成就钩锁之体，犹如金刚，铿然坚强，不可破坏。那如来之身没有生藏，也没有熟藏，又没有坚软，也没有不净、大小便利、咳唾之秽。又如来之身如紫金色，没有怯弱，没有恐畏。寂意！你且观察如来之身：旷然无极，极妙坚固，犹如金刚，而身体柔软，如细天衣。有时上妙的天人玉女，以微妙之身稽首于足下，礼敬如来之身，触到如来的足，柔软极细，不可譬喻，都发起无上正真道意，永无种种尘垢。如果有贪淫、瞋恚、愚痴或等分（三毒等起）的人，见到如来之身，刚一亲眼看到，他们的淫、怒、痴以及等分的一切身行都被消除，不再有种种尘垢。如果有悭贪、犯戒、瞋恚、懈怠、乱心、愚痴的人，使他们布施、持戒、忍辱、精进、一心、智慧。总而言之，如果有远离清白之法的人，见到如来之身，就舍弃不善之想，都修习德本。以不妄想来观如来，才名为真道。寂意！这就是如来身的秘要。

【按】慧琳《一切经音义》卷第十一说（解释）：“钩锁”连环之义；“鏗然”是金声。

#### 如来化现而无所想

“如果有布施，如来以瑞应所化，自在无碍，以律开化众生，而不受其长育；了解众生之想而为他们宣说，建立应度之法。如来在那里观察，无所作业，也无所行。如来至真从来不曾这样想：‘我应当化现形体。’那所应当被化度的人，就在将被化度时心中自念（而见如来）。又如来所化之事，在所观之处，如来至真在这事业之前，乃至在所说的土地、无数世界中，如来所化现的往来所至之处，如来在那里观察，无所思想。

“那如来，从身上放出光明，有种种色、无数色、不可计限的百千光耀之色，那光明所照，远至恒河沙数诸佛国土，那些奉行善业的众生都从那里被开化。由于这无业之所作、无行之所行，所以，寂意！如来身的秘要，所有念行、所宣说、所成就，都令人发起无上正真道意。又如来身的秘密不可称计。”

【按】“若干种色”之“种”，CBETA 据高丽藏作“数”，即“若干数色”。

宣说这如来身行秘要时，一万人发起无上正真道意，八千菩萨得到无所从生法忍。诸天人民、阿须轮、世间之人都赞叹密迹：“善哉，善哉！”诸天伎乐不鼓自鸣，降下天花。世尊以紫磨金色的右手放在密迹金刚力士的头顶上，赞叹说：“善哉，善哉！密迹！你畅快善妙地宣说了这如来身的秘要。你现在所宣说的，正如佛所教的，没有两样。”

### 如来口密

#### 一字演说无量义

密迹力士对寂意说：“什么是如来口的秘要呢？从如来证得无上正真之道、成最正觉的那一夜，到入于无余界泥洹之界灭度的那一日夜，在这中间，施设一个文字，就能一一宣说分别，在无数亿载中讲演布散无限的义理。为什么呢？因为如来常在定中。如来至真没有出入息，没有思念，也没有所行，也不再有思想，都无所行；虽然口有所宣说，却无想无行。如来所行，没有应与不应，无言无说，不想有人。世尊所说，一切都超越三昧正受，都以文字分别宣说；众生依于所宣说的文字而执著，一切众生就这样周旋往来：‘如来为我讲说经法。’这就名为如来在那里也没有想念。如来所观察，知道止足；他的舌门口宣音响，听闻所宣之音的人无不欢喜。演说如来的言辞教法，发出一个音声，就普遍周遍于众生所想、众生心念，这就是如来从口敷演。

#### 如来六十种音声

“如来的言辞发出六十品各不相同的音声。哪六十种呢？吉祥音、柔软音、可乐音、悦意清净音、离垢音、显曜音、微妙音、明听音、无乱音、无愦音、师父音、无刚硬音、无粗犷音、善顺音、安重音、身所吉和音、随心时音、空悦音、与爱安想音、无恼热音、方正音、识达音、亲近音、意好音、欢悦音、和教音、晓了音、精勤音、忍和音、重了音、其响去秽音、应师子音、龙鸣音、雨好音、海雷龙王音、真陀罗伎音、哀鸾音、鹰畅音、鹤鸣音、耆域音、英鸟音、雷震音、不卒音、不暴音、普入响音、去非时音、无乏音、无怯音、悦豫音、通畅音、戒禁音、美甘音、进行音、广普音、具足音、诸根无瑕音、不轻疾音、无住音、响普入众会音、宣诸德音。”

【按】“无刚鞕音”之“鞕”，《大正藏》作“鞭”，CBETA 据高丽藏作“鞕”（硬）。异译《如来不思议秘密大乘经》作“如来语言具有六十四种殊妙之相”。

密迹金刚力士对寂意菩萨说：“这就是如来的六十品音声。那如来的音声，普遍通达十方诸佛世界，能令一切众生的心性行为欢悦。如来所观察的没有妄想，如来的道心不作这样的念头：‘我应当为他们口宣经法：通闻经、德经、所演经、分别经、颂诗经、藏经；或者是顺经、生经、方等经、未曾有法经、譬喻经、章句经；或者说古代的譬喻，或者有引用的譬喻，有宣说的言论、谈语，种种无上之说，讲说种种事，敷演众事，有所分处，布于远近，开通其本源，自己解了明白，宣畅其义理而为开化。’

【按】此诸经名，竺法护译语，大略相当于十二部经，照原文保留。“颂诗经”之“颂”，《大正藏》作“颁”，CBETA 据高丽藏作“颂”。

“又众会中，如来至真所宣说的法典，那亲近佛座的比丘众、比丘尼、清信士女，诸天、龙、神、揵沓和、阿须轮、迦留罗、真陀罗、摩休勒、人与非人等众会之辈，随众生的根性、所行的精进，依其所乐之法，而令他们入道。以随顺令他们入道，众生虽无因缘，也开化他们，乐法的音响也是这样。这些众生心中自念：‘这是从如来口中说出的。’如来并不是各别说法，而是随众生之心各别差异、言行应时，众生各各听到法而得开解，这就名为如来的口密要。

#### 随众生行而说异法

“又有，寂意！无数众生所行不可计，他们的言辞有八万四千种暗处下劣，为了诱进这些无明的众生，令他们进入如来法中而蒙受开化。又众生所行不可限量：如果有贪淫的，就随时依那众生所行，从而进入其中而救济他；对怒、痴的众生，以及等分行、被三事所蔽的众生之类，随其在三界中思想的顷刻，庄严拔济，令他们无所住；而以无异之心进入众生罪福之行中，为他们分别。如来示现寿命有限有尽，似乎不知众生所行的罪福，以权巧方便各说不同的法。如来善权方便，众生无限，不可计量，所行不同，就为他们宣说种种品类之法。又因为众生在我面前相见相值，如来所说都普遍入于他们心中，随其本行宣布道业，各各理解而入道，这就名为如来的秘要。

“如果有菩萨进入如来的秘要，这些人不知道，以为如来至真演说的是有为之门，而如来之法都是无为的。又如来宣说一品之音，众生依其想念，坐着认为有所说，只是忆想乐于如来音声的人，期望想象有所说，不应当这样观察，因为如来之口永无所说。为什么呢？

原文：“或有众生闻如来音，眉间之相谓之在顶，若有想发知之绀色从天中𥩳，目善明好；人不堪任谛视如来。所以施与，消除诸非、弃诤讼门，无危害心，若颈肩臂去众阴事。若诸指事若以身胁，若有宣颂从背至足、若以腹、若以脐又阴马藏、若以膝腨无瞋休息、若以有相及成种好，于世最上。”（大意：有的众生听到如来的音声，以为是从眉间白毫相、从顶上发出；有的以为是从绀青色的头发中发出；有的以为从眼目中发出，眼目明好，人不堪仔细凝视如来；有的以为从颈、肩、臂发出，能施与安乐，消除诸非，舍弃诤讼之门，没有危害之心，去除种种阴盖之事；有的以为从手指、从身胁、从背至足、从腹部、从脐、从阴马藏、从膝与小腿发出，令人无瞋而得休息；有的以为从诸相与随形好中发出——于世间最为上妙。存疑。）

【按】“𥩳”字照原字录出。慧琳《一切经音义》卷第十一释“膝腨”：腨是小腿肚。

“如果有人想知道如来至真，听到他的音响，就随其所好、诸根的厚薄，依其应度之法而开化他们，演说这音训，都使他们入于律仪。虽然如此，如来所观察开化，也没有想念。

#### 伎乐、呼声与如意珠之喻

“犹如，寂意！譬如伎乐，调好音调，以手弹奏，那声音悲凉和雅，并不是有人在那里作这声音，都是由于方便因缘和合，而有殊特悲和之音。正是这样，寂意！如来的言辞，化度众生之心，随缘而畅演教法，如来在那里有所演说，没有偏党，都是宿世因缘所造立之行而有殊特，如来至真在众生之中超绝巍巍，是由于本来的殊特。

“犹如，寂意！呼喊之声的回响，那声音远远传开，那声音所出之处，不在内，也不在外，也不在中间。如来也是这样，宣说音声，训诲众生之心，他的言辞教法不从身出，也不从心出，不内不外，也不从中间。犹如大海之中的如意明珠，放出它的光耀，满足一切众生；如果宝明珠系在幢头，就遍照城市，随着众生心中所欲的志愿，那明月珠出生珍宝，众人各得所欲，而这明珠宝也没有想念。如来也是这样：怀着如宝之心，志存清净，执持大悲之幢，随众生的根性无所不应，各使他们开解，虽然显现这教法，也没有想念。这就是如来所宣说的秘要。”

#### 目连试佛音声

密迹金刚力士又对寂意菩萨说：“我现在普遍观察天上世间、诸魔、梵天、沙门、梵志、诸天人民，都不能测知如来所宣说音响文辞的限量。为什么呢？我亲身记得这样一件事：世尊在灵鹫山，与诸菩萨眷属围绕，有一部法典名叫《净音场》，广为众生宣说，当时是慈氏菩萨所建立。那时，贤者大目连心中想：‘我想要试着知道如来的音响传到多远。’这时，大目连就从他的座位上忽然隐没，住在须弥山顶，听到如来的声音，就像在眼前一样。他以自己的神力，游遍这三千大千世界，到了最边际之处，越过众多须弥山、四方区域、一切铁围山，住在最边缘的大铁围山顶，听到如来的声音，依然如故，没有差异，就像在近处，不觉得远。

“佛心中想：‘这大目连想要试探如来清净的音场，我现在何不显现他的神足？’于是世尊发现神足之力，这时大目连承佛的圣旨，蒙佛加持自己的神足，到了西方界分离此极远之处，越过九十九恒河沙等诸佛国土，有一个佛世界名叫光明幡，那国土的佛名叫光明王如来、至真、等正觉，现在正在说法。目连到了那里，住在那佛土中，仍然听到佛的声音，就像有人当面所说的话一样。

“那光明幡佛土有大光明，佛身高四十里，诸菩萨身高二十里，诸菩萨所用的钵器高一里。目连在钵的边缘上行走，这时诸菩萨对世尊说：‘是的，大圣！这只小虫是从哪里来的，穿着沙门的衣服，在钵沿上行走？’那时，那佛说：‘诸族姓子！千万不要生起轻慢这位贤者之心。为什么呢？现在这位耆年名叫大目连，是释迦文佛诸声闻中的大弟子，神足第一。’这时，光明王佛告诉大目连：‘我国土的菩萨以及诸声闻，见你身体矮小，都生起轻慢。仁者应当自己显现神足之力，承释迦文佛的威德圣势。’

“这时，大目连前往光明王佛那里，稽首礼足，右绕七匝，退在前面站立，对那佛说：‘现在我这个身体，想要在这地上结跏趺坐，可以吗？’佛告诉他：‘随你所乐。’这时，大目连腾跃于虚空中，高达亿百仞，在那宝地上就作了一张床座，结跏趺坐。从他的床座上垂下种种名贵的宝珠璎珞，有亿百千姟；每一串珠璎、每一颗珠中放出百千种光明，每一种光明中各有莲花，一切莲花上都显现释迦文佛之身坐在莲花上，他们所说的声音，如同释迦文佛的音响一样清净，宣说经典，没有差异。这时，大目连显现神足之力之后，又回到佛前。这时，诸菩萨得未曾有，惊怪其中的缘由，上前对佛说：‘这大目连为什么来到这个世界？’世尊告诉他们：‘他想要试探释迦文佛的音响传到多远，所以来到这个国土。’

“这时，光明王佛告诉贤者大目连：‘仁者不应该这样试探。如来至真的音响无限，没有远近，怎么能想要知道它的限量呢？你大大地错了。假使目连仁者以神足经过恒河沙劫向西行走不休，也不能知道如来音响所闻的限量。诸佛世尊的音响旷远超绝，无限无量，巍巍无量，不可譬喻。’这时，大目连在那位世尊面前，自投于足下，自己忏悔过失：‘是的，世尊！我身不聪敏。佛的音声无量，我却横生妄心，想要知道它的限量、所闻的远近。’

“那光明王佛告诉目连：‘你虽然从远方而来，越过九十九恒河沙诸佛世界到了这佛土……’目连又对佛说：‘太远了，太远了！天中之天！我身体极为疲劳，不能再回到我的本土了。’世尊告诉他：‘目连你意下如何？是以自己的神力到这个世界的吗？不要这样看。这是世尊释迦文佛的威德所建立，你才到这个世界。你应当遥向释迦文佛自归，稽首作礼，那佛的圣旨就会带你回到本土。假使你以自己的神足想要回到本国，一劫也到不了；你还没有到达，就见不到能仁佛灭度时了。目连你意下如何？我们从哪个方向来？是东方、南方、西方、北方吗？’目连回答说：‘不知道是哪个方向。现在已经迷惑，不知道本土在什么地方，在哪个方向。’世尊告诉目连：‘释迦文佛在东方。’

“这时，大目连右膝着地，向着释迦文佛所在的东方，合掌自归，当时说偈颂道：

唯天人之尊，见垂力愍念，
威德大巍巍，天人所恭敬。

（大意：唯愿天人之尊，垂降力量，愍念于我；您的威德极为巍巍，为天人所恭敬；您的音响彻于无量，您的智慧没有边际；愿您显示您的国土，我现在想要回到那个国土。）

“正是这样，寂意！诸佛世尊的音声无际，不可限量。释迦文佛游化在灵鹫山时，舍利弗听到贤者大目连宣扬大声，惊怪其中的缘由。贤者阿难上前对佛说：‘是谁现在宣扬大声，遥遥自归命？’佛对阿难说：‘耆年大目连在西方境内，离这里九十九恒河沙佛土，世界名叫光明幡，那国土的佛号叫光明王如来至真，现在正在说法。耆年大目连到了那佛土，心中想要回到这个国土，所以遥遥宣扬这宏大的声音。’阿难又问：‘他以什么因缘到了那佛土？’佛告诉阿难：‘大目连回来时，应当问他的心意。’

“这时，大众会各自对佛说：‘我们想要见到光明幡世界以及光明王佛如来、至真、等正觉，见到大目连在那国中游行。’那时，世尊见诸众会劝助之意，当时从眉间白毫相放出大光明，名叫俱受，照耀九十九恒河沙等诸佛世界，到达光明幡佛土。那大光明普遍照耀众会，大众都见到那国土的光明王如来至真，以及大目连见到光明而自投于地、宣称大声。那时，世尊释迦文佛告诉贤者大目连：‘承这光明回到这个国土。’这时，目揵连依着佛的光明，一念发意之顷，就回到这个国土，稽首礼佛足，右绕七匝，就站在佛前，悔过自归，重重自责：‘我太迷误了。如来的音响不可限量，我却想要试探它。我所到达之处极为旷远，所到之处听到的声音都一样，近而不觉其远，如来的音响巍巍无际。’佛说：‘正是这样，目连！如你所说。如来的音响传得遥远，无可譬喻。想要知道如来音响的远近，就好像想要限量虚空、得其边际。为什么呢？犹如虚空普遍周遍，没有边际，如来的言辞音响传彻无际、辽远也是这样。’

“寂意！在宣说目连往返品时，随即那会中有一万人都发起无上正真道意。这就是如来言辞的秘要。”

#### 佛知一切众生心念

密迹金刚力士说：“寂意你所知道的如何？一切众生心中各自所念，可以知道吗？”

寂意回答说：“一个人的心念思想就难以限量，假使三千大千世界的众生在一劫中共同计算观察其多少，也不能知道，何况一切众生的心念思想，不可称限，竟是这样。”

（密迹说：）“现在所以殷勤地嘱累你：如同一切众生的心想那样多，如来所演说的音响也无限如此；何况一切众生的心性，是无形无想的，不可计量譬喻。”于是说偈颂道：

```
三千界众生，皆使成缘觉，
一人一劫中，心念不能知。
一切心所念，佛悉知志思，
以无想之心，佛悉了此念。
其一切众生，三世所想念，
世护口所言，所布各得解。
佛随之所念，宣音讲经典，
斯音响在心，乃演其道宜。
如一切众生，所思诸名色，
世雄一毛孔，所演光如是。
如一切众生，名色及心念，
如来演音响，过于彼众想。
佛颁宣一切，引喻计诸想，
其音不休废，不得佛言际。
```

（大意：即使三千世界的众生都成为缘觉，一个人在一劫中，也不能知道一切众生的心念。一切众生心中所念，佛都知道他们的志意思惟，以无想之心，佛都了知这些念头。一切众生三世所想所念，世间护者（佛）口中所说的，所宣布的都令他们各得理解。佛随顺他们所念，宣说音声，讲说经典，这音响在他们心中，就演说其道义所宜。如同一切众生所思的种种名色，世雄一个毛孔所放的光明也这样多；如同一切众生的名色以及心念，如来所演的音响，超过那些众生的一切想。佛宣说一切，引用譬喻来计量种种想，他的音声不休不废，不能得到佛言语的边际。）

```
无色谁能得，愍无言之辞，
无色无有言，消灭无色尘。
假使尘无色，一切不可得，
以是无色尘，究竟不可获。
设言虚无实，无内亦无外，
尘劳虚空等，故曰无内外。
如使不得辞，佛言通十方，
尘劳亦无际，斯建立所处。
一切众生言，上中下之辞，
无身口心事，不舍无所立。
想应如倡妓，诸天之音乐，
亦无身言辞，而音响普周。
如是本甚净，众生心若斯，
佛皆颁宣之，其心无所想。
犹如呼声响，无内亦无外，
人尊言如是，乃无内无外。
无想如妙宝，所说悦众生，
其言无妄想，可一切萌类。
```

（大意：无色，谁能得到？悲愍那无言之辞；无色就没有言语，消灭无色的尘垢。假使尘垢无色，一切都不可得；由于这无色的尘垢，究竟不可获得。假设说虚而无实，无内也无外；尘劳与虚空相等，所以说无内无外。如果得不到言辞，佛的言语却通达十方；尘劳也没有边际，这就是建立所处。一切众生的言语，上、中、下的言辞，都没有身、口、心之事，不舍也无所立。想想应当如同倡伎、诸天的音乐，也没有身体与言辞，而音响却普遍周遍。这样本来极为清净，众生之心也是这样，佛都为他们宣说，他的心无所想。犹如呼喊之声的回响，无内也无外，人中之尊的言语也是这样，无内无外。无想如同妙宝，所说的令众生欢悦，他的言语没有妄想，满足一切众生。存疑。）


### 以诸方言宣说四谛

密迹金刚力士对寂意说：“这就是如来口言的秘要。又如来的秘要，随着众生的音声，为他们说法开化。在这三千大千世界中设有种种（言语），如来至真宣布训诲，随其音辞，以不可计数的种种名号化导，建立至诚，如往无业；这就名为苦习尽道（苦、集、灭、道），名为地神拥护，令其心坚固、意本坚定。”于是说咒道：

### 随诸国音声而化度

第二十二离辞诸天、第二十三假使诸天、第二十四善见诸天、第二十五一究竟诸天——净居天有四天，就是所谓奉行决了一处究竟天、真究竟天、无瞋恚天、不亲近天。寂意！这就是诸天立至诚誓言的智慧之众。同样，诸夜叉鬼神、揵沓和、阿须轮、迦楼罗、真陀罗、摩休勒、迦卢迹鬼神、持花鬼神，他们的言辞教法各各不同。

“又，寂意！这阎浮利天下的大国，具足有一千个，各有大郡；其中十六个大国以政治相互摄护，各自称赞。一切人以及非人，言语各异，音声不同，言辞有轻有重。如来的圣慧随着他们的音响，随时而入，都化度他们，建立正真之业。他们各有种族名号：释种、安息、月支、大秦、剑浮、扰动、丘慈（龟兹）、于阗、沙勒、禅善（鄯善）、乌耆（焉耆），前后诸国，匈奴、鲜卑、吴、蜀、秦地，诸麽夷狄，他罗多的愚民野人，以及诸须曼耶咒、女人处国、牟兜吒国、因缘国、波罗奈国、数树国、金本国、脾罗本国、倚脾沙国、益本国、上本国、他谈国、北方异国、西方所持国；海中的诸神、众虫鱼鳖；诸山中的神，一切有形含血之类，阿拘罗、摩拘罗、阿那散，诸牧羊人、诸禽兽，所负诸瘘之种，心不平正，以及前曾生者、现处在世者。正是这样，寂意！像这样的一千个国家周围充满，在阎浮利天下各自分居。这些人以及非人之类，言语各异，志操不同，音声各别，如来至真随着他们的言音而进入其中，因而开化他们，立于正真。”

【按】“乌耆”，宫本作“焉耆”。“匈奴”之“匈”，《大正藏》作“匃”，CBETA 校作“匈”。慧琳《一切经音义》卷第十一说（解释）：“于阗”，《大唐西域记》译为瞿萨旦那国，唐言地乳，旧曰于阗。诸国名号照原文录出，不一一考订。

### 如来一言决一切疑

密迹金刚力士对寂意菩萨说：“这三千大千世界，有八十四亿百千姟众生之类，言辞各异；然而计算这一切，都归于一义——至真的智慧、至诚而无怒。正是这样，寂意！这就是如来言辞的秘要。又，寂意！如来的言辞，能决除一切众生的疑网，令没有余结。

“十方一切所有的众生，众生的种类多于大地的尘土；这些众生之类所行各异，与本来不同，罪报都令尽毕，得到人身；得人身之后，从思想而生；这些众生都得到智慧、辩才、圣明、勇猛，如同舍利弗。把这些智慧合为一个圣者的智慧，以此比喻，普使一切众生都得到这样的智慧，各如前面那一位圣者的明慧。以这样的圣明，在一劫或超过一劫中，以智慧禅思观察种种想，求其本末。如果第一人以智慧禅思，不再教诲，第二人都受其言教，智慧圣达，各有大明。以这样的比喻，这些众生各自所疑之事，前往如来那里，如来在一弹指之顷，就全都说出其本末。大圣就是这样：常以一心进入一切众生的心念，都能分别智慧光明之所在，以一句言辞全都决除疑结之网，各令他们处当于智慧之本所在，各令欣然而得其所，所听闻的如来智慧明达，如来都令他们明了。

“又，寂意！如来全都决除一切众生前后所疑，令没有余结，这就是如来言辞的秘要。所入的音响以及那言教，这还不足以言说；如来的言辞不可限量，无可譬喻。”

宣说这如来秘要言辞时，二万二千众生都发起无上正真道意。一切众会得未曾有，普遍听闻密迹金刚力士宣说如来言辞秘要之业，各怀欢悦，各从座起，稽首归礼密迹金刚力士。
