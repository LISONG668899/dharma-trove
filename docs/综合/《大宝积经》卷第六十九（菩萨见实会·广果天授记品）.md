# 《大宝积经》卷第六十九（菩萨见实会·广果天授记品）

北齐·三藏那连提耶舍 译

## 菩萨见实会第十六之九

### 广果天授记品第二十二

#### 广果天得诸辩才

那时有八亿广果天，见到阿修罗、伽楼罗、龙以及龙女、鸠槃茶、乾闼婆、夜叉、紧那罗、摩睺罗伽、诃罗伽阇天、四天王天、三十三天、夜摩天、兜率陀天、化乐天、他化自在天、梵摩天、光音天、遍净天等供养如来、听闻授记之后，欢喜踊跃，都称心如意。他们进入一一法门，从一一法门中见到无量法门，在一切法门中得无量辩、不断辩、相应辩、解脱辩、无著辩、无碍辩、微细辩、甚深辩、种种辩、美妙辩、相续辩。对各种辩才都了知之后，在如来处敬信尊重，这样说：

【按】“伽楼罗”之“伽”，明本作“迦”。“鸠槃茶”之“茶”，宋、元、宫、圣、圣乙本作“荼”。

#### 无量门陀罗尼与阴入

“世尊！有一种陀罗尼名为无量门，若有菩萨修集这陀罗尼，当知便得那不断辩等，在一切境界中心不迷惑。这些境界中，没有一法不是陀罗尼；这位菩萨摩诃萨得此陀罗尼时，在诸法中都得陀罗尼的理解，辩才无碍。若菩萨安住于这无量法门陀罗尼时，对于五阴之入、十二入之入、十八界之入，对于诸根之入、四谛之入、十二因缘之入，对于众生之入以及非众生之入，对于有之入、非有之入，对于取相之入、非取相之入，对于依之入、非依之入，对于空之入，对于我之入，对于相之入、非相之入，对于愿之入、非愿之入，对于有为之入、无为之入，像这样在一切处都得到不可破坏的辩才。

【按】“是诸境界”之“诸”，圣、圣乙本作“谓”。“取相入”之“相”，宋、元、明、宫、圣、圣乙本作“想”。

“这位菩萨在阴入中得陀罗尼，就是说，所谓色阴，即不是成就。为什么呢？没有少许色法能够成就。为什么呢？地，地界之性不是成就。同样，水、火、风界之性也不是成就。为什么呢？因为地性自离；若法无有体性，这就名为不是成就。同样，水、火、风之性自离，因为法无体性，所以不是成就。像这样色不是成就，因为不是成就，所以不可说为过去、现在以及未来。为什么呢？因为色不是有法，所以不可得。若色不生，便是不灭，因为不生不灭，所以不可言说。又有这样的说法：所有过去之色、现在未来之色，这些和合名为色阴；那色的体性也不可得，哪里有过去、现在、未来？所以色阴不是可以言说的。受、想、行、识也是这样，所以阴入就是陀罗尼入。因为是陀罗尼入，所以阴不可得。因为阴不可得，陀罗尼也不可得。因为陀罗尼入不可得，所以唯是但名、但用、但假，只是世俗，只是言说，只是施设，并非阴，并非色，也非色入，也没有陀罗尼的体性可得。

【按】“地地界性”之第一“地”，宋、元、明、宫本无。“是故阴入”之“是”，宋、宫本无。

“为什么呢？所谓阴等，并不是造作之法，因为不是造作之法，所以没有积聚；因为有积聚，才得名为阴。譬如世间许多物品积聚，假名为城：屋舍、宅第、殿堂，重阁、楼阙、窗牖、栏楯，城壁、女墙、却敌、寮孔，四周具足，名之为城。那色性即不可得，没有积聚，因为没有积聚，便没有色，也没有色阴。受、想、行、识也是这样，本性不可得，没有积聚，因为没有积聚，便没有识，也没有识阴。那些阴入应当这样了知。

【按】“假名城”之“城”，宫、圣、圣乙本作“成”。

#### 眼入

“那眼入是什么入？就是苦入。什么是眼？就是清净四大所造之色，名为眼。什么是四大？就是清净的地界，以及水、火、风界。那清净地界本性自离，因为法体不可得，它就不是成就。同样，清净的水、火、风界体性自离，因为法体不可得，它就不是成就。像这样眼入不是成就，所以不可说为过去、现在、未来。为什么呢？眼入不是物。因为不是物，所以不生不灭；若不生灭，就不可言说。像这样眼不生灭，入也不生灭，因为不生灭，所以不可言说。应当这样了知。唯是但名、但用、但假，只是世俗，只是言说。那名，名的体性也离自性。为什么呢？没有一法能够名为眼、名为入、名为苦。因为名不可得，所以眼入也不可得；因为眼不可得，这就是陀罗尼入。这陀罗尼入也不可得。为什么呢？因为本性自离，只是但名、但用、但假施设，世俗言说。像这样以眼入得入陀罗尼，得陀罗尼之后便得辩才。应当知道耳、鼻、舌、身、意，色、声、香、味、触、法也都是这样。

#### 界入

“在那界入中得陀罗尼：眼，眼的体性不可得；界，界的体性不可得。为什么呢？因为眼离眼之性，界离界之性。因为法体不可得，它就不是物。因为不是物，所以不是成就；不是成就的，不生不灭；因为不生不灭，它就非过去、非现在、非未来，只是但名、但用、但假，只是世俗，只是言说，只是施设。那名离名的自性，乃至施设也离施设的自性。若法无自性、不可得，就不是物；因为不是物，所以不是成就；不是成就的，便非生灭；因为不生不灭，它就非过去、非现在、非未来。

【按】“界，界体不可得”之“界，”，《大正藏》无，今依CBETA（所据房山石经）补；圣、圣乙本于“眼体不可得”下作“得界”。

“若是三世所不摄的，那名即非相，也非想、非用、非假、非有为、非可说、非来非去、非可为他人宣说、非可显示、非可知、非可识、非黑非白；非窟宅，因为离窟宅；非至，因为非可至；非得，因为非可得；非证，因为非可证；非凡夫，也非凡夫地；非声闻，也非声闻地；非缘觉，也非缘觉地；非菩萨，也非菩萨地；非佛，也非佛地；非地，也非非地。这就是真如、不异如、非非如，寂灭无相，只是但用、但假。所谓如来，只是因为世俗而说名为如来，并非第一义中有如来。为什么呢？那法不可得，所以没有如来。在那界入中，应当这样入于眼、耳、鼻、舌、身、意界，法界、意识界。像这样其余一切界也应了知，应当这样广入法界。

【按】“非相亦非想”之“想”，圣乙本作“相”。

#### 法界与诸根

“世尊！那法界在说为阴时，并不坏那法界的本性。说为入时、说为界时、说为四谛时、说为十二因缘时，也不坏本来法界的体性。那法界随其所说之处，一切诸法建立名字，都不坏那法界的体性。世尊！譬如地界随其所在之处立不同的名字，而不坏那本来的地界之性。世尊！像这样法界随其所在之处立不同的名字，也不坏法界的本性。水、火、风界也同样如此。世尊！譬如虚空随其所在有差别的不同作用，而不坏那虚空的体性。世尊！像这样法界随其所在有差别的名与用，而不坏那法界的体性。

“世尊！入诸根时，就是入法界。所说的诸根，就是眼根、耳根、鼻根、舌根、身根、意根，男根、女根、命根，乐根、苦根、喜根、忧根、舍根，信根、精进根、念根、定根、慧根，未知欲知根、知根、知已根。那眼，眼的体性不可得；根，根的体性不可得。为什么呢？因为这眼离眼的自性。因为法无体性，它就不是物；因为不是物，所以不是成就；不是成就的，它就不生；若不生，就是不灭；因为不生灭，所以不可说它是过去、现在、未来。若在三世中不生灭，它就不是眼，也不是眼根，怎么会有作用？应当这样了知。

【按】“知己根”，依上下文二十二根之列，当即“知已根”，译文依此。

“世尊！譬如空拳，虚诳无物，只有名字乃至言说，在第一义中空拳也不存在。像这样眼以及眼根，犹如空拳，虚妄不实，而显现虚假之相，诳惑凡夫，只有名字乃至言说。在第一义中，眼以及眼根都不可得。像这样，世尊得一切智之后，为了度化众生，所以说名为根。那些诸根在第一义中，因为本性自离，根的体性都空。其法体空的，作用也是虚妄，非有非实，诳惑凡愚，因为离自性，所以不生不灭；不生灭的，不能说它是过去、现在、未来。若在三世中没有，它就无名无相，非可说、非可为他人宣说，非生、非可生，非已知、非当知，非已闻、非当闻，非识、非可识，非已证、非当证，非已得、非当得，非已见、非当见，非已到、非当到。为什么呢？因为它非有。

“世尊！譬如有人在梦中享乐、欢笑、说梦话、游戏。这人那时从睡梦中醒来，忆念梦中所享之乐与游戏，忆念之后去寻求，却不见也不得。为什么呢？那人在梦中享乐、欢笑、说梦话、游戏，尚且不是真实，何况醒时能见能得，绝无此理。世尊！像这样诸根犹如梦中享乐游戏，实不可得。同样，一切诸法的体性也不可得，因为不可得，所以不可说它是过去、现在、未来。若在三世中不可得，它就不可言说。一切诸根应当这样了知。

【按】“呓语”之“语”，圣、圣乙本作“语例语”。

#### 四谛入

“世尊！若入法界，就是入一切法；入一切法，就是入法界。世尊！入四谛法，就是入法界。哪四种呢？就是苦、集、灭、道。世尊也说一切诸法都是空，非众生、非命、非福伽罗、非想非相。我们对此法没有疑虑。世尊！因为没有众生，所以也没有苦。为什么呢？没有众生之处，苦谛也就没有；因为没有苦，集谛也就没有。为什么呢？没有这样有因而无果的。

【按】“福伽罗”，明本作“补特伽罗”。

“世尊！因为没有集，灭谛也就没有。为什么呢？因为没有集谛，也就没有断集；因为没有灭，道谛也就没有。为什么呢？没有这样的道而不断集的。

“世尊！道的果就是灭谛。那烦恼不可得断，烦恼之灭也不可得。因为灭不可得，道也不可得，没有这样的道而无其果的。这四圣谛只是分别，虚妄非有。因为非有，所以不可说为过去、现在以及未来。若在三世中不可得，它就非生非灭、非相非想、非设非可设、非示非可示、非显非可显、非语言非可语言、非言辞非可言辞、非说非可说、非见非可见、非知非可知、非识非可识、非测非可测、非达非可达、非到非可到、非得非可得、非闻非可闻、非见非可见、非对非可对、非证非可证、非白非黑、非明非暗、非去非来、非浅非深、非清非浊、非畏非安、非缚非解、非憎非爱、非烦恼非清净、非智非非智、非路非非路、非坏非非坏、非摄受非非摄受、非生死非非生死、非可得非不可得、非众生非非众生、非命非非命、非寿者非非寿者、非我非非我、非物非非物、非空非不空、非相非非相、非愿非不愿、非依非不依、非有为非无为、非断非常、非邪非正、非实非妄、非妄想非非妄想、非处非非处、非宅非非宅、非知非不知、非舍非修、非生死非涅槃、非觉非不觉、非凡夫境界、非声闻境界、非缘觉境界、非菩萨境界、非佛境界、非境界非非境界、非作非不作。像这样入谛就是入法界，入法界之后便得陀罗尼，得陀罗尼之后便得辩才。

【按】“可言词”之“词”，宋、元、明、宫、圣、圣乙本作“辞”。“非依非不依”之“不”，圣、圣乙本作“非”。“非知非不知”之“不”，宫、圣、圣乙本作“可”。

#### 十二因缘入

“入十二因缘就是入法界：无明缘行，行缘识，识缘名色，名色缘六入，六入缘触，触缘受，受缘渴爱，渴爱缘取，取缘有，有缘生，生缘老死、忧悲苦恼，这是众苦大聚。像这样无明灭则行灭，乃至忧悲苦恼灭，众苦大聚灭。世尊！那无明，无明的体性不可得。为什么呢？因为本性自离。若法无体性，它就不是物；因为不是物，所以不是成就；不是成就的，非生非灭；非生灭的，就非过去、非现在、非未来。若在三世中不可得，便无名、无形、无相、无想，也没有差别，唯是但名、但假、但用，只是世俗，只是言说，是为了教化一切凡夫众生。那无明在第一义中实不可得，不可得的就没有差别，作用也不可说。

“世尊！若只是但名乃至但施设，它就不真实，唯是虚妄的言说、分别、觉观，并非决定，只是戏论。那无明若无自性，怎能生行？无明不存在，所以行也不生。因为不生，它就不老、不病、不死、不流转，就是不生。为什么呢？若不生，怎会有老？因为没有老，乃至不生。若不生不死，就是一切过去、现在、未来诸佛的菩提，只是世俗名字，并非第一义；所说的无明，就是菩提。应当知道诸有支也是这样。像这样入十二因缘，应当知道就是入于法界。

#### 一切法即是如来

“世尊！如来不生，一切诸法也不生，所以一切法就是如来。如来不灭，一切诸法也不灭，所以一切法就是如来。世尊！如来无相，一切诸法也无相，所以一切法就是如来。简略而言，像这样无相不可得，非垢非净，非爱非憎，法界不可识，也不可知。世尊！真如就是如来。一切诸法就是真如，所以一切法就是如来。世尊！实际就是如来，一切诸法就是实际，所以一切法就是如来。世尊！随在什么法中，就有如来；在那法中，就有一切法，所以一切法就是如来。

“世尊！若有人说如来得阿耨多罗三藐三菩提，那些众生是计著之见。为什么呢？如来不二，菩提也不二，不二不能觉悟不二。世尊！若又有人这样说：‘如来转无上法轮。’那些众生是执著之见。为什么呢？如来非进非退。世尊！若又有人这样说：‘如来灭度无量众生。’他们一切都是执见。为什么呢？一切诸法实无众生，所以没有得灭度的人。世尊！若又有人这样说：‘如来利益无量众生。’他们一切是取著之见。为什么呢？如来既不是为利益众生，也不是为不利益众生而出现于世。世尊！若又有人在未来世这样说：‘如来舍弃寿命。’那些众生都是执见。为什么呢？法界无有摄受，也无有舍弃。世尊！若又有人这样说：‘如来入于无余涅槃界。’那些众生是计著之见。为什么呢？法界非生死，也非涅槃。世尊！若又有人对我所说之法能决定了知，那些众生对阿耨多罗三藐三菩提都不退转。世尊！假使法界有所变异，这些善男子、善女人能这样信受的，必定当觉悟无上菩提，没有变退。”

【按】“觉寤”之“寤”，元、明本作“悟”。

#### 广果天以偈赞佛

那时八亿广果天在世尊处演说自己所证之法后，头面礼足，右绕三匝，退住一面，合掌而立，异口同声以偈赞佛：

```
敬礼善逝知法者，
那罗延力大导师，
怜愍一切胜牟尼，
方便示现于真实。
既自了知一切法，
如实显示诸世间，
稽首无量功德身，
智慧最胜无上士。
如是真实微妙法，
圣说相应无有异，
世尊无等大医王，
能令众生法眼净。
敷演八种真圣路，
为得无上大菩提，
归敬无量功德身，
智慧最胜无上士。
显示菩提正直道，
毕定趣向大涅槃，
获得无等胜菩提，
寂灭安隐最坚固。
度脱多亿那由他，
轮回生死苦众生，
顶礼无量功德身，
智慧最胜无上士。
```
（大意：敬礼善逝、知法者、具那罗延力的大导师，怜愍一切的殊胜牟尼，以方便示现真实。既已自己了知一切法，又如实显示给诸世间，稽首无量功德之身、智慧最胜的无上士。这样真实微妙之法，与圣者所说相应，没有差异，世尊是无等的大医王，能令众生法眼清净。敷演八种真实的圣道，为得无上大菩提，归敬无量功德之身、智慧最胜的无上士。显示菩提正直之道，必定趣向大涅槃，获得无等的殊胜菩提，寂灭安隐，最为坚固。度脱多亿那由他在生死中轮回受苦的众生，顶礼无量功德之身、智慧最胜的无上士。）

```
观察五阴悉空无，
阴体毕竟不可得，
彼阴即体离诸观，
唯诳愚惑痴众生。
凡夫于此悉被缚，
犹如猕猴胶所粘，
智者于斯得解脱，
游行无碍如空风。
诸界即体性自空，
一切智人如是说，
彼空亦空无自性，
究竟求之不可得。
凡夫于此皆被缚，
都由不知真实性，
智者观察得解脱，
于其三界无所著。
诸入无体自空寂，
一切智人如是说，
犹如空拳虚非实，
诳惑愚痴众生辈。
凡夫妄起取著心，
皆由于法生疑惑，
坠落生死皆丧坏，
犹如商人没巨海。
```
（大意：观察五阴都是空无，阴的体性毕竟不可得，那阴即体性离于诸观，只是诳惑愚痴的众生。凡夫于此都被系缚，犹如猕猴被胶所粘，智者于此得解脱，游行无碍，如空中之风。诸界即体性自空，一切智人这样宣说，那空也是空，没有自性，究竟去求，不可得。凡夫于此都被系缚，都是由于不知真实之性，智者观察而得解脱，对三界无所执著。诸入无体，自性空寂，一切智人这样宣说，犹如空拳，虚而不实，诳惑愚痴的众生们。凡夫妄起取著之心，都是由于对法生起疑惑，坠落生死，都遭丧坏，犹如商人沉没于大海。）

```
彼等诸根性自空，
毕竟推求不可得，
譬如镜中现面像，
其像无实毕竟空。
凡愚无智于此著，
正由不知真实法，
犹如众鸟入罗网，
亦如渊中所钓鱼。
众生无体离生相，
依真求之不可得，
譬如壁上彩画像，
究竟无实众生性。
凡夫无智而取著，
皆由不知真实义，
智者观彼得解脱，
犹如卵生出于㲉。
因缘生法悉无常，
皆悉空寂离攀缘，
譬如梦中所受乐，
非实诳惑痴凡夫。
愚无智慧为彼缚，
由不思量妄分别，
智人观察得解脱，
犹如飞鸟出笼网。
```
（大意：那些诸根本性自空，毕竟推求不可得，譬如镜中显现面像，那像不实，毕竟是空。凡愚无智于此执著，正是由于不知真实之法，犹如众鸟进入罗网，也如深渊中被钓的鱼。众生无体，离于生相，依真实去求，不可得，譬如墙壁上的彩画之像，众生之性究竟不实。凡夫无智而取著，都是由于不知真实之义，智者观察它而得解脱，犹如卵生者破壳而出。因缘所生之法都是无常，都是空寂，远离攀缘，譬如梦中所受之乐，不实，诳惑愚痴的凡夫。愚人没有智慧，被它系缚，由于不思量而妄加分别，智人观察而得解脱，犹如飞鸟出离笼网。）

【按】“彩画”之“彩”，圣、圣乙本作“綵”。“众生性”之“性”，元、明本作“相”。“㲉”字先前电子文本未能显示，今据《大正藏》补出，即卵壳。

```
如佛功德不思议，
一切诸法亦如是，
诸法无相如牟尼，
法体寂灭如涅槃。
诸法无依如如来，
于其三界不取著，
是故所有成佛者，
皆由得知此义故。
诸法无怖如世尊，
不起自身及他想，
诸法难思如导师，
唯佛能知导群生。
法无分别如善逝，
非是凡夫心所行，
是诸如来妙境界，
唯佛大圣能了知。
```
（大意：如佛的功德不可思议，一切诸法也是这样，诸法无相，如同牟尼，法体寂灭，如同涅槃。诸法无依，如同如来，对三界不取著，所以所有成佛的人，都是由于得知此义。诸法无怖，如同世尊，不起自身与他人之想，诸法难思，如同导师，唯有佛能了知，引导群生。法无分别，如同善逝，不是凡夫心所能行，这是诸如来的妙境界，唯有佛大圣能够了知。）

```
若有无智作是言，
佛证无等大菩提，
若复有人作是言，
世尊已转妙法轮。
若复有人作是言，
善逝已度那由众，
彼悉为见之所缚，
皆由不知真实性。
若人谓佛如是说，
杀害行阴及与命，
若言十力入涅槃，
利益无量众生已。
彼人一切皆执见，
入于魔罗之所缚，
不能解知真如法，
以不知故不知佛。
若有善知是非者，
彼皆能知大导师，
当获无上功德聚，
成佛怜愍于世间。
斯即真如无变易，
一切诸法离疑惑，
人中无上最胜尊，
我等已知如是义。
```
（大意：若有无智之人这样说：“佛证得无等的大菩提”；若又有人这样说：“世尊已转妙法轮”；若又有人这样说：“善逝已度那由他众”；他们都被见所系缚，都是由于不知真实之性。若有人说佛这样宣说：杀害行阴以及寿命；若说十力者入涅槃，是在利益无量众生之后；那些人一切都是执见，入于魔罗的系缚，不能理解真如之法，因为不知真如，所以不知佛。若有人善知是与非，他们都能了知大导师，当获得无上的功德聚，成佛而怜愍世间。这就是真如，没有变易，一切诸法远离疑惑，人中无上的最胜尊，我们已知这样的义理。）

【按】“魔罗”之“罗”，宋、元、明、宫本作“𦊰”。

#### 授广果天记

那时世尊知道广果诸天深信具足，对佛法决定无疑，为了令大众种植善根，而现出微笑。那时慧命马胜以偈颂问世尊说：

```
智慧导师功德山，
非是无因而现笑，
我从善逝亲自闻，
世尊现笑必有因。
如来示此微笑相，
令众皆受清凉乐，
天人修罗大导师，
唯愿演说笑因缘。
今见如来从面门，
所现微笑甚清凉，
此诸众会悉怀疑，
一心瞻仰如来面。
大悲最胜人中上，
愿说希有微笑因，
世间若得从佛闻，
决定必除疑惑心。
世尊！彼等诸天众，
咸皆演说自授记，
以何功德获何果？
愿说成佛神通事。
开演微妙梵音声，
唯愿普断诸有疑，
一切大众闻佛说，
皆悉踊悦甚欣喜。
```
（大意：具智慧的导师、功德之山，并非无因而现笑，我从善逝亲自听闻，世尊现笑必有其因。如来示现这微笑之相，令大众都受清凉之乐，天、人、阿修罗的大导师，唯愿演说笑的因缘。现在见到如来从面门所现的微笑甚为清凉，这些众会都怀疑惑，一心瞻仰如来之面。大悲最胜的人中之上者，愿说希有微笑之因，世间若得从佛听闻，决定必能除去疑惑之心。世尊！那些天众都演说自己的授记，以什么功德获得什么果？愿说成佛的神通之事。开演微妙的梵音之声，唯愿普断一切疑惑，一切大众听闻佛说，都踊跃悦乐，甚为欢喜。）

```
斯等合掌皆一心，
净信瞻仰恭敬住，
佛子天众各思惟，
悕求无上大菩提。
是诸众会有疑惑，
唯愿如来为除断，
必当得力知是非，
具足成就一切智。
得闻如来八种音，
天众靡不皆喜悦，
当得护持如来教，
随顺正法如说行。
观察知彼天心已，
无上大智愿解说，
以是大众生欣喜，
于佛法中得信解。
今于导师愿得闻，
天众过去所修行，
若蒙如来解说已，
所愿皆悉得满足。
广果诸天如法行，
必得成就一切智，
当度世间诸群生，
显示真如法体性。
```
（大意：这些人合掌，都一心以净信瞻仰，恭敬而住，佛子天众各自思惟，希求无上大菩提。这些众会有疑惑，唯愿如来为之除断，他们必当得力，知是与非，具足成就一切智。听闻如来的八种音声，天众无不喜悦，当得护持如来之教，随顺正法，如所说而行。观察知道那些天的心意之后，无上大智者愿为解说，因此大众生起欢喜，在佛法中得到信解。现在愿从导师得闻天众过去所修之行，若蒙如来解说之后，所愿都得满足。广果诸天如法而行，必得成就一切智，当度世间群生，显示真如的法体之性。）

那时世尊便以偈颂回答慧命马胜说：

```
善哉马胜汝知时，
今者问我正是宜。
我为广果诸天辈，
于此大众现微笑。
今当为汝分别说，
咸皆一心共谛听，
所现微笑因缘义，
汝及大众悉得闻。
如来具足一切智，
观察因缘有三种，
二足德聚正观已，
而现微笑示世间。
有乐住于涅槃者，
少智微浅愿声闻，
复有乐住默然者，
志求辟支佛菩提。
复有乐求世导师，
成佛大力那罗延，
我观彼等深信已，
随所乐欲而度脱。
```
（大意：善哉马胜，你知道时机，现在问我正合时宜。我为了广果诸天，在这大众中现出微笑。现在当为你分别宣说，你们都一心共同谛听，所现微笑的因缘之义，你以及大众都将得闻。如来具足一切智，观察因缘有三种，二足功德聚正观之后，现出微笑，显示给世间。有人乐于安住涅槃，智慧少而微浅，愿为声闻；又有人乐于安住默然，志求辟支佛菩提；又有人乐求成为世间导师，成佛而具那罗延的大力；我观察他们深信之后，随其所乐而度脱他们。）

```
为求声闻示现者，
当知是其最下笑，
应当知我中品笑，
为求辟支而示现。
马胜当知此上笑，
为诸天众授佛记，
我说此三解笑因，
所谓最下及中上。
善解世间胜导师，
而作微笑现瑞相，
佛知众生欲三乘，
愿乐求证于圣果。
为求声闻现笑者，
微笑光明从足没，
为求辟支所示现，
当知笑光入脐轮。
为受无上十力者，
其光从佛顶上入，
马胜汝今应当知，
微笑因缘有三种。
```
（大意：为求声闻者示现的，当知是最下品之笑；应当知道我的中品之笑，是为求辟支佛者而示现。马胜当知这上品之笑，是为诸天众授佛之记；我说这三种，解释笑的因缘，就是最下以及中品、上品。善解世间的殊胜导师作出微笑，显现瑞相，佛知道众生欲求三乘，愿乐求证圣果。为求声闻者现笑时，微笑的光明从足部隐没；为求辟支佛者所示现的，当知笑光入于脐轮；为授无上十力者之记，那光从佛的顶上入；马胜你现在应当知道，微笑的因缘有这三种。）

【按】“授佛记”之“授”，圣、圣乙本作“受”。“脐轮”之“脐”，圣、圣乙本作“齐”。

```
我向所现微笑光，
彼光于我顶上没，
当知先所现微笑，
悉为无上菩提记。
我今当更为汝说，
微笑复有三种因，
善哉马胜及大众，
一心静意俱谛听。
前现微笑为佛者，
其光即从顶上入，
有光少时住身腰，
须臾没者为辟支。
我现微笑放光明，
暂时在于足前住，
斯光随乘而变现，
当知此为声闻人。
```
（大意：我先前所现的微笑之光，那光在我顶上隐没，当知先前所现的微笑，都是为无上菩提授记。我现在当再为你宣说，微笑又有三种因，善哉马胜以及大众，一心静意共同谛听。先前所现的微笑若是为佛道，那光便从顶上入；有光少时停在身腰，须臾隐没的，是为辟支佛。我现出微笑放出光明，暂时在足前停住，这光随乘而变现，当知这是为声闻之人。）

【按】“先所现微笑”之“先”，宋、元、明、宫本作“光”。

```
今复更说微笑因，
马胜谛听有三种，
导师所放诸光明，
出已围绕于十力。
其光既出皆踈散，
还复速聚绕身腰，
渐渐转复更增广，
亦还右绕于如来。
有光初停后广大，
渐渐右绕于我身，
彼光悉遍世尊形，
与身俱等无有异。
其光庄严佛身相，
晖赫犹如真金聚，
牟尼所放微笑光，
当知此光记刹土。
有光出已犹如盖，
于上遍覆世尊身，
有光如花空中住，
其光照曜于导师。
彼光一切皆右旋，
三匝围绕如来身，
当知此光记寿命，
出世大智现斯瑞。
斯等三种微笑光，
善逝随根差别现，
马胜汝今应当知，
此是三种微笑因。
```
（大意：现在再说微笑之因，马胜谛听，有三种：导师所放的诸光明，放出之后围绕十力者。那光出来后都疏散，又迅速聚合，围绕身腰，渐渐又更加增广，也右绕如来。有的光起初停住，后来广大，渐渐右绕我身，那光遍满世尊之形，与身全然相等，没有差异。那光庄严佛的身相，辉赫犹如真金之聚，牟尼所放的这种微笑之光，当知此光是授记刹土。有的光放出后犹如宝盖，在上方遍覆世尊之身，有的光如花住于空中，那光照耀导师。那些光一切都右旋，三匝围绕如来之身，当知此光是授记寿命，出世大智者现出这种瑞相。这三种微笑之光，是善逝随众生根机差别而显现，马胜你现在应当知道，这是三种微笑之因。）

【按】“照曜”之“曜”，明本作“矅”。

```
世间导师所现相，
善知众生深信乐，
今于如来教法中，
汝等闻此得除疑。
是诸广果天众等，
其数满足有八亿，
广说微妙正法门，
各于异刹得成佛。
寿命具足无有量，
经由多劫住于世，
是故如来现斯瑞，
广大光明五种色。
此诸天众于过去，
三十有六僧祇劫，
常得值遇诸世尊，
亲承供养习诸善。
又复经于三十六，
阿僧祇劫广修行，
斯等大士住世间，
供养如来未曾倦。
思惟救度众生故，
数数勤修供养佛，
供养世尊应其宜，
悕求无上大菩提。
```
（大意：世间导师所现之相，是善知众生的深信乐欲，现在于如来教法中，你们听闻此说便得除疑。这些广果天众等，其数满足八亿，广说微妙的正法之门，各在不同的刹土得以成佛。寿命具足，没有限量，经过多劫住于世间，所以如来现出这瑞相，广大光明有五种颜色。这些天众在过去三十六阿僧祇劫中，常得值遇诸世尊，亲自承事供养，修习诸善。又再经过三十六阿僧祇劫广为修行，这些大士住于世间，供养如来，未曾疲倦。为了思惟救度众生，屡屡勤修供养佛，供养世尊，都合其所宜，希求无上大菩提。）

```
彼诸天众未来世，
当得作佛那罗延，
成妙牟尼功德山，
其劫号曰胜金幢。
是诸如来各自住，
清净庄严国土中，
彼佛同号日光轮，
具足无量功德聚。
一一如来各住世，
经于无量那由劫，
此诸善逝所集众，
无量无边不可数。
一一导师成佛时，
所有声闻弟子辈，
十力住经那由劫，
算数彼众不可尽。
若有算师悉共聚，
亦算彼众不能尽，
当时所有诸菩萨，
倍多于彼声闻众。
皆悉发心住佛乘，
愿得当成一切智，
于其清净国土中，
悉当成佛具十力。
```
（大意：那些天众在未来世，当得作佛，具那罗延之力，成就妙牟尼的功德之山，那劫号为胜金幢。这些如来各自住于清净庄严的国土中，那些佛同号日光轮，具足无量功德之聚。每一位如来各自住世，经过无量那由他劫，这些善逝所集之众，无量无边，不可计数。每一位导师成佛时，所有的声闻弟子，在十力者住世经那由他劫中，计数那些大众也数不尽。若有算师全都聚在一起，计算那些大众也算不尽，那时所有的菩萨，比那些声闻众更多一倍。他们都发心安住佛乘，愿得当成一切智，在那清净的国土中，都当成佛，具足十力。）

```
是诸菩萨所修行，
皆如本师无有异，
彼诸如来灭度后，
正法兴显久住世。
经于十二那由劫，
为诸佛子所护持，
此诸佛法炽盛时，
有发无上菩提心。
其数过于恒河沙，
皆悉勤修菩萨行，
彼诸善逝灭度已，
所有一切声闻众。
斯众皆悉得涅槃，
过于大海诸沙数，
如是彼诸佛正法，
具足兴显于世间。
饶益无量诸众生，
彼教如法大兴盛。
```
（大意：这些菩萨所修之行，都如本师，没有差异，那些如来灭度之后，正法兴盛显扬，久住于世。经过十二那由他劫，为诸佛子所护持，这些佛法炽盛之时，有人发无上菩提心，其数超过恒河沙，都勤修菩萨行。那些善逝灭度之后，所有一切声闻众，这些大众都得涅槃，超过大海的沙数，像这样那些佛的正法，具足兴盛，显扬于世间，饶益无量众生，那教法如法而大为兴盛。）

```
如是闻佛所说已，
一切大众皆信解，
必当得成佛世尊，
广能利益诸群生。
是时众会悉欣喜，
头面礼拜如来足，
无等恭敬于善逝，
如法供养天人师。
```
（大意：这样听闻佛所说之后，一切大众都信解，必当得成佛世尊，广能利益群生。这时众会都欢喜，头面礼拜如来之足，以无等的恭敬对待善逝，如法供养天人之师。）

```
是故踊跃发精进，
犹如有人救头燃，
常应亲近善知识，
勤修般若波罗蜜。
此是见实胜进行，
汝等比丘应修习，

功德如山利世间。
```
（大意：“所以应当踊跃发起精进，犹如有人救头上之火，常应亲近善知识，勤修般若波罗蜜。这是见实殊胜的进修之行，你们比丘应当修习，当成就无上的二足尊，功德如山，利益世间。”）
