# 《大宝积经》卷第三十九（菩萨藏会·如来不思议性品）

唐·三藏法师玄奘 奉诏译

## 菩萨藏会第十二之五

【按】本卷续《如来不思议性品》，说如来四无所畏与不思议大悲，相当于《佛说大乘菩萨藏正法经》（T0316）《如来不思议品》中的相应部分。

### 如来不思议性品第四之三

#### 八、如来不思议无畏

那时，佛告诉舍利子：“菩萨摩诃萨怎样对如来不思议无畏信受谛奉，心志清净，无惑无疑，倍加踊跃，深生欢喜，生起希奇之想？舍利子！如来、应、正等觉有四种不思议无畏。由于成就这四无畏，如来、应、正等觉在大众中自称我处于大仙尊位，作正狮子吼，转大梵轮，一切世间沙门、婆罗门、诸天、魔、梵，都不能如法而转。舍利子！什么名为四无所畏？

【按】“心志清净”之“志”，宫本作“至”。

#### 第一，正等觉无畏

“舍利子！如来、应、正等觉成就无上智力，在大众中自称我是正等觉者；这其中，诸天世间不见有谁能在如来面前立这样的论：‘你对于这法不是正等觉。’舍利子！为什么如来名为正等觉？舍利子！如来能对一切诸法平等正觉，没有不平等的：无论凡夫法、诸圣法、诸佛法、诸学法、无学法、独觉法、菩萨法，都平等平等；无论世间法、出世间法，有罪、无罪，有流、无流，有为、无为，这样的一切诸法，如来都能平等正觉，所以名为正等觉者。

“舍利子！什么名为平等之性？舍利子！诸见的自体与那空性，其性平等；诸相的自体与那无相，其性平等；三界的自体与那无愿，其性平等；生法的自体与那无生，其性平等；诸行的自体与那无行，其性平等；起法的自体与那不起，其性平等；贪性的自体与那无贪，其性平等；三世的自体与那真如，其性平等；无明、有爱的自体与明、解脱，其性平等；生死流转的自体与那寂静涅槃，其性平等。这样，舍利子！如来能对一切诸法平等正觉，所以如来名为正等觉。

“再者，舍利子！如来的这一无畏不可思议，又以大悲为方便，是真如平等、真性如性、非不如性、不变异性、无覆藏性、无怖畏性、无退屈性、无违诤性，由于这样的缘故，光显大众，能令大众悦豫，遍身怡适，心生净信，踊跃欢喜。舍利子！世间众生没有谁能对如来的无畏生起违诤。为什么？因为如来的无畏不可与之诤论。它如性平等，处于法界之性，流布遍满一切世界之中，无能违害。舍利子！如如来的无畏对于一切甚深微细、难可了知之法能正等觉，如来也这样安住于大悲，以种种言音、种种法门为那些有情开示妙法；若能依此修习远离之行，便能迅速穷尽苦际。若有含识实际上不是大师而自称大师，不是正等觉而自称正等觉，以如来不思议无畏的缘故，都被映夺，令那些众生的傲慢摧碎，逃奔远避。舍利子！如来的无畏不可思议，无边无际，譬如虚空，若有人想求如来无畏的边际，无异于有人求虚空的边际。舍利子！诸菩萨摩诃萨听闻如来宣说这不思议无畏之后，信受谛奉，清净无疑，欢喜踊跃，生起希奇之想。舍利子！这名为第一正等觉无畏。由于如来成就这一无畏，在大众中作正狮子吼，转大梵轮，乃至是一切世间所不能转的。

【按】“悦豫”之“豫”，宋、宫本作“预”。“如如来无畏”，圣本作“如是如来无畏”。“难可知法”之“难”，《大正藏》作“杂”，宫、圣本及高丽藏作“难”，今从之。

#### 第二，流尽无畏

“再者，舍利子！如来、应、正等觉成就无上智力，在大众中自称：我现在诸流已尽；这其中，诸天世间没有谁能在如来面前如法立论：‘你还有这样的诸流未尽。’舍利子！什么是如来流尽之性？舍利子！如来对于欲流，心善解脱，因为永断一切贪行习气；如来对于有流，心善解脱，因为永断一切瞋行习气；如来对于无明流，心善解脱，因为永断一切痴行习气；如来对于见流，心善解脱，因为永断一切烦恼行习气。以这因缘，所以说如来诸流已尽。

“舍利子！这样说法是依于世俗，不是依于胜义；在胜义中，没有一法住于圣智之前，是可遍知、可永断、可修习、可作证的。为什么？舍利子！所说的尽，是从来无不尽，其性究竟是尽，不是由于对治而说名为尽，而是如实之性的尽。因为如实之性已尽，所以无法可尽；因为无法可尽，所以就是无为；因为是无为，所以无生无灭，也没有住。所以说：如来出世或不出世，法性常住，法界常住。就在其中圣智慧运转，虽然这样运转，却无转无还。舍利子！由于这一法门，所以没有诸流，也没有流尽可得。这样，如来安住于大悲之后，为诸有情宣说流尽之法。

“再者，舍利子！如来的这一无畏不可思议，又以大悲为方便，是真如平等、真性如性、非不如性、不变异性、无覆藏性、无怖畏性、无退屈性、无违诤性，由于这样的缘故，光显大众，能令大众悦豫，遍身怡适，心生净信，欢喜踊跃。舍利子！世间众生没有谁能对如来的无畏生起违诤。为什么？因为如来的无畏不可与之诤论，真如平等，处于法界之性，流布遍满一切世界之中，无能违害。这样不可思议、无量无数、无有边际的妙法成就，由于如来以大悲熏心，为众生宣说流尽之法，想令他们永断那些诸流。舍利子！如来的无畏不可思议，无边无际，譬如虚空，若有人想求如来无畏的边际，无异于有人求虚空的边际。舍利子！这些菩萨摩诃萨听闻如来宣说这不思议无畏之后，信受谛奉，清净无疑，乃至生起希奇之想。舍利子！这名为第二流尽无畏。由于成就这一无畏，如来在大众中作正狮子吼，自称我处于大仙尊位，转大梵轮，乃至是一切世间所不能转的。

#### 第三，说障法无畏

“再者，舍利子！如来、应、正等觉成就无上智力，在大众中这样唱言：‘我说障法决定能障。’这其中，诸天世间没有谁能在如来面前如法立论：‘你说这样的障法不能为障。’舍利子！什么名为能障碍之法？舍利子！是说有一法能为障碍。是哪一法？就是心不清净。又有二法能为障碍，就是无惭、无愧。又有三法能为障碍，就是身恶行、语恶行、意恶行。又有四法能为障碍：由于贪欲而行所不应行，由于瞋恚而行所不应行，由于愚痴而行所不应行，由于怖畏而行所不应行。又有五法能为障碍，就是杀生、不与取、欲邪行、妄语、饮酒。又有六法能为障碍，就是不恭敬佛菩提、不恭敬法、不恭敬僧、不恭敬律仪、不恭敬三摩地、不恭敬建立施设。又有七法能为障碍，就是慢、胜慢、胜上慢、增上慢、邪慢、下慢、我慢。又有八法能为障碍。是哪八法？就是邪见、邪思、邪语、邪业、邪命、邪勤、邪念、邪三摩地。又有九法能为障碍。是哪九法？就是：对我自身在过去、未来、现在世作不饶益而生恼害之事；对我所爱的人在过去、未来、现在世作不饶益而生恼害之事；对我所不爱的人在过去、未来、现在世作饶益而生恼害之事。又有十法能为障碍，就是十不善道。所以，略说这十种法能为障碍；为了止息、寂静、永断这样的障碍之法，如来为诸有情敷演正法。

【按】“我所不爱于去来今而作”之“而”，宋、明本作“世”；“饶益”，宋、明本作“不饶益”。

“舍利子！乃至一切与违罪作意相应的诸结，若由于诸法而住于爱味之观，与颠倒相应，违背出离，爱见执著，对诸有味著，有所依事的身语意业，那一切相，如来了知都是障碍；了知之后，如实宣说为能障碍之法。

【按】“违罪作意”之“罪”，宋、元、明、宫、圣本作“理”，即“违理作意”。

“再者，舍利子！如来的这一无畏不可思议，以大悲为方便，是真如平等、真性如性、非不如性、无变异性、无覆藏性、无怖畏性、无退屈性、无违诤性，由于这样的缘故，光显大众，能令大众悦豫，遍身怡适，心生净信，踊跃欢喜。舍利子！世间众生没有谁能对如来的无畏生起违诤。为什么？因为如来的无畏不可与之诤论。它如性平等，处于法界之性，流布遍满一切世界之中，无能违害。这样无量无数、不可思议、无与等者、不可宣说的妙法成就，而如来以大悲熏心，为诸有情宣说障碍之法，想令他们止息、寂静、永断那些障法。舍利子！如来的无畏不可思议，无边无际，譬如虚空，若有人想求如来无畏的边际，无异于有人求虚空的边际。舍利子！这些菩萨摩诃萨听闻如来宣说这不思议无畏如同虚空之后，信受谛奉，清净无疑，乃至生起希奇之想。舍利子！这名为第三说障法无畏。由于如来成就这一无畏，在大众中作正狮子吼，转大梵轮，乃至是一切世间所不能转的。

#### 第四，说圣出离道无畏

“再者，舍利子！如来、应、正等觉成就无上智力，在大众中这样唱言：‘我说圣出离，所修的能正尽苦之道；若诸有情修习此道，必定出离。’这其中，诸天世间没有谁能在如来面前如法立论：‘你所说的道不能出离。’舍利子！什么名为圣出离道？舍利子！就是一正趣之道，能令众生毕竟清净。又有二法能令众生毕竟出离，就是奢摩他以及毘钵舍那。又有三法能令出离，就是空、无相、无愿解脱之门。又有四法能令出离，就是缘身生念、缘受生念、缘心生念、缘法生念。又有五法能令出离，就是信根、勤根、念根、三摩地根、慧根。又有六法能令出离，就是念佛、念法、念僧、念戒、念舍、念天。又有七法能令出离，就是念等觉支、择法等觉支、勤等觉支、喜等觉支、安息等觉支、三摩地等觉支、舍等觉支。又有八法能令出离，就是圣八支道：正见、正思惟、正语、正业、正命、正勤、正念、正三摩地。又有九种悦的根本法能令出离，就是悦、喜、安息、乐、三摩地、如实智见、厌、离欲、解脱。又有十法能令出离，就是十善业道。这样，如来为诸有情如实开示圣出离之行。

【按】“开示圣出离行”，《大正藏》作“开示离圣出行”，CBETA依高丽藏作“圣出离行”，今从之。

“舍利子！乃至一切所有正善的菩提分法，或与戒聚相应，或与三摩地聚、慧聚、解脱聚、解脱智见聚相应，或与圣谛相应，这样名为能出离之行。又，舍利子！能出离的，就是所谓正行。所说的正行，在这法中没有一法，或增或减，或来或去，或取或舍。为什么？不是行正行者行于一种觉。若能如实知见诸法都是不二之性，这便名为圣出离之行。

原文：“非行正行者行一种觉”（大意：不是行正行者行于一种觉。所指未详，存疑。）

“舍利子！如来的这一无畏不可思议，以大悲为方便，是真如平等、真性如性、非不如性、无变异性、无覆藏性、无怖畏性、无退屈性、无违诤性，由于这样的缘故，光显大众，能令大众悦豫，遍身怡适，心生净信，踊跃欢喜。舍利子！世间众生没有谁能对如来的无畏生起违诤。为什么？因为如来的无畏不可与之诤论。它如性平等，处于法界之性，流布遍满一切世界之中，无能违害。这样的圣出离之行，是无量无数、不可思议、无与等者、不可宣说的妙法成就，而如来以大悲熏心，为众生开示演说圣出离之行。若有众生如实解了，修行正道，必能出离，迅速穷尽诸苦。舍利子！如来的无畏无边无际，譬如虚空，若有人想求如来无畏的边际，无异于有人求虚空的边际。舍利子！诸菩萨摩诃萨听闻这如来不思议无畏之后，信受谛奉，清净无疑，乃至生起希奇之想。舍利子！这名为第四说圣出离道无畏。由于如来成就这一无畏，在大众中作正狮子吼，转大梵轮，一切世间沙门、婆罗门、诸天、魔、梵都不能如法而转。舍利子！如来这样的四种无畏无边无际，譬如虚空，一切众生都不能穷尽其边际。诸菩萨摩诃萨听闻如来这样的不思议无畏如同虚空之后，信受谛奉，清净无疑，倍加踊跃，深生欢喜，生起希奇之想。”

【按】“非不如性”之“如”，《大正藏》作“知”，CBETA依高丽藏作“如”，今从之。

那时世尊想重宣此义，而说颂道：

```
自然正觉悟，诸法平等性，
故遍见如来，说名正等觉。
若诸凡夫法，及学无学法，
最胜独觉法，佛法悉平等。
一切世间法，及诸出世法，
善不善不动，涅槃路平等。
若空若无相，若离诸愿乐，
无生无有为，悉见平等性。
觉平等性已，如所应宣说，
解脱诸有情，大牟尼无畏。
已解脱三有，复开示解脱，
诸人天圣尊，显第二无畏。
```
（大意：自然正觉觉悟诸法平等之性，所以遍见的如来名为正等觉。无论凡夫之法，以及有学、无学之法，最胜的独觉之法，与佛法都是平等的。一切世间法以及诸出世法，善、不善、不动，与涅槃之路都平等。或空、或无相、或离诸愿乐，无生、无有为，都见其平等之性。觉悟平等性之后，如其所应而宣说，令诸有情解脱，这是大牟尼的无畏。自己已解脱三有，又开示解脱之道，诸人天的圣尊，显示第二种无畏。）

```
最胜觉障法，习不证解脱，
非清净下劣，不具诸羞愧。
未甞有身护，及以语意护，
贪瞋痴怖畏，害命损他财，
行邪欲妄语，饮酒不恭敬，
七慢八邪支，悉非解脱处，
九恼害多过，十不善业道，
不如理思惟，愚痴无解脱。
颠倒修诸行，执虚妄放逸，
佛知说障法，是第三无畏。
```
（大意：最胜者觉知障法：修习它而不能证得解脱；不清净而下劣，不具种种羞愧；从未有身的守护，以及语与意的守护；贪、瞋、痴、怖畏，害命、损他财物，行邪欲、妄语，饮酒、不恭敬，七慢、八邪支，都不是解脱之处；九种恼害多有过患，十不善业道，不如理思惟，愚痴而无解脱；颠倒地修种种行，执著虚妄而放逸——佛知道这些而宣说为障法，这是第三种无畏。）

```
清净门无量，修习证菩提，
佛自然通达，说趣甘露法。
乃至诸所有，众多妙善法，
助清净菩提，最胜所称赞。
若善修习已，不证诸解脱，
必无有是处，十力者诚言。
若如理思惟，息广大烦恼，
观诸法平等，善修习圣行。
不执著诸相，是法及非法，
解脱诸忧怖，大净者所说。
善知种种法，虚廓如净空，
又如幻如梦，解脱诸有海。
若放逸造业，轮回诸有趣，
大悲愍众生，欲令证解脱。
十力牟尼尊，处生死化法，
是第四无畏，清净等虚空。
```
（大意：清净之门无量，修习而证菩提，佛自然通达，宣说趣向甘露之法。乃至一切所有的众多妙善之法，资助清净菩提，为最胜者所称赞。若善加修习之后，而不证得诸解脱，必定无有是处，这是十力者的诚实之言。若如理思惟，止息广大烦恼，观察诸法平等，善加修习圣行，不执著于诸相，无论是法与非法，便解脱种种忧怖，这是大净者所说。善知种种法虚廓如同净空，又如幻如梦，便解脱诸有之海。若放逸造业，轮回于诸有趣中，大悲怜悯众生，想令他们证得解脱。十力牟尼尊处于生死中教化说法，这是第四种无畏，清净等同虚空。）

“这样，舍利子！这名为如来不思议无畏，菩萨摩诃萨信受谛奉，清净无疑，乃至生起希奇之想。”

#### 九、如来不思议大悲

那时，佛告诉舍利子：“菩萨摩诃萨怎样对如来不思议大悲信受谛奉，乃至生起希奇之想？舍利子！诸佛如来的大悲常转。为什么？因为诸佛如来不舍一切众生，在一切时为了成熟一切众生，应当知道大悲常起不息。舍利子！如来的这大悲是这样无量，这样不可思议，这样无等等，这样无边，这样不可说，这样猛利，这样久远，随着诸众生，乃至如来一切的语业，对这大悲也难以宣说。为什么？犹如如来证得菩提不可思议，如来对于众生发起大悲也是这样不可思议。

#### 无根无住

“舍利子！如来怎样证得菩提？舍利子！由于如来入于这样的无根无住，所以证得菩提。舍利子！什么是根？什么是住？有身为根，虚妄分别为住。如来对这二法平等解了，所以说，由于如来入于无根无住，所以证得阿耨多罗三藐三菩提。一切众生不能解了这样的二法，如来对他们发起大悲：‘我现在定当开示，令他们解了这样的无根无住之法。’

【按】“犹如来入”之“犹”，宋、元、明、宫、圣本作“由”，今依之译作“由于”。

#### 寂静二法

“再者，舍利子！菩提，其性寂静。什么名为寂静二法？舍利子！于内为寂，于外为静。为什么？眼性是空，离于我与我所；这样，耳、鼻、舌、身、意，意性是空，离于我与我所；若这样了知，名之为寂。如实了知眼性空之后，不趣向于色，乃至如实了知意性空之后，不趣向于法；若这样了知，名之为静。一切众生对于这寂静二法不能解了，如来对他们发起大悲：‘我现在定当开示，令他们解了这样的寂静二法。’

#### 自性清净

“再者，舍利子！我证得的菩提自性清净。什么名为自性清净？舍利子！菩提之性，其体无有染污；菩提之性与虚空相等；菩提之性就是虚空之性；菩提之性同于虚空；菩提与虚空平等平等，究竟其性清净。愚痴凡夫不觉知这样的自性清净，而被客尘烦恼所染污。一切众生对于这自性清净不能解了，如来对他们发起大悲：‘我现在定当开示，令他们解了这样的自性清净。’

#### 无入无出

“再者，舍利子！我证得的菩提无入无出。什么名为入出二法？舍利子！所说的入，名为执著诸法；所说的出，名为不执著诸法。如来明见无入无出的平等法性，犹如如来明见无远也无彼岸。为什么？因为一切法之性离于远与彼岸，能证得这法，所以名为如来。一切众生对于这无入无出的法性不能觉了，如来对他们发起大悲：‘我现在定当开示，令他们觉了这样的无入无出之法。’

原文：“犹如如来明见无远及无彼岸。何以故？以一切法性离远及彼岸故”（大意：犹如如来明见无“远”也无彼岸，因为一切法之性离于“远”与彼岸。“远”所指未详，存疑。）

#### 无相无境

“再者，舍利子！我证得的菩提无相无境。什么名为无相无境？舍利子！不得眼识，名为无相；不观于色，名为无境；乃至不得意识，名为无相；不观于法，名为无境。舍利子！无相无境是众圣所行。是什么所行？就是在三界中的愚痴凡夫，因为不能行于众圣所行，所以对于无相无境不能觉了。如来对他们发起大悲：‘我现在定当开示，令他们觉了这样的无相无境之法。’

#### 三世平等，三相轮断

“再者，舍利子！所说的菩提，不是过去、未来、现在，三世平等，三相之轮已断。什么名为三相轮断？舍利子！对于过去世，心无顾念流转；对于未来世，识无趣向；对于现在世，意无起作。这心意识无有安住，不分别过去，不执著未来，不戏论现在。一切众生不能觉悟三世平等之性、三轮清净，如来对他们发起大悲：‘我现在定当开示，令他们觉悟这样的三世三轮平等清净。’

#### 无为无性

“再者，舍利子！我证得的菩提无为无性。为什么名为无为无性？舍利子！这菩提之性不是眼识所识，乃至不是意识所识。所说的无为，是无生、无灭，也没有住，三相永离，所以名为无为。舍利子！了知无为之性，应当觉知有为。为什么？因为诸法的自性就是无性；所说的无性，就是其体无二。一切众生不能觉悟这无性无为，如来对他们发起大悲：‘我现在定当开示，令他们觉悟这样的无性无为。’

#### 无差别迹

“再者，舍利子！我证得的菩提是无差别之迹。为什么名为无差别之迹？舍利子！真如与法性二者都名为迹，其性无别异、其性无安住，名为无差别。诸法实际名之为迹，其性无动摇名为无差别。诸法空性名之为迹，其性不可得名为无差别。诸法无相名之为迹，其性不可寻名为无差别。诸法无愿名之为迹，其性无发起名为无差别。无众生之性名之为迹，其体性即无，名为无差别。虚空之相名之为迹，其性不可得名为无差别。其性无生，这名为迹；其性无灭，名为无差别。其性无为，这名为迹；其性无行无住，名为无差别。作为菩提之相，这名为迹；其性寂静，名为无差别。作为涅槃之相，这名为迹；其性无生，名为无差别。舍利子！一切众生不能觉悟无差别之迹，如来对他们发起大悲：‘我现在定当开示，令他们觉悟这样的无差别之迹。’

【按】“性无行住”之“住”，宫、圣本作“往”。

#### 非身心所证

“再者，舍利子！所说的菩提，不可以身证，不可以心证。为什么？身之性无知，没有作用，譬如草木、墙壁、琢石之光；心之性也是这样，譬如幻事、阳焰、水中之月。若能这样觉悟身心，这名为菩提。舍利子！只是以世俗言说假名为菩提，菩提的真实之性不可言说：不可以身得，不可以心得，不可以法得，不可以非法得，不可以真实得，不可以非真实得，不可以谛得，不可以妄得。为什么？因为菩提之性离于言说，也离于一切诸法之相。又，因为菩提没有形相，用通常的言说，譬如虚空没有形状处所，所以不可说。舍利子！如实寻求，一切诸法都无言说。为什么？因为诸法之中没有言说，言说之中也没有诸法。一切众生不能觉悟这样的诸法理趣，如来对他们发起大悲：‘我现在定当开示诸法理趣，令他们觉悟这样的谛实义旨。’

原文：“又以菩提无有形相用通言说”（大意：又，因为菩提没有形相，用通常的言说。“用通言说”所指未详，存疑。）

#### 无取无藏

“再者，舍利子！所说的菩提无取无藏。什么名为无取无藏？舍利子！了知眼，所以名为无所取；不观色，所以名为无藏。舍利子！如来证得这无取无藏的菩提，所以不取于眼，不藏于色，不住于识，乃至不取于意，不藏于法，不住于识。虽不住于识，却能了知一切众生心之所住。怎样了知？就是众生的心住于四法。是哪四法？一切众生的心住于识，心住于受，心住于想，心住于行。如来这样如实了知住与不住，一切众生不能觉悟无住的实际，如来对他们发起大悲：‘我现在定当开示，令他们觉悟这样的无住实际之法。’

#### 菩提即空

“再者，舍利子！所说的菩提，是空的异名。由于空是空的，所以菩提也是空；由于菩提是空，所以诸法也是空。所以如来如其空性觉悟一切法，不是由于空而觉悟诸法的空性，而是由于一理趣之智而觉悟诸法之性空。空与菩提，其性无二；由于无二，所以不可说这是菩提、这是空性；若有二，便可以说这是菩提、这是空性。因为法无二，没有二相，无名、无相、无行，毕竟不行，也不现行。所说的空，是远离取执，在胜义谛中无法可得，由于其性空，所以说名为空。如说太虚名为虚空，而太虚之性不可言说；这样，空法说名为空，而那空性不可言说。这样悟入：诸法实际上没有名，只是假立名而说，然而诸法之名无方所、无处所；如名诠表诸法，这法无方所、无处所，也是这样。如来了知一切诸法从本以来无生无起，这样了知之后而证解脱，然而其真实之性无缚无脱。诸痴凡夫不能觉悟这菩提之性，如来对他们发起大悲：‘我当开示，令他们觉悟这样的菩提真实之性。’

#### 等与不等

“再者，舍利子！菩提之性与太虚相等，然而太虚之性无等与不等；菩提也是这样，无等与不等，犹如诸法之性没有真实，不可说是平等或不平等。这样，舍利子！如来觉悟一切诸法其性平等，没有不平等；如实觉悟没有少许之法可以是平等或不平等，这样，如来的如实智量穷尽诸法之量。什么名为如实智呢？就是知道诸法本无而生，生后离散，无主而生，无主而散，或生或散，随众缘而转，其中没有一法或转、或还、或随转，所以说如来为断诸径而说微妙之法。一切众生不能觉悟断诸径之法，如来对他们发起大悲：‘我当开示，令他们觉悟这样的断诸径之法。’

原文：“故说如来为断诸径说微妙法”（大意：所以说如来为断诸径而说微妙之法。“诸径”所指未详，存疑。）

#### 如句

“再者，舍利子！所说的菩提，就是如句。什么名为如句之相？舍利子！如菩提之相，诸色也是这样，同那真如，无有退还而不遍至；受、想、行、识也是这样，如那真如，无不遍至。舍利子！如菩提之相同那真如，四大之性也是这样，如那真如，无有退还而不遍至。如菩提之性同那真如，眼界、色界以及眼识界，乃至意界、法界以及意识界也是这样。如菩提之相只是假施设，一切诸法蕴、界、处等只是假施设，也是这样。知道这样的相，名为如句。又，舍利子！如来一切如实觉悟，不颠倒觉，犹如前际，中际与后际也是这样。为什么？前际无生，后际无趣，中际远离，这样一切名为如句；这样一句一切也是这样，这样一切一句也是这样，不是在如性中有一性、多性可得。一切众生不能觉悟这如句，如来对他们发起大悲：‘我当开示，令他们觉悟这样的真如法句。’

#### 入行与入无行

“再者，舍利子！所说的菩提，名为入于行以及入于无行。什么名为行与无行？舍利子！发起善法，名之为行；一切诸法即不可得，名为无行。住于不住之心，名之为行；无相三摩地解脱门，名为无行。舍利子！所说的行，是称量、算数、观察于心；所说的无行，是超过称量等。什么名为超过称量等？因为在一切处都没有诸识的作用之业。舍利子！所说的行，是说在此处观察有为；所说的无行，是说在此处证得无为。愚痴凡夫不能觉悟入行与非行，如来对他们发起大悲：‘我当开示，令他们觉悟这样的入行非行之法。’

【按】“入行非行”之“行”，圣本作“于”。

#### 无流无取

“再者，舍利子！菩提无流无取。什么名为无流无取？舍利子！离于四流之性，所以名为无流。是哪四流？离欲流之性，离有流之性，离无明流之性，离见流之性。舍利子！离于四取之性，所以名为无取。是哪四取？离欲取之性，离有取之性，离见取之性，离戒取之性。舍利子！这样的四取都由于无明，而被盲暗、爱水的城池所拥闭，由于执著于我而受蕴、界、处。如来在其中如实了知，于我取的根本自证清净，也令众生证得清净。舍利子！如来既已证得这清净，所以在诸法中无所分别。为什么？舍利子！由于这分别而生起不如理思惟；这只与如理相应，所以不生起无明；不生起无明，所以不能发起十二有支；若不发起十二有支，这就是无生；若是无生，这就是决定；若是决定，这就是了义；若是了义，这就是胜义；若是胜义，就是无人之义；无人之义，就是不可说之义；不可说之义，就是缘起之义；诸缘起之义，就是法义；诸法之义，就是如来之义。舍利子！若能这样观察缘起，就是观法；若观法，就是观如来。这样观察的人，离开真如之外没有所观。这其中为什么有所有呢？就是相与缘。这二法若能观察为无相无缘，就是真实之观。如来觉悟这样的诸法平等，所以平等；愚痴凡夫不能觉悟这无流无取之性，如来对他们发起大悲：‘我当开示，令他们觉悟这样的无流无取之性。’

原文：“由此分别起不如理思惟，此但如理相应故不起无明”（大意：由于这分别而生起不如理思惟；这只与如理相应，所以不生起无明。前后两句所指不甚相应，存疑。）

#### 清净无垢无执

“再者，舍利子！菩提，其性清净、无垢、无执。什么名为清净、无垢以及无执？舍利子！因为空，所以清净；因为无相，所以无垢；因为无愿，所以无执。又，舍利子！因为无生，所以清净；因为无作，所以无垢；因为无取，所以无执。又，舍利子！因为自性，所以清净；因为遍净，所以无垢；因为光洁，所以无执。又，舍利子！因为无戏论，所以清净；因为离戏论，所以无垢；因为戏论寂静，所以无执。又，舍利子！因为真如，所以清净；因为法界，所以无垢；因为实际，所以无执。又，舍利子！因为虚静，所以清净；因为无碍，所以无垢；因为空寂，所以无执。又，舍利子！因为对内遍知，所以清净；因为对外不行，所以无垢；因为内外不可得，所以无执。又，舍利子！因为对蕴遍知，所以清净；因为是界的自体，所以无垢；因为处的损减，所以无执。又，舍利子！因为过去的尽智，所以清净；因为未来的无生智，所以无垢；因为现在的法界住智，所以无执。

“舍利子！这样的清净、无垢、无执之性，同趣于一句；所说的一句，就是寂静之句。诸寂静就是极寂静，极寂静就是遍寂静，遍寂静名为大牟尼。舍利子！犹如太虚，菩提也是这样；如菩提之性，诸法也是这样；如诸法之性，真实也是这样；如真实之性，国土也是这样；如国土之性，涅槃也是这样。所以说涅槃与诸法平等，也名为究竟；因为是无边际之相，所以没有对治；因为离于对治之相，所以这样的诸法本来清净、无垢、无执。舍利子！如来对于这色与无色等一切诸法，如实觉悟，观察有情之性，游戏于清净、无垢、无执之中，发起大悲：‘我现在定当开示，令他们觉悟这样的清净、无垢、无执之法。’

#### 大悲任运常转

“再者，舍利子！如来这样不可思议的大悲，不由功用，任运常转，流布遍满十方世界，无有障碍。舍利子！如来的大悲不可思议，无边无际，犹如虚空，若有人想求如来大悲的边际，无异于有人求虚空的边际。舍利子！这些菩萨摩诃萨听闻如来不思议大悲同于虚空之后，信受谛奉，清净无疑，乃至生起希奇之想。”那时世尊想重宣此义，而说颂道：

```
诸佛证菩提，无根无所住，
如佛所证已，为诸众生说。
诸佛证菩提，寂静极寂静，
观眼等内空，色等外空性。
有情不觉悟，寂静极寂静，
如来知句义，于彼起大悲。
菩提性光洁，清净等虚空，
是众生不了，于彼起大悲。
诸佛证菩提，无去来取舍，
是众生不了，于彼起大悲。
诸佛证菩提，无相无境界，
众圣之所行，非愚夫所履。
诸凡夫不知，虽知不明达，
如来于彼类，兴起于大悲。
```
（大意：诸佛证得菩提，无根，无所住，如佛所证之后，为众生宣说。诸佛证得菩提，寂静、极寂静，观察眼等内空，色等外空之性。有情不能觉悟寂静、极寂静，如来知道这句义，对他们生起大悲。菩提之性光洁，清净等同虚空，这些众生不能了知，对他们生起大悲。诸佛证得菩提，无去无来，无取无舍，这些众生不能了知，对他们生起大悲。诸佛证得菩提，无相、无境界，是众圣所行，不是愚夫所履。诸凡夫不知道，虽然知道也不明达，如来对那一类人，兴起大悲。）

```
无为之自性，无生亦无灭，
于彼亦无住，三轮长解脱。
愚夫不能觉，诸有为自性，
于彼起大悲，开如是理趣。
菩提非身证，亦不由心证，
身自性无知，心如幻事等。
愚夫不能觉，身心自体性，
于彼起大悲，开如是妙理。
诸佛自然证，广大胜菩提，
安坐树王下，观察含灵性。
登上生死轮，循环种种趣，
如来见彼已，兴猛厉大悲。
```
（大意：无为的自性，无生也无灭，于其中也无所住，三轮长久解脱。愚夫不能觉知诸有为的自性，对他们生起大悲，开示这样的理趣。菩提不是以身证得，也不由心证得，身的自性无知，心如幻事等。愚夫不能觉知身心的自体之性，对他们生起大悲，开示这样的妙理。诸佛自然证得广大殊胜的菩提，安坐在树王之下，观察含灵之性：他们登上生死之轮，循环于种种诸趣，如来见到他们之后，兴起猛厉的大悲。）

```
憍慢之所坏，见网恒缠裹，
于苦生乐想，无常起常想。
计净我众生，命者见所坏，
如来观彼已，兴猛厉大悲。
一切众生性，覆障于痴膜，
无有慧光明，如重云掩日。
如来见彼已，兴猛厉大悲，
以无垢智光，当为彼明照。
既入诸恶趣，常迷失正道，
或堕地狱趣，畜生鬼趣中。
过去佛已知，导开前正路，
今佛见彼已，兴猛厉大悲。
佛知一切法，真如及实性，
清净等虚空，证成真解脱。
诸众生不知，如是净妙法，
如来见彼已，兴猛厉大悲。
```
（大意：被憍慢所败坏，被见网恒常缠裹，对苦生起乐想，对无常生起常想，计执净、我、众生、命者，被这些见所败坏，如来观察他们之后，兴起猛厉的大悲。一切众生之性，被痴膜所覆障，没有智慧的光明，如浓云遮掩太阳；如来见到他们之后，兴起猛厉的大悲，以无垢的智慧之光，当为他们明照。他们既已进入诸恶趣，常迷失正道，或堕入地狱趣，或在畜生、鬼趣之中；过去佛已经知道，为他们开导前面的正路，如今佛见到他们之后，兴起猛厉的大悲。佛知一切法的真如以及实性，清净等同虚空，证成真实的解脱；诸众生不知道这样清净美妙之法，如来见到他们之后，兴起猛厉的大悲。）

“这样，舍利子！这名为如来不思议大悲。诸菩萨摩诃萨听闻这不可思议大悲之后，信受谛奉，清净无疑，倍加踊跃，深生欢喜，生起希奇之想。”
