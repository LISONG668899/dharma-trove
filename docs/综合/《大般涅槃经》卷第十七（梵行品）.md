# 《大般涅槃经》卷第十七（梵行品）

北凉·天竺三藏昙无谶 译　刘宋·沙门慧严等 依《泥洹经》再治

## 梵行品之第四

### 阿阇世王弑父生疮

那时王舍大城的阿阇世王，性情凶恶，喜好杀戮，口具四种恶业，贪、恚、愚痴，其心炽盛；只见现在，不见未来，全以恶人作为眷属。因为贪著现世五欲之乐，父王无辜，他却横加逆害。

害父之后，心中生起悔恨焦热，身上脱去璎珞，不再享用伎乐。因为心中悔恨焦热，遍体生疮，那疮臭秽，不可靠近。他随即自念：“我现在这身已受花报，地狱的果报将近不远了。”

那时他的母亲，名叫韦提希，用种种药为他涂敷，那疮却越来越重，没有减轻。王就对母亲说：“这样的疮是从心而生，不是四大所起。若说众生中有能治的，没有这样的道理。”

### 六臣荐六师

#### 月称荐富兰那

当时有一位大臣，名叫月称，来到王所，站在一旁，说：“大王为什么愁苦憔悴，面容不悦？是身痛，还是心痛？”

王回答大臣说：“我现在身心怎能不痛？我父无辜，我却横加逆害。我曾从智者那里听到这样的道理：世间有五种人不能脱离地狱，就是犯五逆罪的人。我现在已有无量无边阿僧祇的罪，身心怎能不痛？又没有良医能治我的身心。”

大臣说：“大王，不要太过愁苦。”就说偈：

```
若常愁苦，愁遂增长，如人喜眠，眠则滋多，
贪淫嗜酒，亦复如是。
```

（大意：若常常愁苦，愁苦就越来越增长；如人喜欢睡觉，睡得就越来越多；贪淫嗜酒，也是这样。）

“如王所说，世间有五种人不能脱离地狱，谁去见过而回来告诉大王的？所谓地狱，只是世间多智之人的说法。如王所说，世间没有良医能治身心，现在有一位大医，名叫富兰那，一切知见，得自在定，究竟修习清净梵行，常为无量无边众生演说无上涅槃之道。他为弟子们说这样的法：没有黑业，没有黑业之报；没有白业，没有白业之报；没有黑白业，没有黑白业之报；没有上业以及下业。这位大师现在就在王舍城中，唯愿大王屈驾前往，可以让这位大师为您治疗身心。”

当时王回答说：“若真能这样灭除我的罪，我就归依他。”

#### 藏德荐末伽梨拘舍离子

又有一位大臣，名叫藏德，又来到王所，说：“大王，为什么面貌憔悴，嘴唇干焦，声音微弱，犹如胆怯的人见到大怨敌，脸色惶惧变异？有什么苦？是身痛，还是心痛？”

王就回答说：“我现在身心怎能不痛？我愚痴盲目，没有智慧之眼，亲近诸恶友，与他们亲善，听从提婆达多这恶人的话，对正法之王横加逆害。我过去曾听智者说偈：

```
若于父母，佛及弟子，生不善心，起于恶业，
如是果报，在阿鼻狱。
```

（大意：若对父母、佛以及佛弟子生起不善之心，造作恶业，这样的果报就在阿鼻地狱。）

“因为这件事，我现在心中恐怖，生起大苦恼，又没有良医来救治。”

大臣又说：“唯愿大王暂且不要愁怖。法有两种：一是出家之法，二是王法。王法是说，害其父而王其国土，虽说是逆，其实无罪。如迦罗罗虫，必须破坏母腹，然后才得出生，其生法就是这样，虽然破坏母身，其实也无罪；骡子怀孕等也是这样。治国之法，按法理应当如此，虽然杀害父兄，其实无罪。出家之法，乃至杀蚊蚁也有罪。唯愿大王放宽心意，不要愁苦。为什么呢？

```
若常愁苦，愁遂增长，如人喜眠，眠则滋多，
贪淫嗜酒，亦复如是。
```

“如王所说，世间没有良医能治身心，现在有一位大师，名叫末伽梨拘舍离子，一切知见，怜悯众生犹如赤子，已离烦恼，能拔众生三毒利箭。一切众生对于一切法不知、不见、不觉，唯有这一人独自知、见、觉。这位大师常为弟子说这样的法：一切众生的身体有七分。哪七分？地、水、火、风、苦、乐、寿命。这七法不是变化所成，不是造作所成，不可毁害，如伊师迦草；安住不动，如须弥山；不舍不作，犹如乳酪；各不相争，无论是苦是乐、是善是不善。投以利刀，也无所伤害。为什么呢？七分之间是空的，没有妨碍，所以命也不受伤害。为什么呢？没有害者以及死者，无作无受，无说无听，没有念者以及教者。他常说这法，能令众生灭除一切无量重罪。这位大师现在就在王舍大城，唯愿大王前往他那里，大王若见到他，众罪就会消灭。”

当时王回答说：“若真能这样除灭我的罪，我就归依他。”

#### 实得荐删阇耶毗罗胝子

又有一位大臣，名叫实得，又来到王所，就说偈：

```
大王何故，身脱璎珞，首发蓬乱，乃至如是，
王身何故，战栗不安，犹如猛风，吹动花树。
```

（大意：大王为什么身上脱去璎珞，头发蓬乱到这样的地步？王的身体为什么战栗不安，犹如猛风吹动花树？）

“大王现在为什么面容愁苦憔悴，犹如农夫下种之后天不下雨，这样愁苦？是心痛，还是身痛？”

王就回答说：“我现在身心怎能不痛？我父先王慈爱怜恤，特别垂念我，实在无罪。他曾去问相师，相师回答说：‘这孩子出生之后，必定会害父亲。’虽然听到这话，仍然养育照看我。我曾听智者这样说：若有人与母亲私通，与比丘尼私通，偷盗僧祇之物，杀害发无上菩提心的人，以及害其父亲，这样的人必定堕入阿鼻地狱。我现在身心怎能不痛？”

大臣又说：“唯愿大王暂且不要愁苦。如果父王是修解脱的人，杀害他就有罪；若是依治国之法，杀了就无罪。大王，非法名为无法，无法也名为无法。譬如没有儿子名为无子，也如有恶子也称为无子；虽然说无子，其实并非没有儿子。如食物中没有盐名为无盐，食物中盐少也称为无盐。如河中没有水名为无水，若有少许水也称为无水。如念念生灭也称为无常，即使住一劫也称为无常。如人受苦名为无乐，即使受少许乐也称为无乐。如不自在名为无我，即使有少许自在也称为无我。如黑夜时名为无日，云雾之时也称为无日。大王，虽说少法名为无法，其实并非无法。愿大王留神听臣所说。

【按】南本此句，《大正藏》作“非法者名为无法，无法者名为无法”（先前电子文本衍一“无”字，曾误判为南本误衍，今改正）；北本作“非法者名为非法”。南本与下文“恶子名之无子”“少盐亦名无盐”等譬喻正相呼应，今依南本译。大臣之意，是说先王所行不合法，也就等于无法，以此开脱弑父之罪，属诡辩之词。

“一切众生都有余业，因为业缘的缘故，屡受生死。若使先王有余业，现在大王杀了他，究竟有什么罪？唯愿大王放宽心意，不要愁苦。为什么呢？

```
若常愁苦，愁遂增长，如人喜眠，眠则滋多，
贪淫嗜酒，亦复如是。
```

“如王所说，世间没有良医能治身心，现在有一位大师，名叫删阇耶毗罗胝子，一切知见，其智慧深邃犹如大海，有大威德，具大神通，能令众生离开诸疑网。一切众生不知、不见、不觉，唯有这一人独自知、见、觉。他现在就住在王舍城附近，为弟子们说这样的法：一切众人之中，若是国王，自在随意造作善恶，虽然作了众恶，都没有罪。如火烧物，没有净与不净，国王也是这样，与火同性。譬如大地，净物秽物普遍承载，虽然这样，从来没有瞋喜，国王也是这样，与地同性。譬如水，净物秽物都能洗涤，虽然这样，也没有忧喜，国王也是这样，与水同性。譬如风，净物秽物平等吹拂，虽然这样，也没有忧喜，国王也是这样，与风同性。如秋天砍去树枝，春天又会重生，虽然砍伐，其实无罪；一切众生也是这样，在此间命终，还在此间受生，因为还会再生，有什么罪？

“一切众生苦乐的果报，都不由现在世的业，因在过去，现在受果；现在无因，未来无果。因为现在的果报，众生持戒，勤修精进，遮止现在的恶果；因为持戒，就得无漏；得无漏，就尽有漏业；因为业尽，众苦得尽；众苦尽了，就得解脱。唯愿大王速往他那里，让他治疗身心苦痛。大王若见到他，众罪就会除灭。”

王就回答说：“若真有这位大师能除我的罪，我就归依他。”

#### 悉知义荐阿耆多翅舍钦婆罗

又有一位大臣，名叫悉知义，就来到王所，这样说：“大王现在为什么形貌不端严，如失去国家的人，如泉水枯竭，如池中无莲花，如树无花叶，如破戒比丘身无威德？是身痛，还是心痛？”

王就回答说：“我现在身心怎能不痛？我父先王慈悲怜念我，然而我不孝，不知报恩。他常以安乐安乐我，而我背恩，反而断了他的安乐。先王无罪，我却横加逆害。我也曾听智者说：若有人害父，当在无量阿僧祇劫中受大苦恼。我现在不久必定堕入地狱，又没有良医救治我的罪。”

大臣就说：“唯愿大王放下愁苦。大王没有听说吗？过去有国王名叫罗摩，杀害父亲之后得继王位；跋提大王、毗楼真王、那睺沙王、迦帝迦王、毗舍佉王、月光明王、日光明王、爱王、持多人王，这些国王都杀害父亲而得继王位，然而没有一个国王入地狱。现在当今的毗琉璃王、优陀那王、恶性王、鼠王、莲花王，这些国王都杀害父亲，也没有一个国王生愁恼的。虽然说有地狱、饿鬼、天中，谁见过呢？大王，只有两种有：一是人道，二是畜生。虽有这两种，不是因缘而生，不是因缘而死；若不是因缘，哪有善恶？唯愿大王不要心怀愁怖。为什么呢？

```
若常愁苦，愁遂增长，如人喜眠，眠则滋多，
贪淫嗜酒，亦复如是。
```

“如王所说，世间没有良医能治身心，现在有一位大师，名叫阿耆多翅舍钦婆罗，一切知见，观金与土平等无二，有人用刀砍他的右胁，有人用栴檀涂他的左胁，对这两人心无差别，平等看待怨亲，心无异相。这位大师真是世间的良医，或行或立，或坐或卧，常在三昧，心无散乱。他告诉弟子们这样说：或自己作，或教他人作；或自己砍，或教他人砍；或自己烤，或教他人烤；或自己害，或教他人害；或自己偷，或教他人偷；或自己淫，或教他人淫；或自己妄语，或教他人妄语；或自己饮酒，或教他人饮酒；或杀一村、一城、一国，或以刀轮杀尽一切众生；或在恒河以南布施众生，在恒河以北杀害众生，都没有罪福，没有布施、持戒、禅定。他现在就住在王舍城附近，愿大王速往，大王若见到他，众罪就会除灭。”

王说：“大臣，若真能这样除灭我的罪，我就归依他。”

#### 吉德荐迦罗鸠驮迦旃延

又有一位大臣，名叫吉德，又来到王所，这样说：“大王现在为什么面无光泽，如日中之灯，如白昼之月，如失国之君，如荒败之土？大王，现在四方太平，没有怨敌，而现在为什么这样愁苦？是身苦，还是心苦？有些王子常生这样的念头：‘我什么时候才能得自在？’大王现在已经实现了心愿，自在统领摩伽陀国，先王的宝藏全都得到了，只应快意纵情享乐，这样的愁苦何必挂在心上？”

王就回答说：“我现在怎能不愁恼？大臣，譬如愚人只贪滋味，不见利刀；如吃杂有毒药的食物，不见其过患，我也是这样。如鹿只见草，不见深陷阱；如老鼠贪食，不见猫狸，我也是这样，只见现在的快乐，不见未来不善的苦果。我曾从智者那里听到这样的话：‘宁可在一日之中受三百次矛刺，也不对父母生起一念恶心。’我现在已经接近地狱的炽火，怎能不愁恼？”

【按】“受三百𥎞”，“𥎞”字由“矛”与“赞”组成，先前电子文本未能显示，今据《大正藏》补出；宋、元、明本作“矛”，北本作“钻”（先前曾误记北本作“赞”，今改正）。意即受三百次矛刺之刑。

大臣又说：“谁来欺骗大王说有地狱？如荆棘的尖刺，是谁造的？飞鸟的羽色各异，又是谁作的？水性湿润，石性坚硬，如风的动性，如火的热性，一切万物自死自生，是谁作的？所谓地狱，只是智者以文辞造作出来的。所谓地狱，有什么意义？臣当为王解说：地名为地，狱名为破，破了地狱就没有罪报，这名为地狱。又，地名为人，狱名为天，因为杀害其父，所以到达人天。因为这个道理，婆薮仙人宣称：‘杀羊能得人天之乐。’这名为地狱。又，地名为命，狱名为长，因为杀生，得寿命长，所以名为地狱。大王，所以应当知道实在没有地狱。

“大王，如种麦得麦，种稻得稻；杀地狱的，还得地狱；杀害人的，应当还得为人。大王，现在应当听臣所说：实在没有杀害。若有我，实在也没有杀害；若没有我，又没有所害。为什么呢？若有我，就常住不变易；因为常住，不可杀害，不破不坏，不系不缚，不瞋不喜，犹如虚空，怎会有杀害之罪？若没有我，诸法无常；因为无常，念念坏灭；因为念念灭，杀者、死者都念念灭；若念念灭，谁会有罪？

“大王，如火烧木，火没有罪；如斧砍树，斧也没有罪；如镰割草，镰实在没有罪；如刀杀人，刀实在不是人，刀既无罪，人怎会有罪？如毒药杀人，毒药实在不是人，毒药无罪，人怎会有罪？一切万物都是这样，实在没有杀害，怎会有罪？唯愿大王不要生起愁苦。为什么呢？

```
若常愁苦，愁遂增长，如人喜眠，眠则滋多，
贪淫嗜酒，亦复如是。
```

“如王所说，世间没有良医能治恶业，现在有一位大师，名叫迦罗鸠驮迦旃延，一切知见，明了三世，在一念之顷能见无量无边世界，听闻声音也是这样，能令众生远离过恶。犹如恒河，无论内外所有诸罪都能清净；这位大良师也是这样，能除去众生内外的众罪。他为弟子们说这样的法：若人杀害一切众生，心无惭愧，终不堕恶道，犹如虚空不受尘与水；有惭愧的，就入地狱，犹如大水浸湿大地。一切众生都是自在天所作，自在天欢喜，众生就安乐；自在天瞋怒，众生就苦恼。一切众生无论罪福，都是自在天所为，怎能说人有罪福？譬如工匠制作机关木人，能行住坐卧，只是不能说话；众生也是这样，自在天比喻工匠，木人比喻众生之身。这样的造化，谁会有罪？这样的大师现在就住在王舍城附近，唯愿速往，若见到他，众罪就会消灭。”

王就回答说：“若真有这个人能灭我的罪，我就归依他。”

#### 无所畏荐尼乾陀若提子

又有一位大臣，名叫无所畏，来到王所，这样说：“大王，世间有愚人，一日之中百喜、百愁、百眠、百醒、百惊、百哭；有智之人没有这些事。大王为什么这样忧愁，如失去同伴的旅客，如陷入深泥而无人救拔，如人干渴而得不到饮浆，犹如迷路的人没有向导，如困苦的病人没有医生救治，如海船破了而无人救接？大王现在是身痛，还是心痛？”

王就回答说：“我现在身心怎能不痛？我亲近恶友，不察其口中过失，先王无罪，我却横加逆害。我现在确知必定会入地狱，又没有良医来救济。”

大臣就说：“唯愿大王不要生起愁毒。刹利名为王种，若为了国土，若为了沙门以及婆罗门，为了安定人民，即使杀害，也没有罪。先王虽然恭敬沙门，却不能承事诸婆罗门，心不平等；因为不平等，就不是刹利。大王现在为了供养诸婆罗门而杀害先王，有什么罪？大王，实在没有杀害。所谓杀害，是杀害寿命；命名为风气，风气之性不可杀害，怎能说害命而有罪？唯愿大王不要再愁苦。为什么呢？

```
若常愁苦，愁遂增长，如人喜眠，眠则滋多，
贪淫嗜酒，亦复如是。
```

“如王所说，世间没有良医能治疗，现在有一位大师，名叫尼乾陀若提子，一切知见，怜悯众生，善知众生诸根利钝，通达一切随宜方便，世间八法所不能染污，寂静修习清净梵行。他为弟子们这样说：没有布施，没有善，没有父，没有母，没有今世后世，没有阿罗汉，没有修，没有道。一切众生经过八万劫，在生死之轮中自然得以解脱，有罪无罪都是这样。如四大河，即辛头河、恒河、博叉河、私陀河，都流入大海，没有差别；一切众生也是这样，得解脱时，都没有差别。这位大师现在就住在王舍城，唯愿大王速往他那里，若得见到，众罪就会消除。”

王就回答说：“若真有这位大师能除我的罪，我就归依他。”

【按】六臣所荐的富兰那、末伽梨、删阇耶、阿耆多、迦罗鸠驮、尼乾陀，即佛世的“六师外道”，诸臣所说的无业报、无地狱、王者无罪、杀亦无罪等，正是六师邪见的代表，经文借此反衬后文耆婆劝王归佛。各家学说的归属，诸经所记不尽相同，这里照本经译出。

### 耆婆问安眠

那时有一位大医，名叫耆婆，来到王所，说：“大王，睡得安稳吗？”

王以偈回答：

```
若有能永断，一切诸烦恼，
不贪染三界，乃得安隐眠，
若得大涅槃，演说甚深义，
名真婆罗门，乃得安隐眠，
身无诸恶业，口离于四过，
心无有疑网，乃得安隐眠，
身心无热恼，安住寂静处，
获致无上乐，乃得安隐眠，
心无有取著，远离诸怨仇，
常和无诤讼，乃得安隐眠，
若不造恶业，心常怀惭愧，
信恶有果报，乃得安隐眠，
敬养于父母，不害一生命，
不盗他财物，乃得安隐眠，
调伏于诸根，亲近善知识，
破坏四魔众，乃得安隐眠。
```

（大意：若能永断一切烦恼，不贪染三界，才得安稳而眠。若得大涅槃，演说甚深之义，名为真婆罗门，才得安稳而眠。身无诸恶业，口离四种过失，心无疑网，才得安稳而眠。身心没有热恼，安住寂静之处，获得无上之乐，才得安稳而眠。心无取著，远离怨仇，常和无诤，才得安稳而眠。不造恶业，心常怀惭愧，相信恶有果报，才得安稳而眠。敬养父母，不害一条生命，不盗他人财物，才得安稳而眠。调伏诸根，亲近善知识，破坏四魔，才得安稳而眠。）

```
不见吉不吉，及以苦乐等，
为诸众生故，轮转于生死，
若能于是者，乃得安隐眠，
谁得安隐眠，所谓诸佛是，
深观空三昧，身心安不动，
谁得安隐眠，所谓慈悲者，
常修不放逸，视众如一子。
```

（大意：不见吉与不吉以及苦乐等分别，为了众生而轮转于生死，若能这样，才得安稳而眠。谁得安稳而眠？就是诸佛，深观空三昧，身心安然不动。谁得安稳而眠？就是有慈悲的人，常修不放逸，看待众生如同独子。）

```
众生无明冥，不见烦恼果，
常造诸恶业，不得安隐眠，
若为于自身，及以他人身，
造作十恶业，不得安隐眠，
若言为乐故，害父无过咎，
随是恶知识，不得安隐眠，
若食过节度，冷饮而过差，
如是则病苦，不得安隐眠，
若于王有过，邪念他妇女，
及行旷路者，不得安隐眠，
持戒果未熟，太子未绍位，
盗者未获财，不得安隐眠。
```

（大意：众生被无明所蒙蔽，不见烦恼的果报，常造诸恶业，不得安稳而眠。若为了自己或他人造作十恶业，不得安稳而眠。若说为了享乐，害父没有过错，听从这样的恶知识，不得安稳而眠。若饮食没有节制，冷饮过度，就会病苦，不得安稳而眠。若对国王有过失，邪念他人妇女，以及行走在旷野道路上的人，不得安稳而眠。持戒之果尚未成熟，太子尚未继位，盗贼尚未得到财物，都不得安稳而眠。）

“耆婆，我现在病重，对正法之王作了恶逆之害，一切良医、妙药、咒术、善巧看护都不能治。为什么呢？我父法王如法治国，实在无罪，我却横加逆害。如鱼处在陆地上，有什么快乐？如鹿落在罗网中，毫无欢心；如人自知活不过今天；如国王失去国家，逃窜到他乡；如人听说自己的病不可治疗；如破戒的人听人说其罪过。我过去曾听智者说：身、口、意业若不清净，应当知道此人必定堕入地狱。我也是这样，怎能睡得安稳？现在我又没有无上大医为我演说法药，除去我的病苦。”

### 耆婆说惭愧

耆婆回答说：“善哉，善哉！大王虽然作了罪，心中生起深重的悔恨，而怀惭愧。大王，诸佛世尊常这样说：有两种白法能救众生，一是惭，二是愧。惭是自己不作罪，愧是不教他人作；惭是内心自己羞耻，愧是向人发露；惭是羞于人，愧是羞于天。这名为惭愧。没有惭愧的，不名为人，名为畜生。因为有惭愧，所以能恭敬父母师长；因为有惭愧，所以说有父母、兄弟、姊妹。善哉，大王具有惭愧！

“大王且听，臣听佛说：智者有两种：一是不造诸恶，二是作了之后能忏悔。愚者也有两种：一是作罪，二是覆藏。虽然先前作恶，后来能发露，悔过之后心怀惭愧，再也不敢作，犹如浊水，放入明珠，因为珠的威力，水就变清；如烟云散去，月亮就清明。作恶能悔，也是这样。大王若忏悔，心怀惭愧，罪就会除灭，清净如初。

“大王，财富有两种：一是象马等种种畜生，二是金银等种种珍宝。象马虽多，比不上一颗宝珠。大王，众生也是这样：一是恶的财富，二是善的财富。多作诸恶，不如一善。臣听佛说：修一善心，能破百种恶。大王，如少许金刚能毁坏须弥山，也如少许火能烧一切，如少许毒药能害众生；少许善也是这样，能破大恶。虽名为少善，其实是大，为什么呢？因为能破大恶。

“大王，如佛所说，覆藏的就有漏，不覆藏的就没有漏；发露悔过，所以不漏。若作了众罪，不覆不藏，因为不覆藏，罪就微薄；若心怀惭愧，罪就消灭。大王，如水滴虽然微小，渐渐能盈满大器，善心也是这样，一一善心都能破大恶。若覆藏罪过，罪就增长；发露惭愧，罪就消灭。所以诸佛说有智慧的人不覆藏罪过。善哉，大王能相信因果，相信业，相信报！唯愿大王不要心怀愁怖。

“若有众生造作诸罪，覆藏不悔，心无惭愧，不见因果以及业报，不能请教有智之人，不亲近善友，这样的人，一切良医乃至看护都不能治。如迦摩罗病，世间的医生只能束手；覆罪之人也是这样。什么样的罪人？就是一阐提。一阐提不信因果，没有惭愧，不信业报，不见现在以及未来世，不亲近善友，不随顺诸佛所说的教诫，这样的人名为一阐提，诸佛世尊也不能治。为什么呢？如世间的死尸，医生不能治，一阐提也是这样，诸佛世尊也不能治。大王现在不是一阐提，怎能说不可救治？

【按】迦摩罗病，即黄疸一类的重病，古时以为难治。

### 耆婆劝王见佛

“如王所说，没有能治的人。大王应当知道，迦毗罗城净饭王之子，姓瞿昙，名悉达多，无师而自觉悟，自然得到无上正等正觉，以三十二相、八十种好庄严其身，具足十力、四无所畏，一切知见，大慈大悲，怜悯一切如同罗睺罗。他随顺善良的众生，如小牛追随母牛。他知时而说，非时不语，说真实语、清净语、微妙语、有义语、如法语、一致语，能令众生永离烦恼。他善知众生诸根心性，随宜方便，无不通达。他的智慧高大如须弥山，深邃广远犹如大海。这位佛世尊有金刚之智，能破众生一切恶罪，若说不能，没有这样的道理。

“他现在离此十二由旬，在拘尸那城娑罗双树间，为无量阿僧祇的诸菩萨僧演说种种法：或有，或无；或有为，或无为；或有漏，或无漏；或烦恼之果，或善法之果；或色法，或非色法，或非色非非色法；或我，或非我，或非我非非我；或常，或非常，或非常非非常；或乐，或非乐，或非乐非非乐；或相，或非相，或非相非非相；或断，或非断，或非断非非断；或世间，或出世间，或非世间非出世间；或乘，或非乘，或非乘非非乘；或自作自受，或自作他受，或无作无受。大王，若在佛那里听到无作无受，所有的重罪就会消灭。

#### 帝释五衰相灭

“大王且听，释提桓因寿命将终时，有五种相出现：一是衣裳垢腻，二是头上花鬘枯萎，三是身体臭秽，四是腋下出汗，五是不乐本座。那时天帝释或在静处，若见到沙门或婆罗门，就到他那里，生起是佛之想。那时沙门及婆罗门见帝释来，深自庆幸，就说：‘天主，我现在归依你。’帝释听了，才知道他不是佛，又自念：‘他若不是佛，就不能治我的五种衰退之相。’

“这时他的御者名叫般遮尸，对帝释说：‘憍尸迦，乾闼婆王名叫敦浮楼，那王有个女儿名叫须跋陀。王若能把此女赐给我，臣当指示王除去衰相的地方。’帝释就回答说：‘善男子，毗摩质多阿修罗王有个女儿舍脂，是我所敬重的，你若真能指示我消灭恶相的地方，尚且可以把她给你，何况须跋陀？’

“‘憍尸迦，有一位佛世尊，名叫释迦牟尼，现在在王舍大城，若能前往他那里请问未闻之法，衰没之相必定能除灭。’

“‘善男子，若佛世尊真能灭除，就可以掉转车驾到他的住处。’

“御者奉命，就掉转车乘，到王舍城耆阇崛山，到了佛所，头面礼足，退坐一旁，对佛说：‘世尊，天人之中，什么是系缚？’

“‘憍尸迦，是悭贪与嫉妒。’

“又问：‘悭贪嫉妒从什么而生？’

“回答：‘从无明而生。’

“又问：‘无明又从什么而生？’

“回答：‘从放逸而生。’

“又问：‘放逸又从什么而生？’

“回答：‘从颠倒而生。’

“又问：‘颠倒又从什么而生？’

“回答：‘从疑心而生。’

“‘世尊，颠倒之法从疑而生，实在如圣教所说。为什么呢？我有疑心，因为疑心，就生颠倒，对不是世尊的人生起是世尊之想。我现在见到佛，疑网就除去了；疑网除了，颠倒也尽了；颠倒尽了，就没有悭心乃至妒心。’

“佛说：‘你说没有悭妒之心，你现在已得阿那含了吗？阿那含没有贪心，若没有贪心，为什么为了求命来到我这里？阿那含实在不求命。’

“‘世尊，有颠倒的人就求命，没有颠倒的人就不求命。然而我现在实在不求命，所想求的，唯有佛的法身以及佛的智慧。’

“‘憍尸迦，求佛法身以及佛的智慧，在将来之世必定能得到。’

“那时帝释听佛说了之后，五种衰没之相即时消灭，便起身作礼，绕佛三匝，恭敬合掌，对佛说：‘世尊，我现在是即死即生，失命又得命；又听到佛授记我当得无上正等正觉，这就是重生，就是重新得命。世尊，一切人天因什么而增益？又因什么而损减？’

“‘憍尸迦，因斗诤的因缘，人天损减；善修和敬，就得增益。’

“‘世尊，若因斗诤而损减，我从今日起，再也不与阿修罗作战。’

“佛说：‘善哉，善哉！憍尸迦，诸佛世尊说忍辱法，是无上正等正觉之因。’

“那时释提桓因就上前礼佛，然后回去了。大王，如来能除诸恶相，所以称佛不可思议。大王若前往，所有的重罪必定能除。

### 佛为无上良医，非六师

#### 鸯崛魔罗

“大王且听，有一位婆罗门之子，名叫不害，因为杀了无量众生，所以名为鸯崛魔。他又想杀害母亲，恶心起时，身体也随着动作；身心都动，就是五逆之因；因为有五逆之因，必定堕入地狱。后来见到佛时，身心又都动起来，又想加害；身心都动，就是五逆之因；因为有五逆之因，当入地狱。此人得遇如来大师，即时灭除了地狱的因缘，发无上正等正觉之心。所以称佛为无上医，不是六师。

#### 须毗罗王子

“大王，又有须毗罗王子，他的父亲恼怒他，截断他的手足，把他推入深井。他的母亲怜悯他，派人把他拉出来，带到佛所。他一见到佛，手足就恢复完具，随即发无上正等正觉之心。大王，因为见佛的缘故，得到现世的果报，所以称佛为无上医，不是六师。

#### 恒河饿鬼

“大王，如恒河边有一群饿鬼，数目五百，在无量岁中从未见到水，即使到了河上，所见全是流火。被饥渴所逼，发声号哭。那时如来在那河边的优昙钵林中，坐在一棵树下。当时诸饿鬼来到佛所，对佛说：‘世尊，我们饥渴，命将不久了。’

“佛说：‘恒河的流水，你们为什么不喝？’

“鬼就回答：‘如来见到的是水，我们见到的是火。’

“佛说：‘恒河清流，实在没有火。因为恶业的缘故，心中自生颠倒，以为是火。我当为你们除灭颠倒，令你们见到水。’

“那时世尊为诸鬼广说悭贪的过患。诸鬼就说：‘我们现在干渴，虽然听闻法言，都入不了心。’

“佛说：‘你们若干渴，先入河水随意饮用。’

“这些鬼因为佛力的缘故，就得以饮水。饮水之后，如来又为他们说种种法；听法之后，都发无上正等正觉之心，舍去饿鬼之形，得到天身。大王，所以称佛为无上医，不是六师。

#### 五百盲贼

“大王，舍婆提国有五百群贼，波斯匿王挖去他们的眼睛，他们失明，没有向导，不能前往佛所。佛因为怜悯，就到群贼那里，慰问晓喻他们说：‘善男子，好好守护身口，不要再造恶。’诸贼当时听到如来微妙清澈的声音，随即恢复了眼睛，就在佛前合掌礼佛，对佛说：‘世尊，我们现在知道佛的慈心普覆一切众生，不只是人天。’那时如来就为他们说法，听法之后，都发无上正等正觉之心。所以如来真是世间的无上良医，不是六师。

#### 旃陀罗气嘘

“大王，舍婆提国有一个旃陀罗，名叫气嘘，杀了无量的人，见到佛弟子大目犍连，即时破除了地狱的因缘，而得上生三十三天。因为有这样的圣弟子，所以称佛如来为无上医，不是六师。

#### 阿逸多三逆

“大王，波罗捺城有一个长者之子，名叫阿逸多，与他的母亲私通，因为这个因缘，杀了他的父亲。他的母亲又与外人私通，儿子知道后，又杀了母亲。有一位阿罗汉是他的旧识，他对这位旧识又生起羞愧，就把他也杀了。杀了之后，就到祇桓精舍请求出家。当时诸比丘都知道此人犯有三逆罪，没有人敢允许。因为不允许，他更加瞋恚，就在当夜放大火焚烧僧坊，杀了很多无辜的人。然后又去王舍城，到如来所，哀求出家。如来就允许了，为他说法要，令他的重罪渐渐轻微，发无上正等正觉之心。所以称佛为世间良医，不是六师。

#### 醉象

“大王，大王本性暴恶，信受恶人提婆达多，放大醉象，想让它践踏佛。大象一见到佛，即时醒悟，佛就伸手摩其头顶，又为它说法，令它得以发起无上正等正觉之心。大王，畜生见佛尚且能破坏畜生的业果，何况是人？大王应当知道，若见到佛，所有的重罪必定能灭。

【按】“王本性暴恶”，耆婆当面直指阿阇世王本人曾放醉象害佛之事，即卷第十四所说“护财象”。

#### 魔、旷野鬼、广额、龙印

“大王，世尊未得无上正等正觉时，魔与无量无边的眷属来到菩萨所。菩萨那时以忍辱之力，摧坏魔的恶心，令魔接受正法，随即发无上正等正觉之心。佛有这样的大功德力。

“大王，有旷野鬼多害众生，如来那时为了善贤长者，到旷野村为他说法。当时旷野鬼听法欢喜，就把长者交给如来，然后发无上正等正觉之心。

“大王，波罗奈国有一个屠夫，名叫广额，每天杀无量的羊，见到舍利弗，就受八戒，持了一日一夜。因为这个因缘，命终之后得为北方天王毗沙门之子。如来的弟子尚且有这样的大功德果，何况是佛？

【按】“波罗奈国”，《大正藏》作“波罗㮈”，“㮈”同“奈”，宋、元、明本作“奈”。此字先前电子文本未能显示，并非藏经缺字。

“大王，北天竺有一座城，名叫细石，那城中有一位国王，名叫龙印，贪图国家的权位，杀害了他的父亲。害父之后，心生悔恨，就舍弃国政，来到佛所，哀求出家。佛说：‘善来。’他就成了比丘，重罪消灭，发无上正等正觉之心。大王应当知道，佛有这样无量无边的大功德果。

#### 提婆达多

“大王，如来有个堂弟提婆达多，破坏僧团，出佛身血，害莲花比丘尼，作了三逆罪。如来为他说种种法要，令他的重罪随即微薄。所以如来是大良医，不是六师。

“大王，若能相信臣的话，唯愿速往如来所；若不相信，愿好好思量。

### 佛心平等，普为一切

“大王，诸佛世尊大悲普覆，不限于一人；正法弘广，无所不包；怨亲平等，心无憎爱；终不偏为一人令得无上正等正觉，而其余的人不得。如来不只是四部众之师，普遍是一切天、人、龙、鬼、地狱、畜生、饿鬼等的老师。一切众生也应当把佛看作父母。

“大王应当知道，如来不只是为豪贵之人跋提迦王演说法要，也为下贱的优波离等说；不只是接受须达多、阿那邠坻所奉的饭食，也接受贫人须达多的饭食；不只是为舍利弗等利根之人说法，也为钝根的周梨槃特说；不只是允许大迦叶等无贪之性的人出家求道，也允许大贪的难陀出家；不只是允许烦恼薄的优楼频螺迦叶等出家求道，也允许烦恼深厚、造重罪的波斯匿王之弟优陀耶出家求道。

“不只是因为纱草恭敬供养，才为他拔除瞋根；鸯崛摩罗以恶心想要加害，也不舍弃而不救度。

“不只是为有智慧的男子演说法要，也为极其愚钝、已经婚配的女人说法；不只是令出家之人得四道果，也令在家之人得三道果；不只是为富多罗等舍弃诸般事务、闲静思惟的人说法要，也为频婆娑罗王等统领国事、处理王务的人说法要；不只是为断酒的人说，也为嗜酒荒醉的郁伽长者说；不只是为入禅定的离婆多等说，也为丧子乱心的婆罗门女婆私吒说；不只是为自己的弟子说，也为外道尼乾子说；不只是为盛年二十五岁的人说，也为衰老八十岁的人说；不只是为善根成熟的人说，也为善根未熟的人说；不只是为末利夫人说，也为淫女莲花女说；不只是接受波斯匿王的上等美味，也接受长者尸利鞠多掺有毒药的食物。大王应当知道，尸利鞠多往昔也作了逆罪之因，因为遇佛闻法，就发无上正等正觉之心。

【按】“纱草”，《大正藏》作“𦀟草”（“𦀟”同“纱”），宋、元、明本作“莎草”。慧琳《一切经音义》注明“此是人名”，所以此句是以恭敬供养的纱草与心怀恶意的鸯崛摩罗对举。先前误以“莎草”为供物，今改正。“牉合智者女人”，宋、元、明本作“判合婚者女人”。慧琳音义释“判合”为“得偶而合”，即婚配，今依三本译出。

#### 一念向佛，胜于广大布施

“大王，假使一个月中常以衣食供养恭敬一切众生，不如有人一念念佛所得功德的十六分之一。大王，假使用金子铸成人像，用车马载运珍宝，数目各一百，用来布施，不如有人发心向佛，举足走一步。大王，假使又用象车一百乘，载满大秦国种种珍宝，以及身佩璎珞的女人，数目也满一百，用来布施，仍然不如发心向佛，举足走一步。且不说这些，若以四事供养三千大千世界所有的众生，也仍然不如发心向佛，举足走一步。且不说这些，若使大王供养恭敬恒河沙数无量众生，不如一往娑罗双树，到如来所，诚心听法。”

### 王自鄙不敢往

那时大王回答耆婆说：“如来世尊本性已经调柔，所以得到调柔的人作为眷属；如栴檀林，全以栴檀围绕。如来清净，所有的眷属也清净，犹如大龙，全以诸龙作为眷属。如来寂静，所有的眷属也寂静；如来无贪，所有的眷属也无贪；佛无烦恼，所有的眷属也无烦恼。我现在是极恶之人，恶业缠裹其身，臭秽不堪，系属于地狱，怎能到如来所？我即使前往，恐怕佛也不会顾念我，与我交谈。你虽然劝我去佛所，然而我今天深深自鄙自伤，全无前去的心。”

### 空中父王之声

那时虚空中随即发出声音说：“无上佛法将要衰灭，甚深法河将要干涸，大法明灯将要熄灭，不久法山将要崩颓，法船将要沉没，法桥将要毁坏，法殿将要倒塌，法幢将要倾倒，法树将要折断，善友将要离去，大恐怖将至，众生饥渴于法的时候不久将到，烦恼疫病将要流行，大黑暗的时候到了，渴法之时来了，魔王欣喜庆贺，解下甲胄，佛日将要没入大涅槃之山。

“大王，佛若去世，大王的重恶再没有人能治。大王，你现在已造阿鼻地狱极重之业，以这业缘，必定受报，毫无疑问。

“大王，阿名为无，鼻名为间，中间没有片刻的快乐，所以名为无间。大王，假使一人独自堕入这地狱，其身长大八万由旬，遍满其中，没有空隙，其身周遍受种种苦；假设有很多人，身体也都遍满，互不妨碍。大王，寒地狱中，偶然遇到热风，以此为乐；热地狱中，偶然遇到寒风，也名为乐；活地狱中，即使命终，若听到‘活’的声音，随即就复活。阿鼻地狱都没有这些事。

【按】“有地狱中设命终已”，南本诸本同，北本作“活地狱中”，即等活地狱，罪人死后听到“活”声就又复活。今依北本译。

“大王，阿鼻地狱四方有门，每一门外各有猛火，东西南北交相贯通，八万由旬，周围是铁墙，上面覆盖铁网，地面也是铁，上面的火烧透到下面，下面的火烧透到上面。大王，如鱼在鏊中，脂膏焦燃，这里的罪人也是这样。大王，造一种逆罪的，就具受这样一份罪；若造两种逆罪，罪就加倍；五逆都具足的，罪也就五倍。大王，我现在确知大王的恶业必定不能免脱，唯愿大王速往佛所，除了佛世尊，再没有能救你的。我现在怜悯你，所以劝导你。”

【按】“若鱼在鏊”，《大正藏》作“𨫼”，慧琳《一切经音义》说即“鏊”字，是烙饼用的平底铁锅。先前电子文本未能显示此字，并非藏经缺字。

那时大王听了这话，心怀怖惧，全身战栗，五体颤动如芭蕉树，仰头回答说：“你是谁？不现形像，只有声音。”

“大王，我是你的父亲频婆娑罗。你现在应当听从耆婆所说，不要听从邪见六臣的话。”

当时王听了，闷绝倒地，身上的疮更加剧烈，臭秽比先前加倍；虽然用冷药涂敷治疗，疮的蒸毒热痛只增不减。

大般涅槃经卷第十七
