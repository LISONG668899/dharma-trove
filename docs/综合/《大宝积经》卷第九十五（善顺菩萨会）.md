# 《大宝积经》卷第九十五（善顺菩萨会）

唐·三藏法师菩提流志 奉诏译

## 善顺菩萨会第二十七

【按】译者题名“大”字，明本无；“诏”，宋、元、宫本作“诰”。本会异译有曹魏白延译《须赖经》（T0328）、前凉支施仑译《佛说须赖经》（T0329），“须赖”即善顺之音译。

#### 序分：善顺菩萨

如是我闻：一时，佛在舍卫国祇树给孤独园，被五百声闻、一万菩萨等大众恭敬围绕。当时舍卫城有一位菩萨，名为善顺，已在过去无量佛所种诸善根，承事供养，对阿耨多罗三藐三菩提得不退转，住于大慈，心不瞋恚，住于大悲，弘济无倦，住于大喜，善安于法界，住于大舍，苦乐平等，饮食节量合时，少欲知足，常为众生所乐见。他恒以五戒以及八斋法在那城中怜愍教化，然后又劝人布施、持戒、忍辱、精进、禅定、智慧、慈悲喜舍、清净梵行。那时善顺菩萨为了令众生见佛闻法，被众人前后围绕，将要前往佛所。

【按】“于某城中”之“某”，宋、元、明、宫本作“其”，今依此译作“那城”。

#### 帝释四试：一试杀

当时天帝释以清净天眼见到这位菩萨住于上精进，行头陀行，具足清净尸罗，弘济坚固，便自己想：“现在这善顺对种种梵行从不懈怠止息，莫非是为了求帝释之位吗？或是贪求王位以及欲乐吗？”这样想之后，便化作四个男子，来到菩萨面前，以种种恶言毁骂菩萨，又以刀杖以及瓦石打掷加害。那时菩萨住于慈忍之力，全都忍受，从无瞋恨。

【按】“住上精进”之“上”，宋、元、明、宫本作“止”。“刀杖”之“杖”，宋、宫本作“仗”。

当时天帝释又化作四个大男子，来对菩萨说：“唉，善顺！那些恶人以不善之言骂辱你，又以瓦石刀杖之类横加打害，为什么不让我为你报仇？我当为你断他们的命根。”那时菩萨告诉那些人说：“善男子们，不要说这样的话。若杀害他人，便成就恶业。假使有人把我这身体节节支解，犹如枣叶，我终不生杀害之心。为什么呢？杀害之人堕于地狱、饿鬼、畜生，乃至虽然得到人身，所生的父母尚且不爱念他，恒为众人所憎恶。善男子！一切诸法总有两种：一是善法，二是不善法。由于不善法堕于恶趣，若依善法便获得福利。”那时善顺菩萨想重宣此义，而说偈道：

```
善恶犹种植，皆随业所生，
何有苦子因，成熟甘果者？
现见法如是，智者应思惟，
苦报酬恶缘，为善常安乐。
```
（大意：善恶犹如种植，都随业而生，哪有苦的种子为因，而成熟甘甜之果的？现见法就是这样，智者应当思惟：苦报是酬偿恶缘，行善常得安乐。）

那时天帝所化之人听了这话，自己想到不能令那菩萨作杀害之业，便忽然不见。

#### 二试盗

那时天帝又化作金银宝聚，令那些男子到菩萨那里，这样说：“你可以设法取这些珍宝，随意使用。”那时菩萨告诉那些人说：“诸位善男子，不要这样说。为什么呢？盗业能令众生贫穷下劣，无依无靠。即使我贫穷，性命不保，终不行不与而取之法。诸君应当知道，凡夫愚昧，被贪求所覆蔽，哪有智者会行不与而取？”那时善顺菩萨说偈道：

```
积财虽千亿，贪著心不舍，
智者说此人，在世恒贫苦。
彼虽无一物，安住舍离心，
智者说斯人，世间最富贵。
智者离诸恶，一切皆端严，
愚夫由作罪，举身皆丑陋。
智者劝修善，愚夫恒为恶，
宁受智毁骂，不用愚称赞。
```
（大意：积聚财物虽有千亿，贪著之心不舍，智者说这人在世恒常贫苦。那人虽然一无所有，却安住于舍离之心，智者说这人是世间最富贵的。智者远离种种恶，一切都端严；愚夫由于作罪，全身都丑陋。智者劝人修善，愚夫恒常为恶；宁可受智者的毁骂，也不要愚人的称赞。）

【按】“愚夫由作罪”之“罪”，宋、元、明、宫本作“业”。

当时那天帝所化之人听了这话，怅然而去。

#### 三试妄语

那时天帝亲自来试探，拿着一俱胝金，到菩萨那里这样说：“我先前在这舍卫大城，与波斯匿王以及其余男子有所诤论，需要一个人为我作偏袒的证明。你若能为我作证人，便把这些金子奉上。”那时菩萨告诉帝释说：“仁者应当知道，妄语是不善之业，既欺诳自身，也欺诳天、龙、夜叉、乾闼婆、阿修罗、迦楼罗、紧那罗、摩睺罗伽。由于妄语，能成为一切恶的根本，趣向不善之道，毁坏清净戒，能毁坏色身，口气常臭，所说的言词被人厌恶轻贱。”那时菩萨重说偈道：

```
妄语之人，口气常臭，入苦恶道，无能救者。
夫妄语者，诳于自身，亦诳天龙，摩睺罗等。
当知妄语，为诸恶本，毁清净戒，死入三涂。
汝设与我，满阎浮金，我终不能，作于妄语。
```
（大意：妄语之人，口气常臭，入于苦恶之道，无人能救。妄语的人欺诳自身，也欺诳天、龙乃至摩睺罗伽等。应当知道妄语是诸恶的根本，毁坏清净戒，死后入于三途。你即使给我满阎浮提的金子，我终究不能作妄语。）

【按】“我终不能”之“不”，《大正藏》作“天”，今依CBETA（所录高丽藏）作“不”。

当时天帝释听了这些，便忽然不见。

#### 四试淫

那时天帝又令舍支夫人、日光夫人以及五髻等诸夫人前往菩萨那里，再加试炼，想破坏他的禁戒。当时舍支等便与五百位盛年女人，以香涂身，以花装扮修饰，在后夜分来到菩萨面前，这样说：“我们女人年轻貌美，愿与你亲近枕席，共相欢娱。”那时菩萨以无染之眼看着那些女人，告诉她们说：“地狱、畜生、阎罗王界，诸狂乱者、心不正者，耽于昏乱臭秽、脓血不净，爱恶罗刹是你们的亲友，不是诸天人的清净眷属。”那时菩萨重说偈道：

【按】“花粧”之“粧”，宋、元、明、宫本作“庄”。

```
愚人昏迷念不净，
耽染臭秽脓血身，
诸欲迅灭归无常，
永沈地狱阎罗界。
假令变化如汝等，
色身殊胜满世间，
我无一念贪染心，
常生如梦如怨想。
```
（大意：愚人昏迷，念于不净，耽染臭秽脓血之身；诸欲迅速消灭，归于无常，永远沉没于地狱阎罗界。假使变化出如你们这样色身殊胜的女人，充满世间，我也没有一念贪染之心，常生如梦、如怨家之想。）

当时舍支等虽然用尽种种媚态，那菩萨始终没有贪染，她们各自回到天宫，对帝释说：“我们观察善顺志愿坚固，将成正觉，没有疑问。为什么呢？他对我们没有少许贪爱，只生厌离。”

【按】“但生厌离”之“但”，《大正藏》作“俱”，今依CBETA（所录高丽藏）作“但”。

#### 帝释问愿

那时帝释虽然听了这话，仍然怀着忧恼，如箭射中身体，恒常这样想：“那人必定会夺我的位子，没有疑问。我现在应当再去试他，看他在种种愿中究竟愿求什么？”这样思量之后，来到菩萨面前，舍去憍慢，以头顶礼菩萨之足，以偈问道：

```
仁今勤修净梵行，
于诸欲愿何所求？
为求日月释梵天？
为求三有诸王位？
```
（大意：仁者现在勤修清净梵行，在种种欲愿中求的是什么？是求日月天、帝释、梵天之位？还是求三有中的诸王之位？）

那时善顺菩萨以偈回答：

```
我观日月释梵天，
世间王位三有报，
一切无常不坚固，
何有智者为兹愿？
```
（大意：我观察日月天、帝释、梵天，以及世间王位等三有的果报，一切都无常、不坚固，哪有智者会以此为愿？）

那时天帝听了这颂，又对菩萨说：“若如你所说，你求的是什么愿？”于是菩萨以偈回答：

```
我本不贪世间乐，
但求不生不灭身，
勤修方便济群生，
愿同登彼菩提路。
```
（大意：我本来不贪世间之乐，只求不生不灭之身，勤修方便，济度群生，愿与他们一同登上那菩提之路。）

那时天帝听了这颂，心生安乐，确知菩萨不求帝释之位。欢喜踊跃，以偈赞叹道：

```
汝言弘济为群生，
此心广大无与等，
愿破魔军证甘露，
由斯恒转胜法轮。
```
（大意：你说弘济是为了群生，这心广大，无与伦比；愿你破除魔军，证得甘露，由此恒转殊胜的法轮。）

【按】“不求释位”之“求”，宫本作“乐”。

那时天帝说了这偈之后，恭敬旋绕，礼菩萨之足，忽然不见。

【按】“旋遶”，宋、元、明、宫本作“遶旋”。

#### 金铃施最贫者

那时善顺菩萨在早晨进入舍卫城游化往来，得到一只劫初时的阎浮金铃，那铃的价值超过阎浮提。那时菩萨拿着这金铃，在四衢道中高声唱道：“这舍卫城中谁最贫穷，我当以这铃施给他。”当时有一位最胜耆旧长者，听了这话奔跑而来，对菩萨说：“我在这城中最为贫穷，可以把这铃施给我。”那时菩萨对长者说：“你不是贫穷的人。为什么呢？在这城中有一位善男子是贫中最贫，应当以这铃施给他。”长者问：“这人是谁？”菩萨回答：“波斯匿王在这城中最为贫穷。”当时那长者对菩萨说：“不要这样说。为什么呢？波斯匿王富贵多财，库藏满溢，珍奇财货用之不尽。怎么说他是贫中最贫？”那时菩萨在大众中以偈回答：

```
设有伏藏千亿余，
以贪爱心无厌足，
犹如大海吞众流，
如斯愚人最为贫。
由此复令贪增长，
展转滋蔓相续生，
于现在世及未来，
彼无智者常贫匮。
```
（大意：假设有千亿余的宝藏，而以贪爱之心无有厌足，犹如大海吞纳众流，这样的愚人最为贫穷。由此又令贪欲增长，辗转滋蔓，相续而生，在现在世以及未来世，那无智的人常常贫乏。）

【按】“答言”之“言”，宋、元、明、宫本作“曰”。“常贫匮”之“常”，宫本作“当”。

那时善顺菩萨说了这偈之后，与大众便前往波斯匿王那里。当时那位国王正与五百余位长者算数校计库藏财宝。菩萨那时上前对王说：“我在这城中往来游化，得到一只劫初时的阎浮金铃，那铃的价值超过阎浮提。我当时私下这样想：‘这城中若有最贫穷的人，当以这铃施给他。’又思惟：‘城中最贫穷的莫过于国王。’现在带着这铃，愿奉送给您，王既然贫穷，请为我接受它。”那时菩萨说了这话之后，重说偈道：

```
若人多贪求，积财无厌足，
如是狂乱人，名为最贫者。
王恒多赋税，横罚无过人，
爱著于国城，不观来世业。
于世得自在，不能荫群生，
见诸贫苦人，曾无怜愍念。
耽染于女人，不惧于恶道，
邪乱未常觉，岂非贫穷者？
若人知净信，归依佛法僧，
于身及命财，常念不坚固。
知不坚固已，于彼不迷惑，
能于身命财，永得常坚固。
若能勤念住，乐于不放逸，
彼人名富贵，善财常安乐。
如火焚烧时，不厌于林树，
王今亦如是，贪爱无厌足。
水不厌于云，海不厌于水，
王今亦如是，何有厌足时。
日月常巡历，不厌于四方，
王今亦如是，终命无休息。
如火焚烧时，不厌于草木，
智人亦如是，未甞不行善。
如水不厌云，如海不厌水，
智人亦如是，不厌善增长。
王位虽自在，毕竟归无常，
一切皆不净，智者应舍离。
```
（大意：若人多所贪求，积财没有厌足，这样狂乱的人名为最贫穷的人。王恒常多征赋税，横加处罚无过之人，爱著于国土城邑，不观察来世之业。在世间得自在，却不能庇荫群生，见到种种贫苦之人，从无怜愍之念。耽染于女人，不惧怕恶道，邪乱而从未觉察，难道不是贫穷的人吗？若人懂得净信，归依佛、法、僧，对身、命、财常念其不坚固；知道它们不坚固之后，对它们不再迷惑，便能对身、命、财永远得到常住坚固。若能勤于念住，乐于不放逸，那人名为富贵，有善财而常得安乐。如火焚烧时不厌足于林树，王现在也是这样，贪爱无有厌足。水不厌足于云，海不厌足于水，王现在也是这样，哪有厌足之时？日月常常巡行，不厌足于四方，王现在也是这样，直至命终都不休息。如火焚烧时不厌足于草木，智人也是这样，从未不行善。如水不厌足于云，如海不厌足于水，智人也是这样，不厌足于善的增长。王位虽然自在，毕竟归于无常，一切都不清净，智者应当舍离。）

【按】“邪乱未常觉”之“常”，宋、元、明、宫本作“甞”，今依此译作“从未觉察”。

#### 佛从地涌出为证

那时波斯匿王听了这话，内心惭愧，对菩萨说：“善哉仁者！你虽然善于劝导，我还是不信。现在你这话，是你自己说的？还是有证明的？”菩萨回答：“你没有听说吗？如来、应、正等觉具足一切智，现在正与无量天人、乾闼婆、阿修罗等在舍卫大城祇树给孤独园，他当证明大王是贫穷之人。”王说：“仁者！若如你所说，我愿与你一同去见如来，听闻教诲，归依供养。”菩萨回答：“大王应当知道，如来的境界不是诸凡愚所能测度的，他破除了烦恼与憍慢，哀愍众生，已以圣智能知此世以及来世。若有善根与殊胜意乐的人，虽然在极远之处，佛也常加护念。若佛知道我的心，想令大王对我生信，必定会来这里为我作证。”

【按】“今者现与”之“现”，宋、宫本作“见”。“无量天人”之“天”，《大正藏》作“大”，今依CBETA（所录高丽藏）作“天”，宫本同。

那时菩萨便在王前偏袒一肩，右膝著地，合掌恭敬，以偈颂请如来说：

```
如来真实智，悲愍诸群生，
愿知我深心，垂哀为作证。
```
（大意：如来具真实之智，悲愍群生，愿知我的深心，垂哀为我作证。）

那时菩萨说偈请佛之后，那大地忽然震裂。五百声闻、一万菩萨、梵天帝释诸天以及龙、鬼，无量众生围绕如来，从地中涌出。善顺菩萨合掌恭敬，上前对佛说：“世尊！我先前在这舍卫城中游化往来，得到一只劫初时的阎浮金铃，那铃的价值超过阎浮提。我当时便这样想：‘若舍卫城中有最贫穷的众生，当以这铃施给他。’又自己思惟：‘波斯匿王在这城中最为贫穷。为什么呢？他依恃王位，对众生从未怜愍，残害剥夺，欺骗掠夺，横加侵损，被贪爱覆蔽而不知厌足。’我以这位国王为最贫穷的人，想把金铃施给他。王问我说：‘说我贫穷，谁来作证？’我又回答说：‘如来大师、应、正等觉，舍离烦恼瞋垢无余，对众生都平等，当为我作证。’唯愿世尊示教利喜。”

【按】“从地踊出”之“踊”，宋、元、明、宫本作“涌”。“欲将金铃”之“欲”，明本作“故”。“唯愿”之“唯”，明本作“惟”。

#### 佛说贫富之法

那时世尊为了调伏波斯匿王，告诉他说：“大王应当知道，在某种法上，善顺贫穷，王为富贵。在某种法上，王为贫穷，善顺富贵。为什么呢？身登王位，在世间自在，金、银、摩尼、砗磲、珊瑚，库藏盈满；就这一点而言，善顺贫穷，王为富贵。勤修梵行，乐于清净尸罗，舍家而多闻，远离种种放逸，持八斋五戒，弘济无疲。在这一点上，王实在贫穷，善顺富贵。王现在应当知道，憍萨罗国一切众生的财物库藏，与善顺坚固清净的五戒八斋相比，百分不及一，千分不及一，乃至俱胝分也不及一。”

【按】“车𤦲”之“𤦲”字先前电子文本未能显示，今据CBETA补出，同“璩”，“车𤦲”即砗磲。

那时波斯匿王亲闻如来真实的教诲，舍弃憍慢，合掌殷勤，瞻仰善顺，说偈道：

```
善哉摧伏我憍慢，
当得如来最胜身，
以此王位舍于汝，
愿恒为汝菩提众。
我实贫穷汝为富，
今知此说非妄言，
王位徒为众苦因，
背于白法生恶趣。
```
（大意：善哉，你摧伏了我的憍慢，你当得如来最胜之身；我以这王位舍给你，愿恒常作你菩提道中的眷属。我确实贫穷，你才富有，现在知道这话不是妄言；王位只是众苦之因，背离白净之法而生于恶趣。）

【按】“摧伏”之“摧”，《大正藏》作“推”，今依CBETA作“摧”。

那时波斯匿王说了这偈之后，对佛说：“世尊！我现在发起无上大菩提心，愿令众生安乐，解脱生死系缚。我现在愿把财物库藏、金银之类分为三分：一分奉施如来世尊以及比丘众，一分施与舍卫城中贫穷苦恼、无依无靠的人，一分财物留作国用。凡我所有的园林、池沼、花果，都愿奉施最胜如来以及比丘众。唯愿世尊垂哀纳受。”那时憍萨罗国五百位长者见到这件事，都发起无上大菩提心。

#### 佛说三无量资粮与三十二法

那时善顺菩萨对佛说：“世尊！唯愿如来为大众宣说法要，令遇到如来的众生不致空过。”那时世尊告诉众人说：“善男子们，有三种无量的功德资粮，诸如来虽有称说，尚且说不尽，何况声闻等二乘。哪三种？一是护持正法，二是发菩提心，三是劝众生发起无上之愿。

【按】“声闻诸三乘等”之“三”，宋、元、明、宫本作“二”，今依此译作“二乘”。

“又有三十二法，若善男子、善女人能勤加修习，便是见到如来而不空过。一是对诸如来生起不坏之信，二是护持正法令其久住，三是对可尊重的僧众不轻慢，四是对应受供养的人恭敬亲近，五是对所爱与所憎心常平等，六是恒常对正法乐闻恭敬，七是安住于寂静、远离喧闹，八是对如来乘演说无倦，九是说法时不为名利，十是志求真实、如理勤修，十一是舍施，十二是持戒，十三是忍辱，十四是精进，十五是禅定，十六是正慧，十七是对众生随其所乐而护念，十八是成熟众生而不忘失法，十九是恒常对自身善加调伏，二十是以善法要义调伏他人，二十一是不染烦恼，二十二是常乐出家，二十三是住阿兰若，二十四是于圣种喜足，二十五是勤行头陀，二十六是舍弃不善之法，二十七是弘誓坚固，二十八是住阿兰若而不懈，二十九是种植众善之本，三十是常不放逸，三十一是远离二乘之见，三十二是赞叹大乘。”

【按】“不忘失法”之“忘”，《大正藏》作“妄”，今依CBETA（所录高丽藏）作“忘”。“植众善本”之“植”，宋、元、宫本作“殖”。

于是五百比丘听了这法，远尘离垢，得法眼净。又有一万二千众生同发阿耨多罗三藐三菩提心。那时世尊以法教化，令众生获得善利之后，与比丘们以及其余前来的大众忽然不见。

【按】“远尘离垢”，明本作“远离尘垢”。

#### 善顺不受王衣

那时波斯匿王见到这件事，踊跃欢喜，便以价值百千两金的两件衣服施给善顺菩萨，这样说：“善哉仁者！愿垂哀纳受。”善顺菩萨告诉国王说：“大王应当知道，我对这衣不应接受。为什么呢？我自有百衲之衣，常挂在树枝上作为箱箧，一切众生都没有欺夺之想。我自身既无悭吝之心，也令他人不生爱著，这样的布施名为清净施。”当时波斯匿王又这样说：“你若不接受，愿你为我用脚踏一踏它，令我长夜安乐利益。”菩萨那时为了国王，便以双足踏这两件衣服。当时波斯匿王对菩萨说：“现在这衣服，已由你为我受讫。我还拿它做什么用？”善顺菩萨告诉国王说：“你拿这衣服，施给城中贫穷苦恼、无依无靠的人。”

【按】“然我自有”之“然”，宫本无。“百衲”之“衲”，宋、元、明、宫本作“纳”。“时波斯匿王复作是言”之“王”，宫本无。

那时波斯匿王依菩萨的教导，拿着这两件衣服，集合贫人布施给他们。当时诸贫人接触到这衣服的，狂者恢复心智，聋者得以听闻，盲者得以看见，诸根不具者都得具足，这是由于菩萨的威神之力。那时众人一同发声说：“我们现在拿什么报答菩萨的恩德？”那时空中有声音告诉他们：“诸人应当知道，对善顺菩萨不能以花香饮食来报恩，只应当迅速发菩提心。”当时五百位贫人听到空中有这样的声音，都说偈道：

```
我等今者，发菩提心，当成正觉，说诸胜法。
于诸众生，施以安乐，我乐菩提，得佛法故。
```
（大意：我们现在发菩提心，将成正觉，宣说种种殊胜之法。对众生施予安乐，我们乐于菩提，是为了得到佛法。）

#### 菩萨眷属

那时波斯匿王对菩萨说：“善哉仁者！你若要前往那里去见如来，愿及时告诉我，我当随从。”善顺菩萨说：“大王应当知道，诸佛难以值遇，正法难以听闻，岂能只有大王独自前往？应当为众生作善友。王应当在这舍卫城中敕令人民都随从前往，违背王命的，以王法惩治。为什么呢？诸菩萨尚且有眷属围绕庄严，何况国王。”当时波斯匿王对菩萨说：“什么是菩萨的眷属？”菩萨回答：“劝发菩提心是菩萨的眷属，因为令人觉悟。劝见如来是菩萨的眷属，因为不虚妄。劝闻正法是菩萨的眷属，因为获得多闻。劝见圣众是菩萨的眷属，因为得到善友。四摄是菩萨的眷属，因为摄受众生。六波罗蜜是菩萨的眷属，因为增长菩提。三十七品是菩萨的眷属，因为趣向道场。菩萨有这样的眷属庄严侍卫，能摧伏魔军，乃至作狮子吼，登上最胜之处。”

那时波斯匿王以及大众欢喜踊跃，九千众生远离烦恼之垢，得清净眼。

佛说此经之后，善顺菩萨、波斯匿王以及诸天、人、乾闼婆、阿修罗等，听闻佛所说，欢喜奉行。
