# 《大宝积经》卷第一百一十一（净信童女会、弥勒菩萨问八法会、弥勒菩萨所问会）

唐·三藏菩提流志 奉诏译

## 净信童女会第四十

【按】译者题名，明本无“大”字，“三藏”作“三藏法师”；“诏”，圣、宫本作“诰”。本会未见汉译异本。

#### 序分

如是我闻：一时，佛在舍卫国祇树给孤独园，与大比丘众五百人在一起。又有菩萨摩诃萨八千人，都是众人所知识的，得陀罗尼，辩才无碍，具足诸忍，降伏魔怨，已获得诸如来所得之法。他们的名字是：持世菩萨、持道菩萨、持地菩萨、持大地菩萨、乐慧菩萨、令信乐菩萨、妙色庄严菩萨、宝焰菩萨、宝幢菩萨、宝思菩萨、宝处菩萨、宝慧菩萨、宝德菩萨、宝光菩萨；又有贤劫诸菩萨等，以弥勒菩萨为上首；又有六十位心不可比喻的诸菩萨等，以文殊师利为上首；又有十六位大士，以贤护菩萨为上首；又有二万兜率天子一同在会中。

那时世尊处在大庄严藏师子之座上，无量百千大众围绕，光明照耀犹如日月，威德殊胜如帝释、梵王，高出大众如须弥山，光焰猛盛犹如大火炬，顾视安详如大象王，说法无畏如师子吼，覆盖诸大众如罗睺罗阿修罗王，相好庄严，威光炽盛，发出梵音声遍满三千大千世界，为了觉悟一切众生，普令安住于决定的胜义，在大众中演说佛法。

#### 净信童女以偈请问

那时波斯匿王所生的爱女，名为净信，年纪幼小，颜貌端严，为众生所乐见。她宿世种植善本，修习大乘，与五百童女前后围绕，各自拿着金鬘，出舍卫城，前往祇陀林。到了如来所，顶礼佛足，右绕三圈，退住一边，便在佛前说偈道：

```
久积福善清净业，
满足无边功德海，
令众信乐皆欢喜，
故我顶礼牟尼尊。
显现威光相奇特，
开示法门众宝处，
身光一寻常照曜，
我礼大慧清凉池。
功德大树福无尽，
人中最尊世所赞，
本愿戒行已圆满，
故我顶礼应供尊。
安住妙法常寂然，
等心世间如一子，
智慧善巧知诸行，
示平坦路如导师。
若有坚固勇进者，
慈悲利益众生类，
如是菩萨正修行，
唯愿如来为宣说。
```
（大意：久积福善与清净之业，圆满无边的功德之海，令众人信乐都欢喜，所以我顶礼牟尼尊。显现威光，相好奇特，开示法门众宝之处，身光一寻常常照耀，我礼敬这大慧的清凉之池。功德大树，福德无尽，人中最尊，为世所赞，本愿与戒行已经圆满，所以我顶礼应供尊。安住妙法，常寂然不动，平等看待世间如同一子，智慧善巧，了知诸行，如导师指示平坦之路。若有坚固勇进的人，以慈悲利益众生之类，这样的菩萨怎样正确修行，唯愿如来为我宣说。）

【按】“本愿戒行”之“本愿”，圣本作“大愿”。

```
云何当得坚固力，
安住生死降魔众？
云何当得平等法？
云何成熟诸众生？
云何如地如虚空，
如风如水亦如火？
云何得信住于法，
如彼须弥师子王？
云何远离憎爱心，
净意质直无谀谄？
云何出生施戒忍，
精进禅定及解脱，
智慧破诸烦恼暗，
而常安住大方便，
三昧总持无碍辩，
住四无量五神通？
云何得在诸佛前，
常受化生知宿命？
头陀无诤住兰若，
调伏其心灭烦恼，
持戒修习菩提道，
证甘露灭降魔怨，
施众安乐转法轮，
如是正道愿宣说。
```
（大意：怎样能得坚固之力，安住生死而降伏魔众？怎样能得平等之法？怎样成熟诸众生？怎样如地、如虚空、如风、如水，也如火？怎样得信而住于法，如那须弥山、如师子王？怎样远离憎爱之心，意念清净，质直而无谄谀？怎样出生布施、持戒、忍辱、精进、禅定以及解脱，以智慧破除诸烦恼之暗，而常安住于大方便，得三昧、总持、无碍辩才，住于四无量心与五神通？怎样能在诸佛面前常受化生，知晓宿命？怎样行头陀、无诤、住于兰若，调伏其心，灭除烦恼，持戒修习菩提之道，证甘露灭，降伏魔怨，施众安乐，转于法轮？这样的正道，愿为宣说。）

#### 八力：坚固勇猛于生死

那时世尊告诉净信童女说：“菩萨若能成就八种力，便能在生死中坚固勇猛而不疲倦。哪八种？一是志乐力，因为没有谄诳；二是胜解力，因为远离诸恶；三是加行力，因为常修善法；四是净信力，因为深信业报；五是菩提心力，因为不求小乘；六是大慈力，因为不害众生；七是大悲力，因为堪忍诸恶；八是善友力，因为时时警觉。童女！这名为八力。菩萨因为成就这样的力，坚固勇猛，在生死中无所染著。”

【按】“加行力”之“加”，宫本作“如”。

那时世尊又说偈道：

```
志乐勇猛，离诸谄诳，常行质直，正趣菩提。
以胜解力，远离众恶，纯修善行，住于正勤。
加行具足，恒善观察，精进坚固，安乐众生。
净信力故，了知业报，信于佛智，摄受世间。
菩提心力，远离小乘，不断佛种，安住法性。
大慈力故，等观众生，无爱无憎，不生恚害。
大悲力故，堪忍众恶，不染生死，亦无疲厌。
以善友力，常相警悟，心不退没，安住菩提。
彼勇进者，得是八力，当坐道场，破诸魔众。
```
（大意：志乐勇猛，远离种种谄诳，常行质直，正趣菩提。以胜解之力远离众恶，纯修善行，住于正勤。加行具足，常善观察，精进坚固，安乐众生。因为净信之力，了知业报，信于佛智，摄受世间。以菩提心之力远离小乘，不断佛种，安住法性。因为大慈之力，平等看待众生，无爱无憎，不生恚害。因为大悲之力，堪忍众恶，不染生死，也无疲厌。以善友之力，常相警醒觉悟，心不退没，安住菩提。那勇进之人得这八力，当坐道场，破诸魔众。）

【按】“重说偈言”之“重”，宋、元、明、宫本作“而”，下同。

#### 八法住于平等

“又，童女！菩萨成就八种法，便住于平等。哪八种？一是一切众生平等，因为本来无我；二是一切法平等，因为诸法寂静；三是一切刹土平等，因为入于空界；四是一切智平等，因为平等说法；五是一切行平等，因为因缘无自性；六是一切乘平等，因为同等无为；七是心平等，因为心如幻；八是诸魔平等，因为以烦恼为先，不可得。这是八法住于平等。”那时世尊又说偈道：

```
众生本无我，念念不可得，
住于平等者，应当如是观。
一切法平等，本性常空寂，
文字有分别，诸法本无差。
十方诸刹土，边际不可得，
其性如虚空，佛国常平等。
三世诸如来，住法界平等，
无边智解脱，佛佛皆如是。
众生本缘起，一切皆平等，
善知其所行，如应为开悟。
众生若干种，了知如幻化，
内外无所取，自性常清净。
诸乘种种说，无为性平等，
导师善方便，分别说三乘。
现住烦恼魔，烦恼无所有，
天魔及蕴死，境界悉皆空。
```
（大意：众生本来无我，念念不可得，住于平等的人应当这样观察。一切法平等，本性常空寂，文字上有分别，诸法本来没有差别。十方诸刹土，边际不可得，其性如虚空，佛国常平等。三世诸如来住于法界平等，无边的智慧与解脱，佛佛都是这样。众生本是缘起，一切都平等，善知其所行，如其所应为他们开悟。众生有若干种，了知如幻化，内外无所取，自性常清净。诸乘作种种说法，无为之性平等，导师以善巧方便，分别宣说三乘。现前住着烦恼魔，烦恼无所有，天魔以及蕴魔、死魔，境界都是空。）

#### 八法离诸憎爱

“又，童女！菩萨成就八种法，便离诸憎爱。哪八种？一是慈，二是悲，三是常行利益，四是不染世法，五是不执著自身，六是常修定心，七是舍离身命，八是观察烦恼。修这八法，能离憎爱。”那时世尊又说偈道：

```
坚被慈心铠，哀悲于一切，
安住平等心，则不生憎爱。
智人行利益，常施他安乐，
得利不自高，轻毁不生恨，
不为八风动，则不生憎爱。
于己若于他，不生憎爱想，
诸想悉舍离，境界无所著。
常自观其身，不惜于躯命，
智者于苦乐，不动如虚空。
善观察烦恼，我我所俱离，
持行恒如地，则不生憎爱。
```
（大意：坚固披上慈心之铠，哀悲一切众生，安住平等之心，便不生憎爱。智者行于利益，常施他人安乐，得利不自高，被轻毁不生恨，不为八风所动，便不生憎爱。对自己或对他人，不生憎爱之想，诸想全都舍离，对境界无所执著。常自观其身，不惜身躯性命，智者对于苦乐，不动如虚空。善于观察烦恼，我与我所都远离，持身行事常如大地，便不生憎爱。）

【按】“不惜于躯命”之“惜”，圣本作“憎”。

#### 八法于生死无疲倦

“又，童女！菩萨成就八种法，在生死中便没有疲倦。哪八种？一是因为善根广大；二是因为观察众生；三是因为常得见佛修习供养；四是因为得见无量诸佛刹；五是因为常求佛智；六是因为了知生死犹如梦；七是因为对殊胜之法没有怯弱；八是因为观察前际以及后际如同实际。”那时世尊又说偈道：

```
若诸行道者，修善无瑕垢，
如空月清净，度脱苦众生，
摄诸功德故，生死无疲倦。
观察众生性，坚固行精进，
于无量佛刹，恭敬供养佛，
是故十力者，生死无疲倦。
无量无边世，说不思议法，
不断三宝种，当成于法王，
坚持禁戒者，生死无疲倦。
了知生死性，如梦如云电，
于法得解脱，生死无疲倦。
安住于菩提，喜心常悦豫，
度于方便岸，生死无疲倦。
常修殊胜法，如空月增长，
爱乐佛功德，生死无疲倦。
生死无边际，常住于实际，
一念慧相应，生死无疲倦。
```
（大意：若诸行道之人修善而无瑕垢，如空中之月清净，度脱受苦众生，因为摄集种种功德，在生死中无疲倦。观察众生之性，坚固地行于精进，在无量佛刹恭敬供养佛，所以这具十力者在生死中无疲倦。在无量无边之世，宣说不思议法，不断三宝之种，当成为法王，坚持禁戒的人在生死中无疲倦。了知生死之性如梦、如云、如电，于法得解脱，在生死中无疲倦。安住于菩提，喜心常常悦豫，度到方便的彼岸，在生死中无疲倦。常修殊胜之法，如空中之月增长，爱乐佛的功德，在生死中无疲倦。生死没有边际，而常住于实际，一念与智慧相应，在生死中无疲倦。）

【按】“悦豫”之“豫”，宋、元、宫本作“预”。

#### 八法心界平等

“又，童女！成就八种法，心界便平等。哪八种？一是心如地，二是心如水，三是心如火，四是心如风，五是心如虚空，六是心等于法界，七是心等于解脱，八是心等于涅槃。这名为八种心界平等。”那时世尊又说偈道：

```
等心如地，荷负一切，于善于恶，无所增减。
等心如水，洗诸垢秽，养育世间，除烦恼渴。
等心如火，烧灭烦恼，大炬光明，无所不燎。
等心如风，无处无依，飃戒闻香，流遍三世。
等心如空，离见清净，遍入一切，而不随魔。
等心法界，善得安住，不增不减，常入平等。
声闻缘觉，所得解脱，无有缚者，亦无解者。
生死涅槃，无来无去，安住寂静，遍游三世。
```
（大意：平等之心如大地，荷负一切，对善对恶，无所增减。平等之心如水，洗除种种垢秽，养育世间，除去烦恼之渴。平等之心如火，烧灭烦恼，是大火炬的光明，无所不照。平等之心如风，无处无依，飘送戒闻之香，流遍三世。平等之心如虚空，离见而清净，遍入一切，而不随魔。平等之心如法界，善得安住，不增不减，常入平等。声闻、缘觉所得的解脱，没有被缚者，也没有解脱者。生死与涅槃，无来无去，安住寂静，遍游三世。）

#### 八法出生菩提

“又，童女！有八种法，菩萨成就，便出生菩提。哪八种？一是布施能出生，因为舍弃诸有；二是持戒能出生，因为无所违犯；三是忍辱能出生，因为没有瞋恚；四是精进能出生，因为不懈怠退转；五是禅定能出生，因为行于方便；六是智慧能出生，因为持戒多闻；七是梵住（四无量心）能出生，因为解脱寂静；八是神通能出生，因为常在定中。”那时世尊又说偈道：

```
常修行施者，离诸贪热恼，
不希求果报，回向佛菩提。
持戒为大乘，割截无瞋恨，
志求大安乐，除习证真灭。
菩萨行精进，多劫为众生，
忍苦游世间，精进力增长。
修行禅定者，远离诸戏论，
到诸禅彼岸，而不随禅生。
大慧无等伦，永离诸边见，
了知世空寂，痴暗灭无余。
寂静修梵住，净除诸恶道，
常为释梵王，勤修诸义利。
神通游佛刹，侍佛听闻法，
善知诸性欲，说法度众生。
```
（大意：常修行布施的人，远离种种贪爱的热恼，不希求果报，回向佛的菩提。持戒成就大乘，被割截身体也无瞋恨，志求大安乐，除去习气，证得真实的寂灭。菩萨行于精进，多劫为了众生，忍苦游于世间，精进之力增长。修行禅定的人远离种种戏论，到达诸禅的彼岸，而不随禅定受生。大智慧无与伦比，永离种种边见，了知世间空寂，愚痴之暗灭尽无余。寂静地修习梵住，净除诸恶道，常作帝释、梵王，勤修种种义利。以神通游于佛刹，侍奉佛，听闻法，善知众生的诸性与欲乐，说法度化众生。）

#### 八法得陀罗尼辩才无碍

“又，童女！菩萨成就八种法，便得陀罗尼与无碍辩才。哪八种？一是尊重法，二是承事和上（亲教师）与阿阇梨（轨范师），三是求法无厌，四是如所闻而演说，五是不悭吝法，六是不宣扬他人的恶，七是爱敬法师如同和上，八是不看他人的过失，而劝他离过。这名为八法，菩萨成就，便具足总持与无碍辩才。”那时世尊又说偈道：

【按】“和上”，明本作“和尚”。

```
志乐常求法，事师亲善友，
远离恶知识，得无尽藏持。
多闻无厌足，勇猛勤求法，
如闻而演说，不希求利养，
得清净辩才。能令众欢喜，
欣乐行法施，远离于悭嫉，
行法无所著，获得陀罗尼。
护戒自观身，不求他过失，
慈悲为依止，发语不非时，
当得无碍辩。度言说彼岸，
于善说法者，爱敬如师想，
隐过劝离恶，获无尽海持。
```
（大意：以志乐常求正法，事奉师长，亲近善友，远离恶知识，便得无尽藏的总持。多闻无厌足，勇猛勤求法，如所闻而演说，不希求利养，便得清净的辩才。能令大众欢喜，欣乐行于法施，远离悭吝嫉妒，行法无所执著，便获得陀罗尼。守护戒律，自观其身，不寻求他人过失，以慈悲为依止，发言不失时宜，当得无碍辩才，度到言说的彼岸。对善于说法的人，爱敬如同师长之想，隐覆他人之过，劝其离恶，便获得无尽之海的总持。）

#### 八法于佛前莲花化生

“又，童女！菩萨成就八种法，便在诸佛面前莲花化生。哪八种？一是乃至失去性命也不说他人的过失；二是劝化众生，令他们归依三宝；三是把一切众生安置于菩提心中；四是梵行无染；五是造立佛像，安置在莲花座上；六是对忧恼的众生，令他们除去忧恼；七是对贡高之人常自谦下；八是不恼害他人。”那时世尊又说偈道：

```
假令苦逼身，终不说他过，
常称叹三宝，化生诸佛前。
劝发菩提心，令求一切智，
常修于梵行，化生诸佛前。
黄金严佛像，坐宝莲花座，
除众生忧恼，化生诸佛前。
于彼憍慢人，谦卑如弟子，
不令他生恼，化生诸佛前。
```
（大意：假使苦痛逼身，终不说他人的过失，常称叹三宝，便化生于诸佛之前。劝人发菩提心，令他们求一切智，常修梵行，便化生于诸佛之前。以黄金庄严佛像，坐在宝莲花座上，除去众生的忧恼，便化生于诸佛之前。对那些憍慢之人，谦卑如同弟子，不令他人生恼，便化生于诸佛之前。）

#### 八法成就头陀，乐住兰若

“又，童女！有八种法，菩萨成就，便成就头陀功德，常乐住于阿兰若处。哪八种？一是少欲，二是知足，三是满足于善法，四是以善法自养，五是常持圣种，六是见到生死的过患，心常厌离，七是常观无常、苦、空、无我，八是深信坚固，不随他人之教。”那时世尊又说偈道：

```
少欲知足不放逸，
法喜众善为资养，
爱乐常修于圣种，
见生死患生怖心，
由是常乐行头陀，
如犀一角独无侣。
有为之法苦无我，
慧心深信住正勤，
自见于法不随他，
常处空闲佛所赞，
头陀远离无恼患，
无诸诤论众过失，
远离眷属绝称誉，
由是乐住阿兰若。
```
（大意：少欲知足而不放逸，以法喜与众善为资养，爱乐常修圣种，见生死之患而生怖畏之心，由此常乐行头陀，如犀牛的独角，独行无侣。有为之法是苦、无我，以智慧之心深信而住于正勤，自己见法而不随他人，常处空闲之处，为佛所赞叹。行头陀、远离尘嚣，没有恼患，没有种种诤论与众多过失，远离眷属，断绝称誉，由此乐住于阿兰若。）

#### 八法摧伏魔怨

“又，童女！菩萨成就八种法，便摧伏魔怨。哪八种？一是入于性空，二是信于无相，三是信于无愿，四是了知无作，五是内心没有疑惑，六是忍于无生，七是决了无自性，八是对一切法方便观察而不坏于真如。”那时世尊又说偈道：

```
于空无相及无愿，
得三解脱降魔怨。
有为无为无二相，
证于无生得解脱，
诸法无生如是忍，
彼等降伏诸魔怨。
于此无生无灭中，
蕴界无我犹如幻，
决定了知法无性，
不坏于如巧方便，
分别诸法为魔业，
舍离分别则降魔。
智慧方便二俱行，
若有若空无所住，
修习如是殊胜法，
得善方便妙色身。
```
（大意：于空、无相以及无愿，得三解脱而降伏魔怨。有为与无为没有二相，证于无生而得解脱，对诸法无生这样安忍，他们便降伏诸魔怨。在这无生无灭之中，蕴、界无我犹如幻化，决定了知诸法无自性，不坏真如而有善巧方便。分别诸法是魔业，舍离分别便降伏魔。智慧与方便二者俱行，于有于空都无所住，修习这样殊胜之法，便得善巧方便与妙色之身。）

#### 八法不离菩提

“又，童女！菩萨成就八种法，便不离菩提。哪八种？一是正见，因为要成熟持邪见的众生；二是正念，因为悲愍持邪念的众生；三是正语，因为怜愍种种邪语者；四是正业，因为要摄受种种邪业者；五是正精进，因为要度化邪勤者；六是正命，因为不舍弃邪命的众生；七是正思惟，因为要令众生离开邪思惟；八是正定，因为要令邪定者发起增进。”那时世尊又说偈道：

【按】“愍诸邪语”之“诸”，《北藏》作“语”。

```
成就正见者，化彼诸邪见；
常修行正念，哀悲邪念者；
清净正言说，愍诸邪语者；
安住于正业，摄诸邪业者；
常修于正勤，不舍邪勤者；
相应正净命，摄诸邪命者；
智者正思惟，哀愍邪思者；
常住于正定，摄诸邪定者。
无上八正道，安隐度暴流，
复渡漂流者，是大菩提道。
声闻及缘觉，草筏唯自渡，
菩萨广运济，如彼大船师。
```
（大意：成就正见的人，化导那些邪见者；常修行正念，哀悲那些邪念者；以清净的正确言说，怜愍那些邪语者；安住于正业，摄受那些邪业者；常修于正勤，不舍那些邪勤者；与清净的正命相应，摄受那些邪命者；智者正确思惟，哀愍那些邪思者；常住于正定，摄受那些邪定者。无上的八正道，安稳地度过暴流，又度那些漂流的人，这是大菩提之道。声闻以及缘觉，以草筏只是自度；菩萨广大运载济度，如那大船师。）

【按】“复渡漂流者”之“渡”，宋、元、明、宫本作“度”。“船师”之“船”，宋、元、宫本作“舡”。

#### 八法证甘露道

“又，童女！菩萨成就八种法，便证甘露之道。哪八种？一是住于无诤之法；二是善守无障碍之心；三是常观如实之义；四是住于菩提心，修习六念；五是精勤修习诸波罗蜜；六是积集善根，成熟众生；七是住于大悲，摄受正法；八是得无生忍，住于不退转。”那时世尊又说偈道：

```
常修无诤行，住大沙门法，
远离瞋恚过，积集诸善根。
善观如实义，得诸无尽辩，
安住菩提心，常念于无念。
一切波罗蜜，勤修无退转，
得诸方便力，由是度众生。
能以法王财，悲心施一切，
速证无生忍，不退转菩提。
若能如是行，佛法不难得，
不久降魔众，证最上菩提。
```
（大意：常修无诤之行，住于大沙门之法，远离瞋恚的过失，积集种种善根。善观如实之义，得种种无尽的辩才，安住于菩提心，常念于无念。对一切波罗蜜勤修而不退转，得种种方便之力，由此度化众生。能以法王之财，以悲心施与一切，迅速证得无生忍，于菩提不退转。若能这样修行，佛法便不难得，不久便降伏魔众，证得最上菩提。）

#### 八法转女身

那时净信童女听了这法，欢喜踊跃，对佛说：“世尊！成就几种法能转女身？”佛告诉童女：“成就八种法，当转女身。哪八种？一是不嫉妒，二是不悭吝，三是不谄曲，四是不瞋恚，五是说实语，六是不恶口，七是舍离贪欲，八是远离种种邪见。童女！修这八法，便迅速转女身。”

【按】“成熟几法”之“成熟”，宋、元、明、宫本作“成就”，今依此译作“成就”。

那时世尊又说偈道：

```
不嫉妬他人，离悭常乐法，
不行于谄诳，厌患女人身。
慈心舍离瞋，常修于实语，
除贪离恶口，安住正见中。
若厌女人身，应修如是法，
便当速得转，受善丈夫身。
```
（大意：不嫉妒他人，离开悭吝，常乐于法，不行谄诳，厌患女人之身。以慈心舍离瞋恚，常修实语，除去贪欲，远离恶口，安住于正见之中。若厌离女人之身，应当修习这样的法，便当迅速得以转身，受贤善的丈夫之身。）

“又，童女！成就八种法，能转女身。哪八种？一是尊重佛，深乐于法；二是恭敬供养持戒、忍辱、多闻的沙门、婆罗门；三是对丈夫、子女以及家居不生爱著；四是受持禁戒，无所缺犯；五是对一切人不生邪念；六是以增上的意乐厌离女身；七是住于菩提心的大丈夫之法；八是观察世间家业如幻如梦。”那时世尊又说偈道：

```
敬佛深乐法，尊重戒多闻，
不生贪爱心，女身速当转。
持戒具惭愧，不妄念他人，
安住菩提心，不乐余乘法，
由是速能转，不净女人身。
胜志得厌心，一切皆如幻，
诸法本无动，因缘性空寂，
勤修如实法，速得丈夫身。
```
（大意：敬佛，深乐于法，尊重持戒与多闻之人，不生贪爱之心，女身便当迅速转变。持戒，具足惭愧，不妄念他人，安住于菩提心，不乐于其余诸乘之法，由此便能迅速转变不净的女人之身。以殊胜的志愿生起厌离之心，（观）一切都如幻化，诸法本来不动，因缘之性空寂，勤修如实之法，便迅速得丈夫之身。）

#### 散鬘供佛，五百童女发愿

那时净信童女把所持的金鬘散在佛的上方，在虚空中变成真金的宫殿楼阁，宫殿中有化现的如来坐在金座上。那时五百童女各自解下身上的庄严之具，散在那佛的上方，也在空中变成金色楼阁，有宝帐、宝盖，种种庄严。那时五百童女见到大神变，异口同音说偈道：

```
世尊人中最殊胜，
哀愍利益诸众生，
我今已发菩提心，
志乐相应住调伏，
为世导师施安乐，
我当供养人中尊。
闻法已离于尘垢，
我等无复诸疑惑，
方离女身众染污，
永破烦恼降魔怨。
十方无量俱胝佛，
我当欢喜常供养，
安住施戒勤精进，
忍辱禅定善调心，
智慧方便摄众生，
当证最上菩提道。
利益无量人天众，
悉令发起大乘心，
我等当能师子吼，
我等当作人天师。
```
（大意：世尊在人中最为殊胜，哀愍利益诸众生。我们现在已发菩提心，与志乐相应，住于调伏，为世间导师施与安乐，我们当供养人中之尊。听闻佛法之后已离尘垢，我们不再有种种疑惑，正当离开女身的众多染污，永破烦恼，降伏魔怨。对十方无量俱胝诸佛，我们当欢喜常常供养，安住于布施、持戒，勤加精进，以忍辱、禅定善于调心，以智慧方便摄受众生，当证得最上的菩提之道。利益无量人天大众，令他们都发起大乘之心，我们当能作师子吼，我们当作人天之师。）

#### 如来微笑授记

那时世尊便现微笑，按照诸佛的常法，种种颜色的光——青、黄、赤、白、红、紫、玻璃色——从佛口中放出，遍照无量无边世界，乃至梵天世界，绕佛三圈，又从佛顶进入。那时长老阿难从座而起，对佛说：“世尊！以什么因、什么缘现这微笑？”佛告诉阿难：“你见到净信童女了吗？”阿难说：“是的，已经见到。”

佛说：“阿难！这净信等五百童女在人中寿尽后，当舍女身，生于兜率陀天，承事供养弥勒世尊以及贤劫中一切如来。这净信童女过八万四千俱胝那由他劫，在电光世界当得作佛，号为光明庄严王如来，劫名常光。那佛的寿命如兜率陀天的十二千岁，那国纯以无量无边的大菩萨众作为眷属，这五百童女在这众中最为上首，犹如我现在的六十位菩萨，以文殊师利为上首。阿难！若有女人得闻此经，受持读诵，尽此女身之后不再受女身，迅速证得阿耨多罗三藐三菩提。”

【按】“大菩萨众”之“众”，宫本无。

佛说此经之后，净信等五百童女，以及一切世间天、人、阿修罗，听闻佛所说，都大欢喜，信受奉行。

## 弥勒菩萨问八法会第四十一

元魏·三藏菩提留支 译

【按】译者题名“元魏”之“元”，圣本作“后”。本会未见汉译异本。

#### 弥勒请问

如是我闻：一时，婆伽婆住在王舍城耆阇崛山中，与大比丘众一千二百五十人在一起，以及诸菩萨摩诃萨一万人等。那时弥勒菩萨摩诃萨便从座起，偏袒右肩，右膝著地，合掌向佛，对佛说：“世尊！我现在想以少许法问如来、应供、正遍知，不知世尊是否听许？”那时世尊告诉弥勒菩萨摩诃萨说：“弥勒！随你心中所想，问如来、应供、正遍知，我当为你分别解说，令你心中欢喜。”

那时弥勒菩萨摩诃萨对佛说：“世尊！是的，愿乐欲闻。世尊！诸菩萨摩诃萨究竟成就几种法，便于阿耨多罗三藐三菩提不退，在胜进之法中不退不转，行菩萨行时降伏一切诸魔怨敌，如实了知一切法的自体之相，对诸世间心不疲倦，因为心不疲倦的缘故不依他人之智，迅速成就阿耨多罗三藐三菩提？”

那时世尊告诉弥勒菩萨摩诃萨说：“善哉善哉。弥勒！你现在竟能问如来这样深的义理。”佛又告诉弥勒菩萨摩诃萨说：“你现在应当一心谛听，我当为你分别解说这样深的义理。”当即弥勒菩萨摩诃萨对佛说：“世尊！是的，愿乐欲闻。”

#### 八法总标

佛又告诉弥勒菩萨摩诃萨说：“弥勒！若诸菩萨摩诃萨究竟成就八种法，便于阿耨多罗三藐三菩提不退，在胜进之法中不退不转，行菩萨行时降伏一切诸魔怨敌，如实了知一切法的自体之相，对诸世间心不疲倦，因为心不疲倦的缘故不依他人之智，迅速成就阿耨多罗三藐三菩提。哪八种？弥勒！就是诸菩萨摩诃萨成就深心，成就行心，成就舍心，成就善知回向方便之心，成就大慈心，成就大悲心，成就善知方便，成就般若波罗蜜。

#### 深心、行心、舍心

“弥勒！怎样是诸菩萨摩诃萨成就深心？弥勒！若诸菩萨摩诃萨听到赞叹佛以及毁谤佛，他的心终究对阿耨多罗三藐三菩提坚固不动；听到赞叹法以及毁谤法，他的心终究对阿耨多罗三藐三菩提坚固不动；听到赞叹僧以及毁谤僧，他的心终究对阿耨多罗三藐三菩提坚固不动。弥勒！这样是诸菩萨摩诃萨究竟成就深心。

“弥勒！怎样是诸菩萨摩诃萨成就行心？弥勒！若诸菩萨摩诃萨远离杀生，远离偷盗，远离邪婬，远离妄语，远离两舌，远离恶口，远离绮语，弥勒！这样是诸菩萨摩诃萨究竟成就行心。

“弥勒！怎样是诸菩萨摩诃萨成就舍心？弥勒！若诸菩萨摩诃萨是能舍之主，是施主，布施给诸沙门以及婆罗门、贫穷乞丐、下贱之人等衣服、饮食、卧具、随病所需的汤药等所需之物，弥勒！这样是诸菩萨摩诃萨究竟成就舍心。

#### 回向方便心、大慈心、大悲心

“弥勒！怎样是诸菩萨摩诃萨成就善知回向方便之心？弥勒！若诸菩萨摩诃萨所修的善根，就是身、口、意之业，都回向阿耨多罗三藐三菩提，弥勒！这样是诸菩萨摩诃萨究竟成就善知回向方便之心。

“弥勒！怎样是诸菩萨摩诃萨成就大慈心？弥勒！若诸菩萨摩诃萨究竟成就大慈的身业，究竟成就大慈的口业，究竟成就大慈的意业，弥勒！这样是诸菩萨摩诃萨究竟成就大慈心。

“弥勒！怎样是诸菩萨摩诃萨成就大悲心？弥勒！若诸菩萨摩诃萨究竟成就不可讥呵的身业，究竟成就不可讥呵的口业，究竟成就不可讥呵的意业，弥勒！这样是诸菩萨摩诃萨究竟成就大悲心。

#### 善知方便、般若波罗蜜

“弥勒！怎样是诸菩萨摩诃萨成就善知方便？弥勒！若诸菩萨摩诃萨善知世俗谛，善知第一义谛，善知二谛，弥勒！这样是诸菩萨摩诃萨究竟成就善知方便。

“弥勒！怎样是诸菩萨摩诃萨成就般若波罗蜜？弥勒！若诸菩萨摩诃萨这样觉知：依这法便有这法，依这法生便生这法，就是无明缘行，行缘识，识缘名色，名色缘六入，六入缘触，触缘受，受缘爱，爱缘取，取缘有，有缘生，生缘老死忧悲苦恼，这样只有大苦聚集。弥勒！这法无故这法无，这法灭故这法灭，就是无明灭则行灭，行灭则识灭，识灭则名色灭，名色灭则六入灭，六入灭则触灭，触灭则受灭，受灭则爱灭，爱灭则取灭，取灭则有灭，有灭则生灭，生灭则老死忧悲苦恼灭，这样只有大苦聚集灭。弥勒！这样是诸菩萨摩诃萨究竟成就般若波罗蜜。

#### 总结与流通

“弥勒！这名为诸菩萨摩诃萨究竟成就八种法，便于阿耨多罗三藐三菩提不退，在胜进之法中不退不转，行菩萨行时降伏一切诸魔怨敌，如实了知一切法的自体之相，对诸世间心不疲倦，因为心不疲倦的缘故不依他人之智，迅速成就阿耨多罗三藐三菩提。”

佛说此经之后，弥勒菩萨摩诃萨以及其余诸菩萨摩诃萨，比丘、比丘尼、优婆塞、优婆夷，天、龙、夜叉、乾闼婆、阿修罗、迦楼罗、紧那罗、摩睺罗伽、人非人等，一切大众听闻佛所说，都大欢喜，信受奉行。

## 弥勒菩萨所问会第四十二

唐·三藏菩提流志 译

【按】译者题名“大唐三藏菩提流志译”，明本无“大”字；“译”，宋、元、明、宫本作“新译”；圣本此行作“西晋三藏竺法护译”。本会异译有西晋竺法护译《弥勒菩萨所问本愿经》（T0349）。

#### 序分

如是我闻：一时，佛在波罗奈国施鹿林中，与大比丘众五百人在一起，都是众人所知识的。他们的名字是：阿若憍陈如、摩诃迦叶、优楼频螺迦叶、伽耶迦叶、那提迦叶、舍利弗、大目犍连、阿难、罗睺罗等，作为上首。又有菩萨摩诃萨一万人在一起，他们的名字是：善意菩萨、增上意菩萨、坚固意菩萨、师子意菩萨、观世音菩萨、大势至菩萨、辩积菩萨、美音菩萨、胜幢菩萨、信慧菩萨、水天菩萨、帝胜菩萨、帝天菩萨、无攀缘菩萨、具辩才菩萨、神通妙华菩萨、弥勒菩萨、文殊师利法王子等，作为上首。那时世尊被无量百千大众围绕，供养恭敬，佛为他们说法。

#### 弥勒请问

这时弥勒菩萨摩诃萨在众会中，便从座起，偏袒右肩，右膝著地，合掌顶礼，对佛说：“世尊！我有少许疑惑，现在想要咨问，唯愿如来垂允听许。”佛告诉弥勒菩萨说：“若有所疑，现在任你提问，当为你解说，令你欢喜。”那时弥勒菩萨听到佛允许后，欢喜踊跃，对佛说：“世尊！菩萨成就几种法，便离开诸恶道以及恶知识，而能迅速证得阿耨多罗三藐三菩提？”

佛告诉弥勒菩萨说：“善哉善哉。弥勒！你现在为了哀愍一切，利益安乐天人世间，能问如来这样深的义理。你应当谛听，好好思念，我当为你分别解说。”弥勒菩萨便对佛说：“是的，世尊！愿乐欲闻。”

【按】“佛告弥勒言”之“言”，宫本无。

#### 一法至十法

佛告诉弥勒说：“菩萨成就一种法，便离开诸恶道以及恶知识，能迅速证得阿耨多罗三藐三菩提。哪一种？就是发起殊胜意乐的菩提之心，这名为一。

“弥勒！又有二种法，离开诸恶道以及恶知识，能迅速证得阿耨多罗三藐三菩提。哪二种？一是对奢摩他（止）常勤修习，二是对毗钵舍那（观）得以善巧，这名为二。

【按】“云何为二”之“何为”，《大正藏》作“为何”，今依CBETA（所录高丽藏）作“何为”。

“弥勒！又有三种法，离开诸恶道以及恶知识，能迅速证得阿耨多罗三藐三菩提。哪三种？一是成就大悲，二是修习空法，三是对一切法不生分别，这名为三。

“弥勒！又有四种法，离开诸恶道以及恶知识，能迅速证得阿耨多罗三藐三菩提。哪四种？一是安住净戒，二是离开种种疑网，三是乐住阿兰若，四是生起正见之心，这名为四。

“弥勒！又有五种法，离开诸恶道以及恶知识，能迅速证得阿耨多罗三藐三菩提。哪五种？一是住于空法，二是不寻求他人过失，三是常自观察，四是爱乐正法，五是摄护他人，这名为五。

“弥勒！又有六种法，离开诸恶道以及恶知识，能迅速证得阿耨多罗三藐三菩提。哪六种？一是没有贪欲，二是不生瞋恚，三是不起愚痴，四是常离粗恶之语，五是住于空性，六是心如虚空，这名为六。

“弥勒！又有七种法，离开诸恶道以及恶知识，能迅速证得阿耨多罗三藐三菩提。哪七种？一是住于正念，二是成就择法，三是发起精进，四是常生欢喜，五是身得轻安，六是住于诸禅定，七是具足行舍，这名为七。

【按】“成就择法”之“择”，宫本作“释”。

“弥勒！又有八种法，离开诸恶道以及恶知识，能迅速证得阿耨多罗三藐三菩提。哪八种？一是正见，二是正思惟，三是正语，四是正业，五是正命，六是正勤，七是正念，八是正定，这名为八。

【按】“正勤”之“勤”，宫本作“勒”。

“弥勒！又有九种法，离开诸恶道以及恶知识，能迅速证得阿耨多罗三藐三菩提。哪九种？一是远离诸欲与恶不善法，安住于初禅，有寻、有伺、喜、乐、心一境性；二是远离寻伺，安住于二禅，内净、喜、乐、心一境性；三是远离喜，安住于三禅，舍、念、慧、乐、心一境性；四是远离忧苦以及喜乐，安住于四禅，舍念清净，不苦不乐，心一境性；五是超过色想，没有种种异想攀缘，安住于无边虚空处定；六是超过无边空处定之后，能安住于无边识定；七是超过无边识处定之后，能安住于无所有定；八是超过无所有处定之后，安住于非想非非想定；九是超过非想非非想处定之后，能安住于灭受想定，这名为九。

【按】“速离诸欲”之“速离”，宋、元、明、宫本作“远离”，今依此译作“远离”。

“弥勒！又有十种法，离开诸恶道以及恶知识，能迅速证得阿耨多罗三藐三菩提。哪十种？一是善能成就金刚三昧，二是成就处非处相应三昧，三是成就方便行三昧，四是成就遍照明三昧，五是成就普光明三昧，六是成就普遍照明三昧，七是成就宝月三昧，八是成就月灯三昧，九是成就出离三昧，十是成就胜幢臂印三昧，这名为十。弥勒！菩萨成就这样的法之后，便离开诸恶道以及恶知识，能迅速证得阿耨多罗三藐三菩提。”

【按】“出离三昧”之“出离”，圣本作“生离”。

#### 弥勒以偈赞佛

那时弥勒菩萨听闻这法，心中大欢喜，偏袒右肩，右膝著地，合掌恭敬，便在佛前以偈赞叹道：

```
佛于过去劫，舍所爱妻子，
头目及骨髓，到于施彼岸。
佛常护禁戒，如牦牛爱尾，
最胜无伦匹，到于戒彼岸。
佛以忍辱力，舍离于违诤，

究竟常安乐，到于勤彼岸。

自性无所有，到于慧彼岸。
佛于菩提树，降伏诸魔军，
具足最胜智，成就无上道。
导师无畏力，于波罗奈国，
转清净法轮，摧破诸外道。

能放净光明，善说诸法要。
如来清净色，智慧及功德，
超过诸世间，能到于彼岸。

（大意：佛于过去劫中，舍弃所爱的妻子、头目以及骨髓，到达布施的彼岸。佛常守护禁戒，如牦牛爱惜其尾，最胜无与伦比，到达持戒的彼岸。佛以忍辱之力舍离种种违逆诤论，不寻求他人的过恶，到达忍辱的彼岸。佛以精进之力得无上寂静，究竟常住安乐，到达精进的彼岸。佛以禅定之力能灭种种罪垢，为天人导师，到达禅定的彼岸。佛以智慧之力善于了知诸法自性无所有，到达智慧的彼岸。佛在菩提树下降伏诸魔军，具足最胜之智，成就无上之道。导师以无畏之力，在波罗奈国转清净法轮，摧破诸外道。无上的大智慧超出于世间，能放清净光明，善说诸法要。如来清净之色身、智慧以及功德，超过诸世间，能到于彼岸。）

#### 弥勒往昔作贤寿得忍

那时阿难对佛说：“世尊！这位弥勒菩萨甚为稀有，能成就无量辩才，随众生之念平等说法，而对文字无所系著。”佛告诉阿难：“是这样，是这样，如你所说。阿难！弥勒菩萨岂只今日能在我面前以偈赞佛。往昔过去十无数劫，那时有佛，号为焰光游戏妙音自在王如来、应供、正遍知、明行足、善逝、世间解、无上士、调御丈夫、天人师、佛、世尊。

【按】“乃往过去”之“去”，宫本作“云”。

```
佛于十方界，最尊无有上，
超过诸世间，我今稽首礼。

#### 二种摄取庄严；释迦超九劫

阿难对佛说：“世尊！若弥勒菩萨早已证得无生法忍，为什么还未得阿耨多罗三藐三菩提？”佛告诉阿难：“菩萨有两种庄严、两种摄取，就是摄取众生、庄严众生，摄取佛国、庄严佛国。弥勒菩萨在过去世修菩萨行，常乐摄取佛国、庄严佛国；我在往昔修菩萨行，常乐摄取众生、庄严众生。那弥勒修菩萨行已经过了四十劫，我那时才发阿耨多罗三藐三菩提心，由于我勇猛精进之力，便超越了九劫，在贤劫中得阿耨多罗三藐三菩提。

“阿难！我以十种法得证菩提。哪十种？一是能施所爱之物，二是能施所爱之妻，三是能施所爱之子，四是能施所爱之头，五是能施所爱之眼，六是能施所爱的王位，七是能施所爱的珍宝，八是能施所爱的血肉，九是能施所爱的骨髓，十是能施所爱的肢体，这名为十。我行这法，能得阿耨多罗三藐三菩提。

“阿难！又有十种法能证菩提。哪十种？一是获得持戒的功德，二是成就忍辱之力，三是发起精进，四是得种种禅定，五是有大智慧，六是对诸众生常不舍离，七是对诸众生生起平等心，八是对种种空法常常修习，九是善能成就真实空性，十是善能成就无相、无愿，这名为十。我行这法，能得阿耨多罗三藐三菩提。阿难！弥勒菩萨往昔行菩萨道时，不能舍施手足头目，只以善巧方便的安乐之道，积集无上正等菩提。”

【按】“获戒功德”之“获戒”，元、明本作“护戒”。“积集无上”之“上”，宫本作“二”。

#### 弥勒往昔六时忏悔之偈

那时阿难对佛说：“世尊！弥勒往昔行菩萨道时，怎样只以善巧方便的安乐之道，而能积集无上菩提？”佛告诉阿难：“弥勒往昔行菩萨道时，昼夜六时偏袒右肩，右膝著地，合掌顶礼，在诸佛面前说这偈道：

```
我今归命礼，十方一切佛，
菩萨声闻众，大仙天眼者。
亦礼菩提心，远离诸恶道，
能得生天上，乃至证涅槃。
若我作少罪，随心之所生，
今对诸佛前，忏悔令除灭。
我今身口意，所集诸功德，
愿作菩提因，当成无上道。
十方国土中，供养如来者，
及佛无上智，我今尽随喜。
有罪悉忏悔，是福皆随喜，
我今礼诸佛，愿成无上智。
十方大菩萨，证于十地者，
我今稽首礼，愿速证菩提。
得证菩提已，摧伏于魔军，
转清净法轮，饶益众生类。
常愿住世间，无量俱胝劫，
击于大法鼓，度脱苦众生。
```
（大意：我现在归命礼敬十方一切佛、菩萨、声闻众以及具天眼的大仙。也礼敬菩提心，它能远离诸恶道，能令人生于天上，乃至证得涅槃。若我作了少许罪，随心所生起的，现在对诸佛面前忏悔，令其除灭。我现在以身口意所积集的种种功德，愿作菩提之因，当成无上之道。对十方国土中供养如来的人，以及佛的无上之智，我现在完全随喜。有罪都忏悔，有福都随喜，我现在礼敬诸佛，愿成就无上之智。对十方证于十地的大菩萨，我现在稽首礼敬，愿他们迅速证得菩提。证得菩提之后，摧伏魔军，转清净法轮，饶益众生之类。愿他们常住世间无量俱胝劫，击大法鼓，度脱受苦的众生。）

```
我没于欲泥，贪绳之所系，
种种多缠缚，愿佛垂观察。
众生虽垢重，诸佛不厌舍，
愿以大慈悲，度脱生死海。
现在诸世尊，过去未来佛，
所行菩萨道，我今愿修学。
具足波罗蜜，成就六神通，
度脱诸众生，证于无上道。
了知诸法空，无相无自性，
无住无表示，不生亦不灭。
又如大仙尊，善了于无我，
无补特伽罗，乃至无寿者。
```
（大意：我沉没在欲望的泥中，被贪爱之绳所系缚，有种种众多的缠缚，愿佛垂念观察。众生虽然垢重，诸佛不厌舍，愿以大慈悲度脱生死之海。现在诸世尊、过去与未来之佛所行的菩萨道，我现在愿修学。具足波罗蜜，成就六神通，度脱诸众生，证于无上之道。了知诸法空，无相，无自性，无住，无表示，不生也不灭。又如大仙尊善于了知无我，没有补特伽罗（人我），乃至没有寿者。）

【按】“度脱生死海”，圣本作“哀愍常摄护”。

```
于诸布施事，不执我我所，
为安乐众生，施与无悭悋。
愿我所施物，不假功用生，
观察了知空，具施波罗蜜。
持戒无缺减，得佛净尸罗，
以无所住故，具戒波罗蜜。
忍辱如四大，不生分别心，
以无瞋恚故，具忍波罗蜜。
愿以身心力，发起大精进，
坚固无懈怠，具勤波罗蜜。
以如幻如化，及勇猛精进，
金刚等三昧，具禅波罗蜜。
愿证三明智，入于三脱门，
了三世平等，具慧波罗蜜。
诸佛妙色身，光明大威德，
菩萨精进行，愿我皆圆满。
```
（大意：对种种布施之事，不执著我与我所，为了安乐众生，施与而无悭吝。愿我所施之物，不假造作之功而生，观察了知其空，具足布施波罗蜜。持戒无缺减，得佛的清净尸罗，以无所住的缘故，具足持戒波罗蜜。忍辱如四大，不生分别之心，以无瞋恚的缘故，具足忍辱波罗蜜。愿以身心之力发起大精进，坚固无懈怠，具足精进波罗蜜。以如幻、如化以及勇猛精进的金刚等三昧，具足禅定波罗蜜。愿证三明之智，入于三解脱门，了知三世平等，具足智慧波罗蜜。诸佛美妙的色身、光明、大威德，以及菩萨的精进之行，愿我都能圆满。）

【按】“愿证三明智”之“三明”，元、明本作“三昧”。

```
弥勒名称者，勤修如是行，
具六波罗蜜，安住于十地。
```
（大意：有名称的弥勒，勤修这样的行，具足六波罗蜜，安住于十地。）

#### 释迦往昔舍身血

佛告诉阿难：“弥勒菩萨安住于这样的善巧方便，积集阿耨多罗三藐三菩提。阿难！我往昔求道受苦无量，才能积集阿耨多罗三藐三菩提。为什么呢？往昔古时有一位太子，名为见一切义，端正殊妙，诸相具足，见者欢喜。他出游园苑，见到一位病人受种种重苦，生起悲愍之心，便问他说：‘你现在这病，难道没有药能疗治吗？’那时病人便以偈颂对太子说：

```
我病药难求，世间不可得，
国王亦无有，何况病恼者。
通达于诸论，善说医方者，
虽欲为疗治，其药难可得。
```
（大意：我这病的药难求，世间不可得到，国王也没有，何况是病恼之人。通达诸论、善说医方的人，即使想要为我疗治，那药也难以得到。）

“那时太子又以偈颂告诉病人说：

```
金银摩尼珠，乃至于象马，
所求皆当说，为汝除忧恼。
```
（大意：金银、摩尼珠，乃至象马，所求的都应当说出来，我为你除去忧恼。）

“那时病人又以偈颂对太子说：

```
若饮太子血，我必得安乐。
愿生欢喜心，施我无忧恼。
```
（大意：若能喝太子的血，我必定能得安乐。愿你生欢喜心，施给我，令我没有忧恼。）

“那时太子又以偈颂告诉病人说：

```
我为诸众生，坠堕无间狱，
多劫犹能忍，何况于身血！
```
（大意：我为了诸众生，即使坠堕无间地狱，多劫之中尚且能忍，何况是身上的血！）

【按】“无间狱”之“间”，宫本作“明”。

“那时太子便取利刀刺身出血，令那病人随意取用，不生一念悔恨之心。阿难应当知道，那时的太子见一切义难道是别人吗？就是现在的我身。四大海水尚且可以测量，我于往昔行菩萨道舍弃自身之血，不可称计。”

【按】“犹可测量”之“测”，《大正藏》作“侧”，今依CBETA作“测”。

#### 释迦往昔舍骨髓

佛告诉阿难：“往昔古时有一位太子，名为妙花，端正殊胜，诸相具足，见者欢喜。他从园苑出来，见到一位病人身体羸瘦，生起悲愍之心，便问他说：‘你现在这病，难道没有药能疗治吗？’那时病人便以偈颂对太子说：

```
世虽有良医，无药疗我病，
唯愿生慈愍，为我除忧恼。
```
（大意：世间虽有良医，却没有药能疗治我的病，唯愿你生起慈愍，为我除去忧恼。）

“那时太子便以偈颂告诉病人说：

```
我为利世间，一切咸施与，
身分及珍宝，须者皆当说。
```
（大意：我为了利益世间，一切都施与，身体各部分以及珍宝，需要的都应当说出来。）

“那时病人又以偈颂对太子说：

```
譬如大药王，随意疗众病，
亦如日月光，普照诸世间。
若能出身髓，遍涂于我身，
是病乃消除，长夜得安乐。
```
（大意：（你）譬如大药王，随意疗治众病，也如日月之光，普照诸世间。若能取出身中骨髓，遍涂我的身体，这病才能消除，长夜得以安乐。）

“那时太子又以偈颂告诉病人说：

```
若有诸众生，碎我身出髓，
为利于世间，心不生忧恼。
```
（大意：若有诸众生碎我身体取出骨髓，为了利益世间，我心中不生忧恼。）

“那时太子便自己碎身取出骨髓，给那病人随意取用，不生一念悔恨之心。阿难应当知道，那时的妙花太子难道是别人吗？就是现在的我身。四大海水尚且可以测量，我于往昔行菩萨道舍弃身中骨髓，不可称计。”

#### 释迦往昔舍眼

佛告诉阿难：“往昔古时有一位国王，名为月光，端正殊妙，诸相具足，见者欢喜。他从园苑出来，见到一位盲人贫穷乞讨，生起悲愍之心，便问他说：‘你需要什么，我当施给你。或饮食、衣服、庄严资具、金银、摩尼以及种种珍宝，随你所欲，都当给你。’那时盲人便以偈颂对国王说：

```
大王犹日月，光明照世间，
具足胜功德，不久生天上。
一切净妙色，我今悉不见，
愿王起慈悲，施我所爱眼。
```
（大意：大王犹如日月，光明照耀世间，具足殊胜功德，不久当生天上。一切清净美妙之色，我现在都看不见，愿大王生起慈悲，施给我所爱的眼睛。）

【按】“愿王起慈悲”之“起”，明本作“超”。

“那时大王便以偈颂告诉盲人说：

```
汝速来取眼，令汝得安乐。
愿我当来世，得佛清净眼。
我行菩萨道，一切皆当舍，
若我不施汝，是则违本愿。
```
（大意：你快来取眼，令你得到安乐。愿我在未来世得佛的清净之眼。我行菩萨道，一切都应当舍弃，若我不施给你，便是违背本愿。）

“那时月光王便取利刀，自己挖出眼睛，给那盲人随意取用，不生一念悔恨之心。阿难应当知道，那时的月光王难道是别人吗？就是我身。须弥山王尚且可以度量，我于往昔行菩萨道舍弃所爱之眼，不可称计。

#### 二佛本愿

“阿难！弥勒菩萨往昔修行菩萨道时，作这样的愿：‘若有众生婬怒痴淡薄，成就十善，我在那时才成阿耨多罗三藐三菩提。’阿难！在未来世有诸众生婬怒痴淡薄，成就十善，弥勒菩萨在那时当得阿耨多罗三藐三菩提。为什么呢？由于那菩萨的本愿之力。”

佛告诉阿难：“我于往昔行菩萨道，作这样的话：‘愿我当于五浊恶世，贪瞋垢重，诸恶众生不孝父母，不敬师长，乃至眷属不相和睦之时，我在那时当成阿耨多罗三藐三菩提。’阿难！因为这愿的缘故，我现在所入的城邑聚落，有很多众生毁骂我，以断见、常见之法招集众会；若行乞食时，有人以尘土撒我，有人和上种种杂毒给我吃，或以女人诽谤我。阿难！我现在以本愿之力，为这样等诸恶众生生起大悲心，而为他们说法。”

那时阿难对佛说：“世尊！如来、应供、正等觉能作难作之事，能忍难忍之事，对不调伏的都令其调伏，荷担这样罪垢深重的众生而为他们说法。”佛告诉阿难：“是这样，是这样，如你所说。为什么呢？因为被如来大悲所摄的缘故。”

【按】“荷担如是”之“是”，宫本作“来”。

#### 经名与流通

那时阿难对佛说：“世尊！我听到如来坚固的誓愿，身上汗毛都竖起。世尊！应当怎样称呼这部经？我们怎样受持？”佛告诉阿难：“这部经名为《弥勒所问》，也名为《往昔本愿因缘》，你应当以这名字受持。”

【按】“受持”，明本作“奉持”。

佛说此经之后，弥勒菩萨、尊者阿难，一切世间天、人、阿修罗、乾闼婆等，听闻佛所说，都大欢喜，信受奉行。
