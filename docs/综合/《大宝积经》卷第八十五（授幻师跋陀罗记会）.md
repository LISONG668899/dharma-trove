# 《大宝积经》卷第八十五（授幻师跋陀罗记会）

唐·三藏菩提流志 奉诏译

## 授幻师跋陀罗记会第二十一

【按】本会异译有西晋竺法护译《幻士仁贤经》（T0324）。

#### 序分：法会大众与如来功德

如是我闻：一时，佛在王舍城耆阇崛山中，与大比丘众一千二百五十人在一起，都是阿罗汉，为众人所知识。又有菩萨摩诃萨五十人，得大神通，变现自在，证得无生忍以及陀罗尼，他们的名字是：师子菩萨、师子慧菩萨、妙栴檀菩萨、调御菩萨、大调御菩萨、光胜菩萨、光现菩萨、光威菩萨、光严菩萨、明觉菩萨、众上菩萨、调御众生菩萨，以及贤劫中的一切菩萨，以弥勒菩萨摩诃萨、文殊师利法王子等为上首。又有四大天王、释提桓因、娑婆世界主大梵天王，以及无量的天、龙、夜叉、阿修罗、乾闼婆、紧那罗、摩睺罗伽等众围绕。

【按】“五十人”，宋、元、明本作“五千人”。

如来世尊因为有大名称，普闻于世间，就是：如来、应供、正遍知、明行足、善逝、世间解、无上士、调御丈夫、天人师、佛、世尊，是一切知者、一切见者，成就十力、四无所畏、四无碍解、十八不共法、大慈大悲，五眼具足，记说神变、教诲神变、神通神变都圆满。能把三千大千世界的大地、城邑、草木、丛林、须弥山等，大海、江河、诸天宫殿，安置在一根毛端上，令其住于虚空，或经一劫或超过一劫，随心念所期，而不倾动。当时王舍城的国王、大臣、婆罗门、居士以及一切人民，都对如来深生尊重，以种种上妙的饮食、衣服、卧具、汤药恭敬供养。

#### 幻师跋陀罗起意较试

那城中有一位幻师，名叫跋陀罗，熟习外道异论、工巧咒术，在诸幻师中最为上首。摩竭提国中，除了见谛之人以及具正信的优婆塞、优婆夷等，其余愚人都被他的幻术所迷惑，没有不归信他的。当时那幻师听到如来的功德名称，便生起这样的念头：“现在这城中的一切众生，都对我生起尊重之心，只有瞿昙沙门还未信服，我现在应当去他那里较量试探。他若归附于我，摩竭提国的人必定都会对我加倍恭敬。”

【按】“较试”之“较”，元、明本作“角”。

那时那幻师往昔所种善缘成熟的时候到了，又由于世尊威德之力，便从王舍城前往耆阇崛山。看见佛的光明超过百千个太阳，面轮庄严美好犹如满月，身相圆满如尼拘陀树，白毫之相清净如摩尼宝光，眼睛是绀青色，如青莲花，乃至梵天也不能见到他的顶相，以六十种清净音声为大众说法。而这幻师虽然看见如来的威德特别尊胜，仍然怀着邪慢，又想：“我现在应当试验他。他若是一切知见者，应当知道我的心意。”这样想之后，上前礼佛之足，这样说：“愿您明日接受我微薄的供养。”那时世尊观察那幻师以及王舍城众生等根性成熟的时候已到，为了成熟他们，默然接受邀请。那幻师见世尊接受了邀请，又这样想：“现在这瞿昙不识破我的心意，可以断定不是一切智人。”便辞退，作礼而去。

【按】“逾百千日”之“逾”，宫本作“愈”。

#### 佛告目连：如来所作是真幻化

尊者目连当时在会中，看见这件事，上前对佛说：“这跋陀罗想对如来以及比丘众有所欺诳，唯愿世尊不要接受他的邀请。”佛告诉目连：“不要作这样的念头。贪、瞋、痴才能造成诳惑，我对这些早已断灭，因为证得诸法本来无生。我在长劫中安住于正行，哪有人能欺诳我？你现在应当知道，他所作的不是真正的幻化，如来所作的才是真正的幻化。为什么呢？因为现证诸法都如幻。假使一切众生都成就如跋陀罗那样的幻术，与如来相比，百分不及一、千分不及一，乃至算数譬喻都不能及。”

又告诉目连：“你认为怎样？那幻师能变现三千大千所有世界，令其庄严吗？”目连回答：“不能。”“目连应当知道，我现在能在一根毛端中变现庄严恒河沙数世界，还未穷尽如来的神力。目连应当知道，有大风轮名为碎坏，它能破坏三千世界。又有风轮名为毗岚婆，能破坏世界，又能令世界成立。又有风轮名为鼓动，那风常能旋转世界。又有风轮名为安住，那风能行到有顶之处。又有风轮名为飘散，它能飘散须弥山王以及黑山等。又有风轮名为猛焰，劫火燃烧时，能把猛焰飘上至梵天。又有风轮名为止息，劫火燃烧时，它能止息劫火的焚烧。又有风轮名为清凉，能使一片云普覆三千大千世界。又有风轮名为遍霔，劫火燃烧时，普遍在世界降注大雨。又有风轮名为干竭，劫水漂荡时，能令那水全都枯涸。像这样的风轮，我若一一具说，穷劫也说不尽。目连应当知道，你认为怎样？这幻师能在这样的风轮中暂时安住吗？”目连回答：“不能。”佛告诉目连：“如来能在这样的风轮中行、住、坐、卧而不动摇。又能把这样的风轮纳入芥子之中，显现诸风轮所作之事，而芥子没有增减，诸风轮也互不妨碍。目连应当知道，如来所成就的幻术之法没有限极。”

【按】“破坏三千世界”之“破”，宋、元、明、宫本作“碎”。“遍霔”之“霔”，宫本作“霑”。“内芥子中”之“内”，明本作“纳”，“内”即纳入。

那时尊者大目乾连以及大众，听到如来这样说，生起希有之心，顶礼佛足，同声唱言：“我们现在遇到具大威德神通的导师，获得大饶益。若有人得闻如来世尊这样的神力而深生信解，此人必定当获大善利，发起阿耨多罗三藐三菩提心。”

【按】“目乾连”之“乾”，明本作“揵”。

#### 幻师化作道场，天王帝释助成

那幻师当夜就前往王舍城，在最下劣污秽的地方，化作一座宽广平正的道场，以缯彩、幡盖种种庄严，散布花香，覆以宝帐。又化现八千棵宝树行列，每棵宝树下都有狮子座，无量敷具都庄严美好。为了供养比丘们，又化作百味饮食，并化现五百个侍奉之人，穿着白衣，佩戴庄严之具。化作这些之后，那时四天王来到会中，告诉幻师说：“你为了明日供养如来，化作这样无量的庄严之具，由这一因缘获得大功德。我现在为了帮助你，供养如来，在这里化作第二座道场，你能允许吗？”那幻师听了这话，生起奇特之心，便允许了。于是四天王便变现无量殊妙庄严之具，超过幻师所幻化之事一倍。

那时天帝释又与三万天子等来到道场，对幻师说：“我现在也想借你的供养来庄严道场。”幻师惊悚，又允许了。于是天帝为了如来，化作堂宇，犹如三十三天殊胜的宫殿。又化作波利质多、俱鞞陀罗等天上妙树，次第行列。幻师那时见到这些事之后，嗟叹、惊惧、后悔，想收回他所化的东西，用尽他的咒术，所幻化之事仍然如故。便自己思念：“这真是奇怪。我从以前以来，所变化的东西隐现随心。而现在却不能隐没，必定是因为为那如来的缘故。”那时天帝释知道他的心念，告诉幻师说：“你现在为了如来而庄严道场，所以不能隐没。由此应当知道，若又有人对如来乃至发起一念之心，由这善根，毕竟能作为般涅槃之因。”他听天帝这样说，心中非常欢喜。

过了夜分之后，他前往如来之所，说：“世尊！我现在已经营办完毕，愿垂哀愍。”

【按】“营办”之“办”，宫本作“辨”。“哀慜”之“慜”，宋、元、明、宫本作“愍”。

#### 世尊赴供，说一切皆幻

那时世尊在早晨著衣持钵，与大众恭敬围绕，进入王舍城，前往那幻师的道场。摩竭提国的外道梵志、婆罗门等，都希望如来被幻师所幻惑，为了想看，都来集会。比丘、比丘尼、优婆塞、优婆夷，乐于见闻如来的神变以及狮子吼，也都来集会。那时如来以佛的神力，令那幻师、帝释、四天王各自见到世尊在自己所庄严之处。那幻师见到这样之后，舍弃憍慢，上前礼佛之足，说：“世尊！我现在在如来面前悔过发露。我先前对佛妄生欺诳，幻化种种庄严之事。后来虽然渐渐后悔，却不能令其隐没。”

【按】“诸比丘”之“比”，《大正藏》脱，今依CBETA补。“渐悔”之“渐”，宋、元、明、宫本作“惭”。

那时世尊告诉幻师说：“一切众生以及种种资具都是幻化，因为由业所幻。比丘众也是幻化，因为由法所幻。我身也是幻，因为由智所幻。三千大千一切世界也都是幻，因为由一切众生共同所幻。所有一切法无不是幻，因为由因缘和合所幻。你现在应当拿幻化的饮食依次行食。”那时那幻师与四天王、释提桓因以及同来的眷属，还有所幻化的侍奉之人等，便拿饮食布施佛及僧众，同会的众人都得充足。

#### 诸大弟子、菩萨说偈

那时摩诃迦叶说偈道：

```
知食是幻化，受者亦复然，
了此平等时，乃名为净施。
```
（大意：了知饮食是幻化，受食者也是这样，了知这平等之时，才名为清净的布施。）

大目乾连说：

```
知座是幻化，坐者亦复然，
了此平等时，乃名为净施。
```
（大意：了知座位是幻化，坐的人也是这样，了知这平等之时，才名为清净的布施。）

舍利弗说：

```
如化给侍人，受者心亦然，
施者能如是，乃名为净施。
```
（大意：如同化现的侍奉之人，受者的心也是这样，布施者能这样了知，才名为清净的布施。）

须菩提说：

```
勿以施为施，勿以受为受，
施者能如是，乃名为净施。
```
（大意：不要把布施执为布施，不要把受取执为受取，布施者能这样，才名为清净的布施。）

阿难陀说：

```
所施如虚空，受者不可得，
远离于身心，其施最清净。
```
（大意：所施之物如虚空，受者不可得，远离于身与心，这样的布施最为清净。）

光幢菩萨说：

```
譬如彼幻师，幻化庄严事，
诸法皆如是，愚人不觉知。
```
（大意：譬如那位幻师幻化出庄严之事，诸法都是这样，愚人却不能觉知。）

光严菩萨说：

```
如座及诸树，皆幻心所为，
幻心与虚空，何有少差别？
```
（大意：如座位以及诸树，都是幻心所作；幻心与虚空，哪有少许差别？）

师子菩萨说：

```
野干未曾闻，师子所哮吼，
其心无所惧，嘷叫林树间，
适闻师子声，藏窜而无所。
幻师亦如是，不对如来前，
常于外道中，自赞超过佛。
幻师虽造作，幻术有其边，
如来所成就，幻术无穷尽，
一切诸天魔，莫能知边际。
```
（大意：野干未曾听过狮子的吼声，心中无所畏惧，在林树间嗥叫，一听到狮子之声，便藏窜而无处可躲。幻师也是这样，不在如来面前时，常在外道之中自我赞叹超过佛。幻师虽然有所造作，他的幻术有边际；如来所成就的幻术无穷无尽，一切诸天与魔都不能知其边际。）

师子慧菩萨说：

```
了知给侍人，饮食并食者，
一切皆幻化，善施无过上。
```
（大意：了知侍奉之人、饮食以及食者，一切都是幻化，这样的善施无可超过。）

弥勒菩萨说：

```
如火得苏油，展转而增盛，
世尊对幻师，幻化亦如是。
```
（大意：如火得到酥油，辗转更加炽盛；世尊对着幻师，所现的幻化也是这样。）

【按】“苏油”之“苏”，元、明本作“酥”。

文殊师利菩萨说：

```
此会众善事，如本未曾为，
一切法皆然，常等于前际。
```
（大意：这法会的种种善事，如同本来未曾作过；一切法都是这样，常与前际平等。）

#### 化长者示现佛在诸处

那时世尊为了成熟那位幻师，化作一位长者进入会中，对幻师说：“你现在在这里想做什么？”幻师回答：“我为了供养沙门瞿昙而设下种种饮食。”长者说：“不要这样说。如来现在正与比丘们在阇王宫中受供而食。”由于佛的神力，令那幻师看见如来与比丘们在那里用食。又化作第二位长者，对幻师说：“你在做什么？”幻师回答：“我为了供养沙门瞿昙。”长者又说：“不要这样说。如来现在正与比丘们在梵志的里巷中巡行乞食。”由于佛的神力，令那幻师又看见如来与圣众在里巷中巡行乞食。又化作第三位长者，告诉幻师说：“如来现在在医王耆婆的园中，为四众宣说妙法。”由于佛的神力，令那幻师都看见这样的情景。接着又化作释提桓因，来到幻师那里告诉他：“如来现在在三十三天为大众说法。”那时幻师又看见如来在天众中演说诸法要义。

【按】“与诸比丘”，宋、元、明、宫本作“与比丘众”。“皆见如是”之“如是”，元、明本作“如来”。“三十三天”之“十”，宋本作“千”。

那时幻师又在林树花叶之间，以及一切狮子座上，还有王舍城的里巷、垣墙、室宅、堂殿以及种种胜处，都看见如来具足种种相好。也在一切如来之所，看见自己在悔过发露。那幻师那时只见佛身，其余一无所见，欢喜踊跃，便获得念佛三昧。从三昧起来，合掌向佛，说偈道：

#### 幻师说偈请问

```
我昔于阎浮，幻化无过上，
今比佛神通，无能及少分。
由是方了知，诸佛难思力，
随心能变现，化佛如恒沙。
所见诸如来，皆具于相好，
愿尊为显示，何者是真佛？
```
（大意：我往昔在阎浮提，幻术无人能超过，现在与佛的神通相比，连少分也不及。由此才了知诸佛不可思议之力，随心能变现如恒河沙数的化佛。所见的诸如来都具足相好，愿世尊为我显示，哪一位是真佛？）

```
于此诸如来，我欲修供养，
愿尊为我说，何者为胜果？
若人于佛所，不生尊重心，
如是诸凡夫，退失于安乐。
今于世尊前，发露先所犯，
妄试如来罪，永愿灭无余。
梵释并大众，愿皆证知我，
为度诸群生，今发菩提心。
```
（大意：对这些如来，我想修供养，愿世尊为我说，什么是殊胜之果？若有人对佛不生尊重之心，这样的凡夫便退失安乐。现在在世尊面前，发露先前所犯，妄试如来之罪，愿永远灭尽无余。梵天、帝释以及大众，愿都为我证知：为了度化群生，我现在发菩提心。）

```
以智慧光明，觉悟于世间，
施与甘露法，悉皆令充满。
若人于佛所，见如是神变，
及闻悦意言，胜行无碍智。
何有明慧者，不发菩提心？
愿示菩提道，及遍清净行。
```
（大意：以智慧光明觉悟世间，施予甘露之法，令众生都得充满。若有人在佛所见到这样的神变，又听闻悦意之言、殊胜之行与无碍之智，哪有明慧之人不发菩提心？愿佛开示菩提之道以及遍清净之行。）

```
何等为修行，二乘不能入？
云何所行处，尊重而供养？
云何具威仪，及离诸疑悔？
云何于多闻，无厌修坚实？
云何为人说，令乐于正法，
无希利养心，及善知恩报？
云何于众生，常为不坏友？
云何近善友，舍离恶知识？
云何值诸佛，供养心无倦？
云何为学处，尊重及清净？
云何定种姓，成就如理心？
及舍不如理，具足正思惟？
云何无怯弱，不为魔所摄，
思惟于义理，不舍诸众生？
云何不应舍，不取而摄取，
得入于正行，具足善方便？
云何修慈悲，成就诸神通，
证于无碍辩，及得陀罗尼？
云何获法忍，清净之辩才，
当舍应舍法，得入甚深义？
云何于誓愿，一切皆圆满，
于诸波罗蜜，而得不退转？
我于如是法，当愿勤修行，
唯愿大悲尊，为我广宣说。
```
（大意：什么样的修行是二乘不能入的？什么是所行之处，什么是尊重供养？怎样具足威仪以及远离疑悔？怎样对多闻无厌足，修得坚实？怎样为人说法，令人乐于正法，没有希求利养之心，以及善于知恩报恩？怎样对众生常为不坏之友？怎样亲近善友、舍离恶知识？怎样值遇诸佛，供养而心不倦？怎样对学处尊重，以及学处清净？怎样决定三昧种姓，成就如理之心，以及舍离不如理之心，具足正思惟？怎样没有怯弱、不被魔所摄，思惟义理，不舍众生？怎样是不应舍、不取而摄取之法，得入于正行，具足善巧方便？怎样修慈悲，成就诸神通，证得无碍辩，以及得陀罗尼？怎样获得法忍、清净的辩才，舍离应舍之法，得入于甚深之义？怎样令誓愿一切圆满，对诸波罗蜜得不退转？我对这样的法，愿当勤加修行，唯愿大悲世尊为我广为宣说。）

【按】“定种姓”之“姓”，宋、元、明、宫本作“性”。

#### 世尊以偈答真佛之问

那时世尊以偈回答：

```
若了一切法，皆同于幻化，
是人则能现，百亿诸佛身，
往于俱胝刹，度脱诸众生。
譬如跋陀罗，无色现众色，
不生亦不灭，无住无去来。
世尊变化身，及与比丘众，
亦无有生灭，乃至于涅槃。
```
（大意：若了知一切法都如同幻化，这人便能示现百亿佛身，前往俱胝佛刹度脱众生。譬如跋陀罗，本无色而现出种种色，不生也不灭，无住、无去来。世尊的变化身以及比丘众，也没有生灭，乃至涅槃也是这样。）

```
此皆是如来，不思议神变，
亦如幻化者，现象马军阵。
迷惑诸众生，妄见为真实，
如是象马军，无性亦无生。
诸佛无色相，无去亦无来，
住于我见人，妄生于佛想。
不应以色相，种族及生处，
乃至梵音声，而欲观如来。
亦难以心识，分别于诸佛，
诸佛法性身，超过于三世。
```
（大意：这些都是如来不可思议的神变，也如幻术师幻现象军、马军的军阵，迷惑众生，妄见为真实；这样的象马军无自性也无生。诸佛没有色相，无去也无来，住于我见的人才妄生佛想。不应以色相、种族以及出生之处，乃至梵音声来观如来。也难以用心识分别诸佛，诸佛的法性身超过三世。）

```
自性离诸相，不堕于法数，
所现诸如来，自性无生起，
亦无蕴界处，住于无所依，
如是佛法身，非五眼能见。
若谓我见佛，是则不能见，
以无见为见，如空中鸟迹。
如汝所见佛，及余未见者，
平等如虚空，一相无差别。
戒定慧解脱，及解脱知见，
一切诸如来，功德无差别，
皆住于空性，于法无所著，
一切皆幻化，无性亦无生。
```
（大意：佛的自性远离诸相，不堕于法数之中；所现的诸如来，自性无生起，也没有蕴、界、处，住于无所依；这样的佛法身，不是五眼所能见。若说“我见到佛”，那就是不能见；以无见为见，如空中的鸟迹。如你所见的佛以及其余未见的佛，平等如虚空，一相而无差别。戒、定、慧、解脱以及解脱知见，一切如来的功德没有差别，都住于空性，对法无所执著，一切都是幻化，无自性也无生。）

```
供养一如来，则供于多佛，
诸佛之法身，平等无差别。
如是一切佛，咸能生福利，
普施诸如来，皆获于大果。
同证于平等，清净之法性，
是故诸如来，无种种差别。
```
（大意：供养一位如来，便是供养众多佛，诸佛的法身平等无差别。这样的一切佛都能出生福利，普遍布施诸如来，都获得大果。诸佛同证平等清净的法性，所以诸如来没有种种差别。）

```
如汝先所问，何者为真佛？
当舍散乱心，谛听我宣说。
应住正念慧，观察于诸法，
一切皆无生，妄见为真实。
色相若有生，则应亦有灭，
是故诸如来，毕竟无有生。
彼亦非己生，亦无有散灭，
由是观如来，以无见为见，
如汝所见佛，不依止方所。
```
（大意：如你先前所问“哪一位是真佛”，应当舍弃散乱之心，谛听我宣说。应当住于正念与智慧，观察诸法：一切都无生，众生却妄见为真实。色相若有生，就应当也有灭，所以诸如来毕竟无有生。佛也不是自己出生的，也没有散灭，由此观察如来，以无见为见；如你所见的佛，不依止于方所。）

【按】“则应亦有灭”之“亦”，宋、元、明、宫本作“无”。

```
一切诸凡夫，皆依于五蕴，
应当于彼蕴，如佛而观察。
诸佛及诸法，乃至于众生，
以无相为相，无有依止者，
若作是观察，速证于菩提。
诸法皆非有，由妄分别生，
因缘体性空，离作者性故。
如是能了达，因缘作者空，
彼则能了知，离染清净法，
以清净法眼，得见诸如来。
```
（大意：一切凡夫都依于五蕴，应当对那五蕴如观佛那样观察。诸佛与诸法乃至众生，都以无相为相，没有所依止者；若这样观察，迅速证得菩提。诸法都非实有，由妄分别而生，因缘的体性是空，因为远离作者之性。若能这样了达因缘与作者都空，他便能了知离染的清净之法，以清净法眼得见诸如来。）

那幻师听了这些之后，得顺法忍，五千众生发阿耨多罗三藐三菩提心，二百菩萨证得无生忍。那时世尊用饭完毕，为了满足幻师布施之愿，又说偈道：

```
能于所施物，施者及受人，
等无分别心，是则施圆满。
```
（大意：能对所施之物、施者以及受者，平等而无分别心，这就是布施圆满。）

那时阿难对佛说：“世尊！我们愿如来以佛的神力加持幻师，令他现在所施设的庄严之事，在七日中不隐没。”当时如来因为大众请求，令那幻师所幻化的道场满足七日，庄严如故。那时如来与比丘们以及大菩萨，天、龙、夜叉、乾闼婆等恭敬围绕，回到耆阇崛山为大众说法。

#### 佛说菩萨四法

那时幻师又前往佛所，顶礼佛足，右绕三匝，退住一面，对佛说：“世尊！愿为我演说诸菩萨道，勤加修行的人能迅速到达菩提道场。”佛说：“谛听，好好思念，当为你说。”幻师说：“是的，世尊！愿乐欲闻。”

佛说：“善男子！有四种法是菩萨道。若能修行，迅速当得到达菩提道场。哪四种？一是对菩提心永不退失，二是对众生常不弃舍，三是对一切善根求无厌足，四是护持正法，发起大精进。

“善男子！菩萨又有四法是遍清净行。哪四种？一是律仪清净，二是意乐清净，三是智慧清净，四是受生清净。

“又有四法，只有菩萨行，不是二乘所能入的。哪四种？一是修习禅定而不随禅定受生，二是对甚深义理心能抉择，三是对众生生起大悲心，四是以种种辩才演说法而无碍。

“又有四法是所行之处。哪四种？一是乐住于闲静寂静之处，二是厌离喧闹，三是对众生生起大慈心，四是能了知诸行没有去来。

【按】“大慈心”，宋、元、明本作“大悲心”。

“又有四法是尊重供养。哪四种？一是不惜身命，二是心常欢悦，三是舍离憍慢，四是如所说而修行。

“又有四法是威仪具足：一是知时，二是知处，三是寂静，四是真实。

“又有四法能离疑悔。哪四种？一是对恶作之事应当预先防护，二是对智者应当乐于亲近，三是对所听闻的义理常常好好思惟，原文：“四者不以慈心不举他过。”（大意：四是不因为慈心而不举出他人的过失。存疑。）

“又有四法是多闻无厌。哪四种？一是为了增长自他的正智慧，二是为了能断除他人的疑惑，三是为了能摄受佛的正法，四是为了赞叹诸如来无尽。

【按】“无有厌足”之“足”，宋本作“定”。

“又有四法是多闻坚实。哪四种？一是听闻正法之后能好好理解，二是听闻正法之后不作诸恶，三是听闻正法之后为他人开示，四是听闻正法之后回向菩提。

“又有四法是说法的利益。哪四种？一是常受他人的香味饮食，二是恒受衣服种种供养，三是令魔的眷属势力羸弱，四是诸天护持，魔不能得便。

“又有四法令他人信乐所说之法。哪四种？一是因为心少欲，二是因为常知足，三是因为言语柔软，四是因为身体随顺于法。

“又有四法能演说正法而没有希求。哪四种？一是在生死中恒常怀着怖畏，二是不求世间的利养与亲友，三是对众生常常拥护，四是能修习诸圣种。

“又有四法是知恩报恩。哪四种？一是因为劝众生趣向菩提，二是因为知道所作之业不会失坏，三是因为慈爱众生如自己之身，四是因为善能修行菩萨之事。

“又有四法对众生为不坏之友。哪四种？一是因为能披忍辱的大铠甲，二是因为福利众生而不求回报，三是因为大悲心常不退失，四是因为虽受众多恼害也不舍弃。

“又有四法是对善友应当亲近的。哪四种？一是成就善巧方便，二是成就殊胜意乐，三是成就菩萨正行，四是成就劝赞菩提。

“又有四法是对恶友应当舍离的。哪四种？一是赞说二乘，二是令人退失菩提，三是增长恶法，四是损坏诸善。

“又有四法得值遇诸佛。哪四种？一是因为恒常一心专念佛，二是因为称赞如来的种种功德，三是因为所受的律仪普遍清净，四是因为以殊胜意乐发起弘大誓愿。

“又有四法供养诸佛而心无懈倦。哪四种？一是应当自己庆幸‘我现在供养最上福田’，二是‘由于我供养，一切众生也将供养’，三是‘因供养之后，菩提心当得坚固’，四是看见如来的三十二相，善根增长。

“又有四法对诸学处生起尊重之心。哪四种？一是超过恶道，二是得生善趣，三是尊重如来，四是圆满诸愿。

“又有四法是所应学处。哪四种？一是对菩提心常不舍离，二是对众生心行平等，三是对波罗蜜精进修行，四是听闻无量法而不生恐怖。

“又有四法是学处清净。哪四种？一是不造诸恶，二是深解空性，三是不谤诸佛，四是灭坏诸见。

“又有四法是三昧种姓。哪四种？一是因为远离喧闹，二是因为乐于寂静，三是因为心无散乱，四是因为善根增长。

【按】“三昧种姓”之“姓”，明本作“性”。

“又有四法是应当成就的如理之心。哪四种？一是所修的善法回向趣入菩提，二是心常宴默寂静而无执著，三是对解脱门常勤修习，四是从不求证二乘涅槃。

“又有四法是应当舍离的不如理之心。哪四种？一是对生死有所怖畏，二是对所修行不生信受，三是对秘密之教不求胜解，四是对善根不修习。

“又有四法是应当好好修学的正思惟心。哪四种？一是菩萨乃至为了一个众生，在无量劫中受生死之苦；二是应当先了知一切众生根性的差别，而为他们说法，令他们舍弃烦恼；三是应当断一切恶、修一切善，降伏魔军，证得阿耨多罗三藐三菩提；四是应当为三千大千世界无量众生，以一种梵音演说诸法要义。

“又有四法是无怯弱之心，魔不能摧坏。哪四种？一是观一切法犹如幻化，二是常与如理的正智相应，三是对一切法无所分别，四是对一切相无所执著。

“又有四法是思惟义理。哪四种？一是知一切法从因缘生，二是知没有少许法名为生起者，三是知缘生之法即是无起，四是知法无生也无灭坏。

“又有四法是不舍众生。哪四种？一是不舍弘大誓愿，二是忍受疲苦，三是不惜身命，四是恒修四摄。

“又有四法是不应舍离的。哪四种？一是对布施不舍离，二是对成熟众生不舍离，三是对常自觉察不舍离，四是对增长他人善根不舍离。

“又有四法是常应摄受的。哪四种？一是微少的善根也应当修习，二是增长他人善根而心无懈怠，三是听闻宣说布施、持戒便能信受，四是不求一切利养名誉。

“又有四法是入于正行。哪四种？一是成就神通与智慧，二是安住于大三昧，三是修习空性，四是无所执著。

“又有四法是善巧方便。哪四种？一是菩萨对种种发心，都以菩提心为上首，乃至烦恼尚且令其随顺趣向无上菩提，何况发起种种善心等；二是观察众生，乃至安住于邪见的人，都是法器；三是了知诸法没有自性；四是修习解脱，对三昧门没有执著之想。

“又有四法是修大慈心。哪四种？一是修大慈心救护众生，二是修大慈心度脱众生，三是修大慈心觉悟众生，四是修大慈心为了令众生入于涅槃。

“又有四法是修大悲心。哪四种？一是修大悲心为了令众生远离恶道、安住善趣，二是修大悲心为了令众生舍弃恶行、修习善法，三是修大悲心为了令众生远离小乘、入于大乘，四是修大悲心为了令众生远离生死、得到涅槃。

“又有四法是成就神通。哪四种？一是因为不惜身命、没有爱恋，二是因为了知一切法如幻化，三是因为对众生生起尊重，四是因为修奢摩他而无散乱。

“又有四法得无碍辩。哪四种？一是随顺于义而不随于文，二是随顺于法而不随于人，三是了达诸法远离文字，四是依于了达文字而演说无尽。

“又有四法得陀罗尼。哪四种？一是对多闻没有厌足，二是对多闻的人恭敬供养，三是以种种名称宣说真实之义，四是随顺秘密之教能正确趣入。

“又有四法能得法忍。哪四种？一是多修胜解，二是没有退转，三是资粮圆满，四是精勤无倦。

“又有四法得清净辩才。哪四种？一是对说法之人无所违逆，二是尊重法师，恭敬听受，三是不因多闻而自生憍慢，四是对少闻的人不生轻贱。

“又有四法是应当舍离的。哪四种？一是对贪、瞋、痴应当舍离，二是对声闻乘应当舍离，三是对缘觉乘应当舍离，四是对善法之想应当舍离。

【按】“善法想”之“想”，《大正藏》作“相”，今依CBETA（所录高丽藏、碛砂藏）作“想”。

“又有四法是入于甚深之义。哪四种？一是对有为法深达缘起，二是对秘密之义能正确了知，三是对诸法之性深生正解，四是对一切法了达空义。

“又有四法令誓愿圆满。哪四种？一是尸罗清净，二是净除恶业，三是没有谄诳，四是增长善根。

“又有四法对诸波罗蜜得不退转。哪四种？一是以善巧方便，能在一种波罗蜜中遍通诸波罗蜜；二是以善巧方便，随了知一个众生便遍了知一切众生；三是以善巧方便，证得一法清净便遍证一切诸法清净；四是以善巧方便，了知一佛便遍能了知一切诸佛。为什么呢？因为法性没有差别。”

#### 世尊微笑，阿难偈问

佛说这样的菩萨四法法门时，幻师跋陀罗证得无生忍，心中踊跃喜悦，便升到虚空，身体离地七多罗树之高。那时世尊和悦微笑，从面门放出无量光明，那光普照诸佛世界，回来在如来顶上隐没。那时尊者阿难这样想：“如来、应、正等觉现出这微笑，不是没有因缘的。”便从座起，偏袒右肩，右膝著地，合掌向佛，以偈问道：

```
普闻三界遍知尊，
威德智处难思者，
已达菩提功德岸，
今现微笑有何缘？
十方五趣诸众生，
心行种性上中下，
如来于彼悉能了，
今现微笑有何缘？
```
（大意：名闻三界的遍知之尊，威德与智慧之处难以思议的您，已到达菩提功德的彼岸，现在现出微笑有什么因缘？十方五趣的众生，心行与种性有上、中、下，如来对他们都能了知，现在现出微笑有什么因缘？）

【按】“已达”之“已”，《大正藏》作“己”，今依CBETA作“已”。

```
人天八部诸大众，
所出种种妙音声，
比于如来清净音，
乃至不及歌罗分。
世尊光明遍十方，
普照无量诸佛刹，
日月摩尼梵天光，
无有能比如来者。
已了性空甚深法，
无我无人及众生，
有无二边皆舍离，
善知三际如水月。
```
（大意：人、天、八部大众所发出的种种妙音声，与如来清净之音相比，乃至不及歌罗分之一。世尊的光明遍照十方，普照无量诸佛刹土，日、月、摩尼与梵天之光，没有能与如来相比的。您已了达性空甚深之法，无我、无人以及众生，有、无二边都舍离，善知三世如水中之月。）

```
今谁趣于最上乘，
绍继如来法种性，
生于广大三宝中？
微笑因缘愿宣说。
如来所现微笑光，
为彼诸乘有差别，
于膝于肩而没者，
如斯为彼二乘人。
今者所放无量光，
此光入于如来顶，
天中胜者为何人，
于此佛乘当授记？
```
（大意：现在是谁趣向最上乘，继承如来的法种性，生于广大的三宝之中？请宣说微笑的因缘。如来所现的微笑之光，为不同的乘而有差别：在膝上、在肩上隐没的，是为那二乘之人。现在所放的无量光明，这光入于如来顶上，天中最胜之尊，是为什么人在这佛乘中授记？）

#### 授记神变王如来

那时世尊告诉阿难说：“你现在看见这跋陀罗了吗？”阿难说：“已经看见。”佛告诉阿难：“这位善男子，过了九万二千劫，将在大庄严国土、善化劫中成佛，号为神变王如来、应、正等觉。那佛国土人民繁盛，安隐丰乐，大地平坦柔软如兜罗绵，花果诸树次第行列，以幢幡宝盖作为庄严，众乐自鸣，妙香充遍，所需的饮食随念而至，所受用的种种资生之具，与忉利天没有不同。那国土常常显现种种庄严，所以号为大庄严土。那国内一切人民都安住于大乘，深信坚固。那神变王如来寿命一万岁，正法住世满百亿年。临涅槃时，为名称菩萨授阿耨多罗三藐三菩提记，告诉他说：‘你在来世将次第作佛，号为一切最胜如来、应、正等觉。’”

【按】“寿十千岁”之“十”，宋、元、明、宫本作“七”。

跋陀罗听到如来这样的授记之后，从空中下来，顶礼佛足，这样说：“我现在归命如来、应、正等觉以及法与比丘。”这样慇懃地说了无量俱胝数百千遍。又这样说：“如佛世尊因为真如没有差异，说一切法不异于真如，乃至没有差别、没有缺减、没有分别、无生无作。我现在的归依也是这样。”

#### 阿难与跋陀罗问答：如来是大惑乱

那时尊者阿难对跋陀罗说：“你若如佛所说的真如而归依，你现在难道对佛的法性有所得吗？”幻师回答：“我的身就是如来的法性。为什么呢？我与如来无二无别，因为一切诸法都是真如。说真如，就是一切法无差别之性，一切众生也是这样。尊者应当知道，说无二，是无所分别，这才是无二。为什么呢？遍知诸法只有名字，这是佛智。”

【按】“汝若如佛”之“若”，南藏作“等”。

尊者阿难上前对佛说：“奇哉，世尊！这跋陀罗竟有这样的智慧辩才。从前以幻化惑乱世间，现在又以智慧惑乱世间。”佛告诉跋陀罗说：“善男子！你真是这样吗？”跋陀罗说：“如佛所作的惑乱之事，我也这样惑乱世间。为什么呢？佛世尊在无我之中说有众生以及寿命者，这对世间是大惑乱。如来证得菩提之后，不见有少许法是生死往来，却说生死往来。依我的意思，只有如来才是大惑乱。”佛说：“善男子！善哉善哉，正如你所说。诸佛如来在无我之中，乃至没有生死往来，而随顺世俗说众生等。也没有少许法名为涅槃，然而为了证得涅槃之法，所以说涅槃。”

#### 跋陀罗出家

跋陀罗听了这些之后，上前对佛说：“我愿出家作比丘。”那时世尊告诉弥勒菩萨摩诃萨说：“你应当为这位善男子剃除须发，授具足戒。”弥勒菩萨奉佛的教旨，便为他出家，授具足戒。出家之后，他又对佛说：“世尊！这样的出家只是形相而已，不是真正的出家。若诸菩萨真正出家，是远离诸相，处于三界之中成熟众生，才可以名为真正的出家。”说这话时，五千众生发阿耨多罗三藐三菩提心，都对诸漏心得解脱。

#### 流通

那时阿难对佛说：“世尊！应当怎样称呼此经？我们应当怎样奉持？”佛告诉阿难：“此经名为‘授幻师跋陀罗记法门’，也名为‘渐证菩提法门’。若有众生在未来世想见如来以及为众生作佛事，应当对此经受持、读诵，广为人说。为什么呢？这人便是已经见到如来，也已经为他人施作佛事。所以阿难！若对此经受持、读诵、流通，便是哀愍利乐众生。若想发心趣向无上菩提，也应当对此经勤加修习。此经能出生无上菩提，此经能生起无上菩提，所以此经也名为‘出生菩提’。若有受持此经典的人，应当知道诸佛止住于他的身中，何况在其中如理修行。”

【按】“止住其身”，宋、元、明、宫本作“住止其身”。

那时跋陀罗又对佛说：“世尊！此经也名为‘发觉善根’。为什么呢？因为现在在佛所得闻此经，一切善根都现前。”

佛说此经之后，尊者阿难以及跋陀罗，天、人大众、阿修罗、乾闼婆等，听闻佛所说，都大欢喜，信受奉行。
