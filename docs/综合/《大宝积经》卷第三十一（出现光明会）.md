# 《大宝积经》卷第三十一（出现光明会）

唐·三藏菩提流志 译

【按】译者题名，宋、元、宫、圣本作“大唐”；宋、元、明、宫、圣本无“天竺”二字；宋、元、明、宫本“三藏”作“三藏法师”，“译”作“奉诏译”。

## 出现光明会第十一之二

【按】本卷开头承上卷，仍是世尊为月光童子所说偈颂；其后世尊宣说两种八十法，月光童子说偈赞佛，世尊微笑放光，弥勒菩萨说偈请问微笑因缘，至卷末偈颂未完，接下卷。

### 世尊续说往昔为此经所修诸行

#### 为此经所行的施戒忍等

```
我昔为是经，护持清净戒，
常修于定慧，及施诸众生。
我昔为是经，恶人来毁骂，
我时生怜愍，于彼不加害。
我昔为是经，求者皆施与，
各随其所乐，悉令得欢喜。
我昔为是经，奉施诸宫殿，
庄严众宝网，供养于诸佛。
我昔为是经，舍种种珍玩，
及以摩尼宝，供养于诸佛。
我昔为是经，有恩常忆念，
乃至闻一偈，于彼恒尊重。
我昔为是经，尊重持戒者，
乃至经行处，于彼常恭敬。
```
（大意：我往昔为了这部经，护持清净戒，常修禅定与智慧，并布施众生。我往昔为了这部经，有恶人来毁谤辱骂，我当时生起怜悯，对他不加伤害。我往昔为了这部经，凡有来求的都施与，各随他们所喜好的，都令得欢喜。我往昔为了这部经，奉施种种宫殿，以众宝网庄严，供养诸佛。我往昔为了这部经，舍弃种种珍玩以及摩尼宝，供养诸佛。我往昔为了这部经，对有恩于我的人常常忆念，乃至只从他那里听闻一偈，也对他恒常尊重。我往昔为了这部经，尊重持戒的人，乃至对他经行之处，也常恭敬。）

```
我昔为是经，或处于生死，
乃至有少恩，于彼常怀报。
我昔为是经，不求利谤法，
哀愍于亲友，乃至诸众生。
我昔为是经，具多闻善说，
于法无所著，不悭亲友家。
我昔为是经，若心生不善，
速忏令除灭，终不使增长。
我昔为是经，身为王太子，
所得诸珍宝，涂香及末香，
我时生净心，回施于诸佛。
```
（大意：我往昔为了这部经，或处在生死之中，乃至对我只有少许恩惠的人，也常怀报答之心。我往昔为了这部经，不为求利而谤法，哀悯亲友，乃至一切众生。我往昔为了这部经，具足多闻，善于宣说，于法无所执著，对亲友之家不起悭吝。我往昔为了这部经，若心中生起不善，便迅速忏悔，令其除灭，终不让它增长。我往昔为了这部经，身为国王太子时，把所得的种种珍宝以及涂香、末香，以清净心回施诸佛。）

```
我昔为是经，愍诸囚徒类，
种种加楚毒，以身而代受。
我昔为是经，舍诸五欲乐，
常于月六斋，受持诸禁戒。
我昔为是经，常修行忍辱，
乃至于妻室，亦不生贪悋。
我昔为是经，令诸贫乏者，
皆悉得安乐，丰足诸财宝。
我昔为是经，摄受于一切，
沙门婆罗门，种种群生类。
```
（大意：我往昔为了这部经，怜悯那些囚徒，他们遭受种种酷刑，我以自身代他们承受。我往昔为了这部经，舍弃五欲之乐，常在每月六斋日受持禁戒。我往昔为了这部经，常修忍辱，乃至对于妻室也不生贪吝。我往昔为了这部经，令贫乏之人都得安乐，丰足财宝。我往昔为了这部经，摄受一切沙门、婆罗门以及种种众生。）

```
我昔为是经，利益于一切，
常为大施主，求者心无悋，
或莳于华果，不令人剪伐，
普施诸众生，随意皆充足。
我昔布施时，其心常平等，
持戒具功德，破戒无惭愧，
或证大神通，下至凡愚类，
皆生希有心，恭敬而周给。
我昔布施时，其心无高下，
不求生善趣，志乐于此经，
或令国界中，一切无怨敌，
调伏诸龙众，应时霔甘雨。
```
（大意：我往昔为了这部经，利益一切，常作大施主，对来求的人心无吝惜；或者种植花果，不让人砍伐，普施众生，随其所需都得充足。我往昔布施时，其心常平等：持戒具足功德的人，破戒无惭愧的人，或证得大神通的人，下至凡愚之类，我对他们都生起希有之心，恭敬而周遍供给。我往昔布施时，心无高下，不求生于善趣，只是志心爱乐这部经；或令国界之中一切没有怨敌，调伏诸龙众，使其应时降下甘雨。）

#### 嘱月光末世弘经

```
月光汝当知，我于无量劫，
为求是经故，修习诸苦行，
设于百千劫，宣说不能尽。
汝已住净信，当来末世时，
应生正念心，演说是经典。
```
（大意：月光！你应当知道，我在无量劫中，为了求这部经，修习种种苦行，即使在百千劫中宣说，也说不尽。你已安住于清净信心，未来末世之时，应当生起正念之心，演说这部经典。）

【按】“无量劫”之“劫”，宫、圣本作“世”。宫本在“明见未来世”之后重出“设于百千劫，宣说不能尽，汝已住净信，当来末世时”四句。

#### 佛眼了知未来众生

```
我以佛眼观，明见未来世，
随其种种行，一切皆了知。
若有诸比丘，为求无上智，
能以净信心，演说此经典，
是人及方所，一切皆了知。
若于末世时，闻是经爱乐，
志愿及方便，一切皆了知。
若诸下劣人，不闻是经典，
诽谤宣说者，一切皆了知。
若有诸比丘，及诸比丘尼，
得闻于是经，悲感而涕泣，
我皆与受记，得见最胜尊。
```
（大意：我以佛眼观察，明见未来之世，随众生的种种行为，一切都了知。若有比丘为求无上智，能以清净信心演说这部经典，这个人以及他所在的地方，我一切都了知。若在末世时，有人听闻这部经而爱乐，他的志愿与方便，我一切都了知。若有下劣之人，不听闻这部经典，反而诽谤宣说的人，我一切都了知。若有比丘以及比丘尼，得闻这部经，悲感而流泪，我都给他们授记，将得见最胜尊。）

【按】“受记”，明本作“授记”。

```
月光汝当知，诸佛神通力，
若人意清净，或有不清净，
乃至于信解，一切皆了知。
若有诸众生，志乐常寂静，
安住诸禅定，不著生死中，
乃至于习气，究竟皆永断，
如是等功德，一切皆了知。
或有诸众生，耽著虚妄法，
或有诸众生，于佛生欣乐，
如是未来事，一切皆了知。
```
（大意：月光！你应当知道诸佛的神通力：人的意念清净或不清净，乃至他的信解，一切都了知。若有众生志乐常处寂静，安住于诸禅定，不执著于生死之中，乃至习气也究竟永断，这样的功德，一切都了知。或有众生耽著虚妄之法，或有众生对佛生起欣乐，这样的未来之事，一切都了知。）

#### 出现光的因缘与应修之行

```
若有诸众生，染著世间乐，
于佛菩提种，不能善开发，
以是因缘故，退失诸方便。
若有能了知，诸佛菩提种，
是人当获得，清净无边光。
月光汝当观，如是光明等，
一一诸因缘，各各有差别，
汝以智慧力，一切应了知。
```
（大意：若有众生染著世间之乐，对于诸佛的菩提种子不能善加开发，因为这个缘故，便退失种种方便。若有人能了知诸佛的菩提种子，这个人将获得清净无边之光。月光！你应当观察，这样的种种光明，每一种的因缘各各有差别，你应当以智慧之力一切了知。）

```
若舍恶知识，亲近于善友，
护持清净戒，成就佛光明。
汝当护诸根，舍离无惭愧，
修行于善法，随护诸众生。
汝当舍违诤，了达于性空，
不贪著利养，具多闻善说。
汝当观利养，犹如于粪秽，
无以利养垢，染污清净心，
常求于明脱，常得无上利。
```
（大意：若舍弃恶知识，亲近善友，护持清净戒，便成就佛的光明。你应当守护诸根，舍离无惭无愧，修行善法，随顺守护众生。你应当舍弃违诤，了达性空，不贪著利养，具足多闻，善于宣说。你应当观察利养犹如粪秽，不要以利养之垢染污清净之心；常求明与解脱，常得无上之利。）

【按】“明脱”之“明”，圣本作“解”。“常得无上利”之“常”，宋、元、明、宫本作“当”。

```
汝当修佛道，观佛同法性，
常然大法炬，普照于世间。
汝当如山王，其心安不动，
毁骂及捶打，一切皆能忍。
汝当为众生，作真实善友，
应舍下劣心，常修于净业。
汝以坚固心，演说无上法，
如是微妙经，当授慈心者。
欲求无上智，勿怖于生死，
由此舍诸恶，当得于胜利。
```
（大意：你应当修佛道，观佛与法性同一，常燃大法炬，普照世间。你应当如山王一般，其心安稳不动，毁骂与捶打，一切都能忍受。你应当为众生作真实善友，应舍弃下劣之心，常修清净之业。你应以坚固之心演说无上之法；这样微妙的经典，应当传授给具慈心的人。想求无上智，不要怖畏生死；由此舍离诸恶，当得殊胜之利。）

#### 用火喻与治毒喻

```
譬如明智人，善能用于火，
成熟种种味，不为火所烧。
若诸愚痴人，无有善方便，
将火置于掌，便为火所烧。
亦如人中毒，迷闷心狂乱，
以火而灸疗，因此得除愈。
月光汝当知，智者亦如是，
依意了意空，故处于生死，
依眼了眼空，于眼无执著，
若能如是知，住眼亦无恼。
```
（大意：譬如明智之人善于用火，以火成熟种种滋味，而不被火所烧；若是愚痴之人，没有善巧方便，把火放在掌中，便被火所烧。又如人中了毒，迷闷而心狂乱，以火灸治，因此得以痊愈。月光！你应当知道，智者也是这样：依于意而了知意空，所以能处于生死之中；依于眼而了知眼空，对眼无所执著；若能这样了知，住于眼中也没有烦恼。）

【按】“灸疗”之“灸”，《大正藏》作“炙”，CBETA依高丽藏作“灸”，今从之。

#### 了眼性空而得出现光

```
若了眼性空，成就真实智，
以真实智故，当得出现光。
若了眼性空，永灭于贪欲，
以无贪欲故，当得出现光。
如是瞋与痴，我执并覆恼，
悭嫉无惭愧，不忍将贡高，
憍慢及增上，谄诳兼放逸，
乃至矫诈等，一一如贪说。
```
（大意：若了知眼性空，便成就真实智；以真实智的缘故，当得出现光。若了知眼性空，便永灭贪欲；以无贪欲的缘故，当得出现光。像这样，瞋与痴、我执以及覆、恼、悭、嫉、无惭愧、不忍与贡高、憍慢及增上慢、谄、诳与放逸，乃至矫诈等，每一种都如贪欲那样来说。）

【按】“矫诈”之“矫”，《大正藏》作“憍”，CBETA依高丽藏作“矫”，今从之。

```
若得真实智，了知眼寂灭，
以知寂灭故，当得出现光。
若得真实智，住佛理趣中，
以住理趣故，当得出现光。
若得真实智，住佛方便中，
以住方便故，当得出现光。
若不修实智，永离于障恼，
成就出现光，我昔未闻见。
若勤修实智，永离于障恼，
能顺于是行，当得出现光。
若求最胜行，当学于此经，
供养诸如来，得实智方便。
```
（大意：若得真实智，了知眼寂灭；以知寂灭的缘故，当得出现光。若得真实智，住于佛的理趣之中；以住理趣的缘故，当得出现光。若得真实智，住于佛的方便之中；以住方便的缘故，当得出现光。若不修真实智，而能永离障恼、成就出现光，这是我往昔从未闻见的。若勤修真实智，永离障恼，能随顺这样的修行，当得出现光。若求最胜之行，应当修学这部经，供养诸如来，得真实智与方便。）

【按】“以知寂灭故，当得出现光”之“出现光”，宫本作“真实智”。

```
若修真实智，当供养诸佛，
成就出现光，犹如掌中果。
若迷眼无我，退失沙门法，
彼人不能得，如是出现光。
若了眼无我，成就沙门法，
彼人当证得，如是出现光。
若了眼尽际，亦了耳生边，
由了耳生边，是大沙门法。
```
（大意：若修真实智，应当供养诸佛，成就出现光，犹如掌中之果。若迷于眼无我，便退失沙门之法，此人不能得到这样的出现光。若了知眼无我，便成就沙门之法，此人当证得这样的出现光。若了知眼的尽际，也了知耳的生边——由于了知耳的生边，这就是大沙门法。）

#### 遍知、善知、现知眼的边际与清净

```
若不遍了知，眼性之边际，
于眼生边际，亦不能遍知，
彼人不能得，如是出现光。
若能遍了知，眼性之边际，
于眼生边际，亦能遍了知，
彼人当证得，如是出现光。
若不善了知，眼性之边际，
于眼生边际，亦不能善知，
彼人不能得，如是出现光。
若能善了知，眼性之边际，
于眼生边际，亦能善了知，
彼人当证得，如是出现光。
```
（大意：若不能遍知眼性的边际，对于眼的生起边际也不能遍知，此人不能得到这样的出现光；若能遍知眼性的边际，对于眼的生起边际也能遍知，此人当证得这样的出现光。若不能善知眼性的边际，对于眼的生起边际也不能善知，此人不能得到这样的出现光；若能善知眼性的边际，对于眼的生起边际也能善知，此人当证得这样的出现光。）

```
若不现了知，眼性之边际，
于眼生边际，亦不能现知，
彼人不能得，如是出现光。
若能现了知，眼性之边际，
于眼生边际，亦能现了知，
彼人当证得，如是出现光。
若不善了知，眼性之边际，
于眼生边际，亦不能遍知，
彼人不能得，如是出现光。
若能善了知，眼性之边际，
于眼生边际，亦能现了知，
彼人当证得，如是出现光。
```
（大意：若不能现前了知眼性的边际，对于眼的生起边际也不能现前了知，此人不能得到这样的出现光；若能现前了知眼性的边际，对于眼的生起边际也能现前了知，此人当证得这样的出现光。若不能善知眼性的边际，对于眼的生起边际也不能遍知，此人不能得到这样的出现光；若能善知眼性的边际，对于眼的生起边际也能现前了知，此人当证得这样的出现光。）

```
若不善了知，眼性之清净，
于耳性清净，亦不能善知，
彼人不能得，如是出现光。
若能善了知，眼性之清净，
于耳性清净，亦能善了知，
彼人当证得，如是出现光。
乃至耳鼻舌，身意与色声，
香味并触法，地水若火风，
性事世间苦，蕴界世将生，
及以声名等，一切皆如是。
```
（大意：若不能善知眼性的清净，对于耳性的清净也不能善知，此人不能得到这样的出现光；若能善知眼性的清净，对于耳性的清净也能善知，此人当证得这样的出现光。乃至耳、鼻、舌、身、意与色、声、香、味、触、法，地、水、火、风，性、事、世间、苦，蕴、界、世与生，以及声、名等，一切都是这样。）

【按】“声名等”之“名”，明本作“香”。

### 圆满出现光的八十种善根资粮

那时，世尊告诉月光童子说：“善男子！若有众生发心趣向大乘，想要圆满成就这样的出现光，有八十种善根资粮。是哪八十种？就是：护念众生；心无损害；对清净戒奉持无缺；其心平等，没有谄曲，也没有悭、嫉、贪、诳之心；深信大乘微妙经典；也不耽爱富贵与憍逸；忍力具足；志愿不退；意乐清净；住阿兰若；不依赖眷属、利养、名闻；安住诸禅与现光三昧；对持戒者无谄而承事；对同梵行者生起殊胜意乐；因敬法的缘故，常对和上、阿阇梨深生尊重；了达契经；善巧宣说；所言诚实；住于正思惟；勤种善根；常行慧施；觉知魔业；严密守护诸根；言词安详审慎；善解真谛；也能了知诸地的自相；求无尽之色；不惜身命；教化四众；断绝世俗的思惟；远离诸邪见；无后世法；不在未学者面前矫饰作态；常对已学者随力开示；从不赞美歌咏之声；也不称誉庄严资具；证入诸谛；具足多闻；舍离睡眠；勤求正法；对佛尊重；发菩提心；舍弃世间事业；修诸学处；为爱法的缘故依止胜友；求诸善根心无厌足；爱乐出家；护持佛法；不起恶业；对教法无疑；善说譬喻；开示秘密；对大菩提志求不倦；所受持的经典未曾忘失；不舍自己的修学；摧伏他人的论说；求出离之道；修无量行；对那法智其心决定；明见因果相续轮回；不著三有，远离增上慢；为有信者建立对治；了达未来果报的差别；善知前际，不假他缘；对远离之行精勤修习；以佛的相好具足庄严。这就是八十种。

【按】“和上”，宋、元、明、宫本作“和尚”。“慧施”，即惠施，布施之意。“增上慢”之“慢”，宫本作“熳”。“为于信者”，宋、元、明、宫本作“于不信者”。

原文：“求无尽色”（大意：求取无尽之色，所指未详，存疑。）

原文：“无后世法”（大意：无有后世之法，所指未详，存疑。）

“再者，月光！这八十法归入五法。是哪五法？就是：知生死、知涅槃、知烦恼尽、知增上、知福果。再者，月光！这五法归入二法。是哪二法？就是：心清净庄严、色清净庄严。再者，月光！这二法归入一法。是哪一法？就是：能成就诸佛如来的无碍解脱。

### 成就如来无碍解脱的八十种法

“再者，月光！又有八十种法，善能成就诸佛如来的无碍解脱。是哪八十种？就是：布施资粮；广大智慧；修清净戒；远离烦恼之热；摧伏憍慢；言词柔软；对种种事无不知时；也识得善友；发心趣向大乘；披精进铠甲；以威仪利益众生；令堕于烦恼的人断除疑惑；毁除诸不善；修行白净之法；不与恶人为伴；种诸善根无有厌足；发菩提心，勇猛精进；觉知魔事；证于诸谛；真实供养，决了无疑；心念众生，常怀济度；不执著诸有；生起大心；对不善的众生指出其过恶；舍离贪瞋痴；不求欲乐之利；成熟众生；修治佛塔；对诸圣者尊重恭敬；对住于大乘的人亲近承事；终不赞叹下劣乘的人；远离声闻；摧伏怨敌；在世尊处广大供养；以殊胜之心种种奉施；得无碍智；具足辩才；以种种譬喻开示正法，而与性空不相违背；求法无懈；显发深义；具大总持；说法无染；能广为流布；化导无厌；圆满诸行，具大威德；辩才无滞；成就多闻；不赞恶人；修习善业；解了诸蕴；舍离诸见；通达因性；超越所行；远离非境；生起清净信；住于正道；爱乐大乘；平等摄受；不执著无我；不厌生死；乐求涅槃；因少欲的缘故住阿兰若；常行乞食，无有懈倦；随有所得，心生喜足；远离无惭愧；亲近于佛；与善友同住；舍离非其同类者；怜悯凡夫；与众生同其所行；对佛有清净信；远离非法器之人；有相违背的人，不与他言说；不来求法的人，不为他开晓；若有来求的，便如其所应为他宣说；对饮食平等；常时布施，平等布施；开门大施。就是这样，童子！这八十法能得诸佛的无碍解脱。”

### 世尊微笑放光，弥勒菩萨说偈请问

那时，世尊知道月光童子深心所念，和悦微笑，放出金色光明。那光普照无量无边诸佛国土，在那些国界作了利益之后，绕佛三匝，还从如来顶上而入。这时，弥勒菩萨即从座起，偏袒右肩，右膝着地，顶礼佛足，合掌恭敬，以种种偈赞而问佛说：

#### 何缘现此光

```
云雷师子吼，迦陵频伽声，
出大法鼓音，何缘现微笑？
殊胜百千日，清净妙音声，
功德甚希有，何缘现此光？
施戒忍精进，定慧等庄严，
一切皆圆满，何缘现此光？
如来柔软音，常远离麁语，
善疗众生病，何缘现此光？
```
（大意：如云中雷鸣、如狮子吼，如迦陵频伽之声，出大法鼓之音，因何缘故显现微笑？殊胜过百千个太阳，清净美妙的音声，功德极为希有，因何缘故显现此光？布施、持戒、忍辱、精进、禅定、智慧等庄严，一切都已圆满，因何缘故显现此光？如来柔软之音，常远离粗恶之语，善能疗治众生之病，因何缘故显现此光？）

#### 赞佛所说空寂之法

```
大悲两足尊，知眼常空寂，
以清净梵音，为众生演说。
耳鼻舌身心，乃至声名等，
并诸集灭道，智忍亦如是。
大悲两足尊，知眼尽生际，
寂静及流转，一切皆空寂。
耳鼻舌身心，色声香味触，
乃至声名等，一切皆如是。
又说因缘法，远离于断常，
非自非他作，众缘之所生。
或以种种门，开示于苦本，
或以种种义，称赞佛光明，
以无量言词，演说寂灭法，
无人无寿者，无我无众生。
过去无量佛，亦以不思议，
百千诸偈颂，演说如是法。
```
（大意：大悲两足尊知眼常空寂，以清净梵音为众生演说；耳、鼻、舌、身、心，乃至声、名等，以及集、灭、道，智、忍，也都是这样。大悲两足尊知眼的尽际与生际，寂静与流转，一切都空寂；耳、鼻、舌、身、心，色、声、香、味、触，乃至声、名等，一切都是这样。又说因缘法，远离断见与常见，非自作，非他作，是众缘所生。或以种种门开示苦的根本，或以种种义称赞佛的光明，以无量言词演说寂灭之法：无人、无寿者、无我、无众生。过去无量诸佛，也以不可思议的百千偈颂演说这样的法。）

```
如来所演说，真实功德法，
无说无说者，所说法亦无。
佛说最胜法，觉悟于群生，
诸天及夜叉，闻者皆能了，
一切阿修罗，意乐已清净，
无量诸人众，疑网悉皆除。
了知贪自性，灭坏瞋与痴，
爱慢及无明，谄嫉并戏论，
乃至苦蕴等，一切皆舍离，
如是诸句义，究竟悉清净。
```
（大意：如来所演说的真实功德之法，没有所说，没有说者，所说之法也无。佛说最胜之法，觉悟众生，诸天以及夜叉，闻者都能了解；一切阿修罗，意乐已得清净；无量人众，疑网都已除尽。了知贪的自性，灭坏瞋与痴，爱、慢以及无明、谄、嫉与戏论，乃至苦蕴等，一切都已舍离；这样的种种句义，究竟都已清净。）

```
如来于一法，通达种种名，
其数百千万，乃至不思议。
于无量佛所，善学如是法，
而于一法中，演说无穷尽。
如来善了达，种种诸法门，
亦能分别知，名句上中下。
修学于一切，种种异言词，
善巧而宣说，微妙第一义。
如是清净音，因缘和合起，
亦不依喉舌，乃至于身心。
其地六种动，十方众咸集，
合掌瞻仰佛，愿为除众疑。
如来善了知，眼尽生边际，
自性常空寂，无去亦无来。
无住无处所，深入于实际，
佛眼无障碍，是故我今问。
```
（大意：如来对于一法，通达种种名称，其数有百千万，乃至不可思议。在无量佛所善学这样的法，而在一法之中演说无穷无尽。如来善能了达种种法门，也能分别了知名、句的上、中、下。修学一切种种不同的言词，善巧宣说微妙的第一义。这样清净的音声，是因缘和合而起，也不依于喉舌，乃至不依于身心。大地六种震动，十方大众都来集会，合掌瞻仰佛，愿佛为大众除去疑惑。如来善能了知眼的尽、生边际，其自性常空寂，无去也无来，无住、无处所，深入于实际；佛眼无有障碍，所以我今天发问。）

【按】“愿为除众疑”之“众疑”，圣本作“疑惑”。

#### 何缘现微笑

```
如来善了知，眼性前后际，
尽无尽流转，自性常空寂。
开示诸法义，令世间欢喜，
牟尼美妙音，何缘现微笑？
佛知前后际，眼性常空寂，
离分别言词，何缘现微笑？
佛知眼无量，种种言宣说，
本性常空寂，何缘现微笑？
佛知尽生边，眼性常空寂，
舍离诸烦恼，证佛菩提智，
具足胜名闻，何缘现微笑？
如来久修学，演说不思议，
了达眼性空，离垢常清净，
无量诸心行，一念皆了知，
光明照世间，为是何瑞相？
大仙等正觉，最胜两足尊，
烦恼悉已除，其心常寂静，
如来殊胜智，深达眼尽边，
复以何因缘，而今现微笑？
```
（大意：如来善能了知眼性的前际后际，尽与无尽以及流转，自性常空寂；开示诸法之义，令世间欢喜，牟尼美妙之音，因何缘故显现微笑？佛知前际后际，眼性常空寂，远离分别的言词，因何缘故显现微笑？佛知眼无量，以种种言词宣说，其本性常空寂，因何缘故显现微笑？佛知尽、生之边，眼性常空寂，舍离诸烦恼，证得佛菩提智，具足殊胜名闻，因何缘故显现微笑？如来久已修学，演说不可思议之法，了达眼性空，离垢而常清净，无量众生的心行，一念之间都能了知，光明照耀世间，这是什么瑞相？大仙等正觉、最胜两足尊，烦恼已全部除尽，其心常寂静；如来殊胜之智深达眼的尽边，又以什么因缘，今天显现微笑？）

（大意：耳、鼻、舌、身、心，六尘以及四大，乃至声、名等，一切都是这样。佛知眼无我，也通达耳无常，并了知鼻性空，因何缘故显现微笑？佛知舌无我，也通达身无常，并了知心性空，因何缘故显现微笑？佛知色无我，也通达声无常，并了知香性空，因何缘故显现微笑？佛知味无我，也通达触无常，并了知法性空，因何缘故显现微笑？佛知地无我，也通达水无常，并了知火性空，因何缘故显现微笑？佛知风无我，也通达性无常，并了知事性空，因何缘故显现微笑？知世间无我，也通达苦无常，并了知蕴性空，因何缘故显现微笑？佛知界无我，也通达世无常，并了知生性空，因何缘故显现微笑？佛知声无我，也通达名无常，并了知道性空，因何缘故显现微笑？佛知智无我，了知寂静无常以及众生性空，因何缘故显现微笑？佛知性即无性，也知我即非我，并了知意乐空，因何缘故显现微笑？观生死无我，也通达常与无常，并了知涅槃空，因何缘故显现微笑？）

【按】“亦达声无常”之“无常”，宫本作“无我”。

```

帝释与人王，龙神咸供养。

无量诸佛子，俱集于众会，

超过于一切，在家修学者。

```
（大意：如来心得解脱，名闻遍满三界，帝释与人王、龙神都来供养。如来善能了知眼的尽、生边际，乃至寂静，因何缘故显现微笑？无量佛子都聚集在大会之中，他们从佛口所生，从法变化所生，都来到佛前安住，合掌而尊重；为了这些大众，我请问这光明的因缘。如来善能了知眼性空无我，超过一切在家修学的人。佛以平等之智，了知诸法无有差别；如来是以意乐而知，并非以神通所见。佛知眼无我，性空，无去无来，清净之智无边，因何缘故显现微笑？）
