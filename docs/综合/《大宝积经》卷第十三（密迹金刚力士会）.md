# 《大宝积经》卷第十三（密迹金刚力士会）

西晋·三藏竺法护 译

## 密迹金刚力士会第三之六

### 密迹请佛应供

#### 请佛七日受供

这时，密迹金刚力士所愿已经具足，得受佛的授记，所期望的已经完成，欣然大悦，合掌对佛说：“唯愿佛大圣前往我旷野之界的鬼王国土，在密迹的宫舍中七日受请。诸菩萨以及大声闻，唯愿垂愍，眷顾而不忽略。当于佛的所在，在旷野鬼王的土地、在我简陋的宫舍中，垂意小食，教化鬼神众、妖魅、反足之类、揵沓和、摩休勒以及其余所居的众生，使他们见到如来世尊，听闻这部经法，长夜安隐，没有种种患难，一心安定，没有危难，便会舍弃瞋恚毒害，不怀悖逆之心。那四天王的一切眷属游行在旷野鬼神王界的，如果见到如来、听闻所说之法，就常获安和，不遭危难。”

这时，佛默然，接受了密迹七日供养的邀请，是出于愍念的缘故，并且想要开化无数众生，使他们种植德本。那时，密迹见佛默然接受了他的邀请，欢喜踊跃，稽首礼佛足，右绕三匝，礼毕退去，忽然隐没，回到旷野国，归于他的宫中。

#### 三昧中庄严高座

这时，密迹力士心中自念：“应当为大圣庄严宫殿，使欲界天人、色界天人得未曾有，十方世界的诸菩萨等都会欢喜。”他心中又自念：“我记得，往昔有一次夜里怀着志愿，所尊奉的道法不可思议，现在也应当这样。”随即入于三昧正受，宣说不可限量；那时高座以及无数亿百千兆载的狮子座自然普遍显现，以珍宝作脚，以奇珍作栏楯，以百千天衣铺在上面；清净妙花、真珠璎珞分布在八条交道上，以宝莲花覆盖其上。

刚入三昧正受，（他想：）“东方离这里恒河沙数的佛国，有一个世界名叫无量宝德净，那佛号叫净王。我应当把那净王如来所庄严的清净狮子座取来；那佛将为一万菩萨授记，那佛国土所见的庄严清净，超过无数诸天人民所有的庄严清净。我现在何不前往那佛土，庄严高座？”

那时，密迹力士入于净宝王三昧正受。刚入三昧，就自然庄严，显现美好的高座，高广美好清净，与无量宝德净佛土的狮子高座相等，没有差异，忽然之间已到了旷野鬼神界土。他所设的高座巍巍如此，极为高广：东西二千四百八十里，南北一千二百八十里；以绀琉璃、水精、砗磲为地，以吉祥藏宝与无量的名香、杂香熏染，竖立无数众宝香炉，焚烧殊妙之香，散布种种天花，种种品物极好，巍巍光色辉煌，能令人心欢悦、身体安和。从其心意应时行菩萨之法，不失其节度，功勋无际，所赞叹的妙德没有边底。又那高座自然所化，有亿百千垓不可计数的狮子座，以宝为脚，以宝为栏楯，以无数天衣铺在上面；种种宝莲花与清净珠饰的交露帐立在八条交道上，以众宝铺在其上，建在地上，一切普遍具足。

【按】“车𤦲”之“𤦲”，先前电子文本未能显示，今据《大正藏》补出。“炜晔”之“炜”，《大正藏》作“暐”，CBETA 据高丽藏、碛砂藏作“炜”。“绀琉璃”之“绀”，宋、元、宫、圣本作“细”。

那时，密迹力士这样设立了种种不可思议的高座，高广庄严清净，殊特无量的狮子之座，安然从容地从三昧中起身。随即在当夜准备种种甘美的饮食，尊奉菩萨，调和性行，兴发如来的报应之果。种种供养准备完毕，天还未亮，他告诉四天王：“诸位应当知道：世尊今日到我宫中受食，邀请为期七日，诸菩萨众以及诸声闻都将来集会。你们要恭敬，不要放逸；大圣难遇，亿世才有一次；都应当一心，舍弃世俗、仰慕道法，恭敬奉事；去除生死，弘扬慈悲至道。时机也难遭遇，正法不易听闻；三界无所依怙，唯有道可以依恃，普遍如虚空，无所障碍；不要怀着乱心而行放逸之行。你们的眷属、徒众、使役、妻子、仆从，供养七日，不要贪恋身心，唯以道为根本，不要随顺其他事业而损违道教，专精一心供养如来，常当谦下，加倍恭敬，没有二心。令这旷野鬼神之处、王者之地的鬼神妖魅、反足诸鬼、揵沓和等，都归命于佛与秘密的道法。那四天王以及其余众生，都不失时机，普遍蒙受济度。诸位应当明白：已经邀请了天尊，稽首归命，供养佛之后，勤于听受经典，宣布八方，使一切众生都蒙受，这才是报答佛恩。”

#### 遣二子召请诸天

那时，密迹力士有一位太子，名叫密兵，告诉他说：“你去普遍告知地神以及虚空神，告诉四天王、忉利天、焰天、兜率天、无憍慢天、他化自在天，上至魔天，各令他们知道：世尊今日在旷野鬼王的土界，接受密迹金刚力士的邀请，在宫舍中将受饮食，菩萨与声闻也是这样。如果想见佛、听闻道教，都前往那里。”太子金刚兵受教宣命，须臾之间就传遍了。

【按】“密兵”，下文作“金刚兵”，照原文录出。

他的第二个儿子名叫善分，他告诉他说：“孩子！你现在亲自以自己的神足之力，去告知诸梵天、梵迦夷天、梵满天、梵度著天、大梵天、有光天、少光天、无量光天、光音天、清净天、少净天、无量净天、净难逮天、净离秽天、顺行天、少顺行天、无量行天、行果实天、亦然天、于是天、善愿天、善现天、至一善天，都普遍告知他们：今日世尊游化于旷野鬼王国土，在密迹金刚力士宫舍中受请，诸位想要见佛，都一起前往集会。”善分受教宣令。这样须臾之顷，欲界天、色界天人都共同集会在虚空中，纵广四万里，上下也是四万里，周遍诸天，各自依次而坐。

#### 遥请佛时已到

于是，密迹金刚力士庄严道场之地，供养饮食准备完毕，合掌向着佛的所在，遥遥启白说：“现在时间已到，愿佛大圣垂光回意。”并说偈颂道：

```
丈夫尊雄屈，人中上愿顾，
莲花正士发，大圣人时到。
两足尊枉神，天人圣祠祀，
人中尊屈意，圣明时以至。
戒如莲华盛，精进转增长，
覆护上惭愧，最胜唯顾意。
建立于圣谛，慈哀加弘恩，
无我无所施，最胜师子顾。
```

（大意：丈夫中的尊雄啊，请屈驾；人中之上者，愿您眷顾。莲花般的正士出发吧，大圣人，时间已到。两足尊枉驾神威，天人圣者所供奉祭祀的人中之尊，请屈意前来，圣明的时候已到。您的戒如盛开的莲花，精进转而增长，覆护于上，具足惭愧，最胜者唯愿眷顾。您建立于圣谛，以慈悲加施弘恩，无我无所施，最胜的狮子，请眷顾。）

【按】“愿顾”之“顾”，《大正藏》作“愿”，CBETA 据高丽藏、碛砂藏作“顾”。“枉神”之“枉”，《大正藏》作“在”，CBETA 据碛砂藏作“枉”。

```
戒行博闻业，茂盛觉意花，
解脱具足实，殊胜树愿来。
功勋海唯枉，其意深且广，
清水定为意，炽盛精进业，
奉哀道场业，智慧璎珞严，
明本慧开觉，圣达降怨顾，
第一明无动，以药树疗病，
学不学盛明，最胜唯屈神。
```

（大意：您以戒行、博闻为业，茂盛着觉意之花，具足解脱之果，殊胜之树，愿您前来。功勋之海，唯愿枉驾；您的心意深而且广，以清水般的禅定为意，炽盛精进之业，奉行大悲与道场之业，以智慧璎珞庄严，明本之慧开发觉悟，圣达者降伏怨敌，请眷顾。第一明者，无有动摇，以药树治疗众病，学与无学都盛明，最胜者唯愿屈驾神威。）

【按】“降怨”之“怨”，宋、元、明、宫本作“慈”。

### 佛赴旷野鬼王界

#### 佛与大众前往

那时，世尊见密迹金刚力士启白时间已到，告诉诸比丘：“都早早整理衣服，著衣持钵。”并命令护寺的人（留守）：“密迹金刚力士来启白时间已到，各自出发前行，七日应请。诸声闻众、菩萨等，如果得到神足的，就以自己的神力随后侍从佛；没有神足的，就进入如来的光明，承其威明，佛愍念他们，都能前往。”

那时，世尊刚一出发上路，诸菩萨都在前面引导，诸声闻众在后面侍从，诸天龙神持着花香伎乐在虚空中侍从，诸天玉女赞叹佛，于是说偈颂道：

```
欢喜发光明，妓乐自然鸣，
震动佛刹土，天雨于众花。
佛之大威德，神足度无极，
圣变化无限，娱乐佛无底。
佛吉祥无际，佛神圣无量，
佛威仪无底，佛功勋无限。
游灵鹫之山，在于八山中，
于上虚空中，无碍如鹰王。
```

（大意：欢喜放出光明，伎乐自然鸣响，震动佛的刹土，天上降下种种花。佛的大威德，神足度于无极，圣者的变化无限，佛的娱乐没有边底。佛的吉祥无际，佛的神圣无量，佛的威仪无底，佛的功勋无限。佛从游化的灵鹫山出发，在八山之中，于上方虚空中，无碍如同鹰王。）

【按】“鹰王”之“鹰”，明本作“雁”。

那时，欲界天人、色界天人见到佛世尊从虚空中来，犹如日光显现在水中，如满月在众星中独自明亮，犹如天帝在诸天中最尊，又如梵王照耀大众集会，见到这样的变化，大悦欣然，降下天上青、红、黄、白种种杂色莲花，供养散在佛身上：意花、大意花、柔软花、大柔软花、昼夜树花，有果有大实，以及诸转轮王的离垢之花，百叶、千叶，又有百千叶，欢乐喜生之味兴起，光照一切的香花；善妙香、常熏香、乌虚延香，常有花乐、眼目之乐。这样的众花兴云降雨，降下种种杂香，鼓奏天上的妙乐，诸天玉女眷属百千。

那时，须臾之间到达旷野鬼王国土毗沙门天王界，在他的宫殿中。一切声闻、诸菩萨众眷属围绕，佛刚一下来站在地上，大地大震动，光照十方，安和柔软，不扰乱众生。

【按】“在其宫殿”之“宫”，《大正藏》作“空”，CBETA 据高丽藏作“宫”。

#### 四天王与鬼神归佛

这时，四天王见佛世尊到了大旷野鬼王之国，急急忙忙地与他们的宫人及诸眷属，持着花香、杂香、泽香、缯彩、幢盖、伎乐，排列成行吹着螺贝，各自拿着这些供品前往佛所，稽首礼佛足，绕佛三匝，退立一面，把所带来的供品供养散在佛身上。见到佛大悦，心中欢喜；供养散佛之后，退立一面，合掌自归。那时，世尊因为四天王（的缘故），应病随时宣说经法，一万三千鬼神、妖魅、厌鬼之类都发起无上正真道意，一万玉女也发起这无上大意。

这时，密迹力士与宫人、婇女、诸子眷属，持着花香、杂香、捣香、幢盖、伎乐，从他的宫中前往毗沙门天王宫舍，到世尊所，稽首礼佛足，右绕七匝，各自把所执持的供品供养散在佛身上。在毗沙门天王宫中依次而坐，鼓奏种种伎乐，自入清净之心，无所执著；所带的侍从各自就座。如来的高座独自显现，巍巍清净，妙极无比；密迹的诸子举起所庄严的交露之帐与狮子高座，从虚空中降下，安放在地上，寂然不动。诸菩萨众以及诸声闻仍坐在原位。

#### 高座的来历

这时，欲界天人、色界天人见到他所设的座位高广庄严美好，得未曾有，惊怪难及，心中自念：“密迹力士从哪里见到这宝饰高广的狮子之座？玄妙无极，殊特难喻。”这时，承佛的威神，在虚空中自然传来声音：“你们想知道吗？东方离这里的界分，越过恒河沙数诸佛国土，有一个世界名叫限净，那佛号净王如来、至真、等正觉。密迹金刚力士曾见到那国土的微妙庄严清净，现在为了法的缘故，送来这殊妙巍巍的高座。”

这时，佛刚登上高处的狮子高广之座，当时旷野鬼王国土的鬼神、妖魅、反足之鬼、揵沓和、迦楼罗、真陀罗、摩休勒，都前往佛所，稽首礼足，退立一面，合掌归佛。

#### 劝众助施与供养

那时，密迹金刚力士对四天王以及诸来会大众说：“诸位贤者，请屈意，都同心和合；饮食已经准备好，各自亲手斟酌，勤加供养佛与菩萨圣众。为什么呢？如佛所说：如果能欢喜地辅助兴办功德，供养所蒙受的福祐无量，而本来施主的福德也不减少。诸位仁者以这样劝助、辅佐其布施，能得到不可限量的功德福祚。”

于是，密迹金刚力士与他的宫人、婇女、一切诸子以及诸眷属，亲手斟酌百种佳肴、不可计数的美味，心中辅助开士（菩萨）求如来之福，以更加谦恭之心供养大圣，佛与菩萨、诸声闻众都得到充足饱满。饮食完毕，行澡水后，密迹金刚力士另取一张小床坐在佛前，对世尊说：“唯愿加施弘大的慈悲，应时演说正法，宣说入法之门，使众生之类了知道心与所行的由来：那还没有发心的，兴起这道心；已经发起道心的，至于不退转。令这些鬼神、妖魅、揵沓和等长夜永安，没有种种患难，多得安和。多多悲愍诸天与人、三界众生，使他们得到殊特之愿，超越世间。”

### 佛于密迹宫中说法

#### 在家修善与罪福之报

那时，世尊告诉密迹金刚力士以及诸大会众：“仔细听，仔细听，好好地思惟忆念。如果族姓子、族姓女修行进入法门，坚固安住于此，至于殊特之愿，没有分别，不至于损耗。”密迹力士与诸大众受教而听。

佛告诉密迹力士：“如果族姓子以及族姓女，应当奉持笃信，善于随顺道法，多有顺宜，想要见到贤圣，乐于听闻正法；心不悭嫉，不吝惜财业，伸手布施，舍弃世俗的习惯，喜好布施之福而不期望回报；心不怀害，志意清净，专精一心而不暴乱；相信报应之果，喜好善良真实之业，不怀狐疑，从不犹豫；见到清白之理，知道果报不会消失，宁可失去身命，也不犯非义之事；仁慈不杀，不与不取，不行邪淫，不犯妄言、两舌、恶口、绮语、嫉妒、瞋恚、愚痴；不犯十恶，身行十善，也劝他人奉行。

“常奉持平等的信心，见到诸沙门奉持戒律、具足法度、勤精修行，志存思惟道法，常应合义节，寂然调和，心存恬淡；受持而无所执著，不受邪语；志性仁慈，舍弃恶法，行为不卒暴；明如火炬，不像野兽那样愚昧；言语无所毁谤，心性平和；断绝睡眠，舍弃唐突之心，放下沉重的担子；屡屡惠施；见到诸善友、一切诸佛及佛弟子，常行恭敬。像这样，常常追随侍从沙门梵志，谦下作礼，习与相随，不失其意，常奉事这些诸善知识。由于爱乐的缘故，更以法施救济危厄；以宣说正法劝化他人，演说其所报应：布施招致大富，持戒得以生天，博闻得到大智，修行合于道。各为他们说明果报：布施得大财，悭贪堕饿鬼；持戒、忍辱、精进、一心、智慧，渐渐入于道的根元；犯戒堕地狱，瞋恚得丑陋，懈怠荒废道业，乱意堕于罪中，愚痴投入黑暗。这就是由身、由言、由意的恶行之报，这就是身、口、意善恶之果。犯这三事，长夜不安，投入地狱、饿鬼、畜生；护持这三业，就生在天上人间、十方佛前，长夜永安，没有众患。各为他们开示罪福之报与善恶的去处。

【按】“搪揬”，宋、宫、圣本作“唐突”，元、明本作“搪突”。“重檐”之“檐”，即“担”。“稍入道元”之“元”，宋、元、宫、圣本作“无”，明本作“法”。

#### 十二缘起与生灭

“如果见到堪为法器的人，就为他们演说深法：空、无相、无愿，行无所行，至无所至，无我、无人、无寿、无命；分别幽奥的十二缘起：如果依倚这件事，就有生；如果不依倚这件事，就没有生；从这里导致那里，不从就不导致。从无明导致行，从行导致识，从识导致名色，从名色导致六入，从六入导致更（触），从更导致痛（受），从痛导致爱，从爱导致取，从取导致有，从有导致生，从生导致老死，从老死合成大苦阴，成为四大之身。痴灭就没有行，行灭就没有识，识灭就没有名色，名色灭就没有六入，六入灭就没有更，更灭就没有痛，痛灭就没有爱，爱灭就没有取，取灭就没有有，有灭就没有生，生灭就没有老病死、大苦阴的聚合，不受四大之身，就常得永安，长无众患。由于灭尽，就无所有。为什么呢？起这个就生这个，没有这个就没有那个。犹如种树，开始生出芽根、茎节、枝叶、花果；拔掉树就没有芽，又从哪里有茎节、枝叶、花果呢？理解了没有无明，心无所著，就没有牵连。

【按】“更”即触，“痛”即受，皆竺法护译语。

“十二缘起都是从缘与对而生，没有缘就没有对，一切三界都是本无（真如），都从无而生。从有而死：由于不通达于无，以为有而导致生，不知道有是空，依倚于这个‘我’，便导致死。理解了无就不生，了知了有就不死；（那些）被罪所追逐、被尘劳所逮的，颠倒苦恼，愚痴黑暗不实，为他们宣说真谛，应合其仪节；所观察的如法，而对诸法无所造作；不得所造，就没有退，也不是没有退，没有往来周旋之难。假使心意于法，心意无所执著，信受本来空，一切诸本都清净恬淡。

#### 菩萨常得见佛与无放逸

“安住于这样的人，如果是菩萨大士，就常得见佛，从不远离；不失听闻正法，不违离圣众，在在所生之处，常见诸佛。虽然有所生，却不生在无佛的国土；生了就见佛，行于不放逸，仰慕追求真正精进之法。勤修这些之后，不用家业，善于奉行清净之行；不用妻子、男女、奴婢、仆使守护宅舍，迅速持守正法，不以戏逸自恣于爱欲。对于诸佛世尊所施的言教，由于笃信的缘故，舍家为道。信受出家之后，作为善妙的亲友、真正的伴侣。由于受持真业，性行微妙，听闻玄妙之法，以修行为要，不归于外在的装饰；以觉意为第一，而求博闻不知厌足。如所闻之法，广为人说，没有希望供养之心，不以自己的言语有所依仰；讲说经典，依所闻之慧，按其所行所住而为人说，使听法的人兴隆大慈，而对众生发起无尽的悲心。由于得到博闻，无所爱吝；不贪恋身命，少欲少求而知足，以善妙贵重之业作最好的供养，喜好闲居，专精守节。依所闻之法观察其义趣，自归于正义，思惟奉行，不归于外饰。他所导御的天上世间，不只是为了自己而有所行，是为了众生的缘故求上大乘，至诚仰慕佛道自在之乘，成就无放逸。

“什么叫无放逸呢？由于通达境界：眼不见色（而执取），不受妄想，不著于文饰，了知色的灾难；虽然先前曾经爱乐，便舍弃而去，晓了它本来无有。如果耳听声、鼻闻香、众想、舌嗜美味、身之所触、心之所法，也是这样。所谓无放逸，就是自己的心无所生，护持他人之心；舍弃爱欲之乐，入于法乐；不行欲想，没有瞋恚想以及危害想，没有贪、瞋、痴之业。没有这些恶的根本，身不行恶，口不说非，心不行秽，不起反念，不犯一切诸不善法，这就叫无放逸。

#### 有与无

“由于无放逸，常应合节行，晓了有与无，知道无与无有。什么叫有？什么叫无？行于平等的人，有贤圣的解脱；修邪行的人，没有贤圣的解脱。又其次，也有罪福之报，或者没有罪福之报；或者有眼，或者无眼；或者耳、鼻、舌、身，或者有意，或者无意。又能了知色是无常、苦、空、别离之法，这叫作有。志于学道，（而凡夫）计执色为常、长存永立、没有别离之法；由于没有平等之住，有这样的念头，所以有痛（受）、想、行、识；有了知无常、苦、空、别离之法。又从无明之缘便生起不善，如果没有无明，就没有行；从生之缘，所以有老病死，如果没有生之缘，就没有老病死。布施招致大福，贫穷是由于不施舍；穷困是由于有贪嫉，悭吝就没有大财。奉法至于道，不顺义理就不能至于道业。精进的菩萨能得大慧，懈怠的菩萨不能至于道。不自大的人能真正得到异决（授记），那贡高的人不能至于灭度。如果普遍入于寂静，至于空无（就能得道）；计执吾我、人、贪身、寿命的，不能至于道慧。这就是为人应当顺时的仪节。”

原文：“志学于道，计色有常，长存永立无别离法。以无平等住、有是念故、有痛想行识。”（大意：志于学道，（而凡夫）计执色为常、长存永立、没有别离之法；由于没有平等之住，有这样的念头，所以有痛（受）、想、行、识。存疑。）

#### 四法印

佛说：“如果族姓子、族姓女修习普明之智，或者达到所知：无论在世间还是不在世间，普智计量这些，都没有所知。那有天食而无所执著，如果没有天食也无所执著。一切如来都敷演入于顺义的一切诸法，如来明证下面四法的缘故。哪四法呢？一是一切万物都归于无常，二是一切诸有都是苦毒，三是一切诸法都没有我，四是一切有形都至于空无、无为、泥洹寂灭。

“所以说一切万物都归于无常，是因为众生愚惑，自己想象为常，如来说法是为了断除种种常的计执。一切所有都是苦毒，是因为众生暗塞，计执想象为乐，所以为他们说法，断除种种乐的执著。一切诸法都没有我，而众生心中计执有吾我，所以为他们说法，断除种种我想。一切有形都归于空，众生沉迷，反而想象都是实有，所以为他们说法，断除对有的执著之想，令入寂然泥洹。一切众生怀有自大之心的，如来说法，使自大的人不再贡高，舍去依倚执著。

“由于听闻‘无常’之音，理解其音声都是空，才晓了无常之义。那义是什么呢？都不生，不增，不起不灭，这才名为入于永恒的无常。由于听闻‘苦’之音，入于所愿之际，五阴空无所起，这名为苦义。由于听闻诸法都无我之音，奉行空解脱门，对于我与非我，没有这二相，这是非我之义。由于听闻泥洹寂灭，志造无想，不燃不灭，是彻底寂灭之定，无终无始，这才名为理解了空义，而不以无想作为取证。正是这样，贤者！如果有菩萨能行这些，就从未违失一切诸行与道品之法；以无想之行，普遍周备一切诸佛道法三十七品。”

【按】“入际所愿”之“际”，宋、元、明、宫、圣本作“除”。

那时，世尊在密迹金刚力士的宫殿中应病演法，随即那会中二万天人都发起无上正真道意，不可计数的人都受持五戒。

### 四天王护世之法

那时，四天王上前对佛说：“唯愿哀愍宣说，我们应当怎样护持世间？”

佛告诉四天王：“你们应当以行十法护持世间众生。哪十法呢？一是不伤害一切有命之类，二是不窃取他人的财宝，三是不侵犯他人的妻室，四是不两舌挑拨他人，五是不妄言欺诈他人，六是不以恶口言辞伤人，七是一切所说从不绮饰，八是不怀嫉妒、生起彼此分别之心，九是对于善恶之业不发瞋恚，十是常修正见，不随邪疑。这就是十法。诸位仁者以这十件事护持世间，才合于法教。”

佛又告诉四天王：“又诸位仁者，还有八法护持天下。哪八法呢？一是言行相应，从不相违；二是奉敬尊长，不怀轻慢；三是言辞柔软，不说粗犷之语；四是谦下恭顺，常执逊让之意；五是常行质朴，不作谀谄；六是常修仁和，没有佞饰；七是一切诸恶都无所犯；八是以种种德本将护随顺世间。这就是八法。”

佛告诉四天王：“还有六件事护持天下。哪六件呢？一是身常行慈，不害众生；二是口宣仁慈，不说恶言；三是意念慈心，不怀增损之心；四是得到利养，平等地驾御使用；五是平等护持禁戒而无所犯；六是平等地以正见开导曲戾之人。这就是六件事。”

【按】“不抱增损”之“抱”，宋、元、宫本作“施”，明本作“暴”。

佛告诉四天王：“还有四件事，常作为法的首要，护持世间。哪四件呢？一是有所建立行持，从不贪嫉；二是不怀瞋恚加害他人；三是不以愚冥障蔽，加于未达之人；四是所行所至之处，不怀恐惧。这就是四件事。”

佛告诉四天王：“还有二件事，用来护持法与世间人民。哪二件呢？一是惭耻：（惭耻）自己从无数劫以来不合于道法；二是怀愧自责：（愧于）不能深入于法、救护一切。这就是二件事。”

佛说：“诸位仁者！应当行这些法以护持天下。由于能建立这样的法行，才能护持世间。”

### 密迹所问诸法

那时，密迹金刚力士以宝饰交露之帐贡覆在佛上，又对佛说：“菩萨怎样以无瞋恚之法，至于无上正真之道？”

佛说：“族姓子！菩萨有十件事，行无瞋恚之法，至于无上正真之道。哪十件呢？一是常行慈心，不犯伤害；二是不厌众难，常修大悲；三是所作事业常勤精进而有殊特；四是常奉行空，得到三昧；五是从因缘发起，入于智慧；六是以权巧方便普入一切；七是了达三世，清净过去、未来、现在；八是以真谛之见，无所罣碍；九是遵奉道业，入于一切法；十是一切诸法都归于空。这就是十件事。”

密迹金刚力士又对佛说：“菩萨有几种法，听闻佛不可思议之法而不恐惧？”

佛说：“族姓子！菩萨有八种法，听闻佛的不可思议，心无恐惧。哪八种呢？一是所造的功德常能究竟；二是一心禅思，畅达不乱；三是有善友，而得将护随顺；四是心常笃信，乐于微妙之法；五是理解诸法都如幻化；六是晓了一切法不可思议；七是了知诸法不可成就，犹如进入虚空；八是畅达一切法都是狂惑、放逸、虚伪之相。这就是八种。”

【按】“狂惑”之“狂”，宋、元、明、宫本作“诳”。

密迹金刚力士又对佛说：“菩萨怎样在一切事业与开士之法中得到自在？”

佛说：“菩萨有四种法而得自在。哪四种呢？一是遵行如幻三昧，畅达一切法，入于五神通而特别超越；二是以三解脱门超过四禅；三是以智度无极（般若）修四梵行；四是行权巧方便，具足六度无极。这就是四种。”

密迹金刚力士又对佛说：“菩萨有几种法进入法门？”

佛说：“族姓子！菩萨有四种法进入法门。哪四种呢？一是入禅思之门，具足晓了一切众生的根本；二是入智慧之门，分别一切章句义理，为大众敷演；三是入总持之门，一切所执持的常念不忘；四是入辩才之门，因而能令众生心中欢悦。这就是四种。”

密迹金刚力士又对佛说：“菩萨有几种力，成就开士之行？又这道力无人能挡，能降伏众魔？”

佛说：“族姓子！菩萨有八种力，无人能挡，能降伏众魔。哪八种呢？一是道心之力，性行清净；二是精进行之力，而不退转；三是博闻行之力，奉持无极的智慧；四是忍辱行之力，为了护持众生的缘故；五是无所生之力，不怀瞋恚；六是不虚妄之力，具足解脱；七是修道行之力，完备智慧；八是以大悲之力开化众生。这就是八种。”

### 密迹护法神咒

佛说这个法时，密迹金刚力士以及五百个儿子都得到无所从生法忍。得到法忍之后，上前对佛说：“唯愿大圣以这八法经典的要义，使它流传天下，以愍念我们；使这密迹宫自然广大，以这德本光明普照；如来灭度之后，令它遍布流传而不消失。”

那时，世尊见到密迹诸子心中所念、劝请启白佛，佛告诉密迹金刚力士：“密迹堪当这些章句。我到佛树下时，你那时与诸菩萨（在一起），魔将兵前来，你以威势前来拥护我，所以降伏魔兵，你当时就想念、讽诵、通利（这些章句）。现在又应当护持将来的末世，令正法流布，遍及阎浮利，周遍十方，令所施的教法久存，制伏一切外道异学。”

那时，密迹金刚力士见佛世尊劝告，随即从座起，长跪合掌，当时就以这些言辞章句宣说咒道：

```
醯黎
休留休留
其强飚聚
各罗眼动摇归救
忍力力尽
寂怕作角鵄伊犁佉丘佉犁佉犁
护无择
住胜生往还无曲以慈受之调和成
施持已
```

【按】此咒竺法护多半意译，依例保留原文，不作翻译。“佉丘”，宋、元本作“住丘”，圣本作“住兵”；“佉犁”之“佉”，宋本作“住”。

“诸天、龙，告诸鬼神、揵沓和、妖魅、人与非人：常得吉祥安隐。（此咒能）动摇山王，也震动天地，也扰动水王。由于宣说这咒的缘故，摄伏外道，为法君所救护，光耀法焰，应当笃信这些章句。”

听闻这咒之后，诸天众各自举声赞叹说：

```
正法住甚久，动三千佛土，
一切众会同，自投人王前。
归命使无罪，施此无恐难，
其持是言教，令正法永存。
```

（大意：愿正法久住，震动三千佛土，一切众会同心，自投于人王（佛）之前。归命，使无罪过，施予这无恐无难之法；那受持这言教的人，能令正法永存。）

【按】“其持”，宋、元、宫本作“甚持”，圣本作“甚特”。

### 佛还灵鹫山

那时，世尊在旷野鬼王国土密迹金刚力士宫中受供七日，开化了无数众生。七日期满，忽然从旷野宫中隐没，腾升到虚空中，与诸菩萨以及声闻众一起；一切诸天在上方普遍共同供养佛以及圣众，诸玉女众都共同赞叹，放出大光明，诸天人的伎乐百种自鸣，空中降下花雨，佛土大震动，显现佛的大神变。佛从密迹力士宫殿隐没，犹如凤凰之王，回到灵鹫山住。

【按】“宫殿”之“宫”，明本作“空”。

### 阿阇世王问密迹本缘

#### 王来问

佛在灵鹫山与比丘众在一起，以及诸菩萨眷属周旋，各自思惟道教。那时，阿阇世王从罗阅祇大城出来，与笃信慕乐的长者、梵志一起；一国的人民听说佛回到国中，各自在傍晚聚集，也从城中出来，前往灵鹫山，到了佛所，稽首礼佛足，右绕七匝，退立一面。

国王上前对佛说：“我曾经坐着有所商议时，诸比丘来到太子那里，口中宣说：‘今日世尊前往旷野鬼王土界，到密迹金刚力士家中受食。’是的，世尊！我听到这件事，惊怪难及，前所未有。诸佛世尊不可思议，竟能以大悲垂愍众生。如来行慈，普济众生，犹如虚空，言语没有偏私，是为了一切众生的缘故，前往旷野鬼王土界，到密迹金刚力士家中受食。佛的弘大志愿不可譬喻，没有言辞可以说尽。如果有人得以蒙受如来讲法，宣传道训、决疑之律，无不得到安乐。又，世尊！那密迹力士有几件事处于平等而得正觉？他最为至重地种下众多德本，才能有这样微妙广大的辩才？”

佛说：“大王！这件事是究竟而不可企及的，他的至德之本，没有能超过的。”

国王对佛说：“确实是至真的，种下那样的德本，所以获得这样的果报。如果有人相信，他的功德会怎样呢？”

佛对大王说：“假使十方各有恒河沙数，那一一沙数尚且可以知其限量；密迹金刚力士所见的诸佛不可计数，穷尽其边际地供养奉事，由于这个行持的缘故，合聚积累而成大辩才。应当这样看：一切都有本末。”

【按】“合积大辩”之“合”，宋、元、明、宫本作“今”。

#### 勇力菩萨本生

佛告诉国王：“在过去无数劫、不可限量之前，那时有一尊佛，号叫息意如来、至真、等正觉、明行成为、善逝、世间解、无上士、道法御、天人师，号佛、世尊。那世界名叫选主，劫名不移。那息意佛纯一化导一切诸菩萨众，令他们都精进，说作菩萨之法，没有懈怠，心无厌倦，舍弃身体寿命也不吝惜，唯志于道法。

“那时有一位菩萨，名叫勇力，随即从座起，前往息意佛所，稽首礼足，上前对佛说：‘如大圣所宣说的，我承受理解其意义：如果有菩萨心中自念：’我应当迅速证得无上正真之道，成为最正觉。”有这样念头的菩萨，名为懈怠。为什么呢？如果菩萨不用精进，厌患生死，这样的心就不能成就佛的大道。如果有菩萨见到生死之难，就见到缚结，不能至于灭度；唯有化度众生，才能成就正觉。为什么呢？是的，世尊！菩萨之法，是普遍修行勤修，在在生死、常所在处，开导利益无量众生，令他们都灭度，而也无所教。所以，世尊！菩萨作行，应当重视生死，不敬重灭度。菩萨造行重视生死之后，奉事无限诸佛，导利开化无量众生，听闻无数法，入于众生之念；（如果）所行的志性敬重泥洹之行，重于种种观（寂灭之观），便会自己堕落，沉没在小节之中。如果有菩萨畏惧生死而怀恐难，乐于泥洹之行，应当这样看：这样的菩萨就是堕落，由于无行而堕失如来之行，对于众生就有罪咎。

【按】“我当疾逮”之“当”，《大正藏》作“等”，CBETA 据高丽藏作“当”。

“什么样的菩萨不随顺而行、乐于声闻缘觉之地呢？那只观察自己的行持、（不）想化度众生的，所以名为没有开士之行；那行于声闻的，就没有菩萨之行。为什么呢？诸声闻之行，畏惧生死之苦；菩萨游于无量生死而不以为拘束。”

“这时，息意如来赞叹勇力菩萨说：‘善哉，善哉！正士！你畅快地说了这番教言，淳正善美。菩萨行道，舍弃自身的安乐，不舍弃他人；常省察自身，不求他人的过失。’（勇力）又问：‘什么是菩萨的所行呢？’

“佛说：‘族姓子！端正自己的行为，而为众生宣说成败之事与生死之难；受无量生死之患而无恐畏；不乐声闻、缘觉之地，修习菩萨之行；不贪近禅思，处于三界而晓了禅定；分别恶趣，修习方便；完全了知禅定智慧的功德圣慧，而不可穷尽。发起无生之慧，为人宣说一切本无；智慧无所生，知其所受；了知诸众生而无吾我，以智慧开化一切众生；晓了诸法寂灭，了解护持诸法；畅达诸佛土，了知一切，自然如虚空，佛国清净；他的智慧鲜明，以智慧圣达一切法无，增益相好，入于庄严；智慧无所行，因而奉遵一切德本，从不忘舍；少恼少事，对有为众生所可造作的，常行拔难；身心恬淡，积功累法，无所秽厌；兴发禅思，晓了长久的寂静，正定一心；以方便觉达深妙之法，或以宣布种种品类的教法，分别诸观，护持德果；开化声闻、缘觉之律，爱乐如来所解脱之业；降伏（示现）菩萨之行，示现如来所行的根本。这就是，族姓子！如来所行之业。’

【按】此段“积功累法”“兴发禅思”“深妙之法”诸句中的“法”“禅”二字，《大正藏》互倒，CBETA 据高丽藏校正。

“大王应当知道：那时勇力菩萨在那如来所听闻宣说这样所行清净之法，又对那佛说：‘太难得了，世尊！前所未有！现在如来至真之言，宣说了这菩萨所应当行的。又，世尊！如佛所说，我观察理解其意义：善权方便，是诸菩萨对于一切诸法都由自己所行。犹如世尊观察虚空，含受一切十方万物，为一切色显现自体，不可称计，显现包容一切有形之类，而虚空的行业已无所障碍。正是这样，世尊！善权方便，是诸菩萨在一切法中而得自在：有学之法与无学之法、凡夫之法与最正觉之法，都由它而成。犹如，世尊！火所遇到的草木百谷，无不被烧；菩萨也是这样，在一切法中自在所行，以智慧之焰烧尽一切愚冥，三界没有烟。犹如，世尊！大怒的丈夫，瞋恚炽盛，逆害他人而无所顾忌；菩萨也是这样，以权巧方便自在由己，以智度无极断除一切众生的尘劳。犹如，世尊！清水宝珠放在浊水中，随即清澈；菩萨也是这样，以权巧方便消除一切尘垢与三垢秽浊。犹如，世尊！有一种大威力的药，名叫消除，如果放在毒中，能消除一切毒，永无剩余；菩萨也是这样，以权巧方便游于一切三界之难，执持权智之业，灭除众生的尘劳爱欲。由于这个缘故，世尊！应当这样看：善权方便，是诸菩萨在一切诸法中自在由己所行。’

“正是这样，大王！勇力菩萨说这些话时，不可计数的人都发起无上正真道意。大王想知道吗？那时的勇力菩萨难道是别人吗？不要作这样的看法。为什么呢？就是现在的密迹金刚力士之身。这位正士之身坚强精进，披着弘誓功德无极的大铠，巍巍如此；供养诸佛不可称计，光明如此，无可譬喻。”

### 金刚杵之重

那时，阿阇世王心中自念：“这位密迹金刚力士所执持的金刚有多重呢？是以大力才能执持吗？”

这时，密迹金刚力士知道阿阇世王心中所念，就把所持的金刚放在地上。刚放在地上，三千大千世界六种震动。密迹金刚力士对阿阇世王说：“大王试着举起它。”

这时，阿阇世王以大力士的力量，竭尽全力去举它，却不能使它离地如一根毛发。这时，国王惊怪，得未曾有，上前对佛说：“世尊！我自身有大力士的力量，披着极为奇特的铠甲，能牵捉大象，举起象鼻把它投掷出去，无所障碍；今日举这小小的金刚杵，却不能移动它如一根毛发那样大。”这时，阿阇世王更加怀疑：“世尊！为什么会这样呢？”

佛说：“大王！这金刚入于重大的功德之中，不能以披铠之力以及大象之力来举起、移动它。”

那时，密迹对天帝释说：“仁者名号叫执持金刚，拘翼（憍尸迦），今日请仁者从地上举起这金刚杵。”这时，天帝释以无限的神力，极尽神足之力，想要举起那金刚，却完全不能举起。那时，天帝释上前对佛说：“我们自身与诸天一起，与阿须轮战斗时，以一根手指举起维质阿须轮所在之处，把他投掷出去如同一颗圆丸，使他们都奔驰逃散，不知去向。而这金刚形体小小，为什么却不能移动呢？”

【按】“我身世尊”，明本作“世尊我身”。“犇驰”即“奔驰”。

佛说：“拘翼！这金刚入于重大的功德之中，不能与阿须轮三百三十六万里之身可以投掷相比。拘翼你心中所知如何？须弥山王重不重？”

帝释回答说：“极重，世尊！不可计量譬喻。”

佛说：“拘翼！假使有勇士大神，威力无极，取这金刚，右手执持，把这金刚放在须弥山边，藏在其中只露出一点形状，同时举起这两样东西，须弥山王尚且比金刚还轻。如果，天帝释！密迹金刚力士以这金刚击打铁围山、大铁围山以及金刚山，能令它们碎如微尘。虽然这样，这位正士还没有完全显现他的力量，不可譬喻穷尽。”

【按】本卷相当于异译《如来不思议秘密大乘经》金刚手菩萨大秘密主授记品后分及其后诸品。
