## 富楼那会第十七之二

【按】译者题名，宋、宫本作“姚秦三藏鸠摩罗什译”。会题“之二”，宫本作“之三”。

### 具善根品第四

【按】品次“第四”，宫本作“第七”。

#### 第一法：修行忍辱

那时佛告诉富楼那：“菩萨摩诃萨发起大乘，常当修习亲近四法，便能具摄一切善法，也能具足一切善根。哪四法？富楼那！善男子、善女人发大乘心，修习亲近，行忍辱之法。这样修行忍辱之法时，因为如其心平等，便得平等波罗蜜，也得一切众生平等波罗蜜，这菩萨成就心平等波罗蜜、智平等波罗蜜。

【按】“何等四法”之“法”，宋、元、明、宫本无。

“无论行走、站立、坐着、躺卧，醒着或睡着，有时有人前来，或拿着屎瓶，或拿着毒瓶，或拿着盛沸汤的瓶，或种种垃圾，或拿着火炭，或拿着屎尿，或拿着热灰，捶打他的头上，或捶打他的身体，菩萨对此不应瞋恨，令心散乱而生忿恚，不应自己说‘我有什么罪’，又不应以恶心看对方，只应一心求自利之法，对所修之事专心不舍。应当这样调伏其心：‘此人因为什么因缘，拿这屎瓶、毒瓶、灰、火来加在我身上？我的身体并不因为这些东西的因缘而得痛恼。’菩萨这时应当这样观察众因缘法：是谁给予这东西？这东西与谁相异？以什么东西给予？此人这样如实思惟，不见有法是给予者，谁是领受者，什么是法。这样以正念思惟观察时，因为此与彼都不可得，一切诸法都不可得，都不可见。这菩萨因为不得、不见一切法，所以不生瞋恨。

【按】“搥其头上”之“搥”，明本作“塠”。“此物异谁”之“异”，宋、元、明、宫本作“与”。

“富楼那！若菩萨这样思惟，仍有瞋恨心生起，又应当这样以正念思惟：‘是什么触的因缘使我身体疼痛？这些触是触在何处？是在身上，还是在心上？若在身上，身如草木、瓦石、影像，无觉无知，非我非彼。若在心上，心无形色，念念生灭，须臾不住，非我非彼。只是以虚妄的忆想分别，说这是苦、是乐、是不苦不乐。我现在不应生起这虚妄的忆想分别，我现在应当观察平等的实相，我当修习贤圣所作的，不应随逐凡夫所作的。什么是贤圣所作的？就是对诸法远离而解脱。我为远离而学，不为和合而学。这样的虚妄忆想分别都是和合。与谁和合？是与贪欲和合，是与瞋恚、愚痴和合。什么叫作与贪欲、瞋恚、愚痴和合？因为对身愚痴，因为身见的愚痴，因为贪著身见，身受苦时瞋恚他人，这名为与瞋恚和合。有因为身见的愚痴，因为贪著身见，因为不随己意而瞋恚他人，这名为与愚痴和合。若人这样被三毒所缚，或生起这样的罪业因缘，诸佛都不能救，何况其余的人。我应当善于观察诸因缘法，观察空法。’

“菩萨这样随顺正观诸因缘法，不见有法是谁给予、谁领受、以什么东西给予。那时菩萨应当这样想：‘一切诸法从众缘生，自性本空，决定不可得。我怎能在无所得的虚妄法中，执得为法而作业，生起瞋恚，起行因缘？我现在应当生起无瞋恨之心，修行无作、无起、无生之法，应当观察空法，不随顺我心。我现在应当观察不作、不起、无生之法，不应依止起作之法。我应当如实思惟诸法，我现在不应在这虚妄无所有之中勉强作法，虚妄勉强作法，就是指瞋恨。为什么呢？依止法的本体便有瞋恨，在诸法实相毕竟空中，没有法的本体可以依止。’菩萨这样思惟诸法，其心寂然，瞋恨不起。

【按】“我今应观”之“今”，宋、元、明、宫、圣本作“念”。

“又，这菩萨无论行走、站立、坐着、躺卧，醒着或睡着，有时有人前来，以好的美香、末香、涂香，以好的名花散在他身上，或以上妙的香花璎珞、瞻卜花鬘、婆梨师花鬘、众花璎珞覆盖其身，或以上妙细软的衣服，就是加尸衣、拘摄衣、拘珍婆衣、憍施耶衣、刍摩衣、劫贝衣、细钦婆罗、细缯衣，以这样等柔软细衣覆盖其身。或以上妙的缯盖幢幡张设在其上方，或以诸天的名花、香妙之衣、珍宝璎珞覆盖其身，或以天上甘美的饮食进奉给他。菩萨对这种种供养，不应生起爱心，令心贪著，不因这缘故亲附其人。随顺其意，往来问讯，不应偏心而生起爱著。菩萨对此应以平等之心，通达一切诸法平等，应当这样想：‘我对众生不应瞋恨，不应爱念。为什么呢？憎与爱二事都是烦恼。我现在于此不应生爱，应当善于通达诸法的如实。为什么呢？在诸烦恼中，由爱缘所和合的这种最为深重。这样的烦恼深透骨髓，就是在能生结使的法中爱心染著。为什么呢？所贪著之事若不随意，便生瞋恨。人都自己贪爱其身，有侵扰的便生瞋恨。所以应当知道，瞋恚是染爱的果报，贪著是愚痴的果报。我现在应当远离染爱的恶心，对诸法无所贪著。我们不为贪欲而学，不为瞋恚而学，不为愚痴而学，我当广学诸法的真实，对诸法之相如实观察，随所宣说的如实而行。只应依止业报因缘，对于种种供养与苦恼之事，应当知道都是宿世业行的因缘，所以对随顺之法不生喜爱，对违逆之法不生瞋恨，只应清净其心，无所忿恚，不令随爱、随瞋、随痴的恶法在心中生起。’富楼那！菩萨成就这第一法，能得具足一切功德。”那时世尊想阐明此义，说偈道：

【按】“瓔珞”，明本作“缨珞”，圣、圣乙本作“缨络”。“瞻卜”之“瞻”，《大正藏》作“胆”，明本作“薝”，今依CBETA（所录高丽藏）作“瞻”。“能生结使”之“生”，圣乙本作“告”。“我等不为”之“不”，圣乙本无。

```
我常赞智慧，亦赞持戒者，
称扬行忍辱，亦常赞多闻。
我赞行善法，慈心爱语者，
为饶益众生，随宜赞众德。
我常诃五欲，瞋恨愚痴人，
嫉妬慢谄曲，浊乱娆众生。
懈怠嬾惰心，𢤱戾难与语，
背恩无反复，小事发大恚。
贪求于利养，我当得利养，
不欲令人得，是等我不赞。
小智于利养，自欲嫉彼得，
于他家生苦，是等我不赞。
为求得利养，转易威仪行，
此命非清净，离我法甚远。
不修行道者，有此诸过咎，
是等恶道缘，无一事可赞。
不断恶我见，贪爱心则多，
贪爱心多故，勤求于利养。
```
（大意：我常称赞智慧，也称赞持戒的人，称扬修行忍辱，也常称赞多闻。我称赞修行善法、慈心爱语的人，为了饶益众生，随宜称赞众德。我常呵责五欲，以及瞋恨愚痴之人，嫉妒、傲慢、谄曲，浊乱扰恼众生的人；懈怠懒惰之心，刚愎乖戾、难以与之交谈，背恩而不知回报，因小事而发大怒的人。贪求利养，“我应当得到利养”，不想让别人得到，这些人我不称赞。小智之人对于利养，自己想得而嫉妒别人得到，在他人之家生起苦恼，这些人我不称赞。为求得利养，改变威仪与行止，这样的活命不清净，离我的法甚远。不修行道的人，有这些过失，这些是恶道之缘，没有一件事可以称赞。不断除邪恶的我见，贪爱之心便多，因为贪爱之心多，便勤求利养。）

【按】“嫉妬”之“嫉”，圣、圣乙本作“疾”。“𢤱”字先前电子文本未能显示，今据CBETA（所录高丽藏）补出，《大正藏》作“儱”；“𢤱戾”即刚愎乖戾。

```
菩萨作是念：行忍益众生，
摧伏刚强心，疾得成佛道。
我当行慈心，忍辱愍众生，
而知诸法空，从缘无所属。
何缘有诸法？是法兴于心，
妄想生瞋恚，不念则皆空。
妄想生三界，相续身不绝，
不分别妄想，则无如是过。
常思量诸法，知皆从缘生，
常观诸法空，而能度一切。
离戒苦众生，憍慢所伤害，
为说灭苦法，多有所饶益。
```
（大意：菩萨这样想：“修行忍辱，饶益众生，摧伏刚强之心，迅速成就佛道。我当修行慈心，以忍辱怜愍众生，而了知诸法是空，从缘而生，无所属。诸法从何缘而有？这法生于心，由妄想生起瞋恚，若不忆念便都是空。妄想生起三界，相续不断地受身，若不分别妄想，便没有这样的过失。”常思量诸法，知道都从缘而生，常观诸法是空，而能度化一切。对离开戒律而受苦的众生、被憍慢所伤害的人，为他们宣说灭苦之法，多有所饶益。）

```
若人从东来，南西北四维，
执持屎毒瓶，以搥其头上。
我不生瞋心，谁与谁受者？
何法名为我？观以勤精进。
不恶色视彼，何罪而见加，
但发坚强思，慈心覆于彼。
知是宿业缘，今受此果报，
偿已更不作，安住佛道中。
余人无有此，轻毁苦恼事，
此必是业缘，虽久而不失。
众生在世间，常起善恶业，
我今受此苦，当知是业缘。
若还以恶报，后复受苦果，
宁可以恶事，而加于彼人。
当求无上法，求已为人说，
度脱众生类，一切诸苦恼。
```
（大意：若有人从东方而来，或从南、西、北、四维而来，拿着屎瓶、毒瓶，捶打我的头上，我不生瞋心：谁是给予者？谁是领受者？什么法名为我？以此观察而勤行精进。不以恶意的脸色看对方：“我有什么罪而被加害？”只发起坚强的思惟，以慈心覆护对方。知道这是宿业之缘，现在受这果报，偿还之后便不再作，安住于佛道之中。别人没有遭受这样的轻毁苦恼之事，这必定是业缘，虽然久远也不会消失。众生在世间，常起善恶之业，我现在受这苦，应当知道是业缘。若还以恶相报，以后又要受苦果，怎能把恶事加在对方身上？应当求无上之法，求得之后为人宣说，度脱众生的一切苦恼。）

【按】“屎毒瓶”之“瓶”，明本作“缾”。

```
若人以香花，璎珞供养我，
不应生爱心，当习平等观。
憎爱则非道，常应行舍心，
当正观诸法，谁与谁受者？
空与空受耶？内空外亦空，
空无与无受，一切皆无我。
空无有贪离，空无有烦恼，
亦无有清净，离垢净是空。
空中无分别，空中无诸性，
空常空无相，是比清净道。
若使有人来，段段解我身，
于中不生恚，知从业缘有。
众生起善恶，随业自受果，
我必先世恶，今受此苦报。
今受此恶报，观身如影像，
水沫幻化炎，无空毕竟空。
```
（大意：若有人以香花、璎珞供养我，不应生起爱心，应当修习平等之观。憎与爱都不是道，常应修行舍心，应当正观诸法：谁是给予者？谁是领受者？是空领受空吗？内是空，外也是空，空中没有给予，也没有领受，一切都无我。空中没有贪也没有离，空中没有烦恼，也没有清净，离垢清净也是空。空中没有分别，空中没有诸性，空常是空，无相，这是清净之道。若有人来，一段一段地支解我的身体，我在其中不生瞋恚，知道这是从业缘而有。众生生起善恶，随其业自受果报，我必定是先世作恶，现在受这苦报。现在受这恶报，观身如影像、水沫、幻化、阳焰，“无空毕竟空”一句存疑。）

【按】“璎珞”之“璎”，圣乙本作“缨”。“影像”之“像”，圣本作“象”。

```
若人支解身，有人将养我，
当念报恩者，不以为欢喜。
利养不以喜，恶骂不瞋恨，
二皆是障碍，非佛正真道。
当离诸一切，贪爱瞋恚心，
常当修空寂，悉断诸障碍。
忍辱十力本，诸佛神通原，
无碍智大悲，皆以忍为本。
四谛念正勤，根力觉道分，
皆以忍为本，何智不修忍？
我于波罗奈，转无上法轮，
亦以忍为本，诸佛常赞忍。
汝等亦应修，空忍无生灭，
诸法相常尔，乃得佛功德。
```
（大意：若有人支解我身，或有人供养我，对供养者当念为应报恩的人，却不因此而欢喜。得利养不因此而喜，被恶骂也不瞋恨，这二者都是障碍，不是佛的正真之道。应当远离一切贪爱与瞋恚之心，常当修习空寂，断除一切障碍。忍辱是十力的根本，是诸佛神通的源头，无碍智与大悲，都以忍为根本。四谛、念处、正勤，根、力、觉支、道分，都以忍为根本，有智慧的人谁不修忍？我在波罗奈转无上法轮，也以忍为根本，诸佛常称赞忍。你们也应当修习空忍与无生灭之忍，诸法之相常常如此，才能得到佛的功德。）

【按】“障碍”之“碍”，圣乙本作“阂”。

#### 第二法：乐于出家

“又，富楼那！菩萨摩诃萨能离开五欲，常乐出家，心随顺出家，趣向出家，不贪著五欲。得以出家之后，远离种种喧闹，远居山林，不失善法。菩萨成就这第二法，便能具足一切功德。”那时世尊以偈颂说：

```
心常乐出家，而能常出家，
常乐在山林，增益功德处。
亲近在空闲，即离五欲著，
此中无众閙，失诸善法缘。
无有诸语言，往来问讯事，
空闲寂然快，诸佛所称赞。
是故诸菩萨，所应常亲近，
勿贪乐聚落，近生利养心。
若得利养喜，失则生忧恼，
此人供养佛，不名为供养。
欲除如是过，当离诸利养，
远离在空闲，修习于空法。
```
（大意：心中常乐出家，又能常常出家，常乐在山林，这是增益功德之处。亲近于空闲之处，便离开对五欲的执著，这里没有众人的喧闹，那是失去善法之缘。没有种种言语与往来问讯之事，空闲寂然而快乐，为诸佛所称赞。所以诸菩萨应当常常亲近，不要贪乐聚落，亲近便生利养之心。若得利养便欢喜，失去便生忧恼，此人供养佛，不名为供养。想除去这样的过失，应当远离种种利养，远离而在空闲之处，修习空法。）

#### 第三法：求法读诵

“又，富楼那！菩萨常学习求法，求得之后读诵，就是求净戒、头陀等细行之法，不求多欲无厌足之法；求灭除贪欲，不求增益贪欲；求破除瞋恚，不求增长瞋恚；求断除愚痴，不求增益愚痴；求破除憍慢，不求生起慢心；求破除我慢，不求增长我慢；求断除我、我所之法，不求增长我、我所之法；求无我之法，不求依止我、人、众生、寿命之法；常求能得大智慧之法，不求退失大智慧之法；常求得无等智慧之法，不求得小智慧之法；求得具足一切诸法，不求不具足诸功德之法。求这样的法，求得之后读诵，思惟正观，如所说而行，为人演说，不求世间利益，乃至不求别人称赞善哉，教导多众生令其安住于此法。富楼那！菩萨成就这第三法，能得具足一切功德。”那时世尊以偈颂说：

【按】“无厌足法”之“足”，圣乙本作“之”。“不益贪欲”之“益”，宫、圣、圣乙本作“然”。

```
菩萨乐出家，持戒行头陀，
以是增智慧，智雨益终流。
得是深净法，正念思其义，
于如所说中，能如所闻行。
常以清净心，为人广解说，
饶益诸众生，心无所悕望。
得诸功德味，自住是法中，
亦令余人住，是故增佛法。
若于无量劫，所集诸功德，
令皆现在前，摄入菩萨道。
故应求深法，佛所称赞者，
常为众生说，功德从是生。
```
（大意：菩萨乐于出家，持戒修行头陀，以此增长智慧，如智慧之雨增益终流（存疑）。得到这深净之法，以正念思惟其义，在如所说之中，能如所闻而行。常以清净之心为人广为解说，饶益众生，心中无所希望。得到诸功德之味，自己安住于此法中，也令其余的人安住，所以增长佛法。若在无量劫中所积集的诸功德，令其都现在前，摄入于菩萨道。所以应当求取深法，佛所称赞的，常为众生宣说，功德由此而生。）

#### 弥楼揵驮佛末法与陀摩尸利王子

```
世间不得底，菩萨而不没，
住于净戒中，广利诸众生。
本事及譬喻，示众以佛道，
诸佛之所说，此是决定法。
菩萨能行利，亦能利众生，
守护诸佛法，教众以菩提。
众生如法事，菩萨皆为作，
教众以佛道，是则近菩提。
护持诸佛道，亦广利众生，
诸天龙鬼神，大人所敬养。
是故闻清净，诸空深妙法，
一心应思求，是则智增长。
```
（大意：菩萨听闻甚深清净决定之法，自身能安住，也教导其余的人。世间不能到底的，菩萨却不沉没，安住于净戒之中，广利众生。以本事以及譬喻，向众生显示佛道，这是诸佛所说的决定之法。菩萨能行利益，也能利益众生，守护诸佛之法，以菩提教导众生。众生的如法之事，菩萨都为他们去作，以佛道教导众生，这便接近菩提。护持诸佛之道，也广利众生，为诸天、龙、鬼神与大人所敬养。所以听闻清净、空寂的深妙之法，应当一心思惟求取，这便使智慧增长。）

【按】“大人所敬养”之“大”，宋、元、明、宫本作“天”。

#### 第四法：具足诸行

“又，富楼那！菩萨摩诃萨具足诸行，因为诸行具足，便能具足善根福德。什么是行？富楼那！菩萨亲近善知识，修行布施、持戒、忍辱、精进、禅定、智慧与方便。什么是菩萨的善知识？菩萨从之听闻这样的经的，以及教化方便的诸佛、阿罗汉，以及以深心求佛道的菩萨，都名为菩萨的善知识。菩萨成就这第四法，便能具足一切功德。”那时世尊以偈颂说：

```
我说诸菩萨，所当应行法，
施已心欢喜，无有诸悔恨。
云何为欢喜？谓乐悉遍身，
常以此喜心，而行菩萨道。
菩萨所布施，回向于菩提，
饶益诸众生，自利无有量。
若见有乞者，心生于佛想，
念是人今来，施遗我佛道。
我因于是人，得净佛国土，
是人示我佛，教化我佛道。
我今值此人，快得大吉利，
欢乐遍满身，更不乐余事。
若有人来诣，遥见而问讯，
仁者须何物？我当尽相与。
```
（大意：我宣说诸菩萨所应当修行之法：布施之后心中欢喜，没有种种悔恨。什么是欢喜？就是乐遍满全身，常以这欢喜之心修行菩萨道。菩萨所作的布施，回向于菩提，饶益众生，自利也无量。若见到有乞求的人，心中生起佛想，想着此人现在前来，赠送给我佛道。我因为此人，得以清净佛国土，此人向我显示佛，教化我以佛道。我现在值遇此人，快速得到大吉利，欢乐遍满全身，更不乐于其他事。）

```
若言无所须，菩萨亦欢喜，
为欲教化我，故言无所须。
此贤以所乐，少欲知足法，
今来开悟我，使得菩提缘。
我今因此人，复得教以法，
汝言无所须，是语为善哉。
若言须此物，以是可与我，
菩萨若有者，欢喜言汝取。
若行布施已，于后无所悔，
以念佛道故，心常得欢喜。
布施已回向，众生皆有分，
普令无所乏，尽使得知足。
若行菩萨道，众生闻我名，
自然知止足，不生悭贪心。
```
（大意：若有人前来，远远见到便问讯：“仁者需要什么东西？我当全部给你。”若说没有需要，菩萨也欢喜：“是为了教化我，所以说没有需要。这位贤者以其所乐的少欲知足之法，今天来开悟我，使我得到菩提之缘。我现在因为此人，又得到以法教导，你说没有需要，这话说得善哉。”若说需要这东西，“可以把这个给我”，菩萨若有，便欢喜地说：“你拿去。”若行布施之后，以后没有悔恨，因为念佛道的缘故，心中常得欢喜。布施之后回向，众生都有一份，普遍令他们无所匮乏，全都令他们知足。若修行菩萨道，众生听闻我的名号，自然知足，不生悭贪之心。）

```
今我国众生，顺道皆知足，
舍诸五欲著，皆乐行出家。
如是无量行，以施而回向，
愿常行布施，众生亦效我。
菩萨行布施，以慈覆众生，
一切诸世间，无有如是乐。
如大富长者，多财饶珍宝，
唯正有一子，积年久远行。
长者闻子还，欢乐遍满身，
久别而今归，便若如更生。
菩萨见乞人，其心大欢喜，
长者欢喜分，十六不及一。
若得施行已，心则大欢喜，
慈心所生乐，此乐无有比。
```
（大意：“将来我国土的众生，都随顺于道而知足，舍弃对五欲的执著，都乐于出家。”这样无量之行，都以布施而回向，愿常行布施，众生也效仿我。菩萨修行布施，以慈心覆护众生，一切世间，没有这样的快乐。如大富长者，多有财物，饶有珍宝，只有一个儿子，远行多年。长者听说儿子回来，欢乐遍满全身，久别而今归来，便如同再生。菩萨见到乞求的人，心中大欢喜，长者的欢喜，不及菩萨欢喜的十六分之一。）

【按】“唯正有一子”之“唯正”，明本作“惟止”。

```
如王治罪人，勅使支节解，
杀者将杀处，举刀垂当下。
王恕赐荣位，是人大欢喜，
犹不及菩萨，施贫得欢乐。
菩萨行道时，不求于福田，
有乞则便与，故得大欢乐。
菩萨若值佛，罗汉辟支佛，
敬心知难遇，故往供养施。
菩萨有威德，明利心调顺，
乐功德求道，供养佛及众。
不以深恭敬，奉事诸天神，
唯除于诸佛，及诸佛弟子。
若有辟支佛，自然得涅槃，
亦行而供养，有是诸功德。
```
（大意：若行布施之后，心中便大欢喜，慈心所生的快乐，这快乐无可比拟。如国王惩治罪人，命令支解其肢节，行刑者带到杀人之处，举起刀刚要落下，国王宽恕，并赐予荣位，此人大欢喜，仍不及菩萨布施贫人所得的欢乐。菩萨行道时，不求福田，有乞求便给予，所以得到大欢乐。菩萨若值遇佛、罗汉、辟支佛，以恭敬心知道难以遇到，所以前往供养布施。菩萨有威德，明利而心调顺，乐于功德而求道，供养佛以及僧众。不以深切的恭敬奉事诸天神，唯除诸佛以及诸佛弟子。若有辟支佛，自然得涅槃，也前往供养，有这些种种功德。）

【按】“施贫得欢乐”之“乐”，宋、元、明、宫本作“喜”。

```
菩萨亦能知，福田善不善，
世间诸智者，不敬恶外道。
安住持戒品，慈心覆众生，
精进无有比，忍智多闻广。
行是诸功德，于世为高尊，
能证佛菩提，转无上法轮。
菩萨能修行，如是上四法，
一切诸善根，悉皆现在前。
无量亿数劫，所修诸功德，
悉皆摄入此，所行菩萨道。
是故诸菩萨，应常修慈心，
出家处山林，乐在空闲处。
常求诸清净，甚深决定法，
具足菩萨行，以此自增长。
```
（大意：菩萨也能了知福田的善与不善，世间的智者，不恭敬邪恶的外道。安住于持戒之品，以慈心覆护众生，精进无可比拟，忍辱、智慧、多闻广大。修行这些功德，在世间成为高尊，能证得佛的菩提，转无上法轮。菩萨能修行这样上妙的四法，一切善根都现在前。在无量亿劫中所修的种种功德，都摄入于此所行的菩萨道。所以诸菩萨应当常修慈心，出家住于山林，乐在空闲之处。常求种种清净、甚深、决定之法，具足菩萨之行，以此自我增长。）

【按】“转无上法轮”之“轮”，明本作“转”。

### 神力品第五

【按】品题“神力品”，宋、元、明、宫本作“神通力品”；品次“第五”，宫本作“第八”。

#### 佛现神力

那时世尊以神通之力，从身上每一个毛孔同时放出百千万亿光明，又从每一个毛孔放出如须弥山那样大的猛烈火焰，又从每一个毛孔现出恒河沙数诸佛说法。那时会中大众普遍见到这样的大神通力。那时世尊示现神力之后，恢复如故，对富楼那说：“你见到如来从诸毛孔现出这样的神力了吗？”“已经见到，世尊！”“富楼那！如来常有这样的神力，没有休止。现在诸弟子只知道如来在这里说法，而我实际上在十方恒河沙等世界常作佛事，没有休息，也在十方世界这样说法。富楼那！若有人说实话，谁是无等等、无可比拟的人？是两足尊、福田，极深难测，无边行者举足一步，一切众生都不能得知，不能思量他以什么心、什么行举足下足，应当说是我。富楼那！一切众生都不能思量如来以什么思、什么心、什么行举足下足。”那时世尊想阐明此义，说偈道：

【按】“还复如故”之“如”，圣、圣乙本作“如是”。“今诸弟子”之“今”，元、明本作“令”。

```
世尊以何思、何行举下足？
动不动众生，常不知此事。
神通力无量，行处亦无量，
功德无量故，第一极高尊，
大神慧无量，无能尽知者。
假令一切人，智慧神通力，
皆如舍利弗，及与目揵连，
亦不能知我，举足下足事。
正使一切人，皆作辟支佛，
```
（大意：世尊以什么思、什么行举足下足？动与不动的众生，常常不知这件事。神通之力无量，所行之处也无量，因为功德无量，所以是第一、极高的尊者，大神通与智慧无量，没有人能完全了知。假使一切人的智慧与神通之力，都如舍利弗以及目犍连，也不能了知我举足下足之事。即使一切人都作辟支佛，也不知道我的一步，何况其余的甚深佛法。）

【按】“大神慧无量”之“神”，宋、元、明、宫、圣、圣乙本作“智”。“世尊以何思、何行举下足”一句十字，原文如此。

```
不知我一步，况余深佛法。
假无量日月，合为一日轮，
不能及如来，一毛孔光明。
假使七万亿，那由他世界，
日轮纵广等，遍照无量土。
如是诸大日，如十方恒沙，
合以为一日，一光如须弥。
如是诸大日，常照十方界，
比于佛光明，不现如焦树。
是诸大日光，不能彻树叶，
诸山河石壁，皆悉能障碍。
如来光所照，一切须弥山，
铁围金刚山，彻过无有障。
光明神通力，威德无有量，
谁见不发心？唯除于不信。
众生见如是，光明大神力，
```
（大意：假使无量日月合成一个日轮，也不能及如来一个毛孔的光明。假使七万亿那由他世界，日轮纵广与之相等，遍照无量国土。像这样的大日，如十方恒河沙数，合为一个太阳，一道光明如须弥山。像这样的大日常照十方世界，与佛的光明相比，显现不出来，如同焦枯的树。这些大日的光明，不能穿透树叶，种种山河石壁都能障碍它。如来光明所照之处，一切须弥山、铁围山、金刚山，都能穿透而过，没有障碍。光明与神通之力，威德无量，谁见了不发心？唯除不信的人。众生见到这样的光明与大神力，多发无上之心：“我们也当得到。”）

```
多发无上心，我等亦当得。
时佛则微笑，阿难即问讯：
世尊何故笑？无碍智愿答。
时佛答阿难：众生今见我，
所现大神力，发心愿作佛。
众中三万人，愿护持是法：
我等于佛后，赞诵如是经。
是人我灭后，得闻是经法，
中时及后时，闻已如说行。
发道心者难，深乐佛法难，
后世能持诵，是等经复难。
千万亿数劫，诸佛出甚难，
于后末世中，说是经复难。
```
（大意：那时佛便微笑，阿难便问讯：“世尊为什么笑？具无碍智者，愿为回答。”那时佛回答阿难：“众生现在见到我所现的大神力，发心愿作佛。”众中有三万人，愿护持此法：“我们在佛灭度后，赞叹诵持这样的经。”“这些人在我灭度后，得以听闻此经法，在中时以及后时，听后如所说而行。发道心的人难得，深乐佛法难得，后世能持诵这样的经，又更难得。在千万亿劫中，诸佛出世甚为难得，在后来的末世中，宣说此经又更难得。”）

#### 嘱累阿难与第一供养

那时佛告诉阿难：“我以这样等经再三嘱累于你。为什么呢？阎浮提内，凡有这样的菩萨藏经，便有佛法。阿难！这样等深经灭亡，如所说而行之法也就灭亡。如所说而行之法灭亡，佛法便灭亡。阿难！你现在应当以第一供具供养我。怎样作为弟子以第一供具供养我？你心中不要以为名花、好香、末香、涂香、幡盖、璎珞、衣服、伎乐、赞叹如来是上等的供养。阿难！这样不名为第一供养。若人得以听闻这样等深经，受持读诵，如所说而行，这名为以第一供具供养、恭敬、尊重、赞叹佛。为什么呢？诸佛都共同供养、恭敬、尊重于法，不看重世间的种种供具。所以阿难！现在以此经郑重殷勤地嘱累于你。

【按】“汝心勿谓”之“汝”，北藏作“法”。“妓乐”之“妓”，宋、宫本作“伎”。

“为什么呢？阿难！我学习这样等经，现今得阿耨多罗三藐三菩提，转无上法轮。过去诸佛本来行菩萨道时，也学习这样等经，得阿耨多罗三藐三菩提，转无上法轮。未来诸佛也学习这样等经，当得阿耨多罗三藐三菩提，转无上法轮。现在十方世界诸佛本来行菩萨道时，也学习这样等经，得阿耨多罗三藐三菩提，现今转法轮。所以阿难！这菩萨藏经，名为‘转法轮经’，应当奉持。我在波罗奈国梨师山鹿园中，为声闻弟子转法轮。阿难！我现在在这竹园中，转这菩萨藏经的不退转法轮，断一切众生的疑惑。

#### 竹园不共功德

“阿难！过去诸佛也都在这虚空地分宣说这菩萨藏经，未来诸佛也都将在这虚空地分宣说这菩萨藏经，我现今得阿耨多罗三藐三菩提，也在这虚空地分宣说这菩萨藏经。所以应当知道，此地是佛的大塔，是天人世间所供养之处。阿难！此地独有不与他处相共的功德，就是过去诸佛在这里宣说种种深经。阿难！所有贪欲、瞋恚、愚痴的众生，进入这竹园便不起贪欲、瞋恚、愚痴。阿难！如来虽然也住在其余的精舍，却都没有这样的功德。为什么呢？阿难！现在这迦兰陀竹林，畜生进来不起淫欲，众鸟进来不在非时鸣叫。

“摩竭国洴沙灌顶大王当初登位时，与众婇女进入这园中共相娱乐。进来后自己觉察到，心中没有淫欲与娱乐嬉戏之事。众婇女也都自己觉察到，心中没有欲望，不乐于嬉戏娱乐。那时国王欢喜，常常这样想：‘愿世间有佛出现在我国，我当得以见到。见到之后心生信仰。信仰之后加以供养。当以这园奉献给佛。佛住在其中。我当听闻佛法。为什么呢？可受供养的人应住在这园中，不是五欲之人所应住的。’阿难！洴沙王进入这竹园，生起这样的善心，都是因为过去诸佛住在这园中宣说这菩萨藏经。所以此园所有的功德不与其余之处相共，一切世间的天、人、阿修罗都应当礼敬。阿难！这园中没有毒蛇、蜈蚣、蚊虻等毒螫之物，若住在其中，便不再有毒害之心，这也是竹园不共的功德。我若用一百年称说此园所有的功德，仍不能说尽。为什么呢？阿难！现在这竹园精舍成就无量功德，其余之处不是这样。”

【按】“婇女”之“婇”，圣、圣乙本作“綵”。“入此园中”之“园”，圣本作“国”；“住此园中”之“园”，圣乙本作“国”。“诸婬女众”之“婬”，元、明本作“婇”，译文依此。“虺蛇”之“虺”，宋、元、明、宫本作“蚖”。

阿难对佛说：“我本来不知道竹园竟有这样的功德。世尊！我本来不想作佛的侍者。我现在忏悔谢罪这样的过失。”佛告诉阿难：“你初次于法得到法眼净时，那时已经为你除灭了这罪。”
