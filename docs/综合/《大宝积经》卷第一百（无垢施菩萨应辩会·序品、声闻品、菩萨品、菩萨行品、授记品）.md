# 《大宝积经》卷第一百（无垢施菩萨应辩会·序品、声闻品、菩萨品、菩萨行品、授记品）

西晋·居士聂道真 译

## 无垢施菩萨应辩会第三十三

【按】译者题名“居士聂道真”，宋、元、明、宫本作“清信士聂道真”，圣本作“三藏竺法护”。本会异译有西晋竺法护译《离垢施女经》（T0338）、元魏瞿昙般若流支译《得无垢女经》（T0339），“离垢施”“无垢”即无垢施。

### 序品第一

#### 八大声闻、八大菩萨入城之愿

如是我闻：一时，佛游化于舍卫国祇树给孤独园，与大比丘众一千人在一起，都是阿罗汉，诸漏已尽，不再有烦恼，于诸法中都得自在，所作已办，舍弃重担，获得自利，尽除诸有的结缚，得正智解脱，心得善解脱，慧得善解脱，其心调伏如大象王，心得自在，到达彼岸，入于八解脱；只除阿难一人。又有诸菩萨摩诃萨，都有大庄严，为众人所知识，得不退转，都是一生补处。他们的名字是：宝手菩萨、德藏菩萨、慧严菩萨、称意菩萨、观世音菩萨、文殊师利法王子、悦音法王子、不思议解脱行法王子、思惟诸法无障碍法王子、弥勒菩萨、施无忧菩萨、无痴见菩萨、离恶趣菩萨、无碍行菩萨、断幽冥菩萨、除诸盖菩萨、辩严菩萨、宝德智威菩萨、金花光明德菩萨、思无碍菩萨，这样等菩萨摩诃萨一万二千人在一起。

【按】“无碍行菩萨”之“碍”，宋、元、明、宫本作“痴”，与下文“无痴行菩萨”相合。

那时大德舍利弗、大德目犍连、大德摩诃迦叶、大德须菩提、大德富楼那弥多罗尼子、大德离越、大德阿那律、大德阿难，以及文殊师利法王子、无痴见菩萨、宝相菩萨、离恶趣菩萨、除诸盖菩萨、观世音菩萨、辩严菩萨、无痴行菩萨，这样等八大菩萨以及八大声闻，在早晨执持衣钵，想进入舍卫城乞食。当时在道路中，各自这样想，共同议论这件事。

【按】“目犍连”之“犍”，宫本作“揵”，下同。

那时大德舍利弗说：“我当入于这样的定之后，前往舍卫城乞食，愿令城中一切众生听闻四圣谛。”大德目犍连说：“我当入于这样的定，前往舍卫城乞食，愿令城中一切众生没有魔事。”摩诃迦叶说：“我当入于这样的定，前往舍卫城乞食，愿令城中布施给我的众生获得无尽的果报，乃至泥洹。”大德须菩提说：“我当入于这样的定，前往舍卫城乞食，愿城中见到我的众生，以这因缘，令那些众生在天上人中受种种快乐，得以穷尽苦的边际。”大德富楼那弥多罗尼子说：“我当入于这样的定，前往舍卫城乞食，愿令城中一切外道梵志、尼揵子等都得正见。”大德离越说：“我当入于这样的定，前往舍卫城乞食，愿令城中一切众生得无诤之乐。”大德阿那律说：“我当入于这样的定，前往舍卫城乞食，愿令城中一切众生了识宿世的业报。”大德阿难说：“我当入于这样的定，前往舍卫城乞食，愿令城中一切众生先前所闻之法都现前。”

【按】“诣舍卫城”之“诣”，《大正藏》作“脱”，今依CBETA作“诣”。“舍卫城乞食”之“城”，宫本无。

文殊师利法王子这样想：“我当令舍卫城中一切门户、窗牖、墙壁、器物、树木枝叶花果、衣服璎珞，都发出空、无相、无愿、无所有、无我、无戏论、无性之声。”无痴见菩萨这样想：“我当令舍卫城中若有众生应得阿耨多罗三藐三菩提的，他们所见之物都是如来之像，又令他们对阿耨多罗三藐三菩提得以决定。”宝相菩萨这样想：“我当令舍卫城中一切族姓的室宅之中，宝藏涌出，具足七宝。”离恶趣菩萨这样想：“我当令舍卫城中若有众生应堕恶趣的，都使他们在现世轻受而迅速脱离苦恼。”除诸盖菩萨这样想：“我当令舍卫城中众生全部除去五盖。”观世音菩萨这样想：“我当令舍卫城中众生，被关在牢狱中的迅速得到解脱，临当处死的即得保全性命，恐怖的人即得无畏。”辩严菩萨这样想：“我当令舍卫城中见到我的众生都得辞辩，以种种妙偈互相问答。”无痴行菩萨这样想：“我当令舍卫城中若有众生见到我的，得无痴之见，对阿耨多罗三藐三菩提得以决定。”这样等八大菩萨以及八大声闻共同议论上述之事，便到了舍卫城门。

【按】“宝相菩萨”之“宝”，宫本作“实”。“宝藏勇出”之“勇”，元、明本作“湧”。“速脱苦恼”之“苦”，宫本作“若”。“得无痴见”之“痴”，宫本作“疑”。

#### 无垢施女与梵志偈答

那时城内波斯匿王的女儿，名为无垢施，年方八岁，颜貌端严，世所希有。那女孩在二月八日沸星出现之日，与五百位婆罗门一起，拿着满瓶的水出到城外洗浴天神之像。那时五百位婆罗门见到诸比丘站在城门外，见后都认为不吉。当时婆罗门众中最年长的一位，一百二十岁，名为梵天，对无垢施女说：“现在诸比丘站在城门外。这事不吉，我们应当回到城里，不必见他们。若见了他们，对祭祀所宜的利益吉祥等事都不吉利。”

【按】“佛星”之“佛”，元、明、宫本、圣本作“沸”，原有夹注“丹本沸”；“沸星”即鬼宿。“皆为不吉”之“为”，宋、元、明、宫本作“谓”。

那时无垢施女以偈回答婆罗门说：

```
此等皆无受，第一所应赞，
能为多众生，洗除一切恶。
此等皆清净，尽见四圣谛，
外道非清净，为痴冥所覆。
两足尊福田，施此报无量，
种于此中者，于三有无尽。
戒行净具足，出淤泥无著，
行世如良医，治救病众生。
佛为世中胜，是诸法之王，
此等是佛子，成办阿罗汉。
如是行菩萨，慧人云何离？
行此妙行者，世人所应赞。
此等是慧人，久远常行施，
梵志敬此者，众事吉无疑。
赞此具相者，心净良福田，
梵志若信者，得喜无忧乐。
```
（大意：这些人都没有执受，是第一应受赞叹的，能为众多众生洗除一切恶。这些人都清净，都已见到四圣谛；外道不清净，被愚痴黑暗所覆。他们是两足尊的福田，布施他们果报无量，在这福田中种植的人，于三有之中福报无尽。他们戒行清净具足，出于淤泥而无染著，行于世间如良医，救治有病的众生。佛是世间最胜者，是诸法之王；这些人是佛子，成就阿罗汉。这样修行的菩萨，有智慧的人怎能远离？行这妙行的人，是世人所应赞叹的。这些人是智者，久远以来常行布施；梵志若恭敬他们，种种事都吉利，没有疑问。赞叹这些具足相好的人，他们心净，是良好的福田；梵志若信他们，便得欢喜，没有忧愁而得安乐。）

【按】“此等皆无受”之“受”，宋、元、明、宫本、圣本作“爱”。“成办”之“办”，宫本作“辨”。

那时梵志又以偈回答无垢施女说：

```
勿随愚小心，祠莫见沙门，
剃发被袈裟，求乐者莫近。
汝父母不喜，我等怀惭愧，
汝若欲行施，其事亦不吉。
善哉勿恭敬，此等诸比丘。
```
（大意：不要随顺愚小之心，祭祀时不要见沙门；剃发披袈裟的人，求快乐的人不要接近。你的父母不会喜欢，我们心怀惭愧；你若想行布施，这事也不吉利。善哉，不要恭敬这些比丘。）

那时无垢施女以偈回答梵志说：

【按】“报梵志言”之“言”，宋、元、明、宫本无。

```
我若堕恶道，父母诸眷属，
财宝及勇健，尽所不能救；
除彼威德众，谁能救我者。
敬佛法众故，舍身及寿命，
除尊三宝已，更无可依道。
```
（大意：我若堕入恶道，父母与诸眷属、财宝以及勇健之力，都不能救我；除了那有威德的僧众，谁能救我？为了恭敬佛、法、僧，我能舍弃身体与寿命；除了尊贵的三宝，再没有可依止之道。）

#### 无垢施女说天子赞佛

那时梵志问无垢施女说：“你未曾见过佛以及僧，也未曾听闻佛法，从哪里有这样的信心？”无垢施女回答梵志说：“我初生七日时，处在高殿之上的金足床上，见到五百天子飞行于虚空，以无量功德赞叹佛、法、僧，我当时得以听闻。又有一位天子，未曾见佛、闻法以及见到众僧，问诸天子说：‘佛是什么样子？’那些天子知道我至诚之心，一并回答那位天子所问，为了令他生起喜悦，而说偈道：

```
其发如绀青，清净而右旋，
佛面如满月，百叶莲花色，
毫相如珂雪，右旋人乐观，
黑蜂遶青莲，眉目亦如是。
颊车如师子，眼眴如牛王，
唇如频婆果，齿白密齐平，
其发如鹅行，舌广而覆面，
畅音甚清净，闻者皆欢喜。
孔雀鹅鴈声，音如琉璃琴，
紧那众铃声，迦陵频伽音，
拘那罗鸟音，命命拘吉罗，
及种种音乐，佛声亦如是。
其吼如师子，能破诸竞论，
除去诸垢恼，实语断诸见。
处在于大众，能尽诸问疑，
不谬而和柔，悦可于众心。
去离于二边，正说于中道，
恒说适意音，闻音皆欢喜。
口行无谄曲，随语各得解，
佛语慧庄严，如杂妙花鬘。
项圆臂修直，掌平轮相净，
手指纤长妙，爪如赤铜色。
佛身坚平满，细腰师子体，
深齐而圆好，阴藏如马王。
其身如金山，一孔一毛生，
右旋而上向，其喻如龙象。
𦟛髀鹿𨄔肠，踝平钩锁骨，
足平轮相现，千辐具分明。
```
（大意：佛的头发如绀青色，清净而右旋；佛面如满月，如百叶莲花之色；白毫之相如珂贝、白雪，右旋而令人乐观；如黑蜂绕着青莲，佛的眉目也是这样。佛的颊车如狮子，眼睫如牛王，唇如频婆果，牙齿洁白，密致齐平；行步犹如白鹅，舌头广长，能覆盖面部；音声畅达，甚为清净，听者都欢喜。如孔雀、鹅、雁之声，音如琉璃琴，如紧那罗众与铃声，如迦陵频伽之音，如拘那罗鸟、命命鸟、拘吉罗鸟之音，以及种种音乐，佛的声音也是这样。佛吼如狮子，能破种种竞论，除去种种垢恼，以实语断除诸见。处在大众之中，能尽解种种疑问，不谬而和柔，悦可大众之心。远离二边，正说中道，恒常说适意之音，听闻者都欢喜。口所行没有谄曲，随其所说各得理解；佛语以智慧庄严，如杂妙花鬘。颈项圆满，手臂修直，手掌平整，有清净轮相；手指纤长美妙，指甲如赤铜之色。佛身坚实平满，细腰如狮子之体，肚脐深而圆好，阴藏如马王。其身如金山，一孔生一毛，右旋而向上，其譬喻如龙象。髀骨均直，小腿如鹿王之腨，脚踝平整，骨如钩锁相连；足底平整，现出轮相，千辐都具足分明。）

【按】“乐观”之“观”，元、明本作“覩”。“其发如鹅行”，宋、元、明、宫本、圣本“发”作“犹”，宋、元、明、宫本“如”作“白”，即“其犹白鹅行”，今依此译。“皆欢喜”之“喜”，圣本作“悦”。“𦟛”字先前电子文本未能显示，今据CBETA补出，同“傭”，即均直；“𨄔”字，《大正藏》作“𬧅”，今依CBETA作“𨄔”，即腨，小腿肚。“钩锁”之“锁”，宋、宫本作“瑣”，圣本作“琑”。

“梵志！那时诸天子在虚空中，以这样的事赞叹如来。再者，如来、应供度一切有而到达彼岸，得大慈悲，如大医王护持众生。憎与爱都不能染著，如莲花在水中。对于世尊的功德，我只赞叹了少分。梵志！我生下才七天，听闻世尊这样真实的功德，从那以后恒常没有睡眠，也没有欲觉、瞋恚觉、恼害觉。从那以后，我对父母、兄弟、姊妹、亲属、财宝、璎珞、衣服、城邑、园林以及自己的身体寿命，都没有恋爱之心，只是念佛。如来在在处处有所说法，我都系心前往听闻，全部受持，无论文句或义理，一句也不失。梵志！我在日夜之中未曾不见诸佛世尊。梵志！我观佛无厌，听法无足，供养僧众无倦。”

那时无垢施女这样以种种方式赞叹佛、法、僧。当时梵天婆罗门等五百人都发阿耨多罗三藐三菩提心。

#### 无垢施女请法，父王问忧

当时无垢施女便下车步行，前往诸菩萨、声闻之所。到了之后，一一顶礼他们的足，以恭敬尊重之心前往大德舍利弗之所。到了之后站在他面前，对舍利弗说：“我是女人，智慧微浅，多有烦恼，又多放逸，乐于卑下之事，被不正的思惟所牵引。善哉大德舍利弗！为了怜愍我，请宣说微妙之法。我听闻之后，在长夜中得到利益，增长安乐。”

刚开始议论这件事，波斯匿王来到她那里。听了她所说的话，王对无垢施女说：“你种种快乐都不缺少，为什么面带忧色而不睡眠、不乐世间之乐？”当时波斯匿王便为他的女儿说偈道：

```
端严如天女，澡浴涂香服，
璎珞等具足，何忧不睡眠？
国富多财宝，父母得自由，
有何不可乐，而不睡眠耶？
汝悦众亲意，诸人悉敬望，
我种种庄严，汝何为不乐？
汝见闻何事，而怀此忧戚？
善哉何所愿？汝语我此事。
```
（大意：你端严如天女，洗浴、涂香、穿著好衣，璎珞等都具足，有什么忧愁而不睡眠？国家富足，多有财宝，父母都能自由行事，有什么不可乐的，而不睡眠呢？你令众亲属心悦，众人都敬仰你，我以种种庄严给你，你为什么不乐？你见到或听到了什么事，而怀着这样的忧戚？你有什么愿望？请把这事告诉我。）

那时无垢施女以偈回答父王说：

```
王不觉家中，阴界入诸羸，
居世如幻妓，人命无暂停。
饮毒谁能眠？处死谁有欢？
坠岩何望活？世相皆如是。
如人处蛇间，何有睡与欲？
四大如毒蛇，何有欢乐心？
为诸怨所遶，如饥何有乐？
为诸怨国者，父王何有乐？
自从见世尊，发心愿成佛，
王我未见闻，菩萨暂放逸。
```
（大意：王不觉察，这身家之中，阴、界、入都是羸弱的；住在世间如幻化的伎人，人命没有片刻停留。喝了毒药，谁能睡得着？身处死地，谁还有欢乐？坠落山崖，怎能指望活命？世间之相都是这样。如人处在毒蛇之间，哪有睡眠与欲乐？四大如毒蛇，哪有欢乐之心？被种种怨敌所围绕，如饥饿之人哪有快乐？被种种怨国所围困的人，父王，哪有快乐？自从见到世尊，我便发心愿成佛；王，我从未见过或听说菩萨有片刻放逸。）

【按】“幻妓”之“妓”，元、明本作“技”。

### 声闻品第二

#### 问舍利弗智慧

那时无垢施女对舍利弗说：“大德！我想稍有所问，愿为解说，以怜愍之故。世尊授记仁者在智慧中最为第一。这智慧是有为呢？还是无为呢？若是有为，便是虚诳不实之法。若是无为，无为之法便没有生，无生之法便没有起。因为没有起，大德的智慧便无所有。”舍利弗便默然。

【按】“愿为解说”之“说”，《大正藏》作“脱”，今依CBETA（所录高丽藏）作“说”，宫本同。

#### 问目犍连神足

大德目犍连对舍利弗说：“大德！为什么不回答无垢施女所问？”舍利弗回答目犍连说：“这女孩不是问有为之法，而是问第一义谛。第一义中没有言说，所以不可以用言语回答。”当时无垢施女对目犍连说：“世尊授记大德在神足人中最为第一。大德乘神足时，是作众生想呢？还是作法想呢？若住于众生想，众生不实，那神足也不实。若住于法想，法没有变异，若没有变异便无所得，若无所得便没有分别。”大德目犍连便默然。

#### 问迦叶受施报恩

摩诃迦叶对目犍连说：“大德！为什么不回答无垢施女所问？”目犍连说：“这女孩不是问分别神足。诸如来的菩提无作、无分别，这便不可言说。”当时无垢施女对摩诃迦叶说：“世尊授记大德在头陀人中最为第一。又，大德为了怜愍众生，入八解脱之后才受布施，乃至一念之间受他人布施，是以身来报答呢？还是以心来报答呢？若以身来报答，身性是无记，譬如草木、墙壁、瓦砾等没有不同，所以不能必定报答施恩。若以心来报答，心念念不停，也不能报答。若除去身心，便是无为法。若是无为法，谁能报答？”摩诃迦叶便默然。

#### 问须菩提无诤

大德须菩提对摩诃迦叶说：“为什么不回答无垢施女所问？”摩诃迦叶回答须菩提说：“这女孩所问的，是问法的真际。这道理不可以用言语宣说回答。”当时无垢施女对须菩提说：“世尊授记大德在无诤人中最为第一。这无诤行，是入于有性呢？还是入于如性呢？若入于如性，如非生相，如非灭相。若非生相、非灭相，便是平等；若是平等，便是如尔；若是如尔，便是无作；若是无作，便没有言说；若没有言说，便不可思议；若不可思议，便不可宣示表达。若在有性，有性是虚诳的。若是虚诳，便不是圣者所行。”大德须菩提便默然。

【按】“若是虚诳”之“是”，《大正藏》作“见”，今依CBETA（所录高丽藏）作“是”。

#### 问富楼那说法

富楼那弥多罗尼子对须菩提说：“为什么不回答无垢施女所问？”须菩提回答富楼那说：“我在道理上不应有回答，只有默然是我所乐之处。这女孩所问的是无戏论之法，若有言说便生过患。法性无说，就是无诤行。”当时无垢施女对富楼那说：“世尊授记大德在说法人中最为第一。说法时，是说有境界之法呢？还是说无境界之法呢？若说有境界之法，便与凡夫相同。为什么呢？因为凡夫说有境界之法，所以大德不离凡夫之法。若无境界，便无所有。若无所有，怎么名为说法人中最为第一？”富楼那便默然。

#### 问离越禅定

大德离越对富楼那说：“大德！为什么不回答无垢施女所问？”富楼那回答离越说：“这女孩不是问有为，而是问第一义。第一义中没有言说，所以没有道理可以回答。”当时无垢施女对离越说：“世尊授记大德在行禅人中最为第一。大德入禅时，是依有心禅呢？还是依无心禅呢？若依心入禅，心如幻化不实，这定也不实。若无心入禅，外在的种种草木、枝叶、花果等也应得禅。为什么呢？因为它们同样无心。”大德离越便默然。

大德阿那律对离越说：“为什么不回答无垢施女所问？”离越回答阿那律说：“这女孩所问的是诸佛所行之处，不是声闻所能回答的。”当时无垢施女说：“诸佛之法与声闻之法有差异吗？若是有差异，无为有两种吗？诸贤圣都行于无为，无为之法便没有生，若没有生便是无二，若是无二便是如尔。如尔是无二的，所以大德离越为什么这样说呢？”

#### 问阿那律天眼

当时无垢施女对阿那律说：“世尊授记大德在诸天眼人中最为第一。大德以天眼所见的，是有物呢？还是无物呢？若见有物，便是见常；若见无物，便是见断；若离开二边，便是无所见。”大德阿那律便默然。

#### 问阿难多闻

大德阿难对阿那律说：“为什么不回答无垢施女所问？”阿那律回答阿难说：“这女孩所问的是破坏假名，所以不可以用假名回答。”当时无垢施女对阿难说：“世尊授记大德在多闻人中最为第一。这多闻之法，是真实之义呢？还是文字呢？若是真实之义，义不可说。若是不可说之法，便不是耳识所能知。若不是耳识所能知，又不可说。若是文字，世尊说依于了义，不依于文字。所以大德阿难也不是多闻，也不是了义。”大德阿难便默然。

文殊师利法王子对大德阿难说：“为什么不回答无垢施女所问？”阿难说：“这女孩所问的多闻远离文字，这便不可以用音声回答。她问的是平等，平等不是心，因为远离心相。这不是学地之人的法，我怎能回答？这是诸如来法王到达彼岸之处。”

### 菩萨品第三

#### 问文殊甚深

那时无垢施女对文殊师利法王子说：“世尊授记你在深解的菩萨中最为第一。你是以十二因缘之深为深呢？还是以真实之深为深呢？若以十二因缘之深为深，没有众生能成就十二因缘之深。为什么呢？因为十二因缘无来无去，不是眼识所能知，不是耳、鼻、舌、身、意识所能知，这其中的十二因缘不是行法。若以真实之深为深，真实之深便不是深，也没有得到真实之深的人。”文殊师利回答无垢施女说：“以本际之深为深。”无垢施女问文殊师利说：“本际便不是际，所以你的知也不是知。”文殊师利回答无垢施女说：“以无知而得无得，所以说本际罢了。”无垢施女问文殊师利说：“在无得之中没有言说的分，超过言语之道，无所可说。”文殊师利回答无垢施女说：“只是以假借的文字来说罢了。”无垢施女对文殊师利说：“诸佛的菩提超过文字语句与言说，所以菩提不可说。”

#### 问无痴见见佛

那时无垢施女对无痴见菩萨说：“你这善男子这样说：‘我这样想，前往舍卫城，愿令城中必定应得阿耨多罗三藐三菩提的众生，他们所见之物都是如来之像，又令他们对阿耨多罗三藐三菩提得以决定。’若见如来时，是以色身来观呢？还是以法身来观呢？若以色身来观，便不见佛，如世尊所说：若见我的色身、听闻我的音声，那人是边见，不是见我。若以法身来观，法身不可见。为什么呢？法身远离见闻，不可执取，所以不可见闻。”当时无痴见菩萨便默然。

【按】“我作是念”，宋、元、明、宫本作“我为作是念”。

宝相菩萨对无痴见菩萨说：“善男子！为什么不回答无垢施女所问？”无痴见菩萨说：“无垢施女所问的是无性之法，这无性之法不可说，所以不回答。”无垢施女说：“善男子！我不是问无性之法，无性之法不可问。学了之后回答，便没有障碍。”

#### 问宝相施宝

那时无垢施女对宝相菩萨说：“善男子！你说：‘我当这样想，前往舍卫城，愿令城中一切族姓的居家宝藏涌出，具足七宝。’你施宝之心，是有染著呢？还是无染著呢？若有染著，便与凡愚相同。为什么呢？因为凡夫有爱著。若无爱著，在无爱著之中便没有施宝。”当时宝相菩萨便默然。

#### 问离恶趣转业

当时无垢施女对离恶趣菩萨说：“善男子！你说：‘我这样想，前往舍卫城，愿令城中若有众生应堕恶趣的，都使他们在现世轻受而迅速脱离苦恼。’如来说业不可思议，这不可思议的业可以迅速断除吗？若可以断除，便违背如来所说。若不知道，怎能令其轻受而迅速断除？若能断除，在无主之法中你便是主宰。若能断除，也应当能不断除。”离恶趣菩萨回答无垢施女说：“我以愿力，所以能令其轻受而迅速断除。”无垢施女问离恶趣菩萨说：“善男子！诸法的如性，不可以用愿力来受取。”当时离恶趣菩萨便默然。

#### 问除诸盖除五盖

那时无垢施女对除诸盖菩萨说：“善男子！你说：‘我当这样想，愿令舍卫城中众生全部除去五盖。’你这样想：‘入了这定之后，能令众生不被五盖所覆。’在这定中，是自己自在呢？还是他人自在呢？若是自己自在，便无从涉及他人。一切诸法没有能到达他人的，你怎么入于禅定而除去他人的五盖？若是他人自在，便不能利益他人。”除诸盖菩萨回答无垢施女说：“这修行以慈为首。”无垢施女问除诸盖菩萨说：“诸佛都行慈行。善男子！难道有哪位佛因此令众生不以五盖为患吗？”除诸盖菩萨便默然。

【按】“患者也”之“也”，明本作“耶”。

#### 问观世音施无畏

当时无垢施女对观世音菩萨说：“善男子！你说：‘我当这样想，愿令舍卫城中众生，被关在牢狱中的迅速得到解脱，临当处死的即得保全性命，恐怖的人即得无畏。’所谓畏，是有所取呢？还是无所取呢？若是有所取，凡愚之人也有所取，所以不对。若是无所取，便无所施，在无施之法中怎么有除畏？”观世音菩萨便默然。

辩严菩萨对观世音菩萨说：“善男子！为什么不回答无垢施女所问？”观世音菩萨说：“这女孩不是问生灭之法，所以不可回答。”无垢施女问观世音菩萨说：“难道有无生无灭的问题吗？”观世音回答无垢施女说：“在无生无灭之中，没有文字言说。”无垢施女问观世音说：“诸有智慧的人，在无文字之中假说文字，然而不执著于文字。法性无碍，所以有智慧的人不被文字所碍。”

#### 问辩严施辩

当时无垢施女对辩严菩萨说：“善男子！你说：‘我当这样想，愿令舍卫城中见到我的众生都得辞辩，以种种妙偈互相问答。’善男子！你所施的这辞辩，是由觉观而起吗？若由觉观而起，一切有为都由觉观而起，所以不是寂静。若由爱而起，所施便是虚妄。”辩严菩萨回答无垢施女说：“这是我初发菩提心时，愿见到我的人都得辞辩，以种种妙偈互相问答。”当时无垢施女问辩严菩萨说：“善男子！你现在还有那发菩提心的愿吗？若现在还有，便是常见；若现在没有，便不能施给他人，所以所愿是虚妄。”当时辩严便默然。

#### 问无痴行菩提

那时无垢施女对无痴行菩萨说：“善男子！你说：‘我这样想，愿令舍卫城中若有众生见到我的，得无痴之见，对阿耨多罗三藐三菩提得以决定。’这菩提是有呢？还是无呢？若是有，便是有为的菩提，执于边见。若是无，便是虚妄，也堕于边见。”当时无痴见菩萨回答无垢施女说：“这菩提名为智。”无垢施女问无痴见菩萨说：“这智名为生呢？还是无生呢？若名为生，便不是善顺思惟所生，是有为之智，为凡愚所知。若名为无生，无生之中无所有。若无所有，便没有分别，菩萨、声闻、辟支佛、诸如来的菩提没有分别。凡愚之人分别菩提，有智慧的人便没有分别。”当时无痴见菩萨便默然。

【按】此段问无痴行菩萨，答者原文作“无痴见菩萨”，原文如此。

#### 同诣佛所，偈问菩萨行

那时大德须菩提对诸大德声闻以及诸大菩萨说：“诸大德！我们应当回去，不必进入舍卫城乞食。为什么呢？无垢施女所说的就是智者的法食。我们今日乐于法食，不需要段食。”无垢施女问须菩提说：“如说诸法无上无下，在这法中，还有什么要求而去乞食？大德！不戏论之法是比丘所行，不可乐于戏论。这是无依之法，不是有所依止的人所行。贤圣所行没有退转。”

【按】“抟食”之“抟”，《大正藏》作“搏”，今依CBETA作“抟”；抟食即段食。

那时八大声闻、八大菩萨、梵天等五百婆罗门、无垢施女、波斯匿王以及大众，一同前往佛所。到了之后顶礼佛足，右绕三匝，退坐一面。无垢施女另外绕佛七匝，顶礼佛足，合掌而立，以偈问佛：

```
我问无等尊，应供无量称，
施众甘露喜，菩萨云何行？
云何在道树，破魔降劳怨？
云何动天地，山王及林薮？
云何放光明，显发无量称？
愿大悲世尊，说应菩提行。
云何得总持，如来妙音声？
云何能修持，清净妙胜定？
云何诸行人，能得神足力？
今劝请世尊，说诸人实行。
云何得专念，及与坚固心？
云何得应辩，微妙成具足？
云何得顺理，含众义圆足？
美说微妙法，慧者无所碍。
云何乐施慧，净戒及忍辱，
善精进禅定，智慧照世间？
云何忆宿命，天眼明了见，
天耳他心智，神足过诸刹？
云何不处胎，化生莲花中，
恒于诸佛前，说空无我法？
云何等怨亲，断爱及荒秽，
志行无高下，其犹如风地？
利衰及毁誉，称讥与苦乐，
云何舍八法，行世犹如日？
云何不谄诤，除我舍憍慢，
寂静处禅定，智者乐实义？
云何不爱乐，妻子及财宝？
云何诸行人，乐于闲静处？
云何如飞鸟，亦如麟一角？
云何乐正法，及乐喜悦心？
```

【按】“能修持”之“持”，宫本、圣本作“于”。“微妙成具足”之“成”，圣本作“咸”。“美说”之“美”，宋、元、明本作“善”。“施慧”之“慧”，元、明本作“惠”。“麟一角”之“麟”，宫本作“驎”。

```
云何诸智人，观地水火风，
无倾动分别，处禅如虚空，
不行非法行，不乐观他行，
宁舍于身命，终不舍离法？
云何于菩提，生想如世尊，
生世尊想已，能发菩提愿？
云何得净土，及与清净僧，
智者得长寿，称名获安乐，
方便至彼岸，见谛不取证，
能度无量众，劝乐行善根？
云何得端正，及得于化生，
智慧多财宝，能知众生心？
云何忆宿命，常与诸佛会，
于千万亿劫，恒不生难处？
云何得种好，及三十二相？
云何善辞辩，及得于应辩？
云何修净土，成就比丘众，
随所愿乐处，能得生于彼？
导者作何行，能得色名称？
得力精进等，云何得不坏？
云何不犹豫，能行菩萨道，
去离诸掉悔，为众生说法？
于佛法众中，云何得最胜，
宁舍己身命，而不诽谤法？
世尊无不知，今世及未来，
愿大智世尊，次说菩萨行。
```
（大意：诸智者怎样观察地、水、火、风，没有倾动与分别，处于禅定如同虚空，不行非法之行，不乐于观察他人之行，宁舍身命，终不舍离正法？怎样对菩提生起如世尊之想，生起世尊之想后，能发菩提之愿？怎样得清净佛土以及清净的僧众，智者得长寿，称念其名获得安乐，以方便到达彼岸，见谛而不取证，能度无量众生，劝人乐于修行善根？怎样得端正，以及得化生，智慧与多财宝，能知众生之心？怎样忆念宿命，常与诸佛相会，在千万亿劫中，恒常不生于难处？怎样得种种随形好，以及三十二相？怎样得善巧的辞辩，以及得应辩？怎样修清净佛土，成就比丘众，随所愿乐之处，能得生于那里？导师作什么行，能得色身与名称？得到力与精进等，怎样能得不坏？怎样没有犹豫，能行菩萨道，远离种种掉悔，为众生说法？在佛、法、僧之中，怎样得到最胜，宁舍自己的身命，也不诽谤正法？世尊无所不知今世以及未来，愿大智世尊依次宣说菩萨之行。）

【按】“掉悔”之“掉”，《大正藏》作“悼”，今依CBETA作“掉”，宋、元、明、宫本同。

### 菩萨行品第四

#### 破魔、放光、动刹、陀罗尼、三昧、神足

那时世尊赞叹无垢施女说：“善哉善哉！你为了多多安乐利益众生，为了怜愍世间诸天人，向如来问诸菩萨摩诃萨这样的修行。谛听谛听，好好思念，我当为你分别解说。”当时无垢施女以及大众都说：“善哉！愿乐欲闻。”

那时世尊便为他们宣说：“菩萨成就四法，能破诸魔。哪四法？对他人的利养不生憎嫉，远离两舌，劝众多众生种植善根，对一切众生生起慈愍之心。无垢施女！这是菩萨成就四法，能破诸魔。”那时世尊想重宣此义，而说偈道：

```
不生憎嫉心，及以两舌语，
能教多众生，种善法根栽，
能修广慈心，普及于十方，
善行此行者，能摧诸魔怨。
```
（大意：不生憎嫉之心以及两舌之语，能教众多众生种植善法的根栽，能修广大的慈心，普及于十方；善于修行这些行的人，能摧伏诸魔怨敌。）

“无垢施女！若菩萨成就四法，能放光明，超过无量佛土。哪四法？能布施灯明，正法将灭时护持正法，能为了放逸以及堕于难处的众生前往他们那里为他们说法，能以宝饰璎珞布施佛塔庙。这是菩萨成就四法，能放光明，超过十方佛刹。”那时世尊想重宣此义，而说偈道：

```
若能施灯明，法末中护法，
开导难放逸，宝饰施佛庙，
是故诸菩萨，能放净光明，
过无量佛土，所照无边涯，
蒙光皆安乐，即发无上心。
```
（大意：若能布施灯明，在末法之中护持正法，开导身处难处与放逸的人，以宝饰布施佛庙，所以诸菩萨能放清净光明，超过无量佛土，所照无边无际，蒙受光明的人都得安乐，即发无上之心。）

“无垢施女！若菩萨能成就四法，能震动无量无边诸佛刹土。哪四法？如所说而修行，得深法忍，坚持善法，教化无量众生修行阿耨多罗三藐三菩提。这是菩萨成就四法，能震动无量无边诸佛刹土。”那时世尊想重明此义，而说偈道：

【按】“能振动”之“振”，宋、元、明、宫本作“震”。“欲重明此义”之“重”，宫本无，下同。

```
如所说修行，善解深法忍，
欲得白净法，坚持诸妙行，
能教无量众，发于菩提心，
行此四法者，能动无量刹。
```
（大意：如所说而修行，善解深法忍，想得到白净之法，坚持种种妙行，能教无量众生发起菩提之心；修行这四法的人，能震动无量佛刹。）

“无垢施女！若菩萨成就四法，得陀罗尼。哪四法？能布施清净美妙的种种所需，有需要庄严诸婇女的便施与，常以种种法赞叹诸如来，亲近而多多修习般若波罗蜜。这是菩萨成就四法，得诸陀罗尼。”那时世尊想重明此义，而说偈道：

```
若行种种施，能得陀罗尼，
庄严好婇女，随意之所须，
悉皆能充足，常赞叹如来，
修诸实智慧，世尊之所许。
以此四事者，即得陀罗尼，
于百千亿劫，所闻终不忘，
十方佛所说，尽能受忆念。
```
（大意：若行种种布施，能得陀罗尼；庄严美好的婇女，随其意之所需，都能令其充足；常赞叹如来，修习种种真实的智慧，为世尊所赞许。以这四事，即得陀罗尼，在百千亿劫中，所闻终不忘失，十方诸佛所说，都能受持忆念。）

“无垢施女！若菩萨成就四法，能得三昧。哪四法？多厌患生死，常乐闲静之处，常勤精进，善能成就所作的种种事业。这是菩萨成就四法，能得三昧。”那时世尊想重宣此义，而说偈道：

```
舍离诸有生，独行如骐驎，
善男子勤行，成就所作业。
慧者能成就，此四胜妙法，
亲近于菩提，求诸最胜法。
有寂静意者，能得诸三昧，
觉了胜菩提，诸佛之行处。
```
（大意：舍离诸有之生，独自修行如麒麟；善男子勤加修行，成就所作的事业。有智慧的人能成就这四种殊胜妙法，亲近菩提，求取种种最胜之法。有寂静之意的人，能得种种三昧，觉了殊胜的菩提，这是诸佛所行之处。）

【按】“骐驎”，元、明本作“麒麟”。

“无垢施女！若菩萨成就四法，能得神足。哪四法？因为身轻，因为心轻，因为在一切法中无所依止，因为受持四界如同空界。这是菩萨成就四法，能得神足。”那时世尊想重明此义，而说偈道：

```
身心轻亦尔，智者不著法，
受此诸四界，与空界同等。
具此四法者，能得乘神足，
一念过亿刹，供养尔所佛。
```
（大意：身轻，心也轻，智者不执著于法，受持这四界，与空界同等。具足这四法的人，能乘神足，一念之间超过亿数佛刹，供养那么多的佛。）

#### 端正、化生、财富、智慧、宿命、值佛

“无垢施女！若菩萨成就四法，得殊妙端正。哪四法？去除种种荒秽，不行瞋恚；乐于清净佛塔庙，以美妙的装饰来供养；住于威仪，持戒，常先开口问讯；不讥毁说法者，恒生世尊之想。这是菩萨成就四法，得殊妙端正。”那时世尊想重宣此义，而说偈道：

```
不瞋恼他人，去离荒秽行，
扫洒世尊庙，恭敬献饰宝，
常持于净戒，发意先问讯，
于法师无碍，敬心如世尊。
行此四善事，是谓勇健者，
殊妙最第一，见者莫不欢。
```
（大意：不瞋恼他人，远离荒秽之行，扫洒世尊的庙宇，恭敬献上装饰宝物，常持清净之戒，先开口问讯，对法师无所障碍，恭敬之心如对世尊。修行这四种善事，这名为勇健之人，殊妙最为第一，见到的人无不欢喜。）

【按】“发意先问讯”之“发意”，宫本作“不废”。“莫不欢”之“欢”，宋、宫本、圣本作“观”。

“无垢施女！若菩萨成就四法，能得化生。哪四法？雕刻莲花与坐佛的形像，以优钵罗花、钵头摩花、拘末头花、分陀利花以及其余种种杂妙之花，满捧来散于如来以及诸塔庙；立志利益无量众生，恒常和敬而不讥毁他人的短处；所种的善根是为了利益安乐众多众生，令其脱离生死苦恼；为了愿成阿耨多罗三藐三菩提。这是菩萨成就四法，能得化生。”那时世尊想重宣此义，而说偈道：

```
刻花坐尊像，种种花供养，
利益不恼众，化生诸佛刹，
恒发弘誓愿，度十方众生，
以此四妙行，恒生诸佛刹。
```
（大意：雕刻莲花与坐着的尊像，以种种花供养，利益而不恼害众生，便化生于诸佛刹；恒常发弘誓之愿，度化十方众生，以这四种妙行，恒常生于诸佛刹。）

“无垢施女！若菩萨成就四法，得大财富。哪四法？对乞求者不拒绝，对所施之物不生爱惜，恒愿众生获得众多财宝，舍离种种见而随顺正信。这是菩萨成就四法，得大财富。”那时世尊想重明此义，而说偈道：

```
施心无所逆，于财无悋惜，
信解诸佛法，生生获财富，
信解无谄嫉，不讼彼过患，
专心一向信，是故得财宝。
```
（大意：布施之心无所拒绝，对财物没有吝惜，信解诸佛之法，生生世世获得财富；信解而没有谄曲嫉妒，不讼说他人的过患，专心一向信奉，所以得到财宝。）

【按】“不讼彼过患”之“讼”，圣本作“诵”。

“无垢施女！若菩萨成就四法，得大智慧。哪四法？对他人之法不生憎嫉，宣说除过之法令人没有疑悔，对勤精进的人劝勉不令其废止，自身常乐于多修空法。这是菩萨成就四法，得大智慧。”那时世尊想重宣此义，而说偈道：

```
不嫉于正法，教他除疑悔，
常将导众生，修佛诸空行。
智者乐此法，得智慧名称，
善解诸佛语，速成两足尊。
```
（大意：不嫉妒正法，教他人除去疑悔，常常引导众生修习佛的种种空行。智者乐于这法，得智慧之名称，善解诸佛之语，迅速成就两足尊。）

“无垢施女！若菩萨成就四法，能忆识宿命。哪四法？对学问诵习有所忘失的人为他作忆念，为忘失的人宣说；恒常发出适意的好声音，令人乐于听闻；常行法施，不令其废止，为了脱离生死，趣向泥洹；愿如善财那样入于禅定的方便。这是菩萨成就四法，能忆宿命。”那时世尊想重宣此义，而说偈道：

【按】“能忆宿命”之“忆”，《大正藏》作“亿”，今依CBETA作“忆”。

```
废忘令忆念，恒出适意音，
说法不疲倦，常修诸定相。
以此四法者，咸得识宿命，
能忆无量劫，速悟佛行处。
```
（大意：对废忘的人令其忆念，恒常发出适意之音，说法不疲倦，常修种种定相。以这四法，都能了识宿命，能忆念无量劫，迅速悟入佛所行之处。）

“无垢施女！若菩萨成就四法，常遇诸佛。哪四法？宁舍身命不诽谤正法，宁舍身命不诽谤菩萨，宁舍身命不亲近恶知识，忆念诸佛没有厌足。这是菩萨成就四法，常遇诸佛。”那时世尊想重宣此义，而说偈道：

```
不谤于菩提，亦不毁菩萨，
乐离恶知识，念诸佛无厌。
大德行此行，得值遇诸佛，
未成正觉顷，恒与诸佛会。
```
（大意：不诽谤菩提，也不毁谤菩萨，乐于远离恶知识，念诸佛没有厌足。大德修行这些行，得以值遇诸佛，在未成正觉之前，恒常与诸佛相会。）

#### 相好、应辩、净土、净众、随愿往生

“无垢施女！若菩萨成就四法，得三十二相之身。哪四法？采集种种珍宝散于佛塔庙；以种种香油涂塔的基座；以杂花鬘庄严塔庙，以种种伎乐来供养；常给侍贤圣，从不违离。这是菩萨成就四法，得三十二相。”那时世尊想重宣此义，而说偈道：

```
采宝散塔庙，又以香油涂，
杂花众伎乐，给侍适贤圣。
具相庄严身，端妙殊特好，
以此得众相，以严人中尊。
```
（大意：采集宝物散于塔庙，又以香油涂饰，以杂花、众伎乐供养，给侍贤圣，令其适意。以具足相好庄严其身，端妙殊特美好，以此得到众相，来庄严人中之尊。）

【按】“殊特”，宋、元、宫本作“特殊”。

“无垢施女！若菩萨成就四法，得八十随形好。哪四法？脱下种种妙衣来敷设法座，给侍一切而终无疲厌，前往说法之处没有好胜争论之心，恭敬大众，只生世尊之想，劝众多众生发菩提心。这是菩萨成就四法，得八十随形好。”那时世尊想重宣此义，而说偈道：

```
敷座众妙衣，供养无疲厌，
不与持法竞，劝众发道心。
能行此法者，速得成众好，
菩萨亲近行，具好八十种。
```
（大意：以种种妙衣敷设法座，供养没有疲厌，不与持法者竞争，劝众人发起道心。能修行这些法的人，迅速成就种种随形好，菩萨亲近修行，具足八十种随形好。）

【按】“菩萨亲近行”之“亲”，圣本作“观”。

“无垢施女！若菩萨成就四法，得善巧应辩。哪四法？受持、亲近菩萨法藏；昼夜六时诵三阴经；诸佛的菩提无生无灭，世人难以相信，然而能受持读诵；广为他人宣说，令其得到喜悦，不爱惜身命。这是菩萨成就四法，得善巧应辩。”那时世尊想重宣此义，而说偈道：

```
护持菩萨藏，勇猛诵三阴，
无生世相追，方便说令喜，
不爱于身命，持十力正法，
无疑虑而行，最上胜菩提。
修此甚深法，便能得应辩，
譬如杂花鬘，天人所乐见。
```
（大意：护持菩萨藏，勇猛诵持三阴经；原文“无生世相追，方便说令喜”，大意为对世人难信的无生之法，以方便宣说令人喜悦，存疑。不爱惜身命，持守十力的正法，没有疑虑而修行最上殊胜的菩提。修习这甚深之法，便能得到应辩，譬如杂花鬘，为天人所乐见。）

【按】“世相追”之“追”，明本作“违”。

“无垢施女！若菩萨成就四法，得清净佛土。哪四法？因为不嫉妒，因为心平等，因为护持菩提之行，因为不亲近四部众。这是菩萨成就四法，得清净佛土。”那时世尊想重宣此义，而说偈道：

```
不嫉于他人，见彼得利喜，
等心行大慈，化众无染著。
行此四无量，智者善守护，
得净土无难，速成无上道。
```
（大意：不嫉妒他人，见他人得利而欢喜，以平等心行大慈，教化众生而无所染著。修行这四种无量，智者善加守护，便得清净佛土，没有八难，迅速成就无上道。）

“无垢施女！若菩萨成就四法，得清净徒众。哪四法？因为不希望得到他人的徒众，对不和合的人摄受令其和解，对学问诵习的人给予其所需，舍离两舌。这是菩萨成就四法，得清净徒众。”那时世尊想重宣此义，而说偈道：

```
终不望他众，离者能令合，
给学人所乏，不离别众生。
能行此四事，便得清净众，
为清众故行，极苦亦不舍。
```
（大意：终不希望得到他人的徒众，对离散的人能令其和合，供给学人所缺乏的，不令众生别离。能修行这四事，便得清净徒众，为了清净徒众而修行，即使极苦也不舍弃。）

“无垢施女！若菩萨成就四法，随所愿的佛土便得往生。哪四法？对他人的名誉利养之法不生憎嫉；专心修习六波罗蜜；对一切菩萨生世尊之想；从初发心乃至坐于道场，常以平等心观察，终不为了利养名誉而谄曲虚赞。这是菩萨成就四法，随所愿的佛土即得往生。”那时世尊想重宣此义，而说偈道：

```
不憎他名利，求清净六度，
等尊观菩萨，终不谄求名。
菩萨行此善，能见十方界，
随心之所愿，即得生其中。
```
（大意：不憎恨他人的名利，求取清净的六度，平等尊重地看待菩萨，终不谄曲以求名。菩萨修行这些善，能见到十方世界，随心之所愿，即得生于其中。）

#### 无垢施女誓变男身

那时无垢施女对佛说：“世尊！如所说的菩萨行，我当奉行。如世尊所说的诸菩萨行，在这些法中若有一法不行，便是欺诳十方现在说法的诸佛。”那时大德目连对无垢施女说：“你敢在佛前作大狮子吼，难道不知道菩萨行难行吗？终究不能以女身得阿耨多罗三藐三菩提。”那时无垢施女回答大德目连说：“我现在在佛前作诚实之愿：若我在来世必定得以成佛、如来、无所著、等正觉，乃至佛、世尊、天人师，以这诚实之愿，令这三千大千世界六种变动震动，对众生不令其恼乱。如世尊所说的诸菩萨行，我尽形寿修行，以这真实之愿，令虚空中雨下众多天花，百千种伎乐不鼓自鸣，令我把这女身变成十六岁的童子。”无垢施女发了这诚实之愿之后，当时三千大千世界六种变动震动，虚空中雨下众多天花，百千种天乐不鼓自鸣，无垢施女即刻把女身变成十六岁的童子。

当时大德目连偏袒右肩，右膝著地，合掌向佛，对佛说：“世尊！我现在面礼诸佛与菩萨，从初发意乃至坐于道场的。世尊！这女人竟有这样大威德的神足之力，能发大愿，发愿之后随愿都成就。”佛告诉目连：“是这样，是这样，如你所说。菩萨从初发意乃至坐于道场，为天人所礼敬，如佛塔庙，是诸声闻、辟支佛的无上福田。”

【按】“面礼”，元、明、宫本作“南无”。

#### 世尊微笑，阿难偈问

那时世尊和悦微笑。诸佛的常法是，若微笑时，口中便放出青、黄、赤、白、紫、颇黎等种种色光，照于无量无边诸佛刹土，诸天、魔宫、日月的光明都不再明亮，光明收回后从顶上入。那时大德阿难便从座起，重新整理衣服，偏袒右肩，右膝著地，合掌向佛，以偈问道：

【按】“白紫”，元、明本作“白红紫”。“颇黎”，元、明、宫本作“玻瓈”。“更正衣服”之“正”，元、明本作“整”。

```
天龙梵音师子吼，
迦陵频伽雷震声，
除贪瞋痴生喜悦，
愿十力海说笑缘。
六变震动无所娆，
雨天妙花悦众情，
世尊摧伏诸外道，
犹如师子伏野干。
唯愿世尊为我说，
所以微笑之因缘。
万亿日月珠电光，
天龙梵王诸光明，
释迦口出净光明，
遏诸光明佛光胜。
眉间毫相如珂月，
圆满柔软喻天衣，
白毫放光照无量，
愿说何故放斯光？
世尊齿净无垢秽，
方平齐密白如雪，
佛口应出杂色光，
青黄赤白紫颇黎。
假使界坏日月落，
地满虚空无居处，
水性可使变为火，
火性亦可变为水，
大海尽可令枯竭，
如来实语终不二。
生十方趣诸众生，
假令一时成缘觉，
一一缘觉集诸问，
百千万种经亿劫，
尽共集会如来前，
各以异音同时问，
如来即以一音报，
能断彼众无量疑。
成就智慧至彼岸，
一切智慧所庄严，
具三十二最胜尊，
大威德者愿解说，
世尊何缘而微笑？
授何众生菩提记？
诸天世人咸欲闻，
愿如来演微笑音。
```
（大意：如天龙之音、梵音、狮子吼，如迦陵频伽之声与雷震之声，能除去贪瞋痴而生起喜悦，愿十力之海宣说微笑的因缘。六种变动震动而无所扰乱，雨下天上妙花，悦乐众人之情；世尊摧伏诸外道，犹如狮子降伏野干。唯愿世尊为我宣说微笑的因缘。万亿日月、珠宝、闪电之光，天、龙、梵王的种种光明，释迦口中放出的清净光明，遮蔽诸光，佛光最胜。眉间白毫之相如珂贝与明月，圆满柔软，可比天衣，白毫放光照耀无量，愿说为何放此光明？世尊牙齿清净无垢秽，方正平整齐密，白如雪，佛口应放出杂色之光，青、黄、赤、白、紫、颇黎色。假使世界毁坏，日月坠落，大地充满虚空而无居处，水性可使变为火，火性也可变为水，大海都可令其枯竭，如来的实语终无二言。假令生于十方诸趣的众生，一时都成为缘觉，每一位缘觉都汇集种种问题，百千万种，经过亿劫，全都共同集会于如来面前，各以不同的声音同时发问，如来便以一音回答，能断那些大众无量的疑惑。成就智慧到达彼岸，以一切智慧庄严，具足三十二相的最胜之尊，大威德的世尊，愿为解说：世尊因何缘故而微笑？为哪些众生授菩提记？诸天世人都想听闻，愿如来宣说微笑的因缘。）

【按】“愿十力海”之“力”，宫本作“方”。“经亿劫”之“经”，宫本作“逕”。“愿解说”之“说”，宫本作“脱”。

#### 佛说无垢施久远发心

那时佛告诉阿难：“你看见这位无垢施菩萨以诚实之愿震动这三千大千世界了吗？”阿难对佛说：“世尊！是的，已经看见。”佛说：“这位无垢施菩萨发心以来，已在八万阿僧祇劫中修行阿耨多罗三藐三菩提之行。这位无垢施菩萨修菩萨行经过六十劫之后，文殊师利法王子才发菩萨心。阿难！如文殊师利等八万六千位大菩萨所有的功德与庄严佛土，与那么多菩萨相等，没有差异。”

那时大德目连对无垢施菩萨说：“善男子！你已久发阿耨多罗三藐三菩提心，为什么不转女人之身？”无垢施菩萨回答目连说：“世尊授记大德在神足人中最为第一。为什么不转为男子之身？”大德目连便默然。无垢施菩萨对大德目连说：“也不是以女身得阿耨多罗三藐三菩提，也不是以男身得阿耨多罗三藐三菩提。为什么呢？菩提无生，所以不可得。”


### 授记品第五

#### 佛赞功德，说经名

那时文殊师利法王子对佛说：“未曾有啊，世尊！这位无垢施菩萨竟能善解甚深之法，以誓愿之力成就种种愿。”佛告诉文殊师利说：“是这样，是这样，如你所说。这位无垢施菩萨曾在六十亿佛所修空三昧，在八十亿佛所修无生法忍，在三十亿佛所问甚深之法。曾以衣服饮食供养八十亿诸佛，并问这分别辩印三昧。又，文殊师利！若有善男子、善女人为了菩提，以如恒河沙等诸佛刹土中充满的珍宝来布施，不如受持此经，读诵通利，广为人说，乃至只是书写受持，其功德最上最胜，何况如说修行。为什么呢？因为能受持诸菩萨的菩提行法。”文殊师利对佛说：“世尊！应当怎样称呼此经？怎样奉持？”佛告诉文殊师利：“应当名为‘分别说应辩’，也名为‘说三昧门’，应当这样奉持。”佛说此经时，八万亿众生，诸天以及人，都发阿耨多罗三藐三菩提心，必定不退转。

#### 授记无垢光相王如来

那时辩严菩萨对佛说：“世尊！这位无垢施菩萨何时当成就阿耨多罗三藐三菩提？”佛告诉辩严：“善男子！这位无垢施菩萨过了若干劫、供养若干佛之后，当得成佛，号为无垢光相王如来、应供、正遍知、明行足、善逝、世间解、无上士、调御丈夫、天人师、佛、世尊。世界号为无量德庄严，没有声闻、辟支佛，微妙的严饰胜过诸天之处。”

无垢施菩萨亲从如来听闻授记之名，心净踊跃，跃在虚空，高八十亿多罗树，放大光明，照百千亿诸佛刹土，在世尊顶上化作八万四千种种天宝庄严的殊妙宝盖，便在空中以无量神足之力供养礼拜十方无量诸佛之后，回到佛所，在一面站立。

【按】“踊在虚空”之“踊”，宋、元、宫、明本作“勇”。

#### 五百婆罗门忏悔赞佛

那时婆罗门梵天以及五百婆罗门，听闻为无垢施菩萨授记，以及见到神足变现，踊跃欢喜，一时同声以偈赞佛：

```
能恭敬佛者，得世第一利，
发心求菩提，为佛第一智。
我等昔造恶，今生邪见家，
得见佛及僧，发口出恶言。
我今诚心悔，恶口所犯罪，
见诸贤佛子，谓为是不吉。
若不见如来，两足中最尊，
唐受此人身，唐食人所食。
我及无垢施，出为祀祠故，
施女见佛子，敬重而赞叹。
我等见赞叹，即呵其可叹，
我等即问之，汝曾见佛耶？
于时答我言，我生适七日，
闻天叹佛名。女赞叹如来，
真实无差异。我等闻叹已，
即发最胜心，求无上善根。
我闻佛名故，于宿业得悟，
即来礼救世，为求胜法故。
见佛礼敬心，闻最无上法，
见人中尊仙，永离诸苦际。
佛之所说法，真实能度世，
我等于中学，为无上法故。
闻菩萨所行，为得佛法故，
我等亦应习，为得佛道故。
说出要道门，菩萨所应行，
我亦趣此门，为世所敬礼。
```
（大意：能恭敬佛的人，得世间第一的利益；发心求菩提，是为了佛的第一智慧。我们往昔造恶，今生生在邪见之家，得见佛以及僧，却开口说出恶言。我们现在诚心忏悔恶口所犯之罪：见到诸贤圣佛子，却说是不吉。若不见如来这两足中最尊的人，便白白受了这人身，白白吃了人所吃的食物。我们与无垢施为了祭祀而出城，无垢施女见到佛子，恭敬尊重而赞叹。我们见她赞叹，便呵斥她所赞叹的；我们便问她：你曾见过佛吗？当时她回答我们：我生下才七天，听到天人赞叹佛的名号。女孩赞叹如来，真实无有差异。我们听了她的赞叹之后，即发最胜之心，求取无上的善根。我们因为听闻佛的名号，对宿世之业得以醒悟，即来礼敬救世者，是为了求取殊胜之法。见佛礼敬之后，听闻最无上之法，见到人中的尊仙，永离种种苦的边际。佛所说的法，真实能度世间，我们在其中修学，是为了无上之法。听闻菩萨所行，是为了得到佛法，我们也应当修习，是为了得到佛道。宣说出离的要道之门，是菩萨所应修行的，我们也趣向这门，为世间所敬礼。）

【按】“求无上善根”之“善根”，宋、元、明本作“菩提”，宫本、圣本作“善持”。“见佛礼敬心”之“心”，宋、元、明、宫本、圣本作“已”，今依此译作“礼敬之后”。“永离诸苦际”之“永”，明本作“求”。

```
佛知彼诚心，熙怡而微笑。
阿难即白佛：愿说笑因缘。
```
（大意：佛知道他们的诚心，和悦而微笑。阿难便对佛说：“愿说微笑的因缘。”）

那时佛以偈告诉阿难说：

```
此诸婆罗门，及梵志梵天，
同共一劫中，次第成正觉。
曾于过去世，具供五百佛，
从今以妙行，当见亿数佛。
于八十亿劫，终不堕难处，
于一一劫中，当觐亿数佛，
然后乃当成，最胜两足尊，
皆当同一号，号曰梵光明。
寿命亦同等，寿八十亿岁，
刹土皆同等，各八十亿僧。
化度无量众，利益众生已，
当入于泥洹，证寂静灭度。
```
（大意：这些婆罗门以及梵志梵天，将在同一劫中次第成就正觉。他们曾在过去世具足供养五百佛，从今以后以妙行修持，将见到亿数的佛。在八十亿劫中终不堕于难处，在每一劫中都将觐见亿数的佛，然后才当成就最胜的两足尊，都将同一名号，号为梵光明。寿命也都相同，寿八十亿岁；佛土也都相同，各有八十亿僧众。度化无量众生，利益众生之后，将入于泥洹，证得寂静灭度。）

【按】“从今以妙行”之“妙”，宋、元、明、宫本、圣本作“涉”。

#### 流通

佛说此经之后，无垢施菩萨摩诃萨，以及大众、梵天、梵志等，五百位菩萨大士，波斯匿王，诸大声闻弟子，诸天八部，人以及非人，听闻佛所说，都大欢喜。
