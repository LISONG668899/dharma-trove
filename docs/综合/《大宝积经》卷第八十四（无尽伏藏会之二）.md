# 《大宝积经》卷第八十四（无尽伏藏会之二）

唐·三藏菩提流志 奉诏译

## 无尽伏藏会第二十之二

#### 菩萨不共之法：猛火与须弥四面之喻

“再者，电得！菩萨成就这样的智慧之后，对众生的根性、行为与意乐善巧了知。若见到多贪的众生，为了调伏、疗治他们的病，便示现与凡夫相同，现受诸欲，有妻子、家业、资生之物，犹如莲花而不染著。有些众生愚痴无智，不知菩萨的善巧方便，而这样想：‘哪有智者贪受诸欲的？与凡夫没有不同。’便以为菩萨远离菩提。这样的众生因为心不清净，生起大瞋忿，不生敬信，由于这一业，身坏命终堕入大地狱。又以菩萨密化的因缘，罪报受完之后，决定当得入于平等。电得！譬如猛火，随投入什么草木，一切都炽燃起来，全部成为火。菩萨也是这样，智慧之火炽燃，所有众生，无论贪、瞋、痴，无论善、不善，菩萨与他们同行，一切炽燃都成为智慧。这名为菩萨的不共之法。

【按】“因缘”之“缘”，《大正藏》作“绿”，今依CBETA作“缘”。

“又如须弥山王的不共之相，就是四面由四宝所成。随众生青、黄、赤、白种种色相，他们若前往琉璃那一面，都同为一色，如那琉璃；前往金色那一面，都如金色；银面、颇梨面也都同样。菩萨也是这样，得不共之法，随众生无论贪、瞋、痴，无论善、不善，来到菩萨之所，与他们同行，一切都令入于菩萨之智。他们因为心不清净、自己的恶业，或堕地狱、饿鬼、畜生、阎摩罗界。由于菩萨这不共的功德以及愿力，他们罪报受完之后，决定当得阿耨多罗三藐三菩提。

【按】“颇梨”之“颇”，宫本作“玻”。

#### 往昔因缘：广授王与无垢比丘

“电得！过去无量无边阿僧祇劫五浊之世时，有佛出世，号为宝聚功德声如来、应供、正遍知、明行足、善逝、世间解、无上士、调御丈夫、天人师、佛、世尊。当时世人寿命一百二十岁，如我今日。那些众生被极重的贪欲、瞋恚、愚痴烦恼所覆蔽，违逆父母、兄弟、朋友，不顺从和上以及阿阇梨，不知恩德。常怀毒害、奸诈、贼害之心，互相破坏，非理而行，对佛、法、僧不生敬信，悭吝鄙劣，行饿鬼之法。那佛刹中有这样等难以调伏的诸恶众生。当时那位世尊也由于往昔誓愿之力，在这恶世中得阿耨多罗三藐三菩提。那佛又有二万二千大声闻众。当时有一位国王，名为广授，以自在王法教化统治阎浮提，对佛法信心清净，请那位如来以及比丘众在夏安居期间广设供养。

【按】“无上士”之“士”，宋本作“正”。“和上”，明本作“和尚”。

“那时有一位法师比丘，名为无垢，具足辩才，善巧说法，为大众所乐闻，开示众生常不疲倦。凡所说法，没有希求，容貌和悦，先开口问讯，色力具足，颜貌端严，为众生所乐见，受到供养、恭敬、尊重、赞叹。又有一位新学的年少比丘，常随无垢出入王宫，没有障碍，受到衣服、饮食、卧具、医药种种供养。当时那僧众中有很多比丘，不知修习身、戒、心、慧，不敬佛、法以及众僧，持常见、断见以及我见等，诽谤佛法，轻躁难调。不收摄诸根，住于非法，没有沙门之行而自称沙门，身口意业全都邪僻。

“当时那位世尊过了安居之后便入涅槃。广授王以赤栴檀荼毗供养，造立八十俱胝宝塔，以赤栴檀作为栏楯，四面都有金色莲花。无垢比丘是佛所授记的多闻第一，在佛灭度后弘扬宣说正法。随所游行的城邑聚落，教化无量百千众生，都令他们安住于阿耨多罗三藐三菩提。

【按】“记别”之“别”，明本作“莂”。

“那时有很多恶比丘，不知修行，常怀嫉妒，被魔所迷惑，前往国王那里这样说：‘大王所师事尊敬的无垢比丘，出入王宫没有禁制。而那比丘没有离开贪欲，非时而食，以香鬘庄严身体，实在不是梵行，不应供养。我们为这件事来禀告大王，免得以后对佛的正法生起不信。’当时有一个魔，名为极恶，便自己变身作比丘之像，又前往国王那里，如前面那样重说一遍。当时广授王多次听到这话，便这样想：‘无垢比丘精勤有智，为我所尊重，若说有这种事，终究是不可能的。’这样想之后，那时魔众在虚空中现出半身，向着国王说偈道：

```
王应学伎艺，善识于机宜，
广授不能知，非是人王相。
佛罗汉弟子，已具于大智，
如是语不依，云何随断见？
比丘为利益，告汝以诚言，
断见恶趣人，实非修梵行。
彼人于宫内，共婇女娱乐，
王应与侍从，亲覩离疑心。
```
（大意：大王应当学习技艺，善于识别时机；广授王却不能了知，这不是人中之王的样子。佛的阿罗汉弟子已具足大智慧，这样的话你不依从，怎么反倒随顺断见的人？比丘们为了利益你，以诚实之言告诉你：那持断见、趣向恶道的人，实在不是修梵行者。那人在宫中与婇女娱乐，大王应带侍从亲眼去看，以离开疑心。）

【按】“婇女”之“婇”，《大正藏》作“采”，今依CBETA（所录高丽藏）作“婇”，宫本同。

```
王闻如是事，心生大惊怖，
即便将侍从，速疾诣宫中。
无垢时在宫，演说第一义，
诸法自性空，无我无寿者。
王与诸兵众，俱为魔所惑，
见宫中婇女，围遶于比丘，
瞋猛如醉象，便勅旃陀罗：
比丘污我宫，当治以苦法。
臣佐及眷属，皆为魔所持，
于无罪比丘，随忿而生害。
魁脍持刀进，无垢便悲泣。
王语：汝非法，何故而复悲？
无垢白王言：是事难自表，
且待须臾间，我当有明证。
王闻比丘言，即止于魁脍，
当试作何事，汝应速宣说。
```
（大意：国王听到这样的事，心中大为惊怖，便带着侍从迅速赶到宫中。无垢当时正在宫中，演说第一义：诸法自性空，无我、无寿者。国王与诸兵众都被魔所迷惑，看见宫中婇女围绕着比丘，便瞋怒猛烈如醉象，命令旃陀罗：“比丘污秽我的宫闱，应当以苦刑惩治。”臣佐以及眷属都被魔所控制，对无罪的比丘随着忿怒而生起加害之心。刽子手持刀上前，无垢便悲泣。国王说：“你行非法，为何又悲泣？”无垢对国王说：“这件事难以自我表白，请稍待片刻，我当有明证。”国王听了比丘的话，便止住刽子手：“你要试作什么事，应当快说。”）

【按】“惊怖”之“怖”，宋、元、明、宫本作“恼”。

```
成就胜意乐，行慈利世者，
合十指爪掌，而发于誓言：
大王汝当知，若实无此事，
愿地六种动，空中雨妙花。
当发如是言，大地六种动，
空界雨天花，魔众怀忧恼。
王时生净信，礼足求欢喜：
我当堕地狱，无依愿覆护。
咄哉遇此恶，如何起毒心？
无覆无所依，所从唯恶友；
十方我无护，唯有于大师。
我当舍王位，尽寿归依住。
```
（大意：那成就殊胜意乐、行慈利益世间的比丘，合起十指手掌，发出誓言：“大王你应当知道，若确实没有此事，愿大地六种震动，空中雨下妙花。”刚说出这样的话，大地便六种震动，空中雨下天花，魔众怀着忧恼。国王当时生起净信，礼比丘之足，求他欢喜：“我当堕地狱，无所依靠，愿您覆护我。唉！遇到这样的恶事，我怎么会生起毒害之心？我无所覆护、无所依靠，所随从的只是恶友；十方之中我没有护佑，只有您这位大师。我当舍弃王位，尽此一生归依安住于您。”）

【按】“王时生净信”之“时”，明本作“闻”。

```
比丘知彼王，及眷属志乐，
为说第一义，王闻得正信。
与百亿眷属，舍王位出家，
修习头陀行，不受他人请。
时王后宫内，婇女八万人，
闻说第一义，皆住不退转。
王依于佛教，二十四年中，
日夜常忏悔，罪业犹不尽。
百俱胝眷属，恶心向法师，
由此命终后，堕于无间狱。
多亿年受苦，罪毕遇如来，
以昔恐怖因，余报常羸劣。
次第转修习，供养千亿佛，
各于余国中，悉皆成正觉，
俱同一名字，号功德名称。
```
（大意：比丘了知国王以及眷属的志乐，为他们说第一义，国王听后得到正信。国王与百亿眷属舍弃王位出家，修习头陀行，不受他人邀请。当时王的后宫中有婇女八万人，听闻宣说第一义，都安住于不退转。国王依照佛教，在二十四年中日夜常常忏悔，罪业仍未消尽。百俱胝眷属曾以恶心对待法师，由此命终之后堕入无间地狱。他们在多亿年中受苦，罪报完毕后遇到如来，由于往昔令法师恐怖的因，余报使他们常常羸弱低劣。他们次第辗转修习，供养千亿佛，各在其他国土中都成正觉，都同一名号，号为功德名称。）

```
时彼广授王，慈忍比丘所，
由起毒害意，于多亿岁中，
受昔恶业对，堕大叫地狱。
毕此业报已，还得于人身，
值普眼如来，亲近常供养。
由此转奉事，八十俱胝佛，
然后成正觉，今则我身是。
彼比丘欲害，无罪法师者，
当来得作佛，弥勒菩萨是。
时彼王宫内，八万诸婇女，
净信植众德，承事无量佛。
于今复发行，大愿利众生，
当奉千亿佛，各成等正觉。
我今告汝等，一切勿生害，
修慈佛所赞，速得大菩提。
```
（大意：当时那广授王对慈忍的比丘生起毒害之意，因此在多亿年中受往昔恶业的报应，堕入大叫唤地狱。受完这一业报之后，又得到人身，值遇普眼如来，亲近并常常供养。由此辗转奉事八十俱胝佛，然后成就正觉，就是现在的我。那位想加害无罪法师的比丘，将来得以作佛，就是弥勒菩萨。当时那王宫中的八万婇女，以净信种植众多功德，承事无量诸佛。如今又发起修行，以大愿利益众生，将奉事千亿佛，各自成就等正觉。我现在告诉你们：对一切都不要生加害之心，修习慈心为佛所赞叹，能迅速证得大菩提。）

【按】“受昔恶业对”之“昔”，宫本作“首”。“业对”即业报。

#### 如来智慧最尊

“所以电得！对众生的根性、志乐不能善知的时候，任何时候都不应生加害之心。电得！譬如诸山之中，须弥山为最。如来的智慧也是这样，在诸智之中最尊无上。譬如一切水之中，大海最为殊胜。如来的智慧也是这样，在诸智之中最为深广。又如诸国王之中，转轮圣王最为尊上。如来的智慧也是这样，在诸智之中是无上之上。电得！如来因为成就这样的智慧，一切众生贪、瞋、痴之行，心念一念一念的转变，如来全都了知，在一弹指间都能摄受。

“电得！如来成就一切种智，如明眼人自己观看掌中五颗庵罗果，不用功力，明了无疑。如来也是这样，了知一切众生的心行，在大众中种种说法。无量无数佛世界中与贪行相应的众生，为贪欲热恼日夜寻思，虚度时光，我全都知见。他们为贪欲热恼而起身口种种之业，我全都知见。瞋行众生瞋忿覆心，互相憎恨嫉妒，因为毒害而堕入无间之处，我全都知见。与痴行相应的众生，被无明黑暗所迷惑，执著、乐于随顺邪见，我全都了知。有堪任的、不堪任的，有增进的、有退失的，在如来乘种善根的、在缘觉乘种善根的、在声闻乘种善根的，我全都了知。

【按】“五庵罗果”之“庵”，宋本作“若”。“无量无数”之“无数”，《大正藏》作“无边”，今依CBETA（所录碛砂藏）作“无数”；宋、元、明、宫本作“无”。“贪行”之“贪”，宫本作“贫”。“无明暗”，宋、元、明本作“无明暗蔽”。

“如来成就这样的智慧，处在大众之中，能了知众生心行的差别，知道时机未到，便默然舍置而住，只这样想：‘这些众生对法迷惑，不能理解。’如来具足殊胜的根力，善知时机，所以哪些堪受调伏、哪些有殊胜志乐、哪些能堪忍、哪些能接受善言，我全都了知。这样了知之后，对那些众生摄受利益。

#### 初业菩萨勿起嫌害

“所以电得！初业菩萨未入正位，对众生殊胜的志乐与行为不能善知，无论在家还是出家，都不应生起嫌恨加害之心，不要在长夜中自招衰损苦恼。所以菩萨从初发心起，应当对一切安住于大乘的人生起佛想；对其余众生，即使看见他们作种种恶业，也不生起损害之心。为什么呢？如来常说，若众生对清白之法稍有缺减，终究不能入于涅槃。

【按】“如来常说”之“常”，宫本作“甞”。

“菩萨若见到贪行众生，应当这样想：‘他被贪欲热恼所烧，这是我的过失。’见到被瞋恚以及愚痴热恼所烧的众生，都想：‘这是我的罪过。’为什么呢？我见到一切众生的病苦，应当为他们求药，方便疗治。我先前发誓愿要除去众生之病，而现在却舍置不顾，这是我的过失。菩萨成就这样的意乐，自省己过，对众生深深生起慈心。若遇到杀害、割截身体，对那怨家生起报复之心，是不可能的。电得！菩萨这样正修行时，过去所有的不善之业永尽无余，未来的不善终究不再生起。

#### 往昔因缘：可畏旃陀罗与牛

“电得！在往昔无量阿僧祇劫、然灯佛之前，有一位佛名为胜生如来、应供、正遍知、明行足、善逝、世间解、无上士、调御丈夫、天人师、佛、世尊，出现于世。世界名为光明。他住在安隐王城的林中。那时有一个旃陀罗，名为可畏，凶险好杀，安于残忍，毫无慈心，手上涂着血，看见的人都害怕。当时这旃陀罗把一头牛系在他的屋舍，正要进去宰杀，牛看见了惊怖，挣断绳子奔逃，跑往胜生如来所住的林中。这旃陀罗持刀追赶，那牛惶怖之下坠入深坑，性命将尽，痛楚号叫。旃陀罗看见这牛之后更加忿怒，便进入坑中持刀要杀。

【按】“安忍无慈”，宫本作“无安忍慈”。“牛已”之“已”，《大正藏》作“己”，今依CBETA作“已”。

“刀尚未落下之时，那时胜生如来在那林中，被无量百千大众围绕，广为分别缘起法门，就是：无明缘行、行缘识、识缘名色、名色缘六入、六入缘触、触缘受、受缘爱、爱缘取、取缘有、有缘生、生缘老死忧悲苦恼，这样的因缘一切都是纯大苦聚的集起。电得！在这缘起之中，无明对行无思无觉，行对无明也无思无觉，乃至生对老死无思无觉，老死对生也无思无觉。这样诸法之性不可得，无行无念，无我、我所，本性清净，各不相知。凡夫因为不闻这样的法，执著色是我、我有诸色、色属于我，乃至受、想、行、识也是这样。由于执著我、我所，便无常计为常、苦计为乐、不净计为净、无我计为我，生起四颠倒。因为颠倒之见，无明迷惑，不正思惟，随心染著而不能破除，被有爱所系缚，生死轮回相续不断。智者因为善观法界之相，不见有少许我、人、众生乃至寿命、生老病死、系缚杀害可得。

【按】“于彼林中”之“彼”，宫本无。

“电得！那时可畏旃陀罗在这时候，远远听到如来说法之声，当即觉悟，止息杀心，丢弃所持之刀，从坑中出来。前往佛所，顶礼佛的双足，退住一面，说：‘世尊！我现在愿在佛法中出家修道。’佛说：‘可以。善来比丘。’他当即成为沙门，得具足戒。那时胜生如来知道他的意乐已渐渐成熟，便广为演说诸菩萨行。可畏听闻之后证得无生忍，在佛法中永不退转。那头牛得闻如来所说的缘起法句，其声微妙，心生喜悦，命终之后生于兜率天，得见弥勒，成就正信。

“像这样，电得！众生之行甚深微密，难识难知。所以电得！菩萨欲求阿耨多罗三藐三菩提，应当善知众生的根性与行为，对一切众生安住于平等心、无碍之心，对一切法常无染著，舍弃一切所有、修持净戒、安住忍辱、发起精进、入于诸禅定、如实观察一切法性。电得！菩萨圆满这样的六法，迅速能证得阿耨多罗三藐三菩提。怎样圆满？就是依止一切智智而修行。

#### 诸法伏藏：四无碍辩

“电得！什么是诸菩萨的法伏藏？就是菩萨见一切色，如实了知它本来不生、自性清净。菩萨因为对色得到善巧，便能成就四无碍辩。哪四种？就是义无碍、法无碍、词无碍、乐说无碍。义无碍，是对色的义理没有障碍。什么是色的义理？就是第一义。什么是第一义？就是色不可得。成就这样的第一义智，名为义无碍。法无碍，是对色法如实观察、如实了知，名为法无碍。词无碍，是对色以无碍智、善巧言词种种分别，名为词无碍。乐说无碍，是对色随众生根机开示演说，无染无著，名为乐说无碍。菩萨成就这样的智慧之后，普遍对一切迷惑执著色法的众生，随其性欲，以无功用智如其所应而说法，而对法界不作二相；广说乃至香、味、触、法也是这样。

“电得！这名为诸菩萨摩诃萨的法伏藏。菩萨证得此伏藏之后，为了调伏在这样等境界中迷惑的众生，随其意乐，在每一处，或一劫或超过一劫，以种种言词善巧宣说，也不能穷尽诸处的边际，菩萨的智慧也没有损减，因为不离法界，随顺无二无差别。这名为菩萨善巧演说一切诸法无差别之相。获得这样的法伏藏之后，能为众生如其所应而说法，令他们具足无尽的法财，生死贫穷全都永远断除。电得！这名为菩萨摩诃萨的五种伏藏，是大伏藏、无尽伏藏、遍无尽伏藏、无边伏藏。菩萨成就这样的伏藏，因为圆满殊胜的种种功德，以少许功力迅速得阿耨多罗三藐三菩提。”

#### 法会得益与无功用智

宣说这伏藏法门时，电得菩萨得陀罗尼，五百菩萨得电光明三昧，三万六千天子发阿耨多罗三藐三菩提心。

那时月幢菩萨对佛说：“世尊！如佛所说‘无功用智’，这是什么意思？”佛告诉月幢：“若有菩萨在善法中身心相应，攀缘造作，这名为功用。若有菩萨身心调柔，无念、无依，远离修行之相，因为他成就往昔的愿智，在亿千佛刹中所作的种种示现，而对法界也没有动摇；常演说法，而没有少许法相；以四摄法成熟众生，也没有众生可度；庄严清净一切诸佛刹土，而也不见不净的佛刹；常念诸佛，不观色相；游历诸佛刹，不离法界。这名为菩萨的无功用智。菩萨因为成就这样的智慧，满足众生的一切希望，而对所作之事也没有染著。”

那时世尊宣说这无功用智时，三千大千世界六种震动，释提桓因与忉利天众在上方空中雨下曼陀罗花、优钵罗花、拘物头花、波头摩花、分陀利花、栴檀末香，散在佛上。天鼓自鸣，大光明遍照，是往昔未曾见过的，遇到这光明的众生身得清凉。

【按】“分陀利”之“分”，明本作“芬”。

#### 流通

那时世尊告诉电得菩萨说：“过去的如来、应、正等觉，都在此处开示演说这样的法门。未来诸佛出世时，也将在此处开示演说这样的法门。现在无量阿僧祇世界中的诸佛如来，为了使这法门不断绝，放出大光明。”

那时长老阿难从座而起，偏袒右肩，右膝著地，合掌向佛说：“世尊！应当怎样称呼此经？我应当怎样奉持？”佛告诉阿难：“此经名为‘无尽伏藏’，也名为‘说一切法无差别相’，以这名字你应当奉持。”

佛说此经之后，电得菩萨、长老阿难以及四众，一切世间的天、人、阿修罗、乾闼婆等，听闻佛所说，都大欢喜，信受奉行。
