#### 能摄四天王及其眷属

佛说：“无边庄严！什么是能摄四天王及其眷属的句呢？”随即说偈颂道：

```
于彼住夜叉，无忿无扰乱，
多闻之长子，及父咸恭敬。
删阇耶夜叉，及诸胜军旅，
而常拥护彼，爱乐此法者。
持国大神王，恒将诸眷属，
彼亦常卫护，善说此经者。
丑目之眷属，自身与军众，
若能住此教，一切当拥护。
增长王亦尔，军旅及诸众，
爱乐此法者，普皆作卫护。
```

（大意：住在那里的夜叉，没有忿怒，没有扰乱，多闻天王的长子以及父亲都恭敬此法。删阇耶夜叉以及种种殊胜的军旅，常常拥护那些爱乐此法的人。持国大神王常率领诸眷属，也常常卫护善说这部经的人。丑目天王的眷属，自身与军众，如果有人能安住于这个教法，他们都会拥护。增长天王也是这样，带着军旅与诸众，对爱乐此法的人普遍作卫护。）

```
幢幡大幢力，此住于东方，
大称罗刹斯，彼皆摄入此。
而于此法门，有能受持者，
自身与眷属，常亲近守护。
蓝婆毘羯遮，并及悉驮多，
奚离末底等，此皆住南方。
侍卫于帝释，彼皆摄入此，
拥护益精气，一切智者说。
剑离三蜜多，及伽罗系翅，
并与蜜室多，名称罗刹斯，
皆住于西方，此等皆摄来，
说法了义者，一切常拥护。
实谛有实谛，名称罗刹斯，
深信于此法，彼住于北方。
佛为拥护故，摄彼来入此，
由如来威力，一切合掌住。
```

（大意：幢幡、大幢力，住在东方，以及大称罗刹女，他们都被摄入这里；对于这个法门，有能受持的人，他们自身与眷属常亲近守护。蓝婆、毗羯遮以及悉驮多、奚离末底等，都住在南方，侍卫帝释，他们都被摄入这里，拥护并增益精气，这是一切智者所说。剑离、三蜜多以及伽罗系翅，和蜜室多等有名称的罗刹女，都住在西方，这些都被摄来，对于宣说了义的说法者，一切都常加拥护。实谛、有实谛等有名称的罗刹女，深信这个法，住在北方。佛为了拥护的缘故，把她们摄来这里，由于如来的威力，一切都合掌而住。）

#### 十八不共法

“无边庄严！如来安住于十八种不共法中，能善了知众生的心行，并能了知心所摄的诸法。无边庄严！什么名为十八佛不共法呢？

“无边庄严！就是：如来从某夜现觉阿耨多罗三藐三菩提，乃至入于无余涅槃，在这中间：没有误失，没有卒暴之音，没有忘失之念，没有不择之舍，没有种种异想，没有不定之心；精进无退，念无退，志欲无退，等持无退，慧无退，解脱无退，解脱智见无退；一切如来的身业，以智为前导，随智而转；一切如来的语业，以智为前导，随智而转；一切如来的意业，以智为前导，随智而转；如来的智见对于过去世无著无碍，如来的智见对于未来世无著无碍，如来的智见对于现在世无著无碍。

“无边庄严！如来由于成就这十八不共法，由于无量的智见与力都已成就，能开演这陀罗尼门清净法品：为了令一切不信的有情生起清净的信心，为了令有清净信心的人在这个法门中得到清净的智慧。无边庄严！如来随其所乐欲，以种种无量的语言分别解说这陀罗尼门，也不能说尽这陀罗尼门断疑理趣的百分之一，乃至俱胝百千分、算数分以及譬喻分。为什么呢？这些法门是无量之门、不可思议之门，这所有的门能令一切智智转起的缘故。

#### 由内清净故一切法清净

“如果善男子、善女人等，发心求趣大菩提而想随我正确修学的，想要拥护我的法教的，想要受持诸如来无量法藏的，就应当在这个法中勤加修习，志乐精进，安住于不放逸，不执著三界；对于一切智智之心的作意善加持守的，对于色缘的清净善巧善加修习的，对于受、想、行、识的清净善巧勤加修习的，对于实谛之句出生清净而勤加修习的——在诸法中应当乐求种种清净之智。

“无边庄严！由于内清净，所以一切法清净；由于内寂静，所以一切法寂静；由于内寂灭，所以一切法寂灭；由于内无所取，所以一切法无所取；由于内不住，所以诸法不住；由于内灭，所以一切法灭；由于内无所作，所以一切法无所作；由于内无来去，所以一切诸法也无来去。

“无边庄严！这些门句，令诸菩萨的内心清净而转；由于外的本性无分别，所以不起分别，然而能受持清净的陀罗尼门。他们舍离贪恚，心不贡高，为诸如来所称叹，在众生中最为殊胜，作无上之主；将能证得无碍智的言说与欢喜的辩才；在前际与后际得到清净之智，能普遍记别，并能随念中道之性；并能证得无生法忍，能证缘起之愿的殊胜性；对于种种愿能普遍清净，将能遍持不共一切的法智善巧；所发的语言，大众都信受，将来能降大法雨。

【按】“遍记䇷”之“䇷”字，先前电子文本未能显示，今据《大正藏》补出；宋、元、明、宫本作“别”。

#### 无生智门

“无边庄严！菩萨由于得到陀罗尼，必定将证得无生法忍，得到一切法的清净之智，并能出生这样的法智，即一切法不生不灭。又能证得这样的法智：虚妄之生，生而不成就；不成就的，就会散坏；散坏之法，就无所趣；这一切法都是灭坏之门。这灭坏之门同于无生之相；如果是无生，那就没有灭。如实观察一切诸法远离之相后，就不执著，就不戏论。无边庄严！这就是诸菩萨无生智门的善巧观察，能进入这些陀罗尼，由此能迅速获得无生忍，辩才具足。”

#### 偈颂

这时，世尊想要重新宣说这个义理，而说偈颂道：

```
若法虚妄生，生已必灭坏，
诸法离于有，于谁可遍持？
诸法既非有，无有无可取，
若法不可得，于何而遍持？
若不了诸法，自性不可得，
彼则行于相，不得陀罗尼。
诸法如虚空，由是说开示，
虚空及开示，二俱无所有。
此二离于有，诸法亦空无，
如是解法者，彼能获总持。
随觉无初始，不分别中后，
诸法离分别，一切悉空无。
若处无坚实，不实亦非有，
依诸法真理，云何得遍持？
如是了诸法，自性无所有，
我今略说彼，得清净总持。
```

（大意：如果法是虚妄而生的，生了之后必定灭坏；诸法远离于有，对谁可以遍持呢？诸法既然不是有，没有“有”可以取；如果法不可得，又在何处遍持呢？如果不了知诸法的自性不可得，他就是行于相，得不到陀罗尼。诸法犹如虚空，因此才说“开示”；虚空与开示，二者都无所有。这二者远离于有，诸法也是空无的，这样理解法的人，就能获得总持。随觉没有初始，不分别中与后，诸法远离分别，一切都是空无的。如果某处没有坚实，不实的也不是有，依照诸法的真理，又怎么能得遍持呢？这样了知诸法的自性无所有，我现在简略地说，他就能得到清净的总持。）

```
诸法如虚空，亦等于空旷，
以慧常观察，彼能获总持。
诸法无所有，不生亦不起，
无有无可取，此云何遍持？
一切法无相，自性无戏论，
一切皆离相，说法无所有。
若能如是解，一切法如理，
彼则无分别，而能得遍持。
诸法以自性，无故不可得，
解了无有义，彼成就总持。
若如是观察，一切法不染，
智不分别空，彼能持诸法。
无常义空义，苦义及厌离，
若以慧了知，彼智得增长。
示说无所取，涅槃如理义，
坚无分别意，亦不分别法。
由是能受持，诸法不坚固，
无有无所取，寂静空难见。
若解法已说，于说不分别，
无著无分别，能持此法门。
若解了相已，能了于无相，
彼亦于诸法，不起舍离想。
```

（大意：诸法犹如虚空，也等同于空旷，以智慧常常观察，他就能获得总持。诸法无所有，不生也不起，没有“有”可以取，这又怎么遍持呢？一切法无相，自性没有戏论，一切都离于相，所说之法无所有。如果能这样理解一切法如理，他就没有分别，而能得到遍持。诸法以自性而言，因为本无所以不可得，理解了无有之义，他就成就总持。如果这样观察一切法不染，智慧不分别空，他就能受持诸法。无常之义、空之义、苦之义以及厌离之义，如果以智慧了知，他的智慧就得增长。示说无所取、涅槃的如理之义，坚固而无分别之意，也不分别于法。由此能受持诸法不坚固，无有无所取，寂静而空，难以见到。如果理解法之后宣说，对于所说不作分别，无著无分别，就能受持这个法门。如果理解了相之后，能了知于无相，他对于诸法也不生起舍离之想。）

```
彼能了此义，正觉之所说，
善巧说秘密，彼能随我觉。
若如理观察，无量一切法，
彼舍离诸量，能觉此理趣。
若能观察法，无名及无相，
能了达此义，彼能增长忍。
诸愿与殊胜，及如理观察，
所愿并诸色，不住能违彼。
了此法门义，能如理观察，
于诸法理中，彼亦无疑惑。
若以慧观察，一切诸法相，
决定解了者，彼则入无相。
彼于此理趣，能了善安住，
如是无畏者，能速证佛法。
于法不戏论，平等无分别，
了法相应已，于厌离无惑。
于灭不分别，蕴尽寂静义，
彼于法平等，得如理辩才。
能修习慈悲，利益诸众生，
善住相应者，彼觉了无上。
若离众生相，能了法无我，
法无戏论义，如理不戏论。
```

（大意：他能了知这个义理，这是正觉所说的善巧秘密之言，他能随我而觉悟。如果如理观察无量的一切法，他舍离种种量，能觉悟这个理趣。如果能观察法无名、无相，能了达这个义理，他就能增长忍。种种愿与殊胜，以及如理观察，所愿以及种种色，不住于此，就能不违于彼。存疑。了知这个法门的义理，能如理观察，对于诸法的道理，他也没有疑惑。如果以智慧观察一切诸法之相，决定理解的人，他就进入无相。他对于这个理趣，能了知而善安住，这样无畏的人，能迅速证得佛法。对于法不作戏论，平等无分别，了知法与相应之后，对于厌离没有疑惑。对于灭不作分别，以及诸蕴尽灭的寂静之义，他对于法平等，就能得到如理的辩才。能修习慈悲，利益众生，善住于相应的人，他就觉了无上菩提。如果远离众生之相，能了知法无我，以及法无戏论之义，就如理而不戏论。）


```
若闻此法已，能速得净信，
彼当见正觉，弥勒两足尊。
彼令我欢喜，于此众会中，
若有闻此法，彼能作贤爱。
敬爱如来者，是则无破坏，
由闻此法已，能为善贤爱。
若于贤劫中，欲见诸如来，
修学此法门，能令诸佛喜。
无量寿威光，阿閦大名称，
若欲见彼者，当学此法门。
若欲成菩提，寂静最胜法，
或求转轮位，当学此法门。
若乐求最上，善巧总持门，
当于此法学，常应不放逸。
若欲成广大，最上殊胜愿，
求证菩提者，当学此法门。
```

（大意：如果听闻这个法之后，能迅速得到清净的信心，他将见到正觉——弥勒两足尊。他令我欢喜；在这众会中，如果有人听闻这个法，他就能成为贤善可爱之人。敬爱如来的人，他的信心就没有破坏，由于听闻这个法，能成为善妙贤爱之人。如果在贤劫之中想要见到诸如来，就修学这个法门，能令诸佛欢喜。想要见到无量寿佛那样的威光、阿閦佛那样的大名称，就应当修学这个法门。如果想要成就菩提这寂静最殊胜之法，或者求转轮王之位，就应当修学这个法门。如果乐求最上的善巧总持之门，就应当在这个法中修学，常常不放逸。如果想要成就广大、最上、殊胜的愿，求证菩提的人，就应当修学这个法门。）

```
此经之所说，陀罗尼法门，
能开示诸法，此印最无上。
诸法内真实，以总持开示，
此虚空法门，善决无边义。
所说诸善门，此法能开示，
总持义善巧，陀罗尼力故。
总持说为慧，能持一切法，
总持义善巧，以慧能了知。
于此异多释，已善说佛法，
以义正开示，无上菩提分。
差别智善巧，于斯正开示，
若于此法学，证无上菩提。
于此教开示，无上善法门，
得方便智已，应当说此法。
未曾说诸法，此无上种性，
于此义当学，开示甘露句。
智者若欲求，诸佛无碍慧，
若于此义学，当获最上智。
```

（大意：这部经所说的陀罗尼法门，能开示诸法，这个法印最为无上。诸法内在的真实，以总持来开示；这虚空法门，善能决定无边的义理。所说的种种善门，这个法能开示，因为总持之义的善巧，是陀罗尼之力的缘故。总持被说为智慧，能持一切法；总持之义的善巧，以智慧能够了知。在这里以多种异名解释，已经善说了佛法，以义理正确开示无上的菩提分。差别之智的善巧，在这里正确开示，如果在这个法中修学，就能证得无上菩提。在这个教法中开示无上的善法门，得到方便之智后，应当宣说这个法。这是未曾宣说的诸法，是无上的种性，应当在这个义理中修学，开示甘露之句。智者如果想求诸佛的无碍之慧，如果在这个义理中修学，将获得最上的智慧。）

```
我于往昔时，无量无数劫，
若不学此法，不证寂理趣。
由我曾供养，无量百千佛，
为是能了知，说此无上法。
我为诸众生，作无边义利，
汝等应当作，得此陀罗尼。
若能了知此，陀罗尼门印，
智者由一句，能入此法门。
我智慧无上，亦无有数量，
由我具智蕴，能开示此法。
智者于此求，随觉菩提义，
于此义法门，无畏当勤学。
智者若欲求，广大智慧性，
于佛生尊重，当学此法门。
若欲转法轮，及吹大法螺，
智者应如理，当学此法门。
若欲放光明，普照无边际，
求于佛法时，于此如理学。
```

（大意：我在往昔之时，无量无数劫中，如果不学这个法，就不能证得寂静的理趣。由于我曾经供养无量百千尊佛，因此能够了知，宣说这无上之法。我为众生作无边的义利，你们也应当这样作，得到这陀罗尼。如果能了知这陀罗尼门之印，智者由一句就能进入这个法门。我的智慧无上，也没有数量，由于我具足智蕴，能开示这个法。智者在这里求随觉菩提之义，对于这个义理法门，应当无畏地勤学。智者如果想求广大的智慧之性，对佛生起尊重，就应当修学这个法门。如果想要转法轮，以及吹大法螺，智者应当如理，修学这个法门。如果想要放出光明，普照无边际，在求佛法时，就在这里如理修学。）

```
于天人世间，若欲为上首，
彼可学此经，决定一切法。
欲求广大智，发起诸功德，
乐求佛慧时，于此应随学。
欲开示法门，乐求于最胜，
无戏论佛智，于此义当学。
若欲乐开示，无碍智所说，
修学此法已，应说甘露句。
若欲照俱胝，无量无边界，
彼等于此教，应当善修学。
此无上法门，能净除诸法，
一切法清净，于此经中说。
种智两足尊，演此广大法，
于为菩萨说，此经最无上。
```

（大意：在天人世间，如果想要成为上首，他可以修学这部经，决定一切法。想求广大的智慧、发起种种功德，乐求佛的智慧时，就应当在这里随学。想要开示法门，乐求最殊胜、无戏论的佛智，就应当在这个义理中修学。如果想要乐于开示无碍智所说的法，修学这个法之后，就应当宣说甘露之句。如果想要照耀俱胝无量无边的世界，他们就应当在这个教法中善加修学。这无上的法门，能清净一切诸法，一切法的清净，就在这部经中宣说。具一切种智的两足尊，演说这广大之法，在为菩萨所说的经中，这部经最为无上。）

#### 受持流通

佛告诉无边庄严：“所以，诸菩萨对这个法教生起爱乐之后，为了摄持这个法令其久住，又为了哀愍众生，对这个法教应当书写、受持、读诵。无边庄严！如果又有人在那时听闻这个法之后，对如来以爱乐之心常常思念，那些人将得到如来无边法藏的种种陀罗尼，辩才具足，对一切法迅速得到自在，能具足摄受不可思议的佛刹庄严以及声闻、菩萨。无边庄严！如果诸菩萨安住于一切法无戏论，由于陀罗尼清净之门，这些法门就常得现前，都能摄受无量不可思议的殊胜功德。无边庄严！这就是第三陀罗尼门清净法品。

“无边庄严！在那后来之时，如果有菩萨想要随我修学这陀罗尼法门，就应当亲近善友，远离恶友；为了普遍拥护这些法门，应当舍弃身命，受持陀罗尼清净法印。譬如迦利邸迦月圆满时，光明照耀，在众星之中最为殊胜。同样，这陀罗尼印三品所摄受的所有法门也是这样，在一切契经之中，这个法的光明最为殊胜，一切菩萨都大加尊重，所以能出生无量的辩才。

【按】“迦利邸迦月”，慧琳《一切经音义》卷第十一说（解释）：是梵语，唐言昴星；每年九月十五日，月临昴宿，所以取这颗星作为九月之名；经中引秋月圆满、光明澄净，以比喻真言的妙净。

“这无量的辩才，应当知道就是不放逸之地。什么是不放逸之地呢？就是对这个法作意思惟，如理观察，不生妄念，这样能令遍忍清净。如果诸菩萨精勤志求不放逸，对这个法门应当善加修习。为了令这个法得以久住，心常谦下，尊重正法，书写经卷，不离身手；见到有志乐希求正法的人、发心趣向大菩提的人，应当为他们开示流布，教授读诵、书写经卷，乃至随其义理而为解释。对于所受持的所有法门，不应藏匿，而应发愿：‘愿众生得到这无上佛法的利益，我们要令一切众生对诸佛之法常不缺减。’这样的菩萨对法没有吝惜，常乐施予他人；对义理不秘藏，全都为人宣说，没有少许法门不开示的。无边庄严！为了利益安乐众生，你应当受持这法门品的陀罗尼门能清净之句。”

#### 付嘱阿难陀

这时，世尊又告诉尊者阿难陀说：“你应当受持这个法门品。我的诸弟子中承事我的，也应当受持这样的经典。”

这时阿难陀对世尊说：“以佛的神力，我已经受持了。我由于成就这个法门，无量的法门都得以现前。”

佛说：“阿难陀！正是这样，正是这样，如你所说。由于佛的威力以及这个法门普遍清净的缘故，所有受持这个法门的人，以及亲自承事我而能受持的人，无量的法门都得以现前。所以，阿难陀！你应当受持如来法教的无量法藏。”

宣说这个法时，在众会中，无量的菩萨随即获得大法光明；由于得到法的光明，无量诸佛所说的法门都得以现前，并得以接近一切智智，如其所乐求的殊胜之愿庄严，都能成就。

“阿难陀！你看诸法的本性甚深，像这样，如来能对无名相之法作名相之说，又能开示诸法的本性，也能净除，令人见到清净；虽然说诸法，却没有法可说，也没有能说者。”

佛说：“阿难陀！如果能这样观察诸法之性，便能生起无量的智慧。”宣说这个法时，无数的菩萨证得无生法忍，无量的众生发起阿耨多罗三藐三菩提心，将在阿僧祇劫证得无上正等菩提，又能出生无量的辩才。

这时，世尊加持这陀罗尼门，放出大光明，那光明普照无量无边诸佛世界。由于这光明，那些世界所有的菩萨都得以听闻这陀罗尼；听闻这个法之后，能普遍成熟菩提法分。在那里又有无量的众生都发起阿耨多罗三藐三菩提心。在那时，一切众生都得到安乐。这时又有诸天，在大众会的诸菩萨中降下天上的波头摩花，唱这样的话：“愿一切众生得佛的智慧。”

#### 经名与流通

这时，无量辩才菩萨对佛说：“世尊！这个法门应当叫什么名字？我应当怎样奉持？”

佛告诉无量辩才菩萨说：“这个法门名为《陀罗尼王》，也名为《陀罗尼印》，也名为《三品所摄善巧》，你应当受持。这是无边辩才、摄一切义的善巧法门。由于这个法门，能照了一切诸法，断除一切疑惑，所以诸菩萨对这个法门应当奉持。”

这时，一切大众为了供养正法，把五色花散在佛的身上。佛说完这部经，诸菩萨摩诃萨、一切众会以及天、人、阿修罗、乾闼婆等，听闻佛所说，都大欢喜，信受奉行。

【按】无边庄严会至此终，凡四卷三品：无上陀罗尼品、出离陀罗尼品、清净陀罗尼品。
