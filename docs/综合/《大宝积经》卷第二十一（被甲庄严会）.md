# 《大宝积经》卷第二十一（被甲庄严会）

唐·三藏菩提流志 奉诏译

## 被甲庄严会第七之一

### 无边慧菩萨请问

如是我闻：一时，佛住在王舍城迦兰陀竹林，与大比丘众以及诸菩萨摩诃萨在一起，他们都是从种种佛刹前来集会的。那时，世尊为无量百千大众所围绕，受他们供养恭敬。

这时，大众中有一位菩萨摩诃萨名叫无边慧，即从座起，偏袒右肩，右膝着地，稽首作礼，合掌向佛，说道：“世尊！我有少许疑问要请问如来，愿您垂允听许，为我宣说。”

那时，无边慧菩萨摩诃萨说偈道：

```
大雄大丈夫，世间无与等，
我为众生故，少疑当请问。
不起师子座，现身遍十方，
一切异论中，无能倾动者，
智藏无边际，诸力无有量，
世尊一一力，普能度世间，
善住一切智，善住于十力，
无畏大师子，最胜无上尊，
十八不共法，如来之所有，
照明于世间，摧伏诸外道，
了知一切法，是故无过上，
无失大导师，我疑当请问。
```

（大意：大雄大丈夫，世间无与等同；我为了众生的缘故，有少许疑问要请问。您不起师子座，而现身遍于十方；在一切异论之中，无人能够倾动您。您的智慧宝藏无有边际，诸力无有限量，世尊的每一种力，都能普度世间。您善住于一切智，善住于十力，是无畏的大师子，最胜无上的至尊；十八不共法，是如来所具有的；您照明世间，摧伏诸外道，了知一切法，所以无人能超过您。您是无有过失的大导师，我有疑问要请问。）

```
无边离垢智，大海不动智，
境界无碍智，我疑当请问。
世尊善修集，于道无疑惑，
安隐大导师，我疑当请问。
已度诸暴流，已断诸结缚，
能拔众毒箭，我疑当请问。
已破无明㲉，已息烦恼热，
清凉善安住，我疑当请问。
无畏无上智，无著无碍智，
法海一切智，如来已证得。
佛无量功德，智证悉圆满，
尽一切有漏，破诸烦恼见。
世尊多积集，无量大功德，
不思议法王，我疑当请问。
世尊殊胜智，普能照世间，
演畅法光明，无边功德海。
导师法光故，遍照于世间，
是故世间中，佛法光明现。
法海一切智，辩才无有上，
精进不思议，清净离诸见。
佛眼无边故，智境亦无边，
世间无等尊，我疑当请问。
```

（大意：您具有无边离垢之智、大海般不动之智、于境界无碍之智，我有疑问要请问。世尊善于修集，对于道没有疑惑，是安稳的大导师，我有疑问要请问。您已渡过诸暴流，已断除诸结缚，能拔出众生的毒箭，我有疑问要请问。您已破除无明之壳，已止息烦恼之热，清凉而善安住，我有疑问要请问。无畏的无上智、无著无碍之智、法海般的一切智，如来都已证得。佛具无量功德，智慧证悟都已圆满，尽除一切有漏，破除诸烦恼之见。世尊积集了无量大功德，是不可思议的法王，我有疑问要请问。世尊殊胜之智普照世间，演畅法的光明，是无边功德之海。由于导师法的光明遍照世间，所以世间之中有佛法的光明显现。您具法海般的一切智，辩才无上，精进不可思议，清净而远离诸见。由于佛眼无边，所以智慧的境界也无边，您是世间无等之尊，我有疑问要请问。）

【按】“无明㲉”之“㲉”，先前电子文本未能显示，今据《大正藏》补出，即卵壳。

```
法王大牟尼，能断众生惑，
导师我当问，愿随其意乐。
我观一切处，天上及人间，
无有等如来，普遍照明者。
善住诸功德，庄严大丈夫，
不思议法王，仙中照曜者。
譬如大雪山，众宝端严处，
世尊安法座，端严亦如是。
妙音大精进，能宣悦意声，
众生若得闻，善根悉清净。
世尊人中胜，时演法光明，
以是诸众生，随意便开觉。
知时知众会，知人大导师，
敷演法光明，以时智慧者。
梵音大精进，愿赐清净言，
如天雨大地，法润遍沾洽。
世尊处众会，普宣法雨已，
于此法悕望，众生皆满足。
最上胜安住，如王处妙高，
惠施诸众生，能令众欢喜。
大雄两足尊，不思议境界，
一切诸众生，无有能知者。
无量大丈夫，众会已和合，
依怙大牟尼，志求佛境界。
我于佛境界，发趣故来集，
导师无碍智，如何疾开觉。
我随其意乐，瞻颜欲请问，
世尊愿开示，为断诸疑惑。
若闻无上法，便得心欢喜，
踊跃充遍身，能断众疑网。
```

（大意：法王大牟尼能断众生的疑惑，导师啊，我要请问，愿随我的意乐而答。我观察一切处，天上与人间，没有能与如来等同、普遍照明的。您善住于诸功德，是庄严的大丈夫，是不可思议的法王，是诸仙中照耀者。譬如大雪山以众宝端严其处，世尊安坐法座，端严也是如此。您以妙音大精进，能宣说令人悦意之声，众生若能听到，善根都得清净。世尊是人中最胜者，适时演说法的光明，因此诸众生随其意乐便得开悟。您知时、知众会、知人，是大导师，适时敷演法的光明，是以时宣说的智者。您具梵音、大精进，愿赐予清净之言，如天雨降于大地，法的滋润普遍沾洽。世尊处于众会中普降法雨之后，众生对此法的希望都得满足。您最上殊胜而安住，如国王处于妙高山，惠施诸众生，能令大众欢喜。大雄两足尊不可思议的境界，一切众生无人能知。无量的大丈夫众已经和合集会，依怙大牟尼，志求佛的境界。我为了佛的境界发心而来集会，导师具无碍智，如何能迅速开悟？我随自己的意乐，瞻仰尊颜想要请问，愿世尊开示，为我断除诸疑惑。若听闻无上之法，便得心中欢喜，踊跃遍满全身，能断除众多疑网。）

```
法王无上尊，一切智无畏，
一切知见者，我疑当请问。
佛于一切法，无有少疑惑，
精进大导师，我疑当请问。
无上断疑者，于法不疑惑，
无边功德海，我疑当请问。
无边大光明，无边大功德，
无边清净智，我疑当请问。
无边精进智，无边境界智，
无边饶益智，我疑当请问。
世尊无边智，离边及无边，
能断一切疑，我疑当请问。
不思议法王，垂哀听我问，
见许我当问，牟尼为宣说。
请问一切智，释迦名称尊，
若垂听许我，愿决我疑网。
```

（大意：法王是无上之尊，具一切智而无畏，是一切知见者，我有疑问要请问。佛对一切法没有少许疑惑，是精进的大导师，我有疑问要请问。您是无上的断疑者，对法没有疑惑，是无边的功德海，我有疑问要请问。您有无边的大光明、无边的大功德、无边的清净智，我有疑问要请问。您有无边的精进智、无边的境界智、无边的饶益智，我有疑问要请问。世尊有无边的智慧，远离边与无边，能断一切疑惑，我有疑问要请问。不可思议的法王啊，请您垂哀听我请问；若蒙您允许，我就请问，愿牟尼为我宣说。我请问具一切智、名称远扬的释迦尊，若蒙垂允听许，愿您决断我的疑网。）

### 世尊许问

那时，世尊告诉无边慧菩萨摩诃萨说：“无边慧！你现在对我渴仰志求，想向如来问多少事？若有所问，我当为你解说。”

那时，世尊说偈道：

```
告无边慧，汝欲何问，
悉应问之，我当解说。
如彼所问，一一发明，
随其乐欲，速为开示。
我为汝说，一切无疑，
如汝志求，称汝所问。
汝今时问，如时如义，
以时问故，我决定说。
如汝意乐，问所应问，
我皆随顺，为汝说之。
汝今时问，我亦时说，
断汝疑网，当得无疑。
我为法王，了义究竟，
于一切法，得无疑惑。
我于诸法，正觉难思，
如众生意，所问为说。
我于诸法，悉无有疑，
时而问者，速当为说。
我时为说，无有疑惑，
如其意乐，释彼所疑。
我常了知，时及众会，
诸众生等，意趣所同。
亦常观察，一切众生，
有欲无欲，彼皆明见。
```

（大意：告诉无边慧：你想问什么，都应当问，我当为你解说。如你所问，一一为你阐明，随你的乐欲，迅速为你开示。我为你宣说，一切都无疑惑，如你的志求，与你所问相称。你现在应时而问，应时如义；因为应时而问，我决定为你宣说。如你的意乐，问所应问的事，我都随顺，为你宣说。你现在应时而问，我也应时而说，断除你的疑网，使你得到无疑。我是法王，于了义究竟，对一切法都没有疑惑。我对于诸法，正觉难以思议，如众生的心意，随其所问而为宣说。我对于诸法全无疑惑，应时而问的，我当迅速为他宣说。我适时为人宣说，没有疑惑，如其意乐，解释他的疑问。我常了知时节与众会，以及诸众生意趣的异同；也常观察一切众生，有欲还是无欲，我都明见。）

【按】“一一发明”，宋、元、明本作“发问”，宫本作“明问”。“意趣所同”之“所”，宋、元、明、宫本作“不”。

```
若有智者，能善修行，
我皆以时，正法开悟。
若无智者，愚痴迷乱，
彼无慧明，不尊重法。
若无尊重，于法不求，
虽闻此法，无大明智。
法善巧者，于法希求，
若闻此法，得大明智。
乐大乘者，求人中尊，
闻斯法已，得大明智。
佛无上智，不思议智，
而发趣者，闻皆满足。
乐无碍智，求最上尊，
彼闻此法，得大饶益。
若有智性，求不思议，
彼闻此法，得无上智。
若有众生，求佛道场，
转无上轮，得法欢喜。
爱乐精进，于法尊崇，
闻离垢法，欣然踊跃。
若有众生，乐善修习，
以法光明，说无上法。
荷诸重担，无边策修，
彼闻法已，欢喜充满。
若有希愿，善法思惟，
于彼慈哀，为之开释。
```

（大意：若有智者能善于修行，我都适时以正法开悟他。若是无智的人，愚痴迷乱，他没有智慧的光明，不尊重正法；若不尊重，就不求法，即使听到此法，也没有大的明智。善巧于法的人，对法有所希求，若听到此法，就得到大的明智。乐于大乘、求人中尊的人，听到此法后，得到大的明智。对佛的无上智、不可思议智而发心趣向的人，听到后都得满足。乐求无碍智、求最上尊的人，他听到此法，得到大饶益。若有智慧的根性、求不可思议法的人，他听到此法，得到无上智。若有众生求佛的道场、转无上法轮，就会因法而得欢喜。爱乐精进、尊崇正法的人，听到离垢之法，欣然踊跃。若有众生乐于善修习，以法的光明宣说无上法，荷负诸重担，无边地策励修行，他听到法后，欢喜充满。若有人有所希愿，思惟善法，我对他慈哀，为他开释。）

【按】“得法欢喜”之“得”，宋、元、明、宫本作“闻”。

```
哀愍汝等，随汝所问，
我能决定，当断汝疑。
我多千岁，修行善巧，
疑惑已除，知汝意乐。
若有疑者，恣汝所问，
当为汝说，断诸疑惑。
若有疑者，恣汝所问，
如其乐欲，我当说之。
若有疑者，恣汝所问，
我住于法，得无动摇。
```

（大意：我哀愍你们，随你们所问，我能决定，当断除你们的疑惑。我在多千年中修行善巧，疑惑已经除尽，知道你们的意乐。若有疑惑的人，任你们发问，我当为你们宣说，断除诸疑惑。若有疑惑的人，任你们发问，如你们的乐欲，我当宣说。若有疑惑的人，任你们发问，我安住于法，不会动摇。）

### 无边慧菩萨广问

那时，无边慧菩萨摩诃萨对佛说：“世尊！如来、应、正遍知！我对菩萨乘有少许疑问，现在要请问。

“什么样的善丈夫，远离怖畏，一心正念，为诸众生披大甲胄，又以种种庄严来庄严这大甲胄，生起大爱乐而尊重它，以不放逸心乘此大乘，行于大清净平正之道——这道没有土堆、瓦石、荆棘、众恶杂秽与诸见的稠林，也没有毒刺、苦恼与坑陷，也没有系缚、执著、怖惧与艰难；正直无曲，是如理的平坦之道、无障碍之道；剪除诸稠林，撕裂一切罗网，远离黑暗，蠲除爱著，因为舍离和合（执著）的缘故，而发心趣向阿耨多罗三藐三菩提？

“世尊！如来、应、正遍知！我为了这个意义而作此问：什么样的善丈夫？什么样的大甲胄？披这甲胄，乘于大乘，以这大道而发心趣向？

“世尊！应当宣说诸菩萨摩诃萨的甲胄庄严：安住于道，安住于诸法理趣的善巧；因为安住于诸法理趣的善巧，而能生起诸法理趣善巧的光明；由于法的光明，不舍甲胄，乘于大乘，以不退转的精进之力、不忘失的念根、相续的慧力，迅速成就对法界理趣的分明善巧，前往道场，转于法轮，为诸众生演说佛法，使一切众生如其所愿、如其所发心趣向而解脱生死。

“世尊！如来、应、正遍知！对于这大乘，我想利益安乐众生，所以问这个意义。世尊！如来是一切知者、一切见者，以什么法成就诸菩萨摩诃萨的一切诸法海印三昧，以这三昧，令诸菩萨摩诃萨乃至未证阿耨多罗三藐三菩提之前仍不退转？世尊！如来的知见成就未曾有之法，是善治众生的智慧之药，所以我请问。”

那时，无边慧菩萨摩诃萨说偈道：

```
为诸菩萨故，我问两足尊，
一切知见者，甚深佛法义。
大乘所修行，何定能发趣？
我今皆请问，饶益诸众生。
云何善丈夫，能被无边甲？
如是被甲已，云何当发趣？
云何起乐欲？云何爱于彼？
云何大精进？云何不放逸？
云何诸菩萨，乘于此大乘？
乘已复云何？此事应当说。
云何乘大乘，发趣菩萨道？
唯愿世尊师，速为我宣说。
云何平正道，平等而发趣？
于诸见稠林，剪伐恒无倦。
于诸境界中，云何得超越？
云何以平等，裂于贪爱网？
云何除黑暗，得大智光明？
彼诸菩萨等，云何当发趣？
云何能观察，远离众结缚？
云何诸菩萨，离缚善安住？
云何诸菩萨，超过大怖畏，
善巧诸法义，发趣于无上？
```

（大意：为了诸菩萨的缘故，我请问两足尊、一切知见者甚深的佛法义理。修行大乘，以什么三昧能发心趣向？我现在都要请问，以饶益诸众生。善丈夫如何能披无边之甲？这样披甲之后，如何发心趣向？如何生起乐欲？如何爱乐于它？如何大精进？如何不放逸？诸菩萨如何乘于此大乘？乘了之后又如何？这事应当宣说。如何乘大乘而发心趣向菩萨道？唯愿世尊导师迅速为我宣说。如何以平正之道平等地发心趣向，对于诸见稠林恒常剪伐而不倦？在诸境界之中，如何得以超越？如何以平等裂破贪爱之网？如何除去黑暗，得到大智光明？那些菩萨等如何发心趣向？如何能观察而远离众多结缚？诸菩萨如何离缚而善安住？诸菩萨如何超过大怖畏，善巧于诸法的义理，发心趣向无上？）

```
菩萨被何等，无边大甲胄？
被斯甲胄已，乘于此大乘。
云何诸菩萨，发趣平正道？
我今所问者，世尊应演说。
菩萨云何得，庄严大甲胄，
庄严无上乘？世尊应演说。
安住于斯道，及彼道庄严，
诸法之善巧，世尊应演说。
云何能了知，法界之理趣，
法善巧光明？世尊应演说。
云何诸菩萨，得此法光明，
究竟一切法？世尊应演说。
云何诸菩萨，得法光明已，
不舍大甲胄，由是而发趣？
云何诸菩萨，乘于此大乘，
精进不退转，由是而发趣？
云何诸菩萨，志念常坚固，
能以智慧力，而得善调伏？
云何得法界，理趣之善巧？
法王不思议，世尊愿宣说。
```

### 佛说菩萨被大甲胄

那时，世尊告诉无边慧菩萨摩诃萨说：“善哉，善哉！无边慧！你往昔供养承事无量诸佛，种植诸善根，积集的诸功德不可称量；对这深法欣求渴仰，以大志乐成就众生，而兴起大悲来问如来。你现在仔细听，好好思念，我当为你宣说诸菩萨摩诃萨以功德成就而发心趣向阿耨多罗三藐三菩提。”

无边慧说：“是的，世尊！我愿意听闻。”

那时，世尊告诉无边慧菩萨摩诃萨说：“无边慧！诸菩萨摩诃萨为阿耨多罗三藐三菩提披甲胄：为了摄取诸众生而披大甲胄；为了诸众生布施清净而披大甲胄；为了诸众生持戒清净而披大甲胄；为了诸众生忍辱清净而披大甲胄；为了诸众生精进清净而披大甲胄；为了诸众生禅定清净而披大甲胄；为了诸众生智慧清净而披大甲胄；为了诸众生获得安乐而披大甲胄；为了对诸众生生起与饶益之事相应之心而披大甲胄；为了对治诸众生的贪瞋痴病而披大甲胄；为了于大功德作善巧而披大甲胄；为了无上智善得圆满而披大甲胄；为了救护诸众生的生死怖畏而披大甲胄；为了显现无等等智善得圆满而披大甲胄。

“为了与这三千大千世界所有的诸魔、魔眷属、魔使者、住于魔业的人，以及行于诸见稠林险径的一切外道——遮罗迦出家者、吠陀、乌摩利迦、路伽耶陀，以及与这些外道相应之辈——交战，而披大甲胄。

【按】“遮罗迦”“吠陀”“乌摩利迦”“路伽耶陀”，都是外道名称的音译。路伽耶陀即顺世外道。

“诸菩萨摩诃萨这样披上大甲胄之后，不舍甲胄，发起大精进，能进入一切众生界中，以忍安住，远离怖畏，不惊、不惧、不动、不乱，而又披上无边甲胄，就是：救护一切众生的甲胄，剪除一切见稠林的甲胄，破诸魔军的甲胄，能授予智慧的甲胄，无边津梁的甲胄，度诸重担的甲胄，增长净信的甲胄，安住尸罗（戒）的甲胄，净治业藏的甲胄，一切清净力藏的甲胄，方便善巧力藏的甲胄，能断一切执著的甲胄，不退不悔的智慧甲胄。诸菩萨摩诃萨披上这样的大甲胄之后，也不舍离，乃至穷尽边际，坚固的精进之力从不动摇，而发心趣向阿耨多罗三藐三菩提。”

那时，世尊说偈道：

```

众生无边故，被甲亦无边。
布施清净故，一切令充悦，
为利诸众生，乃被斯甲胄。
持戒清净故，饶益于世间，
为利诸众生，乃被斯甲胄。
忍辱清净故，勇猛善安住，
为利诸众生，乃被斯甲胄。
精进清净故，成就不退转，
为利诸众生，乃被斯甲胄。
禅定清净故，所行境亦然，
为利诸众生，乃被斯甲胄。
智慧清净故，无漏无过上，
为利诸众生，乃被斯甲胄。
一切诸众生，乐具悉当与，
善知此义故，乃被斯甲胄。
菩萨于众生，能为饶益事，
以清净四摄，普遍诸有中。
若病贪瞋痴，而为对治者，
授诸众生药，所患令消除。
由是诸菩萨，善能被甲胄，

```

（大意：菩萨披甲胄，是为了摄受诸众生；众生无边，所以所披之甲也无边。为了布施清净，令一切众生充足喜悦；为了利益诸众生，才披这甲胄。持戒清净，饶益世间，为了利益众生，才披这甲胄。忍辱清净，勇猛而善安住；精进清净，成就不退转；禅定清净，所行之境也是如此；智慧清净，无漏而无可超过——都是为了利益诸众生，才披这甲胄。一切众生，安乐之具都当给与；善知这个意义，才披这甲胄。菩萨对于众生，能作饶益之事，以清净的四摄普遍于诸有之中。若众生病于贪瞋痴，菩萨作为对治者，给众生授药，使所患消除。由此，诸菩萨善能披甲胄，对功德资粮获得无边的善巧。）

### 甲胄无相不可坏

“又，无边慧！诸菩萨摩诃萨在无量劫中荷负诸重担，披大甲胄；这样的甲胄，魔、魔眷属、魔使者，以及行于邪见稠林恶碛的诸众生等，都不能见到。为什么？因为它没有形色，不可示现，无对、无相、舍相、离相、无有名字的缘故。

“无边慧！假使有飞箭大如须弥山，攒聚锋刃激射，也没有能射中的。假设三千大千世界所有的众生一一都是魔，各有若干魔军眷属，竞相同时发射诸利箭，每支也大如须弥山，他们终究不能毁坏诸菩萨摩诃萨这样的甲胄，乃至不能损伤一根毛端。对于诸菩萨摩诃萨的心意，尚且不能令其生起异念，何况其身。诸菩萨摩诃萨若以一念之心摧伏他们，能令众魔退散消灭；善能安住于这样的甲胄而不动摇，一切众生无能毁坏。为什么？因为它无相，不是诸众生之见所能行到的，所以一切众生不能见知。

“诸菩萨摩诃萨能了知一切法，所以如实知见而披大甲胄，是为了救护诸众生。对于一切法无所执著，是为了饶益诸众生。对于一切法也无所得，所以众生不能见知。

“这样的甲胄，没有形相，没有示现，没有言说，所以不与色相应，不与受、想、行、识相应；不与内相应，不与外相应，不与亦内亦外相应，不与非内非外相应；不与界相应，不与处相应；不与地界相应，不与水界相应，不与火、风、空界相应；不与欲界相应，不与色界、无色界相应；不与有作相应，不与无作相应，不与亦有作亦无作相应，不与非有作非无作相应；不与声闻地相应，不与独觉地相应，不与佛地相应；不与语言之道相应。也不与色之因相应，不与色之相相应；不与受、想、行、识之因相应，不与受、想、行、识之相相应；也不与相、非相相应；也不与一切法相应，也非不相应。没有系缚，没有解脱，也不是算数譬喻所能知的，因为一切法超过诸数的缘故。

“这样的甲胄，对一切法的见都不可得：色之见不可得，受、想、行、识之见不可得，乃至没有少许法之见可得。这样的甲胄，不与一切法相应，也非不相应；不与色相应，也非不相应；不与受、想、行、识相应，也非不相应。对于一切法，无论相应、不相应，都已远离。

“这样的甲胄也没有造作，因为没有作者；也没有相，因为相非实有；没有处所之相，没有和合之相，没有分别，没有动摇，没有攀缘，没有可见之性。披甲胄的人也不可得，这样的披甲也不可见。为什么？诸菩萨摩诃萨披甲胄时，不见有谁在披甲，在何处披甲，从何处披甲；也不见有我能披甲，我所披之甲；也不见有在此处披甲、在他处披甲；也不见有这样披甲所为的众生，因为对一切法无所行、无所有的缘故。

“诸菩萨摩诃萨披这样的甲胄，就是披如来所披的甲胄：身不可得，心不可得，意不可得；因为不可得，所以远离分别。诸菩萨摩诃萨若住于少许法、若得少许法，而现在披甲胄、将来披甲胄，就不应说名为披大甲胄；若心已超过（一切法），才可以说名为披不可思议的大甲胄。

“诸菩萨摩诃萨不是为少数众生而披大甲胄，也不是为一劫的众生而披大甲胄，也不是为百千劫、百千俱胝劫、百千那由他俱胝劫的诸众生而披大甲胄，而是为无量无数劫中的诸众生而披大甲胄，所以说名为披无量的大甲胄。

“诸菩萨摩诃萨披甲胄时，披的是不住众生想的甲胄、不起我想的甲胄、离众生想的甲胄、灭我想的甲胄、知众生性的甲胄、知我性的甲胄、超过想与受的甲胄、知一切法无作相的甲胄、空相的甲胄、无想相的甲胄、无愿相的甲胄、知一切法无生相的甲胄、无灭相的甲胄、知一切法差别性相的甲胄、无差别性相的甲胄、知一切法事相的甲胄、无事相的甲胄。

“无边慧！若住于事而披甲胄，终究不能说名为披大甲胄。因为诸菩萨摩诃萨不住于事而求大智慧，所以说为披大甲胄。”


（大意：在无量千劫中，披上大无边之甲，是为了令众生解脱诸苦恼。这样的大甲胄，魔、魔使以及作诸魔业的人，眼睛都不能看见；以及其余行于诸见稠林的众生，这甲胄不可思议，也不是他们所能见到的。它无色、无形像、无对、无相待，这甲胄不可思议，所以不是眼睛所能见到的。它无名也无相，远离一切相，这甲胄无有边际，所以没有能见其相的人。假如有大如须弥的箭攒聚射来，这甲胄不可思议，令箭自己摧折。世界所有的魔，也用大如须弥的箭，竞相向这大甲胄激射，然而对这大甲胄，连毛端那么一点也不能损伤；这甲胄不可思议，没有能摧坏的。由此，诸菩萨身心没有变异；这甲胄不可思议，谁能倾动呢？若以一念之心摧伏诸魔众，菩萨不可思议，魔军都退散。这样的大甲胄，从未有过动摇，一切众生都没有能看见的；一切众生不知甲胄的相，所以众生的眼睛不能看见。菩萨作为依怙，能知一切法，犹如殊胜的金刚，这才是善于披甲的人。不受取一切法，救护诸众生，随顺诸佛之法，这才是善于披甲的人。甲胄无所取，随顺一切法，甲胄不可思议，这才是善于披甲的人。甲胄没有示现，净治一切法；诸法远离言说，没有能示现的。）

### 大乘无边际

“又，无边慧！这大甲胄名为妙法严具庄严；也名为最上，因为不可破坏；也名为一切法无差别，因为不对少许法作差别。

“诸菩萨摩诃萨披上这甲胄，持大慧力，乘于大乘——最上之乘、无等等乘、大摄受乘、无边摄受乘。一切众生乘此乘的，此乘无不容受，然而此乘不增不减，能令众生安乐而住，也令众生安乐而出离。若有众生乘这决定安乐之乘，就没有身心疲倦劳苦。

“无边慧！此乘映蔽一切世间的天、人、阿修罗、声闻、缘觉以及其余诸乘而当出离。此乘无来、无去，无住、无见、无知，前际不可得，后际不可得，中际不可得，三世平等，犹如虚空，不沾尘染，没有相待，没有障碍，也没有执著；以此乘的缘故，而当出离。此乘无量，因为不可量的缘故；本来是无碍之相，因为不住于相的缘故；最上第一。乘此乘的人没有怯弱之心，而发心趣向阿耨多罗三藐三菩提。

【按】“不离尘染”之“离”，宋、元、明、宫本作“杂”，今从之，译作“不沾尘染”。

“无边慧！此乘如灯，如日月之轮，为诸众生作大光明。这大乘也是这样，光照三千大千世界，无能映蔽，无能障碍，能以无边的大功德海而发心趣向阿耨多罗三藐三菩提。

“无边慧！此乘远离黑暗，能除一切世间之病，超过一切世间之法；它摄受大众生，不是诸下劣之人所能乘的，唯有能披大甲胄的人才能乘。如我所说，在无量劫中救护众生、供养诸佛、以种种善根资粮而清净的人，才能乘此乘。声闻、缘觉以及其余下劣、系缚于世间、与世间相应、或怀增上慢、被慢所调伏的人，以及一切外道无信之辈，尚且不想听闻此乘之名，何况能乘此乘。若有众生游戏于不可思议境界，乘了此乘之后，就如其殊胜之愿，而发心趣向阿耨多罗三藐三菩提。

“无边慧！此乘无有边际，初际、中际、后际都不可了知。此乘的边际已断，边际不可得；无边际就是此乘的边际，无量际就是此乘的边际。

“无边慧！此乘没有边际，也没有中际，没有少许边际可以断除。所说的‘际断’，是以没有少许边际而说为际断，以不分别边际而说为际断，这就名为此乘的际断。边际无所有，说为中际；边际无所有，说为边际；边际无所有，而以边际来说它。在那边际中，边际不可得；因为不可得，所以边际、中际都无边际、无断，而入于际门；因为入于际门，此乘就超过了它，而在那超过之中也无所得。

“无边慧！什么是边际？就是断际与常际。因为落入语言的缘故，边际就不是真正的边际。那断常二际没有边际，因为那边际之相的相是无边的。所说的边际，没有分别；因为分别已断，所以超过边际，远离断常。

“无边慧！有身见的人，就会依止于际门；若没有身见，就不执著于际门。因为不执著，才能超过断常二际。无边慧！断常二际并不真实，只是诳惑人的语言。在三有之中分别二际，对那二际若不摄取、不相应，才能超过。因为断除身见，所以对二际之门没有执著。

“无边慧！若诸菩萨摩诃萨尚未远离身见，就不名为披大甲胄、乘于大乘，对那际门就有执著；即使想要断除边际，也生起断际之想，对前际、后际有所分别。若诸菩萨摩诃萨已经远离身见，这才名为披大甲胄、乘于大乘，对那际门就无所执著；超过二际之后，以安乐之乘而发心趣向阿耨多罗三藐三菩提。

### 得法光明劝众乘此乘

“无边慧！诸菩萨摩诃萨以大慧力，能对一切住于边际的法不断不破，以善巧方便摄取止观，修习无相，得无相之证，就为诸佛授予法的光明。由于法的光明，一切边际都断；对那际断也无所执著，没有少许边际在那际门中，无论相应、不相应，忆念、不忆念；对一切法以善巧方便安住于止观，便获得无边的大法光明。

“由于法的光明，远离黑暗与令人毛竖的怖畏，建立大法幢，发出大梵音，作大师子吼，告诉众生说：‘你们快来，在这大乘、大安乐乘、大调御乘、大发趣乘中，发心趣向阿耨多罗三藐三菩提。’为诸众生演说法的光明；由于法的光明，能令众生披大甲胄，乘此大乘。

“无边慧！诸菩萨摩诃萨对这大乘、这大甲胄不要生起悭吝，应当愿众生发菩提心，披这甲胄，乘这大乘。对这大乘、这大甲胄也不要悭吝，而能辗转劝导诸众生，又愿众生披这甲胄、乘这大乘而得出离。诸菩萨摩诃萨住于这样的修行时，摄取佛国、清净佛国，摄取声闻与诸菩萨的圆满功德，以这无边的大功德海而发心趣向阿耨多罗三藐三菩提。

“无边慧！这大乘等同于法界，此岸与彼岸都不可得，然而能运载一切众生从此岸到达法界之中——无处相应，与法界相应，与甲胄相应。若对这等同法界之乘勤加修习，就能发心趣向阿耨多罗三藐三菩提。

“无边慧！譬如法界没有尘染，无能破坏，无能染污；这大乘也是这样，无坏无染，因为无坏无染，而当趣向一切智智，所以此乘名为大乘。此乘无碍，一切世间的天、人、阿修罗都不能令它退转，因为无所执著，而当趣向一切智智，所以此乘名为大乘。所说的大乘，就是大庄严，一切庄严无不入于这大乘之中。”

### 大乘中的有为庄严

那时，无边慧菩萨摩诃萨对佛说：“世尊！在这乘中，难道有有为的诸庄严吗？”

那时，世尊告诉无边慧菩萨摩诃萨说：“是这样，是这样。无边慧！我随顺世俗，在这乘中也宣说一切有为的庄严。无边慧！如转轮王、帝释、梵王，无不都是从这大乘中出生的。已出生的、将出生的，虽然住于转轮王、帝释、梵王的尊位，却不被生死烦恼的过失所染著，能对诸欲一一衡量，衡量之后就厌舍它们，对出离之道而能了知。

“无边慧！若诸菩萨摩诃萨乘此乘，虽然受生死，在一切处都不被染污，能见过患，能知出离。即使我在这里没有宣说诸法以及诸庄严，以此乘之相，对那些法与庄严也能了知，而发心趣向阿耨多罗三藐三菩提。”

那时，世尊说偈道：

```
大乘无上乘，此乘不思议，
若有乘此乘，彼皆当出离。
是大依止处，此乘不思议，
无量无边际，故名为大乘。
一切诸众生，乘于此乘者，
此乘无有减，亦复无有增。
一切诸众生，乘于此乘者，
安乐而发趣，于中无苦恼。
若诸菩萨等，于此乘发趣，
直进无他行，身心不疲倦；
照明于世间，天人阿修罗，
当于此大乘，无上而发趣；
映蔽诸缘觉，及以声闻乘，
亦于此大乘，无上而发趣。
无来亦无去，无住无前际，
后际及中际，无得无所见。
三世悉平等，犹若净虚空，
此乘亦如是，远离诸烦恼。
此乘无相待，无障无罣碍，
一切悉能救，所向无执著。
此乘无有量，亦无一切相，
自性不可得，无畏不思议。
若有乘此乘，得无所畏者，
乃于佛法中，无障无罣碍。
以此乘发趣，普明于世间，
如日百千光，无时而不照。
此乘不可坏，无能映蔽者，
无量德资粮，无上而发趣。
此乘超世间，出过于三界，
远离诸黑暗，能趣于无漏。
```

（大意：大乘是无上之乘，此乘不可思议，若有人乘此乘，他们都当出离。它是大依止处，此乘不可思议，无量无边际，所以名为大乘。一切众生乘此乘的，此乘不会减少，也不会增加；一切众生乘此乘的，安乐而发心趣向，其中没有苦恼。若诸菩萨等于此乘发心趣向，直进而不行他道，身心不疲倦；照明世间的天、人、阿修罗，当于此大乘无上而发趣；映蔽诸缘觉以及声闻之乘，也于此大乘无上而发趣。此乘无来也无去，无住，无前际、后际与中际，无所得也无所见；三世都平等，犹如清净的虚空，此乘也是这样，远离诸烦恼。此乘没有相待，无障无碍，一切都能救护，所向之处无所执著。此乘无有限量，也没有一切相，自性不可得，无畏而不可思议。若有人乘此乘而得无所畏，才能在佛法中无障无碍。以此乘发心趣向，普照世间，如太阳百千道光明，无时不照。此乘不可破坏，无能映蔽，以无量功德资粮无上而发趣。此乘超越世间，出过三界，远离诸黑暗，能趣向无漏。）

```
此乘唯摄取，一切诸菩萨，
其余众生类，于中不容受。
若有智慧者，无量千劫中，
方便勤修习，乃乘于此乘；
非诸声闻众，及以诸缘觉，
一切外道辈，而能乘此乘。
若有诸众生，趣于非道者，
斯人鲜福德，不堪闻此乘。
若有诸众生，于不思议法，
善巧而游戏，安住于此乘，
随其所建立，殊胜之誓愿，
住斯正道中，无上而发趣。
```

（大意：此乘唯摄受一切诸菩萨，其余众生类，其中不能容受。若有智慧的人，在无量千劫中以方便勤加修习，才能乘此乘；不是诸声闻众以及诸缘觉、一切外道之辈所能乘的。若有众生趣向非道，这人福德浅薄，不堪听闻此乘。若有众生对不可思议之法善巧游戏，安住于此乘，随其所建立的殊胜誓愿，住于这正道之中，无上而发趣。）

```
此乘无边际，亦无有中际，
边际及中际，一切不可得。
以际不可得，此乘无有际，
一切际断故，安乐而发趣。
此乘无边际，无边是乘际，
此乘无量际，无量是乘际。
此乘无际断，无际为际断，
于际不分别，断亦不可得。
乘际无边际，亦无有中际，
亦无无际际，际性无所有。
于际无际相，非际为际相，
于彼诸际中，际相无所有。
非际说际门，此乘已超过，
于彼所过量，相应不可得。
我说断常际，有边无边际，
如是一切际，彼际悉非际。
一切际无边，际相无所有，
一切际自性，于中不分别。
如是诸际中，以断于分别，
边际无边际，一切悉能断。
```

（大意：此乘没有边际，也没有中际，边际与中际一切都不可得。因为边际不可得，所以此乘没有边际；因为一切边际已断，所以安乐而发趣。此乘无边际，无边就是此乘的边际；此乘无量际，无量就是此乘的边际。此乘没有际断，以无际作为际断；对边际不作分别，断也不可得。此乘的边际没有边际，也没有中际，也没有无际之际，边际之性无所有。于边际中没有边际之相，以非际作为际相；在那些边际中，边际之相无所有。以非际而说际门，此乘已经超过它；对那所超过的，相应不可得。我所说的断际、常际、有边际、无边际，这样一切边际，那边际都不是边际。一切边际无边，边际之相无所有；一切边际的自性，在其中不作分别。在这些边际中，因为断除了分别，所以边际与无边际，一切都能断除。）

```
若有有身见，则说诸际门，
执著此诸际，为无依怙者。
若无有身见，不著诸际门，
不执一切际，为能照明者。
一切际非际，诸际非真实，
一切际性相，彼皆无所有。
不受一切际，于际悉超过，
不著诸际门，能断有身见。
若于有身见，不断不远离，
不被大甲胄，不乘于大乘。
以受于诸际，分别诸际相，
前际及后际，一切皆分别。
若于有身见，一切已能断，
乃被无边甲，乘于无上乘。
不著诸际门，为世智慧者，
能于种种际，一切悉超过。
```

（大意：若有身见，就会说出种种际门，执著这些边际，是没有依怙的人；若没有身见，不执著种种际门，不执著一切边际，是能照明世间的人。一切边际都不是边际，诸边际并不真实，一切边际的性与相，都无所有。不受取一切边际，对边际全都超过，不执著种种际门，能断除有身见。若对有身见不断除、不远离，就不是披大甲胄，不是乘于大乘；因为受取诸边际，分别诸边际之相，对前际与后际一切都加以分别。若对有身见一切都已能断除，才是披无边之甲，乘于无上之乘。不执著种种际门，是世间的智者，能对种种边际一切都超过。）

```
由是佛法中，安乐而发趣，
菩萨善观察，能以大慧力。
不得少有法，可断可除灭，
常以善方便，善摄于止观。
一相了知故，诸相皆了知，
安住于正法，得大法光明。
以是法光明，决了彼诸际，
不见少有际，若际及非际。
于彼可相应，一切无所著，
若见苦众生，慰谕而告言：
『汝来于此乘，安乐而出离。』
一切受生处，能作法光明，
被甲乘大乘，亦以此开示。
此乘此甲胄，于彼勿悭悋，
亦令诸众生，被甲乘大乘，
乘此安乐乘，无上而发趣。
如是诸菩萨，安住此修行，
能于佛法中，以速而发趣。
清净佛国土，摄受诸声闻，
及诸菩萨等，功德庄严事。
```

（大意：由此在佛法中安乐而发心趣向，菩萨善于观察，能以大慧之力，不得少许法可断、可除灭，常以善巧方便善摄止观。因为了知一相，所以诸相都能了知；安住于正法，得到大法光明。以这法的光明，决了那些边际，不见少许边际，无论是边际还是非边际；对那可相应的，一切都无所执著。若见到受苦的众生，就慰谕他们说：“你们来乘此乘，安乐而出离。”在一切受生之处，能作法的光明，披甲、乘大乘，也以此开示众生。对这乘、这甲胄，不要悭吝，也令诸众生披甲、乘大乘，乘这安乐之乘，无上而发趣。这样的诸菩萨安住于这样的修行，能在佛法中迅速发心趣向，成就清净佛国土，摄受诸声闻与诸菩萨等功德庄严之事。）
