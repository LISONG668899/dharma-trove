# 《大宝积经》卷第八十三（无尽伏藏会之一）

唐·三藏菩提流志 奉诏译

## 无尽伏藏会第二十之一

【按】译者题名，明本无“大”字，“三藏”作“三藏法师”。本会未见汉译异本。

#### 序分：法会大众

如是我闻：一时，佛在王舍城耆阇崛山，与大比丘众一千人在一起，都成就殊胜功德，能作狮子吼。又有菩萨摩诃萨五百人，都得陀罗尼门，辩才无碍，证得无生忍，住于不退转，具足种种三昧与游戏神通，善知众生心行的趣向，他们的名字是：日幢菩萨、月幢菩萨、普光菩萨、月王菩萨、照高峰菩萨、毗卢遮那菩萨、师子慧菩萨、功德宝光菩萨、一切义成菩萨、成就宿缘菩萨、成就愿行菩萨、空慧菩萨、等心菩萨、喜爱菩萨、乐众菩萨、战胜菩萨、慧行菩萨、电得菩萨、胜辩菩萨、师子吼菩萨、妙言音菩萨、能警觉菩萨、巧转行菩萨、寂灭行菩萨，像这样等菩萨摩诃萨为上首。又有释提桓因、四大天王、娑婆世界主梵天王，以及具大威德的诸天、龙、夜叉、乾闼婆、阿修罗、迦楼罗、紧那罗、摩睺罗伽，像这样等无量大众在一起。

#### 电得菩萨请问

那时电得菩萨见到大众寂然清净，诸大龙象都已集会，便从座而起，偏袒右肩，右膝著地，合掌向佛说：“世尊！我有少许疑惑，现在想请问，唯愿如来垂允听许。”那时世尊告诉电得菩萨说：“如来、应、正等觉任你所问，当为你宣说。”电得菩萨对佛说：“世尊！菩萨摩诃萨成就什么法，能满足众生一切所欲，不被种种过失所染著，随其根性方便引导，令那些众生身坏命终不堕恶趣，决定当得证于平等，处世无染犹如莲花，不动法界而游于诸佛刹土，常不离佛而不见色身，住于三解脱而不入正位，随众生之欲庄严清净佛土，在刹那之间迅速能成就阿耨多罗三藐三菩提？”那时电得菩萨摩诃萨便在佛前以偈问道：

【按】“速能成就”之“能”，明本作“得”。

```
无上人中尊，无边知见者，
安住于共法，利益诸世间。
等心视众生，为世所依怙，
示诸邪正道，令毕竟安乐。
积集胜功德，犹如众宝聚，
世间智慧日，三界应供尊。
愿说最上乘，成就菩萨道，
面相如满月，具足奢摩他。
开示寂静法，能灭诸烦恼，
愿说菩萨行，饶益诸众生。
佛刹并寿命，色身与眷属，
三业及诸法，一切皆清净。
```
（大意：无上的人中之尊、具无边知见的人，安住于共法，利益诸世间。以平等心看待众生，为世间所依怙，指示邪道与正道，令众生毕竟安乐。积集殊胜功德，犹如众宝之聚，是世间的智慧之日，是三界应受供养的尊者。面相如满月、具足奢摩他的尊者，愿宣说最上乘，成就菩萨道。开示寂静之法，能灭种种烦恼，愿宣说菩萨行，饶益众生。佛刹以及寿命，色身与眷属，三业以及诸法，怎样一切都清净？）

```
唯愿如来说，清净菩萨行，
云何降伏魔？云何而说法？
云何不忘失，唯愿为宣说，
云何勇进者，遍入于生死，
安住一相中，于法常无动？
云何诸佛所，亲近而供养，
常观佛色身，毕竟离诸相？
虽证三解脱，如鸟飞空界，
未具诸功德，终不入涅槃？
知诸根性欲，随顺无所畏，
亦不生染著，成熟彼众生？
先施世间乐，后令发净心，
具足殊胜智，证无上菩提？
如是深妙义，唯愿如来说。
```
（大意：唯愿如来宣说清净的菩萨行：怎样降伏魔？怎样说法？怎样不忘失？唯愿为我宣说。勇猛精进的人怎样遍入于生死，安住于一相之中，对法常无动摇？怎样在诸佛之所亲近供养，常观佛的色身，而毕竟远离诸相？虽然证得三解脱，如鸟飞于空中，未具足种种功德，终不入涅槃？了知众生的根性与意欲，随顺而无所畏，也不生染著，而成熟那些众生？先施予世间之乐，后令其发起净心，具足殊胜智慧，证得无上菩提？这样深妙的义理，唯愿如来宣说。）

#### 五种伏藏

那时世尊告诉电得菩萨摩诃萨说：“善哉善哉！善男子！你竟能问佛这样的义理，利益安乐无量众生，摄受现在世间的天人，以及未来世的诸菩萨等。所以电得！应当谛听，好好思念，当为你宣说。”电得菩萨说：“是的，世尊！愿乐欲闻。”

佛告诉电得：“菩萨摩诃萨有五种伏藏，是大伏藏、无尽伏藏、遍无尽伏藏、无边伏藏。菩萨具足这样的伏藏，永离贫穷，便能成就如上所说的殊胜功德，以少许功力迅速当得阿耨多罗三藐三菩提。哪五种？就是贪行伏藏、瞋行伏藏、痴行伏藏、等分行伏藏、诸法伏藏。

#### 贪行伏藏：了知贪病贪药

“电得！什么名为菩萨摩诃萨的贪行伏藏？就是众生与贪行相应，被颠倒所系缚，随顺诸相而行，种种分别，对色、声、香、味、触、法等种种境界，执著坚固，耽乐昏迷。菩萨对那些众生的种种心行应当如实了知：那些众生乐欲什么？在什么境界中染习增强？具足成就什么样的信解？往昔曾种什么样的善根？当在哪一乘中发心趣向？所有的善根多久才能成熟？菩萨为了断除众生的一切欲望，为了令他们的善心常相续，审谛观察而为他们疗治。

【按】“常相续”之“常”，宋本作“当”。

“电得应当知道，众生根行的差别难以识知，是一切声闻、辟支佛所不能知的，何况凡夫以及诸外道。所以电得！或有众生虽然执著诸欲，也能成熟阿耨多罗三藐三菩提。或有众生才触及欲境，或以染心说出言语，便得以成熟无上的明与解脱。或有众生看见美妙之色，心生欲染，那色变坏之后便即觉知，欲恼便息，深念无常，便能成熟无上的明与解脱。或有众生虽然见到女人不生贪著，以后思念时才起染心，想着她的形貌而生爱恋。或有众生在梦中见到可意之色，心生贪著，系念追求。或有众生听到女人的声音便生贪爱，有时暂时见到便离开贪染之心，便得以成熟无上的明与解脱。所以电得！菩萨对这种种贪病以及贪药都善巧了知，而对法界没有二相，对这些迷惑于法界的众生生起大悲心。

#### 示现男女身拔贪欲箭

“电得！无论贪、瞋、痴，或法界智，没有少许法可得，菩萨这样想：‘如我所见，这些众生在这无相、自性空寂、假名安立的和合之法中，生起贪欲、瞋恚、愚痴。我当在这里如实观察，为那些迷惑于贪欲的众生，住于大悲，成就圆满往昔的誓愿，不动法界，以无功用智成熟他们。’若有男子对女人妄生清净之想，生起深重的贪染，菩萨便示现女身，端正殊妙，色相具足，以珍宝璎珞种种庄严，犹如那人往昔所未见过的天女，随顺那众生令其爱著。待他极为贪恋之后，衡量他的堪任程度，以方便拔出他的贪欲毒箭。以自在之力还复变化女身，出现在那人面前为他说法，令那众生通达法界，便隐没不现。若有女人对男子心生爱染，菩萨便为她示现男子之身，乃至拔出她的贪欲毒箭，为她说法，令其入于法界，便隐没不现。

“电得！这些贪行有二万一千种，以及那些诸行有八万四千种，菩萨以无功用智出生无量亿千法门，开晓众生，悉令解脱，而也不念‘我为众生这样说法’，也没有得解脱的众生。

#### 无热龙王、帝释、日轮、真金诸喻

“电得！譬如无热龙王，因为业力的缘故，在其宫内流出四条大河，为水陆所住的众生，在夏季炎热苦恼时带来清凉，滋润花果，充实五谷，令众生安隐快乐。而那龙王不这样想：‘我现在令这河水流出，已经流出，将要流出。’然而那四条河常常自然充满，供众生使用。菩萨也是这样，成就往昔的誓愿，以无功用智宣说四圣谛，灭除一切生死热恼，普施人天以圣者解脱之乐。而这菩萨也不这样想：‘我现在说法，已经说，将要说。’只是任运安住于大悲之心，观察众生，随其所应而说法。

【按】“已出”之“已”，《大正藏》作“巳”，今依CBETA作“已”。

“又，电得！譬如帝释有十二那由他天女等，因为那帝释的自在之力，示现多身，令诸天女对那欲乐都得满足，各自想：‘我现在独自与帝释欢娱。’而这帝释实际上没有染著。菩萨也是这样，对众生中可度的人，随其意乐而成熟他们，然而这菩萨也没有染著。又，电得！譬如日轮从山峰出来时，光明普遍照耀阎浮提，所照之处，青、黄、赤、白种种形色都显现出来，而那日轮只是一色一光，没有差别之相。菩萨也是这样，智慧之日轮照耀法界，从众生的执著山峰中出来，所缘是一相，随其意乐而为说法，然而对法界没有二相。电得！这名为菩萨摩诃萨的贪行伏藏。菩萨证得此伏藏之后，或在一劫，或超过一劫，随众生的种种意乐示现无量身，以种种言辞为他们说法，然而对法界也没有二相。

“又，电得！譬如真金，由于工匠巧力，随意制作种种璎珞庄严之具，其相各不相同，而那金的本性没有差别。菩萨也是这样，善观法界，随众生的种种意乐示现无量身，以种种言辞为他们说法，然而对法界也没有二相，这是常入于法界一相。菩萨获得这样的伏藏，能为众生种种说法。他们听闻法之后，具足富有无尽的圣财，生死的贫穷都永远断除。

【按】“随诸众生”之“生”，宫本作“性”。

#### 瞋行伏藏

“又，电得！什么名为菩萨摩诃萨的瞋行伏藏？就是众生与憍慢相应，计执我与我所，住于自他之相，从久远以来不修慈忍，瞋恚热恼毁坏自心，对佛、法、僧不生忆念，被瞋毒所覆，迷惑于法。菩萨对那些多瞋的众生终不生起损害伤恼之心，只这样想：‘奇哉，众生愚痴迷惑，竟在诸法本性寂静、无垢浊、无和合、无违诤、远离之法中，与颠倒相应，妄生瞋恨。’这样想之后，住于大悲之心，常自恳切悲恻，即使有人支解他的身体，为了调伏瞋行众生，也安住于忍辱。若那无量瞋行众生相互违背，心怀恚恨，这业成就之后，当堕入毒蛇等恶趣之中。安住于忍辱的菩萨以慈念之力教化这些众生，能令他们不受恶趣之报，决定当得证于平等。这名为菩萨的善巧方便，灭除众生的瞋恚之行。

【按】“瞋恚”之“恚”，宫本作“忿”。

“又，电得！菩萨若见到瞋恼的众生，这样想：‘一切诸法本性清净，这些众生随相而行，妄生分别，在这平等无违之法中生起瞋心。那些众生对法界之性不能了知。若这些众生见到法性，终不会对他人生起忿害，因为不了知法界本性，所以生瞋。’菩萨对那些多瞋的众生，倍增慈愍，住于大悲，成就圆满往昔的誓愿，以无功用智，为了破坏众生的瞋恚之行，开示演说种种法门，而也不念‘我为众生除瞋而说法’。为什么呢？因为菩萨善观法界之相。这是菩萨安住于法界无差别之相而灭除烦恼之行。

“电得！譬如不是除去黑暗才显现光明，也不是没有能除黑暗的。这样黑暗以及光明之性，都如虚空，没有差别。菩萨也是这样，依此法界无差别之智，善巧说法，摧灭种种瞋行众生，不在法界中作差别。电得！譬如日轮所发出的光明，随所照之处，都为日轮所摄。菩萨也是这样，为了调伏、灭除瞋行，所有的言说都是法轮，不在法界中作差别。这样的瞋行有二万一千种，以及那些诸行有八万四千种，菩萨成就无功用智，随那些众生的种种瞋行而为说法，不这样想：‘我为众生现在说法，已经说，将要说。’这名为菩萨摩诃萨的瞋行伏藏。菩萨证得此伏藏之后，或在一劫，或超过一劫，随众生的种种意乐，以种种文字语言方便演说，不能穷尽其瞋行的边际，而这菩萨的智慧辩才也不可穷尽。这名为菩萨善说法界无差别之相，获得这样的瞋行伏藏。

#### 痴行伏藏

“又，电得！什么名为菩萨摩诃萨的痴行伏藏？电得！诸菩萨等这样的修行甚为难事，就是为了随惑而行的人、恼害他人的人、被无明胎壳所缠裹的人、如蚕处在茧中自我系缚的人、在法界中没有方便的人、不善观察所应行的人、执著我见的人、行于邪道的人、住于钝行的人、难以出离的人，为了这样等迷惑的众生，从初发心便起大加行，不生疲苦，也不懈怠。这样思惟：‘应当以什么缘、什么样的胜解、怎样说法，令这些众生入于菩萨行而得解脱？’菩萨往昔善观法界，以无功用智住于大悲，知道那些众生迷惑于法界之后，随其力之所堪而为说法，悉令调伏。也不这样想：‘我现在说法，已经说，将要说。’以他往昔誓愿之力，善观缘起，自然演出百千法门，断除众生的无明业行，令其得解脱。

【按】“㲉”字先前电子文本未能显示，今据《大正藏》补出，即卵壳；“胎㲉”即胎壳。

“电得！譬如良医善于疗治众病，先善于综合学习医方诸论，才见病相便全部了知，所施的咒与药没有不除愈的。菩萨也是这样，善观法界，以无功用智，为那些积集痴行的众生，随其根性开示演说百千法门，悉令明了。电得！这名为菩萨摩诃萨的痴行伏藏。菩萨证得此伏藏之后，善观缘起，为这样等痴行众生，或在一劫，或超过一劫，随其性欲以种种文字语言善巧演说，不能穷尽其痴行的边际，而这菩萨的智慧辩才也不可穷尽。这名为菩萨对一切法无差别之相善巧宣说，获得这样的痴行伏藏。这样的痴行有二万一千种，以及那些诸行有八万四千种，菩萨为了断除这样的行，开示演说百千法门。这名为菩萨的痴行伏藏。

【按】“积集”之“集”，明本作“习”。“是名菩萨痴行伏藏”之“是”，宫本无。

#### 等分行伏藏

“又，电得！什么名为菩萨摩诃萨的等分行伏藏？譬如四面镜轮，清澈明净，没有污垢翳障，悬挂在十字街头，所对的色像都在其中显现，没有增减。而这明镜也不这样想：‘我能显现这种种色像。’然而善于磨莹这镜轮之后，一切诸相自然显现。菩萨也是这样，善于磨莹法界的镜轮之后，住于无功用三昧，随众生心行的差别，开示演说百千法门，悉令了知，都得解脱，不起法相以及众生相。为什么呢？因为菩萨善观法界之相，对这与四种行相应的众生如实了知，随其根性而为说法，而对法界以及众生界如实观察，没有二相。因为明见那样的法界以及众生界无二、无差别。

“电得！譬如虚空，没有种种差别之相，也没有建立。菩萨也是这样，善观法界，了知一切法入于一相。也由于往昔誓愿之力，随众生之行种种说法，而对法界没有差别。电得！这等分行有二万一千种，以及那些诸行有八万四千种，菩萨观察都明了。譬如良医知病而授药，以无功用智种种说法，这名为菩萨摩诃萨的等分行伏藏。菩萨证得此伏藏之后，为众生或在一劫，或超过一劫，随其志乐以种种言辞善巧宣说，不能穷尽其诸行的边际，菩萨的智慧辩才也不可穷尽。这名为菩萨善说法界无差别之相，获得这样的等分行伏藏。
