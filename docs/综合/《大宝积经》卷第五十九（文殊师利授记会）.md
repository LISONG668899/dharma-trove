# 《大宝积经》卷第五十九（文殊师利授记会）

唐·于阗三藏实叉难陀 译

## 文殊师利授记会第十五之二

#### 弥勒敷座

那时世尊告诉弥勒菩萨摩诃萨说：“你现在为佛庄严备办法座，我升座之后，将宣说往昔以志乐所修的诸行，善巧出生诸佛刹土功德庄严、趣向真实的法门。”那时弥勒菩萨便这样想：“现在世尊为什么令我庄严法座，而不让阿难、大目连等去做？为何舍弃那些声闻，莫非只为诸菩萨宣说？或者那些声闻以及辟支佛对这法门不是法器，所以世尊令我敷座？”那时弥勒菩萨便以神通力为如来化作众宝师子之座，高四万由旬，周围庄严华丽，以柔软的天衣铺在上面；从那座中发出种种光明，照耀这三千大千世界。那时如来升上那座之后，令这世界六种震动。

#### 成就一法至三法：出家、劝趣佛乘、住阿兰若

那时世尊告诉长老舍利弗：“菩萨成就四种法，能令所愿都得满足。是哪四种？一是发起殊胜的志乐，二是对众生生起悲愍之心，三是发起精进，四是承事善知识。

“再者，舍利弗！菩萨成就一种法，令愿不退，庄严清净佛刹。是哪一种法？就是这菩萨应当乐于修学不动如来作菩萨时本来所修行而立下的弘誓愿：‘我在所生之处，初生之时，若不出家，便是欺诳十方诸佛。’像这样，舍利弗！这些菩萨应当随顺修学，无论佛出世还是不出世，在一切生处都决定舍家出家。为什么？诸菩萨最殊胜的利益就是出家。舍利弗！乐于出家的人，便能摄取十种功德。是哪十种？一是不著于诸欲，二是乐于阿兰若，三是行佛所行，四是远离凡夫之行，五是不著于妻子以及财产，六是远离恶道之因，七是修习善趣之法，八是宿世的善根都不损减，九是恒常为诸天所赞叹羡慕，十是一切鬼神都恭敬守护。若菩萨常乐出家，便获得这样十种功德。所以，舍利弗！菩萨立志求菩提、想要度众生，应当常常出家。这名为菩萨成就一种法。

“再者，舍利弗！菩萨成就两种法，令愿不退，庄严清净佛刹。是哪两种？就是菩萨不乐于声闻地，不求声闻乘，不爱乐宣说声闻乘之处，不亲近声闻乘人，不学声闻戒，不乐于宣说与声闻乘相应之法，也不劝他人行声闻乘；对缘觉乘也是这样，唯为佛法劝发众生成就最上的阿耨多罗三藐三菩提。这名为两种。舍利弗！若有人劝他人趣入佛乘，这菩萨便能摄取十种功德。是哪十种？一是得到清净的国土，没有声闻以及辟支佛；二是得到纯一清净的菩萨众；三是为诸佛世尊所护念；四是常为诸佛称名赞叹，为其说法；五是所发之心都全部广大；六是若生于天上，当作帝释或梵天王；七是若生于人中，作转轮王；八是常见诸佛；九是为诸天人所爱乐；十是摄取无量无边阿僧祇的功德。为什么？舍利弗！若有人能令三千大千世界所有众生都得阿罗汉果，或者都安置于缘觉之地；若又有人能把一个众生安置于佛菩提中，这功德比那还要多得多。为什么？舍利弗！不是由于声闻、缘觉出现而佛种不断；世间若没有佛，便没有声闻以及辟支佛。舍利弗！由于佛出现，令佛种不断，也出生声闻、缘觉。所以，舍利弗！菩萨令他人安住于佛乘中，得到这样等等的十种功德，得到清净的国土。

【按】“当作帝释”之“当”，宋本作“常”。

“再者，舍利弗！菩萨成就三种法，令愿不退，摄受佛刹功德庄严。是哪三种？一是尊重爱乐住于阿兰若，二是无所染著而行法施，三是坚固安住于清净的戒律律仪。舍利弗！菩萨坚固安住于戒律，得十种无畏。是哪十种？一是入聚落无畏，二是在大众中说法无畏，三是饮食无畏，四是出聚落无畏，五是入寺院无畏，六是在大众中进食无畏，七是教授无畏，八是亲近和上、阿阇梨无畏，九是以慈心教诲自己的眷属无畏，十是受用衣服、饮食、卧具、医药无畏，安住戒律的人所有的言说都能令他人信受。舍利弗！这是菩萨的十种无畏。舍利弗！菩萨说法，心无所著，便能摄受十种功德。是哪十种？一是不生恶欲，二是不求他人认识了知自己，三是不起求名闻之心，四是对施主之家心不系著，五是不占护他人之家，六是对极下劣的四事供养也生喜足，七是说法能令他人信受，八是善神守护，九是不生邪觉，十是生起念佛之心。这名为十种。舍利弗！菩萨尊敬爱乐住于阿兰若，成就十种功德利益。是哪十种？一是远离世俗的言论，二是专心修习闲静，三是心缘于定境，四是舍弃种种营务，五是爱乐诸佛，六是恒受禅定的喜乐，七是修梵行时没有障碍，八是少用功力便得三昧，九是所受的教法从未忘失，十是所闻的法义都全部了知。这名为十种。

【按】“未甞”之“甞”，元、明本作“常”。

#### 四法：如说能行、谦下、离悭嫉、见他得利欢喜

“再者，舍利弗！菩萨成就四种法，令愿不退，庄严清净佛刹。是哪四种？一是如所说而能行，如所行而能说；二是常自谦下；三是远离悭嫉；四是见他人得利，心生欢喜。这名为四种。舍利弗！这菩萨如所行而能说，有四种利益。是哪四种？一是口中常出青莲花香，二是语业清净，言无错谬，三是为一切世间所共同信受，四是摄受诸佛圆满的音声。这名为四种。舍利弗！菩萨谦下，有四种利益。是哪四种？一是远离恶趣畜生等身，二是受妙快乐，三是暗中图谋的人与暴贼都不能伤害，四是堪受人天的恭敬礼拜。这名为四种。舍利弗！菩萨远离悭嫉，有四种利益。是哪四种？一是不忘布施之心，二是在饥馑之时作大施主，三是见到持戒者前来，便承迎接纳，四是无论接受他人布施或布施于他人，没有一人生起嫉妒。这名为四种。舍利弗！菩萨见他人得利而生欢喜之心，有四种利益。是哪四种？一是常生这样的心：我摄受众生，本应给予利乐，他们既然自己得到了，所以生欢喜；二是所有的财物，王难、水火、劫贼、怨家、亲人都不能侵夺；三是随所生之处，财宝诸子都全部具足，国王尚且不嫉忌，何况其他人；四是积蓄与使用的资财都无穷尽。这名为四种。舍利弗！这是菩萨成就四种法。

【按】“稸用”之“稸”，元、明本作“蓄”。

#### 五法

“再者，舍利弗！菩萨成就五种法，令愿不退，庄严清净佛刹。是哪五种？一是那菩萨前往说法者处问道：‘修什么样的行能得到佛刹的清净庄严？’听到之后，便如所说而修行。二是菩萨由于清净持戒以及愿力，生于佛国中；生于那国之后，观察那国土种种庄严的众宝资具，以及诸声闻、菩萨大众种种微妙之相，在如来处恭敬尊重，说：‘世尊！菩萨修什么样的行，能得到广大佛刹的清净庄严？’而那位如来知道这菩萨志乐殊胜，便为他宣说这样的成就佛刹的功德，他听闻之后便如法修行。三是菩萨有智有行，应当净化其智，应当增进其行。怎样净化其智？就是对能缘以及所缘之法，远离声闻、缘觉之智。怎样增进其行？就是如所听闻的必定修行，远离不行。四是菩萨善知有因以及善知出离之言。有因，就是不正思惟，它是四颠倒所依止之处，是生死之因；出离，就是正确修行，对一切法不起分别，这是出离。五是菩萨了知诸佛的体性以及刹土之性都只有名，名也寂灭，这样了知，也不起了知之想。这名为五种。

#### 六法：施、戒、忍、进、禅、慧

“再者，舍利弗！菩萨成就六种法，能迅速得到阿耨多罗三藐三菩提，也能摄取一切世界中最上的佛刹。是哪六种？

“一是这菩萨作大施主，所有珍玩可爱之物，都欢喜布施，无所吝著。又这样想：‘我行大布施，圆满大乘，就是求阿耨多罗三藐三菩提时，一切都舍，心无所著，具足成就菩提资粮；舍弃自己的身命尚且不生悔恨，何况财产以及妻子等。’舍利弗！为什么如来名为一切智？就是行菩萨行时，对自己所有的一切都全部舍弃，以这义理，得菩提之后名为一切智。

“二是菩萨无论在家出家，宁可舍弃身命，终不破戒，以这持戒与众生共同回向阿耨多罗三藐三菩提。这样持戒，自觉欢喜，乐修梵行，昼夜安乐，更加求法，安住正修行，厌怖三界，希求出离。虽然见到出离之要，却顾念众生：‘如我所受的苦，他们也都是这样，我当担起这重担，摄取众生，安置于涅槃安乐之处。’这样持戒，自觉欢喜时获得大悲之心，乃至尚未得到一切种智，不舍精进，如救头上之火。

“三是菩萨披上忍辱之铠，远离高慢，得大忍力。若遇到骂辱以及捶打时，成就忍心，不生瞋恨。假使有如须弥山那样大的棒，有人拿着，在亿劫中常常打骂，也不生怨恨之心。为什么？‘那些众生没有随佛修学，而我正要随佛修学。’所以对他们所给予的打骂，便能增长那么多的大悲：‘我当为众生披上弘誓之铠，摄取众生，令其得到解脱，入于涅槃。所以我现在不应瞋恨。’菩萨正住于这样的忍辱时，便得成就十种具足。是哪十种？一是种姓，二是财产，三是眷属，四是色相，五是善于施舍，六是善友，七是得闻正法，八是如说修行，九是临命终时得见诸佛，十是见佛之后生起清净信心。这是十种功德具足。

【按】“种姓”之“姓”，明本作“性”。

“四是菩萨为了成就善法，坚固自我督责，发起精进；又为每一个众生，尽未来际在生死中，次第修行种种精进之行而不疲倦；以自我督责的功课以及这大悲，为一切众生，在那么长的时间中流转生死，不舍众生。舍利弗！若有菩萨以十方各如恒河沙数世界中充满的七宝，在念念之中奉献如来，这样相续尽未来际；若有菩萨发大悲心，披上精进之铠，这功德比那还要多。舍利弗！菩萨具足这精进，得十种殊胜志乐之法。是哪十种？一是远离凡愚之行，二是摄受佛行，三是见到生死的过患，四是安住于大悲心，五是不退本愿，六是少有疾病，七是随顺诸佛之教，八是淫怒痴淡薄，九是随文了知其义，十是修行成就。这名为十种。

“五是菩萨这样思惟：‘诸佛如来心常在定，从未失念，我应随佛所行。若心散乱，终究不能证得佛所行之处，所以应当舍离一切心中所取著的，也舍弃一切利养恭敬、聚落城邑、饮食资生以及诸亲友；为了利益众生，不舍众生，乐于阿兰若，住在寂静之处，独行无伴，如犀牛一角。住在静处之后，生起大慈心，先遍满一方，渐渐遍至十方，普遍一切众生；慈心遍满之后，得以入于禅定。’舍利弗！若有在家菩萨，以一切乐具在恒河沙劫中供养一切恒河沙数诸佛以及比丘众；若有出家菩萨，走七步向阿兰若寂静之处，这福德比那还要多得多，因为能迅速得到大菩提。舍利弗！菩萨乐住寂静、入于禅定，获得十种功德利益。是哪十种？一是得念，二是得慧，三是修行，四是迅捷的辩才，五是得陀罗尼，六是善知法的生起，七是善知法的灭去，八是戒聚无犯，九是诸天供养，十是不贪他人的好处。这名为十种。

【按】“未曾失念”之“曾”，宋本作“善”。“恒沙诸佛”之“恒”，元、明本作“恒河”。

“六是菩萨善知智慧的等流，就是这样想：‘智慧以戒为首，白法增长以慧为首，所以菩萨应当修学智慧。世间所有难作难成的一切工巧、一切医药，都全部遍学，而这样的智慧不能证入离欲寂灭，也不能趣向菩提，不是趣向沙门，不是趣向婆罗门，不是趣向涅槃。所以我现在应当更加遍求法药与工巧，以这样的智慧令我得到那究竟的寂灭。’那菩萨寻求诸法的根本，不见有少许法能生起法；由于不见，便住于寂灭；由于住于寂灭，便无热恼；由于无热恼，便了知生死；为了众生而受那生，令众生除灭其苦。这名为六种。

#### 七法至十法

“再者，舍利弗！菩萨成就七种法，令愿不退，庄严清净佛刹。是哪七种？一是自己舍一切而布施，因为不可得；二是持戒无缺犯，因为不计著于戒；三是忍辱柔和，而众生不可得；四是发起精进，因为身心不可得；五是成就禅定，因为不住于禅；六是智慧圆满，因为无分别；七是随念诸佛，因为远离相。这名为七种。

“再者，舍利弗！菩萨成就八种法，令愿不退，庄严清净佛刹。是哪八种？一是不乐涅槃，二是布施庄严之具，三是其心广大，四是尊敬法师，五是不行邪命，六是平等惠施，七是不自矜高，八是不凌蔑他人。这名为八种。

【按】“邪命”之“命”，《大正藏》作“名”，今依CBETA所录高丽藏作“命”。

“再者，舍利弗！菩萨成就九种法，令愿不退，庄严清净佛刹。是哪九种？一是具足身律仪，二是具足语律仪，三是具足意律仪，四是灭除种种贪欲，五是灭除种种瞋恚，六是灭除种种愚痴，七是不行欺诳，八是作坚固的朋友，九是不轻慢善知识。这名为九种。

“再者，舍利弗！菩萨成就十种法，令愿不退，庄严清净佛刹。是哪十种？一是听到地狱之苦，只生起大悲，不生怖畏；二是听到畜生之苦，只生起大悲，不生怖畏；三是听到饿鬼之苦，只生起大悲，不生怖畏；四是听到诸天的衰恼，只生起大悲，不生怖畏；五是听到人中的饥馑、贼盗、怨敌、杀害，只生起大悲，不生怖畏；六是菩萨这样想：‘我在此时当发起精进，乃至未得清净佛刹，终不懈慢。’七是：‘令我的国土中饮食衣服随念即得。’八是：‘我的佛刹中众生寿命无量。’九是：‘我的佛刹中众生没有彼我之心。’十是：‘我的佛刹中所有众生决定趣向无上菩提。’这名为十种。

#### 诸行回向佛刹庄严

“再者，舍利弗！若菩萨拿着妙花前往如来处或佛塔处兴修供养时，发这样的愿：‘如这妙花色香殊胜，见者欣悦；我成佛时，令我的国土中这样种种妙花遍布，以及众宝树周匝庄严。’乃至以末香、涂香、衣服、饮食、宝盖、幢幡、金银、琉璃、真珠等宝供养时，也应当这样回向佛刹功德庄严。由于那菩萨安住于戒律，随心所愿都得成就。

“再者，舍利弗！菩萨不求自己的安乐，喜见他人得乐，所以菩萨得菩提时，那佛刹中所有众生都具足一向的快乐。

“再者，舍利弗！菩萨应当常常普遍摄取十善业道，全部回向一切种智，所以菩萨得菩提时，那佛刹中所有众生初生便具足十善业道以及出离之智。

“再者，舍利弗！菩萨随所到之处，劝众生都趣向无上菩提，唯赞叹佛乘，不说二乘以及与二乘共通之法，所以菩萨得菩提时，那佛刹中所有众生决定当得无上菩提，永离声闻以及辟支佛，无量菩萨充满其国。

“再者，舍利弗！菩萨对他人的利养终不遮断，见他人得利常生欢喜，所以菩萨得菩提时，那佛刹中所有众生受用的资具恒无断绝，具足获得大法光明。

“再者，舍利弗！菩萨若见到比丘、比丘尼有过犯，终不张扬，只自己安住于正法之中，所以菩萨得菩提时，那佛刹中一切都没有过失之名。为什么？因为那大众都得清净无过失之法。

“再者，舍利弗！菩萨乐法求法，不生热恼，如所听闻之法正住修行，所以菩萨得菩提时，那佛刹中所生的众生，求法乐法都无热恼，如所听闻之法随顺修行。

“再者，舍利弗！菩萨以弦歌、鼓吹种种音乐供养佛塔，以这善根回向佛刹功德庄严，所以菩萨得菩提时，那佛刹中百千种音乐不鼓自鸣。

“再者，舍利弗！菩萨若见到失念的众生，令其得到正念，所以菩萨得菩提时，令诸弟子得到禅悦之食。

“舍利弗！这样的佛刹功德，即使以如来的辩才具足宣说，或一劫或超过一劫，也说不能尽。舍利弗！然而我现在随诸菩萨的乐欲这样略说，有殊胜志乐的人听了而趣向，当得圆满的佛刹功德。

#### 三法：大愿、不放逸、如闻修行

“舍利弗！菩萨成就三种法，能迅速得到阿耨多罗三藐三菩提，所求的佛刹都得成就。是哪三种？一是大愿殊胜，二是安住不放逸，三是如所听闻之法生起正确修行。这名为三种。”

那时舍利弗对佛说：“世尊！如来稀有，善说此法。世尊由于安住不放逸，所以得到菩提分法；由于安住修行，所以得到大菩提；由于安住殊胜之愿，所以成就佛刹功德庄严。”

佛告诉舍利弗：“是这样，是这样，如你所说。如我往昔以大愿力成就佛刹，由于不放逸而得成菩提。舍利弗！若只有言说，住于放逸而不修行，他尚且不能到达声闻地，何况能得阿耨多罗三藐三菩提？所以菩萨若想自知是真菩萨，应当如菩萨所学而这样修学。”

那时会中四万菩萨从座而起，合掌向佛，同声说：“如佛所说的菩萨学处，我们当随之修学，安住不放逸，修行成就，满足大愿，庄严清净佛刹。”

【按】“如佛所说”之“说”，元、明本作“记”。

那时世尊熙怡微笑。那时舍利弗对佛说：“世尊！因为什么因缘现出这微笑？”佛告诉舍利弗：“你看见这些善男子作师子吼了吗？”舍利弗说：“是的，已经看见了。”佛说：“舍利弗！这些善男子超过百千劫，各在不同的国土得阿耨多罗三藐三菩提，同号为愿庄严，也如将来的师子佛等，其国土清净如无量寿佛的国土，唯有寿量除外。”舍利弗说：“那些如来的寿量有多少？”佛说：“那每一尊佛都寿十劫。”

#### 文殊师利说不趣菩提

那时师子勇猛雷音菩萨便从座起，偏袒右肩，右膝着地，合掌向佛说：“这位文殊师利童真菩萨，为诸佛世尊常所称叹，要经过多久当得阿耨多罗三藐三菩提？所得的佛刹又是怎样的？”佛说：“善男子！你应当亲自问文殊师利。”

那时师子勇猛问文殊师利说：“仁者何时当得阿耨多罗三藐三菩提？”回答说：“善男子！为何不问我是否趣向菩提，却问我成就菩提呢？为什么？我对菩提尚且不趣向，何况当得。”问道：“文殊师利！仁者难道不是为了利益众生而趣向菩提吗？”回答说：“不是。为什么？因为众生不可得。若众生是有，可以为了利益他们而趣向菩提；而众生、寿命以及福伽罗都无所有，所以我现在不趣向菩提，也不退转。”

【按】福伽罗，即补特伽罗。

师子勇猛说：“文殊师利！仁者趣向诸佛之法吗？”回答说：“不。善男子！一切诸法都趣向佛法。为什么？诸法无漏无系，无形无相；为趣向佛，如同趣向佛，诸法也是这样。善男子！而你所问的趣向佛法，我现在问你，你随意回答。你认为怎样？是色求菩提吗？是色的本性求、色的如求、色的自体求、色的空求、色的离求、色的法性求菩提吗？善男子！你认为怎样？是色得菩提吗？乃至是色的法性得菩提吗？”回答说：“不是。文殊师利！色不求菩提，乃至色的法性不求菩提；色不得菩提，乃至色的法性也不得菩提。”

文殊师利说：“你认为怎样？受、想、行、识求菩提吗？乃至识的法性求菩提吗？识得菩提吗？乃至识的法性得菩提吗？”回答说：“不是。文殊师利！受、想、行、识不求菩提，乃至识的法性不求菩提；识不得菩提，乃至识的法性不得菩提。”文殊师利说：“你认为怎样？离开五蕴，有我与我所吗？”回答说：“没有。”文殊师利说：“是这样，是这样。善男子！还以什么法来求菩提以及得菩提？”

原文：“诸法无漏无系、无形无相，为趣向佛、如趣向佛，诸法亦然”（大意：诸法无漏无系，无形无相；为趣向佛，如同趣向佛，诸法也是这样。句意未详，存疑。）

师子勇猛说：“文殊师利！仁者所说的话大众都诚信，而现在却说不求菩提、不得菩提，新发意的菩萨听到这样的话，必定会生起惊怖。”文殊师利说：“善男子！一切诸法没有惊怖，在实际中也没有惊怖。如来是为无惊怖的人演说法；若惊怖，他便生厌；若生厌，他便离欲；若离欲，他便解脱；若解脱，便无菩提；若无菩提，便是无住；他若无住，便是无去；若无去，便是无来，便无愿求；若无愿求，便不退转；若不退转，便是退转。退转什么法？就是执著我、众生、命者以及福伽罗，或断或常、取相分别，都全部退转。他若退转，便不退转。不退转什么法？就是空、无相、无愿、实际以及诸佛之法都不退转。什么是佛法？就是不离不著，以及无所缘，无入无出，无有所行，也无表示，只有其名，空而无有生，无去无来，无染无净，无尘离尘，无我无分别，无和合无执取，平等无违，这便是佛法。善男子！这诸佛之法，非法非非法。为什么？因为诸佛之法没有生处。所以那新发意的菩萨听了这话之后，若生惊怖，便能迅速得到菩提。若起分别，这样想：‘现在我们所成的菩提，随着有发心、住于现证，才得菩提；若不发心，终究不能得到。’这样的分别都不生起，所以菩提以及心都不可得；由于不可得，便无分别；若无分别，便无现证。为什么？因为现证的所因不可得。善男子！你认为怎样？虚空可以得菩提吗？”回答说：“不能。”又说：“善男子！如来难道不是证知一切法同于虚空吗？”回答说：“是这样，是这样。”又说：“善男子！如虚空，菩提也是这样；如菩提，虚空也是这样；虚空与菩提无二无别。若菩萨了知这平等，便无有知，也无不知，也无不见。”

【按】“则无去”之“则”，《大正藏》作“即”，今依CBETA所录高丽藏作“则”。“故彼新发意”之“故”，元、明本无。“速得菩提”之“速”，南藏作“悉”。“证一切法”之“证”，宋、元、明、宫本作“说”。

说此法时，一万四千比丘尽诸有漏，心得解脱；十二那由他比丘远尘离垢，于诸法中得法眼净；九万六千众生发菩提心；五万二千菩萨得无生忍。

#### 都不见心名为平等

那时师子勇猛雷音菩萨对文殊师利说：“仁者发菩提心以来有多久了？”文殊师利说：“止！善男子！不要生起妄念。若有人在无生法中这样说：‘我发菩提心，我行菩提行。’这是大邪见。善男子！我都不见有心发向菩提；由于不见心以及菩提，所以无所发。”师子勇猛说：“文殊师利！都不见心，是什么句义？”文殊师利说：“善男子！这都不见，说名为平等。”又问：“怎样说为平等？”回答说：“善男子！这样的平等，是由于种种性都无所有，那一切诸法同一味，所以这样说。说一味，就是离：无染无净，不断不常，不生不灭，无我无受，不取不舍。这样说法，不念我在说，也无分别。善男子！在这平等法中了知修行，这名为平等。再者，善男子！若菩萨入于这平等，都不见有种种界，或一或多；在平等中不见平等，在相违中不见相违，因为它们本来自性清净。”

#### 文殊师利往昔发心因缘

那时师子勇猛雷音菩萨对佛说：“世尊！这位文殊师利不肯亲自说发心的久近，这大众都乐于想听。”佛说：“善男子！文殊师利是得甚深忍的人，在甚深忍中菩提以及心都不可得，由于不可得，所以不说。然而善男子！我现在当说文殊师利发心的久近。善男子！过去久远，超过七十万阿僧祇恒河沙劫，有佛名为雷音如来、应、正等觉出现于世，在东方距此超过七十二那由他佛刹，有一个世界名为无生，那雷音如来在其中说法，声闻众有八十四亿那由他，菩萨众比前加倍。善男子！那时有一位国王名为普覆，七宝具足，统治四天下，以正法治理教化，为法轮王。在八万四千年中，以每一件都殊妙的衣服、饮食、宫殿、台观、僮仆给侍，恭敬供养雷音如来以及诸菩萨、声闻大众。那国王的亲族、中宫婇女、王子、大臣，唯务供养，其余什么都不做，虽经多年，从未疲倦。过了这以后，那国王独自在静处思惟：‘我现在已集广大的善根，而还没有决定回向之处，是为了求帝释、大梵天王、转轮王呢？还是为了求声闻、辟支佛呢？’这样想了之后，空中诸天告诉他说：‘大王！不要生起这样狭劣之心。为什么？大王所集的福德甚多，应当发阿耨多罗三藐三菩提心。’善男子！那时普覆王听了这话，欢喜地想：‘我现在对此决定不退。为什么？诸天知道我的心而来告诉我。’善男子！那时那国王与大众八十亿那由他百千众生，前往雷音佛所，顶礼双足，右绕七匝，曲躬恭敬，合掌向佛，而说颂道：

【按】“我今问”之“问”，元、明本作“闻”。

```
我今问最胜，愿当为我说。
云何得成就，最上人中尊？
世间所依止，我已广供养，
以不决定心，未知回向处。
已修广大福，当何所回向？
为求梵天位、帝释转轮王、
为求于声闻、及以辟支佛？
```
（大意：“我现在请问最胜者，愿为我宣说：怎样才能成就最上的人中之尊？世间所依止的诸佛，我已广为供养，由于心不决定，不知道回向何处。已修了广大的福德，应当回向何处？是为求梵天之位、帝释、转轮王，还是为求声闻以及辟支佛？”）

```
我发此念时，空中天告我：
大王汝勿起，狭劣回向心，
为一切众生，当兴广大愿，
利益世间故，应发菩提心。
我今请世尊，于法自在者，
愿说菩提心，发起之方便。
发菩提心已，当得如牟尼。
唯愿两足尊，为我具宣说。
```
（大意：“我生起这念头时，空中的天人告诉我：‘大王你不要生起狭劣的回向之心，应当为一切众生兴起广大之愿，为了利益世间，应当发菩提心。’我现在请问于法自在的世尊，愿为我宣说发起菩提心的方便。发菩提心之后，当得如牟尼一样。唯愿两足尊为我详细宣说。”）

“那时雷音如来为普覆王说颂道：

```
大王汝谛听，我当次第说。
一切因缘法，随根欲所行，
如其所有愿，得如是果报。
我亦于往昔，发起菩提心，
为诸众生故，愿当作利益。
如我所作愿，如昔所发心，
得不退菩提，意愿速圆满。
大王应坚固，修习于诸行，
汝当得广大，无上佛菩提。
```
（大意：“大王你谛听，我当次第宣说。一切因缘之法，随根性与欲乐而行，如其所有的愿，便得如此的果报。我也在往昔发起菩提心，为了众生，愿作利益。如我所发的愿，如往昔所发的心，得到不退的菩提，意愿迅速圆满。大王应当坚固地修习诸行，你当得广大的无上佛菩提。”）

“那时普覆王听了佛所说，欢喜踊跃，得未曾有，在大众前作大师子吼，而说颂道：

```
今对一切众，发大菩提心。
为一一众生，誓尽未来际，
受无量生死，而作大饶益，
备修菩萨行，救诸众生苦。
从今若违誓，起于贪欲心，
及悭嫉怨恨，则诳十方佛。
又我从今日，乃至成菩提，
常当学诸佛，修行于梵行，
随顺净戒律，远离诸过咎。
又我于菩提，亦不愿速证，
```
（大意：“我现在面对一切大众，发大菩提心。为了每一个众生，誓愿尽未来际，受无量生死，而作大饶益，具备修习菩萨行，救度众生之苦。从今以后若违此誓，生起贪欲之心，以及悭嫉怨恨，便是欺诳十方诸佛。又我从今日起，乃至成就菩提，常当学习诸佛，修行梵行，随顺清净戒律，远离种种过咎。”）

```
当尽未来际，广利诸群生，
严净诸佛刹，无量不思议，
当令我名号，普闻十方界。
我今自授记，决定当成佛，
志乐胜清净，于此固无疑。
我当净三业，不令起诸恶，
我以此真实，成佛人中尊。
若此心真实，地当六种动，
若我语诚谛，无有虚妄者，
当使虚空中，音乐自然奏。
若我无谄曲，及以怨恨心，
由此真实故，当雨曼陀花。
```
（大意：“又我对于菩提，也不愿迅速证得，当尽未来际，广为利益群生，庄严清净诸佛刹土，无量不可思议，当令我的名号普闻于十方世界。我现在自己授记，决定当成佛，志乐殊胜清净，对此坚定无疑。我当清净三业，不令生起诸恶，我以此真实，成佛作人中之尊。若此心真实，大地当六种震动；若我所说诚实，没有虚妄，当使虚空中音乐自然演奏；若我没有谄曲以及怨恨之心，由于这真实，当降下曼陀罗花。”）

“那时普覆王说了这颂之后，由于心诚实，十方亿国土六种震动，在虚空中演奏种种音乐，降下曼陀罗花。那时随从国王的二十亿众生都大欢喜，自相庆贺说：‘我们当得最上菩提。’便学那国王发菩提心。”

佛告诉大众：“那时的普覆王难道是别人吗？就是现在的文殊师利菩萨。他在往昔超过七十万阿僧祇恒河沙劫初发菩提之心，其次过了六十四恒河沙劫得无生法忍，能具足菩萨十地、如来十力，佛地诸法都全部圆满，而从未生起一念之心：‘我当得佛。’善男子！那时随从那国王在雷音佛所发菩提心的二十亿众生，都是由于文殊师利劝发，令他们入于布施、持戒、忍辱、精进、禅定、智慧，现在都已证得阿耨多罗三藐三菩提，转大法轮，作完佛事，而般涅槃。文殊师利都供养了那些如来，也都护持那些佛法。唯有一尊佛号为地持山，在此下方超过四十恒河沙国土，其佛世界名为地持，也有无数声闻众，佛寿无量，现在仍在世。”说这文殊师利宿缘之时，大众中七千众生发阿耨多罗三藐三菩提心。
