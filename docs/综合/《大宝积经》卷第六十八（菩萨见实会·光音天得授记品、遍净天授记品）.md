# 《大宝积经》卷第六十八（菩萨见实会·光音天得授记品、遍净天授记品）

北齐·三藏那连提耶舍 译

## 菩萨见实会第十六之八

### 光音天得授记品第二十

#### 光音天说照耀一切法三昧

那时有五十八千万光音天，见到阿修罗、伽楼罗乃至梵天等供养如来、听闻授记之后，欢喜踊跃，都称心如意，偏袒右肩，右膝著地，向佛合掌，恭敬作礼，对佛说：“世尊！有一种三昧，名为照耀一切法，若菩萨摩诃萨修学此三昧，在一切法中都得光明，得以进入菩萨法门。菩萨摩诃萨解了知晓之后，得无边辩、无碍辩、相续辩、种种辩、美妙辩、真善辩、相应辩、解脱辩、微细辩、不共辩、甚深辩，乃至得如来之辩。

【按】品题“光音天”，宋、元、明、宫本作“光音天等”；“得授记”之“授”，宋、元、明、宫本作“受”。“伽楼罗”之“伽”，明本作“迦”。

“世尊！什么名为照耀一切法三昧？菩萨因为进入这些法门，忆念诸觉观，知道一切法无觉、离觉，这无觉之法遍一切处，没有一法能够觉察。为什么呢？因为本性自离。若法无有自性，怎能觉知一切法？既然没有能觉，便入阿字门，得上等辩才。那菩萨入阿字门之后，得无边辩。阿字无边，阿字不是普遍，阿字无作，阿字不是有为，阿字不是成就，阿字不是事，阿字无所依，阿字无有动转，阿字不是略，阿字不是广，阿字不是分别，阿字不是众事所成，阿字不可穿透，阿字不是色，阿字不可显示，阿字不可观，阿字没有能见者，阿字不可思，阿字不定住，阿字不是可知，阿字不是能知，阿字不可测，阿字不能自己示现，阿字也不能示现他者，阿字不可思议，阿字不去，阿字不来，阿字不近，阿字不远，阿字不是言说，阿字也不是可说之法，阿字不是名，阿字不是用，阿字不是现前，阿字不是覆障，阿字不是移转，阿字不可改变，阿字没有差别，阿字无二，阿字不是生，阿字不是虚妄，阿字不是真实，阿字不可说，阿字不是生灭，阿字不是清净，阿字也不是可净之法，阿字不是执持，阿字不摄取他者，阿字不是弃舍，阿字不为他法所作，阿字也不造作他法，阿字不生，阿字不灭，阿字不能生他法，也不能灭诸法，阿字非生非不生，阿字不为生法作生因，也不作不生之缘，阿字非依非不依，阿字非假非不假，阿字非却非不却，阿字非许非不许，阿字非可得也非不可得，阿字非空非不空，阿字非分别非不分别，阿字非相非不相，阿字非愿非不愿。

“世尊！一切诸法都是这样的相，就是无相。一切诸法都同一实，就是无实。都同一趣，就是无趣。都同一入，就是无入。都同一假，就是无假。都同一用，就是无用。一切诸法都同一说，就是无说。世尊！诸法无起，因为不可得。诸法非有，因为无有。诸法无生，因为不生。诸法无灭，因为不灭。所谓无为法，是因为无有造作。世尊！一切法都同一如，应当这样了知。

“世尊！这些不生之法，它们的事用怎样得知呢？世尊！譬如有人在梦中所作，当知诸法也是这样。为什么呢？梦中所作之事，不生不起，也非实有。梦虽不真实，却并非没有假名，说有梦中所作。一切诸法也都是这样。世尊！譬如回响之声只有假名，诸法只是假名，也是这样。世尊！譬如幻人只是假名，当知诸法也是这样。世尊！譬如阳焰只是假名，诸法的假名也是这样。世尊！如镜中影像只有名与用，当知诸法也是这样。世尊！为了悦豫凡愚，说有梦中之事，梦中所作都不真实，回响、幻化、阳焰、影像也是这样，只有假名，都无实作。世尊！我们这样理解如来所说的法义。”

【按】“一切法皆同一如”之“法”，明本作“诸法”。“不生不起”之“起”，宫本作“趣”。

#### 光音天以偈赞佛

那时光音诸天以偈赞佛：

```
世尊善知此法义，
及余种种无边法，
如来所有诸佛子，
得父资财常游戏。
世间少智莫能入，
由常计著我心故，
十方求我不可得，
我体本来性自空。
如空阳炎非实水，
愚痴见彼作水想，
都由无智生迷惑，
虚妄颠倒计我人，
彼痴愚惑如来教，
是故不解深义趣。
```
（大意：世尊善知此法义，以及其余种种无边之法，如来所有的佛子，得到父亲的资财，常得游戏。世间少智之人不能契入，由于常常计著我心；在十方求我不可得，我的体性本来自空。如同空中阳焰不是真水，愚痴者见了却作水想，都是由于无智而生迷惑，虚妄颠倒，计著我、人，那些愚痴者迷惑于如来之教，所以不解深义。）

【按】“生迷惑”之“迷”，圣本作“悉”。

```
凡夫心识如炎水，
不能了知诸阴义，
心乐生死著苦箭，
诸根驶流所漂溺。
斯等毕竟无自性，
为痴覆蔽妄受苦，
彼皆失智心迷乱，
于诸苦中生乐想。
心常颠倒顺三毒，
是诸烦恼甚可怖，
贪欲瞋恚及愚痴，
斯诸结使常随逐。
深乐受故生渴爱，
愚痴不识故受苦，
无智随顺诸烦恼，
如人痴负怨家行。
闻佛所说空教门，
于空反畏失解脱，
譬如怯人执持刀，
应得安隐反生畏。
```
（大意：凡夫的心识如同阳焰之水，不能了知诸阴之义，心乐生死，中了苦箭，被诸根的急流所漂溺。这些毕竟无有自性，被愚痴覆蔽，妄受众苦，他们都失去智慧，心意迷乱，在诸苦中生起乐想。心常颠倒，随顺三毒，这些烦恼甚为可怖，贪欲、瞋恚以及愚痴，这些结使常相随逐。深乐于受，所以生起渴爱，愚痴不识，所以受苦，无智而随顺诸烦恼，如同愚痴之人背负怨家而行。听闻佛所说的空教门，对空反而畏惧，失去解脱，譬如怯懦之人手执刀杖，本应得安隐，反而生畏。）

【按】“驶流”之“驶”，《大正藏》作“駃”，宋、元、明、宫本作“驶”，今依CBETA作“驶”。

```
大智世尊所说法，
谓是微妙阿字门，
能生真实胜智慧，
犹如平地生大树。
降诸魔怨那由众，
能寤安隐妙菩提，
以彼八正大船栰，
于诸有海度群生。
世尊所有诸佛子，
了知如来胜教法，
速灭烦恼诸怨敌，
疾证无上大菩提。
既自解脱离毒心，
见余毒者施智药，
得到究竟彼岸果，
获大安乐无为处。
一切诸法皆悉空，
诸余外论妄分别，
明人弃恶就正路，
皆由本来久修学。
```
（大意：大智世尊所说之法，就是微妙的阿字门，能生真实殊胜的智慧，犹如平地生出大树。降伏那由他数的魔怨之众，能觉悟安隐的妙菩提，以那八正道的大船筏，在诸有之海度化群生。世尊所有的佛子，了知如来的殊胜教法，迅速灭除烦恼怨敌，疾证无上大菩提。既已自己解脱，远离毒害之心，见到其余中毒的人便施予智慧之药，得到究竟彼岸之果，获得大安乐的无为之处。一切诸法都是空，其余外道之论妄加分别，明智之人弃恶就正路，都由于本来久已修学。）

【按】“能寤”之“寤”，元、明本作“悟”。

```
心无所著即解脱，
诸法体性自如是，
彼能如是了知者，
成佛大力那罗延。
无有系缚及缚者，
诸法性空皆亦无，
真如寂灭及非如，
非是垢秽亦非净。
烦恼无相亦无断，
以其本来性自空，
如是能知真实法，
彼人当得一切智。
自证解脱复度他，
此等不生亦不灭，
世间天人皆迷惑，
如春禽兽见炎水。
虚妄分别起渴心，
想见男女受苦恼，
以业种种生诸趣，
由心作故有差别，
造业有报及以受，
彼业无有能作者。
```
（大意：心无所著即是解脱，诸法的体性本自如此，能这样了知的人，当成佛而具那罗延的大力。没有系缚以及能缚者，诸法性空，都是无有，真如、寂灭以及非如，不是垢秽，也不是清净。烦恼无相，也无可断，因为本来自性空，能这样了知真实之法，此人当得一切智。自证解脱又度化他人，这些不生也不灭，世间天人都迷惑，如春天的禽兽见到阳焰之水。虚妄分别生起渴心，想见男女而受苦恼，以种种业生于诸趣，由于心所作，所以有差别，造业有果报以及领受，那业却没有能作者。）

【按】“起渴心”之“渴”，圣本作“浊”。

```
我等如是解佛法，
是诸如来妙境界，
是故如来心调伏，
诸根寂静能忍辱。
世尊如法得供养，
清净无垢尽诸秽，
具足众德离暗冥，
唯佛能施三界眼。
我今赞佛所获福，
唯有出世大导师，
二足世尊功德聚，
能知我等所得报。
以此微妙胜善根，
回施一切诸群生，
愿彼当于未来世，
悉得成就一切智。
```
（大意：我们这样理解佛法，是诸如来的妙境界，所以如来心已调伏，诸根寂静，能够忍辱。世尊如法得到供养，清净无垢，尽除诸秽，具足众德，远离暗冥，唯有佛能施予三界之眼。我现在赞佛所获的福德，唯有出世的大导师、二足世尊功德聚，能知我们所得的果报。以此微妙殊胜的善根，回施一切群生，愿他们在未来世，都得成就一切智。）

#### 授光音天记

那时世尊知道光音天已具深信之心，并知道他们修行，辩才具足，为了令大众的功德善根渐渐增进增长，这时如来便现出微笑。那时慧命马胜便以偈颂问世尊说：

```
大悲善逝非无因，
而现希有微笑相，
能利世间无上士，
正觉智慧超群生。
两足世尊功德聚，
怜愍众生愿演说，
为谁而现此微笑，
殊胜光显于世间？
一切众生若得闻，
心意决定大喜悦，
修行善业证佛果，
得离生死到涅槃。
斯诸世间天人众，
生死苦恼之所逼，
愿度群生于有海，
演说八正大船路。
如是得闻大仙说，
具八功德最胜道，
世间于是生欣喜，
乐修诸善愿成佛。
勇猛精进有大力，
内心清净离诸疑，
当传如来所说法，
是佛真子顺圣教。
```
（大意：大悲善逝并非无因，而现出希有的微笑之相，能利益世间的无上士，正觉智慧超越群生。两足世尊功德聚，愿怜愍众生而为演说，为谁现出这微笑，殊胜之光显照于世间？一切众生若得听闻，心意决定，大大喜悦，修行善业，证得佛果，得以离开生死，到达涅槃。这些世间的天人之众，为生死苦恼所逼迫，愿在有海中度化群生，演说八正道的大船之路。这样听闻大仙宣说具八功德的最胜之道，世间因此生起欢喜，乐修诸善，愿得成佛。勇猛精进有大力，内心清净，远离诸疑，当传如来所说之法，是佛的真子，随顺圣教。）

【按】“如是得闻”之“闻”，圣本作“间”。

```
此诸众会无余念，
一心瞻仰大瞿昙，
唯愿敷演授记事，
令其决断疑惑心。
合掌恭敬正意住，
咸皆愿乐欲听闻，
善哉愿说甘露味，
诸有渴法当得饮。
是等一切诸会众，
心净爱乐胜功德，
瞻仰如来最胜颜，
犹如婴儿观母面。
大慧愿授此天记，
开现微笑因缘事，
得闻如来授记已，
世间当获大利益。
谁于牟尼增善根，
及以发愿得满足，
克获微妙功德藏，
我今乐闻彼受记。
大众必生欣喜心，
闻佛所说授记故，
决定当具念慧力，
及得修行三昧定。
```
（大意：这些众会没有其余念头，一心瞻仰大瞿昙，唯愿敷演授记之事，令他们决断疑惑之心。合掌恭敬，正意而住，都愿乐想要听闻，善哉，愿说甘露之味，诸有渴求法者当得饮用。这一切会众，心净，爱乐殊胜功德，瞻仰如来最胜之颜，犹如婴儿看着母亲的面容。大慧者愿为这些天授记，开显微笑的因缘之事，听闻如来授记之后，世间当获大利益。是谁在牟尼处增长善根，以及所发之愿得以满足，克获微妙的功德之藏？我现在乐于听闻他们的受记。大众必定生起欢喜之心，因为听闻佛所说的授记，决定当具足念与慧之力，以及得以修行三昧禅定。）

那时世尊便以偈颂回答慧命马胜说：

```
善哉马胜所问事，
辩才应机正是时。
斯即如来神通力，
以是汝今生智慧，
为利世间故增辩，
是故汝今能致问。
我今为彼说授记，
寂静诸根一心听。
此诸胜慧光音天，
过去已供无量佛，
见是世间孤无救，
发心安住欲作佛。
修治真实微妙行，
必定当成一切智，
为求佛道诸众生，
如迷失径教正路。
如是得闻世尊教，
其声最胜无等等，
乐佛功德智慧人，
必得究竟到彼岸。
彼有智力知善恶，
决定当获佛菩提，
欣喜已发菩提愿，
如妇生男称其心。
```
（大意：善哉马胜所问之事，辩才应机，正是时候。这就是如来的神通之力，因此你现在生起智慧，为利益世间而增长辩才，所以你现在能够发问。我现在为他们宣说授记，你们寂静诸根，一心谛听。这些具殊胜智慧的光音天，过去已供养无量佛，见到这世间孤独无救，便发心安住，想要作佛。修治真实微妙之行，必定当成一切智，对为求佛道的众生，如同对迷失道路的人，指示正路。这样听闻世尊的教法，其声最胜，无等等，乐于佛功德的智慧之人，必得究竟到达彼岸。他们有智力知晓善恶，决定当获佛的菩提，欢喜而已发菩提之愿，如妇人生男，称其心意。）

【按】“故增辩”之“故”，宫本作“成”。“如是得闻世尊教”之“如”，宫本作“见”。“知善恶”之“善恶”，宋、元、明、宫、圣本作“善根”。

```
此天为求菩提者，
示其出世真正路，
于不可说那由劫，
修习菩萨胜妙行。
所化众生过众星，
安置于佛菩提已，
当来具足世间解，
自然成就一切智。
彼等妙土不可说，
世界宽广有百亿，
是诸妙刹甚清净，
无量种种胜庄严。
彼佛国土诸众生，
无三恶趣及八难，
一切皆发菩提心，
咸各得住不退转。
彼诸如来国土中，
亦复无有小乘法，
众生悉皆求佛道，
便得进趣不退地。
是诸刹土众生类，
一切寿命悉齐等，
经于十亿恒沙劫，
皆由值遇诸佛故。
```
（大意：这些天为求菩提的人指示出世的真正之路，在不可说那由他劫中，修习菩萨殊胜妙行。所化的众生超过众星，将他们安置于佛菩提之后，未来当具足世间解，自然成就一切智。他们的妙土不可说，世界宽广，有百亿之多，这些妙刹甚为清净，有无量种种殊胜庄严。那些佛国土的众生，没有三恶趣以及八难，一切都发菩提心，都得以住于不退转。那些如来的国土中，也没有小乘之法，众生都求佛道，便得进趣不退之地。这些刹土的众生，一切寿命都相齐等，经过十亿恒河沙劫，都是由于值遇诸佛的缘故。）

```
若教那由刹众生，
悉得入于小涅槃，
若复有人化一人，
或男或女入大乘。
初福比此功德聚，
算数譬喻不能及，
是故若住大乘者，
应当转化于余人。
马胜！以是因缘故，
如来出世甚为难，
犹如优昙极难值，
无边大智如是说。
以巧深智善知识，
善解方便示正路，
安隐无上胜菩提，
若人求者应亲近。
```
（大意：若教化那由他刹土的众生，使他们都得入于小涅槃，若又有人教化一人，或男或女，令入大乘；前者的福德与这功德聚相比，算数譬喻都不能及，所以若是住于大乘的人，应当转而教化其余的人。马胜！由于这个因缘，如来出世甚为难得，犹如优昙花极难值遇，无边大智者这样宣说。具善巧深智的善知识，善解方便，指示正路，安隐无上的殊胜菩提，若有人求取，应当亲近他们。）

```
从佛口闻如是语，
具足微妙甚深义，
一切大众皆欣喜，
踊跃充满称心意。
那由诸天住空中，
皆散天衣旋转下，
欣喜赞声满虚空：
敬礼无比大神力，
清净妙智度世间，
能灭众生烦恼热。
佛说甘露灭三毒，
如阿伽陀消众毒，
得闻智慧断诸结。
世间迷惑多苦恼，
于其有趣当得脱，
从佛得闻胜法故。
```
（大意：从佛口中听闻这样的话，具足微妙甚深之义，一切大众都欢喜，踊跃充满，称心如意。那由他诸天住在空中，都散下天衣，旋转而下，欢喜的赞叹之声充满虚空：“敬礼无比的大神力者，以清净妙智度化世间，能灭众生的烦恼之热。佛说甘露，灭除三毒，如阿伽陀药消除众毒，听闻智慧而断诸结。世间迷惑，多诸苦恼，于诸有趣当得解脱，因为从佛听闻了殊胜之法。”）

### 遍净天授记品第二十一

#### 遍净天说超过一切法三昧

那时十二那由他遍净诸天等，见到阿修罗、伽楼罗乃至光音天等供养如来、听闻授记之后，欢喜踊跃，都称心如意，自现威力，对佛说：“世尊！有一种三昧，名为超过一切法。菩萨摩诃萨得此三昧之后，对于各种攀缘以及一切事都生起乐受，不生苦受。假使在地狱之事中受种种苦恼，也都生起乐想。或在畜生道中受畜生之报，也生乐想。或在饿鬼道中受饥饿之苦，也生乐想。或在阿修罗道中，也生乐想。或在人中所受的种种苦，也生起乐想，不生苦想。

【按】“地狱事中”之“事”，圣本作“道”。

“假使被截手以及截足，割耳劓鼻，或被鞭打，杖刺入身，或被关在牢狱中系闭，或被倒悬，或被像裁剪衣帛一样裁割，或被裹缚以及束缚，或被切成脍，或被像甘蔗一样锤捣，或被像芦苇一样蹉踏破碎，或被像酥油灯炷一样火烧，或被燃身如同明炬，或被给狮子虎狼作食物，或被以浓醋以及辛辣之汁浇灌口鼻，或被蒸煮以及火炙，或被狂象践踏其身，或被挑去眼目，或被以矛矟穿刺高举，假使有人瞋怒来截其首，像这样一切都生乐想。

【按】“苏油炷”之“苏”，《大正藏》作“穌”，宋、元、明、宫本作“酥”，今依CBETA（所录高丽藏）作“苏”。“然身喻若明炬”之“喻”，《大正藏》作“踏”，今依CBETA（所录高丽藏）作“喻”。“师子”，元、明本作“狮子”。“酽醋”，宫、圣本作“严酢”。

“为什么呢？由于那菩萨在长夜修菩萨行时发这样的愿：‘若有众生施我饮食，愿他们一切都得涅槃之乐。若有人为我洗浴身体，礼拜奉迎，尊重供养，若有众生骂辱我，又有人赞叹我，若有众生鞭打斫刺，夺我身命，愿他们一切都得涅槃之乐，乃至觉悟无上菩提。’那菩萨成就这样的心，具足这样的业，也具足这样的愿，对一切众生都生起乐想，常能修集，无间不断。由于这业报，得一切法乐善取三昧。

【按】“复有人人赞叹于我”，明本作“或复有人赞叹于我”，元本作“是故阴人赞叹于我”。“乐善取”之“取”，明本作“最”。

“那菩萨得此三昧时，不被众魔所动摇破坏，也不被魔事所系缚。当知这菩萨得五种自在。哪五种呢？一是寿命自在，二是受生自在，三是业自在，四是觉观自在，五是资具果报自在。那菩萨摩诃萨若想过一生便证阿耨多罗三藐三菩提，以那三昧之力便能得到。若不乐于速证无上菩提，能住无量阿僧祇劫度脱众生。为什么呢？当知那菩萨住于大乘，常为诸菩萨的导师，摄受一切其余菩萨。这位大菩萨厌离诸趣，为了众生，也受生于一切趣中，究竟一切菩萨所学，为般若波罗蜜所摄受，具足一切善巧方便之力，了知诸魔业，得法究竟。那些菩萨承佛威神，对一切法都能尽知。”

#### 遍净天以偈赞佛

那时遍净诸天便以偈颂赞叹世尊说：

```
我等一切遍净天，
于诸佛法皆尽知，
头面归敬天人师，
诸根寂静知寂灭。
解了诸义智所供，
已度生死牟尼尊，
我今赞叹大导师，
能善导他非他导。
诸法性相非究竟，
亦复无有依住处，
如来善知妄想事，
犹如幻师知幻术。
智人解了语言音，
喻若深谷诸响声，
世尊如是善知见，
一切世间天人等。
无有众生及以命，
亦复无人无寿者，
大智观察一切想，
了达众想悉归空。
二足世尊慈无等，
恒常行慈不暂舍，
一切世间诸天人，
不能测知如来智。
导师演说缘众生，
所谓慈心是善修，
了知一切诸众生，
无有众生及命者。
我等于此无垢浊，
其心清净离疑惑，
是故于佛胜智慧，
应受供者令供养。
```
（大意：我们一切遍净天，对诸佛法都已尽知，头面归敬天人之师，诸根寂静，了知寂灭。解了诸义，为智者所供养，已度生死的牟尼尊，我现在赞叹大导师，他能善于引导他人，而不为他人所引导。诸法的性相并非究竟，也没有依住之处，如来善知妄想之事，犹如幻师了知幻术。智人解了语言之音，犹如深谷中的回响，世尊这样善知善见一切世间天人等。没有众生以及命者，也没有人，没有寿者，大智者观察一切想，了达众想都归于空。二足世尊之慈无与伦比，恒常行慈，不曾暂舍，一切世间的诸天人，不能测知如来之智。导师演说以众生为缘，所谓慈心，这是善修，了知一切众生，并没有众生以及命者。我们于此没有垢浊，其心清净，远离疑惑，所以对具殊胜智慧的佛，这位应受供养者，现在加以供养。）

【按】“知寂灭”之“知”，明本作“如”。“语言音”之“音”，圣本作“事”。“悉归空”之“归”，圣本作“空”。“是善修”之“善修”，宋、元、明、宫、圣本作“善根”。“令供养”之“令”，宫、圣本作“今”，今依文意从之。

```
于其十方世界中，
求苦毕竟不可得，
如来无上天中天，
说于众生起慈心。
斯即是其世尊教，
我今得解亦如佛，
是故我于世间解，
今得供养应供者。
既无众生亦无苦，
是故无有可救度，
已得遣除心忧闷，
便获欣喜大踊悦。
如是佛教不思议，
我等已得如实知，
是故我今供养佛，
愿得如来无上智。
佛于诸趣不见苦，
涅槃亦复不可得，
增上弃舍于生死，
以此饶益诸世间。
无苦无趣无众生，
亦无涅槃而可依，
如是得知佛法已，
是故我等今供养。
```
（大意：在十方世界中寻求苦，毕竟不可得，如来无上天中天，却说要对众生生起慈心。这就是世尊之教，我现在得以理解，也如佛一样，所以我对世间解者，今得供养这位应供者。既无众生，也无苦，所以没有可救度的，已得遣除心中的忧闷，便获得欢喜，大大踊悦。这样的佛教不可思议，我们已得如实了知，所以我现在供养佛，愿得如来的无上智。佛在诸趣中不见苦，涅槃也不可得，增上弃舍生死，以此饶益诸世间。无苦、无趣、无众生，也没有涅槃可以依止，这样得知佛法之后，所以我们现在供养。）

```
佛具慈悲及喜舍，
转为世间常演说，
而复不见有众生，
得住于四无量心。
不见有其放逸者，
亦复不见不放逸，
如是知佛教法已，
我今供养大导师。
于身离身无上士，
观身毕竟不可得，
虽然亦非不有说，
而说有念失念者。
善逝常说修学念，
所谓观身正念处，
我等如是知佛法，
今得供养救度者。
世尊观受不可得，
以受无有体性故，
亦复观察于受者，
毕竟无其真实性。
又复观彼修念者，
究竟亦复不可得，
我等如是知佛性，
今得供养天人师。
```
（大意：佛具慈悲以及喜舍，辗转为世间常常演说，而又不见有众生，得住于四无量心。不见有放逸的人，也不见不放逸的人，这样了知佛的教法之后，我现在供养大导师。于身而离身的无上士，观身毕竟不可得，虽然如此，也并非不说有，而说有念与失念的人。善逝常说修学念，就是观身的正念处，我们这样了知佛法，今得供养救度者。世尊观受不可得，因为受没有体性，也观察受者，毕竟没有真实之性。又观察那修念的人，究竟也不可得，我们这样了知佛性，今得供养天人师。）

【按】“佛具慈悲”之“具”，宫、圣本作“见”。“得住于四无量心”，圣本作“得依住于四无量”。“不有说”之“有说”，宋、元、明、宫、圣本作“说念”。“知佛性”之“性”，宋、元、明本作“法”。

```
观心及以心数法，
毕竟无体不可得，
亦复不见有修念，
及以正住念处者。
佛说念与心和合，
乐求解脱应修学，
我等如是知佛教，
今得供养正遍知。
如来不见有诸法，
亦复不见修法者，
大圣所说修习念，
彼念亦复性自空。
复说念与法和合，
欲求解脱应当修，
我等如是知佛法，
今得供养一切智。
念处一尚不可得，
何况而复有三四，
所谓于彼念住处，
彼诸念处皆悉无。
是故真求不可得，
毕竟无受苦乐者，
我等如是知圣教，
今得供养佛世尊。
```
（大意：观心以及心数法，毕竟无体，不可得，也不见有修念的人，以及正住于念处的人。佛说念与心和合，乐求解脱的人应当修学，我们这样了知佛教，今得供养正遍知。如来不见有诸法，也不见修法的人，大圣所说的修习念，那念也是自性空。又说念与法和合，想求解脱应当修习，我们这样了知佛法，今得供养一切智者。一个念处尚且不可得，何况还有三个、四个，所谓在那念住之处，那些念处都是无有。所以真正去求，不可得，毕竟没有受苦乐的人，我们这样了知圣教，今得供养佛世尊。）

```
牟尼所说四正勤，
若有比丘专修习，
斯即能为解脱路，
当得出于生死海。
而无解脱无缚者，
无佛无教及菩提，
然复不坏假名用，
是故我今供大圣。
佛说四种如意足，
胜妙安隐解脱道，
寂静诸根众生辈，
修行此道得涅槃。
如意及足修行者，
真实观察不可得，
而非断绝示有作，
智慧境界不可见。
如是世尊教法中，
我等于此皆悉知，
其心清净无垢秽，
皆得远离诸疑惑。
以斯即为上供养，
供养堪受胜供者，
是故妙智无伦匹，
我今悉得修供养。
```
（大意：牟尼所说的四正勤，若有比丘专心修习，这就能成为解脱之路，当得出离生死之海。然而没有解脱，没有被缚者，没有佛，没有教以及菩提，然而又不破坏假名之用，所以我现在供养大圣。佛说四种如意足，是殊胜美妙安隐的解脱之道，诸根寂静的众生们，修行此道得涅槃。如意以及足、修行者，真实观察都不可得，然而并非断绝，示现有作，这是智慧的境界，不可得见。在这样的世尊教法中，我们于此都已了知，其心清净，没有垢秽，都得以远离种种疑惑。以此就是上等的供养，供养堪受殊胜供养者，所以对这妙智无与伦比者，我现在都得以修行供养。）

【按】“无伦匹”之“匹”，圣本作“返”。

```
世间解者说五根，
出世能趣解脱道，
慎莫放逸常勤修，
是为趣向涅槃路。
无根及以修根者，
亦无解脱及脱者，
我等于此悉无疑，
是故今得供养佛。
导师所说五种力，
非邪能趣涅槃城，
此能尽灭烦恼缚，
令诸缚者得解脱。
彼诸力体性自空，
烦恼及佛皆亦无，
我等于此无疑虑，
是故今得供如来。
大仙所说七种善，
菩提分法最胜道，
能解一切众生缚，
趣向涅槃大正路。
无有系缚及解脱，
亦无受缚得脱者，
我等于斯无疑惑，
是故今得供养佛。
```
（大意：世间解者宣说五根，能出世趣向解脱之道，切莫放逸，常常勤修，这是趣向涅槃之路。没有根以及修根的人，也没有解脱以及得脱的人，我们对此都无疑惑，所以今得供养佛。导师所说的五种力，不是邪道，能趣向涅槃之城，这能尽灭烦恼之缚，令被缚者得解脱。那些力的体性本自空，烦恼以及佛也都没有，我们对此没有疑虑，所以今得供养如来。大仙所说的七种善，是菩提分法中最殊胜之道，能解一切众生之缚，趣向涅槃的大正路。没有系缚以及解脱，也没有受缚而得脱的人，我们对此没有疑惑，所以今得供养佛。）

```
世尊说此八正路，
显示一切诸群生，
是诸烦恼苦之本，
修学圣道能断除。
斯等二法离对治，
所谓圣路及烦恼，
诸天于此悉无疑，
故今供养应供者。
修奢摩他及舍那，
斯道能尽诸苦边，
令受诸苦习气垢，
世尊旷劫已荡除。
奢摩他及舍那果，
是等一切皆悉空，
天众于此离疑网，
是故我等今供养。
佛说不净治贪欲，
慈心对治于瞋恚，
毘婆舍那痴对治，
如来显示诸众生。
斯皆无作无暂停，
是故无垢亦无净，
我等于是悉无疑，
常乐供养大导师。
```
（大意：世尊宣说这八正道，显示给一切群生，这些烦恼是苦的根本，修学圣道能够断除。这两种法远离对治，就是圣道以及烦恼，诸天于此都无疑惑，所以现在供养应供者。修习奢摩他以及舍那，此道能尽诸苦的边际，使人受诸苦的习气之垢，世尊旷劫以来已经荡除。奢摩他以及舍那之果，这一切都是空，天众对此远离疑网，所以我们现在供养。佛说以不净对治贪欲，以慈心对治瞋恚，以毗婆舍那对治愚痴，如来向众生显示。这些都是无作，没有暂时的停住，所以无垢也无净，我们于此都无疑惑，常乐供养大导师。）

【按】“令受诸苦”之“令”，宋、宫本作“尔”，元、明本作“示”。“于是悉无疑”之“于”，元、明本作“如”。

```
如来所说十不善，
斯等名之为业道，
杀生偷盗及邪淫，
妄语两舌与恶口，
绮语贪欲及瞋恚，
最后第十名邪见，
佛说此等为不善，
是诸众生恶业道。
既无众生亦无害，
自余九业亦如是，
无有对治诸善恶，
以彼自性空寂故。
然复非无十力教，
以其不坏法体性，
我于佛慧亦不疑，
是故今供无上智。
若有修此如来法，
是人即为真佛子，
彼人处处皆受乐，
恒常远离诸苦恼。
如是善逝胜智慧，
安隐引导诸群生，
我等于此离疑心，
今悉供养应供者。
```
（大意：如来所说的十不善，这些名为业道：杀生、偷盗以及邪淫，妄语、两舌与恶口，绮语、贪欲以及瞋恚，最后第十名为邪见，佛说这些是不善，是众生的恶业道。既然没有众生，也就没有伤害，其余九种业也是如此，没有善恶的对治，因为它们自性空寂。然而并非没有十力者之教，因为不坏法的体性，我对佛的智慧也无疑惑，所以现在供养无上智者。若有人修习这如来之法，此人就是真佛子，此人处处都受安乐，恒常远离诸苦恼。善逝这样的殊胜智慧，安隐引导群生，我们于此远离疑心，现在都供养应供者。）

【按】“邪淫”之“淫”，宋、元、宫本作“婬”。

#### 授遍净天记

那时遍净诸天以偈赞佛之后，都默然退住一面。那时世尊见那天众默然而住，并知道那些天已有深信之心，便现出微笑。那时慧命马胜以偈颂问道：

```
今佛世尊最胜智，
为利世间现微笑，
十力世雄超一切，
而能化伏诸大众。
善解诸法大导师，
所现微笑非无因，
心无所乏世间解，
唯愿解说微笑义。
此诸大众皆一心，
无其乱想住正念，
喜心瞻仰功德山，
唯乐听闻恭敬住。
于佛自在大论师，
若得闻说必欣喜，
善解诸法决定智，
当得作佛导群生。
若人于佛生净信，
必成大智世间最，
测知微妙甘露句，
是人能观于十方。
谁于未来世劫中，
当得作佛愍世间？
微妙言辞大导师，
唯愿说彼令众喜。
```
（大意：现在佛世尊具最胜之智，为利益世间而现出微笑，十力世雄超越一切，而能化伏诸大众。善解诸法的大导师，所现的微笑并非无因，心无所乏的世间解，唯愿解说微笑之义。这些大众都一心，没有乱想，安住正念，以欢喜心瞻仰功德之山，唯乐听闻，恭敬而住。对佛这位自在的大论师，若得听闻宣说，必定欢喜，善解诸法，具决定之智，当得作佛，引导群生。若人对佛生起净信，必成大智，为世间最胜，测知微妙的甘露之句，此人能观察十方。谁在未来世劫中，当得作佛，怜愍世间？说微妙言辞的大导师，唯愿说出他们，令大众欢喜。）

```
若于圣雄沙门所，
生其敬信尊重心，
亦住正法生信慧，
一切诸魔不能动。
若能生信得决定，
即是佛子从心生，
唯愿世尊演说彼，
以是大众得除疑。
若有于其众生所，
慈心普覆遍世间，
智慧坚固当成佛，
便得安住一切智。
百福庄严无上士，
唯愿开演除疑网，
谁欲受持世尊法，
如来为其现微笑？
愿得闻佛善巧说，
具八功德微妙音，
先自得趣于善道，
后能引导诸群生。
如是善逝微妙法，
佛子得住于彼中，
世尊佛种不断绝，
必得久住于世间。
```
（大意：若在圣雄沙门之所，生起敬信尊重之心，也安住正法，生起信与慧，一切诸魔都不能动摇。若能生信，得到决定，就是从心所生的佛子，唯愿世尊演说他们，因此大众得以除疑。若有人对众生，以慈心普覆，遍满世间，智慧坚固，当成佛道，便得安住一切智。百福庄严的无上士，唯愿开演，除去疑网，是谁想要受持世尊之法，如来为他现出微笑？愿得听闻佛的善巧宣说，具八功德的微妙之音，自己先得趣于善道，然后能引导群生。像这样善逝的微妙之法，佛子得以安住其中，世尊的佛种不断绝，必得久住于世间。）

【按】“唯愿世尊”之“唯”，明本作“惟”。“演说彼”之“彼”，元、明、圣本作“法”。

那时世尊便以偈颂回答慧命马胜说：

```
马胜汝今问笑光，
我为利益诸世间，
汝获福德称其心，
斯福无量不可尽。
妙士乃能应时问，
以是大利诸众生，
汝及一切大众等，
欣喜一心听我说。
斯等遍净诸天众，
于我法中悉无疑，
一切欣喜净信心，
以偈赞颂我功德。
此天曾于过去世，
供养千亿那由佛，
亦于彼佛问斯义，
一切法中得无疑。
由彼往昔因缘故，
今以偈颂赞叹我，
亦复净心当赞叹，
贤劫一切诸如来。
当于优波罗劫中，
成佛大力那罗延，
教化不思那由众，
引导入于涅槃城。
彼诸大仙成佛时，
所得名称甚微妙，
我今为汝说彼佛，
一心寂静善谛听。
```
（大意：马胜你现在问这笑光，我是为了利益诸世间，你获得福德，称其心意，此福无量，不可穷尽。妙士才能应时发问，因此大利众生，你以及一切大众等，欢喜一心听我宣说。这些遍净诸天众，对我的法都无疑惑，一切都以欢喜清净的信心，以偈颂赞颂我的功德。这些天曾在过去世，供养千亿那由他佛，也曾在那些佛所问这义理，在一切法中得无疑惑。由于他们往昔的因缘，现在以偈颂赞叹我，也将以净心赞叹贤劫的一切如来。他们当在优波罗劫中成佛，具那罗延的大力，教化不可思议那由他众，引导他们入于涅槃之城。那些大仙成佛之时，所得的名称甚为微妙，我现在为你宣说那些佛，你一心寂静，好好谛听。）

```
同其劫中悉作佛，
号曰法幢等正觉，
咸皆救度不思议，
那由他众入涅槃。
彼诸如来灭度已，
焚身广布诸舍利，
以此舍利皆起塔，
遍满佛刹如散花。
尔时一切佛舍利，
各各皆悉广流布，
彼佛一一涅槃后，
咸皆饶益于世间。
不思那由众生辈，
供养彼佛舍利已，
当得甘露妙涅槃，
三世诸佛之所赞。
若有称彼诸佛名，
所获微妙胜善根，
当得成就有学道，
值佛转获殊胜果。
犹如无量难思众，
皆于我所种善根，
欣喜信乐清净心，
当得值遇弥勒佛。
如是彼佛声闻众，
从佛复至诸佛所，
常得值佛入众会，
皆由供养彼舍利。
```
（大意：他们在同一劫中都作佛，号为法幢等正觉，都救度不可思议那由他众入于涅槃。那些如来灭度之后，焚身，广布舍利，以这些舍利都起塔，遍满佛刹，如同散花。那时一切佛的舍利，各各都广泛流布，那些佛一一涅槃之后，都饶益世间。不可思议那由他众生们，供养那些佛的舍利之后，当得甘露的妙涅槃，为三世诸佛所称赞。若有人称念那些佛的名号，所获得的微妙殊胜善根，当得成就有学之道，值佛而转获殊胜之果。犹如无量难思之众，都在我这里种下善根，以欢喜信乐的清净之心，当得值遇弥勒佛。像这样那些佛的声闻众，从一佛之所又到诸佛之所，常得值佛，入于众会，都是由于供养那些舍利。）

【按】“难思众”之“众”，圣本作“议”。

```
得闻如斯佛语已，
一切大众生希有，
胜妙功德有威神，
遍净诸天清信士，
及诸大众普欣喜，
悉皆流注向菩提，
得知如来大势力，
咸各顶礼世尊足。
```
（大意：听闻这样的佛语之后，一切大众都生希有之心，具殊胜美妙功德、有威神的遍净诸天清信之士，以及诸大众普遍欢喜，都流注趋向菩提，得知如来的大势力，都各自顶礼世尊之足。）

【按】“胜妙功德”之“妙”，圣本作“如”。
