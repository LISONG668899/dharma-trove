# 关于我们

古文与藏文，于今日华语读者而言，确是一重实质的门槛。佛法宝藏浩如烟海，历代译师大德已倾力弘传，然而典籍浩瀚，真正转为白话、可供今人直接阅读思惟的部分，终究仍是少数。许多珍贵教言并未失传，只是仍沉睡在古文与藏文之中，与读者彼此不能相见。

近年 AI 语言工具的出现，第一次让个人或小团队有能力进入过去只有专业译者才能承担的浩繁文本。我们借助 ChatGPT、Claude 等工具协助整理与转译，但 AI 只是语言工具，不是佛法权威，更不能代替传承、闻思与实修——重要文本仍以原文为本，参照既有译本校正，遇有歧义宁可存疑，不强作确定之说。

我们所做的，不是制造更多佛教内容，而是尽量撤除语言本身造成的遮蔽，让原典重新说话。

唯识中观之精微、禅门宝箧之直截、密续法要之深广、大手印大圆满之了义、华严法界之圆融——愿借此转译之力，使佛法精华不因时移语迁而隐没于末世，令有缘读者得以直探本怀。

以此善根，回向圣教久住，愿一切有缘者，皆至佛地！
