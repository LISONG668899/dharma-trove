# 关于我们

古文与藏文，于今日华语读者而言，确是一重实质的门槛。佛法宝藏浩如烟海，历代译师大德已倾力弘传，然而典籍浩瀚，真正转为白话、可供今人直接阅读思惟的部分，终究仍是少数。许多珍贵教言并未失传，只是仍沉睡在古文与藏文之中，与读者彼此不能相见。

近年 AI 语言工具的出现，第一次让个人或小团队有能力进入过去只有专业译者才能承担的浩繁文本。我们借助 ChatGPT、Claude 等工具协助整理与转译，但 AI 只是语言工具，不是佛法权威，更不能代替传承、闻思与实修——重要文本仍以原文为本，参照既有译本校正，遇有歧义宁可存疑，不强作确定之说。

我们所做的，不是制造更多佛教内容，而是尽量撤除语言本身造成的遮蔽，让原典重新说话。

**藏文原典**：本站收录德格版《甘珠尔》与《丹珠尔》藏文全文，读者可以直接阅读佛陀教言与印度论师论典的藏文原貌。阅读时选中一段藏文，可以请机器即时译成白话。机器译文只是方便初读的参考，难免疏漏，一切以藏文原文为准。在网站顶部的搜索框里输入藏文，可以在《甘珠尔》《丹珠尔》全部经论里检索，经名相符的排在最前，正文里找到的每一处都附有前后文，点开即跳到原文并标出所搜的字。

**划线收藏与导出**：阅读任何一篇文章时，选中一段文字即可划线收藏，收藏的段落会画上金色下划线，并按文章汇集在“我的收藏”里；藏文原典的原文与译文也可以一并收藏。收藏的内容可以随时导出为 PDF、Word 或纯文本，便于抄录、研读与分享。

**不收集读者信息**：本站不设注册，不记录读者的姓名、IP 等任何个人信息。收藏只保存在读者自己设备的浏览器里，换手机或清除浏览器数据后会消失，请记得导出留存。

**我们的使命**：承继利美精神，不拘宗派，致力于藏汉显密佛法精华文献的发掘、白话转译与长久保存，愿正法余晖，于末世愈加灿耀。

唯识中观之精微、禅门直指之峻烈、密续法要之深广、大手印大圆满之了义、华严法界之圆融——愿借此转译之力，令有缘读者得以直探本怀。

以此善根，回向圣教久住，愿一切有缘者，皆至佛地！
